# 设计规范 · Graphite & Amber / 精装仪表

> 这份文件是**唯一标准**。改样式前先在这里找到对应的令牌，不要在组件里现编数值。
> 令牌实现：`app/src/styles/tokens.css`；排版基线：`app/src/styles/base.css`。

---

## 0. 为什么要有这份规范

一次审计（用 CDP 统计渲染后的计算样式）暴露了三类问题：

| 问题 | 证据（改版前） |
| --- | --- |
| 字号失控 | 单页出现 12 种字号：9 / 9.5 / 10 / 10.5 / 11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 14 / 15.5；半像素字号在 100% 缩放下会抖 |
| 颜色两套 | 深色底上还残留暖纸色：`#8f8470`、`#6d6a62`、`#a8a195`、`rgba(231,221,201,.3)` —— 这些是浅色主题的遗物 |
| 圆角失控 | 同时存在 0 / 2 / 3 / 4 / 6 / 8 / 10 / 12 / 14 / 999 / 50% 共 11 种 |
| 字体名是假的 | `--font-body` 首位写的是 `'Inter'`，但项目从没装过 Inter，实际渲染的是 Segoe UI / PingFang |

### 改版结果（同一套审计脚本，改版后）

| 指标 | 改版前 | 改版后 |
| --- | --- | --- |
| hex 颜色字面值 | 215 | **1**（`base.css` 里 `::selection` 的白） |
| `rgba()` 字面值 | 83 | **5**（滚动条 / 选中态 / 背景光晕） |
| 写死 `font-size` | 251 处、31 种取值 | **0**（全部走令牌） |
| 写死 `border-radius` | 52 处 | **1**（滚动条滑块） |
| 手写 `box-shadow` | 8 | **0**（全部走 `--shadow-*` / `--mat-*` / `--ring-*`） |
| 单页渲染字号档数 | 12 | **6–10** |

复跑方式：`python tools/audit_style.py`（脚本说明见文件头）。

> 改版目标不是「换个好看的颜色」，而是**把显示层收敛成一套可预测的规则**，同时让不同区域有明确的材质差异。

## 1. 主张：四种材质

整个界面只允许存在四种材质。**跨材质混用是最容易「看着不专业」的地方。**

| 材质 | 用在哪 | 背景 | 描边 | 圆角 | 阴影 | 字体 |
| --- | --- | --- | --- | --- | --- | --- |
| **chrome** 外壳 | 侧栏、顶栏 | `--mat-chrome`（最暗最冷） | 只在与内容交界处 1px `--border-subtle` | 0 | 无 | UI |
| **content** 内容 | 卡片、表格、表单、统计块 | `--mat-content-bg` | 1px `--mat-content-border` | `--r-lg` | `--shadow-1` + `--inset-top`（顶部 1px 微高光，制造「抬起」） | UI |
| **code** 代码 | 编辑器、终端、代码块、行内代码 | `--mat-code-bg`（比 content 更暗更冷，偏蓝） | 1px `--border-code` | `--r-code`(2px) | `--inset-code`（内阴影，制造「凹进去」） | mono |
| **reading** 阅读 | 题面、精讲、解析正文 | 透明（落在 canvas 上） | 不用盒子，用分割线 / 左侧竖线 | 0 | 无 | UI + display 标题 |

**编辑器内外的差异就是 content ↔ code 的差异**：进入代码区时，底色更暗更冷、圆角几乎变方、阴影从「凸起」变成「凹陷」、字体切换成等宽。这三件事同时发生，用户才能感到「换了个东西」。

## 2. 字体

### 2.1 字体族（已捆绑，见 `main.tsx`）

| 令牌 | 字体 | 用途 |
| --- | --- | --- |
| `--font-ui` | Instrument Sans Variable → PingFang SC / 微软雅黑 / Noto Sans SC | 界面与正文。**拉丁字母用捆绑字体，中文自动回落系统黑体** |
| `--font-display` | Fraunces Variable → Songti SC | 大标题、衬线数字（「印刷品」气质） |
| `--font-mono` | JetBrains Mono Variable | 代码、题号、快捷键、标识符 |
| `--font-num` | Fraunces Variable | 30px 以上的统计数字 |
| `--font-data` | JetBrains Mono Variable | 表格里的数值列（等宽对齐） |

> 不再使用 `'Inter'` 这种没装的字体名。中文 Web 字体动辄数 MB，本项目**不引入**，靠系统黑体 + 拉丁捆绑字体混排。

### 2.2 字号阶梯（只有这 10 档）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--fs-2xs` | 10px | 图例、极小元信息（**谨慎使用**） |
| `--fs-xs` | 11px | 标签、辅助说明、eyebrow |
| `--fs-sm` | 12px | 次要正文、表格副信息、徽标 |
| `--fs-md` | 13.5px | **正文与控件基准** |
| `--fs-lg` | 15px | 小标题、强调正文 |
| `--fs-xl` | 17px | 区块标题 |
| `--fs-2xl` | 21px | 卡片大标题 |
| `--fs-3xl` | 26px | 页面标题 |
| `--fs-4xl` | 34px | 大标题 |
| `--fs-5xl` | 44px | hero（配 `clamp()`） |

### 2.3 行高 / 字距 / 字重

- 行高：`--lh-tight` 1.2（大标题）、`--lh-snug` 1.4（标题、控件）、`--lh-normal` 1.6（拉丁正文）、`--lh-cjk` 1.75（中文正文）、`--lh-loose` 1.85（阅读区）
- 字距：中文**不要**加字距；拉丁大标题 `--ls-tight` -0.02em；全大写拉丁标签 `--ls-caps` 0.12em；普通小标签 `--ls-wide` 0.06em
- 字重只用 400 / 500 / 600。**不要用 700**（中文会变糊，且微软雅黑只有 400/700，700 会显得突兀）

### 2.4 中文排版硬规则

1. 正文中文行高 ≥ 1.7；阅读区 1.85
2. `text-transform: uppercase` 对中文无意义 —— 只给纯拉丁文本用（`.eyebrow--caps`）
3. 不要 `word-break: break-all`；用 `overflow-wrap: break-word`（已在 `base.css` 处理）
4. 中西混排时，数字和英文标识符用等宽（`.mono` / `.data`）比用比例字更整齐
5. 标题用 `text-wrap: balance`，段落用 `text-wrap: pretty`（已在 `base.css`）

### 2.5 数字

- 大数字（≥30px）：`.num`（Fraunces + tnum）
- 表格/统计数值：`.data`（JetBrains Mono + tnum），右对齐
- 不要给正文里的数字加 `tabular-nums`（比例数字更好读）

## 3. 颜色

### 3.1 表面（从暗到亮）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--bg-chrome` | `#07090b` | 侧栏、顶栏 |
| `--bg-canvas` | `#0a0c0f` | 页面底 |
| `--bg-code` | `#0a0e13` | 编辑器/终端/代码块（冷色） |
| `--bg-code-2` | `#0f141a` | 代码区内嵌块、输入 |
| `--bg-surface` | `#12161b` | 卡片 |
| `--bg-surface-2` | `#171c22` | 卡片 hover、次级面板 |
| `--bg-surface-3` | `#1d232b` | 输入框、标签底 |
| `--bg-surface-hover` | `#232a33` | 按钮 hover |
| `--bg-overlay` | `rgba(5,7,10,.72)` | 弹层遮罩 |

### 3.2 文字（对比度按 canvas 计算）

| 令牌 | 值 | 对比度 | 用途 |
| --- | --- | --- | --- |
| `--text-1` | `#e9edf2` | ≈15:1 | 正文、标题 |
| `--text-2` | `#a3adb9` | ≈8:1 | 次要正文 |
| `--text-3` | `#7d8894` | ≈4.7:1 | 辅助说明、占位 |
| `--text-4` | `#5b6672` | ≈3.1:1 | **只用于装饰**，不要承载信息 |

### 3.3 描边

`--border-subtle` 6% / `--border-default` 10% / `--border-strong` 16%（白）。深色界面里**描边比阴影更重要**。

### 3.4 强调色（琥珀）

`--accent` #f5a524 只给三种东西：**当前项、主操作、关键数字**。其余一律用中性色。
配套：`--accent-hover` / `--accent-press` / `--accent-wash` / `--accent-line` / `--accent-ink`（琥珀底上的深色文字）。

### 3.5 语义色

success / danger / info 各三档：`--{sem}-text`（文字）、`--{sem}-line`（描边）、`--{sem}-wash`（底色）。
徽标、状态点、结果反馈只用这三个，不要自己调透明度。

### 3.6 代码语法色（编辑器专用）

从品牌色推导，不用第三方主题原色：`--syn-keyword`(蓝) / `--syn-string`(绿) / `--syn-number`(琥珀) / `--syn-comment`(灰 3:1) / `--syn-function`(亮白) / `--syn-type`(淡紫) / `--syn-operator` / `--syn-punct` / `--syn-gutter` / `--syn-selection` / `--syn-active-line`。

### 3.7 浅色主题（`html[data-theme='light']`）

上面 3.1–3.6 写的是**深色默认值**（`:root`）。浅色是同一个文件末尾的覆盖层，
选择器 `:root[data-theme='light']`，**只覆盖原始值和语义别名** —— 组件 CSS 一行都不用改。
开关在「设置 → 颜色模式」（深色 / 浅色 / 跟随系统），顶栏右侧还有一个深↔浅快捷按钮；
偏好存 `lc.ui.theme`，首屏由 `index.html` 的内联脚本在样式表之前定好，不会闪。

气质：**暖白纸面 + 琥珀**，不是纯白 + 冷蓝。

| 令牌 | 深色 | 浅色 | 说明 |
| --- | --- | --- | --- |
| `--bg-canvas` | `#0a0c0f` | `#f7f6f3` | 暖白纸，不是纯白 |
| `--bg-chrome` | `#07090b` | `#efece6` | 侧栏 / 顶栏 / 标题栏（像纸的背面） |
| `--bg-surface` | `#12161b` | `#ffffff` | 卡片才用纯白，这样「抬起来」 |
| `--bg-surface-2` | `#171c22` | `#f4f2ed` | 卡片 hover、次级面板 |
| `--bg-surface-3` | `#1d232b` | `#e9e6df` | 输入框、标签底、键帽 |
| `--bg-code` | `#0a0e13` | `#f3f1ec` | 代码区在浅色下比 canvas **略暗一档**，和正文区分开 |
| `--text-1` | `#e9edf2` | `#1c1b18` | 对 canvas **15.9:1** |
| `--text-2` | `#a3adb9` | `#4d4a44` | **8.2:1** |
| `--text-3` | `#7d8894` | `#6a665f` | **5.3:1**（在 chrome / surface-3 上也 ≥ 4.6） |
| `--text-4` | `#5b6672` | `#9a958d` | 2.8:1，**只做装饰** |
| `--border-*` | 白 6 / 10 / 16% | 黑 8 / 12 / 18% | `--border-subtle` 统一指向 `--hairline` |
| `--wash-1/2/3` | 白 4 / 12 / 22% | 黑 3 / 8 / 14% | 「叠层高光」：内高光、滚动条、反光、涟漪、流光 |
| `--shadow-1/2/3` | 0 1px 2px `.5` … | 0 1px 2px `.06` … | 浅色下阴影要淡一个数量级 |
| `--inset-top` | 白 4.5% | 白 75% | content 顶部微高光 |
| `--inset-code` | 黑 55% 凹陷 | 黑 4% 凹陷 | 代码材质的「凹进去」 |
| `--accent` | `#f5a524` | `#f5a524` | **填充**仍是亮琥珀，配 `--accent-ink` 深色字 |
| `--accent-ink` | `#1a1206` | `#241a06` | 琥珀底上的文字，浅色下依然是深色 |
| `--accent-text` | `#f5a524` | `#7d4a00` | 琥珀当**文字**用：浅色下必须压深，否则 1.9:1 |
| `--accent-text-soft` | `#ffc46b` | `#885200` | 同上，次要一档 |
| `--accent-display` | `#f5a524` | `#b26a00` | 仅 hero 那种 ≥26px 的 display 标题（大字号 3:1 即可） |

规则：

1. **琥珀只分两种角色**：填充（`--accent` / `--accent-soft`）和文字（`--accent-text` / `--accent-text-soft`）。
   写 `color:` 时用后者，写 `background:` / `border-color:` 时用前者 —— 混用会在浅色下变成「白底亮黄字」。
2. **不要在 CSS 里写白/黑半透明**（`rgba(255,255,255,.12)` 这种）。深色下是「叠白」的地方，
   浅色下必须「叠黑」，所以统一走 `--wash-*` / `--hairline` / `--accent-glow` 等令牌。
3. 语法色浅色版：`--syn-keyword` `#1d5fa8`、`--syn-string` `#1f7a4d`、`--syn-number` `#9a5b00`、
   `--syn-comment` `#6f6a62`、`--syn-type` `#6b4fa8`、`--syn-function` `#1c1b18`，
   对 `--bg-code` **全部 ≥ 4.5:1**（行号槽 3.3:1，装饰性，深色下是 2.6:1）。
4. `color-scheme` 跟着主题走（`:root` 是 `dark`，浅色覆盖层是 `light`），原生滚动条 / 表单控件才会一起变。
5. 新增组件时**两套主题都要看一眼**：只写深色的颜色值，浅色下一定会坏。

## 4. 间距 / 尺寸 / 圆角 / 阴影

- 间距：4px 基准，`--sp-1`=4 … `--sp-9`=56。**不要写 5px / 7px / 9px / 13px 这类值**
- 控件高度：`--h-sm` 26 / `--h-md` 32 / `--h-lg` 38
- 圆角：`--r-xs` 3 / `--r-sm` 5 / `--r-md` 8 / `--r-lg` 12 / `--r-xl` 16 / `--r-pill` 999 / `--r-code` 2
- 阴影：`--shadow-1`（卡片）/ `--shadow-2`（浮起）/ `--shadow-3`（弹层）；`--inset-top`（content 高光）/ `--inset-code`（code 凹陷）
- 焦点环：`--ring-accent` / `--ring-info` / `--ring-danger`（3px wash）

## 6. 组件配方

- **按钮**：高 32（sm 26 / lg 38），圆角 `--r-md`，`--fs-sm`，字重 500。primary = 琥珀渐变 + `--accent-ink` 文字 + 顶部内高光；secondary = `--bg-surface-2` + `--border-default`；ghost = 透明 + hover 才出底色。三者 hover 都必须改变**至少两个属性**（底色 + 描边）。
- **输入**：高 32，`--bg-surface-3`，`--border-subtle`，focus 时 `--accent-line` + `--ring-accent`。占位文字 `--text-3`。
- **卡片**：`--mat-content-*`；hover 只提亮到 `--bg-surface-2` + `--border-default`，**不要**同时放大和加深阴影（会显得廉价）。
- **表格**：表头 `--fs-xs` + `--text-3`；行高 40；hover `--bg-surface-2`；数值列 `.data` 右对齐；分组行用 `--border-strong` 上边线 + 专题名 `--fs-lg`。
- **徽标/标签**：高 20/21，`--r-pill`（状态）或 `--r-xs`（标签），`--fs-xs`，语义色三档。
- **弹层**：`--mat-overlay-*`，`--r-xl`，遮罩 `--bg-overlay` + `backdrop-filter: blur(8px)`。
- **提示气泡**：`--bg-surface-3` + `--border-default`，`--fs-xs`，`--shadow-2`。

## 7. 代码材质（编辑器 / 终端 / 代码块）

1. 背景 `--bg-code`，外框 `1px --border-code`，圆角 `--r-code`，内阴影 `--inset-code`
2. 字体 `--font-mono`，字号 `--fs-code`（13px，等宽字体的视觉重量比比例字体轻，所以单独给一档），行高 1.65
3. 行号 `--syn-gutter`，不抢视线；当前行背景 `--syn-active-line`
4. 选中 `--syn-selection`
5. **必须用第 3.6 节的语法色**，不能保留 One Dark 的原始紫/绿
6. 工具条属于 code 材质的一部分：背景 `--bg-code-2`，与编辑器区用 1px `--border-code` 分隔
7. 代码块（prose 里的 `pre`）：同背景，但圆角 `--r-sm`，且**不要**再加内阴影（嵌在阅读区里，避免双层凹陷）

## 8. 阅读材质（题面 / 精讲 / 解析）

1. 不套卡片：直接落在 canvas 上，靠排版节奏分隔
2. 正文 `--fs-md`–`--fs-lg`，行高 `--lh-loose`（1.85），段间距 `1em`
3. 标题用 `--font-display`，层级靠字号 + 上间距，不靠颜色
4. 正文最大宽度约 `68ch`（中文约 38–42 字/行）
5. 引用块：左侧 2px `--accent` 竖线 + `--bg-surface` 底
6. 行内代码：`--bg-surface-3` + `--accent-soft` 文字 + `--r-xs`
7. 表格：`--border-subtle` 横线，表头 `--bg-surface-2`

---

## 9. 禁止事项

1. 不要新增颜色值、字号、圆角、阴影 —— 只能用令牌
2. 不要用 `!important`（除非覆盖第三方库，且要写注释说明）
3. 不要给整块大内容加 `filter: blur()` / `backdrop-filter`（性能和可读性都差）
4. 不要把琥珀色当装饰大面积使用
5. 不要在深色底上用纯白 `#fff` 做正文（太刺眼，用 `--text-1`）
6. 不要混用材质：卡片里嵌卡片、阅读区里嵌卡片、代码区里用 `--r-lg`
