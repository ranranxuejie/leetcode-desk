# 使用指南 · LeetCode 训练台

> 一份「第一次拿到这个项目，怎么跑起来、数据在哪、怎么不丢」的说明。
> 面向使用者，不面向改代码的人（改代码看 [app/README.md](../app/README.md)）。

## 一、怎么打开

三种方式，任选一种：

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| **桌面版（推荐）** | 双击 `launcher\LeetCode训练台.exe` | 日常刷题。无边框窗口、深色自绘标题栏、无地址栏 |
| 浏览器 | 在 `app` 目录执行 `npm run dev`，打开 <http://127.0.0.1:5173> | 边改代码边看效果 |
| 静态产物 | `npm run build` 后用 `launcher\server.mjs` 起服务 | 不装 Node 依赖时 |

> 地址一定要固定用 **`127.0.0.1`**。用 `localhost` 打开是另一个 origin，进度会「看起来丢了」（其实是另一份 localStorage）。

## 一·六、想要「像软件一样安装」？

双击 `launcher\LeetCode训练台-安装程序.exe`（约 45MB）：

- 装到当前用户目录，**不需要管理员权限**，装完桌面和开始菜单都有图标；
- 卸载走「设置 → 应用 → 已安装的应用」，**默认保留学习进度**；
- 内嵌 Node 运行时，装完不用再装 Node.js。

如果你只是自己用这台机器，直接双击 `launcher\LeetCode训练台.exe` 也一样（免安装）。

## 一·五、桌面版的窗口

桌面版是**无边框窗口**：标题栏由应用自己画（左侧「题」印章 + 应用名 + 当前页面，右侧最小化 /
最大化 / 关闭），颜色和内容区一致，不再是一条浅灰的浏览器标题栏。

- 按住标题栏空白处拖动窗口；双击标题栏最大化/还原；拖到屏幕边缘仍会触发系统分屏（Aero Snap）。
- 窗口大小和位置不会跨次记忆（每次居中打开），需要的话可以自己拖。
- **第一次启动会把旧版（Chrome 窗口）的进度自动搬过来**：会闪一个小窗口（约 2 秒），
  那是迁移用的，完成后自动关闭。Chrome 里的数据不会被删。

## 一·七、颜色模式

顶栏右侧有个 ☀/☾ 按钮，点一下在深色和浅色之间切换；也可以去「设置 → 颜色模式」选三档：

| 档位 | 说明 |
| --- | --- |
| 深色（默认） | 原来的样子，晚上/暗环境 |
| 浅色 | 暖白纸感，白天/亮环境；代码区会略微压暗一档，和正文区分开 |
| 跟随系统 | 跟着 Windows 的浅色/深色设置走，系统切换时界面实时跟随（不用刷新） |

选择存在 `lc.ui.theme`，刷新后保持。两套主题的正文对比度都在 7:1 以上（浅色正文 15.9:1）。

## 二、每天怎么用

1. **今日页**：四张卡是入口 —— 已掌握 / 连续学习 / 今日运行 / 错题待消化，点哪张看哪张。
2. **今日计划**：点「按路线排 3 题」，按学习路线（专题由浅入深）给你排当天的题；做完打勾。
3. **题目页**左侧是题面（题面 / 解析 / 精讲 / 我的笔记），右侧是代码台：
   - 写代码 → `Ctrl + Enter` 运行；
   - 官方示例是硬标准，标着「边界」的用例是构建期按类型生成的，**与参考解不一致只提示、不判红**；
   - 卡住时：解析 tab 里有「参考答案」（AI 生成，只保证过官方示例，**先自己想 20 分钟**）。
4. **错题本**：题目页右上角「记为错题」，之后在错题本里复习；复习通过会记一次。
5. **统计**：热力图、专题分布、难度分布、全过率、提交记录。

## 三、快捷键

按 **`?`** 随时打开快捷键总览（表里的每一条都对应真实绑定）。常用的：

| 键 | 作用 |
| --- | --- |
| `Ctrl/⌘ K` | 全局搜索（题目 / 教程章节） |
| `Ctrl/⌘ B` | 收起 / 展开侧边栏 |
| `?` | 快捷键总览 |
| `/` | 题库页聚焦搜索框 |
| `j` / `k` | 题库里上下移动选中行，`Enter` 打开 |
| `Ctrl/⌘ Enter` | 运行代码 |
| `Ctrl/⌘ \`` | 聚焦 Python 终端 |
| `Ctrl L` | 清空终端 |

> Windows 上显示 `Ctrl`，mac 上显示 `⌘`（按平台自动切换）。

## 四、数据存在哪 · 怎么不丢

- **进度全部在浏览器 localStorage**，键名 `lc.progress.v1`。没有账号、没有云端。
- 界面偏好（侧栏宽度、分栏比例、编辑器字号等）在 `lc.ui.*`，导出进度时**不会**带出去。
- **导出 / 导入**：设置弹窗（顶栏右上角齿轮）→「本地数据」→ 导出 JSON。今日页超过 7 天没备份会给一次提醒。
- 会丢进度的操作：清浏览器数据、换浏览器、换端口（`127.0.0.1` ↔ `localhost`）、隐私模式。
- 存档版本现在是 **v3**；v1/v2 的老文件导入时会自动迁移（补空字段，不重算历史）。

## 五、题库和内容是哪来的

| 内容 | 数量 | 来源 |
| --- | --- | --- |
| 题目 | 4504 道 | 力扣公开目录（`data/lc_catalog.json`） |
| 题面 / 示例 | 4152 道有题面、3575 道有示例 | 力扣 GraphQL 抓取（`data/statements_full.json`） |
| 精选题精讲 | 365 道 | 手工整理的精讲 markdown |
| Hot 100 AI 精讲 | 100 篇（平均 ~4800 字） | DeepSeek 读题面后生成 |
| 边界用例 | 3806 道 / 22733 条 | 按 LeetCode `metaData` 参数类型生成 |
| 有期望输出的边界用例 | 2934 道 / 12126 条 | 参考解跑出来的（AI 生成，先过官方示例） |
| AI 参考解 | 3105 道 | DeepSeek 生成，**只保证过官方示例** |

## 六、已知限制（用之前先知道）

1. **AI 参考解只过官方示例**：边界情况、特殊输入没经过验证，别当标准答案背。
2. **边界期望有 ~3.6% 的不一致率**（实测抽样：74% 来自越界输入），所以「与参考解不一致」只提示、不判红、不计入通过。
3. **53% 的边界用例有期望输出**，其余「只运行不判定」—— 看到「判定 0 · 只运行 N」是正常的，不是没跑。
4. **790 道会员题没有题面**（只有元数据和标签），点进去只有「去力扣看题」入口。
5. 窄屏（< 980px）是单栏布局；手机浏览器能用但没专门适配（题库表格的标题列会被挤窄）。
6. 没有云端同步、没有多设备进度合并。

## 七、改代码前先跑回归

```bash
cd app
npm run unit     # 34 条纯函数断言（判题规则 / 顺序白名单 / 筛选 / 用例构建 / 复习节奏）
npm run verify   # 16 项页面级回归（自己拉无头 Chrome，约 3 分钟）
npm run firstrun # 干净 profile 走一遍新用户全流程（5 步）
npm run check    # tsc + oxlint + 单测 + 回归，一条命令全跑
```

改任何 UI 或判题逻辑之前跑 `npm run check` —— 这是唯一的防线。两个脚本都**不需要装测试框架**：单测在浏览器里 `import` 真实 TS 模块跑断言，回归用 CDP 驱动真实页面。

## 八、出问题时

| 现象 | 原因 / 处理 |
| --- | --- |
| 打开还是旧题库 | 桌面版老版本把 `data/*.json` 标成了「一年不可变」缓存；现在改成协商缓存 + 前端 `no-store`。强刷一次（`Ctrl+Shift+R`） |
| 题目页白屏 | 现在有错误边界：外壳保留、内容区出错误卡片，可「重试 / 回今日 / 清空这道题的记录」 |
| 进度看起来丢了 | 先看地址栏是不是 `localhost` 而不是 `127.0.0.1` |
| AI 功能不可用 | 需要 `app/.env.local` 里的 `DEEPSEEK_API_KEY`；改完重启 |
| 端口 5173 被占用 | 桌面版会复用已有服务；如果是别的程序占着，先关掉它 |

## 九、重建数据后必跑自检

```bash
python tools/audit_data.py        # 数据自检（规模下限 + 边界用例语法 + 分片完整性）
```

它会检查 `exampleCount` / `edgeExpectedTotal` / `refCodeCount` 这些数字有没有被某次重建悄悄冲掉（这个坑踩过一次），并校验 22739 条边界用例的调用表达式都是合法 Python。任何一项不达标就 exit 1。
