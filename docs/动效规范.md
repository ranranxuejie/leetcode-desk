# 动效规范 · 词汇表与参数

> 这份文档解决两个问题：
> 1. **怎么描述** —— 说得出名字和参数，才能让 AI 一次做对，也才能和设计对齐；
> 2. **这个项目做到哪了** —— 每条都标了实现状态，没做的写清为什么不做。
>
> 配套：`docs/设计规范.md`（颜色 / 排版 / 材质）。代码在 `app/src/lib/motion.tsx` + `app/src/styles/motion.css`。

---

## 〇、三条底线

1. **动效是反馈，不是装饰**。用户点了一下，界面必须在一个节拍内回应（≤150ms 开始、≤400ms 结束）。
2. **能用 CSS 就不上 JS**；能用一次性的 `IntersectionObserver` 就不挂滚动监听。
3. **降级优先**：`prefers-reduced-motion: reduce` 或 `html[data-motion='off']` 时，所有位移/缩放归零，只留透明度变化。

本项目的三档开关在「设置 → 动效强度」：**完整 / 克制 / 关闭**，对应 `html[data-motion]`。

## 一、鼠标交互动效（6 个）

| # | 名称 | 关键参数 | 本项目 |
| --- | --- | --- | --- |
| 1 | 悬停反馈 Hover Feedback | 上浮 2px、阴影加深、背景加深 8%、150ms `ease-out`、光标变手型 | ✅ 按钮 / 卡片 / 表格行 / chip 全站统一 |
| 2 | 下拉菜单 Dropdown Menu | 展开 200ms；移出稍等再收起；斜着移出 | ✅ 自绘下拉（`components/Select.tsx`），180ms + 6px 位移，`data-placement` 决定向上/向下翻 |
| 3 | 磁吸按钮 Magnetic Button | 靠近时最大偏移 30px（本项目 12px），离开弹回 | ⚠️ 未做：磁吸会让人「点偏」，训练台是长时间工具，不适合 |
| 4 | 自定义光标 Custom Cursor | 12px 圆点 + 轻微延迟；悬停按钮放大到 48px 半透明环；触屏不启用 | ✅ `PointerFx`（点 + 环 + 拖尾），代码区自动让位给系统 I-beam |
| 5 | 光标聚光灯 Cursor Spotlight | 半径 240px、透明度 15%、照亮范围内卡片边框 | ✅ 点阵推开 + 卡片聚光（`--accent-spot`），半径 120px |
| 6 | 倾斜卡片 Tilt Card | ≤10°，移出 300ms 复位 | ✅ 首页统计卡（`--tilt-x/y`，最大 6°） |

**为什么磁吸不做**：视频里它是「引导用户点主按钮」的营销页技巧。这个应用的主循环是「筛选 → 读题 → 写码」，磁吸会让精确点击变难。

## 二、滚动交互动效（4 个）

| # | 名称 | 关键参数 | 本项目 |
| --- | --- | --- | --- |
| 7 | 滚动渐显 Scroll Reveal | 进入视口 15% 时从下方 24px 淡入，400ms 缓出，同组依次延迟 80ms，只播一次 | ✅ `Reveal`（IntersectionObserver，`rootMargin: -15%`，延迟 `index * 60ms`） |
| 8 | 导航吸顶 Sticky Navigation | 吸顶后收矮到 48px + 毛玻璃 | ✅ 顶栏 56px，滚动时 `--scroll-pct` 驱动顶部进度条（**不改变高度**，避免布局跳动） |
| 9 | 平滑滚动 Smooth Scroll | 400ms 滚到目标；到达后高亮当前章节 | ✅ 精讲目录跳转（`scrollIntoView({ behavior: 'smooth' })` + 目标闪烁） |
| 10 | 回到顶部 Back to Top | 滚过一屏浮出；点击回顶；到顶隐藏 | ✅ 题目页长题面（滚动超过 1 屏出现） |

**吸顶为什么不做「收矮」**：这个应用顶部已经有面包屑 + 搜索 + 状态，收矮会让它们跳位；改用「顶部 2px 进度条」表达滚动进度，信息量更大、成本更低。

## 五、弹簧参数速查

原生 CSS 没有弹簧，本项目用 `cubic-bezier` 近似；要真弹簧就上 `linear()` 或 WAAPI `spring()`（浏览器支持还不齐）。

| 手感 | 推荐曲线 | 用在哪 |
| --- | --- | --- |
| 快速响应、不过冲 | `cubic-bezier(.2,.7,.2,1)` | 悬停、按下、下拉展开 |
| 有回弹（模拟 260/12） | `cubic-bezier(.34,1.56,.64,1)` | 打勾、达成、弹窗进场 |
| 收尾很稳（模拟 200/15） | `cubic-bezier(.22,1,.36,1)` | 横幅、Toast |
| 线性 | `linear` | 进度条、倒计时条 |

| 名称 | 刚度 | 阻尼 | 对应本项目 |
| --- | --- | --- | --- |
| 按压回弹 | 260 | 12 | `--ease-spring` |
| 弹性开关 | 200 | 14 | — |
| 点赞 | 300 | 10 | — |
| 磁吸 | 150 | 15 | — |

> 时长参考：位移 ≤ 24px 用 200–260ms；整屏切换 300–400ms；超过 500ms 用户会觉得卡。

## 六、页面骨架：6 个区域

观察任何页面都可以拆成这 6 块。**本项目对应的实现**：

| 区域 | 作用 | 本项目 |
| --- | --- | --- |
| ① 页眉 Header | 标识 + 名称，让用户知道在哪 | 侧栏顶部「题」印章 + 应用名；桌面版还有自绘标题栏 |
| ② 导航栏 Navigation | 主要入口，标出当前位置 | 左侧栏（今日 / 题库 / 教程 / 错题本 / 统计）+ 顶栏面包屑 |
| ③ 首屏 Hero | 一句话说清这是干什么的 | 今日页大标题「今天，把一道题想透，而不是刷过」 |
| ④ 主要内容区 Main | 核心信息，按主题分段 | 题库表格 / 题面 / 代码台 |
| ⑤ 辅助区 Aside | 相关推荐、筛选 | 右侧「分级进度 / 学习热力 / 今日目标」 |
| ⑥ 页脚 Footer | 联系方式、版权 | 无（单机应用没有页脚语义）；侧栏底部放「路线进度 / 错题数」 |

**提示词模板**（要复刻这套骨架时用）：
> 做网页页眉：高 56px，左侧 28px 品牌印章 + 名称，右侧放搜索和设置；导航固定左侧 244px，只放 5 个入口并高亮当前项；窄屏（<900px）导航变成顶部横条。

## 七、排版：6 个方法

| 方法 | 要点 | 本项目参数 |
| --- | --- | --- |
| ① 栅格 Grid | 所有元素沿共同列线 | 内容区最大 1400px；卡片 12px 圆角；表格行 40px |
| ② 留白 Whitespace | 区块之间大、组内小 | 区块 32–56px、组内 8–12px、卡片内边距 16–24px |
| ③ 对齐 Alignment | 同组统一左对齐，不混用居中 | 正文一律左对齐；只有数字 / 标题在统计卡里居中 |
| ④ 层级 Hierarchy | 字号 + 字重 + 间距三件套 | 10 档字号（10/11/12/13.5/15/17/21/26/34/44），字重 400/500/600 |
| ⑤ 分组 Grouping | 卡片 / 分隔线 / 背景区分 | 四种材质：chrome / content / code / reading（见设计规范） |
| ⑥ 窄屏 Narrow | 两栏改一栏 | 断点 980px（题目页单栏）、900px（侧栏变横条）、720px（弹层单列） |

**提示词模板**：
> 用 12 列栅格排：内容最大宽 1200px、列间距 24px；区块间距 64px、组内 16px、卡片内边距 24px；标题 40/24/16 三级、行高 1.6；窄于 768px 改单栏、图片在上文字在下。

## 八、加新动效时的检查清单

- [ ] 有明确的**触发**（进入视口 / 点击 / 状态变化）和**结束**（时长 ≤400ms，或明确是循环）
- [ ] 只用令牌（`--t-*` / `--ease-*`），不写字面时长和色值
- [ ] `data-motion='off'` 和 `prefers-reduced-motion` 下退化正常
- [ ] 不触发 layout（只动 `transform` / `opacity`）；列表动效不挂 `scroll` 监听
- [ ] 同一个动作全站只有一种动效（比如「成功」永远是打勾 + 光环，不用两套）
- [ ] 在 `npm run verify` 的截图里看一眼：动效不能把内容挤位
