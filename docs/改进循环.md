## 与大厂 App 的差距（按「用户能感知」排序）

1. **崩一次就白屏**：任何运行时异常会整页白，没有兜底（之前 `state.cases` 就踩过）。
2. **状态不在 URL 里**：筛选条件只在 localStorage，刷新能恢复但**不能分享、不能后退**。
3. **效率工具不全**：只有 ⌘K / Ctrl+B / `/` / Ctrl+Enter；没有快捷键总览，命令面板只能搜题不能执行动作。
4. **无障碍没做全**：弹窗不锁焦点、关闭不还焦点；表格缺 `scope`；tabs 缺 `tabpanel` 关联。
5. **首次使用没有引导**：新用户看到今日页不知道第一步干什么。
6. **数据仍有缺口**：790 道会员题无题面；94% 边界用例无期望；面试经典 150 未标记。
7. **编辑器偏好不可调**：字号、行号、换行都写死。
8. **没有提交历史/学习报告**：数据都在，但没呈现。

## 附：浅色模式窗口黑边 + 文档与 README 收尾（2026-11-22 20:40）

### 1. 浅色模式下窗口最上端一条黑边

**根因**：桌面版窗口是 `FormBorderStyle=None` + `WS_THICKFRAME`（为了能拖边框缩放），Windows 会留出一圈非客户区。
这圈边框由 DWM 按「窗口是不是深色」来涂 —— 而我在 `ApplyFramePolish()` 里把 `DWMWA_USE_IMMERSIVE_DARK_MODE` **写死成 1**，
于是浅色模式下非客户区仍被涂成 `#202020` 深灰，就是那条黑边（实测高 8px，DPI 150%）。

**修法**：
- `ApplyThemeColors(light)` 里把 `DWMWA_USE_IMMERSIVE_DARK_MODE` 跟着主题设（浅色 = 0）；
- `ApplyFramePolish()` 不再无条件设深色，改为调用 `ApplyThemeColors(_light)`；
- 页面每次导航完由宿主主动问一次 `document.documentElement.dataset.theme` 再同步（消息通道有时序问题，页面可能在窗口 Shown 之前就发了）；
- 顺手把安装包的静默安装改成「先关掉正在跑的实例」+ 失败写日志不弹模态框（之前覆盖安装会卡在错误弹窗上）。

**验证**：窗口顶部像素从 `#202020` 变成 `#F3F3F3`（跟随主题的边框色），标题栏 `#EFECE6` 无缝衔接。
