## 一句话思路
Tarjan 求桥：DFS 中若 `low[v] > dfn[u]`，则边 `(u,v)` 是唯一回路，删掉即断连。

## 怎么做
1. 建邻接表 `g`，`dfn` 记录访问时间戳，`low` 记录子树能回溯到的最小 `dfn`。
2. 从 0 号点 DFS，跳过父边（用边的下标而非父节点，防重边误判）。
3. 回溯时 `low[u] = min(low[u], low[v])`；若 `low[v] > dfn[u]`，把 `[u,v]` 加入答案。
4. 用 `dfn[v] == 0` 判断未访问，避免用 `visited` 数组多开内存。

以示例 1 为例：`n=4, connections=[[0,1],[1,2],[2,0],[1,3]]`。DFS 走 0→1→2，到 2 时发现 0 已访问且 `dfn[0]=1`，于是 `low[2]=1`；回溯到 1，`low[1]=min(2,1)=1`，`low[2]=1 > dfn[1]=2` 不成立，边 `(1,2)` 不是桥。再从 1 走 3，`low[3]=4 > dfn[1]=2`，边 `(1,3)` 入答案。

```python
def dfs(u, parent_edge):
    nonlocal timer
    timer += 1
    dfn[u] = low[u] = timer
    for v, eid in g[u]:
        if eid == parent_edge:
            continue
        if dfn[v] == 0:
            dfs(v, eid)
            low[u] = min(low[u], low[v])
            if low[v] > dfn[u]:
                ans.append([u, v])
        else:
            low[u] = min(low[u], dfn[v])
```

## 复杂度
时间 O(n + m)：每条边在 DFS 中访问两次（正反各一次），m 为 `connections` 长度。
空间 O(n + m)：邻接表存 2m 条边，`dfn`/`low` 各开 n 个槽，递归栈最深 n 层。

## 易错点
- 输入含重边（如 `[[0,1],[0,1]]`）时若用「跳过父节点」而非「跳过父边下标」，会把重边误判成桥；正确做法是记录进入当前点的边 id，只跳过那一条。
- 图不保证从 0 号点连通时（本题题面说连通，但若换题），只从 0 号 DFS 会漏掉其他分量；正确做法是对每个 `dfn[i]==0` 的点都启动一次 DFS。

## 如果面试官追问
问：n 到 10^6 递归会爆栈怎么办？
答：改写成显式栈的迭代 DFS，用 `(u, parent_edge, 迭代器下标)` 三元组模拟回溯。
