## 一句话思路
从最高位开始尽量填 9，剩余位留给后面的数字，这样高位越大整体越大。

## 怎么做
1. 若 `s > 9 * n`，无解返回 `-1`；若 `s == 0`，返回 `0`。
2. 从第 1 位到第 `n` 位，每位取 `min(9, s)`，然后 `s -= 该位`。
3. 把各位数字拼成整数返回。

以 `n = 2, s = 9` 为例：第 1 位取 `min(9, 9) = 9`，`s` 变为 `0`；第 2 位取 `min(9, 0) = 0`，`s` 仍为 `0`；拼得 `90`。

```python
def largestInteger(n, s):
    if s > 9 * n:
        return -1
    if s == 0:
        return 0
    res = 0
    for _ in range(n):
        d = min(9, s)
        res = res * 10 + d
        s -= d
    return res
```

关键中间值：循环第 1 轮 `d = 9`，`res = 9`，`s = 0`；第 2 轮 `d = 0`，`res = 90`。

## 复杂度
时间：O(n)，循环 n 次，每次 O(1)。
空间：O(1)，只用了 `res`、`s`、`d` 三个变量。

## 易错点
- `n = 5, s = 0` → 若直接走贪心循环会得到 `00000` 即 `0`，但若先判 `s > 9*n` 再判 `s == 0` 顺序反了不影响；真正坑是漏判 `s == 0` 时返回 `0` 而非空串，正确做法是显式返回 `0`。
- `n = 2, s = 19` → 若不先判 `s > 9 * n`，循环里第 1 位取 9、第 2 位取 9 后 `s` 还剩 1，会错误返回 `99`，正确做法是先判 `19 > 18` 返回 `-1`。

## 如果面试官追问
问：若要求返回字符串而非整数（n 可达 10^5）？
答：同样贪心，用列表逐位 append `min(9, s)`，最后 `''.join`，避免大整数拼接。
