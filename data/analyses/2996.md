## 一句话思路
先扫出最长顺序前缀的和 `s`，再用集合从 `s` 开始逐个试，第一个不在集合里的就是答案。

## 怎么做
1. 从 `nums[0]` 起累加 `s`，只要 `nums[i] == nums[i-1] + 1` 就继续，否则停。
2. 把 `nums` 全部丢进 `set`，注意集合要包含整个数组而不只是前缀。
3. 令 `x = s`，`while x in seen: x += 1`，返回 `x`。

用示例 2 走一遍：`nums = [3,4,5,1,12,14,13]`，`i=1` 时 `4==3+1`、`i=2` 时 `5==4+1` 都成立，`i=3` 时 `1 != 5+1` 停下，此时 `s = 3+4+5 = 12`。集合是 `{3,4,5,1,12,14,13}`，`12` 在、`13` 在、`14` 在，`15` 不在，返回 `15`。

```python
seen = set(nums)
s = nums[0]
for i in range(1, len(nums)):
    if nums[i] != nums[i - 1] + 1:
        break
    s += nums[i]
x = s
while x in seen:
    x += 1
return x
```

关键细节：循环里 `break` 之前不能把 `nums[i]` 加进 `s`，否则示例 2 会算成 `s = 12+1 = 13`，答案错成 `15` 之外的数。另外 `s` 的初值必须是 `nums[0]`，长度 1 的数组直接返回 `nums[0]`（若它不在集合里，但它在，所以返回 `nums[0]+1`）。

## 复杂度
时间 O(n + k)，n 是数组长度，k 是从 `s` 起连续命中的个数，最坏 O(n + 50)。
空间 O(n)，`seen` 存了全部 n 个元素。

## 易错点
- 输入 `nums = [1,2,3,2,5]`：若把整个数组都当顺序前缀累加，`s` 会变成 `1+2+3+2+5=13`，答案错成 `13`；正确做法是遇到 `2 != 3+1` 立刻 `break`，`s` 停在 `6`。
- 输入 `nums = [1]`：若循环写成 `for i in range(1, len(nums))` 之外还漏了 `s` 初始化，或误以为前缀为空，会返回 `1`；正确做法是 `s = nums[0] = 1`，`1` 在集合里，`x` 递增到 `2` 返回。

## 如果面试官追问
问：`nums` 长度放大到 10^5、值域也放大，还能这么做吗？
答：能，`set` 建表 O(n)，从 `s` 起最多试到 `s + n`，总时间仍是 O(n)。
