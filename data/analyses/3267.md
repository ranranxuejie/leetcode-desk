## 一句话思路
把每个数补零到 7 位，枚举至多两次交换得到的所有变体，用哈希表按「变体 → 出现次数」累加，避免 O(n²) 比较。

## 怎么做
1. 统一补零到 7 位：`s = str(x).zfill(7)`，这样 `213` 和 `0213` 能对齐比较。
2. 对每个数生成变体集合 `{s}` ∪ 一次交换 ∪ 两次交换，用 `set` 去重。
3. 遍历 `nums`，对当前数的每个变体查哈希表，把已有计数累加进答案，再把当前数自身的 7 位串计数 +1。
4. 关键中间值：`nums=[1,10,100]`，`1` 的变体含 `0000001`；`10` 补零为 `0000010`，交换后两位得 `0000001`，命中计数 1；`100` 补零 `0000100`，交换得 `0000001` 和 `0000010`，各命中 1，答案 3。

```python
from collections import defaultdict

def variants(x):
    s = str(x).zfill(7)
    res = {s}
    n = len(s)
    for i in range(n):
        for j in range(i + 1, n):
            t = list(s); t[i], t[j] = t[j], t[i]
            res.add(''.join(t))
            for k in range(n):
                for l in range(k + 1, n):
                    u = t[:]; u[k], u[l] = u[l], u[k]
                    res.add(''.join(u))
    return res

cnt = defaultdict(int)
ans = 0
for x in nums:
    for v in variants(x):
        ans += cnt[v]
    cnt[str(x).zfill(7)] += 1
```

## 复杂度
时间：每个数生成约 C(7,2)² ≈ 441 个变体，总 O(n·7⁴)，n=5000 可过。
空间：哈希表存至多 n 个键，O(n)。

## 易错点
- 不补零直接 `str(x)`：`1` 和 `10` 长度不同，交换后永远对不上，示例 2 会得 0 而非 3；必须 `zfill(7)`。
- 只生成一次交换的变体：`1023` 到 `2310` 需要两次交换，漏掉两次交换会少算示例 1 的第一对；必须双层循环枚举两对下标。

## 如果面试官追问
问：若操作次数改为至多 k 次怎么办？
答：变体数按 C(7,2)^k 爆炸，需改成按「数位多重集」分组，同组内两两计数。
