## 一句话思路
用 pandas 的列向量化运算 `employees["salary"] * 2` 直接覆盖原列，逐元素乘法天然对齐行。

## 怎么做
1. 拿到 DataFrame 后不要遍历行，直接对 `salary` 这一列做整体乘法。
2. 把结果赋回 `employees["salary"]`，实现原地修改。
3. 返回 `employees` 本身。

以官方示例第一行为例：`employees["salary"]` 是 `[19666, 74754, 62509, 54866]`，乘以 2 后中间结果是 `[39332, 149508, 125018, 109732]`，第一个元素 19666*2=39332 与输出表 Jack 行一致，说明列对齐没串行。

```python
import pandas as pd

def modifySalaryColumn(employees: pd.DataFrame) -> pd.DataFrame:
    employees["salary"] = employees["salary"] * 2
    return employees
```

关键点：`employees["salary"] * 2` 返回的是同长度 Series，索引与 `employees` 一致，赋值时按索引对齐，所以不会错位。若写成 `employees["salary"] = 2 * employees["salary"]` 结果相同，乘法可交换。

## 复杂度
时间：O(n)，n 为行数，逐元素做一次乘法。
空间：O(n)，新建一个长度 n 的 Series 作为中间结果。

## 易错点
- 误用 `employees["salary"].apply(lambda x: x * 2)`：功能对但慢，n 大时逐行 Python 调用开销明显；正确做法是直接列运算 `employees["salary"] * 2`。
- 写成 `employees["salary"] *= 2` 之外的链式赋值如 `employees.loc[:, "salary"] = ...` 一般没问题，但若先 `employees = employees.copy()` 再改副本却返回原对象，输出仍是原薪水；正确做法是改完直接 `return employees`，确保返回的是被修改的那个对象。

## 如果面试官追问
问：若 salary 列含缺失值 `None` 怎么办？答：`None * 2` 在 pandas 数值列中传播为 `NaN`，需先 `fillna` 或按题意保留缺失，不能默认当 0 处理。
