## 一句话思路
二分答案 `limit`，再用状压 DP 判断能否把全部工作塞进 k 个不超过 `limit` 的工人里。

## 怎么做
1. 二分下界 `max(jobs)`、上界 `sum(jobs)`，对每个 `limit` 做可行性判定。
2. 预处理 `cost[mask]`：掩码 `mask` 里所有工作的总耗时，用 `cost[mask] = cost[mask ^ lowbit] + jobs[lowbit 下标]` 递推。
3. 定义 `dp[mask]` 为「做完 `mask` 这批工作，最少占用几个工人」，转移时枚举 `mask` 的子集 `sub` 作为最后一个工人的任务，若 `cost[sub] <= limit` 则 `dp[mask] = min(dp[mask], dp[mask ^ sub] + 1)`。
4. 判定 `dp[(1<<n)-1] <= k` 即 `limit` 可行，二分收敛到最小可行值。

以 `jobs = [1,2,4,7,8], k = 2` 为例，二分到 `limit = 11` 时，`mask = 0b11111` 的一个可行拆分是 `sub = 0b10110`（工作 2、4、8，`cost = 2+4+8 = 14` 超限，被跳过），真正命中的是 `sub = 0b11001`（1、2、8，`cost = 11`），剩下 `0b00110`（4、7，`cost = 11`），`dp` 得 2，可行。

```python
n = len(jobs)
full = (1 << n) - 1
cost = [0] * (1 << n)
for mask in range(1, 1 << n):
    low = mask & -mask
    cost[mask] = cost[mask ^ low] + jobs[low.bit_length() - 1]

def ok(limit):
    dp = [n + 1] * (1 << n)
    dp[0] = 0
    for mask in range(1, 1 << n):
        sub = mask
        while sub:
            if cost[sub] <= limit:
                dp[mask] = min(dp[mask], dp[mask ^ sub] + 1)
            sub = (sub - 1) & mask
    return dp[full] <= k
```

## 复杂度
时间：二分 `log(sum(jobs))` 轮，每轮枚举全部子集共 `3^n`，合计 `O(3^n · log S)`。
空间：`cost` 与 `dp` 各开 `2^n` 个整数，`O(2^n)`。

## 易错点
- `jobs = [3,2,3], k = 3` 若把二分下界写成 0 或 1，`ok(1)` 里 `cost[sub] <= 1` 对所有非空 `sub` 都不成立，`dp[full]` 停在 `n+1`，判定恒假，白白多跑几轮；下界必须取 `max(jobs) = 3`。
- `jobs = [1,2,4,7,8], k = 2` 若在转移时只枚举「包含 `mask` 最低位的子集」以外的写法漏掉对称拆分，或忘记 `sub = (sub - 1) & mask` 而写成 `sub -= 1`，会枚举到 `mask` 之外的位，`cost[sub]` 越界或算出错误和；必须用 `& mask` 收敛到子集。

## 如果面试官追问
问：k 很大（比如 k ≥ n）时还要跑 `3^n` 吗？
答：此时答案就是 `max(jobs)`，直接返回，二分和 DP 都不用进。
