## 一句话思路
按 `\n` 切行，用栈存每层目录的累计路径长度，遇文件就更新最大值。

## 怎么做
1. 用 `input.split('\n')` 切行，每行开头的 `\t` 个数就是深度 `depth`，去掉制表符后的部分是名字 `name`。
2. 栈 `stack` 存「当前路径到该层为止的累计长度」，栈长度即当前深度。
3. 每行先 `while len(stack) > depth: stack.pop()`，把栈裁到父目录那一层。
4. 若 `name` 含 `.` 就是文件，候选长度 = `stack[-1] + len(name)`（栈空时就是 `len(name)`）；否则把 `stack[-1] + len(name) + 1` 压栈（`+1` 是斜杠）。

拿示例 1 走一遍：`"dir\n\tsubdir1\n\tsubdir2\n\t\tfile.ext"`。处理 `dir` 时栈空，压入 `3+1=4`；`subdir1` 深度 1，栈长 1 不弹，压入 `4+7+1=12`；`subdir2` 深度 1，弹掉 `12` 后压入 `4+7+1=12`；`file.ext` 深度 2，栈长 1 不弹，候选 `12+8=20`，答案 20。

```python
stack, ans = [], 0
for line in input.split('\n'):
    depth = len(line) - len(line.lstrip('\t'))
    name = line.lstrip('\t')
    while len(stack) > depth:
        stack.pop()
    if '.' in name:
        ans = max(ans, (stack[-1] if stack else 0) + len(name))
    else:
        stack.append((stack[-1] if stack else 0) + len(name) + 1)
return ans
```

## 复杂度
时间 O(n)：n 是 `input` 总字符数，每行只被切一次、最多入栈出栈各一次。
空间 O(d)：d 是最大目录深度，栈最多存 d 个累计长度。

## 易错点
1. 输入 `"a"` 或 `"dir\n\tsubdir1"`（无文件）→ 若把目录也当候选更新 `ans`，会错成 1 或 12 → 只有 `'.' in name` 才更新 `ans`，否则返回 0。
2. 输入 `"file1.txt\nfile2.txt\nlongfile.txt"` → 若压栈时无脑 `+1` 或读 `stack[-1]` 前不判空，会 `IndexError` 或多算 1 → 根层文件直接取 `len(name)`，目录压栈才 `+1`。

## 如果面试官追问
问：要求返回最长路径字符串本身而不只是长度？
答：栈里改存 `(累计长度, 路径字符串)`，遇文件时拼 `stack[-1][1] + '/' + name` 并记录最优串。
