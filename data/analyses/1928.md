## 一句话思路
按「已花时间」分层做 DP，`dp[t][v]` 表示恰好花 t 分钟到 v 的最小费用，逐层松弛边。

## 怎么做
1. 建邻接表 `g[v] = [(to, w), ...]`，双向边各存一次。
2. 初始化 `dp = [[inf]*n for _ in range(maxTime+1)]`，`dp[0][0] = passingFees[0]`。
3. 外层 `t` 从 0 到 maxTime，内层遍历所有点 v，若 `dp[t][v]` 有限，就对每条边松弛 `dp[t+w][to] = min(..., dp[t][v] + passingFees[to])`。
4. 答案取 `min(dp[t][n-1] for t in range(maxTime+1))`，全 inf 则返回 -1。

以示例 1 为例：`dp[0][0]=5`；松弛 `0->1` 得 `dp[10][1]=6`，松弛 `0->3` 得 `dp[1][3]=25`。到 `t=20` 时 `dp[20][2]=8`，再走 `2->5` 花 10 分钟，`dp[30][5]=11`，正好等于 maxTime，所以答案 11；示例 2 中 maxTime=29 使 `dp[30][5]` 越界被丢弃，只能走 `0->3->4->5` 得 48。

```python
inf = float('inf')
dp = [[inf] * n for _ in range(maxTime + 1)]
dp[0][0] = passingFees[0]
for t in range(maxTime + 1):
    for v in range(n):
        cur = dp[t][v]
        if cur == inf:
            continue
        for to, w in g[v]:
            if t + w <= maxTime:
                nt = cur + passingFees[to]
                if nt < dp[t + w][to]:
                    dp[t + w][to] = nt
ans = min(dp[t][n - 1] for t in range(maxTime + 1))
return -1 if ans == inf else ans
```

## 复杂度
时间 O(maxTime · (n + m))，maxTime 与边数 m 各贡献一层循环。
空间 O(maxTime · n)，就是那张二维 dp 表，邻接表另算 O(n + m)。

## 易错点
- 把 `dp[t][v]` 当成「不超过 t 分钟」→ 示例 1 里 `dp[30][5]` 会被 `dp[29][5]` 之类的值污染，松弛时 `t+w` 的语义就乱了；正确做法是严格「恰好 t 分钟」，最后再对 t 取 min。
- 忘记起点通行费 → 示例 1 会输出 6 而不是 11；初始化必须写 `dp[0][0] = passingFees[0]`，且每次松弛加的是 `passingFees[to]` 而非 `passingFees[v]`。

## 如果面试官追问
问：maxTime 放大到 1e9 怎么办？
答：时间维不能开数组，改用 Dijkstra 式优先队列按费用出堆，状态存 (cost, v, time)，靠 time ≤ maxTime 剪枝。
