## 一句话思路
用 `split()` 按任意空白切词，`Counter` 计数，再按频次降序输出。

## 怎么做
1. 读入全文，用 `text.split()` 切分——它把连续空格当单个分隔符，正好匹配题面「一个或多个空格」。
2. 用 `Counter(words)` 得到 `{词: 频次}`，示例输入得到 `{'the': 4, 'is': 3, 'sunny': 2, 'day': 1}`。
3. 用 `most_common()` 按频次降序取出 `(词, 频次)` 对，逐行拼成 `"词 频次"`。
4. 题面保证频次唯一，所以无需处理并列排序。

```python
from collections import Counter

text = open("words.txt").read()
words = text.split()          # 连续空格被合并，无空串
cnt = Counter(words)          # {'the': 4, 'is': 3, 'sunny': 2, 'day': 1}
for w, c in cnt.most_common():
    print(w, c)
```

关键中间值：`text.split()` 对示例返回 `['the','day','is','sunny','the','the','the','sunny','is','is']`，长度 10；`Counter` 后 `the` 的计数为 4，与期望输出首行一致。

## 复杂度
时间：O(n) 扫描切词与计数，排序 O(k log k)，k 为不同词数。
空间：O(k) 存 Counter，n 为字符总数。

## 易错点
- 用 `text.split(" ")` 而非 `split()`：示例第一行 `the day is sunny the the` 中间是单空格没问题，但若文件出现连续两个空格，`split(" ")` 会产生空串 `''`，被 `Counter` 记成一个「词」并输出 `  2` 这类脏行；正确做法是无参 `split()`。
- 输出用 `print(w, c)` 而非 `print(w + " " + c)`：后者在 Python 里字符串加整数会抛 `TypeError`，因为 `c` 是 `int`；要么 `str(c)`，要么直接用 `print` 的多参数形式（默认以空格分隔）。

## 如果面试官追问
问：如果词频允许并列，怎么保证输出稳定？
答：`most_common()` 在 Python 3.7+ 对并列保持插入序，若要字典序可加 `key=lambda x: (-x[1], x[0])` 显式排序。
