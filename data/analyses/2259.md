## 一句话思路
从左往右找第一个满足 `number[i] == digit and number[i] < number[i+1]` 的位置删掉，否则删最后一个 `digit`。

## 怎么做
1. 遍历 `i` 从 0 到 `len(number)-2`，找第一个 `number[i] == digit` 且 `number[i] < number[i+1]` 的位置。
2. 找到就返回 `number[:i] + number[i+1:]`，因为删掉这个较小的 `digit` 能让后面更大的数字前移一位，结果最大。
3. 没找到说明所有 `digit` 都不小于后一位（如 `"551"`），删哪个都一样，用 `rfind` 删最后一个。
4. 以 `number = "1231", digit = '1'` 为例：`i=0` 时 `number[0]='1' == digit` 且 `'1' < '2'`，命中，返回 `"231"`；若不比较后一位直接删第一个 `'1'` 之外的，就会错。

```python
def removeDigit(number, digit):
    for i in range(len(number) - 1):
        if number[i] == digit and number[i] < number[i + 1]:
            return number[:i] + number[i + 1:]
    j = number.rfind(digit)
    return number[:j] + number[j + 1:]
```

关键中间值：`"1231"` 扫到 `i=0` 时 `number[0]='1'`、`number[1]='2'`，`'1' < '2'` 成立，立刻返回，不会再看 `i=3` 的第二个 `'1'`。

## 复杂度
时间 O(n)：一次线性扫描，`n = len(number)`。
空间 O(n)：切片拼接产生新字符串，无额外数据结构。

## 易错点
- 输入 `"1231", digit='1'` → 若直接删第一个出现的 `'1'` 得 `"231"` 碰巧对，但输入 `"112", digit='1'` 删第一个得 `"12"`、删第二个得 `"12"` 也对，真正翻车是 `"2131", digit='1'`：删 `i=1` 的 `'1'` 得 `"231"`，删 `i=3` 的得 `"213"`，必须靠 `number[i] < number[i+1]` 判断，不能只看出现位置。
- 输入 `"551", digit='5'` → 循环里 `'5' < '5'` 和 `'5' < '1'` 都不成立，若忘记兜底会返回空或原串；正确做法是循环结束后 `rfind` 删最后一个 `'5'` 得 `"51"`。

## 如果面试官追问
问：若要求移除恰好 k 个 `digit` 使结果最大？答：贪心改成用栈，遇到 `digit` 且栈顶小于当前位就弹，弹够 k 个为止，尾部再补删。
