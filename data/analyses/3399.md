## 一句话思路
二分答案 L，对每个连续段用「切成 ≤L 的块」算最少翻转次数，总次数 ≤ numOps 即可行。

## 怎么做
1. 先扫一遍 s，把每段连续相同字符的长度收集到 `runs`，例如 `"000001"` → `[5, 1]`。
2. 二分答案 `L` 在 `[1, max(runs)]`，判定函数 `need(L)` 返回把所有段压到 ≤L 所需的最少翻转数。
3. 对长度 `m` 的段，翻转一次能把它劈成两半，故需要 `m // (L+1)` 次翻转（`m=5, L=2` → `5//3=1`，正好对应示例 1 把 `s[2]` 翻成 `1`）。
4. 累加所有段的 `m // (L+1)`，若 `≤ numOps` 则 `L` 可行，收缩右界。

```python
runs = []
i = 0
while i < n:
    j = i
    while j < n and s[j] == s[i]:
        j += 1
    runs.append(j - i)
    i = j

def need(L):
    return sum(m // (L + 1) for m in runs)

lo, hi = 1, max(runs)
while lo < hi:
    mid = (lo + hi) // 2
    if need(mid) <= numOps:
        hi = mid
    else:
        lo = mid + 1
return lo
```

关键中间值：示例 1 `runs=[5,1]`，`L=2` 时 `need=5//3+1//3=1 ≤ 1`，可行；`L=1` 时 `need=5//2=2 > 1`，不可行，故答案 2。

## 复杂度
时间：O(n + k·log(maxrun))，n 来自扫描建 runs，log 来自二分，k 为段数。
空间：O(k) 存 runs，最坏 O(n)。

## 易错点
- 输入 `s="0000", numOps=2`：若把 `need` 写成 `m // L` 会得 `4//1=4 > 2` 误判 L=1 不可行；正确是 `m // (L+1)`，得 `4//2=2 ≤ 2`，答案 1。
- 输入 `s="0101", numOps=0`：若二分下界取 0 或忘记 `runs` 全为 1 时 `hi=1`，会死循环或返回 0；正确是 `lo=1`，`max(runs)=1` 直接返回 1。

## 如果面试官追问
问：若要求输出具体翻转方案而非长度？答：在 `need(L)` 里记录每段翻转位置（从段首起每隔 `L+1` 翻一个），二分收敛后回放这些下标即可。
