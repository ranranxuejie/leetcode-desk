## 一句话思路
以 0 为根把树看成无向图做一次 DFS，遇到「顺着根往外指」的边就计数，因为这条边必须反向。

## 怎么做
1. 把 `connections` 建成无向邻接表，每条边额外记一个方向标记：`[a,b]` 存 `(b, 0)` 表示 a→b 顺向，反向存 `(a, 1)`。
2. 从 0 出发 DFS，只往父节点以外的邻居走，避免在树上绕回。
3. 走到一条标记为 1 的边（即原方向是「子→父」，与「指向 0」相反）时，`ans += 1`。

以示例 1 为例：`connections = [[0,1],[1,3],[2,3],[4,0],[4,5]]`。从 0 出发，邻边是 `(1,0)` 和 `(4,1)`。走 `(1,0)` 不计数；从 1 到 3 的边是 `(3,0)`，不计数；从 3 到 2 的边是 `(2,1)`，`ans` 变 1。回到 0 走 `(4,1)`，`ans` 变 2；从 4 到 5 的边是 `(5,1)`，`ans` 变 3。最终 `ans = 3`，与输出一致。

```python
def dfs(u, parent):
    nonlocal ans
    for v, rev in graph[u]:
        if v == parent:
            continue
        ans += rev
        dfs(v, u)

graph = [[] for _ in range(n)]
for a, b in connections:
    graph[a].append((b, 0))
    graph[b].append((a, 1))
ans = 0
dfs(0, -1)
return ans
```

关键点：`rev` 的含义是「这条边在原图中从子指向父」，而我们要的是父指向子，所以它必须翻转。`parent` 参数在树上是必需的，否则 0→1→0 会死循环。

## 复杂度
时间 O(n)：每条边在邻接表里出现两次，DFS 各访问一次。
空间 O(n)：邻接表存 2(n-1) 个二元组，递归栈最深 n 层。

## 易错点
- 输入 `n = 2, connections = [[1,0]]`：若把 `rev` 标记写反（`graph[a].append((b,1))`），会输出 1，正确是 0，因为 1→0 本来就指向 0。建图时 `[a,b]` 的 a→b 是顺向，标记 0 给 `graph[a]`、标记 1 给 `graph[b]`。
- 输入 `n = 50000` 且是一条链 `[[1,0],[2,1],...]`：递归深度到 5 万，Python 默认递归上限约 1000，会 `RecursionError`。要么 `sys.setrecursionlimit(10**5)`，要么改写成显式栈的迭代 DFS，栈里存 `(u, parent)`。

## 如果面试官追问
问：要求输出具体要翻转哪些边，怎么办？
答：DFS 时把 `rev == 1` 对应的原始下标 `i` 记进列表，返回该列表即可，复杂度不变。
