## 一句话思路
排序后回溯，用 `used` 数组标记，同层跳过重复元素，保证每个排列只生成一次。

## 怎么做
1. 先对 `nums` 排序，让相同数字相邻，便于剪枝。
2. 回溯时用 `used[i]` 标记是否已选，`path` 记录当前排列，长度等于 `len(nums)` 时收集。
3. 关键剪枝：若 `i > 0 and nums[i] == nums[i-1] and not used[i-1]`，跳过 `nums[i]`。

以 `nums = [1,1,2]` 为例，排序后为 `[1,1,2]`。第一层选第一个 `1` 后，`used = [True,False,False]`；第二层若想选第二个 `1`，此时 `nums[1]==nums[0]` 且 `used[0]==True`，允许选，得到 `[1,1,2]`。若第一层没选第一个 `1` 而直接选第二个 `1`，则 `used[0]==False`，触发剪枝跳过，避免重复生成以 `1` 开头的排列。

```python
nums.sort()
res, path, used = [], [], [False] * len(nums)

def dfs():
    if len(path) == len(nums):
        res.append(path[:])
        return
    for i in range(len(nums)):
        if used[i]:
            continue
        if i > 0 and nums[i] == nums[i-1] and not used[i-1]:
            continue
        used[i] = True
        path.append(nums[i])
        dfs()
        path.pop()
        used[i] = False

dfs()
```

4. 收集结果时用 `path[:]` 拷贝，避免后续修改影响已存结果。

## 复杂度
时间：O(n × n!)，n 为数组长度，每个排列拷贝耗时 O(n)。
空间：O(n)，递归栈深度 n，`used` 和 `path` 各 O(n)，结果集不计入。

## 易错点
- 输入 `[1,1,2]` → 若只写 `nums[i]==nums[i-1]` 就跳过，会把 `[1,1,2]` 这种合法排列也剪掉，输出只剩 2 个 → 必须加上 `not used[i-1]` 条件，区分「同层重复」和「同枝重复」。
- 输入 `[1,1,2]` → 若忘记先 `sort()`，相同数字不相邻，`nums[i]==nums[i-1]` 判断失效，输出含重复排列 → 回溯前必须先排序。

## 如果面试官追问
问：若要求按字典序输出所有排列怎么办？
答：先排序，DFS 按索引从小到大枚举，收集顺序天然字典序，无需额外排序。
