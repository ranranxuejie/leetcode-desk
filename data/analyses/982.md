## 一句话思路
先枚举所有 `nums[i] & nums[j]` 用哈希表计数，再对每个 `nums[k]` 累加与之按位与为 0 的配对数量。

## 怎么做
1. 用 `Counter` 统计所有 `(i, j)` 组合的 `nums[i] & nums[j]` 值，键是结果，值是出现次数。
2. 对每个 `nums[k]`，遍历哈希表所有键 `v`，若 `v & nums[k] == 0` 则累加 `cnt[v]`。
3. 累加结果即为答案，因为每个 `(i,j)` 对与每个 `k` 组合恰好对应一个三元组。

以 `nums = [2,1,3]` 为例：配对结果 `2&2=2`、`2&1=0`、`2&3=2`、`1&2=0`、`1&1=1`、`1&3=1`、`3&2=2`、`3&1=1`、`3&3=3`，哈希表为 `{2:3, 0:2, 1:3, 3:1}`。对 `k=0`（`nums[0]=2`），满足 `v&2==0` 的键有 `0`（2 次）和 `1`（3 次），贡献 5；`k=1`（`nums[1]=1`）满足的键有 `0`（2 次）和 `2`（3 次），贡献 5；`k=2`（`nums[2]=3`）满足的键有 `0`（2 次），贡献 2。总计 12。

```python
from collections import Counter
cnt = Counter()
for a in nums:
    for b in nums:
        cnt[a & b] += 1
ans = 0
for k in nums:
    for v, c in cnt.items():
        if v & k == 0:
            ans += c
```

## 复杂度
时间：O(n² + n·U)，U 是不同按位与结果数，最坏 O(n²)。
空间：O(U)，哈希表存不同与值，U ≤ min(n², 2^16)。

## 易错点
- `nums = [0,0,0]` → 若误以为 `0&0&0` 不合法或漏算自配对，会得 0 或 6，正确是 27（每个 `(i,j,k)` 都满足，3³=27）。
- `nums = [2,1,3]` → 若只枚举 `i<j<k` 的有序组合，会漏掉 `i=j` 或 `j=k` 的情况，正确做法是 `i,j,k` 各自独立遍历全部下标，允许重复。

## 如果面试官追问
若 `nums` 长度扩到 10⁵ 但值域仍 `< 2^16`，怎么做？答：用 SOS DP 对值域做超集和，O(16·2^16) 预处理后 O(1) 查询每个 `k`。
