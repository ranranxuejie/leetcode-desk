## 一句话思路
从左到右扫一遍，只记录最近一次出现的 1 和 2 的下标，每次遇到另一种值就更新最小差。

## 怎么做
1. 用 `last1 = -1`、`last2 = -1` 记录最近出现的 1 和 2 的下标，`ans = n`（n 为长度，作为上界）。
2. 遍历 `i, v in enumerate(nums)`：`v == 1` 时若 `last2 != -1` 就用 `i - last2` 更新 `ans`，再令 `last1 = i`。
3. `v == 2` 时对称处理：若 `last1 != -1` 就用 `i - last1` 更新 `ans`，再令 `last2 = i`。
4. 遍历结束若 `ans == n` 说明没更新过，返回 `-1`，否则返回 `ans`。

以 `nums = [1,0,0,2,0,1]` 为例：i=0 时 `last1=0`；i=3 遇到 2，`last1=0` 有效，`ans = 3-0 = 3`，`last2=3`；i=5 遇到 1，`last2=3` 有效，`ans = min(3, 5-3) = 2`。最终返回 2，与示例一致。

```python
last1 = last2 = -1
ans = len(nums)
for i, v in enumerate(nums):
    if v == 1:
        if last2 != -1:
            ans = min(ans, i - last2)
        last1 = i
    elif v == 2:
        if last1 != -1:
            ans = min(ans, i - last1)
        last2 = i
return ans if ans < len(nums) else -1
```

关键点：`i - last2` 一定非负，因为 `last2` 是之前扫到的下标，不需要 `abs`；而「最近一次」就够，因为更早的同值下标只会让差更大。

## 复杂度
时间 O(n)：一次遍历，每个元素常数次比较。
空间 O(1)：只开了 `last1`、`last2`、`ans` 三个变量。

## 易错点
- 输入 `nums = [2,1]` → 若先判 `v == 1` 分支再判 `v == 2` 却忘了初始化 `last1/last2` 为 `-1`，会把 `-1` 当有效下标算出 `1-(-1)=2` → 正确做法是两个哨兵都初始化为 `-1`，并在用之前显式判 `!= -1`。
- 输入 `nums = [0,0,0]` 或 `[1,0,1,0]` → 若把 `ans` 初始化为 `0` 或 `2**31 - 1` 后直接返回，会返回 `0` 或巨大值 → 正确做法是用 `len(nums)` 当上界，结束时 `ans < len(nums)` 才返回，否则返回 `-1`。

## 如果面试官追问
问：如果数组长度到 10^7 且要求返回具体下标对而不只是差值？
答：同样一次扫描，把 `ans` 更新处同时记下 `(i, last2)` 或 `(i, last1)`，空间仍是 O(1)。
