## 一句话思路
先数出原数组的相邻相等对数 base，再对每个值 x 统计「替换 x 为 y 后新增多少对」，取最大增益。

## 怎么做
1. 遍历一遍 `nums`，统计 `base = sum(nums[i]==nums[i-1])`，同时用哈希表 `cnt` 记录每个值出现次数。
2. 对每个值 x，枚举它所有出现位置，看左右邻居是否等于某个候选 y，用字典 `gain[x][y]` 累加「把 x 变成 y 后能新增的相邻对数」。
3. 对每个 x，取 `max(gain[x].values())` 作为增益，答案 = `base + max_gain`；若没有任何增益（如 `[1,1,1]`），答案就是 base。
4. 关键中间值：以 `nums=[1,2,3,2]` 为例，base=0；x=3 时左右邻居都是 2，`gain[3][2]=2`，答案 = 0+2 = 2。

```python
from collections import defaultdict
base = 0
gain = defaultdict(lambda: defaultdict(int))
for i in range(1, len(nums)):
    if nums[i] == nums[i-1]:
        base += 1
for i, x in enumerate(nums):
    for j in (i-1, i+1):
        if 0 <= j < len(nums) and nums[j] != x:
            gain[x][nums[j]] += 1
best = 0
for x in gain:
    best = max(best, max(gain[x].values()))
return base + best
```

## 复杂度
时间：O(n)，每个位置最多被左右邻居各访问一次，哈希操作均摊 O(1)。
空间：O(n)，`gain` 最坏存 O(n) 个 (x,y) 键值对。

## 易错点
- 输入 `[1,1,1]`：若强行替换某个 x，`gain` 为空导致 `max()` 报错或返回 0 却漏掉 base=2 → 正确做法是 `best` 初始化为 0，答案 = base + best = 2。
- 输入 `[1,2,1,2,1]`：只统计「x 的邻居等于 y」会漏掉 x 与 y 交替段中 x 两侧都是 y 的情况，若按位置只加 1 而非分别看左右两侧 → 正确做法是对 i-1 和 i+1 分别判断并各加 1，得到 `gain[1][2]=4`，答案 4。

## 如果面试官追问
问：若允许替换 k 次（k 个不同值各换一次）怎么做？
答：把 `gain[x][y]` 看成带权边，问题变成在图上选 k 条出边最大化总增益，贪心取每个 x 的最大增益再排序取前 k 即可。
