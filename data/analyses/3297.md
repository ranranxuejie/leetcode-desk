## 一句话思路
用滑动窗口维护「窗口内每个字母数 ≥ word2 需求数」的最短右边界，右边界越靠后合法子串越多。

## 怎么做
1. 用 `need[26]` 统计 word2 各字母需求，`missing` 记录还差多少个字母（按总需求数计）。
2. 右指针 `r` 逐位扩张，`cnt[word1[r]] += 1`，若该字母计数未超需求则 `missing -= 1`。
3. 当 `missing == 0`，说明 `[l, r]` 已满足，此时以 `r` 结尾、起点在 `[0, l]` 的子串都合法，累加 `l + 1`；随后收缩 `l`，若移出的字母使计数低于需求则 `missing += 1`。
4. 关键中间值：以 `word1 = "bcca", word2 = "abc"` 为例，`need = {a:1,b:1,c:1}`，`missing` 初值 3；`r` 走到 3（字符 `a`）时 `missing` 归 0，`l = 0`，累加 `0 + 1 = 1`，再收缩 `l` 到 1 时 `missing` 变 1，窗口失效，最终答案 1。

```python
need = [0] * 26
for ch in word2:
    need[ord(ch) - 97] += 1
missing = len(word2)
cnt = [0] * 26
ans, l = 0, 0
for r, ch in enumerate(word1):
    i = ord(ch) - 97
    if cnt[i] < need[i]:
        missing -= 1
    cnt[i] += 1
    while missing == 0:
        ans += len(word1) - r
        j = ord(word1[l]) - 97
        cnt[j] -= 1
        if cnt[j] < need[j]:
            missing += 1
        l += 1
```

## 复杂度
时间 O(n + m)，n = len(word1)，m = len(word2)，每个字符进出窗口各一次。
空间 O(1)，只开两个长度 26 的定长数组。

## 易错点
1. 用 `missing` 计「还差几个字母」时，若写成「窗口内不同字母种类数」而非按需求总量计，遇到 `word2 = "aaabc"` 这种重复字母会少算需求，`missing` 提前归零导致多计合法子串；正确做法是 `missing = len(word2)`，每匹配一个需求单位减一。
2. 收缩窗口时先减 `cnt[j]` 再判断 `cnt[j] < need[j]`，顺序反了会把刚移出的字母又算回需求里，`missing` 永远不增，`while` 死循环；必须先减计数、再比较、再 `missing += 1`、最后 `l += 1`。

## 如果面试官追问
问：word1 长度到 10^5 但 word2 到 10^4，答案会超 32 位吗？
答：会，`len(word1)` 平方量级约 5×10^9，Python 整数天然安全，其他语言需用 64 位。
