## 一句话思路
逐个小球算数位和当盒子下标，用哈希表计数，边加边更新最大值。

## 怎么做
1. 建一个字典 `cnt`，键是盒子编号（数位和），值是球数。
2. 从 `lowLimit` 遍历到 `highLimit`，对每个 `x` 求数位和 `s`。
3. `cnt[s] += 1`，同时 `ans = max(ans, cnt[s])`，省掉最后再扫一遍字典。
4. 返回 `ans`。

以示例 2 的 `lowLimit = 5, highLimit = 15` 为例：`x = 5` 时 `s = 5`，`cnt[5] = 1`；`x = 10` 时 `s = 1 + 0 = 1`，`cnt[1] = 1`；`x = 14` 时 `s = 1 + 4 = 5`，`cnt[5]` 从 1 变 2，`ans` 更新为 2；`x = 15` 时 `s = 6`，`cnt[6]` 也变 2，`ans` 仍是 2。最终返回 2。

```python
cnt = {}
ans = 0
for x in range(lowLimit, highLimit + 1):
    s = 0
    y = x
    while y:
        s += y % 10
        y //= 10
    cnt[s] = cnt.get(s, 0) + 1
    if cnt[s] > ans:
        ans = cnt[s]
return ans
```

注意 `while y` 对 `y = 0` 不进入循环，但本题 `lowLimit >= 1`，不会出现 `x = 0`，所以 `s` 初值 0 没问题。

## 复杂度
时间：O(n · log highLimit)，n = highLimit - lowLimit + 1，每个数拆位 log 次。
空间：O(log highLimit) 量级的字典键数，最多约 9 × 位数 个盒子。

## 易错点
- 输入 `lowLimit = 19, highLimit = 28` → 若把盒子编号当成 `x` 本身而不是数位和，会得到 1，正确是 2（19→10、28→10 都进 10 号盒）。必须先拆位求和再计数。
- 输入 `lowLimit = 1, highLimit = 10` → 若在循环外统一 `max(cnt.values())` 而字典为空（比如误把范围写成空区间），会抛 `ValueError`；本题范围非空，但边遍历边更新 `ans` 更稳，不依赖字典非空假设。

## 如果面试官追问
问：`highLimit` 放大到 10^9 还能这么算吗？
答：不能逐个枚举，得按数位和分组做数位 DP 统计区间内每个和出现次数，取最大。
