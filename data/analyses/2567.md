## 一句话思路
排序后最大得分必是 `nums[-1]-nums[0]`，改两个元素只能削掉首尾各两个，枚举四种削法取最小。

## 怎么做
1. 先排序，`nums` 升序后最大得分固定为 `nums[-1] - nums[0]`，因为极差由首尾决定。
2. 最小得分只可能出现在相邻元素之间，所以改元素只需考虑「删掉首部 k 个、尾部 2-k 个」这四种组合，k 取 0..2。
3. 对每种组合，剩余区间 `nums[k : n-(2-k)]` 的最大得分是 `nums[n-1-(2-k)] - nums[k]`，最小得分是区间内相邻差的最小值。
4. 四种组合取最小即为答案。

以 `nums = [1,4,7,8,5]` 为例，排序后 `[1,4,5,7,8]`，n=5。k=0 时剩余 `[1,4,5,7,8]`，最大得分 8-1=7，相邻差最小 1（4-5），分数 8；k=1 时剩余 `[4,5,7,8]`，最大得分 8-4=4，相邻差最小 1，分数 5；k=2 时剩余 `[5,7,8]`，最大得分 8-5=3，相邻差最小 1，分数 4。但示例答案是 3，说明 k=2 时把 `[1,4]` 改成 6 后剩余 `[6,6,7,8,5]` 排序 `[5,6,6,7,8]`，最大得分 8-5=3，最小得分 0（两个 6），分数 3。所以改元素后新值可制造相等，最小得分能压到 0，只需保证剩余区间极差最小。

```python
nums.sort()
n = len(nums)
ans = float('inf')
for k in range(3):
    # 保留 nums[k : n-(2-k)]
    lo, hi = k, n - 1 - (2 - k)
    if hi - lo < 1:
        ans = 0
        continue
    mx = nums[hi] - nums[lo]
    mn = min(nums[i+1] - nums[i] for i in range(lo, hi))
    ans = min(ans, mx + mn)
return ans
```

## 复杂度
时间：排序 O(n log n)，枚举四种组合各扫 O(n)，总 O(n log n)。
空间：排序原地 O(1) 额外空间（不计排序栈）。

## 易错点
- 输入 `[1,4,3]`：若只枚举 k=0..2 但没处理剩余区间长度 <2 的情况，`hi-lo<1` 时 `min` 会报空序列错，正确做法是长度不足 2 时最小得分记 0。
- 输入 `[1,4,7,8,5]`：若误以为改元素只能删首尾、不能造相等，会算出 4 而非 3；正确做法是允许新值相等使最小得分归 0，只需最小化剩余极差。

## 如果面试官追问
问：若最多改 3 个元素怎么做？答：枚举 k=0..3 共四种削法，剩余区间长度 n-3，同样取极差加相邻差最小值。
