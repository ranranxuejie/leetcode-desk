## 一句话思路
对每个 `strength[i]` 用单调栈求出它作为最小值能覆盖的左右边界，再用前缀和算出这些子数组的和之和，乘上 `strength[i]` 累加。

## 怎么做
1. 用单调栈求 `left[i]`：左边第一个严格小于 `strength[i]` 的下标，没有则 `-1`；求 `right[i]`：右边第一个小于等于 `strength[i]` 的下标，没有则 `n`。
2. 这样每个子数组的最小值唯一归属到某个下标，避免重复计数。
3. 预处理前缀和 `pre`，`pre[k] = strength[0..k-1]` 之和。
4. 对每个 `i`，枚举左端点 `l ∈ (left[i], i]`、右端点 `r ∈ [i, right[i])`，子数组和 = `pre[r+1] - pre[l]`，对所有组合求和后乘 `strength[i]`。

以 `strength = [1,3,1,2]` 为例，`i=1`（值 3）：`left[1]=0`，`right[1]=2`，只有 `l=1, r=1` 一种，和 = `pre[2]-pre[1] = 4-1 = 3`，贡献 `3*3=9`。`i=0`（值 1）：`left[0]=-1`，`right[0]=2`（右边第一个 ≤1 是下标 2），`l=0`，`r∈{0,1}`，和 = `1 + 4 = 5`，贡献 5。

```python
MOD = 10**9 + 7
n = len(strength)
pre = [0] * (n + 1)
for i, v in enumerate(strength):
    pre[i + 1] = pre[i] + v

left, st = [-1] * n, []
for i in range(n):
    while st and strength[st[-1]] >= strength[i]:
        st.pop()
    left[i] = st[-1] if st else -1
    st.append(i)

right, st = [n] * n, []
for i in range(n - 1, -1, -1):
    while st and strength[st[-1]] > strength[i]:
        st.pop()
    right[i] = st[-1] if st else n
    st.append(i)

ans = 0
for i in range(n):
    L, R = i - left[i], right[i] - i
    # 左端点 l 的 pre[l] 之和、右端点 r+1 的 pre[r+1] 之和
    sumL = sum(pre[left[i] + 1:i + 1])
    sumR = sum(pre[i + 1:right[i] + 1])
    ans = (ans + strength[i] * (sumR * L - sumL * R)) % MOD
```

## 复杂度
时间：单调栈 O(n)，每个 `i` 的 `sumL/sumR` 若用前缀和 O(1)，总 O(n)。
空间：`left`、`right`、`pre`、栈各 O(n)。

## 易错点
1. 边界条件写反：求 `left` 用 `>=` 弹栈（严格小于才停），求 `right` 用 `>` 弹栈（小于等于才停）。若两边都用 `>=`，`[1,3,1,2]` 中两个 1 会重复归属，答案偏大。
2. 直接双重循环枚举 `l,r` 是 O(n²)，`n=10^5` 会超时。必须用前缀和把 `sumL/sumR` 压到 O(1)，否则 31.4% 通过率就是这么来的。

## 如果面试官追问
问：若要求输出每个子数组的最小值下标而非求和？答：单调栈求出的 `left/right` 区间内，每个 `i` 对应的子数组集合互不重叠，直接按区间输出即可。
