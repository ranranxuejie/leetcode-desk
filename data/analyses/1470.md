## 一句话思路
新建长度 2n 的数组，第 i 位填 `nums[i]`、第 i+1 位填 `nums[i+n]`，一次遍历搞定。

## 怎么做
1. 开结果数组 `res = [0] * (2 * n)`，长度和 `nums` 相同。
2. 枚举 `i` 从 0 到 `n-1`，`res[2*i] = nums[i]`，`res[2*i+1] = nums[i+n]`。
3. 返回 `res`。

拿示例 1 `nums = [2,5,1,3,4,7], n = 3` 走一遍：`i=0` 时 `res[0]=nums[0]=2`、`res[1]=nums[3]=3`；`i=1` 时 `res[2]=nums[1]=5`、`res[3]=nums[4]=4`；`i=2` 时 `res[4]=nums[2]=1`、`res[5]=nums[5]=7`，得 `[2,3,5,4,1,7]`。关键中间量是下标映射 `i -> 2i` 和 `i+n -> 2i+1`，两个源下标差恒为 `n`。

```python
res = [0] * (2 * n)
for i in range(n):
    res[2 * i] = nums[i]
    res[2 * i + 1] = nums[i + n]
return res
```

也可以写成一行推导：`[v for pair in zip(nums[:n], nums[n:]) for v in pair]`，`zip` 把 `x` 段和 `y` 段配对，内层 `for v in pair` 把每对摊平成两个元素，顺序天然是 x1,y1,x2,y2。切片 `nums[:n]`、`nums[n:]` 各开一份新列表，空间常数比手写下标大一点，但 n ≤ 500 无所谓。

## 复杂度
时间 O(n)：循环 n 次，每次两次赋值，2n 个元素各写一次。
空间 O(n)：额外开了长度 2n 的 `res`，输入本身不计。

## 易错点
- 把 `res[2*i+1]` 写成 `res[2*i] + 1` 或 `res[i+n]`：对示例 1 会得到 `[2,0,5,0,1,0]` 这类错位结果，因为 `i+n` 是源下标不是目标下标，正确目标下标必须是 `2*i+1`。
- 用原地交换硬做：`nums` 前 n 个是 x 段、后 n 个是 y 段，原地重排需要处理环，示例 2 `[1,2,3,4,4,3,2,1]` 里 `nums[1]=2` 和 `nums[4]=4` 互换后又会覆盖未读的 `nums[2]=3`，容易把值冲掉；直接开新数组最稳。

## 如果面试官追问
追问：要求 O(1) 额外空间原地重排怎么办？
答：按 `i -> 2i mod (2n-1)` 的置换环逐环轮换，每个元素只搬一次，注意最后一个下标 `2n-1` 是自环跳过。
