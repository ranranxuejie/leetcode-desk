## 一句话思路
用 `CASE WHEN` 对每行做条件判断，满足「id 为奇数且 name 不以 M 开头」就取 salary，否则取 0。

## 怎么做
1. 条件写成 `employee_id % 2 = 1 AND name NOT LIKE 'M%'`，两个条件必须同时成立。
2. 用 `CASE WHEN ... THEN salary ELSE 0 END` 生成 `bonus` 列，别名必须叫 `bonus`。
3. 外层 `ORDER BY employee_id` 保证输出顺序。

拿官方示例第 3 行 `(7, 'Addilyn', 7400)` 走一遍：`7 % 2 = 1` 为真，`'Addilyn' NOT LIKE 'M%'` 为真，`AND` 得真，`bonus = 7400`。再看 `(3, 'Michael', 3800)`：`3 % 2 = 1` 真，但 `'Michael' LIKE 'M%'` 真，取反为假，`AND` 得假，落到 `ELSE 0`。

```python
# 伪 SQL 表达，实际提交为 SQL
# SELECT employee_id,
#        CASE WHEN employee_id % 2 = 1 AND name NOT LIKE 'M%'
#             THEN salary ELSE 0 END AS bonus
# FROM Employees
# ORDER BY employee_id;

# 若用 pandas 模拟同一逻辑：
mask = (df["employee_id"] % 2 == 1) & (~df["name"].str.startswith("M"))
df["bonus"] = df["salary"].where(mask, 0)
df = df[["employee_id", "bonus"]].sort_values("employee_id")
```

关键在 `&` 两侧都要加括号：`~df["name"].str.startswith("M")` 里的 `~` 优先级高于 `&`，不加括号会把布尔序列按位取反出错。

## 复杂度
时间：O(n log n)，n 为 Employees 行数，排序贡献 log n，扫描贡献 n。
空间：O(n)，结果集与排序缓冲各占一份，未额外建索引。

## 易错点
- 写成 `name NOT LIKE 'M%' OR employee_id % 2 = 1` → 示例中 `(2, 'Meir', 3000)` 会因 id 偶数但名字不以 M 开头而误得 3000，正确是 `AND`，该行应为 0。
- 用 `name LIKE 'M%'` 直接判假而不取反 → `(3, 'Michael', 3800)` 会得 3800，正确是 `NOT LIKE`，该行应为 0；注意 `LIKE 'M%'` 区分大小写，`'meir'` 不算以 M 开头。

## 如果面试官追问
问：若奖金改为「奇数 id 且名字不以 M 开头取 50% 工资」怎么改？
答：把 `THEN salary` 换成 `THEN salary * 0.5`，其余条件与排序不变。
