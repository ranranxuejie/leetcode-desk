## 一句话思路
用 26 个栈按字符存未标记下标，扫到 s[i] 时弹镜像字符栈顶，栈顶天然是最近的未标记 j。

## 怎么做
1. 建 `st = [[] for _ in range(26)]`，`mirror(c) = chr(ord('z') - (ord(c) - ord('a')))`。
2. 从左到右扫 `i, c`，先算 `m = mirror(c)`，若 `st[m]` 非空则 `j = st[m].pop()`，`ans += i - j`。
3. 否则把 `i` 压入 `st[c]`（只有没被配对的下标才留在栈里，所以栈顶必是最近的未标记）。
4. 返回 `ans`。

以 `s = "aczzx"` 为例：i=0 压 `st['a']=[0]`；i=1 压 `st['c']=[1]`；i=2 是 `'z'`，镜像 `'a'`，弹出 j=0，`ans=2`；i=3 是 `'z'`，镜像 `'a'`，`st['a']` 已空，压 `st['z']=[3]`；i=4 是 `'x'`，镜像 `'c'`，弹出 j=1，`ans=2+3=5`。

```python
def calculateScore(s):
    st = [[] for _ in range(26)]
    ans = 0
    for i, c in enumerate(s):
        m = 25 - (ord(c) - 97)
        if st[m]:
            ans += i - st[m].pop()
        else:
            st[ord(c) - 97].append(i)
    return ans
```

关键点：`st[m]` 里存的是「镜像字符为 m 的那些未标记下标」，弹栈即取最近的一个，不需要额外比较距离。

## 复杂度
时间 O(n)：每个下标最多入栈一次、出栈一次，26 个栈的初始化是常数。
空间 O(n)：最坏情况（如 `"abcdef"`）所有下标都留在栈里，共 n 个整数。

## 易错点
- 把 `i` 无条件压栈 → 对 `"aczzx"` 的 i=2 会先压 `'z'` 再配对，导致 i=3 的 `'z'` 弹出 j=2 得 1 分而非跳过，最终答案错成 6。正确做法是配对成功时只弹不压。
- 镜像算成 `chr(ord('a') + 25 - (ord(c) - 97))` 之外的写法，或对 `'a'` 用 `ord('z') - ord(c)` 直接减 → `'a'` 得 `'z'` 对，但 `'b'` 会得 `'y'` 之外的值。统一用 `25 - (ord(c) - 97)` 作下标最稳。

## 如果面试官追问
问：若要求输出所有配对方案而非总分？
答：把 `ans += i - j` 换成 `pairs.append((j, i))`，其余不变，仍是 O(n)。
