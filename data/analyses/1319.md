## 一句话思路
用并查集数出连通分量个数 `k`，答案就是 `k-1`，前提是边数 `len(connections) >= n-1`。

## 怎么做
1. 先判 `len(connections) < n - 1`，直接返回 `-1`，因为连通 n 个点至少要 n-1 条边。
2. 并查集合并每条 `connections[i] = [a, b]`，统计合并后根节点个数即连通分量数 `k`。
3. 返回 `k - 1`：每个多余分量贡献一条可拔的边，恰好够连 `k-1` 次。

以示例 2 为例：`n=6`，边 `[[0,1],[0,2],[0,3],[1,2],[1,3]]`，合并后 `{0,1,2,3}` 一个分量、`{4}`、`{5}` 各一个，`k=3`，返回 `3-1=2`。边数 5 ≥ 5，可行。

```python
parent = list(range(n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
if len(connections) < n - 1:
    return -1
for a, b in connections:
    ra, rb = find(a), find(b)
    if ra != rb:
        parent[ra] = rb
k = sum(find(i) == i for i in range(n))
return k - 1
```

## 复杂度
时间：O(n + m·α(n))，m 为边数，路径压缩近似常数。
空间：O(n)，`parent` 数组开 n 个。

## 易错点
- 输入 `n=6, connections=[[0,1],[0,2],[0,3],[1,2]]`（示例 3）→ 若只算 `k-1` 会得 2，但边数 4 < 5，实际返回 `-1`。必须先判边数再算分量。
- 输入 `n=1, connections=[]` → 若把 `k-1` 当答案会得 0 没问题，但若先判 `len < n-1` 得 `0 < 0` 为假，正确返回 0；注意别写成 `<=` 误判成 -1。

## 如果面试官追问
要求输出具体操作方案怎么办？答：在并查集里额外记录每个分量的任意一条边，把非主分量的边拔下，依次连到主分量上即可。
