## 一句话思路
把「1 从位置 i 能跳到哪些位置」建成图，用 BFS 分层求最短路，用有序集合跳过已访问点保证每个位置只入队一次。

## 怎么做
1. 关键观察：1 在位置 i 时，选一个长度 k、包含 i 的窗口 `[L, L+k-1]`，翻转后 1 落到 `L + (L+k-1) - i = 2L + k - 1 - i`。所以可达位置集合是 `{2L+k-1-i | max(0,i-k+1) <= L <= min(i, n-k)}`，即一段**步长为 2 的等差数列**。
2. 用两个有序集合（或两个 `SortedList`）分别存「偶数下标未访问点」和「奇数下标未访问点」，BFS 时按奇偶取对应集合，把区间内所有点一次性弹出、赋距离、入队。
3. 起点 p 距离 0；banned 里的点从一开始就不放进集合。

以示例 1 为例：`n=4, p=0, k=4`，L 只能取 0，可达位置 `2*0+4-1-0 = 3`，偶数集合里 0 已弹出、2 被 banned 排除，奇数集合弹出 3 得距离 1，答案 `[0,-1,-1,1]`。

```python
from sortedcontainers import SortedList
# 偶数/奇数下标各一个有序集合，banned 预先剔除
sets = [SortedList(), SortedList()]
for i in range(n):
    if i not in banned_set:
        sets[i & 1].add(i)
dist = [-1] * n
dist[p] = 0
q = deque([p])
while q:
    i = q.popleft()
    lo = max(0, i - k + 1)          # L 的下界
    hi = min(i, n - k)              # L 的上界
    if lo > hi:
        continue
    a = 2 * lo + k - 1 - i          # 可达位置最小值
    b = 2 * hi + k - 1 - i          # 可达位置最大值
    s = sets[a & 1]                 # 步长 2，奇偶不变
    idx = s.bisect_left(a)
    while idx < len(s) and s[idx] <= b:
        j = s.pop(idx)
        dist[j] = dist[i] + 1
        q.append(j)
```

## 复杂度
时间 O(n log n)：每个位置最多被弹出一次，每次 `bisect`/`pop` 是 log n。
空间 O(n)：两个有序集合加 dist、队列。

## 易错点
- `k=1` 时窗口只有 `[i,i]`，翻转后位置不变，可达集合退化成 `{i}` 本身。若照搬公式 `a=b=i`，会把 i 自己再弹一次导致死循环——必须先 `pop` 掉 i 再算，或直接特判 `k==1` 返回只有 p 为 0。
- 区间端点算错：`lo = max(0, i-k+1)`、`hi = min(i, n-k)`，漏掉 `n-k` 这个上界时，示例 1 中 i=0 会算出 L 上界为 0 没问题，但 n=5,k=3,i=4 时会取到 L=4 导致窗口越界，得到不存在的目标位置。

## 如果面试官追问
问：不用 SortedList 行不行？答：可以，用「并查集指向下一个未访问点」按奇偶各维护一条链，弹出后 `parent[x]=find(x+2)`，复杂度降到近似 O(n α(n))。
