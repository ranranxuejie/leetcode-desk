## 一句话思路
枚举所有子数组起点，向右扩展时用哈希集合存元组去重，同时维护可被 p 整除的计数，超 k 就停。

## 怎么做
1. 外层 `i` 遍历起点，内层 `j` 从 `i` 向右扩展，`cnt` 记录 `nums[j] % p == 0` 的个数。
2. 每扩展一步，若 `cnt > k` 立即 `break`（再往右只会更多），否则把 `tuple(nums[i:j+1])` 加入 `seen`。
3. 用元组而非切片列表做键，因为列表不可哈希；`len(seen)` 即答案。

以 `nums = [2,3,3,2,2], k = 2, p = 2` 为例：`i=0` 时 `j` 走到 3，`cnt` 从 1→1→1→2，四个子数组入集合；`j=4` 时 `cnt=3 > k` 触发 `break`，所以 `[2,3,3,2,2]` 不入集合。`i=1` 时 `j` 可走到 4，`cnt` 最多 2，产出 `[3]`、`[3,3]`、`[3,3,2]`、`[3,3,2,2]`；`i=2` 产出 `[3,2]`、`[3,2,2]`；`i=3` 产出 `[2,2]`。集合最终 11 个元素。

```python
seen = set()
n = len(nums)
for i in range(n):
    cnt = 0
    for j in range(i, n):
        if nums[j] % p == 0:
            cnt += 1
        if cnt > k:
            break
        seen.add(tuple(nums[i:j + 1]))
return len(seen)
```

注意 `break` 必须在 `add` 之前判断，否则会把违规子数组也塞进去。

## 复杂度
时间：O(n^3)，n=200 时约 8×10^6 次元素拷贝，可过；外层内层 O(n^2)，每次切片拷贝 O(n)。
空间：O(n^3) 最坏，集合里存 O(n^2) 个元组，每个长度 O(n)。

## 易错点
- 输入 `nums = [1,2,3,4], k = 4, p = 1`：若把 `cnt > k` 写成 `cnt >= k`，`cnt` 到 4 就提前 `break`，会漏掉长度 4 的子数组，答案从 10 掉到 9。正确写法是严格大于才停。
- 输入 `nums = [2,3,3,2,2], k = 2, p = 2`：若用 `nums[i:j+1]` 列表直接 `add`，Python 抛 `TypeError: unhashable type: 'list'`；必须 `tuple(...)` 转换，且转换要在 `cnt` 检查通过之后做，避免白拷贝。

## 如果面试官追问
问：n 放大到 10^5 怎么办？
答：O(n^2) 枚举不可行，需按「可整除位置」分段 + 滚动哈希去重，或改用后缀自动机思路，但本题 n≤200 不必。
