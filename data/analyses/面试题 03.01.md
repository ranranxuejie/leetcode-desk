## 一句话思路
用一个长度 `3*stackSize` 的数组，第 `i` 个栈独占 `[i*stackSize, (i+1)*stackSize)` 段，每段配一个栈顶指针即可。

## 怎么做
1. 构造时开 `self.data = [0]*(3*stackSize)` 和 `self.top = [-1,-1,-1]`，`top[i]` 存的是**段内偏移**，不是全局下标。
2. `push` 先判 `top[i] == stackSize-1`（满），满了直接 return，不报错。
3. 全局下标统一写 `i*stackSize + top[i]`，`pop`/`peek` 先判 `top[i] == -1` 返回 `-1`。
4. `isEmpty` 就是 `top[i] == -1`。

拿示例 1 走一遍：`stackSize=1`，`data` 长度 3。`push(0,1)` 后 `top=[0,-1,-1]`，写入 `data[0*1+0]=data[0]=1`；再 `push(0,2)` 时 `top[0]==0==stackSize-1`，判满丢弃，所以随后 `pop(0)` 返回 1 而不是 2。

```python
def push(self, i, v):
    if self.top[i] == self.size - 1:
        return
    self.top[i] += 1
    self.data[i * self.size + self.top[i]] = v

def pop(self, i):
    if self.top[i] == -1:
        return -1
    v = self.data[i * self.size + self.top[i]]
    self.top[i] -= 1
    return v
```

`peek` 与 `pop` 只差最后那行 `top[i] -= 1`，别复制错。

## 复杂度
时间：每次操作 O(1)，只碰一个 `data` 下标和 `top[i]`。
空间：O(3*stackSize)，预分配定长数组，无动态扩容。

## 易错点
- `stackSize=0` 时（示例外的边界）`data` 为空，`top[i]==-1` 同时等于 `stackSize-1`，若先判满再判空，`pop` 会误返回而不是走空分支；正确做法是先判 `top[i]==-1` 再判满，或构造时直接让所有操作短路。
- 把 `top[i]` 当全局下标用：`push(1,v)` 时若写 `data[top[1]]`，会覆盖栈 0 的 `data[0]`；必须写 `i*stackSize + top[i]`，示例 2 中 `stackSize=2` 时栈 1 的起点是 2，写成 `top[1]=0` 就落到 `data[0]` 上。

## 如果面试官追问
问：改成不定长、三栈共享整个数组怎么设计？
答：用「中段向两端长」的经典方案，或直接每栈一个 list 再拼，面试说清取舍即可。
