## 一句话思路
枚举每个 `nums[i]` 当异常值，用哈希表 O(1) 判断剩下的数能否凑出「和 + 特殊数字」的结构。

## 怎么做
1. 先算 `total = sum(nums)`，并建 `Counter(nums)` 记录每个值出现次数。
2. 枚举 `x = nums[i]` 作为异常值，则剩余元素之和为 `rest = total - x`。
3. 关键恒等式：若剩余里存在和 `s` 与特殊数字集合，则 `rest = s + sum(特殊数字)`，而 `s` 本身也是剩余元素之一，故 `s = rest / 2` 必须成立——即 `rest` 必须为偶数，且 `s = rest // 2` 在剩余元素中存在。
4. 用 `Counter` 校验 `s` 的可用次数：若 `s == x` 需要 `cnt[s] >= 2`，否则 `cnt[s] >= 1`；满足则 `x` 是合法异常值，取最大。

以 `nums = [2,3,5,10]` 为例：`total = 20`。枚举 `x = 10`，`rest = 10`，`s = 5`，`cnt[5] = 1 >= 1`，合法，答案 10。

```python
from collections import Counter

total = sum(nums)
cnt = Counter(nums)
ans = -2**31
for x in nums:
    rest = total - x
    if rest % 2 != 0:
        continue
    s = rest // 2
    need = 2 if s == x else 1
    if cnt[s] >= need:
        ans = max(ans, x)
return ans
```

注意 `rest % 2` 对负数在 Python 里也正确（`-3 % 2 == 1`），无需特判。

## 复杂度
时间：O(n)，一次求和 + 一次建 Counter + 一次枚举，每次 O(1) 查表。
空间：O(n)，Counter 最多存 n 个不同值。

## 易错点
- 输入 `[1,1,1,1,1,5,5]` 枚举 `x = 5` 时 `s = 5`，若只判 `cnt[5] >= 1` 会把同一个 5 同时当和与异常值 → 必须用 `need = 2` 区分 `s == x` 的情形。
- 输入 `[-2,-1,-3,-6,4]` 中 `rest` 可能为负，若写成 `rest // 2` 前不检查奇偶、或用 `rest >> 1` 处理负数，会得到错误商 → 统一用 `rest % 2 != 0` 跳过，再 `rest // 2`。

## 如果面试官追问
问：若要求输出具体方案（哪些是特殊数字）而非仅最大值？
答：在命中 `x` 时记录 `s`，从 Counter 里扣掉 `x` 和 `s` 各一次，剩余键值展开即为特殊数字集合。
