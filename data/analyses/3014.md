## 一句话思路
把 word 的字母按「按键内第几位」分层，前 8 个字母各按 1 次，接下来 8 个各按 2 次，依此类推，累加即得最少次数。

## 怎么做
1. 设 `n = len(word)`，因为字母互不相同，只需关心字母个数，与具体是哪些字母无关。
2. 8 个按键（2~9）每个第 1 位都只花 1 次，所以前 `min(n, 8)` 个字母成本为 1。
3. 第 2 层再放 8 个字母，成本为 2；第 3 层成本为 3……即第 `i` 层（从 0 计）的字母成本是 `i + 1`。
4. 用循环按层累加：每层取 `min(8, 剩余字母数)` 个，乘上当前层成本。

以 `word = "xycdefghij"`（n = 10）为例：第 0 层取 8 个字母，成本 8×1 = 8；剩余 2 个字母进入第 1 层，成本 2×2 = 4；合计 12，与官方输出一致。

```python
n = len(word)
ans = 0
layer = 1          # 当前按键内第几位，成本即 layer
remain = n
while remain > 0:
    take = min(8, remain)
    ans += take * layer
    remain -= take
    layer += 1
# ans 即最少按键次数
```

也可以直接写成闭式：`ans = sum((i // 8 + 1) for i in range(n))`，因为第 `i` 个（0 起）字母落在第 `i // 8` 层，成本 `i // 8 + 1`。两种写法等价，循环版更直观。

## 复杂度
时间 O(n)，n 为 word 长度，循环最多 4 轮（n ≤ 26）。
空间 O(1)，只用 `ans / layer / remain` 几个整型变量。

## 易错点
- 输入 `word = "abcde"`（n = 5）→ 若误以为每个按键只能放 1 个字母、或按 26 个字母平均分 8 键去算，会得到 5 以外的错误值 → 正确做法是前 8 个字母一律成本 1，5 个字母全在第 0 层，答案就是 5。
- 输入 `word = "abcdefghi"`（n = 9）→ 若把第 9 个字母也算成成本 1（忘记每键第 2 位要按 2 次），会错成 9 → 正确做法是第 0 层只容纳 8 个，第 9 个字母进入第 1 层，答案 8×1 + 1×2 = 10。

## 如果面试官追问
问：若允许某些按键映射 0 个字母，答案会变吗？
答：不会，空按键不省成本，最优仍是尽量把字母塞满前 8 个键的第 1 位。
