## 一句话思路
两树直径取 `max(d1, d2, ceil(d1/2)+ceil(d2/2)+1)`，因为连接点选各自直径中点最优。

## 怎么做
1. 对每棵树用两次 BFS 求直径：从任意点出发找最远点 `u`，再从 `u` 出发找最远距离即直径。
2. 记 `d1`、`d2` 为两树直径，答案取三者最大值。
3. 关键中间值：示例 1 中 `edges1` 是星形，`d1 = 2`；`edges2` 是单边，`d2 = 1`。代入得 `max(2, 1, 1+1+1) = 3`，与输出一致。
4. 示例 2 两树同构，`d1 = d2 = 4`，得 `max(4, 4, 2+2+1) = 5`。

```python
from collections import deque

def diameter(edges):
    n = len(edges) + 1
    g = [[] for _ in range(n)]
    for a, b in edges:
        g[a].append(b); g[b].append(a)
    def bfs(s):
        dist = [-1] * n
        dist[s] = 0
        q = deque([s])
        while q:
            x = q.popleft()
            for y in g[x]:
                if dist[y] < 0:
                    dist[y] = dist[x] + 1
                    q.append(y)
        far = max(range(n), key=lambda i: dist[i])
        return far, dist[far]
    u, _ = bfs(0)
    _, d = bfs(u)
    return d

d1, d2 = diameter(edges1), diameter(edges2)
return max(d1, d2, (d1 + 1) // 2 + (d2 + 1) // 2 + 1)
```

## 复杂度
时间：O(n + m)，两次 BFS 各遍历一遍两棵树的边。
空间：O(n + m)，邻接表和 `dist` 数组。

## 易错点
- 空树边界：`edges1 = []` 时 `n = 1`，`d1 = 0`，公式给 `0+ceil(d2/2)+1`，若误把 `d1` 当 1 会多算 1。正确做法是 `diameter` 对单节点返回 0。
- 中点取整：`d1 = 3` 时半直径是 `2` 不是 `1`，用 `(d1+1)//2` 而非 `d1//2`；示例 1 的 `d2 = 1` 若写成 `0` 会得 2，错。

## 如果面试官追问
要求输出具体连接方案？答：在两次 BFS 的 `dist` 数组上从直径端点回溯到中点，返回两棵树各自的中点节点对即可。
