## 一句话思路
用哈希表把两个数组的 weight 按 value 累加，再按 value 升序输出。

## 怎么做
1. 建一个字典 `d`，先遍历 `items1`，把 `d[value] = weight`。
2. 再遍历 `items2`，用 `d[value] = d.get(value, 0) + weight` 累加，这样重复的 value 自动合并。
3. 把 `d.items()` 按 key 排序，转成 `[[v, w], ...]` 返回。

以示例 1 为例：`items1 = [[1,1],[4,5],[3,8]]` 处理完 `d = {1:1, 4:5, 3:8}`；再处理 `items2 = [[3,1],[1,5]]`，`d[3]` 从 8 变 9，`d[1]` 从 1 变 6，最终 `d = {1:6, 4:5, 3:9}`，排序后得 `[[1,6],[3,9],[4,5]]`。

```python
d = {}
for v, w in items1:
    d[v] = w
for v, w in items2:
    d[v] = d.get(v, 0) + w
return [[v, d[v]] for v in sorted(d)]
```

关键点：`items1` 里 value 唯一，所以第一步直接赋值不会覆盖；第二步必须用 `get(v, 0)`，否则 `items2` 里独有的 value（示例 3 的 7）会 `KeyError`。

## 复杂度
时间：O((m+n) + k log k)，m、n 是两数组长度，k 是不同 value 数，排序贡献 log。
空间：O(k)，字典存 k 个 value 的累计重量。

## 易错点
- `items2` 中独有的 value（如示例 3 的 7）→ 若写成 `d[v] += w` 会 `KeyError` → 必须 `d.get(v, 0) + w`。
- 忘记排序直接返回 `d.items()` → 字典插入序是 `1,4,3`，输出 `[[1,6],[4,5],[3,9]]` 而非升序 → 必须 `sorted(d)` 或 `sorted(d.items())`。

## 如果面试官追问
若 value 范围扩大到 10^9 且要求 O(m+n) 不排序？答：改用有序结构（如平衡树）边插边维护，或先哈希再对 key 排序，规模大时排序不可避免。
