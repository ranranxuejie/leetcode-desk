## 一句话思路
n≤8，用状压 DP：`dp[mask]` 表示已开锁集合为 mask 时的最少分钟，按「下一个开哪把」转移。

## 怎么做
1. 关键观察：开锁顺序决定每把锁的 x，而 x 只由「之前开了几把」决定，即第 j 把开的锁 x = 1 + j*k，与开的是谁无关。
2. 于是 `dp[mask]` 里 mask 的 popcount 就是已开锁数，下一把锁的 x = 1 + popcount(mask)*k，开它需 `ceil(strength[i] / x)` 分钟。
3. 从 `dp[0]=0` 出发，枚举 mask 与不在 mask 中的 i，取 min 更新 `dp[mask | 1<<i]`。
4. 答案 `dp[(1<<n)-1]`。

以 `strength=[3,4,1], k=1` 为例：`dp[0]=0`，先开 i=2（strength=1），x=1，耗时 `ceil(1/1)=1`，得 `dp[0b100]=1`；再开 i=1，x=1+1*1=2，耗时 `ceil(4/2)=2`，累计 3；最后开 i=0，x=1+2*1=3，耗时 `ceil(3/3)=1`，累计 4。

```python
n = len(strength)
INF = 10**18
dp = [INF] * (1 << n)
dp[0] = 0
for mask in range(1 << n):
    if dp[mask] == INF:
        continue
    x = 1 + bin(mask).count("1") * k
    for i in range(n):
        if mask >> i & 1:
            continue
        cost = (strength[i] + x - 1) // x
        nm = mask | (1 << i)
        if dp[mask] + cost < dp[nm]:
            dp[nm] = dp[mask] + cost
return dp[(1 << n) - 1]
```

## 复杂度
时间：`O(2^n * n)`，2^n 个状态各枚举 n 把锁。
空间：`O(2^n)`，dp 数组；无其他额外结构。

## 易错点
- 把 x 算成「已开锁数 * k」漏了初始的 1：示例 1 第一把锁 x 应为 1，若写成 0 会除零或把 `ceil(1/1)` 算错，正确是 `x = 1 + popcount(mask)*k`。
- 用浮点 `math.ceil(strength[i]/x)`：strength 最大 10^6、x 小时浮点误差可能把 3/3 算成 1.0000001 再向上取整成 2，正确用整数 `(strength[i] + x - 1) // x`。

## 如果面试官追问
若 n 放大到 15 以上怎么办？答：状压 `2^n` 会爆，但本题 x 单调递增，可改按 strength 降序贪心验证——不过那需要额外证明，面试时先说明状压是 n≤8 的稳妥解。
