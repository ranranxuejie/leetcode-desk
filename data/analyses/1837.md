## 一句话思路
反复用 `n % k` 取当前最低位、`n //= k` 右移，累加余数即为各位数字和。

## 怎么做
1. 初始化 `total = 0`，循环条件 `while n > 0`。
2. 每轮取 `n % k` 加到 `total`，这就是 k 进制下当前最低位的数字。
3. 然后 `n //= k`，把这一位丢掉，进入下一位。
4. 循环结束时 `n` 归零，`total` 即答案。

以 `n = 34, k = 6` 为例：第一轮 `34 % 6 = 4`，`total = 4`，`n = 34 // 6 = 5`；第二轮 `5 % 6 = 5`，`total = 9`，`n = 5 // 6 = 0`，循环结束返回 9。关键中间值是 `n` 从 34 变成 5 再变成 0，余数序列 4、5 逆序拼起来正是 `54`。

```python
def sum_base(n, k):
    total = 0
    while n > 0:
        total += n % k
        n //= k
    return total
```

注意这里不需要真的构造出 `"54"` 字符串再逐字符转数字，取模过程天然按位拆解，省掉字符串拼接和 `int()` 转换。

## 复杂度
时间：O(log_k n)，循环次数等于 n 在 k 进制下的位数。
空间：O(1)，只用了 `total` 和循环变量，没开数组或字符串。

## 易错点
- 输入 `n = 10, k = 10` → 若误以为要特判「k 等于 10 时直接返回 n」会错成 10，正确做法是照常循环：`10 % 10 = 0`、`10 // 10 = 1`、`1 % 10 = 1`，累加得 1。
- 输入 `n = 1, k = 2` → 若循环条件写成 `while n > 1` 会漏掉最高位，错成 0；正确做法是 `while n > 0`，保证最后一位（此处为 1）也被计入。

## 如果面试官追问
问：若 k 可能大于 n，比如 `n = 5, k = 100` 呢？
答：循环只跑一轮，`5 % 100 = 5`、`5 // 100 = 0`，返回 5，逻辑无需改动。
