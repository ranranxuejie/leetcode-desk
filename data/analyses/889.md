## 一句话思路
用哈希表记 postorder 下标，前序首元素是根、次元素是左子树根，据此在后序里切出左右子树区间递归。

## 怎么做
1. 建 `pos = {v: i for i, v in enumerate(postorder)}`，O(1) 定位任意值在后序中的位置。
2. 递归 `build(pre_lo, pre_hi, post_lo, post_hi)`，区间左闭右开；`pre_lo == pre_hi` 返回 `None`。
3. 根是 `preorder[pre_lo]`；若区间只剩一个元素直接返回该节点，否则左子树根是 `preorder[pre_lo + 1]`。
4. 用 `pos[preorder[pre_lo + 1]]` 得左根在后序的下标 `k`，左子树大小 `left_size = k - post_lo + 1`，据此切两段递归。

以示例 1 为例：`pre_lo=0`，根 `1`，左根 `preorder[1]=2`，`pos[2]=2`，`post_lo=0`，故 `left_size = 2 - 0 + 1 = 3`。左子树前序 `[2,4,5]`、后序 `[4,5,2]`；右子树前序 `[3,6,7]`、后序 `[6,7,3]`。

```python
def build(pre_lo, pre_hi, post_lo, post_hi):
    if pre_lo == pre_hi:
        return None
    root = TreeNode(preorder[pre_lo])
    if pre_hi - pre_lo == 1:
        return root
    k = pos[preorder[pre_lo + 1]]
    left_size = k - post_lo + 1
    root.left = build(pre_lo + 1, pre_lo + 1 + left_size, post_lo, k + 1)
    root.right = build(pre_lo + 1 + left_size, pre_hi, k + 1, post_hi)
    return root
```

## 复杂度
时间 O(n)：每个节点建一次，哈希查表 O(1)。
空间 O(n)：`pos` 字典 n 项，递归栈最坏 O(n)（链状树）。

## 易错点
- 单元素区间不特判 → 对 `preorder=[1]` 会去取 `preorder[1]` 越界，或对叶子节点算出 `left_size` 后切出非法区间。正确做法是 `pre_hi - pre_lo == 1` 时直接返回根，不再切分。
- 右子树前序起点写成 `pre_lo + 1 + left_size` 之外的值（如漏加 1）→ 示例 1 中右子树会从 `5` 开始而不是 `3`，整棵树错位。正确做法是左段长度 `left_size` 同时用于前序和后序：前序右段起点 `pre_lo + 1 + left_size`，后序右段起点 `k + 1`。

## 如果面试官追问
追问：若允许重复值怎么办？
答：前序次元素不再唯一确定左根，需按后序中「根前一个元素」配对判断，最坏退化 O(n²)，无法用单值哈希。
