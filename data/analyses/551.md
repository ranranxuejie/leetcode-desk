## 一句话思路
一次遍历同时维护缺勤计数 `a` 和当前连续迟到长度 `cur`，任一条件被破坏立刻返回 `False`。

## 怎么做
1. 初始化 `a = 0`、`cur = 0`，遍历 `s` 的每个字符 `ch`。
2. 若 `ch == 'A'`：`a += 1`，`cur` 归零；若此时 `a >= 2` 直接返回 `False`。
3. 若 `ch == 'L'`：`cur += 1`，若 `cur >= 3` 直接返回 `False`。
4. 若 `ch == 'P'`：只把 `cur` 归零，`a` 不动。

以 `s = "PPALLL"` 为例：读到第 3 个字符 `'A'` 时 `a` 从 0 变 1，`cur` 从 0 归零；接着连续三个 `'L'` 让 `cur` 依次变成 1、2、3，在 `cur == 3` 那一刻返回 `False`——注意此时 `a` 仍为 1，是迟到条件单独否决的，不是缺勤条件。

```python
a = cur = 0
for ch in s:
    if ch == 'A':
        a += 1
        cur = 0
        if a >= 2:
            return False
    elif ch == 'L':
        cur += 1
        if cur >= 3:
            return False
    else:
        cur = 0
return True
```

关键点：`'A'` 和 `'P'` 都要把 `cur` 清零，只有 `'L'` 才累加。漏掉 `'A'` 的清零，`"LLALL"` 会被误判为连续 4 个 `'L'`。

## 复杂度
时间 O(n)：`n = len(s)`，每个字符只被访问一次。
空间 O(1)：只开了 `a`、`cur` 两个整型变量，没有额外数组。

## 易错点
- 输入 `"ALL"` 或 `"LAL"`：若只在 `'L'` 分支累加、忘了 `'A'` 也清零，`"LAL"` 的 `cur` 会累到 2 甚至 3 而误判 `False`；正确做法是 `'A'` 和 `'P'` 两个分支都执行 `cur = 0`。
- 输入 `"AA"` 或 `"AALLL"`：若把缺勤条件写成 `a > 2` 而非 `a >= 2`，`"AA"` 会错返回 `True`；题面要求「严格少于两天」，即 `a == 2` 就该否决，用 `a >= 2` 提前返回。

## 如果面试官追问
追问：若把「连续 3 天迟到」改成「任意 3 天迟到」怎么改？
答：`cur` 换成全局 `late` 计数，判 `late >= 3` 即可，不再需要清零逻辑。
