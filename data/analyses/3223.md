## 一句话思路
按字符计数：出现次数 ≥3 的字符，每 3 个能消掉 2 个，最终只留 1 或 2 个。

## 怎么做
1. 用 `Counter(s)` 统计每个字母出现次数 `c`。
2. 对每个 `c`：若 `c < 3`，贡献 `c`；否则贡献 `1 if c % 2 == 1 else 2`。
3. 累加所有贡献即为答案。

以 `s = "abaacbcbb"` 为例，计数得 `a:3, b:4, c:2`。`a` 的 3 个可消成 1 个，`b` 的 4 个消成 2 个，`c` 的 2 个原样保留，合计 `1+2+2=5`，与示例一致。

关键中间值：`c=3` 时 `3 % 2 == 1` 取 1；`c=4` 时 `4 % 2 == 0` 取 2。奇偶决定剩 1 还是 2。

```python
from collections import Counter

def minimumLength(s):
    ans = 0
    for c in Counter(s).values():
        if c < 3:
            ans += c
        else:
            ans += 1 if c % 2 == 1 else 2
    return ans
```

为什么成立：一个字符只要还剩 ≥3 个，就总能挑出「左中右」三个同字符，删掉两侧两个，净减 2。所以每个字符的个数只能从 `c` 一路减到 1（奇数）或 2（偶数），且不同字符互不干扰——操作只删同字符，不会改变别的字符的计数。

## 复杂度
时间 O(n)：遍历 `s` 建计数表，n 为字符串长度。
空间 O(1)：只有 26 个小写字母的计数，常数级额外空间。

## 易错点
- 输入 `s = "aa"` → 若误以为「有重复就能删」会返回 0 → 正确做法是 `c < 3` 直接保留，`aa` 只有 2 个凑不出中间字符，答案 2。
- 输入 `s = "aaa"`（`c=3`）→ 若写成 `c % 3` 或 `c - 2` 会算成 0 或 1 之外的值 → 正确做法是按奇偶取 1/2，3 个消一次剩 1 个，答案 1。

## 如果面试官追问
问：若要求输出操作后的最短字符串本身而非长度？
答：每个字符保留 1 或 2 个，按原串首次出现顺序拼接即可，长度不变。
