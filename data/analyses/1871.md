## 一句话思路
用前缀和记录「可达位置数」，对每个 `s[j]=='0'` 的位置查窗口 `[j-maxJump, j-minJump]` 内是否有可达点，避免 O(n·maxJump) 枚举。

## 怎么做
1. 建 `pre` 数组，`pre[i]` 表示下标 `0..i-1` 中可达位置个数，`pre[0]=0`；`reach[0]=True`。
2. 从 `j=1` 扫到 `n-1`，只对 `s[j]=='0'` 计算窗口左右界 `lo=max(0, j-maxJump)`、`hi=j-minJump`。
3. 若 `hi>=0` 且 `pre[hi+1]-pre[lo]>0`，则 `reach[j]=True`。
4. 每轮结束把 `reach[j]` 累加进 `pre[j+1]=pre[j]+reach[j]`，最后返回 `reach[n-1]`。

以示例 1 `s="011010"`（去空格）、`minJump=2, maxJump=3` 为例：`j=3` 时 `lo=0, hi=1`，`pre[2]-pre[0]=1>0`，故 `reach[3]=True`；`j=5` 时 `lo=2, hi=3`，`pre[4]-pre[2]` 含 `reach[3]`，得 `reach[5]=True`。

```python
n = len(s)
reach = [False] * n
reach[0] = True
pre = [0] * (n + 1)
for j in range(1, n):
    if s[j] == '0':
        lo = max(0, j - maxJump)
        hi = j - minJump
        if hi >= 0 and pre[hi + 1] - pre[lo] > 0:
            reach[j] = True
    pre[j + 1] = pre[j] + (1 if reach[j] else 0)
return reach[n - 1]
```

## 复杂度
时间 O(n)：每个下标只做一次常数次前缀和查询。
空间 O(n)：`reach` 与 `pre` 各开长度 n 的数组。

## 易错点
- `s="01101110", minJump=2, maxJump=3`：若把 `hi` 写成 `j-minJump+1` 或漏掉 `hi>=0` 判断，`j=1` 时 `hi=-1` 会越界或误判可达，正确做法是先判 `hi>=0` 再查 `pre[hi+1]-pre[lo]`。
- 示例 1 中 `j=4` 是 `'1'`：若对 `'1'` 也写 `reach[j]=True`，`pre` 会虚增，导致 `j=5` 被错误判可达；正确做法是只在 `s[j]=='0'` 分支内赋值 `reach[j]`，`pre` 累加用 `reach[j]` 原值。

## 如果面试官追问
问：若要求输出一条具体跳跃路径？答：额外存 `from[j]` 记录窗口内任一可达前驱，从 `n-1` 回溯到 0 即可，时间仍 O(n)。
