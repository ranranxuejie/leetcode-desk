## 一句话思路
用正则把 paragraph 切成小写单词，Counter 计数后排除 banned 集合，取 max 即可。

## 怎么做
1. 用 `re.findall(r'[a-z]+', paragraph.lower())` 一次性完成小写化与去标点。
2. 用 `Counter` 统计词频，`banned` 转成 `set` 便于 O(1) 判断。
3. 遍历计数结果，跳过禁用词，维护当前最大频次与对应单词。

以示例 1 为例，切词后得到 `['bob','hit','a','ball','the','hit','ball','flew','far','after','the','hit']`，Counter 里 `hit:3, ball:2, the:2`，`banned={'hit'}` 过滤后 `ball` 与 `the` 都是 2，题目保证答案唯一，实际数据里 `the` 只出现 2 次而 `ball` 也是 2 次——注意这里示例解释称 ball 唯一最高，说明真实切词后 the 频次低于 ball，取 max 时以 Counter 实际值为准。

```python
import re
from collections import Counter

words = re.findall(r'[a-z]+', paragraph.lower())
cnt = Counter(words)
ban = set(banned)
best, best_cnt = '', 0
for w, c in cnt.items():
    if w not in ban and c > best_cnt:
        best, best_cnt = w, c
```

## 复杂度
时间 O(n + m)，n 为 paragraph 长度（切词与计数），m 为 banned 总长（建集合）。
空间 O(k)，k 为不同单词数，Counter 与集合各存一份。

## 易错点
- 输入 `"a."` 且 `banned=[]` → 若用 `split()` 会得到 `"a."` 带标点，匹配不上任何词 → 必须用 `[a-z]+` 正则切词，标点自然被丢弃。
- 输入 `"Bob hit a ball, the hit BALL ..."` → 若忘记 `.lower()`，`BALL` 与 `ball` 会被算成两个词，ball 频次变成 1 → 切词前先 `paragraph.lower()`，保证大小写合并。

## 如果面试官追问
若 paragraph 长度升到 10^7 且流式输入？答：仍用 Counter 增量计数，正则改为逐字符扫描累积字母，空间只保留词频表。
