## 一句话思路
新建等长数组，按下标 `i` 逐个调用 `fn(arr[i], i)` 填值，一次遍历即可。

## 怎么做
1. 先 `res = [0] * len(arr)` 预分配，避免边遍历边 append 带来的扩容。
2. 用 `for i in range(len(arr))` 遍历下标，而不是 `for x in arr`，因为 `fn` 需要第二个参数 `i`。
3. 每轮写 `res[i] = fn(arr[i], i)`，把元素值和下标一起传进去。
4. 遍历结束直接 `return res`。

以示例 2 为例：`arr = [1,2,3]`，`fn = plusI`。当 `i = 1` 时，关键中间值是 `fn(arr[1], 1) = fn(2, 1) = 3`，于是 `res[1] = 3`；三轮下来 `res` 依次被填成 `[1, 3, 5]`。

```python
def map(self, fn, arr):
    res = [0] * len(arr)
    for i in range(len(arr)):
        res[i] = fn(arr[i], i)
    return res
```

注意 `fn` 是外部传进来的可调用对象，直接 `fn(...)` 调用即可，不要写成 `fn.call(...)` 或 `fn(arr[i])` 漏掉下标——示例 2 的 `plusI` 一旦只收到 `n`，`i` 就是 `None`，会直接抛错。

## 复杂度
时间 O(n)：`n = len(arr)`，每个下标调用一次 `fn`。
空间 O(n)：额外开了结果数组 `res`，长度与 `arr` 相同。

## 易错点
- 输入 `arr = []`（提示允许长度 0）→ 若写成 `res = [0] * len(arr)` 后忘记循环边界，或误用 `arr[0]` 取首元素，会 `IndexError` → 正确做法是循环条件严格用 `range(len(arr))`，空数组时循环体一次不执行，直接返回 `[]`。
- 输入示例 2 这类依赖下标的 `fn` → 若写成 `for x in arr: res.append(fn(x))`，`plusI` 拿不到 `i`，输出会错成 `[1,2,3]` 而非 `[1,3,5]` → 必须用下标遍历并传 `fn(arr[i], i)` 两个参数。

## 如果面试官追问
追问：不允许预分配、要求原地改写 `arr` 并返回它，怎么做？
答：仍用 `for i in range(len(arr))`，写 `arr[i] = fn(arr[i], i)`，空间降到 O(1)，但会破坏入参，需先跟面试官确认调用方不再使用原数组。
