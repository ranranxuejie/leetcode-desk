## 一句话思路
分别用「对数取小数部分」求前 5 位、用模 10^5 求后 5 位，同时统计因子 2/5 的个数得到 C。

## 怎么做
1. 遍历 `[left, right]`，对每个 `x` 反复除以 2 和 5，累计 `c2`、`c5`，`C = min(c2, c5)`。
2. 把每个 `x` 去掉全部因子 2 和 5 后，用 `log10` 累加得到 `log_sum`，用 `% 100000` 累乘得到 `suf`。
3. 补回多余的因子：若 `c2 > c5`，`suf` 乘 `2**(c2-c5)` 再取模；反之乘 `5` 的幂。
4. 位数 `d = floor(log_sum) + 1`；`d <= 10` 直接输出 `suf`，否则前 5 位由 `10**(log_sum - floor(log_sum) + 4)` 取整得到。

以 `left=2, right=11` 为例：去掉 2/5 后各数变为 `1,3,1,1,7,1,9,1,11`，`c2=8, c5=2`，`C=2`；`log_sum ≈ 5.601`，`d=6`，`suf=399168`，输出 `399168e2`。

```python
import math
c2 = c5 = 0
log_sum = 0.0
suf = 1
for x in range(left, right + 1):
    while x % 2 == 0:
        x //= 2; c2 += 1
    while x % 5 == 0:
        x //= 5; c5 += 1
    log_sum += math.log10(x)
    suf = suf * x % 100000
C = min(c2, c5)
suf = suf * pow(2, c2 - C, 100000) * pow(5, c5 - C, 100000) % 100000
d = int(log_sum) + 1
pre = int(10 ** (log_sum - math.floor(log_sum) + 4))
```

## 复杂度
时间：O((right-left+1) log right)，每个数除因子 2/5 的循环次数是 log 级。
空间：O(1)，只开了 c2、c5、log_sum、suf 几个标量。

## 易错点
- `left=1, right=4` 时 `d=2 <= 10`，若仍套 `pre...suf` 格式会输出 `24...24e0`；正确做法是先判 `d <= 10` 直接返回 `str(suf) + "e" + str(C)`。
- `left=371, right=375` 中 375 含 3 个因子 5、只有 1 个因子 2，`c5 > c2`；若只补 2 的幂不补 5 的幂，`suf` 会少乘 `5**2`，末 5 位算错，必须两边都补。

## 如果面试官追问
若 `right` 放大到 10^9 怎么办？答：不能逐个数遍历，需按 2/5 的幂次分段统计，前 5 位改用 Stirling 或分段 log 求和。
