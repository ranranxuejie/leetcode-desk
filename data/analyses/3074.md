## 一句话思路
把苹果总数算出来，从容量最大的箱子开始累加，加到总容量 ≥ 苹果总数时的箱子数就是答案。

## 怎么做
1. 求 `total = sum(apple)`，这是唯一需要关心的量，包裹怎么切分无所谓。
2. 把 `capacity` 降序排序，大箱子优先用，才能用最少的箱子凑够容量。
3. 从大到小累加 `s`，一旦 `s >= total` 就返回已用箱子数。

以示例 1 为例：`total = 1+3+2 = 6`，`capacity` 降序为 `[5,4,3,2,1]`。累加过程 `s = 5`（不够 6），`s = 5+4 = 9 >= 6`，用了 2 个箱子，返回 2。

```python
total = sum(apple)
capacity.sort(reverse=True)
s = 0
for i, c in enumerate(capacity, 1):
    s += c
    if s >= total:
        return i
```

示例 2 验证：`total = 15`，降序 `[7,4,2,2]`，累加 `7,11,13,15`，第 4 个才够，返回 4，与官方一致。

## 复杂度
时间：排序 `capacity` 是 O(m log m)，遍历 O(m)，`sum(apple)` 是 O(n)。
空间：排序原地进行，额外只开了 `total`、`s`、`i` 几个变量，O(1)。

## 易错点
- 误以为要按包裹整体装箱 → 对 `apple = [5,5,5]`、`capacity = [7,4,2,2]` 会认为 7 装不下 5 而跳过，实际 7 能装 5，答案仍是 4 但推理错；正确做法是只看 `sum(apple) = 15` 与容量和比较，包裹边界不存在。
- 用升序排序或从容量小的开始累加 → 示例 1 会先加 `1,2,3` 得 `s = 6` 用 3 个箱子，错成 3；正确做法是 `sort(reverse=True)`，先吃 5 和 4。

## 如果面试官追问
问：如果要求输出具体选了哪些箱子、每个箱子装多少苹果？
答：选中的箱子按容量降序，依次从包裹里顺序取苹果填满即可，用双指针扫 `apple` 和选中箱子。
