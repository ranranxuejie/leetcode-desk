## 一句话思路
用 `CASE WHEN` 对每行做三边不等式判断，三边两两之和都大于第三边才输出 `Yes`。

## 怎么做
1. 三边能成三角形的充要条件是任意两边之和大于第三边，即 `x+y>z and x+z>y and y+z>x`。
2. 用 `CASE WHEN` 把这个布尔条件映射成字符串 `'Yes'` / `'No'`，别名取 `triangle`。
3. 原样保留 `x, y, z` 三列，不做任何过滤或聚合。

拿官方第一行 `(13, 15, 30)` 走一遍：`13+15=28 > 30` 不成立，条件整体为假，输出 `No`。第二行 `(10, 20, 15)`：`10+20=30>15`、`10+15=25>20`、`20+15=35>10` 三条全真，输出 `Yes`。

```python
# 关键判断逻辑（伪 SQL 转写，便于核对条件顺序）
def triangle_judgement(x, y, z):
    ok = (x + y > z) and (x + z > y) and (y + z > x)
    return "Yes" if ok else "No"
```

对应的 SQL 主体：

```sql
SELECT x, y, z,
       CASE WHEN x + y > z AND x + z > y AND y + z > x
            THEN 'Yes' ELSE 'No' END AS triangle
FROM Triangle;
```

注意 `AND` 三个条件缺一不可：只写 `x+y>z` 会把 `(10, 20, 15)` 判对，但会把 `(1, 2, 3)` 这种退化情形漏判成 `Yes`（`1+2=3` 不大于 3，实际应为 `No`）。

## 复杂度
时间：O(n)，n 为 Triangle 行数，每行做 3 次加法比较。
空间：O(1)，只多一个字符串列，无额外表。

## 易错点
- 输入含退化三角形如 `(1, 2, 3)`（两边之和恰等于第三边）→ 若把条件写成 `>=` 会错判成 `Yes` → 必须用严格大于 `>`。
- 输入含 `(0, 0, 0)` 或负数长度 → 若只写 `x+y>z` 单条会误判 → 三条不等式全写，`0+0>0` 为假自然输出 `No`，无需额外判非正。

## 如果面试官追问
问：如果要求只输出能成三角形的行怎么办？
答：把 `CASE` 换成 `WHERE x+y>z AND x+z>y AND y+z>x`，直接过滤，不再需要 `triangle` 列。
