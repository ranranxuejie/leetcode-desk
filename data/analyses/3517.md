## 一句话思路
统计每个字母出现次数，左半段按 a→z 各取 `cnt//2` 个拼出最小前缀，中间放那个奇数字符，再镜像。

## 怎么做
1. 用长度 26 的 `cnt` 统计 `s` 中每个字母出现次数。
2. 从左到右扫 a→z，把 `chr(97+i) * (cnt[i] // 2)` 依次追加到 `left`，这样前缀字典序最小。
3. 找出 `cnt[i] % 2 == 1` 的那个字母（回文串保证至多一个），记为 `mid`。
4. 返回 `left + mid + left[::-1]`。

以 `s = "babab"` 为例：`cnt` 中 a=2、b=3。扫到 a 时 `cnt[0]//2 = 1`，`left = "a"`；扫到 b 时 `cnt[1]//2 = 1`，`left = "ab"`；`mid = "b"`（b 的计数为奇数）。结果 `"ab" + "b" + "ba" = "abbba"`，与官方输出一致。

```python
cnt = [0] * 26
for ch in s:
    cnt[ord(ch) - 97] += 1

left = []
mid = ""
for i in range(26):
    c = chr(97 + i)
    left.append(c * (cnt[i] // 2))
    if cnt[i] % 2 == 1:
        mid = c

left = "".join(left)
return left + mid + left[::-1]
```

关键点：`left` 必须按字母升序拼接，因为回文串的字典序由前半段唯一决定——前半段越小，整体越小；后半段是前半段的镜像，无法独立优化。

## 复杂度
时间 O(n + 26)：遍历 `s` 统计是 O(n)，扫 26 个字母是常数。
空间 O(n)：`left` 和最终结果字符串各占 O(n)，`cnt` 是固定 26。

## 易错点
- 输入 `s = "aabb"`（无奇数字符）→ 若把 `mid` 初始化为某个字母会多出一个字符 → `mid` 应初始化为空串 `""`，只在 `cnt[i] % 2 == 1` 时赋值。
- 输入 `s = "z"` → 若先拼 `left` 再找 `mid` 时漏掉单字符情况，`left` 为空、`mid` 为 `"z"`，结果 `"" + "z" + "" = "z"` 正确；但若把 `mid` 写成 `left` 的最后一个字符就会错 → 必须独立扫描 `cnt` 找奇数项，不能从 `left` 反推。

## 如果面试官追问
若要求返回所有不同的最小回文排列？答：当存在多个奇数字符时（本题保证至多一个），需对中间字符做全排列去重，用 `itertools.permutations` 加 `set` 处理。
