## 一句话思路
用 `head` 记录当前剩余序列首元素、`step` 记录相邻元素间隔，每轮按方向决定是否移动 `head`，直到 `n == 1`。

## 怎么做
1. 初始化 `head = 1`（首元素）、`step = 1`（间隔）、`n` 为当前剩余个数、`left = True`（本轮从左删）。
2. 每轮删完，剩余个数变为 `n // 2`，间隔翻倍 `step *= 2`。
3. 关键：只有当「从左删」或「剩余个数为奇数」时，首元素才会被删掉，此时 `head += step`；否则 `head` 不动。
4. 交替方向 `left = not left`，直到 `n == 1` 返回 `head`。

以 `n = 9` 为例：
- 第 1 轮 `left=True`，`head=1` 被删 → `head=1+1=2`，`n=4`，`step=2`。
- 第 2 轮 `left=False` 且 `n=4` 为偶数，首元素 `2` 保留 → `head` 仍为 `2`，`n=2`，`step=4`。
- 第 3 轮 `left=True`，`head=2` 被删 → `head=2+4=6`，`n=1`，返回 `6`。

```python
head, step, left = 1, 1, True
while n > 1:
    if left or n % 2 == 1:
        head += step
    n //= 2
    step *= 2
    left = not left
return head
```

核心就一行判断：`left or n % 2 == 1`。从右删时若剩余个数是奇数，最右元素被删后，最左元素也会被删（因为奇数个元素从右往左隔一个删一个，首尾都被覆盖），所以 `head` 要右移。

## 复杂度
时间：O(log n)，每轮 `n` 减半，最多约 30 轮（n ≤ 10^9）。
空间：O(1)，只开了 `head`、`step`、`left` 三个变量。

## 易错点
- `n = 2` 时：第 1 轮从左删，`head=1` 被删变 `2`，`n=1` 返回 `2`。若漏掉 `left` 判断直接每轮都 `head += step`，会错成 `3` 越界。正确做法是严格按 `left or n % 2 == 1` 决定是否移动。
- `n = 4` 时：第 2 轮从右删且 `n=4` 为偶数，`head=2` 应保留。若误以为「从右删首元素一定不动」而忽略奇数判断，在 `n=6`（第 2 轮 `n=3` 为奇数）会错：正确 `head` 从 `2` 移到 `4`，漏判则停在 `2`，最终答案错。

## 如果面试官追问
问：若要求返回整个消除过程每轮剩下的序列？答：每轮按 `head` 和 `step` 生成等差数列 `range(head, head + n*step, step)` 即可，时间升到 O(n)。
