## 一句话思路
用位掩码表示 target 中已拼出的字母集合，记忆化搜索每次选一张贴纸能新覆盖哪些位，取最小步数。

## 怎么做
1. 预处理每张贴纸对 target 的字母计数（只保留 target 中出现的字母），去掉空贴纸。
2. 状态 `mask` 的每一位表示 target 对应位置是否已拼出，从 `mask=0` 搜到 `mask=(1<<m)-1`。
3. 每步枚举贴纸，用贴纸字母数贪心匹配 target 中尚未覆盖的位置，得到新 mask。
4. 记忆化 `dfs(mask)` 返回最少贴纸数，无法到达返回 `inf`。

以 `stickers=["with","example","science"], target="thehat"` 为例，`m=6`。初始 `mask=0`，选 `"with"` 时按顺序匹配 t,h,e,h,a,t：w 无用，i 无用，t 覆盖位置 0，h 覆盖位置 1，得 `new_mask=0b000011=3`。继续搜索最终 `mask=0b111111=63` 时返回 0，回溯得 3。

```python
from functools import lru_cache
from collections import Counter

m = len(target)
cnts = []
for s in stickers:
    c = Counter(s)
    v = [c[ch] for ch in target]
    if any(v):
        cnts.append(v)

@lru_cache(None)
def dfs(mask):
    if mask == (1 << m) - 1:
        return 0
    best = float('inf')
    for v in cnts:
        avail = v[:]
        new_mask = mask
        for i in range(m):
            if not (mask >> i) & 1 and avail[i] > 0:
                avail[i] -= 1
                new_mask |= 1 << i
        if new_mask != mask:
            best = min(best, 1 + dfs(new_mask))
    return best

ans = dfs(0)
return -1 if ans == float('inf') else ans
```

## 复杂度
时间：O(2^m · n · m)，m=target 长度≤15，n=贴纸数≤50。
空间：O(2^m) 记忆化表，每项存一个整数。

## 易错点
- 贴纸含 target 没有的字母（如 `"with"` 的 w、i）→ 若直接按贴纸全字母匹配会误判可覆盖 → 预处理时只保留 target 中出现的字母计数，w/i 计为 0。
- 同一贴纸内重复字母（如 `"thehat"` 的 t 出现两次）→ 若每轮只减一次 avail 会漏覆盖 → 循环内对每个未覆盖位置都检查 `avail[i] > 0` 并递减，保证一张贴纸的多个同字母都能用上。

## 如果面试官追问
问：target 长度放宽到 30 怎么办？
答：2^30 状态爆炸，改用 BFS + 启发式或按字母计数做 IDA*，剪枝靠剩余字母下界。
