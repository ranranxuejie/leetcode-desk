## 一句话思路
用递归下降：`parse(i)` 从下标 `i` 解析一个表达式并返回 `(值, 新下标)`，作用域靠每层 `let` 复制一份字典向下传。

## 怎么做
1. 遇到 `(` 就跳过它读关键字，`add`/`mult` 各递归两次，`let` 循环「读变量名 → 递归求值 → 写进新字典」直到只剩最后一个表达式。
2. 遇到数字或变量名就顺着读到空格或 `)` 为止，变量名去字典里查。
3. 关键中间值：示例 1 里外层 `let` 建 `{'x': 2}`，进入 `(mult x (let x 3 y 4 (add x y)))` 后内层 `let` 复制成 `{'x': 3, 'y': 4}`，`(add x y)` 得 `7`，`mult` 得 `2 * 7 = 14`。

```python
def parse(i, env):
    if expression[i] != '(':
        j = i
        while j < len(expression) and expression[j] not in ' )':
            j += 1
        tok = expression[i:j]
        return (env[tok] if tok[0].isalpha() else int(tok)), j
    j = i + 1
    while expression[j] != ' ':
        j += 1
    op = expression[i+1:j]
    if op == 'let':
        env = dict(env)
        while True:
            j += 1
            if expression[j] == '(' or expression[j].isdigit() or expression[j] == '-':
                return parse(j, env)
            k = j
            while expression[k] != ' ':
                k += 1
            name = expression[j:k]
            val, j = parse(k + 1, env)
            env[name] = val
    a, j = parse(j + 1, env)
    b, j = parse(j + 1, env)
    return (a + b if op == 'add' else a * b), j + 1
```

## 复杂度
时间：`O(n)`，每个字符被扫描常数次，`dict(env)` 复制是 `O(作用域变量数)`，总量级仍线性。
空间：`O(n)`，递归深度等于括号嵌套层数，每层 `let` 复制一份字典。

## 易错点
- 输入 `(let x 3 x 2 x)`：若先扫完所有赋值再求最后表达式，会得 `3`；正确是按顺序处理，`x` 先绑 `3` 再被 `2` 覆盖，答案 `2`。
- 输入 `(let x 1 y 2 x (add x y) (add x y))`：若 `let` 里共用同一个字典而不复制，内层赋值会污染外层；正确是每进一层 `let` 就 `dict(env)` 拷贝，答案 `5`。

## 如果面试官追问
问：表达式长度到 10^5 怎么办？答：递归会爆栈，改成显式栈迭代，或先把 token 切好再自底向上求值。
