## 一句话思路
枚举 0 到 n，用 `x & (x-1) == 0` 判单比特（0 特判），n ≤ 1000 直接暴力即可。

## 怎么做
1. 从 0 遍历到 n，逐个判断是否为单比特数。
2. 单比特数的二进制形如 `111...1`，满足 `x & (x+1) == 0`；注意 0 也符合，需单独计入。
3. 以 n = 4 为例：x=0 时 `0 & 1 == 0` 成立计入；x=1 时 `1 & 2 == 0` 成立；x=2 时 `2 & 3 == 2 ≠ 0` 排除；x=3 时 `3 & 4 == 0` 成立；x=4 时 `4 & 5 == 4 ≠ 0` 排除，累计 3。
4. 返回计数。

```python
cnt = 0
for x in range(n + 1):
    if x == 0 or (x & (x + 1)) == 0:
        cnt += 1
return cnt
```

## 复杂度
时间：O(n)，每个数一次位运算，n 为输入值。
空间：O(1)，只开计数变量。

## 易错点
- 输入 n = 0 → 若用 `x & (x-1) == 0` 判单比特，0 会被误判为「非单比特」而漏计 → 正确做法是对 0 单独判断，或统一用 `x & (x+1) == 0` 并显式把 0 计入。
- 输入 n = 1 → 若只统计 `1, 3, 7...` 这类全 1 数而忘了 0，会输出 1 而非 2 → 正确做法是循环从 0 开始，把 0 当作合法的单比特数。

## 如果面试官追问
若 n 放大到 10^18 怎么办？答：单比特数只有 0 和 2^k - 1，直接枚举 k 直到 2^k - 1 > n，O(log n) 计数。
