## 一句话思路
用哈希表统计每个字母出现次数，再分别取元音集合和辅音集合中的最大频数相加。

## 怎么做
1. 用 `Counter(s)` 一次性统计所有字母频数。
2. 遍历 `cnt` 的键，按是否属于 `set("aeiou")` 分流，分别更新 `vmax` 和 `cmax`。
3. 两个最大值初始为 0，天然处理「没有元音/辅音」的情况。
4. 返回 `vmax + cmax`。

以 `s = "successes"` 为例，`cnt = {'s':4,'e':2,'c':2,'u':1}`。遍历到 `'s'` 时不在元音集合，`cmax = max(0, 4) = 4`；遍历到 `'e'` 时在元音集合，`vmax = max(0, 2) = 2`。最终 `4 + 2 = 6`。

```python
from collections import Counter

cnt = Counter(s)
vowels = set("aeiou")
vmax = cmax = 0
for ch, f in cnt.items():
    if ch in vowels:
        vmax = max(vmax, f)
    else:
        cmax = max(cmax, f)
return vmax + cmax
```

关键点：只遍历 `cnt` 的键（最多 26 个），而不是遍历 `s` 的每个字符，避免重复比较同一字母。

## 复杂度
时间：O(n)，`Counter(s)` 扫一遍字符串贡献 n，之后最多 26 次比较是常数。
空间：O(1)，哈希表最多存 26 个键值对，元音集合固定 5 个元素。

## 易错点
- 输入 `s = "aeiaeia"` → 若把 `cmax` 初始化为 `-1` 或忘记处理无辅音，会返回 `3 + (-1) = 2` 或报错 → 正确做法是两个最大值都初始为 0，因为题目规定缺失时频率视为 0。
- 输入 `s = "aaaa"` → 若用 `s.count(ch)` 对每个字符单独计数，会变成 O(n²) 且对重复字母重复计算 → 正确做法是用 `Counter` 一次统计，或遍历时用数组 `freq[26]` 累加。

## 如果面试官追问
问：如果要求返回具体的元音字母和辅音字母而不只是和？
答：在更新 `vmax`/`cmax` 时同步记录对应的 `ch`，平局时任取一个即可，逻辑不变。
