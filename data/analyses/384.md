## 一句话思路
用 Fisher-Yates 洗牌：从后往前，把 `nums[i]` 与 `[0, i]` 中随机一个位置交换，每种排列概率都是 1/n!。

## 怎么做
1. 构造时把入参存成 `self.origin`，`shuffle` 每次从它复制一份 `a` 出来，保证 `reset` 随时能还原。
2. 从 `i = len(a)-1` 递减到 1，取 `j = random.randint(0, i)`。
3. 交换 `a[i], a[j]`，走完循环返回 `a`。

以 `nums = [1,2,3]` 为例，`i=2` 时 `j` 可能是 0/1/2；若 `j=0`，交换后 `a = [3,2,1]`，此时位置 2 已定死为 3，后续只在 `[0,1]` 里继续换，不会再动它——这正是等概率的关键。

```python
import random

def shuffle(self):
    a = self.origin[:]
    for i in range(len(a) - 1, 0, -1):
        j = random.randint(0, i)
        a[i], a[j] = a[j], a[i]
    return a

def reset(self):
    return self.origin[:]
```

`reset` 返回副本而不是 `self.origin` 本身，否则调用方改返回值会污染初始状态。

## 复杂度
时间：`shuffle` O(n)，`reset` O(n) 复制；n 是数组长度。
空间：额外 O(n)，就是 `a = self.origin[:]` 这份副本。

## 易错点
- 写成 `j = random.randint(0, n-1)`（全范围随机）→ `[1,2,3]` 的 6 种排列概率不再相等，比如 `[1,2,3]` 会偏大 → 必须限制 `j` 在 `[0, i]`，让已固定的尾部不再参与。
- `reset` 直接 `return self.origin` → 调用方拿到引用后原地改（如 `res[0] = 99`），下次 `shuffle` 的基准就错了 → 返回 `self.origin[:]` 副本。

## 如果面试官追问
问：不允许额外 O(n) 空间怎么办？答：在 `self.origin` 的副本上原地洗，`reset` 时用 `self.origin[:]` 覆盖回去，空间仍是 O(n) 但只开一份。
