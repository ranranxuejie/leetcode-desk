## 一句话思路
把问题转成「保留哪些字符」：两串的公共子序列保留，其余字符全删，用 DP 求删除代价最小的对齐方式。

## 怎么做
1. 定义 `dp[i][j]` 为 `s1[:i]` 与 `s2[:j]` 变成相等的最小删除和，边界 `dp[i][0] = sum(ord(c) for c in s1[:i])`，`dp[0][j]` 同理。
2. 转移：若 `s1[i-1] == s2[j-1]`，这对字符可都保留，`dp[i][j] = dp[i-1][j-1]`。
3. 否则至少删一个：`dp[i][j] = min(dp[i-1][j] + ord(s1[i-1]), dp[i][j-1] + ord(s2[j-1]))`。
4. 答案取 `dp[len(s1)][len(s2)]`。

以 `s1="sea", s2="eat"` 为例，`dp[1][1]`（`'s'` vs `'e'`）不等，取 `min(0+115, 0+101)=101`；到 `dp[3][3]` 时 `'a'` 与 `'t'` 不等，最终得 231，即删 `'s'`(115) 与 `'t'`(116)。

```python
m, n = len(s1), len(s2)
dp = [[0] * (n + 1) for _ in range(m + 1)]
for i in range(1, m + 1):
    dp[i][0] = dp[i-1][0] + ord(s1[i-1])
for j in range(1, n + 1):
    dp[0][j] = dp[0][j-1] + ord(s2[j-1])
for i in range(1, m + 1):
    for j in range(1, n + 1):
        if s1[i-1] == s2[j-1]:
            dp[i][j] = dp[i-1][j-1]
        else:
            dp[i][j] = min(dp[i-1][j] + ord(s1[i-1]),
                           dp[i][j-1] + ord(s2[j-1]))
return dp[m][n]
```

## 复杂度
时间 O(m·n)，两层循环各遍历 s1、s2 长度。
空间 O(m·n)，`dp` 表大小 `(m+1)×(n+1)`，可滚动到 O(n)。

## 易错点
- 相等时误写成 `dp[i-1][j-1] + ord(...)`：`s1="a", s2="a"` 会得 97 而非 0；相等字符无需删除，直接继承 `dp[i-1][j-1]`。
- 边界只初始化 `dp[0][0]=0`：`s1="ab", s2=""` 时 `dp[1][0]` 若为 0 会漏算 `'a'` 的 97；必须用前缀和填满第 0 行与第 0 列。

## 如果面试官追问
要求输出具体删除方案怎么办？答：从 `dp[m][n]` 回溯，不等时看哪边转移值小就往哪走，记录被删字符即可。
