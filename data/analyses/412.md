## 一句话思路
从 1 到 n 逐个判断能否被 3、5 整除，按 15→3→5 的优先级拼字符串，否则转成 `str(i)`。

## 怎么做
1. 建空列表 `ans`，循环 `i` 从 1 到 `n`（含 `n`）。
2. 先判 `i % 15 == 0`，命中就 `append("FizzBuzz")` 并 `continue`。
3. 再判 `i % 3 == 0` 追加 `"Fizz"`，`i % 5 == 0` 追加 `"Buzz"`，都不中追加 `str(i)`。
4. 返回 `ans`。

拿 `n = 15` 走关键一步：`i = 15` 时 `15 % 15 == 0` 成立，直接得 `"FizzBuzz"`，不会先被 `15 % 3 == 0` 截成 `"Fizz"`——顺序就是全部正确性所在。`i = 14` 时三个条件全假，落到 `str(14) == "14"`。

```python
ans = []
for i in range(1, n + 1):
    if i % 15 == 0:
        ans.append("FizzBuzz")
    elif i % 3 == 0:
        ans.append("Fizz")
    elif i % 5 == 0:
        ans.append("Buzz")
    else:
        ans.append(str(i))
return ans
```

另一种写法是拼串：`s = ("Fizz" if i % 3 == 0 else "") + ("Buzz" if i % 5 == 0 else "")`，`s` 为空时用 `str(i)`。它省掉 15 这个魔数，但每次循环多一次字符串拼接，`n = 10^4` 下无所谓。

## 复杂度
时间 O(n)：循环 n 次，每次取模和 append 都是 O(1)，`str(i)` 的位数最多 5 位可视为常数。
空间 O(n)：`ans` 存 n 个字符串，除此之外只有循环变量 `i`。

## 易错点
- `n = 15` 时若先判 `i % 3 == 0` 再判 `i % 15 == 0`，`i = 15` 会错成 `"Fizz"`，输出末尾缺 `"FizzBuzz"`；必须让 15 的分支排在最前，或用拼串写法天然合并。
- `n = 1` 时若循环写成 `range(1, n)`，会返回空列表 `[]`，而正确答案是 `["1"]`；`range` 右端必须写 `n + 1`，且 `i = 1` 三个条件全假，要确保 `else` 分支真的执行到 `str(1)`。

## 如果面试官追问
问：n 放大到 10^9 且只要求第 k 个元素怎么办？
答：不建列表，直接对 k 做同样的 15/3/5 判断返回单个字符串，O(1) 时间 O(1) 空间。
