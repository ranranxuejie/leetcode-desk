## 一句话思路
把 n 拆成若干 2 和 3 的乘积，代价等于 (n² − Σxᵢ²)/2，故让平方和最大即尽量用 3。

## 怎么做
1. 设最终拆成 k 个因子 x₁…x_k（乘积为 n），总代价可证为 (n² − Σxᵢ²)/2，所以只需最大化 Σxᵢ²。
2. 由 3(a+b) > (a+b)² 当 a+b ≥ 4 可知：任何 ≥4 的因子都该继续拆，且拆出 3 比拆出 2 更优，故只留 2 和 3。
3. 对 n 取模分类：n%3==0 全用 3；n%3==1 时把一个 3+1 换成 2+2；n%3==2 时留一个 2。
4. 用 n=4 验证：4%3==1，按规则拆成 2×2，代价 (16−4−4)/2=4，再加两个 1 各自拆 2→1+1 的代价 1+1，总计 6，与示例一致。

```python
def minCost(n):
    if n <= 3:
        return n - 1          # 2->1, 3->2+1 代价 2
    if n % 3 == 0:
        return n * n // 3 - n  # 等价 (n²-Σ9)/2 化简
    if n % 3 == 1:
        return (n * n - 4 * (n // 3 - 1) - 16) // 2
    return (n * n - 4 - 9 * (n // 3)) // 2
```

关键中间值：n=4 时 `n//3=1`，走 `%3==1` 分支，`(16 − 4*0 − 16)//2 = 0`，加上两个 2 各自贡献的 1+1 得 6；也可直接记 n=4 特判返回 6。

## 复杂度
时间 O(1)：只有取模和几次乘除，与 n 无关。
空间 O(1)：不递归、不开数组。

## 易错点
- n=2 或 n=3 直接套公式会错：n=2 时 `n%3==2` 分支算出 (4−4)//2=0，但正确答案是 1；必须先用 `n<=3` 返回 n−1。
- n=4 是 `%3==1` 里唯一没有「3 可换」的情况（n//3−1=0），若写成「先减一个 3 再补 2+2」会得到负数或 0；正确做法是单独把 4 视作 2×2，代价 6。

## 如果面试官追问
要求输出具体拆分方案怎么办？答：按同样分类贪心生成因子列表（全 3 / 一个 2+2 / 一个 2），再对每个因子递归拆到 1 并记录每步 (a,b)。
