## 一句话思路
用入度数组找唯一根，再从根 DFS 数访问节点数，等于 n 且无重复访问才是二叉树。

## 怎么做
1. 遍历 `leftChild` 和 `rightChild`，对每个非 -1 的子节点 `indegree[child] += 1`。
2. 统计 `indegree` 中值为 0 的节点数，必须恰好为 1，否则返回 `False`（0 个是环，多个是森林）。
3. 从该根做 DFS/BFS，用 `visited` 记录，若某节点被访问两次立即返回 `False`（说明有节点有两个父亲）。
4. 最后检查 `visited` 数量是否等于 `n`。

以示例 2 为例：`leftChild = [1,-1,3,-1]`，`rightChild = [2,3,-1,-1]`。子节点为 1、2、3、3，`indegree = [0,1,1,2]`。节点 3 入度为 2，说明它有两个父节点（节点 0 的右孩子和节点 2 的左孩子），从根 0 出发 DFS 时第二次访问 3 会触发重复检测，返回 `False`。

```python
indegree = [0] * n
for i in range(n):
    for c in (leftChild[i], rightChild[i]):
        if c != -1:
            indegree[c] += 1
roots = [i for i in range(n) if indegree[i] == 0]
if len(roots) != 1:
    return False
visited = set()
stack = [roots[0]]
while stack:
    u = stack.pop()
    if u in visited:
        return False
    visited.add(u)
    for c in (leftChild[u], rightChild[u]):
        if c != -1:
            stack.append(c)
return len(visited) == n
```

## 复杂度
时间：O(n)，每个节点和每条边各访问常数次。
空间：O(n)，`indegree` 数组和 `visited` 集合各占 n。

## 易错点
- 示例 3 输入 `leftChild = [1,0]`，`rightChild = [-1,-1]`：两个节点入度都是 1，`roots` 为空，若只检查 `len(roots) != 1` 会正确返回 `False`；但若先 DFS 再判根，会因找不到起点而误判。必须先确认根唯一再遍历。
- 示例 2 中节点 3 入度为 2：若只数 `visited` 数量而不检测重复访问，DFS 会把 3 访问两次但 `visited` 仍是 3 个节点，`len(visited) == n` 成立，误返回 `True`。必须在入栈/出栈时用 `visited` 拦截重复。

## 如果面试官追问
若要求返回所有非法原因（多根/环/多父），怎么改？答：分别统计根数、DFS 中重复访问数、遍历后未访问数，三者任一非零即报对应错误。
