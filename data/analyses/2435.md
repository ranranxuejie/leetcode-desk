## 一句话思路
按路径和模 k 的余数做状态压缩 DP，因为只需知道余数而非真实和。

## 怎么做
1. 定义 `dp[i][j][r]` 为到达 `(i,j)` 时路径和模 k 余 `r` 的路径数，起点初始化为 `dp[0][0][grid[0][0] % k] = 1`。
2. 每个格子从上方和左方转移：`dp[i][j][(r + grid[i][j]) % k] += dp[i-1][j][r] + dp[i][j-1][r]`。
3. 用滚动数组把第一维压掉，只保留上一行 `prev` 和当前行 `cur`，每行长度 `n*k`。
4. 返回 `dp[m-1][n-1][0]`。

以示例 1 的 `grid[0][1]=2` 为例：起点余数 `5%3=2`，到 `(0,1)` 时新余数 `(2+2)%3=1`，`dp[0][1][1]=1`；到 `(1,0)` 时 `(2+3)%3=2`，`dp[1][0][2]=1`。两条路径余数不同，后续才可能分别归零。

```python
MOD = 10**9 + 7
m, n = len(grid), len(grid[0])
prev = [[0] * k for _ in range(n)]
prev[0][grid[0][0] % k] = 1
for i in range(m):
    cur = [[0] * k for _ in range(n)]
    for j in range(n):
        if i == 0 and j == 0:
            cur[0][grid[0][0] % k] = 1
            continue
        v = grid[i][j] % k
        for r in range(k):
            cnt = 0
            if i > 0: cnt += prev[j][r]
            if j > 0: cnt += cur[j-1][r]
            cur[j][(r + v) % k] = (cur[j][(r + v) % k] + cnt) % MOD
    prev = cur
return prev[n-1][0]
```

## 复杂度
时间：O(m·n·k)，每个格子枚举 k 个余数。
空间：O(n·k)，滚动数组只存一行。

## 易错点
- `grid` 含 0 且 `k=5`（示例 2）：若把 `dp` 初始余数写成 `grid[0][0]` 而非 `grid[0][0] % k`，余数会越界或状态错位；正确做法是起点就取模，`0%5=0` 直接落在 `dp[0][0][0]`。
- `k=1`（示例 3）：所有余数恒为 0，若循环里用 `if r + v < k` 之类的分支跳过取模，会漏加路径；正确做法是统一 `(r + v) % k`，`k=1` 时结果就是总路径数 10。

## 如果面试官追问
问：若要求输出具体路径而非计数？答：DP 只存计数无法回溯，需在转移时记录前驱余数或改用 DFS 枚举，规模大时不可行。
