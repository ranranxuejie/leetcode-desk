## 一句话思路
用集合记录走过的坐标，每走一步就查一次，重复即相交。

## 怎么做
1. 初始化 `x = y = 0`，`seen = {(0, 0)}`，原点必须先入集合。
2. 遍历 `path` 的每个字符，按 `N/S/E/W` 更新 `x` 或 `y`。
3. 每步更新后立刻判断 `(x, y) in seen`，命中就返回 `True`。
4. 没命中则把 `(x, y)` 加入 `seen`，循环结束返回 `False`。

以 `path = "NESWW"` 为例：走完 `N`、`E`、`S` 后坐标是 `(1, 0)`，`seen` 为 `{(0,0),(0,1),(1,1),(1,0)}`；第 4 步 `W` 回到 `(0, 0)`，此时 `(0, 0) in seen` 为 `True`，直接返回。

```python
x = y = 0
seen = {(0, 0)}
for c in path:
    if c == 'N':
        y += 1
    elif c == 'S':
        y -= 1
    elif c == 'E':
        x += 1
    else:
        x -= 1
    if (x, y) in seen:
        return True
    seen.add((x, y))
return False
```

关键点：判断必须在 `add` 之前，否则自己这一步刚加的坐标会立刻命中自己。

## 复杂度
时间 O(n)：`path` 长度 n，每步集合查找均摊 O(1)。
空间 O(n)：`seen` 最多存 n+1 个坐标元组。

## 易错点
- 忘记把原点 `(0, 0)` 放进 `seen` → 对 `path = "NS"` 会错成 `False`，实际走回原点应返回 `True`。正确做法是初始化时就写 `seen = {(0, 0)}`。
- 先 `seen.add((x, y))` 再判断 → 每一步都会命中自己刚加入的坐标，`path = "NES"` 也返回 `True`。正确做法是先查 `in`，未命中再 `add`。

## 如果面试官追问
问：如果要求返回第一个相交点的坐标怎么办？
答：把 `return True` 改成 `return (x, y)`，其余逻辑不变。
