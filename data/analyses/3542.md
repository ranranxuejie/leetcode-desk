## 一句话思路
用单调栈维护「尚未被清零的严格递增段」，每遇到一个比栈顶小的值就弹出，弹出次数即操作数。

## 怎么做
1. 维护一个严格递增栈 `st`，初始为空；答案 `ans = 0`。
2. 遍历 `nums` 中每个 `x`：若 `x == 0`，说明 0 天然是分隔符，直接清空 `st`（0 左边和右边的非零段无法被同一次操作覆盖）。
3. 否则先 `while st and st[-1] > x: st.pop()`，每弹一次 `ans += 1`；再判断 `if not st or st[-1] < x: st.append(x)`（相等则不压，因为同一个值可被一次操作一起清零）。
4. 遍历结束后，`st` 里剩下的每个值各需一次操作，`ans += len(st)`。

以 `nums = [3,1,2,1]` 为例：读 3 压栈 `st=[3]`；读 1 弹出 3（`ans=1`），压 1 得 `st=[1]`；读 2 压栈 `st=[1,2]`；读 1 弹出 2（`ans=2`），栈顶 1 与 1 相等不压，`st=[1]`；收尾 `ans += 1` 得 3。对应操作：先清 1（覆盖下标 1、3），再清 2，再清 3。

```python
st, ans = [], 0
for x in nums:
    if x == 0:
        st.clear()
        continue
    while st and st[-1] > x:
        st.pop()
        ans += 1
    if not st or st[-1] < x:
        st.append(x)
ans += len(st)
```

## 复杂度
时间 O(n)：每个元素最多入栈一次、出栈一次，`while` 总弹出次数 ≤ n。
空间 O(n)：`st` 最坏情况存下整个严格递增数组，如 `[1,2,3,...,n]`。

## 易错点
- 输入 `[0,2]` → 若把 0 当成普通值压栈，会得到 `st=[0,2]`、答案 2；正确做法是遇到 0 直接 `st.clear()`，0 是天然分界，答案 1。
- 输入 `[1,1,1]` → 若写成 `st[-1] <= x` 就压栈，会压成 `[1,1,1]`、答案 3；正确做法是只在 `st[-1] < x` 时压栈，相等值共享一次操作，答案 1。

## 如果面试官追问
要求输出具体操作方案（每个子数组的区间）怎么办？
答：栈里同时存 `(值, 起始下标)`，弹出时记录该值覆盖的区间右端，收尾时把剩余区间一并输出。
