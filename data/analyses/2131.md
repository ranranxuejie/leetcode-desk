## 一句话思路
用哈希表统计每种单词出现次数，对称对 `ab`/`ba` 取 `min` 成对拼接，自反词 `aa` 取偶数个，最后至多补一个落单自反词居中。

## 怎么做
1. 遍历 `words`，用 `Counter` 统计每个两字母串的频次。
2. 对每个 `w = ab` 且 `a != b`，只处理 `w < w[::-1]` 的一侧，取 `cnt[w]` 与 `cnt[w[::-1]]` 的较小值 `k`，累加 `4*k`，避免重复计数。
3. 对自反词 `aa`，累加 `4*(cnt["aa"]//2)`，并记下是否存在 `cnt["aa"] % 2 == 1`。
4. 若存在落单自反词，答案再加 2（它单独放正中间）。

以示例 2 `["ab","ty","yt","lc","cl","ab"]` 为例：`cnt = {ab:2, ty:1, yt:1, lc:1, cl:1}`。处理 `ab` 时 `ab > ba` 跳过；处理 `ty` 时 `ty < yt`，`k = min(1,1) = 1`，累加 4；`lc` 同理累加 4，得 8。无自反词，最终 8。

```python
from collections import Counter

cnt = Counter(words)
ans = 0
center = False
for w, c in cnt.items():
    if w[0] == w[1]:
        ans += 4 * (c // 2)
        if c % 2 == 1:
            center = True
    elif w < w[::-1]:
        ans += 4 * min(c, cnt[w[::-1]])
if center:
    ans += 2
```

## 复杂度
时间 O(n)，n 为 `words` 长度，遍历一次建表加一次遍历键（键至多 26×26 种）。
空间 O(1)，哈希表最多存 676 个键，与 n 无关。

## 易错点
- 输入 `["ab","ba","ab","ba"]` → 若对 `ab` 和 `ba` 各算一次 `min`，会得 16，实际只有 8 → 必须只从 `w < w[::-1]` 一侧计数，另一侧跳过。
- 输入 `["cc","cc","cc"]` → 若把三个 `cc` 都算进去得 6，实际 `"cccc"` 长 4 → 自反词只能取 `2*(c//2)` 个，余数最多贡献一个居中 +2。

## 如果面试官追问
问：若要求返回具体回文串而非长度？答：把每对 `ab`+`ba` 按 `ab` 左、`ba` 右的顺序存入左右列表，最后 `"".join(left) + 中间词 + "".join(reversed(right))`。
