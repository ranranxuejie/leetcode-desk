## 一句话思路
把 k 步拆成向右 r 步、向左 l 步，解 r+l=k 且 r-l=endPos-startPos，答案就是组合数 C(k, r)。

## 怎么做
1. 令 `d = abs(endPos - startPos)`，若 `d > k` 或 `(k - d) % 2 == 1`，直接返回 0。
2. 否则 `r = (k + d) // 2`，即必须向右走的步数，剩下 `k - r` 步向左。
3. 答案就是在这 k 个位置里挑 r 个放「右」，即 `C(k, r) mod 10**9+7`。
4. 用递推 `C(k, r) = C(k-1, r-1) * k // r` 逐项乘，边乘边取模（除法前先乘逆元或用整数精确除法）。

以示例 1 为例：`startPos=1, endPos=2, k=3`，`d=1`，`(3-1)%2=0` 合法，`r=(3+1)//2=2`，答案 `C(3,2)=3`，与输出一致。

```python
MOD = 10**9 + 7
d = abs(endPos - startPos)
if d > k or (k - d) % 2:
    return 0
r = (k + d) // 2
# 计算 C(k, r) mod MOD
num = den = 1
for i in range(1, r + 1):
    num = num * (k - r + i) % MOD
    den = den * i % MOD
return num * pow(den, MOD - 2, MOD) % MOD
```

## 复杂度
时间：O(r)，r ≤ k/2 ≤ 500，来自组合数循环。
空间：O(1)，只用了 num、den 几个标量。

## 易错点
- `startPos=2, endPos=5, k=10` → 若忘记判 `(k-d)%2`，会算出 r=7.5 或错误取整得非零 → 正确做法是先判奇偶，`d=3`、`k-d=7` 为奇数直接返回 0。
- `startPos=1, endPos=2, k=3` → 若用 `C(k, (k-d)//2)` 取左步数，结果一样但若 d 为负（endPos<startPos）会算错 → 正确做法是先 `d = abs(...)` 再取 `r=(k+d)//2`。

## 如果面试官追问
若 k 扩大到 10^9 怎么办？答：用 Lucas 定理或预处理阶乘+逆元，把 O(k) 降到 O(log MOD)。
