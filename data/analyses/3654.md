## 一句话思路
用前缀和模 k 的哈希表做 DP：`dp[i]` 表示前 i 个元素删完后的最小剩余和，同余前缀可互相转移。

## 怎么做
1. 令 `pre[i]` 为前 i 项和，`dp[i]` 为前 i 项的最小剩余和，初值 `dp[i] = dp[i-1] + nums[i-1]`（不删）。
2. 若存在 `j < i` 使 `(pre[i] - pre[j]) % k == 0`，则 `nums[j..i-1]` 可整段删除，`dp[i] = min(dp[i], dp[j])`。
3. 用哈希表 `best[r]` 记录同余 `r` 下最小的 `dp[j]`，遍历时先查 `best[pre[i] % k]` 更新 `dp[i]`，再把 `dp[i]` 写回该余数。
4. 以 `nums=[3,1,4,1,5], k=3` 为例：`pre=[0,3,4,8,9,14]`，模 3 为 `[0,0,1,2,0,2]`；到 i=4 时 `pre[4]%3=0`，`best[0]=dp[0]=0`，故 `dp[4]=0`，即删掉 `[3,1,4,1]` 后剩余 0，最终 `dp[5]=5`。

```python
pre = 0
dp = [0] * (len(nums) + 1)
best = {0: 0}          # 余数 -> 最小 dp[j]
for i, x in enumerate(nums, 1):
    pre += x
    dp[i] = dp[i-1] + x
    r = pre % k
    if r in best:
        dp[i] = min(dp[i], best[r])
    if r not in best or dp[i] < best[r]:
        best[r] = dp[i]
return dp[-1]
```

## 复杂度
时间 O(n)：一次遍历，哈希表均摊 O(1)。
空间 O(min(n, k))：`dp` 数组 O(n)，`best` 至多 k 个余数。

## 易错点
- `nums=[1,1,1], k=2` → 若只允许删一次会得 2，正确是删 `[1,1]` 后剩 `[1]` 和为 1；必须允许链式删除，所以 `dp[j]` 要用已删除后的最优值而非原始前缀和。
- `nums=[3], k=3` → 若把 `best` 初值写成空字典，i=1 时查不到余数 0，会漏掉整段删除得 3；正确是预置 `best={0:0}`，让 `pre[i]%k==0` 能匹配空前缀。

## 如果面试官追问
若要求输出具体删除方案而非最小和？答：在 `best` 里同时存下标 j，回溯 `dp` 的转移链即可还原每次删除的区间。
