## 一句话思路
把和大的数组往小改、和小的往大改，每个元素能贡献的「可调幅度」是有限集合，按幅度从大到小贪心凑差值。

## 怎么做
1. 算 `s1 = sum(nums1)`、`s2 = sum(nums2)`，若 `s1 == s2` 直接返回 0；令 `diff = abs(s1 - s2)`，把「和大的」记为 `big`、「和小的」记为 `small`。
2. 对 `big` 中每个 `x`，最多能减 `x - 1`；对 `small` 中每个 `x`，最多能加 `6 - x`。把这些幅度全丢进一个列表 `gains`。
3. 把 `gains` 降序排序，从大到小累加，累加到 `>= diff` 时用的个数就是答案；加完还不够则返回 -1。
4. 关键中间值：示例 1 中 `s1 = 21`、`s2 = 10`，`diff = 11`；`big = nums1` 的幅度是 `[0,1,2,3,4,5]`，`small = nums2` 的幅度是 `[5,5,4,4,4,4]`，合并降序后前三个是 `5,5,5`，和 `15 >= 11`，故答案 3。

```python
s1, s2 = sum(nums1), sum(nums2)
if s1 == s2:
    return 0
big, small = (nums1, nums2) if s1 > s2 else (nums2, nums1)
diff = abs(s1 - s2)
gains = [x - 1 for x in big] + [6 - x for x in small]
gains.sort(reverse=True)
ops = 0
for g in gains:
    if diff <= 0:
        break
    diff -= g
    ops += 1
return ops if diff <= 0 else -1
```

## 复杂度
时间：O((n + m) log(n + m))，排序贡献 log，n、m 分别是两数组长度。
空间：O(n + m)，`gains` 列表额外开了两数组长度之和。

## 易错点
- 输入 `nums1 = [1,1,1,1,1,1,1]`、`nums2 = [6]`：`diff = 1`，但 `big` 的幅度全是 0、`small` 的幅度是 0，`gains` 全零，循环跑完 `diff` 仍为 1，必须返回 -1；若写成「循环结束直接返回 ops」会错答 8。
- 输入 `nums1 = [6,6]`、`nums2 = [1]`：`diff = 11`，`gains = [5,5,5]`，恰好凑满；若贪心时只取 `big` 的幅度（`[5,5]` 只到 10）就判 -1，会漏掉把 `small` 的 1 抬到 6 这一手，正确做法是两边幅度合并排序。

## 如果面试官追问
要求输出具体操作方案怎么办？答：排序时把幅度和来源下标一起存，按同样顺序取前 k 个，逐个把元素改成 `1` 或 `6`，最后一次只改到刚好补齐 `diff`。
