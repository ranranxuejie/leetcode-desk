## 一句话思路
对值域二分答案 `mid`，用「≤mid 的元素个数」与 `k` 比较来收缩区间，因为该计数随 `mid` 单调不减。

## 怎么做
1. 取 `lo = matrix[0][0]`、`hi = matrix[n-1][n-1]`，答案必在此闭区间内。
2. 每轮取 `mid = (lo + hi) // 2`，从右上角 `(0, n-1)` 出发统计 `≤ mid` 的个数。
3. 若 `count < k` 则 `lo = mid + 1`，否则 `hi = mid`；循环至 `lo == hi` 返回 `lo`。
4. 计数时若 `matrix[i][j] <= mid`，则第 `j` 列上方整列（`i+1` 个）都 ≤ mid，累加后右移；否则上移一行。

以示例 1 为例，`lo=1, hi=15`，首轮 `mid=8`：从 `(0,2)=9>8` 上移无效（已在第 0 行），实际走 `(0,2)` 比较后左移，最终 `count=2`（只有 1、5），`2 < 8` 故 `lo=9`。继续二分，`mid=12` 时 `count=6`，`lo=13`；`mid=14` 时 `count=8`，`hi=14`；`mid=13` 时 `count=8`，`hi=13`，返回 13。

```python
n = len(matrix)
lo, hi = matrix[0][0], matrix[n-1][n-1]
while lo < hi:
    mid = (lo + hi) // 2
    count, j = 0, n - 1
    for i in range(n):
        while j >= 0 and matrix[i][j] > mid:
            j -= 1
        count += j + 1
    if count < k:
        lo = mid + 1
    else:
        hi = mid
return lo
```

## 复杂度
时间：二分 `log(hi-lo)` 轮，每轮计数 `O(n)`，共 `O(n log(hi-lo))`，`hi-lo` 可达 2×10^9。
空间：`O(1)`，只用了 `lo/hi/mid/count/j` 几个变量。

## 易错点
- 输入含重复值如示例 1 的两个 13 → 若用「找第一个 count == k 的 mid」会漏掉重复，返回偏小值 → 必须用 `count >= k` 时 `hi = mid` 的写法，让 `lo` 收敛到真实第 k 小。
- `k = n^2`（如 `[[-5]]`, k=1）→ 若 `hi` 取 `matrix[n-1][n-1]` 之外的哨兵或 `lo` 初值取 0，会返回不存在的值 → `lo/hi` 必须严格取矩阵角元素，保证答案在闭区间内。
