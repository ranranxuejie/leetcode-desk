## 一句话思路
把 nums1 的值映射成它在 nums2 中的下标，问题变成统计这个新数组的递增三元组，用树状数组按中间元素累加。

## 怎么做
1. 先建 `pos2[v] = v 在 nums2 的下标`，再把 nums1 逐位替换成 `a[i] = pos2[nums1[i]]`，此时好三元组等价于 `a` 中满足 `i<j<k 且 a[i]<a[j]<a[k]` 的三元组。
2. 对每个位置 `j`，用树状数组统计它左边比 `a[j]` 小的个数 `left[j]`，右边比 `a[j]` 大的个数 `right[j] = (n-1-a[j]) - (j - left[j])`。
3. 以 `j` 为中间元素，贡献是 `left[j] * right[j]`，全部累加即为答案。

以示例 1 为例：`nums1=[2,0,1,3]`，`pos2=[0,2,1,3]`（值 0→0,1→2,2→1,3→3），得 `a=[1,0,2,3]`。取 `j=2`（`a[2]=2`）：左边比 2 小的有 `{1,0}` 共 2 个，右边比 2 大的只有 `3` 共 1 个，贡献 `2*1=2`？注意 `left` 里 `1` 在 `a[0]`，但 `a[0]=1 > a[1]=0`，`(1,0,2)` 不是递增，所以 `left[2]` 实际只数 `a[1]=0` 一个，贡献 `1*1=1`，与答案一致。

```python
n = len(nums1)
pos2 = [0] * n
for i, v in enumerate(nums2):
    pos2[v] = i
a = [pos2[v] for v in nums1]
tree = [0] * (n + 1)
def add(i):
    i += 1
    while i <= n:
        tree[i] += 1
        i += i & -i
def query(i):  # 统计 <= i 的个数
    i += 1; s = 0
    while i > 0:
        s += tree[i]
        i -= i & -i
    return s
ans = 0
for j, v in enumerate(a):
    left = query(v - 1) if v > 0 else 0
    right = (n - 1 - v) - (j - left)
    ans += left * right
    add(v)
```

## 复杂度
时间：O(n log n)，n 次树状数组查询与更新各 O(log n)。
空间：O(n)，`pos2`、`a`、`tree` 三个长度 n 的数组。

## 易错点
- 忘记先做 `pos2` 映射，直接对 `nums1` 原值建树状数组 → 示例 1 中 `a` 应为 `[1,0,2,3]` 却当成 `[2,0,1,3]`，`left/right` 全错，答案算成 0 或 2 → 必须先转成 nums2 下标序列。
- `right` 用 `(n-1-v) - (j-left)` 推导时，把 `j-left` 当成「左边比 v 大的个数」→ 实际 `j-left` 是左边比 v 大的个数（因为左边共 j 个，比 v 小的有 left 个），所以右边比 v 大的 = 总比 v 大的 `(n-1-v)` 减去左边比 v 大的 `(j-left)`，符号写反会得到负数贡献。

## 如果面试官追问
问：n 扩大到 10^6 还能过吗？答：O(n log n) 常数小仍可，但 `tree` 与 `pos2` 各占 10^6 级内存，需换 `array('i')` 或分块；若只要计数不建映射，可改用归并排序求逆序对变体。
