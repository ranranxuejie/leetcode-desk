## 一句话思路
用滑动窗口维护「窗口内各字母计数 ≥ word2 计数」，窗口右端固定时统计所有合法左端点。

## 怎么做
1. 先统计 `need = Counter(word2)`，记 `missing = len(word2)` 表示还差多少个字符没被窗口覆盖。
2. 右指针 `r` 从左到右扫 `word1`，把 `word1[r]` 计入窗口：若该字母在 `need` 里且窗口内该字母数量还没超过需求，则 `missing -= 1`。
3. 当 `missing == 0` 时，窗口 `[l, r]` 合法；此时所有左端点 `0..l` 都合法（缩短窗口仍满足），答案累加 `l + 1`，然后尝试右移 `l` 直到窗口不再合法。
4. 关键中间值：以 `word1 = "bcca", word2 = "abc"` 为例，`need = {a:1,b:1,c:1}`，`missing` 初始为 3；扫到 `r = 3`（字符 `a`）时 `missing` 才降到 0，此时 `l = 0`，累加 `0 + 1 = 1`。

```python
from collections import Counter

need = Counter(word2)
missing = len(word2)
l = ans = 0
for r, ch in enumerate(word1):
    if need[ch] > 0:
        missing -= 1
    need[ch] -= 1
    while missing == 0:
        ans += len(word1) - r          # 右端 r 固定，左端 0..l 全合法
        need[word1[l]] += 1
        if need[word1[l]] > 0:
            missing += 1
        l += 1
```

注意 `need` 在窗口收缩时会被加回去，所以它实际表示「还缺多少」，而不是原始需求。

## 复杂度
时间：`O(n + m)`，`n = len(word1)`、`m = len(word2)`，每个字符进出窗口各一次。
空间：`O(1)`，`need` 最多 26 个键。

## 易错点
1. 输入 `word1 = "abcabc", word2 = "abc"`：若在 `missing == 0` 时只累加 1 而不是 `len(word1) - r`，会漏掉右端固定时更短的合法子串，正确输出应为 10 而非 3。
2. 输入 `word1 = "abcabc", word2 = "aaabc"`：若把 `need[ch] > 0` 的判断写成 `need[ch] >= 0`，`missing` 永远降不到 0，会错判为有解；正确做法是只在窗口内该字母数量未超需求时才减 `missing`，此题应输出 0。

## 如果面试官追问
问：若要求输出所有合法子串的起止下标而非计数？
答：在 `missing == 0` 时枚举 `0..l` 作为左端点输出 `[left, r]`，复杂度退化为 `O(答案规模)`。
