## 一句话思路
把负数取绝对值后，第 k 大和 = 总和 − 第 k 小子集和，用堆按「排序后前缀」生成最小子集和。

## 怎么做
1. 设 `total = sum(nums)`，把 `nums` 中每个元素取绝对值后升序排序，记作 `a`。
2. 第 k 大子集和等于 `total` 减去第 k 小的「绝对值子集和」（含空集 0 为第 1 小）。
3. 用最小堆生成第 2 到第 k 小的子集和：堆里存 `(和, 下标)`，弹出 `(s, i)` 后压入 `(s + a[i+1], i+1)` 和 `(s - a[i] + a[i+1], i+1)`。
4. 弹 `k-1` 次，最后一次弹出的 `s` 就是第 k 小，返回 `total - s`。

以 `nums = [2,4,-2], k = 5` 为例：`total = 4`，`a = [2,2,4]`。堆初始 `(0, -1)`；第 1 次弹出 0，压入 `(2,0)`；第 2 次弹出 2，压入 `(4,1)`、`(2,1)`；第 3 次弹出 2，压入 `(6,2)`、`(4,2)`；第 4 次弹出 2（第 4 小），压入 `(6,2)`、`(4,2)`。第 5 次弹出 2，`total - 2 = 2`，与示例一致。

```python
import heapq
a = sorted(abs(x) for x in nums)
total = sum(nums)
h = [(0, -1)]
cur = 0
for _ in range(k - 1):
    cur, i = heapq.heappop(h)
    if i + 1 < len(a):
        heapq.heappush(h, (cur + a[i + 1], i + 1))
        heapq.heappush(h, (cur - a[i] + a[i + 1], i + 1))
return total - cur
```

## 复杂度
时间：排序 O(n log n)，堆操作 k 次、每次 O(log k)，共 O(n log n + k log k)。
空间：堆最多 O(k) 个元素，排序额外 O(n)。

## 易错点
1. 输入含负数如 `nums = [2,4,-2]` → 直接对原数组建堆会得到错误顺序，因为负数取绝对值后大小关系翻转 → 必须先 `abs` 再排序，最后用 `total` 减回去。
2. `k = 1` 时 → 循环 `range(0)` 不执行，`cur` 仍是初始 0，返回 `total`，这正确；但若把初始堆写成 `(a[0], 0)` 就会漏掉空集，`k=1` 时错成 `total - a[0]` → 初始必须压 `(0, -1)` 表示空集。

## 如果面试官追问
问：k 放大到 10^5 怎么办？答：堆仍只弹 k 次，复杂度 O(n log n + k log k)，k=10^5 也可接受，无需换算法。
