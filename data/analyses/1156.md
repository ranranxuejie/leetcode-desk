## 一句话思路
按字符分组统计每段连续长度，用「段长之和 + 1」与全局该字符总数取 min，一次扫描即可。

## 怎么做
1. 先统计每个字符在 text 中的总出现次数 `total[c]`。
2. 扫描 text，把连续相同字符切成段，记录每段字符 c 和长度 L。
3. 对每段，若左右相邻段也是 c（中间只隔一个别的字符），可合并为 `L + Lleft + Lright`，否则只能 `L`；再 `+1` 表示从别处换一个 c 进来。
4. 结果取 `min(合并长度 + 1, total[c])` 的最大值。

以 `text = "aaabaaa"` 为例：三段分别是 a:3、b:1、a:3。处理第二段 a:3 时，左邻 a:3、右邻 a:3，合并得 9，但 `total['a'] = 6`，故 `min(9+1, 6) = 6`，即答案。

```python
from collections import Counter
total = Counter(text)
ans = 0
i, n = 0, len(text)
while i < n:
    j = i
    while j < n and text[j] == text[i]:
        j += 1
    L = j - i
    merged = L
    if i > 0 and j < n and text[i-1] == text[i] == text[j]:
        # 左右邻段同字符，需再取长度
        pass
    ans = max(ans, min(merged + 1, total[text[i]]))
    i = j
```

上面片段省略了左右邻段长度的获取；实际实现可先存 `segs = [(c, L), ...]`，再遍历 `segs[k]`，检查 `segs[k-1][0] == segs[k+1][0] == c` 时 `merged = L + segs[k-1][1] + segs[k+1][1]`。

## 复杂度
时间 O(n)：一次扫描切段，n 为 text 长度。
空间 O(1)：total 最多 26 个键，segs 至多 n 段但可边扫边算。

## 易错点
- 输入 `"aaabaaa"` → 若只算单段 `L+1` 得 4，漏掉左右合并 → 正确要检查左右邻段同字符，合并后 `min(9+1, 6)=6`。
- 输入 `"aaaaa"` → 若盲目 `L+1` 得 6，超过字符总数 → 正确用 `min(L+1, total[c])` 截到 5。

## 如果面试官追问
问：若允许交换 k 次而非 1 次？答：把 `+1` 换成 `+k`，合并时最多跨 k 个异字符段，仍用 `min(总长+k, total[c])` 截断。
