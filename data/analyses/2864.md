## 一句话思路
数出 `s` 里 `'1'` 的个数 `ones`，末位固定放一个 `'1'`，其余 `ones-1` 个 `'1'` 全堆最前面，中间补零。

## 怎么做
1. 统计 `s.count('1')` 得到 `ones`，`n = len(s)`。
2. 末位必须是 `'1'`，否则结果是偶数，不满足"奇数"。
3. 剩下的 `ones - 1` 个 `'1'` 放在最高位，因为二进制里高位权重最大，把 1 往左挪一定变大。
4. 中间用 `'0'` 填满，长度保持 `n`。

以 `s = "0101"` 为例：`ones = 2`，`n = 4`。末位放 1 个 `'1'`，剩下 `ones - 1 = 1` 个 `'1'` 放最前，中间 `4 - 1 - 1 = 2` 个 `'0'`，拼出 `"1" + "00" + "1" = "1001"`。

```python
ones = s.count('1')
n = len(s)
# 前面 ones-1 个 1，中间补 0，末尾一个 1
return '1' * (ones - 1) + '0' * (n - ones) + '1'
```

关键点：`'0' * (n - ones)` 的个数是 `n - ones`，不是 `n - ones - 1`。因为末尾那个 `'1'` 已经占了一位，而 `ones - 1` 个 `'1'` 占了前面，剩下的零正好是 `n - (ones - 1) - 1 = n - ones`。

## 复杂度
时间：O(n)，`count` 扫一遍，字符串拼接再扫一遍。
空间：O(n)，返回的新字符串本身，无额外辅助结构。

## 易错点
- 输入 `s = "1"`（`ones = 1`）→ 若写成 `'1' * ones + ... + '1'` 会得到 `"11"`，长度变 2 → 正确是 `'1' * (ones - 1)` 得空串，拼出 `"1"`，长度仍为 1。
- 输入 `s = "010"`（`ones = 1`）→ 若把零的个数写成 `n - ones - 1` 会得到 `"0" + "1" = "01"`，长度 2 少了 → 正确零个数是 `n - ones = 2`，输出 `"001"`。

## 如果面试官追问
问：如果要求结果不能有前导零怎么办？
答：那 `ones - 1` 个 `'1'` 必须紧跟首位，即首位放 `'1'`，其余 `ones - 2` 个 `'1'` 放次高位，零全部后移，末尾仍留一个 `'1'`。
