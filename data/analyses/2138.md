## 一句话思路
按步长 k 切片，最后一段不足 k 就用 `ljust(k, fill)` 补齐，一次遍历即可。

## 怎么做
1. 用 `range(0, len(s), k)` 枚举每段起点 `i`，切片 `s[i:i+k]` 得到当前组。
2. 对每段调用 `ljust(k, fill)`：长度已满 k 时原样返回，不足时在右侧补 `fill`。
3. 把结果依次 append 进 `res` 并返回。

以示例 2 为例：`s = "abcdefghij"`，`k = 3`。当 `i = 9` 时切片得到 `s[9:12] = "j"`，长度 1，`"j".ljust(3, 'x')` 返回 `"jxx"`，这正是最后一组；而 `i = 0/3/6` 时切片长度都是 3，`ljust` 不补任何字符。

```python
res = []
for i in range(0, len(s), k):
    res.append(s[i:i + k].ljust(k, fill))
return res
```

关键点：`range` 的步长是 `k` 而不是 1，所以循环次数是 `ceil(len(s)/k)`，最后一组自然落在 `i = (n-1)//k*k` 这个起点上，不需要单独判断「是否整除」。

## 复杂度
时间 O(n)：切片和 `ljust` 合计处理 n 个原字符加至多 k-1 个填充字符。
空间 O(n)：`res` 里存了补齐后的全部字符，输出本身就要 n 个字符。

## 易错点
- 输入 `s = "abc"`、`k = 5`、`fill = 'x'` → 若写成 `s[i:i+k]` 直接 append 会得到 `["abc"]`，长度只有 3 → 必须走 `ljust(5, 'x')` 得到 `"abcxx"`，否则最后一组长度不合法。
- 输入 `s = "abcdefghi"`、`k = 3` → 若用 `while len(s) % k != 0: s += fill` 先补原串再切片，虽然结果对，但把 `s` 改掉了，若后面还要用原串就出错 → 正确做法是只对切片结果补，不动 `s`。

## 如果面试官追问
问：如果要求返回时把填充字符去掉、只保留原始分组信息怎么办？
答：切片后不调 `ljust`，直接 append `s[i:i+k]`，最后一组允许长度小于 k。
