## 一句话思路
两个数组的 id 都严格递增，用双指针归并，id 相同就把 val 相加，不同就取小的那个。

## 怎么做
1. 指针 `i`、`j` 分别指向 `nums1`、`nums2` 开头，结果列表 `res` 为空。
2. 当 `i < len(nums1)` 且 `j < len(nums2)` 时，比较 `nums1[i][0]` 与 `nums2[j][0]`。
3. 相等则 `res.append([id, nums1[i][1] + nums2[j][1]])` 并双指针后移；否则取 id 较小的一对直接 append，只移动该侧指针。
4. 循环结束后把剩余一侧整体拼到 `res` 尾部。

以示例 1 为例，`i=0,j=0` 时 `nums1[0][0]=1` 与 `nums2[0][0]=1` 相等，写入 `[1, 2+4]=[1,6]`，两指针同时后移；下一步 `nums1[1][0]=2 < nums2[1][0]=3`，直接写入 `[2,3]`，只移动 `i`。

```python
i = j = 0
res = []
while i < len(nums1) and j < len(nums2):
    a, b = nums1[i], nums2[j]
    if a[0] == b[0]:
        res.append([a[0], a[1] + b[1]])
        i += 1
        j += 1
    elif a[0] < b[0]:
        res.append(a)
        i += 1
    else:
        res.append(b)
        j += 1
res.extend(nums1[i:])
res.extend(nums2[j:])
```

## 复杂度
时间：O(m + n)，两个指针各自最多走完自己的数组一遍。
空间：O(m + n) 存结果，除结果外只用了 `i`、`j` 两个变量。

## 易错点
- 某一侧先走完时，若忘记 `res.extend(nums1[i:])` / `res.extend(nums2[j:])`，示例 2 会漏掉 `[5,5]`（`nums1` 尾部剩余），输出变成 4 个元素。
- 相等分支里只 `i += 1` 忘了 `j += 1`，示例 1 的 id=1 会被重复写入两次，结果出现两个 `[1,6]` 且长度变 5。

## 如果面试官追问
若 id 不再有序、数组长度到 10^5 怎么办？答：改用哈希表累加 `val`，最后对 key 排序，时间 O((m+n) log(m+n))。
