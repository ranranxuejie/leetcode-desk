## 一句话思路
用 `pd.DataFrame(student_data, columns=["student_id", "age"])` 一次性构造，列名按位置对齐。

## 怎么做
1. 直接调用 `pd.DataFrame`，把 `student_data` 作为数据、`columns` 作为列名传入。
2. 列名列表必须按 `["student_id", "age"]` 的顺序写，因为 DataFrame 是按位置把列名贴到每行元素上的。
3. 不要额外传 `index`，默认 RangeIndex 0..3 正好对应原列表顺序。

以官方示例为例，`student_data = [[1,15],[2,11],[3,11],[4,20]]`，构造后 `df.shape == (4, 2)`，`df.iloc[1].tolist() == [2, 11]`，即第 2 行仍是 `[2, 11]`，顺序未被改动。

```python
import pandas as pd

def create_a_dataframe(student_data):
    return pd.DataFrame(student_data, columns=["student_id", "age"])
```

关键中间值：`pd.DataFrame([[1,15],[2,11]], columns=["student_id","age"]).dtypes` 得到两列都是 `int64`，因为原始元素是 Python `int`，pandas 推断为整数列，不会变成 `object`。

## 复杂度
时间：O(n)，n 为 `student_data` 的行数，逐行拷贝元素。
空间：O(n)，新建 DataFrame 存 n 行 × 2 列，无额外辅助结构。

## 易错点
- 列名写成 `["id", "age"]` 或漏写 `columns` → 输出列名变成 `0, 1`，与期望的 `student_id` 不匹配 → 必须显式传 `columns=["student_id", "age"]`。
- 传 `student_data` 时误加 `index=` 或先 `sorted()` → 行顺序被打乱，示例中 `[2, 11]` 可能跑到第一行 → 保持原列表原样传入，不排序、不重排索引。

## 如果面试官追问
问：若 `student_data` 是空列表 `[]` 怎么办？
答：仍传 `columns`，得到 0 行 2 列的空 DataFrame，列名正确，不会报错。
