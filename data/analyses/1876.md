## 一句话思路
固定长度 3 的窗口逐位右移，只需比较窗口内三个字符两两是否相等，相等就计数。

## 怎么做
1. 若 `len(s) < 3` 直接返回 0，否则从下标 0 滑到 `len(s) - 3`。
2. 每个窗口取 `a, b, c = s[i], s[i+1], s[i+2]`，判断 `a != b and b != c and a != c`。
3. 成立则 `ans += 1`，窗口整体右移一格，重复到末尾。

以 `s = "aababcabc"` 为例：`i = 0` 时窗口是 `"aab"`，`a == b` 不成立；`i = 3` 时窗口 `"abc"`，三个字符互不相等，`ans` 从 2 变 3；`i = 6` 时窗口又是 `"abc"`，`ans` 变 4，与示例输出一致。

```python
n = len(s)
ans = 0
for i in range(n - 2):
    a, b, c = s[i], s[i + 1], s[i + 2]
    if a != b and b != c and a != c:
        ans += 1
return ans
```

注意 `range(n - 2)` 的上界：`n = 7` 时 `i` 取 0..4，正好覆盖 5 个窗口，不会越界。

## 复杂度
时间 O(n)：`i` 走 n-2 步，每步三次字符比较是常数。
空间 O(1)：只开了 `ans`、`i`、`a/b/c` 几个标量，没有额外数组。

## 易错点
- 输入 `s = "aaa"` → 若只写 `a != b and b != c` 会漏判 `a == c`，把 `"aaa"` 错记成好子串，答案变成 1 → 必须三个不等式全写，`a != c` 不能省。
- 输入 `s = "ab"`（长度不足 3）→ 若循环写成 `range(n - 2)` 会得到 `range(0)` 不报错但若误写成 `range(n)` 再取 `s[i+2]` 就 IndexError → 先判 `n < 3` 返回 0，或严格用 `range(n - 2)`。

## 如果面试官追问
问：若长度改成 k 而非固定 3 呢？
答：窗口内用集合或计数数组判重，滑出时减计数，O(n) 时间、O(k) 空间。
