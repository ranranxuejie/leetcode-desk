## 一句话思路
遍历 `hours`，用 `h >= target` 计数，因为「至少」是闭区间，等号必须算进去。

## 怎么做
1. 初始化计数器 `cnt = 0`，准备扫一遍 `hours`。
2. 对每个 `h` 判断 `h >= target`，成立就 `cnt += 1`。
3. 遍历结束返回 `cnt`。

拿示例 1 走一遍：`hours = [0,1,2,3,4]`，`target = 2`。逐个比较：`0 >= 2` 假、`1 >= 2` 假、`2 >= 2` 真（`cnt` 从 0 变 1）、`3 >= 2` 真（`cnt = 2`）、`4 >= 2` 真（`cnt = 3`），返回 3。关键中间值是 `h = 2` 那一步：它让 `cnt` 第一次加 1，说明边界值本身被计入。

```python
cnt = 0
for h in hours:
    if h >= target:
        cnt += 1
return cnt
```

等价的一行写法是 `sum(h >= target for h in hours)`，Python 里 `True` 当 1 加，结果一样。示例 2 里 `hours = [5,1,4,2,2]`、`target = 6`，最大值 5 都小于 6，`cnt` 全程不动，返回 0——这也说明不能拿 `max(hours)` 和 `target` 比完就下结论，必须逐个计数。

## 复杂度
时间：O(n)，n 是 `hours` 长度，每个元素比较一次。
空间：O(1)，只开了 `cnt` 一个整数。

## 易错点
- 写成 `h > target` → 示例 1 中 `h = 2` 被漏掉，返回 2 而不是 3 → 必须用 `>=`，题面是「至少」。
- 用 `hours.count(target)` 或只统计等于 `target` 的人 → 示例 1 返回 1，示例 2 返回 0（碰巧对）→ 要统计的是区间 `[target, +∞)`，不是单点。

## 如果面试官追问
问：如果 `hours` 有序，能不能更快？
答：可以二分找第一个 `>= target` 的下标 `i`，答案是 `n - i`，时间降到 O(log n)。
