## 一句话思路
从右下角逆推，`dp[i][j]` 表示进入 `(i,j)` 前至少需要的血量，取右/下两条路中需求较小者。

## 怎么做
1. 定义 `dp[i][j] = max(1, min(dp[i+1][j], dp[i][j+1]) - dungeon[i][j])`，即先看后继最少要多少，再扣掉本格收益。
2. 边界：越界格视为无穷大（`2**31 - 1`），保证 `min` 只取真实邻居；右下角 `dp[m-1][n-1] = max(1, 1 - dungeon[m-1][n-1])`。
3. 从 `(m-1,n-1)` 倒序双重循环填表，最终返回 `dp[0][0]`。

以示例 1 的右下角为例：`dungeon[2][2] = -5`，`dp[2][2] = max(1, 1-(-5)) = 6`；再算 `dp[2][1]`：右邻 `dp[2][2]=6`，下邻越界为 `2**31-1`，`min=6`，`dungeon[2][1]=30`，`dp[2][1] = max(1, 6-30) = 1`——30 点回血把需求压到最低 1。继续逆推得 `dp[0][0]=7`。

```python
m, n = len(dungeon), len(dungeon[0])
INF = 2**31 - 1
dp = [[INF] * (n + 1) for _ in range(m + 1)]
for i in range(m - 1, -1, -1):
    for j in range(n - 1, -1, -1):
        if i == m - 1 and j == n - 1:
            need = 1
        else:
            need = min(dp[i + 1][j], dp[i][j + 1])
        dp[i][j] = max(1, need - dungeon[i][j])
return dp[0][0]
```

## 复杂度
时间：O(m·n)，每个格子算一次。
空间：O(m·n)，开了 `(m+1)×(n+1)` 的 `dp` 表（可压成一维）。

## 易错点
- 正推（从左上角记录「当前剩余血量」）→ 同一格可能对应多条路径的不同剩余值，无法只留一个状态，会错成贪心；正确做法是逆推「进入该格前的最低需求」，因为需求只由后继决定。
- 忘记 `max(1, ...)` → 遇到 `dungeon[2][1]=30` 这类大回血格会算出 `need-30 = -24`，把负数当需求传下去，最终 `dp[0][0]` 偏小；正确做法是每格都夹到至少 1，因为血量必须为正。

## 如果面试官追问
问：能否把空间降到 O(n)？
答：可以，`dp` 只依赖下一行和本行右侧，用一维数组从右往左滚动更新，`dp[j] = max(1, min(dp[j], dp[j+1]) - dungeon[i][j])`。
