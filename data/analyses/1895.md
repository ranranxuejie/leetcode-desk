## 一句话思路
从最大可能边长往下枚举 k，用二维前缀和 O(1) 取任意子方阵的行、列、对角线和，全相等即返回。

## 怎么做
1. 预处理二维前缀和 `pre`，`pre[i+1][j+1] = pre[i][j+1] + pre[i+1][j] - pre[i][j] + grid[i][j]`。
2. 边长从 `k = min(m, n)` 递减到 2，对每个左上角 `(r, c)` 枚举子方阵。
3. 用前缀和算出第一行和 `target`，再逐行、逐列、两对角线比对，全部等于 `target` 就返回 `k`。
4. 循环结束返回 1（1×1 恒为幻方）。

以示例 1 为例，`k=3`、左上角 `(0,1)` 时子方阵是 `[[1,4,5],[5,1,6],[5,4,3]]`：第一行和 `target = 10`，但第二行 `5+1+6 = 12 ≠ 10`，直接剪掉；换到 `(1,0)` 时 `target = 5+1+6 = 12`，三行、三列、两对角线都是 12，返回 3。

```python
m, n = len(grid), len(grid[0])
pre = [[0] * (n + 1) for _ in range(m + 1)]
for i in range(m):
    for j in range(n):
        pre[i+1][j+1] = pre[i][j+1] + pre[i+1][j] - pre[i][j] + grid[i][j]

def rect(r1, c1, r2, c2):  # 闭区间
    return pre[r2+1][c2+1] - pre[r1][c2+1] - pre[r2+1][c1] + pre[r1][c1]

for k in range(min(m, n), 1, -1):
    for r in range(m - k + 1):
        for c in range(n - k + 1):
            target = rect(r, c, r, c + k - 1)
            ok = all(rect(r+i, c, r+i, c+k-1) == target for i in range(k))
            ok = ok and all(rect(r, c+j, r+k-1, c+j) == target for j in range(k))
            ok = ok and rect(r, c, r+k-1, c+k-1) == target
            ok = ok and rect(r, c+k-1, r+k-1, c) == target
            if ok:
                return k
return 1
```

## 复杂度
时间：O(min(m,n) · m · n · k)，k 层枚举乘每层 O(k) 校验，最坏约 O(m·n·min(m,n)²)。
空间：O(m·n)，只开了 `pre` 这张 (m+1)×(n+1) 表。

## 易错点
- 边长从 1 往上枚举 → 示例 1 会先命中某个 2×2 就提前返回 2 → 必须从 `min(m, n)` 递减，第一个通过的就是最大。
- 只校验行和列、漏掉两条对角线 → 示例 2 的 2×2 子阵 `[[3,3],[3,3]]` 行列都相等但主对角线 `3+3=6`、副对角线 `3+3=6` 恰好也过；换成 `[[1,2],[2,1]]` 这类就会误判 → 四条线（行、列、主对角、副对角）都要和 `target` 比。

## 如果面试官追问
问：m、n 放大到 500 怎么办？
答：枚举边长仍是瓶颈，可先按行前缀和预筛候选左上角，或对每个 k 用哈希存行和向量加速比对，但最坏仍是立方级。
