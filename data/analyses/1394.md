## 一句话思路
用哈希表统计每个数的频次，再遍历键值对取「键等于值」的最大键。

## 怎么做
1. 用 `Counter(arr)` 一次遍历得到频次表 `cnt`。
2. 遍历 `cnt.items()`，筛出 `num == freq` 的候选。
3. 用 `max(..., default=-1)` 直接取最大候选，无候选时返回 -1。

以示例 2 `arr = [1,2,2,3,3,3]` 为例，`cnt = {1:1, 2:2, 3:3}`，三个键都满足 `num == freq`，`max` 取到 3。

```python
from collections import Counter

cnt = Counter(arr)
ans = -1
for num, freq in cnt.items():
    if num == freq and num > ans:
        ans = num
return ans
```

也可以写成一行：`return max((k for k, v in Counter(arr).items() if k == v), default=-1)`。生成器表达式比先建列表省内存，`default=-1` 正好覆盖示例 3、4 的无解情况。

关键点在于「频次」是统计出来的，不是数出来的位置；`arr` 里重复元素只贡献计数，不贡献新键。示例 5 `[7]*7` 的 `cnt` 是 `{7:7}`，直接命中。

## 复杂度
时间 O(n)：`Counter` 扫一遍 arr，再扫一遍至多 n 个不同键。
空间 O(n)：哈希表最多存 n 个不同数值的计数。

## 易错点
- 输入 `[2,2,2,3,3]` → 若只判断「值出现过 value 次」而不比较 `num == freq`，会把 3 误判为幸运数（3 出现 2 次）→ 必须严格 `num == freq`，示例 3 正确答案是 -1。
- 输入 `[1,2,2,3,3,3]` → 若找到第一个幸运数就 `return`，会返回 1 而非 3 → 必须遍历完所有键再取最大，或用 `max(..., default=-1)`。

## 如果面试官追问
追问：arr 长度放大到 10**7 且值域也到 10**7，怎么办？
答：仍用哈希表 O(n)，但可先排序再线性扫描连续段，空间降到 O(1)（不计排序栈），代价是 O(n log n)。
