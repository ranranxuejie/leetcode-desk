## 一句话思路
用 DFS 洪水填充每个岛屿并累加 `total`，边填边判 `total % k == 0`，避免额外存岛屿列表。

## 怎么做
1. 遍历 `grid` 每个格子，遇到 `grid[i][j] > 0` 就启动一次 DFS，同时把该格置 0 标记已访问。
2. DFS 返回该连通块的值之和，用 `total` 接收。
3. 判断 `total % k == 0`，成立则 `ans += 1`。

以示例 1 为例，从 `grid[0][1]=2` 出发，连通块是 `{2,5,1}`（`(0,1),(1,1),(2,2)`），`total=8`，`8 % 5 = 3` 不计；从 `grid[0][2]=1` 出发的块 `{1,1,4,7,2}` 得 `total=15`，`15 % 5 == 0` 计入。注意 `(0,2)` 与 `(0,1)` 不连通（中间是 0），别把两块合并。

```python
def dfs(i, j):
    if i < 0 or i >= m or j < 0 or j >= n or grid[i][j] == 0:
        return 0
    v = grid[i][j]
    grid[i][j] = 0          # 就地标记，省 visited
    return v + dfs(i+1, j) + dfs(i-1, j) + dfs(i, j+1) + dfs(i, j-1)

ans = 0
for i in range(m):
    for j in range(n):
        if grid[i][j] > 0:
            if dfs(i, j) % k == 0:
                ans += 1
```

## 复杂度
时间 O(m·n)：每格最多被 DFS 访问一次。
空间 O(m·n)：递归栈最坏深度等于单个岛屿格数，未额外开 visited。

## 易错点
- 输入是 1000×1000 的单块大陆（`m*n = 10^5` 但形状细长）→ Python 递归深度超过默认 1000 触发 `RecursionError` → 改用显式栈的迭代 DFS，或 `sys.setrecursionlimit(10**6)`。
- 用 `grid[i][j] == 1` 判陆地 → 示例 1 里值为 2、5、7 的格子被漏掉，岛屿被切碎、`total` 偏小 → 必须用 `> 0` 判陆地，因为题面说陆地是正整数而非 1。

## 如果面试官追问
问：`m*n` 放大到 10^7 怎么办？答：DFS 递归栈会爆，改用并查集按行滚动合并，只保留上一行父指针，空间降到 O(n)。
