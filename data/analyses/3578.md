## 一句话思路
用 `dp[i]` 表示前 i 个元素的分割数，滑动窗口 + 单调队列维护合法左端点区间，前缀和 O(1) 转移。

## 怎么做
1. 设 `dp[0]=1`，`dp[i]` 为前 i 个元素的分割方式数，`pre[i]=pre[i-1]+dp[i-1]` 为前缀和。
2. 用两个单调队列维护窗口 `[left, i-1]` 的最大值和最小值，`left` 是最小的合法起点。
3. 对每个 `i`，右端固定为 `nums[i-1]`，把所有使 `max-min > k` 的起点排除，得到合法起点区间 `[left, i-1]`。
4. 转移：`dp[i] = pre[i] - pre[left]`（模 `10**9+7`）。

以 `nums=[9,4,1,3,7], k=4` 为例，处理到 `i=5`（`nums[4]=7`）时，窗口内最大值 9、最小值 1，差 8 > 4，`left` 右移到 1，合法起点为 `[1,4]`，`dp[5] = pre[5]-pre[1] = 6-1 = 5`，再加 `dp[4]=4` 得 6。

```python
from collections import deque
MOD = 10**9 + 7
n = len(nums)
dp = [0] * (n + 1)
pre = [0] * (n + 1)
dp[0] = 1
pre[1] = 1
mx, mn = deque(), deque()
left = 0
for i in range(1, n + 1):
    x = nums[i - 1]
    while mx and nums[mx[-1]] <= x: mx.pop()
    mx.append(i - 1)
    while mn and nums[mn[-1]] >= x: mn.pop()
    mn.append(i - 1)
    while nums[mx[0]] - nums[mn[0]] > k:
        left += 1
        if mx[0] < left: mx.popleft()
        if mn[0] < left: mn.popleft()
    dp[i] = (pre[i] - pre[left]) % MOD
    pre[i + 1] = (pre[i] + dp[i]) % MOD
return dp[n]
```

## 复杂度
时间 O(n)：每个下标最多进出单调队列各一次。
空间 O(n)：`dp`、`pre` 各 n+1，两个队列各至多 n。

## 易错点
- `nums=[3,3,4], k=0`：若用 `<=` 和 `>=` 之外的条件去重，会把相等元素误判为超差；相等时差为 0 仍合法，单调队列弹出用 `<=`/`>=` 只影响存哪个下标，不影响极值。
- 全相同数组如 `[5,5,5], k=0`：若 `left` 只在严格大于 k 时移动，窗口永远合法，`dp` 应为 `2**(n-1)=4`；写成 `left` 每次必移会漏算，正确是仅当 `nums[mx[0]]-nums[mn[0]] > k` 才移。

## 如果面试官追问
问：若要求输出所有分割方案而非计数？答：把 `dp` 换成回溯 + 剪枝，用同一窗口预处理每个右端点的合法左端点集合，再 DFS 枚举。
