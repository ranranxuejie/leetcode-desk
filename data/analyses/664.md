## 一句话思路
区间 DP：`dp[i][j]` 表示打印 `s[i..j]` 的最少次数，靠「首尾同字符可省一次」转移。

## 怎么做
1. 先压缩连续相同字符，`"aaabbb"` 变成 `"ab"`，答案不变但状态更少。
2. 初始化 `dp[i][i] = 1`，长度从 2 到 n 枚举区间。
3. 转移：若 `s[i] == s[j]`，`dp[i][j] = dp[i][j-1]`；否则枚举分割点 `k`，`dp[i][j] = min(dp[i][k] + dp[k+1][j])`。
4. 返回 `dp[0][n-1]`。

以 `s = "aba"` 为例：`dp[0][0]=dp[1][1]=dp[2][2]=1`。算 `dp[0][2]` 时 `s[0]=='a'==s[2]`，直接取 `dp[0][1]`；而 `dp[0][1]` 因 `'a'!='b'` 取 `dp[0][0]+dp[1][1]=2`，故 `dp[0][2]=2`，与示例一致。

```python
def strangePrinter(s):
    t = []
    for c in s:
        if not t or t[-1] != c:
            t.append(c)
    n = len(t)
    dp = [[0] * n for _ in range(n)]
    for i in range(n):
        dp[i][i] = 1
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if t[i] == t[j]:
                dp[i][j] = dp[i][j - 1]
            else:
                dp[i][j] = min(dp[i][k] + dp[k + 1][j] for k in range(i, j))
    return dp[0][n - 1] if n else 0
```

## 复杂度
时间：O(n³)，三层循环枚举区间与分割点。
空间：O(n²)，`dp` 二维表，n 为压缩后长度。

## 易错点
- 输入 `"aba"` 若不压缩直接按原串 DP，`s[0]==s[2]` 仍成立但区间内 `'b'` 干扰分割，容易把答案算成 3；正确做法是先压缩成 `"aba"` 再转移，或原串上严格用 `dp[i][j-1]`。
- 输入 `"aaabbb"` 若漏掉压缩，`dp[0][5]` 枚举 `k` 时会把 `"aaa"` 拆成多次打印得 3 以上；正确做法是压缩后 `"ab"` 直接得 2。

## 如果面试官追问
问：n 到 1000 怎么办？答：O(n³) 会超时，需换记忆化搜索加剪枝，或利用字符集只有 26 个做区间合并优化。
