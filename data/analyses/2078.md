## 一句话思路
答案只可能来自「首元素 vs 某个尾部元素」或「某头部元素 vs 末元素」，从两端各扫一次取最大即可。

## 怎么做
1. 记 `n = len(colors)`，`last = n - 1`，答案初值 0。
2. 从右往左找第一个 `colors[i] != colors[0]` 的下标 `i`，候选 `i - 0`。
3. 从左往右找第一个 `colors[j] != colors[last]` 的下标 `j`，候选 `last - j`。
4. 两者取 `max` 返回。

以示例 1 `colors = [1,1,1,6,1,1,1]` 为例：`colors[0] = 1`，从右往左第一个不等于 1 的是下标 3（值 6），候选 `3 - 0 = 3`；`colors[6] = 1`，从左往右第一个不等于 1 的也是下标 3，候选 `6 - 3 = 3`；答案 3。

为什么只查这两条？设最优对是 `(i, j)`，`i < j`。若 `colors[0] != colors[j]`，则 `(0, j)` 不劣于 `(i, j)`；否则 `colors[0] == colors[j]`，而 `colors[i] != colors[j]`，故 `colors[i] != colors[0]`，于是 `(i, last)` 不劣于 `(i, j)`（因为 `last >= j`）。两种情况都被上面两次扫描覆盖。

```python
n = len(colors)
last = n - 1
ans = 0
for i in range(last, -1, -1):
    if colors[i] != colors[0]:
        ans = max(ans, i)
        break
for j in range(n):
    if colors[j] != colors[last]:
        ans = max(ans, last - j)
        break
return ans
```

注意第二个循环里 `last - j` 而不是 `j`，因为 `j` 是从左端出发的下标，距离要拿右端点减。

## 复杂度
时间 O(n)：两次线性扫描，每次最多走完整个数组。
空间 O(1)：只用了 `n`、`last`、`ans`、循环变量。

## 易错点
- 输入 `colors = [1,1,1,6,1,1,1]`：若只从左边找「第一个和 `colors[0]` 不同的」，会得到下标 3、答案 3，看似对；但换成 `[6,1,1,1,1,1,1]` 时左扫得 1，而正确答案是 6（下标 0 与 6），必须补上「末元素 vs 头部」这一路。
- 输入 `colors = [0,1]`：第二个循环若写成 `ans = max(ans, j)` 会得 0，正确是 `last - j = 1 - 0 = 1`；距离永远是右下标减左下标，别把 `j` 直接当距离。

## 如果面试官追问
问：如果要求返回具体下标对而不只是距离？答：两次扫描时顺手记下 `(0, i)` 和 `(j, last)` 两个候选对，比较距离时一起带上即可。
