## 一句话思路
直接按定义 `ans[i] = nums[nums[i]]` 逐位取值，因为 `nums` 是 0 到 n-1 的排列，`nums[i]` 必是合法下标。

## 怎么做
1. 建一个长度等于 `len(nums)` 的列表 `ans`，先填 0 占位。
2. 遍历 `i` 从 0 到 `len(nums)-1`，取 `j = nums[i]`，再取 `nums[j]` 写进 `ans[i]`。
3. 返回 `ans`。

以 `nums = [0,2,1,5,3,4]` 为例，`i=3` 时 `j = nums[3] = 5`，`nums[5] = 4`，所以 `ans[3] = 4`；`i=4` 时 `j = nums[4] = 3`，`nums[3] = 5`，所以 `ans[4] = 5`。两次下标都落在 0..5 内，不会越界。

```python
n = len(nums)
ans = [0] * n
for i in range(n):
    ans[i] = nums[nums[i]]
return ans
```

进阶的 O(1) 空间做法：把结果先编码进 `nums` 自身。因为 `nums[i] < n`，可令 `nums[i] = nums[i] + n * nums[nums[i]]`，此时 `nums[i] % n` 仍是原值、`nums[i] // n` 是新值。但注意 `nums[nums[i]]` 里的 `nums[i]` 必须用原值，所以要先 `old = nums[i] % n` 再取 `nums[old] % n`。全部编码完再统一 `nums[i] //= n`。示例 1 中 `i=3`：`old = 5`，`nums[5] % 6 = 4`，`nums[3]` 变成 `5 + 6*4 = 29`，最后 `29 // 6 = 4`，与 `ans[3]` 一致。

## 复杂度
时间：O(n)，每个下标只做两次随机访问。
空间：O(n) 存 `ans`；进阶版原地编码，额外空间 O(1)。

## 易错点
- 输入 `nums = [5,0,1,2,3,4]` 时，若误写成 `ans[i] = nums[i]` 或只取一层下标，会得到 `[5,0,1,2,3,4]` 而非 `[4,5,0,1,2,3]`；正确做法是严格两层 `nums[nums[i]]`。
- 进阶原地写法中，若在循环里直接用已被改写的 `nums[i]` 当下标，例如 `i=0` 时 `nums[0]` 已变成 `5 + 6*4 = 29`，再取 `nums[29]` 直接越界；正确做法是先 `old = nums[i] % n` 拿到原值再索引。

## 如果面试官追问
问：若 `nums` 不是排列、元素可能 ≥ n 怎么办？
答：两层下标会越界，需先校验 `0 <= nums[i] < n`，否则按题意返回空或抛异常。
