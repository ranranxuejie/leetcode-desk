## 一句话思路
按长度递增枚举数字集合，用回溯拼出最小回文，取第一个大于 n 的。

## 怎么做
1. 特殊数的长度由「每个数字 k 出现恰好 k 次」决定：选中的数字集合 S 的总位数 `sum(S)` 必须是偶数（回文左右对称），且左半部分恰好是 `sum(S)//2` 位。
2. 对每个目标长度 L（从 `len(str(n))` 起，最多到 1+2+...+9=45 位），枚举所有满足 `sum(S)==L` 且 L 为偶数的数字集合 S。
3. 对每个 S，左半部分由 S 中每个数字 k 贡献 `k//2` 个副本组成（k 为奇数时中间位放一个 k），用回溯按字典序从小到大填左半，第一个能拼出 > n 的即为答案。
4. 若当前长度无解，L 加 2 继续；L 超过 45 时答案必然存在（如全用 9 和 8 等组合）。

以 n = 33 为例：`len(str(33))=2`，L=2 时可选 S={1,2}（sum=3≠2）不行，S={2}（sum=2）得 "22" 不大于 33；L=4 时 S={1,3}（sum=4）左半需 1 个 '1' 和 1 个 '3'，最小左半 "13" → 回文 "1331" > 33，但 S={1,2} 不满足 sum=4；实际 L=3 时 S={1,2}（sum=3，奇数）中间位放 2，左半 "1" → "212" > 33，取最小即 212。

```python
def build(S, half, mid):
    # half: 左半需要的数字列表（已排序），mid: 中间字符或 ''
    left = ''.join(sorted(half))
    return int(left + mid + left[::-1])

# 对固定 S，左半 multiset = {k: k//2 for k in S}
# 回溯按升序填 left，剪枝：当前前缀已大于 n 对应前缀则直接取最小剩余
```

关键剪枝：填左半时逐位与 `str(n)` 的左半比较，一旦某位大于 n 对应位，剩余位直接升序填最小即可，不必继续搜索。

## 复杂度
时间：O(2^9 × 45 × 回溯分支)，集合枚举 512 种，每种回溯至多 45 位。
空间：O(45) 递归栈 + 临时字符串，与 n 的位数同阶。

## 易错点
- n = 0 → 若直接从 `len(str(0))=1` 开始找，L=1 无偶数长度解会漏掉；正确做法是 L 从 `max(2, len(str(n)))` 起且强制偶数，答案 22 而非 1。
- n = 10^15（16 位）→ 若只枚举到 16 位会找不到解（16 位内无满足条件的集合），必须允许 L 增长到 18、20…直到 45；正确做法是循环 `while L <= 45` 而非固定上界。

## 如果面试官追问
问：若 n 上限提到 10^100 怎么办？
答：集合枚举不变（仍 512 种），但回溯需按长度分段处理，且大数比较改用字符串，复杂度对位数线性。
