## 一句话思路
用 DFS 维护路径上各值出现次数的奇偶位掩码，到叶子时判断掩码是否只有 0 或 1 个 1。

## 怎么做
1. 递归时把 `mask` 与 `1 << (node.val - 1)` 异或，进入节点即翻转该值的奇偶性。
2. 叶子判定用 `not node.left and not node.right`，此时 `mask` 就是整条根到叶路径的奇偶状态。
3. 伪回文条件：`mask == 0 or mask & (mask - 1) == 0`，即至多一个值出现奇数次。
4. 非叶子则把左右子树的结果相加返回。

以示例 1 的红色路径 `[2,3,3]` 为例：进入 2 后 `mask = 1<<1 = 2`，进入第一个 3 后 `mask = 2 ^ 4 = 6`，进入第二个 3 后 `mask = 6 ^ 4 = 2`；`2 & 1 == 0`，判为伪回文。绿色路径 `[2,1,1]` 同理得 `mask = 2`，也计数。而 `[2,3,1]` 得 `mask = 2 ^ 4 ^ 1 = 7`，`7 & 6 = 6 != 0`，不计数。

```python
def dfs(node, mask):
    if not node:
        return 0
    mask ^= 1 << (node.val - 1)
    if not node.left and not node.right:
        return 1 if mask == 0 or mask & (mask - 1) == 0 else 0
    return dfs(node.left, mask) + dfs(node.right, mask)

return dfs(root, 0)
```

注意 `mask` 是值传递（Python 整数不可变），回溯时无需手动撤销异或，这是本题用位掩码比用计数数组更省事的地方。

## 复杂度
时间 O(n)：每个节点访问一次，异或和叶子判定都是 O(1)。
空间 O(h)：递归栈深度为树高 h，最坏链状树 h = n，未额外开数组。

## 易错点
- 把叶子判定写成 `if not node` 就返回：空节点不是叶子，会在 `[9]` 这类单节点树上把根当成非叶子继续递归，返回 0 而非 1。正确做法是先判 `not node.left and not node.right` 再统计。
- 用计数数组 `cnt[10]` 统计后忘记回溯（`cnt[v] -= 1`）：同一层兄弟分支会互相污染，示例 1 中走完红色路径的 `cnt[3]=2` 会带进绿色路径，导致 `[2,1,1]` 被误判。位掩码异或天然可逆，进出各一次即恢复。

## 如果面试官追问
问：节点值范围从 1-9 扩到 1-100 怎么办？
答：位掩码放不下，改用 `dict` 记奇偶集合，叶子时判断 `len(odd) <= 1`，复杂度不变。
