## 一句话思路
只要数组里有 1，答案就是 1；否则用最小值 m 去模所有更大的数，答案等于「大于 m 的元素个数」与 1 取较大值。

## 怎么做
1. 先扫一遍求 `m = min(nums)`，同时统计 `m` 出现次数 `cnt`。
2. 若 `m == 1`，直接返回 1（1 模任何数得 0，0 无法再参与操作，但 1 本身能吃掉其余全部元素）。
3. 否则，用 `m` 作模数去模每个 `nums[i] > m`，得到 `nums[i] % m`，这些余数都 `< m`，可以继续当「新模数」用。
4. 关键结论：只要存在一个 `nums[i] % m != 0`，就能造出比 `m` 更小的正数，进而滚雪球吃掉全部元素，答案 1；若所有 `nums[i] % m == 0`（即全是 `m` 的倍数），余数全是 0，0 不能参与操作，只能留下 `cnt` 个 `m`，但 `cnt` 个 `m` 之间互相模得 0，最终能压到 1 个 `m` 加若干 0，答案就是 1？——不对，示例 2 给出 2，说明 `cnt` 个相同 `m` 两两相模得 0，每消耗 2 个 `m` 换 1 个 0，最终剩 `cnt % 2` 个 `m` 加一堆 0，长度 = `cnt % 2 + (n - cnt)` 个 0 中的非零部分……实际是 `ceil(cnt/2)` 个非零残留。

以示例 2 `nums = [5,5,5,10,5]` 验证：`m = 5`，`cnt = 4`，`10 % 5 = 0`，全是倍数。4 个 5 两两配对：5%5=0，消耗 2 个 5 换 1 个 0，剩 2 个 5 + 1 个 0；再配对剩 0 个 5 + 2 个 0？但示例答案是 2，说明配对后剩 2 个非零。正确公式是 `(cnt + 1) // 2`：`(4+1)//2 = 2`，对上。

```python
m = min(nums)
if m == 1:
    return 1
cnt = nums.count(m)
for x in nums:
    if x % m != 0:
        return 1
return (cnt + 1) // 2
```

## 复杂度
时间 O(n)：一次求 min、一次 count、一次遍历取模。
空间 O(1)：只用了 `m`、`cnt` 两个变量。

## 易错点
- 输入 `[5,5,5,10,5]` → 误以为「有倍数关系就返回 1」→ 实际余数全 0，0 不能参与操作，正确返回 `(cnt+1)//2 = 2`。
- 输入 `[2,3,4]` → 只检查 `min` 是否为 1 就返回 `n` 或 `cnt` → 漏了 `3 % 2 = 1` 能造出 1，正确做法是遍历找任一 `x % m != 0` 就返回 1。

## 如果面试官追问
问：如果要求输出具体操作序列怎么办？
答：先造出最小非零余数 r，再用 r 依次模掉其余所有元素（r % x 当 r < x 时得 r 本身不减小，应反过来用 x % r），每步记录 (i, j) 即可。
