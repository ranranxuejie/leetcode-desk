## 一句话思路
对每个字母统计它在每个单词中出现的最小次数，按次数重复输出该字母。

## 怎么做
1. 用 `cnt = [100] * 26` 记录每个字母在各单词中的最小出现次数，初值取上界 100（单词最长 100）。
2. 遍历 `words` 中每个单词 `w`，用 `Counter(w)` 得到该词的字母频次。
3. 对 26 个字母逐个取 `cnt[i] = min(cnt[i], freq.get(chr(97+i), 0))`，某词缺某字母就把该字母计数压到 0。
4. 最后按 `cnt[i]` 次把 `chr(97+i)` 追加进结果。

以 `words = ["bella","label","roller"]` 为例：处理完 `"bella"` 后 `cnt` 中 `e=1, l=2, b=1, a=1`；处理 `"label"` 后 `l` 仍为 2、`b` 仍为 1；处理 `"roller"` 时该词 `b=0, a=0`，于是 `cnt[b]=0, cnt[a]=0`，`l` 取 `min(2,2)=2`，`e` 取 `min(1,1)=1`，最终输出 `["e","l","l"]`。

```python
from collections import Counter

cnt = [100] * 26
for w in words:
    freq = Counter(w)
    for i in range(26):
        cnt[i] = min(cnt[i], freq.get(chr(97 + i), 0))

res = []
for i in range(26):
    res.extend(chr(97 + i) for _ in range(cnt[i]))
```

关键点：`freq.get(ch, 0)` 的默认值 0 保证「某词没有该字母」时计数归零，而不是保留上一轮的值。

## 复杂度
时间 O(L + 26·n)，L 是所有单词字符总数，26·n 来自每词扫一遍字母表。
空间 O(1)，`cnt` 固定 26 项，`Counter` 最多 26 项。

## 易错点
- 输入 `["cool","lock","cook"]` → 若只对第一个词建频次表、后续词只做「是否包含」判断，会输出 `["c","o","o"]`，多出一个 `o`；正确做法是对每个词都取 `min`，`"lock"` 只有一个 `o`，把 `cnt[o]` 压到 1。
- 输入 `["abc","def"]` → 若 `cnt` 初值设 0 再用 `max` 或忘记处理缺失字母，会保留 `abc` 的计数；正确做法是初值取大数 100 配 `min`，缺失字母经 `get(ch, 0)` 归零。

## 如果面试官追问
若 `words[i]` 含大写和数字怎么办？答：把 26 改成 128 或 62 的字符表，索引换成 `ord(ch)`，逻辑不变。
