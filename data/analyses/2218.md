## 一句话思路
对每个栈先算「取前 j 个」的前缀和，再做分组背包：每组只能按顺序取前 j 个，容量是 k。

## 怎么做
1. 把 `piles[i]` 转成前缀和数组 `pre`，`pre[j]` 表示从第 i 个栈取 j 个硬币的面值和（j 从 1 开始）。
2. 定义 `dp[c]` 为「处理完当前若干栈、恰好取 c 个硬币」的最大面值和，初始 `dp[0]=0`，其余 `-inf`。
3. 对每个栈做 0/1 分组背包：`new_dp[c] = max(dp[c-j] + pre[j])`，j 从 0 到 `min(len(pile), c)`，j=0 表示这个栈一个不取。
4. 答案为 `dp[k]`。

用示例 1 `piles=[[1,100,3],[7,8,9]], k=2`：第一个栈前缀和 `[1,101,104]`，处理完 `dp=[0,1,101]`（取 0/1/2 个）；第二个栈前缀和 `[7,15,24]`，更新时 `dp[2] = max(101, dp[1]+7=8, dp[0]+15=15) = 101`，最终返回 101。

```python
NEG = -10**18
dp = [NEG] * (k + 1)
dp[0] = 0
for pile in piles:
    pre = [0]
    for v in pile:
        pre.append(pre[-1] + v)
    ndp = dp[:]                      # j=0：这个栈不取
    for c in range(k + 1):
        if dp[c] == NEG:
            continue
        for j in range(1, min(len(pile), k - c) + 1):
            if dp[c] + pre[j] > ndp[c + j]:
                ndp[c + j] = dp[c] + pre[j]
    dp = ndp
return dp[k]
```

## 复杂度
时间：O(k · Σlen(piles[i]))，每个栈的每个 j 都要扫一遍容量 c。
空间：O(k)，只开 `dp`/`ndp` 两个长度 k+1 的数组，前缀和就地算。

## 易错点
- 把栈当普通 0/1 背包逐个硬币取 → 对 `[[1,100,3]]` 会算出取 100 和 3 得 103，但取 3 必须先取 1 和 100，正确只能取前缀 `[1,101,104]` 中的值。
- 内层用 `dp` 原地更新（正序或倒序都不行）→ 同一个栈会被重复取多次，示例 1 中 `dp[2]` 可能被算成 `1+1` 之类的非法组合；必须用 `ndp` 承接、循环结束后再赋值。

## 如果面试官追问
问：k 增大到 10^5 怎么办？答：Σlen 只有 2000，先把每个栈截断到前 k 个，且总可取数不超过 Σlen，实际复杂度仍是 O(k·Σlen) 的上界内。
