## 一句话思路
用双指针在 `s` 的前 `k` 个字符上原地对撞交换，因为反转前缀只需首尾两两互换。

## 怎么做
1. 把 `s` 转成列表 `a`，因为 Python 字符串不可变，交换必须落在可变序列上。
2. 设 `i = 0`、`j = k - 1`，两个指针都只在前缀区间 `[0, k-1]` 内活动。
3. 当 `i < j` 时交换 `a[i]` 与 `a[j]`，然后 `i += 1`、`j -= 1`。
4. 循环结束后 `''.join(a)` 返回，`k` 之后的部分从未被触碰。

以 `s = "abcd", k = 2` 为例：`a = ['a','b','c','d']`，`i = 0`、`j = 1`，交换后 `a = ['b','a','c','d']`，接着 `i = 1`、`j = 0` 退出循环，`join` 得 `"bacd"`。关键中间值就是交换后的 `a[0]='b'`、`a[1]='a'`，而 `a[2]='c'`、`a[3]='d'` 原封不动。

```python
a = list(s)
i, j = 0, k - 1
while i < j:
    a[i], a[j] = a[j], a[i]
    i += 1
    j -= 1
return ''.join(a)
```

注意 `j` 的初值是 `k - 1` 而不是 `k`：前缀是前 `k` 个字符，下标范围 `0..k-1`，写成 `k` 会把第 `k+1` 个字符也卷进来。示例 3 中 `k = 1` 时 `i = 0`、`j = 0`，`i < j` 直接为假，一次交换都不做，返回原串 `"hey"`，这正是单字符前缀反转的边界。

## 复杂度
时间：O(k)，交换次数为 `k // 2`，`join` 复制整串贡献 O(n)。
空间：O(n)，`list(s)` 和结果串各占一份，指针只占 O(1)。

## 易错点
- `s = "abcd", k = 4` → 若把 `j` 写成 `k`，会访问 `a[4]` 抛 `IndexError`；正确做法是 `j = k - 1`，让 `j` 落在最后一个前缀字符上。
- `s = "hey", k = 1` → 若用 `for i in range(k // 2)` 之外的写法（如先 `k -= 1` 再无条件交换）会自己和自己换或越界；正确做法是保留 `while i < j` 判断，`k = 1` 时零次交换。

## 如果面试官追问
问：若要求反转前 `k` 个字符且 `k` 可能大于 `len(s)` 怎么办？
答：先取 `k = min(k, len(s))`，再走同一套双指针，避免 `j` 越界。
