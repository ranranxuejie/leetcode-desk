## 一句话思路
把 dictionary 里每个词预加密成密文，用哈希表按密文计数；decrypt 只需查表，因为解密的多解性已被预加密穷举掉。

## 怎么做
1. 构造时建 `enc` 字典（字符→两字符）和 `cnt` 字典（密文→dictionary 中能加密成它的词数）。
2. 对 dictionary 每个词逐字符查 `enc`，任一字符不在 `enc` 中则该词永不可达，跳过；否则把整词密文 `cnt[c] += 1`。
3. `encrypt` 逐字符拼 `enc[ch]`，字符缺失返回 `""`。
4. `decrypt` 直接返回 `cnt.get(word2, 0)`。

以官方示例为例：`dictionary` 中 `"abcd"` 加密为 `"ei"+"zf"+"ei"+"am" = "eizfeiam"`，`"abad"` 加密为 `"ei"+"zf"+"ei"+"am"` 也是 `"eizfeiam"`（`a` 和 `c` 都映射 `"ei"`），故 `cnt["eizfeiam"] = 2`，`decrypt` 直接命中。

```python
def __init__(self, keys, values, dictionary):
    self.enc = {k: v for k, v in zip(keys, values)}
    self.cnt = {}
    for w in dictionary:
        if all(ch in self.enc for ch in w):
            c = "".join(self.enc[ch] for ch in w)
            self.cnt[c] = self.cnt.get(c, 0) + 1

def encrypt(self, word1):
    if any(ch not in self.enc for ch in word1):
        return ""
    return "".join(self.enc[ch] for ch in word1)

def decrypt(self, word2):
    return self.cnt.get(word2, 0)
```

关键点：`decrypt` 不做任何搜索，多解性在构造阶段就被 `cnt` 的合并计数吸收了。

## 复杂度
时间：构造 O(Σ|dictionary[i]|)，encrypt O(|word1|)，decrypt O(|word2|) 仅哈希查表。
空间：`cnt` 存至多 100 条密文，`enc` 至多 26 项，与 dictionary 总长同阶。

## 易错点
- 直接把 `word2` 按两字符切块、对每块枚举所有匹配的 key 再拼组合 → 组合数指数爆炸（示例中 `"ei"` 对应 `a`、`c` 两个 key，4 块就是 16 种）。正确做法是反过来预加密 dictionary，让哈希表承担去重。
- 构造时对 dictionary 里含 `enc` 之外字符的词也强行加密 → 抛 KeyError 或算出错误密文。必须先 `all(ch in self.enc ...)` 过滤，这类词永远无法被任何 `word2` 解出。

## 如果面试官追问
问：若 dictionary 规模涨到 10^5、总长 10^6，还这么做吗？
答：仍可行，构造 O(总长) 一次性摊掉，之后每次 decrypt 都是 O(|word2|) 查表，比每次枚举解密组合快得多。
