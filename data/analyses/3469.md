## 一句话思路
按顺序每三个一组处理，用 DP 记录「前 i 个元素清空的最小代价」，转移时枚举三元素中保留哪个与后面合并。

## 怎么做
1. 定义 `dp[i]` 为清空前 i 个元素的最小代价，`dp[0] = 0`，其余初始化为无穷大。
2. 对每个 i，若 `i >= 2`，考虑从 `dp[i-2]` 转移：把 `nums[i-2]`、`nums[i-1]` 作为一次操作移除，代价 `max(nums[i-2], nums[i-1])`。
3. 若 `i >= 3`，考虑从 `dp[i-3]` 转移：三元素 `nums[i-3..i-1]` 中移除两个，留下一个与后续合并，代价为三者之和减去留下的那个（即移除两个的 max 等价于三者和减最小值？需验证）。
4. 最终答案 `dp[n]`。

以 `nums = [6,2,8,4]` 为例：`dp[2] = max(6,2) = 6`；`dp[3]` 从 `dp[0]` 转移，三元素 6,2,8 移除两个留一个，最优留 2（移除 6,8 代价 8），`dp[3] = 8`；`dp[4]` 从 `dp[1]`（无穷）或 `dp[2]` 转移：`dp[2] + max(8,4) = 6 + 8 = 14`，或从 `dp[1]` 三元素 2,8,4 留 2 代价 8，`dp[1]` 无穷。实际最优是 12，说明转移需更细。

正确转移：`dp[i] = min(dp[i-2] + max(nums[i-2], nums[i-1]), dp[i-3] + max(nums[i-3], nums[i-2], nums[i-1]) 中移除两个的最小代价)`。三元素移除两个的最小代价 = 三者和 - 最大值（留最大值与后续合并最省）。

```python
n = len(nums)
dp = [float('inf')] * (n + 1)
dp[0] = 0
for i in range(2, n + 1):
    dp[i] = min(dp[i], dp[i-2] + max(nums[i-2], nums[i-1]))
    if i >= 3:
        s = nums[i-3] + nums[i-2] + nums[i-1]
        dp[i] = min(dp[i], dp[i-3] + s - max(nums[i-3], nums[i-2], nums[i-1]))
return dp[n]
```

## 复杂度
时间：O(n)，每个 i 常数次转移。
空间：O(n)，dp 数组长度 n+1。

## 易错点
- 输入 `[6,2,8,4]` → 若只考虑两两配对（`dp[i-2]` 转移）会得 14，漏掉三元素留一个的转移 → 必须同时枚举 `dp[i-3]` 分支，三元素移除两个的代价是「和减最大值」而非「和减最小值」。
- 输入 `[2,1,3,3]` → 若三元素转移时误留最小值（留 1 移除 2,3 代价 3），会得 3+3=6 → 正确是留最大值 3，移除 2,1 代价 2，再移除 3,3 代价 3，总 5。

## 如果面试官追问
问：n 扩大到 10^5 还能做吗？答：能，DP 仍是 O(n)，只需滚动保存前三个状态，空间降到 O(1)。
