## 一句话思路
把 n 的二进制 1 位从低到高映射成 powers，再用前缀积（存指数）回答区间查询。

## 怎么做
1. 遍历 `i` 从 0 到 30，若 `n >> i & 1`，把 `2**i` 追加进 `powers`；因为二进制表示唯一，这样得到的元素数最少且天然非递减。
2. 对 `n = 15`（二进制 `1111`），得到 `powers = [1, 2, 4, 8]`，长度 4。
3. 关键：`powers` 全是 2 的幂，乘积等于 `2**(指数和)`，所以前缀和存的是**指数**而不是值，避免大数相乘。
4. 对每个 `[l, r]`，指数和 `= pre[r+1] - pre[l]`，答案 `pow(2, s, 10**9+7)`。

```python
MOD = 10**9 + 7
powers = [1 << i for i in range(31) if n >> i & 1]
pre = [0]
for p in powers:
    pre.append(pre[-1] + p.bit_length() - 1)
ans = []
for l, r in queries:
    s = pre[r + 1] - pre[l]
    ans.append(pow(2, s, MOD))
```

`n = 15` 时 `pre = [0, 0, 1, 3, 6]`；查询 `[0,1]` 得 `s = pre[2] - pre[0] = 1`，`pow(2,1) = 2`，与示例一致。

## 复杂度
时间：O(log n + q)，构造 powers 扫 31 位，每个查询 O(1)（`pow` 是 O(log s) 但 s ≤ 30）。
空间：O(log n + q)，powers 与 pre 各约 31 项，答案数组 q 项。

## 易错点
- `n = 1` → 若循环写成 `range(1, 31)` 会漏掉 `2**0 = 1`，powers 变空、查询越界；正确做法是从 `i = 0` 开始扫，`1 >> 0 & 1 == 1` 要收进来。
- 直接存 `powers` 的前缀**积** → `n = 10**9` 时前缀积可达 `2**30` 量级再相乘，虽 Python 不溢出但取模后做除法求区间积会失效（模逆需保证互质且易写错）；正确做法是前缀和存指数，区间内只做减法。

## 如果面试官追问
若 n 上限改成 `10**18` 且要求输出 powers 本身，怎么改？答：循环上界改成 `range(61)`，其余逻辑不变，长度仍是 O(log n)。
