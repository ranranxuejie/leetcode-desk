## 一句话思路
枚举每个元素作为子数组最小值，用单调栈求它的左右边界，再用前缀和 O(1) 算区间和取最大。

## 怎么做
1. 前缀和 `pre[i+1] = pre[i] + nums[i]`，区间 `[l, r]` 的和为 `pre[r+1] - pre[l]`。
2. 单调栈求每个 `nums[i]` 左边第一个严格小于它的位置 `left[i]`，右边第一个严格小于它的位置 `right[i]`。
3. 以 `nums[i]` 为最小值的最大区间是 `[left[i]+1, right[i]-1]`，乘积为 `nums[i] * (pre[right[i]] - pre[left[i]+1])`。
4. 遍历取最大值，最后对 `10**9 + 7` 取余。

以 `nums = [1,2,3,2]` 为例：对 `i=1`（值 2），左边第一个更小是下标 0（值 1），右边第一个更小不存在（记为 4），区间 `[1,3]` 即 `[2,3,2]`，和 `pre[4]-pre[1] = 8-1 = 7`，乘积 `2*7 = 14`。

```python
n = len(nums)
pre = [0] * (n + 1)
for i, x in enumerate(nums):
    pre[i + 1] = pre[i] + x
left, right = [-1] * n, [n] * n
st = []
for i in range(n):
    while st and nums[st[-1]] >= nums[i]:
        right[st.pop()] = i
    left[i] = st[-1] if st else -1
    st.append(i)
ans = 0
for i in range(n):
    s = pre[right[i]] - pre[left[i] + 1]
    ans = max(ans, nums[i] * s)
return ans % (10**9 + 7)
```

## 复杂度
时间：O(n)，每个下标进出栈各一次，前缀和与遍历各 O(n)。
空间：O(n)，`pre`、`left`、`right`、栈各占 O(n)。

## 易错点
- 相等元素处理：`nums = [2,3,3,1,2]` 若用 `>` 出栈，两个 3 会互相把对方截断，`i=1` 的右边界错成 2，区间只剩 `[3]`，乘积 3；正确用 `>=` 出栈，让相等元素共享边界，`i=1` 得到 `[1,2]`，`3*6 = 18`。
- 取余时机：`nums` 全为 `10**4` 量级且长度大时，先取余再比大小会选错区间；必须用完整乘积比较 `ans`，只在 `return` 时取余。

## 如果面试官追问
问：若要求返回取得最大值的子数组下标区间？答：在更新 `ans` 时同步记录 `(left[i]+1, right[i]-1)`，相等时保留先出现的即可。
