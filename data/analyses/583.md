## 一句话思路
答案 = len(word1) + len(word2) - 2 × 最长公共子序列长度，删掉的正是两边各自不属于 LCS 的字符。

## 怎么做
1. 把问题转成求 `word1` 与 `word2` 的 LCS 长度 `L`，返回 `m + n - 2*L`。
2. 定义 `dp[i][j]` 为 `word1[:i]` 与 `word2[:j]` 的 LCS 长度，`dp` 是 `(m+1) × (n+1)` 全 0 表。
3. 逐格填：`word1[i-1] == word2[j-1]` 时 `dp[i][j] = dp[i-1][j-1] + 1`，否则取 `max(dp[i-1][j], dp[i][j-1])`。
4. 返回 `m + n - 2*dp[m][n]`。

以 `word1="sea"`、`word2="eat"` 为例，`m=n=3`。填到 `i=2, j=2`（字符 `e` 对 `a`）时不等，`dp[2][2] = max(dp[1][2], dp[2][1]) = max(1,1) = 1`；最终 `dp[3][3] = 2`（LCS 是 `"ea"`），答案 `3+3-2*2 = 2`。

```python
m, n = len(word1), len(word2)
dp = [[0] * (n + 1) for _ in range(m + 1)]
for i in range(1, m + 1):
    for j in range(1, n + 1):
        if word1[i - 1] == word2[j - 1]:
            dp[i][j] = dp[i - 1][j - 1] + 1
        else:
            dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
return m + n - 2 * dp[m][n]
```

## 复杂度
时间 O(m·n)：`m = len(word1)`、`n = len(word2)`，双层循环各走一遍。
空间 O(m·n)：开了 `(m+1)×(n+1)` 的 `dp` 表；可压成一维 `n+1`。

## 易错点
- `word1="sea"`、`word2="eat"` 若直接按「逐位比较、不同就删」贪心，会把 `s` 和 `t` 都删掉得 2 但理由错，遇到 `"abc"` vs `"bca"` 会算成 4 而正确是 2（LCS 为 `"bc"` 或 `"ba"`）→ 必须走 LCS，不能逐位对齐。
- 下标错位：`dp[i][j]` 对应字符 `word1[i-1]`、`word2[j-1]`，写成 `word1[i]` 会在 `i=m` 时越界或整体错一格，`"sea"/"eat"` 会得 3 而非 2 → 循环从 1 开始、比较时统一减 1。

## 如果面试官追问
问：只允许删除 `word1` 的字符、`word2` 不动，怎么改？
答：那就不是 LCS 了，改成判断 `word2` 是否为 `word1` 的子序列，是则返回 `m-n`，否则无解。
