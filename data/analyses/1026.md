## 一句话思路
自顶向下 DFS 传递路径上的最小值和最大值，每个节点用 `max(hi - val, val - lo)` 更新答案。

## 怎么做
1. 递归函数带三个参数：当前节点、祖先路径最小值 `lo`、最大值 `hi`。
2. 进入节点先更新答案 `ans = max(ans, hi - val, val - lo)`，再更新 `lo = min(lo, val)`、`hi = max(hi, val)`。
3. 用更新后的 `lo`、`hi` 递归左右子树，空节点直接返回。

以示例 1 为例：走到节点 `1` 时，路径上 `lo = hi = 8`，`ans = max(0, 8-1, 1-8) = 7`；随后 `lo` 变成 1，继续下探到 `4`、`7` 时 `hi` 仍是 8，`8-4=4`、`8-7=1` 都超不过 7。关键在于 `lo`/`hi` 是**路径上**的极值，不是全局极值——`10` 分支的 `14`、`13` 拿不到 `1`，所以 `|10-13|=3` 而不是 9。

```python
def dfs(node, lo, hi):
    if node is None:
        return 0
    v = node.val
    best = max(hi - v, v - lo)
    lo, hi = min(lo, v), max(hi, v)
    return max(best, dfs(node.left, lo, hi), dfs(node.right, lo, hi))
```

根节点调用时 `lo = hi = root.val`，此时 `hi - v` 和 `v - lo` 都是 0，不会污染答案。

## 复杂度
时间 O(n)：每个节点访问一次，n 为节点数。
空间 O(h)：递归栈深度等于树高 h，最坏链状树 O(n)，无额外数组。

## 易错点
- 把 `lo`/`hi` 写成全局变量：示例 1 中 `10` 的右子树会拿到左子树的 `1`，算出 `|10-1|=9`，答案错成 9。必须作为参数沿路径传递，回溯时自然丢弃。
- 先更新 `lo`/`hi` 再算差值：走到 `1` 时若先令 `lo = 1`，`v - lo = 0`，`|8-1|=7` 就丢了。顺序必须是先算 `hi - v`、`v - lo`，再收缩区间。

## 如果面试官追问
问：要求返回取得最大差值的两个节点值而非差值本身？
答：把 `best` 换成记录 `(差值, 祖先值, 后代值)` 三元组，比较时同步替换即可，逻辑不变。
