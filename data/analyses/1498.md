## 一句话思路
排序后对每个左端点 `i` 二分出最大合法右端点 `j`，中间元素任选，贡献 `2^(j-i)`。

## 怎么做
1. 先对 `nums` 排序，排序不改变子序列计数（子序列只看元素集合，不看原顺序）。
2. 枚举最小元素下标 `i`，在 `[i, n-1]` 上二分找最大的 `j` 使 `nums[i] + nums[j] <= target`。
3. 固定 `i` 为最小、`j` 为最大时，`nums[i+1..j-1]` 共 `j-i` 个元素可任意取舍，贡献 `2^(j-i)` 个子序列（含只取 `[nums[i]]` 的情形）。
4. 累加所有 `i` 的贡献，对 `10**9 + 7` 取余。

以 `nums = [3,5,6,7], target = 9` 为例：`i=0`（值 3）时二分得 `j=2`（值 6，3+6=9 合法，3+7=10 超），贡献 `2^(2-0)=4`，正好是示例的 4 个；`i=1`（值 5）时 `5+5=10>9`，`j` 落空，贡献 0。

```python
MOD = 10**9 + 7
nums.sort()
n = len(nums)
pow2 = [1] * (n + 1)
for k in range(1, n + 1):
    pow2[k] = pow2[k - 1] * 2 % MOD
ans = 0
for i in range(n):
    lo, hi, j = i, n - 1, -1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[i] + nums[mid] <= target:
            j = mid
            lo = mid + 1
        else:
            hi = mid - 1
    if j >= i:
        ans = (ans + pow2[j - i]) % MOD
```

## 复杂度
时间：排序 `O(n log n)`，`n` 次二分各 `O(log n)`，共 `O(n log n)`。
空间：`pow2` 表 `O(n)`，排序栈开销 `O(log n)`。

## 易错点
- `nums = [3,3,6,8], target = 10`：若把重复的 3 当成同一个元素去重，会漏掉 `[3,6]` 的两种选法，输出 5 而非 6。正确做法是不去重，两个下标各算一次，`i=0` 和 `i=1` 各贡献 `2^1=2`。
- `nums = [7], target = 9`：若二分区间写成 `[i+1, n-1]`，`j` 找不到，单元素子序列 `[7]` 被漏掉，输出 0。正确做法是区间从 `i` 开始，让 `j == i` 时贡献 `2^0 = 1`。

## 如果面试官追问
问：不排序、要求输出所有合法子序列本身怎么办？
答：排序后按 `i` 枚举，对每个 `i` 用位掩码枚举 `nums[i+1..j-1]` 的取舍，复杂度升到输出规模级别。
