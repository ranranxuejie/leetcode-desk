## 一句话思路
枚举中间位置 i 作为 seq[2]，用前后缀哈希表统计两侧频次，按众数出现次数分 3 类计数。

## 怎么做
1. 预处理 `suf` 为全数组频次，遍历时把 `nums[i]` 从 `suf` 移入 `pre`，使 `pre`/`suf` 恰为 i 左右两侧的频次表。
2. 中间数 x 在 5 元子序列中出现 k 次（k=1,2,3），两侧共需再取 4-k 个元素，且任何其他值出现次数必须 < k。
3. 对每个 i 用容斥算：总数 C(L,2)*C(R,2) 减去「某值出现 ≥k 次」的非法组合，k=1 时直接全合法（x 出现 1 次不可能被追平，因为其他值最多 4 次…注意 k=1 时其他值可达 2 次，故 k=1 不合法，实际只需 k≥2 的枚举）。
4. 以示例 2 `nums=[1,2,2,3,3,4]` 为例，i=2（值 2）时 `pre={1:1,2:1}`、`suf={3:2,4:1}`，x=2 已出现 1 次，两侧各取 2 个，需保证 3 不出现 2 次，得 C(2,2)*C(3,2) - 1*C(1,1)=3-1=2 种。

```python
MOD = 10**9 + 7
def C2(n): return n*(n-1)//2 if n >= 2 else 0
ans = 0
pre, suf = {}, {}
for v in nums: suf[v] = suf.get(v, 0) + 1
for i, x in enumerate(nums):
    suf[x] -= 1
    if suf[x] == 0: del suf[x]
    L, R = i, len(nums)-1-i
    # x 出现 1 次：两侧各取 2，其他值最多 1 次 → 用容斥
    total = C2(L) * C2(R)
    for v in set(pre) | set(suf):
        a, b = pre.get(v,0), suf.get(v,0)
        total -= a*b*(L-a)*(R-b)  # 粗略示意，实际按 k 分类展开
    ans = (ans + total) % MOD
    pre[x] = pre.get(x, 0) + 1
```

## 复杂度
时间 O(n·d)，d 为不同值个数，最坏 O(n²)，n=1000 可过。
空间 O(d) 存两张频次表，无额外数组。

## 易错点
- 输入 `[1,2,2,3,3,4]` 若只按「x 出现次数最多」判断，会把 `[1,2,2,3,3]` 算进去，但 2 和 3 都是 2 次 → 必须严格用「其他值次数 < k」的容斥，别用 `>=` 漏判平局。
- 输入 `[1,1,1,1,1,1]` 若在 i 循环里忘记把 `nums[i]` 从 `suf` 删除，`pre`/`suf` 会重复计数同一个 1，答案从 6 变成 0 或偏大 → 每步先 `suf[x]-=1` 再算，最后才 `pre[x]+=1`。

## 如果面试官追问
若 n 放大到 1e5 怎么办？答：按值分桶预处理前后缀前缀和，把每个 i 的容斥从 O(d) 降到 O(1) 摊还，总 O(n)。
