## 一句话思路
对每个顶点做一次 BFS，用「非父边碰到已访问点」的深度和更新最短环，因为环必有一棵 BFS 树的最浅点。

## 怎么做
1. 建邻接表 `adj`，遍历 `edges` 双向插入。
2. 枚举起点 `s`，从 `s` 跑 BFS，记录 `dist`（起点距离）和 `parent`（BFS 树上的父节点）。
3. 扫到 `u` 的邻居 `v` 时：若 `v` 未访问，入队并记 `dist[v]=dist[u]+1`、`parent[v]=u`；若 `v` 已访问且 `v != parent[u]`，说明 `u-v` 这条非树边与树路径合成一个环，长度 `dist[u]+dist[v]+1`，更新答案。
4. 所有起点跑完仍无更新则返回 `-1`。

以示例 1 的 `s=0` 为例：`dist[0]=0`，`1`、`2` 入队得 `dist=1`。处理 `u=1` 时邻居 `2` 已访问且 `parent[1]=0 != 2`，环长 `dist[1]+dist[2]+1 = 1+1+1 = 3`，答案锁定 3。

```python
from collections import deque

def bfs(s):
    dist = [-1] * n
    parent = [-1] * n
    dist[s] = 0
    q = deque([s])
    best = float('inf')
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                parent[v] = u
                q.append(v)
            elif v != parent[u]:
                best = min(best, dist[u] + dist[v] + 1)
    return best
```

外层对 `s in range(n)` 调用并取最小值即可。

## 复杂度
时间：每个起点一次 BFS，O(n·(n+m))，n、m 均来自顶点数与边数。
空间：`adj` 占 O(n+m)，每次 BFS 的 `dist`、`parent`、队列各 O(n)。

## 易错点
- 输入是三角形 `[[0,1],[1,2],[2,0]]` 时，若漏掉 `v != parent[u]` 判断，会把 `u` 回看父节点 `parent[u]` 当成环，算出长度 2 的错误答案；必须显式排除父边。
- 输入是示例 2 这种森林 `[[0,1],[0,2]]`，若只从顶点 0 跑一次 BFS 就返回，会漏掉其他连通块里的环；必须对每个 `s` 都跑，且 `best` 初值设 `float('inf')` 而非 0，否则 `min` 永远得 0。

## 如果面试官追问
若 n 放大到 10^5 且边稀疏，还能逐点 BFS 吗？答：不能，O(nm) 会超时，需改用「删边 + 并查集/桥」或对每个连通块做一次 BFS 配合度数剪枝。
