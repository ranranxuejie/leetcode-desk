## 一句话思路
区间 DP：枚举三角形 (i,k,j) 把多边形切成两块子多边形，`dp[i][j] = min(dp[i][k]+dp[k][j]+values[i]*values[k]*values[j])`。

## 怎么做
1. 定义 `dp[i][j]` 为顶点 i 到 j 这段连续链围成的子多边形的最低分，长度小于 3 时（i+1>=j）为 0。
2. 按区间长度 `length` 从 3 到 n 递增枚举，保证子问题先算好。
3. 对每个 (i,j) 枚举中间顶点 k ∈ (i, j)，取上式最小值。
4. 返回 `dp[0][n-1]`。

以 `values = [3,7,4,5]` 为例，n=4。先算长度 3 的区间：`dp[0][2]` 只有 k=1，得 `3*7*4=84`；`dp[1][3]` 只有 k=2，得 `7*4*5=140`。再算 `dp[0][3]`：
- k=1：`dp[0][1]+dp[1][3]+3*7*5 = 0+140+105 = 245`
- k=2：`dp[0][2]+dp[2][3]+3*4*5 = 84+0+60 = 144`

取 144，与示例一致。注意 k=1 对应三角形 (0,1,3)，k=2 对应 (0,2,3)，两条对角线各切出一种剖分。

```python
n = len(values)
dp = [[0] * n for _ in range(n)]
for length in range(3, n + 1):
    for i in range(n - length + 1):
        j = i + length - 1
        dp[i][j] = 2**31 - 1
        for k in range(i + 1, j):
            cost = dp[i][k] + dp[k][j] + values[i] * values[k] * values[j]
            if cost < dp[i][j]:
                dp[i][j] = cost
return dp[0][n - 1]
```

## 复杂度
时间：O(n³)，三层循环 length、i、k 各贡献一个 n。
空间：O(n²)，`dp` 是 n×n 表，无其他额外结构。

## 易错点
- 区间长度从 2 开始枚举 → `dp[i][j]` 在 k 循环里取到未初始化的 0，`[3,7,4,5]` 会错答 105（只算一个三角形）。必须从 length=3 起，因为 length=2 时 i+1==j 无三角形可分。
- 把 `dp[i][j]` 初值写成 0 而非大数 → 所有 cost 都大于 0，min 永远取不到，返回 0。正确做法是每轮进入 i 循环时先置 `2**31 - 1`（本题最大和约 49×100³=4.9e7，远小于该值，安全）。

## 如果面试官追问
问：n 放大到 500 还能这么做吗？
答：O(n³) 会超时，凸多边形最优三角剖分本质是矩阵链式 DP，可尝试四边形不等式优化到 O(n²)，但实现复杂，面试中先确认 n 范围。
