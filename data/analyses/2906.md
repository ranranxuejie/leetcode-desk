## 一句话思路
用前后缀积把「除自己外的乘积」拆成左侧前缀积乘右侧后缀积，避免求逆元（12345 非质数且元素可能不互素）。

## 怎么做
1. 把 `grid` 按行优先展平成一维列表 `a`，长度 `k = n*m`；答案也先存一维 `res`，最后再切回 `n` 行。
2. 正序扫一遍，`pre[i]` 表示 `a[0..i-1]` 的乘积模 12345，`pre[0] = 1`。
3. 逆序扫一遍，边扫边维护 `suf`（`a[i+1..k-1]` 的乘积模 12345），直接令 `res[i] = pre[i] * suf % 12345`，省掉后缀数组。
4. 把 `res` 按每 `m` 个一组切片返回。

以 `grid = [[1,2],[3,4]]` 为例，展平 `a = [1,2,3,4]`，`pre = [1,1,2,6]`。逆序时 `i=3` 的 `suf=1`，`res[3]=6*1=6`；`i=2` 时先把 `suf` 乘上 `a[3]=4` 得 4，`res[2]=2*4=8`；继续得 `res[1]=1*12=12`、`res[0]=1*24=24`，与输出一致。

```python
k, m = len(a), len(grid[0])
pre = [1] * k
for i in range(1, k):
    pre[i] = pre[i - 1] * a[i - 1] % 12345
res = [0] * k
suf = 1
for i in range(k - 1, -1, -1):
    res[i] = pre[i] * suf % 12345
    suf = suf * a[i] % 12345
return [res[i * m:(i + 1) * m] for i in range(k // m)]
```

## 复杂度
时间 O(n*m)：正序、逆序各扫一遍展平数组。
空间 O(n*m)：`pre` 和 `res` 各开一个长度 k 的列表，无递归。

## 易错点
- `grid = [[12345],[2],[1]]` → 若想用「总乘积 × 逆元」会翻车：12345 不是质数，`2` 和 `12345` 不互素，逆元不存在，且总乘积模 12345 恒为 0，除法还原不出 2。正确做法是前后缀积，`res[0]` 只由 `a[1]*a[2]=2` 得到。
- 元素最大 `10^9`，`pre[i-1] * a[i-1]` 在 Python 里不会溢出，但若照抄 C++ 思路先累乘再取模，中间值会到 `10^(9k)` 量级。必须在每次乘法后立刻 `% 12345`，即 `pre[i] = pre[i-1] * a[i-1] % 12345`。

## 如果面试官追问
问：若把模数换成质数 1000000007，能否用总乘积乘逆元？
答：可以，费马小定理求逆元 O(log MOD)，但元素为模数倍数时总积为 0 仍需特判，前后缀积更稳。
