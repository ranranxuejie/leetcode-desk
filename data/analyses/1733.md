## 一句话思路
枚举教的语言 L，只统计「好友双方都不含 L」的边数，取最小值。

## 怎么做
1. 先把 `languages` 每项转成 `set`，方便 O(1) 判断某人是否会某语言。
2. 遍历 `friendships`，把 `u-1, v-1` 转成 0 基下标；若两人语言集合无交集，这条边记为「待修复」，存入 `bad`。
3. 对每种语言 `L in 1..n`，数 `bad` 中有多少条边两端都不会 `L`，这就是教 `L` 需要的人数。
4. 返回这些计数的最小值；`bad` 为空时直接返回 0。

以示例 1 为例：`languages = [{1},{2},{1,2}]`，三条好友边中 `(1,2)` 两端是 `{1}` 和 `{2}`，交集为空，进 `bad`；`(1,3)`、`(2,3)` 都有公共语言，不进。于是 `bad = [(0,1)]`。枚举 `L=1`：用户 0 会 1，用户 1 不会，计数 1；`L=2`：用户 0 不会，计数 1。答案 1。

```python
langs = [set(x) for x in languages]
bad = []
for u, v in friendships:
    a, b = u - 1, v - 1
    if not (langs[a] & langs[b]):
        bad.append((a, b))

best = len(bad)
for L in range(1, n + 1):
    cnt = sum(1 for a, b in bad if L not in langs[a] and L not in langs[b])
    best = min(best, cnt)
return best
```

关键点：一条边只要有一端会 `L`，就无需再教；只有两端都不会才 +1。`best` 初值取 `len(bad)` 是安全的，因为任意语言最多也就教 `len(bad)` 人。

## 复杂度
时间：O(F + n·F)，F 为好友边数，`bad` 最多 F 条，枚举 n 种语言各扫一遍。
空间：O(F) 存 `bad`，外加 `langs` 的集合开销，与 n 无关。

## 易错点
- 输入 `friendships` 是 1 基下标，`languages` 是 0 基列表：直接写 `langs[u]` 会越界或错位。必须先 `u-1, v-1`，示例 1 中 `[1,2]` 对应 `langs[0]` 和 `langs[1]`。
- 把「已能沟通的好友」也算进待教人数：示例 1 的 `(1,3)` 两人都会语言 1，若不过滤 `bad`，枚举 `L=1` 会得到 3 而非 1。正确做法是先筛出交集为空的边，再在 `bad` 上计数。

## 如果面试官追问
要求输出具体教谁？答：对最优 `L` 再扫一遍 `bad`，把不会 `L` 的那端下标收集起来即可，代价仍是 O(F)。
