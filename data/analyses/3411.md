## 一句话思路
n≤100 且 nums[i]≤10，直接枚举所有子数组，用 gcd/lcm 递推判断 prod==lcm*gcd。

## 怎么做
1. 外层枚举左端点 i，内层从 i 向右扩展 j，边扩展边维护 p、g、l。
2. 扩展时更新：`g = gcd(g, x)`，`l = l * x // gcd(l, x)`，`p *= x`。
3. 每次扩展后判断 `p == l * g`，成立就更新答案。
4. 以 nums=[2,3,4,5,6] 为例，i=1 时扩展 j=1→3：p 从 3 变 12 变 60，g 恒为 1，l 从 3 变 12 变 60；j=3 时 p=60、l*g=60，长度 3 命中答案。

```python
from math import gcd
ans = 0
n = len(nums)
for i in range(n):
    p, g, l = 1, 0, 1
    for j in range(i, n):
        x = nums[j]
        p *= x
        g = gcd(g, x)
        l = l * x // gcd(l, x)
        if p == l * g:
            ans = max(ans, j - i + 1)
```

注意 g 初值取 0（gcd(0,x)=x），l 初值取 1，这样单元素子数组也能正确判等。

## 复杂度
时间 O(n² log max(nums))：n² 对子数组，每次两次 gcd 各 O(log 10)。
空间 O(1)：只开了 p、g、l、ans 四个标量。

## 易错点
- 用 `l = l * x // gcd(l, x)` 而不是 `l * x`：nums=[2,3,4,5,6] 中 l 会涨到 60，若先乘后除顺序写反（`l*x//gcd` 写成 `l//gcd*x`）在 l 不整除时结果错，必须保证先乘再整除。
- g 初值写成 1 而非 0：nums=[2,3,4,5,6] 从 i=1 起 g 会一直是 1，看似没事，但若子数组首元素是 1，gcd(1,1)=1 掩盖问题；正确用 0 让 gcd(0,x)=x 自然接管。

## 如果面试官追问
若 nums[i] 放大到 10^9、n 到 10^5 怎么办？答：乘积会爆，改用质因子指数向量比较，或利用 prod==lcm*gcd 等价于元素两两「互不共享质因子」的更强条件做滑动窗口。
