## 一句话思路
从右往左扫，用栈维护已确定的组，靠「追及时间」判断左侧机器人能否并入右侧组。

## 怎么做
1. 从最右机器人开始，栈里存每个组的 `(位置, 速度)`，初始只有最后一个机器人。
2. 向左遍历每个机器人 `i`，用 `(pos_r - position[i]) / (speed[i] - speed_r)` 算它追上栈顶组所需时间；若 `speed[i] <= speed_r` 则永远追不上。
3. 追不上就新开一组压栈；追得上就弹出栈顶、继续和新的栈顶比，直到追不上或栈空。
4. 栈的大小就是答案。

以示例 1 `position=[1,5,6,20], speed=[4,3,2,3], distance=1` 为例：先压入 `(20,3)`；`i=2` 是 `(6,2)`，`speed 2 < 3` 追不上，压栈得 `[(20,3),(6,2)]`；`i=1` 是 `(5,3)`，对栈顶 `(6,2)` 算得 `(6-5)/(3-2)=1` 秒追上，弹出；再对 `(20,3)` 算得 `(20-5)/(3-3)` 除零，说明速度相等追不上，压栈；`i=0` 是 `(1,4)`，对 `(5,3)` 算得 `(5-1)/(4-3)=4` 秒追上，弹出，栈最终剩 `[(20,3),(1,4)]`，答案 2。

```python
stack = [(position[-1], speed[-1])]
for i in range(len(position) - 2, -1, -1):
    p, v = position[i], speed[i]
    while stack:
        pr, vr = stack[-1]
        if v <= vr:
            break
        if (pr - p) / (v - vr) > distance:
            break
        stack.pop()
    stack.append((p, v))
return len(stack)
```

关键在 `> distance` 这个比较：追及时间超过 `distance` 秒，说明在合并距离内追不上，必须新开组。

## 复杂度
时间 O(n)：每个机器人最多入栈出栈各一次，n 为 `position` 长度。
空间 O(n)：栈最多存 n 个组。

## 易错点
- `speed[i] == speed_r` 时直接除零崩溃 → 正确做法是先判 `v <= vr` 就 `break`，速度相等永远追不上。
- 用 `>= distance` 而非 `> distance` 判追不上 → 示例 1 中 `(6-5)/(3-2)=1` 恰好等于 `distance=1`，用 `>=` 会漏掉这次合并，答案错成 3；正确是 `> distance` 才 break。

## 如果面试官追问
问：若要求输出每个组的成员下标列表？答：栈元素从 `(p,v)` 改成 `(p,v,成员列表)`，弹出时把被并组的列表 `extend` 进当前组即可。
