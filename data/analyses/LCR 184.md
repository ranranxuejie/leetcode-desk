## 一句话思路
用「普通队列 + 单调递减双端队列」同步维护，单调队列头始终是当前队列最大值。

## 怎么做
1. 开两个结构：`q` 存真实入队顺序（`collections.deque`），`dq` 存候选最大值、从头到尾单调递减。
2. `add(v)`：`q.append(v)`；然后 `while dq and dq[-1] < v: dq.pop()`，再 `dq.append(v)`——把尾部所有比 `v` 小的都弹掉，它们永远不可能再当最大值。
3. `remove()`：`q` 为空返回 `-1`；否则 `x = q.popleft()`，若 `dq[0] == x` 则 `dq.popleft()`（只有队头那个最大值被真正移走时才同步弹出）。
4. `get_max()`：`q` 为空返回 `-1`，否则返回 `dq[0]`。

以示例 1 走关键一步：`add(4)` 后 `q=[4], dq=[4]`；`add(7)` 时 `dq[-1]=4 < 7`，弹出 4，`dq=[7]`，此时 `get_max()` 返回 `dq[0]=7`。接着 `remove()` 弹出 `q` 的 4，`dq[0]=7 != 4` 故 `dq` 不动；再 `get_max()` 仍是 7——这正是示例输出 `7,4,7` 中第二个 7 的来源。

```python
from collections import deque

q, dq = deque(), deque()

def add(v):
    q.append(v)
    while dq and dq[-1] < v:
        dq.pop()
    dq.append(v)

def remove():
    if not q:
        return -1
    x = q.popleft()
    if dq[0] == x:
        dq.popleft()
    return x

def get_max():
    return dq[0] if dq else -1
```

## 复杂度
时间：每次操作均摊 O(1)，每个元素最多进/出 `dq` 各一次，总 O(n)。
空间：O(n)，`q` 与 `dq` 各最多存 n 个元素。

## 易错点
- `add(7)` 时若只写 `if dq[-1] < v` 弹一次而非 `while`，遇到 `add(4), add(7), add(9)` 会残留 `dq=[7,9]` 之类错误结构，`get_max` 仍对但 `remove` 同步会错位；必须用 `while` 弹到 `dq[-1] >= v`。
- `remove()` 里若不加 `dq[0] == x` 判断就无条件 `dq.popleft()`，示例 1 中移除 4 会把 7 一起弹掉，第二次 `get_max()` 错成 -1；只有被移除值恰是 `dq` 队头时才同步弹出。

## 如果面试官追问
若要求 `get_min()` 同时支持？再开一个单调递增双端队列，`add` 时用 `while dq_min[-1] > v` 弹尾，其余逻辑对称。
