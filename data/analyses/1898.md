## 一句话思路
删除前 k 个下标后 p 是否仍是子序列，这个判定对 k 单调（k 越大越难成立），所以二分 k，每次用双指针扫一遍 s 验证。

## 怎么做
1. 把 `removable[:k]` 的下标集合先标记出来，用一个 `set` 或布尔数组 `dead`。
2. 双指针扫 s：`i` 走 s，`j` 走 p，遇到 `dead[i]` 就跳过，字符相等则 `j += 1`。
3. 扫完看 `j == len(p)` 是否成立，成立说明 k 可行。
4. 在 `[0, len(removable)]` 上二分，找最大的可行 k。

拿示例 1 说：`s="abcacb"`, `p="ab"`, `removable=[3,1,0]`。试 `k=2`，dead={3,1}，扫 s 得 i=0 的 'a' 匹配 j→1，i=1 跳过，i=2 的 'c' 不匹配，i=3 跳过，i=4 的 'c' 不匹配，i=5 的 'b' 匹配 j→2，`j==2` 成立；试 `k=3`，dead={3,1,0}，i=0 跳过，i=2 起只剩 "ccb"，'a' 再也匹配不上，`j` 停在 0，失败。故答案 2。

```python
def ok(k):
    dead = set(removable[:k])
    j = 0
    for i, ch in enumerate(s):
        if i in dead:
            continue
        if j < len(p) and ch == p[j]:
            j += 1
    return j == len(p)

lo, hi = 0, len(removable)
while lo < hi:
    mid = (lo + hi + 1) // 2
    if ok(mid):
        lo = mid
    else:
        hi = mid - 1
return lo
```

注意 `mid = (lo + hi + 1) // 2` 是上取整，配合 `lo = mid` 才不会死循环。

## 复杂度
时间：二分 log(len(removable)) 次，每次 O(len(s)) 扫一遍，共 O(n log m)。
空间：`dead` 集合最多存 k 个下标，O(m) 额外空间。

## 易错点
- 二分写 `mid = (lo + hi) // 2` 配 `lo = mid`：当 `lo=1, hi=2` 时 mid 恒为 1，死循环。必须上取整 `(lo + hi + 1) // 2`，或改成 `lo = mid + 1` 的写法。
- 判定时忘了 `j < len(p)` 的边界：p 已全部匹配完还继续比 `ch == p[j]`，会 `IndexError`。示例 1 中 k=2 扫到 i=5 时 j 已到 2，必须靠这个判断挡住。

## 如果面试官追问
问：如果 removable 不是前 k 个而是任意子集，还能二分吗？
答：不能，单调性没了，只能退化成枚举子集或贪心，规模大时不可行。
