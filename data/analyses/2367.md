## 一句话思路
把 nums 丢进 set，枚举中间元素 j，检查 `nums[j]-diff` 和 `nums[j]+diff` 是否都在集合里。

## 怎么做
1. 用 `set(nums)` 建哈希集合 `s`，O(1) 判断某个值是否存在。
2. 遍历 `nums` 中每个元素作为中间项 `x`（即 nums[j]），检查 `x - diff in s and x + diff in s`。
3. 成立就 `ans += 1`，因为 nums 严格递增，每个中间值唯一确定一个三元组，不会重复计数。

以示例 1 `nums = [0,1,4,6,7,10], diff = 3` 为例：遍历到 `x = 4` 时，`4-3=1` 在集合中、`4+3=7` 也在集合中，计数 +1；遍历到 `x = 7` 时，`7-3=4`、`7+3=10` 都在，再 +1；其余 x 至少缺一边，最终 `ans = 2`。

```python
s = set(nums)
ans = 0
for x in nums:
    if x - diff in s and x + diff in s:
        ans += 1
return ans
```

注意这里枚举的是**值**而不是下标：因为数组严格递增，值唯一对应下标，且 `x-diff < x < x+diff` 自动保证下标顺序 i<j<k，无需再比较下标。

## 复杂度
时间 O(n)：建集合 O(n)，遍历 n 个元素每次两次哈希查询 O(1)。
空间 O(n)：额外开了一个大小为 n 的 set，无其他结构。

## 易错点
- 输入 `nums = [4,5,6,7,8,9], diff = 2` → 若误用双指针固定 i 再找 j、k，容易在 j 移动时漏掉 `(1,3,5)` 这组 → 正确做法是枚举中间项 x，一次判断两端，天然覆盖所有组合。
- 输入 `nums = [0,1,4,6,7,10], diff = 3` → 若把 `x - diff in s` 写成 `x - diff in nums`，每次查询 O(n)，退化成 O(n²)，n=200 虽能过但思路错 → 必须先 `s = set(nums)`，查询走集合。

## 如果面试官追问
问：若 nums 不严格递增、含重复值，怎么改？
答：先 `Counter(nums)` 去重计数，枚举中间值 x 时答案加 `cnt[x-diff] * cnt[x] * cnt[x+diff]`，注意 x 自身重复也要算。
