## 一句话思路
把数字和字母分到两个列表，数量差超过 1 就返回空串，否则从多的那类开始交替拼接。

## 怎么做
1. 遍历 `s`，用 `s[i].isdigit()` 分流到 `digits` 和 `letters` 两个列表。
2. 若 `abs(len(digits) - len(letters)) > 1`，直接返回 `""`。
3. 令 `longer` 为元素多的那个列表，`shorter` 为另一个，用 `zip` 交替取，长度不等时补上 `longer` 末尾多出的一个。
4. 用 `"".join(...)` 拼成结果。

以示例 4 `s = "covid2019"` 为例：`letters = ['c','o','v','i','d']`（5 个），`digits = ['2','0','1','9']`（4 个）。差为 1 合法，`longer = letters`，所以结果必须以字母开头，交替后得到 `"c2o0v1i9d"`，末尾多出的 `'d'` 单独补上。

```python
digits, letters = [], []
for ch in s:
    (digits if ch.isdigit() else letters).append(ch)
if abs(len(digits) - len(letters)) > 1:
    return ""
longer, shorter = (digits, letters) if len(digits) >= len(letters) else (letters, digits)
res = []
for a, b in zip(longer, shorter):
    res.append(a)
    res.append(b)
if len(longer) > len(shorter):
    res.append(longer[-1])
return "".join(res)
```

关键点：`longer` 的选择决定了首字符类型。示例 5 `s = "ab123"` 中 `letters` 有 2 个、`digits` 有 3 个，`longer = digits`，所以输出 `"1a2b3"` 以数字开头；若误从字母开头会得到 `"a1b23"`，末尾两个数字相邻，非法。

## 复杂度
时间 O(n)：一次遍历分流加一次拼接，n 为 `len(s)`。
空间 O(n)：`digits`、`letters`、`res` 三个列表合计存 n 个字符。

## 易错点
- 输入 `s = "aa00"`（字母数字各 2 个）→ 若先判断「字母多才字母开头」会漏掉相等的情况 → 相等时 `longer` 取哪个都行，但必须保证交替后不剩两个同类相邻，用 `zip` 加末尾补一个的写法天然正确。
- 输入 `s = "a"`（只有 1 个字母）→ 若只检查「两类都非空」会误返回空串 → 正确判据是数量差 ≤ 1，`"a"` 差为 1 合法，应返回 `"a"`。

## 如果面试官追问
问：若要求返回字典序最小的合法结果怎么办？
答：交替位置固定后，把 `digits` 和 `letters` 各自排序再按同样顺序拼接即可。
