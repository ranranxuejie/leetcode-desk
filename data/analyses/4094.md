## 一句话思路
枚举左端点，向右扩展时维护「首次出现顺序」的频次表，一旦某值频次超过其序号就剪枝，符合阶梯就计数。

## 怎么做
1. 外层 `l` 从 0 到 n-1，内层 `r` 从 `l` 向右扩展，用 `order` 列表记录首次出现的值、`cnt` 字典记频次。
2. 遇到新值 `x` 时，它将成为第 `len(order)+1` 个不同值，要求最终频次恰为 `len(order)+1`；先把 `x` 追加进 `order`，`cnt[x]=1`。
3. 每次扩展后检查：对 `order` 中第 `i` 个值（0 起），若 `cnt[order[i]] > i+1` 则永久非法，`break`；若全部 `cnt[order[i]] == i+1` 则 `ans += 1`。
4. 剪枝依据：频次只增不减，一旦超过 `i+1` 就再也回不来。

以 `nums = [5,8,8,2,2,2]`、`l=0` 为例：`r=0` 时 `order=[5], cnt={5:1}`，`1==1` 计数；`r=1` 时 `order=[5,8], cnt={5:1,8:1}`，第 2 个值 `8` 需 2 次但只有 1 次，不计数；`r=2` 时 `cnt[8]=2`，`[1,2]` 计数；`r=5` 时 `cnt={5:1,8:2,2:3}`，`[1,2,3]` 计数。该 `l` 贡献 3。

```python
for l in range(n):
    order, cnt = [], {}
    for r in range(l, n):
        x = nums[r]
        if x not in cnt:
            order.append(x)
            cnt[x] = 0
        cnt[x] += 1
        ok = True
        for i, v in enumerate(order):
            if cnt[v] > i + 1:
                ok = False
                break
        if not ok:
            break
        if all(cnt[v] == i + 1 for i, v in enumerate(order)):
            ans += 1
```

## 复杂度
时间：O(n²·k)，k 为不同值个数，最坏 O(n³)，n=1500 时靠剪枝实际远小于此。
空间：O(n)，`order` 与 `cnt` 最多存 n 个不同值。

## 易错点
- 输入 `[6,6,9,9]`：若只比较「频次集合是否等于 {1..k}」而不看首次出现顺序，会把 `nums[0...3]=[6,6,9,9]`（频次 2,2）误判；必须按 `order` 下标逐位比对 `cnt[order[i]] == i+1`。
- 输入 `[2,3,4,4,3,4]`：若在 `cnt[v] > i+1` 时只跳过不 `break`，会继续扩展并可能因后续值凑巧满足而误计；频次单调递增，超限即永久非法，必须 `break` 内层。

## 如果面试官追问
若 n 放大到 10⁵ 怎么办？答：利用「阶梯总长 = 1+2+...+k ≤ n」限制 k ≤ O(√n)，配合按值分块或双指针维护首次出现位置，把每左端点的扩展步数压到 O(√n)。
