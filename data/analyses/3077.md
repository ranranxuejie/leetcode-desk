## 一句话思路
按「第 i 段乘 (k-i+1)、符号交替」把系数摊到每个元素上，用 dp[j] 表示已选 j 段、当前元素在段内/段外的最大能量。

## 怎么做
1. 把能量式拆成逐元素贡献：第 i 段每个元素乘 `(k-i+1) * (-1)^(i+1)`，所以选第 j 段时系数是 `c = (k-j+1) if j%2==1 else -(k-j+1)`。
2. 定义 `dp[j]` = 处理到当前下标、已开 j 段且当前元素**在**第 j 段内的最大值；`best[j]` = 已开 j 段、当前元素**不在**段内的最大值（即可以随时开新段）。
3. 对每个 `x` 从后往前更新 j（避免同一元素被用两次）：`dp[j] = max(dp[j], best[j-1]) + c_j * x`，再 `best[j] = max(best[j], dp[j])`。
4. 用示例 1 `nums=[1,2,3,-1,2], k=3`：处理到 `x=3` 时 j=1 的 `dp[1]=6`（段和 1+2+3），j=2 的 `dp[2]=6-2*3=0`，j=3 的 `dp[3]=0+1*3=3`；最终 `best[3]=22`。

```python
n, NEG = len(nums), -10**30
dp = [NEG] * (k + 1)
best = [NEG] * (k + 1)
best[0] = 0
for x in nums:
    for j in range(min(k, n), 0, -1):
        c = (k - j + 1) if j % 2 == 1 else -(k - j + 1)
        dp[j] = max(dp[j], best[j - 1]) + c * x
        best[j] = max(best[j], dp[j])
return best[k]
```

## 复杂度
时间 O(n·k)，n 来自遍历 nums，k 来自内层段数循环。
空间 O(k)，只开 dp 和 best 两个长度 k+1 的数组。

## 易错点
- `nums=[-1,-2,-3], k=1`：若把 `best[0]` 初始化成 0 又允许「不开段直接取 max」，会返回 0 而非 -1；必须强制恰好选 k 段，用 `NEG` 占位且只从 `best[j-1]` 转移。
- 内层 j 若从小到大遍历，同一个 `x` 会先更新 `dp[j]` 再被 `dp[j+1]` 复用，等于把 `x` 算进两段；必须 `range(..., 0, -1)` 倒序。

## 如果面试官追问
要求输出具体选了哪些子数组怎么办？答：在 `best[j]` 更新时记录前驱下标和「开段/续段」标记，最后从 `best[k]` 回溯即可，空间升到 O(n·k)。
