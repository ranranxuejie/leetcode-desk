## 一句话思路
排序后枚举「选中人数 k」，只需检查分界点两侧的 `nums[k-1] < k` 与 `nums[k] > k` 是否同时成立。

## 怎么做
1. 把 `nums` 升序排序，这样「选中的 k 人」一定是最小的 k 个，选中集合只由 k 决定。
2. 枚举 k 从 0 到 n，k=0 和 k=n 单独处理（边界没有分界点，只需一侧条件）。
3. 对 1≤k≤n-1，检查 `nums[k-1] < k`（被选中的最大值也严格小于 k）且 `nums[k] > k`（未选中的最小值严格大于 k）。
4. 两个条件都成立则计数加一。

以 `nums = [6,0,3,3,6,7,2,7]` 为例，排序后为 `[0,2,3,3,6,6,7,7]`，n=8。
k=1：`nums[0]=0 < 1` 且 `nums[1]=2 > 1`，成立。
k=4：`nums[3]=3 < 4` 且 `nums[4]=6 > 4`，成立。
k=8：全选，`nums[7]=7 < 8`，成立。共 3 种，与示例一致。
k=2 时 `nums[1]=2 < 2` 不成立（严格小于），k=3 时 `nums[2]=3 < 3` 不成立，都排除。

```python
nums.sort()
n = len(nums)
ans = 1  # k = 0，空组恒成立
for k in range(1, n):
    if nums[k - 1] < k and nums[k] > k:
        ans += 1
if nums[-1] < n:  # k = n，全选
    ans += 1
return ans
```

关键点：排序后只需看两个相邻元素，因为选中集合内所有值 ≤ `nums[k-1]`，未选中集合内所有值 ≥ `nums[k]`，检查这两个极值就覆盖了全部学生。

## 复杂度
时间：排序 O(n log n)，枚举 O(n)，共 O(n log n)。
空间：排序栈开销 O(log n)，其余 O(1)。

## 易错点
- 把条件写成 `<=` / `>=`：如 `nums=[1,1]`，k=1 时 `nums[0]=1 < 1` 为假，若写成 `<=` 会误判为可行，答案从 2 变成 3。题面要求「严格大于 / 严格小于」，必须用 `<` 和 `>`。
- 漏掉 k=0 或 k=n 的边界：如 `nums=[0]`，k=0 空组和 k=1 全选都成立，答案 2；若循环只写 `range(1, n)` 且不单独加 `ans=1` 和全选判断，会输出 0。空组恒成立，全选需 `nums[-1] < n`。

## 如果面试官追问
若要求输出所有可行分组方案而非计数？答：排序后对每个满足条件的 k 直接取前 k 个下标即可，O(n log n) 时间、O(n) 输出。
