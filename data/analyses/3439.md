## 一句话思路
枚举被「清空」的连续 k 个会议，用前缀和 O(1) 算出合并后的空档，取最大。

## 怎么做
1. 把会议之间的空档和首尾空档都看成数组 `gap`：`gap[0]=startTime[0]`，`gap[i]=startTime[i]-endTime[i-1]`，`gap[n]=eventTime-endTime[n-1]`。
2. 移走连续 k 个会议 `[i, i+k-1]` 后，`gap[i]` 到 `gap[i+k]` 这 k+1 段空档会连成一片，长度是它们之和。
3. 用前缀和 `pre` 让这个和变成 `pre[i+k+1]-pre[i]`，滑一遍取最大。
4. 注意 k 个会议被移走后要能塞进别处，但题目只问空档，不用真的排。

以示例 2 为例：`eventTime=10`，会议 `[0,1],[2,4],[9,10]`，`gap=[0,1,5,0]`。k=1 时枚举 i=1，合并 `gap[1]+gap[2]=1+5=6`，正是答案。

```python
n = len(startTime)
gap = [startTime[0]]
for i in range(1, n):
    gap.append(startTime[i] - endTime[i - 1])
gap.append(eventTime - endTime[-1])

pre = [0] * (len(gap) + 1)
for i, g in enumerate(gap):
    pre[i + 1] = pre[i] + g

ans = 0
for i in range(n - k + 1):
    ans = max(ans, pre[i + k + 1] - pre[i])
return ans
```

## 复杂度
时间 O(n)：建 gap、前缀和、滑窗各扫一遍。
空间 O(n)：gap 和 pre 各开 n+1 长度。

## 易错点
- 只算中间空档漏掉首尾：`startTime[0]=1` 时 `gap[0]=1` 必须计入，否则示例 1 会得 1 而不是 2。
- 窗口长度写成 k 而不是 k+1：移走 k 个会议合并的是 k+1 段空档，`pre[i+k+1]-pre[i]` 的右端点差是 k+1，写成 `pre[i+k]-pre[i]` 会少算一段。

## 如果面试官追问
问：k 很大接近 n 怎么办？
答：公式不变，i 只取 0，合并全部 gap，即 `eventTime` 减去所有会议总时长。
