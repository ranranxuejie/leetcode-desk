## 一句话思路
用「减法加速」：把除数不断翻倍，一次减掉尽可能大的 2^k 倍，商按位累加，避免逐次减一。

## 怎么做
1. 先处理符号与溢出：`a == -2**31 and b == -1` 直接返回 `2**31 - 1`，其余情况把 `a`、`b` 都转成负数再算，避免 `abs(-2**31)` 越界。
2. 用 `sign = -1 if (a < 0) != (b < 0) else 1` 记录结果符号，之后只处理负数。
3. 每轮从 `d = b`、`q = 1` 开始，当 `d >= a - d`（即 `2*d` 不会小于 `a`）时把 `d` 翻倍、`q` 翻倍，得到本轮最大倍数。
4. 把 `q` 累加进 `res`，`a -= d`，重复直到 `a > b`。

以 `a = 15, b = 2` 为例：转负数后 `a = -15, b = -2`。第一轮 `d = -2, q = 1`，翻倍到 `d = -8, q = 4` 时 `2*d = -16 < -15` 停止，`res += 4`，`a = -7`；第二轮 `d = -2, q = 1` 翻倍到 `d = -4, q = 2`，`res += 2`，`a = -3`；第三轮 `d = -2, q = 1`，`res += 1`，`a = -1`，结束，`res = 7`。

```python
def divide(a, b):
    if a == -2**31 and b == -1:
        return 2**31 - 1
    sign = -1 if (a < 0) != (b < 0) else 1
    a, b = (a if a < 0 else -a), (b if b < 0 else -b)
    res = 0
    while a <= b:
        d, q = b, 1
        while d >= a - d:
            d += d
            q += q
        res += q
        a -= d
    return sign * res
```

## 复杂度
时间：O(log²|a|)，外层每轮至少减半 `a`，内层翻倍最多 log|a| 次。
空间：O(1)，只用了 `d`、`q`、`res` 几个整数变量。

## 易错点
1. 输入 `a = -2**31, b = -1` → 若先取绝对值再算，`abs(-2**31)` 在 32 位语义下越界，或结果 `2**31` 超出上界 → 正确做法是在函数开头单独判断这组输入，直接返回 `2**31 - 1`。
2. 输入 `a = -2**31, b = 1` → 若统一转正数处理，`-a` 会溢出 → 正确做法是全程用负数运算（负数范围比正数多一个 `-2**31`），只在最后乘 `sign`。

## 如果面试官追问
问：如果允许用乘法，能否更快？答：可以，用 `b * 2**k` 直接二分找最大 `k`，把内层翻倍换成位运算，仍是 O(log²|a|) 但常数更小。
