## 一句话思路
固定右端点 r，用滑动窗口维护最小左端点 l，使 `(前缀和差) * 长度 < k`，则所有以 r 结尾的合法子数组恰有 `r - l + 1` 个。

## 怎么做
1. 用 `left` 指向窗口左端，`total` 维护 `nums[left..right]` 的和，`right` 从 0 遍历到 n-1。
2. 每步先 `total += nums[right]`，然后 `while total * (right - left + 1) >= k` 就 `total -= nums[left]; left += 1`。
3. 收缩结束后，以 `right` 结尾、起点在 `[left, right]` 的子数组全部合法，累加 `right - left + 1`。
4. 以示例 1 的 `nums = [2,1,4,3,5], k = 10` 为例：`right=2` 时窗口为 `[2,1,4]`，`total=7`，`7*3=21 >= 10`，移出 2 得 `total=5, left=1`，`5*2=10 >= 10`，再移出 1 得 `total=4, left=2`，`4*1=4 < 10` 停，累加 `2-2+1=1`。

```python
left = total = ans = 0
for right, x in enumerate(nums):
    total += x
    while total * (right - left + 1) >= k:
        total -= nums[left]
        left += 1
    ans += right - left + 1
return ans
```

关键点：`total` 是窗口和而非全局前缀和，收缩时同步减掉 `nums[left]`，两者始终一致。

## 复杂度
时间：O(n)，`right` 和 `left` 各单调前进至多 n 次，内层 while 总摊还 O(n)。
空间：O(1)，只开了 `left`、`total`、`ans` 三个标量。

## 易错点
- 写成 `total * (right - left + 1) > k` 才收缩 → 示例 1 中 `[1,4]` 分数恰为 10，会被误算合法，答案变 7。题目要求严格小于，条件必须是 `>= k` 才收缩。
- 用 `total` 当全局前缀和、收缩时忘记减 `nums[left]` → 窗口和虚高，`left` 被推过头，示例 2 的 `[1,1,1]` 会漏算。正确做法是每移出一次就 `total -= nums[left]`。

## 如果面试官追问
问：若 nums 含 0 或负数，滑动窗口还成立吗？
答：不成立，窗口和不再随长度单调增，需改前缀和加二分或双指针失效后另寻单调性。
