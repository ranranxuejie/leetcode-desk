## 一句话思路
用一个栈按顺序存每个有效回合的得分，四种操作分别对应压入、压入、弹出、读栈顶，最后求和。

## 怎么做
1. 建空栈 `stack`，遍历 `ops` 里每个字符串 `op`。
2. 若 `op` 是 `"+"`，把 `stack[-1] + stack[-2]` 压栈；若 `"D"`，压 `2 * stack[-1]`；若 `"C"`，`stack.pop()`。
3. 否则 `op` 是整数字符串，`int(op)` 压栈。
4. 遍历结束后返回 `sum(stack)`。

以示例 2 的 `["5","-2","4","C","D","9","+","+"]` 为例，走到第二个 `"+"` 时栈是 `[5, -2, -4, 9, 5]`，取 `stack[-1]=5` 与 `stack[-2]=9`，压入 `14`，栈变 `[5, -2, -4, 9, 5, 14]`，`sum` 得 27。

```python
stack = []
for op in ops:
    if op == "+":
        stack.append(stack[-1] + stack[-2])
    elif op == "D":
        stack.append(2 * stack[-1])
    elif op == "C":
        stack.pop()
    else:
        stack.append(int(op))
return sum(stack)
```

关键点：`"C"` 只删栈顶，不删更早的；`"+"` 取的是**当前栈顶两个**，不是原始数组里前两个元素，因为中间可能已被 `"C"` 删过。

## 复杂度
时间 O(n)：n 为 `ops` 长度，每个操作 O(1)，最后 `sum` 再扫一遍栈。
空间 O(n)：栈最多存 n 个得分，无其他额外结构。

## 易错点
- 输入含 `"C"` 后再接 `"+"`，如示例 2 的 `["5","-2","4","C","D","+"]`：若按原始 `ops` 下标找「前两次得分」，会取到已被删的 `4` 和 `-2`，错算成 `2`；正确做法是只从 `stack` 尾部取 `stack[-1]`、`stack[-2]`，此时应是 `-2 + (-4) = -6`。
- 输入含负数如 `"-2"`：若用 `op.isdigit()` 判断是否整数，`"-2".isdigit()` 为 `False`，会误入 `"C"`/`"D"`/`"+"` 分支或漏压栈；正确做法是先用 `op in ("+", "D", "C")` 排除三种符号，剩下的直接 `int(op)`。

## 如果面试官追问
问：若要求返回每一步操作后的累计总分而非最终值？答：维护一个 `total` 变量，压栈时加、`"C"` 弹出时减，每步把 `total` 追加到结果列表。
