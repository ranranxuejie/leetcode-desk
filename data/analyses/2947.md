## 一句话思路
把元音记 +1、辅音记 −1 做前缀和，两个前缀和相等即元音数等于辅音数，再按长度校验乘积整除 k。

## 怎么做
1. 预处理 `diff[i]`：`s[i]` 是元音则 `diff[i+1] = diff[i] + 1`，否则 `diff[i+1] = diff[i] - 1`。
2. 枚举左端点 `i` 和右端点 `j`（`j > i`），子串 `s[i:j]` 的元音数 `v = (j - i + diff[j] - diff[i]) // 2`。
3. 若 `diff[j] == diff[i]` 且 `v * v % k == 0`，计数加一。

以 `s = "baeyh", k = 2` 为例，`diff = [0, -1, 0, 1, 2, 1]`。取 `i = 1, j = 5`（子串 `"aeyh"`）：`diff[5] == diff[1] == -1`，长度 4，`v = (4 + (-1) - (-1)) // 2 = 2`，`2 * 2 % 2 == 0`，命中。

```python
n = len(s)
diff = [0] * (n + 1)
for i, ch in enumerate(s):
    diff[i + 1] = diff[i] + (1 if ch in "aeiou" else -1)

ans = 0
for i in range(n):
    for j in range(i + 1, n + 1):
        if diff[j] != diff[i]:
            continue
        v = (j - i) // 2
        if v * v % k == 0:
            ans += 1
```

注意 `diff[j] == diff[i]` 时长度必为偶数，`v = (j - i) // 2` 直接成立，不必再套上面的公式。

## 复杂度
时间：O(n²)，双重枚举左右端点，n 为 `len(s)`。
空间：O(n)，只开了长度 n+1 的 `diff` 数组。

## 易错点
- `s = "abba", k = 1` 时若只判 `diff[j] == diff[i]` 就计数，会把 `"bb"`（v=0, c=2）算进去；必须同时要求 `v * v % k == 0`，`v=0` 时乘积为 0 恒被 k 整除，但 `diff` 相等已排除 v≠c 的情况，真正要防的是漏掉 `v * v` 这步校验。
- `s = "bcdf", k = 1` 全辅音，`diff` 单调递减永不相等，若把 `j` 从 `i` 开始枚举（允许空串）会误判 `diff[i] == diff[i]` 成立、`v = 0`、`0 % 1 == 0`，凭空多算 n+1 个；`j` 必须从 `i + 1` 起。

## 如果面试官追问
若 n 放大到 10⁵ 怎么办？答：按 `diff` 值分桶，桶内再按子串长度模 k 的余数分组，用哈希表 O(n) 统计同余对。
