## 一句话思路
用滑动窗口维护一个「至多含两种水果」的区间，右指针每步扩张、左指针只在种类超 2 时收缩，窗口长度最大值即答案。

## 怎么做
1. 初始化 `left = 0`、`cnt = {}`（水果种类 → 窗口内出现次数）、`ans = 0`。
2. 右指针 `right` 从 0 遍历到 `len(fruits)-1`，把 `fruits[right]` 计入 `cnt`。
3. 当 `len(cnt) > 2` 时，循环把 `fruits[left]` 的计数减 1，减到 0 就 `del cnt[fruits[left]]`，然后 `left += 1`。
4. 每轮用 `right - left + 1` 更新 `ans`。

以 `fruits = [1,2,3,2,2]` 为例：`right=2` 时窗口是 `[1,2,3]`，`cnt = {1:1, 2:1, 3:1}`，`len(cnt)=3 > 2`，于是 `left` 从 0 挪到 1，`cnt` 变成 `{2:1, 3:1}`，窗口 `[2,3]` 长度 2；继续扩张到 `right=4` 时窗口 `[2,3,2,2]` 长度 4，即答案。

```python
left, ans, cnt = 0, 0, {}
for right, f in enumerate(fruits):
    cnt[f] = cnt.get(f, 0) + 1
    while len(cnt) > 2:
        cnt[fruits[left]] -= 1
        if cnt[fruits[left]] == 0:
            del cnt[fruits[left]]
        left += 1
    ans = max(ans, right - left + 1)
return ans
```

关键点：`left` 只增不减，所以每个下标最多被移出窗口一次，整体是线性的；`del` 那一步不能省，否则 `len(cnt)` 永远不降，`while` 会死循环。

## 复杂度
时间 O(n)：`right` 走 n 步，`left` 总共最多走 n 步，`cnt` 的增删查都是 O(1)。
空间 O(1)：`cnt` 里最多同时存 3 个键（超 2 立刻收缩），与 n 无关。

## 易错点
- 输入 `fruits = [1,2,1]` 这类只有两种水果的数组 → 若把收缩条件写成 `len(cnt) >= 2`，会把窗口压到长度 1，输出 1 而非 3 → 条件必须是 `len(cnt) > 2`，允许恰好两种。
- 输入 `fruits = [0,1,2,2]` → 若减计数后忘了 `del cnt[fruits[left]]`，`cnt` 里留着 `0:0` 这种值为 0 的键，`len(cnt)` 仍是 3，`while` 不退出或窗口算错 → 计数归零必须删除该键，让 `len(cnt)` 真实反映种类数。

## 如果面试官追问
问：如果篮子数从 2 改成 k 呢？
答：把 `len(cnt) > 2` 换成 `len(cnt) > k`，其余不变，仍是 O(n)。
