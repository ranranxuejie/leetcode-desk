## 一句话思路
用哈希表存 knowledge，单次扫描 s，遇 `(` 就跳到 `)` 取键查表，命中填值、未命中填 `?`。

## 怎么做
1. 把 knowledge 转成字典 `d = {k: v for k, v in knowledge}`，键唯一，直接覆盖无风险。
2. 用 `i` 扫 s：普通字符直接 append，遇 `(` 时记 `j = s.index(')', i)`。
3. 取 `key = s[i+1:j]`，`res.append(d.get(key, '?'))`，然后 `i = j + 1` 跳过右括号。
4. 循环结束 `return ''.join(res)`。

以示例 1 为例：`s = "(name)is(age)yearsold"`，`i=0` 遇 `(`，`j=5`，`key="name"`，`d.get("name")` 得 `"bob"`，`i` 跳到 6；接着 `i=6..7` 是 `"is"` 原样追加；`i=8` 遇 `(`，`j=12`，`key="age"` 得 `"two"`；剩余 `"yearsold"` 逐字符追加，最终 `"bobistwoyearsold"`。

```python
d = {k: v for k, v in knowledge}
res, i, n = [], 0, len(s)
while i < n:
    if s[i] == '(':
        j = s.index(')', i)
        res.append(d.get(s[i+1:j], '?'))
        i = j + 1
    else:
        res.append(s[i])
        i += 1
return ''.join(res)
```

关键点：`i = j + 1` 而不是 `i = j`，否则右括号会被当普通字符再 append 一次。

## 复杂度
时间 O(n + m)：n 是 s 长度（每字符最多访问一次），m 是 knowledge 建表开销。
空间 O(m + n)：字典存 m 个键值对，`res` 列表最坏存 n 个片段。

## 易错点
- 输入 `s = "hi(name)"`、knowledge 只有 `[["a","b"]]`：若用 `d[key]` 直接索引会抛 KeyError，正确做法是 `d.get(key, '?')`，输出 `"hi?"`。
- 输入 `s = "(a)(a)(a)aaa"`：若把 `i = j + 1` 写成 `i = j`，右括号 `)` 会被当普通字符追加，输出变成 `"yes)yes)yes)aaa"`；正确做法是跳过右括号，且括号外的 `aaa` 必须原样保留、不能查表。

## 如果面试官追问
若 s 长度涨到 10^7 且要求原地修改？答：Python 字符串不可变，只能改用 `bytearray` 或分块写入，思路仍是单次扫描 + 哈希查表。
