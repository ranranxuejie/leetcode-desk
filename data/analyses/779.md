## 一句话思路
第 k 个字符由 k 的二进制决定：从根 0 出发，k 的二进制去掉最高位后，每遇到一个 1 就翻转一次。

## 怎么做
1. 把 k 减 1 得到 `k -= 1`，这样第 k 个字符对应从 0 开始的下标。
2. 观察规律：第 n 行第 k 个字符，等于第 n-1 行第 `(k+1)//2` 个字符，若 k 是偶数则翻转。
3. 等价地，`k-1` 的二进制中 1 的个数（popcount）的奇偶性就是答案。
4. 直接返回 `(k-1).bit_count() & 1`。

以示例 n=3, k=3 为例：`k-1 = 2`，二进制 `10`，popcount 为 1，奇偶为 1，返回 1。验证第 3 行 `0110` 第 3 个字符确实是 1。

```python
def kthGrammar(n, k):
    return (k - 1).bit_count() & 1
```

如果面试官要求手写 popcount（不允许用 `bit_count`）：

```python
def kthGrammar(n, k):
    x = k - 1
    cnt = 0
    while x:
        cnt ^= x & 1
        x >>= 1
    return cnt
```

关键中间值：n=3, k=3 时 `x = 2 = 0b10`，循环第一次 `cnt ^= 0` 不变，第二次 `cnt ^= 1` 得 1，返回 1。

## 复杂度
时间：O(log k)，即 k 的二进制位数，n 不参与循环。
空间：O(1)，只用了 `x` 和 `cnt` 两个整型变量。

## 易错点
- 忘记 `k -= 1`：k=2 时直接算 `2.bit_count() = 1` 返回 1 碰巧对，但 k=3 时 `3.bit_count() = 2`，`2 & 1 = 0`，而正确答案是 1，错在把 1-based 下标当成了 0-based。
- 用递归 `kthGrammar(n-1, (k+1)//2)` 时，k 为偶数要翻转、奇数不翻转，写成 `k % 2 == 0` 翻转容易和 `k % 2 == 1` 搞反；验证方法：n=2, k=2，`(2+1)//2 = 1`，父字符是 0，k 偶数应翻转为 1，与示例一致。

## 如果面试官追问
问：如果 n 很大（比如 10^9）但 k 很小，还能这样做吗？
答：能，答案只依赖 k 的二进制，与 n 无关，只要 k ≤ 2^(n-1) 保证下标合法即可。
