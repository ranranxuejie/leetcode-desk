## 一句话思路
按位模拟竖式加法，用 `carry` 记录进位，从个位（链表头）向高位逐节点推进。

## 怎么做
1. 建哑节点 `dummy`，游标 `cur = dummy`，`carry = 0`。
2. 循环条件写 `while l1 or l2 or carry`，三者全空才停。
3. 每轮取 `x = l1.val if l1 else 0`、`y = l2.val if l2 else 0`，算 `s = x + y + carry`，`carry = s // 10`，挂 `ListNode(s % 10)`。
4. 三个指针各自后移，返回 `dummy.next`。

以 `(7->1->6) + (5->9->2)` 为例：第一轮 `x=7, y=5, carry=0`，`s=12`，挂节点 `2`，`carry=1`；第二轮 `x=1, y=9`，`s=1+9+1=11`，挂 `1`，`carry=1`；第三轮 `x=6, y=2`，`s=6+2+1=9`，挂 `9`，`carry=0`；此时 `l1`、`l2` 都空但 `carry=0`，循环结束，得 `2->1->9`。

```python
dummy = cur = ListNode(0)
carry = 0
while l1 or l2 or carry:
    x = l1.val if l1 else 0
    y = l2.val if l2 else 0
    s = x + y + carry
    carry = s // 10
    cur.next = ListNode(s % 10)
    cur = cur.next
    l1 = l1.next if l1 else None
    l2 = l2.next if l2 else None
return dummy.next
```

关键在循环条件里的 `or carry`：`(5) + (5)` 走完一轮后两链表都空，但 `carry=1`，必须再挂一个 `1`，否则返回 `0` 而不是 `10`。

## 复杂度
时间 O(max(m, n))，m、n 为两链表长度，多走一轮进位。
空间 O(max(m, n))，结果链表节点数；递归写法还要 O(max(m, n)) 栈。

## 易错点
- 输入 `(5) + (5)` → 若循环只写 `while l1 or l2`，返回 `0`，丢掉最高位进位 → 条件必须带 `or carry`。
- 输入 `(1->8) + (0)`（即 81 + 0）→ 若在某条链表空时直接 `l1 = l1.next` 而不判空，会 `AttributeError` → 用 `l1.next if l1 else None` 收尾。

## 如果面试官追问
问：进阶要求数位正向存放（`6->1->7` + `2->9->5`）怎么办？
答：先各自反转链表再套本题，或把两链表压栈后从栈顶逐位相加，结果头插。
