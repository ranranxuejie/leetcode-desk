## 一句话思路
从右往左找第一个 `arr[i] > arr[i+1]` 的位置，再在右侧找小于 `arr[i]` 的最大值中最靠左的那个交换。

## 怎么做
1. 从右往左扫描，找第一个满足 `arr[i] > arr[i+1]` 的下标 `i`；找不到说明数组非递减，直接返回原数组。
2. 在 `arr[i+1:]` 中找所有小于 `arr[i]` 的元素里最大的那个值 `best`。
3. 在右侧从右往左找第一个等于 `best` 的位置 `j`（最靠左的 `best`），交换 `arr[i]` 和 `arr[j]`。

以 `arr = [1,9,4,6,7]` 为例：从右往左，`7>6` 不满足，`6>4` 不满足，`4>9` 不满足，`9>4` 满足，所以 `i=1`（`arr[1]=9`）。右侧 `[4,6,7]` 中小于 9 的最大值是 `7`，从右往左第一个 `7` 在下标 4，交换后得 `[1,7,4,6,9]`。

```python
n = len(arr)
i = n - 2
while i >= 0 and arr[i] <= arr[i + 1]:
    i -= 1
if i < 0:
    return arr
best = -1
for k in range(i + 1, n):
    if arr[k] < arr[i] and arr[k] > best:
        best = arr[k]
j = n - 1
while arr[j] != best:
    j -= 1
arr[i], arr[j] = arr[j], arr[i]
return arr
```

关键点：`best` 初始化为 `-1`，因为 `arr[k] >= 1`，保证能正确更新；找 `j` 时从右往左扫，保证取到最靠左的 `best`，这样交换后高位变化最小。

## 复杂度
时间：O(n)，从右往左找 `i` 一次、扫右侧找 `best` 一次、找 `j` 一次，各 O(n)。
空间：O(1)，只用了 `i`、`best`、`j`、`k` 几个变量，原地交换。

## 易错点
- 输入 `[3,1,2]` → 若从右往左找 `arr[i] > arr[i+1]` 时写成 `>=`，会跳过 `3>1` 继续找，最终返回原数组；正确做法是严格用 `arr[i] <= arr[i+1]` 跳过，找到 `i=0` 后交换 `3` 和 `2` 得 `[2,1,3]`。
- 输入 `[1,1,5]` → 若在右侧找 `best` 时允许 `arr[k] == arr[i]`，会把 `5` 和 `1` 交换得到 `[5,1,1]`，字典序反而变大；正确做法是条件写 `arr[k] < arr[i]`，严格小于，此时右侧无满足元素，`best` 保持 `-1`，应直接返回原数组。

## 如果面试官追问
追问：如果允许交换任意多次（不限制一次），怎么求小于原排列的最大排列？
答：先找第一个 `arr[i] > arr[i+1]` 的 `i`，把 `arr[i]` 换成右侧小于它的最大值，再把 `arr[i+1:]` 降序排列即可。
