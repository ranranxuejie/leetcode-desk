## 一句话思路
用三指针 DP：`dp[i]` 是第 i+1 个丑数，每个丑数由前面某个丑数乘 2/3/5 得到，取三者最小值推进。

## 怎么做
1. 初始化 `dp = [1] * n`，三个指针 `p2 = p3 = p5 = 0`。
2. 每轮算 `cand2 = dp[p2]*2`、`cand3 = dp[p3]*3`、`cand5 = dp[p5]*5`，取 `dp[i] = min(cand2, cand3, cand5)`。
3. 谁等于最小值谁前进一格（用三个独立 `if`，不是 `elif`，否则重复值会漏推）。
4. 返回 `dp[n-1]`。

以 n=10 为例，走到 i=9 时 `dp = [1,2,3,4,5,6,8,9,10,12]`，此时 `p2=5`（dp[5]=6→12）、`p3=3`（dp[3]=4→12）、`p5=2`（dp[2]=3→15），`min(12,12,15)=12`，三个指针里 p2、p3 都推进。

```python
dp = [1] * n
p2 = p3 = p5 = 0
for i in range(1, n):
    c2, c3, c5 = dp[p2] * 2, dp[p3] * 3, dp[p5] * 5
    dp[i] = min(c2, c3, c5)
    if dp[i] == c2: p2 += 1
    if dp[i] == c3: p3 += 1
    if dp[i] == c5: p5 += 1
return dp[n - 1]
```

## 复杂度
时间：O(n)，循环 n-1 次，每次常数次比较。
空间：O(n)，`dp` 数组存 n 个丑数；指针只占 3 个变量。

## 易错点
1. n=1 → 循环 `range(1, 1)` 不执行，直接返回 `dp[0]=1`；若把循环写成 `range(n)` 或初始化 `dp=[0]*n`，会返回 0 或越界。正确做法是 `dp=[1]*n` 且从 i=1 起。
2. 用 `elif` 串联三个指针推进 → 遇到 6 这类同时等于 `dp[p2]*2` 和 `dp[p3]*3` 的值时只推一个指针，下一轮会重复产出 6，导致 n=10 时第 10 个变成 10 而非 12。正确做法是三个独立 `if`。

## 如果面试官追问
问：n 放大到 10^6 且要求 O(1) 空间怎么办？
答：三指针法本身只需 3 个指针，但取第 n 个必须保留历史值，可改用堆 + 哈希去重，空间仍是 O(n)，无法真正 O(1)。
