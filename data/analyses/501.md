## 一句话思路
BST 中序遍历得到非降序列，相同值必然相邻，边遍历边统计连续段长度即可求众数。

## 怎么做
1. 用中序遍历（递归或迭代）按序访问节点，维护 `prev`（上一个值）、`cnt`（当前值连续出现次数）、`best`（历史最大频次）、`res`（众数列表）。
2. 每访问到 `node.val`：若 `node.val == prev` 则 `cnt += 1`，否则 `cnt = 1`。
3. 比较 `cnt` 与 `best`：`cnt > best` 时清空 `res`、更新 `best` 并加入当前值；`cnt == best` 时直接追加。
4. 遍历结束后 `res` 即答案。

以 `root = [1,null,2,2]` 为例：中序访问顺序是 `1, 2, 2`。访问第一个 `2` 时 `prev=1`，`cnt` 重置为 1，`best` 从 1 更新为 1，`res=[2]`；访问第二个 `2` 时 `node.val == prev`，`cnt=2 > best=1`，清空 `res` 后 `res=[2]`、`best=2`。最终返回 `[2]`。

```python
def dfs(node):
    nonlocal prev, cnt, best
    if not node:
        return
    dfs(node.left)
    if prev is not None and node.val == prev:
        cnt += 1
    else:
        cnt = 1
    if cnt > best:
        best, res[:] = cnt, [node.val]
    elif cnt == best:
        res.append(node.val)
    prev = node.val
    dfs(node.right)
```

关键点：`prev` 初值用 `None` 而不是 `-10**5 - 1`，避免与合法值 `-10**5` 混淆；`res[:] = [node.val]` 原地清空，避免闭包里重新绑定。

## 复杂度
时间 O(n)：每个节点访问一次，n 为节点数。
空间 O(h)：递归栈深度 h，最坏链状树 h=n；`res` 额外开销不超过 O(n)。

## 易错点
- 输入 `[1,null,2,2]` 若用哈希表统计再二次扫描，虽然也对，但没利用 BST 有序性，面试官会追问进阶；正确做法是中序一次遍历，靠 `prev` 判断相邻相等。
- 输入 `[0]` 或全相同值如 `[2,2,2]`：若 `prev` 初值设成 `-10**5 - 1` 且树中恰有该值，第一个节点会被误判为重复，`cnt` 从 2 起算导致频次虚高；正确做法是 `prev = None` 显式判空。

## 如果面试官追问
问：不用递归、也不用额外数组怎么做？答：用 Morris 中序遍历，把左子树最右节点的 `right` 临时指向当前节点，空间降到 O(1)，统计逻辑不变。
