## 一句话思路
用四个哈希表按行、列、两条对角线统计灯数，查询时 O(1) 判断，关灯时只删查询点周围 9 格内的灯。

## 怎么做
1. 把 `lamps` 去重后，分别累加到 `rows[r]`、`cols[c]`、`diag1[r-c]`、`diag2[r+c]` 四个计数器里。
2. 查询 `(r, c)` 时，只要 `rows[r]`、`cols[c]`、`diag1[r-c]`、`diag2[r+c]` 任一计数大于 0，就记 1，否则记 0。
3. 然后遍历 `(r, c)` 周围 9 个格子，若某格在灯集合 `lamp_set` 中，就从四个计数器各减 1 并从集合删除。
4. 关键中间值：示例 1 中 `lamps=[[0,0],[4,4]]`，查询 `(1,1)` 时 `diag1[1-1]=diag1[0]=2`（两盏灯都在主对角线），故返回 1；关灯只删 `(0,0)` 附近，`(4,4)` 不受影响。

```python
lamp_set = set(map(tuple, lamps))
rows, cols, d1, d2 = Counter(), Counter(), Counter(), Counter()
for r, c in lamp_set:
    rows[r] += 1; cols[c] += 1; d1[r-c] += 1; d2[r+c] += 1

ans = []
for r, c in queries:
    ans.append(1 if rows[r] or cols[c] or d1[r-c] or d2[r+c] else 0)
    for dr in (-1, 0, 1):
        for dc in (-1, 0, 1):
            p = (r+dr, c+dc)
            if p in lamp_set:
                lamp_set.remove(p)
                x, y = p
                rows[x] -= 1; cols[y] -= 1; d1[x-y] -= 1; d2[x+y] -= 1
```

## 复杂度
时间：O(L + Q)，L 为去重后灯数，Q 为查询数，每次查询固定查 9 格。
空间：O(L)，四个 Counter 加一个 `lamp_set`，与 n 无关。

## 易错点
- `lamps` 有重复坐标（如 `[[0,0],[0,0]]`）→ 若直接遍历累加，`rows[0]` 会变成 2，关灯时减 1 后仍大于 0，误判为照亮 → 必须先用 `set` 去重再建计数器。
- 查询点本身有灯且被关掉后，同一坐标再次查询 → 若只删计数器不删 `lamp_set`，第二次关灯会重复减 1 导致计数变负、后续误判 → 删灯前必须 `if p in lamp_set` 判存在。

## 如果面试官追问
若 n 缩小到 1000 且要求输出每次查询后被照亮格子总数？答：维护一个被照亮格子的集合，关灯时重算受影响 9 格的四方向覆盖，用计数器判断是否仍被照亮。
