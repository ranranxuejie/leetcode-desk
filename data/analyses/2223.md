## 一句话思路
把 s 反转后，s_i 的得分就是后缀 `t[i-1:]` 与整个 t 的 LCP，用 Z 函数一次求出全部 LCP 再求和。

## 怎么做
1. 令 `t = s[::-1]`，则原题中长度 i 的前缀串 s_i 反转后正好是 `t[n-i:]`，得分不变。
2. 对 `t` 求 Z 数组：`z[k] = LCP(t, t[k:])`，即 `t[k:]` 与 `t` 的最长公共前缀长度。
3. 得分和 = `sum(z[k] for k in range(n))`，因为 `t[k:]` 对应原串长度 `n-k` 的那个 s_i，其得分恰为 `z[k]`；`k=0` 时 `z[0]=n` 对应 s_n 自身。

以 `s = "babab"` 为例：`t = "babab"`，Z 数组为 `[5,0,3,0,1]`，求和 `5+0+3+0+1 = 9`，与示例一致。注意 `z[2]=3` 对应原串 `s_3="bab"`，`z[4]=1` 对应 `s_1="b"`。

```python
n = len(s)
t = s[::-1]
z = [0] * n
z[0] = n
l = r = 0
for i in range(1, n):
    if i < r:
        z[i] = min(r - i, z[i - l])
    while i + z[i] < n and t[z[i]] == t[i + z[i]]:
        z[i] += 1
    if i + z[i] > r:
        l, r = i, i + z[i]
return sum(z)
```

## 复杂度
时间 O(n)：Z 函数的 while 循环总扩展次数不超过 n，每个 i 均摊 O(1)。
空间 O(n)：`z` 数组和反转后的 `t` 各占 n，无其他额外结构。

## 易错点
- 忘记 `z[0] = n` → 对 `"babab"` 会得到 `0+0+3+0+1 = 4` 而非 9，因为 s_n 自身得分必须是全长 n，循环从 `i=1` 开始，`z[0]` 必须手动置 n。
- Z-box 更新写成 `if i + z[i] >= r` 或漏掉 `z[i-l]` 的截断 → 对 `"aaaa"` 这类高重复串，`i < r` 时若直接用 `z[i-l]` 而不取 `min(r-i, ...)`，会算出超过盒子右边界的值，导致后续比较越界或结果偏大；正确写法是先 `min(r - i, z[i - l])` 再暴力扩展。

## 如果面试官追问
若要求返回每个 s_i 的得分数组而非总和？答：Z 数组逆序即为答案，`ans[n-k] = z[k]`，`k` 从 0 到 n-1，无需额外计算。
