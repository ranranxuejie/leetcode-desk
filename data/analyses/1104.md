## 一句话思路
从 label 反复求父节点，每层先把标号按该行镜像翻回「从左到右」的序号再除 2，最后反转路径。

## 怎么做
1. 用 `label.bit_length()` 得到 label 所在行号 `row`（根为第 1 行），该行区间是 `[2**(row-1), 2**row - 1]`。
2. 偶数行是从右往左标号，求父节点前先把 label 翻成该行的「左起序号」：`mirror = lo + hi - label`。
3. 父节点 = `mirror // 2`，把父节点加入路径，令 `label = mirror // 2` 继续上溯，直到 label 为 1。
4. 路径是自底向上收集的，返回前 `reverse`。

以 label = 14 为例：`bit_length()` 为 4，row = 4，区间 `[8, 15]`。第 4 行是偶数行，`mirror = 8 + 15 - 14 = 9`，父节点 `9 // 2 = 4`。label 变 4，row = 3，区间 `[4, 7]`，第 3 行是奇数行不翻转，父节点 `4 // 2 = 2`；再上一层 label = 2，row = 2，区间 `[2, 3]`，`mirror = 2 + 3 - 2 = 3`，父节点 `3 // 2 = 1`。路径自底向上是 `[14, 4, 2, 1]`，反转得 `[1, 2, 4, 14]`。

```python
path = [label]
while label > 1:
    row = label.bit_length()
    lo, hi = 1 << (row - 1), (1 << row) - 1
    if row % 2 == 0:              # 偶数行镜像
        label = (lo + hi - label) // 2
    else:
        label //= 2
    path.append(label)
path.reverse()
```

注意翻转只影响「求父节点」这一步，写进 path 的始终是原始标号，不是 mirror 值。

## 复杂度
时间：O(log label)，每层一次位运算和除法，行数即 label 的二进制位数。
空间：O(log label)，path 存路径上的每个节点，无其他额外结构。

## 易错点
- label = 1 → 若先做镜像再判断，`lo + hi - 1` 会算出 2，父节点变 1 死循环；正确做法是循环条件写 `label > 1`，根直接返回 `[1]`。
- label = 2（第 2 行偶数行）→ 忘记翻转会得父节点 `2 // 2 = 1` 碰巧对，但 label = 3 时得 `3 // 2 = 1`，而真实父节点是 1 也对；真正翻车在 label = 6：不翻转得 `6 // 2 = 3`，正确父节点是 2（`mirror = 4 + 7 - 6 = 5`，`5 // 2 = 2`），路径会错成 `[1, 3, 6]`。

## 如果面试官追问
问：label 上限改成 10^18 还成立吗？
答：成立，Python 大整数无溢出，`bit_length` 和移位照常，复杂度仍是 O(log label)。
