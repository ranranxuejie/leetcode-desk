## 一句话思路
用布尔索引筛 `weight > 100`，再 `sort_values` 降序，最后 `[['name']]` 只留一列，全程链式。

## 怎么做
1. 先 `animals[animals['weight'] > 100]` 过滤，注意是严格大于，`Stefan` 的 50 和 `Khaled` 的 41 被剔除。
2. 对过滤结果 `sort_values('weight', ascending=False)`，此时顺序为 Tatiana(464)、Jonathan(463)、Tommy(349)、Alex(328)。
3. 末尾 `[['name']]` 取单列，双中括号保证返回 DataFrame 而非 Series。

关键中间值：过滤后剩 4 行，`weight` 列是 `[464, 463, 349, 328]`；排序后 `name` 列依次是 `Tatiana, Jonathan, Tommy, Alex`，与示例输出逐行对齐。

```python
def findHeavyAnimals(animals):
    return (
        animals[animals['weight'] > 100]
        .sort_values('weight', ascending=False)
        [['name']]
    )
```

链式写法成立的前提是每步都返回 DataFrame：布尔索引返回 DataFrame，`sort_values` 返回 DataFrame，`[['name']]` 也返回 DataFrame，所以能一路点下去。若写成 `['name']` 单中括号，返回的是 Series，列名丢失，力扣比对会失败。

## 复杂度
时间 O(n log n)：n 为行数，过滤 O(n)，排序贡献 log n 因子。
空间 O(n)：布尔掩码和排序后的副本各占一份，额外没开别的结构。

## 易错点
- 写成 `weight >= 100` → `Stefan` 体重正好 100 会被错误保留，输出多一行 → 题目要求严格超过，必须用 `>`。
- 末尾用 `['name']` 而非 `[['name']]` → 返回 Series，列名变成索引名，判题报格式不符 → 双中括号取列，保持 DataFrame 结构。

## 如果面试官追问
问：若要求同时返回 species 且按 weight 降序、weight 相同按 name 升序？
答：`sort_values(['weight', 'name'], ascending=[False, True])`，多键排序一次搞定。
