## 一句话思路
用 `deque` 存 FIFO 顺序、`set` 存三元组去重、`dict[destination] -> 有序 timestamp 列表` 支持二分计数。

## 怎么做
1. 初始化 `self.q = deque()`、`self.seen = set()`、`self.by_dest = defaultdict(list)`。
2. `addPacket` 先查 `(source, destination, timestamp)` 是否在 `seen` 中，在则返回 `False`；否则若 `len(q) == memoryLimit`，弹出队首并从 `seen` 和 `by_dest` 中删掉它。
3. 新包入队、入 `seen`、把 `timestamp` 追加到 `by_dest[destination]`（因 timestamp 非递减，列表天然有序）。
4. `getCount` 对 `by_dest[destination]` 用 `bisect_right(endTime) - bisect_left(startTime)`。

以示例 1 为例：`memoryLimit=3`，加完 `[1,4,90]`、`[2,5,90]`、`[3,5,95]` 后队列满；再 `addPacket(4,5,105)` 时弹出队首 `[1,4,90]`，此时 `by_dest[5]` 从 `[90,95]` 变为 `[90,95,105]`。之后 `forwardPacket` 弹出 `[2,5,90]`，`by_dest[5]` 变 `[95,105]`。最后 `getCount(5,100,110)` 在 `[95,105]` 上二分，`bisect_left(100)=1`、`bisect_right(110)=2`，返回 `1`。

```python
from collections import deque, defaultdict
from bisect import bisect_left, bisect_right

def addPacket(self, source, destination, timestamp):
    key = (source, destination, timestamp)
    if key in self.seen:
        return False
    if len(self.q) == self.memoryLimit:
        s, d, t = self.q.popleft()
        self.seen.discard((s, d, t))
        self.by_dest[d].pop(0)   # 队首必是该 dest 最旧的时间戳
    self.q.append(key)
    self.seen.add(key)
    self.by_dest[destination].append(timestamp)
    return True
```

## 复杂度
时间：`addPacket` 均摊 O(1)（`pop(0)` 是 O(n) 的隐患，见易错点），`getCount` O(log n)，n 为该 destination 的包数。
空间：O(memoryLimit)，`q`、`seen`、`by_dest` 各存一份。

## 易错点
1. 用 `list.pop(0)` 删 `by_dest[d]` 队首 → 每次 O(n)，10^5 次调用最坏退化成 O(n²)。正确做法是让 `by_dest[d]` 也存 `deque`，但 `bisect` 不支持 `deque`；折中方案是记录每个 destination 的「已删前缀长度」`offset[d]`，二分时在 `by_dest[d][offset[d]:]` 上算，或改用 `SortedList`。
2. 淘汰时只从 `q` 和 `seen` 删、忘了同步 `by_dest` → 示例 1 中 `getCount(5,100,110)` 会把已淘汰的 `[1,4,90]` 之外的旧包也算进去，返回偏大。必须三者同步删除。

## 如果面试官追问
问：若 timestamp 不再非递减怎么办？
答：`by_dest[d]` 改用 `SortedList` 或每次插入后 `insort`，`getCount` 仍是两次二分，代价是 `addPacket` 从 O(1) 变 O(n) 挪位。
