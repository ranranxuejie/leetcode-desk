## 一句话思路
按「含 x 的位置」把牌分成两类，同类内只有另一位置不同的牌才兼容，逐类用哈希计数配对。

## 怎么做
1. 只保留含 `x` 的牌，按 `x` 在下标 0 还是 1 分成两组 `g0`、`g1`。
2. 同组内两张牌兼容当且仅当另一位置字母不同（x 位置相同），所以组内问题变成「同字母不能配对」。
3. 每组用 `Counter` 统计另一位置字母频次，答案 = 组内 `min(总数//2, 总数 - 最大频次)`。
4. 两组答案相加。

以示例 1 `cards = ["aa","ab","ba","ac"], x = "a"` 为例：`g0`（x 在下标 0）是 `aa, ab, ac`，另一位置计数 `{a:1, b:1, c:1}`，总数 3、最大频次 1，得 `min(1, 2) = 1`；`g1` 是 `ba`，另一位置 `{b:1}`，得 0；合计 1？实际应为 2——注意 `aa` 的 x 同时在下标 0 和 1，它应同时进两组，重算：`g0` 含 `aa,ab,ac` 得 1，`g1` 含 `aa,ba` 另一位置 `{a:1,b:1}` 得 1，合计 2，与答案一致。

```python
from collections import Counter

def score(cards, x):
    g = [Counter(), Counter()]
    for s in cards:
        if s[0] == x:
            g[0][s[1]] += 1
        if s[1] == x:
            g[1][s[0]] += 1
    ans = 0
    for c in g:
        tot = sum(c.values())
        ans += min(tot // 2, tot - max(c.values(), default=0))
    return ans
```

关键点：`aa` 这种双 x 牌两个 `if` 都成立，会同时进两组，这是正确的，因为它在任一位置都能和别的牌配对。

## 复杂度
时间 O(n)，遍历 cards 一次，每组 Counter 求和与取最大值是常数 10 个字母。
空间 O(1)，只开两个大小 ≤10 的 Counter。

## 易错点
- 把 `aa` 只放进一组（比如用 `if/elif`）→ 示例 1 会得 1 而非 2 → 必须用两个独立 `if`，让双 x 牌进两组。
- 组内直接算 `tot // 2` 而不减最大频次 → 输入 `["aa","aa","ab"], x="a"` 时 `g0` 是 `aa,aa,ab`，另一位置 `{a:2,b:1}`，`tot//2=1` 恰好对，但 `["aa","aa","aa","ab"]` 时 `tot//2=2` 而实际只能配 1 对（三个 a 互相不兼容）→ 必须取 `min(tot//2, tot - maxfreq)`。

## 如果面试官追问
若要求输出具体配对方案而非分数？答：每组内按频次从大到小，把最大频次那堆与其余堆轮流交叉配对，贪心即可构造。
