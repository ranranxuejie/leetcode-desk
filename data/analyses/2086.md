## 一句话思路
从左到右贪心：遇到没被喂的 `H` 就在它右边放桶，右边不行才放左边，因为桶越靠右能覆盖越多的后续仓鼠。

## 怎么做
1. 先扫一遍，若出现 `"HHH"` 连续三只，中间那只左右都是 `H`，永远放不了桶，直接返回 `-1`。
2. 从左往右遍历，用 `fed` 记录上一个桶的位置；遇到 `H` 且 `i-1 != fed`（左边没桶）时，必须给它补一个桶。
3. 补桶优先放 `i+1`（能顺带喂 `i+2`），只有 `i+1` 越界或已是 `H` 时才放 `i-1`，同时 `count += 1`、`fed = 放桶位置`。

以 `"H..H"` 为例：`i=0` 是 `H`，左边无桶，`i+1=1` 是 `.`，放桶于 1，`count=1, fed=1`；`i=3` 是 `H`，`i-1=2 != fed=1`，`i+1=4` 越界，改放 `i-1=2`，`count=2`。结果 2，与官方一致。

```python
count, fed = 0, -10
for i, c in enumerate(hamsters):
    if c != 'H' or i - 1 == fed:
        continue
    if i + 1 < len(hamsters) and hamsters[i + 1] == '.':
        fed = i + 1
    elif i - 1 >= 0 and hamsters[i - 1] == '.':
        fed = i - 1
    else:
        return -1
    count += 1
return count
```

注意 `fed` 初值取 `-10` 而非 `-1`：`i=0` 时 `i-1=-1`，若 `fed=-1` 会误判成「左边已有桶」而漏喂第一只。

## 复杂度
时间 O(n)：一次遍历，`n = len(hamsters)`。
空间 O(1)：只用了 `count`、`fed` 两个标量。

## 易错点
- 输入 `"H"`（长度 1）→ 若 `fed` 初值写成 `-1`，`i-1 == fed` 成立会跳过，返回 0；正确应返回 -1，因为唯一位置是 `H` 放不了桶。初值必须取 `-10` 之类。
- 输入 `".HHH."` → 若只靠贪心循环，`i=2` 时 `i+1` 和 `i-1` 都是 `H`，会走 `else` 返回 -1，这没问题；但若把「放桶」写成无条件放 `i+1`，就会把桶放到 `H` 上，返回错误的 2。必须先判 `hamsters[i+1] == '.'`。

## 如果面试官追问
要求输出具体放桶位置而非数量？答：把 `fed = i+1` 改成 `fed = i+1; res.append(i+1)`，两个分支各记一次即可，贪心结构不变。
