## 一句话思路
用埃氏筛一次筛出 `[1, right]` 的质数表，再顺序扫 `[left, right]` 找相邻质数最小差。

## 怎么做
1. 建 `is_prime = [True] * (right + 1)`，把 0、1 置 `False`，从 `i = 2` 筛到 `i * i <= right`，把 `i` 的倍数全置 `False`。
2. 从 `left` 扫到 `right`，用 `prev` 记住上一个质数，遇到新质数就更新 `best`。
3. 差严格小于 `best` 才更新，这样并列时保留先出现的（`nums1` 更小）。
4. 扫完 `best` 仍是初值就返回 `[-1, -1]`。

以 `left = 10, right = 19` 为例：筛完后 `is_prime[11] = is_prime[13] = is_prime[17] = is_prime[19] = True`。扫到 11 时 `prev = 11`；扫到 13 时 `13 - 11 = 2 < best(inf)`，`best = 2`，`ans = [11, 13]`；扫到 17 时 `17 - 13 = 4`，不更新；扫到 19 时 `19 - 17 = 2`，因要求严格小于，不更新，最终仍是 `[11, 13]`。

```python
n = right
is_prime = [True] * (n + 1)
is_prime[0] = is_prime[1] = False
for i in range(2, int(n ** 0.5) + 1):
    if is_prime[i]:
        for j in range(i * i, n + 1, i):
            is_prime[j] = False

prev, best, ans = -1, float('inf'), [-1, -1]
for x in range(left, right + 1):
    if is_prime[x]:
        if prev != -1 and x - prev < best:
            best, ans = x - prev, [prev, x]
        prev = x
```

## 复杂度
时间：筛法 O(right log log right)，扫描 O(right - left)，总 O(right log log right)。
空间：`is_prime` 数组 O(right)，无其他额外结构。

## 易错点
- `left = 1` 或 `left = 2` 时，若忘记把 `is_prime[0]`、`is_prime[1]` 置 `False`，会把 1 当质数，`[1, 2]` 被误判为合法对；正确做法是筛前先置这两个下标为 `False`。
- 区间内只有 0 或 1 个质数（如 `left = 4, right = 6`，只有 5）时，`prev` 始终没机会配对，若把 `best` 初值设成 0 或漏判 `prev != -1`，会返回 `[5, 5]` 或越界；正确做法是 `best` 初值设 `float('inf')`，最后判 `ans == [-1, -1]` 直接返回。

## 如果面试官追问
问：`right` 放大到 `10^9` 但区间长度很小怎么办？
答：改用对区间内每个数做 `O(sqrt(x))` 试除，只依赖 `right - left`，不建全量筛表。
