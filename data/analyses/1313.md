## 一句话思路
按 `i` 每次走 2 步读 `[freq, val]`，把 `val` 重复 `freq` 次追加到结果列表，一趟扫完即得解压结果。

## 怎么做
1. 建空列表 `res`，用 `range(0, len(nums), 2)` 遍历，`i` 只落在偶数下标上。
2. 每轮取 `freq = nums[i]`、`val = nums[i+1]`，这是本题唯一的下标约定，别写成 `nums[i]` 和 `nums[i+2]`。
3. 用 `res.extend([val] * freq)` 一次性追加，比 `for _ in range(freq): res.append(val)` 少一层循环。
4. 遍历结束直接返回 `res`。

拿示例 1 `nums = [1,2,3,4]` 走一遍：`i=0` 时 `freq=1, val=2`，`res` 变成 `[2]`；`i=2` 时 `freq=3, val=4`，`[4]*3` 是 `[4,4,4]`，`extend` 后 `res = [2,4,4,4]`，与输出一致。关键中间值就是 `i=2` 那轮的 `[4,4,4]`——它证明 `freq` 和 `val` 的取值顺序没搞反。

```python
res = []
for i in range(0, len(nums), 2):
    freq, val = nums[i], nums[i + 1]
    res.extend([val] * freq)
return res
```

注意 `[val] * freq` 里 `val` 在前、`freq` 在后，写成 `[freq] * val` 在示例 1 上会得到 `[1,3,3,3]`，一眼能看出错但很容易手滑。

## 复杂度
时间：O(n + m)，`n = len(nums)` 走 `n/2` 轮，`m` 是解压后总长度，由 `extend` 贡献。
空间：O(m)，只额外开了结果列表 `res`，`[val] * freq` 是临时小列表，不计入。

## 易错点
- 输入 `nums = [1,1,2,3]`（示例 2）→ 若把 `freq` 和 `val` 读反，会得到 `[1,1,3,3,3]` 而不是 `[1,3,3]` → 正确做法是死记 `nums[2*i]` 是频次、`nums[2*i+1]` 是值，`freq` 永远在偶数位。
- 输入 `nums = [2,5]` 这种单对 → 若用 `range(len(nums))` 逐元素遍历再判断奇偶，容易在 `i=1` 时越界访问 `nums[2]` → 正确做法是步长直接设 2，`i` 最大只到 `len(nums)-2`，天然不越界。

## 如果面试官追问
问：如果 `freq` 很大（比如 `10**9`）导致解压后列表放不进内存怎么办？
答：改成返回生成器或按区间查询第 `k` 个元素，用前缀和定位落在哪一对里，不必真展开。
