## 一句话思路
逐条扫描 operations，看字符串里是 `+` 还是 `-` 决定 X 加 1 还是减 1，因为四种操作只差符号位置。

## 怎么做
1. 初始化 `x = 0`，遍历 `operations` 中每个字符串 `op`。
2. 判断符号：`op` 里含 `+` 就 `x += 1`，否则 `x -= 1`。
3. 用 `'+' in op` 一次判断即可，不必区分 `++X` 和 `X++`。

拿示例 1 `["--X","X++","X++"]` 走一遍：初始 `x=0`；`"--X"` 不含 `+`，`x=-1`；`"X++"` 含 `+`，`x=0`；再一个 `"X++"`，`x=1`，返回 1。

```python
x = 0
for op in operations:
    if '+' in op:
        x += 1
    else:
        x -= 1
return x
```

关键点：四种操作里 `+`/`-` 一定出现两次，但只需判断有没有 `+`，因为 `--X` 和 `X--` 都不含 `+`，`++X` 和 `X++` 都含 `+`，符号位置不影响结果。

## 复杂度
时间 O(n)，n 为 operations 长度，每个字符串做一次 `in` 判断（长度固定为 3）。
空间 O(1)，只开了一个累加变量 x。

## 易错点
- 输入 `["--X"]` → 若用 `op[0] == '+'` 判断会漏掉 `X++` 这种 `+` 在末尾的写法，把 `"X++"` 误判成减 → 正确做法是判断 `'+' in op`，不依赖位置。
- 输入 `["X--","--X"]` → 若把 `op == "++X"` 和 `op == "X++"` 分开写、漏掉 `X--` 分支，会少减一次 → 正确做法是用 `+`/`-` 二分覆盖全部四种，别枚举四个字符串。

## 如果面试官追问
问：如果操作里混入非法字符串怎么办？
答：先校验 `op in {"++X","X++","--X","X--"}`，非法则抛异常或跳过，别让 `'+' in op` 把垃圾串当加法。
