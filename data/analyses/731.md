## 一句话思路
用差分数组（或有序端点表）维护每个时刻的预订数，插入前检查新区间内最大重叠是否已达 2。

## 怎么做
1. 把所有已接受事件的端点收集起来，用差分数组 `diff` 记录每个端点的净变化，`book` 时先试加再检查。
2. 对新区间 `[s, e)`，只需检查落在其中的端点处前缀和是否 ≥ 2（因为新区间本身贡献 +1，若原值 ≥2 就成三重）。
3. 若通过则真正写入差分，否则回滚。

以示例第 4 次 `book(5, 15)` 为例：此时已接受 `[10,20)`、`[50,60)`、`[10,40)`，端点排序后 `10` 处前缀和为 2（`[10,20)` 与 `[10,40)` 重叠），`5 < 10 < 15`，检查到 `10` 时原值 2，加 1 变 3，返回 `False`。

```python
def book(self, s, e):
    pts = sorted(set(self.starts + [s]))
    # 简化：直接扫描所有已存区间计数
    for x in pts:
        if s <= x < e:
            cnt = sum(1 for a, b in self.events if a <= x < b)
            if cnt >= 2:
                return False
    self.events.append((s, e))
    return True
```

（实际实现用差分数组 `diff` 按端点排序后前缀和判断，避免每次 O(n) 扫描；上面片段展示判定逻辑。）

## 复杂度
时间：每次 `book` O(n log n)，n 为已接受事件数（排序端点）；n ≤ 1000 可接受。
空间：O(n) 存差分表与事件列表。

## 易错点
- 输入 `[5,10)` 接在 `[10,20)` 后：半开区间端点相接不算重叠，若用 `<=` 判断会误判为三重 → 必须用 `a <= x < b` 严格半开。
- 示例第 6 次 `book(25,55)`：`[25,40)` 与 `[10,40)` 重叠成二重，`[40,50)` 仅一重，若整段一刀切判"有重叠就拒绝"会错拒 → 要逐端点检查前缀和，不能只看区间是否相交。

## 如果面试官追问
若 `book` 调用到 10^5 次怎么办？答：改用线段树/有序集合维护区间覆盖计数，单次 O(log n)，端点需离散化。
