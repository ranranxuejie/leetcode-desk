## 一句话思路
一次遍历相邻字符，把 `ord` 差与 2 比较，任一超限即返回 `False`。

## 怎么做
1. 用 `for i in range(len(s) - 1)` 枚举相邻下标对，不切片、不建新列表。
2. 每对取 `abs(ord(s[i]) - ord(s[i+1]))`，与 2 比较。
3. 一旦差值大于 2 立即 `return False`，不必看完剩余字符。
4. 循环正常结束返回 `True`。

以 `s = "129"` 为例：`i = 0` 时 `abs(ord('1') - ord('2')) = 1`，通过；`i = 1` 时 `abs(ord('2') - ord('9')) = 7 > 2`，此处直接返回 `False`，`s[2]` 之后不再参与比较。若用 `s = "132"`，两次差值分别是 2 和 1，都 `<= 2`，循环走完返回 `True`。

```python
def isAdjacentDiffAtMostTwo(s: str) -> bool:
    for i in range(len(s) - 1):
        if abs(ord(s[i]) - ord(s[i + 1])) > 2:
            return False
    return True
```

关键点：`ord('0')` 到 `ord('9')` 是连续的，所以字符码差等于数字差，不需要 `int(s[i])` 转换；`abs` 保证 `"31"` 这种降序对也算 2 而不是 -2。

## 复杂度
时间 O(n)：n 为 `len(s)`，最坏扫完 n-1 对相邻字符。
空间 O(1)：只用了下标 `i` 和两个临时整数，没有额外容器。

## 易错点
- 输入 `s = "19"`：若写成 `ord(s[i+1]) - ord(s[i]) > 2` 漏掉 `abs`，得到 -8 不触发返回，错判 `True`；正确做法是两侧都套 `abs` 再比 2。
- 输入 `s = "909"`：若先 `int(s[i])` 再比较却把阈值写成 `< 2`（漏等号），`abs(9-0)=9` 仍会返回 `False` 看似没事，但换成 `s = "132"` 时 `abs(1-3)=2` 会被误判 `False`；正确做法是判断 `> 2` 才失败，即允许等于 2。

## 如果面试官追问
问：若要求返回第一个违规位置的下标而非布尔值？答：把 `return False` 改成 `return i`，循环结束返回 `-1`，逻辑不变。
