## 一句话思路
预处理每个格子向右、向下的连续黑像素长度，再按边长从大到小枚举左上角验证四条边。

## 怎么做
1. 定义 `right[i][j]` 为从 `(i,j)` 起向右连续 0 的个数，`down[i][j]` 为向下连续 0 的个数，从右下往左上递推。
2. 按 `size` 从 `n` 递减到 1 枚举，对每个 `(r,c)` 检查四条边是否全黑。
3. 四条边条件：`right[r][c] >= size`、`down[r][c] >= size`、`right[r+size-1][c] >= size`、`down[r][c+size-1] >= size`。
4. 第一个命中的就是最大边长；同一 `size` 下按 `r` 升序、`c` 升序枚举，天然满足字典序要求。

以示例 1 为例，`matrix[1][0]=0`，`right[1][0]=2`、`down[1][0]=2`；`right[2][0]=2`、`down[1][1]=2`，四条边都 `>= 2`，所以 `size=2` 在 `(1,0)` 命中，返回 `[1,0,2]`。

```python
n = len(matrix)
right = [[0]*(n+1) for _ in range(n+1)]
down  = [[0]*(n+1) for _ in range(n+1)]
for i in range(n-1, -1, -1):
    for j in range(n-1, -1, -1):
        if matrix[i][j] == 0:
            right[i][j] = right[i][j+1] + 1
            down[i][j]  = down[i+1][j] + 1
for size in range(n, 0, -1):
    for r in range(n-size+1):
        for c in range(n-size+1):
            if (right[r][c] >= size and down[r][c] >= size
                and right[r+size-1][c] >= size
                and down[r][c+size-1] >= size):
                return [r, c, size]
return []
```

## 复杂度
时间：O(n³)，枚举 size 与左上角共 O(n³)，预处理 O(n²)。
空间：O(n²)，`right`、`down` 两张 (n+1)² 表。

## 易错点
- 输入 `[[1]]`（全白）→ 若循环写成 `range(n, 0, -1)` 后直接返回 `[0,0,0]` 会错 → 必须显式 `return []`，因为 `size=1` 也要求该格为 0。
- 示例 2 的对角线 `[[0,1,1],[1,0,1],[1,1,0]]` → 若只查 `right[r][c]` 和 `down[r][c]` 两个角，会把 `size=2` 误判成立 → 必须同时查右下角 `(r+size-1, c)` 的 `right` 和右上角 `(r, c+size-1)` 的 `down`，四条边缺一不可。

## 如果面试官追问
问：n 放大到 2000 怎么办？
答：O(n³) 会超时，改用「按 `min(right,down)` 定上界 + 二分 size」或对每行做单调栈，把验证降到 O(n² log n)。
