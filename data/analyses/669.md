## 一句话思路
用 DFS 按 BST 有序性剪枝：节点值越界时直接返回它唯一可能合法的子树，递归结果接回父节点。

## 怎么做
1. 空节点返回 `None`，作为递归出口。
2. `root.val < low` 时，左子树全部更小也越界，返回 `trimBST(root.right, low, high)`。
3. `root.val > high` 时，右子树全部更大也越界，返回 `trimBST(root.left, low, high)`。
4. 值在区间内则递归修剪左右子树并接回 `root.left` / `root.right`，返回 `root`。

以示例 2 的 `root = [3,0,4,null,2,null,null,1], low = 1, high = 3` 为例：根 3 合法，进入左子树 0；`0 < low=1`，丢弃 0 及其左子树，返回 `trimBST(0.right=2, 1, 3)`；节点 2 合法，其左子 1 合法保留、右子为空，于是 2 的左孩子是 1，最终 3 的左孩子变成 2，输出 `[3,2,null,1]`。

```python
def trimBST(root, low, high):
    if not root:
        return None
    if root.val < low:
        return trimBST(root.right, low, high)
    if root.val > high:
        return trimBST(root.left, low, high)
    root.left = trimBST(root.left, low, high)
    root.right = trimBST(root.right, low, high)
    return root
```

关键点：越界时不是返回 `None`，而是返回「可能还有合法节点」的那一侧子树，这一步决定了 0 的右子 2 不会丢。

## 复杂度
时间 O(n)：每个节点最多被访问一次，n 为节点数。
空间 O(h)：递归栈深度为树高 h，最坏链状 O(n)，未额外开数组。

## 易错点
- 输入 `root=[1,0,2], low=1, high=2` 时，若对越界的 0 直接返回 `None`，会连带丢掉 0 的右子 2，输出 `[1]`；正确做法是 `0 < low` 时返回 `trimBST(root.right,...)`，让 2 顶上来。
- 输入 `root=[3,0,4,null,2,null,null,1], low=1, high=3` 时，若只剪当前节点不递归接回，3 的右子 4 会被保留，输出多出 4；正确做法是合法节点也要执行 `root.left = trimBST(...)` 和 `root.right = trimBST(...)` 再返回 `root`。

## 如果面试官追问
问：若要求返回被删除节点的值列表？答：在越界分支里收集 `root.val` 再继续向合法侧递归，注意被整棵剪掉的子树要遍历收集。
