## 一句话思路
把答案拆成「单段内最大子数组」和「跨段拼接」两类，用 Kadane 在长度 2n 的数组上跑一遍即可覆盖 k≥2 的所有情况。

## 怎么做
1. 先算 `total = sum(arr)` 和单段 Kadane 结果 `best1`（允许空子数组，初值 0）。
2. 若 `k == 1`，直接返回 `best1 % MOD`。
3. 否则在 `arr + arr` 上跑 Kadane 得到 `best2`，它已经包含了「跨一个边界」的最优拼接。
4. 若 `total > 0`，答案取 `max(best2, best1 + (k - 2) * total)`；否则答案就是 `best2`。

以 `arr = [1,2], k = 3` 为例：`total = 3`，`best1 = 3`，在 `[1,2,1,2]` 上 `best2 = 6`，`total > 0` 时 `best1 + (3-2)*3 = 6`，取 max 得 6？这里要注意：`best2` 只覆盖两段，实际三段全取是 9，所以公式应是 `best2 + (k-2)*total`。修正后 `6 + 1*3 = 9`，与示例一致。

```python
MOD = 10**9 + 7
total = sum(arr)
def kadane(a):
    cur = best = 0
    for x in a:
        cur = max(0, cur + x)
        best = max(best, cur)
    return best
best1 = kadane(arr)
if k == 1:
    return best1 % MOD
best2 = kadane(arr + arr)
if total > 0:
    return (best2 + (k - 2) * total) % MOD
return best2 % MOD
```

关键中间值：`arr=[1,-2,1]` 时 `total=0`，`best1=1`，`arr+arr=[1,-2,1,1,-2,1]` 上 `best2=2`，`total` 不大于 0，返回 2，与示例 2 一致。

## 复杂度
时间 O(n)：Kadane 扫 `arr` 和 `arr+arr` 各一遍，与 k 无关。
空间 O(n)：`arr + arr` 新建长度 2n 的列表，其余为常数。

## 易错点
- `arr = [-1,-2], k = 7` → 若忘记允许空子数组、把 Kadane 初值设成 `-inf`，会返回负数 → 正确做法是 `cur = best = 0`，全负时返回 0。
- `arr = [1,2], k = 3` → 若写成 `best1 + (k-1)*total` 或漏掉 `best2` 直接 `best1 + (k-2)*total`，会得到 6 而非 9 → 正确做法是 `best2 + (k-2)*total`，因为 `best2` 已含两段。

## 如果面试官追问
问：k 达到 10^18 怎么办？答：公式里 k 只以乘法出现，`(k-2)*total` 用 Python 大整数直接算再取模，O(n) 不变。
