## 一句话思路
把每个数映射成「偶 +b、奇 −a」，子数组有效等价于映射后区间和 ≤ 0 且含至少一个奇数，用前缀和 + 树状数组计数。

## 怎么做
1. 令 `w[i] = b if nums[i] % 2 == 0 else -a`，则子数组 `(l, r]` 的 x/y ≤ a/b 等价于 `b*x - a*y ≤ 0`，即 `pre[r] - pre[l] ≤ 0`。
2. 还需 y > 0，即区间内至少一个奇数；用 `lastOdd` 记录最后一个奇数的下标，左端点 l 必须 ≥ lastOdd。
3. 从右往左扫：维护树状数组存「下标 ≥ lastOdd 的 pre[l]」，对每个 r 查询有多少个 pre[l] ≥ pre[r]。
4. 以 `nums = [1,2,1,2], a=3, b=2` 为例，`w = [-3,2,-3,2]`，`pre = [0,-3,-1,-4,-2]`；r=2 时 lastOdd=2，可选的 l 只有 2，`pre[2]=-1 ≥ pre[2]`，计入 1 个。

```python
pre = [0]
for v in nums:
    pre.append(pre[-1] + (b if v % 2 == 0 else -a))
vals = sorted(set(pre))
bit = [0] * (len(vals) + 1)
def add(i):
    i += 1
    while i <= len(vals):
        bit[i] += 1; i += i & -i
def query(i):  # 统计 <= vals[i] 的个数
    i += 1; s = 0
    while i > 0:
        s += bit[i]; i -= i & -i
    return s
```

## 复杂度
时间 O(n log n)：n 次扫描，每次树状数组操作 log n。
空间 O(n)：pre 数组、离散化 vals、bit 各开 n 级别。

## 易错点
- `nums = [2,2,2]` 时全偶，若不加 `lastOdd` 限制会把 y=0 的区间算进去，答案错成 6 而非 0；必须只在 l ≥ lastOdd 的范围内查询。
- 比较 `b*x <= a*y` 时若用浮点除法 `x/y <= a/b`，`a=3,b=2` 这类比例在 x、y 较大时会有精度误差；必须交叉相乘用整数比较，Python 里直接 `b*x <= a*y` 不会溢出。

## 如果面试官追问
若 n 扩大到 10^5 且要求输出所有有效子数组？答：计数仍用树状数组 O(n log n)，但输出方案数可能 O(n²)，需按需枚举并说明输出本身的下界。
