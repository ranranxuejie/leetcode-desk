## 一句话思路
快慢指针找中点后反转后半段，再与前半段逐节点比对，用 O(1) 空间完成回文判定。

## 怎么做
1. 快指针 `fast` 每次走两步、慢指针 `slow` 每次走一步，循环结束时 `slow` 落在后半段起点（偶数长度）或正中间（奇数长度）。
2. 从 `slow` 起反转后半段链表，得到新头 `prev`。
3. 用 `head` 和 `prev` 同步前进比对 `val`，任一不等即返回 `False`。
4. 全部相等返回 `True`。

以 `[1,2,3,3,2,1]` 为例：循环结束时 `slow` 指向第 4 个节点（值 3），反转后 `prev` 指向原最后一个节点（值 1），`head` 仍是值 1 的头节点，两路同步走 3 步全部相等。

```python
fast = slow = head
while fast and fast.next:
    fast = fast.next.next
    slow = slow.next
prev = None
while slow:
    slow.next, prev, slow = prev, slow, slow.next
left, right = head, prev
while right:
    if left.val != right.val:
        return False
    left, right = left.next, right.next
return True
```

奇数长度时 `slow` 停在正中间那个节点，反转后它成为后半段尾部，`right` 比 `left` 少走一步，所以循环条件写 `while right` 而不是 `while left`。

## 复杂度
时间 O(n)：找中点、反转、比对各扫一遍，合计约 2n 次指针移动。
空间 O(1)：只用了 `fast`、`slow`、`prev`、`left`、`right` 五个指针，没有额外容器。

## 易错点
- 输入 `[1,2,1]`（奇数长度）→ 若比对循环写成 `while left`，`left` 会多走一步到已反转的中间节点，与 `right` 的 `None` 比较报错 → 正确做法是循环条件用 `while right`，让较短的后半段控制次数。
- 输入 `[1,2]` → 若找中点后忘记判断 `slow` 是否为空就直接反转，或把 `fast.next.next` 写成 `fast.next`，`slow` 会停在错误位置导致误判为 `True` → 正确做法是循环条件严格写 `while fast and fast.next`，保证 `slow` 恰好落在后半段起点。

## 如果面试官追问
问：不允许修改原链表怎么办？
答：改用递归，用函数调用栈从尾到头回溯比对，时间 O(n)、空间 O(n)，代价是栈深度等于链表长度。
