## 一句话思路
统计全部字符的总频次，若每个字母的计数都能被 `len(words)` 整除，就能均分给每个字符串。

## 怎么做
1. 用 `Counter` 把 `words` 里所有字符串拼起来的字符全部计数。
2. 设 `n = len(words)`，遍历计数结果，检查每个 `cnt % n == 0`。
3. 任一字母不整除就返回 `False`，全通过返回 `True`。

以 `words = ["abc","aabc","bc"]` 为例，`n = 3`，总计数是 `a:3, b:3, c:3`，三个值都 `% 3 == 0`，所以返回 `True`。反例 `["ab","a"]`：`n = 2`，计数 `a:2, b:1`，`b` 的 `1 % 2 != 0`，返回 `False`。

```python
from collections import Counter

def makeEqual(words):
    n = len(words)
    cnt = Counter("".join(words))
    for v in cnt.values():
        if v % n != 0:
            return False
    return True
```

关键点：操作允许字符在任意两个字符串间自由搬运，所以唯一约束是「每种字符的总数能被字符串个数整除」——每个字符串最终长度都是 `总长度 / n`，字符构成也必须一致。

## 复杂度
时间：O(L)，L 为所有字符串字符总数，拼接与计数各扫一遍。
空间：O(1)，`Counter` 最多 26 个键（小写字母表固定）。

## 易错点
- 输入 `["ab","a"]` → 若只比较各字符串长度是否相等会误判为 `True`（长度 2 和 1 不等其实已排除，但换成 `["ab","ba"]` 长度相等却字符分布不同）→ 正确做法是必须按字符频次对 `n` 取模，不能只看长度。
- 输入 `["a","a","a"]` → 若误用 `len(set(words)) == 1` 判断会得 `True` 但逻辑不通用；换成 `["ab","ab","ab"]` 看似相等，但若题目改成允许移动后需重新分配，仍要回到频次整除判断，不能依赖原串是否已相等。

## 如果面试官追问
问：若要求输出一种具体分配方案怎么办？
答：对每个字母按 `cnt // n` 个分给每个字符串，剩余按顺序补齐，构造出目标串即可。
