## 一句话思路
边扫边维护每个数的频次 `cnt` 和「频次→有多少个数」的 `freq`，每步用三条判据判断当前前缀能否删一个数后频次全等。

## 怎么做
1. 维护 `cnt[x]`（x 出现次数）、`freq[c]`（出现 c 次的数有几个）、`maxc`（当前最大频次）。
2. 每读入一个 `x`，先把旧的 `cnt[x]` 从 `freq` 里减掉，再更新 `cnt[x]` 和 `freq`，同步 `maxc`。
3. 用三条判据判断长度 `i+1` 的前缀是否合法，合法就更新答案。
4. 三条判据：`maxc == 1`（全不同，删谁都行）；`freq[maxc] == 1 and freq[maxc-1] * (maxc-1) + maxc == i+1`（只有一个数频次为 maxc，删它一次）；`freq[maxc] * maxc == i - 1`（其余都是 maxc 次，只有一个数频次为 1，删掉它）。

拿示例 1 走一遍：扫到 `[2,2,1,1,5,3,3]`（i+1=7）时，`cnt = {2:2, 1:2, 5:1, 3:2}`，`maxc=2`，`freq[2]=3`，`freq[1]=1`。第三条判据 `freq[2]*2 = 6 = 7-1` 成立，答案更新为 7。

```python
cnt, freq = {}, {}
maxc = ans = 0
for i, x in enumerate(nums):
    c = cnt.get(x, 0)
    if c:
        freq[c] -= 1
    cnt[x] = c + 1
    freq[c + 1] = freq.get(c + 1, 0) + 1
    maxc = max(maxc, c + 1)
    n = i + 1
    if maxc == 1 or \
       (freq[maxc] == 1 and freq.get(maxc - 1, 0) * (maxc - 1) + maxc == n) or \
       (freq[maxc] * maxc == n - 1):
        ans = n
```

## 复杂度
时间 O(n)：每个元素 O(1) 更新 `cnt`/`freq`/`maxc`。
空间 O(n)：`cnt` 与 `freq` 各存至多 n 个键。

## 易错点
- 输入 `[1,1]` → 若漏掉 `maxc == 1` 判据，会错判为不合法返回 0；正确做法是单独处理「所有数频次都是 1」，此时删任意一个都合法，答案取满长。
- 输入 `[1,1,1,2,2,2,3,3,3,4,4,4,5]` → 若把第三条判据写成 `freq[maxc]*maxc == n`，会漏掉「删掉频次为 1 的那个数」的情形，错成 12；正确做法是减 1 后比较，即 `freq[maxc]*maxc == n - 1`。

## 如果面试官追问
问：要求返回删除后每个数出现次数相同的具体方案怎么办？
答：在三条判据命中时记录 `maxc` 和 `freq` 快照，回溯找出频次为 `maxc` 或 1 的那个数，返回它的一个下标即可。
