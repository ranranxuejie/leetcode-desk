## 一句话思路
先预处理「置位数 → 1 需要几步」，再用数位 DP 统计小于 n 且置位数落在可约简集合里的数。

## 怎么做
1. 预处理 `step[c]`：`step[1]=0`，其余 `step[c]=step[popcount(c)]+1`，c 最大 800，几十步内收敛。
2. 可约简的置位数集合 `good = {c : step[c] <= k-1}`，因为从 x 到 1 的第一步就是 popcount(x)，之后还需 `step[c]` 步，总步数 `1+step[c] <= k`。
3. 数位 DP：从高位到低位枚举 s，维护已放 1 的个数 `ones`，遇到 `s[i]=='1'` 时，把这一位放 0、后面 `rem` 位任取，累加 `C(rem, j)` 对所有满足 `ones+j ∈ good` 的 j。
4. 最后减去 x=0 这一项（若 0 被算进去），并注意 s 本身不参与统计。

以 `s="111", k=1` 为例：`good={1}`（step[1]=0）。i=0 时 rem=2，ones=0，需 j=1，`C(2,1)=2`；i=1 时 rem=1，ones=1，需 j=0，`C(1,0)=1`；i=2 时 rem=0，ones=2，不满足。合计 3，与答案一致。

```python
MOD = 10**9 + 7
L = len(s)
# 组合数 C[i][j]
C = [[0]*(L+1) for _ in range(L+1)]
for i in range(L+1):
    C[i][0] = 1
    for j in range(1, i+1):
        C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD

step = [0]*(L+1)
for c in range(2, L+1):
    step[c] = step[bin(c).count('1')] + 1
good = {c for c in range(1, L+1) if step[c] <= k-1}

ans, ones = 0, 0
for i, ch in enumerate(s):
    if ch == '1':
        rem = L - i - 1
        for j in range(rem + 1):
            if ones + j in good:
                ans = (ans + C[rem][j]) % MOD
        ones += 1
return ans % MOD
```

## 复杂度
时间：O(L²)，组合数表 O(L²) 主导，DP 扫描 O(L²)。
空间：O(L²)，存 C 表；step 和 good 只占 O(L)。

## 易错点
- `s="1"` 时循环里 `ch=='1'` 但 rem=0、ones=0，`0 not in good`，ans=0，正确；若把 good 写成含 0 会多算。
- `k=1` 时 good 只含 1，但 `step[1]=0` 需 `1+0<=1` 成立；若写成 `step[c]<=k` 会把 2、4 等漏掉或多算，务必用 `step[c] <= k-1`。
- 统计的是「小于 n」，s 本身不能计入；上面的循环只在 `s[i]=='1'` 时把该位改 0 再累加，天然排除了 s 自身，别额外加 1。

## 如果面试官追问
若 k 很大（如 k=800）怎么办？答：good 会覆盖几乎所有 c，直接返回 n-1 的模值，或把 step 预处理上限提到 L 即可，逻辑不变。
