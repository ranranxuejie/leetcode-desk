## 一句话思路
逐行逐列各建一个长度 n+1 的布尔数组，边扫边标记，重复即判假。

## 怎么做
1. 取 `n = len(matrix)`，外层循环 `i` 从 0 到 n-1，同时处理第 `i` 行和第 `i` 列。
2. 每轮新建 `row_seen = [False] * (n + 1)` 和 `col_seen = [False] * (n + 1)`。
3. 内层 `j` 从 0 到 n-1，分别读 `matrix[i][j]` 和 `matrix[j][i]`，若对应 `seen` 已为 `True` 就返回 `False`，否则置 `True`。
4. 全部循环走完返回 `True`。

以示例 2 的 `matrix = [[1,1,1],[1,2,3],[1,2,3]]` 为例：`i = 0` 时 `row_seen` 依次标记 1、1——第二次读到 `matrix[0][1] = 1` 时 `row_seen[1]` 已是 `True`，直接返回 `False`，根本不用检查列。

```python
n = len(matrix)
for i in range(n):
    row_seen = [False] * (n + 1)
    col_seen = [False] * (n + 1)
    for j in range(n):
        r, c = matrix[i][j], matrix[j][i]
        if row_seen[r] or col_seen[c]:
            return False
        row_seen[r] = col_seen[c] = True
return True
```

关键点：题目保证 `1 <= matrix[i][j] <= n`，所以「n 个格子互不相同」等价于「恰好是 1..n 的一个排列」，不需要额外统计缺了哪个数。

## 复杂度
时间：O(n²)，每个格子被行、列各访问一次。
空间：O(n)，每轮复用两个长度 n+1 的布尔数组，不随 n² 增长。

## 易错点
- 输入 `[[1]]`（n=1）→ 若把 `seen` 开成 `[False] * n` 会下标越界 → 必须开 `n + 1`，因为值域是 1..n 而非 0..n-1。
- 输入示例 2 这类「行合法但列不合法」的矩阵 → 只查行会误判为 `True` → 必须在同一轮里用 `matrix[j][i]` 同步查列，别写成两个独立循环后漏掉列检查。

## 如果面试官追问
问：如果矩阵不是方阵、值域也不保证在 1..n 内怎么办？
答：先判 `len(matrix) == len(matrix[0])`，再把 `seen` 换成 `set` 并显式比对 `len(set) == n`。
