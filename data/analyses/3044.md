## 一句话思路
从每个格子沿 8 个方向延伸拼数，用哈希表计数，再筛出大于 10 的质数取频率最高者。

## 怎么做
1. 预处理质数表：最大数字不超过 6 位（矩阵最多 6×6，单方向最长 6 格），筛到 10**6 即可。
2. 对每个起点 `(i,j)`，枚举 8 个方向 `(di,dj)`，沿方向逐步累加 `cur = cur * 10 + mat[x][y]`。
3. 每走一步若 `cur > 10` 且为质数，就 `cnt[cur] += 1`。
4. 遍历 `cnt`，按 `(频率, 数值)` 取最大，无则返回 -1。

以示例 1 的 `mat = [[1,1],[9,9],[1,1]]` 为例，从 `(0,0)` 向东南走：`cur` 依次为 1、19，19 是质数计入；向南走：1、19、191，19 和 191 都计入。最终 `cnt[19]` 累计到 4，是最高频质数。

```python
limit = 10 ** 6
is_p = [True] * (limit + 1)
is_p[0] = is_p[1] = False
for i in range(2, int(limit ** 0.5) + 1):
    if is_p[i]:
        for j in range(i * i, limit + 1, i):
            is_p[j] = False

cnt = {}
m, n = len(mat), len(mat[0])
for i in range(m):
    for j in range(n):
        for di, dj in dirs:
            x, y, cur = i, j, 0
            while 0 <= x < m and 0 <= y < n:
                cur = cur * 10 + mat[x][y]
                if cur > 10 and is_p[cur]:
                    cnt[cur] = cnt.get(cur, 0) + 1
                x += di; y += dj
```

## 复杂度
时间：O(m·n·8·L + 10^6)，L 为单方向最长格数（≤6），筛表占主导。
空间：O(10^6) 的 `is_p` 布尔表，加 O(不同质数个数) 的 `cnt`。

## 易错点
- 输入 `mat = [[7]]` → 若把 `cur > 10` 写成 `cur >= 10` 或漏判，会把 7 计入并返回 7 → 必须严格 `cur > 10`，单格矩阵返回 -1。
- 输入含大量重复路径 → 若从每个格子只朝 4 个方向走，会漏掉东南、西南、西北、东北四条斜线，示例 1 的 19 就少算一半 → 必须枚举全部 8 个方向。

## 如果面试官追问
问：矩阵扩大到 100×100 怎么办？答：单方向最长 100 格，数字达 100 位，质数表失效，需改用 Miller-Rabin 判素，且只对 `cur > 10` 的候选做概率判素。
