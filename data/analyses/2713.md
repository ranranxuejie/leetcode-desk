## 一句话思路
按值从小到大分组处理，用 `row_best`/`col_best` 记录每行每列已能到达的最长链，同值必须整组算完再更新，避免同值互推。

## 怎么做
1. 把所有格子按 `(mat[i][j], i, j)` 排序，同值聚成一组。
2. 对组内每个格子算 `cur = max(row_best[i], col_best[j]) + 1`，先只存进临时列表，不写回。
3. 整组算完后，再用临时值更新 `row_best[i]` 和 `col_best[j]`，答案取全局最大。
4. 关键中间值：以 `mat = [[3,1],[3,4]]` 为例，排序后处理值 1 的格子 `(0,1)`，此时 `row_best=[0,0]`、`col_best=[0,0]`，得 `cur=1`；处理值 3 的两个格子 `(0,0)`、`(1,0)` 时 `col_best[0]` 仍是 0（同值未写回），各得 `cur=1`；最后值 4 的格子 `(1,1)` 读到 `row_best[1]=1`，得 `cur=2`，答案 2。

```python
cells = sorted((mat[i][j], i, j) for i in range(m) for j in range(n))
row_best, col_best = [0] * m, [0] * n
ans, k = 0, 0
while k < len(cells):
    v, tmp = cells[k][0], []
    while k < len(cells) and cells[k][0] == v:
        _, i, j = cells[k]
        tmp.append((i, j, max(row_best[i], col_best[j]) + 1))
        k += 1
    for i, j, c in tmp:
        row_best[i] = max(row_best[i], c)
        col_best[j] = max(col_best[j], c)
        ans = max(ans, c)
```

## 复杂度
时间：排序 `m*n` 个格子贡献 `O(mn log(mn))`，扫描一遍 `O(mn)`。
空间：`cells` 存 `mn` 个三元组，`row_best`/`col_best` 各 `m`、`n`，共 `O(mn)`。

## 易错点
- 输入 `[[1,1],[1,1]]` → 若边算边写回 `row_best`，第二个同值格子会读到刚写的 1 得到 2，错答 2 → 必须整组算完再统一更新，正确答案 1。
- 输入 `[[3,1],[3,4]]` → 若只按行或只按列递推，会漏掉跨行列的转移（如 `(0,1)→(1,1)` 靠列、`(1,0)→(1,1)` 靠行）→ 必须同时维护 `row_best` 和 `col_best` 并取 `max`。

## 如果面试官追问
问：要求输出具体路径怎么办？答：在 `tmp` 里额外存前驱格子坐标，更新 `row_best`/`col_best` 时一并记录，最后从 `ans` 对应格子回溯即可。
