## 一句话思路
用 `astype(int)` 把 `grade` 列从 float 转成 int，因为示例里 73.0、87.0 都是整值，直接截断不丢信息。

## 怎么做
1. 拿到 `students` 这个 DataFrame，定位到 `grade` 列。
2. 对 `grade` 调用 `.astype(int)`，返回新列或直接赋回。
3. 返回整个 DataFrame，其余三列 `student_id`、`name`、`age` 原样不动。

以官方示例为例，`grade` 列原始值是 `[73.0, 87.0]`，`dtype` 为 `float64`；执行 `astype(int)` 后中间结果变成 `[73, 87]`，`dtype` 变为 `int64`，而 `student_id` 仍是 `[1, 2]`、`age` 仍是 `[6, 15]`，不受影响。

```python
def changeDatatype(students):
    students["grade"] = students["grade"].astype(int)
    return students
```

也可以写成 `students.astype({"grade": int})`，效果等价，但前者更直白，只碰一列，不会误伤 `student_id` 和 `age` 的 dtype。

## 复杂度
时间：O(n)，n 为行数，需逐行转换 `grade` 的 n 个值。
空间：O(n)，`astype` 生成新的整数列，额外开一个长度 n 的数组。

## 易错点
- 若 `grade` 出现 `73.5` 这类非整值 → `astype(int)` 会**截断**成 73 而非四舍五入 → 本题示例全是 `.0`，但换数据要先确认语义，需要四舍五入得用 `.round().astype(int)`。
- 若 `grade` 含 `NaN` → `astype(int)` 直接抛 `ValueError: Cannot convert non-finite values` → 正确做法是先 `fillna` 或 `dropna`，不能裸转。

## 如果面试官追问
问：如果 `grade` 有缺失值怎么办？
答：先 `students["grade"].fillna(0)` 或按业务填默认值，再 `astype(int)`，否则转换会报错。
