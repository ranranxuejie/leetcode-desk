## 一句话思路
用 `dp[i]` 表示 `s[:i]` 的最少剩余字符数，枚举以 `i` 结尾的字典词做转移，多出的字符单独丢弃。

## 怎么做
1. 建 `dp = [0] + [inf]*n`，`dp[i]` 表示前 `i` 个字符的最优剩余数。
2. 对每个 `i`，先令 `dp[i] = dp[i-1] + 1`，即 `s[i-1]` 直接丢弃。
3. 再枚举 `dictionary` 中每个词 `w`，若 `i >= len(w)` 且 `s[i-len(w):i] == w`，则 `dp[i] = min(dp[i], dp[i-len(w)])`。
4. 返回 `dp[n]`。

以 `s = "leetscode"`、`dictionary = ["leet","code","leetcode"]` 为例：算到 `i = 4` 时，`s[0:4] == "leet"`，`dp[4] = min(dp[3]+1, dp[0]) = 0`；算到 `i = 9` 时，`s[5:9] == "code"`，`dp[9] = min(dp[8]+1, dp[5])`，而 `dp[5] = dp[4]+1 = 1`（下标 4 的 `s` 被丢弃），故 `dp[9] = 1`。

```python
n = len(s)
dp = [0] + [n] * n
for i in range(1, n + 1):
    dp[i] = dp[i - 1] + 1
    for w in dictionary:
        L = len(w)
        if i >= L and s[i - L:i] == w:
            dp[i] = min(dp[i], dp[i - L])
return dp[n]
```

## 复杂度
时间：`O(n * m * L)`，`n = len(s)`，`m` 为词数，`L` 为词长，切片比较贡献 `L`。
空间：`O(n)`，只开 `dp` 数组，字典本身不计入。

## 易错点
- 输入 `s = "leetcode"`、`dictionary = ["leet","code","leetcode"]` → 若只按最短词贪心切 `"leet"+"code"` 会剩 0，但若先匹配 `"leetcode"` 也剩 0，看似都对；真正翻车在 `s = "leetscode"` 上贪心取 `"leetcode"` 失败后回退不彻底 → 必须用 `dp` 枚举所有结尾词，不能贪心。
- 输入 `s = "aaa"`、`dictionary = ["aa"]` → 若忘记 `dp[i] = dp[i-1] + 1` 这条「丢弃」转移，`dp[3]` 会停在 `inf` 或错误值 → 每个 `i` 都要先无条件继承 `dp[i-1]+1`，再尝试匹配。

## 如果面试官追问
问：`n` 放大到 `10^5` 怎么办？答：把 `dictionary` 建成字典树，从每个 `i` 向前沿树走，转移从 `O(m*L)` 降到 `O(L)`，总 `O(n*L)`。
