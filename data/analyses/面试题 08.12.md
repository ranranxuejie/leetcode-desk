## 一句话思路
逐行放置皇后，用三个集合记录已占用的列、主对角线、副对角线，冲突即剪枝，走到第 n 行即得一个解。

## 怎么做
1. 递归参数 `row` 表示当前要放第几行，`cols`、`diag1`、`diag2` 分别记录已占用的列、`row-col`、`row+col`。
2. 在第 `row` 行枚举列 `c`，若 `c in cols or row-c in diag1 or row+c in diag2` 则跳过。
3. 否则把三个值加入集合，递归 `row+1`，返回后从集合移除（回溯）。
4. `row == n` 时把 `board` 的每行 `"".join` 成字符串，加入结果。

以 `n=4` 为例，第一行放 `c=1` 后 `cols={1}`、`diag1={-1}`、`diag2={1}`；递归到 `row=1` 时 `c=3` 被 `diag2` 中的 `1+3=4`？不冲突，但 `c=1` 因 `cols` 命中被剪，`c=3` 通过，继续到 `row=2` 时 `c=0` 因 `2-0=2` 不在 `diag1`、`2+0=2` 与已有 `diag2={1,4}` 不撞而通过，最终得到第一个解 `[".Q..","...Q","Q...","..Q."]`。

```python
def dfs(row):
    if row == n:
        res.append(["".join(r) for r in board])
        return
    for c in range(n):
        if c in cols or row - c in diag1 or row + c in diag2:
            continue
        board[row][c] = "Q"
        cols.add(c); diag1.add(row - c); diag2.add(row + c)
        dfs(row + 1)
        cols.remove(c); diag1.remove(row - c); diag2.remove(row + c)
        board[row][c] = "."
```

## 复杂度
时间：O(n!)，每行可选列数递减，剪枝后实际远小于 n^n。
空间：O(n)，三个集合各至多 n 个元素，递归栈深 n，结果集不计。

## 易错点
- `n=1` 时若忘记在 `row==n` 分支先构造 `board` 再 `join`，会返回 `[["Q"]]` 之外的错误结构；正确做法是 `board` 初始化为 `n` 行 `["."]*n`，命中时逐行 `join`。
- 回溯时只 `remove` 了 `cols` 却漏了 `diag1`/`diag2`，`n=4` 第二个解会被吞掉只剩 1 个；三个集合必须成对增删，且 `board[row][c]` 要复位成 `"."`。

## 如果面试官追问
问：只要求输出方案数怎么办？答：把 `res.append` 改成计数器 `+1`，空间降到 O(n)，时间不变。
