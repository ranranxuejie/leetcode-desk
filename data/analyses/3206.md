## 一句话思路
枚举每个位置 i 作中间瓷砖，用取模访问环上左右邻居，判断 colors[i] 是否同时异于两侧。

## 怎么做
1. 令 n = len(colors)，遍历 i 从 0 到 n-1。
2. 左邻居取 colors[(i-1) % n]，右邻居取 colors[(i+1) % n]，取模把环首尾接上。
3. 若 colors[i] != 左 且 colors[i] != 右，计数加一。
4. 返回计数。

以 colors = [0,1,0,0,1] 为例，n=5。i=0 时左邻居是 colors[4]=1、右邻居是 colors[1]=1，colors[0]=0 与两侧都不同，计数 1；i=1 时两侧都是 0、中间是 1，计数 2；i=2 时左 1 右 0、中间 0 与右相同，跳过；i=3 时左 0 右 1、中间 0 与左相同，跳过；i=4 时左 0 右 0、中间 1，计数 3。结果 3，与示例一致。

```python
n = len(colors)
ans = 0
for i in range(n):
    left = colors[(i - 1) % n]
    right = colors[(i + 1) % n]
    if colors[i] != left and colors[i] != right:
        ans += 1
return ans
```

关键在 `(i - 1) % n`：Python 的 `%` 对负数返回非负余数，`(0 - 1) % 5 == 4`，所以 i=0 时左邻居自动落到末尾，不需要单独写 `if i == 0` 分支。

## 复杂度
时间 O(n)：每个下标只做常数次取模和比较。
空间 O(1)：只用了 left、right、ans 三个变量。

## 易错点
- 用 `colors[i-1]` 直接取左邻居 → i=0 时变成 `colors[-1]`，虽然 Python 恰好取到末尾元素、结果碰巧对，但换成 `i+1` 越界就崩；统一写 `% n` 才稳。
- 把「交替」理解成三块颜色互不相同 → 本题只有 0/1 两种颜色，条件等价于中间与两侧都不同，写成 `len(set(...)) == 3` 会永远为假，答案恒为 0。

## 如果面试官追问
若 n 扩大到 10^5 且要求 O(1) 空间？答：本解已是 O(n) 时间 O(1) 空间，无需改动，直接可用。
