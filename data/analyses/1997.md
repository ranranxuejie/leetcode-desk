## 一句话思路
用 dp[i] 记录「第一次到达 i 的日期」，利用 nextVisit[i] ≤ i 保证回跳只落在已算好的区间，逐房间递推。

## 怎么做
1. 定义 `dp[i]` = 第一次访问房间 i 的日期，`dp[0] = 0`。
2. 关键观察：第一次到 i 时访问次数为奇数，会跳回 `nextVisit[i]`；要再回到 i，必须把 `[nextVisit[i], i-1]` 每个房间都走成偶数次，这段往返耗时 `dp[i] - dp[nextVisit[i]] + 1`。
3. 于是 `dp[i+1] = dp[i] + 1 + (dp[i] - dp[nextVisit[i]] + 1)`，化简为 `dp[i+1] = 2*dp[i] - dp[nextVisit[i]] + 2`，全程对 `10**9+7` 取模。
4. 答案就是 `dp[n-1]`。

以示例 2 `nextVisit = [0,0,2]` 为例：`dp[0]=0`；`dp[1] = 2*0 - dp[0] + 2 = 2`；`dp[2] = 2*2 - dp[0] + 2 = 6`，返回 6，与题面一致。

```python
MOD = 10**9 + 7
n = len(nextVisit)
dp = [0] * n
for i in range(n - 1):
    dp[i + 1] = (2 * dp[i] - dp[nextVisit[i]] + 2) % MOD
return dp[n - 1]
```

注意 `dp[nextVisit[i]]` 的下标一定 ≤ i，因为题目保证 `nextVisit[i] <= i`，所以递推时它已经算好，不需要额外回溯。

## 复杂度
时间：O(n)，一次线性递推，每个房间只算一次。
空间：O(n)，dp 数组存 n 个日期；可优化到 O(1) 但需保留历史值，一般不必。

## 易错点
- 输入 `nextVisit = [0,0,2]` 时若写成 `dp[i+1] = 2*dp[i] + 2`（漏减 `dp[nextVisit[i]]`），会得 `dp[2]=6` 碰巧对，但示例 3 `[0,1,2,0]` 会算错；必须减 `dp[nextVisit[i]]`。
- 忘记取模：n 到 10^5 时 dp 值指数增长，Python 虽不溢出但数字巨大拖慢运算；每步都对 `10**9+7` 取模，且减法后加 MOD 再取模避免负数。

## 如果面试官追问
问：能否把空间降到 O(1)？答：不能简单降，因为 `dp[nextVisit[i]]` 可能回跳到任意更早下标，需保留整个 dp 数组供随机访问。
