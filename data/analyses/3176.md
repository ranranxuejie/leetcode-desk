## 一句话思路
用 `dp[v][j]` 记以值 v 结尾、已用 j 次「不等」的最长长度，转移只分「接相同值」和「接不同值」两种。

## 怎么做
1. 状态定义：`dp[v][j]` = 以值 `v` 结尾、恰好用了 `j` 次相邻不等的子序列最大长度。
2. 转移分两类：接同值直接 `dp[v][j] + 1`；接不同值要枚举所有 `u != v`，取 `max(dp[u][j-1]) + 1`。
3. 用 `best[j]` 维护「所有值里 `dp[·][j]` 的最大值」，不同值转移就变成 `best[j-1] + 1`，省掉枚举 u。
4. 按 `nums` 顺序更新，注意 `best` 必须用更新前的旧值，所以每轮先算新 `dp` 再刷 `best`。

拿 `nums = [1,2,1,1,3], k = 2` 走一遍关键一步：处理到第 3 个元素 `1` 时，`dp[1][0]` 已是 1（子序列 `[1]`），接同值得 `dp[1][0] = 2`；同时 `best[0] = 1`（来自值 2），走不同值分支得 `dp[1][1] = best[0] + 1 = 2`。最终 `dp[1][2] = 4`，对应 `[1,2,1,1]`。

```python
from collections import defaultdict
dp = defaultdict(lambda: [-10**9] * (k + 1))
best = [-10**9] * (k + 1)
best[0] = 0
ans = 0
for x in nums:
    cur = dp[x][:]
    for j in range(k + 1):
        # 接相同值
        cur[j] = max(cur[j], dp[x][j] + 1)
        # 接不同值
        if j > 0:
            cur[j] = max(cur[j], best[j - 1] + 1)
    dp[x] = cur
    for j in range(k + 1):
        best[j] = max(best[j], cur[j])
        ans = max(ans, cur[j])
return ans
```

## 复杂度
时间：`O(n·k)`，n 为 `nums` 长度，每个元素扫 `k+1` 个状态。
空间：`O(d·k)`，d 为不同值个数，`dp` 哈希表 + 长度 `k+1` 的 `best`。

## 易错点
- `nums = [1,2,1,1,3], k = 2` 若在循环里就地改 `best` 再算不同值分支，会用本轮刚更新的 `best[j-1]`，把同一元素重复计数，答案偏大；正确做法是先算完 `cur` 再统一刷 `best`。
- `k = 0` 且 `nums = [1,2,3,4,5,1]` 时，若把「接不同值」分支写成无条件下标 `j-1`，会访问 `best[-1]` 拿到末尾垃圾值；正确做法是 `j > 0` 才走该分支，答案应为 2（两个 1）。

## 如果面试官追问
若 `k` 放大到 `n`（如 500）且 `n` 也到 5000，`O(n·k)` 还够吗？答：`n·k` 到 2.5e7 尚可，但可改用「按值分组 + 前缀最大值」把每轮压到 `O(k)`，本质不变。
