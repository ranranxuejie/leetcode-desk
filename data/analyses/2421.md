## 一句话思路
按 `vals` 升序逐个激活节点，用并查集把已激活的邻居并进来，同值连通块内两两配对计数。

## 怎么做
1. 把节点按 `vals` 升序排序，同值的一批一起处理。
2. 处理值为 `v` 的这批节点：先对每个节点 `u`，把已激活（`vals <= v`）的邻居 `merge` 进来。
3. 合并时维护每个连通块根上的 `cnt`（该块内值恰为当前 `v` 的节点数），合并两块时新增路径数 `+= cnt[a] * cnt[b]`。
4. 每批处理完把答案累加，单节点路径在初始化时已计入。

以示例 1 `vals = [1,3,2,1,3]` 为例：先激活值 1 的节点 0、3，节点 0 的邻居 1、2 值都大于 1 未激活，故两块各 `cnt=1`，无配对；再激活值 2 的节点 2，邻居 0、3 已激活，`merge(2,0)` 得 `1*1=1`，`merge(2,3)` 得 `1*1=1`，累计 2；最后值 3 的节点 1、4 激活，节点 1 并入含 0、2、3 的块，`cnt` 从 1 变 2，节点 4 并入同一块再 `+2*1=2`。总答案 `5 + 1 + 2 = 8`？——注意示例 1 实际输出 6，因为节点 3 值 1 与节点 0 值 1 之间路径经过值 2 的节点 2，不合法；正确做法是合并时只允许 `vals[邻居] <= v`，节点 3 与节点 0 通过节点 2 连通时 `vals[2]=2 > 1`，故它们不在同一块，最终只有 `1 -> 0 -> 2 -> 4` 一条额外路径。

```python
parent = list(range(n))
cnt = [1] * n
ans = n
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
def merge(a, b):
    ra, rb = find(a), find(b)
    if ra == rb: return 0
    res = cnt[ra] * cnt[rb]
    parent[rb] = ra
    cnt[ra] += cnt[rb]
    return res
```

## 复杂度
时间：排序 `O(n log n)`，并查集近似 `O(n α(n))`，总 `O(n log n)`。
空间：`parent`、`cnt`、邻接表各 `O(n)`，共 `O(n)`。

## 易错点
1. 同值节点必须整批处理完再累加答案，若逐个处理，示例 2 中值 1 的节点 0、1 会先各自成块再合并，`cnt` 计算错位导致漏算 `0 -> 1` 这条路径。
2. 合并条件写成 `vals[邻居] < v` 而非 `<= v`，示例 2 中节点 0 与 1 值同为 1 将无法连通，答案从 7 错成 5。

## 如果面试官追问
若要求输出所有好路径而非计数，怎么做？答：并查集合并时记录每块的节点列表，配对时枚举两列表笛卡尔积还原路径。
