## 一句话思路
二分出「卖到的价值下界」`k`，让所有高于 `k` 的球先按等差数列卖掉，剩余零头从 `k` 里补。

## 怎么做
1. 二分答案 `k`：统计所有 `inventory[i] > k` 的球，从 `inventory[i]` 卖到 `k+1`，共 `inventory[i]-k` 个，累加数量 `cnt`。
2. 找最大的 `k` 使 `cnt <= orders`，此时 `k+1` 以上的球必须全卖，剩下的 `orders-cnt` 个球价值都是 `k`。
3. 用等差数列求和 `(hi+lo+1)*(hi-lo)//2` 累加每段，最后补 `(orders-cnt)*k`。

以 `inventory=[2,5], orders=4` 为例：二分得 `k=2`，`5` 卖到 `3` 共 3 个（`cnt=3`），剩 1 个价值 `2`，总和 `5+4+3+2=14`。

```python
lo, hi = 0, max(inventory)
while lo < hi:
    mid = (lo + hi + 1) // 2
    cnt = sum(x - mid for x in inventory if x > mid)
    if cnt <= orders:
        lo = mid
    else:
        hi = mid - 1
k = lo
ans = cnt = 0
for x in inventory:
    if x > k:
        ans += (x + k + 1) * (x - k) // 2
        cnt += x - k
ans += (orders - cnt) * k
return ans % (10**9 + 7)
```

## 复杂度
时间：排序/二分 `O(n log max(inventory))`，`n` 是颜色数，`log` 来自二分上界。
空间：`O(1)`，只用了 `lo/hi/cnt/ans` 几个标量。

## 易错点
- `inventory=[1000000000], orders=1000000000` → 若先累加再取模，Python 虽不溢出但中间值巨大拖慢；正确做法是每段求和后立刻 `% (10**9+7)`，或最后统一取模（Python 可承受，但面试要说明）。
- `orders` 恰好等于某段总和时 → 若二分条件写成 `cnt < orders`，`k` 会偏小，多算一个价值 `k` 的球；正确用 `cnt <= orders`，让 `k` 取到最大可行值。

## 如果面试官追问
若 `orders` 远大于所有库存总和怎么办？答：题目保证 `orders <= sum(inventory)`，否则需先特判返回全卖总和。
