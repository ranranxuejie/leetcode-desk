## 一句话思路
枚举右端点，用两个单调队列维护窗口内质数的最大最小值，双指针收缩到合法后一次性计入左端点可选数。

## 怎么做
1. 先筛出 `5*10^4` 以内的质数表，把 `nums` 中质数的下标和值单独抽成 `pos`、`val` 两个列表，非质数只影响左端点能往左延伸多远。
2. 右指针 `r` 扫 `pos`，把 `val[r]` 压入维护最大值的递减队列 `qmax` 和维护最小值的递增队列 `qmin`。
3. 当 `val[qmax[0]] - val[qmin[0]] > k` 时，左指针 `l` 右移并弹出队头过期下标，直到差值 ≤ k。
4. 此时窗口 `[l, r]` 内质数个数为 `r-l+1`，若 ≥2，则以 `pos[r]` 结尾、质数起点落在 `pos[l..r-1]` 的合法子数组左端点可取 `pos[l-1]+1 .. pos[r-1]`，累加 `pos[r-1] - (pos[l-1] if l>0 else -1)`。

以 `nums=[2,3,5,7], k=3` 为例：`pos=[0,1,2,3]`，`r=3` 时 `qmax` 队头是 7、`qmin` 队头是 2，差 5>3，`l` 移到 1，差变 4>3，`l` 移到 2，此时 `qmax=[3]`、`qmin=[2]`，差 2≤3，计入 `pos[2]-pos[1]=1` 个。

```python
for r in range(len(pos)):
    while qmax and val[qmax[-1]] <= val[r]: qmax.pop()
    qmax.append(r)
    while qmin and val[qmin[-1]] >= val[r]: qmin.pop()
    qmin.append(r)
    while val[qmax[0]] - val[qmin[0]] > k:
        l += 1
        if qmax[0] < l: qmax.popleft()
        if qmin[0] < l: qmin.popleft()
    if r - l + 1 >= 2:
        left = pos[l - 1] if l > 0 else -1
        ans += pos[r - 1] - left
```

## 复杂度
时间：筛质数 `O(M log log M)`，`M=5*10^4`；双指针每个质数下标进出队各一次，`O(n)`。
空间：质数表 `O(M)`，两个单调队列与 `pos/val` 共 `O(n)`。

## 易错点
- `nums=[1,2,3]` 这类前缀有非质数：若把左端点直接取 `pos[l]`，会漏掉 `[1,2,3]` 这种从下标 0 开始的子数组，正确做法是左端点下界取 `pos[l-1]+1`（`l=0` 时取 0）。
- `nums=[2,3,5], k=0`：窗口内质数差恒 >0，`l` 会一路推到 `r`，此时 `r-l+1==1` 必须跳过累加，否则会把只含一个质数的子数组算进去。

## 如果面试官追问
若 `nums[i]` 上限提到 `10^9`：筛法失效，改用 Miller-Rabin 逐个数判质，双指针与单调队列结构不变，时间仍是 `O(n)` 次判定。
