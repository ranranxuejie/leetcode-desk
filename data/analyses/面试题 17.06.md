## 一句话思路
按位统计：对每一位算它上面出现 2 的次数，高位、当前位、低位三段拼出计数，逐位相加。

## 怎么做
1. 从个位开始，令 `factor = 1`，每轮取 `high = n // (factor * 10)`、`cur = n // factor % 10`、`low = n % factor`。
2. 当前位贡献分三种：`cur < 2` 时是 `high * factor`；`cur == 2` 时是 `high * factor + low + 1`；`cur > 2` 时是 `(high + 1) * factor`。
3. 累加后 `factor *= 10`，直到 `factor > n`。

以 n = 25 为例，个位 `factor=1`：`high=2, cur=5, low=0`，`cur>2` 贡献 `(2+1)*1 = 3`（即 2、12、22 的个位）。十位 `factor=10`：`high=0, cur=2, low=5`，`cur==2` 贡献 `0*10 + 5 + 1 = 6`（20~25 的十位）。合计 3 + 6 = 9，与示例一致。

```python
def count2(n):
    total, factor = 0, 1
    while factor <= n:
        high = n // (factor * 10)
        cur = n // factor % 10
        low = n % factor
        if cur < 2:
            total += high * factor
        elif cur == 2:
            total += high * factor + low + 1
        else:
            total += (high + 1) * factor
        factor *= 10
    return total
```

关键在 `cur == 2` 那一支：`low + 1` 是因为当前位固定为 2 时，低位可以从 0 取到 `low`，共 `low + 1` 种。

## 复杂度
时间 O(log n)：`factor` 每次乘 10，循环次数是 n 的十进制位数。
空间 O(1)：只开了 `total`、`factor`、`high`、`cur`、`low` 五个整数。

## 易错点
- 输入 n = 0 → 若循环条件写成 `while factor < n` 或直接返回 `factor`，会漏掉 0 这一位或死循环；正确做法是 `while factor <= n`，n = 0 时一次都不进循环、返回 0。
- 输入 n = 22 → 若把 `cur == 2` 也按 `high * factor` 算，十位只算 0*10 = 0，漏掉 20~22 的 3 次；正确做法是 `cur == 2` 时加 `low + 1`，得 `0 + 2 + 1 = 3`。

## 如果面试官追问
问：n 改成 10^18 呢？答：算法不变，循环次数变成 19 次，Python 大整数直接算，无需改类型。
