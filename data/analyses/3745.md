## 一句话思路
排序后取最大的两个数之和减去最小的数，因为 a、b 只贡献正值、c 只贡献负值，三者下标天然不同。

## 怎么做
1. 对 `nums` 排序，最大值和次大值一定在末尾，最小值一定在开头。
2. 取 `nums[-1] + nums[-2] - nums[0]` 作为答案。
3. 用官方示例 1 `[1,4,2,5]` 验证：排序得 `[1,2,4,5]`，`nums[-1]=5`、`nums[-2]=4`、`nums[0]=1`，结果 `5+4-1=8`，与输出一致。
4. 示例 2 `[-2,0,5,-2,4]` 排序得 `[-2,-2,0,4,5]`，`5+4-(-2)=11`，也吻合。

```python
nums.sort()
return nums[-1] + nums[-2] - nums[0]
```

关键中间值：示例 2 里 `nums[0]` 是 `-2` 而不是 `0`，因为排序后两个 `-2` 都排在 `0` 前面，取到的是更小的那个，减负数反而加分，这正是答案能到 11 的原因。

## 复杂度
时间 O(n log n)：排序贡献 n log n，取三个下标是 O(1)。
空间 O(1)：排序原地进行，只用了三个下标变量。

## 易错点
- 输入 `[1,4,2,5]` 时若误以为 a、b、c 必须按原顺序取（a 在下标 0、b 在下标 1、c 在下标 2），会算成 `1+4-2=3`；题目只要求下标互不相同，正确做法是排序后取 `nums[-1]+nums[-2]-nums[0]`。
- 输入 `[-2,0,5,-2,4]` 时若把 c 取成 `nums[0]` 之外的“最小非负数”或误用 `min` 时跳过重复值，会得到 `5+4-0=9`；正确做法是直接取排序后第一个元素 `-2`，重复值不影响，`5+4-(-2)=11`。

## 如果面试官追问
问：如果要求输出具体下标而不是值？答：排序前先记录每个元素的原下标，取末尾两个和开头一个的原下标即可，注意三个下标互不相同。
