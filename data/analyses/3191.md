## 一句话思路
从左往右扫，遇到 0 就必须以它为左端点翻转，用队列记录未失效的翻转次数判断当前位实际值。

## 怎么做
1. 维护 `queue` 存每次翻转的左端点 `i`，`flip` 表示当前下标已被覆盖的翻转次数。
2. 遍历 `i`，若 `queue[0] == i-3` 则出队（该翻转已不影响 `i`），`flip` 同步减一。
3. 当前实际值为 `nums[i] ^ (flip & 1)`，若为 0 则必须以 `i` 为左端点翻转：`i+2 < n` 才可行，否则返回 -1。
4. 入队 `i`、`flip += 1`、`ans += 1`。

以 `nums = [0,1,1,1,0,0]` 为例：`i=0` 时 `flip=0`，`nums[0]^0=0`，翻转 `[0,2]`，`queue=[0]`，`flip=1`；`i=1` 时 `flip=1`，`1^1=0`，翻转 `[1,3]`，`queue=[0,1]`，`flip=2`；`i=3` 时 `queue[0]=0` 出队，`flip=1`，`nums[3]^1=0`，翻转 `[3,5]`，`ans=3`。

```python
from collections import deque
q = deque()
flip = ans = 0
n = len(nums)
for i in range(n):
    if q and q[0] == i - 3:
        q.popleft()
        flip -= 1
    if nums[i] ^ (flip & 1) == 0:
        if i + 2 >= n:
            return -1
        q.append(i)
        flip += 1
        ans += 1
return ans
```

## 复杂度
时间：O(n)，每个下标最多入队出队各一次，循环体 O(1)。
空间：O(n)，`queue` 最坏存 n/3 个左端点。

## 易错点
- 输入 `[0,1,1,1]`：`i=0` 时 `i+2=2 < 4` 可翻转，但 `i=3` 处 `nums[3]^1=0` 且 `i+2=5 >= 4`，必须返回 -1；若只判断 `i+2 < n` 漏掉末尾残留会错答 1。
- 输入 `[1,0,1,0,1]`：`i=1` 翻转后 `i=3` 的 `flip` 应为 1（`queue=[1]`），若忘记 `i-3` 出队条件写成 `i-2`，`flip` 提前归零，`nums[3]^0=0` 会多翻一次得 2，正确是 1。

## 如果面试官追问
若要求输出具体翻转方案而非次数？答：把每次入队的 `i` 追加到 `ops` 列表，返回 `ops` 即可，逻辑不变。
