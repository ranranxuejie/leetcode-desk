## 一句话思路
先求总和，再用前缀和枚举每条水平/垂直切线，看前半和是否等于总和一半。

## 怎么做
1. 求 `total = sum(map(sum, grid))`，若 `total` 为奇数直接返回 `False`（正整数下两部分和必为整数）。
2. 水平切：逐行累加 `row_sum`，在 `i` 从 0 到 m-2 时判断 `row_sum * 2 == total`。
3. 垂直切：逐列累加 `col_sum`，在 `j` 从 0 到 n-2 时判断 `col_sum * 2 == total`。

以 `grid = [[1,4],[2,3]]` 为例：`total = 10`，`target = 5`。水平切时 `i=0` 累加得 `row_sum = 1+4 = 5`，`5*2 == 10` 成立，返回 `True`。垂直切同理在 `j=0` 时 `col_sum = 1+2 = 3`，`3*2 != 10`，不成立。

```python
total = sum(map(sum, grid))
if total % 2:
    return False
m, n = len(grid), len(grid[0])
s = 0
for i in range(m - 1):
    s += sum(grid[i])
    if s * 2 == total:
        return True
s = 0
for j in range(n - 1):
    s += sum(grid[i][j] for i in range(m))
    if s * 2 == total:
        return True
return False
```

注意垂直切那层 `sum(grid[i][j] for i in range(m))` 是 O(m)，外层 n 次，合计 O(mn)，不会超时；但若想更稳可先算好每列和数组再扫。

## 复杂度
时间 O(m*n)：水平切 O(m*n)，垂直切 O(n*m)，各扫一遍。
空间 O(1)：只用了 `total`、`s` 等常数变量，没开额外矩阵。

## 易错点
- 切在最后一行/最后一列之后 → 会得到空部分却判 `True` → 循环上界必须是 `m-1`、`n-1`，不能写 `range(m)`。
- `total` 为奇数时仍去枚举 → 白跑一遍且可能因整数比较漏判 → 先 `if total % 2: return False` 提前剪枝，正整数保证两部分和相等时 `total` 必为偶数。

## 如果面试官追问
问：若要求返回具体切线位置和方向？
答：把 `return True` 改成 `return ("row", i)` 或 `("col", j)`，末尾返回 `None` 即可，逻辑不变。
