## 一句话思路
一次 DFS 求出每个子树的欧拉序区间，回文判定转成区间字符串哈希比较，O(n) 出全部答案。

## 怎么做
1. 按编号升序建孩子表，跑一次 DFS，记录每个节点进入/离开时的 `tin[x]`、`tout[x]`，并把 `s[x]` 追加到全局序列 `arr` 尾部（后序位置）。
2. 关键性质：`dfs(x)` 产生的字符串恰好是 `arr[tin[x]:tout[x]+1]`，因为子树内所有节点都在这个连续区间里。
3. 对 `arr` 和它的反转 `arr[::-1]` 各建前缀哈希，区间 `[l,r]` 的回文判定就是 `hash(arr,l,r) == hash(rev, n-1-r, n-1-l)`。
4. 对每个 x 取 `l=tin[x], r=tout[x]` 比较即可。

以示例 1 为例：`parent=[-1,0,0,1,1,2]`，节点 0 的孩子是 1、2，节点 1 的孩子是 3、4，节点 2 的孩子是 5。后序 DFS 得到 `arr="abaaba"`，`tin[0]=0, tout[0]=5`；节点 2 的区间是 `[4,5]`，对应 `"ab"`，正反哈希不等，`answer[2]=False`。

```python
MOD = (1 << 61) - 1
BASE = 131
def build(t):
    h = [0] * (len(t) + 1)
    for i, c in enumerate(t):
        h[i+1] = (h[i] * BASE + ord(c)) % MOD
    return h
def get(h, l, r):          # 闭区间 [l, r]
    return (h[r+1] - h[l] * pow(BASE, r-l+1, MOD)) % MOD
```

## 复杂度
时间 O(n)：一次 DFS 加 n 次 O(1) 哈希比较，`pow` 预计算后不再贡献 log。
空间 O(n)：`arr`、`tin/tout`、两组前缀哈希各占 n。

## 易错点
- 孩子遍历顺序：题目要求按节点编号升序，若直接按 `parent` 数组顺序挂链，示例 1 中节点 0 的孩子会变成 2、1，`arr` 变成 `"baaaba"`，`answer[0]` 会错判成 False。建表后必须对每个孩子列表 `sort()`。
- 哈希方向：反转串的区间要映射成 `[n-1-r, n-1-l]`，写成 `[l, r]` 会让所有长度 1 的串仍为 True、长度 2 的串全错，示例 1 的节点 2 会被误判为 True。用 `arr[::-1]` 建哈希时下标换算要单独验一遍。

## 如果面试官追问
若要求不用哈希、确定性判定？答：改用 Manacher 在 `arr` 上预处理每个中心的最长回文半径，再对每个区间 O(1) 查表，总时间仍是 O(n)。
