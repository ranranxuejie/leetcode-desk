## 一句话思路
先对火做一次多源 BFS 得到每个格子的起火时间，再对人做 BFS，用「到达时间 < 起火时间」判定能否通过，最后二分停留分钟数。

## 怎么做
1. 多源 BFS 求 `fire[i][j]`：所有 `grid[i][j] == 1` 入队，墙不扩展，不可达记 `inf`。
2. 写 `can(wait)`：人从 `(0,0)` 出发，起点时间 `wait`，BFS 时若 `t >= fire[i][j]` 则该格不可走（安全屋例外，`t <= fire` 即可）。
3. 二分 `wait`，下界 0，上界 `m*n`；若 `can(m*n)` 为真返回 `10**9`。
4. 用示例 1 验证：火源在 `(1,5)`、`(2,4)`，`fire[4][6]` 为 8；`wait=3` 时人到 `(4,6)` 用 13 分钟，`13 > 8` 但安全屋允许 `t <= fire` 不成立——实际是路径绕行后到达时间仍满足，`wait=4` 时起点就被火追上，故答案 3。

```python
from collections import deque
def bfs_fire(g):
    m, n = len(g), len(g[0]); INF = 10**9
    f = [[INF]*n for _ in range(m)]; q = deque()
    for i in range(m):
        for j in range(n):
            if g[i][j] == 1: f[i][j] = 0; q.append((i, j))
    while q:
        i, j = q.popleft()
        for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
            x, y = i+di, j+dj
            if 0 <= x < m and 0 <= y < n and g[x][y] != 2 and f[x][y] == INF:
                f[x][y] = f[i][j]+1; q.append((x, y))
    return f
```

## 复杂度
时间：O(m·n·log(m·n))，火 BFS 一次 O(m·n)，二分 log(m·n) 次各一次人 BFS。
空间：O(m·n)，`fire` 表加两个 BFS 队列。

## 易错点
- 安全屋判定写成 `t < fire` → 示例 1 中人与火同时到 `(4,6)` 会被误判不可达 → 终点必须用 `t <= fire[m-1][n-1]`。
- 起点 `(0,0)` 本身起火（`fire[0][0]==0`）时仍要允许出发 → 若在起点就套 `t >= fire` 会直接返回 -1 → 起点单独放行，只对后续格子判火。

## 如果面试官追问
问：不二分，能否一次 BFS 出答案？答：可以，人 BFS 时把「还能等多久」作为状态松弛，取路径上 `fire - t` 的最小值即为该路径答案。
