## 一句话思路
用单调栈从右往左扫，靠「当前值必须小于最近一次弹出的祖先」这条 BST 后序的充要条件判真伪。

## 怎么做
1. 从右往左遍历 `postorder`，维护一个**单调递减栈**（栈底到栈顶递减），以及变量 `root = -2**31`，表示「当前允许的最大下界」。
2. 对每个 `x`：若 `x < root`，直接返回 `False`；否则把栈里所有 `< x` 的元素弹出，最后一个弹出的值赋给 `root`。
3. 把 `x` 压栈，继续左移。

以 `postorder = [4,6,5,9,8]` 为例（从右往左）：`8` 入栈，栈 `[8]`，`root=-2**31`；`9` 弹出 `8`，`root=8`，栈 `[9]`；`5` 不弹，栈 `[9,5]`；`6` 弹出 `5`，`root=5`，栈 `[9,6]`；`4` 不弹，栈 `[9,6,4]`，全程 `x >= root`，返回 `True`。

对照 `[4,9,6,5,8]`：`8` 入栈；`5` 入栈；`6` 弹出 `5`，`root=5`；`9` 弹出 `6`、`8`（`8<9` 也弹），`root=8`；最后 `4 < root=8`，返回 `False`——正是示例 1 的答案。

```python
stack = []
root = -2**31
for x in reversed(postorder):
    if x < root:
        return False
    while stack and stack[-1] < x:
        root = stack.pop()
    stack.append(x)
return True
```

关键点：`root` 记录的是「最近一个把 `x` 当作左子树祖先的节点值」，它只会单调上升，所以后续任何比它小的值都说明越界。

## 复杂度
时间 O(n)：每个元素最多入栈、出栈各一次，`reversed` 只扫一遍。
空间 O(n)：最坏（严格递减序列）栈里存满 n 个元素，`root` 是常数。

## 易错点
- 输入 `[4,9,6,5,8]` 时若只写 `while stack and stack[-1] < x` 却忘了 `x < root` 的前置判断，会在 `4` 处漏判，错答 `True`；正确做法是每轮先比 `root` 再弹栈。
- 输入 `[1,3,2]` 这类「右子树比根大」的序列，若把 `root` 初始化为 `0` 或 `postorder[0]`，会把合法序列误判；`root` 必须初始化为 `-2**31`（题面无重复且长度 ≤1000，值域内足够小），保证第一轮不误杀。

## 如果面试官追问
问：若数组含重复数字怎么办？答：`x < root` 改 `x <= root` 会误杀合法重复，需先明确「重复值放左还是右」，再相应调整比较符，不能直接套用。
