## 一句话思路
先统计整串字符频次作为右侧初始状态，再从左往右扫，每步把当前字符从右侧搬到左侧，比较两侧不同字符数。

## 怎么做
1. 用 `Counter(s)` 得到右侧频次 `right`，左侧频次 `left` 初始为空，`ans = 0`。
2. 遍历 `s[:-1]`（最后一个字符不能切，右侧会为空），对每个字符 `ch`：`left[ch] += 1`，`right[ch] -= 1`，若 `right[ch] == 0` 则 `del right[ch]`。
3. 每步比较 `len(left) == len(right)`，相等则 `ans += 1`。

以 `s = "aacaba"` 为例，初始 `right = {a:4, c:1, b:1}`。切到 `i=2`（左 `"aac"`）时，`left = {a:2, c:1}` 长度 2，`right = {a:2, b:1}` 长度 2，相等，`ans` 加 1；切到 `i=3`（左 `"aaca"`）时 `left` 长度 2、`right = {a:1, b:1}` 长度 2，再得 1，最终 `ans = 2`。

```python
from collections import Counter

right = Counter(s)
left = Counter()
ans = 0
for ch in s[:-1]:
    left[ch] += 1
    right[ch] -= 1
    if right[ch] == 0:
        del right[ch]
    if len(left) == len(right):
        ans += 1
```

关键在 `del right[ch]`：不删的话 `len(right)` 会把频次为 0 的字符也算进去，`"aacaba"` 在 `i=4` 时右侧只剩 `{b:1}`，若不删 `a` 会误判长度 2。

## 复杂度
时间 O(n)：一次建 Counter、一次单遍扫描，n 为 `len(s)`。
空间 O(1)：两侧字典最多各存 26 个小写字母。

## 易错点
- 遍历写成 `for ch in s`（含最后一个字符）→ 最后一步右侧为空、`len(right) = 0`，若左侧恰好也为 0 才相等，但 `"aaaaa"` 会多算一次得 5 而非 4 → 必须用 `s[:-1]`，保证右侧非空。
- 只做 `right[ch] -= 1` 不删零频键 → `"aacaba"` 在 `i=4` 时 `len(right)` 仍为 2（`a` 残留 0 次），把本该不算的切法算进去 → 频次归零立即 `del`。

## 如果面试官追问
若要求返回所有好分割的下标列表而非计数？答：把 `ans += 1` 换成 `res.append(i + 1)`，其余逻辑不变，仍是 O(n)。
