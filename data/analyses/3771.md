## 一句话思路
把「从 j 出发的剩余生命」写成 `hp - (pre[i] - pre[j-1])`，得分条件变成前缀和比较，逐房间二分出最早失分点。

## 怎么做
1. 令 `pre[i] = damage[1]+...+damage[i]`，`pre[0]=0`；从 j 出发进到房间 i 后剩余生命是 `hp - (pre[i] - pre[j-1])`。
2. 得分条件 `hp - pre[i] + pre[j-1] >= requirement[i]` 等价于 `pre[i] + requirement[i] <= hp + pre[j-1]`，左边只与 i 有关。
3. 预处理 `need[i] = pre[i] + requirement[i]`，它对 i 单调递增（damage、requirement 都为正），于是对每个 j 二分找最后一个满足 `need[i] <= hp + pre[j-1]` 的 i。
4. 该 i 及之前全得分、之后全不得分，`score(j) = i - j + 1`（i < j 时记 0），累加。

用示例 1：`pre = [0,3,9,16]`，`need = [4,11,21]`。j=1 时阈值 `hp + pre[0] = 11`，二分得 i=2（need[2]=11 ≤ 11，need[3]=21 > 11），`score(1) = 2 - 1 + 1 = 2`，与题面一致。

```python
pre = [0] * (n + 1)
for i in range(1, n + 1):
    pre[i] = pre[i - 1] + damage[i - 1]
need = [pre[i] + requirement[i - 1] for i in range(1, n + 1)]
ans = 0
for j in range(1, n + 1):
    limit = hp + pre[j - 1]
    i = bisect_right(need, limit)  # 得分房间数（从 1 数起）
    if i >= j:
        ans += i - j + 1
return ans
```

## 复杂度
时间 O(n log n)：n 个起点各一次二分，二分贡献 log n。
空间 O(n)：额外开了 `pre` 和 `need` 两个长度 n+1 的数组。

## 易错点
- `hp=2, damage=[10000,1]`：若用 `hp - pre[i]` 直接和 requirement 比，会漏掉 `pre[j-1]` 这个起点偏移，j=2 时算成 `2-1=1` 之前先减了 10000，score(2) 错成 0；正确做法是阈值取 `hp + pre[j-1]`，j=2 时阈值 2，need[2]=2 命中，得 1 分。
- 二分结果 `i < j` 时（如示例 2 的 j=1，need[1]=10001 > 2，i=0），若直接累加 `i - j + 1` 会得到负数把答案拉低；必须先判 `i >= j` 再加。

## 如果面试官追问
若 n 升到 10^7 要求 O(n)？答：`need` 单调，用双指针随 j 递增地推进 i，均摊 O(n)。
