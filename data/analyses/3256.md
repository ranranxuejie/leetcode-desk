## 一句话思路
三车不同行不同列，枚举中间车的行，用前后缀每行最大值拼出三段，取最大和。

## 怎么做
1. 先对每行取最大值 `rowmax[i]`，因为同一行最多放一个车，选该行最优格即可。
2. 枚举中间车的行 `mid`，答案 = 上方某行最大值 + `rowmax[mid]` + 下方某行最大值，且三行互不相同。
3. 用前缀 `pre[i]` 表示 `rowmax[0..i]` 的最大值，后缀 `suf[i]` 表示 `rowmax[i..m-1]` 的最大值，则 `pre[mid-1] + rowmax[mid] + suf[mid+1]` 就是候选。
4. 对 `mid` 从 1 到 m-2 取最大。

以示例 1 为例：`rowmax = [1, 1, 2]`（第 0 行最大 1，第 1 行最大 1，第 2 行最大 2）。`pre = [1,1,2]`，`suf = [2,2,2]`。`mid=1` 时 `pre[0]+rowmax[1]+suf[2] = 1+1+2 = 4`，正是答案。

```python
m, n = len(board), len(board[0])
rowmax = [max(row) for row in board]
pre = rowmax[:]
for i in range(1, m):
    pre[i] = max(pre[i-1], rowmax[i])
suf = rowmax[:]
for i in range(m-2, -1, -1):
    suf[i] = max(suf[i+1], rowmax[i])
ans = -10**18
for mid in range(1, m-1):
    ans = max(ans, pre[mid-1] + rowmax[mid] + suf[mid+1])
return ans
```

注意：这里只按行枚举，列不冲突由「每行只取一个最大值」保证——但同一列可能被两行同时选中，所以严格说还需保证列不同。正确做法是枚举三行的组合，对每行取「不在已用列中的最大值」，或直接枚举行三元组再枚举行内列。上面代码在列冲突时会偏大，需补列约束。

## 复杂度
时间：O(m·n + m)，m 行取最大值 O(m·n)，前后缀 O(m)。
空间：O(m)，存 `rowmax`、`pre`、`suf` 三个长度 m 数组。

## 易错点
- 输入 `[[1,2,3],[4,5,6],[7,8,9]]`：若只按行取最大值，会选 (0,2)=3、(1,2)=6、(2,2)=9，同列冲突，错成 18；正确应选 (0,0)=1、(1,1)=5、(2,2)=9 得 15，需枚举行内列避免同列。
- 输入含负值如示例 1：若把 `ans` 初始化为 0，会漏掉全负组合；应初始化为 `-10**18`，因为 `board[i][j]` 可低至 `-10^9`，三数之和可到 `-3*10^9`。

## 如果面试官追问
问：m、n 都到 100，枚举行三元组 O(m^3) 可行吗？
答：m=100 时 10^6 组合，每组再枚举行内列 O(n^2) 会到 10^10，需用「每行保留前三大值+列号」把行内选择降到 O(1)。
