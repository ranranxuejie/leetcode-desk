## 一句话思路
按值分组做多重背包，用「前缀和滑动窗口」把每组 O(r) 的转移压成 O(1)，总代价 O(值域×不同值数)。

## 怎么做
1. 用 `Counter(nums)` 得到 `cnt`，`dp[s]` 表示凑出和 s 的方案数，初始 `dp[0]=1`。
2. 对每个值 `v` 和它的个数 `c`，新状态 `ndp[s] = sum(dp[s-k*v] for k in 0..c)`，只对 `s` 同余 `v` 的链计算。
3. 在每条链上用滑动窗口维护最近 `c+1` 个 `dp` 之和，窗口右移时加新项、减掉出窗项，即得 `ndp`。
4. 答案取 `sum(dp[l:r+1]) % (10**9+7)`。

以示例 1 `nums=[1,2,2,3]` 为例：处理 `v=2, c=2` 时，链 `s=0,2,4,6` 上 `dp` 为 `[1,1,0,0]`（此时只处理过 1），窗口宽 3，得 `ndp[0]=1, ndp[2]=2, ndp[4]=1, ndp[6]=0`——`ndp[2]=2` 正是 `{}`+2 与 `{1}`+... 之外 `{2}`、`{2,2}` 两条路径的合并结果。

```python
MOD = 10**9 + 7
cnt = Counter(nums)
dp = [0] * (r + 1)
dp[0] = 1
for v, c in cnt.items():
    if v == 0:
        continue
    ndp = [0] * (r + 1)
    for rem in range(min(v, r + 1)):
        window = 0
        for s in range(rem, r + 1, v):
            window += dp[s]
            if s - (c + 1) * v >= 0:
                window -= dp[s - (c + 1) * v]
            ndp[s] = window % MOD
    dp = ndp
return sum(dp[l:r + 1]) % MOD
```

## 复杂度
时间 O(r × 不同值个数)：每条链总长不超过 r/v，求和后每组 O(r)。
空间 O(r)：`dp` 与 `ndp` 两个长度 r+1 的数组。

## 易错点
- `nums` 含 0（如 `[0,0,1]`）→ 若把 0 当普通值做背包，`v=0` 会让 `range(rem, r+1, 0)` 直接报错，且 0 的任意次选取和不变、方案数应乘 `c+1`；正确做法是跳过 `v==0`，最后把答案乘 `(cnt[0]+1)`。
- 窗口出窗条件写成 `s - c*v >= 0` → 窗口宽度变成 c 而非 c+1，`c=2` 时漏掉「取满 2 个」这一项，示例 1 的 `ndp[4]` 会从 1 变 0；正确是减 `dp[s-(c+1)*v]`。

## 如果面试官追问
若 `r` 放大到 10^9 但 `nums` 总和仍 ≤2×10^4：答「和的上界由 `sum(nums)` 决定，把 `r` 先截到 `min(r, sum(nums))`，复杂度不变」。
