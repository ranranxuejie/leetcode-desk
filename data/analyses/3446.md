## 一句话思路
按 `i-j` 分组取对角线，左下（`i>=j`）降序、右上（`i<j`）升序，再按原位置写回。

## 怎么做
1. 用 `i-j` 作键收集每条对角线，键相同即在同一条对角线上。
2. 判断方向：键 `>=0` 落在左下三角形（含主对角线），用 `reverse=True`；键 `<0` 落在右上，用升序。
3. 排序后按收集顺序写回原坐标。

以 `grid = [[1,7,3],[9,8,2],[4,5,6]]` 为例，键 `0` 收集到 `[1,8,6]`，降序后为 `[8,6,1]`，写回 `(0,0),(1,1),(2,2)`；键 `-1` 收集到 `[7,2]`，升序后为 `[2,7]`，写回 `(0,1),(1,2)`。

```python
from collections import defaultdict
n = len(grid)
diag = defaultdict(list)
for i in range(n):
    for j in range(n):
        diag[i - j].append((i, j))
for k, cells in diag.items():
    vals = sorted((grid[i][j] for i, j in cells), reverse=(k >= 0))
    for (i, j), v in zip(cells, vals):
        grid[i][j] = v
```

## 复杂度
时间：O(n² log n)，每条对角线长度最多 n，排序总代价由 n 条对角线贡献。
空间：O(n²)，`diag` 存了全部坐标对。

## 易错点
- 主对角线 `i==j` 时键为 `0`，若写成 `k > 0` 才降序，`[1,8,6]` 会错排成 `[1,6,8]`；正确是 `k >= 0` 归入左下。
- 收集顺序必须与写回顺序一致：若先 `sorted` 坐标再取值，`(0,1),(1,2)` 的取值顺序会与排序结果错位；正确做法是先存 `(i,j)` 元组，排序值后按同一 `cells` 顺序 `zip` 写回。

## 如果面试官追问
若 n 扩大到 10³ 且要求 O(n²)？答：每条对角线用计数排序或双指针原地反转，避免 log n。
