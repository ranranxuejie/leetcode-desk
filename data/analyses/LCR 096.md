## 一句话思路
用二维 DP 记 `dp[i][j]`：`s1` 前 i 个字符与 `s2` 前 j 个字符能否拼出 `s3` 前 i+j 个字符，逐格转移。

## 怎么做
1. 先卡长度：`len(s1)+len(s2) != len(s3)` 直接返回 `False`，省掉后面所有计算。
2. 定义 `dp[i][j]` 为布尔值，`dp[0][0] = True`，`i` 走 `s1`、`j` 走 `s2`，`s3` 的下标恒为 `i+j-1`。
3. 转移只看两个来源：`dp[i][j] = (dp[i-1][j] and s1[i-1]==s3[i+j-1]) or (dp[i][j-1] and s2[j-1]==s3[i+j-1])`。
4. 用一维滚动数组把 `i` 压掉，内层 `j` 从 1 到 `len(s2)` 正序更新。

拿示例 1 走关键一格：`s1="aabcc"`、`s2="dbbca"`、`s3="aadbbcbcac"`。算 `dp[2][3]` 时 `i+j-1=4`，`s3[4]='b'`；`dp[1][3]` 为 True 但 `s1[1]='a'≠'b'`，左边不成立；`dp[2][2]` 为 True 且 `s2[2]='b'=='b'`，于是 `dp[2][3]=True`。这一格正是靠 `s2` 的 `b` 续上的，若只看 `s1` 会误判 False。

```python
n, m = len(s1), len(s2)
if n + m != len(s3):
    return False
dp = [False] * (m + 1)
dp[0] = True
for j in range(1, m + 1):
    dp[j] = dp[j-1] and s2[j-1] == s3[j-1]
for i in range(1, n + 1):
    dp[0] = dp[0] and s1[i-1] == s3[i-1]
    for j in range(1, m + 1):
        c = s3[i+j-1]
        dp[j] = (dp[j] and s1[i-1] == c) or (dp[j-1] and s2[j-1] == c)
return dp[m]
```

## 复杂度
时间 O(n·m)，n、m 分别是 `s1`、`s2` 长度，每格常数次比较。
空间 O(m)，只开长度 `m+1` 的 `dp` 数组，滚动掉 `s1` 那一维。

## 易错点
- `s1=""`、`s2="a"`、`s3="a"`：若漏写 `dp[0]` 的初始化循环（`dp[0] = dp[0] and s1[i-1]==s3[i-1]`），`i` 维全空，返回 False；正确做法是每轮外层先单独更新 `dp[0]`，它只可能由 `s1` 前缀决定。
- `s1="aabcc"`、`s2="dbbca"`、`s3="aadbbbaccc"`（示例 2）：若转移里写成 `or` 短路后不检查字符相等、或把 `s3` 下标写成 `i+j`，会错判 True；正确做法是下标严格用 `i+j-1`，且两个分支都必须带 `==c` 判断。

## 如果面试官追问
要求输出一种具体交织方案怎么办？答：DP 存布尔后从 `dp[n][m]` 反向回溯，每步优先试 `s1` 分支，记录选了哪个字符串的字符，逆序即得方案。
