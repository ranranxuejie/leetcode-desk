## 一句话思路
按千位切块，每块（0–999）用同一套 `three()` 递归翻译，再拼上 Thousand/Million/Billion。

## 怎么做
1. 从低位起每 3 位取一块，`num % 1000` 得到当前块，`num //= 1000` 推进，块序号决定单位。
2. 写 `three(n)` 处理 0–999：`n // 100` 出百位，余下两位查表。
3. 小于 20 直接查 `ones` 表；否则 `n // 10` 查 `tens`、`n % 10` 查 `ones`，中间用空格连。
4. 非零块的结果加单位后压入列表，最后 `" ".join(reversed(...))`。

以 1234567 为例：第一次取块 `1234567 % 1000 = 567` → `"Five Hundred Sixty Seven"`，`num` 变 1234；第二次取 `1234 % 1000 = 234` → `"Two Hundred Thirty Four" + " Thousand"`；第三次 `1` → `"One Million"`。倒序拼接即得示例 3。

```python
ones = ["", "One", "Two", ..., "Nineteen"]
tens = ["", "", "Twenty", "Thirty", ..., "Ninety"]
units = ["", "Thousand", "Million", "Billion"]

def three(n):
    if n < 20: return ones[n]
    if n < 100: return tens[n // 10] + (" " + ones[n % 10] if n % 10 else "")
    rest = three(n % 100)
    return ones[n // 100] + " Hundred" + (" " + rest if rest else "")

parts, i = [], 0
while num:
    if num % 1000: parts.append(three(num % 1000) + (" " + units[i] if i else ""))
    num //= 1000; i += 1
return " ".join(reversed(parts)) or "Zero"
```

## 复杂度
时间 O(log n)：n 的十进制位数，最多 10 位，每块常数工作。
空间 O(log n)：`parts` 最多 4 个字符串，递归深度常数。

## 易错点
- 输入 `0` → 循环一次不进，`parts` 为空，`join` 得 `""` → 必须显式返回 `"Zero"`，别指望 `three(0)` 兜底。
- 输入 `1000000` → 中间块 `num % 1000 == 0`，若不加 `if` 判断会拼出 `"One Million  Thousand"` 这种空块带单位 → 只有非零块才 `append`，单位跟着块走。

## 如果面试官追问
问：num 扩到 10^15 以上怎么办？
答：`units` 表补 Quadrillion 等，循环和 `three()` 完全不动，只加表项。
