## 一句话思路
把技能集合压成位掩码，用 `dp[mask]` 记录覆盖 `mask` 的最少人数团队，逐人做 0/1 背包式更新。

## 怎么做
1. 先给 `req_skills` 建 `skill_id`，把每个 `people[i]` 转成整数掩码 `pm[i]`。
2. `dp` 用字典或长度 `1<<m` 的数组，`dp[0]=[]`，其余为 `None`；对每个人只从旧状态扩展，避免同一人重复选。
3. 更新时 `new = mask | pm[i]`，若 `dp[new]` 为空或 `len(dp[mask])+1 < len(dp[new])` 就替换。
4. 返回 `dp[(1<<m)-1]`。

以示例 1 为例：`req_skills` 映射 `java=0,nodejs=1,reactjs=2`，三人掩码为 `1,2,6`。处理 `people[2]` 时，从 `mask=2`（团队 `[1]`）得到 `new=2|6=6`，团队变 `[1,2]`；但 `mask=1` 得 `new=7`，团队 `[0,2]` 更短，最终 `dp[7]=[0,2]`。

```python
m = len(req_skills)
idx = {s: i for i, s in enumerate(req_skills)}
pm = [sum(1 << idx[s] for s in p) for p in people]
dp = {0: []}
for i, p in enumerate(pm):
    for mask, team in list(dp.items()):
        new = mask | p
        if new not in dp or len(team) + 1 < len(dp[new]):
            dp[new] = team + [i]
return dp[(1 << m) - 1]
```

关键点：`list(dp.items())` 固定了本轮开始前的状态，保证一个人最多进队一次。

## 复杂度
时间：`O(n * 2^m)`，`n=len(people)`，`m=len(req_skills)`，每人扫全部掩码。
空间：`O(2^m)` 个掩码，每个存一个团队列表，最坏 `O(2^m * m)`。

## 易错点
1. 直接遍历 `dp.items()` 并在循环里写入 `dp` → Python 抛 `RuntimeError: dictionary changed size during iteration`，或同一人被反复加入。正确做法是先 `list(dp.items())` 快照旧状态再更新。
2. 用「人数更少才替换」但漏掉 `new not in dp` 的判断 → 首次到达某掩码时 `dp[new]` 不存在，比较会报 `KeyError` 或误判。正确写法是 `new not in dp or len(team)+1 < len(dp[new])`，先判存在再比长度。

## 如果面试官追问
问：`m` 增大到 20 以上怎么办？答：`2^m` 状态爆炸，需换搜索/剪枝或按技能覆盖贪心近似，精确解不再可行。
