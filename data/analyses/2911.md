## 一句话思路
预处理每个子串变成半回文串的最小代价 `cost[i][j]`，再用 DP 按分割点切 k 段取最小和。

## 怎么做
1. 对每个起点 `i`，枚举长度 `L` 得到子串 `s[i:i+L]`，枚举 `L` 的真因数 `d`（`d < L` 且 `L % d == 0`），对每组 `s[i+r], s[i+r+d], ...` 用双指针数不匹配对数，取所有 `d` 的最小值存入 `cost[i][i+L-1]`。
2. 以 `s = "abcac", k = 2` 为例：`cost[0][1]`（子串 `"ab"`）只有 `d=1`，`"ab"` 不是回文，改 1 个字符 → 1；`cost[2][4]`（`"cac"`）`d=1` 时本身是回文 → 0。
3. DP：`dp[t][j]` 表示前 `j` 个字符切成 `t` 段的最小代价，转移 `dp[t][j] = min(dp[t-1][i] + cost[i][j-1])`，`i` 从 `t-1` 到 `j-1`。
4. 答案 `dp[k][n]`。上例 `dp[1][2]=cost[0][1]=1`，`dp[2][5]=dp[1][2]+cost[2][4]=1+0=1`。

```python
n = len(s)
cost = [[0]*n for _ in range(n)]
for i in range(n):
    for L in range(2, n-i+1):
        best = L
        for d in range(1, L):
            if L % d: continue
            c = 0
            for r in range(d):
                a, b = i+r, i+L-1-((L-1-r) % d)
                while a < b:
                    if s[a] != s[b]: c += 1
                    a += d; b -= d
            best = min(best, c)
        cost[i][i+L-1] = best
INF = 10**9
dp = [[INF]*(n+1) for _ in range(k+1)]
dp[0][0] = 0
for t in range(1, k+1):
    for j in range(t, n+1):
        for i in range(t-1, j):
            dp[t][j] = min(dp[t][j], dp[t-1][i] + cost[i][j-1])
return dp[k][n]
```

## 复杂度
时间：`O(n^3 · 因数个数)`，预处理枚举 `i、L、d` 与组内双指针，DP 为 `O(k n^2)`。
空间：`O(n^2)` 存 `cost` 与 `dp`，`n ≤ 200` 可接受。

## 易错点
- 长度 1 的子串：题面说它没有合法因数，但切出的单字符段必须算代价 0（本身即半回文），若在预处理里跳过 `L=1` 又没初始化 `cost[i][i]=0`，`dp` 会取到 `INF` 而错成极大值。
- 组内配对下标：第 `r` 组是 `i+r, i+r+d, ...`，回文配对是首尾两端，写成 `s[a] != s[a+d]` 相邻比较会把 `"abcabc"`（`d=3`）误判为非半回文，正确是 `a` 与 `i+L-1-((L-1-r)%d)` 两端向中间夹。

## 如果面试官追问
若 `n` 放大到 2000 怎么办？答：`cost` 预处理是瓶颈，可只对每个 `(i,L)` 枚举 `L` 的因数并复用 `d` 的组内前缀不匹配计数，把 `O(n^3)` 降到 `O(n^2 log n)` 量级。
