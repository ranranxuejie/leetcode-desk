## 一句话思路
统计 s 和 t 的字符频次差，把 s 多出的字符数（等于 t 多出的字符数）相加即为答案。

## 怎么做
1. 用长度 26 的数组 `diff` 记录 s 与 t 每个字母的频次差（s 加、t 减）。
2. 遍历 `diff`，把正值累加得 `extra_s`，负值绝对值累加得 `extra_t`。
3. 答案就是 `extra_s + extra_t`，因为 s 多出的每个字符都要在 t 里补一个，反之亦然。

以 `s = "leetcode", t = "coats"` 为例：`diff` 中 `'e'` 为 +3、`'l'` 为 +1、`'d'` 为 +1（共 5 个 s 多出），`'a'` 为 -1、`'s'` 为 -1（共 2 个 t 多出），答案 5+2=7。

```python
diff = [0] * 26
for c in s:
    diff[ord(c) - 97] += 1
for c in t:
    diff[ord(c) - 97] -= 1
ans = 0
for d in diff:
    ans += abs(d)
return ans
```

注意 `abs(d)` 对每个字母恰好把「s 多」和「t 多」各算一次，总和就是 `extra_s + extra_t`，无需分开累加。

## 复杂度
时间 O(n + m + 26)，n、m 分别为 s、t 长度，26 是常数。
空间 O(26) 即 O(1)，只开了固定长度 `diff` 数组。

## 易错点
- 输入 `s = "a", t = "a"` 时若误把 `diff` 全零当成需要操作，会返回非 0；正确做法是 `abs(0)` 累加为 0，直接返回 0。
- 输入 `s = "ab", t = "a"` 时若只统计 s 多出的字符（`'b'` 一个），会错成 1；正确做法是 `abs(diff)` 把 t 缺的也算上，但这里 t 没多字符，答案仍是 1——真正会翻车的是 `s = "a", t = "ab"`，只算 s 多得 0，正确应得 1，必须用 `abs` 覆盖两个方向。

## 如果面试官追问
若要求输出具体追加方案而非步数？答：对每个 `diff[i] > 0` 的字母向 t 追加 `diff[i]` 个，`diff[i] < 0` 的向 s 追加 `-diff[i]` 个，顺序任意。
