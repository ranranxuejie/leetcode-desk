## 一句话思路
把「先戳谁」倒过来想成「最后戳谁」，用区间 DP 枚举区间内最后被戳的球 k，从而把左右两段彻底解耦。

## 怎么做
1. 两侧各补一个 1，得到 `a = [1] + nums + [1]`，长度 `m = n + 2`；这样边界球天然有邻居，不用特判。
2. 定义 `dp[i][j]` 为开区间 `(i, j)` 内全部戳破的最大收益，`i`、`j` 是保留不戳的哨兵。
3. 枚举 `(i, j)` 中最后被戳的 `k`：此时 `k` 的左右邻居正是 `i` 和 `j`，收益 `a[i]*a[k]*a[j]`，加上左右两段 `dp[i][k] + dp[k][j]`。
4. 按区间长度从小到大递推，答案 `dp[0][m-1]`。

以 `nums = [3,1,5,8]` 为例，`a = [1,3,1,5,8,1]`。算 `dp[0][5]` 时枚举最后戳的 `k`：取 `k=1`（值 3），得 `a[0]*a[1]*a[5] = 1*3*1 = 3` 加 `dp[0][1]=0` 加 `dp[1][5]`；而 `dp[1][5]` 里取 `k=4`（值 8）时贡献 `a[1]*a[4]*a[5] = 3*8*1 = 24`，层层叠加最终 `dp[0][5] = 167`。

```python
a = [1] + nums + [1]
m = len(a)
dp = [[0] * m for _ in range(m)]
for length in range(2, m):          # 开区间跨度
    for i in range(m - length):
        j = i + length
        for k in range(i + 1, j):
            dp[i][j] = max(dp[i][j],
                           dp[i][k] + dp[k][j] + a[i] * a[k] * a[j])
return dp[0][m - 1]
```

## 复杂度
时间：`O(n^3)`，三层循环分别枚举区间左端、右端、最后戳的 k。
空间：`O(n^2)`，`dp` 是 `(n+2)×(n+2)` 的表，无其他额外结构。

## 易错点
- 直接按「先戳谁」写记忆化：`nums = [3,1,5,8]` 先戳 1 后数组变成 `[3,5,8]`，子问题依赖已删元素，状态无法复用 → 必须倒过来定义「最后戳 k」，让 `a[i]`、`a[j]` 始终是哨兵。
- 忘记补两侧的 1：`nums = [1,5]` 若直接对原数组 DP，戳 1 时左邻居越界，收益会算成 `5*1` 而非 `1*1*5` → 先构造 `a = [1] + nums + [1]`，答案取 `dp[0][m-1]` 而不是 `dp[0][n-1]`。

## 如果面试官追问
问：n 放大到 5000 怎么办？
答：`O(n^3)` 撑不住，这题本质是矩阵链式结构，一般规模下没有更快的通用解法，只能说明瓶颈在第三层枚举 k。
