## 一句话思路
按分隔符判断走哪条分支：含 `.` 就按 IPv4 逐段校验，含 `:` 就按 IPv6 逐段校验，其余直接 Neither。

## 怎么做
1. 先看 `queryIP` 里有没有 `.`，有就调 `check4`，否则看有没有 `:`，调 `check6`，都没有返回 `"Neither"`。
2. IPv4 用 `queryIP.split('.')`，段数必须正好 4，否则直接 False。
3. 每段要满足：非空、全是数字、无前导零（`len(s) > 1 and s[0] == '0'` 即 False）、`int(s) <= 255`。
4. IPv6 用 `queryIP.split(':')`，段数必须正好 8，每段长度 1~4 且每个字符在 `0123456789abcdefABCDEF` 里。

拿示例 1 `"172.16.254.1"` 走一遍：`split('.')` 得到 `['172','16','254','1']`，长度 4 通过；`'172'` 首字符不是 `'0'`、`int('172')=172 <= 255`，四段全过，返回 `"IPv4"`。

```python
def check4(ip):
    parts = ip.split('.')
    if len(parts) != 4:
        return False
    for s in parts:
        if not s or not s.isdigit():
            return False
        if len(s) > 1 and s[0] == '0':
            return False
        if int(s) > 255:
            return False
    return True

def check6(ip):
    parts = ip.split(':')
    if len(parts) != 8:
        return False
    hexs = set('0123456789abcdefABCDEF')
    return all(1 <= len(s) <= 4 and all(c in hexs for c in s) for s in parts)
```

## 复杂度
时间：O(n)，n 是 `queryIP` 长度，split 和逐字符扫描各扫一遍。
空间：O(n)，split 出的段列表和 IPv6 的 16 字符集合。

## 易错点
- 输入 `"192.168.01.1"` → 若只判 `isdigit()` 和 `<=255`，`int('01')=1` 会误判为 IPv4 → 必须显式拦 `len(s)>1 and s[0]=='0'`。
- 输入 `"2001:0db8:85a3:0000:0000:8a2e:0370:7334:"` 或 `"1:2:3:4:5:6:7:8:9"` → 若用 `split(':')` 后不检查段数，尾随空串或 9 段会被放过 → 必须 `len(parts) != 8` 直接 False；注意 `"::"` 这类压缩写法本题不合法，split 出空串也会被长度检查挡掉。

## 如果面试官追问
问：如果允许 IPv6 的 `::` 压缩写法怎么改？
答：split 后统计空段个数，只允许出现一次连续空段，并按缺失段数补零再校验。
