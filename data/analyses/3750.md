## 一句话思路
逐位比较 s 与其反转，统计 s[i] != s[L-1-i] 的位置对数，每对贡献一次翻转。

## 怎么做
1. 用 `bin(n)[2:]` 取二进制串 s，长度 L 记为 `L = len(s)`。
2. 双指针 i 从 0 到 `L//2 - 1`，j 从 `L-1` 递减，只比较前半段与后半段的对称位。
3. 若 `s[i] != s[j]`，说明这一对必须翻转其中一位才能相等，`ans += 1`。
4. 返回 ans。

以 n = 10 为例，s = "1010"，L = 4。i=0 时 s[0]='1'、s[3]='0'，不等，ans=1；i=1 时 s[1]='0'、s[2]='1'，不等，ans=2。循环只跑 `L//2 = 2` 次，最终返回 2？——注意这里要核对：示例输出是 4，因为题目要求 s 与反转完全相等，而反转 "0101" 与 "1010" 每一位都不同，需翻转 4 位。所以正确判定是逐位比较 s[i] 与 s[L-1-i]，**每一位**不等的都要计入，而不是只计前半段的对数。

修正后的做法：
1. `s = bin(n)[2:]`，`L = len(s)`。
2. i 从 0 到 L-1，比较 `s[i]` 与 `s[L-1-i]`。
3. 不等则 `ans += 1`。
4. 返回 ans。

n = 10 时：i=0 比 '1' vs '0' 不等；i=1 比 '0' vs '1' 不等；i=2 比 '1' vs '0' 不等；i=3 比 '0' vs '1' 不等，ans=4，与示例一致。n = 7 时 s="111"，四位全等，ans=0。

```python
s = bin(n)[2:]
L = len(s)
ans = 0
for i in range(L):
    if s[i] != s[L - 1 - i]:
        ans += 1
return ans
```

等价写法：`sum(s[i] != s[L-1-i] for i in range(L))`。

## 复杂度
时间：O(log n)，遍历二进制串长度 L = ⌊log2 n⌋ + 1。
空间：O(log n)，`bin(n)` 生成的字符串占 L 个字符。

## 易错点
- 只遍历前半段 `range(L//2)` → n = 10 会得 2 而非 4 → 必须遍历全部 L 位，因为反转后每一位都可能与原来不同。
- 用 `bin(n)` 忘了 `[2:]` → 前缀 "0b" 参与比较，n = 7 时 "0b111" 反转 "111b0"，会算出非零答案 → 先切掉前缀再比较。

## 如果面试官追问
若 n 大到 10^18 且要求 O(1) 空间？答：仍可逐位取 `(n >> i) & 1` 与 `(n >> (L-1-i)) & 1` 比较，不建字符串。
