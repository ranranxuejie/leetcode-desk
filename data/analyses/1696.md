## 一句话思路
用单调队列维护窗口 `[i-k, i-1]` 内 `dp` 的最大值，`dp[i] = nums[i] + 队首值`，O(n) 解决。

## 怎么做
1. 定义 `dp[i]` 为跳到下标 `i` 时的最大得分，`dp[0] = nums[0]`。
2. 用双端队列存下标，队列内 `dp` 值严格递减，队首即窗口最大值。
3. 遍历 `i` 从 1 到 n-1：先弹出队首中 `< i-k` 的过期下标，再取 `dp[i] = nums[i] + dp[deque[0]]`，最后从队尾弹出 `dp` 值 `<= dp[i]` 的下标并入队。

以示例 1 `nums = [1,-1,-2,4,-7,3], k = 2` 为例：`dp[0]=1`，队列 `[0]`。`i=1` 时窗口只有 0，`dp[1]=-1+1=0`，队尾 `dp[0]=1 > 0` 保留，队列 `[0,1]`。`i=2` 时 `dp[2]=-2+1=-1`，队尾 `dp[1]=0 > -1`，队列 `[0,1,2]`。`i=3` 时先弹过期下标 0（`3-2=1`），队首变 1，`dp[3]=4+dp[1]=4`，再从队尾弹掉 `dp` 值 ≤4 的 2、1，队列 `[3]`。最终 `dp[5]=3+dp[3]=7`。

```python
dp = [0] * n
dp[0] = nums[0]
dq = collections.deque([0])
for i in range(1, n):
    while dq and dq[0] < i - k:
        dq.popleft()
    dp[i] = nums[i] + dp[dq[0]]
    while dq and dp[dq[-1]] <= dp[i]:
        dq.pop()
    dq.append(i)
return dp[-1]
```

## 复杂度
时间 O(n)：每个下标最多入队出队各一次。
空间 O(n)：`dp` 数组 O(n)，队列最坏 O(k)。

## 易错点
- `nums = [1,-5,-20,4,-1,3,-6,-3], k = 2` 若忘记弹过期下标，`i=3` 时队首仍是 0，`dp[3]` 会算成 `4+dp[0]=5`，实际窗口只含下标 1、2，正确 `dp[3]=4+dp[1]=-1`。必须先 `while dq[0] < i-k` 再取队首。
- 弹队尾时用 `<=` 而非 `<`：`nums=[10,-5,-2,4,0,3], k=3` 中 `dp` 值相等时保留旧下标会提前过期，导致 `i=5` 时队首被误弹，`dp[5]` 取不到 `dp[2]` 而偏小。相等时弹掉旧下标更安全。
