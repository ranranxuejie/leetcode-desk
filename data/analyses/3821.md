## 一句话思路
按二进制位从高到低逐位定 0/1，用组合数 `C(剩余位, 剩余k)` 数出「这一位放 0 时有多少个合法数」，与 n 比较后决定该位。

## 怎么做
1. 从最高位 `b = 49` 往下扫到 0，维护还需放置的 1 的个数 `k` 和当前排名 `n`（1-indexed）。
2. 若这一位放 0，则剩下 `b` 个低位要放满 `k` 个 1，方案数 `cnt = C(b, k)`；`cnt >= n` 说明答案这一位是 0，直接跳过。
3. 否则这一位是 1，`n -= cnt`，`k -= 1`，把 `1 << b` 累加进答案。
4. 提前 `k == 0` 时后面全 0，可 break。

以 `n = 4, k = 2` 为例：`b = 3` 时 `C(3,2) = 3 < 4`，故第 3 位取 1，`n = 1, k = 1`；`b = 2` 时 `C(2,1) = 2 >= 1`，第 2 位取 0；`b = 1` 时 `C(1,1) = 1 >= 1`，第 1 位取 0；`b = 0` 时 `C(0,1) = 0 < 1`，第 0 位取 1。答案 `1001₂ = 9`。

```python
from math import comb
def nthSmallest(n, k):
    ans = 0
    for b in range(49, -1, -1):
        if k == 0:
            break
        cnt = comb(b, k) if b >= k else 0
        if cnt < n:
            n -= cnt
            ans |= 1 << b
            k -= 1
    return ans
```

注意 `comb(b, k)` 在 `b < k` 时返回 0（Python 3.8+ 行为），但显式写 `if b >= k else 0` 更稳。

## 复杂度
时间：O(50)，每位一次 `comb`，与 n 大小无关。
空间：O(1)，只存 `ans/n/k/b`，`comb` 内部 O(k) 可忽略。

## 易错点
- `n = 1, k = 50`：若循环上界写成 `range(49,-1,-1)` 但没处理 `b < k`，`comb(3,50)` 会抛 `ValueError` 而非返回 0（旧版本 Python），正确做法是显式判 `b >= k` 再算。
- `n = 2**50, k = 1`：答案接近 `2**50`，若把上界写成 48 会漏掉最高位，返回偏小的数；必须从 `b = 49` 起扫，因为题目保证答案 `< 2**50` 即最多 50 位。

## 如果面试官追问
问：若 n 上限提到 `2**63`、k 到 63 怎么办？
答：把循环上界改成 62，`comb` 结果用 Python 大整数即可，逻辑不变。
