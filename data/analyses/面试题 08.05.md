## 一句话思路
用递归把 `B` 每次折半，`B` 为偶数时 `multiply(A, B//2)` 结果翻倍，奇数时再加一个 `A`，靠加法与位移替代 `*`。

## 怎么做
1. 递归出口：`B == 1` 时直接返回 `A`，这是唯一不需要再拆的底。
2. 先算 `half = multiply(A, B // 2)`，把规模从 `B` 降到 `B//2`。
3. 偶数 `B` 返回 `half + half`，奇数 `B` 返回 `half + half + A`。
4. 用 `B & 1` 判奇偶、`B >> 1` 代替 `B // 2`，符合「吝啬」要求。

以示例 2 `A = 3, B = 4` 为例：`B=4` 偶数，先求 `multiply(3, 2)`；`B=2` 偶数，再求 `multiply(3, 1)` 得 `3`；回代 `half=3` 得 `6`，再回代 `half=6` 得 `12`。关键中间值是 `B=2` 那层的 `half=3`，翻倍后才是 `6`。

```python
def multiply(A, B):
    if B == 1:
        return A
    half = multiply(A, B >> 1)
    if B & 1:
        return half + half + A
    return half + half
```

注意 `B >> 1` 对正整数等价于 `B // 2`，题面保证正整数，不必处理 `B == 0`；若面试官放宽到非负，出口要改成 `B == 0` 返回 `0`。

## 复杂度
时间：`O(log B)`，递归深度由 `B` 每次右移一位决定。
空间：`O(log B)`，递归栈帧，无额外数组。

## 易错点
- 输入 `A = 3, B = 4` 时若出口写成 `B == 0` 返回 `0` 却没处理 `B == 1`，`half` 会多递归一层、结果仍是 `12` 但多一次调用；正确做法是明确 `B == 1` 返回 `A`，让 `B >> 1` 恰好收敛到 1。
- 输入 `A = 1, B = 10` 时若把奇数分支写成 `half + half`（漏加 `A`），`B=5` 那层会少算 `1`，最终得 `8` 而非 `10`；正确做法是奇数分支严格 `half + half + A`，用 `B & 1` 判断。

## 如果面试官追问
问：若 `B` 可达 `10**18` 且要求迭代版？
答：把 `A` 左移 `i` 位、按 `B` 的第 `i` 位累加，循环 `B` 的二进制位数即可，空间降到 `O(1)`。
