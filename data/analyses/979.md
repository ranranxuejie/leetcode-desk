## 一句话思路
后序 DFS 返回子树「多余硬币数」，每条父子边必须搬运的枚数就是该子树余额的绝对值，累加即答案。

## 怎么做
1. 定义 `dfs(node)` 返回以 `node` 为根的子树在满足内部每点 1 枚后，多出（正）或欠缺（负）的硬币数。
2. 空结点返回 0；叶子 `val=0` 返回 -1，`val=3` 返回 2。
3. 合并：`need = node.val - 1 + dfs(left) + dfs(right)`，这个 `need` 必须整份跨过 `node` 与父结点之间那条边。
4. 该边贡献 `abs(need)` 次移动，用 `nonlocal ans` 累加，最后返回 `need`。

以 `root = [0,3,0]` 为例：左叶 `val=3` 返回 `3-1=2`，右叶 `val=0` 返回 `-1`；根 `need = 0-1+2+(-1) = 0`，累加 `abs(2)+abs(-1)=3`，与输出 3 一致。

```python
def dfs(node):
    nonlocal ans
    if not node:
        return 0
    need = node.val - 1 + dfs(node.left) + dfs(node.right)
    ans += abs(need)
    return need

ans = 0
dfs(root)
return ans
```

关键点：`need` 的符号决定搬运方向，但次数只取绝对值；`node.val - 1` 里的 `-1` 是留给结点自己的那一枚，漏掉它示例 1 会算成 3。

## 复杂度
时间 O(n)：每个结点进 `dfs` 一次，合并是常数操作。
空间 O(h)：递归栈深度为树高 h，最坏链状 O(n)，未开额外数组。

## 易错点
- 把 `node.val - 1` 写成 `node.val` → 示例 1 的根返回 3 而非 2，答案变 3；正确是每个结点先扣掉自己那枚再上传余额。
- 只累加正余额、忽略负数 → 示例 2 的右叶 `-1` 不计，答案变 2；正确是 `abs(need)`，缺硬币的子树同样要搬进来。

## 如果面试官追问
问：要输出具体移动方案怎么办？
答：在 `dfs` 里记录每条边搬运的枚数与方向，按后序把「子→父」或「父→子」的搬运逐条列出即可，次数不变。
