## 一句话思路
左移子数组只改变 l 和 r 两个位置的奇偶贡献，枚举 r 并用前缀和/DP 维护最优 l 即可。

## 怎么做
1. 记原脉冲值 `base = sum(nums[i] * (1 if i%2==0 else -1))`。
2. 左移 `nums[l..r]` 后，只有 `nums[l]` 移到 `r`、`nums[l+1..r]` 整体前移一位，等价于：`nums[l]` 的符号从 `s(l)` 变成 `s(r)`，`nums[l+1..r]` 每个元素符号翻转。
3. 增量 `delta = nums[l]*(s(r)-s(l)) + sum_{i=l+1..r} nums[i]*(-2*s(i))`，其中 `s(i)=1 if i%2==0 else -1`。
4. 对每个 `r`，维护 `best = max over l<r of (nums[l]*(s(r)-s(l)) - 2*sum_{i=l+1..r} nums[i]*s(i))`，用前缀和 O(1) 转移。

以 `nums=[1,5,2]` 为例：`base=-2`。取 `l=0,r=1`，`s(0)=1,s(1)=-1`，`delta=1*(-1-1)+5*(-2*(-1))=-2+10=8`，得 `-2+8=6`，与答案一致。

```python
n = len(nums)
s = [1 if i % 2 == 0 else -1 for i in range(n)]
pre = [0] * (n + 1)          # pre[i] = sum_{j<i} nums[j]*s[j]
for i in range(n):
    pre[i+1] = pre[i] + nums[i] * s[i]
base = pre[n]
ans = base
best = -10**30               # max over l<r of nums[l]*(s(r)-s(l)) - 2*(pre[r]-pre[l+1])
for r in range(1, n):
    l = r - 1
    cand = nums[l] * (s[r] - s[l]) - 2 * (pre[r] - pre[l+1])
    best = max(best, cand)
    ans = max(ans, base + best)
```

## 复杂度
时间 O(n)：一次前缀和 + 一次枚举 r，均为线性扫描。
空间 O(n)：`s` 和 `pre` 两个长度 n+1 的数组。

## 易错点
- `n=1` 时没有合法 `l<r`，循环不进入，`ans` 必须初始化为 `base` 而非 `-inf`，否则返回错误值。
- `nums[i]` 可达 `-10^9`、n 达 `10^5`，`base` 量级约 `10^14`，必须用 Python 原生 int（题目若规定按 32 位截断需自行处理），不要假设结果落在 `2**31-1` 内。

## 如果面试官追问
问：若允许循环左移任意 k 位？答：增量变为区间内每个元素符号按 k 的奇偶整体翻转，仍可前缀和 O(n) 枚举 l,r。
