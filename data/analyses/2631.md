## 一句话思路
一次遍历，用字典把 `fn(item)` 的返回值当键、把 `item` 追加进对应列表，顺序自然保持。

## 怎么做
1. 建空字典 `groups = {}`。
2. 遍历 `array`，对每个 `item` 算 `key = fn(item)`。
3. 若 `key` 不在 `groups`，先置 `groups[key] = []`，再 `append(item)`。
4. 返回 `groups`。

拿示例 1 走一遍：`item = {"id":"1"}` 时 `key = "1"`，`groups` 从 `{}` 变成 `{"1": [{"id":"1"}]}`；第二个同 id 对象追加后是 `{"1": [{"id":"1"},{"id":"1"}]}`；第三个 `key = "2"` 新建列表。最终两个键的顺序就是首次出现的顺序。

```python
def group_by(array, fn):
    groups = {}
    for item in array:
        key = fn(item)
        if key not in groups:
            groups[key] = []
        groups[key].append(item)
    return groups
```

关键只有两行：`if key not in groups` 负责建桶，`append` 负责保序。用 `dict.setdefault(key, []).append(item)` 可以压成一行，但 `setdefault` 每次都会构造一个空列表实参，10^5 规模下多分配对象，显式判断更稳。

注意 `fn` 返回的一定是字符串（题面保证），所以 `"1"` 和 `1` 不会混键；示例 3 里 `String(n > 5)` 得到 `"true"`/`"false"` 两个字符串键，正好对应输出里的两个字段。

## 复杂度
时间 O(n)：n 为 `array` 长度，每个元素算一次 `fn`、做一次哈希查找和一次 append。
空间 O(n)：额外开了字典和 n 个元素引用，键的个数最多 n。

## 易错点
- 输入 `array = []` → 若先写 `groups[fn(array[0])]` 会直接 IndexError → 正确做法是循环体从空字典开始，空数组自然返回 `{}`。
- 输入示例 3 的 `[1..10]` → 若把 `fn` 返回值当布尔或数字直接做键，`True` 和 `"true"` 在 Python 里不相等，输出键名就对不上 → 必须原样用 `fn(item)` 的字符串结果当键，不做任何转换。

## 如果面试官追问
追问：若要求分组后每组内按某字段排序怎么办？
答：分组完对每个 `groups[key]` 单独 `sort(key=...)`，总代价 O(n + Σ k_i log k_i)，不改变分组本身。
