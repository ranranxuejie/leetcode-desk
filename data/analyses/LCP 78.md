## 一句话思路
二分答案 `d`，每段城墙在「左边界尽量靠左」的贪心下检查能否全部膨胀 `d` 且不重叠。

## 怎么做
1. 答案单调：能膨胀 `d` 则一定能膨胀 `d-1`，故二分 `[0, 10**8]`。
2. 检查函数从左往右扫，维护上一段膨胀后的右端点 `prev_r`；第 `i` 段左端最左只能到 `max(rampart[i][0]-d, prev_r)`。
3. 若 `max(...) + (rampart[i][1]-rampart[i][0]) + d < prev_r` 说明放不下，返回 `False`；否则更新 `prev_r = max(...) + 长度 + d`。
4. 第一段左端无约束，`prev_r` 初始为 `-inf`（用 `-10**18`）。

以示例 1 `[[0,3],[4,5],[7,9]]`、`d=3` 为例：第 0 段左端 `max(0-3, -inf)=-3`，右端 `-3+3+3=3`；第 1 段左端 `max(4-3,3)=3`，右端 `3+1+3=7`；第 2 段左端 `max(7-3,7)=7`，右端 `7+2+3=12`，全部通过，故 `d=3` 可行。

```python
def check(d):
    prev_r = -10**18
    for x, y in rampart:
        left = max(x - d, prev_r)
        if left + (y - x) + d < prev_r:  # 放不下
            return False
        prev_r = left + (y - x) + d
    return True
```

二分时 `lo, hi = 0, 10**8`，`while lo < hi` 取 `mid = (lo + hi + 1) // 2`，`check(mid)` 真则 `lo = mid` 否则 `hi = mid - 1`，返回 `lo`。

## 复杂度
时间：`O(n log C)`，`n` 是城墙段数，`log C` 来自二分上界 `10**8`。
空间：`O(1)`，只用了 `prev_r`、`left` 几个标量。

## 易错点
- 第 0 段若把 `prev_r` 初始化为 `0`，输入 `[[0,3],...]` 时第 0 段左端被错误限制为 `max(-d,0)=0`，少算了向左膨胀的空间，答案偏小；正确做法是初始化为 `-10**18` 表示无约束。
- 判断放不下时若写成 `left + (y-x) + d > prev_r` 或漏掉长度项，`[[4,5]]` 这类短段会误判；正确条件是 `left + (y-x) + d < prev_r`，即新右端退到上一段右端左侧才算冲突。

## 如果面试官追问
问：要求输出每段具体膨胀量怎么办？
答：`check` 里记录每段 `left` 与 `prev_r`，二分定下 `d` 后再跑一遍 `check(d)` 输出 `[left - x, prev_r - y]` 即可。
