## 一句话思路
把「做空」等价成对取负后的价格做普通交易，用 `hold`/`free` 两个状态按天滚动 DP，交易次数作为外层维度。

## 怎么做
1. 关键观察：做空利润 `prices[i]-prices[j]` 等于在 `-prices` 上做普通交易的利润，所以每天有两种「持仓方向」，状态里要区分。
2. 定义 `buy[t]` = 已完成 t 笔交易且当前持有多头（买入未卖）的最大收益，`sell[t]` = 当前持有空头（卖出未买回）的最大收益，`free[t]` = 已完成 t 笔且空仓。
3. 按天推进，每天用前一天的值更新，注意同一天不能既买又卖，所以更新顺序要用旧值。
4. 答案取 `max(free[0..k])`。

以示例 1 `prices=[1,7,9,8,2], k=2` 为例，第 2 天价格 9 时，`free[1]` 从第 0 天买入价 1 得到 `9-1=8`；第 4 天价格 2 时，`free[2]` 由第 3 天做空价 8 得到 `8-2=6`，累计 `8+6=14`。

```python
# 滚动数组，prev_* 为前一天状态
NEG = -10**18
free = [0] + [NEG]*k
buy  = [NEG]*(k+1)
sell = [NEG]*(k+1)
for p in prices:
    nf, nb, ns = free[:], buy[:], sell[:]
    for t in range(k+1):
        nb[t] = max(buy[t], free[t] - p)      # 开多头
        ns[t] = max(sell[t], free[t] + p)     # 开空头
        if t > 0:
            nf[t] = max(free[t], buy[t-1] + p, sell[t-1] - p)
    free, buy, sell = nf, nb, ns
return max(free)
```

## 复杂度
时间：O(n·k)，n 为天数，k 为交易上限，每天扫一遍 k 个状态。
空间：O(k)，只开 `free`/`buy`/`sell` 三个长度 k+1 的数组。

## 易错点
- 输入 `prices=[1,7,9,8,2], k=2` 若在同一天内先更新 `free` 再更新 `buy`，会用当天新值开仓，导致同一天买卖，利润虚高；正确做法是先把 `buy`/`sell` 基于旧 `free` 算完，再更新 `free`。
- `k` 给到 `prices.length/2` 时，若把 `free` 初值只设 `free[0]=0` 其余为 `NEG`，忘记 `max(free)` 取所有 t，会漏掉用不满 k 笔的更优解；正确做法是答案取 `free[0..k]` 最大值。

## 如果面试官追问
问：若要求输出具体交易方案怎么办？
答：在 DP 转移时记录每步选择的来源（开多头/开空头/平仓），回溯即可还原每笔的买卖日。
