## 一句话思路
对每个格子枚举 3×3 邻域，用边界裁剪代替补零，累加后除以实际格子数。

## 怎么做
1. 双层循环遍历每个 `(i, j)`，内层用 `di, dj ∈ {-1,0,1}` 枚举 9 个候选位置。
2. 候选坐标 `ni = i + di`、`nj = j + dj` 越界就跳过，不参与累加也不计入分母。
3. 用 `total // cnt` 向下取整写入结果矩阵同位置。

以示例 2 的 `(0,0)` 为例：候选 9 个位置里只有 `(0,0)=100`、`(0,1)=200`、`(1,0)=200`、`(1,1)=50` 合法，`total=550`、`cnt=4`，`550 // 4 = 137`，与输出 `137` 一致。若误把越界当 0 补进去，分母会变成 9，得到 `61`，整张图全错。

```python
m, n = len(img), len(img[0])
res = [[0] * n for _ in range(m)]
for i in range(m):
    for j in range(n):
        total = cnt = 0
        for di in (-1, 0, 1):
            for dj in (-1, 0, 1):
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n:
                    total += img[ni][nj]
                    cnt += 1
        res[i][j] = total // cnt
```

关键点是 `cnt` 必须和 `total` 同步累加，不能预先写死 9 或 4——角上是 4、边上是 6、内部是 9，只有跟着 `if` 走才不会错。

## 复杂度
时间 O(m·n·9) = O(m·n)，每个格子固定看 9 个邻居。
空间 O(m·n) 存结果矩阵，除输出外只用了 `total`、`cnt` 两个标量。

## 易错点
- 输入 `[[1]]`（1×1）→ 若把分母写死成 9，得到 `1 // 9 = 0`，实际只有自身一格，应为 `1 // 1 = 1` → 分母必须用实时累加的 `cnt`。
- 输入示例 2 的角点 `(0,0)` → 若用「越界补 0 再除以 9」，得 `550 // 9 = 61`，正确是 `550 // 4 = 137` → 越界位置要整个跳过，既不进 `total` 也不进 `cnt`。

## 如果面试官追问
若 m、n 放大到 10^4 且要求多次查询不同半径的平滑值，怎么办？
答：先对每行做一维前缀和，再对列方向累加，把每个格子的邻域求和降到 O(1)，整体 O(m·n)。
