## 一句话思路
把每个连通水域块当整体，用 DFS 累加块内鱼数，取所有块和的最大值。

## 怎么做
1. 双重循环遍历每个格子，`grid[r][c] > 0` 时从它启动一次 DFS。
2. DFS 进入即把 `grid[r][c]` 清零（原地标记已访问），返回该格鱼数加四邻递归结果。
3. 每次 DFS 的返回值就是当前连通块的鱼总数，用它更新 `best`。
4. 遍历结束返回 `best`，无水域时 `best` 保持 0。

以示例 1 为例：从 `(1,3)` 出发，`grid[1][3]=3` 清零后向下到 `(2,3)`，`grid[2][3]=4` 清零，其四邻中 `(1,3)` 已为 0、`(3,3)=0`、`(2,2)=0`，递归返回 4，故本次 DFS 返回 `3+4=7`，`best` 更新为 7；而 `(0,1)` 那块只有 `2+1=3`，`(1,0)` 那块只有 4，都小于 7。

```python
def dfs(r, c):
    if not (0 <= r < m and 0 <= c < n) or grid[r][c] == 0:
        return 0
    fish = grid[r][c]
    grid[r][c] = 0
    for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
        fish += dfs(r + dr, c + dc)
    return fish

best = 0
for r in range(m):
    for c in range(n):
        if grid[r][c] > 0:
            best = max(best, dfs(r, c))
```

## 复杂度
时间：O(m·n)，每个格子最多被 DFS 访问一次，四邻检查是常数。
空间：O(m·n)，最坏情况递归栈深度等于整个网格（全为水域时），无额外数组。

## 易错点
- 全 0 网格如 `[[0,0],[0,0]]` → 若把 `best` 初始化为 `-1` 或直接返回 `dfs(0,0)`，会输出 -1 或 0 但逻辑错位 → `best` 必须初始化为 0，因为题目要求无水域返回 0。
- 忘记原地清零 → 如示例 1 中 `(1,3)` 与 `(2,3)` 互相递归，不清零会无限递归或重复累加 3 和 4 → 进入 DFS 第一件事就是 `grid[r][c] = 0`，用 0 兼作「陆地」和「已访问」标记。

## 如果面试官追问
若 m、n 放大到 10^3 且不允许改原数组，怎么办？
答：改用显式栈做迭代 DFS，另开 `visited` 布尔矩阵，空间 O(m·n) 但避免递归深度超限。
