## 一句话思路
用二维 DP：`dp[i][j]` 表示走到 `(i,j)` 的最小和，它只可能从上方或左方来，取较小者加 `grid[i][j]`。

## 怎么做
1. 初始化 `dp[0][0] = grid[0][0]`，第一行只能从左来、第一列只能从上来，直接累加。
2. 其余格子按行优先遍历，`dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`。
3. 用示例 1 走关键一步：`dp[1][1]` 处，上方 `dp[0][1]=4`、左方 `dp[1][0]=2`，取 2，加 `grid[1][1]=5` 得 `dp[1][1]=7`；继续推到 `dp[2][2]` 得 7。
4. 返回 `dp[m-1][n-1]`。

```python
m, n = len(grid), len(grid[0])
dp = [[0] * n for _ in range(m)]
dp[0][0] = grid[0][0]
for j in range(1, n):
    dp[0][j] = dp[0][j-1] + grid[0][j]
for i in range(1, m):
    dp[i][0] = dp[i-1][0] + grid[i][0]
for i in range(1, m):
    for j in range(1, n):
        dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])
return dp[m-1][n-1]
```

## 复杂度
时间：O(m·n)，每个格子算一次，m、n 分别是行数、列数。
空间：O(m·n) 的 `dp` 表；可压成一维 O(n)，因为 `dp[i][j]` 只依赖上一行同列和本行左邻。

## 易错点
- 输入 `grid = [[5]]`（单格）→ 若先跑双重循环从 `i=1` 开始会漏掉 `dp[0][0]` 的赋值，返回 0 → 正确做法是先单独写 `dp[0][0] = grid[0][0]`，再处理首行首列。
- 输入 `grid = [[1,2,3]]`（单行）或 `[[1],[2],[3]]`（单列）→ 若只写通用递推 `min(dp[i-1][j], dp[i][j-1])`，越界或把不存在的方向当 0 取最小，结果偏小 → 正确做法是首行、首列单独累加，不参与 `min`。

## 如果面试官追问
问：空间能否压到 O(n)？
答：能，一维数组 `dp[j]` 原地更新，`dp[j] = grid[i][j] + min(dp[j], dp[j-1])`，`dp[j]` 是上方、`dp[j-1]` 是左方。
