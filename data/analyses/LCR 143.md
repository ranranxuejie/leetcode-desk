## 一句话思路
对 A 的每个节点做一次「同根匹配」DFS，用双递归把「找起点」和「比结构」分开。

## 怎么做
1. 外层 `dfs(A)`：A 为空返回 `False`，否则依次试 `match(A, B)`、`dfs(A.left)`、`dfs(A.right)`。
2. 内层 `match(a, b)`：`b` 为空返回 `True`（B 已匹配完，A 多出的部分不算错）；`a` 为空或 `a.val != b.val` 返回 `False`。
3. 两者都非空且值相等时，递归 `match(a.left, b.left) and match(a.right, b.right)`。
4. 入口先判 `B is None` 直接返回 `False`，因为空树不算子树。

以示例 2 为例：`A = [3,6,7,1,8]`，`B = [6,1]`。外层走到 `A.left`（值 6）时，`match(6, 6)` 值相等 → 递归左子：`match(1, 1)` 值相等 → 递归左子 `match(None, None)` 返回 `True`，右子同理 → 整体 `True`，外层立刻短路返回，不再试 `A.right`。

```python
def match(a, b):
    if b is None:
        return True
    if a is None or a.val != b.val:
        return False
    return match(a.left, b.left) and match(a.right, b.right)

def dfs(a):
    if a is None:
        return False
    return match(a, b) or dfs(a.left) or dfs(a.right)
```

关键点：`match` 里 `b is None` 的判断必须放在 `a is None` 之前，顺序反了示例 2 的叶子层就会返回 `False`。

## 复杂度
时间 O(n·m)：n 为 A 节点数，m 为 B 节点数，最坏每个 A 节点都触发一次深度 m 的匹配。
空间 O(h_A + h_B)：递归栈深度由两棵树高度决定，无额外数组。

## 易错点
- 输入 `A = [1,7,5]`、`B = [6,1]`：若把 `match` 写成「值不等就继续往下找」，会在 7 处误配出结构，错成 `True`；正确做法是值不等立刻返回 `False`，交给外层 `dfs` 换起点。
- 输入 `B = []`（空树）：若漏判 `B is None`，`match` 首行 `b is None` 直接返回 `True`，任何 A 都判成 `True`；正确做法是入口先返回 `False`。

## 如果面试官追问
问：A 有 10^5 节点、B 也有 10^5 节点，双递归会退化吗？
答：会，最坏 O(n·m)；可先对两棵树做序列化哈希，用 KMP 在 A 的序列里找 B 的序列，降到 O(n+m)。
