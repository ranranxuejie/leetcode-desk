## 一句话思路
按序匹配两串的非下划线字符，字符必须相同，且 `R` 在 start 中不能更靠右、`L` 不能更靠左。

## 怎么做
1. 先比较两串去掉 `_` 后的结果，不同直接返回 `False`（片段种类和顺序不可变）。
2. 双指针 `i`、`j` 分别扫 `start`、`target`，跳过 `_`，每次停在下一个片段字符上。
3. 若 `start[i] == 'R'`，要求 `i <= j`（R 只能右移，start 位置不能超过 target）；若为 `'L'`，要求 `i >= j`（L 只能左移）。
4. 全部匹配完返回 `True`。

以示例 1 为例：`start = "_L__R__R_"`，`target = "L______RR"`。第一对片段是 `start[1]='L'` 与 `target[0]='L'`，`i=1 >= j=0` 成立；最后一对是 `start[7]='R'` 与 `target[8]='R'`，`i=7 <= j=8` 成立，故返回 `True`。

```python
i = j = 0
n = len(start)
while i < n or j < n:
    while i < n and start[i] == '_': i += 1
    while j < n and target[j] == '_': j += 1
    if i == n or j == n:
        return i == n and j == n
    if start[i] != target[j]:
        return False
    if start[i] == 'R' and i > j:
        return False
    if start[i] == 'L' and i < j:
        return False
    i += 1; j += 1
return True
```

## 复杂度
时间：O(n)，`i`、`j` 各单向扫一遍，每字符最多访问两次。
空间：O(1)，只开了 `i`、`j`、`n` 三个整型变量。

## 易错点
- `start = "R_L_"`、`target = "__LR"` → 只比较去下划线后的 `"RL"` 会误判为 `True` → 必须加位置约束：`start` 的 `R` 在下标 0，`target` 的 `R` 在下标 2，`0 <= 2` 通过，但 `L` 在 `start` 下标 2、`target` 下标 3，`2 < 3` 违反 `L` 只能左移，返回 `False`。
- `start = "_R"`、`target = "R_"` → 若只查字符集合相同就返回 `True` → 正确做法是 `R` 在 `start` 下标 1、`target` 下标 0，`1 > 0` 违反 `R` 只能右移，返回 `False`。

## 如果面试官追问
问：若允许 `L`、`R` 互相穿越（即不区分方向约束）？答：退化为只比较去下划线后的字符串是否相等，O(n) 一次扫描即可。
