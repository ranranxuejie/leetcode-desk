## 一句话思路
用 `dp[i]` 表示覆盖前 i 个水果的最少金币，转移时从能免费覆盖到 i 的购买点里取最小值，用单调队列维护窗口最小值。

## 怎么做
1. 定义 `dp[i]` 为「前 i 个水果全部到手」的最小花费，`dp[0] = 0`，答案是 `dp[n]`。
2. 若在位置 j 购买（1-indexed），花费 `prices[j-1]`，可免费覆盖到 `2j`，所以 `dp[i] = min(dp[j-1] + prices[j-1])`，其中 j 满足 `j <= i <= 2j`，即 `ceil(i/2) <= j <= i`。
3. 把候选值 `dp[j-1] + prices[j-1]` 按 j 递增放进单调队列，窗口左端随 i 增大而右移，队首即当前最小。
4. 以 `prices = [3,1,2]` 为例：i=1 时窗口 j∈[1,1]，候选 `dp[0]+3=3`，`dp[1]=3`；i=2 时窗口 j∈[1,2]，候选 3 和 `dp[1]+1=4`，`dp[2]=3`；i=3 时窗口 j∈[2,3]，候选 4 和 `dp[2]+2=5`，`dp[3]=4`。

```python
from collections import deque
n = len(prices)
dp = [0] * (n + 1)
q = deque()  # 存 j，按 dp[j-1]+prices[j-1] 单调递增
for i in range(1, n + 1):
    j = i
    val = dp[j - 1] + prices[j - 1]
    while q and dp[q[-1] - 1] + prices[q[-1] - 1] >= val:
        q.pop()
    q.append(j)
    while q[0] < (i + 1) // 2:
        q.popleft()
    dp[i] = dp[q[0] - 1] + prices[q[0] - 1]
```

## 复杂度
时间 O(n)：每个 j 入队出队各一次，i 从 1 到 n 扫一遍。
空间 O(n)：dp 数组和单调队列各开 n 个位置。

## 易错点
- 窗口左边界写成 `i // 2` 而非 `(i + 1) // 2`：i=3 时 j=1 已无法覆盖到 3（1 最多覆盖到 2），却仍留在队列里，`prices=[3,1,2]` 会错算成 3 而非 4。正确做法是用 `ceil(i/2) = (i+1)//2` 弹出过期 j。
- 忘记「免费拿到也能再买」：`prices=[3,1,2]` 中第 2 个水果被第 1 次购买免费覆盖，但花 1 金币买它能覆盖第 3 个，总花费 4 优于只买第 1 个的 3+2=5。转移时必须允许 j 落在已被覆盖的区间内，不能跳过。

## 如果面试官追问
问：n 扩大到 10^5 还能这么做吗？答：能，单调队列已是 O(n)，瓶颈只在读入；若要求输出具体购买方案，额外记录每个 dp[i] 的最优 j 并回溯即可。
