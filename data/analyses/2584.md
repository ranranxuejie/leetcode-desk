## 一句话思路
把每个质因子映射到它最后出现的下标，前缀扫描时取这些下标的右界，右界等于 i 就是合法切点。

## 怎么做
1. 用 SPF（最小质因子）筛到 `max(nums)`，把每个 `nums[i]` 拆成质因子集合。
2. 建 `last[p] = 该质因子最后出现的下标`；再对每个 `i` 求 `far[i] = max(last[p] for p in 质因子(nums[i]))`。
3. 从左往右维护 `reach = max(reach, far[i])`，若 `reach == i` 且 `i < n-1`，返回 `i`。

以 `nums = [4,7,8,15,3,5]` 为例：质因子 `4→{2}`、`8→{2}`，所以 `last[2]=2`；`15→{3,5}`，`last[3]=4`、`last[5]=5`。于是 `far = [2,1,2,5,4,5]`。扫描到 `i=2` 时 `reach = max(2,1,2) = 2 == i`，返回 2。而 `i=1` 时 `reach=2 != 1`，因为因子 2 在右边还出现，切了就不互质。

```python
N = max(nums)
spf = list(range(N + 1))
for i in range(2, int(N**0.5) + 1):
    if spf[i] == i:
        for j in range(i * i, N + 1, i):
            if spf[j] == j:
                spf[j] = i
last = {}
for i, x in enumerate(nums):
    while x > 1:
        p = spf[x]
        last[p] = i
        while x % p == 0:
            x //= p
reach = 0
for i, x in enumerate(nums):
    while x > 1:
        p = spf[x]
        reach = max(reach, last[p])
        while x % p == 0:
            x //= p
    if reach == i and i < len(nums) - 1:
        return i
return -1
```

## 复杂度
时间：筛法 O(M log log M)，M = max(nums)；分解与扫描 O(n log M)。
空间：`spf` 数组 O(M)，`last` 哈希表 O(M) 量级。

## 易错点
- `nums = [1,1]`：1 没有质因子，`reach` 始终为 0，`i=0` 时 `reach==0==i` 会返回 0，这其实正确（1 和 1 互质）；但若写成「质因子为空就跳过判断」，会漏掉这个切点，返回 -1。
- `nums = [2,3,5]`：三个质因子互不相同，`far=[0,1,2]`，`i=0` 时 `reach=0` 就返回 0，正确；但若把条件写成 `reach <= i`，在 `nums=[4,7,8,15,3,5]` 的 `i=1` 处 `reach=2 > 1` 不触发，看似没事，遇到 `reach < i` 的情形（如 `nums=[6,5,1]`，`last[2]=0`、`last[3]=0`，`far=[0,1,0]`，`i=2` 时 `reach=1 < 2`）会误判，必须严格 `==`。

## 如果面试官追问
若要求返回所有合法切点而非最小下标？答：把 `reach == i` 的分支改成收集进列表，继续扫到 `n-2`，逻辑不变。
