## 一句话思路
用单调栈求每个元素左右第一个严格大于它的位置，以该元素为端点的合法子数组数 = 左可选数 × 右可选数。

## 怎么做
1. 对每个下标 i，求 `left[i]`：i 左边第一个 `nums[j] > nums[i]` 的下标，没有则 -1。
2. 同理求 `right[i]`：i 右边第一个 `nums[j] > nums[i]` 的下标，没有则 n。
3. 以 i 为子数组左端点时，右端点可取 i..right[i]-1；以 i 为右端点时，左端点可取 left[i]+1..i，两者相乘即 i 贡献的数目。
4. 累加所有 i 的贡献。

以 `nums = [1,4,3,3,2]` 为例，i=2（值 3）：左边第一个严格大于 3 的是下标 1（值 4），右边第一个严格大于 3 的没有（下标 5），贡献 `(2-1)*(5-2)=3`，对应 [3]、[3,3]、[3,3,2] 三个子数组。

```python
n = len(nums)
left = [-1] * n
st = []
for i in range(n):
    while st and nums[st[-1]] <= nums[i]:
        st.pop()
    left[i] = st[-1] if st else -1
    st.append(i)
right = [n] * n
st = []
for i in range(n - 1, -1, -1):
    while st and nums[st[-1]] <= nums[i]:
        st.pop()
    right[i] = st[-1] if st else n
    st.append(i)
ans = sum((i - left[i]) * (right[i] - i) for i in range(n))
```

关键在弹栈条件用 `<=`：相等元素互相弹出，保证每个子数组只被其最左（或最右）的最大值端点统计一次。若改成 `<`，`[3,3,3]` 会被重复计数。

## 复杂度
时间：O(n)，每个下标入栈出栈各一次，两趟扫描。
空间：O(n)，`left`、`right` 两个数组加栈。

## 易错点
- 输入 `[3,3,3]` → 弹栈用 `<` 时，i=0 的 right 会是 1 而非 3，贡献算成 1，总数变 3 而非 6 → 必须用 `<=`，让相等元素把彼此弹出，使每个子数组只由最左那个最大值统计。
- 输入 `[1,4,3,3,2]` → 若把 `left[i]` 定义成「第一个大于等于」的位置，i=3（值 3）的 left 会变成 2，贡献从 `(3-1)*(5-3)=4` 缩成 `(3-2)*2=2`，漏掉 [3,3] 这类以相等元素为另一端的子数组 → 严格大于才是正确边界。

## 如果面试官追问
问：要求输出所有合法子数组而非计数？
答：对每个 i 枚举左端点 `left[i]+1..i` 和右端点 `i..right[i]-1` 组合，输出规模本身是 O(答案)，无法更快。
