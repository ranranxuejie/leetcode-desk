## 一句话思路
滑动窗口 + 单调队列维护窗口内 max/min，右端每扩一格，以 right 结尾的合法子数组数就是窗口长度。

## 怎么做
1. 用两个双端队列 `maxq`、`minq` 分别存窗口内元素下标，保持 `maxq` 对应值单调递减、`minq` 单调递增。
2. 右指针 `right` 逐个右移，先把 `nums[right]` 从队尾弹掉破坏单调性的下标再入队。
3. 当 `nums[maxq[0]] - nums[minq[0]] > 2` 时，说明窗口不合法，左指针 `left` 右移，并把等于 `left` 的队头弹出，直到差值 ≤ 2。
4. 此时 `[left, right]` 内所有以 `right` 结尾的子数组都合法，累加 `right - left + 1`。

以 `nums = [5,4,2,4]` 为例：`right=2` 时窗口 `[5,4,2]` 的 `maxq[0]=0`（值 5）、`minq[0]=2`（值 2），差 3 > 2，`left` 移到 1，窗口变 `[4,2]`，差 2 合法，累加 `2-1+1=2`。最终 1+2+2+3 = 8。

```python
from collections import deque
maxq, minq = deque(), deque()
left = ans = 0
for right, x in enumerate(nums):
    while maxq and nums[maxq[-1]] <= x:
        maxq.pop()
    maxq.append(right)
    while minq and nums[minq[-1]] >= x:
        minq.pop()
    minq.append(right)
    while nums[maxq[0]] - nums[minq[0]] > 2:
        if maxq[0] == left: maxq.popleft()
        if minq[0] == left: minq.popleft()
        left += 1
    ans += right - left + 1
```

## 复杂度
时间：O(n)，每个下标最多进出 `maxq`/`minq` 各一次，`left` 只增不减。
空间：O(n)，两个双端队列最坏各存 n 个下标。

## 易错点
- `nums = [1,2,3]` 若把条件写成 `>= 2` 或漏掉 `left` 收缩，会把 `[1,2,3]` 判为不合法，答案从 6 掉成 5；正确是差值 `> 2` 才收缩，`[1,2,3]` 差 2 合法。
- `nums = [5,4,2,4]` 收缩时若只弹 `maxq` 不弹 `minq`，`minq[0]` 会停在已出窗的下标 2，后续 `nums[minq[0]]` 读到过期值，差值算错；必须两个队列都检查 `== left` 再 `popleft`。

## 如果面试官追问
若把差值上限从 2 改成 k，怎么做？答：代码里 `> 2` 换成 `> k` 即可，单调队列逻辑不变，仍是 O(n)。
