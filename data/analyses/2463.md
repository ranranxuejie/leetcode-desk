## 一句话思路
排序后按工厂顺序 DP，每个工厂只修一段连续的机器人，因为跨工厂交叉分配一定可以交换成不交叉而不增加距离。

## 怎么做
1. 把 `robot` 升序排序，`factory` 按 `position` 升序排序。
2. 定义 `dp[i][j]`：前 `i` 个工厂修好前 `j` 个机器人的最小总距离，`dp[0][0]=0`，其余为 `inf`。
3. 对第 `i` 个工厂（`pos, lim`），枚举它修 `k` 个（`0<=k<=lim`），转移 `dp[i][j] = min(dp[i-1][j-k] + cost(j-k, j, pos))`。
4. `cost(l, r, pos)` 是机器人 `l..r-1` 到 `pos` 的距离和，用前缀和 `pre` 做到 O(1)。

用示例 1：`robot=[0,4,6]`，`factory=[[2,2],[6,2]]`。第一个工厂 `pos=2, lim=2`，修前 2 个机器人 `0,4`，`cost=|2-0|+|2-4|=4`；第二个工厂 `pos=6` 修 `6`，`cost=0`，合计 4。

```python
robot.sort()
factory.sort()
n = len(robot)
pre = [0] * (n + 1)
for i, x in enumerate(robot):
    pre[i + 1] = pre[i] + x
INF = float('inf')
dp = [INF] * (n + 1)
dp[0] = 0
for pos, lim in factory:
    ndp = dp[:]  # k=0
    for j in range(1, n + 1):
        for k in range(1, min(lim, j) + 1):
            l = j - k
            c = abs(pre[j] - pre[l] - k * pos)
            if dp[l] + c < ndp[j]:
                ndp[j] = dp[l] + c
    dp = ndp
return dp[n]
```

## 复杂度
时间：O(F·n·L)，F 工厂数、n 机器人数、L 最大 limit，均 ≤100。
空间：O(n)，只保留一维 `dp` 和前缀和 `pre`。

## 易错点
- `robot` 未排序就 DP → 连续段假设失效，示例 1 中 `[0,4,6]` 若乱序会把不相邻机器人分给同一工厂，答案偏大；必须先 `robot.sort()`。
- `factory` 未按 `position` 排序 → 转移顺序错乱，`[[6,2],[2,2]]` 会先处理 `6` 导致 `dp` 状态不可达；必须先 `factory.sort()`。

## 如果面试官追问
若 `limit` 总和远大于 `n`，能否优化？答：内层 `k` 上界取 `min(lim, j)`，且可提前 break 当 `dp[l]` 为 `inf`，实际远小于 O(n·L)。
