## 一句话思路
逐位比较 `guess[i]` 与 `answer[i]`，相等就计数，因为三次游戏互相独立、位置一一对应。

## 怎么做
1. 用 `zip(guess, answer)` 把两组三次选择按位置配对。
2. 对每一对 `(g, a)` 判断 `g == a`，成立则计数加一。
3. 返回累计的计数。

以示例 2 为例：`guess = [2,2,3]`、`answer = [3,2,1]`。配对后依次是 `(2,3)`、`(2,2)`、`(3,1)`；第一对 `2 != 3` 不计，第二对 `2 == 2` 计数变 1，第三对 `3 != 1` 不计，最终返回 1。

```python
cnt = 0
for g, a in zip(guess, answer):
    if g == a:
        cnt += 1
return cnt
```

等价的一行写法是 `sum(g == a for g, a in zip(guess, answer))`，`True` 当 1 累加。两种写法结果一致，前者更直白，后者更短。

## 复杂度
时间：O(n)，n 为数组长度 3，逐位比较一次。
空间：O(1)，只开了一个计数变量 `cnt`，没有额外数组。

## 易错点
- 把「猜对」理解成「猜过的数字出现在 answer 里」→ 示例 2 中 `guess[0]=2` 在 `answer` 里确实存在（`answer[1]=2`），会错算成 2 甚至 3 → 正确做法是只比同一下标的 `guess[i]` 与 `answer[i]`，位置错开不算对。
- 用 `set(guess) & set(answer)` 求交集大小 → 示例 2 得 `{2}` 大小为 1 碰巧对，但 `guess=[1,1,2]`、`answer=[1,2,2]` 会得 2，实际逐位只有第一位对，应为 1 → 正确做法是按下标配对比较，不要用集合去重。

## 如果面试官追问
问：如果长度不是 3 而是 n，且允许提前终止呢？
答：逻辑不变仍是 O(n) 逐位比较；若要提前退出，只能在「剩余位置全对也追不上目标」时剪枝，本题无此需求。
