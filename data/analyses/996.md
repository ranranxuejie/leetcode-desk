## 一句话思路
先按值去重计数，再在「值」上做回溯，用 `used` 记录每个值还剩几个，避免重复排列。

## 怎么做
1. 用 `Counter(nums)` 得到 `cnt`，把问题从「12 个下标」压成「若干个不同值」。
2. 预处理 `ok[a][b]`：`a + b` 是否为完全平方数，用 `int(sqrt(s)) ** 2 == s` 判断。
3. 回溯时枚举「下一个值」而不是「下一个下标」，选完 `cnt[v] -= 1`，递归后恢复。
4. 终止条件是已放 `len(nums)` 个数，答案加一。

以 `nums = [1,17,8]` 为例：`cnt = {1:1, 17:1, 8:1}`，`ok[1][8] = True`（9），`ok[8][17] = True`（25），但 `ok[1][17] = False`（18 不是平方数）。所以从 1 出发只能接 8，再必须接 17，得到 `[1,8,17]`；从 17 出发对称得到 `[17,8,1]`；从 8 出发两条路都断，共 2 个。

```python
from collections import Counter
from math import isqrt

def dfs(last, depth):
    if depth == n:
        return 1
    total = 0
    for v in cnt:
        if cnt[v] and (last is None or ok[last][v]):
            cnt[v] -= 1
            total += dfs(v, depth + 1)
            cnt[v] += 1
    return total

cnt = Counter(nums)
n = len(nums)
vals = list(cnt)
ok = {(a, b): isqrt(a + b) ** 2 == a + b for a in vals for b in vals}
return dfs(None, 0)
```

关键点：`last is None` 只用于第一个位置，之后 `ok[last][v]` 直接查表，不用每次重算平方数。

## 复杂度
时间：`O(2^m · m)` 量级，`m` 是不同值的个数，最坏 `m = n = 12`，每个状态枚举 `m` 个后继。
空间：`O(m^2)` 存 `ok` 表，递归栈 `O(n)`，`cnt` 字典 `O(m)`。

## 易错点
- 输入 `[2,2,2]` → 若按下标回溯会数出 `3! = 6` 个排列 → 正确做法是按值回溯，`cnt[2]` 从 3 减到 0 只有一条路径，答案 1。
- 输入 `[0,0,0,0]` → 若用 `isqrt` 后忘记判 `0` 的平方是 `0` 本身，会漏掉 `ok[0][0]` → 正确做法是 `isqrt(0) ** 2 == 0` 为 `True`，四个 0 全相邻合法，答案 1；同时注意 `nums[i]` 可达 `10^9`，两数之和到 `2*10^9`，`isqrt` 在 Python 里安全，不要手写 `int(sqrt())` 浮点比较。

## 如果面试官追问
问：若要求输出所有方案而非计数？答：把 `total += 1` 改成把当前 `path` 拷贝进结果列表，其余不变，复杂度多乘方案数。
