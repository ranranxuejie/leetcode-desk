## 一句话思路
逐元素比较 `matrix[i][j]` 与左上邻居 `matrix[i-1][j-1]`，全相等即托普利茨。

## 怎么做
1. 从 `i = 1, j = 1` 开始遍历，跳过第 0 行和第 0 列（它们没有左上邻居）。
2. 对每个位置检查 `matrix[i][j] == matrix[i-1][j-1]`，不等立刻返回 `False`。
3. 全部通过返回 `True`。

以示例 2 `[[1,2],[2,2]]` 为例：`i=1, j=1` 时比较 `matrix[1][1]=2` 与 `matrix[0][0]=1`，不相等，直接返回 `False`。示例 1 中 `i=1, j=1` 比较 `matrix[1][1]=1` 与 `matrix[0][0]=1` 相等，继续；`i=2, j=3` 比较 `matrix[2][3]=2` 与 `matrix[1][2]=2` 相等，最终返回 `True`。

```python
m, n = len(matrix), len(matrix[0])
for i in range(1, m):
    for j in range(1, n):
        if matrix[i][j] != matrix[i-1][j-1]:
            return False
return True
```

这个写法等价于「每条对角线相邻元素相同」，因为同一条对角线上任意两个相邻元素恰好是 `(i-1, j-1)` 与 `(i, j)` 的关系，传递性保证整条对角线一致。

## 复杂度
时间 O(m·n)，每个元素最多访问一次。
空间 O(1)，只用了 `i`、`j` 两个下标，没有额外数组。

## 易错点
- 输入 `[[1]]` 或单行 `[[1,2,3]]`：若从 `i=0` 或 `j=0` 开始访问 `matrix[-1][-1]`，Python 负索引会绕到矩阵末尾，可能误判为 `False` 或读到错误值；正确做法是循环从 `i=1, j=1` 起，天然跳过无左上邻居的边界。
- 输入 `[[1,2],[2,2]]`：若只比较同行相邻元素（`matrix[i][j]` 与 `matrix[i][j-1]`），会得到 `1≠2` 而误判，但真正该比的是对角线方向；正确做法是固定偏移 `(-1,-1)`，只和左上比。

## 如果面试官追问
问：矩阵只能按行流式读入、内存放不下一整行怎么办？
答：缓存上一行的前 `n-1` 个元素，读当前行时逐列与缓存比较，读完用当前行替换缓存，空间 O(n)。
