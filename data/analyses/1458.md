## 一句话思路
用 `dp[i][j]` 表示 nums1 前 i 个与 nums2 前 j 个能取到的最大点积，转移时把「以 i、j 结尾新乘一项」和「不选」分开讨论。

## 怎么做
1. 定义 `dp[i][j]`（i、j 从 1 起）为 nums1[:i] 与 nums2[:j] 的最大点积，初值 `-inf`，因为答案可能为负。
2. 转移三选一：`dp[i-1][j]`、`dp[i][j-1]`、以及用 `nums1[i-1]*nums2[j-1]` 接在 `dp[i-1][j-1]` 后面（若前者为 `-inf` 则只取这一项，保证非空）。
3. 关键中间值：示例 1 中 `dp[1][1]=6`，到 `dp[4][3]` 时 `nums1[3]*nums2[2]=5*(-6)=-30`，接在 `dp[3][2]=6` 上得 `-24`，不如 `dp[3][3]=18`，故最终 18。
4. 答案取 `dp[n][m]`。

```python
NEG = float('-inf')
n, m = len(nums1), len(nums2)
dp = [[NEG] * (m + 1) for _ in range(n + 1)]
for i in range(1, n + 1):
    for j in range(1, m + 1):
        prod = nums1[i-1] * nums2[j-1]
        best = prod if dp[i-1][j-1] == NEG else dp[i-1][j-1] + prod
        dp[i][j] = max(best, dp[i-1][j], dp[i][j-1])
return dp[n][m]
```

## 复杂度
时间：O(n*m)，两层循环各遍历 nums1、nums2 一次。
空间：O(n*m) 的 dp 表；可压成一维，但需保留左上角旧值。

## 易错点
- 全负输入如 `nums1=[-1,-1]`、`nums2=[1,1]`：若把 dp 初值设成 0，会错误地允许「空序列」并返回 0；正确做法是初值 `-inf`，且 `dp[i-1][j-1]` 为 `-inf` 时只取 `prod`，强制非空。
- 示例 1 的 `nums2` 含 0：若只写 `dp[i-1][j-1] + prod` 而不与 `dp[i-1][j]`、`dp[i][j-1]` 取 max，会漏掉「跳过 nums2 的 0」这条路径，得到 6 而非 18。

## 如果面试官追问
问：要求输出具体选中的两个子序列？
答：在 dp 里额外存每格的来源方向（上/左/斜），从 `dp[n][m]` 回溯即可还原下标。
