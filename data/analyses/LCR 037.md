## 一句话思路
用栈保存「尚未爆炸」的行星，只有栈顶为正、当前为负时才碰撞，循环消解直到稳定。

## 怎么做
1. 遍历 `asteroids`，每个元素先当作候选 `x`，准备压栈。
2. 当 `stack` 非空、`stack[-1] > 0` 且 `x < 0` 时，说明栈顶向右、`x` 向左，必然相撞，进入 while。
3. 循环内比较 `stack[-1]` 与 `-x`：栈顶小则 `pop` 后继续比；相等则 `pop` 并令 `x = 0` 表示同归于尽；栈顶大则 `x = 0` 直接消失。
4. 循环结束后若 `x != 0` 才 `append`，保证被吃掉的行星不入栈。

以 `[10,2,-5]` 为例：压入 10、2 后栈为 `[10,2]`；处理 `-5` 时 `stack[-1]=2 < 5`，`pop` 掉 2，栈变 `[10]`，继续比 `10 > 5`，令 `x=0`，`-5` 不入栈，最终 `[10]`。

```python
stack = []
for x in asteroids:
    while stack and stack[-1] > 0 and x < 0:
        if stack[-1] < -x:
            stack.pop()
        elif stack[-1] == -x:
            stack.pop()
            x = 0
            break
        else:
            x = 0
            break
    if x != 0:
        stack.append(x)
```

关键点：`x = 0` 是「本颗已死」的哨兵，`break` 后不再压栈；`x` 被保留时说明它吃掉了栈顶，还要继续和新的栈顶比。

## 复杂度
时间：O(n)，每个行星最多入栈一次、出栈一次，while 总次数不超过 n。
空间：O(n)，`stack` 最坏存下全部 n 个行星。

## 易错点
- 输入 `[-2,-1,1,2]` → 若只判断「栈顶正、当前负」却忘了 `stack[-1] > 0` 的完整条件，会把 `-2` 和 `-1` 当成碰撞对 → 正确做法是方向条件必须同时满足栈顶为正、当前为负，同向永不碰撞。
- 输入 `[1,-1]` → 若相等时只 `pop` 不把 `x` 置 0，会把 `-1` 又压回栈，得到 `[-1]` → 正确做法是相等分支里 `pop` 后令 `x = 0` 并 `break`，让两颗一起消失。

## 如果面试官追问
问：若要求返回碰撞发生的次数而非结果数组，怎么改？
答：在每次 `pop`（含相等时的那次）后累加计数器，`x=0` 的两种分支各计一次碰撞，最后返回计数即可。
