## 一句话思路
二分答案 k，判定「最强的 k 个工人做最弱的 k 个任务」是否可行，判定时用单调队列按需分配药丸。

## 怎么做
1. 两个数组升序排序，答案在 `[0, min(n, m)]` 上二分。
2. 判定 `k`：取 `tasks[:k]` 和 `workers[m-k:]`，从强到弱配对，任务也从大到小扫。
3. 对每个工人，先把所有 `tasks[i] <= w` 的任务入队（这些不吃药也能做），若队非空就弹一个；否则若还有药，就把 `tasks[i] <= w + strength` 的任务入队再弹一个，药数减一。
4. 队列空且无药可用即失败。

以示例 4 为例，`tasks` 排序后 `[5,5,8,9,9]`，`workers` 排序后 `[1,2,4,6,6]`，`pills=1, strength=5`。判 `k=3`：任务 `[5,5,8]`，工人 `[4,6,6]`。工人 6 先入队 `5,5`，弹 5；工人 6 入队 5，弹 5；工人 4 队列空，用药后 `4+5=9 >= 8`，入队 8 并弹出，成功。

```python
from collections import deque

def can(k):
    q = deque()
    i, p = k - 1, pills
    for w in workers[m-k:][::-1]:
        while i >= 0 and tasks[i] <= w:
            q.append(tasks[i]); i -= 1
        if q:
            q.pop()
        elif p > 0:
            while i >= 0 and tasks[i] <= w + strength:
                q.append(tasks[i]); i -= 1
            if not q:
                return False
            q.pop(); p -= 1
        else:
            return False
    return True
```

## 复杂度
时间：排序 `O((n+m)log(n+m))`，二分 `log(min(n,m))` 轮，每轮判定 `O(k)`，合计 `O((n+m)log(n+m))`。
空间：队列最多存 `k` 个任务，`O(min(n,m))`，排序额外开销不计。

## 易错点
- 判定时若写成「工人从弱到强、任务从大到小」配对，示例 1 中工人 0 会先撞上任务 3，白吃药还失败；正确是从强到弱配对，让强工人先吃掉大任务。
- 药丸不能提前用：示例 2 中工人 0 若一上来就吃药去够任务 5，看似可行，但队列里 `tasks[i] <= w` 的免费任务必须先弹完再考虑吃药，否则药被浪费在本来能免费做的任务上。

## 如果面试官追问
问：要输出具体分配方案怎么办？
答：判定时记录每个工人弹出了哪个任务、是否用药，二分收敛后重跑一次 `can(k)` 收集结果即可。
