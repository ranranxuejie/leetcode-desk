## 一句话思路
按「每消耗 5 升主油箱燃料换 1 升」循环模拟，因为每次转移都让主油箱净减 4 升，循环次数有限。

## 怎么做
1. 用 `while mainTank >= 5 and additionalTank >= 1` 作为循环条件，两个条件缺一不可。
2. 每轮先扣 5 升、加 1 升：`mainTank -= 4`，`additionalTank -= 1`，同时把这段里程 `5 * 10 = 50` 累加。
3. 循环结束后主油箱不足 5 升（或副油箱空了），剩余燃料一次性跑完：`mainTank * 10`。

以 `mainTank = 5, additionalTank = 10` 为例：进入循环时 `mainTank = 5 >= 5` 且 `additionalTank = 10 >= 1`，执行后 `mainTank = 1`、`additionalTank = 9`、`dist = 50`；此时 `mainTank = 1 < 5` 退出循环，补上 `1 * 10 = 10`，得 60。

```python
dist = 0
while mainTank >= 5 and additionalTank >= 1:
    mainTank -= 4          # 消耗 5 升、补回 1 升
    additionalTank -= 1
    dist += 50
dist += mainTank * 10
return dist
```

注意 `mainTank -= 4` 而不是 `-= 5` 再 `+= 1`，两者等价但前者少一次赋值，也避免中间出现负数让人误判。

## 复杂度
时间：O(mainTank / 4)，循环每轮主油箱净减 4，最多约 25 轮（mainTank ≤ 100）。
空间：O(1)，只用了 `dist`、`mainTank`、`additionalTank` 三个标量。

## 易错点
1. 循环条件只写 `mainTank >= 5` → 对 `mainTank = 5, additionalTank = 0` 会错误地进入循环，把 `mainTank` 减成 1 并白送 50 km，实际副油箱没油不该转移，正确答案是 50。必须同时判 `additionalTank >= 1`。
2. 把转移当成「连续按比例」→ 对 `mainTank = 9, additionalTank = 1` 会算成 9 升里含 1 次转移得 100 km，但正确是消耗 5 升触发转移后 `mainTank = 5`，再消耗 5 升又触发一次——此时 `additionalTank` 已为 0，只能得 90 km。必须严格按「每满 5 升触发一次、且副油箱有货」逐次模拟。

## 如果面试官追问
问：`mainTank` 放大到 10^9 怎么优化？
答：直接算 `k = min((mainTank - 5) // 4 + 1, additionalTank)`，距离为 `(mainTank + k) * 10`，O(1)。
