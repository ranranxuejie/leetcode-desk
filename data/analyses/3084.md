## 一句话思路
数出 `s` 中 `c` 出现的次数 `k`，答案就是 `k*(k+1)//2`，因为任选两个出现位置（可相同）就唯一确定一个以 `c` 开头结尾的子串。

## 怎么做
1. 遍历 `s`，统计字符等于 `c` 的下标个数，记为 `k`。
2. 答案等于从 `k` 个位置中可重复地选两个的组合数，即 `k*(k+1)//2`。
3. 用 `"abada"`、`c='a'` 走一遍：`c` 出现在下标 0、2、4，`k=3`，答案 `3*4//2=6`，与示例一致。
4. 注意 `k` 最大到 `10^5`，乘积约 `10^10`，Python 整数天然支持，无需特殊处理。

```python
k = 0
for ch in s:
    if ch == c:
        k += 1
return k * (k + 1) // 2
```

关键中间值：`"abada"` 扫完 `k=3`，`k*(k+1)//2 = 6`。

## 复杂度
时间：O(n)，`n = len(s)`，一次遍历统计 `k`。
空间：O(1)，只开了一个计数器 `k`。

## 易错点
1. 输入 `s="zzz", c='z'` → 若误以为子串必须长度 ≥2 或首尾不同位置，会算成 `C(3,2)=3` → 正确做法是允许首尾取同一位置，`k=3` 时答案为 `3*4//2=6`。
2. 输入 `s="abc", c='d'`（`c` 不在 `s` 中）→ 若循环里漏判 `k=0` 直接返回，可能返回 `0*1//2=0` 看似对，但若写成 `k*(k-1)//2` 会得 `0` 而 `k=1` 时得 `0` 错 → 正确公式固定为 `k*(k+1)//2`，`k=0` 和 `k=1` 都返回 0 和 1。

## 如果面试官追问
问：若要求输出所有子串而非计数？答：双重循环枚举 `c` 的每对出现位置 `(i,j)`，`i<=j`，切片 `s[i:j+1]`，时间升到 O(k²·n)。
