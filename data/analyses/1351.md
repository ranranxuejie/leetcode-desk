## 一句话思路
从右上角出发，利用行列递减性，每步排除一行或一列，O(m+n) 统计负数。

## 怎么做
1. 起点设为右上角 `(i, j) = (0, n-1)`，计数器 `count = 0`。
2. 若 `grid[i][j] < 0`，说明该列从 `i` 往下全是负数，直接 `count += m - i`，然后 `j -= 1` 左移。
3. 若 `grid[i][j] >= 0`，说明该行从 `j` 往右全非负，`i += 1` 下移。
4. 循环直到 `i == m` 或 `j < 0`，返回 `count`。

以示例 1 为例：`grid[0][3] = -1 < 0`，`count += 4 - 0 = 4`，`j` 变 2；`grid[0][2] = 2 >= 0`，`i` 变 1；`grid[1][2] = 1 >= 0`，`i` 变 2；`grid[2][2] = -1 < 0`，`count += 4 - 2 = 2`（累计 6），`j` 变 1；`grid[2][1] = 1 >= 0`，`i` 变 3；`grid[3][1] = -1 < 0`，`count += 4 - 3 = 1`（累计 7），`j` 变 0；`grid[3][0] = -1 < 0`，`count += 4 - 3 = 1`（累计 8），`j` 变 -1 结束。

```python
i, j = 0, len(grid[0]) - 1
count = 0
m = len(grid)
while i < m and j >= 0:
    if grid[i][j] < 0:
        count += m - i
        j -= 1
    else:
        i += 1
return count
```

## 复杂度
时间：O(m+n)，`i` 只增、`j` 只减，最多走 m+n 步。
空间：O(1)，只开了 `i`、`j`、`count` 三个变量。

## 易错点
- 起点选左下角 `(m-1, 0)` 时，若写成 `grid[i][j] < 0` 就 `i -= 1`，方向会反：左下角负数应向右扩列而非上移，容易把 `count += j + 1` 写成 `count += n - j`，示例 1 会得 10 而非 8。正确做法是固定用右上角，负数时整列 `m - i` 个全算。
- 全非负矩阵如示例 2 `[[3,2],[1,0]]`：若在 `grid[i][j] >= 0` 分支里也累加，会把 0 算成负数得 2。正确做法是只在 `< 0` 分支累加，`>= 0` 分支只移动 `i`。

## 如果面试官追问
追问：若矩阵只保证行有序、列无序怎么办？
答：逐行二分找第一个负数的位置，每行 O(log n)，总 O(m log n)。
