## 一句话思路
把 k 当作「进位」从 num 末位往前逐位相加，k 自身不断整除 10，最后把 k 剩余的高位补到结果前面。

## 怎么做
1. 从 `i = len(num) - 1` 开始倒序遍历，每轮把 `num[i] + k % 10` 的和取个位放进结果，进位直接累加回 `k`。
2. 关键中间值：以 `num = [2,1,5], k = 806` 为例，第一轮 `5 + 806 % 10 = 11`，个位 `1` 入结果，`k = 806 // 10 + 11 // 10 = 81`。
3. 遍历结束后若 `k > 0`，说明还有更高位没处理，继续 `k % 10` 入结果、`k //= 10`。
4. 结果是从低位往高位追加的，最后 `reverse` 一次即可。

```python
res = []
i = len(num) - 1
while i >= 0 or k > 0:
    if i >= 0:
        k += num[i]
        i -= 1
    res.append(k % 10)
    k //= 10
return res[::-1]
```

注意 `k += num[i]` 这一步把「当前位数字」和「上一轮进位」合并进同一个变量，所以循环条件只需判断 `k > 0`，不必单独维护 carry。

## 复杂度
时间 O(max(n, log k))，n 是 num 长度，log k 是 k 的位数，两者取大。
空间 O(max(n, log k))，只开了结果数组 res，没有额外结构。

## 易错点
- `num = [0], k = 10000` → 若循环只写 `while i >= 0`，k 的高位 1 会丢失，输出 `[0]` 而非 `[1,0,0,0,0]`；正确做法是循环条件带上 `or k > 0`，让 k 剩余位继续入结果。
- `num = [9,9,9], k = 1` → 若把 `k += num[i]` 写成 `k = num[i] + k % 10`，进位被截断，输出 `[0,0,0]` 而非 `[1,0,0,0]`；正确做法是让 k 承载完整和，再 `k //= 10` 自然带出进位。

## 如果面试官追问
问：若 num 长度到 10^5 且 k 也是大数字符串怎么办？
答：把 k 转成数字数组，双指针从两数组末尾同步相加，逻辑同上，只是进位变量单独维护。
