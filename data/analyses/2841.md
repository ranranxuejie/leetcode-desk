## 一句话思路
定长窗口滑过 nums，用哈希表维护窗口内频次，窗口和与不同元素数同时增量更新，取满足 distinct ≥ m 的最大和。

## 怎么做
1. 先把前 k 个元素塞进 `cnt` 字典，同时算出 `window_sum` 和 `len(cnt)`。
2. 从 `i = k` 开始，每次右进 `nums[i]`、左出 `nums[i-k]`，同步更新 `cnt` 与 `window_sum`。
3. 每步若 `len(cnt) >= m`，用 `window_sum` 更新答案。
4. 遍历结束返回答案（初始 0，天然覆盖不存在的情况）。

以示例 1 `nums = [2,6,7,3,1,7], m=3, k=4` 为例：初始窗口 `[2,6,7,3]`，`cnt={2:1,6:1,7:1,3:1}`，`window_sum=18`，`len(cnt)=4 ≥ 3`，答案记为 18。滑到 `[6,7,3,1]` 时 `window_sum=17`，仍满足但更小；最后 `[7,3,1,7]` 中 7 出现两次，`cnt[7]=2`，`len(cnt)=3` 恰好达标，和 18 打平。最终 18。

```python
cnt = {}
window_sum = 0
for x in nums[:k]:
    cnt[x] = cnt.get(x, 0) + 1
    window_sum += x
ans = window_sum if len(cnt) >= m else 0
for i in range(k, len(nums)):
    out, inn = nums[i - k], nums[i]
    window_sum += inn - out
    cnt[inn] = cnt.get(inn, 0) + 1
    cnt[out] -= 1
    if cnt[out] == 0:
        del cnt[out]
    if len(cnt) >= m and window_sum > ans:
        ans = window_sum
```

## 复杂度
时间 O(n)：每个元素进出窗口各一次，哈希操作均摊 O(1)。
空间 O(k)：`cnt` 最多存 k 个不同键。

## 易错点
- 移出元素时只做 `cnt[out] -= 1` 而不删零值键 → 示例 1 滑到 `[6,7,3,1]` 时 `cnt` 里残留 `2:0`，`len(cnt)` 虚高成 5，把 distinct 数算大，可能误判不达标窗口为达标。正确做法是计数归零立刻 `del cnt[out]`。
- 用 `len(cnt) >= m` 判断前忘了 `k` 可能等于 `len(nums)` → 若只在滑动循环里更新答案，`nums` 长度恰为 k 时循环体一次不执行，直接返回 0，而示例 1 若 `k=6` 应返回 25。正确做法是初始窗口先判一次。

## 如果面试官追问
问：若要求返回该子数组的起始下标而非和？
答：把 `ans` 换成 `(best_sum, best_start)` 元组，更新时同步记录 `i-k+1` 即可，逻辑不变。
