## 一句话思路
逐行 DP，用两次左右扫描把 `max(dp[c'] - |c-c'|)` 压成 O(n)，避免 O(n²) 枚举。

## 怎么做
1. 令 `dp[c]` 为选到当前行第 `c` 列的最大得分，初始 `dp = points[0][:]`。
2. 对下一行，先算 `best[c] = max(dp[c'] - |c-c'|)`：左扫维护 `dp[c'] - c'` 的最大值，右扫维护 `dp[c'] + c'` 的最大值，取两者较大者。
3. 新 `dp[c] = points[r][c] + best[c]`，逐行滚动更新。
4. 最后返回 `max(dp)`。

以示例 1 的 `points = [[1,2,3],[1,5,1],[3,1,1]]` 为例，第一行后 `dp = [1,2,3]`。处理第二行时，左扫得到 `best = [1,2,3]`（`dp[c']-c'` 最大为 1），右扫得到 `best = [3,2,3]`（`dp[c']+c'` 最大为 5），取较大者 `best = [3,2,3]`，于是新 `dp = [1+3, 5+2, 1+3] = [4,7,4]`。处理第三行同理，最终 `max(dp) = 9`。

```python
m, n = len(points), len(points[0])
dp = points[0][:]
for r in range(1, m):
    best = [0] * n
    cur = -10**18
    for c in range(n):
        cur = max(cur, dp[c] - c)
        best[c] = cur + c
    cur = -10**18
    for c in range(n - 1, -1, -1):
        cur = max(cur, dp[c] + c)
        best[c] = max(best[c], cur - c)
    dp = [points[r][c] + best[c] for c in range(n)]
return max(dp)
```

## 复杂度
时间：O(m·n)，每行左右各扫一遍。
空间：O(n)，只开 `dp` 和 `best` 两个长度 n 的数组。

## 易错点
- 左扫时 `cur` 初值若设 0，遇到全负的 `dp[c]-c` 会取错 → 应设 `-10**18`，因为 `points[r][c]` 可为 0 但 `dp` 可能为负。
- 右扫必须复用同一个 `best` 数组取 `max`，若直接覆盖会丢掉左扫结果 → 示例 1 第二行左扫 `[1,2,3]`、右扫 `[3,2,3]`，覆盖后 `best[0]` 会从 3 变回 1，答案错成 7。

## 如果面试官追问
要求输出选中的列坐标方案？答：每行额外存 `argmax` 来源列，回溯时按 `best[c]` 的来源列反推即可。
