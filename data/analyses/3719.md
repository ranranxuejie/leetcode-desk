## 一句话思路
枚举左端点，向右扩展时用两个集合维护不同偶数/奇数，集合大小相等就更新答案。

## 怎么做
1. 外层 `i` 从 0 到 n-1，每次新建 `evens=set()`、`odds=set()`。
2. 内层 `j` 从 `i` 向右走，按 `nums[j] % 2` 把值塞进对应集合。
3. 每步比较 `len(evens) == len(odds)`，相等则 `ans = max(ans, j - i + 1)`。
4. 提前剪枝：若 `j - i + 1` 已不可能超过 `ans` 就跳过比较（可选）。

以 `nums = [3,2,2,5,4]` 为例，`i=0` 走到 `j=4` 时，`evens={2,4}`、`odds={3,5}`，两者长度都是 2，`j-i+1=5` 更新 `ans=5`；中途 `j=2` 时 `evens={2}`、`odds={3}` 也相等，长度 3 只是过渡值。

```python
n = len(nums)
ans = 0
for i in range(n):
    evens, odds = set(), set()
    for j in range(i, n):
        if nums[j] % 2 == 0:
            evens.add(nums[j])
        else:
            odds.add(nums[j])
        if len(evens) == len(odds):
            ans = max(ans, j - i + 1)
return ans
```

关键点：集合去重是必须的，`[3,2,2,5,4]` 里两个 2 只算一个不同偶数，若用计数器累加会得到偶数 3 个、奇数 2 个，误判为不平衡。

## 复杂度
时间：O(n²)，外层 n 个左端点，内层平均 n/2 步，每步集合操作均摊 O(1)。
空间：O(n)，两个集合最多存 n 个不同值，无其他额外结构。

## 易错点
- 输入 `[2,2,2,3]` → 若用计数变量而非集合，会认为偶数出现 3 次、奇数 1 次，永远不相等，返回 0；正确做法是用 `set` 去重，`{2}` 与 `{3}` 长度都为 1，答案应为 4。
- 输入 `[1]` 或 `[2]` → 若初始化 `ans = 0` 且只在相等时更新，单元素子数组 `{1}` 与空集长度不等，返回 0；但题目要求非空子数组，单元素本身不平衡，返回 0 是对的，别误改成返回 1。

## 如果面试官追问
问：n 放大到 10^5 怎么办？
答：O(n²) 会超时，需按「不同值个数」分块或对每个左端点用前缀哈希记录首次出现位置，把内层降为 O(不同值数)，最坏仍是 O(n·√n) 级别。
