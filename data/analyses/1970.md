## 一句话思路
答案关于天数单调（越晚水越多、越难连通），二分天数 + BFS 判定第 k 天能否从上走到下。

## 怎么做
1. 二分区间 `lo, hi = 1, len(cells)`，找最后一个仍连通的 `mid`。
2. 判定函数：把 `cells[:mid]` 全部标成水，从第 1 行所有陆地格入队做 BFS。
3. 出队格若 `r == row` 立即返回 `True`，否则四方向扩展未访问陆地。
4. 队列空返回 `False`，二分收缩到 `lo`。

以示例 1 为例，`mid = 2` 时水格是 `(1,1),(2,1)`，第 1 行只剩 `(1,2)` 入队，它下探到 `(2,2)` 即 `r == row`，判定 `True`；`mid = 3` 时 `(1,2)` 也被淹，第 1 行无陆地，队列空，判定 `False`，故答案 2。

```python
def ok(k):
    wet = set(map(tuple, cells[:k]))
    q = deque((1, c) for c in range(1, col + 1) if (1, c) not in wet)
    seen = set(q)
    while q:
        r, c = q.popleft()
        if r == row:
            return True
        for nr, nc in ((r+1,c),(r-1,c),(r,c+1),(r,c-1)):
            if 1 <= nr <= row and 1 <= nc <= col and (nr,nc) not in wet and (nr,nc) not in seen:
                seen.add((nr,nc)); q.append((nr,nc))
    return False
```

## 复杂度
时间：`O(row*col*log(row*col))`，二分 `log` 次，每次 BFS 扫全图。
空间：`O(row*col)`，`wet` 集合与 `seen` 各存至多 `row*col` 个坐标。

## 易错点
- 二分写成找第一个不连通的天再返回它：示例 1 会返回 3，正确是返回 `lo` 即最后一个连通天 2，因为 `ok(2)=True` 时要把 `lo` 抬到 `mid`。
- 起点只取 `(1,1)`：示例 1 第 2 天 `(1,1)` 已是水，会误判 `False`，必须把第 1 行所有非水格都入队。

## 如果面试官追问
若 `row*col` 放大到 10^6 且要求输出具体路径？答：二分仍可行，但每次 BFS 要存 `parent` 指针回溯，空间涨到 `O(row*col)` 的字典。
