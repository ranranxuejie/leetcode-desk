## 一句话思路
用最小堆按腐烂日排序，每天先扔掉过期苹果，再吃最早烂的那个，这样最紧迫的苹果先被消耗。

## 怎么做
1. 遍历第 `i` 天，把 `apples[i] > 0` 的苹果以 `(i + days[i], apples[i])` 入堆，腐烂日 `i + days[i]` 是「第几天起不能吃」。
2. 每天吃之前，把堆顶 `expire <= i` 的条目弹出，这些已经烂了。
3. 堆非空就吃堆顶一个，`count += 1`，该条目剩余数减一，大于 0 就留在堆里。
4. `i` 从 0 走到 `n-1` 后继续往后走，直到堆空为止（因为 n 天后还能吃）。

以示例 1 为例，第 3 天（`i=2`）时堆里是 `(3,1)`（第 0 天苹果，第 3 天烂）和 `(4,2)`（第 1 天苹果）。吃之前弹出 `expire <= 2` 的？`3 > 2` 不弹。吃堆顶 `(3,1)`，第 3 天苹果 `apples[2]=3` 的腐烂日是 `2+1=3`，入堆后 `(3,3)` 与 `(3,1)` 并列，第 3 天结束它俩都烂，第 4 天起只能吃第 3 天（`i=3`）的 5 个苹果。

```python
import heapq
h = []
ans = 0
i = 0
n = len(apples)
while i < n or h:
    if i < n and apples[i] > 0:
        heapq.heappush(h, (i + days[i], apples[i]))
    while h and h[0][0] <= i:
        heapq.heappop(h)
    if h:
        exp, cnt = heapq.heappop(h)
        ans += 1
        if cnt > 1:
            heapq.heappush(h, (exp, cnt - 1))
    i += 1
```

## 复杂度
时间：`O((n + 答案) log n)`，每天一次堆操作，`n` 是入堆次数。
空间：`O(n)`，堆最多存 `n` 个不同腐烂日的条目。

## 易错点
- 示例 2 的 `apples=[3,0,0,0,0,2]`：若循环只写到 `i < n` 就停，第 6 天（`i=5`）的 2 个苹果只能吃到 1 个，答案错成 4；正确是 `while i < n or h`，让 `i` 越过 `n` 继续消耗堆。
- 腐烂日边界：`days[i]` 是「`i + days[i]` 天后腐烂」，第 `i + days[i]` 天已不能吃，所以弹出条件是 `expire <= i` 而非 `< i`；示例 1 第 3 天（`i=2`）若写成 `<`，会误吃第 3 天苹果，答案偏大。

## 如果面试官追问
问：若要求输出每天吃哪个苹果的方案？答：堆里存 `(expire, count, born_day)`，每天记录弹出的 `born_day` 即可，复杂度不变。
