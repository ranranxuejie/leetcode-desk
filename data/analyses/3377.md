## 一句话思路
把每个非质数当节点、数位±1当边，边权是目标值，跑 Dijkstra 求 n 到 m 的最短代价。

## 怎么做
1. 先筛出 10^4 以内质数表，`n` 或 `m` 是质数直接返回 -1。
2. 节点是 0..9999 的非质数；从 x 出发，对每个数位 ±1 得到 y，若 y 非质数则边权为 y。
3. 用堆做 Dijkstra，`dist[n]=0`，每次弹出最小 `dist`，松弛邻居 `dist[y] = dist[x] + y`。
4. 弹出 m 即返回 `dist[m]`，堆空返回 -1。

以 `n=10, m=12` 为例：从 10 出发，数位加 1 得 20（非质数，代价 20），20→21（代价 21），21→22（代价 22），22→12（代价 12），累计 20+21+22+12=75？注意起点 10 本身也计入代价，实际路径 10→20→21→22→12 的代价和是 10+20+21+22+12=85，与示例一致——**起点值要算进总代价**。

```python
import heapq
def minOperations(n, m):
    if is_prime[n] or is_prime[m]: return -1
    dist = {n: n}
    pq = [(n, n)]
    while pq:
        d, x = heapq.heappop(pq)
        if x == m: return d
        if d > dist.get(x, 1 << 60): continue
        for y in neighbors(x):
            if is_prime[y]: continue
            nd = d + y
            if nd < dist.get(y, 1 << 60):
                dist[y] = nd
                heapq.heappush(pq, (nd, y))
    return -1
```

`neighbors(x)` 枚举每个数位 ±1，注意首位不能变 0（否则位数减少，与「数位数目相同」矛盾）。

## 复杂度
时间：O(V log V + E)，V≤10^4 个非质数节点，E≤4V 条边，堆操作贡献 log V。
空间：O(V) 存 dist 和堆，质数表 O(10^4)。

## 易错点
- 起点代价漏算：`n=10` 时若 `dist[n]=0`，路径和变成 75 而非 85。正确做法是初始化 `dist[n]=n`，把起点值计入。
- 首位减到 0：如 `n=10` 把首位 1 减成 0 得 `00`，位数从 2 变 1，违反「数位数目相同」。正确做法是枚举首位时跳过减到 0 的情况。

## 如果面试官追问
问：若 n、m 可达 10^9 怎么办？答：节点数爆炸，Dijkstra 不可行，需按数位独立分析或改用 A* / 双向搜索。
