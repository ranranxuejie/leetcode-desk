## 一句话思路
从国王出发沿 8 个方向逐格外扩，每个方向遇到的第一个皇后就是该方向唯一能攻击的皇后。

## 怎么做
1. 把 `queens` 转成集合 `qset`，判断某格有没有皇后是 O(1)。
2. 对 8 个方向向量 `(dx, dy)` 各做一次射线：从 `king` 出发，每步 `x += dx, y += dy`。
3. 越界（`x` 或 `y` 不在 `0..7`）就换下一个方向；命中 `qset` 就记录并立即 `break`。
4. 收集到的坐标即答案，顺序任意。

以示例 1 为例，`king = [0,0]`，方向 `(0,1)` 上依次检查 `(0,1)` 命中 `[0,1]` 就停；方向 `(1,1)` 上 `(1,1)` 不在 `qset`，继续到 `(2,2)` 不在，`(3,3)` 命中 `[3,3]`；方向 `(1,0)` 第一步 `(1,0)` 命中。而 `[4,0]` 在 `(1,0)` 方向上被 `[1,0]` 挡住，`[0,4]` 被 `[0,1]` 挡住，`[2,4]` 不在任何射线上——正好排除掉这三个。

```python
qset = {tuple(q) for q in queens}
res = []
for dx in (-1, 0, 1):
    for dy in (-1, 0, 1):
        if dx == 0 and dy == 0:
            continue
        x, y = king[0] + dx, king[1] + dy
        while 0 <= x < 8 and 0 <= y < 8:
            if (x, y) in qset:
                res.append([x, y])
                break
            x += dx
            y += dy
```

## 复杂度
时间：O(8 × 8 + q)，每个方向最多走 7 步，q 为 `queens` 长度，建集合一次。
空间：O(q)，`qset` 存全部皇后坐标，`res` 最多 8 个。

## 易错点
- 某方向上有多个皇后时（如 `queens = [[0,1],[0,3]]`、`king = [0,0]`），若遍历完整个方向把所有命中都收进 `res`，会把 `[0,3]` 也当成能攻击的皇后；正确做法是命中第一个就 `break`，因为 `[0,1]` 挡住了后面。
- 方向向量写成 `(dx, dy)` 后循环里误用 `x += dy, y += dx`，在示例 1 的 `(1,1)` 方向上会走到 `(1,1)`、`(2,2)`、`(3,3)` 看似没错，但换成 `(1,-1)` 这类不对称方向就会漏掉 `[1,0]`；正确做法是严格 `x += dx, y += dy`，且 `dx` 管行、`dy` 管列与输入 `[x, y]` 的语义一致。

## 如果面试官追问
若棋盘不是 8×8 而是 10^9×10^9、皇后数 10^5，怎么办？答：不能逐格走，改为对每个皇后判断是否与国王同行/同列/同对角线，再按方向分组取距离最近者。
