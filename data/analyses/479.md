## 一句话思路
从 `hi = 10**n - 1` 起降序枚举 `a`，用回文构造而非回文判定，第一个能被 `a` 整除的即最大。

## 怎么做
1. 令 `hi = 10**n - 1`（n=2 时 `hi=99`），`lo = 10**(n-1)`，两个 n 位因子的上界与下界。
2. 外层 `a` 从 `hi` 递减，内层用 `a` 拼出回文 `p`：`p = int(str(a) + str(a)[::-1])`，n=2、`a=99` 时 `p=9999`。
3. 内层 `b` 从 `hi` 递减到 `lo`，一旦 `p % b == 0` 且 `p // b <= hi` 就返回 `p % 1337`；`b*b < p` 时提前跳出。
4. n=2 时 `a=99` 的 `9999` 试到 `b=99` 不整除（`9999 % 99 = 0` 但 `9999//99=101 > 99`，越界），继续 `a=98` 得 `9889`，直到 `a=91` 得 `9009 = 99*91`，返回 `9009 % 1337 = 987`。

```python
hi = 10 ** n - 1
lo = 10 ** (n - 1)
for a in range(hi, lo - 1, -1):
    p = int(str(a) + str(a)[::-1])
    for b in range(hi, lo - 1, -1):
        if b * b < p:
            break
        if p % b == 0 and p // b <= hi:
            return p % 1337
```

关键点：`p` 由 `a` 唯一确定，所以外层降序保证回文值降序，第一个命中就是最大；`b*b < p` 的剪枝把内层从 90 次压到约 10 次。

## 复杂度
时间：外层约 `9*10**(n-1)` 个回文，内层剪枝后约 `10**n` 次取模，n=8 时约 10^8 量级但常数极小。
空间：只存 `hi/lo/a/b/p` 几个整数，O(1)。

## 易错点
- n=1 时 `lo = 10**0 = 1`、`hi = 9`，若把 `lo` 写成 `10**n // 10` 之外的式子或漏掉 `lo-1` 边界，`range` 会漏掉 `a=1`，返回 `None`；正确做法是 `range(hi, lo-1, -1)` 且 n=1 直接命中 `9 = 9*1`。
- 只判 `p % b == 0` 不判 `p // b <= hi`，n=2、`a=99` 时 `9999 % 99 == 0` 会误返回 `9999 % 1337 = 642`，但 `9999//99 = 101` 是三位数；必须加 `p // b <= hi` 才是两个 n 位整数之积。

## 如果面试官追问
问：n 放宽到 10 以上怎么办？答：回文枚举量涨到 10^9，改用「从最大回文往下判、对每个回文试除到 sqrt」或直接数学构造，不再逐 `a` 拼串。
