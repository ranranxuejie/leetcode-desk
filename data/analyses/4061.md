## 一句话思路
答案只可能是 0/1/2：同行、同列或同对角线一步到，否则两步必达，用三个条件判断即可。

## 怎么做
1. 若 `source == target`，返回 0。
2. 若 `sr == tr` 或 `sc == tc`，返回 1（同行或同列）。
3. 若 `abs(sr - tr) == abs(sc - tc)`，返回 1（同对角线）。
4. 以上都不满足，返回 2。

以示例 2 的 `source = [4,2]`、`target = [1,3]` 为例：`sr != tr`、`sc != tc`，且 `abs(4-1)=3`、`abs(2-3)=1`，两个差值不等，所以不是一步可达，返回 2。

```python
def minQueenMoves(source, target):
    sr, sc = source
    tr, tc = target
    if sr == tr and sc == tc:
        return 0
    if sr == tr or sc == tc:
        return 1
    if abs(sr - tr) == abs(sc - tc):
        return 1
    return 2
```

为什么两步一定够：任意两个格子 `(sr,sc)` 和 `(tr,tc)`，先沿行走到 `(sr,tc)`，再沿列走到 `(tr,tc)`，两步覆盖所有情况。所以不存在 3 步及以上的答案，枚举 0/1/2 是完备的。

## 复杂度
时间：O(1)，只做常数次比较和减法，与棋盘大小无关。
空间：O(1)，只用了 `sr/sc/tr/tc` 四个变量，没有额外数组。

## 易错点
- 输入 `source = [1,1]`、`target = [1,1]` → 若先判同行 `sr == tr` 就返回 1，会错成 1 → 必须把「完全相同」的判断放在最前面返回 0。
- 输入 `source = [8,1]`、`target = [1,8]` → 若只判 `sr == tr or sc == tc` 就返回 2，会错成 2 → 必须补上 `abs(sr-tr) == abs(sc-tc)` 的对角线判断，此例 `abs(8-1)=7`、`abs(1-8)=7` 相等，返回 1。

## 如果面试官追问
问：若棋盘不是 8×8 而是 n×n，答案会变吗？
答：不会，两步构造 `(sr,tc)` 对任意 n 都成立，仍是 0/1/2。
