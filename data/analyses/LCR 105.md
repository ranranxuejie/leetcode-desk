## 一句话思路
对每个值为 1 的格子做 DFS 并原地把 1 改成 0，一次遍历统计连通块大小，取最大值。

## 怎么做
1. 双重循环扫 `grid`，遇到 `grid[i][j] == 1` 就以它为起点 DFS，返回面积并更新 `best`。
2. DFS 入口先判越界或 `grid[i][j] != 1`，直接返回 0；否则立刻置 `grid[i][j] = 0` 再向四邻递归。
3. 置 0 是「访问标记」，保证同一块土地只被计入一次，也省掉 `visited` 数组。

以示例 1 为例：扫到 `grid[0][2] == 1`，DFS 只向下、向右探，四邻全是 0，返回面积 1；继续扫到 `grid[0][7]`，这一块经 `(1,7)→(1,8)→(1,9)` 展开，面积 4；扫到 `grid[2][1]` 时，`(2,1)` 与 `(3,1)`、`(4,1)` 连成竖条，面积 3。最大仍为 4，直到扫到 `grid[3][8]` 那一块（含 `(4,8)(4,9)(4,10)(5,10)` 等）才得到 6。

```python
def dfs(i, j):
    if i < 0 or i >= m or j < 0 or j >= n or grid[i][j] != 1:
        return 0
    grid[i][j] = 0
    return 1 + dfs(i+1, j) + dfs(i-1, j) + dfs(i, j+1) + dfs(i, j-1)

best = 0
for i in range(m):
    for j in range(n):
        if grid[i][j] == 1:
            best = max(best, dfs(i, j))
return best
```

## 复杂度
时间 O(m·n)：每个格子最多被访问常数次，置 0 后不再进入。
空间 O(m·n)：最坏情况整张图是一条蛇形岛屿，递归栈深度达到 m·n。

## 易错点
- 忘记置 `grid[i][j] = 0`（或另开 visited）→ 示例 1 中 `(3,8)` 与 `(4,8)` 会互相反复递归，直接栈溢出或面积重复累加。必须在递归前、判完 `== 1` 之后立刻置 0。
- 只写 `if grid[i][j] != 1: return 0` 而不判越界 → 从 `(0,0)` 向左会访问 `grid[0][-1]`，Python 负索引会静默取到本行最后一个元素，把不相连的岛屿算进来。越界判断必须写在取值之前。

## 如果面试官追问
若 m、n 放大到 3000×3000，递归会爆栈怎么办？答：改显式栈存 `(i, j)` 做迭代 DFS，或按行扫描用并查集合并左、上邻居，空间降到 O(m·n) 的父数组但无栈深风险。
