## 一句话思路
利用异或的自反性：`pref[i] = pref[i-1] ^ arr[i]`，两边同异或 `pref[i-1]` 即得 `arr[i] = pref[i] ^ pref[i-1]`。

## 怎么做
1. `arr[0] = pref[0]`，因为前缀异或的第一项就是首元素本身。
2. 对 `i` 从 1 到 `n-1`，令 `arr[i] = pref[i] ^ pref[i-1]`。
3. 顺序填完即得答案，无需额外校验。

以 `pref = [5,2,0,3,1]` 为例：`arr[0]=5`；`arr[1]=2^5=7`；`arr[2]=0^2=2`；`arr[3]=3^0=3`；`arr[4]=1^3=2`，得到 `[5,7,2,3,2]`。关键中间值是 `arr[1]=7`——它由 `pref[1]^pref[0]=2^5` 得到，而不是 `pref[1]` 本身。

```python
def findArray(pref):
    arr = [pref[0]]
    for i in range(1, len(pref)):
        arr.append(pref[i] ^ pref[i - 1])
    return arr
```

也可以原地改 `pref` 省一个数组：从后往前 `pref[i] ^= pref[i-1]`，但正序更直观，`n ≤ 10^5` 时多开一个列表完全可接受。

## 复杂度
时间：O(n)，一次遍历，每个元素做一次异或。
空间：O(n)，额外开 `arr` 存结果；若原地改 `pref` 则 O(1)。

## 易错点
1. 把 `arr[i]` 写成 `pref[i] ^ arr[i-1]` → 对 `pref=[5,2,0,3,1]` 会算出 `[5,7,5,6,7]`，与答案 `[5,7,2,3,2]` 不符 → 正确是异或**前一个前缀值** `pref[i-1]`，不是前一个 `arr`。
2. 循环从 `i=0` 开始并访问 `pref[-1]` → 在 `pref=[13]` 这种单元素输入上会拿 `pref[-1]=13` 算出 `arr[0]=0`，错成 `[0]` → 正确做法是先把 `pref[0]` 放进结果，循环从 `i=1` 起。

## 如果面试官追问
问：若要求原地修改 `pref` 且不许开新数组，怎么写？
答：从后往前 `pref[i] ^= pref[i-1]`，因为 `pref[i-1]` 在被覆盖前已用完，倒序保证它还是原值。
