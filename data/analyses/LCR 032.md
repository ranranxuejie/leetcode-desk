## 一句话思路
用长度 26 的计数数组对 s 加、对 t 减，最后全为 0 即为异位词；先比长度可挡掉一半输入。

## 怎么做
1. 先判 `len(s) != len(t)` 直接返回 `False`，长度不同必然不是。
2. 建 `cnt = [0] * 26`，遍历 `s` 时 `cnt[ord(c) - 97] += 1`。
3. 遍历 `t` 时 `cnt[ord(c) - 97] -= 1`，若某次减完变负可提前返回 `False`。
4. 全部走完返回 `True`（长度相等时，减完为负等价于最终不全为 0）。

以 `s = "anagram", t = "nagaram"` 为例：走完 `s` 后 `cnt` 在 `a` 位是 3、`n` 位 1、`g` 位 1、`r` 位 1、`m` 位 1；走 `t` 的 `n,a,g,a,r,a,m` 时逐位减回 0，中途无负值，返回 `True`。

```python
if len(s) != len(t):
    return False
cnt = [0] * 26
for c in s:
    cnt[ord(c) - 97] += 1
for c in t:
    i = ord(c) - 97
    cnt[i] -= 1
    if cnt[i] < 0:
        return False
return True
```

注意示例 3 `s = t = "a"`：计数全对但顺序完全相同，按本题定义应返回 `False`，所以严格实现还需加一句 `s != t` 的前置判断（主站 242 不需要）。这是本题与 242 的唯一实质差异。

## 复杂度
时间：O(n)，n 为串长，两趟遍历各 O(n)，26 次比较是常数。
空间：O(1)，只开长度 26 的 `cnt`，与 n 无关。

## 易错点
- 输入 `s = "a", t = "a"` → 只做计数会返回 `True`，但本题要求「顺序不完全相同」→ 开头补 `if s == t: return False`，再进计数逻辑。
- 输入 `s = "ab", t = "a"` → 若省掉长度判断，遍历 `t` 时 `cnt` 里 `b` 位残留 1，靠末尾全零检查也能拦住，但若用「减到负数就返回」的写法，`t` 走完没触发就误判 `True` → 长度判断必须放在最前面。

## 如果面试官追问
问：含 unicode 字符怎么办？
答：把 `[0]*26` 换成 `collections.Counter(s)` 与 `Counter(t)` 比较，或 `defaultdict(int)` 按字符计数，索引不再依赖 `ord(c)-97`。
