## 一句话思路
用后缀和把「拿走的石子数」变成 O(1) 查询，再对状态 `(i, M)` 做记忆化搜索，每层取「当前拿走的 + 剩余总量 − 对手最优」的最大值。

## 怎么做
1. 预处理 `suf[i] = sum(piles[i:])`，`suf[n] = 0`，这样「从第 i 堆起还剩多少石子」直接查表。
2. 定义 `dfs(i, M)`：轮到某人、从第 `i` 堆开始、当前 `M` 时，**当前行动者**能拿到的最大石子数。
3. 枚举 `X` 从 1 到 `min(2*M, n-i)`，拿走 `suf[i] - suf[i+X]`，对手在 `(i+X, max(M, X))` 里拿 `dfs(i+X, max(M,X))`，自己拿剩下的 `suf[i+X] - 对手所得`。
4. 取所有 `X` 里的最大值；`i == n` 返回 0。

以 `piles = [2,7,9,4,4]` 为例，`suf = [26,24,17,8,4,0]`。`dfs(0,1)` 枚举 `X=1,2`：
- `X=1`：拿走 `26-24=2`，对手 `dfs(1,1)` 返回 14（Bob 拿 7+9 后 Alice 只能拿 4+4 中的一部分，实际 Bob 最优拿 14），Alice 得 `2 + (24-14) = 12`？——注意这里 `dfs(1,1)` 是 Bob 视角的最大值，Alice 得 `2 + 24 - 14 = 12`，但示例答案是 10，说明 Bob 在 `(1,1)` 下不会让 Alice 拿到 12，正确值是 Bob 拿 16、Alice 得 `2+24-16=10`。
- `X=2`：拿走 `26-17=9`，对手 `dfs(2,2)` 返回 8，Alice 得 `9 + 17 - 8 = 18`？——同样，`dfs(2,2)` 是 Alice 视角（轮到 Alice），此处应取 Bob 视角，实际 Bob 拿 8、Alice 得 `9+17-8=18` 不对，正确是 Bob 拿 17、Alice 得 9。

关键中间值：`dfs(0,1)` 的两个候选是 10 和 9，取 10。

```python
from functools import lru_cache
n = len(piles)
suf = [0] * (n + 1)
for i in range(n - 1, -1, -1):
    suf[i] = suf[i + 1] + piles[i]

@lru_cache(None)
def dfs(i, M):
    if i == n:
        return 0
    best = 0
    for X in range(1, min(2 * M, n - i) + 1):
        take = suf[i] - suf[i + X]
        best = max(best, take + (suf[i + X] - dfs(i + X, max(M, X))))
    return best

return dfs(0, 1)
```

## 复杂度
时间：状态数 `O(n^2)`（`i` 有 n 个、`M` 最多 n），每个状态枚举 `O(n)` 个 `X`，共 `O(n^3)`。
空间：`lru_cache` 存 `O(n^2)` 个状态，加 `suf` 的 `O(n)`。

## 易错点
1. `X` 的上界写成 `2*M` 而漏掉 `n-i` → 对 `piles=[1,2,3,4,5,100]` 在 `i=5, M=3` 时会枚举到 `X=6`，`suf[11]` 越界 → 正确写法是 `min(2*M, n-i)`。
2. 把 `dfs(i+X, max(M,X))` 的返回值当成「自己还能拿的」直接加 → 对示例 1 的 `X=1` 会算出 `2+14=16` 而非 10 → 必须用 `suf[i+X] - dfs(...)` 表示「剩余总量减去对手所得」。

## 如果面试官追问
问：n 扩大到 10^5 怎么办？
答：`O(n^3)` 不可行，需利用 `M` 增长与 `i` 的单调关系做斜率/单调队列优化，或改写成「Alice 得分 = 总和 − Bob 得分」的区间 DP 压缩状态。
