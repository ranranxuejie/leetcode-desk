## 一句话思路
线性 DP，`dp[i]` 表示偷到第 i 间为止的最大金额，转移时只多判断 `colors[i] == colors[i-1]` 这一种冲突。

## 怎么做
1. 定义 `dp[i]` 为前 i+1 间房能偷到的最大金额，`dp[0] = nums[0]`。
2. 颜色不同时，`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`，即「不偷 i」或「偷 i 且不偷 i-1」。
3. 颜色相同时，不能同时偷 i-1 和 i，所以「偷 i」只能接 `dp[i-3]`：`dp[i] = max(dp[i-1], dp[i-3] + nums[i])`。
4. 用三个滚动变量代替数组，返回最后一个值。

拿示例 3 `nums=[10,1,3,9], colors=[1,1,1,2]` 走一遍：`dp[0]=10`；`i=1` 同色，`dp[1]=max(10, 0+1)=10`；`i=2` 同色，`dp[2]=max(10, 10+3)=13`；`i=3` 异色，`dp[3]=max(13, dp[1]+9)=max(13,19)=19`？这里要小心——`dp[1]+9=19` 但正确答案是 22，说明「异色时接 `dp[i-2]`」在 i=3 时接的是 `dp[1]=10`，而 10 对应的是只偷了第 0 间，第 2 间没偷，所以 10+9=19 合法但非最优；最优是 10+3+9=22，需要「偷 i 且偷 i-1」——但 i-1=2 与 i=3 异色，可以同时偷，所以异色时应接 `dp[i-1]` 再判断？不对，`dp[i-1]` 已含 i-1，异色时 i 和 i-1 可共存，故 `dp[i] = max(dp[i-1], dp[i-1] + nums[i])` 会重复。正确转移：异色时 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` 仍成立，但 i=3 时 `dp[1]=10` 只含第 0 间，`dp[2]=13` 含第 0、2 间，`dp[2]+9=22` 才对——所以异色应接 `dp[i-1]`？`dp[2]=13` 含第 2 间，与 i=3 异色可共存，故 `dp[i]=max(dp[i-1], dp[i-1]+nums[i])` 错在重复。实际正确式：异色 `dp[i]=max(dp[i-1], dp[i-2]+nums[i])`，但 i=3 时 `dp[1]=10` 不含第 2 间，`dp[2]=13` 含第 2 间，`dp[2]+9` 重复第 2 间。所以异色应接 `dp[i-1]` 当 `colors[i]!=colors[i-1]` 时 i 与 i-1 可共存，`dp[i]=dp[i-1]+nums[i]`？那 i=1 异色时 `dp[1]=dp[0]+nums[1]` 对，但 i=3 时 `dp[2]+9=22` 对。故异色 `dp[i]=dp[i-1]+nums[i]`，同色 `dp[i]=max(dp[i-1], dp[i-2]+nums[i])`。验证示例 1：`dp[0]=1`；i=1 同色 `max(1,0+4)=4`；i=2 异色 `4+3=7`；i=3 同色 `max(7,4+5)=9` ✓。

```python
prev2, prev1 = 0, nums[0]
for i in range(1, n):
    if colors[i] == colors[i-1]:
        cur = max(prev1, prev2 + nums[i])
    else:
        cur = prev1 + nums[i]
    prev2, prev1 = prev1, cur
return prev1
```

## 复杂度
时间：O(n)，一次遍历，n 为房屋数。
空间：O(1)，只开 `prev1`、`prev2`、`cur` 三个变量。

## 易错点
1. 异色时误用 `max(dp[i-1], dp[i-2]+nums[i])` → 示例 3 得 19 而非 22 → 异色时 i 与 i-1 可共存，应直接 `dp[i-1]+nums[i]`。
2. 同色时误用 `dp[i-2]+nums[i]` 而漏掉 `max` 与 `dp[i-1]` 比较 → 示例 1 的 i=1 得 4 但若 nums[1] 很小会丢 `dp[i-1]` → 同色必须取 `max(dp[i-1], dp[i-2]+nums[i])`。
