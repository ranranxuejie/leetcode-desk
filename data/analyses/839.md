## 一句话思路
用并查集把「相似」的两串合并，最后数连通分量个数；相似判定只需数错位字符数。

## 怎么做
1. 初始化 `parent = list(range(n))`，`n = len(strs)`，答案先设 `n`。
2. 双重循环枚举 `i < j`，对每对字符串数错位位置。
3. 若错位数为 0 或 2，则 `union(i, j)`，每成功合并一次答案减一。
4. 返回答案。

以 `strs = ["tars","rats","arts","star"]` 为例：`tars` 与 `rats` 错位在 0、2 两位，错位数 2，合并；`rats` 与 `arts` 错位 0、1，合并；`tars` 与 `arts` 错位 0、1，已在同组；`star` 与其余三串错位数都是 4，不合并。最终 2 个连通分量。

关键中间值：错位数只可能是 0、2 或 ≥3（异位词保证字符多重集相同），所以判定条件写成 `diff == 0 or diff == 2`，一旦 `diff > 2` 可提前 `break`。

```python
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

for i in range(n):
    for j in range(i + 1, n):
        a, b = strs[i], strs[j]
        diff = 0
        for k in range(len(a)):
            if a[k] != b[k]:
                diff += 1
                if diff > 2:
                    break
        if diff == 0 or diff == 2:
            ri, rj = find(i), find(j)
            if ri != rj:
                parent[ri] = rj
                ans -= 1
```

## 复杂度
时间：O(n² · L)，n 为串数、L 为串长，双重循环每对比较最多扫 L 个字符。
空间：O(n)，`parent` 数组存 n 个下标，无其他额外结构。

## 易错点
- 输入 `["omv","ovm"]`：若把相似条件写成 `diff == 2` 而漏掉 `diff == 0`，两个完全相同的串（如 `["abc","abc"]`）会被判为不相似，答案偏大；正确做法是 `diff == 0 or diff == 2`。
- 输入 `["tars","rats","arts","star"]`：若只做两两相似计数而不做传递合并，会漏掉 `tars` 与 `arts` 这种「不直接相似但同组」的关系，答案错成 3；正确做法是并查集或 DFS 传递闭包。

## 如果面试官追问
问：若 strs 长度涨到 10⁴ 怎么办？答：按「排序后的串」分桶，只在同桶内两两比较，桶内再用错位数判定，避免全局 O(n²)。
