## 一句话思路
先数出复写后实际能落进数组的零的个数，再从右往左倒着写，避免覆盖未读元素。

## 怎么做
1. 正序扫一遍，用 `cnt` 记录「复写后占用的位置数」，遇到 0 就多占一格，直到 `cnt >= n` 停下，记下最后一个被处理的下标 `i`。
2. 若 `cnt` 恰好越过 `n`（即 `cnt == n + 1`），说明末尾那个 0 只能写一个，先单独把 `arr[n-1] = 0` 处理掉，`i` 减一。
3. 从 `i` 开始倒序写：非零直接搬到 `arr[j]`，零则写两次 `arr[j]` 和 `arr[j-1]`，`j` 相应减 1 或 2。

以 `arr = [1,0,2,3,0,4,5,0]`，`n = 8` 为例：正序累加时 `cnt` 依次为 1,3,4,5,7,8,9,11，在 `i = 5`（值 4）处 `cnt = 8` 首次达到 `n`，但继续看 `i = 6` 时 `cnt = 9`，说明第 7 位是 0 且被截断——实际停在 `i = 6`、`cnt = 9 = n + 1`，于是先置 `arr[7] = 0`，`i` 退到 5，`j = 6`，再倒着填。

```python
n = len(arr)
cnt = i = 0
while cnt < n:
    if arr[i] == 0:
        cnt += 1
    cnt += 1
    i += 1
i -= 1
j = n - 1
if cnt == n + 1:
    arr[j] = 0
    j -= 1
    i -= 1
while i >= 0:
    arr[j] = arr[i]
    if arr[i] == 0:
        j -= 1
        arr[j] = 0
    i -= 1
    j -= 1
```

## 复杂度
时间 O(n)：正序扫一遍加倒序写一遍，各 n 次。
空间 O(1)：只用 `cnt`、`i`、`j` 三个变量，原地改 `arr`。

## 易错点
- 输入 `[1,0,0,2,3]` 这类「零在中间且末尾被截断」的情况 → 若正序直接边扫边右移，会把还没读的 0 覆盖掉，结果错成 `[1,0,0,0,2]` → 必须先用 `cnt` 定位截断点，再倒序写。
- 输入 `[0,0,0]` 或 `[1,0]` 这类 `cnt == n + 1` 的边界 → 若忽略「末尾 0 只写一次」的分支，`j` 会越界写成 `arr[-1]` 或错位 → 先单独处理 `arr[n-1] = 0` 并把 `i`、`j` 各退一格。

## 如果面试官追问
问：若允许返回新数组、空间不限，还这么写吗？
答：不必，正序扫原数组、往新数组 append 两次零再截断到 n 即可，O(n) 时间 O(n) 空间，倒序技巧只在要求原地时才必要。
