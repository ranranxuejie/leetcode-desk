## 一句话思路
每个 nums[i] 独立，只需在它附近找最近的正回文数；因操作步长是 2，奇偶性必须一致，所以按奇偶分别二分查回文表。

## 怎么做
1. 预处理：生成 1 到 10^9 附近所有正回文数，按奇偶分成两个有序表 `odd`、`even`。
2. 对每个 x，按 `x % 2` 选表，用 `bisect_left` 找到第一个 ≥ x 的回文数 `hi`，前一个为 `lo`。
3. 代价取 `min(abs(x-lo), abs(x-hi)) // 2`，累加。
4. 以 `nums = [10,12,14,16]` 为例：10 偶表最近是 8 和 22，取 8 代价 1；12 取 8 代价 2；14 取 8 代价 3；16 取 22 代价 3，合计 9。

```python
from bisect import bisect_left

def build():
    odd, even = [], []
    for half in range(1, 100000):
        s = str(half)
        for p in (s + s[-2::-1], s + s[::-1]):
            v = int(p)
            if v <= 2 * 10**9:
                (odd if v % 2 else even).append(v)
    return sorted(set(odd)), sorted(set(even))

odd, even = build()
ans = 0
for x in nums:
    arr = odd if x % 2 else even
    j = bisect_left(arr, x)
    best = min(abs(x - arr[k]) for k in (j - 1, j) if 0 <= k < len(arr))
    ans += best // 2
```

## 复杂度
时间：生成回文表 O(10^5)，每个元素一次二分 O(log 10^5)，总 O(n log 10^5)。
空间：两张回文表共约 2×10^5 个整数，O(10^5)。

## 易错点
- 输入 `nums = [10]` → 若不分奇偶，会选到 9 或 11，代价算成 1，但 10 只能变偶数，正确最近是 8，代价 1（此处巧合相等）；换成 `nums = [12]` 就会错成 11 代价 1，正确是 8 代价 2。必须按 `x % 2` 选表。
- 输入 `nums = [1]` → 若回文表从 0 开始或允许 0，会得到 0 代价 1，但题目要求正回文整数，正确是 1 本身代价 0。生成时从 half=1 起，且 lo 越界时只取 hi。

## 如果面试官追问
问：若操作改成每次 ±1 呢？
答：去掉奇偶分组，直接在全体回文表上二分取最近即可，其余不变。
