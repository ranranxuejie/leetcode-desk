## 一句话思路
从左半段找第一个不是 `'a'` 的字符改成 `'a'`，找不到就把最后一个字符改成 `'b'`。

## 怎么做
1. 遍历 `palindrome` 的前 `n // 2` 个位置，`i` 从 0 到 `n // 2 - 1`。
2. 遇到第一个 `palindrome[i] != 'a'`，把它改成 `'a'` 后立即返回。
3. 左半段全是 `'a'` 时，把末尾字符改成 `'b'`（末尾原本必是 `'a'`，改成 `'b'` 一定破坏回文）。
4. 长度小于 2 直接返回 `""`。

以 `"abccba"` 为例，`n = 6`，左半段是下标 0~2 的 `"abc"`。`i = 0` 是 `'a'` 跳过；`i = 1` 是 `'b' != 'a'`，改成 `'a'`，得到 `"aaccba"` 并返回。注意 `i = 1` 的镜像位置 `n-1-i = 4` 仍是 `'b'`，所以结果确实不是回文。

```python
n = len(palindrome)
if n < 2:
    return ""
s = list(palindrome)
for i in range(n // 2):
    if s[i] != 'a':
        s[i] = 'a'
        return ''.join(s)
s[-1] = 'b'
return ''.join(s)
```

关键点：只需扫左半段。右半段任何改动都会被左半段镜像位置"抵消"回文性，且左半段位置更靠前，字典序收益更大。

## 复杂度
时间 O(n)：最坏扫完左半段 `n // 2` 个字符，`join` 再花 O(n)。
空间 O(n)：`list(palindrome)` 开了长度 n 的副本，返回值也是 n。

## 易错点
- 输入 `"aa"` → 左半段只有下标 0 的 `'a'`，循环不触发，若忘记兜底会返回原串（仍是回文）→ 正确做法是走 `s[-1] = 'b'` 得 `"ab"`。
- 输入 `"aba"` → 左半段下标 0 是 `'a'` 跳过，若误把中间字符 `s[1]` 也纳入扫描范围，会改成 `"aaa"` 仍是回文 → 正确做法是循环上界严格取 `n // 2`，中间字符不碰。

## 如果面试官追问
问：如果要求返回所有能得到的最小字典序结果的数量？答：左半段首个非 `'a'` 位置唯一，兜底也唯一，答案恒为 1（`n < 2` 时为 0）。
