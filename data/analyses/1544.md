## 一句话思路
用栈：新字符与栈顶互为大小写同字母就弹出栈顶，否则入栈，一遍扫完即答案。

## 怎么做
1. 建空列表 `st` 当栈，遍历 `s` 的每个字符 `c`。
2. 判断 `st` 非空且 `st[-1]` 与 `c` 是同一字母的大小写对：`st[-1].lower() == c.lower() and st[-1] != c`。
3. 成立就 `st.pop()`，否则 `st.append(c)`。
4. 最后 `"".join(st)` 返回。

以 `s = "leEeetcode"` 为例，扫到 `'E'` 时栈是 `['l','e']`，`st[-1]='e'` 与 `'E'` 同字母且大小写不同，弹出后栈回到 `['l']`；接着 `'e'` 入栈，栈变 `['l','e']`，与最终 `"leetcode"` 的前缀一致。

```python
st = []
for c in s:
    if st and st[-1].lower() == c.lower() and st[-1] != c:
        st.pop()
    else:
        st.append(c)
return "".join(st)
```

关键点：`st[-1] != c` 这个条件不能省。若只写 `lower()` 相等，遇到 `"aa"` 会把两个 `'a'` 误判成一对弹掉，而题目只删「相同字母、不同大小写」的相邻对。

## 复杂度
时间 O(n)：`s` 的每个字符进出栈各一次，n 为 `len(s)`。
空间 O(n)：最坏（如 `"abc"` 无配对）栈里存下全部 n 个字符。

## 易错点
- 输入 `"aa"` 或 `"AA"` → 若判断条件漏掉 `st[-1] != c`，会错删成 `""` → 正确做法是同时要求 `lower()` 相等且原字符不相等。
- 输入 `"abBAcC"` → 若用「从左往右找第一对相邻可删、删完重扫」的暴力模拟，容易在删除后忘记回退下标，漏掉新形成的相邻对（如删 `bB` 后 `a` 与 `A` 才相邻）→ 用栈天然处理这种「删除后新相邻」，无需回退。

## 如果面试官追问
问：若要求返回所有可能的整理结果（不保证唯一）怎么办？
答：栈只能给一种；需 DFS 枚举每步可删的相邻对，用集合去重，规模大时不可行。
