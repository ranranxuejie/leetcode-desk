## 一句话思路
不真正改矩阵，只把每次 update 的 `(row1,col1,row2,col2,newValue)` 追加进列表，getValue 时从后往前找第一个覆盖该点的记录。

## 怎么做
1. 构造函数里把 `rectangle` 存成 `self.rect`，另开空列表 `self.ops`。
2. `updateSubrectangle` 只做 `self.ops.append((row1,col1,row2,col2,newValue))`，不碰矩阵。
3. `getValue` 逆序遍历 `self.ops`，命中第一个包含 `(row,col)` 的区间就返回它的 `newValue`。
4. 全部不命中才返回 `self.rect[row][col]`，即初始值。

以示例 1 为例：两次 update 后 `ops = [(0,0,3,2,5), (3,0,3,2,10)]`。查 `getValue(3,1)` 时先看第二条，`3<=3<=3 and 0<=1<=2` 成立，直接返回 10，根本不用看第一条的 5——这就是逆序的意义。

```python
def updateSubrectangle(self, row1, col1, row2, col2, newValue):
    self.ops.append((row1, col1, row2, col2, newValue))

def getValue(self, row, col):
    for r1, c1, r2, c2, v in reversed(self.ops):
        if r1 <= row <= r2 and c1 <= col <= c2:
            return v
    return self.rect[row][col]
```

关键点：后写的覆盖先写的，所以逆序找到的第一个就是最终值，不需要比较时间戳。

## 复杂度
时间：update O(1)；getValue O(k)，k 为已发生的 update 次数，最坏 500。
空间：`ops` 存 k 个五元组，O(k)，矩阵本身 O(rows*cols) 不计入额外开销。

## 易错点
- 把 `ops` 正序遍历 → 示例 1 查 `(3,1)` 会先命中 `(0,0,3,2,5)` 返回 5，而正确答案是 10。必须 `reversed`，因为后一次 update 覆盖前一次。
- 边界判断写成 `r1 < row < r2` 用严格不等号 → 示例 1 查 `(0,2)` 时 `0 < 0` 不成立，会漏掉整行更新而错误返回初始值 1。四个比较都必须是 `<=`，因为区间端点本身也被更新。

## 如果面试官追问
若 update 次数涨到 10^5 而 getValue 也 10^5，怎么办？答：改成二维差分或按行存区间，把 getValue 降到 O(log n)，代价是 update 变慢。
