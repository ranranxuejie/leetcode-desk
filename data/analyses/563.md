## 一句话思路
后序 DFS 一次返回子树和，同时把每个节点的 `abs(left_sum - right_sum)` 累加进全局答案。

## 怎么做
1. 定义 `dfs(node)` 返回以 `node` 为根的子树节点值之和，空节点返回 0。
2. 先递归取 `left_sum = dfs(node.left)`、`right_sum = dfs(node.right)`，再累加 `ans += abs(left_sum - right_sum)`。
3. 返回 `left_sum + right_sum + node.val` 给父节点用。
4. 主函数返回 `dfs(root)` 过程中累积的 `ans`（用 `nonlocal` 或列表存）。

以示例 2 的根节点 4 为例：左子树返回 `3+5+2=10`，右子树返回 `9+7=16`，此时 `ans += abs(10-16) = 6`，返回 `10+16+4=30` 给上层。注意 6 是在**访问 4 时**才加进去的，子节点 2、9 的坡度 2 和 7 在更早的递归里已经加过。

```python
def dfs(node):
    if node is None:
        return 0
    left_sum = dfs(node.left)
    right_sum = dfs(node.right)
    ans[0] += abs(left_sum - right_sum)
    return left_sum + right_sum + node.val

ans = [0]
dfs(root)
return ans[0]
```

关键点：坡度用的是**子树节点值之和**，不是子树节点个数，也不是子树坡度之和。示例 2 里节点 4 的左右和是 10 和 16，若误用节点数会得到 `|3-3|=0`。

## 复杂度
时间 O(n)：每个节点恰好被 `dfs` 访问一次，`abs` 和加法都是 O(1)。
空间 O(h)：递归栈深度等于树高 h，最坏链状树 O(n)，平衡树 O(log n)，无额外数组。

## 易错点
- 空树输入 `root = []` → 若直接访问 `root.left` 会抛 `AttributeError` → 正确做法是 `dfs` 开头判 `node is None` 返回 0，主函数对空树返回 0。
- 把坡度写成「左右子树坡度之差」→ 示例 2 节点 4 会算成 `|2-7|=5` 而非 6 → 正确做法是累加 `abs(left_sum - right_sum)`，其中 `left_sum` 是子树**值之和**（10），不是子树坡度（2）。

## 如果面试官追问
问：节点值含负数时还成立吗？
答：成立，`abs(left_sum - right_sum)` 对负数同样取绝对值，只是子树和可能为负，逻辑不变。
