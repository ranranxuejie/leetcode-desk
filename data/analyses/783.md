## 一句话思路
中序遍历 BST 得到升序序列，最小差值必出现在相邻两元素之间，边遍历边比较即可。

## 怎么做
1. 用迭代中序（显式栈）或递归中序，维护 `prev` 记录上一个访问的节点值。
2. 每访问一个节点，若 `prev is not None`，用 `node.val - prev` 更新 `best`。
3. 更新 `prev = node.val`，继续遍历。

以 `root = [4,2,6,1,3]` 为例：中序访问顺序是 `1,2,3,4,6`。访问到 `2` 时 `prev=1`，`best=min(inf, 2-1)=1`；访问到 `3` 时 `prev=2`，`3-2=1` 不更小；访问到 `4` 时 `prev=3`，差 1；访问到 `6` 时 `prev=4`，差 2。最终 `best=1`。

```python
best = float('inf')
prev = None
stack, cur = [], root
while stack or cur:
    while cur:
        stack.append(cur)
        cur = cur.left
    cur = stack.pop()
    if prev is not None:
        best = min(best, cur.val - prev)
    prev = cur.val
    cur = cur.right
```

关键点：`prev` 存的是**值**不是节点，因为比较的是 `cur.val - prev`；`best` 初值用 `float('inf')`，节点数 ≥2 保证至少更新一次。

## 复杂度
时间 O(n)：每个节点入栈出栈各一次，n 为节点数。
空间 O(h)：栈深度等于树高 h，最坏链状 O(n)，平衡时 O(log n)。

## 易错点
- 输入 `[1,0,48,null,null,12,49]` → 若只比较父子节点（如 `48-12=36`、`12-1=11`）会错成 11 或 36 → 正确做法是中序相邻比较，真实答案是 `1-0=1`。
- 输入 `[2,1,3]` → 若把 `best` 初值设为 0 或忘记 `prev is not None` 判断，第一个节点 `1` 会拿 `1 - None` 报错或拿 `1-0=1` 误判 → 正确做法是 `prev` 初值 `None`，首节点只赋值不比较。

## 如果面试官追问
问：若树不是 BST 而是普通二叉树怎么办？
答：中序失效，需先收集所有值排序后取相邻差，时间 O(n log n)；或对每个节点求与其余节点的最小差，O(n²)。
