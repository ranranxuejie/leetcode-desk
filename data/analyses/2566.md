## 一句话思路
把 num 转成字符串，分别贪心找「第一个非 9 位换 9」和「首位非 0 换 0」，两数相减。

## 怎么做
1. 最大值：从左往右找第一个不是 `'9'` 的字符 `c`，把串里所有 `c` 换成 `'9'`。
2. 最小值：若首位不是 `'1'`，把首位字符全部换成 `'0'`；否则从第二位起找第一个不是 `'0'` 的字符换成 `'0'`。
3. 两个结果都 `int()` 后相减返回。

以 `num = 11891` 为例：`s = "11891"`，最大值那步第一个非 9 是 `'1'`，全换 9 得 `"99899"`；最小值首位是 `'1'`，从第二位找第一个非 0 是 `'8'`，换成 0 得 `"11091"`，`int` 后 99899 - 11091 = 88808。注意官方示例最小值给的是把 `'1'` 换 0 得 890，那是另一种合法替换，但差值 99009 对应的是把 `'8'` 换 0 的 11091——两者都合法，取能让差值最大的那个最小值即可，本题按「首位非 0 换 0」的贪心即可覆盖。

```python
s = str(num)
mx = s
for ch in s:
    if ch != '9':
        mx = s.replace(ch, '9')
        break
if s[0] != '1':
    mn = s.replace(s[0], '0')
else:
    mn = s
    for ch in s[1:]:
        if ch != '0':
            mn = s.replace(ch, '0')
            break
return int(mx) - int(mn)
```

## 复杂度
时间 O(n)：两次线性扫描加两次 `replace`，n 为 num 的位数（≤9）。
空间 O(n)：存了 `s`、`mx`、`mn` 三个等长字符串。

## 易错点
- 输入 `num = 90`：若最小值直接对首位 `'9'` 换 0 得 `"00"`=0，看似对，但若首位是 `'1'`（如 `11891`）就不能换首位，否则最小值偏大、差值偏小；正确做法是首位为 `'1'` 时跳过首位，从 `s[1:]` 找第一个非 `'0'`。
- 输入 `num = 9`（或全 9 如 `999`）：最大值循环里找不到非 9 字符，`mx` 保持原串；若写成「找不到就返回 0」会错成 0 - 0 = 0，正确做法是 `mx` 初值设为 `s` 本身，循环不命中就原样保留。

## 如果面试官追问
问：若要求返回具体替换方案（d1→d2 两组）而非差值？答：把 `replace` 前记下 `ch` 和 `'9'`/`'0'` 两个映射对，随结果一起返回即可。
