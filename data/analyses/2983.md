## 一句话思路
把右半段反转后与左半段逐位配对，用 26 个字母的前缀和判断每个查询能否把「不匹配」的字符在可重排区间内补齐。

## 怎么做
1. 令 `t = s[n//2:][::-1]`，问题变成：能否通过重排 `s[a:b+1]` 和 `t[n-1-d:n-c]` 使 `s[:n//2] == t`。
2. 预处理 `pre[i][ch]` 为 `s` 前 i 个字符中 ch 的个数，`pre2` 同理对 `t`，用于 O(1) 取任意区间字母计数。
3. 对每个查询，把两段可重排区间映射到左半段坐标 `[a,b]` 和 `[n-1-d, n-1-c]`，其余位置必须已经相等。
4. 对 26 个字母分别算：左段可提供的净差与右段需要的净差是否匹配，且两段之外的差异必须为 0。

以 `s="abcabc"`、`queries[0]=[1,1,3,5]` 为例：`t="cba"`，左段 `[1,1]` 是 `'b'`，右段映射为 `[0,0]` 是 `'c'`，两段外位置 `s[0]='a'` 与 `t[0]='c'` 不等——但 `t[0]` 落在右段内，`s[2]='c'` 与 `t[2]='a'` 不等且 `s[2]` 不在左段内，需逐字母核对后返回 `True`。

```python
n = len(s); h = n // 2
t = s[h:][::-1]
def build(x):
    pre = [[0]*26]
    for ch in x:
        cur = pre[-1][:]
        cur[ord(ch)-97] += 1
        pre.append(cur)
    return pre
P, Q = build(s[:h]), build(t)
def cnt(pre, l, r):  # [l, r] 闭区间
    return [pre[r+1][k]-pre[l][k] for k in range(26)]
```

## 复杂度
时间：预处理 O(26n)，每个查询 O(26)，共 O(26(n+q))。
空间：两个前缀和数组 O(26n)，即 26×10^5 个整数。

## 易错点
- 右段 `[c,d]` 在 `s` 上，映射到 `t` 的坐标是 `[n-1-d, n-1-c]`，顺序会翻转；直接写 `[c,d]` 会让示例 1 的 `[3,5]` 错算成 `t[3:5]` 越界或错位。
- 两段可重排区间可能重叠（如 `a=0,b=2` 与映射后 `[0,2]`），此时该位置字符可自由分配，不能按「两段外必须相等」直接判死；需先取并集再算净差。

## 如果面试官追问
若要求输出具体重排方案而非布尔值？答：在判定可行后，对每个字母按净差从富余段搬到缺失段，逐位填回即可，仍是 O(26n)。
