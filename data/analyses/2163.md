## 一句话思路
枚举分割点 i，用前后缀各维护 n 个元素的最优和，取 `left[i] - right[i]` 最小值。

## 怎么做
1. 设 `n = len(nums) // 3`，分割点 `i` 表示前 `i` 个元素里选 n 个作第一部分、后 `3n-i` 个里选 n 个作第二部分，`i` 的范围是 `[n, 2n]`。
2. 从左往右扫，用大顶堆维护前 `i` 个元素中最小的 n 个，`left[i]` 记录它们的和；堆超过 n 就弹出最大值。
3. 从右往左扫，用小顶堆（存负数）维护后 `3n-i` 个元素中最大的 n 个，`right[i]` 记录它们的和。
4. 答案 = `min(left[i] - right[i])`，`i` 取 `n..2n`。

以 `nums = [7,9,5,8,1,3]`，`n = 2` 为例：`i = 3` 时，前 3 个 `[7,9,5]` 取最小 2 个得 `left[3] = 12`；后 3 个 `[8,1,3]` 取最大 2 个得 `right[3] = 11`，差为 1，正是答案。

```python
import heapq
n = len(nums) // 3
m = len(nums)
left = [0] * (m + 1)
h = []
s = 0
for i in range(m):
    heapq.heappush(h, -nums[i]); s += nums[i]
    if len(h) > n:
        s += heapq.heappop(h)   # 弹出的是负数，等价于减去最大值
    left[i + 1] = s
right = [0] * (m + 1)
h = []; s = 0
for i in range(m - 1, -1, -1):
    heapq.heappush(h, nums[i]); s += nums[i]
    if len(h) > n:
        s -= heapq.heappop(h)
    right[i] = s
ans = min(left[i] - right[i] for i in range(n, 2 * n + 1))
```

## 复杂度
时间：每个元素进出堆各一次，O(n log n)，log 来自堆大小 n。
空间：`left`/`right` 各 O(n)，堆 O(n)，共 O(n)。

## 易错点
- 分割点范围写成 `0..m` → `left[i]` 或 `right[i]` 会取不满 n 个元素，和偏小导致答案错 → 必须限定 `i ∈ [n, 2n]`，保证两侧各有至少 n 个元素可选。
- 左扫用大顶堆时直接 `heappop` 正数堆 → 弹出的是最小值而非最大值，`left[i]` 偏大 → Python 只有小顶堆，存 `-nums[i]`，弹出后 `s += 弹出的负数` 才是减去最大值。

## 如果面试官追问
要求输出具体删除方案怎么办？答：在 `left`/`right` 计算时额外记录每个分割点选中的下标集合，取到最优 `i` 后合并两侧集合，剩余下标即被删除的元素。
