## 一句话思路
用 `dp[i][len]` 记「以 i 结尾、末段长 len」的方案数，靠前缀和把枚举前段长度的 O(n) 压成 O(1)。

## 怎么做
1. 定义 `dp[i][L]`：`num[0:i]` 的划分中，最后一段是 `num[i-L:i]` 且合法的方案数；末段首位 `num[i-L]` 为 `'0'` 时直接为 0。
2. 前一段长度 `k` 满足 `k < L` 时必然 `num[i-L-k:i-L] < num[i-L:i]`（短者小），用 `pre[i-L][L-1]` 一次取完。
3. `k == L` 时需逐位比较 `num[i-2L:i-L]` 与 `num[i-L:i]`，用 `lcp` 表 O(1) 判定，成立则加 `dp[i-L][L]`。
4. 答案 = `pre[n][n]`，即所有以 n 结尾的末段方案之和。

以 `num = "327"` 为例：`dp[1][1]=1`（"3"）；`dp[2][1]` 末段 "7" 前段 "2" 不满足非递减，0；`dp[2][2]=1`（"27" 整体）；`dp[3][1]` 末段 "7" 前段 "32" 不成立；`dp[3][2]` 末段 "27" 前段 "3" 成立，得 1；`dp[3][3]=1`。合计 2。

```python
MOD = 10**9 + 7
n = len(num)
if num[0] == '0': return 0
dp = [[0]*(n+1) for _ in range(n+1)]
pre = [[0]*(n+1) for _ in range(n+1)]
for i in range(1, n+1):
    for L in range(1, i+1):
        if num[i-L] == '0': continue
        if L == i: dp[i][L] = 1
        else:
            dp[i][L] = pre[i-L][min(L-1, i-L)]
            if i >= 2*L and num[i-2*L:i-L] <= num[i-L:i]:
                dp[i][L] = (dp[i][L] + dp[i-L][L]) % MOD
        pre[i][L] = (pre[i][L-1] + dp[i][L]) % MOD
return pre[n][n]
```

## 复杂度
时间 O(n²)：i 与 L 两层各到 n，字符串比较用切片是 O(L)，严格说 O(n³)，需 lcp 表才降到 O(n²)。
空间 O(n²)：dp 与 pre 两张 (n+1)² 表，n=3500 时约 2×1225 万格。

## 易错点
- `num = "094"` 或 `"0"` → 若只判末段首位非零，会漏掉首段以 `'0'` 开头的情况，错答非 0；正确做法是开头 `num[0]=='0'` 直接返回 0，因为任何划分的第一段都从下标 0 起。
- `num = "9999999999999"`（13 个 9）→ 若 `k == L` 时不做逐位比较、一律认为前段更小，会把 "99|99" 这类等长但前段更大的组合算进去，答案偏大；正确做法是等长时比较 `num[i-2L:i-L] <= num[i-L:i]`，等号要取（非递减允许相等），本例正确答案 101。

## 如果面试官追问
问：n 提到 10⁵ 怎么办？
答：O(n²) 表存不下，改用滚动数组 + 后缀和，并预处理 lcp 表把等长比较降到 O(1)，时间仍 O(n²) 但空间 O(n)。
