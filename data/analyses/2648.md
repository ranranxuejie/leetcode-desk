## 一句话思路
用两个变量 `a, b` 滚动保存相邻两项，每次 `yield a` 后更新 `a, b = b, a + b`，天然对应递推式。

## 怎么做
1. 初始化 `a, b = 0, 1`，分别代表当前项和下一项。
2. 循环里先 `yield a`，把当前项交出去。
3. 再执行 `a, b = b, a + b`，让窗口右移一格。
4. 用 `itertools.islice` 或手动 `next()` 取 `callCount` 个值收集成列表。

以 `callCount = 5` 为例，关键中间值：第 1 次 `yield` 时 `a=0`，更新后 `a=1, b=1`；第 2 次 `yield` 时 `a=1`，更新后 `a=1, b=2`；第 3 次 `yield` 时 `a=1`，更新后 `a=2, b=3`；第 4 次 `yield` 时 `a=2`，更新后 `a=3, b=5`；第 5 次 `yield` 时 `a=3`。收集结果正好是 `[0,1,1,2,3]`。

```python
def fib():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b

def take(callCount):
    g = fib()
    return [next(g) for _ in range(callCount)]
```

`callCount = 0` 时 `range(0)` 为空，列表推导不执行，直接返回 `[]`，不会触发任何 `yield`，与示例 2 一致。

## 复杂度
时间：O(callCount)，每次 `next` 只做一次加法和一次元组赋值。
空间：O(callCount) 用于存结果列表，生成器本身只占 O(1) 两个变量。

## 易错点
- `callCount = 0` → 若写成 `while True` 里先 `yield` 再判断，或手动 `next()` 前没检查次数，会多取一个值返回 `[0]` → 正确做法是用 `range(callCount)` 控制次数，0 次自然不取。
- 初始值写成 `a, b = 1, 1` → 输出变成 `[1,1,2,3,5]`，首项错成 1 且整体后移 → 必须 `a, b = 0, 1`，让第一次 `yield` 出 0。

## 如果面试官追问
问：`callCount` 放大到 10**6 且要求边生成边处理、不存全量怎么办？
答：保留生成器，用 `for x in islice(fib(), callCount)` 流式消费，空间仍是 O(1)。
