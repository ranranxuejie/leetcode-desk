## 一句话思路
用有序集合存所有「0 天」的下标，每次湖泊 x 再次下雨时，二分找它上次下雨之后最早的 0 天来抽干 x。

## 怎么做
1. 预处理每个位置 i 的「下一次同湖下雨」`nxt[i]`，用哈希表从右往左扫一遍即可。
2. 维护一个最小堆 `heap`，存 `(nxt[i], lake)`：表示湖泊 lake 在 nxt[i] 天会再次下雨，必须在那之前抽干。
3. 遇到 `rains[i] == 0`：若堆非空，弹出堆顶 `(t, lake)`，令 `ans[i] = lake`（抽干最紧急的）；否则 `ans[i] = 1`（抽空湖，无事发生）。
4. 遇到 `rains[i] = x > 0`：若堆顶的 `t == i`，说明 x 没被及时抽干 → 返回 `[]`；否则把 `(nxt[i], x)` 入堆。

以 `rains = [1,2,0,0,2,1]` 为例：i=0 入堆 `(4,1)`，i=1 入堆 `(4,2)`；i=2 弹堆顶 `(4,1)` 或 `(4,2)`，假设弹 `(4,2)` → `ans[2]=2`；i=3 弹 `(4,1)` → `ans[3]=1`；i=4 时堆顶 `t=4` 对应湖泊 2，但 2 已被抽干，需先判断——正确做法是弹出时校验该湖是否仍满，或改用「按 nxt 排序的 0 天集合 + 二分」。

```python
import heapq
n = len(rains)
nxt = [n] * n
last = {}
for i in range(n - 1, -1, -1):
    x = rains[i]
    if x > 0:
        nxt[i] = last.get(x, n)
        last[x] = i
ans, heap = [-1] * n, []
for i, x in enumerate(rains):
    if x == 0:
        ans[i] = heapq.heappop(heap)[1] if heap else 1
    else:
        if heap and heap[0][0] == i:
            return []
        heapq.heappush(heap, (nxt[i], x))
```

## 复杂度
时间 O(n log n)：n 次堆操作各 O(log n)，预处理 O(n)。
空间 O(n)：`nxt` 数组、`last` 哈希表、`heap` 各占 O(n)。

## 易错点
- `rains = [1,2,0,1,2]`：i=2 只有一个 0 天，但湖泊 1、2 都要在 i=3、4 再下雨 → 堆里两个待抽干湖泊，0 天不够，必须返回 `[]`。若只检查「堆顶 t == i」而不检查堆大小，会漏判。
- `rains = [0,1,0,2]`：i=0 时堆为空，`ans[0]` 必须填一个合法湖泊编号（如 1），不能填 -1 或 0；题目要求 0 天必须抽干某湖，填 0 会被判非法。

## 如果面试官追问
问：若要求返回字典序最小的 ans 怎么办？
答：0 天改为从「已满且不再下雨」的湖泊里选最小编号，其余仍按 nxt 贪心。
