## 一句话思路
用栈暂存待加的项，遇 `*` `/` 立刻与栈顶结算，最后求和；因为乘除优先级高于加减。

## 怎么做
1. 预处理：在 `s` 末尾补一个 `'+'`，让最后一个数字也能被统一处理。
2. 扫描时维护 `num`（当前数字）、`op`（上一个运算符，初值 `'+'`），遇空格跳过。
3. 遇运算符时按 `op` 决定 `num` 入栈方式：`+` 入 `num`，`-` 入 `-num`，`*` `/` 则弹出栈顶与 `num` 结算后压回。
4. 扫描结束返回 `sum(stack)`。

以 `"3+2*2"` 为例：读到第二个 `*` 时 `num=2`、`op='+'`，栈为 `[3, 2]`；继续读到末尾补的 `'+'` 时 `num=2`、`op='*'`，弹出栈顶 `2` 算出 `2*2=4` 压回，栈变 `[3, 4]`，求和得 `7`。

```python
stack, num, op = [], 0, '+'
for ch in s + '+':
    if ch.isdigit():
        num = num * 10 + int(ch)
    elif ch != ' ':
        if op == '+': stack.append(num)
        elif op == '-': stack.append(-num)
        elif op == '*': stack.append(stack.pop() * num)
        else: stack.append(int(stack.pop() / num))
        op, num = ch, 0
return sum(stack)
```

## 复杂度
时间 O(n)：`s` 每个字符扫一次，栈的 push/pop 均摊 O(1)。
空间 O(n)：最坏全为加减时栈存 n/2 个数。

## 易错点
- 输入 `"3/2"` 或 `"14-3/2"` → 用 `//` 会得 `-2`（向下取整），错成 `14-3//2=13`；正确做法是 `int(a / b)` 向零截断，得 `14-1=13` 才对，注意负数场景如 `"-3/2"` 应得 `-1` 而非 `-2`。
- 输入 `" 3+5 / 2 "` → 忘记跳过空格，`ch.isdigit()` 对空格为 `False` 却进了 `elif ch != ' '` 分支外的逻辑，或把空格当运算符重置 `num`；正确做法是显式 `elif ch != ' '` 过滤，且末尾补 `'+'` 保证 `num=2` 被结算，结果 `3+2=5`。

## 如果面试官追问
若加入括号 `"2*(3+4)"` 怎么办？答：遇 `(` 递归调用 `calculate` 或再开一个栈，遇 `)` 返回当前和，其余逻辑不变。
