## 一句话思路
用前序遍历（根-左-右）序列化，空节点写成 `#`，反序列化时按同一顺序消费 token 递归重建，前序加空标记能唯一确定树形。

## 怎么做
1. 序列化：前序遍历，节点值转字符串，空节点写 `#`，用 `,` 拼接。
2. 反序列化：把字符串按 `,` 切成 `tokens`，用下标 `i` 从左往右消费。
3. 遇到 `#` 返回 `None`，否则建当前节点，再递归建左、右子树。

以 `root = [1,2,3,null,null,4,5]` 为例，序列化得到 `"1,2,#,#,3,4,#,#,5,#,#"`；反序列化时 `tokens[0]="1"` 建根，`i` 移到 1 建左子树 `2`，接着两个 `#` 让 `2` 的左右都为空，`i` 到 4 时 `tokens[4]="3"` 成为根的右孩子。

```python
def serialize(root):
    out = []
    def dfs(node):
        if not node:
            out.append("#"); return
        out.append(str(node.val))
        dfs(node.left); dfs(node.right)
    dfs(root)
    return ",".join(out)

def deserialize(data):
    tokens = data.split(",")
    i = 0
    def build():
        nonlocal i
        if tokens[i] == "#":
            i += 1; return None
        node = TreeNode(int(tokens[i])); i += 1
        node.left = build(); node.right = build()
        return node
    return build()
```

## 复杂度
时间：序列化和反序列化各访问每个节点一次，O(n)，n 为节点数。
空间：递归栈最坏 O(n)（链状树），`out`/`tokens` 各 O(n)。

## 易错点
- 空树 `root = []` → 若序列化直接返回 `""`，反序列化 `"".split(",")` 得到 `[""]`，`tokens[0]` 不是 `#` 会 `int("")` 报错 → 正确做法是空树也输出 `"#"`，或反序列化前判 `if not data: return None`。
- 节点值为负数如 `-1000` → 若用单字符分隔或按位解析会切错 → 必须用 `,` 分隔并整体 `int(token)`，`#` 与负数不会混淆。

## 如果面试官追问
问：节点数到 10^4 链状树递归会爆栈吗？答：Python 默认递归深度约 1000，链状 10^4 会 `RecursionError`，改用显式栈迭代前序即可。
