## 一句话思路
自底向上递归：先处理子节点再判断当前值，因为空数组 `[]` 和空对象 `{}` 是 truthy，必须靠子层结果决定去留。

## 怎么做
1. 写 `dfs(v)`：`v` 是 dict 就返回 `{k: dfs(x) for k, x in v.items() if dfs(x) is not None}` 的过滤版，是 list 就返回过滤后的列表，标量原样返回。
2. 关键：递归结果用 `None` 当「该删」的哨兵，而不是 `False`——因为 `0`、`""` 本身是假值但也是合法标量，用 `False` 会混淆。
3. 用示例 3 走一遍：`[0]` 递归后 `dfs(0)` 返回 `None`，列表过滤成 `[]`；`[]` 是 truthy，所以 `[0]` 这个位置保留为 `[]`，最终 `[5, [], [16]]`。
4. 顶层若返回 `None`（如输入 `0`），按题意返回 `{}` 或 `[]` 的空壳，但提示保证长度 ≥2，实际不会触发。

```python
def dfs(v):
    if isinstance(v, dict):
        out = {}
        for k, x in v.items():
            r = dfs(x)
            if r is not None:
                out[k] = r
        return out
    if isinstance(v, list):
        return [r for x in v if (r := dfs(x)) is not None]
    return None if not v else v
```

注意 `not v` 对 `0`、`""`、`False`、`None` 都为真，正好是题目定义的假值集合；而 `[]`、`{}` 走的是前两个分支，不落到这里。

## 复杂度
时间 O(n)：n 是 JSON 里所有键值对与数组元素的总数，每个节点访问一次。
空间 O(d)：d 是最大嵌套深度（递归栈），输出对象本身不计入额外空间。

## 易错点
- 输入 `[null, 0, 5, [0], [false, 16]]` → 若在列表层直接 `if x` 过滤，`[0]` 和 `[false, 16]` 是 truthy 会被整个保留，得到 `[5, [0], [false, 16]]`；正确做法是先递归子层，`[0]` 变 `[]`、`[false, 16]` 变 `[16]`，再判断子层结果是否为 `None`。
- 输入 `{"a": null, "b": [false, 1]}` → 若用 `False` 当删除哨兵，`dfs(0)` 返回 `False` 与「删除」无法区分，`{"c": 0}` 会被误删；正确做法是哨兵统一用 `None`，标量假值只在父层被丢弃、自身返回值仍是原值。

## 如果面试官追问
问：若要求原地修改、不新建对象？答：对 dict 边遍历边 `del` 需先 `list(d.items())` 快照键，list 则用双指针原地压缩后 `del lst[k:]`，空间降到 O(d)。
