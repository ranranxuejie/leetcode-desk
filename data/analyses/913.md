## 一句话思路
用状态 `(mouse, cat, turn)` 做反向拓扑排序，从已知胜负的终局倒推出每个状态的结果，剩下的未定状态即平局。

## 怎么做
1. 状态定义为 `(m, c, t)`，`t=0` 表示轮到老鼠走、`t=1` 表示轮到猫走；初始状态是 `(1, 2, 0)`。
2. 先把所有终局入队：`m == 0` 记老鼠胜（结果 1），`m == c` 记猫胜（结果 2），并记录每个状态的出度 `deg[m][c][t]`（老鼠走时是 `len(graph[m])`，猫走时是 `len(graph[c])` 但要排除通往 0 的边）。
3. 反向 BFS：弹出状态 `(m, c, t)` 时，枚举它的前驱——若 `t=0`，前驱是猫刚走完，即 `(m, c_prev, 1)`，`c_prev` 取 `graph[c]` 中非 0 的点；若 `t=1`，前驱是老鼠刚走完，即 `(m_prev, c, 0)`，`m_prev` 取 `graph[m]`。
4. 前驱若已定则跳过；若当前状态是猫胜（2），前驱轮到猫走时猫能选到它，前驱直接判 2；若当前是老鼠胜（1），前驱轮到老鼠走时同理判 1；否则前驱出度减一，减到 0 时判为「对手必胜」的结果。

以示例 2 `graph = [[1,3],[0],[3],[0,2]]` 为例：`(0,2,0)` 老鼠已进洞，结果 1 入队；它的前驱 `(1,2,1)`（老鼠在 1、猫在 2、轮到猫走）出度只有 `graph[2]=[3]` 一条，减到 0 后判为 1，说明猫无论怎么走都拦不住，最终 `(1,2,0)` 得 1。

```python
from collections import deque
# res[m][c][t]: 0 未知, 1 鼠胜, 2 猫胜
q = deque()
for m in range(n):
    for c in range(n):
        if m == 0: res[m][c][0] = res[m][c][1] = 1; q.append((m, c, 0)); q.append((m, c, 1))
        elif m == c: res[m][c][0] = res[m][c][1] = 2; q.append((m, c, 0)); q.append((m, c, 1))
while q:
    m, c, t = q.popleft()
    if t == 0:  # 前驱是猫走
        for pc in graph[c]:
            if pc == 0 or res[m][pc][1]: continue
            if res[m][c][t] == 2: res[m][pc][1] = 2; q.append((m, pc, 1))
            else:
                deg[m][pc][1] -= 1
                if deg[m][pc][1] == 0: res[m][pc][1] = 1; q.append((m, pc, 1))
    else:       # 前驱是老鼠走
        for pm in graph[m]:
            if res[pm][c][0]: continue
            if res[m][c][t] == 1: res[pm][c][0] = 1; q.append((pm, c, 0))
            else:
                deg[pm][c][0] -= 1
                if deg[pm][c][0] == 0: res[pm][c][0] = 2; q.append((pm, c, 0))
```

## 复杂度
时间：`O(n^2 * (n + E))`，状态数 `2n^2`，每个状态枚举一次前驱边。
空间：`O(n^2)` 存 `res` 和 `deg`，队列最多 `2n^2` 个状态。

## 易错点
- 猫的合法边要排除节点 0：若把 `graph[c]` 原样当出度，示例 1 中猫在节点 2 时会把通往 0 的边算进去，`deg` 偏大导致该状态永远减不到 0，被误判成平局。
- 前驱判胜负的方向别写反：当前状态是 2（猫胜）时，只有「轮到猫走」的前驱能直接继承 2；若错写成轮到老鼠走的前驱也继承 2，示例 2 的 `(1,2,0)` 会被判成 2 而不是 1。
