## 一句话思路
一次遍历，用 `cur` 记当前连续 1 的长度、`best` 记历史最大值，遇 0 就把 `cur` 清零。

## 怎么做
1. 初始化 `cur = 0`、`best = 0`，两者都从 0 起，因为数组至少有一个元素但可能全是 0。
2. 遍历 `nums`，遇到 1 就 `cur += 1`，遇到 0 就 `cur = 0`。
3. 每次更新 `cur` 后立刻 `best = max(best, cur)`，这样结尾那段连续 1 不会被漏掉。

拿示例 1 `nums = [1,1,0,1,1,1]` 走一遍关键位置：处理到下标 1 时 `cur = 2`、`best = 2`；下标 2 是 0，`cur` 被清成 0，`best` 仍是 2；下标 3、4、5 连续三个 1 使 `cur` 依次变成 1、2、3，最后 `best = 3`。注意 `best` 的更新必须放在清零之后也执行，否则 `[1,1,0,1,1,1]` 里最后那段 3 个 1 就只在循环末尾被算到一次，容易写漏。

```python
cur = best = 0
for x in nums:
    if x == 1:
        cur += 1
        if cur > best:
            best = cur
    else:
        cur = 0
return best
```

也可以写成 `cur = cur + 1 if x == 1 else 0` 再统一 `best = max(best, cur)`，行数更少，但把「清零」和「取最大」压在一行里，调试时不好打断点。两种写法在 `nums = [0]` 上都返回 0，这是必须覆盖的边界。

## 复杂度
时间 O(n)：`n = len(nums)`，每个元素只被读一次，循环体内是常数次比较和赋值。
空间 O(1)：只开了 `cur`、`best` 两个整数，没有额外数组或栈。

## 易错点
- 输入 `nums = [1,1,1]`（结尾就是最长段）→ 若把 `best = max(best, cur)` 只写在 `else` 分支里，循环结束 `best` 还是 0，返回 0 → 正确做法是每轮都更新 `best`，或在 `return` 前补一次 `best = max(best, cur)`。
- 输入 `nums = [0,0,0]` → 若把 `best` 初始化为 `-1` 或 `nums[0]`，前者返回 -1、后者在 `[0,1]` 上返回 0 却漏掉后面的 1 → 正确做法是 `best = 0` 起，因为答案下界就是 0。

## 如果面试官追问
问：如果允许把最多 k 个 0 翻成 1，怎么求最长全 1 子数组？
答：改成滑动窗口，`left` 只在窗口内 0 的个数超过 k 时右移，窗口长度最大值即答案，仍是 O(n)。
