## 一句话思路
从下标 0 开始按位置回溯，每个空位优先试最大的未用数字，第一个填满的序列就是字典序最大解。

## 怎么做
1. 序列长度固定为 `2*n-1`，用 `res = [0]*(2*n-1)` 和 `used = [False]*(n+1)` 记录占用状态。
2. 每层递归找最左边的空位 `i`，从 `n` 往下枚举 `v`，先试大数保证字典序。
3. 放 `v` 需满足：`v==1` 只占 `i`；`v>1` 要求 `i+v < len(res)` 且 `res[i+v]==0`，两个位置一起占。
4. 递归失败就回滚两个位置和 `used[v]`，继续试下一个 `v`。

以 `n=5` 为例，`res` 长 9。`i=0` 先试 `v=5`，检查 `res[5]==0` 成立，写入 `res[0]=res[5]=5`；接着 `i=1` 试 `v=4` 时 `res[5]` 已被占，失败回滚，改试 `v=3`，写入 `res[1]=res[4]=3`——这正是示例 `[5,3,1,4,3,5,2,4,2]` 的前两步。

```python
def dfs(i):
    if i == len(res):
        return True
    if res[i]:
        return dfs(i + 1)
    for v in range(n, 0, -1):
        if used[v]:
            continue
        j = i if v == 1 else i + v
        if j < len(res) and res[j] == 0:
            res[i] = res[j] = v
            used[v] = True
            if dfs(i + 1):
                return True
            res[i] = res[j] = 0
            used[v] = False
    return False
```

关键剪枝：`v>1` 时先判 `j < len(res)`，否则 `res[j]` 越界；`res[i]` 非零直接跳过，避免重复枚举。

## 复杂度
时间：最坏 O(n!)，每层最多试 n 个值，剪枝后远小于此。
空间：O(n)，`res` 长 `2n-1`，`used` 长 `n+1`，递归深度 `2n-1`。

## 易错点
1. `n=1` 时 `len(res)=1`，若循环里先算 `j=i+v` 再判边界，`v=1` 会访问 `res[1]` 越界；正确做法是 `v==1` 单独走 `j=i` 分支，不进 `i+v` 计算。
2. `n=20` 时若从 `v=1` 往上试，第一个可行解是字典序最小的，返回 `[1,2,...]` 而非最大；必须 `range(n,0,-1)` 降序枚举，且找到即 `return True` 不再回溯。

## 如果面试官追问
问：`n` 放大到 100 还能这样回溯吗？
答：不能，阶乘级搜索会超时，需要改用构造法或约束传播，本题 `n≤20` 正是为回溯留的空间。
