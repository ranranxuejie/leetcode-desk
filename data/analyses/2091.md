## 一句话思路
只有三种删法：全从前面、全从后面、两头各删一段，取三者最小。

## 怎么做
1. 用 `nums.index(min(nums))` 和 `nums.index(max(nums))` 拿到两个下标，记为 `lo`、`hi`，再令 `lo, hi = min(lo, hi), max(lo, hi)`，让 `lo` 始终是靠前的那个。
2. 三种策略的代价分别是：`hi + 1`（从前面删到 `hi`，两个元素都被扫掉）、`n - lo`（从后面删到 `lo`）、`lo + 1 + (n - hi)`（前面删掉 `lo` 及之前，后面删掉 `hi` 及之后）。
3. 返回三者最小值。

以示例 1 的 `nums = [2,10,7,5,4,1,8,6]` 为例：最小值 1 在 `nums[5]`，最大值 10 在 `nums[1]`，排序后 `lo=1, hi=5, n=8`。三种代价为 `5+1=6`、`8-1=7`、`1+1+(8-5)=5`，取 5，与答案一致。

```python
n = len(nums)
i, j = nums.index(min(nums)), nums.index(max(nums))
lo, hi = min(i, j), max(i, j)
return min(hi + 1, n - lo, lo + 1 + n - hi)
```

关键点：`lo + 1 + n - hi` 里 `lo + 1` 是删掉下标 0..lo 的个数，`n - hi` 是删掉下标 hi..n-1 的个数，两段不重叠，因为 `lo < hi` 时中间那段 `lo+1..hi-1` 可以保留。

## 复杂度
时间：O(n)，`min`/`max`/`index` 各扫一遍数组，共常数次线性扫描。
空间：O(1)，只开了 `i, j, lo, hi` 四个整数。

## 易错点
- 输入 `nums = [101]`（单元素）→ 若先算 `lo+1+n-hi` 会得到 `1+1+0=2`，错成 2 → 必须先排序 `lo, hi` 再取 `min`，此时 `lo=hi=0`，三项为 `1, 1, 1`，正确输出 1。
- 输入 `nums = [0,-4,19,1,8,-2,-3,5]` → 若忘记 `lo, hi = min(i,j), max(i,j)`，当最小值下标大于最大值下标（如 `i=1, j=2` 时恰好没触发，但换成 `[5,1,9]` 就会）→ 公式里 `n - hi` 会算成负数，必须先把两个下标排序。

## 如果面试官追问
问：如果要求输出具体删除方案（删哪几次、从哪头删）？
答：记录三种策略中胜出的那个分支，按 `lo+1` 次前删、`n-hi` 次后删的顺序输出即可。
