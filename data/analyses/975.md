## 一句话思路
从右往左预处理每个位置奇/偶跳的落点，再用 DP 逆推能否到末尾，因为落点索引恒大于当前索引。

## 怎么做
1. 用单调栈求 `odd_next[i]`：把下标按 `(arr[i], i)` 升序排序，维护一个单调递减栈，栈顶就是右侧第一个 `arr >= arr[i]` 的最小值位置。
2. 同理按 `(arr[i], -i)` 排序求 `even_next[i]`，栈顶是右侧第一个 `arr <= arr[i]` 的最大值位置。
3. 逆序 DP：`odd_ok[i] = odd_ok[odd_next[i]]`，`even_ok[i] = even_ok[even_next[i]]`，末尾两状态都为 `True`。
4. 答案 = `odd_ok` 中 `True` 的个数（起点必是奇数跳）。

以 `[2,3,1,1,4]` 为例：`odd_next[0] = 1`（右侧 ≥2 的最小值是 3），`even_next[1] = 2`（右侧 ≤3 的最大值 1，取最小索引 2），`odd_next[2] = 3`，`odd_next[3] = 4`。逆推得 `odd_ok[3]=True`、`odd_ok[2]=odd_ok[3]=True`、`odd_ok[1]=even_ok[2]=False`、`odd_ok[0]=odd_ok[1]=False`，共 3 个。

```python
n = len(arr)
odd_ok = [False] * n
even_ok = [False] * n
odd_ok[-1] = even_ok[-1] = True
for i in range(n - 2, -1, -1):
    j = odd_next[i]
    if j != -1:
        odd_ok[i] = even_ok[j]
    j = even_next[i]
    if j != -1:
        even_ok[i] = odd_ok[j]
return sum(odd_ok)
```

## 复杂度
时间：排序 O(n log n)，单调栈与 DP 各 O(n)。
空间：两个 next 数组、两个 ok 数组、栈，共 O(n)。

## 易错点
- 排序键写成 `(arr[i], i)` 求偶数跳 → 相同值时会选到较大索引，如 `[2,3,1,1,4]` 中 `even_next[1]` 会错成 3 而非 2 → 偶数跳必须用 `(arr[i], -i)` 让相同值中最小索引先入栈。
- 逆推时把 `odd_ok[i]` 写成 `odd_ok[odd_next[i]]` → 奇偶交替被破坏，`[2,3,1,1,4]` 会算出 4 而非 3 → 奇数跳后接偶数状态，必须交叉引用 `even_ok[j]`。

## 如果面试官追问
若要求输出一条具体跳跃路径怎么办？答：从起点按 `odd_next`/`even_next` 交替走，每步记录索引，直到末尾或落点为空。
