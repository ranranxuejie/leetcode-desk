## 一句话思路
贪心模拟：能换就立刻换，因为 numExchange 只增不减，早换成本更低。

## 怎么做
1. 先把初始满瓶全喝掉，`drunk = numBottles`，`empty = numBottles`。
2. 循环判断 `empty >= numExchange`，成立就用 `empty -= numExchange` 换一瓶，`numExchange += 1`。
3. 换到的满瓶立刻喝掉：`drunk += 1`，`empty += 1`。
4. 循环退出时 `empty < numExchange`，返回 `drunk`。

以 `numBottles = 13, numExchange = 6` 为例：喝完 13 瓶后 `empty = 13`。第一轮 `13 >= 6`，换 1 瓶，`empty = 7`，`numExchange = 7`，喝掉后 `empty = 8`。第二轮 `8 >= 7`，换 1 瓶，`empty = 1`，`numExchange = 8`，喝掉后 `empty = 2`。此时 `2 < 8` 退出，`drunk = 15`。

```python
drunk = numBottles
empty = numBottles
while empty >= numExchange:
    empty -= numExchange
    numExchange += 1
    drunk += 1
    empty += 1
return drunk
```

关键点：换来的满瓶必须马上喝，否则 `empty` 少算 1，第二轮判断会提前失败。

## 复杂度
时间：O(n)，n 是最终喝到的瓶数，每轮 `drunk` 加 1，循环次数不超过答案。
空间：O(1)，只开了 `drunk`、`empty` 两个整型变量。

## 易错点
1. 输入 `numBottles = 10, numExchange = 3` → 若把「换到的满瓶」攒着不喝，`empty` 停在 7 就以为还能再换，实际第二轮 `numExchange` 已变 4，会多算或死循环 → 正确做法是每换一瓶立刻 `empty += 1` 并计入 `drunk`。
2. 输入 `numBottles = 1, numExchange = 1` → 若循环条件写成 `empty > numExchange`，第一轮就跳过，返回 1，漏掉换瓶 → 正确做法是用 `>=`，因为 `empty == numExchange` 恰好能换。

## 如果面试官追问
问：numBottles 放大到 10^9 还能模拟吗？
答：不能逐瓶模拟，但每轮 numExchange 递增，循环次数约 O(√n)，10^9 量级仍可接受；若要 O(1) 需解二次不等式求换瓶轮数。
