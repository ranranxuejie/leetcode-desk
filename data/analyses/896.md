## 一句话思路
用两个布尔标记 `inc`、`dec` 扫一遍相邻对，任一方向被打破就置 `False`，最后看是否至少剩一个方向成立。

## 怎么做
1. 初始化 `inc = dec = True`，分别表示「目前还没发现递减」和「目前还没发现递增」。
2. 遍历 `i` 从 1 到 `len(nums)-1`，只看相邻的 `nums[i-1]` 与 `nums[i]`。
3. 若 `nums[i-1] > nums[i]`，说明出现下降，令 `inc = False`；若 `nums[i-1] < nums[i]`，说明出现上升，令 `dec = False`。
4. 返回 `inc or dec`。

以 `nums = [1,3,2]` 为例：`i=1` 时 `1 < 3`，`dec` 被置 `False`；`i=2` 时 `3 > 2`，`inc` 被置 `False`。两个标记都塌了，返回 `False`。而 `[1,2,2,3]` 中相等对 `2,2` 既不触发 `>` 也不触发 `<`，两个标记都不动，`inc` 始终为 `True`。

```python
inc = dec = True
for i in range(1, len(nums)):
    if nums[i - 1] > nums[i]:
        inc = False
    elif nums[i - 1] < nums[i]:
        dec = False
return inc or dec
```

关键点：相等元素必须「两个方向都不算违反」，所以用 `>` 和 `<` 而不是 `>=`、`<=`。

## 复杂度
时间：O(n)，一次遍历，每个相邻对只比较一次。
空间：O(1)，只开了 `inc`、`dec` 两个布尔量，没有额外数组。

## 易错点
- 输入 `[1,2,2,3]` → 若把相等判成违反递增（写成 `nums[i-1] >= nums[i]` 就置 `inc=False`），会在 `2,2` 处误判为 `False` → 正确做法是相等时两个标记都不动，只让严格 `>` 打掉 `inc`、严格 `<` 打掉 `dec`。
- 输入 `[1,1,1]` 或长度 1 的 `[5]` → 若先假设「一定存在上升或下降」再去找，会找不到方向而返回错值 → 正确做法是初始两个标记都为 `True`，全相等时 `inc` 和 `dec` 都保持 `True`，自然返回 `True`。

## 如果面试官追问
问：如果要求返回具体是递增还是递减（或都不是）？
答：把返回值从 `inc or dec` 换成 `"inc" if inc else ("dec" if dec else "none")`，全相等时按题意归入任一方向即可。
