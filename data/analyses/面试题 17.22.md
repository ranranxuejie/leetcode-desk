## 一句话思路
用 BFS 从 `beginWord` 逐层扩展，记录每个词的父节点，找到 `endWord` 后沿父指针回溯出路径。

## 怎么做
1. 先把 `wordList` 转成 `set` 便于 O(1) 判断，若 `endWord` 不在其中直接返回 `[]`。
2. BFS 队列存词，`parent` 字典记录 `{子词: 父词}`，`beginWord` 的父设为 `None`。
3. 每出队一个词，枚举每个位置替换 26 个字母，命中 `wordSet` 且未访问的就入队并记父。
4. 首次弹出 `endWord` 即停止，从 `endWord` 沿 `parent` 回溯到 `beginWord` 再反转。

以示例 1 为例：`hit` 出队后枚举得 `hot`，记 `parent["hot"]="hit"`；`hot` 出队得 `dot`、`lot`，记 `parent["dot"]="hot"`、`parent["lot"]="hot"`；继续到 `cog` 时 `parent["cog"]="log"`，回溯得 `hit→hot→lot→log→cog`（示例给的是另一条合法路径，两者都对）。

```python
from collections import deque
wordSet = set(wordList)
if endWord not in wordSet:
    return []
parent = {beginWord: None}
q = deque([beginWord])
while q:
    w = q.popleft()
    if w == endWord:
        break
    for i in range(len(w)):
        for c in "abcdefghijklmnopqrstuvwxyz":
            nxt = w[:i] + c + w[i+1:]
            if nxt in wordSet and nxt not in parent:
                parent[nxt] = w
                q.append(nxt)
if endWord not in parent:
    return []
path, cur = [], endWord
while cur is not None:
    path.append(cur)
    cur = parent[cur]
return path[::-1]
```

## 复杂度
时间：O(N·L·26)，N 为字典词数、L 为词长，每个词枚举 L 个位置各试 26 个字母。
空间：O(N·L)，`parent` 存 N 个词、队列最多 N 个词，每词长 L。

## 易错点
- `endWord` 不在 `wordList`（如示例 2 的 `"cog"`）→ 若只判断 `beginWord` 可达性会白跑一遍 BFS 才返回空 → 入口先 `if endWord not in wordSet: return []`。
- `beginWord` 本身可能就在 `wordList` 里 → 若初始化时把 `beginWord` 也放进 `wordSet` 并允许被再次访问，会形成自环或重复入队 → 用 `parent` 做访问标记，`beginWord` 预先占位，`nxt not in parent` 才入队。

## 如果面试官追问
问：要返回**所有**最短转换序列怎么办？
答：BFS 时不提前 break，改用 `dist` 记录层号，只对 `dist[nxt] == dist[w]+1` 的边建反向图，再从 `endWord` DFS 回溯所有路径。
