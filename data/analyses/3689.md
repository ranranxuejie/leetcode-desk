## 一句话思路
全局最大值减全局最小值就是单个子数组能拿到的上限，且这个上限可以被 k 个子数组同时取到，所以答案就是 `k * (max(nums) - min(nums))`。

## 怎么做
1. 先确认上界：任意子数组的值 ≤ `max(nums) - min(nums)`，因为它的 max 不超过全局 max、min 不小于全局 min。
2. 再确认可达：取 `i = nums.index(max(nums))`、`j = nums.index(min(nums))`，则 `nums[min(i,j)..max(i,j)]` 同时包含两者，值恰好等于上界。
3. 该子数组可被重复选 k 次（题面允许相同 l、r 重复选），于是总值 = k × 上界。
4. 用示例 2 验证：`nums = [4,2,5,1]`，`max = 5`（下标 2）、`min = 1`（下标 3），区间 `nums[2..3] = [5,1]` 值 = 4，k = 3 得 12，与输出一致。

```python
def maxTotalValue(nums, k):
    lo = min(nums)
    hi = max(nums)
    return k * (hi - lo)
```

关键中间值：示例 2 里 `hi - lo = 5 - 1 = 4`，乘 `k = 3` 得 `12`；注意 `k` 最大 1e5、`hi - lo` 最大 1e9，乘积到 1e14，Python 整数天然支持，无需特殊处理。

## 复杂度
时间：O(n)，一次遍历求 min 和 max，n 是 `len(nums)`。
空间：O(1)，只存 `lo`、`hi` 两个变量，没有额外数组。

## 易错点
- `nums` 全相同（如 `[7,7,7]`、k = 5）→ 若误以为「必须找不同元素」会去凑别的区间，甚至返回负数或报错 → 正确做法是直接返回 `k * 0 = 0`，因为 `hi - lo = 0`，公式自动成立。
- `k` 很大而 `hi - lo` 也很大（如 `nums = [0, 10**9]`、k = 1e5）→ 若按 32 位截断或误用取模会得到错误值 → 题目要求返回 `long`，Python 直接返回 `10**14` 即可，不要做任何截断。

## 如果面试官追问
问：如果要求 k 个子数组互不相同（l、r 不能重复）怎么办？
答：上界不再总能取满 k 次，需要按区间长度/端点枚举候选，退化为排序后取前 k 大，复杂度升到 O(n log n)。
