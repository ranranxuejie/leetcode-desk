## 一句话思路
答案 = 三条两两路径权值和的一半，用 LCA 求树上距离即可 O(log n) 回答每次查询。

## 怎么做
1. 预处理：以 0 为根 DFS，记录 `depth`、`dist`（到根的距离）和倍增表 `up[k][v]`。
2. 对查询 `(a, b, d)`，设 `x = dist(a,b)`、`y = dist(a,d)`、`z = dist(b,d)`。
3. 答案是 `(x + y + z) // 2`，因为最小子树就是三条路径的并，每条边被计两次。

以示例 1 的 `[2,3,4]` 为例：`dist(2,3)=3+5=8`，`dist(2,4)=3+4=7`，`dist(3,4)=5+4=9`，`(8+7+9)//2 = 12`，与输出一致。

```python
def lca(u, v):
    if depth[u] < depth[v]: u, v = v, u
    for k in range(LOG):
        if (depth[u] - depth[v]) >> k & 1:
            u = up[k][u]
    if u == v: return u
    for k in range(LOG - 1, -1, -1):
        if up[k][u] != up[k][v]:
            u, v = up[k][u], up[k][v]
    return up[0][u]

def dist(u, v):
    return dist_root[u] + dist_root[v] - 2 * dist_root[lca(u, v)]
```

## 复杂度
时间：预处理 O(n log n)，每次查询 3 次 LCA 共 O(log n)，总 O((n + q) log n)。
空间：`up` 表 O(n log n)，`depth`/`dist_root` 各 O(n)。

## 易错点
- 忘记 `// 2`：`[2,3,4]` 直接返回 `8+7+9=24` 而非 12，三条路径的并集每条边被算两次，必须整除 2。
- 倍增表 `LOG` 取 `n.bit_length()` 而非固定 17：n 可达 10^5，`LOG=17` 时 `2**17=131072` 够用但边界易错，用 `n.bit_length()` 更稳；另外 `depth` 差跳表要从高位到低位或按位判断，顺序反了会跳错。

## 如果面试官追问
问：若要求输出具体子树边集怎么办？
答：取三条路径的并，DFS 标记路径上的边，去重后输出即可，复杂度不变。
