## 一句话思路
把每台机器的「盈余」看成前缀和，答案就是所有前缀和绝对值与单点盈余的最大值——因为衣服只能相邻传递，前缀和就是必须跨过这条边界的件数。

## 怎么做
1. 先判 `sum(machines) % n != 0`，不整除直接返回 `-1`。
2. 令 `avg = sum(machines) // n`，从左往右累加 `machines[i] - avg` 得到前缀和 `prefix`。
3. 答案取 `max(ans, abs(prefix), machines[i] - avg)`：`abs(prefix)` 是这条边界必须过的件数，`machines[i] - avg` 是单台机器一次只能送一件的下限。
4. 遍历完返回 `ans`。

以 `[1,0,5]` 为例，`avg = 2`。`i=0`：`prefix = -1`，`machines[0]-avg = -1`，`ans = 1`；`i=1`：`prefix = -2`，`machines[1]-avg = -2`，`ans = 2`；`i=2`：`prefix = 1`，`machines[2]-avg = 3`，`ans = 3`。中间值 `prefix` 在 `i=1` 时到 `-2`，说明前两台共缺 2 件，必须从右边过 2 件；而第 3 台盈余 3，一次只能送 1 件，所以下限是 3，最终答案 3。

```python
total = sum(machines)
n = len(machines)
if total % n:
    return -1
avg = total // n
ans = prefix = 0
for x in machines:
    diff = x - avg
    prefix += diff
    ans = max(ans, abs(prefix), diff)
return ans
```

## 复杂度
时间：O(n)，一次遍历，`n` 是机器台数。
空间：O(1)，只开了 `avg`、`ans`、`prefix` 三个变量。

## 易错点
1. 输入 `[0,0,0]` 或 `[3,3,3]` → 若把 `ans` 初值设成 `-1` 或漏掉 `diff` 项，会返回 0 或负数 → 正确做法是 `ans` 初值 0，且 `max` 里必须同时含 `abs(prefix)` 和 `diff`，全相等时两者都是 0，返回 0。
2. 输入 `[0,2,0]` → 若只判 `total % n` 就以为能均分（`2 % 3 = 2` 其实不整除，这里没问题），但换成 `[0,3,0]` 时 `total=3, n=3` 整除，`avg=1`，`prefix` 依次 `-1, 1, 0`，`diff` 依次 `-1, 2, -1`，`ans=2` 正确；真正的坑是 `[0,0,6]` 这类，`diff=4` 但 `abs(prefix)` 只有 2，漏掉 `diff` 会错答 2 而非 4。

## 如果面试官追问
问：如果要求输出具体操作序列而非步数？答：按前缀和从两端向中间贪心配对，每步选 `prefix` 符号相反的两台相邻机器各送一件，步数不变但需记录每步的 `m` 台机器下标。
