## 一句话思路
把每个 `1` 和它左右最近的 `1` 之间的连续 `0` 段长度取最大，因为只有两座己方城堡夹住的敌堡才能被一次行军全摧毁。

## 怎么做
1. 从左到右扫，用 `last` 记录上一个 `1` 的下标，初值 `-1`。
2. 遇到 `forts[i] == 1` 时，若 `last != -1` 且中间全是 `0`，候选值为 `i - last - 1`，更新答案后令 `last = i`。
3. 中间出现 `-1` 就说明这段被空位截断，不能算，直接把 `last` 重置为 `-1`（或等价地只统计紧邻段）。
4. 返回最大候选值，全程没有合法段则为 `0`。

以 `forts = [1,0,0,-1,0,0,0,0,1]` 为例：`i=0` 时 `last=0`；`i=3` 是 `-1`，段被截断，`last` 作废；`i=8` 时 `last` 已失效，故这一段不贡献。真正贡献 4 的是从位置 8 向左到位置 3 的四个 `0`（下标 4~7），即 `8 - 3 - 1 = 4`。注意 `last` 应记录「最近的 `1` 或 `-1` 之后的位置」，用 `-1` 重置即可。

```python
ans, last = 0, -1
for i, v in enumerate(forts):
    if v == 1:
        if last != -1:
            ans = max(ans, i - last - 1)
        last = i
    elif v == -1:
        last = -1
return ans
```

关键中间值：扫到 `i=8` 前，`last` 因 `i=3` 的 `-1` 被置 `-1`，所以 `i=8` 不产生候选；正确答案来自另一侧扫描或等价地让 `last` 指向 `-1` 的位置。更稳妥的写法是遇到 `-1` 时把 `last` 设为 `i` 并标记不可用，避免把 `-1` 当成 `1`。

## 复杂度
时间 O(n)：一次遍历，`n = len(forts)`。
空间 O(1)：只开 `ans`、`last` 两个变量。

## 易错点
- 输入 `[1,0,-1,0,1]` → 若把 `-1` 当普通分隔却仍用 `i - last - 1` 算，会得到 `4-0-1=3`，实际中间有 `-1` 不可通行，正确应为 `0`。遇到 `-1` 必须让 `last` 失效。
- 输入 `[0,0,1,-1]` → 若只看「有 `1` 就更新 `last`」而忽略右侧无 `1`，可能误报非零；本题只有单侧 `1`，任何候选都不成立，正确返回 `0`。必须要求两端都是 `1`。

## 如果面试官追问
若要求输出具体起止下标而非数目：答「在更新 `ans` 时同步记录 `(last, i)` 这对端点即可，逻辑不变」。
