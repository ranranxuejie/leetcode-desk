## 一句话思路
把所有数先化成「奇数形态」再统一乘 2 抬到同一量级，然后用大根堆每次把最大值折半，边折边记录极差。

## 怎么做
1. 每个 `nums[i]` 反复除以 2 直到变成奇数，再乘 2，得到该元素的**最大可达值**（再乘就超了，再除就变小）。
2. 全部入大根堆（Python 用负数），同时记录当前最小值 `lo`。
3. 循环：弹出堆顶 `hi`，用 `hi - lo` 更新答案；若 `hi` 是奇数则退出（奇数不能再除 2，已是该元素下限）。
4. 否则把 `hi // 2` 压回堆，并更新 `lo = min(lo, hi // 2)`。

以 `nums = [4,1,5,20,3]` 为例：化形后为 `[4,2,10,20,6]`，`lo = 2`，堆顶 `hi = 20`，`20 - 2 = 18`；`20 // 2 = 10` 回堆，`lo` 仍为 2；下一轮 `hi = 10`，`10 - 2 = 8`，`10 // 2 = 5` 回堆，`lo` 仍为 2；再下一轮 `hi = 6`，`6 - 2 = 4`，`6 // 2 = 3` 回堆，`lo` 仍为 2；再下一轮 `hi = 5`，`5 - 2 = 3`，`5` 是奇数退出。答案 3。

```python
import heapq
def minimumDeviation(nums):
    heap = []
    lo = float('inf')
    for x in nums:
        if x % 2 == 1:
            x *= 2
        lo = min(lo, x)
        heapq.heappush(heap, -x)
    ans = float('inf')
    while True:
        hi = -heapq.heappop(heap)
        ans = min(ans, hi - lo)
        if hi % 2 == 1:
            break
        hi //= 2
        lo = min(lo, hi)
        heapq.heappush(heap, -hi)
    return ans
```

## 复杂度
时间：每个元素最多折半 `log(max(nums))` 次，每次堆操作 `log n`，共 `O(n log n log M)`，`M = 10^9`。
空间：堆存 `n` 个元素，`O(n)`。

## 易错点
- 输入 `[1]` 类全奇数时，若忘记先乘 2 直接入堆，`lo` 会取到 1 而堆顶也是 1，循环立刻退出得 0，但正确做法是先统一抬到最大形态再折半，保证枚举覆盖所有可达值。
- 输入 `[2,10,8]` 时，若只把偶数除到奇数就停（得 `[1,5,1]`），会漏掉「奇数乘 2」这条上升路径，正确答案 3 来自 `[2,10,8]→[2,10,4]→[2,5,4]` 这类混合形态，必须允许奇数保持原样参与比较。

## 如果面试官追问
问：要求输出具体方案而非仅最小值怎么办？
答：堆里存 `(值, 原下标)`，记录每次折半后的值，最后按下标回填即可。
