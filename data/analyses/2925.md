## 一句话思路
对每个节点做 DFS，返回「保留该节点值时的最小代价」与「全取子树时的总分」，二者取小决定是否清零该节点。

## 怎么做
1. 把 edges 建成邻接表，从 0 出发 DFS，用 parent 参数防止回头。
2. 对节点 u，先递归所有子节点，累加 `sub_total = values[u] + sum(子节点全取分)`。
3. 若 u 是叶子，返回 `(values[u], values[u])`；否则返回 `(min(values[u], sum(子节点保留代价)), sub_total)`。
4. 根节点返回的 `sub_total - 保留代价` 即答案（总分减去必须保留的那部分）。

以示例 1 为例：节点 5 是叶子，返回 `(1,1)`；节点 4 只有子 5，`sub_total=1+1=2`，保留代价 `min(1,1)=1`，返回 `(1,2)`；节点 2 子为 4，`sub_total=5+2=7`，保留代价 `min(5,1)=1`，返回 `(1,7)`。根 0 的 `sub_total=5+2+5+2+1+1=16`，保留代价 `min(5, 2+2+1)=5`，答案 `16-5=11`。

```python
def dfs(u, p):
    total = values[u]
    keep = 0
    is_leaf = True
    for v in adj[u]:
        if v == p: continue
        is_leaf = False
        k, t = dfs(v, u)
        keep += k
        total += t
    if is_leaf:
        return values[u], values[u]
    return min(values[u], keep), total
```

## 复杂度
时间 O(n)：每个节点被 DFS 访问一次，邻接表遍历 2(n-1) 条边。
空间 O(n)：邻接表存 2(n-1) 个整数，递归栈最深 n 层。

## 易错点
- 输入是链状树（如 0-1-2-…-n-1）时，递归深度达 2*10^4，Python 默认递归上限 1000 会 RecursionError；正确做法是 `sys.setrecursionlimit(300000)` 或改迭代栈。
- 把「保留代价」误写成 `values[u]` 而不与子节点代价比较：示例 2 中节点 1 的 values=10，但子节点 3、4 保留代价 7+4=11，若直接取 10 会漏掉清零节点 1 更优的情况，导致答案偏小。

## 如果面试官追问
要求输出具体清零哪些节点怎么办？
DFS 返回时记录每个节点选了「清零自己」还是「保留自己」，回溯时把清零的节点编号收集起来即可。
