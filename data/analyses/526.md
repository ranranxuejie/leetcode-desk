## 一句话思路
用位掩码 `mask` 记录已用数字、按位置 `i` 逐层回溯，每层只枚举满足整除条件的候选数。

## 怎么做
1. 定义 `dfs(i, mask)`：`i` 是当前要填的下标（从 1 开始），`mask` 的二进制第 `k-1` 位表示数字 `k` 是否已用。
2. 终止条件 `i > n` 时返回 1，表示填满一个合法排列。
3. 枚举 `v` 从 1 到 `n`，跳过 `mask >> (v-1) & 1` 为 1 的已用数，只保留 `v % i == 0 or i % v == 0` 的候选。
4. 对每个候选递归 `dfs(i+1, mask | (1 << (v-1)))` 并累加。

以 `n = 2` 为例：`dfs(1, 0)` 时 `i=1`，`v=1` 和 `v=2` 都满足 `v % 1 == 0`，分别进入 `dfs(2, 0b01)` 和 `dfs(2, 0b10)`；在 `i=2` 时，前者只剩 `v=2`（`2 % 2 == 0`），后者只剩 `v=1`（`2 % 1 == 0`），两条路径各返回 1，合计 2。

```python
def dfs(i, mask):
    if i > n:
        return 1
    total = 0
    for v in range(1, n + 1):
        if mask >> (v - 1) & 1:
            continue
        if v % i == 0 or i % v == 0:
            total += dfs(i + 1, mask | (1 << (v - 1)))
    return total
return dfs(1, 0)
```

关键剪枝在于：位置 `i` 的候选数天然很少（约数个数级别），不必先枚举全排列再校验。

## 复杂度
时间：`O(n · 2^n)`，状态数 `2^n`、每状态枚举 `n` 个候选。
空间：`O(2^n)` 递归栈深度 `n`，若加记忆化则需 `n · 2^n` 的表。

## 易错点
- `n = 15` 时若只写纯回溯不加记忆化，最坏会重复计算同一 `(i, mask)` 状态多次；正确做法是加 `@lru_cache` 或按 `mask` 递推，把状态压到 `2^n` 量级。
- 下标从 1 开始，若写成 `for i in range(n)` 从 0 起，`v % i` 会触发 `ZeroDivisionError`；正确做法是位置变量从 1 枚举到 `n`，位掩码用 `v - 1` 作偏移。

## 如果面试官追问
问：要求输出所有方案而非计数？答：把 `total` 换成路径列表，递归时携带当前 `perm`，到 `i > n` 时 `append` 副本，复杂度升到方案数级别。
