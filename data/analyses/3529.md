## 一句话思路
把网格按行优先、列优先各拉成一条长串，用滚动哈希找 pattern 的所有出现位置，再映射回格子求交集。

## 怎么做
1. 行优先展平：`flat = [grid[i][j] for i in range(m) for j in range(n)]`，长度 `m*n`；水平子串就是 `flat` 的连续窗口，起点 `s` 覆盖格子 `s, s+1, ..., s+L-1`（`L=len(pattern)`），注意窗口不能跨过 `m*n` 末尾。
2. 列优先展平：`flat2 = [grid[i][j] for j in range(n) for i in range(m)]`，垂直子串同理，起点 `s` 覆盖格子 `(s%m, s//m), ((s+1)%m, (s+1)//m), ...`。
3. 对两条串各做一次滚动哈希，把 pattern 的哈希与每个长度 `L` 窗口比对，命中就记录该窗口覆盖的格子编号（行优先编号 `i*n+j`）。
4. 两个集合取交集，返回大小。

以示例 2 为例：`m=n=4`，`L=3`，`flat` 中 `"aba"` 出现在起点 1（格子 1,2,3）和起点 9（格子 9,10,11）；`flat2` 中出现在起点 0（格子 0,4,8）和起点 8（格子 8,9,10）。交集是 `{9,10}` 加上另一处，共 4 个格子，与输出 4 一致。

```python
MOD, B = (1 << 61) - 1, 131
def hashes(seq, L):
    n = len(seq)
    pw = [1] * (n + 1)
    for i in range(n): pw[i+1] = pw[i] * B % MOD
    h = [0] * (n + 1)
    for i, c in enumerate(seq): h[i+1] = (h[i] * B + ord(c)) % MOD
    target = h[L]
    return [s for s in range(n - L + 1) if (h[s+L] - h[s]*pw[L]) % MOD == target]
```

## 复杂度
时间 O(m·n)：两次展平各 O(m·n)，哈希窗口扫描 O(m·n)，集合求交 O(m·n)。
空间 O(m·n)：两条展平串、前缀哈希数组、幂表、两个格子集合。

## 易错点
- 窗口越界：`flat` 长度是 `m*n`，若 `L > m*n` 直接返回 0；若只按 `range(n-L+1)` 扫而忘了行优先串长度是 `m*n` 而非 `n`，示例 1 中 `L=5`、`n=4` 会算出负范围漏掉全部水平匹配。
- 哈希碰撞：单模 `2**61-1` 在 `m*n=10^5` 规模下碰撞概率可忽略，但若换成 `10**9+7` 单模且 `B` 取小值（如 26），示例 2 里 `"aba"` 与某些窗口可能误判；正确做法是双模或随机化 `B`，或命中后再逐字符校验。

## 如果面试官追问
问：若要求输出所有重叠格子的坐标而非计数？答：把两个集合换成 `set` 存 `(i,j)` 元组，最后 `sorted(h & v)` 返回即可，复杂度不变。
