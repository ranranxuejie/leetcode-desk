## 一句话思路
按「右→下→左→上」四方向模拟走位，用 `-1` 初始化矩阵，边走边从链表取值，走满 `m*n` 格或链表耗尽即停。

## 怎么做
1. 建 `m x n` 全 `-1` 矩阵，方向数组 `dirs = [(0,1),(1,0),(0,-1),(-1,0)]`，起点 `(0,0)`、方向索引 `d=0`。
2. 每步先写值 `mat[r][c] = cur.val`，再让 `cur = cur.next`。
3. 预判下一步 `(nr, nc)`：越界或已被填过（值不再是 `-1`）就 `d = (d+1) % 4` 转向，否则直走。
4. 循环条件 `cur is not None`，链表走完就停，剩余格子保持 `-1`。

以示例 1（`m=3, n=5`，链表 13 个值）为例：走到 `(1,4)` 填 `1` 后，下一步 `(1,5)` 越界，`d` 从 1 转 2 改为向左；继续填 `(1,3)` 时该格已是 `-1` 之外的空位，正常写入 `-1` 位置前的 `0`，直到 `(2,1)` 填 `2` 后链表耗尽，`(1,2)(1,3)` 保持 `-1`。

```python
mat = [[-1] * n for _ in range(m)]
dirs = [(0, 1), (1, 0), (0, -1), (-1, 0)]
r = c = d = 0
cur = head
while cur:
    mat[r][c] = cur.val
    cur = cur.next
    nr, nc = r + dirs[d][0], c + dirs[d][1]
    if not (0 <= nr < m and 0 <= nc < n) or mat[nr][nc] != -1:
        d = (d + 1) % 4
        nr, nc = r + dirs[d][0], c + dirs[d][1]
    r, c = nr, nc
```

## 复杂度
时间：O(m*n)，每个格子最多访问一次，链表节点数不超过 `m*n`。
空间：O(m*n)，即输出矩阵本身，方向数组是常数。

## 易错点
- 链表长度恰好等于 `m*n`（如 `m=1,n=4` 且链表 4 个值）→ 最后一步填完 `(0,3)` 后仍去算 `nr,nc`，若此时 `cur` 已空但循环体已进入下一轮判断，可能越界访问 `mat[nr][nc]` → 正确做法是把「写值 + 移动」放在 `while cur` 内，转向判断只在 `cur` 非空时执行。
- 用「已填值是否等于 `-1`」判断是否走过 → 若链表里恰好有值 `-1`（本题 `Node.val >= 0` 不会出现，但换成允许负数就会翻车）→ 本题安全，但更稳的写法是单独维护 `visited` 或靠边界收缩；本题直接判 `mat[nr][nc] != -1` 即可。

## 如果面试官追问
若 `m*n` 达 `10^9` 但链表只有 `10^5` 个节点，怎么优化？答：不必建满矩阵，只按螺旋坐标生成前 `len` 个位置，用公式直接算坐标，空间降到 O(len)。
