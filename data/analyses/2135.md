## 一句话思路
把每个字符串压成 26 位掩码，startWords 的掩码入集合，targetWords 逐个删掉一位后查集合。

## 怎么做
1. 写 `mask(s)`：遍历字符，`m |= 1 << (ord(c) - 97)`，返回整数。
2. 把 `startWords` 全部转成掩码放进 `set`，记作 `S`。
3. 对每个 `targetWords` 的 `t`，先算 `mt = mask(t)`，再枚举 `mt` 中每个为 1 的位 `b`，检查 `mt ^ b` 是否在 `S` 里，命中即计数并 `break`。
4. 关键中间值：示例 1 中 `"act"` → `mt = 0b10101`（位 0、2、18），`"tack"` → `0b1000000000010101`；`"tack"` 去掉位 10（'k'）得 `0b10101`，正好在 `S` 里，计数 +1。

```python
def mask(s):
    m = 0
    for c in s:
        m |= 1 << (ord(c) - 97)
    return m

S = {mask(w) for w in startWords}
ans = 0
for t in targetWords:
    mt = mask(t)
    b = mt
    while b:
        low = b & -b
        if (mt ^ low) in S:
            ans += 1
            break
        b ^= low
```

`b & -b` 取最低位的 1，`b ^= low` 消掉它，循环次数等于 `t` 的长度（≤26）。

## 复杂度
时间：O(Σ|startWords| + Σ|targetWords| × 26)，26 是每个 target 最多枚举的位数。
空间：O(|startWords|) 个整数存集合，每个整数 ≤ 2**26。

## 易错点
- 输入 `startWords = ["act"]`、`targetWords = ["act"]` → 若直接查 `mask("act") in S` 会错判为可得到 → 必须强制删掉一位再查，长度相同的一律不匹配。
- 输入 `targetWords = ["a"]` 这类长度为 1 的串 → 删位后 `mt ^ low == 0`，若 `S` 里恰好有 `mask("")`（本题不会出现，但若手写初始化 `S = {0}`）会误计 → 保证 `S` 只由 `startWords` 构造，不预置 0。

## 如果面试官追问
问：若允许追加任意多个字母（不限于一个）怎么改？
答：改成判断 `mt` 是否为某个 `s in S` 的超集，即 `mt & s == s`，用子集枚举或按位分组加速。
