## 一句话思路
从左往右找第一对相邻且同奇偶、且前大后小的数字，交换即得最小串；找不到就不动。

## 怎么做
1. 从左到右遍历 `i`，只看 `s[i]` 和 `s[i+1]` 这一对。
2. 判断同奇偶：`int(s[i]) % 2 == int(s[i+1]) % 2`。
3. 再判断逆序：`s[i] > s[i+1]`（字符比较即可，数字字符的字典序与数值序一致）。
4. 两个条件同时成立就交换并立即返回，遍历完没命中就原样返回。

以 `s = "45320"` 为例：`i=0` 时 `'4'` 与 `'5'` 奇偶不同，跳过；`i=1` 时 `'5'` 与 `'3'` 都是奇数且 `'5' > '3'`，交换得 `"43520"`，直接返回。注意 `i=2` 的 `'3'` 与 `'2'` 虽然 `'3' > '2'`，但一奇一偶，不能换——这正是「先判奇偶再判大小」顺序不能反的原因。

```python
def getSmallestString(s: str) -> str:
    a = list(s)
    for i in range(len(a) - 1):
        if int(a[i]) % 2 == int(a[i + 1]) % 2 and a[i] > a[i + 1]:
            a[i], a[i + 1] = a[i + 1], a[i]
            return "".join(a)
    return s
```

为什么「第一对」就是最优：交换只影响位置 `i` 和 `i+1`，前缀 `s[:i]` 不变。若在更靠后的 `j > i` 处交换，位置 `i` 仍是原来的 `s[i]`；而在 `i` 处交换能把 `s[i]` 换成更小的 `s[i+1]`，字典序在第一个不同位置就更小，必胜。所以越靠左的可行交换越优先，找到即停。

## 复杂度
时间 O(n)：最坏扫一遍 `s`，n 为字符串长度。
空间 O(n)：`list(s)` 开了长度 n 的字符数组，返回串也是 O(n)。

## 易错点
- 输入 `"45320"` 若先判 `s[i] > s[i+1]` 再判奇偶，会在 `i=2` 的 `'3' > '2'` 处误换，得到 `"45230"`，比正确答案大；必须先判 `int(a[i]) % 2 == int(a[i+1]) % 2`。
- 输入 `"001"` 或 `"12"` 这类无可行交换的串，若写成「找到最小字符再往前挪」会越界或错位；正确做法是循环结束直接 `return s`，不做任何兜底交换。

## 如果面试官追问
若允许交换任意多次相邻同奇偶数字，怎么做？答：同奇偶的数字可任意重排，把奇数位、偶数位各自排序后按原奇偶序列回填即可。
