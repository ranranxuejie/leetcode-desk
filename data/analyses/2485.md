## 一句话思路
用前缀和公式把「1..x 之和 = x..n 之和」化成 x² = n(n+1)/2，开方后验证。

## 怎么做
1. 记 `total = n*(n+1)//2`，它是 1..n 的总和。
2. 等式 `x*(x+1)//2 == total - x*(x-1)//2` 两边化简得 `x*x == total`，所以候选 `x = isqrt(total)`。
3. 用 `x*x == total` 验证候选，成立返回 `x`，否则返回 `-1`。
4. 以 `n = 8` 为例：`total = 36`，`isqrt(36) = 6`，`6*6 == 36` 成立，返回 6；若 `n = 4`，`total = 10`，`isqrt(10) = 3`，`3*3 = 9 != 10`，返回 -1。

```python
from math import isqrt

def pivotInteger(n):
    total = n * (n + 1) // 2
    x = isqrt(total)
    return x if x * x == total else -1
```

关键中间值：`n = 8` 时 `total = 36`、`x = 6`、`x*x = 36`，三者对齐才返回 6。

## 复杂度
时间：O(1)，`isqrt` 对 ≤ 500500 的整数是常数级，与 n 无关。
空间：O(1)，只开 `total`、`x` 两个整数。

## 易错点
- 用 `int(total ** 0.5)` 取候选 → `n = 8` 时浮点开方可能得 5.999…，截断成 5，`25 != 36` 误返回 -1 → 改用 `math.isqrt` 做整数开方。
- 只算 `x = isqrt(total)` 就直接返回、不做 `x*x == total` 校验 → `n = 4` 时 `total = 10`、`isqrt = 3`，会错返回 3 → 必须补平方相等判断，不等返回 -1。

## 如果面试官追问
问：n 放大到 10^18 还成立吗？
答：成立，`n*(n+1)//2` 与 `isqrt` 在 Python 大整数下都精确，仍是 O(1) 次大数运算。
