## 一句话思路
对每天的回答先 `set` 去重，再用一个哈希表累计每个回答出现的天数，最后按「次数降序、字典序升序」取第一个。

## 怎么做
1. 建 `cnt = {}`，遍历 `responses` 的每一天。
2. 每天先 `set(day)` 去重，再对去重后的每个词 `cnt[w] += 1`——这一步保证同一天重复的 `"good"` 只加一次。
3. 遍历 `cnt`，用 `max` 的键 `(cnt[w], 取反字典序)` 或手写比较选出答案。

以示例 1 为例，第 0 天 `set(["good","ok","good","ok"])` 得 `{"good","ok"}`，`cnt` 变为 `{"good":1,"ok":1}`；第 1 天去重得 `{"ok","bad","good"}`，`cnt` 变为 `{"good":2,"ok":2,"bad":1}`；四天走完 `cnt = {"good":3,"ok":2,"bad":2}`，`good` 次数最高直接胜出。

```python
cnt = {}
for day in responses:
    for w in set(day):
        cnt[w] = cnt.get(w, 0) + 1

best = None
for w, c in cnt.items():
    if best is None or c > cnt[best] or (c == cnt[best] and w < best):
        best = w
return best
```

比较条件里 `c > cnt[best]` 优先，相等时才用 `w < best`，正好对应「频率最高、同频取字典序最小」。示例 2 中 `cnt = {"good":2,"ok":2,"bad":2,"notsure":1,"great":1}`，三者同频，`bad < good < ok`，返回 `"bad"`。

## 复杂度
时间 O(N)，N 为所有 `responses[i][j]` 的总个数，`set` 去重和计数各扫一遍。
空间 O(D)，D 为不同回答的个数，哈希表存 D 个键值对。

## 易错点
- 忘记对每天去重：示例 1 第 0 天 `"good"` 出现 2 次，若直接累加 `cnt["good"]` 会变成 4 而不是 3，答案可能错成别的词。必须先 `set(day)` 再计数。
- 同频时比较方向写反：示例 2 若用 `w > best` 选字典序最大，会返回 `"ok"` 而不是 `"bad"`。相等分支必须是 `w < best`。

## 如果面试官追问
问：如果要求返回所有最高频回答而非一个？
答：把比较改成先求 `max(cnt.values())`，再收集所有 `cnt[w] == maxc` 的词并排序返回。
