## 一句话思路
枚举中间峰 j，用前缀最小值和后缀最小值 O(1) 拿到两侧最小元素，取三者之和最小。

## 怎么做
1. 预处理 `left[i] = min(nums[0..i-1])`，`left[0]` 设为无穷大。
2. 预处理 `right[i] = min(nums[i+1..n-1])`，`right[n-1]` 设为无穷大。
3. 遍历 j 从 1 到 n-2，若 `left[j] < nums[j] and right[j] < nums[j]`，更新 `ans = min(ans, left[j] + nums[j] + right[j])`。
4. 遍历结束若 `ans` 仍是无穷大则返回 -1。

以 `nums = [8,6,1,5,3]` 为例，`left = [inf,8,6,1,1]`，`right = [1,1,3,3,inf]`。j=3 时 `left[3]=1 < 5`、`right[3]=3 < 5`，候选和 `1+5+3=9`；j=2 时 `right[2]=3` 但 `nums[2]=1` 不满足峰条件，跳过。最终 9。

```python
n = len(nums)
inf = float('inf')
left = [inf] * n
for i in range(1, n):
    left[i] = min(left[i-1], nums[i-1])
right = [inf] * n
for i in range(n-2, -1, -1):
    right[i] = min(right[i+1], nums[i+1])
ans = inf
for j in range(1, n-1):
    if left[j] < nums[j] and right[j] < nums[j]:
        ans = min(ans, left[j] + nums[j] + right[j])
return -1 if ans == inf else ans
```

## 复杂度
时间 O(n)：两趟预处理加一趟枚举，各扫 n 个元素。
空间 O(n)：额外开了 `left`、`right` 两个长度 n 的数组。

## 易错点
- 输入 `[1,2,3]` 这类单调递增数组 → 若只判 `left[j] < nums[j]` 就更新答案，会把 `right[j]=inf` 加进去得到 inf 或错值 → 必须同时判 `right[j] < nums[j]`，两侧都严格小于才成立。
- 输入 `[6,5,4,3,4,5]` 这种先降后升的数组 → 若把 `left`/`right` 的边界初始化成 0 或 `nums[0]`，j=1 时 `left[1]` 会取到 6 而非 inf，误判出峰 → 边界必须用 `float('inf')`，保证不存在左侧元素时条件自然不成立。

## 如果面试官追问
若要求输出三元组下标而非和？答：在更新 `ans` 时同步记录当前的 `(i, j, k)`，其中 i 取 `left` 数组对应的最小元素下标，需额外存 `left_idx`/`right_idx` 两个数组。
