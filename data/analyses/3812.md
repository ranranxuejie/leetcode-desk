## 一句话思路
把 `start[i] != target[i]` 的节点标成"需要翻转"，问题变成在树上选最少的边覆盖这些奇点，用自底向上 DFS 贪心。

## 怎么做
1. 先算 `diff[i] = start[i] != target[i]`，若 `diff` 中 1 的个数为奇数直接返回 `[-1]`（每次操作翻转两个节点，奇偶性不变）。
2. 以 0 为根建邻接表，记录每条边下标，DFS 后序处理。
3. 对节点 u，收集所有子节点 v 回传的"未匹配需求"：若 `diff[u]` 为真，把 u 的需求向上传；否则把子节点需求两两配对，用 u 到子节点的边消掉。
4. 具体到示例 2：`diff` 在节点 4、6 为 1（`start="0011000"`，`target="0010001"`，逐位比较得 4 和 6 不同）。DFS 从 4 回传需求到 3，从 6 回传需求到 1，在 1 处与节点 2 的需求配对，选边 1、2、5。

```python
def dfs(u, p):
    need = diff[u]
    for v, idx in adj[u]:
        if v == p: continue
        if dfs(v, u):
            if need:
                res.append(idx); need = False
            else:
                need = True
    return need
```

配对逻辑：子节点回传 `True` 表示该子树有一个未消的奇点，若当前 u 已有需求就配对消掉，否则 u 承接这个需求继续向上。

## 复杂度
时间 O(n)：DFS 遍历每个节点和每条边一次，配对是常数操作。
空间 O(n)：邻接表存 2(n-1) 条边，递归栈深度最坏 n。

## 易错点
- `diff` 中 1 的个数为奇数（如示例 3：`start="00"`、`target="01"`，只有节点 1 不同）→ 会错成返回某个边序列 → 正确做法是先判奇偶，奇数直接 `[-1]`，因为每次翻转改变两个节点颜色，奇偶性守恒。
- 递归深度达到 10^5 的链状树（如 `edges=[[0,1],[1,2],...]`）→ Python 默认递归上限 1000 会 `RecursionError` → 正确做法是 `sys.setrecursionlimit(300000)` 或改写成显式栈的迭代后序。

## 如果面试官追问
问：如果要求返回字典序最小的最短序列怎么办？
答：贪心配对时优先选下标小的边，DFS 后序保证子树先消，同层按边下标升序配对即可。
