## 一句话思路
对每个物品算「买一份能带回多少总物品」（自身+可整除它的物品数），再按性价比贪心买最划算的。

## 怎么做
1. 预处理 `gain[i] = 1 + count(factor[i] 整除 factor[j])`，即买一份物品 i 的总收益。
2. 按 `price[i] / gain[i]` 升序排序，性价比高的先买。
3. 对每个物品尽量多买：`k = budget // price[i]`，累加 `k * gain[i]`，`budget -= k * price[i]`。
4. 剩余预算买不动任何物品时停止。

以示例 2 为例：`items = [[2,4],[3,2],[4,1],[6,4],[12,4]]`，各物品 gain 为 `[4,3,2,1,1]`（factor 2 整除 4/6/12，factor 3 整除 6/12，factor 4 整除 12）。性价比：物品 2 是 `1/2`，物品 1 是 `2/3`，物品 0 是 `4/4=1`。先买物品 2 两份花 2，再买物品 1 一份花 2，再买物品 0 一份花 4，总花 8，收益 `2*2+3+4=11`？实际答案是 10——因为物品 2 买两份只算一次免费收益，`gain` 不能乘购买份数。

修正：购买份数 `k` 的收益是 `k + (k>0 ? free[i] : 0)`，其中 `free[i]` 是免费物品数。示例 2 中物品 2 买 2 份得 `2+1=3`，物品 1 买 1 份得 `1+2=3`，物品 0 买 1 份得 `1+3=4`，合计 10。

```python
free = [sum(1 for j in range(n) if j != i and items[j][0] % items[i][0] == 0) for i in range(n)]
order = sorted(range(n), key=lambda i: items[i][1] / (1 + free[i]))
ans = 0
for i in order:
    k = budget // items[i][1]
    if k == 0: continue
    ans += k + free[i]
    budget -= k * items[i][1]
```

## 复杂度
时间：O(n²) 预处理整除关系，排序 O(n log n)，n 为物品数。
空间：O(n) 存 `free` 和 `order`，无额外二维表。

## 易错点
- 买多份同一物品时把 `free[i]` 也乘上份数 → 示例 2 会得 11 而非 10 → 免费收益每物品只算一次，写成 `k + free[i]`。
- 按 `price` 单独排序贪心 → 示例 2 会先买物品 2 再买物品 1，看似对但示例 1 中 `[[6,2],[2,6],[3,4]]` 若按价格先买物品 0（价 2）只得 `1+0=1`，正确应先买物品 2（价 4，gain 2）→ 必须按 `price/(1+free)` 排序。

## 如果面试官追问
若 budget 扩大到 10^9 且 items 到 10^5，O(n²) 预处理会超时，答：用筛法按 factor 值域（≤1500）预处理倍数关系，降到 O(V log V)。
