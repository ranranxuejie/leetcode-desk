## 一句话思路
用单调队列维护窗口内 `chargeTimes` 最大值，配合滑动窗口和 `runningCosts` 前缀和，右指针只进不退，一次扫描得最长窗口。

## 怎么做
1. 预处理 `runningCosts` 的前缀和 `pre`，使窗口 `[l, r]` 的运行成本和为 `pre[r+1] - pre[l]`。
2. 右指针 `r` 从 0 到 n-1 逐个入窗，同时用单调递减队列存 `chargeTimes` 的下标，队首即当前窗口最大值。
3. 每次入窗后检查 `chargeTimes[dq[0]] + (r-l+1) * (pre[r+1]-pre[l]) > budget`，超了就 `l += 1` 并弹出队首过期下标，直到满足预算。
4. 每轮用 `r-l+1` 更新答案。

以示例 1 为例，`r=2` 时窗口 `[0,2]`，`chargeTimes` 队列队首是下标 1（值 6），`pre[3]-pre[0]=6`，开销 `6 + 3*6 = 24 ≤ 25`，答案更新为 3；`r=3` 时窗口扩到 `[0,3]`，`pre[4]-pre[0]=10`，开销 `6 + 4*10 = 46 > 25`，`l` 右移收缩。

```python
from collections import deque
pre = [0] * (n + 1)
for i in range(n):
    pre[i + 1] = pre[i] + runningCosts[i]
dq = deque()
l = ans = 0
for r in range(n):
    while dq and chargeTimes[dq[-1]] <= chargeTimes[r]:
        dq.pop()
    dq.append(r)
    while dq and chargeTimes[dq[0]] + (r - l + 1) * (pre[r + 1] - pre[l]) > budget:
        if dq[0] == l:
            dq.popleft()
        l += 1
    ans = max(ans, r - l + 1)
```

## 复杂度
时间：O(n)，每个下标最多入队出队各一次，`l`、`r` 各走 n 步。
空间：O(n)，前缀和数组 `pre` 与单调队列 `dq` 各占 O(n)。

## 易错点
- 收缩窗口时忘记同步弹出队首过期下标：如示例 1 中 `l` 移到 1 后，若队列仍留着下标 0，队首最大值会算成 3 而非 6，开销偏小导致答案虚高。正确做法是 `l` 右移时判断 `dq[0] == l` 就 `popleft()`。
- 用 `while` 收缩而非 `if`：窗口可能一次超预算很多，如 `chargeTimes=[100,1,1]`、`budget=50` 时单个 100 就超，必须连续弹出直到窗口为空，`if` 只弹一次会留下非法窗口。

## 如果面试官追问
问：若要求返回具体是哪一段机器人怎么办？
答：在更新 `ans` 时同步记录 `(l, r)`，最后按区间切片输出即可，复杂度不变。
