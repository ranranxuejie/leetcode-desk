## 一句话思路
从 k 出发 DFS 求可疑集合 S，再扫一遍 invocations 看是否有 S 外的点指向 S 内，有则返回全部。

## 怎么做
1. 建邻接表 `g[a].append(b)`，从 k 做 DFS/BFS，标记 `suspect[b] = True`，得到可疑集合。
2. 扫 `invocations` 中每条 `[a, b]`：若 `not suspect[a] and suspect[b]`，说明外部方法调用了可疑方法，整组不可移除。
3. 不可移除时返回 `list(range(n))`；否则返回所有 `suspect[i] == False` 的 i。

以示例 1 为例：`n=4, k=1, invocations=[[1,2],[0,1],[3,2]]`。从 1 出发 DFS 得 `suspect = [False, True, True, False]`，S={1,2}。扫边时 `[0,1]` 满足 `suspect[0]=False and suspect[1]=True`，命中外部调用，直接返回 `[0,1,2,3]`。

```python
suspect = [False] * n
suspect[k] = True
stack = [k]
while stack:
    u = stack.pop()
    for v in g[u]:
        if not suspect[v]:
            suspect[v] = True
            stack.append(v)

for a, b in invocations:
    if not suspect[a] and suspect[b]:
        return list(range(n))
return [i for i in range(n) if not suspect[i]]
```

注意第 2 步只需检查「外部→内部」这一个方向；「内部→外部」不影响移除，因为外部方法留下后不会再被删掉的方法调用。

## 复杂度
时间 O(n + m)，m = len(invocations)，DFS 与扫边各一遍。
空间 O(n + m)，邻接表存 m 条边，suspect 与栈各 O(n)。

## 易错点
1. 只检查可疑集合内部是否自洽，漏掉外部入边。示例 1 中若只看 S={1,2} 内部，会误判可移除并返回 `[0,3]`；正确做法是扫全部 invocations 找 `not suspect[a] and suspect[b]`。
2. 把「可疑」当成「k 的直接出边」。示例 3 中 `k=2`，直接出边只有 0，但 0→1→2 形成环，间接可达使 S={0,1,2}，答案 `[]`；必须用 DFS/BFS 传递闭包，不能只取一层。

## 如果面试官追问
若 invocations 规模涨到 10^6 且要求在线多次查询不同 k？答：预处理 SCC 缩点，可疑集合即 k 所在 SCC 及其后代，用 bitset 或拓扑序前缀判断外部入边。
