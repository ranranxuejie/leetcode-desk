## 一句话思路
用 `dp[j]` 表示跳过 `j` 次休息时到达当前道路的最短耗时，逐条路推进并取最小值。

## 怎么做
1. 把时间统一乘 `speed`，用整数 `dist` 累加代替浮点除法，最后与 `hoursBefore * speed` 比较。
2. `dp[j]` 记录「走完前 i 条路、跳过 j 次休息」的最小累计「距离当量」；不跳过时向上取整到 `speed` 的倍数。
3. 对每条路 `d`，从大到小更新 `dp[j] = min(dp[j] + d, ceil(dp[j-1]/speed)*speed + d)`，避免同一轮重复用。
4. 最后找最小的 `j` 使 `dp[j] <= hoursBefore * speed`，找不到返回 `-1`。

以示例 1 `dist=[1,3,2], speed=4, hoursBefore=2` 为例：`limit=8`。处理 `1` 后 `dp=[0,1]`；处理 `3` 时，不跳过得 `ceil(1/4)*4+3=7`，跳过得 `1+3=4`，`dp=[0,4,4]`；处理 `2` 后最小可行 `j=1`，对应 `dp[1]=6<=8`。

```python
limit = hoursBefore * speed
INF = 2**31 - 1
dp = [0] + [INF] * n
for d in dist:
    for j in range(n, -1, -1):
        best = INF
        if dp[j] < INF:
            best = min(best, (dp[j] + speed - 1) // speed * speed + d)
        if j > 0 and dp[j-1] < INF:
            best = min(best, dp[j-1] + d)
        dp[j] = best
for j in range(n + 1):
    if dp[j] <= limit:
        return j
return -1
```

## 复杂度
时间：`O(n^2)`，外层 `n` 条路，内层 `n+1` 个跳过次数。
空间：`O(n)`，只开一个长度 `n+1` 的 `dp` 数组。

## 易错点
- 用浮点 `dist[i]/speed` 累加再 `ceil`，在 `dist=[1,3,2], speed=4` 这类除不尽时会因精度误差把 `1.5` 判成 `1.5000000001`，导致多算一次休息；正确做法是全程用整数距离当量，只在取整时做 `(x+speed-1)//speed*speed`。
- 内层 `j` 从小到大更新，会把本轮刚算出的 `dp[j-1]` 当成上一轮的用，等于同一条路被跳过多次；必须 `range(n, -1, -1)` 倒序，保证 `dp[j-1]` 还是处理这条路之前的值。

## 如果面试官追问
问：如果 `n` 涨到 `10^5` 怎么办？答：`O(n^2)` 会超时，可改二分答案 `k`，用贪心验证「最多跳 `k` 次能否准时」，把内层降为 `O(n)`。
