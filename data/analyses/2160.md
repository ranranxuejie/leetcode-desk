## 一句话思路
把四个数位升序排好，按奇偶下标分别拼成两个数，和最小。

## 怎么做
1. 把 `num` 拆成四个数位放进列表 `d`，`d.sort()` 升序。
2. 让 `d[0]`、`d[2]` 组成一个数，`d[1]`、`d[3]` 组成另一个数——即排序后交替取位，保证两个数的高位都尽量小。
3. 返回 `(d[0]*10+d[2]) + (d[1]*10+d[3])`。

以 `num = 2932` 为例：拆位得 `[2,9,3,2]`，排序后 `d = [2,2,3,9]`。交替取位得 `new1 = 2*10+3 = 23`，`new2 = 2*10+9 = 29`，和 `52`，与官方答案一致。若贪心地把最小的两个 `2,2` 都放到十位（`22` 和 `39`），和是 `61`，反而更大——所以必须交替分配，而不是把最小两位凑一起。

```python
d = sorted(int(c) for c in str(num))
return (d[0] * 10 + d[2]) + (d[1] * 10 + d[3])
```

为什么交替最优：两个数各占两个数位，十位权重 10、个位权重 1。总和 = 10*(两个十位数字之和) + (两个个位数字之和)。要让总和最小，就得让两个十位数字之和尽量小，即取排序后最小的两个 `d[0]`、`d[1]` 当十位；剩下 `d[2]`、`d[3]` 当个位。至于哪个十位配哪个个位，不影响总和（`10a+c + 10b+d` 与 `10a+d + 10b+c` 相等），所以 `d[0]` 配 `d[2]`、`d[1]` 配 `d[3]` 即可。

## 复杂度
时间：O(1)，固定 4 位，排序 4 个元素。
空间：O(1)，只开了长度 4 的列表 `d`。

## 易错点
- 输入 `num = 4009` → 若把两个 0 都塞进同一个数（如 `400` 和 `9`）→ 会错成 `409`；正确做法是排序得 `[0,0,4,9]`，交替取位得 `4` 和 `9`，和 `13`。前导 0 必须允许，`0*10+4` 就是 `4`。
- 输入 `num = 1122` → 若把最小两位 `1,1` 都放十位凑成 `11` 和 `22` → 得 `33`；正确做法是交替取位 `12 + 12 = 24`。判断依据是十位数字之和要最小，而不是让某个数最小。

## 如果面试官追问
问：如果 `num` 不是四位而是任意长度呢？
答：同样排序后交替分配到两个数（轮流取位），因为每位权重固定，让高位数字尽量小即可，贪心仍成立。
