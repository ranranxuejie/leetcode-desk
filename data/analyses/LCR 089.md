## 一句话思路
用两个滚动变量记录「偷到前一家」和「偷到前两家」的最优解，每步取 `max(不偷, 偷)`。

## 怎么做
1. 定义 `prev2` 为偷到 `i-2` 家的最大金额，`prev1` 为偷到 `i-1` 家的最大金额，初始都设为 0。
2. 遍历 `nums`，对每个 `x` 计算 `cur = max(prev1, prev2 + x)`：要么跳过这家沿用 `prev1`，要么偷这家加上 `prev2`。
3. 每步结束后滚动更新 `prev2, prev1 = prev1, cur`，避免开数组。
4. 遍历结束返回 `prev1`。

以 `nums = [2,7,9,3,1]` 为例，走到 `x = 9` 时 `prev2 = 2`（偷到第 1 家）、`prev1 = 7`（偷到第 2 家），`cur = max(7, 2 + 9) = 11`；再走到 `x = 1` 时 `prev2 = 7`、`prev1 = 11`，`cur = max(11, 7 + 1) = 11`，最终返回 12。

```python
prev2 = prev1 = 0
for x in nums:
    cur = max(prev1, prev2 + x)
    prev2, prev1 = prev1, cur
return prev1
```

关键点：`prev2 + x` 里的 `prev2` 必须是「偷到 `i-2` 家」的值，而不是 `i-1`，否则会把相邻两家一起偷。

## 复杂度
时间：O(n)，`nums` 每个元素遍历一次，每步 O(1) 运算。
空间：O(1)，只开了 `prev2`、`prev1`、`cur` 三个变量，没有额外数组。

## 易错点
- 输入 `nums = [2,7,9,3,1]` → 若写成 `cur = max(prev1, prev1 + x)` 或忘记滚动 `prev2`，会把相邻的 7 和 9 一起算成 16 → 正确做法是 `prev2 + x`，且每步先算 `cur` 再同时更新两个变量。
- 输入 `nums = [0]` 或 `nums = [5]` → 若循环里先更新 `prev2` 再算 `cur`，单元素时 `prev2` 被覆盖成 0，结果错成 0 → 正确做法是用 `prev2, prev1 = prev1, cur` 这种元组同时赋值，保证 `cur` 用的是旧的 `prev2`。

## 如果面试官追问
问：如果要求输出具体偷了哪几家？
答：把 `cur` 的来源（取 `prev1` 还是 `prev2 + x`）记进一个布尔数组，最后从末尾倒推回溯即可。
