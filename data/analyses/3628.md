## 一句话思路
枚举插入位置与插入字母，用前缀/后缀计数把「LCT」增量算成 O(1)，取最大。

## 怎么做
1. 先算原串的 `LCT` 子序列数：扫一遍，维护 `cntL`、`cntLC`，遇 `T` 就累加 `cntLC`。
2. 插入字母只会是 `L`、`C`、`T` 之一（其他字母不参与子序列，等价于不插），且插入位置只需考虑「某字符段之间」，用前缀 `L` 数、后缀 `T` 数即可。
3. 插 `L` 在位置 i：新增 = 该位置之后能形成的 `CT` 对数；插 `T` 在位置 i：新增 = 该位置之前能形成的 `LC` 对数；插 `C` 在位置 i：新增 = 前面 `L` 数 × 后面 `T` 数。
4. 对每个位置取三种增量的最大值，加上原串答案。

以 `s = "LCCT"` 为例：原串 `LCT` 数 = 2（两个 C 各配一个 T）。在开头插 `L`，位置 0 之后 `CT` 对数 = 2×1 = 2，总答案 2+2 = 4，与示例一致。

```python
n = len(s)
cntL = cntLC = base = 0
for ch in s:
    if ch == 'L': cntL += 1
    elif ch == 'C': cntLC += cntL
    elif ch == 'T': base += cntLC

sufT = [0] * (n + 1)          # sufT[i] = s[i:] 中 T 的个数
for i in range(n - 1, -1, -1):
    sufT[i] = sufT[i + 1] + (s[i] == 'T')

best = 0
preL = preLC = 0
for i in range(n + 1):
    # 在 i 处插入
    best = max(best, preL * sufT[i])          # 插 C
    best = max(best, preLC)                    # 插 T：前面 LC 对数
    # 插 L：i 之后 CT 对数，需要后缀 CT 计数，下面用一次反向扫描补
    if i < n:
        if s[i] == 'L': preL += 1
        elif s[i] == 'C': preLC += preL
```

插 `L` 的增量需要后缀 `CT` 对数，反向再扫一遍：维护 `sufT`、`sufCT`，遇 `C` 时 `sufCT += sufT`，位置 i 的增量即 `sufCT[i]`。两遍扫描合并即可，代码不重复贴。

## 复杂度
时间 O(n)：正反各扫一遍，n 为字符串长度。
空间 O(n)：`sufT`、`sufCT` 两个长度 n+1 的数组。

## 易错点
- 输入 `"L"` 或 `"LT"`：只算原串得 0 就返回，漏掉「插入后仍凑不出 LCT」的判断 → 正确做法是 `best` 初值 0，插入增量算完仍为 0 时返回 0，不能返回负数或未初始化值。
- 输入 `"TTT"` 或 `"LLL"`：在开头插 `L` 时 `sufT[i]` 全为 0，增量 0；若误把「插 L 增量」写成 `preL * sufT[i]` 会得 0 但语义错位 → 插 `L` 必须用后缀 `CT` 对数，插 `C` 才用 `preL * sufT[i]`，两者不能混。

## 如果面试官追问
若要求输出具体插入方案（位置+字母）？答：在取 `best` 时同步记录 `(i, ch)`，反向扫描时把 `sufCT` 的贡献也带上位置即可，O(1) 额外空间。
