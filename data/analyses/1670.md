## 一句话思路
用两个 `deque` 把队列劈成前后两半，始终维持 `len(left) == len(right)` 或 `len(left) == len(right) - 1`，中位就落在固定位置。

## 怎么做
1. 定不变式：`left` 存前半，`right` 存后半，只允许 `len(left) == len(right)` 或 `len(left) + 1 == len(right)`，即 `right` 不比 `left` 短、最多长 1。
2. 每次 push 后调 `balance()`：`len(left) > len(right)` 时把 `left.pop()` 挪到 `right.appendleft()`；`len(right) > len(left) + 1` 时把 `right.popleft()` 挪到 `left.append()`。
3. `pushMiddle` 一律先 `left.append(val)` 再 balance，这样新元素落在靠前的中位；`popMiddle` 取 `left.pop()`（`left` 空则取 `right.popleft()`）。
4. 以示例 `[1,4,3,2]` 为例：`left=[1,4]`、`right=[3,2]`，`popMiddle` 取 `left.pop()` 得 4，`left=[1]`、`right=[3,2]`，balance 后 `left=[1,3]`、`right=[2]`。

```python
from collections import deque

class FrontMiddleBack:
    def __init__(self):
        self.left, self.right = deque(), deque()

    def _balance(self):
        if len(self.left) > len(self.right):
            self.right.appendleft(self.left.pop())
        elif len(self.right) > len(self.left) + 1:
            self.left.append(self.right.popleft())

    def pushMiddle(self, val):
        self.left.append(val)
        self._balance()

    def popMiddle(self):
        if not self.left and not self.right:
            return -1
        v = self.left.pop() if self.left else self.right.popleft()
        self._balance()
        return v
```

`pushFront` 走 `left.appendleft`、`pushBack` 走 `right.append`，`popFront` 优先 `left.popleft()`（空则 `right.popleft()`），`popBack` 走 `right.pop()`，每次操作后都 `_balance()`。

## 复杂度
时间：每次 push/pop 均摊 O(1)，`deque` 两端操作常数时间，balance 最多挪一个元素。
空间：O(n)，n 为当前元素总数，两个 `deque` 合计存 n 个元素。

## 易错点
- `pushMiddle` 若写成 `right.appendleft(val)`，对 `[1,2]` 会得到 `left=[1]`、`right=[3,2]`，中位变成 3 而非靠前的 2；正确做法是固定往 `left` 尾部加再 balance。
- `popMiddle` 在 `left` 为空（如队列只有 `[5]` 时 `left=[]`、`right=[5]`）若直接 `left.pop()` 会抛异常；正确做法是先判 `left` 非空，否则取 `right.popleft()`。
