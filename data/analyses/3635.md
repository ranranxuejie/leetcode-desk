## 一句话思路
只需保留每类中「最早结束时间」最小的那个设施，两种顺序各算一次取最小。

## 怎么做
1. 对陆地类，求 `min(landStartTime[i] + landDuration[i])` 记为 `bestLand`；水同类求 `bestWater`。
2. 先陆后水：结束时间 = `max(bestLand, waterStartTime[j]) + waterDuration[j]`，对每个 j 取最小。
3. 先水后陆：对称地 = `max(bestWater, landStartTime[i]) + landDuration[i]`，对每个 i 取最小。
4. 答案取两者较小值。

关键中间值：示例 1 中 `bestLand = min(2+4, 8+1) = 6`，`bestWater = 6+3 = 9`。先陆后水对 j=0：`max(6,6)+3 = 9`；先水后陆对 i=0：`max(9,2)+4 = 13`，i=1：`max(9,8)+1 = 10`，取 9。

```python
best_land = min(s + d for s, d in zip(landStartTime, landDuration))
best_water = min(s + d for s, d in zip(waterStartTime, waterDuration))
ans = 2**31 - 1
for s, d in zip(waterStartTime, waterDuration):
    ans = min(ans, max(best_land, s) + d)
for s, d in zip(landStartTime, landDuration):
    ans = min(ans, max(best_water, s) + d)
```

为什么只留最早结束的那个？因为第一项结束后，第二项的开始时间只取决于「第一项结束时刻」和「第二项开放时刻」的较大者；第一项结束越早，这个 max 只会越小或不变，所以同类别里其余设施永远不可能更优。

## 复杂度
时间：O(n + m)，两次线性扫描求 min，再各扫一遍。
空间：O(1)，只存 `best_land`、`best_water`、`ans` 三个标量。

## 易错点
- 只算「先陆后水」一种顺序 → 示例 2 会输出 18，正确是 14（水 1+10=11 结束，陆地 11 开始，11+3=14）。必须两种顺序都算。
- 误以为要枚举所有 (i, j) 对 → n=m=5×10⁴ 时 2.5×10⁹ 次超时。正确做法是先各自压缩成 `best_land`/`best_water` 再线性扫，O(n+m)。

## 如果面试官追问
问：如果要求输出具体选了哪两个设施怎么办？
答：求 `best_land` 时同时记下对应下标，第二遍扫描时记录取到最小值的 j（或 i），两个下标一起返回即可。
