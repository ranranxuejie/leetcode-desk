## 一句话思路
按 BST 递归拆左右子树，方案数 = 左右子树方案数 × 左右元素交错排列的组合数。

## 怎么做
1. 取 `nums[0]` 为根，按大小把剩余元素分成左子树序列 `left` 和右子树序列 `right`（保持原相对顺序）。
2. 递归求 `ways(left)` 和 `ways(right)`，再乘上把两段序列交错合并的方案数 `C(len(left)+len(right), len(left))`。
3. 用记忆化按子序列（或按区间）缓存，避免重复计算。

以 `nums = [3,4,5,1,2]` 为例：根 3，`left=[1,2]`，`right=[4,5]`。左右各只有一种合法顺序，交错方案 `C(4,2)=6`，但左子树 `[1,2]` 本身是递增链，`ways([1,2])=0`？不对——`[1,2]` 插入得 1 为根、2 为右孩子，只有原顺序一种，`ways=1`；右同理。所以答案 `1×1×C(4,2)=6`，再核对示例输出 5，说明还需注意：`[1,2]` 与 `[4,5]` 各自只有 1 种，`C(4,2)=6`，但示例是 5。差异在于根 3 固定首位后，交错是 6 种，其中一种 `[3,4,5,1,2]` 是原数组本身也算，题目统计的是重排方案，示例列了 5 个不含原序，故返回 `6-1=5`。实现上通常直接返回 `6` 再减 1，或按题意返回 `ways-1`。

```python
from math import comb
MOD = 10**9 + 7

def dfs(seq):
    if len(seq) <= 1:
        return 1
    root = seq[0]
    left = [x for x in seq[1:] if x < root]
    right = [x for x in seq[1:] if x > root]
    return dfs(left) * dfs(right) % MOD * comb(len(seq)-1, len(left)) % MOD

# 调用：return (dfs(nums) - 1) % MOD
```

## 复杂度
时间：每个节点扫一遍子序列，最坏 O(n²)（链状 BST）。
空间：递归栈 + 子序列拷贝 O(n²) 最坏，缓存另计。

## 易错点
- 输入 `[1,2,3]`（递增链）→ 若忘记减 1，会返回 1 而非 0；正确做法是最终 `(dfs(nums)-1) % MOD`，因为原排列本身被计入。
- 输入 `[2,1,3]` → 若用 `comb(len(seq), len(left))` 而非 `comb(len(seq)-1, len(left))`，会把根也算进交错，得 3 而非 1；正确是剩余 `n-1` 个位置里选 `len(left)` 个给左子树。

## 如果面试官追问
问：n 到 10^5 怎么办？答：用单调栈建树 + 预处理阶乘逆元算组合，把 O(n²) 降到 O(n log n)。
