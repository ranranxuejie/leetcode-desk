## 一句话思路
把 mappings 压成 26+10 个字符的映射表，再对 s 的每个长度为 len(sub) 的窗口逐位判断 sub[j] 能否变成 s[i+j]。

## 怎么做
1. 建 `allow[c]`：`allow[ord(old)]` 里放 `{old, new1, new2, ...}`，注意 old 自身也算合法（不替换）。
2. 枚举 s 中所有起点 `i`，范围 `0..len(s)-len(sub)`。
3. 对每个窗口逐位比对：`s[i+j]` 必须在 `allow[ord(sub[j])]` 中，否则该窗口失败。
4. 任一窗口全通过即返回 `True`，全部失败返回 `False`。

以示例 1 为例：`s="fool3e7bar"`, `sub="leet"`, `mappings=[["e","3"],["t","7"],["t","8"]]`。建表后 `allow['e']={'e','3'}`，`allow['t']={'t','7','8'}`。起点 `i=4` 时窗口是 `"l3e7"`：`sub[0]='l'` 对 `s[4]='l'` 命中自身，`sub[1]='e'` 对 `s[5]='3'` 在 `allow['e']` 中，`sub[2]='e'` 对 `s[6]='e'` 命中自身，`sub[3]='t'` 对 `s[7]='7'` 在 `allow['t']` 中，四位全过，返回 `True`。

```python
allow = {chr(c): {chr(c)} for c in range(128)}
for old, new in mappings:
    allow[old].add(new)

n, m = len(s), len(sub)
for i in range(n - m + 1):
    if all(s[i + j] in allow[sub[j]] for j in range(m)):
        return True
return False
```

关键点：`allow` 初始化时把每个字符自己放进去，这样「不替换」和「替换成 new」用同一个 `in` 判断，不用分支。

## 复杂度
时间 O((n-m+1)·m)，n=len(s)、m=len(sub)，最坏 5000×5000。
空间 O(1)，`allow` 固定 128 个键，与输入规模无关。

## 易错点
- `mappings` 里同一 old 有多个 new（如 `t→7`、`t→8`）→ 若用 `dict` 只存最后一个 new，示例 1 里 `t→8` 会覆盖 `t→7`，窗口 `"l3e7"` 判失败 → 必须用 `set` 累积所有 new。
- 忘记把 old 自身放进集合 → 示例 1 中 `sub[0]='l'`、`sub[2]='e'` 这类不替换的位置会被判不匹配，整题返回 `False` → 初始化时对每个字符先 `{chr(c)}` 再 `add(new)`。

## 如果面试官追问
若 s 长度升到 10^6、sub 到 10^5，怎么做？答：把每个窗口的逐位判断换成对 sub 建「允许字符集」的自动机或按字符分桶做位运算匹配，避免 O(n·m)。
