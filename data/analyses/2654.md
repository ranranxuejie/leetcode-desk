## 一句话思路
先看整个数组的 gcd 是否为 1，是则必能全变 1；否则 -1。有 1 时直接数非 1 个数，无 1 时找最短的 gcd 为 1 的连续子段。

## 怎么做
1. 统计 `ones = nums.count(1)`，若 `ones > 0`，答案就是 `n - ones`（每个非 1 元素与相邻的 1 做一次 gcd 即可）。
2. 否则用 `reduce(gcd, nums)` 判断全局 gcd；若 `!= 1` 直接返回 -1，因为任何操作都只是取子集的 gcd，不会产生新的质因子。
3. 全局 gcd 为 1 时，枚举左端点 `i`，向右累加 `g = gcd(g, nums[j])`，一旦 `g == 1` 就记录长度 `j - i + 1` 并 break，取所有长度最小值 `best`。
4. 答案 = `best - 1 + (n - 1)`：先用 `best - 1` 次操作把这段压成 1 个 1，再用 `n - 1` 次把这个 1 扩散到其余元素。

以 `nums = [2,6,3,4]` 为例：全局 gcd 为 1，`i=2` 时 `g = gcd(3,4) = 1`，长度 2，`best = 2`，答案 `1 + 3 = 4`，与示例一致。

```python
from math import gcd
from functools import reduce

n = len(nums)
ones = nums.count(1)
if ones:
    return n - ones
if reduce(gcd, nums) != 1:
    return -1
best = n
for i in range(n):
    g = 0
    for j in range(i, n):
        g = gcd(g, nums[j])
        if g == 1:
            best = min(best, j - i + 1)
            break
return best - 1 + n - 1
```

## 复杂度
时间：外层 `i` 与内层 `j` 各贡献 n，每次 gcd 贡献 log(max(nums))，共 O(n² log V)。
空间：只用了 `g`、`best` 等常数个变量，O(1)。

## 易错点
- `nums = [2,10,6,14]` 这类全局 gcd 为 2 的输入 → 若跳过第 2 步直接枚举子段，会得到 `best = n` 并返回 `2n - 2` 的错误正数 → 必须先判 `reduce(gcd, nums) != 1` 返回 -1。
- `nums = [1,1,5]` 这类已含 1 的输入 → 若仍走子段枚举，`best` 可能取到 1 但公式 `best - 1 + n - 1` 会多算 → 有 1 时必须走 `n - ones` 分支，答案是 1 而不是 3。

## 如果面试官追问
问：n 放大到 10^5 怎么办？答：用双指针维护滑动窗口的 gcd 不可行（gcd 不满足可减性），改用稀疏表预处理区间 gcd，二分最短长度，O(n log n log V)。
