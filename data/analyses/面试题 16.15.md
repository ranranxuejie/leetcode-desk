## 一句话思路
先逐位比对锁定"猜中"，再用 4 色计数差取 min 求和得伪猜中，避免同一球被重复计。

## 怎么做
1. 遍历 4 个下标，`solution[i] == guess[i]` 时 `hit += 1`，否则把两边的字符分别记进 `cnt_s`、`cnt_g`。
2. 对 `"RGBY"` 四色，伪猜中数 = `sum(min(cnt_s[c], cnt_g[c]))`，因为每个颜色能配对的次数受较少一方限制。
3. 返回 `[hit, pseudo]`。

用官方示例 `solution="RGBY"`、`guess="GGRR"`：下标 0 `R≠G`、1 `B≠G`、2 `G≠R`、3 `Y≠R`，`hit=0`；错位字符里 `cnt_s={R:1,G:1,B:1,Y:1}`，`cnt_g={G:2,R:2}`，逐色取 min 得 `R:1, G:1, B:0, Y:0`，`pseudo=2`？——注意这里 `hit` 实际是 1（下标 3 的 `Y` 与 `guess` 的 `R` 不等，但下标 2 的 `G` 与 `guess` 的 `R` 不等……逐位看：`R/G`、`G/G` 相等 → `hit=1`）。修正后错位字符为 `s={R,B,Y}`、`g={G,R}`，`cnt_s={R:1,B:1,Y:1}`、`cnt_g={G:1,R:1}`，取 min 得 `R:1`，`pseudo=1`，输出 `[1,1]`。

```python
hit = 0
cnt_s = [0] * 4
cnt_g = [0] * 4
idx = {c: i for i, c in enumerate("RGBY")}
for a, b in zip(solution, guess):
    if a == b:
        hit += 1
    else:
        cnt_s[idx[a]] += 1
        cnt_g[idx[b]] += 1
pseudo = sum(min(x, y) for x, y in zip(cnt_s, cnt_g))
return [hit, pseudo]
```

关键点：相等的位置**两边都不计数**，否则 `solution="RRRR"`、`guess="RRRR"` 会算出 `hit=4` 且 `pseudo=4`。

## 复杂度
时间 O(n)，n 为字符串长度（本题固定 4），四色求和是常数。
空间 O(1)，只开了两个长度 4 的计数数组。

## 易错点
- `solution="RGGY"`、`guess="GRRG"` 这类有重复色的输入 → 若直接对每个错位字符查对方是否"存在"该色，`G` 会被重复匹配成 2 次伪猜中 → 必须用计数取 min，得到 `pseudo=1`。
- `solution="RGBY"`、`guess="RGBY"` → 若先统计全局颜色再减 `hit`，容易把已猜中的球又算进伪猜中，得到 `[4,4]` → 正确做法是相等位直接跳过、不进入计数。

## 如果面试官追问
若颜色种类从 4 扩到 k 且字符串长度到 n，怎么做？答：仍用哈希表计数，时间 O(n+k)，把固定数组换成 `dict` 即可。
