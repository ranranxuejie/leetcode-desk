## 一句话思路
用两个变量分别记录「以奇/偶结尾」的最大得分，逐个元素滚动更新，因为跳到 j 的最优前驱只取决于前驱的奇偶性。

## 怎么做
1. 初始化 `best = [nums[0] if nums[0] % 2 == 0 else -inf, nums[0] if nums[0] % 2 == 1 else -inf]`，即只有 0 号位置可达。
2. 从左到右遍历 `nums[1:]`，对每个 `v` 算出 `p = v % 2`。
3. 更新 `best[p] = max(best[p] + v, best[1-p] - x + v)`：同奇偶直接接上，异奇偶要扣 `x`。
4. 答案是 `max(best)`。

以示例 1 `nums = [2,3,6,1,9,2], x = 5` 为例：初始 `best = [2, -inf]`。处理 `3`（奇）时，`best[1] = max(-inf+3, 2-5+3) = 0`；处理 `6`（偶）时 `best[0] = max(2+6, 0-5+6) = 8`；处理 `1`（奇）时 `best[1] = max(0+1, 8-5+1) = 4`；处理 `9`（奇）时 `best[1] = max(4+9, 8-5+9) = 13`；处理 `2`（偶）时 `best[0] = max(8+2, 13-5+2) = 10`。最终 `max(10, 13) = 13`，与答案一致。

```python
NEG = float('-inf')
best = [NEG, NEG]
best[nums[0] % 2] = nums[0]
for v in nums[1:]:
    p = v % 2
    best[p] = max(best[p] + v, best[1 - p] - x + v)
return max(best)
```

关键点：`best[p] + v` 表示前驱与 `v` 同奇偶，不扣分；`best[1-p] - x + v` 表示跨奇偶，扣一次 `x`。两者取大即当前最优。

## 复杂度
时间 O(n)：一次遍历 `nums`，每个元素做常数次比较。
空间 O(1)：只开 `best` 两个槽位，不随 n 增长。

## 易错点
- 若把 `best` 初值都设成 0 或 `-inf` 之外的值，示例 1 中处理 `3` 时会误算成从「不存在的偶数前驱」出发，得到错误起点；正确做法是只让 `best[nums[0] % 2] = nums[0]`，另一槽保持 `-inf`。
- 若写成 `best[p] = max(best[p], best[1-p] - x) + v` 之外的顺序（先加 `v` 再比较），跨奇偶分支会漏扣或多扣一次 `x`；正确做法是两条候选都先算完整得分再取 `max`，如示例 1 处理 `9` 时必须是 `max(4+9, 8-5+9)`。

## 如果面试官追问
问：要求输出具体访问路径怎么办？
答：再开一个 `pre` 数组记录每个位置最优前驱下标，最后从 `max(best)` 对应位置回溯即可，空间升到 O(n)。
