## 一句话思路
按边数分层做 DP，`dp[e][v]` 存「走 e 条边到 v 的所有和」的集合，用哈希去重后只保留小于 t 的值。

## 怎么做
1. 建邻接表 `adj[u] = [(v, w), ...]`，初始化 `dp[0][v] = {0}`（0 条边到任意点，和为 0）。
2. 对 `e` 从 1 到 k，遍历每条边 `(u, v, w)`，把 `dp[e-1][u]` 里每个 `s` 加 `w` 后塞进 `dp[e][v]`，只留 `s + w < t` 的。
3. 用 `set` 去重，因为不同路径可能得到同一个和，重复值只会拖慢后续层。
4. 答案取 `max(dp[k][v])` 对所有 v，空则返回 -1。

以示例 1 为例：`dp[0] = {0:{0}, 1:{0}, 2:{0}}`；`e=1` 时边 `(0,1,1)` 给 `dp[1][1]` 塞入 1，边 `(1,2,2)` 给 `dp[1][2]` 塞入 2；`e=2` 时 `dp[1][1]={1}` 加 2 得 `dp[2][2]={3}`，3 < 4 保留，答案 3。

```python
from collections import defaultdict

adj = defaultdict(list)
for u, v, w in edges:
    adj[u].append((v, w))

dp = [defaultdict(set) for _ in range(k + 1)]
for v in range(n):
    dp[0][v].add(0)

for e in range(1, k + 1):
    for u in range(n):
        for v, w in adj[u]:
            for s in dp[e - 1][u]:
                if s + w < t:
                    dp[e][v].add(s + w)

ans = max((max(s) for s in dp[k].values() if s), default=-1)
```

## 复杂度
时间：O(k · E · S)，S 是每层每个点的不同和个数，上界受 t 限制（≤600）。
空间：O(k · n · S)，即 k+1 层、每层 n 个点各存一个 set。

## 易错点
- 边界写成 `s + w <= t` → 示例 2 中 `0->2` 权重 3 会被误收，答案错成 3；必须严格 `< t`，因为题面要求「严格小于」。
- 不去重直接存 list → 示例 1 这种链没问题，但边多时同一 `(e, v)` 会积累大量重复和，k=300、t=600 时集合大小本可压到 600 以内，不去重会指数膨胀超时。

## 如果面试官追问
问：k 很大（如 10^5）怎么办？答：和的上界被 t 卡死，dp 层数超过 t 后集合必空，可提前 break，实际有效层数 ≤ t。
