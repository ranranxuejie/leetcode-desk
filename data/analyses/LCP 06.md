## 一句话思路
每堆独立，尽量每次拿 2 枚，所以一堆 `c` 枚的最少次数是 `c // 2 + c % 2`，即 `(c + 1) // 2`。

## 怎么做
1. 遍历 `coins`，对每堆单独算次数，因为一次只能动一堆，堆与堆之间没有取舍。
2. 一堆 `c` 枚时，先拿 `c // 2` 次两枚，剩 `c % 2` 枚再拿一次。
3. 把每堆结果累加进 `total` 返回。

以 `coins = [4,2,1]` 为例：`4` 得 `4//2 + 4%2 = 2`，`2` 得 `1`，`1` 得 `0 + 1 = 1`，`total = 2+1+1 = 4`，与示例一致。关键中间值是第一堆的 `4 // 2 = 2`、`4 % 2 = 0`，说明偶数堆正好整除、不额外加一次。

```python
total = 0
for c in coins:
    total += c // 2 + c % 2
return total
```

等价的写法是 `(c + 1) // 2`：`c = 4` 时 `5 // 2 = 2`，`c = 1` 时 `2 // 2 = 1`，对奇偶都成立。两种写法选一种即可，别在同一份代码里混用导致自己看错。

## 复杂度
时间：O(n)，n 是堆数，每堆只做常数次算术。
空间：O(1)，只开 `total` 一个累加变量，没有额外数组。

## 易错点
- 输入 `[1]` → 若写成 `c // 2` 会得 `0`，漏掉最后那枚单币 → 必须补 `c % 2`，或用 `(c + 1) // 2`。
- 输入 `[2,3,10]` → 若误以为可以跨堆凑两枚（比如把两堆各 1 枚合并成一次拿 2 枚）会算成 7 → 一次只能选一堆，正确是 `1+2+5 = 8`。

## 如果面试官追问
问：如果每次可以拿 1 到 k 枚呢？
答：每堆变成 `c // k + (1 if c % k else 0)`，即 `(c + k - 1) // k`，仍然逐堆独立求和。
