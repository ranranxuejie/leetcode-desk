## 一句话思路
二分答案 D，判定能否用同一对 (x,y) 填满所有 -1 使相邻差 ≤ D，单调性保证二分成立。

## 怎么做
1. 二分 D 的上下界：`lo=0`，`hi=max(nums)-min(nums)`（非 -1 值之间），全 -1 时直接返回 0。
2. 判定函数：扫描每个「连续 -1 段」，取它左右两侧的固定值 `L`、`R`（段在数组头/尾时只有一侧）。
3. 单侧约束时，只需存在一个值 v 使 `|v-L|<=D`，即区间 `[L-D, L+D]` 与正整数集有交，恒可行（取 v=L 即可），所以只有「两侧都有」的段才真正收紧。
4. 两侧都有时，要存在 v 同时满足 `|v-L|<=D`、`|v-R|<=D`，即 `[L-D,L+D] ∩ [R-D,R+D]` 非空，等价于 `|L-R| <= 2D`。

以示例 1 `nums=[1,2,-1,10,8]` 验证 D=4：唯一 -1 段左右是 `L=2, R=10`，`|2-10|=8 <= 2*4=8`，可行；D=3 时 `8 <= 6` 不成立，故答案 4。

```python
def ok(D):
    i, n = 0, len(nums)
    while i < n:
        if nums[i] != -1:
            i += 1
            continue
        j = i
        while j < n and nums[j] == -1:
            j += 1
        if i > 0 and j < n and abs(nums[i-1] - nums[j]) > 2 * D:
            return False
        i = j
    return True
```

注意段内相邻两个 -1 之间差为 0，天然满足；段长 ≥2 时中间值可自由取，不额外加约束。

## 复杂度
时间 O(n log(max-min))：每轮判定扫一遍 n，二分 log 值域。
空间 O(1)：只用了 i、j、D 几个标量。

## 易错点
- 把段首/段尾的单侧段也套 `|L-R|<=2D`：`nums=[-1,10,-1,8]` 会误判不可行；正确做法是单侧段直接跳过，只检查 `i>0 and j<n` 的段。
- 二分的 `hi` 取成 `max(nums)`：`nums=[1,2,-1,10,8]` 时 hi=10 虽不致命，但全 -1 数组会因 `max=-1` 出错；正确做法是先判全 -1 返回 0，hi 用非 -1 值的极差。

## 如果面试官追问
要求输出具体 (x,y) 而非仅最小值？答：二分到最小 D 后，对每个两侧段在交集 `[max(L-D,R-D), min(L+D,R+D)]` 里取一个值，所有段取值去重后不足两个就补任意正整数。
