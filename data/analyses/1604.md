## 一句话思路
按人分组把时间转成分钟排序，滑动窗口看任意连续三次的跨度是否 ≤60。

## 怎么做
1. 用字典 `d` 把 `keyName[i]` 映射到分钟列表，`int(t[:2])*60 + int(t[3:])` 转换。
2. 对每个人的时间列表 `sorted` 升序，因为输入不保证有序（示例 2 的 alice 就是 `12:01` 在 `12:00` 前）。
3. 只检查 `ts[i+2] - ts[i] <= 60`：若存在三次在一小时内，排序后必存在连续三次满足，无需枚举所有组合。
4. 命中就加入结果，最后 `sorted` 输出。

以示例 1 的 daniel 为例，转换后 `[600, 640, 660]`，`ts[2]-ts[0] = 660-600 = 60 <= 60`，命中；luis 是 `[540, 660, 780, 900]`，`660-540=120`、`780-660=120`、`900-780=120`，全部超 60，不警告。

```python
from collections import defaultdict

d = defaultdict(list)
for name, t in zip(keyName, keyTime):
    d[name].append(int(t[:2]) * 60 + int(t[3:]))

ans = []
for name, ts in d.items():
    ts.sort()
    for i in range(len(ts) - 2):
        if ts[i + 2] - ts[i] <= 60:
            ans.append(name)
            break
return sorted(ans)
```

关键点：`ts[i+2] - ts[i] <= 60` 而不是 `< 60`，因为 `"10:00"` 到 `"11:00"` 算一小时。

## 复杂度
时间：O(n log n)，n 为记录数，主要是每个人的时间列表排序。
空间：O(n)，字典存全部转换后的分钟数，结果列表最多 O(n)。

## 易错点
- 输入时间未排序 → 直接按原顺序扫窗口，示例 2 的 alice 是 `12:01, 12:00, 18:00`，会漏掉 `12:00` 和 `12:01` 的相邻关系 → 必须先 `ts.sort()` 再滑窗。
- 边界写成 `< 60` → 示例 1 的 daniel 跨度正好 60 分钟会被判成不警告，输出 `[]` → 必须用 `<= 60`，题面明确 `"10:00"-"11:00"` 算一小时。

## 如果面试官追问
问：如果要求返回每个员工最早触发警告的那三次时间怎么办？
答：滑窗命中时记录 `(ts[i], ts[i+1], ts[i+2])` 即为该员工最早的一组，因为排序后首次命中跨度最小。
