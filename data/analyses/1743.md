## 一句话思路
用哈希表把每个值映射到它的邻居列表，度数为 1 的值就是端点，从端点出发沿未访问邻居一路走完。

## 怎么做
1. 遍历 `adjacentPairs`，对每个 `[u, v]` 双向建图：`g[u].append(v)`、`g[v].append(u)`。
2. 找出 `len(g[x]) == 1` 的任意一个 `x` 作为起点（n≥2 保证存在且恰有两个）。
3. 从起点出发，每次取当前节点邻居中「不等于上一个节点」的那个，追加到结果并前移。

以示例 1 `[[2,1],[3,4],[3,2]]` 为例，建图后 `g = {2:[1,3], 1:[2], 3:[4,2], 4:[3]}`，度数为 1 的是 `1` 和 `4`，取 `1` 出发：`1 → 2 → 3 → 4`。

```python
g = {}
for u, v in adjacentPairs:
    g.setdefault(u, []).append(v)
    g.setdefault(v, []).append(u)

start = next(x for x in g if len(g[x]) == 1)
res, prev, cur = [start], None, start
while len(res) < len(g):
    nxt = g[cur][0] if g[cur][0] != prev else g[cur][1]
    res.append(nxt)
    prev, cur = cur, nxt
```

关键点：`g[cur]` 长度最多为 2，所以 `g[cur][0] != prev` 时取 `[0]`，否则取 `[1]`，不需要循环过滤。

## 复杂度
时间 O(n)：建图遍历 n-1 对，走链 n 步，每步 O(1)。
空间 O(n)：哈希表存 2(n-1) 条邻接记录，结果数组 n 个元素。

## 易错点
- 输入 `[[100000,-100000]]`（n=2）→ 若用 `while len(res) < len(g)` 但忘了 `g` 只有两个键、起点邻居唯一，取 `g[cur][1]` 会越界 → 正确做法是先判断 `g[cur][0] != prev` 再取下标，n=2 时 `prev=None` 恒取 `[0]`。
- 输入含负数如示例 2 `[[4,-2],[1,4],[-3,1]]` → 若用数组下标当哈希（如 `g[u]` 直接索引）会因 `-2`、`-3` 负下标错位 → 必须用 `dict` 的 `setdefault`，键是原始值本身。

## 如果面试官追问
若要求返回字典序最小的那个合法数组？答：两个端点各试一次，从较小端点出发走出的链即为字典序最小，比较两条链取小。
