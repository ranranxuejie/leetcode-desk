## 一句话思路
用数组 `stk` 存栈元素，另开 `add[i]` 记录「加到第 i 个元素为止的增量」，pop 时把增量下推给前一个位置，inc 只改 `add[min(k,len)-1]`。

## 怎么做
1. `push(x)`：`len(stk) < maxSize` 时 `stk.append(x)` 且 `add.append(0)`，否则直接丢弃。
2. `inc(k, val)`：`i = min(k, len(stk)) - 1`，若 `i >= 0` 则 `add[i] += val`，O(1)。
3. `pop()`：空栈返回 `-1`；否则取 `i = len(stk)-1`，`res = stk[i] + add[i]`，把 `add[i]` 下推给 `add[i-1]`（若 `i > 0`），再 `pop` 两个数组，返回 `res`。

关键中间值：示例执行到 `increment(5,100)` 时栈长 3，`i = min(5,3)-1 = 2`，只令 `add[2] = 100`；接着 `increment(2,100)` 令 `add[1] = 100`。此时 `add = [0,100,100]`，`stk = [1,2,3]`。`pop()` 得 `3+100 = 103`，并把 100 下推成 `add[1] = 200`；再 `pop()` 得 `2+200 = 202`，下推后 `add[0] = 200`；再 `pop()` 得 `1+200 = 201`。

```python
def push(self, x):
    if len(self.stk) < self.maxSize:
        self.stk.append(x)
        self.add.append(0)

def inc(self, k, val):
    i = min(k, len(self.stk)) - 1
    if i >= 0:
        self.add[i] += val

def pop(self):
    if not self.stk:
        return -1
    i = len(self.stk) - 1
    res = self.stk[i] + self.add[i]
    if i > 0:
        self.add[i - 1] += self.add[i]
    self.stk.pop()
    self.add.pop()
    return res
```

## 复杂度
时间：push/pop/inc 均 O(1)，n 是调用次数，无 log 项。
空间：O(maxSize)，`stk` 与 `add` 两个数组各占 maxSize。

## 易错点
- `inc(k, val)` 中 k 大于栈长时，若直接写 `add[k-1]` 会下标越界（如示例 `inc(5,100)` 而栈长 3）。正确做法是先 `min(k, len(stk))` 再减 1，且结果可能为 -1（空栈）要跳过。
- `pop()` 下推增量时若漏掉 `i > 0` 判断，栈只剩一个元素时 `add[-1]` 会写到数组末尾，污染后续 push 的元素。正确做法是只在 `i > 0` 时执行 `add[i-1] += add[i]`，且 `stk` 与 `add` 必须同步 pop。

## 如果面试官追问
问：若 inc 要支持任意区间 [l, r] 加 val 呢？
答：把 `add` 换成差分数组，`add[l] += val`、`add[r+1] -= val`，pop 时按栈顶顺序累加前缀和即可，仍是 O(1)。
