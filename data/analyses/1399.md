## 一句话思路
用哈希表统计每个数位和出现的次数，再数出现次数等于最大值的键有几个。

## 怎么做
1. 遍历 `i` 从 1 到 `n`，对每个 `i` 求数位和 `s`。
2. 用字典 `cnt` 累加 `cnt[s] += 1`。
3. 取 `mx = max(cnt.values())`，再统计 `cnt` 中值等于 `mx` 的键个数。

以 `n = 13` 为例，`i = 10` 时数位和 `s = 1 + 0 = 1`，于是 `cnt[1]` 从 1（来自数字 1）变成 2；`i = 13` 时 `s = 1 + 3 = 4`，`cnt[4]` 变成 2。最终 `cnt` 里值为 2 的键是 1、2、3、4 共 4 个，返回 4。

```python
cnt = {}
for i in range(1, n + 1):
    s, x = 0, i
    while x:
        s += x % 10
        x //= 10
    cnt[s] = cnt.get(s, 0) + 1
mx = max(cnt.values())
return sum(1 for v in cnt.values() if v == mx)
```

注意 `x //= 10` 是整除，不能用 `/=`；`s` 初值必须置 0，否则上一轮的数位和会串到下一个数。

## 复杂度
时间：O(n log n)，每个数拆位最多 log10(n) 次。
空间：O(log n)，字典最多存 9×4=36 个不同数位和。

## 易错点
- `n = 9` 时若把 `range` 写成 `range(1, n)`，会漏掉 9，`cnt` 只有 8 个键、最大组数错成 1 而非 9；正确是 `range(1, n + 1)`。
- `n = 10000` 时数位和最大为 1（1+0+0+0+0），若误以为最大数位和是 9×5=45 而开固定长度数组 `[0]*46` 倒没错，但若开 `[0]*10` 就会下标越界；正确做法是用字典或按 `9 * len(str(n))` 开数组。

## 如果面试官追问
问：n 扩大到 10^9 怎么办？
答：不能逐个枚举，需按数位 DP 统计每个数位和的个数，再取最大计数。
