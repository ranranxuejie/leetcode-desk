## 一句话思路
用「计数桶双向链表 + key→桶节点哈希表」，桶按计数升序排列，头桶最小、尾桶最大，增删只动相邻桶。

## 怎么做
1. 链表节点存 `cnt` 和 `keys` 集合；`mp[key]` 指向该 key 所在桶节点；哨兵 `head`（cnt=0）与 `tail` 夹住所有桶。
2. `inc(key)`：从 `mp[key]` 取旧桶（不存在则用 `head`），若旧桶下一节点 `cnt != old+1` 就新建桶插在中间，把 key 移过去，旧桶空了就删。
3. `dec(key)`：对称地找 `cnt-1` 的桶；`cnt-1 == 0` 时直接从 `mp` 删 key，不建桶。
4. `getMaxKey` 返回 `tail.prev` 里任一 key，`getMinKey` 返回 `head.next` 里任一 key；桶空则返回 `""`。

以官方示例走一遍：`inc("hello")` 后 `head.next` 是 `cnt=1` 的桶，`keys={"hello"}`，`mp["hello"]` 指向它；再 `inc("hello")` 时旧桶 `cnt=1`，下一节点是 `tail`（`cnt` 视为无穷），`1+1 != tail.cnt`，于是新建 `cnt=2` 桶插在 `tail` 前，`hello` 迁入，旧桶清空删除。此时 `getMaxKey` 取 `tail.prev` 得 `"hello"`，`getMinKey` 取 `head.next` 也是 `"hello"`。再 `inc("leet")` 建 `cnt=1` 桶，`head.next` 变 `{"leet"}`，`getMinKey` 返回 `"leet"`。

```python
def inc(self, key):
    node = self.mp.get(key, self.head)
    nxt = node.next
    if nxt.cnt != node.cnt + 1:
        nxt = Node(node.cnt + 1)
        self._insert(node, nxt)
    nxt.keys.add(key)
    self.mp[key] = nxt
    if node is not self.head:
        node.keys.discard(key)
        if not node.keys:
            self._remove(node)
```

## 复杂度
时间：inc/dec/getMax/getMin 均 O(1) 平均，哈希查找 + 链表插删常数次。
空间：O(n)，n 为不同 key 数，桶数不超过 n+1，另开 `mp` 与各桶 `keys` 集合。

## 易错点
- `inc` 时若旧桶下一节点恰好是 `cnt+1` 的桶，必须复用它而不是新建，否则同一计数出现两个桶，`getMinKey` 取 `head.next` 可能拿到非最小计数的桶。
- `dec` 到 0 时若仍建 `cnt=0` 桶并留在链表里，`getMinKey` 会返回已删除的 key；正确做法是 `cnt-1==0` 时只从 `mp` 和旧桶 `keys` 里删掉，不建桶。
- 删桶时忘改 `mp` 中其他 key 的指向不会出错（它们指向别的桶），但忘删空桶会让 `head.next` 指向空桶，`getMinKey` 取到空集合报错。

## 如果面试官追问
问：若要求 `getMaxKey` 返回计数最大的**所有** key 怎么办？
答：桶内 `keys` 已是集合，直接返回整个集合即可，仍是 O(1) 取桶、O(k) 输出。
