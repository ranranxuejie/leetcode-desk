## 一句话思路
用 DSU on Tree（树上启发式合并）维护每棵子树内路径异或值的集合，查询时取第 k 小。

## 怎么做
1. 先 DFS 一遍算出每个节点到根的路径异或值 `px[u] = px[par[u]] ^ vals[u]`，示例 2 得 `px = [5, 7, 0]`。
2. 对每个节点做启发式合并：保留重儿子的集合，把轻儿子子树的所有 `px` 逐个插入，插入前先判重。
3. 合并完成后，当前集合就是 `u` 子树内所有不同路径异或值，按 `queries` 里 `u` 分组，用有序结构取第 `k` 小。
4. 若 `k > len(set)` 返回 `-1`，否则返回第 `k` 小的值。

```python
def dfs(u):
    big = -1
    for v in children[u]:
        dfs(v)
        if big == -1 or len(bag[v]) > len(bag[big]):
            big = v
    bag[u] = bag[big] if big != -1 else set()
    bag[u].add(px[u])
    for v in children[u]:
        if v != big:
            bag[u] |= bag[v]
```

示例 2 中节点 1 的集合为 `{7, 0}`，排序后 `[0, 7]`，`k=2` 返回 `7`。

## 复杂度
时间：每个节点被合并 O(log n) 次，每次集合操作 O(1) 均摊，总 O(n log n + q log n)。
空间：`bag` 集合最多存 n 个不同异或值，加上递归栈，O(n)。

## 易错点
- 查询 `k` 超过子树不同异或值个数时，若直接取排序后第 `k` 个会越界或返回错误值，必须先判 `k > len(bag[u])` 返回 `-1`，如示例 1 的 `[0,3]`。
- 路径异或值可能重复（示例 1 节点 1、2 都是 0），若用列表不去重，`k=2` 会错误返回 `0` 而非 `1`，必须用 `set` 保证不同值。

## 如果面试官追问
若 n 扩大到 10^6 且查询在线，怎么办？答：改用可持久化 Trie 按子树区间查询第 k 小，预处理 O(n log V)，单次查询 O(log V)。
