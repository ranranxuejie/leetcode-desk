## 一句话思路
用滑动窗口维护「最多含一个 0」的位区间，窗口最大长度就是答案。

## 怎么做
1. 把 `num` 看成二进制串，用双指针 `left`/`right` 在 0..31 位上滑动，`zeros` 记录窗口内 0 的个数。
2. `right` 每右移一位，若该位是 0 则 `zeros += 1`；当 `zeros > 1` 时右移 `left` 直到 `zeros <= 1`。
3. 每次收缩后更新 `ans = max(ans, right - left + 1)`，注意 `num` 为 0 时窗口仍能取到长度 1（翻转那一位）。

以 `num = 1775`（二进制 `11011101111`，低 11 位）为例：`right` 扫到第 7 位（值 0）时窗口 `[0,7]` 内已有两个 0（第 3 位和第 7 位），`zeros = 2`，`left` 被迫从 0 移到 4，窗口变成 `[4,7]`，长度 4；继续扫到第 10 位时窗口 `[4,10]` 只含第 7 位一个 0，长度 7，最终在 `[3,10]` 处得到 8。

```python
left = zeros = ans = 0
for right in range(32):
    if (num >> right) & 1 == 0:
        zeros += 1
    while zeros > 1:
        if (num >> left) & 1 == 0:
            zeros -= 1
        left += 1
    ans = max(ans, right - left + 1)
```

注意 `num` 按 32 位补码解释，负数高位全是 1，窗口会自然延伸到第 31 位，无需特判。

## 复杂度
时间：O(32)，`right` 和 `left` 各最多走 32 步，与 `num` 大小无关。
空间：O(1)，只开了 `left`/`zeros`/`ans` 三个整型变量。

## 易错点
- 输入 `num = 0` → 若循环里只统计「已有 1 的段」会返回 0 → 正确做法是窗口允许含一个 0，`[0,0]` 长度 1，翻转后得到 1。
- 输入 `num = -1`（32 位全 1）→ 若只扫到最高有效位就停会漏掉高位 → 正确做法是固定扫满 `range(32)`，负数高位补 1 也计入窗口。

## 如果面试官追问
问：如果允许翻转 k 个 0 呢？
答：把 `zeros > 1` 改成 `zeros > k`，其余不变，仍是 O(32) 滑窗。
