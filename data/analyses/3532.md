## 一句话思路
nums 已排序，只需看相邻差是否 ≤ maxDiff，用并查集把连续可达的段合并，查询时比较根即可。

## 怎么做
1. 初始化并查集，每个节点自成一派。
2. 从左到右扫 i=1..n-1，若 `nums[i] - nums[i-1] <= maxDiff` 就 union(i-1, i)。
3. 对每个 `[u, v]`，答案就是 `find(u) == find(v)`。

以示例 2 为例：nums=[2,5,6,8]，maxDiff=2。相邻差依次是 3、1、2，所以 0 与 1 断开，1-2、2-3 合并。最终根为 {0}、{1,2,3}。查询 [1,3] 同根返回 True，[0,2] 不同根返回 False。

```python
parent = list(range(n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

for i in range(1, n):
    if nums[i] - nums[i - 1] <= maxDiff:
        parent[find(i)] = find(i - 1)

return [find(u) == find(v) for u, v in queries]
```

## 复杂度
时间：O((n + q) α(n))，q 为 queries 长度，路径压缩近似常数。
空间：O(n)，parent 数组额外开销。

## 易错点
- 误判「非相邻也能连边」：如 nums=[1,3,5]、maxDiff=2，节点 0 与 2 差 4 无边，但 0-1、1-2 有边，路径仍连通。正确做法是只 union 相邻对，靠传递性得到连通性，不要对每对 (i,j) 判差。
- 查询 u==v 时：若代码先判 `nums[u] - nums[v] <= maxDiff` 再返回，可能因差为 0 恒真而侥幸对，但若写成「必须存在边」的判定逻辑就会漏掉自环。正确做法是直接走 find 比较，自反性天然成立。

## 如果面试官追问
问：若 nums 未排序怎么办？答：先对 (值, 原下标) 排序，再按排序后相邻差建并查集，查询仍用原下标映射。
