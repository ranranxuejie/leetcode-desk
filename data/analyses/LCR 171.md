## 一句话思路
双指针各走完自己再跳对方链头，两轮后必在交点相遇（或同时到 `None`），因为两人总步数都是 `lenA+lenB`。

## 怎么做
1. 令 `p = l1`、`q = l2`，循环条件 `p is not q`。
2. 每轮 `p` 走一步，走空就跳到 `l2`；`q` 同理跳到 `l1`。
3. 循环结束时 `p` 就是交点或 `None`，直接返回。

拿示例 1 走关键一步：`l1=[4,1,8,4,5]` 长 5，`l2=[5,0,1,8,4,5]` 长 6。`p` 走 5 步到 `None` 后跳到 `l2` 头，`q` 走 6 步到 `None` 后跳到 `l1` 头。此时 `p` 在 `l2` 上已走 1 步（值 5），`q` 在 `l1` 上已走 0 步（值 4）；再各走 2 步，`p` 到值 8 的节点、`q` 也到值 8 的节点，`p is q` 成立，返回该节点。

```python
p, q = l1, l2
while p is not q:
    p = p.next if p else l2
    q = q.next if q else l1
return p
```

注意 `p.next if p else l2` 这一行：`p` 为 `None` 时才换链，不是 `p.next` 为 `None` 时换，写错会跳过交点。

## 复杂度
时间 O(m+n)：`p`、`q` 各走至多 `m+n` 步，m、n 为两链长度。
空间 O(1)：只开了 `p`、`q` 两个指针，没建集合也没改链表。

## 易错点
- 用 `p.val == q.val` 判相交 → 示例 1 中 `l1` 的值 4 和 `l2` 的值 4 会误判成交点 → 必须用 `p is q` 比节点身份，题目要的是同一个节点而非同值。
- 换链写成 `p = p.next if p.next else l2` → 示例 3 两链不相交时，`p` 走到尾节点就直接跳 `l2`，少走一步，两指针错位永远碰不上，死循环 → 判空条件必须是 `p` 本身为 `None`。

## 如果面试官追问
问：不许改链表、也不许用双指针换链，还能 O(1) 空间吗？
答：先各求长度差 `d`，长链先走 `d` 步再同步走，同样 O(1) 空间，只是多扫一遍求长度。
