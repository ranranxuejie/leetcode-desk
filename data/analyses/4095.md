## 一句话思路
固定右端点 r，用「首次出现位置单调 + 频次阶梯只可能从少数左端点成立」的双指针/哈希维护候选左端点集合。

## 怎么做
1. 枚举右端点 r，维护窗口内每个值的出现次数 `cnt` 和首次出现位置 `first`。
2. 关键观察：合法子数组的左端点 l 必须满足「l 是某个值的首次出现位置」，且这些值按首次出现顺序的频次恰为 1,2,...,k。
3. 用 `pos` 记录每个值首次出现下标，候选 l 只能是这些 `pos` 值；对每个 r 检查候选。
4. 以 `nums=[5,8,8,2,2,2]`、r=5 为例：`cnt={5:1,8:2,2:3}`，`first={5:0,8:1,2:3}`，按首次出现排序得频次 `[1,2,3]`，l=0 合法，答案 +1。

```python
from collections import defaultdict

def countStaircase(nums):
    n = len(nums)
    ans = 0
    for l in range(n):
        cnt = defaultdict(int)
        order = []
        for r in range(l, n):
            v = nums[r]
            if cnt[v] == 0:
                order.append(v)
            cnt[v] += 1
            ok = all(cnt[order[i]] == i + 1 for i in range(len(order)))
            if ok:
                ans += 1
    return ans
```

上面是 O(n²) 暴力，仅用于说明判定逻辑；实际需用双指针把候选 l 压缩到 O(1) 均摊。

## 复杂度
时间：暴力 O(n²)，优化后 O(n)，n 为 nums 长度，每个元素进出窗口一次。
空间：O(n)，`cnt` 和 `first` 各存至多 n 个不同值。

## 易错点
- 输入 `[6,6,9,9]`：若只按「频次集合是 {1,2}」判定，会把 `[6,6,9]` 误判合法（频次 [2,1] 顺序错）→ 必须严格按首次出现顺序核对第 i 个值频次等于 i+1。
- 输入 `[2,3,4,4,3,4]`：若忽略「首次出现顺序」，会把 `[3,4,4,3]` 当成 [2,2] 合法 → 正确做法是维护 `order` 列表，逐个比对 `cnt[order[i]] == i+1`。

## 如果面试官追问
问：n 扩大到 10^6 怎么办？
答：用双指针维护候选左端点集合，每个 r 只增删 O(1) 个候选，总 O(n)。
