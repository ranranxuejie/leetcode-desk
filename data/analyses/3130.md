## 一句话思路
用 `dp0[i][j]`/`dp1[i][j]` 记以 0/1 结尾、用 i 个 0 和 j 个 1 的稳定数组数，靠前缀和把「连续段长度 ≤ limit」的转移压到 O(1)。

## 怎么做
1. 定义 `dp0[i][j]`：恰好用 i 个 0、j 个 1，且末位是 0 的稳定数组数；`dp1` 对称。
2. 末位是 0 时，末尾那段连续的 0 长度可以是 1..limit，前面接一个末位为 1 的数组（或整段就是全部 0）：`dp0[i][j] = sum(dp1[i-k][j] for k in 1..limit)`，其中 k 是末尾 0 的个数。
3. 用前缀和 `pre1[i][j] = dp1[0..i][j]` 的列前缀，把上面的求和变成 `pre1[i-1][j] - pre1[i-limit-1][j]`，O(1) 出值。
4. 边界：`dp0[i][0] = 1 if i <= limit else 0`（全 0 数组），`dp1[0][j]` 同理；答案 `dp0[zero][one] + dp1[zero][one]`。

以示例 3 `zero=3, one=3, limit=2` 为例，算到 `dp0[2][1]`：末尾 0 段长 1 时接 `dp1[1][1]`，段长 2 时接 `dp1[0][1]`，而 `dp1[0][1]=1`（数组 `[1]`）、`dp1[1][1]=1`（`[1,0]` 末位是 0 不算，实际是 `[0,1]`），故 `dp0[2][1]=2`，对应 `[1,0,0]` 与 `[0,1,0]`。

```python
MOD = 10**9 + 7
dp0 = [[0]*(one+1) for _ in range(zero+1)]
dp1 = [[0]*(one+1) for _ in range(zero+1)]
for i in range(1, min(zero, limit)+1): dp0[i][0] = 1
for j in range(1, min(one, limit)+1): dp1[0][j] = 1
# pre0[i][j] = dp0[0][j]+...+dp0[i][j]
for i in range(1, zero+1):
    for j in range(1, one+1):
        lo = max(0, i-limit)
        dp0[i][j] = (pre1[i-1][j] - (pre1[lo-1][j] if lo else 0)) % MOD
        lo = max(0, j-limit)
        dp1[i][j] = (pre0[i][j-1] - (pre0[i][lo-1] if lo else 0)) % MOD
    # 同步更新 pre0/pre1 的当前行
```

## 复杂度
时间 O(zero × one)，两层循环各走一遍，前缀和把内层 limit 求和消掉。
空间 O(zero × one)，开了 dp0/dp1 两张表（可滚动成一维，但本题 1000×1000 够用）。

## 易错点
- `limit >= zero` 时全 0 数组合法，若把边界写成 `i < limit` 会漏掉 `[0,0,...,0]` 这一种，示例 1 的 `limit=2, zero=1` 就会少算。
- 前缀和下标 `i-limit-1` 在 `i-limit == 0` 时会取到 -1，Python 里 `pre[-1]` 是最后一行而非 0，必须显式判 `lo == 0` 时减 0，否则 `zero=3, one=3, limit=2` 会算出负数或错值。

## 如果面试官追问
问：若要求输出所有稳定数组而非计数？答：把 dp 换成「以 (i,j,末位) 为键存列表」，回溯时按末尾段长 1..limit 展开，复杂度变成输出规模乘以 limit。
