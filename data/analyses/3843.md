## 一句话思路
先统计每个值的频率，再统计每个频率出现几次，最后按原数组顺序找第一个频率计数为 1 的值。

## 怎么做
1. 用 `Counter(nums)` 得到 `freq`，键是元素值、值是出现次数。
2. 用 `Counter(freq.values())` 得到 `freq_cnt`，键是频率、值是有多少个元素恰好是这个频率。
3. 从左到右遍历 `nums`，第一个满足 `freq_cnt[freq[x]] == 1` 的 `x` 就是答案。
4. 遍历完没有就返回 `-1`。

以示例 1 `nums = [20,10,30,30]` 为例：`freq = {20:1, 10:1, 30:2}`，`freq_cnt = {1:2, 2:1}`。扫描到 20 时 `freq_cnt[1] == 2` 跳过，10 同理，30 时 `freq_cnt[2] == 1`，返回 30。

```python
from collections import Counter

freq = Counter(nums)
freq_cnt = Counter(freq.values())
for x in nums:
    if freq_cnt[freq[x]] == 1:
        return x
return -1
```

关键点：判断的是「频率」是否唯一，不是「元素」是否唯一。示例 2 中 `freq = {20:2, 10:1, 30:3}`，`freq_cnt` 三个键的值都是 1，所以第一个元素 20 直接命中。

## 复杂度
时间：O(n)，`Counter(nums)` 和最后一遍扫描各 O(n)，n 是 `len(nums)`。
空间：O(n)，`freq` 和 `freq_cnt` 最多各存 n 个不同键。

## 易错点
- 输入 `[20,10,30,30]` → 若直接返回第一个只出现一次的元素，会错成 20；正确做法是先看 `freq_cnt[freq[x]]`，20 的频率 1 被 10 共享，不唯一，应返回 30。
- 输入 `[10,10,20,20]` → 若只判断 `freq[x] == 1` 会漏掉「频率 2 也不唯一」的情况，错成 -1 之前误判；正确做法是必须用 `freq_cnt` 统计频率的重复度，这里 `freq_cnt = {2:2}`，所有元素频率都不唯一，返回 -1。

## 如果面试官追问
问：如果要求返回所有频率唯一的元素而非第一个？
答：把最后一遍扫描改成遍历 `freq` 的键，收集 `freq_cnt[freq[x]] == 1` 的值，顺序按首次出现位置排。
