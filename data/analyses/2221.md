## 一句话思路
逐层原地压缩：每轮把 `nums[i]` 更新为 `(nums[i] + nums[i+1]) % 10`，长度减一，直到只剩一个元素。

## 怎么做
1. 外层循环让 `n` 从 `len(nums)` 递减到 1，每轮只处理前 `n-1` 个位置。
2. 内层 `for i in range(n - 1)` 执行 `nums[i] = (nums[i] + nums[i+1]) % 10`，因为 `nums[i+1]` 还没被本轮覆盖，原地写安全。
3. 每轮结束 `n -= 1`，最后一轮 `n == 1` 时内层不执行，循环退出。
4. 返回 `nums[0]`。

以 `nums = [1,2,3,4,5]` 为例，第一轮后变成 `[3,5,7,9]`（`(1+2)%10=3`、`(2+3)%10=5`、`(3+4)%10=7`、`(4+5)%10=9`），第二轮 `[8,2,6]`，第三轮 `[0,8]`，第四轮 `[8]`，返回 8。

```python
n = len(nums)
while n > 1:
    for i in range(n - 1):
        nums[i] = (nums[i] + nums[i + 1]) % 10
    n -= 1
return nums[0]
```

关键点：内层必须从左往右、且只写到 `n-1`。若从右往左写，`nums[i+1]` 已被本轮改过，`[1,2,3,4,5]` 第一轮会算成 `[3,5,7,9]` 之外的值；若写到 `n-1` 之外会越界。

## 复杂度
时间：O(n²)，每轮长度减一，总操作数 n+(n-1)+…+1。
空间：O(1)，只改原数组，没有额外开 newNums。

## 易错点
- 输入 `[1,2,3,4,5]` 时若从右往左更新，`nums[3]` 先变成 `(4+5)%10=9`，再算 `nums[2]=(3+9)%10=2`，正确应为 7 → 必须从左往右，保证 `nums[i+1]` 是上一轮的值。
- 输入 `[5]`（n=1）时若写成 `while n > 0` 并在内层访问 `nums[i+1]`，`range(0)` 虽不执行但循环体会多跑一轮 → 条件必须是 `n > 1`，直接返回 `nums[0]`。

## 如果面试官追问
若 n 放大到 10^5 并要求更快？答：答案是 Σ C(n-1,i)·nums[i] mod 10，用组合数递推 O(n) 算，注意模 10 下不能直接除，需用杨辉三角或 Lucas。
