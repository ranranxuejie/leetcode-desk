## 一句话思路
用二分查找第一个「缺失数个数 ≥ k」的位置，答案由该位置的前一个元素推出。

## 怎么做
1. 定义 `missing(i) = arr[i] - i - 1`，表示 `arr[i]` 之前（含自身位置前）缺失的正整数个数。
2. 该函数随 `i` 单调不减，因此可二分找第一个 `missing(i) >= k` 的下标 `lo`。
3. 若所有位置都满足 `missing < k`，答案直接是 `arr[-1] + (k - missing(len(arr)-1))`；否则答案是 `arr[lo-1] + (k - missing(lo-1))`（`lo=0` 时用 `k` 本身）。

以 `arr = [2,3,4,7,11], k = 5` 为例：`missing` 依次为 `1,1,1,3,6`。二分找到 `lo = 4`（`missing(4)=6 >= 5`），前一个 `i=3` 时 `missing=3`，答案 `arr[3] + (5-3) = 7+2 = 9`。

```python
lo, hi = 0, len(arr)
while lo < hi:
    mid = (lo + hi) // 2
    if arr[mid] - mid - 1 >= k:
        hi = mid
    else:
        lo = mid + 1
if lo == 0:
    return k
prev = lo - 1
return arr[prev] + (k - (arr[prev] - prev - 1))
```

关键中间值：`lo=4` 时 `prev=3`，`arr[3]=7`，`missing(3)=3`，补 `k-missing=2` 得 9。

## 复杂度
时间：二分 `O(log n)`，`n` 为 `arr` 长度。
空间：`O(1)`，只开了 `lo/hi/mid/prev` 几个变量。

## 易错点
- `arr = [1,2,3,4], k = 2`：若直接用 `arr[lo-1] + k` 会错成 `4+2=6` 看似对，但换成 `arr=[1,2], k=3` 就错成 `2+3=5`（正确是 5？实际缺失是 3,4,5，第 3 个是 5，恰好对；真正翻车在 `arr=[2], k=1`，`lo=0` 时 `arr[-1]+k` 得 `2+1=3`，正确是 1）→ 必须单独处理 `lo==0` 返回 `k`。
- `arr` 全不缺失（`arr=[1,2,3,4]`）：`missing` 恒为 0，二分 `lo` 落到 `len(arr)`，此时 `prev=len-1`，`arr[3]+(2-0)=6` 正确；但若误把 `hi` 初始化为 `len(arr)-1`，`lo` 停在 3，`prev=2`，得 `3+2=5` 错 → `hi` 必须取 `len(arr)` 作为哨兵。

## 如果面试官追问
问：若 `arr` 允许重复元素怎么办？答：`missing` 不再单调，二分失效，需先按值去重或改用线性扫描累加缺失计数。
