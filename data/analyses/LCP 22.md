## 一句话思路
枚举涂黑的行数 `r` 和列数 `c`，用 `r*n + c*n - r*c == k` 判定，方案数累加 `C(n,r)*C(n,c)`。

## 怎么做
1. 双重循环枚举 `r` 从 0 到 `n`、`c` 从 0 到 `n`，`r`、`c` 是涂黑的行列数。
2. 黑色格子数 = 行覆盖 + 列覆盖 − 重叠，即 `r*n + c*n - r*c`，等于 `k` 才计入。
3. 该组合的方案数是 `comb(n, r) * comb(n, c)`，累加到答案。
4. 以 `n=2, k=2` 为例：`(r,c)=(0,1)` 得 `0+2-0=2`，贡献 `C(2,0)*C(2,1)=2`；`(1,0)` 同理贡献 2；`(1,1)` 得 `2+2-1=3≠2` 跳过；合计 4。

```python
from math import comb

def paintingPlan(n, k):
    ans = 0
    for r in range(n + 1):
        for c in range(n + 1):
            if r * n + c * n - r * c == k:
                ans += comb(n, r) * comb(n, c)
    return ans
```

关键中间值：`n=2, k=2` 时 `(r,c)=(1,1)` 算出 `2+2-1=3`，与 `k=2` 不等，被正确排除——重叠区只算一次是公式成立的核心。

## 复杂度
时间：`O(n^2)`，双重循环各 `n+1` 次，`comb` 在 `n≤6` 下可视为常数。
空间：`O(1)`，只存 `ans`，无额外数组。

## 易错点
- `k=0` 时若从 `r=1` 开始枚举 → 漏掉「一行一列都不涂」这一种方案 → 必须让 `r`、`c` 都从 0 起，`(0,0)` 贡献 `C(n,0)*C(n,0)=1`。
- 把黑色格子数写成 `r*n + c*n` 漏减重叠 → `n=2, k=3` 时 `(1,1)` 会算成 4 而错判 → 必须减 `r*c`，因为交叉格被涂了两次。

## 如果面试官追问
问：若 `n` 放大到 `10^9` 怎么求？
答：`k` 固定时枚举 `r`，由 `r*n + c*(n-r) = k` 解出 `c = (k - r*n) // (n - r)`，只需验证整除且 `0≤c≤n`，降到 `O(n)`；再大就要靠数论分解。
