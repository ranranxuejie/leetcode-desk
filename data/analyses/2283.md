## 一句话思路
用长度 10 的计数数组统计每个数字出现次数，再逐位比对 `cnt[i] == int(num[i])`。

## 怎么做
1. 建 `cnt = [0] * 10`，遍历 `num` 的每个字符 `ch`，执行 `cnt[int(ch)] += 1`。
2. 再遍历下标 `i` 从 0 到 `len(num) - 1`，比较 `cnt[i]` 与 `int(num[i])`。
3. 任一位不等立即返回 `False`，全部相等返回 `True`。

以 `num = "1210"` 为例：第一遍扫完得到 `cnt = [1, 2, 1, 0, 0, 0, 0, 0, 0, 0]`；第二遍 `i = 0` 时 `cnt[0] = 1` 与 `num[0] = '1'` 相等，`i = 1` 时 `cnt[1] = 2` 与 `'2'` 相等，四位全过，返回 `True`。

```python
cnt = [0] * 10
for ch in num:
    cnt[int(ch)] += 1
for i in range(len(num)):
    if cnt[i] != int(num[i]):
        return False
return True
```

关键点：`cnt` 的下标是「数字」，`num` 的下标是「位置」，两者靠 `i` 对齐——题目要求恰好是「位置 i 上的数字值 = 数字 i 的出现次数」，所以第二遍循环必须用 `i` 同时索引两边。

## 复杂度
时间 O(n)：两遍扫描，n 为 `num` 长度，计数数组固定 10 次。
空间 O(1)：只开了长度 10 的 `cnt`，与 n 无关。

## 易错点
- 输入 `"030"` → 若只统计不比对，会误判为 `True`；实际 `cnt[0] = 2` 而 `num[0] = '0'`，`cnt[1] = 0` 而 `num[1] = '3'`，两处不等，必须返回 `False`。
- 输入 `"1"` 这类短串 → 若循环写成 `for i in range(10)` 去比 `num[i]`，会越界；正确做法是只遍历 `range(len(num))`，因为 `num` 长度可能小于 10，超出部分的位置 i 根本不存在。

## 如果面试官追问
若 n 放大到 10^5 且数字范围不止 0-9？答：计数数组改成字典，第二遍只遍历 `num` 中实际出现的位置，逻辑不变。
