## 一句话思路
固定左端点 i，用前缀和把 mid 右端点 j 的合法区间算成两个二分边界，区间长度即方案数。

## 怎么做
1. 先算前缀和 `pre`，`pre[k]` 表示 `nums[0..k-1]` 的和，这样任意子数组和都是两个前缀相减。
2. 枚举左段终点 `i`（`left = pre[i+1]`），mid 从 `i+1` 开始，right 至少留一个元素，所以 `j` 的上界是 `n-2`。
3. 对每个 `i`，二分找 `j` 的下界：最小的 `j` 使 `pre[j+1]-pre[i+1] >= left`；再二分找上界：最大的 `j` 使 `pre[j+1]-pre[i+1] <= pre[n]-pre[j+1]`。
4. 两个边界都落在 `[i+1, n-2]` 内时，`hi-lo+1` 累加进答案，最后对 `10**9+7` 取余。

拿示例 2 `nums = [1,2,2,2,5,0]` 说：`pre = [0,1,3,5,7,12,12]`。`i=0` 时 `left=1`，下界二分得 `j=1`（mid 和 2 ≥ 1），上界要求 mid 和 ≤ right 和，`j=1` 时 mid=2、right=10 成立，`j=2` 时 mid=4、right=8 成立，`j=3` 时 mid=6、right=6 成立，`j=4` 时 mid=11 > right=1 不成立，故 `j∈[1,3]`，贡献 3。`i=1` 时 `left=3`，`j=1` 的 mid=2 < 3 不合法，无贡献。合计 3。

```python
pre = [0]
for x in nums:
    pre.append(pre[-1] + x)
n, MOD, ans = len(nums), 10**9 + 7, 0
for i in range(n - 2):
    left = pre[i + 1]
    lo = bisect_left(pre, pre[i + 1] + left, i + 2, n) - 1
    hi = bisect_right(pre, (pre[n] + pre[i + 1]) // 2, i + 2, n) - 1
    lo, hi = max(lo, i + 1), min(hi, n - 2)
    if lo <= hi:
        ans = (ans + hi - lo + 1) % MOD
```

## 复杂度
时间：外层 n 次，每次两次二分 O(log n)，共 O(n log n)。
空间：前缀和数组 `pre` 占 O(n)，其余常数。

## 易错点
- `nums` 含大量 0（如 `[0,0,0,0]`）→ 下界二分可能返回 `i` 之前的位置，把空 mid 算进去 → 必须 `max(lo, i+1)` 保证 mid 非空。
- 上界用 `(pre[n] + pre[i+1]) // 2` 时，若直接对 `pre` 二分而忘了 `hi` 上限 `n-2`，会把 right 为空的分割算进来 → 必须 `min(hi, n-2)`。

## 如果面试官追问
问：要求输出所有方案而不是计数？答：把二分改成双指针滑动 `j`，每个合法 `j` 直接产出 `(i, j)` 三元组，复杂度仍是 O(n log n + 方案数)。
