## 一句话思路
用区间 DP 枚举所有「任意运算顺序」的结果集合，正确答案单独按规则算，答案落在集合里就得分。

## 怎么做
1. 把 s 拆成数字数组 `nums` 和运算符数组 `ops`，长度分别为 m+1 和 m。
2. `dp[i][j]` 表示 nums[i..j] 用任意运算顺序能得到的所有结果集合，用 `set` 存。
3. 枚举区间长度和分割点 k，把 `dp[i][k]` 与 `dp[k+1][j]` 按 `ops[k]` 两两组合。
4. 正确答案按「先乘后加」单独算一次，再遍历 answers 打分。

以 `s = "3+5*2"` 为例：`nums=[3,5,2]`，`ops=['+','*']`。`dp[0][2]` 由 k=0 得 `3+dp[1][2]={3+10}={13}`，由 k=1 得 `dp[0][1]*2={8*2}={16}`，集合为 `{13,16}`。正确答案 13 得 5 分，16 在集合里得 2 分，其余 0 分，合计 19。

```python
nums = [int(c) for c in s if c.isdigit()]
ops = [c for c in s if c in '+*']
m = len(ops)
dp = [[set() for _ in range(m + 1)] for _ in range(m + 1)]
for i in range(m + 1):
    dp[i][i].add(nums[i])
for length in range(2, m + 2):
    for i in range(m + 2 - length):
        j = i + length - 1
        for k in range(i, j):
            for a in dp[i][k]:
                for b in dp[k + 1][j]:
                    dp[i][j].add(a + b if ops[k] == '+' else a * b)
valid = dp[0][m]
```

正确答案用栈或一次扫描：遇 `*` 立即与栈顶相乘，遇 `+` 压栈，最后求和。

## 复杂度
时间：O(m³ · V²)，m≤15 运算符，V 为单区间结果数上界，实际远小于理论上限。
空间：O(m² · V)，即 dp 表里所有 set 的元素总数。

## 易错点
- `s = "6+0*1"` 时正确答案 6 也在错误顺序集合里 → 若先判「在集合中」再判正确值，会把 6 判成 2 分 → 必须先判 `ans == correct` 给 5 分，再判 `ans in valid` 给 2 分。
- `s = "7+3*1*2"` 中 20 来自 `(7+3)*1*2`，若 DP 只按「相邻两数先算」枚举会漏掉这种跨段组合 → 必须用区间分割 `dp[i][k]` 与 `dp[k+1][j]` 全组合，不能只做线性扫描。

## 如果面试官追问
问：运算符到 100 个怎么办？
答：结果集合会爆炸，改用「只判断 answers 中每个值是否可达」的记忆化搜索，按目标值剪枝。
