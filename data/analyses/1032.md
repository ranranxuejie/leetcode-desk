## 一句话思路
把 words 全部**反转**建字典树，查询时维护字符流反转后的最长 200 前缀，沿树走一遍即可。

## 怎么做
1. 建树时对每个 `w` 反转后插入，节点用 `dict` 存子节点，末尾节点打 `end=True`。
2. 维护一个 `buf` 保存最近收到的字符（反转顺序），长度上限取 `max(len(w))`。
3. 每次 `query(letter)` 把 `letter` 插到 `buf` 头部，然后从根沿 `buf` 逐字符下走，走到 `end` 就返回 `True`。

以官方示例 `words=["cd","f","kl"]` 为例，树根下有 `d`、`f`、`l` 三条边。收到 `'c'` 时 `buf="c"`，根无 `c` 边，返回 `False`；收到 `'d'` 时 `buf="dc"`，先走 `d`（非 end），再走 `c` 命中 `end`，返回 `True`。

```python
def build(words):
    root = {}
    for w in words:
        node = root
        for ch in reversed(w):
            node = node.setdefault(ch, {})
        node['#'] = True
    return root

def query(letter):
    buf.insert(0, letter)
    if len(buf) > limit: buf.pop()
    node = root
    for ch in buf:
        if ch not in node: return False
        node = node[ch]
        if node.get('#'): return True
    return False
```

关键中间值：`buf` 是**反转后**的流前缀，所以 `"cd"` 在树里对应路径 `d→c`，与 `buf="dc"` 顺序一致。

## 复杂度
时间：建树 O(Σ|w|)，每次 query 最多走 `limit ≤ 200` 步，总 O(Q·200)。
空间：字典树 O(Σ|w|) 个节点，`buf` 额外 O(200)。

## 易错点
- 忘记反转：`words=["cd"]` 直接正序建树，收到 `'c'` 时根无 `c` 边直接 `False`，收到 `'d'` 也走不通，永远匹配不到 `"cd"`。正确做法是插入和 `buf` 都按反转顺序。
- `buf` 不截断：查询 4×10⁴ 次后 `buf` 长达 4×10⁴，每次 query 都全量遍历，退化成 O(Q²)。正确做法是 `limit = max(len(w))`，超出就 `pop()` 尾部。

## 如果面试官追问
问：如果 words 里字符串很长（比如 10⁵）怎么办？
答：`buf` 上限跟着变长，单次 query 最坏 O(10⁵)，此时改用 AC 自动机在流上增量匹配更稳。
