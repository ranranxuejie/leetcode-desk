## 一句话思路
用栈维护「当前路径」，按每个节点前导短横线数得到深度，弹出栈中深度不小于它的节点后挂到新栈顶。

## 怎么做
1. 扫描字符串，先数连续 `-` 得 `depth`，再读连续数字得 `val`。
2. 栈里存的是从根到当前节点父节点的路径，`len(stack)` 恰好等于「下一个节点应有的父深度 + 1」。
3. 当 `len(stack) > depth` 时不断 `pop`，直到栈顶就是新节点的父节点。
4. 新节点挂到栈顶的 `left`（若空）否则 `right`，再 `push` 自己。

以 `"1-2--3--4-5--6--7"` 为例：读到 `3` 时 `depth=2`，栈为 `[1,2]`，`len=2` 不大于 2，直接挂到 `2.left`；读到 `4` 时 `depth=2`，栈为 `[1,2,3]`，`len=3>2` 弹掉 `3`，栈变 `[1,2]`，挂到 `2.right`。这一步是整题唯一需要想清楚的地方：**深度相等意味着是兄弟，必须弹栈**。

```python
stack = []
i = 0
while i < len(traversal):
    depth = 0
    while traversal[i] == '-':
        depth += 1
        i += 1
    val = 0
    while i < len(traversal) and traversal[i].isdigit():
        val = val * 10 + int(traversal[i])
        i += 1
    node = TreeNode(val)
    while len(stack) > depth:
        stack.pop()
    if stack:
        if stack[-1].left is None:
            stack[-1].left = node
        else:
            stack[-1].right = node
    stack.append(node)
```

## 复杂度
时间 O(n)：每个字符被 `i` 扫一次，每个节点最多入栈出栈各一次。
空间 O(h)：栈深等于树高，最坏链状 O(n)，另加输出树本身。

## 易错点
- 输入 `"1-2--3---4-5--6---7"` → 若用 `len(stack) == depth` 判断父子，读到 `4`（depth=3）时栈为 `[1,2,3]`，`len=3` 相等会误挂成 `3` 的左子，实际应是 `3` 的左子没错但 `7`（depth=3）会挂错；正确做法是统一用 `while len(stack) > depth: pop()`，让「弹到深度恰好」成为唯一规则。
- 输入 `"1-401--349---90--88"` → 若用 `traversal[i] != '-'` 判断数字结束，`401` 会被正确读完，但若在数完 `-` 后忘记重置 `val=0`，`349` 会累加成 `401349`；正确做法是每轮循环开头把 `val` 重新置 0，且用 `isdigit()` 而非 `!= '-'` 界定数字。

## 如果面试官追问
问：节点数涨到 10^6 怎么办？答：字符串扫描仍是 O(n)，但递归建树会爆栈，改成显式栈（如上）即可，深度只受内存限制。
