## 一句话思路
用前缀和 `pre[i]` 对 k 取余，同余的两个前缀和之差就是长度被 k 整除的子数组和，边扫边存每个余数的最早前缀和。

## 怎么做
1. 令 `pre[0]=0`，`pre[i]=nums[0]+...+nums[i-1]`，答案子数组 `nums[j..i-1]` 的和是 `pre[i]-pre[j]`，长度 `i-j` 被 k 整除等价于 `i%k==j%k`。
2. 用字典 `first` 记录每个余数 `r` 第一次出现的下标，初始化 `first={0:0}`，因为 `pre[0]=0` 在余数 0 处、下标 0。
3. 从左到右扫 `i=1..n`，累加 `pre`，算 `r=pre%k`（Python 负数取模结果非负，正好可用）；若 `r` 已在 `first` 中，就用 `pre-first[r]` 更新答案。
4. 若 `r` 不在 `first` 中才写入 `first[r]=i`，保留最早下标才能让差值最大。

以 `nums=[-5,1,2,-3,4], k=2` 为例：`pre` 依次为 `-5,-4,-2,-5,-1`，取模得 `1,0,0,1,1`。`i=2` 时 `r=0` 命中 `first[0]=0`，候选 `-4-0=-4`；`i=3` 时 `r=0` 命中 `first[0]=0`，候选 `-2`；`i=5` 时 `r=1` 命中 `first[1]=1`，候选 `-1-(-5)=4`，即子数组 `[1,2,-3,4]`，答案 4。

```python
first = {0: 0}
pre = 0
ans = -2**63
for i, x in enumerate(nums, 1):
    pre += x
    r = pre % k
    if r in first:
        ans = max(ans, pre - first[r])
    else:
        first[r] = i
return ans
```

## 复杂度
时间 O(n)：一次遍历，每个元素做一次取模和一次字典查询。
空间 O(min(n,k))：`first` 最多存 k 个余数，前缀和只用单个变量 `pre`。

## 易错点
- `nums=[-1,-2,-3,-4,-5], k=4` 全为负数 → 若把 `ans` 初始化成 0，会返回 0，但合法子数组和必为负 → 应初始化成 `-2**63`（或 `float('-inf')` 再转 int），保证 `[-1,-2,-3,-4]` 的 `-10` 能被取到。
- 同余时若用「最新下标」覆盖 `first[r]` → 对 `nums=[1,2], k=1` 这种只有余数 0 的情况，`i=1` 写入 `first[0]=1` 后 `i=2` 只能得 `3-2=1`，丢掉 `[1,2]` 的 3 → 必须只在 `r not in first` 时写入，保留最早下标。

## 如果面试官追问
要求返回子数组本身而非和？答：`first` 里存下标即可，命中时记下 `(first[r], i)` 这对端点，最后切片还原。
