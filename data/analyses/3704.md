## 一句话思路
按十进制逐位做数位 DP，统计每位上 a、b 两数字均非 0 且相加（含进位）等于 n 该位的方案数，各数位方案数相乘。

## 怎么做
1. 把 n 的十进制位从低位到高位取出，记作 `digits`，并维护进位 `carry`（初值 0）。
2. 对每一位目标数字 `d`，枚举 a 该位 `x` 与 b 该位 `y`，都取 1..9，要求 `x + y + carry` 的个位等于 `d`，新进位为 `(x + y + carry) // 10`。
3. 用 DP 记录「处理到第 i 位、进位为 c」的方案数，逐位转移；最终答案是处理完所有位且进位为 0 的方案数。
4. 关键中间值：以 n = 11 为例，`digits = [1, 1]`。第 0 位 d=1、carry=0，需 `x+y` 个位为 1，即 `x+y=11`，有 (2,9)…(9,2) 共 8 组，新进位 1；第 1 位 d=1、carry=1，需 `x+y+1` 个位为 1 即 `x+y=10`，但 x,y≥1 时最小为 2、且要进位后仍为 0，无解使最终 carry=0，故只有第 0 位那 8 组在「无更高位」时成立——实际 n=11 的答案 8 正来自这里，高位必须让 a、b 都不再延伸。

```python
digits = list(map(int, str(n)[::-1]))
# dp[c] = 处理到当前位、进位为 c 的方案数
dp = {0: 1}
for d in digits:
    ndp = {}
    for c, ways in dp.items():
        for x in range(1, 10):
            for y in range(1, 10):
                s = x + y + c
                if s % 10 == d:
                    nc = s // 10
                    ndp[nc] = ndp.get(nc, 0) + ways
    dp = ndp
ans = dp.get(0, 0)
```

## 复杂度
时间：O(log n × 81 × 2)，位数 log n 主导，每位 9×9 枚举与 2 种进位。
空间：O(1)，只开两个长度 ≤2 的进位字典。

## 易错点
- n = 2 时若允许 a 或 b 取 0，会多算 (0,2)、(2,0)；本题 a、b 必须是正整数，x、y 枚举从 1 开始，别从 0 起。
- n = 11 时若忽略「最高位之后进位必须归零」，会把第 1 位 carry=1 的中间态也算进答案，得到大于 8 的结果；最后必须取 `dp[0]` 而非所有进位求和。

## 如果面试官追问
问：若要求输出所有数对而非计数？答：把 DP 的 ways 换成方案列表，逐位拼接 x、y 的十进制串，回溯时按位还原即可，代价是输出规模。
