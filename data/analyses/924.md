## 一句话思路
先求连通块，再统计每块里有几个 `initial` 节点：只有恰好 1 个的块，删掉那个节点才能救下整块。

## 怎么做
1. 用 DFS/并查集把 `graph` 划分成连通块，记录每个节点所属的块 `comp[i]` 和每块大小 `size[c]`。
2. 遍历 `initial`，统计每块被感染的节点数 `cnt[c]`，同时记下该块唯一的感染源（若 `cnt[c] == 1`）。
3. 对每个 `initial` 中的 `u`，若 `cnt[comp[u]] == 1`，它能救下 `size[comp[u]]` 个节点；取救下最多者，平局取索引最小。
4. 若没有任何块满足 `cnt == 1`（如示例 2 中 0 和 2 各自独立），则救不下任何节点，直接返回 `min(initial)`。

以示例 1 为例：`graph` 中 0、1 相连成块 `{0,1}`，大小 2；节点 2 独立，大小 1。`initial=[0,1]` 都落在第一块，`cnt=2`，不满足 `cnt==1`，所以救不下任何节点，返回 `min(initial)=0`。

```python
n = len(graph)
comp = [-1] * n
size = []
for s in range(n):
    if comp[s] != -1: continue
    cid = len(size); stack = [s]; comp[s] = cid; cnt_nodes = 0
    while stack:
        u = stack.pop(); cnt_nodes += 1
        for v in range(n):
            if graph[u][v] and comp[v] == -1:
                comp[v] = cid; stack.append(v)
    size.append(cnt_nodes)
cnt = [0] * len(size)
for u in initial: cnt[comp[u]] += 1
best, best_save = min(initial), -1
for u in initial:
    c = comp[u]
    if cnt[c] == 1 and size[c] > best_save:
        best_save, best = size[c], u
    elif cnt[c] == 1 and size[c] == best_save and u < best:
        best = u
```

## 复杂度
时间：O(n²)，邻接矩阵每个格子访问一次，DFS 与统计都是这个量级。
空间：O(n)，`comp`、`size`、`cnt` 和 DFS 栈各占 O(n)。

## 易错点
- 输入 `graph=[[1,1,0],[1,1,0],[0,0,1]], initial=[0,1]` → 若误以为删掉 0 能救下节点 1，会返回 0 但理由是错的；正确做法是先看 `cnt[comp[0]]==2`，整块有两个感染源，删谁都救不下，只能按 `min(initial)` 返回 0。
- 输入 `graph=[[1,1,1],[1,1,1],[1,1,1]], initial=[1,2]` → 若只比较「删掉后剩余感染数」而不看块大小，会误选 1 或 2 中任意一个；正确做法是整块 `cnt==2` 不满足条件，退化为 `min(initial)=1`，与示例 3 一致。

## 如果面试官追问
问：若 `initial` 很大、`n` 到 10⁵ 且图用边列表给出，怎么改？
答：并查集按边合并，再按根聚合 `cnt` 和 `size`，复杂度降到 O(n α(n))。
