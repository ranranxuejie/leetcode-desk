## 一句话思路
按 n 的奇偶分两类：偶数时每刀都是过圆心的直径，一刀出两块；奇数时每刀只能从圆心切到圆上，一刀出一块。

## 怎么做
1. 判断 `n % 2 == 0`，偶数走直径方案，返回 `n // 2`。
2. 奇数时直径切不出等分（n=3 时直径把圆分成 2 块，无法再均分），只能全用半径刀，返回 `n`。
3. 特判 `n == 1`：圆本身就是 1 等分，不需要切，返回 0，否则会错答成 1。

以 `n = 4` 为例：`4 % 2 == 0`，走第一支，`n // 2 = 2`，即两条互相垂直的直径，一刀落下同时切开两段圆弧，2 刀得 4 块。以 `n = 3` 为例：`3 % 2 == 1`，走第二支返回 3，三条半径各占 120°，每刀只新增一块。

```python
def numberOfCuts(n):
    if n == 1:
        return 0
    if n % 2 == 0:
        return n // 2
    return n
```

关键在「一刀能新增几块」：直径刀两端都在圆上且过圆心，一刀同时贯穿两条半径方向，等价于两刀半径，所以偶数能省一半；奇数时若用一条直径，剩下两侧各是半圆，要再均分成 (n-2)/2 份，每份角度不是整圆等分角，凑不出等面积，因此直径在奇数情形下不可用。

## 复杂度
时间：O(1)，只做一次取模和一次整除，与 n 无关。
空间：O(1)，没有开任何额外容器。

## 易错点
- 输入 `n = 1` → 若直接套 `n // 2` 或返回 `n`，会错成 0 之外的 1；正确做法是先特判返回 0，因为圆本身已是 1 等分。
- 输入 `n = 3` → 若误以为「一刀最多两块」就套 `ceil(n/2) = 2`，会错成 2；正确做法是奇数一律返回 `n`，因为直径无法把圆分成 3 个等面积扇形。

## 如果面试官追问
问：若要求输出具体切法（每条切割的端点角度）怎么办？
答：偶数输出 n/2 条角度为 `2πk/n` 的直径；奇数输出 n 条角度为 `2πk/n` 的半径，k 从 0 到 n-1。
