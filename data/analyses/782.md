## 一句话思路
行交换和列交换互不干扰，分别把行模式、列模式排成 0101… 或 1010…，各自取最小交换数相加。

## 怎么做
1. 用每行的二进制值（或元组）给行分类，必须恰好 2 种模式且互为按位取反，否则返回 -1；列同理。
2. 两种模式出现次数差不超过 1，否则 -1（n 为奇数时多数派必须占 (n+1)//2 个）。
3. 对行模式序列，算把它变成 0101… 需要的交换数：统计位置 i 上「应为 0 却放了 1」的个数，即错位数 //2；再算 1010… 的，按 n 奇偶取可行者中较小值。
4. 行、列各得一个最小交换数，相加返回。

以示例 1 为例：行模式只有 `0110` 和 `1001` 两种，各出现 2 次。行序列是 `[0110,0110,1001,1001]`，目标 0101 要求位置 0、2 放 `0110`，实际位置 0、1 是 `0110`，错位 2 个 → 交换 1 次；列模式同理得 1 次，合计 2。

```python
def cost(seq, n):
    # seq: 每行(列)的模式值，0/1 表示它属于哪一类
    res = []
    for start in (0, 1):          # 目标序列首项
        diff = sum(1 for i in range(n) if seq[i] != (start + i) % 2)
        if diff % 2 == 0:
            res.append(diff // 2)
    return min(res) if res else -1
```

`seq[i]` 是第 i 行属于哪一类（用 `board[i][0]` 归一化即可），`diff` 是错位数，交换一次修好两个错位，所以除以 2。

## 复杂度
时间 O(n²)：读矩阵一遍，之后每行每列 O(1) 比较。
空间 O(n)：只存行、列的模式序列。

## 易错点
- 输入 `[[1,0],[1,0]]`：两行相同、列模式只有一种，若只检查「行内是否交替」会漏判，错答 0；必须先验证行模式恰好 2 种且互补，直接返回 -1。
- n 为奇数如 3 时：`diff` 可能为奇数，此时该起点不可行，若直接 `diff//2` 会少算一次；正确做法是只保留 `diff % 2 == 0` 的起点，两个起点都不可行才返回 -1。

## 如果面试官追问
要求输出具体交换方案怎么办？答：在 `cost` 里记录每个错位位置，把位置 i 与第一个「该位是 1 却是 0」的位置配对交换，逐对输出即可。
