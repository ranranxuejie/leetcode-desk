## 一句话思路
设巨无霸 x 个、小皇堡 y 个，由 x+y=cheeseSlices 与 4x+2y=tomatoSlices 联立解出 x=(tomatoSlices-2*cheeseSlices)/2，再验整数与非负。

## 怎么做
1. 奶酪每片对应一个汉堡，所以总数固定：`x + y == cheeseSlices`。
2. 番茄方程减去两倍奶酪方程，消掉 y：`2*x == tomatoSlices - 2*cheeseSlices`，即 `x = (tomatoSlices - 2*cheeseSlices) // 2`。
3. 用 `(tomatoSlices - 2*cheeseSlices) % 2 != 0` 判非整数，用 `x < 0 or x > cheeseSlices` 判越界，任一成立返回 `[]`。
4. 否则 `y = cheeseSlices - x`，返回 `[x, y]`。

以示例 1 为例：`tomatoSlices=16, cheeseSlices=7`，中间值 `diff = 16 - 2*7 = 2`，`x = 2 // 2 = 1`，`y = 7 - 1 = 6`，得 `[1,6]`。示例 2 中 `diff = 17 - 8 = 9`，`9 % 2 == 1`，直接返回 `[]`。

```python
diff = tomatoSlices - 2 * cheeseSlices
if diff % 2 != 0:
    return []
x = diff // 2
if x < 0 or x > cheeseSlices:
    return []
return [x, cheeseSlices - x]
```

注意 `diff` 可能为负（如 `tomatoSlices=4, cheeseSlices=17` 时 `diff = -30`），Python 的 `%` 对负数仍返回非负余数，`-30 % 2 == 0` 能正确判偶，但 `x = -15 < 0` 会被第二步拦下，所以两个判断缺一不可。

## 复杂度
时间 O(1)，只做常数次加减乘除与取模。
空间 O(1)，除返回的两个整数外没开额外结构。

## 易错点
- `tomatoSlices=3, cheeseSlices=1` → 只判 `x >= 0` 会算出 `x = 0.5` 被 `//` 截成 0、返回 `[0,1]`，但 0 个巨无霸加 1 个小皇堡只要 2 片番茄，剩 1 片 → 必须先判 `diff % 2 != 0` 返回 `[]`。
- `tomatoSlices=2, cheeseSlices=2` → 只判 `diff` 偶数和 `x >= 0` 会得 `x = -1` 漏判，或反过来只判 `x <= cheeseSlices` 得 `x = -1` 通过 → 必须同时卡 `x < 0` 和 `x > cheeseSlices` 两端，本题 `x` 的合法区间是 `[0, cheeseSlices]`。

## 如果面试官追问
问：若番茄上限提到 10^18 呢？答：公式不变，Python 大整数直接算，无需改逻辑，只是别用浮点除法。
