## 一句话思路
用一个 `called` 布尔标记记录是否已调用过，首次调用时置位并转发给 `fn`，之后直接返回 `None`。

## 怎么做
1. 在 `once` 内定义 `called = False`，闭包持有这个状态。
2. 返回的包装函数先检查 `called`，为 `True` 就返回 `None`，不碰 `fn`。
3. 否则把 `called` 置为 `True`，再 `return fn(*args)`。
4. 用示例 1 走一遍：`onceFn(1,2,3)` 时 `called` 从 `False` 变 `True`，返回 `6`；第二次 `onceFn(2,3,6)` 进来 `called` 已是 `True`，直接返回 `None`，`fn` 未被调用。

```python
def once(fn):
    called = False
    def wrapper(*args):
        nonlocal called
        if called:
            return None
        called = True
        return fn(*args)
    return wrapper
```

关键在 `nonlocal called`：不写它，`called = True` 会在 `wrapper` 内新建局部变量，外层永远是 `False`，每次调用都会执行 `fn`。

## 复杂度
时间：每次调用 O(1) 判断，总时间由 `fn` 自身开销决定，与 `calls` 长度无关。
空间：O(1)，只多存一个 `called` 布尔值，不缓存参数或结果。

## 易错点
- 漏写 `nonlocal called` → 示例 1 第二次调用 `onceFn(2,3,6)` 仍返回 `18` 而非 `None`，因为赋值创建了局部变量，外层 `called` 始终 `False`。正确做法是在 `wrapper` 首行声明 `nonlocal called`。
- 把 `called = True` 写在 `return fn(*args)` 之后 → 若 `fn` 抛异常，`called` 没置位，下次调用会再次执行 `fn`，违反「最多一次」。正确做法是先置位再调用，保证异常路径下也只执行一次。

## 如果面试官追问
问：若要求缓存首次结果、后续调用返回同一结果而非 `None` 呢？
答：把 `called` 换成 `result = None` 哨兵，首次算完存进 `result`，之后直接返回它。
