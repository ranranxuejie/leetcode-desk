## 一句话思路
容斥：先算无上限的隔板法 C(n+2,2)，再减去至少一人超 limit 的三种情况，加回两人超的。

## 怎么做
1. 无约束时，n 颗糖分给 3 人（允许 0）方案数是 C(n+2, 2)。
2. 设 A_i 为「第 i 人拿到 ≥ limit+1 颗」，先给这人 limit+1 颗，剩 n-limit-1 颗自由分，方案 C(n-limit+1, 2)，共 3 项。
3. 两人同时超：先各给 limit+1，剩 n-2(limit+1)，方案 C(n-2limit, 2)，共 3 项，加回。
4. 三人同时超：剩 n-3(limit+1)，方案 C(n-3limit-3, 2)，减掉。

以 n=5, limit=2 为例：C(7,2)=21；单项 C(5-2+1,2)=C(4,2)=6，3 项减 18 得 3；两人项 n-2limit=1，C(1,2)=0；三人项为负，0。结果 3，与示例一致。

```python
def c2(x):            # C(x, 2)，x < 2 时为 0
    return x * (x - 1) // 2 if x >= 2 else 0

ans = c2(n + 2)
ans -= 3 * c2(n - limit + 1)
ans += 3 * c2(n - 2 * limit)
ans -= c2(n - 3 * limit - 3)
return ans
```

关键点：`c2` 的入参可能为负（如 n=5, limit=2 时三人项是 -4），必须返回 0 而不是让负数参与乘法。

## 复杂度
时间：O(1)，只有四次组合数计算，与 n、limit 无关。
空间：O(1)，没有开任何数组或哈希表。

## 易错点
- n=5, limit=2 时 `n - 3*limit - 3 = -4`，若直接算 `x*(x-1)//2` 会得到 10 并错误地减掉 → 必须加 `x >= 2` 的守卫，让负数项贡献 0。
- n=3, limit=3 时 `n - limit + 1 = 1`，`c2(1)` 若写成 `x*(x-1)//2` 得 0 恰好正确，但 n=3, limit=1 时 `n-limit+1=3`、`n-2limit=1`，容易漏掉两人项为 0 的判断 → 统一走 `c2` 守卫，别手写分支。

## 如果面试官追问
问：若改成 k 个小朋友呢？答：容斥变成 Σ(-1)^i C(k,i)·C(n-i(limit+1)+k-1, k-1)，i 从 0 到 k，O(k) 时间。
