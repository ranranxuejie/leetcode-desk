## 一句话思路
贪心：从下标 0 开始，只要 `groups[i] != groups[last]` 就收下 `words[i]`，因为跳过同组元素不会损失任何长度。

## 怎么做
1. 答案先放 `words[0]`，记 `last = groups[0]`。
2. 从 `i = 1` 扫到 `n-1`，只比较 `groups[i]` 和 `last`。
3. 不相等就 `append(words[i])` 并更新 `last = groups[i]`；相等直接跳过。
4. 返回收集到的列表。

以示例 2 `words = ["a","b","c","d"], groups = [1,0,1,1]` 为例：初始 `ans = ["a"]`、`last = 1`；`i=1` 时 `groups[1]=0 != 1`，收下 `"b"`，`last` 变 0；`i=2` 时 `1 != 0`，收下 `"c"`，`last` 变 1；`i=3` 时 `groups[3]=1 == last`，跳过。最终 `["a","b","c"]`，长度 3。

```python
ans = [words[0]]
last = groups[0]
for i in range(1, len(words)):
    if groups[i] != last:
        ans.append(words[i])
        last = groups[i]
return ans
```

关键点：`last` 存的是**上一个被收下的**组值，不是 `groups[i-1]`。示例 2 里 `i=3` 若错写成和 `groups[2]` 比，`1 == 1` 也会跳过，结果碰巧一样；但换成 `groups = [1,0,0,1]`，`i=2` 时 `groups[2]=0 == groups[1]` 跳过，`i=3` 时 `1 != groups[2]=0` 收下，用 `last` 同样得 `[0,3]`，两种写法在这题上等价——因为被跳过的元素组值必然等于 `last`。真正要守住的是「只和上一个收下的比」。

## 复杂度
时间 O(n)：一次线性扫描，`n = len(words)`。
空间 O(1) 额外（不计返回的 `ans` 列表本身）。

## 易错点
- 输入 `groups = [0,0,0]` → 若写成「相邻不同才收」，会得到 `["e"]` 长度 1，其实正确答案就是长度 1，但若误以为必须交替两次而返回空或报错就错了；正确做法是允许长度 1 的子序列，`ans` 初始就放 `words[0]`。
- 输入 `words = ["a"], groups = [0]` → 循环 `range(1, 1)` 不执行，若把 `ans` 初始化写在循环里会返回 `[]`；正确做法是循环外先放首元素。

## 如果面试官追问
问：如果要求返回**字典序最小**的最长交替子序列怎么办？
答：贪心不再直接成立，需在每段连续同组区间内取字典序最小的 `words`，再按交替拼接。
