## 一句话思路
对每个 `nums[i]` 用循环取余累加各位数字，边算边更新最小值，一次遍历即可。

## 怎么做
1. 初始化 `ans = 10**9`（比任何数位和都大），遍历 `nums` 中每个 `x`。
2. 对当前 `x` 用 `while x:` 循环：`s += x % 10`，再 `x //= 10`，直到 `x` 归零。
3. 每算完一个数位和 `s`，执行 `ans = min(ans, s)`。
4. 遍历结束返回 `ans`。

以示例 3 `nums = [999,19,199]` 为例：处理 `999` 时，循环依次取出 `9`、`9`、`9`，`s` 累加到 `27`，`x` 变为 `0`，`ans` 更新为 `27`；处理 `19` 时取出 `9`、`1`，`s = 10`，`ans` 更新为 `10`；处理 `199` 时 `s = 19`，`10 < 19` 所以 `ans` 保持 `10`，最终返回 `10`。

```python
ans = 10**9
for x in nums:
    s = 0
    while x:
        s += x % 10
        x //= 10
    ans = min(ans, s)
return ans
```

注意循环里 `x` 被就地改写成 `0`，所以不能拿它再做别的判断；如果后面还需要原值，得先存一份 `v = x`。本题不需要，直接改就行。

## 复杂度
时间：O(n · log M)，n 是 `nums` 长度，log M 是单个数的位数（`nums[i] ≤ 10^4`，最多 5 位）。
空间：O(1)，只开了 `ans`、`s` 两个标量。

## 易错点
- 输入 `nums = [10000]` → 若把「数位和」误写成「数位个数」或漏掉末尾的 `0`，会算成 `1` 以外的值；正确做法是 `while x:` 里先 `s += x % 10` 再 `x //= 10`，`10000` 应得 `1`。
- 输入 `nums = [999,19,199]` → 若先把整个数组替换完再求 `min`，逻辑没错但多开一个列表；若在循环里用 `x` 当累加器又忘了重置 `s = 0`，第二个数会得到 `27 + 10 = 37`；正确做法是每个 `x` 进入 `while` 前把 `s` 清零。

## 如果面试官追问
问：如果 `nums[i]` 上限提到 `10^18` 呢？答：位数变成 18，仍是 O(n · 18)，循环写法不用改，只是每轮多几次取余。
