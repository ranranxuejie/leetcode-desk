## 一句话思路
n≤13，直接枚举 2^n 个非空子集，用位掩码判连通、判奇偶，一次遍历计数。

## 怎么做
1. 把邻接关系压成 `adj[i]` 位掩码，`adj[i] |= 1 << v`（双向）。
2. 枚举 `mask` 从 1 到 `(1<<n)-1`，先算 `parity = bin(mask & valmask).count('1') & 1`，为 1 直接跳过。
3. 连通性用 BFS：从 `mask` 的最低位 `start = mask & -mask` 出发，`seen = start`，反复 `seen |= adj[i] & mask` 直到不变，最后 `seen == mask` 才算连通。
4. 计数加一。

以示例 1 `nums=[1,0,1]`、`edges=[[0,1],[1,2]]` 为例：`valmask = 0b101`。`mask=0b111` 时 `mask & valmask = 0b101`，`count('1')=2`，偶，进入连通判定；`start=0b001`，`adj[0]=0b010`，`seen` 扩到 `0b011`，再扩到 `0b111`，等于 `mask`，计数。`mask=0b101`（节点 0、2）时 `seen` 停在 `0b001`，不连通，跳过。最终得 2。

```python
n = len(nums)
adj = [0] * n
for u, v in edges:
    adj[u] |= 1 << v
    adj[v] |= 1 << u
valmask = sum(1 << i for i in range(n) if nums[i])
ans = 0
for mask in range(1, 1 << n):
    if bin(mask & valmask).count('1') & 1:
        continue
    seen = mask & -mask
    while True:
        nxt = seen
        for i in range(n):
            if seen >> i & 1:
                nxt |= adj[i] & mask
        if nxt == seen:
            break
        seen = nxt
    if seen == mask:
        ans += 1
```

## 复杂度
时间 O(2^n · n)：每个子集做一次最多 n 轮的扩张，每轮扫 n 个点。
空间 O(n)：`adj` 数组加常数个掩码变量。

## 易错点
- 空集：`mask` 从 1 开始，若从 0 起会把空集算进去，且 `mask & -mask` 为 0 导致死循环。
- 连通判定只看 `mask` 内：扩张时必须写 `adj[i] & mask`，漏掉 `& mask` 会把子集外的邻居拉进来，`[0,2]` 这种不连通子集会被误判为连通。

## 如果面试官追问
若 n 放大到 20 以上怎么办？答：枚举不可行，需按连通块分别做树形 DP 统计奇偶方案数再合并。
