## 一句话思路
按位独立统计：第 b 位在全部 n³ 个三元组里出现奇数次才留下，而出现次数只取决于 nums 中第 b 位为 1 的个数 c。

## 怎么做
1. 固定一位 b，记 c = nums 中第 b 位为 1 的元素个数。有效值第 b 位为 1 当且仅当 `(nums[i]|nums[j])` 第 b 位为 1 且 `nums[k]` 第 b 位为 1。
2. 前者的补集是 i、j 都取到第 b 位为 0 的元素，共 (n-c)² 种；故 (i,j) 有 n²-(n-c)² 种，再乘 k 的 c 种，该位出现次数 = c·(n²-(n-c)²)。
3. 只关心奇偶：n 为偶数时 n² 偶、(n-c)² 与 c 同奇偶，可化简为 c 与 n 同奇偶时该位计入；n 为奇数时 n² 奇，化简为 c 为奇数时计入。直接算原式取 `& 1` 更稳。
4. 对每个 b 累加 `1 << b`。

以 nums = [1,4] 为例，n=2。b=0：c=1，次数 = 1·(4-1)=3，奇数，计入 1。b=1：c=0，次数 0，不计。b=2：c=1，次数 3，计入 4。结果 1^4=5，与示例一致。

```python
n = len(nums)
ans = 0
for b in range(31):
    c = sum((x >> b) & 1 for x in nums)
    cnt = c * (n * n - (n - c) * (n - c))
    if cnt & 1:
        ans |= 1 << b
return ans
```

注意 `cnt` 最大约 10^5·10^10 = 10^15，Python 无溢出问题；若换语言需用 64 位。

## 复杂度
时间 O(31n)：外层 31 位，内层扫一遍 nums 数 c。
空间 O(1)：只用了 c、cnt、ans 三个标量。

## 易错点
- 误以为答案等于全体 nums 的异或：对 [1,4] 会得 5 碰巧对，但 [15,45,...] 会算错；必须按位统计出现次数的奇偶，不能直接折叠数组。
- 用 `n % 2` 和 `c % 2` 硬套化简公式却记反分支：n 偶时条件是 c 偶、n 奇时条件是 c 奇，写反后 [1,4] 的 b=0 位（c=1）会被丢掉，输出 4 而非 5；直接算 `c*(n*n-(n-c)**2) & 1` 免去记忆负担。

## 如果面试官追问
若 n 扩大到 10^9 但 nums 值域不变，怎么办？答：仍按 31 位统计每位的 c，公式只依赖 c 和 n，与 n 的具体大小无关，O(31·值域位数) 不变。
