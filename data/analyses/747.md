## 一句话思路
一次遍历同时记录最大值和次大值，最后比较 `max >= 2 * second`，成立就返回最大值的下标。

## 怎么做
1. 用 `max_val = -1`、`second = -1`、`idx = -1` 初始化，遍历 `enumerate(nums)`。
2. 遇到 `v > max_val` 时，先把旧最大值降级给 `second`，再更新 `max_val = v`、`idx = i`。
3. 遇到 `max_val > v > second` 时只更新 `second = v`，不动下标。
4. 遍历结束后判断 `max_val >= 2 * second`，成立返回 `idx`，否则返回 `-1`。

以 `nums = [3,6,1,0]` 为例：i=0 时 `max_val=3, second=-1, idx=0`；i=1 时 `v=6 > 3`，于是 `second=3, max_val=6, idx=1`；i=2 时 `1` 既不大于 6 也不大于 3，跳过；i=3 时 `0` 同样跳过。最终 `6 >= 2*3` 成立，返回 `1`。

```python
max_val, second, idx = -1, -1, -1
for i, v in enumerate(nums):
    if v > max_val:
        second = max_val
        max_val, idx = v, i
    elif v > second:
        second = v
return idx if max_val >= 2 * second else -1
```

关键在 `elif`：它保证 `second` 拿到的是「除最大值外最大的那个」，而不是被最大值覆盖掉。若写成两个独立 `if`，`[3,6,1,0]` 里 6 会先更新 `max_val`，随后又被自己比较一次，`second` 可能错成 6，判断 `6 >= 12` 直接返回 -1。

## 复杂度
时间 O(n)：一次遍历，n 为 `nums` 长度。
空间 O(1)：只开 `max_val`、`second`、`idx` 三个变量。

## 易错点
- 输入 `[1,0]` → 若把 `second` 初始化成 0 而非 -1，`1 >= 2*0` 仍成立但掩盖了「没有次大值」的语义；正确做法是初始化 `-1`，因为 `nums[i] >= 0`，-1 一定小于任何真实元素。
- 输入 `[0,1]` → 若用 `v >= max_val` 更新，最大值下标会落到错误位置；题目保证最大值唯一，必须用严格 `>`，这样 `idx` 始终指向唯一最大值。

## 如果面试官追问
问：如果数组里最大值不唯一怎么办？
答：先扫一遍统计最大值出现次数，出现两次及以上直接返回 -1，否则再按上面的逻辑比较次大值。
