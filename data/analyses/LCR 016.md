## 一句话思路
用滑动窗口 `[left, right]` 维护一个无重复字符的区间，右指针扩张、遇重复就收缩左指针，窗口长度最大值即答案。

## 怎么做
1. 用字典 `last` 记录每个字符**最近一次出现的下标**，`left` 指向当前窗口左边界，`ans` 存最大长度。
2. `right` 从 0 遍历到 `len(s)-1`，每步先看 `s[right]` 是否在 `last` 里且其下标 `>= left`。
3. 若是，说明窗口内重复了，把 `left` 跳到 `last[s[right]] + 1`（不是 `left + 1`，这是关键）。
4. 更新 `last[s[right]] = right`，再用 `right - left + 1` 刷新 `ans`。

以 `s = "pwwkew"` 为例：`right=2` 读到第二个 `'w'` 时，`last['w'] = 1 >= left = 0`，于是 `left` 从 0 跳到 2，窗口变成 `"w"`；继续到 `right=4` 时窗口为 `"wke"`，`ans = 3`。

```python
last = {}
left = ans = 0
for right, ch in enumerate(s):
    if ch in last and last[ch] >= left:
        left = last[ch] + 1
    last[ch] = right
    ans = max(ans, right - left + 1)
return ans
```

注意 `last[ch] >= left` 这个判断不能省：`s = "abba"` 到 `right=3` 读 `'a'` 时，`last['a'] = 0` 但 `left` 已经是 2，此时不该回退 `left`，否则窗口长度算错。

## 复杂度
时间 O(n)：`right` 走一遍，`left` 只增不减，每个字符最多进出窗口一次。
空间 O(k)：`last` 字典存字符到下标，k 为字符集大小，本题最多 128 量级。

## 易错点
- 输入 `s = "abba"` → 若把收缩写成 `left += 1` 或漏掉 `last[ch] >= left` 判断，`right=3` 时会把 `left` 错误回退到 1，得到长度 3 的错误答案 → 正确做法是 `left = max(left, last[ch] + 1)`，只前进不后退。
- 输入 `s = ""` → 若在循环外先取 `s[0]` 或初始化 `ans = 1`，空串会返回 1 或直接报错 → 正确做法是 `ans` 初始为 0，循环体不执行时自然返回 0。

## 如果面试官追问
问：要求返回最长子串本身而非长度，怎么改？
答：额外记录 `ans` 更新时的 `(left, right)`，最后切片 `s[best_l:best_r+1]` 即可，复杂度不变。
