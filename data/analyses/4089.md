## 一句话思路
用「最后一个越界位置 + 最近 minK 位置 + 最近 maxK 位置」三指针扫一遍，每个右端点累加合法左端点个数。

## 怎么做
1. 维护 `bad` = 最近一个不在 `[minK, maxK]` 内的下标（初值 -1），`lastMin`、`lastMax` 分别为最近出现的 `minK`、`maxK` 下标（初值 -1）。
2. 遍历右端点 `i`：若 `nums[i]` 越界则更新 `bad = i`；若等于 `minK` 更新 `lastMin`；若等于 `maxK` 更新 `lastMax`。
3. 以 `i` 结尾的合法左端点必须 `> bad` 且 `<= min(lastMin, lastMax)`，个数为 `min(lastMin, lastMax) - bad`，若为正就累加。

以 `nums = [1,4,7,3], minK=1, maxK=5` 为例：`i=2` 时 `nums[2]=7` 越界，`bad=2`；`i=3` 时 `lastMin=0`、`lastMax=1`，`min(0,1)-2 = -2` 不累加。最终只有 `i=0,1,3` 各贡献 1、1、2，合计 4。

```python
bad = lastMin = lastMax = -1
ans = 0
for i, x in enumerate(nums):
    if x < minK or x > maxK:
        bad = i
    if x == minK:
        lastMin = i
    if x == maxK:
        lastMax = i
    left = min(lastMin, lastMax)
    if left > bad:
        ans += left - bad
```

## 复杂度
时间 O(n)：每个元素只被扫一次，三指针都是 O(1) 更新。
空间 O(1)：只开了 `bad`、`lastMin`、`lastMax`、`ans` 四个变量。

## 易错点
- `nums = [1,1], minK=1, maxK=1`：若把 `minK == maxK` 当成特殊情况跳过或只更新一个指针，会漏掉 `[1,1]` 这个子数组，错成 2。正确做法是 `lastMin` 和 `lastMax` 两个 `if` 都独立执行，同一位置同时更新。
- `nums = [1,4,7,3], minK=1, maxK=5`：若忘记 `bad` 只增不减、或在 `left <= bad` 时仍累加负数，会把跨越 7 的子数组算进去。正确做法是 `left > bad` 才累加 `left - bad`，`bad` 一旦更新就不再回退。

## 如果面试官追问
问：若要求返回所有宽界子数组本身而非计数？答：枚举每个右端点时左端点取 `bad+1 .. min(lastMin,lastMax)` 全部展开，输出规模可能 O(n²)，复杂度随之退化。
