## 一句话思路
枚举左端点，向右累加和并维护子数组最大值，用哈希表记录值出现次数，判断和是否落在其中。

## 怎么做
1. 外层 `i` 从 0 到 n-1，内层 `j` 从 `i` 向右扩展，维护 `s`（当前子数组和）与 `mx`（当前子数组最大值）。
2. 每扩展一步，把 `nums[j]` 计入 `s`，更新 `mx = max(mx, nums[j])`。
3. 判断 `s` 是否等于子数组中某个元素：因为 `mx` 是最大值，若 `s == mx` 则命中；否则需要检查 `s` 是否在 `[min, mx]` 内且确实出现过——用哈希表 `cnt` 记录当前窗口各值出现次数，`s in cnt` 即可。
4. 命中则 `ans += 1`。

以 `nums = [-1,1,0]` 为例：`i=1, j=2` 时窗口 `[1,0]`，`s=1`，`mx=1`，`cnt={1:1,0:1}`，`s in cnt` 为真，计数 +1；`i=0, j=2` 时 `s=0`，`cnt` 含 0，也命中。

```python
n = len(nums)
ans = 0
for i in range(n):
    s = 0
    cnt = {}
    for j in range(i, n):
        s += nums[j]
        cnt[nums[j]] = cnt.get(nums[j], 0) + 1
        if s in cnt:
            ans += 1
```

注意 `s in cnt` 判断的是「和这个值在窗口里出现过」，而非「和等于最大值」——`[-1,1,0]` 的 `[1,0]` 和是 1，1 在窗口里，命中；若只比 `mx` 会漏掉和等于中间值的情况。

## 复杂度
时间：O(n²)，两层循环枚举所有子数组，内层每步 O(1) 哈希操作。
空间：O(n)，每个左端点开一个哈希表，最多存 n 个不同值。

## 易错点
- 输入 `nums = [0,0,0]` → 若用「和等于最大值」判断，`[0,0]` 和是 0、最大值 0，看似命中，但 `[1,0]` 这类和等于中间值的情况会被漏判 → 必须用哈希表判断和是否在窗口中出现过。
- 输入 `nums = [2,-3]` → 若只统计长度 ≥2 的子数组会漏掉单元素子数组 → 单元素子数组和等于自身，必然命中，循环从 `j=i` 开始即可覆盖。

## 如果面试官追问
若 n 扩大到 10^5 怎么办？答：O(n²) 不可行，需换思路，比如按最大值分治或用单调栈统计每个值作为最大值的区间，再结合前缀和哈希。
