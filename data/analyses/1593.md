## 一句话思路
回溯枚举每个切分点，用集合去重，n≤16 保证 2^15 种切法可枚举。

## 怎么做
1. 从下标 `i` 开始，枚举子串终点 `j`（`i < j <= n`），取 `s[i:j]`。
2. 若 `s[i:j]` 不在 `seen` 中，加入后递归 `j`，返回时移除（回溯）。
3. 当 `i == n` 时用 `len(seen)` 更新全局最大值 `best`。
4. 剪枝：`len(seen) + (n - i) <= best` 时直接返回，因为剩余字符最多再贡献 `n-i` 个唯一子串。

以 `s = "ababccc"` 为例，走到 `i=2` 时 `seen = {'a','b'}`，此时若选 `s[2:3]='a'` 会与已有 `'a'` 冲突被跳过，选 `s[2:4]='ab'` 才继续；最终路径 `a|b|ab|c|cc` 让 `seen` 大小到 5。

```python
def dfs(i):
    nonlocal best
    if len(seen) + (n - i) <= best:
        return
    if i == n:
        best = max(best, len(seen))
        return
    for j in range(i + 1, n + 1):
        sub = s[i:j]
        if sub not in seen:
            seen.add(sub)
            dfs(j)
            seen.remove(sub)
```

## 复杂度
时间：O(2^(n-1) · n)，每个切分点选或不选，子串哈希与切片各 O(n)。
空间：O(n)，递归栈深度 ≤ n，`seen` 最多存 n 个子串。

## 易错点
- 输入 `"aa"` → 若忘记回溯时 `seen.remove(sub)`，第二次搜索时 `'a'` 残留导致后续分支全被误判冲突，答案错成 0 或 1 之外的怪值 → 必须在 `dfs(j)` 返回后立刻移除。
- 输入 `"ababccc"` → 若剪枝写成 `len(seen) + (n - i) < best`（少个等号），等于 best 的分支仍会展开，虽不出错但白跑；若把剪枝条件写成 `>=` 则会把可能更优的分支砍掉，答案偏小 → 用 `<=` 提前返回。

## 如果面试官追问
问：n 放大到 30 怎么办？
答：这题本质是集合划分搜索，n=30 需换思路，如按字符频次上界剪枝或 DP 状压不可行，实际面试仍按 n≤16 的回溯答。
