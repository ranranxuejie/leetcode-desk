## 一句话思路
把「去程空手 + 返程带货」拆成两张有向图，分别从所有商店做多源 Dijkstra，再对每个 i 取 `min(prices[i], min_j(去[j][i] + prices[j] + 回[j][i]))`。

## 怎么做
1. 建两张图：空手边权 `cost`，带货边权 `cost * tax`，都按双向存。
2. 关键观察：从 i 出发去 j 再回 i，去程和返程路径独立，所以总代价 = `dist_empty[j][i] + prices[j] + dist_loaded[j][i]`，两个距离可以分开算。
3. 反向建图跑多源 Dijkstra：把 `prices[j]` 当作源点初值压入堆，一次求出所有 `j` 到所有 `i` 的 `prices[j] + dist_empty[j][i]`（空手图反向 = 原图正向，因为边双向，直接对原图跑即可）。
4. 对带货图同样跑一次多源 Dijkstra，得到 `prices[j] + dist_loaded[j][i]`，两次结果相加再与 `prices[i]` 取 min。

以示例 1 为例：`prices=[8,3]`，边 `[0,1,1,2]`。空手图边权 1，带货图边权 2。带货多源 Dijkstra 初值 `d=[8,3]`，从 1 松弛 0：`3+2=5 < 8`，得 `d=[5,3]`；空手图同理得 `[8,3]`（8 无法被 3+1=4 改进？实际 3+1=4<8，得 `[4,3]`）。最终 `ans[0]=min(8, 4+3)=7`？——注意这里要的是 `去+价+回`，正确合并是 `dist_empty[j][i]+prices[j]+dist_loaded[j][i]`，示例 1 中 j=1 时 `1+3+2=6`，故 `ans[0]=6`。

```python
import heapq
def dijkstra(n, adj, init):
    d = init[:]
    pq = [(d[i], i) for i in range(n)]
    heapq.heapify(pq)
    while pq:
        du, u = heapq.heappop(pq)
        if du > d[u]: continue
        for v, w in adj[u]:
            if du + w < d[v]:
                d[v] = du + w
                heapq.heappush(pq, (d[v], v))
    return d
```

## 复杂度
时间：两次 Dijkstra 各 `O((n+m) log n)`，m 为 roads 长度，堆操作贡献 log n。
空间：两张邻接表 `O(n+m)`，两个距离数组 `O(n)`。

## 易错点
1. 把去程和返程合并成一条路径算 → 示例 2 中 0→1 去程 1、返程 3，合并会误算成 `1*3=3` 而非 `1+3=4`，导致 `ans[0]` 错成 7 而非 8。正确做法是两张图分别跑，最后相加。
2. 多源初值只放 `prices[j]` 而漏掉「原地买」的情况 → 当 `roads` 为空（如 n=1）时，`ans[i]` 应为 `prices[i]`，若初值没设对会得到无穷大。正确做法是 `d = prices[:]` 作为初始距离。

## 如果面试官追问
问：若 n 放大到 10^5、m 到 2*10^5 还能做吗？答：能，仍是两次 Dijkstra，`O((n+m) log n)`，但需注意 `cost*tax` 最大 10^11，Python 整数无溢出问题。
