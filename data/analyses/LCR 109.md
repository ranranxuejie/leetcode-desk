## 一句话思路
从 `"0000"` 做 BFS，每层是旋转次数，第一次弹出 `target` 的层数就是最小步数。

## 怎么做
1. 把 `deadends` 转成 `set`，`"0000"` 在其中直接返回 `-1`。
2. 队列存 `(状态, 步数)`，`visited` 同时装已访问状态和死亡数字，入队前查一次。
3. 每个状态枚举 4 位 × 上下两个方向，共 8 个邻居。
4. 弹出时判 `target`，队列空返回 `-1`。

以示例 1 为例，第 0 层是 `"0000"`；第 1 层生成 `"1000"`、`"9000"`、`"0100"`…，其中 `"0100"` 的下一步 `"0101"` 在 `deadends` 里被 `visited` 挡掉，所以最短路径绕开它走 `"1000"→"1100"→"1200"→"1201"→"1202"→"0202"`，共 6 步。

```python
from collections import deque

dead = set(deadends)
if "0000" in dead:
    return -1
q = deque([("0000", 0)])
seen = dead | {"0000"}
while q:
    cur, d = q.popleft()
    if cur == target:
        return d
    for i in range(4):
        for delta in (1, -1):
            nxt = cur[:i] + str((int(cur[i]) + delta) % 10) + cur[i+1:]
            if nxt not in seen:
                seen.add(nxt)
                q.append((nxt, d + 1))
return -1
```

关键中间值：处理 `cur = "0000"`、`i = 0`、`delta = -1` 时，`int('0') - 1 = -1`，`-1 % 10 = 9`，得到 `"9000"`——Python 的 `%` 对负数返回非负，正好对应 `'0'` 反向拨到 `'9'`。

## 复杂度
时间 O(10^4 × 8)，状态数上限 10000，每个状态常数次字符串拼接。
空间 O(10^4)，`seen` 集合最多存 10000 个 4 字符串。

## 易错点
- `deadends` 含 `"0000"`（示例 4）→ 若先入队再判死亡，会返回 0 或继续搜 → 必须在建队列前就 `return -1`。
- 反向拨动用 `(int(cur[i]) - 1) % 10` → 写成 `int(cur[i]) - 1` 会得到 `"-1"` 这种非法状态，或写成 `max(0, ...)` 把 `'0'` 卡死 → 必须取模 10。

## 如果面试官追问
要求输出具体旋转序列怎么办？BFS 里给每个状态存 `parent` 字典，命中 `target` 后从它回溯到 `"0000"` 再反转即可。
