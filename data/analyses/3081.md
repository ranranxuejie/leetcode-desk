## 一句话思路
统计已有字母频次，把每个 `?` 依次填成当前频次最小的字母（同频取小），分数最小且字典序最小。

## 怎么做
1. 先扫一遍 `s`，用 `cnt[26]` 记下每个字母已出现的次数。
2. 把 `?` 的个数记为 `q`，用最小堆 `heap` 存 `(cnt[c], c)`，共 26 个元素。
3. 弹出 `q` 次堆顶，每次把字母 `c` 记进待填列表 `fill`，再把 `(cnt[c]+1, c)` 压回堆。
4. 对 `fill` 升序排序，按从左到右的顺序依次替换 `s` 中的 `?`。

以 `s = "a?a?"` 为例：`cnt['a']=2`，其余为 0，`q=2`。第一次弹出 `(0,'b')`，第二次弹出 `(0,'c')`，`fill=['b','c']` 排序后仍是 `['b','c']`，替换得 `"abac"`，分数为 1。

```python
import heapq
cnt = [0] * 26
for ch in s:
    if ch != '?':
        cnt[ord(ch) - 97] += 1
q = s.count('?')
heap = [(cnt[c], c) for c in range(26)]
heapq.heapify(heap)
fill = []
for _ in range(q):
    v, c = heapq.heappop(heap)
    fill.append(chr(c + 97))
    heapq.heappush(heap, (v + 1, c))
fill.sort()
it = iter(fill)
res = ''.join(next(it) if ch == '?' else ch for ch in s)
```

## 复杂度
时间：O(n + q log 26)，n 来自扫描 `s` 与拼接，q 次堆操作是常数级 log。
空间：O(26 + q)，堆固定 26 项，`fill` 与结果串各占 O(q)、O(n)。

## 易错点
- 只按频次贪心、忘了同频取小：`s = "???"` 若堆里按 `(cnt, c)` 但 `c` 用了 `ord` 反序，会得到 `"zyx"` 而非 `"abc"`，字典序就错了；堆元素必须是 `(cnt[c], c)` 且 `c` 为 0..25。
- 把 `fill` 直接按弹出顺序填回 `?`：`s = "?a?"` 弹出 `['b','c']` 顺序恰好对，但 `s = "??a"` 时若先填 `'b'` 到第一个 `?`、`'c'` 到第二个，得到 `"bca"`；正确是先对 `fill` 排序再从左到右填，得 `"abc"`，分数同为 0 但字典序更小。

## 如果面试官追问
若字母表扩大到 10^5 个字符、`s` 长 10^5，还能用堆吗？
能，堆大小变成字符集大小 k，复杂度 O(n + q log k)，仍可行；k 极大时改用计数排序找最小频次。
