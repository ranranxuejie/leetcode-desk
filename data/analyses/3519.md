## 一句话思路
把 l、r 转成 b 进制字符串，用数位 DP 统计「≤ 上界且逐位非递减」的个数，再作差。

## 怎么做
1. 写 `to_base(x, b)` 把十进制字符串转成 b 进制数字列表（从高位到低位）。
2. 写 `count(s, b)`：统计 `[0, s]` 内 b 进制逐位非递减的个数，用记忆化 DFS，状态是 `(pos, prev, tight, started)`。
3. 答案 = `(count(r) - count(l) + is_valid(l)) % (10**9+7)`，因为 count 是闭区间前缀和，要补回 l 本身。
4. 关键转移：`started=False` 时可选跳过前导零（`prev` 保持 -1），否则下一位 `d >= prev` 才合法。

以示例 1 的 `count("34", 8)` 为例：8 进制 `34` 即数字 28，枚举到 `33` 时 `prev=3, d=3` 合法，`34` 时 `prev=3, d=4` 合法，`27` 时 `prev=2, d=7` 合法，共 3 个，与输出一致。

```python
def count(s, b):
    digits = to_base(s, b)
    n = len(digits)
    from functools import lru_cache
    @lru_cache(None)
    def dfs(pos, prev, tight, started):
        if pos == n:
            return 1 if started else 0
        hi = digits[pos] if tight else b - 1
        res = 0
        for d in range(hi + 1):
            if started and d < prev:
                continue
            res += dfs(pos + 1, d if started or d > 0 else -1,
                       tight and d == hi, started or d > 0)
        return res
    return dfs(0, -1, True, False)
```

注意 `prev` 用 -1 表示「还没开始」，`started` 为 False 时跳过前导零不消耗数字。

## 复杂度
时间：O(len(r) · b · b)，状态数 len·b·2·2，每状态枚举 b 个数字。
空间：O(len(r) · b) 记忆化表，递归栈 O(len(r))。

## 易错点
- 输入 `l="2", r="7", b=2`：若把前导零也当数字参与非递减判断，`10` 会被误判合法（0≤1 但实际是 `10` 应不合法）。正确做法是用 `started` 标记，前导零不更新 `prev`。
- 输入 `l="1", r="1", b=10`：若直接 `count(r)-count(l)` 会漏掉 l 本身（count 是闭区间前缀和）。正确做法是加回 `is_valid(l)`，或改用 `count(r)-count(l-1)`。

## 如果面试官追问
若 b 扩大到 10^9 怎么办？答：状态里的 `prev` 无法枚举，改为按「当前位数字」做组合计数，用前缀和公式 O(len·b) 直接算，不再逐位枚举。
