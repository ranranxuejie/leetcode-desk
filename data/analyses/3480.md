## 一句话思路
对每个右端点 r 维护「最紧的冲突左界」，删对等价于把某个 r 的第二紧左界提上来，用前缀和差分统计增益。

## 怎么做
1. 把每对 `[a,b]` 规范成 `a<b`，按 `b` 挂到 `by_b[b]` 上。
2. 从左到右扫 `r=1..n`，维护 `mx1`（最大左界）和 `mx2`（次大左界）及 `mx1` 来自哪个 `b`。以 `r` 结尾的合法子数组数是 `r - mx1`，累加进 `base`。
3. 关键：删掉 `mx1` 对应的那一对后，左界变成 `mx2`，多出的子数组数是 `mx1 - mx2`，把它记到 `gain[mx1]` 上（同一个 `mx1` 会被多个 `r` 共享，所以是累加）。
4. 答案 = `base + max(gain)`，`gain` 全 0 时删任意一对无影响。

以示例 2 `n=5, pairs=[[1,2],[2,5],[3,5]]` 为例：`r=5` 时 `by_b[5]` 有 `2` 和 `3`，`mx1=3`（来自 `[3,5]`）、`mx2=2`，贡献 `5-3=2` 给 `base`，`gain[3] += 1`。最终 `base=12`，`gain` 最大为 0，答案 12。

```python
by_b = [[] for _ in range(n + 1)]
for a, b in conflictingPairs:
    if a > b: a, b = b, a
    by_b[b].append(a)
base = 0
gain = [0] * (n + 1)
mx1 = mx2 = 0
for r in range(1, n + 1):
    for a in by_b[r]:
        if a > mx1: mx2, mx1 = mx1, a
        elif a > mx2: mx2 = a
    base += r - mx1
    gain[mx1] += mx1 - mx2
return base + max(gain)
```

## 复杂度
时间 O(n + m)，m 为冲突对数，扫描与挂链各一次，无 log。
空间 O(n)，`by_b` 与 `gain` 各开 n+1。

## 易错点
- 输入含 `[4,1]` 这种反序对 → 不规范化会让 `by_b[1]` 收到 4，`mx1` 超过 `r`，`r-mx1` 变负 → 必须先 `if a > b: a, b = b, a`。
- 多个 `r` 共享同一 `mx1` 时 → 若把 `gain` 写成赋值 `gain[mx1] = mx1-mx2` 而非 `+=`，示例 2 里 `mx1=3` 只被算一次，增益被低估 → 必须累加，因为删同一对能同时放宽多个右端点。

## 如果面试官追问
若要求输出删哪一对？答：在 `gain` 取最大时额外记下产生该 `mx1` 的那对 `[mx1, b]`，扫描时同步保存 `owner[mx1]=b` 即可。
