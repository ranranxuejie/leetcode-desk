## 一句话思路
恰好三个除数等价于 n 是某个质数的平方，枚举 i 判 `i*i == n` 且 i 是质数。

## 怎么做
1. 从 2 开始枚举 i，直到 `i * i > n`，因为若 n 有三个除数，其平方根必为质数。
2. 对每个 i 先判 `i * i == n`，不等就跳过，避免对非平方数做无谓的质数判定。
3. 相等时再判 i 是否为质数：用 `j` 从 2 试到 `j * j <= i`，一旦 `i % j == 0` 就说明 i 合数。
4. 只有「是平方」且「根是质数」两个条件同时成立才返回 `True`，否则枚举结束返回 `False`。

以 n = 4 为例：i = 2 时 `2 * 2 == 4` 成立，再判 2 是质数（试除循环 `j * j <= 2` 不进入），返回 `True`。若 n = 16，i = 4 时 `4 * 4 == 16` 成立，但试除 j = 2 得 `4 % 2 == 0`，4 非质数，继续枚举到 `i * i > 16` 后返回 `False`。

```python
i = 2
while i * i <= n:
    if i * i == n:
        j = 2
        while j * j <= i:
            if i % j == 0:
                return False
            j += 1
        return True
    i += 1
return False
```

## 复杂度
时间：外层枚举到 √n，内层对根再试除到 n^(1/4)，整体 O(√n)。
空间：只用了 i、j 两个整型变量，O(1)。

## 易错点
- n = 1 → 只有 1 这一个除数，若把「平方根是质数」写成「平方根 ≥ 2」会误判为 `True`；正确做法是循环从 i = 2 起，1 直接落到 `return False`。
- n = 9 → 若只判 `i * i == n` 不判质数，9 的根 3 是质数没问题；但 n = 16 时根 4 非质数，漏判质数会把 16 错判成 `True`，必须补上试除循环。

## 如果面试官追问
问：n 放大到 10^12 怎么办？
答：仍只需枚举到 10^6，判根质数用试除到 10^3，总代价可接受；再大就上 Miller-Rabin。
