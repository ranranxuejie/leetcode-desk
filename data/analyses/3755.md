## 一句话思路
把「异或为 0」和「奇偶数量相等」压成一个前缀状态 `(xor, odd-even)`，同状态最早出现的位置到当前位置就是合法子数组。

## 怎么做
1. 定义前缀状态：`px[i]` 是前 i 个元素的异或，`pd[i]` 是前 i 个元素中奇数个数减偶数个数。
2. 子数组 `nums[l..r]` 合法 ⟺ `px[r+1]==px[l]` 且 `pd[r+1]==pd[l]`，即两个前缀状态完全相同。
3. 用字典 `first` 记录每个 `(px, pd)` 第一次出现的下标，初始 `first[(0,0)] = 0`。
4. 从左到右扫，若状态已出现过，用 `i - first[state]` 更新答案；否则记下当前下标。

以示例 1 `nums = [3,1,3,2,0]` 为例：扫到下标 4（元素 0）时，`px = 3^1^3^2^0 = 3`，`pd = 3-2 = 1`，而 `(3,1)` 在 i=1 时首次出现，长度 `5-1 = 4`，正是答案。

```python
first = {(0, 0): 0}
px = pd = 0
ans = 0
for i, x in enumerate(nums, 1):
    px ^= x
    pd += 1 if x & 1 else -1
    state = (px, pd)
    if state in first:
        ans = max(ans, i - first[state])
    else:
        first[state] = i
return ans
```

关键点：`pd` 用「奇数 +1、偶数 -1」，这样「奇偶数量相等」就等价于 `pd` 前后相等，不用分别记两个计数器。

## 复杂度
时间 O(n)：一次遍历，字典均摊 O(1)。
空间 O(n)：`first` 最多存 n+1 个状态。

## 易错点
- 输入 `[0]`：若把 `first[(0,0)]` 初始化成 0 后忘记「非空」约束，会算出长度 1；正确做法是状态相同才更新，`i - first[state]` 在 i=1 时状态 `(0,-1)` 未出现过，答案保持 0。
- 输入 `[1,1]`：异或为 0 但奇偶是 2 奇 0 偶，若只判异或会返回 2；必须同时比对 `pd`，这里 `pd` 序列是 1、2，无重复状态，答案 0。

## 如果面试官追问
问：要求返回具体子数组下标而不是长度？
答：在 `first` 里存下标，命中时记录 `(first[state], i-1)`，取最长的那组即可。
