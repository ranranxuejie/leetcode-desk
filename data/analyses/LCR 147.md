## 一句话思路
辅助栈 `mins` 与主栈 `stk` 同步压弹，`mins` 栈顶始终是当前栈内最小值，故 `getMin` 为 O(1)。

## 怎么做
1. `push(val)`：`stk` 压 `val`；`mins` 压 `min(val, mins[-1])`（`mins` 空时直接压 `val`）。
2. `pop()`：两栈同时弹，保证 `mins` 顶与 `stk` 顶对应同一时刻的最小值。
3. `top()` 返回 `stk[-1]`，`getMin()` 返回 `mins[-1]`。

用官方示例走关键一步：push(-2) 后 `stk=[-2]`、`mins=[-2]`；push(0) 时 `min(0, -2) = -2`，`mins=[-2, -2]`；push(-3) 时 `min(-3, -2) = -3`，`mins=[-2, -2, -3]`，此时 `getMin()` 取 `mins[-1] = -3`。接着 `pop()` 两栈同弹，`mins` 回到 `[-2, -2]`，`top()` 得 `stk[-1] = 0`，再 `getMin()` 得 `-2`，与输出 `[null,null,null,null,-3,null,0,-2]` 一致。

```python
def push(self, val):
    self.stk.append(val)
    self.mins.append(val if not self.mins else min(val, self.mins[-1]))

def pop(self):
    self.stk.pop()
    self.mins.pop()

def top(self):
    return self.stk[-1]

def getMin(self):
    return self.mins[-1]
```

注意 `mins` 压的是 `min(val, mins[-1])` 而非 `val`，这样重复最小值（如连压两个 -3）也能在弹出时正确回退。

## 复杂度
时间：每个操作 O(1)，`push` 只做一次 `min` 比较。
空间：O(n)，`stk` 与 `mins` 各存 n 个元素，额外开销为 n。

## 易错点
- 输入 `push(-3), push(-3), pop(), getMin()` → 若 `mins` 只在 `val < mins[-1]` 时才压，第二个 -3 不压，弹出后 `mins` 顶丢失，`getMin` 错成更早的值 → 必须用 `<=` 或直接压 `min(val, mins[-1])`，保证每次 push 都同步压一个。
- 输入 `push(0), pop(), push(-2), getMin()` → 若 `pop` 只弹 `stk` 不弹 `mins`，`mins` 残留 0，`getMin` 错成 0 → 两栈必须同弹，长度始终相等。

## 如果面试官追问
追问：不用辅助栈能否 O(1) 空间？答：可存差值 `val - min`，用单个变量记当前最小值，弹出时按差值符号还原前一个最小值。
