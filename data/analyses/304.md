## 一句话思路
用二维前缀和 `pre[i][j]` 存左上角 (0,0) 到 (i-1,j-1) 的和，任意子矩形由四个前缀和容斥 O(1) 得出。

## 怎么做
1. 开 `(m+1) x (n+1)` 的 `pre`，多出的一行一列全 0，省掉边界判断。
2. 递推 `pre[i][j] = matrix[i-1][j-1] + pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1]`。
3. 查询用容斥：`pre[row2+1][col2+1] - pre[row1][col2+1] - pre[row2+1][col1] + pre[row1][col1]`。

以官方示例 `sumRegion(2,1,4,3)` 为例，关键中间值是 `pre[5][4]`（覆盖 0..4 行、0..3 列）减去 `pre[2][4]`、`pre[5][1]`，再加回被减两次的 `pre[2][1]`，得 8。注意 `pre` 下标比原矩阵大 1，`row2+1` 才是右下角的开区间。

```python
m, n = len(matrix), len(matrix[0])
pre = [[0] * (n + 1) for _ in range(m + 1)]
for i in range(1, m + 1):
    for j in range(1, n + 1):
        pre[i][j] = (matrix[i-1][j-1] + pre[i-1][j]
                     + pre[i][j-1] - pre[i-1][j-1])

def query(r1, c1, r2, c2):
    return (pre[r2+1][c2+1] - pre[r1][c2+1]
            - pre[r2+1][c1] + pre[r1][c1])
```

## 复杂度
时间：建表 O(m·n)，每次 `sumRegion` O(1)，共 10^4 次查询。
空间：额外开 `(m+1)(n+1)` 的 `pre`，即 O(m·n)。

## 易错点
- 查询时写成 `pre[row2][col2]` 而非 `pre[row2+1][col2+1]` → 右下角整行整列被漏掉，示例 1 第一个查询会得 5 而不是 8 → 记住 `pre` 下标整体偏移 1，四个角全用 `+1` 版本。
- 容斥符号写错，比如把 `+ pre[row1][col1]` 写成减 → 示例 1 第二个查询 `(1,1,2,2)` 会得 3 而不是 11 → 固定记「大减小减加」，最后一项必为加。

## 如果面试官追问
问：矩阵会动态修改怎么办？
答：改用二维树状数组或线段树，单点更新 O(log m·log n)，查询同样 O(log m·log n)，代价是建表逻辑变复杂。
