## 一句话思路
从右往左扫一遍，用一个变量 `mx` 记住「当前元素右侧的最大值」，边扫边更新，一次遍历搞定。

## 怎么做
1. 记 `mx = -1`，它代表最后一个元素右侧的「最大值」（空集约定为 -1）。
2. 从 `i = len(arr) - 1` 倒着遍历到 0，先把 `arr[i]` 存进临时变量 `cur`，再把 `arr[i]` 写成 `mx`。
3. 用 `cur` 更新 `mx = max(mx, cur)`，这样下一轮（更左边一位）看到的 `mx` 就是它右侧的最大值。

拿 `arr = [17,18,5,4,6,1]` 走一遍关键几步：初始 `mx = -1`；`i=5` 时 `cur=1`，`arr[5]` 写成 `-1`，`mx` 更新为 `1`；`i=4` 时 `cur=6`，`arr[4]` 写成 `1`，`mx` 更新为 `6`；`i=3` 时 `arr[3]` 写成 `6`，`mx` 仍是 `6`；`i=1` 时 `cur=18`，`arr[1]` 写成 `6`，`mx` 更新为 `18`；`i=0` 时 `arr[0]` 写成 `18`。结果 `[18,6,6,6,1,-1]`。

```python
mx = -1
for i in range(len(arr) - 1, -1, -1):
    cur = arr[i]
    arr[i] = mx
    if cur > mx:
        mx = cur
return arr
```

顺序不能反：必须**先**把 `arr[i]` 覆盖成 `mx`，**再**用 `cur` 更新 `mx`。如果先更新 `mx`，`i` 位置就会拿到自己的值。

## 复杂度
时间 O(n)：倒序遍历每个下标恰好一次，n 是 `arr` 长度。
空间 O(1)：只开了 `mx` 和 `cur` 两个标量，原地改 `arr`。

## 易错点
- 输入 `arr = [400]`（单元素）→ 若循环写成 `range(len(arr) - 2, -1, -1)` 会漏掉下标 0，返回原值 `[400]` → 正确起点是 `len(arr) - 1`，让 `arr[0]` 也被写成初始的 `-1`。
- 输入 `arr = [17,18,5,4,6,1]` → 若先执行 `mx = max(mx, arr[i])` 再写 `arr[i] = mx`，`arr[1]` 会变成 `18` 而不是 `6`，因为 `mx` 已被当前位置污染 → 必须用 `cur` 暂存原值，先写后更新。

## 如果面试官追问
问：如果要求返回新数组、不许改 `arr`？答：新建等长 `res`，同样倒序填 `res[i] = mx`，空间变 O(n)，逻辑不变。
