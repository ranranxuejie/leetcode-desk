## 一句话思路
从 (0,0) 出发做 BFS/DFS，只把数位和 ≤ cnt 的格子入队，因为可达性由「路径上每格都合法」决定，不能只数合法格子。

## 怎么做
1. 写 `digit(x)` 求数位和，用 `while x: s += x % 10; x //= 10`。
2. 从 `(0,0)` 起 BFS，队列存坐标，`visited` 用 `m x n` 布尔矩阵或 `set`。
3. 出队时计数加一，向 `(i+1,j)`、`(i,j+1)` 扩展，越界、已访问、`digit(i)+digit(j) > cnt` 一律跳过。
4. 起点本身也要先判 `digit(0)+digit(0)=0 <= cnt`，cnt ≥ 0 恒成立，可直接入队。

以 `m=4, n=7, cnt=5` 为例：起点 (0,0) 数位和 0 入队；扩展到 (0,1) 和 (1,0)，数位和都是 1；继续到 (0,5) 时 `digit(0)+digit(5)=5` 合法，(0,6) 为 6 被挡；到 (3,2) 时 `3+2=5` 合法，(3,3) 为 6 被挡。最终队列弹出 18 次，返回 18。

```python
from collections import deque

def digit(x):
    s = 0
    while x:
        s += x % 10
        x //= 10
    return s

q = deque([(0, 0)])
seen = {(0, 0)}
ans = 0
while q:
    i, j = q.popleft()
    ans += 1
    for ni, nj in ((i + 1, j), (i, j + 1)):
        if ni < m and nj < n and (ni, nj) not in seen \
           and digit(ni) + digit(nj) <= cnt:
            seen.add((ni, nj))
            q.append((ni, nj))
```

## 复杂度
时间 O(m·n)：每个格子最多入队一次，`digit` 最多算 3 位。
空间 O(m·n)：`seen` 集合和队列各存最多 m·n 个坐标。

## 易错点
- 只遍历所有格子数 `digit(i)+digit(j) <= cnt` 的个数 → 会把被非法格子隔断的「孤岛」也算进去，如 cnt=0 时 (0,1) 合法但 (1,1) 不可达；正确做法是从 (0,0) 做可达性搜索。
- 用 DFS 递归且 m=n=100 时递归深度可达 200 层，Python 默认递归上限 1000 虽够但栈开销大；正确做法用显式栈或 BFS，且入队时就标记 `seen`，否则同一格会被重复入队。

## 如果面试官追问
问：若要求输出所有需整理格子的坐标列表而非计数？答：BFS 时把弹出的 `(i,j)` 追加到结果列表，顺序即层序，复杂度不变。
