## 一句话思路
只有起点 `rounds[0]` 和终点 `rounds[-1]` 决定覆盖区间，中间经过的扇区不影响最终计数。

## 怎么做
1. 观察：整条路径从 `rounds[0]` 出发，最终停在 `rounds[-1]`，中间所有 `rounds[i]` 只是途经点，绕圈后回到同一扇区的次数相同，对「谁最多」没有影响。
2. 把路径展开成从 `s = rounds[0]` 沿编号递增方向走到 `e = rounds[-1]` 的一段（环形）。
3. 若 `s <= e`，覆盖区间是 `[s, e]`；若 `s > e`，覆盖区间是 `[s, n] ∪ [1, e]`，即跨过 n 回到 1。
4. 区间内每个扇区都恰好被经过一次，所以答案就是这段区间里的全部扇区，按升序输出。

以示例 1 `n = 4, rounds = [1,3,1,2]` 为例：`s = 1, e = 2`，`s <= e`，区间 `[1,2]`，答案 `[1,2]`。中间那个 `3` 和 `1` 完全没参与判断。

```python
s, e = rounds[0], rounds[-1]
if s <= e:
    return list(range(s, e + 1))
return list(range(s, n + 1)) + list(range(1, e + 1))
```

关键中间值：示例 2 中 `s = 2, e = 2`，`s <= e` 成立，区间 `[2,2]`，答案 `[2]`，与绕了 4 圈无关。

## 复杂度
时间：O(n)，构造答案区间最多遍历 n 个扇区，与 `rounds` 长度 m 无关。
空间：O(1) 额外空间（不计返回的答案列表）。

## 易错点
- 输入 `rounds = [1,3,1,2]` 时若逐段模拟每个 `rounds[i] -> rounds[i+1]` 并累加计数，虽然结果对，但把 m 段都算了一遍，白做 O(m·n)；正确做法是只取首尾两个端点定区间。
- 输入 `n = 4, rounds = [3,1]` 时若写成 `range(3, 2)` 会得到空列表；`s > e` 必须拆成 `[3,4]` 和 `[1,1]` 两段拼接，答案 `[1,3,4]`。

## 如果面试官追问
问：如果要求返回每个扇区被经过的次数而非只返回最多的呢？
答：仍只需首尾定区间，区间内全为 1、区间外全为 0，不必逐段模拟。
