## 一句话思路
用 DFS 从 0 出发维护当前路径 path，走到 n-1 就把 path 的副本收进结果；DAG 保证无环，无需 visited。

## 怎么做
1. 结果 `res = []`，当前路径 `path = [0]`，从节点 0 开始递归。
2. 进入 `dfs(u)` 先判终点：`u == len(graph) - 1` 时 `res.append(path[:])` 并返回。
3. 否则遍历 `graph[u]` 的每个邻居 `v`：`path.append(v)` → `dfs(v)` → `path.pop()`。
4. 以示例 1 `graph = [[1,2],[3],[3],[]]` 为例，n-1 = 3：先走 0→1，path 变 `[0,1]`，再走 1→3，path 变 `[0,1,3]`，命中终点收下；回溯 pop 掉 3、1，再从 0 走 2，得到 `[0,2,3]`。

```python
def dfs(u):
    if u == n - 1:
        res.append(path[:])
        return
    for v in graph[u]:
        path.append(v)
        dfs(v)
        path.pop()

n = len(graph)
res, path = [], [0]
dfs(0)
```

关键在 `path[:]` 而不是 `path`：示例 1 收下 `[0,1,3]` 后马上会 pop 成 `[0]`，若存引用，最终 res 里两条路径都会变成 `[0]`。

## 复杂度
时间 O(所有路径长度之和)，最坏每条路径长 n，路径数指数级。
空间 O(n) 递归栈 + O(n) 的 path，结果 res 不计入。

## 易错点
- 存 `res.append(path)` 而非 `path[:]`：示例 1 里回溯后 path 被清成 `[0]`，res 中两条路径全变成 `[0]`，输出错成 `[[0],[0]]`；必须拷贝。
- 误加 visited 数组：DAG 中同一节点会在不同路径里重复出现（示例 2 的节点 3 出现在 4 条路径中），加了 visited 会漏掉 `[0,1,3,4]` 等路径；本题靠 DAG 无环保证不无限递归，不需要 visited。

## 如果面试官追问
问：若图不保证无环怎么办？答：加 `on_path` 集合，进入时加入、回溯时移除，只拦截当前路径上的环，仍能枚举所有简单路径。
