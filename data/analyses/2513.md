## 一句话思路
对答案 x 二分，用容斥数出 1..x 中「只能给 arr1」「只能给 arr2」「两边都能用」的个数，判断能否凑够。

## 怎么做
1. 设 `g = gcd(divisor1, divisor2)`，`lcm = divisor1 // g * divisor2`。
2. 对给定 x，记 `only1 = x - x//divisor1 - (x//divisor2 - x//lcm)`，即不被 divisor1 整除、但被 divisor2 整除的个数；对称地 `only2 = x - x//divisor2 - (x//divisor1 - x//lcm)`；`both = x - x//divisor1 - x//divisor2 + x//lcm`。
3. 判定：`only1 + both >= uniqueCnt1` 且 `only2 + both >= uniqueCnt2` 且 `only1 + only2 + both >= uniqueCnt1 + uniqueCnt2`。
4. 二分下界 1、上界 `2*(uniqueCnt1+uniqueCnt2)`，找最小可行 x。

以示例 3（d1=2, d2=4, c1=8, c2=2）验证 x=15：`lcm=4`，`only1 = 15-7-(3-3)=8`，`only2 = 15-3-(7-3)=8`，`both = 15-7-3+3=8`。三个条件 8+8≥8、8+8≥2、8+8+8≥10 全过；x=14 时 `only1=7<8` 失败，故答案 15。

```python
from math import gcd
def ok(x):
    a, b = x // divisor1, x // divisor2
    ab = x // (divisor1 // gcd(divisor1, divisor2) * divisor2)
    only1 = x - a - (b - ab)
    only2 = x - b - (a - ab)
    both = x - a - b + ab
    return (only1 + both >= uniqueCnt1 and
            only2 + both >= uniqueCnt2 and
            only1 + only2 + both >= uniqueCnt1 + uniqueCnt2)
lo, hi = 1, 2 * (uniqueCnt1 + uniqueCnt2)
while lo < hi:
    mid = (lo + hi) // 2
    if ok(mid): hi = mid
    else: lo = mid + 1
```

## 复杂度
时间 O(log(uniqueCnt1+uniqueCnt2))，每次判定 O(1) 次整除与 gcd。
空间 O(1)，只存几个计数变量。

## 易错点
- 当 divisor1 与 divisor2 不互质（如 2 和 4）时，若把 `both` 算成 `x - x//d1 - x//d2`，会漏掉被两者同时整除的数，导致 x=15 被判不可行；必须加回 `x//lcm`。
- 只检查 `only1+only2+both >= c1+c2` 就返回，会漏掉「only1 不够、必须动用 both」的情形；示例 3 中 x=14 总数够但 `only1=7<8`，必须三条判定同时成立。

## 如果面试官追问
要求输出具体分配方案怎么办？答：先按 only1 填 arr1、only2 填 arr2，缺的从 both 里补，再按需把 both 剩余元素分给任一边即可。
