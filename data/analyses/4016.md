## 一句话思路
二分边长 k，用二维前缀和判每个 k×k 全 1，再用「左上/右上/左下/右下」四张最值表判两块能否不重叠放下。

## 怎么做
1. 前缀和 `pre` 使 `pre[r][c]` 为左上角 (0,0) 到 (r-1,c-1) 的 1 的个数，判 k×k 全 1 只需一次四角容斥。
2. 对每个合法左上角 (i,j) 记 `ok[i][j]=True`，再建四张表：`tl[i][j]` 表示行 ≤i、列 ≤j 范围内是否存在合法左上角，其余三张同理。
3. 对每个合法左上角 (i,j)，用四张表检查「上方」「下方」「左侧」「右侧」是否有另一个合法左上角，有则 k 可行。
4. 边长 k 可行则面积 k² 单调，二分 k ∈ [1, min(m,n)//1]，不可行返回 0。

以示例 1 为例，k=2 时合法左上角只有 (0,0) 与 (1,2)；查 `tl` 在 (0,0) 上方无、查 `tr` 在 (1,2) 上方无，但 (0,0) 的右侧列区间 [2,3] 内 `tr` 命中 (1,2)，故 k=2 可行，答案 4。

```python
def can(k):
    ok = [[False]*n for _ in range(m)]
    for i in range(m-k+1):
        for j in range(n-k+1):
            s = pre[i+k][j+k]-pre[i][j+k]-pre[i+k][j]+pre[i][j]
            ok[i][j] = (s == k*k)
    # 四张表 tl/tr/bl/br 用二维前缀 max 递推，此处省略建表
    for i in range(m-k+1):
        for j in range(n-k+1):
            if not ok[i][j]: continue
            if i >= k and tl[i-k][n-1]: return True
            if i+k < m and bl[i+k][j]: return True
            if j >= k and tl[m-1][j-k]: return True
            if j+k < n and tr[i][j+k]: return True
    return False
```

## 复杂度
时间：二分 log(min(m,n)) 次，每次 O(mn) 建表与扫描，共 O(mn log min(m,n))。
空间：`pre`、`ok`、四张表各 O(mn)，共 6 个 m×n 数组。

## 易错点
- 只判「一个在上一个在下」漏掉左右并排：示例 1 的 (0,0) 与 (1,2) 行区间重叠，必须同时查左右两侧，否则 k=2 被判不可行、错答 1。
- 边界写 `i >= k` 而非 `i > 0`：上方正方形底边须 ≤ i-1，即左上角行 ≤ i-k；写成 `i-1` 会把行 i-1 起的方块算进来，与当前块共享单元格。

## 如果面试官追问
要求输出两个正方形坐标怎么办？答：`can(k)` 命中时把当前 (i,j) 和命中的那个左上角一起返回，二分里保留最后一组可行解即可。
