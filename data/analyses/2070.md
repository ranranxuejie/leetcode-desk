## 一句话思路
按价格排序后把美丽值改成前缀最大值，再对每个 query 二分找最后一个 `price <= q` 的位置。

## 怎么做
1. 把 `items` 按 `price` 升序排序。
2. 原地把 `items[i][1]` 改成 `max(items[0..i][1])`，让美丽值随价格单调不减。
3. 对每个 `q`，二分找 `price <= q` 的最右下标 `i`，答案取 `items[i][1]`，找不到则 0。

用示例 1：排序后 `items = [[1,2],[2,4],[3,2],[3,5],[5,6]]`，做前缀最大值后变成 `[[1,2],[2,4],[3,4],[3,5],[5,6]]`。查 `q=3` 时二分落在下标 3（`price=3`），直接读 `5`；查 `q=4` 也落在下标 3，同样得 `5`，不用再扫一遍。

```python
items.sort()
for i in range(1, len(items)):
    items[i][1] = max(items[i][1], items[i - 1][1])

prices = [p for p, _ in items]
ans = []
for q in queries:
    i = bisect_right(prices, q) - 1
    ans.append(items[i][1] if i >= 0 else 0)
```

关键在 `bisect_right(prices, q) - 1`：`bisect_right` 返回第一个 `> q` 的位置，减一才是「最后一个 `<= q`」；`i < 0` 说明最小价格都大于 `q`，返回 0。

## 复杂度
时间：排序 `O(m log m)`，每个查询二分 `O(log m)`，共 `O((m + n) log m)`，`m = len(items)`、`n = len(queries)`。
空间：`prices` 额外 `O(m)`，排序原地，答案数组 `O(n)`。

## 易错点
- 不做前缀最大值：`items` 排序后是 `[[1,2],[2,4],[3,2],[3,5],[5,6]]`，查 `q=3` 二分落在下标 3 得 `5` 没问题，但若查 `q=2` 落在下标 1 得 `4`，而 `q=3` 若二分落在下标 2（`price=3, beauty=2`）就会错答成 `2`。必须先让美丽值单调不减，才能只读一个位置。
- 用 `bisect_left` 或忘记减一：`q=1` 时 `bisect_right([1,2,3,3,5], 1) = 1`，减一得 0 读 `2` 正确；若用 `bisect_left` 得 0，再减一变成 `-1`，会误判成「无物品」返回 0，而正确答案是 `2`。

## 如果面试官追问
问：如果要求返回每个查询选中的物品下标而不是美丽值？
答：前缀最大值时同步记下取到最大值的那个下标，二分后直接返回该下标即可。
