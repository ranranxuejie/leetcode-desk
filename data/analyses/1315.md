## 一句话思路
DFS 向下传「父节点值」和「祖父节点值」，祖父为偶数就把当前节点值累加。

## 怎么做
1. 递归函数带三个参数：`node`、`parent`、`grandparent`，初始 `parent = grandparent = None`。
2. 进入节点先判断 `grandparent is not None and grandparent % 2 == 0`，成立就累加 `node.val`。
3. 向下递归时把 `parent` 传给 `grandparent`、`node.val` 传给 `parent`，左右子树各走一次。

以官方示例 `[6,7,8,2,7,1,3,9,null,1,4,null,null,null,5]` 为例：走到节点 `9` 时，`parent = 2`、`grandparent = 6`，`6 % 2 == 0` 成立，累加 9；走到节点 `1`（7 的左子）时 `grandparent = 7`，奇数，跳过。最终命中的是 9、1、4、5 四个节点，和为 18。

```python
def dfs(node, parent, grandparent):
    if node is None:
        return 0
    total = 0
    if grandparent is not None and grandparent % 2 == 0:
        total += node.val
    total += dfs(node.left, node.val, parent)
    total += dfs(node.right, node.val, parent)
    return total

return dfs(root, None, None)
```

关键点：传参顺序是 `(node.val, parent)`，即当前值变成下一层的父、原父变成下一层的祖父，写反了就会把父节点当祖父判断。

## 复杂度
时间 O(n)：每个节点访问一次，n 为节点数。
空间 O(h)：递归栈深度等于树高 h，最坏链状树 O(n)，无额外数组。

## 易错点
- 根节点和根的左右孩子没有祖父 → 若把 `grandparent` 初始化为 0 或直接 `grandparent % 2`，`None % 2` 会抛 `TypeError`，或把 0 当偶数误判。正确做法是初始传 `None` 并先判 `is not None`。
- 示例中节点 `1`（7 的左子）祖父是 7 为奇数 → 若只判断父节点 `2` 是偶数就累加，会把 1 和 4 都算进去得到 23。正确做法是判断 `grandparent` 而非 `parent`。

## 如果面试官追问
问：节点数涨到 10^7、递归会爆栈怎么办？
答：改成显式栈存 `(node, parent_val, grandparent_val)` 三元组迭代，空间仍是 O(h)，避开 Python 默认递归深度限制。
