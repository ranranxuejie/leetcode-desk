## 一句话思路
用滑动窗口维护合法区间，右端每加入一个字符就检查以它结尾、长度 ≤10 的后缀是否命中 forbidden，命中则把左端跳到该后缀起点之后。

## 怎么做
1. 把 forbidden 全部放进集合 `bad`，因为每个串长 ≤10，只需检查窗口内长度 1..10 的后缀。
2. 右指针 `r` 从 0 遍历 word，内层 `L` 从 1 到 10 取 `word[r-L+1:r+1]`，一旦在 `bad` 中就把 `l` 更新为 `r-L+2`。
3. 每轮用 `r-l+1` 更新答案。

以 `word="cbaaaabc"`、`bad={"aaa","cb"}` 为例：`r=1` 时后缀 `"cb"` 命中，`l` 跳到 2；`r=4` 时后缀 `"aaa"`（`word[2:5]`）命中，`l` 跳到 5；最终最长窗口是 `r=7,l=4` 的 `"aabc"`，长度 4。

```python
bad = set(forbidden)
l = 0
ans = 0
for r in range(len(word)):
    for L in range(1, min(10, r - l + 1) + 1):
        if word[r - L + 1:r + 1] in bad:
            l = r - L + 2
            break
    ans = max(ans, r - l + 1)
```

关键点：内层上界写 `min(10, r-l+1)`，只扫当前窗口内的后缀，避免把已被排除的字符重新拉回来。

## 复杂度
时间 O(10n)：n 为 word 长度，每个 r 最多查 10 个后缀，切片本身 O(10)。
空间 O(m·10)：m 为 forbidden 个数，集合存全部禁用串，无其他额外数组。

## 易错点
- 输入 `word="aaaa"`、`forbidden=["aa"]`：若内层只查长度 1 或只查最长后缀，会漏掉 `"aa"` 导致答案偏大；必须枚举 1..10 全部长度。
- 输入 `word="cbaaaabc"`、`forbidden=["cb"]`：若命中后写成 `l = r - L + 1`（少加 1），窗口会把禁用串的末字符留在里面，答案错成 5；正确是 `l = r - L + 2`，跳过整个禁用串。

## 如果面试官追问
若 forbidden 串长上限放大到 10^5 怎么办？答：改用 Aho-Corasick 自动机，在扫描 word 时同步匹配所有模式，仍能 O(n + 总长) 定位每个右端最靠右的禁用串起点。
