## 一句话思路
用后缀二维前缀和统计剩余披萨苹果数，记忆化搜索 `(r, c, k)`：每次枚举切法，只保留切下部分含苹果的分支。

## 怎么做
1. 预处理 `pre[i][j]` 为 `pizza[i:][j:]` 的苹果数，倒序累加，`pre[r][c]` 即当前剩余块苹果总数。
2. 状态 `dfs(r, c, k)`：左上角在 `(r, c)`、还要切出 `k` 块时的方案数；`k == 1` 时若 `pre[r][c] > 0` 返回 1，否则 0。
3. 垂直切：枚举 `nc in (c+1, cols)`，切下左边 `[r:, c:nc]`，苹果数 `pre[r][c] - pre[r][nc]`，大于 0 才累加 `dfs(r, nc, k-1)`。
4. 水平切同理，枚举 `nr`，切下上边 `[r:nr, c:]`，苹果数 `pre[r][c] - pre[nr][c]`。

以示例 1 `pizza = ["A..","AAA","..."]`、`k = 3` 为例：`pre[0][0] = 4`。第一次垂直切在 `nc = 1`，左边一列含 1 个苹果（`pre[0][0] - pre[0][1] = 4 - 3 = 1`），合法，转入 `dfs(0, 1, 2)`；若切在 `nc = 2`，左边两列苹果数 `4 - 1 = 3` 也合法。最终三条路径都要求最后一块非空。

```python
def dfs(r, c, k):
    if k == 1:
        return 1 if pre[r][c] > 0 else 0
    if (r, c, k) in memo:
        return memo[(r, c, k)]
    ans = 0
    for nc in range(c + 1, cols):
        if pre[r][c] - pre[r][nc] > 0:
            ans += dfs(r, nc, k - 1)
    for nr in range(r + 1, rows):
        if pre[r][c] - pre[nr][c] > 0:
            ans += dfs(nr, c, k - 1)
    memo[(r, c, k)] = ans % (10**9 + 7)
    return memo[(r, c, k)]
```

## 复杂度
时间：状态数 `rows*cols*k`，每状态枚举 `rows+cols` 刀，约 `O(rows*cols*k*(rows+cols))`。
空间：`pre` 表 `O(rows*cols)`，`memo` 字典 `O(rows*cols*k)`。

## 易错点
- `k = 1` 且整块无苹果（如 `pizza = ["..."]`）→ 若直接返回 1 会错成 1，正确是 `pre[r][c] > 0` 才返回 1，否则 0。
- 切下部分苹果数为 0 仍继续递归 → 会把「送出一块空披萨」的非法方案算进去，示例 1 中切在 `nc = 3`（左边三列含 2 苹果）合法但切在 `nc` 使左侧为 0 时必须跳过，判断条件写成 `pre[r][c] - pre[r][nc] > 0` 而非 `>= 0`。

## 如果面试官追问
若 `k` 增大到 50 且 `rows, cols` 不变，怎么优化？答：状态数仍是 `rows*cols*k`，但可把「剩余苹果数 < k」的状态直接剪枝返回 0，减少无效枚举。
