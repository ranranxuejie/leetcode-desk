## 一句话思路
以每个右端点 i 维护「以 i 结尾的所有子数组 AND」的去重集合，集合大小 ≤ 30，逐位收缩即可。

## 怎么做
1. 关键性质：固定右端点 i，随着左端点左移，AND 只会不断丢失二进制位，所以不同取值最多 30 个（nums[i] ≤ 10^9 < 2^30）。
2. 用 `cur` 存上一轮的 `(AND值, 出现次数)` 列表，本轮对每个 `(v, c)` 算 `v & nums[i]`，相邻相同值合并计数。
3. 再把 `(nums[i], 1)` 加进去（左端点 = i 的子数组），累加所有值等于 k 的计数。
4. 以 `nums = [1,1,2], k = 1` 为例：i=0 时 `cur = [(1,1)]`，答案 +1；i=1 时 `cur = [(1,2)]`，答案 +2；i=2 时 `cur = [(0,2),(2,1)]`，无 k=1，答案停在 3。

```python
ans = 0
cur = []                      # [(and值, 个数)]
for x in nums:
    nxt = []
    for v, c in cur:
        nv = v & x
        if nxt and nxt[-1][0] == nv:
            nxt[-1] = (nv, nxt[-1][1] + c)
        else:
            nxt.append((nv, c))
    if nxt and nxt[-1][0] == x:
        nxt[-1] = (x, nxt[-1][1] + 1)
    else:
        nxt.append((x, 1))
    cur = nxt
    ans += sum(c for v, c in cur if v == k)
```

## 复杂度
时间：O(n · 30)，每个右端点最多 30 个不同 AND 值，n 来自数组长度。
空间：O(30)，只存当前轮的 `cur`/`nxt` 两个列表。

## 易错点
- `nums = [1,1,2]` 若只存 AND 值不存次数，i=1 时会把两个左端点算成 1 个，答案错成 2；必须用 `(值, 次数)` 合并计数。
- `k = 0` 且 `nums = [0,0]` 时，若提前用 `v < k` 剪枝会漏掉 AND 继续降到 0 的子数组；判断条件只能是 `v == k`，不能假设 AND 单调靠近 k。

## 如果面试官追问
问：n 变成 10^6 还能这么做吗？
答：能，仍是 O(30n)，瓶颈是 Python 循环常数，可把 `cur` 换成两个平行数组减少元组开销。
