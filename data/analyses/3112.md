## 一句话思路
在 Dijkstra 松弛时加一道闸：新距离必须严格小于 `disappear[v]`，否则这条边作废。

## 怎么做
1. 用 `disappear` 建邻接表，重边全保留（本题不删重边，堆会自然淘汰差的）。
2. 起点 `dist[0] = 0`，其余 `2**31 - 1`；堆里放 `(0, 0)`。
3. 弹出 `(d, u)` 时若 `d != dist[u]` 就跳过；否则对每条 `(v, w)` 算 `nd = d + w`，只有 `nd < disappear[v] and nd < dist[v]` 才更新入堆。
4. 最后把仍是 `2**31 - 1` 的位置改成 `-1`。

拿示例 1：`n=3, edges=[[0,1,2],[1,2,1],[0,2,4]], disappear=[1,1,5]`。弹出 `(0,0)`，到 1 得 `nd=2`，但 `2 < disappear[1]=1` 为假，节点 1 直接丢弃；到 2 得 `nd=4 < 5`，入堆。之后堆里没有能改进 2 的路径，答案 `[0,-1,4]`。注意节点 1 被丢弃后，经 1 到 2 的路径 `0→1→2` 也就不会生成，这正是题意要的。

```python
import heapq
dist = [2**31 - 1] * n
dist[0] = 0
pq = [(0, 0)]
while pq:
    d, u = heapq.heappop(pq)
    if d != dist[u]:
        continue
    for v, w in adj[u]:
        nd = d + w
        if nd < disappear[v] and nd < dist[v]:
            dist[v] = nd
            heapq.heappush(pq, (nd, v))
return [-1 if x == 2**31 - 1 else x for x in dist]
```

## 复杂度
时间 O((n + m) log n)，m 为边数，每条边最多触发一次入堆，堆操作 log n。
空间 O(n + m)，邻接表存 2m 条有向边，dist 与堆各 O(n)。

## 易错点
- 起点判断漏掉：`disappear[0]` 可能为 1，若把闸门也套在起点上，`0 < 1` 成立没事；但若写成 `d <= disappear[u]` 才继续，示例 3 中 `disappear=[1,1]`、到 1 时 `d=1`，`1 <= 1` 会放行，错答 `[0,1]`，正确是 `[0,-1]`——必须严格小于。
- 用 `dist[v]` 初值当「不可达」再和 `disappear` 比较：若把初值设成 `10**9` 而 `disappear[v]` 最大 1e5，`nd < dist[v]` 恒真没问题；但若把初值设成 `0` 或 `disappear[v]` 本身，松弛条件会失效，节点永远不更新，全输出 -1。

## 如果面试官追问
问：若要求输出到达每个节点的具体路径怎么办？
答：加 `parent[v] = u`，松弛成功时记录，最后从目标节点沿 parent 回溯到 0 再反转。
