## 一句话思路
用极坐标：角度均匀取，半径取 `R*sqrt(u)`，因为面积随半径平方增长，直接均匀取半径会往圆心堆。

## 怎么做
1. 构造函数里存下 `self.r`、`self.xc`、`self.yc`，`randPoint` 每次只做常数次随机。
2. 取角度 `theta = 2*pi*random()`，在 `[0, 2π)` 上均匀。
3. 取半径 `rho = self.r * sqrt(random())`，开方是均匀性的关键。
4. 返回 `[self.xc + rho*cos(theta), self.yc + rho*sin(theta)]`。

以示例 `radius=1.0, x_center=0.0, y_center=0.0` 为例：若某次 `random()` 得 `0.25`，则 `rho = 1.0*sqrt(0.25) = 0.5`；若 `theta` 得 `π/2`，点就是 `[0.0, 0.5]`。若误写成 `rho = 1.0*0.25`，同样的随机数只落到半径 0.25，半径 0.5 以内的点被系统性压向圆心。

```python
import math, random

def rand_point(r, xc, yc):
    theta = 2 * math.pi * random.random()
    rho = r * math.sqrt(random.random())
    return [xc + rho * math.cos(theta), yc + rho * math.sin(theta)]
```

## 复杂度
时间：每次 `randPoint` 是 O(1)，只有 1 次 sqrt、1 次 cos、1 次 sin。
空间：O(1)，只存三个标量，返回的 2 元素列表不算额外结构。

## 易错点
- 半径写成 `r * random()` → 点密度正比于 1/rho，圆心附近过密，示例里 `[-0.02493, -0.38077]` 这类近心点会明显偏多 → 必须 `r * sqrt(random())`，让半径落在 `[0, rho]` 的概率等于 `rho²/r²`。
- 角度用 `random()*pi` 只覆盖上半圆 → 返回的 y 永远非负，示例中 `-0.38077` 这种负 y 点根本出不来 → 角度系数必须是 `2*pi`。

## 如果面试官追问
问：不用 sqrt，改用拒绝采样行不行？
答：行，在 `[-r, r]²` 里撒点，`dx²+dy² <= r²` 才收，期望 4/π ≈ 1.27 次，但 `r=10^8` 时坐标量级大、边界比较要小心浮点误差，极坐标法更稳。
