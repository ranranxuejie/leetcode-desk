## 一句话思路
用三个滚动变量代替数组做递推，因为 `T(n)` 只依赖前三个值，空间压到 O(1)。

## 怎么做
1. 先处理 `n < 3` 的边界，直接返回 `[0, 1, 1][n]`。
2. 初始化 `a, b, c = 0, 1, 1`，分别代表 `T(0)`、`T(1)`、`T(2)`。
3. 从 `i = 3` 循环到 `n`，每轮算出 `a + b + c`，再把三个变量整体后移一位。
4. 循环结束后 `c` 就是 `T(n)`。

以官方示例 `n = 4` 为例：初始 `a=0, b=1, c=1`。`i=3` 时 `s = 0+1+1 = 2`，滚动后 `a=1, b=1, c=2`；`i=4` 时 `s = 1+1+2 = 4`，滚动后 `c=4`，返回 4。关键中间值就是 `i=3` 那轮的 `s=2`，它正是 `T(3)`。

```python
if n < 3:
    return (0, 1, 1)[n]
a, b, c = 0, 1, 1
for i in range(3, n + 1):
    a, b, c = b, c, a + b + c
return c
```

滚动赋值必须写成 `a, b, c = b, c, a + b + c` 这一行，Python 会先算右边再统一赋值；拆成三行 `a = b; b = c; c = a + b + c` 就会用到已被覆盖的 `a`，结果错。

## 复杂度
时间：O(n)，循环执行 `n - 2` 次，每次常数加法。
空间：O(1)，只开 `a, b, c` 三个变量，没有数组或递归栈。

## 易错点
- 输入 `n = 0` 或 `n = 1` → 若直接进循环 `range(3, n+1)` 为空、返回初始 `c=1`，`n=0` 会错成 1 → 必须先判 `n < 3` 返回 `(0, 1, 1)[n]`。
- 输入 `n = 4` → 若把循环写成 `range(3, n)`，只跑到 `i=3`，返回 `c=2` 而不是 4 → 上界必须是 `n + 1`，因为要算到 `T(n)` 本身。

## 如果面试官追问
问：若 n 放大到 10^9 怎么优化？
答：用 3×3 矩阵快速幂，把递推写成矩阵乘法后二分幂，时间降到 O(log n)。
