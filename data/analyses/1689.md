## 一句话思路
答案就是 n 各位数字里的最大值，因为每一位的 1 都要靠不同的十-二进制数来凑。

## 怎么做
1. 把 n 看成一列竖式，第 i 位需要 `d = int(n[i])` 个 1 叠起来。
2. 每个十-二进制数在某一位上最多贡献一个 1，所以凑出某一位的 d 至少需要 d 个数。
3. 取所有位需求的最大值 `max(digit)`，它就是下界。
4. 这个下界可达：取 `max(digit)` 个数，第 k 个数在第 i 位放 1 当且仅当 `k <= int(n[i])`，逐位相加恰好等于 n。

以 `n = "82734"` 为例，逐位需求是 8、2、7、3、4，最大值 8，所以答案是 8。构造时第 1 个数在最高位放 1（8≥1），第 8 个数只在最高位放 1（其余位需求都 < 8），八个数相加正好是 82734。

```python
best = 0
for ch in n:
    d = ord(ch) - ord('0')
    if d > best:
        best = d
return best
```

等价写法 `return max(int(c) for c in n)`，但循环版避免生成器开销，10^5 长度下更稳。

## 复杂度
时间 O(len(n))，只扫一遍字符串，每位做一次 `ord` 减法。
空间 O(1)，只存 `best` 一个整数，不额外开数组。

## 易错点
- 输入 `n = "10"` → 若误以为答案是位数或 1 的个数，会得 2 或 1；正确是 `max(1,0)=1`，因为 10 本身就是十-二进制数。
- 输入 `n = "1000"` → 若把前导零之外的 0 也计入统计，会得 4；正确只取非零位的最大值 1，0 位不需要任何数贡献。

## 如果面试官追问
要求输出具体方案怎么办？答：按 `k = 1..best` 逐位判断 `k <= int(n[i])` 拼出每个数，O(best·len(n)) 时间。
