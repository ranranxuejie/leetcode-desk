## 一句话思路
用一个栈模拟书架，按 putIn 顺序压入，每压一个就尽量弹出与 takeOut 当前位相同的栈顶。

## 怎么做
1. 维护栈 `st` 和指向 takeOut 的指针 `j = 0`。
2. 遍历 `putIn` 的每个 `x`，先 `st.append(x)`。
3. 压入后立刻用 `while st and st[-1] == takeOut[j]` 循环弹出并 `j += 1`。
4. 遍历结束若 `j == len(takeOut)` 则返回 `True`，否则 `False`。

以示例 1 为例，压到 9 时 `st = [6,7,8,9]`，`takeOut[0] = 9`，弹出后 `st = [6,7,8]`、`j = 1`；继续压 10、11，`st[-1] = 11 == takeOut[1]`，连续弹出 11、10，`j = 3`，此时 `st[-1] = 8 == takeOut[3]`，再连弹 8、7、6，`j = 6`，返回 `True`。

```python
st, j = [], 0
for x in putIn:
    st.append(x)
    while st and j < len(takeOut) and st[-1] == takeOut[j]:
        st.pop()
        j += 1
return j == len(takeOut)
```

关键点：弹出必须用 `while` 而不是 `if`，因为一次压入可能触发连续多次弹出（示例 1 压入 11 后连弹 11、10、8、7、6 中的前两个，后续压入不再发生，靠 while 才能一路清空）。

## 复杂度
时间 O(n)：每个元素最多入栈一次、出栈一次，n 为 putIn 长度。
空间 O(n)：最坏情况（takeOut 逆序）栈 `st` 存满 n 个元素。

## 易错点
- 输入 `putIn = [6,7,8,9,10,11], takeOut = [11,9,8,10,6,7]` → 若用 `if` 只弹一次，压入 11 后弹出 11、`j = 1`，接着 `st[-1] = 10 != 9` 就卡住，最终 `j < 6` 返回 `False` 看似正确，但换示例 1 会误判 → 必须用 `while` 连续弹。
- 输入 `putIn = [], takeOut = []` → 若循环里没判 `j < len(takeOut)` 就访问 `takeOut[j]`，空数组会 `IndexError` → 在 while 条件里加 `j < len(takeOut)` 短路保护。

## 如果面试官追问
问：若 putIn 有重复编号怎么办？
答：题面保证编号互不相同，有重复时需改用计数或记录位置，不能只靠栈顶相等判断。
