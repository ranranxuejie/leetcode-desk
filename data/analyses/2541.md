## 一句话思路
逐位看差值 `nums2[i]-nums1[i]`，必须被 `k` 整除且正负总和相抵，答案就是正差值的总和除以 `k`。

## 怎么做
1. 遍历每一位，算 `d = nums2[i] - nums1[i]`，若 `d % k != 0` 直接返回 `-1`。
2. 累加所有正差值到 `need`，所有负差值到 `give`（或直接累加 `d` 看是否为 0）。
3. 若 `need + give != 0`，说明总量对不上，返回 `-1`。
4. 否则返回 `need // k`，因为一次操作只能把一个 `+k` 和一个 `-k` 配对。

以示例 1 为例：`nums1=[4,3,1,4]`，`nums2=[1,3,7,1]`，`k=3`。逐位差值 `d = [-3, 0, 6, -3]`，都能被 3 整除；正差值和 `need = 6`，负差值和 `give = -6`，相抵为 0，答案 `6 // 3 = 2`。

```python
need = give = 0
for a, b in zip(nums1, nums2):
    d = b - a
    if d % k != 0:
        return -1
    if d > 0:
        need += d
    else:
        give += d
if need + give != 0:
    return -1
return need // k
```

注意 `k == 0` 时不能做 `% k`，需单独判断：此时只有 `nums1 == nums2` 才返回 0，否则 -1。

## 复杂度
时间：O(n)，一次遍历，`zip` 逐位比较。
空间：O(1)，只开了 `need`、`give` 两个累加变量。

## 易错点
- `k == 0` 且 `nums1 != nums2`：直接跑 `d % k` 会抛 `ZeroDivisionError`，正确做法是先判 `k == 0`，相等返回 0，否则 -1。
- 只看正差值不看负差值：如 `nums1=[1,1]`、`nums2=[4,1]`、`k=3`，`need=3` 但 `give=0`，若直接返回 `need//k=1` 就错了，必须校验 `need + give == 0`。

## 如果面试官追问
问：若要求输出具体操作序列怎么办？
答：把正差值下标和负差值下标分别入栈，每次各弹一个配对，共 `need//k` 次。
