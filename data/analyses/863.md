## 一句话思路
把树看成无向图：先 DFS 建每个结点到父结点的映射，再从 target 出发 BFS 走 k 层。

## 怎么做
1. 一次 DFS 用 `parent` 字典记录每个结点的父结点，根 `3` 的父为 `None`。
2. 从 `target=5` 出发 BFS，邻居取 `node.left`、`node.right`、`parent[node]` 三者中非 `None` 的。
3. 第 `k` 层出队时收集 `node.val`；`k=0` 直接返回 `[target.val]`。

关键中间值：示例 1 中 `parent[5]=3`、`parent[7]=2`、`parent[1]=3`。BFS 第 1 层从 5 得到 `{3,6,2}`，第 2 层从 3 得到 1、从 2 得到 7 和 4，故答案 `[1,7,4]`。

```python
parent = {}
def dfs(node, p):
    if not node: return
    parent[node] = p
    dfs(node.left, node); dfs(node.right, node)
dfs(root, None)

q, seen = deque([target]), {target}
for _ in range(k):
    for _ in range(len(q)):
        cur = q.popleft()
        for nb in (cur.left, cur.right, parent[cur]):
            if nb and nb not in seen:
                seen.add(nb); q.append(nb)
return [x.val for x in q]
```

`seen` 必须存结点对象而非 `val`，否则 `parent[cur]` 回指时会重复入队。

## 复杂度
时间 O(n)：建父表 DFS 一遍，BFS 每个结点至多入队一次。
空间 O(n)：`parent` 字典 n 项、`seen` 集合 n 项、队列最宽 O(n)。

## 易错点
- `k=0` 时若仍进 BFS 循环，`range(0)` 不执行、直接返回空列表 → 漏掉 target 自己。正确做法是循环前特判 `if k == 0: return [target.val]`。
- 只往左右孩子走、不查 `parent[cur]` → 示例 1 中从 5 永远到不了 3，答案只剩 `[7,4]`，丢掉 1。正确做法是三邻居齐取，且用 `seen` 挡住回边，否则 5→3→5 无限循环。

## 如果面试官追问
问：结点数涨到 10^5、k 也很大怎么办？
答：仍是 O(n)，但递归 DFS 会爆栈，改显式栈建父表，BFS 队列用 `deque` 即可。
