## 一句话思路
自底向上 DFS 后序，每个节点只依赖子节点的完成时间，返回 `latest + (latest - earliest) + baseTime[i]`。

## 怎么做
1. 用 `edges` 建子节点表 `children[u].append(v)`，因为边方向是父→子，直接存即可。
2. 对节点 `u` 后序 DFS：先递归拿到所有子节点的完成时间。
3. 叶子直接返回 `baseTime[u]`；非叶子取 `earliest = min(...)`、`latest = max(...)`，返回 `latest + (latest - earliest) + baseTime[u]`。
4. 答案就是 `dfs(0)`。

以示例 3 为例，`baseTime = [5,8,2,1]`：节点 2 的子节点 3 返回 1，于是 `earliest = latest = 1`，节点 2 返回 `1 + 0 + 2 = 3`；节点 0 的子节点返回 8 和 3，`earliest = 3, latest = 8`，返回 `8 + (8-3) + 5 = 18`。

```python
def dfs(u):
    if not children[u]:
        return baseTime[u]
    ts = [dfs(v) for v in children[u]]
    lo, hi = min(ts), max(ts)
    return hi + (hi - lo) + baseTime[u]
```

注意 `n = 1` 时 `edges` 为空，`children[0]` 为空，直接返回 `baseTime[0]`，无需特判。

## 复杂度
时间 O(n)：每个节点被访问一次，子节点列表总长 n-1。
空间 O(n)：`children` 存 n-1 条边，递归栈最坏 O(n)（链状树）。

## 易错点
- 链状树如 `edges = [[0,1],[1,2],...]` 深度达 10^5 → Python 默认递归上限 1000 会 `RecursionError` → 需 `sys.setrecursionlimit(300000)`，或改写成显式栈的迭代后序。
- 把 `ownDuration` 写成 `latest - earliest + baseTime[i]` 后忘记再加 `latest`，示例 2 会得 5 而不是 12 → 返回式必须是 `latest + ownDuration`，即 `2*latest - earliest + baseTime[i]`。

## 如果面试官追问
问：n 扩大到 10^6 且树是链怎么办？
答：递归栈会爆，改成迭代后序（栈存 `(u, visited)`）或按拓扑序从叶子往上推，空间仍是 O(n) 但不受递归深度限制。
