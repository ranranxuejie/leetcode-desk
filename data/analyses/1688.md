## 一句话思路
每场比赛恰好淘汰一支队伍，从 n 支淘汰到 1 支必然打 n-1 场，直接返回 n-1。

## 怎么做
1. 把「配对次数」换成「淘汰人数」：每场产生一个败者，胜者留下。
2. 起点 n 支、终点 1 支，净减少 n-1 支，所以总场次恒为 n-1。
3. 用 n=7 验证：7→4 淘汰 3，4→2 淘汰 2，2→1 淘汰 1，合计 3+2+1=6=n-1。
4. 代码只有一行，不需要循环。

```python
def numberOfMatches(n):
    return n - 1
```

模拟写法对照（面试官要过程时给这个）：

```python
def numberOfMatches(n):
    total = 0
    while n > 1:
        total += n // 2          # 本轮场次
        n = n // 2 + n % 2       # 晋级队伍数
    return total
```

n=7 时循环里依次是 `total=3, n=4` → `total=5, n=2` → `total=6, n=1`，退出返回 6。

## 复杂度
时间：O(1)，公式法不循环；模拟法 O(log n)，队伍数每轮约减半。
空间：O(1)，只存 total 和 n 两个整数。

## 易错点
- n=1 → 若写成 `while n > 0` 再累加，会多算一轮甚至死循环；正确做法是循环条件 `n > 1`，公式法直接 `n-1=0`。
- 奇数轮晋级数算错 → n=7 时若写 `n = n // 2` 得 3 而不是 4，后续变成 3→1 只加 1 场，总数错成 5；正确写法是 `n // 2 + n % 2`，把轮空那支加回去。

## 如果面试官追问
问：n 到 10**18 还能算吗？答：公式法 O(1) 直接返回 n-1，模拟法也只需约 60 轮，都不受影响。
