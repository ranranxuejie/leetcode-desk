## 一句话思路
用两个栈 `in_stack` 和 `out_stack`，push 只进 `in_stack`，pop/peek 时把 `in_stack` 整体倒进 `out_stack`，倒序两次即还原队列顺序。

## 怎么做
1. `push(x)`：直接 `in_stack.append(x)`。
2. `pop()`/`peek()`：若 `out_stack` 为空，把 `in_stack` 全部 `pop` 出来 `append` 进 `out_stack`。
3. 之后所有出队操作只碰 `out_stack` 的栈顶。
4. `empty()`：两个栈都空才返回 `True`。

以官方示例为例：push(1)、push(2) 后 `in_stack = [1, 2]`（栈顶是 2）。第一次 `peek()` 触发搬运，`out_stack` 变成 `[2, 1]`，栈顶是 1，正好是队首，返回 1。此后 `pop()` 直接弹 `out_stack` 顶，仍是 1。

```python
def push(self, x):
    self.in_stack.append(x)

def _shift(self):
    if not self.out_stack:
        while self.in_stack:
            self.out_stack.append(self.in_stack.pop())

def pop(self):
    self._shift()
    return self.out_stack.pop()

def peek(self):
    self._shift()
    return self.out_stack[-1]

def empty(self):
    return not self.in_stack and not self.out_stack
```

关键在 `_shift` 的 `if not self.out_stack` 判断：只有 `out_stack` 空了才搬，否则会把新元素压到旧队首上面，顺序就乱了。

## 复杂度
时间：每次元素最多被搬一次，均摊 O(1)，单次 `pop` 最坏 O(n)。
空间：两个栈合计存 n 个元素，额外 O(n)。

## 易错点
- 连续 `push(3)` 后直接 `pop()`：若每次 `pop` 都无条件搬运，`out_stack` 里残留的 `[2, 1]` 会被新倒进来的 3 压住，弹出 3 而非 1。正确做法是仅在 `out_stack` 为空时搬运。
- `push(1)`、`push(2)`、`pop()` 后再 `peek()`：`pop` 已把 `out_stack` 搬空，此时 `peek` 若不重新触发 `_shift` 会访问空栈报错。正确做法是 `peek` 和 `pop` 都先调 `_shift`。

## 如果面试官追问
问：能否让 `pop` 严格 O(1)？
答：可以，push 时就把元素倒进 `out_stack` 维护队首，代价是 push 变 O(n)，本质是摊还位置互换。
