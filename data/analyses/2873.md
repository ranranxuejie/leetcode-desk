## 一句话思路
枚举 j，维护 j 左侧最大值 `max_i`，用 `(max_i - nums[j]) * nums[k]` 对每个 k 取最大。

## 怎么做
1. 固定 j 时，`nums[i] - nums[j]` 要最大，只需 i 取 `[0, j)` 内的最大值 `max_i`，与具体下标无关。
2. 于是对每个 j，先更新 `max_i = max(max_i, nums[j-1])`，再枚举 k > j 计算候选值。
3. 用 `ans = max(ans, (max_i - nums[j]) * nums[k])` 累积，最后 `return max(ans, 0)`。

以 `nums = [12,6,1,2,7]` 为例：j=2 时 `max_i = max(12,6) = 12`，k=4 得 `(12-1)*7 = 77`，这就是最终答案；j=1 时 `max_i=12`，k=4 得 `(12-6)*7=42`，被 77 压过。

```python
n = len(nums)
ans = 0
max_i = nums[0]
for j in range(1, n - 1):
    max_i = max(max_i, nums[j - 1])
    for k in range(j + 1, n):
        ans = max(ans, (max_i - nums[j]) * nums[k])
return ans
```

注意 `max_i` 在进入 j 循环体时先吸收 `nums[j-1]`，保证它只覆盖 `[0, j)`；若写成先算候选再更新，j=1 时 `max_i` 还是 `nums[0]` 之外的值就会漏掉 i=0 这一项。

## 复杂度
时间 O(n²)：外层 j 走 n 步，内层 k 平均 n/2 步。
空间 O(1)：只开了 `ans`、`max_i`、`j`、`k` 四个标量。

## 易错点
- 输入 `[1,2,3]` → 若把 `ans` 初始化为 `-inf` 或直接返回 `ans`，会输出 `-3` → 正确做法是 `ans` 初值取 0，或返回 `max(ans, 0)`，因为题目要求全负时返回 0。
- 输入 `[12,6,1,2,7]` → 若在 j 循环里先算 `(max_i - nums[j]) * nums[k]` 再更新 `max_i`，j=1 时 `max_i` 仍是 `nums[0]=12` 没问题，但若把更新写成 `max_i = max(max_i, nums[j])`，j=2 时 `max_i` 会变成 12 仍对，可一旦数组是 `[5,100,1,2]`，j=1 时 `max_i` 被错误更新为 100，i 就取到了 j 本身 → 必须只吸收 `nums[j-1]`，保证 i < j。

## 如果面试官追问
若 n 放大到 10⁵ 怎么办？答：把内层 k 的枚举换成后缀最大值 `suf_max[j+1]`，O(n) 一遍扫完，因为固定 j 后 k 只需取右侧最大 `nums[k]`。
