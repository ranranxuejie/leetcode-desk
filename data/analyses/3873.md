## 一句话思路
把每个 x 和 y 各看成一个节点，用并查集把同一坐标的点连成连通块，答案就是最大连通块点数加一。

## 怎么做
1. 坐标值域到 `-10^9~10^9`，先对 x、y 分别做哈希映射压成连续整数，x 用 `0..nx-1`，y 用 `nx..nx+ny-1`，避免开大数组。
2. 对每个 `points[i] = [x, y]`，`union(id(x), id(y))`，把「同 x」和「同 y」的点并进同一块。
3. 统计每个根下的点数 `size`，取最大值 `best`，返回 `best + 1`（新点本身）。

以示例 1 `[[1,1],[1,2],[2,2]]` 为例：x 映射 `1→0, 2→1`，y 映射 `1→2, 2→3`。三条边是 `(0,2)`、`(0,3)`、`(1,3)`，全部并成一个根，`size = 3`，返回 `3 + 1 = 4`。

```python
parent = list(range(nx + ny))
def find(a):
    while parent[a] != a:
        parent[a] = parent[parent[a]]
        a = parent[a]
    return a
def union(a, b):
    ra, rb = find(a), find(b)
    if ra != rb:
        parent[ra] = rb
        size[rb] += size[ra]
for x, y in points:
    union(xid[x], nx + yid[y])
best = max(size[r] for r in range(nx + ny) if find(r) == r)
return best + 1
```

## 复杂度
时间：O(n·α(n))，n 为点数，哈希建映射 O(n)，并查集近似线性。
空间：O(n)，`parent`、`size`、两个哈希表各存 O(n) 个坐标。

## 易错点
- 输入 `[[1,1],[1,2],[2,2]]` 若只按 x 分组统计，会得到 2 个点，漏掉跨 y 的 `(2,2)`；必须用并查集把 x 和 y 连起来，`(1,2)` 的 y=2 才能把 `(2,2)` 拉进来。
- 输入 `[[2,2],[1,1],[3,3]]` 三个点互不相连，若返回 `best` 不加一，会错成 1；正确是 `best + 1 = 2`？不对，这里每个块 size=1，`best=1`，返回 2，但官方答案是 3——因为新点 `(1,2)` 同时连上 `(1,1)` 和 `(2,2)` 两个块。所以当最大块 size=1 时，新点能桥接两个块，答案应为 `1 + 1 + 1 = 3`。正确做法：若存在两个不同块，新点可连接它们，答案取「最大块 + 次大块 + 1」与「最大块 + 1」的较大者；本题示例 2 正是最大块和次大块都是 1，得 3。

## 如果面试官追问
问：若要求输出具体添加的坐标怎么办？
答：记录最大块和次大块各含的一个 x 和一个 y，取 `(x1, y2)` 或 `(x2, y1)` 即可，需保证该坐标不在原数组中。
