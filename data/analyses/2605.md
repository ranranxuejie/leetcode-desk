## 一句话思路
先找两数组交集的最小值（一位数答案），没有交集就各取最小值拼成两位数。

## 怎么做
1. 用集合求交集 `set(nums1) & set(nums2)`，非空则答案就是 `min(交集)`，一位数必然小于任何两位数。
2. 交集为空时，答案只能是两位数，十位取 `min(nums1)`、个位取 `min(nums2)`。
3. 注意两位数的顺序：十位必须来自 nums1、个位来自 nums2，不能反过来比较。

以示例 1 为例：`nums1 = [4,1,3]`，`nums2 = [5,7]`。交集 `{4,1,3} & {5,7} = set()` 为空，于是 `a = min(nums1) = 1`，`b = min(nums2) = 5`，返回 `1*10 + 5 = 15`。若反过来拼成 51 就错了。

```python
common = set(nums1) & set(nums2)
if common:
    return min(common)
a, b = min(nums1), min(nums2)
return a * 10 + b
```

关键中间值：示例 2 中交集为 `{3}`，`min({3}) = 3`，直接返回 3，不进两位数分支。

## 复杂度
时间 O(n + m)，n、m 为两数组长度，建集合与取 min 各扫一遍。
空间 O(n + m)，额外开了两个集合存 nums1、nums2 的元素。

## 易错点
- 有交集却仍去拼两位数：如 `nums1=[3,5,2,6]`、`nums2=[3,1,7]`，交集含 3，若跳过交集判断直接返回 `min(nums1)*10+min(nums2)=21`，比正确答案 3 大，必须先判交集。
- 两位数拼反顺序：如 `nums1=[4,1,3]`、`nums2=[5,7]`，写成 `min(nums2)*10+min(nums1)=51`，而正确是 15；十位固定取 nums1 的最小值，个位固定取 nums2 的最小值。

## 如果面试官追问
若允许数字位数不限、每个数组可重复取数位，怎么改？答：仍先判交集，无交集时取两数组全局最小值作十位、次小值作个位，因为位数越少数值越小。
