## 一句话思路
答案就是 s 中不同字符的个数，用 set 去重计数即可。

## 怎么做
1. 关键观察：对某个字符 c 执行一次操作，会删掉它左右各一个最近的 c，但**被选中的那个 c 本身保留**，所以每种字符至少剩 1 个。
2. 反过来，只要某字符出现 ≥2 次，就一定能选到某个 c 使左右至少一侧有同字符可删，反复操作可把该字符压到 1 个。
3. 因此最小长度 = 不同字符种类数，直接 `len(set(s))`。

以 `s = "aaabc"` 为例：`set(s)` 得到 `{'a','b','c'}`，长度 3，与示例输出一致。中间过程对应示例里把 `"aaabc"` 的 a 删到只剩一个，变成 `"abc"`。

```python
def minimizedStringLength(s: str) -> int:
    seen = set()
    for ch in s:
        seen.add(ch)
    return len(seen)
```

第 2 步的成立性值得盯一眼：`"cbbd"` 中 b 出现两次，选下标 1 的 b，右侧最近 b 在下标 2，删掉后得 `"cbd"`，b 只剩 1 个，长度 3 = 不同字符数 {c,b,d}。`"dddaaa"` 中 d 三次、a 三次，各自压到 1 个，得 `"da"`，长度 2 = 不同字符数 {d,a}。两个官方示例都验证了「种类数」这个结论。

## 复杂度
时间 O(n)：遍历 s 一次，n 为 s 长度，每个字符做一次 set 插入。
空间 O(1)：set 最多存 26 个小写字母，与 n 无关。

## 易错点
- 输入 `"aaabc"` → 若误以为要模拟删除、按「连续段」或「出现次数」算，会得到 3 以外的值（比如把 a 算成 3 个）→ 正确做法是只数不同字符，`len(set(s))` 直接得 3。
- 输入 `"dddaaa"` → 若以为每种字符只能删到「出现次数的一半」或漏掉「被选中的 c 保留」这条，会算成 1 或 4 → 正确做法是记住每种字符最终恰好留 1 个，答案是 2。

## 如果面试官追问
问：如果要求输出最小化后的字符串本身，而不只是长度？
答：每种字符保留任意一个原位置即可，按原顺序拼接这些保留字符，长度仍是种类数。
