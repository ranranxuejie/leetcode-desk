## 一句话思路
把 board 按行、按列切成被 `#` 分隔的连续段，每段长度等于 `len(word)` 时，用正反两个方向逐格比对即可。

## 怎么做
1. 收集所有候选段：每行从左到右扫，遇 `#` 就结算当前段；每列同理，得到 `(格子列表)` 的段。
2. 只保留长度恰好等于 `len(word)` 的段，长度不等直接跳过（短了放不下，长了左右/上下会贴到非障碍格）。
3. 对每个候选段，用 `word` 和 `word[::-1]` 各比一次，任一格是 `' '` 或等于对应字母就算匹配。
4. 任一段匹配成功即返回 `True`。

以示例 1 为例：`board = [["#"," ","#"],[" "," ","#"],["#","c"," "]]`，`word = "abc"`。按列扫描第 1 列（下标 1）得到段 `[' ', ' ', 'c']`，长度 3 等于 `len("abc")`；正序比对 `' '` vs `'a'`、`' '` vs `'b'`、`'c'` vs `'c'` 全部通过，返回 `True`。

```python
def ok(seg, w):
    return all(c == ' ' or c == ch for c, ch in zip(seg, w))

def check(seg):
    return len(seg) == len(word) and (ok(seg, word) or ok(seg, word[::-1]))

# 行段
for row in board:
    seg = []
    for c in row + ['#']:
        if c == '#':
            if check(seg): return True
            seg = []
        else:
            seg.append(c)
# 列段同理，把 board 换成 zip(*board)
```

列方向用 `zip(*board)` 转置后复用同一段逻辑，注意 `zip` 返回元组，`row + ['#']` 要改成 `list(row) + ['#']`。

## 复杂度
时间 O(m·n)：每个格子最多被行、列各扫一次，比对总代价不超过段长之和。
空间 O(max(m,n))：转置或暂存单段，未开 m×n 额外矩阵。

## 易错点
- 段长大于 `len(word)` 时误判：如示例 2 第 0 列是 `[' ',' ',' ']` 长 3，`word="ac"` 长 2，若只做前缀比对会误以为能放，实际放下后下方还留空格违反相邻约束 → 必须先判 `len(seg) == len(word)`。
- 忘记反向：示例 3 中 `word="ca"` 只能从右到左放进 `[' ',' ','c']` 段，只比正序会漏掉 `word[::-1]` 这一路 → 两个方向都要试。

## 如果面试官追问
问：要输出具体放置方案（起点、方向）怎么办？
答：`check` 里返回 `(段起点, 方向)` 而非布尔值，行段记 `(r, start, 'LR')`，列段记 `(start, c, 'UD')`，命中即返回。
