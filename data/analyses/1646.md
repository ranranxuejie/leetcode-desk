## 一句话思路
按 i 从 1 递推到 n//2，用 nums[i] 直接填 nums[2i] 和 nums[2i+1]，边填边更新最大值。

## 怎么做
1. 特判 n == 0 返回 0，n == 1 返回 1，因为 nums[1] 的下标依赖不成立。
2. 开长度 n+1 的 nums，置 nums[0]=0、nums[1]=1，ans 初值取 1。
3. 令 i 从 1 循环到 n//2，偶数位 nums[2*i] = nums[i]，奇数位在 2*i+1 <= n 时填 nums[i]+nums[i+1]。
4. 每填一个位置就和 ans 比较，循环结束返回 ans。

以 n = 7 为例：i=1 时 nums[2]=nums[1]=1、nums[3]=nums[1]+nums[2]=2；i=2 时 nums[4]=1、nums[5]=nums[2]+nums[3]=3，此时 ans 从 2 抬到 3；i=3 时 nums[6]=nums[3]=2、nums[7]=nums[3]+nums[4]=3，ans 保持 3。关键中间值是 i=2 那步算出的 nums[5]=3，它就是最终答案。

```python
if n == 0:
    return 0
nums = [0] * (n + 1)
nums[1] = 1
ans = 1
for i in range(1, n // 2 + 1):
    nums[2 * i] = nums[i]
    ans = max(ans, nums[2 * i])
    if 2 * i + 1 <= n:
        nums[2 * i + 1] = nums[i] + nums[i + 1]
        ans = max(ans, nums[2 * i + 1])
return ans
```

## 复杂度
时间：O(n)，i 从 1 走到 n//2，每个下标只被写一次。
空间：O(n)，额外开了长度 n+1 的 nums 数组，无其他结构。

## 易错点
- n = 1 时若直接进循环，`range(1, 1//2+1)` 为空，ans 初值若写成 0 会返回 0；正确做法是 ans 初值取 1，或先特判 n == 1 返回 1。
- n 为偶数时最后一个下标 n 是偶数位，只走 `nums[2*i]` 分支；若把 `2*i+1 <= n` 的判断漏掉，n = 6 时 i=3 会写 nums[7] 越界报 IndexError，正确做法是奇数位赋值前显式判 `2 * i + 1 <= n`。

## 如果面试官追问
问：n 大到 10^7 且只要最大值，怎么省空间？
答：递推只依赖 nums[i] 和 nums[i+1]，但 i 与 2i 跨度大，仍需保留前半段，可只存到 n//2+1 并用滚动方式回填，空间降到 O(n/2)。
