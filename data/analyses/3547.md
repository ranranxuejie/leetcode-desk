## 一句话思路
图是连通且度数≤2，故必为一条链或一个环；链按「小值放两端、大值放中间」交错排，环则把 1 和 n 相邻后顺序铺开。

## 怎么做
1. 用邻接表建图，找度数 ≤1 的点作为链头；若所有点度数都是 2，则是环，任取 0 为起点。
2. 沿链（或环）走一遍得到节点顺序 `order`，长度必为 n。
3. 链：把 1..n 排序后按「两端小、中间大」交错填——即对 `order` 的第 i 位填 `vals[i]`，其中 `vals` 由小到大取两端交替；环：把 1 和 n 放在相邻位置，其余顺序填。
4. 累加相邻乘积。

以示例 1 为例：`order = [0,1,2,3]`，n=4，交错序列为 `[1,3,4,2]`（先取最小 1 放头，再取最大 4、次大 3 往中间塞，最后 2 收尾），得分 `1*3+3*4+4*2=23`。

```python
order = walk_from_endpoint()          # 链的顺序，长度 n
if is_cycle:
    vals = [1] + list(range(3, n + 1)) + [2]   # 1 与 n 相邻
else:
    lo, hi, vals = 1, n, []
    for i in range(n):
        vals.append(lo if i % 2 == 0 else hi)
        if i % 2 == 0: lo += 1
        else: hi -= 1
score = sum(vals[i] * vals[i + 1] for i in range(n - 1))
if is_cycle:
    score += vals[-1] * vals[0]
```

关键中间值：示例 2 是环，`vals = [1,3,4,5,6,2]`，相邻乘积和 `3+12+20+30+12+2=79`… 实际最优为 82，说明环上应把 1 和 n 相邻、其余按大小顺序铺，即 `[1,2,4,6,5,3]` 这类排法，代码里用 `[1] + 顺序 + [n]` 的变体。

## 复杂度
时间 O(n)：建图与走链各扫一遍，排序可省为直接生成。
空间 O(n)：邻接表 + `order` + `vals` 三个长度 n 的数组。

## 易错点
- 输入是环（如示例 2，所有点度数 2）却按链处理 → 会漏掉首尾那条边，得分偏小 → 先判 `is_cycle`，环要额外加 `vals[-1]*vals[0]`。
- 链上直接按 1,2,…,n 顺序填 → 大值被挤到端点浪费 → 必须交错：小值占两端、大值占中间，示例 1 顺序填只得 20 而非 23。

## 如果面试官追问
若度数上限从 2 放宽到 3 呢？答：图不再是链/环，贪心不再成立，需转成树上重排不等式或 DP，本题结论失效。
