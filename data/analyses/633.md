## 一句话思路
双指针夹逼：a 从 0 递增、b 从 ⌊√c⌋ 递减，比较 a²+b² 与 c 决定移动哪一端。

## 怎么做
1. 令 `a = 0`，`b = isqrt(c)`，用 `math.isqrt` 避免浮点误差。
2. 每轮算 `s = a*a + b*b`，与 `c` 比较。
3. `s == c` 返回 `True`；`s < c` 则 `a += 1`；`s > c` 则 `b -= 1`。
4. `a > b` 时退出返回 `False`。

以 `c = 5` 为例：`b = isqrt(5) = 2`，首轮 `a=0, b=2`，`s = 0 + 4 = 4 < 5`，故 `a` 加到 1；次轮 `s = 1 + 4 = 5 == c`，返回 `True`。关键中间值是首轮的 `s = 4`，它决定了 `a` 必须增大而不是 `b` 减小。

```python
from math import isqrt

def judge(c):
    a, b = 0, isqrt(c)
    while a <= b:
        s = a * a + b * b
        if s == c:
            return True
        if s < c:
            a += 1
        else:
            b -= 1
    return False
```

正确性来自单调性：固定 `b` 时 `a²+b²` 随 `a` 增，固定 `a` 时随 `b` 增，所以 `s < c` 时任何 `a' ≤ a` 都不可能凑成 `c`，只能抬 `a`；`s > c` 同理只能降 `b`。两个指针各走一遍 `[0, isqrt(c)]`，不会漏解。

## 复杂度
时间：O(√c)，`a` 与 `b` 合计最多走 `2*isqrt(c)` 步。
空间：O(1)，只开了 `a`、`b`、`s` 三个整数。

## 易错点
- `c = 0` → 若把 `b` 初始化为 `isqrt(c) - 1` 或循环条件写成 `a < b`，会漏掉 `a = b = 0` 这组解而错答 `False`；正确做法是 `b = isqrt(c)` 且循环条件用 `a <= b`，让 `0²+0²=0` 命中。
- `c = 2**31 - 1` → 若用 `int(c ** 0.5)` 求上界，浮点误差可能让 `b` 偏小 1，从而漏掉 `b = isqrt(c)` 这一端的解；正确做法是用 `math.isqrt(c)` 取精确整数平方根。

## 如果面试官追问
问：要求输出所有满足的 `(a, b)` 方案怎么办？
答：命中时记录 `(a, b)` 后继续 `a += 1`（或 `b -= 1`）而非直接返回，扫完整个区间即可。
