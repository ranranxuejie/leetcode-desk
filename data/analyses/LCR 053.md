## 一句话思路
利用 BST 中序有序，从根往下走，遇到 `root.val > p.val` 就记下候选并左转，否则右转。

## 怎么做
1. 初始化 `res = None`，`cur = root`。
2. 循环：若 `cur.val > p.val`，说明 `cur` 可能是后继，`res = cur` 后 `cur = cur.left`。
3. 否则 `cur.val <= p.val`，后继必在右侧，`cur = cur.right`。
4. 循环结束返回 `res`。

以示例 2 的 `root = [5,3,6,2,4,null,null,1], p = 6` 为例：`cur=5` 时 `5<6` 右转；`cur=6` 时 `6<=6` 右转到 `None`，`res` 始终没被赋值，返回 `None`，正确。

```python
res, cur = None, root
while cur:
    if cur.val > p.val:
        res = cur
        cur = cur.left
    else:
        cur = cur.right
return res
```

关键点：`p` 是节点引用，直接比较 `p.val`，不要去树里找 `p`。命中 `cur.val > p.val` 时不能立刻返回，因为左子树里可能有更小的更大值——比如 `root=[5,3,6,2,4,null,null,1]`、`p=2`，走到 `3` 时记下 `3`，再左转到 `1`，`1<2` 右转到 `None`，最终返回 `3` 而不是中途的 `5`。

## 复杂度
时间 O(h)：只沿一条根到叶路径走，h 为树高，最坏 O(n)。
空间 O(1)：只用了 `res`、`cur` 两个指针，无递归栈。

## 易错点
- `p` 是最大节点（如示例 2 的 `p=6`）→ 若把 `res` 初值写成 `root` 或某个默认节点，会返回错误节点 → 必须初始化为 `None`，全程没被赋值就返回 `None`。
- 命中 `cur.val > p.val` 就 `return cur` → 对 `p=2`、路径经过 `5` 的情况会返回 `5` 而非 `3` → 必须继续左探，用 `res` 保存当前最优候选。

## 如果面试官追问
问：若 `p` 不在树中怎么办？答：本解法只依赖 `p.val` 做比较，仍返回「大于 `p.val` 的最小值」节点，语义自然退化为查找插入位置的后继。
