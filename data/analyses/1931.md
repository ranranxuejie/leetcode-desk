## 一句话思路
按列做状态压缩 DP：每列只有 3·2^(m-1) 种合法竖排，预处理相邻列兼容关系后逐列转移。

## 怎么做
1. 枚举一列的所有合法涂色（相邻格不同色），用三进制数编码，存进 `states`。
2. 预处理 `ok[i][j]`：`states[i]` 与 `states[j]` 逐位不同才为 `True`。
3. `dp[j]` 表示当前列涂成 `states[j]` 的方案数，逐列用 `ok` 累加。
4. 取 `m = min(m, n)` 让状态数取小的一维，答案不变。

以 `m = 5, n = 5` 为例：`states` 共 3·2^4 = 48 个；初始化 `dp` 全为 1，转移 4 次后求和得 580986。

```python
MOD = 10**9 + 7
m, n = min(m, n), max(m, n)
states = []
for x in range(3**m):
    s, ok = [], True
    for _ in range(m):
        s.append(x % 3); x //= 3
    for i in range(1, m):
        if s[i] == s[i-1]: ok = False
    if ok: states.append(s)
k = len(states)
ok = [[all(a != b for a, b in zip(states[i], states[j])) for j in range(k)] for i in range(k)]
dp = [1] * k
for _ in range(n - 1):
    dp = [sum(dp[i] for i in range(k) if ok[i][j]) % MOD for j in range(k)]
return sum(dp) % MOD
```

## 复杂度
时间：O(n · k²)，k = 3·2^(m-1)，由列数 n 与状态对数 k² 贡献。
空间：O(k²) 存 `ok` 表，`dp` 只占 O(k)。

## 易错点
- `m = 1, n = 1` 时若忘记 `m = min(m, n)` 且原 `m` 很大，`3**m` 会爆内存；先交换维度，保证枚举的是短边。
- `m = 1, n = 2` 时若把 `ok` 写成「同列相邻不同」而非「跨列逐位不同」，会漏掉横向约束，得到 9 而非 6；`ok[i][j]` 必须比较两列同行的颜色。

## 如果面试官追问
问：若要求输出一种具体方案而非计数？
答：在 `dp` 转移时额外记录每个状态的前驱下标，最后从末列任一非零状态回溯即可。
