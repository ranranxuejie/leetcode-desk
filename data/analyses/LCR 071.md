## 一句话思路
把权重累加成前缀和数组，在 `[0, total)` 上均匀取随机数，二分找它落在哪个前缀区间。

## 怎么做
1. 构造时把 `w` 变成前缀和 `pre`，`pre[i] = w[0]+...+w[i]`，`total = pre[-1]`。
2. 每次 `pickIndex` 取 `x = random.randrange(total)`，即 `0 <= x < total` 的整数。
3. 二分找第一个满足 `pre[i] > x` 的下标 `i`，返回 `i`。

以 `w = [1, 3]` 为例：`pre = [1, 4]`，`total = 4`。取 `x = 0` 时 `pre[0]=1 > 0`，返回 0；取 `x = 1, 2, 3` 时 `pre[0]=1` 不满足，`pre[1]=4 > x`，返回 1。于是下标 0 命中 1 个值、下标 1 命中 3 个值，比例正好 1:3。

```python
import random, bisect

# 构造阶段
self.pre = []
s = 0
for v in w:
    s += v
    self.pre.append(s)
self.total = s

# pickIndex 阶段
x = random.randrange(self.total)
return bisect.bisect_right(self.pre, x)
```

关键点：用 `bisect_right` 而不是 `bisect_left`。`x` 是区间左闭右开的下标，`pre[i] > x` 才是答案；`bisect_right(pre, x)` 返回第一个 `> x` 的位置，正好对上。若用 `bisect_left`，当 `x` 恰好等于某个 `pre[i]` 时会返回 `i`，把本该属于 `i+1` 的样本错判给 `i`。

## 复杂度
时间：构造 O(n)，每次 pickIndex O(log n)，n 为 `w` 长度。
空间：O(n)，额外只开了前缀和数组 `pre`。

## 易错点
- 随机数写成 `random.randint(0, total)` → 上界多取到 `total`，`bisect_right` 返回 `len(pre)` 越界 → 必须用 `randrange(total)` 或 `randint(0, total-1)`，保证 `x < total`。
- 用 `bisect_left` 配 `x = randrange(total)` → 当 `x` 等于某个 `pre[i]`（如 `w=[1,3]` 取到 `x=1`）时返回 `i` 而非 `i+1`，概率分布整体左偏 → 统一用 `bisect_right`，或改用 `x = random.random() * total` 浮点再配 `bisect_left`，两者不可混搭。

## 如果面试官追问
问：`w` 长度涨到 10^6、pickIndex 调用 10^6 次怎么办？
答：构造仍 O(n)，查询 O(log n) 已够；若要 O(1) 查询，可对权重做别名采样（Alias Method），预处理 O(n)、单次 O(1)。
