## 一句话思路
把 2×3 棋盘压成 6 位字符串做状态，从目标串反向 BFS 建全图，查表得答案。

## 怎么做
1. 目标态固定为 `"123450"`，把 board 按行拼成字符串 `start`，如示例 3 得 `"412503"`。
2. 预处理每个下标可交换的邻居：`0` 的邻居是 `{1,3}`，`1` 是 `{0,2,4}`，`2` 是 `{1,5}`，`3` 是 `{0,4}`，`4` 是 `{1,3,5}`，`5` 是 `{2,4}`。
3. 从 `"123450"` 出发 BFS，每步找到 `'0'` 的下标 `i`，与邻居 `j` 交换字符生成新串，记入 `dist`。
4. 返回 `dist.get(start, -1)`。

关键中间值：示例 3 从 `"123450"` 出发，第一层得到 `"123405"`、`"123540"`；BFS 到第 5 层时 `dist["412503"] = 5`，与输出一致。

```python
from collections import deque
nxt = {0:(1,3), 1:(0,2,4), 2:(1,5), 3:(0,4), 4:(1,3,5), 5:(2,4)}
dist = {"123450": 0}
q = deque(["123450"])
while q:
    s = q.popleft()
    i = s.index('0')
    for j in nxt[i]:
        t = list(s); t[i], t[j] = t[j], t[i]; t = ''.join(t)
        if t not in dist:
            dist[t] = dist[s] + 1
            q.append(t)
start = ''.join(str(x) for row in board for x in row)
return dist.get(start, -1)
```

反向建图的好处：一次 BFS 覆盖全部 360 个可达状态，多组输入直接查表，不用每次从 `start` 搜。

## 复杂度
时间：状态数 6!/2 = 360，每态最多 3 次交换，O(360×3) 常数级。
空间：`dist` 存 360 个字符串，O(360)。

## 易错点
- 输入 `[[1,2,3],[5,4,0]]` → 若只从 `start` 正向 BFS 且不判重，会在 `"123540"` 与 `"123450"` 间来回震荡超时 → 必须用 `dist` 或 `visited` 记录已访问串。
- 输入 `[[1,2,3],[5,4,0]]` → 若忘记返回 `-1` 而直接返回 `dist[start]`，会 KeyError → 用 `dist.get(start, -1)`；该例中 `"123540"` 与 `"123450"` 奇偶性不同，BFS 永远到不了。

## 如果面试官追问
问：要输出具体移动路径怎么办？
答：BFS 时给每个状态存 `(前驱串, 交换的两个下标)`，从 `start` 回溯到 `"123450"` 再反转即可。
