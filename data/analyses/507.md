## 一句话思路
枚举到 √num 配对累加因子，因为因子成对出现，只需扫到平方根。

## 怎么做
1. 先处理边界：`num <= 1` 直接返回 `False`，因为 1 的真因子和为 0。
2. 令 `total = 1`（1 一定是真因子），从 `i = 2` 循环到 `int(num ** 0.5)`。
3. 若 `num % i == 0`，把 `i` 加入 `total`；若 `i != num // i`，把配对的 `num // i` 也加入。
4. 循环结束返回 `total == num`。

以 `num = 28` 为例：`total` 初始为 1，`i = 2` 时 `28 % 2 == 0`，加 2 和 14，`total = 17`；`i = 4` 时加 4 和 7，`total = 28`；`i = 5` 时 `28 % 5 != 0`，跳过；循环到 `i = 5` 结束（`int(28**0.5) = 5`），返回 `True`。

```python
if num <= 1:
    return False
total, i = 1, 2
while i * i <= num:
    if num % i == 0:
        total += i
        if i != num // i:
            total += num // i
    i += 1
return total == num
```

关键细节：`i != num // i` 这个判断专门处理完全平方数。比如 `num = 16`，`i = 4` 时 `16 // 4 == 4`，只加一次 4，否则 `total` 会多算 4，变成 19 而不是 15。

## 复杂度
时间 O(√n)：循环从 2 走到 `int(num ** 0.5)`，最多约 10^4 次。
空间 O(1)：只开了 `total`、`i` 两个整型变量。

## 易错点
- `num = 1` → 若直接进循环，`total = 1` 会误判为 `True`（1 的真因子和应为 0）→ 必须在开头单独返回 `False`。
- `num = 16` → 若不加 `i != num // i` 判断，`i = 4` 时把 4 加两次，`total = 19` 误判 `False` → 配对因子相等时只加一次。

## 如果面试官追问
问：num 上限提到 10^12 怎么办？
答：√n 枚举仍可行（10^6 次），但可先用欧拉筛预处理素数，再按因子和公式分解质因数加速。
