## 一句话思路
最大元素是全局固定的，先求出 `mx = max(nums)`，再用滑动窗口统计「含 `mx` 至少 k 个」的子数组数。

## 怎么做
1. 先扫一遍求 `mx = max(nums)`，因为子数组的最大元素只可能是全局最大值。
2. 右指针 `r` 从 0 到 n-1 移动，遇到 `nums[r] == mx` 时 `cnt += 1`。
3. 当 `cnt >= k` 时，收缩左指针 `l` 直到窗口内 `mx` 恰好剩 k 个，此时以 `r` 结尾的合法子数组左端点有 `l+1` 个（0..l 都行）。
4. 累加 `ans += l + 1`，最后返回 `ans`。

以 `nums = [1,3,2,3,3], k = 2` 为例：`mx = 3`。`r=3` 时窗口 `[1,3,2,3]` 内 `cnt=2`，`l` 停在 0（`nums[0]=1` 不是 mx，不收缩），`ans += 1`；`r=4` 时 `cnt=3`，`l` 移到 1（`nums[1]=3` 移出后 `cnt=2`），`ans += 2`。累计 6。

```python
mx = max(nums)
ans = l = cnt = 0
for r, x in enumerate(nums):
    if x == mx:
        cnt += 1
    while cnt >= k:
        if nums[l] == mx:
            cnt -= 1
        l += 1
    ans += l
return ans
```

注意 `while` 退出时 `cnt == k-1`，即 `l` 已经越过「刚好 k 个」的边界，所以合法左端点数是 `l` 而不是 `l+1`——上面第 3 步的 `l+1` 是「收缩前」的写法，代码里用收缩后的 `l` 直接累加，两者等价。

## 复杂度
时间 O(n)：`r` 和 `l` 各走一遍数组，求 `max` 也是 O(n)。
空间 O(1)：只开了 `mx`、`ans`、`l`、`cnt` 四个变量。

## 易错点
- `nums = [1,4,2,1], k = 3`：若把「最大元素」理解成「子数组自身的最大值」而非全局 `mx`，会去枚举每个子数组的最大值，复杂度爆炸且答案错。正确做法是先固定 `mx = max(nums)`，只数 `mx` 的出现次数。
- `nums = [3,3,3], k = 1`：若在 `cnt >= k` 时用 `ans += l + 1` 但 `l` 已收缩到 `cnt == k-1`，会多算。正确做法是收缩后累加 `ans += l`，此时 `l` 恰好等于「以 `r` 结尾的合法左端点数」。

## 如果面试官追问
问：若要求输出所有合法子数组而非计数？答：把 `ans += l` 换成对每个 `r` 枚举 `0..l-1` 作为左端点，复杂度退化为 O(n²)，需按输出规模接受。
