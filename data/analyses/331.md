## 一句话思路
用「槽位」计数：每个节点消耗 1 个空位，非空节点再补 2 个，全程槽位不能提前归零，末尾必须恰好为 0。

## 怎么做
1. 把 `preorder` 按 `,` 切分，初始化 `slots = 1`（根节点占一个待填位置）。
2. 遍历每个 token：先 `slots -= 1`，若此时 `slots < 0` 直接返回 `False`（说明多出一个节点没处放）。
3. 若 token 不是 `'#'`，说明它是非空节点，`slots += 2`（它的左右孩子各占一个位置）。
4. 遍历结束后返回 `slots == 0`。

以示例 1 的 `"9,3,4,#,#,1,#,#,2,#,6,#,#"` 为例，走到第 4 个 token `'#'` 时，`slots` 依次是 1→2→3→4→3，非空节点 `9,3,4` 各补 2，`#` 不补；最后两个 `#` 把 `slots` 压到 0，返回 `True`。

```python
def isValidSerialization(preorder):
    slots = 1
    for tok in preorder.split(','):
        slots -= 1
        if slots < 0:
            return False
        if tok != '#':
            slots += 2
    return slots == 0
```

关键点：`slots -= 1` 必须在判断 `tok` 之前做，这样 `#` 也消耗一个槽位；`slots < 0` 的检查放在补 2 之前，才能拦住 `"1,#"` 这种中途就超支的输入。

## 复杂度
时间 O(n)：`split` 和一次遍历都扫过 n 个 token，n 是逗号分隔的项数。
空间 O(n)：`split` 产生的列表占 n 个字符串，`slots` 是 O(1)。

## 易错点
- 输入 `"1,#"` → 若只在末尾判断 `slots == 0` 而不在中途检查 `slots < 0`，会漏掉「根节点只有一个孩子」的非法情况，错判为 `True`；正确做法是每步先减 1 再判负。
- 输入 `"9,#,#,1"` → 若把 `slots < 0` 的判断放在 `slots += 2` 之后，`#` 后面多出的 `1` 会让 `slots` 先被补回非负，错判为 `True`；正确做法是减 1 后立刻判负，再决定是否补 2。

## 如果面试官追问
问：如果要求返回第一个出错的位置而不是布尔值？
答：在 `slots < 0` 或末尾 `slots != 0` 时记录当前 token 下标即可，逻辑不变。
