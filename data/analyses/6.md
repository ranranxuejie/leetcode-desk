## 一句话思路
按行号把字符分桶，行号随 `step` 在 0 与 `numRows-1` 之间往返，最后拼接各行。

## 怎么做
1. 特判 `numRows == 1` 或 `numRows >= len(s)`，直接返回 `s`，否则 `step` 会卡在 0。
2. 建 `rows = [""] * numRows`，用 `row` 记当前行、`step` 记方向，初始 `row = 0, step = 1`。
3. 遍历 `s` 的每个字符 `ch`：`rows[row] += ch`，然后若 `row == 0` 则 `step = 1`，若 `row == numRows-1` 则 `step = -1`，再 `row += step`。
4. 返回 `"".join(rows)`。

以 `s = "PAYPALISHIRING", numRows = 3` 为例，前 4 个字符走完 `row` 依次是 0,1,2,1，`rows` 变成 `["P","A","Y"]` 后 `P` 落到第 1 行，即 `rows[1] == "PA"`；走完全串 `rows == ["PAHN","APLSIIG","YIR"]`，拼接得 `"PAHNAPLSIIGYIR"`。

```python
if numRows == 1 or numRows >= len(s):
    return s
rows = [""] * numRows
row, step = 0, 1
for ch in s:
    rows[row] += ch
    if row == 0:
        step = 1
    elif row == numRows - 1:
        step = -1
    row += step
return "".join(rows)
```

关键在判断顺序：先改 `step` 再 `row += step`，否则在 `row == 0` 时会先减到 -1 越界。

## 复杂度
时间 O(n)：`n = len(s)`，每个字符只做一次追加，拼接再扫一遍各行。
空间 O(n)：`rows` 共装 n 个字符，另加 `join` 产生的输出串。

## 易错点
- `numRows = 1` 时若不加特判，`row == 0` 和 `row == numRows-1` 同时成立，`step` 在 1 与 -1 间反复翻转，`row` 变成 0,-1,0,-1 直接索引越界；正确做法是开头就 `return s`。
- `numRows >= len(s)`（如 `s = "AB", numRows = 5`）时若仍建 5 个桶，后 3 个桶恒为空，结果虽对但白开内存；更隐蔽的是 `row` 永远到不了 `numRows-1`，`step` 一直是 1，逻辑上没错但说明你没想清边界，正确做法是同样直接返回 `s`。

## 如果面试官追问
问：不建 `numRows` 个桶，能否 O(1) 额外空间直接按行输出？
答：能，第 r 行字符下标是周期 `2*(numRows-1)` 上的 `r` 和 `周期-r` 两个位置，逐行枚举即可。
