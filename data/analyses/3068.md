## 一句话思路
每个节点只有「翻/不翻」两种状态，翻的节点数必须为偶数，故用树形 DP 求最小损失。

## 怎么做
1. 记 `gain[i] = (nums[i] ^ k) - nums[i]`，先取 `base = sum(nums)`，问题变成选偶数个节点翻，使 `sum(gain)` 最大。
2. 关键结论：树上任意偶数个节点都能通过边操作实现（沿路径两两配对翻转，路径中间节点被翻两次抵消），所以树结构其实不影响答案，只需保证翻的个数为偶数。
3. 把所有 `gain[i] > 0` 的节点都翻，设个数为 `cnt`、总收益为 `pos`；若 `cnt` 为偶数直接返回 `base + pos`。
4. 若 `cnt` 为奇数，必须去掉一个正收益节点，或额外翻一个非正收益节点，取损失最小者：`min(min(gain[i] for gain[i] > 0), -max(gain[i] for gain[i] <= 0))`。

以示例 1 为例：`nums=[1,2,1], k=3`，`gain=[1,1,1]`，`base=4`，`cnt=3` 为奇数，最小正收益是 1，故 `4+3-1=6`。

```python
base = sum(nums)
gain = [(x ^ k) - x for x in nums]
pos = [g for g in gain if g > 0]
ans = base + sum(pos)
if len(pos) % 2 == 1:
    drop = min(pos)
    if len(pos) < len(gain):
        drop = min(drop, -max(g for g in gain if g <= 0))
    ans -= drop
return ans
```

## 复杂度
时间 O(n)：遍历 `nums` 求 `gain` 与极值，`edges` 完全不用。
空间 O(n)：额外存 `gain` 数组（可省为 O(1) 滚动）。

## 易错点
- 输入 `nums=[7,7,7,7,7,7], k=3`：`gain` 全为负，`pos` 为空，`cnt=0` 是偶数，直接返回 42；若误判「必须翻一次」会得到 36。
- 输入 `nums=[1,2,1], k=3`：`cnt=3` 为奇数时若直接返回 `base+pos=7`，忽略了翻的个数必须为偶数，正确应减去最小损失 1 得 6。

## 如果面试官追问
若要求输出具体操作序列怎么办？答：把翻的节点按 DFS 序两两配对，沿树上路径依次对边操作，路径中间节点被翻两次自动抵消。
