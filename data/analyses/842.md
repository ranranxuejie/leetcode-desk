## 一句话思路
回溯枚举前两个数的切分位置，之后每块都由前两块之和唯一确定，只需校验字符串是否以该和开头。

## 怎么做
1. 外层枚举第一块 `num[:i]`、内层枚举第二块 `num[i:j]`，`i` 从 1 到 `len(num)-2`，`j` 从 `i+1` 到 `len(num)-1`。
2. 每块先过两道闸：长度 >1 时首位不能是 `'0'`；`int(块) > 2**31 - 1` 直接剪枝。
3. 定下前两块后进入 `dfs(start, a, b)`：算 `c = a + b`，若 `num` 从 `start` 起不以 `str(c)` 开头就返回 `False`，否则 `start += len(str(c))` 继续。
4. `start == len(num)` 且序列长度 ≥3 时返回 `True`，把路径原样带回。

以 `num = "1101111"` 为例，取 `i=1, j=2` 得 `a=1, b=1`，`c=2`，但 `num[2:]` 以 `'0'` 开头，`str(2)` 对不上，这条分支立刻死掉；换 `i=2, j=3` 得 `a=11, b=0`，`c=11`，`num[3:5] == "11"` 命中，`start` 推到 5，再算 `0+11=11`，`num[5:7] == "11"` 命中，`start==7` 收工，得到 `[11,0,11,11]`。

```python
def dfs(start, a, b, path):
    if start == len(num):
        return len(path) >= 3
    c = a + b
    s = str(c)
    if c > 2**31 - 1 or not num.startswith(s, start):
        return False
    path.append(c)
    if dfs(start + len(s), b, c, path):
        return True
    path.pop()
    return False
```

外层拿到 `a, b` 后调 `dfs(j, a, b, [a, b])`，返回 `True` 即得答案。

## 复杂度
时间：最坏 O(n·2^n) 量级，`n` 是 `num` 长度，主要花在枚举前两块和每层的 `startswith` 比较。
空间：递归深度 O(n)，路径 `path` 最多 O(n) 个元素，无额外大数组。

## 易错点
- 输入 `"0123"`：若只判 `int(块)` 不判前导零，会把 `"01"` 当成 1 收进序列，错解成 `[0,1,1,2]` 之类；正确做法是切块时若 `len(块) > 1 and 块[0] == '0'` 直接跳过，只有单字符 `"0"` 合法。
- 输入 `"112358130"`：若 `dfs` 里只比较 `num[start:start+len(s)] == s` 而不检查 `c > 2**31 - 1`，`a+b` 会滚成超长数字串，`startswith` 永远失败却白跑大量分支；正确做法是算出 `c` 后先卡 `2**31 - 1` 上限再比较，题目规定每块必须落在 32 位有符号范围内。

## 如果面试官追问
问：`num` 长度涨到 10^4 还能这么做吗？
答：不能，指数级枚举前两块会爆；需要改成先枚举第一块、用字符串加法推后续块，并加记忆化或直接放弃回溯改数学构造。
