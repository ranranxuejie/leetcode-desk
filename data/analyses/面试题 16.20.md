## 一句话思路
把每个字母换成它所在的数字键，再和 `num` 逐位比对，相等就留下。

## 怎么做
1. 建一张 26 字母到数字字符的映射表 `key`，例如 `key['a']='2'`、`key['s']='7'`。
2. 遍历 `words`，对每个 `w` 用 `all(key[c] == num[i] for i, c in enumerate(w))` 判断。
3. 全部位相等就 `append` 进结果，否则跳过。

以 `num = "8733"`、`w = "tree"` 为例：`t→8`、`r→7`、`e→3`、`e→3`，拼出的 `"8733"` 与 `num` 完全相同，所以保留；`"used"` 是 `u→8`、`s→7`、`e→3`、`d→3`，同样命中。

```python
key = {}
for d, s in zip("23456789", ["abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"]):
    for c in s:
        key[c] = d

res = []
for w in words:
    if all(key[c] == num[i] for i, c in enumerate(w)):
        res.append(w)
```

注意 `7` 和 `9` 各挂 4 个字母（`pqrs`、`wxyz`），别按 3 个一组硬切。

## 复杂度
时间 O(L)，L 为所有 `words[i]` 长度之和（题面保证等于 `len(num)` 乘词数）。
空间 O(1)，除结果列表外只开了 26 项的 `key`。

## 易错点
- `num = "2"`、`words = ["a","b","c","d"]` → 若把 `key` 建成数字到字母串再反向查找，容易漏掉 `d` 或把 `d` 也映射到 `2`；正确做法是逐字母建 `key[c]=d`，`d` 不在任何串里，自然被排除，输出 `["a","b","c"]`。
- `num = "8733"`、`w = "tree"` → 若只比较字母集合或排序后比较，`"tree"` 与 `"used"` 都可能误判；必须按位置 `enumerate(w)` 逐位对齐 `num[i]`，顺序错一位就应淘汰。

## 如果面试官追问
若 `words` 涨到 10^5 且长度不一，怎么优化？答：先按 `len(w)` 分桶，只和 `len(num)` 相同的桶比对，避免无谓扫描。
