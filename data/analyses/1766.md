## 一句话思路
DFS 维护「根到当前节点的路径」，对每个节点只查与 `nums[i]` 互质的值里深度最大的那个祖先。

## 怎么做
1. 预处理 `1..50` 两两的 `gcd`，得到 `coprime[v]` = 与 `v` 互质的值集合（`nums[i] ≤ 50`，这是关键约束）。
2. 建邻接表，从 0 号点 DFS，参数带 `parent` 和当前深度。
3. 进入节点 `i` 时，遍历 `coprime[nums[i]]` 里的每个值 `v`，取 `last[v]`（该值最近一次出现的祖先节点）中深度最大的那个，写入 `ans[i]`。
4. 把 `last[nums[i]]` 暂存为 `i`，递归子节点，回溯时恢复旧值。

以示例 1 为例：DFS 到节点 2（值 3）时，路径上 `last[2]=0`、`last[3]=1`。`coprime[3]` 含 2 不含 3，所以只命中 `last[2]=0`，`ans[2]=0`；若直接取 `last[3]=1` 就错了，因为 `gcd(3,3)=3`。

```python
def dfs(i, p, d):
    best, bd = -1, -1
    for v in coprime[nums[i]]:
        if last[v] != -1 and depth[last[v]] > bd:
            best, bd = last[v], depth[last[v]]
    ans[i] = best
    old, last[nums[i]] = last[nums[i]], i
    depth[i] = d
    for j in adj[i]:
        if j != p:
            dfs(j, i, d + 1)
    last[nums[i]] = old
```

`depth` 也可直接用递归层数，但显式存一份更省心。

## 复杂度
时间：O(n · 50)，每个节点最多枚举 50 个互质值，建图 O(n)。
空间：O(n + 50)，邻接表、`ans`、`depth` 各 O(n)，`last` 只有 51 个槽。

## 易错点
- 输入 `nums = [3,3]`、`edges = [[0,1]]`：若用「值 → 最近节点」而不判互质，会把 `ans[1]` 错填成 0；实际 `gcd(3,3)=3`，正确输出是 `[-1,-1]`。必须先过 `coprime` 过滤再比深度。
- 输入 `nums = [2,3,3,2]`（示例 1）：若回溯时忘记恢复 `last[nums[i]]`，节点 2 处理完后 `last[3]` 仍是 1，进入节点 3 时会把 `last[3]=1` 当成候选，但 3 与 2 互质、1 与 2 也互质，深度比较恰好还对；换成兄弟子树值相同的用例就会串味。正确做法是进入时存 `old`、退出时写回。

## 如果面试官追问
若 `nums[i]` 上限从 50 放大到 10^5 怎么办？答：预处理每个值的质因子，用「质因子 → 最近祖先」的容斥或按质因子集合查询，避免 O(50) 枚举。
