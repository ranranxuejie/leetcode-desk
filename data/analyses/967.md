## 一句话思路
从首位 1–9 出发逐位向后拼接，每步只保留与末位差绝对值为 k 的数字，BFS 到长度 n 即得全部解。

## 怎么做
1. 初始队列放 `1..9`，n=1 时直接返回它们（本题 n≥2，但保持通用）。
2. 每轮取队首 `cur`，用 `last = cur % 10` 取末位，候选下一数字是 `last + k` 和 `last - k`。
3. 候选必须落在 `0..9`，且当 `k == 0` 时两个候选相同，只拼一次，否则会重复。
4. 拼成 `cur * 10 + d` 入队，长度到 n 时收集进结果。

以 `n = 3, k = 7` 为例：初始 `[1,2,...,9]`；处理 `cur = 1` 时 `last = 1`，候选 `1+7=8`、`1-7=-6`（丢弃），得 `18`；下一轮 `cur = 18`，`last = 8`，候选 `15`（丢弃）、`1`，得 `181`，长度 3 收进答案。同理 `cur = 7` 时 `last = 7`，候选 `14`（丢弃）、`0`，得 `70`，再得 `707`；而 `0` 开头拼出的 `070` 因为首位从 1 起步，天然不会出现。

```python
from collections import deque

q = deque(range(1, 10))
res = []
while q:
    cur = q.popleft()
    if len(str(cur)) == n:
        res.append(cur)
        continue
    last = cur % 10
    for d in {last + k, last - k}:
        if 0 <= d <= 9:
            q.append(cur * 10 + d)
```

`{last + k, last - k}` 用集合去重，正好处理 `k == 0` 时两个候选相同的情况，比写 `if k != 0` 分支更短。

## 复杂度
时间：O(答案个数 × n)，每个数被逐位构造一次，位数 n 贡献因子。
空间：O(答案个数 × n)，队列和结果各存这些整数，无额外数组。

## 易错点
- `k == 0` 且用列表 `[last + k, last - k]` 而非集合 → 每个数被入队两次，`n=2, k=0` 输出 `[11,11,22,22,...]` 重复 → 用 `set` 去重或加 `if k != 0` 判断。
- 首位从 `0` 开始枚举 → `n=3, k=7` 会多出 `070`、`07` 这类前导零数 → 初始队列只放 `1..9`，`0` 永远不作为首位出现。

## 如果面试官追问
若 n 放大到 10^5 且只要计数而非枚举？答：改成按末位数字做 10 状态 DP，`dp[len][d]` 表示长度 len 末位为 d 的方案数，转移只依赖 `d±k`，O(10n)。
