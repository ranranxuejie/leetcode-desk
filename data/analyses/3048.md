## 一句话思路
对答案秒数 `t` 二分，判定「前 t 秒能否标记全部」用贪心：每个下标只在它最后一次出现处标记，之前的时间全用来减。

## 怎么做
1. 先判 `set(changeIndices)` 是否覆盖 `1..n`，不覆盖直接 `-1`。
2. 二分 `t ∈ [1, m]`，判定函数 `check(t)`：扫 `changeIndices[0:t]`，记录每个下标最后一次出现的秒数 `last[i]`。
3. 按秒数从小到大扫，维护「可用减操作次数」`free`：遇到 `s == last[i]` 时，要求 `free >= nums[i-1]`，然后 `free -= nums[i-1]`（标记本身不占 free）；否则 `free += 1`。
4. 第一个 `check(t) == True` 的 `t` 即答案。

以示例 1 的 `t = 8` 为例：`last = {1:8, 2:6, 3:5}`。扫到第 5 秒 `free = 4`，`nums[2] = 0`，扣 0；第 6 秒 `free = 4`，`nums[1] = 2`，扣成 2；第 8 秒 `free = 3`，`nums[0] = 2`，扣成 1，通过。而 `t = 7` 时下标 1 没出现，`last` 缺项，直接失败。

```python
def check(t):
    last = {}
    for s in range(t):
        last[changeIndices[s]] = s
    if len(last) < n:
        return False
    free = 0
    for s in range(t):
        i = changeIndices[s]
        if last[i] == s:
            if free < nums[i - 1]:
                return False
            free -= nums[i - 1]
        else:
            free += 1
    return True
```

## 复杂度
时间：`check` 是 O(t)，二分 O(log m) 次，共 O(m log m)；`n` 只进 `len(last) < n` 这一句。
空间：`last` 字典最多存 n 个键，O(n)。

## 易错点
- `nums` 里有 0（如示例 1 的 `nums[2] = 0`）→ 若写成 `free > nums[i-1]` 才通过，会把 0 误判为失败 → 正确是 `free >= nums[i-1]`，0 只需 0 次减。
- 某下标在 `changeIndices` 中完全不出现（示例 3 的下标 1）→ 若二分只判 `free` 够不够，会返回某个 t 而不是 -1 → 必须先查 `len(last) < n` 或开头查覆盖，缺项直接 `-1`。

## 如果面试官追问
若 `nums[i]` 上限提到 1e9、`m` 到 2e5 呢？答：二分不变，`check` 里 `free` 用 Python 大整数累加即可，复杂度 O(m log m) 仍成立。
