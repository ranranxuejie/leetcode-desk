## 一句话思路
双指针贪心匹配 s 与 t，记录失配次数，失配 ≤1 即 true——因为替换只能救一个字符。

## 怎么做
1. 用 `i` 扫 s、`j` 扫 t，`miss` 记失配数。
2. 当 `s[i] == t[j]` 时双指针同进；否则 `i += 1` 且 `miss += 1`，`j` 不动。
3. 若 `miss > 1` 立即返回 `False`；扫完 s 返回 `True`。

以 `s = "cat", t = "chat"` 为例：`i=0,j=0` 时 `'c'=='c'`，双进到 `i=1,j=1`；`'a' != 'h'`，`miss=1`、`i=2`、`j` 仍为 1；`'t' != 'h'`，`miss=2` → 返回 `False`？不对——这里 `j` 该前进跳过 `'h'`。

正确做法是失配时**只让 `j` 前进**（把 t 中这个字符当"被删掉"），`i` 不动，`miss` 不增；只有当 `j` 走到 t 末尾而 `i` 还没走完，才说明必须靠替换，此时 `miss += 1` 并让 `i` 前进。等价写法：先贪心匹配尽量多的前缀，剩下的长度差就是需要替换的字符数。

```python
i = j = 0
while i < len(s) and j < len(t):
    if s[i] == t[j]:
        i += 1
    j += 1
# i 之前的 s 前缀已匹配，s[i:] 全需替换
return len(s) - i <= 1
```

回到 `"cat"/"chat"`：`'c'` 匹配后 `i=1,j=1`；`'a'` 与 `'h'` 不等，`j=2`；`'a'` 与 `'a'` 匹配，`i=2,j=3`；`'t'` 与 `'t'` 匹配，`i=3`。循环结束 `len(s)-i = 0 ≤ 1`，返回 `True`。

## 复杂度
时间 O(len(s) + len(t))，两个指针各自单调前进，`j` 最多走完 t。
空间 O(1)，只开了 `i`、`j` 两个整数。

## 易错点
- 失配时误让 `i` 前进：`s="cat", t="chat"` 会在 `'a'` vs `'h'` 处把 `i` 推到 2，导致 `'t'` 再失配、`miss=2` 误判 `False`。正确是失配只推进 `j`，把 t 的字符当删除。
- 忘记"最多替换一个"包含**零次**：`s="ab", t="ab"` 完全匹配时 `len(s)-i = 0`，必须返回 `True`；若写成 `== 1` 就错。

## 如果面试官追问
若要求输出替换后的具体字符串？答：记录 `i` 停下时的位置，把 `s[i]` 改成 `t[j]`（若 `j` 未越界），其余保持原样即可。
