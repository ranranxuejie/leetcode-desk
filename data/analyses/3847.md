## 一句话思路
用布尔量 `first_active` 跟踪当前主动玩家是谁，逐场按两条规则翻转，再按身份把 `nums[i]` 加减到答案上。

## 怎么做
1. 初始化 `first_active = True`、`diff = 0`，表示第 0 场开始前第一位玩家是主动玩家。
2. 遍历 `i, x`：先判 `x % 2 == 1` 就翻转 `first_active`，再判 `(i + 1) % 6 == 0` 就再翻转一次。
3. 翻转完成后，`first_active` 为真则 `diff += x`，否则 `diff -= x`。
4. 遍历结束返回 `diff`。

以示例 2 的 `nums = [2,4,2,1,2,1]` 为例，关键在第 5 场（`i = 5`）：`x = 1` 是奇数，`first_active` 由 `False` 翻成 `True`；又因 `(5 + 1) % 6 == 0`，再翻回 `False`。两次翻转抵消，第二位玩家仍拿这 1 分，最终 `diff = 8 - 4 = 4`。若漏掉第二条规则，第 5 场会记成第一位玩家得分，答案错成 6。

```python
first_active = True
diff = 0
for i, x in enumerate(nums):
    if x % 2 == 1:
        first_active = not first_active
    if (i + 1) % 6 == 0:
        first_active = not first_active
    diff += x if first_active else -x
return diff
```

注意两条规则是**先后各判一次**，不是 `if/elif`；同一场可能翻转两次（如 `i = 5` 且 `x` 为奇数），也可能一次都不翻。

## 复杂度
时间 O(n)：遍历 `nums` 一次，每场常数次判断。
空间 O(1)：只开 `first_active` 和 `diff` 两个变量，不复制数组。

## 易错点
- 把两条翻转写成 `if/elif` → 遇到 `i = 5` 且 `nums[5]` 为奇数（示例 2）只翻一次，第 5 场的 1 分记到第一位玩家头上，答案从 4 变成 6 → 两条规则必须独立判断、顺序执行。
- 用 `i % 6 == 0` 判第 6 场 → 第 0 场就被误判为「每第 6 场」，示例 1 的 `nums[0] = 1` 会连翻两次回到第一位玩家，输出变成 2 而非 0 → 条件是 `(i + 1) % 6 == 0`，即索引 5、11、17。

## 如果面试官追问
问：若规则改成「每第 k 场互换」，代码怎么改？
答：把 `(i + 1) % 6 == 0` 换成 `(i + 1) % k == 0`，其余不变，复杂度仍是 O(n)。
