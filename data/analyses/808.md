## 一句话思路
把毫升数除以 25 压缩成 4 单位一格，用记忆化 DP 递推四种等概率分支，n 大时直接返回 1。

## 怎么做
1. 令 `m = ceil(n / 25)`，把状态记为 `(a, b)` 两个整数单位，四种操作变成 `(4,0)`、`(3,1)`、`(2,2)`、`(1,3)`。
2. 边界：`a <= 0 and b <= 0` 返回 0.5，`a <= 0` 返回 1，`b <= 0` 返回 0。
3. 否则 `f(a,b) = 0.25 * (f(a-4,b) + f(a-3,b-1) + f(a-2,b-2) + f(a-1,b-3))`，用字典缓存。
4. `n >= 4800`（即 `m >= 192`）时直接返回 1.0，因为此时 A 先空的概率与 1 的差已小于 1e-5。

以 `n = 50` 为例，`m = 2`，状态 `(2,2)`：四个分支分别是 `f(-2,2)=1`、`f(-1,1)=1`、`f(0,0)=0.5`、`f(1,-1)=0`，加权得 `0.25*(1+1+0.5+0) = 0.625`，与示例一致。

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def f(a, b):
    if a <= 0 and b <= 0:
        return 0.5
    if a <= 0:
        return 1.0
    if b <= 0:
        return 0.0
    return 0.25 * (f(a-4, b) + f(a-3, b-1) + f(a-2, b-2) + f(a-1, b-3))

m = (n + 24) // 25
return 1.0 if m >= 192 else f(m, m)
```

## 复杂度
时间：O(m²)，m = ceil(n/25)，m ≥ 192 时提前返回，实际最多约 192² 个状态。
空间：O(m²) 的缓存字典，同样被 192 封顶。

## 易错点
- `n = 0` → 若先算 `m = 0` 再进递推，`f(0,0)` 会走 `a <= 0 and b <= 0` 返回 0.5，但题面要求两汤初始都为空时 A 在 B 前取完的概率应为 0；正确做法是 `n == 0` 直接返回 0.0，或确认边界顺序后单独处理。
- `n = 4799` 附近 → 若把阈值写成 `m >= 192` 却用 `n // 25` 取整，`n = 4800` 得 `m = 192` 提前返回 1.0，而 `n = 4799` 得 `m = 191` 走递推，两者结果差可能超过 1e-5；正确做法是统一用 `(n + 24) // 25` 向上取整，保证阈值判断和状态压缩口径一致。

## 如果面试官追问
问：如果四种操作概率不等，比如分别是 0.4/0.3/0.2/0.1，怎么改？
答：递推式里把 0.25 换成对应权重即可，状态转移和缓存结构完全不变。
