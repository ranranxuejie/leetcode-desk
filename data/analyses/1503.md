## 一句话思路
把相遇换向等价成「蚂蚁互相穿过、身份互换」，于是答案就是 max(left 的最大值, n - right 的最小值)。

## 怎么做
1. 认定相遇换向不改变「某只蚂蚁在 t 时刻的位置集合」，只交换标签，所以掉落时刻与标签无关。
2. 向左的蚂蚁里，位置最大的那只（`max(left)`）离左端最远，它走到 0 需要 `max(left)` 秒。
3. 向右的蚂蚁里，位置最小的那只（`min(right)`）离右端最远，它走到 n 需要 `n - min(right)` 秒。
4. 答案取这两者的较大值；某个数组为空时对应项不参与。

拿示例 1 走一遍：`n = 4, left = [4,3], right = [0,1]`。`max(left) = 4`，`min(right) = 0` 得 `n - min(right) = 4`，两者取大仍是 4，与输出一致。注意这里 `left` 里的 4 本身就在端点，t=0 立刻掉，真正撑到 t=4 的是「身份互换」后从 0 出发向右的那只——这正是等价变换的关键。

```python
def getLastMoment(n, left, right):
    ans = 0
    if left:
        ans = max(ans, max(left))
    if right:
        ans = max(ans, n - min(right))
    return ans
```

## 复杂度
时间：O(len(left) + len(right))，一次求 max/min。
空间：O(1)，只存 ans，没有额外数组。

## 易错点
- `right` 为空（如示例 3 的 `left = [0..7], right = []`）→ 若直接写 `n - min(right)` 会抛 `ValueError: min() arg is an empty sequence` → 必须先判空再取 `n - min(right)`。
- 把 `right` 的贡献写成 `min(right)` 而不是 `n - min(right)` → 示例 2 里 `right = [0..7]` 会算出 0，正确是 7 → 向右的蚂蚁离右端距离是 `n - pos`，别漏减。

## 如果面试官追问
问：若要求输出每只蚂蚁的掉落时刻呢？
答：仍用穿模，把每只蚂蚁的「身份」按初始位置排序后与穿模轨迹配对，再各自算到端点的距离即可。
