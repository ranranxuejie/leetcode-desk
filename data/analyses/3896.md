## 一句话思路
偶数位向上找最近的质数、奇数位向上找最近的合数，两路各自独立求和，因为每次只能 +1 且目标单调。

## 怎么做
1. 预处理 `MAX = 10**5 + 100` 的质数表（埃氏筛），因为 `nums[i]` 最多加几十就能碰到质数，多留 100 的余量足够。
2. 偶数下标 `i`：从 `nums[i]` 起向上找第一个质数，代价 `p - nums[i]`。
3. 奇数下标 `i`：从 `nums[i]` 起向上找第一个非质数（注意 1 也不是质数，算非质数），代价 `q - nums[i]`。
4. 全部累加。

以 `nums = [1,2,3,4]` 为例：下标 0 从 1 向上，1 非质数、2 是质数，代价 1；下标 1 从 2 向上，2 质数、3 质数、4 非质数，代价 2；下标 2 的 3 已是质数，代价 0；下标 3 的 4 已是非质数，代价 0。合计 3。

```python
MAX = 10**5 + 100
is_p = [True] * (MAX + 1)
is_p[0] = is_p[1] = False
for i in range(2, int(MAX**0.5) + 1):
    if is_p[i]:
        for j in range(i * i, MAX + 1, i):
            is_p[j] = False

ans = 0
for i, x in enumerate(nums):
    want_prime = (i % 2 == 0)
    y = x
    while is_p[y] != want_prime:
        y += 1
    ans += y - x
```

`while` 循环的步数就是「到下一个质数/合数的距离」，质数间隙在 1e5 附近不超过 100，所以不会退化。

## 复杂度
时间：筛表 O(MAX log log MAX)，遍历 O(n · gap)，gap 为质数间隙，实际很小。
空间：`is_p` 数组 O(MAX)，约 1e5 个布尔值。

## 易错点
- 输入 `nums = [1]`（单元素、下标 0 要求质数）→ 若把 1 当质数会输出 0 → 正确做法是筛表里显式设 `is_p[1] = False`，答案应为 1（1→2）。
- 输入 `nums = [2,2]`（下标 1 的 2 是质数，必须往上找非质数）→ 若只判断「是不是质数就跳过」会漏掉奇数位 → 正确做法是奇数位找 `is_p[y] == False`，2→4 代价 2，答案 2。

## 如果面试官追问
问：如果操作允许 +1 或 -1 呢？
答：偶数位取左右最近质数的较小距离，奇数位同理取最近非质数，仍可独立求和，但需双向预筛。
