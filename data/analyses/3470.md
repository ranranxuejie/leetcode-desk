## 一句话思路
按位贪心：每步枚举下一位候选值，用「剩余奇偶个数 + 上一位奇偶」的计数公式算分支数，够 k 就定下这一位。

## 怎么做
1. 设 `odd = (n+1)//2`、`even = n//2`，分别表示剩余可用奇数、偶数个数；`last` 记录上一位的奇偶（`None` 表示首位无约束）。
2. 关键计数：若下一位取奇数，则剩余可排数为 `f(odd-1, even, 偶)`；取偶数则为 `f(odd, even-1, 奇)`。`f` 用组合数闭式算，不递归枚举。
3. 从左到右逐位试：按值从小到大枚举候选 `v`，算出该分支的方案数 `cnt`；若 `k > cnt` 则 `k -= cnt` 跳过，否则锁定 `v`，更新 `odd/even/last` 进入下一位。
4. 若首位所有候选的 `cnt` 之和都 `< k`，直接返回 `[]`。

以 `n=4, k=6` 为例：`odd=2, even=2`。首位试 `1`（奇），剩余 `odd=1, even=2`，下一位必须偶数，方案数 `f=2`（即 `[1,2,3,4]`、`[1,4,3,2]`）；`k=6>2`，`k=4`。试 `2`（偶），`f=2`，`k=4>2`，`k=2`。试 `3`（奇），`f=2`，`k=2<=2`，锁定首位 `3`。第二位试 `2`（偶），剩余 `odd=1, even=1`，`f=1`，`k=2>1`，`k=1`；试 `4`（偶），`f=1`，`k=1<=1`，锁定 `4`。后续同理得 `[3,4,1,2]`。

```python
# 剩余 o 个奇数、e 个偶数，下一位要求类型 t（0 奇 1 偶）时的方案数
def f(o, e, t):
    if t == 0:  # 下一位取奇数
        if o == 0: return 0
        return comb(o - 1, e) * fact[o - 1] * fact[e] if e <= o else 0
    else:
        if e == 0: return 0
        return comb(e - 1, o) * fact[e - 1] * fact[o] if o <= e else 0
# 逐位：for v in 未用值: cnt = f(...); if k > cnt: k -= cnt else: 选 v
```

（`f` 的闭式：交替排列要求两类个数差不超过 1，奇数多时奇数占奇数位，用组合数选位置再各自全排列。）

## 复杂度
时间：每位枚举 O(n) 个候选、每个候选 O(1) 算 `f`，共 O(n²)。
空间：`fact`/`comb` 表 O(n)，外加已用标记 O(n)。

## 易错点
- `n=100` 时方案数远超 `10^15`，若用 Python 大整数直接算 `fact[100]` 再比较，数值巨大但不会溢出；正确做法是把 `cnt` 与 `k` 比较前先 `min(cnt, k)` 截断，避免无谓的大数运算拖慢。
- `n=2, k=3`：首位试 `1` 得 `cnt=1`，`k=3>1` 变 `k=2`；试 `2` 得 `cnt=1`，`k=2>1` 变 `k=1`，循环结束仍未锁定，必须返回 `[]` 而不是返回空首位或抛异常。

## 如果面试官追问
问：`k` 上限提到 `10^18` 且 `n` 到 `10^5` 怎么办？
答：`f` 的闭式仍 O(1)，但逐位枚举候选退化成 O(n²)，需用有序集合（如树状数组）按值域二分定位第 k 个候选，降到 O(n log n)。
