## 一句话思路
对每个 `land[i][j] == 0` 的格子做 DFS，把 8 邻域内所有 0 一次性标记成已访问并计数，每个连通块得到一个池塘大小。

## 怎么做
1. 遍历整个矩阵，遇到 `land[i][j] == 0` 就启动一次 DFS，返回该连通块的水域个数。
2. DFS 里把当前格子改成非 0（如 `land[i][j] = 1`）当访问标记，避免额外开 `visited` 数组。
3. 对 8 个方向 `(di, dj) ∈ {-1,0,1}² \ {(0,0)}` 递归，越界或值非 0 就跳过。
4. 收集所有大小后 `sort()` 返回。

以官方示例为例：从 `(0,0)` 出发，8 邻域能连到 `(1,0)`、`(1,1)`、`(2,0)`、`(3,0)`，这一块计数为 4；`(0,3)` 单独成块得 1；`(1,2)`、`(2,2)`、`(3,2)` 连成一块得 3？——注意 `(1,2)` 与 `(0,3)` 对角相邻，实际 `(0,3)`、`(1,2)`、`(2,2)`、`(3,2)` 是同一块，得 4；剩下 `(1,3)` 与 `(3,3)` 各为 1。最终 `sizes = [1,1,1,4,4]`？——按题面输出应为 `[1,2,4]`，说明 `(1,3)` 与 `(0,3)` 对角相连、`(3,3)` 与 `(2,2)` 对角相连，归入大块，故三块大小为 1、2、4。

```python
def dfs(i, j):
    if not (0 <= i < m and 0 <= j < n) or land[i][j] != 0:
        return 0
    land[i][j] = 1
    cnt = 1
    for di in (-1, 0, 1):
        for dj in (-1, 0, 1):
            if di or dj:
                cnt += dfs(i + di, j + dj)
    return cnt

sizes = [dfs(i, j) for i in range(m) for j in range(n) if land[i][j] == 0]
sizes.sort()
```

## 复杂度
时间 O(m·n)：每个格子最多被访问一次，8 邻域是常数。
空间 O(m·n)：最坏递归深度等于整个矩阵都是水时的格子数。

## 易错点
- 只搜 4 邻域（上下左右）→ 官方示例里 `(0,3)` 和 `(1,2)` 对角相连会被拆成两块，输出 `[1,1,1,1,4]` 之类 → 必须枚举 8 个方向，`di`、`dj` 都取 `-1,0,1` 并排除 `(0,0)`。
- 用 `land[i][j] == 0` 判断后忘记改值 → 对角相邻的格子会被重复计数，同一池塘大小翻倍 → 进入 DFS 立刻把 `land[i][j]` 置为非 0，靠原矩阵当 `visited`。

## 如果面试官追问
若矩阵大到无法递归（如 10⁶ 格）怎么办？答：把 DFS 换成显式栈的迭代版，或按行扫描用并查集合并 8 邻域，避免递归深度爆栈。
