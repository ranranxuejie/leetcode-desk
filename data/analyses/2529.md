## 一句话思路
数组非递减，负数全在左、正数全在右，用二分找 0 的左右边界，直接算出 neg 和 pos。

## 怎么做
1. 用 `bisect_left(nums, 0)` 求第一个 ≥ 0 的下标 `l`，则 `neg = l`。
2. 用 `bisect_right(nums, 0)` 求第一个 > 0 的下标 `r`，则 `pos = len(nums) - r`。
3. 返回 `max(neg, pos)`。

以示例 2 `nums = [-3,-2,-1,0,0,1,2]` 为例：`bisect_left(nums, 0)` 返回 3（`nums[3]` 是第一个 0），所以 `neg = 3`；`bisect_right(nums, 0)` 返回 5（`nums[5] = 1` 是第一个正数），所以 `pos = 7 - 5 = 2`；`max(3, 2) = 3`。注意 `neg` 直接等于 `l` 是因为下标 0..l-1 恰好全是负数，中间那段 0 被两个边界自动跳过。

```python
from bisect import bisect_left, bisect_right

def maximumCount(nums):
    l = bisect_left(nums, 0)      # 第一个 >= 0 的位置
    r = bisect_right(nums, 0)     # 第一个 > 0 的位置
    neg = l
    pos = len(nums) - r
    return max(neg, pos)
```

关键点：`neg` 用 `bisect_left` 而不是 `bisect_right`，因为 `bisect_right(nums, 0)` 会把 0 也算进左边，示例 2 里就会得到 `neg = 5`，答案错成 5。同理 `pos` 必须用 `bisect_right`，用 `bisect_left` 会把 0 算成正数。

## 复杂度
时间：O(log n)，两次二分，n 是 `len(nums)`。
空间：O(1)，只开了 `l`、`r`、`neg`、`pos` 四个整数。

## 易错点
- 输入 `nums = [0,0,0]` → 若用 `bisect_right(nums, 0)` 算 `neg` 会得到 3，错答 3；正确做法是 `neg = bisect_left(nums, 0) = 0`，`pos = 3 - bisect_right(nums, 0) = 0`，返回 0。
- 输入 `nums = [5,20,66,1314]`（全正，无 0）→ 若把 `pos` 写成 `r` 会得到 0，错答 0；正确做法是 `pos = len(nums) - r = 4 - 0 = 4`，返回 4。

## 如果面试官追问
问：如果数组不是有序的怎么办？
答：退化成 O(n) 一次遍历，用 `x > 0` 和 `x < 0` 分别累加 `pos`、`neg`，有序性才是二分的前提。
