## 一句话思路
用前缀和递推：从左到右扫一遍、再从右到左扫一遍，把「左边所有球移过来的代价」和「右边所有球移过来的代价」相加。

## 怎么做
1. 先统计球总数 `total`，并令 `left_cnt = 0`、`left_cost = 0`，从左往右扫。
2. 扫到下标 `i` 时，先把 `left_cost` 记进 `ans[i]`，再把 `boxes[i] == '1'` 的球并入 `left_cnt`，并让 `left_cost += left_cnt`（这些球之后每往右走一格都要多付 1）。
3. 再从右往左扫一遍，对称维护 `right_cnt`、`right_cost`，累加到同一个 `ans[i]` 上。

以 `boxes = "001011"` 为例：从左扫到 `i = 3` 时，`left_cnt = 1`（下标 2 的球），`left_cost = 1`；再往右一步到 `i = 4`，`left_cost` 变成 `1 + 1 = 2`，正好是下标 2 的球走到 4 的步数。右侧同理，`i = 4` 右边有下标 5 的球，`right_cost = 1`，合计 `ans[4] = 3`，与输出一致。

```python
n = len(boxes)
ans = [0] * n
cnt = cost = 0
for i in range(n):
    ans[i] += cost
    if boxes[i] == '1':
        cnt += 1
    cost += cnt
cnt = cost = 0
for i in range(n - 1, -1, -1):
    ans[i] += cost
    if boxes[i] == '1':
        cnt += 1
    cost += cnt
```

## 复杂度
时间：O(n)，两趟线性扫描，每趟只做常数次加减。
空间：O(n)，只有答案数组 `ans`，`cnt`/`cost` 是常数级。

## 易错点
- 顺序写反：若先 `cost += cnt` 再 `ans[i] += cost`，`"110"` 的 `ans[0]` 会变成 1 而不是 0——`i` 位置的球移到 `i` 本身代价为 0，必须先记录再累加。
- 忘记把 `boxes[i] == '1'` 的球计入 `cnt` 就继续累加：`"001011"` 中下标 2 的球会被漏掉，`ans[4]` 算成 2 而非 3；正确做法是每步先判断当前位是否为 `'1'` 再更新 `cnt`。

## 如果面试官追问
问：n 放大到 10^5 且要求在线回答单点查询怎么办？
答：预处理前缀的 `cnt` 和 `cost` 数组，单点查询 O(1)，总空间 O(n)。
