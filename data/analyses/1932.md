## 一句话思路
把所有树节点塞进哈希表按值索引，找唯一没被任何叶子指向的根，再中序遍历验证严格递增。

## 怎么做
1. 遍历 `trees` 中每棵树的每个节点，把 `val -> node` 存进 `dict`，同时把每棵树的根值记进 `roots` 集合。
2. 再遍历所有节点，若某节点是叶子且其值出现在 `roots` 里，说明它会被别的树替换，从 `roots` 中删掉该值。
3. `roots` 剩下恰好一个值就是最终根；否则返回 `None`。
4. 从该根做中序遍历，检查序列严格递增，是则返回根，否则 `None`。

以示例 1 为例：`roots` 初始 `{2,3,5}`，叶子 `1`、`4` 不在其中，叶子 `2` 和 `5` 在，删后剩 `{3}`，根为 3。中序得 `[1,2,3,4,5]` 严格递增，返回该树。

```python
idx, roots = {}, set()
for t in trees:
    roots.add(t.val)
    stack = [t]
    while stack:
        u = stack.pop()
        idx[u.val] = u
        if u.left: stack.append(u.left)
        if u.right: stack.append(u.right)
for u in idx.values():
    if not u.left and not u.right and u.val in roots:
        roots.discard(u.val)
if len(roots) != 1:
    return None
root = idx[roots.pop()]
```

验证时用栈中序，记录 `prev`，一旦 `u.val <= prev` 立即返回 `None`。

## 复杂度
时间 O(N)，N 为所有节点总数，建表与中序各扫一遍。
空间 O(N)，`idx` 哈希表存全部节点，栈最深 O(N)。

## 易错点
- 输入 `trees=[[5,4],[3]]`：两棵树根 5、3 都不是任何叶子，`roots` 剩两个 → 必须返回 `None`，别默认取第一个根硬合并。
- 输入 `[[5,3,8],[3,2,6]]`：合并后中序为 `[2,3,6,5,8]`，`6` 在 `5` 左边违反 BST；只查「根唯一」不查中序会错返回该树，必须做严格递增校验（用 `<=` 而非 `<` 判失败）。

## 如果面试官追问
若每棵树节点数不再 ≤3 而是任意大，做法还成立吗？
成立，哈希表与中序校验都与单树规模无关，仍是 O(N)，只是建表时 DFS 要处理更深递归，改用显式栈即可。
