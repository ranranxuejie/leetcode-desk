## 一句话思路
用三状态 DP 逐位推进，`dp[j]` 表示当前字符归入第 j 段（红/黄/红）时的最小替换数。

## 怎么做
1. 定义 `dp = [0, inf, inf]`，`dp[j]` 是处理到当前字符为止、该字符落在第 j 段的最小代价；初始只有第 0 段合法。
2. 每读一个字符 `c`，用上一轮的 `dp` 算出新的 `ndp[j] = min(dp[j], dp[j-1]) + (c != 期望字符)`，第 0 段只能从 `dp[0]` 转移，第 2 段只能从 `dp[1]`/`dp[2]` 转移。
3. 期望字符为 `'r','y','r'`；遍历结束后答案是 `dp[2]`。
4. 以 `leaves = "rrryyyrryyyrr"` 为例：处理到下标 5（第 6 个字符 `y`）时，`dp` 约为 `[0, 0, 3]`——前 6 位全归第 1 段只需把 3 个 `r` 改成 `y`，代价 3；继续推进到末尾 `dp[2] = 2`，对应把中间两片 `r` 改成 `y`。

```python
expect = "ryr"
inf = float("inf")
dp = [0, inf, inf]
for c in leaves:
    ndp = [inf, inf, inf]
    for j in range(3):
        if j == 0:
            prev = dp[0]
        else:
            prev = min(dp[j], dp[j - 1])
        ndp[j] = prev + (c != expect[j])
    dp = ndp
# 答案即 dp[2]
```

关键在转移时 `min(dp[j], dp[j-1])`：允许第 j 段延续，也允许从上一段切过来，但绝不回退，保证三段顺序固定。

## 复杂度
时间 O(n)，n 为 `leaves` 长度，每位只做 3 次常数转移。
空间 O(1)，只维护长度 3 的 `dp`/`ndp`，与 n 无关。

## 易错点
- 输入 `"ryr"` 这类已合法的串 → 若把 `dp` 初值写成 `[0,0,0]`，会让第 1、2 段在还没切段时就“免费”成立，答案错成 0 甚至负数偏移 → 初值必须是 `[0, inf, inf]`，强制段边界从左到右依次出现。
- 输入 `"rrr"` 或 `"yyy"` → 若允许某段长度为 0（即 `dp[j]` 直接从 `dp[j-1]` 继承而不消耗字符），会得到 0 次操作，但题目要求每部分至少 1 片 → 靠“每个字符必须归入恰好一段”的逐位转移天然保证每段非空，不要额外写 `dp[j] = min(dp[j], dp[j-1])` 这种不消耗字符的松弛。

## 如果面试官追问
要求输出具体调整后的字符串怎么办？答：在 DP 里额外记录每位的段归属（或从 `dp[2]` 反向回溯每步选了哪个 j），再按段把字符统一成 `r/y/r` 即可，时间仍是 O(n)。
