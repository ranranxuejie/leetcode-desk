## 一句话思路
用快速选择把 `stock` 划分到第 `cnt` 小元素就位，左侧 `cnt` 个即最小 `cnt` 个，平均 O(n)。

## 怎么做
1. 特判 `cnt == 0` 直接返回 `[]`，`cnt == len(stock)` 直接返回 `stock`。
2. 在 `[0, len(stock)-1]` 上做快排式划分，`pivot = stock[lo]`，双指针把小于 `pivot` 的换到左边。
3. 划分后 `pivot` 落在下标 `p`：`p == cnt-1` 停；`p < cnt-1` 只递归右半；`p > cnt-1` 只递归左半。
4. 返回 `stock[:cnt]`，顺序不限。

以 `stock = [2,5,7,4], cnt = 1` 为例：`lo=0, hi=3, pivot=2`，扫描后 `4` 换到 `5` 前，数组变 `[2,4,7,5]`，`p=0`，正好 `p == cnt-1`，返回 `[2]`。

```python
def partition(a, lo, hi):
    pivot, i = a[lo], lo
    for j in range(lo + 1, hi + 1):
        if a[j] < pivot:
            i += 1
            a[i], a[j] = a[j], a[i]
    a[lo], a[i] = a[i], a[lo]
    return i

lo, hi = 0, len(stock) - 1
while lo < hi:
    p = partition(stock, lo, hi)
    if p == cnt - 1:
        break
    elif p < cnt - 1:
        lo = p + 1
    else:
        hi = p - 1
return stock[:cnt]
```

## 复杂度
时间：平均 O(n)，每轮只递归一侧，总扫描量约 2n；最坏 O(n²)，出现在已排序输入。
空间：O(1) 额外，仅 `lo/hi/pivot/i/j` 几个变量，原地交换。

## 易错点
- `stock = [0,2,3,6], cnt = 2` 且 `pivot` 取 `stock[lo]=0` 时，`p=0 < cnt-1=1`，若写成 `lo = p` 会死循环；必须 `lo = p + 1`，因为 `p` 位置已确定是第 `p+1` 小。
- `cnt == 0` 时若直接进循环，`cnt-1 = -1` 永远不满足 `p == -1`，`hi` 一路减到 `-1` 后 `stock[:0]` 虽返回 `[]` 但循环里可能越界访问 `stock[lo]`；开头先返回 `[]`。

## 如果面试官追问
问：`stock` 涨到 10⁷ 且要求稳定输出前 `cnt` 个的升序？
答：快速选择后对 `stock[:cnt]` 单独排序，O(n + cnt log cnt)，比全排序 O(n log n) 省。
