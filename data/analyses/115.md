## 一句话思路
用二维 DP 数「s 的前 i 个字符里能凑出 t 的前 j 个字符的方案数」，因为每个 s 字符只有「用/不用」两种选择。

## 怎么做
1. 定义 `dp[i][j]` = `s[:i]` 的子序列中等于 `t[:j]` 的个数，`dp[i][0] = 1`（空串永远有 1 种凑法），`dp[0][j>0] = 0`。
2. 转移：`s[i-1] == t[j-1]` 时 `dp[i][j] = dp[i-1][j] + dp[i-1][j-1]`，否则 `dp[i][j] = dp[i-1][j]`。
3. 用一维滚动数组，`j` 必须**从大到小**遍历，否则 `dp[j-1]` 已被本轮覆盖。
4. 返回 `dp[len(t)]`。

以 `s = "rabbbit", t = "rabbit"` 为例，关键在 s 的三个连续 `b`（下标 2、3、4）。处理到 `t` 的第 4 个字符 `b` 时，`dp[4]` 依次累加成 1、2、3；再往后 `i`、`t` 都匹配，最终 `dp[6] = 3`。三个 `b` 里任选两个，正是 3 种方案。

```python
m, n = len(s), len(t)
dp = [0] * (n + 1)
dp[0] = 1
for i in range(1, m + 1):
    for j in range(n, 0, -1):
        if s[i - 1] == t[j - 1]:
            dp[j] += dp[j - 1]
return dp[n]
```

注意 `dp[j] += dp[j-1]` 就是 `dp[i-1][j] + dp[i-1][j-1]` 的原地写法：等号左边的 `dp[j]` 还是上一行（`i-1`）的值，右边的 `dp[j-1]` 因为倒序也还是上一行的值。

## 复杂度
时间：`O(m*n)`，`m = len(s)`、`n = len(t)`，两层循环各贡献一个因子。
空间：`O(n)`，只开长度 `n+1` 的 `dp` 数组，滚动掉 s 那一维。

## 易错点
- `s = "aaa", t = "aa"` → 内层若写成 `for j in range(1, n+1)` 正序，`dp[2]` 会用到本轮刚更新的 `dp[1]`，把同一个 `s` 字符重复使用，答案错成 3 而非 1 → 必须 `range(n, 0, -1)` 倒序。
- `s = "babgbag", t = "bag"` → 若把 `dp[0]` 初始化为 0，或忘记 `dp[0] = 1`，所有转移都乘 0，答案错成 0 → 空串是任何串的子序列且只有 1 种，`dp[0]` 必须为 1。

## 如果面试官追问
问：要求输出所有具体方案而非只计数？答：DP 只存计数会丢信息，需在 `dp[i][j]` 里存方案列表或用回溯 + 记忆化枚举，空间从 `O(n)` 涨到与方案数同阶。
