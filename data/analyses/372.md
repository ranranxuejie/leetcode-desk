## 一句话思路
用欧拉降幂把指数按 1337 的欧拉函数 1140 缩小，再对数组 b 逐位做秦九韶式取模。

## 怎么做
1. 先算 `a %= 1337`，因为底数只影响模 1337 的结果。
2. 把数组 b 当成十进制大数，逐位累加指数：`e = (e * 10 + d) % 1140`，其中 1140 是 φ(1337)=φ(7·191)=6·190。
3. 用快速幂算 `pow(a, e, 1337)`，注意 e 可能为 0 时要返回 1。
4. 特判 `a % 1337 == 0` 时直接返回 0（此时 e 为 0 会误算成 1）。

以示例 2 为例：`a=2, b=[1,0]`。第 2 步中，先 `e = (0*10+1)%1140 = 1`，再 `e = (1*10+0)%1140 = 10`；第 3 步 `pow(2,10,1337)=1024`，与输出一致。

```python
MOD = 1337
PHI = 1140

a %= MOD
if a == 0:
    return 0
e = 0
for d in b:
    e = (e * 10 + d) % PHI
return pow(a, e, MOD)
```

关键中间值：示例 2 的 `e` 从 1 变成 10，`pow(2,10,1337)` 得 1024；示例 1 的 `e=3`，`pow(2,3,1337)=8`。

## 复杂度
时间：O(len(b) + log 1140)，遍历 b 一次，快速幂最多 11 次乘法。
空间：O(1)，只存 `e` 和 `a`，没有额外数组。

## 易错点
- 输入 `a=1337, b=[1]` → 若直接 `pow(1337,1,1337)` 得 0 没问题，但若先算 `e=1%1140=1` 再 `pow(0,1,1337)=0` 也对；真正翻车是 `a=1337, b=[0]` 不存在（b 不含前导 0 且为正整数），但 `a=1337, b=[2]` 时 `pow(0,2,1337)=0` 正确。坑在 `a % 1337 == 0` 且 `e` 被缩成 0 的情况，比如 `a=1337, b=[1140]`：`e=1140%1140=0`，`pow(0,0,1337)=1`，但真实 `1337^1140 mod 1337 = 0`。正确做法是先判 `a % 1337 == 0` 返回 0。
- 输入 `a=2, b=[1,0,0,0]`（指数 1000）→ 若忘记对 1140 取模而直接 `pow(2,1000,1337)` 也能对，但 b 长度 2000 时指数有 2000 位，Python 大整数虽能算但慢；正确做法是逐位 `e=(e*10+d)%1140`，把指数压到 1140 以内。

## 如果面试官追问
问：如果模数不是 1337 而是任意 m，还能用欧拉降幂吗？
答：能，但 a 与 m 不互质时要用扩展欧拉定理，指数需保留 `e % φ(m) + φ(m)` 的修正项。
