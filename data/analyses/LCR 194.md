## 一句话思路
后序 DFS 返回「子树里找到的 p 或 q」，左右都非空的那个节点就是 LCA。

## 怎么做
1. 递归函数 `dfs(node)` 返回：以 `node` 为根的子树中，若含 p 或 q 则返回那个节点，否则返回 `None`。
2. 递归出口：`node is None` 或 `node is p` 或 `node is q` 时直接返回 `node`。
3. 分别求 `left = dfs(node.left)`、`right = dfs(node.right)`；`left` 与 `right` 都非空说明 p、q 分居两侧，`node` 即答案。
4. 只有一侧非空就把它往上抛，两侧都空返回 `None`。

以示例 2（p=5, q=4）走一遍关键那步：递归到节点 2 时，`dfs(2.left=7)` 返回 `None`，`dfs(2.right=4)` 返回节点 4，于是 `dfs(2)` 返回 4；回到节点 5，`left = dfs(5.left=6) = None`，`right = dfs(5.right=2) = 4`，只有右侧非空，返回 5；再回到根 3，`left = 5`、`right = dfs(1) = None`，返回 5，即答案。

```python
def dfs(node):
    if node is None or node is p or node is q:
        return node
    left = dfs(node.left)
    right = dfs(node.right)
    if left and right:
        return node
    return left or right
```

注意 `left and right` 判的是「两个返回值都非 None」，不是判值相等；`left or right` 在 Python 里返回的是非 None 的那个节点对象本身，正好是需要的语义。

## 复杂度
时间 O(n)：每个节点被访问一次，n 是节点总数。
空间 O(h)：递归栈深度等于树高 h，最坏链状树 O(n)，无额外数组。

## 易错点
- 输入 p=5、q=4 这类「祖先是自己」的情形 → 若在递归里先判 `node.left and node.right` 再判 `node is p`，节点 5 会被继续下探而错过后代 4 → 正确做法是把 `node is p or node is q` 放在函数最前面当出口，命中即返回。
- 输入是链状树（如 root=[1,2,null,3,null,4] 且 p、q 在深处）→ 递归深度到 n，Python 默认递归上限约 1000，n 大时抛 `RecursionError` → 正确做法是确认题目规模或改写成显式栈的迭代后序，别默认递归一定安全。

## 如果面试官追问
问：若 p、q 不保证存在于树中怎么办？
答：加一个计数器统计命中数，DFS 结束后命中数小于 2 就返回 `None`，其余逻辑不变。
