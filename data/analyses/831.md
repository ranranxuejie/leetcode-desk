## 一句话思路
先看 `s` 里有没有 `'@'` 分流：有就按邮箱切名字和域名，没有就抽数字按国家码位数套模板。

## 怎么做
1. 用 `'@' in s` 判断类型，这是唯一的分流条件。
2. 邮箱：`name, domain = s.split('@')`，输出 `name[0].lower() + '*****' + name[-1].lower() + '@' + domain.lower()`。
3. 电话：`digits = [c for c in s if c.isdigit()]`，`local = digits[-10:]`，`code = digits[:-10]`。
4. 按 `len(code)` 选前缀 `''`、`'+*-'`、`'+**-'`、`'+***-'`，拼 `'-'.join(['***','***',''.join(local[-4:])])`。

以 `s = "AB@qq.com"` 为例：`name = "AB"`，`name[0].lower() = 'a'`，`name[-1].lower() = 'b'`，中间固定 5 个星，得 `"a*****b@qq.com"`——注意名字只有 2 个字符时中间照样是 5 个星，不是 `len(name)-2` 个。

以 `s = "1(234)567-890"` 为例：`digits = ['1','2','3','4','5','6','7','8','9','0']` 共 10 位，`code = digits[:-10] = []`，`local = digits[-10:]`，`local[-4:]` 是 `'7890'`，前缀为空，输出 `"***-***-7890"`。

```python
if '@' in s:
    name, domain = s.split('@')
    return name[0].lower() + '*****' + name[-1].lower() + '@' + domain.lower()
digits = [c for c in s if c.isdigit()]
code, local = digits[:-10], digits[-10:]
prefix = ['', '+*-', '+**-', '+***-'][len(code)]
return prefix + '***-***-' + ''.join(local[-4:])
```

## 复杂度
时间 O(n)：`n` 是 `len(s)`，一次扫描抽数字或一次 `split`。
空间 O(n)：`digits` 列表最多存 13 个字符，邮箱分支的 `split` 另开两个串。

## 易错点
1. `s = "AB@qq.com"` → 若写成 `name[0] + '*'*(len(name)-2) + name[-1]`，会得到 `"a@qq.com"`（0 个星）→ 正确做法是星号恒为 5 个，与名字长度无关。
2. `s = "+1-234-567-8901"` → 若用 `digits[-10:]` 当本地号码却把 `len(digits)-10` 算成前缀长度时忘了 `digits` 是字符列表而非字符串，`digits[:-10]` 在 10 位时是 `[]` 而非 `''`，`len([]) = 0` 恰好对；但若写成 `s[:-10]` 取到的是含分隔符的原文 → 必须先抽数字再切片。

## 如果面试官追问
问：如果国家码允许 4 位怎么办？
答：把前缀表扩成 `['', '+*-', '+**-', '+***-', '+****-']`，其余逻辑不变，因为 `len(code)` 直接索引。
