## 一句话思路
用两个栈 in_stack 和 out_stack 拼队列：push 只进 in_stack，pop 时若 out_stack 空就把 in_stack 全部倒过去，再弹栈顶。

## 怎么做
1. push 一律 `in_stack.append(bookID)`，不碰 out_stack。
2. pop 前先检查 `out_stack`，为空才把 `in_stack` 逐个 `pop` 到 `out_stack`。
3. 倒完后 `out_stack.pop()` 就是最早归还的书；两个栈都空则返回 -1。
4. 关键中间值：示例 push(1)、push(2) 后 `in_stack=[1,2]`、`out_stack=[]`；第一次 pop 触发倒栈，`in_stack=[]`、`out_stack=[2,1]`，弹出 2 的栈顶 1，正是输出 1。

```python
def push(self, bookID):
    self.in_stack.append(bookID)

def pop(self):
    if not self.out_stack:
        while self.in_stack:
            self.out_stack.append(self.in_stack.pop())
    return self.out_stack.pop() if self.out_stack else -1
```

倒栈只在 out_stack 空时发生，所以每本书最多被搬一次，均摊 O(1)。注意 `in_stack=[1,2]` 倒过去变成 `[2,1]`，栈顶 1 是最早进的，顺序才对。

## 复杂度
时间：每次操作均摊 O(1)，n 次调用共 O(n)，每本书最多倒一次栈。
空间：O(n)，in_stack 与 out_stack 合计最多存 n 本书。

## 易错点
1. 连续 pop 时每次都倒栈 → 把 `in_stack=[1,2]` 反复搬运，顺序被打乱且退化成 O(n) 每次 → 只在 `out_stack` 为空时倒，非空直接用栈顶。
2. 空队列 pop → 直接 `out_stack.pop()` 抛 IndexError，而题目要求返回 -1 → 倒栈后仍为空就返回 -1，别让异常冒出去。

## 如果面试官追问
问：如果要求 pop 后还能查看队首但不弹出？
答：加 peek，逻辑同 pop 但不弹栈顶，out_stack 空时同样先倒栈再读 `out_stack[-1]`。
