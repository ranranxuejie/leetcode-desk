## 一句话思路
按层 BFS，每层先求整层和，再用「层和 − 本节点值 − 兄弟值」得到每个节点的堂兄弟和。

## 怎么做
1. 用队列逐层遍历，先把当前层所有节点收集成 `level` 列表。
2. 对 `level` 求 `total = sum(node.val for node in level)`。
3. 对每个节点，看它的两个孩子：`sib = (左值 if 有) + (右值 if 有)`，把两个孩子的新值都记为 `total - node.val - sib`。
4. 把非空孩子入队，进入下一层。

以 `root = [5,4,9,1,10,null,7]` 为例：第 2 层 `level = [4,9]`，`total = 13`。处理节点 4 时，它的孩子是 1 和 10，`sib = 11`，于是 1 和 10 的新值都是 `13 - 4 - 11 = -2`？不对——注意 `total` 要减去的是**父节点值**，而堂兄弟和只跟同层其他子树有关：正确公式是 `total - node.val - sib`，其中 `node.val` 是父节点值，`sib` 是亲兄弟值。对节点 4：`13 - 4 - 11 = -2` 显然错，因为 1 和 10 的堂兄弟只有 7，应为 7。问题在于 `total` 包含了 4 和 9 本身，而堂兄弟和应只算**下一层**。所以正确做法是：先算下一层的总和，再减父值减兄弟值。

修正后的关键步骤：处理第 2 层时，先算第 3 层总和 `total3 = 1 + 10 + 7 = 18`。对节点 4，孩子 1、10 的 `sib = 11`，新值 `18 - 4 - 11 = 3`？仍不对。真正公式：节点 1 的堂兄弟是 7，即 `total3 - (1+10) = 7`，与父值无关。所以应为 `total3 - sib`，其中 `sib` 是**该节点所在兄弟对**的值和。对 1 和 10：`18 - 11 = 7` ✓；对 7：`18 - 7 = 11` ✓。

```python
from collections import deque
q = deque([root])
while q:
    level = [q.popleft() for _ in range(len(q))]
    nxt = []
    for node in level:
        if node.left: nxt.append(node.left)
        if node.right: nxt.append(node.right)
    total = sum(x.val for x in nxt)
    for node in level:
        sib = (node.left.val if node.left else 0) + (node.right.val if node.right else 0)
        if node.left: node.left.val = total - sib
        if node.right: node.right.val = total - sib
    q.extend(nxt)
```

## 复杂度
时间 O(n)：每个节点被访问常数次，`sum` 与赋值各扫一遍层。
空间 O(w)：队列最宽一层 w 个节点，最坏 O(n)。

## 易错点
- 用「整层和减父值减兄弟值」→ 示例 1 中节点 1 会得 `13-4-11=-2`，错成负数；正确是只对**下一层**求和 `total`，再减兄弟对和 `sib`，得 7。
- 叶子节点没有孩子时 `sib=0`、`nxt` 为空，`total=0`，若仍执行 `node.left.val = ...` 会 `AttributeError`；必须先判 `if node.left` 再赋值。

## 如果面试官追问
若节点数涨到 10^7、内存吃紧？答：改用 DFS 两遍，第一遍按深度累加和存数组，第二遍原地改写，省掉队列的 O(w) 峰值。
