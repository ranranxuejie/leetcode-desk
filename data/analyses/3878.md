## 一句话思路
对每个右端点 r，维护所有以 r 结尾子数组的按位或去重集合，并判断其中哪个值等于某个元素。

## 怎么做
1. 关键观察：子数组按位或等于其中某元素 x，等价于该子数组所有元素都是 x 的「子集」（`a | x == x`），且至少有一个 x。
2. 对每个右端点 r，用单调栈维护「以 r 结尾、按位或值」的分段：值随左端点左移单调不减，段数 ≤ 30（因为 10^9 < 2^30）。
3. 枚举每段，若段值 v 在 `[l, r]` 内出现过，则该段内所有左端点都合法，累加段长。
4. 用 `last[v]` 记录值 v 最近一次出现的下标，判断 v 是否落在段区间内。

以 `nums = [4,2,3]` 为例：r=1（值 2）时，段为 `[(2, [1,1])]`，`last[2]=1` 在区间内，累加 1；r=2（值 3）时，段为 `[(3,[2,2]), (2|3=3,[1,1])]` 合并后仍是值 3 覆盖 `[1,2]`，`last[3]=2` 在区间内，累加 2。总计 1+1+2=4。

```python
# 伪代码骨架，非完整提交
segs = []          # [(or_val, leftmost_l, rightmost_l)]
last = {}          # 值 -> 最近下标
ans = 0
for r, x in enumerate(nums):
    new = [(x, r, r)]
    for v, lo, hi in segs:
        nv = v | x
        if nv == new[-1][0]:
            new[-1] = (nv, new[-1][1], hi)
        else:
            new.append((nv, lo, hi))
    segs = new
    for v, lo, hi in segs:
        if last.get(v, -1) >= lo:
            ans += hi - lo + 1
    last[x] = r
```

## 复杂度
时间 O(n·30)：每个右端点最多 30 段，每段 O(1) 合并与判定。
空间 O(30)：只存当前 segs 与 last 字典，与 n 无关。

## 易错点
- 输入 `[0,0]`：按位或 0 等于元素 0，两个单元素子数组和 `[0,0]` 都合法，答案 3。若把「或值等于元素」误判成「或值非零」会漏掉全 0 段。
- 输入 `[1,3,1]`：r=2 时值 3 的段覆盖 `[0,2]`，`last[3]=1` 落在段内，累加 3；若只比较段值是否等于 `nums[r]` 会漏掉 `[1,3]`、`[1,3,1]` 这类「或值等于中间元素」的情况。

## 如果面试官追问
若要求输出所有好子数组而非计数，怎么做？答：在每段命中时枚举左端点 `lo..hi` 输出 `(l, r)`，总输出量即答案规模，复杂度不变。
