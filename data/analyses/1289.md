## 一句话思路
逐行 DP，每格只需上一行的最小值与次小值（不同列），O(n²) 代替 O(n³) 枚举。

## 怎么做
1. 令 `dp[j]` 表示落到当前行第 `j` 列的最小路径和，初始 `dp = grid[0]`。
2. 每行先扫一遍 `dp`，记下最小值 `m1`、其列号 `c1`、次小值 `m2`（`m2` 是除 `c1` 列外的最小值）。
3. 新行每列 `j`：若 `j != c1` 取 `m1`，否则取 `m2`，再加 `grid[i][j]`。
4. 最后返回 `min(dp)`。

以 `[[1,2,3],[4,5,6],[7,8,9]]` 为例：第一行 `dp=[1,2,3]`，`m1=1,c1=0,m2=2`。第二行：`j=0` 用 `m2=2` 得 `2+4=6`；`j=1` 用 `m1=1` 得 `1+5=6`；`j=2` 用 `m1=1` 得 `1+6=7`，`dp=[6,6,7]`。此时 `m1=6,c1=0,m2=6`。第三行：`j=0` 用 `m2=6` 得 `13`；`j=1`、`j=2` 用 `m1=6` 得 `14`、`15`。`min=13`，与示例一致。

```python
dp = grid[0][:]
for row in grid[1:]:
    m1 = m2 = 2**31 - 1
    c1 = -1
    for j, v in enumerate(dp):
        if v < m1:
            m2, m1, c1 = m1, v, j
        elif v < m2:
            m2 = v
    dp = [row[j] + (m1 if j != c1 else m2) for j in range(len(row))]
return min(dp)
```

关键点：`m2` 必须是「列号不等于 `c1` 的最小值」，不是全局第二小。若 `dp=[6,6,7]`，`m1=6,c1=0`，`m2` 取 `6`（来自 `j=1`），而不是 `7`。

## 复杂度
时间：O(n²)，每行扫两遍 n 列，共 n 行。
空间：O(n)，只保留一行 `dp`，未开 n×n 表。

## 易错点
- 输入 `[[1,2,3],[4,5,6],[7,8,9]]` 时，若把 `m2` 写成全局第二小（`2` 而非按列排除），第二行 `j=0` 会误用 `m1=1` 得 `5`，最终答案偏小成 `12`。正确做法是 `m2` 只在 `j != c1` 的列里取最小。
- 输入 `[[7]]` 或单行矩阵时，循环体不执行，若把 `m1/m2` 初始化成 `2**31 - 1` 后直接返回 `min(dp)` 没问题，但若在循环内才初始化 `dp` 会漏掉首行。正确做法是 `dp = grid[0][:]` 先落地，再进循环。

## 如果面试官追问
问：要求输出具体路径而非和？
答：每行额外存 `prev[j]` 记录上一行选中的列号，回溯即可，空间升到 O(n²)。
