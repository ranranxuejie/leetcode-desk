## 一句话思路
中序遍历 BST 得到有序数组，再用 `bisect_left` 二分查每个 query 的前驱后继。

## 怎么做
1. 中序遍历 `root`，把节点值依次追加到 `vals`，得到严格递增数组。
2. 对每个 `q`，用 `bisect_left(vals, q)` 求下标 `i`。
3. `i < len(vals) and vals[i] == q` 时答案是 `[q, q]`；否则前驱取 `vals[i-1]`（`i>0`），后继取 `vals[i]`（`i<len`），越界填 `-1`。

以示例 1 为例：中序得 `vals = [1,2,4,6,9,13,14,15]`。`q=5` 时 `bisect_left` 返回 `i=3`（`vals[3]=6`），前驱 `vals[2]=4`、后继 `vals[3]=6`，得 `[4,6]`；`q=16` 时 `i=8` 等于长度，前驱 `vals[7]=15`、后继 `-1`。

```python
vals = []
def dfs(node):
    if not node:
        return
    dfs(node.left)
    vals.append(node.val)
    dfs(node.right)
dfs(root)

ans = []
for q in queries:
    i = bisect_left(vals, q)
    if i < len(vals) and vals[i] == q:
        ans.append([q, q])
    else:
        lo = vals[i - 1] if i > 0 else -1
        hi = vals[i] if i < len(vals) else -1
        ans.append([lo, hi])
```

## 复杂度
时间：中序 O(n)，每个 query 二分 O(log n)，共 O(n + q log n)。
空间：`vals` 存 n 个值 O(n)，递归栈最坏 O(n)。

## 易错点
- `q` 恰好等于某节点值：若只写 `vals[i-1]` 和 `vals[i]` 而不判等，`q=2` 会得 `[1,6]` 而非 `[2,2]`，必须先判 `vals[i] == q`。
- `q` 小于最小值或大于最大值：`q=16` 时 `i=8`，直接取 `vals[8]` 会下标越界，必须用 `i < len(vals)` 兜底填 `-1`；`q` 小于 `vals[0]` 时同理 `i=0` 不能取 `vals[-1]`。

## 如果面试官追问
若树是普通二叉树而非 BST？答：先中序排序成数组再二分，代价从 O(n) 遍历变成 O(n log n) 排序，查询逻辑不变。
