## 一句话思路
把 `nums` 看成每个下标 i 指向 `nums[i]` 的有向图，每个点出度恰为 1，答案就是最大环长度，用原地标记一次遍历即可。

## 怎么做
1. 遍历每个起点 `i`，若 `nums[i] != -1` 说明这条链没被走过，进入内层循环。
2. 内层沿 `nums[cur]` 走，每到一个点先记下 `nxt = nums[cur]`，再把 `nums[cur] = -1` 标记为已访问，`cur = nxt`，`length += 1`。
3. 走到 `nums[cur] == -1` 时停下，用 `max` 更新答案。

以 `A = [5,4,0,3,1,6,2]` 为例，从 `i=0` 出发：`cur=0` 时 `nxt=5`，标记 `A[0]=-1`；接着 `cur=5` 时 `nxt=6`，标记 `A[5]=-1`；再 `cur=6` 时 `nxt=2`；再 `cur=2` 时 `nxt=0`，此时 `A[2]=-1` 已标记，`length` 累计到 4，答案更新为 4。之后 `i=1` 时 `A[1]=4` 未被标记，走 `1→4→1` 得长度 2，不更新。

```python
n = len(nums)
best = 0
for i in range(n):
    if nums[i] == -1:
        continue
    cur, length = i, 0
    while nums[cur] != -1:
        nxt = nums[cur]
        nums[cur] = -1
        cur = nxt
        length += 1
    best = max(best, length)
return best
```

关键点：标记必须在「读走 `nxt` 之后、跳过去之前」做，否则 `cur` 已经变成下一个点，标记的就不是刚走过的那个下标。

## 复杂度
时间 O(n)：每个下标最多被标记一次，外层循环加内层总步数不超过 2n。
空间 O(1)：只用了 `cur`、`nxt`、`length`、`best` 几个变量，标记直接写在 `nums` 上。

## 易错点
- 输入 `A = [1,0]` 这种二元环：若先 `cur = nums[cur]` 再标记，会把 `A[1]` 标成 -1 而漏标 `A[0]`，下一轮从 `i=1` 又走一遍，长度算成 2 但逻辑已乱；正确做法是先存 `nxt`、标 `nums[cur]`、再移动。
- 输入 `A = [0]` 这种自环：`nums[0] = 0`，若循环条件写成 `while nums[cur] != cur` 会死循环；必须用 `-1` 作哨兵，因为 `nums` 原值域是 `[0, n-1]`，`-1` 不会与合法值冲突。

## 如果面试官追问
问：要求输出最长环的具体下标序列怎么办？
答：标记时把 `cur` 追加进临时列表，`length` 超过 `best` 时整体拷贝该列表，空间升到 O(n)。
