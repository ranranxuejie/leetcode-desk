## 一句话思路
用单调递减栈维护「右子树还没着落的祖先链」，新值比栈顶大就弹栈找父节点，比栈顶小就挂成栈顶的左孩子。

## 怎么做
1. 建 `root = TreeNode(preorder[0])`，栈 `stack = [root]`，从 `preorder[1]` 开始扫。
2. 当前值 `v` 小于栈顶值时，`v` 一定是栈顶的左孩子，直接挂上并压栈。
3. 否则持续弹栈，直到栈空或栈顶值大于 `v`；最后弹出的那个节点 `last` 就是 `v` 的父节点，`v` 挂成 `last.right`，再压栈。

以 `[8,5,1,7,10,12]` 为例：压入 8、5、1 后栈为 `[8,5,1]`；读到 7，7>1 弹出 1，7>5 弹出 5，7<8 停，`last=5`，7 成为 5 的右孩子，栈变 `[8,7]`；读到 10，10>7 弹 7，10>8 弹 8，栈空，`last=8`，10 成为 8 的右孩子。

```python
stack = [root]
for v in preorder[1:]:
    node = TreeNode(v)
    if v < stack[-1].val:
        stack[-1].left = node
    else:
        last = stack.pop()
        while stack and stack[-1].val < v:
            last = stack.pop()
        last.right = node
    stack.append(node)
```

关键点：弹栈时 `last` 要一路更新成**最后弹出**的节点，而不是第一个；`while` 条件用 `<` 而非 `<=`，因为值互不相同，用 `<=` 在遇到相等时会多弹一层（本题不会触发，但换成有重复值的变体就翻车）。

## 复杂度
时间 O(n)：每个节点入栈出栈各一次，`while` 总弹栈次数不超过 n。
空间 O(n)：栈最坏（严格递减输入如 `[5,4,3,2,1]`）存 n 个节点，另加 n 个 TreeNode。

## 易错点
- 输入 `[1,3]`：若把「弹栈后 `last` 取第一个弹出的节点」写死，`last` 会是 1 本身没问题，但换成 `[8,5,1,7]` 时第一个弹出的是 1，7 会错挂成 1 的右孩子；正确做法是循环里持续 `last = stack.pop()`，让 `last` 停在 5。
- 输入 `[10,5,15,3,7]`：若在 `v < stack[-1].val` 分支里忘了 `stack.append(node)`，栈顶永远停在 10，读到 3 时 3<10 会错挂成 10 的左孩子；正确做法是两个分支末尾统一压栈。

## 如果面试官追问
问：若 preorder 含重复值（左子树 ≤ 根 < 右子树）怎么办？
答：弹栈条件改成 `stack[-1].val <= v`，挂左孩子条件改成 `v <= stack[-1].val`，其余不变。
