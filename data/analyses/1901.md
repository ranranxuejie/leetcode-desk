## 一句话思路
对行二分：每行取最大值，比较它与下一行同列的值，据此决定向上还是向下收缩。

## 怎么做
1. 二分行区间 `lo, hi = 0, m-1`，取 `mid = (lo + hi) // 2`。
2. 在 `mat[mid]` 中找最大值所在列 `j = mat[mid].index(max(mat[mid]))`。
3. 若 `mid+1 < m` 且 `mat[mid+1][j] > mat[mid][j]`，说明下方更大，峰值在下方，令 `lo = mid + 1`；否则若 `mid-1 >= 0` 且 `mat[mid-1][j] > mat[mid][j]`，令 `hi = mid - 1`；否则 `[mid, j]` 就是峰值。
4. 循环到 `lo > hi` 前必返回。

以示例 2 为例：`m=3`，`lo=0, hi=2`，`mid=1`，`mat[1] = [21,30,14]`，最大值列 `j=1`（值 30）。比较 `mat[2][1]=16 < 30`，`mat[0][1]=20 < 30`，两侧都不更大，直接返回 `[1,1]`。

```python
lo, hi = 0, len(mat) - 1
while lo <= hi:
    mid = (lo + hi) // 2
    row = mat[mid]
    j = row.index(max(row))
    if mid + 1 < len(mat) and mat[mid + 1][j] > row[j]:
        lo = mid + 1
    elif mid - 1 >= 0 and mat[mid - 1][j] > row[j]:
        hi = mid - 1
    else:
        return [mid, j]
```

关键点：行内最大值保证了左右邻居都比它小，只需再验证上下；若下方更大就往下走，因为下方那一行在列 `j` 上有一个更大的值，沿该列继续找必能落到峰值。

## 复杂度
时间 O(m log n)：每轮二分行做一次 O(n) 的行内扫描，共 log m 轮，实际是 O(n log m)。
空间 O(1)：只用了 `lo, hi, mid, j` 几个变量，没有额外数组。

## 易错点
- 输入 `mat = [[1]]`（单行单列）→ 若先判 `mid+1 < m` 再判 `mid-1 >= 0` 却漏了边界，会越界或死循环 → 两个方向都要先判下标存在，都不满足时直接返回 `[mid, j]`。
- 输入 `mat = [[1,4],[3,2]]` → 若只比较 `mat[mid+1][j]` 就往下走，可能错过上方峰值；若把「行内最大值」换成「行首元素」比较，会走到非峰值格 → 必须用 `row.index(max(row))` 取行内最大列，保证左右邻居已满足。

## 如果面试官追问
问：若要求 O(m + n) 而非 O(n log m) 怎么做？
答：从右上角出发，每次与左、下邻居比较，朝更大者移动，每步消掉一行或一列，最多 m+n 步。
