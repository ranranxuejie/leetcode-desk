## 一句话思路
用哈希表抵消两篮共有水果，剩余差异必须成对互补，排序后取「小的一半」与 `2*全局最小值` 逐项取小求和。

## 怎么做
1. 用 `diff[x] = count1[x] - count2[x]` 统计差值；任一 `diff[x]` 为奇数则返回 `-1`（该值无法在两篮间均分）。
2. 把 `diff[x] > 0` 的值重复 `diff[x]//2` 次压入 `a`（basket1 多出的），`diff[x] < 0` 的压入 `b`（basket2 多出的），两者长度必相等。
3. 排序后只需配对 `a` 的小半与 `b` 的大半：`a` 升序、`b` 降序，逐位取 `min(a[i], b[i])` 累加。
4. 每个配对还可借全局最小值 `mn` 中转：成本 `2*mn`，故每项取 `min(a[i], b[i], 2*mn)`。

以示例 1 为例：`basket1=[4,2,2,2]`、`basket2=[1,4,1,2]`，差值 `diff = {4:0, 2:2, 1:-2}`，得 `a=[2]`、`b=[1]`，`mn=1`。配对成本 `min(2, 1, 2*1)=1`，答案 1。

```python
from collections import Counter
c1, c2 = Counter(basket1), Counter(basket2)
diff = {x: c1[x] - c2[x] for x in c1.keys() | c2.keys()}
if any(v % 2 for v in diff.values()):
    return -1
a = sorted(x for x, v in diff.items() for _ in range(v // 2) if v > 0)
b = sorted((x for x, v in diff.items() for _ in range(-v // 2) if v < 0), reverse=True)
mn = min(min(basket1), min(basket2))
return sum(min(x, y, 2 * mn) for x, y in zip(a, b))
```

## 复杂度
时间：O(n + k log k)，k 为差异元素个数（≤ n），排序贡献 log。
空间：O(k)，Counter 与 a、b 两个列表。

## 易错点
- 输入 `basket1=[1,1]`、`basket2=[1,2]`：`diff[2]=-1` 为奇数，若只判「总差异为偶数」会漏判，误算出成本；必须逐值检查 `v % 2`，奇数直接 `-1`。
- 输入 `basket1=[1,100]`、`basket2=[100,100]`：只按 `min(a[i], b[i])` 配对得 100，忽略 `2*mn=2` 中转；正确做法是每项取 `min(a[i], b[i], 2*mn)`，答案 2。

## 如果面试官追问
问：要求输出具体交换方案而非成本？答：排序配对后记录每对 `(a[i], b[i])` 及是否走 `mn` 中转，按原数组下标回填即可。
