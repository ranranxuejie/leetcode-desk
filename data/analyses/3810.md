## 一句话思路
按值分组看下标集合，每个值 x 只需一次操作就能覆盖它所有「当前是 x 且 nums[i] != target[i]」的极大段，答案就是这类值的个数。

## 怎么做
1. 只关心 `nums[i] != target[i]` 的位置，这些位置必须被某次操作改掉。
2. 对每个值 x，收集所有满足 `nums[i] == x and nums[i] != target[i]` 的下标。
3. 关键判断：这些下标若在数组里被「非 x 的位置」隔开，就是多个极大段，但一次选 x 会同时更新所有段，所以仍只算 1 次。
4. 因此答案 = 存在待改位置的 x 的种数，用集合统计即可。

以示例 3 `nums = [7,3,7], target = [5,5,9]` 为例：待改位置是 0、1、2。下标 0 和 2 的 `nums` 都是 7，虽然中间隔着下标 1 的 3，选 x=7 时两个极大段 `[0,0]`、`[2,2]` 同时更新，只花 1 次；下标 1 的 3 再花 1 次，共 2。

```python
need = set()
for a, b in zip(nums, target):
    if a != b:
        need.add(a)
return len(need)
```

注意 `need` 存的是 `nums` 的值，不是下标，也不是 `target` 的值。

## 复杂度
时间 O(n)：一次遍历，集合插入均摊 O(1)。
空间 O(n)：`need` 最多存 n 个不同的 nums 值。

## 易错点
- 把「极大段个数」当答案：示例 3 中 x=7 有两个极大段，若按段计数会得 3，正确是 2，因为一次选 x 同时更新所有段。
- 用 `target[i]` 而不是 `nums[i]` 入集合：示例 1 中待改位置 0、1 的 target 是 2、1，会得 2 碰巧对；但示例 3 待改位置 target 是 5、5、9，会得 2 也碰巧对，换成 `nums=[1,1], target=[2,3]` 就会错成 2，正确是 1（选 x=1 一次改完）。

## 如果面试官追问
问：若要求输出具体操作序列怎么办？
答：按 `need` 里每个值 x 输出一次操作即可，顺序任意，因为每次只改 `nums[i]==x` 的段，互不干扰。
