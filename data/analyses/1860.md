## 一句话思路
按秒模拟，每轮把 `i` 从剩余内存较多的那条扣掉，扣不动就退出；总量 ≤ 2^32，秒数上界约 9 万，直接循环即可。

## 怎么做
1. 初始化 `t = 1`，循环条件写成 `while True`，每轮先判断两条内存是否都 `< t`。
2. 若都扣不动，返回 `[t, memory1, memory2]`，此时 `t` 就是 crashTime。
3. 否则选目标：`memory1 >= memory2` 时扣 `memory1`（相等也归第一条，这是题面规定的平局规则），否则扣 `memory2`。
4. 扣完 `t += 1` 继续。

拿示例 2 走关键几步：`memory1=8, memory2=11`。t=1 时 11>8 扣第二条 → `(8,10)`；t=2 时 10>8 扣第二条 → `(8,8)`；t=3 时相等，按规则扣第一条 → `(5,8)`。注意 t=2 结束时两条相等，t=3 必须走 `>=` 分支扣 memory1，若写成 `>` 就会扣 memory2，后面全错。

```python
t = 1
while True:
    if memory1 < t and memory2 < t:
        return [t, memory1, memory2]
    if memory1 >= memory2:
        memory1 -= t
    else:
        memory2 -= t
    t += 1
```

循环终止的保证：每轮至少扣掉 `t` 位，两条内存总和单调下降，且 `t` 单调上升，最多约 `sqrt(2 * (memory1 + memory2))` 轮就会双双不足。

## 复杂度
时间：O(sqrt(memory1 + memory2))，秒数 t 贡献，上界约 9.3 万轮。
空间：O(1)，只用了 `t` 和两个入参本身。

## 易错点
- 输入 `memory1 = 2, memory2 = 2` → 若平局时扣 memory2，会得到 `[3,0,1]` 而非 `[3,1,0]`。正确做法是判断条件写 `memory1 >= memory2`，把等号归给第一条。
- 输入 `memory1 = 0, memory2 = 0` → 若先扣再判，会误扣成负数并多跑一轮。正确做法是每轮开头先判 `memory1 < t and memory2 < t`，t=1 时立刻返回 `[1,0,0]`。

## 如果面试官追问
问：内存上限提到 10^18 还能循环吗？
答：不能，秒数是 O(sqrt(S))，10^18 要 10^9 轮；改成对每条内存解二次方程求它能撑到第几秒，再取较小者。
