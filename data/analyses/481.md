## 一句话思路
用双指针边生成 s 边统计：指针 i 读「组长度」，指针 j 写「字符」，交替写入 1 和 2。

## 怎么做
1. 初始化 `s = [1, 2, 2]`，`i = 2`（读组长度）、`j = 3`（写新字符），`ones = 2`（前 3 位里 1 的个数），当前要写的字符 `cur = 1`。
2. 循环条件 `j < n`：取 `cnt = s[i]`，把 `cur` 连续追加 `cnt` 次，每追加一次 `j += 1`，若 `cur == 1` 则 `ones += 1`；追加时一旦 `j == n` 立即停。
3. 每轮结束 `i += 1`，`cur = 3 - cur`（1↔2 翻转）。
4. 返回 `ones`。

以 `n = 6` 为例：`s = [1,2,2]`，`i=2` 读到 `s[2]=2`，`cur=1`，追加两个 1 → `s=[1,2,2,1,1]`，`j=5`，`ones=4`；翻转 `cur=2`，`i=3` 读到 `s[3]=1`，追加一个 2 → `s=[1,2,2,1,1,2]`，`j=6` 停。前 6 位 `122112` 中 1 的个数是 3（`ones` 初值 2 只覆盖前 3 位，第 4、5 位各加 1 得 4，但第 6 位是 2 不加，最终截断到 n=6 时正确值为 3——所以更稳的写法是生成完再 `s[:n].count(1)`，或把 `ones` 只在 `j <= n` 时累加）。

```python
s = [1, 2, 2]
i = 2
cur = 1
while len(s) < n:
    cnt = s[i]
    s.extend([cur] * cnt)
    i += 1
    cur = 3 - cur
return s[:n].count(1)
```

关键中间值：`n=6` 时循环结束 `s = [1,2,2,1,1,2]`，`s[:6].count(1) == 3`。

## 复杂度
时间 O(n)：`i` 和 `len(s)` 都单调增长到 n，每个位置只写一次。
空间 O(n)：`s` 列表最多存 n 个元素，无其他辅助结构。

## 易错点
- `n = 1` 或 `n = 2`：若循环条件写成 `while len(s) <= n` 会多生成一位，`s[:n]` 虽能截断但 `i` 可能越界读 `s[i]`；正确做法是 `while len(s) < n`，且初始 `s` 已含 3 位，`n <= 3` 直接返回。
- 用 `ones` 边生成边累加时，最后一组可能被 `n` 截断：如 `n = 5`，第 3 组 `cnt=2` 只该写 1 个 1 就停，若整组写完再判断会多算一个 1；正确做法是生成后 `s[:n].count(1)`，或追加时逐位检查 `len(s) < n`。

## 如果面试官追问
问：n 扩大到 10^7 怎么办？答：仍 O(n) 但内存吃紧，可只保留 `s` 的前若干位并用滚动计数，因为读指针 `i` 永远落后写指针，实际只需存到约 `n/2` 位即可。
