## 一句话思路
按位定数：第 i 位由 `(k-1) // (n-i-1)!` 选出候选数字，再用余数继续定位下一位。

## 怎么做
1. 维护候选列表 `nums = [1..n]` 和从 0 开始的序号 `k -= 1`。
2. 第 i 位（剩余 `m = n-i` 个数字）每个前缀固定时后面有 `(m-1)!` 种排列，块大小 `block = (m-1)!`。
3. 该位取 `nums[k // block]`，然后 `k %= block`，从 `nums` 中删掉它。
4. 重复 n 次，拼成字符串返回。

以 `n=4, k=9` 为例：先 `k=8`，`m=4` 时 `block=3!=6`，`8//6=1` 取 `nums[1]=2`，`k=8%6=2`；`m=3` 时 `block=2`，`2//2=1` 取 `nums[1]=3`，`k=0`；`m=2` 时 `block=1`，取 `nums[0]=1`，`k=0`；最后剩 `4`，得 `"2314"`。

```python
nums = list(range(1, n + 1))
fact = [1] * (n + 1)
for i in range(1, n + 1):
    fact[i] = fact[i - 1] * i
k -= 1
res = []
for m in range(n, 0, -1):
    block = fact[m - 1]
    idx = k // block
    res.append(str(nums.pop(idx)))
    k %= block
return "".join(res)
```

关键中间值：`n=4, k=9` 时 `fact=[1,1,2,6,24]`，第一轮 `idx=1`、`k=2`，第二轮 `idx=1`、`k=0`，之后 `idx` 恒为 0。

## 复杂度
时间 O(n²)：n 轮，每轮 `nums.pop(idx)` 是 O(n) 搬移。
空间 O(n)：`fact` 数组和 `nums` 列表各 n 个元素。

## 易错点
- `k` 是 1-based，直接 `k // block` 会在 `n=3, k=3` 时算出 `idx=1` 得 `"132"`；必须先 `k -= 1` 再整除，才能得到 `"213"`。
- `n=1, k=1` 时若循环写成 `range(n-1)` 只处理 n-1 位，会漏掉最后一位返回 `""`；循环必须跑满 n 次，最后一位 `block=fact[0]=1` 自然取到唯一剩余数字。

## 如果面试官追问
若 n 很大（如 n=10^5）但 k 很小，怎么优化？答：只需定位前几位，剩余数字按升序直接拼接，因为 `k` 小意味着前缀块序号多为 0。
