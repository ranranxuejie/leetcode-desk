## 一句话思路
答案只由两个集合的大小和交集大小决定：先各保留一半，交集中的元素能多留就多留。

## 怎么做
1. 设 `a = len(set(nums1))`，`b = len(set(nums2))`，`c = len(set(nums1) & set(nums2))`，`half = n // 2`。
2. 只看 nums1：它最多能贡献 `min(a, half)` 个不同值；nums2 同理 `min(b, half)`。
3. 交集里的 `c` 个值若两边都保留，会重复计数，故答案 = `min(a, half) + min(b, half) - max(0, min(a, half) + min(b, half) - (a + b - c))`，等价于 `min(a + b - c, min(a, half) + min(b, half))`。
4. 用示例 2 验证：`a=6, b=3, c=2, half=3`，`min(6,3)+min(3,3)=6`，`a+b-c=7`，取小得 5，与输出一致。

```python
a = len(set(nums1))
b = len(set(nums2))
c = len(set(nums1) & set(nums2))
half = len(nums1) // 2
return min(a + b - c, min(a, half) + min(b, half))
```

关键中间值：示例 2 中 `a=6, b=3, c=2`，`min(a,half)=3`、`min(b,half)=3`，上限 6 被并集大小 7 兜住，最终 5。

## 复杂度
时间：O(n)，两次建集合各扫一遍数组，交集再扫较小集合。
空间：O(n)，两个 set 各存至多 n 个不同值。

## 易错点
- 输入 `nums1=[1,2,1,2], nums2=[1,1,1,1]`：若直接返回 `a+b-c=2` 看似对，但换成 `nums1=[1,2,3,4], nums2=[5,6,7,8]` 会得 8，超过 `half*2=4` 的上限。正确做法是取 `min(a+b-c, min(a,half)+min(b,half))`。
- 输入 `nums1=[1,1,1,1], nums2=[1,1,1,1]`：若忘记 `half` 截断，`min(a,half)=1` 但误用 `a=1` 直接加，得 1 尚可；真正翻车在 `nums1` 全同、`nums2` 全异时，如 `nums1=[1,1,1,1], nums2=[2,3,4,5]`，`a=1,b=4,c=0,half=2`，正确 3，若漏掉 `min(a,half)` 写成 `a+min(b,half)=3` 恰好对，但 `nums1=[1,1,1,1], nums2=[1,2,3,4]` 时 `a=1,b=4,c=1`，漏截断会得 4，正确 3。

## 如果面试官追问
问：若要求输出具体保留哪些元素？答：先按上述公式定下保留个数，再从交集中优先保留 `min(c, half)` 个，剩余名额从各自独有元素补足。
