## 一句话思路
按公共值把两条数组切成若干段，每段取两数组段和较大者累加，双指针一次扫描即可。

## 怎么做
1. 双指针 `i`、`j` 同步扫描，维护 `sum1`、`sum2` 分别记录「上一个公共值之后」两数组各自的累加和。
2. 遇到 `nums1[i] == nums2[j]` 时，把 `max(sum1, sum2) + 该公共值` 累进 `ans`，两个 sum 清零，`i`、`j` 同时后移。
3. 否则谁小谁前进，并把该值加进对应的 sum。
4. 扫描结束后，把剩余段的 `max(sum1, sum2)` 再累加一次。

以示例 1 为例：走到公共值 4 时 `sum1 = 2+4 = 6`、`sum2 = 4`，取 6 进 `ans`；到公共值 8 时 `sum1 = 5+8 = 13`、`sum2 = 6+8 = 14`，取 14，`ans = 6+14 = 20`；尾部 `sum1 = 10`、`sum2 = 9`，取 10，最终 `ans = 30`。

```python
i = j = 0
sum1 = sum2 = ans = 0
while i < len(nums1) or j < len(nums2):
    if i < len(nums1) and j < len(nums2) and nums1[i] == nums2[j]:
        ans += max(sum1, sum2) + nums1[i]
        sum1 = sum2 = 0
        i += 1; j += 1
    elif j == len(nums2) or (i < len(nums1) and nums1[i] < nums2[j]):
        sum1 += nums1[i]; i += 1
    else:
        sum2 += nums2[j]; j += 1
ans += max(sum1, sum2)
return ans % (10**9 + 7)
```

## 复杂度
时间：O(m + n)，`i`、`j` 各单调前进一次，m、n 为两数组长度。
空间：O(1)，只开了 `i`、`j`、`sum1`、`sum2`、`ans` 五个变量。

## 易错点
- 示例 3 这类无公共值的输入 → 若忘记循环后补 `ans += max(sum1, sum2)`，会返回 0 而非 40 → 收尾必须再取一次两段和的较大者。
- 公共值本身 → 若在 `max(sum1, sum2)` 之外又单独加一次 `nums1[i]`，或把它留在 sum 里重复统计，示例 1 的 4 会被算两次 → 公共值只在切换时加一次，且加完立刻把两个 sum 清零。

## 如果面试官追问
要求输出具体路径而非和？答：在每次切换处记录选了哪条数组，回溯拼接各段即可，时间空间不变。
