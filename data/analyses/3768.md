## 一句话思路
用树状数组维护窗口内元素，滑动时增量更新逆序对数，取所有窗口最小值。

## 怎么做
1. 离散化 `nums`，把值域压到 `1..m`，因为 `nums[i]` 可达 `10^9` 而树状数组下标必须连续。
2. 先对前 `k` 个元素逐个插入树状数组，插入 `nums[i]` 时累加「已插入且比它大的个数」= `i - query(rank)`，得到初始窗口逆序对数。
3. 窗口右移一位：删掉左端 `nums[l]`，它贡献的逆序对是「窗口内比它小的个数」= `query(rank-1)`；加入右端 `nums[r]`，它新增的逆序对是「窗口内比它大的个数」= `k - query(rank)`（此时窗口已有 `k` 个元素，含新元素自身）。
4. 每步更新后与答案取 `min`。

以 `nums=[3,1,2,5,4], k=3` 为例：初始窗口 `[3,1,2]`，插入 3 得 0，插入 1 得 1，插入 2 得 1，共 `cnt=2`。右移：删 3 减 `query(rank3-1)=0`，加 5 增 `3-query(rank5)=3-2=1`，`cnt=3`？注意删 3 时窗口内比 3 小的只有 1、2 两个，实际 `query(rank3-1)=2`，故 `cnt=2-2+1=1`，对应 `[1,2,5]` 应为 0——这里 `k - query(rank5)` 中 `query` 已含 5 自身，应为 `k-1-query(rank5-1)`。修正：加元素新增逆序对 = `(k-1) - query(rank-1)`。

```python
def add(i, v):
    while i <= m:
        tree[i] += v; i += i & -i

def query(i):
    s = 0
    while i > 0:
        s += tree[i]; i -= i & -i
    return s

# 初始窗口
cnt = 0
for i in range(k):
    r = rank[i]
    cnt += i - query(r)   # 已插入中比它大的
    add(r, 1)
ans = cnt
for r in range(k, n):
    l = r - k
    cnt -= query(rank[l] - 1)          # 左端贡献：比它小的
    cnt += (k - 1) - query(rank[r] - 1)  # 右端新增：比它大的
    add(rank[l], -1); add(rank[r], 1)
    ans = min(ans, cnt)
```

## 复杂度
时间：`O(n log n)`，`n` 次插入/查询，每次 `log m`，`m` 为去重后值域。
空间：`O(n)`，树状数组 `tree` 与离散化数组 `rank` 各占 `O(n)`。

## 易错点
- `k=1` 时窗口无逆序对，但若按「加元素新增 `(k-1)-query`」算，`k-1=0` 恒为 0，初始 `cnt` 也为 0，答案 0 正确；坑在删元素时 `query(rank[l]-1)` 对单元素窗口恒 0，不会出错，但若把 `k-1` 写成 `k` 就会在 `k=1` 时算出负数。
- 重复元素：`nums=[2,2,1], k=2`，插入第二个 2 时 `query(rank)` 已含第一个 2，`i-query` 得 0，正确不计逆序对；若用 `i-query(rank-1)` 会把相等元素误算成逆序对。

## 如果面试官追问
若要求返回取得最小逆序对的窗口起始下标？答：在 `ans = min(ans, cnt)` 处同步记录 `r-k+1`，相等时取更早的即可。
