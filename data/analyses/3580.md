## 一句话思路
用窗口函数按员工分区、按日期排序取最近 3 条评分，再判断这 3 条是否严格递增。

## 怎么做
1. 用 `ROW_NUMBER() OVER (PARTITION BY employee_id ORDER BY review_date DESC)` 给每位员工的评估倒序编号，`rn <= 3` 即最近三次。
2. 把这三行聚合成一行：`MAX(CASE WHEN rn=1 THEN rating END)` 是最后一次评分，`rn=3` 是最早一次，`rn=2` 居中。
3. 过滤条件写成 `last > mid AND mid > first`，进步分数 `last - first`。
4. 与 `employees` 连接取 `name`，按 `improvement_score DESC, name ASC` 排序。

以 Bob Smith（employee_id=2）为例：倒序编号后 rn=1 是 2023-11-01 的 5，rn=2 是 2023-08-01 的 4，rn=3 是 2023-05-01 的 2；`5 > 4 and 4 > 2` 成立，分数 `5 - 2 = 3`。而 David Wilson 三次都是 4，`4 > 4` 为假被剔除。

```python
# 关键聚合片段（伪 SQL 表达，实际用 pandas 等价实现）
# rn=1 最新, rn=3 最早
last  = max(r for r, k in zip(ratings, rn) if k == 1)
mid   = max(r for r, k in zip(ratings, rn) if k == 2)
first = max(r for r, k in zip(ratings, rn) if k == 3)
if last > mid > first:
    score = last - first
```

若用 pandas：先 `sort_values(['employee_id','review_date'], ascending=[True,False])`，`groupby('employee_id').head(3)`，再 `groupby` 取 `first/middle/last` 三列比较。

## 复杂度
时间：O(m log m)，m 为 performance_reviews 行数，排序主导。
空间：O(m)，窗口编号与聚合结果各占一份。

## 易错点
- 排序方向写反：若按 `review_date ASC` 取前 3 条，Alice 会拿到 2,3,4 而非 3,4,5，分数算成 2 但递增判断对象错了；必须 `DESC` 取最近三次。
- 用 `>=` 判递增：David Wilson 的 4,4,4 会被误判通过并输出分数 0；必须严格 `>`，且 `rn=2` 的中间值不能省。

## 如果面试官追问
问：若要求「最近连续 k 次」而非固定 3 次？答：把 `rn <= 3` 换成 `rn <= k`，递增判断改为对窗口内 `rating` 做 `diff` 全为正。
