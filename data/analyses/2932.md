## 一句话思路
n≤50 且值≤100，直接双重循环枚举所有 (x, y) 判 `abs(x-y) <= min(x,y)` 取最大异或即可。

## 怎么做
1. 把 `nums` 排序，这样对每个 `x`，满足条件的 `y` 只落在 `[x, 2x]` 区间内。
2. 外层枚举 `x = nums[i]`，内层从 `j = i` 开始枚举 `y = nums[j]`，一旦 `nums[j] > 2*x` 就 `break`。
3. 对每个合法对更新 `ans = max(ans, x ^ y)`，注意 `j` 从 `i` 开始以覆盖 `(x, x)` 自身配对。

以 `nums = [1,2,3,4,5]` 为例：排序后取 `x = 3`，内层 `y` 依次是 3、4、5，`2*x = 6` 全部合法；`3 ^ 4 = 7` 刷新 `ans`，`3 ^ 5 = 6` 不超。取 `x = 4` 时 `y` 只到 5（`4^5=1`），`x = 5` 时 `y` 只有 5（`5^5=0`），最终 `ans = 7`。

```python
nums.sort()
ans = 0
for i, x in enumerate(nums):
    for j in range(i, len(nums)):
        y = nums[j]
        if y > 2 * x:
            break
        ans = max(ans, x ^ y)
```

关键点：`|x-y| <= min(x,y)` 等价于 `y <= 2x`（设 `y >= x`），所以排序后内层可以提前 `break`，不必写 `abs`。

## 复杂度
时间：O(n²)，排序 O(n log n) 被双重循环主导，内层 break 只剪常数。
空间：O(1) 额外，排序原地（Python 的 `sort` 用 O(n) 临时空间）。

## 易错点
- `nums = [10,100]` → 若内层从 `j = i+1` 开始，会漏掉 `(10,10)`、`(100,100)` 这两个自身配对，答案仍是 0 但逻辑错；正确做法是 `j` 从 `i` 起，因为题目允许同一整数选两次。
- `nums = [5,6,25,30]` → 若只判 `abs(x-y) <= x` 而不先保证 `y >= x`，对 `(25,30)` 判成 `5 <= 25` 通过没问题，但对 `(30,25)` 这种逆序会误判；正确做法是排序后固定 `x <= y`，条件简化为 `y - x <= x` 即 `y <= 2*x`。

## 如果面试官追问
若 n 放大到 5×10⁴、值域到 2³¹，怎么做？答：排序后对每个 x 在 `[x, 2x]` 窗口内用字典树查最大异或，配合双指针维护窗口，O(n log V)。
