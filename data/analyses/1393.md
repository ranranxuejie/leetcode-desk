## 一句话思路
按 `stock_name` 分组，把 `Sell` 的 `price` 记正、`Buy` 的 `price` 记负，求和即资本损益。

## 怎么做
1. 用 `CASE WHEN operation = 'Sell' THEN price ELSE -price END` 把每行转成带符号金额。
2. 按 `stock_name` 分组对带符号金额求 `SUM`，别名 `capital_gain_loss`。
3. 用 `GROUP BY stock_name` 输出，顺序任意。

以 Corona Masks 为例，带符号序列是 `-10, +1010, -1000, +500, -1000, +10000`，求和 `9500`，与示例一致；Leetcode 是 `-1000 + 9000 = 8000`。

```python
# 思路等价写法（pandas）
df["signed"] = df["price"].where(df["operation"] == "Sell", -df["price"])
res = df.groupby("stock_name", as_index=False)["signed"].sum()
res = res.rename(columns={"signed": "capital_gain_loss"})
```

SQL 版本核心就一行：

```sql
SELECT stock_name,
       SUM(CASE WHEN operation = 'Sell' THEN price ELSE -price END) AS capital_gain_loss
FROM Stocks
GROUP BY stock_name;
```

关键点：不需要按 `operation_day` 排序配对，因为题面保证买卖成对且每笔卖出都有对应买入，符号求和天然把每对 `Sell - Buy` 累加。

## 复杂度
时间 O(n)：扫一遍 Stocks 的 n 行做分组求和。
空间 O(k)：k 为不同 `stock_name` 个数，即分组哈希表大小。

## 易错点
- 把 `Buy` 记成正、`Sell` 记成负 → Corona Masks 会算成 `-9500`，符号全反；正确是 `Sell` 正、`Buy` 负。
- 试图按 `operation_day` 排序后相邻配对相减 → Corona Masks 第 4 天买、第 5 天卖、第 6 天又买，若只取首尾会漏掉中间一笔，得到 `10000-10=9990` 而非 `9500`；正确做法是逐行带符号求和，不依赖顺序。

## 如果面试官追问
问：若同一股票同一天既有买又有卖怎么办？
答：主键是 `(stock_name, operation_day)`，同一天只能有一条记录，不会冲突；若放开约束，需按时间排序后用栈配对，不能直接求和。
