## 一句话思路
按利润降序取前 k 个作基准，再用堆把「重复类别的低利润项」换成「新类别项」，边换边更新 `total + d*d`。

## 怎么做
1. 把 `items` 按 `profit` 降序排序，取前 k 个，累加 `total`，用 `set` 记类别数 `d`。
2. 前 k 个里同类别只保留利润最高的那个，其余进 `dup` 最小堆（存利润）。
3. 从第 k 个往后扫，遇到 `category` 不在 `set` 里的项，就弹出 `dup` 堆顶换掉它：`total += profit - dup.pop()`，`d += 1`，更新答案。
4. 堆空或扫完即停，返回历史最大值。

以示例 2 `items = [[3,1],[3,1],[2,2],[5,3]], k = 3` 为例：排序后前 3 个是 `[5,3],[3,1],[3,1]`，`total = 11`，`d = 2`（类别 3、1），第二个 `[3,1]` 进 `dup`。扫到 `[2,2]` 时类别 2 是新的，弹出 3 换入 2：`total = 10`，`d = 3`，优雅度 `10 + 9 = 19`。

```python
items.sort(key=lambda x: -x[0])
total, seen, dup = 0, set(), []
for p, c in items[:k]:
    total += p
    if c in seen:
        heapq.heappush(dup, p)
    else:
        seen.add(c)
ans = total + len(seen) ** 2
for p, c in items[k:]:
    if c not in seen and dup:
        total += p - heapq.heappop(dup)
        seen.add(c)
        ans = max(ans, total + len(seen) ** 2)
return ans
```

## 复杂度
时间：排序 O(n log n)，堆操作 O(n log k)，合计 O(n log n)。
空间：`seen` 与 `dup` 各 O(k)，排序栈 O(log n)。

## 易错点
- `items = [[1,1],[2,1],[3,1]], k = 3` 时若把前 k 个里所有同类别项都塞进 `dup`，堆里会有 2 个元素却永远换不出去，答案仍对但逻辑混乱；正确做法是每个类别只留利润最高的，其余才入堆。
- 示例 1 若只按利润取 `[10,1],[5,1]` 得 `15 + 1 = 16`，漏掉换类别；正确做法是扫到 `[3,2]` 时用 3 换掉堆里的 5，`total = 13`、`d = 2`，得 17——注意换入项利润可以更低，靠 `d*d` 补回来。

## 如果面试官追问
问：要求输出具体选中的 k 项怎么办？
答：`dup` 里存 `(profit, index)`，替换时记录被换出的下标和新换入的下标，最后按下标集合还原。
