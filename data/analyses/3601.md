## 一句话思路
先按司机和上/下半年分组算每次行程效率的平均值，再用 `HAVING` 卡住两半都有行程，最后相减排序。

## 怎么做
1. 用 `CASE WHEN MONTH(trip_date) <= 6 THEN 'H1' ELSE 'H2' END` 给每条行程打半年标签，效率是 `distance_km / fuel_consumed`。
2. 按 `driver_id` 分组，用 `AVG(CASE WHEN ... THEN distance_km/fuel_consumed END)` 分别算两半均值，`COUNT` 两半行程数用于过滤。
3. 只保留两半 `COUNT` 都 `> 0` 的司机，`JOIN drivers` 取名字。
4. 提升 = `second_half_avg - first_half_avg`，`ROUND(..., 2)`，按提升降序、名字升序。

以 Bob Smith（driver_id=2）为例：上半年两条行程效率 100.0/9.0=11.11、250.0/22.0=11.36，均值 11.24；下半年只有 200.0/15.0=13.33，`COUNT(H2)=1` 仍保留，提升 13.33-11.24=2.09→四舍五入 2.10。

```python
# 关键聚合（伪 SQL 对应 pandas/SQL 均可）
df["half"] = df["trip_date"].dt.month.le(6).map({True: "H1", False: "H2"})
df["eff"] = df["distance_km"] / df["fuel_consumed"]
g = df.groupby(["driver_id", "half"])["eff"].agg(["mean", "count"]).unstack()
ok = g[("count", "H1")].gt(0) & g[("count", "H2")].gt(0)
res = g[ok]
res["improve"] = (res[("mean", "H2")] - res[("mean", "H1")]).round(2)
```

## 复杂度
时间 O(n)：n 为 trips 行数，一次分组聚合；drivers 的 JOIN 是 O(m)。
空间 O(d)：d 为有行程的司机数，存两半均值与计数。

## 易错点
- 只有单半年行程的司机（Carol 只有 H1、David 只有 H2）→ 若只按 `driver_id` 分组不检查两半 `COUNT`，会把缺失侧当 0 或 NaN 混进结果 → 必须 `HAVING COUNT(H1)>0 AND COUNT(H2)>0`。
- 先对 `distance_km`、`fuel_consumed` 各自求平均再相除 → 得到的是「总距离/总油量」而非「每次效率的平均」，Bob 会算成 350/31=11.29 而非 11.24 → 必须先逐行算 `distance_km/fuel_consumed` 再 `AVG`。

## 如果面试官追问
问：若要求「提升严格大于 0 才输出」怎么改？答：在 `HAVING` 或外层加 `second_half_avg > first_half_avg`，注意用未舍入的原始均值比较，避免 0.004 被舍成 0.00 误判。
