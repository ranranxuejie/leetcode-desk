## 一句话思路
按 x 分组存 y 集合，枚举两列 x1<x2 求交集，取最小 (x2-x1)*min(Δy)。

## 怎么做
1. 用字典 `cols` 把每个 x 映射到它所有 y 的集合，同时记下排序后的 x 列表 `xs`。
2. 双重循环枚举 `xs` 中每一对 x1 < x2。
3. 对每对列求 `cols[x1] & cols[x2]`，交集大小 < 2 就跳过。
4. 交集排序后取相邻差的最小值 `dy`，用 `(x2-x1)*dy` 更新答案。

以示例 2 为例：`cols = {1:{1,3}, 3:{1,3}, 4:{1,3}}`。枚举 (1,3) 时交集 `{1,3}`，`dy = 3-1 = 2`，面积 `(3-1)*2 = 4`；枚举 (3,4) 时交集同样 `{1,3}`，`dy = 2`，面积 `(4-3)*2 = 2`，答案更新为 2。

```python
cols = {}
for x, y in points:
    cols.setdefault(x, set()).add(y)
xs = sorted(cols)
best = float('inf')
for i in range(len(xs)):
    for j in range(i + 1, len(xs)):
        x1, x2 = xs[i], xs[j]
        if (x2 - x1) * 1 >= best:      # 宽度已不小于当前最优，剪枝
            continue
        common = sorted(cols[x1] & cols[x2])
        for k in range(1, len(common)):
            best = min(best, (x2 - x1) * (common[k] - common[k - 1]))
return 0 if best == float('inf') else best
```

## 复杂度
时间：O(n²) 枚举列对，每对交集与排序最坏 O(n log n)，n 为点数。
空间：O(n) 存 `cols` 的 y 集合与 `xs` 列表。

## 易错点
- 输入 `[[1,1],[1,3],[3,1],[3,3],[2,2]]` → 若只按「两列有 ≥2 个公共 y」就取首尾 y 差，会把 `[2,2]` 这类孤立点误当矩形边 → 必须对交集排序后取**相邻** y 差的最小值，本例 `{1,3}` 得 dy=2，面积 4。
- 输入 `[[1,1],[2,2],[3,3]]` → 若忘了交集大小检查，`cols[1]&cols[3]` 为空集，`common[1]` 直接 IndexError → 先判 `len(common) < 2` 再进内层循环，最后无矩形时返回 0 而非 `inf`。

## 如果面试官追问
若要求输出矩形本身而非面积？答：在更新 `best` 时同步记录 `(x1, x2, common[k-1], common[k])` 四个值即可，逻辑不变。
