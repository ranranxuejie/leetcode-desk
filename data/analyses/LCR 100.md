## 一句话思路
自底向上原地累加，`triangle[i][j] += min(下一行 j、j+1)`，因为每个格子只被上方两个格子依赖，倒着算就不用处理边界。

## 怎么做
1. 从倒数第二行 `i = len(triangle)-2` 开始往上遍历，最后一行不动。
2. 对第 `i` 行每个下标 `j`，把 `triangle[i][j]` 加上 `min(triangle[i+1][j], triangle[i+1][j+1])`。
3. 遍历完 `triangle[0][0]` 就是答案。

以示例 1 为例，处理 `i=2`（行 `[6,5,7]`）时：`j=0` 取 `min(4,1)=1`，`6→7`；`j=1` 取 `min(1,8)=1`，`5→6`；`j=2` 取 `min(8,3)=3`，`7→10`，该行变成 `[7,6,10]`。再处理 `i=1`（`[3,4]`）：`3+min(7,6)=9`，`4+min(6,10)=10`，得 `[9,10]`；最后 `2+min(9,10)=11`。

```python
n = len(triangle)
for i in range(n - 2, -1, -1):
    for j in range(len(triangle[i])):
        triangle[i][j] += min(triangle[i + 1][j], triangle[i + 1][j + 1])
return triangle[0][0]
```

若要求 O(n) 额外空间，只留一行 `dp = triangle[-1][:]`，每层用 `dp[j] = triangle[i][j] + min(dp[j], dp[j+1])` 从右往左覆盖，因为 `dp[j+1]` 必须先于 `dp[j]` 被读。

## 复杂度
时间 O(n²)：三角形共 n(n+1)/2 个格子，每个格子做一次 min。
空间 O(1)：原地改 `triangle`；若用滚动数组则 O(n)。

## 易错点
- 输入 `[[-10]]`（只有一行）→ 若循环写成 `range(n-2, -1, -1)` 且没处理 `n=1`，`range(-1,-1,-1)` 为空、直接返回 `triangle[0][0]` 恰好对，但若误写成 `range(n-1, 0, -1)` 会从最后一行开始加、越界访问 `triangle[i+1]` → 正确做法是起点固定 `n-2`，并确认 `n==1` 时直接返回。
- 滚动数组从左往右更新 → `dp[j]` 已被本层覆盖，`min(dp[j], dp[j+1])` 里 `dp[j]` 是旧值、`dp[j+1]` 也是旧值没问题，但若先更新 `dp[j+1]` 再算 `dp[j]`，`dp[j]` 会读到本层新值 → 必须从右往左（`j` 从 `len(triangle[i])-1` 递减到 0）覆盖。

## 如果面试官追问
问：要输出具体路径而不只是和？
答：另开 `parent[i][j]` 记录选了 `j` 还是 `j+1`，最后从 `triangle[0][0]` 顺着走一遍还原。
