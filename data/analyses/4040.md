## 一句话思路
对每个 nums[i] 枚举它所有可达值（先乘后除），用 0/1 背包 DP 求凑出 sum 的最小总操作数。

## 怎么做
1. 对每个 nums[i]，枚举「乘 k 次再除 j 次」得到的所有值 v 及代价 k+j，k 上限取到 v 超过 sum 即可停（因为子集和不超过 sum，超过 sum 的正数没用）。
2. 用 dp[s] 表示凑出和 s 的最小操作数，初始 dp[0]=0，其余为无穷。
3. 逐个元素做 0/1 背包：对每个可达值 v、代价 c，倒序更新 dp[s] = min(dp[s], dp[s-v]+c)。
4. 答案取 dp[sum]，若仍为无穷返回 -1。

以示例 1 的 nums[0]=5 为例：可达值有 5(0次)、10(1次)、2(1次)、1(2次)、4(2次)……其中 1 的代价是 2（5→2→1）。nums[1]=6 可达 3(1次)。最终 dp[4] 由 1+3 得到，代价 2+1=3。

```python
INF = float('inf')
dp = [INF] * (sum + 1)
dp[0] = 0
for x in nums:
    cand = {}
    v, k = x, 0
    while v <= sum:          # 乘法阶段
        u, j = v, 0
        while u >= 1:        # 除法阶段
            cand[u] = min(cand.get(u, INF), k + j)
            u //= 2
            j += 1
        v *= 2
        k += 1
    for s in range(sum, -1, -1):
        for val, c in cand.items():
            if s >= val and dp[s - val] + c < dp[s]:
                dp[s] = dp[s - val] + c
return -1 if dp[sum] == INF else dp[sum]
```

## 复杂度
时间：O(n · log(sum) · sum)，每个元素约 log(sum) 个可达值，各扫一遍背包。
空间：O(sum)，只有 dp 数组和单个元素的候选字典。

## 易错点
- 乘法阶段不设 `v <= sum` 上限 → 对 nums=[5,6,10]、sum=4 会枚举出 5→10→20… 无限乘下去死循环；正确做法是 v 一旦超过 sum 就停止乘（更大的正数不可能参与凑 sum）。
- 背包内层正序更新 → 同一个元素被重复使用，示例 2 中 2 会被当成可反复取用而算出错误的小代价；必须对 s 倒序遍历，保证每个 nums[i] 只用一次。

## 如果面试官追问
问：sum 放大到 10^9 怎么办？答：DP 数组开不下，需改用 meet-in-the-middle 或按可达值集合做稀疏 DP，只保留 ≤sum 的状态。
