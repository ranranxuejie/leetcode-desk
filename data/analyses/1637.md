## 一句话思路
把所有点的 x 坐标抽出来排序，相邻两个 x 的差就是一块不含点的垂直区域，取最大差。

## 怎么做
1. 只关心 x，`xs = sorted(p[0] for p in points)`，y 坐标全程不参与。
2. 排序后任意两个相邻 x 之间不可能夹着别的点，所以宽度就是 `xs[i+1] - xs[i]`。
3. 扫一遍取最大值即可。

以示例 2 的 `points = [[3,1],[9,0],[1,0],[1,4],[5,3],[8,8]]` 为例：抽出 x 得 `[3,9,1,1,5,8]`，排序后 `xs = [1,1,3,5,8,9]`。相邻差依次是 `0,2,2,3,1`，最大值 3 出现在 `8` 和 `9` 之间，与输出一致。注意 `1` 和 `1` 的差是 0，说明重复 x 不贡献宽度，但也不会干扰最大值。

```python
xs = sorted(p[0] for p in points)
best = 0
for i in range(1, len(xs)):
    best = max(best, xs[i] - xs[i - 1])
return best
```

关键点：区域边界上的点不算在区域内，所以宽度取的是「相邻 x 之差」而不是「差减一」——点落在边界上正好被排除，差值本身就是合法宽度。

## 复杂度
时间：排序 O(n log n)，扫描 O(n)，n 是点数。
空间：排序产生的 `xs` 列表 O(n)，除此之外只用了 `best` 一个变量。

## 易错点
- 输入 `[[1,0],[1,4],[3,1]]` → 若把重复 x 当成非法或去重后错位，会得到错误宽度；正确做法是保留重复值，`xs = [1,1,3]` 时差为 `0,2`，答案 2，重复项自然贡献 0 不影响结果。
- 输入 `[[8,7],[9,9],[7,4],[9,7]]` → 若按 y 排序或对 `points` 整体排序（先比 x 再比 y），`[9,9]` 和 `[9,7]` 的相对顺序会变，但 x 序列仍是 `[7,8,9,9]`，答案 1 不变；真正的坑是误以为要按 y 分组——y 完全无关，只取 `p[0]`。

## 如果面试官追问
问：如果要求返回具体的那个区域（左右边界 x 值）而不只是宽度？
答：扫描时记录 `best` 更新处的 `xs[i-1]` 和 `xs[i]`，返回这对值即可，复杂度不变。
