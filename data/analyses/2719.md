## 一句话思路
用数位 DP 求 `f(num)` = 数位和在 `[min_sum, max_sum]` 内的 `1..num` 个数，答案 `f(num2) - f(num1-1)`。

## 怎么做
1. 把 `num1` 减一得到上界 `num1-1`（字符串大数减法），避免单独处理 `num1` 本身。
2. `f(s)` 从高位到低位枚举，状态 `(i, sum, tight)`：`i` 是当前位，`sum` 是已累计数位和，`tight` 表示前缀是否贴着 `s`。
3. `tight` 为真时当前位上限是 `int(s[i])`，否则是 `9`；`sum` 超过 `max_sum` 直接剪枝返回 0。
4. 枚举完所有位后，返回 `min_sum <= sum <= max_sum`。

以 `num1="1", num2="12", min_sum=1, max_sum=8` 为例：`f("12")` 中，走到 `i=1, sum=1, tight=False` 时，个位可取 0..9，但 `sum+digit<=8` 只允许 0..7，贡献 8 个；`tight=True` 分支个位只能取 2，`sum=3` 合法，再贡献 1 个，共 9。`f("0")` 返回 0，答案 9？不对——`f("12")` 还要算上 `i=0` 取 0 的分支（即 1..9 中个位数），实际 `f("12")=11`，`f("0")=0`，答案 11。

```python
MOD = 10**9 + 7
def f(s):
    n = len(s)
    from functools import lru_cache
    @lru_cache(None)
    def dfs(i, sm, tight):
        if sm > max_sum: return 0
        if i == n: return 1 if sm >= min_sum else 0
        hi = int(s[i]) if tight else 9
        return sum(dfs(i+1, sm+d, tight and d == hi) for d in range(hi+1)) % MOD
    return dfs(0, 0, True)
```

## 复杂度
时间：`O(len(num2) * max_sum * 10)`，`len` 最多 23，`max_sum` 最多 400。
空间：`O(len(num2) * max_sum)` 的 `lru_cache` 表，外加递归栈深度 23。

## 易错点
- `num1="1"` 时直接算 `f(num1)` 再减会漏掉 `num1` 本身；必须先做字符串减一得 `"0"`，`f("0")` 返回 0 才对。
- `max_sum=400` 但 `num2` 只有 2 位时，`sm` 上限远小于 400，若把 `sm` 当维度开 401 的数组会浪费且易越界；用 `lru_cache` 按实际访问的 `sm` 缓存即可。

## 如果面试官追问
问：`num2` 到 `10^22` 但 `max_sum` 只有 400，能否不按位 DP？答：可以，数位和超过 400 的数直接排除，等价于对每个 `sum` 统计组合数，但实现更繁，DP 更稳。
