## 一句话思路
把 k 次乘 2 全砸在同一个数上（左移 k 位），枚举这个数，其余数按位或起来，取最大。

## 怎么做
1. 先算出全体元素的或 `total`，再对每个下标 i 用「去掉 nums[i] 的或」拼上 `nums[i] << k`。
2. 去掉 nums[i] 的或不能每次重算 O(n)，用前缀或 `pre[i]` 与后缀或 `suf[i]` 拼：`pre[i] | suf[i+1]`。
3. 枚举 i，候选值 `(pre[i] | suf[i+1]) | (nums[i] << k)`，取最大。
4. 为什么全给一个数最优：左移 k 位只抬高一个数的高位，分散给多个数时每个只抬几位，高位覆盖不如集中。

以 `nums = [8,1,2], k = 2` 为例：`pre = [0,8,9,11]`，`suf = [11,3,2,0]`。i=0 时 `pre[0] | suf[1] = 0 | 3 = 3`，`8 << 2 = 32`，候选 `3 | 32 = 35`；i=1 时 `8 | 2 = 10`，`1 << 2 = 4`，候选 14；i=2 时 `8 | 1 = 9`，`2 << 2 = 8`，候选 9。最大 35，与示例一致。

```python
n = len(nums)
pre = [0] * (n + 1)
suf = [0] * (n + 1)
for i in range(n):
    pre[i + 1] = pre[i] | nums[i]
for i in range(n - 1, -1, -1):
    suf[i] = suf[i + 1] | nums[i]
ans = 0
for i in range(n):
    rest = pre[i] | suf[i + 1]
    ans = max(ans, rest | (nums[i] << k))
return ans
```

注意 `pre` 长度 n+1、`suf` 长度 n+1，`suf[n]=0`，这样 i=n-1 时 `suf[n]` 不越界。

## 复杂度
时间 O(n)：两遍前缀后缀 + 一遍枚举，k ≤ 15 的左移是常数。
空间 O(n)：pre、suf 各开 n+1 个整数。

## 易错点
1. 输入 `nums = [12,9], k = 1`：若只把 k 次操作平均分给多个数（12→24、9→9），得 `24|9 = 25`，比正确答案 30 小。必须整份 k 给同一个数，枚举 i 时用 `nums[i] << k` 而不是 `nums[i] << (k // n)`。
2. 输入 `nums = [1], k = 15`：若用 `pre[i] | suf[i+1]` 但把 suf 开成 n 长度，i=0 时 `suf[1]` 越界抛 IndexError。正确做法是 pre、suf 都开 n+1，`suf[n] = 0` 兜底。

## 如果面试官追问
问：如果 k 可以分别作用在不同元素上（每次操作选任意数）怎么办？
答：那就不是全给一个数了，得按位从高到低贪心分配，复杂度升到 O(n log max)。
