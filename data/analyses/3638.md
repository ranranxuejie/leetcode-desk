## 一句话思路
从左到右扫描，维护当前段最大值 `mx`；一旦 `weight[i] < mx` 就立刻切一段并清零，贪心最早切分最优。

## 怎么做
1. 初始化 `mx = weight[0]`、`ans = 0`，从下标 1 开始遍历。
2. 若 `weight[i] < mx`，说明以 `i` 结尾的当前段是平衡的，`ans += 1`，并把 `mx` 重置为 `weight[i+1]`（若还有元素），跳过 `i+1` 继续。
3. 否则 `mx = max(mx, weight[i])`，继续扩展当前段。
4. 关键中间值：以 `[2,5,1,4,3]` 为例，`mx` 依次为 2→5，到 `i=2` 时 `1 < 5` 成立，`ans=1`，`mx` 重置为 `weight[3]=4`；`i=4` 时 `3 < 4`，`ans=2`。

```python
mx = weight[0]
ans = 0
i = 1
while i < len(weight):
    if weight[i] < mx:
        ans += 1
        i += 2
        if i < len(weight):
            mx = weight[i - 1]
    else:
        mx = max(mx, weight[i])
        i += 1
```

注意重置时 `mx` 取的是被跳过那个元素 `weight[i-1]`，即新段的首元素。

## 复杂度
时间 O(n)：每个下标最多被访问一次，`i` 单调递增。
空间 O(1)：只开了 `mx`、`ans`、`i` 三个变量。

## 易错点
- 输入 `[4,4]`：若把条件写成 `weight[i] <= mx`，会误判 `4 <= 4` 成立而返回 1；题目要求严格小于，必须用 `<`，正确答案是 0。
- 输入 `[1,2,3]`：若切分后忘记重置 `mx`（仍保留旧段最大值），后续判断会沿用错误基准；正确做法是切分后把 `mx` 设为新段首元素 `weight[i+1]`，本题应返回 0（全程递增无平衡段）。

## 如果面试官追问
问：若要求输出具体切分方案而非数量？
答：在 `ans += 1` 处记录区间 `[start, i]`，切分后更新 `start = i+1`，其余逻辑不变。
