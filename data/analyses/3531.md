## 一句话思路
按行、按列分别求最大最小坐标，建筑被覆盖当且仅当它既不是所在行的 x 极值也不是所在列的 y 极值。

## 怎么做
1. 用两个哈希表 `row`、`col` 记录每行/每列出现的 y（或 x）的最小值和最大值，遍历 `buildings` 一次填完。
2. 再遍历一次 `buildings`，对每个 `[x, y]` 检查 `row[x]` 的 min < y < max 且 `col[y]` 的 min < x < max。
3. 两个条件都成立就 `ans += 1`。

以示例 1 为例：`row[2] = (1, 3)`，`col[2] = (1, 3)`。检查 `[2,2]`：`1 < 2 < 3` 两边都成立，计数 +1；检查 `[1,2]`：`row[1]` 只有 y=2，min == max == 2，不满足严格小于，跳过。最终 `ans = 1`。

```python
row, col = {}, {}
for x, y in buildings:
    if x not in row: row[x] = [y, y]
    else:
        row[x][0] = min(row[x][0], y)
        row[x][1] = max(row[x][1], y)
    if y not in col: col[y] = [x, x]
    else:
        col[y][0] = min(col[y][0], x)
        col[y][1] = max(col[y][1], x)

ans = 0
for x, y in buildings:
    if row[x][0] < y < row[x][1] and col[y][0] < x < col[y][1]:
        ans += 1
```

关键点：只要该行存在 y 更小的建筑和 y 更大的建筑，左右方向就都满足，无需知道具体是哪一个。

## 复杂度
时间：O(m)，m = len(buildings)，两趟线性扫描，哈希表均摊 O(1)。
空间：O(m)，`row` 最多 m 个键、`col` 最多 m 个键，各存两个整数。

## 易错点
1. 用 `<=` 代替 `<`：示例 1 中 `[1,2]` 的 `row[1]` 是 `[2,2]`，若写成 `row[x][0] <= y <= row[x][1]` 会把它误判为被覆盖，答案变成 2。必须严格小于，因为极值建筑在该方向上没有别的建筑。
2. 只按行判断就下结论：示例 2 的 `[1,2]` 在行 1 中 y 是极值（`row[1]=[1,2]`），但列 2 中 x 也是极值（`col[2]=[1,2]`），两个条件都得查；漏掉列判断会把 `[1,2]`、`[2,1]` 之类算进去，输出非 0。

## 如果面试官追问
问：如果 n 很大但 buildings 稀疏，能不能不建哈希表？答：可以，把 buildings 按 x 排序扫一遍求行极值，再按 y 排序扫一遍求列极值，空间降到 O(1) 额外（不计排序），代价是 O(m log m)。
