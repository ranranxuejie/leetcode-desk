## 一句话思路
按字符顺序模拟 A/B 两条赋值式，因为 `s.length ≤ 10`，直接遍历即可。

## 怎么做
1. 初始化 `x, y = 1, 0`，与题面给定初值一致。
2. 遍历 `s` 的每个字符 `c`：`c == 'A'` 时执行 `x = 2 * x + y`，否则执行 `y = 2 * y + x`。
3. 遍历结束后返回 `x + y`。

以 `s = "AB"` 为例：读到 `'A'` 后 `x = 2*1+0 = 2`，`y` 仍为 0；读到 `'B'` 后 `y = 2*0+2 = 2`，`x` 保持 2，返回 `2+2 = 4`。关键中间值是第一次 A 之后的 `(x, y) = (2, 0)`，它决定了 B 里 `2*y+x` 的 `x` 取 2 而不是 1。

```python
x, y = 1, 0
for c in s:
    if c == 'A':
        x = 2 * x + y
    else:
        y = 2 * y + x
return x + y
```

注意两条式子都**先算新值再覆盖**：`x = 2*x + y` 里右边的 `x` 是旧值，Python 单条赋值天然满足，不需要临时变量。

## 复杂度
时间 O(n)，n 为 `s` 长度，每个字符一次常数运算。
空间 O(1)，只开了 `x`、`y` 两个整数。

## 易错点
- `s = ""`（空串）→ 若把循环写成 `for i in range(1, len(s))` 或先处理首字符再循环，会漏算或越界 → 正确做法是直接 `for c in s`，空串不进循环，返回初值 `1+0 = 1`。
- `s = "B"` → 若把 B 分支误写成 `x = 2*y + x`（把 `y` 的更新写给了 `x`），会得到 `x=1, y=0` 返回 1，而正确是 `y = 2*0+1 = 1`，返回 `1+1 = 2` → 正确做法是 A 只改 `x`、B 只改 `y`，赋值目标别串。

## 如果面试官追问
问：若 `s` 长度到 10^5 且要求答案对 `10**9+7` 取模？
答：模拟不变，两条式子每步后对 `x`、`y` 各自取模即可，O(n) 时间不变。
