## 一句话思路
用栈存操作数，遇算符弹出栈顶两个数算完压回，因为后缀表达式保证算符出现时其两个操作数必在栈顶。

## 怎么做
1. 建空栈 `st`，遍历 `tokens` 每个 `t`。
2. `t` 不是算符就 `int(t)` 入栈（注意 `"-11"` 也能被 `int` 正确解析，别用 `t.isdigit()` 判断）。
3. 是算符就弹 `b = st.pop()`、`a = st.pop()`，按 `a op b` 计算后压回。
4. 遍历完 `st[0]` 即答案。

以示例 2 `["4","13","5","/","+"]` 为例：`4`、`13`、`5` 依次入栈得 `st = [4,13,5]`；遇 `/` 弹 `b=5`、`a=13`，算 `13 // 5 = 2` 压回，`st = [4,2]`；遇 `+` 弹 `b=2`、`a=4` 得 `6`。关键中间值就是 `13 // 5` 必须为 `2` 而非 `2.6`。

```python
st = []
for t in tokens:
    if t in {"+", "-", "*", "/"}:
        b = st.pop()
        a = st.pop()
        if t == "+": st.append(a + b)
        elif t == "-": st.append(a - b)
        elif t == "*": st.append(a * b)
        else: st.append(int(a / b))   # 向零截断
    else:
        st.append(int(t))
return st[0]
```

除法这行是重点：Python 的 `a // b` 是向下取整，`-7 // 2 = -4`，而题目要 `-3`。所以用 `int(a / b)`（`int` 对 float 是向零截断），或 `-(-a // b) if a * b < 0 else a // b`。示例 3 里 `6 / -132` 得 `0`，两种写法都对，但负负组合会翻车。

## 复杂度
时间 O(n)：n 为 `tokens` 长度，每个 token 入栈出栈各一次。
空间 O(n)：最坏全为数字时栈存 n 个操作数。

## 易错点
- 输入含负数除法如 `["-7","2","/"]` → 用 `a // b` 得 `-4` → 正确是 `int(a / b)` 得 `-3`，向零截断。
- 输入 `["-11","2","*"]` → 用 `t.isdigit()` 判断数字会把 `"-11"` 当算符 → 应判断 `t in {"+","-","*","/"}` 或 `len(t) > 1 or t.isdigit()`。

## 如果面试官追问
问：若要求支持 `^` 幂运算且右结合怎么办？
答：后缀表达式本身已消歧义，`2 3 ^ 2 ^` 按栈顺序算即可，无需额外处理结合性。
