## 一句话思路
两遍 DFS：先求高度 h，再按深度 d 累加 `nums[i] * (h - d + 1)`，因为权重只依赖 h 和 d。

## 怎么做
1. 用 `parent` 建邻接表 `children`，跳过 `parent[0] == -1`。
2. 第一遍 DFS 从 0 出发，记录最大深度得到 `h`。
3. 第二遍 DFS 带深度参数 `d`，把 `nums[u] * (h - d + 1)` 累加进答案。
4. 以示例 1 为例：`children[0]=[1,2,3]`、`children[2]=[4,5]`；第一遍得 `h=3`；第二遍到节点 4 时 `d=3`，贡献 `4*(3-3+1)=4`，与表中一致。

```python
def dfs_h(u, d):
    nonlocal h
    h = max(h, d)
    for v in children[u]:
        dfs_h(v, d + 1)

def dfs_sum(u, d):
    nonlocal ans
    ans += nums[u] * (h - d + 1)
    for v in children[u]:
        dfs_sum(v, d + 1)

h = 0
dfs_h(0, 1)
ans = 0
dfs_sum(0, 1)
```

## 复杂度
时间：两遍 DFS 各访问 n 个节点，O(n)。
空间：`children` 存 n-1 条边，递归栈最深 h，O(n)。

## 易错点
- 深度从 1 起算：若把根写成 `d=0`，示例 1 根节点贡献会变成 `5*(3-0+1)=20` 而非 15，总和错成 42。DFS 入口必须传 `d=1`。
- 链状输入 `parent=[-1,0,1,2]` 递归深度达 n=10^5，Python 默认递归上限约 1000 会 `RecursionError`。需 `sys.setrecursionlimit(300000)`，或改写成显式栈迭代。

## 如果面试官追问
问：n 扩大到 10^6 且内存受限怎么办？
答：不建邻接表，利用 `parent[i] < i` 的性质按编号顺序递推深度数组，再一遍求和，空间降到 O(n) 单数组。
