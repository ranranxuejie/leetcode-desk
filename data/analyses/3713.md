## 一句话思路
枚举「子串里不同字符数 k」和「每个字符出现次数 c」，用前缀计数哈希表判断是否存在长度 k·c 的平衡子串。

## 怎么做
1. 预处理 `pre[i][ch]`：`s[:i]` 中字符 `ch` 的出现次数，则子串 `s[l:r]` 中 `ch` 的计数为 `pre[r][ch] - pre[l][ch]`。
2. 外层枚举 `k = 1..26`（子串中不同字符个数），内层枚举 `c = 1..n//k`（每个字符的目标次数），目标长度 `L = k*c`。
3. 对每个 `(k, c)`，用哈希表存「前 `i` 个字符的计数向量」的某种编码，扫描 `r`，查 `r-L` 处的向量是否与当前向量逐字符差恰好为 `c`。
4. 更省事的等价写法：固定 `k` 后，把每个字符计数减去「该字符是否出现」的偏移，转成「相对目标 c 的偏差向量」再查表。

以 `s = "abbac"` 为例，`k=2, c=2, L=4`：`r=4` 时 `pre[4] = {a:2,b:2}`，`l=0` 时 `pre[0] = {a:0,b:0}`，差值 `{a:2,b:2}` 全等于 `c=2`，命中，答案 4。

```python
n = len(s)
pre = [[0]*26 for _ in range(n+1)]
for i, ch in enumerate(s):
    pre[i+1] = pre[i][:]
    pre[i+1][ord(ch)-97] += 1
ans = 1
for k in range(1, 27):
    for c in range(1, n//k + 1):
        L = k*c
        seen = {}
        for r in range(L, n+1):
            l = r - L
            key = tuple(pre[r][j] - pre[l][j] for j in range(26))
            if key in seen: ans = max(ans, L); break
            seen[key] = l
```

## 复杂度
时间：`O(26 * n * 26 * 26)` 量级，实际是 `O(k_max * n * 26)`，`n=1000` 可过。
空间：`pre` 表 `O(26n)`，每轮哈希表最多 `O(n)` 个 26 维元组。

## 易错点
- 输入 `"aba"`：若只枚举 `k=1` 会漏掉 `"ab"`（`k=2, c=1`），答案错成 1；必须让 `k` 从 1 枚举到 26，`c` 从 1 起。
- 输入 `"zzabccy"`：若把「不同字符数」当成固定 26 去算 `c`，`c` 会算成 0 或负数导致死循环；正确做法是 `c` 上限取 `n//k`，且 `k` 不能超过 `s` 中实际出现的不同字符数。

## 如果面试官追问
问：`n` 放大到 `10^5` 怎么办？
答：枚举 `k` 的 26 层不变，但内层 `c` 的枚举要改成对每个 `k` 用「计数差向量 + 哈希」一次扫描，复杂度降到 `O(26n)`。
