## 一句话思路
对每个 `words[i]` 用 `split(separator)` 切分，再把非空片段按原顺序追加到结果列表。

## 怎么做
1. 建空列表 `res`，遍历 `words` 中每个字符串 `w`。
2. 对 `w` 调用 `w.split(separator)`，得到片段列表。
3. 遍历片段，`if part:` 才 `res.append(part)`，跳过空串。
4. 返回 `res`。

以示例 2 的 `w = "$easy$"`、`separator = "$"` 为例：`split` 得到 `['', 'easy', '']`，中间变量 `part` 依次取到 `''`、`'easy'`、`''`，只有 `'easy'` 通过 `if part` 判断被追加。

```python
res = []
for w in words:
    for part in w.split(separator):
        if part:
            res.append(part)
return res
```

关键点：`str.split` 在分隔符连续或位于首尾时会产生空串，所以过滤必须放在内层循环，不能只过滤 `words` 元素。

## 复杂度
时间 O(n)，n 为所有 `words[i]` 字符总数，每个字符被扫描常数次。
空间 O(n)，`res` 存放全部非空片段，最坏情况片段总长接近 n。

## 易错点
- 输入 `words = ["|||"]`、`separator = "|"` → 若不过滤空串，会返回 `['', '', '', '']` → 正确做法是内层 `if part:` 判断，返回 `[]`。
- 输入 `words = ["$easy$"]`、`separator = "$"` → 若用 `strip(separator)` 再 `split`，会误删字符串内部合法内容（如 `"a$$b"` 想保留 `a`、`b` 但 `strip` 只处理两端）→ 正确做法是只 `split` 后过滤空串，不做 `strip`。

## 如果面试官追问
若 `separator` 变成多字符字符串（如 `"ab"`）怎么办？答：Python `split` 本身支持多字符分隔符，逻辑不变；若要求手写，则用双指针匹配整段 `separator` 再切。
