## 一句话思路
用 `word.isupper()` / `word.islower()` 判全大写或全小写，否则只允许 `word[0]` 大写且 `word[1:]` 全小写。

## 怎么做
1. 先判 `word.isupper()` 或 `word.islower()`，命中直接返回 `True`。
2. 否则检查首字母：`word[0].isupper()` 为假就返回 `False`。
3. 再判剩余部分 `word[1:].islower()`，为真返回 `True`，否则 `False`。

以 `word = "FlaG"` 为例：`isupper()` 为 `False`（有 `l`、`a`），`islower()` 为 `False`（有 `F`、`G`），首字母 `F` 是大写通过第 2 步，但 `word[1:]` 是 `"laG"`，`"laG".islower()` 为 `False`（`G` 大写），返回 `False`。关键中间值就是 `word[1:] == "laG"` 这一刀。

```python
if word.isupper() or word.islower():
    return True
if not word[0].isupper():
    return False
return word[1:].islower()
```

注意 `word[1:]` 在 `len(word) == 1` 时是空串，`"".islower()` 返回 `False`，但单字符走不到这一步：单字符要么 `isupper` 要么 `islower`，第 1 步已返回。所以不用特判长度。

## 复杂度
时间 O(n)：`isupper`/`islower` 各扫一遍，最多三次扫描，n 为 `len(word)`。
空间 O(1)：`word[1:]` 切片会复制一份，最坏 O(n)，若在意可改 `word[1:].islower()` 为逐字符判断。

## 易错点
- 输入 `"a"` 或 `"A"` → 若先写 `word[0].isupper() and word[1:].islower()` 再兜底，容易漏掉全小写单字符；正确做法是第 1 步先放 `isupper() or islower()`，单字符必被它接住。
- 输入 `"FlaG"` → 若只判 `word[0].isupper()` 就返回 `True`，会把 `"FlaG"` 错判为合法；必须补 `word[1:].islower()`，因为 `"laG"` 里 `G` 大写。
- 输入 `"USA"` → 若先判首字母大写再判 `word[1:].islower()`，`"SA".islower()` 为 `False` 会错判；所以全大写分支必须排在第 2 步之前。

## 如果面试官追问
追问：若允许「首字母小写、其余全大写」这种新规则怎么改？答：加一条 `word[0].islower() and word[1:].isupper()` 分支，其余不变。
