## 一句话思路
每个节点出度为 1，图是「若干棵内向树挂到环上」；先拓扑剥掉树、给环上节点定值，再逆拓扑序把子节点答案 = 父节点答案 + 1 回填。

## 怎么做
1. 统计入度 `indeg`，把入度为 0 的节点入队，做拓扑排序，`order` 记录出队顺序。
2. 拓扑后 `indeg[i] > 0` 的节点就是环上节点；对每个未处理的环，沿 `edges` 走一圈数出环长 `L`，环上每个节点 `ans = L`。
3. 逆序遍历 `order`（即从树靠近环的一端往叶子走），`ans[u] = ans[edges[u]] + 1`。
4. 返回 `ans`。

以 `edges = [1,2,0,0]` 为例：`indeg = [2,1,1,0]`，只有 3 入度为 0，出队后 `indeg[0]` 变 1，队列空，`order = [3]`。剩下 0、1、2 的 `indeg` 都 > 0，是环，环长 `L = 3`，得 `ans[0]=ans[1]=ans[2]=3`。逆序处理 `order`：`ans[3] = ans[edges[3]] + 1 = ans[0] + 1 = 4`。

```python
n = len(edges)
indeg = [0] * n
for v in edges:
    indeg[v] += 1
q = deque(i for i in range(n) if indeg[i] == 0)
order = []
while q:
    u = q.popleft()
    order.append(u)
    v = edges[u]
    indeg[v] -= 1
    if indeg[v] == 0:
        q.append(v)
ans = [0] * n
for i in range(n):
    if indeg[i] > 0:          # 环上未赋值
        cur, L = edges[i], 1
        while cur != i:
            cur = edges[cur]; L += 1
        cur = i
        for _ in range(L):
            ans[cur] = L; indeg[cur] = 0; cur = edges[cur]
for u in reversed(order):
    ans[u] = ans[edges[u]] + 1
```

## 复杂度
时间 O(n)：拓扑每个节点进出队一次，每个环只走一遍，逆序回填一次。
空间 O(n)：`indeg`、`order`、`ans` 三个长度 n 的数组加一个队列。

## 易错点
- 环长统计写成 `while cur != i` 却忘了先 `cur = edges[i]`、`L` 初值取 1：对 `edges=[1,0]` 会数成 0 或死循环，正确是 2。用「先走一步再数」的写法。
- 环上节点赋值后没把 `indeg[cur]` 清零：若图里有多个环（如 `edges=[1,0,3,2]`），第二个环的遍历会重复覆盖或漏判，正确做法是赋完值立刻置 0 当已访问标记。

## 如果面试官追问
问：若要求输出从每个点出发的完整访问序列而不只是计数？
答：在 `ans` 回填时同时存 `nxt` 指针，环上接回环首、树上接父节点，按需展开即可，空间仍是 O(n)。
