## 一句话思路
用 26 位掩码的前缀异或，区间内出现奇数次的字母个数就是掩码的 popcount，判断它的一半是否 ≤ k。

## 怎么做
1. 预处理 `pre[i]`：`s[0..i-1]` 的字母奇偶掩码，`pre[i] = pre[i-1] ^ (1 << (ord(s[i-1]) - 97))`。
2. 区间 `[l, r]` 的掩码 `m = pre[r+1] ^ pre[l]`，`m` 的第 c 位为 1 表示字母 c 在该子串中出现奇数次。
3. 回文最多允许 1 个奇数字母（长度奇数时），其余奇数对必须靠替换消掉，每替换 1 个字符能消掉 2 个奇数字母，所以条件是 `popcount(m) // 2 <= k`。

以 `s = "abcda"`、`queries[3] = [0,3,2]` 为例：`pre[4]` 对应 `"abcd"`，掩码为 `0b1111`，`popcount = 4`，`4 // 2 = 2 <= 2`，返回 `True`；而 `[0,3,1]` 时 `2 > 1`，返回 `False`。

```python
pre = [0] * (len(s) + 1)
for i, ch in enumerate(s):
    pre[i + 1] = pre[i] ^ (1 << (ord(ch) - 97))

ans = []
for l, r, k in queries:
    m = pre[r + 1] ^ pre[l]
    ans.append(m.bit_count() // 2 <= k)
```

`bit_count()` 是 Python 3.8+ 的整数方法，等价于 `bin(m).count('1')`，但更快。

## 复杂度
时间：预处理 O(n)，每个查询 O(1)，共 O(n + q)，n 为 `len(s)`，q 为 `len(queries)`。
空间：`pre` 数组 O(n)，每个元素是 26 位整数，无额外结构。

## 易错点
- 区间掩码写成 `pre[r] ^ pre[l]` → 会漏掉 `s[r]` 这个字符，`[3,3,0]` 会算成空串掩码 0 而误判 `True`；正确是 `pre[r+1] ^ pre[l]`，下标偏移一位。
- 判断条件写成 `popcount(m) <= k` → `[0,3,1]` 的 `popcount = 4`，`4 <= 1` 为 `False` 碰巧对，但 `[0,3,2]` 时 `4 <= 2` 为 `False`，与正确答案 `True` 相反；必须除以 2，因为一次替换消掉一对奇数字母。

## 如果面试官追问
问：如果要求输出具体替换方案而非布尔值？
答：先统计每个奇数字母的位置，两两配对，把每对中一个位置改成另一个的字母，剩余至多一个奇数位改任意字母即可。
