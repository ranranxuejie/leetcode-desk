## 一句话思路
相撞等价于「交换身份」直接穿过，所以把每个机器人按方向算出 d 秒后的落点，排序后前缀和求两两距离。

## 怎么做
1. 把相撞看成两个机器人互换身份继续走：位置集合与「直接穿过」完全一致，因此每个机器人独立算终点 `nums[i] + d`（'R'）或 `nums[i] - d`（'L'）。
2. 把所有终点收集进 `pos` 并排序，因为两两距离之和只依赖位置集合，不依赖谁是谁。
3. 排序后第 i 个点到前面所有点的距离和 = `pos[i] * i - prefix`，累加进答案，再更新 `prefix += pos[i]`。

用示例 1：`nums = [-2,0,2]`，`s = "RLL"`，`d = 3`，终点是 `[-2+3, 0-3, 2-3] = [1,-3,-1]`，排序得 `[-3,-1,1]`。i=1 时贡献 `(-1)*1 - (-3) = 2`，i=2 时贡献 `1*2 - (-4) = 6`，合计 8，与答案一致。

```python
MOD = 10**9 + 7
pos = sorted(x + d if c == 'R' else x - d for x, c in zip(nums, s))
ans = 0
prefix = 0
for i, p in enumerate(pos):
    ans = (ans + p * i - prefix) % MOD
    prefix += p
return ans % MOD
```

注意 `prefix` 不取模（或取模后 `p*i - prefix` 仍要 `% MOD` 修正负数），Python 大整数能扛住 `10^5 * 2*10^9` 量级。

## 复杂度
时间 O(n log n)：排序主导，扫描是 O(n)。
空间 O(n)：`pos` 存 n 个终点，其余是常数。

## 易错点
- 把相撞真的模拟成「反弹」→ 示例 1 里 0 号机器人 1 秒后到 -1 再往左，会算出与「穿过」不同的轨迹 → 记住相撞只交换身份，位置集合等于直接穿过，直接算 `x ± d`。
- 终点可能为负且排序后前缀和出现负数 → 若对 `prefix` 取模，`p * i - prefix` 可能为负，Python 的 `%` 虽返回非负但中间值语义已乱 → 让 `prefix` 保持原值不取模，只在 `ans` 上取模。

## 如果面试官追问
若要求输出每个机器人最终的身份归属（谁走到了哪个位置）？答：按初始坐标排序后，穿过模型的落点排序与身份排序一一对应，用双指针配对即可还原。
