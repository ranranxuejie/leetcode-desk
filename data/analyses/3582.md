## 一句话思路
按空格切词，逐词做「首字母大写、其余小写」的驼峰拼接，最后统一过滤非字母并截到 100 字符。

## 怎么做
1. 用 `caption.split()` 切词，得到 `words`；示例 2 得到 `["can","I","Go","There"]`。
2. 遍历 `words`，下标 0 的词整体 `lower()`，其余词取 `w[0].upper() + w[1:].lower()`。
3. 拼成 `"#" + "".join(...)`；示例 2 此时是 `"#canIGoThere"`，长度 12。
4. 再过滤掉 `#` 之后所有非字母字符，最后 `[:100]` 截断。

关键中间值：示例 1 的 `words` 是 `["Leetcode","daily","streak","achieved"]`，第 2 步后得到 `"leetcode"+"Daily"+"Streak"+"Achieved"`，拼上 `#` 即 `"#leetcodeDailyStreakAchieved"`。

```python
words = caption.split()
parts = [words[0].lower()]
for w in words[1:]:
    parts.append(w[0].upper() + w[1:].lower())
tag = "#" + "".join(parts)
tag = "#" + "".join(c for c in tag[1:] if c.isalpha())
return tag[:100]
```

注意题面说 caption 只含字母和空格，所以第 4 步的过滤在当前约束下是空操作，但按步骤顺序保留它更稳。

## 复杂度
时间 O(n)：n 为 caption 长度，split、拼接、过滤各扫一遍。
空间 O(n)：`words` 列表和 `parts` 各存一份字符，输出 tag 另算。

## 易错点
- 输入 `"can I Go There"` → 若对每个词都做 `w[0].upper()+w[1:]` 而不 `lower()` 剩余部分，`"Go"` 会保留成 `"Go"` 侥幸对，但 `"GO"` 会错成 `"GO"`，正确是 `"Go"`；第一个词必须整体 `lower()`，`"CAN"` 要变 `"can"`。
- 输入示例 3 那个 101 个 `h` 的单词 → 若先截断再拼 `#`，或截断时把 `#` 算进 100 里，会少一个 `h`；正确是先拼出 `"#"+101个h` 再取 `[:100]`，结果 `#` 加 99 个 `h`，共 100 字符。

## 如果面试官追问
问：若 caption 含数字和标点，步骤顺序能换吗？
答：不能，必须先驼峰再过滤，否则 `"a1b"` 切词后 `"1b"` 首字母大写会丢信息，顺序反了结果不同。
