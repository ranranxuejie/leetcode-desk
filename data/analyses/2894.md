## 一句话思路
用总和减去两倍 m 的倍数和，即 `total - 2 * sum_of_multiples`，因为 num1 - num2 = (total - num2) - num2。

## 怎么做
1. 先算 `total = n * (n + 1) // 2`，即 [1, n] 全部整数之和。
2. 算倍数个数 `k = n // m`，则 m 的倍数为 `m, 2m, ..., km`。
3. 倍数和 `num2 = m * k * (k + 1) // 2`。
4. 返回 `total - 2 * num2`。

以 n = 10, m = 3 为例：`total = 55`，`k = 10 // 3 = 3`，`num2 = 3 * 3 * 4 // 2 = 18`，答案 `55 - 36 = 19`，与示例一致。

```python
total = n * (n + 1) // 2
k = n // m
num2 = m * k * (k + 1) // 2
return total - 2 * num2
```

关键点：`num1 = total - num2`，所以 `num1 - num2 = total - 2 * num2`，只需算一次倍数和，不必分别枚举两类数。

## 复杂度
时间：O(1)，只有常数次算术运算，与 n 无关。
空间：O(1)，只用了 total、k、num2 三个整型变量。

## 易错点
- n = 5, m = 6 → 若写成 `k = n // m` 后仍按 `m * k * (k+1) // 2` 算，k = 0 得 num2 = 0，正确；但若误用 `(n // m + 1)` 之类公式会多算一项 6，答案错成 15 - 12 = 3。正确做法是 k 直接取 `n // m`，k = 0 时自然得 0。
- n = 5, m = 1 → 若先算 num1 再减 num2 时把 num1 写成 `total - num2` 却忘了 num2 已含全部数，会得 0 - 15 = -15 正确；但若误判 m = 1 时 num1 应为空而跳过减法，会错成 15。正确做法是统一用 `total - 2 * num2`，m = 1 时 num2 = 15，答案 -15。

## 如果面试官追问
问：若 n 可达 10^9 且要求答案对 10^9+7 取模？答：公式不变，但 `n * (n+1)` 需先取模再乘逆元 2，或先除再模，避免中间值过大。
