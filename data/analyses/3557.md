## 一句话思路
贪心：从左往右扫，一旦当前字符在「已见集合」里出现，就立刻切一段，因为越早切越不亏。

## 怎么做
1. 维护一个 `seen` 集合，记录当前这段里出现过的字符，以及答案 `ans`。
2. 从左到右遍历 `word`，遇到 `word[i]` 已在 `seen` 中，就说明 `word[start..i]` 首尾相同，长度必然 ≥ 4（因为中间至少隔了 3 个不同字符），于是 `ans += 1`，清空 `seen`，从 `i+1` 重新开始。
3. 否则把 `word[i]` 加入 `seen`，继续。

用 `word = "abcdeafdef"` 走一遍：扫到 `a`(下标 0) 入集合，`b c d e` 依次入集合，扫到下标 5 的 `a` 时命中，切出 `"abcdea"`，`ans = 1`，`seen` 清空；接着 `f d e` 入集合，下标 9 的 `f` 命中，切出 `"fdef"`，`ans = 2`。剩余为空，返回 2。

```python
seen = set()
ans = 0
for ch in word:
    if ch in seen:
        ans += 1
        seen.clear()
    else:
        seen.add(ch)
return ans
```

关键点：命中时**不要**把 `ch` 留在新集合里。切完这段后 `ch` 属于上一段，新段从下一个字符开始，所以直接 `clear()`。

## 复杂度
时间 O(n)：每个字符最多被访问一次，`clear()` 摊还 O(1)。
空间 O(1)：`seen` 最多 26 个小写字母。

## 易错点
- 输入 `"aaaa"` → 若写成「命中后保留 `ch` 再继续」，会得到 1 段但边界处理混乱；正确做法是命中即 `clear()`，`"aaaa"` 在下标 3 命中一次，返回 1，与示例 2 的 `"bcdaaaab"` 一致。
- 输入 `"abcdeafdef"` → 若贪心地「找最长的首尾相同段」而不是最早命中就切，会把 `"abcdea"` 和后面的 `fdef` 合并考虑，可能少切一段；正确做法是命中立刻切，因为早切不会减少后续可用字符。

## 如果面试官追问
问：如果要求返回具体的子串列表而不只是数量？
答：在 `ans += 1` 处记录 `word[start:i+1]`，并把 `start` 更新为 `i+1`，其余逻辑不变。
