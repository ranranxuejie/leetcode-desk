## 一句话思路
按列扫描，只要某列出现 `strs[i][j] > strs[i+1][j]` 就删这一列，因为非严格递增只要求相邻行不降。

## 怎么做
1. 外层枚举列下标 `j`，范围是 `range(len(strs[0]))`。
2. 内层枚举相邻行 `i`，比较 `strs[i][j]` 与 `strs[i+1][j]`。
3. 一旦发现前者大于后者，`ans += 1` 并 `break`，这一列不必再看。
4. 全部列扫完返回 `ans`。

以示例 1 `strs = ["cba","daf","ghi"]` 为例，`j = 1` 时：`strs[0][1]='b'`、`strs[1][1]='a'`，`'b' > 'a'` 成立，`ans` 从 0 变 1，直接跳出内层；`j = 0` 的比较是 `'c'<'d'<'g'`，`j = 2` 是 `'a'<'f'<'i'`，都不触发。

```python
ans = 0
for j in range(len(strs[0])):
    for i in range(len(strs) - 1):
        if strs[i][j] > strs[i + 1][j]:
            ans += 1
            break
return ans
```

注意 `break` 只跳出内层 `for i`，外层 `j` 继续，这正是「一列只计一次」的关键。

## 复杂度
时间 O(n·m)，n 是行数、m 是列宽，最坏每列都要比完 n-1 对相邻字符。
空间 O(1)，只用了 `ans`、`j`、`i` 三个整数，没有额外数组。

## 易错点
- 输入 `strs = ["a","b"]`（n=2, m=1）→ 若把循环写成 `range(len(strs))` 去索引 `strs[i+1]`，`i=1` 时越界 `IndexError` → 内层必须是 `range(len(strs) - 1)`。
- 输入 `strs = ["zyx","wvu","tsr"]` → 若把比较写成 `>=` 或漏掉 `break`，前者会把相等的列也误删（如 `["ab","ab"]` 的列 0 应保留），后者会把同一列重复计数 → 严格用 `>` 判降序，命中即 `break`。

## 如果面试官追问
问：如果要求返回要删除的列下标列表而不只是个数？
答：把 `ans += 1` 换成 `ans.append(j)`，`break` 逻辑不变，返回列表即可。
