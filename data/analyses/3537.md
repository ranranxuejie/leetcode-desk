## 一句话思路
按「右上→右下→左下→左上」的象限顺序递归，每层给四个象限依次分配连续递增的数值区间。

## 怎么做
1. 设 `size = 2**n`，递归函数 `fill(r, c, size, base)` 表示用 `[base, base+size*size)` 填左上角在 `(r,c)` 的方块。
2. 象限顺序固定为右上、右下、左下、左上，每块大小 `half = size//2`，块内数值个数 `half*half`。
3. 按顺序给四块分配 `base`、`base+q`、`base+2q`、`base+3q`（`q = half*half`），再递归。
4. `size == 1` 时直接写 `grid[r][c] = base`。

以 `N = 2` 为例：`size = 4`，`half = 2`，`q = 4`。四个象限的 `base` 依次是 0、4、8、12，所以右上角填 `[0,4)`、右下角填 `[4,8)`、左下角填 `[8,12)`、左上角填 `[12,16)`。右上角再递归时 `half = 1`，`q = 1`，四个格子依次拿到 0、1、2、3，落位后正是 `[[3,0],[2,1]]`，与示例 3 的右上角一致。

```python
def fill(r, c, size, base):
    if size == 1:
        grid[r][c] = base
        return
    h = size // 2
    q = h * h
    fill(r, c + h, h, base)          # 右上
    fill(r + h, c + h, h, base + q)  # 右下
    fill(r + h, c, h, base + 2 * q)  # 左下
    fill(r, c, h, base + 3 * q)      # 左上

grid = [[0] * (2 ** n) for _ in range(2 ** n)]
fill(0, 0, 2 ** n, 0)
```

## 复杂度
时间：`O(4^N)`，即格子总数 `2^(2N)`，每个格子写一次。
空间：递归深度 `O(N)`，加上输出矩阵 `O(4^N)`。

## 易错点
- 象限顺序写成「左上→右上→右下→左下」→ 数值大小关系反了，`N=1` 会输出 `[[0,1],[2,3]]`，违反「右上 < 右下 < 左下 < 左上」。正确做法是严格按右上、右下、左下、左上分配递增的 `base`。
- `N = 0` 时 `size = 1`，若先算 `half = size//2 = 0` 再递归 → 死循环或越界。正确做法是在函数开头判 `size == 1` 直接写 `grid[0][0] = 0` 返回。

## 如果面试官追问
问：如果要求返回任意一个合法解而非固定解，思路变吗？
答：不变，四个象限的数值区间只要保持递增顺序，块内递归顺序可任意换。
