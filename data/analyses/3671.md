## 一句话思路
按值域从大到小枚举 g，用树状数组统计「以 g 的倍数为元素、严格递增」的子序列数，再容斥减去 GCD 为 2g、3g… 的部分。

## 怎么做
1. 把 nums 按值分组，记 `cnt[v]` 为值 v 出现次数；值域 M = max(nums) ≤ 7×10^4。
2. 从 M 到 1 枚举 g，收集所有 g 的倍数 v（升序），对每个 v 用树状数组查「末尾值 < v 的递增子序列数」`s`，则以 v 结尾的新子序列数为 `(s+1) * cnt[v]`（+1 是单元素 [v]），再把这些贡献按 v 更新回树状数组。
3. 累加得到 `f[g]` = 元素全为 g 的倍数、严格递增的子序列总数（含单元素）。
4. 从大到小做容斥：`exact[g] = f[g] - Σ_{k≥2} exact[k*g]`，答案累加 `g * exact[g]`。

以 `nums=[4,6]` 为例：g=6 时 f[6]=1（[6]）；g=4 时 f[4]=1（[4]）；g=2 时倍数序列 [4,6]，处理 4 得 1，处理 6 时查末尾<6 得 1，贡献 (1+1)*1=2，f[2]=3（[4],[6],[4,6]）。容斥：exact[6]=1，exact[4]=1，exact[2]=3-exact[4]-exact[6]=1，答案 6+4+2=12。

```python
MOD = 10**9 + 7
M = max(nums)
cnt = [0] * (M + 1)
for x in nums: cnt[x] += 1
f = [0] * (M + 1)
for g in range(M, 0, -1):
    bit = [0] * (M // g + 2)   # 下标按 v//g 压缩
    tot = 0
    for v in range(g, M + 1, g):
        if cnt[v] == 0: continue
        i = v // g
        s = 0; j = i - 1
        while j > 0: s += bit[j]; j -= j & -j
        add = (s + 1) * cnt[v] % MOD
        tot = (tot + add) % MOD
        j = i
        while j <= M // g: bit[j] = (bit[j] + add) % MOD; j += j & -j
    f[g] = tot
exact = f[:]
for g in range(M, 0, -1):
    for k in range(2 * g, M + 1, g):
        exact[g] = (exact[g] - exact[k]) % MOD
return sum(g * exact[g] for g in range(1, M + 1)) % MOD
```

## 复杂度
时间：Σ_{g} (M/g)·log(M/g) ≈ M log²M，M 为值域上界。
空间：`cnt`、`f`、`exact` 各 O(M)，每次重建的 `bit` 峰值 O(M)。

## 易错点
- 重复元素：`nums=[2,2]` 时若把两个 2 当不同位置各算一次单元素，f[2] 会得 3 而非 2（[2] 只算一次，但两个 2 不能组成递增对）。正确做法是 `(s+1)*cnt[v]` 一次性乘上出现次数，且树状数组只在处理完 v 后更新，保证同值不互相接续。
- 容斥方向：`nums=[4,6]` 若从小到大做 `exact[g] -= exact[k*g]`，减到 2 时 exact[4]、exact[6] 还没算出来，会得 exact[2]=3，答案变 15。必须从 M 往 1 倒序枚举 g。

## 如果面试官追问
若 nums 长度涨到 10^5 而值域不变？答：值域仍是瓶颈，按值分组后复杂度不变，只需把 `cnt` 统计换成 Counter，重复元素靠 `cnt[v]` 吸收。
