## 一句话思路
以步数为层做 BFS，传送门字母首次被触及时把同字母所有格子零代价入队，每个字母只展开一次。

## 怎么做
1. 预处理：扫一遍 `matrix`，用字典 `pos[ch]` 收集每个大写字母的全部坐标，`'#'` 跳过。
2. BFS 队列存 `(i, j)`，`dist` 二维数组初始 `-1`，`dist[0][0] = 0`；另开 `used = set()` 记录已展开的字母。
3. 出队时先判传送门：若 `matrix[i][j]` 是大写字母且不在 `used`，把它加入 `used`，将 `pos[ch]` 中所有格子按 `dist[i][j]` 入队（传送不计步）。
4. 再向四邻扩展，合法且 `dist == -1` 的格子 `dist = dist[i][j] + 1` 入队；出队到 `(m-1, n-1)` 即返回。

以 `["A..",".A.","..."]` 为例：`(0,0)` 出队时 `dist[0][0]=0`，字母 `'A'` 未用过，`pos['A'] = [(0,0),(1,1)]`，于是 `(1,1)` 以 `dist=0` 入队；它再向右、向下各走一步，`dist[2][2]=2`，与示例一致。

```python
from collections import deque
pos = {}
for i in range(m):
    for j in range(n):
        c = matrix[i][j]
        if c.isalpha():
            pos.setdefault(c, []).append((i, j))
dist = [[-1] * n for _ in range(m)]
dist[0][0] = 0
q, used = deque([(0, 0)]), set()
while q:
    i, j = q.popleft()
    c = matrix[i][j]
    if c.isalpha() and c not in used:
        used.add(c)
        for x, y in pos[c]:
            if dist[x][y] == -1:
                dist[x][y] = dist[i][j]
                q.append((x, y))
    for x, y in ((i+1,j),(i-1,j),(i,j+1),(i,j-1)):
        if 0 <= x < m and 0 <= y < n and matrix[x][y] != '#' and dist[x][y] == -1:
            dist[x][y] = dist[i][j] + 1
            q.append((x, y))
```

## 复杂度
时间 O(m·n)：每个格子入队一次，每个字母的坐标列表只被遍历一次。
空间 O(m·n)：`dist` 二维数组加队列，`pos` 总共存不超过 m·n 个坐标。

## 易错点
- 传送门字母不标记 `used`：`["AA","AA"]` 里 `'A'` 会被反复展开，同字母格子重复入队，队列膨胀甚至死循环；正确做法是出队时先 `used.add(c)` 再展开，保证每个字母只处理一次。
- 传送后忘记 `dist[x][y] == -1` 判重：`(0,0)` 自身就在 `pos['A']` 里，会把起点以 `dist=0` 重新入队；正确做法是入队前统一检查 `dist` 是否为 `-1`，起点已赋值所以被跳过。

## 如果面试官追问
要求输出具体路径而非步数怎么办？答：`dist` 之外再存 `parent` 指针，传送边记成同层零代价边，回溯时跳过传送段即可。
