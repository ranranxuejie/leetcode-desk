## 一句话思路
把「移动+等待」合并成一跳的代价，在网格上做二维 DP，因为到达 (i,j) 的步数奇偶固定，等待成本可提前并入转移。

## 怎么做
1. 定义 `dp[i][j]` 为到达 (i,j) 并完成该格等待后的最小成本，起点 `dp[0][0] = 1 + waitCost[0][0]`。
2. 从 (i,j) 向右/下移动时，进入成本是 `(i+1)*(j+1)`，落点还要再等一秒，所以一跳代价 = 进入成本 + 落点 `waitCost`。
3. 转移：`dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + (i+1)*(j+1) + waitCost[i][j]`，第一行/第一列只有单方向来源。
4. 终点不需要等待，答案取 `dp[m-1][n-1] - waitCost[m-1][n-1]`。

以示例 2 为例：`dp[0][0]=1+3=4`；`dp[1][0]=4+(2*1)+2=8`；`dp[0][1]=4+(1*2)+5=11`；`dp[1][1]=min(8,11)+(2*2)+4=16`，减去终点等待 4 得 12？这里要小心——示例答案是 9，说明终点等待不能简单减，正确做法是终点转移时不加 `waitCost`。

```python
dp = [[0] * n for _ in range(m)]
dp[0][0] = 1
for i in range(m):
    for j in range(n):
        if i == 0 and j == 0:
            continue
        best = 2**63 - 1
        if i > 0:
            best = min(best, dp[i-1][j])
        if j > 0:
            best = min(best, dp[i][j-1])
        dp[i][j] = best + (i+1)*(j+1)
        if i != m-1 or j != n-1:
            dp[i][j] += waitCost[i][j]
```

## 复杂度
时间：O(m*n)，每个格子常数次转移。
空间：O(m*n) 的 dp 表；可滚动到 O(n)。

## 易错点
- 终点 (m-1,n-1) 也加 `waitCost` → 示例 2 会得 13 而非 9 → 终点转移时跳过等待成本。
- 起点 `dp[0][0]` 写成 0 或漏加进入成本 1 → 示例 1 得 2 而非 3 → 起点固定为 `1`，且起点不额外加 `waitCost[0][0]`（题面只要求进入成本）。

## 如果面试官追问
问：m、n 到 10^5 但 m*n ≤ 10^5，空间能再省吗？
答：用一维滚动数组，只保留上一行，空间降到 O(n)。
