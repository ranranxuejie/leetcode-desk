## 一句话思路
用滑动窗口枚举每个「恰好含 k 个 1」的极小区间，再向两侧剥掉多余的 0 取最短，同长取字典序最小。

## 怎么做
1. 先扫一遍数 1 的总数，若 `< k` 直接返回 `""`（示例 3 的 `"000"` 在此出局）。
2. 用左右指针维护窗口，使窗口内 1 的个数恰为 k：右指针每遇到一个 `'1'` 就计数加一，计数到 k 时左指针收缩到窗口最左的 `'1'` 上。
3. 此时窗口 `s[l:r+1]` 首尾都是 `'1'`，是含这 k 个 1 的最短形式；比较长度，等长时用 `s[l:r+1] < ans` 取字典序小者。
4. 左指针跳过这个 `'1'` 继续，让窗口滑向下一个 1。

以 `s = "100011001", k = 3` 为例：右指针走到下标 6（字符 `'1'`）时窗口内 1 数首次到 3，左指针收缩到下标 4，得候选 `s[4:7] = "110"`；继续右移到下标 8，窗口覆盖下标 4..8，收缩左指针到下标 4 仍是 `'1'`，候选 `s[4:9] = "11001"`，长度 5 成为答案。

```python
ans = ""
cnt = left = 0
for right, ch in enumerate(s):
    if ch == '1':
        cnt += 1
    while cnt == k:
        if s[left] == '1':
            cand = s[left:right + 1]
            if not ans or len(cand) < len(ans) or (len(cand) == len(ans) and cand < ans):
                ans = cand
            cnt -= 1
        left += 1
return ans
```

关键在 `while cnt == k` 里：只有 `s[left] == '1'` 时才记录候选并让 `cnt` 减一，否则只是把左侧的 0 剥掉，窗口变短但不改变 1 的个数。

## 复杂度
时间 O(n)：左右指针各单调前进至多 n 步，字符串切片比较最多 O(n) 但总长受 n 约束。
空间 O(n)：只存答案字符串 `ans`，最坏长度 n。

## 易错点
- 输入 `s = "1011", k = 2`：若在 `cnt == k` 时立刻记录 `s[left:right+1]` 而不先剥左侧 0，会得到 `"101"` 这类含多余 0 的候选，长度 3 输给正确答案 `"11"`；必须先 `while s[left] == '0': left += 1` 再记录。
- 输入 `s = "100011001", k = 3`：若只在窗口首次达到 k 时记录一次，会漏掉后面 `"11001"`；必须在 `cnt == k` 的循环里反复记录，每记录一次就 `cnt -= 1` 并 `left += 1`，让窗口继续右滑。

## 如果面试官追问
若 n 放大到 10^5 且要求返回所有最短美丽子串？答：仍用同一滑动窗口，只维护当前最短长度，用一个列表收集等长候选，最后按字典序排序输出。
