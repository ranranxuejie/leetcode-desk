## 一句话思路
枚举行的上下边界压成一维数组，用前缀和 + 有序集合找「不超过 k 的最大子段和」。

## 怎么做
1. 固定上边界 `top`，向下扩展下边界 `bot`，把 `matrix[top..bot]` 按列求和得到一维数组 `col`。
2. 对 `col` 求前缀和 `pre`，问题变成找 `pre[j] - pre[i] <= k` 的最大值，即 `pre[i] >= pre[j] - k`。
3. 用有序集合维护已见过的 `pre[i]`，对每个 `pre[j]` 二分找最小的 `pre[i] >= pre[j] - k`。
4. 用 `pre[j] - pre[i]` 更新答案，把 `pre[j]` 插入集合。

以示例 1 `matrix = [[1,0,1],[0,-2,3]], k = 2` 为例：取 `top=0, bot=1`，`col = [1, -2, 4]`，前缀和 `pre = [0, 1, -1, 3]`。处理 `pre[3]=3` 时，需找 `>= 3-2 = 1` 的最小值，集合中有 `1`，得 `3-1=2`，更新答案为 2。

```python
from sortedcontainers import SortedList
m, n = len(matrix), len(matrix[0])
ans = -2**31
for top in range(m):
    col = [0] * n
    for bot in range(top, m):
        for c in range(n):
            col[c] += matrix[bot][c]
        pre, sl = 0, SortedList([0])
        for x in col:
            pre += x
            idx = sl.bisect_left(pre - k)
            if idx < len(sl):
                ans = max(ans, pre - sl[idx])
            sl.add(pre)
```

## 复杂度
时间：`O(m^2 * n * log n)`，`m^2` 对上下边界，`n log n` 来自每列的二分插入。
空间：`O(n)`，`col` 数组和 `SortedList` 各占 `n`。

## 易错点
- 输入 `matrix = [[2,2,-1]], k = 3`：若只枚举行不枚举列方向，`col` 始终是单行，会漏掉跨列矩形。正确做法是行方向枚举上下边界，列方向用前缀和扫描。
- 集合初始必须含 `0`：若忘记插入 `0`，当整个前缀和 `pre[j] <= k` 时找不到 `pre[i]=0`，会漏掉从第一列开始的矩形。示例 2 中 `pre=[2,4,3]`，`pre[0]=2<=3` 就依赖初始的 `0`。

## 如果面试官追问
问：行数远大于列数怎么办？
答：转置矩阵，让枚举方向落在较少的那一维上，复杂度从 `O(m^2 n log n)` 降为 `O(n^2 m log m)`。
