## 一句话思路
把 sequences 里相邻元素连成有向边做拓扑排序，队列中同时出现 ≥2 个入度 0 的点就说明最短超序列不唯一。

## 怎么做
1. 建图：对每个 `seq` 的相邻对 `(seq[i], seq[i+1])` 加边 `seq[i] -> seq[i+1]`，同时 `indeg[seq[i+1]] += 1`；重复边要跳过，否则入度会虚高。
2. 把所有 `indeg[v] == 0` 的点入队，若队列长度 ≠ 1 直接返回 `False`（起点就不唯一）。
3. 每轮必须恰好弹出 1 个点，把它接到结果序列末尾，再让它的后继入度减 1；减到 0 的入队后若队列长度 > 1，返回 `False`。
4. 走完 n 个点后，把结果序列和 `nums` 逐位比对，全等才返回 `True`。

以示例 1 `nums=[1,2,3], sequences=[[1,2],[1,3]]` 为例：边是 `1->2`、`1->3`，`indeg=[0,1,1]`（下标 1..3）。初始队列只有 `[1]`，弹出 1 后 2 和 3 同时入度归零，队列变成 `[2,3]`，长度 2 → 返回 `False`。这正是「[1,2,3] 和 [1,3,2] 都合法」的图论表现。

```python
from collections import deque
indeg = [0] * (n + 1)
adj = [[] for _ in range(n + 1)]
for seq in sequences:
    for a, b in zip(seq, seq[1:]):
        adj[a].append(b)
        indeg[b] += 1
q = deque(v for v in nums if indeg[v] == 0)
order = []
while q:
    if len(q) > 1:
        return False
    u = q.popleft()
    order.append(u)
    for v in adj[u]:
        indeg[v] -= 1
        if indeg[v] == 0:
            q.append(v)
return order == nums
```

注意 `zip(seq, seq[1:])` 只取相邻对，别写成两重循环枚举所有 `(i, j)`，那会把非相邻元素也连成边，`[1,2,3]` 会多出 `1->3`，入度算错。

## 复杂度
时间 O(n + Σ|sequences[i]|)：建图扫一遍所有相邻对，拓扑排序每个点每条边各访问一次。
空间 O(n + Σ|sequences[i]|)：`adj` 存全部边，`indeg` 和队列各开 n+1。

## 易错点
- `sequences` 里出现重复边（如 `[[1,2],[1,2]]`）→ 若不去重，`indeg[2]` 变成 2，2 永远进不了队列，`order` 长度不足 n，误判 `False`；正确做法是加边前用 `set` 去重，或建图时判断 `b not in adj[a]`。
- `sequences` 只覆盖了部分点（如示例 2 `[[1,2]]`，点 3 孤立）→ 初始队列里 1 和 3 都是入度 0，长度 2 直接返回 `False`，这恰好是对的；但若漏掉「最后比对 `order == nums`」这一步，遇到 `nums=[2,1,3]` 这类顺序不符的输入会误判 `True`。

## 如果面试官追问
问：不要求唯一，只要判断 `nums` 是不是某个最短超序列，怎么改？
答：去掉 `len(q) > 1` 的检查，只保留最后 `order == nums` 的比对即可。
