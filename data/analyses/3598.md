## 一句话思路
先算出原数组每对相邻的 LCP，删掉 i 只影响 i-1 和 i 两对，用前缀/后缀最大值 O(1) 合并。

## 怎么做
1. 令 `p[j] = lcp(words[j], words[j+1])`，j 取 0..n-2，共 n-1 个值。
2. 建 `pre[j] = max(p[0..j])`、`suf[j] = max(p[j..n-2])`，用于跳过被删的那一对。
3. 删 i 后新增一对 `(i-1, i+1)`，其 LCP 记为 `c = lcp(words[i-1], words[i+1])`（i 在两端时无此项）。
4. 答案 = 左侧 `pre[i-2]`、右侧 `suf[i+1]`、新增 `c` 三者取最大，越界当 0。

以 `words = ["jump","run","run","jump","run"]` 为例：`p = [0,3,0,0]`（jump/run 首字母不同为 0，run/run 为 3）。删 i=1 时，左侧 `pre[-1]` 不存在取 0，右侧 `suf[2] = max(p[2],p[3]) = 0`，新增对 `("jump","run")` 的 `c = 0`，故 `answer[1] = 0`；删 i=0 时只剩右侧 `suf[1] = max(3,0,0) = 3`，得 3。

```python
def lcp(a, b):
    k = 0
    while k < len(a) and k < len(b) and a[k] == b[k]:
        k += 1
    return k

n = len(words)
p = [lcp(words[j], words[j+1]) for j in range(n-1)]
pre = [0]*max(n-1, 0)
suf = [0]*max(n-1, 0)
for j in range(n-1):
    pre[j] = max(pre[j-1] if j else 0, p[j])
for j in range(n-2, -1, -1):
    suf[j] = max(suf[j+1] if j+1 < n-1 else 0, p[j])
ans = []
for i in range(n):
    best = 0
    if i >= 2: best = max(best, pre[i-2])
    if i + 1 <= n-2: best = max(best, suf[i+1])
    if 0 < i < n-1: best = max(best, lcp(words[i-1], words[i+1]))
    ans.append(best)
```

## 复杂度
时间 O(L + n)：L 为所有字符串长度总和，只在算 p 和新增对时扫字符。
空间 O(n)：p、pre、suf 三个长度 n-1 的数组，无其他额外结构。

## 易错点
- `n == 1` 时删完数组为空，`p`、`pre`、`suf` 长度都是 0，若写成 `pre = [0]*(n-1)` 再访问 `pre[i-2]` 会越界；正确做法是边界判断 `i >= 2` 和 `i+1 <= n-2` 都先挡住，直接返回 `[0]`。
- 删 i 时新增对是 `(i-1, i+1)` 而不是 `(i-1, i)` 或 `(i, i+1)`，后者是原数组里已被删掉的相邻对；示例 1 删 i=1 若误用 `lcp(words[0], words[1])` 会得 0 碰巧对，但删 i=3 时会漏掉 `("run","run")` 得 0 而非 3。

## 如果面试官追问
若要求输出每个 i 对应的最长公共前缀字符串而非长度？答：把 `max` 换成比较长度后保留对应字符串，新增对直接存 `words[i-1][:c]`，其余逻辑不变。
