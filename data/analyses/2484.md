## 一句话思路
枚举中间字符，用左右两侧同数字的配对计数相乘，累加得答案。

## 怎么做
1. 预处理 `left[i][d]` 和 `right[i][d]`：分别表示 `s[i]` 左侧、右侧数字 `d` 的出现次数。
2. 枚举中间位置 `i`（即回文第 3 位），对每个数字 `d` 计算左右两侧各选一个 `d` 的配对数 `left[i][d] * right[i][d]`。
3. 对每个 `i`，把 10 个数字的配对数两两组合相乘再求和，即 `sum_{a,b} left[i][a]*right[i][a]*left[i][b]*right[i][b]`（`a != b`），加上 `a == b` 时选两个相同数字的组合数。
4. 全部累加后对 `10**9 + 7` 取余。

以 `s = "103301"` 为例，中间位置 `i = 2`（字符 `'3'`），左侧 `left[2] = {1:1, 0:1}`，右侧 `right[2] = {3:1, 0:1, 1:1}`。数字 `0` 的配对数为 `1 * 1 = 1`，数字 `1` 的配对数为 `1 * 1 = 1`，两者组合得 `1 * 1 = 1`，对应子序列 `"10301"`（选左 `1`、左 `0`、中 `3`、右 `0`、右 `1`）。

```python
MOD = 10**9 + 7
n = len(s)
left = [[0]*10 for _ in range(n)]
right = [[0]*10 for _ in range(n)]
for i in range(1, n):
    left[i] = left[i-1][:]
    left[i][int(s[i-1])] += 1
for i in range(n-2, -1, -1):
    right[i] = right[i+1][:]
    right[i][int(s[i+1])] += 1
ans = 0
for i in range(n):
    for a in range(10):
        for b in range(10):
            ans += left[i][a] * right[i][a] * left[i][b] * right[i][b]
            ans %= MOD
```

## 复杂度
时间：O(10² · n)，n 为字符串长度，内层 100 次常数枚举。
空间：O(10 · n)，左右两侧计数表各占 10n。

## 易错点
- `s = "0000000"` → 若只统计 `a != b` 的组合会漏掉全同数字的回文 → 必须包含 `a == b` 的情况，此时 `left[i][0] * right[i][0]` 选两个 `0` 的组合数直接相乘即可。
- `s = "9999900000"` → 若在累加过程中不取余，答案会超出 32 位 → 每步 `ans %= MOD`，不能只在最后取余。

## 如果面试官追问
若要求长度为 7 的回文子序列？答：需枚举两个中间位置，用四维前缀计数或改为枚举外层配对再乘内层方案数，复杂度升至 O(10² · n²)。
