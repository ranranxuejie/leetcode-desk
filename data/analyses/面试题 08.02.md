## 一句话思路
用回溯（DFS）从 (0,0) 向终点搜，搜过的格子标记为障碍，避免重复搜索导致超时。

## 怎么做
1. 先判 `obstacleGrid[0][0] == 1` 或右下角为 1，直接返回 `[]`。
2. 从 (0,0) 出发，按「右、下」顺序尝试，把当前格子加入 `path`。
3. 若到达 `(r-1, c-1)` 返回 `True`，整条 `path` 即为答案。
4. 若两个方向都走不通，把当前格子置 1（记忆化剪枝）并 `path.pop()` 回溯。

以示例 `[[0,0,0],[0,1,0],[0,0,0]]` 为例：从 (0,0) 一路向右到 (0,2)，再向下到 (1,2)、(2,2)，此时 `path = [[0,0],[0,1],[0,2],[1,2],[2,2]]`，长度 5，直接返回。关键中间值是 `path` 的长度与终点坐标相等。

```python
def dfs(i, j):
    if i >= r or j >= c or obstacleGrid[i][j] == 1:
        return False
    path.append([i, j])
    if i == r - 1 and j == c - 1:
        return True
    if dfs(i, j + 1) or dfs(i + 1, j):
        return True
    obstacleGrid[i][j] = 1   # 死路标记，防重复
    path.pop()
    return False
```

注意 `obstacleGrid[i][j] = 1` 是本题的核心剪枝：不标记的话，同一死格子会被从不同方向反复进入，最坏指数级。

## 复杂度
时间：O(r·c)，每个格子最多被访问一次（标记后不再进入）。
空间：O(r+c)，递归栈深度加 `path` 长度，未额外开矩阵。

## 易错点
- 输入 `[[0]]`（1×1 且无障碍）→ 若先判终点再判起点会漏掉，或忘记返回 `[[0,0]]` → 正确做法是起点即终点时直接返回 `[[0,0]]`。
- 输入 `[[0,1],[1,0]]` → 不标记死格子时 DFS 会在 (0,0) 反复尝试两个方向，虽能返回 `[]` 但可能超时 → 正确做法是回溯前把 `obstacleGrid[i][j]` 置 1。

## 如果面试官追问
问：要求返回**所有**可行路径怎么办？
答：去掉死路标记，改用 `visited` 数组按路径回溯，复杂度升到指数级，需按路径数计。
