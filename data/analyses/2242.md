## 一句话思路
枚举中间边 (b,c)，两端各取不与对方冲突的最高分邻居，只需保留每个点分数前 3 的邻居。

## 怎么做
1. 建邻接表 `adj`，对每个点只保留 `scores` 最大的 3 个邻居（因为序列两端各只需一个邻居，冲突最多排除 2 个，第 4 名永远用不上）。
2. 枚举每条边 `(b, c)` 作为序列中间两个节点，即序列形如 `a - b - c - d`。
3. 从 `adj[b]` 里挑 `a != c` 的最高分，从 `adj[c]` 里挑 `d != b` 且 `d != a` 的最高分，四者分数相加更新答案。

以示例 1 为例：`scores = [5,2,9,8,4]`，枚举中间边 `(1,2)` 时，`adj[1]` 前 3 是 `[0(5), 3(8), 2(9)]`，取 `a = 3`（8 分，跳过 `c=2`）；`adj[2]` 前 3 是 `[3(8), 1(2), 4(4)]`，`d` 要跳过 `b=1` 和 `a=3`，取 `d = 4`（4 分）。和 = 2+9+8+4 = 23。真正最优是中间边 `(1,2)` 配 `a=0, d=3`：5+2+9+8 = 24，说明 `a` 的候选必须遍历全部 3 个，不能只取第一个。

```python
adj = [[] for _ in range(n)]
for a, b in edges:
    adj[a].append(b)
    adj[b].append(a)
for i in range(n):
    adj[i] = sorted(adj[i], key=lambda x: -scores[x])[:3]

ans = -1
for b, c in edges:
    for a in adj[b]:
        if a == c:
            continue
        for d in adj[c]:
            if d != b and d != a:
                ans = max(ans, scores[a] + scores[b] + scores[c] + scores[d])
```

## 复杂度
时间：O(E log E) 排序（每点邻居数 ≤ 5e4，实际按度排序），枚举 O(E·9)。
空间：O(n + E) 存邻接表，每点最多留 3 个邻居。

## 易错点
- 只保留前 3 个邻居后，若 `adj[b]` 里前两名恰好是 `c` 和 `a` 的候选，第三名才轮到，所以必须遍历全部 3 个而非只取第一个 → 会漏掉示例 1 的 24 → 正确做法是双重循环遍历 `adj[b]` 和 `adj[c]` 全部候选。
- 忘记 `d != a` 这个条件：当 `a` 和 `d` 是同一个节点时序列出现重复 → 会算出非法高分 → 必须同时排除 `b` 和 `a`。

## 如果面试官追问
问：如果要求返回具体序列而不只是分数？答：在更新 `ans` 时同步记录 `(a, b, c, d)` 四元组即可，逻辑不变。
