## 一句话思路
把 s 中所有长度为 2 的子串放进集合，再看反转串的相邻字符对是否命中。

## 怎么做
1. 遍历 `s`，用 `s[i:i+2]` 收集所有相邻字符对到集合 `pairs`。
2. 反转 `s` 得到 `r = s[::-1]`，再遍历 `r` 的相邻字符对。
3. 只要某个 `r[i:i+2]` 在 `pairs` 中，立即返回 `True`；遍历完返回 `False`。

以 `s = "leetcode"` 为例：`pairs = {"le","ee","et","tc","co","od","de"}`；`r = "edocteel"`，当扫到 `r[1:3] = "do"` 不命中，扫到 `r[2:4] = "oc"` 不命中，直到 `r[6:8] = "ee"` 命中，返回 `True`。

关键观察：`s` 中长度为 2 的子串 `s[i:i+2]` 出现在 `reverse(s)` 中，等价于 `s[i+1] + s[i]` 出现在 `s` 中。所以也可以只扫一遍 `s`，检查 `s[i+1] + s[i]` 是否在 `pairs` 里，省掉反转串。

```python
pairs = {s[i:i+2] for i in range(len(s) - 1)}
for i in range(len(s) - 1):
    if s[i+1] + s[i] in pairs:
        return True
return False
```

这段代码里 `s[i+1] + s[i]` 就是「反转后的相邻对」，直接和原串的相邻对集合比对，逻辑更短。

## 复杂度
时间 O(n)：建集合和扫描各一遍，n 为 `len(s)`。
空间 O(n)：集合最多存 n-1 个长度为 2 的字符串。

## 易错点
- `s = "a"` 时 `range(len(s) - 1)` 为空，集合为空、循环不执行，直接返回 `False`；若写成 `range(len(s))` 再取 `s[i:i+2]`，会得到单字符 `"a"` 混进集合，虽然本题仍返回 `False`，但语义已错，应统一用 `len(s) - 1` 作上界。
- `s = "abcba"` 中 `"ab"` 和 `"ba"` 互为反转对，若只检查 `s[i:i+2] == s[i+1] + s[i]`（即相邻两字符相等），会漏掉 `"ab"`/`"ba"` 这种非回文对而错判 `False`；正确做法是查集合而不是查相邻相等。

## 如果面试官追问
若要求返回具体的那个子串而非布尔值？答：在命中时直接返回 `s[i+1] + s[i]`，集合里存的是原串对，命中即答案。
