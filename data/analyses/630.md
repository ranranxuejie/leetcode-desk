## 一句话思路
按 lastDay 升序贪心选课，超期时用大顶堆弹出已选课程中 duration 最大的那门，换出时间给后面的课。

## 怎么做
1. 把 courses 按 lastDay（即 `c[1]`）升序排序，让截止早的课先被考虑。
2. 维护 `total`（已选课程总时长）和一个大顶堆 `heap`（存已选课程的 duration，用负数模拟）。
3. 对每门 `[d, last]`：先 `total += d` 并 `heappush(heap, -d)`，若 `total > last` 就弹出堆顶 `heappop(heap)` 并从 `total` 里减掉它（即 `total += popped`，popped 是负数）。
4. 遍历结束后 `len(heap)` 就是最多能修的课程数。

拿示例 1 走关键一步：排序后为 `[[100,200],[1000,1250],[200,1300],[2000,3200]]`。处理到 `[200,1300]` 时 `total = 100+1000+200 = 1300`，恰好 `<= 1300` 不弹；处理 `[2000,3200]` 时 `total = 3300 > 3200`，堆顶是 2000，弹出后 `total = 1300`，堆里剩 `{100,1000,200}`，长度 3。

```python
import heapq

def scheduleCourse(courses):
    courses.sort(key=lambda c: c[1])
    heap, total = [], 0
    for d, last in courses:
        total += d
        heapq.heappush(heap, -d)
        if total > last:
            total += heapq.heappop(heap)  # 弹出的是负数，等于减去最大 duration
    return len(heap)
```

## 复杂度
时间：排序 O(n log n)，每门课一次 push 加至多一次 pop，各 O(log n)，合计 O(n log n)。
空间：堆最多存 n 个 duration，O(n) 额外空间。

## 易错点
- 输入 `[[3,2],[4,3]]`：若按 duration 升序排，先选 3 但 `3 > 2` 直接超期，容易误判成能选 1 门；正确是按 lastDay 排序，两门都因 `total > last` 被弹出，返回 0。
- 输入 `[[5,5],[5,10],[5,15]]`：若只在 `total > last` 时跳过当前课而不回看堆，会漏掉「用短课替换长课」的机会；正确做法是无论当前课多长都先入堆，再靠弹出堆顶保证堆内始终是当前最优的一组课。

## 如果面试官追问
问：如果要输出具体选了哪几门课？答：堆里存 `(duration, 课程下标)`，结束后按下标回原数组取课即可。
