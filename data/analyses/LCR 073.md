## 一句话思路
答案在 `[1, max(piles)]` 上单调（K 越大耗时越少），对它二分，用 `sum(ceil(p/k))` 判可行。

## 怎么做
1. 下界 `lo = 1`，上界 `hi = max(piles)`；`hi` 一定可行，因为每堆最多一小时。
2. 二分取 `mid`，算总耗时 `hours = sum((p + mid - 1) // mid for p in piles)`。
3. `hours <= h` 说明 `mid` 可行，收缩上界 `hi = mid`；否则 `lo = mid + 1`。
4. 循环到 `lo == hi` 返回 `lo`。

以示例 1 `piles = [3,6,7,11], h = 8` 为例：`lo=1, hi=11`，`mid=6` 时 `hours = 1+1+2+2 = 6 <= 8`，可行，`hi=6`；`mid=3` 时 `hours = 1+2+3+4 = 10 > 8`，`lo=4`；`mid=5` 时 `hours = 1+2+2+3 = 8 <= 8`，`hi=5`；`mid=4` 时 `hours = 1+2+2+3 = 8`，`hi=4`，返回 4。

```python
lo, hi = 1, max(piles)
while lo < hi:
    mid = (lo + hi) // 2
    hours = 0
    for p in piles:
        hours += (p + mid - 1) // mid
    if hours <= h:
        hi = mid
    else:
        lo = mid + 1
return lo
```

关键点：`(p + mid - 1) // mid` 就是 `ceil(p / mid)`，避免浮点；`hours` 累加时一旦超过 `h` 可以提前 `break`，但本题 `10^4 * 10^9` 量级下不 break 也能过。

## 复杂度
时间：`O(n log M)`，`n = len(piles)`，`M = max(piles)`，二分 `log M` 轮，每轮扫一遍数组。
空间：`O(1)`，只开了 `lo/hi/mid/hours` 四个变量。

## 易错点
- `h` 恰好等于 `len(piles)` 时（如 `piles=[30,11,23,4,20], h=5`），每堆必须一小时吃完，答案就是 `max(piles)=30`；若把上界写成 `sum(piles)` 或 `10**9`，二分仍能收敛但多跑约 30 轮，且容易在 `hi` 初值上写错导致返回 31 之类。
- 用 `p / mid` 浮点再 `math.ceil` 时，`p=10**9, mid=3` 这类值在浮点下可能算出 `333333333.0000001`，`ceil` 后多 1，导致 `hours` 偏大、答案偏大；必须用整数 `(p + mid - 1) // mid`。

## 如果面试官追问
问：如果要求输出具体每小时吃哪堆的方案？答：二分定下 K 后，按堆顺序贪心分配，每堆耗时 `ceil(p/K)` 小时，记录起止时刻即可，因为堆之间互不影响。
