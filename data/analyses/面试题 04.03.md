## 一句话思路
用 BFS 逐层遍历，每层出队时把该层节点串成链表，层与层之间天然分开。

## 怎么做
1. 队列 `q` 初始放 `[tree]`，结果数组 `res = []`。
2. 每轮先记 `size = len(q)`，这正好是当前层的节点数。
3. 循环 `size` 次出队，用 `dummy` 头节点把出队节点串成链表，同时把非空左右孩子入队。
4. 每层结束把 `dummy.next` 追加进 `res`。

以官方示例 `[1,2,3,4,5,null,7,8]` 为例：第二轮开始时 `q = [2,3]`，`size = 2`；出队 2 后把 4、5 入队，出队 3 后只把 7 入队（`null` 跳过），本轮链表为 `2->3`，`q` 变成 `[4,5,7]`，正好是下一层。

```python
q = [tree] if tree else []
res = []
while q:
    size = len(q)
    dummy = cur = ListNode(0)
    for _ in range(size):
        node = q.pop(0)
        cur.next = ListNode(node.val)
        cur = cur.next
        if node.left: q.append(node.left)
        if node.right: q.append(node.right)
    res.append(dummy.next)
```

关键点：`size` 必须在出队前固定，否则新入队的孩子会被算进本层。

## 复杂度
时间 O(n)：每个节点入队出队各一次，串链表一次。
空间 O(n)：队列最宽一层 + 输出链表本身，递归栈为 0。

## 易错点
- 输入 `[1,2,3,4,5,null,7,8]` 中 3 的右孩子是 7、左孩子是 `null`：若写成 `if node.left: ... else: q.append(node.right)` 这种配对逻辑，7 会丢失或错层；必须左右各自独立判断。
- 空树 `tree = None`：若直接 `q = [tree]` 再进循环，`node.val` 会抛 `AttributeError`；正确做法是初始化时写 `[tree] if tree else []`，直接返回 `[]`。

## 如果面试官追问
问：要求返回链表而非数组，能否原地复用树节点？
答：可以，把 `cur.next = node` 直接串原节点，但会破坏 `left/right` 指针，需先存孩子再改链。
