## 一句话思路
用两个 DP 状态分别记录「第 i 小时喝 A / 喝 B」的最大能量，切换时跳过一小时。

## 怎么做
1. 定义 `dpA[i]` 为第 i 小时喝 A 的最大总能量，`dpB[i]` 同理。
2. 转移：`dpA[i] = max(dpA[i-1], dpB[i-2]) + energyDrinkA[i]`，即上一小时也喝 A，或两小时前喝 B 后跳过一小时。
3. 用 `dpB[i-2]` 需要处理 i<2 的边界，初始化 `dpA[0]=A[0]`、`dpB[0]=B[0]`、`dpA[1]=max(A[0],B[0])+A[1]` 等。
4. 答案取 `max(dpA[n-1], dpB[n-1])`。

以示例 2 `A=[4,1,1], B=[1,1,3]` 为例：
- `dpA[0]=4, dpB[0]=1`
- `dpA[1]=max(4, 0)+1=5`（0 表示无 i-2），`dpB[1]=max(1,0)+1=2`
- `dpA[2]=max(5, dpB[0]=1)+1=6`，`dpB[2]=max(2, dpA[0]=4)+3=7`
- 答案 `max(6,7)=7`，与官方一致。

```python
n = len(energyDrinkA)
dpA = [0] * n
dpB = [0] * n
dpA[0], dpB[0] = energyDrinkA[0], energyDrinkB[0]
for i in range(1, n):
    prevA = dpA[i-1]
    prevB = dpB[i-1]
    crossA = dpB[i-2] if i >= 2 else 0
    crossB = dpA[i-2] if i >= 2 else 0
    dpA[i] = max(prevA, crossA) + energyDrinkA[i]
    dpB[i] = max(prevB, crossB) + energyDrinkB[i]
return max(dpA[-1], dpB[-1])
```

## 复杂度
时间：O(n)，一次遍历两个数组。
空间：O(n)，开了 dpA、dpB 两个长度 n 的数组（可滚动到 O(1)）。

## 易错点
1. 输入 `A=[4,1,1], B=[1,1,3]` 时，若转移写成 `dpB[i]=max(dpB[i-1], dpA[i-1])+B[i]`（漏掉跳过一小时），会得到 `dpB[2]=max(2,5)+3=8`，错成 8；正确是 `dpA[i-2]` 即 `dpA[0]=4`，得 7。
2. i=1 时访问 `dpB[-1]` 在 Python 里不报错但取到末尾元素，会污染结果；必须显式判断 `i>=2` 才用 `dpX[i-2]`，否则取 0。

## 如果面试官追问
问：能否把空间压到 O(1)？
答：只需保留 `dpA[i-1], dpA[i-2], dpB[i-1], dpB[i-2]` 四个变量滚动更新即可。
