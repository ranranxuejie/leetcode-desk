## 一句话思路
把 s 复制成 s+s，用长度 n 的滑动窗口枚举所有循环移位，窗口内相邻相等对数用「进一减一」增量维护。

## 怎么做
1. 先算初始窗口 `t = s + s` 中 `[0, n)` 的得分：遍历 `i in range(n-1)`，`t[i] == t[i+1]` 就加一。
2. 窗口右移一位：新窗口是 `[l+1, l+n)`，只需去掉左端那对 `(l, l+1)`、加上右端新进的那对 `(l+n-1, l+n)`。
3. 每移一次就判断 `score == k`，累加计数；共移 n 次（含初始窗口），覆盖全部 n 种移位。

以 `s = "aab", n = 3, k = 1` 为例：`t = "aabaab"`，初始窗口 `"aab"` 得分 1（`t[0]==t[1]`）。右移后窗口 `"aba"`，去掉 `(0,1)` 得 0，加上 `(2,3)` 即 `t[2]='b'` 与 `t[3]='a'` 不等，得分仍 0。再右移窗口 `"baa"`，去掉 `(1,2)`、加上 `(3,4)` 即 `'a'=='a'`，得分 1。三次得分 1,0,1，等于 k 的有 2 个。

```python
t = s + s
n = len(s)
score = sum(1 for i in range(n - 1) if t[i] == t[i + 1])
ans = 0
for l in range(n):
    if score == k:
        ans += 1
    if l == n - 1:
        break
    if t[l] == t[l + 1]:
        score -= 1
    if t[l + n - 1] == t[l + n]:
        score += 1
```

注意 `t[l+n]` 的下标最大到 `2n-1`，`t` 长度正好 `2n`，不越界。

## 复杂度
时间 O(n)：初始得分 O(n)，之后 n 次移位每次 O(1)。
空间 O(n)：额外开了长度 2n 的 `t = s + s`。

## 易错点
- `s = "aaaa", k = 3`：若只枚举 `l in range(n-1)` 会漏掉最后一种移位，答案错成 2 而非 1。循环必须走满 n 个窗口，且初始窗口也要计入。
- `s = "ab", k = 0`：若把「去掉左端对」写成无条件 `score -= 1`，初始得分 0 会被减成 -1，后续再也回不到 0。减和加都必须先判断 `t[l] == t[l+1]`、`t[l+n-1] == t[l+n]`。

## 如果面试官追问
若 n 放大到 10^6 且要求输出所有满足的移位起点？答：滑动窗口仍是 O(n)，把 `ans += 1` 换成 `ans.append(l)`，空间 O(n) 存结果。
