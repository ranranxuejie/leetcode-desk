## 一句话思路
把每个 1×1 方格拆成 4 个小三角形，用并查集合并被斜杠切开的相邻三角形，最后数连通分量。

## 怎么做
1. 每个格子 `(i,j)` 拆成 4 个三角形，编号 `4*(i*n+j)+k`，`k=0,1,2,3` 分别代表上、右、下、左。
2. 按字符决定格内合并：空格全连；`'/'` 连 0-3、1-2；`'\\'` 连 0-1、2-3。
3. 再合并跨格相邻三角形：本格右(1)与右邻左(3)、本格下(2)与下邻上(0)。
4. 并查集根节点个数即答案。

以 `grid = ["/\\","\\/"]`（即 `/\`、`\/`）为例，n=2，共 16 个三角形。格 (0,0) 是 `'/'`，合并 0-3、1-2；格 (0,1) 是 `'\\'`，合并 0-1、2-3。跨格再合并 (0,0) 的 1 与 (0,1) 的 3、(0,0) 的 2 与 (1,0) 的 0 等，最终根节点数为 5。

```python
def find(x):
    while p[x] != x:
        p[x] = p[p[x]]
        x = p[x]
    return x

def union(a, b):
    ra, rb = find(a), find(b)
    if ra != rb:
        p[ra] = rb

p = list(range(4 * n * n))
for i in range(n):
    for j in range(n):
        b = 4 * (i * n + j)
        c = grid[i][j]
        if c == ' ':
            union(b, b+1); union(b+1, b+2); union(b+2, b+3)
        elif c == '/':
            union(b, b+3); union(b+1, b+2)
        else:
            union(b, b+1); union(b+2, b+3)
        if j + 1 < n: union(b+1, b+5)
        if i + 1 < n: union(b+2, b+4*n)
return len({find(x) for x in range(4*n*n)})
```

## 复杂度
时间：O(n²·α(n²))，每个格子常数次并查集操作，α 近似常数。
空间：O(n²)，并查集数组开 4n² 个元素。

## 易错点
- 输入 `["/\\","\\/"]` 中 `'\\'` 是转义后的单个反斜杠，若按两个字符处理会越界或错连；Python 里判断 `c == '\\'` 即可。
- 跨格只连右邻和下邻，漏掉会导致 `[" /","/ "]` 错算成 3 而非 2；必须补上 `union(b+1, b+5)` 和 `union(b+2, b+4*n)`。

## 如果面试官追问
若 n 扩大到 3000 且内存受限，怎么办？答：改用 DFS 洪水填充，按三角形编号原地标记访问，空间降到 O(n²) 但常数更小。
