## 一句话思路
用滑动窗口维护窗口内不同值的和 `s`，右指针扩张、左指针在 `s >= k` 时收缩，记录最短窗口。

## 怎么做
1. 用 `cnt` 字典统计窗口内每个值的出现次数，`s` 记录不同值之和（某值首次进入窗口时加一次）。
2. 右指针 `r` 遍历 `nums`：`cnt[nums[r]] += 1`，若计数从 0 变 1，则 `s += nums[r]`。
3. 当 `s >= k` 时，用 `r - l + 1` 更新答案，然后尝试移出 `nums[l]`：计数减 1，若归零则 `s -= nums[l]`，`l += 1`，循环直到 `s < k`。
4. 遍历结束若答案仍为初值，返回 -1。

以 `nums = [2,2,3,1], k = 4` 为例：`r=0` 时 `cnt={2:1}`、`s=2`；`r=1` 时 `cnt={2:2}`、`s` 仍为 2（2 不是首次进入）；`r=2` 时 `cnt={2:2,3:1}`、`s=5 >= 4`，窗口 `[0,2]` 长度 3，移出 `nums[0]=2` 后 `cnt[2]=1`、`s` 不变仍为 5，再移出 `nums[1]=2` 后 `cnt[2]=0`、`s=3 < 4` 停止，此时 `l=2`；`r=3` 时 `s=3+1=4 >= 4`，窗口 `[2,3]` 长度 2，更新答案为 2。

```python
cnt, s, l, ans = {}, 0, 0, len(nums) + 1
for r, x in enumerate(nums):
    cnt[x] = cnt.get(x, 0) + 1
    if cnt[x] == 1:
        s += x
    while s >= k:
        ans = min(ans, r - l + 1)
        y = nums[l]
        cnt[y] -= 1
        if cnt[y] == 0:
            s -= y
        l += 1
return ans if ans <= len(nums) else -1
```

## 复杂度
时间 O(n)：每个元素最多被右指针加入一次、左指针移出一次。
空间 O(d)：`cnt` 最多存 d 个不同值，d ≤ min(n, 10^5)。

## 易错点
1. 输入 `nums = [5,5,4], k = 5` → 若在 `cnt[x]` 已存在时仍执行 `s += x`，`s` 会变成 10 而误判窗口更短 → 必须只在 `cnt[x] == 1`（首次进入）时加。
2. 输入 `nums = [1,1], k = 5` → 若 `ans` 初值设为 `n` 且最后直接返回 `ans`，会输出 2 而非 -1 → 初值用 `n + 1`，返回前判断 `ans <= n`。

## 如果面试官追问
若要求输出具体子数组而非长度？答：在 `ans` 更新处同时记录 `(l, r)`，最后切片 `nums[l:r+1]` 即可，复杂度不变。
