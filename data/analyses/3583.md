## 一句话思路
枚举中间下标 j，用左侧哈希表存 nums[i] 的计数、右侧哈希表存 nums[k] 的计数，答案累加 `left[nums[j]*2] * right[nums[j]*2]`。

## 怎么做
1. 先统计全数组每个值的出现次数放进 `right`，`left` 初始为空。
2. 从下标 0 扫到 n-1，每步先把 `nums[j]` 从 `right` 移出（保证 right 只含 j 右侧元素），再以 j 为中间点结算，最后把 `nums[j]` 放进 `left`。
3. 结算时 `t = nums[j] * 2`，若 `t` 同时出现在 left 和 right，累加 `left[t] * right[t]`。

以 `nums = [8,4,2,8,4]` 为例：初始 `right = {8:2, 4:2, 2:1}`。扫到 j=1（`nums[1]=4`）时，right 已扣掉 8 和 4，剩 `{8:1, 4:1, 2:1}`，left 为 `{8:1}`；`t = 8`，`left[8]=1`、`right[8]=1`，累加 1。扫到 j=2（`nums[2]=2`）时 left 为 `{8:1,4:1}`，right 剩 `{8:1,4:1}`，`t=4`，`left[4]*right[4]=1*1=1`，累计 2，与答案一致。

```python
MOD = 10**9 + 7
right = {}
for x in nums:
    right[x] = right.get(x, 0) + 1
left = {}
ans = 0
for j, x in enumerate(nums):
    right[x] -= 1
    if right[x] == 0:
        del right[x]
    t = x * 2
    ans = (ans + left.get(t, 0) * right.get(t, 0)) % MOD
    left[x] = left.get(x, 0) + 1
return ans
```

## 复杂度
时间 O(n)：一次建表加一次扫描，每个元素 O(1) 哈希操作。
空间 O(n)：left、right 两个哈希表最多各存 n 个不同值。

## 易错点
- `nums = [0,1,0,0]` → 若先结算再移出 right，j=2 时 right 里还留着 `nums[2]=0` 自己，会多算成 2；正确做法是每步先 `right[x] -= 1` 再结算，保证 k 严格在 j 右侧。
- `nums = [6,3,6]` → 若把 `t = x * 2` 写成 `t = x // 2`，j=1 时 `t=1`，left/right 都查不到，答案错成 0；本题条件固定为 `nums[i] == nums[j]*2`，乘 2 方向不能反。

## 如果面试官追问
问：若要求返回所有三元组的具体下标而非计数？答：把 `left[t]` 从计数改成存下标列表，结算时双重循环拼出 `(i, j, k)`，复杂度升到 O(n + 答案数)。
