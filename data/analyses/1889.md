## 一句话思路
对每个供应商的箱子排序后，用二分把包裹按「装进哪个箱子」分段，前缀和算每段浪费，取最小。

## 怎么做
1. 把 `packages` 排序并求前缀和 `pre`，`pre[i]` 表示前 i 个包裹尺寸之和。
2. 对某个供应商，把它的箱子尺寸排序去重（题目保证互不相同，排序即可），若最大箱子 < 最大包裹，该供应商直接跳过。
3. 遍历箱子 `b`，用 `bisect_right(packages, b)` 得到能装进 `b` 的包裹右边界 `r`，上一轮的 `r` 记为 `l`，则这一段包裹全用尺寸 `b` 的箱子，浪费为 `b*(r-l) - (pre[r]-pre[l])`。
4. 所有供应商取最小值，对 `10**9+7` 取余返回。

以示例 3 的第三个供应商 `[10,5,14]` 为例：排序后 `[5,10,14]`，`packages=[3,5,8,10,11,12]`。`b=5` 时 `bisect_right` 得 `r=2`，浪费 `5*2-(3+5)=2`；`b=10` 时 `r=4`，浪费 `10*2-(8+10)=2`；`b=14` 时 `r=6`，浪费 `14*2-(11+12)=5`，合计 9。

```python
from bisect import bisect_right
packages.sort()
pre = [0]
for p in packages:
    pre.append(pre[-1] + p)
ans = float('inf')
for bs in boxes:
    bs.sort()
    if bs[-1] < packages[-1]:
        continue
    l = 0
    cost = 0
    for b in bs:
        r = bisect_right(packages, b)
        cost += b * (r - l) - (pre[r] - pre[l])
        l = r
    ans = min(ans, cost)
return -1 if ans == float('inf') else ans % (10**9 + 7)
```

## 复杂度
时间：每个供应商排序 O(k log k)，每个箱子二分 O(log n)，总 O(Σk log k + Σk log n)。
空间：`pre` 数组 O(n)，排序原地，无其他额外结构。

## 易错点
- 供应商最大箱子装不下最大包裹（如示例 2 的 `[1,4]` 对包裹 5）→ 若直接算会得到负浪费或漏装 → 必须先判 `bs[-1] < packages[-1]` 跳过，全部跳过才返回 -1。
- 箱子尺寸可能重复出现在不同供应商但同一供应商内互不相同，若忘记对 `bs` 排序，`bisect_right` 的 `l` 会乱序导致某段包裹被重复计算 → 每个供应商的 `bs` 必须先 `sort()` 再顺序扫描。

## 如果面试官追问
问：若要求输出具体装箱方案而非只给浪费值？
答：在每段记录 `(b, l, r)`，即尺寸 b 的箱子装 `packages[l:r]`，按段输出即可。
