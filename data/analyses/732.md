## 一句话思路
用差分 + 有序字典维护每个时间点的净变化，每次 book 后扫一遍前缀和取最大值。

## 怎么做
1. 用 `SortedDict`（或普通 dict + 每次排序）记录 `delta[t]`：`delta[start] += 1`，`delta[end] -= 1`。
2. 每次 book 后按时间顺序累加前缀和，记录过程中出现的最大值即为答案。
3. 由于 book 最多 400 次，每次重扫全部时间点（≤800 个）完全可接受。

以示例第 4 次 `book(5, 15)` 为例，此时 delta 为 `{10:1, 20:-1, 50:1, 60:-1, 40:-1, 5:1, 15:-1}`（合并后 `{5:1, 10:2, 15:-1, 20:-1, 40:-1, 50:1, 60:-1}`），前缀和依次为 1,3,2,1,0,1,0，最大值 3。

```python
from sortedcontainers import SortedDict

def book(self, start, end):
    self.d[start] = self.d.get(start, 0) + 1
    self.d[end] = self.d.get(end, 0) - 1
    cur = best = 0
    for t in sorted(self.d):
        cur += self.d[t]
        best = max(best, cur)
    return best
```

## 复杂度
时间：每次 book 排序 O(m log m) + 扫描 O(m)，m 为时间点数量（≤800），总 O(n·m log m)。
空间：O(m) 存差分字典，m ≤ 2n。

## 易错点
1. 区间是左闭右开 `[start, end)`，若在 `end` 处写成 `+1` 而非 `-1`，示例第 1 次 `book(10,20)` 后 `20` 处前缀和会变成 2，返回 2 而非 1。正确做法：`end` 处减 1。
2. 同一时间点多次出现时若用列表存事件再逐个累加，顺序错乱会导致中间值偏大；应合并到 dict 的同一 key 上再扫描，如示例中 `10` 处累计为 `+2`。

## 如果面试官追问
若 book 调用次数放大到 10^5 且时间范围到 10^9，怎么办？
答：改用动态开点线段树，每个节点维护区间最大覆盖数，单次 book O(log C)，C 为坐标范围。
