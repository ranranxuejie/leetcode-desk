## 一句话思路
枚举每个棋子的全部（方向, 步数）落点，回溯组合，逐秒模拟检查碰撞。

## 怎么做
1. 对每个棋子预生成所有合法移动 `(dr, dc, steps)`，`steps=0` 表示不动。
2. 回溯枚举组合，把 n 个移动放进列表 `moves`。
3. 对组合做逐秒模拟：第 t 秒位置为 `pos[i] + t*(dr,dc)`（t 不超过 steps），检查同秒是否同格或对穿。
4. 全部通过则计数加一。

以示例 4 `pieces=["rook","rook"], positions=[[1,1],[8,8]]` 为例：每个车 15 种移动，共 225 组合。当两车都选 `(dr,dc,steps)=(-1,0,7)` 和 `(0,-1,7)` 时，第 7 秒都到 `(8,1)`，`seen` 里 `(8,1)` 出现两次，该组合被剔除；最终 223。

```python
def ok(moves):
    for t in range(1, max(m[2] for m in moves) + 1):
        seen = set()
        for i, (dr, dc, s) in enumerate(moves):
            if t <= s:
                p = (positions[i][0] + dr * t, positions[i][1] + dc * t)
                if p in seen:
                    return False
                seen.add(p)
        # 对穿：i 在 t-1 的位置 == j 在 t 的位置，且 j 在 t-1 == i 在 t
        for i in range(len(moves)):
            for j in range(i + 1, len(moves)):
                a, b = moves[i], moves[j]
                if t <= a[2] and t <= b[2]:
                    pi = (positions[i][0] + a[0]*(t-1), positions[i][1] + a[1]*(t-1))
                    pj = (positions[j][0] + b[0]*(t-1), positions[j][1] + b[1]*(t-1))
                    qi = (positions[i][0] + a[0]*t, positions[i][1] + a[1]*t)
                    qj = (positions[j][0] + b[0]*t, positions[j][1] + b[1]*t)
                    if pi == qj and pj == qi:
                        return False
    return True
```

## 复杂度
时间：O(Π 移动数 × 最大步数 × n²)，n≤4、每子≤27 种移动，规模极小。
空间：O(n) 递归栈与 `seen` 集合，无额外大表。

## 易错点
- 只查同秒同格不查对穿：如两车相邻互选对方方向，第 1 秒交换位置，`seen` 各自唯一不冲突，会误判有效；必须额外比较 `pi==qj and pj==qi`。
- 把 `steps=0` 漏掉：示例 1 车在 `(1,1)` 有 14 个方向落点加不动共 15，漏掉不动会得 14；生成移动时显式加入 `(0,0,0)`。

## 如果面试官追问
若 n 扩大到 8 且棋子同型，如何优化？答：按棋子类型分组，先算两两兼容表，再回溯剪枝，避免重复模拟。
