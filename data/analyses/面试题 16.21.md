## 一句话思路
设 `diff = sum(array1) - sum(array2)`，则需 `a - b = diff // 2`，把 `array2` 丢进集合后逐个查 `a - diff // 2`。

## 怎么做
1. 先算 `diff = sum(array1) - sum(array2)`；若 `diff` 为奇数，直接返回 `[]`，因为交换后两边总和差必须是偶数才能被 2 整除。
2. 目标差值 `half = diff // 2`，即要从 `array1` 取出的数比从 `array2` 取出的数大 `half`。
3. 把 `array2` 转成 `set`，遍历 `array1` 的每个 `a`，查 `a - half` 是否在集合里。
4. 命中就返回 `[a, a - half]`，遍历完没命中返回 `[]`。

用示例 1：`sum(array1) = 11`，`sum(array2) = 15`，`diff = -4`，`half = -2`。遍历到 `a = 1` 时查 `1 - (-2) = 3`，`3` 在 `set(array2) = {3, 6}` 里，返回 `[1, 3]`。验证：交换后 `array1` 和变 13，`array2` 和也变 13。

```python
diff = sum(array1) - sum(array2)
if diff % 2:
    return []
half = diff // 2
s2 = set(array2)
for a in array1:
    if a - half in s2:
        return [a, a - half]
return []
```

注意 `diff % 2` 在 Python 里对负数也返回 0 或 1，`-4 % 2 == 0`、`-3 % 2 == 1`，所以不用额外取绝对值。

## 复杂度
时间 O(m + n)：建 `set(array2)` 是 O(n)，遍历 `array1` 是 O(m)，哈希查询均摊 O(1)。
空间 O(n)：额外开了 `set(array2)`，最坏 n 个元素。

## 易错点
- 输入 `array1 = [1, 2, 3], array2 = [4, 5, 6]`：`diff = -9` 是奇数，若跳过奇偶判断直接算 `half = -9 // 2 = -5`（Python 向下取整），会拿 `a + 5` 去查，可能误命中不存在的配对逻辑，正确做法是先 `if diff % 2: return []`。
- 输入 `array1 = [1, 1], array2 = [1, 1]`：`diff = 0`、`half = 0`，遍历到 `a = 1` 查 `1 - 0 = 1` 命中，返回 `[1, 1]`，这是合法答案（交换相同值，两边和不变）；若误以为「必须交换不同值」而跳过，会错返 `[]`。

## 如果面试官追问
问：要求返回所有满足条件的数对怎么办？
答：把 `array2` 建成 `值 -> 出现次数` 的字典，遍历 `array1` 时收集所有 `a - half` 存在的 `(a, a - half)`，用集合去重后返回。
