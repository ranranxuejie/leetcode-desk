## 一句话思路
只有前 6 个灯的状态独立，且 4 个开关按两次等于没按，所以枚举开关子集即可。

## 怎么做
1. 每个开关按两次等于没按，所以只需关心 4 个开关的奇偶性，共 16 种组合。
2. 但「恰好 presses 次」有奇偶约束：组合里按的开关数 `k` 必须满足 `k <= presses` 且 `(presses - k) % 2 == 0`。
3. 对每个合法组合，只算前 `min(n, 6)` 个灯的状态，因为开关 4 的周期是 3，开关 2/3 的周期是 2，前 6 个灯能覆盖所有模式。
4. 用集合去重，返回集合大小。

以 `n = 3, presses = 1` 为例：合法组合只有单个开关（k=1）。开关 1 得 `[0,0,0]`，开关 2 得 `[1,0,1]`，开关 3 得 `[0,1,0]`，开关 4 得 `[0,1,1]`，集合大小 4。

```python
def flipLights(n, presses):
    n = min(n, 6)
    seen = set()
    for mask in range(16):
        k = bin(mask).count('1')
        if k > presses or (presses - k) % 2:
            continue
        state = [1] * n
        for i in range(n):
            pos = i + 1
            if mask & 1: state[i] ^= 1
            if mask & 2 and pos % 2 == 0: state[i] ^= 1
            if mask & 4 and pos % 2 == 1: state[i] ^= 1
            if mask & 8 and pos % 3 == 1: state[i] ^= 1
        seen.add(tuple(state))
    return len(seen)
```

## 复杂度
时间：O(16 × min(n,6))，n 被截断到 6，常数级。
空间：O(16 × 6) 存状态元组，与 n 无关。

## 易错点
- `presses = 0` 时，只有 mask=0 合法（k=0），返回 1。若漏掉奇偶约束会错误地允许按 2 次开关，得到多余状态。
- `n` 很大时（如 n=1000），若直接对全部 n 个灯算状态会超时且浪费；必须截断到 6，因为第 7 个灯之后的状态完全由前 6 个决定，开关 4 周期 3、开关 2/3 周期 2，最小公倍数 6。

## 如果面试官追问
问：如果要求输出所有可能状态的具体方案而非数量？
答：在集合里存 `(state_tuple, mask)`，最后按 state 分组输出对应开关组合即可。
