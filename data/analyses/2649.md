## 一句话思路
用显式栈模拟递归：栈里存 `(数组, 下标)`，遇整数就产出，遇子数组就压栈，避免深度 10^5 时爆递归栈。

## 怎么做
1. 栈初始为 `[(arr, 0)]`，表示「当前正在遍历 arr、下一个待看位置是 0」。
2. 循环取栈顶 `(cur, i)`；若 `i == len(cur)` 说明该层走完，弹栈。
3. 否则看 `cur[i]`：是整数就产出并把栈顶下标 `i` 加 1；是列表就压入 `(cur[i], 0)`，父层下标先不动。
4. 栈空即结束。

以 `arr = [[[6]],[1,3],[]]` 为例，压栈过程是 `(arr,0)` → `([[6]],0)` → `([6],0)` → `([6],1)` 时产出 `6`；弹回 `(arr,1)` 后产出 `1`、`3`，最后 `(arr,2)` 指向空列表 `[]`，压入后立刻因 `i == len([]) == 0` 弹掉。

```python
def inorder(arr):
    stack = [(arr, 0)]
    while stack:
        cur, i = stack[-1]
        if i == len(cur):
            stack.pop()
        elif isinstance(cur[i], list):
            stack.append((cur[i], 0))
        else:
            yield cur[i]
            stack[-1] = (cur, i + 1)
```

关键点：产出整数后必须把**父层**下标推进（`stack[-1] = (cur, i + 1)`），否则同一个整数会被反复产出，`[[[6]]]` 会死循环吐 `6`。

## 复杂度
时间 O(n)：n 是 `arr.flat()` 的元素个数，每个整数产出一次、每个子数组进出栈各一次。
空间 O(d)：d 是最大嵌套深度，栈最多存 d 层 `(数组, 下标)`，与元素总数无关。

## 易错点
- 输入 `[[[6]]]` 这类深层嵌套 → 若用递归 `for x in arr: yield from inorder(x)`，深度 10^5 会触发 `RecursionError` → 必须改成上面的显式栈，栈深度只受内存限制。
- 输入 `[[1], 2]` → 若在压入子数组时就把父层下标加 1，回到父层会跳过 `2`，输出 `[1]` → 父层下标只在**产出整数后**推进，压栈时保持 `i` 不变，等子数组弹栈后再处理 `cur[i]`。

## 如果面试官追问
问：要求返回列表而非生成器，且内存只允许 O(1) 额外空间怎么办？
答：原地把嵌套列表摊平到 `arr` 前部再切片，或先算总数预分配，避免栈。
