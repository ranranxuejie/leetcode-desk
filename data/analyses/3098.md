## 一句话思路
排序后，能量等于相邻元素差的最小值，用「枚举最小值 d + DP 计数」把 min 转成求和。

## 怎么做
1. 先对 `nums` 排序，子序列的能量只取决于排序后相邻元素的差，`min` 一定落在某对相邻元素上。
2. 枚举候选能量值 `d`（所有 `nums[j]-nums[i]`，含 0），统计「能量 ≥ d」的长度 k 子序列个数 `cnt(d)`。
3. 用恒等式 `sum(能量) = Σ_d cnt(d)`（d 取正差值），因为每个子序列能量 e 会被 d=1..e 各计一次。
4. `cnt(d)` 用 DP：`dp[i][t]` 表示以 i 结尾、长度 t 且相邻差都 ≥ d 的子序列数，转移时只从满足 `nums[i]-nums[j] >= d` 的 j 来。

以 `nums=[1,2,3,4], k=3` 为例：d=1 时所有长度 3 子序列都合法，`cnt=4`；d=2 时只有 `[1,3]`、`[1,4]`、`[2,4]` 这类间隔，凑不出 3 个，`cnt=0`；d=3 同理 0。故答案 `4*1 = 4`。

```python
nums.sort()
vals = sorted({nums[j] - nums[i] for i in range(n) for j in range(i+1, n)})
ans = 0
for d in vals:
    dp = [[0]*(k+1) for _ in range(n)]
    for i in range(n):
        dp[i][1] = 1
        for j in range(i):
            if nums[i] - nums[j] >= d:
                for t in range(2, k+1):
                    dp[i][t] += dp[j][t-1]
    ans += sum(dp[i][k] for i in range(n))
return ans % (10**9 + 7)
```

## 复杂度
时间：O(n²·k·D)，D 为不同差值个数（≤ n²/2），n=50 时约 3e6。
空间：O(n·k) 的 dp 表，每轮 d 重建。

## 易错点
- 输入 `[2,2], k=2`：若只枚举正差值，会漏掉能量为 0 的子序列，答案仍对但逻辑不完整；正确做法是差值集合含 0，或直接对 0 单独处理（本题 0 不影响和，但计数要一致）。
- 输入 `[1,2,3,4], k=3`：若把 `dp[i][1]=1` 写在 j 循环内，会重复累加导致 `cnt` 偏大；正确做法是每个 i 先置 `dp[i][1]=1` 再枚举 j。
- 差值可能为负：排序后 `nums[i]-nums[j]` 才非负，未排序直接用原下标会算错 `d`。

## 如果面试官追问
若 n 放大到 1000、k 也大，怎么优化？答：把「枚举 d」换成对差值排序后二分 + 前缀和 DP，或按 d 从大到小增量维护合法边，复杂度降到 O(n²k log n)。
