## 一句话思路
用 `Object.keys(obj).length === 0` 判断，因为对象和数组都能被它统一取到「元素个数」。

## 怎么做
1. 直接对 `obj` 调用 `Object.keys`，它返回对象自身可枚举键组成的数组，对数组则返回下标字符串数组。
2. 用返回数组的 `length` 与 0 比较，为 0 即空。
3. 以 `obj = {"x": 5, "y": 42}` 为例，`Object.keys(obj)` 得到 `["x", "y"]`，`length` 为 2，返回 `False`。
4. 以 `obj = [null, false, 0]` 为例，`Object.keys(obj)` 得到 `["0", "1", "2"]`，`length` 为 3，返回 `False`；而 `obj = {}` 得到 `[]`，`length` 为 0，返回 `True`。

```python
def isEmpty(obj):
    if isinstance(obj, list):
        return len(obj) == 0
    return len(obj.keys()) == 0
```

上面是 Python 版写法；若按题面 JS 环境，核心一行是 `Object.keys(obj).length === 0`。注意 `Object.keys` 对数组返回的是下标，不是元素值，所以 `[null, false, 0]` 不会被误判为空——这点很关键，因为数组里全是假值元素时，任何「遍历找真值」的写法都会翻车。

## 复杂度
时间：`Object.keys` 需遍历全部键，n 为键或元素个数，O(n)。
空间：返回的键数组额外占 O(n)，除此之外无额外空间。

## 易错点
- 输入 `[null, false, 0]` → 若用 `if not obj` 或遍历找真值判断，会错判为 `True`（空）→ 正确做法是只看长度，不看元素真假。
- 输入 `{}` 与 `[]` → 若只写 `obj.length === 0`，对 `{}` 得到 `undefined === 0` 为 `False`，把空对象判成非空 → 正确做法是对象走 `Object.keys`、数组走 `length`，或统一用 `Object.keys`。

## 如果面试官追问
问：能否做到 O(1) 时间？答：JS 里 `Object.keys` 是 O(n)；若允许维护计数，可在插入/删除时同步更新 size，查询即 O(1)。
