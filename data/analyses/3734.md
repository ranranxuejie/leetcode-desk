## 一句话思路
把 s 折成前半段计数，从右往左找第一个能抬高的位置，抬高后剩余字符升序填满即最小。

## 怎么做
1. 统计 `cnt[26]`，若奇数频次字符超过 1 个直接返回 `""`（示例 3 的 `"abc"` 有 3 个奇数频次，返回空）。
2. 只保留前半段计数 `half[c] = cnt[c] // 2`，长度 `m = n // 2`；回文由前半段唯一决定，字典序比较也只看前半段。
3. 从 `i = m-1` 往左扫，在 `half` 里找比 `target[i]` 大的最小字符 `c`：把 `half[target[i]]` 还回去、`half[c]` 减一，位置 `i` 放 `c`，`i` 之后按字母升序铺满剩余 `half`，拼成 `left + mid + left[::-1]` 即为答案。
4. 若整个前半段都找不到可抬高的位置，返回 `""`（示例 2 的 `"baba"` 对 `"bbaa"`：`half = {a:1, b:1}`，`i=1` 时 `target[1]='b'` 无更大字符，`i=0` 时 `target[0]='b'` 也无，返回空）。

以示例 1 `s="baba", target="abba"` 为例：`cnt = {a:2, b:2}`，`half = {a:1, b:1}`，`m=2`。`i=1`：`target[1]='b'`，`half` 中无大于 `b` 的字符，跳过。`i=0`：`target[0]='a'`，`half` 中大于 `a` 的最小字符是 `b`，还回 `a`、用掉 `b`，`half` 变为 `{a:1}`，位置 0 放 `b`，位置 1 铺 `a`，得 `left="ba"`，`mid=""`，答案 `"baab"`。

```python
from collections import Counter
cnt = Counter(s)
if sum(v % 2 for v in cnt.values()) > 1:
    return ""
half = [0] * 26
for ch, v in cnt.items():
    half[ord(ch) - 97] = v // 2
mid = next((ch for ch, v in cnt.items() if v % 2), "")
m = len(s) // 2
for i in range(m - 1, -1, -1):
    t = ord(target[i]) - 97
    for c in range(t + 1, 26):
        if half[c]:
            half[t] += 1
            half[c] -= 1
            left = target[:i] + chr(97 + c)
            left += "".join(chr(97 + k) * half[k] for k in range(26))
            return left + mid + left[::-1]
    half[t] += 1
return ""
```

## 复杂度
时间 O(26n)：外层扫 m 个位置，内层最多 26 次字符探测，拼串 O(n)。
空间 O(n)：`half` 固定 26 格，`left` 与返回值各占 O(n)。

## 易错点
- `s="aac", target="abb"`：若只比较前半段 `"a"` 与 `target[:1]="a"` 就判定「不大于」返回空，会漏掉 `"aca"`。正确做法是回退时把 `target` 前缀原样保留，只抬高第 `i` 位，再拼 `mid` 和反转，`"aca"` 才大于 `"abb"`。
- `s="baba", target="abba"`：若在 `i=1` 处发现 `target[1]='b'` 无更大字符就整体返回空，会漏掉 `i=0` 的抬高。正确做法是 `for i` 循环里找不到就 `half[t] += 1` 还回去、继续往左扫，不能提前退出。

## 如果面试官追问
问：n 放大到 10^5 怎么办？答：把内层 26 次探测换成有序集合或位掩码找后继，仍是 O(26n) 但常数更小，拼串用列表 join。
