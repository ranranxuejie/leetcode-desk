## 一句话思路
用 `a - b` 的符号位当选择器，配合位掩码 `mask` 在 `a`、`b` 间做无分支选择。

## 怎么做
1. 令 `diff = a - b`，取它的符号位 `sign = (diff >> 63) & 1`（按 64 位补码，负数右移得全 1）。
2. 令 `mask = -sign`：`a >= b` 时 `sign = 0`、`mask = 0`；`a < b` 时 `sign = 1`、`mask = -1`（全 1）。
3. 返回 `a - (diff & mask)`：`mask = 0` 时原样返回 `a`，`mask = -1` 时返回 `a - diff = b`。
4. 全程只有减法、移位、按位与，没有比较运算符。

以官方示例 `a = 1, b = 2` 走一遍：`diff = -1`，`sign = (-1 >> 63) & 1 = 1`，`mask = -1`，`diff & mask = -1`，返回 `1 - (-1) = 2`。关键中间值是 `mask = -1`，它把「选 b」编码成了「减去整个 diff」。

```python
diff = a - b
sign = (diff >> 63) & 1
mask = -sign
return a - (diff & mask)
```

若担心 `a - b` 超出 64 位（Python 大整数无溢出，但符号位位置会漂移），可先统一到 64 位补码再取符号位；本题数据范围内直接右移 63 位即可。

## 复杂度
时间：O(1)，三次算术/位运算，与 a、b 大小无关。
空间：O(1)，只开了 `diff`、`sign`、`mask` 三个临时整数。

## 易错点
1. `a = -5, b = 3` 这类异号输入 → 若用 `(a - b) >> 31` 取符号位，Python 大整数右移不会截断到 32 位，`-8 >> 31` 得 `-1` 看似对，但 `a - b` 一旦超过 2**63 量级符号位位置就漂移 → 正确做法是固定右移 63 位并 `& 1`，或先把差值规约到 64 位补码。
2. `a = b`（如 `a = 2, b = 2`）→ 若把 `mask` 写成 `sign - 1` 之类，相等时 `sign = 0` 会得到 `mask = -1`，错误返回 `b`（虽然值相同但逻辑错，遇到 `a = b` 且后续要区分分支时会翻车）→ 正确做法是 `mask = -sign`，相等时 `mask = 0`，返回 `a`，语义明确。

## 如果面试官追问
追问：不允许用减法怎么办？
答：用 `a ^ b` 与 `a & b` 逐位比较最高不同位，或用 `(a - b)` 的等价位运算展开，本质仍是找符号位。
