## 一句话思路
开一个长度 n+2 的数组按 id 直接落位，ptr 只向前扫，扫到空位就停。

## 怎么做
1. 构造时开 `buf = [None] * (n + 2)`，`ptr = 1`；下标直接用 id，省掉 id-1 的换算。
2. `insert` 先写 `buf[id] = value`，这一步与 ptr 无关，乱序到达也能存住。
3. 从 `ptr` 开始往后收集：只要 `buf[ptr]` 不是 `None` 就 append 并 `ptr += 1`，遇到空位立刻停。
4. 返回收集到的列表；没收集到任何东西时自然返回 `[]`。

拿官方示例走一遍关键那步：`buf` 初始全 `None`，`ptr=1`。插入 `(3,"ccccc")` 后 `buf[3]="ccccc"`，但 `buf[1]` 仍是 `None`，循环零次，返回 `[]`。接着插入 `(1,"aaaaa")`，`buf[1]` 有值，收集 `"aaaaa"`，`ptr` 变 2，`buf[2]` 是 `None` 停，返回 `["aaaaa"]`。再插入 `(2,"bbbbb")`，从 `ptr=2` 起连收 `"bbbbb"`、`"ccccc"`，`ptr` 跳到 4，`buf[4]` 空停。

```python
def insert(self, id, value):
    self.buf[id] = value
    res = []
    while self.buf[self.ptr] is not None:
        res.append(self.buf[self.ptr])
        self.ptr += 1
    return res
```

注意 `buf` 开 n+2 而不是 n+1：ptr 最多推进到 n+1，`while` 会去读 `buf[n+1]`，多留一格才不会越界。

## 复杂度
时间：每次 insert 的 while 均摊 O(1)，ptr 总共只前进 n 次，n 次调用合计 O(n)。
空间：`buf` 开 n+2 个槽，O(n)，没有额外的哈希表。

## 易错点
- 数组只开 n+1 个槽（下标 0..n）→ 当 id=1..n 全部到齐，ptr 推到 n+1 时 `buf[n+1]` 越界报错 → 开 n+2，或循环条件写成 `ptr <= n and buf[ptr] is not None`。
- 把「返回最长连续序列」理解成「每次从 1 重新扫」→ 示例里插入 `(2,"bbbbb")` 会重复返回 `"aaaaa"`，输出变成 `["aaaaa","bbbbb","ccccc"]` → ptr 是单调不回退的游标，只从当前位置往后扫，已返回过的 id 不再碰。

## 如果面试官追问
问：id 范围不是 1..n 而是任意大整数怎么办？
答：换成 `dict` 存 `id -> value`，ptr 从 1 起查字典，命中就删键并前进，逻辑不变。
