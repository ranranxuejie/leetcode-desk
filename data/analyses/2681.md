## 一句话思路
排序后枚举最大值，用前缀和把「以 nums[i] 为最大值的所有子集」的 min 之和一次算出来。

## 怎么做
1. 升序排序，这样任何子集的最大值就是下标最大的那个元素，最小值是下标最小的。
2. 枚举 nums[i] 作为子集最大值：子集其余元素只能从 nums[0..i-1] 里选，min 由「选中的最小下标 j」决定。
3. 对固定 j，j 必选、j+1..i-1 任选，共 2^(i-1-j) 种，贡献 nums[j] * 2^(i-1-j)；把 j 从 0 到 i-1 累加，再乘 nums[i]^2。
4. 维护前缀和 s = Σ nums[j] * 2^(i-1-j)，递推 s = s * 2 + nums[i]，答案累加 nums[i]^2 * s。

以 nums = [2,1,4] 排序得 [1,2,4] 为例：i=0 时 s=0，ans += 1*1*1=1，随后 s=1；i=1 时 ans += 4*1=4，s=1*2+2=4；i=2 时 ans += 16*4=64，s=4*2+4=12，累计 1+4+64=69？注意单元素子集要单独算：i=0 的 s 应为 nums[0] 本身，故初始化 s=0 后先 ans += nums[i]^3 再 ans += nums[i]^2 * s，最后 s = s*2 + nums[i]。

```python
MOD = 10**9 + 7
nums.sort()
ans = 0
s = 0  # sum of nums[j] * 2^(i-1-j)
for x in nums:
    ans = (ans + x * x % MOD * x + x * x % MOD * s) % MOD
    s = (s * 2 + x) % MOD
return ans
```

## 复杂度
时间 O(n log n)：排序贡献 log n，单次线性扫描贡献 n。
空间 O(1)：只开 ans、s 两个变量（排序原地）。

## 易错点
- 单元素子集：若只写 `ans += x*x*s`，i=0 时 s=0 会漏掉 nums[0]^3，示例 [2,1,4] 会得 68 而非 141。必须单独加 `x*x*x`。
- 取模时机：`s*2 + x` 中 x 可达 1e9，若先累加再取模，s 会膨胀到 2^1e5 量级；每步都对 s 和 ans 取模，且 `x*x%MOD*x` 要分步乘，否则中间值过大拖慢运算。

## 如果面试官追问
若要求输出每个子集而非只求和？答：前缀和思路失效，需按最大值分组回溯枚举，复杂度退化到 O(2^n)，只能加剪枝。
