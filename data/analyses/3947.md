## 一句话思路
按价格从低到高贪心购买，每买一个就记一次「免费额度」，额度优先兑换最贵的可整除物品。

## 怎么做
1. 把 items 按 price 升序排序，维护 `bought` 计数和 `free` 额度（每买一件 +1）。
2. 从最便宜的开始买，能买就买，`budget -= price`，`bought += 1`，`free += 1`。
3. 每买一件后，用 `free` 额度去兑换当前最贵的、factor 能被已购物品整除的物品，兑换成功则 `free -= 1`，`total += 1`。
4. 最终返回 `bought + 免费数`。

以示例 1 为例：items 排序后为 `[[2,4],[3,5],[1,6]]`。先买 `[2,4]`，budget=15，bought=1，free=1；再买 `[3,5]`，budget=10，bought=2，free=2；此时 free=2 可兑换 `[1,6]`（factor 1 能被 2 和 3 整除），免费得 1 件，total=3。继续买 `[1,6]`，budget=4，bought=3，free=1，再兑换一件，total=5。

```python
items.sort(key=lambda x: x[1])
bought = free = 0
for f, p in items:
    if budget >= p:
        budget -= p
        bought += 1
        free += 1
# 用 free 额度兑换最贵的可整除物品
for f, p in sorted(items, key=lambda x: -x[1]):
    if free > 0 and any(f % bf == 0 for bf, _ in bought_items):
        free -= 1
        bought += 1
return bought
```

## 复杂度
时间：排序 O(n log n)，兑换扫描 O(n²) 最坏，n 为 items 长度。
空间：O(n) 存已购物品列表，堆/排序额外开销。

## 易错点
1. 输入 `[[1,6],[2,4],[3,5]]`，budget=19 → 若先买贵的 `[1,6]` 再买 `[2,4]`，剩余 9 买不了 `[3,5]`，只能得 4 件；正确做法是按价格升序买，先买 `[2,4]` 和 `[3,5]` 腾出额度。
2. 输入 `[[2,8],[1,10],[6,6],[4,12],[5,20],[5,17]]`，budget=35 → 若兑换时随便挑一件可整除的（如先兑 `[4,12]`），可能浪费额度在便宜物品上；正确做法是优先兑换最贵的可整除物品，把便宜额度留给更贵的。

## 如果面试官追问
若 budget 扩大到 10^18 且 items 长度不变，贪心策略还成立吗？答：成立，因为每件物品单价固定，买最便宜的永远最优，只需把循环改成批量购买 `budget // price` 件。
