## 一句话思路
相邻异或为 0 等价于两数相等，所以只需把每段连续相同值压成 1 个，答案就是 n 减去压缩后长度。

## 怎么做
1. 遍历 `nums`，维护 `keep = 1`（第一个元素一定保留）和 `prev = nums[0]`。
2. 对每个 `x`，若 `x != prev` 则 `keep += 1` 并更新 `prev = x`；相等就跳过（删掉它）。
3. 返回 `len(nums) - keep`。

以 `nums = [1,1,2,2,2,3]` 为例：`prev` 依次为 1→1（跳过）→2（keep=2）→2（跳过）→2（跳过）→3（keep=3），最终 `keep=3`，答案 `6-3=3`。关键中间值：`keep` 只在值变化时加 1，所以连续三个 2 只贡献一次。

```python
keep = 1
prev = nums[0]
for x in nums[1:]:
    if x != prev:
        keep += 1
        prev = x
return len(nums) - keep
```

为什么成立：`a[i] XOR a[i+1] == 0` 当且仅当 `a[i] == a[i+1]`。若原数组相邻两数不同，无需删除；若相同，删掉其中一个即可让它们不再相邻。连续 k 个相同值只需保留 1 个，删 k-1 个，且不同值段之间天然异或非零，所以按段压缩是最优的，不存在「删中间某个值反而更省」的情况。

## 复杂度
时间 O(n)：一次遍历 `nums`，n 为数组长度。
空间 O(1)：只开了 `keep`、`prev` 两个变量。

## 易错点
- 输入 `[4,4,9,4]` → 若误以为要删掉所有重复值（把 4 全删）会得 2，正确是只删相邻重复中的一个，得 1，因为首尾两个 4 不相邻，`4 XOR 9 != 0`。
- 输入 `[1,1,1]` → 若用「统计每个值出现次数减 1 再求和」会得 2，正确也是 2，但换成 `[1,1,2,1]` 这种写法会得 2 而正确是 1（只删第二个 1），必须按「相邻段」而非「全局频次」计数。

## 如果面试官追问
若要求输出删除后的数组而非次数？答：同样按段压缩，保留每段第一个元素，其余丢弃，顺序自然保持。
