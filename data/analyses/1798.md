## 一句话思路
把 coins 升序排序后维护「当前能连续构造到 reach」，只要下一枚硬币 ≤ reach+1 就能把区间无缝接上，否则断档。

## 怎么做
1. 先对 coins 排序，让硬币从小到大逐个接入。
2. 设 reach 表示当前能连续构造出 [0, reach] 全部整数，初值 0。
3. 遍历每枚硬币 c：若 c > reach + 1，说明 reach+1 这个值永远补不上，直接 break。
4. 否则 reach += c，区间扩展为 [0, reach+c]。

以示例 2 的 `coins = [1,1,1,4]` 为例：reach 依次变成 1、2、3；处理 4 时判断 `4 <= 3+1` 成立，reach 变成 7，答案 `reach+1 = 8`。若换成示例 1 的 `[1,3]`，reach 到 1 后判断 `3 > 1+1`，立即 break，返回 2。

```python
coins.sort()
reach = 0
for c in coins:
    if c > reach + 1:
        break
    reach += c
return reach + 1
```

关键在 `c > reach + 1` 这个判断：等于 reach+1 时必须继续，因为新硬币恰好补上缺口，区间从 [0, reach] 变成 [0, reach+c] 仍然连续。

## 复杂度
时间：排序 O(n log n) 主导，遍历 O(n)。
空间：排序额外 O(log n)（Python 的 Timsort 栈），其余只有 reach 一个变量。

## 易错点
- 把判断写成 `c > reach` 而不是 `c > reach + 1`：输入 `[1,1]` 时第二枚 1 会被误判为断档，返回 2，正确是 3（0,1,2 都能构造）。
- 忘记排序直接按原顺序累加：输入 `[3,1]` 时先看 3 > 0+1 就 break，返回 1，正确应先排成 `[1,3]` 得 2。硬币顺序不影响可达集合，但贪心的正确性依赖升序。

## 如果面试官追问
问：如果要求返回具体构造方案而不只是个数？
答：reach 扩展时记录每枚被采纳的硬币，对目标 x 从大到小贪心取不超过剩余值的硬币即可还原。
