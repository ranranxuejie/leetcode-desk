## 一句话思路
用读指针 `i` 扫描分组、写指针 `w` 原地落笔，因为压缩后长度必不超过原长，写指针永远追不上读指针。

## 怎么做
1. 初始化 `w = 0`，`i = 0`，外层 `while i < len(chars)` 每次处理一整组。
2. 记 `ch = chars[i]`，内层 `j = i` 一路右移直到 `chars[j] != ch`，组长为 `j - i`。
3. 先写字符 `chars[w] = ch; w += 1`；若 `j - i > 1`，把 `str(j - i)` 的每个字符依次写进 `chars[w]`。
4. `i = j` 进入下一组，循环结束返回 `w`。

以示例 3 的 `["a","b","b",...]`（共 13 个元素，1 个 a + 12 个 b）为例：第一组 `i=0, j=1`，组长 1，只写 `chars[0]='a'`，`w=1`；第二组 `i=1`，`j` 扫到 13，组长 12，写 `chars[1]='b'` 后 `w=2`，再写 `"12"` 得 `chars[2]='1'`、`chars[3]='2'`，`w=4`，返回 4。

```python
w = 0
i = 0
n = len(chars)
while i < n:
    ch = chars[i]
    j = i
    while j < n and chars[j] == ch:
        j += 1
    chars[w] = ch
    w += 1
    if j - i > 1:
        for d in str(j - i):
            chars[w] = d
            w += 1
    i = j
return w
```

关键点：`str(j - i)` 天然把 12 拆成 `'1'`、`'2'` 两个字符，不用自己算位数；写指针 `w` 只增不减，且 `w <= i` 恒成立，所以覆盖不会污染还没读的数据。

## 复杂度
时间 O(n)：`i` 和 `j` 各单调右移，总移动次数不超过 2n。
空间 O(1)：只用了 `w`、`i`、`j`、`ch` 几个标量，`str(j - i)` 长度是 O(log n) 但受 n ≤ 2000 限制为常数级。

## 易错点
- 组长为 1 时误写数字：输入 `["a"]` 若不加 `if j - i > 1` 判断，会写成 `["a","1"]` 返回 2，正确是只写字符返回 1。
- 组长 ≥ 10 时当成单个字符写：输入 12 个 `"b"` 若写 `chars[w] = str(12)` 会抛类型错误或只落一个字符，正确是遍历 `str(j - i)` 的每个字符逐个写入，得到 `'1'`、`'2'` 两个位置。

## 如果面试官追问
问：若要求返回压缩后的字符串而非原地改数组？答：去掉写指针，用列表 `res` 追加 `ch` 和 `str(cnt)`，最后 `"".join(res)`，空间变 O(n)。
