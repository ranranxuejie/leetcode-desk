## 一句话思路
用数位 DP 求 `f(x)` = [1, x] 内步进数个数，答案 = `f(high) - f(low-1)`，靠「上界 tight + 上一位数字」记忆化。

## 怎么做
1. 写 `f(s)`：从高位到低位枚举，状态为 `(pos, prev, tight, started)`，`started=False` 表示还没放非零位（前导零阶段）。
2. 未 started 时可继续跳过（保持 False），或放 `1..9` 中受 tight 限制的数字，转入 started。
3. started 后只能放 `prev-1` 或 `prev+1`（在 `0..9` 内且受 tight 限制）。
4. 记忆化只对 `tight=False` 缓存，key 用 `(pos, prev, started)`。

以 `low="90", high="101"` 为例：`f("101")` 中，走到 `pos=1, prev=1, tight=True` 时，下一位只能取 `0`（`prev-1`）或 `2`（`prev+1`），但 tight 限制上界是 `0`，故只有 `0` 可行，得到 `10`（长度 2 的步进数）——注意 `10` 本身合法，`101` 也合法。`f("89")` 再减，最终差为 2。

```python
MOD = 10**9 + 7
def f(s):
    n = len(s)
    from functools import lru_cache
    @lru_cache(None)
    def dfs(pos, prev, tight, started):
        if pos == n:
            return 1 if started else 0
        hi = int(s[pos]) if tight else 9
        res = 0
        for d in range(hi + 1):
            nt = tight and d == hi
            if not started:
                if d == 0:
                    res += dfs(pos + 1, -1, nt, False)
                else:
                    res += dfs(pos + 1, d, nt, True)
            elif abs(d - prev) == 1:
                res += dfs(pos + 1, d, nt, True)
        return res % MOD
    return dfs(0, -1, True, False)
```

`low-1` 用字符串减法：从末位借位，注意 `low="1"` 时结果为 `"0"`，`f("0")` 应返回 0（started 始终 False）。

## 复杂度
时间：`O(n * 10 * 2 * 2 * 10)`，n 为串长（≤100），常数级状态转移。
空间：记忆化表 `O(n * 11 * 2 * 2)`，递归栈 `O(n)`。

## 易错点
- `low="1"` 时 `low-1="0"`，若直接对 `"0"` 调 `f` 且未处理 started，会把 `0` 算成步进数 → 正确做法是 `f("0")` 返回 0，因为 `started` 全程 False，终态返回 0。
- `high="101"` 这类含 0 的数：若在 started 后错误允许 `prev=0` 时取 `-1`，会越界或漏算 `10` → 正确做法是 `abs(d-prev)==1` 且 `d` 在 `0..9`，`10` 中 `prev=1, d=0` 合法。

## 如果面试官追问
问：若 high 长度到 10^5 怎么办？
答：状态转移固定 10 个数字，可改成矩阵快速幂或直接按位递推，`O(n * 10)` 仍可行，记忆化表按位置滚动即可。
