## 一句话思路
用两个滚动变量记录「到上一家为止的最优」和「到上上家为止的最优」，每步取「接当前」与「不接当前」的较大者。

## 怎么做
1. 设 `prev2` 表示处理到 `i-2` 时的最优总时长，`prev1` 表示处理到 `i-1` 时的最优总时长，初始都为 0。
2. 遍历 `nums` 中每个 `x`，当前最优 `cur = max(prev1, prev2 + x)`：不接则继承 `prev1`，接则跳过相邻的 `prev1` 用 `prev2 + x`。
3. 每步后滚动：`prev2, prev1 = prev1, cur`。
4. 遍历结束返回 `prev1`。

以示例 2 `[2,7,9,3,1]` 为例，关键中间值：处理到 `9` 时 `prev2=2, prev1=7`，`cur = max(7, 2+9) = 11`；再处理 `3` 时 `prev2=7, prev1=11`，`cur = max(11, 7+3) = 11`；最后处理 `1` 时 `prev2=11, prev1=11`，`cur = max(11, 11+1) = 12`，返回 12。

```python
prev2 = prev1 = 0
for x in nums:
    cur = max(prev1, prev2 + x)
    prev2, prev1 = prev1, cur
return prev1
```

## 复杂度
时间 O(n)：一次遍历 `nums`，每个元素做一次 `max`。
空间 O(1)：只开 `prev2`、`prev1`、`cur` 三个变量，不建 dp 数组。

## 易错点
- 输入 `[2,7,9,3,1]` → 若把转移写成 `cur = max(prev1, prev2) + x`（误以为必须接）会得 19，正确是 `max(prev1, prev2 + x)` 得 12。
- 输入 `[1]` 或 `[]` → 若循环里先更新 `prev2` 再算 `cur`，单元素或空数组会返回 0 或错位；正确做法是先用旧 `prev2` 算 `cur`，再同时滚动 `prev2, prev1 = prev1, cur`。

## 如果面试官追问
要求输出具体选了哪些预约怎么办？答：把滚动变量换成 dp 数组，回溯时比较 `dp[i]` 与 `dp[i-1]`，不等则选 `i` 并跳到 `i-2`。
