## 一句话思路
排序后每个元素作为最小值/最大值的贡献只取决于它左右两侧能选多少元素，用组合数前缀和一次扫完。

## 怎么做
1. 先对 `nums` 升序排序，子序列顺序无关，排序不改变答案。
2. 对排序后下标 `i`，它作为**最小值**时，右侧 `n-1-i` 个元素中任选 `0..k-1` 个，贡献 `nums[i] * sum(C(n-1-i, j))`。
3. 它作为**最大值**时，左侧 `i` 个元素中任选 `0..k-1` 个，贡献 `nums[i] * sum(C(i, j))`。
4. 两者相加，对每个 `i` 累加，取模 `10**9+7`。

以 `nums=[1,2,3], k=2` 为例：排序后不变。`i=1`（值 2）作最小值时右侧 1 个元素，`sum(C(1,0..1))=2`，贡献 `2*2=4`；作最大值时左侧 1 个元素同样 `2`，贡献 `4`。三个下标累加得 `2+4+6`（单元素部分）加组合部分，最终 24。

```python
MOD = 10**9 + 7
n = len(nums)
nums.sort()
# 预处理组合数 C(i, j)，i 到 n，j 到 k-1
C = [[0] * k for _ in range(n + 1)]
for i in range(n + 1):
    C[i][0] = 1
    for j in range(1, min(i, k - 1) + 1):
        C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD
# 前缀和 pre[i] = sum_{j=0}^{k-1} C(i, j)
pre = [sum(row) % MOD for row in C]
ans = 0
for i, x in enumerate(nums):
    ans = (ans + x * pre[n-1-i] + x * pre[i]) % MOD
```

## 复杂度
时间：排序 `O(n log n)`，组合数表 `O(nk)`，扫描 `O(n)`，`k ≤ 100`。
空间：`O(nk)` 存组合数表，`pre` 数组 `O(n)`。

## 易错点
- `k` 大于 `n` 时，`C(i, j)` 中 `j` 超过 `i` 的部分为 0，代码里 `min(i, k-1)` 已截断；若直接写 `range(k)` 会越界或读到脏值，导致 `pre[i]` 偏大。
- 单元素子序列被算了两次：作最小值时 `j=0` 选空集、作最大值时也选空集，各贡献一次 `nums[i]`，正好是题面要求的「最小值+最大值=2×元素」，别以为重复而减掉一次。

## 如果面试官追问
若 `k` 可达 `n`（10^5），`O(nk)` 组合数表会爆，怎么改？答：用 `2^(n-1-i)` 直接替代 `pre`，因为 `k=n` 时全选，贡献退化为幂次，`O(n)` 预处理即可。
