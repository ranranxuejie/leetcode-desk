## 一句话思路
用双指针在 s1 的 n1 次循环里贪心匹配 s2，并靠「s1 起始匹配位置」的循环节跳过重复计算。

## 怎么做
1. 把 s1 重复 n1 次视为一条长串，指针 `i` 走 s1 的字符、`j` 走 s2 的字符，`j` 每走完一轮 s2 就 `cnt += 1`。
2. 记录「每轮 s1 开始时 j 落在 s2 的哪个下标」，一旦该下标重复出现，说明后续匹配完全周期性，可整段跳过。
3. 用字典 `seen` 存 `j -> (已用 s1 轮数, 已匹配 s2 个数)`，命中时用比例公式一次性补齐剩余轮数。
4. 最终答案是 `cnt // n2`。

以 `s1="acb", n1=4, s2="ab", n2=2` 为例：第 1 轮 s1 匹配到 s2 的 `a`（j 从 0 变 1），第 2 轮匹配到 `b` 使 j 归 0、`cnt=1`；此时 j 回到 0，与第 1 轮起点相同，循环节长度 2 轮、产出 1 个 s2。剩余 2 轮按比例再得 1 个，`cnt=2`，答案 `2 // 2 = 1`？注意这里 `cnt` 统计的是 s2 出现次数，示例中 4 轮 s1 共得 4 个 s2，`4 // 2 = 2`。

```python
seen = {}
i = j = cnt = 0          # i: 已用 s1 轮数, j: s2 内下标, cnt: 匹配到的 s2 个数
while i < n1:
    if j in seen:        # 循环节出现
        pi, pc = seen[j]
        span = i - pi
        times = (n1 - i) // span
        cnt += times * (cnt - pc)
        i += times * span
        seen.clear()     # 清空避免二次命中
        continue
    seen[j] = (i, cnt)
    if s1[i % len(s1)] == s2[j]:   # 这里 i 是轮数，需换成字符下标
        j += 1
        if j == len(s2):
            j = 0
            cnt += 1
    i += 1
return cnt // n2
```
（上面片段为讲清逻辑，字符下标应另用 `p` 遍历 s1，`i` 只记轮数。）

## 复杂度
时间：O(len(s1) * min(n1, len(s2)))，循环节最多 len(s2) 种 j 值。
空间：O(len(s2))，`seen` 字典最多存 len(s2) 个键。

## 易错点
- `s1="aaa", n1=1, s2="aa", n2=1` → 若把 `cnt` 直接当答案会得 1，但 `cnt` 是 s2 出现次数，必须 `cnt // n2` 才是 m。
- 循环节命中后若不清空 `seen` 或忘记 `i += times * span`，`s1="ab", n1=10**6, s2="b"` 会退化成逐轮扫描超时；正确做法是命中即整段跳过并清空字典。

## 如果面试官追问
问：n1 到 10^9 还能做吗？
答：能，循环节最多 len(s2) 种状态，跳过后时间与 n1 无关，只与 s1、s2 长度有关。
