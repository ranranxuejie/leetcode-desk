## 一句话思路
先判 `len(original) == m * n`，成立就按每 `n` 个元素切片拼行，不成立直接返回 `[]`。

## 怎么做
1. 用 `m * n` 与 `len(original)` 比较，不等就返回 `[]`（示例 3：`2 != 1*1`，返回 `[]`）。
2. 相等时循环 `i` 从 `0` 到 `m-1`，每轮取 `original[i*n : i*n+n]` 作为第 `i` 行。
3. 把每行 append 进结果列表返回。

以示例 1 为例：`original = [1,2,3,4], m = 2, n = 2`，`m*n = 4` 等于长度，通过校验。`i=0` 时切片 `original[0:2]` 得到 `[1,2]`；`i=1` 时切片 `original[2:4]` 得到 `[3,4]`，拼成 `[[1,2],[3,4]]`。关键中间量是每轮的起点 `i*n`：`0` 和 `2`，正好是行首下标。

```python
if m * n != len(original):
    return []
res = []
for i in range(m):
    res.append(original[i * n : i * n + n])
return res
```

切片右端 `i*n+n` 在最后一行恰好等于 `len(original)`，Python 切片越界不报错，但这里根本不会越界，因为长度已校验过。也可以写成 `original[i*n:(i+1)*n]`，两者等价，后者更直观地表达「第 i 行的 n 个元素」。

## 复杂度
时间 O(m·n)：每个元素被切片复制一次，共 `len(original)` 个。
空间 O(m·n)：结果二维数组存了全部元素，切片本身也是新列表。

## 易错点
- 输入 `original = [1,2], m = 1, n = 1` → 若跳过长度校验直接切片，会得到 `[[1]]`，丢掉元素 `2` 却仍返回非空 → 必须先判 `m*n != len(original)` 返回 `[]`。
- 输入 `original = [3], m = 1, n = 2` → 若用 `range(0, len(original), n)` 按数据长度分行，只会切出 `[[3]]`，行数不足 `m` → 循环上界必须是 `m`，不是 `len(original)//n`。

## 如果面试官追问
问：若 `original` 是流式输入、不能整体持有怎么办？
答：边读边攒满 `n` 个就 flush 成一行，最后校验总个数是否恰为 `m*n`，空间降到 O(n)。
