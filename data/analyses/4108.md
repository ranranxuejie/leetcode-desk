## 一句话思路
树形 DP：对每个节点算「子树内红色已连通 / 未连通」两态的最小代价，翻转代价就是子树大小。

## 怎么做
1. 后序 DFS 求每个节点子树大小 `sz[u]`，翻转 `u` 的代价就是 `sz[u]`。
2. 设 `dp[u][1]` = 子树内红色已连成一块且含 `u` 的最小代价，`dp[u][0]` = 子树内无红或红块不含 `u` 的最小代价。
3. 合并子节点 `v`：若 `u` 保持红，`v` 的红块必须接到 `u` 上，否则 `v` 侧的红要翻蓝；若 `u` 翻蓝，则 `v` 侧红块不能连到 `u`。
4. 答案取根节点两态最小值。

以示例 3 `n=4, colors="BRRR", edges=[[0,1],[0,2],[0,3]]` 为例：`sz[1]=sz[2]=sz[3]=1`，`sz[0]=4`。三个叶子都是红，根是蓝。合并时根保持蓝，每个红叶子的红块若保留则必须独立，最终只能保留一个红叶子，另外两个翻蓝，代价 `1+1=2`。

```python
def dfs(u, p):
    sz[u] = 1
    for v in g[u]:
        if v != p:
            dfs(v, u)
            sz[u] += sz[v]
    # dp[u][0]: 无红块 / 红块不含 u；dp[u][1]: 红块含 u
    dp[u][0] = 0 if colors[u] == 'B' else sz[u]
    dp[u][1] = 0 if colors[u] == 'R' else sz[u]
    for v in g[u]:
        if v == p: continue
        # u 红：v 红块必须接上，否则翻蓝
        dp[u][1] += min(dp[v][1], dp[v][0] + sz[v])
        # u 蓝：v 红块不能接上
        dp[u][0] += min(dp[v][0], dp[v][1] + sz[v])
```

## 复杂度
时间 O(n)：每个节点合并一次子节点，边遍历一次。
空间 O(n)：邻接表、`sz`、`dp` 各开 n 个。

## 易错点
- 输入 `colors="RBR", edges=[[0,1],[1,2]]`：若只把「红块不含 u」当成无红，会漏掉「子树内已有红块但不含 u」的合法状态，导致根为蓝时误判。正确做法是 `dp[u][0]` 同时容纳「无红」和「红块不含 u」两种情形。
- 输入 `colors="BBB"`：若初始化 `dp[u][1]=sz[u]` 后不检查根，可能返回非零。正确做法是根为蓝时答案取 `min(dp[0][0], dp[0][1])`，全蓝时 `dp[0][0]=0` 直接命中。

## 如果面试官追问
问：要求输出具体翻转方案怎么办？
答：在 DP 里记录每个子节点选的是「接上」还是「翻蓝」，回溯时按选择收集被翻的节点即可。
