## 一句话思路
把下标整体右移 k 位再对 n 取模，用切片拼接一次成型，O(n) 完成。

## 怎么做
1. 记 `n = len(s)`，先算 `k %= n`，把 k 压到 `[0, n)` 内，避免无谓的整圈旋转。
2. 加密后第 i 位来自原串第 `(i + k) % n` 位，等价于把原串左移 k 位。
3. 用 `s[k:] + s[:k]` 直接拼出结果，无需逐字符循环。
4. 以 `s = "dart", k = 3` 为例：`n = 4`，`k % 4 = 3`，`s[3:] = "t"`，`s[:3] = "dar"`，拼接得 `"tdar"`，与示例一致。

```python
n = len(s)
k %= n
return s[k:] + s[:k]
```

关键中间值：`s[3:]` 是 `"t"`，`s[:3]` 是 `"dar"`，拼起来正好是 `"tdar"`。注意方向：是「原串第 i+k 位搬到第 i 位」，所以切点在 k，不是 n-k。

## 复杂度
时间：O(n)，切片和拼接各扫一遍 s，n 为字符串长度。
空间：O(n)，`s[k:]` 与 `s[:k]` 两个临时串合计 n 个字符。

## 易错点
- `k` 大于 `n` 时（如 `s = "abc", k = 10000`）→ 若直接用 `s[k:] + s[:k]`，`s[10000:]` 是空串、`s[:10000]` 是整串，结果变成原串没动 → 必须先 `k %= n` 再切。
- 切点方向搞反（如 `s = "dart", k = 3`）→ 写成 `s[n-k:] + s[:n-k]` 得 `"rtda"`，与 `"tdar"` 不符 → 记住是左移 k 位，切点在 `k`，即 `s[k:] + s[:k]`。

## 如果面试官追问
若 k 可达 10^18 且要求原地修改？答：`k %= n` 后仍是循环左移，用三次反转（整体、前 n-k、后 k）即可 O(1) 额外空间。
