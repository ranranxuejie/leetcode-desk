## 一句话思路
统计每个值出现次数，全为偶数即可配对，因为每个数对必须由两个相同值组成。

## 怎么做
1. 用 `Counter(nums)` 统计每个值出现次数。
2. 遍历计数值，只要有一个是奇数就返回 `False`。
3. 全部为偶数则返回 `True`。

以 `nums = [3,2,3,2,2,2]` 为例，计数得 `{3:2, 2:4}`，两个值都是偶数，返回 `True`。若换成 `[1,2,3,4]`，计数为 `{1:1,2:1,3:1,4:1}`，第一个 `1` 就是奇数，立即返回 `False`。

```python
from collections import Counter

def divideArray(nums):
    cnt = Counter(nums)
    for v in cnt.values():
        if v % 2 == 1:
            return False
    return True
```

也可以一行：`return all(v % 2 == 0 for v in Counter(nums).values())`。

## 复杂度
时间：O(n)，遍历 nums 建计数表一次，再遍历不同值。
空间：O(k)，k 为不同值个数，最坏 O(n)。

## 易错点
1. 输入 `[1,1,2]` 长度为奇数 → 会误以为只需检查计数，实际题面保证长度是 `2*n`，但若自己加校验，应先判 `len(nums) % 2`，否则 `[1,1,2]` 计数 `{1:2,2:1}` 会因 `2:1` 返回 `False`，逻辑碰巧对但原因错；正确做法是依赖题面长度约束，只查计数奇偶。
2. 输入 `[1,1,1,1]` → 计数 `{1:4}` 是偶数，返回 `True`，正确；但若误写成「每个值出现次数必须等于 2」会返回 `False`；正确做法是判断 `v % 2 == 0` 而非 `v == 2`。

## 如果面试官追问
问：若要求返回具体配对方案而非布尔值？答：对每个值取 `v // 2` 对 `(x, x)` 依次输出即可，计数为奇数时返回空列表。
