## 一句话思路
把 documents 当作哈希表用：把每个 id 交换到下标等于它的位置，撞到已就位的相同 id 即为副本。

## 怎么做
1. 遍历下标 i，当 `documents[i] != i` 时进入交换循环。
2. 若 `documents[documents[i]] == documents[i]`，说明目标位置已有同值，直接返回该值。
3. 否则交换 `documents[i]` 与 `documents[documents[i]]`，把当前值送到它的「家」。
4. 全部就位仍无冲突则返回 -1（本题保证有副本，实际不会走到）。

以 `documents = [2, 5, 3, 0, 5, 0]` 为例：i=0 时 `documents[0]=2`，目标位 `documents[2]=3` 不等，交换后数组变 `[3, 5, 2, 0, 5, 0]`；继续 i=0，`documents[0]=3`，目标位 `documents[3]=0` 不等，交换得 `[0, 5, 2, 3, 5, 0]`，此时 i=0 就位。走到 i=1 时 `documents[1]=5`，目标位 `documents[5]=0` 不等，交换得 `[0, 0, 2, 3, 5, 5]`；再判 `documents[1]=0`，目标位 `documents[0]=0` 相等，返回 0。

```python
for i in range(len(documents)):
    while documents[i] != i:
        j = documents[i]
        if documents[j] == j:
            return j
        documents[i], documents[j] = documents[j], documents[i]
return -1
```

关键中间值：i=1 交换后 `documents[0]` 与 `documents[1]` 同为 0，`documents[j] == j` 成立，命中返回。

## 复杂度
时间：O(n)，每个值最多被交换到正确位置一次，while 总次数不超过 n。
空间：O(1)，只在原数组上交换，没有额外开哈希表或计数数组。

## 易错点
- 输入 `[2, 5, 3, 0, 5, 0]` 若先排序再找相邻相等，返回的是排序后第一个重复值，可能不是原数组中「先出现」的那个；本题允许返回任一，但排序是 O(n log n)，白丢分。正确做法是原地交换，O(n) 且不改语义。
- 交换时写成 `documents[i], documents[documents[i]] = ...` 会因右侧先求值、左侧赋值顺序导致下标错位；必须先存 `j = documents[i]` 再用 `j` 做交换，否则 `[0, 5, 2, 3, 5, 0]` 这类输入会死循环或越界。

## 如果面试官追问
问：不允许修改原数组怎么办？
答：用快慢指针找环入口，值当 next 指针，O(n) 时间 O(1) 空间，但要求值域在 `[0, n-1]` 内。
