## 一句话思路
把边界并入栅栏坐标后，枚举所有两两间距，用哈希表求水平与垂直间距的交集，取最大公共边长的平方。

## 怎么做
1. 把 `1` 和 `m` 加入 `hFences`，`1` 和 `n` 加入 `vFences`，排序后得到全部可选边界位置。
2. 双重循环枚举所有 `(i, j)` 对，把间距 `pos[j] - pos[i]` 存入集合 `hs` 和 `vs`。
3. 遍历较小的集合，若间距也在另一集合中，用 `side * side` 更新答案。
4. 无交集返回 `-1`，否则返回 `ans % (10**9 + 7)`。

以示例 1 为例：`hFences` 排序后为 `[1,2,3,4]`，间距集合 `hs = {1,2,3}`；`vFences` 排序后为 `[1,2,3]`，间距集合 `vs = {1,2}`。交集 `{1,2}` 中最大为 `2`，面积 `2*2 = 4`。

```python
hs, vs = set(), set()
h = sorted(hFences + [1, m])
v = sorted(vFences + [1, n])
for i in range(len(h)):
    for j in range(i + 1, len(h)):
        hs.add(h[j] - h[i])
for i in range(len(v)):
    for j in range(i + 1, len(v)):
        vs.add(v[j] - v[i])
ans = -1
for side in hs:
    if side in vs:
        ans = max(ans, side * side)
return ans % (10**9 + 7) if ans != -1 else -1
```

关键中间值：`h = [1,2,3,4]`，`hs` 含 `3`（来自 `4-1`），但 `vs` 最大只有 `2`，所以边长 `3` 被排除，最终取 `2`。

## 复杂度
时间：O(H² + V²)，H、V 为加入边界后的栅栏数，各约 602。
空间：O(H² + V²)，两个间距集合各存至多约 18 万个整数。

## 易错点
- 忘记把 `1` 和 `m`（或 `n`）加入坐标数组 → 示例 1 中 `hs` 会漏掉 `4-1=3` 和 `3-1=2`，交集变小甚至为空 → 必须先 `hFences + [1, m]` 再排序。
- 用 `hFences` 原数组直接双重循环算间距 → 会漏掉「从边界 1 到某栅栏」和「某栅栏到边界 m」的间距，示例 1 中 `vs` 会漏掉 `3-1=2`，答案错成 `1` → 边界必须作为坐标参与枚举。

## 如果面试官追问
问：若要求输出具体移除哪些栅栏而非仅面积？
答：在哈希表里存 `间距 -> (i, j)` 的下标对，取到最大公共边长后反查两组下标，移除区间外的栅栏即可。
