## 一句话思路
把 `primeFactors` 拆成尽量多的 3，余 1 时退一个 3 换成 2+2，快速幂取模。

## 怎么做
1. 好因子数等于 n 各质因数指数加一连乘，即 `∏(e_i+1)`；在 `∑e_i ≤ primeFactors` 约束下，把指数拆成 3 最优（2 和 4 等价于两个 2，5 不如 3+2）。
2. 按 `primeFactors % 3` 分三种情况：余 0 全取 3；余 1 取一个 4（即 2×2）剩下全 3；余 2 取一个 2 剩下全 3。
3. 用快速幂算 `3**k % (10**9+7)`，再乘上那个 2 或 4。

以 `primeFactors = 5` 为例：`5 % 3 == 2`，先取一个 2，剩 `k = (5-2)//3 = 1`，答案 `2 * 3**1 = 6`，与示例一致。若 `primeFactors = 4`，`4 % 3 == 1`，取 4，剩 `k = (4-4)//3 = 0`，答案 `4 * 3**0 = 4`（对应 n=2·2·3·3 之类，好因子 4 个）。

```python
MOD = 10**9 + 7
def qpow(b, e):
    r = 1
    while e:
        if e & 1:
            r = r * b % MOD
        b = b * b % MOD
        e >>= 1
    return r

if primeFactors == 1:
    ans = 1
elif primeFactors % 3 == 0:
    ans = qpow(3, primeFactors // 3)
elif primeFactors % 3 == 1:
    ans = 4 * qpow(3, (primeFactors - 4) // 3) % MOD
else:
    ans = 2 * qpow(3, (primeFactors - 2) // 3) % MOD
```

## 复杂度
时间：快速幂 O(log primeFactors)，循环次数由指数 `k ≈ primeFactors/3` 的二进制位数决定。
空间：O(1)，只存 `r`、`b`、`e` 三个整数，无额外数组。

## 易错点
- `primeFactors = 1` → 若直接走 `% 3 == 1` 分支会算 `(1-4)//3 = -1`，快速幂死循环或结果错 → 必须单独返回 1（n 取质数，好因子只有它自己）。
- `primeFactors = 2` 或 `3` → 若写成「余 1 就减 4」会得到负数指数 → 余 1 分支只在 `primeFactors >= 4` 时成立，2、3 分别直接返回 2、3。

## 如果面试官追问
问：若要求输出具体的 n 而不只是数目？答：把每个 3 分配给不同质数（如 2³·3³…），余下的 2 或 4 再各分配一个指数，构造即得。
