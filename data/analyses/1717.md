## 一句话思路
先贪心删分值高的那种对，再用栈扫一遍删剩下的，因为高分的先删不会让低分的变少。

## 怎么做
1. 若 `x < y`，交换 `x, y` 并把 `a`/`b` 对调，保证先删的永远是 `"ab"`。
2. 用栈扫 `s`：遇 `'b'` 且栈顶是 `'a'` 就弹出并加 `x`，否则入栈。
3. 把栈里剩下的字符拼成新串，再扫一遍删 `"ba"`，每删一个加 `y`。

拿示例 1 的 `s = "cdbcbbaaabab"`、`x=4, y=5` 来说，先交换成 `x=5` 删 `"ba"`、`y=4` 删 `"ab"`。第一遍栈扫到末尾时，`"cdbcbbaaabab"` 里连续弹出 3 次 `"ba"`，得分 15，栈剩 `"cdbcba"`；第二遍再删 1 个 `"ab"` 得 4，合计 19。

```python
def gain(t, p, q):          # 先删 p 分的那种对
    st, sc = [], 0
    for c in t:
        if c == 'b' and st and st[-1] == 'a':
            st.pop(); sc += p
        else:
            st.append(c)
    return ''.join(st), sc

if x < y:
    x, y = y, x
    s = s.translate(str.maketrans('ab', 'ba'))
s, s1 = gain(s, x, 0)
_, s2 = gain(s, y, 0)
return s1 + s2
```

## 复杂度
时间 O(n)：两遍栈扫各走一次，`n = len(s)`。
空间 O(n)：栈最坏存下整个串。

## 易错点
- 输入 `s = "ab"`、`x=1, y=100`：若直接按题面顺序先删 `"ab"`，只得 1 分；正确做法是先比较 `x` 和 `y`，把高分对换到前面，答案应是 100。
- 输入 `s = "aabbaa"`、`x=3, y=2`：若第一遍删 `"ab"` 时把中间的 `"bb"` 当成阻断就提前收手，会漏掉后面 `"aa"` 与 `"bb"` 重组出的新对；正确做法是让栈自然把 `"bb"` 留下、`"aa"` 压栈，第二遍才能继续配对。

## 如果面试官追问
问：如果要求输出删除顺序而不只是分数？
答：在栈里存 `(字符, 原下标)`，每次弹出时记录这对下标，两遍扫完按下标序列输出即可。
