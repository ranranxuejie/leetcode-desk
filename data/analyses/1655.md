## 一句话思路
把 nums 压成「每个值出现次数」的频次表，对顾客做位掩码 DP，逐个值决定它喂给哪些未满足的顾客。

## 怎么做
1. 用 `Counter(nums)` 得到频次列表 `cnt`，`m = len(quantity)`，状态是 `1<<m` 个顾客子集。
2. `dp[mask]` 表示「已满足 mask 中顾客后，当前这个值还剩多少可用」；`-1` 表示该状态不可达。
3. 对 `cnt` 中每个值 `c`，从 `dp` 推出 `ndp`：对每个可达 mask，枚举未满足顾客的子集 `sub`，若 `sum(quantity[i] for i in sub) <= c` 则 `ndp[mask|sub] = max(..., c - 该和)`。
4. 全部值处理完，看 `dp[(1<<m)-1] >= 0`。

以示例 3 `nums=[1,1,2,2], quantity=[2,2]` 为例：`cnt=[2,2]`。第一个值 2 时，`dp[0]=2`，可喂顾客 0 或顾客 1，得 `dp[01]=0`、`dp[10]=0`；第二个值 2 时从 `dp[01]=0` 出发喂顾客 1 需 2，`2<=2` 成立，`dp[11]=0`，返回 `True`。

```python
from collections import Counter
cnt = list(Counter(nums).values())
m, full = len(quantity), (1 << len(quantity)) - 1
need = [0] * (1 << m)
for mask in range(1, 1 << m):
    low = mask & -mask
    i = low.bit_length() - 1
    need[mask] = need[mask ^ low] + quantity[i]
dp = [-1] * (1 << m)
dp[0] = 0
for c in cnt:
    ndp = [-1] * (1 << m)
    for mask in range(1 << m):
        if dp[mask] < 0:
            continue
        rest = full ^ mask
        sub = rest
        while True:
            if need[sub] <= c:
                ndp[mask | sub] = max(ndp[mask | sub], c - need[sub])
            if sub == 0:
                break
            sub = (sub - 1) & rest
    dp = ndp
return dp[full] >= 0
```

## 复杂度
时间：`O(50 * 3^m)`，每个值枚举子集对，`m<=10`；`n` 只贡献建 Counter 的 `O(n)`。
空间：`O(2^m)` 的 `dp`、`ndp`、`need` 三个数组，与 `n` 无关。

## 易错点
- `nums=[1,2,3,4], quantity=[2]`：若只比较「不同值个数 4 >= 顾客数 1」就返回 `True`，错；必须看单个值的频次，最大频次 1 < 2，正确返回 `False`。
- `quantity` 里有重复订单如 `[2,2]`：若按顾客下标去重或只枚举「值→一个顾客」，会漏掉两个顾客各拿一个值的情形；必须用位掩码区分顾客，`sub` 枚举的是顾客子集而非值。

## 如果面试官追问
要求输出具体分配方案怎么办？在 `ndp` 转移时额外记录 `(mask, sub)` 前驱，最后从 `full` 回溯每个值分给了哪些顾客即可。
