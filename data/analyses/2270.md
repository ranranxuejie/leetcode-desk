## 一句话思路
用前缀和 `pre` 边累加边与 `total - pre` 比较，一次遍历即可统计所有合法切点。

## 怎么做
1. 先求 `total = sum(nums)`，作为右侧和的基准。
2. 令 `pre = 0`，遍历 `i` 从 `0` 到 `n-2`（不含最后一个下标，保证右边非空）。
3. 每步 `pre += nums[i]`，判断 `pre >= total - pre`，成立则 `ans += 1`。
4. 返回 `ans`。

以 `nums = [10,4,-8,7]` 为例，`total = 13`：
- `i=0`：`pre=10`，右侧 `13-10=3`，`10>=3` 成立，`ans=1`；
- `i=1`：`pre=14`，右侧 `-1`，成立，`ans=2`；
- `i=2`：`pre=6`，右侧 `7`，`6>=7` 不成立，`ans` 仍为 2。

```python
total = sum(nums)
pre = ans = 0
for i in range(len(nums) - 1):
    pre += nums[i]
    if pre >= total - pre:
        ans += 1
return ans
```

关键点：`range(len(nums) - 1)` 天然排除了 `i = n-1`，不需要额外写 `if i < n-1`。

## 复杂度
时间：O(n)，一次求和加一次遍历，各扫 n 个元素。
空间：O(1)，只用了 `total`、`pre`、`ans` 三个变量。

## 易错点
- 循环写成 `range(len(nums))` → 会把 `i = n-1` 也算进去，此时右侧为空、`total - pre = 0`，若 `pre >= 0` 就多计一次，示例 1 会输出 3 而非 2 → 必须用 `range(len(nums) - 1)`。
- 用 `pre > total - pre` 而非 `>=` → 示例 2 的 `i=2`：`pre=6`、右侧 `0`，`6>=0` 成立但 `6>0` 也成立，看不出差别；换成 `nums=[1,1]`，`i=0` 时 `pre=1`、右侧 `1`，`>=` 应计 1 次，写成 `>` 会漏掉 → 题面是「大于等于」，必须用 `>=`。

## 如果面试官追问
问：要求输出所有合法切点下标而非计数，怎么改？
答：把 `ans += 1` 换成 `ans.append(i)`，其余不变，仍是 O(n) 时间、O(k) 额外空间（k 为方案数）。
