## 一句话思路
交替串只有两种：以 `'0'` 开头或以 `'1'` 开头，分别数出与 `s` 不同的位数，取较小值。

## 怎么做
1. 枚举两种目标串的起始字符 `start`（`'0'` 和 `'1'`）。
2. 遍历 `s`，第 `i` 位期望字符是 `str((int(start) + i) % 2)`，不等则计数加一。
3. 对两个计数取 `min` 返回。

以 `s = "0100"` 为例：`start='0'` 时目标 `"0101"`，只有 `i=3` 处 `'0' != '1'`，计数 1；`start='1'` 时目标 `"1010"`，四位全不同，计数 4。`min(1, 4) = 1`。

```python
def minOperations(s):
    n = len(s)
    diff0 = 0
    for i, ch in enumerate(s):
        expect = '0' if i % 2 == 0 else '1'
        if ch != expect:
            diff0 += 1
    return min(diff0, n - diff0)
```

关键点：`start='1'` 的计数恰好是 `n - diff0`，因为每一位要么匹配 `'0'` 开头要么匹配 `'1'` 开头，二者互补，所以只需扫一遍。

## 复杂度
时间：O(n)，`n = len(s)`，一次遍历。
空间：O(1)，只用了 `diff0` 一个计数器。

## 易错点
- 输入 `s = "1111"` → 只算 `start='0'` 得 4，忘记取 `min` 会错成 4 → 正确是 `min(4, 0) = 0`？不对，`start='1'` 目标 `"1010"`，`i=1` 和 `i=3` 处 `'1' != '0'`，计数 2，答案 `min(4, 2) = 2`。务必两个方向都算。
- 输入 `s = "0"`（长度 1）→ 误以为需要判断相邻对而返回 1 → 单字符天然交替，答案 0；代码里 `diff0 = 0`，`n - diff0 = 1`，`min` 得 0，正确。

## 如果面试官追问
问：如果要求返回具体的目标串而不只是次数？
答：记录 `diff0 <= n - diff0` 的布尔值，按对应 `start` 重建 `''.join(str((int(start)+i)%2) for i in range(n))`。
