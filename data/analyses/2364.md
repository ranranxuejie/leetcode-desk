## 一句话思路
把 `j - i != nums[j] - nums[i]` 变形为 `nums[i] - i != nums[j] - j`，用哈希表统计每个 `nums[i] - i` 出现次数，总数减去相等对即为坏对数。

## 怎么做
1. 总对数 = `n*(n-1)//2`，n 为数组长度。
2. 遍历时维护哈希表 `cnt`，键为 `nums[i] - i`，值为该差值已出现次数。
3. 对每个 i，把 `cnt[nums[i] - i]` 累加到 `good`（相等对数），再把该差值计数加一。
4. 返回 `total - good`。

以 `nums = [4,1,3,3]` 为例：i=0 差值 4，good=0，cnt={4:1}；i=1 差值 0，good=0，cnt={4:1,0:1}；i=2 差值 1，good=0，cnt 加 1:1；i=3 差值 0，good 累加 cnt[0]=1，cnt[0] 变 2。total=6，good=1，答案 5。

```python
n = len(nums)
total = n * (n - 1) // 2
cnt = {}
good = 0
for i, x in enumerate(nums):
    d = x - i
    good += cnt.get(d, 0)
    cnt[d] = cnt.get(d, 0) + 1
return total - good
```

关键中间值：i=3 时 `d = 3 - 3 = 0`，`cnt[0]` 此前为 1，good 从 0 变 1，最终 `6 - 1 = 5`。

## 复杂度
时间：O(n)，一次遍历，哈希表均摊 O(1) 查询。
空间：O(n)，最坏所有 `nums[i] - i` 互不相同，cnt 存 n 个键。

## 易错点
- 输入 `[1,2,3,4,5]` 时每个 `nums[i]-i` 都等于 1，good 累加到 10，total 也是 10，返回 0；若误把 good 当成坏对数直接返回会得 10。正确做法是返回 `total - good`。
- 输入 `[4,1,3,3]` 中 i=2 和 i=3 的差值都是 0，若在累加 good 前就把当前差值计数加一，i=3 会读到 cnt[0]=2 导致 good 多算。正确做法是先 `good += cnt.get(d,0)` 再 `cnt[d] += 1`。

## 如果面试官追问
问：若要求输出所有坏数对下标而非计数？
答：哈希表改为存每个差值对应的下标列表，对每个 i 取 `cnt[d]` 中所有下标与 i 组合，复杂度升到 O(n + 答案规模)。
