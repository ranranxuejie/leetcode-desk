## 一句话思路
维护偶数和 `total`，每次查询只根据 `A[index]` 修改前后的奇偶性增量更新，避免每次重扫数组。

## 怎么做
1. 先扫一遍 `A`，把偶数累加进 `total`（示例得 `2+4=6`）。
2. 对每个 `queries[i] = [val, index]`，先记下旧值 `old = A[index]`。
3. 若 `old` 是偶数，从 `total` 中减去 `old`；再把 `val` 加到 `A[index]` 上。
4. 若新值 `A[index]` 是偶数，把新值加回 `total`，然后 `answer.append(total)`。

以示例第一次查询 `[1,0]` 为例：`old = 1` 是奇数，不减；`A[0]` 变成 `2`，是偶数，`total = 6 + 2 = 8`，与输出首项一致。第二次 `[-3,1]`：`old = 2` 是偶数，`total = 8 - 2 = 6`；`A[1]` 变成 `-1` 是奇数，不加，答案 `6`。

```python
total = sum(x for x in A if x % 2 == 0)
ans = []
for val, index in queries:
    old = A[index]
    if old % 2 == 0:
        total -= old
    A[index] = old + val
    if A[index] % 2 == 0:
        total += A[index]
    ans.append(total)
```

关键点：先减旧值再加新值，顺序不能反，否则同一个偶数会被重复计入。

## 复杂度
时间：O(n + q)，n 为 `A` 长度做一次初始化，q 为 `queries` 长度每次 O(1)。
空间：O(1) 额外（不计输出数组 `ans`）。

## 易错点
- 输入 `A = [2], queries = [[2,0]]`：若先加 `val` 再判断旧值，会把 `2` 和 `4` 都算进 `total`，得到 `6`；正确是先按旧值 `2` 减去，再加新值 `4`，得 `4`。
- 输入 `A = [1], queries = [[1,0]]`：旧值 `1` 是奇数不减，新值 `2` 是偶数要加，若漏掉「新值判断」会输出 `0`；正确输出 `[2]`。

## 如果面试官追问
若要求返回每次查询后所有偶数下标而非和？答：同样维护 `total` 不够，需额外用集合记录偶数下标，查询时按需输出。
