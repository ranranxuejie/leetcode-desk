## 一句话思路
用 26 位布尔数组分别记大小写出现情况，从 'Z' 往下扫第一个双全的字母。

## 怎么做
1. 开两个长度 26 的布尔数组 `lower`、`upper`，遍历 `s` 一次填满。
2. 从 `i = 25` 倒序扫到 `0`，第一个满足 `lower[i] and upper[i]` 的 `i` 就是答案。
3. 扫完没有就返回 `""`。

以 `s = "a rR AzFif"` 为例：遍历后 `lower` 中 `a,r,z,f,i` 为 `True`，`upper` 中 `R,A,F` 为 `True`。倒序扫时 `i=25`（'Z'）不满足，`i=24`（'Y'）不满足……直到 `i=17`（'R'）时 `lower[17] and upper[17]` 首次为 `True`，直接返回 `"R"`，不再看 `i=5`（'F'）和 `i=0`（'A'）。

```python
lower = [False] * 26
upper = [False] * 26
for ch in s:
    if 'a' <= ch <= 'z':
        lower[ord(ch) - ord('a')] = True
    elif 'A' <= ch <= 'Z':
        upper[ord(ch) - ord('A')] = True
for i in range(25, -1, -1):
    if lower[i] and upper[i]:
        return chr(ord('A') + i)
return ""
```

倒序是关键：题目要「字母表里更靠后」的，正序扫会先撞上 'A' 而错答。

## 复杂度
时间：O(n + 26)，n 是 `len(s)`，遍历字符串一次，26 次扫描是常数。
空间：O(1)，两个固定 26 长度的布尔数组，与 n 无关。

## 易错点
- 输入 `"AbCdEfGhIjK"` → 若只检查「大写存在」就返回，会错答 `"K"`；必须 `lower[i] and upper[i]` 同时为 `True`，此题应返回 `""`。
- 输入 `"a rR AzFif"` → 若正序从 `i=0` 扫，会先命中 `'A'` 返回 `"A"`；必须 `range(25, -1, -1)` 倒序，才能先拿到 `'R'`。

## 如果面试官追问
问：如果要求返回所有满足条件的字母（降序）？
答：把 `return` 换成 `append`，循环不提前退出，最后返回列表即可。
