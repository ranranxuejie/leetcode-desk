## 一句话思路
把除 `2^p - 1` 外的数两两配成 `(x, 2^p-1-x)`，交换位后每对变成 `1` 和 `2^p-2`，乘积最小。

## 怎么做
1. 观察 `nums` 共 `2^p - 1` 个数，最大值 `M = 2^p - 1` 的 p 位全为 1，任何交换都动不了它，它必然留在乘积里。
2. 剩下 `2^p - 2` 个数按位互补配对：`x` 与 `M - x` 逐位恰好相反，交换后能变成 `1` 和 `M - 1`。
3. 于是最小乘积 = `M * (M-1)^((2^p-2)/2) = M * (M-1)^(2^(p-1)-1)`，用快速幂对 `10^9+7` 取模。

以 `p = 3` 为例：`M = 7`，指数 `2^2 - 1 = 3`，答案 `7 * 6^3 = 7 * 216 = 1512`，与示例一致。中间值 `M-1 = 6` 就是示例里反复出现的那个 `110`。

```python
MOD = 10**9 + 7
M = (1 << p) - 1
exp = (1 << (p - 1)) - 1
base = (M - 1) % MOD
res = 1
while exp:
    if exp & 1:
        res = res * base % MOD
    base = base * base % MOD
    exp >>= 1
return M % MOD * res % MOD
```

注意 `p = 1` 时 `exp = 0`，循环不进入，`res = 1`，返回 `M = 1`，正好对上示例 1。

## 复杂度
时间：`O(log exp) = O(p)`，快速幂按指数 `2^(p-1)-1` 的二进制位迭代，最多 p 次。
空间：`O(1)`，只用了 `res`、`base`、`exp` 三个整数。

## 易错点
1. `p = 60` 时 `M = 2^60 - 1` 和指数 `2^59 - 1` 都极大，若先算 `(M-1)**exp` 再取模会直接卡死；必须用快速幂边乘边 `% MOD`，且 `base` 先 `% MOD` 再平方。
2. `p = 1` 时数组只有 `[1]`，指数 `2^0 - 1 = 0`；若把公式写成 `M * pow(M-1, 2^(p-1))` 会多乘一个 `M-1 = 0`，返回 0，而正确答案是 1，指数必须减 1。

## 如果面试官追问
问：如果要求输出最终的 nums 数组而非乘积？答：把每对 `(x, M-x)` 中较小的置 1、较大的置 `M-1`，`M` 不动，`O(2^p)` 构造即可。
