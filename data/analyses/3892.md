## 一句话思路
环形数组上峰值互不相邻，按「选/不选」做线性 DP，代价是 `max(左,右)+1-nums[i]` 的截断到 0。

## 怎么做
1. 先判 `k > n // 2` 直接返回 -1，因为环形数组里峰值不能相邻。
2. 固定下标 0 是否被选，把环拆成链，避免首尾互相影响。
3. 对链做 DP：`dp[i][j]` 表示前 i 个位置选了 j 个峰值的最小代价，转移时若选 i 则 i-1 不能选。
4. 代价按 `max(nums[i-1], nums[i+1]) + 1 - nums[i]` 计算，负数取 0。

以 `nums = [2,1,2], k = 1` 为例：下标 2 的代价是 `max(2,1)+1-2 = 1`，选它得 1；下标 0 代价 `max(2,1)+1-2 = 1`；下标 1 代价 `max(2,2)+1-1 = 2`。取最小 1。

```python
def cost(i):
    l = nums[(i - 1) % n]
    r = nums[(i + 1) % n]
    return max(0, max(l, r) + 1 - nums[i])

ans = 10**18
for first in (0, 1):          # 下标 0 选或不选
    dp = [[10**18] * (k + 1) for _ in range(n + 1)]
    dp[0][0] = 0
    for i in range(n):
        for j in range(k + 1):
            dp[i + 1][j] = min(dp[i + 1][j], dp[i][j])   # 不选 i
            if j < k and not (i == 0 and first == 0) and not (i == n - 1 and first == 1):
                dp[i + 1][j + 1] = min(dp[i + 1][j + 1], dp[i][j] + cost(i))
    ans = min(ans, dp[n][k])
return -1 if ans == 10**18 else ans
```

## 复杂度
时间：O(n·k)，两层循环各 n、k，外层再乘 2 种首元素状态。
空间：O(n·k) 的 dp 表，可滚动到 O(k)。

## 易错点
- `nums = [3,7,3], k = 2`：若不先判 `k > n//2`，DP 会算出「选下标 0 和 2」的非法组合（两者相邻于环上），错答 0 而非 -1；正确做法是入口处 `if k > n // 2: return -1`。
- `nums = [2,1,2], k = 1`：若忘记固定下标 0 的状态，会同时把「选 0」和「选 2」当成独立方案累加，或让 0 与 n-1 同时被选；正确做法是枚举 `first ∈ {0,1}`，在 i=0 和 i=n-1 处按 first 屏蔽。

## 如果面试官追问
问：n 放大到 10^5 怎么办？答：k 也被 n//2 限制，仍 O(n·k)，但可把 dp 压成 O(k) 滚动数组，常数减半。
