## 一句话思路
枚举每个长度为 k 的窗口，窗口内 `'W'` 的个数就是把它涂黑的代价，取最小值。

## 怎么做
1. 先数 `blocks[0:k]` 里 `'W'` 的个数，记为 `cur`，`ans = cur`。
2. 窗口右移一格：`cur += (blocks[i] == 'W') - (blocks[i-k] == 'W')`，即进窗的字符是 W 就加一，出窗的是 W 就减一。
3. 每移一步用 `ans = min(ans, cur)` 更新。
4. 遍历到 `i = n-1` 结束，返回 `ans`。

用示例 1 `blocks = "WBBWWBBWBW", k = 7`：初始窗口 `blocks[0:7] = "WBBWWBB"`，其中 W 在下标 0、3、4，`cur = 3`，`ans = 3`。右移到 `blocks[1:8] = "BBWWBBW"`，出窗的 `blocks[0]='W'` 减一、进窗的 `blocks[7]='W'` 加一，`cur` 仍是 3。继续右移到 `blocks[3:10] = "WWBBWBW"`，W 在下标 3、4、8，`cur = 3`。全程最小值 3，返回 3。

```python
n = len(blocks)
cur = blocks[:k].count('W')
ans = cur
for i in range(k, n):
    if blocks[i] == 'W':
        cur += 1
    if blocks[i - k] == 'W':
        cur -= 1
    if cur < ans:
        ans = cur
return ans
```

关键点：窗口长度恒为 k，所以「涂几次」就等于窗口里白块数，不需要考虑窗口外的块——把窗口内 W 全涂黑，这 k 个位置必然连续全黑。

## 复杂度
时间：O(n)，一次初始化 O(k) 加 n-k 次 O(1) 滑动，n 是字符串长度。
空间：O(1)，只用了 `cur`、`ans`、`i` 三个标量，没有额外数组。

## 易错点
- `k == n` 时循环 `range(k, n)` 为空，直接返回初始 `cur`。若把初始化写成 `ans = float('inf')` 又忘了在循环外更新，会返回 inf；正确做法是初始化就令 `ans = cur`。
- 滑动时两个判断必须都写，且顺序无关但都要执行。若写成 `if blocks[i] == 'W': cur += 1` 后接 `elif blocks[i-k] == 'W': cur -= 1`，当进出窗同时为 W 时只加不减，`cur` 会虚高，示例 1 中从 `blocks[0:7]` 移到 `blocks[1:8]` 就会算成 4 而非 3。

## 如果面试官追问
问：如果要求返回具体涂哪几个位置，怎么做？
答：滑动时记录使 `cur` 最小的窗口起点 `best_l`，最后返回 `[best_l + j for j in range(k) if blocks[best_l + j] == 'W']`。
