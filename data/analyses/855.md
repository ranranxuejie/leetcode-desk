## 一句话思路
用有序集合维护已坐座位，每次 seat 只考察「每对相邻已坐座位的中点」和「0 号、n-1 号」这几个候选，取距离最大者。

## 怎么做
1. 用 `sortedcontainers.SortedList` 存已坐座位 `seats`，`seat()` 时枚举候选：左端 `0`、右端 `n-1`、以及每对相邻 `a,b` 的中点 `(a+b)//2`。
2. 对每个候选算「到最近人的距离」，取最大；距离相同取编号最小——所以按编号从小到大枚举、只在严格大于时更新即可。
3. 选中后插入 `seats`；`leave(p)` 直接 `seats.remove(p)`。

以示例 n=10 走一遍：初始空，返回 0，`seats=[0]`；再 seat，候选 0（距离 0，跳过，因为 0 已坐）、9（距离 9），返回 9，`seats=[0,9]`；再 seat，中点 `(0+9)//2=4`，距离 `min(4-0,9-4)=4`，返回 4，`seats=[0,4,9]`；再 seat，候选中点 2（距离 2）、6（距离 2），取小编号 2。`leave(4)` 后 `seats=[0,2,9]`，再 seat：中点 1（距离 1）、5（距离 `min(5-2,9-5)=4`），返回 5，与输出一致。

```python
from sortedcontainers import SortedList

def seat(self):
    if not self.seats:
        self.seats.add(0)
        return 0
    best, best_d = 0, self.seats[0]          # 左端 0 号
    for a, b in zip(self.seats, self.seats[1:]):
        mid = (a + b) // 2
        d = min(mid - a, b - mid)
        if d > best_d:
            best, best_d = mid, d
    d = self.n - 1 - self.seats[-1]          # 右端 n-1 号
    if d > best_d:
        best = self.n - 1
    self.seats.add(best)
    return best
```

## 复杂度
时间：每次 seat 遍历 O(k) 个相邻对，k 为已坐人数，插入 O(log k)；leave O(log k)。
空间：`seats` 存至多 k 个座位，O(k)；n 只参与端点计算，不占空间。

## 易错点
- 空考场或只有一个人时：若把「相邻对」当唯一候选，`seats=[0]` 时没有相邻对，会漏掉右端 `n-1`，示例第二步就应返回 9 却返回 0。正确做法是单独处理左端 0 和右端 `n-1` 两个候选。
- 距离相同时取小编号：若用 `>=` 更新 `best`，`seats=[0,4,9]` 时中点 2 和 6 距离都是 2，会返回 6 而非 2。正确做法是按编号升序枚举且只在 `d > best_d` 时更新，保证平局留小编号。

## 如果面试官追问
问：n 到 10^9、调用到 10^5 次怎么办？答：仍用有序集合，每次 seat 只 O(k) 枚举相邻对，k 是已坐人数而非 n，规模由调用次数而非 n 决定。
