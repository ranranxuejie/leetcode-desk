## 一句话思路
先把所有负数按绝对值从大到小翻正，k 用完后若还剩奇数次，就翻绝对值最小的那个。

## 怎么做
1. 按绝对值降序排序，这样负数里绝对值最大的排最前，翻正收益最大。
2. 顺序扫描，遇到负数且 k > 0 就翻正并 `k -= 1`。
3. 扫完后若 k 仍为奇数，把当前绝对值最小的元素（排序后是 `nums[-1]`）再翻一次。
4. 返回 `sum(nums)`。

以示例 3 `nums = [2,-3,-1,5,-4], k = 2` 为例：按绝对值降序排成 `[-4,-3,5,2,-1]`，翻 `-4`、`-3` 后 k 归零，数组为 `[4,3,5,2,-1]`，和为 13。若 k 是 3，则翻完两个负数后剩 1 次，翻绝对值最小的 `-1` 得 `[4,3,5,2,1]`，和为 15。

```python
nums.sort(key=abs, reverse=True)
for i in range(len(nums)):
    if k > 0 and nums[i] < 0:
        nums[i] = -nums[i]
        k -= 1
if k % 2 == 1:
    nums[-1] = -nums[-1]
return sum(nums)
```

关键点：排序后 `nums[-1]` 一定是绝对值最小的元素，所以剩余奇数次翻转直接作用在它身上，不用再找最小值。

## 复杂度
时间 O(n log n)：排序主导，n 为 `len(nums)`，扫描是 O(n)。
空间 O(1)：原地排序，除排序栈外没开额外数组。

## 易错点
- 输入 `nums = [2,-3,-1,5,-4], k = 2` 时若按普通升序排序，`-4` 排在 `-3` 前没问题，但 `[3,-1,0,2], k = 3` 这类含 0 的用例里，翻完 `-1` 后剩 2 次，若错误地继续翻正数会得到 4 而非 6；正确做法是剩余偶数次直接忽略，因为翻两次等于没翻。
- 输入 `nums = [-1], k = 2` 时若只翻负数不检查剩余次数，会返回 1；正确做法是翻一次得 `[1]`，k 剩 1 为奇数，再翻回 `[-1]`，返回 -1。剩余奇数次必须作用在绝对值最小的元素上。

## 如果面试官追问
问：如果要求输出最终数组而不只是和？
答：上面的原地修改已经得到最终数组，直接返回 `nums` 即可，无需额外步骤。
