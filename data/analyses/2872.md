## 一句话思路
自底向上 DFS 后序累加子树和，余数为 0 就切一刀计数，因为子树和模 k 为 0 时切掉它不影响祖先的余数。

## 怎么做
1. 把 `edges` 建成邻接表 `g`，任选 0 为根，DFS 时传 `parent` 防止回走。
2. 后序返回子树和 `s`，先算完所有孩子再判断，保证切点从叶子往上定。
3. 若 `s % k == 0`，把这块独立出去、`ans += 1`，向父节点返回 0；否则返回 `s`。
4. 根节点最后那块余数必为 0（题面保证总和可被 k 整除），已被第 3 步计入，不再额外加。

以示例 1 为例：`values = [1,8,1,4,4]`，`k = 6`，根取 0。节点 3 返回 4，节点 1 收到 4 后 `s = 8+4 = 12`，`12 % 6 == 0`，切一刀 `ans = 1`，向 2 返回 0；节点 4 返回 4，节点 2 得 `s = 1+0+4 = 5` 不切；节点 0 返回 1，根处 `s = 1+5 = 6`，`6 % 6 == 0`，`ans = 2`。

```python
def dfs(u, p):
    s = values[u]
    for v in g[u]:
        if v != p:
            s += dfs(v, u)
    if s % k == 0:
        nonlocal ans
        ans += 1
        return 0
    return s
```

关键点：切完返回 0 而不是返回 `s`，否则父节点会把已独立块的和对进来，余数算错。

## 复杂度
时间 O(n)：每条边在 DFS 里访问两次，`s % k` 是 O(1)。
空间 O(n)：邻接表存 2(n-1) 条边，递归栈最深 n 层。

## 易错点
- `n = 3 * 10**4` 的链状树（如 `edges = [[i, i+1] ...]`）→ Python 默认递归深度约 1000，直接 `RecursionError` → 用 `sys.setrecursionlimit(10**5)`，或改写成显式栈的后序迭代。
- 切块后仍返回 `s` 而非 0 → 示例 1 中节点 1 返回 12 给节点 2，节点 2 的 `s` 变成 `1+12+4 = 17`，`17 % 6 != 0`，根处也凑不出 6，答案错成 1 → 切块后必须 `return 0`。

## 如果面试官追问
要求输出具体删哪些边怎么办？答：DFS 里记录触发切分的 `(u, parent)` 边，切点即该边，按后序收集即可。
