## 一句话思路
f(x) 单调不减且只跳 5 的倍数，二分出 f(x)≥k 的最小 x 与 f(x)≥k+1 的最小 x，两者之差即答案。

## 怎么做
1. 写 `z(x)`：累加 `x//5, x//25, ...` 得 x! 末尾零数，循环条件 `while x: x //= 5`。
2. 二分 `lo=0, hi=5*(k+1)`，找第一个 `z(mid) >= k` 的位置 `L`。
3. 同样二分找第一个 `z(mid) >= k+1` 的位置 `R`，返回 `R - L`。
4. k=0 时 L=0、R=5，返回 5，与示例一致。

以 k=3 为例：`z(15)=3`（15//5=3），`z(14)=2`，故 L=15；`z(20)=4`，`z(19)=3`，故 R=20；答案 20-15=5。关键中间值是 `z(15)=3` 恰好等于 k，说明 15 是第一个达标点。

```python
def z(x):
    s = 0
    while x:
        x //= 5
        s += x
    return s

lo, hi = 0, 5 * (k + 1)
while lo < hi:
    mid = (lo + hi) // 2
    if z(mid) >= k:
        hi = mid
    else:
        lo = mid + 1
L = lo
# 同理求 R：把上面 k 换成 k+1，返回 R - L
```

上界取 `5*(k+1)` 的理由：`z(5*(k+1)) >= k+1 > k`，保证第一个二分的解一定落在区间内。

## 复杂度
时间 O(log k · log k)：二分约 log(5k) 轮，每轮 z 计算约 log₅(5k) 次除法。
空间 O(1)：只用 lo/hi/mid/s 几个整数，无额外数组。

## 易错点
- k=5 → 若直接返回 `R-L` 而不检查 `z(L)==k`，会误判；实际 L 处 `z(L)=6>5`，说明 5 被跳过，答案应为 0。正确做法是先算 `z(L)`，不等于 k 就返回 0（或依赖 R-L 自然为 0，但要确认 L 处确实越过了 k）。
- k=10^9 → 若上界写成 `5*k` 而非 `5*(k+1)`，二分区间可能不含解，`lo` 停在错误位置；且 `z` 里用 `x//5` 累加时若误写成 `x/5` 会得到浮点，Python 下大数除法丢精度。正确做法是全程 `//`，上界留 `5*(k+1)` 的余量。

## 如果面试官追问
问：k 上限提到 10^18 还成立吗？
答：成立，二分轮数只增到约 60，z 的循环约 26 次，Python 大整数无溢出问题。
