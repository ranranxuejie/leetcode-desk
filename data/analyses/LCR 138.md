## 一句话思路
用三个布尔标记 `seen_digit`、`seen_dot`、`seen_e` 从左到右扫一遍，边扫边校验每个字符出现的合法性。

## 怎么做
1. 先 `s = s.strip()` 去掉首尾空格，中间空格一律非法，扫到直接返回 `False`。
2. 维护三个标记：`seen_digit` 表示当前段是否已有数字，`seen_dot` 表示小数点是否已出现，`seen_e` 表示指数是否已出现。
3. 逐字符判断：数字则置 `seen_digit = True`；`.` 要求 `not seen_dot and not seen_e`；`e/E` 要求 `not seen_e and seen_digit`，同时把 `seen_digit` 重置为 `False`（指数部分必须重新攒数字）；`+/-` 只允许出现在下标 0 或紧跟 `e/E` 之后。
4. 扫完返回 `seen_digit`，保证 `"1e"`、`"e3"`、`"."` 这类尾巴没数字的情况被拦下。

以 `s = "0"` 为例：`strip` 后仍是 `"0"`，循环里 `c='0'` 命中数字分支，`seen_digit` 从 `False` 变 `True`，循环结束返回 `True`。再看 `"."`：`c='.'` 时 `seen_dot` 为 `False` 通过，但 `seen_digit` 始终没被置 `True`，最后返回 `False`。

```python
s = s.strip()
seen_digit = seen_dot = seen_e = False
for i, c in enumerate(s):
    if c.isdigit():
        seen_digit = True
    elif c == '.':
        if seen_dot or seen_e: return False
        seen_dot = True
    elif c in 'eE':
        if seen_e or not seen_digit: return False
        seen_e = True
        seen_digit = False
    elif c in '+-':
        if i > 0 and s[i-1] not in 'eE': return False
    else:
        return False
return seen_digit
```

## 复杂度
时间 O(n)：`n = len(s)`，每个字符只被访问一次。
空间 O(1)：只开了三个布尔标记，`strip` 产生的副本不计入。

## 易错点
- 输入 `"1e"` → 若不在 `e` 处把 `seen_digit` 重置为 `False`，结尾 `return seen_digit` 会误判为 `True` → 正确做法是遇到 `e/E` 后立刻清零，强制指数段重新攒数字。
- 输入 `"+-3"` 或 `"3e+7"` → 若只判断 `c in '+-'` 就放行，`"+-3"` 会被误判为合法 → 正确做法是要求符号位下标为 0 或前一字符是 `e/E`，`"3e+7"` 的 `+` 前一字符是 `e` 才通过。

## 如果面试官追问
问：不用标记，改用正则怎么写？答：`^\s*[+-]?(\d+\.?\d*|\.\d+)([eE][+-]?\d+)?\s*$`，注意 `\d+\.?\d*` 和 `\.\d+` 两支覆盖 `"4."` 与 `".9"`。
