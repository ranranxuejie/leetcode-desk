## 一句话思路
把 0 记作 -1，问题变成「前缀和相等的最远下标差」，用哈希表存每个前缀和首次出现的下标。

## 怎么做
1. 令 `pre = 0`，`first = {0: -1}`——空前缀和为 0，下标记 -1，这样从下标 0 开始的子数组也能被算到。
2. 遍历 `i, x`，`pre += 1 if x == 1 else -1`。
3. 若 `pre` 已在 `first` 里，`i - first[pre]` 就是以 `i` 结尾的最长合法长度，更新答案；否则 `first[pre] = i`。
4. 只记录首次出现，因为要最长，越早的下标越有利。

以 `nums = [0,1,0]` 为例：`i=0` 时 `pre=-1`，`first` 无此键，记 `first[-1]=0`；`i=1` 时 `pre=0`，`first[0]=-1` 已存在，长度 `1-(-1)=2`；`i=2` 时 `pre=-1`，`first[-1]=0`，长度 `2-0=2`。答案 2。

```python
pre = 0
first = {0: -1}
ans = 0
for i, x in enumerate(nums):
    pre += 1 if x == 1 else -1
    if pre in first:
        ans = max(ans, i - first[pre])
    else:
        first[pre] = i
return ans
```

关键点：`first` 里存的是**下标**不是计数；`pre` 相同意味着两下标之间的 0 和 1 数量相等，因为 1 加 1、0 减 1，净变化为 0。

## 复杂度
时间 O(n)：一次遍历，每个元素做一次哈希查找/插入。
空间 O(n)：`first` 最多存 n+1 个不同前缀和。

## 易错点
- 输入 `nums = [0,1]`：若初始化 `first = {}` 而不放 `{0: -1}`，`i=1` 时 `pre=0` 查不到，答案错成 0；正确做法是预置空前缀和 0 对应下标 -1。
- 输入 `nums = [0,0,1,0,0,0,1,1]`：若每次遇到相同 `pre` 都覆盖 `first[pre] = i`，最左下标丢失，答案偏小；正确做法是只在键不存在时写入，保留首次下标。

## 如果面试官追问
要求返回该子数组本身而非长度？答：`first[pre]` 存首次下标，命中时记下 `(first[pre]+1, i)` 这对端点，最后切片即可，空间不变。
