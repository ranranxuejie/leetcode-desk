## 一句话思路
把元音记 +1、辅音记 −1 做前缀和，相等条件变成前缀和相等，再用 gcd 把乘积整除条件化简成对前缀和取模。

## 怎么做
1. 令 `pre[i]` = 前 i 个字符的（元音数 − 辅音数），元音 +1、辅音 −1。子串 `(j, i]` 元音数 = 辅音数 ⟺ `pre[i] == pre[j]`。
2. 设该子串元音数 = 辅音数 = v，则长度 `i - j = 2v`，乘积 `v*v % k == 0`。令 `g = gcd(2, k)`，条件等价于 `(i - j) % (2*k//g) == 0`，即 `i ≡ j (mod m)`，其中 `m = 2*k//gcd(2,k)`。
3. 于是扫一遍，用哈希表 `cnt[(pre[i], i % m)]` 累计前面同余同前缀和的起点个数，答案累加即可。

以 `s = "baeyh", k = 2` 为例：`g = gcd(2,2) = 2`，`m = 2*2//2 = 2`。前缀和序列为 `pre = [0, -1, 0, 1, 0, -1]`（b−1, a+1, e+1, y−1, h−1 累加）。`i=4` 时 `pre=0, i%2=0`，与 `i=0` 的 `(0,0)` 配对得子串 `"baey"`；`i=5` 时 `pre=-1, i%2=1`，与 `i=1` 的 `(-1,1)` 配对得 `"aeyh"`，共 2 个。

```python
from math import gcd
from collections import defaultdict

m = 2 * k // gcd(2, k)
cnt = defaultdict(int)
cnt[(0, 0)] = 1
pre = ans = 0
for i, ch in enumerate(s, 1):
    pre += 1 if ch in "aeiou" else -1
    ans += cnt[(pre, i % m)]
    cnt[(pre, i % m)] += 1
```

## 复杂度
时间 O(n)：一次扫描，哈希表均摊 O(1)，`gcd` 只算一次。
空间 O(n)：哈希表最多存 n 个 `(pre, i % m)` 键。

## 易错点
- `k` 为奇数时若直接取 `m = 2*k`，会把 `"abba", k=1` 的 `m` 算成 2，漏掉长度 4 的 `"abba"`（v=2, 4%2=0 但需 4%2 与 2*k//gcd=2 一致才不误判）；正确是 `m = 2*k//gcd(2,k)`，k=1 时 m=2，长度 4 仍满足 `i%2==j%2`，答案 3 才对。
- 初始项写成 `cnt[(0, 0)] = 1` 而非 `cnt[0] = 1`：键必须带 `i % m`，否则 `i=0` 的起点会被错误匹配到 `pre=0` 但 `i%m != 0` 的位置，`"baeyh"` 会多算出非法子串。

## 如果面试官追问
若 k 可达 10^9 而 n 只有 5*10^4，怎么办？答：`m` 可能超过 n，但只需对 `i % m` 取模，哈希表键数仍 ≤ n，复杂度不变。
