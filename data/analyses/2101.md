## 一句话思路
把每个炸弹看作有向图节点，i 能引爆 j 就连边，再对每个起点做 DFS 数可达节点取最大。

## 怎么做
1. 先 O(n²) 建邻接表：对每对 (i, j)，若 `(xi-xj)**2 + (yi-yj)**2 <= ri**2` 则 `graph[i].append(j)`。
2. 注意边是**单向**的：i 半径够到 j 不代表 j 够到 i，所以必须双重循环判两次，不能只判一半。
3. 对每个起点 i 做 DFS/BFS，用 `visited` 集合统计能到达的节点数，取最大值。
4. 用示例 1 `[[2,1,3],[6,1,4]]` 验证：0→1 距离平方 `(2-6)**2+(1-1)**2=16`，`r0**2=9`，16>9 不连边；1→0 同样 16，但 `r1**2=16`，16<=16 连边。所以从 1 出发能引爆 2 个。

```python
n = len(bombs)
graph = [[] for _ in range(n)]
for i in range(n):
    xi, yi, ri = bombs[i]
    for j in range(n):
        if i != j:
            xj, yj, _ = bombs[j]
            if (xi - xj) ** 2 + (yi - yj) ** 2 <= ri ** 2:
                graph[i].append(j)

def dfs(start):
    seen, stack = {start}, [start]
    while stack:
        u = stack.pop()
        for v in graph[u]:
            if v not in seen:
                seen.add(v)
                stack.append(v)
    return len(seen)

return max(dfs(i) for i in range(n))
```

关键中间值：示例 1 中 `graph = [[], [0]]`，`dfs(0)=1`、`dfs(1)=2`，答案 2。

## 复杂度
时间 O(n²)：建图 O(n²)，每个起点 DFS 最坏 O(n²)，共 O(n³) 但 n≤100 可过。
空间 O(n²)：邻接表最多 n² 条边，visited 和栈各 O(n)。

## 易错点
- 距离比较用 `sqrt` 会引入浮点误差，如 `[[0,0,1],[1,0,1]]` 中 `sqrt(1)=1.0` 边界可能判错 → 应比较平方：`(xi-xj)**2+(yi-yj)**2 <= ri**2`，全程整数运算。
- 只建单向边或只判 `i<j` 的一半 → 示例 1 中会漏掉 1→0 这条边，答案错成 1 → 必须对每对 (i,j) 和 (j,i) 分别判断，因为半径不同方向不同。

## 如果面试官追问
若 n 扩大到 10⁵ 怎么办？答：O(n²) 建图不可行，需用空间索引（如 KD-tree 或网格分桶）只连邻近炸弹，再在稀疏图上做可达性统计。
