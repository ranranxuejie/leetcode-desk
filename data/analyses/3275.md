## 一句话思路
维护一个大小为 k 的大顶堆存当前最近的 k 个距离，堆顶就是第 k 近。

## 怎么做
1. 遍历 `queries`，对每个 `[x, y]` 算曼哈顿距离 `d = abs(x) + abs(y)`。
2. 堆未满 k 个就 `heappush(-d)`；满了且 `d < -heap[0]` 才替换堆顶。
3. 每步若堆大小等于 k，答案取 `-heap[0]`，否则填 `-1`。

以示例 1 的 `queries = [[1,2],[3,4],[2,3],[-3,0]]`、`k = 2` 为例：前两步堆为 `[-7,-3]`，堆顶 `-7` 对应第 2 近距离 7；第三步 `d = 5`，`5 < 7` 成立，弹出 `-7` 压入 `-5`，堆变 `[-5,-3]`，答案 5；第四步 `d = 3`，`3 < 5` 成立，弹出 `-5` 压入 `-3`，堆变 `[-3,-3]`，答案 3。注意第三步若不比较就直接 push，堆会变成 3 个元素，堆顶 `-7` 让答案错成 7。

```python
import heapq

def resultsArray(queries, k):
    heap = []
    res = []
    for x, y in queries:
        d = abs(x) + abs(y)
        if len(heap) < k:
            heapq.heappush(heap, -d)
        elif d < -heap[0]:
            heapq.heapreplace(heap, -d)
        res.append(-heap[0] if len(heap) == k else -1)
    return res
```

关键就两行：`elif d < -heap[0]` 决定要不要换，`-heap[0]` 是当前第 k 近的距离。

## 复杂度
时间 O(n log k)：n 为 `queries.length`，每次堆操作 log k。
空间 O(k)：堆最多存 k 个距离，结果数组 O(n) 不计入额外空间。

## 易错点
- 堆满后无条件 `heappush` → 堆里超过 k 个元素，堆顶变成第 k+1 近，示例 1 第三步会输出 7 而非 5 → 必须先判 `d < -heap[0]` 再替换，用 `heapreplace` 一步完成。
- 用 `-1` 当哨兵混进堆 → 距离本身可能为 0（如 `[0,0]`），负数堆里 `-1` 与真实距离混淆 → 只在 `len(heap) < k` 时输出 `-1`，堆里永远只放 `-d`。

## 如果面试官追问
问：如果要求返回第 k 近障碍物的坐标而不只是距离？
答：堆里存 `(-d, x, y)` 三元组，比较时按距离，输出时取后两位即可。
