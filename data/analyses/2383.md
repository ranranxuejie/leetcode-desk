## 一句话思路
精力必须一次性预支（总消耗固定），经验只能边打边涨，故两路分别贪心累加缺口。

## 怎么做
1. 精力侧：把 `energy` 全加起来得 `need_energy = 1+4+3+2 = 10`，初始 `initialEnergy = 5` 不够，缺口 `10 - 5 = 5`，但要求每场结束后精力仍为正（严格超过对手后减掉），实际需保证总精力 > 总消耗，即至少 `11`，故补 `11 - 5 = 6` 小时。
2. 经验侧：不能预支总量，只能逐场检查当前 `cur_exp` 是否严格大于 `experience[i]`，不够就补差值 `+1`。
3. 用示例 1 走一遍：`cur_exp = 3`，第 0 场对手 2，`3 > 2` 通过，`cur_exp = 3+2 = 5`；第 1 场对手 6，`5 <= 6`，补 `6-5+1 = 2` 小时使 `cur_exp = 7`，通过后 `cur_exp = 7+6 = 13`；后续 3、1 均无需再补，经验侧共 2 小时。
4. 总答案 `6 + 2 = 8`，与示例一致。

```python
total_e = sum(energy)
ans = max(0, total_e + 1 - initialEnergy)  # 精力需严格大于总消耗
cur = initialExperience
for x in experience:
    if cur <= x:
        ans += x - cur + 1
        cur = x + 1
    cur += x
return ans
```

关键中间值：第 1 场时 `cur = 5`、`x = 6`，补 `2` 小时后 `cur = 7`，这是经验侧唯一一次补课。

## 复杂度
时间：O(n)，遍历 `experience` 一次，`sum(energy)` 一次。
空间：O(1)，只用了 `ans`、`cur`、`total_e` 三个标量。

## 易错点
- 精力写成 `max(0, total_e - initialEnergy)`：示例 1 会得 `10-5=5` 而非 `6`，因为「严格超过」要求剩余精力始终为正，必须 `total_e + 1`。
- 经验补差值时写成 `ans += x - cur` 而不 `+1`：示例 1 第 1 场补 `1` 小时后 `cur = 6`，`6 > 6` 为假，仍打不过，正确是补 `x - cur + 1` 让 `cur = x + 1`。

## 如果面试官追问
问：若允许把训练小时分配到「每场之间」而非赛前，答案会变吗？
答：不会，精力总量约束与经验逐场约束都不依赖训练时机，答案不变。
