## 一句话思路
把 `cost` 降序排序，每三个一组，每组前两个付钱、第三个免费，因为最贵的两个必须买，让最贵的当赠品最省钱。

## 怎么做
1. 对 `cost` 降序排序，得到 `[9,7,6,5,2,2]`。
2. 从下标 0 开始，每 3 个一组，取组内前两个累加进 `total`。
3. 组内第三个（下标 2、5、8…）跳过，作为免费糖果。
4. 返回 `total`。

以示例 2 为例：排序后 `[9,7,6,5,2,2]`，第一组 `9,7` 付钱、`6` 免费，第二组 `5,2` 付钱、`2` 免费，`total = 9+7+5+2 = 23`。

```python
cost.sort(reverse=True)
total = 0
for i in range(len(cost)):
    if i % 3 != 2:
        total += cost[i]
return total
```

关键中间值：`i=2` 时 `i % 3 == 2`，跳过 `cost[2]=6`，这正是被免费拿走的那颗。

## 复杂度
时间：排序 O(n log n) 主导，遍历 O(n)。
空间：排序原地进行，额外只开 `total`，O(1)。

## 易错点
- 输入 `[5,5]`（长度不足 3）→ 若按「每 3 个取 2 个」硬套分组，可能误以为能免费一颗 → 正确做法是 `i % 3 != 2` 判断，长度 2 时两个下标 0、1 都付钱，得 10。
- 输入 `[1,2,3]` → 若升序排序后取前两个 `1,2` 付钱、`3` 免费，违反「赠品 ≤ 两个购买价的较小值」→ 必须降序，让 `3,2` 付钱、`1` 免费，得 5。

## 如果面试官追问
问：如果改成「买三送一」怎么改？
答：降序后每 4 个一组，跳过下标 `i % 4 == 3` 的元素，其余累加。
