## 一句话思路
用归并排序：把数组对半切到单元素，再两两合并有序段，合并时按大小取数即得全局有序。

## 怎么做
1. 递归把 `nums` 从中间 `mid` 切开，直到每段长度 ≤1（天然有序）。
2. 合并两个有序段时用双指针 `i`、`j`，每次取较小者写入临时数组 `tmp`。
3. 把 `tmp` 写回 `nums` 对应区间，返回上一层继续合并。

以 `nums = [5,2,3,1]` 为例：切到 `[5]`、`[2]` 合并得 `[2,5]`；`[3]`、`[1]` 合并得 `[1,3]`；最后合并 `[2,5]` 与 `[1,3]`，双指针先取 1、再取 2、再取 3、最后取 5，`tmp = [1,2,3,5]`。

```python
def merge_sort(a, lo, hi, tmp):
    if hi - lo <= 1:
        return
    mid = (lo + hi) // 2
    merge_sort(a, lo, mid, tmp)
    merge_sort(a, mid, hi, tmp)
    i, j, k = lo, mid, lo
    while i < mid and j < hi:
        if a[i] <= a[j]:
            tmp[k] = a[i]; i += 1
        else:
            tmp[k] = a[j]; j += 1
        k += 1
    while i < mid:
        tmp[k] = a[i]; i += 1; k += 1
    while j < hi:
        tmp[k] = a[j]; j += 1; k += 1
    a[lo:hi] = tmp[lo:hi]
```

调用 `merge_sort(nums, 0, len(nums), [0]*len(nums))` 即可，`tmp` 全程复用一份。

## 复杂度
时间 O(n log n)：递归树 log n 层，每层合并共扫 n 个元素。
空间 O(n)：只额外开了一份长度 n 的 `tmp`，递归栈 O(log n) 可忽略。

## 易错点
- 合并判断写成 `a[i] < a[j]` 而非 `<=`：输入 `[5,1,1,2,0,0]` 时相等元素 1 与 1 会先取右边，破坏稳定性；本题只要升序不影响正确性，但若追问稳定排序就必须用 `<=`。
- 切分用 `mid = (lo + hi) // 2` 后递归写 `(lo, mid)` 和 `(mid, hi)`：若误写成 `(lo, mid-1)`，`hi - lo == 1` 时 `mid == lo`，会切出空段或死递归；保持左闭右开区间最省心。

## 如果面试官追问
问：值域只有 `[-5*10^4, 5*10^4]`，能更快吗？
答：用计数排序，开长度 10^5+1 的桶统计频次再顺序展开，时间 O(n + V)、空间 O(V)，V 是值域宽度。
