## 一句话思路
把每个格子拆成因子 2 和 5 的个数，枚举拐点，用四个方向的前缀和拼出「横臂+竖臂」的 2、5 总量取 min。

## 怎么做
1. 预处理 `two[i][j]`、`five[i][j]`：对 `grid[i][j]` 反复除 2 / 除 5 计数。
2. 建四个前缀和：`L`（含自身向左）、`R`（向右）、`U`（向上）、`D`（向下），每个都存 2 和 5 两个量。
3. 枚举每个格子作拐点，四种组合（左+上、左+下、右+上、右+下），臂长之和减去重复计入的拐点本身。
4. 对每个组合取 `min(sum2, sum5)`，全局取最大。

以示例 1 的拐点 `grid[2][2]=6` 为例：`two=1, five=0`。取左臂到 `grid[2][0]=9`（two=0,five=0）与上臂到 `grid[0][2]=15`（two=0,five=1），横臂 2 总量 `0+1+1=2`、5 总量 `0+0+0=0`；竖臂 2 总量 `0+0+1=1`、5 总量 `1+0+0=1`。合并减拐点后 2 总量 `2+1-1=2`，5 总量 `0+1-0=1`，`min=1`。真正最优是 `15,20,6,1,10` 这条，2 总量 5、5 总量 3，`min=3`。

```python
def cnt(x, p):
    c = 0
    while x % p == 0:
        x //= p; c += 1
    return c

# 以 L 为例，其余三向同构
L2 = [[0]*n for _ in range(m)]
for i in range(m):
    for j in range(n):
        L2[i][j] = two[i][j] + (L2[i][j-1] if j else 0)
# 枚举拐点 (i,j)，四组合
for i in range(m):
    for j in range(n):
        for h2, h5, v2, v5 in combos(i, j):
            s2 = h2 + v2 - two[i][j]
            s5 = h5 + v5 - five[i][j]
            ans = max(ans, min(s2, s5))
```

## 复杂度
时间：`O(m*n)`，每个格子常数次四方向查询，因子分解每格最多 `log(1000)`。
空间：`O(m*n)`，八个前缀和数组（四方向 × 2/5）。

## 易错点
- 拐点被横臂和竖臂各算一次 → 不减 `two[i][j]`/`five[i][j]` 会多算，示例 1 拐点 `6` 的 2 因子会被重复计入，答案偏大。合并时必须减去拐点自身。
- 路径可以只有一个方向（无弯），即退化成单条横臂或竖臂 → 只枚举四组合会漏掉纯直线。正确做法是把「单臂」也当作合法候选，或让另一臂长度为 0 时公式自然覆盖。

## 如果面试官追问
问：`m*n` 放大到 `10^7` 怎么办？
答：前缀和数组从 8 个降到 2 个滚动行，按行扫描时只保留上一行的 `U/D`，空间降到 `O(n)`。
