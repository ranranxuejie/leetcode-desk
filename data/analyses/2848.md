## 一句话思路
用差分数组在坐标轴上打标记，前缀和还原每个整数点被覆盖的次数，统计大于 0 的点数。

## 怎么做
1. 坐标上限是 100，开长度 102 的差分数组 `diff`，`diff[start] += 1`、`diff[end + 1] -= 1`。
2. 从 1 到 100 累加前缀和，得到每个点被几辆车覆盖。
3. 统计前缀和大于 0 的位置个数。

以 `nums = [[3,6],[1,5],[4,7]]` 为例：打完差分后 `diff[1]=1, diff[3]=1, diff[4]=1, diff[5]=-1, diff[6]=-1, diff[7]=-1, diff[8]=-1`；累加后点 1 到 7 的前缀和依次为 1,1,2,2,2,1,1，点 8 回到 0，故答案 7。

```python
diff = [0] * 102
for s, e in nums:
    diff[s] += 1
    diff[e + 1] -= 1
ans = cur = 0
for x in range(1, 101):
    cur += diff[x]
    if cur > 0:
        ans += 1
```

注意 `end + 1` 这个位置必须减，否则点 `end + 1` 会被误算成被覆盖。

## 复杂度
时间：O(n + 100)，n 是车的数量，100 是坐标上限的固定扫描。
空间：O(100)，只开了长度 102 的 `diff` 数组。

## 易错点
- 输入 `[[1,3],[5,8]]` → 若只写 `diff[e] -= 1` 而不写 `diff[e + 1] -= 1`，点 3 和点 8 会被漏算，答案错成 5 → 正确做法是区间 `[s, e]` 闭合，差分在 `e + 1` 处减。
- 输入 `[[1,1]]` → 若循环写成 `range(1, 100)` 会漏掉点 100，若写成 `range(1, 101)` 但差分数组只开到 101 则 `diff[101]` 越界 → 正确做法是数组开到 102、扫描到 100，保证 `end = 100` 时 `diff[101]` 可写。
