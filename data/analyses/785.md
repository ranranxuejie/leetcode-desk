## 一句话思路
用染色法 DFS：给每个节点染 0/1，沿边要求邻点颜色相反，冲突即非二分图；图可能不连通，需对每个未染色节点重新起搜。

## 怎么做
1. 开 `color = [-1] * n`，-1 表示未染色，遍历每个节点，遇到 `color[i] == -1` 就从它开始 DFS 并染 0。
2. DFS 中遍历 `graph[u]` 的每个 `v`：若 `color[v] == -1` 染成 `1 - color[u]` 继续递归；若 `color[v] == color[u]` 直接返回 `False`。
3. 用示例 1 `graph = [[1,2,3],[0,2],[0,1,3],[0,2]]` 走一遍：节点 0 染 0，邻点 1、2、3 全染 1；从 1 出发看邻点 2，`color[2] == 1 == color[1]`，冲突，返回 `False`。
4. 全部节点染完无冲突返回 `True`；示例 2 中 0→1 得 `color[1]=1`，1→2 得 `color[2]=0`，2→3 得 `color[3]=1`，3→0 时 `color[0]=0 != color[3]`，通过。

```python
def dfs(u, c):
    color[u] = c
    for v in graph[u]:
        if color[v] == -1:
            if not dfs(v, 1 - c):
                return False
        elif color[v] == c:
            return False
    return True

color = [-1] * len(graph)
for i in range(len(graph)):
    if color[i] == -1 and not dfs(i, 0):
        return False
return True
```

## 复杂度
时间：O(n + E)，每个节点染一次色、每条无向边被两端各看一次，E 为 `graph` 中所有邻接项总数。
空间：O(n)，`color` 数组占 n，DFS 递归栈最坏 O(n)（链状图）。

## 易错点
- 输入 `graph = [[],[]]`（两个孤立节点）→ 若只从节点 0 起搜就返回 `True` 但漏判节点 1，或误以为必须连通 → 正确做法是外层 `for i in range(n)` 对每个 `color[i] == -1` 的节点都起一次 DFS。
- 输入 `graph = [[1],[0]]` 这种两点一边 → 若把 `color[v] == c` 写成 `color[v] != -1` 就判错 → 正确做法是只在「已染色且颜色相同」时报冲突，未染色时递归染 `1 - c`。

## 如果面试官追问
要求输出具体分组方案怎么办？答：DFS 结束后把 `color[i] == 0` 的节点收进 A、`== 1` 的收进 B，冲突时返回空表示无解。
