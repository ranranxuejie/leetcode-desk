## 一句话思路
滑动窗口维护窗口内质因数计数，右扩左缩，窗口内不同质因数数 ≤ k 时更新答案。

## 怎么做
1. 预处理 `MAXV = max(nums)` 的 SPF（最小质因数）表，用线性筛或埃氏筛，之后对每个 `x` 反复除以 SPF 得到去重质因数。
2. 右指针 `r` 遍历 `nums`，把 `nums[r]` 的每个质因数 `p` 计入 `cnt[p]`，若 `cnt[p]` 从 0 变 1 则 `distinct += 1`。
3. 当 `distinct > k` 时，左指针 `l` 右移，把 `nums[l]` 的质因数从 `cnt` 中减，减到 0 则 `distinct -= 1`，直到 `distinct <= k`。
4. 每次收缩后 `ans = max(ans, r - l + 1)`。

以示例 1 `nums = [7,6,10,12,11], k = 3` 为例：`r=3` 处理 `12` 时，`12` 的质因数是 `{2,3}`，此时窗口 `[6,10,12]` 的 `cnt` 为 `{2:3, 3:2, 5:1}`，`distinct=3` 不超限，`ans` 更新为 3；`r=4` 加入 `11` 后 `distinct=4 > 3`，`l` 从 0 移到 1，移出 `7` 后 `distinct` 仍为 4（`7` 不在窗口质因数里），继续移到 2 移出 `6`，`cnt[3]` 减到 1 未归零，`distinct` 仍 4，直到移出 `10` 使 `cnt[5]` 归零，`distinct=3`，窗口 `[12,11]` 长度 2，答案保持 3。

```python
spf = list(range(MAXV + 1))
for i in range(2, int(MAXV**0.5) + 1):
    if spf[i] == i:
        for j in range(i*i, MAXV + 1, i):
            if spf[j] == j:
                spf[j] = i

def factors(x):
    res = []
    while x > 1:
        p = spf[x]
        res.append(p)
        while x % p == 0:
            x //= p
    return res

cnt = {}
distinct = l = ans = 0
for r, x in enumerate(nums):
    for p in factors(x):
        if cnt.get(p, 0) == 0:
            distinct += 1
        cnt[p] = cnt.get(p, 0) + 1
    while distinct > k:
        for p in factors(nums[l]):
            cnt[p] -= 1
            if cnt[p] == 0:
                distinct -= 1
        l += 1
    ans = max(ans, r - l + 1)
```

## 复杂度
时间：筛表 O(MAXV log log MAXV)，每个元素分解 O(log nums[i])，双指针各扫一遍，总 O(n log MAXV)。
空间：SPF 表 O(MAXV)，`cnt` 哈希表最多存 MAXV 内质数个数，额外 O(MAXV)。

## 易错点
- `nums` 含 `4`、`8`、`9` 这类质因数重复的数：若分解时不写 `while x % p == 0: x //= p` 去重，`4` 会被算成 `{2,2}`，`cnt[2]` 多加一次，移出时 `cnt[2]` 减不到 0，`distinct` 永远偏大，窗口被错误收缩。正确做法是每个质因数只计一次。
- `k` 大于等于全局不同质因数总数时（如示例 2 的 `k=4`）：若在 `while distinct > k` 里用 `l < r` 之类边界条件提前停，会漏掉整个数组。正确做法是让 `l` 一直收缩到 `distinct <= k`，此时 `ans` 自然取到 `n`。

## 如果面试官追问
问：若要求返回具体子数组而非长度？
答：在 `ans` 更新处同时记录 `(l, r)`，最后切片 `nums[l:r+1]` 即可，逻辑不变。
