## 一句话思路
对每个候选 k 求「把 nums[i] 按能否被 k 整除映射成 ±nums[i]」的最大子段和，取最大差与最小 k。

## 怎么做
1. 候选 k 只需枚举到 `max(nums)`：k 超过最大值时没有任何元素被整除，差为 `-sum(nums)`，不可能优于 k=2 的某个区间。
2. 对固定 k，令 `w[i] = nums[i] if nums[i] % k == 0 else -nums[i]`，问题变成最大子段和（Kadane），因为区间外的元素不计分。
3. 用 `cur = max(w[i], cur + w[i])` 滚动，`best` 记录全局最大；`best` 严格变大时才更新答案的 k，保证同分取最小 k。
4. 答案 `best * k % (10**9+7)`，Python 负数取模自动得正，示例 3 的 `-2` 直接变 `1000000005`。

以 `nums = [2,1,2]`、`k = 2` 为例：`w = [2,-1,2]`，Kadane 依次得 `cur = 2, 1, 3`，`best = 3`；k=3 时 `w = [-2,-1,-2]`，`best = -1`，故最终 k=2、差 3，输出 6。

```python
MOD = 10**9 + 7
best, best_k = -10**18, 2
for k in range(2, max(nums) + 1):
    cur = 0
    for x in nums:
        w = x if x % k == 0 else -x
        cur = w if cur <= 0 else cur + w
        if cur > best:
            best, best_k = cur, k
return best * best_k % MOD
```

注意 `cur <= 0` 时直接重置为 `w`，等价于 `max(w, cur + w)`，少一次加法。

## 复杂度
时间 O(n · max(nums))：外层枚举 k 到 10^6，内层扫 n=1000。
空间 O(1)：只开 `cur/best/best_k`，不建 w 数组。

## 易错点
- `nums = [1]`：若把 `best` 初始化为 0，会得到差 0、k=2、输出 0；正确是 `best = -10**18`，让 k=2 的 `-1` 成为最大值，输出 `1000000005`。
- `nums = [4,6,8]`：k=2 与 k=4 都能让整个数组被整除、差都是 18；若用 `>=` 更新会留下较大的 k，必须用严格 `>` 才取到最小 k=2。

## 如果面试官追问
问：nums[i] 上限提到 10^9 怎么办？
答：候选 k 不能枚举到 max，改为枚举所有 nums[i] 的约数（每个数至多约 1344 个），去重后逐个跑 Kadane。
