## 一句话思路
答案只可能是 0、1、2：全相等为 0，否则一次全数组 AND 必让所有元素变成同一个值，最多两次。

## 怎么做
1. 先判断 `nums` 是否已经全部相等，是则返回 0。
2. 否则返回 1 或 2，关键看一次操作能否成功。
3. 一次操作选 `[l, r]` 后，区间内全变成 `AND(nums[l..r])`，区间外不变；要让全数组相等，区间外元素必须本来就等于这个 AND 值。
4. 结论：若存在某个子数组，其 AND 等于区间外所有元素的值（且区间外元素彼此相等），答案为 1，否则为 2。

以 `nums = [1,2]` 为例：`1 & 2 = 0`，选 `[0,1]` 后变成 `[0,0]`，一次成功，返回 1。再看 `nums = [1,2,3]`：全数组 AND 为 `0`，但区间外为空，一次操作后是 `[0,0,0]`，其实也只需 1 次——注意这里区间外为空时恒成立。

```python
def minOperations(nums):
    if len(set(nums)) == 1:
        return 0
    n = len(nums)
    # 尝试所有子数组，看能否一次搞定
    for l in range(n):
        cur = nums[l]
        for r in range(l, n):
            if r > l:
                cur &= nums[r]
            # 区间外元素必须都等于 cur
            ok = True
            for i in range(n):
                if not (l <= i <= r) and nums[i] != cur:
                    ok = False
                    break
            if ok:
                return 1
    return 2
```

实际上 n ≤ 100，三重循环最多 10^6 次，完全够用。

## 复杂度
时间：O(n^3)，枚举 l、r 与检查区间外各 O(n)。
空间：O(1)，只用了 `cur`、`ok` 等常数变量。

## 易错点
- 输入 `[1,2,3]` → 误以为要 2 次，因为全数组 AND 为 0 而原数组没有 0；正确做法是选 `[0,2]`，区间外为空，一次操作后 `[0,0,0]` 全相等，返回 1。
- 输入 `[1,1,2]` → 只检查全数组 AND（`1&1&2=0`）就返回 1，但选 `[0,2]` 得 `[0,0,0]` 确实可行；真正会错的是 `[1,2,1]` 这类，全数组 AND 为 0 但区间外无元素，仍返回 1——需注意「区间外为空」是合法的一次成功，别漏判。

## 如果面试官追问
问：如果要求输出具体操作方案怎么办？
答：记录使 `ok` 为真的 `(l, r)`，返回该区间；若为 2 次，先对全数组 AND 一次，再对剩余不同值区间操作。
