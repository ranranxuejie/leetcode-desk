## 一句话思路
离线倒序处理查询：把「删除」变成「加回」，用并查集维护每个电网的在线最小节点。

## 怎么做
1. 先对 `connections` 建并查集，得到每个电站所属的电网根；再对每个根维护一个有序集合（堆）存该电网所有节点，初始全在线。
2. 正序扫描 `queries`，把类型 2 的 `x` 标记为离线，并把它从所属电网的堆中弹出（惰性删除：只标记，不真删）。
3. 倒序重放查询：遇到 `[2,x]` 就把 `x` 重新上线并 push 回堆；遇到 `[1,x]` 时，若 `x` 在线则答案 `x`，否则取 `x` 所属电网堆顶的最小在线节点，堆空则 `-1`。
4. 用官方示例 1 走一遍：正序后离线集合是 `{1,2}`；倒序第一个 `[1,2]` 时 2 已离线，电网根下在线节点为 `{3,4,5}`，堆顶 `3`，答案 3；继续倒序遇到 `[2,2]` 把 2 加回，再遇到 `[1,1]` 时堆顶变 `2`，答案 2。

```python
# 倒序重放的核心几行（parent 为并查集，alive 为在线标记，heap 按根分组）
for t, x in reversed(queries):
    if t == 2:
        alive[x] = True
        heappush(heap[find(x)], x)
    else:
        if alive[x]:
            ans.append(x)
        else:
            h = heap[find(x)]
            ans.append(h[0] if h else -1)
ans.reverse()
```

关键中间值：示例 1 倒序处理到 `[1,1]` 时，`find(1)` 对应的堆内容为 `[2,3,4,5]`，`h[0] == 2`。

## 复杂度
时间：建图与并查集 O(c + n α(c))，每个查询一次堆操作 O(log c)，总计 O((c + n + q) log c)。
空间：并查集、alive 数组、按根分组的堆共 O(c + n)。

## 易错点
- 正序直接模拟删除：每次 `[1,x]` 都要在电网里线性找最小在线节点，`c=10^5`、`queries=2*10^5` 会退化成 O(cq) 超时；必须倒序把删除转成插入，让堆顶始终是最小在线节点。
- 惰性删除没做干净：正序标记离线时若只改 `alive` 不把节点从堆里清掉，倒序 `[1,x]` 可能取到已离线节点；正确做法是正序阶段就 `heappop` 掉（或倒序时只 push 回真正恢复的节点），保证堆内元素与 `alive` 一致。

## 如果面试官追问
问：如果要求在线（正序）实时回答，怎么改？答：每个电网再挂一个有序集合，删除时 O(log c) 摘除、查询取首元素，代价是额外 O(c) 结构与实现复杂度。
