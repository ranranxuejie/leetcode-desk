## 一句话思路
从右往左找最长的「无重复后缀」，它左边有 k 个元素，答案就是 ceil(k/3)。

## 怎么做
1. 倒序遍历 `nums`，用 `set` 记录已见元素，遇到重复就停，记下后缀起点 `i+1`。
2. 设 `k = i + 1`（需要被删掉的前缀长度），答案是 `(k + 2) // 3`。
3. 以 `nums = [1,2,3,4,2,3,3,5,7]` 为例：从右扫，`7,5,3,3` 时 `3` 重复，停在索引 6，`k = 7`，`(7+2)//3 = 3`？——注意这里要修正：重复发生在 `nums[6]=3`，后缀从索引 7 开始才无重复，`k = 7`，但示例答案是 2。原因是删 6 个元素（2 次操作）后剩 `[3,5,7]` 已互异，即只需保证「删完后剩下的后缀」无重复，而删 6 个后起点是索引 6，`[3,5,7]` 确实无重复。所以正确判据是：找最小的操作次数 t，使 `nums[3t:]` 无重复，即 `3t >= k` 中 k 为「最长无重复后缀的起点」。上面 `[3,5,7]` 起点 6，`3t >= 6` 得 t=2。
4. 代码：倒扫找最长无重复后缀起点 `start`，返回 `(start + 2) // 3`。

```python
seen = set()
start = len(nums)
for i in range(len(nums) - 1, -1, -1):
    if nums[i] in seen:
        break
    seen.add(nums[i])
    start = i
return (start + 2) // 3
```

关键中间值：示例 1 中 `start = 6`（后缀 `[3,5,7]`），`(6+2)//3 = 2`。

## 复杂度
时间：O(n)，倒扫一次，每个元素进 `set` 一次。
空间：O(n)，`seen` 最坏存整个数组的去重值。

## 易错点
- 输入 `[4,5,6,4,4]` → 若只找「最长无重复后缀」得 `start = 5`（空后缀），返回 `(5+2)//3 = 2`，恰好对；但若误用「第一个重复位置」当 k，会得 `k=3` 返回 1，错。正确做法是让 `start` 表示后缀起点，用 `(start+2)//3` 向上取整。
- 输入 `[6,7,8,9]` → 若忘记 `start` 初值为 `len(nums)` 且循环正常走完，可能返回 0 以外的值；正确做法是循环不 break 时 `start=0`，`(0+2)//3=0`。

## 如果面试官追问
若每次删 2 个而非 3 个？答：同一套倒扫，答案改成 `(start + 1) // 2`，向上取整的除数换成 2。
