## 一句话思路
枚举保留下来的频率下界 `base`，把每个字符裁到 `[base, base+k]` 区间内，取删除量最小者。

## 怎么做
1. 用 `Counter(word)` 统计频率，只保留非零值，排序得到 `freqs`（长度 ≤ 26）。
2. 枚举 `base` 取 `freqs` 中每个值（最优解的下界一定等于某个原频率，否则可整体上移不亏）。
3. 对每个 `base`，遍历 `freqs`：`f > base+k` 时删 `f-(base+k)`，`f < base` 时整段删掉 `f`，其余不动。
4. 累加删除量，取所有 `base` 中的最小值。

以 `word="dabdcbdcdcd", k=2` 为例：频率为 `a:1, b:2, c:3, d:5`。取 `base=2` 时，`a` 的 1 小于 2 全删（1），`d` 的 5 超过 `2+2=4` 删 1，`b`、`c` 不动，合计 2，与答案一致。

```python
from collections import Counter

freqs = sorted(Counter(word).values())
best = len(word)
for base in freqs:
    cost = 0
    for f in freqs:
        if f < base:
            cost += f
        elif f > base + k:
            cost += f - (base + k)
    best = min(best, cost)
```

注意 `base` 只从 `freqs` 里取，不要从 0 枚举到 `max(freqs)`——那样虽然也对，但多了一层无意义循环。

## 复杂度
时间：`O(26^2 + n)`，`n` 来自 `Counter` 扫描，26² 来自双层枚举。
空间：`O(26)`，只存频率表，与 `n` 无关。

## 易错点
- 输入 `word="aaabaaa", k=2`：若只考虑「削高频」不考虑「删低频」，会漏掉删掉 `b` 的 1 次、让 `a` 保持 6 的方案，错答成 0 或更大。正确做法是 `f < base` 时整段删除 `f`，因为低频字符无法靠删字符变高。
- 输入 `k=0` 且频率为 `[1,2,3]`：若把 `base` 固定成最小值 1，会算出删 `1+1=2`；但取 `base=2` 只需删 `1+1=2`、取 `base=3` 删 `2+1=3`，最优其实是把 1 和 3 都往 2 靠。正确做法是枚举每个 `base` 而非只取最小频率。

## 如果面试官追问
要求输出具体删除方案怎么办？答：在枚举 `base` 时同步记录每个字符删多少，取最优 `base` 的那份记录，按字符逐个删即可。
