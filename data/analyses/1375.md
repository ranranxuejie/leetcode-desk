## 一句话思路
维护已翻转位置的最大值 `mx`，第 `i` 步后若 `mx == i`，说明 `1..i` 恰好全被翻过，计数加一。

## 怎么做
1. 遍历 `flips`，用 `enumerate(flips, 1)` 让步数 `i` 从 1 开始。
2. 每步更新 `mx = max(mx, x)`，`mx` 是前 `i` 步翻过的最大下标。
3. 判断 `mx == i`：因为 `flips` 是 `1..n` 的排列，前 `i` 步翻了 `i` 个互不相同的位置，若最大值恰为 `i`，这 `i` 个数只能正好是 `1..i`。
4. 成立则 `ans += 1`，最后返回 `ans`。

以 `flips = [3,2,4,1,5]` 为例：第 3 步时 `mx = max(3,2,4) = 4`，而 `i = 3`，`4 != 3`，不计数；第 4 步翻 `1`，`mx` 仍为 4，`i = 4`，`mx == i` 成立，`ans` 变 1；第 5 步 `mx = 5 == i`，`ans` 变 2。

```python
mx = 0
ans = 0
for i, x in enumerate(flips, 1):
    if x > mx:
        mx = x
    if mx == i:
        ans += 1
return ans
```

关键点：不需要真的维护字符串或布尔数组，`mx == i` 这一个等式就等价于「`[1,i]` 全 1、其余全 0」。因为前 `i` 步恰好翻了 `i` 个不同位置，最大值等于 `i` 意味着这 `i` 个位置全落在 `1..i` 内，而 `1..i` 只有 `i` 个位置，必然被占满。

## 复杂度
时间 O(n)：一次遍历 `flips`，每步 O(1) 比较。
空间 O(1)：只开 `mx`、`ans` 两个变量，不建字符串。

## 易错点
- 把条件写成 `mx <= i` 或 `mx >= i`：`flips = [4,1,2,3]` 第 2 步 `mx = 4`、`i = 2`，`mx >= i` 会误判成立，答案错成 3；必须严格 `mx == i`。
- 用 `enumerate(flips)` 从 0 开始数步：`flips = [3,2,4,1,5]` 第 4 个元素 `1` 时 `i = 3`，`mx = 4 != 3`，漏掉正确答案；必须 `enumerate(flips, 1)` 让步数与下标 1 对齐。

## 如果面试官追问
若 `flips` 不是排列、可能重复翻转同一位怎么办？答：`mx == i` 不再充分，需额外记录已翻位置数 `cnt`，条件改为 `mx == i and cnt == i`。
