## 一句话思路
枚举右端点 j，用前缀最大 `best = max(nums[0..j-k])` 配对，一次遍历得答案。

## 怎么做
1. 约束 `j - i >= k` 等价于 `i <= j - k`，所以固定 j 时只需在 `nums[0..j-k]` 里挑最大值。
2. 从左往右扫 j，维护一个变量 `best`，它始终等于 `max(nums[0..j-k])`；j 每加 1，就把 `nums[j-k]` 并入 best。
3. 对每个 j 算 `best + nums[j]` 更新答案，j 从 k 开始（否则 `j-k < 0` 没有合法 i）。

以 `nums = [1,3,5,2,8], k = 2` 为例：j=2 时先把 `nums[0]=1` 并入，`best=1`，候选 `1+5=6`；j=3 并入 `nums[1]=3`，`best=3`，候选 `3+2=5`；j=4 并入 `nums[2]=5`，`best=5`，候选 `5+8=13`，答案 13。注意 j=4 时 best 是 5 而不是 8——`nums[4]` 自己不能当 i。

```python
best = nums[0]
ans = 0
for j in range(k, len(nums)):
    best = max(best, nums[j - k])
    ans = max(ans, best + nums[j])
return ans
```

关键点：并入 `nums[j-k]` 必须发生在计算候选**之前**，这样 j 时刻的 best 覆盖的正好是 `0..j-k`。

## 复杂度
时间 O(n)：一次遍历，n 为 `len(nums)`。
空间 O(1)：只开 `best`、`ans` 两个变量。

## 易错点
- `nums = [5,1,9], k = 1` 时若把 `best` 初始化成 `nums[0]` 却在循环里先算候选再并入，j=1 会拿 `5+1=6`，漏掉 j=2 的 `5+9=14`；正确顺序是先 `best = max(best, nums[j-k])` 再算 `best + nums[j]`。
- 若把 `best` 写成「当前扫过的全局最大值」而不限制下标 `<= j-k`，`nums = [1,3,5,2,8], k = 2` 在 j=4 会取到 `nums[4]=8` 自身或 `nums[3]=2`，得到 10 或 16 这类非法值；必须只并入 `nums[j-k]` 这一个位置。

## 如果面试官追问
问：要求返回具体下标对而不只是和？
答：再存一个 `best_idx`，随 `best` 一起更新，命中时记录 `(best_idx, j)` 即可，空间仍是 O(1)。
