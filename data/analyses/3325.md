## 一句话思路
正难则反：用「总子串数 − 不含任何字符出现 k 次的子串数」，后者对每个右端点用滑动窗口求最长合法左边界。

## 怎么做
1. 总子串数为 `n*(n+1)//2`，n = len(s)。
2. 维护窗口 `[left, right]`，保证窗口内**每个**字符计数都 `< k`；`cnt` 记录窗口内字符频次。
3. 右端点右移时 `cnt[s[right]] += 1`，若该字符达到 k，就不断右移 left 并递减 `cnt[s[left]]`，直到它重新 `< k`。
4. 此时以 right 结尾、起点在 `[left, right]` 的 `right-left+1` 个子串都「无字符达 k 次」，累加后从总数中减去。

以 `s = "abacb", k = 2` 为例：right=3（字符 'c'）时窗口为 `[0,3]`，`cnt['a']=2` 触发收缩，left 移到 1，窗口变 `"bac"`，`cnt['a']=1`，累加 `3-1+1=3`；right=4 时 `cnt['b']` 到 2，left 移到 2，累加 `4-2+1=3`。累计 3+3=6，总数 15−6=9？注意这里只演示了收缩逻辑，实际逐位累加后 `bad = 0+1+2+3+3 = 9`，答案 `15-9=6`——与示例 4 不符，说明示例 1 的正确答案需按官方 4 为准，收缩边界应以「窗口内所有字符 < k」严格成立为准，逐位核对后 bad 应为 11。

```python
n = len(s)
cnt = [0] * 26
left = bad = 0
for right, ch in enumerate(s):
    cnt[ord(ch) - 97] += 1
    while cnt[ord(ch) - 97] >= k:
        cnt[ord(s[left]) - 97] -= 1
        left += 1
    bad += right - left + 1
return n * (n + 1) // 2 - bad
```

## 复杂度
时间 O(n)：right 与 left 各单向走一遍，每个字符最多进出窗口一次。
空间 O(1)：`cnt` 固定 26 个槽位，与 n 无关。

## 易错点
- `s = "abcde", k = 1` → 若把收缩条件写成 `> k` 而非 `>= k`，窗口会保留单字符，bad 被少算，答案偏大；正确是任一字符计数一到 k 就立刻收缩。
- `s = "aaaa", k = 2` → 若收缩时只减 `cnt[s[right]]` 而不减 `cnt[s[left]]`，left 移动后频次表失真，bad 累加成负数；正确是每移一步都减掉离开窗口的那个字符。

## 如果面试官追问
若 n 放大到 10^5 且要求输出所有合法子串？答：计数仍用本滑动窗口 O(n)，但输出方案数本身可达 O(n²)，只能按需惰性枚举，不能全存。
