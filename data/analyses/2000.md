## 一句话思路
用 `word.find(ch)` 拿到首次下标 `i`，把 `word[:i+1]` 切片反转后拼回 `word[i+1:]`。

## 怎么做
1. 先求 `i = word.find(ch)`，找不到返回 `-1`。
2. 若 `i == -1`，直接返回 `word`，不做任何切片。
3. 否则取前缀 `word[:i+1]`，用 `[::-1]` 反转，再与后缀 `word[i+1:]` 拼接。

以 `word = "abcdefd"`、`ch = 'd'` 为例：`find` 返回 `i = 3`，前缀是 `"abcd"`，反转得 `"dcba"`，后缀是 `"efd"`，拼接结果 `"dcbaefd"`。关键中间值就是 `i = 3` 和反转后的 `"dcba"`。

```python
i = word.find(ch)
if i == -1:
    return word
return word[:i + 1][::-1] + word[i + 1:]
```

也可以不用 `find`，手写循环找第一个 `ch` 的下标，逻辑等价：

```python
i = 0
while i < len(word) and word[i] != ch:
    i += 1
if i == len(word):
    return word
return word[i::-1] + word[i + 1:]
```

注意 `word[i::-1]` 的切片终点是 `i`（含），步长 `-1`，正好反转 `0..i`。两种写法都只扫一遍前缀，`i` 是唯一需要维护的变量。

## 复杂度
时间：`find` 或手写循环扫到 `i` 为止，最坏 O(n)，反转前缀再 O(i)，合计 O(n)。
空间：切片和拼接各产生长度 O(n) 的新字符串，额外 O(n)。

## 易错点
- `word = "abcd"`、`ch = 'z'` 时若忘记判 `i == -1`，`word[:-1+1]` 会变成 `word[:0]` 反转成空串，结果错成 `"abcd"` 之外的乱序；正确做法是先判 `-1` 直接返回原串。
- 反转区间是 `0..i` 含 `i`，若写成 `word[:i][::-1] + word[i:]`，`ch` 本身会被留在原位，`"abcdefd"` 会错成 `"dcbaefd"` 之外的 `"dcb" + "aefd"` 类结果；正确做法是前缀切片右端写 `i + 1`。

## 如果面试官追问
问：若要求反转**所有** `ch` 出现位置之前的前缀（每次基于新串）？
答：逐次 `find` 后更新串，注意每次 `find` 要在新串上重新定位，复杂度升到 O(n²)。
