## 一句话思路
用一个最小堆存已释放的座位号，再用指针 `next_seat` 记录从未被预约过的最小座位，`reserve` 时取两者较小值。

## 怎么做
1. 初始化 `next_seat = 1`，堆 `heap = []`，`next_seat` 指向「从未被预约过」的最小座位。
2. `reserve()`：若堆非空且 `heap[0] < next_seat`，弹出堆顶返回；否则返回 `next_seat` 并自增。
3. `unreserve(seatNumber)`：把该座位压入堆，等下次 `reserve` 时再和 `next_seat` 比较。

以官方示例 `n=5` 为例，前两次 `reserve` 后 `next_seat=3`、堆为空；`unreserve(2)` 后堆为 `[2]`。第三次 `reserve` 时 `heap[0]=2 < next_seat=3`，弹出 2 返回，`next_seat` 保持 3——这正是关键中间值，堆里的座位优先于指针。

```python
import heapq

class SeatManager:
    def __init__(self, n: int):
        self.next_seat = 1
        self.heap = []

    def reserve(self) -> int:
        if self.heap and self.heap[0] < self.next_seat:
            return heapq.heappop(self.heap)
        seat = self.next_seat
        self.next_seat += 1
        return seat

    def unreserve(self, seatNumber: int) -> None:
        heapq.heappush(self.heap, seatNumber)
```

## 复杂度
时间：`reserve`/`unreserve` 均摊 O(log n)，堆操作贡献 log n，总调用次数 m ≤ 10^5。
空间：堆最多存 O(n) 个已释放座位，`next_seat` 是 O(1)。

## 易错点
- 若 `reserve` 只从堆取而不比较 `next_seat`：当堆为空但还有未预约座位（如示例第三次调用后堆空、`next_seat=3`）会取错或越界，正确做法是每次都比较 `heap[0]` 与 `next_seat` 取较小。
- 若 `unreserve` 时直接把 `next_seat` 回退：示例中 `unreserve(2)` 后 `next_seat` 已是 3，回退会重复发放 2 且丢失 3，正确做法是只压堆、不动指针。

## 如果面试官追问
若 n 扩大到 10^9 但调用次数仍 ≤ 10^5，还能用这方法吗？能，堆只存被释放的座位，`next_seat` 是整数，空间与 n 无关。
