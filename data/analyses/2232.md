## 一句话思路
枚举左括号在 `+` 左侧的切点 `i` 和右括号在 `+` 右侧的切点 `j`，共 O(n²) 种，逐一算值取最小。

## 怎么做
1. 用 `expression.index('+')` 拿到 `p`，左半 `a = expression[:p]`，右半 `b = expression[p+1:]`。
2. 左括号位置 `i` 取 `0..len(a)-1`，右括号位置 `j` 取 `0..len(b)-1`，组合遍历。
3. 每种组合拆成三段：`a[:i]`、`a[i:] + '+' + b[:j+1]`、`b[j+1:]`，空串按 1 处理，三者相乘。
4. 记录乘积最小时的 `(i, j)`，最后按同样规则拼回字符串。

以 `"247+38"` 为例：`a="247"`，`b="38"`。当 `i=1, j=1` 时，三段是 `"2"`、`"47+3"`、`"8"`，值 `2 * 50 * 8 = 800`；当 `i=1, j=0` 时，三段是 `"2"`、`"47+38"`、`""`（按 1），值 `2 * 85 * 1 = 170`，这就是最优。注意 `j=0` 时右括号紧贴 `+` 右侧，第三段为空串，必须乘 1 而不是跳过。

```python
p = expression.index('+')
a, b = expression[:p], expression[p+1:]
best, bi, bj = None, 0, 0
for i in range(len(a)):
    for j in range(len(b)):
        left = int(a[:i]) if i else 1
        mid = int(a[i:]) + int(b[:j+1])
        right = int(b[j+1:]) if j + 1 < len(b) else 1
        if best is None or left * mid * right < best:
            best, bi, bj = left * mid * right, i, j
return a[:bi] + '(' + a[bi:] + '+' + b[:bj+1] + ')' + b[bj+1:]
```

## 复杂度
时间 O(n²)：`i`、`j` 双重循环，每次 `int()` 转换最多 O(n)，n 为表达式长度。
空间 O(n)：只存 `a`、`b` 和结果字符串，无额外数组。

## 易错点
- 输入 `"12+34"` 时若只枚举 `i` 不枚举 `j`，会漏掉 `"1(2+3)4"` 这个 `1*5*4=20` 的解，错答成 `"(12+3)4"=60`；必须两层循环都枚举。
- 输入 `"999+999"` 时若把空串段直接跳过不乘，`i=0, j=len(b)-1` 会算成 `999+999=1998` 却漏乘两侧的 1，虽然本题结果碰巧对，但 `"1+1"` 这类会算错；空串段必须显式乘 1。

## 如果面试官追问
问：若允许加多对括号呢？答：本题只有一对，多对时需区间 DP，按 `+` 分割枚举括号覆盖范围，复杂度升到 O(n³)。
