## 一句话思路
把「排列 words 使相邻重叠最大」建成 TSP：`dp[mask][i]` 记以 i 结尾的最短串长，回溯出顺序再拼接。

## 怎么做
1. 预处理 `overlap[i][j]`：words[i] 后缀与 words[j] 前缀的最长匹配长度，取 `min(len_i, len_j)` 为上限。
2. 状态 `dp[mask][i]` = 已用集合 mask、末尾为 i 时的最短总长，转移 `dp[mask|1<<j][j] = min(dp[mask][i] + len_j - overlap[i][j])`。
3. 记录 `parent[mask][j]`，从满 mask 的最小 dp 值回溯出顺序，再按 overlap 拼接。

以示例 2 为例，`overlap[2][1]`（"gcta"→"ctaagt"）为 3，因为 "gcta" 的后缀 "cta" 等于 "ctaagt" 的前缀；拼接时只追加 "agt"，长度 4+6-3=7。最终顺序 gcta→ctaagt→ttca→catg→atgcatc 得 "gctaagttcatgcatc"。

```python
n = len(words)
ov = [[0]*n for _ in range(n)]
for i in range(n):
    for j in range(n):
        if i != j:
            for k in range(min(len(words[i]), len(words[j])), 0, -1):
                if words[i][-k:] == words[j][:k]:
                    ov[i][j] = k
                    break
INF = float('inf')
dp = [[INF]*n for _ in range(1 << n)]
par = [[-1]*n for _ in range(1 << n)]
for i in range(n):
    dp[1 << i][i] = len(words[i])
for mask in range(1 << n):
    for i in range(n):
        if dp[mask][i] == INF:
            continue
        for j in range(n):
            if not (mask >> j) & 1:
                nm, nd = mask | (1 << j), dp[mask][i] + len(words[j]) - ov[i][j]
                if nd < dp[nm][j]:
                    dp[nm][j], par[nm][j] = nd, i
```

## 复杂度
时间：O(2^n · n^2)，状态数 2^n·n，每个状态枚举 n 个后继。
空间：O(2^n · n)，dp 与 par 两张表，外加 O(n^2) 的 ov。

## 易错点
- 预处理 overlap 时上限写成 `len(words[j])` 而非 `min(len_i, len_j)`：如 words=["ab","b"] 会算出 1 但实际 "b" 是 "ab" 子串，题面保证无包含关系所以不炸，但换成 ["abc","bc"] 这类边界会越界取到错误重叠，正确做法是 `range(min(...), 0, -1)`。
- 回溯时从 `dp[(1<<n)-1]` 里取最小值的下标作为终点，而不是固定取 n-1：示例 2 的最优终点是 "atgcatc"（下标 4），固定取最后一个词会拼出更长的串。

## 如果面试官追问
问：n 增大到 20 以上怎么办？答：状压 DP 的 2^n 撑不住，只能退化成贪心按 overlap 排序的近似解，或改用 A* 搜索。
