## 一句话思路
对每个等于 `target[0]` 的格子做 DFS 回溯，用原地改字符标记已访问，逐位匹配 `target`。

## 怎么做
1. 遍历 `grid` 每个 `(i, j)`，只从 `grid[i][j] == target[0]` 的位置起搜，其余直接跳过。
2. DFS 参数带 `k`（当前要匹配 `target[k]`），越界、字符不等、已访问都立即返回 `False`。
3. 进入时把 `grid[i][j]` 暂存并改成 `'#'`，四个方向递归，返回前恢复原字符。
4. `k == len(target) - 1` 时直接返回 `True`，省掉最后一层递归。

以示例 3 `target = "ABCB"` 为例：从 `(0,0)='A'` 出发走到 `(0,1)='B'`、`(0,2)='C'`，此时 `k=2`，`grid[0][1]` 已被改成 `'#'`；下一步要匹配 `target[3]='B'`，四个邻居是 `'#'`、`'E'`、`'F'`、`'S'`，全不等，回溯返回 `False`，最终输出 `False`。

```python
def dfs(i, j, k):
    if not (0 <= i < m and 0 <= j < n) or grid[i][j] != target[k]:
        return False
    if k == len(target) - 1:
        return True
    tmp, grid[i][j] = grid[i][j], '#'
    ok = any(dfs(i + di, j + dj, k + 1)
             for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)))
    grid[i][j] = tmp
    return ok
```

外层 `for i in range(m): for j in range(n): if dfs(i, j, 0): return True`，全跑完返回 `False`。

## 复杂度
时间：`O(m * n * 3^L)`，`L = len(target)`，每格首步 4 方向、之后 3 方向（不回踩）。
空间：递归栈 `O(L)`，原地改字符不额外开 visited 数组。

## 易错点
- 忘记恢复 `grid[i][j] = tmp`：示例 1 中 `(0,1)='B'` 被永久改成 `'#'` 后，后续从别的起点搜索时该格不可用，本应 `True` 的用例可能返回 `False`。正确做法是 `any(...)` 之后无条件恢复。
- 把 `k == len(target) - 1` 的判断放在字符比较之前：示例 2 `target="SEE"` 走到 `k=2` 时若先判终止，会把不匹配的格子也当成功。正确顺序是先校验 `grid[i][j] != target[k]` 再判终止。

## 如果面试官追问
问：`target` 长度涨到 10^4 怎么办？答：回溯指数爆炸，改用「反向删字符」——从 `target` 尾部逐个剥掉能在 `grid` 中找到的字符，或直接判定不可行。
