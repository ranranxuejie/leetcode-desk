## 一句话思路
按位置 DP，`dp[i]` 表示后缀 `caption[i:]` 变好标题的最小代价，每步枚举把 `caption[i:i+3]` 统一成某个字母。

## 怎么做
1. 从右往左算 `dp[i]`，`dp[n]=0`，`dp[i]` 由 `dp[i+3]` 转移，因为每组至少 3 个字符。
2. 枚举目标字母 `c` 从 `'a'` 到 `'z'`，代价是 `caption[i:i+3]` 三个字符到 `c` 的绝对距离之和，取 `cost + dp[i+3]` 最小。
3. 字典序最小：代价相同时选更小的 `c`；由于从右往左，`dp[i]` 只依赖后缀，贪心选最小 `c` 不会破坏最优性。
4. 长度不足 3 或 `dp[0]` 不可达返回 `""`。

以 `caption = "cdcd"` 为例：`dp[4]=0`，`dp[1]` 处理 `"dcd"`，统一成 `'c'` 代价 `|d-c|+|c-c|+|d-c|=2`，`dp[1]=2`；`dp[0]` 处理 `"cdc"`，统一成 `'c'` 代价 `0+1+0=1`，加 `dp[3]`（`"d"` 不足 3，不可达）——实际 `dp[0]` 只能走 `dp[3]`，而 `dp[3]` 不可达，所以 `dp[0]` 走 `dp[3]` 失败；正确转移是 `dp[0]` 用 `caption[0:3]="cdc"` 加 `dp[3]`，`dp[3]` 处理 `"d"` 不足 3 不可达，故 `dp[0]` 需从 `dp[3]` 之外——实际 `n=4`，`dp[0]` 只能覆盖前 3 个，剩 1 个无法成组，所以 `dp[0]` 不可达？但答案是 `"cccc"`，说明分组是 `[0,1,2,3]` 四个一组。修正：每组长度可以是 3 或 4，转移用 `dp[i+3]` 和 `dp[i+4]`。

```python
n = len(caption)
if n < 3: return ""
INF = 10**9
dp = [INF] * (n + 1)
dp[n] = 0
for i in range(n - 1, -1, -1):
    for L in (3, 4):
        if i + L > n: continue
        for c in range(26):
            cost = sum(abs(ord(caption[i+j]) - ord('a') - c) for j in range(L))
            dp[i] = min(dp[i], cost + dp[i+L])
```

## 复杂度
时间：`O(26 * n * 4)`，n 为 `caption` 长度，常数 26 和 4 可忽略。
空间：`O(n)`，`dp` 数组长度 `n+1`。

## 易错点
- 只按 3 分组 → 对 `"cdcd"` 会算出 `dp[0]` 不可达返回 `""`，正确做法是同时允许长度 4 的组，转移 `dp[i+4]`。
- 代价相同时没选最小字母 → 对 `"aca"` 统一成 `'a'` 和 `'b'` 代价都是 2，若先枚举 `'b'` 会返回 `"bbb"`，正确做法是 `c` 从 `'a'` 升序枚举并严格小于才更新。

## 如果面试官追问
问：若要求输出所有最优方案中字典序最小的完整字符串而非只算代价？答：在 DP 里同时存每个 `dp[i]` 对应的最优后缀字符串，转移时按 `(cost, 字符串)` 比较取最小。
