## 一句话思路
按值统计频次，每个频次 c 独立求最少操作数：c 为 1 时无解，否则用尽量多的 3 元操作，余数用 2 元操作补齐。

## 怎么做
1. 用 `Counter(nums)` 得到每个值出现的次数，问题按值拆成互不影响的子问题。
2. 对单个频次 c：c == 1 直接返回 -1（1 个元素凑不出 2 或 3）。
3. 其余情况取 `c // 3` 次三元操作，再看余数 `c % 3`：余 0 收工；余 2 补一次二元操作；余 1 时把一次三元拆成 2+2（即三元次数减 1，二元次数加 2）。
4. 把每个频次的操作数累加。

以示例 1 的 `nums = [2,3,3,2,2,4,2,3,4]` 为例，频次为 `{2:4, 3:3, 4:2}`：c=4 时 `4//3=1`、余 1，拆成 2+2 得 2 次；c=3 得 1 次；c=2 得 1 次，合计 4。

```python
from collections import Counter

def min_ops(nums):
    ans = 0
    for c in Counter(nums).values():
        if c == 1:
            return -1
        q, r = divmod(c, 3)
        if r == 0:
            ans += q
        elif r == 2:
            ans += q + 1
        else:              # r == 1，且 c >= 4
            ans += q + 1   # q-1 次三元 + 2 次二元
    return ans
```

注意 `r == 1` 分支里 `q + 1` 恰好等于 `(q-1) + 2`，不用分开写两个计数。

## 复杂度
时间 O(n)：Counter 扫一遍 nums，之后遍历不同值的个数。
空间 O(k)：k 为不同值的个数，最坏 O(n)。

## 易错点
- 频次为 1 时返回 -1，但别把「余数为 1」也当成无解：`c=4` 时 `4%3==1`，正确是 2 次（2+2），若直接返回 -1 或写成 `q+2` 就错。判无解只看 `c == 1`。
- 余数为 1 时不能简单 `ans += q + 1` 就以为用了 q 次三元：`c=7` 时 `7//3=2` 余 1，实际是 1 次三元 + 2 次二元共 3 次，写成 `q+1=3` 数值对但含义要对得上，别在需要输出方案时按 q 次三元去还原。

## 如果面试官追问
要求输出具体操作方案怎么办？答：对每个频次按 `q-1` 次三元、2 次二元（余 1）或 `q` 次三元加 1 次二元（余 2）展开，记录每个值剩余个数即可还原。
