## 一句话思路
先按长度分三种情况，长度在 [6,20] 内只处理重复段和缺类，超长时用删除优先削 `len%3==0` 的重复段。

## 怎么做
1. 统计缺失字符种类 `miss = 3 - (有小写) - (有大写) - (有数字)`，并把每个连续重复段长度记入 `runs`。
2. `n < 6`：答案是 `max(miss, 6 - n)`，因为插入既能补长度也能顺手补种类、还能打断重复。
3. `6 <= n <= 20`：答案是 `max(miss, sum(L // 3 for L in runs))`，替换一步同时能补种类和打断一段。
4. `n > 20`：先算必须删的 `need = n - 20`，按 `L % 3` 从小到大（0、1、2）消耗删除额度，每删 1 个能让该段少一次替换；剩余额度再按每 3 个换 1 次替换抵扣。

以 `"a"` 为例：`n=1`，`miss=2`（缺大写、数字），`6-n=5`，`max(2,5)=5`，与输出一致。

```python
runs = []
i = 0
while i < n:
    j = i
    while j < n and password[j] == password[i]:
        j += 1
    if j - i >= 3:
        runs.append(j - i)
    i = j

if n < 6:
    return max(miss, 6 - n)
replace = sum(L // 3 for L in runs)
if n <= 20:
    return max(miss, replace)

need = n - 20
for mod in (0, 1, 2):
    for k, L in enumerate(runs):
        if need <= 0:
            break
        if L % 3 == mod:
            use = min(need, L // 3 if mod == 0 else 1)
            runs[k] -= use * (mod + 1)
            need -= use * (mod + 1)
replace = sum(L // 3 for L in runs)
return (n - 20) + max(miss, replace - need // 3)
```

## 复杂度
时间：O(n)，扫描一遍字符串并遍历 `runs`，`runs` 长度不超过 n。
空间：O(n)，最坏存 n/3 个段长。

## 易错点
- 输入 `"aaaAAA111"`（n=9）→ 只算 `miss=0` 就返回 0 → 正确是 `max(0, 3)=3`，每段 `L//3=1` 必须计入替换。
- 输入 `"aaaaa"`（n=5）→ 用 `max(miss, 5//3)=1` 得 1 → 正确是 `max(miss, 6-5)=1` 但若 `"a"` 这类短串漏掉 `6-n` 会得 2 而非 5，短串必须走 `6-n` 分支。

## 如果面试官追问
问：若允许「交换相邻字符」作为新操作，答案怎么变？
答：交换不改变字符计数和段长奇偶性，只影响段内顺序，需重新推导 `runs` 的削减规则，不能直接复用 `L//3`。
