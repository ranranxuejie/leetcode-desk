## 一句话思路
二分答案 `d`，用贪心检查能否让每个工人间隔至少 `d` 地依次落位。

## 怎么做
1. 答案单调：若间隔 `d` 可行，则更小的 `d` 也可行，故二分 `d ∈ [0, m-1]`。
2. 检查函数：从 `station` 左端开始，为 `skill[0]` 找第一个匹配位置 `p`，之后每个工人从 `p+d` 起找第一个匹配字符。
3. 用 `station.find(skill[i], pos)` 一步跳到下一个匹配下标，找不到返回 `-1` 即失败。
4. 以 `skill="xyz", station="xyzz"` 为例：`d=2` 时 `p=0`，工人 1 从 `0+2=2` 起找 `'y'` 得 `-1`，失败；`d=1` 时得 `p=0,1,3`，成功，故答案为 2。

```python
def ok(d):
    pos = 0
    for ch in skill:
        pos = station.find(ch, pos)
        if pos == -1:
            return False
        pos += d
    return True

lo, hi = 0, len(station) - 1
while lo < hi:
    mid = (lo + hi + 1) // 2
    if ok(mid):
        lo = mid
    else:
        hi = mid - 1
return lo
```

注意 `ok` 里 `pos += d` 放在 `find` 之后，第一个工人不受 `d` 约束，这与「间隔是相邻差」一致。

## 复杂度
时间：二分 `log m` 轮，每轮 `find` 总扫描不超过 `m`，共 `O((n+m) log m)`。
空间：只用了 `pos`、`lo`、`hi`、`mid` 几个整数，`O(1)`。

## 易错点
- `skill="aa", station="aaaa"`：若把 `pos += d` 写在 `find` 之前，第一个工人就被要求从下标 `d` 起找，`d=3` 时 `find('a',3)=3` 后第二个工人从 6 起找失败，答案错成 2；正确是首个工人从 0 起找。
- `skill="cbc", station="cbcdbc"`：若检查时只验证「每个字符在 station 中出现过」而不维护递增下标，会误判 `d=5` 可行；必须用 `find(ch, pos)` 保证 `j0<j1<j2` 严格递增。

## 如果面试官追问
问：要求输出具体分配方案而非最大间隔？
答：`ok` 里把每次 `find` 得到的 `pos` 存进列表，二分收敛后重跑一次 `ok(lo)` 返回该列表即可。
