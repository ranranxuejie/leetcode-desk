## 一句话思路
把每个数约去自身平方因子后，强度等于两数约分后剩余部分的乘积，枚举所有数对取最大。

## 怎么做
1. 化简公式：设 `g = gcd(a, b)`，`a = g*x`，`b = g*y`，则强度 `= (g*x*g*y)/g² = x*y`，其中 `gcd(x, y) = 1`。
2. 关键观察：`x = a/gcd(a,b)` 只由 `a` 和两数的公共因子决定，无法单独预处理成「每个数一个值」——因为 `g` 依赖配对对象。所以直接双重循环枚举 `i < j`。
3. 对每对算 `g = gcd(nums[i], nums[j])`，强度 `= (nums[i]//g) * (nums[j]//g)`，用 `max` 更新答案。
4. 用具体输入验证：`nums = [4,6,8]`，取 `i=1, j=2` 即 `6` 和 `8`，`g = gcd(6,8) = 2`，强度 `= (6//2)*(8//2) = 3*4 = 12`，与示例一致。

```python
from math import gcd

best = 0
n = len(nums)
for i in range(n):
    for j in range(i + 1, n):
        g = gcd(nums[i], nums[j])
        best = max(best, (nums[i] // g) * (nums[j] // g))
return best
```

注意 `(nums[i]//g) * (nums[j]//g)` 先除后乘，避免 `nums[i]*nums[j]` 在中间步骤变大；Python 本身不溢出，但先除更贴近公式 `x*y` 的语义。

## 复杂度
时间：O(n² · log M)，n 来自双重循环，log M 来自每次 gcd（M = max(nums)）。
空间：O(1)，只开了 `g`、`best` 几个标量。

## 易错点
- 输入 `nums = [3,3]` → 若先算 `nums[i]*nums[j] = 9` 再除以 `g² = 9` 得 1 没问题，但若误写成除以 `g` 会得 3 → 正确是除以 `g²`，等价于先各自除 `g` 再相乘，得 `1*1 = 1`。
- 输入 `nums = [4,6,8]` → 若只比较相邻或只取最大值 `8` 与次大值 `6` 之外的组合会漏解；本题最大对是 `(6,8)` 而非 `(4,8)`（`(4,8)` 强度 `= 1*2 = 2`）→ 必须枚举全部 `i < j`，不能靠排序贪心。

## 如果面试官追问
问：n 放大到 10⁵ 怎么办？答：按「约去平方因子后的值」分组，同组内取最大两数相乘，跨组需枚举因子对，复杂度降到 O(M log M) 级别。
