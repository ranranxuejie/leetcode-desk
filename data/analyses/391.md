## 一句话思路
用「面积和 + 顶点异或」判定：总面积等于包围盒面积，且所有小矩形顶点按出现次数奇偶抵消后只剩包围盒四角。

## 怎么做
1. 扫描所有矩形，累加面积 `area += (a-x)*(b-y)`，同时更新包围盒 `minx, miny, maxx, maxy`。
2. 若 `area != (maxx-minx)*(maxy-miny)`，直接返回 `False`（示例 2 中面积和 6，包围盒 3×3=9，立刻判否）。
3. 用集合 `corners` 对每个矩形的四个角做「出现则删、不出现则加」的异或操作。
4. 最后检查 `corners == {(minx,miny),(minx,maxy),(maxx,miny),(maxx,maxy)}`。

以示例 1 为例：面积和 = 4+1+2+1+1 = 9，包围盒 (1,1)-(4,4) 面积 9，通过；顶点异或后只剩 (1,1),(1,4),(4,1),(4,4)，返回 `True`。

```python
area = 0
corners = set()
for x, y, a, b in rectangles:
    area += (a - x) * (b - y)
    minx, miny = min(minx, x), min(miny, y)
    maxx, maxy = max(maxx, a), max(maxy, b)
    for p in ((x,y),(x,b),(a,y),(a,b)):
        corners.symmetric_difference_update([p])
if area != (maxx-minx)*(maxy-miny):
    return False
return corners == {(minx,miny),(minx,maxy),(maxx,miny),(maxx,maxy)}
```

## 复杂度
时间：O(n)，n 为矩形个数，每个矩形常数次哈希操作。
空间：O(n)，`corners` 最多存 4n 个顶点。

## 易错点
- 只查面积和顶点、不查包围盒四角：示例 3 中面积和 4+1+1+4=10，包围盒 3×3=9 已不等，但若构造面积恰好相等的重叠输入（如两个 2×2 叠成 2×3 加一个 2×1 补角），顶点集合会多出内部点，必须严格比对四角集合而非仅判非空。
- 顶点用计数而非异或：三个矩形共享同一内部顶点时，计数为 3 仍非零，异或会误消成 0；本题精确覆盖下内部顶点必为偶数次，用 `symmetric_difference_update` 等价于奇偶，但若改用 `add` 去重会漏判重叠。

## 如果面试官追问
若矩形数增到 10^6 且坐标范围小，怎么做？答：改用扫描线按 x 切分，逐段维护 y 区间覆盖长度，校验每段并集连续且总长等于包围盒高。
