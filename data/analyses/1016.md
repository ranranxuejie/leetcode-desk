## 一句话思路
把 s 里所有长度 ≤ len(bin(n))-2 的二进制子串丢进 set，再逐个查 1..n 的二进制是否在其中。

## 怎么做
1. 先算 `L = len(bin(n)) - 2`，即 n 的二进制位数；任何 ≤ n 的数位数不超过 L。
2. 枚举 s 中所有长度 1..L 的子串加入集合 `seen`（长度超过 L 的子串不可能是 1..n 的表示，直接跳过）。
3. 对 `i in range(1, n+1)`，若 `bin(i)[2:] not in seen` 立即返回 `False`。
4. 全部命中返回 `True`。

以 `s = "0110", n = 3` 为例：`bin(3) = '0b11'`，`L = 2`。枚举长度 1、2 的子串得 `seen = {'0','1','01','11','10'}`。检查 `i=1`→`'1'` 在，`i=2`→`'10'` 在，`i=3`→`'11'` 在，返回 `True`。若 `n=4`，`bin(4)='100'`，`L=3`，`'100'` 不在 `seen` 中，返回 `False`。

```python
L = len(bin(n)) - 2
seen = set()
for length in range(1, L + 1):
    for start in range(len(s) - length + 1):
        seen.add(s[start:start + length])
for i in range(1, n + 1):
    if bin(i)[2:] not in seen:
        return False
return True
```

关键剪枝：`n` 可达 10^9，但 `L ≤ 30`，所以子串枚举量是 `O(len(s) * L)` 而非 `O(len(s)^2)`；同时若 `n` 很大而 `s` 很短，`seen` 装不下所有数，循环会在早期 `i` 就返回 `False`，不会真的跑满 10^9 次——但最坏情况（`s` 恰好覆盖）仍需注意，见易错点。

## 复杂度
时间：枚举子串 `O(len(s) * log n)`，校验 `O(n * log n)`（每次 `bin(i)` 与哈希比较）。
空间：`seen` 存至多 `len(s) * log n` 个子串，`O(len(s) * log n)`。

## 易错点
- `s = "0110", n = 4`：若只枚举长度恰为 `L` 的子串，会漏掉 `'1'`、`'10'` 等短表示，误判 `True`。必须枚举长度 1..L 全部子串。
- `n = 1, s = "0"`：`bin(1)[2:] = '1'` 不在 `{'0'}` 中，应返回 `False`；若把 `range(1, n+1)` 写成 `range(n)` 会漏查 `n` 本身，误判 `True`。循环上界必须是 `n+1`。

## 如果面试官追问
问：n 到 10^9 时逐个校验会不会超时？答：`s` 长度 ≤ 1000 时 `seen` 最多约 3 万个子串，一旦 `i` 超过 `2**L` 量级必然缺失提前返回，实际不会跑满 n 次。
