## 一句话思路
用一个队列，push 后把新元素前面的所有元素依次搬到队尾，队头恒为栈顶。

## 怎么做
1. push(x) 时先 `q.append(x)`，此时 x 在队尾。
2. 记下当前长度 `n = len(q)`，把前 `n-1` 个元素逐个 `q.append(q.popleft())` 搬到队尾，x 就转到队头。
3. pop 直接 `q.popleft()`，top 直接 `q[0]`，empty 判 `not q`。

以官方示例为例：push(1) 后队列 `[1]`，n=1，搬 0 个，队头是 1。再 push(2)：先 `[1,2]`，n=2，搬 1 个——把 1 移到队尾得 `[2,1]`，队头变成 2。此时 top 返回 `q[0]=2`，pop 弹出 2 后队列 `[1]`，empty 返回 `False`。

```python
from collections import deque

class MyStack:
    def __init__(self):
        self.q = deque()

    def push(self, x):
        self.q.append(x)
        for _ in range(len(self.q) - 1):
            self.q.append(self.q.popleft())

    def pop(self):
        return self.q.popleft()

    def top(self):
        return self.q[0]

    def empty(self):
        return not self.q
```

关键就一行：`for _ in range(len(self.q) - 1)` 里的 `len(self.q)` 在循环开始时已固定，循环中 append 不会让它多搬。

## 复杂度
时间：push 为 O(n)，pop/top/empty 为 O(1)，n 是当前栈内元素数。
空间：O(n)，只开了一个 deque 存全部元素，无额外结构。

## 易错点
- push 时写成 `for _ in range(len(self.q))` → 会把刚入队的 x 也搬回队尾，队头变成旧元素，top 返回错误值（示例中会返回 1 而非 2）→ 必须减 1。
- 用两个队列时在 pop 里把元素倒来倒去 → 容易漏掉「最后一个元素不回填」导致栈顶丢失 → 单队列方案在 push 阶段一次性旋转，pop 只做 popleft，不会踩这个坑。

## 如果面试官追问
追问：能否不用 deque 只用 list？答：可以，用 `list.pop(0)` 模拟 popleft，但每次 O(n)，push 退化为 O(n²)，仅小数据可接受。
