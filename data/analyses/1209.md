## 一句话思路
用栈存 `(字符, 连续计数)`，新字符与栈顶相同则计数加一，满 k 就弹出，天然处理删除后左右拼接。

## 怎么做
1. 遍历 `s` 的每个字符 `c`，维护栈 `st`，元素是 `[字符, 计数]`。
2. 若 `st` 非空且 `st[-1][0] == c`，则 `st[-1][1] += 1`；否则压入 `[c, 1]`。
3. 若栈顶计数达到 `k`，立即 `st.pop()`——这一步等价于删掉这 k 个字符，且让更早的字符重新相邻。
4. 最后把栈里每个字符按计数重复拼起来。

以 `s = "deeedbbcccbdaa", k = 3` 为例，扫到第 4 个字符时栈是 `[['d',1],['e',3]]`，`['e',3]` 计数满 3 被弹出，栈回到 `[['d',1]]`；继续扫 `bb` 得 `[['d',1],['b',2]]`，再遇 `b` 变 `['b',3]` 又弹出。关键中间值就是「弹出后栈顶仍是 `d`」，后续的 `d` 才能继续累加。

```python
st = []
for c in s:
    if st and st[-1][0] == c:
        st[-1][1] += 1
    else:
        st.append([c, 1])
    if st[-1][1] == k:
        st.pop()
return ''.join(ch * cnt for ch, cnt in st)
```

注意 `st[-1][1] == k` 用等号而非 `>=`：计数每次只加一，不会跳过 k。

## 复杂度
时间 O(n)：每个字符进栈出栈各一次，n 为 `len(s)`。
空间 O(n)：栈最多存 n 个 `[字符, 计数]`，输出串另占 O(n)。

## 易错点
- 输入 `s = "aab", k = 2` 若只在「新字符与栈顶不同」时判断删除，会漏掉压栈后立刻满 k 的情况 → 正确做法是每轮循环末尾统一检查 `st[-1][1] == k` 并弹出，与是否新压栈无关。
- 输入 `s = "deeedbbcccbdaa", k = 3` 若用「先删一段再重扫整串」的暴力法，删除 `eee` 后 `d` 与 `bbb` 相邻，需反复回退，容易写成 O(n²) 或死循环 → 用栈的计数合并让「删除后拼接」自动发生，无需回退指针。

## 如果面试官追问
问：若要求返回所有可能的删除顺序方案数？答：栈只能给唯一终态，方案数需在弹出时对相同字符段做组合计数，属于另一类区间 DP，不能复用本解。
