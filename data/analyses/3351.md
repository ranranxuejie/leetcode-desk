## 一句话思路
按值域做 DP：`cnt[v]` 记 v 出现次数，`f[v]` 记以值 v 结尾的好子序列个数，`g[v]` 记这些子序列的元素和，只从 v-1 转移。

## 怎么做
1. 统计每个值出现次数 `cnt[v]`，值域上界取 `max(nums)`。
2. 从小到大枚举 v，先算「只含单个 v」的贡献：`f[v] += cnt[v]`，`g[v] += v * cnt[v]`。
3. 若 `v-1` 存在，把 v-1 结尾的每条子序列后面接一个 v，得到 `f[v] += f[v-1] * cnt[v]`，`g[v] += (g[v-1] + f[v-1] * v) * cnt[v]`。
4. 答案累加所有 `g[v]`，每步取模。

以 `nums = [1,2,1]` 为例：`cnt[1]=2, cnt[2]=1`。v=1 时 `f[1]=2, g[1]=2`；v=2 时先得 `f[2]=1, g[2]=2`，再接 v-1：`f[2] += 2*1 = 3`，`g[2] += (2 + 2*2)*1 = 8`，即 `g[2]=10`。总和 `2+10=14`，与示例一致。

```python
MOD = 10**9 + 7
cnt = [0] * (max(nums) + 2)
for x in nums:
    cnt[x] += 1
f = [0] * (max(nums) + 2)
g = [0] * (max(nums) + 2)
ans = 0
for v in range(max(nums) + 1):
    f[v] = (f[v] + cnt[v]) % MOD
    g[v] = (g[v] + v * cnt[v]) % MOD
    if v > 0 and cnt[v]:
        g[v] = (g[v] + (g[v-1] + f[v-1] * v) * cnt[v]) % MOD
        f[v] = (f[v] + f[v-1] * cnt[v]) % MOD
    ans = (ans + g[v]) % MOD
```

## 复杂度
时间 O(n + V)，n 是数组长度，V 是 `max(nums)`，值域扫描贡献 V。
空间 O(V)，开了 `cnt`、`f`、`g` 三个长度 V+2 的数组。

## 易错点
- 输入 `[1,1,1]`：若把相同值的元素当成「连续元素差为 1」硬接，会算出 `[1,1]` 这类非法子序列。正确做法是相同值之间不转移，`f[v]` 只从 `f[v-1]` 来，重复元素只通过 `cnt[v]` 的乘法体现「选哪一个」。
- 输入 `[3,4,5]`：若在 v=4 时用 `g[4]` 覆盖而不是累加，会漏掉「只含 4」的贡献，答案变成 37 而非 40。正确做法是先加 `v*cnt[v]` 再加转移项，两项都进 `g[v]`。

## 如果面试官追问
问：值域开到 10^9 怎么办？答：把 `cnt` 换成哈希表，只对出现过的值排序后扫描，时间 O(n log n)，空间 O(n)。
