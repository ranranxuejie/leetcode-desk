## 一句话思路
按值域 1..200 做「每个数分给 seq1 / seq2 / 丢弃」的三路 DP，用 gcd 作为状态压缩。

## 怎么做
1. 设 `f[g1][g2]` 为处理完当前元素后，seq1 的 GCD 为 `g1`、seq2 的 GCD 为 `g2` 的方案数，`0` 表示该序列还空着。
2. 对 `nums` 里每个 `x`，新状态 = 丢弃（原样）+ 放进 seq1（`g1 -> gcd(g1,x)`）+ 放进 seq2（`g2 -> gcd(g2,x)`），三份都累加。
3. 全部处理完后，答案 = `sum(f[g][g] for g in 1..200)`，因为 `g=0` 表示空序列，不合法。
4. 用 `[1,2,3,4]` 走一遍：处理完 `1,2` 后 `f[1][1]` 已经含 `({1},{2})`、`({1,2},{1})` 等；最终 `f[1][1]` 贡献 10，其余 `g` 全为 0，输出 10。

```python
MOD = 10**9 + 7
M = 201
f = [[0] * M for _ in range(M)]
f[0][0] = 1
for x in nums:
    nf = [row[:] for row in f]          # 丢弃
    for g1 in range(M):
        for g2 in range(M):
            v = f[g1][g2]
            if v:
                nf[math.gcd(g1, x)][g2] = (nf[math.gcd(g1, x)][g2] + v) % MOD
                nf[g1][math.gcd(g2, x)] = (nf[g1][math.gcd(g2, x)] + v) % MOD
    f = nf
ans = sum(f[g][g] for g in range(1, M)) % MOD
```

注意 `gcd(0, x) = x`，所以「空序列第一次放元素」自动得到正确的 `g1 = x`，不用特判。

## 复杂度
时间：`O(n * V^2)`，`n = len(nums)`，`V = 200` 是值域上界，每步扫 201×201 个状态。
空间：`O(V^2)` 两张 201×201 表，`nf` 是每轮新开的拷贝。

## 易错点
- 输入 `[1,1,1,1]` → 若把 `g=0` 也算进答案，会多出「两个空序列」等非法对；正确做法是只累加 `g >= 1` 的 `f[g][g]`，得 50。
- 输入 `[10,20,30]` → 若原地更新 `f` 而不先拷贝 `nf`，同一个 `x` 会被重复放进 seq1 和 seq2，答案从 2 涨到 6；正确做法是每轮从旧表 `f` 读、往新表 `nf` 写。

## 如果面试官追问
问：`nums[i]` 放大到 10^5 怎么办？答：值域 DP 失效，改为按「GCD 只可能是某个数的约数」枚举候选 GCD，再对每个 `d` 统计能被 `d` 整除的元素个数做容斥。
