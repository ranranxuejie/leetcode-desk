## 一句话思路
用哈希表把每个值映射到它的索引列表，pick 时在列表里等概率随机取一个。

## 怎么做
1. 构造时遍历 `nums`，用 `defaultdict(list)` 把 `nums[i]` 追加到 `pos[nums[i]]`。
2. `pick(target)` 直接取 `pos[target]`，用 `random.choice` 返回其中一个索引。
3. 以官方示例 `nums = [1, 2, 3, 3, 3]` 为例：构造后 `pos[3] = [2, 3, 4]`，`pos[1] = [0]`；`pick(3)` 在 `[2, 3, 4]` 里等概率选，`pick(1)` 只能返回 0。

```python
from collections import defaultdict
import random

class _S:
    def __init__(self, nums):
        self.pos = defaultdict(list)
        for i, v in enumerate(nums):
            self.pos[v].append(i)

    def pick(self, target):
        return random.choice(self.pos[target])
```

关键中间值：`pos[3]` 长度 3，`random.choice` 内部取 `randrange(3)`，三个索引概率各 1/3。

## 复杂度
时间：构造 O(n) 遍历一次，pick O(1) 取列表加随机下标。
空间：O(n) 存所有索引，最坏全相同元素时 `pos` 里一个列表长 n。

## 易错点
- `nums = [3, 3, 3]` 且连续 `pick(3)` 多次 → 若用「记录上次返回下标再 +1 轮转」会变成确定性序列，不满足等概率 → 必须每次独立调用 `random.choice`，不复用状态。
- `target` 只出现一次（如示例 `pick(1)`）→ 若写成「随机取 0..n-1 再判等、不等就重试」在极端稀疏时会退化甚至死循环风险 → 正确做法是只在 `pos[target]` 这个精确列表里取，长度 1 时直接返回该索引。

## 如果面试官追问
追问：不允许额外 O(n) 空间怎么办？
答：用水塘抽样，遍历 `nums` 时对第 k 个匹配项以 1/k 概率替换答案，空间 O(1)、时间 O(n)。
