## 一句话思路
用快慢指针找链表中点当根，递归左右两半，天然平衡。

## 怎么做
1. 空链表直接返回 `None`，这是递归的出口。
2. 快指针 `fast` 每次走两步、慢指针 `slow` 每次走一步，同时用 `prev` 记住 `slow` 的前一个节点。
3. 当 `fast` 或 `fast.next` 为空时，`slow` 就是中点，`prev.next = None` 把链表切成两半。
4. 以 `slow.val` 建根，左子树递归 `head`，右子树递归 `slow.next`。

拿示例 `[-10,-3,0,5,9]` 走一遍：初始 `slow=-10, fast=-10`；一轮后 `slow=-3, fast=0`；再一轮 `slow=0, fast=9`，此时 `fast.next` 为 `None` 停下，根取 `0`，`prev=-3` 被置 `next=None`，左链 `[-10,-3]`、右链 `[5,9]` 各自递归，得到 `[0,-3,9,-10,None,5]`。

```python
def build(head):
    if not head:
        return None
    slow = fast = head
    prev = None
    while fast and fast.next:
        prev = slow
        slow = slow.next
        fast = fast.next.next
    if prev:
        prev.next = None
    root = TreeNode(slow.val)
    root.left = build(head if prev else None)
    root.right = build(slow.next)
    return root
```

注意 `prev` 为 `None` 说明只有一个节点，左子树必须传 `None` 而不是 `head`，否则 `head` 还是 `slow` 自己，无限递归。

## 复杂度
时间 O(n log n)：每层递归扫当前链表长度，共 log n 层。
空间 O(log n)：递归栈深度，链表本身不额外开数组。

## 易错点
- 输入 `[1]` 单节点 → 若左子树仍传 `head`，`head` 就是 `slow` 本身，`build` 无限递归爆栈 → 用 `prev` 是否为 `None` 判断，为 `None` 时左子树传 `None`。
- 输入 `[-10,-3,0,5,9]` → 若忘了 `prev.next = None`，左半段递归时 `fast` 会越过中点继续跑到右半段，左子树把 `5,9` 也吃进去，节点重复 → 切链必须在建根前执行。

## 如果面试官追问
问：要求 O(n) 时间怎么办？
答：先中序遍历把节点值存进数组，再用下标 `mid` 分治建树，随机访问 O(1)，总时间 O(n)。
