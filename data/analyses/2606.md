## 一句话思路
把每个字符映射成价值后，问题变成「最大子数组和」，用 Kadane 边扫边维护当前段和。

## 怎么做
1. 建长度 26 的 `val` 数组，先填默认值 `i+1`，再用 `zip(chars, vals)` 覆盖。
2. 遍历 `s`，把字符转成 `val[ord(c) - 97]` 得到价值序列。
3. 对价值序列跑 Kadane：`cur = max(x, cur + x)`，`best = max(best, cur)`。
4. 返回 `best`，初值取 0 以覆盖空串。

以示例 1 `s = "adaa"`、`chars = "d"`、`vals = [-1000]` 为例：`val['a'] = 1`，`val['d'] = -1000`。扫描到 `'d'` 时 `cur = max(-1000, 1 + (-1000)) = -1000`，`best` 仍是 1；后面两个 `'a'` 让 `cur` 回到 1、2，最终 `best = 2`。

```python
val = [i + 1 for i in range(26)]
for c, v in zip(chars, vals):
    val[ord(c) - 97] = v

cur = best = 0
for c in s:
    x = val[ord(c) - 97]
    cur = max(x, cur + x)
    best = max(best, cur)
return best
```

关键点：`cur` 允许被单个负值重置，但 `best` 初值 0 保证全负时返回 0（示例 2 三个 `-1`，`cur` 每步都被重置为 `-1`，`best` 始终 0）。

## 复杂度
时间 O(n + |chars|)，n 为 `s` 长度，建表最多 26 次覆盖。
空间 O(26) = O(1)，只开了固定大小的 `val` 数组。

## 易错点
- 输入 `s = "abc"`、`chars = "abc"`、`vals = [-1,-1,-1]` → 若把 `best` 初值设成 `-inf` 或 `val[0]`，会返回 `-1` → 正确做法是 `best = 0`，因为空串开销为 0 且允许取空串。
- 输入 `s = "adaa"`、`chars = "d"`、`vals = [-1000]` → 若忘记给未出现在 `chars` 里的字符填默认值 `i+1`，`val['a']` 会是 0，答案错成 0 → 正确做法是先整体初始化 `[i+1 for i in range(26)]` 再覆盖。

## 如果面试官追问
问：要求返回最大开销子串本身而非开销？
答：Kadane 时额外记录 `cur` 的起点下标，`best` 更新时同步存 `(start, i)`，最后切片即可。
