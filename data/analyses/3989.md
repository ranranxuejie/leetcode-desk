## 一句话思路
把每列当节点，列 a 能接在列 b 后当且仅当所有行差 ≤ limit，求 DAG 最长路即答案。

## 怎么做
1. 预处理 `ok[a][b]`：对每对列 a<b，逐行检查 `abs(grid[i][b]-grid[i][a]) <= limit`，全过则 `ok[a][b]=True`。
2. 定义 `dp[b]` 为以列 b 结尾的最长一致列数，初值全 1（至少保留一列）。
3. 按列序递推：`dp[b] = max(dp[b], dp[a]+1)` 对所有满足 `ok[a][b]` 的 a<b。
4. 答案是 `max(dp)`。

以示例 2 `grid=[[1,-1,1],[2,2,2]], limit=1` 为例：列 0 与列 2 在第 0 行差 `|1-1|=0`、第 1 行差 `|2-2|=0`，故 `ok[0][2]=True`；而列 0 与列 1 第 0 行差 `|-1-1|=2>1`，`ok[0][1]=False`。递推得 `dp=[1,1,2]`，返回 2。

```python
m, n = len(grid), len(grid[0])
ok = [[False]*n for _ in range(n)]
for a in range(n):
    for b in range(a+1, n):
        ok[a][b] = all(abs(grid[i][b]-grid[i][a]) <= limit for i in range(m))
dp = [1]*n
for b in range(n):
    for a in range(b):
        if ok[a][b]:
            dp[b] = max(dp[b], dp[a]+1)
return max(dp)
```

注意 `ok` 只需上三角，`a<b` 的遍历顺序保证 `dp[a]` 已算好。

## 复杂度
时间 O(n²·m)：n² 对列各扫 m 行，加 O(n²) 递推。
空间 O(n²)：`ok` 布尔矩阵，`dp` 只占 O(n)。

## 易错点
- 只比较相邻保留列而非所有对：题面要求「每一对相邻的剩余列」，但相邻性是在**保留后**的序列里判定的，所以 `ok[a][b]` 必须对原始列 a、b 直接算差，不能只查 `ok[a][a+1]` 链式传递——`|x-z|<=limit` 不保证 `|x-y|<=limit` 且 `|y-z|<=limit` 时成立（如 -5,0,5, limit=5）。
- 忘记至少保留一列：若所有 `ok` 全 False（如示例 3），`max(dp)` 应为 1 而非 0，初值必须设 1；若把 `dp` 初始化成 0 再在循环里加，会返回 0。

## 如果面试官追问
问：n 到 10^4 怎么办？答：O(n²m) 会爆，需按行做区间约束剪枝或改用 bitset 加速 `ok` 的批量判定，本质仍是 DAG 最长路。
