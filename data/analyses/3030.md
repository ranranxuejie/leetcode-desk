## 一句话思路
枚举每个 3×3 窗口，用并查集/DFS 判窗口内相邻差是否全 ≤ threshold，合格就累加其向下取整均值到窗口内 9 个格子。

## 怎么做
1. 对每个左上角 `(i,j)`（`0<=i<=m-3`，`0<=j<=n-3`）取 3×3 窗口，检查窗口内 12 条相邻边（横 6 条、竖 6 条）是否都满足 `abs` 差 ≤ threshold。
2. 合格则算 `avg = sum(9格) // 9`，把 `avg` 累加到 `acc[9格]` 和 `cnt[9格]`。
3. 最后 `result[i][j] = acc//cnt if cnt else image[i][j]`。

以示例 1 左上角 `(0,0)` 窗口 `[[5,6,7],[8,9,10],[11,12,13]]` 为例：横边差最大 `|7-10|=3`、竖边差最大 `|5-8|=3`，全 ≤3，合格，`sum=81`，`avg=9`，9 个格子各 `acc+=9, cnt+=1`。

```python
m, n = len(image), len(image[0])
acc = [[0]*n for _ in range(m)]
cnt = [[0]*n for _ in range(m)]
for i in range(m-2):
    for j in range(n-2):
        ok = True
        for r in range(i, i+3):
            for c in range(j, j+3):
                if r+1 < i+3 and abs(image[r][c]-image[r+1][c]) > threshold: ok = False
                if c+1 < j+3 and abs(image[r][c]-image[r][c+1]) > threshold: ok = False
        if not ok: continue
        s = sum(image[r][c] for r in range(i,i+3) for c in range(j,j+3))
        avg = s // 9
        for r in range(i, i+3):
            for c in range(j, j+3):
                acc[r][c] += avg; cnt[r][c] += 1
return [[acc[i][j]//cnt[i][j] if cnt[i][j] else image[i][j] for j in range(n)] for i in range(m)]
```

## 复杂度
时间：`O(m*n*9)`，每个窗口常数 9 格检查，m、n 各 500 时约 2.2e6 次。
空间：`O(m*n)`，`acc` 与 `cnt` 两个同尺寸矩阵。

## 易错点
- 窗口内只查 12 条边而非全部 36 对：若写成两两比较，示例 1 中 `(0,0)=5` 与 `(2,2)=13` 差 8 > 3 会误判不合格，正确只查上下左右相邻。
- 两次取整顺序：示例 1 区域 2 均值 9.67，必须先用 `//9` 得 9 再参与平均；若先累加 9.67 最后才取整，结果会偏离官方输出 9。

## 如果面试官追问
问：m、n 到 5000 怎么优化？答：预处理每条横/竖边的合格布尔值，窗口检查退化为查 12 个布尔，仍是 `O(m*n)` 但常数更小。
