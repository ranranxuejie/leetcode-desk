## 一句话思路
先排序让相同元素相邻，回溯时同一层跳过重复值，就能保证每个子集只生成一次。

## 怎么做
1. 先 `nums.sort()`，把 `[1,2,2]` 变成 `[1,2,2]`，重复的 `2` 挨在一起。
2. 回溯函数带起点 `start`，每层从 `start` 往后枚举，把当前路径 `path` 加入结果。
3. 同一层里若 `i > start and nums[i] == nums[i-1]`，跳过——这是去重核心。
4. 递归 `dfs(i+1)`，回溯时 `path.pop()`。

关键中间值：`nums=[1,2,2]`，第一层选 `1` 后进入 `start=1`，枚举到 `i=1` 取 `2` 得 `[1,2]`；回到该层 `i=2` 时 `nums[2]==nums[1]` 且 `i>start`，跳过，避免再生成 `[1,2]`。

```python
def dfs(start):
    res.append(path[:])
    for i in range(start, len(nums)):
        if i > start and nums[i] == nums[i-1]:
            continue
        path.append(nums[i])
        dfs(i + 1)
        path.pop()
```

注意 `i > start` 而非 `i > 0`：它只跳过「本层」的重复，允许不同层选同一个 `2`，所以 `[2,2]` 仍能生成。

## 复杂度
时间 O(n·2^n)：最多 2^n 个子集，每个拷贝长度 O(n)。
空间 O(n)：递归栈与 `path` 深度，结果集本身 O(n·2^n) 不计入。

## 易错点
- 输入 `[1,2,2]` → 若写成 `if i > 0 and nums[i]==nums[i-1]: continue`，会把 `[2,2]` 也砍掉，输出少了 `[2,2]`；正确是 `i > start`，只在本层去重。
- 输入 `[2,2]` → 若忘记先 `sort()`，两个 `2` 不相邻，`nums[i]==nums[i-1]` 判断失效，输出出现两个 `[2]`；必须先排序再回溯。

## 如果面试官追问
问：不排序能去重吗？答：可以用 `set` 存 `tuple(path)` 去重，但要多 O(2^n) 空间，排序+剪枝更省。
