## 一句话思路
沿环走一圈，在第一个满足 `cur.val <= insertVal <= cur.next.val` 的缝里插入；走完没找到就插在最大值后面。

## 怎么做
1. `head is None` 时建单节点自环直接返回。
2. 用 `cur = head` 起走，每步检查三种可插位置：普通升序缝、跨最大值到最小值的断点缝、以及值落在 `[min, max]` 之外时插在 `max` 后。
3. 走满一圈（`cur.next is head` 时停）仍未插入，说明全环等值，插在 `head` 后即可。

以 `head = [3,4,1], insertVal = 2` 为例：`cur=3` 时 `3<=2` 不成立；`cur=4` 时 `4<=2` 不成立，但 `cur.next.val=1 < cur.val=4` 是断点，且 `2` 不在 `[1,4]` 内，不插；`cur=1` 时 `1<=2<=3` 成立，插在 `1` 与 `3` 之间。关键中间值：断点判定 `cur.val > cur.next.val` 只在 `4→1` 处为真。

```python
node = ListNode(insertVal)
if head is None:
    node.next = node
    return node
cur = head
while True:
    if cur.val <= insertVal <= cur.next.val:
        break
    if cur.val > cur.next.val and (insertVal >= cur.val or insertVal <= cur.next.val):
        break
    cur = cur.next
    if cur is head:
        break
node.next = cur.next
cur.next = node
return head
```

## 复杂度
时间 O(n)：最坏走满一圈，n 是节点数。
空间 O(1)：只开了新节点 `node` 一个额外对象。

## 易错点
- 输入 `head = [1], insertVal = 0`：只判 `cur.val <= insertVal <= cur.next.val` 会永远不成立，死循环。正确做法是单节点时 `cur.next is cur`，`cur.val > cur.next.val` 为假，必须靠走满一圈的 `cur is head` 兜底退出。
- 输入 `head = [3,4,1], insertVal = 5`：值大于全环最大值，普通缝和断点缝都不满足，会漏插。正确做法是在断点 `4→1` 处补判 `insertVal >= cur.val or insertVal <= cur.next.val`，把 `5` 插到 `4` 后面。

## 如果面试官追问
问：若要求返回最小元素节点而非原 `head`？答：插入后从 `head` 再走一圈找 `val` 最小的节点返回，仍是 O(n)、O(1)。
