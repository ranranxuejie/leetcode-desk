## 一句话思路
用树状数组维护前缀和，update 改点、sumRange 用两次前缀和相减，两个操作都是 O(log n)。

## 怎么做
1. 建树：把 `nums` 逐位 `add(i+1, nums[i])` 灌进树状数组 `tree`（长度 `n+1`，下标从 1 开始）。
2. `update(index, val)`：先算增量 `delta = val - nums[index]`，再 `add(index+1, delta)`，最后写回 `nums[index] = val`。
3. `sumRange(left, right)`：返回 `prefix(right+1) - prefix(left)`，其中 `prefix(i)` 是 `tree` 上从 `i` 往下跳 `i -= i & -i` 的累加。
4. 关键中间值：示例 `nums=[1,3,5]` 建完后 `tree=[0,1,4,5]`；`update(1,2)` 时 `delta=-1`，`add(2,-1)` 让 `tree[2]` 从 4 变 3；再 `sumRange(0,2)` 得 `prefix(3)-prefix(0)=8-0=8`。

```python
def add(i, d):
    while i <= n:
        tree[i] += d
        i += i & -i

def prefix(i):
    s = 0
    while i > 0:
        s += tree[i]
        i -= i & -i
    return s

# update(index, val)
add(index + 1, val - nums[index])
nums[index] = val
# sumRange(left, right)
return prefix(right + 1) - prefix(left)
```

## 复杂度
时间：建树 O(n log n)，每次 update / sumRange 各 O(log n)，log 来自树状数组的下标跳转。
空间：`tree` 额外开 n+1 个整数，`nums` 原地保留，共 O(n)。

## 易错点
- `update` 传的是「新值」不是「增量」：若直接 `add(index+1, val)`，示例里 `update(1,2)` 会把 3 加成 5 而非替换成 2，`sumRange(0,2)` 错成 10；必须先算 `val - nums[index]` 再写回 `nums`。
- 下标偏移漏加 1：`sumRange(0,2)` 若写成 `prefix(2)-prefix(0)`，只累到 `nums[1]`，返回 4 而不是 9；树状数组 1-based，`right` 要传 `right+1`，`left` 直接传 `left`（因为减的是 `prefix(left)` 即前 `left` 个）。

## 如果面试官追问
若要求区间加、区间求和怎么办？答：树状数组要维护两个数组做差分前缀，或直接上带 lazy 的线段树，单次仍是 O(log n)。
