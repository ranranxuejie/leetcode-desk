## 一句话思路
用 `ans[i] = ans[i >> 1] + (i & 1)` 递推：右移一位去掉最低位，最低位是 1 就补 1。

## 怎么做
1. 开长度 `n + 1` 的数组 `ans`，`ans[0] = 0`。
2. 从 `i = 1` 扫到 `n`，每步取 `ans[i >> 1]` 再加 `i & 1`。
3. 返回 `ans`。

拿 `n = 5` 走一遍关键几步：`i = 4` 时 `i >> 1 = 2`，`ans[2] = 1`，`i & 1 = 0`，所以 `ans[4] = 1`；`i = 5` 时 `i >> 1 = 2`，`ans[2] = 1`，`i & 1 = 1`，所以 `ans[5] = 2`。结果 `[0,1,1,2,1,2]`，和示例一致。

```python
ans = [0] * (n + 1)
for i in range(1, n + 1):
    ans[i] = ans[i >> 1] + (i & 1)
return ans
```

等价写法是 `ans[i] = ans[i & (i - 1)] + 1`，`i & (i - 1)` 抹掉最低位的 1，同样 O(1) 转移。两种都行，前者更好记，后者在追问「最低位 1 的位置」时更顺手。

## 复杂度
时间 O(n)：`i` 从 1 到 `n` 各做一次 O(1) 转移，没有 log n 项。
空间 O(n)：`ans` 数组本身占 `n + 1` 个元素，除此之外只用了 `i` 一个变量。

## 易错点
- `n = 0` → 若循环写成 `range(1, n)` 或忘了初始化 `ans[0]`，会返回空数组或越界 → 正确做法是 `ans = [0] * (n + 1)` 且循环上界写 `n + 1`，`n = 0` 时直接返回 `[0]`。
- 用 `ans[i // 2] + i % 2` 时把 `i % 2` 写成 `i % 2 == 1` → 布尔值参与加法虽然 Python 能算，但语义上应写 `i & 1` 或 `int(i % 2)`，避免在别的语言里翻车；本题 Python 下 `True + 1` 得 2 不会报错，反而掩盖了错误。

## 如果面试官追问
问：要求只输出 `i = n` 单个值的 popcount，且不能用内置函数？
答：用 `while x: x &= x - 1; cnt += 1`，循环次数等于 1 的个数，最坏 O(log n)。
