## 一句话思路
先用哈希表统计每个数的频次，再把频次放进集合，比较集合大小与频次个数是否相等。

## 怎么做
1. 用 `Counter(arr)` 得到 `{数值: 频次}`，键是数组里的不同数。
2. 取出所有频次 `freqs = list(cnt.values())`。
3. 判断 `len(set(freqs)) == len(freqs)`，相等即每个频次互不相同。

以 `arr = [1,2,2,1,1,3]` 为例：`cnt = {1:3, 2:2, 3:1}`，`freqs = [3,2,1]`，`set(freqs) = {1,2,3}`，长度 3 等于 3，返回 `True`。若换成 `arr = [1,2]`，`freqs = [1,1]`，`set` 只剩 `{1}`，长度 1 ≠ 2，返回 `False`。

```python
from collections import Counter

def unique_occurrences(arr):
    cnt = Counter(arr)
    freqs = list(cnt.values())
    return len(set(freqs)) == len(freqs)
```

关键点：比较的是**频次**的去重，不是数值的去重。`[1,2]` 里数值本身互不相同，但频次都是 1，所以答案是 `False`——这正是示例 2 要考的地方。

## 复杂度
时间：O(n)，`Counter` 扫一遍 arr，n 为数组长度。
空间：O(k)，k 为不同数值个数，`cnt` 和 `set(freqs)` 各占 O(k)。

## 易错点
- 输入 `[1,2]` → 误以为「数值都不同」就返回 `True` → 正确做法是对 `cnt.values()` 去重，频次 `[1,1]` 有重复，应返回 `False`。
- 输入 `[1,1,2]` → 只比较 `len(cnt)` 和 `len(set(cnt.values()))` 会漏判 → 必须比较 `len(freqs)` 与 `len(set(freqs))`，这里 `freqs=[2,1]` 无重复返回 `True`，但若写成比较数值个数就会把 `[1,2]` 也判成 `True`。

## 如果面试官追问
问：arr 长度放大到 10^7 怎么办？答：仍是一遍哈希统计，O(n) 时间不变，只是 `Counter` 内存随不同数值数增长，可改用排序后线性扫描频次。
