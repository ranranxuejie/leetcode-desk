## 一句话思路
把 hidden[0] 当自由变量，其余元素都是 hidden[0] 加前缀和，只需统计前缀和的极差能塞进 [lower, upper] 的起点个数。

## 怎么做
1. 令 `s = 0`，遍历 `differences`，每次 `s += d`，把 `s` 记入前缀和序列（含初始 0）。
2. 记 `lo = min(前缀和)`、`hi = max(前缀和)`，则 hidden 的极差固定为 `hi - lo`，与起点无关。
3. 起点 `x = hidden[0]` 需满足 `lower <= x + lo` 且 `x + hi <= upper`，即 `x ∈ [lower - lo, upper - hi]`。
4. 答案就是该区间整数个数 `max(0, upper - hi - (lower - lo) + 1)`。

以示例 1 `differences = [1,-3,4]` 为例：前缀和为 `0, 1, -2, 2`，故 `lo = -2`、`hi = 2`。起点区间是 `[1-(-2), 6-2] = [3, 4]`，共 2 个，与输出一致。

```python
s = 0
lo = hi = 0
for d in differences:
    s += d
    if s < lo:
        lo = s
    if s > hi:
        hi = s
left = lower - lo
right = upper - hi
return max(0, right - left + 1)
```

关键点：`lo`、`hi` 必须从 0 起算，因为 `hidden[0]` 本身对应空前缀和 0，漏掉它会在全正或全负差值时算错。

## 复杂度
时间：O(n)，n 为 `differences` 长度，一次遍历求前缀和极值。
空间：O(1)，只维护 `s`、`lo`、`hi` 三个变量，不存前缀和数组。

## 易错点
- 忘记把初始 0 纳入极值：`differences = [4,-7,2]` 若只统计累加后的 `4,-3,-1`，得 `lo=-3, hi=4`，起点区间 `[6,2]` 为空返回 0 恰好对；但 `differences = [1,1]`、`lower=0`、`upper=10` 时漏 0 会得 `lo=1,hi=2`，区间 `[-1,8]` 算成 10 个，正确是 9 个（起点 0..8）。
- 区间端点写反：`left = lower - lo` 用的是最小值、`right = upper - hi` 用的是最大值，写成 `lower - hi` 会把示例 1 的区间算成 `[-1,8]` 得 10 而非 2；另外 `right - left + 1` 为负时必须 `max(0, ...)` 截断，否则示例 3 会返回负数。

## 如果面试官追问
问：若要求输出所有合法 hidden 数组而非计数？
答：起点区间 `[lower-lo, upper-hi]` 每个整数对应一个解，枚举起点再累加 `differences` 即可，代价 O(答案数 × n)。
