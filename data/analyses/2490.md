## 一句话思路
只需检查每个空格两侧的字符是否相等，再单独检查首尾字符，因为空格恰好是「前词末字符」和「后词首字符」的分界。

## 怎么做
1. 遍历 `sentence` 的每个下标 `i`，遇到空格就比对 `sentence[i-1]` 与 `sentence[i+1]`。
2. 任一空格处不相等，立即返回 `False`。
3. 全部空格通过后，再比对 `sentence[0]` 与 `sentence[-1]`，这一步对应「末词末字符 = 首词首字符」。
4. 两者都相等才返回 `True`。

以 `"Leetcode is cool"` 为例，第一个空格在 `i=8`，`sentence[7]='e'`、`sentence[9]='i'`，`'e' != 'i'`，直接返回 `False`，根本走不到首尾比较。而 `"eetcode"` 没有空格，循环体一次都不执行，只剩 `sentence[0]=='e'` 与 `sentence[-1]=='e'` 比较，返回 `True`——单单词句正是靠这一步兜住的。

```python
for i, ch in enumerate(sentence):
    if ch == ' ' and sentence[i - 1] != sentence[i + 1]:
        return False
return sentence[0] == sentence[-1]
```

关键点：`sentence[i-1]` 和 `sentence[i+1]` 一定合法，因为题面保证无前导/尾随空格、单词间单空格，所以空格不会出现在下标 0 或末尾。

## 复杂度
时间 O(n)：`n = len(sentence)`，一次线性扫描，每个字符看一次。
空间 O(1)：只用了 `i`、`ch` 两个临时变量，没有 split 出单词列表。

## 易错点
- 输入 `"eetcode"`（无空格）→ 若只写空格循环、忘了末尾 `sentence[0] == sentence[-1]`，会错成 `True` 但理由是「没检查」；正确做法是循环后必须补这一句，单单词句的成败全押在它上面。
- 输入 `"Leetcode is cool"` → 若先 `split()` 再逐词比较，容易漏掉「最后一个词与第一个词」这条闭环条件，只查相邻词会错成 `True`；正确做法是把首尾比较当成独立一步，或直接不 split、用空格下标法。

## 如果面试官追问
问：如果单词间允许多个连续空格怎么办？
答：空格下标法失效，需先 `split()` 过滤空串再比较相邻词首尾，最后补首尾闭环。
