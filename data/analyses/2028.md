## 一句话思路
先由总和反解缺失部分的和 `need`，再把它摊成 n 个 1~6 的数：先均分，余数逐个 +1。

## 怎么做
1. 算出缺失 n 次的总和 `need = mean * (len(rolls) + n) - sum(rolls)`。
2. 可行性只需两条边界：`need < n`（每个至少 1）或 `need > 6 * n`（每个至多 6）就返回 `[]`。
3. 均分：`base, extra = divmod(need, n)`，前 `extra` 个取 `base + 1`，其余取 `base`。
4. 因为 `n <= need <= 6n`，`base` 必在 1~6，`base + 1` 最多 6，构造一定合法。

以示例 2 为例：`rolls = [1,5,6], mean = 3, n = 4`，`sum(rolls) = 12`，`need = 3 * 7 - 12 = 9`，`divmod(9, 4) = (2, 1)`，于是得到 `[3,2,2,2]`，和官方输出 `[2,3,2,2]` 只是顺序不同，同样合法。

```python
total = mean * (len(rolls) + n)
need = total - sum(rolls)
if need < n or need > 6 * n:
    return []
base, extra = divmod(need, n)
return [base + 1] * extra + [base] * (n - extra)
```

关键点：`need` 是「缺失部分的和」，不是总和；边界判断用 `need` 而不是 `total`，因为 `total` 里混进了已知的 `sum(rolls)`。

## 复杂度
时间：O(m + n)，`sum(rolls)` 扫 m 个，构造答案写 n 个。
空间：O(n)，只有返回数组本身，无额外辅助结构。

## 易错点
- 输入 `rolls = [1,2,3,4], mean = 6, n = 4` → 若只判断 `need > 6 * n` 而漏掉上界方向写反，会算出 `need = 6*8 - 10 = 38 > 24` 却仍去 `divmod`，得到 `base = 9` 这种非法骰子值 → 必须先判 `need < n or need > 6 * n` 直接返回 `[]`。
- 输入 `rolls = [1], mean = 3, n = 1` → 若把 `need` 写成 `mean * n - sum(rolls) = 3 - 1 = 2`，会返回 `[2]`，总和 3、平均 1.5 全错 → 分母必须是 `len(rolls) + n`，即 `mean * (len(rolls) + n) - sum(rolls) = 5`。

## 如果面试官追问
问：若要求返回字典序最小的方案？
答：把 `base + 1` 放在末尾、`base` 放前面，即 `[base] * (n - extra) + [base + 1] * extra`，小值优先即最小。
