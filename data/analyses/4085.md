## 一句话思路
从每个候选根做一次 BFS 校验颜色递进和子节点数，候选根只可能是度数 ≤2 的节点，且颜色序列由根色唯一确定。

## 怎么做
1. 枚举所有节点作为根，先剪枝：根的子节点数等于度数，度数 >2 直接跳过。
2. 对候选根做 BFS，用 `depth` 数组记录深度，同时检查每个节点已扩展的子节点数 ≤2。
3. 颜色校验：根色 `colors[root]` 决定循环序列，深度 d 的期望颜色是 `seq[(start + d) % 3]`，其中 `seq = "RBW"`，`start = seq.index(colors[root])`。
4. 任一节点颜色不符或子节点超 2，该根失败；全部通过则返回该根。

以示例 1 `edges = [[3,1],[3,2],[1,4],[2,0]], colors = "BRRWB"` 为例，根 3 颜色 `'B'`，`start = 1`，深度 1 期望 `seq[2] = 'W'`，但节点 1、2 颜色都是 `'R'`——等等，实际示例说根 3 成立，说明序列方向是 `W→R→B`，即根色 `'B'` 对应深度 1 是 `'R'`。正确映射：`seq = "RBW"`，根色 `'B'` 时 `start = 1`，深度 1 期望 `seq[(1+1)%3] = 'W'` 不符。改用 `seq = "RWB"` 或反向：根 `'B'` 深度 1 应为 `'R'`，即 `'B'→'R'→'W'`，对应 `seq = "BRW"`，`start = 0`，深度 1 期望 `seq[1] = 'R'` ✓，深度 2 期望 `seq[2] = 'W'`，节点 4、0 颜色 `'W'` ✓。所以循环序列是 `R→B→W→R` 的反向 `R→W→B`？实际是 `B→R→W→B`，即 `seq = "BRW"` 循环。

```python
seq = "BRW"
start = seq.index(colors[root])
# BFS 中检查
if colors[v] != seq[(start + depth[v]) % 3]:
    return False
```

## 复杂度
时间：O(n²)，每个候选根 BFS 一次，最坏 n 个根各扫 n 个节点。
空间：O(n)，`depth` 数组和 BFS 队列各占 n。

## 易错点
- 颜色循环方向搞反：根 `'B'` 时深度 1 应是 `'R'` 不是 `'W'`，写成 `"RBW"` 会让示例 1 的根 3 被误判失败，正确序列是 `"BRW"` 循环。
- 只检查颜色不检查子节点数：示例 1 中若某节点度数为 3 且颜色恰好匹配，会漏判二叉树性质，必须单独统计每个节点在 BFS 中扩展的子节点数 ≤2。

## 如果面试官追问
问：n 到 10^5 时 O(n²) 会超时，怎么优化？
答：先找颜色递进必须成立的边方向，用两次 DFS 定出唯一候选根，再 O(n) 校验。
