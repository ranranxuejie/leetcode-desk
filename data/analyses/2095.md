## 一句话思路
快慢指针让 `slow` 停在待删节点的前一个，再用 `slow.next = slow.next.next` 跳过它。

## 怎么做
1. 特判 `head.next is None` 和 `head.next.next is None`，分别返回 `None` 和 `head`（n=1、n=2 时中间节点就是头或第二个）。
2. `slow, fast = head, head.next.next`，让 `fast` 先走两步，这样 `slow` 天然落后一步，最终停在中间节点的前驱。
3. 循环 `while fast and fast.next:`，每轮 `slow = slow.next; fast = fast.next.next`。
4. 循环结束后 `slow.next = slow.next.next`，返回 `head`。

以 `[1,3,4,7,1,2,6]` 为例：初始 `slow=1, fast=4`；第一轮后 `slow=3, fast=1`；第二轮后 `slow=4, fast=6`；`fast.next` 为 `None` 退出，此时 `slow=4`（下标 2），`slow.next=7` 正是中间节点，跳过即可。

```python
if head.next is None:
    return None
if head.next.next is None:
    return head
slow, fast = head, head.next.next
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
slow.next = slow.next.next
return head
```

关键在 `fast` 的起点是 `head.next.next` 而不是 `head`：若从 `head` 起步，n 为偶数时 `slow` 会落在中间节点本身，拿不到前驱，就没法删。

## 复杂度
时间 O(n)：`fast` 每次走两步，遍历约 n/2 轮。
空间 O(1)：只开了 `slow`、`fast` 两个指针。

## 易错点
- 输入 `[1,2]`（n=2）→ 若只写 `head.next is None` 的特判，`fast = head.next.next` 会取到 `None`，循环不执行，`slow` 仍是 `1`，`slow.next.next` 对 `None` 取属性直接报错 → 必须先单独处理 n=2 返回 `head`。
- 输入 `[1,3,4,7,1,2,6]`（n=7）→ 若 `fast` 从 `head` 起步，两轮后 `slow` 停在 `7` 本身，`slow.next = slow.next.next` 删掉的是 `1`，输出变成 `[1,3,4,7,2,6]` → 起点必须是 `head.next.next`，保证 `slow` 是前驱。

## 如果面试官追问
问：要求返回被删节点的值而不改链表？
答：同样用快慢指针定位到 `slow.next`，返回 `slow.next.val` 即可，指针走法完全不变。
