## 一句话思路
按数字 0-9 逐个把「放几个到奇数位、几个到偶数位」做组合 DP，最后乘上两边的排列数。

## 怎么做
1. 设 `n=len(num)`，奇数位个数 `odd=(n+1)//2`，偶数位个数 `even=n//2`；平衡要求奇数位数字和等于总和一半，总和为奇数直接返回 0。
2. 预处理阶乘 `fact` 与逆元 `inv_fact`，用于算「从剩余空位里选位置」的组合数 `C(a,b)`。
3. DP 状态 `dp[i][j]`：处理完前 i 种数字后，奇数位已填 j 个、其数字和为 `s` 的方案数；按数字逐个转移，枚举该数字分到奇数位的个数 `k`。
4. 转移时乘 `C(odd - j, k) * C(even - (used - j), cnt - k)`，即两边各选位置；最后 `dp[10][odd]` 就是答案。

以 `num="123"` 为例：`n=3`，`odd=2`，`even=1`，总和 6，目标奇数位和 3。数字 1 分 1 个到奇数位时 `j=1, s=1`，乘 `C(2,1)*C(1,0)=2`；数字 2 再分 1 个到奇数位得 `j=2, s=3`，乘 `C(1,1)*C(1,0)=1`；数字 3 只能进偶数位，最终 `dp=2`，对应 `"132"` 和 `"231"`。

```python
MOD = 10**9 + 7
n = len(num)
odd, even = (n + 1) // 2, n // 2
total = sum(map(int, num))
if total % 2: return 0
target = total // 2
cnt = [0] * 10
for ch in num: cnt[int(ch)] += 1
# dp[j][s]: 奇数位填 j 个、和为 s 的方案数
dp = [[0] * (target + 1) for _ in range(odd + 1)]
dp[0][0] = 1
used = 0
for d in range(10):
    ndp = [[0] * (target + 1) for _ in range(odd + 1)]
    for j in range(odd + 1):
        for s in range(target + 1):
            if not dp[j][s]: continue
            for k in range(min(cnt[d], odd - j) + 1):
                ns = s + k * d
                if ns > target: break
                ways = C(odd - j, k) * C(even - (used - j), cnt[d] - k) % MOD
                ndp[j + k][ns] = (ndp[j + k][ns] + dp[j][s] * ways) % MOD
    dp = ndp
    used += cnt[d]
return dp[odd][target]
```

## 复杂度
时间：`O(10 * odd * target * cnt[d])`，`target ≤ 9n/2`，n 来自字符串长度。
空间：`O(odd * target)` 的 DP 表，另开阶乘与逆元数组 `O(n)`。

## 易错点
- `num="12345"` 总和 15 为奇数 → 若漏判会继续跑 DP 得到 0 但浪费，且 `target=7` 时 `s` 上界错位；正确做法是开头 `if total % 2: return 0`。
- `num="112"` 有重复数字 → 若按位置而非按数字种类转移，会把 `"112"` 的两种 1 当成不同排列重复计数得 2；正确做法是按 `cnt[d]` 分堆，用 `C(odd-j,k)*C(even-(used-j),cnt-k)` 一次性分配，天然去重。

## 如果面试官追问
问：n 扩到 500 怎么办？答：`target` 涨到 2250，`O(10*odd*target*cnt)` 约 10^8 量级偏紧，可把 `s` 维度换成「奇数位和减偶数位和」的偏移量并滚动数组压空间。
