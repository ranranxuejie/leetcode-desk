## 一句话思路
只需线性扫一遍：维护当前擂主和其连胜数，遇到更强的就换擂主并重置连胜，因为队列里其余人的相对顺序不影响谁先达到 k 胜。

## 怎么做
1. 令 `champ = 0`、`streak = 0`，从 `i = 1` 开始遍历。
2. 若 `skills[i] > skills[champ]`，则 `champ = i`、`streak = 1`；否则 `streak += 1`。
3. 每轮结束检查 `streak == k`，成立就返回 `champ`。
4. 循环走完仍未返回，说明 `champ` 是全局最大值，返回 `champ`（它此后一直赢）。

以 `skills = [4,2,6,3,9], k = 2` 为例：`i=1` 时 2<4，`streak=1`；`i=2` 时 6>4，`champ=2, streak=1`；`i=3` 时 3<6，`streak=2` 命中，返回 2。

```python
champ, streak = 0, 0
for i in range(1, len(skills)):
    if skills[i] > skills[champ]:
        champ, streak = i, 1
    else:
        streak += 1
    if streak == k:
        return champ
return champ
```

关键点：失败者被排到队尾，但队尾的人要等前面所有人轮完才可能再上场，所以「下一个挑战者」永远是尚未与擂主交手的下一个人，即 `i` 递增即可，无需真的维护队列。

## 复杂度
时间 O(n)：`i` 从 1 到 n-1 各访问一次，最多 n-1 场比赛。
空间 O(1)：只开了 `champ`、`streak`、`i` 三个变量。

## 易错点
- `k` 很大（如 `skills=[2,5,4], k=3`）时，若只扫到 `n-1` 就停，会漏掉擂主 1 在第二轮击败 0 的那场胜利 → 错成返回 -1 或空 → 正确做法是循环结束后直接返回 `champ`，因为全局最大值一旦登顶就再也不会输。
- `k = 1` 且 `skills[1] < skills[0]`（如 `[4,2], k=1`）时，若把 `streak` 初值设成 1 或先比较后判断，会错成返回 1 → 正确做法是 `streak` 从 0 起，第一场比较完再判断是否等于 `k`。

## 如果面试官追问
问：若要求返回完整的比赛过程（每场胜负）？答：仍用同一擂主指针，额外把每场的 `(champ, i, winner)` 追加进列表，时间仍是 O(n)。
