## 一句话思路
用滑动窗口维护「符号交替」的最长区间，窗口右端每步只需和左端前一个比较符号是否翻转。

## 怎么做
1. 把相邻比较压成符号：`arr[i] < arr[i+1]` 记 `+1`，`>` 记 `-1`，`==` 记 `0`。
2. 窗口 `[left, right]` 内符号序列必须非零且严格交替，`right` 右移时检查 `sign[right-1]` 与 `sign[right-2]` 是否异号。
3. 遇到 `0` 或同号，`left` 直接跳到 `right-1`（`0` 时跳到 `right`），窗口长度重置。
4. 每步用 `right - left + 1` 更新 `best`。

以 `arr = [9,4,2,10,7,8,8,1,9]` 为例，符号为 `-,-,+,-,+,0,-,+`。走到 `right=5`（`8,8`）时符号 `0`，`left` 跳到 `5`，窗口长度从 5 掉到 1；`right=8` 时窗口 `[5,8]` 长度 4，最终 `best=5`（对应 `arr[1..5]`）。

```python
n = len(arr)
if n < 2:
    return 1
best = left = 1
for right in range(1, n):
    if arr[right] == arr[right - 1]:
        left = right + 1
    elif right > 1 and (arr[right] - arr[right - 1]) * (arr[right - 1] - arr[right - 2]) > 0:
        left = right
    best = max(best, right - left + 2)
return best
```

注意 `right - left + 2`：`left` 记的是「符号下标起点」，元素个数比符号数多 1。

## 复杂度
时间：O(n)，`right` 单次遍历，`left` 只增不减。
空间：O(1)，只存 `best/left` 两个变量，没有额外数组。

## 易错点
- 输入 `[4,8,12,16]` 全递增 → 若只判「相邻不等」会返回 4，实际符号全 `+` 不交替，正确是 2。必须判 `(a-b)*(b-c) > 0` 才算同号断窗。
- 输入 `[9,4,2,...]` 中 `arr[1]>arr[2]` 后接 `arr[2]<arr[3]` → 若把 `left` 设成 `right-1` 而长度用 `right-left+1`，会少算 1，示例 1 得 4 而非 5。长度公式固定为 `right-left+2`。

## 如果面试官追问
问：要求返回最长湍流子数组本身而非长度？
答：在更新 `best` 时同步记录 `(left, right)`，最后切片 `arr[left-1:right+1]` 即可，仍是 O(n)。
