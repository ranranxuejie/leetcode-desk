## 一句话思路
按空格切分后逐个 token 用字符分类规则校验，因为每个 token 的合法性只取决于它自身的字符构成。

## 怎么做
1. 用 `sentence.split()` 切分，它自动吞掉连续空格，得到 token 列表。
2. 对每个 token 先扫一遍：遇到数字直接判无效。
3. 再统计 `-` 和标点（`!.,`）的位置与个数。
4. 规则合并成三个条件：`-` 至多一个且不在首尾；标点至多一个且在末尾。

以示例 2 的 `"!this 1-s b8d!"` 为例，`split()` 得到 `["!this", "1-s", "b8d!"]`。第一个 token 标点 `!` 在索引 0 而非末尾，判无效；第二个含数字 `1`，判无效；第三个含数字 `8`，判无效，最终计数 0。

```python
def countValidWords(sentence):
    ans = 0
    for t in sentence.split():
        if any(c.isdigit() for c in t):
            continue
        if t.count('-') > 1:
            continue
        if '-' in t and (t[0] == '-' or t[-1] == '-'):
            continue
        punc = [i for i, c in enumerate(t) if c in '!.,']
        if len(punc) > 1 or (punc and punc[0] != len(t) - 1):
            continue
        ans += 1
    return ans
```

关键中间值：对 `"a-b."`，`t.count('-') == 1`，`punc == [3]`，`len(t)-1 == 3`，三个条件全过，计数加一。

## 复杂度
时间 O(n)：n 为 sentence 长度，每个字符被扫常数次。
空间 O(n)：`split()` 生成的 token 列表，最坏每个字符一个 token。

## 易错点
- 输入 `"!"` 或 `"a!"` → 若把「标点必须在末尾」写成「标点不能出现」，会把 `"!"` 误判无效；正确做法是只检查标点位置 `punc[0] == len(t)-1`，允许 token 只有一个标点。
- 输入 `"-ab"` 或 `"ab-"` → 若只检查 `-` 的个数不检查位置，会误判有效；正确做法是额外判断 `t[0] != '-' and t[-1] != '-'`，注意 `"a-b"` 中间连字符合法。

## 如果面试官追问
问：若标点集合扩大到任意非字母数字字符怎么办？
答：把 `'!.,'` 换成 `not c.isalnum() and c != '-'` 判断即可，其余逻辑不变。
