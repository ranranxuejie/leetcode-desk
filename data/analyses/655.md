## 一句话思路
先 DFS 求树高 `h`，再按公式把每个节点直接写进 `m×(2**(h+1)-1)` 的矩阵，坐标由递归参数算。

## 怎么做
1. 递归求高度：空节点返回 `-1`，否则 `1 + max(h(left), h(right))`；示例 2 得 `h = 2`。
2. 开矩阵 `res = [[""] * (2**(h+1)-1) for _ in range(h+1)]`，示例 2 是 3 行 7 列。
3. 从 `(0, (n-1)//2)` 开始 DFS，示例 2 根节点落在 `res[0][3]`。
4. 递归时传 `r` 和 `c`，左子 `c - 2**(h-r-1)`、右子 `c + 2**(h-r-1)`；示例 2 中 `r=0` 时偏移 `2**1 = 2`，节点 2 落在 `res[1][1]`，节点 3 落在 `res[1][5]`。

```python
def dfs(node, r, c):
    if not node:
        return
    res[r][c] = str(node.val)
    gap = 2 ** (h - r - 1)
    dfs(node.left, r + 1, c - gap)
    dfs(node.right, r + 1, c + gap)

dfs(root, 0, (n - 1) // 2)
return res
```

关键在 `gap` 的指数是 `h - r - 1` 而不是 `h - r`：示例 2 里 `h=2`、根层 `r=0`，偏移必须是 2，若写成 `2**(h-r)` 就变成 4，节点 2 会落到 `res[1][-1]` 越界。

## 复杂度
时间 O(m·n)：矩阵共 `(h+1)·(2**(h+1)-1)` 个格子，DFS 只填节点数。
空间 O(m·n)：矩阵本身占满，递归栈额外 O(h)。

## 易错点
- 输入 `root = [1,2]`（`h=1`，n=3）：若把高度定义成节点层数（空树返回 0），`h` 会算成 2，矩阵变成 4 行 7 列，输出行数对不上。正确做法是空节点返回 `-1`，让叶子高度为 0。
- 输入 `root = [1,2,3,null,4]`：若用 BFS 按层填、每层均匀铺开，节点 4 是节点 2 的右子，会落到 `res[2][2]` 而不是 `res[2][2]` 之外的正确答案 `res[2][2]` 位置需按公式 `c ± 2**(h-r-1)` 算——BFS 均匀铺开在缺节点时列号全错，必须用公式定位。

## 如果面试官追问
若树深到 30 层，矩阵规模 `2**31` 存不下怎么办？答：此时输出本身已不可行，应改为返回带缩进的字符串或只输出非空节点坐标。
