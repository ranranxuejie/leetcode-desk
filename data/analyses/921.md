## 一句话思路
用平衡计数器扫一遍：遇到 `)` 且计数器为 0 就必须补一个 `(`，扫完剩下的计数器值就是缺的 `)`。

## 怎么做
1. 维护 `need`（已补的左括号数）和 `balance`（当前未匹配的 `(` 数），初值都为 0。
2. 遍历 `s` 的每个字符 `ch`：`ch == '('` 时 `balance += 1`。
3. `ch == ')'` 时先看 `balance`：为 0 说明这个右括号没有左括号可配，`need += 1`；否则 `balance -= 1`。
4. 遍历结束后返回 `need + balance`，`balance` 就是尾部多出来、需要补右括号的个数。

以 `s = "())"` 为例：第一个 `(` 使 `balance = 1`；第二个 `)` 使 `balance = 0`；第三个 `)` 时 `balance == 0`，于是 `need = 1`。循环结束 `balance = 0`，返回 `1 + 0 = 1`。关键中间值是第三个字符处的 `balance == 0` 这个判断——它决定了 `need` 从 0 变 1。

```python
need = 0
balance = 0
for ch in s:
    if ch == '(':
        balance += 1
    elif balance == 0:
        need += 1
    else:
        balance -= 1
return need + balance
```

注意 `elif balance == 0` 这一支不需要动 `balance`：这个右括号被“凭空补的左括号”抵消掉了，`balance` 保持 0 才对。

## 复杂度
时间：O(n)，n 为 `s` 长度，每个字符只判一次。
空间：O(1)，只开了 `need` 和 `balance` 两个整数。

## 易错点
- 输入 `s = "((("` → 若只统计 `need` 而忘记加 `balance`，会返回 0，正确是 3。扫完后必须返回 `need + balance`，尾部未闭合的左括号每个都要补一个 `)`。
- 输入 `s = ")("` → 若把 `balance` 写成可以为负的普通计数（遇 `)` 就 `balance -= 1`），会得到 `balance = 0` 而误判为已配平，正确是 2。必须在 `balance == 0` 时走 `need += 1` 分支，不让 `balance` 变负。

## 如果面试官追问
问：要求输出具体插入方案而不只是数量？
答：在 `need += 1` 处记录“在此位置前插 `(`”，末尾追加 `balance` 个 `)`，位置列表即方案。
