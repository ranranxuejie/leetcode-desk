## 一句话思路
用 DP，`dp[j]` 只依赖前 3 个位置，因为单次跳跃最多跨 3 级。

## 怎么做
1. 定义 `dp[j]` 为到达第 `j` 级台阶的最小总成本，`dp[0] = 0`。
2. 对每个 `j`，枚举 `i = j-3, j-2, j-1`（`i >= 0`），转移 `dp[j] = min(dp[i] + costs[j-1] + (j-i)**2)`。
3. 注意 `costs` 下标是 `j-1`，因为 `costs[i]` 对应第 `i+1` 级台阶。
4. 返回 `dp[n]`。

以示例 2 `n=4, costs=[5,1,6,2]` 为例：`dp[1]=5+1=6`；`dp[2]=min(dp[0]+1+4, dp[1]+1+1)=5`；`dp[3]=min(dp[0]+6+9, dp[1]+6+4, dp[2]+6+1)=12`；`dp[4]=min(dp[1]+2+9, dp[2]+2+4, dp[3]+2+1)=11`。关键中间值是 `dp[2]=5`，它让 `dp[4]` 从 `dp[2]` 转移得到 `5+2+4=11`。

```python
dp = [0] * (n + 1)
for j in range(1, n + 1):
    best = float('inf')
    for i in range(max(0, j - 3), j):
        cand = dp[i] + costs[j - 1] + (j - i) ** 2
        if cand < best:
            best = cand
    dp[j] = best
return dp[n]
```

## 复杂度
时间：`O(n)`，每个 `j` 只枚举 3 个前驱。
空间：`O(n)`，开了长度 `n+1` 的 `dp` 数组。

## 易错点
- 输入 `n=1, costs=[9]` → 若写成 `costs[j]` 会越界或取错值 → 正确用 `costs[j-1]`，`dp[1]=9+1=10`。
- 输入 `n=4, costs=[5,1,6,2]` → 若只从 `j-1` 和 `j-2` 转移会漏掉跨 3 级 → 必须枚举 `j-3`，示例 3 的 `0→3` 就是跨 3 级。

## 如果面试官追问
问：能否把空间压到 `O(1)`？答：可以，只保留最近 3 个 `dp` 值滚动更新，因为转移只依赖前 3 项。
