## 一句话思路
统计每个值的出现次数，最大频次就是最少需要的组数，只要它不超过 `len(nums) // k` 即可。

## 怎么做
1. 用 `Counter(nums)` 统计每个值的频次，记下最大值 `mx`。
2. 组数 `g = len(nums) // k`，若 `len(nums) % k != 0` 直接返回 `False`。
3. 判断 `mx <= g`：频次最高的值必须分散到不同组，每组最多放它一次，所以它需要至少 `mx` 个组。
4. 其余元素按频次从高到低依次填入各组空位即可，`mx <= g` 保证不会冲突。

以 `nums = [3,5,2,2], k = 2` 为例：`Counter` 得 `{2: 2, 3: 1, 5: 1}`，`mx = 2`，`g = 4 // 2 = 2`，`2 <= 2` 返回 `True`。值 `2` 分别进组 1 和组 2，`3`、`5` 各补一个空位。

```python
from collections import Counter

def partitionArray(nums, k):
    n = len(nums)
    if n % k != 0:
        return False
    g = n // k
    cnt = Counter(nums)
    return max(cnt.values()) <= g
```

关键点：`mx <= g` 是充要条件。必要性显然；充分性靠贪心填位——把频次最高的值先铺满 `mx` 个组，剩余空位总数 `n - mx * 1` 足够容纳其他元素，且任何值的频次都不超过 `mx`，不会出现同组重复。

## 复杂度
时间：`O(n)`，`Counter` 遍历一次 `nums`，`max` 遍历不同值。
空间：`O(d)`，`d` 为不同值个数，最坏 `O(n)`。

## 易错点
- `nums = [1,5,2,3], k = 3`：只检查 `n % k` 得 `4 % 3 = 1 != 0` 返回 `False` 是对的，但若输入 `[1,1,2,3,4,5], k = 3`，`n % k == 0` 却因 `1` 出现两次、`g = 2`、`mx = 2 <= 2` 返回 `True`——此时组 1 放 `[1,2,3]`、组 2 放 `[1,4,5]` 合法，别误判为 `False`。
- `nums = [1,1,1,2,2,3], k = 2`：`n = 6`，`g = 3`，`mx = 3 <= 3` 返回 `True`，三个 `1` 各占一组，`2,2,3` 补位；若误用「不同值个数 `>= k`」判断会得 `3 >= 2` 为 `True` 但逻辑错误，正确判据只有 `mx <= g`。

## 如果面试官追问
要求输出具体分组方案怎么办？
答：按频次降序，每轮取当前频次最高的 `k` 个不同值组成一组，用堆维护频次即可，`O(n log d)`。
