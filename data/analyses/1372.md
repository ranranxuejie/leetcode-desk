## 一句话思路
自顶向下 DFS，每个节点带「上一步是从父节点往哪个方向来的」，只允许往反方向走，边走边更新全局最大值。

## 怎么做
1. 定义 `dfs(node, from_left, length)`：`from_left=True` 表示到达 `node` 的最后一步是「父→左」，因此下一步只能走右子；`length` 是当前已走步数。
2. 走右子时 `length+1`，走左子时重置为 `1`（因为方向没交错，只能从这条边重新起算）；两个分支都要递归，不能只走「合法」那一边。
3. 用 `nonlocal` 的 `best` 记录所有 `length` 的最大值，空节点返回。
4. 以示例 2 `root = [1,1,1,null,1,null,null,1,1,null,1]` 为例：根走左到节点 2，`length=1`；节点 2 只能走右到节点 4，`length=2`；节点 4 走左到节点 7，`length=3`；节点 7 走右到节点 9，`length=4`，`best` 更新为 4。

```python
def dfs(node, from_left, length):
    nonlocal best
    if not node:
        return
    best = max(best, length)
    dfs(node.right, False, length + 1 if from_left else 1)
    dfs(node.left, True, length + 1 if not from_left else 1)

best = 0
dfs(root, True, 0)
return best
```

关键点：`from_left` 为 `True` 时走右子才 `+1`，走左子必须重置成 `1`——重置而不是 `0`，因为这条边本身已经算一步。

## 复杂度
时间 O(n)：每个节点恰好被访问一次，n 为节点数。
空间 O(h)：递归栈深度等于树高 h，最坏链状树 O(n)，无额外数组。

## 易错点
- 输入是单节点 `[1]` → 若把 `best` 初始化为 `1` 或把 `length` 从 `1` 起算，会输出 1 → 正确做法是 `best=0`、`length=0`，因为单节点路径长度定义为 0。
- 输入是纯左链（如 `[1,1,null,1,null,...]`）→ 若在「方向不合法」时直接 `return` 不递归，会漏掉从子节点重新起算的更长路径 → 正确做法是两个子节点都递归，只是不合法那侧传 `1`。

## 如果面试官追问
要求返回最长交错路径的具体节点序列怎么办？
答：把 `best` 换成记录「当前路径列表」，更新 `best` 时深拷贝一份，空间升到 O(n·h)，其余逻辑不变。
