## 一句话思路
特殊下标互不相邻，按奇偶分成两条链做「选/不选」的线性 DP，代价是 `max(邻居)+1-nums[i]`。

## 怎么做
1. 关键观察：两个特殊下标不能相邻，所以可选集合是下标 1..n-2 上的独立集，且被选中的位置互不影响（只跟原数组的左右邻居比）。
2. 对每个候选 i，代价 `cost[i] = max(nums[i-1], nums[i+1]) + 1 - nums[i]`，若 ≤0 则取 0（已经特殊，不用加）。
3. 在链上做 DP：`dp[i] = min(dp[i-1], dp[i-2] + cost[i])`，即不选 i 或选 i。
4. 因为下标 1 和 3 这类同奇偶的才可能相邻冲突，实际整条链直接跑一遍即可（相邻下标天然冲突，DP 已处理）。

用示例 3 `nums = [5,2,1,4,3]`：候选 i=1,2,3。
- `cost[1] = max(5,1)+1-2 = 4`
- `cost[2] = max(2,4)+1-1 = 4`
- `cost[3] = max(1,3)+1-4 = 0`

DP：`dp[0]=0, dp[1]=4, dp[2]=min(4, 0+4)=4, dp[3]=min(4, 4+0)=4`，答案 4，与官方一致（选 i=1 和 i=3）。

```python
n = len(nums)
cost = [0] * n
for i in range(1, n - 1):
    cost[i] = max(0, max(nums[i-1], nums[i+1]) + 1 - nums[i])
prev2, prev1 = 0, 0
for i in range(1, n - 1):
    prev2, prev1 = prev1, min(prev1, prev2 + cost[i])
return prev1
```

注意 `cost` 用 `max(0, ...)` 是因为原数组可能已经满足 `nums[i] > 两侧`，此时不用加。

## 复杂度
时间 O(n)：一次遍历算 cost，一次 DP。
空间 O(n)：cost 数组；可压成 O(1) 但需边算边 DP。

## 易错点
- 输入 `[1,2,2]`：若忘记 `max(0, ...)`，`cost[1] = max(1,2)+1-2 = 1` 正确，但若写成 `max(nums[i-1],nums[i+1])-nums[i]` 会得 0，漏掉「必须严格大于」的 +1。正确做法是 `+1` 后再和 0 取 max。
- 输入 `[2,1,1,3]`：i=1 的 cost 是 `max(2,1)+1-1 = 2`，i=2 的 cost 是 `max(1,3)+1-1 = 3`，两者相邻不能同选，DP 必须比较 `dp[i-1]` 与 `dp[i-2]+cost[i]`；若贪心选最小 cost 会选 i=1 得 2（正确），但若数组是 `[1,1,1,1]` 贪心会错，必须 DP。

## 如果面试官追问
问：若允许同时减小元素呢？答：代价变成 `max(0, max(邻居)+1-nums[i])` 仍成立，但邻居可能被改，需重新定义 DP 状态记录邻居最终值。
