## 一句话思路
按列从低位到高位回溯，每列只枚举「当前列尚未确定」的字符，用进位 `carry` 剪枝，避免 10! 全排列。

## 怎么做
1. 把 `words` 和 `result` 右对齐，按列处理；先统计每个字符的权重 `weight[ch] = Σ(在 words 中该位 +1，在 result 中该位 -1) × 10^pos`，这样方程等价于 `Σ weight[ch]*digit[ch] == 0`。
2. 记录 `leading` 集合：`words[i][0]` 和 `result[0]` 不能取 0。
3. 按权重绝对值从大到小排序字符，回溯时优先定大权重字符，剪枝更早生效。
4. 每定一个字符就累加 `total += weight[ch]*d`，若剩余字符全取最大可能值仍无法把 `total` 拉回 0，则剪枝。

以 `["SEND","MORE"]` / `"MONEY"` 为例：`weight['D']=1, weight['E']=10-1000-100=...`，实际算得 `D=7,E=5,N=6,S=9,M=1,O=0,R=8,Y=2` 时 `total` 恰为 0，返回 `True`。

```python
def dfs(i, total):
    if i == len(chars):
        return total == 0
    ch = chars[i]
    for d in range(10):
        if used[d] or (d == 0 and ch in leading):
            continue
        used[d] = True
        if dfs(i + 1, total + weight[ch] * d):
            return True
        used[d] = False
    return False
```

## 复杂度
时间：`O(10^k)`，`k` 为不同字符数（≤10），剪枝后远小于 `10!`。
空间：`O(k)` 递归栈 + `O(1)` 的 `used[10]` 与权重表。

## 易错点
- 输入 `words=["AB"], result="AB"`：若忘记 `leading` 约束，会把 `A` 映射成 0 得到 `0B=0B` 误判 `True`；正确做法是 `A` 在 `leading` 中，`d==0` 时跳过。
- 输入 `["SIX","SEVEN","SEVEN"]` / `"TWENTY"`：若按字符出现顺序而非权重排序回溯，`S` 权重远大于 `Y`，会先枚举 `Y` 导致大量无效分支；正确做法是按 `abs(weight[ch])` 降序排 `chars`。

## 如果面试官追问
问：若要求输出所有可行映射而非只判存在？答：把 `return True` 改成收集 `digit` 快照后继续搜，注意同一 `total==0` 叶子可能对应多组解，需完整遍历不剪枝。
