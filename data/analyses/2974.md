## 一句话思路
排序后每两个一组，组内先取大的再取小的，因为 Bob 先入 arr、Alice 后入 arr。

## 怎么做
1. 对 `nums` 排序，使每轮 Alice 取到的就是当前最小的两个。
2. 按 `i = 0, 2, 4, ...` 遍历，每轮取 `nums[i]`（Alice）和 `nums[i+1]`（Bob）。
3. 每轮先追加 `nums[i+1]`，再追加 `nums[i]`。

以 `nums = [5,4,2,3]` 为例：排序得 `[2,3,4,5]`；第一轮 `i=0`，Alice 取 `2`、Bob 取 `3`，arr 追加 `3,2`；第二轮 `i=2`，追加 `5,4`，结果 `[3,2,5,4]`。

```python
nums.sort()
arr = []
for i in range(0, len(nums), 2):
    arr.append(nums[i + 1])
    arr.append(nums[i])
return arr
```

关键点：排序后 `nums[i] < nums[i+1]` 恒成立，所以「Bob 取较大者」不需要额外比较，直接按下标取即可。

## 复杂度
时间：排序 `O(n log n)` 主导，遍历 `O(n)`。
空间：`arr` 占 `O(n)`，排序栈开销 `O(log n)`。

## 易错点
1. 输入 `nums = [2,5]` → 若按「先小后大」追加会得到 `[2,5]` → 正确是 Bob 先入，追加顺序必须是 `nums[i+1]` 再 `nums[i]`，得 `[5,2]`。
2. 输入 `nums = [5,4,2,3]` → 若不排序直接两两取，第一轮会拿 `5,4` 得 `[4,5,...]` → 必须先 `sort()`，保证每轮取的是当前全局最小两个。

## 如果面试官追问
问：如果 nums 长度到 10^5 且要求在线处理（边读边出）？
答：用最小堆，每轮 `heappop` 两次，先 push 第二次弹出的、再 push 第一次弹出的。
