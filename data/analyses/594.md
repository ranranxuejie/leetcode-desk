## 一句话思路
用哈希表统计每个值的出现次数，再对每个值 x 查 x+1 的计数，取两者之和的最大值。

## 怎么做
1. 遍历 `nums`，用 `Counter` 得到 `cnt`，键是元素值、值是出现次数。
2. 遍历 `cnt` 的每个键 `x`，若 `x + 1` 也在 `cnt` 中，则候选长度为 `cnt[x] + cnt[x + 1]`。
3. 用 `best` 记录候选长度的最大值，初始为 0；遍历结束返回 `best`。

以示例 1 的 `nums = [1,3,2,2,5,2,3,7]` 为例，`cnt = {1:1, 3:2, 2:3, 5:1, 7:1}`。当 `x = 2` 时，`cnt[2] + cnt[3] = 3 + 2 = 5`，这就是答案；`x = 1` 时 `cnt[1] + cnt[2] = 1 + 3 = 4`，`x = 3` 时 `cnt[3] + cnt[4]` 因 4 不存在而跳过。

```python
from collections import Counter

cnt = Counter(nums)
best = 0
for x in cnt:
    if x + 1 in cnt:
        best = max(best, cnt[x] + cnt[x + 1])
return best
```

关键点在于：子序列不要求连续，所以只要值域上相邻的两个数都存在，就能把它们的全部出现次数都收进来，顺序问题不存在。

## 复杂度
时间 O(n)：建 `Counter` 扫一遍 `nums`，再扫一遍至多 n 个不同键。
空间 O(n)：`Counter` 最多存 n 个键值对。

## 易错点
- 输入 `nums = [1,1,1,1]` → 若把「最大值减最小值 ≤ 1」当成和谐条件，会返回 4 → 题目要求差别**正好**是 1，单值数组必须返回 0，所以循环里必须靠 `x + 1 in cnt` 这个判断把单值情况挡掉。
- 输入 `nums = [1,2,3,4]` → 若只检查 `x` 与 `x+1` 中较小的那个方向、或误用 `x - 1` 配对后没去重，可能漏掉 `[3,4]` 或重复计数 → 统一只朝 `x + 1` 一个方向查，每个相邻对恰好被枚举一次，`best` 自然取到 2。

## 如果面试官追问
问：如果要求输出具体子序列而不只是长度？
答：在 `cnt` 里记下每个值的首次下标，取到最优的 `x` 后按原数组顺序筛出值为 `x` 或 `x+1` 的元素即可。
