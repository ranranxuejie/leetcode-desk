## 一句话思路
把每个数对看成有向边 start→end，求一条欧拉路径；Hierholzer 栈式 DFS 逆序拼接即可。

## 怎么做
1. 用 `out_deg - in_deg` 找起点：差值 +1 的节点是起点，全为 0 则任取一条边的起点。
2. 建邻接表 `adj[start].append(end)`，同时统计入度出度。
3. 从起点做迭代式 Hierholzer：沿边走、边出栈边把节点压入 `path`，走不动就回退。
4. `path` 逆序后相邻两两配对，就是答案。

以示例 1 `[[5,1],[4,5],[11,9],[9,4]]` 为例：出度减入度中 11 是 +1（出 1 入 0），5、4、9 都是 0，1 是 -1，所以起点 `start = 11`。从 11 出发走 11→9→4→5→1，`path` 得到 `[1,5,4,9,11]`，逆序后配对成 `[[11,9],[9,4],[4,5],[5,1]]`。

```python
from collections import defaultdict, Counter
adj = defaultdict(list)
deg = Counter()
for s, e in pairs:
    adj[s].append(e)
    deg[s] += 1
    deg[e] -= 1
start = next((v for v in deg if deg[v] == 1), pairs[0][0])
stack, path = [start], []
while stack:
    v = stack[-1]
    if adj[v]:
        stack.append(adj[v].pop())
    else:
        path.append(stack.pop())
path.reverse()
return [[path[i], path[i + 1]] for i in range(len(path) - 1)]
```

## 复杂度
时间 O(n)：每条边恰好被 pop 一次，n 是 pairs 长度。
空间 O(n)：`adj` 存 n 条边，`stack` 与 `path` 各至多 n+1 个节点。

## 易错点
- 起点选错：示例 2 `[[1,3],[3,2],[2,1]]` 所有节点出入度相等，若硬找 `deg == 1` 会拿到 `None` 崩溃；正确做法是回退到 `pairs[0][0]`（这里取 1），从环上任意点出发都能走完。
- 用递归写 DFS：pairs 长度到 10^5，链式图如 `[[1,2],[2,3],...]` 递归深度 10^5 直接 `RecursionError`；必须用显式 `stack` 迭代，且 `path.append(stack.pop())` 的顺序不能反，反了配对出的边方向全错。

## 如果面试官追问
问：若要求输出字典序最小的合法排列？
答：把 `adj[v]` 换成最小堆，Hierholzer 仍成立，但逆序后需再校验，复杂度多一个 log n。
