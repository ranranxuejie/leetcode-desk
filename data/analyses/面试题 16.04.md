## 一句话思路
逐行、逐列、两条对角线各扫一遍，看是否有 N 个相同非空字符连成线；同时记录空格判断 Pending/Draw。

## 怎么做
1. 把行、列、两条对角线统一成「一条线」来检查，写个 `check(line)` 返回该线上唯一的非空字符或 `None`。
2. 对每行 `board[i]`、每列 `[board[r][i] for r in range(n)]`、主对角 `board[i][i]`、副对角 `board[i][n-1-i]` 依次调用。
3. 任一 `check` 返回非 `None` 即为赢家，直接返回。
4. 无赢家时，若存在 `" "` 返回 `"Pending"`，否则 `"Draw"`。

以示例 1 `board = ["O X"," XO","X O"]` 为例，n=3。主对角是 `board[0][0],board[1][1],board[2][2]` = `'O','X','O'`，`check` 里 `set(line)` 得 `{'O','X'}`，长度 2，返回 `None`。副对角 `board[0][2],board[1][1],board[2][0]` = `'X','X','X'`，`set` 得 `{'X'}`，返回 `'X'`，即答案。

```python
def check(line):
    s = set(line)
    if len(s) == 1 and " " not in s:
        return s.pop()
    return None

n = len(board)
lines = [board[i] for i in range(n)]
lines += [[board[r][i] for r in range(n)] for i in range(n)]
lines.append([board[i][i] for i in range(n)])
lines.append([board[i][n-1-i] for i in range(n)])
for line in lines:
    w = check(line)
    if w:
        return w
return "Pending" if any(" " in row for row in board) else "Draw"
```

## 复杂度
时间 O(n²)：n 条线各长 n，共扫 n² 个格子。
空间 O(n)：`lines` 里每列/对角线各建一个长度 n 的列表。

## 易错点
- 输入 `["OOX","XXO","OX "]` → 若只查行不查列/对角线，会漏判；这里列 `board[0][1],board[1][1],board[2][1]` = `'O','X','X'` 不成立，但必须全查才能确认 Pending。正确做法是四类线都过一遍。
- 全空行如 `["   ","   ","   "]` → `set(line)` 得 `{' '}`，长度 1，若不加 `" " not in s` 会误判空格为赢家。正确做法是 `check` 里显式排除空格。

## 如果面试官追问
若 N 扩大到 10⁴ 且棋盘稀疏（只存已落子坐标），怎么判赢？答：维护每行/列/两对角线的 X、O 计数，落子时 O(1) 更新并检查是否达到 N。
