## 一句话思路
用栈存每层括号的分数，遇 `(` 压 0，遇 `)` 弹出后按「空层得 1、非空层翻倍」算完再累加回上一层。

## 怎么做
1. 初始化 `stack = [0]`，栈底那个 0 是虚拟外层，专门接收最外层并列项的累加结果。
2. 遇 `(` 就 `stack.append(0)`，表示进入新的一层，该层分数从 0 开始攒。
3. 遇 `)` 先 `v = stack.pop()`，再 `stack[-1] += 1 if v == 0 else 2 * v`。
4. 扫完返回 `stack[0]`。

拿示例 4 `"(()(()))"` 走一遍关键几步：读到第 5 个字符 `(` 时栈是 `[0, 0, 0]`；读到它后面的 `)` 时 `v = 0`，于是 `stack[-1] += 1`，栈变 `[0, 0, 1]`；再读到倒数第二个 `)` 时 `v = 1`，`stack[-1] += 2`，栈变 `[0, 2]`；最后一个 `)` 时 `v = 2`，`stack[-1] += 4`，得 `[0, 4]`。等等——这里要小心，`"(()(()))"` 的最外层是 `( ... )`，所以最终 `stack[0]` 拿到的是 `2 * 2 = 4`？不对，正确答案是 6。问题出在中间那步：`"(()(()))"` 拆成 `( () (()) )`，内层是 `1 + 2 = 3`，外层翻倍得 6。所以第 5 个字符 `(` 对应的 `)` 弹出后应得 1，累加到它所在层；倒数第二个 `)` 弹出的是那个 `1`，翻倍成 2 累加；最后一个 `)` 弹出的是 `1 + 2 = 3`，翻倍成 6。关键中间值：处理到倒数第二个 `)` 时 `v = 1`，`stack[-1]` 从 1 变 3；最后一个 `)` 时 `v = 3`，`stack[-1] += 6`。

```python
stack = [0]
for ch in s:
    if ch == '(':
        stack.append(0)
    else:
        v = stack.pop()
        stack[-1] += 1 if v == 0 else 2 * v
return stack[0]
```

## 复杂度
时间：O(n)，n 为 `s` 长度，每个字符进出栈各一次。
空间：O(n)，最坏全嵌套时栈深 n/2 + 1。

## 易错点
- 输入 `"()"`：若写成遇 `)` 直接 `stack[-1] += 1` 而不先 `pop`，`"()"` 会得 1 看似对，但 `"(())"` 会错成 2 之外的数——必须先 `pop` 出 `v` 再判断 `v == 0`，否则分不清「空层」和「已有内容」。
- 输入 `"()()"`：若把 `stack[-1] += ...` 写成 `stack[-1] = ...`，第二个 `()` 会覆盖第一个的 1，结果错成 1；正确是累加，两个并列项各 1 得 2。

## 如果面试官追问
问：若 `s` 长度到 10^5 且要求 O(1) 空间？答：用计数器 `depth` 记录深度，只在 `()` 相邻处按 `2 ** (depth - 1)` 累加，无需栈。
