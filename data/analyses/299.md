## 一句话思路
先逐位比对统计公牛，再用两个长度 10 的计数数组对非公牛位做「取小求和」得到奶牛。

## 怎么做
1. 遍历 `i in range(len(secret))`，`secret[i] == guess[i]` 时 `bulls += 1`，否则把 `secret[i]` 和 `guess[i]` 分别记进 `cnt_s`、`cnt_g`。
2. 对数字 `d in range(10)`，`cows += min(cnt_s[d], cnt_g[d])`——同一数字在两边各剩多少，最多只能配对这么多。
3. 返回 `f"{bulls}A{cows}B"`。

以 `secret = "1123"`、`guess = "0111"` 为例：下标 0 是 `'1'` vs `'0'` 不匹配，下标 1 是 `'1'` vs `'1'` 匹配 → `bulls = 1`；剩下非公牛位是 secret 的 `'1','2','3'` 和 guess 的 `'0','1','1'`，于是 `cnt_s[1]=1`、`cnt_g[1]=2`，`min` 取 1，其余数字取 0，得 `cows = 1`，输出 `"1A1B"`。关键就在这个 `min`：guess 里两个 `'1'` 只能配掉 secret 剩下的一个 `'1'`。

```python
cnt_s = [0] * 10
cnt_g = [0] * 10
bulls = cows = 0
for s, g in zip(secret, guess):
    if s == g:
        bulls += 1
    else:
        cnt_s[int(s)] += 1
        cnt_g[int(g)] += 1
for d in range(10):
    cows += min(cnt_s[d], cnt_g[d])
return f"{bulls}A{cows}B"
```

## 复杂度
时间 O(n)，n 为串长，逐位比对一遍加固定 10 次取小。
空间 O(1)，只开了两个长度 10 的计数数组。

## 易错点
- 输入 `secret = "1123"`、`guess = "0111"` → 若把非公牛位直接按「数字出现过就算奶牛」计数，会得到 `1A3B`，因为 guess 的两个 `'1'` 都被算上；正确做法是对每个数字取 `min(cnt_s[d], cnt_g[d])`，这里 `'1'` 只贡献 1。
- 输入 `secret = "1807"`、`guess = "7810"` → 若先统计全部数字频次再减公牛，容易把已匹配位置的数字重复计入奶牛；正确做法是公牛位直接跳过、不写进 `cnt_s`/`cnt_g`，非公牛位才计数。

## 如果面试官追问
问：若 secret 和 guess 长度不等怎么办？答：先按较短长度比位置，多出的字符只进计数数组，`min` 逻辑不变。
