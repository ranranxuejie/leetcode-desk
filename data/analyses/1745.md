## 一句话思路
先用区间 DP 预处理 `pal[i][j]` 表示 `s[i:j+1]` 是否回文，再枚举两个切点验证三段全回文。

## 怎么做
1. 建 `n×n` 的 `pal` 表，按长度从 1 到 n 递推：`pal[i][j] = s[i]==s[j] and (j-i<2 or pal[i+1][j-1])`。
2. 枚举第一个切点 `i`（第一段是 `s[0:i]`，需 `pal[0][i-1]`）。
3. 枚举第二个切点 `j`（第二段 `s[i:j]`，第三段 `s[j:n]`），三段都回文即返回 `True`。

以 `s = "abcbdd"` 为例，`pal[1][3]` 对应 `"bcb"`：`s[1]=='b'==s[3]` 且 `pal[2][2]=True`，故为 `True`。枚举到 `i=1, j=4` 时，`pal[0][0]`（`"a"`）、`pal[1][3]`（`"bcb"`）、`pal[4][5]`（`"dd"`）全为 `True`，返回 `True`。

```python
n = len(s)
pal = [[False] * n for _ in range(n)]
for i in range(n):
    pal[i][i] = True
for length in range(2, n + 1):
    for i in range(n - length + 1):
        j = i + length - 1
        if s[i] == s[j] and (length == 2 or pal[i + 1][j - 1]):
            pal[i][j] = True
for i in range(1, n - 1):
    if not pal[0][i - 1]:
        continue
    for j in range(i + 1, n):
        if pal[i][j - 1] and pal[j][n - 1]:
            return True
return False
```

## 复杂度
时间：O(n²)，预处理填表 O(n²) 加枚举切点 O(n²)。
空间：O(n²)，`pal` 二维表占 n×n 个布尔值。

## 易错点
- 输入 `"abcbdd"` 若把切点写成 `i` 从 0 开始，`pal[0][-1]` 会取到末字符而非空串，误判第一段回文 → 切点必须从 1 开始，保证三段非空。
- 输入 `"aaa"` 若只枚举 `i<j` 却漏掉 `j=n-1` 的边界，第三段 `s[j:n]` 为空串被当成回文 → 循环上界写 `range(i+1, n)`，`j` 最大到 `n-1`，第三段至少 1 个字符。

## 如果面试官追问
问：要求输出所有分割方案怎么办？
答：把 `return True` 换成收集 `(i, j)` 到结果列表，枚举完再返回，复杂度不变。
