## 一句话思路
状态取「已到岸的人」的位掩码加当前阶段，用 Dijkstra 跑最短路，因为每次转移的代价依赖阶段且阶段只由 floor 决定。

## 怎么做
1. 状态 `(mask, stage)`，`mask` 表示已到达目的地的人，起点 `(0, 0)`，终点 `mask == (1<<n)-1`。
2. 从营地出发时枚举 `mask` 补集的子集 `g`，`|g| <= k`，代价 `max(time[i] for i in g) * mul[stage]`，新阶段 `(stage + floor(d)) % m`。
3. 若 `mask|g` 未满员，必须有人返回：枚举 `g` 中的人 `r`，代价 `time[r] * mul[new_stage]`，再推进阶段。
4. 用堆按累计时间弹出，第一次弹出满员状态即为答案。

以示例 2 为例：起点 `(0,0)`，选 `g={0,2}`，`d = max(2,8)*1.0 = 8.0`，`floor(8)%3 = 2`，新阶段 2；返回 `r=0`，`1.5`，`floor(1.5)%3=1`，阶段回到 0；再选 `g={0,1}`，`5.0`，总 `14.5`。

```python
import heapq
full = (1 << n) - 1
dist = {(0, 0): 0.0}
pq = [(0.0, 0, 0)]
while pq:
    d, mask, st = heapq.heappop(pq)
    if d > dist.get((mask, st), 1e18): continue
    if mask == full: return d
    rest = full ^ mask
    sub = rest
    while sub:
        if sub.bit_count() <= k:
            t = max(time[i] for i in range(n) if sub >> i & 1) * mul[st]
            ns = (st + int(t)) % m
            nm = mask | sub
            if nm == full and d + t < dist.get((nm, ns), 1e18):
                dist[(nm, ns)] = d + t; heapq.heappush(pq, (d + t, nm, ns))
            elif nm != full:
                for r in range(n):
                    if sub >> r & 1:
                        rt = time[r] * mul[ns]
                        ns2 = (ns + int(rt)) % m
                        nd = d + t + rt
                        if nd < dist.get((nm, ns2), 1e18):
                            dist[(nm, ns2)] = nd; heapq.heappush(pq, (nd, nm, ns2))
        sub = (sub - 1) & rest
return -1.0
```

## 复杂度
时间：`O(2^n * m * (3^n 子集枚举 + n 返回枚举) * log)`，n≤12 可接受。
空间：`O(2^n * m)` 的 dist 字典加堆。

## 易错点
- `k=1` 且 `n>=2`（示例 3）：只枚举单人出发，返回后永远无法凑满，会死循环或返回错误值 → 正确做法是满员前必须有人返回，单人船无法推进，最终堆空返回 `-1.0`。
- 阶段推进用 `int(t)` 而非 `round`：`t=1.5` 时 `floor` 是 1，若用四舍五入得 2，阶段错位导致示例 2 算出 15.0 而非 14.5。

## 如果面试官追问
问：n 放大到 20 怎么办？答：位掩码 2^20 太大，需按「已到岸人数 + 阶段」分层或改用贪心配对（最快两人往返）近似，但精确解仍是指数级。
