## 一句话思路
开一个长度 n 的结果数组，把 `s[i]` 直接放到 `res[indices[i]]`，因为 indices 是 0..n-1 的一个排列。

## 怎么做
1. 建 `res = [''] * n`，长度取 `len(s)`。
2. 遍历 `i`，执行 `res[indices[i]] = s[i]`。
3. 用 `''.join(res)` 拼回字符串返回。

拿示例 1 走一遍：`s = "codeleet"`，`indices = [4,5,6,7,0,2,1,3]`。i=0 时 `res[4] = 'c'`；i=1 时 `res[5] = 'o'`；i=4 时 `res[0] = 'l'`；i=6 时 `res[1] = 'e'`。全部填完后 `res` 是 `['l','e','e','t','c','o','d','e']`，join 得 `"leetcode"`。

```python
n = len(s)
res = [''] * n
for i in range(n):
    res[indices[i]] = s[i]
return ''.join(res)
```

关键点：方向是「从 s 取字符，按 indices 放到 res」，不是「从 res 的位置去 s 里找」。后者需要先求逆排列 `pos[indices[i]] = i`，多一步且容易写反。

## 复杂度
时间 O(n)：一次遍历填 n 个位置，join 再扫一遍。
空间 O(n)：额外开了长度 n 的 `res` 列表，返回值本身不计。

## 易错点
- 把赋值方向写反成 `res[i] = s[indices[i]]`：示例 1 会得到 `s[4]='l'` 放在 res[0]、`s[5]='o'` 放在 res[1]，输出 `"loetcede"` 而非 `"leetcode"`。记住 indices[i] 是「字符 i 的目的地」，是 res 的下标。
- 用 `res = ''` 然后 `res[indices[i]] = s[i]`：Python 字符串不可变，直接抛 `TypeError`。必须先开 list 再 join，或改用 `bytearray`。

## 如果面试官追问
问：如果 indices 不保证是排列、可能有重复值怎么办？
答：题目保证唯一才成立；有重复时目标位置冲突，需先声明覆盖规则（如后者覆盖前者），否则题意无解。
