## 一句话思路
用二维 DP：`dp[i][j]` 表示 `text1[:i]` 与 `text2[:j]` 的 LCS 长度，靠末尾字符是否相等做转移。

## 怎么做
1. 定义 `dp` 为 `(m+1) x (n+1)` 全 0 矩阵，`dp[0][*]` 和 `dp[*][0]` 表示空串，天然是 0。
2. 双循环 `i` 从 1 到 `m`、`j` 从 1 到 `n`，比较 `text1[i-1]` 与 `text2[j-1]`。
3. 相等则 `dp[i][j] = dp[i-1][j-1] + 1`，否则取 `max(dp[i-1][j], dp[i][j-1])`。
4. 返回 `dp[m][n]`。

拿 `text1="abcde"`、`text2="ace"` 说关键一步：算到 `i=3, j=2` 时 `text1[2]='c'`、`text2[1]='c'` 相等，`dp[3][2] = dp[2][1] + 1 = 1 + 1 = 2`，即 `"ac"`；若这里误写成 `dp[i-1][j]+1` 会得到 2 但后续 `i=5,j=3` 处 `'e'=='e'` 时前缀被污染，最终可能算成 2 而非 3。

```python
m, n = len(text1), len(text2)
dp = [[0] * (n + 1) for _ in range(m + 1)]
for i in range(1, m + 1):
    for j in range(1, n + 1):
        if text1[i - 1] == text2[j - 1]:
            dp[i][j] = dp[i - 1][j - 1] + 1
        else:
            dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
return dp[m][n]
```

滚动数组版只需两行 `prev/cur`，但注意 `cur[0] = 0` 每轮重置。

## 复杂度
时间：`O(m*n)`，`m=len(text1)`、`n=len(text2)` 各贡献一层循环。
空间：`O(m*n)` 存整个 `dp` 表；滚动数组可降到 `O(n)`。

## 易错点
- 下标错位：写成 `text1[i] == text2[j]`（用 0 基下标配 1 基 `dp`）→ 在 `"abc"/"abc"` 上 `i=3` 时越界或错配成 `dp[2][2]+1` 得 2 → 必须写 `text1[i-1] == text2[j-1]`。
- 不等时只取一边：写成 `dp[i][j] = dp[i-1][j]` → 在 `"abcde"/"ace"` 的 `i=2,j=3`（`'b'` vs `'e'`）处丢掉 `dp[2][2]=1` 的信息，最终返回 2 → 必须 `max(dp[i-1][j], dp[i][j-1])`。

## 如果面试官追问
要求输出具体 LCS 字符串而非长度？答：从 `dp[m][n]` 回溯，相等则收字符并 `i-=1,j-=1`，否则朝 `dp` 值大的方向走，最后反转结果。
