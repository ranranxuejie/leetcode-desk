## 一句话思路
枚举目标值 v，用前缀和求「把某段全变成 v 能多赚多少」的最大值，再加原有 k 的个数。

## 怎么做
1. 统计 `base = nums.count(k)`，这是不动任何元素时 k 的个数。
2. 对每个候选值 v（1..50，只需考虑 nums 里出现过的），把数组映射成权重：`nums[i]==v` 记 +1，`nums[i]==k` 记 -1，其余记 0。
3. 对权重数组求最大子段和 `best`，它表示「选这段做加法后，v 变 k 的净增数」；答案取 `base + max(best, 0)`。
4. 用 Kadane 一遍扫完，O(50n)。

以示例 2 `nums=[10,2,3,4,5,5,4,3,2,2], k=10` 为例，`base=1`。取 v=2 时权重为 `[-1,1,0,0,0,0,0,0,1,1]`，Kadane 在 `[1..9]` 段得 `best=3`，答案 `1+3=4`，与官方一致。

```python
base = nums.count(k)
ans = base
for v in set(nums):
    if v == k:
        continue
    cur = best = 0
    for a in nums:
        w = 1 if a == v else (-1 if a == k else 0)
        cur = max(w, cur + w)
        best = max(best, cur)
    ans = max(ans, base + best)
```

关键点：权重里 `a==k` 记 -1，因为这段里的 k 会被加走、不再等于 k，必须扣掉；`a==v` 记 +1 才是净赚。

## 复杂度
时间：O(50n)，外层枚举至多 50 个不同值，内层 Kadane 扫 n。
空间：O(1)，只用了 `cur/best/base` 几个变量，`set(nums)` 至多 50 个元素。

## 易错点
- 输入 `nums=[1,2,3,4,5,6], k=1`：若把 `a==k` 记 0 而非 -1，权重全非负，Kadane 会选整段得 `best=5`，答案错成 6；正确是 `base=1` 加 `[2..5]` 段（含末尾那个 1 记 -1）得 `best=1`，答案 2。
- 输入 `nums=[1,1,1], k=1`：若允许 v==k 参与枚举，权重全 +1，`best=3`，答案错成 6；必须 `continue` 跳过 v==k，答案保持 3。
- 输入 `nums=[5,5,5], k=1`：若忘记 `max(best,0)`，某段权重全负时 `best` 可能为负，`base+best` 小于 `base`；取 0 兜底才对。

## 如果面试官追问
问：若 nums[i] 范围放大到 10^9 怎么办？
答：枚举对象从「所有值」改成「出现过的值」，用哈希表存下标列表，只对每个值的下标做 Kadane，复杂度 O(n)。
