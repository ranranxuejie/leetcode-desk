## 一句话思路
逐位把屏幕字符串从 `'a'` 递增到 `target[i]`，每按一次键 2 就记录一次当前串，最后追加按键 1 的结果。

## 怎么做
1. 维护当前串 `cur`（初始 `""`），对 `target` 的每个字符 `ch` 依次处理。
2. 若 `cur` 为空，先按按键 1 得到 `"a"` 并记录，再从 `'a'` 递增到 `ch`。
3. 非首位时，先按按键 1 追加 `'a'` 并记录，再递增末位到 `ch`，每次递增都记录。
4. 递增用 `chr(ord(cur[-1]) + 1)`，注意 `'z'` 之后回到 `'a'`。

以 `target = "abc"` 为例：处理 `'a'` 时 `cur` 为空，按 1 得 `"a"` 记录；处理 `'b'` 时先按 1 得 `"aa"` 记录，再递增末位得 `"ab"` 记录；处理 `'c'` 时先按 1 得 `"aba"`，递增两次得 `"abb"`、`"abc"`，共 6 个串，与输出一致。

```python
res, cur = [], ""
for ch in target:
    if not cur:
        cur = "a"
        res.append(cur)
    else:
        cur += "a"
        res.append(cur)
    while cur[-1] != ch:
        nxt = chr((ord(cur[-1]) - 97 + 1) % 26 + 97)
        cur = cur[:-1] + nxt
        res.append(cur)
```

## 复杂度
时间 O(n·26)：每个字符最多递增 25 次，每次拼接 O(n)，n 为 `target` 长度。
空间 O(n·26)：结果列表存约 26n 个串，每个串长 O(n)。

## 易错点
- `target = "za"` → 若递增写成 `chr(ord(cur[-1]) + 1)` 会得到 `'{'` 而非 `'a'` → 必须用 `(ord(c) - 97 + 1) % 26 + 97` 做回绕。
- `target = "a"` → 若在循环外统一先追加 `'a'` 再判断，会多出一个空串或重复 `"a"` → 首位要单独走「`cur` 为空则直接置 `"a"`」分支，不进 `while`。

## 如果面试官追问
问：若 target 长度到 10^5 还要求输出全部串？答：输出本身就有 O(26n²) 字符，瓶颈在输出，只能流式写结果、不缓存整串。
