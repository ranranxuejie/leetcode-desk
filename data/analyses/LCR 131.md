## 一句话思路
尽量切出长度为 3 的段，因为 3 的「单位长度收益」最高；余数 1 时把 3+1 换成 2+2。

## 怎么做
1. 特判 `bamboo_len <= 3`：此时不切反而更大（2→1、3→2），直接返回 `bamboo_len - 1`。
2. 用 `bamboo_len // 3` 得到 3 的个数 `q`，`bamboo_len % 3` 得到余数 `r`。
3. 按余数修正：`r == 0` 返回 `3**q`；`r == 1` 返回 `3**(q-1) * 4`；`r == 2` 返回 `3**q * 2`。
4. 关键中间值：以 `bamboo_len = 12` 为例，`q = 4`、`r = 0`，结果 `3**4 = 81`，与示例一致。

```python
def cuttingBamboo(bamboo_len):
    if bamboo_len <= 3:
        return bamboo_len - 1
    q, r = divmod(bamboo_len, 3)
    if r == 0:
        return 3 ** q
    if r == 1:
        return 3 ** (q - 1) * 4
    return 3 ** q * 2
```

为什么 3 最优：把一段长度 `x` 拆成 `a + b`，乘积 `a*b` 在 `a,b` 接近时最大；而 `3*3 = 9 > 2*2*2 = 8`，说明同样用 6 的长度，切成两个 3 比三个 2 更划算，所以只要不出现余 1，就全切 3。余 1 时 `3*1 < 2*2`，故把一个 3 和这个 1 合并成 2+2。

## 复杂度
时间：O(log n)，`3**q` 的快速幂按指数 q ≈ n/3 的对数计。
空间：O(1)，只存 `q`、`r` 两个整数。

## 易错点
- `bamboo_len = 2` 或 `3` → 若直接套 `3**q * r` 公式会得到 1 或 3，但正确答案是 1 和 2（必须切至少两段）→ 先特判 `<= 3` 返回 `bamboo_len - 1`。
- `bamboo_len = 4` → 若写成 `r == 1` 时返回 `3**q * 1` 会得 3，正确是 `2*2 = 4` → 余 1 时必须退一个 3 出来凑成 4。

## 如果面试官追问
问：要求返回具体切法而非乘积？答：按上面 `q`、`r` 直接构造列表，余 1 时输出 `q-1` 个 3 加两个 2，余 2 时末尾补一个 2。
