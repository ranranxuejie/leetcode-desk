## 一句话思路
用差分数组对每个 k 累加「哪些位置能得分」的区间，一次扫描求最大得分的最小下标。

## 怎么做
1. 对每个元素 `nums[i]`，它轮调 k 后落到位置 `(i - k) % n`，得分条件是 `nums[i] <= (i - k) % n`。
2. 解这个不等式，得到 k 的合法区间：`k ∈ [i - nums[i] + 1, i]`（模 n 意义下），长度 `nums[i]`。
3. 用差分数组 `diff` 在区间两端打标记，注意区间可能跨过 n 的边界要拆成两段。
4. 前缀和还原每个 k 的得分，取最大值且下标最小。

以 `nums = [2,3,1,4,0]`，n=5 为例：
- i=0, nums[0]=2：区间 `[0-2+1, 0] = [-1, 0]`，模 5 后为 `[4,4]` 和 `[0,0]`。
- i=3, nums[3]=4：区间 `[0, 3]`，diff[0]+=1, diff[4]-=1。
- 累加后 k=3 得分 4，最大。

```python
n = len(nums)
diff = [0] * (n + 1)
for i, v in enumerate(nums):
    lo = (i - v + 1) % n
    hi = i
    if lo <= hi:
        diff[lo] += 1
        diff[hi + 1] -= 1
    else:
        diff[0] += 1
        diff[hi + 1] -= 1
        diff[lo] += 1
        diff[n] -= 1
best, cur, ans = -1, 0, 0
for k in range(n):
    cur += diff[k]
    if cur > best:
        best, ans = cur, k
```

## 复杂度
时间 O(n)：每个元素打两次差分标记，再扫一遍前缀和。
空间 O(n)：额外开 `diff` 数组长度 n+1。

## 易错点
- 区间跨边界时忘记拆成两段：如 `nums=[0]`，i=0, v=0，lo=1, hi=0，lo>hi 必须拆成 `[0,0]` 和 `[1,4]`，否则漏算 k=0 的得分。
- 取最大值时用 `>=` 而非 `>`：示例 2 所有 k 得分相同，必须保留最小下标 0，用 `>=` 会返回最后一个 k。

## 如果面试官追问
问：如果要求返回所有最高分的 k 怎么办？
答：把 `if cur > best` 改成收集所有 `cur == best` 的下标即可，逻辑不变。
