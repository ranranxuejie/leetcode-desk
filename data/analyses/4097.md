## 一句话思路
按固定下标配对 `(nums[i], nums[i+1])`，用 `a * 10**len(str(b)) + b` 拼出每个合并值，取最小。

## 怎么做
1. 以步长 2 遍历 `i = 0, 2, 4, ...`，配对是题面写死的，不能重排。
2. 对每对 `a, b`，用 `a * 10 ** len(str(b)) + b` 拼接，关键是乘的幂由 `b` 的位数决定。
3. 用 `ans` 记录当前最小值，初始化为第一对的合并值。
4. 遍历结束返回 `ans`。

以 `nums = [34,7,11,11]` 为例：第一对 `a=34, b=7`，`len(str(7)) = 1`，所以 `34 * 10**1 + 7 = 347`；第二对 `a=11, b=11`，`len(str(11)) = 2`，得 `11 * 100 + 11 = 1111`；`ans = min(347, 1111) = 347`。

```python
ans = None
for i in range(0, len(nums), 2):
    a, b = nums[i], nums[i + 1]
    merged = a * 10 ** len(str(b)) + b
    if ans is None or merged < ans:
        ans = merged
return ans
```

注意 `b = 7` 时位数是 1 而不是 2，若误用 `10**2` 会得到 `3407`，直接改变答案。

## 复杂度
时间：O(n)，每对做一次位数计算和拼接，n 是数组长度。
空间：O(1)，只开了 `ans`、`a`、`b`、`merged` 几个变量。

## 易错点
1. 输入 `nums = [9,20]` → 若把 `b=20` 的位数当成 1（比如用 `len(str(a))` 或固定 `10**1`），会拼成 `9*10+20 = 110`，错成 110；正确做法是位数取自第二个数 `b`，`len(str(20)) = 2`，得 `9*100+20 = 920`。
2. 输入 `nums = [1000,1]` → 若用 `while b: b //= 10` 数位数，`b=1` 时循环只跑一次得 1 位没问题，但若 `b` 被写成 0 的变体（题面 `nums[i] >= 1` 不会出现，但若放宽约束）会得 0 位、乘 `10**0=1`，拼成 `1000*1+0`；正确做法是直接用 `len(str(b))`，对任意正整数都稳。

## 如果面试官追问
问：如果允许任意两两配对（不固定相邻），怎么求最小？
答：合并值大小主要由拼接后的位数决定，位数固定时再比字典序，可先按位数分组再贪心配对，复杂度升到 O(n log n)。
