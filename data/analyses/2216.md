## 一句话思路
用栈维护已确定的美丽前缀，栈长为偶数且新元素等于栈顶时删掉新元素，否则入栈。

## 怎么做
1. 维护一个栈 `st`，它始终是「已处理部分能构成的最长美丽前缀」，长度偶数时下一个元素要当偶数位，长度奇数时当奇数位。
2. 遍历 `nums` 的每个 `x`：若 `len(st) % 2 == 1` 且 `st[-1] == x`，说明这一对会相等，必须删掉 `x`（删栈顶那个也行，但删 `x` 更省事，因为栈顶已经固定）。
3. 否则 `st.append(x)`。
4. 最后若 `len(st)` 是奇数，还得再删一个（末尾那个），答案是 `len(nums) - len(st) + len(st) % 2`。

拿示例 2 `nums = [1,1,2,2,3,3]` 走一遍：`x=1` 入栈 `[1]`；`x=1` 时栈长 1 为奇且 `st[-1]==1`，删掉，栈仍 `[1]`；`x=2` 入栈 `[1,2]`；`x=2` 时栈长 2 为偶，不触发，入栈 `[1,2,2]`；`x=3` 时栈长 3 为奇且 `st[-1]==2 != 3`，入栈 `[1,2,2,3]`；`x=3` 时栈长 4 为偶，入栈 `[1,2,2,3,3]`。最终栈长 5 为奇，答案 `6 - 5 + 1 = 2`。

```python
st = []
for x in nums:
    if len(st) % 2 == 1 and st[-1] == x:
        continue          # 删掉 x
    st.append(x)
return len(nums) - len(st) + len(st) % 2
```

关键点：栈长奇偶决定「当前 x 是配对位还是被配对位」，只有栈长为奇（即 `st[-1]` 处于偶数下标）时才可能冲突。

## 复杂度
时间 O(n)：每个 `nums` 元素最多入栈一次、被跳过一次。
空间 O(n)：`st` 最坏存下全部元素。

## 易错点
- 输入 `[1,1,1]`：若只在 `st[-1]==x` 时删栈顶而不看栈长奇偶，会把 `[1]` 和第二个 `1` 误判成冲突对，实际第二个 `1` 处于奇数下标、无需比较；正确做法是先判 `len(st) % 2 == 1`。
- 输入 `[1,2,3]`（本身无相邻相等）：若忘记最后补 `len(st) % 2`，会返回 0，但长度 3 是奇数、不是美丽数组，正确答案是 1；必须加上末尾奇偶修正。

## 如果面试官追问
要求输出具体删除的下标方案怎么办？答：遍历时记录被 `continue` 跳过的下标，末尾若栈长为奇再补删原数组最后一个未被删元素的下标。
