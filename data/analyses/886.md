## 一句话思路
把 dislikes 建成无向图，用二染色 DFS 判二分图；冲突即返回 False。

## 怎么做
1. 建邻接表 `g = [[] for _ in range(n+1)]`，对每条 `[a,b]` 双向加边。
2. `color` 数组初始 0，1/2 表示两组；遍历 1..n，未染色的点从 1 开始 DFS。
3. DFS 中把邻居染成 `3 - color[u]`，若邻居已染色且等于 `color[u]` 则冲突。

以示例 2 `n=3, dislikes=[[1,2],[1,3],[2,3]]` 为例：从 1 染 1，邻居 2、3 染 2；访问 2 时邻居 3 已是 2，与 `3 - color[2] = 1` 不符，返回 False。

```python
def dfs(u, c):
    color[u] = c
    for v in g[u]:
        if color[v] == c:
            return False
        if color[v] == 0 and not dfs(v, 3 - c):
            return False
    return True

for i in range(1, n + 1):
    if color[i] == 0 and not dfs(i, 1):
        return False
return True
```

注意图可能不连通（如 n=4 但只有 `[[1,2]]`），所以外层必须循环所有点，不能只从 1 出发。

## 复杂度
时间 O(n + m)，m = len(dislikes)，每条边访问两次。
空间 O(n + m)，邻接表存 2m 条边，color 长 n+1，递归栈最深 n。

## 易错点
- 输入 `n=1, dislikes=[]` → 若外层只写 `dfs(1,1)` 后直接返回 True 尚可，但若漏掉循环、只处理有边的点，遇到孤立点会漏判；正确做法是 `for i in range(1, n+1)` 全扫。
- 输入 `dislikes=[[1,2],[2,1]]` 这类对称边（题面保证 `a<b` 且不重复，但自测时易造）→ 邻接表里同一对出现两次，DFS 会重复访问但不会误判；真正会翻车的是把 `color[v] == c` 写成 `color[v] != 0`，那样任何已染色邻居都判冲突，示例 1 会错成 False。

## 如果面试官追问
要求输出具体分组方案怎么办？答：DFS 结束后按 `color[i]` 收集，1 进 group1、2 进 group2，孤立点随意归组。
