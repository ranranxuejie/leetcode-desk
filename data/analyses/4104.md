## 一句话思路
双指针滑窗：对每个右端点 r，维护最小的左端点 l 使 s[l..r] 不含 "abc" 子序列，累加 r-l+1。

## 怎么做
1. 关键观察：子串含 "abc" 子序列，当且仅当存在 a 在 b 前、b 在 c 前。窗口右扩时，只需记录窗口内"已匹配到 ab 的最早 b 位置"。
2. 用 `last_a` 记窗口内最靠左的 a 下标，`ab_end` 记窗口内能形成 "ab" 的最小 b 下标（即 `last_a` 之后第一个 b）。
3. 遇到 c 时，若 `ab_end` 存在，则 l 必须移到 `last_a + 1`，同时重置 `last_a`、`ab_end` 为窗口内剩余部分的值。
4. 每步累加 `r - l + 1`。

以 s = "abac" 为例：r=0 'a'，last_a=0，ans+=1；r=1 'b'，ab_end=1，ans+=2；r=2 'a'，last_a=2，ans+=3；r=3 'c'，ab_end=1 存在，l 移到 1，ans+=3，累计 9。

```python
l = 0
last_a = -1
ab_end = -1
ans = 0
for r, ch in enumerate(s):
    if ch == 'a':
        last_a = r
    elif ch == 'b':
        if last_a >= l:
            ab_end = r
    else:  # 'c'
        if ab_end >= l:
            l = last_a + 1
            last_a = ab_end = -1
            # 需重新扫描 [l, r] 恢复 last_a/ab_end
    ans += r - l + 1
```

注意第 3 步重置后要重扫窗口，实际实现可改用"记录每个位置之前最近的 a 和 ab 结束位置"的预处理数组，避免重扫。

## 复杂度
时间 O(n)：每个字符至多被左右指针各扫一次。
空间 O(1)：只存 l、last_a、ab_end、ans 四个变量。

## 易错点
- 输入 s = "aabc"：若在遇到第一个 c 时只把 l 移到 `last_a+1` 而不重扫窗口，会漏掉窗口内第二个 a 与 b 组成的 "ab"，导致后续 c 判断失效。正确做法是重置后重新扫描 `[l, r]` 恢复 `last_a` 和 `ab_end`。
- 输入 s = "abcabc"：若用 `ab_end` 记录"任意 b"而非"last_a 之后第一个 b"，会把 "bc" 误判为含 "abc"。正确做法是只在 `last_a >= l` 时才更新 `ab_end`。

## 如果面试官追问
若要求输出所有有效子串而非计数？答：滑窗仍成立，对每个 r 枚举 l 从当前左界到 r，输出 s[l..r]，总输出量即答案规模。
