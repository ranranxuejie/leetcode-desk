## 一句话思路
DFS 从根往下走，用 `path` 累积节点值，到叶子时把 `"->".join(path)` 收进结果。

## 怎么做
1. 空树直接返回 `[]`，否则从 `root` 和 `path=[str(root.val)]` 开始递归。
2. 判断叶子：`not node.left and not node.right`，此时把 `"->".join(path)` 追加到 `res`。
3. 否则对每个存在的子节点，先 `path.append(str(child.val))`，递归后 `path.pop()` 回溯。
4. 用官方示例 `root = [1,2,3,null,5]` 走一遍：到节点 5 时 `path = ["1","2","5"]`，`join` 得 `"1->2->5"`；回溯 `pop` 掉 `"5"` 后 `path` 回到 `["1","2"]`，再回到 `["1"]`，走右子树 3 得 `"1->3"`。

```python
def dfs(node, path):
    if not node.left and not node.right:
        res.append("->".join(path))
        return
    for child in (node.left, node.right):
        if child:
            path.append(str(child.val))
            dfs(child, path)
            path.pop()
```

关键点：`path` 存的是 `str(val)`，因为 `join` 只接受字符串；节点值可能是负数（如 `-100`），`str(-100)` 直接可用，不需要额外处理。

## 复杂度
时间 O(n·h)：n 个节点，每个叶子拼接路径长度最多 h，最坏 O(n²)。
空间 O(h)：递归栈深度 h，`path` 也占 h，结果列表不计入。

## 易错点
- 输入 `root = [1]`（单节点即叶子）→ 若先判断 `node.left` 再判断叶子，会漏掉根节点这条路径 → 必须先判叶子再递归子节点，保证单节点树返回 `["1"]`。
- 输入 `[1,2,3,null,5]` → 若 `path.append` 后忘记 `path.pop()`，走完 `1->2->5` 再进右子树 3 时 `path` 残留 `["1","2","5"]`，输出变成 `"1->2->5->3"` → 递归返回后必须 `pop`，让 `path` 恢复到进入该子树前的状态。

## 如果面试官追问
问：节点数放大到 10^5 且要求 O(n) 总时间怎么办？
答：改用迭代 + 显式栈存 `(node, path_str)`，每个节点只拼一次字符串，避免重复 join。
