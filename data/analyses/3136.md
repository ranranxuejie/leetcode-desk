## 一句话思路
一次遍历同时统计长度、非法字符、元音、辅音四个标志，任一条件不满足即返回 `False`。

## 怎么做
1. 先判 `len(word) < 3`，直接返回 `False`。
2. 用 `set("aeiouAEIOU")` 做元音表，遍历每个字符 `c`。
3. 对每个 `c`：非字母非数字则置 `bad = True`；是元音置 `has_v = True`；是字母且非元音置 `has_c = True`。
4. 遍历结束返回 `not bad and has_v and has_c`。

以 `"234Adas"` 为例：`'2'`、`'3'`、`'4'` 是数字，跳过字母判断；`'A'` 命中元音表使 `has_v = True`；`'d'` 是字母且不在元音表，使 `has_c = True`；最终 `bad = False`，三个标志齐备返回 `True`。

```python
vowels = set("aeiouAEIOU")
bad = has_v = has_c = False
for c in word:
    if c.isdigit():
        continue
    if c.isalpha():
        if c in vowels:
            has_v = True
        else:
            has_c = True
    else:
        bad = True
return not bad and has_v and has_c
```

注意 `c.isalpha()` 对 `'@'`、`'#'`、`'$'` 返回 `False`，所以它们会落到 `else` 分支置 `bad`，这正是示例 3 中 `'$'` 被抓住的路径。

## 复杂度
时间：O(n)，n 为 `word` 长度，每个字符只查一次表。
空间：O(1)，元音表固定 10 个字符，只开了三个布尔标志。

## 易错点
- 输入 `"b3"` → 若只判长度和元音，会漏掉「没有元音」而错判；正确做法是长度不足 3 时直接返回 `False`，不要继续走标志判断。
- 输入 `"a3$e"` → 若把 `'$'` 当成普通字符跳过，会因 `has_c` 为 `False` 返回 `False`，看似答案对但理由错；正确做法是显式置 `bad = True`，保证非法字符独立拦截。
- 输入 `"AB1"` → 若元音表只写小写 `"aeiou"`，`'A'` 会被误判为辅音使 `has_c = True`，但实际 `has_v` 应为 `True`；正确做法是元音表同时含大写。

## 如果面试官追问
问：若要求返回第一个不满足的条件名而非布尔值？
答：把四个标志改成按顺序检查并返回对应字符串，遍历时记录首个失败原因即可。
