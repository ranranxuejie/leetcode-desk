## 一句话思路
每个长方体先内部排序成 `a≤b≤c`，整体按 `(a,b,c)` 升序排，再做最长上升子序列式的 DP，`dp[i]` 是以 i 为顶的最大高度。

## 怎么做
1. 每个 `cuboids[i]` 原地 `sort()`，得到 `a≤b≤c`，此时 `c` 是唯一值得当高的边（把最长边当高，底面才最小，最容易被托住）。
2. 对全部三元组按字典序升序排序，保证「能叠在下面的」一定排在前面。
3. `dp[i] = c_i + max(dp[j])`，`j<i` 且 `a_j≤a_i and b_j≤b_i and c_j≤c_i`，无解则 `dp[i]=c_i`。
4. 返回 `max(dp)`。

以示例 1 为例：排序后三个长方体变成 `[20,45,50]`、`[37,53,95]`、`[12,23,45]`，整体排序为 `[12,23,45]`、`[20,45,50]`、`[37,53,95]`。算到 `[37,53,95]` 时，`[20,45,50]` 的 `20≤37、45≤53、50≤95` 成立，`dp = 45+50+95 = 190`。

```python
cuboids = [sorted(c) for c in cuboids]
cuboids.sort()
n = len(cuboids)
dp = [0] * n
for i in range(n):
    a, b, c = cuboids[i]
    dp[i] = c
    for j in range(i):
        aj, bj, cj = cuboids[j]
        if aj <= a and bj <= b and cj <= c:
            dp[i] = max(dp[i], dp[j] + c)
return max(dp)
```

注意 `dp[i]` 初值必须是 `c` 而不是 0，否则单个长方体（示例 2 的 `[76,35,3]` 排序成 `[3,35,76]`）会返回 0。

## 复杂度
时间：`O(n²)`，双重循环比较每对长方体；排序的 `O(n log n)` 被它吞掉。
空间：`O(n)`，只有 `dp` 数组，排序是原地或 `O(n)` 辅助。

## 易错点
- 输入 `[[38,25,45],[76,35,3]]` → 若只按原始 `height` 当高、不排序内部三边，会认为无法堆叠且高度取 45 或 3，错成 45；正确做法是每个长方体先 `sort()`，取 `[3,35,76]` 的 76 当高，答案 76。
- 输入 `[[7,11,17]]*6`（示例 3 的六种排列）→ 若比较时用严格 `<` 而非 `≤`，六个相同长方体互相叠不上，错成 17；正确做法是三个维度都用 `≤`，因为旋转后尺寸相同的长方体可以叠，答案 102。

## 如果面试官追问
问：n 放大到 10⁵ 怎么办？答：这题本质是三维偏序上的最长链，`O(n²)` 的 DP 换成 CDQ 分治或树状数组维护 `(a,b)` 二维前缀最大值，可降到 `O(n log² n)`。
