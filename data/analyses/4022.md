## 一句话思路
按块长累加定位 k 落在哪个块，再在块内按奇偶定序定位到具体数字和数位。

## 怎么做
1. 块 b 覆盖 `10*b` 到 `10*b+9`，共 10 个整数，每个数位数相同（b=0 时是 1~9，特判）。先按位数分段：d 位数对应 b 从 `10**(d-1)//10` 到 `10**d//10 - 1`，每块长度 `10*d`，整段长度 `10*d*块数`。
2. 用循环从 d=1 起减，找到 k 落在哪个位数段、段内第几个块、块内第几个字符。
3. 块内偏移 `off`（0 起），b 偶数时数字是 `10*b + off//d`，b 奇数时是 `10*b + 9 - off//d`；数位是 `str(num)[off % d]`。
4. 特判 b=0：前 9 位直接是 k 本身。

以 k=15 为例：d=1 段长 9（b=0），k 减为 6；d=2 段 b=1..9 共 9 块、每块 20，6 落在 b=1、off=5。b 奇数，num = `10*1+9-5//2` = 17，数位 `str(17)[5%2]` = `'7'`，与示例一致。

```python
def kthDigit(k):
    if k <= 9:
        return k
    k -= 9
    d = 2
    while True:
        blocks = 9 * 10**(d-2)          # b 从 10**(d-2) 到 10**(d-1)-1
        seg = blocks * 10 * d
        if k <= seg:
            break
        k -= seg
        d += 1
    b = 10**(d-2) + (k - 1) // (10 * d)
    off = (k - 1) % (10 * d)
    num = 10*b + off//d if b % 2 == 0 else 10*b + 9 - off//d
    return int(str(num)[off % d])
```

## 复杂度
时间：O(log k)，位数 d 最多到 16，循环次数即 d。
空间：O(1)，只用了 k、d、b、off、num 几个整数。

## 易错点
- k=10 时若漏掉 b=0 特判，会把它当成 d=1 段里 b=1 的块，算出 1 而不是 9；正确做法是 `k <= 9` 直接返回 k，再 `k -= 9` 进入 d≥2 的循环。
- b 的奇偶判断用 `b % 2`，若误用 `d % 2` 或 `(b+1) % 2`，k=15 会算成 num=12、返回 `'2'`；正确做法是严格按块号 b 判断，b 偶数递增、奇数递减。

## 如果面试官追问
若 k 上限提到 10^18 甚至更大？答：循环仍只跑到 d≈18，O(log k) 不变，Python 大整数直接算，无需改结构。
