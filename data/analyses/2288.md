## 一句话思路
按空格切词，用 `word[0] == '$' and word[1:].isdigit()` 判定价格，再格式化回两位小数。

## 怎么做
1. 用 `sentence.split(' ')` 切词，保留空串风险为零（题面保证单空格分隔）。
2. 对每个词判断：首字符是 `$` 且剩余部分全为数字，才是价格。
3. 价格用 `int(word[1:]) * (100 - discount) / 100` 计算，`f"{x:.2f}"` 格式化。
4. 用 `' '.join(...)` 拼回。

以示例 1 的 `"$1"` 为例：`word[1:]` 是 `"1"`，`isdigit()` 为 `True`，`1 * 50 / 100 = 0.5`，格式化为 `"0.50"`，拼成 `"$0.50"`。而 `"5$"` 首字符不是 `$`，直接跳过。

```python
def discountPrices(sentence, discount):
    res = []
    for w in sentence.split(' '):
        if w[0] == '$' and w[1:].isdigit():
            price = int(w[1:]) * (100 - discount) / 100
            res.append(f"${price:.2f}")
        else:
            res.append(w)
    return ' '.join(res)
```

关键点：`w[1:].isdigit()` 对空串返回 `False`，所以单独的 `"$"` 不会被误判；`"$1e5"` 含字母 `e`，`isdigit()` 为 `False`，也正确排除。

## 复杂度
时间 O(n)：n 为 `sentence` 长度，每个字符被扫描常数次。
空间 O(n)：`res` 列表和 `join` 结果各占 O(n)。

## 易错点
- 输入 `"$10$"` → 若只判断 `w[0] == '$'` 就替换，会错成 `"$5.00$"`；正确做法是 `w[1:].isdigit()` 必须为 `True`，`"10$"` 含 `$` 不是数字，保持原样。
- 输入 `discount = 100` 且 `"$3"` → 若用 `int` 截断或 `round` 处理，可能得到 `"$0"` 或 `"$0.0"`；正确做法是 `f"{0.0:.2f}"` 固定输出 `"$0.00"`，且 `3 * 0 / 100 = 0.0` 不丢精度。

## 如果面试官追问
若价格上限从 10 位放宽到 10^5 位数字怎么办？答：改用字符串模拟大数乘 `(100 - discount)` 再除 100，避免 `int` 转换。
