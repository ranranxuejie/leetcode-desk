## 一句话思路
用 Counter 统计每个字符频次，再按频次分桶，取桶内字符数最多（并列取频次大）的那一桶。

## 怎么做
1. 用 `Counter(s)` 得到每个字符的出现次数 `cnt`。
2. 建字典 `groups`，键是频次 k，值是该频次下的字符列表，遍历 `cnt` 填入。
3. 遍历 `groups`，按 `(len(chars), k)` 取最大，返回该列表拼成的字符串。

以 `s = "pfpfgi"` 为例：`cnt = {p:2, f:2, g:1, i:1}`，分桶后 `groups = {2:['p','f'], 1:['g','i']}`。两个桶大小都是 2，比较元组 `(2,2)` 与 `(2,1)`，前者大，所以选 k=2 的桶，输出 `"pf"`（顺序不限）。

```python
from collections import Counter

cnt = Counter(s)
groups = {}
for ch, k in cnt.items():
    groups.setdefault(k, []).append(ch)

best_k = max(groups, key=lambda k: (len(groups[k]), k))
return "".join(groups[best_k])
```

关键在 `key=lambda k: (len(groups[k]), k)`：元组比较先比组大小，再比 k，正好对应题目的两级规则，不用写 if-else 分支。

## 复杂度
时间 O(n + 26)，n 是 s 长度，统计频次扫一遍，分桶和选桶只涉及至多 26 个字符。
空间 O(26)，`cnt` 和 `groups` 都只存小写字母，与 n 无关。

## 易错点
- 输入 `"pfpfgi"` → 只按组大小取最大，会在 k=2 和 k=1 之间随便挑一个（字典序或插入序），可能输出 `"gi"` → 必须用 `(len(groups[k]), k)` 元组比较，让并列时落到更大的 k。
- 输入 `"abcd"` → 误以为要返回出现次数最多的字符（这里全是 1 次），或误以为众数频率组只含一个字符 → 正确理解是「组内不同字符数最多」，四个字符同属 k=1 的组，应全部返回 `"abcd"`。

## 如果面试官追问
问：如果 s 长度到 10^6 且字符集扩到全部 Unicode，怎么改？
答：Counter 和分桶逻辑不变，只是空间从 O(26) 变成 O(不同字符数)，仍是一遍扫描。
