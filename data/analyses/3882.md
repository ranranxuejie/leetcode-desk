## 一句话思路
用集合 DP 按格维护「到达该格所有可能的异或值」，因为值域只有 0~1023，集合规模被 1024 封顶。

## 怎么做
1. 每个格子维护一个集合 `dp[i][j]`，存从 (0,0) 走到 (i,j) 所有路径的异或值。
2. 转移：`dp[i][j] = {v ^ grid[i][j] for v in dp[i-1][j] | dp[i][j-1]}`，起点单独初始化。
3. 用滚动数组压成一维，只保留上一行；每格先合并「上方集合」和「左方集合」再异或。
4. 答案取 `dp[n-1]` 里的最小值。

以 `grid = [[1,2],[3,4]]` 为例：`dp[0]` 初始 `{1}`，处理 (0,1) 得 `{1^2}={3}`；处理 (1,0) 时上方是 `{1}`、左方为空，得 `{1^3}={2}`；处理 (1,1) 时上方 `{3}`、左方 `{2}` 合并为 `{2,3}`，各自异或 4 得 `{6,7}`，取 min 为 6，与示例一致。

```python
m, n = len(grid), len(grid[0])
dp = [set() for _ in range(n)]
for i in range(m):
    for j in range(n):
        if i == 0 and j == 0:
            dp[0] = {grid[0][0]}
            continue
        s = set()
        if i > 0: s |= dp[j]
        if j > 0: s |= dp[j-1]
        dp[j] = {v ^ grid[i][j] for v in s}
return min(dp[n-1])
```

## 复杂度
时间：O(m·n·1024)，每格集合最多 1024 个值，各做一次异或。
空间：O(n·1024)，滚动数组只留 n 列，每列一个集合。

## 易错点
- `grid = [[2,7,5]]` 这种单行输入 → 若只写 `if i > 0` 取上方、忘了 `j > 0` 取左方，dp[1] 会变成空集、最终 `min` 报错 → 两个方向都要判，且起点 `(0,0)` 必须单独初始化，不能靠合并空集得到。
- 值域 0~1023 意味着异或结果不会超过 1023，但若用「只保留当前最小值」的贪心 → 在 `[[6,7],[5,8]]` 上会先取 6^7=1 再 ^8=9，看似对；换成需要保留多个候选的输入就会漏解 → 必须保留整个集合，不能只留 min。

## 如果面试官追问
问：若 m·n 放大到 10^5 怎么办？
答：集合上界仍是 1024，复杂度 O(m·n·1024) 不变，只需把滚动数组换成按行复用，空间仍是 O(n·1024)。
