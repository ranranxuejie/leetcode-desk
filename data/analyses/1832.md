## 一句话思路
用 26 位掩码记录出现过的字母，遍历完 `sentence` 后掩码等于 `(1<<26)-1` 即为全字母句。

## 怎么做
1. 初始化 `mask = 0`，表示还没有任何字母出现。
2. 遍历 `sentence` 的每个字符 `ch`，把 `ord(ch) - ord('a')` 对应的位用 `mask |= 1 << (ord(ch) - ord('a'))` 置 1。
3. 遍历结束后判断 `mask == (1 << 26) - 1`，相等返回 `True`，否则 `False`。

拿示例 1 的 `"thequickbrownfoxjumpsoverthelazydog"` 说：前 7 个字符 `t h e q u i c` 依次把第 19、7、4、16、20、8、2 位置 1，此时 `mask` 的二进制低 26 位里这 7 位是 1；继续扫完整个串，26 位全部被置 1，`mask` 恰好等于 `67108863`（即 `(1<<26)-1`），返回 `True`。

```python
mask = 0
for ch in sentence:
    mask |= 1 << (ord(ch) - ord('a'))
    if mask == (1 << 26) - 1:
        return True
return False
```

提前返回是可选的优化：一旦 26 位齐了就没必要再扫，示例 1 会在扫到最后一个 `g` 时命中。

## 复杂度
时间 O(n)：n 为 `sentence` 长度，每个字符做一次移位和或运算。
空间 O(1)：只开了一个整数 `mask`，与 n 无关。

## 易错点
- 输入 `"leetcode"` → 若只判断「出现过 26 种不同字符」而不校验范围，会误以为字符种类够多就返回 `True`；本题限定小写字母，直接用 `ord(ch)-ord('a')` 做位下标即可，不需要额外去重集合。
- 输入长度恰好 26 但含重复字母（如 `"a"*26`）→ 若用 `len(set(sentence)) == 26` 之外的写法却漏了「至少一次」的语义，容易把重复当覆盖；正确做法是掩码必须 26 位全 1，`"a"*26` 的 `mask` 只有第 0 位是 1，返回 `False`。

## 如果面试官追问
问：若字符集扩展到大小写加数字共 62 个，怎么做？答：把 `(1<<26)-1` 换成 `(1<<62)-1`，下标映射改成先判断大小写再偏移，Python 整数天然支持 62 位掩码。
