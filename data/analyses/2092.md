## 一句话思路
按时间分组处理会议，每组内用并查集把同时间连通的专家合并，再只保留含知情者的连通块，避免同时间传递顺序问题。

## 怎么做
1. 把 `meetings` 按 `time` 排序，再按时间切成若干组，同组会议时间相同。
2. 每组内建一个临时并查集，只把该组会议涉及的专家 `union` 起来。
3. 组内合并完后，遍历该组出现的专家，若其根节点所在集合含知情者，则把整个集合标记为知情。
4. 清空临时并查集，处理下一组。

以示例 3 为例：`meetings = [[3,4,2],[1,2,1],[2,3,1]]`，`firstPerson = 1`。时间 1 的组有 `[1,2]` 和 `[2,3]`，组内合并后 `{1,2,3}` 连通，因 1 已知情，整块标记知情；时间 2 的组 `[3,4]` 中 3 已知情，4 也被标记。最终 `[0,1,2,3,4]`。

```python
meetings.sort(key=lambda m: m[2])
i = 0
while i < len(meetings):
    j = i
    parent = {}
    def find(x):
        parent.setdefault(x, x)
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    while j < len(meetings) and meetings[j][2] == meetings[i][2]:
        a, b, _ = meetings[j]
        parent[find(a)] = find(b)
        j += 1
    for x in list(parent):
        if find(x) in secret_roots:
            secret_roots.add(find(x))
    i = j
```

## 复杂度
时间：排序 `O(m log m)`，并查集近似 `O(m α(n))`，`m = len(meetings)`。
空间：`O(n)` 存并查集和知情标记，`n` 为专家数。

## 易错点
1. 同一时间有多场会议且形成链 `[1,2,t]`、`[2,3,t]` → 若按顺序逐场传播，可能 2 先不知情导致 3 漏标 → 必须先把同时间所有会议合并成连通块，再统一判断是否含知情者。
2. 专家 0 和 `firstPerson` 初始就知情 → 若只标记 `firstPerson` 而漏掉 0，示例 2 中 0 会被错误排除 → 初始化时同时把 0 和 `firstPerson` 加入知情集合。

## 如果面试官追问
若要求输出每个专家首次知晓秘密的时间？答：在并查集合并后记录该连通块最早知情时间，传播时取 `min` 更新即可。
