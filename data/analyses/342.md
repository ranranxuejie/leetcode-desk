## 一句话思路
用 `n > 0 and n & (n-1) == 0 and n & 0x55555555` 一次判定：2 的幂且 1 的位落在偶数位上。

## 怎么做
1. 先排除 `n <= 0`，负数与 0 都不可能是 4 的幂。
2. 用 `n & (n-1) == 0` 判断是否为 2 的幂，4 的幂必然是 2 的幂。
3. 再用掩码 `0x55555555`（二进制 0101…0101，共 32 位）与 `n` 相与，非零说明唯一的 1 落在偶数位（第 0、2、4…位），即指数为偶数。
4. 三步全真返回 `True`，否则 `False`。

以 `n = 16` 为例：`16 & 15 = 0`，是 2 的幂；`16` 的二进制是 `10000`，1 在第 4 位（偶数位），`16 & 0x55555555 = 16 != 0`，返回 `True`。若 `n = 8`，`8 & 7 = 0` 通过第二步，但 `8 & 0x55555555 = 0`，第三步拦下，返回 `False`——这正是 2 的幂但不是 4 的幂的典型。

```python
def isPowerOfFour(n):
    if n <= 0:
        return False
    if n & (n - 1) != 0:
        return False
    return (n & 0x55555555) != 0
```

掩码为什么是 32 位：题目范围 `-2**31 <= n <= 2**31 - 1`，正数最大 `2**31 - 1`，最高位是第 30 位（偶数位），`0x55555555` 恰好覆盖第 0 到第 30 的所有偶数位，够用。

## 复杂度
时间：O(1)，三次位运算，与 n 大小无关。
空间：O(1)，只用了掩码常量，无额外数组或递归栈。

## 易错点
- 输入 `n = 0` 或负数（如 `n = -4`）→ 若漏掉 `n <= 0` 判断，`0 & -1 == 0` 会让 0 误判为真，负数在 Python 里位运算结果也可能骗过掩码 → 正确做法是第一步就 `return False`。
- 输入 `n = 8` 或 `n = 2` → 只用 `n & (n-1) == 0` 会误判为 `True`，因为它们是指数为奇数的 2 的幂 → 必须加 `n & 0x55555555` 这一步把奇数位上的 1 筛掉。

## 如果面试官追问
问：不用掩码常量，怎么判偶数位？
答：`n % 3 == 1`，因为 4 ≡ 1 (mod 3)，4 的幂模 3 恒为 1，而 2 的奇数次幂模 3 为 2。
