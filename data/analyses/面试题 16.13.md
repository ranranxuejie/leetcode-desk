## 一句话思路
两正方形中心连线的中点必在所求直线上，直线绕该点旋转取斜率最大者，即过两点中心、斜率无穷大时取竖直。

## 怎么做
1. 算两正方形中心 `c1=(x1+s1/2, y1+s1/2)`、`c2=(x2+s2/2, y2+s2/2)`；平分线必过各自中心，故必过 `c1c2` 中点 `m`。
2. 斜率最大：若 `c1.x == c2.x`，直线竖直 `x=m.x`，直接与两正方形求交；否则取过 `c1`、`c2` 的直线（斜率最大那条），即 `m` 与 `c1` 连线方向。
3. 用参数式 `p = m + t*d`（`d = c2 - c1`），对每个正方形求 `t` 的进入/离开区间，取 4 个交点。
4. 4 点中取距离最远的两点，按 `x` 升序（相等则 `y` 升序）输出。

以官方示例 `square1={-1,-1,2}`、`square2={0,-1,2}`：`c1=(0,0)`、`c2=(1,0)`，`m=(0.5,0)`，`d=(1,0)`，直线 `y=0`。与 square1 交 `x∈[-1,1]`，与 square2 交 `x∈[0,2]`，最远两点 `(-1,0)`、`(2,0)`。

```python
def cut(c1, c2, s1, s2):
    m = ((c1[0]+c2[0])/2, (c1[1]+c2[1])/2)
    if c1[0] == c2[0]:
        d = (0.0, 1.0)
    else:
        d = (c2[0]-c1[0], c2[1]-c1[1])
    pts = []
    for (cx, cy), s in ((c1, s1), (c2, s2)):
        lo, hi = -1e18, 1e18
        for axis in (0, 1):
            if abs(d[axis]) < 1e-12:
                continue
            a = (cx - s/2 - m[axis]) / d[axis]
            b = (cx + s/2 - m[axis]) / d[axis]
            lo, hi = max(lo, min(a, b)), min(hi, max(a, b))
        pts += [(m[0]+lo*d[0], m[1]+lo*d[1]), (m[0]+hi*d[0], m[1]+hi*d[1])]
    pts.sort()
    return [pts[0][0], pts[0][1], pts[-1][0], pts[-1][1]]
```

## 复杂度
时间 O(1)：固定 2 个正方形、每边 2 次求交，无 n。
空间 O(1)：只存 4 个交点。

## 易错点
- `c1.x == c2.x`（如 `{-1,-1,2}` 与 `{-1,1,2}`）→ 若仍用 `d=(0, dy)` 求交，`d[0]=0` 时区间约束失效得 `lo=-1e18`，端点飞出正方形 → 竖直情形单独令 `d=(0,1)` 并跳过 `x` 轴约束。
- 两正方形同心（`c1==c2`）→ `d=(0,0)` 使所有 `t` 无定义，返回 NaN → 此时任取过中心的直线，按题目取斜率最大即竖直 `x=c1.x`，需在 `d` 计算前判 `c1==c2`。

## 如果面试官追问
若要求返回直线方程而非端点？答：仍先定 `m` 与 `d`，输出 `(d.y, -d.x, d.x*m.y - d.y*m.x)` 的 `Ax+By+C=0`，竖直时 `A=1,B=0,C=-m.x`。
