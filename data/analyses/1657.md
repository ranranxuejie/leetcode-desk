## 一句话思路
两个字符串的字符集合必须相同，且字符频次的多重集合必须相同——操作 1 任意重排、操作 2 互换频次，恰好对应这两个不变量。

## 怎么做
1. 长度不同直接返回 `False`，因为两种操作都不改变字符总数。
2. 用 `Counter` 分别统计 `word1`、`word2`，比较两者的键集合（字符种类）是否相等。
3. 比较两个 `Counter` 的 `values()` 排序后是否相等，即频次多重集是否一致。

以示例 3 为例：`word1 = "cabbba"` 得到 `{'c':1,'a':2,'b':3}`，`word2 = "abbccc"` 得到 `{'a':1,'b':2,'c':3}`。键集合都是 `{a,b,c}` 相等；排序后频次都是 `[1,2,3]`，返回 `True`。注意频次是**按值排序**而非按字符对齐——`c` 在 word1 里是 1 次、在 word2 里是 3 次，但通过操作 2 可以把 `c` 和 `a` 整体互换，所以对齐无意义。

```python
from collections import Counter

c1, c2 = Counter(word1), Counter(word2)
if len(word1) != len(word2):
    return False
if set(c1) != set(c2):
    return False
return sorted(c1.values()) == sorted(c2.values())
```

关键点：`set(c1)` 比的是**出现过哪些字符**，`sorted(values())` 比的是**频次分布**。两者缺一不可。

## 复杂度
时间：O(n + m + 26 log 26)，n、m 为两串长度，扫描计数主导，排序只对 ≤26 个频次。
空间：O(26)，两个 Counter 各存至多 26 个小写字母的计数。

## 易错点
- 输入 `word1="a", word2="aa"` → 若只比字符集合 `{a}=={a}` 会错判 `True` → 必须先比长度，或让频次排序比较兜住（`[1]` vs `[2]` 不等）。
- 输入 `word1="abc", word2="xyz"` → 若只比频次排序 `[1,1,1]==[1,1,1]` 会错判 `True` → 必须额外校验字符集合相同，因为操作 2 只能在**已有字符**之间转换，不能凭空造出 `x`。

## 如果面试官追问
问：若字符集扩到 Unicode、长度到 10^7 怎么办？
答：把 26 换成哈希表存键，排序改为对频次做计数排序或直接比较频次直方图，时间仍是 O(n)。
