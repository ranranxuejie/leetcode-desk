## 一句话思路
把两条线的连线看成公共子序列，不相交等价于下标同时递增，所以就是求 LCS 长度。

## 怎么做
1. 定义 `dp[i][j]` 为 `nums1[:i]` 与 `nums2[:j]` 的最大连线数，多开一行一列放 0 处理空前缀。
2. 若 `nums1[i-1] == nums2[j-1]`，这条线一定可以画，`dp[i][j] = dp[i-1][j-1] + 1`。
3. 否则这条线画不成，退一步取 `max(dp[i-1][j], dp[i][j-1])`。
4. 按 i 外层、j 内层填表，答案在 `dp[m][n]`。

以示例 1 的 `nums1=[1,4,2]`、`nums2=[1,2,4]` 为例，填到 `i=2, j=2` 时 `nums1[1]=4 != nums2[1]=2`，取 `max(dp[1][2], dp[2][1]) = max(1,1) = 1`；到 `i=3, j=3` 时 `2 != 4`，取 `max(dp[2][3], dp[3][2]) = max(2,1) = 2`，即答案。

```python
m, n = len(nums1), len(nums2)
dp = [[0] * (n + 1) for _ in range(m + 1)]
for i in range(1, m + 1):
    for j in range(1, n + 1):
        if nums1[i - 1] == nums2[j - 1]:
            dp[i][j] = dp[i - 1][j - 1] + 1
        else:
            dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
return dp[m][n]
```

## 复杂度
时间 O(m·n)：m、n 分别是 `nums1`、`nums2` 长度，双重循环各走一遍。
空间 O(m·n)：开了 (m+1)×(n+1) 的 `dp` 表，可滚动成一维 O(n)。

## 易错点
- 把 `nums1[i-1] == nums2[j-1]` 写成 `nums1[i] == nums2[j]`：示例 1 中 i=1 会去取 `nums1[1]=4` 与 `nums2[1]=2` 比较，首行首列全错，答案变 1。正确做法是 dp 下标比数组下标大 1，比较时统一减 1。
- 相等时误写成 `max(dp[i-1][j], dp[i][j-1]) + 1`：示例 2 中 `nums1[1]=5` 与 `nums2[1]=5` 匹配时，会多算一条本不存在的线，答案从 3 变 4。相等时只能接 `dp[i-1][j-1]`，因为两条线不能共用端点。

## 如果面试官追问
问：只要求返回最大连线数，能否把空间压到 O(n)？
答：可以，内层 j 从 1 到 n 正序更新一维 `dp`，用变量 `prev` 暂存旧 `dp[j-1]` 即可，注意别覆盖。
