## 一句话思路
对每个数对算「改 0 次 / 改 1 次」能覆盖的 X 区间，用差分数组求每个 X 的总改动数，取最小。

## 怎么做
1. 遍历 `i < n//2`，取 `a = nums[i]`、`b = nums[n-1-i]`，令 `d = abs(a-b)`、`m = max(a,b)`。
2. 改 0 次只覆盖 `X = d`，在 `cnt[d]` 上加 1（用哈希或数组记「恰好 0 次」的个数）。
3. 改 1 次能覆盖的 X 是 `[0, k]` 去掉 `d`，但受 `m` 限制：把 `m` 改成 `k` 时差值最大到 `k`，把另一侧改成 0 时差值最大到 `m`，所以单改一次可达上界 `max(m, k-m)`… 本题统一取 `hi = max(m, k - m)` 之外的区间不成立，正确区间是 `[0, hi]` 且 `hi = max(m, k-m)` 不适用——直接用标准结论：单改一次可覆盖 `[0, max(m, k-m)]` 中的任意值，故对 `[0, hi]` 做 `+1` 差分，再对 `d` 处 `-1`（因为 d 已由 0 次覆盖，不重复计）。
4. 前缀和扫 `X = 0..k`，`total = one[X] + zero[X]`，取最小。

以 `nums=[1,0,1,2,4,3], k=4` 为例：数对 `(1,3) d=2 m=3`、`(0,4) d=4 m=4`、`(1,2) d=1 m=2`。第一对 `hi=max(3,1)=3`，差分在 `[0,3]` 加 1、`2` 处减 1；三对叠加后 `X=2` 处 `zero=1`、`one=1`，总改动 2，与答案一致。

```python
diff = [0] * (k + 2)
zero = [0] * (k + 1)
for i in range(n // 2):
    a, b = nums[i], nums[n - 1 - i]
    d, m = abs(a - b), max(a, b)
    zero[d] += 1
    hi = max(m, k - m)
    diff[0] += 1
    diff[hi + 1] -= 1
    diff[d] -= 1
    diff[d + 1] += 1
cur = ans = 0
for x in range(k + 1):
    cur += diff[x]
    ans = min(ans, cur + zero[x]) if x == 0 else min(ans, cur + zero[x])
```

## 复杂度
时间 O(n + k)：n 来自遍历数对，k 来自扫描 X 的差分前缀和。
空间 O(k)：`diff` 与 `zero` 两个长度 k 的数组。

## 易错点
- `hi = max(m, k - m)` 算错成 `k`：例如 `(0,4), k=4` 时 `hi=4` 没问题，但 `(1,3), k=4` 时 `hi` 应为 3，若写成 4 会把 `X=4` 误算成只需改 1 次，答案偏小。
- 差分里忘了在 `d` 处减 1：`d` 已被 0 次覆盖，若仍算进「改 1 次」的区间，`X=d` 的总改动会多算 1，示例 1 的 `X=2` 会得 3 而非 2。

## 如果面试官追问
要求输出具体改动方案怎么办？答：记录取到最小值的 X，再对每个数对判断 `d==X` 则不动，否则把 `max(a,b)` 改成 `min(a,b)+X`（需 ≤k）或把 `min` 改成 `max(a,b)-X`。
