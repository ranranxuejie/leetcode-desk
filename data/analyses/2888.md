## 一句话思路
用 `pandas.concat([df1, df2], ignore_index=True)` 沿行方向堆叠，两表列名完全一致所以直接拼接即可。

## 怎么做
1. 确认两表列名与顺序一致：`student_id`、`name`、`age`，这是能直接 `concat` 的前提。
2. 调用 `pandas.concat` 并传入列表 `[df1, df2]`，默认 `axis=0` 即按行堆叠。
3. 加 `ignore_index=True` 让结果索引重排为 0..5，否则 df2 的行会带着自己的 0、1 索引，出现重复索引。
4. 返回结果 DataFrame。

以官方示例为例：`df1` 有 4 行（索引 0-3），`df2` 有 2 行（索引 0-1）。不加 `ignore_index` 时结果的 index 是 `[0,1,2,3,0,1]`；加上之后变成 `[0,1,2,3,4,5]`，行数 6，`student_id` 依次为 1,2,3,4,5,6。

```python
import pandas as pd

def concatenateTables(df1: pd.DataFrame, df2: pd.DataFrame) -> pd.DataFrame:
    return pd.concat([df1, df2], ignore_index=True)
```

关键中间值：`pd.concat([df1, df2])` 的 `shape` 是 `(6, 3)`，`columns` 仍是 `['student_id', 'name', 'age']`。

## 复杂度
时间：O(n+m)，n、m 分别是 df1、df2 的行数，逐行复制。
空间：O(n+m)，新建一个结果 DataFrame 存放全部行。

## 易错点
- 忘记 `ignore_index=True`：输入就是示例里 df1 四行、df2 两行 → 结果索引变成 `[0,1,2,3,0,1]` 出现重复，判题按位置比对行时可能对不上 → 正确做法是显式传 `ignore_index=True`。
- 用 `df1.append(df2)`：pandas 2.0 起 `append` 已被移除，直接 `AttributeError` → 正确做法是统一用 `pd.concat([df1, df2], ignore_index=True)`。

## 如果面试官追问
问：如果两表列顺序不同（df2 是 `name, student_id, age`）怎么办？
答：`concat` 按列名对齐而非位置，结果列取并集顺序，缺失补 `NaN`，必要时先 `df2[df1.columns]` 重排。
