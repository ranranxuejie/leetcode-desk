## 一句话思路
后序 DFS 返回子树高度，同时用 -1 当「已失衡」的哨兵向上短路，一次遍历判完。

## 怎么做
1. 定义 `dfs(node)`：空节点返回 0，否则返回该子树高度，失衡则返回 -1。
2. 递归取 `left = dfs(node.left)`、`right = dfs(node.right)`，任一为 -1 立即返回 -1。
3. 检查 `abs(left - right) > 1`，成立返回 -1，否则返回 `max(left, right) + 1`。
4. 主函数返回 `dfs(root) != -1`，空树 `dfs(None)` 得 0，`0 != -1` 为 `True`，与示例 3 一致。

以示例 2 的 `[1,2,2,3,3,null,null,4,4]` 为例：最左路径到节点 4 时 `left=0, right=0`，返回 1；其父节点 3 的左子返回 1、右子为空返回 0，`abs(1-0)=1` 通过，返回 2；再往上节点 2 的左子返回 2、右子为空返回 0，`abs(2-0)=2 > 1`，此处返回 -1，一路短路到根，结果为 `False`。关键中间值是节点 2 处的 `left=2, right=0`——若只算高度不比较，就会漏掉这个失衡点。

```python
def dfs(node):
    if not node:
        return 0
    left = dfs(node.left)
    if left == -1:
        return -1
    right = dfs(node.right)
    if right == -1:
        return -1
    if abs(left - right) > 1:
        return -1
    return max(left, right) + 1

return dfs(root) != -1
```

## 复杂度
时间 O(n)：每个节点只被 `dfs` 访问一次，n 为节点数。
空间 O(h)：递归栈深度等于树高 h，最坏链状树 h=n，额外只开了常数个局部变量。

## 易错点
- 输入 `[1,2,2,3,3,null,null,4,4]` → 若写成「先求左右子树高度再递归判断左右子树是否平衡」，每个节点被重复求高度，复杂度退化成 O(n²)，5000 个节点的链会超时 → 正确做法是让 `dfs` 一次返回高度，用 -1 哨兵把失衡信息随返回值一起上传。
- 输入 `[1,2,2,3,null,null,3,4,null,null,4]` 这类深层失衡 → 若在 `abs(left-right) > 1` 时返回 0 或 `False` 而非 -1，上层会把 0 当成合法高度继续算，可能误判为 `True` → 哨兵值必须与所有合法高度（≥0）区分开，统一用 -1 并在取到后立刻向上返回。

## 如果面试官追问
问：节点数涨到 10^6、递归会爆栈怎么办？
答：改成显式栈做后序，用字典存每个节点的高度，逻辑不变，空间仍是 O(n)。
