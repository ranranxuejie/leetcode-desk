## 一句话思路
逐格扫描，用 `i == j or i + j == n - 1` 判断是否在主/副对角线上，对角线非零、其余为零即成立。

## 怎么做
1. 取 `n = len(grid)`，双重循环遍历每个 `(i, j)`。
2. 用 `on_diag = (i == j or i + j == n - 1)` 标记该格是否属于 X 的两条对角线。
3. 若 `on_diag` 且 `grid[i][j] == 0`，直接返回 `False`；若不在对角线上且 `grid[i][j] != 0`，也返回 `False`。
4. 全部扫完没触发返回，则返回 `True`。

以示例 1 的 `grid = [[2,0,0,1],[0,3,1,0],[0,5,2,0],[4,0,0,2]]` 为例，`n = 4`。扫到 `(0, 3)` 时 `i + j = 3 = n - 1`，属于副对角线，`grid[0][3] = 1` 非零，通过；扫到 `(1, 2)` 时 `i + j = 3` 也在副对角线，`grid[1][2] = 1` 非零，通过；而 `(1, 1)` 是主对角线，`grid[1][1] = 3` 非零，通过。反例示例 2 中 `(0, 1)`：`i != j` 且 `i + j = 1 != 2`，不在对角线上，但 `grid[0][1] = 7 != 0`，立即返回 `False`。

```python
n = len(grid)
for i in range(n):
    for j in range(n):
        on_diag = (i == j or i + j == n - 1)
        if on_diag and grid[i][j] == 0:
            return False
        if not on_diag and grid[i][j] != 0:
            return False
return True
```

关键点：`i + j == n - 1` 是副对角线的判定式，别写成 `i + j == n`。

## 复杂度
时间：O(n²)，每个格子访问一次，n 是边长。
空间：O(1)，只用了 `i`、`j`、`on_diag` 几个变量，没有额外数组。

## 易错点
- 副对角线判定写成 `i + j == n`：对示例 1 的 `(0, 3)` 会判成非对角线，此时 `grid[0][3] = 1 != 0` 就误返回 `False`，把正确答案 `True` 判错。正确写法是 `i + j == n - 1`。
- 只检查对角线非零、漏掉「其余必须为 0」：示例 2 的 `(0, 1) = 7` 不在对角线上，若只查对角线会漏判，返回 `True`。必须补上 `not on_diag and grid[i][j] != 0` 这一支。

## 如果面试官追问
问：若 n 很大、矩阵按行流式给出，能否 O(1) 空间判断？答：可以，逐行读入时用行号 `i` 和列号 `j` 现场算 `on_diag`，不存整个矩阵。
