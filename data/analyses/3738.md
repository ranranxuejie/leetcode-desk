## 一句话思路
用两个 DP 状态分别记录「还没用替换」和「已用掉替换」的最长非递减后缀长度，扫一遍取最大。

## 怎么做
1. 定义 `dp0` = 以当前元素结尾、未使用替换的最长非递减长度；`dp1` = 以当前元素结尾、已使用替换的最长非递减长度。
2. 对每个 `i`，若 `nums[i] >= nums[i-1]`，则 `dp0` 和 `dp1` 都各自加一；否则 `dp0` 重置为 1，`dp1` 只能靠「把 `nums[i]` 改成 ≥ `nums[i-1]`」来续上，即 `dp1 = dp0_prev + 1`。
3. 用 `dp0_prev` 保存上一轮的 `dp0`，因为更新 `dp1` 时要用到它；同时用 `ans` 记录所有 `dp0`、`dp1` 的最大值。
4. 以 `nums = [1,2,3,1,2]` 为例：到 `i=3`（值 1）时，`nums[3] < nums[2]=3`，`dp0` 重置为 1，`dp1 = dp0_prev + 1 = 3 + 1 = 4`，正好对应把 1 改成 3 后接上前面的 `[1,2,3]`。

```python
dp0 = dp1 = 1
ans = 1
for i in range(1, len(nums)):
    prev0 = dp0
    if nums[i] >= nums[i - 1]:
        dp0 += 1
        dp1 += 1
    else:
        dp0 = 1
        dp1 = prev0 + 1
    ans = max(ans, dp0, dp1)
return ans
```

关键点：`dp1` 在「断崖」处不是重置为 1，而是 `prev0 + 1`，因为替换掉当前元素就能把前面那段未替换的非递减段接上。

## 复杂度
时间：O(n)，一次遍历，n 为 `len(nums)`。
空间：O(1)，只开了 `dp0`、`dp1`、`prev0`、`ans` 四个变量。

## 易错点
- 输入 `[5,4,3,2,1]` → 若在 `nums[i] < nums[i-1]` 时把 `dp1` 也重置为 1，会错成答案 2；正确做法是 `dp1 = prev0 + 1`，这里 `prev0` 是上一轮未替换的长度，得到 2 才对（替换一个元素最多接上长度 2）。
- 输入 `[1,2,3,1,2]` → 若忘记在 `nums[i] >= nums[i-1]` 时也更新 `dp1 += 1`，会漏掉「替换发生在更早位置、后面继续延伸」的情况，错成 3；正确做法是相等/递增时两个状态同步加一。

## 如果面试官追问
问：如果允许替换至多 k 个元素呢？
答：把状态扩成 `dp[0..k]`，断崖处 `dp[j] = dp_prev[j-1] + 1`，时间 O(nk)。
