## 一句话思路
用单调栈求每个元素作为最大/最小值的最长管辖区间，再按「长度不超过 k」截断计数，一次遍历同时累加最大与最小贡献。

## 怎么做
1. 对每个下标 i，用单调栈求出它作为**最小值**时向左、向右能延伸到的最远边界 `lmin[i]`、`rmin[i]`（严格小于才弹出，保证相等元素只被算一次）。
2. 同理求它作为**最大值**的边界 `lmax[i]`、`rmax[i]`（严格大于才弹出）。
3. 设左可选个数 `a = i - l + 1`，右可选个数 `b = r - i + 1`，含 i 且落在区间内的子数组共 `a*b` 个；但长度要 ≤ k，需要减去超长部分。
4. 用公式 `cnt(a,b,k) = 总对数 - 长度>k 的对数`，把 `nums[i]` 乘上 `cnt` 累加进答案（最小值加、最大值也加）。

以 `nums=[1,2,3], k=2` 为例，i=1（值 2）：作为最小值时左边被 1 挡住 `lmin=2`，右边无更小 `rmin=2`，`a=1,b=2`；作为最大值时 `lmax=0,rmax=2`，`a=2,b=2`。对 `a=2,b=2,k=2`，总对数 4，长度>2 的只有 (2,2) 一种，故 `cnt=3`，贡献 `2*3=6`。

```python
def cnt(a, b, k):
    # 含当前点、左右各取 x∈[1,a], y∈[1,b]，要求 x+y-1<=k
    total = a * b
    # 超长：x+y-1 > k  =>  x+y >= k+2
    over = 0
    for x in range(1, a + 1):
        y = k + 2 - x          # 最小的违规 y
        if y <= b:
            over += b - y + 1
    return total - over
```
（实际实现用 O(1) 闭式：令 `s=k+1`，超长对数 = 两段等差数列求和，避免上面 O(a) 循环。）

## 复杂度
时间 O(n)：两次单调栈各 O(n)，每个下标 O(1) 计数。
空间 O(n)：`lmin/rmin/lmax/rmax` 四个数组加两个栈。

## 易错点
- `nums=[1,1,1], k=2`：若用「小于等于」弹栈，相等元素区间互相吞并，`cnt` 重复计数导致答案偏大；必须一侧严格、一侧非严格（如左用 `<`、右用 `<=`），保证每个子数组的最小值只归属一个下标。
- `k` 大于等于 `n` 时：`cnt` 里 `k+2-x` 恒大于 `b`，`over` 应为 0；若把 `s=k+1` 写成 `s=k`，会误减掉合法长度，`[1,2,3],k=3` 会算小。

## 如果面试官追问
问：若 k 固定为 n（即所有子数组）怎么简化？
答：`cnt` 直接等于 `a*b`，省掉截断逻辑，仍是两次单调栈 O(n)。
