## 一句话思路
二分答案 W，用记忆化搜索判断「在每辆车等待 ≤ W 的前提下最多能服务几辆」，取可行 W 的最小值。

## 怎么做
1. 关键观察：第 i 辆车被允许的时间恰好等于第 i-1 辆车的开始时间，所以「等待时间」= 开始时间 − 上一辆的开始时间，只需在状态里记录两台加油机各自的空闲时刻和剩余燃料。
2. 状态取 `(i, t0, t1, f0, f1)`：i 是下一辆待服务的车，t0/t1 是加油机空闲时刻，f0/f1 是剩余燃料；返回从该状态起最多还能服务多少辆。
3. 对每辆车枚举分给 0 号或 1 号机：开始时刻 = max(允许时刻, 该机空闲时刻)，若等待 > W 或燃料不足则该分支非法。
4. 二分 W ∈ [0, 总需求]，找最小可行值；若 W=总需求都服务不了第 0 辆，返回 -1。

以示例 1 为例，W=6 时：车 0 上机 0，t0=6, f0=10；车 1 上机 1，t1=8, f1=5；车 2 允许时刻 0，机 0 空闲 6，等待 6 ≤ 6，合法，t0=10, f0=6。而 W=5 时车 2 在两台机上都等 6 > 5，只能服务 2 辆，故答案 6。

```python
from functools import lru_cache

def best(i, t0, t1, f0, f1):
    if i == n:
        return 0
    allow = 0 if i == 0 else (t0 if last[i] == 0 else t1)
    res = 0
    for j in (0, 1):
        tj, fj = (t0, f0) if j == 0 else (t1, f1)
        st = max(allow, tj)
        if st - allow <= W and fj >= demand[i]:
            nt = (st + demand[i], t1, f0 - demand[i], f1) if j == 0 \
                 else (t0, st + demand[i], f0, f1 - demand[i])
            res = max(res, 1 + best(i + 1, *nt))
    return res
```

## 复杂度
时间：二分 O(log S) 层 × 状态数 O(n·S²·F²)，S 为总时长、F 为燃料上限。
空间：记忆化表存同样多的状态，每层递归栈深 O(n)。

## 易错点
- 把「允许时刻」当成固定的 i：实际是上一辆的开始时间，示例 1 中车 2 的允许时刻是 0（车 1 在 0 开始），不是 2；用错会让 W=6 误判为不可行。
- 燃料不足时直接终止而非跳过：若当前车两台机燃料都不够，应停止计数并返回已服务数，而不是继续尝试后面的车；示例 3 中 demand[0]=10 > 8，必须返回 -1 而不是 0。

## 如果面试官追问
问：n 放大到 500 怎么办？答：状态里的时刻和燃料维度会爆炸，需改成按「两机时间差 + 已用燃料」压缩，或直接贪心枚举分配方案。
