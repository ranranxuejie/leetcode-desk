## 一句话思路
对每个值收集其下标，答案就是「同一值相邻下标（含首尾环绕）最大间隔的一半向下取整」在所有值里的最小值。

## 怎么做
1. 用哈希表 `pos` 把每个值出现的下标按顺序存成列表。
2. 对每个值的下标列表，把首下标 `+n` 追加到末尾，形成环绕闭环。
3. 相邻两项之差 `d` 表示两个同值元素之间隔着 `d-1` 个异值位置，这段被两侧同时填充，需要 `d//2` 秒。
4. 取该值所有间隔的最大值，再对所有值取最小。

以 `nums = [2,1,3,3,2]` 为例：`pos[3] = [2,3]`，追加 `2+5=7` 得 `[2,3,7]`，间隔 `1` 和 `4`，`max(1//2, 4//2) = 2`；`pos[2] = [0,4]`，追加 `5` 得 `[0,4,5]`，间隔 `4` 和 `1`，结果也是 `2`。答案 `2`。

```python
from collections import defaultdict

pos = defaultdict(list)
n = len(nums)
for i, x in enumerate(nums):
    pos[x].append(i)

ans = n
for idx in pos.values():
    idx.append(idx[0] + n)
    need = max((idx[k+1] - idx[k]) // 2 for k in range(len(idx) - 1))
    ans = min(ans, need)
return ans
```

注意 `idx.append(idx[0] + n)` 这一步：不追加就漏掉「最后一个下标绕回第一个下标」这段间隔，`[2,1,3,3,2]` 里 `pos[2]` 会只算出间隔 `4`，漏掉环绕的 `1`。

## 复杂度
时间：O(n)，遍历一次建表，每个下标在间隔计算中只被访问一次。
空间：O(n)，`pos` 存下全部 n 个下标，另有每个不同值的列表开销。

## 易错点
- 输入 `nums = [1,2,1,2]`：只算相邻下标差 `2-0=2` 得 `1` 秒，看似对，但若忘了环绕追加，`pos[1]=[0,2]` 只算一个间隔，遇到 `[1,2,3,1]` 这类首尾同值分布会漏掉环绕段而偏大。正确做法是先把 `idx[0] + n` 追加到列表末尾再算。
- 输入 `nums = [5,5,5,5]`：`pos[5] = [0,1,2,3]`，追加 `4` 后间隔全是 `1`，`1//2 = 0`，答案 `0`，正确；但若把间隔写成 `d-1` 再取半，会得到 `0` 也对，可若写成 `(d+1)//2` 就会错成 `1`。统一用 `d//2`，别加一。

## 如果面试官追问
问：如果要求输出最终变成的那个值以及每秒的具体替换方案？
答：值取使 `max(d//2)` 最小的那个；方案按 BFS 从每个同值下标同时向两侧扩散，记录每步的层号即可。
