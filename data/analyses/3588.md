## 一句话思路
枚举每条水平/竖直边作为底，用该行/列的最大最小坐标差当高，取最大乘积。

## 怎么做
1. 按 y 分组，记录每个 y 上 x 的最小值和最大值；按 x 分组，记录每个 x 上 y 的最小值和最大值。
2. 全局记录 `min_x, max_x, min_y, max_y`，它们给出任意水平/竖直底的最大跨度。
3. 对每个 y：底 = `xmax[y] - xmin[y]`，高 = `max(max_y - y, y - min_y)`，更新答案。
4. 对每个 x 对称做一遍：底 = `ymax[x] - ymin[x]`，高 = `max(max_x - x, x - min_x)`。

以示例 1 `[[1,1],[1,2],[3,2],[3,3]]` 为例：`y=2` 上 x 为 {1,3}，底 = 2；全局 `min_y=1, max_y=3`，高 = max(3-2, 2-1) = 1，乘积 2。`x=1` 上 y 为 {1,2}，底 = 1；全局 `min_x=1, max_x=3`，高 = max(3-1, 1-1) = 2，乘积 2。答案 2。

```python
from collections import defaultdict
xmin, xmax = {}, {}
ymin, ymax = {}, {}
for x, y in coords:
    xmin[y] = min(xmin.get(y, x), x)
    xmax[y] = max(xmax.get(y, x), x)
    ymin[x] = min(ymin.get(x, y), y)
    ymax[x] = max(ymax.get(x, y), y)
min_x = min(xmin.values()); max_x = max(xmax.values())
min_y = min(ymin.values()); max_y = max(ymax.values())
ans = -1
for y in xmin:
    ans = max(ans, (xmax[y] - xmin[y]) * max(max_y - y, y - min_y))
for x in ymin:
    ans = max(ans, (ymax[x] - ymin[x]) * max(max_x - x, x - min_x))
```

## 复杂度
时间 O(n)：一次遍历建四个字典，再各扫一遍键，键数 ≤ n。
空间 O(n)：四个字典各存至多 n 个条目。

## 易错点
- 输入 `[[1,1],[2,2],[3,3]]` 三点共线 → 若只按「有平行边」判断会误判，实际任意两点 x、y 都不同，无水平/竖直边，应返回 -1；代码里 `ans` 初值必须是 -1 而非 0。
- 输入 `[[1,1],[1,2]]` 只有两个点 → 无法构成三角形，但按上面的公式 `x=1` 会算出底 1、高 0，乘积 0；必须保证面积非零，即底和高都 > 0 才更新，否则返回 -1。

## 如果面试官追问
要求输出具体三个顶点坐标怎么办？答：在更新 `ans` 时同时记下该 y（或 x）对应的 `xmin/xmax` 两点，以及取到 `max_y` 或 `min_y` 的那个点，O(1) 额外空间即可还原。
