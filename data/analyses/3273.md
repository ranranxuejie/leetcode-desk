## 一句话思路
按 `damage[i] / ceil(health[i]/power)` 从大到小排序，即单位击杀时间伤害最高的敌人先杀，交换论证可证最优。

## 怎么做
1. 对每个敌人算击杀所需秒数 `t[i] = (health[i] + power - 1) // power`。
2. 以 `damage[i] / t[i]` 降序排序，等价于按 `damage[i] * t[j] > damage[j] * t[i]` 比较，避免浮点。
3. 顺序击杀，维护剩余总伤害 `alive`，每段耗时 `t` 秒内 Bob 承受 `alive * t`，然后 `alive -= damage[i]`。

以示例 1 为例：`t = [1,2,2,2]`，比值 `1/1, 2/2, 3/2, 4/2`，排序后顺序为敌人 3、2、0、1。第一段 `alive = 10`，`t = 2`，累加 `20`；随后 `alive` 变 `6`，第二段 `6*2 = 12`；再 `alive = 3`，`3*1 = 3`；最后 `alive = 2`，`2*2 = 4`，合计 `39`。

```python
from functools import cmp_to_key

def cmp(a, b):
    # a, b = (damage, t)；a 应排在 b 前当 damage_a * t_b > damage_b * t_a
    return -1 if a[0] * b[1] > b[0] * a[1] else 1

items = [(damage[i], (health[i] + power - 1) // power) for i in range(len(damage))]
items.sort(key=cmp_to_key(cmp))
alive = sum(damage)
ans = 0
for d, t in items:
    ans += alive * t
    alive -= d
```

## 复杂度
时间 O(n log n)：排序主导，`n = len(damage)`；每段累加 O(n)。
空间 O(n)：存 `items` 列表，排序额外栈 O(log n)。

## 易错点
- 用 `health[i] // power` 算秒数 → 示例 3 中 `59 // 8 = 7`，少算一秒，答案从 `320` 错成 `280`；必须写 `(health[i] + power - 1) // power`。
- 用浮点 `damage[i] / t[i]` 排序 → 当 `damage` 与 `t` 都接近 `10^4` 时比值精度不足，可能把 `(9999, 10000)` 和 `(9998, 9999)` 判成相等；改用交叉相乘 `a[0]*b[1] > b[0]*a[1]` 比较。

## 如果面试官追问
若 `power` 改为每次攻击只对单个敌人造成伤害且可切换目标，怎么处理？答：此时攻击顺序不影响总时长，只需按 `damage` 降序贪心，先打高伤害敌人以减少其存活秒数。
