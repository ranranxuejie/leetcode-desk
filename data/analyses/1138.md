## 一句话思路
把每个字母映射到 (行, 列)，逐字符先上下后左右移动并追加 `!`，且必须先上后下、先左后右以绕开 `z` 的缺口。

## 怎么做
1. 用 `divmod(ord(ch) - 97, 5)` 得到目标坐标，起点 `(0, 0)`。
2. 对每个字符，先算 `dr = r - cr`、`dc = c - cc`，按 `U`/`D` 和 `L`/`R` 拼出移动串。
3. 顺序固定为：先 `U` 再 `D`，先 `L` 再 `R`，最后追加 `!`，更新当前位置。

以 `target = "leet"` 为例：`l` 是 `(2,1)`，从 `(0,0)` 出发 `dr=2, dc=1`，得 `DDR!`，位置变 `(2,1)`；接着 `e` 是 `(0,4)`，`dr=-2, dc=3`，得 `UURRR!`。前两段拼起来正是 `DDR!UURRR!`，与官方输出一致。

```python
pos = {chr(97 + i): divmod(i, 5) for i in range(26)}
cr = cc = 0
ans = []
for ch in target:
    r, c = pos[ch]
    if r < cr: ans.append('U' * (cr - r))
    if c < cc: ans.append('L' * (cc - c))
    if r > cr: ans.append('D' * (r - cr))
    if c > cc: ans.append('R' * (c - cc))
    ans.append('!')
    cr, cc = r, c
return ''.join(ans)
```

关键点：`z` 在 `(5,0)`，第 5 行只有一列。若从 `(5,0)` 去 `(0,4)` 先右移会撞到不存在的 `(5,1)`，所以必须先 `U` 到第 0 行再 `R`；反过来从 `(0,4)` 去 `z` 必须先 `L` 到第 0 列再 `D`。代码里 `U`/`L` 分支写在 `D`/`R` 之前，正好满足。

## 复杂度
时间 O(n + 总移动量)，n 为 `target` 长度，每字符移动量 ≤ 10。
空间 O(总移动量)，即答案串长度，`pos` 字典固定 26 项。

## 易错点
- 输入含 `z` 且前后是右侧字母，如 `"za"`：若先 `R` 再 `D` 会生成越界路径 `(5,1)`，答案非法；正确做法是固定先 `U`/`L` 后 `D`/`R`，`"za"` 应输出 `U!RRRRRDDDDD!` 这类先上行再右移的序列。
- 输入 `"z"` 单字符：若忘记起点就是 `(0,0)` 而把 `z` 当 `(0,25)` 处理，会多出 5 个 `D`；正确做法是用 `divmod(ord('z')-97, 5) = (5,0)`，直接 `DDDDD!`。

## 如果面试官追问
若要求输出**最短**指令序列（而非任意一条），怎么办？答：本题任意合法路径已是最短，因为每步曼哈顿距离不可省，只需保证不绕路即可。
