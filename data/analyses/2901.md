## 一句话思路
按 `words` 下标顺序做 DP，`dp[i]` 记以 i 结尾的最长合法子序列长度，转移时枚举前驱 j 并检查汉明距离为 1 且 `groups` 不同。

## 怎么做
1. 预处理：按字符串长度分组，只让同长度的下标互相比较，避免无谓的汉明距离计算。
2. 对每个 i，枚举所有 j < i 且 `len(words[j]) == len(words[i])`，若 `groups[j] != groups[i]` 且汉明距离恰为 1，则 `dp[i] = max(dp[i], dp[j] + 1)`。
3. 记录 `prev[i]` 指向最优前驱，最后从 `dp` 最大值处回溯出下标序列。
4. 用示例 1 走一遍：`words = ["bab","dab","cab"]`，`groups = [1,2,2]`。i=0 时 `dp[0]=1`；i=1 时 j=0 满足 `groups` 不同且 `"bab"` 与 `"dab"` 汉明距离为 1，`dp[1]=2`；i=2 时 j=0 也满足，`dp[2]=2`，j=1 因 `groups[1]==groups[2]` 被跳过。最终取 `dp[1]` 或 `dp[2]` 回溯，得到 `["bab","dab"]` 或 `["bab","cab"]`。

```python
n = len(words)
dp = [1] * n
prev = [-1] * n
for i in range(n):
    for j in range(i):
        if groups[j] == groups[i] or len(words[j]) != len(words[i]):
            continue
        diff = sum(a != b for a, b in zip(words[i], words[j]))
        if diff == 1 and dp[j] + 1 > dp[i]:
            dp[i] = dp[j] + 1
            prev[i] = j
best = max(range(n), key=lambda i: dp[i])
res = []
while best != -1:
    res.append(words[best])
    best = prev[best]
res.reverse()
```

## 复杂度
时间：O(n² · L)，L ≤ 10 为字符串长度，双重循环贡献 n²，汉明距离比较贡献 L。
空间：O(n)，`dp` 和 `prev` 各开一个长度 n 的数组。

## 易错点
- 输入 `words = ["a","b","c","d"]`、`groups = [1,2,3,4]` 时，若忘记检查长度相等，`"a"` 与 `"b"` 长度都是 1 没问题，但换成 `["ab","c"]` 就会把长度不同的字符串误判为汉明距离 1 → 必须先比较 `len(words[j]) != len(words[i])` 再算距离。
- 输入 `groups = [1,2,2]`、`words = ["bab","dab","cab"]` 时，若只检查汉明距离而漏掉 `groups[j] != groups[i]`，会把 `"dab"` 和 `"cab"` 连起来（`groups[1]==groups[2]`）→ 转移前先判 `groups` 不等。

## 如果面试官追问
若 n 扩大到 10^5 怎么办？答：按 (长度, 通配模式) 建哈希，把每个词枚举一位替换成 `*` 生成 L 个 key，同 key 内只需找 groups 不同的最长链，配合线段树或分桶维护。
