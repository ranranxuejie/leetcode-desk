## 一句话思路
用二维前缀和 O(1) 判断每个 stampHeight×stampWidth 窗口能否放邮票，能放就打差分标记，最后前缀和还原看每个 0 格是否被盖住。

## 怎么做
1. 对 grid 建二维前缀和 `pre`，`pre[i][j]` 表示左上角 (0,0) 到 (i-1,j-1) 的 1 的个数。
2. 枚举每个可作邮票左上角的 (i,j)，`i+stampHeight<=m`、`j+stampWidth<=n`，用 `pre` 判断该窗口内 1 的个数是否为 0。
3. 若为 0，在差分数组 `diff` 上对窗口四角做 +1/-1 标记。
4. 对 `diff` 求二维前缀和得到 `cover`，逐格检查：`grid[i][j]==0` 且 `cover[i][j]==0` 则返回 `False`，全通过返回 `True`。

以示例 1 为例：grid 5×4，stampHeight=4、stampWidth=3。可放邮票的左上角只有 (0,1) 和 (1,1) 两处（第 0 列全是 1，窗口不能含 1）。对 (0,1) 窗口（行 0-3、列 1-3）和 (1,1) 窗口（行 1-4、列 1-3）打差分标记，还原后 `cover` 在列 1-3 的所有行都 ≥1，而列 0 全是 1 不需覆盖，故返回 `True`。

```python
m, n = len(grid), len(grid[0])
pre = [[0]*(n+1) for _ in range(m+1)]
for i in range(m):
    for j in range(n):
        pre[i+1][j+1] = grid[i][j] + pre[i][j+1] + pre[i+1][j] - pre[i][j]
diff = [[0]*(n+1) for _ in range(m+1)]
for i in range(m - stampHeight + 1):
    for j in range(n - stampWidth + 1):
        r, c = i + stampHeight, j + stampWidth
        if pre[r][c] - pre[i][c] - pre[r][j] + pre[i][j] == 0:
            diff[i][j] += 1; diff[r][j] -= 1
            diff[i][c] -= 1; diff[r][c] += 1
for i in range(m):
    for j in range(n):
        if i: diff[i][j] += diff[i-1][j]
        if j: diff[i][j] += diff[i][j-1]
        if i and j: diff[i][j] -= diff[i-1][j-1]
        if grid[i][j] == 0 and diff[i][j] == 0:
            return False
return True
```

## 复杂度
时间 O(m·n)：建前缀和、枚举窗口、还原差分各扫一遍矩阵。
空间 O(m·n)：`pre` 和 `diff` 各开 (m+1)×(n+1)。

## 易错点
1. 窗口边界算错 → 对示例 1 若把 `range(m - stampHeight + 1)` 写成 `range(m - stampHeight)`，会漏掉左上角 (1,1) 这个合法窗口，导致行 4 的空格判为未覆盖而错返 `False`；正确是 `+1` 保证取到最后一个合法左上角。
2. 差分数组尺寸开成 m×n → 对示例 1 在 (0,1) 窗口打标记时 `diff[r][c]` 的 `r=4`、`c=4` 越界；正确做法是 `diff` 开 (m+1)×(n+1)，让右下角减标记有位置落。

## 如果面试官追问
要求输出具体邮票放置方案怎么办？答：把打差分时记录的每个合法左上角 (i,j) 存进列表，直接返回该列表即为一种可行方案，无需额外计算。
