## 一句话思路
按「去掉零后的数」反向计数：统计所有由 1-9 组成、且能由某个 ≤n 的数去零得到的串，用数位 DP 判可达。

## 怎么做
1. 关键观察：去零后的数只含 1-9，且长度 ≤ len(n)。对每个候选串 s，判断是否存在 x ≤ n 使去零(x)=s。
2. 可达条件：把 s 的每位之间插入任意个 0（含 0 个），得到的数若 ≤ n 则 s 可达。等价于「s 与 n 同长时逐位比较，s 的某前缀严格小于 n 对应前缀，或全等」。
3. 用数位 DP 统计：枚举 s 长度 L，从高位到低位填 1-9，维护 tight（是否与 n 前缀相等）。tight 时下一位上界是 n 的对应位，但注意 0 可任意插入，所以只要 s 的某位 < n 同位即可松绑。
4. 具体到 n=10：L=1 时 s∈{1..9}，s=1 满足 1≤10 可达；s=2..9 也各自由 2..9 本身可达，共 9 个；L=2 时最小 s=11>10 不可达。答案 9。

```python
def countDistinct(n):
    s = str(n)
    m = len(s)
    total = 0
    for L in range(1, m + 1):
        # dp[tight] = 方案数
        dp = [0, 0]
        dp[1] = 1
        for i in range(L):
            nd = [0, 0]
            for tight in (0, 1):
                if dp[tight] == 0:
                    continue
                hi = int(s[i]) if (tight and i < m) else 9
                lo = 1
                for d in range(lo, hi + 1):
                    nt = 1 if (tight and i < m and d == int(s[i])) else 0
                    nd[nt] += dp[tight]
            dp = nd
        total += dp[0] + dp[1]
    return total
```
（上面是示意，L<m 时 tight 分支需按「补零对齐」处理，实际实现把 s 左补到 L 位比较。）

## 复杂度
时间：O(len(n)^2 * 9)，外层枚举长度 L、内层 L 位、每位 9 个数字。
空间：O(1)，只开长度 2 的 dp 数组。

## 易错点
- n=10 时若只统计「s 本身 ≤ n」会漏掉 s=1 由 10 去零得到 → 错成 8 → 正确做法是允许在 s 各位间插 0 后再比 ≤n。
- n=100 时 s=1 由 100 去零得到，但 s=11 需 110>100 不可达 → 若把「插 0 后长度可超 len(n)」也算进去会多算 → 正确做法是插 0 后总长 ≤ len(n) 才可能 ≤n。

## 如果面试官追问
问：n 到 10^100 怎么办？答：len(n) 到 100，O(L^2) 仍可，但需把 dp 改成按位滚动并处理大数比较，避免转 int。
