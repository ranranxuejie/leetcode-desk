## 一句话思路
沿右链下行找第一个值小于 val 的节点，把 val 插在它上面，原右链断开成新节点的左子树。

## 怎么做
1. 若 `root.val < val`，val 比整棵树都大，新节点直接当根，`root` 挂到它的左子树，返回新节点。
2. 否则从 `root` 出发只走右孩子：最大树里右子树对应原数组后缀，val 追加在末尾，只可能落在右链上。
3. 找到第一个 `cur.right.val < val` 的 `cur`，把 `cur.right` 换成新节点 `node`，`node.left = 旧 cur.right`，`node.right = None`。
4. 若右链走到底都没遇到更小的（`cur.right is None`），直接挂 `cur.right = node`。

以示例 3 为例：`root = [5,2,3,null,1]`，`val = 4`。从 5 出发，`5.right = 3 < 4` 命中，此时 `cur = 5`、`old = 3`；新节点 4 的 `left` 指向 3，`5.right` 改成 4，得到 `[5,2,4,null,1,3]`。

```python
node = TreeNode(val)
if root.val < val:
    node.left = root
    return node
cur = root
while cur.right and cur.right.val > val:
    cur = cur.right
node.left = cur.right
cur.right = node
return root
```

注意循环条件是 `cur.right.val > val` 而不是 `>=`，因为题目保证值互不相同，用 `>` 停下时 `cur.right.val < val` 必然成立。

## 复杂度
时间 O(h)，h 是右链长度，最坏 O(n)（树退化成右斜链）。
空间 O(1)，只开了 `node`、`cur` 两个指针，没有递归栈。

## 易错点
- 输入 `root = [4,1,3,null,null,2], val = 5`：若先写循环再判根，会走进右链把 5 挂到 4 下面，输出根仍是 4。正确做法是循环前先判 `root.val < val`，让 5 当新根、4 整体成为左子树。
- 输入 `root = [5,2,4,null,1], val = 3`：若把 `node.left` 写成 `cur` 或忘记接 `old`，会丢掉 4 这棵子树，输出变成 `[5,2,3]`。正确做法是先存 `old = cur.right`，再 `node.left = old`、`cur.right = node`，顺序不能反。

## 如果面试官追问
问：如果 val 不是追加在末尾，而是插入到数组任意位置 i 呢？
答：那就得先由树还原数组 a（中序不是，要按 Construct 的递归定义取最大值切分），再重建，O(n) 起步，不能只走右链。
