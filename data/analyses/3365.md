## 一句话思路
把 s 和 t 都按长度 m = n // k 切块，比较两边的块多重集是否相同——因为重排只能改变块的顺序，不能改变块的内容。

## 怎么做
1. 算块长 `m = len(s) // k`，若 `m == 0` 直接返回 `True`（k == n 时每块单字符，异位词保证可重排）。
2. 用切片把 s 切成 `s[i:i+m]` 共 k 块，t 同样切法。
3. 对两边块列表排序后逐位比较，或直接比较 `Counter`。

以示例 3 为例：`s = "aabbcc", t = "bbaacc", k = 2`，`m = 3`。s 的块是 `["aab", "bcc"]`，t 的块是 `["bba", "acc"]`。排序后 `["aab","bcc"] != ["acc","bba"]`，返回 `False`。注意 t 的块边界必须按 `m=3` 切，不能按字符对齐——`"bbaacc"` 前 3 位是 `"bba"` 而非 `"bb"`。

```python
from collections import Counter

def isPossibleToRearrange(s, t, k):
    m = len(s) // k
    if m == 0:
        return True
    cs = Counter(s[i:i+m] for i in range(0, len(s), m))
    ct = Counter(t[i:i+m] for i in range(0, len(t), m))
    return cs == ct
```

用 `Counter` 比排序更省：排序是 O(n log k) 的字符串比较，`Counter` 是 O(n) 哈希。

## 复杂度
时间 O(n)：切块和哈希各扫一遍，n 为字符串长度。
空间 O(n)：`Counter` 存 k 个长度 m 的块，合计 n 字符。

## 易错点
1. 示例 2 与示例 3 输入完全相同、只有 k 不同 → 若把块长写死成 2 或按字符频率比较，会把示例 3 误判为 `True`。正确做法是每次用 `m = len(s) // k` 重新切块，k=2 时块长是 3。
2. `k == len(s)` 时 `m = 1`，此时任意异位词都可重排 → 若在切块前就假设 `m >= 2` 或对 `m == 0` 做除法会崩。正确做法是先判 `m == 0` 返回 `True`（本题 `m` 最小为 1，但写成防御式更稳）。

## 如果面试官追问
若要求输出具体重排方案？答：对 t 的每个块在 s 的 `Counter` 里查并删除，按序记录下标即可，O(n)。
