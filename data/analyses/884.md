## 一句话思路
把两个句子拼起来统一计数，只出现一次的单词就是答案，因为跨句重复的会被计到 2。

## 怎么做
1. 用 `(s1 + " " + s2).split()` 得到全部单词，拼成一个列表。
2. 用 `Counter` 对列表计数，得到 `cnt`。
3. 遍历 `cnt`，挑出 `v == 1` 的键。

以示例 1 为例：拼接后是 `"this apple is sweet this apple is sour"`，`cnt` 中 `this`、`apple` 各为 2，`is`、`sweet`、`sour` 各为 1，所以输出 `["is","sweet","sour"]` 之外的……注意 `is` 在两个句子里都出现，计数为 2，被正确排除；最终只剩 `sweet` 和 `sour`。

```python
from collections import Counter

words = (s1 + " " + s2).split()
cnt = Counter(words)
return [w for w, c in cnt.items() if c == 1]
```

关键点：**不要分两个字典分别计数再比对**。分句计数时，`s1` 里出现 1 次、`s2` 里也出现 1 次的单词（如 `is`）会被误判为不常见；合并计数后它变成 2，自动被排除。这是本题唯一的核心技巧。

## 复杂度
时间 O(n+m)，n、m 分别是两句话的字符数，split 和计数各扫一遍。
空间 O(n+m)，`words` 列表和 `cnt` 字典各存一份单词。

## 易错点
- 输入 `s1 = "apple apple", s2 = "banana"` → 若分句计数，`apple` 在 s1 中计数为 2 被排除、`banana` 计数为 1 保留，结果碰巧对；但换成 `s1 = "is", s2 = "is"` 就会把 `is` 误判为不常见 → 正确做法是合并成一个字符串再计数。
- 输入 `s1 = "a b", s2 = "a"` → 若用 `set(s1.split()) ^ set(s2.split())` 做对称差，`b` 会保留但 `a` 也会被错误保留（`a` 在两边都出现，应排除）→ 必须用计数 `c == 1` 判断，不能用集合运算。

## 如果面试官追问
问：如果要求按单词在原句中首次出现的顺序输出怎么办？
答：合并计数后按 `words` 列表顺序遍历，用 `seen` 集合去重，只保留 `cnt[w] == 1` 的首次出现。
