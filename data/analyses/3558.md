## 一句话思路
先 BFS 求出最大深度 d，答案只由路径长度 d 决定：奇数权重边个数为奇数即可，共 2^(d-1) 种。

## 怎么做
1. 从节点 1 出发 BFS，记录每个节点的深度，取 `max_depth`。
2. 关键观察：路径上每条边权重 1 或 2，权重 2 不改变奇偶性，只有权重 1 的边数决定奇偶。
3. 长度为 d 的路径，要让和为奇数，权重 1 的边数必须是奇数；d 条边中选奇数条赋 1，方案数 = 2^(d-1)。
4. 用快速幂对 10^9+7 取模。

以示例 2 `edges = [[1,2],[1,3],[3,4],[3,5]]` 为例：BFS 得深度 1→0，2→1，3→1，4→2，5→2，`max_depth = 2`。路径长度 d=2，权重 1 的边数须为奇数，即选 1 条，C(2,1)=2，答案 2。

```python
MOD = 10**9 + 7
# BFS 求最大深度
depth = {1: 0}
q = [1]
max_depth = 0
while q:
    u = q.pop(0)
    for v in adj[u]:
        if v not in depth:
            depth[v] = depth[u] + 1
            max_depth = max(max_depth, depth[v])
            q.append(v)
# 答案 = 2^(max_depth-1) mod MOD
ans = pow(2, max_depth - 1, MOD)
```

注意 `max_depth` 是边数，即路径长度 d；若 d=0（只有根）则答案为 0，但 n≥2 保证 d≥1。

## 复杂度
时间：O(n)，BFS 遍历所有节点和边，快速幂 O(log d)。
空间：O(n)，邻接表存 2(n-1) 条边，depth 字典和队列各 O(n)。

## 易错点
1. 输入 `edges = [[1,2]]` 时若把 `max_depth` 当成节点数而非边数，会算成 2^(1-1)=1 恰好对，但示例 2 会算成 2^(3-1)=4 而非 2。正确做法：`max_depth` 是 BFS 层数减 1，即路径边数。
2. 若用 DFS 递归求深度，n=10^5 的链状树会触发 Python 递归深度限制（默认约 1000）→ RecursionError。正确做法：用 BFS 或显式栈迭代。

## 如果面试官追问
问：如果权重可设为 1 到 k 而非 1 或 2，答案怎么变？
答：只有权重为奇数的边影响奇偶性，设奇数权重有 m 种，偶数权重有 k-m 种，答案 = ((k^d - (k-2m)^d) / 2) mod MOD，用快速幂加逆元。
