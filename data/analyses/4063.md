## 一句话思路
把「至多取反一次」转成前缀和模 k 的两种余数匹配，用哈希表存最早出现的下标。

## 怎么做
1. 设子数组和为 `s`，取反元素 `x` 后和为 `s - 2x`；要 `(s - 2x) % k == 0`，即 `s % k == 2x % k`。
2. 于是有效子数组等价于：`(pre[j] - pre[i]) % k` 等于 `0`（不取反）或等于某个 `2*nums[t] % k`（`t` 在区间内）。
3. 枚举右端点 `j`，维护哈希表 `first[r]` = 前缀和模 k 为 `r` 的最早下标；对每个 `j`，检查 `r = pre[j] % k` 和 `r = (pre[j] - 2*nums[j]) % k` 是否出现过。
4. 用 `j - first[r]` 更新答案。

以 `nums = [4,1,2], k = 3` 为例：`pre = [0,4,5,7]`，模 3 为 `[0,1,2,1]`。`j=3` 时 `pre[3]%3 = 1`，`first[1] = 1`，长度 `3-1=2`；再看取反 `nums[2]=2`，`(7 - 4) % 3 = 0`，`first[0] = 0`，长度 `3-0=3`，答案 3。

```python
first = {0: 0}
pre = 0
ans = 0
for j, x in enumerate(nums, 1):
    pre += x
    r = pre % k
    if r in first:
        ans = max(ans, j - first[r])
    r2 = (pre - 2 * x) % k
    if r2 in first:
        ans = max(ans, j - first[r2])
    if r not in first:
        first[r] = j
```

注意 `first` 只记录 `pre % k`，不记录取反后的余数——取反余数依赖区间内的元素，不能提前存。

## 复杂度
时间 O(n)：每个下标只做常数次哈希查询，n 为 `nums` 长度。
空间 O(min(n, k))：哈希表最多存 k 个不同余数。

## 易错点
- `nums = [2,2,5], k = 6`：若只检查 `pre[j] % k` 是否出现过，会漏掉取反分支，`[2,2]` 的和 4 模 6 为 4，但 `(4 - 2*2) % 6 = 0` 才命中，答案错成 1 而非 2。
- 负数取模：`nums[i]` 可为负，Python 的 `%` 返回非负，但若手写成 `pre - (pre // k) * k` 且 `pre` 为负会得负余数，导致 `first` 键不匹配；统一用 `pre % k`。

## 如果面试官追问
若要求输出具体子数组下标而非长度？答：哈希表存 `(余数 → 最早下标)`，命中时同时记录 `(i, j)` 和是否取反，回溯即可。
