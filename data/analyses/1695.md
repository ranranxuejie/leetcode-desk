## 一句话思路
用滑动窗口维护「窗口内元素互不相同」，右指针扩张、遇重复就收缩左指针，同时用窗口和更新答案。

## 怎么做
1. 用 `left`、`cur`（窗口和）、`seen`（元素→下标）三个变量，`right` 从 0 遍历到末尾。
2. 若 `nums[right]` 已在 `seen` 中且其下标 `>= left`，说明窗口内重复，把 `left` 移到该下标 +1，并从 `cur` 中减去被移出的元素。
3. 把 `nums[right]` 加入 `seen`、累加到 `cur`，用 `cur` 更新 `ans`。

以 `nums = [4,2,4,5,6]` 为例：`right=2` 时 `nums[2]=4` 已在 `seen` 中（下标 0），`left` 从 0 跳到 1，`cur` 由 6 减 4 得 2；随后加入 4、5、6，`cur` 依次为 6、11、17，`ans=17`。

```python
left = cur = ans = 0
seen = {}
for right, x in enumerate(nums):
    if x in seen and seen[x] >= left:
        while left <= seen[x]:
            cur -= nums[left]
            left += 1
    seen[x] = right
    cur += x
    ans = max(ans, cur)
```

注意 `seen[x] >= left` 这个判断不能省：`seen` 里可能残留窗口外的旧下标，比如 `[1,2,1,3]` 处理到 `right=3` 时 `seen[1]=2` 仍在窗口内才需收缩，而窗口外的旧值必须忽略。

## 复杂度
时间 O(n)：`right` 走 n 步，`left` 总共也只前进 n 步。
空间 O(k)：`seen` 存窗口内至多 k 个不同元素，k ≤ n。

## 易错点
- 输入 `[1,2,1,3]`：若只写 `if x in seen` 就收缩，会把窗口外的旧下标也当成重复，`left` 被错误推到 3，答案错成 4 而非 6。正确做法是加 `seen[x] >= left` 条件。
- 输入 `[5,2,1,2,5,2,1,2,5]`：若收缩时只把 `left` 移到 `seen[x]` 而不减 `cur`，窗口和会虚高，输出大于 8。正确做法是 `while left <= seen[x]` 逐个减 `cur` 再 `left += 1`。

## 如果面试官追问
问：要求输出该子数组本身怎么办？
答：在更新 `ans` 时同步记录 `(left, right)`，最后切片 `nums[best_l:best_r+1]` 即可。
