## 一句话思路
用容斥原理：3、5、7 各自倍数之和相加，减去两两公倍数，加回 105 的倍数，避免重复计数。

## 怎么做
1. 写辅助函数 `f(k)`，返回 `[1, n]` 内所有 `k` 的倍数之和。
2. `f(k)` 用等差数列公式：倍数个数 `m = n // k`，和 = `k * m * (m + 1) // 2`。
3. 答案 = `f(3) + f(5) + f(7) - f(15) - f(21) - f(35) + f(105)`。

以 `n = 10` 为例：`f(3)` 的 `m = 3`，得 `3*3*4//2 = 18`（即 3+6+9）；`f(5)` 的 `m = 2`，得 `5*2*3//2 = 15`（5+10）；`f(7)` 的 `m = 1`，得 7。三者相加 40，而 `f(15)=f(21)=f(35)=f(105)=0`，最终 40，与示例一致。

```python
def f(k):
    m = n // k
    return k * m * (m + 1) // 2

return f(3) + f(5) + f(7) - f(15) - f(21) - f(35) + f(105)
```

注意 `f(105)` 这一项不能省：当 `n >= 105` 时，105 的倍数被三个集合各算一次、又被三个两两交集各减一次，净计数为 0，必须加回一次。

## 复杂度
时间：O(1)，七次整除和乘法，与 n 无关。
空间：O(1)，只用了 `m` 等几个临时整数。

## 易错点
- `n = 105` 时若漏掉 `+ f(105)`：105 被 3、5、7 各算一次（+3），又被 15、21、35 各减一次（-3），净贡献 0，答案会少 105。正确做法是补上 `+ f(105)`。
- `n = 7` 时若用 `range(1, n)` 枚举：会漏掉 7 本身，得到 14 而非 21。正确做法是枚举到 `n` 含端点，或直接用公式 `m = n // k`。

## 如果面试官追问
若把 3、5、7 换成任意 k 个除数，怎么改？答：对除数的每个非空子集求最小公倍数，按子集大小奇加偶减，共 2^k - 1 项。
