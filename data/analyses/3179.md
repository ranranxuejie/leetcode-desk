## 一句话思路
每轮更新就是一次前缀和，做 k 轮后取末位；等价于 a[n-1] 是 C(k+n-1, n-1) 的组合数。

## 怎么做
1. 直接模拟 k 轮前缀和，每轮对每个位置累加前一项，取模 `10**9+7`。
2. 用示例 n=4, k=5 走一遍：第 1 轮后 `[1,2,3,4]`，第 2 轮 `[1,3,6,10]`，第 5 轮 `[1,6,21,56]`，末位 56。
3. 关键中间值：第 4 轮末位是 35，第 5 轮 `a[3] = a[0]+a[1]+a[2]+a[3] = 1+5+15+35 = 56`，正是前缀和。
4. 若用组合数：答案 = C(k+n-1, n-1) mod M，n=4,k=5 即 C(8,3)=56，与模拟一致。

```python
MOD = 10**9 + 7
a = [1] * n
for _ in range(k):
    for i in range(1, n):
        a[i] = (a[i] + a[i-1]) % MOD
return a[n-1]
```

组合数写法（k、n 都 ≤1000，直接乘逆元）：

```python
MOD = 10**9 + 7
m = k + n - 1
r = n - 1
num = den = 1
for i in range(1, r + 1):
    num = num * (m - r + i) % MOD
    den = den * i % MOD
return num * pow(den, MOD - 2, MOD) % MOD
```

## 复杂度
时间：模拟 O(n·k)，组合数 O(n + log MOD)（快速幂求逆元）。
空间：模拟 O(n) 存数组，组合数 O(1) 额外空间。

## 易错点
- 输入 n=1, k=1000 → 模拟里 `range(1, 1)` 为空，数组始终 `[1]`，答案应为 1；若误把内层写成 `range(n)` 会把 `a[0]` 自加两次，得到错误值。
- 输入 n=1000, k=1000 → 组合数 C(1999,999) 极大，若中途不取模会得到天文数字；必须在每次乘 `num`、`den` 后都 `% MOD`，否则 Python 虽不溢出但结果对不上。

## 如果面试官追问
问：k 放大到 10^9 怎么办？
答：模拟 O(n·k) 会超时，改用组合数 C(k+n-1, n-1)，用 Lucas 定理或预处理阶乘逆元，O(n + log MOD) 即可。
