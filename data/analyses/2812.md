## 一句话思路
先多源 BFS 求出每个格子的安全值 `safe[r][c]`，再用最大堆按「路径最小安全值」贪心扩展，第一次到终点即为答案。

## 怎么做
1. 把所有 `grid[r][c] == 1` 的坐标入队，BFS 一层层外扩，`safe[r][c]` 记录到最近小偷的曼哈顿距离。
2. 以 `(0,0)` 起，堆里存 `(-safe, r, c)`，每次弹出当前路径瓶颈最大的格子。
3. 弹出即标记访问；若 `(r,c)` 是 `(n-1,n-1)` 直接返回 `-neg`。
4. 邻居入堆时取 `min(当前瓶颈, safe[nr][nc])`，保证堆顶始终是「已探索路径中最小安全值最大」的那条。

以示例 2 `grid = [[0,0,1],[0,0,0],[0,0,0]]` 为例：BFS 后 `safe[0][0] = 2`、`safe[0][2] = 0`、`safe[1][1] = 1`。堆首弹出 `(0,0)` 瓶颈 2，扩展 `(0,1)` 得 `min(2,1)=1`、`(1,0)` 得 `min(2,2)=2`；继续弹出 `(1,0)` 瓶颈 2，最终到 `(2,2)` 时瓶颈仍是 2，返回 2。

```python
from collections import deque
import heapq

n = len(grid)
safe = [[-1] * n for _ in range(n)]
q = deque()
for r in range(n):
    for c in range(n):
        if grid[r][c] == 1:
            safe[r][c] = 0
            q.append((r, c))
while q:
    r, c = q.popleft()
    for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
        nr, nc = r + dr, c + dc
        if 0 <= nr < n and 0 <= nc < n and safe[nr][nc] == -1:
            safe[nr][nc] = safe[r][c] + 1
            q.append((nr, nc))

heap = [(-safe[0][0], 0, 0)]
seen = {(0, 0)}
while heap:
    neg, r, c = heapq.heappop(heap)
    if (r, c) == (n - 1, n - 1):
        return -neg
    for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
        nr, nc = r + dr, c + dc
        if 0 <= nr < n and 0 <= nc < n and (nr, nc) not in seen:
            seen.add((nr, nc))
            heapq.heappush(heap, (max(neg, -safe[nr][nc]), nr, nc))
```

## 复杂度
时间：BFS 与堆各 O(n² log n)，堆操作贡献 log n。
空间：`safe` 与 `seen` 各 O(n²)，堆最坏 O(n²)。

## 易错点
- 起点 `(0,0)` 本身是 1（如示例 1）→ 若先判终点再算 `safe` 会漏掉起点安全值为 0，答案错成 1；正确做法是 BFS 初始化时把起点也置 0，堆首瓶颈直接为 0。
- 邻居入堆用 `max(neg, -safe[nr][nc])` 而非直接 `-safe[nr][nc]` → 否则路径瓶颈会被后一个格子的安全值覆盖，示例 2 中 `(0,1)` 安全值 1 会盖掉起点 2，答案错成 1；正确做法是取两者较大（负值下即较小瓶颈）。

## 如果面试官追问
若要求输出具体路径而非仅安全值？答：在堆元素里额外存父指针或路径列表，弹出终点时回溯即可，空间多 O(n²)。
