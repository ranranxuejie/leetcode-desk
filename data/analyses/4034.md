## 一句话思路
象每步保持 `r+c` 或 `r-c` 不变，所以先判两格是否同色，再判是否同一条对角线，否则两步必达。

## 怎么做
1. 算 `d1 = (sr + sc) - (tr + tc)` 和 `d2 = (sr - sc) - (tr - tc)`，象一步只能改一个对角线和，故 `d1` 与 `d2` 奇偶性必须相同。
2. 若 `(sr + sc) % 2 != (tr + tc) % 2`，两格异色，返回 `-1`。
3. 若 `d1 == 0 or d2 == 0`，已在同一对角线，返回 `1`。
4. 否则同色不同对角线，返回 `2`。

以示例 2 `source = [4,2], target = [1,3]` 为例：`sr+sc = 6`、`tr+tc = 4`，`d1 = 2`；`sr-sc = 2`、`tr-tc = -2`，`d2 = 4`。两者都是偶数，同色；`d1`、`d2` 均非 0，故答案是 `2`，与题解路径 (4,2)→(3,1)→(1,3) 一致。

```python
def minBishopMoves(source, target):
    sr, sc = source
    tr, tc = target
    if (sr + sc) % 2 != (tr + tc) % 2:
        return -1
    if sr + sc == tr + tc or sr - sc == tr - tc:
        return 1
    return 2
```

关键点：`sr - sc` 与 `tr - tc` 相等表示同一条「副对角线」，`sr + sc == tr + tc` 表示同一条「主对角线」，两者只要命中一个就是一步。

## 复杂度
时间：O(1)，只做四次加减和两次取模，与棋盘大小无关。
空间：O(1)，只用了 `d1`、`d2` 两个临时整数。

## 易错点
- 输入 `source = [1,1], target = [3,4]` → 若只判对角线相等就返回 `2`，会错成 `2`；正确做法是先判 `(1+1)%2 = 0` 与 `(3+4)%2 = 1` 不等，直接返回 `-1`。
- 输入 `source = [8,1], target = [1,8]` → 若把 `sr - sc` 与 `tr - tc` 的符号写反（如用 `sc - sr`），`d2` 变成 `7` 与 `-7`，会漏判一步、错答 `2`；正确做法是统一用 `行 - 列` 或统一用 `列 - 行`，两边一致即可。

## 如果面试官追问
若棋盘不是 8×8 而是任意 `n×m`，答案会变吗？答：不会，同色判据和两条对角线判据与边界无关，仍是 `-1/1/2`，因为两步之内总能找到交点且交点必在棋盘内（对角线的交点由两格坐标唯一确定）。
