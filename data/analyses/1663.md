## 一句话思路
从右往左贪心填：每位置尽量放 `'a'`，把剩余数值全压给最靠右的字符，字典序自然最小。

## 怎么做
1. 先给 n 个位置全填 `'a'`，此时总和为 n，还差 `k - n` 要补。
2. 从最右位开始，每位最多能加 `25`（`'a'`→`'z'`），把 `min(25, 剩余)` 加到这个位置。
3. 剩余减掉刚加的量，继续往左走，直到剩余为 0。
4. 因为补的量优先堆在最右边，左边尽量保持 `'a'`，前缀最小 → 字典序最小。

以 `n = 3, k = 27` 为例：初始 `['a','a','a']`，`剩余 = 27 - 3 = 24`。最右位加 `min(25,24)=24`，变成 `'y'`（1+24=25），剩余归 0，结果 `"aay"`。

```python
res = ['a'] * n
rem = k - n
i = n - 1
while rem > 0:
    add = min(25, rem)
    res[i] = chr(ord('a') + add)
    rem -= add
    i -= 1
return ''.join(res)
```

关键中间值：`rem` 从 24 一步变 0，`res[2]` 由 `'a'` 变 `'y'`，`i` 只走到 2 就停。

## 复杂度
时间：O(n)，循环最多走 n 个位置，每步 O(1)。
空间：O(n)，`res` 列表存 n 个字符，无其他额外结构。

## 易错点
- `n = 1, k = 26` → 若从左边开始贪心填 `'z'`，会得到 `"z"` 但剩余没处放或越界；正确做法是 `rem = 25`，最右位（也是唯一位）加 25 得 `'z'`，一步到位。
- `n = 5, k = 73` → 若每位平均分配（73/5≈14）会得到类似 `"nnnnn"` 的错误串；正确做法是 `rem = 68`，从右往左：`'z'`(25)、`'z'`(25)、`'s'`(18)，剩 0，得 `"aaszz"`，左边两位保持 `'a'`。

## 如果面试官追问
问：若要求返回所有满足条件的字符串中字典序第 m 小？
答：先按上述贪心定位前缀，再对剩余可分配量做组合计数逐位确定，复杂度升到 O(n·26)。
