## 一句话思路
从左到右扫描，用 26 个栈按字母存下标，遇到 `*` 就删当前最小的非空字母栈顶，最后按下标重建字符串。

## 怎么做
1. 建 `pos = [[] for _ in range(26)]`，遍历 `s`，字母 `c` 把下标压入 `pos[ord(c)-97]`，`*` 则从 `'a'` 往上找第一个非空栈，弹出栈顶。
2. 被弹出的下标记入 `deleted` 集合，`*` 的下标也记入。
3. 以 `s = "aaba*"` 为例：扫到 `*` 时 `pos[0] = [0,1,3]`，弹出 `3`，`deleted = {3,4}`。
4. 最后按 `i not in deleted` 拼接，得 `"aab"`。

```python
pos = [[] for _ in range(26)]
deleted = set()
for i, c in enumerate(s):
    if c == '*':
        deleted.add(i)
        for k in range(26):
            if pos[k]:
                deleted.add(pos[k].pop())
                break
    else:
        pos[ord(c) - 97].append(i)
return ''.join(c for i, c in enumerate(s) if i not in deleted)
```

关键点：`*` 只能删它**左边**的字符，所以必须边扫边弹，不能先收集所有 `*` 再统一处理。

## 复杂度
时间 O(26n)：每个字符最多入栈出栈一次，每次 `*` 最多扫 26 个字母桶。
空间 O(n)：`pos` 存所有字母下标，`deleted` 最多 n 个元素。

## 易错点
- 输入 `"a*b*"` → 若先处理第二个 `*` 再处理第一个，会删掉 `b` 导致结果错 → 必须严格从左到右，每个 `*` 只在其左侧已扫过的字符里选最小。
- 输入 `"abac*"` → 若用单个栈只记「当前最小」而不分字母桶，遇到 `*` 时可能删掉 `c` 而非 `a` → 必须按 26 个字母分桶，从 `'a'` 起找第一个非空桶，保证删的是字典序最小的。

## 如果面试官追问
若要求返回删除方案（哪些下标被删）？答：`deleted` 集合本身就是方案，按 `*` 出现顺序记录每次弹出的下标即可。
