## 一句话思路
一次遍历，用 `res` 记录结果，只有当 `res` 末尾已有两个相同字符且当前字符与之相同时才跳过。

## 怎么做
1. 初始化空列表 `res`，遍历 `s` 中每个字符 `c`。
2. 若 `len(res) >= 2 and res[-1] == c and res[-2] == c`，说明加入 `c` 会形成三连，跳过。
3. 否则把 `c` 追加进 `res`。
4. 最后 `"".join(res)` 返回。

以 `s = "aaabaaaa"` 为例：前两个 `a` 都进 `res`，第三个 `a` 时 `res[-1] == res[-2] == 'a'`，跳过；接着 `b` 进；后面四个 `a` 中只有前两个能进，后两个被跳过，最终 `res = ['a','a','b','a','a']`。

```python
res = []
for c in s:
    if len(res) >= 2 and res[-1] == c and res[-2] == c:
        continue
    res.append(c)
return "".join(res)
```

关键点：判断的是**结果串末尾**是否已有两个相同字符，而不是原串中连续出现了几个。因为删除后原本不相邻的相同字符可能拼到一起，只看原串的连续段长度会漏判。

## 复杂度
时间：O(n)，n 为 `s` 长度，每个字符最多访问一次。
空间：O(n)，`res` 列表最多存 n 个字符。

## 易错点
- 输入 `s = "aaabaaaa"` → 若只按原串连续段计数（第一段 3 个删 1、第二段 4 个删 2）会得到错误结果，因为两段之间隔着 `b` 不会合并，但若输入是 `"aabaa"` 这类删除后可能拼接的情况，必须用结果串末尾判断。正确做法是始终检查 `res[-1]` 和 `res[-2]`。
- 输入 `s = "a"` 或 `"aa"` → 若在循环里无条件访问 `res[-2]` 会越界（Python 中 `res[-2]` 对长度 1 的列表会抛 IndexError）。正确做法是先判断 `len(res) >= 2` 再比较。

## 如果面试官追问
问：如果要求返回删除字符的最小数量而不是结果串？
答：遍历时统计被 `continue` 跳过的次数即可，逻辑不变，额外一个计数器。
