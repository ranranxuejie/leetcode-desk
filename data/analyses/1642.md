## 一句话思路
维护一个最小堆存已用梯子跳过的高度差，砖块先垫付，堆超 `ladders` 就把最小的差换成砖块。

## 怎么做
1. 遍历相邻高度差 `diff = heights[i+1] - heights[i]`，`diff <= 0` 直接跳过。
2. 每个正的 `diff` 先入堆并扣砖块 `bricks -= diff`。
3. 堆大小超过 `ladders` 时，弹出最小差 `d`，把砖块还回去 `bricks += d`（即这一跳改用梯子）。
4. 若 `bricks < 0`，说明第 `i+1` 栋到不了，返回 `i`。

以示例 1 `heights = [4,2,7,6,9,14,12], bricks = 5, ladders = 1` 为例：到 `i=1` 时 `diff = 7-2 = 5`，堆 `[5]`、`bricks = 0`；到 `i=3` 时 `diff = 9-6 = 3`，堆 `[3,5]` 超容量，弹出 `3`，`bricks = 3`；到 `i=4` 时 `diff = 14-9 = 5`，堆 `[5,5]` 再弹 `5`，`bricks = 3-5 = -2 < 0`，返回 `4`。

```python
import heapq
heap = []
for i in range(len(heights) - 1):
    diff = heights[i + 1] - heights[i]
    if diff <= 0:
        continue
    heapq.heappush(heap, diff)
    bricks -= diff
    if len(heap) > ladders:
        bricks += heapq.heappop(heap)
    if bricks < 0:
        return i
return len(heights) - 1
```

关键点：堆里始终是「当前已用梯子」的那些差，且是最小的 `ladders` 个被踢出去换成砖块——梯子留给最大的差才最省砖。

## 复杂度
时间 O(n log ladders)：遍历 n 个高度差，每次堆操作 O(log ladders)。
空间 O(ladders)：堆最多存 `ladders + 1` 个元素。

## 易错点
- `ladders = 0`（示例 3）时，堆每加一个就立刻弹出，等价于全用砖块；若写成「先判断 `len(heap) > ladders` 再 push」会漏掉这次兑换，`bricks` 少还一笔导致提前返回。
- 下降或平路 `diff <= 0` 若也入堆，堆里混入 0 和负数，弹出时 `bricks += 0` 白占一个梯子名额，示例 1 的 `4→2` 会让 `ladders = 1` 被浪费在 `diff = -2` 上。

## 如果面试官追问
要求输出具体方案（哪几跳用梯子）怎么办？答：堆里存 `(diff, i)`，最终堆中剩下的下标就是梯子所在跳，其余正差用砖块。
