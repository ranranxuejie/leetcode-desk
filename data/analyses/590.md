## 一句话思路
用「根-右-左」的逆序压栈遍历，最后整体反转，等价于后序（子-根）。

## 怎么做
1. 空树直接返回 `[]`，否则把 `root` 压入栈 `st`。
2. 循环弹栈：弹出节点就把 `val` 追加到 `res`，再按原顺序把 `children` 全部压栈。
3. 因为栈后进先出，子节点会以逆序被访问，得到的是「根-子逆序」，即根-右-左。
4. 遍历结束后 `res.reverse()`，得到子-根的后序。

以示例 1 的 `root = [1,null,3,2,4,null,5,6]` 为例：先弹 `1`，`res=[1]`，压入 `3,2,4`；弹 `4`，`res=[1,4]`；弹 `2`，`res=[1,4,2]`；弹 `3`，`res=[1,4,2,3]`，压入 `5,6`；弹 `6`、`5`，`res=[1,4,2,3,6,5]`；反转得 `[5,6,3,2,4,1]`。

```python
if not root:
    return []
st, res = [root], []
while st:
    node = st.pop()
    res.append(node.val)
    for c in node.children:
        st.append(c)
res.reverse()
return res
```

递归写法只需三行：对每个 `c in root.children` 递归，再 `res.append(root.val)`。迭代法省掉递归深度 1000 的栈风险，但要注意反转这一步不能漏。

## 复杂度
时间 O(n)：每个节点入栈出栈各一次，反转再扫一遍。
空间 O(n)：栈最坏存一层所有节点，`res` 存 n 个值。

## 易错点
- 输入 `root = []`（节点总数可为 0）→ 直接 `st=[root]` 会弹 `None` 报 `AttributeError` → 开头必须 `if not root: return []`。
- 压子节点时若写成 `for c in reversed(node.children)` → 示例 1 会得到 `[6,5,3,2,4,1]`，子节点顺序反了 → 必须按 `children` 原顺序 `append`，让栈自己完成逆序。

## 如果面试官追问
问：不用反转，能否一遍得到后序？
答：栈里存 `(node, visited)`，第二次弹出时才写 `val`，用标记位区分首次访问和子节点处理完。
