## 一句话思路
先用哈希表把 mat 每个值映射到 (行,列)，再顺序遍历 arr 累加行列计数，某行或某列计数满即返回当前下标。

## 怎么做
1. 遍历 mat，建 `pos[值] = (r, c)`，值域是 1..m*n，也可用数组代替字典。
2. 开 `row = [0]*m`、`col = [0]*n`，记录每行每列已涂格数。
3. 顺序遍历 arr，对 `arr[i]` 取 `(r,c)`，`row[r] += 1`、`col[c] += 1`。
4. 若 `row[r] == n` 或 `col[c] == m`，立刻返回 `i`。

以示例 1 为例，`mat = [[1,4],[2,3]]`，建表后 `pos = {1:(0,0), 4:(0,1), 2:(1,0), 3:(1,1)}`。遍历到 `i=2`、`arr[2]=4` 时，`row[0]` 由 1 变 2，等于列数 n=2，返回 2。

```python
pos = {}
for r in range(m):
    for c in range(n):
        pos[mat[r][c]] = (r, c)
row, col = [0] * m, [0] * n
for i, v in enumerate(arr):
    r, c = pos[v]
    row[r] += 1
    col[c] += 1
    if row[r] == n or col[c] == m:
        return i
```

关键点：判定条件是「计数等于该方向的长度」，不是「大于等于」；因为每个格子只涂一次，计数单调加一，第一次相等就是答案。

## 复杂度
时间 O(m*n)：建表扫一遍 mat，遍历 arr 也是 m*n 次，每次 O(1)。
空间 O(m*n)：pos 存 m*n 个坐标，另开长度 m、n 的两个计数数组。

## 易错点
- 把判定写成 `row[r] == m`：行方向应满 n 列、列方向应满 m 行，示例 1 中 `row[0]` 到 2 就该返回，写成 m=2 恰好也对，但示例 2 的 3x3 会掩盖错误，换非方阵如 2x3 立刻错。正确做法是行比 n、列比 m。
- 边涂边判 vs 涂完再判：若在 `row[r] += 1` 之前判断，示例 1 的 `i=2` 时 `row[0]` 还是 1，会漏掉答案返回 3。必须先自增再比较。

## 如果面试官追问
问：若 arr 只含部分整数、可能无解怎么办？
答：循环结束后返回 -1，计数逻辑不变，只是不保证命中。
