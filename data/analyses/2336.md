## 一句话思路
用一个指针 `cur` 指向无限集中尚未被弹出的最小数，再用小根堆 `heap` 加集合 `added` 存被 `addBack` 回来的数，每次取两者较小者。

## 怎么做
1. 初始化 `cur = 1`，`heap = []`，`added = set()`。
2. `addBack(num)`：仅当 `num < cur` 且 `num not in added` 时入堆并记入 `added`；`num >= cur` 说明它本来就在无限集里，直接忽略。
3. `popSmallest()`：若堆非空且 `heap[0] < cur`，弹出堆顶并从 `added` 移除；否则返回 `cur` 后 `cur += 1`。
4. 关键中间值：示例中连续弹出 1、2、3 后 `cur == 4`；此时 `addBack(1)` 使 `heap == [1]`、`added == {1}`，下一次 `popSmallest` 因 `heap[0]=1 < cur=4` 返回 1，再下一次堆空，返回 `cur=4`。

```python
import heapq

def addBack(self, num):
    if num < self.cur and num not in self.added:
        heapq.heappush(self.heap, num)
        self.added.add(num)

def popSmallest(self):
    if self.heap and self.heap[0] < self.cur:
        x = heapq.heappop(self.heap)
        self.added.remove(x)
        return x
    self.cur += 1
    return self.cur - 1
```

## 复杂度
时间：每次 `popSmallest`/`addBack` 为 O(log k)，k 是堆中元素个数，k ≤ 1000。
空间：O(k)，堆与 `added` 各存一份被加回的数，`cur` 是 O(1)。

## 易错点
- 对 `addBack(2)` 在 `cur=1` 时直接入堆：2 本来就在无限集中，堆里多出一个 2，之后 `popSmallest` 会先返回 1 再返回堆里的 2，看似对，但若先弹出过 2（`cur` 已到 3）再 `addBack(2)`，重复入堆会让 2 被返回两次。正确做法是入堆前判 `num < cur` 且 `num not in added`。
- 弹出堆顶后忘记 `added.remove(x)`：之后 `addBack(x)` 会被 `x in added` 挡掉，x 永久丢失。示例中弹出 1 后若不清 `added`，再 `addBack(1)` 就加不回来，输出变成 4、5、6。

## 如果面试官追问
问：若 `num` 上限放大到 10^9、调用次数到 10^5 呢？
答：本解与 `num` 大小无关，只与调用次数有关，仍是 O(log k)，无需改动。
