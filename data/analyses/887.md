## 一句话思路
反过来定义 `dp[t][e]` = t 次操作、e 枚蛋最多能确定多少层，再二分最小的 t 使 `dp[t][k] >= n`。

## 怎么做
1. 状态转移：`dp[t][e] = dp[t-1][e-1] + dp[t-1][e] + 1`，碎掉的那枚往下查、没碎的往上查，加 1 是当前这层本身。
2. 边界：`dp[t][0] = 0`（没蛋查不了），`dp[0][e] = 0`（没次数查不了），`e >= t` 时退化为 `2**t - 1`。
3. 对 t 二分：上界取 `n`（一枚蛋逐层扔必能确定），下界 1，找第一个 `dp[t][k] >= n`。
4. 用一维滚动数组按 t 递增更新，`e` 从 k 倒序或正序都行（依赖的是上一轮 t-1 的值）。

以 `k=2, n=6` 为例：t=1 时 `dp[1][2]=1`；t=2 时 `dp[2][2]=dp[1][1]+dp[1][2]+1=1+1+1=3`；t=3 时 `dp[3][2]=3+3+1=7 >= 6`，返回 3。

```python
def superEggDrop(k, n):
    lo, hi = 1, n
    while lo < hi:
        mid = (lo + hi) // 2
        prev = [0] * (k + 1)
        for _ in range(mid):
            cur = [0] * (k + 1)
            for e in range(1, k + 1):
                cur[e] = prev[e - 1] + prev[e] + 1
            prev = cur
        if prev[k] >= n:
            hi = mid
        else:
            lo = mid + 1
    return lo
```

## 复杂度
时间：二分 `log n` 轮，每轮 `mid * k` 次转移，约 `O(k * n * log n)`。
空间：滚动数组 `prev/cur` 各 `k+1`，`O(k)`。

## 易错点
- `k=1, n=2`：若直接套 `dp[t][e]` 转移却把 `dp[t][0]` 初始化成 1，会算出 t=1 就够，错答 1；正确是 `dp[t][0]=0`，答案 2。
- `k=3, n=14`：若二分上界取 `k` 或某个小常数，`dp[3][3]=7 < 14` 会越界或死循环；上界必须取 `n`，答案 4。

## 如果面试官追问
问：n 放大到 10^9 怎么办？
答：t 的上界仍是 `k*log n` 量级，二分 t 后单次判定用 `dp[t][e]` 递推，复杂度 `O(k * t)`，不随 n 线性增长。
