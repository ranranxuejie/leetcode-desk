## 一句话思路
把四条车道当前队首的「出车组合」预处理成合法掩码，再对四个队列长度做记忆化 DP，每步枚举合法掩码。

## 怎么做
1. 把 `directions[i]` 反转，使队尾是最近路口的车，用 `pop()` 取车。
2. 预处理 16 个掩码：对每个掩码取四车道的队首字符，检查「每车道最多出一辆」（掩码本身保证）、「每车道最多进一辆」（按目标方向计数 ≤1）、「路线不相交」（用固定冲突表判断）。
3. 记忆化搜索 `dfs(state)`，`state` 是四个队列剩余长度，枚举所有合法掩码，取 `1 + min(dfs(next))`。

以示例 2 `directions = ["NS","WE","SE","EW"]` 为例，反转后队首分别是 `S`、`E`、`E`、`W`。掩码 `1111` 对应四车同时出：目标方向为 `S`、`E`、`E`、`W`，`E` 出现两次，违反「一个方向只允许驶入一辆」，所以第 1 秒不能四车齐出，只能选子集，最终 3 秒走完。

```python
conflict = {(0,1),(1,0),(0,3),(3,0),(1,2),(2,1),(2,3),(3,2)}  # 相邻方向直行冲突
def ok(mask, heads):
    dst = []
    for i in range(4):
        if mask >> i & 1:
            dst.append(heads[i])
    if len(set(dst)) < len(dst):
        return False
    for a in range(len(dst)):
        for b in range(a+1, len(dst)):
            if (dst[a], dst[b]) in conflict:
                return False
    return True
```

## 复杂度
时间：状态数 `21^4 ≈ 1.9e5`，每状态枚举 16 掩码，`O(16 · 21^4)`。
空间：记忆化字典存 `21^4` 个状态，加四个队列，`O(21^4)`。

## 易错点
- 输入 `["W","N","ES","W"]`：若把 `directions[i]` 正序当队首，第 1 秒会取到 `W` 而不是 `E`，答案错成 3；正确做法是反转字符串，`pop()` 取最近路口的车。
- 输入 `["NS","WE","SE","EW"]`：若只检查「每车道出一辆」而不检查目标方向重复，掩码 `1111` 会被判合法，第 1 秒四车齐出，答案错成 2；正确做法是按目标方向 `S/E/E/W` 计数，`E` 重复即非法。

## 如果面试官追问
若要求输出每秒的具体调度方案而非最少秒数？答：在 `dfs` 里额外记录每步选中的掩码，回溯时沿 `choice` 链还原即可，状态空间不变。
