## 一句话思路
枚举多重集大小 m，只要 `m*k <= num` 且 `(num - m*k) % 10 == 0` 就成立，取最小 m。

## 怎么做
1. 特判 `num == 0` 直接返回 0（空集合法）。
2. 从 m = 1 枚举到 10：每个数至少是 k（个位为 k 的最小正整数），所以 m 个数的和至少 `m*k`。
3. 关键：把每个数写成 `k + 10*t_i`，总和 `num = m*k + 10*Σt_i`，于是只需 `num - m*k` 是 10 的非负倍数，就能把差值全塞进某一个数里。
4. 为什么枚举到 10 就够：m 与 m+10 的 `(num - m*k) % 10` 相同，若前 10 个都不行则永远不行。

以 `num = 58, k = 9` 为例：m=1 时 `58-9=49`，`49 % 10 = 9` 不行；m=2 时 `58-18=40`，`40 % 10 == 0` 成立，返回 2（对应 [9,49]）。

```python
if num == 0:
    return 0
for m in range(1, 11):
    rest = num - m * k
    if rest >= 0 and rest % 10 == 0:
        return m
return -1
```

注意 `k = 0` 时每个数形如 10,20,...，m 个数和必是 10 的倍数，上面公式 `num - 0` 恰好退化成 `num % 10 == 0`，无需单独分支。

## 复杂度
时间：O(1)，固定枚举 10 次，与 num 无关。
空间：O(1)，只用 m、rest 两个变量。

## 易错点
- `num = 37, k = 2`：若只判断 `num % 10 == k` 就返回 1，会漏掉多元素情形；正确做法是逐个 m 检查 `(num - m*k) % 10`，这里 m=1..10 全不满足，返回 -1。
- `num = 5, k = 9`：若忘记 `rest >= 0` 判断，m=1 时 `5-9 = -4`，`-4 % 10 == 6` 在 Python 里不为 0 侥幸不中，但 `num = 3, k = 3` 时 m=2 得 `3-6 = -3`，`-3 % 10 = 7` 也不中；真正危险的是 `num = 10, k = 5`，m=1 得 5 不中，m=2 得 0 中，返回 2 正确——但若写成 `rest % 10 == 0` 而漏掉非负，`num = 4, k = 9` 时 m=1 得 -5，`-5 % 10 = 5` 不中，仍安全；所以真正必须写 `rest >= 0` 的场景是 `num = 0` 已被特判后的边界，建议保留以防 `k > num` 时误判。

## 如果面试官追问
问：要求输出具体方案怎么办？
答：m 确定后令 `t = (num - m*k) // 10`，方案是 `[k + 10*t] + [k]*(m-1)`，一个数吸收全部差值。
