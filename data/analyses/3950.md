## 一句话思路
用 `n & (n >> 1)` 把每对相邻置位压成一个 1，再判断结果是否恰好是 2 的幂（即只有一个 1）。

## 怎么做
1. 令 `pairs = n & (n >> 1)`：`n >> 1` 右移后与原数按位与，只有原本相邻的两个 1 才会在结果里留下一个 1。
2. 检查 `pairs` 是否恰有一个 1：`pairs != 0 and pairs & (pairs - 1) == 0`。
3. 两个条件缺一不可：`pairs == 0` 表示没有相邻对（如 `n = 5`），`pairs & (pairs - 1) != 0` 表示至少两对。

以 `n = 6`（二进制 `110`）为例：`n >> 1 = 3`（`011`），`pairs = 6 & 3 = 2`（`010`），非零且 `2 & 1 == 0`，返回 `True`。

```python
def consecutive_set_bits(n):
    pairs = n & (n >> 1)
    return pairs != 0 and (pairs & (pairs - 1)) == 0
```

关键点：`pairs` 的每一位对应「原数该位和它右边一位是否同时为 1」，所以 `pairs` 的 1 的个数就是相邻对的对数。`n = 7`（`111`）时 `pairs = 7 & 3 = 3`（`011`），有两个 1，`3 & 2 = 2 != 0`，正确返回 `False`。

## 复杂度
时间：O(log n)，`n >> 1` 与按位与都只扫一遍二进制位数。
空间：O(1)，只开了 `pairs` 一个临时整数。

## 易错点
- `n = 3`（`11`）→ 若只写 `pairs != 0` 就返回 `True`，但 `n = 7`（`111`）也会通过，错成 `True`；必须再加 `pairs & (pairs - 1) == 0` 排除多对。
- `n = 0` 或 `n = 1` → `pairs = 0`，若漏掉 `pairs != 0` 直接算 `pairs & (pairs - 1)`，`0 & -1 == 0` 会误判为 `True`；正确做法是先判非零。

## 如果面试官追问
问：如果要求返回相邻对的具体位置怎么办？
答：遍历 `i` 从 0 到 `n.bit_length()`，检查 `(n >> i) & 3 == 3` 收集下标即可，时间仍是 O(log n)。
