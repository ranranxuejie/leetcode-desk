## 一句话思路
先让 x 继承 num1 的全部 1 位，再用剩余置位数从低位补 1，因为异或为 0 的位代价最低。

## 怎么做
1. 用 `num2.bit_count()` 得到目标置位数 `k`，用 `num1.bit_count()` 得到已占位数 `c`。
2. 若 `c >= k`，从 num1 的低位起清掉 `c - k` 个 1，高位 1 保留。
3. 若 `c < k`，保留 num1 全部 1 位，再从最低的 0 位起补 `k - c` 个 1。
4. 返回构造出的 x。

以 `num1 = 1, num2 = 12` 为例：`k = 2`，`c = 1`，num1 的 1 位在 bit0，需补 1 个 1，最低的 0 位是 bit1，故 x = `0b11` = 3，`3 XOR 1 = 2`。

```python
k = num2.bit_count()
c = num1.bit_count()
x = num1
if c > k:
    for i in range(32):
        if k == c:
            break
        if x >> i & 1:
            x ^= 1 << i
            c -= 1
else:
    i = 0
    while c < k:
        if not (x >> i & 1):
            x |= 1 << i
            c += 1
        i += 1
```

关键点：清 1 时从低位清，因为低位 1 对异或值的贡献小；补 1 时也从低位补，同理。

## 复杂度
时间：O(32)，固定扫描 32 个二进制位，与 num1、num2 大小无关。
空间：O(1)，只开了 `k`、`c`、`x`、`i` 几个整型变量。

## 易错点
- `num1 = 3, num2 = 5`（k=2, c=2）→ 若误判为需要补位而进入 else 分支，会多补 1 位得到 7 → 正确做法是先比较 `c` 与 `k`，相等时直接返回 num1。
- `num1 = 7, num2 = 1`（k=1, c=3）→ 若从高位清 1，会得到 `0b011`=3，异或值 4；从低位清得到 `0b100`=4，异或值 3 → 正确做法是清 1 必须从最低位开始，因为清低位 1 对异或值增量更小。

## 如果面试官追问
若 num1、num2 上限提到 10^18 怎么办？答：循环上界从 32 改成 64，或直接用 `while` 扫到 `c == k` 为止，逻辑不变。
