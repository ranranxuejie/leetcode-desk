## 一句话思路
用 `head` 记录当前序列首元素、`step` 记录相邻元素间隔、`rem` 记录剩余个数，按删除方向决定是否右移 `head`，每轮 `step *= 2`。

## 怎么做
1. 初始化 `head = 1, step = 1, rem = n, left = True`，`head` 始终是当前序列第一个真实值。
2. 每轮删除后 `rem //= 2`；若本轮从左侧删（`left` 为真），首元素必被保留，`head` 不动。
3. 若本轮从右侧删，则仅当 `rem` 为奇数时首元素会被删掉，此时 `head += step`。
4. 翻转 `left`、`step *= 2`，直到 `rem == 1` 返回 `head`。

以 `n = 8` 走一遍：初始 `head=1, step=1, rem=8`。第 1 轮左侧删，`rem=4`，`head` 仍为 1，`step=2`；第 2 轮右侧删，`rem=2` 是偶数，首元素 1 保留，`head=1`，`step=4`；第 3 轮左侧删，`rem=1`，返回 `head=1`？这与示例不符——问题在第 2 轮：右侧删时序列是 `[1,3,5,7]`，删掉的是 1 和 5，首元素被删，`rem=4` 是偶数却要右移。修正判据：右侧删时，若 `rem` 为**偶数**则首元素被删（因为从右往左隔一个删，右端先删，偶数个时左端也被删）。重走：第 2 轮 `rem=4` 偶数 → `head=1+2=3`，`step=4`；第 3 轮左侧删 `rem=2`，`head=3` 不动，`step=8`；第 4 轮右侧删 `rem=1` 奇数 → `head` 不动，返回 3。正确。

```python
head, step, rem, left = 1, 1, n, True
while rem > 1:
    if not left and rem % 2 == 0:
        head += step
    rem //= 2
    step *= 2
    left = not left
return head
```

## 复杂度
时间：O(log n)，每轮 `rem` 减半，最多约 50 轮（n ≤ 10^15）。
空间：O(1)，只开了 `head/step/rem/left` 四个变量。

## 易错点
- `n = 8` 第 2 轮右侧删时误判「`rem` 偶数则首元素保留」→ 得到 1 而非 3。正确判据是右侧删且 `rem` 为偶数时 `head += step`，因为右端先删、偶数个时左端也被波及。
- `n = 5` 第 2 轮右侧删，`rem=3` 为奇数，首元素 1 保留；若写成「右侧删一律 `head += step`」→ 得到 3 而非 1。奇数个时右端删完左端恰好留下。

## 如果面试官追问
问：若要求返回删除过程中每一步剩下的序列？答：不能只维护 `head`，需显式模拟数组，时间退化到 O(n log n)，n 大时不可行。
