## 一句话思路
逐行数 1 的个数，用严格大于更新最优，天然保留最小行下标。

## 怎么做
1. 初始化 `best_row = 0`、`best_cnt = -1`，让第 0 行无论几个 1 都能刷新。
2. 用 `enumerate(mat)` 同时拿到行下标 `i` 和行 `row`，对每行算 `cnt = row.count(1)`。
3. 只在 `cnt > best_cnt` 时更新 `best_row, best_cnt = i, cnt`，用严格大于而非 `>=`。
4. 返回 `[best_row, best_cnt]`。

以示例 1 `mat = [[0,1],[1,0]]` 为例：第 0 行 `cnt = 1`，`1 > -1` 成立，`best_row = 0, best_cnt = 1`；第 1 行 `cnt = 1`，`1 > 1` 不成立，不更新，最终返回 `[0,1]`。若这里写成 `>=`，第 1 行就会把 `best_row` 覆盖成 1，答案错成 `[1,1]`。

```python
best_row, best_cnt = 0, -1
for i, row in enumerate(mat):
    cnt = row.count(1)
    if cnt > best_cnt:
        best_row, best_cnt = i, cnt
return [best_row, best_cnt]
```

`row.count(1)` 是 C 层循环，比手写 `sum(x == 1 for x in row)` 快，且不会把 `True` 和 `1` 混淆（本题元素就是整数 0/1，两者等价，但 `count` 更短）。`best_cnt` 初值取 `-1` 而不是 `0`，是因为全 0 矩阵时每行 `cnt = 0`，若初值为 0 则一次都不更新，`best_row` 恰好还是 0，答案碰巧对；但用 `-1` 语义更干净——保证第 0 行一定被写入一次。

## 复杂度
时间 O(m·n)：每行 `count` 扫 n 个元素，共 m 行。
空间 O(1)：只开了 `best_row`、`best_cnt`、`cnt` 三个标量。

## 易错点
- 输入 `mat = [[0,1],[1,0]]` → 若写成 `if cnt >= best_cnt`，第 1 行会覆盖第 0 行，返回 `[1,1]` → 必须用严格大于 `>`，才能保证并列时保留最小下标。
- 输入 `mat = [[0,0],[0,0]]` → 若把 `best_cnt` 初值设成 `0` 且用 `>`，循环体一次都不执行，虽然 `best_row` 默认 0 侥幸正确，但一旦把初值写成 `best_row = -1` 就会返回 `[-1,0]` → 初值取 `best_cnt = -1`，让第 0 行无条件写入。

## 如果面试官追问
追问：若矩阵每行是「0 在前 1 在后」的有序行，能否更快？
答：每行二分找第一个 1 的位置，O(m log n)，但本题 n ≤ 100，`count` 已足够。
