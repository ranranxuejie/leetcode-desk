## 一句话思路
对区间 `[lo, hi]` 枚举根 `i`，递归取左 `[lo,i-1]`、右 `[i+1,hi]` 的所有树做笛卡尔积，天然覆盖全部 BST。

## 怎么做
1. 定义 `build(lo, hi)` 返回该区间能生成的所有树根列表，`lo > hi` 时返回 `[None]`（不是空列表）。
2. 枚举根值 `i` 从 `lo` 到 `hi`，递归拿到 `lefts = build(lo, i-1)` 和 `rights = build(i+1, hi)`。
3. 双重循环把每个 `l` 和每个 `r` 拼成 `TreeNode(i, l, r)` 收进结果。
4. 主函数返回 `build(1, n)`。

以 `n = 3` 为例，`i = 2` 时 `lefts = build(1,1) = [节点1]`，`rights = build(3,3) = [节点3]`，笛卡尔积只产生 `[2,1,3]` 这一棵；而 `i = 1` 时 `lefts = [None]`、`rights = build(2,3)` 有 `[2,null,3]` 和 `[3,2]` 两棵，于是得到 `[1,null,2,null,3]` 和 `[1,null,3,2]`。5 棵正好对上示例。

```python
def build(lo, hi):
    if lo > hi:
        return [None]
    res = []
    for i in range(lo, hi + 1):
        for l in build(lo, i - 1):
            for r in build(i + 1, hi):
                res.append(TreeNode(i, l, r))
    return res
return build(1, n)
```

关键点：`lo > hi` 必须返回 `[None]` 而不是 `[]`，否则 `i = lo` 时左子树的循环体一次都不执行，整棵左斜树消失。

## 复杂度
时间：O(卡特兰数 C_n × n)，每个根枚举左右组合，n=3 时是 5 棵。
空间：递归栈 O(n)，结果集本身占 O(C_n × n)，无额外缓存。

## 易错点
- `n = 1` 或任意 `i = lo` 的情形 → 若把空区间写成返回 `[]`，`for l in []` 直接跳过，`[1]` 这类单边树全丢 → 空区间返回 `[None]`，让 `None` 参与一次组合。
- `n = 3` 时若在循环外复用同一个 `TreeNode(i)` 再改 `left/right` → 多棵树共享同一节点对象，返回的 5 棵树互相污染成同一棵 → 每次 `res.append` 都新建 `TreeNode(i, l, r)`，不复用节点。

## 如果面试官追问
问：n 很大时内存爆了怎么办？
答：改成生成器 `yield`，或用迭代栈按需产出，避免一次性物化 C_n 棵树。
