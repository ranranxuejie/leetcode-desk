## 一句话思路
把 grid 反解成「第 k 步在哪个格子」，再逐步验证相邻两步的坐标差是 (1,2) 或 (2,1)。

## 怎么做
1. 建 `pos = [None] * (n*n)`，遍历 grid 把 `pos[grid[r][c]] = (r, c)`，同时检查 `grid[0][0] == 0`。
2. 从 `k = 1` 到 `n*n-1`，取 `(r0,c0)=pos[k-1]`、`(r1,c1)=pos[k]`，算 `dr=abs(r1-r0)`、`dc=abs(c1-c0)`。
3. 若 `dr*dc != 2` 就返回 `False`（只有 1×2 或 2×1 才满足），全部通过返回 `True`。

拿示例 2 走一遍：`pos[7]=(2,1)`、`pos[8]=(1,2)`，`dr=1, dc=1`，`dr*dc=1 != 2`，在第 8 步就判 False——正是题面说的「第 7 次行动后位置无效」。

```python
n = len(grid)
if grid[0][0] != 0:
    return False
pos = [None] * (n * n)
for r in range(n):
    for c in range(n):
        pos[grid[r][c]] = (r, c)
for k in range(1, n * n):
    dr = abs(pos[k][0] - pos[k-1][0])
    dc = abs(pos[k][1] - pos[k-1][1])
    if dr * dc != 2:
        return False
return True
```

注意 `dr*dc != 2` 这个判据：合法步只有 (1,2) 和 (2,1)，乘积恒为 2；(0,2)、(2,2)、(1,1) 乘积都不是 2，一步就筛掉。

## 复杂度
时间 O(n²)：建 pos 扫一遍 n² 格，再走 n²-1 步，每步 O(1)。
空间 O(n²)：额外开 pos 数组存 n² 个坐标元组。

## 易错点
- 输入 `grid[0][0] != 0`（如把起点挪到别处）→ 只验证相邻步差会全部通过、错判 True → 必须先单独检查左上角是第 0 步。
- 用 `dr+dc == 3` 当判据 → 对 (0,3)、(3,0) 也成立，n≥4 的棋盘上会放过非法步 → 用 `dr*dc == 2` 或显式写 `(dr,dc) in ((1,2),(2,1))`。

## 如果面试官追问
问：不保证 grid 是 0..n²-1 的排列怎么办？
答：先判 `len(set(flat)) == n*n` 且值域在 `[0, n*n-1]`，否则直接 False，再走上面的流程。
