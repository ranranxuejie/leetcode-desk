## 一句话思路
用 `len(nums)` 判空后取 `nums[-1]`，Python 负索引天然指向末元素，空数组单独返回 -1。

## 怎么做
1. 先判 `len(nums) == 0`，为空直接返回 -1，避免 `nums[-1]` 抛 `IndexError`。
2. 非空时返回 `nums[-1]`，负索引 -1 等价于 `nums[len(nums)-1]`。
3. 用官方示例 `nums = [None, {}, 3]` 走一遍：`len(nums) == 3` 不为 0，`nums[-1]` 取到下标 2 的元素，中间值就是 `3`，直接返回。
4. 第二个示例 `nums = []`：`len(nums) == 0` 成立，返回 -1，不进入索引分支。

```python
def last(nums):
    if len(nums) == 0:
        return -1
    return nums[-1]
```

关键点：`[None, {}, 3]` 里前两个元素是 `None` 和空字典，它们不影响末元素取值，`nums[-1]` 只看下标，不做类型判断。

## 复杂度
时间：O(1)，`len` 和负索引都是常数操作，与数组长度 n 无关。
空间：O(1)，只读不复制，没有额外开数组。

## 易错点
- 输入 `nums = []` → 直接写 `nums[-1]` 会抛 `IndexError`，而不是返回 -1 → 必须先判 `len(nums) == 0` 再取索引。
- 输入 `nums = [None]` → 误以为「元素是 None 就当空数组返回 -1」→ 实际长度是 1，应返回 `None`，判空只看长度不看元素值。

## 如果面试官追问
问：若要求返回倒数第 k 个元素且 k 可能超过长度怎么办？
答：先判 `k > len(nums)` 返回 -1，否则返回 `nums[-k]`，仍是 O(1)。
