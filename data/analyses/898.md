## 一句话思路
以每个位置结尾的子数组按位或只有 O(30) 种不同值，用集合滚动去重即可。

## 怎么做
1. 维护 `cur`：以 `arr[i]` 结尾的所有子数组的按位或值集合。
2. 递推：`cur = {x | arr[i] for x in cur} | {arr[i]}`，因为新子数组要么是 `[arr[i]]`，要么是旧子数组接上 `arr[i]`。
3. 把 `cur` 并入全局 `ans`，最后返回 `len(ans)`。
4. 以 `arr = [1,2,4]` 为例：`i=0` 时 `cur={1}`；`i=1` 时 `cur={2, 1|2=3}`；`i=2` 时 `cur={4, 2|4=6, 3|4=7}`，`ans` 累计为 `{1,2,3,4,6,7}`，长度 6。

```python
ans = set()
cur = set()
for x in arr:
    cur = {v | x for v in cur}
    cur.add(x)
    ans |= cur
return len(ans)
```

关键点：`cur` 的大小不会超过 31。因为按位或只会把 0 位变 1，从 `arr[i]` 往左扩展时，每多一个不同的值至少多一个 1 位，而 `arr[i] <= 10**9 < 2**30`，所以最多 30 次变化。

## 复杂度
时间：O(n · 30)，n 为 `arr` 长度，每个位置最多处理 30 个不同的或值。
空间：O(30) 存 `cur`，另加 O(n · 30) 最坏存 `ans` 的不同结果。

## 易错点
1. 输入 `arr = [1,1,2]` → 若忘记 `cur.add(x)`，`i=1` 时 `cur` 会变成 `{1|1=1}` 而漏掉单独的 `1`，但这里恰好不丢；真正丢的是 `arr=[0]` 时 `cur` 初始为空、`{v|0}` 也为空，结果错成 0 → 正确做法是每轮先 `cur = {v|x for v in cur}` 再 `cur.add(x)`。
2. 输入 `arr = [1,2,4]` → 若把 `ans` 写成 `ans = cur`（覆盖而非并集），最后只剩 `{4,6,7}`，输出 3 而非 6 → 正确做法是用 `ans |= cur` 累积所有位置的结果。

## 如果面试官追问
问：如果要求输出所有不同的按位或值本身而非数量？答：把 `ans` 从 `set` 直接返回即可，逻辑不变，只是返回值类型改为集合。
