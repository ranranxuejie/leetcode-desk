## 一句话思路
后序 DFS 自底向上返回每棵子树的和，边算边用哈希表计数，最后取计数最大的那些和。

## 怎么做
1. 建 `cnt = {}`，写后序 DFS：空结点返回 0。
2. 递归拿到 `left`、`right` 后，`s = left + right + node.val`，`cnt[s] = cnt.get(s, 0) + 1`，返回 `s`。
3. 遍历 `cnt` 找最大频次 `best`，再收集所有 `v == best` 的键。

以 `root = [5,2,-3]` 为例：叶子 2 返回 2（`cnt{2:1}`），叶子 -3 返回 -3（`cnt{2:1,-3:1}`），根 `s = 2 + (-3) + 5 = 4`，`cnt{2:1,-3:1,4:1}`，三个频次都是 1，输出 `[2,-3,4]`。

```python
def dfs(node):
    if not node:
        return 0
    s = dfs(node.left) + dfs(node.right) + node.val
    cnt[s] = cnt.get(s, 0) + 1
    return s

cnt = {}
dfs(root)
best = max(cnt.values())
return [v for v in cnt if cnt[v] == best]
```

关键点：`s` 必须在两个递归调用**都返回之后**才算，写成 `node.val + dfs(left) + dfs(right)` 在 Python 里求值顺序虽是从左到右、结果也对，但读起来容易误以为先算根值；显式拆成 `left`/`right` 更稳。

## 复杂度
时间 O(n)：每个结点访问一次，哈希表插入均摊 O(1)。
空间 O(n)：递归栈最坏 n 层（链状树），`cnt` 最多存 n 个不同和。

## 易错点
- 输入 `[5,2,-5]` → 若把「子树元素和」理解成只算叶子或只算非叶结点，会得到 `[2,-5]` 或 `[5]`；正确是每个结点都算：2、-5、`2+(-5)+5=2`，`cnt{2:2,-5:1}`，输出 `[2]`。
- 输入含负值（如 `[-1,-1]`）→ 若用 `if s in cnt` 之外还拿 `s` 当数组下标或假设和为正，会漏计或越界；正确做法是哈希表键直接用 `s`，负数和 0 一视同仁。

## 如果面试官追问
问：结点数涨到 10^6、值域也放大，怎么办？
答：算法不变仍是 O(n)，只需把递归改成显式栈后序，避免 Python 递归深度限制。
