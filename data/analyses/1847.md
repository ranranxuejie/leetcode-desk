## 一句话思路
把房间按面积降序、查询按 minSize 降序，边扫边把合格房间号塞进有序集合，再二分找 preferred 的左右邻居。

## 怎么做
1. 房间按 size 降序排，查询带上原始下标按 minSize 降序排。
2. 双指针扫查询：对每个 `(pref, minS, idx)`，把 size ≥ minS 的房间号逐个 `add` 进有序结构。
3. 在有序集合里 `bisect_left(pref)` 找插入点，取左右两个候选（若存在），按 `(abs(id-pref), id)` 取小者。
4. 没有候选就写 -1。

以示例 2 为例：rooms 按面积降序为 `[(3,5),(1,4),(2,3),(5,2),(4,1)]`，查询排序后先处理 `[2,5]`，此时只有房间 3 入集合，`bisect_left(3)` 得插入点 0，左无、右为 3，答案 3；再处理 `[2,4]`，房间 1 入集合，集合 `{1,3}`，`bisect_left(2)=1`，左 1 右 3，`abs` 都是 1，取小者 1。

```python
from sortedcontainers import SortedList
from bisect import bisect_left

rooms.sort(key=lambda r: -r[1])
order = sorted(range(len(queries)), key=lambda i: -queries[i][1])
sl, p, ans = SortedList(), 0, [-1] * len(queries)
for i in order:
    pref, minS = queries[i]
    while p < len(rooms) and rooms[p][1] >= minS:
        sl.add(rooms[p][0]); p += 1
    if not sl: continue
    j = bisect_left(sl, pref)
    cand = []
    if j < len(sl): cand.append(sl[j])
    if j > 0: cand.append(sl[j - 1])
    ans[i] = min(cand, key=lambda x: (abs(x - pref), x))
```

## 复杂度
时间：排序 O(n log n + k log k)，每个房间入集合一次、每个查询两次二分，共 O((n+k) log n)。
空间：有序集合存 n 个房间号，答案数组与排序下标各 O(k)。

## 易错点
- 查询必须按 minSize 降序处理，指针 `p` 只增不减；若按原顺序处理，已入集合的房间可能 size 不达标，示例 1 中 `[3,3]` 会错误返回 3 而不是 -1。
- 距离相等要取更小 id：示例 2 的 `[2,4]` 中 1 和 3 距离都是 1，只写 `min(cand, key=abs)` 可能返回 3；必须用 `(abs(x-pref), x)` 双关键字。

## 如果面试官追问
问：不用 sortedcontainers 怎么办？
答：用 `bisect.insort` 维护普通列表，插入 O(n)，总复杂度退化到 O(nk)，n、k 到 1e5 会超时，需换平衡树或离线离散化。
