## 一句话思路
按行做轮廓线 DP，状态是「上一行每格的棋子 + 本行已填格子的棋子」，因为共鸣只跨相邻两行、且同色间隔必须为偶数。

## 怎么做
1. 把「恰好隔一颗棋子」翻译成：同色两子列距为 2，或行距为 2；异色则禁止列距 2 / 行距 2。
2. 逐格填，状态压缩成 `(上一行 m 格, 本行已填 m 格)`，每格 3 值（空/B/R），用三进制或两个 bitmask。
3. 填 `(i,j)` 时只需检查与 `(i,j-2)`、`(i-2,j)` 的冲突——更远的同色/异色组合由这两步传递保证。

以示例1 `["..R","..B","?R?"]` 为例：第 0 行 `..R` 固定，第 1 行 `..B` 固定，第 2 行 `?R?` 待定。填到 `(2,2)` 时，若放 `B`，则与 `(2,0)` 的 `?` 若为 `R` 会异色列距 2 → 冲突；与 `(0,2)` 的 `R` 行距 2 异色 → 也冲突。所以 `(2,2)` 只能为空或 `R`，这直接砍掉一半分支，最终得 5。

```python
# 三进制状态：0=空,1=B,2=R；pre 为上一行，cur 为本行已填
def ok(pre, cur, j, v):
    if j >= 2 and cur[j-2] and v and cur[j-2] != v: return False
    if pre[j] and v and pre[j] != v: return False
    return True

dp = {0: 1}          # 初始：上一行全空
for i in range(n):
    ndp = {}
    for st, cnt in dp.items():
        pre, cur = st >> m, st & ((1 << m) - 1)
        # 逐格枚举 v ∈ {0,B,R}，用 ok 剪枝后累加
    dp = ndp
```

## 复杂度
时间：`O(n * m * 3^m * 3)`，`n*m ≤ 30` 时取 `m = min(n,m)` 使 `3^m` 最小。
空间：`O(3^m)` 的 dp 字典，`m` 为压缩维。

## 易错点
- 输入 `n=1, m=30` 时若按行压缩，`3^30` 直接爆炸 → 必须转置成 `m=1` 再 DP，即取 `min(n,m)` 作压缩维。
- 示例2 `["?R?","B?B","?R?"]` 中 `(0,1)=R` 与 `(2,1)=R` 行距 2 同色合法，但若误判成「同色也禁止」会得 0 → 正确规则是**异色**才禁止，同色隔一颗是允许的。

## 如果面试官追问
若要求输出所有方案而非计数？答：把 dp 值从计数改成方案列表，状态转移时拼接，规模受 `3^m` 限制只适合小 `m`。
