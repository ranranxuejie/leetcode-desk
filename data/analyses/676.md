## 一句话思路
按长度分组存字典，search 时只比对同长度单词，逐位统计不同字符数是否恰为 1。

## 怎么做
1. `buildDict` 里用 `self.groups = {}`，键是 `len(w)`，值是单词列表，把 `["hello","leetcode"]` 分成 `{5:["hello"], 8:["leetcode"]}`。
2. `search` 先取 `cand = self.groups.get(len(searchWord), [])`，长度不在字典里直接 `return False`，省掉全部比对。
3. 对每个 `w in cand` 逐位比，用 `diff` 计数，一旦 `diff > 1` 就 `break` 提前退出。
4. 只有 `diff == 1` 才 `return True`；扫完所有候选返回 `False`。

关键中间值：`search("hhllo")` 时 `cand = ["hello"]`，逐位比 `h/h` 同、`h/e` 异、`l/l` 同、`l/l` 同、`o/o` 同，`diff` 累计为 1，命中返回 `True`。而 `search("hello")` 的 `diff` 始终是 0，不满足「恰好一个」，返回 `False`——这是本题最容易漏的判定。

```python
def buildDict(self, dictionary):
    self.groups = {}
    for w in dictionary:
        self.groups.setdefault(len(w), []).append(w)

def search(self, searchWord):
    for w in self.groups.get(len(searchWord), []):
        diff = 0
        for a, b in zip(w, searchWord):
            if a != b:
                diff += 1
                if diff > 1:
                    break
        if diff == 1:
            return True
    return False
```

## 复杂度
时间：build 为 O(总字符数)；search 为 O(同长度候选数 × 单词长度)，最坏 O(n·L)。
空间：O(总字符数) 存分组，未额外开字典树节点。

## 易错点
- `search("hello")` 与字典里的 `"hello"` 完全相同 → 若写成 `diff <= 1` 就返回 `True`，错成「零次替换也算」。必须严格 `diff == 1`，因为题目要求「只将一个字母换成另一个字母」，替换后必须真的不同。
- `search("hell")` 长度为 4，字典只有长度 5 和 8 → 若不分长度直接全量比对，`zip` 会截断成 4 位比较，可能误判 `"hell"` 与 `"hello"` 前 4 位全同 `diff=0` 后仍去比别的词。正确做法是先按 `len` 过滤，长度不等直接 `False`。

## 如果面试官追问
追问：字典很大、search 调用上万次怎么办？
答：换字典树，search 时 DFS 带一个 `changed` 布尔量，沿树走并在首次不同字符处翻转标记，剪掉大量候选。
