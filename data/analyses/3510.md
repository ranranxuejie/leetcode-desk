## 一句话思路
用双向链表维护相邻关系、小根堆按 (和, 左下标) 取最小对，只重算受影响的两个相邻对。

## 怎么做
1. 建 `val` 数组、`prev`/`next` 双向链表，把所有 `i` 满足 `val[i] > val[next[i]]` 的下降点计数为 `bad`；堆里压入每个相邻对的 `(val[i]+val[i+1], i)`。
2. 循环：弹出堆顶，若 `i` 已失效（`next[i]` 变了或 `val` 已合并）就跳过；否则合并 `i` 与 `next[i]`，更新 `bad` 并重算 `i` 与 `prev[i]` 两个位置的下降状态，把新对压堆。
3. `bad == 0` 时返回操作次数。

以 `nums = [5,2,3,1]` 为例：初始 `bad = 3`（5>2、2<3 不算、3>1）。堆顶是 `(4, 2)` 即 `3+1`，合并后 `val[2]=4`，`next[2]=None`，此时 `val[1]=2 < 4` 不再下降，`bad` 降到 2；再弹 `(6,1)` 合并 `2+4`，`val[1]=6`，`5<6`，`bad=0`，返回 2。

```python
import heapq
n = len(nums)
val, prv, nxt = nums[:], list(range(-1, n-1)), list(range(1, n+1))
bad = sum(1 for i in range(n-1) if val[i] > val[i+1])
h = [(val[i]+val[i+1], i) for i in range(n-1)]
heapq.heapify(h)
ans = 0
while bad:
    s, i = heapq.heappop(h)
    j = nxt[i]
    if j == n or val[i] + val[j] != s: continue
    val[i] = s; nxt[i] = nxt[j]
    if nxt[j] < n: prv[nxt[j]] = i
    ans += 1
    bad = sum(1 for k in (prv[i], i) if 0 <= k < n and nxt[k] < n and val[k] > val[nxt[k]])
    # 实际实现需在合并前后增量维护 bad，此处仅示意
```

## 复杂度
时间 O(n log n)：堆最多 O(n) 个元素，每次合并弹压各一次。
空间 O(n)：`val`/`prv`/`nxt` 三个数组加堆。

## 易错点
- 堆里存的是旧 `(和, i)`，合并后 `i` 的右邻已变 → 直接取堆顶会合并错元素 → 弹出时校验 `val[i]+val[nxt[i]] == s` 且 `nxt[i]` 未失效，不符就 `continue`。
- 合并只影响 `i` 和 `prv[i]` 两处的下降关系，若全量重扫 `bad` → 退化成 O(n²) → 必须只增量更新这两个位置，别用 `sum(...)` 全表扫。

## 如果面试官追问
若要求输出每次合并后的数组？答：在链表上从 `head` 沿 `nxt` 走一遍即可，O(剩余长度)，总代价仍是 O(n log n)。
