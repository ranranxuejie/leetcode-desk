## 一句话思路
按「结尾值 + 已用切换次数」做 DP，用哈希表存每个值在各切换次数下的最长长度，转移时取同值继承或异值 +1。

## 怎么做
1. 定义 `dp[x][j]` 为以值 `x` 结尾、恰好用了 `j` 次切换的最长子序列长度。
2. 遍历 `nums` 中每个 `v`，对每个 `j`，同值继承 `dp[v][j] + 1`，异值取 `max(dp[u][j-1]) + 1`。
3. 用 `best[j]` 维护所有值在 `j` 次切换下的最大值，避免每次扫全部哈希表。
4. 更新时先算新值再写回，防止同一元素被重复使用。

以 `nums = [1,2,1,1,3], k = 2` 为例：处理到第二个 `1` 时，`dp[1][0]=1`，`best[0]=1`（来自 `2`），所以 `dp[1][1] = max(1+1, best[0]+1) = 2`；继续到第三个 `1`，`dp[1][1]` 变为 3，最终答案 4。

```python
from collections import defaultdict

def maximumLength(nums, k):
    dp = defaultdict(lambda: [0] * (k + 1))
    best = [0] * (k + 1)
    ans = 0
    for v in nums:
        cur = dp[v]
        new = cur[:]
        for j in range(k + 1):
            cand = cur[j] + 1
            if j > 0:
                cand = max(cand, best[j - 1] + 1)
            new[j] = cand
            ans = max(ans, cand)
        dp[v] = new
        for j in range(k + 1):
            best[j] = max(best[j], new[j])
    return ans
```

## 复杂度
时间：O(n·k)，n 为 `nums` 长度，k 为允许切换次数。
空间：O(m·k)，m 为不同值个数，`dp` 哈希表存储。

## 易错点
1. 输入 `nums = [1,2,1,1,3], k = 2` 时，若先更新 `best` 再算 `dp`，会把当前元素自己当成「异值前驱」，导致 `dp[1][1]` 错误地变成 3 而非 2。正确做法是先算完 `new` 再统一刷新 `best`。
2. 输入 `nums = [1,2,3,4,5,1], k = 0` 时，若忘记 `j=0` 不能从 `best[-1]` 转移，会越界或错误地允许切换。正确做法是 `j > 0` 才取 `best[j-1]`，`j=0` 只做同值继承。

## 如果面试官追问
若 k 增大到 n 级别怎么办？答：此时 O(n·k) 退化，可改为记录每个值的最优长度并只维护全局前 k 大，或直接用 O(n²) 暴力 DP 配合剪枝。
