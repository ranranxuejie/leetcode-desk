## 一句话思路
按花费维度做 DP：`dp[j][c]` 表示到达当前行第 j 列、恰好花 c 的最大分数，逐行滚动更新。

## 怎么做
1. 初始化 `dp` 为 `(n) x (k+1)` 的 `-1` 表，`dp[0][0] = 0`（起点 grid[0][0]==0，花费 0 分数 0）。
2. 逐行遍历，对每个格子 `(i,j)`，从上方 `dp[j]` 和左方 `dp[j-1]` 取较大值合并，再按 `grid[i][j]` 的 cost/score 平移花费维度。
3. 用示例 1 `grid=[[0,1],[2,0]], k=1` 走一遍：处理 `(1,0)` 时，从上方 `dp[0][0]=0` 加 `grid[1][0]=2` 得 `dp[0][1]=2`；处理 `(1,1)` 时，左方 `dp[0][1]=2` 加 `grid[1][1]=0` 得 `dp[1][1]=2`，最终 `max(dp[n-1]) = 2`。
4. 返回 `max(dp[n-1])`，若全为 `-1` 则返回 `-1`。

```python
n, k = len(grid[0]), k
dp = [[-1] * (k + 1) for _ in range(n)]
dp[0][0] = 0
for i in range(m):
    for j in range(n):
        v = grid[i][j]
        cost, score = (0, 0) if v == 0 else (1, v)
        for c in range(k, cost - 1, -1):
            best = dp[j][c - cost]
            if j > 0 and dp[j - 1][c - cost] > best:
                best = dp[j - 1][c - cost]
            if best >= 0:
                dp[j][c] = max(dp[j][c], best + score)
```

## 复杂度
时间：O(m·n·k)，每个格子扫一遍花费维度。
空间：O(n·k)，滚动一行，n 来自列数、k 来自花费上限。

## 易错点
- 起点 `(0,0)` 若误加 `grid[0][0]` 的分数/花费 → 示例 1 会得 2 分 1 花费但起点本应为 0，导致后续路径判断偏移；正确做法是初始化 `dp[0][0]=0` 后从 `(0,0)` 开始按值累加，起点值为 0 时天然无影响，但代码里别额外加。
- 花费维度必须**倒序**遍历 `c`（从 k 到 cost），否则同一格子的分数会被重复累加；正序会让 `dp[j][c]` 用到刚更新的 `dp[j][c-cost]`，示例 1 中 `(1,0)` 的 2 分可能被算两次。

## 如果面试官追问
问：若 k 很大（如 10^9）怎么办？答：花费只有 0/1 两种，可改为按「花费 1 的格子数」做状态，或二分答案转判定，把 k 压到路径长度量级。
