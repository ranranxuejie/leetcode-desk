## 一句话思路
枚举「子串里出现哪几个字符」共 7 种，对每种把前缀计数差哈希成 key，找最早出现的同 key 位置。

## 怎么做
1. 枚举字符集合 `mask`（`'a'`、`'b'`、`'c'` 的非空子集，共 7 种），只考虑 `mask` 内的字符。
2. 对固定 `mask`，维护前缀计数 `cnt[c]`，把「各字符计数减去 mask 中第一个字符的计数」拼成元组当 key。
3. 哈希表 `first` 记录每个 key 最早出现的下标，初始 `{全零元组: -1}`；再次遇到同 key 时，两位置之间的子串各字符增量相等，即平衡。
4. 用 `i - first[key]` 更新答案。

以 `s = "abbac"`、`mask = {'a','b'}` 为例：走到下标 3（字符 `'b'`）时 `cnt = (2,2)`，key 为 `(0,)`，与初始 key 相同，`first` 里是 `-1`，得长度 `3 - (-1) = 4`，正是 `"abba"`。

```python
from itertools import combinations
first = {}
for mask in masks:                      # 7 种字符集合
    first = {(0,) * (len(mask) - 1): -1}
    cnt = {c: 0 for c in mask}
    for i, ch in enumerate(s):
        if ch not in cnt:
            continue
        cnt[ch] += 1
        base = cnt[mask[0]]
        key = tuple(cnt[c] - base for c in mask[1:])
        if key in first:
            ans = max(ans, i - first[key])
        else:
            first[key] = i
```

注意 `mask` 只有一个字符时 key 是空元组 `()`，任意长度都「平衡」，答案至少为 1，这个分支自然覆盖。

## 复杂度
时间 O(7n)，7 是常数，实际就是 O(n)，每个下标对每个 mask 做一次元组构造。
空间 O(n)，`first` 最多存 n 个 key，每个 key 长度 ≤2。

## 易错点
- 输入 `s = "ab"`、`mask = {'a','b','c'}`：若把 `'c'` 的计数也放进 key，`'c'` 恒为 0 不影响差值，看似没事；但若用「计数元组」而非「差值元组」当 key，`"ab"` 的 `(1,1,0)` 与 `"aab"` 的 `(2,1,0)` 都被判为不同 key，会漏掉 `"ab"` 这类答案。必须减 `mask[0]` 的计数。
- 输入 `s = "aba"`、`mask = {'a','b'}`：若 `first` 初始只放 `(0,)` 而不放下标 `-1`，下标 1 处 key 为 `(0,)` 时找不到起点，会错成 0 或 1；正确做法是 `first = {(0,): -1}`，让 `"ab"` 从 `-1` 起算得长度 2。
- 输入 `s = "aaaa"`：单字符 mask 下 key 恒为 `()`，若忘记初始化 `first`，第一次就 `KeyError`；初始化后每次命中 `-1`，答案 4 正确。

## 如果面试官追问
问：字符集扩到 26 个字母怎么办？
答：7 种 mask 变成 `2**26` 不可枚举，改用「枚举子串长度 L，滑动窗口检查 26 个计数是否都等于 L 或 0」，O(26n) 但需按 L 分桶，或直接放弃枚举 mask 改随机化哈希。
