## 一句话思路
先把所有 `==` 用并查集合并成连通块，再逐个检查 `!=` 两端是否落在同一块里。

## 怎么做
1. 开 26 个元素的 `parent`，`parent[i] = i`，下标用 `ord(ch) - ord('a')` 映射。
2. 第一遍只扫 `==`：对 `equations[i][1] == '='` 的，把 `equations[i][0]` 和 `equations[i][3]` 合并。
3. 第二遍只扫 `!=`：若两端 `find` 结果相同，立刻返回 `False`。
4. 全部通过返回 `True`。

拿示例 4 `["a==b","b!=c","c==a"]` 走一遍：第一遍合并后 `a`、`b`、`c` 的根都是同一个（比如都指向 `a`），此时 `parent` 里 `b`、`c` 的根已等于 `a` 的根；第二遍处理 `"b!=c"`，`find('b') == find('c')` 成立，直接返回 `False`。

```python
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

parent = list(range(26))
for e in equations:
    if e[1] == '=':
        parent[find(ord(e[0]) - 97)] = find(ord(e[3]) - 97)
for e in equations:
    if e[1] == '!' and find(ord(e[0]) - 97) == find(ord(e[3]) - 97):
        return False
return True
```

关键是**两遍分离**：先让所有等式生效，再验证不等式。若边扫边判，`["a==b","b!=a"]` 里 `b!=a` 会先于合并被检查，误判成 `True`。

## 复杂度
时间 O(n·α(26))，n 为方程数，α 近似常数，两遍扫描各一次。
空间 O(26)，只有 `parent` 数组，与 n 无关。

## 易错点
- 输入 `["a==b","b!=a"]` → 若把 `==` 和 `!=` 混在一遍里处理，`b!=a` 可能在合并前被检查，错返回 `True` → 必须两遍分离，先合并全部等式再验不等式。
- 输入 `["c==c","b==d","x!=z"]` → 若把 `c==c` 这种自反等式当成非法或跳过合并逻辑写错，可能误判 → 自反等式 `find(x)==find(x)` 天然成立，正常合并即可，`x!=z` 两端不同根所以返回 `True`。

## 如果面试官追问
若变量不止小写字母而是任意字符串？答：把 `parent` 换成 `dict`，键为变量名，`find` 里用 `setdefault` 初始化即可，逻辑不变。
