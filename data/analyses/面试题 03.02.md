## 一句话思路
用辅助栈 `mins` 同步记录「当前主栈的最小值」，push/pop 时两栈同进同出，`getMin` 直接读 `mins[-1]`。

## 怎么做
1. 主栈 `st` 存元素，辅助栈 `mins` 存「压入该元素后主栈的最小值」。
2. `push(x)`：`st.append(x)`；`mins.append(x if not mins else min(x, mins[-1]))`。
3. `pop()`：两栈同时 `pop()`，保证 `mins[-1]` 始终对应 `st` 当前状态的最小值。
4. `getMin()` 返回 `mins[-1]`，`top()` 返回 `st[-1]`。

以官方示例走一遍关键步：push(-2) 后 `mins=[-2]`；push(0) 时 `min(0,-2)=-2`，`mins=[-2,-2]`；push(-3) 时 `min(-3,-2)=-3`，`mins=[-2,-2,-3]`，此时 `getMin()` 读 `mins[-1]` 得 -3。随后 `pop()` 两栈同弹，`mins` 回到 `[-2,-2]`，`getMin()` 得 -2，与示例一致。

```python
st, mins = [], []

def push(x):
    st.append(x)
    mins.append(x if not mins else min(x, mins[-1]))

def pop():
    st.pop()
    mins.pop()

def top():
    return st[-1]

def getMin():
    return mins[-1]
```

注意 `mins` 存的是「历史最小值快照」而非去重后的最小值集合，所以长度恒等于 `st`，pop 时无需判断是否等于当前最小值。

## 复杂度
时间：push/pop/top/getMin 均 O(1)，无循环。
空间：O(n)，`st` 与 `mins` 各存 n 个元素，额外开销是辅助栈。

## 易错点
- 输入 push(-2)、push(0)、push(-3) 后连续两次 pop：若 `mins` 只在「新元素更小」时才压栈，第二次 pop 后 `mins` 已空，`getMin()` 越界报错；正确做法是每次 push 都往 `mins` 压一份当前最小值，两栈等长。
- 输入 push(0)、push(0)：若用 `x < mins[-1]` 严格小于判断是否更新，重复最小值不会入栈，pop 掉一个 0 后 `mins` 与 `st` 长度错位；正确做法用 `min(x, mins[-1])` 无条件压栈，重复值也各占一格。

## 如果面试官追问
追问：要求额外空间 O(1) 怎么办？
答：`mins` 改存「与当前最小值的差值」，用单个变量记最小值，pop 时按差值符号还原，代价是差值可能超出 32 位需按题目规定截断处理。
