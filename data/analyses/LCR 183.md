## 一句话思路
用单调队列存下标，队首始终是当前窗口最大值的下标，出队入队各 O(1)。

## 怎么做
1. 建空双端队列 `q` 存下标，遍历 `i` 从 0 到 `len(heights)-1`。
2. 队首过期就弹：`q[0] <= i - limit` 时 `popleft()`。
3. 队尾比新值小就弹：`heights[q[-1]] <= heights[i]` 时 `pop()`，保证队列值单调递减。
4. `i >= limit - 1` 时把 `heights[q[0]]` 追加进结果。

拿示例 `heights = [14,2,27,-5,28,13,39], limit = 3` 走关键一步：`i=2` 时，先弹掉队尾的 `1`（`heights[1]=2 <= 27`）和 `0`（`14 <= 27`），`q` 变成 `[2]`，此时 `i >= 2`，输出 `heights[2] = 27`。到 `i=4` 值 `28` 时，`q` 里剩的 `2`（值 27）也被弹掉，`q=[4]`，输出 28。

```python
from collections import deque
q = deque()
res = []
for i, h in enumerate(heights):
    if q and q[0] <= i - limit:
        q.popleft()
    while q and heights[q[-1]] <= h:
        q.pop()
    q.append(i)
    if i >= limit - 1:
        res.append(heights[q[0]])
```

注意 `while` 用 `<=` 而不是 `<`：相等时弹掉旧下标，队列里不留重复值，长度更短。

## 复杂度
时间 O(n)：每个下标最多入队一次、出队一次，`n = len(heights)`。
空间 O(limit)：队列最多存 `limit` 个下标，结果数组 O(n - limit + 1)。

## 易错点
- `limit = 1` 时，若把输出条件写成 `i >= limit`，第一个窗口 `i=0` 就被跳过，结果少一个元素；正确是 `i >= limit - 1`，`limit=1` 时每个 `i` 都输出，答案等于 `heights` 本身。
- 队首过期判断写成 `q[0] < i - limit` 会漏弹：`i=3, limit=3` 时窗口是 `[1,3]`，下标 `0` 已过期，`0 < 0` 为假不弹，队首仍是 `heights[0]=14`，输出错成 14 而非 28；正确是 `q[0] <= i - limit`。

## 如果面试官追问
问：要求返回每个窗口最大值和次大值怎么办？
答：队列里保留两个候选，或改用存 `(下标, 值)` 的单调队列并维护前两名，出队时同步更新。
