## 一句话思路
先生成从 0 开始的格雷码，再整体异或 `start`，因为异或同一常数不改变相邻两项的「只差一位」性质。

## 怎么做
1. 用公式 `i ^ (i >> 1)` 生成第 i 个格雷码，i 从 0 到 `2**n - 1`。
2. 把每个格雷码异或 `start`，得到以 `start` 开头的序列。
3. 直接返回该列表。

以 `n = 2, start = 3` 为例：格雷码序列是 `[0,1,3,2]`（二进制 `00,01,11,10`），逐项异或 3 得 `[3,2,0,1]`，正是示例输出。关键中间值：`i=2` 时 `2 ^ (2>>1) = 2 ^ 1 = 3`，异或 3 得 0。

```python
def circularPermutation(n, start):
    res = []
    for i in range(1 << n):
        res.append((i ^ (i >> 1)) ^ start)
    return res
```

为什么异或 `start` 不破坏性质：相邻两项 `g[i]` 和 `g[i+1]` 只差一位，异或同一个 `start` 后，`g[i]^start` 与 `g[i+1]^start` 的差异位集合不变，仍只差一位。首项 `g[0]^start = 0^start = start`，满足 `p[0] = start`。末项与首项：格雷码首尾 `0` 和 `2^(n-1)` 也只差一位，异或后同样成立。

## 复杂度
时间 O(2^n)，每个 i 做两次异或和一次移位。
空间 O(2^n)，结果列表本身；除此外只用了循环变量 i。

## 易错点
- `n = 16` 时序列长度 65536，若用递归回溯枚举会超时或爆栈 → 必须用 `i ^ (i >> 1)` 直接算，不要写 DFS。
- 忘记异或 `start` 只对首项做处理（比如把 `start` 插到列表头再删重复）→ 会得到 `[start, 0, 1, 3, 2]` 这种长度 `2^n+1` 的错误结果；正确做法是对每一项都异或 `start`，长度恰好 `2^n`。

## 如果面试官追问
问：如果要求返回字典序最小的合法排列怎么办？
答：格雷码异或 `start` 后整体顺序固定，需在两种反射格雷码方向中取较小者，比较 `res[1]` 与 `res[-1]` 即可。
