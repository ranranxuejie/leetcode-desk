## 一句话思路
把 s 的所有循环移位按「是否等于 t」分成两类，用 2×2 矩阵快速幂做 k 次转移。

## 怎么做
1. 一次操作等价于把 s 循环左移 l 位（l 取 1..n-1），所以可达状态只有 s 的 n 个循环移位。
2. 用 KMP 在 `s+s` 上匹配 t，统计 s 的循环移位中等于 t 的个数 `cnt`（注意 `s+s` 长度 2n，起点只取 0..n-1）。
3. 设 `a` = 等于 t 的移位个数 = `cnt`，`b` = n - a；状态转移：从「等于 t」出发，一步后仍等于 t 的方案数是 a-1（不能选 l=0 原地不动），变成不等于 t 的是 b；从「不等于 t」出发，一步后等于 t 的是 a，仍不等于 t 的是 b-1。
4. 初始向量看 s 本身是否等于 t，做 k 次矩阵幂后取对应分量。

以示例 1 为例：`s="abcd"`，`t="cdab"`，`s+s="abcdabcd"`，在起点 0..3 中只有起点 2 匹配，故 `a=1, b=3`。k=2 时从「s 不等于 t」出发，两步后等于 t 的方案数 = `a*(b-1) + (a-1)*a = 1*2 + 0 = 2`，与输出一致。

```python
MOD = 10**9 + 7
def mat_mul(A, B):
    return [[sum(A[i][x] * B[x][j] for x in range(2)) % MOD for j in range(2)] for i in range(2)]

def mat_pow(M, e):
    R = [[1, 0], [0, 1]]
    while e:
        if e & 1: R = mat_mul(R, M)
        M = mat_mul(M, M); e >>= 1
    return R

# a = 等于 t 的循环移位个数, b = n - a
M = [[(a - 1) % MOD, a % MOD], [b % MOD, (b - 1) % MOD]]
P = mat_pow(M, k)
start = 0 if s == t else 1   # 0 表示初始等于 t
ans = P[start][0]
```

## 复杂度
时间：KMP 求 `cnt` 是 O(n)，矩阵快速幂 O(log k)，n 来自字符串长度，log k 来自 k ≤ 10^15。
空间：O(n) 存 `s+s` 与 pi 数组，矩阵只占常数 4 个格子。

## 易错点
- `s="ababab", t="ababab"`：`s+s` 中起点 0、2、4 都匹配，`a=3` 而非 1；若只判断 `s==t` 就取 a=1，k=1 会算成 0，正确是 `a-1=2`。
- 转移矩阵对角元写成 `a`、`b` 而非 `a-1`、`b-1`：等于把 l=0 的「原地不动」也算成一次操作，示例 1 中 k=2 会多出 1 条路径，正确做法是减去自身这一种。

## 如果面试官追问
问：k 很小（如 k ≤ 100）时还要矩阵幂吗？
答：不用，直接 O(k) 递推两个标量 `eq, ne` 即可，矩阵幂只在 k 达 10^15 时才必要。
