## 一句话思路
用数位 DP 分别求 `[0, x]` 的美丽数个数，答案 = `f(high) - f(low-1)`，状态里带「偶数位个数 − 奇数位个数」和「当前余数」。

## 怎么做
1. 把 `x` 拆成十进制数字列表 `digits`，`f(x)` 从最高位往下填，用 `(pos, diff, rem, tight, started)` 记忆化，`diff` 初值 0，偶数位 +1、奇数位 −1。
2. `started=False` 时填 0 表示还没开始，不改变 `diff` 和 `rem`，避免把前导零算成偶数位。
3. 终止条件：`pos == len(digits)` 时返回 `started and diff == 0 and rem == 0`。
4. 转移：`rem = (rem * 10 + d) % k`，`diff` 按 `d % 2 == 0` 加减。

以 `low=10, high=20, k=3` 为例，`f(20)` 中走到 `d=1, d=2` 时 `diff=0, rem=12%3=0`，这一支被计入；`d=1, d=6` 时 `rem=16%3=1` 被剪掉，所以 `f(20)` 里 12、18 都命中。

```python
from functools import lru_cache

def f(x):
    if x <= 0:
        return 0
    ds = list(map(int, str(x)))
    @lru_cache(None)
    def dfs(pos, diff, rem, tight, started):
        if pos == len(ds):
            return int(started and diff == 0 and rem == 0)
        up = ds[pos] if tight else 9
        res = 0
        for d in range(up + 1):
            nt = tight and d == up
            if not started and d == 0:
                res += dfs(pos + 1, diff, rem, nt, False)
            else:
                nd = diff + (1 if d % 2 == 0 else -1)
                res += dfs(pos + 1, nd, (rem * 10 + d) % k, nt, True)
        return res
    return dfs(0, 0, 0, True, False)
```

## 复杂度
时间：`O(len * 2*len * k * 2 * 2 * 10)`，`len ≤ 10`、`k ≤ 20`，常数很小。
空间：记忆化表同阶，额外只存 `digits` 和缓存。

## 易错点
- 输入 `low=1, high=10, k=1`：若不用 `started` 标记，数字 10 的前导零会被当成偶数位，`diff` 算成 1 而漏掉答案 1；正确做法是前导零不参与 `diff` 和 `rem` 计算。
- 输入 `low=5, high=5, k=2`：若终止条件只判 `diff == 0` 不判 `started`，空数（全前导零）会被算成美丽数，`f(5)-f(4)` 多出 1；正确做法是 `started and diff == 0 and rem == 0` 三者同时成立。

## 如果面试官追问
问：`high` 放大到 `10^18` 怎么办？答：数位 DP 本身与位数线性，只需把 `len` 上限提到 19，状态规模不变，仍可秒过。
