## 一句话思路
把 `_` 全部投给当前占优的那个轴，答案就是 `|x|+|y|+下划线数`，因为每个 `_` 最多贡献 1。

## 怎么做
1. 先只统计四个方向字符，得到固定位移 `x = R - L`、`y = U - D`，以及 `blank = moves.count('_')`。
2. 关键结论：`_` 的每个字符都能让曼哈顿距离 +1，无论投给哪个方向，所以答案 = `abs(x) + abs(y) + blank`。
3. 用示例 1 `"L_D_"` 验证：`x = 0 - 1 = -1`，`y = 0 - 0 = 0`，`blank = 2`，答案 `1 + 0 + 2 = 4`，与官方输出一致。
4. 示例 2 `"U_R"`：`x = 1`，`y = 1`，`blank = 1`，答案 `1 + 1 + 1 = 3`。

```python
x = y = blank = 0
for c in moves:
    if c == 'R': x += 1
    elif c == 'L': x -= 1
    elif c == 'U': y += 1
    elif c == 'D': y -= 1
    else: blank += 1
return abs(x) + abs(y) + blank
```

为什么每个 `_` 都恰好 +1：设当前 `x >= 0`，把 `_` 当 `R` 则 `x` 增 1，`|x|` 增 1；若 `x < 0` 就当 `L`，`|x|` 同样增 1。`y` 轴同理，两轴互不干扰，所以 `blank` 个下划线全部能兑现成距离，一个不浪费。

## 复杂度
时间 O(n)：一次遍历 `moves`，n 为字符串长度。
空间 O(1)：只开 `x`、`y`、`blank` 三个整数。

## 易错点
- 输入 `"UD"` → 若把 `U` 和 `D` 分别累加成两个正数再相加，会错成 2；正确做法是 `y = U - D` 先抵消，`abs(0) + abs(0) = 0`。
- 输入 `"__"` → 若只算固定位移会错成 0；正确做法是 `blank` 必须加进答案，两个下划线投同一方向得 2，投相反方向也是 2，结果恒为 `blank`。

## 如果面试官追问
问：如果 `_` 只能替换成 `U` 或 `R`（不能选 `L`/`D`）呢？
答：那就不能全兑现，答案是 `abs(x) + abs(y) + blank` 减去被迫反向的部分，需要按 `x`、`y` 的符号分类讨论。
