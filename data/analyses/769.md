## 一句话思路
从左往右扫，维护前缀最大值 `mx`，当 `mx == i` 时切一刀，因为前 `i+1` 个元素恰好是 `0..i`。

## 怎么做
1. 初始化 `mx = -1`、`ans = 0`，`mx` 表示 `arr[0..i]` 的最大值。
2. 遍历 `i` 从 0 到 n-1，每步更新 `mx = max(mx, arr[i])`。
3. 若 `mx == i`，说明 `arr[0..i]` 这 `i+1` 个数正好是 `0..i` 的一个排列，可以在此处封口，`ans += 1`。
4. 返回 `ans`。

以 `arr = [1,0,2,3,4]` 为例：
- `i=0`：`mx = max(-1,1) = 1`，`1 != 0`，不切。
- `i=1`：`mx = max(1,0) = 1`，`1 == 1`，切第一块 `[1,0]`，`ans=1`。
- `i=2`：`mx = max(1,2) = 2`，`2 == 2`，切 `[2]`，`ans=2`。
- `i=3`：`mx = 3`，`3 == 3`，切 `[3]`，`ans=3`。
- `i=4`：`mx = 4`，`4 == 4`，切 `[4]`，`ans=4`。

关键中间值就是 `i=1` 时的 `mx=1`：它证明前两个位置的最大值没超过下标 1，块内元素不会跑到后面去。

```python
mx = -1
ans = 0
for i, x in enumerate(arr):
    mx = max(mx, x)
    if mx == i:
        ans += 1
return ans
```

为什么 `mx == i` 就够？因为 `arr` 是 `0..n-1` 的排列，前 `i+1` 个位置若最大值恰为 `i`，则这 `i+1` 个数全在 `0..i` 内且互不相同，只能是 `0..i` 全体，单独排序后正好落在正确位置。反之若 `mx > i`，说明有个大于 `i` 的数被关在前缀里，它必须和后面的小元素交换，块不能在此断开。

## 复杂度
时间 O(n)：一次遍历，每步一次 `max` 比较。
空间 O(1)：只开 `mx`、`ans` 两个标量。

## 易错点
- 输入 `arr = [4,3,2,1,0]` → 若用「`arr[i] == i` 就切」会错成 0 或乱切 → 正确看前缀最大值：`i=0` 时 `mx=4 != 0`，全程 `mx` 都大于 `i`，只有 `i=4` 时 `mx=4 == 4`，答案 1。
- 输入 `arr = [0,1,2]` → 若把 `mx` 初始化为 `0` 而非 `-1`，`i=0` 时 `mx=0 == 0` 仍对，但若写成 `mx = arr[0]` 再从头循环会漏判或重复计数 → 统一用 `mx = -1` 起手，保证 `i=0` 时 `mx` 由 `arr[0]` 决定。

## 如果面试官追问
若要求输出每个块的下标区间？答：在 `mx == i` 处记录 `(start, i)` 并把 `start = i+1`，其余逻辑不变。
