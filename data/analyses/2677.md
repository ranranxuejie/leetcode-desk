## 一句话思路
按下标 `i` 从 0 步进 `size` 切片 `arr[i:i+size]`，因为每块起点恰好是 `size` 的倍数，切片自动处理末尾不足一块的情况。

## 怎么做
1. 用 `range(0, len(arr), size)` 生成每块起点，步长就是 `size`。
2. 对每个起点 `i` 取 `arr[i:i+size]`，切片越界不报错、自动截断。
3. 把切片追加进结果列表，空数组时循环不执行、直接返回 `[]`。

以示例 2 为例：`arr = [1,9,6,3,2]`，`size = 3`。`range(0, 5, 3)` 给出 `i = 0, 3`；`i=0` 时 `arr[0:3]` 得 `[1,9,6]`，`i=3` 时 `arr[3:6]` 只取到下标 3、4，得 `[3,2]`——注意上界 6 超出长度 5 但切片不报错，这正是末尾短块不用特判的原因。

```python
def chunkify(arr, size):
    res = []
    for i in range(0, len(arr), size):
        res.append(arr[i:i + size])
    return res
```

等价的推导式写法：`[arr[i:i + size] for i in range(0, len(arr), size)]`。两种写法都只遍历一次 `arr`，没有额外拷贝整表。

## 复杂度
时间 O(n)，n 为 `arr` 长度，每个元素被切片复制一次。
空间 O(n)，结果列表存下全部 n 个元素（不计输出则额外空间 O(1)）。

## 易错点
- `arr = []`、`size = 1` → 若写成 `while i <= len(arr)` 或先算 `len(arr) // size` 再循环，会多出一个空块 `[[]]` 或直接崩 → 用 `range(0, 0, 1)` 天然为空，返回 `[]`。
- `arr = [8,5,3,2,6]`、`size = 6` → 若用 `for i in range(0, len(arr) - size + 1, size)` 这类「保证整块」的边界，会一块都不切、返回 `[]` → 起点上界必须是 `len(arr)`，让 `arr[0:6]` 自己截断成 5 个元素。

## 如果面试官追问
问：`size` 可能为 0 或负数怎么办？答：题面保证 `size >= 1`；若放开，需在入口判断 `size <= 0` 时返回 `[]`，否则 `range` 步长为 0 会抛 `ValueError`。
