## 一句话思路
用并查集把可互换的下标并成连通块，块内元素可任意重排，于是每块把最大值堆到偶数位、最小值堆到奇数位。

## 怎么做
1. 对每个 `swaps[i] = [p, q]` 做 union，得到若干连通块。
2. 按根节点把下标分组，同时收集每块里的 `nums` 值。
3. 每块的值排序，块内偶数位个数 `even_cnt` 决定取最大的 `even_cnt` 个放偶数位、其余放奇数位。
4. 累加 `sum(大的一半) - sum(小的一半)`。

以示例 1 `nums = [1,2,3], swaps = [[0,2],[1,2]]` 为例：三个下标并成一块 `{0,1,2}`，值排序为 `[1,2,3]`，偶数位有 2 个（下标 0、2），取 `3+2` 放偶数位、`1` 放奇数位，交替和 `3+2-1 = 4`。

```python
parent = list(range(n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
for p, q in swaps:
    parent[find(p)] = find(q)
groups = {}
for i in range(n):
    groups.setdefault(find(i), []).append(i)
ans = 0
for idxs in groups.values():
    vals = sorted(nums[i] for i in idxs)
    even_cnt = sum(1 for i in idxs if i % 2 == 0)
    ans += sum(vals[len(vals) - even_cnt:]) - sum(vals[:len(vals) - even_cnt])
```

## 复杂度
时间：并查集近似 O(n α(n))，排序总计 O(n log n)，n 为 `len(nums)`。
空间：`parent`、`groups`、每块 `vals` 共 O(n)。

## 易错点
- 块内偶数位个数不等于块大小的一半时（如示例 1 的块 `{0,1,2}` 偶数位 2 个、奇数位 1 个），若按「一半一半」切分，会把 `3` 放到奇数位、算出 `2+1-3=0`；正确做法是先数 `even_cnt`，再从排序后尾部取 `even_cnt` 个。
- `swaps = []` 时每个下标自成一元块，若跳过单元素块或误以为可全局排序，示例 3 会算成正数；正确做法是单元素块也走同一逻辑，`even_cnt` 为 1 或 0，结果保持原交替和 `-2999999997`。

## 如果面试官追问
若要求输出达到最大交替和的一个具体排列？答：每块排序后，把尾部 `even_cnt` 个依次填回该块的偶数下标、其余填回奇数下标即可。
