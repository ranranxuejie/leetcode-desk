## 一句话思路
用 `dp[i][j]` 表示前 `i` 个字符切成 `j` 段的方案数，转移靠前缀和把「枚举上一刀位置」压成 O(1)。

## 怎么做
1. 预处理 `ok[i]`：`s[i]` 是质数数字（`'2''3''5''7'`）且 `s[i-1]` 是非质数数字，表示第 `i` 个字符可以作为某段的起点（`i` 从 1 开始计）。
2. 定义 `dp[i][j]`：前 `i` 个字符分成 `j` 段且第 `j` 段以 `s[i-1]` 结尾的方案数；只有 `s[i-1]` 非质数时才有意义。
3. 转移：`dp[i][j] = sum(dp[p][j-1])`，其中 `p <= i - minLength` 且 `s[p]` 是质数数字（即第 `p+1` 个字符能开新段）。用前缀和 `pre[j][x] = sum(dp[p][j] for p <= x)` 把求和变 O(1)。
4. 答案取 `dp[n][k]`。

以示例 1 `s="23542185131", k=3, minLength=2` 为例：`n=11`，`s[1]='3'` 是质数、`s[3]='4'` 非质数，所以 `ok[2]=True`（下标 1 起）。算到 `dp[4][1]`：前 4 字符 `"2354"` 一段，末字符 `'4'` 非质数、首字符 `'2'` 质数、长度 4≥2，故 `dp[4][1]=1`。再算 `dp[7][2]`：上一刀 `p` 满足 `p<=5` 且 `s[p]` 质数，`p=4`（`s[4]='2'`）时 `dp[4][1]=1` 贡献进来，得 `dp[7][2]=1`，对应 `"2354|218"`。

```python
MOD = 10**9 + 7
n = len(s)
prime = set('2357')
dp = [[0]*(k+1) for _ in range(n+1)]
pre = [[0]*(n+1) for _ in range(k+1)]
dp[0][0] = 1
pre[0][0] = 1
for i in range(1, n+1):
    pre[0][i] = pre[0][i-1]
for j in range(1, k+1):
    for i in range(1, n+1):
        if s[i-1] not in prime:          # 末字符必须非质数
            p = i - minLength
            if p >= 0 and (p == 0 or s[p-1] in prime):
                dp[i][j] = pre[j-1][p]
        pre[j][i] = (pre[j][i-1] + dp[i][j]) % MOD
return dp[n][k]
```

## 复杂度
时间 O(n·k)：两层循环各 n、k，前缀和把内层求和降到 O(1)。
空间 O(n·k)：`dp` 和 `pre` 各开 (n+1)×(k+1)。

## 易错点
- 边界 `p == 0`：`s[p-1]` 会越界。示例 1 中 `dp[4][1]` 的 `p=2`，但 `dp[2][1]` 的 `p=0` 必须特判为合法（第一段无前驱），否则 `"23"` 这类前缀全丢，答案偏小。
- 末字符判定用 `s[i-1]` 而非 `s[i]`：示例 1 里 `dp[4][1]` 看的是 `s[3]='4'`，若误写成 `s[4]='2'`（质数）就会把 `"2354"` 判成非法，示例 1 直接输出 0。

## 如果面试官追问
要求输出所有方案而非计数？答：把 `pre` 换成「上一刀位置列表」，回溯时按 `p` 枚举，复杂度升到方案数级别。
