## 一句话思路
把 `nums` 去重成集合 `s`，对每个 `x` 检查 `x+k` 是否在 `s` 里，命中就计数——去重后每个数对只可能被数一次。

## 怎么做
1. 若 `k < 0` 直接返回 0（本题 k≥0，可省）。
2. `s = set(nums)`，把重复元素压掉，示例 1 的 `[3,1,4,1,5]` 变成 `{1,3,4,5}`。
3. `k == 0` 时，数对要求同一个值出现两次，所以答案是「原数组中频次 ≥2 的不同值个数」，示例 3 中只有 `1` 出现两次，返回 1。
4. `k > 0` 时遍历 `s`，对每个 `x` 判断 `x + k in s`，成立则 `ans += 1`。示例 1 中 `x=1` 命中 `3`、`x=3` 命中 `5`，`x=4` 找 `6` 落空，`x=5` 找 `7` 落空，得 2。

```python
from collections import Counter

def findPairs(nums, k):
    if k < 0:
        return 0
    if k == 0:
        return sum(1 for v in Counter(nums).values() if v >= 2)
    s = set(nums)
    ans = 0
    for x in s:
        if x + k in s:
            ans += 1
    return ans
```

关键点：只查 `x + k` 不查 `x - k`，因为遍历的是整个集合，`(a, a+k)` 这对会在 `x = a` 时被数到，在 `x = a+k` 时查的是 `a+2k`，不会重复。若两个方向都查，示例 1 会得 4 而不是 2。

## 复杂度
时间：O(n)，建集合和 Counter 各扫一遍，遍历集合 O(n)。
空间：O(n)，`s` 与 `Counter` 各存至多 n 个不同值。

## 易错点
- `k == 0` 时套用 `x + 0 in s` 的循环：`x + 0` 就是 `x` 本身，恒为真，示例 3 会返回 4（集合大小）而不是 1。正确做法是单独用 `Counter` 数频次 ≥2 的值。
- 双向查找 `x - k in s or x + k in s`：示例 1 中 `(1,3)` 会在 `x=1` 和 `x=3` 各数一次，输出 4。正确做法是只查 `x + k`，靠「遍历全集 + 单向偏移」保证每对只数一次。

## 如果面试官追问
问：要求返回所有数对而不只是个数？
答：把 `ans += 1` 换成 `res.append((x, x + k))`，`k == 0` 分支改成对每个频次 ≥2 的值追加 `(v, v)`，复杂度不变。
