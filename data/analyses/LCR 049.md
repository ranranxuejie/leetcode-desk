## 一句话思路
DFS 向下传「到当前节点为止拼成的数」`cur`，到叶子就把 `cur` 累加进总和。

## 怎么做
1. 递归参数带 `cur`，进入节点时更新 `cur = cur * 10 + node.val`。
2. 判断叶子：`node.left is None and node.right is None`，此时 `cur` 就是一条完整路径的数，直接返回它。
3. 非叶子则返回左右子树结果之和（空子树返回 0）。
4. 以 `root = [4,9,0,5,1]` 为例：走到 `4->9->5` 时 `cur` 依次为 4、49、495；走到 `4->0` 时 `cur` 为 4 再变 40，叶子处返回 40。

```python
def dfs(node, cur):
    if node is None:
        return 0
    cur = cur * 10 + node.val
    if node.left is None and node.right is None:
        return cur
    return dfs(node.left, cur) + dfs(node.right, cur)

return dfs(root, 0)
```

关键点：`cur` 是**按值传递**的，左子树算完 495 不影响右子树从 49 继续算 491，不需要回溯撤销。

## 复杂度
时间 O(n)：每个节点访问一次，`cur * 10` 是常数操作。
空间 O(h)：递归栈深度，h ≤ 10；无额外数组。

## 易错点
- 把叶子判断写成 `if not node.left and not node.right` 之外的 `if node is None` 就返回 `cur` → 对 `[1,2,3]` 会在空孩子处多返回一次 12 和 13 的重复值，答案偏大；正确做法是只在真叶子处返回 `cur`，空节点返回 0。
- 用全局变量 `total` 累加却不重置，或把 `cur` 写成可变对象（如列表）在递归间共享 → 对 `[4,9,0,5,1]` 右分支会拿到 495 而不是 491，得到 1030；正确做法是 `cur` 作为参数传值，或显式 `cur // 10` 回溯。

## 如果面试官追问
问：节点值改成可以是多位数怎么办？
答：把 `cur * 10 + node.val` 换成 `cur * 10**len(str(node.val)) + node.val`，其余不变。
