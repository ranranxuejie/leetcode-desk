## 一句话思路
12 个区域只有 2^12 种「赢/不赢」组合，枚举子集，每个赢的区域花 `aliceArrows[i]+1` 支箭，剩余箭全丢给 0 分区。

## 怎么做
1. 用 12 位掩码 `mask` 枚举 Bob 想赢的区域集合，`mask` 第 i 位为 1 表示要赢下 i 分区。
2. 对每个 `mask` 累加代价 `cost = sum(aliceArrows[i]+1)`，`cost > numArrows` 直接跳过。
3. 代价合法时，得分是 `mask` 中所有位的下标之和，取最大者记为 `best`。
4. 按 `best` 构造答案：赢的区域填 `aliceArrows[i]+1`，其余填 0，最后把 `numArrows - cost` 支剩余箭全加到 `bobArrows[0]`。

以示例 1 为例，`numArrows=9`，最优 `best` 对应区域 {4,5,8,9,10,11}，代价 `1+1+1+2+3+1=9`，得分 `4+5+8+9+10+11=47`，剩余 0 支，输出 `[0,0,0,0,1,1,0,0,1,2,3,1]`。

```python
best, best_cost = 0, 0
for mask in range(1 << 12):
    cost = score = 0
    for i in range(12):
        if mask >> i & 1:
            cost += aliceArrows[i] + 1
            score += i
    if cost <= numArrows and score > best:
        best, best_cost = score, cost

bob = [0] * 12
for i in range(12):
    if best >> i & 1:
        bob[i] = aliceArrows[i] + 1
bob[0] += numArrows - best_cost
```

注意 `best` 存的是得分，构造时要用它当掩码——两者恰好都是同一个 `mask` 的产物，别把 `best_cost` 当掩码用。

## 复杂度
时间：`2^12 * 12`，n 是固定 12 个区域，与 `numArrows` 无关。
空间：`O(1)`，只开了 `bob` 长度 12 的数组和几个标量。

## 易错点
- 剩余箭必须塞进 0 分区：若 `numArrows=9` 而赢的区域只花 5 支，剩下 4 支若随手加到某个已赢区域，会破坏「刚好 `aliceArrows[i]+1`」的最小代价，甚至让该区域箭数虚高但得分不变，输出仍合法但容易在别处写错；正确做法是全部加到 `bob[0]`，因为 0 分区得分恒为 0，不影响总分。
- `aliceArrows[i]=0` 的区域要赢需 1 支箭：示例 2 中 `aliceArrows[8]=0`，赢 8 分区花 1 支而非 0 支；若写成 `cost += aliceArrows[i]`，会误判区域 8、9、10 全免费，得到代价 0、得分 27 的假最优，实际需 3 支箭刚好用完 `numArrows=3`。

## 如果面试官追问
若 `numArrows` 涨到 10^9 而区域数仍是 12？答：枚举子集不变，只把 `cost <= numArrows` 的判断保留，剩余箭照样丢 0 分区，复杂度仍是 `2^12 * 12`。
