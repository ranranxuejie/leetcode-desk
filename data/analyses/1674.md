## 一句话思路
对每对 `(a, b)` 用差分数组统计「目标和取 x 时需要几次操作」，再取全局最小值。

## 怎么做
1. 每对 `a = nums[i]`、`b = nums[n-1-i]`，目标和 x 落在 `[2, 2*limit]`；x 在 `[min(a,b)+1, max(a,b)+limit]` 内只需改一个数，否则要改两个，x 恰为 `a+b` 时零次。
2. 用差分数组 `diff` 记录「改两个数」的基线：初始每对贡献 2，即 `diff[2] += 2`、`diff[2*limit+1] -= 2`。
3. 对每对把「改一个数」的区间 `[min+1, max+limit]` 从 2 降到 1（区间减 1），再把 `a+b` 这一点从 1 降到 0（单点减 1）。
4. 前缀和扫 `x = 2..2*limit`，取最小。

以 `nums=[1,2,4,3], limit=4` 为例，第一对 `a=1,b=3`：`min+1=2`、`max+limit=7`，区间 `[2,7]` 减 1；`a+b=4` 单点再减 1。第二对 `a=2,b=4`：区间 `[3,8]` 减 1，`a+b=6` 单点减 1。扫到 `x=4` 时前缀和为 1，即答案。

```python
diff = [0] * (2 * limit + 2)
for i in range(n // 2):
    a, b = nums[i], nums[n - 1 - i]
    lo, hi = min(a, b) + 1, max(a, b) + limit
    diff[2] += 2
    diff[2 * limit + 1] -= 2
    diff[lo] -= 1
    diff[hi + 1] += 1
    diff[a + b] -= 1
    diff[a + b + 1] += 1
ans, cur = n, 0
for x in range(2, 2 * limit + 1):
    cur += diff[x]
    ans = min(ans, cur)
```

## 复杂度
时间 O(n + limit)：n 对做常数次差分，再扫 2*limit 个位置。
空间 O(limit)：只开了长度 2*limit+2 的 `diff` 数组。

## 易错点
- `limit=1` 时 `nums` 全为 1，`a+b=2`，`lo=2`、`hi=2`，区间减 1 和单点减 1 落在同一位置，若把单点写成 `diff[a+b] -= 1` 而漏掉 `diff[a+b+1] += 1`，前缀和会一路错到底，答案偏小。必须成对写。
- 差分数组上界要开到 `2*limit+1`：`hi = max(a,b)+limit` 最大为 `2*limit`，`hi+1` 会写到下标 `2*limit+1`，数组长度按 `2*limit+2` 开，否则 `hi+1` 越界。

## 如果面试官追问
问：要求输出具体的目标和与改动方案？
答：前缀和时记下取最小值的 x，再对每对判断 x 是否等于 a+b、是否落在 `[min+1, max+limit]`，据此决定改 0/1/2 个数并给出新值。
