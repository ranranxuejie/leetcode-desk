## 一句话思路
按元素算贡献：`arr[i]` 出现在「左边取偶数个 + 右边取偶数个」的奇数长子数组里，贡献 = 左偶×右偶 + 左奇×右奇。

## 怎么做
1. 设 `i` 左边有 `l = i` 个元素、右边有 `r = n - 1 - i` 个元素。
2. 左边取偶数个有 `l // 2 + 1` 种（含取 0 个），取奇数个有 `(l + 1) // 2` 种；右边同理。
3. 子数组长度 = 左取数 + 右取数 + 1，要奇数就必须左右同奇偶，所以贡献 = `(l//2+1)*(r//2+1) + ((l+1)//2)*((r+1)//2)`。
4. 累加 `arr[i] * 贡献`。

以 `arr = [1,4,2,5,3]`、`i = 2`（值 2）为例：`l = 2, r = 2`，左偶 = `2//2+1 = 2`，右偶 = 2，左奇 = `3//2 = 1`，右奇 = 1，贡献 = `2*2 + 1*1 = 5`，即 2 出现在 `[2]`、`[4,2,5]`、`[1,4,2]`、`[2,5,3]`、`[1,4,2,5,3]` 这 5 个奇数长子数组里，贡献 `2*5 = 10`。

```python
n = len(arr)
total = 0
for i, x in enumerate(arr):
    l, r = i, n - 1 - i
    le, lo = l // 2 + 1, (l + 1) // 2
    re, ro = r // 2 + 1, (r + 1) // 2
    total += x * (le * re + lo * ro)
return total
```

## 复杂度
时间 O(n)：一次遍历，每个 `i` 只做常数次整除和乘法。
空间 O(1)：只开 `total`、`l`、`r`、`le/lo/re/ro` 几个标量。

## 易错点
- `arr = [1,2]` 时若把「左右同奇偶」写成「左右都取偶数」，`i=0` 的 `r=1` 会漏掉右边取 1 个的情况，`[1,2]` 长度 2 本就不该算，但 `i=1` 的 `l=1` 会漏算 `[1,2]` 之外的组合；正确做法是同时加 `lo*ro` 项，两个示例的 3 和 58 都要对上。
- `arr = [10,11,12]` 若用「枚举所有起点终点再判长度奇偶」的 O(n³) 写法，`n=100` 时是 10⁶ 次内层求和，虽能过但会超时风险；正确做法是上面的 O(n) 贡献法，或至少前缀和降到 O(n²)。

## 如果面试官追问
问：如果要求返回所有奇数长子数组的和的列表而不是总和？
答：贡献法失效，需按长度 1、3、5… 滑动窗口枚举，O(n²) 起步，`n=100` 仍可接受。
