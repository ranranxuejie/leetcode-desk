## 一句话思路
从右往左维护单调递减栈，栈里存「可能的 nums[k]」，再用一个变量 `third` 记录已弹出的最大候选，遇到比 `third` 小的数即成立。

## 怎么做
1. 逆序遍历 `nums`，栈 `st` 保持从栈底到栈顶递减（栈顶最小）。
2. 若 `nums[i] < third`，说明左边找到了 `nums[i]`，中间有比它大的 `nums[j]`，右边有 `third` 这个 `nums[k]`，直接返回 `True`。
3. 否则当 `nums[i] > st[-1]` 时不断弹出栈顶赋给 `third`，再把 `nums[i]` 压栈——被弹出的值都满足「右边存在比它大的数」，是合格的 `nums[k]` 候选。

以 `nums = [3,1,4,2]` 为例：i=3 压 2，`st=[2]`；i=2 时 4>2 弹出，`third=2`，压 4，`st=[4]`；i=1 时 1<2，返回 `True`。

```python
st = []
third = -2**31 - 1
for x in reversed(nums):
    if x < third:
        return True
    while st and x > st[-1]:
        third = st.pop()
    st.append(x)
return False
```

关键中间值：走到 `x=1` 时 `third=2`、`st=[4]`，`1 < 2` 立即命中。

## 复杂度
时间：每个元素进出栈各一次，O(n)。
空间：栈最多存 n 个元素，O(n)。

## 易错点
- `third` 初值写成 `0` 或 `-1`：`nums = [-1,3,2,0]` 里负数会被误判，`-1 < 0` 直接返回 `True` 但实际 `third` 还没被赋值过。正确做法是初始化成 `-2**31 - 1`（题目值域下界之外）。
- 把 `while` 条件写成 `x >= st[-1]`：`nums = [1,2,3,4]` 会因相等元素被反复弹出、`third` 被抬到 3，最后误判。正确做法是严格 `x > st[-1]`，相等时保留栈顶。

## 如果面试官追问
问：要求输出一组具体的 `(i,j,k)` 怎么办？
答：弹出时把 `(下标, 值)` 一起入栈，命中时记录当前 `i`、栈顶对应 `j`、`third` 对应 `k` 即可。
