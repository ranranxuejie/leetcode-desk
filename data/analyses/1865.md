## 一句话思路
把 nums2 做成「值→出现次数」的哈希表，count 时遍历较短的 nums1 查 `tot - x`，add 时同步改表。

## 怎么做
1. 初始化时对 nums2 建 `Counter`（记作 `cnt2`），nums1 原样保存；因为 add 只动 nums2，nums1 无需索引。
2. `add(index, val)`：先从 `cnt2` 里把旧值 `nums2[index]` 的计数减 1，再更新 `nums2[index] += val`，把新值计数加 1。
3. `count(tot)`：遍历 nums1 的每个 `x`，累加 `cnt2.get(tot - x, 0)`，返回总和。
4. 关键中间值：官方示例初始 `cnt2 = {1:1, 4:2, 5:2, 2:1}`，`count(7)` 时 nums1 里 `x=2` 贡献 `cnt2[5]=2`，三个 2 共 6；`x=3` 贡献 `cnt2[4]=2`，合计 8。
```python
from collections import Counter

class FindSumPairs:
    def __init__(self, nums1, nums2):
        self.nums1 = nums1
        self.nums2 = nums2
        self.cnt2 = Counter(nums2)

    def add(self, index, val):
        old = self.nums2[index]
        self.cnt2[old] -= 1
        self.nums2[index] = old + val
        self.cnt2[old + val] += 1

    def count(self, tot):
        return sum(self.cnt2.get(tot - x, 0) for x in self.nums1)
```
注意 `cnt2[old] -= 1` 后若为 0 不必删键，`get` 返回 0 不影响结果。

## 复杂度
时间：count 为 O(len(nums1))，add 为 O(1)，建表 O(len(nums2))。
空间：额外开一个 `cnt2`，大小是 nums2 中不同值的个数。

## 易错点
- `add` 时只更新 `nums2[index]` 忘了改 `cnt2` → 后续 `count` 仍用旧计数，示例中 `add(3,2)` 后 `count(8)` 会错算成 0 而非 2 → 必须旧值减一、新值加一。
- 对 nums1 也建哈希表然后双重遍历 → 示例 `count(7)` 中 nums1 有 3 个 2、nums2 有 2 个 5，若按「值对」计数会得 1 而非 6 → 必须按元素逐个遍历 nums1 累加次数。

## 如果面试官追问
若 add 次数远多于 count，怎么优化？答：把 nums1 也做成 Counter，count 时遍历较小的一侧值域，add 仍 O(1)。
