## 一句话思路
二分答案 `k`，用滑动窗口数出「不同元素数 ≤ k」的子数组个数，与中位数下标比较。

## 怎么做
1. 子数组总数 `m = n*(n+1)//2`，中位数是升序第 `(m+1)//2` 个（1-indexed），即要找最小的 `k` 使 `count(≤k) >= (m+1)//2`。
2. 滑动窗口：右端 `r` 扩张时维护窗口内不同元素数 `d`，当 `d > k` 就左移 `l` 直到 `d <= k`；此时以 `r` 结尾的合法子数组有 `r-l+1` 个，累加。
3. 二分 `k` 在 `[1, n]` 上，`count(≤k) >= target` 时收缩右界。

以 `nums = [3,4,3,4,5]` 为例，`n=5`，`m=15`，`target=8`。取 `k=1`：窗口内不同数始终为 1 时，`r=0` 贡献 1、`r=1` 时 `d=2>1` 左移到 `l=1` 贡献 1，`r=2` 时 `nums[2]=3` 与 `nums[1]=4` 不同又左移……最终 `count(≤1)=5 < 8`，说明 `k=1` 不够；`k=2` 时 `count=12 >= 8`，答案收敛到 2。

```python
def count_leq(k):
    cnt = 0
    l = 0
    freq = {}
    for r, x in enumerate(nums):
        freq[x] = freq.get(x, 0) + 1
        while len(freq) > k:
            y = nums[l]
            freq[y] -= 1
            if freq[y] == 0:
                del freq[y]
            l += 1
        cnt += r - l + 1
    return cnt

lo, hi = 1, len(nums)
while lo < hi:
    mid = (lo + hi) // 2
    if count_leq(mid) >= target:
        hi = mid
    else:
        lo = mid + 1
return lo
```

## 复杂度
时间：二分 `log n` 轮，每轮滑窗 `O(n)`，共 `O(n log n)`。
空间：`freq` 哈希表最多存 `n` 个不同值，`O(n)`。

## 易错点
1. `nums = [1,1,1]` 这类全相同输入 → 若把 `target` 写成 `m//2` 而非 `(m+1)//2`，会偏到更小的 `k`；本题取较小中位数，必须用 `(m+1)//2`。
2. 滑窗里 `freq[y]` 减到 0 后忘记 `del`，`len(freq)` 就永远不降 → `while len(freq) > k` 死循环或计数虚高；正确做法是计数归零立即删除该键。

## 如果面试官追问
若要求返回唯一性数组本身而非中位数？答：无法在 `O(n log n)` 内枚举全部 `O(n^2)` 个子数组，只能按 `k` 分桶计数后定位，仍不构造完整数组。
