## 一句话思路
折半枚举前 n 个与后 n 个元素的所有子集和，按选取个数分组排序，再二分配对。

## 怎么做
1. 把 `nums` 切成 `a = nums[:n]` 和 `b = nums[n:]`，各长 n，枚举子集只需 2^n 次。
2. 对 `a` 的每个掩码算 `(选了几个, 和)`，按个数 k 存进 `sumA[k]`；`b` 同理存 `sumB[k]`。
3. 对每个 k 把 `sumB[n-k]` 排序，遍历 `sumA[k]` 中的 s，二分找最接近 `total/2 - s` 的值。
4. 用 `abs(total - 2*(s+t))` 更新答案，`total = sum(nums)`。

以示例 1 `nums = [3,9,7,3]`，n=2，`a=[3,9]`、`b=[7,3]`，total=22。`sumA[1] = [3,9]`，`sumB[1] = [7,3]` 排序后 `[3,7]`。取 s=3 时目标 `11-3=8`，`bisect_left([3,7],8)=2`，取下标 1 得 t=7，差值 `abs(22-2*10)=2`，即答案。

```python
from bisect import bisect_left
total = sum(nums)
sumA = [[] for _ in range(n + 1)]
sumB = [[] for _ in range(n + 1)]
for mask in range(1 << n):
    sa = sb = 0
    k = mask.bit_count()
    for i in range(n):
        if mask >> i & 1:
            sa += a[i]
            sb += b[i]
    sumA[k].append(sa)
    sumB[k].append(sb)
ans = 2**63 - 1
for k in range(n + 1):
    sumB[n - k].sort()
    for s in sumA[k]:
        target = total / 2 - s
        j = bisect_left(sumB[n - k], target)
        for idx in (j - 1, j):
            if 0 <= idx < len(sumB[n - k]):
                ans = min(ans, abs(total - 2 * (s + sumB[n - k][idx])))
```

## 复杂度
时间：O(2^n · n) 枚举加 O(2^n · n) 二分，n≤15 约 5×10^5 量级。
空间：O(2^n) 存两组子集和，排序原地进行。

## 易错点
- `nums` 含负数（如示例 2 `[-36,36]`）时，若按「选 k 个最大」贪心会错成 0；必须枚举全部 2^n 个子集和，负数让和不再单调。
- 二分只查 `j` 不查 `j-1`：示例 1 中 target=8 落在 `[3,7]` 末尾，`j=2` 越界，漏掉 `j-1=1` 的 7 就会错成 22；两个下标都要判边界。

## 如果面试官追问
问：n 放大到 30 怎么办？答：折半枚举退化，改用 meet-in-the-middle 加剪枝或 DP 按和值域压缩，本题 n≤15 才保证 2^n 可行。
