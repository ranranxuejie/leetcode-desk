## 一句话思路
用 `(x, y)` 哈希集合记黑格，逐步模拟转向移动，同时维护走过的矩形边界。

## 怎么做
1. 状态用 `x, y, d` 表示，`d` 取 0..3 对应右、下、左、上，`black` 集合存黑格坐标。
2. 每步先查 `(x, y) in black`：白格则 `d = (d + 1) % 4` 并加入 `black`，黑格则 `d = (d - 1) % 4` 并移出 `black`。
3. 按 `dx = [0, 1, 0, -1]`、`dy = [1, 0, -1, 0]` 移动，更新 `minx/maxx/miny/maxy`。
4. 最后按 `maxy` 到 `miny` 逐行、`minx` 到 `maxx` 逐列拼字符，蚂蚁所在格写 `"RDLU"[d]`。

以 K=2 为例：起点 `(0,0)` 白，转右朝下、变黑，走到 `(0,-1)`；该格白，转右朝左、变黑，走到 `(-1,-1)`。此时 `black = {(0,0),(0,-1)}`，边界 `x∈[-1,0]`、`y∈[-1,0]`，蚂蚁在 `(-1,-1)` 朝左，输出 `["_X","LX"]`。

```python
black = set()
x = y = 0
d = 0                      # 0右 1下 2左 3上
dx, dy = [0, 1, 0, -1], [1, 0, -1, 0]
minx = maxx = miny = maxy = 0
for _ in range(K):
    if (x, y) in black:
        black.remove((x, y)); d = (d - 1) % 4
    else:
        black.add((x, y));    d = (d + 1) % 4
    x += dx[d]; y += dy[d]
    minx, maxx = min(minx, x), max(maxx, x)
    miny, maxy = min(miny, y), max(maxy, y)
```

## 复杂度
时间：O(K + 矩形面积)，K 步模拟加一次逐格渲染。
空间：O(K)，`black` 最多存 K 个坐标，输出矩形同阶。

## 易错点
- K=0 时若先移动再记录，会输出 `["_"]` 或越界；正确做法是循环 0 次，直接用初始 `(0,0)` 和 `d=0` 渲染出 `["R"]`。
- 行序写反：`y` 向下增长，输出必须从 `maxy` 递减到 `miny`，否则示例 2 会变成 `["LX","_X"]`；列则从 `minx` 递增到 `maxx`。

## 如果面试官追问
K 放大到 10^9 怎么办？答：兰顿蚂蚁轨迹有已知的高速公路周期，可先模拟到进入周期，再按周期长度取模跳过剩余步数。
