## 一句话思路
求前缀和的最小值 `min_pre`，答案就是 `1 - min_pre`（若 `min_pre >= 0` 则取 1），因为 startValue 只需把最深的坑填到 1。

## 怎么做
1. 从左到右累加 `nums`，维护前缀和 `cur` 与历史最小值 `min_pre`。
2. 遍历结束后，`startValue + min_pre >= 1` 即 `startValue >= 1 - min_pre`。
3. 又因 startValue 必须是正数，取 `max(1, 1 - min_pre)`。

以 `nums = [-3,2,-3,4,2]` 为例，前缀和依次为 `-3, -1, -4, 0, 2`，`min_pre = -4`，故 `startValue = 1 - (-4) = 5`。验证：`5 + (-4) = 1`，恰好卡在边界。

```python
cur = 0
min_pre = 0
for x in nums:
    cur += x
    if cur < min_pre:
        min_pre = cur
return max(1, 1 - min_pre)
```

注意 `min_pre` 初始化为 0 而非 `nums[0]`，这样全正数组（如 `[1,2]`）得到 `min_pre = 0`，返回 `max(1, 1) = 1`，与示例 2 一致。

## 复杂度
时间：O(n)，一次遍历 `nums`，每个元素做一次加法和一次比较。
空间：O(1)，只开了 `cur` 和 `min_pre` 两个变量。

## 易错点
- 输入 `nums = [1,2]` → 若把 `min_pre` 初始化为 `nums[0] = 1`，会算出 `1 - 1 = 0`，返回 0 而非正数 → 正确做法是初始化为 0，最后用 `max(1, ...)` 兜底。
- 输入 `nums = [-3,2,-3,4,2]` → 若只记最终前缀和 `2`，会误判 `startValue = 1` 够用，但中途 `cur = -4` 时和为 `-3 < 1` → 必须记录遍历过程中的最小值 `min_pre`，而非末值。

## 如果面试官追问
问：若要求输出所有可行的最小 startValue 方案（即哪些位置触发了下界）？
答：在更新 `min_pre` 时记录首次达到最小值的下标，该下标即约束最紧的位置。
