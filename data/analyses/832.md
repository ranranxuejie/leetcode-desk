## 一句话思路
双指针从每行两端向中间走，交换两端值并同时取反，一趟完成翻转加反转。

## 怎么做
1. 外层遍历每一行 `row`，内层用 `i`、`j = 0, n-1` 相向移动。
2. `i < j` 时，交换 `row[i]` 与 `row[j]` 再各自取反，等价于 `row[i], row[j] = 1 - row[j], 1 - row[i]`。
3. `i == j`（n 为奇数）时中间元素只翻转不交换，写 `row[i] ^= 1`。
4. 原地改完直接返回 `image`。

以示例 1 第一行 `[1,1,0]` 为例：`i=0, j=2`，交换并取反得 `row[0], row[2] = 1-0, 1-1 = 1, 0`，行变成 `[1,1,0]`；`i=1, j=1` 命中中间，`row[1] ^= 1` 得 `0`，最终 `[1,0,0]`，与输出一致。

```python
n = len(image)
for row in image:
    i, j = 0, n - 1
    while i < j:
        row[i], row[j] = 1 - row[j], 1 - row[i]
        i += 1
        j -= 1
    if i == j:
        row[i] ^= 1
return image
```

关键点：交换和取反必须写在同一条赋值里，先交换再取反会多扫一遍；`1 - x` 对 0/1 就是取反，比 `x ^ 1` 和 `not x` 都直观。

## 复杂度
时间 O(n²)：n 行每行 n/2 对，共 n²/2 次交换取反。
空间 O(1)：只用了 `i`、`j` 两个下标，原地修改 `image`。

## 易错点
- n 为奇数如 `[[1]]` 或 `[[1,0,1]]` → 只写 `while i < j` 会漏掉正中元素，`[1,0,1]` 错成 `[1,0,1]` 而非 `[0,1,0]` → 循环后补 `if i == j: row[i] ^= 1`。
- 先整体翻转再整体取反分两趟写 → 第二趟容易把已经处理过的行再翻一次，`[[1,1,0],[1,0,1],[0,0,0]]` 第二行会错成 `[1,0,1]` 而非 `[0,1,0]` → 每行只走一次双指针，交换与取反合并。

## 如果面试官追问
追问：如果要求返回新矩阵、不许改 `image` 怎么办？
答：新建同尺寸矩阵，`res[r][c] = 1 - image[r][n-1-c]`，一趟映射即可，空间升到 O(n²)。
