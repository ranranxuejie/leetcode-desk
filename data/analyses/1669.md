## 一句话思路
双指针先定位 list1 中下标 a-1 的节点 `prev` 和下标 b+1 的节点 `after`，把 `prev.next` 接到 list2 头、list2 尾接到 `after`。

## 怎么做
1. 从 `list1` 走 a-1 步，停在 `prev`（下标 a-1 的节点）。
2. 从 `prev` 再走 b-a+2 步，停在 `after`（下标 b+1 的节点）。
3. 走 `list2` 到尾节点 `tail2`，接 `prev.next = list2`、`tail2.next = after`。

以示例 1 为例：`list1 = [10,1,13,6,9,5], a=3, b=4`。走 a-1=2 步后 `prev` 是值为 13 的节点；从 `prev` 再走 b-a+2=3 步，`after` 是值为 5 的节点（下标 5）。`list2` 尾 `tail2` 是 1000002，接完后 13→1000000，1000002→5。

```python
prev = list1
for _ in range(a - 1):
    prev = prev.next
after = prev
for _ in range(b - a + 2):
    after = after.next
tail2 = list2
while tail2.next:
    tail2 = tail2.next
prev.next = list2
tail2.next = after
return list1
```

关键点：`after` 从 `prev` 出发而不是从 `list1` 头出发，步数是 `b-a+2` 而不是 `b-a+1`——因为要跨过被删的 b-a+1 个节点再多走一步。

## 复杂度
时间：O(a + (b-a) + m) = O(n + m)，n 是 list1 长度、m 是 list2 长度，各扫一遍。
空间：O(1)，只用了 `prev`、`after`、`tail2` 三个指针，没有新建节点。

## 易错点
1. 输入 `a=1`（如 list1=[0,1,2,3], a=1, b=2）→ 若循环写成 `range(a)` 会让 `prev` 停在值为 1 的节点，把下标 0 的节点也删了 → 正确是 `range(a-1)`，a=1 时循环 0 次，`prev` 就是头节点，返回 `list1` 仍正确。
2. 输入 `b = list1.length - 2`（如示例 2 的 b=5，长度 7）→ 若 `after` 循环写成 `range(b-a+1)`，`after` 会停在值为 5 的节点，导致 5 和 6 都被丢掉 → 正确步数是 `b-a+2`，`after` 落在下标 b+1 即值为 6 的节点。

## 如果面试官追问
问：如果 a、b 用 1-based 下标给呢？
答：只需把两处循环改成 `range(a-1)` 和 `range(b-a+1)`，其余不动。
