## 一句话思路
用两个数组分别记录「以 i 结尾的最长非递增长度」和「以 i 开头的最长非递减长度」，再判断是否都 ≥ k。

## 怎么做
1. 从左往右扫，`inc[i]` 表示以 `i` 结尾的连续非递增段长度：`nums[i-1] >= nums[i]` 时 `inc[i] = inc[i-1] + 1`，否则为 1。
2. 从右往左扫，`dec[i]` 表示以 `i` 开头的连续非递减段长度：`nums[i] <= nums[i+1]` 时 `dec[i] = dec[i+1] + 1`，否则为 1。
3. 遍历 `i ∈ [k, n-k-1]`，若 `inc[i-1] >= k and dec[i+1] >= k`，则 `i` 是好下标。

以 `nums = [2,1,1,1,3,4,1], k = 2` 为例：`inc = [1,1,2,3,1,1,1]`（下标 3 处 `1,1,1` 连续非递增，长度 3），`dec = [1,1,1,1,3,2,1]`（下标 4 处 `3,4` 非递减，长度 2）。检查 `i=2`：`inc[1]=1 < 2`，不满足——注意这里 `inc[i-1]` 是 `inc[1]`，而 `nums[0..1]=[2,1]` 是非递增的，长度应为 2，说明 `inc` 定义要改成「以 i 结尾」时 `inc[1]` 应为 2。修正：`inc[0]=1`，`nums[0]>=nums[1]` 故 `inc[1]=2`，`nums[1]>=nums[2]` 故 `inc[2]=3`，`inc[3]=4`，`nums[3]<nums[4]` 故 `inc[4]=1`。于是 `i=2` 时 `inc[1]=2>=2` 且 `dec[3]=1`——`dec[3]` 是 `nums[3..]` 的非递减长度，`nums[3]=1 <= nums[4]=3` 故 `dec[3]=2`，满足。`i=3` 时 `inc[2]=3>=2`、`dec[4]=2>=2`，满足。结果 `[2,3]`。

```python
n = len(nums)
inc = [1] * n
for i in range(1, n):
    if nums[i-1] >= nums[i]:
        inc[i] = inc[i-1] + 1
dec = [1] * n
for i in range(n-2, -1, -1):
    if nums[i] <= nums[i+1]:
        dec[i] = dec[i+1] + 1
res = [i for i in range(k, n-k) if inc[i-1] >= k and dec[i+1] >= k]
```

## 复杂度
时间 O(n)：两次线性扫描加一次判定，n 为数组长度。
空间 O(n)：`inc`、`dec` 各开 n 个整数，结果列表最坏 n 个。

## 易错点
- 边界写成 `range(k, n-k+1)`：`n-k` 本身越界，`dec[i+1]` 会取到 `dec[n]` 报 IndexError。正确是 `range(k, n-k)`，因为 `i` 之后还要留 k 个元素，`i <= n-k-1`。
- 把 `inc[i-1] >= k` 写成 `inc[i] >= k`：`inc[i]` 含 `nums[i]` 本身，而条件只要求 `i` 之前 k 个非递增。示例 1 中 `i=2` 时 `inc[2]=3>=2` 恰好也成立，但 `nums=[1,2,1,1], k=1` 时 `i=1` 的 `inc[1]=1`（`nums[0]<nums[1]`），若用 `inc[1]>=1` 会误判——实际 `nums[0]=1` 单独一个元素非递增，`i=1` 应是好下标，用 `inc[i]` 反而对；真正翻车在 `nums=[1,1,2,1], k=1`，`i=2` 处 `inc[2]=1`（`1<2` 断开），但 `i` 之前只有 `nums[1]=1`，非递增成立，用 `inc[i]` 会漏掉。正确用 `inc[i-1]`。

## 如果面试官追问
若 k 改为每次查询不同值（多次询问）？答：预处理 `inc`、`dec` 后每次查询 O(1) 判定，总 O(n + q)。
