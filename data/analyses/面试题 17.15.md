## 一句话思路
把 words 全塞进哈希集合，按「长度降序、字典序升序」排序后逐个用记忆化 DFS 判断能否被拆成至少两个词。

## 怎么做
1. 建 `S = set(words)`，排序键 `key=lambda w: (-len(w), w)`，第一个能拆的就是答案。
2. 对候选词 `w`，DFS 从下标 0 往后切：`dfs(i)` 表示 `w[i:]` 能否由 S 中词拼出。
3. 枚举切点 `j`，若 `w[i:j] in S` 且 `dfs(j)` 成立则返回 True；`j` 必须大于 `i`，且整词不能一次吃掉自己。
4. 用 `memo` 记录失败下标，避免重复搜索。

以 `"dogwalker"` 为例：`i=0` 时 `j=3` 得 `"dog" in S`，递归 `dfs(3)`；`i=3` 时 `j=7` 得 `"walk" in S`，`dfs(7)` 再取 `"er"` 失败，回溯到 `j=9` 取 `"walker" in S`，`dfs(9)` 到末尾返回 True。关键中间值是 `memo` 里只留下失败的下标 7 和 9。

```python
S = set(words)
def can(w):
    memo = {}
    def dfs(i):
        if i == len(w):
            return True
        if i in memo:
            return memo[i]
        for j in range(i + 1, len(w) + 1):
            if w[i:j] in S and (j < len(w) or i > 0) and dfs(j):
                return True
        memo[i] = False
        return False
    return dfs(0)
```

`j < len(w) or i > 0` 保证至少切两刀，排除整词自匹配。

## 复杂度
时间：O(m·L³)，m 为候选词数、L 为词长，每个下标枚举切点并切片。
空间：O(L) 递归栈加 memo，另有 O(n·L) 存集合 S。

## 易错点
- 输入 `["a"]` 或 `["cat"]`：若不加 `j < len(w) or i > 0`，`"cat"` 会匹配自己返回 `"cat"`；正确做法是强制至少切两段。
- 输入 `["cat","cats","catsdogcats","dog","dogcatsdog"]`：若排序只按长度不按字典序，同长度时可能先返回 `"dogcatsdog"` 而非字典序更小的 `"catsdogcats"`；正确做法是 `(-len(w), w)` 双键排序。

## 如果面试官追问
问：words 规模涨到 10⁴、词长 10³ 怎么办？答：改用字典树存 S，DFS 沿树走而非枚举切点切片，把每层 O(L²) 降到 O(L)。
