## 一句话思路
以每个辅音为界切段，段内用双指针数「含全五种元音」的子串，因为元音子串不可能跨越辅音。

## 怎么做
1. 把 `word` 按非元音字符切成若干纯元音段，逐段处理。
2. 段内固定右端 `r`，用 `cnt` 记录窗口 `[l, r]` 的五种元音计数，`l` 只增不减地右移直到窗口不再含全五种。
3. 此时 `[l, r]` 是含全五种的最短窗口，任何起点 `i < l` 的 `[i, r]` 也合法，贡献 `l` 个子串（起点取 `0..l-1`）。
4. 累加所有 `r` 的贡献。

以 `word = "aeiouu"` 为例：整串是纯元音段。`r=4`（第二个 `u` 之前）时窗口 `[0,4]` 首次凑齐 `a,e,i,o,u`，`l` 停在 0，贡献 `l=0`？不对——`l` 是窗口左端下标，`[0,4]` 合法且 `l=0`，贡献应为 `l+1=1`。`r=5` 时 `l` 仍为 0，贡献 1，合计 2，与示例一致。

```python
VOWELS = set("aeiou")
ans = 0
for seg in re.split(r"[^aeiou]+", word):
    cnt = {}
    l = 0
    for r, ch in enumerate(seg):
        cnt[ch] = cnt.get(ch, 0) + 1
        while len(cnt) == 5:
            cnt[seg[l]] -= 1
            if cnt[seg[l]] == 0:
                del cnt[seg[l]]
            l += 1
        ans += l
```

注意 `while` 退出时 `l` 已经比「最短合法窗口左端」大 1，所以贡献正好是 `l`（起点数 = `l` 个：`0..l-1`）。

## 复杂度
时间 O(n)：每个字符最多被 `l` 和 `r` 各扫一次，`re.split` 也是 O(n)。
空间 O(1)：`cnt` 最多 5 个键，段列表总长不超过 n。

## 易错点
- 输入 `"aeiouu"`：若在 `while` 里先 `l += 1` 再删计数，`l` 会多 1，答案变 3。正确做法是先减计数、判零删除，最后才 `l += 1`，让 `l` 表示「已排除的起点个数」。
- 输入 `"cuaieuouac"`：若不分段、直接在整串上跑双指针，`l` 会跨过辅音 `c`，把含辅音的窗口算进去。正确做法是先用 `re.split(r"[^aeiou]+", word)` 切段，辅音处强制重置 `l=0` 和 `cnt={}`。

## 如果面试官追问
若 `word` 长度放大到 10^5 且要求输出所有合法子串的起止下标，怎么办？
答：仍按辅音分段，段内对每个 `r` 记录最短合法左端 `l`，输出 `(i, r)` 对 `i in range(l)`，总输出量即答案规模。
