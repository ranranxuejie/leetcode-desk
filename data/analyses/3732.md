## 一句话思路
替换值只取 ±10^5 两个极值，枚举「被替换的下标」等价于枚举「原数组中保留的另外两个下标」，取最大。

## 怎么做
1. 关键观察：替换值取 10^5 或 -10^5 时乘积绝对值最大，所以只需考虑这两个候选值。
2. 枚举被替换的下标 i，剩下两个下标从 nums 中除 i 外任选，乘积为 `nums[j]*nums[k]*10^5` 或 `nums[j]*nums[k]*(-10^5)`。
3. 直接枚举 i,j,k 是 O(n^3)，改为：对每个 i，只需知道「除 i 外」的最大两数乘积和最小两数乘积（负数乘负数得正）。
4. 用排序后取前 3 大、前 3 小（含重复下标处理）来覆盖，或直接枚举 i 并维护前后缀极值。

以 `nums = [-5,7,0]` 为例：排序后 `[-5,0,7]`。替换 0 为 -10^5，保留 -5 和 7，乘积 `(-5)*7*(-10^5) = 3500000`，即最大两数乘积 `7*0` 与最小两数乘积 `(-5)*0` 都不如 `(-5)*7` 配负极值。

```python
nums.sort()
n = len(nums)
# 候选：保留最大两数配 +1e5，或保留最小两数配 +1e5，或保留一正一负配 -1e5
cand = []
cand.append(nums[-1] * nums[-2] * 10**5)
cand.append(nums[0] * nums[1] * 10**5)
cand.append(nums[0] * nums[-1] * (-10**5))
cand.append(nums[0] * nums[1] * (-10**5))
cand.append(nums[-1] * nums[-2] * (-10**5))
```

注意：上面只覆盖了「保留的两个数来自排序两端」的情况，严格做法是枚举被替换下标 i，用前缀/后缀最大最小两数乘积。但排序后取前 3 小、前 3 大两两组合已足够覆盖最优解（因为最优保留的两个数必在极值附近）。

## 复杂度
时间：排序 O(n log n)，枚举常数组合 O(1)，n 来自数组长度。
空间：O(1) 额外空间（排序原地，不计输入）。

## 易错点
- 输入 `[-4,-2,-1,-3]` → 若只取最大两数配 +10^5 得 `(-1)*(-2)*10^5=200000`，漏掉最小两数 `(-4)*(-3)*10^5=1200000` → 必须同时枚举最小两数配正极值。
- 输入 `[0,10,0]` → 若忽略 0 的存在直接算极值乘积，会得非零值 → 正确做法是保留 0 与任意数相乘得 0，答案 0；代码中 `nums[0]*nums[1]*10^5` 自然覆盖。

## 如果面试官追问
问：若替换值范围改为 [-k, k] 且 k 很小（如 k=1）怎么办？
答：极值不再是 ±10^5，需枚举替换值取 -k、k 及原数组元素附近的候选，不能只取两端。
