## 一句话思路
把 target 按 x 进制拆位，每层用记忆化在「向下取整」和「向上进位」两种表示间取最小运算符数。

## 怎么做
1. 定义 `dfs(t)`：用 x 的幂表示 t 所需的最少运算符数，t 先按 x 进制处理最低位 `r = t % x`。
2. 最低位有两种凑法：直接加 r 个 x（代价 `r`，但每个 x 之间要 1 个运算符，故为 `r`），或向上进位成 `x - r` 个再减（代价 `x - r`）。
3. 递归到 `t // x` 或 `t // x + 1`，每上升一层，单个 x 的乘号代价加 1。
4. 用字典缓存 `dfs` 结果，避免重复。

以 x=3, target=19 为例：`19 % 3 = 1`，向下走 `dfs(6)` 代价 1，向上走 `dfs(7)` 代价 2；`dfs(6)` 中 `6 % 3 = 0`，直接进 `dfs(2)`；`dfs(2)` 中 `2 % 3 = 2`，向下 `dfs(0)` 代价 2、向上 `dfs(1)` 代价 1。最终拼出 5。

```python
from functools import lru_cache

def least(x, target):
    @lru_cache(None)
    def dfs(t):
        if t == 0:
            return 0
        if t == 1:
            return 1  # 单独一个 x，无运算符
        r = t % x
        down = r + dfs(t // x)
        up = (x - r) + dfs(t // x + 1)
        return min(down, up)
    return dfs(target) - 1  # 减去最顶层多算的一个运算符
```

注意 `t == 1` 返回 1 是占位，最后统一减 1 修正；若 target 本身是 x 的幂，`dfs` 会一路整除到 1。

## 复杂度
时间：O(log_x target) 个状态，每状态 O(1)，即 O(log target)。
空间：递归栈与缓存共 O(log_x target)。

## 易错点
- 输入 x=100, target=100000000 → 若忘记 `t==1` 的基准返回 1，会多算一层乘号，输出 4 而非 3 → 基准要单独处理，最后减 1 修正。
- 输入 x=3, target=19 → 若只考虑向下取整 `r + dfs(t//x)`，得 6 而非 5 → 必须同时比较向上进位 `(x-r) + dfs(t//x+1)`。

## 如果面试官追问
问：若要求输出具体表达式而非仅数量？答：在 `dfs` 里同时返回表达式字符串，按选中的 down/up 分支拼接即可。
