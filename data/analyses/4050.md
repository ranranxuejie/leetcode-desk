## 一句话思路
把 n 拆成若干段连续整数和，段内是 1+2+…+k，段间用跳过隔开，枚举段数做 DP 取最少天数。

## 怎么做
1. 一段长度 k 的连胜得 `k*(k+1)//2` 分、花 k 天；两段之间必须夹 1 天跳过。
2. 设 `dp[s]` 为凑出 s 分的最少天数，转移时枚举最后一段长度 k，`dp[s] = min(dp[s], dp[s - k*(k+1)//2] + k + (1 if s > k*(k+1)//2 else 0))`。
3. 以 n=9 为例：k=3 时 `dp[6]=3`，再补一段 k=2 得 `dp[9]=dp[6]+2+1=6`，与示例一致；k=4 时 `4*5//2=10>9` 直接跳过。
4. 外层 s 从 1 到 n，内层 k 满足 `k*(k+1)//2 <= s`，k 上界约 `sqrt(2n)`。

```python
dp = [0] + [10**9] * n
for s in range(1, n + 1):
    k = 1
    while k * (k + 1) // 2 <= s:
        seg = k * (k + 1) // 2
        cost = dp[s - seg] + k + (1 if s > seg else 0)
        if cost < dp[s]:
            dp[s] = cost
        k += 1
return dp[n]
```

## 复杂度
时间：O(n·sqrt(n))，n 来自分数上限，sqrt(n) 来自单段长度上界。
空间：O(n)，只开了一个长度 n+1 的 dp 数组。

## 易错点
- n=2 → 若只枚举 k=1 得 `dp[2]=dp[1]+1+1=3` 正确，但若漏掉「段间加 1 天跳过」会算成 2 → 转移里必须加 `(1 if s > seg else 0)`。
- n=1 → 若 dp 初值写成 0 而非 `10**9`，`dp[1]` 会被错误地保持 0 → 初值必须设大，且 `dp[0]=0` 单独给。

## 如果面试官追问
问：n 放大到 10^9 怎么办？答：不能开数组，改用数学：找最小 t 使 `t*(t+1)//2 >= n`，再看差值能否用一次跳过调整，否则加天数。
