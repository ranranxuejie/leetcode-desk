## 一句话思路
把项目依赖和小组依赖各做一次拓扑排序：先排小组，再在组内排项目，两层都无环才有解。

## 怎么做
1. 建两张图：项目图 `beforeItems[i]` 里 `u -> i` 表示 u 先于 i；小组图对每条跨组边 `group[u] != group[i]` 加 `group[u] -> group[i]`。
2. 对小组图跑拓扑排序，得到小组顺序 `gorder`；若小组图有环直接返回 `[]`。
3. 对每个小组内部的项目跑拓扑排序，得到组内顺序 `iorder[g]`；任一组内有环返回 `[]`。
4. 按 `gorder` 拼接各组 `iorder`，`group == -1` 的项目各自视为独立单元。

以示例 1 为例：`beforeItems[3] = [6]`，`group[6]=0`、`group[3]=0`，同组不加小组边；`beforeItems[4] = [3,6]`，`group[4]=0`，`group[3]=0`、`group[6]=0`，仍同组。真正跨组的是 `beforeItems[2]=[5]`：`group[5]=1`、`group[2]=1`，同组。示例 1 中所有依赖都在组内，小组图无边，`gorder` 任意；组 0 内项目 `{3,4,6}` 的拓扑序为 `[6,3,4]`，组 1 内 `{2,5}` 为 `[5,2]`，拼接得 `[6,3,4,1,5,2,0,7]`（`-1` 项目 0、1、7 穿插）。

```python
from collections import deque

def topo(nodes, adj, indeg):
    q = deque(x for x in nodes if indeg[x] == 0)
    res = []
    while q:
        u = q.popleft(); res.append(u)
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0: q.append(v)
    return res if len(res) == len(nodes) else []
```

关键点：`-1` 项目不能共用一个「虚拟组」，否则会把无关项目强行相邻；应让每个 `-1` 项目单独成组（或直接当作独立单元处理）。

## 复杂度
时间 O(n + m + E)，E 为 `beforeItems` 总边数，两次拓扑各扫一遍边。
空间 O(n + m + E)，存两张邻接表和两个入度数组。

## 易错点
- 把 `group == -1` 的项目全塞进同一个虚拟组 → 示例 1 中项目 0、1、7 会被强制相邻，输出非法 → 每个 `-1` 项目单独成组，或单独处理。
- 只检查项目图有环、漏查小组图 → 示例 2 中 `beforeItems[4]=[3]` 且 `beforeItems[6]=[4]`，`group[3]=0`、`group[4]=0`、`group[6]=0` 同组，但组内 3→4→6 与 `beforeItems[6]` 无冲突；真正成环的是跨组边 `group[4]=0 -> group[6]=0` 不成立，需仔细核对：示例 2 中 `beforeItems[6]=[4]`，`group[4]=0`、`group[6]=0` 同组，组内 4→6；而 `beforeItems[4]=[3]`，组内 3→4；`beforeItems[3]=[6]`，组内 6→3，形成 3→4→6→3 环 → 必须对每组内部也做环检测。

## 如果面试官追问
问：若要求返回字典序最小的方案怎么办？
答：两次拓扑都把队列换成最小堆，按编号取最小即可，复杂度多一个 log。
