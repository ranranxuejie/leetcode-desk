## 一句话思路
把 `date` 按 `-` 切成三段转成整数，累加前 `month-1` 个月的固定天数，再补上 `day`，闰年时二月多算一天。

## 怎么做
1. 用 `date.split('-')` 得到 `y, m, d` 三个字符串，再 `int()` 转成整数。
2. 准备月份天数表 `days = [31,28,31,30,31,30,31,31,30,31,30,31]`，下标 0 对应一月。
3. 累加 `days[0:m-1]` 的和，再加上 `d`。
4. 若 `m > 2` 且该年是闰年，结果再 `+1`。

以 `"2019-02-10"` 为例：`y=2019, m=2, d=10`，`sum(days[0:1]) = 31`，加 `d` 得 `41`；`m=2` 不满足 `m > 2`，不加闰日，输出 `41`，与示例一致。

```python
y, m, d = map(int, date.split('-'))
days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
ans = sum(days[:m - 1]) + d
leap = (y % 4 == 0 and y % 100 != 0) or y % 400 == 0
if m > 2 and leap:
    ans += 1
return ans
```

关键中间值：`"2019-02-10"` 时 `days[:1]` 是 `[31]`，`sum` 为 `31`，`ans` 先得 `41`。

## 复杂度
时间：O(1)，`split` 与固定长度 12 的月份表求和都不随输入增长。
空间：O(1)，只开了 `days` 这个长度 12 的常量列表和三个整数。

## 易错点
- 输入 `"2000-03-01"` → 若闰年判据只写 `y % 4 == 0`，会把 2000 判成非闰年，少加 1 得 60，正确是 61；必须用 `(y%4==0 and y%100!=0) or y%400==0`。
- 输入 `"2019-01-09"` → 若把闰年判断放在 `m > 2` 之外无条件执行，一月也会被 +1 得 10；正确做法是先判 `m > 2` 再判闰年，一月直接返回 `d`。

## 如果面试官追问
问：若日期范围扩到公元前或改用其他历法怎么办？
答：把月份表和闰年规则抽成参数，闰年判据换成对应历法的函数即可，主流程不变。
