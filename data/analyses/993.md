## 一句话思路
一次 DFS 同时记录 x、y 的深度和父节点值，最后比较这两个字段是否分别相等且父节点不同。

## 怎么做
1. 用 `dfs(node, depth, parent)` 递归，遇到 `node.val == x` 或 `== y` 时把 `(depth, parent)` 存进字典 `info`。
2. 从 `root` 以 `depth=0, parent=None` 出发，左右子树递归时 `depth+1`、`parent=node.val`。
3. 遍历结束后取 `info[x]` 和 `info[y]`，返回 `dx == dy and px != py`。

以示例 2 `root = [1,2,3,null,4,null,5], x = 5, y = 4` 为例：走到节点 4 时 `info[4] = (2, 2)`，走到节点 5 时 `info[5] = (2, 3)`；深度都是 2，父节点 2 ≠ 3，返回 `True`。

```python
def dfs(node, depth, parent):
    if not node:
        return
    if node.val in (x, y):
        info[node.val] = (depth, parent)
    dfs(node.left, depth + 1, node.val)
    dfs(node.right, depth + 1, node.val)

info = {}
dfs(root, 0, None)
dx, px = info[x]
dy, py = info[y]
return dx == dy and px != py
```

关键点：`parent` 传的是**父节点的值**而不是节点对象，因为题目保证值唯一，用值比较最省事；传 `None` 作为根的父节点，根不可能成为答案（x、y 不同且都非根时才有意义）。

## 复杂度
时间 O(n)：每个节点访问一次，n 是节点数。
空间 O(h)：递归栈深度为树高 h，最坏链状 O(n)，另加常数大小的 `info`。

## 易错点
- 输入 `root = [1,2,3,4], x = 4, y = 3` → 若只比较深度会错判为 `True`（4 在深度 2、3 在深度 1，其实深度就不同）；若只比较父节点不同也会错。正确做法是深度和父节点两个条件同时校验，本例 `info[4]=(2,2)`、`info[3]=(1,1)`，深度不等直接 `False`。
- 输入 `root = [1,2,3,null,4], x = 2, y = 3` → 两者深度都是 1 但父节点都是 1，若漏掉 `px != py` 会错成 `True`。正确做法是显式判断父节点值不相等，本例 `info[2]=(1,1)`、`info[3]=(1,1)`，父节点相同返回 `False`。

## 如果面试官追问
问：如果 x、y 可能不在树里怎么办？
答：DFS 结束后先检查 `x in info and y in info`，缺一个直接返回 `False`，再走深度和父节点比较。
