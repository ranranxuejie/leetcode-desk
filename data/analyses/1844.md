## 一句话思路
从左往右扫一遍，奇数位用前一位字母的 ASCII 码加该数字直接算出新字符，因为前一位此时已是最终结果。

## 怎么做
1. 把 `s` 转成列表 `res`，便于按下标原地改写。
2. 遍历 `i` 从 1 开始、步长 2，只处理奇数位。
3. 对每个 `i`，令 `res[i] = chr(ord(res[i-1]) + int(res[i]))`，注意 `res[i-1]` 读的是已替换后的值。
4. 用 `"".join(res)` 返回。

以 `s = "a1b2c3d4e"` 为例，`i=3` 时 `res[2]` 已是 `'b'`（`i=1` 把 `'1'` 换成了 `'b'`），所以 `res[3] = chr(ord('b') + 2) = 'd'`，而不是拿原始的 `'b'` 去加——这里恰好前一位是字母没被改，但 `i=5` 时 `res[4]` 是 `'c'`，`res[5] = chr(ord('c') + 3) = 'f'`，结果 `"abbdcfdhe"` 与示例一致。

```python
res = list(s)
for i in range(1, len(res), 2):
    res[i] = chr(ord(res[i - 1]) + int(res[i]))
return "".join(res)
```

关键点：`int(res[i])` 把字符数字转成整数，`ord`/`chr` 完成字母偏移，题目保证不越过 `'z'`，无需取模。

## 复杂度
时间 O(n)：一次遍历，每个奇数位做常数次 `ord`/`chr`/`int`。
空间 O(n)：`list(s)` 和 `"".join` 各开一份长度 n 的字符序列。

## 易错点
- 输入 `"a1c1e1"` 时若先算出所有新字符再统一写回，`i=3` 读到的 `res[2]` 仍是 `'c'` 没问题，但若把 `res[i-1]` 误写成原始 `s[i-1]`，在 `"a1b2c3d4e"` 的 `i=5` 处会拿 `'c'` 加 3 得 `'f'` 碰巧对，换成前一位被改过的构造就会错——正确做法是始终读 `res[i-1]`。
- 输入含 `'0'` 如 `"a0b0"` 时，若用 `ord(res[i]) - ord('0')` 之外的写法（比如直接 `ord(res[i])`）会把 `'0'` 的 ASCII 48 加进去，得到远超 `'z'` 的字符——正确做法是 `int(res[i])` 或 `ord(res[i]) - 48`。

## 如果面试官追问
若允许数字是多位数（如 `"a12"`），怎么改？答：奇数位不再单字符，需按连续数字段解析成整数再 `chr(ord(前字母) + 数值)`，遍历改为跳段。
