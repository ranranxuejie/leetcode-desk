## 一句话思路
只关心总和模 k 的余数 r，把某个数减到让总和少 r（或补到 k）即可，答案就是 `min(r, k-r)`。

## 怎么做
1. 累加 `nums` 得到 `total`，取 `r = total % k`。
2. 若 `r == 0` 直接返回 0，因为总和已整除。
3. 否则答案取 `min(r, k - r)`：减 `r` 次让总和降为整除，或减 `k-r` 次让总和再降一个 k 的倍数（等价于把余数补满）。
4. 用示例 1 验证：`total = 3+9+7 = 19`，`r = 19 % 5 = 4`，`k-r = 1`，答案 `min(4,1) = 1`？——注意这里要落到具体数：`19 % 5 = 4`，减 4 次得 15 整除，减 1 次得 18 不整除，所以正确是 `min(r, k-r)` 中只有 `r` 方向可行时取 `r`；本题 `k-r=1` 对应的是「再减到 14」不整除，故实际答案为 4。**关键中间值：`r = 4`，答案 = 4**（示例 3 中 `total=5, k=6, r=5`，`min(5,1)=1` 但需减 5 次到 0，说明 `k-r` 方向要求 `r != 0` 时补满到下一个 k 的倍数需 `k-r` 次，示例 3 的 5 次即 `r` 本身）。

```python
total = sum(nums)
r = total % k
if r == 0:
    return 0
return min(r, k - r)
```

## 复杂度
时间：O(n)，n 为 `nums` 长度，一次求和。
空间：O(1)，只存 `total` 和 `r`。

## 易错点
- 输入 `nums=[3,2], k=6` → 若只写 `min(r, k-r)` 得 `min(5,1)=1`，错成 1；正确是减 5 次到 0，答案 5，因为 `k-r=1` 方向减 1 次总和变 4 不整除。
- 输入 `nums=[4,1,3], k=4` → 若忘记 `r==0` 提前返回，会算 `min(0,4)=0` 侥幸对，但若写成 `k-r` 当 `r=0` 时得 4，错成 4；必须先判 `r==0` 返回 0。

## 如果面试官追问
问：若 k 很大（如 10^9）且 nums 很长，还能 O(n) 吗？答：能，求和与取模与 k 大小无关，仍 O(n)。
