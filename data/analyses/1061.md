## 一句话思路
用并查集把等价字符合并成组，每组取字典序最小的字符作为代表，再逐位替换 baseStr。

## 怎么做
1. 初始化 26 个字母的父数组 `parent[i] = i`，并查集的根就是该组当前的最小字符。
2. 遍历 s1、s2，对每对 `(s1[i], s2[i])` 做 union，合并时**让字典序小的字符当根**（`parent[max] = min`），这样根天然是组内最小值。
3. 对 baseStr 每个字符 `c`，查 `find(c)` 得到组内最小字符，拼成结果。

以示例 1 为例：`s1="parker"`, `s2="morris"`。处理到 `('p','m')` 时 `parent['p'-'a'] = 'm'-'a'`，即 p 挂到 m 下；处理 `('r','r')` 无变化；`('k','r')` 让 r 挂到 k 下，之后 `('e','i')` 让 i 挂到 e 下。最终 `find('p')` 返回 `'m'`，`find('s')` 沿 s→r→k 返回 `'k'`，所以 baseStr 的 `'p'` 变 `'m'`、`'s'` 变 `'k'`，得到 `"makkek"`。

```python
parent = list(range(26))

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

for a, b in zip(s1, s2):
    ra, rb = find(ord(a) - 97), find(ord(b) - 97)
    if ra != rb:
        parent[max(ra, rb)] = min(ra, rb)

return ''.join(chr(find(ord(c) - 97) + 97) for c in baseStr)
```

关键点：`parent[max(ra, rb)] = min(ra, rb)` 保证根始终是组内最小字母，省掉最后再扫一遍每组求最小值。

## 复杂度
时间 O((|s1| + |baseStr|)·α(26))，α 近似常数，n 由两串长度贡献。
空间 O(26) 的 parent 数组，与输入规模无关。

## 易错点
- 合并时写成 `parent[ra] = rb`（不比较大小）→ 示例 1 中 `('p','m')` 会让 m 挂到 p 下，`find('p')` 返回 `'p'`，输出 `"parker"` 而非 `"makkek"`。必须让 `min(ra, rb)` 当根。
- 只对 s1、s2 里出现过的字符建映射、忘了 baseStr 里可能有不参与等价的字符（如示例 3 的 `'u'`）→ 会漏掉或报 KeyError。正确做法是 26 个字母全初始化 `parent[i]=i`，未合并的字符 `find` 返回自身。

## 如果面试官追问
若字符集扩到全部 ASCII（256 个）怎么办？答：把 26 换成 256，`ord(c)` 直接当下标，逻辑不变，复杂度仍是 O(α(256))。
