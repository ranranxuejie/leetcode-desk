## 一句话思路
维护已扫描数组的最小值和最大值，用当前数组的极值分别与它们作差取最大，因为跨数组最大距离必由某数组的最小值配另一数组的最大值产生。

## 怎么做
1. 用 `min_val = arrays[0][0]`、`max_val = arrays[0][-1]` 初始化，`ans = 0`。
2. 从第二个数组开始遍历，先算 `cur[0]` 与 `max_val`、`cur[-1]` 与 `min_val` 的差，更新 `ans`。
3. 再用 `cur[0]`、`cur[-1]` 更新 `min_val`、`max_val`。
4. 顺序不能反：先算距离再更新极值，否则同一数组会被配对。

以示例 1 `[[1,2,3],[4,5],[1,2,3]]` 为例：初始 `min_val=1, max_val=3, ans=0`。处理 `[4,5]` 时，`5-1=4`、`4-3=1`，`ans` 变为 4，随后 `min_val` 仍为 1、`max_val` 变为 5。处理第三个数组时 `1-5=-4`、`3-1=2`，`ans` 保持 4。

```python
min_val, max_val = arrays[0][0], arrays[0][-1]
ans = 0
for cur in arrays[1:]:
    ans = max(ans, cur[-1] - min_val, max_val - cur[0])
    min_val = min(min_val, cur[0])
    max_val = max(max_val, cur[-1])
return ans
```

## 复杂度
时间 O(N)，N 为所有数组元素总数，每个数组只取首尾两个元素。
空间 O(1)，只开了 `min_val`、`max_val`、`ans` 三个变量。

## 易错点
- 输入 `[[1],[1]]` → 若把 `ans` 初始化为 `-1` 或忘记处理单元素数组，会返回错误值 → 正确做法是 `ans = 0`，因为 `1-1=0` 是合法答案。
- 输入 `[[1,4],[0,5]]` → 若先更新 `min_val`/`max_val` 再算距离，会让同一数组的 `0` 和 `5` 配对得到 5，但题目要求两个不同数组 → 必须先算 `cur[-1]-min_val` 和 `max_val-cur[0]`，再更新极值。

## 如果面试官追问
若要求输出具体是哪两个数组和哪两个数，怎么改？
答：在更新 `ans` 时额外记录 `min_val` 所属数组下标和 `max_val` 所属下标，返回时带上这两个下标及对应值即可。
