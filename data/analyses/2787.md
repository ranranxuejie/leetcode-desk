## 一句话思路
把每个候选底数 i 的 i^x 当成一件 0/1 背包物品，对容量 n 做方案数背包 DP。

## 怎么做
1. 先枚举出所有 i^x ≤ n 的底数 i，得到物品列表 `items`；n=10、x=2 时 `items = [1, 4, 9]`（i=1,2,3，4^2=16 已超）。
2. 定义 `dp[s]` 为「用已处理过的物品凑出和 s 的方案数」，初始化 `dp[0] = 1`。
3. 对每个 `v in items`，容量 s 从 n 倒序降到 v，执行 `dp[s] += dp[s-v]`；倒序保证每个底数只用一次。
4. 返回 `dp[n] % (10**9+7)`。

关键中间值（n=10, x=2）：处理 v=1 后 dp[1..10] 全为 1；处理 v=4 后 dp[5]=1（1+4）、dp[10]=1（1+9 尚未加入，此时 dp[10] 仍为 0，处理 v=9 后 dp[10] 由 dp[1] 贡献变为 1）；最终 dp[10]=1，对应 1+9。

```python
MOD = 10**9 + 7
items = []
i = 1
while i**x <= n:
    items.append(i**x)
    i += 1
dp = [0] * (n + 1)
dp[0] = 1
for v in items:
    for s in range(n, v - 1, -1):
        dp[s] = (dp[s] + dp[s - v]) % MOD
return dp[n]
```

注意 `i**x` 在 x=1 时就是 i 本身，items 会是 1..n 全部整数，这正是示例 2 里 n=4 得到 2 种（4；3+1）的原因。

## 复杂度
时间：O(√[x]{n} · n)，物品数约 n^(1/x)，每个物品扫一遍 n 个容量。
空间：O(n)，只有一维 dp 数组，无额外二维表。

## 易错点
- 内层容量写成正序 `for s in range(v, n+1)` → n=4, x=1 时 1 会被重复使用，dp[4] 算成 5 而非 2 → 必须倒序，保证 0/1 而非完全背包。
- 枚举底数时用 `i <= n` 而非 `i**x <= n` → n=300, x=5 时会把 4^5=1024 这类超容量物品塞进 items，虽不影响 dp[n] 但白跑循环；更糟的是 x=1 时若误用 `i*i <= n` 会漏掉 3、4 等底数，n=4 输出错成 1 → 统一写 `while i**x <= n`。

## 如果面试官追问
问：若允许重复使用同一个幂（完全背包）怎么改？
答：内层容量改成正序 `for s in range(v, n+1)`，其余不动。
