## 一句话思路
从低位向高位逐位相加，进位在 -2 进制下可以取 -1、0、1，用 `carry` 统一处理即可。

## 怎么做
1. 双指针从 `arr1`、`arr2` 末尾往前扫，`i`、`j` 越界时该位取 0。
2. 每轮算 `total = a + b + carry`，当前位是 `total % 2`，新进位是 `-(total // 2)`。
3. 把当前位 `append` 进结果，最后反转；去掉末尾（反转后是开头）多余的 0。

以示例 1 为例，最低位 `a=1, b=1, carry=0`，`total=2`，当前位 `2 % 2 = 0`，新进位 `-(2 // 2) = -1`。下一位 `a=1, b=0, carry=-1`，`total=0`，位为 0，进位 `-(0 // 2) = 0`。这就是 -2 进制与普通二进制的核心差别：进位可以是负数。

```python
res, carry = [], 0
i, j = len(arr1) - 1, len(arr2) - 1
while i >= 0 or j >= 0 or carry:
    a = arr1[i] if i >= 0 else 0
    b = arr2[j] if j >= 0 else 0
    total = a + b + carry
    res.append(total % 2)
    carry = -(total // 2)
    i, j = i - 1, j - 1
while len(res) > 1 and res[-1] == 0:
    res.pop()
return res[::-1]
```

注意 `total % 2` 在 Python 里对负数也返回非负余数（`-1 % 2 == 1`），正好符合「位只能是 0 或 1」的要求，不用额外修正。

## 复杂度
时间 O(max(len(arr1), len(arr2)))，循环次数由较长数组长度加进位决定。
空间 O(max(len(arr1), len(arr2)))，`res` 存结果位，无其他辅助结构。

## 易错点
- 输入 `arr1=[1], arr2=[1]`：若照搬普通二进制写 `carry = total // 2`，得到进位 1，结果会错成 `[1,0]`（表示 -2），正确进位是 `-(2 // 2) = -1`，结果应为 `[1,1,0]`（表示 2）。
- 输入 `arr1=[0], arr2=[0]`：若循环条件只写 `i >= 0 or j >= 0`，会正常退出，但若忘了最后的去零，`res` 反转后可能带前导 0；正确做法是 `while len(res) > 1 and res[-1] == 0: res.pop()`，保证 `[0]` 不被删空。

## 如果面试官追问
问：如果改成 -3 进制怎么做？答：同样逐位加，当前位取 `total % 3`，进位 `-(total // 3)`，只是取模和整除的基数从 2 换成 3。
