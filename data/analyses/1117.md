## 一句话思路
用两个信号量 `h`、`o` 加一把锁控制配比：氧线程先抢锁再等两个氢，氢线程先等氧再放行，保证每 3 个线程成组。

## 怎么做
1. 初始化 `h = Semaphore(0)`、`o = Semaphore(0)`、`lock = Lock()`，`h` 表示已就位的氢数，`o` 表示氧是否已到。
2. 氧线程：`lock.acquire()` 后 `o.release()` 放行一个氧，再 `h.acquire()` 两次等两个氢，最后 `lock.release()`。
3. 氢线程：`o.acquire()` 等氧就位，`releaseHydrogen()` 输出，`h.release()` 通知氧「我又到了一个」。
4. 关键在锁只包住氧的「登记 + 等氢」段，氢线程不进锁，避免死锁。

以 `water = "HOH"` 为例：第一个 H 线程卡在 `o.acquire()`；O 线程拿到锁，`o.release()` 唤醒它，自己阻塞在第一次 `h.acquire()`；H 输出后 `h.release()`，O 醒来再等第二个 H；第二个 H 同样先过 `o`（此时 `o` 已被 O 消费，需 O 再 `release`）——所以 `o` 的放行次数必须与氧线程数一致，靠 `lock` 保证一个氧只放一个氢过 `o` 门。

```python
def hydrogen():
    o.acquire()          # 等一个氧就位
    releaseHydrogen()
    h.release()          # 告诉氧：来了一个氢

def oxygen():
    lock.acquire()
    o.release()          # 放一个氢过 o 门
    h.acquire()          # 等第一个氢
    h.acquire()          # 等第二个氢
    releaseOxygen()
    lock.release()
```

## 复杂度
时间：O(n)，n 为水分子数，每个线程只做常数次信号量操作。
空间：O(1)，两个信号量加一把锁，与 n 无关。

## 易错点
- 输入 `"OOHHHH"`（两个氧连发）→ 若 `o` 只 `release` 一次，第二个氧线程永远等不到氢、第一个氢线程抢不到 `o` 门，整体卡死 → 每个氧线程都必须各自 `o.release()` 一次，放行次数等于氧线程数。
- 输入 `"HHHOOO"`（氢先扎堆）→ 若把 `h.release()` 写在 `releaseHydrogen()` 之前，氧可能在氢真正输出前就凑齐两个 `h` 并 `releaseOxygen()`，导致输出顺序错乱成 `OHH` 之外的非法组合 → 必须先 `releaseHydrogen()` 再 `h.release()`，保证「输出」与「计数」同序。

## 如果面试官追问
问：若要求严格按到达顺序输出（不允许重排）怎么办？
答：把 `o`/`h` 换成带序号的 `Condition`，按到达序号排队唤醒，配比约束不变。
