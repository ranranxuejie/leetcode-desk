## 一句话思路
统计每个字符出现次数的奇偶性，奇数频次字符不超过 1 个即可重排成回文。

## 怎么做
1. 用一个整数 `mask` 记录每个字符频次的奇偶：出现一次就异或翻转对应位。
2. 遍历 `s` 的每个字符 `c`，执行 `mask ^= 1 << (ord(c) - ord('a'))`。
3. 遍历结束后，`mask` 中为 1 的位就是出现奇数次的字符。
4. 判定 `mask & (mask - 1) == 0`，即最多只有一位为 1。

以官方示例 `s = "tactcoa"` 为例，逐字符异或后，`t`、`a`、`c`、`o` 各出现两次，对应位被翻转回 0；最终 `mask` 只剩 `t` 对应的位（`1 << 19`），`mask & (mask - 1) == 0` 成立，返回 `True`。

```python
mask = 0
for c in s:
    mask ^= 1 << (ord(c) - ord('a'))
return mask & (mask - 1) == 0
```

如果字符集不限于小写字母，可改用哈希表统计频次，再数奇数个数是否 `<= 1`：

```python
from collections import Counter
odd = sum(v % 2 for v in Counter(s).values())
return odd <= 1
```

位运算版本的关键中间值是 `mask`：它不记录具体次数，只记录「奇/偶」，这正是回文排列的充要条件——回文串最多允许一个字符落在正中间，其余字符必须成对出现。

## 复杂度
时间 O(n)：`n = len(s)`，每个字符做一次移位和异或。
空间 O(1)：`mask` 是单个整数，26 个小写字母只占 26 位。

## 易错点
- 输入 `s = ""` → 若把「奇数频次字符数」写成必须恰好为 0 或 1 且漏掉空串分支，会错判；空串是合法回文排列，`mask = 0` 时 `mask & (mask - 1) == 0` 恰好返回 `True`，不要额外加 `if not s: return False`。
- 输入 `s = "aab"` → 若用「字符种类数是否为奇数」判断会错成 `False`；正确做法是数频次的奇偶，`a` 出现 2 次、`b` 出现 1 次，奇数频次只有 1 个，应返回 `True`。

## 如果面试官追问
问：如果要求输出一个具体的回文排列而不是只判真假？
答：把奇数频次字符放中间，其余每字符取一半拼左半，再镜像右半即可。
