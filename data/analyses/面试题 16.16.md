## 一句话思路
从左往右扫记录「当前最大值」，凡是比它小的位置都说明左边界至少到这里；反向同理定右边界。

## 怎么做
1. 正向扫一遍，维护 `mx = array[0]`，若 `array[i] < mx` 则更新 `right = i`，否则 `mx = array[i]`。
2. 反向扫一遍，维护 `mn = array[-1]`，若 `array[i] > mn` 则更新 `left = i`，否则 `mn = array[i]`。
3. 若 `left == -1`（没被更新过）说明整体有序，返回 `[-1, -1]`。

用官方示例 `[1,2,4,7,10,11,7,12,6,7,16,18,19]`：正向扫到 `i=6` 时 `array[6]=7 < mx=11`，`right` 更新为 6；继续扫到 `i=8` 时 `array[8]=6 < mx=11`，`right` 变成 8；`i=9` 时 `array[9]=7 < mx=11`，`right` 最终为 9。反向扫到 `i=5` 时 `array[5]=11 > mn=7`，`left` 更新为 5；继续到 `i=3` 时 `array[3]=7 > mn=6`，`left` 变成 3。结果 `[3,9]`。

```python
left, right = -1, -1
mx = array[0]
for i in range(1, len(array)):
    if array[i] < mx:
        right = i
    else:
        mx = array[i]
mn = array[-1]
for i in range(len(array) - 2, -1, -1):
    if array[i] > mn:
        left = i
    else:
        mn = array[i]
return [left, right] if left != -1 else [-1, -1]
```

关键点：`right` 记录的是「最后一个小于左侧最大值的下标」，`left` 记录的是「最前一个大于右侧最小值的下标」，两者夹出的区间恰好覆盖所有乱序元素。

## 复杂度
时间：O(n)，正向反向各扫一遍，n 为数组长度。
空间：O(1)，只开了 `mx`、`mn`、`left`、`right` 四个变量。

## 易错点
- 输入 `[1,3,2,4]` → 只比较相邻元素会以为只需换 `3,2`，但正确区间是 `[1,2]`（下标 1 到 2），因为 `3` 和 `2` 都要动；必须用「左侧最大值」而非「前一个元素」判断。
- 输入 `[2,1]` → 反向扫时若把 `mn` 初始化为 `array[0]` 而非 `array[-1]`，`left` 会漏更新；`mn` 必须从最右端开始，保证比较的是「右侧最小值」。

## 如果面试官追问
问：如果数组含大量重复元素，比如 `[1,1,1,0,1,1]`，算法还对吗？
答：对，`<` 和 `>` 严格比较，重复值不会误触发边界更新，结果仍是 `[0,3]`。
