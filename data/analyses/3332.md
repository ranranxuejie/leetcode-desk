## 一句话思路
按天滚动 DP：`dp[c]` 表示第 i 天结束时人在城市 c 的最大点数，每天从「原地留」和「从任意城市飞来」取最大。

## 怎么做
1. 初始化 `dp = [0]*n`，因为第 0 天之前没有任何得分，起点任意。
2. 对每一天 `i` 从 0 到 k-1，用旧 `dp` 算出新 `ndp[c]`：留在 c 得 `dp[c] + stayScore[i][c]`，从 p 飞来得 `dp[p] + travelScore[p][c]`。
3. 取所有来源的最大值写进 `ndp[c]`，一天算完再整体替换 `dp = ndp`。
4. 返回 `max(dp)`。

以示例 2 为例（n=3, k=2）：第 0 天 `dp` 从 `[0,0,0]` 出发，`ndp = [3,4,2]`（只能原地留，因为起点任意且第 0 天没有「前一天城市」）。第 1 天算 `ndp[2]`：留城 2 得 `2 + stayScore[1][2] = 2+2 = 4`；从城 1 飞来得 `dp[1] + travelScore[1][2] = 4+4 = 8`，取 8。最终 `max(dp) = 8`。

```python
dp = [0] * n
for i in range(k):
    ndp = [0] * n
    for c in range(n):
        best = dp[c] + stayScore[i][c]
        for p in range(n):
            if p != c:
                best = max(best, dp[p] + travelScore[p][c])
        ndp[c] = best
    dp = ndp
return max(dp)
```

关键点：第 0 天不能「飞来」，但 `dp` 全 0 时 `dp[p] + travelScore[p][c]` 只会更小或相等（travelScore 非负，但 stayScore ≥ 1），所以统一公式不会错。

## 复杂度
时间：O(k·n²)，每天对每个目的地 c 枚举 n 个来源 p。
空间：O(n)，只开 `dp` 和 `ndp` 两个长度 n 的数组。

## 易错点
- 把 `ndp` 写成原地更新 `dp[c]`：第 1 天算 `ndp[2]` 时若已覆盖 `dp[1]`，`dp[1] + travelScore[1][2]` 会用当天的新值，示例 2 会算出 10 而非 8。必须用独立 `ndp` 再整体替换。
- 漏掉「起点任意」：若强行固定起点为城市 0，示例 2 第 0 天只能得 `stayScore[0][0]=3`，最终最多 7。正确做法是 `dp` 初始全 0，让第 0 天每个城市都能作为起点。

## 如果面试官追问
若 k 和 n 都放大到 10⁵ 且 travelScore 是稠密矩阵，怎么办？答：稠密矩阵下 O(k·n²) 无法避免，只能改用「每行取最大两个来源」的技巧把内层降到 O(1)，但前提是 travelScore 行最大值可预处理。
