## 一句话思路
用异或算无进位和、与运算左移算进位，循环到进位为 0，即得两数之和。

## 怎么做
1. 令 `a` 存无进位和、`b` 存进位，循环条件是 `b != 0`。
2. 每轮先算 `carry = (a & b) << 1`，再算 `a = a ^ b`，最后 `b = carry`。
3. 顺序不能反：`a` 被覆盖后 `a & b` 就错了，所以进位必须先存进临时变量。
4. 以 `a = 2, b = 3` 为例：`2 & 3 = 2`，左移得 `carry = 4`；`2 ^ 3 = 1`，于是 `a = 1, b = 4`。第二轮 `1 & 4 = 0`，`carry = 0`；`1 ^ 4 = 5`，`a = 5, b = 0`，循环结束返回 5。

```python
a, b = 2, 3
while b != 0:
    carry = (a & b) << 1
    a = a ^ b
    b = carry
# a == 5
```

负数靠 Python 的无限位补码天然成立：`a = -1, b = 1` 时 `-1 & 1 = 1`，`carry = 2`，`-1 ^ 1 = -2`；下一轮 `-2 & 2 = 2`，`carry = 4`，`-2 ^ 2 = -4`……进位不断左移，直到 `b` 超出 `a` 的位宽后 `a & b = 0`，循环终止，结果正确。所以本题不需要额外处理符号位。

## 复杂度
时间：O(log(max(|a|,|b|)))，进位每轮左移一位，最多循环到最高位。
空间：O(1)，只开了 `carry` 一个临时变量。

## 易错点
- 写成 `a = a ^ b; b = (a & b) << 1` → `a` 已被覆盖，`a & b` 用的是新 `a`，`a=2,b=3` 会算出 `b = (1 & 3) << 1 = 2` 死循环 → 必须先存 `carry` 再改 `a`。
- 用 `while a != 0` 或把 `a` 当循环条件 → `a = 1, b = 2` 第一轮后 `a = 3` 看似没事，但 `a = 0, b = 5` 这类输入会直接跳过循环返回 0 → 循环条件必须是 `b != 0`，因为终止标志是进位。

## 如果面试官追问
问：如果要求答案按 32 位截断（超出 `2**31 - 1` 回绕）怎么办？
答：循环结束后把 `a` 对 `2**32` 取模，再判断是否大于 `2**31 - 1`，是则减 `2**32`。
