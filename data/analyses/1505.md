## 一句话思路
从左到右逐位贪心：在剩余 k 次交换内，把当前位置能拉到的最靠前的最小数字换过来，用树状数组维护每个数字的原始下标。

## 怎么做
1. 为每个数字 0-9 建一个队列，按原串顺序存它的下标。
2. 从左到右填答案位，对每个位置尝试数字 d 从 0 到 9，取该数字队列的队首下标 p，用树状数组查询 p 前面还有多少个尚未被移走的数字，这个数就是把它移到当前位置所需的交换次数。
3. 若该次数 ≤ 剩余 k，就选它：k 减去次数，弹出队首，树状数组在 p 处减 1，填答案；否则试下一个 d。
4. 若 0-9 都不可行，就保留原位置数字，同样弹出队首、树状数组减 1。

以 `num="4321", k=4` 为例：位置 0 试 d=1，其下标 p=3，树状数组前缀和显示 p 前有 3 个未移走的数（4、3、2），3 ≤ 4，于是 k 变为 1，答案首位填 `1`；位置 1 试 d=2，p=2，前面剩 4、3 两个，2 > 1 不可行，试 d=3 得 p=1，前面剩 1 个，1 ≤ 1，填 `3`，k 变 0；剩下按原序补出 `42`，得 `1342`。

```python
# bit 为树状数组，初始每个位置都是 1
for i in range(n):
    for d in range(10):
        if not pos[d]:
            continue
        p = pos[d][0]
        cost = query(p)          # p 之前仍存活的数字个数
        if cost <= k:
            k -= cost
            pos[d].popleft()
            update(p, -1)
            ans.append(str(d))
            break
```

## 复杂度
时间：O(10 · n · log n)，n = len(num)，每位最多试 10 个数字，每次树状数组查询/更新 log n。
空间：O(n)，树状数组、10 个下标队列、答案串各占 O(n)。

## 易错点
- `num="100", k=1`：若只允许把比当前位更小的数字前移、不允许 0 前移，会输出 `100`；正确做法是 d 从 0 开始试，0 的下标 p=1，前缀和 1 ≤ k，输出 `010`，前导 0 必须保留。
- `num="4321", k=4`：若用「原始下标差」当交换次数，位置 0 拉 1 会算成 3 次没错，但位置 1 拉 2 时原始差是 1、实际前面只剩 1 个存活数，两者恰好相等容易蒙对；换成 `num="54321"` 就会偏差——必须用树状数组前缀和统计存活数，不能用 `p - i`。

## 如果面试官追问
若 k 缩小到 10^4 且 n 不变，能否去掉 log？答：可以，用链表加每步线性扫描前 k 个存活位置找最小数字，O(n·k) 在小 k 下更快。
