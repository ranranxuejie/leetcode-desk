## 一句话思路
枚举每个位置当峰值，用单调栈分别预处理左右两侧「不升/不降」的最大高度和，取 `left[i]+right[i]-maxHeights[i]` 的最大值。

## 怎么做
1. 从左往右扫，维护一个**严格递增**的栈（存下标），栈内高度单调不减，算出 `left[i]`：以 `i` 结尾、左侧非降的最大高度和。
2. 弹栈时把被弹出段整段压平到 `maxHeights[i]`，用 `left[栈顶] + (i-栈顶)*maxHeights[i]` 累加，避免逐元素重算。
3. 从右往左同样扫一遍得 `right[i]`，最后遍历取 `left[i]+right[i]-maxHeights[i]` 的最大值。

以 `maxHeights = [6,5,3,9,2,7]` 为例：扫到 `i=3`（值 9）时栈里是 `[2]`（值 3），`left[3] = left[2] + (3-2)*9 = 6+9 = 15`；右侧 `right[3]` 同理得 9+2+2=13，峰值和 `15+13-9 = 19`？实际最优峰值在 `i=3` 得 22，因为 `left[3]` 应为 `3+3+3+9=18`——注意 `left[2]=6` 是 `3+3`，加 `(3-2)*9` 得 15 是错的，正确是 `left[2] + (3-2)*9` 中 `left[2]` 已含下标 2 的 3，`i-栈顶=1` 段只补下标 3 的 9，故 `6+9=15` 对应 `[3,3,3,9]` 前四和 18？——这里 `left[2]=6` 是 `[3,3]` 下标 0,1，加下标 2 的 3 才是 9。**关键：`left[i]` 定义含 `i` 本身**，弹栈后 `left[i] = left[top] + (i-top)*maxHeights[i]`，`top` 是弹完后栈顶，`i-top` 段含 `i`。

```python
def maximumSumOfHeights(maxHeights):
    n = len(maxHeights)
    left = [0]*n
    st = []
    for i, h in enumerate(maxHeights):
        while st and maxHeights[st[-1]] >= h:
            st.pop()
        left[i] = (left[st[-1]] if st else 0) + (i - (st[-1] if st else -1)) * h
        st.append(i)
    right = [0]*n
    st = []
    for i in range(n-1, -1, -1):
        h = maxHeights[i]
        while st and maxHeights[st[-1]] >= h:
            st.pop()
        right[i] = (right[st[-1]] if st else 0) + ((st[-1] if st else n) - i) * h
        st.append(i)
    return max(left[i] + right[i] - maxHeights[i] for i in range(n))
```

## 复杂度
时间：每个下标入栈出栈各一次，O(n)。
空间：`left`、`right`、栈各 O(n)。

## 易错点
- 弹栈条件写成 `>` 而非 `>=`：`[3,2,5,5,2,3]` 中相邻相等 5 不弹，`left[3]` 会少算一段，正确用 `>=` 保证相等高度也压平。
- `left[i]` 忘记含 `i` 本身：`[6,5,3,9,2,7]` 在 `i=3` 会算成 15 而非 18，最终答案 19 而非 22；公式里 `(i-top)` 段必须包含 `i`。

## 如果面试官追问
要求输出具体 heights 方案怎么办？答：在求 `left`/`right` 时记录每个 `i` 的「左侧压平起点」`top`，回溯时从峰值向两侧按 `maxHeights` 与栈分段填值即可，O(n) 还原。
