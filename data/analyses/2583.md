## 一句话思路
BFS 逐层累加得到每层和，存入列表后降序取第 k 个；层数不足 k 返回 -1。

## 怎么做
1. 用队列 `q` 做 BFS，每轮先记下 `len(q)` 作为本层节点数，只处理这么多节点。
2. 累加本层所有节点值得到 `level_sum`，把非空子节点入队，再把 `level_sum` 追加到 `sums`。
3. 队列空后，若 `len(sums) < k` 返回 -1，否则 `sorted(sums, reverse=True)[k-1]`。

以示例 1 为例：第一轮 `q=[5]`，`level_sum=5`，入队 8、9；第二轮处理 2 个节点，`level_sum=8+9=17`，入队 2、1、3、7；第三轮 `level_sum=2+1+3+7=13`，入队 4、6；第四轮 `level_sum=10`。`sums=[5,17,13,10]`，降序 `[17,13,10,5]`，`k=2` 取 13。

```python
from collections import deque
q = deque([root])
sums = []
while q:
    level_sum = 0
    for _ in range(len(q)):
        node = q.popleft()
        level_sum += node.val
        if node.left: q.append(node.left)
        if node.right: q.append(node.right)
    sums.append(level_sum)
if len(sums) < k:
    return -1
sums.sort(reverse=True)
return sums[k - 1]
```

关键点：`for _ in range(len(q))` 必须在循环前求值，否则边入队边扩张会把下一层混进本层。

## 复杂度
时间 O(n + L log L)，n 是节点数（每个节点进出队一次），L 是层数（排序）。
空间 O(n)，队列最宽一层 + `sums` 列表各占 O(n)。

## 易错点
- 输入 `root=[1,2,null,3], k=1`：若把 `null` 当节点入队，`level_sum` 会算错或抛 `AttributeError`。正确做法是入队前判 `if node.left` / `if node.right`，跳过 `None`。
- 输入 `root=[1,2,3], k=5`（层数 2 < k）：直接 `sums[k-1]` 会 `IndexError`。正确做法是先判 `len(sums) < k` 返回 -1，再取下标。

## 如果面试官追问
问：节点值上限 10^6、n=10^5，层和会溢出吗？
答：Python 整数无溢出；若换 C++ 需用 `long long`，单层最大 10^11 超 32 位。
