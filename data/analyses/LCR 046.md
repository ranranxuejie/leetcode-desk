## 一句话思路
BFS 逐层遍历，每层最后一个出队的节点就是该层右视图值。

## 怎么做
1. 空树直接返回 `[]`，否则把 `root` 放进队列 `q`。
2. 每轮先记下当前层的节点数 `size = len(q)`，这个数就是本层要弹出几次。
3. 循环 `size` 次弹出队首，把左右非空孩子入队；当弹到第 `size` 次（即 `i == size - 1`）时，把该节点值追加进 `res`。
4. 队列空时 `res` 就是答案。

以示例 1 的 `[1,2,3,null,5,null,4]` 为例：第 1 层 `q=[1]`，`size=1`，弹出 1 时 `i==0==size-1`，`res=[1]`，入队 2、3；第 2 层 `q=[2,3]`，`size=2`，弹出 2 时 `i=0` 不记录，入队 5，弹出 3 时 `i=1==size-1`，`res=[1,3]`，入队 4；第 3 层 `q=[5,4]`，`size=2`，弹出 5 不记录，弹出 4 时 `i=1`，`res=[1,3,4]`。注意 5 是 2 的右孩子，但它在第 3 层排在 4 左边，所以看不到——右视图看的是「每层最右」，不是「每个右孩子」。

```python
from collections import deque
q = deque([root]) if root else deque()
res = []
while q:
    size = len(q)
    for i in range(size):
        node = q.popleft()
        if i == size - 1:
            res.append(node.val)
        if node.left:
            q.append(node.left)
        if node.right:
            q.append(node.right)
```

DFS 也能做：先递归右子树，用 `depth` 记录层号，当 `depth == len(res)` 时说明这一层第一次被访问，此时节点必是最右节点，追加即可。

## 复杂度
时间 O(n)：每个节点入队出队各一次，n 为节点数。
空间 O(w)：队列最多存一层，w 为最大层宽，最坏 O(n)。

## 易错点
- 输入 `[1,2,3,null,5,null,4]` → 若误以为「每层取最右的非空孩子」会得到 `[1,3,4]` 碰巧对，但换成 `[1,2,3,4]` 就会错成 `[1,3]`（第 3 层只有 4，是 2 的左孩子，仍应输出 4）→ 正确做法是取每层最后一个出队节点，与它是左孩子还是右孩子无关。
- 输入 `[1,null,3]` → 若在入队前就判断 `node.right` 是否存在来记录，会漏掉只有左孩子的层 → 必须在弹出时按 `i == size - 1` 记录，保证每层恰好记一个。

## 如果面试官追问
追问：不用队列，O(1) 额外空间能做吗？
答：可以，Morris 式遍历或先序 DFS 只维护 `depth` 和结果数组，递归栈深度 O(h)，h 为树高。
