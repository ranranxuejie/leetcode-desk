## 一句话思路
先筛出 `0..n-1` 中的质数下标，再按质数/非质数把 `nums[i]` 累加到两个和里，最后取绝对差。

## 怎么做
1. 用埃氏筛预处理长度 `n` 的布尔表 `is_prime`，`is_prime[0] = is_prime[1] = False`。
2. 遍历 `i in range(n)`，质数下标累加到 `sum_a`，否则累加到 `sum_b`。
3. 返回 `abs(sum_a - sum_b)`。

以 `nums = [-1,5,7,0]` 为例：`n = 4`，筛后 `is_prime = [F,F,T,T]`。`i=0` 非质数，`sum_b = -1`；`i=1` 非质数，`sum_b = 4`；`i=2` 质数，`sum_a = 7`；`i=3` 质数，`sum_a = 7 + 0 = 7`。最终 `abs(7 - 4) = 3`。

```python
n = len(nums)
is_prime = [True] * n
if n > 0: is_prime[0] = False
if n > 1: is_prime[1] = False
for p in range(2, int(n ** 0.5) + 1):
    if is_prime[p]:
        for k in range(p * p, n, p):
            is_prime[k] = False
sum_a = sum_b = 0
for i, x in enumerate(nums):
    if is_prime[i]:
        sum_a += x
    else:
        sum_b += x
return abs(sum_a - sum_b)
```

注意 `n = 1` 时 `is_prime[1]` 越界，必须先判 `n > 1`；`n = 2` 时 `is_prime[1] = False` 后循环 `range(2, 2)` 为空，正确。

## 复杂度
时间：`O(n log log n)`，筛法贡献 `log log n`，累加贡献 `n`。
空间：`O(n)`，额外开了长度 `n` 的 `is_prime` 布尔表。

## 易错点
- `nums = [5]`（`n = 1`）→ 直接写 `is_prime[1] = False` 会 `IndexError` → 先判 `n > 1` 再置 `False`，此时 `sum_a = 0`、`sum_b = 5`，答案 5。
- `nums = [2,3,4]` 中下标 0、1 不是质数 → 误把 `nums[0]=2` 当质数下标元素放进 A，得 `|2+4-3|=3` → 质数定义要求大于 1，`is_prime[0]` 和 `is_prime[1]` 都必须为 `False`，正确答案 1。

## 如果面试官追问
问：`n` 扩大到 `10^7` 且只查询少数几个下标是否为质数，还筛吗？
答：改用单点 `O(sqrt(i))` 试除，避免 `O(n)` 布尔表开销。
