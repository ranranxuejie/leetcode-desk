## 一句话思路
一次遍历同时累加满足 `x % 3 == 0 and x % 2 == 0` 的元素和与个数，最后用 `total // cnt` 取整。

## 怎么做
1. 初始化 `total = 0`、`cnt = 0`，分别记录合格元素的和与个数。
2. 遍历 `nums`，用 `x % 3 == 0 and x % 2 == 0` 判断；`x % 6 == 0` 等价，但写两个条件更贴合题意。
3. 命中就 `total += x`、`cnt += 1`。
4. 循环结束后 `cnt == 0` 直接返回 `0`，否则返回 `total // cnt`。

以 `nums = [1,3,6,10,12,15]` 为例：`3` 被 3 整除但是奇数，跳过；`6` 命中，此时 `total = 6, cnt = 1`；`12` 命中，`total = 18, cnt = 2`；`15` 是奇数，跳过。最终 `18 // 2 = 9`。

```python
total = 0
cnt = 0
for x in nums:
    if x % 3 == 0 and x % 2 == 0:
        total += x
        cnt += 1
return total // cnt if cnt else 0
```

关键点：`//` 在 Python 里对正数是向下取整，本题 `nums[i] >= 1`，`total` 和 `cnt` 都非负，所以 `total // cnt` 就是题目要的「向下取整」，不需要 `math.floor`。若用 `/` 会得到 `9.0` 这种浮点，虽然示例 1 恰好整除看不出差别，但换成 `[6, 12, 18]` 之外的组合（比如只有 `6` 和 `12` 之外的奇数个）就可能出现 `.5`，返回类型也会错。

## 复杂度
时间 O(n)：一次遍历 `nums`，每个元素做两次取模。
空间 O(1)：只开了 `total`、`cnt` 两个整型变量。

## 易错点
- 输入 `nums = [3, 9, 15]` → 只判 `x % 3 == 0` 会把三个奇数全算进去，得到 `(3+9+15)//3 = 9`，而正确答案是 `0` → 必须同时判 `x % 2 == 0`，或直接判 `x % 6 == 0`。
- 输入 `nums = [1,2,4,7,10]` → 忘记处理 `cnt == 0` 直接写 `total // cnt` 会抛 `ZeroDivisionError` → 返回前先判 `cnt`，为空返回 `0`。

## 如果面试官追问
问：如果要求返回所有满足条件的偶数列表而不是平均值？答：把 `total += x` 换成 `res.append(x)`，最后返回 `res`，复杂度不变。
