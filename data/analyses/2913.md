## 一句话思路
n≤100，直接双重循环枚举所有子数组，用 set 统计不同值个数再平方累加即可。

## 怎么做
1. 外层 `i` 从 0 到 n-1，内层 `j` 从 `i` 到 n-1，枚举每个子数组 `nums[i..j]`。
2. 内层维护一个 `seen = set()`，每加入 `nums[j]` 就更新，`len(seen)` 即当前子数组的不同计数。
3. 把 `len(seen) ** 2` 累加到 `ans`。
4. 返回 `ans`。

以 `nums = [1,2,1]` 为例：`i=0` 时，`j=0` 得 `seen={1}`，贡献 1；`j=1` 得 `seen={1,2}`，贡献 4；`j=2` 时 `1` 已在集合中，`seen` 仍为 `{1,2}`，贡献 4。`i=1` 贡献 1+4，`i=2` 贡献 1，合计 15。

```python
ans = 0
n = len(nums)
for i in range(n):
    seen = set()
    for j in range(i, n):
        seen.add(nums[j])
        ans += len(seen) ** 2
return ans
```

关键点：`seen` 必须在内层循环外、外层循环内新建，这样每个 `i` 都从空集开始，`j` 递增时集合只增不减，正好对应子数组向右扩展。

## 复杂度
时间：O(n²)，外层 n 次、内层平均 n/2 次，每次 set 操作 O(1)。
空间：O(n)，`seen` 最多存 n 个不同值，无其他额外结构。

## 易错点
- 把 `seen = set()` 写在内层 `j` 循环里 → 每个子数组都重新统计，`[1,2,1]` 的 `[1,2,1]` 会算成 1 而非 2 → 正确做法是放在 `i` 循环内、`j` 循环外，让集合随 `j` 累积。
- 用 `len(set(nums[i:j+1]))` 每次切片重建集合 → 逻辑对但多一层 O(n) 开销，n=100 虽不超时，但把简单题写成 O(n³)；应复用 `seen` 增量更新。

## 如果面试官追问
若 n 放大到 10⁵ 怎么办？答：需按右端点扫描，用「每个不同值上一次出现位置」维护贡献，配合树状数组/线段树做区间加与平方和维护，O(n log n)。
