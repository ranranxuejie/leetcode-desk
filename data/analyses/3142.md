## 一句话思路
逐格检查：下方存在就要求相等，右方存在就要求不等，任一违反立即返回 `False`。

## 怎么做
1. 用 `m, n = len(grid), len(grid[0])` 取行列数，双重循环遍历每个 `grid[i][j]`。
2. 若 `i + 1 < m` 且 `grid[i][j] != grid[i+1][j]`，直接返回 `False`。
3. 若 `j + 1 < n` 且 `grid[i][j] == grid[i][j+1]`，直接返回 `False`。
4. 全部格子走完没触发返回，说明都满足，返回 `True`。

以示例 2 的 `grid = [[1,1,1],[0,0,0]]` 为例：走到 `i=0, j=0` 时，下方 `grid[1][0]=0` 与 `grid[0][0]=1` 不等，第 2 步立刻返回 `False`——其实还没轮到检查右边那对 `1,1`。反过来说，示例 1 的 `[[1,0,2],[1,0,2]]` 里每列上下相等（`1==1`、`0==0`、`2==2`），每行相邻都不同（`1!=0`、`0!=2`），两个条件同时成立才返回 `True`。

```python
m, n = len(grid), len(grid[0])
for i in range(m):
    for j in range(n):
        if i + 1 < m and grid[i][j] != grid[i + 1][j]:
            return False
        if j + 1 < n and grid[i][j] == grid[i][j + 1]:
            return False
return True
```

关键点是把「下方相等」和「右方不等」写成两个独立的 `if`，不要合并成一个条件——它们方向不同、判定符号相反，合并容易把 `!=` 和 `==` 写反。

## 复杂度
时间 O(m·n)：每个格子最多做两次常数比较，m 行 n 列各贡献一层循环。
空间 O(1)：只用了 `i, j, m, n` 几个标量，没有额外开数组。

## 易错点
- 输入 `[[1],[2],[3]]`（单列多行）→ 只检查右边会漏掉整列，误判成 `True` → 必须保留 `i + 1 < m` 的向下比较，示例 3 正是靠它返回 `False`。
- 输入 `[[1,1,1],[0,0,0]]` → 若先判右边再判下边、或把两个条件用 `and` 串起来，可能因短路顺序不同而漏判 → 两个方向各自独立判断，任一不满足就 `return False`，别依赖短路顺序。

## 如果面试官追问
问：如果要求返回第一个违反条件的位置怎么办？
答：把两处 `return False` 改成 `return (i, j)`，循环结束返回 `None` 表示全部满足。
