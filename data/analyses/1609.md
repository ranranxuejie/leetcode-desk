## 一句话思路
按层 BFS，每层用 `prev` 记录上一个值，边遍历边校验奇偶性与单调性，任一层失败即返回 `False`。

## 怎么做
1. 队列初始化为 `[root]`，`level = 0`。
2. 每轮先取 `size = len(q)`，只处理这 `size` 个节点，保证同一层一起比较。
3. 偶数层要求 `val % 2 == 1` 且 `val > prev`；奇数层要求 `val % 2 == 0` 且 `val < prev`。
4. 把子节点入队，`level += 1`，队列空则返回 `True`。

以示例 2 的 `root = [5,4,2,3,3,7]` 为例，第 2 层节点是 `[3,3,7]`：处理到第二个 `3` 时 `prev = 3`，`3 > 3` 不成立，直接返回 `False`——这正是官方解释里说的「2 层不满足严格递增」。

```python
q, level = [root], 0
while q:
    prev = None
    for _ in range(len(q)):
        node = q.pop(0)
        v = node.val
        if level % 2 == 0:
            if v % 2 == 0 or (prev is not None and v <= prev):
                return False
        else:
            if v % 2 == 1 or (prev is not None and v >= prev):
                return False
        prev = v
        if node.left: q.append(node.left)
        if node.right: q.append(node.right)
    level += 1
return True
```

关键点：`prev` 每层重置为 `None`，用 `prev is not None` 而不是 `prev != 0` 判首元素，否则值为 0 的节点会被误判。

## 复杂度
时间 O(n)：每个节点入队出队各一次，n 为节点数。
空间 O(w)：队列最多存一层节点，w 为最大层宽，最坏 O(n)。

## 易错点
- 输入 `[5,4,2,3,3,7]` 的第 2 层 `[3,3,7]` → 若把递增写成 `v >= prev` 才报错，就会漏掉相等的情况 → 必须用 `v <= prev` 判失败，严格递增不允许相等。
- 输入 `[1,10,4,3,null,7,9,...]` 中某层首节点值为 0 → 若用 `prev = 0` 初始化并靠 `prev != 0` 判断首元素，会把 0 当成「还没赋值」→ 用 `prev = None` 加 `is not None` 判断。

## 如果面试官追问
问：节点数涨到 10^7、树极深怎么办？
答：BFS 队列会撑爆内存，改成 DFS 带 `(node, level)` 递归，用每层 `prev` 数组记录，空间降到 O(树高)。
