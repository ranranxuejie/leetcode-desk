## 一句话思路
把每个字母当点、`words` 里的二元串当有向边建图，最短公共超序列长度 = 边数 + 该弱连通分量的最少链覆盖数，用状压 DP 枚举链覆盖。

## 怎么做
1. 只保留出现过的字母（≤16 个），把 `words` 中 `"xy"` 建成边 `x→y`；`"xx"` 是自环，只贡献一次频率，不参与拓扑。
2. 对每个弱连通分量单独处理：分量内边数 `E` 固定，超序列长度 = `E + k`，`k` 是该分量 DAG 的最少链覆盖数（Dilworth：`k = |V| - 最大匹配`，但这里点少，直接状压枚举链划分）。
3. 枚举所有把分量点集划分成若干条链的方案，取 `k` 最小的那些；每条链内部顺序唯一（DAG 上链的拓扑序唯一），链与链之间任意交错，所以频率 = 各点出现次数之和，与交错方式无关。
4. 把各分量的候选频率向量做笛卡尔积，去重后返回。

以 `words = ["ab","ba"]` 为例：点 `{a,b}`，边 `a→b`、`b→a`，成环，无法划分成链，`k=2`，长度 `2+2=4`？实际答案是 3。这里要修正：环上 `a→b→a` 的链覆盖需 2 条链，但 `"aba"` 长度 3 已覆盖两条边，说明长度公式应为 `E + k - (环带来的重复点)`。正确做法是先对分量做 SCC 缩点，环内点必须全部出现至少一次，再对缩点后的 DAG 求链覆盖。

```python
# 缩点后对 DAG 求最少链覆盖（状压）
def min_chains(n, adj):
    # dp[mask] = 用链覆盖 mask 的最少条数
    dp = [n + 1] * (1 << n)
    dp[0] = 0
    for mask in range(1 << n):
        # 枚举一条链：从 mask 中选一个拓扑序合法的子集
        for sub in range(mask, 0, (mask - 1) & mask):
            if is_chain(sub, adj):
                dp[mask] = min(dp[mask], dp[mask ^ sub] + 1)
    return dp[(1 << n) - 1]
```

## 复杂度
时间：`O(2^16 * 2^16)` 枚举链划分，实际按分量规模远小于此，`16` 是不同字母数上限。
空间：`O(2^16)` 的 `dp` 数组，外加每个分量的候选频率列表。

## 易错点
- 输入 `["ab","ba"]` 直接对原图求链覆盖会得 `k=2`、长度 4，错成 `[2,2]`；正确是先 SCC 缩点，环内点各计一次，得 `"aba"`/`"bab"` 两种频率。
- 输入 `["aa","ac"]` 时自环 `aa` 只让 `a` 的频率 +1，若把自环也当边参与拓扑会误判成环、多算长度；正确做法是自环单独累加频率、不进邻接表。

## 如果面试官追问
问：若 `words[i].length` 不固定为 2 呢？
答：边变成超边，链覆盖退化为一般 DAG 路径覆盖，状压仍可用但需先对每条串内部去重。
