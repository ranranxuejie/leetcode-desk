## 一句话思路
把所有字符串看成图的点，相似就连边，用并查集数连通块个数，因为相似性可传递成组。

## 怎么做
1. 初始化 `parent = list(range(n))`，`n = len(strs)`，每个串自成一族。
2. 双重循环枚举 `i < j`，对每对串判断是否相似：逐位比较，统计不同位置数 `diff`。
3. 相似条件写成 `diff == 0 or diff == 2`（题面保证互为字母异位词，所以不会出现 `diff == 1`）。
4. 相似就 `union(i, j)`，最后统计 `parent[x] == x` 的根个数。

以 `strs = ["tars","rats","arts","star"]` 为例，`i=0, j=1` 时逐位比 `tars` 与 `rats`：位置 0 是 `t`≠`r`，位置 2 是 `r`≠`t`，其余相同，`diff = 2`，于是 `union(0,1)`。再看 `i=0, j=3`，`tars` 与 `star` 四位全不同，`diff = 4`，不合并，`star` 单独成组，答案 2。

```python
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

for i in range(n):
    for j in range(i + 1, n):
        diff = sum(a != b for a, b in zip(strs[i], strs[j]))
        if diff == 0 or diff == 2:
            ri, rj = find(i), find(j)
            if ri != rj:
                parent[ri] = rj
return sum(find(i) == i for i in range(n))
```

## 复杂度
时间：O(n² · L)，n 个串两两配对，每对逐位比较 L 个字符。
空间：O(n)，`parent` 数组存 n 个根，无额外字符串拷贝。

## 易错点
- 把相似条件写成 `diff <= 2` → 对 `["omv","ovm"]` 这类 `diff = 2` 的能过，但遇到 `diff = 1` 的非法输入会误判；本题保证字母异位词所以 `diff` 只能是 0、2 或 ≥3，写 `diff == 0 or diff == 2` 才严谨。
- 只比较相邻两个串就合并 → 对 `["tars","rats","arts","star"]` 会得到 3 组（漏掉 `tars` 与 `arts` 的间接连通）；必须两两全枚举再并查集，靠传递性把 `tars`—`rats`—`arts` 串成一组。

## 如果面试官追问
问：n 涨到 10⁵ 怎么办？答：先按字符计数签名分桶，只在同桶内两两比较，跨桶必不相似，可把 O(n²) 降到桶内规模。
