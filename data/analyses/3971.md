## 一句话思路
二分一个阈值 x，只取每次收益 ≥ x 的选择，用等差求和算出总收益与次数，再补差额。

## 怎么做
1. 对下标 i，第 t 次收益 `value[i] - decay[i]*(t-1) ≥ x` 等价于 `t ≤ (value[i]-x)//decay[i] + 1`，记这个次数为 `cnt_i`（负数取 0）。
2. 二分 x：x 越大总次数越少，找最大的 x 使 `sum(cnt_i) ≥ m`，此时所有 ≥ x 的收益都该拿。
3. 设阈值 x 下总次数 `tot ≥ m`、总收益 `S`，多出的 `tot - m` 次是收益恰为 x 的那些，扣掉 `(tot-m)*x`。
4. 用示例 1 验证：`value=[6,5,4], decay=[2,1,1], m=4`，x=4 时 cnt 为 `[2,2,1]`，tot=5，S=6+4+5+4+4=23，扣 `(5-4)*4=4` 得 19。

```python
def maxTotalValue(value, decay, m):
    def count(x):
        tot = s = 0
        for v, d in zip(value, decay):
            if v >= x:
                c = (v - x) // d + 1
                tot += c
                s += c * v - d * c * (c - 1) // 2
        return tot, s
    lo, hi = 0, max(value)
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if count(mid)[0] >= m:
            lo = mid
        else:
            hi = mid - 1
    tot, s = count(lo)
    return (s - (tot - m) * lo) % (10**9 + 7)
```

## 复杂度
时间 O(n log(max(value)))，n 来自每轮遍历 value/decay，log 来自二分。
空间 O(1)，只用了 tot、s、lo、hi 几个标量。

## 易错点
- `value=[4,3], decay=[5,4], m=5`：若强行凑满 5 次会取到负收益，答案错成 4+3-1-1-2=3；正确是只取 4、3 得 7，因为收益 ≤0 的选择不该做，`tot` 可能小于 m。
- `value=[7,2,2], decay=[3,2,1], m=2`：若按「每个下标先取一次再比第二次」贪心会先拿 7、2 得 9；正确是连取下标 0 两次得 7+4=11，必须让同一下标的高收益项参与全局排序，二分阈值正好做到这点。

## 如果面试官追问
要求输出具体选择方案怎么办？答：在阈值 x 下对每个下标取满 `cnt_i` 次，再从收益恰为 x 的项里删掉 `tot-m` 个即可。
