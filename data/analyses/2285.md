## 一句话思路
总重要性 = Σ(城市值 × 该城市度数)，把 1..n 中最大的值配给度数最大的城市，排序后加权求和。

## 怎么做
1. 用长度 n 的 `deg` 数组统计每个城市在 `roads` 中出现的次数。
2. 把 `deg` 降序排序，让下标 0 对应最大度数。
3. 令最大度数乘 n、次大乘 n-1，依次递减，累加。

以示例 1 为例，`deg = [2,3,4,2,1]`，降序后 `[4,3,2,2,1]`。加权：`4*5 + 3*4 + 2*3 + 2*2 + 1*1 = 20+12+6+4+1 = 43`，与输出一致。注意城市 2 度数为 4，拿到值 5；城市 4 度数为 1，拿到值 1。

```python
deg = [0] * n
for a, b in roads:
    deg[a] += 1
    deg[b] += 1
deg.sort(reverse=True)
ans = 0
for i, d in enumerate(deg):
    ans += d * (n - i)
return ans
```

关键点：每条道路 `[a,b]` 对总和的贡献是 `val[a] + val[b]`，把所有道路加起来，城市 `a` 的值 `val[a]` 恰好被加了 `deg[a]` 次。所以总和 = Σ `deg[i] * val[i]`，这是重排不等式：两个序列同序相乘最大。

## 复杂度
时间：O(n + m + n log n)，m = len(roads) 用于统计度数，n log n 来自排序。
空间：O(n)，只开了 `deg` 数组，排序原地进行。

## 易错点
- `roads` 为空或城市孤立：孤立城市度数为 0，仍要参与排序占位。若只对出现过的城市排序，`n - i` 的权重会错位，示例 2 中城市 1 度数为 0 但必须占一个位置，否则权重从 5 开始递减会算错。
- 返回值类型：题目要求 `long`，Python 整数无溢出问题，但若用其他语言需注意 `n=5*10^4` 时最大度数可达 `5*10^4`，乘 `n` 后约 `2.5*10^9` 超过 `2**31 - 1`，必须用 64 位。

## 如果面试官追问
要求输出具体分配方案怎么办？答：排序时保留原城市下标（对 `(deg[i], i)` 排序），按降序位置依次赋 `n, n-1, ...` 即可还原每个城市的值。
