## 一句话思路
贪心取最小的可用正整数，遇到 `target - x` 已在集合里就跳过，用等差数列公式一次算完。

## 怎么做
1. 从小到大枚举候选值 `x = 1, 2, 3, ...`，只取不与已选值冲突的数。
2. 关键观察：冲突只发生在 `x` 与 `target - x` 之间。当 `x < target - x`（即 `2x < target`）时，`target - x > x` 还没被选，`x` 一定安全；当 `x >= target - x` 时，`target - x` 已被选过，`x` 必须跳过。
3. 所以安全区是 `1 .. (target-1)//2`，共 `m = (target-1)//2` 个数。若 `n <= m`，答案就是 `1+2+...+n`；否则先取完这 `m` 个，再从 `target` 开始连续取 `n - m` 个（`target, target+1, ...` 两两之和都 ≥ `2*target > target`，不会冲突）。
4. 两段都用等差数列求和，最后对 `10**9 + 7` 取模。

以 `n = 3, target = 3` 为例：`m = (3-1)//2 = 1`，先取 `[1]`，再从 `target=3` 取 `3-1=2` 个得 `[3,4]`，和 `1 + 3 + 4 = 8`。

```python
MOD = 10**9 + 7
m = (target - 1) // 2
if n <= m:
    ans = n * (n + 1) // 2
else:
    ans = m * (m + 1) // 2
    k = n - m
    ans += k * (2 * target + k - 1) // 2
return ans % MOD
```

## 复杂度
时间：O(1)，只有几次整数运算，与 `n`、`target` 的规模无关。
空间：O(1)，没有开集合或数组。

## 易错点
- `target = 1` 时 `m = 0`，安全区为空，必须直接从 `1` 开始取 `n` 个（`1,2,...,n`）。若照搬「从 `target` 开始取」会得到 `1,2,...` 恰好也对，但若写成从 `target+1` 起就错了，正确做法是第二段起点恒为 `target`。
- `n` 很大（如 `n = 10**9`）时若真去循环枚举会超时；且 `n*(n+1)//2` 在 Python 里不会溢出，但题目要求对 `10**9+7` 取模，必须在最后 `% MOD`，不能中途漏掉导致输出巨大整数。

## 如果面试官追问
问：若要求输出这个最小和对应的数组本身？
答：前 `min(n,m)` 个取 `1..min(n,m)`，剩余从 `target` 起连续补齐即可，O(n) 输出。
