## 一句话思路
枚举 top 与 left 两个词，用首尾字符约束筛出 right 与 bottom，四角条件即全部约束。

## 怎么做
1. 把 words 按首字母分桶 `by_first`，按尾字母分桶 `by_last`，方便 O(1) 取候选。
2. 枚举 `top` 和 `left`，要求 `top[0] == left[0]`，否则跳过。
3. 由 `top[3]` 定 right 的首字母、`left[3]` 定 bottom 的首字母，再要求 `right[3] == bottom[3]`。
4. 四个词互不相同，收集后按元组字典序排序。

以示例 1 为例，取 `top="able"`、`left="area"`：`top[3]='e'` 所以 right 从 `by_first['e']` 取到 `"echo"`；`left[3]='a'` 所以 bottom 从 `by_first['a']` 取到 `"also"`；校验 `right[3]='o' == bottom[3]='o'` 通过，得到 `["able","area","echo","also"]`。

```python
by_first, by_last = {}, {}
for w in words:
    by_first.setdefault(w[0], []).append(w)
    by_last.setdefault(w[3], []).append(w)

res = []
for top in words:
    for left in words:
        if top[0] != left[0] or top == left:
            continue
        for right in by_first.get(top[3], []):
            for bottom in by_first.get(left[3], []):
                if right[3] != bottom[3]:
                    continue
                if len({top, left, right, bottom}) == 4:
                    res.append([top, left, right, bottom])
res.sort()
```

## 复杂度
时间：O(n² + n²·k²)，n 为 words 长度（≤15），k 为单桶平均大小，排序 O(m log m)。
空间：O(n) 存两个桶，答案列表 O(m) 个四元组。

## 易错点
- 输入 `["able","area","echo","also"]`：若漏掉 `top == left` 的排除，`top` 与 `left` 取同一个词时四元组里出现重复词，会多出非法方案；正确做法是用 `len({top,left,right,bottom}) == 4` 一次性卡住四个词互异。
- 输入 `["code","cafe","eden","edge"]`：若只校验 `top[0]==left[0]` 与 `top[3]==right[0]` 就收，会漏掉 `bottom[0]==left[3]` 和 `bottom[3]==right[3]`，把不成立的组合放进答案；正确做法是四个角全部对齐，且 right 与 bottom 必须从 `by_first` 里按 `top[3]`、`left[3]` 取，不能从 `by_last` 取。

## 如果面试官追问
问：若 words 长度放宽到 1000 怎么办？
答：桶内两两配对仍是 O(n²) 量级，可先按 (首,尾) 二元组建索引，把 right/bottom 的候选压到常数级。
