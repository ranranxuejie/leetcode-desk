## 一句话思路
枚举回文前半段生成所有 k 回文，用数位多重集哈希去重，再对每个多重集算全排列数。

## 怎么做
1. 枚举前半段 `half`（`10**(m-1)` 到 `10**m - 1`，`m=(n+1)//2`），拼出回文 `p`，若 `p % k == 0` 则把它的数位排序成元组 `key` 存入 `set`。
2. 对每个 `key` 用组合数算「首位非零」的排列数：`total = (n-1)! / ∏(cnt_i!)` 的变体，即先固定首位从非零数字里选。
3. 累加所有 `key` 的排列数即为答案。

以 `n=3, k=5` 为例：`half` 从 10 到 99，`half=51` 拼出 `515`，`515 % 5 == 0`，`key=(1,5,5)` 入集合；`half=55` 拼出 `555`，`555 % 5 == 0`，`key=(5,5,5)` 入集合。最终集合大小对应 27 个不同多重集。

```python
from math import factorial
from collections import Counter

seen = set()
m = (n + 1) // 2
for half in range(10**(m-1), 10**m):
    s = str(half)
    p = int(s + s[-1-(n%2)::-1])
    if p % k == 0:
        seen.add(tuple(sorted(str(p))))

ans = 0
for key in seen:
    cnt = Counter(key)
    total = 0
    for d in cnt:
        if d == '0':
            continue
        cnt[d] -= 1
        ways = factorial(n-1)
        for v in cnt.values():
            ways //= factorial(v)
        total += ways
        cnt[d] += 1
    ans += total
```

## 复杂度
时间：枚举 `10^m` 个前半段，`m=⌈n/2⌉`，每个拼回文与取模 O(n)，共 O(10^⌈n/2⌉ · n)。
空间：`seen` 存至多 `10^⌈n/2⌉` 个长度 n 的元组，O(10^⌈n/2⌉ · n)。

## 易错点
- `n=1` 时 `s[-1-(n%2)::-1]` 的切片边界要验证：`n=1, half=4` 应得 `p=4`，若切片写成 `s[-1::-1]` 会拼出 `44`，导致 `4 % 4 == 0` 但 `44` 是两位数，答案偏大；正确是 `s[-1-(n%2)::-1]` 在 n 为奇数时跳过中间位。
- 首位为 0 的排列必须排除：`key=('0','1','1')` 若直接算 `3!/2!=3` 会把 `011` 算进去，正确做法是对每个非零数字 `d` 先 `cnt[d]-=1` 再算剩余 `n-1` 位排列，本例得 `d='1'` 时 `2!/1!=2`，答案 2 而非 3。

## 如果面试官追问
问：n 扩大到 15 怎么优化？答：`10^8` 前半段枚举太慢，改为按数位多重集直接枚举（`C(n+8,8)` 量级）并检查是否存在某个排列能被 k 整除，用模 k 的 DP 判定。
