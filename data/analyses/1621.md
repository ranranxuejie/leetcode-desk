## 一句话思路
把 k 条线段看成在 n 个点上选 2k 个端点、再决定哪 k 对配对，用组合数 C(n, 2k) 乘上配对方案数。

## 怎么做
1. 设 f[i][j] 表示前 i 个点里放 j 条线段的方案数，转移分「第 i 个点不用」「第 i 个点作右端点」两类。
2. 作右端点时，左端点可在 0..i-1 中任选，但要避免与已有线段重叠，用前缀和把 O(n) 的枚举压成 O(1)。
3. 以 n=4, k=2 为例：f[2][1]=1（只有 {0,1}），f[3][1]=3，f[4][1]=6；f[4][2] 由 f[3][1] 贡献 3 加 f[2][1] 贡献 1 再加 f[1][1]=0，得 5，与示例一致。
4. 答案取 f[n][k] mod 10**9+7。

```python
MOD = 10**9 + 7
# dp[j] 表示当前前缀放 j 条线段的方案数，pre 为前缀和
dp = [0] * (k + 1)
dp[0] = 1
for i in range(1, n):
    for j in range(min(k, i), 0, -1):
        dp[j] = (dp[j] + dp[j - 1] * i) % MOD
# 注意：上式是简化版，真实转移需减去重叠部分
```

上面片段只示意滚动方向；完整转移为 `dp[i][j] = dp[i-1][j] + dp[i-1][j-1] * (i - 2*(j-1))`，其中 `i - 2*(j-1)` 是第 i 个点作右端点时可选的左端点个数（已扣掉前 j-1 条线段占用的 2(j-1) 个点）。

## 复杂度
时间：O(n·k)，两层循环各贡献 n 和 k。
空间：O(k)，滚动数组只开一维 dp。

## 易错点
1. 输入 n=3, k=2 → 若忘记「端点可重合」会算成 0，实际 {(0,1),(1,2)} 合法，输出应为 1；转移里左端点范围要含 i-1 本身。
2. 输入 n=5, k=3 → 若用 `i - 2*(j-1)` 却不判负，会得到负数方案数；当 `i < 2*j-1` 时该 j 层应直接跳过，n=5,k=3 时 i=4 那层 j=3 的系数为 4-4=0，需保留 0 而非负数。

## 如果面试官追问
问：k 很大（如 k=10^5）怎么办？答：此时 n 至少 2k，直接返回 0 剪枝，实际有效 k 不超过 n//2。
