## 一句话思路
按位枚举 30 个二进制位，对每个位求「该位为 1 的元素」上的最长严格递增子序列，取最大值。

## 怎么做
1. 答案非零意味着存在某一位 b，使子序列所有元素第 b 位都是 1（AND 结果该位为 1），故只需对每个位单独求 LIS。
2. 对位 b，把 `nums` 中 `x >> b & 1` 为 1 的元素按原顺序抽出，得到子序列 `seq`。
3. 对 `seq` 跑标准 O(m log m) 的 LIS（`bisect_left` 维护 `tails`），长度即该位候选答案。
4. 30 个位取最大；全为 0 时返回 0。

以 `nums = [2,3,6]` 为例，位 b=1：2(10)、3(11)、6(110) 第 1 位都是 1，`seq=[2,3,6]`，`tails` 依次变为 `[2]`、`[2,3]`、`[2,3,6]`，长度 3，即答案。

```python
from bisect import bisect_left

ans = 0
for b in range(30):
    tails = []
    for x in nums:
        if x >> b & 1:
            i = bisect_left(tails, x)
            if i == len(tails):
                tails.append(x)
            else:
                tails[i] = x
    ans = max(ans, len(tails))
return ans
```

注意 `bisect_left` 而非 `bisect_right`：严格递增要求相等元素不能续接，`[2,2]` 在位 b=1 上 LIS 应为 1。

## 复杂度
时间：O(30 · n log n)，外层 30 个位，每位对至多 n 个元素做二分插入。
空间：O(n)，`tails` 最坏存 n 个元素，`seq` 可省去不建。

## 易错点
- 输入 `[2,2]` → 用 `bisect_right` 会把第二个 2 续在第一个后面得 2 → 严格递增必须用 `bisect_left`，得 1。
- 输入 `[0,1]` → 只对 b=0 检查会漏掉 1 单独成序列的情况，或误把 0 计入 → 0 的 30 个位全为 0，任何位都抽不到它，答案自然为 1，不要特判跳过 0 之外再加逻辑。

## 如果面试官追问
问：若要求输出该子序列本身而非长度？
答：每位 LIS 时额外记录前驱下标，取最长的那位回溯即可，时间空间不变。
