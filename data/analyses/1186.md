## 一句话思路
用两个状态滚动 DP：`keep` 表示没删过元素的当前子数组和，`drop` 表示已删一个元素的当前子数组和，答案取两者最大值。

## 怎么做
1. 初始化 `keep = arr[0]`、`drop = -inf`、`ans = arr[0]`，`drop` 用负无穷表示「还没删过」。
2. 遍历 `arr[1:]`，先算新的 `drop`：要么在已删过的子数组上续接 `drop + x`，要么在没删过的子数组上删掉当前 `x`，即 `keep`。
3. 再算新的 `keep = max(keep + x, x)`，顺序不能反，否则 `drop` 会用到更新后的 `keep`。
4. 每步用 `max(keep, drop)` 更新 `ans`。

以 `arr = [1,-2,0,3]` 为例：初始 `keep=1, drop=-inf`。处理 `-2` 时 `drop = max(-inf, keep) = 1`（对应删掉 `-2`，保留 `[1]`），`keep = max(-1, -2) = -1`；处理 `0` 时 `drop = max(1+0, -1) = 1`，`keep = max(-1, 0) = 0`；处理 `3` 时 `drop = max(1+3, 0) = 4`，`keep = 3`，`ans = 4`。

```python
keep, drop, ans = arr[0], float('-inf'), arr[0]
for x in arr[1:]:
    drop = max(drop + x, keep)
    keep = max(keep + x, x)
    ans = max(ans, keep, drop)
return ans
```

注意 `drop = max(drop + x, keep)` 里的 `keep` 是上一轮的旧值，所以必须先更新 `drop` 再更新 `keep`。

## 复杂度
时间 O(n)：一次遍历 `arr`，每个元素常数次比较。
空间 O(1)：只开 `keep`、`drop`、`ans` 三个变量，不随 n 增长。

## 易错点
- 输入 `arr = [-1,-1,-1,-1]` → 若把 `drop` 初始化为 0 或允许「删完为空」，会错答 0 → 正确做法是 `drop` 初始为 `-inf`，且 `drop` 只能由 `keep`（至少含一个元素）转移而来，保证删后非空。
- 输入 `arr = [1,-2,-2,3]` → 若先更新 `keep` 再更新 `drop`，`drop` 会用到已含当前元素的 `keep`，等于把 `x` 既算进和又当被删元素，错答 4 → 正确做法是严格先 `drop` 后 `keep`。

## 如果面试官追问
要求输出具体子数组的起止下标和删除位置怎么办？
答：额外存 `drop` 取到 `keep` 时的下标 `i` 作为删除点，并记录 `keep` 的起点，回溯即可。
