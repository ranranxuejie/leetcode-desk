## 一句话思路
定义 `dp[i]` 为到达下标 `i` 的最大跳跃次数，从前往后枚举 `j < i` 且 `|nums[i]-nums[j]| <= target` 转移。

## 怎么做
1. 初始化 `dp = [-1]*n`，`dp[0] = 0`，其余表示不可达。
2. 对每个 `i` 从 1 到 n-1，遍历所有 `j < i`，若 `dp[j] != -1` 且 `abs(nums[i]-nums[j]) <= target`，则 `dp[i] = max(dp[i], dp[j]+1)`。
3. 返回 `dp[n-1]`（若仍为 -1 即不可达）。

以示例 1 `nums=[1,3,6,4,1,2], target=2` 为例，关键一步是 `i=3`（`nums[3]=4`）：`j=1` 时 `dp[1]=1` 且 `|4-3|=1<=2`，得 `dp[3]=2`；`j=2` 时 `|4-6|=2<=2` 但 `dp[2]=-1`（`|6-1|=5>2` 不可达），不更新。最终 `dp[5]=3`。

```python
n = len(nums)
dp = [-1] * n
dp[0] = 0
for i in range(1, n):
    for j in range(i):
        if dp[j] != -1 and abs(nums[i] - nums[j]) <= target:
            dp[i] = max(dp[i], dp[j] + 1)
return dp[n - 1]
```

注意 `dp[j] != -1` 这个前置判断不能省：`dp[j]+1` 在 `dp[j]=-1` 时会得到 0，把不可达状态误标成可达。示例 1 中 `i=2` 时 `j=0` 差值为 5 不满足，`j=1` 满足得 `dp[2]=2`，若漏判会把 `dp[2]` 从 -1 变成 0。

## 复杂度
时间 O(n²)：双重循环枚举所有 (j, i) 对，n ≤ 1000 时约 5×10⁵ 次比较。
空间 O(n)：只开一个长度 n 的 `dp` 数组，无其他辅助结构。

## 易错点
- `target=0` 且 `nums` 有重复值（如 `[1,1,1]`）→ 会误以为无解返回 -1 → 差值为 0 满足 `<= target`，应正常转移，`dp` 逐格 +1。
- 只写 `dp[i] = dp[j]+1` 不取 max → 示例 2 中 `i=2` 会先被 `j=0`（差值 5 > 3 跳过）再被 `j=1` 赋值，但若顺序反过来会覆盖成较小值 → 必须 `max(dp[i], dp[j]+1)` 保留最大跳数。

## 如果面试官追问
若 n 放大到 10⁵ 怎么做？答：按 `nums` 值域建线段树/树状数组维护区间最大 `dp`，查询 `[nums[i]-target, nums[i]+target]` 内的最大值，O(n log n)。
