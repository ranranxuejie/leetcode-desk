## 一句话思路
把 `y_i + y_j + x_j - x_i` 拆成 `(y_j + x_j) + (y_i - x_i)`，用单调队列维护窗口内最大的 `y_i - x_i`。

## 怎么做
1. 遍历每个点作为右端点 `j`，队列存下标，按 `y_i - x_i` 递减。
2. 弹出队首所有 `x_j - x_i > k` 的下标，保证窗口合法。
3. 若队列非空，用 `points[que[0]][1] - points[que[0]][0] + y_j + x_j` 更新答案。
4. 弹出队尾所有 `y_i - x_i <= y_j - x_j` 的下标，再把 `j` 入队。

以示例 1 `points = [[1,3],[2,0],[5,10],[6,-10]], k = 1` 为例：`j=1` 时队首是 `i=0`，`x_1 - x_0 = 1 <= 1`，值为 `(3-1) + (0+2) = 4`，答案更新为 4；`j=2` 时 `x_2 - x_0 = 4 > 1`，弹出 `0`，队列空，跳过。

```python
from collections import deque
que = deque()
ans = -2**63
for j, (x, y) in enumerate(points):
    while que and x - points[que[0]][0] > k:
        que.popleft()
    if que:
        i = que[0]
        ans = max(ans, points[i][1] - points[i][0] + y + x)
    cur = y - x
    while que and points[que[-1]][1] - points[que[-1]][0] <= cur:
        que.pop()
    que.append(j)
```

## 复杂度
时间：O(n)，每个下标最多入队出队各一次，n 为 `points` 长度。
空间：O(n)，`deque` 最坏存全部下标。

## 易错点
1. 输入 `points = [[0,0],[3,0],[9,2]], k = 3` 时，若先入队再判窗口，`j=2` 会把 `x=0` 的过期点留在队首算出 `0+2+9=11`；正确做法是先 `popleft` 掉 `x_j - x_i > k` 的点再取队首。
2. 输入 `points = [[1,3],[2,0],[5,10],[6,-10]], k = 1` 时，若队尾用 `<` 而非 `<=` 去重，`y_i - x_i` 相等的旧点会堆积，窗口左移后队首可能已过期；正确做法是 `<=` 时也弹出，保留最新的下标。

## 如果面试官追问
若要求输出取得最大值的点对下标？答：更新 `ans` 时同步记录 `(que[0], j)`，弹出队首不影响已记录结果。
