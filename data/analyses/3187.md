## 一句话思路
把「i 是峰值」压成 0/1 数组，用树状数组做单点改、区间和，改 `nums[p]` 只影响 p-1、p、p+1 三个位置。

## 怎么做
1. 定义 `is_peak(i) = 0 < i < n-1 and nums[i-1] < nums[i] > nums[i+1]`，建树状数组 `bit`，`bit` 里存这个 0/1。
2. 查询 `[l, r]` 时，峰值只可能落在 `l+1 .. r-1`，两端元素按题意不算峰值，所以答案是 `sum(r-1) - sum(l)`（前缀和相减，下标含 l+1 到 r-1）。
3. 更新 `nums[p] = val` 后，只有 `p-1, p, p+1` 的峰值状态可能变，逐个重算并 `add(i, new - old)`。
4. 用示例 2 走一遍：`nums=[4,1,4,2,1,5]`，初始峰值只有 i=2（4>1 且 4>2），`bit` 在 2 处置 1。查询 `[1,0,2]` 时区间是 `1..1`，`sum(1)-sum(0)=0`，输出 0；查询 `[1,0,4]` 时区间 `1..3`，`sum(3)-sum(0)=1`，输出 1。

```python
def is_peak(i):
    return 0 < i < n - 1 and nums[i-1] < nums[i] > nums[i+1]

def add(i, d):
    i += 1
    while i <= n:
        bit[i] += d
        i += i & -i

def query(i):          # 前缀和 [0..i]
    s, i = 0, i + 1
    while i > 0:
        s += bit[i]
        i -= i & -i
    return s
```

更新时对 `p-1, p, p+1` 各算一次 `old = is_peak(i)`，改完 `nums[p]` 再算 `new`，`add(i, new - old)`。

## 复杂度
时间：每次更新 O(log n)（3 个位置），每次查询 O(log n)，共 O((n+q) log n)。
空间：`bit` 长度 n+1，O(n)。

## 易错点
- 查询 `[l, r]` 且 `r - l <= 1`（如 `[0,2]` 之外的 `[3,4]`）→ 若写成 `sum(r) - sum(l-1)` 会把端点算进去，示例 2 的 `[1,0,2]` 就会错答 1 → 正确是只统计 `l+1..r-1`，即 `sum(r-1) - sum(l)`。
- 更新 `p=0` 或 `p=n-1` → 若循环 `for i in (p-1,p,p+1)` 不判边界，`is_peak(-1)` 会读到 `nums[-1]`（Python 负索引取到末尾元素）→ 循环前加 `if 0 <= i < n` 过滤。

## 如果面试官追问
若要求输出所有峰值下标而非计数？答：树状数组只能求和，需换成有序集合（如 `SortedList`）存峰值下标，查询时二分取 `[l+1, r-1]` 区间长度。
