## 一句话思路
用倒排索引把「词 → 含该词的文档 id 列表」建起来，只对共享至少一个词的文档对累加交集，避免 500×500 全量比对。

## 怎么做
1. 遍历 `docs`，对每个 `docs[i]` 里的整数 `w`，把 `i` 追加进 `inverted[w]`。
2. 对每个词 `w` 的文档列表 `ids`，两两组合 `(a, b)`（`a < b`），在字典 `inter[a, b]` 上 `+1`。
3. 遍历 `inter`，用 `len(docs[a]) + len(docs[b]) - c` 算并集，`c / union` 即相似度，`> 0` 才格式化输出。
4. 格式化用 `f"{a},{b}: {sim:.4f}"`，`a` 天然小于 `b`。

以示例为例：词 `9` 出现在文档 0 和 1，词 `3` 也在 0 和 1，词 `15` 在 0 和 2。处理完 `inter` 后 `inter[(0,1)] = 2`，并集 `5 + 5 - 2 = 8`，得 `0.2500`；`inter[(0,2)] = 1`，并集 `5 + 6 - 1 = 10`，得 `0.1000`。

```python
from collections import defaultdict

inverted = defaultdict(list)
for i, doc in enumerate(docs):
    for w in doc:
        inverted[w].append(i)

inter = defaultdict(int)
for ids in inverted.values():
    for x in range(len(ids)):
        for y in range(x + 1, len(ids)):
            inter[(ids[x], ids[y])] += 1

res = []
for (a, b), c in inter.items():
    sim = c / (len(docs[a]) + len(docs[b]) - c)
    res.append(f"{a},{b}: {sim:.4f}")
```

## 复杂度
时间：O(Σ|docs[i]| + Σ C(k_w,2))，`k_w` 是词 w 的文档频次，稀疏时远小于 500²。
空间：O(Σ|docs[i]|) 存倒排表，加 O(不同文档对数) 存 `inter`。

## 易错点
- 文档里有重复整数时（题面说各不相同，但若输入不保证）→ 同一对文档被同一词重复 `+1`，交集虚高 → 建倒排前先 `set(doc)` 去重。
- 某词出现在 3 个以上文档时 → 只累加相邻两篇会漏对 → 必须用双重循环枚举 `ids` 中所有 `(x, y)` 组合，不能只配 `ids[0]`。

## 如果面试官追问
问：文档数涨到 10⁵ 怎么办？答：先按文档长度或词频剪枝，只对高频词做候选对生成，再用 MinHash/LSH 近似过滤，精确计算只留给候选对。
