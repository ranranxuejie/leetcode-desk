## 一句话思路
把每个词反转后查哈希集合，命中就计数并从集合删掉，保证每个词只用一次。

## 怎么做
1. 先把 `words` 全部放进集合 `seen`，因为题目保证字符串互不相同，集合大小就是 50 以内。
2. 遍历 `words`，对每个 `w` 算 `r = w[::-1]`。
3. 若 `r != w` 且 `r in seen`，说明配对成立，`ans += 1`，同时 `seen.discard(w)` 和 `seen.discard(r)`。
4. 遍历结束返回 `ans`。

以示例 1 `["cd","ac","dc","ca","zz"]` 为例：`seen` 初始含 5 个词。处理 `w="cd"` 时 `r="dc"`，`"dc" in seen` 为真，`ans` 变 1，集合删掉 `"cd"` 和 `"dc"`；处理 `w="ac"` 时 `r="ca"` 命中，`ans` 变 2；处理 `w="zz"` 时 `r == w`，跳过。最终 2。

```python
seen = set(words)
ans = 0
for w in words:
    r = w[::-1]
    if r != w and r in seen:
        ans += 1
        seen.discard(w)
        seen.discard(r)
return ans
```

关键在 `r != w` 这个判断：`"zz"` 反转还是自己，若不排除会把它算成一对，但题目要求 `i < j` 且两个不同下标，自反词不能配对。

## 复杂度
时间 O(n·L)，n 是词数 50，L 是词长 2，反转和哈希查找各一次。
空间 O(n)，`seen` 最多存 50 个长度 2 的字符串。

## 易错点
1. 输入 `["aa","ab"]` → 若漏掉 `r != w` 判断，`"aa"` 反转仍是 `"aa"` 且在集合里，会错答 1 → 正确做法是先判 `r != w` 再查集合，自反词直接跳过。
2. 输入 `["ab","ba","cc"]` → 若只查集合不删元素，处理 `"ab"` 时配对成功，处理 `"ba"` 时 `r="ab"` 仍在集合里，会重复计数错答 2 → 正确做法是命中后 `discard` 掉 `w` 和 `r` 两个词，保证每个词最多用一次。

## 如果面试官追问
若词长不是 2 而是任意长度、词数涨到 10^5，怎么做？答：思路不变，仍是集合 + 反转查找，时间 O(总字符数)，只是反转成本随词长上升。
