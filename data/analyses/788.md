## 一句话思路
逐位打表：每个数字标成「无效 / 自转 / 变转」，一个数是好数当且仅当全位有效且至少一位变转。

## 怎么做
1. 建表 `kind[d]`：0、1、8 记 0（自转），2、5、6、9 记 1（变转），3、4、7 记 -1（无效）。
2. 对每个 x 从 1 到 N，逐位取 `d = x % 10`，累加状态：遇到 -1 直接判死，否则记录是否出现过 1。
3. 只有「没出现 -1 且出现过 1」才计数，因为全自转（如 1、10、11）旋转后与原数相同。
4. 用示例 N=10 走一遍：x=2 时 `d=2`，`kind[2]=1`，无 -1 且有变转 → 计数；x=10 时两位 `kind` 都是 0，无变转 → 不计数；最终得 4。

```python
kind = [0, 0, 1, -1, -1, 1, 1, -1, 0, 1]
ans = 0
for x in range(1, n + 1):
    y, changed, ok = x, False, True
    while y:
        k = kind[y % 10]
        if k == -1:
            ok = False
            break
        if k == 1:
            changed = True
        y //= 10
    if ok and changed:
        ans += 1
```

## 复杂度
时间：O(N log N)，每个 x 拆位约 log₁₀x 次。
空间：O(1)，只开了长度 10 的 `kind` 表。

## 易错点
- 输入 N=1 或 N=10 → 若只判「全位有效」会把 1、10 算成好数 → 必须额外要求 `changed` 为真，即至少一位落在 2/5/6/9。
- 输入含 3、4、7 的数如 13 → 若先判 `changed` 再判无效位，可能因 `break` 顺序漏掉 → 先查 `kind[d] == -1` 立即置 `ok=False` 并跳出，再谈变转。

## 如果面试官追问
问：N 放大到 10⁹ 怎么办？
答：改成数位 DP，状态记「是否已出现变转」「是否贴着上界」，按位转移，O(log N)。
