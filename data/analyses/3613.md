## 一句话思路
答案单调：限权 ≤ X 时用并查集数连通块，块数 ≤ k 即可行，二分最小 X。

## 怎么做
1. 把边按 w 升序排好，二分答案区间 `[0, max_w]`（无边的分量成本 0，所以下界取 0）。
2. 对候选 `mid`，只把 `w <= mid` 的边做 union，统计剩余连通块数 `cnt`。
3. `cnt <= k` 说明 mid 可行，收缩右界；否则放大左界。
4. 返回收敛后的最小可行值。

以示例 1 为例：`edges` 排序后为 `(1,3,2),(1,2,3),(0,1,4),(3,4,6)`，`max_w = 6`。试 `mid = 3`：只并前两条，得到 `{0},{1,2,3},{4}` 共 3 块 > k=2，不可行；试 `mid = 4`：再并 `(0,1,4)`，得到 `{0,1,2,3},{4}` 共 2 块 ≤ 2，可行，故答案 4。

```python
def feasible(mid):
    parent = list(range(n))
    cnt = n
    for u, v, w in edges:          # edges 已按 w 升序
        if w > mid:
            break
        ru, rv = find(u), find(v)
        if ru != rv:
            parent[ru] = rv
            cnt -= 1
    return cnt <= k

lo, hi = 0, max(w for _, _, w in edges)
while lo < hi:
    mid = (lo + hi) // 2
    if feasible(mid):
        hi = mid
    else:
        lo = mid + 1
return lo
```

注意 `cnt` 从 `n` 起算而不是从 1，因为孤立点本身就是一个成本为 0 的分量，这正是 `k` 能大于 1 的原因。

## 复杂度
时间：排序 O(m log m)，二分 O(log W) 轮，每轮 O(m α(n))，m = len(edges)。
空间：并查集 parent 数组 O(n)，排序额外 O(m)（或原地）。

## 易错点
- 把 `cnt` 初始化成 1 或只数「有边的块」→ 示例 1 中 `mid=4` 会算成 1 块，误判可行，甚至返回 3。正确做法是 `cnt = n`，每成功 union 一次减 1，孤立点天然计入。
- 二分下界写成 `min_w` 或 1 → 当 `k = n` 时答案应为 0（全删边，每个点成本 0），却返回最小边权。正确做法是 `lo = 0`，因为无边分量成本定义为 0。

## 如果面试官追问
问：要求输出具体保留哪些边怎么办？
答：二分定下 X 后，再跑一次 `w <= X` 的并查集，保留所有成功 union 的边即可，块数自然 ≤ k。
