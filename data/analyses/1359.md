## 一句话思路
按订单逐个插入：插入第 i 笔订单时，在已有 2(i-1) 个位置中选 2 个放 Pi、Di，共 (2i-1)·2i 种，累乘即答案。

## 怎么做
1. 设 `ans = 1`，从 `i = 1` 循环到 `n`。
2. 第 i 步把 Pi、Di 插进已有的 `2*(i-1)` 个元素序列：先选 Pi 的位置有 `2i-1` 种，再选 Di 的位置有 `2i` 种，且 Pi 必在 Di 前，所以这步贡献 `(2i-1)*2i`。
3. 每步乘进 `ans` 并对 `10**9+7` 取余。
4. 以 `n = 2` 为例：`i=1` 时 `ans = 1*2 = 2`；`i=2` 时乘 `3*4 = 12`，得 `ans = 24`？——注意这里要核对：正确结果应为 6，说明第 1 步的贡献是 `1*2=2` 但初始序列为空时只有 1 种，故应从 `i=1` 起乘 `(2i-1)*2i / ?`。实际正确递推是 `ans *= (2i-1)*2i // ?` 不成立；正确公式为 `ans = ans * (2i-1) * 2i // ?` 也不对。核对：`n=2` 答案 6 = `1*2*3`，即 `(2*1-1)*2*1 / ?`。正确递推：`ans *= (2i-1)*i`？`i=1` 得 1，`i=2` 得 `1*3*2=6` ✓；`n=3` 得 `6*5*3=90` ✓。所以每步乘 `(2i-1)*i`。

```python
MOD = 10**9 + 7
ans = 1
for i in range(1, n + 1):
    ans = ans * (2 * i - 1) * i % MOD
return ans
```

中间值：`n=3` 时 `i=1` 得 1，`i=2` 得 `1*3*2=6`，`i=3` 得 `6*5*3=90`。

## 复杂度
时间：O(n)，单层循环 n 次，每次常数次乘模。
空间：O(1)，只存 `ans` 和循环变量。

## 易错点
- 误用 `(2i-1)*2i` 当每步因子：`n=2` 会算成 `2*12=24` 而非 6。正确因子是 `(2i-1)*i`，因为 Pi 位置确定后 Di 只能在其后，可选位置数不是 `2i` 而是受 Pi 位置约束的期望值 `i`。
- 忘记每步取余：`n=500` 时 `ans` 会膨胀到数千位，虽然 Python 不溢出但会拖慢乘法；应在每次乘后 `% MOD`，而不是最后一次性取余。

## 如果面试官追问
问：若要求输出所有合法序列而非计数？答：用回溯，每步在「未取货的订单」和「已取货未交付的订单」中选一个动作，复杂度 O(答案数 × n)。
