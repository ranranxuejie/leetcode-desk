## 一句话思路
从最大的字母开始贪心，每次尽量连续放满 `repeatLimit` 个，放不下时用次大字母插一个隔断，用计数数组代替堆。

## 怎么做
1. 用长度 26 的 `cnt` 统计 `s` 中每个字母出现次数，从 `i = 25` 往下扫描。
2. 每轮取当前最大的非零字母 `i`，连续追加 `min(cnt[i], repeatLimit)` 个。
3. 若 `cnt[i]` 还有剩余，就向下找下一个非零字母 `j` 插一个作隔断，然后回到 `i` 继续；找不到 `j` 就结束。
4. 以 `s = "cczazcc", repeatLimit = 3` 为例：`cnt['z']=2, cnt['c']=4, cnt['a']=1`。先放 `"zz"`（z 用完），再放 `"ccc"`（c 剩 1），c 放不下时插 `'a'` 得 `"zzccca"`，最后补剩下的 1 个 c 得 `"zzcccac"`。

```python
cnt = [0] * 26
for ch in s:
    cnt[ord(ch) - 97] += 1
res = []
i = 25
while i >= 0:
    if cnt[i] == 0:
        i -= 1
        continue
    take = min(cnt[i], repeatLimit)
    res.append(chr(97 + i) * take)
    cnt[i] -= take
    if cnt[i] > 0:
        j = i - 1
        while j >= 0 and cnt[j] == 0:
            j -= 1
        if j < 0:
            break
        res.append(chr(97 + j))
        cnt[j] -= 1
return "".join(res)
```

## 复杂度
时间：O(26n)，每个字符最多被追加一次，内层找 `j` 最多扫 26 个字母。
空间：O(26) 计数数组加 O(n) 结果串。

## 易错点
- 输入 `s = "aababab", repeatLimit = 2`：若把 `'b'` 一次放完再放 `'a'`，会得到 `"bbbaaa"` 之类非法串。正确做法是 b 放满 2 个后立刻插一个 `'a'` 隔断，得 `"bbabaa"`。
- 输入 `s = "cczazcc", repeatLimit = 3`：若在 c 剩 1 个时直接丢弃剩余字符，会漏掉末尾的 `'c'`，输出 `"zzccca"` 而非 `"zzcccac"`。正确做法是插完隔断后回到 `i` 继续消费 `cnt[i]`。

## 如果面试官追问
问：若要求必须用完 s 中所有字符怎么办？答：当最大字母剩余且无更小字母可隔断时无法构造，需返回空串或报无解，贪心框架不变。
