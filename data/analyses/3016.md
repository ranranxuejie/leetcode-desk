## 一句话思路
按字母出现次数降序排，前 8 个各占一键按 1 次，之后每 8 个字母按键次数 +1，加权求和。

## 怎么做
1. 用 `Counter(word)` 统计每个字母的出现次数，得到频次列表 `freq`。
2. 把 `freq` 降序排序——出现越多的字母越该排在按键的前面（按 1 次）。
3. 第 `i` 个（0 基）字母的按键次数是 `i // 8 + 1`，因为 8 个按键（2~9）每个位置能放一个"第 k 层"的字母。
4. 累加 `freq[i] * (i // 8 + 1)`。

以 `word = "aabbccddeeffgghhiiiiii"` 为例：频次降序为 `[6,2,2,2,2,2,2,2,2]`（i 出现 6 次，其余 8 个字母各 2 次）。前 8 个下标 0~7 的按键次数都是 `i//8+1 = 1`，第 9 个（下标 8）是 `8//8+1 = 2`。总成本 `6*1 + 2*1*7 + 2*2 = 6+14+4 = 24`，与示例一致。

```python
from collections import Counter

freq = sorted(Counter(word).values(), reverse=True)
ans = 0
for i, c in enumerate(freq):
    ans += c * (i // 8 + 1)
return ans
```

关键点：`i // 8` 而不是 `i // 9`——只有 8 个可用按键（2 到 9），不是 9 个。

## 复杂度
时间：O(n + 26 log 26)，n 是 `word` 长度，排序只排最多 26 个频次。
空间：O(26)，`Counter` 和频次列表都只存小写字母。

## 易错点
- 把按键数当成 9（把 1 也算进去）→ `i // 9 + 1`，示例 3 会算成 22 而非 24 → 必须用 8，因为 1、0、*、# 不映射字母。
- 按字母表顺序而非频次降序分配 → `"aabbccddeeffgghhiiiiii"` 里 i 出现 6 次却排最后，成本变大 → 必须先 `sorted(..., reverse=True)`，高频字母占按 1 次的位置。

## 如果面试官追问
问：如果要求输出具体映射方案（每个字母分到哪个键、第几层）？答：排序后按下标 `i` 分到第 `i % 8` 个键、第 `i // 8 + 1` 层，遍历时记录即可。
