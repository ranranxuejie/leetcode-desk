## 一句话思路
若 `a == b` 返回 -1，否则返回 `max(len(a), len(b))`——较长串整体不可能是较短串的子序列。

## 怎么做
1. 先判 `a == b`：两串完全相同，任何子序列都互相包含，返回 -1。
2. 否则取较长串本身作为候选特殊序列，长度 `max(len(a), len(b))`。
3. 关键论证：设 `len(a) > len(b)`，`a` 的任意子序列长度 ≤ `len(a)`，而 `b` 的子序列长度 ≤ `len(b) < len(a)`，故 `a` 整体不可能是 `b` 的子序列。

以 `a = "aba", b = "cdc"` 为例：`a != b`，`len(a) = len(b) = 3`，返回 `max(3, 3) = 3`。验证：`"aba"` 是 `a` 的子序列；`b = "cdc"` 中只有 `c`、`d`，不含 `a`，故 `"aba"` 不是 `b` 的子序列，长度 3 成立。

```python
def findLUSlength(a: str, b: str) -> int:
    if a == b:
        return -1
    return max(len(a), len(b))
```

等长但不同时（如 `"aba"` vs `"cdc"`），两串互不为对方子序列，答案就是 `len(a)`，不需要逐字符比对。

## 复杂度
时间：O(min(len(a), len(b)))，`a == b` 的字符串比较逐字符扫描到首个不同处。
空间：O(1)，只存两个长度整数，无额外容器。

## 易错点
- 输入 `a = "aaa", b = "aa"` → 若误判「`a` 含 `b` 全部字符就返回 -1」会错成 -1 → 正确做法：`a != b` 时直接返回 `max(len(a), len(b)) = 3`，`"aaa"` 长度 3 超过 `b` 的子序列上限 2，必不是 `b` 的子序列。
- 输入 `a = "abc", b = "abc"` → 若只比长度（`max(3,3)=3`）会错成 3 → 正确做法：先判 `a == b` 返回 -1，因为两串子序列集合完全相同，不存在独有的。

## 如果面试官追问
追问：若要求返回具体的最长特殊序列而非长度？答：`a != b` 时直接返回较长串本身（等长返回任一），它整体就不是对方的子序列，无需构造。
