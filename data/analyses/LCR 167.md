## 一句话思路
用左右指针维护一个无重复窗口，右指针每扩一格就用哈希表查它上次出现的位置，超界就把左指针跳过去。

## 怎么做
1. 建 `last = {}` 记录每个字符最后出现的下标，`left = 0`、`ans = 0`。
2. 右指针 `right` 从 0 扫到 `len(arr)-1`，每步先查 `arr[right]` 是否在 `last` 里且 `last[arr[right]] >= left`。
3. 若命中，说明窗口内已有同一字符，令 `left = last[arr[right]] + 1`，把旧位置连同它左边全部踢出窗口。
4. 更新 `last[arr[right]] = right`，再算 `ans = max(ans, right - left + 1)`。

拿 `arr = "dbascDdad"` 走关键一步：扫到 `right = 6`（字符 `'d'`）时，`last['d'] = 0` 且 `0 >= left = 0`，于是 `left` 跳到 `1`，窗口从 `"dbascDd"` 收缩成 `"bascDd"`，长度 `6`，与答案吻合。注意 `'D'` 和 `'d'` 是两个不同键，不会互相干扰。

```python
last = {}
left = ans = 0
for right, ch in enumerate(arr):
    if ch in last and last[ch] >= left:
        left = last[ch] + 1
    last[ch] = right
    ans = max(ans, right - left + 1)
return ans
```

`left` 只增不减，所以每个字符最多被左指针跨过一次，整体是线性的。

## 复杂度
时间 O(n)：`right` 走 n 步，`left` 总共最多前进 n 步，哈希查改均摊 O(1)。
空间 O(k)：`last` 存不同字符，k 为字符集大小，本题最多 40000 个键。

## 易错点
- 输入 `"abba"` → 若只写 `if ch in last: left = last[ch] + 1` 而不判 `last[ch] >= left`，扫到第二个 `'a'`（`right=3`）时会把 `left` 从 `2` 拉回 `1`，窗口反而变长，错答 3；正确做法是加 `last[ch] >= left` 这个门槛，`left` 保持 `2`，答案 2。
- 输入 `"KKK"` → 若把 `last[ch] = right` 写在判断之前，`last['K']` 已被当前下标覆盖，`left` 永远跳不动，错答 3；正确做法是先判重、再更新 `last`，答案 1。

## 如果面试官追问
问：要求返回最长的那段子串本身而不是长度？答：额外记 `best_start`，在 `ans` 被刷新时同步存 `left`，最后返回 `arr[best_start:best_start+ans]`。
