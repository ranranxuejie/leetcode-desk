## 一句话思路
先 `filter` 掉非数字得到纯数字串 `digits`，再按「余数 4 拆 2+2、余数 2 单独成块」的规则切块拼接。

## 怎么做
1. 用 `''.join(c for c in number if c.isdigit())` 得到 `digits`，长度记为 `n`。
2. 前 `n - 2` 个字符（若 `n % 3 == 1` 则取 `n - 4`）按每 3 个切块，剩下的尾巴按 2 或 4 处理。
3. 更省事的写法：先算 `k = n - 2 if n % 3 == 1 else n`，前 `k` 位每 3 个一组，尾部 `n - k` 位按 2 或 4 拆。
4. 用 `'-'.join(blocks)` 返回。

以示例 2 `"123 4-567"` 为例：`digits = "1234567"`，`n = 7`，`7 % 3 == 1`，所以 `k = 5`，前 5 位切成 `["123", "45"]`，尾部 `"67"` 单独成块，结果 `"123-45-67"`。

```python
digits = ''.join(c for c in number if c.isdigit())
n = len(digits)
k = n - 2 if n % 3 == 1 else n
blocks = [digits[i:i+3] for i in range(0, k, 3)]
tail = digits[k:]
if len(tail) == 4:
    blocks += [tail[:2], tail[2:]]
elif tail:
    blocks.append(tail)
return '-'.join(blocks)
```

关键点：`n % 3 == 1` 时不能把最后 4 位切成 `"1"+"3"`，必须退一位让尾部变成 4 位再拆 2+2。

## 复杂度
时间：O(n)，`filter` 扫一遍、切块扫一遍，n 是 `number` 长度。
空间：O(n)，`digits` 和 `blocks` 各占一份，输出串本身也是 O(n)。

## 易错点
- 输入 `"123 4-5678"`（n=8，8%3=2）→ 若按「每 3 个切到底」会得到 `"123-456-78"` 看似对，但换成 n=7 时就会切出 `"123-4-567"` 这种含 1 位块 → 正确做法是先判断 `n % 3 == 1` 再把 `k` 减 2。
- 输入 `"12"`（n=2）→ 若循环条件写成 `while len(digits) > 4` 再处理尾巴，容易漏掉「尾部 2 位直接成块」的分支 → 正确做法是 `tail` 长度为 2 或 3 时直接 `append`，只有 4 才拆 2+2。

## 如果面试官追问
问：如果要求每块最多 3 位且不允许出现 1 位块，但块数要最少怎么办？
答：先尽量切 3，若余 1 就把最后一个 3 改成 2+2，块数不变，逻辑同上。
