## 一句话思路
把最长木棍 n 插到 n-1 的排列里：放末尾不增可见数，放其余 n-1 个位置各增 1，得 dp[n][k] = dp[n-1][k-1] + (n-1)·dp[n-1][k]。

## 怎么做
1. 定义 `dp[i][j]` 为 i 根木棍恰好看到 j 根的排列数，边界 `dp[1][1] = 1`。
2. 递推时把长度 i 这根最长棍插入 i-1 根的排列：插在末尾（i-1 个位置中的最后）不新增可见，插在其余 i-1 个位置必定新增一根可见。
3. 于是 `dp[i][j] = dp[i-1][j-1] + (i-1) * dp[i-1][j]`，两项分别对应"新增可见"和"不新增可见"。
4. 以 n=3, k=2 验证：`dp[2][1]=1, dp[2][2]=1`；`dp[3][2] = dp[2][1] + 2*dp[2][2] = 1 + 2 = 3`，与示例一致。

```python
MOD = 10**9 + 7
dp = [[0] * (k + 2) for _ in range(n + 1)]
dp[1][1] = 1
for i in range(2, n + 1):
    for j in range(1, min(i, k) + 1):
        dp[i][j] = (dp[i-1][j-1] + (i-1) * dp[i-1][j]) % MOD
return dp[n][k]
```

注意内层 j 上界取 `min(i, k)`：i 根最多看到 i 根，且超过 k 的列对答案无贡献，可省一半循环。

## 复杂度
时间：O(n·k)，两层循环各贡献 n 和 k。
空间：O(n·k) 的 dp 表；滚动数组可压到 O(k)。

## 易错点
- n=1, k=1 → 若把 `dp[1][1]` 初始化漏掉或写成 `dp[0][0]=1` 后不特判，会返回 0；正确做法是显式设 `dp[1][1]=1` 并从 i=2 起递推。
- k > n 或 k < 1 → 直接返回 0，但若循环上界写成 `range(1, k+1)` 且 k>n，会访问 `dp[i-1][j]` 越界或读到未定义列；正确做法是上界取 `min(i, k)` 并在入口判 `k > n` 返回 0。

## 如果面试官追问
问：n 到 10^5 怎么办？答：这是第一类斯特林数，需用生成函数/多项式方法，O(n log n) 求单点值，不能直接 O(nk) 递推。
