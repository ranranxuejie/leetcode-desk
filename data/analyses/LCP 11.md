## 一句话思路
按能力值分组，每组贡献期望恒为 1，答案就是不同能力值的个数，用哈希集合去重即可。

## 怎么做
1. 用 `set(scores)` 把能力值去重，集合大小就是答案。
2. 关键推理：同一能力值有 k 份简历，小 A 和小 B 各自从 k! 个排列中等可能取一个，某个固定位置两人撞上的概率是 1/k，k 个位置加起来期望是 k × (1/k) = 1。
3. 不同能力值之间互不影响，期望可加，所以总数 = 组数。
4. 拿示例 3 `scores = [1,1,2]` 走一遍：能力值 1 这组 k=2，贡献 1；能力值 2 这组 k=1，贡献 1；合计 2，与输出一致。

```python
def expectNumber(scores):
    return len(set(scores))
```

上面是核心一行。若不想用 `set`，也可排序后数相邻不同值：

```python
def expectNumber(scores):
    scores.sort()
    cnt = 1
    for i in range(1, len(scores)):
        if scores[i] != scores[i - 1]:
            cnt += 1
    return cnt
```

注意示例 2 `[1,1]`：k=2，期望 = 2 × (1/2) = 1，不是 2 也不是 0，别把「同值组贡献 1」记成「贡献 k」。

## 复杂度
时间：O(n)，`set` 遍历一遍 scores，n 为数组长度。
空间：O(n)，最坏所有能力值互异，集合存 n 个元素。

## 易错点
- 输入 `[1,1]` → 误以为同值组贡献是 k=2，输出 2 → 正确是每组恒贡献 1，答案 1。
- 输入 `[1,1,2]` → 误按「总长度减重复数」算成 3-1=2 碰巧对，但换成 `[1,1,1]` 会算成 3-2=1 对、`[1,1,2,2]` 算成 4-2=2 也对，逻辑侥幸；正确做法是直接数不同值个数，别绕减法。

## 如果面试官追问
问：若要求输出每个能力值组的期望贡献明细？
答：对每个不同值 v 记频次 k，输出 (v, 1)，因为每组期望恒为 1，与 k 无关。
