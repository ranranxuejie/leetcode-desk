## 一句话思路
用递推 `p(n) = 1/n + (n-2)/n * p(n-1)` 化简得 `p(n) = 1/2`（n≥2），因为第 1 人要么直接坐对、要么坐进第 n 座、要么坐进中间某座把问题缩成同构子问题。

## 怎么做
1. 第 1 人随机选座，三种结局：坐 1 号座（概率 `1/n`，之后全员对号，第 n 人必对）；坐 n 号座（概率 `1/n`，第 n 人必错）；坐中间第 k 座（`2 ≤ k ≤ n-1`，概率 `(n-2)/n`）。
2. 坐中间第 k 座后，第 2..k-1 人全部对号入座，轮到第 k 人时他的座被占，他成了「新的随机乘客」，剩余可选座位是 1 号座和 k+1..n 号座，共 `n-k+1` 个，结构与原问题完全同构，规模缩为 `n-k+1`。
3. 于是 `p(n) = 1/n + (n-2)/n * p(n-1)`，代入 `p(2)=1/2` 归纳得 `p(n)=1/2`（n≥2）。
4. 代码只需处理 `n==1` 返回 `1.0`，其余返回 `0.5`。

以 `n=2` 验证：第 1 人坐 1 号座概率 `1/2`，第 2 人对；坐 2 号座概率 `1/2`，第 2 人错，故 `p(2)=1/2`，与递推式 `1/2 + 0 * p(1)` 一致。

```python
def nthPersonGetsNthSeat(n: int) -> float:
    if n == 1:
        return 1.0
    return 0.5
```

若面试要求写递推版（便于解释），可写成：

```python
def nthPersonGetsNthSeat(n: int) -> float:
    p = 1.0
    for i in range(2, n + 1):
        p = 1.0 / i + (i - 2) / i * p
    return p
```

## 复杂度
时间：O(1)（闭式解），递推版 O(n)，n 来自乘客数。
空间：O(1)，只存一个 `p` 变量，无额外数组。

## 易错点
1. `n=1` 时若直接返回 `0.5` → 错成 0.5，但第 1 人只有自己的座，必坐对，正确返回 `1.0`。这是唯一需要特判的边界，`n≥2` 才恒为 `0.5`。
2. 误以为要模拟随机过程或算全排列 → 对 `n=10^5` 会超时或精度崩。正确做法是识别「坐中间座后问题同构」这一步，直接得闭式解，不枚举 `k`。

## 如果面试官追问
问：若第 1 人不是随机选，而是以概率 `q` 坐自己座、`1-q` 均匀坐其他座，答案变吗？
答：变，`p(n)` 不再恒为 `1/2`，需按 `p(n)=q+(1-q)/(n-1)*[...]` 重新递推，`n=2` 时为 `q+(1-q)/2`。
