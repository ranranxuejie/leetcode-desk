## 一句话思路
按连续相同字符分段，每段长度 L 贡献 L 种可能，答案 = 1 + Σ(L-1)。

## 怎么做
1. 用 `itertools.groupby(word)` 把 `word` 切成连续段，每段得到字符和长度。
2. 对每段长度 `L`，若 Alice 在这段上多按了键，原串该字符可以是 1 到 L 个，共 L 种；不多按则只有 1 种。
3. 因为至多犯错一次，各段独立，总方案 = 各段方案数之积 = Π L。
4. 等价写法：答案 = 1 + Σ(L-1)，即「不犯错」1 种加上「在某一段多按」的 Σ(L-1) 种。

以 `word = "abbcccc"` 为例，分段为 `a:1, b:2, c:4`。`b` 段 L=2 贡献 2 种（`b` 或 `bb`），`c` 段 L=4 贡献 4 种（`c/cc/ccc/cccc`），`a` 段贡献 1 种，乘积 1×2×4=8？不对——注意这里各段只能有一段犯错，所以是 1 + (2-1) + (4-1) = 1+1+3 = 5，与示例一致。

```python
from itertools import groupby

ans = 1
for _, g in groupby(word):
    ans += sum(1 for _ in g) - 1
return ans
```

或不用 groupby，单次扫描：

```python
ans, i, n = 1, 0, len(word)
while i < n:
    j = i
    while j < n and word[j] == word[i]:
        j += 1
    ans += j - i - 1
    i = j
return ans
```

## 复杂度
时间：O(n)，n 为 `word` 长度，每个字符被扫描一次。
空间：O(1)，只用了 `ans`、`i`、`j` 几个整数变量。

## 易错点
- 输入 `word = "aaaa"` → 若误把答案算成各段长度之积 4 之外的组合（如认为可同时缩短两处），会得 4 但含义错；正确做法是只允许一段被缩短，答案 = 1 + (4-1) = 4。
- 输入 `word = "abcd"` → 若忘记加初始的 1（不犯错方案），会得 0；正确做法是 `ans` 初值设为 1，每段只累加 `L-1`。

## 如果面试官追问
问：若允许至多 k 次犯错，答案怎么变？
答：变成各段长度 L 的生成函数系数问题，等价于从每段选 1..L 个、总「多按次数」≤k 的方案数，用 DP 按段累加即可。
