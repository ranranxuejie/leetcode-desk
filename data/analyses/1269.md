## 一句话思路
按步数滚动 DP，`dp[i]` 表示走完当前步数后停在索引 `i` 的方案数，每步由 `i-1 / i / i+1` 三处转移而来。

## 怎么做
1. 有效位置上限取 `m = min(arrLen, steps // 2 + 1)`，因为从 0 出发再回到 0 至少要 2 步，索引超过 `steps//2` 的位置永远回不来。
2. 初始化 `dp = [1] + [0] * (m - 1)`，第 0 步只有停在 0 这一种方案。
3. 每步用 `ndp[i] = dp[i-1] + dp[i] + dp[i+1]`（越界项按 0 处理），再对 `10**9 + 7` 取模。
4. 走完 `steps` 步后返回 `dp[0]`。

以 `steps = 3, arrLen = 2` 为例：`m = min(2, 2) = 2`，初始 `dp = [1, 0]`。第 1 步 `ndp[0] = dp[0] + dp[1] = 1`，`ndp[1] = dp[0] + dp[1] = 1`，得 `[1, 1]`；第 2 步得 `[2, 2]`；第 3 步 `ndp[0] = dp[0] + dp[1] = 2 + 2 = 4`，返回 4。

```python
MOD = 10**9 + 7
m = min(arrLen, steps // 2 + 1)
dp = [1] + [0] * (m - 1)
for _ in range(steps):
    ndp = [0] * m
    for i in range(m):
        v = dp[i]
        if i > 0:
            v += dp[i - 1]
        if i + 1 < m:
            v += dp[i + 1]
        ndp[i] = v % MOD
    dp = ndp
return dp[0]
```

## 复杂度
时间：`O(steps * min(arrLen, steps))`，两层循环分别由 `steps` 和有效位置数 `m` 贡献。
空间：`O(min(arrLen, steps))`，只开 `dp` 和 `ndp` 两个长度 `m` 的数组。

## 易错点
- `arrLen` 很大而 `steps` 很小（如 `steps = 2, arrLen = 10**6`）→ 直接开 `arrLen` 长度的数组会超内存 → 必须用 `m = min(arrLen, steps // 2 + 1)` 截断，本题中 `m = 2`。
- 忘记对 `ndp[i]` 取模 → `steps` 较大时方案数指数增长，Python 虽不溢出但大整数运算会拖慢 → 每次转移后立刻 `% MOD`，不要留到最后统一取模。

## 如果面试官追问
问：如果要求输出所有具体方案而不是方案数？
答：把 `dp[i]` 从计数换成路径列表，转移时做列表拼接，复杂度变成输出规模级别。
