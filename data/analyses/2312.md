## 一句话思路
对每个尺寸 (h,w) 记忆化：max(整块卖价, 所有横切/竖切的两半之和)，因为任意切割方案的最后一步必是某条切线。

## 怎么做
1. 用 `price[h][w]` 存整块卖价，未出现的尺寸记 0（不卖）。
2. `dfs(h,w)` 返回该尺寸最优收益，先取 `price[h][w]` 作下界。
3. 枚举竖切 `i in 1..w-1`：`dfs(h,i)+dfs(h,w-i)`；枚举横切 `j in 1..h-1`：`dfs(j,w)+dfs(h-j,w)`，取最大。
4. 用 `memo[h][w]` 缓存，`-1` 表示未算。

以示例 1（m=3,n=5）为例，`dfs(2,2)`：整块卖 7；竖切 1+1 得 `dfs(2,1)*2 = 3+3 = 6`；横切同理 6，故返回 7。而 `dfs(3,5)` 竖切成 `dfs(3,2)+dfs(3,3)`，其中 `dfs(3,2)=dfs(3,2)` 横切 1+2 得 `dfs(1,2)+dfs(2,2)=0+7=7`，两块合计 14，再加 `dfs(3,3)` 拆出的 3+2=5，共 19。

```python
def dfs(h, w):
    if memo[h][w] != -1:
        return memo[h][w]
    best = price[h][w]
    for i in range(1, w):
        best = max(best, dfs(h, i) + dfs(h, w - i))
    for j in range(1, h):
        best = max(best, dfs(j, w) + dfs(h - j, w))
    memo[h][w] = best
    return best
```

## 复杂度
时间 O(m·n·(m+n))：每个状态枚举 m+n 条切线，共 m·n 个状态。
空间 O(m·n)：memo 表与 price 表各开 201×201。

## 易错点
- 只按 prices 里出现的尺寸切，不枚举「切出无卖价但能继续切」的中间块 → 示例 2 中 4×6 必须先横切出 1×6 再竖切，若跳过无价尺寸会漏掉 1×4 的 2 元，得 30 而非 32。正确做法是对所有 1..h、1..w 枚举切线。
- 把 `price[h][w]` 初始化为 -1 或漏掉「整块不切直接卖」的分支 → 当某尺寸整块卖价高于任何切法时（如示例 1 的 2×2 卖 7 > 切得 6），会返回切分结果 6。正确做法是 `best` 初值取 `price[h][w]`（无价时为 0）。

## 如果面试官追问
问：m、n 放大到 10^4 怎么办？答：状态数爆炸，需换思路——只对 prices 中出现的尺寸及其组合做离散化 DP，或证明最优解只切出有价尺寸。
