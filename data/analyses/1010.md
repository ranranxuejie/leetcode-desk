## 一句话思路
用长度 60 的计数数组 `cnt` 边扫边查：当前余数 `r` 只需找已出现过的 `(60-r) % 60` 配对。

## 怎么做
1. 开 `cnt = [0] * 60`，`ans = 0`，按 `time` 从左到右扫。
2. 对每个 `t`，先算 `r = t % 60`，把 `cnt[(60 - r) % 60]` 累加进 `ans`——这些是下标更小、能和它配对的歌。
3. 再把 `cnt[r] += 1`，把自己登记进去，保证 `i < j` 不重复计数。
4. 返回 `ans`。

拿示例 1 `time = [30,20,150,100,40]` 走一遍关键中间值：处理 `150` 时 `r = 30`，查 `cnt[(60-30)%60] = cnt[30] = 1`（前面那个 30），`ans` 从 0 变 1；处理 `100` 时 `r = 40`，查 `cnt[20] = 1`，`ans` 变 2；处理 `40` 时 `r = 40`，查 `cnt[20] = 1`，`ans` 变 3。最终 3，与输出一致。

```python
cnt = [0] * 60
ans = 0
for t in time:
    r = t % 60
    ans += cnt[(60 - r) % 60]
    cnt[r] += 1
return ans
```

注意 `(60 - r) % 60` 里的取模不能省：`r = 0` 时 `60 - 0 = 60` 会越界，取模后落回 0，正好让余数 0 的歌两两配对（示例 2 的 `[60,60,60]` 靠这一步得到 3）。

## 复杂度
时间 O(n)：n 为 `time` 长度，每个元素 O(1) 查表。
空间 O(1)：额外只开固定 60 个槽的 `cnt`，与 n 无关。

## 易错点
- 输入 `time = [60,60,60]` → 若写成 `cnt[60 - r]` 而不取模，`r = 0` 时下标 60 越界报错 → 必须写 `cnt[(60 - r) % 60]`，让余数 0 的歌互相配对。
- 输入 `time = [30,30]` → 若先 `cnt[r] += 1` 再累加 `ans`，会把自己和自己算成一对，得到 1 而非 1 之外的错误值（自配对）→ 顺序必须是「先查后登记」，保证只统计下标更小的歌。

## 如果面试官追问
问：若要求返回所有配对的下标而不是数量？答：把 `cnt` 换成 `defaultdict(list)` 存下标列表，查表时遍历列表逐个产出 `(i, j)`，时间仍是 O(n + 答案数)。
