## 一句话思路
二分答案 D，把曼哈顿距离 < D 的点对用并查集合并，若连通块数 ≥ 2 则 D 可行。

## 怎么做
1. 答案单调：若 D 可行，则更小的 D 也可行（合并的边更少，连通块只会更多），故二分。
2. 对给定 D，枚举所有点对 `(i, j)`，若 `abs(xi-xj)+abs(yi-yj) < D` 就 `union(i, j)`。
3. 统计连通块个数 `cnt`，`cnt >= 2` 说明能把点分成两组且组内距离都 ≥ D，返回 `True`。
4. 二分区间 `[0, 4*10**8+1]`，取最大可行值。

以示例 1 `[[0,0],[0,2],[2,0],[2,2]]` 为例，D=4 时四条边距离都等于 4，不满足 `< 4`，不合并，`cnt=4 ≥ 2`，可行；D=5 时四条边全合并，`cnt=1`，不可行，故答案 4。

```python
def ok(D):
    parent = list(range(n))
    def find(a):
        while parent[a] != a:
            parent[a] = parent[parent[a]]
            a = parent[a]
        return a

                parent[find(i)] = find(j)
    return len({find(i) for i in range(n)}) >= 2
```

## 复杂度
时间：二分 O(log C) 次，每次 O(n² α(n))，C 为坐标范围，n=500 时约 30×250000。
空间：并查集数组 O(n)，无额外大结构。

## 易错点
- 用 `<= D` 而非 `< D` 合并 → 示例 1 中 D=4 时四条边全被合并，`cnt=1`，答案错成 3；正确做法是距离严格小于 D 才合并，因为划分因子要求组内距离 ≥ D。
- 二分上界取 `10**8` 而非 `4*10**8` → 示例 2 中 `[0,1]` 与 `[10,0]` 距离 11 超过上界，答案被截断；正确上界是 `2*(10**8+10**8)+1`，即 `4*10**8+1`。

## 如果面试官追问
若 n 扩大到 10⁵ 怎么办？答：改用曼哈顿距离的 Kruskal 式最小生成树，按边权排序后取第 n-1 条边权即答案，O(n² log n) 建边仍是瓶颈，需借助网格分桶或旋转坐标降维。
