## 一句话思路
用前缀和算出第 `favoriteType` 类糖果的起始下标 `pre[t]` 和结束下标 `pre[t+1]-1`，再判断第 `favoriteDay` 天能吃的糖果数量区间是否与它相交。

## 怎么做
1. 先对 `candiesCount` 求前缀和 `pre`，`pre[i]` 表示第 `i` 类糖果之前共有多少颗。
2. 第 `t` 类糖果占据的全局下标区间是 `[pre[t], pre[t+1]-1]`。
3. 第 `d` 天能吃到的最少糖果数是 `d+1`（每天至少吃 1 颗），最多是 `(d+1)*cap`。
4. 两个区间 `[d+1, (d+1)*cap]` 与 `[pre[t], pre[t+1]-1]` 有交集就返回 `True`。

以示例 1 的 `[4,2,4]` 为例：`pre = [0,7,11,16,19,27]`，第 4 类区间是 `[19,26]`；第 2 天最多吃 `3*4=12` 颗，`12 < 19`，区间不相交，返回 `False`。

```python
pre = [0] * (len(candiesCount) + 1)
for i, c in enumerate(candiesCount):
    pre[i + 1] = pre[i] + c

ans = []
for t, d, cap in queries:
    lo, hi = d + 1, (d + 1) * cap
    if lo <= pre[t + 1] - 1 and hi >= pre[t]:
        ans.append(True)
    else:
        ans.append(False)
```

## 复杂度
时间：O(n + q)，n 是 `candiesCount` 长度，q 是 `queries` 长度，前缀和与查询各扫一遍。
空间：O(n)，额外开了长度 `n+1` 的 `pre` 数组，答案数组 O(q)。

## 易错点
1. 把第 `d` 天的最少吃糖数写成 `d` 而不是 `d+1`。例如 `[0,2,2]`，第 2 天最少已吃 3 颗，若写成 2 会误判区间下界，导致本该 `True` 的查询算错。正确做法是下界取 `d+1`。
2. 上界 `(d+1)*cap` 在 Python 里不会溢出，但若照搬 C++ 写法用 32 位整数会溢出。题目规定答案按 32 位截断，Python 直接用大整数即可，不要手动截断。

## 如果面试官追问
问：如果要求输出具体每天吃几颗的方案怎么办？
答：按区间交集确定第 `d` 天落在第 `t` 类，再贪心分配每天吃 `min(cap, 剩余)` 颗即可。
