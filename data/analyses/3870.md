## 一句话思路
按位数分段：k 位数（k≥4）每个数有 `(k-1)//3` 个逗号，用区间长度乘一下累加。

## 怎么做
1. 从 `lo = 1`、`digits = 1` 开始，每轮处理 `[lo, min(n, 10**digits - 1)]` 这一段，段内所有数位数相同。
2. 段内每个数的逗号数是 `(digits - 1) // 3`，乘上段长 `hi - lo + 1` 累加进 `ans`。
3. 段处理完把 `lo` 推到 `hi + 1`、`digits += 1`，直到 `lo > n`。

以 `n = 1002` 为例：`digits = 1..3` 三段逗号数都是 0；到 `digits = 4` 时 `lo = 1000`、`hi = min(1002, 9999) = 1002`，段长 3，每个数 `(4-1)//3 = 1` 个逗号，`ans = 3`，与示例一致。

```python
ans = 0
lo, digits = 1, 1
while lo <= n:
    hi = min(n, 10 ** digits - 1)
    ans += (hi - lo + 1) * ((digits - 1) // 3)
    lo = hi + 1
    digits += 1
return ans
```

注意 `digits = 1, 2, 3` 时 `(digits-1)//3` 都是 0，所以三位数及以下天然不加，不需要额外判断。

## 复杂度
时间：O(log n)，循环次数等于 n 的位数，每轮常数次运算。
空间：O(1)，只开了 `ans`、`lo`、`digits`、`hi` 四个整数。

## 易错点
- `n = 1000` → 若把 `hi` 写成 `10**digits`（少减 1），段长会算成 1 而不是 1，或把 1000 归到 5 位段导致逗号数错成 2；正确做法是 `hi = min(n, 10**digits - 1)`，让 1000 落在 `digits = 4` 段、逗号数 `(4-1)//3 = 1`。
- `n = 999999` → 若用 `(digits // 3)` 而不是 `(digits - 1) // 3`，6 位数会算成 2 个逗号（实际 `999,999` 只有 1 个）；正确做法是减 1 再整除，因为最左边那组不足三位不产生逗号。

## 如果面试官追问
问：n 放大到 10^18 还成立吗？答：成立，循环只跑 19 轮，Python 大整数直接算 `10**digits` 不溢出。
