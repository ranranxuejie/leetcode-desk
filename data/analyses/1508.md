## 一句话思路
二分答案 `mid`，用双指针数出「和 ≤ mid 的子数组个数及总和」，再对第 k 小前缀和做两次差分。

## 怎么做
1. 前缀和 `pre[i]`，子数组和 = `pre[j] - pre[i]`，问题变成数有序对。
2. 二分找第 k 小的子数组和：`count(mid)` 返回 `(个数, 总和)`，双指针 `i` 固定左端、`j` 右移。
3. 用 `S(right) - S(left-1)` 得答案，`S(k)` = 前 k 小的和。

以 `nums=[1,2,3,4]`、`left=1,right=5` 为例：`pre=[0,1,3,6,10]`。二分到 `mid=4` 时，双指针数出和 ≤4 的子数组是 `[1],[1,2],[1,2,3]` 中前两个加 `[2],[3],[4]` 等，共 6 个、总和 15；`mid=3` 时 5 个、总和 11。第 5 小是 4，前 5 个和 = 11 + (5-5)*4 = 11？实际排序后前 5 个是 `1,2,3,3,4` 和 13，说明 `mid=3` 时个数应为 4（`1,2,3,3`），总和 9，再加第 5 个 4 得 13。

```python
def count(mid):
    cnt = tot = 0
    j = 0
    for i in range(n):
        while j < n and pre[j+1] - pre[i] <= mid:
            j += 1
        cnt += j - i
        tot += (pre[j] - pre[i]) * (j - i) - (pre_sum[j] - pre_sum[i])
    return cnt, tot
```

其中 `pre_sum` 是 `pre` 的前缀和，用于 O(1) 算区间和。

## 复杂度
时间：二分 O(log(sum)) 轮，每轮双指针 O(n)，共 O(n log(sum))，sum ≤ 10^5。
空间：`pre` 和 `pre_sum` 两个长度 n+1 数组，O(n)。

## 易错点
- `nums=[1,2,3,4]`、`left=1,right=5`：若 `count` 里 `j` 不随 `i` 回退（写成每轮重置 `j=i`），会漏数跨左端的子数组，得到 4 个而非 5 个，答案错成 9。正确做法是 `j` 单调不回退，因为 `pre[j+1]-pre[i]` 随 `i` 增大而减小。
- 二分边界取 `lo=0, hi=pre[n]`：若 `hi` 取 `pre[n]-1`，当 `right` 等于总数时第 k 小恰为 `pre[n]`，会死循环或返回错值。正确做法是 `hi=pre[n]` 且用 `lo<hi` 的 `mid=(lo+hi)//2`。

## 如果面试官追问
问：若 `nums` 含负数怎么办？
答：前缀和不再单调，双指针失效，需换成分治或堆，复杂度升到 O(n² log n)。
