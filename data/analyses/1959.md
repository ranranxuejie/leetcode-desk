## 一句话思路
把数组切成至多 k+1 段，每段统一取该段最大值作 size，用前缀和 O(1) 算段浪费，DP 求最小。

## 怎么做
1. 定义 `dp[j][i]`：前 i 个元素（`nums[0..i-1]`）切成 j 段的最小浪费，答案取 `min(dp[j][n])`，j ≤ k+1。
2. 段浪费公式：段 `[l, r)` 取 `mx = max(nums[l:r])`，浪费 = `mx*(r-l) - (pre[r]-pre[l])`。
3. 转移：`dp[j][i] = min(dp[j-1][l] + cost(l, i))`，l 从 `j-1` 到 `i-1`。
4. 用示例 3 `nums=[10,20,15,30,20], k=2` 验证：`dp[1][5]`（一段）= `30*5 - 95 = 55`；`dp[2][5]` 在 l=3 处得 `dp[1][3] + cost(3,5) = 10 + (30*2-50) = 20`；`dp[3][5]` 在 l=3 得 `dp[2][3] + 10 = 5 + 10 = 15`，即答案。

```python
n = len(nums)
pre = [0] * (n + 1)
for i, v in enumerate(nums):
    pre[i + 1] = pre[i] + v

def cost(l, r):
    mx = max(nums[l:r])
    return mx * (r - l) - (pre[r] - pre[l])

INF = float('inf')
dp = [[INF] * (n + 1) for _ in range(k + 2)]
dp[0][0] = 0
for j in range(1, k + 2):
    for i in range(j, n + 1):
        for l in range(j - 1, i):
            dp[j][i] = min(dp[j][i], dp[j - 1][l] + cost(l, i))
return min(dp[j][n] for j in range(1, k + 2))
```

## 复杂度
时间：O(k·n²)，三层循环，n=200 时约 8×10⁶ 次。
空间：O(k·n) 的 dp 表加 O(n) 前缀和。

## 易错点
- `k >= n-1` 时每段长度 1，浪费必为 0，但若把段数上限写成 `k` 而非 `k+1`，会漏掉「每元素独立成段」这一最优解，返回非 0。正确做法是段数上限取 `k+1`，并让 `l` 从 `j-1` 起保证每段非空。
- 段浪费若写成 `mx*(r-l) - sum` 却把 `sum` 取成 `pre[r]-pre[l-1]`（闭区间写法），会多减 `nums[l]`，示例 1 中 `cost(0,2)` 会算成 `20*2-30=10` 看似对，但 `cost(1,2)` 会算成 `20-20=0` 而实际应为 `20-20=0` 恰好掩盖，示例 3 的 `cost(3,5)` 会错成 `30*2-50=10` 与正确值一致——真正翻车在 `l=0` 的段。统一用左闭右开 `[l, r)` 配 `pre[r]-pre[l]`。

## 如果面试官追问
问：n 放大到 10⁵ 怎么办？答：段浪费满足四边形不等式，可用分治优化或单调栈+斜率优化把内层降到 O(n log n)，但需先证 `cost` 的单调性。
