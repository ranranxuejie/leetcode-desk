## 一句话思路
按传送次数分层 DP：`dp[t][i][j]` 表示用恰好 t 次传送到达 (i,j) 的最小成本，传送层用「后缀最小值」一次性松弛。

## 怎么做
1. 定义 `dp[t][i][j]`，t 从 0 到 k；t=0 时只能普通移动，按行列顺序递推。
2. 普通移动：`dp[t][i][j] = grid[i][j] + min(dp[t][i-1][j], dp[t][i][j-1])`（起点特判为 0）。
3. 传送松弛：从 (i,j) 可零成本跳到任意 `grid[x][y] <= grid[i][j]` 的格子，等价于对每个 t，把 `dp[t]` 中满足值阈值的格子取全局最小，赋给 `dp[t+1]` 的对应位置。
4. 答案取 `min(dp[t][m-1][n-1] for t in range(k+1))`。

以示例 1 为例，`grid=[[1,3,3],[2,5,4],[4,3,5]]`，k=2。t=0 层普通移动得到 `dp[0][1][1]=1+3+5=9`（路径 1→3→5）。t=1 层：从 (1,1) 值 5 可传送到 (2,2) 值 5，`dp[1][2][2]=dp[0][1][1]=9`？实际最优是 1→2→5 到 (1,1) 成本 7，再传送到 (2,2)，得 7。关键中间值：`dp[0][1][1]=7`（走 1→2→5 而非 1→3→5），传送后 `dp[1][2][2]=7`。

```python
# 传送松弛：对每个阈值取全局最小
INF = 2**31 - 1
for t in range(k):
    best = INF
    # 按 grid 值从大到小扫描，维护已见格子的最小 dp
    order = sorted(((grid[i][j], i, j) for i in range(m) for j in range(n)), reverse=True)
    for val, i, j in order:
        if dp[t][i][j] < best:
            best = dp[t][i][j]
        # 此处 best 即所有 grid >= val 的格子中的最小 dp
        dp[t+1][i][j] = min(dp[t+1][i][j], best)
```

## 复杂度
时间：O(k·m·n·log(mn))，排序贡献 log，k 层各扫一遍。
空间：O(k·m·n)，存全部 dp 层；可滚动到 O(m·n)。

## 易错点
- 传送条件是 `grid[x][y] <= grid[i][j]`（目标值不超过当前值），不是「任意格子」。若误写成无条件传送，示例 1 会算出 0（直接从 (0,0) 传到 (2,2) 值 5>1 不合法），正确是 7。
- 传送后仍可继续普通移动再传送，层间必须串行：`dp[t+1]` 依赖 `dp[t]` 全部算完。若在同层内就地更新，示例 2 的 k=1 会少算一次传送机会，得 9 而非更优值。

## 如果面试官追问
若 k 增大到 10^9 怎么办？答：传送次数超过「值严格递减链长」后无增益，可把 k 截断到 O(mn) 或用最短路建模。
