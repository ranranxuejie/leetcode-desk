## 一句话思路
交换只发生在同奇偶下标之间，所以分别比较 s1、s2 的偶数位集合和奇数位集合是否相同。

## 怎么做
1. 取偶数位 `s1[0], s1[2]` 与 `s2[0], s2[2]`，排序后比较。
2. 取奇数位 `s1[1], s1[3]` 与 `s2[1], s2[3]`，排序后比较。
3. 两组都相等返回 `True`，否则 `False`。

以 `s1 = "abcd", s2 = "cdab"` 为例：偶数位 `s1` 是 `['a','c']`、`s2` 是 `['c','a']`，排序后都是 `['a','c']`；奇数位 `s1` 是 `['b','d']`、`s2` 是 `['d','b']`，排序后都是 `['b','d']`，两组都过，返回 `True`。

```python
def canBeEqual(s1, s2):
    even1 = sorted([s1[0], s1[2]])
    even2 = sorted([s2[0], s2[2]])
    odd1 = sorted([s1[1], s1[3]])
    odd2 = sorted([s2[1], s2[3]])
    return even1 == even2 and odd1 == odd2
```

关键点：`j - i = 2` 意味着下标 0 只能和 2 换、1 只能和 3 换，两个位置组互不连通。组内只有两个元素，交换任意次只能得到「原序」或「逆序」两种排列，所以集合相等就是可达。示例 2 中 `s1` 偶数位是 `['a','c']`，`s2` 偶数位是 `['d','b']`，集合不同，直接 `False`。

## 复杂度
时间：O(1)，长度固定为 4，排序常数个元素。
空间：O(1)，只开了几个长度 2 的列表。

## 易错点
- 输入 `s1 = "abab", s2 = "baba"` → 若只比较整体字符计数会错判 `True`，但偶数位 `s1` 是 `['a','a']`、`s2` 是 `['b','b']`，实际应为 `False`；必须分奇偶两组比。
- 输入 `s1 = "abcd", s2 = "badc"` → 若把偶数位和奇数位混在一起排序（整体排成 `['a','b','c','d']`）会错判 `True`，但 `s1` 偶数位 `['a','c']` 与 `s2` 偶数位 `['b','d']` 不等，正确是 `False`；分组时下标别写错成 `s1[0], s1[1]`。

## 如果面试官追问
若长度放宽到 n 且操作仍是 `j - i = 2`，怎么做？答：按奇偶下标分成两个子序列，各自比较字符多重集是否相同，O(n) 时间。
