## 一句话思路
每个单词独立求「多重集排列数」再相乘，因为单词位置固定、字符不能跨空格移动。

## 怎么做
1. 按空格 `s.split(' ')` 切出单词列表，逐个处理。
2. 对单词 `w`，用 `Counter(w)` 得到每个字母的频次，排列数 = `len(w)! / ∏ cnt!`。
3. 除法在模 `10**9+7` 下换成乘逆元：`pow(fact, MOD-2, MOD)`，或预处理阶乘与逆阶乘。
4. 各单词结果累乘取模。

以 `s = "too hot"` 为例：`"too"` 的 `Counter` 是 `{'t':1,'o':2}`，排列数 `3!/(1!·2!) = 3`；`"hot"` 三个字母全不同，`3! = 6`；答案 `3*6 = 18`，与官方一致。注意 `"aa"` 只有 `2!/2! = 1`。

```python
MOD = 10**9 + 7
n = len(s)
fact = [1] * (n + 1)
for i in range(1, n + 1):
    fact[i] = fact[i-1] * i % MOD

ans = 1
for w in s.split(' '):
    ways = fact[len(w)]
    for c in Counter(w).values():
        ways = ways * pow(fact[c], MOD - 2, MOD) % MOD
    ans = ans * ways % MOD
```

关键中间值：处理 `"too"` 时 `ways` 先取 `fact[3]=6`，再乘 `pow(fact[2], MOD-2, MOD)`，得 `6 * inv(2) ≡ 3`。

## 复杂度
时间：O(n + n log MOD)，`n = len(s)`，每个频次做一次快速幂。
空间：O(n)，`fact` 数组长度 n+1，`Counter` 最多 26 个键。

## 易错点
- 输入 `"aa"` 或 `"aabb"` 这类有重复字母的单词 → 若直接返回 `fact[len(w)]` 会得 2、24 → 必须除以每个字母频次的阶乘（乘逆元）。
- 输入 `"a b"` 这种多单词 → 若把所有字符合起来算一次排列会得 `2! = 2`，但正确答案是 `1*1 = 1` → 必须按空格切分后逐词相乘，单词间字符不可交换。

## 如果面试官追问
问：若 s 长度到 10^7 怎么办？答：预处理阶乘到最大单词长度即可，不必到 n，逆元用线性递推 `inv[i] = MOD - MOD//i * inv[MOD%i] % MOD` 省掉 log。
