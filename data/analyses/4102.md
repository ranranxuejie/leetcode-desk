## 一句话思路
用双指针维护「不含 abc 的最长窗口」，对每个右端点累加窗口长度，因为以 right 结尾的合法子串数恰好等于窗口长度。

## 怎么做
1. 用 `left` 记录窗口左界，`right` 从 0 扫到 n-1，窗口 `s[left..right]` 始终不含 `"abc"`。
2. 每次 `right` 右移后，若 `right >= 2` 且 `s[right-2:right+1] == "abc"`，说明新字符凑出了 `"abc"`，把 `left` 移到 `right - 1`（即丢掉这个 `"abc"` 的 `'a'`）。
3. 此时以 `right` 结尾的合法子串起点可以是 `left..right` 共 `right - left + 1` 个，累加进 `ans`。

以 `s = "abac"` 为例：`right=2` 时 `s[0:3]="aba"` 不是 `"abc"`，`left` 仍为 0，累加 3；`right=3` 时 `s[1:4]="bac"` 也不是，累加 4；总计 1+2+3+4=10。

```python
ans, left = 0, 0
for right in range(len(s)):
    if right >= 2 and s[right-2:right+1] == "abc":
        left = right - 1
    ans += right - left + 1
return ans
```

关键点：`left = right - 1` 而不是 `right - 2`，因为 `"abc"` 的 `'a'` 在 `right-2`，窗口必须从它之后开始才不含 `"abc"`；而 `right-1` 处的 `'b'` 可以保留。

## 复杂度
时间：O(n)，`right` 扫一遍，`left` 单调右移，切片比较是常数 3 个字符。
空间：O(1)，只开了 `ans`、`left`、`right` 三个变量。

## 易错点
- 输入 `s = "abcabc"` → 若写成 `left = right - 2`，窗口会把 `'a'` 留下，后续 `"abc"` 被重复计数，答案偏大 → 正确是 `left = right - 1`，让窗口从 `'b'` 开始。
- 输入 `s = "aabc"` → 若只在 `right >= 2` 时判断而忘了 `left` 可能已经越过 `right-2`，会把已滑出窗口的 `"abc"` 再判一次，导致 `left` 回退 → 正确做法是判断前先确认 `right - 2 >= left`，或直接依赖 `left` 单调不减。

## 如果面试官追问
若要求返回所有合法子串而非计数？答：枚举每个 `right`，起点取 `left..right` 逐个切片输出，复杂度升到 O(n²)，需按输出规模计。
