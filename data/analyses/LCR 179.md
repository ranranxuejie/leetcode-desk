## 一句话思路
数组已升序，用左右双指针从两端夹逼，和偏小移左指针、偏大移右指针，必能命中。

## 怎么做
1. 令 `i = 0`、`j = len(price) - 1`，分别指向最小和最大价格。
2. 每轮算 `s = price[i] + price[j]`，与 `target` 比较。
3. `s == target` 直接返回 `[price[i], price[j]]`；`s < target` 说明 `price[i]` 太小，`i += 1`；`s > target` 说明 `price[j]` 太大，`j -= 1`。
4. 循环到 `i >= j` 结束（本题保证有解，实际不会走到）。

拿示例 1 `price = [3, 9, 12, 15], target = 18` 走一遍：初始 `i=0, j=3`，`s = 3 + 15 = 18`，第一轮就命中，返回 `[3, 15]`。再看示例 2 `price = [8, 21, 27, 34, 52, 66], target = 61`：`i=0, j=5` 时 `s = 8 + 66 = 74 > 61`，`j` 减到 4；`s = 8 + 52 = 60 < 61`，`i` 加到 1；`s = 21 + 52 = 73 > 61`，`j` 减到 3；`s = 21 + 34 = 55 < 61`，`i` 加到 2；`s = 27 + 34 = 61`，返回 `[27, 34]`。关键中间值就是每轮的 `s` 与 `target` 的差值方向。

```python
i, j = 0, len(price) - 1
while i < j:
    s = price[i] + price[j]
    if s == target:
        return [price[i], price[j]]
    if s < target:
        i += 1
    else:
        j -= 1
return []
```

正确性靠升序：`s < target` 时，`price[i]` 配任何 `≤ price[j]` 的元素都只会更小，故 `price[i]` 可整体排除；`s > target` 时同理排除 `price[j]`。每次至少排除一个元素，不会漏解。

## 复杂度
时间 O(n)：`i` 与 `j` 相向移动，合计最多走 n 步，n 为 `price.length`。
空间 O(1)：只开了 `i`、`j`、`s` 三个变量，返回值不计。

## 易错点
- 输入含重复价格如 `price = [3, 3, 4], target = 6` → 若写成 `while i <= j`，`i == j` 时会把同一个 `price[2]` 用两次得到 `[3, 3]` 看似对但下标重复 → 正确写法是 `while i < j`，保证两个不同下标。
- 输入 `price = [1, 2], target = 3` 这类边界 → 若循环条件写成 `while i < j - 1` 会直接跳过唯一一对 → 用 `i < j` 才能覆盖相邻两元素。

## 如果面试官追问
问：若数组无序怎么办？答：先排序再双指针是 O(n log n)，或用哈希表存 `target - price[i]` 做到 O(n) 时间、O(n) 空间。
