## 一句话思路
从左到右贪心：每个位置优先取最短的合法回文（长度 k 或 k+1），取到就立刻切分，因为短回文给后面留的空间最大。

## 怎么做
1. 遍历起点 `i`，先试长度 `k` 的 `s[i:i+k]`，是回文就计数并令 `i += k`。
2. 否则试长度 `k+1` 的 `s[i:i+k+1]`，是回文就计数并令 `i += k+1`。
3. 都不是则 `i += 1` 跳过这个字符。
4. 只需判长度 k 和 k+1：任何更长的回文都能截出等价的短回文，不会更优。

以 `s = "abaccdbbd", k = 3` 为例：`i=0` 时 `s[0:3] = "aba"` 是回文，计数 1、跳到 `i=3`；`s[3:6] = "ccd"` 不是回文，`s[3:7] = "ccdb"` 也不是，`i=4`；`s[4:7] = "ccd"` 不是，`s[4:8] = "ccdb"` 不是，`i=5`；`s[5:8] = "dbb"` 不是，`s[5:9] = "dbbd"` 是回文，计数 2、跳到 `i=9` 结束，返回 2。

```python
def maxPalindromes(s, k):
    n, i, ans = len(s), 0, 0
    while i + k <= n:
        if s[i:i+k] == s[i:i+k][::-1]:
            ans += 1
            i += k
        elif i + k + 1 <= n and s[i:i+k+1] == s[i:i+k+1][::-1]:
            ans += 1
            i += k + 1
        else:
            i += 1
    return ans
```

## 复杂度
时间 O(n·k)：每个起点最多两次长度 k 的切片比较，n 为 s 长度。
空间 O(k)：切片和反转各开一份长度 k 的临时串。

## 易错点
- 只试长度 k 不试 k+1：`s = "abba", k = 3` 时 `s[0:3] = "abb"` 不是回文，会误判为 0；实际 `s[0:4] = "abba"` 是回文，答案 1。
- 找到回文后 `i += 1` 而不是跳过整段：`s = "aba", k = 3` 会从 `i=1` 再判 `s[1:4]` 越界或重复计数，正确是 `i += k` 直接跳到 3。

## 如果面试官追问
要求输出具体方案怎么办？答：把 `i += k` 处改成记录 `(i, i+k)` 区间，其余逻辑不变，贪心选出的区间序列就是一组最优解。
