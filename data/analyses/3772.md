## 一句话思路
两次 DFS 换根 DP：先自底向上算「只往下走」的最优贡献，再自顶向下把父节点方向的贡献补进来。

## 怎么做
1. 以 0 为根建邻接表，`val[i] = 1 if good[i] else -1`，先算 `down[i]`：以 i 为根的子树里，必须含 i 的最大得分。
2. 后序 DFS：`down[i] = val[i] + sum(max(0, down[c]) for c in children)`，负贡献的子树直接不选。
3. 前序 DFS 算 `ans[i]`：对根 `ans[0] = down[0]`；对子节点 c，父方向能带来的贡献是 `max(0, ans[i] - max(0, down[c]))`，于是 `ans[c] = down[c] + max(0, 父方向贡献)`。
4. 返回 `ans`。

用示例 2（`good = [0,1,0,1,1]`，边 `1-0,1-2,1-3,3-4`）走一遍：`val = [-1,1,-1,1,1]`，`down[4]=1`，`down[3]=1+1=2`，`down[2]=-1`，`down[0]=-1`，`down[1]=1+max(0,-1)+max(0,-1)+max(0,2)=3`。换根到 0：父方向贡献 `max(0, 3 - max(0,-1)) = 3`，`ans[0] = -1 + 3 = 2`，与输出一致。

```python
def dfs1(u, p):
    down[u] = val[u]
    for v in adj[u]:
        if v != p:
            dfs1(v, u)
            down[u] += max(0, down[v])

def dfs2(u, p):
    for v in adj[u]:
        if v != p:
            up = max(0, ans[u] - max(0, down[v]))
            ans[v] = down[v] + up
            dfs2(v, u)

dfs1(0, -1); ans[0] = down[0]; dfs2(0, -1)
```

## 复杂度
时间 O(n)：每条边在两次 DFS 中各被访问两次。
空间 O(n)：`adj`、`down`、`ans` 各 n，递归栈最坏 n。

## 易错点
- 链状树（如 `n=10^5` 的一条链）→ Python 默认递归深度 1000 会 `RecursionError` → 必须 `sys.setrecursionlimit(300000)`，或改写成显式栈的迭代后序/前序。
- 换根时写成 `ans[u] - down[v]` 而漏掉 `max(0, ...)` → 当 `down[v]` 为负（如示例 2 的节点 2，`down[2]=-1`）时，父方向贡献被算成 `3-(-1)=4`，`ans[2]` 错成 3 而非 2 → 正确写法是 `ans[u] - max(0, down[v])`，因为负贡献本来就没被加进 `ans[u]`。

## 如果面试官追问
要求输出取得最大得分的具体子图节点集合怎么办？
答：在 `down` 和 `ans` 里同时记录「选了哪些子节点」，换根时把父方向选中的部分并入，最后从每个 i 出发按记录展开即可。
