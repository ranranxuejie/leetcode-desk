## 一句话思路
把每个格子拆成四个角点，隔板连边，从边界外灌水做并查集，没被淹到的封闭角点区域所围格子即蓄水。

## 怎么做
1. 把 `(i,j)` 的四个角编号为 `4*(i*W+j)+{0,1,2,3}`，对应左上、右上、左下、右下。
2. 按 `shape[i][j]` 连边：`'l'` 连左上-右下，`'r'` 连左下-右上，`'.'` 四角全连通（无隔板）。
3. 相邻格共享角点天然连通，再把整个外边框的角点并入一个虚拟源点 `S`，从 `S` 做并查集合并。
4. 遍历每个格子，若它的四个角点都不与 `S` 同集合，说明被隔板完全封住，蓄水量 `+2`。

以示例 3 `["rlrr","llrl","llr."]` 为例：`(2,3)` 是 `'.'`，四角互通；而 `(0,0)` 是 `'r'`，只连左下-右上，其左上角经外边框连到 `S`，故该格不蓄水。最终只有被 `l`/`r` 围死的格子计入，得 `6`。

```python
def find(x):
    while p[x] != x:
        p[x] = p[p[x]]
        x = p[x]
    return x

def union(a, b):
    ra, rb = find(a), find(b)
    if ra != rb:
        p[ra] = rb

# 角点编号：0左上 1右上 2左下 3右下
for i in range(H):
    for j in range(W):
        c = shape[i][j]
        b = 4 * (i * W + j)
        if c == 'l':
            union(b, b + 3)
        elif c == 'r':
            union(b + 2, b + 1)
        else:
            union(b, b + 1); union(b, b + 2); union(b, b + 3)
```

## 复杂度
时间：`O(H*W*α)`，每个格子常数次并查集操作，`α` 为反阿克曼函数。
空间：`O(H*W)`，开了 `4*H*W` 的父数组 `p`。

## 易错点
- 只连格内隔板、忘了相邻格共享角点：如示例 1 中 `(0,4)` 的 `'r'` 与 `(0,5)` 的 `'l'` 若不通过共享角点连通，会把本该透气的区域误判为封闭，答案偏大。正确做法是角点编号按全局坐标算，相邻格自然复用同一编号。
- `'.'` 当成不连通：示例 3 的 `(2,3)` 是 `'.'`，若漏掉四角全连，会把它和外界隔开而多算 `2`。正确做法是 `'.'` 必须把 `b,b+1,b+2,b+3` 全部 union。

## 如果面试官追问
若 `shape` 规模涨到 `500×500` 且要求输出每个蓄水格坐标，怎么做？答：并查集不变，最后遍历时把 `find` 结果不等于 `S` 的格子坐标收集进列表即可，复杂度不变。
