## 一句话思路
只需判断每个 k 的倍数偏移处，`word[i:]` 是否等于 `word[:n-i]`，第一个成立的位置就是答案。

## 怎么做
1. 关键观察：每秒移除前 k 个字符，等价于把原串的起点向后平移 k；末尾补的字符可以任意，所以只要原串剩余的后缀 `word[i:]` 与新串的前缀对齐，就能补成原串。
2. 因此第 t 秒恢复的充要条件是 `word[t*k:] == word[:n-t*k]`，即原串有长度为 `n-t*k` 的 border（真前缀等于真后缀）。
3. 从 `t = 1` 开始枚举 `i = t*k`，第一个满足条件的 t 就是答案；若 `i >= n` 则必然恢复（此时后缀为空，补 k 个字符即可），返回 `ceil(n/k)`。

以 `word = "abacaba", k = 3` 为例：`t=1` 时 `i=3`，比较 `word[3:]="caba"` 与 `word[:4]="abac"`，不等；`t=2` 时 `i=6`，比较 `word[6:]="a"` 与 `word[:1]="a"`，相等，返回 2。

```python
n = len(word)
t = 1
while t * k < n:
    i = t * k
    if word[i:] == word[:n - i]:
        return t
    t += 1
return t
```

注意循环条件用 `< n` 而非 `<= n`：当 `i == n` 时后缀为空串，必然相等，直接落到 `return t`，不必再比较一次。

## 复杂度
时间 O(n²/k)：最多 n/k 轮，每轮字符串比较 O(n)，n 为 `len(word)`。
空间 O(n)：切片 `word[i:]` 和 `word[:n-i]` 各复制一份，无其他额外结构。

## 易错点
- `word = "abacaba", k = 4`：若从 `t=0` 开始枚举，`i=0` 时 `word[0:] == word[:7]` 恒成立，会错答 0；题目要求时间大于零，必须从 `t=1` 起。
- `word = "aaaa", k = 3`：`t=1` 时 `i=3`，`word[3:]="a"` 与 `word[:1]="a"` 相等返回 1，看似没问题；但若写成 `while i < n` 且循环体内不处理 `i >= n` 的收尾，`k >= n` 的输入（如 `word="ab", k=2`）会直接跳出循环返回未定义的 t，正确做法是循环结束后 `return t`，此时 `t=1` 恰好是 `ceil(n/k)`。

## 如果面试官追问
若 n 放大到 10^5，O(n²/k) 会超时，怎么办？答：用 Z 函数或滚动哈希预处理，把每次 `word[i:] == word[:n-i]` 的比较降到 O(1)，总时间 O(n)。
