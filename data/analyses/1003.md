## 一句话思路
用栈扫描，遇到 `'c'` 就检查栈顶是否为 `"ab"` 并弹出，否则压栈；最后栈空即有效。

## 怎么做
1. 遍历 `s` 的每个字符 `ch`，非 `'c'` 一律 `stack.append(ch)`。
2. 遇到 `'c'` 时，若栈顶两个元素恰好是 `'a'`、`'b'`（顺序为 `stack[-2]=='a' and stack[-1]=='b'`），弹出这两个，等价于消掉一个 `"abc"`。
3. 若 `'c'` 时栈不足两个或栈顶不是 `"ab"`，直接返回 `False`。
4. 遍历结束后返回 `not stack`。

拿 `s = "aabcbc"` 走一遍：读到 `'a'` 压栈 → `['a']`；再读 `'a'` → `['a','a']`；读 `'b'` → `['a','a','b']`；读 `'c'`，栈顶两元素是 `'a','b'`，弹出后 `['a']`；读 `'b'` → `['a','b']`；读 `'c'`，弹出后 `[]`，返回 `True`。关键中间值就是第一次消解后栈从 `['a','a','b']` 变成 `['a']`，说明内层 `"abc"` 被正确折叠。

```python
stack = []
for ch in s:
    if ch != 'c':
        stack.append(ch)
    else:
        if len(stack) < 2 or stack[-1] != 'b' or stack[-2] != 'a':
            return False
        stack.pop()
        stack.pop()
return not stack
```

为什么成立：插入 `"abc"` 的逆操作就是删掉一个相邻的 `"abc"`，而任何合法串都能通过反复删除相邻 `"abc"` 归空；栈正是从左到右模拟这个删除，`'c'` 只能和紧邻它左边的 `"ab"` 配对。

## 复杂度
时间 O(n)：每个字符最多入栈出栈各一次，n 为 `len(s)`。
空间 O(n)：最坏全为 `'a'` 时栈存 n 个字符。

## 易错点
- 输入 `s = "abccba"` → 若只判断 `'c'` 时栈非空就弹两个，会把 `"ab"` 弹掉后剩 `"cba"` 误判 → 必须严格校验 `stack[-2]=='a' and stack[-1]=='b'`，此例第二个 `'c'` 时栈顶是 `'c'`，应返回 `False`。
- 输入 `s = "abc"` 长度 3 或 `s = "c"` → 若忘记 `len(stack) < 2` 判断，`stack[-2]` 会抛 `IndexError` → 先判长度再取下标，`'c'` 开头直接 `False`。

## 如果面试官追问
问：若允许插入 `"abc"` 或 `"cba"` 两种，怎么改？
答：`'c'` 时同时匹配栈顶 `"ab"` 或 `"ba"` 两种模式弹出即可，其余不变。
