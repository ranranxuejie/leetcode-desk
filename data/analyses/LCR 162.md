## 一句话思路
按位统计：对每一位算它取 1 时，低位自由、高位受限的组合数，累加即答案。

## 怎么做
1. 从个位起令 `factor = 1`，每轮取 `high = num // (factor * 10)`、`cur = num // factor % 10`、`low = num % factor`。
2. `cur == 0` 时该位贡献 `high * factor`；`cur == 1` 时贡献 `high * factor + low + 1`；`cur > 1` 时贡献 `(high + 1) * factor`。
3. 累加到 `total`，`factor *= 10`，直到 `factor > num` 停止。

以 `num = 13` 为例：`factor = 1` 时 `high = 1, cur = 3, low = 0`，`cur > 1` 贡献 `(1+1)*1 = 2`（即 1、11 的个位）；`factor = 10` 时 `high = 0, cur = 1, low = 3`，贡献 `0*10 + 3 + 1 = 4`（10、11、12、13 的十位）。合计 6。

```python
total = 0
factor = 1
while factor <= num:
    high = num // (factor * 10)
    cur = num // factor % 10
    low = num % factor
    if cur == 0:
        total += high * factor
    elif cur == 1:
        total += high * factor + low + 1
    else:
        total += (high + 1) * factor
    factor *= 10
```

关键点：`cur == 1` 时不能直接给满 `factor`，因为高位等于 `high` 时低位只能取到 `low`，所以是 `low + 1` 个而不是 `factor` 个。

## 复杂度
时间：O(log num)，`factor` 每轮乘 10，循环次数是 num 的十进制位数。
空间：O(1)，只开了 `total/factor/high/cur/low` 五个整数。

## 易错点
- `num = 0` → 若写成 `while factor <= num` 之外的 `do-while` 或先加后判，会返回非 0；正确做法是循环条件 `factor <= num`，`num = 0` 时直接不进循环返回 0。
- `num = 13` 的十位 → 若把 `cur == 1` 也按 `(high + 1) * factor` 算，会得 `1 * 10 = 10`，答案变 12；正确做法是 `cur == 1` 单独用 `high * factor + low + 1`，这里 `low = 3` 得 4。

## 如果面试官追问

答：成立，循环只跑 19 轮，Python 整数无溢出，答案按题目要求处理即可。
