## 一句话思路
枚举逗号切点把数字串分成两段，每段独立枚举小数点位置，用合法性剪枝后做笛卡尔积。

## 怎么做
1. 先剥掉外层括号，得到纯数字串 `t = s[1:-1]`，长度 `n`。
2. 枚举切点 `i`（1 到 n-1），左段 `t[:i]`、右段 `t[i:]` 各自生成所有合法数字形式。
3. 单段生成规则：不插点则要求「长度>1 时不能以 '0' 开头」；插点则要求「整数部分不以 '0' 开头（除非整数部分就是单个 '0'）」且「小数部分不以 '0' 结尾」。
4. 两段结果做笛卡尔积，拼成 `"(" + a + ", " + b + ")"`。

以 `"(0123)"` 为例，切点 `i=1` 时左段是 `"0"`，只能产出 `["0"]`；右段 `"123"` 产出 `["123","12.3","1.23"]`，于是得到 `(0, 123)`、`(0, 12.3)`、`(0, 1.23)` 三条。切点 `i=2` 时左段 `"01"` 因以 '0' 开头且长度>1，不插点被否，插点得 `"0.1"`，右段 `"23"` 得 `["23","2.3"]`，产出 `(0.1, 23)`、`(0.1, 2.3)`。

```python
def forms(u):
    res = []
    if len(u) == 1 or u[0] != '0':
        res.append(u)                      # 不插点
    for k in range(1, len(u)):
        a, b = u[:k], u[k:]
        if (len(a) == 1 or a[0] != '0') and b[-1] != '0':
            res.append(a + '.' + b)
    return res

t = s[1:-1]
ans = []
for i in range(1, len(t)):
    for a in forms(t[:i]):
        for b in forms(t[i:]):
            ans.append('(' + a + ', ' + b + ')')
```

## 复杂度
时间：O(n²) 个切点×点位的组合，每个拼接 O(n)，n 为数字串长度（≤10）。
空间：O(n²) 存结果字符串，递归栈无（纯迭代）。

## 易错点
- 输入 `"(100)"` → 若允许小数部分以 '0' 结尾，会多出 `(1.0, 0)`、`(10.0, 0)` 等非法项 → 插点时必须判 `b[-1] != '0'`，正确答案只有 `(10, 0)`。
- 输入 `"(00011)"` → 若只判「不以 '0' 开头」而不区分整数部分长度，`"00.01"` 会被放过 → 整数部分要么是单个 `'0'`，要么首位非 `'0'`，即 `len(a) == 1 or a[0] != '0'`。

## 如果面试官追问
问：若 S 长度放宽到 30 呢？
答：切点×点位仍是 O(n²)，但结果数量本身指数级，只能改成生成器惰性产出，不能全存列表。
