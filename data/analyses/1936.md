## 一句话思路
逐段看相邻高度差，用 `(gap - 1) // dist` 算出该段必须插入的台阶数，累加即最少。

## 怎么做
1. 把地板 0 也当成起点，令 `prev = 0`，答案 `ans = 0`。
2. 遍历 `rungs` 中每个高度 `h`，算当前跨度 `gap = h - prev`。
3. 若 `gap > dist`，这段至少要插 `(gap - 1) // dist` 个台阶，累加进 `ans`。
4. 更新 `prev = h`，继续下一段。

以示例 1 `rungs = [1,3,5,10], dist = 2` 为例：前三段 gap 分别是 1、2、2，都不超过 2，`ans` 仍为 0；到 `h = 10` 时 `prev = 5`，`gap = 5`，`(5 - 1) // 2 = 2`，`ans` 变成 2，正好对应在 7、8 处插两阶。

```python
prev = 0
ans = 0
for h in rungs:
    gap = h - prev
    if gap > dist:
        ans += (gap - 1) // dist
    prev = h
return ans
```

关键在 `(gap - 1) // dist` 而不是 `gap // dist`：gap 恰好等于 dist 的整数倍时，最后一步正好踩到原台阶，不需要多插。比如 gap = 4、dist = 2，`(4-1)//2 = 1`，只需在中间插 1 阶（高度 2），而不是 2 阶。

## 复杂度
时间：O(n)，n 为 `rungs` 长度，每个台阶只访问一次。
空间：O(1)，只用了 `prev`、`ans` 两个变量。

## 易错点
- 忘记把地板 0 算作起点 → 示例 3 `rungs = [3,4,6,7], dist = 2` 会漏掉第一段 gap = 3，输出 0；正确做法是 `prev` 初始化为 0，第一段算出 `(3-1)//2 = 1`，答案 1。
- 用 `gap // dist` 代替 `(gap - 1) // dist` → 输入 `rungs = [4], dist = 2` 会算成 2，实际只需在高度 2 插 1 阶；整除前先减 1 才能排除「正好落在原台阶」的情况。

## 如果面试官追问
要求输出具体插入的高度方案怎么办？答：每段按 `prev + dist, prev + 2*dist, ...` 依次生成，直到剩余距离不超过 dist，再跳到 `h`。
