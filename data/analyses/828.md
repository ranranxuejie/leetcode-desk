## 一句话思路
对每个位置 i，用左右最近的相同字符夹出「i 是唯一字符」的子串数，累加即答案。

## 怎么做
1. 预处理每个下标 i 的 `left[i]`（左边最近的相同字符下标，无则 -1）和 `right[i]`（右边最近的相同字符下标，无则 n）。
2. 以 i 为唯一字符的子串，起点可在 `(left[i], i]` 共 `i - left[i]` 种，终点可在 `[i, right[i])` 共 `right[i] - i` 种，贡献相乘。
3. 对所有 i 求和。

以 `s = "ABA"` 为例：i=0 的 `left=-1, right=2`，贡献 `1*2=2`；i=1 的 `left=-1, right=3`，贡献 `2*2=4`；i=2 的 `left=0, right=3`，贡献 `2*1=2`；合计 8，与示例一致。注意 i=1 的 'B' 在 "AB"、"BA"、"ABA" 里都唯一，但 "ABA" 中 A 重复，所以 A 的贡献被 `right[0]=2` 截断。

```python
n = len(s)
last = {}
left = [-1] * n
for i, ch in enumerate(s):
    left[i] = last.get(ch, -1)
    last[ch] = i
last = {}
right = [n] * n
for i in range(n - 1, -1, -1):
    ch = s[i]
    right[i] = last.get(ch, n)
    last[ch] = i
ans = 0
for i in range(n):
    ans += (i - left[i]) * (right[i] - i)
return ans
```

## 复杂度
时间 O(n)：两趟扫描建 left/right，再一趟求和，字符集固定 26。
空间 O(n)：left、right 两个长度 n 的数组，哈希表最多 26 项。

## 易错点
- 边界用 0 或 n-1 代替 -1 和 n → 对 `s = "A"` 会算成 `(0-0)*(0-0)=0`，正确是 `(0-(-1))*(1-0)=1`。哨兵必须是 -1 和 n。
- 只记「上一次出现」而漏掉「下一次」→ 对 `s = "ABA"` 的 i=0 会误以为右边无重复，贡献算成 `1*3=3`，实际 `right[0]=2` 应为 2。必须双向各扫一趟。

## 如果面试官追问
若 s 长度升到 10^7、内存吃紧，怎么省掉两个数组？答：先正扫一遍把 `i - left[i]` 累乘进答案的临时结构不可行，改为对每个字符维护「上次、上上次」两个位置，扫到第三次出现时结算中间那次，空间降到 O(26)。
