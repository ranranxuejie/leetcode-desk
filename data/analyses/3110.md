## 一句话思路
一次遍历，用 `ord(s[i]) - ord(s[i-1])` 取绝对值累加，因为分数就是所有相邻差的和。

## 怎么做
1. 初始化 `ans = 0`，从下标 `i = 1` 开始遍历到 `len(s) - 1`。
2. 每步算 `diff = abs(ord(s[i]) - ord(s[i-1]))`，累加进 `ans`。
3. 遍历结束返回 `ans`。

以 `s = "hello"` 为例，`i = 1` 时 `ord('e') - ord('h') = 101 - 104 = -3`，取绝对值得 `3`，`ans` 变成 `3`；`i = 2` 时 `ord('l') - ord('e') = 108 - 101 = 7`，`ans = 10`；`i = 3` 时 `108 - 108 = 0`，`ans` 不变；`i = 4` 时 `111 - 108 = 3`，`ans = 13`。

```python
ans = 0
for i in range(1, len(s)):
    ans += abs(ord(s[i]) - ord(s[i - 1]))
return ans
```

关键点：循环从 `1` 开始而不是 `0`，因为 `s[-1]` 在 Python 里会绕回最后一个字符，`i = 0` 时 `s[i-1]` 是 `s[-1]`，会多算一对 `s[0]` 和 `s[-1]` 的差。

## 复杂度
时间：O(n)，n 为 `len(s)`，每个相邻对访问一次。
空间：O(1)，只用了 `ans` 和 `diff` 两个整数。

## 易错点
1. 循环写成 `for i in range(len(s))` 且用 `s[i-1]` → 对 `"hello"` 会多算 `|ord('h') - ord('o')| = 7`，输出 `20` 而不是 `13` → 正确做法是 `range(1, len(s))`，或显式判断 `i > 0`。
2. 用 `ord(s[i]) - ord(s[i-1])` 忘记 `abs` → 对 `"zaz"` 第一步得 `-25`，累加后 `ans = -25 + 25 = 0`，输出 `0` 而不是 `50` → 每步必须包 `abs(...)`，或先比较大小再相减。

## 如果面试官追问
问：如果字符串长度到 10^7，还能这样写吗？
答：能，O(n) 时间 O(1) 空间已是最优；只是 Python 逐字符 `ord` 有常数开销，可改用 `bytes` 迭代 `s.encode()` 直接拿整数。
