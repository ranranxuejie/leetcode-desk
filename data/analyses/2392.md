## 一句话思路
行约束和列约束互不干扰，各自做一次拓扑排序得到数字的排名，再把数字按行排名、列排名放进矩阵。

## 怎么做
1. 对 `rowConditions` 建图跑拓扑排序，得到 `rowRank[x]` = 数字 x 的行号；若排不满 k 个点说明有环，返回 `[]`。
2. 对 `colConditions` 同样跑一次，得到 `colRank[x]` = 数字 x 的列号，有环同样返回 `[]`。
3. 遍历 x = 1..k，令 `mat[rowRank[x]][colRank[x]] = x`。

以示例 1 为例：行图边为 1→2、3→2，入度 `indeg[2]=2`，队列初始 `[1,3]`，弹出顺序 1、3、2，故 `rowRank = {1:0, 3:1, 2:2}`；列图边 2→1、3→2，弹出顺序 3、2、1，`colRank = {3:0, 2:1, 1:2}`。于是 3 落在 (1,0)、1 落在 (0,2)、2 落在 (2,1)，与官方输出一致。

```python
from collections import deque

def topo(k, cond):
    g = [[] for _ in range(k + 1)]
    indeg = [0] * (k + 1)
    for a, b in cond:
        g[a].append(b)
        indeg[b] += 1
    q = deque(x for x in range(1, k + 1) if indeg[x] == 0)
    rank = [0] * (k + 1)
    cnt = 0
    while q:
        u = q.popleft()
        rank[u] = cnt
        cnt += 1
        for v in g[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return rank if cnt == k else None

r = topo(k, rowConditions)
c = topo(k, colConditions)
if r is None or c is None:
    return []
mat = [[0] * k for _ in range(k)]
for x in range(1, k + 1):
    mat[r[x]][c[x]] = x
return mat
```

## 复杂度
时间：O(k + n + m)，建图与拓扑各扫一遍边，填矩阵 O(k)。
空间：O(k + n + m)，邻接表存两套边，另有 `indeg`、`rank`、`mat` 各 O(k)。

## 易错点
- 只检查了行图有环就返回 `[]`，漏检列图：如 `rowConditions=[[1,2]]`、`colConditions=[[2,1],[1,2]]` 时列图成环，仍会输出矩阵。两次 `topo` 都要判 `cnt == k`。
- 把 `rank` 当成「第几小」而不是「第几个被弹出」：拓扑序不唯一，`rank[u]=cnt` 必须用弹出计数赋值，若改成按节点编号或按入度排序，示例 1 中 1 和 3 的行号会颠倒，虽然仍合法但列方向可能冲突——正确做法是行列两次排序都用同一套弹出计数逻辑，不要混用。

## 如果面试官追问
问：若要求行号尽量小（字典序最小的矩阵）怎么办？
答：拓扑时把队列换成最小堆，每次弹编号最小的零入度点，得到的排名即字典序最小。
