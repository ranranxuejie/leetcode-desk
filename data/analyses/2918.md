## 一句话思路
把每个 0 都填成 1 得到两数组的最小可能和，谁小就把谁的 0 往上加，加到追平为止。

## 怎么做
1. 分别算出 `s1 = sum(nums1)`、`s2 = sum(nums2)`，以及 `z1 = nums1.count(0)`、`z2 = nums2.count(0)`。
2. 每个 0 至少填 1，所以数组 i 的和下限是 `s_i + z_i`，上限是 `s_i + z_i * 10**6`。
3. 若 `s1 + z1 > s2 + z2 * 10**6` 或 `s2 + z2 > s1 + z1 * 10**6`，两个区间不相交，返回 -1。
4. 否则答案是 `max(s1 + z1, s2 + z2)`：小的一侧把差额摊到自己的 0 上，每个 0 最多加 `10**6 - 1`，区间相交保证摊得下。

以示例 1 为例：`s1 = 6, z1 = 2`，下限 `8`；`s2 = 11, z2 = 1`，下限 `12`。`max(8, 12) = 12`，nums1 的两个 0 分别填 2 和 4，正好补上 4 的差额。

```python
s1, s2 = sum(nums1), sum(nums2)
z1, z2 = nums1.count(0), nums2.count(0)
lo1, lo2 = s1 + z1, s2 + z2
hi1, hi2 = s1 + z1 * 10**6, s2 + z2 * 10**6
if lo1 > hi2 or lo2 > hi1:
    return -1
return max(lo1, lo2)
```

## 复杂度
时间：O(n + m)，两次 `sum` 加两次 `count` 各扫一遍。
空间：O(1)，只开了 `s1/s2/z1/z2/lo/hi` 六个标量。

## 易错点
- 把 0 当成「可以填 0」→ 示例 1 会算出 `max(6, 11) = 11`，但 nums1 下限是 8、nums2 下限是 12，11 根本达不到 → 记住每个 0 至少贡献 1，下限必须带 `+ z`。
- 只判断「一侧下限 > 另一侧下限」就返回 -1 → 示例 2 中 `lo1 = 6, lo2 = 5`，看似能追平，但 nums2 没有 0（`z2 = 0`），`hi2 = 5 < lo1 = 6`，永远追不上 → 必须用上限 `hi` 判相交，不能只看下限。

## 如果面试官追问
要求输出具体替换方案怎么办？答：把 `max(lo1, lo2)` 与两侧下限的差额 `d` 依次摊给该侧的每个 0（每个最多加 `10**6 - 1`），边摊边填即可。
