## 一句话思路
按子序列长度奇偶分两态做 DP，状态键是交错和，值是可取到的乘积集合，用集合去重剪枝。

## 怎么做
1. 定义 `even[s]` = 长度为偶数（下一个元素进偶数位，加）时交错和为 s 的所有乘积，`odd[s]` 同理（下一个元素进奇数位，减）。
2. 初始 `even[0] = {1}`，表示空序列；遍历每个 `x`，从旧状态推出新状态，避免同一元素用两次。
3. 转移：从 `even[s]` 取 p，加入 x 后变奇数位，新和 `s - x`，乘积 `p * x`；从 `odd[s]` 取 p，新和 `s + x`，乘积 `p * x`。
4. 乘积超过 `limit` 直接丢弃（x ≥ 0，乘只会变大），最后在 `even[k] ∪ odd[k]` 里取最大值，空则 -1。

以示例 1 `nums=[1,2,3], k=2, limit=10` 为例：处理完 1、2 后 `odd[1-2=-1]` 含 2；再处理 3，从 `odd[-1]` 得 `even[2]` 含 6，同时 `even[2]` 本身含 2（子序列 [2]），取 max 得 6。

```python
even, odd = {0: {1}}, {}
for x in nums:
    ne = {s: set(v) for s, v in even.items()}
    no = {s: set(v) for s, v in odd.items()}
    for s, ps in even.items():
        for p in ps:
            if p * x <= limit:
                no.setdefault(s - x, set()).add(p * x)
    for s, ps in odd.items():
        for p in ps:
            if p * x <= limit:
                ne.setdefault(s + x, set()).add(p * x)
    even, odd = ne, no
ans = even.get(k, set()) | odd.get(k, set())
return max(ans) if ans else -1
```

## 复杂度
时间 O(n · S · P)，S 为交错和取值数（受 k 与元素和约束），P 为每个和下的乘积集合大小。
空间 O(S · P)，存两套哈希表，乘积集合是主要开销。

## 易错点
- 输入含 0 时，`p * x = 0` 不会超 limit，会把 0 塞进集合；若误判「乘积为 0 无意义」而跳过，示例 3 类数据会漏掉合法解，正确做法是照常保留 0。
- 原地更新 `even`/`odd` 会让同一个 x 被重复使用（如 `[2,2]` 被算成用两次同一个 2），必须先复制出 `ne`/`no` 再写回。

## 如果面试官追问
若 nums 含负数怎么办？答：乘积可能由负变正，需同时维护最大最小乘积，且不能再用「超 limit 就丢」的剪枝。
