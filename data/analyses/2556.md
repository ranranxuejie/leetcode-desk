## 一句话思路
先找一条从 (0,0) 到 (m-1,n-1) 的路径，再删掉路径上除两端外的每个格子各试一次，看是否还有路。

## 怎么做
1. 用 DFS 找一条可行路径 `path`，只记录路径上的格子。
2. 若 `path` 长度 ≤ 2（只有起点终点），直接返回 `True`，因为删掉任意中间格都不影响，但此时路径本身只有两端，说明没有中间格可删——实际应返回 `False`；正确判断是：路径上中间格数量为 0 时无法切断，返回 `False`。
3. 对 `path` 中每个非端点格子 `(r,c)`，临时把 `grid[r][c]` 置 0，再跑一次 DFS 判断连通性，若不通返回 `True`，否则恢复。
4. 全部试完仍连通，返回 `False`。

以示例 1 `grid = [[1,1,1],[1,0,0],[1,1,1]]` 为例：第一次 DFS 找到路径 `(0,0)→(0,1)→(0,2)→(1,2)→(2,2)`，中间格为 `(0,1),(0,2),(1,2)`。试删 `(0,1)` 后，从 `(0,0)` 只能走 `(1,0)`，而 `(1,0)` 下方 `(2,0)` 可到 `(2,1)`、`(2,2)`，仍连通；试删 `(0,2)` 后，`(0,1)` 无法向下（`(1,1)=0`），路径断，返回 `True`。

```python
def dfs(r, c, seen):
    if r == m - 1 and c == n - 1:
        return True
    seen.add((r, c))
    for dr, dc in ((1, 0), (0, 1)):
        nr, nc = r + dr, c + dc
        if nr < m and nc < n and grid[nr][nc] == 1 and (nr, nc) not in seen:
            if dfs(nr, nc, seen):
                return True
    return False
```

关键点：只需检查一条路径上的格子。若存在多条路径，删掉某条路径上的格子后其他路径仍连通，说明该格不是割点；若删掉后不连通，则找到答案。

## 复杂度
时间：O(m·n·L)，L 为路径长度，最坏 O((m·n)^2)，每次 DFS 遍历全图。
空间：O(m·n)，`seen` 集合与递归栈。

## 易错点
- 输入 `grid = [[1,1],[1,1]]`：路径中间格只有 `(0,1)` 和 `(1,0)`，删任一后仍有另一条路，应返回 `False`。若只检查第一条路径就下结论会错，必须逐个试删。
- 输入 `grid = [[1]]`：起点即终点，路径长度 1，无中间格可删，应返回 `False`。若误判为 `True` 会错，需特判 `m==1 and n==1`。

## 如果面试官追问
问：能否 O(m·n) 解决？答：可以，用两次 DP 判断每个格子是否在「所有路径」的必经点上，即从起点可达且能到终点的格子中，若存在割点则返回 `True`。
