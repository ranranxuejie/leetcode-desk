## 一句话思路
用哈希表统计每个值出现次数，每 `cnt // 2` 贡献数对，`cnt % 2` 贡献剩余。

## 怎么做
1. 遍历 `nums`，用 `Counter` 或字典累加每个值的出现次数。
2. 对每个计数 `c`，数对累加 `c // 2`，剩余累加 `c % 2`。
3. 返回 `[pairs, remain]`。

以 `nums = [1,3,2,1,3,2,2]` 为例，计数为 `{1:2, 3:2, 2:3}`：`1` 贡献 1 对 0 剩，`3` 贡献 1 对 0 剩，`2` 贡献 `3//2=1` 对、`3%2=1` 剩，合计 `[3,1]`。

```python
from collections import Counter

cnt = Counter(nums)
pairs = remain = 0
for c in cnt.values():
    pairs += c // 2
    remain += c % 2
return [pairs, remain]
```

关键点：数对总数与配对顺序无关，只取决于每个值的奇偶，所以不必真的模拟删除。

## 复杂度
时间 O(n)：遍历 `nums` 建表一次，再遍历不同值，n 是数组长度。
空间 O(k)：k 是不同值的个数，最坏 k = n，额外开了计数表。

## 易错点
- 输入 `nums = [0]` → 若只算 `pairs` 忘了 `remain`，会返回 `[0,0]` 或漏掉余数 → 正确是每个 `c % 2` 都要累加，得 `[0,1]`。
- 输入 `nums = [2,2,2]` → 若用「遇到相同就配对并跳过」的写法容易把三个 2 配成 1 对后剩 1 个却算错剩余 → 正确用 `c//2` 和 `c%2` 一次算清，得 `[1,1]`。

## 如果面试官追问
问：若 `nums` 长度到 10^7 且值域很大怎么办？
答：仍用哈希计数，O(n) 时间；值域大只是 k 变大，空间 O(k)，不要开值域大小的数组。
