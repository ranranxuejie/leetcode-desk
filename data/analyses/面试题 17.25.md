## 一句话思路
按长度分组枚举「行数×列数」，用字典树剪枝逐行回溯，行拼出的每列前缀必须是某单词的前缀。

## 怎么做
1. 把 words 全部塞进字典树 `trie`，同时按长度建 `by_len[L]`，记录最大面积 `best`。
2. 枚举矩形尺寸：行数 `h` 取某个单词长度，列数 `w` 取某个单词长度，`h*w <= best` 直接跳过。
3. 回溯逐行选词：第 `i` 行选词后，把每列已拼出的前缀 `cols[j]` 追加该词第 `j` 个字符，任一列前缀不在 trie 中就剪枝。
4. 选满 `h` 行且每列 `cols[j]` 本身是完整单词，更新 `best` 并保存结果。

以示例 1 为例，`h=3, w=4`：第 0 行选 `"this"`，`cols = ["t","h","i","s"]` 都是 trie 前缀；第 1 行选 `"real"` 后 `cols = ["tr","he","ia","sl"]`，四者都在 trie 中（`trh/hea/iar/sld` 的前缀）；第 2 行选 `"hard"` 得 `["trh","hea","iar","sld"]`，四列都是完整单词，面积 12。

```python
def dfs(i):
    if i == h:
        if all(c in wordset for c in cols):
            best = max(best, h * w); ans = rows[:]
        return
    for word in by_len[w]:
        nxt = [cols[j] + word[j] for j in range(w)]
        if all(trie.has_prefix(p) for p in nxt):
            cols[:] = nxt; rows.append(word); dfs(i + 1); rows.pop()
```

## 复杂度
时间：O(尺寸对数 × 每层候选词数^h × w)，trie 前缀检查把候选词砍到极少。
空间：trie 节点数 O(总字符数)，外加 `cols` 的 O(w·h) 字符。

## 易错点
- 输入 `["aa"]`：只按「行数=列数=单词长度」枚举会漏掉 `h=2,w=2` 的 `["aa","aa"]`，因为单词可重复使用；正确做法是行数、列数各自独立从 `by_len` 的键里取，允许 `h != w` 且同一单词多次入选。
- 示例 1 若只检查「列前缀是某单词前缀」而不在 `i==h` 时校验 `cols[j] in wordset`，会把 `["this","real"]` 这类列 `"tr","he"` 非完整单词的残局当成解；正确做法是收尾时对每列做完整单词判定。

## 如果面试官追问
问：单词数涨到 10^5 怎么办？答：先按长度频次剪掉不可能参与最大面积的尺寸，再对每列前缀做计数预筛，只保留能凑满 `h` 行的候选词。
