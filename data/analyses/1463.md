## 一句话思路
按行做 DP，状态是两机器人当前列 `(c1, c2)`，每行枚举 3×3 种移动组合取最大。

## 怎么做
1. 状态 `dp[c1][c2]` 表示处理完当前行、机器人 1 在列 `c1`、机器人 2 在列 `c2` 时的最大樱桃数，初始 `dp[0][cols-1] = grid[0][0] + grid[0][cols-1]`（若 `cols-1 == 0` 只算一次）。
2. 逐行转移：对每个 `(c1, c2)`，枚举 `nc1 in (c1-1, c1, c1+1)`、`nc2 in (c2-1, c2, c2+1)`，越界跳过。
3. 新收益 = `grid[r][nc1] + (grid[r][nc2] if nc2 != nc1 else 0)`，即同格只摘一次。
4. 取所有前驱的最大值写入 `ndp[nc1][nc2]`，最后返回 `max(dp[c1][c2])`。

用示例 1 的 `grid = [[3,1,1],[2,5,1],[1,5,5],[2,1,1]]`，`cols=3`：第 0 行 `dp[0][2] = 3+1 = 4`；处理第 1 行时，`(c1,c2)=(0,2)` 可转移到 `(1,1)`，收益 `grid[1][1]=5`，得 `dp[1][1] = 4+5 = 9`——两机器人同格只加一次 5。

```python
cols = len(grid[0])
NEG = -1
dp = [[NEG] * cols for _ in range(cols)]
dp[0][cols - 1] = grid[0][0] + (grid[0][cols - 1] if cols > 1 else 0)
for r in range(1, len(grid)):
    ndp = [[NEG] * cols for _ in range(cols)]
    for c1 in range(cols):
        for c2 in range(cols):
            if dp[c1][c2] < 0:
                continue
            for nc1 in (c1 - 1, c1, c1 + 1):
                for nc2 in (c2 - 1, c2, c2 + 1):
                    if 0 <= nc1 < cols and 0 <= nc2 < cols:
                        gain = grid[r][nc1] + (grid[r][nc2] if nc1 != nc2 else 0)
                        ndp[nc1][nc2] = max(ndp[nc1][nc2], dp[c1][c2] + gain)
    dp = ndp
return max(max(row) for row in dp)
```

## 复杂度
时间：`O(rows * cols^2 * 9)`，`cols^2` 来自两机器人列组合，9 是常数。
空间：`O(cols^2)`，只开两层的 `dp`/`ndp` 二维表。

## 易错点
- 两机器人同格时重复加樱桃 → 示例 1 第 1 行 `(1,1)` 若加两次 5 会得 14 而非 9 → 必须用 `if nc1 != nc2` 判断只加一次。
- 初始行 `cols == 2` 时 `(0, cols-1)` 是不同格，但若写成无条件 `grid[0][0] + grid[0][cols-1]`，在 `cols==1` 会重复；本题 `cols >= 2` 安全，但仍要按 `cols > 1` 分支写，避免边界假设。

## 如果面试官追问
问：若要求输出两机器人具体路径怎么办？
答：在 `ndp` 里额外存前驱 `(c1, c2)`，最后从末行最大值回溯即可。
