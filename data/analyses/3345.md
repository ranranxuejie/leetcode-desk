## 一句话思路
从 n 开始逐个加一暴力枚举，因为 n ≤ 100 且答案离 n 很近，逐个验证数位乘积即可。

## 怎么做
1. 令 `x = n`，进入循环。
2. 对 `x` 求各数位之积 `p`：循环 `p *= x % 10; x //= 10`，注意 `x` 要先用临时变量保存。
3. 若 `p % t == 0` 就返回原值，否则 `n += 1` 继续。
4. 关键中间值：以 `n = 15, t = 3` 为例，先试 15，数位积 `1*5 = 5`，`5 % 3 = 2 ≠ 0`；再试 16，数位积 `1*6 = 6`，`6 % 3 = 0`，返回 16。

```python
def check(v, t):
    p = 1
    while v:
        p *= v % 10
        v //= 10
    return p % t == 0

x = n
while not check(x, t):
    x += 1
return x
```

注意 `p` 初值取 1 而不是 0，否则乘积恒为 0；同时 `v` 被除到 0 时循环结束，`n ≥ 1` 保证至少进一次循环。

## 复杂度
时间：O(k · log n)，k 为从 n 到答案的步数（本题极小），每步拆位 log n。
空间：O(1)，只用了 `p`、`x` 两个整型变量。

## 易错点
- 输入 `n = 10, t = 2` → 若把数位积初值写成 0，`0 % 2 == 0` 会误判所有数都合格，直接返回 10 看似对，但换成 `n = 11, t = 2` 就会错返回 11（实际 11 的积是 1，不满足）。正确做法是 `p = 1` 起乘，让 10 的积自然算成 `1*0 = 0`。
- 输入 `n = 100, t = 10` → 若拆位时直接改 `n` 本身（`while n: p *= n % 10; n //= 10`），外层 `n += 1` 会从 0 开始，死循环。正确做法是用临时变量 `v = x` 拆位，保留外层枚举变量。

## 如果面试官追问
问：若 n 放大到 10^9 还能暴力吗？
答：不能，需按数位 DP 或从高位贪心构造最小合法数，枚举候选数位组合而非逐个加一。
