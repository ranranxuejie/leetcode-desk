## 一句话思路
把每个 nums[i] 约去平方因子得到「平方核」，两数乘积为完全平方数当且仅当平方核相等，DFS 时用哈希表维护路径上各核的计数。

## 怎么做
1. 预处理 `core[x]`：对 x 做质因数分解，指数为奇数才乘进去，得到平方核（如 8→2，4→1，9→1）。
2. 建邻接表，从 0 号节点 DFS，参数带上父节点避免回头。
3. 进入节点 i 时，先查 `cnt[core[nums[i]]]` 累加到答案，再把该核计数 +1；离开时 -1，保证表里只有当前路径上的祖先。
4. 根节点 0 也要先入表再递归子节点，否则示例 1 中节点 1 查不到 nums[0]=2 的核。

以示例 1 为例：`nums=[2,8,2]`，核为 `[2,2,2]`。DFS 到节点 1 时表里 `{2:1}`，查到 1，答案变 1；再入表变 `{2:2}`，到节点 2 查到 2，答案变 3。

```python
def core(x):
    r, d = 1, 2
    while d * d <= x:
        e = 0
        while x % d == 0:
            x //= d; e ^= 1
        if e: r *= d
        d += 1
    return r * x

cnt = {}
def dfs(u, p):
    nonlocal ans
    c = core(nums[u])
    ans += cnt.get(c, 0)
    cnt[c] = cnt.get(c, 0) + 1
    for v in adj[u]:
        if v != p: dfs(v, u)
    cnt[c] -= 1
```

## 复杂度
时间：O(n·√max(nums))，每个节点分解一次，DFS 每边两次。
空间：O(n) 邻接表 + O(n) 哈希表 + O(n) 递归栈。

## 易错点
- 忘记把根节点 0 先入表：示例 1 中节点 1 的祖先只有 0，若先递归子节点再入表，`cnt` 为空，答案错成 0 而非 3。
- 回溯时漏减或减错核：示例 1 中节点 2 处理完若不把 `cnt[2]` 从 2 减回 1，兄弟分支会多算；正确做法是进入 +1、退出 -1，且减的是同一个 `c`。

## 如果面试官追问
若 nums[i] 上限提到 10^9 怎么办？答：改用线性筛预处理到 √max 的质数表，分解时只试质数，单次 O(√x/log x)。
