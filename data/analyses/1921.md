## 一句话思路
算出每个怪物的到达时间 `ceil(dist[i]/speed[i])`，排序后逐个检查第 i 个能否在时刻 i 之前被消灭。

## 怎么做
1. 对每个 i 算 `t[i] = (dist[i] + speed[i] - 1) // speed[i]`，即怪物 i 到达城市的分钟数。
2. 把 `t` 升序排序，先打最急的。
3. 从 i = 0 开始遍历，第 i 个怪物必须在第 i 分钟开始时被消灭（武器第 0 分钟就绪，之后每分钟一发）。
4. 若 `t[i] <= i`，说明这个怪物在第 i 分钟或更早到达，游戏已结束，返回 i；否则继续，全部通过返回 n。

以示例 2 `dist=[1,1,2,3], speed=[1,1,1,1]` 为例：`t=[1,1,2,3]`，排序后仍是 `[1,1,2,3]`。i=0 时 `t[0]=1 > 0` 可以打；i=1 时 `t[1]=1 <= 1`，说明第二个怪物在第 1 分钟开始时已到城，返回 1。注意 `t[i] <= i` 用的是 `<=` 而非 `<`，因为恰好整分钟到达也算输。

```python
t = sorted((d + s - 1) // s for d, s in zip(dist, speed))
killed = 0
for i, arrive in enumerate(t):
    if arrive <= i:
        return i
    killed += 1
return killed
```

## 复杂度
时间：O(n log n)，排序主导，算 `t` 是 O(n)。
空间：O(n)，存了长度为 n 的到达时间数组 `t`。

## 易错点
- 用 `dist[i] // speed[i]` 向下取整 → 示例 1 中 `dist=[1,3,4]` 会算成 `[1,3,4]` 看似没事，但 `dist=3, speed=2` 会得 1 而实际是 2，导致提前判负。正确做法是向上取整 `(d + s - 1) // s`。
- 判断条件写成 `arrive < i` → 示例 2 中 `t[1]=1`、`i=1`，`1 < 1` 为假会继续打，错答 2。正确做法是 `arrive <= i`，因为恰好整分钟到达也算输。

## 如果面试官追问
问：若武器冷却不是 1 分钟而是 c 分钟，怎么改？
答：第 i 个怪物的可用时刻变成 `i * c`，判断改为 `t[i] <= i * c`，排序逻辑不变。
