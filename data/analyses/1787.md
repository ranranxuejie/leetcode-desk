## 一句话思路
按 `i mod k` 分组，每组内取值必须全相同，且每组异或和整体为 0，逐组用哈希表取众数、再 DP 修正总异或。

## 怎么做
1. 关键观察：相邻两个长度 k 区间异或为 0 等价于 `nums[i] == nums[i+k]`，所以下标同余 k 的位置必须取同一个值。
2. 于是把 `nums` 切成 k 条链（第 r 条是 `nums[r], nums[r+k], ...`），每条链独立选一个值，代价 = 链长 − 该值在链中出现次数。
3. 但还要满足所有链所选值的异或为 0，用 DP：`dp[x]` = 前若干条链选完、异或为 x 的最小代价。
4. 每条链转移时，对每个 x 取 `min(dp[x] ^ v + cost(v))`，其中 v 遍历该链出现过的值（众数优先）。

以示例 2 `nums=[3,4,5,2,1,7,3,4,7], k=3` 为例：三条链分别是 `[3,2,3]`、`[4,1,4]`、`[5,7,7]`。第 1 条链众数 3 出现 2 次，代价 1；第 2 条链众数 4 代价 1；第 3 条链众数 7 代价 1。三条链众数异或 `3^4^7 = 0`，总代价 3，正好是答案。

```python
from collections import Counter
# 每条链: (长度, Counter)
chains = []
for r in range(k):
    c = Counter(nums[r::k])
    chains.append((len(nums[r::k]), c))

INF = 10**9
dp = {0: 0}
for length, cnt in chains:
    ndp = {}
    for x, base in dp.items():
        for v, f in cnt.items():
            cost = base + length - f
            y = x ^ v
            if cost < ndp.get(y, INF):
                ndp[y] = cost
    dp = ndp
ans = dp.get(0, INF)
```

## 复杂度
时间：O(n + k·S)，S 是 DP 状态数（异或值域），每条链枚举其不同值。
空间：O(S + n)，Counter 存全部元素，dp 存异或状态。

## 易错点
- 只按「每条链取众数」贪心 → 示例 3 三条链众数都是 1，异或 `1^1^1=1≠0`，会错答 0；必须 DP 允许某条链改选次众数来把总异或拉回 0。
- 链长不整除时（如 `n=5,k=3`，第 2 条链只有 2 个元素）→ 若按 `n//k` 统一算长度会多算代价；正确做法是用 `len(nums[r::k])` 逐链取真实长度。

## 如果面试官追问
问：要求输出具体修改方案怎么办？
答：DP 时额外记录每条链选了哪个值，回溯 `dp` 的转移来源即可还原每个位置的新值。
