## 一句话思路
用「至多 k 个辅音」的计数减去「至多 k-1 个辅音」的计数，把恰好等于 k 转成两个单调窗口。

## 怎么做
1. 写辅助函数 `at_most(limit)`：返回辅音数 ≤ limit 且含全部 5 个元音的子串数。
2. 右指针 `r` 逐个吃字符，维护 `cnt`（元音计数数组）和 `cons`（窗口内辅音数）。
3. 当 `cons > limit` 时左指针 `l` 右移收缩，直到 `cons <= limit`；此时以 `r` 结尾的合法左端点有 `l` 个（0..l-1），累加 `l`。
4. 答案 = `at_most(k) - at_most(k-1)`。

以 `word = "ieaouqqieaouqq", k = 1` 为例：`at_most(1)` 在 `r=5`（字符 `q`）时窗口 `[0..5]` 首次凑齐 5 个元音且 `cons=1`，`l=0`，累加 0；`r=6` 再进一个 `q` 使 `cons=2>1`，`l` 移到 1，累加 1……最终 `at_most(1)=4`，`at_most(0)=1`，差为 3，与示例一致。

```python
def at_most(limit):
    cnt = [0] * 5
    kinds = cons = l = res = 0
    for r, ch in enumerate(word):
        if ch in "aeiou":
            i = "aeiou".index(ch)
            if cnt[i] == 0:
                kinds += 1
            cnt[i] += 1
        else:
            cons += 1
        while cons > limit:
            c = word[l]
            if c in "aeiou":
                i = "aeiou".index(c)
                cnt[i] -= 1
                if cnt[i] == 0:
                    kinds -= 1
            else:
                cons -= 1
            l += 1
        if kinds == 5:
            res += l
    return res
return at_most(k) - at_most(k - 1)
```

## 复杂度
时间 O(n)：`at_most` 被调两次，每个字符进出窗口各一次，n = len(word)。
空间 O(1)：只开长度 5 的 `cnt` 和几个标量。

## 易错点
- `k = 0` 时直接调 `at_most(-1)`：`cons > -1` 恒成立，`l` 会一路推到 `r+1`，`res` 恒为 0，结果变成 `at_most(0) - 0`，恰好正确；但若把 `limit` 写成无符号或提前 `return 0`，就会漏掉 `"aeiou"` 这类全元音串，示例 2 会输出 0 而非 1。
- 累加 `res += l` 前忘了判 `kinds == 5`：`"aeioqq"` 在 `r=4` 时 `kinds=5` 但 `cons=0`，`l=0` 累加 0 无害；换成 `"qqaeiou"` 且 `k=1`，`r=6` 时 `l=2`，若漏判会把 `"qqaeio"` 这类缺元音的前缀算进去，答案偏大。

## 如果面试官追问
若 n 放大到 10^5 且要求输出所有方案？答：仍用双窗口，但改为记录每个 `r` 对应的左端点区间 `[l_min, l_max]`，枚举时按区间展开，输出本身可能 O(n²)，需说明按需生成。
