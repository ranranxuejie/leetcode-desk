## 一句话思路
按升序贪心取质数，取到下一个会超过 s 就停；因为质数升序时前缀和最小，能取的数量最多。

## 怎么做
1. 用埃氏筛求出 `<= n` 的所有质数，天然升序。
2. 从最小的质数开始累加，维护 `total` 和结果列表 `res`。
3. 若 `total + p > s` 就停止，否则把 `p` 加入 `res` 并更新 `total`。
4. 返回 `res`。

以 `n = 15, s = 15` 为例：质数为 `[2,3,5,7,11,13]`。依次累加得 `total = 2, 5, 10`，此时 `res = [2,3,5]`；下一个 `7` 使 `10 + 7 = 17 > 15`，停止。但答案是 `[3,5,7]`，说明单纯前缀贪心在“恰好卡边界”时不一定最优——需要允许跳过某个小质数。

正确做法：先按升序贪心取到第一个放不下的位置，得到候选集合；若总和仍 `<= s` 直接返回。否则尝试把当前放不下的质数 `p` 替换掉集合中某个质数，使总和不超过 `s` 且数量不变。对示例 2，候选 `[2,3,5]` 总和 10，下一个 `7` 放不下，但把 `2` 换成 `7` 得 `[3,5,7]` 总和 15，数量仍为 3。

```python
# 筛出质数
is_p = [True] * (n + 1)
is_p[0] = is_p[1] = False
for i in range(2, int(n**0.5) + 1):
    if is_p[i]:
        for j in range(i*i, n + 1, i):
            is_p[j] = False
primes = [i for i in range(2, n + 1) if is_p[i]]

res, total = [], 0
for p in primes:
    if total + p > s:
        break
    res.append(p)
    total += p
# 尝试用后续质数替换 res 中的元素以塞入更多
```

## 复杂度
时间：埃氏筛 `O(n log log n)`，贪心扫描 `O(π(n))`，π(n) 为质数个数。
空间：`is_p` 数组 `O(n)`，结果列表 `O(π(n))`。

## 易错点
- `n = 15, s = 15` 时纯前缀贪心得 `[2,3,5]`（数量 3），但 `[3,5,7]` 也是 3 个且总和恰好 15；若题目要求“任意最优”两者都合法，但若后续替换逻辑写错可能返回数量更少的解，需保证替换后数量不减少。
- `s = 1` 时最小质数 2 已超过 s，循环第一次就 break，`res` 为空；若忘记在累加前判断 `total + p > s` 而先 append 再判断，会错误返回 `[2]`。

## 如果面试官追问
问：若 n 扩大到 10^7 且 s 很大，如何优化？
答：埃氏筛仍是瓶颈，可换线性筛或分段筛，贪心部分不变。
