## 一句话思路
枚举 x 方向异或值 dx（0..k），用哈希表存已扫过的点，查 `(x^dx, y^(k-dx))` 的计数。

## 怎么做
1. 建 `cnt` 字典，键为 `(x, y)`，值为出现次数；答案 `ans = 0`。
2. 对每个点 `(x, y)`，枚举 `dx` 从 0 到 k，令 `dy = k - dx`。
3. 在 `cnt` 里查 `(x ^ dx, y ^ dy)`，把次数累加进 `ans`。
4. 查完再把当前点计入 `cnt`，保证只统计 `i < j`。

以示例 1 的 `coordinates = [[1,2],[4,2],[1,3],[5,2]], k = 5` 为例：处理到 `(5,2)` 时，`dx = 4, dy = 1` 命中 `(5^4, 2^1) = (1,3)`，`cnt` 里它已存在，`ans` 加 1；`dx = 0, dy = 5` 命中 `(5,2)` 自身但尚未入表，不计。最终 `ans = 2`。

```python
cnt = {}
ans = 0
for x, y in coordinates:
    for dx in range(k + 1):
        ans += cnt.get((x ^ dx, y ^ (k - dx)), 0)
    cnt[(x, y)] = cnt.get((x, y), 0) + 1
return ans
```

关键点：`dx` 只需枚举到 `k`，因为异或值非负，`dx > k` 时 `dy` 必为负，不可能凑出距离 `k`。

## 复杂度
时间：`O(n * k)`，n 为点数，k ≤ 100，每点枚举 k+1 个 dx。
空间：`O(n)`，哈希表最多存 n 个不同坐标。

## 易错点
- 输入 `[[1,3]]*5, k = 0` → 若先入表再查询，会把点对自身算进去，得到 15 而非 10 → 必须先查后入表，且 `dx = 0, dy = 0` 时查的是同坐标的其他点，正确。
- 输入 `k = 100` 且坐标全为 0 → 若 `dx` 枚举到 `2**20` 之类的大范围，会超时 → 只需枚举 `0..k`，因为 `dx + dy = k` 且两者非负，`dx > k` 时 `dy < 0` 无解。

## 如果面试官追问
若 k 扩大到 10^6 怎么办？答：枚举 dx 到 k 会退化，改用按位分治或对每个点枚举 x 异或值的二进制位组合，复杂度降到 `O(n * log(maxX))`。
