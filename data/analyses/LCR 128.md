## 一句话思路
在旋转且含重复的升序数组上二分：用 `stock[mid]` 与 `stock[hi]` 比较缩区间，相等时 `hi -= 1` 去重。

## 怎么做
1. 令 `lo, hi = 0, len(stock) - 1`，答案始终落在闭区间 `[lo, hi]` 内。
2. 当 `stock[mid] > stock[hi]` 时，最小值必在 `mid` 右侧，令 `lo = mid + 1`。
3. 当 `stock[mid] < stock[hi]` 时，`mid` 到 `hi` 单调不降，最小值在 `mid` 左侧（含 `mid`），令 `hi = mid`。
4. 当 `stock[mid] == stock[hi]` 时，无法判断，只能令 `hi -= 1` 缩小范围。

以 `stock = [4,5,8,3,4]` 为例：`lo=0, hi=4, mid=2`，`stock[2]=8 > stock[4]=4`，故 `lo=3`；此时 `mid=3`，`stock[3]=3 < stock[4]=4`，令 `hi=3`；`lo==hi` 退出，返回 `stock[3]=3`。

```python
lo, hi = 0, len(stock) - 1
while lo < hi:
    mid = (lo + hi) // 2
    if stock[mid] > stock[hi]:
        lo = mid + 1
    elif stock[mid] < stock[hi]:
        hi = mid
    else:
        hi -= 1
return stock[lo]
```

关键点：`hi = mid` 而不是 `mid - 1`，因为 `mid` 本身可能就是最小值；`lo = mid + 1` 则可以安全跳过，因为 `stock[mid] > stock[hi]` 已排除 `mid`。

## 复杂度
时间：平均 O(log n)，最坏 O(n)，由 `hi -= 1` 逐个剔除重复元素贡献。
空间：O(1)，只用了 `lo`、`hi`、`mid` 三个变量。

## 易错点
1. 输入 `[2,2,2,0,2]` → 若在 `stock[mid] == stock[hi]` 时直接 `return stock[hi]` 或 `hi = mid`，会错成 2 → 正确做法是 `hi -= 1` 逐步收缩，让 `lo` 最终落到下标 3 的 0 上。
2. 输入 `[1,1]` 或 `[3,3,1,3]` → 若把 `stock[mid] < stock[hi]` 的分支写成 `hi = mid - 1`，会跳过真正的最小值 → 必须写 `hi = mid`，保证 `mid` 不被排除。

## 如果面试官追问
问：若数组不含重复元素，能否更快？答：可以去掉 `==` 分支，严格 O(log n)，`stock[mid] > stock[hi]` 与 `<` 已覆盖全部情况。
