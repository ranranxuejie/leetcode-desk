## 一句话思路
统计每个字符出现次数，偶数次全用，奇数次各减一用，最后若存在奇数则中心加 1。

## 怎么做
1. 用 `Counter(s)` 得到每个字符的频次。
2. 遍历频次，把每个 `cnt // 2 * 2` 累加进 `length`，同时记录是否存在奇数频次。
3. 若出现过奇数频次，`length += 1` 作为回文中心。

以 `s = "abccccdd"` 为例：频次为 `{'c':4,'d':2,'a':1,'b':1}`。`c` 贡献 4，`d` 贡献 2，`a`、`b` 各贡献 0 但标记了奇数存在，此时 `length = 6`，最后 `+1` 得 7。

```python
from collections import Counter

def longestPalindrome(s):
    length = 0
    has_odd = False
    for cnt in Counter(s).values():
        length += cnt // 2 * 2
        if cnt % 2 == 1:
            has_odd = True
    return length + 1 if has_odd else length
```

关键点：奇数频次字符不能全丢，减一后仍可成对使用；且全局最多只有一个字符能放在中心。

## 复杂度
时间：O(n)，n 为 `len(s)`，遍历字符串计数加遍历至多 52 个键。
空间：O(1)，哈希表最多存 52 个大小写字母键。

## 易错点
- 输入 `s = "a"` → 若只累加 `cnt // 2 * 2` 得 0，忘记加中心 → 正确做法是标记 `has_odd` 后 `+1`，返回 1。
- 输入 `s = "Aa"` → 若把大小写合并计数会误判为可成对 → 正确做法是 `Counter` 区分大小写，`'A'` 和 `'a'` 是两个键，各计 1，结果应为 1 而非 2。

## 如果面试官追问
问：若要求输出具体回文串而非长度？
答：按频次先构造左右两半，奇数频次字符取一个放中间，拼接 `left + mid + left[::-1]` 即可。
