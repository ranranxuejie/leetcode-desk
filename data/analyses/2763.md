## 一句话思路
固定左端点 `i`，向右扩展 `j` 时用哈希集合增量维护不平衡数，O(n²) 枚举全部子数组。

## 怎么做
1. 外层枚举左端点 `i`，内层 `j` 从 `i` 向右扫，集合 `seen` 只装 `nums[i..j]` 的去重值。
2. 新元素 `x = nums[j]` 加入时，先看 `x-1`、`x+1` 是否已在 `seen` 中，据此增减计数 `cur`。
3. 每步把 `cur` 累加进答案；`j == i` 时 `cur` 恒为 0，不用特殊处理。

关键增量规则：`x` 插入有序序列，只影响它与左右邻居之间的「间隙」。设 `has_prev = x-1 in seen`，`has_next = x+1 in seen`：
- 两者都在：`x` 填平了原来 `x-1` 与 `x+1` 之间那个 >1 的间隙，`cur -= 1`；
- 都不在：`x` 自己制造一个新间隙，`cur += 1`；
- 只有一个在：间隙数不变。

以 `nums = [2,3,1,4]`，`i = 2`（值 1）为例：`j=2` 时 `seen={1}`，`cur=0`；`j=3` 加 4，`3 not in seen`、`5 not in seen`，`cur=1`，答案 +1。这正是子数组 `[1,4]` 贡献的那 1。

```python
ans = 0
n = len(nums)
for i in range(n):
    seen = {nums[i]}
    cur = 0
    for j in range(i + 1, n):
        x = nums[j]
        if x not in seen:
            cur += 1 - (x - 1 in seen) - (x + 1 in seen)
            seen.add(x)
        ans += cur
```

注意 `cur += 1 - (x-1 in seen) - (x+1 in seen)` 一行覆盖三种情况：`True` 当 1 用，两邻居都在时 `1-1-1 = -1`，都不在时 `1-0-0 = 1`，恰有一个在时 `1-1-0 = 0`。重复值 `x in seen` 直接跳过，因为重复元素不改变排序后的相邻差。

## 复杂度
时间 O(n²)：外层 `i` 与内层 `j` 各贡献一个 n，集合查询 O(1)。
空间 O(n)：`seen` 最多存 n 个不同值，无其他额外结构。

## 易错点
- `nums = [1,3,3,3,5]` 中重复的 3 → 若不加 `if x not in seen` 判断，每遇一个 3 都会重算邻居并改动 `cur`，把 `[3,3,5]` 算成 2 → 正确做法是重复值直接跳过，`seen` 天然去重。
- `nums = [1,2]` 这类连续值 → 若只写 `cur += 1` 而不减邻居，会得到 1，但排序后 `2-1=1` 不满足 `>1`，正确答案是 0 → 必须用 `1 - (x-1 in seen) - (x+1 in seen)` 的完整增量式。

## 如果面试官追问
若 n 放大到 1e5 怎么办？答：O(n²) 不可行，需按值域用线段树/树状数组维护「间隙数」，配合分治或离线统计每个间隙被多少子数组包含，思路从枚举端点转为枚举间隙。
