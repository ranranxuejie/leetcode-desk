## 一句话思路
用前序遍历序列化，利用 BST 中序有序的性质，反序列化时靠上下界递归定位每个节点。

## 怎么做
1. 前序遍历把节点值转成逗号分隔字符串，空树返回空串。
2. 反序列化时把字符串切成整数列表，用 `lo`/`hi` 两个边界递归建树。
3. 每次取列表当前值 `val`，若 `val` 不在 `(lo, hi)` 区间内则返回 `None`，否则消费该值并递归左右子树。
4. 左子树边界为 `(lo, val)`，右子树为 `(val, hi)`。

以 `root = [2,1,3]` 为例，序列化得 `"2,1,3"`。反序列化时 `lo=-inf, hi=inf`，取 `val=2` 合法，建根；左递归 `(lo=-inf, hi=2)` 取 `1` 合法；再左递归 `(lo=-inf, hi=1)` 时列表已空，返回 `None`；右递归 `(lo=2, hi=inf)` 取 `3` 合法。关键中间值：处理 `1` 时上界 `hi=2`，处理 `3` 时下界 `lo=2`。

```python
def build(vals, lo, hi):
    if not vals or not (lo < vals[0] < hi):
        return None
    val = vals.pop(0)
    node = TreeNode(val)
    node.left = build(vals, lo, val)
    node.right = build(vals, val, hi)
    return node
```

序列化部分：

```python
def dfs(node, out):
    if not node:
        return
    out.append(str(node.val))
    dfs(node.left, out)
    dfs(node.right, out)
```

## 复杂度
时间：序列化 O(n)，反序列化每个节点只被消费一次，O(n)。
空间：递归栈 O(h)，最坏链状树 O(n)，字符串额外 O(n)。

## 易错点
- 输入 `[1,None,2]` 这类只有右子树的链，若用「中序 + 前序」双序列重建，中序无法区分左右孩子位置，会错建成 `[1,2]` 的左链；正确做法是只用前序 + 上下界，靠 BST 有序性天然区分。
- 输入 `[2,1,3]` 反序列化时若忘记传 `lo`/`hi` 边界，仅按前序顺序建树，会把 `3` 错挂到 `1` 的右孩子；正确做法是左递归传 `hi=val`、右递归传 `lo=val`，让 `3` 在 `(2,inf)` 区间才被接受。

## 如果面试官追问
问：节点值有重复怎么办？答：BST 通常无重复，若有需约定重复放左或右，并在边界判断用 `<=`/`<` 区分，否则 `(lo,hi)` 严格区间会丢节点。
