## 一句话思路
按长度分组存字典，search 时只比对同长度的词，逐位统计不同字符数，恰好为 1 即命中。

## 怎么做
1. `buildDict` 里用 `self.d = {}`，键是 `len(word)`，值是同长度单词列表。
2. `search` 先取 `cand = self.d.get(len(searchWord), [])`，长度不匹配的直接排除。
3. 对每个候选词逐位比较，用 `diff` 计数，`diff > 1` 提前 break。
4. 任一候选 `diff == 1` 返回 `True`，全扫完返回 `False`。

以 `search("hhllo")` 为例：长度 5 命中 `["hello"]`，逐位比较 `h/h` 同、`h/e` 异（diff=1）、`l/l`、`l/l`、`o/o` 同，最终 `diff == 1`，返回 `True`。而 `search("hello")` 与 `"hello"` 逐位全同，`diff == 0`，不满足「必须换一个字母」，返回 `False`。

```python
def buildDict(self, dictionary):
    self.d = {}
    for w in dictionary:
        self.d.setdefault(len(w), []).append(w)

def search(self, searchWord):
    for w in self.d.get(len(searchWord), []):
        diff = 0
        for a, b in zip(searchWord, w):
            if a != b:
                diff += 1
                if diff > 1:
                    break
        if diff == 1:
            return True
    return False
```

## 复杂度
时间：buildDict 为 O(总字符数)；每次 search 最坏 O(同长度单词数 × 词长)，本题上限 100×100。
空间：O(总字符数)，即字典所有单词的字符总量，分组表本身不额外复制字符串。

## 易错点
- `search("hello")` 对字典里的 `"hello"`：若写成 `diff <= 1` 就返回 True，错成 true；题目要求「只将一个字母换成另一个字母」，必须 `diff == 1`，`diff == 0` 不算。
- `search("hell")` 长度 4，字典里只有长度 5 的 `"hello"`、`"leetcode"`：若不按长度分组、直接逐位 zip，`zip` 会静默截断成 4 位比较，可能误判；正确做法是先按 `len` 过滤候选，长度不等直接跳过。

## 如果面试官追问
若字典规模涨到 10^4、search 调用 10^4 次，怎么优化？答：改用字典树，search 时 DFS 带一个「已改一次」的标志位，沿树剪枝，避免全量比对。
