## 一句话思路
把 a 重复到长度 ≥ len(b)+len(a) 再判子串，答案只可能是 ⌈len(b)/len(a)⌉ 或再 +1。

## 怎么做
1. 先算 `k = (len(b) + len(a) - 1) // len(a)`，即让叠加串长度首次 ≥ len(b) 的次数。
2. 检查 `b in a * k`，命中就返回 k。
3. 否则检查 `b in a * (k + 1)`，命中返回 k+1，否则 -1。
4. 为什么只需试到 k+1：b 若出现，起点必落在前 len(a) 个字符内，终点不超过起点+len(b)，故 k+1 次足够覆盖。

以 a="abcd", b="cdabcdab" 为例：len(b)=8, len(a)=4，`k = (8+3)//4 = 2`，`a*2 = "abcdabcd"` 不含 b；`a*3 = "abcdabcdabcd"` 中 b 从下标 2 开始，返回 3。

```python
def repeatedStringMatch(a, b):
    k = (len(b) + len(a) - 1) // len(a)
    if b in a * k:
        return k
    if b in a * (k + 1):
        return k + 1
    return -1
```

关键中间值：k=2 时 `a*2` 长度 8 恰好等于 len(b)，但 b 需要跨越两次拼接的边界，所以必须再叠一次。

## 复杂度
时间 O(len(a)+len(b)) 量级，Python 的 `in` 用高效子串匹配，叠加串总长 ≤ len(b)+2·len(a)。
空间 O(len(a)+len(b))，`a*k` 和 `a*(k+1)` 各开一个临时串。

## 易错点
- a="a", b="aa"：只试 k=2 得 `"aa"` 命中返回 2 是对的，但若写成 `k = len(b)//len(a)` 得 2 也碰巧对；换成 a="ab", b="aba" 时 `len(b)//len(a)=1`，`"ab"` 不含 "aba" 就漏判，必须用向上取整 `(len(b)+len(a)-1)//len(a)`。
- a="abc", b="cabcabca"：k=3 时 `"abcabcabc"` 不含 b，但 k=4 的 `"abcabcabcabc"` 含 b（下标 2 起），返回 4；若只试到 k 就返回 -1 会错，k+1 这一档不能省。

## 如果面试官追问
问：b 长度到 10^7 还这么写吗？
答：思路不变，但别真拼串，用 KMP 在虚拟无限串 `a[i % len(a)]` 上匹配，空间降到 O(len(b))。
