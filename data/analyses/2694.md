## 一句话思路
用字典 `events` 把事件名映射到「回调列表」，`unsubscribe` 靠闭包记住自己在列表里的位置，从列表里删掉即可。

## 怎么做
1. 初始化 `self.events = {}`，键是事件名，值是回调函数列表，列表顺序天然就是订阅顺序。
2. `subscribe(name, cb)`：`self.events.setdefault(name, []).append(cb)`，然后返回一个带 `unsubscribe` 的对象。
3. `unsubscribe` 内部执行 `self.events[name].remove(cb)`——注意 `remove` 按值删，删的是这个闭包捕获的 `cb`，不是下标。
4. `emit(name, args=None)`：取 `self.events.get(name, [])`，对每个 `cb` 执行 `cb(*(args or []))`，把返回值按顺序收集成列表返回。

以示例 4 为例，关键中间值：订阅后 `events["firstEvent"] == [x=>x+1, x=>x+2]`；`sub1.unsubscribe()` 执行 `remove(x=>x+1)` 后列表变成 `[x=>x+2]`；再 `emit("firstEvent", [5])` 得到 `[7]`，而不是 `[6, 7]`。

```python
def subscribe(self, name, cb):
    self.events.setdefault(name, []).append(cb)
    def unsubscribe():
        self.events[name].remove(cb)
    return unsubscribe

def emit(self, name, args=None):
    args = args or []
    return [cb(*args) for cb in self.events.get(name, [])]
```

`emit` 里 `args or []` 处理的是「只传事件名」的情况，示例 1 第一次 `emit("firstEvent")` 就靠它返回 `[]`。

## 复杂度
时间：`subscribe`/`unsubscribe` 是 O(k)（k 为该事件回调数，`remove` 要线性找），`emit` 是 O(k·单次调用开销)。
空间：`events` 存所有回调，O(总订阅数)，无额外结构。

## 易错点
- `emit("firstEvent", [1,2,3])` 若写成 `cb(args)` 而不是 `cb(*args)`，回调收到的是整个列表 `[1,2,3]`，`args.join(',')` 会得到 `"1,2,3"` 之外的错误结果；必须解包。
- 示例 4 中若 `unsubscribe` 用下标 `pop(0)` 实现，删掉 `sub1` 后 `sub2` 的下标从 1 变 0，后续再取消 `sub2` 就会删错人；正确做法是按 `cb` 值 `remove`，与位置无关。

## 如果面试官追问
问：若同一回调被订阅两次，`remove` 会删哪个？
答：删列表里第一个相等的，所以要么保证回调不重复（题面已假设），要么改成存 `(id, cb)` 按 id 删。
