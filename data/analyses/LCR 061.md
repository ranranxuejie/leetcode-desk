## 一句话思路
用最小堆维护「每个 nums1[i] 只配 nums2[0]」的起点，每次弹出后把同一行的 j+1 推入，弹出 k 次即得前 k 小。

## 怎么做
1. 堆里只放 `(nums1[i]+nums2[0], i, 0)`，i 取 `min(len(nums1), k)` 个——第 k 名之后的行不可能进答案。
2. 弹出 `(s, i, j)` 记入结果，若 `j+1 < len(nums2)` 就推入 `(nums1[i]+nums2[j+1], i, j+1)`。
3. 循环直到结果满 k 个或堆空（示例 3 就是堆先空）。

以示例 1 为例：初始堆 `[(3,0,0),(9,1,0),(13,2,0)]`。第一次弹出 `(3,0,0)` 得 `[1,2]`，推入 `(5,0,1)`；此时堆顶变 `(5,0,1)`，第二次弹出得 `[1,4]`，推入 `(7,0,2)`；第三次弹出 `(7,0,2)` 得 `[1,6]`。注意 `(7,1,0)` 的和也是 7，但堆按元组比较，`(7,0,2) < (7,1,0)`，先出哪个都不影响正确性。

```python
import heapq
h = [(nums1[i] + nums2[0], i, 0) for i in range(min(len(nums1), k))]
heapq.heapify(h)
res = []
while h and len(res) < k:
    s, i, j = heapq.heappop(h)
    res.append([nums1[i], nums2[j]])
    if j + 1 < len(nums2):
        heapq.heappush(h, (nums1[i] + nums2[j + 1], i, j + 1))
```

关键点：堆里存的是**下标**不是值，因为示例 2 有重复的 `1`，靠值无法区分是哪一行、j 走到哪。

## 复杂度
时间 O(k log min(n1, k))：堆大小不超过 min(len(nums1), k)，弹推各 k 次。
空间 O(min(len(nums1), k))：堆 + 结果列表，结果本身占 k 个对。

## 易错点
- `nums1 = [1,2], nums2 = [3], k = 3`：若循环条件只写 `len(res) < k`，堆空后 `heappop` 抛 IndexError；必须写成 `while h and len(res) < k`，返回 2 个对而非 3 个。
- `nums1 = [1,1,2], nums2 = [1,2,3], k = 2`：若堆元素只存 `(和, 值对)` 而不带 `(i, j)`，两个 `(2, 1, 1)` 会被去重或无法定位下一列，输出只剩 1 个对；必须存 `(s, i, j)` 三元组，重复和靠 i 区分。

## 如果面试官追问
若 k 放大到 10^9 而两数组各 10^4，怎么办？答：改用二分第 k 小的和值 + 双指针计数，O((n1+n2) log 值域)，不再依赖 k。
