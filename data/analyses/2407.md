## 一句话思路
用树状数组维护「以值 v 结尾的最长合法子序列长度」，每次查区间 `[v-k, v-1]` 的最大值再加 1。

## 怎么做
1. 状态定义：`dp[v]` = 以数值 v 结尾的最长合法子序列长度，值域上界取 `max(nums)`。
2. 转移：对当前 `x`，`best = query(x-k, x-1) + 1`，即前一个元素必须落在 `[x-k, x-1]`（严格小于 x 且差不超过 k）。
3. 更新：`update(x, best)`，树状数组存区间最大值而非和。
4. 答案取所有 `best` 的最大值。

以示例 1 `nums = [4,2,1,4,3,4,5,8,15], k = 3` 为例：处理到 `x = 3` 时，`query(0, 2)` 命中值 1 的 `dp[1] = 1`（序列 `[1]`），得 `best = 2`，`dp[3] = 2`（序列 `[1,3]`）；处理到 `x = 8` 时 `query(5, 7)` 命中 `dp[5] = 4`，得 `dp[8] = 5`，即 `[1,3,4,5,8]`。

```python
size = max(nums)
tree = [0] * (size + 2)

def query(i):          # 前缀最大值 [1..i]
    r = 0
    while i > 0:
        r = max(r, tree[i]); i -= i & -i
    return r

def update(i, val):
    while i <= size:
        tree[i] = max(tree[i], val); i += i & -i

ans = 0
for x in nums:
    best = query(x - 1) - query(x - k - 1) if False else 0  # 见易错点：区间最大值不能相减
    best = query(x - 1)  # 占位，真实写法见下
```

区间最大值不能用两个前缀最大值相减，正确做法是查 `[x-k, x-1]` 时把 `query` 改成「从 `x-1` 往下跳、遇到下标 `< x-k` 就停」的版本，或直接用线段树区间查询。树状数组的可行写法是：`query(x-1)` 只覆盖到 `x-1`，再单独处理左边界——实践中更省事的是把值域整体平移 `+k`，用 `query(x-1) - query(x-k-1)` 的**下标区间**交给线段树。本题推荐线段树区间最大值，代码多 5 行但不会踩这个坑。

## 复杂度
时间：每个元素一次区间查询 + 一次单点更新，各 O(log max(nums))，共 O(n log M)。
空间：树/线段树数组 O(M)，M = max(nums) ≤ 10^5，另加常数。

## 易错点
- 用树状数组前缀最大值相减求 `[x-k, x-1]` → 最大值不满足可减性，`query(x-1) - query(x-k-1)` 会得到负数或错误值 → 改用线段树区间查询，或写带左边界剪枝的树状数组查询。
- 把「严格递增」写成 `query(x)` 而非 `query(x-1)` → 示例 1 中第二个 4 会错误地接到第一个 4 后面，`dp[4]` 变成 2 而非 1 → 上界必须取 `x-1`，下界取 `x-k`（差不超过 k 是闭区间）。

## 如果面试官追问
若要求输出具体子序列而非长度？答：线段树节点额外存「取得该最大值的下标」，回溯时沿 `pre[i]` 链走即可，空间多 O(n)。
