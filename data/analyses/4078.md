## 一句话思路
连续三项和恒等于 `F[k+4] - 1`（从 0,1 起编号），所以只需枚举斐波那契数并检查 `n+1` 是否为斐波那契数。

## 怎么做
1. 记 `F[0]=0, F[1]=1`，连续三项 `F[k]+F[k+1]+F[k+2]` 化简为 `F[k+4]-1`。
2. 于是问题变成：`n+1` 是否出现在斐波那契数列中。
3. 从 `a, b = 0, 1` 递推，直到 `b > n+1` 为止，中途命中即返回 `True`。

以 `n = 16` 为例，`n+1 = 17`。递推序列为 0,1,1,2,3,5,8,13,21，13 之后直接跳到 21，17 不在其中？——注意这里要看清：`F[k+4]-1 = 16` 要求 `F[k+4] = 17`，而 17 确实不是斐波那契数。但示例 1 说 3+5+8=16 成立。矛盾出在化简：`F[k]+F[k+1]+F[k+2] = F[k+2]+F[k+2] = 2F[k+2]`？不对，`F[k]+F[k+1]=F[k+2]`，故三项和 `= 2F[k+2]`。取 k=2：`2*F[4]=2*3=6`，也不对。正确化简：`F[k]+F[k+1]+F[k+2] = F[k+2]+F[k+2] = 2F[k+2]`，k=2 得 6；而 3+5+8 对应 k=4，`2*F[6]=2*8=16`。所以三项和 `= 2*F[k+2]`，即 `n` 必须是某个斐波那契数的两倍。

```python
a, b = 0, 1
while a <= n:
    if 2 * a == n:
        return True
    a, b = b, a + b
return False
```

对 `n = 16`：`a` 依次取 0,1,1,2,3,5,8,13，`2*8 = 16` 命中，返回 `True`。对 `n = 8`：`2*a` 取到 0,2,2,4,6,10,16，无 8，返回 `False`。

## 复杂度
时间：O(log n)，斐波那契数指数增长，循环约 log_φ n 次。
空间：O(1)，只开 `a, b` 两个变量。

## 易错点
- 把三项和当成 `F[k+4]-1` 去查 `n+1` → 对 `n=16` 会查 17 判 `False`，与示例矛盾；正确化简是 `2*F[k+2]`，查 `n` 是否为偶数且 `n//2` 是斐波那契数。
- 循环条件写成 `a < n` 而非 `a <= n` → 当 `n=2` 时 `a` 取到 1 就停，漏掉 `2*1=2`；应写 `while a <= n`，且 `n=2` 时 `a=1` 命中。

## 如果面试官追问
问：若要求返回具体是哪三项？
答：命中 `2*a == n` 时，`a = F[k+2]`，三项即 `F[k], F[k+1], F[k+2]`，回退两步即可输出。
