## 一句话思路
对每个节点，把子树的记录串按字典序排序后拼接，再在末尾补 `1` 回退，自底向上得到全局最小串。

## 怎么做
1. 由 `parents` 建邻接表 `children`，根是 `parents[i] == -1` 的那个 `i`。
2. 对节点 `u`，递归求出每个子节点 `v` 的串 `s[v]`，把 `s[v]` 按字典序升序排序。
3. 拼接：`"0" + s[v1] + "0" + s[v2] + ...`，每个子节点前加 `0` 表示下降，最后补一个 `1` 表示回退到 `u` 的父节点。
4. 根节点特殊：末尾不补 `1`（指针可停在任意节点），直接返回拼接结果。

以 `parents = [-1,0,0,2]` 为例：节点 3 无子节点，`s[3] = "1"`；节点 2 只有子节点 3，`s[2] = "0" + "1" + "1" = "011"`；节点 1 无子节点，`s[1] = "1"`；根节点 0 的子串排序后是 `["011", "1"]`，拼接得 `"0" + "011" + "0" + "1" = "00110"`，与示例一致。

```python
def dfs(u):
    subs = sorted(dfs(v) for v in children[u])
    res = "".join("0" + s for s in subs)
    return res + "1" if u != root else res
```

关键点：排序的是**子树的完整记录串**，不是子节点编号。因为 `0` 开头后接不同串，字典序比较的就是串本身。

## 复杂度
时间：O(n log n)，每个节点贡献一次排序，总比较代价 O(n log n)。
空间：O(n)，邻接表 + 递归栈 + 所有子串存储。

## 易错点
- 根节点末尾多补 `1`：`parents = [-1,0]` 会输出 `"011"` 而非 `"01"`，因为指针可停在节点 1，不需要回退。正确做法是根节点拼接后不追加 `1`。
- 按子节点编号排序而非按子树串排序：`parents = [-1,0,0,2]` 中节点 1 的串 `"1"` 和节点 2 的串 `"011"`，若按编号排会先放 `"1"` 得 `"01011"`，比正确答案 `"00110"` 大。必须按串的字典序排。

## 如果面试官追问
若 `n` 扩大到 `10^5` 且要求 O(n) 时间？答：用后缀数组或 trie 合并比较子树串，避免每层排序的 log 因子。
