## 一句话思路
用单调递减栈，每次弹出比当前 `arr[i]` 小的栈顶，代价取 `min(左邻, arr[i]) * 弹出值`，累加即最小。

## 怎么做
1. 栈初始放哨兵 `float('inf')`，保证任何元素都有左邻可比。
2. 遍历 `arr`，当 `arr[i] >= stack[-1]` 时，弹出栈顶 `mid`，代价 `min(stack[-1], arr[i]) * mid` 累加。
3. 弹出后继续比较，直到栈顶大于 `arr[i]`，再把 `arr[i]` 压栈。
4. 遍历结束后栈里剩递减序列，逐个弹出，代价 `stack[-2] * stack[-1]`（左邻乘弹出值）。

以 `arr = [6,2,4]` 为例：栈 `[inf]`，压 6 → `[inf,6]`；压 2 → `[inf,6,2]`；遇 4，弹出 2，代价 `min(6,4)*2 = 8`，栈变 `[inf,6]`，压 4 → `[inf,6,4]`。收尾弹出 4，代价 `6*4 = 24`，总和 `8+24 = 32`。

```python
stack = [float('inf')]
ans = 0
for x in arr:
    while stack[-1] <= x:
        mid = stack.pop()
        ans += min(stack[-1], x) * mid
    stack.append(x)
while len(stack) > 2:
    ans += stack[-2] * stack.pop()
return ans
```

## 复杂度
时间：O(n)，每个元素入栈出栈各一次。
空间：O(n)，栈最多存 n+1 个元素（含哨兵）。

## 易错点
1. 输入 `arr = [4,11]` → 若用 `stack[-1] < x` 而非 `<=`，11 不触发弹出，收尾时 `stack[-2]*stack[-1] = 4*11 = 44` 仍对；但 `arr = [5,5]` 用 `<` 会漏弹，收尾 `5*5 = 25` 也对——真正翻车在 `arr = [3,5,3]`：`<` 时 5 不弹 3，收尾弹出两个 3 得 `5*3 + 3*3 = 24`，正确是 `3*5 + 3*5 = 30`？不对，正确最小是 `3*5 + 5*3 = 30`，用 `<=` 得 30。必须用 `<=` 保证相等元素及时合并。
2. 收尾循环条件写成 `len(stack) > 1` → 会把哨兵 `inf` 也弹出，`inf * x` 得 `inf`，答案变成浮点无穷。正确是 `len(stack) > 2`，保留哨兵和最后一个元素。

## 如果面试官追问
问：若要求输出具体树结构而非仅代价？
答：在弹出 `mid` 时记录它作为叶子与左邻或右邻合并，最后按合并顺序自底向上建树即可。
