## 一句话思路
用栈从左到右扫描，栈顶与当前字符能拼成 "AB" 或 "CD" 就弹出，否则压入，栈长即答案。

## 怎么做
1. 初始化空栈 `st = []`，遍历 `s` 的每个字符 `c`。
2. 若 `st` 非空且 `st[-1] + c` 属于 `{"AB", "CD"}`，则 `st.pop()`，否则 `st.append(c)`。
3. 遍历结束后返回 `len(st)`。

以 `s = "ABFCACDB"` 为例，关键中间态：扫到第 5 个字符 `C` 时栈为 `['F','C','A']`，第 6 个 `D` 与栈顶 `C` 组成 `"CD"`，弹出后栈变 `['F','C','A']`→`['F','A']`；第 7 个 `B` 与栈顶 `A` 组成 `"AB"`，弹出后栈为 `['F','C']`，长度 2。

```python
st = []
for c in s:
    if st and st[-1] + c in ("AB", "CD"):
        st.pop()
    else:
        st.append(c)
return len(st)
```

正确性依据：任何一次删除都只影响被删字符两侧的相邻关系，栈恰好维护「当前已处理前缀的最简形式」，新字符只可能与栈顶配对，不会与更深的字符配对——因为中间字符若还在，就挡住了；若已消掉，说明它已和别的字符配对完毕，栈顶就是唯一候选。

## 复杂度
时间 O(n)：每个字符最多入栈一次、出栈一次，n 为 `len(s)`。
空间 O(n)：最坏情况（如 `"ACBBD"` 无配对）栈存下全部 n 个字符。

## 易错点
- 输入 `s = "AAB"` → 若只做一次 `s.replace("AB","")` 会得到 `"A"` 长度 1，但正确是删中间 `"AB"` 后剩 `"A"` 也是 1；真正的坑是 `"ABAB"` 这类，一次替换只消掉一对，必须循环或改用栈，栈一次扫描即得 0。
- 输入 `s = "ACBD"` → 若判断条件写成「`c` 是 `'B'` 或 `'D'` 就弹栈」会误弹，`'B'` 前是 `'C'` 不构成 `"AB"`；必须严格比对 `st[-1] + c` 是否等于 `"AB"` 或 `"CD"`，本题只有这两种合法配对。

## 如果面试官追问
若把可删子串扩展成任意长度 k 的固定集合（如同时删 `"ABC"`、`"DE"`）？答：栈改为按最长后缀匹配，每次检查栈顶 k-1 个字符加当前字符是否命中集合，复杂度仍 O(n·k)。
