## 一句话思路
用线段树维护每个区间篮子的最大容量，每次二分找最左的「最大值 ≥ fruits[i]」的位置，找到即占用并把它改成 -1。

## 怎么做
1. 建树：叶子存 `baskets[j]`，内部节点存左右子树最大值。
2. 对每个 `fruits[i]`，在树上做「找最左满足 max ≥ x」的下降：先看左子树最大值是否 ≥ x，是就往左走，否则往右走。
3. 走到叶子就把该位置更新为 `-1`（表示已占用），沿途回溯重算最大值。
4. 若根节点最大值 < `fruits[i]`，说明没有篮子能装，答案 +1，跳过。

以示例 1 为例：`fruits=[4,2,5]`，`baskets=[3,5,4]`。处理 `fruits[0]=4` 时，左子树（位置 0）最大值 3 < 4，转右子树，位置 1 的 5 ≥ 4，占用 baskets[1]，树更新后根最大值变为 4。处理 `fruits[2]=5` 时根最大值 4 < 5，直接判为未放置。

```python
def find_and_remove(node, l, r, x):
    if tree[node] < x:
        return False
    if l == r:
        tree[node] = -1
        return True
    mid = (l + r) // 2
    if tree[node * 2] >= x:
        ok = find_and_remove(node * 2, l, mid, x)
    else:
        ok = find_and_remove(node * 2 + 1, mid + 1, r, x)
    tree[node] = max(tree[node * 2], tree[node * 2 + 1])
    return ok
```

主循环里对每个 `x in fruits` 调一次，返回 `False` 就累加未放置数。

## 复杂度
时间：每个水果一次 O(log n) 的下降加回溯，共 O(n log n)。
空间：线段树数组开 4n，O(n) 额外空间。

## 易错点
- 输入 `fruits=[5], baskets=[4]`：若只比较根最大值就返回，会误判为「找到」，实际应返回 1。正确做法是下降前先判 `tree[1] < x` 直接跳过，别进递归。
- 输入 `fruits=[3,6,1], baskets=[6,4,7]`：若按「容量排序后贪心」而非「最左可用」，`fruits[1]=6` 会错配到 baskets[0]=6，导致 `fruits[2]=1` 无篮可用。必须严格按原下标顺序找最左满足条件的篮子。

## 如果面试官追问
问：n 扩大到 10^6 还这么写？答：线段树常数偏大，可换成分块（每块维护块内最大值），单次 O(√n)，总 O(n√n)，实现更短。
