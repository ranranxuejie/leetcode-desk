## 一句话思路
答案必是「删掉中间一段」，两端各保留 arr 的一个非递减前缀和后缀，用双指针在前后缀间找最长可拼接对。

## 怎么做
1. 从右往左扫，找最长的非递减后缀起点 `j`：`while j > 0 and arr[j-1] <= arr[j]: j -= 1`。
2. 若 `j == 0`，整个数组已有序，直接返回 0。
3. 初始化 `ans = j`（只保留后缀，删掉前缀 `arr[0..j-1]`），然后让 `i` 从左往右走前缀，对每个 `i` 用二分在后缀里找第一个 `>= arr[i]` 的位置 `k`，候选删除长度是 `k - i - 1`。
4. 取所有候选的最小值。

以 `arr = [1,2,3,10,4,2,3,5]` 为例：后缀从 `j=5`（值 2）开始，`arr[4]=4 > arr[5]=2` 停住。`i=0` 时 `arr[0]=1`，后缀 `[2,3,5]` 中第一个 `>=1` 的是下标 5，候选 `5-0-1=4`；`i=2` 时 `arr[2]=3`，后缀中第一个 `>=3` 是下标 6（值 3），候选 `6-2-1=3`，得到答案 3。

```python
j = n - 1
while j > 0 and arr[j-1] <= arr[j]:
    j -= 1
if j == 0:
    return 0
ans = j
for i in range(n):
    if i > 0 and arr[i-1] > arr[i]:
        break
    k = bisect_left(arr, arr[i], j, n)
    ans = min(ans, k - i - 1)
return ans
```

## 复杂度
时间：O(n log n)，外层前缀 O(n)，每次 `bisect_left` 在后缀区间 O(log n)。
空间：O(1)，只用了 `i`、`j`、`k`、`ans` 几个标量。

## 易错点
- 输入 `[1,2,3]` 已有序 → 若忘记 `j == 0` 提前返回，会进入循环算出 `k - i - 1 = -1` 之类的负值或错误候选。正确做法是先判 `j == 0` 直接返回 0。
- 输入 `[5,4,3,2,1]` 严格递减 → 后缀只有 `j=4` 一个元素，若只保留后缀不尝试前缀拼接，会漏掉「保留 `arr[0]` 删后四个」这种同样长度 4 的解；`ans` 初值取 `j` 已覆盖，但循环里 `i=0` 时 `bisect_left` 在 `[4,5)` 区间找不到 `>=5` 返回 5，候选 `5-0-1=4`，需保证 `bisect_left` 的 `hi=n` 不越界。

## 如果面试官追问
要求输出具体删除区间而非长度？答：在更新 `ans` 时同步记录 `(i+1, k-1)` 这对端点，最后返回该区间即可。
