## 一句话思路
统计每个数字的出现次数，答案就是这些次数能否有 ≥2 的公共因子，即整体 gcd 是否 ≥2。

## 怎么做
1. 用 `Counter(deck)` 得到每个数字的频次，记作 `cnt` 的取值集合。
2. 对全部频次求最大公约数 `g`，初值取第一个频次。
3. 返回 `g >= 2`。

以示例 2 `deck = [1,1,1,2,2,2,3,3]` 为例：频次是 `{1:3, 2:3, 3:2}`，`gcd(3,3)=3`，再 `gcd(3,2)=1`，最终 `g=1`，返回 `False`。这一步就是全部判断所在：只要有一个频次把 gcd 拉到 1，就再也回不去。

```python
from collections import Counter
from math import gcd

cnt = Counter(deck).values()
g = 0
for v in cnt:
    g = gcd(g, v)
    if g == 1:
        break
return g >= 2
```

`g` 从 0 起步是刻意的：`gcd(0, v) == v`，省掉取首元素的特判。中途 `g == 1` 直接跳出，因为 gcd 只会越算越小，1 是下界。

## 复杂度
时间 O(n + k log n)：n 是 `len(deck)` 用于计数，k 是不同数字个数，每次 gcd 是 O(log n)。
空间 O(k)：`Counter` 存 k 个键值对，其余是常数。

## 易错点
- `deck = [1]` 或 `[1,1,1]` 这类单一数字：频次只有 3，`g=3` 返回 `True` 是对的；但若写成「频次种类数 ≥ 2 才判断」就会漏掉单数字合法的情况，正确做法是始终对全部频次求 gcd，不预设种类数。
- `deck = [1,1,2,2,2,2]`：频次 `{1:2, 2:4}`，`gcd(2,4)=2` 返回 `True`；若误用「所有频次必须相等」来判断会返回 `False`，正确做法是只要求存在公共因子 X，不要求频次相同。

## 如果面试官追问
问：要求输出具体分组方案怎么办？
答：取 `X = g`，对每个数字把它的频次按 X 切成若干组，每组都是同一数字的 X 张牌。
