## 一句话思路
把 nums1 的每个值当作偏移量，用差分数组维护 nums2 的区间加，查询时对每个 nums1[i] 在有序结构里数 tot - nums1[i] 的出现次数。

## 怎么做
1. 关键观察：`len(nums1) <= 5`，所以一次类型 2 查询最多只需做 5 次「数某个值在 nums2 中出现几次」。
2. 用差分数组 `diff` 记录 nums2 的区间加：`[1,x,y,val]` 执行 `diff[x] += val; diff[y+1] -= val`，再对 diff 做前缀和得到每个位置的累计增量 `add[k]`。
3. 但每次查询都重算前缀和是 O(n)，5e4 次查询会超时；改用「分块」：把 nums2 按块大小 B 分块，块内维护 `Counter`，整块加用 `lazy[block]` 标记，零散位置暴力改并重建该块 Counter。
4. 查询时对每个 `v in nums1`，目标值 `t = tot - v`，遍历所有块：整块查 `cnt[block][t - lazy[block]]`，零散位置逐个比较 `nums2[k] + add[k] == t`。

以示例 1 为例：`nums1=[1,2]`，`nums2=[3,4]`，先查 `tot=5`，对 `v=1` 找 4（出现 1 次），对 `v=2` 找 3（出现 1 次），合计 2；执行 `[1,0,0,2]` 后 `nums2=[5,4]`，再查 `tot=5` 得 1。

```python
from collections import Counter
B = 256
n = len(nums2)
nb = (n + B - 1) // B
cnt = [Counter(nums2[i*B:(i+1)*B]) for i in range(nb)]
lazy = [0] * nb

def update(x, y, val):
    bx, by = x // B, y // B
    if bx == by:
        for k in range(x, y+1): nums2[k] += val
        cnt[bx] = Counter(nums2[bx*B:(bx+1)*B])
    else:
        for k in range(x, (bx+1)*B): nums2[k] += val
        cnt[bx] = Counter(nums2[bx*B:(bx+1)*B])
        for b in range(bx+1, by): lazy[b] += val
        for k in range(by*B, y+1): nums2[k] += val
        cnt[by] = Counter(nums2[by*B:(by+1)*B])

def query(tot):
    res = 0
    for v in nums1:
        t = tot - v
        for b in range(nb):
            res += cnt[b][t - lazy[b]]
    return res
```

## 复杂度
时间：每次更新 O(B + n/B)，每次查询 O(|nums1| · n/B)，总约 O(Q·(B + 5n/B))。
空间：`cnt` 存全部元素共 O(n)，`lazy` O(n/B)，无额外大结构。

## 易错点
- 更新跨块时忘记重建首尾两个块的 Counter，只改了 `nums2` 数组 → 后续查询读到旧计数；正确做法是首尾块改完后都重新 `Counter(...)` 覆盖。
- 查询整块时用 `cnt[b][t]` 而漏减 `lazy[b]` → 示例 2 中 `[1,0,1,1]` 后 `lazy[0]=1`，查 `tot=4` 会少算；必须写 `t - lazy[b]`。

## 如果面试官追问
问：若 nums1 长度也到 5e4 怎么办？答：改为对 nums2 建值域哈希，查询时枚举较小一方，或离线按 tot 排序做双指针。
