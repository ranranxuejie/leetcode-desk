## 一句话思路
n 为偶数时先手必胜、奇数时必败，因为奇数的因子必为奇数，减完变偶数，偶数只需一直减 1。

## 怎么做
1. 判断 `n % 2 == 0`，直接返回 `True`，否则 `False`。
2. 归纳依据：n=1 时先手无 x 可选，必败，是奇数；n=2 时选 x=1 得 1，对手无路可走，必胜，是偶数。
3. 关键中间值：n=3 时因子只有 1，3-1=2 交给鲍勃，鲍勃走 2-1=1 交回，爱丽丝面对 1 无操作，返回 `False`；n=4 时爱丽丝选 x=1 得 3，把奇数局面甩给鲍勃，鲍勃必败。
4. 奇偶性在每步都保持这个传递关系，所以只需看初始 n 的奇偶。

```python
def divisorGame(n: int) -> bool:
    return n % 2 == 0
```

若面试官要求不靠结论、写通用博弈 DP，则用 `dp[i]` 表示面对 i 的先手是否必胜，枚举 i 的真因子 x，只要存在 `dp[i - x] == False` 就置 `dp[i] = True`：

```python
dp = [False] * (n + 1)
for i in range(2, n + 1):
    for x in range(1, i):
        if i % x == 0 and not dp[i - x]:
            dp[i] = True
            break
return dp[n]
```

这段对 n=3 会算出 `dp[3] = False`，与结论一致。

## 复杂度
时间：结论法 O(1)；DP 法 O(n²)，外层 i 与内层枚举因子 x 各贡献一个 n。
空间：结论法 O(1)；DP 法 O(n)，额外开了长度 n+1 的 `dp` 数组。

## 易错点
- n=1 → 误以为「没有因子所以返回 True」→ 实际先手第一步就无合法 x，直接输，应返回 `False`；结论法 `1 % 2 == 0` 为假，恰好正确，别额外加 `n == 1` 的特判写反。
- 写 DP 时内层写成 `range(1, i // 2 + 1)` 却漏掉 x 本身之外的情况没问题，但若写成 `range(1, i)` 又忘了 `i % x == 0` 判断，会把非因子当合法操作 → n=4 时 x=3 被误用，`dp[4]` 仍对但 n=6 会算错，必须保留取模判断。

## 如果面试官追问
问：若把操作改成「x 可以是任意 1≤x<n，不要求整除」呢？
答：那每步都能把 n 减到 1，先手在 n≥2 时总能把局面变成 1 交给对手，恒为 `True`，整除条件是本题结论的关键。
