## 一句话思路
用并查集把 allowedSwaps 连成连通块，块内 source 元素可任意重排，逐块用 Counter 抵消 target 求剩余数。

## 怎么做
1. 对每条 `[a, b]` 做 union，得到每个下标所属的根。
2. 按根把下标分组，同一组内 source 的值可以任意互换。
3. 对每组统计 `Counter(source[i])`，再遍历该组下标减去 `target[i]`。
4. 每组剩余计数之和就是该组无法匹配的下标数，累加即答案。

以示例 1 为例：`allowedSwaps = [[0,1],[2,3]]` 得到两组 `{0,1}` 和 `{2,3}`。组 `{0,1}` 中 source 值 `{1,2}` 与 target 值 `{2,1}` 完全抵消，剩 0；组 `{2,3}` 中 source 值 `{3,4}` 对 target 值 `{4,5}`，抵消掉 4 后剩 `{3}`，贡献 1，答案 1。

```python
parent = list(range(n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
for a, b in allowedSwaps:
    parent[find(a)] = find(b)

groups = {}
for i in range(n):
    groups.setdefault(find(i), []).append(i)

ans = 0
for idxs in groups.values():
    cnt = Counter(source[i] for i in idxs)
    for i in idxs:
        if cnt[target[i]] > 0:
            cnt[target[i]] -= 1
        else:
            ans += 1
```

## 复杂度
时间 O(n α(n) + m α(n))，n 为数组长度、m 为 allowedSwaps 长度，Counter 部分 O(n)。
空间 O(n)，parent 数组与 groups 字典各占 O(n)。

## 易错点
- `allowedSwaps = []` 时若忘记每个下标自成一组的初始化，会把所有下标塞进同一组，示例 2 会错算成 0 而非 2；正确做法是 `parent = list(range(n))`，未 union 的下标根就是自己。
- 用 `Counter(source)` 全局统计再减 `Counter(target)` 会跨组抵消：示例 1 中全局 source 有 4、target 有 4，会误判为 0；必须按 `find(i)` 分组后组内抵消。

## 如果面试官追问
若要求输出具体交换方案而非距离？答：在每组内把 source 值按 target 值做映射，沿环逐个 swap 即可，环长减一即该组最少交换次数。
