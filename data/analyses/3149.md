## 一句话思路
状压 DP 枚举已用集合与末尾元素，求最小环代价，再按字典序贪心回溯构造排列。

## 怎么做
1. 把 score 看成环：`perm[i]` 走到 `perm[i+1]` 的代价是 `|perm[i] - nums[perm[i+1]]|`，最后一位回到 `perm[0]`。
2. 定义 `dp[mask][last]` = 已用集合 `mask`、末尾为 `last` 时的最小前缀代价，起点固定 `perm[0]=0`（字典序最小必以 0 开头）。
3. 转移：`dp[mask|1<<nxt][nxt] = min(dp[mask][last] + abs(last - nums[nxt]))`，`nxt` 不在 `mask` 中。
4. 收尾加 `abs(last - nums[0])` 得环代价；再从小到大枚举 `nxt`，选使 `dp[mask][last] + abs(last-nums[nxt]) + dp[mask|1<<nxt][nxt]` 等于最优值的第一个，贪心出字典序最小解。

以 `nums=[1,0,2]` 为例：`mask=0b001,last=0` 时，选 `nxt=1` 得 `dp[0b011][1]=|0-nums[1]|=0`；选 `nxt=2` 得 `dp[0b101][2]=|0-nums[2]|=2`。最终最优环代价 2，回溯时 `nxt=1` 先被选中，得 `[0,1,2]`。

```python
n = len(nums)
INF = 10**9
dp = [[INF] * n for _ in range(1 << n)]
dp[1][0] = 0
for mask in range(1 << n):
    for last in range(n):
        if dp[mask][last] == INF or not (mask >> last & 1):
            continue
        for nxt in range(n):
            if mask >> nxt & 1:
                continue
            nm = mask | 1 << nxt
            dp[nm][nxt] = min(dp[nm][nxt], dp[mask][last] + abs(last - nums[nxt]))
best = min(dp[(1 << n) - 1][last] + abs(last - nums[0]) for last in range(n))
```

## 复杂度
时间：`O(2^n * n^2)`，`mask` 与 `last`、`nxt` 三重枚举，`n<=14` 约 3.2e6 次。
空间：`O(2^n * n)` 的 `dp` 表，`2^14 * 14` 个整数。

## 易错点
- 忘记加回边 `abs(last - nums[0])`：`nums=[0,2,1]` 会算出前缀代价 0 而误判最优为 0，实际环代价是 `|1-nums[0]|=1` 再加前缀，正确最优为 2。
- 回溯时只按 `dp` 值贪心而不校验剩余路径：`nums=[1,0,2]` 在 `mask=0b011,last=1` 时若直接选 `nxt=2` 得 `|1-nums[2]|=1`，但需确认 `dp[0b111][2]+abs(2-nums[0])=1+1=2` 才等于最优，否则会构造出非最优排列。

## 如果面试官追问
问：n 放大到 20 还能这样做吗？
答：不能，`2^20*20^2` 超时，需换思路或剪枝，本题约束 `n<=14` 正是为状压设计。
