## 一句话思路
先剥掉不含金币的叶子，再把剩下的树「向内缩两圈」，答案就是缩完后的边数乘 2。

## 怎么做
1. 用度数数组 `deg` 做拓扑剥叶：队列里放所有 `coins[i]==0` 的叶子，剥完剩下的节点集合 `alive` 就是「金币的最小连通骨架」。
2. 在骨架上再做一次剥叶，但这次剥两轮（距离金币 2 以内都能白拿），得到真正需要走的节点集 `need`。
3. 统计 `need` 内部的边数 `cnt`，答案 `2*cnt`（因为要回到起点，每条边来回各一次）。

以示例 1 为例：`coins=[1,0,0,0,0,1]`，链 0-1-2-3-4-5。第一轮剥叶把 1、2、3、4 全剥掉（它们 `coins=0` 且是叶子），`alive={0,5}`；第二轮从 0 和 5 各向内扩两圈，`need` 覆盖 0..5 全部，但真正要走的边只有 0-1 和 4-5 这两条「金币到骨架」的边？不对——正确理解是：剥完两圈后剩下的节点是 2 和 3，它们之间的边 2-3 一条，加上 0-1、4-5 各一条，共 3 条边，答案 6？与官方 2 不符。

修正：第二轮剥叶是把「距离金币 ≤2」的节点全部剥掉，剩下的才是必须走的。示例 1 中金币在 0 和 5，距离 2 以内覆盖 0,1,2 和 3,4,5，全部剥光，`need` 为空，答案 0？仍不符。

正确做法（官方思路）：第一轮剥掉无金币叶子得到骨架；第二轮从骨架的叶子向内剥两圈，剥完后剩下的节点之间的边数 ×2 才是答案。示例 1 骨架是整条链（0 和 5 有金币，中间节点虽无金币但连通），第二轮从 0 和 5 向内剥两圈：剥掉 0,1,2 和 3,4,5，剩空，答案 0——但官方是 2。

实际官方解法：第一轮剥叶后骨架为 0-1-2-3-4-5；第二轮对骨架再做剥叶，剥两轮后剩下节点 2 和 3，它们之间的边 2-3 计 1 条，答案 `2*1=2`。关键：第二轮剥的是「骨架的叶子」，每轮剥一层，剥两轮后剩下的核心才是必须走的。

```python
from collections import deque
deg = [len(g[i]) for i in range(n)]
q = deque(i for i in range(n) if deg[i] == 1 and coins[i] == 0)
alive = [True] * n
while q:
    u = q.popleft(); alive[u] = False
    for v in g[u]:
        if alive[v]:
            deg[v] -= 1
            if deg[v] == 1 and coins[v] == 0:
                q.append(v)
# 第二轮：对 alive 节点再剥两轮叶子
for _ in range(2):
    nq = deque(i for i in range(n) if alive[i] and deg[i] == 1)
    while nq:
        u = nq.popleft(); alive[u] = False
        for v in g[u]:
            if alive[v]:
                deg[v] -= 1
                if deg[v] == 1:
                    nq.append(v)
ans = sum(1 for u in range(n) if alive[u] for v in g[u] if alive[v] and u < v)
return 2 * ans
```

## 复杂度
时间 O(n)：两轮拓扑各遍历每条边常数次，`deg` 更新是 O(n)。
空间 O(n)：邻接表 `g`、`deg`、`alive` 各占 n。

## 易错点
1. 全树无金币（`coins` 全 0）→ 第一轮剥叶会把所有节点剥光，`alive` 全 False，第二轮 `nq` 为空，`ans=0`，正确返回 0；若漏判会误算成 2 倍边数。
2. 只有一个金币且它在叶子 → 第一轮不剥它（`coins=1`），第二轮剥两圈后可能只剩它自己，`ans=0`，返回 0；若第二轮剥叶时误把 `coins=1` 的节点也当叶子剥掉，会得到错误的正数。
