## 一句话思路
二维前缀和 O(1) 求任意正方形和，边长可行性随边长单调，故二分边长。

## 怎么做
1. 建 `(m+1) x (n+1)` 前缀和 `pre`，`pre[i+1][j+1] = mat[i][j] + pre[i][j+1] + pre[i+1][j] - pre[i][j]`。
2. 二分边长 `k`，范围 `[0, min(m,n)]`，用 `lo, hi` 找最大可行值。
3. 对给定 `k`，枚举左上角 `(i,j)`，`i in [0,m-k]`、`j in [0,n-k]`，用 `pre[i+k][j+k] - pre[i][j+k] - pre[i+k][j] + pre[i][j]` 判 `<= threshold`。
4. 任一位置可行则 `k` 可行，收缩下界；否则收缩上界。

以示例 1 为例，`mat` 为 3x7、`threshold=4`。二分到 `k=2` 时，左上角 `(0,0)` 的 2x2 和为 `1+1+1+1=4 <= 4`，可行；`k=3` 时最小 3x3 和已含 `3`，超过 4，不可行，故答案 2。

```python
m, n = len(mat), len(mat[0])
pre = [[0] * (n + 1) for _ in range(m + 1)]
for i in range(m):
    for j in range(n):
        pre[i+1][j+1] = mat[i][j] + pre[i][j+1] + pre[i+1][j] - pre[i][j]

def ok(k):
    for i in range(m - k + 1):
        for j in range(n - k + 1):
            s = pre[i+k][j+k] - pre[i][j+k] - pre[i+k][j] + pre[i][j]
            if s <= threshold:
                return True
    return False

lo, hi = 0, min(m, n)
while lo < hi:
    mid = (lo + hi + 1) // 2
    if ok(mid):
        lo = mid
    else:
        hi = mid - 1
return lo
```

## 复杂度
时间：二分 `log(min(m,n))` 次，每次枚举 `O(m*n)` 个左上角，共 `O(m*n*log(min(m,n)))`。
空间：`pre` 为 `(m+1)*(n+1)`，即 `O(m*n)` 额外空间。

## 易错点
1. 全 0 矩阵或 `threshold=0` 且含 0 元素时，`k=0` 恒可行但 `k=1` 也可能可行；若二分写成 `lo=1` 起始或 `ok(0)` 未处理，会漏掉返回 0 的示例 2（全 2、`threshold=1`）。正确做法是 `lo=0` 起，`mid=(lo+hi+1)//2` 取上中位，保证收敛到最大可行值。
2. 前缀和下标偏移：`pre` 是 `(m+1)x(n+1)`，正方形和必须用 `pre[i+k][j+k]-pre[i][j+k]-pre[i+k][j]+pre[i][j]`；若误用 `pre[i+k-1]` 或漏减 `pre[i][j]`，示例 1 中 `(0,0)` 的 2x2 会算成 8 而非 4，把答案压成 1。

## 如果面试官追问
若要求返回最大正方形的左上角坐标而非边长？答：`ok(k)` 里命中时记录 `(i,j)`，二分结束时再跑一次 `ok(lo)` 取该坐标即可，复杂度不变。
