## 一句话思路
先求每个数字的最右出现位置，用「当前段最远右端点」把数组切成不可再分的块，块间缝隙可切可不切，答案即 2^(块数-1)。

## 怎么做
1. 扫一遍 `nums` 建 `last = {值: 最右下标}`，示例 3 得 `{1:2, 2:1, 3:3}`。
2. 再扫一遍，维护 `far = max(far, last[nums[i]])`；当 `i == far` 时，`[start, i]` 内所有数字都不再出现在后面，此处是一个「不可分块」的右边界，`blocks += 1`，`start = i + 1`。
3. 示例 3：`i=0` 时 `far=max(0,2)=2`；`i=1` 时 `far=max(2,1)=2`；`i=2` 时 `i==far`，第一块 `[1,2,1]` 闭合，`blocks=1`；`i=3` 时 `far=3`，`i==far`，`blocks=2`。
4. 相邻两块之间的缝隙共 `blocks-1` 个，每个独立决定切或不切，答案 `pow(2, blocks-1, 10**9+7)`。

```python
MOD = 10**9 + 7
last = {}
for i, x in enumerate(nums):
    last[x] = i
blocks, far = 0, -1
for i, x in enumerate(nums):
    far = max(far, last[x])
    if i == far:
        blocks += 1
return pow(2, blocks - 1, MOD)
```

关键点：`far` 只增不减，所以块内任何数字的后续出现都被 `far` 兜住，`i == far` 时切下去必然安全。

## 复杂度
时间 O(n)：建 `last` 与扫描各一遍，`pow` 是 O(log blocks)。
空间 O(n)：`last` 最坏存 n 个不同值，`nums` 本身不计。

## 易错点
- 把「块内缝隙」也当成可切点：`nums = [1,2,1,3]` 若在 `i=1` 处切，会得到 `[1,2]` 与 `[1,3]`，数字 1 跨两段，错算成 4 种；正确做法是只在 `i == far` 时计块，得 2 种。
- 忘记 `blocks-1` 而写成 `2**blocks`：`nums = [1,2,3,4]` 得 4 块，缝隙只有 3 个，答案 8 而非 16；`nums = [1,1,1,1]` 得 1 块，`2**0 = 1` 才对。

## 如果面试官追问
要求输出所有方案而非计数？答：块数 k 时方案数 2^(k-1)，枚举时对每个缝隙做二进制取舍，按块边界还原下标即可。
