## 一句话思路
把下标和分数配对后按分数降序排序，名次就是排序后的位置，再按下标填回答案。

## 怎么做
1. 构造 `pairs = [(s, i) for i, s in enumerate(score)]`，把分数和原下标绑在一起。
2. 按分数降序排序：`pairs.sort(reverse=True)`，元组比较先比分数，分数互不相同所以下标不参与比较。
3. 遍历排序结果，位置 `r`（从 0 起）决定奖项：`r == 0` 给金牌，`1` 银牌，`2` 铜牌，否则 `str(r + 1)`。
4. 写入 `ans[i]`，`i` 是配对里存的原下标，这样答案顺序和输入对齐。

以 `score = [10,3,8,9,4]` 为例，`pairs` 排序后是 `[(10,0),(9,3),(8,2),(4,4),(3,1)]`；第 0 位 `(10,0)` 拿金牌写进 `ans[0]`，第 1 位 `(9,3)` 拿银牌写进 `ans[3]`，第 4 位 `(3,1)` 的名次是 `str(4+1)="5"` 写进 `ans[1]`，正好对上示例输出的第 2 个元素 `"5"`。

```python
pairs = [(s, i) for i, s in enumerate(score)]
pairs.sort(reverse=True)
ans = [""] * len(score)
medals = ["Gold Medal", "Silver Medal", "Bronze Medal"]
for r, (s, i) in enumerate(pairs):
    ans[i] = medals[r] if r < 3 else str(r + 1)
```

关键点：名次 `r + 1` 是**排序后的位置**，不是 `score[i]` 本身；`str(r + 1)` 里的 `+1` 不能漏，否则第 4 名会输出 `"3"`。

## 复杂度
时间：排序 `O(n log n)` 主导，构造配对和回填各 `O(n)`。
空间：`pairs` 存 n 个二元组、`ans` 存 n 个字符串，共 `O(n)` 额外空间。

## 易错点
- 直接对 `score` 排序再按下标找名次 → 原下标丢失，`[10,3,8,9,4]` 会错排成按分数顺序输出，`ans[1]` 变成 `"Silver Medal"` 而不是 `"5"` → 必须把 `(分数, 下标)` 一起排，回填时用配对里的 `i`。
- 名次字符串写成 `str(r)` → 第 4 名输出 `"3"`、第 5 名输出 `"4"`，整体错位一位 → 用 `str(r + 1)`，且前三名走 `medals[r]` 分支，不要用 `r <= 3` 把第 4 名也判成铜牌。

## 如果面试官追问
问：如果分数允许重复，怎么改？
答：排序键改成 `(-分数, 下标)` 保证稳定，重复分数按并列名次（如 `1,1,3`）处理，回填时比较相邻分数决定是否递增名次。
