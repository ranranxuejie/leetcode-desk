## 一句话思路
按宽度升序、同宽按高度降序排序后，对高度序列求最长严格递增子序列（LIS），用二分维护 tails。

## 怎么做
1. 排序：`envelopes.sort(key=lambda e: (e[0], -e[1]))`，宽度升序、同宽高度降序。
2. 同宽高度降序，保证同一宽度的多个信封在高度 LIS 里最多被选一个，不会互相嵌套。
3. 对高度做 LIS：`tails` 存各长度递增子序列的最小结尾，用 `bisect_left` 找位置替换或追加。
4. 返回 `len(tails)`。

以示例 1 `[[5,4],[6,4],[6,7],[2,3]]` 为例：排序后为 `[[2,3],[5,4],[6,7],[6,4]]`，高度序列 `[3,4,7,4]`。处理到最后一个 `4` 时，`bisect_left([3,4,7], 4)` 返回 1，把 `tails[1]` 从 4 换成 4（不变），`tails` 仍是 `[3,4,7]`，长度 3。若同宽按高度升序排，高度序列会变成 `[3,4,4,7]`，LIS 会错误地取到两个宽度 6 的信封，答案变 4。

```python
from bisect import bisect_left

envelopes.sort(key=lambda e: (e[0], -e[1]))
tails = []
for _, h in envelopes:
    i = bisect_left(tails, h)
    if i == len(tails):
        tails.append(h)
    else:
        tails[i] = h
return len(tails)
```

## 复杂度
时间：排序 O(n log n)，n 个信封各做一次二分 O(n log n)，共 O(n log n)。
空间：`tails` 最坏 O(n)，排序栈开销 O(log n)。

## 易错点
- 同宽按高度升序排 → 示例 1 中 `[6,4]` 和 `[6,7]` 会同时进入 LIS，答案错成 4 → 必须同宽按高度降序，让同宽信封在高度序列里递减、无法同时入选。
- 用 `bisect_right` 代替 `bisect_left` → 高度序列 `[3,4,7,4]` 中重复的 4 会被当成可接续，LIS 长度虚增 → 题目要求严格递增，必须用 `bisect_left`。

## 如果面试官追问
要求输出具体信封序列而非长度怎么办？答：`tails` 只存值不存下标，需额外记录每个元素的前驱下标，最后从最长链尾部回溯。
