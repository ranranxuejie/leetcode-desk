## 一句话思路
路径边权众数保留、其余改掉，答案 = 路径长度 − 出现最多的权重次数；用 LCA + 26 维前缀计数一次查询 O(26)。

## 怎么做
1. 以 0 为根 DFS，记录 `depth[u]`、`up[k][u]`（倍增祖先）和 `cnt[u][w]`：根到 u 路径上权重 w 的边数。
2. 查询 (a,b) 先求 `l = lca(a,b)`，路径长度 `d = depth[a] + depth[b] - 2*depth[l]`。
3. 对 w=1..26 算 `c = cnt[a][w] + cnt[b][w] - 2*cnt[l][w]`，取最大者 `best`，答案 `d - best`。

以示例 1 的查询 `[0,6]` 为例：lca=0，d=6；权重 1 出现 3 次、权重 2 出现 3 次，best=3，答案 6−3=3，与输出一致。

```python
def lca(a, b):
    if depth[a] < depth[b]: a, b = b, a
    for k in range(LOG):
        if (depth[a] - depth[b]) >> k & 1: a = up[k][a]
    if a == b: return a
    for k in range(LOG - 1, -1, -1):
        if up[k][a] != up[k][b]:
            a, b = up[k][a], up[k][b]
    return up[0][a]

d = depth[a] + depth[b] - 2 * depth[l]
best = max(cnt[a][w] + cnt[b][w] - 2 * cnt[l][w] for w in range(1, 27))
ans.append(d - best)
```

注意 `cnt` 只统计到 lca 为止，lca 到 a、lca 到 b 两段的边都算进去了，减 `2*cnt[l][w]` 正好去掉根到 lca 的重复部分。

## 复杂度
时间：预处理 O(n log n)，每条查询 O(26 + log n)，共 O((n+m) log n + 26m)。
空间：`up` 表 O(n log n)，`cnt` 表 O(26n)，均为额外开销。

## 易错点
- 查询 `a == b`（如 `[3,3]`）→ 路径长度 d=0，若仍按 `d - best` 算得 0 正确，但若把 lca 写成返回父节点会得负数 → 先判 `a == b` 直接返回 0。
- 权重范围是 1..26 而非 0..25 → 若循环写 `range(26)` 会漏掉权重 26、把 `cnt[u][0]` 恒 0 计入 → 必须写 `range(1, 27)`，数组开 27 列。

## 如果面试官追问
若 n 和 m 都放大到 10^5 且权重种类变多，怎么办？答：把 26 维前缀换成「每个节点存 dict 的差分」，或改用树上莫队按路径维护频次，避免 26 倍常数。
