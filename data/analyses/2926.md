## 一句话思路
把条件移项成 `nums[i]-i >= nums[j]-j`，对 `nums[i]-i` 离散化后建树状数组求前缀最大 DP。

## 怎么做
1. 令 `b[i] = nums[i] - i`，平衡条件等价于子序列上 `b` 单调不减。
2. 设 `dp[i]` 为以 `i` 结尾的最大和，则 `dp[i] = nums[i] + max(0, max{dp[j] : j < i 且 b[j] <= b[i]})`。
3. 把 `b` 排序去重得到 `vals`，树状数组下标 `k = bisect_right(vals, b[i])`，查询前缀 `[1..k]` 最大值，再单点更新 `k`。
4. 答案取所有 `dp[i]` 的最大值。

以 `nums = [3,3,5,6]` 为例：`b = [3,2,3,3]`，`vals = [2,3]`。`i=0` 查前缀得 0，`dp[0]=3`，更新位置 2 为 3；`i=1` 的 `b=2` 查前缀仍是 0，`dp[1]=3`；`i=2` 的 `b=3` 查到 3，`dp[2]=5+3=8`；`i=3` 查到 8，`dp[3]=6+8=14`。

```python
from bisect import bisect_right
b = [x - i for i, x in enumerate(nums)]
vals = sorted(set(b))
tree = [0] * (len(vals) + 1)
ans = -10**18
for x, v in zip(b, nums):
    k = bisect_right(vals, x)
    best, p = 0, k
    while p > 0:
        best = max(best, tree[p]); p -= p & -p
    cur = v + best
    ans = max(ans, cur)
    p = k
    while p < len(tree):
        tree[p] = max(tree[p], cur); p += p & -p
```

## 复杂度
时间 O(n log n)：排序去重 O(n log n)，每个元素一次查询加一次更新各 O(log n)。
空间 O(n)：`vals`、`tree` 各 O(n)，`b` 可省。

## 易错点
- 全负数如 `nums = [-2,-1]`：若把 `best` 初始化为 `-inf` 或忘记 `max(0, ...)`，会强行拼接前驱导致 `dp` 变小；正确做法是 `best` 从 0 起，允许子序列只含 `i` 自己，答案得 `-1`。
- 相等 `b` 的处理：`nums = [3,3,5,6]` 中 `b[0]=b[2]=3`，若用 `bisect_left` 定位，`i=2` 查不到 `i=0` 的 3，`dp[2]` 会错成 5 而非 8；必须用 `bisect_right` 让相等值落在同一前缀内。

## 如果面试官追问
要求输出具体下标方案怎么办？答：树状数组额外存取得最大值的来源下标，DP 时记录 `pre[i]`，最后从 `ans` 对应位置沿 `pre` 回溯。
