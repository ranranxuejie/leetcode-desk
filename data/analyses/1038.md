## 一句话思路
反中序遍历（右→根→左）配合累加变量 `total`，因为这样访问顺序恰好是从大到小，每个节点只需加上已访问过的更大值之和。

## 怎么做
1. 维护一个非局部累加器 `total = 0`，表示「已访问过的所有节点值之和」。
2. 递归顺序固定为 `root.right → root → root.left`，保证降序访问。
3. 进入节点时先 `total += root.val`，再 `root.val = total`，此时 `total` 正好是「大于等于当前值」的和。
4. 返回 `root`。

以示例 1 的根 `4` 为例：先递归右子树，访问到 `8` 时 `total` 从 0 变 8，`8` 改成 8；回溯到 `7` 时 `total = 8+7 = 15`，`7` 改成 15；再到 `6` 时 `total = 15+6 = 21`，`6` 改成 21；最后回到根 `4`，`total = 21+5+4 = 30`，根值变 30。这与输出首元素 30 一致。

```python
def dfs(node):
    nonlocal total
    if not node:
        return
    dfs(node.right)
    total += node.val
    node.val = total
    dfs(node.left)

total = 0
dfs(root)
return root
```

关键点：`total += node.val` 必须在赋值 `node.val = total` 之前，否则会把旧值覆盖掉，累加就断了。

## 复杂度
时间 O(n)：每个节点恰好访问一次，n 为节点数。
空间 O(h)：递归栈深度等于树高 h，最坏链状树 O(n)，额外只开了 `total` 一个变量。

## 易错点
- 写成普通中序（左→根→右）→ 访问顺序是升序，`total` 累加的是更小值，示例 1 根会错成 4 而不是 30 → 必须右子树先递归。
- 先赋值 `node.val = total` 再 `total += node.val` → 累加的是新值，示例 1 中 `8` 处 `total` 会变 16 而非 8，后续全错 → 顺序必须是先加后赋。

## 如果面试官追问
如果要求不修改原树、返回新树怎么办？答：递归时把 `total` 作为参数往下传，新建节点 `TreeNode(total)` 并挂到新右/左子树上，逻辑不变。
