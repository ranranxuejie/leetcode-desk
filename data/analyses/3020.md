## 一句话思路
用哈希表数频次，对每个不同的底数 x 沿 x→x²→x⁴ 链累加，链尾按频次奇偶决定能否多取一个。

## 怎么做
1. 用 `Counter(nums)` 得到每个值的出现次数 `cnt`。
2. 只对「不是任何数的平方」的值作为链起点枚举，避免重复计算同一条链。
3. 沿 `cur = x` 走，`cur = cur * cur`，每次取 `min(cnt[cur], 2)` 累加；一旦 `cur` 不在 `cnt` 里就停。
4. 链尾若 `cnt[cur] >= 2` 可多放一个（对称中心），否则只能放一个。

以 `nums = [5,4,1,2,2]` 为例：`cnt = {5:1, 4:1, 1:1, 2:2}`。起点 2（4 是平方数跳过），链上 2 取 `min(2,2)=2`，`cur=4` 取 `min(1,2)=1`，`cur=16` 不在表里停，合计 3。起点 5 得 1，起点 1 单独处理。

```python
from collections import Counter
cnt = Counter(nums)
ans = 1 if cnt[1] % 2 == 0 else 0  # 1 的链：1,1,1... 只能取奇数个
for x in cnt:
    r = int(x ** 0.5)
    if r * r == x:          # x 是平方数，不是链起点
        continue
    cur, total = x, 0
    while cur in cnt:
        total += min(cnt[cur], 2)
        cur = cur * cur
    ans = max(ans, total)
```

注意 1 单独算：`cnt[1]` 个 1 全可取，但模式要求对称，实际能取 `cnt[1]` 若为奇数，否则 `cnt[1]-1`。

## 复杂度
时间 O(n + m log log V)：n 建表，m 个不同值各走一条长度 O(log log V) 的链。
空间 O(m)：`Counter` 存 m 个不同值。

## 易错点
- 输入 `[1,1,1]` → 若把 1 当普通链起点，`cur=1` 会死循环 `1*1=1` → 必须把 1 单独处理，取 `cnt[1]` 为奇数则全取，偶数则减一。
- 输入 `[2,2,4]` → 若对 4 也当起点枚举，会重复算同一条链导致答案偏大 → 用 `r*r==x` 判断跳过平方数，只从链头 2 出发。

## 如果面试官追问
问：若 nums 长度到 10^6 且值到 10^18 怎么办？
答：思路不变，`Counter` 仍 O(n)，链长仍是 O(log log V)，但 `x**0.5` 要用 `math.isqrt` 避免浮点误差。
