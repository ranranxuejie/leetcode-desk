## 一句话思路
按步长 1,1,2,2,3,3… 顺时针走，每步都记录坐标，只把落在网格内的坐标收进结果。

## 怎么做
1. 方向顺序固定为东、南、西、北，用 `dirs = [(0,1),(1,0),(0,-1),(-1,0)]` 表示。
2. 步长 `step` 从 1 开始，每走完两个方向就加 1，因为螺旋每转半圈，步长才增加一次。
3. 每走一步，就更新 `r, c`；如果 `0 <= r < rows and 0 <= c < cols`，就把 `[r, c]` 加入结果。
4. 当 `len(res) == rows * cols` 时立即返回，不要等走完整个外圈。

以示例 2（`rows=5, cols=6, rStart=1, cStart=4`）为例：起点 `[1,4]` 先入结果；步长 1 向东走到 `(1,5)`，入结果；转向南，步长 1 走到 `(2,5)`，入结果；步长升到 2，向西走两步到 `(2,4)`、`(2,3)`，都入结果。此时 `res` 长度是 5，而目标长度是 30，继续。

```python
res = [[rStart, cStart]]
r, c = rStart, cStart
dirs = [(0, 1), (1, 0), (0, -1), (-1, 0)]
step, d = 1, 0
while len(res) < rows * cols:
    for _ in range(2):
        dr, dc = dirs[d % 4]
        for _ in range(step):
            r += dr
            c += dc
            if 0 <= r < rows and 0 <= c < cols:
                res.append([r, c])
        d += 1
    step += 1
return res
```

## 复杂度
时间 O(max(rows, cols)^2)：螺旋外扩到覆盖整个网格，走的步数由较大边长决定。
空间 O(rows * cols)：结果列表存全部格子，其余只有常数个变量。

## 易错点
- 起点 `(rStart, cStart)` 必须先放进 `res`，再进入循环；否则示例 1 会输出 `[[0,1],[0,2],[0,3]]`，漏掉 `[0,0]`，长度永远差 1，导致死循环。
- 步长递增的时机是「每走完两个方向」而不是「每走完一个方向」；若写成每个方向后 `step += 1`，示例 2 会在 `(2,5)` 之后直接跳到步长 2 向南，坐标序列与期望的 `[2,4],[2,3]` 错位。

## 如果面试官追问
问：如果网格很大（如 10^9），不能真的走完外部空格怎么办？
答：按圈直接算出每圈与网格的交集区间，只枚举落在网格内的坐标，跳过整段网格外的路径。
