## 一句话思路
按 `(user_id, reaction)` 分组计数，再按用户取最大计数与总反应数比，用窗口函数或两次聚合筛出 ≥60% 的用户。

## 怎么做
1. 先按 `user_id, reaction` 聚合出每个用户每种反应的次数 `cnt`。
2. 再按 `user_id` 聚合，取 `total = sum(cnt)`、`mx = max(cnt)`，同时用 `row_number()` 按 `cnt desc, reaction asc` 取主导反应。
3. 过滤 `total >= 5` 且 `mx / total >= 0.6`，`round(mx/total, 2)` 得 `reaction_ratio`。
4. 按 `reaction_ratio desc, user_id asc` 排序。

以用户 1 为例：`like` 计数 4、`wow` 计数 1，`total=5`、`mx=4`，`4/5=0.80 ≥ 0.6` 保留；用户 2 最大计数只有 2，`2/5=0.40` 被过滤。

```python
from collections import Counter

df = reactions.groupby(["user_id", "reaction"]).size().reset_index(name="cnt")
tot = df.groupby("user_id")["cnt"].transform("sum")
df["total"] = tot
df["ratio"] = df["cnt"] / df["total"]
# 主导反应：同用户内 cnt 最大者
df["rk"] = df.groupby("user_id")["cnt"].rank(method="first", ascending=False)
dom = df[df["rk"] == 1]
res = dom[(dom["total"] >= 5) & (dom["ratio"] >= 0.6)]
res["reaction_ratio"] = res["ratio"].round(2)
res = res.sort_values(["reaction_ratio", "user_id"], ascending=[False, True])
```

## 复杂度
时间：O(n log n)，n 为 reactions 行数，排序与分组主导。
空间：O(n)，存分组计数与中间列。

## 易错点
- 用户 2 这类「最大计数 2、总数 5」的输入 → 若只按 `reaction` 全局计数会误判 → 必须先按 `(user_id, reaction)` 分组再取每用户最大值。
- 主导反应并列时（如某用户 `like` 和 `wow` 各 2 次）→ 若 `rank` 用 `min` 会返回多行 → 用 `method="first"` 或加 `reaction` 升序做 tie-break，保证每用户一行。

## 如果面试官追问
问：若阈值改为「严格大于 60%」？答：把 `>= 0.6` 改成 `> 0.6`，注意浮点比较可用 `mx * 10 > total * 6` 避免精度问题。
