## 一句话思路
正着算长度、倒着找字符：先扫一遍记录每步后的解码长度，再从后往前把 k 折回上一层。

## 怎么做
1. 正向扫描 `s`，用 `size` 累积当前解码串长度；遇字母 `size += 1`，遇数字 `size *= int(ch)`。`size` 只需保留到能覆盖 `k` 的量级，但 Python 大整数无所谓，直接算。
2. 反向扫描 `s`，每步先 `k %= size`（把 k 折回当前层），若 `k == 0` 说明落在本层最后一个字符上，令 `k = size`。
3. 反向遇数字：`size //= int(ch)`，把长度还原到重复前；遇字母：若 `k == size` 则返回该字母，否则 `size -= 1`。

以 `s = "leet2code3", k = 10` 为例：正向得 `size` 序列 1,2,3,4,8,9,10,11,12,36，反向从 `size=36` 开始，遇 `'3'` 得 `size=12`，`k=10` 不变；继续退到 `size=10` 时 `k==size`，该字母是 `'o'`。

```python
size = 0
for ch in s:
    if ch.isdigit():
        size *= int(ch)
    else:
        size += 1
for ch in reversed(s):
    k %= size
    if k == 0:
        k = size
    if ch.isdigit():
        size //= int(ch)
    elif k == size:
        return ch
    else:
        size -= 1
```

## 复杂度
时间 O(n)：正向、反向各扫一遍 `s`，n 为 `s` 长度。
空间 O(1)：只存 `size` 和 `k`，不构造解码串。

## 易错点
- `s = "a2345678999999999999999"` 这类连乘 → 若真去构造解码串会直接爆内存 → 必须只算长度 `size`，靠 `k %= size` 折返，全程不落地字符串。
- `k` 恰好等于某层 `size`（如示例 1 退到 `size=10` 时 `k=10`）→ 若只写 `k %= size` 会得 0 而漏判 → 必须补 `if k == 0: k = size`，否则返回错字符或越界。

## 如果面试官追问
问：若要求返回解码串第 k 到 k+9 共 10 个字符怎么办？
答：仍用长度折返定位首字符，再在反向过程中连续收集，遇数字展开时按 `size` 分段取，不构造整串。
