## 一句话思路
按二进制位统计 1 的个数，对 3 取模，剩下的位拼起来就是只出现一次的数。

## 怎么做
1. 对每一位 `i`（0 到 31），遍历 `nums` 统计该位为 1 的元素个数 `cnt`。
2. `cnt % 3` 就是答案在该位的值，因为其余元素每个贡献 3 次，抵消后只剩目标元素。
3. 把结果累加进 `res`，注意第 31 位（符号位）要按 32 位补码处理。

以 `nums = [2,2,3,2]` 为例：二进制 `2=10`、`3=11`。第 0 位 1 的个数是 1（只有 3），`1%3=1`；第 1 位 1 的个数是 4（2,2,3,2），`4%3=1`。拼起来 `11` 即 3。

```python
res = 0
for i in range(32):
    cnt = 0
    for x in nums:
        cnt += (x >> i) & 1
    if cnt % 3:
        res |= 1 << i
if res >= 2**31:          # 符号位为 1，转成负数
    res -= 2**32
return res
```

关键在最后两行：Python 整数无溢出，第 31 位若为 1，`res` 会得到 `2**31` 到 `2**32-1` 的正数，必须减 `2**32` 还原成题目要求的 32 位有符号值。

## 复杂度
时间：O(32n)，外层固定 32 位，n 来自 `nums` 长度。
空间：O(1)，只用了 `res`、`cnt`、`i` 三个变量。

## 易错点
- 输入含负数如 `nums = [-2,-2,1,1,-2,1,-1]` → 若只循环 `range(31)` 会漏掉符号位，答案错成正数 → 必须循环 `range(32)` 并在 `res >= 2**31` 时减 `2**32`。
- 输入 `nums = [2,2,3,2]` → 若用 `cnt % 3` 后直接 `res += cnt % 3` 而不移位，会把第 1 位的 1 当成值 1 累加，得到 2 而非 3 → 必须写 `res |= (cnt % 3) << i`。

## 如果面试官追问
问：能否用两个变量 `ones`、`twos` 做到 O(1) 且不循环 32 次？
答：可以，`ones = (ones ^ x) & ~twos`，`twos = (twos ^ x) & ~ones`，最后返回 `ones`。
