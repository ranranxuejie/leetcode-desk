## 一句话思路
双指针各走完自己再换到对方链表头，两轮后必在交点相遇或同时为 `None`，因为两边总步数都是 m+n。

## 怎么做
1. 令 `pa = headA`、`pb = headB`，循环条件 `while pa is not pb`。
2. 每轮 `pa = pa.next if pa else headB`，`pb = pb.next if pb else headA`。
3. 循环结束时 `pa` 就是交点（或 `None`），直接返回。

拿示例 1 走一遍：A 长 5、B 长 6，A 独有前缀 2 个（4,1），B 独有前缀 3 个（5,0,1）。`pa` 走 5 步到 `None` 后跳到 `headB`，`pb` 走 6 步到 `None` 后跳到 `headA`。此时 `pa` 在 B 上已走 1 步、`pb` 在 A 上已走 0 步，两者再各走 2 步，`pa` 落在 B 的第 3 个节点、`pb` 落在 A 的第 2 个节点——正是 `8` 这个节点，`pa is pb` 成立。总步数 5+3 = 6+2 = 8，两边对齐。

```python
pa, pb = headA, headB
while pa is not pb:
    pa = pa.next if pa else headB
    pb = pb.next if pb else headA
return pa
```

关键点：判断用 `is` 不用 `==`。示例 1 里 A 的 `8` 和 B 的 `8` 是同一个对象，`is` 成立；若用 `==` 且 ListNode 没重写 `__eq__`，行为一样，但一旦有值相等的不同节点就会误判。

## 复杂度
时间 O(m+n)：`pa`、`pb` 各最多走 m+n 步。
空间 O(1)：只开了 `pa`、`pb` 两个指针。

## 易错点
- 无交点时（示例 3，A=[2,6,4]、B=[1,5]）：若循环写成 `while pa and pb` 或忘了让指针在 `None` 时跳头，会死循环或提前返回错误节点。正确做法是 `pa.next if pa else headB`，让两边都走满 m+n 步后同时变 `None`，循环自然退出返回 `None`。
- 长度差对齐：示例 2 中 A 独有前缀 3 个、B 独有前缀 1 个，若先各自遍历到尾再回退对齐（比如想用「先算长度差再同步走」但差算反了），会从 `9` 或 `3` 开始比较，错过 `2`。用换头法就不需要显式算长度差，别多此一举。

## 如果面试官追问
问：不允许改指针、也不许用双指针换头，怎么办？
答：先各遍历一次记下长度 m、n，长的先走 |m-n| 步，再同步走，首个 `is` 相等的节点即交点，同样 O(1) 空间。
