## 一句话思路
把 s 压成相邻同字符的连续段长度数组，每对相邻段取 min 累加，因为每对段能贡献 min(a,b) 个合法子串。

## 怎么做
1. 一次遍历把 s 切成连续段长度，存进 `groups`；`"00110011"` 得到 `[2,2,2,2]`。
2. 对每对相邻段 `groups[i-1]` 和 `groups[i]`，答案加上 `min(前, 后)`。
3. 以 `"00110011"` 为例，四段两两取 min 都是 2，累加得 6，与示例一致；`"10101"` 得 `[1,1,1,1,1]`，四对 min 都是 1，得 4。

```python
groups = []
cnt = 1
for i in range(1, len(s)):
    if s[i] == s[i - 1]:
        cnt += 1
    else:
        groups.append(cnt)
        cnt = 1
groups.append(cnt)

ans = 0
for i in range(1, len(groups)):
    ans += min(groups[i - 1], groups[i])
return ans
```

关键中间值：`"00110011"` 遍历到 `i=2`（字符 `'1'` 与 `'0'` 不同）时，`groups` 变成 `[2]`、`cnt` 重置为 1；最终 `groups == [2,2,2,2]`，`ans` 依次为 2、4、6。

## 复杂度
时间 O(n)：一次扫描切段、一次扫描累加，n 为 `len(s)`。
空间 O(n)：`groups` 最坏存 n 个 1（如 `"10101"`）。

## 易错点
- 输入 `"0011"` 若只统计「整段对」而漏掉段内偏移，会得 1 而非 2：`groups=[2,2]` 的 min 是 2，对应 `"01"` 和 `"0011"` 两个子串，必须按 min 累加而不是按 1 累加。
- 输入 `"000"` 或 `"1"` 这类单一字符：若在循环里直接 `groups.append(cnt)` 后忘记处理末尾段，`groups` 会为空或漏最后一段，答案错成 0；正确做法是循环结束后无条件再 `append(cnt)` 一次。

## 如果面试官追问
问：能否 O(1) 空间？答：可以，只保留 `prev` 段长和当前 `cur` 段长，段切换时 `ans += min(prev, cur)`，再 `prev, cur = cur, 1`。
