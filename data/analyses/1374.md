## 一句话思路
按 n 的奇偶分两种构造：奇数全填 `'a'`；偶数填 `n-1` 个 `'a'` 加 1 个 `'b'`，两种字符计数都是奇数。

## 怎么做
1. 判断 `n % 2 == 1`，是则直接返回 `'a' * n`，此时 `'a'` 出现 n 次（奇数）。
2. 否则返回 `'a' * (n - 1) + 'b'`，`'a'` 出现 `n-1` 次（偶数减一是奇数），`'b'` 出现 1 次。
3. 以 `n = 4` 为例：`n % 2 == 0`，走第二支，`n - 1 = 3`，得到 `"aaa" + "b" = "aaab"`，`'a'` 计 3、`'b'` 计 1，都奇数，长度 4。
4. 以 `n = 7` 为例：走第一支，返回 `"aaaaaaa"`，`'a'` 计 7，奇数，长度 7。

```python
def generateTheString(n: int) -> str:
    if n % 2 == 1:
        return 'a' * n
    return 'a' * (n - 1) + 'b'
```

关键点：偶数情形下 `n - 1` 一定是奇数，所以不需要再调整；`'b'` 只出现一次，天然是奇数，不会和 `'a'` 冲突（不同字符分别计数）。

## 复杂度
时间：O(n)，字符串构造要写 n 个字符。
空间：O(n)，返回串本身占 n 个字符，无其他额外结构。

## 易错点
- `n = 2` 时若写成 `'a' * n` 直接返回，`'a'` 出现 2 次是偶数，不合法；必须走偶数分支得到 `"ab"`，两个字符各 1 次。
- `n = 1` 时若误用偶数分支 `'a' * 0 + 'b'`，虽然 `"b"` 也合法，但说明分支条件写反了；正确判断是 `n % 2 == 1` 走全 `'a'`，`n = 1` 返回 `"a"`。

## 如果面试官追问
问：如果要求恰好用 k 种字符且每种都奇数次，怎么办？
答：先给 k 种字符各 1 个占 k 长度，剩余 `n - k` 必须是偶数才能全加到某一种上，否则无解。
