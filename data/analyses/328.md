## 一句话思路
用 odd/even 两个指针把奇偶索引节点各自串成链，最后 odd 尾接 even 头，原地改指针即可。

## 怎么做
1. 空链表或单节点直接返回 `head`，否则令 `odd = head`、`even = head.next`，并保存 `even_head = even`。
2. 循环条件 `even and even.next`：把 `odd.next` 指向 `even.next`，`odd` 前移；再把 `even.next` 指向 `odd.next`，`even` 前移。
3. 循环结束后 `odd.next = even_head`，把偶链挂到奇链尾部。

以 `[1,2,3,4,5]` 为例：初始 `odd=1, even=2, even_head=2`。第一轮 `odd.next=3`、`odd=3`，`even.next=4`、`even=4`；第二轮 `odd.next=5`、`odd=5`，`even.next=None`、`even=None`，循环退出，此时 `odd=5`，接上 `even_head=2`，得 `1→3→5→2→4`。

```python
if not head or not head.next:
    return head
odd, even = head, head.next
even_head = even
while even and even.next:
    odd.next = even.next
    odd = odd.next
    even.next = odd.next
    even = even.next
odd.next = even_head
return head
```

关键点：`odd` 和 `even` 始终指向各自链的**当前尾**，所以每轮只需改两条 `next`；`even_head` 必须在第一轮前存下，否则偶链头会丢。

## 复杂度
时间 O(n)：每个节点被 `odd` 或 `even` 访问一次。
空间 O(1)：只开了 `odd`、`even`、`even_head` 三个指针。

## 易错点
- 输入 `[1,2]`（n=2）→ 若循环条件写成 `even.next` 而不判 `even`，`even` 为 `None` 时访问 `.next` 报错 → 正确写法是 `while even and even.next`，先判 `even` 非空。
- 输入 `[1]` 或 `[]` → 若不提前返回，`even = head.next` 为 `None`，`even_head` 也是 `None`，最后 `odd.next = None` 虽不崩但逻辑绕 → 正确做法是开头 `if not head or not head.next: return head` 直接短路。

## 如果面试官追问
问：若要求奇偶分组后**偶数组在前**怎么办？
答：交换初始化，令 `even = head`、`odd = head.next`，最后 `even.next = odd_head` 即可，循环体对称改。
