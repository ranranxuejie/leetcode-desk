## 一句话思路
按下标排序后从左往右扫，用指针 `i` 记录原串已消费位置，边拼结果边跳过被替换的字符。

## 怎么做
1. 把 `indices` 和对应 `sources`、`targets` 打包，按 `indices` 升序排序，保证从左到右处理。
2. 维护 `i` 表示原串 `s` 中尚未拼入结果的起点，`res` 存结果。
3. 对每个操作，先判断 `s[indices[j]:indices[j]+len(sources[j])] == sources[j]`；成立则把 `s[i:indices[j]]` 拼上、再拼 `targets[j]`、令 `i = indices[j] + len(sources[j])`；不成立则什么都不做，`i` 不动。
4. 循环结束后补上 `s[i:]`。

以示例 1 为例：排序后仍是 `(0,"a","eee")`、`(2,"cd","ffff")`。第一个操作匹配，`res="eee"`、`i=1`；第二个操作 `s[2:4]=="cd"` 匹配，拼 `s[1:2]="b"` 再拼 `"ffff"`，`res="eeebffff"`、`i=4`；末尾 `s[4:]` 为空。

```python
order = sorted(range(len(indices)), key=lambda j: indices[j])
res, i = [], 0
for j in order:
    p, src, tgt = indices[j], sources[j], targets[j]
    if s[p:p + len(src)] == src:
        res.append(s[i:p])
        res.append(tgt)
        i = p + len(src)
res.append(s[i:])
return "".join(res)
```

关键点：不匹配时**不能**推进 `i`，否则会漏掉原串字符。示例 2 中 `(2,"ec")` 不匹配，`i` 保持 0，最后 `s[0:]` 整段补上，得到 `"eeecd"`。

## 复杂度
时间 O(k log k + n + Σ|targets|)：排序 k 个下标，扫描原串 n，拼接目标串。
空间 O(n + Σ|targets|)：结果列表与排序下标数组。

## 易错点
- 不匹配的操作若也执行 `i = p + len(src)` → 示例 2 会丢掉 `s[0:2]="ab"` 之前的内容，错成 `"cd"` 之类 → 只有匹配分支才更新 `i`。
- 直接对原串做 `s = s[:p] + tgt + s[p+len(src):]` 逐个替换 → 前面的替换改变了长度，后面 `indices` 全部错位，示例 1 第二个操作会从错误位置取 `"cd"` → 必须用 `i` 指针一次性从左到右拼装，绝不动原串。

## 如果面试官追问
若允许重叠替换怎么办？答：题目保证不重叠才使「排序 + 单指针」成立；有重叠时需按区间合并或改用从右往左替换以保下标不变。
