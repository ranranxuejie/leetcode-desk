## 一句话思路
区间记忆化：对每个子串分别数出结果为 True/False 的括号方案数，按最外层运算符合并。

## 怎么做
1. 把 `s` 拆成 `nums`（数字）和 `ops`（运算符），下标 `i` 对应 `nums[i]`，`ops[i]` 连接 `nums[i]` 与 `nums[i+1]`。
2. `dfs(i, j)` 返回 `(t, f)`：`nums[i..j]` 这段表达式得出 True、False 的方案数，用 `memo[(i,j)]` 缓存。
3. `i == j` 时直接返回 `(1,0)` 或 `(0,1)`；否则枚举 `k in [i, j-1]`，把 `ops[k]` 当最外层运算符，左右两段的结果数按 `&`/`|`/`^` 的真值表组合累加。
4. 返回 `dfs(0, len(nums)-1)[result]`。

以 `s = "1^0|0|1"`、`result = 0` 为例，`nums = [1,0,0,1]`、`ops = ['^','|','|']`。取 `k=0`（`^` 为最外层）时，左段 `dfs(0,0)=(1,0)`，右段 `dfs(1,3)` 得 `(2,1)`（`0|0|1` 有两种括号得 True、一种得 False）；`^` 下 False 的方案 = `1*1 + 0*2 = 1`。再取 `k=1`、`k=2` 各贡献 1 和 0，合计 2。

```python
def dfs(i, j):
    if i == j:
        return (1, 0) if nums[i] == 1 else (0, 1)
    if (i, j) in memo:
        return memo[(i, j)]
    t = f = 0
    for k in range(i, j):
        lt, lf = dfs(i, k)
        rt, rf = dfs(k + 1, j)
        if ops[k] == '&':
            t += lt * rt; f += lf * rt + lt * rf + lf * rf
        elif ops[k] == '|':
            t += lt * rt + lt * rf + lf * rt; f += lf * rf
        else:
            t += lt * rf + lf * rt; f += lt * rt + lf * rf
    memo[(i, j)] = (t, f)
    return memo[(i, j)]
```

## 复杂度
时间：状态数 O(n²)，每状态枚举 O(n) 个分割点，共 O(n³)，n 为数字个数。
空间：`memo` 存 O(n²) 个二元组，递归栈 O(n)。

## 易错点
- 输入 `s = "1"`、`result = 1`：若循环写成 `for k in range(i, j)` 而 `i == j` 时没提前返回，`range(1,1)` 为空，`t=f=0`，答案错成 0。必须先处理单数字的 base case。
- 输入 `s = "0&0&0&1^1|0"`：若把 `&` 的 False 只算成 `lf*rf`，漏掉 `lf*rt` 和 `lt*rf`，示例 2 会小于 10。`&` 只要一侧为 False 就为 False，三种组合都要加。
