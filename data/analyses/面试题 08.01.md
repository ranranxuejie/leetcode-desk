## 一句话思路
用滚动三个变量的 DP 递推 `f(n)=f(n-1)+f(n-2)+f(n-3)`，因为最后一步只能是 1/2/3 阶。

## 怎么做
1. 定义 `a, b, c` 分别表示 `f(n-3), f(n-2), f(n-1)`，初值对应 `f(0)=1, f(1)=1, f(2)=2`。
2. 从 `i = 3` 循环到 `n`，每轮算 `d = (a + b + c) % 1000000007`，再整体左移 `a, b, c = b, c, d`。
3. 循环结束返回 `c`（即 `f(n)`）。

以 `n = 5` 为例：初值 `a=1, b=1, c=2`。`i=3` 时 `d=(1+1+2)%M=4`，滚动后 `a=1, b=2, c=4`；`i=4` 时 `d=(1+2+4)=7`，滚动后 `a=2, b=4, c=7`；`i=5` 时 `d=(2+4+7)=13`，返回 `c=13`，与示例一致。

```python
MOD = 1000000007
if n == 1:
    return 1
if n == 2:
    return 2
a, b, c = 1, 1, 2
for i in range(3, n + 1):
    d = (a + b + c) % MOD
    a, b, c = b, c, d
return c
```

关键点：`n=1` 和 `n=2` 必须提前返回，否则循环不执行、返回的 `c=2` 对 `n=1` 是错的。

## 复杂度
时间：O(n)，循环 `n-2` 次，每次常数次加法取模。
空间：O(1)，只开 `a, b, c, d` 四个变量，没有数组。

## 易错点
- `n = 1` → 若直接进循环返回 `c = 2`，会错成 2，正确是 1；`n = 2` 同理必须单独返回 2，因为初值 `c` 恰好是 `f(2)` 但 `n=1` 时 `c` 不是 `f(1)`。
- `n = 1000000` → 若在循环外才取模、或写成 `d = a + b + c` 不取模，Python 虽不溢出但数值会膨胀到天文位数、循环变慢；正确做法是每轮 `d` 立即 `% 1000000007`，且 `a, b, c` 始终保持已取模的值。

## 如果面试官追问
问：若要输出所有具体走法而非计数？答：把滚动变量换成 `list` 存路径，DFS 回溯枚举，规模大时只能输出前若干条或改用生成器。
