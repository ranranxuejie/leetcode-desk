## 一句话思路
用归并排序：快慢指针找中点拆成两半，递归排好再双指针合并，链表天然适合归并。

## 怎么做
1. 递归终止：`head is None or head.next is None` 直接返回 `head`。
2. 快慢指针找中点：`slow` 走一步、`fast` 走两步，结束时 `slow` 停在左半段末尾。
3. 断链：`mid = slow.next; slow.next = None`，得到 `head` 和 `mid` 两条链，分别递归。
4. 合并：哑结点 `dummy` 挂结果，`cur` 尾插，比较两链当前值，最后接上剩余部分。

以 `[4,2,1,3]` 为例：`slow` 停在 `2`，`mid` 指向 `1`，拆成 `[4,2]` 和 `[1,3]`；各自排好为 `[2,4]`、`[1,3]`；合并时先取 `1`，再比 `2` 与 `3` 取 `2`，得 `[1,2,3,4]`。

```python
def merge(a, b):
    dummy = cur = ListNode(0)
    while a and b:
        if a.val <= b.val:
            cur.next, a = a, a.next
        else:
            cur.next, b = b, b.next
        cur = cur.next
    cur.next = a or b
    return dummy.next

slow, fast = head, head.next
while fast and fast.next:
    slow, fast = slow.next, fast.next.next
mid, slow.next = slow.next, None
return merge(sortList(head), sortList(mid))
```

## 复杂度
时间 O(n log n)：每层合并扫 n 个结点，共 log n 层。
空间 O(log n)：递归栈深度，未额外开数组。

## 易错点
- 输入 `[1,2]`：若 `fast` 从 `head` 起步而非 `head.next`，`slow` 会停在 `1` 之后仍指向 `2`，`mid` 变成 `None`，递归死循环。正确做法是 `fast = head.next`，保证左半段至少一个结点、右半段非空。
- 输入 `[2,1]`：合并时若写成 `cur.next = a` 后忘记推进 `a`，或比较用 `<` 而非 `<=`，会丢结点或死循环。正确做法是每次取完立即 `a = a.next`，且 `<=` 保证稳定。

## 如果面试官追问
要求 O(1) 空间怎么办？答：自底向上归并，用 `step = 1, 2, 4...` 按段长切链两两合并，不递归。
