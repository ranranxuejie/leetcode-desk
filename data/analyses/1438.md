## 一句话思路
用滑动窗口 + 两个单调队列分别维护窗口内的最大值和最小值，`max - min <= limit` 时窗口合法。

## 怎么做
1. 右指针 `r` 遍历 `nums`，把 `nums[r]` 从队尾压入 `maxq`（递减）和 `minq`（递增），弹出所有破坏单调性的下标。
2. 检查 `nums[maxq[0]] - nums[minq[0]]`，若大于 `limit`，说明窗口非法，移动左指针 `l` 并弹出队头已过期的下标。
3. 每次窗口合法后更新 `ans = max(ans, r - l + 1)`。

以 `nums = [8,2,4,7], limit = 4` 为例：`r=1` 时窗口 `[8,2]`，`maxq[0]=0`（值 8），`minq[0]=1`（值 2），差 6 > 4，`l` 移到 1，窗口缩为 `[2]`，`ans` 保持 1；`r=2` 时窗口 `[2,4]`，差 2 ≤ 4，`ans=2`。

```python
from collections import deque
maxq, minq = deque(), deque()
l = ans = 0
for r, x in enumerate(nums):
    while maxq and nums[maxq[-1]] <= x:
        maxq.pop()
    maxq.append(r)
    while minq and nums[minq[-1]] >= x:
        minq.pop()
    minq.append(r)
    while nums[maxq[0]] - nums[minq[0]] > limit:
        if maxq[0] == l: maxq.popleft()
        if minq[0] == l: minq.popleft()
        l += 1
    ans = max(ans, r - l + 1)
```

## 复杂度
时间 O(n)：每个下标最多入队、出队各一次，两个队列合计 O(n)。
空间 O(n)：`maxq`、`minq` 最坏各存 n 个下标。

## 易错点
- 输入 `nums = [4,2,2,2,4,4,2,2], limit = 0`：若用 `<=` 判断弹出队尾，重复的 2 会互相弹出，`minq` 只剩一个下标，窗口长度算错；正确做法是队尾比较用 `<=`/`>=` 弹出旧值，但重复值保留最新下标即可，或改用 `<`/`>` 保留全部重复。
- 输入 `nums = [10,1,2,4,7,2], limit = 5`：收缩窗口时只弹 `maxq` 队头忘了弹 `minq`，导致 `minq[0]` 指向已移出窗口的 1，差值算成 6 继续误缩；正确做法是两个队列都检查 `[0] == l` 再 `popleft()`。

## 如果面试官追问
若要求返回具体子数组而非长度？答：在更新 `ans` 时同步记录 `(l, r)`，最后切片 `nums[l:r+1]` 即可，队列逻辑不变。
