## 一句话思路
偶数位有 5 种选法（0/2/4/6/8）、奇数位有 4 种（2/3/5/7），各位独立相乘即 5^ceil(n/2) * 4^floor(n/2)，用快速幂取模。

## 怎么做
1. 数出偶数下标个数 `even = (n + 1) // 2`，奇数下标个数 `odd = n // 2`。
2. 答案 = `pow(5, even, MOD) * pow(4, odd, MOD) % MOD`。
3. 以 n = 4 为例：`even = 2`、`odd = 2`，中间值 `pow(5,2,10**9+7) = 25`、`pow(4,2,10**9+7) = 16`，相乘得 400，与示例一致。
4. 若手写快速幂，循环里对 `base` 和 `res` 都取模，避免中间值膨胀。

```python
MOD = 10**9 + 7
even = (n + 1) // 2
odd = n // 2
ans = pow(5, even, MOD) * pow(4, odd, MOD) % MOD
return ans
```

手写版本（面试要求不用内置 pow 时）：

```python
def qpow(base, exp):
    res = 1
    while exp:
        if exp & 1:
            res = res * base % MOD
        base = base * base % MOD
        exp >>= 1
    return res
```

## 复杂度
时间：O(log n)，快速幂的指数是 ceil(n/2) 和 floor(n/2)，每轮右移一位。
空间：O(1)，只存 `res`、`base`、`exp` 三个整数，无额外数组。

## 易错点
- n = 1 时若把 `even` 写成 `n // 2`，会得 `even = 0`、`odd = 0`，答案变成 1 而非 5；正确是 `even = (n + 1) // 2 = 1`，因为下标 0 属于偶数位。
- n = 50 时若用 `5**25 * 4**25` 直接算再取模，Python 虽不溢出但中间整数有几十位，且若误写成先乘后模在别的语言里会溢出；正确做法是每步 `% MOD`，或用 `pow(5, 25, MOD)` 得 564908303 对应的因子。

## 如果面试官追问
问：若要求返回具体的好数字字符串列表而非计数？
答：计数是各位独立相乘，枚举则要 DFS 按位填候选集，复杂度从 O(log n) 变成 O(答案个数 × n)，n 稍大就不可行。
