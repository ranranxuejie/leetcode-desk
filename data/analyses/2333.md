## 一句话思路
把 k1+k2 合并成总预算 K，只对差值数组 d 做「削峰」：每次把最大差值减 1，平方降得最多，用二分找最终水位。

## 怎么做
1. 令 `d[i] = abs(nums1[i] - nums2[i])`，总预算 `K = k1 + k2`（改 nums1 还是 nums2 对差值等价）。
2. 二分水位 `x`：统计把每个 `d[i]` 削到不超过 `x` 需要的次数 `need = sum(max(0, d[i] - x))`，找最大的 `x` 使 `need <= K`。
3. 剩余 `K - need` 次继续把值为 `x` 的那些元素各减 1，得到答案。

以示例 2 为例：`d = [4,4,4,3]`，`K = 2`。二分得水位 `x = 3`，`need = 1+1+1+0 = 3 > 2`，故 `x = 4` 时 `need = 0`，取 `x = 4`；剩余 2 次把两个 4 削成 3，最终 `d = [3,3,4,3]`，平方和 `9+9+16+9 = 43`。

```python
d = [abs(a - b) for a, b in zip(nums1, nums2)]
K = k1 + k2
if sum(d) <= K:
    return 0
lo, hi = 0, max(d)
while lo < hi:
    mid = (lo + hi + 1) // 2
    if sum(max(0, v - mid) for v in d) <= K:
        lo = mid
    else:
        hi = mid - 1
x = lo
need = sum(max(0, v - x) for v in d)
rest = K - need
ans = 0
for v in d:
    if v > x:
        ans += x * x
    elif v == x and rest > 0:
        ans += (x - 1) ** 2
        rest -= 1
    else:
        ans += v * v
return ans
```

## 复杂度
时间：O(n log(max d))，n 来自建 d 与两次求和，log 来自二分水位。
空间：O(n) 存差值数组 d，无其他额外结构。

## 易错点
- `sum(d) <= K` 时若仍走二分，`x` 会停在 0，但剩余次数 `rest` 可能把 0 削成负数，平方反而变大；必须先判 `sum(d) <= K` 直接返回 0。
- 剩余次数分配时，只对 `v == x` 的元素减 1，且 `rest` 可能大于等于 `x` 的个数；若写成 `v >= x` 会把已削到 x 以下的元素再减，答案偏小。

## 如果面试官追问
问：k1、k2 不能合并时怎么办？答：改 nums1 和改 nums2 对差值完全对称，合并 K 不改变可行域，答案不变。
