## 一句话思路
把每个数拆成质因子，用并查集把「同一质因子」的下标连起来，最后看是否只剩一个连通块。

## 怎么做
1. 预处理 `max(nums)` 以内的最小质因子表 `spf`，用于 O(log v) 拆因子。
2. 对每个下标 `i`，把 `nums[i]` 拆成互不相同的质因子，用字典 `owner[p]` 记录质因子 `p` 第一次出现的下标，后续同因子的下标直接 `union(i, owner[p])`。
3. 最后统计根节点个数，等于 1 返回 `True`。

以 `nums = [2,3,6]` 为例：`i=0` 拆出 `{2}`，`owner[2]=0`；`i=1` 拆出 `{3}`，`owner[3]=1`；`i=2` 拆出 `{2,3}`，分别与 0、1 合并，三个下标同根，返回 `True`。

```python
spf = list(range(m + 1))
for i in range(2, int(m ** 0.5) + 1):
    if spf[i] == i:
        for j in range(i * i, m + 1, i):
            if spf[j] == j:
                spf[j] = i
owner, parent = {}, list(range(n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
for i, v in enumerate(nums):
    while v > 1:
        p = spf[v]
        if p in owner:
            parent[find(i)] = find(owner[p])
        else:
            owner[p] = i
        while v % p == 0:
            v //= p
return len({find(i) for i in range(n)}) == 1
```

## 复杂度
时间：O(n log V + V log log V)，n 是数组长度，V = max(nums)，筛表与拆因子各占一半。
空间：O(V + n)，spf 表 V 个、owner 字典最多 V 个质因子、parent 数组 n 个。

## 易错点
- `nums` 含 1 → 1 没有质因子，永远孤立，直接返回 `False`；但 `nums = [1]` 单元素时无下标对，应返回 `True`，需先判 `n == 1`。
- 拆因子时不去重（如 12 拆出 2,2,3）→ 同一质因子重复 union 自己，虽不致命但会拖慢；正确做法是内层 `while v % p == 0: v //= p` 把 p 除干净，保证每个质因子只处理一次。

## 如果面试官追问
若 nums 长度放大到 10^6 且值域不变，怎么优化？答：把 owner 换成按质因子预分配的数组，避免字典哈希开销，并复用同一 spf 表。
