## 一句话思路
每个标记只能左移一格，所以下标 i 的标记只能覆盖 i 或 i-1；从左往右贪心，能左移就左移，把位置让给右边更值钱的标记。

## 怎么做
1. 从左往右扫，维护 `carry` 表示「当前下标 i 上有一个可用的标记」。
2. 若 `s[i] == '1'`，先看 `carry`：若 `carry` 为真，说明 i-1 已被占，标记只能留在 i；否则标记左移到 i-1。
3. 若 `s[i] == '0'` 且 `carry` 为真，标记落在 i。
4. 每确定一个落点就累加 `nums[落点]`。

用示例 1 `nums=[9,2,6,1], s="0101"`：i=0 时 `s[0]='0'`、`carry=False`，跳过；i=1 时 `s[1]='1'`、`carry=False`，标记左移到 0，累加 `nums[0]=9`，`carry=False`；i=2 时 `s[2]='0'`、`carry=False`，跳过；i=3 时 `s[3]='1'`、`carry=False`，标记左移到 2，累加 `nums[2]=6`，合计 15。

```python
total = 0
carry = False          # 下标 i 处是否有待安置的标记
for i in range(n):
    if s[i] == '1':
        if carry:      # i-1 已被占，只能留在 i
            total += nums[i]
        else:          # 左移到 i-1
            if i > 0:
                total += nums[i - 1]
            carry = True
    elif carry:        # s[i]=='0' 且上一格有标记
        total += nums[i]
        carry = False
```

注意 `i == 0` 且 `s[0] == '1'` 时标记无处可移，只能留在 0，代码里 `i > 0` 分支已处理。

## 复杂度
时间：O(n)，一次线性扫描，每个下标只判断常数次。
空间：O(1)，只用了 `total` 和 `carry` 两个变量。

## 易错点
- 输入 `s="1..."` 且 `i=0`：若直接写 `total += nums[i-1]`，Python 会取到 `nums[-1]`（最后一个元素），答案凭空多出末尾值。正确做法是先判 `i > 0`，i=0 的标记只能留在原位。
- 输入 `s="11"`、`nums=[1,100]`：两个标记相邻，i=1 的标记不能左移到 0（已被 i=0 的标记占住），若忽略 `carry` 直接左移会重复累加 `nums[0]`。正确做法是用 `carry` 记录占用状态，`carry` 为真时标记留在 i。

## 如果面试官追问
若允许标记右移一格，贪心方向怎么变？答：从右往左扫，对称处理，`carry` 表示右侧格子是否被占。
