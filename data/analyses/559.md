## 一句话思路
用后序 DFS：根的最大深度 = 1 + 所有子树深度的最大值，空树返回 0。

## 怎么做
1. 递归出口：`root is None` 时返回 0。
2. 对 `root.children` 逐个递归，收集每个子树的深度。
3. 取 `max` 后加 1 返回；`children` 为空时 `max` 的默认值取 0，正好得到叶子深度 1。

拿示例 1 的 `root = [1,null,3,2,4,null,5,6]` 走一遍：节点 3 的 `children` 是 `[5,6]`，两次递归都返回 1，`max([1,1]) + 1 = 2`；根节点 1 的 `children` 是 `[3,2,4]`，深度分别是 `[2,1,1]`，`max(...) + 1 = 3`，与输出一致。

```python
def dfs(node):
    if node is None:
        return 0
    best = 0
    for child in node.children:
        best = max(best, dfs(child))
    return best + 1

return dfs(root)
```

关键点是 `best` 初始化为 0 而不是 1：叶子节点循环一次都不进，`0 + 1 = 1` 才对；若初始化成 1，叶子会返回 2，整棵树深度全部偏大。

## 复杂度
时间 O(n)：每个节点恰好被 `dfs` 访问一次，`max` 比较的是子节点个数，总和为 n-1。
空间 O(h)：递归栈深度等于树高 h，最坏链状 h = n，题目保证 h ≤ 1000。

## 易错点
- 输入 `root = []`（节点数可为 0）→ 若直接写 `root.children` 会抛 `AttributeError`，或返回 1 → 必须先判 `root is None` 返回 0，答案应是 0 而不是 1。
- 叶子节点 `children == []` → 若把 `best` 初始化成 1 或写成 `max(dfs(c) for c in node.children)` 不加 `default`，前者深度整体 +1，后者对空序列抛 `ValueError` → 用 `best = 0` 配合 `max(best, ...)` 的循环写法，空 children 自然得 1。

## 如果面试官追问
问：节点数涨到 10^6、深度可能上万，递归会栈溢出怎么办？
答：改成显式栈存 `(node, depth)` 做迭代 DFS，或直接 BFS 按层计数，空间仍是 O(宽度)。
