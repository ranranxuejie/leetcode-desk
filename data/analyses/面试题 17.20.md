## 一句话思路
用一个大顶堆存较小的一半、一个小顶堆存较大的一半，保持两堆大小差不超过 1，中位数只从堆顶取。

## 怎么做
1. 维护 `small`（存较小一半，用负数模拟大顶堆）和 `large`（存较大一半，小顶堆），始终保证 `len(small) == len(large)` 或 `len(small) == len(large) + 1`。
2. `addNum` 先压入 `small`，再把 `small` 的最大值弹给 `large`，若 `large` 比 `small` 多则弹回一个。
3. `findMedian` 若两堆等长取两堆顶平均，否则取 `small` 堆顶。

以官方示例走一遍：`addNum(1)` 后 `small=[-1]`、`large=[]`，`findMedian` 返回 `1`；`addNum(2)` 时先 `heappush(small,-2)` 得 `small=[-2,-1]`，弹出 `-2` 压入 `large` 得 `large=[2]`，此时 `small=[-1]`、`large=[2]`，等长，返回 `(-small[0]+large[0])/2 = (1+2)/2 = 1.5`；`addNum(3)` 后 `small=[-2,-1]`、`large=[3]`，`small` 多一个，返回 `-small[0] = 2`。

```python
import heapq

def addNum(self, num):
    heapq.heappush(self.small, -num)
    heapq.heappush(self.large, -heapq.heappop(self.small))
    if len(self.large) > len(self.small):
        heapq.heappush(self.small, -heapq.heappop(self.large))

def findMedian(self):
    if len(self.small) > len(self.large):
        return float(-self.small[0])
    return (-self.small[0] + self.large[0]) / 2
```

关键在 `addNum` 里「先压 `small` 再转手 `large`」这一步：它同时完成了排序归位和大小平衡，不用写两套分支判断。

## 复杂度
时间：`addNum` 每次 3 次堆操作，各 O(log n)，n 为已插入元素数；`findMedian` O(1)。
空间：两个堆合计存 n 个元素，额外 O(n)。

## 易错点
- 输入 `addNum(1), addNum(2)` 后直接返回 `small[0]` 而不判断等长 → 会错成 `1` 而非 `1.5` → 必须先判 `len(small) > len(large)` 才取单堆顶，否则取平均。
- 只往 `small` 压、忘了把最大值转给 `large`（如连续 `addNum(5), addNum(1)`）→ `small` 会堆成 `[-5,-1]`、`large` 空，中位数错成 `1` 而非 `3` → 每次插入都要执行「压 `small` → 弹最大给 `large` → 必要时弹回」的完整三步。

## 如果面试官追问
追问：数据规模到 10^7 且要求 O(1) 查询怎么办？
答：仍用双堆，查询本就是 O(1)，瓶颈在插入的 log n，可换用有序容器或平衡树，但堆已是最简实现。
