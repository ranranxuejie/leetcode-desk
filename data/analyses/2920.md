## 一句话思路
对每个节点按「祖先用了几次除二」做记忆化 DFS，状态 `(u, t)` 表示节点 u 已被祖先除二 t 次时的子树最大积分。

## 怎么做
1. 用 `edges` 建邻接表，从 0 出发 DFS，传入父节点避免回头。
2. 状态里带 `t`（祖先用第二种方法的次数），节点 u 的实际金币是 `coins[u] >> t`。
3. 在 `(u, t)` 上二选一：取 `(coins[u] >> t) - k` 且子节点仍用 `t`；或取 `(coins[u] >> t) // 2` 且子节点用 `t + 1`，两者取大。
4. `t` 超过约 14 后 `coins[u] >> t` 恒为 0，可截断，避免状态爆炸。

以示例 1 为例，`coins = [10,10,3,3]`、`k = 5`：节点 2 在 `t = 0` 时若选第二种，得 `3 // 2 = 1`，同时把 `t = 1` 传给节点 3，节点 3 的金币变成 `3 >> 1 = 1`，再取 `1 // 2 = 0`，累计 `5 + 5 + 1 + 0 = 11`。

```python
from functools import lru_cache

@lru_cache(None)
def dfs(u, t):
    t = min(t, 14)
    val = coins[u] >> t
    take_all = val - k
    take_half = val // 2
    for v in adj[u]:
        if v == parent[u]:
            continue
        take_all += dfs(v, t)
        take_half += dfs(v, t + 1)
    return max(take_all, take_half)
```

## 复杂度
时间：状态数 `n × 15`，每条边在每层被扫一次，共 `O(15n)`。
空间：`lru_cache` 存 `15n` 个结果，加邻接表 `O(n)`。

## 易错点
- 把 `t` 当成全局变量在 DFS 里累加 → 同一节点被不同祖先路径访问时结果串味，示例 1 中节点 3 会算成 `3 >> 2` 而非 `3 >> 1`；正确做法是把 `t` 作为 `dfs` 参数随递归下传。
- 不截断 `t` → `coins[i] = 10^4` 时 `t` 可涨到 14 以上，状态数退化成 `n × 深度`，链状树直接超时；正确做法是 `t = min(t, 14)`，因为 `10^4 >> 14 = 0`。

## 如果面试官追问
问：若要求输出每个节点用了哪种方法？
答：在 `dfs` 里记录选 `take_all` 还是 `take_half` 的分支，回溯时按 `(u, t)` 还原路径即可。
