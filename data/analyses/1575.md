## 一句话思路
用 `dfs(i, rest)` 记忆化：从城市 i 剩 rest 油到 finish 的路径数，因为状态只由 (i, rest) 决定。

## 怎么做
1. 状态定义为 `dfs(i, rest)`，返回从 i 出发、剩余 rest 油到达 finish 的路径数。
2. 递归时枚举所有 j != i，若 `cost = abs(locations[i]-locations[j]) <= rest` 就累加 `dfs(j, rest-cost)`。
3. 边界：`i == finish` 时先计 1（空路径算一条），再继续枚举后续绕行。
4. 用 `@lru_cache` 或二维数组 `memo[i][rest]` 存结果，取模 `10**9+7`。

以示例 1 为例：`locations=[2,3,6,8,4], start=1, finish=3, fuel=5`。`dfs(1,5)` 枚举 j=3 时 cost=5，`dfs(3,0)` 因 i==finish 返回 1；枚举 j=4 时 cost=1，进入 `dfs(4,4)`，其中 j=3 cost=4 得 1、j=2 cost=2 再进 `dfs(2,2)` 得 1，合计 4。

```python
from functools import lru_cache
MOD = 10**9 + 7

@lru_cache(None)
def dfs(i, rest):
    ans = 1 if i == finish else 0
    for j in range(n):
        if j == i:
            continue
        c = abs(locations[i] - locations[j])
        if c <= rest:
            ans += dfs(j, rest - c)
    return ans % MOD

return dfs(start, fuel)
```

## 复杂度
时间：O(n² · fuel)，状态数 n·fuel，每状态枚举 n 个城市。
空间：O(n · fuel) 记忆化表，加递归栈深度 ≤ fuel。

## 易错点
1. 把 `i == finish` 直接 return 1 而不继续枚举 → 示例 2 中 `1->0->1->0` 这类回到 finish 再出发的路径会漏，答案从 5 错成 3。正确做法是先 `ans = 1` 再继续 for 循环。
2. 忘记对每层累加结果取模 → 城市多、fuel=200 时路径数远超 `2**31-1`，题目要求按 `10**9+7` 取余；Python 整数不溢出，但结果必须 `% MOD` 才能对上答案。

## 如果面试官追问
问：fuel 放大到 10^9 怎么办？
答：fuel 维度不可行，需换思路——本题依赖 fuel ≤ 200 才能 DP，放大后一般无多项式解，可指出这是约束驱动的算法选择。
