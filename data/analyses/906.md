## 一句话思路
枚举回文根 `r`，判断 `r*r` 是否回文且落在 `[left, right]`，因为根最多 9 位、回文根只有约 10 万个。

## 怎么做
1. 把 `left`、`right` 转成 `int`，算出根的上界 `hi = isqrt(right)`，下界 `lo = isqrt(left-1)+1` 只用于剪枝。
2. 按长度 `L` 生成回文根：取前 `(L+1)//2` 位做前缀，镜像后得到 `r`，只保留 `lo <= r <= hi` 的。
3. 对每个 `r` 算 `sq = r*r`，用 `str(sq) == str(sq)[::-1]` 判回文，再判 `left <= sq <= right`，计数。

以 `left="4", right="1000"` 为例：`hi = isqrt(1000) = 31`，枚举到的根是 1,2,3,11,22；`r=11` 时 `sq=121` 回文且入区间，`r=22` 时 `sq=484` 同理；`r=26` 根本不在回文根集合里，所以 676 天然被排除。

```python
from math import isqrt
def gen(L):
    half = (L + 1) // 2
    for p in range(10**(half-1), 10**half):
        s = str(p)
        r = int(s + s[-1-(L%2)::-1]) if L % 2 else int(s + s[::-1])
        yield r
cnt = 0
for L in range(1, 10):
    for r in gen(L):
        sq = r * r
        if sq < left or sq > right:
            continue
        if str(sq) == str(sq)[::-1]:
            cnt += 1
```

## 复杂度
时间：枚举约 2×10^5 个回文根，每个做 O(log right) 的字符串回文判断。
空间：只存当前 `r` 和 `sq` 的字符串，O(log right) 额外空间。

## 易错点
- `left="1", right="2"`：若从 `r=1` 起判 `sq=1` 就漏了 `1` 本身是超级回文数（1=1²，1 是回文）→ 正确做法是根从 1 开始枚举，`sq=1` 要计入，答案是 1 不是 0。
- `right` 接近 `10**18-1`：若用 `isqrt(right)` 后仍按 `L<=9` 生成，`r=10**9` 时 `sq=10**18` 超界 → 生成时用 `lo <= r <= hi` 剪枝，且 `L` 上界取 `len(str(hi))`，别硬写 9。

## 如果面试官追问
问：若 `right` 放宽到 `10**36` 怎么办？
答：根到 18 位，回文根约 2×10^9 个，枚举根会超时，需改用「回文平方数」的构造性质（根本身必为回文且长度受限）或直接打表。
