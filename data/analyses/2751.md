## 一句话思路
按位置排序后从左到右扫，用栈存「还没被撞掉的 R」，遇到 L 就与栈顶反复对撞。

## 怎么做
1. 把 `(positions[i], healths[i], directions[i])` 按位置升序排，得到从左到右的机器人序列。
2. 顺序遍历：遇到 `'R'` 直接压栈；遇到 `'L'` 且栈非空，说明栈顶的 R 在它左边、相向而行，必撞。
3. 碰撞循环：比较栈顶健康度 `h` 与当前 `cur`。`h > cur` → 栈顶 `h -= 1`，当前机器人消失；`h < cur` → 弹栈，`cur -= 1` 继续撞下一个；相等 → 弹栈且当前消失。
4. 遍历完，栈里剩下的 R 和从未入栈的 L 都幸存，按原始下标回填答案。

以示例 2 为例：排序后为 `(2,15,'L'), (3,10,'R'), (5,10,'L'), (6,12,'R')`。扫到位置 5 的 L 时栈顶是 `(3,10,'R')`，健康度相等，两者同归于尽，栈空；位置 6 的 R 入栈。最终只剩位置 2 的 L 和位置 6 的 R，但位置 2 在左、方向 L，位置 6 在右、方向 R，二者背向而行不再碰撞，答案 `[14]` 来自位置 2 的 L 与位置 6 的 R 各自幸存——注意示例解释里说的「机器人 3 和机器人 4」是按输入编号，排序后对应位置 2 和 6。

```python
order = sorted(range(n), key=lambda i: positions[i])
stack, alive = [], {}
for i in order:
    if directions[i] == 'R':
        stack.append(i)
    else:
        cur = healths[i]
        while stack and cur > 0:
            j = stack[-1]
            if healths[j] > cur:
                healths[j] -= 1
                cur = 0
            elif healths[j] < cur:
                stack.pop()
                cur -= 1
            else:
                stack.pop()
                cur = 0
        if cur > 0:
            alive[i] = cur
for j in stack:
    alive[j] = healths[j]
return [alive[i] for i in range(n) if i in alive]
```

## 复杂度
时间 O(n log n)：排序主导，每个机器人最多入栈出栈各一次，碰撞总次数 O(n)。
空间 O(n)：栈和 `alive` 字典各存至多 n 个下标。

## 易错点
- `positions` 乱序（如示例 1 的 `[5,4,3,2,1]`）→ 直接按下标扫会把不相邻的机器人当成相邻，漏撞或错撞 → 必须先按位置排序，再用原始下标回填。
- 一个 L 可能连撞多个 R（如 `healths=[1,1,5]`、方向 `RRL`）→ 只比一次就收手，会让健康度 5 的 L 少减 → 必须用 `while stack and cur > 0` 循环，每撞掉一个 R 就 `cur -= 1` 继续。

## 如果面试官追问
问：若要求输出碰撞发生的先后顺序（哪两个机器人第几次相撞）？
答：栈里存下标的同时记录入栈时间戳，每次弹栈时把 `(栈顶下标, 当前下标)` 追加到事件列表，最后按时间戳排序输出即可。
