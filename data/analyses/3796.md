## 一句话思路
先把每个位置的上界用 diff 从左右各扫一遍压紧，再从左往右贪心取到上界。

## 怎么做
1. 建 `cap = [inf]*n`，`cap[0]=0`，把 `restrictions` 写进对应位置。
2. 从左往右：`cap[i] = min(cap[i], cap[i-1] + diff[i-1])`。
3. 从右往左：`cap[i] = min(cap[i], cap[i+1] + diff[i])`。
4. 再从左往右贪心：`a[i] = min(cap[i], a[i-1] + diff[i-1])`，答案取 `max(a)`。

以示例 1 为例，`cap[3]` 初值 1，左扫后 `cap[4]=min(inf,1+1)=2`；右扫时 `cap[7]=min(inf,1+1)=2`，`cap[6]=min(inf,2+1)=3`，`cap[5]=min(inf,3+4)=7`。于是 `cap[5]=7`，但左扫已给出 `cap[5]=min(inf,2+4)=6`，取 6——这就是答案 6 的来源。

```python
INF = 10**18
cap = [INF] * n
cap[0] = 0
for idx, mx in restrictions:
    cap[idx] = min(cap[idx], mx)
for i in range(1, n):
    cap[i] = min(cap[i], cap[i-1] + diff[i-1])
for i in range(n-2, -1, -1):
    cap[i] = min(cap[i], cap[i+1] + diff[i])
ans = cur = 0
for i in range(1, n):
    cur = min(cap[i], cur + diff[i-1])
    ans = max(ans, cur)
```

## 复杂度
时间：O(n)，三次线性扫描，restrictions 长度不超过 n。
空间：O(n)，额外开了 cap 数组。

## 易错点
- 只做左扫不做右扫：示例 1 中 `cap[5]` 左扫得 6，但 `cap[8]=1` 会反向压紧 `cap[7]=2`、`cap[6]=3`，漏掉右扫会让 `cap[6]` 停在 4，贪心时可能冲出限制。正确做法是两遍都扫。
- 把 `cap[0]=0` 当成普通 restriction 处理：若 restrictions 里没有 idx=0（题面保证 idx≥1），忘记初始化 `cap[0]=0` 会让左扫从 INF 起步，`cap[1]` 变成 `min(INF, INF+diff[0])`，整条链失效。正确做法是显式置 `cap[0]=0`。

## 如果面试官追问
要求输出方案而非最大值？答：贪心那一步把 `cur` 存进数组 `a`，返回 `a` 即可，`a[i]=min(cap[i], a[i-1]+diff[i-1])` 本身就是一个合法最优序列。
