## 一句话思路
用排序后的字符串当哈希键，从左往右扫，只保留与上一个保留词键不同的词。

## 怎么做
1. 对每个 `words[i]` 求 `key = ''.join(sorted(words[i]))`，异位词排序后必然相同。
2. 维护 `res` 和 `last_key`，初始 `last_key = None`。
3. 遍历 `words`，若 `key != last_key` 就 `res.append(w)` 并更新 `last_key = key`，否则跳过。
4. 返回 `res`。

以 `["abba","baba","bbaa","cd","cd"]` 为例：三个词的 key 都是 `"aabb"`，第一个 `"abba"` 进 `res`、`last_key="aabb"`；`"baba"`、`"bbaa"` 的 key 与 `last_key` 相等被跳过；`"cd"` 的 key 是 `"cd"` 不等于 `"aabb"`，进 `res` 并更新 `last_key="cd"`；第二个 `"cd"` 被跳过。结果 `["abba","cd"]`。

```python
res = []
last_key = None
for w in words:
    key = ''.join(sorted(w))
    if key != last_key:
        res.append(w)
        last_key = key
return res
```

关键点：删除是「连锁」的——`"bbaa"` 被删后 `"baba"` 才和 `"abba"` 相邻。但排序键相同意味着这一整段连续异位词最终只会剩第一个，所以不必真的模拟删除，直接和「上一个保留词」比即可。

## 复杂度
时间 O(n·L log L)：n 个词，每个词长度 L≤10 排序贡献 L log L。
空间 O(n·L)：`res` 存结果，`last_key` 只存一个键。

## 易错点
- 拿 `words[i]` 和 `words[i-1]` 原串比相邻：`["abba","baba","bbaa"]` 里 `"bbaa"` 与 `"baba"` 相邻但原串不等，会漏删。必须比排序后的 key。
- 用 `set(w)` 当键：`"abba"` 和 `"aab"` 的 set 都是 `{'a','b'}`，会被误判为异位词。必须用 `sorted` 保留重复字母计数。

## 如果面试官追问
若 words 长度到 10^5、单词长度到 10^3，排序键太贵怎么办？答：改用 26 长度计数数组转元组当键，O(n·L) 建键，代价是键更长。
