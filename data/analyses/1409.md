## 一句话思路
用树状数组维护「空位」计数，把每个值映射到 m+q 长度数组的固定槽位，查询即前缀和。

## 怎么做
1. 开长度 `n = m + len(queries)` 的树状数组，初始把下标 `len(queries)` 到 `n-1` 全部置 1（代表 P 的 m 个元素），前 `len(queries)` 个位置留空给「移到开头」用。
2. 用 `pos[v]` 记录值 v 当前所在的下标，初始 `pos[v] = len(queries) + v - 1`。
3. 对每个 `q`，答案 = `bit.query(pos[q] - 1)`，即它左边还有多少个元素；然后把 `pos[q]` 处减 1，把新槽位 `len(queries) - 1 - i` 置 1，更新 `pos[q]`。
4. 新槽位从 `len(queries)-1` 往前递减，保证每次「移到开头」都落在更靠前的位置。

以 `queries=[3,1,2,1], m=5` 为例，`n=9`，初始 1 在 `pos[1]=4`…`pos[5]=8`。处理 `q=3` 时 `pos[3]=6`，前缀和 `query(5)=2`，正是答案 2；随后 `pos[3]` 改为 `3`（`len(queries)-1-0=3`）。

```python
n = m + len(queries)
bit = [0] * (n + 1)
pos = [0] * (m + 1)
for v in range(1, m + 1):
    pos[v] = len(queries) + v - 1
    i = pos[v] + 1
    while i <= n:
        bit[i] += 1
        i += i & -i
res = []
for k, q in enumerate(queries):
    i = pos[q]
    s = 0
    j = i
    while j > 0:
        s += bit[j]
        j -= j & -j
    res.append(s)
    # 旧位置 -1，新位置 +1，更新 pos[q]
```

## 复杂度
时间：每个 query 两次树状数组操作，O((m+q) log(m+q))，q 为 queries 长度。
空间：bit 与 pos 各 O(m+q)，无其他额外结构。

## 易错点
- 新槽位方向写反（用 `len(queries)+i` 往后放）→ 前缀和会把「已移到开头」的元素算到后面，`[3,1,2,1]` 第 2 步会得 3 而非 1 → 必须从 `len(queries)-1` 往前递减分配。
- 忘记把旧位置 `pos[q]` 清零只加新位置 → 同一个值出现两次（如示例 1 的 1）时前缀和偏大 → 每次移动必须「旧位 -1、新位 +1」成对更新。

## 如果面试官追问
若 m 和 queries 都放大到 10^5 且要求输出最终排列 P？答：同一套树状数组按槽位顺序取前缀和为 1 的下标即可还原，复杂度不变。
