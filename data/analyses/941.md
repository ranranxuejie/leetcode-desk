## 一句话思路
双指针从两端向中间爬，左指针只许上坡、右指针只许下坡，最后必须停在同一个峰顶。

## 怎么做
1. 长度小于 3 直接返回 `False`，因为山脉至少要有一个上坡加一个下坡。
2. `i = 0` 从左边走，只要 `arr[i] < arr[i+1]` 就 `i += 1`，停在第一个不再上升的位置。
3. `j = len(arr) - 1` 从右边走，只要 `arr[j] < arr[j-1]` 就 `j -= 1`，停在第一个不再下降的位置。
4. 返回 `i == j and i != 0 and i != len(arr) - 1`，即两指针汇合且峰顶不在两端。

拿示例 3 `arr = [0,3,2,1]` 走一遍：左指针 `i` 从 0 开始，`0<3` 走到 1，`3<2` 不成立停在 `i=1`；右指针 `j` 从 3 开始，`1<2` 走到 2，`2<3` 走到 1，`3<0` 不成立停在 `j=1`。`i == j == 1`，且 `1 != 0`、`1 != 3`，返回 `True`。

```python
n = len(arr)
if n < 3:
    return False
i = 0
while i + 1 < n and arr[i] < arr[i + 1]:
    i += 1
j = n - 1
while j - 1 >= 0 and arr[j] < arr[j - 1]:
    j -= 1
return i == j and i != 0 and i != n - 1
```

关键在最后那行：`i == j` 保证上坡段和下坡段接在同一个峰顶，两个 `!=` 排除纯递增（`i` 冲到末尾）和纯递减（`j` 冲到 0）这两种「只有半座山」的情况。

## 复杂度
时间 O(n)：`i` 和 `j` 合计最多扫过整个数组一遍。
空间 O(1)：只开了 `i`、`j`、`n` 三个整数变量。

## 易错点
- `arr = [0,1,2,3,4]` 纯递增 → 只写 `i == j` 会返回 `True`（`i` 和 `j` 都停在 4）→ 必须加 `i != n - 1`；对称地 `[4,3,2,1,0]` 要加 `i != 0`。
- `arr = [3,5,5]` 有平台 → 若用 `<=` 判断上坡，`i` 会越过相等段继续走，把非严格递增误判成合法 → 严格用 `<`，相等时立刻停，此时 `i=1`、`j=2`，`i != j` 返回 `False`。

## 如果面试官追问
问：如果要求返回峰顶下标而不是布尔值？
答：直接返回 `i`，但先判 `i == j and i != 0 and i != n - 1`，不满足返回 `-1`。
