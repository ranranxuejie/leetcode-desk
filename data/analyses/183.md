## 一句话思路
用 `Customers` 左连接 `Orders`，筛出 `customerId` 为 `None` 的行，这些客户从未下过单。

## 怎么做
1. 对 `Customers` 按 `id` 左连接 `Orders`，连接键是 `Customers.id == Orders.customerId`。
2. 左连接保留所有客户，没下过单的客户在 `Orders` 侧字段全为 `None`。
3. 用 `customerId.isna()` 过滤，取 `name` 列并重命名为 `Customers`。

以官方示例为例：`Customers` 有 id 1~4，`Orders` 的 `customerId` 只有 3 和 1。左连接后，id=2（Henry）和 id=4（Max）对应的 `customerId` 为 `None`，id=1 和 id=3 分别匹配到订单 2 和 1，被过滤掉。

```python
import pandas as pd

def find_customers(customers: pd.DataFrame, orders: pd.DataFrame) -> pd.DataFrame:
    merged = customers.merge(
        orders,
        how="left",
        left_on="id",
        right_on="customerId",
    )
    result = merged[merged["customerId"].isna()][["name"]]
    return result.rename(columns={"name": "Customers"})
```

关键中间值：`merged` 共 4 行（左连接不丢客户），`merged["customerId"]` 为 `[3.0, 1.0, NaN, NaN]`，`isna()` 得到 `[False, False, True, True]`，取 `name` 后正是 `["Henry", "Max"]`。

## 复杂度
时间：O(n + m)，n 为 `Customers` 行数，m 为 `Orders` 行数，连接与过滤各扫一遍。
空间：O(n + m)，`merge` 生成中间表，额外开了结果列。

## 易错点
- 用内连接（`how="inner"`）→ 只留下下过单的 Joe 和 Sam，输出反了 → 必须用 `how="left"` 保留全部客户。
- 过滤条件写成 `merged["id"].isna()` → `id` 来自 `Customers` 侧永不为空，结果为空表 → 要判 `Orders` 侧的 `customerId`，它才是左连接后可能为 `None` 的列。

## 如果面试官追问
问：如果 `Orders` 里同一客户有多条订单，左连接会不会让结果重复？
答：会，但本题只筛 `customerId` 为 `None` 的客户，这些客户在 `Orders` 中零匹配，不会重复；若改为统计下单次数则需先 `groupby` 去重。
