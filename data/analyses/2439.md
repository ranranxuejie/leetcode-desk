## 一句话思路
二分答案 `x`，从左往右把每个 `nums[i]` 超出 `x` 的部分推给左边，看 `nums[0]` 是否被推爆。

## 怎么做
1. 答案下界 `lo = 0`，上界 `hi = max(nums)`（操作只往左推，最大值不会变大）。
2. 对候选 `x` 做 `check`：从右往左（或从左往右累积）把 `nums[i] - x` 的正数部分加到 `nums[i-1]` 上，若 `nums[0]` 最终超过 `x` 则不可行。
3. 二分收缩，返回 `lo`。

以 `nums = [3,7,1,6]`、`x = 5` 为例：`i=3` 时 `6-5=1` 推给 `nums[2]`，`nums[2]` 变 `2`；`i=2` 时 `2-5<0` 不推；`i=1` 时 `7-5=2` 推给 `nums[0]`，`nums[0]` 变 `5`，恰好不超过 `5`，可行。而 `x = 4` 时 `i=1` 推 `3` 给 `nums[0]`，`nums[0]` 变 `6 > 4`，不可行。

```python
def check(x):
    carry = 0
    for v in reversed(nums):
        carry = max(0, carry + v - x)
    return carry == 0

lo, hi = 0, max(nums)
while lo < hi:
    mid = (lo + hi) // 2
    if check(mid):
        hi = mid
    else:
        lo = mid + 1
return lo
```

注意 `carry` 用「累积超出量」写法：`carry = max(0, carry + v - x)`，最后 `carry == 0` 表示最左端也没溢出。

## 复杂度
时间：二分 `log(max(nums))` 轮，每轮扫 `n` 个元素，共 `O(n log M)`。
空间：只用了 `carry`、`lo`、`hi`、`mid` 几个变量，`O(1)`。

## 易错点
- 输入 `nums = [10,1]` → 若把上界设成 `sum(nums)//n = 5` 会错成 `5`，但 `nums[0]=10` 无法减小，正确答案是 `10`；上界必须取 `max(nums)`。
- 输入 `nums = [0,0,0]` → 若 `lo` 从 `1` 开始或 `check` 里用 `carry > 0` 判断会错成 `1`；`x=0` 本身可行，`lo` 要从 `0` 起，且判断条件是 `carry == 0`。

## 如果面试官追问
要求输出具体操作方案怎么办？答：二分定下 `x` 后，再从右往左模拟一次推数，记录每次 `nums[i]` 减了多少、`nums[i-1]` 加了多少即可。
