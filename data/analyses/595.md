## 一句话思路
用 `WHERE` 对 `area` 和 `population` 做 `OR` 过滤，再 `SELECT` 出三列即可。

## 怎么做
1. 过滤条件写成 `area >= 3000000 OR population >= 25000000`，两个阈值是「至少」，必须带等号。
2. 用 `OR` 而不是 `AND`：题面是「满足两个条件之一」。
3. 输出列顺序是 `name, population, area`，注意 `population` 在 `area` 前面，和表定义顺序不同。
4. 无需 `ORDER BY`，题面允许任意顺序。

拿官方示例走一遍：Afghanistan 的 `area=652230` 不达标，但 `population=25500100 >= 25000000`，`OR` 右侧为 `True`，保留；Algeria 的 `area=2381741` 不达标，`population=37100000` 达标，保留；Angola 的 `area=1246700`、`population=20609294` 两边都 `False`，被剔除。最终两行。

```python
import pandas as pd

def big_countries(world: pd.DataFrame) -> pd.DataFrame:
    mask = (world["area"] >= 3000000) | (world["population"] >= 25000000)
    return world.loc[mask, ["name", "population", "area"]]
```

关键在 `mask` 这一行：`|` 是逐元素或，且两个比较各自加括号，否则 `>=` 和 `|` 的优先级会让表达式算错。`loc` 的列名列表直接决定输出列序。

## 复杂度
时间 O(n)：n 为 World 行数，一次全表扫描做两次比较。
空间 O(k)：k 为大国数量，只存结果行，mask 额外 O(n) 布尔。

## 易错点
- 写成 `area > 3000000`：面积恰好 3000000 的国家（如假设某国 `area=3000000`）会被漏掉，题面是「至少」，必须 `>=`。
- 用 `and` 或 `&` 连接两个条件：`and` 对 Series 会直接报 `ValueError`，`&` 若不加括号则因优先级先算 `3000000 | world["population"]` 得到错误结果；正确写法是 `(a >= x) | (b >= y)` 带括号。

## 如果面试官追问
问：若要求按人口降序、人口相同按面积降序输出？
答：在返回前加 `.sort_values(["population", "area"], ascending=False)`，不影响过滤逻辑。
