## 一句话思路
从两个字符串末尾各设一个指针，跳过被 `#` 抵消的字符，逐位比较实际字符。

## 怎么做
1. 指针 `i = len(s)-1`、`j = len(t)-1`，各配一个待抵消计数 `skip_s = skip_t = 0`。
2. 写一个内层循环：遇到 `#` 就 `skip += 1` 并左移；遇到普通字符且 `skip > 0` 就 `skip -= 1` 并左移；否则停下。
3. 两个指针都停稳后比较 `s[i]` 与 `t[j]`，不等立即返回 `False`，相等则双双左移一位。
4. 循环结束（两指针都越界）返回 `True`。

以 `s = "ab#c"`、`t = "ad#c"` 为例：`i` 从 3 起，`s[3]='c'` 且 `skip_s=0`，停；`j` 从 3 起，`t[3]='c'` 停；`'c'=='c'`，双双左移。接着 `i=2` 是 `#`，`skip_s=1`，`i=1` 的 `'b'` 被抵消，`skip_s=0`，`i=0` 的 `'a'` 停；`t` 侧同理停在 `'a'`。`'a'=='a'`，继续左移，两指针同时越界，返回 `True`。

```python
i, j = len(s) - 1, len(t) - 1
skip_s = skip_t = 0
while i >= 0 or j >= 0:
    while i >= 0:
        if s[i] == '#':
            skip_s += 1; i -= 1
        elif skip_s > 0:
            skip_s -= 1; i -= 1
        else:
            break
    while j >= 0:
        if t[j] == '#':
            skip_t += 1; j -= 1
        elif skip_t > 0:
            skip_t -= 1; j -= 1
        else:
            break
    if i >= 0 and j >= 0:
        if s[i] != t[j]:
            return False
    elif i >= 0 or j >= 0:
        return False
    i -= 1; j -= 1
return True
```

## 复杂度
时间 O(n+m)：`i`、`j` 各自只单调左移，每个字符最多被访问一次。
空间 O(1)：只开了 `i`、`j`、`skip_s`、`skip_t` 四个整型变量，没有额外字符串。

## 易错点
- 输入 `s = "a#c"`、`t = "b"`：若只按「遇 `#` 就删前一个字符」的朴素栈思路写，`s` 得 `"c"`、`t` 得 `"b"`，比较得 `False` 是对的；但若漏掉「`#` 在空文本上继续为空」的边界，`s = "#a"` 会误删成空串再拼 `a`，正确结果是 `"a"`，`skip_s` 计数在 `i` 越界后必须丢弃。
- 输入 `s = "ab##"`、`t = "c#d#"`：两串都化为空串应返回 `True`。若循环条件写成 `while i >= 0 and j >= 0`，`i`、`j` 会同时停在 `-1` 之前就退出，漏掉「一侧先耗尽、另一侧还剩被抵消字符」的判定；正确写法是 `or`，并在比较前用 `elif i >= 0 or j >= 0: return False` 兜住长度不等的情况。

## 如果面试官追问
问：若要求返回退格后的实际字符串而不只是布尔值？答：仍用双指针从后往前收集字符，把停稳的字符依次 append 到结果列表，最后反转即可，空间 O(n) 但省去两次完整重建。
