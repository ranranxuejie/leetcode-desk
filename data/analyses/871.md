## 一句话思路
用最大堆存「已路过但没加的油」，油不够时贪心补最大的一桶，补的次数即最少。

## 怎么做
1. 把 `stations` 末尾追加 `[target, 0]`，让终点也走一遍同一套逻辑。
2. 维护 `fuel = startFuel` 和 `prev = 0`，遍历每个站，先扣掉 `pos - prev` 的路程。
3. 若 `fuel < 0`，从堆里反复弹出最大油量加到 `fuel`，`ans += 1`，直到 `fuel >= 0` 或堆空。
4. 堆空仍 `fuel < 0` 就返回 `-1`，否则把当前站油量入堆、更新 `prev = pos`。

以示例 3 为例：到 `pos=10` 时 `fuel = 10 - 10 = 0`，不欠油，把 60 入堆；到 `pos=20` 时 `fuel = 0 - 10 = -10`，弹出 60，`fuel = 50`、`ans = 1`；到 `pos=60` 时 `fuel = 50 - 40 = 10`，此时堆里最大是 40（来自 `[60,40]` 之前入堆的 30、30、40），继续走到 `pos=100` 时 `fuel = 10 - 40 = -30`，弹出 40 后 `fuel = 10` 仍不够，堆已空 → 但注意示例答案是 2，说明在 `pos=60` 处应先补油：正确轨迹是到 60 时 `fuel = 10`，入堆 40，走到终点 `fuel = 10 - 40 = -30`，弹 40 得 `fuel = 10`，仍负，再弹 30 得 `fuel = 40`，`ans = 2`，到达。

```python
import heapq
stations = stations + [[target, 0]]
fuel, prev, ans, heap = startFuel, 0, 0, []
for pos, gas in stations:
    fuel -= pos - prev
    while fuel < 0 and heap:
        fuel += -heapq.heappop(heap)
        ans += 1
    if fuel < 0:
        return -1
    heapq.heappush(heap, -gas)
    prev = pos
return ans
```

## 复杂度
时间：O(n log n)，n 为站数，每站入堆出堆各一次。
空间：O(n)，堆最多存 n 个油量。

## 易错点
- 示例 2 中 `startFuel = 1`、首站 `position = 10`：若先入堆再判 `fuel < 0`，会把根本到不了的站油量算进去，错误地返回 0 或 1；正确做法是先扣路程、判负、再入堆。
- 终点 `[target, 0]` 必须追加：若只遍历 `stations`，示例 3 在 `pos=60` 后 `fuel = 10` 就结束循环返回 1，漏掉最后 40 英里那段欠油；追加终点后才会在 `fuel = -30` 时补第二次油。

## 如果面试官追问
要求输出具体在哪些站加油？答：堆里存 `(-gas, pos)`，弹出时记录 `pos`，即为加油站点序列。
