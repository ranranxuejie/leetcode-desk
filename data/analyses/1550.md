## 一句话思路
一次遍历，用计数器记当前连续奇数长度，到 3 就返回 `True`，遇偶数清零。

## 怎么做
1. 初始化 `cnt = 0`，表示「以当前位置结尾的连续奇数个数」。
2. 遍历 `arr` 中每个 `x`：`x % 2 == 1` 时 `cnt += 1`，否则 `cnt = 0`。
3. 每次更新后立刻判断 `cnt == 3`，成立就 `return True`，不必等循环结束。
4. 循环走完没命中，`return False`。

拿示例 2 的 `arr = [1,2,34,3,4,5,7,23,12]` 走一遍关键段：处理到 `3` 时 `cnt` 从 0 变 1，接着 `4` 是偶数把 `cnt` 打回 0；再往后 `5`→1、`7`→2、`23`→3，此刻 `cnt == 3` 立即返回 `True`。注意 `cnt` 在 `4` 处被清零，所以 `3` 和 `5` 不会被错连成一段——这正是「连续」二字的落点。

```python
cnt = 0
for x in arr:
    if x % 2 == 1:
        cnt += 1
        if cnt == 3:
            return True
    else:
        cnt = 0
return False
```

`cnt` 只在奇数分支里自增，偶数分支直接归零，两个分支互斥，不会出现「先加后清」的双重计数。

## 复杂度
时间 O(n)：n 是 `arr` 长度，最坏扫完全部元素。
空间 O(1)：只开了一个 `cnt` 整数，没有额外数组。

## 易错点
- 输入 `arr = [1,3]`（长度不足 3）→ 若先写 `arr[i] and arr[i+1] and arr[i+2]` 的下标循环会越界 → 正确做法是计数器法，天然不依赖长度，`cnt` 最多到 2 就结束。
- 输入 `arr = [1,1,2,1,1,1]` → 若把 `cnt` 写成「历史奇数总数」而非「当前连续段」，会在前两个 1 之后误判 → 正确做法是遇偶数必须执行 `cnt = 0`，让 `cnt` 只反映以当前位置结尾的那一段。

## 如果面试官追问
问：要求返回这三个数的起始下标怎么办？
答：把 `return True` 换成 `return i - 2`（`i` 是当前下标），因为 `cnt` 到 3 时这三个数正好是 `arr[i-2:i+1]`。
