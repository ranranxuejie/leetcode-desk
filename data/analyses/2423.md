## 一句话思路
统计每个字母频次，枚举「删掉哪个字母」，删后把频次为 0 的字母剔除，再看剩余频次是否全相等。

## 怎么做
1. 用 `Counter(word)` 得到 `cnt`，键是字母、值是频次。
2. 枚举 `cnt` 中每个字母 `ch`，模拟把它删一次：`cnt[ch] -= 1`。
3. 删后收集所有 `v > 0` 的频次到 `freqs`，判断 `len(set(freqs)) == 1`。
4. 恢复 `cnt[ch] += 1` 再试下一个；任一字母成功即返回 `True`。

以 `word = "abcc"` 为例：`cnt = {'a':1,'b':1,'c':2}`。枚举到 `ch='c'` 时 `cnt['c']` 从 2 变 1，`freqs = [1,1,1]`，`set` 大小为 1，返回 `True`。而 `"aazz"` 的 `cnt = {'a':2,'z':2}`，删任一字母后 `freqs` 都是 `[1,2]`，`set` 大小为 2，两个都失败，返回 `False`。

```python
from collections import Counter

def equalFrequency(word):
    cnt = Counter(word)
    for ch in list(cnt):
        cnt[ch] -= 1
        freqs = [v for v in cnt.values() if v > 0]
        if len(set(freqs)) == 1:
            return True
        cnt[ch] += 1
    return False
```

关键在 `if v > 0` 这个过滤：删掉某字母的唯一一次出现后，它的频次变成 0，这个字母在剩余字符串里已不存在，不能算进「剩余字母的频率」里。漏掉这层过滤，`"abcc"` 删 `'a'` 会得到 `[0,1,2]`，`set` 大小 3，误判失败。

## 复杂度
时间：O(26 × 26)，枚举至多 26 个字母，每次扫 26 个频次，与 n 无关。
空间：O(26)，`cnt` 和 `freqs` 都只存小写字母频次。

## 易错点
- 输入 `"abcc"` 删 `'a'` 时，若不过滤 `v > 0`，`freqs` 会含 0 变成 `[0,1,2]`，误判 `False`；正确做法是只收集 `v > 0` 的频次。
- 输入 `"aazz"` 或 `"aab"` 这类「两个频次相同」的情形，容易只比较最大最小频次就下结论；正确做法是删后必须让 `set(freqs)` 大小恰为 1，`"aab"` 删 `'b'` 得 `[2]` 才是 `True`。

## 如果面试官追问
问：若要求返回具体删除的下标而非布尔值？
答：枚举字母时记录该字母任一出现位置，成功即返回该下标；注意 `"abcc"` 要返回 `'c'` 的某个下标（如 3），不是 `'a'` 的。
