## 一句话思路
用 `dp[i]` 记以 `i` 结尾的等差子数组个数，`nums[i]-nums[i-1]==nums[i-1]-nums[i-2]` 时 `dp[i]=dp[i-1]+1`，累加即答案。

## 怎么做
1. 从下标 2 开始扫，只比较相邻两个差值 `d1 = nums[i]-nums[i-1]`、`d2 = nums[i-1]-nums[i-2]`。
2. 相等则 `cur = cur + 1`，否则 `cur = 0`；`cur` 就是以 `i` 结尾的等差子数组个数。
3. 每步把 `cur` 累加进 `total`，扫完返回 `total`。

拿 `nums = [1,2,3,4]` 走一遍：`i=2` 时 `d1=d2=1`，`cur` 从 0 变 1，`total=1`（对应 `[1,2,3]`）；`i=3` 时 `d1=d2=1`，`cur` 变 2，`total=3`。这 2 个是 `[2,3,4]` 和 `[1,2,3,4]`——长度 4 的等差段里，以 4 结尾的正好 2 个，所以 `cur` 递增而不是恒为 1。

```python
total = cur = 0
for i in range(2, len(nums)):
    if nums[i] - nums[i-1] == nums[i-1] - nums[i-2]:
        cur += 1
    else:
        cur = 0
    total += cur
return total
```

关键在 `cur += 1` 而非 `cur = 1`：一段长度为 L 的等差段贡献 `(L-1)(L-2)/2` 个子数组，靠 `cur` 逐位累加自然得到，不需要额外组合公式。

## 复杂度
时间 O(n)：一次遍历，每个下标只做两次减法。
空间 O(1)：只开 `total`、`cur` 两个变量，不建 dp 数组。

## 易错点
- `nums = [1,2,3,4]` 若写成 `cur = 1`（相等时重置为 1 而非加 1），`i=3` 时 `cur` 仍是 1，`total` 得 2，漏掉 `[1,2,3,4]`；正确是 `cur += 1` 让长度 4 的段贡献 2。
- `nums = [1,2,3,8,13]` 若在 `i=3` 差值不等时忘了 `cur = 0`，`cur` 残留 1，`i=4` 时 `8,13` 差 5 与前面 5 恰好相等会误判——这里其实该算，但若残留值来自更早的段就会多算；正确做法是每次不等立即清零，让 `cur` 只反映当前连续等差段。

## 如果面试官追问
问：要求返回所有等差子数组本身而非个数？
答：在 `cur` 递增时枚举以 `i` 结尾、长度 3 到 `cur+2` 的窗口，总输出量 O(n²)，复杂度随之变为 O(n²)。
