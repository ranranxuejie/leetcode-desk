## 一句话思路
按位数分类计数：k 位数（k≥1）首位 9 选、后面每位从剩余 9 个数字里递减选，累加即得。

## 怎么做
1. 特判 `n == 0` 返回 1（只有 0 本身）。
2. 初始化 `total = 1`（把 0 算进去），`cur = 9`（1 位数的个数）。
3. 从 `k = 1` 循环到 `n`：累加 `cur`，然后 `cur *= (10 - k)` 得到下一位数的个数。
4. 返回 `total`。

以 `n = 2` 为例：`total=1, cur=9`。k=1 时 `total=10`，`cur=9*9=81`；k=2 时 `total=91`，循环结束返回 91。中间值 `cur=81` 正是两位数中各位不同的个数（首位 9 选，次位剩 9 选）。

```python
def countNumbersWithUniqueDigits(n):
    if n == 0:
        return 1
    total, cur = 1, 9
    for k in range(1, n + 1):
        total += cur
        cur *= (10 - k)
    return total
```

注意 `cur` 在 k=10 时会乘 0，但 `n ≤ 8` 不会触发；若放宽到 n≥10，后续项自然为 0，逻辑仍成立。

## 复杂度
时间：O(n)，循环 n 次，每次 O(1)。
空间：O(1)，只开 `total`、`cur` 两个变量。

## 易错点
- `n = 0` → 若直接进循环返回 0，漏掉数字 0 本身 → 正确做法是先特判返回 1，或把 `total` 初值设为 1 且循环从 k=1 起。
- `n = 1` → 若把 `cur` 初值写成 10（误把 0 当一位数首位）→ 会得到 10 而非 9，正确是首位只能 1-9 共 9 种，0 单独由 `total` 初值 1 计入。

## 如果面试官追问
问：若 n 放宽到 100 怎么办？
答：n≥10 后每项都含因子 0，`cur` 归零，答案在 n=10 时封顶为 8877691，直接 `min(n,10)` 截断即可。
