## 一句话思路
这是格雷码的逆映射：`n` 到 0 的最少步数等于 `n` 在格雷码序列中的下标，用 `n ^= n >> 1` 逐位消去即可。

## 怎么做
1. 观察操作规则：第 i 位可翻转当且仅当低位形如 `100...0`，这正是格雷码相邻项只差一位的结构。
2. 因此把 `n` 看作格雷码，求它对应的二进制下标 `k`，答案就是 `k`。
3. 逆变换用 `n ^= n >> 1` 反复折叠：每次把高位的 1 折到低位上，直到所有位消完。
4. 以 `n = 6`（`110`）为例：`6 ^ 3 = 5`（`101`），`5 ^ 2 = 7`（`111`），`7 ^ 3 = 4`（`100`），`4 ^ 2 = 6`… 这里要小心，正确做法是**从高位往低位**逐位还原，而不是简单右移异或。

```python
def minimumOneBitOperations(n: int) -> int:
    ans = 0
    while n:
        ans ^= n
        n >>= 1
    return ans
```

对 `n = 6`：`ans = 6`，`n = 3`，`ans = 6 ^ 3 = 5`，`n = 1`，`ans = 5 ^ 1 = 4`，`n = 0`，返回 `4`，与示例一致。

## 复杂度
时间：O(log n)，循环次数等于 `n` 的二进制位数。
空间：O(1)，只用了 `ans` 和 `n` 两个变量。

## 易错点
- 输入 `n = 0` → 若循环写成 `while n > 0` 之外的变体或漏掉初值，会返回非 0 → 正确做法是 `ans` 初值 0，`n = 0` 时直接返回 0。
- 输入 `n = 2**30`（接近上限 `10^9`）→ 若用递归且不记忆化，会重复计算同一子问题导致超时 → 正确做法是用迭代 `while n` 逐位折叠，天然 O(log n)。

## 如果面试官追问
问：如果要求输出具体操作序列而非次数？
答：从格雷码下标 `k` 反推，每次翻转 `k` 最低位的 1 对应位，逐步构造即可。
