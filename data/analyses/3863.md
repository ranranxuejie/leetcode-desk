## 一句话思路
统计「逆序对涉及的字符」：答案只可能是 0、1、2 或 -1，由字符串中最大字符与最小字符的位置关系决定。

## 怎么做
1. 若 `s` 已非降序，返回 0。
2. 记 `mx = max(s)`、`mn = min(s)`；若 `s[0] == mx` 且 `s[-1] == mn`，说明最大字符卡在开头、最小字符卡在末尾，任何子串排序都动不了它们，返回 -1。
3. 否则检查能否一次搞定：存在某个下标 `i`，使 `s[:i]` 已非降序、`s[i:]` 排序后整体有序，即 `s[i:]` 的最小值 ≥ `s[i-1]`。满足则返回 1。
4. 其余情况返回 2。

以 `s = "card"` 为例：`mx='r'`、`mn='a'`，`s[0]='c' != 'r'`，排除 -1。试 `i=1`：`s[:1]="c"` 有序，`s[1:]="ard"` 最小值 `'a' < 'c'`，不行；`i=2`：`s[:2]="ca"` 已乱序，不行。故返回 2，与示例一致。

```python
def minOperations(s):
    if list(s) == sorted(s):
        return 0
    if s[0] == max(s) and s[-1] == min(s):
        return -1
    n = len(s)
    suf_min = [None] * (n + 1)
    suf_min[n] = '{'          # 比 'z' 大的哨兵
    for i in range(n - 1, -1, -1):
        suf_min[i] = min(s[i], suf_min[i + 1])
    for i in range(1, n):
        if s[i - 1] > s[i]:   # 前缀在此处首次失序，之后不可能再有序
            break
        if suf_min[i] >= s[i - 1]:
            return 1
    return 2
```

## 复杂度
时间 O(n)：一次 `sorted` 比较加一次后缀最小值扫描，`n = len(s)`。
空间 O(n)：`suf_min` 数组占 n+1 个槽位，`sorted(s)` 另占 n。

## 易错点
- 输入 `s = "gf"`：只判「已有序」和「首尾极值」会漏掉 -1 的判定顺序，先返回 1 就错了。必须先判 `s[0]==max(s) and s[-1]==min(s)` 再谈一次操作，因为 `"gf"` 恰好首字符是最大值、末字符是最小值。
- 输入 `s = "ab"` 或 `s = "aa"`：把「需要操作」当成默认情况会返回 1，实际已有序应为 0。判断有序要用 `list(s) == sorted(s)` 而非只比较首尾字符。

## 如果面试官追问
问：若允许排序整个字符串，答案会变吗？
答：会，那样任何字符串都能 1 次排好，-1 分支消失，只剩 0 和 1。
