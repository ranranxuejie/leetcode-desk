## 一句话思路
对下标做回溯，用 `used` 集合在同一层去重，保证每个不同的值只作为一次子序列的下一元素。

## 怎么做
1. 从 `start` 开始枚举下标 `i`，若 `i > start and nums[i] in used` 则跳过，否则把 `nums[i]` 加入 `used`。
2. 若 `path` 为空或 `nums[i] >= path[-1]`，把 `nums[i]` 追加进 `path`，`len(path) >= 2` 时收集答案。
3. 递归 `dfs(i + 1)`，返回后 `path.pop()`，`used` 在每层递归入口重新建空集合。
4. 以 `nums = [4,6,7,7]` 为例：`start=0` 时 `used` 依次收 `4,6,7`，第二个 `7` 因已在 `used` 中被跳过，所以 `[4,7]` 只出现一次，而 `[4,7,7]` 由 `path=[4,7]` 再取下标 3 的 `7` 得到。

```python
def dfs(start):
    used = set()
    for i in range(start, len(nums)):
        if nums[i] in used:
            continue
        used.add(nums[i])
        if not path or nums[i] >= path[-1]:
            path.append(nums[i])
            if len(path) >= 2:
                res.append(path[:])
            dfs(i + 1)
            path.pop()
```

关键中间值：`start=0, i=2` 时 `path=[4,6]`，`used={4,6,7}`；`i=3` 的 `7` 命中 `used` 被跳过，避免重复的 `[4,6,7]`。

## 复杂度
时间：O(2^n * n)，每个下标选或不选，收集答案时复制 `path` 花 O(n)。
空间：O(n) 递归栈加 `path`，`used` 每层最多 n 个元素。

## 易错点
- 输入 `[4,4,3,2,1]` → 若用全局 `used` 或对 `nums` 排序后去重，会漏掉 `[4,4]` 或产生 `[3,2]` 这类非递增序列 → 正确做法是 `used` 只在当前递归层内生效，且比较 `nums[i] >= path[-1]` 而非排序。
- 输入 `[4,6,7,7]` → 若只靠 `nums[i] != nums[i-1]` 去重，会误杀 `[4,7,7]`（两个 7 相邻但合法）→ 正确做法是用层内 `used` 集合按值去重，允许同一值在不同深度重复出现。
