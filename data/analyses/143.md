## 一句话思路
找中点拆成两半，后半段反转，再与前半段交替合并，因为目标序列正是「前半正序 + 后半逆序」交错。

## 怎么做
1. 快慢指针找中点，`slow` 停在 `n//2` 位置，断开 `slow.next`，得到前半 `head` 和后半 `second`。
2. 反转 `second`，标准三指针 `prev/cur/nxt`。
3. 交替合并：`head` 取一个、`second` 取一个，注意先存 `next` 再改 `next`。

以 `[1,2,3,4,5]` 为例：快慢指针走完 `slow` 指向 `3`，`second = 4→5`；反转后 `second = 5→4`；合并时 `1→5→2→4→3`，最后 `second` 为空，`head` 剩 `3` 直接接上。

```python
slow = fast = head
while fast.next and fast.next.next:
    slow, fast = slow.next, fast.next.next
second = slow.next
slow.next = None
prev, cur = None, second
while cur:
    nxt = cur.next
    cur.next = prev
    prev, cur = cur, nxt
second = prev
while second:
    nxt1, nxt2 = head.next, second.next
    head.next = second
    second.next = nxt1
    head, second = nxt1, nxt2
```

关键在合并循环条件用 `while second`：后半段长度 ≤ 前半段，`second` 先耗尽，`head` 尾部（奇数长度时的中间节点）自然保留。

## 复杂度
时间 O(n)：找中点、反转、合并各扫一遍，常数 3 倍。
空间 O(1)：只用了 `slow/fast/prev/cur/nxt` 几个指针，没开数组。

## 易错点
- 输入 `[1,2]` → 若快慢指针写成 `while fast and fast.next`，`slow` 会停在 `2`，`second` 为空，合并时 `head.next = second` 把链表截断成 `[1]` → 正确写法是 `while fast.next and fast.next.next`，让 `slow` 停在 `1`。
- 输入 `[1,2,3,4,5]` → 合并时若先写 `head.next = second` 再取 `head.next`，`head` 的后续节点已丢失 → 必须先存 `nxt1 = head.next` 和 `nxt2 = second.next`，再改指针。

## 如果面试官追问
追问：不允许改指针、只允许改 `val` 怎么做？
答：把节点值读进数组，按 `i` 与 `n-1-i` 双指针重排后写回，时间 O(n)、空间 O(n)，但违反题面「实际交换」的要求。
