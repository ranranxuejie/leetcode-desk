## 一句话思路
按「先 op1 后 op2」的顺序做两轮贪心：每轮都选当前收益最大的下标，因为两操作互不干扰且各自单调。

## 怎么做
1. 先只考虑 op1：对每个下标算 `nums[i] - (nums[i]+1)//2` 作为收益，用大顶堆取前 op1 个。
2. 更新 `nums` 后，再对每个下标算 op2 收益：若 `nums[i] >= k` 则收益为 `k`，否则为 0，取前 op2 个。
3. 累加最终 `nums` 即为答案。

以示例 1 `nums=[2,8,3,19,3], k=3, op1=1, op2=1` 为例：op1 收益分别为 `1,4,2,10,2`，选下标 3 得 `19→10`；此时数组 `[2,8,3,10,3]`，op2 收益 `0,3,3,3,3`，选下标 1 得 `8→5`，和 `23`。

```python
import heapq
def minArraySum(nums, k, op1, op2):
    nums = nums[:]
    h = [(-(x - (x + 1) // 2), i) for i, x in enumerate(nums)]
    heapq.heapify(h)
    for _ in range(op1):
        if not h: break
        _, i = heapq.heappop(h)
        nums[i] = (nums[i] + 1) // 2
    h = [(-k, i) for i, x in enumerate(nums) if x >= k]
    heapq.heapify(h)
    for _ in range(op2):
        if not h: break
        _, i = heapq.heappop(h)
        nums[i] -= k
    return sum(nums)
```

## 复杂度
时间：O(n log n + (op1+op2) log n)，堆操作贡献 log n。
空间：O(n)，两个堆各存 n 个元素。

## 易错点
- 输入 `nums=[2], k=0, op2=1`：若直接对 `nums[i] >= k` 判 0 收益也入堆，会白扣一次 op2 但值不变；正确做法是 `k=0` 时 op2 收益恒为 0，跳过即可。
- 输入 `nums=[1], k=5, op1=1, op2=1`：若先做 op2 再做 op1，`1` 无法减 k 但 op1 后仍为 1；若先 op1 后 op2 结果相同，但若 `nums=[6], k=5`，先 op1 得 3 后 op2 失效，先 op2 得 1 后 op1 得 1，顺序影响结果——本题规定先 op1 后 op2 才能取到最小，不能颠倒。

## 如果面试官追问
问：若 op1 可对同一下标多次执行怎么办？
答：收益递减，改用「每次取当前最大收益」的堆动态更新，复杂度变 O((n+op1) log n)。
