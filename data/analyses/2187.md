## 一句话思路
对答案时间 t 二分：t 时刻总趟数 = Σ(t // time[i])，它随 t 单调不减，所以能二分找最小可行 t。

## 怎么做
1. 下界 `lo = 1`，上界 `hi = min(time) * totalTrips`（让最快的车独自跑完）。
2. 二分取 `mid`，累加 `sum(mid // x for x in time)`，一旦 ≥ totalTrips 就提前 break。
3. 若 `cnt >= totalTrips` 则 `hi = mid`，否则 `lo = mid + 1`。
4. 循环结束返回 `lo`。

以 `time = [1,2,3], totalTrips = 5` 为例：`hi = 1*5 = 5`。第一次 `mid = 3`，`cnt = 3//1 + 3//2 + 3//3 = 3+1+1 = 5 ≥ 5`，收缩到 `hi = 3`；再试 `mid = 2`，`cnt = 2+1+0 = 3 < 5`，`lo = 3`；`lo == hi` 收敛，答案 3。

```python
lo, hi = 1, min(time) * totalTrips
while lo < hi:
    mid = (lo + hi) // 2
    cnt = 0
    for x in time:
        cnt += mid // x
        if cnt >= totalTrips:
            break
    if cnt >= totalTrips:
        hi = mid
    else:
        lo = mid + 1
return lo
```

关键在 `mid // x` 而不是 `mid / x`：整除才是「t 时刻这辆车跑完的整趟数」，浮点会在 `mid = 3, x = 2` 时给出 1.5 污染计数。

## 复杂度
时间：二分 log(min(time)*totalTrips) 层，每层扫 n = len(time)，共 O(n log(min·totalTrips))。
空间：O(1)，只用了 lo/hi/mid/cnt 四个标量。

## 易错点
- 上界写成 `max(time) * totalTrips`：`time=[1,2,3], totalTrips=5` 时上界变 15，二分仍正确但多跑约 2 层；更糟的是若误写成 `totalTrips`（如 5），`time=[100]` 时 `hi=5 < 答案 100`，直接返回错值。正确用 `min(time) * totalTrips`。
- 累加不提前 break：`time` 长 10^5、`mid` 达 10^14 时 `cnt` 会累到 10^19 量级，Python 不溢出但白跑满 n 次；`cnt >= totalTrips` 后立刻 break，示例里 `mid=3` 累到第 3 项就停。

## 如果面试官追问
问：若 time 长度升到 10^7 怎么办？答：先对 time 去重计数，二分内层按「值→个数」加权累加，把 n 压到不同取值个数。
