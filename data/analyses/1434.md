## 一句话思路
按帽子编号 1→40 逐顶决策，用位掩码记录已戴帽的人集合，DP 累加方案数。

## 怎么做
1. 预处理 `hat2people`：把每顶帽子映射到喜欢它的人的下标列表，遍历 `hats[i]` 填入。
2. 状态 `dp[mask]` 表示「处理完前若干顶帽子后，被满足的人集合为 mask」的方案数，初始 `dp[0] = 1`。
3. 对帽子 `h` 从 1 到 40，倒序或新开数组更新：对每个 `mask`，对 `hat2people[h]` 里每个未戴帽的人 `p`，把 `dp[mask]` 加到 `dp[mask | (1<<p)]`。
4. 答案是 `dp[(1<<n) - 1]`。

以示例 2 `hats = [[3,5,1],[3,5]]` 为例，n=2，`hat2people[3]=[0,1]`，`hat2people[5]=[0,1]`，`hat2people[1]=[0]`。处理帽子 1 后 `dp = {0:1, 0b01:1}`；处理帽子 3 时，从 `mask=0` 分出 `0b01`、`0b10`，从 `mask=0b01` 分出 `0b11`；处理帽子 5 再补上剩余分支，最终 `dp[0b11] = 4`。

```python
MOD = 10**9 + 7
n = len(hats)
hat2people = [[] for _ in range(41)]
for p, hs in enumerate(hats):
    for h in hs:
        hat2people[h].append(p)

dp = [0] * (1 << n)
dp[0] = 1
for h in range(1, 41):
    ndp = dp[:]                      # 这顶帽子不用
    for mask in range(1 << n):
        if dp[mask] == 0:
            continue
        for p in hat2people[h]:
            if not (mask >> p) & 1:
                ndp[mask | (1 << p)] = (ndp[mask | (1 << p)] + dp[mask]) % MOD
    dp = ndp
return dp[(1 << n) - 1]
```

## 复杂度
时间：40 × 2^n × 平均每帽人数，n ≤ 10 故约 40·1024·10。
空间：`dp`/`ndp` 各 2^n 个整数，`hat2people` 存 40 个列表。

## 易错点
- 若在同一个 `dp` 数组上原地更新（`dp[mask | (1<<p)] += dp[mask]`），同一顶帽子会被重复分配给多个人，示例 2 会算成大于 4 的值；必须用 `ndp = dp[:]` 或倒序滚动，保证每顶帽子只用一次。
- 若漏掉 `ndp = dp[:]` 的「这顶帽子不用」分支，只从 `dp[mask]` 出发更新，则像示例 1 中帽子 1、2 无人喜欢时状态会被清零；正确做法是先把旧 `dp` 整体拷进 `ndp` 再叠加新分配。

## 如果面试官追问
问：若 n 增大到 15、帽子仍是 40 种，怎么做？答：2^15 状态仍可承受，但需把「按帽子」改为「按人」枚举并配合记忆化，或改用状压 + 剪枝。
