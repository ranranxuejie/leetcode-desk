## 一句话思路
先求差异位下标数组 `diff`，相邻配对用操作二（代价 1/格），跨对用操作一（代价 x），对 `diff` 做 DP 取最小。

## 怎么做
1. 令 `diff = [i for i in range(n) if s1[i] != s2[i]]`，长度 `m` 为奇数直接返回 -1（每次操作翻转两个位，差异数奇偶不变）。
2. 设 `dp[i]` 为消掉 `diff` 前 `i` 个差异位的最小代价，`dp[0] = 0`，`dp[1] = 0`（单个差异位可先欠着，等后面配对）。
3. 转移：`dp[i] = min(dp[i-2] + min(x, 2*(diff[i-1]-diff[i-2])), dp[i-1] + x//2)`——前者把最后两个差异位配对，后者把最后一个差异位与更早的位用操作一配对（`x//2` 是均摊到单个位的代价）。
4. 答案 `dp[m]`。

以示例 1 为例：`s1="1100011000"`，`s2="0101001010"`，逐位比较得 `diff = [0, 3, 4, 8]`，`m=4`。`dp[2] = min(x, 2*(3-0)) = min(2,6) = 2`；`dp[3] = dp[2] + x//2 = 2+1 = 3`；`dp[4] = min(dp[2] + min(2, 2*(8-4)), dp[3] + 1) = min(2+2, 3+1) = 4`，与输出 4 一致。

```python
diff = [i for i in range(n) if s1[i] != s2[i]]
m = len(diff)
if m % 2: return -1
dp = [0] * (m + 1)
dp[1] = 0
for i in range(2, m + 1):
    dp[i] = dp[i-2] + min(x, 2 * (diff[i-1] - diff[i-2]))
    if i >= 3:
        dp[i] = min(dp[i], dp[i-1] + x // 2)
return dp[m]
```

## 复杂度
时间：O(n)，扫描一遍建 `diff`，DP 只走 `m ≤ n` 步。
空间：O(m) 存 `diff` 和 `dp`，`m` 为差异位数。

## 易错点
- `diff` 长度为奇数（如 `s1="10110"`、`s2="00011"` 得 `diff=[0,2,3]`）→ 若漏判会进入 DP 算出错误值 → 必须先 `if m % 2: return -1`，因为两种操作都翻转恰好两个位，差异数奇偶性不变。
- 相邻差异位距离很近时（如 `diff=[0,1]`，`x=4`）→ 若只用 `dp[i-2] + x` 会得 4，实际用操作二只需 `2*(1-0)=2` → 转移里必须写 `min(x, 2*(diff[i-1]-diff[i-2]))`，不能直接加 `x`。

## 如果面试官追问
问：若要求输出具体操作序列怎么办？
答：DP 时记录每个 `dp[i]` 的选择来源，回溯得到配对关系，相邻对展开成连续的操作二，跨对输出操作一即可。
