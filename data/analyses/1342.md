## 一句话思路
按规则模拟：偶数 `num //= 2`，奇数 `num -= 1`，每步计数加一，直到 `num == 0`。

## 怎么做
1. 初始化 `steps = 0`，循环条件写 `while num:`。
2. 偶数走 `num //= 2`，奇数走 `num -= 1`，两条分支都 `steps += 1`。
3. 用 `num & 1` 判奇偶，比 `num % 2` 更贴位运算标签，结果一致。

以 `num = 14` 为例，关键中间值是第 2 步：`14` 偶 → `num = 7`，此时 `7 & 1 == 1` 走减一得 `6`，`steps` 从 1 变 2；之后 `6→3→2→1→0` 共 4 步，合计 6。

```python
steps = 0
while num:
    if num & 1:
        num -= 1
    else:
        num //= 2
    steps += 1
return steps
```

注意 `num = 0` 时循环体一次都不进，直接返回 0，不需要特判。

## 复杂度
时间：O(log num)，偶数分支每步把 num 折半，奇数分支只减一但下一步必折半。
空间：O(1)，只用了 `steps` 和 `num` 两个整型变量。

## 易错点
- 输入 `num = 0` → 若写成 `while True` 加 `if num == 0: break` 之外的死循环结构，或先 `num -= 1` 再判断，会返回 1 或死循环 → 正确做法是 `while num:` 直接跳过，返回 0。
- 输入 `num = 1` → 若把奇数分支写成 `num = (num - 1) // 2` 合并一步，会返回 1 而正确是 1 步（减一到 0），但 `num = 3` 时合并写法得 2 步、正确是 3 步（3→2→1→0）→ 正确做法是奇偶分支严格分开，奇数只减一不折半。

## 如果面试官追问
问：`num` 上限提到 `10**18` 还成立吗？
答：成立，步数约 `2 * log2(num)`，循环次数在 120 以内，Python 大整数无溢出问题。
