## 一句话思路
区间只有 `[n-k, n+k]` 至多 201 个数，直接枚举每个 x 同时验 `abs(n-x)<=k` 和 `(n&x)==0` 即可。

## 怎么做
1. 由 `abs(n-x)<=k` 直接得出枚举范围 `lo=max(1,n-k)`、`hi=n+k`，下界取 1 因为 x 必须是正整数。
2. 对区间内每个 x 判断 `(n & x) == 0`，成立就累加。
3. 用示例 1 走一遍：`n=2,k=3`，`lo=1,hi=5`；x=1 时 `2&1=0` 收；x=2 时 `2&2=2` 弃；x=3 时 `2&3=2` 弃；x=4 时 `2&4=0` 收；x=5 时 `2&5=0` 收，合计 1+4+5=10。
4. 示例 2 中 `n=5,k=1`，`lo=4,hi=6`，`5&4=4`、`5&5=5`、`5&6=4` 全非零，返回 0。

```python
lo, hi = max(1, n - k), n + k
ans = 0
for x in range(lo, hi + 1):
    if (n & x) == 0:
        ans += x
return ans
```

## 复杂度
时间：O(k)，区间长度 2k+1，每个数一次按位与。
空间：O(1)，只开 `lo`、`hi`、`ans` 三个变量。

## 易错点
- `n=1,k=100` 时若下界写成 `n-k=-99`，会把 0 和负数当候选，而 x 必须是正整数，`0&1==0` 还会被误收；正确做法是 `lo=max(1,n-k)`。
- `n=2,k=3` 时若把条件写成 `(n|x)==0` 或漏掉 `==0` 直接 `if n & x`，前者几乎全弃、后者把 `2&2=2` 这类非零值当成立，答案会变成 2+3 之类的错值；正确做法是严格写 `(n & x) == 0`。

## 如果面试官追问
若 n、k 放大到 10^9 怎么做？答：区间太宽不能枚举，改为数位 DP 统计 `[lo,hi]` 内与 n 无公共 1 的数的个数与和，按位分治。
