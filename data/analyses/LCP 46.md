## 一句话思路
把调配过程反过来跑：从最终人数倒推初始人数，用总人数定出场馆 0 的初始值。

## 怎么做
1. 正向调配是线性变换，逆推时把 `plans` 从后往前扫，对每个 `[num, idx]` 做相反操作。
2. 逆推时只有场馆 0 的初始值未知，设它为变量 `x`，其余场馆的初始值都能用 `x` 的线性表达式 `a*x + b` 表示。
3. 用 `totalNum` 解出 `x`，再代回所有表达式得到答案。

以示例 1 为例：`finalCnt=[1,16]` 对应场馆 1、2 的最终人数，场馆 0 最终人数未知。逆推 `plans=[[2,1],[1,0],[3,0]]` 时，场馆 0 的初始值设为 `x`，场馆 1、2 的初始值会写成 `a*x+b` 的形式。最后用 `totalNum=21` 解出 `x=5`，代回得 `[5,7,9]`。

```python
# 逆推：每个场馆的初始人数表示为 (a, b)，即 a*x + b
# 场馆 0 初始为 (1, 0)，其余场馆初始为 (0, finalCnt[i-1])
# 从后往前处理 plans，对 (a, b) 做逆操作
for num, idx in reversed(plans):
    if num == 1:          # 减半的逆：乘 2
        a[idx] *= 2; b[idx] *= 2
    elif num == 2:        # 加相邻的逆：减去 idx 当前值
        for v in adj[idx]:
            a[v] -= a[idx]; b[v] -= b[idx]
    else:                 # 减相邻的逆：加上 idx 当前值
        for v in adj[idx]:
            a[v] += a[idx]; b[v] += b[idx]
# 解 x：sum(a)*x + sum(b) = totalNum
x = (totalNum - sum(b)) // sum(a)
return [a[i]*x + b[i] for i in range(n)]
```

关键中间值：逆推结束后 `sum(a)` 是 `x` 的系数总和，`sum(b)` 是常数项总和，两者代入 `totalNum` 即可解出 `x`。

## 复杂度
时间：`O(n + m * deg)`，`m ≤ 10`，`deg` 为相邻场馆数，总边数 `O(edges)`。
空间：`O(n + edges)`，存邻接表和每个场馆的 `(a, b)` 系数。

## 易错点
- 逆推第 2、3 种方案时，若直接对相邻场馆做加减而不先固定 `idx` 的当前值，会因为 `idx` 自身也在被修改而导致系数错乱。正确做法是先读 `a[idx], b[idx]` 再更新相邻场馆。
- 场馆 0 的初始值设为 `x` 后，若 `sum(a)` 为 0（即 `x` 的系数被消掉），说明总人数无法确定 `x`，此时需检查是否所有场馆的初始值都与 `x` 无关。题目保证有解，但逆推顺序写错会导致 `sum(a)=0` 而除零。

## 如果面试官追问
问：如果 `plans` 长度增加到 `10^5` 怎么办？
答：逆推仍是 `O(m * deg)`，但需注意每次操作只影响相邻场馆，总复杂度仍为 `O(n + edges + m * deg)`，不会退化。
