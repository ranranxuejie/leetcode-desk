## 一句话思路
把每个字符串按 `ord(c) - ord('a')` 逐位拼成十进制数，再比较 `firstWord + secondWord == targetWord` 的数值。

## 怎么做
1. 写一个 `val(s)`：遍历字符，`res = res * 10 + (ord(c) - ord('a'))`。
2. 分别算出 `a = val(firstWord)`、`b = val(secondWord)`、`t = val(targetWord)`。
3. 返回 `a + b == t`。

以示例 1 的 `firstWord = "acb"` 为例：`'a'` 得 0 → `res=0`；`'c'` 得 2 → `res=0*10+2=2`；`'b'` 得 1 → `res=2*10+1=21`。同理 `"cba"` 得 210，`"cdb"` 得 231，`21+210==231` 为 `True`。

```python
def val(s):
    res = 0
    for c in s:
        res = res * 10 + (ord(c) - ord('a'))
    return res

a, b, t = val(firstWord), val(secondWord), val(targetWord)
return a + b == t
```

关键点：`'a'` 映射到 0 而不是 1，所以 `"aaa"` 的数值是 0，不是 111。

## 复杂度
时间：O(n)，n 为三个字符串长度之和，每个字符只做一次乘加。
空间：O(1)，只开了 `res`、`a`、`b`、`t` 几个整数。

## 易错点
- 把 `'a'` 当成 1 起算 → `"aaa"` 会算成 111 而非 0，示例 3 的 `0+0==0` 就判错 → 必须用 `ord(c) - ord('a')`。
- 用 `int(''.join(...))` 拼字符串再转整数 → `"aaa"` 拼出 `"000"` 转成 0 虽对，但 `"a"` 拼出 `"0"` 也靠 `int` 容错；一旦某位是 0 开头、或想省掉转换，直接 `res*10+d` 更稳，且避免空串 `int('')` 报错。

## 如果面试官追问
若字母表扩到 `'a'`–`'z'`（值 0–25）会怎样？答：`res*10` 要改成 `res*26`，否则 `'z'` 的 25 会和相邻位混淆。
