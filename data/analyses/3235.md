## 一句话思路
把每个圆看成障碍节点，若某组圆把矩形「左下角」与「右上角」隔断（连通块同时贴住两条相关边界），则不可达；用并查集判连通。

## 怎么做
1. 预处理：只保留与矩形有交的圆（圆心到矩形距离 ≤ r），其余圆不影响路径。
2. 并查集合并相交/相切的两圆：`(x1-x2)**2+(y1-y2)**2 <= (r1+r2)**2`。
3. 对每个连通块记录它贴住哪些边界（左 x≤r、下 y≤r、右 x+r≥X、上 y+r≥Y）。
4. 若存在连通块同时贴住「左+下」或「右+上」或「左+右」或「下+上」→ 返回 `False`。

以示例 3 为例：`X=Y=3`，圆 A=(2,1,1) 贴下边界（y-r=0≤0）和右边界（x+r=3≥3），圆 B=(1,2,1) 贴左边界（x-r=0≤0）和上边界（y+r=3≥3）。两圆圆心距²=2 ≤ (1+1)²=4，合并成一块，该块同时贴住「左+下」→ `False`。

```python
def canReachCorner(X, Y, circles):
    n = len(circles)
    p = list(range(n))
    def find(a):
        while p[a] != a:
            p[a] = p[p[a]]; a = p[a]
        return a
    for i in range(n):
        for j in range(i+1, n):
            x1,y1,r1 = circles[i]; x2,y2,r2 = circles[j]
            if (x1-x2)**2+(y1-y2)**2 <= (r1+r2)**2:
                p[find(i)] = find(j)
    mask = [0]*n
    for i,(x,y,r) in enumerate(circles):
        if x <= r: mask[i] |= 1        # 左
        if y <= r: mask[i] |= 2        # 下
        if x+r >= X: mask[i] |= 4      # 右
        if y+r >= Y: mask[i] |= 8      # 上
    for i in range(n):
        mask[find(i)] |= mask[i]
    for i in range(n):
        m = mask[find(i)]
        if (m&1 and m&2) or (m&4 and m&8) or (m&1 and m&4) or (m&2 and m&8):
            return False
    return True
```

## 复杂度
时间：O(n²·α(n))，n 为圆数，双重循环枚举圆对贡献 n²。
空间：O(n)，并查集父数组与 mask 各开 n。

## 易错点
- 圆心在矩形外但圆仍可能切进矩形（如示例 4 的 (5,5,1) 与 4×4 矩形无交，应剔除）。若直接用 `x<=r` 判左边界，会把矩形外的圆误判为贴边 → 先按「圆心到矩形距离 ≤ r」过滤，再判边界。
- 两圆相切（距离² == (r1+r2)²）也算连通，路径不能穿过切点。用 `<` 而非 `<=` 会漏合并示例 3 这类相切圆 → 必须用 `<=`。

## 如果面试官追问
问：若要求输出一条具体路径怎么办？
答：并查集只判可达性，输出路径需在矩形内做栅格/几何搜索，复杂度会升到与坐标范围相关，不再适用本题 10^9 规模。
