## 一句话思路
用 BFS 逐层遍历，每层记录第一个出队节点的值，最后一层的那个值就是答案。

## 怎么做
1. 把 `root` 放进队列 `q`，初始化 `ans = root.val`。
2. 外层 `while q` 循环每轮先取 `size = len(q)`，这一轮只处理当前这一层。
3. 内层循环 `i` 从 0 到 `size-1`，`i == 0` 时把出队节点的值写进 `ans`（该层最左）。
4. 出队节点的左右子节点非空就入队，循环结束后 `ans` 即最底层最左值。

以示例 2 `[1,2,3,4,null,5,6,null,null,7]` 为例：第 1 层 `size=1`，出队 `1`，`ans=1`；第 2 层出队 `2,3`，`ans=2`；第 3 层出队 `4,5,6`，`ans=4`；第 4 层只有 `7`，`ans=7`。每层第一个出队节点恰好是该层最左节点，最后一层覆盖掉前面的值。

```python
from collections import deque
q = deque([root])
ans = root.val
while q:
    size = len(q)
    for i in range(size):
        node = q.popleft()
        if i == 0:
            ans = node.val
        if node.left:
            q.append(node.left)
        if node.right:
            q.append(node.right)
```

关键点：`ans` 在每层开头被覆盖，所以循环结束时留下的是最深一层的值，不需要额外记录层号。

## 复杂度
时间 O(n)：每个节点入队出队各一次，n 为节点数。
空间 O(w)：队列最多存一层节点，w 为最大层宽，最坏 O(n)。

## 易错点
- 输入 `[1,2,3,4]`（4 是 2 的左孩子）→ 若用 DFS 只按「先左后右」取第一个到达最深层的节点，容易把 `4` 和别的分支搞混；BFS 按层出队天然保证同层从左到右，不会错。
- 输入 `[1,2,3,4,null,5,6,null,null,7]` → 若把 `ans` 写成「每层最后一个出队节点」，会得到 `3`、`6`、`7` 里的 `7` 看似对，但示例 1 `[2,1,3]` 会错成 `3`；必须取 `i == 0` 的那个。

## 如果面试官追问
问：不用队列、只用 O(1) 额外空间能做吗？
答：可以，用 Morris 遍历按层序模拟，但代码复杂度高，本题 n≤10^4 用 BFS 足够。
