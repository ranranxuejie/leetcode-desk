## 一句话思路
把每个字符串的差值数组转成元组做哈希计数，出现次数为 1 的那个元组对应的字符串就是答案。

## 怎么做
1. 遍历 `words`，对每个 `w` 用 `tuple(ord(w[j+1]) - ord(w[j]) for j in range(len(w)-1))` 算出差值元组。
2. 用字典 `cnt` 统计每个差值元组出现的次数。
3. 再遍历一次，返回第一个差值元组计数为 1 的字符串。

以 `words = ["adc","wzy","abc"]` 为例：`"adc"` 得 `(3,-1)`，`"wzy"` 得 `(3,-1)`，`"abc"` 得 `(1,1)`。`cnt` 为 `{(3,-1):2, (1,1):1}`，第二次遍历到 `"abc"` 时 `cnt[(1,1)] == 1`，返回它。

```python
cnt = {}
for w in words:
    d = tuple(ord(w[j+1]) - ord(w[j]) for j in range(len(w)-1))
    cnt[d] = cnt.get(d, 0) + 1
for w in words:
    d = tuple(ord(w[j+1]) - ord(w[j]) for j in range(len(w)-1))
    if cnt[d] == 1:
        return w
```

也可以只算前三个字符串的差值元组：若前两个相同，则基准是它们，第三个若不同直接返回，否则往后找第一个不同的；若前两个不同，则第三个必与其中之一相同，另一个就是答案。这样省掉字典，但边界分支多，面试时字典法更稳。

## 复杂度
时间：O(m·n)，m 为 `words` 长度，n 为字符串长度，每个字符串扫一遍算差值。
空间：O(m·n)，字典存 m 个长度为 n-1 的元组。

## 易错点
- 用 `list` 当字典键 → 直接 `TypeError: unhashable type: 'list'`，因为差值数组是可变列表；必须 `tuple(...)` 包一层再存。
- 差值算成 `ord(w[j]) - ord(w[j+1])`（顺序反了）→ 示例 1 里 `"adc"` 会得 `(-3,1)`，虽然同组字符串仍一致、答案碰巧不变，但遇到 `["ab","ba",...]` 这类对称数据时正负号翻转会让本该相同的两组被拆开，必须固定 `后减前`。

## 如果面试官追问
问：如果要求返回所有差值数组不同的字符串（可能不止一个）？
答：把第二次遍历改成收集所有 `cnt[d] == 1` 的 `w` 放进列表返回即可，逻辑不变。
