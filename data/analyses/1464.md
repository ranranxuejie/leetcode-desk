## 一句话思路
取 nums 中最大的两个数 a、b，答案就是 (a-1)*(b-1)，因为减 1 不改变大小顺序。

## 怎么做
1. 扫描一遍 nums，维护最大值 `m1` 和次大值 `m2`，两者允许相等但必须来自不同下标。
2. 遇到 `x > m1` 时，先把 `m1` 降级给 `m2`，再更新 `m1 = x`；否则若 `x > m2` 只更新 `m2`。
3. 返回 `(m1 - 1) * (m2 - 1)`。

以 `nums = [3,4,5,2]` 为例：初始 `m1 = m2 = -inf`；读 3 后 `m1=3, m2=-inf`；读 4 时 4>3，故 `m2=3, m1=4`；读 5 时 5>4，故 `m2=4, m1=5`；读 2 时 2 既不大于 5 也不大于 4，两个变量都不动。最终 `(5-1)*(4-1) = 12`。

```python
m1 = m2 = -1
for x in nums:
    if x > m1:
        m1, m2 = x, m1
    elif x > m2:
        m2 = x
return (m1 - 1) * (m2 - 1)
```

注意 `m1, m2 = x, m1` 这一行是同时赋值：旧 `m1` 落到 `m2`，不会先被 `x` 覆盖。若拆成 `m1 = x; m2 = m1`，`m2` 就变成 `x` 本身，`[3,4,5,2]` 会算出 `(5-1)*(5-1)=16`。

## 复杂度
时间 O(n)：一次遍历，n 是 `len(nums)`。
空间 O(1)：只开 `m1`、`m2` 两个变量。

## 易错点
- 输入 `[5,5]` → 若用 `set(nums)` 去重再取前两大，只剩一个 5，直接报错或算错 → 题目要求不同下标、不要求不同值，必须按位置保留两个 5，答案 `(5-1)*(5-1)=16`。
- 输入 `[1,1]` → 若把 `m1`、`m2` 初始化成 0 或 1，`elif x > m2` 分支永远不触发，`m2` 停在初值 → 用 `-1` 初始化（`nums[i] >= 1` 保证任何真实元素都大于它），得到 `(1-1)*(1-1)=0`。

## 如果面试官追问
问：如果要求返回下标而不是乘积呢？
答：`m1`、`m2` 各存一个 `(值, 下标)` 元组，比较时取 `[0]`，返回两个下标即可，逻辑不变。
