## 一句话思路
答案是 `min(n*n, maxWeight // w)`：甲板格子数和重量上限各自给出一个上界，取小者即可达到。

## 怎么做
1. 甲板容量是 `n * n`，这是数量上界。
2. 重量上界是 `maxWeight // w`，整除因为集装箱重量恰好为 `w`，装不满一个就不装。
3. 两个上界同时成立，所以取 `min`，且这个值一定可达（格子够、重量也够）。

以示例 2 为例：`n = 3` 得 `n*n = 9`，`maxWeight // w = 20 // 5 = 4`，`min(9, 4) = 4`。重量上界先卡住，甲板还剩 5 个空格子用不上。

```python
def maxContainers(n, w, maxWeight):
    by_deck = n * n
    by_weight = maxWeight // w
    return min(by_deck, by_weight)
```

关键就一行 `min(n*n, maxWeight // w)`，不需要模拟装船，也不需要排序或贪心遍历。

## 复杂度
时间：O(1)，只做一次乘法、一次整除、一次比较，与 `n`、`maxWeight` 无关。
空间：O(1)，没有开任何额外容器。

## 易错点
- 输入 `n = 3, w = 5, maxWeight = 20` → 若只算 `n*n = 9` 就返回 9，超重（9×5=45 > 20）→ 必须先算 `maxWeight // w = 4` 再取 `min`。
- 输入 `n = 2, w = 3, maxWeight = 15` → 若写成 `maxWeight // w = 5` 直接返回 5，超过甲板 4 个格子 → 必须用 `n*n` 封顶，两个上界缺一不可。

## 如果面试官追问
问：如果每个集装箱重量不同，怎么改？
答：变成带容量约束的 0/1 背包，按重量排序后贪心不再成立，需要 DP。
