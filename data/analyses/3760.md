## 一句话思路
答案就是 `s` 中不同字符的个数：每个不同字符最多贡献一个子串首字母，且按首次出现位置切分即可全部取到。

## 怎么做
1. 用 `set(s)` 统计不同字符数，直接返回其大小。
2. 为什么能取到：按每个字符**首次出现**的位置切分，第 i 段从该字符首次出现处开始，到下一个首现字符前一位结束。
3. 以 `s = "abab"` 为例，`set(s) = {'a','b'}`，大小 2；切分点是下标 0（'a'）和 1（'b'），得到 `"a"` 与 `"bab"`，两段首字母不同。
4. 若某字符只在后面重复出现（如 `"aaaa"` 中只有 'a'），它不产生新段，`set` 大小 1，与示例 3 一致。

```python
def maxDistinct(s):
    seen = set()
    for ch in s:
        seen.add(ch)
    return len(seen)
```

关键中间值：遍历 `"abab"` 时 `seen` 依次变为 `{'a'}`、`{'a','b'}`，之后不再增长，最终 `len(seen) == 2`。

## 复杂度
时间：O(n)，n 为 `s` 长度，每个字符进 `set` 一次。
空间：O(1)，`seen` 最多存 26 个小写字母。

## 易错点
- 输入 `"abab"` → 误以为要数「相邻不同」的对数得 3 或按最长不重复子串得 2 但理由错 → 正确做法是只数不同字符种类，`len(set(s))`。
- 输入 `"aaaa"` → 误按「每个字符一段」得 4 → 正确做法是同一字符只能当一次首字母，答案 1。

## 如果面试官追问
问：若要求输出具体划分方案怎么办？
答：记录每个字符首次出现的下标，排序后作为切分点，相邻切分点之间即一段。
