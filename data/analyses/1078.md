## 一句话思路
把 `text` 按空格切成词数组，扫一遍相邻三词，命中 `first, second` 就收第三个词。

## 怎么做
1. `words = text.split()`，得到词数组，长度记为 `m`。
2. 枚举起点 `i` 从 `0` 到 `m-3`，只检查 `words[i] == first and words[i+1] == second`。
3. 命中就把 `words[i+2]` 追加到结果列表。
4. 返回结果列表。

以示例 1 为例：`words = ["alice","is","a","good","girl","she","is","a","good","student"]`，`m = 10`。`i = 2` 时 `words[2]="a"`、`words[3]="good"` 命中，收 `words[4]="girl"`；`i = 7` 时 `words[7]="a"`、`words[8]="good"` 命中，收 `words[9]="student"`。其余起点不命中，结果 `["girl","student"]`。

```python
words = text.split()
res = []
for i in range(len(words) - 2):
    if words[i] == first and words[i + 1] == second:
        res.append(words[i + 2])
return res
```

关键在 `range(len(words) - 2)`：上界必须是 `m-2`，这样 `i+2` 最大取到 `m-1`，不会越界。示例 2 里 `words = ["we","will","we","will","rock","you"]`，`i = 0` 命中收 `"we"`，`i = 2` 命中收 `"rock"`，`i = 1` 的 `"will","we"` 不匹配被跳过——注意 `i = 2` 的 `"we"` 同时是上一次命中的第三个词，也照样能当新的 `first`，所以不能命中后跳三步。

## 复杂度
时间 O(n)：`n` 是 `text` 字符数，切词和单次扫描各 O(n)。
空间 O(n)：`words` 列表和 `res` 各占 O(n)，`res` 最坏约 `m/2` 个词。

## 易错点
- 用 `range(len(words) - 1)` 或 `range(len(words))` 当上界 → 在 `i = m-2`、`i = m-1` 时访问 `words[i+2]` 抛 IndexError，或漏掉边界判断 → 上界写死 `len(words) - 2`。
- 命中后写 `i += 3` 想跳过已用词 → 示例 2 中 `i = 0` 命中后跳到 `i = 3`，会漏掉 `i = 2` 的 `"we","will"`，少收 `"rock"` → 每次只前进 1，允许重叠匹配。

## 如果面试官追问
问：若 `text` 用任意空白分隔（多个空格、制表符）怎么办？
答：`split()` 不带参数本身就按任意空白切且丢弃空串，代码一行不用改。
