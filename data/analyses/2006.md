## 一句话思路
边扫 `nums` 边用哈希表记录已见数值的频次，对每个 `x` 累加 `x-k` 和 `x+k` 的出现次数，这样每对只被后出现的那个数统计一次。

## 怎么做
1. 初始化空字典 `cnt` 和答案 `ans = 0`。
2. 从左到右遍历 `nums` 中的每个 `x`，先查表再更新表，保证不会把 `x` 和自己配对。
3. 对每个 `x`，把 `cnt.get(x - k, 0) + cnt.get(x + k, 0)` 加到 `ans` 上。
4. 把 `x` 的频次加一，继续下一个。

以示例 1 `nums = [1,2,2,1], k = 1` 为例，走到第二个 `2`（下标 2）时，`cnt` 已经是 `{1: 1, 2: 1}`，此时 `cnt.get(1, 0) + cnt.get(3, 0) = 1 + 0 = 1`，`ans` 从 1 变成 2；最后那个 `1` 查表得 `cnt.get(0,0) + cnt.get(2,0) = 0 + 2 = 2`，`ans` 最终为 4。

```python
cnt = {}
ans = 0
for x in nums:
    ans += cnt.get(x - k, 0) + cnt.get(x + k, 0)
    cnt[x] = cnt.get(x, 0) + 1
return ans
```

关键点：查表必须在 `cnt[x] += 1` 之前，否则 `k = 0` 时 `x` 会和自己配对（本题 `k >= 1`，但顺序仍要写对）。

## 复杂度
时间：O(n)，`n = len(nums)`，每个元素只做两次字典查询和一次插入。
空间：O(min(n, 100))，`cnt` 最多存 100 个不同值（`nums[i] <= 100`）。

## 易错点
- 输入 `nums = [1,2,2,1], k = 1` 时，若先 `cnt[x] += 1` 再查表，第二个 `2` 会把自己算进去，`ans` 偏大；正确做法是先累加 `cnt.get(x-k,0) + cnt.get(x+k,0)`，再更新 `cnt[x]`。
- 输入 `nums = [1,3], k = 3` 时，若只查 `x - k` 不查 `x + k`，会漏掉 `1` 在 `3` 之前出现的情况（`3 - 3 = 0` 查不到，但 `1 + 3 = 4` 也查不到，实际这对差为 2 不满足；换成 `nums = [3,1], k = 2` 时只查 `x - k` 就会漏掉 `1` 配 `3`）；正确做法是 `x - k` 和 `x + k` 两个方向都查。

## 如果面试官追问
追问：若 `nums[i]` 范围放大到 `10**9` 且要求输出所有数对下标？
答：哈希表仍可用，键换成实际值，值存下标列表，查 `x-k`/`x+k` 时把当前下标与列表内每个下标配对输出。
