## 一句话思路
用并查集维护连续 1 段的左右端点，每步合并后按段长计数，记录最后一次计数为 m 的步骤。

## 怎么做
1. 开 `parent`、`size` 两个数组，`parent[i] = i` 表示 i 尚未被点亮（或作为根），点亮 `arr[i]` 时把它当作新段。
2. 点亮位置 `p` 后，检查 `p-1` 和 `p+1` 是否已点亮，若已点亮就 `union` 合并，合并后新段长度 = 两段长度之和 + 1。
3. 用 `cnt` 字典记录当前长度恰好为 `m` 的段数，每步合并后若 `cnt[m] > 0` 就更新 `ans = i+1`（步骤从 1 开始）。
4. 返回 `ans`，初始化为 -1。

以示例 1 `arr = [3,5,1,2,4], m = 1` 为例：步骤 4 点亮 `arr[3]=2`，此时 `p-1=1` 已亮（长度 1），`p+1=3` 已亮（长度 1），合并后段长 = 1+1+1 = 3，`cnt[1]` 从 2 减到 1，仍大于 0，`ans = 4`。

```python
parent = list(range(n + 2))
size = [0] * (n + 2)
cnt = {}
ans = -1

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

for i, p in enumerate(arr):
    size[p] = 1
    for q in (p - 1, p + 1):
        if size[q] > 0:
            rp, rq = find(p), find(q)
            if rp != rq:
                parent[rq] = rp
                size[rp] += size[rq]
    cnt[size[find(p)]] = cnt.get(size[find(p)], 0) + 1
    if cnt.get(m, 0) > 0:
        ans = i + 1
```

## 复杂度
时间：O(n α(n))，每个位置最多被合并两次，路径压缩近似常数。
空间：O(n)，`parent`、`size` 各开 n+2，`cnt` 最多 n 个键。

## 易错点
1. 输入 `arr = [1], m = 1` → 若步骤从 0 开始计数会返回 0，正确做法是 `ans = i + 1`，因为题面步骤从 1 开始。
2. 输入 `arr = [2,1], m = 2` → 若合并时只更新 `size` 不更新 `cnt`，会漏掉步骤 2 的段长 2；正确做法是每次合并后把旧段长从 `cnt` 减 1、新段长加 1，或像上面代码那样只对新段长计数并保留历史。

## 如果面试官追问
问：若 n 扩大到 10^6 且要求输出所有长度为 m 的段？答：仍用并查集，额外维护 `segments` 集合按长度分组，合并时 O(1) 更新。
