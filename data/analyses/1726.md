## 一句话思路
用哈希表统计每对元素乘积出现的次数，同一乘积的任意两对可组成 8 个元组，累加 `C(cnt,2)*8`。

## 怎么做
1. 双重循环枚举所有 `i < j`，把 `nums[i]*nums[j]` 作为 key 累加计数。
2. 遍历哈希表，对每个出现次数 `cnt` 累加 `cnt*(cnt-1)//2 * 8`。
3. 以 `nums = [2,3,4,6]` 为例：乘积表为 `{6:1, 8:1, 12:2, 18:1, 24:1}`，只有 `12` 出现 2 次（来自 `2*6` 和 `3*4`），贡献 `1*8 = 8`。

```python
from collections import defaultdict

def tupleSameProduct(nums):
    cnt = defaultdict(int)
    n = len(nums)
    for i in range(n):
        for j in range(i + 1, n):
            cnt[nums[i] * nums[j]] += 1
    ans = 0
    for c in cnt.values():
        ans += c * (c - 1) // 2 * 8
    return ans
```

关键点：`i < j` 保证每对只统计一次，避免 `2*6` 和 `6*2` 重复计数；`c*(c-1)//2` 是组合数，乘 8 是因为两对 `(a,b)` 和 `(c,d)` 各有 2 种排列，共 `2*2*2 = 8` 个有序元组。

## 复杂度
时间：O(n²)，双重循环枚举所有元素对，n 为 `len(nums)`。
空间：O(n²)，哈希表最多存 n(n-1)/2 个不同乘积。

## 易错点
1. 输入 `[2,3,4,6]` → 若用 `i != j` 双重循环会把 `2*6` 和 `6*2` 都计入，`12` 的计数变成 4 而非 2，答案错成 48 → 必须用 `i < j` 只枚举一次。
2. 输入 `[1,2,4,5,10]` → 若只乘 4 而非 8，得到 8 而非 16 → 两对 `(a,b)`、`(c,d)` 内部各可交换（2×2），两对之间还可互换位置（×2），共 8 种。

## 如果面试官追问
问：若 nums 允许重复元素怎么办？
答：先对每个值计数，枚举值对时按 `cnt[x]*cnt[y]` 加权，再处理同值对 `C(cnt[x],2)`，组合公式不变。
