## 一句话思路
排序后枚举「保留下来的目标豆数」为某个 `beans[i]`，用前缀和 O(1) 算出总代价，取最小。

## 怎么做
1. 升序排序 `beans`，并求前缀和 `pre`，`pre[k]` 表示前 k 个元素之和。
2. 枚举目标值 `t = beans[i]`：比 t 小的袋子全清空，比 t 大的袋子削到 t。
3. 代价 = `pre[i]`（清空前 i 个）+ `(total - pre[i]) - (n - i) * t`（后段削平），取最小。
4. 用示例 1 `[4,1,6,5]` 验证：排序后 `[1,4,5,6]`，`total=16`。取 `i=1, t=4`：清空 `pre[1]=1`，后段 `16-1-(4-1)*4=3`，代价 `1+3=4`，正是答案。

```python
beans.sort()
n = len(beans)
pre = [0] * (n + 1)
for i, x in enumerate(beans):
    pre[i + 1] = pre[i] + x
total = pre[n]
ans = total  # 全清空，上界
for i in range(n):
    t = beans[i]
    cost = pre[i] + (total - pre[i]) - (n - i) * t
    ans = min(ans, cost)
```

关键点：`i` 是「第一个等于 t 的下标」，所以 `pre[i]` 恰好是严格小于 t 的那批袋子的豆数总和，被清空；从 `i` 到 `n-1` 共 `n-i` 个袋子削到 t。

## 复杂度
时间：排序 O(n log n) 主导，枚举 O(n)。
空间：前缀和数组 O(n)，排序本身 O(log n) 栈。

## 易错点
- 输入 `[1,1,1]` 这类全等数组 → 若把「清空前 i 个」写成「清空前 i+1 个」，会把等于 t 的袋子也清空，代价从 0 错成 1 → 正确做法是 `pre[i]` 只覆盖严格小于 t 的部分，等号归到后段削平。
- 输入 `[100000]*100000` → 代价累加达到 10^10 量级，若用 32 位中间变量会截断 → Python 整数天然安全，但若按题目要求做 32 位截断的模拟，要确认 `total - pre[i] - (n-i)*t` 全程用大整数再截断。

## 如果面试官追问
问：如果要求输出具体方案（哪些袋子清空、哪些削到多少）？
答：记录取到最小代价的 `i`，则下标 `< i` 的清空，`>= i` 的统一削到 `beans[i]`，直接按此输出即可。
