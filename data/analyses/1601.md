## 一句话思路
requests 长度 ≤16，枚举全部 2^m 个子集，用「每栋楼净变化全为 0」判定可行，取最大子集大小。

## 怎么做
1. 用 `mask` 从 0 枚举到 `(1<<m)-1`，`m = len(requests)`，`mask` 的第 i 位表示选不选 `requests[i]`。
2. 对每个 `mask` 先看 `mask.bit_count()` 是否超过当前最优 `best`，不超过就跳过，省掉大量无效判定。
3. 维护长度 n 的 `delta` 数组：选中 `[f,t]` 时 `delta[f] -= 1`、`delta[t] += 1`。
4. 判定 `all(x == 0 for x in delta)`，成立则更新 `best`。

以示例 1 为例，`m=6`，最优 `mask` 选中请求 0、1、3、4、5（跳过第二个 `[0,1]`）。此时 `delta` 依次累加：请求 0 得 `[-1,1,0,0,0]`，请求 1 得 `[0,0,0,0,0]`，请求 3 得 `[0,-1,1,0,0]`，请求 4 得 `[-1,-1,1,1,0]`，请求 5 得 `[-1,-1,1,0,1]`——注意这里必须把 5 个请求全算完再看，中途非零不代表失败；最终这组不成立，真正成立的是选 0、1、3、4 再加 `[3,4]` 之外的组合，`best` 停在 5。

```python
m, best = len(requests), 0
for mask in range(1 << m):
    cnt = mask.bit_count()
    if cnt <= best:
        continue
    delta = [0] * n
    for i in range(m):
        if mask >> i & 1:
            f, t = requests[i]
            delta[f] -= 1
            delta[t] += 1
    if all(x == 0 for x in delta):
        best = cnt
return best
```

## 复杂度
时间：O(2^m · m)，m 是 requests 长度（≤16），n 只进 `delta` 初始化。
空间：O(n)，只开一个 `delta` 数组，无递归栈。

## 易错点
1. 输入含 `[0,0]` 这类自环（示例 2）→ 若写成 `delta[f] -= 1; delta[t] += 1` 但误判「from==to 时跳过」→ 会漏掉这个请求仍可被选中、白白少算 1。正确做法是照常执行两条语句，自环自然抵消为 0。
2. 输入如示例 1 有重复请求 `[0,1]` 出现两次 → 若用 `set(requests)` 去重再枚举 → 会把两个不同员工当成一个，答案从 5 掉到 4。正确做法是按**下标**枚举，重复请求各占一位。

## 如果面试官追问
问：requests 长度放大到 30 怎么办？
答：2^30 枚举不可行，改用 DFS 按楼逐个配平 + 剪枝，或转成每个连通分量内求最大欧拉子图，规模依赖分量大小而非全局 m。
