## 一句话思路
对每个结点返回「蓝色连通块大小为 0..k」的 dp 数组，用树形 DP 自底向上合并，因为连通块只可能跨过父子边。

## 怎么做
1. 定义 `dp[u][j]`：以 u 为根的子树中，u 所在蓝色连通块大小为 j 时的最大价值和；`j = 0` 表示 u 不染蓝。
2. 后序遍历，先拿到左右孩子的 dp 数组，再决定 u 是否染蓝。
3. u 不染蓝时，左右孩子各自独立，取各自 dp 的最大值相加。
4. u 染蓝时，左右孩子若染蓝必须与 u 连通，块大小相加再加 1，且不超过 k。

以示例 1 的 `root = [5,2,3,4], k = 2` 为例：叶子 4 的 `dp = [0, 4]`，叶子 3 的 `dp = [0, 3]`。结点 2 只有左孩子 4，染蓝时 `dp[2][2] = 4 + 2 = 6`。根 5 合并时，左孩子 2 取 `max(dp[2]) = 6`（不染蓝分支），右孩子 3 取 3，根染蓝且只接右孩子，得 `5 + 3 + 6 = 14`？注意此时根与 2 不连通，2 的块独立，合法，但答案 12 来自 5、3、4 连通块大小 2 加独立结点 2 不染蓝——关键中间值是 `dp[5][2] = 5 + 3 + 4 = 12`。

```python
def dfs(u):
    if not u:
        return [0] + [-inf] * k
    L, R = dfs(u.left), dfs(u.right)
    bestL, bestR = max(L), max(R)
    dp = [bestL + bestR] + [-inf] * k   # u 不染蓝
    for i in range(k + 1):
        for j in range(k + 1 - i):
            if i + j + 1 <= k and L[i] > -inf and R[j] > -inf:
                dp[i + j + 1] = max(dp[i + j + 1], L[i] + R[j] + u.val)
    return dp
```

## 复杂度
时间：每个结点做 O(k²) 的左右合并，共 O(n·k²)。
空间：dp 数组每层 O(k)，递归栈 O(n)，合计 O(n·k)。

## 易错点
- 空孩子返回 `[0] + [-inf]*k` 而非全 0：若填 0，`dp[i+j+1]` 会把不存在的孩子当成「块大小 0 且价值 0」参与合并，导致 u 染蓝时错误地允许 i 或 j 取到非法值，答案偏大。
- u 不染蓝时左右孩子必须各取 `max`，不能固定取 `dp[0]`：示例 1 中结点 2 若强制不染蓝，`dp[5]` 就丢掉 4 的价值，输出 8 而非 12；正确做法是 `bestL + bestR` 让子树自由选择。

## 如果面试官追问
问：k 放大到 10⁵ 怎么办？答：dp 数组退化成「块大小」维度不可行，需改成按价值贪心或换题意，本题 k ≤ 10 是刻意约束。
