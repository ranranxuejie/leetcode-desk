## 一句话思路
用 `dp[i]` 表示从当前分数 `i` 出发最终不超过 `n` 的概率，从后往前推，用滑动窗口维护 `dp[i+1..i+maxPts]` 的均值。

## 怎么做
1. 边界：`i >= k` 时已停止抽牌，概率为 `1.0`（若 `i <= n`）或 `0.0`（若 `i > n`）。
2. 逆序枚举 `i` 从 `k-1` 到 `0`，`dp[i] = window / maxPts`，其中 `window` 是 `dp[i+1]` 到 `dp[i+maxPts]` 之和。
3. 每步滑动：加入 `dp[i+maxPts]`（若下标 `< k` 才需要，因为 `>= k` 的部分是常数），移出 `dp[i+1]`。
4. 返回 `dp[0]`。

以示例 3（`n=21, k=17, maxPts=10`）为例，`i=16` 时窗口覆盖 `dp[17..26]`，其中 `17..21` 贡献 5 个 `1.0`、`22..26` 贡献 0，故 `dp[16] = 5/10 = 0.5`；继续推到 `dp[0]` 得 `0.73278`。

```python
dp = [0.0] * (n + 1)
window = 0.0
for i in range(k - 1, -1, -1):
    # 加入新进入窗口的 dp[i + maxPts]
    if i + maxPts <= n:
        window += dp[i + maxPts] if i + maxPts < k else 1.0
    # 移出即将离开窗口的 dp[i + 1]
    if i + 1 < k:
        window -= dp[i + 1]
    dp[i] = window / maxPts
return dp[0]
```

注意 `i + maxPts >= k` 的那些项恒为 `1.0`（只要 `<= n`），不必存进 `dp`，直接加常数即可。

## 复杂度
时间 O(n)：`i` 从 `k-1` 到 `0` 各算一次，滑动窗口 O(1)。
空间 O(n)：`dp` 数组长度 `n+1`，无其他额外结构。

## 易错点
- `k = 0` 时爱丽丝一开始就停止，`dp[0]` 应为 `1.0`。若循环写成 `range(k-1, -1, -1)` 会直接跳过返回 `dp[0]=0.0`，错成 0；正确做法是先判 `k == 0` 返回 `1.0`。
- `n` 很大而 `k` 很小时，`i + maxPts` 可能超过 `n`，此时 `dp[i+maxPts]` 越界或应视为 0。若不加 `if i + maxPts <= n` 判断，会错把 `> n` 的项当 `1.0` 累加，概率偏大；正确做法是只在 `i+maxPts <= n` 时加入窗口。

## 如果面试官追问
若 `maxPts` 达到 `10^9` 而 `n` 只有 `10^4`，怎么做？答：窗口右端几乎全是 `1.0`，只需维护 `min(maxPts, n-i)` 个有效项，复杂度仍是 O(n)。
