## 一句话思路
按 26 进制逐位累加，`ord(ch) - ord('A') + 1` 把字母映射成 1~26，因为 Excel 列名是「无 0 的 26 进制」。

## 怎么做
1. 初始化 `res = 0`，从左到右遍历 `columnTitle` 的每个字符 `ch`。
2. 每步先让已有结果左移一位：`res = res * 26`。
3. 再把当前字符的数值加上去：`res += ord(ch) - ord('A') + 1`。
4. 遍历结束返回 `res`。

以示例 2 `columnTitle = "AB"` 为例：处理 `'A'` 后 `res = 0 * 26 + 1 = 1`；处理 `'B'` 时先 `res = 1 * 26 = 26`，再 `res = 26 + 2 = 28`。关键中间值是第二步的 `26`——它体现「A 这一位权重是 26 的一次方」，而不是把 `'A'` 当成 0。

```python
res = 0
for ch in columnTitle:
    res = res * 26 + (ord(ch) - ord('A') + 1)
return res
```

注意 `ord('A') - ord('A') + 1 = 1`，所以 `"A"` 得到 1 而不是 0；这正是「无 0 的 26 进制」与普通 26 进制的唯一差别。示例 3 `"ZY"`：`'Z'` → `26`，`'Y'` → `26 * 26 + 25 = 701`，与输出一致。

## 复杂度
时间 O(n)：n 为 `columnTitle` 长度，最多 7，每字符常数次运算。
空间 O(1)：只开 `res` 一个累加变量，无额外容器。

## 易错点
- 输入 `"A"` → 若写成 `ord(ch) - ord('A')` 会得到 0，输出 0 → 正确做法是 `+ 1`，让 A 映射到 1。
- 输入 `"ZY"` → 若从右往左算却把权重写成 `26**i` 且 i 从 0 起、同时漏掉 `+1`，会得到 700 → 正确做法是每位先乘 26 再加 `1~26` 的值，或从右起用 `26**i` 配 `+1`。

## 如果面试官追问
问：反过来给定整数 n 求列名怎么做？
答：循环 `n -= 1` 后取 `n % 26` 映射成字母、`n //= 26`，因为要消掉「无 0」的偏移。
