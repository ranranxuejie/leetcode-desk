## 一句话思路
把每个串拆成偶数位串 E 和奇数位串 O，等价当且仅当 E、O 各自循环同构，用「最小循环表示」做哈希键分组。

## 怎么做
1. 对每个 `words[i]`，用切片 `s[0::2]`、`s[1::2]` 取出 E 和 O（长度不同不影响，各自独立处理）。
2. 对 E、O 分别求最小循环表示（Booth 算法，O(len)），得到唯一规范形。
3. 以 `(minrep(E), minrep(O))` 为键放进 set，set 大小即答案。
4. 关键中间值：示例 1 的 `"ntgwz"`，E=`"ngz"` 的最小循环表示是 `"gnz"`（三个旋转 `ngz/zng/gnz` 中字典序最小），O=`"tw"` 是 `"tw"`；`"zwntg"` 的 E=`"zng"`、O=`"wt"`，最小表示同样是 `("gnz","tw")`，两串落同一键。

```python
def minrep(s):
    n = len(s)
    if n <= 1: return s
    ss, i, j, k = s + s, 0, 1, 0
    while i < n and j < n and k < n:
        a, b = ss[i + k], ss[j + k]
        if a == b:
            k += 1
            continue
        if a > b: i += k + 1
        else: j += k + 1
        if i == j: j += 1
        k = 0
    return ss[min(i, j):min(i, j) + n]

keys = {(minrep(w[0::2]), minrep(w[1::2])) for w in words}
return len(keys)
```

注意 `w[0::2]` 与 `w[1::2]` 长度最多差 1，但两者永远独立旋转，不能合并成一个键。

## 复杂度
时间：总长 N=5e5，每个字符在 Booth 里被比较常数次，O(N)。
空间：每个串临时开 2 倍 E/O 的 `ss`，峰值 O(max_len)，键集合 O(不同组数 × 串长)。

## 易错点
- 输入 `["ab","ba"]`：E 分别是 `"a"`、`"b"`，O 是 `"b"`、`"a"`，若只比较「E+O 排序后的字符多重集」会误判等价 → 必须分别对 E、O 求最小循环表示，两个键都要对上。
- 输入 `["a","aa"]`：长度不同，E/O 长度也不同，若把键写成 `minrep(E)+minrep(O)` 拼接，`"a"+"a"` 与 `"aa"+""` 可能撞键 → 用元组 `(minrep(E), minrep(O))` 而不是字符串拼接。

## 如果面试官追问
若要求输出具体分组方案而非组数？答：把 set 换成 `dict[key] -> list[word]`，遍历时 append，最后取 values 即可，复杂度不变。
