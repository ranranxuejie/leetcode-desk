## 一句话思路
用长度为 k 的滑动窗口滚动出每个子串的整数值，存进集合，最后看集合大小是否等于 2**k。

## 怎么做
1. 若 `len(s) < k`，直接返回 `False`，因为连一个长度为 k 的子串都凑不出。
2. 先算 `s[:k]` 的整数值 `cur`，把它放进 `seen`。
3. 从 `i = k` 开始滑动：`cur = ((cur << 1) & mask) | int(s[i])`，其中 `mask = (1 << k) - 1`，每步把新值加入 `seen`。
4. 滑完后返回 `len(seen) == 1 << k`。

以 `s = "00110110", k = 2` 为例：`mask = 3`，初始 `cur = 0`（"00"）；`i=2` 时 `cur = ((0<<1)&3)|1 = 1`（"01"）；`i=3` 时 `cur = ((1<<1)&3)|1 = 3`（"11"）；`i=4` 时 `cur = ((3<<1)&3)|0 = 2`（"10"）。`seen = {0,1,3,2}`，大小 4 = `1<<2`，返回 `True`。

```python
if len(s) < k:
    return False
mask = (1 << k) - 1
cur = int(s[:k], 2)
seen = {cur}
for i in range(k, len(s)):
    cur = ((cur << 1) & mask) | (ord(s[i]) - 48)
    seen.add(cur)
return len(seen) == (1 << k)
```

关键点：`& mask` 只保留低 k 位，等价于丢掉窗口最左那位；`ord(s[i]) - 48` 比 `int(s[i])` 快，但语义一样。

## 复杂度
时间 O(n)：n = `len(s)`，每个字符进窗口一次、出窗口一次，集合插入 O(1)。
空间 O(2**k)：`seen` 最多存 2**k 个整数，k ≤ 20 时上限约 100 万。

## 易错点
- `s = "0110", k = 2` → 若只滑到 `i = len(s)-1` 却漏掉初始窗口，`seen` 会缺 `"01"`，误判 `False`；正确做法是先把 `s[:k]` 放进 `seen` 再循环。
- `s = "0", k = 1` → 若没写 `len(s) < k` 的守卫，`int(s[:k], 2)` 在 `k > len(s)` 时切片变短、`mask` 与窗口长度不匹配，算出错误值；正确做法是先判长度再算初值。

## 如果面试官追问
问：k 放大到 10**5 怎么办？答：2**k 个串不可能全出现，直接返回 `False`，因为 `len(s) ≤ 5*10^5 < 2**k`。
