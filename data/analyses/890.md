## 一句话思路
把 pattern 和每个 word 各自压成「首次出现位置编号」的形态串，两串相等即匹配，双射自然被保证。

## 怎么做
1. 写一个 `norm(s)`：遍历 `s`，用字典记每个字符第一次出现时分配的编号，得到形如 `[0,1,1]` 的列表。
2. 对 `pattern` 求 `target = norm(pattern)`，示例中 `pattern="abb"` 得 `[0,1,1]`。
3. 遍历 `words`，`norm(w) == target` 就收进结果。
4. 关键中间值：`norm("mee")` 中 `m` 首次出现给 0、`e` 首次出现给 1、第二个 `e` 已在字典里取 1，得 `[0,1,1]`，与 target 相等 → 收；`norm("ccc")` 得 `[0,0,0]` ≠ `[0,1,1]` → 弃；`norm("dkd")` 得 `[0,1,0]` → 弃。

```python
def norm(s):
    mp, res = {}, []
    for ch in s:
        if ch not in mp:
            mp[ch] = len(mp)
        res.append(mp[ch])
    return res

target = norm(pattern)
ans = []
for w in words:
    if norm(w) == target:
        ans.append(w)
```

等价写法是双向字典：`p2w[pattern[i]] = w[i]` 且 `w2p[w[i]] = pattern[i]`，任一方向冲突即不匹配。形态串写法更短，且不用处理「反向映射已被占用」的分支。

## 复杂度
时间 O(L·n)，L = pattern.length ≤ 20，n = len(words) ≤ 50，每个字符 O(1) 查字典。
空间 O(L)，每个 word 的 `mp` 与 `res` 各至多 L 项，结果列表不计入。

## 易错点
- 只建单向映射 `p2w`：输入 `pattern="abb"`、`word="ccc"` 时 `a->c`、`b->c` 不冲突，会误判为匹配；必须同时校验 `w2p`（或直接用形态串），因为 `a` 和 `b` 不能映射到同一个 `c`。
- 用 `set` 长度比较代替映射：`len(set("abb")) == len(set("ccc"))` 都是 1，看似通过，但 `pattern="ab"`、`word="cc"` 时两个 set 长度 2 vs 1 会误杀/误放；正确做法是逐位比对形态串 `[0,1]` vs `[0,0]`。

## 如果面试官追问
问：若 words 长度到 10^5、pattern 长度到 10^4，怎么优化？
答：形态串仍是 O(L) 每词，瓶颈在总字符量；可先按 `len(set(w))` 与 `len(set(pattern))` 不等直接跳过，减少建字典次数。
