## 一句话思路
排序后对每个 y 用滑动窗口锁定满足 2x ≥ y 的 x 区间，再用二进制字典树在该窗口内查最大异或。

## 怎么做
1. 把 nums 升序排序，条件 |x-y| ≤ min(x,y) 在 x ≤ y 时等价于 2x ≥ y。
2. 双指针维护窗口 [left, i)：i 右移时把 nums[i] 插入字典树，当 2*nums[left] < nums[i] 时把 nums[left] 从树中删除并 left++。
3. 对每个 nums[i]，在树中贪心走相反位求最大异或，更新答案。
4. 以 nums=[1,2,3,4,5] 为例：i=3（值 4）时窗口是 [2,3,4]（2*2=4≥4，2*1=2<4 已踢出 1），树中查 4 得最大 4^3=7。

```python
nums.sort()
left = 0
trie = {}
ans = 0
for i, y in enumerate(nums):
    while 2 * nums[left] < y:
        erase(trie, nums[left]); left += 1
    insert(trie, y)
    ans = max(ans, query_max_xor(trie, y))
return ans
```

## 复杂度
时间 O(n log n + n·20)：排序 O(n log n)，每个数进出字典树各一次、每次 20 位。
空间 O(n·20)：字典树节点数上限，窗口最多 n 个数。

## 易错点
- 输入 [10,100]：若忘记窗口收缩，会把 10 和 100 当强数对算出 110；实际 2*10=20<100，10 必须被踢出，答案只能是 0。
- 输入 [1,2,3,4,5]：若先查后插，i=0 时树为空查不到自身；必须先 insert(y) 再 query，才能覆盖 (x,x) 这种同元素数对。

## 如果面试官追问
问：不排序能否做？答：可以，用值域分桶加前缀字典树，但排序加滑窗更短且常数更小。
