## 一句话思路
对答案 T 二分，用每个工人在 T 秒内能挖的最大高度求和，判断能否覆盖 mountainHeight。

## 怎么做
1. 二分下界 `lo = 1`，上界取 `hi = min(workerTimes) * mountainHeight * (mountainHeight + 1) // 2`（全让最快的工人干）。
2. 对每个候选 `T`，工人 `w` 能挖的最大 x 满足 `w * x * (x + 1) // 2 <= T`，用求根公式 `x = int((sqrt(1 + 8*T//w) - 1) / 2)` 再微调。
3. 累加所有工人的 x，`>= mountainHeight` 则 `hi = mid`，否则 `lo = mid + 1`。
4. 返回 `lo`。

以示例 2 的 `T = 12` 为例：`w=3` 时 `8*12//3=32`，`sqrt(33)≈5.74`，`x=(5.74-1)/2≈2`；`w=2` 时 `8*12//2=48`，`sqrt(49)=7`，`x=3`；`w=4` 时 `8*12//4=24`，`sqrt(25)=5`，`x=2`。总和 `2+3+3+2=10`，恰好覆盖。

```python
from math import isqrt

def can(T):
    total = 0
    for w in workerTimes:
        x = (isqrt(1 + 8 * T // w) - 1) // 2
        while w * (x + 1) * (x + 2) // 2 <= T:
            x += 1
        total += x
        if total >= mountainHeight:
            return True
    return False
```

用 `isqrt` 而非 `sqrt` 避免浮点误差；`while` 微调兜住整数除法向下取整的偏差。

## 复杂度
时间：二分 `O(log(hi))` 轮，每轮遍历 `n = len(workerTimes)`，共 `O(n log(hi))`。
空间：`O(1)`，只用了几个整数变量。

## 易错点
- `mountainHeight=10^5, workerTimes=[1]` 时上界达 `5*10^9`，若用 `2**31-1` 当上界会不够；必须按公式算 `hi`，Python 整数本身不溢出。
- 用 `int(sqrt(...))` 时，如 `T=3, w=1`，`8*3+1=25`，`sqrt=5.0` 可能因浮点误差算成 `4.999...` 得 `x=1` 而非 `2`；改用 `isqrt` 并加 `while` 校正。

## 如果面试官追问
若要求输出每个工人具体挖多少？答：二分定 T 后，按 `x = (isqrt(1+8*T//w)-1)//2` 逐个分配，剩余高度从前往后补 1 即可。
