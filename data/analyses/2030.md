## 一句话思路
单调栈边扫边弹，用「剩余字符够不够凑满 k 和 repetition」当弹出闸门。

## 怎么做
1. 预处理 `s` 中 `letter` 的后缀出现次数 `suf[i]`，用来判断弹栈后还能不能凑够 `repetition`。
2. 从左到右扫 `s`，每来一个字符 `c`，当栈非空且 `栈顶 > c` 且「弹出后仍能凑满长度和 letter 数」时弹栈。
3. 把 `c` 压栈，同时维护已入栈的 `letter` 计数。
4. 扫完后从栈里截取前 `k` 个（栈可能超过 k，因为压栈时没卡上限）。

以 `s = "leetcode", k = 4, letter = "e", repetition = 2` 为例：扫到第二个 `e`（下标 3）时栈为 `['e','t']`，`t > e` 且剩余还有 `cde` 能补足，弹掉 `t`，栈变 `['e']`，最终得 `ecde`。

```python
n = len(s)
suf = [0] * (n + 1)
for i in range(n - 1, -1, -1):
    suf[i] = suf[i + 1] + (s[i] == letter)
st, cnt = [], 0
for i, c in enumerate(s):
    while st and st[-1] > c:
        if len(st) - 1 + (n - i) < k:
            break
        if st[-1] == letter and cnt - 1 + suf[i] < repetition:
            break
        if st.pop() == letter:
            cnt -= 1
    st.append(c)
    if c == letter:
        cnt += 1
return ''.join(st[:k])
```

## 复杂度
时间 O(n)：每个字符至多入栈出栈各一次，`suf` 预处理也是 O(n)。
空间 O(n)：`suf` 数组和栈各占 O(n)，与 k 无关。

## 易错点
- `s = "bb", k = 2, letter = "b", repetition = 2`：若弹栈条件只判长度不判 letter 数，会把第一个 `b` 弹掉，剩 `"b"` 长度不足。正确做法是弹栈前检查 `cnt - 1 + suf[i] >= repetition`。
- `s = "leet", k = 3, letter = "e", repetition = 1`：若压栈时直接卡 `len(st) < k` 就停，会漏掉后面的 `e`，得到 `"lee"` 而非 `"eet"`。正确做法是全程压栈、最后截 `st[:k]`。

## 如果面试官追问
问：若要求 letter 恰好出现 repetition 次而非至少？答：弹栈闸门改成 `cnt - 1 + suf[i] >= repetition` 且入栈后若 `cnt == repetition` 则禁止再收 letter。
