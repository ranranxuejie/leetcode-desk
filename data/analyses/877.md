## 一句话思路
偶数堆时先手必胜：Alice 只需固定拿所有奇数下标堆或所有偶数下标堆中较大的一侧。

## 怎么做
1. 把 piles 按下标奇偶分成两组求和，`odd = sum(piles[0::2])`、`even = sum(piles[1::2])`。
2. 因为总堆数为偶数，两组各占一半，Alice 第一步选定一侧后，Bob 无论取哪端，Alice 都能继续取同一侧。
3. 以 `piles = [5,3,4,5]` 为例：`odd = 5+4 = 9`，`even = 3+5 = 8`，Alice 取下标 0 的 5，之后 Bob 取 3 或 5，Alice 都能拿到 4 或 5，最终至少 9 分。
4. 所以只需比较两组和，Alice 取较大组即必胜，返回 `True`。

```python
def stoneGame(piles):
    odd = sum(piles[0::2])
    even = sum(piles[1::2])
    return odd > even
```

关键中间值：`piles = [5,3,4,5]` 时 `odd = 9`、`even = 8`，`9 > 8` 返回 `True`。

## 复杂度
时间：O(n)，一次遍历求和，n 为堆数。
空间：O(1)，只存两个累加变量。

## 易错点
- 输入 `piles = [3,7,2,3]` 时若误以为要模拟博弈，会写成 O(n²) 的区间 DP，正确做法是直接比较奇偶下标和：`odd = 3+2 = 5`、`even = 7+3 = 10`，返回 `True`。
- 若堆数为奇数（本题约束保证偶数），奇偶分组策略失效，会错成直接返回 `True`；正确做法是回到区间 DP 或极小化极大搜索。

## 如果面试官追问
问：若堆数为奇数怎么办？
答：奇偶分组不再成立，需用区间 DP 或记忆化搜索，状态为 `(l, r)` 表示当前玩家在 `piles[l:r+1]` 上的最大净胜分。
