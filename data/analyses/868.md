## 一句话思路
用 `last` 记录上一个 1 的位置，逐位扫描 `n`，遇到新 1 就算距离并更新最大值。

## 怎么做
1. 初始化 `last = -1`（还没有 1）、`best = 0`、`i = 0`。
2. 循环条件 `while n:`，每轮取最低位 `if n & 1:` 判断是否为 1。
3. 是 1 时：若 `last != -1`，则 `best = max(best, i - last)`；然后 `last = i`。
4. 每轮 `n >>= 1`、`i += 1`，循环结束返回 `best`。

以 `n = 22`（二进制 `10110`）为例：`i=1` 时遇到第一个 1，`last` 从 -1 变成 1；`i=2` 时 `n & 1 == 1`，`best = max(0, 2-1) = 1`，`last = 2`；`i=4` 时再遇 1，`best = max(1, 4-2) = 2`。最终返回 2，与示例一致。

```python
last, best, i = -1, 0, 0
while n:
    if n & 1:
        if last != -1:
            best = max(best, i - last)
        last = i
    n >>= 1
    i += 1
return best
```

关键点：`last = -1` 这个哨兵让「第一个 1」不参与算距离，避免把 `i - (-1)` 这种假距离算进 `best`。

## 复杂度
时间：O(log n)，循环次数等于 `n` 的二进制位数，`n ≤ 10^9` 时最多 30 轮。
空间：O(1)，只开了 `last`、`best`、`i` 三个整数。

## 易错点
1. `n = 8`（`1000`）→ 若把 `last` 初始化为 0 而不是 -1，第一个 1 在 `i=3` 时会算出 `3-0=3` 并写进 `best`，错答 3 → 正确做法是 `last = -1` 并在 `last != -1` 时才更新 `best`，这样只有单个 1 时返回 0。
2. `n = 3`（`11`）→ 若在 `if n & 1` 分支里先 `last = i` 再算距离，`i - last` 恒为 0，错答 0 → 正确顺序是先算 `best = max(best, i - last)`，再执行 `last = i`。

## 如果面试官追问
问：如果要求返回最长间距对应的两个 1 的具体位置怎么办？
答：在更新 `best` 时同步记下 `(last, i)` 这对下标，返回时一并输出即可。
