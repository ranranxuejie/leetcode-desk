## 一句话思路
排序后，最优的 k 个元素必是连续窗口，枚举窗口用前缀和算「全变中位数」代价，二分答案。

## 怎么做
1. 排序 `nums`，建前缀和 `pre`，`pre[i]` 表示前 i 项和。
2. 二分频率 `f`（范围 1..n），判定是否存在长度 f 的窗口代价 ≤ k。
3. 对窗口 `[l, r]`（`r = l+f-1`），中位数下标 `m = (l+r)//2`，代价 = 左半抬到 `nums[m]` + 右半压到 `nums[m]`。
4. 代价公式：`nums[m]*(m-l) - (pre[m]-pre[l])` 加 `(pre[r+1]-pre[m+1]) - nums[m]*(r-m)`。

以 `nums=[1,2,6,4], k=3` 为例，排序后 `[1,2,4,6]`，`pre=[0,1,3,7,13]`。判 `f=3`，窗口 `[0,2]`，`m=1`，`nums[m]=2`：左侧 `2*1-(pre[1]-pre[0])=2-1=1`，右侧 `(pre[3]-pre[2])-2*1=4-2=2`，总代价 3 ≤ k，成立；`f=4` 时窗口 `[0,3]`，`m=1`，右侧 `(13-3)-2*2=6>3`，不成立，答案 3。

```python
def ok(f):
    for l in range(n - f + 1):
        r = l + f - 1
        m = (l + r) // 2
        cost = nums[m]*(m-l) - (pre[m]-pre[l]) \
             + (pre[r+1]-pre[m+1]) - nums[m]*(r-m)
        if cost <= k:
            return True
    return False

lo, hi = 1, n
while lo < hi:
    mid = (lo + hi + 1) // 2
    if ok(mid): lo = mid
    else: hi = mid - 1
return lo
```

## 复杂度
时间：排序 O(n log n)，二分 O(log n) 层，每层滑窗 O(n)，共 O(n log n)。
空间：`pre` 长度 n+1，O(n)。

## 易错点
- `nums=[1,2,6,4], k=3` 若不排序直接滑窗，窗口 `[1,2,6]` 中位数 2 代价算成 1+0+4=5 判失败，答案错成 2；必须先 `sort`，让窗口内元素天然有序才能用前缀和。
- `k=0` 且 `nums=[1,4,4,2,4]` 时，若把二分下界设成 0 或漏判 `f=1`，会返回 0；下界取 1，且 `ok(1)` 代价恒为 0 必成立，保证至少返回原众数频率 3。

## 如果面试官追问
若要求输出最终数组而非频率？答：在判定成功的窗口里记录 `l, m, r`，把窗口内元素全改成 `nums[m]`，其余不动即可。
