## 一句话思路
第 k 个灯泡被切换的次数等于 k 的约数个数，只有完全平方数的约数个数为奇数，所以答案就是 ⌊√n⌋。

## 怎么做
1. 把「第 i 轮切换第 i、2i、3i… 个灯泡」翻译成：灯泡 k 在第 d 轮被切换，当且仅当 d 整除 k。
2. 于是灯泡 k 的最终状态由 k 的约数个数决定，奇数个约数才亮。
3. 约数成对出现（d 与 k//d），只有 d == k//d 即 k 是完全平方数时才落单。
4. 所以亮灯数 = 1..n 中完全平方数的个数 = ⌊√n⌋。

以 n = 3 为例：灯泡 1 的约数是 {1}，切换 1 次，亮；灯泡 2 的约数是 {1,2}，切换 2 次，灭；灯泡 3 的约数是 {1,3}，切换 2 次，灭。只有 1 个完全平方数，返回 1。

```python
import math

def bulb_switch(n: int) -> int:
    # 完全平方数的个数就是 floor(sqrt(n))
    return math.isqrt(n)
```

`math.isqrt` 直接返回整数平方根，n = 3 时得 1，n = 10**9 时得 31622，全程整数运算，不碰浮点。

## 复杂度
时间：O(1)（isqrt 对 10^9 量级是常数级，不随 n 线性增长）。
空间：O(1)，只存一个整数结果。

## 易错点
- 用 `int(math.sqrt(n))` 代替 `math.isqrt(n)`：n 取 10**18 附近的完全平方数时，浮点误差可能让 sqrt 返回 999999999.9999999，int 截断后少 1，答案偏小。正确做法是用整数版 `math.isqrt`。
- 直接模拟 n 轮切换：n = 10**9 时循环次数是 O(n log n) 级别，必然超时。正确做法是识别出「只有完全平方数亮」这一性质，一步算出 ⌊√n⌋。

## 如果面试官追问
问：如果要求输出所有亮着的灯泡编号呢？
答：枚举 i 从 1 到 isqrt(n)，输出 i*i，共 ⌊√n⌋ 个，时间 O(√n)。
