## 一句话思路
按位统计：每个 nums1[i] 在全部数对里出现 len(nums2) 次，异或只看出现次数的奇偶。

## 怎么做
1. 把双重循环的异或和按位拆开，第 k 位上 nums1[i] 的贡献被重复 len(nums2) 次。
2. 偶数次异或抵消，所以 nums1 整体只在 len(nums2) 为奇数时参与；同理 nums2 只在 len(nums1) 为奇数时参与。
3. 用示例 1 验证：len(nums2)=4 为偶，nums1 全部作废；len(nums1)=3 为奇，取 nums2 的异或 10^2^5^0 = 13，与输出一致。
4. 示例 2：len(nums2)=2 偶、len(nums1)=2 偶，两边都不参与，直接返回 0。

```python
def xorAllNums(nums1, nums2):
    ans = 0
    if len(nums2) % 2 == 1:
        for x in nums1:
            ans ^= x
    if len(nums1) % 2 == 1:
        for x in nums2:
            ans ^= x
    return ans
```

关键中间值：示例 1 里 `len(nums2) % 2 == 0`，第一个 if 整段跳过，ans 只由 nums2 的 13 决定。

## 复杂度
时间：O(len(nums1) + len(nums2))，两个循环各扫一遍，n 取两数组长度之和。
空间：O(1)，只开 ans 一个变量，没有额外数组。

## 易错点
- 把条件写反成 `len(nums2) % 2 == 0` 才异或 nums1：示例 1 会算出 2^1^3 = 0 再 ^13 = 13 碰巧对，但示例 2 会返回 1^2^3^4 = 4 而非 0。正确是「对方长度为奇数，自己才参与」。
- 两个 if 写成 if/elif：当两数组长度都为奇数（如 nums1=[1], nums2=[2]）时只算一边得 1 或 2，正确结果是 1^2 = 3，两个条件必须独立判断。

## 如果面试官追问
问：如果要求返回 nums3 数组本身而不是异或和？
答：那退化成 O(n·m) 输出，长度就是 len(nums1)*len(nums2)，只能老老实实双重循环生成，没有位运算捷径。
