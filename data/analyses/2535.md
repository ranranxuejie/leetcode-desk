## 一句话思路
一次遍历同时累加 `nums` 的元素和与逐位拆出的数字和，最后取两者之差的绝对值。

## 怎么做
1. 初始化 `total = 0`、`digit_total = 0`。
2. 遍历 `nums`，每个 `x` 先 `total += x`。
3. 用 `while x:` 循环，`digit_total += x % 10`，再 `x //= 10`，直到 `x` 为 0。
4. 返回 `abs(total - digit_total)`。

拿示例 1 的 `nums = [1,15,6,3]` 走一遍：处理 `15` 时，`total` 从 1 变成 16，内层循环先取 `15 % 10 = 5` 加到 `digit_total`，`x` 变 `1`，再取 `1`，`x` 变 `0` 退出；四个数走完 `total = 25`、`digit_total = 16`，返回 `abs(25 - 16) = 9`。

```python
total = digit_total = 0
for x in nums:
    total += x
    while x:
        digit_total += x % 10
        x //= 10
return abs(total - digit_total)
```

注意内层 `while` 直接改的是循环变量 `x`，它只是 `nums` 里元素的副本，不会污染原数组，所以外层 `total += x` 必须写在内层循环之前——顺序反了 `total` 加的就是被拆成 0 的 `x`。

## 复杂度
时间：O(n·log M)，n 是 `nums` 长度，log M 来自每个数最多 4 位（`nums[i] ≤ 2000`）。
空间：O(1)，只开了 `total`、`digit_total` 两个累加器。

## 易错点
- 把 `total += x` 写在内层 `while` 之后 → `x` 已被拆到 0，`total` 恒为 0，示例 1 会输出 16 而不是 9 → 先累加原值再拆位。
- 内层写成 `x /= 10` → Python 得到浮点数，`x % 10` 变成小数、循环条件永远为真 → 必须用 `x //= 10` 做整除。

## 如果面试官追问
问：如果 `nums[i]` 上限提到 `10**18` 呢？
答：思路不变，只是每个数拆位次数从 4 次涨到约 18 次，时间仍是 O(n·log M)，无需改结构。
