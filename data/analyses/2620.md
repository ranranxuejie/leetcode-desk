## 一句话思路
用闭包保存当前值 `cur`，每次调用先返回再自增，状态在函数对象里跨调用存活。

## 怎么做
1. 把入参 `n` 赋给局部变量 `cur`，它就是唯一的状态。
2. 定义内层函数 `counter`，函数体先 `return cur`，再 `cur += 1`。
3. 顺序不能反：先返回旧值，后自增，才符合「返回前一个值」。
4. 外层返回 `counter` 本身（不加括号），由调用方按 `calls` 次数逐个调用。

以 `n = 10` 为例：第一次进入 `counter`，`cur` 仍是 10，返回 10 后 `cur` 变成 11；第二次返回 11、`cur` 变 12；第三次返回 12。三次结果拼成 `[10, 11, 12]`，与示例一致。

```python
def make_counter(n):
    cur = n
    def counter():
        nonlocal cur
        old = cur
        cur += 1
        return old
    return counter

c = make_counter(10)
res = [c() for _ in calls]   # calls 全是 "call"
```

`nonlocal cur` 是关键一行：没有它，`cur += 1` 会在 `counter` 内部新建局部变量，抛 `UnboundLocalError`。

## 复杂度
时间：O(k)，k 为 `calls` 长度，每次调用 O(1)。
空间：O(1) 额外，只存一个整数 `cur`，输出列表 O(k) 不计入。

## 易错点
1. 写成 `cur += 1; return cur` → 对 `n = 10` 首次返回 11，整体输出 `[11, 12, 13]`，全错位。正确做法是先 `return cur` 再自增，或先存 `old = cur` 再自增后返回 `old`。
2. 内层函数漏写 `nonlocal cur` → 首次调用就抛 `UnboundLocalError: cannot access local variable 'cur'`，因为 `cur += 1` 让 Python 把 `cur` 判定为局部名。正确做法是显式声明 `nonlocal cur`，或改用可变容器如 `state = [n]` 规避。

## 如果面试官追问
问：若要求支持 `reset(n)` 重置起点怎么办？
答：把 `cur` 放进 `state = [n]` 列表，`reset` 里写 `state[0] = n`，闭包共享同一列表即可。
