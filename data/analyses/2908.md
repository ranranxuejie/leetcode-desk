## 一句话思路
枚举中间峰 j，用 j 左侧最小值与右侧最小值配对，O(n) 前缀/后缀最值即可。

## 怎么做
1. 预处理 `left_min[i] = min(nums[0..i-1])`，`right_min[i] = min(nums[i+1..n-1])`，边界设为 `2**31 - 1`。
2. 枚举 j 从 1 到 n-2，若 `left_min[j] < nums[j] and right_min[j] < nums[j]` 则候选和为三者相加。
3. 取所有候选的最小值，无候选返回 -1。

以 `nums = [8,6,1,5,3]` 为例：`left_min = [inf,8,6,1,1]`，`right_min = [1,1,3,3,inf]`。j=3 时 `left_min[3]=1 < 5`、`right_min[3]=3 < 5`，候选和 `1+5+3=9`；j=2 时 `right_min[2]=3 > 1` 不成立，故答案为 9。

```python
n = len(nums)
INF = 2**31 - 1
left_min = [INF] * n
right_min = [INF] * n
for i in range(1, n):
    left_min[i] = min(left_min[i-1], nums[i-1])
for i in range(n-2, -1, -1):
    right_min[i] = min(right_min[i+1], nums[i+1])
ans = INF
for j in range(1, n-1):
    if left_min[j] < nums[j] and right_min[j] < nums[j]:
        ans = min(ans, left_min[j] + nums[j] + right_min[j])
return -1 if ans == INF else ans
```

## 复杂度
时间 O(n)：三次线性扫描，n 为数组长度。
空间 O(n)：额外开了 `left_min`、`right_min` 两个长度 n 的数组。

## 易错点
- `nums = [6,5,4,3,4,5]` → 若只比较 `nums[j-1]` 和 `nums[j+1]` 会误判 j=4（4 的邻居是 3 和 5，右邻不小于它），但真正需要的是右侧全局最小值 5 也不小于 4，正确做法是用 `right_min` 而非相邻元素。
- `nums = [1,2,3]` → 若把 `left_min[0]` 初始化为 `nums[0]` 而非 `INF`，j=1 时会把自身当左侧最小值导致 `left_min[1]=1 < 2` 成立但语义错位；正确做法是边界填 `INF`，保证 j 处只取严格左侧元素。

## 如果面试官追问
若要求输出三元组下标而非和？答：在更新 `ans` 时同步记录 `(i, j, k)`，`i` 取 `left_min` 对应下标、`k` 取 `right_min` 对应下标即可。
