## 一句话思路
先 DP 标记每个下标能否拆到结尾，再从 0 回溯只走可行位置，避免在死路上枚举。

## 怎么做
1. 把 `wordDict` 转成 `set`，并记下最大词长 `max_len`，用于剪枝。
2. 从右往左算 `ok[i]`：`s[i:j]` 在词典里且 `ok[j]` 为真，则 `ok[i]=True`，`ok[n]=True`。
3. 从 0 开始 DFS，枚举 `j` 到 `min(n, i+max_len)`，只对 `s[i:j] in words and ok[j]` 的分支递归。
4. 到 `i == n` 时把当前路径 `" ".join(path)` 收进答案。

以 `s = "catsanddog"` 为例，`ok` 在 0、3、4、7、10 为真；从 0 出发，`s[0:3]="cat"` 且 `ok[3]` 真，`s[0:4]="cats"` 且 `ok[4]` 真，两条分支分别产出 `cat sand dog` 和 `cats and dog`。

```python
words = set(wordDict)
n, max_len = len(s), max(map(len, wordDict))
ok = [False] * (n + 1)
ok[n] = True
for i in range(n - 1, -1, -1):
    for j in range(i + 1, min(n, i + max_len) + 1):
        if s[i:j] in words and ok[j]:
            ok[i] = True
            break

res = []
def dfs(i, path):
    if i == n:
        res.append(" ".join(path))
        return
    for j in range(i + 1, min(n, i + max_len) + 1):
        if s[i:j] in words and ok[j]:
            path.append(s[i:j])
            dfs(j, path)
            path.pop()
dfs(0, [])
```

## 复杂度
时间：DP 是 O(n·max_len)，回溯输出量级为方案数×句长，最坏 O(n·2^n)。
空间：`ok` 为 O(n)，递归栈 O(n)，答案本身占 O(方案数×n)。

## 易错点
- `s = "catsandog"` 时若跳过 `ok` 直接回溯，会枚举 `cat`、`cats` 等大量前缀后才在末尾失败；正确做法是先用 `ok[0]` 判断，为假直接返回 `[]`。
- 枚举 `j` 时若写成 `range(i+1, n+1)` 而不截到 `i+max_len`，`s[i:j]` 会切出长度超过 10 的子串，虽然哈希查不到但白白多做切片；正确做法是上界取 `min(n, i+max_len)`。

## 如果面试官追问
问：`s` 长度放大到 100 怎么办？答：方案数本身可能指数爆炸，只能改成返回方案数（DP 计数）或加长度上限提前截断。
