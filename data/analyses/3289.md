## 一句话思路
用哈希表统计每个数字出现次数，返回计数为 2 的那两个数，因为题目保证恰好两个数各多出现一次。

## 怎么做
1. 建一个字典 `cnt`，遍历 `nums` 累加每个值的出现次数。
2. 遍历 `cnt`，把 `v == 2` 的键收集到结果列表。
3. 返回该列表（长度必为 2，顺序任意）。

以示例 2 `nums = [0,3,2,1,3,2]` 为例，统计完 `cnt = {0:1, 3:2, 2:2, 1:1}`，筛出 `v == 2` 的键得到 `[3, 2]`，与期望 `[2,3]` 等价。

```python
cnt = {}
for x in nums:
    cnt[x] = cnt.get(x, 0) + 1
res = []
for v, c in cnt.items():
    if c == 2:
        res.append(v)
return res
```

也可以一步到位：用 `collections.Counter(nums)` 后取 `[v for v, c in Counter(nums).items() if c == 2]`，逻辑相同，少写三行。

## 复杂度
时间：O(n)，n 为 `nums` 长度，一次遍历计数加一次遍历字典。
空间：O(n)，`cnt` 最多存 n 个不同键（本题 n ≤ 100，实际很小）。

## 易错点
- 把判断写成 `c > 1` 而非 `c == 2`：本题保证恰好重复两次，两者等价；但若误写成 `c >= 1` 会把只出现一次的数也收进来，示例 1 会返回 `[0,1]` 之外的错误结果。正确做法是严格判 `c == 2`。
- 直接对 `nums` 排序后找相邻相等元素：示例 2 排序得 `[0,1,2,2,3,3]`，能找出 `2,3`，但会引入 O(n log n)；且若用 `set` 去重再比较长度差，容易漏掉「两个重复值」的配对关系。正确做法是用计数字典，O(n) 一次搞定。

## 如果面试官追问
若 n 放大到 10^7 且内存受限，怎么办？
答：用原地标记法，把 `nums[nums[i] % n] += n`，最后值 ≥ 2n 的下标即为重复数，空间 O(1)。
