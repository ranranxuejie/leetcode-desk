## 一句话思路
用二分查找比较 `arr[mid]` 与 `arr[mid+1]`：上升则峰在右侧，下降则峰在 `mid` 或左侧。

## 怎么做
1. 令 `lo = 0`、`hi = len(arr) - 1`，在 `[lo, hi]` 上二分。
2. 取 `mid = (lo + hi) // 2`，比较 `arr[mid]` 和 `arr[mid + 1]`。
3. 若 `arr[mid] < arr[mid + 1]`，说明还在上坡，峰一定在 `mid` 右边，令 `lo = mid + 1`。
4. 否则在下坡，峰在 `mid` 或左边，令 `hi = mid`；循环到 `lo == hi` 返回 `lo`。

以 `arr = [1,3,5,4,2]` 为例：初始 `lo=0, hi=4`，`mid=2`，`arr[2]=5 > arr[3]=4`，走第 4 步 `hi=2`；下一轮 `lo=0, hi=2`，`mid=1`，`arr[1]=3 < arr[2]=5`，走第 3 步 `lo=2`；此时 `lo == hi == 2`，返回 2，正是峰顶。

```python
lo, hi = 0, len(arr) - 1
while lo < hi:
    mid = (lo + hi) // 2
    if arr[mid] < arr[mid + 1]:
        lo = mid + 1
    else:
        hi = mid
return lo
```

关键在 `hi = mid` 而不是 `hi = mid - 1`：`mid` 本身可能就是峰顶（如上面第二轮 `mid=2` 就是答案），减一会把它排除掉。

## 复杂度
时间 O(log n)：每轮把 `[lo, hi]` 区间折半，n 是 `len(arr)`。
空间 O(1)：只开了 `lo`、`hi`、`mid` 三个整数。

## 易错点
- 输入 `[0,1,0]` → 若写成 `hi = mid - 1`，第一轮 `mid=1` 时 `arr[1]=1 > arr[2]=0` 走 `hi=0`，把峰顶 1 排除，最后返回 0 → 正确写法是 `hi = mid`，保证峰顶留在区间内。
- 输入 `[3,4,5,1]` → 若循环条件写成 `lo <= hi` 且返回 `mid`，`lo=hi=2` 时还会再算一次 `mid=2`，比较 `arr[2]` 与 `arr[3]` 后 `lo=3` 越界 → 正确写法是 `while lo < hi`，收敛到单点后直接返回 `lo`。

## 如果面试官追问
追问：数组有重复元素还能二分吗？答：不能直接套，`arr[mid] == arr[mid+1]` 时无法判断方向，需先线性去重或改用三分/扫描。
