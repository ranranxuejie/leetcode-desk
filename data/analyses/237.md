## 一句话思路
把后继节点的值抄进 `node`，再让 `node.next` 跳过后继，等价于删掉了 `node`。

## 怎么做
1. 取后继 `nxt = node.next`，它一定存在（题面保证 `node` 不是末尾）。
2. 把 `nxt.val` 写进 `node.val`，此时 `node` 位置上显示的就是后继的值。
3. 让 `node.next = nxt.next`，把后继从链上摘掉，节点数减 1。
4. 不碰 `head`，也不需要前驱指针。

以 `head = [4,5,1,9], node = 5` 为例：`nxt` 是值为 `1` 的节点，执行后 `node.val` 从 `5` 变成 `1`，`node.next` 指向值为 `9` 的节点，链表读出来是 `4 -> 1 -> 9`，与期望一致。注意被摘掉的是原来那个 `1` 节点，但值序列上等价。

```python
def deleteNode(self, head, node):
    nxt = node.next
    node.val = nxt.val
    node.next = nxt.next
```

关键点：`node` 这个对象始终没被移除，被移除的是 `nxt`；因为值唯一，抄值不会造成重复值歧义。

## 复杂度
时间：O(1)，只改了 `node.val` 和 `node.next` 两处。
空间：O(1)，没有新建节点，也没有额外容器。

## 易错点
- 输入 `node` 是末尾节点（如 `[4,5]`、`node` 为 `5`）→ 若照抄 `nxt = node.next` 会拿到 `None`，`nxt.val` 直接 `AttributeError` → 本题保证不是末尾，但面试若放开这个约束，必须改走「遍历找前驱」的 O(n) 方案。
- 输入 `[4,5,1,9]`、`node` 为 `5` → 若写成 `node = node.next`，只是把局部变量 `node` 指向了 `1`，调用方持有的那个节点和链表结构都没变，输出仍是 `[4,5,1,9]` → 必须原地改 `node.val` 和 `node.next`，不能重新绑定名字。

## 如果面试官追问
问：如果允许访问 `head`，且 `node` 可能是末尾节点，怎么写？
答：从头遍历到 `node` 的前驱 `prev`，执行 `prev.next = node.next`，末尾节点也能删，代价 O(n)。
