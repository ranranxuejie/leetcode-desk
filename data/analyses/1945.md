## 一句话思路
先把每个字母映射成 1~26 拼成数字串，再对各位数字求和，重复 k 次；k 次后必收敛到一位数。

## 怎么做
1. 遍历 `s`，用 `ord(ch) - ord('a') + 1` 得到字母值，转成字符串拼起来。
2. 对拼好的串做一次数位求和：`sum(int(d) for d in digits)`。
3. 把第 2 步重复 `k` 次，每次把结果转回字符串再求和。

以 `s = "leetcode", k = 2` 为例：映射后 `digits = "12552031545"`，第一次求和得 `33`，第二次 `3 + 3 = 6`，返回 6。

```python
digits = "".join(str(ord(ch) - ord('a') + 1) for ch in s)
total = sum(int(d) for d in digits)
for _ in range(k - 1):
    total = sum(int(d) for d in str(total))
return total
```

注意 `k >= 1`，所以第一次求和一定执行；循环里跑 `k - 1` 次，别写成 `k` 次多算一轮（多算一轮对一位数无害，但逻辑要对齐题面）。

## 复杂度
时间：O(n + k·log n)，n 是 `s` 长度，log n 来自数位和的位数。
空间：O(n)，`digits` 串最多约 2n 个字符。

## 易错点
- `s = "zbax"` 时若把 `z` 映射成 0（用 `ord(ch) - ord('a')`），`digits` 会变成 `"0262124"`，前导 0 虽不影响求和，但 `"a"` 会变成 `"0"` 而非 `"1"`，结果整体偏移；正确是 `+ 1`。
- `k` 较大时若用整数 `int(digits)` 再反复取模，`s` 长 100 时 `digits` 有 200 位，Python 虽不溢出但没必要；正确做法是直接在字符串上 `sum(int(d) ...)`，避免大整数转换。

## 如果面试官追问
问：若 `s` 长度到 10^5、`k` 到 10^9 怎么办？
答：第一次求和后结果 ≤ 9×2×10^5，之后每轮位数骤降，最多两三轮就到一位数，`k` 大时直接截断到收敛即可。
