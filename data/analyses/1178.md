## 一句话思路
把每个 word 压成 26 位掩码，用哈希表计数，再对每个 puzzle 枚举其 6 个非首字母子集查表。

## 怎么做
1. 对 `words` 每个词求去重字母掩码 `mask`，`cnt[mask] += 1`；如 `"aaaa"` → `1`，`"asas"` → `0b10001`。
2. 对每个 puzzle，取首字母位 `first = 1 << (puzzle[0] - 'a')`，其余 6 个字母位组成 `rest`。
3. 枚举 `rest` 的全部 64 个子集 `sub`，累加 `cnt[sub | first]`。
4. 以 `"aboveyz"` 为例：`first = 1<<0`，`rest` 含 b,o,v,e,y,z 六位；子集 `{}` 查 `cnt[1]` 得 1（来自 `"aaaa"`），其余子集查不到，答案 1。

```python
from collections import Counter
cnt = Counter()
for w in words:
    m = 0
    for ch in w:
        m |= 1 << (ord(ch) - 97)
    cnt[m] += 1

ans = []
for p in puzzles:
    first = 1 << (ord(p[0]) - 97)
    rest = 0
    for ch in p[1:]:
        rest |= 1 << (ord(ch) - 97)
    total, sub = 0, rest
    while True:
        total += cnt[sub | first]
        if sub == 0:
            break
        sub = (sub - 1) & rest
    ans.append(total)
```

关键在 `sub = (sub - 1) & rest` 这个子集枚举写法：它保证只遍历 `rest` 的子集，不会漏也不会重。

## 复杂度
时间：O(总词长 + P·2^6)，P 为 puzzle 数，每个 puzzle 固定查 64 次。
空间：O(W) 存掩码计数，W 为不同掩码数，最多 2^26 但实际远小。

## 易错点
- 单词含 puzzle 外字母时，若只判「word 掩码是 puzzle 掩码子集」而漏了首字母条件，`"based"` 对 `"abcdefg"` 会被误算；必须额外要求 `mask & first != 0`，本题用 `sub | first` 天然满足。
- 单词有重复字母时，若按字符逐个匹配而非先去重成掩码，`"aaaa"` 会被重复计数或判错；正确做法是先 `m |= 1 << ...` 去重，再 `cnt[m] += 1`。

## 如果面试官追问
若 puzzle 长度不再是 7 而是最多 20，怎么办？答：2^19 子集枚举会爆，改用按首字母分组 + 对每个 word 反查包含它的 puzzle，或对 puzzle 建 Trie 剪枝。
