## 一句话思路
对长度 L 二分，用滚动哈希统计所有长度 L 子数组的哈希出现次数，存在计数为 1 即合法。

## 怎么做
1. 单调性：若长度 L 有唯一子数组，则 L+1 也必有（把该唯一子数组任意扩一位，得到的串不可能在别处出现，否则它的子串会重复），故可二分答案。
2. 预处理前缀哈希与幂，O(1) 取任意长度子数组哈希。
3. 对给定 L，用字典统计每个哈希出现次数，一旦某哈希计数为 1 立即返回 True。
4. 二分区间 `[1, n]`，找最小可行 L。

以 `nums = [1,1,2,2,1]` 为例，L=1 时哈希计数 `{1:3, 2:2}` 无计数 1，返回 False；L=2 时 `[1,1]`、`[1,2]`、`[2,2]`、`[2,1]` 各计 1，返回 True，故答案 2。

```python
MOD = (1 << 61) - 1
BASE = 131
n = len(nums)
pw = [1] * (n + 1)
pre = [0] * (n + 1)
for i, x in enumerate(nums):
    pw[i + 1] = pw[i] * BASE % MOD
    pre[i + 1] = (pre[i] * BASE + x) % MOD

def ok(L):
    seen = {}
    for i in range(n - L + 1):
        h = (pre[i + L] - pre[i] * pw[L]) % MOD
        seen[h] = seen.get(h, 0) + 1
    return any(c == 1 for c in seen.values())

lo, hi = 1, n
while lo < hi:
    mid = (lo + hi) // 2
    if ok(mid): hi = mid
    else: lo = mid + 1
return lo
```

## 复杂度
时间：二分 log n 轮，每轮 O(n) 扫描，共 O(n log n)。
空间：前缀哈希、幂数组各 O(n)，每轮字典最多 O(n)。

## 易错点
- 输入 `[3,3,3]`：若二分上界写成 `n-1` 或忘记 L=n 合法，会返回错误值；正确做法是 `hi = n`，因为全长子数组必然唯一。
- 输入 `[1,1,2,2,1]` 这类哈希碰撞场景：若用单模数 `10**9+7` 且 BASE 固定，可能把不同子数组误判为相同导致答案偏大；正确做法用双哈希或 `2**61-1` 大模数降低碰撞。

## 如果面试官追问
问：要求输出该唯一子数组本身怎么办？
答：二分确定最小 L 后，再扫一遍记录每个哈希首次出现的下标，取计数为 1 的那个起点，切片返回即可。
