## 一句话思路
把条件改写成 `2*capacity[l] = prefix[r+1] - prefix[l]`，按左端点值分桶存前缀和，右端点扫到时查桶。

## 怎么做
1. 先算前缀和 `pre[i] = capacity[0..i-1]` 之和，`pre[0]=0`。
2. 条件 `capacity[l] = capacity[r] = 中间和` 等价于 `capacity[l] = pre[r] - pre[l+1]`，即 `pre[r] = pre[l+1] + capacity[l]`；注意 `pre[l+1] = pre[l] + capacity[l]`，所以右式就是 `pre[l] + 2*capacity[l]`。
3. 从左往右扫 `r`，把每个可能的左端点 `l` 的键 `pre[l] + 2*capacity[l]` 存进哈希表，值为该键出现的次数；扫到 `r` 时查 `pre[r]` 在表里的次数累加。
4. 长度至少 3 意味着 `r >= l+2`，所以处理 `r` 之前只能把 `l <= r-2` 的左端点入表。

以 `capacity = [9,3,3,3,9]` 为例：`pre = [0,9,12,15,18,27]`。`r=2` 时先入 `l=0`，键 `pre[0]+2*9=18`；查 `pre[2]=12`，无。`r=4` 时入 `l=2`，键 `pre[2]+2*3=18`；查 `pre[4]=18`，命中 2 次（`l=0` 和 `l=2`），答案 2。

```python
pre = [0] * (n + 1)
for i, x in enumerate(capacity):
    pre[i + 1] = pre[i] + x
cnt = {}
ans = 0
for r in range(2, n):
    l = r - 2
    key = pre[l] + 2 * capacity[l]
    cnt[key] = cnt.get(key, 0) + 1
    ans += cnt.get(pre[r], 0)
```

## 复杂度
时间 O(n)：一次前缀和加一次单指针扫描，哈希表均摊 O(1)。
空间 O(n)：`pre` 数组和 `cnt` 哈希表各占 O(n)。

## 易错点
- 入表时机写成「先查后入当前 `l=r`」→ 会把长度 1、2 的子数组算进去，`[9,3,3,3,9]` 会多出 `l=r` 的假命中；正确做法是每轮只入 `l=r-2`，保证 `r-l>=2`。
- 键写成 `pre[l] + capacity[l]`（漏了 `pre[l+1]` 那一步的推导）→ `[9,3,3,3,9]` 里 `l=0` 的键变成 9，`pre[4]=18` 查不到，答案错成 1；正确键是 `pre[l] + 2*capacity[l]`。

## 如果面试官追问
要求输出所有稳定子数组的下标对怎么办？答：哈希表的值从计数改成存左端点列表，命中时逐个配对输出，时间仍是 O(n + 答案数)。
