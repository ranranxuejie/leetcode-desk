## 一句话思路
反转 n 得 r，在 [min, max] 上逐个试除到 √x 判素并累加，n ≤ 1000 时区间上界最多 1000，暴力完全够。

## 怎么做
1. 用取模循环把 n 的数字倒序拼成 r，注意 `r = r * 10 + n % 10` 后要 `n //= 10`。
2. 取 `lo, hi = min(n, r), max(n, r)`，注意此时 n 已被循环改写成 0，必须提前存原值。
3. 对 `x in range(lo, hi + 1)` 判素：`x < 2` 直接跳过，否则试除 `d` 从 2 到 `isqrt(x)`。
4. 判素通过就累加到 `total`，返回 `total`。

以 n = 13 为例：循环第一轮 `r = 3, n = 1`，第二轮 `r = 31, n = 0`，得 r = 31，区间 [13, 31]。判 13 时试除 d = 2、3 都不整除（isqrt(13) = 3），13 计入；判 25 时 d = 5 整除，跳过。最终累加得 132。

```python
from math import isqrt

def rev(x):
    r = 0
    while x:
        r = r * 10 + x % 10
        x //= 10
    return r

def is_prime(x):
    if x < 2:
        return False
    for d in range(2, isqrt(x) + 1):
        if x % d == 0:
            return False
    return True

lo, hi = sorted((n, rev(n)))
total = sum(x for x in range(lo, hi + 1) if is_prime(x))
```

## 复杂度
时间：O((hi − lo + 1) · √hi)，区间长度最多约 1000，每个数试除到 √1000 ≈ 31。
空间：O(1)，只用了 r、lo、hi、total 几个整数。

## 易错点
- n = 10 → 反转得 1，区间是 [1, 10] 而不是 [10, 1]；若直接 `range(n, r + 1)` 会得到空区间、返回 0，正确做法是先 `min/max` 或 `sorted` 再取范围。
- n = 8 → 区间 [8, 8]，8 不是质数应返回 0；若判素漏掉 `x < 2` 的守卫，遇到 n = 2 反转仍是 2 时没问题，但 n = 1 时区间 [1, 1]，1 会被误判成质数累加 1，正确做法是显式 `if x < 2: return False`。

## 如果面试官追问
若 n 放大到 10^9，区间长度仍是 O(log n) 位数的反转差，但单个数判素变贵，答：改用 Miller-Rabin 或先筛出 √hi 内的小素数再试除。
