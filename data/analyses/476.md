## 一句话思路
用「掩码全 1」与 `num` 异或：掩码位数与 `num` 的有效二进制位数相同，异或即逐位取反。

## 怎么做
1. 先求掩码 `mask`：从 1 开始不断 `mask = (mask << 1) | 1`，直到 `mask >= num`。
2. 此时 `mask` 是形如 `111...1` 的全 1 数，位数正好等于 `num` 的最高位位置。
3. 返回 `mask ^ num`，异或把 `num` 的每一位翻转，且不会引入前导零位。

以 `num = 5`（二进制 `101`）为例：循环中 `mask` 依次为 1、3、7，`3 < 5` 继续，`7 >= 5` 停。此时 `mask = 7`（`111`），`7 ^ 5 = 2`（`010`），正是答案。关键中间值是 `mask = 7`——它比 `num` 多一位就错，少一位也错，必须恰好覆盖 `101` 的三位。

```python
mask = 1
while mask < num:
    mask = (mask << 1) | 1
return mask ^ num
```

等价写法是先求位数再减一：`mask = (1 << num.bit_length()) - 1`，`num = 5` 时 `bit_length()` 为 3，`(1 << 3) - 1 = 7`，结果一致。面试里写 `bit_length` 版本更短，写循环版本更能体现「掩码怎么长出来」。

## 复杂度
时间：O(log num)，循环次数等于 `num` 的二进制位数。
空间：O(1)，只开了 `mask` 一个整数。

## 易错点
- 用 `~num` 直接取反 → `num = 5` 会得到 `-6`，因为 Python 的 `~` 对无限位补码取反，高位全是 1 → 正确做法是先造出与有效位等长的 `mask` 再异或。
- 掩码多造一位 → `num = 5` 若把 `mask` 做成 `15`（`1111`），`15 ^ 5 = 10`（`1010`），多出一个前导 1 → 循环条件必须是 `mask < num` 而非 `mask <= num`，停下时 `mask` 的位数才与 `num` 相同。

## 如果面试官追问
问：`num` 换成 64 位大整数还成立吗？
答：成立，`bit_length()` 和移位都不依赖位宽，只是循环次数变成 O(64)。
