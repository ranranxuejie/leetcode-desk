## 一句话思路
用双端队列 `deque` 存结果，维护 `rev` 标志表示当前是否处于反转态，遇到 `'i'` 翻转标志，其余字符按标志决定塞队头还是队尾。

## 怎么做
1. 初始化 `dq = deque()`、`rev = False`。
2. 遍历 `s` 中每个字符 `c`：若 `c == 'i'`，执行 `rev = not rev` 并跳过。
3. 否则按 `rev` 决定插入端：`rev` 为 `False` 时 `dq.append(c)`，为 `True` 时 `dq.appendleft(c)`。
4. 结束后若 `rev` 为 `True`，把 `dq` 反转再拼成字符串返回。

拿 `s = "string"` 走一遍关键点：处理到 `'i'`（下标 3）时 `rev` 从 `False` 变 `True`，此时 `dq` 是 `deque(['s','t','r'])`；接着 `'n'` 走 `appendleft`，`dq` 变成 `deque(['n','s','t','r'])`；`'g'` 再 `appendleft` 得 `deque(['g','n','s','t','r'])`；最后 `rev` 为 `True`，反转得 `"rtsng"`。

```python
from collections import deque

dq, rev = deque(), False
for c in s:
    if c == 'i':
        rev = not rev
    elif rev:
        dq.appendleft(c)
    else:
        dq.append(c)
if rev:
    dq.reverse()
return ''.join(dq)
```

核心是「不真的反转字符串」：反转态下新字符落在逻辑末尾，而逻辑末尾在物理上就是队头，所以 `appendleft` 等价于「反转后再追加」。连续两个 `'i'` 时 `rev` 翻两次回到 `False`，正好对应示例 2 里 `"poiinter"` 的 `"op"` 又变回 `"po"`。

## 复杂度
时间 O(n)：遍历 `s` 一次，每个字符 O(1) 入队，最后 `join` 再扫一遍。
空间 O(n)：`deque` 存了除 `'i'` 外的全部字符，即 n 减去 `'i'` 的个数。

## 易错点
- 输入 `s = "ii"` 这类连续 `'i'`（虽然题面保证 `s[0] != 'i'`，但中间可连出）→ 若把 `'i'` 也当普通字符插入再反转，会多出字符 → 正确做法是 `'i'` 只翻转 `rev`、绝不入队。
- 输入 `s = "string"` 结尾 `rev` 为 `True` → 若忘了最后 `dq.reverse()`，会输出 `"gnstr"` 而不是 `"rtsng"` → 正确做法是收尾时按 `rev` 决定是否反转整个 `deque`。

## 如果面试官追问
问：若 `'i'` 改成「反转并删除最后一个字符」怎么改？
答：`rev` 为 `False` 时 `pop()`，为 `True` 时 `popleft()`，其余逻辑不变。
