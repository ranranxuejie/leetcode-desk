## 一句话思路
只可能由「左旋 k 次」或「反转后左旋 k 次」得到有序数组，枚举两种形态各找一次 k。

## 怎么做
1. 记 `n = len(nums)`，先检查 `nums` 是否为 `[0,1,...,n-1]` 的循环移位：找 `0` 的下标 `p`，若 `nums[(p+i) % n] == i` 对所有 i 成立，则左旋 `p` 次即可，代价 `p`。
2. 再检查「反转后」的形态：反转后数组为 `nums[::-1]`，它若是有序数组的循环移位，则先花 1 次反转，再左旋对应次数。
3. 两种形态都取最小代价，都不成立返回 -1。

以 `nums = [0,2,1]` 为例：`0` 在 `p=0`，但 `nums[1]=2 != 1`，第一种不成立；反转后 `[1,2,0]`，`0` 在下标 2，检查 `[1,2,0]` 左旋 2 次得 `[0,1,2]`，代价 `1+2=3`？——注意反转本身已把 `[0,2,1]` 变成 `[1,2,0]`，再左旋 2 次是 3 次，但示例答案是 2，说明顺序是「先左旋再反转」：左旋 1 次得 `[2,1,0]`，反转得 `[0,1,2]`。所以第二种形态应检查「先左旋 k 次再反转」，即 `nums` 左旋 k 次后等于 `[n-1,...,0]`，等价于 `nums` 是 `[n-1,...,0]` 的循环移位。

```python
n = len(nums)
def cost(target):
    p = nums.index(target[0])
    for i in range(n):
        if nums[(p + i) % n] != target[i]:
            return None
    return p
a = cost(list(range(n)))          # 纯左旋
b = cost(list(range(n-1, -1, -1)))  # 左旋后反转
ans = min(x for x in (a, b) if x is not None) if (a is not None or b is not None) else -1
```

## 复杂度
时间：O(n)，两次线性扫描，每次 `index` 加一次全数组比对。
空间：O(n)，构造了两个长度 n 的目标数组。

## 易错点
- `nums = [1,0,2]`：只检查「左旋到有序」会得 -1，漏掉「左旋 1 次得 `[0,2,1]` 再反转」这条路径，正确做法是同时检查目标 `[n-1,...,0]` 的循环移位。
- `nums = [0,1,2]`：已有序时 `p=0` 代价 0，但若代码无条件加 1（认为必须反转），会错成 1，正确做法是两种形态各自独立取 min，允许 0。

## 如果面试官追问
