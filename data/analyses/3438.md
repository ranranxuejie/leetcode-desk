## 一句话思路
先统计每个数字出现次数，再从左到右扫相邻对，用计数表 O(1) 判定合法性。

## 怎么做
1. 用长度 10 的数组 `cnt` 统计 `s` 中每个数字出现次数，`cnt[int(c)] += 1`。
2. 从左到右枚举 `i` 从 0 到 `len(s)-2`，取 `a, b = s[i], s[i+1]`。
3. 判定条件：`a != b` 且 `cnt[int(a)] == int(a)` 且 `cnt[int(b)] == int(b)`。
4. 第一个满足的返回 `s[i:i+2]`，扫完没有就返回 `""`。

以 `s = "2523533"` 为例，统计后 `cnt[2]=2, cnt[3]=3, cnt[5]=1`。扫到 `i=3` 时 `a='3', b='5'`，`cnt[3]==3` 成立但 `cnt[5]==1 != 5`，跳过；扫到 `i=4` 时 `a='5', b='3'`，`cnt[5]=1 != 5` 不成立。真正命中的是 `i=1` 的 `"52"`？不——`cnt[5]=1 != 5`，也不成立。实际输出 `"23"` 来自 `i=2`：`a='2', b='3'`，`cnt[2]==2` 且 `cnt[3]==3`，两个都成立，返回 `"23"`。

```python
cnt = [0] * 10
for c in s:
    cnt[int(c)] += 1
for i in range(len(s) - 1):
    a, b = int(s[i]), int(s[i + 1])
    if a != b and cnt[a] == a and cnt[b] == b:
        return s[i:i + 2]
return ""
```

关键点：`cnt` 的下标是数字本身，所以判定就是 `cnt[a] == a`，不需要额外映射；`a != b` 必须显式判断，因为 `"22"` 里 `cnt[2]==2` 成立但两数字相同不合法。

## 复杂度
时间：O(n)，统计一遍加扫描一遍，n 为 `len(s)`。
空间：O(1)，`cnt` 固定长度 10，与 n 无关。

## 易错点
- 输入 `"22"` → 若漏判 `a != b`，会因 `cnt[2]==2` 误返回 `"22"` → 必须先判两数字不同再判计数。
- 输入 `"221"` → 若从右往左扫或先判 `cnt` 再判相邻，可能返回 `"22"` 或漏掉 `"21"` → 必须严格从左到右、先判 `a != b`，`i=1` 时 `a='2', b='1'`，`cnt[2]==2`、`cnt[1]==1` 同时成立才返回 `"21"`。

## 如果面试官追问
若 s 长度扩到 10^6 且要求返回所有合法相邻对？答：仍 O(n) 扫一遍，把命中的 `s[i:i+2]` 收集进列表，计数表大小不变。
