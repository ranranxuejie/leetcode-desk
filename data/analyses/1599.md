## 一句话思路
按轮次模拟，每轮先收人再上 4 人，累计利润刷新最大值，超过 `len(customers)` 后继续空转直到等待队列清空。

## 怎么做
1. 用 `waiting` 记等待人数，`profit` 记累计利润，`best` 记最大利润，`ans` 记对应轮次，初始 `best = 0`、`ans = -1`。
2. 轮次 `i` 从 0 开始，只要 `i < len(customers)` 或 `waiting > 0` 就继续：若 `i < n` 则 `waiting += customers[i]`。
3. 每轮登舱 `board = min(4, waiting)`，`waiting -= board`，`profit += board * boardingCost - runningCost`。
4. 若 `profit > best`，更新 `best = profit`、`ans = i + 1`。

以示例 2 为例，`customers = [10,9,6]`，`boardingCost = 6`，`runningCost = 4`。第 1 轮 `waiting = 10`，`board = 4`，`profit = 4*6 - 4 = 20`，`best` 更新为 20、`ans = 1`。第 2 轮 `waiting = 6 + 9 = 15`，`board = 4`，`profit = 20 + 24 - 4 = 40`。继续到第 7 轮 `waiting = 1`，`board = 1`，`profit = 122`，`ans = 7`。

```python
waiting = profit = 0
best, ans = 0, -1
i = 0
while i < len(customers) or waiting > 0:
    if i < len(customers):
        waiting += customers[i]
    board = min(4, waiting)
    waiting -= board
    profit += board * boardingCost - runningCost
    if profit > best:
        best, ans = profit, i + 1
    i += 1
return ans
```

关键点：循环条件必须包含 `waiting > 0`，否则示例 2 第 4~7 轮（`customers` 已耗尽但还有 13 人等待）会被漏掉，答案错成 3。

## 复杂度
时间 O(n + W/4)，W 为总人数，最多约 5×10^6 轮，实际受 `customers[i] ≤ 50` 约束。
空间 O(1)，只用了 `waiting`、`profit`、`best`、`ans` 几个标量。

## 易错点
- 输入 `customers = [10,9,6]`：若循环只写 `i < len(customers)`，第 4 轮起 `waiting` 还有 13 人却不模拟，返回 3 而非 7。正确做法是条件写成 `i < len(customers) or waiting > 0`，让空转轮次也计入 `profit` 和 `ans`。
- 输入 `customers = [3,4,0,5,1]`、`boardingCost = 1`、`runningCost = 92`：若把 `best` 初始化为 `-inf` 或第一轮利润，会在全负时返回某个轮次而非 -1。正确做法是 `best = 0`、`ans = -1`，只有 `profit > best` 才更新，保证利润非正时 `ans` 保持 -1。

## 如果面试官追问
问：若 `customers[i]` 上限从 50 提到 10^9，还能逐轮模拟吗？
答：不能，等待队列会空转上亿轮；应把连续满员 4 人的轮次用 `waiting // 4` 批量结算，再单独处理余数。
