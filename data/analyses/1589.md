## 一句话思路
用差分数组统计每个下标被多少个 request 覆盖，覆盖次数与 nums 都排序后同序相乘求和，由重排不等式保证最大。

## 怎么做
1. 建长度 n+1 的差分数组 `diff`，对每个 `[s, e]` 做 `diff[s] += 1`、`diff[e+1] -= 1`。
2. 前缀和还原出 `cover[i]`，即下标 i 被几个查询覆盖。
3. `cover` 与 `nums` 各自升序排序，逐位相乘累加，最后对 `10**9 + 7` 取余。

以示例 1 为例：`nums = [1,2,3,4,5]`，`requests = [[1,3],[0,1]]`。差分后 `diff = [1,1,-1,-1,0,-1]`，前缀和得 `cover = [1,2,1,1,0]`。排序后 `cover = [0,1,1,1,2]`，`nums = [1,2,3,4,5]`，乘积和 `0*1 + 1*2 + 1*3 + 1*4 + 2*5 = 19`，与官方答案一致。

```python
n = len(nums)
diff = [0] * (n + 1)
for s, e in requests:
    diff[s] += 1
    diff[e + 1] -= 1

cover = [0] * n
cur = 0
for i in range(n):
    cur += diff[i]
    cover[i] = cur

cover.sort()
nums.sort()
ans = sum(c * v for c, v in zip(cover, nums)) % (10**9 + 7)
```

关键点：`diff` 长度必须是 `n+1`，因为 `e+1` 可能等于 n；`cover` 只取前 n 项，`diff[n]` 不参与。

## 复杂度
时间 O(n log n + m)，n 是 nums 长度，m 是 requests 长度，排序贡献 log n。
空间 O(n)，额外开了 diff 和 cover 两个长度 n 量级的数组。

## 易错点
- `requests` 含 `[n-1, n-1]` 时，若 `diff` 只开长度 n，`diff[e+1]` 越界 → 正确做法是开 `n+1`，且前缀和循环只跑 `range(n)`，别把 `diff[n]` 算进 cover。
- 先乘后取余 vs 边加边取余：`nums[i]` 最大 1e5、覆盖次数最大 1e5、n 最大 1e5，总和可达 1e15 量级，Python 不会溢出但结果必须 `% (10**9+7)`；漏取余会返回未截断的大数 → 在 `sum(...)` 外层统一取余即可。

## 如果面试官追问
问：如果要求返回具体的 nums 排列而不只是和？答：排序后把 nums 按 cover 的升序位置回填，即 `perm[cover 排序前的下标] = nums 对应值`，需要额外记录 cover 的原始索引。
