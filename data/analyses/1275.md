## 一句话思路
按 moves 顺序落子，每步只检查该子所在的行、列、两条对角线是否被同一玩家占满，先满者胜。

## 怎么做
1. 建 3×3 的 `board`，初始全为 `' '`，遍历 `enumerate(moves)`，用 `i % 2 == 0` 判定当前是 A（`'X'`）还是 B（`'O'`）。
2. 落子后立刻检查 `board[r]` 整行、第 `c` 列、以及 `r == c` / `r + c == 2` 两条对角线。
3. 任一方向三格都等于当前棋子，直接返回 `"A"` 或 `"B"`，不必继续。
4. 循环走完没赢家：`len(moves) == 9` 返回 `"Draw"`，否则 `"Pending"`。

以示例 1 为例，第 5 步 `moves[4] = [2,2]` 由 A 落子，此时 `board[2] = ['X','O','X']` 不是整行，但主对角线 `board[0][0]`、`board[1][1]`、`board[2][2]` 全是 `'X'`，返回 `"A"`。

```python
board = [[' '] * 3 for _ in range(3)]
for i, (r, c) in enumerate(moves):
    ch = 'X' if i % 2 == 0 else 'O'
    board[r][c] = ch
    if (all(board[r][j] == ch for j in range(3)) or
        all(board[j][c] == ch for j in range(3)) or
        (r == c and all(board[k][k] == ch for k in range(3))) or
        (r + c == 2 and all(board[k][2 - k] == ch for k in range(3)))):
        return "A" if ch == 'X' else "B"
return "Draw" if len(moves) == 9 else "Pending"
```

关键点：只检查刚落的那一格所在的方向，因为之前所有方向都已检查过且未成线，新成线必然经过新落子。

## 复杂度
时间：O(n)，n = len(moves) ≤ 9，每步固定检查 4 个方向共 12 格。
空间：O(1)，额外只开 3×3 的 `board`，与 n 无关。

## 易错点
- 输入 `moves = [[0,0],[0,1],[1,1],[0,2],[2,2]]`（A 在第 5 步用 `[2,2]` 凑成副对角线）→ 若只检查行和列会漏判，错返回 `"Pending"`；必须同时判 `r + c == 2` 这条副对角线。
- 输入 `moves` 长度恰为 9 且最后一步才成线（如示例 3 变体）→ 若先判 `len(moves) == 9` 再判胜负会错返回 `"Draw"`；正确做法是每步落子后先判胜，循环结束才判满盘。

## 如果面试官追问
问：若棋盘扩成 N×N，怎么改？
答：仍只查新落子的行、列、两对角线，用计数器数组按玩家累加，O(1) 判定，总时间 O(n)。
