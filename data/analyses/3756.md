## 一句话思路
用前缀和分别记录「非零数字拼成的数」和「数字和」，每个查询 O(1) 拼出 x 与 sum 再相乘。

## 怎么做
1. 预处理 `pref[i]` 表示 s[0..i-1] 中非零数字拼成的数对 MOD 取模，`cnt[i]` 表示其中非零数字个数，`ssum[i]` 表示数字和。
2. 对查询 `[l, r]`，取 `x = (pref[r+1] - pref[l] * pow10[cnt[r+1]-cnt[l]]) % MOD`，`sum = ssum[r+1] - ssum[l]`。
3. 答案 `x * sum % MOD`，注意 x 为负时先加 MOD。

以 `s = "10203004"`、查询 `[0,7]` 为例：`cnt[8]=4`，`pow10[4]=10000`，`pref[8]=1234`，`pref[0]=0`，得 `x=1234`；`ssum[8]=10`，`sum=10`，答案 `12340`。

```python
MOD = 10**9 + 7
n = len(s)
pref = [0] * (n + 1)
cnt = [0] * (n + 1)
ssum = [0] * (n + 1)
pow10 = [1] * (n + 1)
for i in range(n):
    pow10[i + 1] = pow10[i] * 10 % MOD
    d = int(s[i])
    if d:
        pref[i + 1] = (pref[i] * 10 + d) % MOD
        cnt[i + 1] = cnt[i] + 1
    else:
        pref[i + 1] = pref[i]
        cnt[i + 1] = cnt[i]
    ssum[i + 1] = ssum[i] + d
```

## 复杂度
时间：预处理 O(m)，每个查询 O(1)，共 O(m + q)。
空间：pref/cnt/ssum/pow10 各 O(m)，额外开 4 个长度 m+1 的数组。

## 易错点
- 查询区间全是 0（如 `s="1000"`、`[1,1]`）→ 若直接用 `pref[r+1]-pref[l]*pow10[0]` 得 0 没问题，但若漏了 `cnt` 差为 0 时仍乘 `pow10[1]` 会错成 0 以外的值 → 必须用 `cnt` 差作指数，差为 0 时 `pow10[0]=1`。
- 减法取模后为负（如 `pref[r+1] < pref[l]*pow10[k] % MOD`）→ 直接返回负数 → 先 `(x % MOD + MOD) % MOD` 再乘 sum。

## 如果面试官追问
若 s 长度到 10^6 且查询在线？答：预处理不变，仍 O(1) 每查询，只是 pow10 需按需扩展或预计算到 m。
