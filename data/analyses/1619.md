## 一句话思路
排序后掐掉首尾各 `n//20` 个元素再求均值，因为「最小/最大 5%」在有序数组里就是头尾两段。

## 怎么做
1. 先算 `k = len(arr) // 20`，题目保证 `len(arr)` 是 20 的倍数，所以 `k` 是整数，不用考虑取整误差。
2. 对 `arr` 原地 `sort()`，让最小的 `k` 个落在 `arr[0:k]`、最大的 `k` 个落在 `arr[n-k:n]`。
3. 取中间段 `arr[k:n-k]` 求和除以 `n - 2*k`，返回浮点结果。

拿示例 2 走一遍：`arr` 长度 20，`k = 1`。排序后是
`[0,0,0,0,1,2,2,2,2,3,5,5,5,5,6,6,7,7,8,8,10]`（注意原数组里 10 只有一个，排序后它落在最后）。
掐掉首元素 `0` 和尾元素 `10`，中间 18 个数求和为 72，`72 / 18 = 4.0`，与输出一致。

```python
def trimMean(self, arr):
    arr.sort()
    n = len(arr)
    k = n // 20
    mid = arr[k:n - k]
    return sum(mid) / len(mid)
```

关键点：`k` 用整除而不是 `0.05 * n` 再取整，浮点乘法在 `n` 较大时可能得到 `k-1e-13` 这类值，`int()` 截断会少删一个。示例 3 的 `n = 40`，`k = 2`，中间 36 个数求和 172，`172 / 36 ≈ 4.77778`，正好对上。

## 复杂度
时间：排序 `O(n log n)`，`n` 是 `arr` 长度，求和是 `O(n)` 被排序盖过。
空间：`O(1)` 额外（Python 的 `sort` 是 Timsort，最坏 `O(n)` 辅助栈，`mid` 切片另开 `O(n)`）。

## 易错点
- 输入 `arr = [1,2,2,...,2,3]`（示例 1，`n=20`，`k=1`）→ 若把「5%」理解成「删 5% 种不同的值」或按值域删，会删错个数；正确做法是按**元素个数**删，`k = n // 20 = 1`，只掐首尾各一个。
- 输入 `n = 20` 且首尾恰好相等（如全 2 的数组）→ 若用 `arr.remove(min)` 逐个删，会删掉中间某个 2 而不是边界元素，结果碰巧对但逻辑错；正确做法是排序后按**下标**切 `arr[k:n-k]`，不依赖值。

## 如果面试官追问
问：如果 `arr` 长度不是 20 的倍数怎么办？
答：`k = int(n * 0.05)` 向下取整，删 `k` 个，分母用 `n - 2*k`，题意通常按此约定。
