## 一句话思路
按左端点扫描 nums，用最小堆维护覆盖当前位的 query 右端点，不够减时贪心取右端点最远的补，最后看能否全部清零。

## 怎么做
1. 把 queries 按 `l` 升序排序，指针 `qi` 指向下一个待加入的 query。
2. 从左到右遍历 `i`，先把所有 `l == i` 的 query 的 `r` 压入最小堆。
3. 维护 `cover` 表示当前位已被多少条 query 覆盖（用差分数组 `diff` 实现），若 `cover < nums[i]`，就反复弹出堆顶 `r`（最小的右端点），`cover += 1`、`diff[r+1] -= 1`、`used += 1`，直到够或堆空。
4. 若堆空仍不够，返回 -1；否则答案 `len(queries) - used`。

以示例 2 `nums=[1,1,1,1], queries=[[1,3],[0,2],[1,3],[1,2]]` 为例：排序后 `[[0,2],[1,2],[1,3],[1,3]]`。`i=0` 压入 `r=2`，`cover=0<1`，弹出 2，`diff[3]-=1`，`used=1`。`i=1` 压入 2、3、3，`cover=1>=1` 跳过。`i=2` 时 `diff[3]` 生效使 `cover` 减 1 变 0，`0<1`，弹出 2，`used=2`。`i=3` 时 `cover` 再减 1 变 0，`0<1`，弹出 3，`used=3`。最终 `4-3=1`？实际示例答案是 2，说明这里 `i=2` 处 `cover` 应为 1（`[0,2]` 仍覆盖），`diff[3]` 在 `i=3` 才生效，故 `i=2` 不需补，`used=2`，答案 `4-2=2`，与官方一致。

```python
queries.sort()
heap, diff = [], [0] * (n + 1)
cover = used = qi = 0
for i in range(n):
    cover += diff[i]
    while qi < len(queries) and queries[qi][0] == i:
        heappush(heap, queries[qi][1]); qi += 1
    while cover < nums[i] and heap:
        r = heappop(heap)
        cover += 1; diff[r + 1] -= 1; used += 1
    if cover < nums[i]:
        return -1
return len(queries) - used
```

## 复杂度
时间 O((n + m) log m)：排序 O(m log m)，每个 query 进出堆各一次。
空间 O(n + m)：`diff` 长 n+1，堆最多存 m 个右端点。

## 易错点
- 输入 `nums=[0,0], queries=[[0,1]]` → 若在 `i=0` 就无条件弹堆，会白用一条 query 使答案偏小 → 必须先判 `cover < nums[i]` 才弹。
- 输入 `nums=[1,2,3,4], queries=[[0,3]]` → 若堆空时直接 `break` 继续下一位，会漏判返回 -1 → 必须在 `cover < nums[i]` 且堆空时立刻 `return -1`。

## 如果面试官追问
问：若要求输出具体保留哪些 query 而非只给个数？
答：堆里存 `(r, 原下标)`，弹出时记录下标，最后用全集减去这些下标即可。
