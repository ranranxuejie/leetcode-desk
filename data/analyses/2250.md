## 一句话思路
按高度分桶 + 对宽度排序做前缀计数：高度只有 1~100，枚举每个点上方所有高度层，用二分数出该层宽度 ≥ x 的矩形数。

## 怎么做
1. 把 rectangles 按 `h` 分到 101 个桶里，每个桶存该高度所有矩形的 `l`，桶内排序。
2. 对每个桶做后缀计数：`cnt[h][i]` 表示高度为 h、宽度 ≥ 桶内第 i 个 l 的矩形个数。
3. 对每个点 `(x, y)`，遍历 `h = y..100`，在每个桶里 `bisect_left` 找第一个 ≥ x 的位置，累加后缀计数。
4. 用示例 1 验证：桶 2 存 `[1]`，桶 3 存 `[2]`，桶 5 存 `[2]`。点 `(2,1)` 在 h=2 桶里 `bisect_left([1],2)=1` 得 0，h=3 桶得 1，h=5 桶得 1，合计 2。

```python
from bisect import bisect_left
buckets = [[] for _ in range(101)]
for l, h in rectangles:
    buckets[h].append(l)
suf = [None] * 101
for h in range(1, 101):
    arr = sorted(buckets[h])
    s = [0] * (len(arr) + 1)
    for i in range(len(arr) - 1, -1, -1):
        s[i] = s[i + 1] + 1
    suf[h] = (arr, s)
res = []
for x, y in points:
    total = 0
    for h in range(y, 101):
        arr, s = suf[h]
        total += s[bisect_left(arr, x)]
    res.append(total)
```

## 复杂度
时间：O((R + P·H)·log R)，R 为矩形数、P 为点数、H=100 为高度上限，log 来自桶内二分。
空间：O(R + 100)，存所有桶的排序数组与后缀计数。

## 易错点
- 点的高度 `y` 可能大于所有矩形高度，如 `points=[[1,100]]` 而矩形最高为 5：若从 `h=1` 开始枚举会多算，必须从 `h=y` 起，因为矩形要满足 `h_i >= y`。
- 宽度相等时点在边上也算包含：`bisect_left` 找的是第一个 `>= x` 的位置，若误用 `bisect_right`，示例 1 中点 `(2,1)` 在桶 3 的 `[2]` 里会得 0 而非 1，答案错成 `[1,1]`。

## 如果面试官追问
若 `h_i` 也到 10^9 怎么办？答：把高度也离散化，按高度降序扫描点、用树状数组维护宽度前缀和，复杂度 O((R+P) log R)。
