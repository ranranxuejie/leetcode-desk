## 一句话思路
对答案 T 二分，判定「前 T 小时内两架无人机各自能送多少」是否够 d，因为可送数随 T 单调不减。

## 怎么做
1. 无人机 i 在 1..T 内可送的小时数 = T 减去其中 r_i 的倍数个数，即 `T - T // r[i]`。
2. 判定条件：`cap(0) >= d[0] and cap(1) >= d[1]` 且 `cap(0) + cap(1) >= d[0] + d[1]`（两机不能同时送，总小时数也要够）。
3. 二分下界 `lo = 0`，上界取 `hi = (d[0] + d[1]) * 2` 足够（最坏每 2 小时送一次）。
4. 以示例 1 `d=[3,1], r=[2,3]` 为例：T=5 时 cap(0)=5-2=3、cap(1)=5-1=4，3>=3 且 4>=1 且 7>=4，成立；T=4 时 cap(0)=4-2=2<3，不成立，故答案 5。

```python
def ok(T):
    c0 = T - T // r[0]
    c1 = T - T // r[1]
    return c0 >= d[0] and c1 >= d[1] and c0 + c1 >= d[0] + d[1]

lo, hi = 0, (d[0] + d[1]) * 2
while lo < hi:
    mid = (lo + hi) // 2
    if ok(mid):
        hi = mid
    else:
        lo = mid + 1
return lo
```

## 复杂度
时间：二分 log(2*(d0+d1)) 次，每次 O(1)，与 r 无关。
空间：只开 lo/hi/mid 等常数个变量，O(1)。

## 易错点
- 只判 `c0>=d[0] and c1>=d[1]` 而漏掉总和条件：如 `d=[1,1], r=[2,2]`，T=1 时 c0=c1=1 看似都够，但两机同一小时不能同时送，实际需 2 小时；必须加 `c0+c1>=d[0]+d[1]`。
- 上界取 `max(d)*2` 或 `d[0]+d[1]`：当 r 很大且两机错峰时可能不够，`d=[1,3], r=[2,2]` 答案 7 已超过 `d[0]+d[1]=4`；用 `(d[0]+d[1])*2` 才安全。

## 如果面试官追问
若改成 n 架无人机？答：判定改为逐机 `cap(i)>=d[i]` 且总和够，二分不变，每次 O(n)。
