## 一句话思路
答案必是某个后缀，用双指针 i、j 比较后缀大小，跳过重复段，O(n) 找到最大后缀起点。

## 怎么做
1. 关键结论：字典序最大的子串一定是某个后缀——若 `s[a:b]` 最大且 `b < n`，则 `s[a:n]` 以它为前缀且更长，必然更大。
2. 于是问题变成找字典序最大的后缀起点，用 i 指向当前候选、j 指向挑战者、k 为已匹配长度。
3. 逐字符比较 `s[i+k]` 与 `s[j+k]`，不等时把落败方整体跳过 k+1 位，相等则 k 加一。
4. 返回 `s[i:]`。

以 `s = "abab"` 为例：i=0, j=1，`s[0]='a' < s[1]='b'`，i 跳到 1；i=1, j=2，`s[1]='b' > s[2]='a'`，j 跳到 3；i=1, j=3，`s[1]='b' = s[3]='b'`，k=1，此时 `j+k=4` 越界，循环结束，返回 `s[1:] = "bab"`。

```python
i, j, k, n = 0, 1, 0, len(s)
while j + k < n:
    if s[i + k] == s[j + k]:
        k += 1
    elif s[i + k] < s[j + k]:
        i = max(i + k + 1, j)
        j = i + 1
        k = 0
    else:
        j = j + k + 1
        k = 0
return s[i:]
```

跳过的依据：若 `s[i+k] < s[j+k]`，则 i 到 i+k 之间任何起点都不可能赢过 j 开头的后缀，直接令 `i = max(i+k+1, j)`；反之 j 到 j+k 全部淘汰。

## 复杂度
时间 O(n)：i、j 单调右移，k 的累加被跳过量抵消，总比较次数线性。
空间 O(1)：只开 i、j、k、n 四个整型变量，返回的切片另算。

## 易错点
- 输入 `s = "aaaa"` → 若相等时只写 `k += 1` 而不检查 `j + k < n`，会越界访问 `s[j+k]`；正确做法是把 `j + k < n` 放进 while 条件，越界即停，返回 `s[0:] = "aaaa"`。
- 输入 `s = "abab"` 这类 i、j 交错的情形 → 若写成 `i = i + k + 1` 而不取 `max(..., j)`，i 可能落到 j 左边甚至等于 j，导致死循环或漏解；正确做法是 `i = max(i + k + 1, j)`，保证 i 始终在 j 左侧。

## 如果面试官追问
问：若要求返回最大子串的起止下标而非字符串本身？答：同一套双指针，循环结束后返回 `(i, n-1)`，切片换成下标即可，复杂度不变。
