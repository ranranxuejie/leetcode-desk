## 一句话思路
按步长 k 切块，每块用 `sum(ord(c)-97)` 求和后 `% 26` 映射回字母，逐块拼接。

## 怎么做
1. 用 `range(0, len(s), k)` 枚举每块起点 `i`，块就是 `s[i:i+k]`。
2. 对块内字符求 `ord(c) - ord('a')` 之和，记作 `total`。
3. 取 `total % 26`，用 `chr(97 + total % 26)` 转回字母，追加到结果列表。
4. 最后 `''.join(...)` 返回。

以示例 1 `s = "abcd", k = 2` 为例：第一块 `s[0:2] = "ab"`，`total = 0 + 1 = 1`，`1 % 26 = 1`，`chr(97+1) = 'b'`；第二块 `s[2:4] = "cd"`，`total = 2 + 3 = 5`，得 `'f'`，结果 `"bf"`。

```python
res = []
for i in range(0, len(s), k):
    total = 0
    for c in s[i:i + k]:
        total += ord(c) - 97
    res.append(chr(97 + total % 26))
return ''.join(res)
```

关键点：`ord(c) - 97` 而不是 `ord(c) - ord('a')` 也行，但别写成 `ord(c)` 直接求和——那样 `"ab"` 会得到 `195`，`195 % 26 = 13`，输出 `'n'`，全错。

## 复杂度
时间 O(n)：每个字符被访问一次，`n = len(s)`。
空间 O(n/k)：结果列表存 `n/k` 个字符，切片 `s[i:i+k]` 额外 O(k)。

## 易错点
- 输入 `s = "mxz", k = 3` → 若忘记 `% 26` 直接 `chr(97 + 60)`，得到 `chr(157)` 这种非小写字母 → 正确做法是先 `60 % 26 = 8` 再 `chr(97+8) = 'i'`。
- 输入 `s = "aaaa", k = 2` → 若把 `ord(c) - 97` 写成 `ord(c) - 96`（'a' 当 1），每块和变 2，输出 `'c'` 而非 `'a'` → 必须用 `'a' → 0` 的映射，`total` 为 0 时结果就是 `'a'`。

## 如果面试官追问
若 k 很大、s 长度到 10^7 怎么优化？答：仍 O(n) 单遍扫描，避免切片拷贝，改用下标 `j` 从 `i` 累加到 `i+k`，空间降到 O(n/k) 只存结果。
