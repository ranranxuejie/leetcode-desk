## 一句话思路
只要数组里存在至少两个偶数，它们的按位或最低位仍是 0，直接返回 `True`。

## 怎么做
1. 遍历 `nums`，统计偶数个数 `cnt`（判据 `x % 2 == 0`）。
2. 若 `cnt >= 2` 返回 `True`，否则返回 `False`。
3. 关键中间值：`nums = [1,2,3,4,5]` 时偶数有 `2`、`4`，`cnt = 2`，`2 | 4 = 6`，二进制 `110` 末尾是 0，成立。

```python
def hasTrailingZeros(nums):
    cnt = 0
    for x in nums:
        if x % 2 == 0:
            cnt += 1
            if cnt >= 2:
                return True
    return False
```

为什么只需看偶数：尾随零等价于结果的第 0 位是 0，即 OR 结果不被 2 整除。OR 的第 0 位等于所有被选元素第 0 位的 OR。只要有一个奇数参与，第 0 位就是 1，结果必为奇数，没有尾随零。所以合法方案里的元素必须全是偶数，而两个偶数 OR 起来第 0 位仍是 0，必然成立。于是问题退化成「偶数是否至少两个」。

注意不能只看「有没有偶数」：`nums = [2,3,5]` 只有一个偶数，选 `2` 和 `3` 得 `2|3 = 3`（`11`），没有尾随零；选三个也是奇数，所以答案是 `False`，而 `cnt = 1 < 2` 正好挡住。

## 复杂度
时间 O(n)：一次遍历 `nums`，每个元素做一次取模。
空间 O(1)：只开了计数器 `cnt`，没有额外数组。

## 易错点
- `nums = [2,3,5]` → 误以为「有偶数就行」返回 `True` → 正确做法是要求偶数个数 `cnt >= 2`，因为任何奇数参与都会把第 0 位置 1。
- `nums = [1,3,5,7,9]` → 误以为「元素多总能凑出尾随零」→ 全奇数时任意子集 OR 都是奇数，必须返回 `False`，靠 `cnt = 0` 挡住。

## 如果面试官追问
问：如果要求返回一组具体的下标方案怎么办？
答：扫一遍记下前两个偶数的下标 `i, j` 返回 `[i, j]`，仍是 O(n) 时间、O(1) 额外空间。
