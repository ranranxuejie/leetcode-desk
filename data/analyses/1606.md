## 一句话思路
用最小堆按结束时间回收空闲服务器，用有序集合维护空闲编号，按 `i % k` 找环上下一个空闲者。

## 怎么做
1. 维护 `busy` 最小堆存 `(结束时间, 服务器号)`，`free` 有序集合存当前空闲编号，`cnt` 数组记各服务器处理数。
2. 每个请求 `i` 到达时，先把 `busy` 中结束时间 `<= arrival[i]` 的全部弹出并加回 `free`。
3. 若 `free` 为空则丢弃该请求；否则在 `free` 中找 `>= i % k` 的最小值，找不到就取 `free` 的最小值（环回）。
4. 选中服务器 `s` 后从 `free` 删除，`cnt[s] += 1`，把 `(arrival[i] + load[i], s)` 压入 `busy`。

以示例 1 的 `i = 3`（`arrival[3] = 4`）为例：此时 `busy` 中服务器 0 的结束时间是 `1 + 5 = 6 > 4`，不弹出；`free = {1, 2}`，`i % k = 0`，`free` 中无 `>= 0` 之外的…实际是找 `>= 0` 的最小值即 1，故请求 3 落到服务器 1，`cnt[1]` 变 2。

```python
from sortedcontainers import SortedList
import heapq

free = SortedList(range(k))
busy, cnt = [], [0] * k
for i, t in enumerate(arrival):
    while busy and busy[0][0] <= t:
        _, s = heapq.heappop(busy)
        free.add(s)
    if not free:
        continue
    j = free.bisect_left(i % k)
    s = free[j] if j < len(free) else free[0]
    free.remove(s)
    cnt[s] += 1
    heapq.heappush(busy, (t + load[i], s))
```

## 复杂度
时间：`O(n log k)`，每个请求最多一次堆弹出/压入与一次有序集合查找，`n = len(arrival)`。
空间：`O(k)`，`busy` 堆、`free` 集合、`cnt` 数组各占 `k` 量级。

## 易错点
- `arrival` 严格递增但 `load` 可能极大（如示例 3 的 `load[0] = 10`），若用「当前时间 + load」判断空闲却忘了 `<=` 而非 `<`，会在结束时刻恰好等于到达时刻时误判为忙，导致示例 2 的 `i = 3` 落到服务器 1 而非 0。
- 环回查找写成 `free[j]` 而不判 `j == len(free)`，当 `i % k` 大于所有空闲编号时（如 `k = 3`、`free = {0, 1}`、`i % k = 2`）会越界；正确做法是 `j < len(free)` 取 `free[j]`，否则取 `free[0]`。

## 如果面试官追问
若 `k` 扩大到 `10^9` 但 `n` 仍 `10^5`，怎么做？答：只对出现过的服务器编号建有序结构，用字典懒初始化，空闲集合规模不超过 `n`。
