## 一句话思路
枚举 26×26 种字符交换，用计数表算出交换后两边去重数是否相等。

## 怎么做
1. 用 `Counter` 统计 `word1`、`word2` 的字符频次，得到 `c1`、`c2`，去重数即 `len(c1)`、`len(c2)`。
2. 枚举 `c1` 中的字符 `a` 和 `c2` 中的字符 `b`，模拟把 `word1` 的一个 `a` 换成 `b`、`word2` 的一个 `b` 换成 `a`。
3. 对每对 `(a, b)` 计算交换后两边的去重数：`word1` 侧若 `c1[a]==1` 则 `a` 消失，若 `b` 不在 `c1` 则 `b` 新增；`word2` 侧对称处理。
4. 任一对满足相等即返回 `True`，全枚举完返回 `False`。

以 `word1="abcc", word2="aab"` 为例：`c1={a:1,b:1,c:2}`，`c2={a:2,b:1}`，初始去重数 3 和 2。枚举到 `a='c', b='a'`：`c1['c']=2` 所以 `c` 不消失，`a` 已在 `c1` 中不新增，`word1` 仍 3；`c2['a']=2` 所以 `a` 不消失，`c` 不在 `c2` 中新增，`word2` 变 3，相等返回 `True`。

```python
from collections import Counter

def isItPossible(word1, word2):
    c1, c2 = Counter(word1), Counter(word2)
    n1, n2 = len(c1), len(c2)
    for a in c1:
        for b in c2:
            d1 = n1 - (c1[a] == 1) + (b not in c1)
            d2 = n2 - (c2[b] == 1) + (a not in c2)
            if d1 == d2:
                return True
    return False
```

注意 `d1` 里 `b not in c1` 判断的是交换前的 `c1`，因为 `a` 换成 `b` 时 `b` 是否已存在只看原表；`a` 消失的条件是 `c1[a]==1`，若 `a==b` 这种自交换也自然成立（`d1==n1`、`d2==n2`）。

## 复杂度
时间：O(|word1| + |word2| + 26×26)，计数扫一遍字符串，枚举常数级。
空间：O(26)，两张哈希表最多存 26 个小写字母。

## 易错点
- 输入 `word1="a", word2="a"`：若只判断 `len(c1)==len(c2)` 就返回 `True`，但交换后仍是 1 和 1 其实也对；真正的坑是 `word1="ab", word2="ab"` 时忘记 `a==b` 自交换不改变去重数，误判为 `False`——正确做法是枚举里允许 `a==b`，此时 `d1==n1`、`d2==n2` 自然相等。
- 输入 `word1="aa", word2="bb"`：若用 `c1[a]-1` 判断 `a` 是否消失，会把 `c1['a']=2` 减成 1 仍存在，但若写成 `c1[a]==0` 就错判 `a` 消失；正确做法是消失条件严格用 `c1[a]==1`，因为只移走一个。

## 如果面试官追问
问：若允许交换 k 次而非恰好一次？答：k≥2 时几乎总能凑平，只需检查初始去重数差是否 ≤2k 且两边字符池够用，退化成贪心判断。
