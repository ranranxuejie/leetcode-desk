## 一句话思路
先统计每行每列的服务器数，再遍历每个 1，看它所在行或列计数是否大于 1。

## 怎么做
1. 用 `row[i]` 和 `col[j]` 分别记录第 i 行、第 j 列的服务器数量，一次遍历 `grid` 填好。
2. 再遍历每个 `grid[i][j] == 1`，若 `row[i] > 1 or col[j] > 1` 则计入答案。
3. 以示例 3 为例：`row = [2,1,1,1]`，`col = [1,0,2,1]`。位置 `(0,0)` 的 `row[0]=2>1` 可通信；`(3,3)` 的 `row[3]=1` 且 `col[3]=1`，不可通信。
4. 返回累计计数即可，无需 DFS/并查集。

```python
m, n = len(grid), len(grid[0])
row = [0] * m
col = [0] * n
for i in range(m):
    for j in range(n):
        if grid[i][j]:
            row[i] += 1
            col[j] += 1
ans = 0
for i in range(m):
    for j in range(n):
        if grid[i][j] and (row[i] > 1 or col[j] > 1):
            ans += 1
return ans
```

## 复杂度
时间：O(m·n)，两次遍历矩阵，m 行 n 列各扫一遍。
空间：O(m+n)，只开了 `row` 和 `col` 两个计数数组。

## 易错点
1. 输入 `[[1,0],[0,1]]` → 若误判「同行或同列有 0 也算连通」会得 2，正确是 `row=[1,1]`、`col=[1,1]`，每个 1 的行列计数都为 1，答案 0。
2. 输入 `[[1,0],[1,1]]` → 若只检查同行不检查同列，会漏掉 `(0,0)` 与 `(1,0)` 的列通信，正确是 `col[0]=2`，三个 1 全部计入，答案 3。

## 如果面试官追问
若要求输出所有可通信服务器坐标而非数量？答：遍历时把满足 `row[i]>1 or col[j]>1` 的 `(i,j)` 收集进列表返回即可，复杂度不变。
