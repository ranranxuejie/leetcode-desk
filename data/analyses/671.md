## 一句话思路
从根值出发做 DFS，只收集严格大于根值的节点值并取最小，因为根值必为全树最小值。

## 怎么做
1. 记 `mn = root.val`，它就是全树最小值（父值等于子值较小者，沿路径只会不减）。
2. DFS 时若 `node.val > mn`，用 `ans = min(ans, node.val)` 更新，且**不再往下递归**——该子树所有值都 ≥ `node.val`，不可能贡献更小的候选。
3. 若 `node.val == mn`，继续递归左右子节点。
4. 结束时 `ans` 仍是初始的 `2**31` 就返回 `-1`。

以 `root = [2,2,5,null,null,5,7]` 为例：`mn = 2`；根 2 递归，左子 2 继续递归（叶子，无更新），右子 5 > 2 → `ans = 5` 并剪枝，不再看它的 5、7。最终返回 5。

```python
def dfs(node):
    nonlocal ans
    if node is None:
        return
    if node.val > mn:
        ans = min(ans, node.val)
        return
    dfs(node.left)
    dfs(node.right)

mn = root.val
ans = 2**31
dfs(root)
return -1 if ans == 2**31 else ans
```

关键中间值：走到右子 5 时 `node.val > mn` 成立，`ans` 从 `2**31` 变成 5，随即 `return` 掉整棵 `[5,7]` 子树。

## 复杂度
时间 O(n)：每个节点最多访问一次，剪枝只会更少。
空间 O(h)：递归栈深度为树高 h，最坏链状 O(n)，未开额外数组。

## 易错点
- 输入 `[2,2,2]` → 若把「第二小」理解成「第二层或第二个不同位置的值」会返回 2 → 正确做法是只认严格大于 `mn` 的值，全树没有就返回 `-1`。
- 输入 `[2,2,5,null,null,5,7]` → 若在 `node.val > mn` 时仍继续递归，会把 7 也纳入比较，虽然 `min` 结果仍是 5，但一旦子树里有比 5 更小的值（如 `[2,2,5,null,null,3,7]` 这类结构）就会误更新 → 正确做法是命中即剪枝，因为子树值单调不减。

## 如果面试官追问
问：不剪枝、直接遍历全部节点收集所有值再排序行不行？
答：行，O(n log n)，但本题父子值单调关系保证了「第一个大于根值的节点值就是答案」，剪枝后 O(n) 且常数更小。
