## 一句话思路
按小时两位、分钟两位分别数合法取值个数，再相乘——因为 hh 与 mm 的约束互不影响。

## 怎么做
1. 把 `time` 拆成 `hh = time[0:2]`、`mm = time[3:5]`，两段独立计数。
2. 小时段按 `hh[0]` 分情况：`'?'` 时看 `hh[1]`——`hh[1] == '?'` 或 `int(hh[1]) <= 3` 则首位可取 0/1/2 共 3 种，否则只能取 0/1 共 2 种（因为 `24`~`29` 非法）。
3. 小时段 `hh[0]` 固定时，看 `hh[1]`：`'?'` 则 `hh[0] == '2'` 只能 0~3 共 4 种，否则 0~9 共 10 种；`hh[1]` 也固定则 1 种。
4. 分钟段同理：`mm[0] == '?'` 取 6 种（0~5），`mm[1] == '?'` 取 10 种，固定则 1 种，两者相乘。

以 `time = "?5:00"` 为例：`hh[0] == '?'`，`hh[1] == '5'`，`int('5') <= 3` 为 `False`，所以首位只能 0/1，小时计数 `2`；分钟 `"00"` 无 `?`，计数 `1`；答案 `2 * 1 = 2`。

```python
def count_hour(hh):
    if hh[0] == '?':
        if hh[1] == '?':
            return 24
        return 3 if int(hh[1]) <= 3 else 2
    if hh[1] == '?':
        return 4 if hh[0] == '2' else 10
    return 1

def count_minute(mm):
    a = 6 if mm[0] == '?' else 1
    b = 10 if mm[1] == '?' else 1
    return a * b
```

## 复杂度
时间：O(1)，只检查 4 个数位，与输入规模无关。
空间：O(1)，只用了几个整型临时变量。

## 易错点
- `time = "2?:00"` → 若把 `hh[1] == '?'` 一律算 10 种，会得到 10 而正确是 4（`20`~`23`）→ 必须对 `hh[0] == '2'` 单独限到 0~3。
- `time = "?4:00"` → 若首位 `'?'` 时无脑给 3 种（0/1/2），会得到 3 而正确是 2（`24` 非法）→ 判断条件要写成 `int(hh[1]) <= 3` 才允许 3 种，`'4'` 不满足。

## 如果面试官追问
问：若 `?` 可替换成任意字符而非仅数字，怎么改？
答：把每段的候选集合从 `range(10)` 换成允许字符集，仍按位枚举后过滤 `<= 23` / `<= 59`。
