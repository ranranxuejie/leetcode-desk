## 一句话思路
用栈模拟 DFS：遇到 `child` 就压栈 `curr.next`，先钻子链，回溯时再拼回。

## 怎么做
1. 用 `stack` 存「被 child 打断的后续链头」，`curr` 从 `head` 走。
2. 遇 `curr.child`：把 `curr.next` 压栈，`curr.next = curr.child`，`curr.child.prev = curr`，`curr.child = None`。
3. 遇 `curr.next` 为空且栈非空：弹出 `nxt`，接上 `curr.next = nxt`、`nxt.prev = curr`。
4. `curr` 前进，直到 `curr` 为空且栈空。

以示例 1 为例：走到 `curr = 3` 时 `3.child = 7`，栈变成 `[4]`，链变为 `3 -> 7`；继续到 `8` 时 `8.child = 11`，栈变成 `[4, 9]`，链变为 `8 -> 11`。走完 `12` 后 `curr.next` 为空，弹出 `9` 接在 `12` 后，再走完 `10` 弹出 `4`，最终 `12 -> 9 -> 10 -> 4`。

```python
stack, curr = [], head
while curr:
    if curr.child:
        if curr.next:
            stack.append(curr.next)
        curr.next = curr.child
        curr.child.prev = curr
        curr.child = None
    if not curr.next and stack:
        nxt = stack.pop()
        curr.next = nxt
        nxt.prev = curr
    curr = curr.next
return head
```

关键点：`curr.child = None` 必须在钻进去之前做，否则回溯到该节点时会被再次压栈，形成死循环。

## 复杂度
时间 O(n)：每个节点入栈出栈各至多一次，`curr` 只前进不后退。
空间 O(d)：栈深度等于嵌套层数，最坏 O(n)，无递归栈开销。

## 易错点
- 输入 `[1,2,null,3]`（`1.child = 3`）→ 若忘记 `curr.child = None`，回溯到 `1` 时 `child` 仍非空，会把 `3` 再压一次栈，链变成 `1->3->3->2` 或死循环 → 钻入前必须置空。
- 输入 `[1,2,3,4,5,6,null,null,null,7,8,9,10,null,null,11,12]` → 若只处理「`curr.next` 为空才弹栈」，走到 `12` 时栈顶是 `9` 而非 `4`，接完 `9->10` 后 `10.next` 为空才弹 `4`，顺序正确；但若在 `curr.child` 非空时也弹栈，`4` 会插到 `7` 前面 → 弹栈条件必须是 `not curr.next and stack`，且 `child` 优先。

## 如果面试官追问
问：不用栈、要求 O(1) 空间怎么做？
答：先递归扁平化 `child` 链拿到其尾节点，再把 `child` 链整体接到 `curr` 与 `curr.next` 之间，用尾指针回填，递归深度即层数。
