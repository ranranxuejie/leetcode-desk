## 一句话思路
倒着拆：每个数贡献自己的二进制 1 的个数，全局乘 2 的次数取所有数二进制位长的最大值。

## 怎么做
1. 正向看，`+1` 只能作用于单个元素，`*2` 作用于整个数组，所以乘 2 的次数由最大的那个数决定。
2. 把每个 `nums[i]` 拆成二进制：`+1` 的次数就是它二进制里 1 的个数（从 0 造出这个数至少要这么多次加一）。
3. 乘 2 的总次数 = `max(nums[i].bit_length()) - 1`，因为最大的数需要这么多位，而最低位不需要乘。
4. 两部分相加即为答案。

以 `nums = [1,5]` 为例：`1` 的二进制是 `1`，1 的个数为 1；`5` 是 `101`，1 的个数为 2，加一次数合计 3。`5.bit_length() = 3`，乘 2 次数 `3 - 1 = 2`。总数 `3 + 2 = 5`，与示例一致。

```python
def minOperations(nums):
    add = 0
    max_bits = 0
    for x in nums:
        add += bin(x).count('1')
        max_bits = max(max_bits, x.bit_length())
    return add + max(max_bits - 1, 0)
```

注意 `nums` 全为 0 时 `max_bits = 0`，`max_bits - 1` 会变成 -1，所以要取 `max(..., 0)`，否则答案错成负数。

## 复杂度
时间 O(n log M)，n 是数组长度，log M 来自每个数的 `bit_length`，M 为最大值。
空间 O(1)，只用了 `add`、`max_bits` 两个变量。

## 易错点
- 输入 `nums = [0]` → 若直接写 `max_bits - 1` 会得到 -1，答案错成 -1 → 正确做法是对乘 2 次数取 `max(max_bits - 1, 0)`。
- 输入 `nums = [2,4,8,16]` → 若把乘 2 次数按每个数各自算再相加（如 1+2+3+4=10）会得到 13 → 正确做法是乘 2 是全局操作，只取所有数位长的最大值减一，即 `5-1=4`，加一总数 4，答案 8。

## 如果面试官追问
问：如果要求输出具体操作序列怎么办？
答：从高位到低位逐位处理，先对需要该位的元素加一，再整体乘 2，按位长倒序生成即可。
