## 一句话思路
把点按 nums1 降序、查询按 x 降序，边扫边把 nums2 塞进树状数组求后缀最大值。

## 怎么做
1. 把 `(nums1[j], nums2[j], nums1[j]+nums2[j])` 按 nums1 降序排序，查询按 x 降序排序并记原下标。
2. 对 nums2 做离散化，树状数组维护「nums2 ≥ 某值」的最大和，用后缀查询实现。
3. 双指针：每处理一个查询，把所有 `nums1[j] >= x` 的点插入树状数组。
4. 查询 `y` 的后缀最大值，无点则 -1。

以示例 1 为例：点排序后为 `(4,2,6),(3,4,7),(2,5,7),(1,9,10)`。查询 `[4,1]` 时只插入 `(4,2,6)`，后缀 ≥1 的最大值是 6；查询 `[1,3]` 时四点全插入，后缀 ≥3 的最大值是 10。

```python
points = sorted(zip(nums1, nums2), reverse=True)
order = sorted(range(len(queries)), key=lambda i: -queries[i][0])
vals = sorted(set(nums2))
tree = [-1] * (len(vals) + 1)
def update(i, v):
    while i <= len(vals):
        tree[i] = max(tree[i], v); i += i & -i
def query(i):  # 后缀最大值
    res = -1
    while i > 0:
        res = max(res, tree[i]); i -= i & -i
    return res
```

## 复杂度
时间：排序 O((n+q) log(n+q))，每个点/查询各一次树状数组 O(log n)。
空间：树状数组与离散化数组 O(n)，答案数组 O(q)。

## 易错点
1. 查询 `[1,3]` 时若只插入 nums1 严格大于 x 的点，会漏掉 nums1=1 的点，答案从 10 变成 7；插入条件必须是 `nums1[j] >= x`。
2. 树状数组若写成前缀最大值，查询 `[2,5]` 会返回 nums2 较小的点；必须用后缀查询（离散化后反向索引或 `i -= i & -i` 的写法），保证取到 nums2 ≥ y 的部分。

## 如果面试官追问
若要求输出取得最大和的下标 j 而非和值？答：树状数组节点同时存 `(最大值, 下标)`，比较时按值取大即可。
