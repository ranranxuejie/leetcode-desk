## 一句话思路
把每个子表达式求成「单项式字典」`{变量元组: 系数}`，用栈按括号递归下降，乘法做字典卷积。

## 怎么做
1. 预处理：把 `evalvars` 建成 `{变量: 值}`，扫描 token 时变量若在表里就直接换成数字。
2. 用 `parse_expr → parse_term → parse_factor` 三层递归，`parse_factor` 遇 `(` 递归、遇数字返回 `{(): n}`、遇变量返回 `{(v,): 1}`。
3. 加减直接按 key 合并系数；乘法对两个字典做双重循环，key 用 `tuple(sorted(a+b))` 拼接。
4. 最后按 `(-len(key), key)` 排序，系数为 0 的项丢弃，拼成 `"-1*a"` 形式。

以示例 3 `"(e + 8) * (e - 8)"` 为例：左括号得 `{(e,):1, ():8}`，右括号得 `{(e,):1, ():-8}`；卷积后 `(e,e)` 项系数 `1*1=1`，常数项 `8*(-8)=-64`，`(e,)` 项 `1*(-8)+8*1=0` 被丢弃，输出 `["1*e*e","-64"]`。

```python
def mul(A, B):
    res = {}
    for ka, va in A.items():
        for kb, vb in B.items():
            k = tuple(sorted(ka + kb))
            res[k] = res.get(k, 0) + va * vb
    return res

def add(A, B, sign):
    res = dict(A)
    for k, v in B.items():
        res[k] = res.get(k, 0) + sign * v
    return res
```

## 复杂度
时间：O(n · 2^d) 量级，n 为 token 数，d 为单项式最高次数，乘法卷积是主开销。
空间：O(2^d) 个字典项，递归栈深度 O(括号层数)。

## 易错点
- 输入 `"e - 8 + temperature - pressure"` 且 `e=1, temperature=12`：若忘了先把变量替换成数字，会输出 `["-1*pressure","1*e","1*temperature","-8"]`；正确做法是 token 化时查表，命中就换成 `evalints` 的值，得到 `["-1*pressure","5"]`。
- 输入 `"a * a * b"`：若 key 用 `tuple` 但拼接时不排序，`(a,a,b)` 和 `(a,b,a)` 会成两个 key；正确做法是每次 `tuple(sorted(ka + kb))`，保证同一次数同变量集合只占一个 key。

## 如果面试官追问
问：若表达式长度到 10^5 怎么办？答：递归下降会爆栈，改成显式栈 + 运算符优先级表迭代求值，乘法卷积仍是瓶颈。
