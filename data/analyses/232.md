## 一句话思路
用 `in_stack` 只管入队、`out_stack` 只管出队，出队时把 `in_stack` 整体倒过去，顺序就翻成先进先出。

## 怎么做
1. `push(x)` 一律压进 `in_stack`，不碰 `out_stack`。
2. `pop`/`peek` 前先调 `_transfer()`：仅当 `out_stack` 为空时，把 `in_stack` 逐个 `pop` 再 `push` 进 `out_stack`。
3. `out_stack` 非空时绝不再倒，否则会把已排好的顺序打乱。
4. `empty()` 判两个栈是否都为空。

以官方示例走一遍：`push(1)`、`push(2)` 后 `in_stack = [1, 2]`（栈底到栈顶），`out_stack = []`。第一次 `peek()` 触发 `_transfer()`，`in_stack` 弹出 2、1 依次压入，得 `out_stack = [2, 1]`，栈顶 `1` 正是队首，返回 1。随后 `pop()` 时 `out_stack` 非空，直接弹栈顶得 1，不再倒。

```python
def _transfer(self):
    if not self.out_stack:
        while self.in_stack:
            self.out_stack.append(self.in_stack.pop())

def push(self, x):
    self.in_stack.append(x)

def peek(self):
    self._transfer()
    return self.out_stack[-1]
```

## 复杂度
时间：单次 `pop`/`peek` 最坏 O(n)，但每个元素最多被搬一次，n 次操作均摊 O(1)。
空间：O(n)，两个栈合计存 n 个元素，无额外结构。

## 易错点
- `push(1)`、`push(2)`、`pop()` 得 1 后 `out_stack = [2]`，此时再 `push(3)`：若 `_transfer()` 写成无条件倒栈，会把 3 压到 2 上面，下次 `pop` 返回 3 而不是 2。正确做法是只在 `out_stack` 为空时倒。
- 连续 `peek()` 两次：若 `peek` 里写成 `self.out_stack.pop()` 再塞回去，或误用 `in_stack[-1]`，第二次会拿到错误值或抛空栈异常。正确做法是 `peek` 只读 `out_stack[-1]`，不弹。

## 如果面试官追问
问：能否让 `push` 也 O(1) 最坏而非均摊？答：可以，改用「入队时倒一次」的对称写法，代价转移到 `push`，均摊结论不变。
