## 一句话思路
逐行求和取最大值：每位客户的资产总量就是 `accounts[i]` 这一行的和，答案即所有行和中的最大者。

## 怎么做
1. 用 `max(sum(row) for row in accounts)` 一行拿到答案，`sum` 负责行内累加，`max` 负责跨行比较。
2. 手写版：外层遍历 `accounts` 的每一行 `row`，内层把 `row` 累加成 `total`。
3. 每算完一行立刻用 `best = max(best, total)` 更新，不保存所有行和。
4. 以示例 2 `[[1,5],[7,3],[3,5]]` 为例：第 1 行 `total = 1+5 = 6`，`best = 6`；第 2 行 `total = 7+3 = 10`，`best` 更新为 10；第 3 行 `total = 3+5 = 8`，`best` 保持 10，返回 10。

```python
best = 0
for row in accounts:
    total = 0
    for x in row:
        total += x
    if total > best:
        best = total
return best
```

`best` 初值取 0 是安全的：提示保证 `accounts[i][j] >= 1`，任何行和都 ≥ 1，不会被 0 压住。若把初值写成 `-1` 也能过，但没必要。

## 复杂度
时间：O(m·n)，每个 `accounts[i][j]` 恰好被加一次。
空间：O(1)，只开 `best` 和 `total` 两个标量，不复制矩阵。

## 易错点
1. 把 `best` 初值写成 0 却在负数场景下用 → 若题目放宽为允许负资产，全负矩阵会错误返回 0 → 应初始化为 `-2**31` 或第一行的和。本题 `accounts[i][j] >= 1` 所以 0 可用，但换约束就要改。
2. 误把「最富客户」理解成「单家银行最大值」→ 对 `[[1,5],[7,3],[3,5]]` 会返回 7（`accounts[1][0]`）而不是 10 → 必须先按行求和再比较，比较对象是 `total` 不是 `x`。

## 如果面试官追问
问：如果 m 到 10^6、n 到 10^6 但矩阵以流式逐行到达，怎么改？
答：保持 `best` 单变量，每读一行算完即弃，空间仍是 O(1)，时间不变。
