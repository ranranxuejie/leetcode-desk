## 一句话思路
尽量多切长度为 3 的段，余数用 2 或 4 收尾，因为 3 是单位长度乘积最大的因子。

## 怎么做
1. 特判小值：`bamboo_len == 2` 返回 1，`== 3` 返回 2，因为必须切成至少两段。
2. 按 `bamboo_len % 3` 分三种情况：余 0 全切 3；余 1 时把一个 3 换成 2+2（即 `3**(n//3 - 1) * 4`）；余 2 时末尾留一个 2。
3. 全程对 `1000000007` 取模，用 `pow(3, k, MOD)` 直接算模幂，避免大整数。
4. 以 `bamboo_len = 12` 为例：`12 % 3 == 0`，`k = 4`，`pow(3, 4, MOD) = 81`，返回 81，与示例一致。

```python
MOD = 1000000007
def cuttingBamboo(n):
    if n == 2: return 1
    if n == 3: return 2
    r = n % 3
    if r == 0:
        return pow(3, n // 3, MOD)
    if r == 1:
        return pow(3, n // 3 - 1, MOD) * 4 % MOD
    return pow(3, n // 3, MOD) * 2 % MOD
```

关键中间值：`n = 12` 时 `n // 3 = 4`、`r = 0`，直接 `pow(3, 4, MOD)` 得 81；若 `n = 10`，`r = 1`，指数变成 `10 // 3 - 1 = 2`，结果 `9 * 4 = 36`，而不是 `3**3 * 1 = 27`。

## 复杂度
时间：O(log n)，`pow` 的模幂按指数 `n // 3` 做快速幂。
空间：O(1)，只存 `r`、`k` 和取模中间量，没有数组。

## 易错点
- `bamboo_len = 2` 或 `3` → 若直接套公式会返回 3 或 9（相当于允许不切），但题目要求至少切一刀 → 必须先特判返回 1 和 2。
- `bamboo_len % 3 == 1` → 若写成 `pow(3, n//3, MOD) * 1`，等于把余数 1 单独成段，乘积偏小（如 `n = 10` 得 27 而非 36）→ 正确做法是退一个 3，用 `4` 补上，即 `pow(3, n//3 - 1, MOD) * 4`。

## 如果面试官追问
问：如果要求返回具体切法而不是乘积？答：按同样规则生成 `n//3` 个 3，余 1 时改成一个 2+2，余 2 时补一个 2，直接输出这个列表即可。
