## 一句话思路
答案只可能是 0/1/2：先数岛屿数，再逐个删陆地判割点，删一个能分离就是 1，否则 2。

## 怎么做
1. 用 DFS 数连通块个数 `cnt`，`cnt != 1` 直接返回 0（含全水）。
2. 枚举每个 `grid[i][j] == 1`，临时置 0，再数一次连通块，若 `> 1` 返回 1，恢复。
3. 全部枚举完都不行，返回 2（删光所有陆地必然分离）。

以示例 1 为例：初始 `cnt = 1`。枚举到 `grid[1][1]` 置 0 后，剩余陆地分成 `{(0,1),(0,2)}` 和 `{(1,2)}` 两块，`cnt = 2 > 1`，直接返回 1？——注意示例答案是 2，因为 `(0,1)-(0,2)-(1,2)` 仍连通，实际 `cnt` 还是 1；真正删 `grid[1][1]` 和 `grid[0][2]` 才分离，故返回 2。这说明单点删除判据必须靠真实 DFS 数块，不能靠直觉。

```python
def count_islands(g):
    seen = set()
    def dfs(i, j):
        if not (0 <= i < len(g) and 0 <= j < len(g[0])) or g[i][j] == 0 or (i, j) in seen:
            return
        seen.add((i, j))
        for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
            dfs(i+di, j+dj)
    c = 0
    for i in range(len(g)):
        for j in range(len(g[0])):
            if g[i][j] == 1 and (i, j) not in seen:
                c += 1
                dfs(i, j)
    return c
```

主流程：`if count_islands(grid) != 1: return 0`；对每个陆地置 0 后 `if count_islands(grid) > 1: return 1`，恢复；最后 `return 2`。

## 复杂度
时间：每个陆地做一次 O(mn) 的 DFS，共 O((mn)^2)，m、n ≤ 30 时约 8×10^5。
空间：DFS 递归栈与 `seen` 集合各 O(mn)。

## 易错点
- 输入 `[[1,1]]` → 误以为删一个就分离，返回 1 → 正确是 2：两个格子互相连通，删任一个只剩单块，必须全删成 0 岛屿。
- 输入全 0 或本身已多岛（如 `[[1,0,1]]`）→ 漏判直接进枚举，可能返回 1 → 入口先 `count_islands != 1` 返回 0，全水也算分离。

## 如果面试官追问
问：m、n 放大到 1000 怎么办？答：用 Tarjan 求割点，O(mn) 判是否存在单点割点，答案仍是 0/1/2。
