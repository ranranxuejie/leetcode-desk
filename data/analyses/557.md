## 一句话思路
用双指针定位每个单词的左右边界，把该区间原地反转后跳过空格，逐词处理。

## 怎么做
1. 把 `s` 转成列表 `chars`，因为 Python 字符串不可变，原地交换必须靠列表。
2. 用 `i` 扫描，遇到非空格时令 `j = i`，向右推进到 `chars[j] == ' '` 或越界，此时 `[i, j-1]` 就是一个单词。
3. 在 `[i, j-1]` 内用 `l, r` 双指针相向交换，直到 `l >= r`。
4. 令 `i = j + 1` 跳过这个空格，继续下一轮；最后 `''.join(chars)`。

以 `s = "Mr Ding"` 为例：`i = 0` 时 `j` 推到 2（`chars[2] == ' '`），单词区间是 `[0, 1]`，交换后 `chars` 变成 `['r', 'M', ' ', 'D', 'i', 'n', 'g']`；接着 `i = 3`，`j` 推到 7 越界，反转 `[3, 6]` 得 `gniD`。

```python
chars = list(s)
i, n = 0, len(chars)
while i < n:
    if chars[i] != ' ':
        j = i
        while j < n and chars[j] != ' ':
            j += 1
        l, r = i, j - 1
        while l < r:
            chars[l], chars[r] = chars[r], chars[l]
            l += 1
            r -= 1
        i = j + 1
    else:
        i += 1
return ''.join(chars)
```

关键点：`j` 停在空格上而不是单词末字符上，所以反转右端是 `j - 1`，下一轮起点是 `j + 1`，两个偏移都不能省。

## 复杂度
时间 O(n)：`i` 和 `j` 各自单调右移，每个字符最多被访问常数次。
空间 O(n)：`chars` 列表和最终 `join` 的字符串各占 n。

## 易错点
- 输入 `"Mr Ding"` 若把反转右端写成 `j` 而非 `j - 1`，会把空格一起卷进交换，得到 `"rMgn iD"` 之类的错位结果；正确做法是区间取 `[i, j-1]`，空格永远不参与交换。
- 输入 `"a"`（单字符单词、无空格）时，若循环条件写成 `while j < n and chars[j] != ' '` 之外还额外假设「一定能找到空格」，`j` 会越界或死循环；正确做法是 `j` 的推进条件同时判 `j < n`，越界即视为单词结束。

## 如果面试官追问
问：如果单词间空格数量不定（可能多个连续空格）怎么办？
答：逻辑不变，`i = j + 1` 后外层 `else` 分支会逐个跳过连续空格，无需额外改动。
