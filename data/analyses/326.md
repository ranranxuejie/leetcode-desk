## 一句话思路
反复用 `n % 3 == 0` 判断并整除，直到 `n == 1` 为真；因为 3 的幂只有因子 3，除不尽就说明混入了别的因子。

## 怎么做
1. 先挡掉 `n <= 0`：`n = 0` 和负数都不可能是 3 的幂，直接返回 `False`。
2. 循环条件写 `n % 3 == 0`，能整除就 `n //= 3`，把因子 3 一个个剥掉。
3. 循环结束后返回 `n == 1`，只有剥到 1 才说明原数全是 3 的因子。

拿 `n = 27` 走一遍：`27 % 3 == 0` → `n = 9`；`9 % 3 == 0` → `n = 3`；`3 % 3 == 0` → `n = 1`；此时 `1 % 3 == 1` 退出循环，返回 `1 == 1` 即 `True`。换成 `n = 45`：`45 → 15 → 5`，`5 % 3 == 2` 退出，返回 `5 == 1` 即 `False`，因为 45 里混了因子 5。

```python
if n <= 0:
    return False
while n % 3 == 0:
    n //= 3
return n == 1
```

进阶版不用循环：`2**31 - 1` 范围内最大的 3 的幂是 `3**19 = 1162261467`，它只含因子 3，所以 `n > 0 and 1162261467 % n == 0` 就等价于「n 是 3 的幂」。注意这里除数和被除数不能写反，写成 `n % 1162261467` 会把 `n = 2` 判成 `True`。

## 复杂度
时间 O(log₃n)：每轮把 n 除以 3，轮数由 n 的 3 进制位数决定。
空间 O(1)：只改 n 本身，没开额外容器。

## 易错点
- `n = 1` → 若把循环条件写成 `while n > 1` 再配 `n % 3`，容易在 `n = 1` 时误判；正确做法是循环用 `n % 3 == 0`，最后单独判 `n == 1`，因为 `3**0 = 1` 是合法答案。
- `n = 0` 或 `n = -3` → 若只写 `while n % 3 == 0`，Python 里 `0 % 3 == 0` 恒成立会死循环，`-3` 则会被一路除到 `-1` 返回 `False` 但过程绕；正确做法是开头 `if n <= 0: return False` 一刀切掉。

## 如果面试官追问
问：不用循环也不用 `3**19` 这种硬编码，还能怎么做？
答：转成三进制字符串，判断是否形如 `1` 后跟全 `0`，即 `s[0] == '1' and set(s[1:]) <= {'0'}`。
