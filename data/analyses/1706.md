## 一句话思路
逐球逐行模拟：每行看 `grid[r][c]` 与相邻格是否同向，同向则列号平移 ±1，否则卡住返回 -1。

## 怎么做
1. 外层遍历起始列 `c`，内层用 `r` 从 0 走到 m-1，维护当前列 `c`。
2. 每行先取 `d = grid[r][c]`，若 `c + d` 越界（`<0` 或 `>= n`）立即判卡住。
3. 再检查 `grid[r][c + d] == d`，不等说明形成 V 形，判卡住；相等则 `c += d` 进入下一行。
4. 走完 m 行未卡住，`answer.append(c)`，否则 `append(-1)`。

以示例 1 的 b0（起始列 0）为例：第 0 行 `grid[0][0] = 1`，`c+1 = 1` 未越界且 `grid[0][1] = 1` 同向，`c` 变为 1；第 1 行 `grid[1][1] = 1`，`c` 变 2；第 2 行 `grid[2][2] = -1`，`c` 变 1；第 3 行 `grid[3][1] = 1`，`c` 变 2；第 4 行 `grid[4][2] = -1`，`c` 变 1，最终输出 1。而 b1 在第 1 行：`grid[1][1] = 1` 指向列 2，但 `grid[1][2] = 1` 与 `grid[1][1]` 同向……实际卡点在 b1 走到第 1 行时 `grid[1][1]=1` 指向 2，`grid[1][2]=1` 同向通过；真正卡住发生在后续行遇到 `grid[r][c]=-1` 而左邻为 `1` 的 V 形，此时 `grid[r][c-1] != -1`，返回 -1。

```python
ans = []
for c0 in range(n):
    c = c0
    for r in range(m):
        d = grid[r][c]
        nc = c + d
        if nc < 0 or nc >= n or grid[r][nc] != d:
            c = -1
            break
        c = nc
    ans.append(c)
```

## 复杂度
时间：O(m·n)，每颗球最多走 m 行，共 n 颗球。
空间：O(1) 额外空间（不计输出数组 ans）。

## 易错点
- 输入 `grid = [[-1]]`：只判 `grid[r][nc] != d` 会漏掉越界，`nc = -1` 直接索引到末列 `grid[0][-1] = -1` 误判通过。必须先判 `nc < 0 or nc >= n` 再取 `grid[r][nc]`。
- 输入示例 3 的最后一列（起始列 5）：第 0 行 `grid[0][5] = 1`，`nc = 6` 越界，应返回 -1；若先访问 `grid[0][6]` 会抛 IndexError。顺序必须是「先越界判断，后同向判断」。

## 如果面试官追问
问：若 m、n 都到 10^4 且球数等于列数，还能更快吗？
答：不能渐进优化，每颗球路径依赖逐行挡板，最坏仍需 O(m·n)；可预处理每行连续同向段来跳过，但最坏不变。
