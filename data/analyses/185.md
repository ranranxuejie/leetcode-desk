## 一句话思路
用窗口函数 `DENSE_RANK()` 按部门分区、工资降序排名，筛出排名 ≤3 的行，再 join 部门名。

## 怎么做
1. 在 Employee 上开窗：`PARTITION BY departmentId ORDER BY salary DESC`，用 `DENSE_RANK()` 得到 `rk`。
2. 关键点：必须用 `DENSE_RANK` 而不是 `ROW_NUMBER`——IT 部门里 Joe 和 Randy 都是 85000，`DENSE_RANK` 让两人同为 2，Will 的 70000 才是 3；若用 `ROW_NUMBER`，Will 会被挤到 4 而漏掉。
3. 外层筛 `rk <= 3`，再 `JOIN Department ON departmentId = Department.id` 取部门名。
4. 输出列别名对齐 `Department / Employee / Salary`。

以官方示例 IT 部门（id=1）为例，工资降序去重后是 90000、85000、70000，对应 `rk` 为 1、2、2、3，四行全部保留；Sales 只有 80000、60000 两个不同值，`rk` 最大为 2，自然没有第三高。

```python
# 伪 SQL 骨架（pandas 里用 rank(method='dense') 等价）
# SELECT d.name AS Department, e.name AS Employee, e.salary AS Salary
# FROM (
#   SELECT *, DENSE_RANK() OVER (
#     PARTITION BY departmentId ORDER BY salary DESC) AS rk
#   FROM Employee
# ) e JOIN Department d ON e.departmentId = d.id
# WHERE e.rk <= 3;

# pandas 等价写法
emp["rk"] = emp.groupby("departmentId")["salary"].rank(method="dense", ascending=False)
res = emp[emp["rk"] <= 3].merge(dept, left_on="departmentId", right_on="id")
res = res[["name_y", "name_x", "salary"]].rename(
    columns={"name_y": "Department", "name_x": "Employee", "salary": "Salary"})
```

## 复杂度
时间：O(n log n)，n 为 Employee 行数，排序/开窗贡献 log n。
空间：O(n)，窗口排名结果与 join 后的中间表各占一份。

## 易错点
- 用 `ROW_NUMBER()` 代替 `DENSE_RANK()`：IT 部门 Joe、Randy 同为 85000 时，`ROW_NUMBER` 给出 2 和 3，Will 的 70000 变成 4 被过滤掉，输出少一行 Will；正确做法是 `DENSE_RANK`，让并列工资共享同一名次。
- 用 `RANK()` 而非 `DENSE_RANK()`：并列后名次会跳号（1、2、2、4），Will 的 70000 得到 4 同样被漏掉；本题要求「不同工资中排名前三」，必须用不跳号的 `DENSE_RANK`。

## 如果面试官追问
问：若要求每个部门前 K 高、K 由参数传入怎么办？
答：把 `rk <= 3` 换成 `rk <= K`，`DENSE_RANK` 逻辑不变，复杂度仍是 O(n log n)。
