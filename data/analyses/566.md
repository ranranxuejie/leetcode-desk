## 一句话思路
元素总数不变时，把一维下标 `k` 同时映射到 `mat[k // n][k % n]` 和 `res[k // c][k % c]`，逐位搬运即可。

## 怎么做
1. 先判 `m * n != r * c`，不等就直接返回 `mat`（示例 2 的 2*2=4 与 2*4=8 不等，原样返回）。
2. 建 `res = [[0] * c for _ in range(r)]`，注意不能写 `[[0]*c]*r`，否则各行是同一对象。
3. 用单个 `k` 从 0 走到 `m*n-1`，按行优先顺序同时算出源、目标两个坐标。
4. 赋值 `res[k // c][k % c] = mat[k // n][k % n]`。

以示例 1 为例，`mat = [[1,2],[3,4]]`，`m=2, n=2, r=1, c=4`。当 `k=2` 时：源坐标 `(2//2, 2%2) = (1, 0)` 取到 `mat[1][0] = 3`；目标坐标 `(2//4, 2%4) = (0, 2)`，于是 `res[0][2] = 3`。`k=3` 时源 `(1,1)=4`、目标 `(0,3)`，最终 `res = [[1,2,3,4]]`。

```python
m, n = len(mat), len(mat[0])
if m * n != r * c:
    return mat
res = [[0] * c for _ in range(r)]
for k in range(m * n):
    res[k // c][k % c] = mat[k // n][k % n]
return res
```

关键点：`k // n` 和 `k % n` 里的除数是**原矩阵列数 n**，`k // c` 和 `k % c` 里的除数是**新矩阵列数 c**，两个除数不能混。行优先顺序天然由 `k` 递增保证，不需要额外记录行列指针。

## 复杂度
时间 O(m*n)：每个元素恰好搬运一次，`k` 循环 m*n 次。
空间 O(r*c)：除返回的 `res` 外只用了常数个变量。

## 易错点
- `mat = [[1,2],[3,4]], r = 2, c = 4` → 若漏判 `m*n != r*c`，会按 `k` 只填前 4 格，返回 `[[1,2,3,4],[0,0,0,0]]` → 正确做法是开头就 `return mat`，示例 2 期望原样输出。
- `mat = [[1,2],[3,4]], r = 4, c = 1` → 若把目标下标写成 `res[k // n][k % n]`（沿用原列数 2），会得到 `[[1,2],[3,4],[0,0],[0,0]]` 并越界 → 目标必须用 `k // c`、`k % c`，此时正确结果是 `[[1],[2],[3],[4]]`。

## 如果面试官追问
问：如果要求原地重塑、不许开新矩阵怎么办？
答：只有 `r == m and c == n` 时才能直接返回 `mat`，否则形状变了必须新开 `r*c` 空间，无法原地。
