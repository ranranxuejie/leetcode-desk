## 一句话思路
对答案时间 T 二分，用 `sum(isqrt(T // r))` 判断 T 分钟内能否修完 cars 辆，单调性保证二分成立。

## 怎么做
1. 上界取 `min(ranks) * cars * cars`：让最快的人独自修完全部车，一定可行。
2. 对 T 做二分，判定函数里每个机械工能修 `isqrt(T // r)` 辆（因为 r*n² ≤ T 即 n ≤ √(T/r)）。
3. 累加所有机械工的产能，`>= cars` 就收缩右界，否则抬左界。
4. 返回左界。

以 `ranks = [4,2,3,1], cars = 10` 为例，二分到 T=16 时：r=4 得 `isqrt(4)=2`，r=2 得 `isqrt(8)=2`，r=3 得 `isqrt(5)=2`，r=1 得 `isqrt(16)=4`，合计 2+2+2+4=10 ≥ 10，判定通过；T=15 时 r=1 只能修 `isqrt(15)=3` 辆，合计 9 < 10，被否掉，所以答案是 16。

```python
from math import isqrt

def can(t):
    total = 0
    for r in ranks:
        total += isqrt(t // r)
        if total >= cars:
            return True
    return False

lo, hi = 0, min(ranks) * cars * cars
while lo < hi:
    mid = (lo + hi) // 2
    if can(mid):
        hi = mid
    else:
        lo = mid + 1
return lo
```

## 复杂度
时间：二分 log(min(ranks)·cars²) 轮，每轮扫 n=len(ranks) 个机械工，共 O(n log(min·cars²))。
空间：只用了 lo/hi/mid/total 几个变量，O(1) 额外空间。

## 易错点
- 上界写成 `max(ranks) * cars * cars` 或 `cars * cars`：ranks 里最小是 1 时前者偏大但不错，后者在 `ranks=[100], cars=10^6` 时上界 10^12 远小于真实值 10^14，二分区间不含答案，返回错误值。正确做法是用 `min(ranks) * cars * cars`。
- 判定里用 `int((t / r) ** 0.5)` 或 `math.sqrt`：`t // r` 很大时浮点开方会向下取整错一位，例如 `t//r = 10**12 - 1` 时 `sqrt` 可能返回 999999.9999999999，`int` 得 999999 而正确是 999999。正确做法是用 `math.isqrt` 做整数开方。

## 如果面试官追问
问：如果要求输出每个机械工各修几辆，怎么改？
答：二分定下最优 T 后，对每个 r 取 `isqrt(T // r)` 辆，再把多出来的产能从后往前削减到总数正好等于 cars。
