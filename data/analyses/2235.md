## 一句话思路
直接返回 `num1 + num2`，因为题目只要求两整数之和，Python 的 `+` 对正负数、零都成立。

## 怎么做
1. 读取两个参数 `num1`、`num2`，不做任何类型转换或边界判断。
2. 直接计算 `num1 + num2`，Python 整数无溢出，结果即数学和。
3. 返回该值。

以示例 1 为例：`num1 = 12`，`num2 = 5`，中间值就是 `12 + 5 = 17`，直接返回 17。示例 2 中 `num1 = -10`，`num2 = 4`，`-10 + 4 = -6`，符号由绝对值大的操作数决定，`+` 已自动处理。

```python
def sum(self, num1: int, num2: int) -> int:
    return num1 + num2
```

若面试官要求不用 `+`，可改用位运算模拟：异或得无进位和，与运算左移得进位，循环到进位为 0。但本题约束 `-100 <= num1, num2 <= 100`，直接相加即可，位运算版只是延伸。

## 复杂度
时间：O(1)，一次加法，与 `num1`、`num2` 大小无关。
空间：O(1)，只存返回值，未开额外数组或哈希表。

## 易错点
- 输入 `num1 = -10, num2 = 4` → 若误以为「两整数相加」只处理非负，可能先取绝对值再拼符号，错成 14 或 -14 → 正确做法是直接用 `num1 + num2`，让 Python 处理符号。
- 输入 `num1 = 100, num2 = 100` → 若按 32 位截断思路手动取模，可能写成 `(num1 + num2) % (2**31)`，错成 200 以外的值 → 本题提示范围仅到 ±100，和最大 200，远小于 `2**31 - 1`，无需截断，直接返回。

## 如果面试官追问
问：若禁用 `+` 且允许负数，怎么写？答：用 `while num2: carry = (num1 & num2) << 1; num1 ^= num2; num2 = carry`，Python 需对负数做掩码处理。
