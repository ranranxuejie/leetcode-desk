## 一句话思路
用两个队列存 R 和 D 的下标，每次让下标小的 senator 禁掉对方队首，被禁的出队、赢家下标加 n 后重新入队，模拟轮次推进。

## 怎么做
1. 把 `senate` 中所有 `'R'` 的下标放进 `rq`，`'D'` 的下标放进 `dq`。
2. 当两个队列都非空时，比较 `rq[0]` 和 `dq[0]`：下标小的那个 senator 先行动，禁掉对方队首。
3. 赢家从自己队列弹出后加 `n` 再入队（表示下一轮），输家直接 `popleft()` 出队。
4. 循环结束时非空的队列对应阵营获胜。

以 `senate = "RDD"`（n=3）为例：初始 `rq=[0]`、`dq=[1,2]`。第一轮 `0 < 1`，R 禁掉 D，`rq` 变成 `[3]`（0+3），`dq` 变成 `[2]`。此时 `3 > 2`，D 禁掉 R，`dq` 变成 `[5]`（2+3），`rq` 空，Dire 胜。关键中间值就是 `rq=[3]` 这个加 n 的操作——它保证 R 在下一轮排在 D 后面。

```python
from collections import deque

rq = deque(i for i, c in enumerate(senate) if c == 'R')
dq = deque(i for i, c in enumerate(senate) if c == 'D')
n = len(senate)

while rq and dq:
    if rq[0] < dq[0]:
        dq.popleft()
        rq.append(rq.popleft() + n)
    else:
        rq.popleft()
        dq.append(dq.popleft() + n)

return "Radiant" if rq else "Dire"
```

## 复杂度
时间：O(n)，每个 senator 最多被弹出一次，队列操作均摊 O(1)。
空间：O(n)，两个 deque 合计存 n 个下标。

## 易错点
- 输入 `"RRDD"` 时若只做一轮比较就返回，会错成 Radiant 或 Dire 的随机结果；正确做法是 `while rq and dq` 持续到一方清空，因为 R 加 n 后可能还要再战。
- 输入 `"DDRRR"` 时若忘记给赢家下标 `+ n`，`rq[0]` 和 `dq[0]` 的相对顺序会乱，导致本该 D 先手却判成 R；正确做法是赢家 `append(popleft() + n)`，用加 n 模拟「下一轮排在所有本轮 senator 之后」。

## 如果面试官追问
问：n 扩大到 10^7 且 senate 以流式输入怎么办？
答：仍需 O(n) 空间存下标，但可改用两个数组加头指针模拟队列，避免 deque 的对象开销。
