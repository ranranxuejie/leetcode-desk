## 一句话思路
正着删会不断裂开，倒着做：把删除序列反过来当「逐个加回」，用并查集维护连续段和，每步取全局最大。

## 怎么做
1. 反向遍历 `removeQueries`，用 `alive` 标记该位置是否已恢复，初始全 `False`。
2. 恢复下标 `i` 时置 `alive[i]=True`，`parent[i]=i`，`seg_sum[i]=nums[i]`，再尝试与 `i-1`、`i+1` 合并。
3. 合并时把根的和相加，用 `best` 记录当前所有段和的最大值，写入 `ans[k]`。
4. 最后把 `ans` 反转即为正序答案。

以示例 1 为例，反向第一个恢复的是 `i=1`（`nums[1]=2`），此时左右都未恢复，段和就是 2；接着恢复 `i=4`（值 1），段和 1，`best` 仍是 2；再恢复 `i=2`（值 5），左邻 `i=1` 已活，合并得段和 7，`best=7`。

```python
parent = list(range(n)); seg = [0]*n; alive = [False]*n
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]; x = parent[x]
    return x
best = 0; ans = [0]*n
for k in range(n-1, -1, -1):
    i = removeQueries[k]; alive[i] = True
    parent[i] = i; seg[i] = nums[i]; best = max(best, seg[i])
    for j in (i-1, i+1):
        if 0 <= j < n and alive[j]:
            ri, rj = find(i), find(j)
            if ri != rj:
                parent[rj] = ri; seg[ri] += seg[rj]
                best = max(best, seg[ri])
    ans[k] = best
return ans[::-1]
```

## 复杂度
时间 O(n·α(n))：n 次恢复，每次至多两次 find，路径压缩近似常数。
空间 O(n)：`parent`、`seg`、`alive`、`ans` 各开一个长度 n 的数组。

## 易错点
- `removeQueries` 最后一个元素被删后数组全空，答案应为 0：反向第一步恢复的正是这个位置，`best` 从 0 起算即可；若把 `best` 初始化成 `-1` 或 `nums[0]`，示例 2 末位会输出错误值。
- 合并时只更新了根的和却没同步 `best`：如示例 1 恢复 `i=2` 后段和 7，若只在单点恢复时更新 `best`，会漏掉 7 而错答成 5；每次 `seg[ri] += seg[rj]` 后必须再取一次 max。

## 如果面试官追问
若要求输出每次删除后最大子段的具体区间？答：并查集根上额外存段左右端点，`best` 同时记下对应根，反序记录后翻转即可。
