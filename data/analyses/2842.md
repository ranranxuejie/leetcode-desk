## 一句话思路
按字符频次降序取前 k 个，频次相同的边界字符用组合数选，其余每个字符乘上它自己的频次。

## 怎么做
1. 用 `Counter(s)` 统计频次，把 `freq` 降序排序；`k` 大于不同字符数时直接返回 0（凑不出 k 个唯一字符）。
2. 从前往后累加，前 `k` 个字符的频次和就是最大美丽值，但计数要按「频次分组」处理。
3. 设第 k 个位置的频次为 `v`，`v` 在 `freq` 中总出现 `total` 次，其中前 k 个里占了 `need` 次，则边界贡献 `C(total, need)`。
4. 前 k 个中频次严格大于 `v` 的每个字符，有 `freq[i]` 种下标选法，全部相乘。

以 `s = "bcca", k = 2` 为例：`freq = [2, 1, 1]`（c, b, a）。前 2 个是 `2, 1`，边界 `v = 1`，`total = 2`（b 和 a 都是 1），`need = 1`，`C(2,1) = 2`；频次大于 1 的只有 c，乘 `2`，答案 `2 * 2 = 4`。

```python
from collections import Counter
from math import comb

MOD = 10**9 + 7
freq = sorted(Counter(s).values(), reverse=True)
if k > len(freq):
    return 0
v = freq[k - 1]
total = freq.count(v)
need = freq[:k].count(v)
ans = comb(total, need) % MOD
for x in freq[:k]:
    if x > v:
        ans = ans * x % MOD
return ans
```

注意 `comb(total, need)` 里 `total ≤ 26`，不会爆，但乘频次时每步都要 `% MOD`。

## 复杂度
时间 O(n + 26 log 26)：`Counter` 扫一遍 s 是 O(n)，排序只排最多 26 个频次。
空间 O(26)：哈希表和频次数组都只存小写字母，与 n 无关。

## 易错点
- `s = "aa", k = 1`：不同字符只有 1 个，`k > len(freq)` 若不判会越界或错算成 0 以外的值，正确做法是先返回 0。
- `s = "bcca", k = 2`：若把边界字符的选法写成 `total` 而不是 `C(total, need)`，会得 2 而非 4；频次相同的字符必须用组合数，且只对「等于 v」的字符用，严格大于 v 的用频次本身相乘。

## 如果面试官追问
若要求输出所有最优子序列的具体下标方案而非计数，怎么改？
答：把组合数展开成枚举，对边界组做 `itertools.combinations` 选 `need` 个字符，再对每个字符枚举其所有出现位置。
