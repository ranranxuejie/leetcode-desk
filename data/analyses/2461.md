## 一句话思路
定长窗口滑过 nums，用哈希表维护窗口内计数，计数全为 1 时用窗口和更新答案。

## 怎么做
1. 先算 `nums[0:k]` 的和 `s`，并把这段元素计数写进 `cnt`。
2. 窗口右移：`s += nums[i] - nums[i-k]`，同时 `cnt[nums[i]] += 1`、`cnt[nums[i-k]] -= 1`，减到 0 就 `del` 掉。
3. 判断 `len(cnt) == k` 即窗口内无重复，此时用 `s` 更新 `ans`。
4. 遍历结束返回 `ans`，初值 0 天然覆盖「不存在」的情况。

以 `nums = [1,5,4,2,9,9,9], k = 3` 为例：初始窗口 `[1,5,4]`，`s = 10`，`len(cnt) = 3`，`ans = 10`。滑到 `i = 4` 时窗口是 `[4,2,9]`，`s = 10 + 9 - 5 = 14`？不对——`i=3` 时 `s = 10 + 2 - 1 = 11`，`i=4` 时 `s = 11 + 9 - 5 = 15`，`cnt = {4:1,2:1,9:1}`，`len(cnt) == 3`，`ans` 更新为 15。

```python
cnt = {}
s = sum(nums[:k])
for x in nums[:k]:
    cnt[x] = cnt.get(x, 0) + 1
ans = s if len(cnt) == k else 0
for i in range(k, len(nums)):
    s += nums[i] - nums[i - k]
    cnt[nums[i]] = cnt.get(nums[i], 0) + 1
    cnt[nums[i - k]] -= 1
    if cnt[nums[i - k]] == 0:
        del cnt[nums[i - k]]
    if len(cnt) == k:
        ans = max(ans, s)
```

## 复杂度
时间 O(n)：每个元素进出窗口各一次，哈希表操作均摊 O(1)。
空间 O(k)：`cnt` 最多存 k 个不同值。

## 易错点
- `nums = [4,4,4], k = 3` 时若只判断「窗口和最大」而不查 `len(cnt)`，会返回 12；必须先确认 `len(cnt) == k` 再更新 `ans`，否则返回 0。
- 计数减到 0 后不 `del cnt[nums[i-k]]`，`len(cnt)` 会一直等于历史不同值个数，`[1,5,4,2,9,9,9]` 滑到 `[9,9,9]` 时 `len(cnt)` 仍可能是 3 而误判合法；必须显式删除零计数键。

## 如果面试官追问
若要求输出该子数组的起止下标？答：在 `len(cnt) == k` 成立时额外记录 `i - k + 1`，与 `ans` 同步更新即可。
