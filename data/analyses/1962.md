## 一句话思路
每次对当前最大堆取 `floor(piles[i]/2)` 移除，用最大堆贪心，因为大堆减半的绝对损失最大。

## 怎么做
1. 把 `piles` 取负建成最小堆，`heapq.heapify`，这样堆顶是当前最大堆。
2. 循环 `k` 次：弹出堆顶 `x`（负数），移除量是 `(-x) // 2`，把 `x + (-x)//2` 压回堆。
3. 最后 `-sum(heap)` 即剩余总数。

以示例 1 `piles=[5,4,9], k=2` 为例：建堆后堆顶是 `-9`，第一次移除 `9//2=4`，压回 `-5`，堆变 `[-5,-5,-4]`；第二次堆顶 `-5`，移除 `5//2=2`，压回 `-3`，堆变 `[-5,-4,-3]`，`-sum = 12`。

```python
import heapq

def minStoneSum(piles, k):
    heap = [-p for p in piles]
    heapq.heapify(heap)
    for _ in range(k):
        x = -heapq.heappop(heap)
        heapq.heappush(heap, -(x - x // 2))
    return -sum(heap)
```

关键在 `x - x // 2` 而不是 `x // 2`：移除的是 `floor(x/2)`，留下的是 `x - floor(x/2)`，对 `x=5` 留 `3`，对 `x=9` 留 `5`。

## 复杂度
时间：`O(n + k log n)`，`n` 来自建堆，`k` 次各一次 `log n` 的弹出/压入。
空间：`O(n)`，堆里存 `n` 个负数，无其他额外结构。

## 易错点
- `piles=[1], k=1` → 若写成 `heapq.heappush(heap, -(x // 2))` 会压入 `0`，答案错成 `0`；正确是留 `x - x//2 = 1`，移除 `0`，答案 `1`。
- `piles=[4,3,6,7], k=3` → 若用排序后从大到小顺序处理而不重新入堆，会漏掉「同一堆多次操作」：`7→4` 后 `4` 仍可能再被选，正确做法是每轮重新取堆顶，示例 2 第三轮选的是 `4` 而非初始的 `6`。

## 如果面试官追问
问：若要求输出每步操作的下标序列？答：堆里存 `(-piles[i], i)` 元组，每轮弹出时记录 `i`，`k` 次后即得序列，复杂度不变。
