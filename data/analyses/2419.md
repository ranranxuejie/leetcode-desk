## 一句话思路
全局最大按位与必等于数组最大值 `max(nums)`，答案就是 `max(nums)` 连续出现的最长段长度。

## 怎么做
1. 按位与只会让数变小或不变（`a & b <= min(a,b)`），所以任何子数组的与值都不超过其中任一元素，上界是 `max(nums)`。
2. 单个 `max(nums)` 元素构成的子数组与值恰为 `max(nums)`，上界可达，故 k = `max(nums)`。
3. 要让与值保持 `max(nums)`，段内每个元素都必须等于 `max(nums)`（否则与值立刻掉下来），问题化为求最长连续相等段。
4. 一遍扫描维护当前段长 `cur` 与答案 `best`。

以 `nums = [1,2,3,3,2,2]` 为例，`max(nums) = 3`；扫描到下标 2、3 时 `cur` 从 1 涨到 2，下标 4 的 `2` 使 `cur` 归零，最终 `best = 2`。

```python
m = max(nums)
best = cur = 0
for x in nums:
    if x == m:
        cur += 1
        best = max(best, cur)
    else:
        cur = 0
return best
```

## 复杂度
时间 O(n)：`max` 一次加一次扫描，n 是 `len(nums)`。
空间 O(1)：只开 `m`、`best`、`cur` 三个变量。

## 易错点
- 输入 `[1,2,3,4]` → 误以为要找「与值最大」的复杂子数组，去写按位枚举或双指针 → 正确做法是先取 `m = 4`，扫描发现 4 只出现一次，直接返回 1。
- 输入 `[3,3,1,3]` → 把「最长子数组」理解成可以跨越 `1` 的段，返回 3 → 正确做法是遇到 `x != m` 立刻 `cur = 0`，答案是 2。

## 如果面试官追问
问：若要求返回该最长子数组的起止下标？答：在 `cur` 更新 `best` 时同步记录 `i - cur + 1` 和 `i` 即可，仍是 O(n)。
