## 一句话思路
一次遍历，用哈希表记每个值上一次出现的下标和当前公差，公差一旦不一致就标记为不合格。

## 怎么做
1. 建两个字典：`last[v]` 存 v 最近一次出现的下标，`gap[v]` 存 v 已确定的公差（首次出现时不存在）。
2. 遍历 `enumerate(nums)`，对每个 `(i, v)`：若 `v` 已出现过，算 `d = i - last[v]`；若 `gap[v]` 已有值且 `d != gap[v]`，把 `v` 记进 `bad` 集合。
3. 若 `gap[v]` 还没有值，就令 `gap[v] = d`；然后无条件更新 `last[v] = i`，并累加 `cnt[v]`。
4. 遍历结束后，答案 = 满足 `cnt[v] >= 3` 且 `v not in bad` 的 v 的个数。

以示例 3 `nums = [8,6,6,8,8]` 为例：处理到下标 4 的 8 时，`last[8] = 3`，`d = 1`，而 `gap[8]` 在下标 3 时已被设为 `3 - 0 = 3`，`1 != 3`，于是 `bad = {8}`；6 的 `cnt` 只有 2，最终答案是 0。

```python
last, gap, cnt, bad = {}, {}, {}, set()
for i, v in enumerate(nums):
    if v in last:
        d = i - last[v]
        if v in gap and gap[v] != d:
            bad.add(v)
        elif v not in gap:
            gap[v] = d
    last[v] = i
    cnt[v] = cnt.get(v, 0) + 1
return sum(1 for v in cnt if cnt[v] >= 3 and v not in bad)
```

关键点：`gap[v]` 只在第二次出现时确定，之后每次都必须相等；`bad` 一旦加入就不再移除，因为只要有一处断裂就永久不合格。

## 复杂度
时间 O(n)：一次遍历，字典均摊 O(1)，n 为 `len(nums)`。
空间 O(k)：k 为不同值的个数，开了 `last`、`gap`、`cnt`、`bad` 四个结构。

## 易错点
- 输入 `[8,8,8,8]`：若把「公差」理解成「必须大于 0」或漏掉第二次出现时设 `gap`，会错判成 0；正确做法是第二次出现时令 `gap[8] = 1`，之后 `d` 恒为 1，判为特别。
- 输入 `[8,6,6,8,8]`：若只在 `cnt[v] >= 3` 时才检查公差，会漏掉 8 在下标 3 处已确定的 `gap[8] = 3` 与下标 4 的 `d = 1` 冲突；正确做法是每次出现都比对，冲突立刻进 `bad`。

## 如果面试官追问
若要求返回所有特别整数而非个数？答：把最后的 `sum(...)` 换成列表推导 `[v for v in cnt if cnt[v] >= 3 and v not in bad]`，其余逻辑不变。
