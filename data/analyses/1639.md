## 一句话思路
按列统计每个字符出现次数，再做「target 前 i 个字符用前 j 列」的二维 DP，逐列滚动。

## 怎么做
1. 预处理 `cnt[j][c]`：`words` 中第 `j` 列等于字符 `c` 的单词个数，因为选第 `j` 列时同列任意单词都可选。
2. 定义 `dp[i]` = 用前若干列构造出 `target[:i]` 的方案数，初始 `dp[0] = 1`。
3. 对每一列 `j` 从后往前更新 `dp[i] += dp[i-1] * cnt[j][target[i-1]]`，倒序保证同一列只用一次。
4. 若 `len(target) > len(words[0])` 直接返回 0，列数不够。

以示例 1 为例，`words = ["acca","bbbb","caca"]`，第 0 列是 `a,b,c`，故 `cnt[0]['a'] = 1`；第 1 列是 `c,b,a`，`cnt[1]['b'] = 1`；第 3 列是 `a,b,a`，`cnt[3]['a'] = 2`。处理完第 3 列后 `dp[3] = 6`。

```python
MOD = 10**9 + 7
m, n = len(words[0]), len(target)
if n > m:
    return 0
cnt = [[0] * 26 for _ in range(m)]
for w in words:
    for j, ch in enumerate(w):
        cnt[j][ord(ch) - 97] += 1
dp = [0] * (n + 1)
dp[0] = 1
for j in range(m):
    for i in range(min(j + 1, n), 0, -1):
        c = ord(target[i - 1]) - 97
        dp[i] = (dp[i] + dp[i - 1] * cnt[j][c]) % MOD
return dp[n]
```

## 复杂度
时间：O(L·W + L·T)，L 为单词长度，W 为单词数，T 为 target 长度。
空间：O(L·26 + T)，`cnt` 表加一维滚动 `dp`。

## 易错点
- 内层 `i` 写成正序 → 同一列被重复使用，示例 1 会算出大于 6 的结果；必须 `range(min(j+1,n), 0, -1)` 倒序。
- 忘记 `len(target) > len(words[0])` 的剪枝 → 列数不足时 `dp[n]` 恒为 0 虽不错，但 `cnt` 只建了 `m` 列，访问 `target` 更长时逻辑仍安全却白跑；正确做法是提前返回 0。

## 如果面试官追问
若要求输出所有具体方案（k 序列）而非计数？答：把 `dp` 换成回溯 + 记忆化，枚举每列匹配的单词下标，方案数指数级时只能按需生成。
