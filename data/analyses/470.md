## 一句话思路
用两次 rand7 拼出 1~49 的均匀整数，只保留 1~40，再按 `(x-1) % 10 + 1` 映射到 1~10。

## 怎么做
1. 调用两次 rand7，令 `x = (rand7() - 1) * 7 + rand7()`，得到 [1,49] 上均匀的整数。
2. 若 `x > 40` 就丢弃并重新采样（拒绝采样），保证剩下的 40 个值等概率。
3. 返回 `(x - 1) % 10 + 1`，把 1~40 每 10 个一组映射到 1~10。

以示例 1（n=1）为例：假设第一次 `rand7()` 返回 3、第二次返回 5，则 `x = (3-1)*7 + 5 = 19`，19 ≤ 40 通过，返回 `(19-1) % 10 + 1 = 9`。若两次得到 7 和 7，`x = 49 > 40`，丢弃重来。

```python
def rand10(self):
    while True:
        x = (rand7() - 1) * 7 + rand7()   # 1..49 均匀
        if x <= 40:                        # 拒绝 41..49
            return (x - 1) % 10 + 1        # 1..40 -> 1..10
```

关键点：`(rand7()-1)*7` 取的是 0,7,14,…,42，加上第二次的 1~7 恰好铺满 1~49 且无重叠，这是「均匀」的来源；`x <= 40` 而不是 `x <= 10`，是因为 40 是 10 的整数倍，截断后每组 10 个值概率仍相等。

## 复杂度
时间：每次 rand10 期望调用 rand7 约 2.4 次（2 / (40/49)），n 次调用线性放大。
空间：O(1)，只用了 `x` 一个临时变量，无额外数组。

## 易错点
- 写成 `rand7() + rand7()` → 得到 2~14 且中间值概率高（如 7 有 6 种组合），分布不均 → 必须用 `(a-1)*7 + b` 的进位拼接，让 49 个结果一一对应。
- 边界写成 `x < 40` 或 `x <= 49` → 前者丢掉 40 导致 10 少一个来源、后者把 41~49 也映射进去使 1~9 偏多 → 正确条件是 `x <= 40`，因为 40 是 10 的倍数。

## 如果面试官追问
问：能否把期望调用次数从 2.4 降到接近 2.1？
答：把被拒的 41~49（9 个值）再乘 7 拼成 63 个候选继续用，即 `(x-40-1)*7 + rand7()` 复用残值，期望降到约 2.19 次。
