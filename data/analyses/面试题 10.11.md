## 一句话思路
排序后从下标 1 起两两交换，让每对 (小,大) 变成 (大,小)，天然满足峰谷交替。

## 怎么做
1. 先 `nums.sort()`，得到非递减序列，此时任意相邻都满足 `nums[i] <= nums[i+1]`。
2. 从 `i = 1` 开始，步长 2，交换 `nums[i]` 与 `nums[i+1]`，即把每对相邻元素翻成「大在前、小在后」。
3. 交换后 `nums[i]` 是峰（≥ 左右），`nums[i+1]` 是谷（≤ 左右），交替成立。

用官方示例 `[5, 3, 1, 2, 3]`：排序后是 `[1, 2, 3, 3, 5]`。`i=1` 交换 `nums[1]=2` 与 `nums[2]=3`，得 `[1, 3, 2, 3, 5]`；`i=3` 交换 `nums[3]=3` 与 `nums[4]=5`，得 `[1, 3, 2, 5, 3]`。检查：`3>=1 and 3>=2` 是峰，`2<=3 and 2<=5` 是谷，`5>=2 and 5>=3` 是峰，`3<=5` 是谷，交替成立。

```python
nums.sort()
for i in range(1, len(nums) - 1, 2):
    nums[i], nums[i + 1] = nums[i + 1], nums[i]
```

关键点：交换后 `nums[i]` 一定 ≥ `nums[i-1]`，因为排序后 `nums[i] >= nums[i-1]`，交换只让 `nums[i]` 变大；而 `nums[i+1]` 交换后变小，仍 ≥ `nums[i+2]` 吗？不需要——`nums[i+1]` 只需 ≤ `nums[i]` 和 `nums[i+2]`，排序保证 `nums[i+1] <= nums[i+2]`，交换后更小，依然成立。

## 复杂度
时间：排序 O(n log n) 主导，交换 O(n)。
空间：排序栈 O(log n)，原地交换无额外数组。

## 易错点
- 循环写成 `range(1, len(nums), 2)` 且不判 `i+1` 越界 → 奇数长度数组在最后一个下标 `i = len-1` 时 `nums[i+1]` 抛 IndexError → 上界写 `len(nums) - 1`，或循环内加 `if i + 1 < len(nums)`。
- 以为要严格大于/小于，对 `[1, 1, 2]` 排序后交换得 `[1, 2, 1]`，担心 `1` 与 `1` 相等不合法 → 题面是「大于或等于」「小于或等于」，相等合法，不要额外去重或特判。

## 如果面试官追问
问：不排序、O(n) 时间能做吗？
答：可以，遍历时若 `i` 为奇数且 `nums[i] < nums[i-1]` 就交换，偶数且 `nums[i] > nums[i-1]` 就交换，一趟扫描即可。
