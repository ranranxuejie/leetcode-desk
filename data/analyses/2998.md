## 一句话思路
从 x 出发做 BFS，状态是当前数值，边是四种操作，第一次碰到 y 即为最少步数。

## 怎么做
1. 用 `deque` 存 `(当前值, 步数)`，`visited` 集合防重复入队。
2. 每层弹出 `cur`，若 `cur == y` 直接返回步数。
3. 生成邻居：`cur-1`、`cur+1`，以及 `cur % 11 == 0` 时的 `cur // 11`、`cur % 5 == 0` 时的 `cur // 5`。
4. 邻居需满足 `1 <= nxt <= 2*x`（上界见易错点），未访问过才入队。

以 `x=26, y=1` 为例：第 0 层 `{26}`；第 1 层由 26 生成 `25`（减 1）；第 2 层 25 是 5 的倍数，生成 `5`；第 3 层 5 生成 `1`，命中，返回 3。关键中间值是 `26 → 25 → 5 → 1`，注意 26 本身不是 5 的倍数，必须先减 1 才能触发除法。

```python
from collections import deque

def bfs(x, y):
    if x == y:
        return 0
    seen = {x}
    q = deque([(x, 0)])
    while q:
        cur, d = q.popleft()
        nxts = [cur - 1, cur + 1]
        if cur % 11 == 0:
            nxts.append(cur // 11)
        if cur % 5 == 0:
            nxts.append(cur // 5)
        for n in nxts:
            if n == y:
                return d + 1
            if 1 <= n <= 2 * x and n not in seen:
                seen.add(n)
                q.append((n, d + 1))
```

## 复杂度
时间：O(x) 个状态，每个状态常数条边，BFS 总 O(x)。
空间：`seen` 与队列各 O(x)，无其他额外结构。

## 易错点
- 上界只写 `n <= x` → 对 `x=54, y=2` 会漏掉 `54+1=55` 这条路径（55 除以 11 得 5，再减到 2 附近），答案偏大。正确做法是放宽到 `2*x`，因为加 1 后再除最多把值拉回 x 量级，超过 2x 的中间值不可能更优。
- 忘记 `x == y` 的提前返回 → 对 `x=5, y=5` 会先入队再绕一圈，虽然结果可能仍是 0 但逻辑上多判一次；更隐蔽的是把 `cur-1` 生成 0 后继续扩展，0 不是正整数，会污染状态空间。正确做法是入队前统一卡 `1 <= n`。

## 如果面试官追问
问：x 上限提到 10^9 怎么办？
答：BFS 状态爆炸，改用记忆化 DFS，只递归 `cur//11`、`cur//5` 及其 ±1 邻域，深度 O(log x)。
