## 一句话思路
对 'T' 和 'F' 各跑一次「最多改 k 个异类」的滑动窗口，取两次窗口最大值中的较大者。

## 怎么做
1. 把问题拆成两个子问题：窗口内全变 'T'（异类是 'F'）和全变 'F'（异类是 'T'），各自求最长合法窗口。
2. 固定异类字符 `bad`，用 `left`、`right` 双指针维护窗口，`cnt` 记录窗口内 `bad` 的个数。
3. `right` 每右移一格就更新 `cnt`；当 `cnt > k` 时不断右移 `left` 并同步减 `cnt`，直到窗口重新合法。
4. 每次窗口合法后用 `right - left + 1` 更新答案。

以 `answerKey = "TTFTTFTT", k = 1` 跑 `bad = 'F'`：`right` 走到下标 4 时窗口 `[0,4]` 是 `TTFTT`，`cnt = 1` 合法，长度 5；`right` 到 5 时 `cnt = 2 > k`，`left` 右移到 1，窗口 `[1,5]` 为 `TFTTF`，`cnt` 仍为 2，继续移到 2 才降到 1，长度 4。最终该轮答案 5，与示例一致。

```python
def maxConsecutiveAnswers(answerKey, k):
    def longest(bad):
        left = cnt = best = 0
        for right, ch in enumerate(answerKey):
            if ch == bad:
                cnt += 1
            while cnt > k:
                if answerKey[left] == bad:
                    cnt -= 1
                left += 1
            best = max(best, right - left + 1)
        return best
    return max(longest('F'), longest('T'))
```

## 复杂度
时间 O(n)：两轮滑动窗口，每轮 `left`、`right` 各最多走 n 步。
空间 O(1)：只开了 `left`、`cnt`、`best` 几个标量，没有额外数组。

## 易错点
- `answerKey = "TTFF", k = 2` 若只跑 `bad = 'F'` 得 4 就返回，会漏掉 `bad = 'T'` 那轮；必须两次取 max，因为最优连续段可能全是 'F'。
- `answerKey = "TFFT", k = 1` 若把 `while cnt > k` 写成 `if`，窗口收缩不彻底，`cnt` 会残留大于 k，长度被高估成 4；必须用 `while` 一直缩到 `cnt <= k`。

## 如果面试官追问
问：要求返回具体改哪几个位置怎么办？
答：在窗口更新 `best` 时记下 `left`、`right`，最后扫该区间，把等于 `bad` 的下标收集起来即为改动位置。
