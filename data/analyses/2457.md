## 一句话思路
从低位向高位逐位「进位抹零」，每次把当前位及以下清零、高位加一，取第一个数位和 ≤ target 的增量。

## 怎么做
1. 先算 `n` 的数位和 `s`，若 `s <= target` 直接返回 0。
2. 令 `p = 1`（当前处理到的位权），循环：取 `low = n % (p * 10)`，增量 `add = p * 10 - low`，候选值 `m = n + add`。
3. 算 `m` 的数位和，若 ≤ target 就返回 `add`；否则 `p *= 10` 继续向高位进位。
4. 循环必然终止：`p` 涨到超过 `n` 时 `m` 形如 `1` 后跟全 0，数位和为 1 ≤ target。

以 `n = 467, target = 6` 为例：`s = 17`。`p = 1` 时 `low = 7`，`add = 10 - 7 = 3`，`m = 470`，数位和 11 > 6；`p = 10` 时 `low = 67`，`add = 100 - 67 = 33`，`m = 500`，数位和 5 ≤ 6，返回 33。关键中间值是 `p = 10` 那一步的 `low = 67`——它决定了抹掉的是十位和个位两位。

```python
def digit_sum(x):
    s = 0
    while x:
        s += x % 10
        x //= 10
    return s

p = 1
while True:
    low = n % (p * 10)
    add = p * 10 - low
    if digit_sum(n + add) <= target:
        return add
    p *= 10
```

## 复杂度
时间：O(log²n)，外层最多 log n 次进位，每次数位和 O(log n)。
空间：O(1)，只用了 `p`、`low`、`add` 几个整数。

## 易错点
- `n = 999, target = 1`：若只抹当前一位（`add = 10 - 9 = 1` 得 1000 之外的中间值）会漏掉跨多位进位，正确做法是用 `n % (p * 10)` 一次抹掉当前位及以下所有低位，得到 1000、增量 1。
- `n = 10**12, target = 1`：若把 `p * 10` 或 `n + add` 当成 32 位处理会截断出错，Python 整数本身不溢出，但若题目规定答案按 32 位截断需自行取模，本题答案最大约 9×10^12，直接返回即可。

## 如果面试官追问
问：如果要求返回所有可行的最小增量方案（多个并列）怎么办？
答：同一 `p` 下 `add` 唯一，并列只可能出现在不同 `p` 得到相同增量，收集全部候选再取最小即可。
