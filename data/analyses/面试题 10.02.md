## 一句话思路
用「排序后的字符串」当哈希键，变位词排序后必然相同，一次遍历即可分组。

## 怎么做
1. 建一个 `dict`，键是排序后的字符串，值是该组原串列表。
2. 遍历 `strs`，对每个 `s` 算 `key = ''.join(sorted(s))`。
3. 用 `groups.setdefault(key, []).append(s)` 一次完成「取或建 + 追加」。
4. 返回 `list(groups.values())`，顺序无所谓。

以官方示例走一遍关键中间值：`"eat"` 排序得 `"aet"`，`"tea"` 排序也是 `"aet"`，`"ate"` 同样 `"aet"`，三者落进同一桶；`"tan"`、`"nat"` 都得 `"ant"`，进第二桶；`"bat"` 得 `"abt"`，单独一桶。最终 `groups` 是 `{"aet": ["eat","tea","ate"], "ant": ["tan","nat"], "abt": ["bat"]}`。

```python
groups = {}
for s in strs:
    key = ''.join(sorted(s))
    groups.setdefault(key, []).append(s)
return list(groups.values())
```

注意 `sorted(s)` 返回的是字符列表，必须 `''.join(...)` 才能当字典键；直接拿列表做键会抛 `TypeError: unhashable type: 'list'`。

## 复杂度
时间 O(n·k log k)：n 为字符串个数，k 为单个串最大长度，每个串排序花 k log k。
空间 O(n·k)：哈希表存下全部字符，另加 n 个键。

## 易错点
- 输入含空串 `""` → 若用 `s[0]` 或 `sorted(s)[0]` 取首字符当键会 `IndexError` → 本题用整串排序做键，空串键为 `""`，天然安全，别自作聪明改成首字母。
- 输入 `["", ""]` 或 `["abc","abc"]` → 若用 `groups[key] = [s]` 赋值而非 `append`，重复串会互相覆盖只剩一个 → 必须用 `setdefault(...).append(s)` 或 `defaultdict(list)`。

## 如果面试官追问
追问：若字符集扩到 Unicode、串很长，排序太贵怎么办？
答：改用「26 个字母计数拼成元组」当键，O(n·k) 时间，代价是键变长。
