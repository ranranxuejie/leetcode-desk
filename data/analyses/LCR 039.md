## 一句话思路
用单调递增栈存下标，弹栈时以被弹柱高为矩形高、左右第一个更矮柱为界算宽度。

## 怎么做
1. 栈 `st` 存下标，保证 `heights[st]` 从栈底到栈顶严格递增；末尾补一个高度 0 的哨兵，逼所有柱子出栈。
2. 遍历到 `i` 时，只要 `heights[st[-1]] > heights[i]` 就弹栈，弹出下标 `j` 后立刻结算。
3. 结算：高 `h = heights[j]`，左界是弹栈后的新栈顶 `st[-1]`，右界是 `i`，宽 `w = i - st[-1] - 1`，面积 `h * w`。
4. 用 `max` 更新答案，再把 `i` 压栈。

以 `heights = [2,1,5,6,2,3]` 为例，走到 `i = 4`（值 2）时，栈是 `[1,2,3]`（对应高度 1,5,6）。先弹 `j = 3`：`h = 6`，新栈顶 `st[-1] = 2`，`w = 4 - 2 - 1 = 1`，面积 6。再弹 `j = 2`：`h = 5`，新栈顶 `st[-1] = 1`，`w = 4 - 1 - 1 = 2`，面积 10，这就是最终答案。

```python
st = []
ans = 0
for i in range(len(heights) + 1):
    cur = heights[i] if i < len(heights) else 0
    while st and heights[st[-1]] > cur:
        j = st.pop()
        left = st[-1] if st else -1
        ans = max(ans, heights[j] * (i - left - 1))
    st.append(i)
```

关键点：`left` 取 `-1` 而不是 0，因为宽度公式是 `i - left - 1`，栈空时左界在 `-1`，宽度正好是 `i`。

## 复杂度
时间 O(n)：每个下标最多入栈一次、出栈一次，`i` 走 n+1 步。
空间 O(n)：`st` 最坏存 n 个下标（高度严格递增时），无其他额外数组。

## 易错点
- `heights = [2,4]` 这类严格递增输入 → 不补哨兵则循环结束栈里还剩 `[0,1]`，只结算到高度 4 宽 1 的面积 4，漏掉高度 2 宽 2 的面积 4 之外的正确值 → 必须补 `cur = 0` 的哨兵，让栈清空。
- `heights = [0,0]` 或含 0 的输入 → 用 `>=` 弹栈会把等高的柱子提前结算，宽度算窄（如 `[2,2]` 得 2 而非 4）→ 弹栈条件写严格大于 `>`，等高柱保留在栈里共享宽度。

## 如果面试官追问
问：要输出最大矩形的左右下标而不只是面积？答：结算时记下 `(left+1, i-1)` 和 `h`，`ans` 更新时同步存这三个值即可。
