## 一句话思路
用 `bits` 数组存真实位、`flipped` 布尔标记是否整体翻转，`ones` 计数，让 flip 变成 O(1)。

## 怎么做
1. 构造时 `bits = [0]*size`、`flipped = False`、`ones = 0`。
2. `fix(idx)`：若 `bits[idx] != flipped` 说明该位已是 1，直接返回；否则 `bits[idx] = flipped` 并 `ones += 1`。
3. `unfix(idx)` 对称：若 `bits[idx] == flipped` 说明已是 0，返回；否则改回并 `ones -= 1`。
4. `flip()` 只做 `flipped = not flipped` 和 `ones = size - ones`；`all()` 判 `ones == size`，`one()` 判 `ones > 0`，`count()` 返回 `ones`。

以官方示例为例：`fix(3)` 后 `bits=[0,0,0,1,0]`、`ones=1`；`fix(1)` 后 `ones=2`；`flip()` 后 `flipped=True`、`ones=3`，此时 `all()` 得 `3==5` 为 `False`，与输出一致。`toString` 时逐位取 `bits[i] ^ flipped`。

```python
def fix(self, idx):
    if self.bits[idx] != self.flipped:
        return
    self.bits[idx] = self.flipped
    self.ones += 1

def flip(self):
    self.flipped = not self.flipped
    self.ones = self.size - self.ones

def toString(self):
    f = self.flipped
    return ''.join('1' if b ^ f else '0' for b in self.bits)
```

## 复杂度
时间：fix/unfix/flip/all/one/count 均 O(1)，toString 为 O(n)，n 是 size。
空间：O(n) 存 `bits` 数组，`flipped`、`ones` 为 O(1)。

## 易错点
1. `fix` 时若写成 `if bits[idx] == 1: return`，在 `flipped=True` 后（如示例 flip 后 `bits=[0,0,0,1,0]`）会把逻辑位 1 误判成 0，导致 `ones` 多加。正确做法是比较 `bits[idx] != flipped`。
2. `flip` 后忘记同步 `ones = size - ones`，示例中 flip 后 `ones` 仍是 2 而非 3，`all()`、`count()` 全错。正确做法是翻转标记与计数在同一函数内一起更新。

## 如果面试官追问
若 size 升到 10^9 但操作仍 10^5 次？答：改用哈希表只存被 fix 过的下标，flip 时用 `ones` 与 `size` 推导，toString 才按需展开。
