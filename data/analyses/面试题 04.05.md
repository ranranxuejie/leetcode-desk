## 一句话思路
用上下界 DFS：每个节点必须落在 `(low, high)` 开区间内，递归时把当前值收窄成子节点的界。

## 怎么做
1. 从 `dfs(root, -inf, inf)` 开始，`low`/`high` 是当前子树允许的开区间端点。
2. 空节点返回 `True`；`node.val <= low or node.val >= high` 直接返回 `False`。
3. 左子树界变 `(low, node.val)`，右子树界变 `(node.val, high)`，两者都真才真。

拿示例 2 的 `[5,1,4,null,null,3,6]` 走一遍：根 `5` 界 `(-inf, inf)` 通过；进右子树 `4` 时界收窄为 `(5, inf)`，`4 <= 5` 立刻判 `False`——注意此时 `4` 的左右孩子 `3`、`6` 根本没被访问，错误在 `4` 这一层就暴露了。这正是只比较父子会漏掉的地方：`4` 比父节点 `5` 小，但它在右子树里就必须大于 `5`。

```python
def dfs(node, low, high):
    if node is None:
        return True
    if node.val <= low or node.val >= high:
        return False
    return (dfs(node.left, low, node.val) and
            dfs(node.right, node.val, high))

return dfs(root, float('-inf'), float('inf'))
```

用 `float('-inf')`/`float('inf')` 而不是 `2**31 - 1` 当初始界，是因为节点值可能正好等于 `2**31 - 1`，用有限值当哨兵会把合法节点误判成越界。

## 复杂度
时间 O(n)：每个节点恰好被 `dfs` 访问一次。
空间 O(h)：递归栈深度等于树高，最坏链状树 O(n)，平衡树 O(log n)。

## 易错点
- 输入 `[5,1,4,null,null,3,6]` → 只写 `node.left.val < node.val < node.right.val` 的父子比较会返回 `True`，因为 `4` 确实小于 `5` 且 `3 < 4 < 6` → 必须带上下界，让 `4` 在界 `(5, inf)` 处被拦下。
- 输入含重复值如 `[2,2,2]` → 用 `<=`/`>=` 写成 `<`/`>` 会返回 `True` → 二叉搜索树要求严格有序，判据必须是 `node.val <= low or node.val >= high` 才算越界。

## 如果面试官追问
问：节点值范围是 `[-2**31, 2**31 - 1]`，初始界还能用 `inf` 吗？
答：能，Python 整数无溢出，`inf` 只作哨兵不参与运算；若换 C++ 则需用 `long long` 或改用「记录前驱」的中序写法。
