## 一句话思路
逐位贪心：小时位优先取最大合法值，分钟位同理，因为高位决定时间大小。

## 怎么做
1. 先处理小时十位 `time[0]`：若为 `?`，看 `time[1]` 是否 ≤3，是则填 `2`，否则填 `1`。
2. 再处理小时个位 `time[1]`：若为 `?`，看 `time[0]` 是否等于 `2`，是则填 `3`，否则填 `9`。
3. 分钟十位 `time[3]` 为 `?` 时直接填 `5`，分钟个位 `time[4]` 为 `?` 时直接填 `9`。
4. 返回拼接后的字符串。

以 `"2?:?0"` 为例：`time[0]='2'` 已定，`time[1]='?'` 且 `time[0]=='2'`，故填 `3`，小时得 `23`；`time[3]='?'` 填 `5`，`time[4]='0'` 保留，分钟得 `50`，结果 `"23:50"`。

```python
def maximumTime(time: str) -> str:
    t = list(time)
    if t[0] == '?':
        t[0] = '2' if t[1] == '?' or t[1] <= '3' else '1'
    if t[1] == '?':
        t[1] = '3' if t[0] == '2' else '9'
    if t[3] == '?':
        t[3] = '5'
    if t[4] == '?':
        t[4] = '9'
    return ''.join(t)
```

关键在 `t[0]` 的判断：`t[1]` 为 `?` 时也填 `2`，因为后面 `t[1]` 会按 `t[0]=='2'` 填 `3`，得到 `23`，比 `19` 大。

## 复杂度
时间：O(1)，只扫固定 5 个字符。
空间：O(1)，额外开一个长度 5 的列表 `t`。

## 易错点
- 输入 `"?3:00"` → 若小时十位无脑填 `2`，得 `23:00` 看似合法，但 `t[1]='3'` 时 `23` 合法没问题；真正的坑是 `"?4:00"`，填 `2` 会得 `24:00` 非法，正确做法是 `t[1] > '3'` 时 `t[0]` 填 `1`，得 `14:00`。
- 输入 `"??:00"` → 若先填 `t[1]='9'` 再填 `t[0]`，会得 `19:00`；正确顺序是先定 `t[0]='2'`（因 `t[1]=='?'`），再让 `t[1]` 按 `t[0]=='2'` 填 `3`，得 `23:00`。

## 如果面试官追问
问：若隐藏位可任意多个、格式不固定怎么办？
答：退化为按位枚举 0-9 取最大合法组合，用合法性校验函数兜底，复杂度仍是常数级。
