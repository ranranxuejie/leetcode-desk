## 一句话思路
逐个数取模 10 剥位，剥出的每一位与 `digit` 比较并累加，因为每个数最多 7 位，直接枚举所有位即可。

## 怎么做
1. 初始化 `ans = 0`，外层遍历 `nums` 中每个 `x`。
2. 内层用 `while x:` 循环，`x % 10` 取出最低位，与 `digit` 相等则 `ans += 1`。
3. 每轮末尾 `x //= 10` 丢掉最低位，直到 `x` 变成 0。
4. 返回 `ans`。

以 `nums = [12,54,32,22], digit = 2` 为例：处理 `12` 时，第一轮 `x % 10 = 2` 命中，`ans` 变 1，`x` 变 1；第二轮 `1 % 10 = 1` 不命中，`x` 变 0 退出。处理 `22` 时两轮都命中，`ans` 从 2 累到 4，最终返回 4。

```python
ans = 0
for x in nums:
    while x:
        if x % 10 == digit:
            ans += 1
        x //= 10
return ans
```

注意 `x //= 10` 必须写在 `if` 外面，否则命中时 `x` 不变会死循环。另外这里直接改循环变量 `x`，不影响 `nums` 本身，因为 `for x in nums` 每次取的是元素副本。

## 复杂度
时间：O(n · log₁₀M)，n 是 `nums` 长度，log 来自每个数最多 7 位（`nums[i] ≤ 10^6`）。
空间：O(1)，只用了 `ans` 和循环变量 `x`，没有额外数组。

## 易错点
- `digit = 0` 且 `nums` 里有 `10`、`100` 这类数 → 若把循环条件写成 `while x > 9` 会漏掉最高位或末尾的 0，比如 `10` 只数到 1 位 → 正确做法是 `while x:`，让 `10` 剥出 `0` 再剥出 `1`，两轮都参与比较。
- 把 `x //= 10` 写进 `if` 分支内 → 命中时 `x` 不变，`while x:` 永远为真，`[22]` 这种输入直接死循环 → 正确做法是缩进到 `if` 同级，保证每轮必减一位。

## 如果面试官追问
问：如果 `nums[i]` 上限提到 `10^18` 呢？
答：方法不变，只是每个数多剥几位，时间仍是 O(n · 位数)，Python 整数无溢出问题。
