## 一句话思路
把 `nums` 转成集合，遍历其中每个正数 `x`，检查 `-x` 是否也在集合里，取满足条件的最大 `x`。

## 怎么做
1. 用 `set(nums)` 建哈希集合 `s`，把「是否存在 -x」的查找从 O(n) 降到 O(1)。
2. 遍历 `s` 中的元素，只保留 `x > 0 and -x in s` 的候选。
3. 用 `max(..., default=-1)` 一次拿到最大值，空候选时自动返回 -1。

以示例 2 `nums = [-1,10,6,7,-7,1]` 为例：`s = {-1,10,6,7,-7,1}`。遍历到 `x = 7` 时 `-7 in s` 为 `True`，候选集为 `{1, 7}`，`max` 得 `7`；而 `10`、`6` 的相反数不在集合里，被过滤掉。

```python
s = set(nums)
ans = -1
for x in s:
    if x > 0 and -x in s:
        ans = max(ans, x)
return ans
```

等价的一行写法（面试可口头提）：`return max((x for x in s if x > 0 and -x in s), default=-1)`。

注意 `x > 0` 这个条件不能省：若只判 `-x in s`，负数 `-7` 也会命中（因为 `7 in s`），虽然取 max 后结果不变，但语义上是在找「正整数 k」，显式过滤更稳。

## 复杂度
时间：O(n)，建集合 O(n)，遍历集合 O(n)，每次 `in` 是 O(1)。
空间：O(n)，额外开了一个大小至多 n 的集合 `s`。

## 易错点
- 输入 `nums = [-1,2,-3,3]` → 若只写 `if -x in s` 不过滤正负，`-1`、`-3` 也进候选，虽然 `max` 仍得 3，但一旦改成「返回所有 k」就会混入负数 → 正确做法是条件写成 `x > 0 and -x in s`。
- 输入 `nums = [-10,8,6,7,-2,-3]`（示例 3）→ 若初始化 `ans = 0` 而不是 `-1`，无解时返回 0，与题目要求的 -1 不符 → 正确做法是 `ans = -1` 或 `max(..., default=-1)`。

## 如果面试官追问
问：若 `nums` 长度升到 10^7、内存吃紧，怎么改？答：先 `nums.sort()`，再用左右双指针从两端向中间夹，空间降到 O(1)，时间 O(n log n)。
