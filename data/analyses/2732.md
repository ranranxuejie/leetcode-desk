## 一句话思路
n≤5 所以每行压成 5 位掩码，好子集大小最多 2（鸽巢），只需查单行全 0 或两行按位与为 0。

## 怎么做
1. 把每行压成整数 `mask`，`mask |= grid[i][j] << j`，同时记录 `pos[mask] = i`（同掩码只留首个下标）。
2. 先扫一遍：若存在 `mask == 0`，直接返回 `[pos[0]]`（k=1 时每列和必须为 0）。
3. 否则枚举掩码对 `(a, b)`，`a & b == 0` 即两行没有同一列同时为 1，返回 `[pos[a], pos[b]]` 并升序。
4. 都不满足返回 `[]`。

为什么最多 2 行：k≥3 时每列和 ≤ floor(k/2) < k，若某列全 1 就爆；而 n≤5 时 3 行两两… 关键是 k=3 要求每列和 ≤1，等价于三行两两按位与为 0，此时任取其中两行也满足 k=2 的条件，所以只需找 2 行。

以示例 1 为例：三行掩码分别是 `0b0110=6`、`0b1000=8`、`0b1111=15`。`6 & 8 = 0`，命中，返回 `[0,1]`。注意 `pos` 里 `6→0`、`8→1`，输出前排序。

```python
pos = {}
for i, row in enumerate(grid):
    mask = 0
    for j, v in enumerate(row):
        mask |= v << j
    if mask == 0:
        return [i]
    pos.setdefault(mask, i)

keys = list(pos)
for x in range(len(keys)):
    for y in range(x + 1, len(keys)):
        if keys[x] & keys[y] == 0:
            return sorted([pos[keys[x]], pos[keys[y]]])
return []
```

## 复杂度
时间：O(m·n + 4^n)，m·n 建掩码，4^n 是掩码对枚举（n≤5 时 ≤1024）。
空间：O(2^n) 存 `pos`，最多 32 个键。

## 易错点
- 输入 `[[0]]`：只写两行枚举会漏掉 k=1 的解，返回 `[]` 而非 `[0]`。正确做法是建掩码时先判 `mask == 0` 立即返回。
- 输入 `[[1,1,1],[1,1,1]]`：两行掩码都是 `0b111=7`，`7 & 7 = 7 ≠ 0`，若用 `setdefault` 后误以为同掩码可配对会错判。正确做法是掩码对必须取不同键，且 `a & b == 0` 严格成立。
- 返回下标要升序：`pos[8]=1`、`pos[6]=0` 时枚举顺序可能先遇到 `8`，直接返回 `[1,0]` 会判错，必须 `sorted`。

## 如果面试官追问
若 n 放大到 20 怎么办？答：鸽巢结论仍成立（好子集大小 ≤2），但 2^n 枚举不可行，改用按列和剪枝或随机化找互补掩码。
