## 一句话思路
双指针从两端向中间模拟，`i < j` 时两人各浇各的，`i == j` 时比较剩余水量决定谁浇。

## 怎么做
1. 初始化 `i = 0`、`j = n - 1`、`a = capacityA`、`b = capacityB`、`ans = 0`。
2. 当 `i < j`：Alice 若 `a < plants[i]` 则 `ans += 1`、`a = capacityA`，然后 `a -= plants[i]`、`i += 1`；Bob 对称处理 `j`。
3. 循环结束后若 `i == j`，剩一株植物：`max(a, b) < plants[i]` 时 `ans += 1`（相等时 Alice 浇，但两人都不够才需要重装，故用 `<` 而非 `<=`）。

以示例 2 `plants = [2,2,3,3], capacityA = 3, capacityB = 4` 为例：第一轮后 `a = 1, b = 1, i = 1, j = 2`；第二轮 `a < plants[1] = 2` 触发重装，`ans` 变 1、`a` 重置为 3 再减 2 得 1；Bob 同理 `b < plants[2] = 3` 触发重装，`ans` 变 2。

```python
i, j = 0, len(plants) - 1
a, b, ans = capacityA, capacityB, 0
while i < j:
    if a < plants[i]:
        ans += 1
        a = capacityA
    a -= plants[i]; i += 1
    if b < plants[j]:
        ans += 1
        b = capacityB
    b -= plants[j]; j -= 1
if i == j and max(a, b) < plants[i]:
    ans += 1
```

## 复杂度
时间：O(n)，双指针各走一半，每株植物只被访问一次。
空间：O(1)，只开了 `i, j, a, b, ans` 五个变量。

## 易错点
- 奇数长度如 `plants = [5], capacityA = 10, capacityB = 8`：若在 `while i < j` 里处理会漏掉中间那株，或在 `i == j` 时误用 `a < plants[i]` 判断（Alice 水够但 Bob 更多时该 Bob 浇，重装次数仍为 0）。正确做法是单独用 `max(a, b) < plants[i]` 判断。
- 重装判断必须用 `<` 而非 `<=`：`a == plants[i]` 时水刚好够，不该重装。例如 `plants = [3], capacityA = 3`，用 `<=` 会多算 1 次。

## 如果面试官追问
若要求输出每株植物由谁浇、重装发生在哪一步？答：在每次 `ans += 1` 处记录 `(i, 'A')` 或 `(j, 'B')`，中间那株按 `a >= b` 归 Alice，其余逻辑不变。
