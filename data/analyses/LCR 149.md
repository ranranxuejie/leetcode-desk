## 一句话思路
用队列做 BFS，每轮先记下队列长度 `size`，只弹出这 `size` 个节点，就能保证同一层的值连续输出。

## 怎么做
1. 空树直接返回 `[]`，否则把 `root` 放进 `deque`。
2. 外层 `while q` 每轮开始取 `size = len(q)`，这个值就是当前层的节点数。
3. 内层循环 `size` 次：`popleft` 出一个节点，把它的值追加到 `level`，再把非空左右孩子入队。
4. 内层结束后把 `level` 整体 `extend` 到结果里。

以 `root = [8,17,21,18,null,null,6]` 为例：第一轮 `size=1`，弹出 8，入队 17、21，`level=[8]`；第二轮 `size=2`，弹出 17 入队 18，弹出 21 入队 6，`level=[17,21]`；第三轮 `size=2`，弹出 18、6，`level=[18,6]`。最终 `[8,17,21,18,6]`。

```python
from collections import deque

q = deque([root]) if root else deque()
res = []
while q:
    size = len(q)
    level = []
    for _ in range(size):
        node = q.popleft()
        level.append(node.val)
        if node.left:
            q.append(node.left)
        if node.right:
            q.append(node.right)
    res.extend(level)
```

关键在 `size` 必须在入队孩子**之前**取定，否则新入队的下一层节点会被算进本层。

## 复杂度
时间 O(n)：每个节点入队出队各一次，n 为节点总数。
空间 O(w)：队列最多存一层节点，w 为最大层宽，最坏 O(n)。

## 易错点
- 用 `while q` 但不锁 `size`，直接 `for node in q` 边遍历边入队 → 会把下一层节点混进本层，示例 1 会输出成 `[8,17,21,18,6]` 之外的乱序（如把 18 和 6 提前）→ 正确做法是先 `size = len(q)` 再循环固定次数。
- 空树 `root = []` 时直接 `deque([root])` → 队列里塞了个 `None`，`node.val` 抛 `AttributeError` → 正确做法是 `deque([root]) if root else deque()`，或先判空返回 `[]`。

## 如果面试官追问
问：要求按层从右到左输出怎么办？
答：内层改成 `appendleft` 收集，或每层 `level.reverse()` 后再 `extend`，BFS 骨架不变。
