## 一句话思路
两棵树结构完全一致，同步 DFS 遍历 original 和 cloned，original 走到 target 时 cloned 的对应位置就是答案。

## 怎么做
1. 写一个 `dfs(o, c)`，参数是两棵树上位置对应的节点，返回 cloned 中的目标节点或 `None`。
2. 先判 `o is target`，是就直接返回 `c`，不必再往下走。
3. 否则递归左子树，非 `None` 就返回；再递归右子树，同样非 `None` 就返回。
4. 两边都空返回 `None`。

以示例 1 的 `tree = [7,4,3,null,null,6,19]`、`target = 3` 为例：根处 `o=7` 不等于 `target`，进左子树 `o=4` 仍不等，`4` 的左右都是 `None` 返回 `None`；回到根进右子树，此时 `o=3` 命中，直接返回 `c=3`（cloned 中值为 3 的那个节点引用），不再访问 `6` 和 `19`。

```python
def dfs(o, c):
    if o is None:
        return None
    if o is target:
        return c
    return dfs(o.left, c.left) or dfs(o.right, c.right)

return dfs(tree, cloned)
```

关键在 `o is target` 用**引用相等**而不是 `o.val == target.val`：题目保证同一棵树没有重复值，但用 `is` 连这个前提都不需要，进阶版直接成立。`or` 的短路也省掉了显式判空。

## 复杂度
时间 O(n)，最坏要走到 target 之前的全部节点，n 为树节点数。
空间 O(h)，递归栈深度等于树高 h，最坏链状树 O(n)。

## 易错点
- 输入 `tree = [7]`、`target = 7`：若把命中判断写在递归子调用之后（先递归再比较），根节点没有子节点会先返回 `None`，答案丢失。正确做法是把 `o is target` 放在函数最前面，命中即返回。
- 输入示例 3 那条右斜链 `[8,null,6,null,5,null,4,...]`、`target = 4`：若只写 `dfs(o.left, c.left)` 忘了右子树，或写成 `dfs(o.left, c.right)` 左右错位，会返回 `None` 或返回 cloned 中错误分支的节点。正确做法是左右子树参数严格同侧配对，且用 `or` 串起来保证右子树也会被搜。

## 如果面试官追问
问：树中允许重复值怎么办？
答：代码不用改，`o is target` 比的是节点引用，重复值不影响定位，只有改成 `o.val == target.val` 才会错。
