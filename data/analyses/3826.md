## 一句话思路
用 DP + 凸包/斜率优化（或分治优化）求恰好 k 段的最小代价，代价函数 sum*(sum+1)/2 满足四边形不等式，可用分治优化降到 O(kn log n)。

## 怎么做
1. 前缀和 `pre[i]`，代价 `w(l,r) = s*(s+1)//2`，其中 `s = pre[r]-pre[l-1]`。
2. 定义 `dp[t][i]` = 前 i 个元素分 t 段的最小分数，转移 `dp[t][i] = min_{j<i} dp[t-1][j] + w(j+1,i)`。
3. 代价函数满足四边形不等式（凸），用分治优化：对每层 t，递归 `solve(l,r,optl,optr)`，取中点 mid，在 `[optl, min(optr,mid-1)]` 枚举最优 j，再递归左右。
4. 以 `nums=[5,1,2,1], k=2` 为例：`pre=[0,5,6,8,9]`。t=1 时 `dp[1][i]=w(1,i)`，得 `dp[1]=[0,15,21,28,45]`。t=2 求 `dp[2][4]`：枚举 j=1,2,3，`dp[1][j]+w(j+1,4)` 分别得 `15+10=25`、`21+6=27`、`28+3=31`，取 25。

```python
def solve(l, r, optl, optr):
    if l > r: return
    mid = (l + r) // 2
    best, bj = INF, -1
    for j in range(optl, min(optr, mid - 1) + 1):
        s = pre[mid] - pre[j]
        v = prev[j] + s * (s + 1) // 2
        if v < best: best, bj = v, j
    cur[mid] = best
    solve(l, mid - 1, optl, bj)
    solve(mid + 1, r, bj, optr)
```

## 复杂度
时间：O(k · n log n)，每层分治枚举总量 O(n log n)。
空间：O(n)，只存 pre、prev、cur 三个长度 n 的数组。

## 易错点
- `k=1` 时直接返回 `pre[n]*(pre[n]+1)//2`，若仍走分治会因 `optl=0, optr=0` 且 mid-1 边界处理不当返回 INF；正确做法是特判 k==1 或让 j 从 0 开始枚举。
- 分治优化要求代价满足四边形不等式，本题 `s*(s+1)//2` 是凸函数成立；但若把 `nums` 含 0 或负数（题面保证 ≥1）代入，凸性被破坏，分治会漏解，需改回 O(kn²) 暴力。

## 如果面试官追问
问：n 放大到 1e5 怎么办？
答：分治优化 O(kn log n) 仍偏大，改用斜率优化（凸包）把每层降到 O(n)，总 O(kn)。
