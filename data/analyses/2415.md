## 一句话思路
用 DFS 同时从左右两侧对称下探，每到一个奇数层就交换两节点的 val，一次遍历完成整层反转。

## 怎么做
1. 写辅助函数 `dfs(a, b, level)`，`a`、`b` 是同一层上关于中轴对称的两个节点，初始调用 `dfs(root.left, root.right, 1)`。
2. 若 `level` 为奇数，交换 `a.val` 与 `b.val`；偶数层不动。
3. 递归下探时保持对称：`dfs(a.left, b.right, level+1)` 和 `dfs(a.right, b.left, level+1)`。
4. 返回 `root`。

以示例 1 `[2,3,5,8,13,21,34]` 为例：初始 `dfs(3, 5, 1)`，`level=1` 是奇数，交换后 `3.val=5`、`5.val=3`；接着 `dfs(8, 34, 2)` 与 `dfs(13, 21, 2)` 都是偶数层，只递归不交换，最终根为 `[2,5,3,8,13,21,34]`。

```python
def dfs(a, b, level):
    if a is None:
        return
    if level % 2 == 1:
        a.val, b.val = b.val, a.val
    dfs(a.left, b.right, level + 1)
    dfs(a.right, b.left, level + 1)

dfs(root.left, root.right, 1)
return root
```

关键点：交换的是 `a` 与 `b` 的 `val`，不是节点本身；`a.left` 必须配 `b.right`，这样第 3 层 `[1,1,1,1,2,2,2,2]` 才会变成 `[2,2,2,2,1,1,1,1]` 而不是原地不动。

## 复杂度
时间 O(n)：每个节点被访问一次，n 为节点总数。
空间 O(log n)：递归栈深度等于树高，完美二叉树高为 log n。

## 易错点
- 输入 `[7,13,11]` 只有 3 个节点 → 若把 `level` 从 0 起算，根层算 0、第 1 层算 1 时判断写成 `level % 2 == 0` 就会漏掉交换，输出仍是 `[7,13,11]`；正确做法是子节点层从 1 起算，奇数层才交换。
- 输入示例 3 第 3 层 `[1,1,1,1,2,2,2,2]` → 若递归写成 `dfs(a.left, b.left)` 和 `dfs(a.right, b.right)`，同侧配对会得到 `[1,1,1,1,2,2,2,2]` 原样不变；正确做法是交叉配对 `a.left↔b.right`、`a.right↔b.left`。

## 如果面试官追问
问：如果树不是完美二叉树，奇数层节点数不对称怎么办？
答：DFS 对称配对失效，改用 BFS 逐层收集节点值，奇数层整体 `reverse()` 后再按序写回。
