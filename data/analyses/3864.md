## 一句话思路
对每个长度 2^k 的区间做记忆化分治：要么整段按公式算，要么对半拆，取两者较小值。

## 怎么做
1. 用前缀和 `pre[i]` 记录 `s[:i]` 中 `'1'` 的个数，区间 `[l, r)` 的敏感数 `X = pre[r] - pre[l]`。
2. 定义 `cost(l, r)`：`X == 0` 直接返回 `flatCost`；否则先算整段费用 `(r-l) * X * encCost`。
3. 若 `(r-l)` 为偶数，再算 `cost(l, mid) + cost(mid, r)`，返回两者较小值；奇数长度无法拆，直接返回整段费用。
4. 用 `(l, r)` 做记忆化键，避免同一区间被重复计算。

以 `s = "1010", encCost = 2, flatCost = 1` 为例：根区间 `[0,4)`，`X = 2`，整段费用 `4*2*2 = 16`；拆成 `[0,2)` 和 `[2,4)`，各 `X = 1`、费用 `2*1*2 = 4`，合计 8；再各拆成两个长度 1 的段，`'1'` 段费用 `1*1*2 = 2`，`'0'` 段 `X = 0` 返回 `flatCost = 1`，总计 `2+1+2+1 = 6`，根节点取 `min(16, 8, 6) = 6`。

```python
def cost(l, r):
    if (l, r) in memo:
        return memo[l, r]
    x = pre[r] - pre[l]
    if x == 0:
        memo[l, r] = flatCost
        return flatCost
    res = (r - l) * x * encCost
    if (r - l) % 2 == 0:
        mid = (l + r) // 2
        res = min(res, cost(l, mid) + cost(mid, r))
    memo[l, r] = res
    return res
```

## 复杂度
时间：每个长度 2^k 的区间只算一次，共 O(n) 个区间，每个 O(1)，总 O(n)。
空间：`memo` 存 O(n) 个键值对，递归深度 O(log n)，合计 O(n)。

## 易错点
- `s = "00", encCost = 1, flatCost = 2` → 若先算 `(r-l)*X*encCost = 0` 再和拆分比较，会错成 0 → 必须先判 `X == 0` 返回 `flatCost`，不能走乘法分支。
- `s = "1010", encCost = 3, flatCost = 10` → 若只拆一层就返回，会错成 12 但漏掉更深层可能更优的情况（本例恰好 12 最优，但 `flatCost` 小时深层更优）→ 必须递归到底取 `min`，不能只比较整段和一层拆分。

## 如果面试官追问
问：`n` 开到 10^6 还够吗？
答：区间数仍是 O(n)，但递归和字典开销大，可改按长度从小到大迭代填表，或只对含 `'1'` 的区间建树。
