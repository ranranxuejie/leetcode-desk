## 一句话思路
按 `DATE_FORMAT(trans_date,'%Y-%m')` 和 `country` 分组，用 `SUM(CASE WHEN state='approved' THEN ...)` 把批准项从全部项里拆出来。

## 怎么做
1. 先造分组键：`DATE_FORMAT(trans_date,'%Y-%m') AS month`，与 `country` 一起进 `GROUP BY`。
2. 总数用 `COUNT(*)` 和 `SUM(amount)`，直接吃整组。
3. 批准数用 `SUM(state='approved')`，批准金额用 `SUM(CASE WHEN state='approved' THEN amount ELSE 0 END)`。
4. 按 `month, country` 排序输出（题目允许任意序，排序只为对照示例）。

关键中间值：以 2018-12 的 US 组为例，两行 `amount` 是 1000、2000，`state` 是 approved、declined。`SUM(amount)=3000`，`SUM(state='approved')=1`，条件求和只吃 1000，所以 `approved_total_amount=1000`——declined 的 2000 必须被 `ELSE 0` 挡掉，不能让它进分子。

```python
# 伪 SQL 落到 pandas 的等价写法
df["month"] = df["trans_date"].dt.strftime("%Y-%m")
g = df.groupby(["month", "country"])
out = g.agg(
    trans_count=("id", "count"),
    trans_total_amount=("amount", "sum"),
)
out["approved_count"] = g.apply(lambda x: (x["state"] == "approved").sum())
out["approved_total_amount"] = g.apply(
    lambda x: x.loc[x["state"] == "approved", "amount"].sum()
)
```

## 复杂度
时间：O(n)，n 为 `Transactions` 行数，分组哈希扫一遍；排序 O(k log k)，k 为组数。
空间：O(k)，存每个 `(month, country)` 的五个聚合值。

## 易错点
1. 用 `COUNT(state='approved')` 或 `COUNT(amount)` 数批准数 → 2018-12 的 US 会得 2 而不是 1，因为 `COUNT` 只判 NULL 不判真假；正确写法是 `SUM(state='approved')` 或 `SUM(CASE WHEN state='approved' THEN 1 ELSE 0 END)`。
2. 批准金额漏写 `ELSE 0`，写成 `SUM(CASE WHEN state='approved' THEN amount END)` → 该组若有 declined 行会返回 NULL 而非 0，示例里 2018-12 US 恰好有 approved 所以看不出来，但某国某月全是 declined 时 `approved_total_amount` 会变 NULL；正确做法是显式 `ELSE 0`，或外层 `COALESCE(...,0)`。

## 如果面试官追问
问：如果要求只输出有批准交易的月份国家？
答：在 `GROUP BY` 后加 `HAVING SUM(state='approved') > 0`，别用 `WHERE`，否则会把 declined 行提前滤掉、`trans_count` 变小。
