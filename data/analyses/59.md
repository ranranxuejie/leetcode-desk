## 一句话思路
按「右→下→左→上」四方向模拟填数，每走完一圈就把边界内缩一格，直到 1 到 n² 填满。

## 怎么做
1. 建 `n x n` 全零矩阵 `matrix`，设四个边界 `top=0, bottom=n-1, left=0, right=n-1`，计数器 `num=1`。
2. 循环内依次走四条边：先填 `matrix[top][left..right]`，再填 `matrix[top+1..bottom][right]`，再填 `matrix[bottom][right-1..left]`，最后填 `matrix[bottom-1..top+1][left]`。
3. 每走完一条边就收缩对应边界（`top+=1`、`right-=1`、`bottom-=1`、`left+=1`），保证下一圈从内层开始。
4. 当 `num > n*n` 时退出，返回 `matrix`。

以 `n=3` 为例，第一圈填完后 `matrix=[[1,2,3],[8,0,4],[7,6,5]]`，此时 `top=1, bottom=1, left=1, right=1`；第二圈只剩中心格，填 `matrix[1][1]=9`，得到 `[[1,2,3],[8,9,4],[7,6,5]]`。

```python
matrix = [[0] * n for _ in range(n)]
top, bottom, left, right = 0, n - 1, 0, n - 1
num = 1
while num <= n * n:
    for j in range(left, right + 1):
        matrix[top][j] = num; num += 1
    top += 1
    for i in range(top, bottom + 1):
        matrix[i][right] = num; num += 1
    right -= 1
    for j in range(right, left - 1, -1):
        matrix[bottom][j] = num; num += 1
    bottom -= 1
    for i in range(bottom, top - 1, -1):
        matrix[i][left] = num; num += 1
    left += 1
```

## 复杂度
时间：O(n²)，每个格子恰好填一次，共 n² 次赋值。
空间：O(1) 额外空间（不计输出矩阵本身），只用四个边界变量和 `num`。

## 易错点
- `n=1` 时若先执行 `top+=1` 再判断，`top=1 > bottom=0`，后续三条边的 `range` 为空但不会报错；真正翻车的是把四条边写成无条件的 `for` 且用 `matrix[top][j]` 时 `top` 已越界——正确做法是每填完一条边立刻收缩边界，让空 `range` 自然跳过。
- `n` 为奇数（如 `n=3`）时，若循环条件写成 `while top < bottom and left < right`，中心格 `matrix[1][1]` 永远填不到，输出中间是 0；正确做法是用 `while num <= n*n` 控制，保证最后一格也被填。

## 如果面试官追问
问：如果要求逆时针螺旋怎么办？
答：把四条边的顺序改成「下→右→上→左」，或等价地把方向数组改为 `(1,0),(0,1),(-1,0),(0,-1)`，边界收缩逻辑不变。
