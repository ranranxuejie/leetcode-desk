## 一句话思路
先排序把「同子集内极差」变成「首尾下标差」，再用位掩码 DP 枚举每个大小为 n/k 的合法子集。

## 怎么做
1. 排序 `nums`，若某值出现次数 > k 直接返回 -1（鸽巢）。
2. 预处理所有大小为 `m = n // k` 且元素互异的掩码，记其代价为 `nums[最大下标] - nums[最小下标]`。
3. 设 `dp[mask]` 为已用掉 `mask` 中元素的最小总代价，转移时只取「包含 mask 中最低未用位」的合法子集，避免同组排列重复。
4. 以示例 1 `nums=[1,2,1,4], k=2` 为例：排序后 `[1,1,2,4]`，`m=2`；合法子集 `{0,2}` 代价 `2-1=1`、`{1,3}` 代价 `4-1=3`，`dp[1111]=4`。

```python
nums.sort()
n, m = len(nums), len(nums) // k
cost = {}
for mask in range(1 << n):
    if bin(mask).count("1") != m: continue
    idx = [i for i in range(n) if mask >> i & 1]
    if len({nums[i] for i in idx}) == m:
        cost[mask] = nums[idx[-1]] - nums[idx[0]]
INF = 2**31 - 1
dp = [INF] * (1 << n); dp[0] = 0
for mask in range(1 << n):
    if dp[mask] == INF: continue
    low = (~mask) & (mask + 1)          # 最低未用位
    for sub, c in cost.items():
        if sub & low and not (sub & mask):
            dp[mask | sub] = min(dp[mask | sub], dp[mask] + c)
return dp[-1] if dp[-1] < INF else -1
```

## 复杂度
时间：`O(2^n · 合法子集数)`，`n` 来自数组长度，枚举掩码是瓶颈。
空间：`O(2^n)`，`dp` 与 `cost` 各一张表。

## 易错点
- `nums=[5,3,3,6,3,3], k=3`：只判 `n % k` 会漏掉 3 出现 4 次 > k=3，DP 跑完得 INF 才返回 -1，浪费且易写错；应在排序后先统计频次提前返回。
- 转移时不锚定 `low`：`[1,2,1,4]` 会把 `{0,2}` 与 `{1,3}` 的两种加入顺序都算一遍，结果虽对但状态数翻倍；必须要求 `sub & low` 非零。

## 如果面试官追问
若 `n` 到 20 以上怎么办？答：位掩码 DP 是 `2^n`，超限时改用按值分组 + 贪心/匹配思路，或说明该规模下问题本身难解。
