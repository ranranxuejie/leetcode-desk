## 一句话思路
按列做 DP，状态是「本列染到第几行」，用前缀和把相邻两列的得分 O(1) 算出。

## 怎么做
1. 记 `h[j]` 为第 j 列被染黑的行数（0 表示不染，n 表示全染），列内黑色是顶部连续段。
2. 关键观察：格子 (i,j) 得分当且仅当它白色（`i >= h[j]`）且左右某列在该行是黑的（`h[j-1] > i` 或 `h[j+1] > i`）。
3. 于是得分可按列拆成「与左邻列配对」的部分，DP 只需记住前一列的 `h`。
4. 转移时枚举 `h[j-1]=a`、`h[j]=b`，配对贡献为 `sum(grid[i][j] for i in [a, b))`（当 `b > a`，即本列比左列高出的那段白格被左列染黑覆盖），用列前缀和 O(1) 取。

以示例 1 为例，取 `h = [0,4,0,5,0]`：第 1 列 `h=4` 与第 0 列 `h=0` 配对，贡献 `grid[0..3][1]` 中白格被左列覆盖的部分，即 `grid[1][1]+grid[2][1]+grid[3][1]`；第 3 列 `h=5` 与第 4 列 `h=0` 配对得 `grid[3][3]`；第 0 列 `h=0` 被第 1 列 `h=4` 覆盖得 `grid[3][0]`，合计 11。

```python
n = len(grid)
pre = [[0]*(n+1) for _ in range(n)]
for j in range(n):
    for i in range(n):
        pre[j][i+1] = pre[j][i] + grid[i][j]

def seg(j, lo, hi):          # 第 j 列 [lo, hi) 行之和
    return pre[j][hi] - pre[j][lo]

NEG = -1
dp = [[NEG]*(n+1) for _ in range(n+1)]
for b in range(n+1):
    dp[b][0] = 0
for j in range(1, n):
    for b in range(n+1):
        best = NEG
        for a in range(n+1):
            add = seg(j-1, min(a,b), max(a,b)) if b > a else 0
            best = max(best, dp[a][j-1] + add)
        dp[b][j] = best
```

## 复杂度
时间 O(n³)：n 列 × n² 个 (a,b) 状态对。
空间 O(n²)：`dp` 与列前缀和 `pre` 各 n²。

## 易错点
- 只算「本列比左列高」的贡献会漏掉右邻列覆盖本列白格的情况：如示例 1 第 0 列 `h=0`，其 `grid[3][0]=5` 是被第 1 列 `h=4` 覆盖的，必须在 `a>b` 分支补上 `seg(j-1, b, a)`，否则答案偏小。
- 边界列只与单侧相邻：第 0 列无左邻、第 n-1 列无右邻，若统一按双侧配对会重复计分；正确做法是 DP 只累计「与左邻」的贡献，最后一列单独加「与右邻」部分，或把 `h` 序列两端补 0 处理。

## 如果面试官追问
若 n 放大到 1000，O(n³) 会超时，怎么办？
答：固定 `b` 时把 `a<b` 与 `a>b` 两段拆开，用前缀最大值维护，转移降到 O(n²)。
