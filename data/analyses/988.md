## 一句话思路
DFS 从根往下拼路径，到叶子时反转得到叶到根的串，取字典序最小者。

## 怎么做
1. 递归时用 `path` 累积根到当前结点的字符，进入结点就 `path.append(chr(node.val + 97))`。
2. 遇到叶子（`not node.left and not node.right`）时，把 `path` 反转拼成候选串，与全局 `best` 比较。
3. 回溯时 `path.pop()`，保证兄弟分支不串味。

以示例 1 `root = [0,1,2,3,4,3,4]` 为例：走到最左叶子 `3` 时 `path = ['a','b','d']`，反转得 `"dba"`，`best` 先设为 `"dba"`；再走到叶子 `4`（路径 `a,b,e`）得 `"eba"`，`"eba" > "dba"` 不更新；右侧叶子 `4`（路径 `a,c,e`）得 `"eca"`，同样不更新，最终返回 `"dba"`。

```python
def dfs(node, path):
    if not node:
        return
    path.append(chr(node.val + 97))
    if not node.left and not node.right:
        cand = ''.join(reversed(path))
        if best[0] is None or cand < best[0]:
            best[0] = cand
    dfs(node.left, path)
    dfs(node.right, path)
    path.pop()

best = [None]
dfs(root, [])
return best[0]
```

关键点：比较的是**反转后**的串，不是 `path` 本身；`best` 用单元素列表承载，避免 `nonlocal` 在嵌套函数里的写法差异。

## 复杂度
时间 O(n·h)：n 个结点，每个叶子拼串 O(h)，最坏 h=n。
空间 O(h)：递归栈与 `path` 各占树高，最坏链状树 O(n)。

## 易错点
- 输入 `[0,1,2,3,4,3,4]` → 若直接比较 `path`（根到叶 `"abd"`）会选出错误分支，因为题目要的是叶到根 `"dba"` → 必须先 `reversed(path)` 再比。
- 输入 `[2,2,1,null,1,0,null,0]` → 若在非叶结点也更新 `best`，会把 `"a"`、`"ab"` 这类前缀误当答案 → 只在 `not node.left and not node.right` 时更新。

## 如果面试官追问
问：结点数涨到 10^5 还这么写行吗？
答：可以，但把拼串改成只在候选更优时构造，或用字符列表逐位比较，避免每个叶子都 O(h) 拼串。
