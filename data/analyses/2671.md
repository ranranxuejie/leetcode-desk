## 一句话思路
用 `cnt` 记每个数的出现次数，再用 `freq` 记「出现 k 次的数有几个」，让 `hasFrequency` 变成 O(1) 查表。

## 怎么做
1. `cnt[number]` 存该数当前次数，`freq[k]` 存「恰好出现 k 次的数字种类数」。
2. `add` 时先把旧次数 `c` 从 `freq` 里减一，再 `cnt[number] = c+1`、`freq[c+1] += 1`。
3. `deleteOne` 先看 `cnt.get(number, 0)`，为 0 直接返回；否则同样先减旧桶再加新桶（新次数为 0 时不用加）。
4. `hasFrequency(f)` 直接返回 `freq.get(f, 0) > 0`。

拿示例 1 走一遍：`add(3)` 后 `cnt={3:1}`、`freq={1:1}`；再 `add(3)`，旧桶 `freq[1]` 减到 0，`cnt[3]=2`、`freq={1:0, 2:1}`；`hasFrequency(2)` 查 `freq[2]=1>0`，返回 `True`。

```python
def add(self, number):
    c = self.cnt.get(number, 0)
    if c: self.freq[c] -= 1
    self.cnt[number] = c + 1
    self.freq[c + 1] = self.freq.get(c + 1, 0) + 1

def deleteOne(self, number):
    c = self.cnt.get(number, 0)
    if c == 0: return
    self.freq[c] -= 1
    self.cnt[number] = c - 1
    if c - 1: self.freq[c - 1] = self.freq.get(c - 1, 0) + 1

def hasFrequency(self, frequency):
    return self.freq.get(frequency, 0) > 0
```

## 复杂度
时间：`add`/`deleteOne`/`hasFrequency` 均 O(1)，共 2*10^5 次调用。
空间：`cnt` 与 `freq` 各至多 O(不同 number 数) 与 O(最大次数)，即 O(n)。

## 易错点
- `deleteOne` 删不存在的数（如示例 2 删完 1 后再删 1）→ 若直接 `cnt[number] -= 1` 会得到 -1 并污染 `freq[-1]` → 必须先判 `c == 0` 直接返回。
- 只维护 `cnt` 不维护 `freq` → `hasFrequency` 每次要扫全部 key，2*10^5 次调用会超时 → 必须同步更新 `freq` 桶，且旧桶减、新桶加两步都不能漏。

## 如果面试官追问
问：若要求 `hasFrequency` 返回具体是哪个数怎么办？
答：把 `freq[k]` 从计数改成存一个集合（或任一代表元素），增删时同步维护即可，仍是 O(1)。
