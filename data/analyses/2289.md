## 一句话思路
用单调栈维护每个元素被删所需的轮数，答案取最大值；因为一个数只会在左侧第一个不小于它的数出现后被删。

## 怎么做
1. 栈里存 `(值, 删除轮数)`，遍历 `nums` 中每个 `x`。
2. 弹出所有 `< x` 的栈顶，同时记录这些被弹元素轮数的最大值 `mx`。
3. 若栈非空，`x` 的轮数 = `mx + 1`；若栈空（左侧没有更大的数），轮数 = 0。
4. 把 `(x, 轮数)` 压栈，全局答案取所有轮数的最大值。

以示例 1 的 `nums = [5,3,4,4,7,3,6,11,8,5,11]` 为例，走到 `x = 6` 时，栈中为 `[(5,0),(7,0),(3,1)]`：弹出 `(3,1)` 得 `mx = 1`，栈顶 `7 > 6`，故 `6` 的轮数为 `1 + 1 = 2`。再走到最后的 `x = 11`，弹出 `(8,3)`、`(5,2)` 等，`mx = 3`，轮数为 `4`？实际答案是 3——因为 `11` 左侧的 `11` 不小于它，`11` 本身不会被删，其轮数不参与答案，最终 `max` 仍是 3。

```python
stack = []          # (value, rounds)
ans = 0
for x in nums:
    mx = 0
    while stack and stack[-1][0] < x:
        mx = max(mx, stack.pop()[1])
    cur = 0 if not stack else mx + 1
    ans = max(ans, cur)
    stack.append((x, cur))
return ans
```

关键点：`mx` 只统计被弹出的元素，栈顶剩余元素（`>= x`）的轮数不加进 `cur`，否则会把「更早被删」误算成「本轮被删」。

## 复杂度
时间 O(n)：每个元素最多入栈出栈各一次，`n = len(nums)`。
空间 O(n)：栈最坏存全部元素，无其他额外结构。

## 易错点
- 输入 `[5,3,4,4,7,3,6,11,8,5,11]` → 若把栈顶未弹出元素的轮数也计入 `mx`，`6` 会算成 `1+1=2` 尚可，但 `8` 会因 `11` 的轮数被抬高 → 正确做法是 `mx` 只取 `pop()` 出来的值。
- 输入 `[1,1,1]` 或 `[4,5,7,7,13]` → 若用 `<=` 弹栈，相等元素会被误删并累加轮数 → 必须用严格 `<`，相等时保留在栈中，轮数为 0。

## 如果面试官追问
问：若要求输出每一轮被删元素的下标列表？
答：在栈中额外存下标，弹出时按 `cur` 值分桶记录，最后按轮数升序输出即可。
