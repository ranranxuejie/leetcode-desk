## 一句话思路
奇数直接返回空；偶数从 2 开始贪心累加，最后一项吸收剩余，保证互不相同且项数最多。

## 怎么做
1. 若 `finalSum` 为奇数，正偶数之和必为偶数，直接返回 `[]`。
2. 从 `cur = 2` 起依次尝试加入，只要 `finalSum - cur > cur` 就收下 `cur` 并令 `finalSum -= cur`、`cur += 2`。
3. 循环结束时把剩下的 `finalSum` 作为最后一项追加，它必然大于已收的最大项，不会重复。

以 `finalSum = 28` 为例：收 2 后剩 26，收 4 后剩 22，收 6 后剩 16，此时 `16 - 8 > 8` 不成立（16 不大于 16），停止；把 16 追加，得 `[2,4,6,16]`，4 项。官方给的 `[6,8,2,12]` 同样 4 项，都合法。

```python
if finalSum % 2:
    return []
res, cur = [], 2
while finalSum - cur > cur:
    res.append(cur)
    finalSum -= cur
    cur += 2
res.append(finalSum)
return res
```

关键在 `finalSum - cur > cur` 这个严格大于：若写成 `>=`，`finalSum = 12` 时会收下 2、4，剩 6，再判断 `6 - 6 >= 6` 为假，追加 6 得 `[2,4,6]` 恰好也对；但 `finalSum = 16` 时会收 2、4，剩 10，判断 `10 - 6 >= 6` 为真收下 6，剩 4，追加 4，得到 `[2,4,6,4]`，4 重复，非法。所以必须严格大于，让剩余项始终大于当前最大项。

## 复杂度
时间 O(sqrt(finalSum))：累加 2+4+…+2k ≈ k² 不超过 finalSum，循环 k 次。
空间 O(sqrt(finalSum))：结果数组本身长度即 k，无其他额外结构。

## 易错点
- 输入 `finalSum = 16` → 判断条件写成 `>=` 会产出 `[2,4,6,4]`，4 重复 → 必须用 `finalSum - cur > cur`，保证追加的尾项严格大于已收最大项。
- 输入 `finalSum = 2` → 循环条件 `2 - 2 > 2` 为假，直接追加 2 得 `[2]`，这是对的；但若先判断 `finalSum < 2` 返回空就会错 → 单项 2 是合法拆分，只有奇数才返回空。

## 如果面试官追问
问：如果要求拆成互不相同的正奇数呢？
答：奇数个奇数之和为奇数，先看 finalSum 与项数奇偶是否匹配，再从 1 起同样贪心，尾项调整奇偶即可。
