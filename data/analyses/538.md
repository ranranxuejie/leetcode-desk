## 一句话思路
反中序遍历（右→根→左）按值从大到小访问，用累加变量 `total` 边加边赋值。

## 怎么做
1. 维护一个非局部累加和 `total`，初值 0。
2. 先递归右子树，因为右子树的值都比当前节点大。
3. 访问根时执行 `total += root.val; root.val = total`。
4. 再递归左子树。

以示例 1 的根 `4` 为例：先走右链 `6→7→8`，到 `8` 时 `total=8`，`8` 变成 8；回退到 `7` 时 `total=15`，`7` 变成 15；到 `6` 时 `total=21`，`6` 变成 21。此时 `total=21`，回到根 `4`，`total=25`，`4` 变成 25？——注意顺序：根 `4` 的右子树处理完后 `total` 已是 21，加 `4` 得 25，但输出里根是 30。原因是 `4` 的右子树含 `5`，`5` 在 `6` 的左子树里，反中序会先访问 `6` 再访问 `5`，`total` 到 `5` 时是 26，回根时 `total=26+4=30`，与输出一致。

```python
def dfs(node):
    nonlocal total
    if not node:
        return
    dfs(node.right)
    total += node.val
    node.val = total
    dfs(node.left)

total = 0
dfs(root)
return root
```

## 复杂度
时间 O(n)：每个节点恰好访问一次，n 为节点数。
空间 O(h)：递归栈深度为树高 h，最坏链状 O(n)，无额外数组。

## 易错点
- 写成中序（左→根→右）→ 得到的是从大到小的前缀和反了，示例 3 的 `[1,0,2]` 会输出 `[1,1,3]` 而非 `[3,3,2]`；必须右→根→左。
- 把 `total` 写成函数参数按值传递 → 递归返回后上层 `total` 不更新，示例 1 的 `6` 会算成 6 而不是 21；要用 `nonlocal` 或实例属性共享同一份累加值。

## 如果面试官追问
若树不是 BST 而是普通二叉树？答：先中序遍历收集有序值数组，再从后往前累加，最后按值回填，时间 O(n)、空间 O(n)。
