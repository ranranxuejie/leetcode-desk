## 一句话思路
把列字母和行数字都换算成 0~7 的整数，两格同色当且仅当 `(列+行)` 的奇偶性相同。

## 怎么做
1. 用 `ord(c) - ord('a')` 把列字母转成 0~7 的列号。
2. 用 `int(c) - 1` 把行字符转成 0~7 的行号。
3. 对每格算 `列号 + 行号`，取 `% 2` 得到颜色标记。
4. 比较两个标记是否相等。

以示例 1 的 `"a1"` 和 `"c3"` 为例：`"a1"` 得列 0、行 0，和 `0`，`0 % 2 = 0`；`"c3"` 得列 2、行 2，和 `4`，`4 % 2 = 0`。两个标记都是 0，返回 `True`。示例 2 的 `"h3"` 得列 7、行 2，和 `9`，`9 % 2 = 1`，与 `"a1"` 的 0 不等，返回 `False`。

```python
def color(s):
    col = ord(s[0]) - ord('a')
    row = int(s[1]) - 1
    return (col + row) % 2

return color(coordinate1) == color(coordinate2)
```

关键点：`(col + row) % 2` 这个值本身没有「黑/白」的语义约定，只用来做相等比较，所以不必纠结 `a1` 到底该是 0 还是 1。

## 复杂度
时间：O(1)，只对两个长度固定为 2 的字符串各做一次 `ord` 和 `int`。
空间：O(1)，只开了 `col`、`row` 两个整型临时变量。

## 易错点
- 把行字符直接当数字用，比如 `int(s[1])` 忘了减 1：`"a1"` 会算成 `0 + 1 = 1`，`"c3"` 算成 `2 + 3 = 5`，两者 `% 2` 都是 1，示例 1 侥幸还对；但 `"a2"` 与 `"b1"` 这种会翻车——正确做法是统一减 1，让行列都落在 0~7。
- 只比较列字母或只比较行数字的奇偶：`"a1"` 与 `"b1"` 列差 1、行相同，颜色其实不同，但只看行会误判为同色；必须把 `col + row` 合起来取模。

## 如果面试官追问
问：如果棋盘不是 8×8 而是 n×n，坐标范围变大，解法要改吗？
答：不用改，`(col + row) % 2` 与棋盘尺寸无关，只要坐标从 0 开始编号就成立。
