## 一句话思路
用回溯按位置填字符，每层从剩余字符里挑一个，选完即恢复，长度到 `len(S)` 就收一个排列。

## 怎么做
1. 把 `S` 转成列表 `chars`，用 `used` 布尔数组标记哪些下标已被占用。
2. 递归函数维护当前路径 `path`，当 `len(path) == len(S)` 时把 `"".join(path)` 加入结果。
3. 每层遍历 `chars` 的所有下标，跳过 `used[i]` 为真的，否则标记、追加、递归、回溯。
4. 以 `S = "qwe"` 为例：第一层选 `'q'` 后 `used = [True, False, False]`、`path = ['q']`；第二层选 `'w'` 得 `path = ['q','w']`，第三层只剩 `'e'`，产出 `"qwe"`；回溯到第二层换 `'e'`，产出 `"qew"`。

```python
def dfs(path):
    if len(path) == n:
        res.append("".join(path))
        return
    for i in range(n):
        if used[i]:
            continue
        used[i] = True
        path.append(chars[i])
        dfs(path)
        path.pop()
        used[i] = False

n = len(S)
chars = list(S)
used = [False] * n
res = []
dfs([])
```

关键点：`used` 是按**下标**标记而不是按字符值，虽然本题字符互不相同，按下标写能直接迁移到有重复字符的变体。

## 复杂度
时间：共 `n!` 个排列，每个拼接 `"".join(path)` 花 O(n)，总计 O(n · n!)。
空间：递归深度 O(n)，`used` 与 `path` 各 O(n)，结果数组占 O(n · n!)。

## 易错点
- 输入 `S = "a"`（长度 1）→ 若把终止条件写成 `len(path) == n - 1` 或漏掉空串起始判断，会返回 `[]` 而不是 `["a"]` → 终止条件必须是 `len(path) == n`，且从 `dfs([])` 起步。
- 输入 `S = "ab"` → 回溯时只 `path.pop()` 却忘了 `used[i] = False`，第二轮外层循环里 `'a'` 仍被标记，结果只剩 `["ab"]` 丢了 `"ba"` → 两个状态必须成对恢复，顺序为 `path.pop()` 后 `used[i] = False`。

## 如果面试官追问
问：若 `S` 含重复字符（如 `"aab"`）怎么改？
答：先对 `chars` 排序，同层循环里加 `if i > 0 and chars[i] == chars[i-1] and not used[i-1]: continue` 剪掉重复分支。
