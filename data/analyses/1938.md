## 一句话思路
把查询按 node 挂到树上，DFS 进出时维护根到当前节点的路径字典树，进节点插入、出节点删除，沿途回答该节点的查询。

## 怎么做
1. 建 children 邻接表，把 `queries[i]` 按 `node_i` 分组存成 `(val_i, i)`，答案数组 `ans` 长度 `len(queries)`。
2. 字典树按位从高到低（本题 `val_i ≤ 2*10^5 < 2**18`，取 17 到 0 位）建，每个节点存 `cnt` 表示当前路径上有多少个数经过它。
3. DFS 进入节点 x 时把 x 插入字典树，然后对挂在 x 上的每个查询做贪心：某位 `b` 若 `cnt[child[1-b]] > 0` 就走异或为 1 的分支，否则走同侧。
4. 回溯离开 x 时把 x 从字典树删除（沿路 `cnt -= 1`），保证树里始终只有根到当前节点的路径。

以示例 1 `parents=[-1,0,1,1]`、查询 `[3,2]` 为例：DFS 到 3 时路径是 `{0,1,3}`，插入后对 `val=2`（二进制 `010`）贪心，最高位取 1 得节点 1，最终 `2 XOR 1 = 3`，写入 `ans[1]`。

```python
def dfs(x):
    insert(x)
    for val, qi in by_node[x]:
        ans[qi] = query(val)
    for c in children[x]:
        dfs(c)
    remove(x)

def query(val):
    res, p = 0, 0
    for b in range(17, -1, -1):
        want = 1 - ((val >> b) & 1)
        if trie[p][want] and cnt[trie[p][want]] > 0:
            res |= 1 << b
            p = trie[p][want]
        else:
            p = trie[p][1 - want]
    return res
```

## 复杂度
时间：O((n + q) * 18)，n 个节点各一次插入删除、q 个查询各一次 18 位贪心。
空间：字典树节点数 O(n * 18)，加 children 与 by_node 的 O(n + q)。

## 易错点
- 忘记回溯删除：DFS 到兄弟子树时字典树里还留着别的分支节点，`[3,2]` 会误把节点 2 算进路径，答案偏大。必须在 `dfs` 末尾对 x 沿路 `cnt -= 1`。
- 位宽取太小：`val_i` 最大 `2*10^5`，但节点编号也参与异或，若只循环到第 16 位（`range(16,-1,-1)`）会漏掉第 17 位，`val=131072` 类查询结果偏小。统一用 `range(17, -1, -1)`。

## 如果面试官追问
若 queries 涨到 10^6 且要求在线回答？答：改用可持久化字典树，按 DFS 序建版本，查询时用 `root[node]` 直接查，免去离线挂载。
