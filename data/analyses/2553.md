## 一句话思路
对每个 `nums[i]` 用 `str()` 拆成字符再转回 `int`，按原顺序 `extend` 进 `answer`，因为字符串天然保持数位顺序。

## 怎么做
1. 初始化空列表 `answer`。
2. 遍历 `nums` 中每个整数 `x`。
3. 把 `x` 转成字符串，逐字符 `int()` 后 `extend` 到 `answer`。
4. 返回 `answer`。

以 `nums = [13,25,83,77]` 为例，处理 `13` 时 `str(13) = "13"`，得到 `[1,3]`，`answer` 变为 `[1,3]`；处理 `25` 后变为 `[1,3,2,5]`，依此类推最终得到 `[1,3,2,5,8,3,7,7]`。

```python
answer = []
for x in nums:
    for ch in str(x):
        answer.append(int(ch))
return answer
```

等价写法（更短，但可读性略降）：

```python
answer = []
for x in nums:
    answer.extend(int(ch) for ch in str(x))
return answer
```

关键点：`str(x)` 的字符顺序就是数位原本顺序，不需要反转，也不需要取模除十。

## 复杂度
时间：O(n·log M)，n 是 `nums` 长度，log M 是单个数的位数（`nums[i] ≤ 10^5` 最多 6 位）。
空间：O(n·log M)，`answer` 存放所有数位，不计输出则额外 O(1)。

## 易错点
1. 输入 `nums = [10, 100]` → 若用取模 `x % 10` 再 `x //= 10` 收集数位，会得到反转顺序 `[0,1,0,0,1]` → 正确做法是收集后 `reverse`，或直接用 `str(x)` 按字符顺序遍历。
2. 输入 `nums = [7,1,3,9]` → 若误以为个位数要特殊处理或跳过，会漏掉元素 → 正确做法是统一走 `str(x)`，`str(7) = "7"` 自然得到 `[7]`，无需分支。

## 如果面试官追问
问：如果 `nums[i]` 上限变成 `10^18` 呢？答：`str()` 方案不变，位数从 6 变 19，复杂度仍是 O(n·log M)，Python 大整数转字符串无溢出问题。
