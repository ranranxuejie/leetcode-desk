## 一句话思路
按出现次数决定行数，用哈希表记录每个数已放到第几行，逐次追加到对应行。

## 怎么做
1. 用 `Counter(nums)` 统计每个值的出现次数，最大次数就是最少行数 `rows`。
2. 建 `rows` 个空列表，再用字典 `pos` 记录每个值下一次该放进第几行。
3. 遍历 `nums`，把 `x` 追加到第 `pos[x]` 行，然后 `pos[x] += 1`。
4. 返回这 `rows` 行。

以 `nums = [1,3,4,1,2,3,1]` 为例：`1` 出现 3 次，所以 `rows = 3`。处理到第二个 `1` 时，`pos[1]` 已从 0 变成 1，于是它进入第 1 行；第三个 `1` 时 `pos[1] = 2`，进入第 2 行。最终三行分别是 `[1,3,4,2]`、`[1,3]`、`[1]`。

```python
from collections import Counter

cnt = Counter(nums)
rows = max(cnt.values())
ans = [[] for _ in range(rows)]
pos = {}
for x in nums:
    i = pos.get(x, 0)
    ans[i].append(x)
    pos[x] = i + 1
return ans
```

关键点：同一个值第 k 次出现就放进第 k 行，天然保证每行内该值只出现一次；不同值互不影响，所以每行都不会有重复。

## 复杂度
时间 O(n)：一次统计加一次遍历，n 为 `nums` 长度。
空间 O(n)：`ans` 存全部元素，`cnt` 和 `pos` 各最多 n 个键。

## 易错点
- 输入 `nums = [1,1,1]` → 若只开一行然后跳过重复值，会丢掉两个 `1`，输出 `[[1]]` → 正确做法是行数取最大频次 3，得到 `[[1],[1],[1]]`。
- 输入 `nums = [1,2,3,4]` → 若按「每个值固定占一行」的思路，会输出 4 行 → 正确做法是行数由最大频次决定，这里最大频次为 1，只开一行 `[[1,2,3,4]]`。

## 如果面试官追问
追问：要求行数最少且每行长度尽量均衡怎么办？
答：仍按频次定行数，把每个值依次填入当前最短的行即可。
