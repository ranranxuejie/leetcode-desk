## 一句话思路
两次贪心扫描：从左到右保证任意前缀的 `)` 不超过可填的 `(`，再从右到左对称检查一遍。

## 怎么做
1. 长度 `n` 为奇数直接返回 `False`，因为有效括号串长度必为偶数。
2. 正扫：用 `balance` 记「当前能提供的最多左括号数」，遇到 `locked[i]=='0'` 或 `s[i]=='('` 就 `+1`，否则 `-1`；一旦 `balance < 0` 返回 `False`。
3. 反扫：把 `(` 和 `)` 的角色对调，同样维护 `balance`，检查后缀里 `(` 是否过多。
4. 两趟都通过返回 `True`。

以示例 1 `s="))()))"`, `locked="010100"` 为例，正扫时 `i=0` 可改记 `+1`，`i=1` 锁定 `)` 记 `-1`，`i=2` 可改记 `+1`，`i=3` 锁定 `)` 记 `-1`，`i=4` 可改记 `+1`，`i=5` 锁定 `)` 记 `-1`，`balance` 依次为 `1,0,1,0,1,0`，全程非负；反扫对称也非负，故返回 `True`。

```python
n = len(s)
if n % 2:
    return False
balance = 0
for i in range(n):
    if locked[i] == '0' or s[i] == '(':
        balance += 1
    else:
        balance -= 1
    if balance < 0:
        return False
balance = 0
for i in range(n - 1, -1, -1):
    if locked[i] == '0' or s[i] == ')':
        balance += 1
    else:
        balance -= 1
    if balance < 0:
        return False
return True
```

## 复杂度
时间：两趟各扫 `n` 个字符，共 `O(n)`。
空间：只用了 `balance` 一个整数，`O(1)` 额外空间。

## 易错点
- 输入 `s=")", locked="0"`：只做正扫会得到 `balance=1` 判 `True`，但长度为奇数根本凑不出配对，正确做法是开头先判 `n % 2`。
- 输入 `s="((()"`, `locked="1111"`：只做正扫 `balance` 全程为正，误判 `True`；实际末尾两个 `(` 无法闭合，必须补一趟反扫，把 `locked[i]=='0'` 或 `s[i]==')'` 记 `+1` 才能发现后缀里 `(` 过多。

## 如果面试官追问
问：要求输出一种具体改法而不是布尔值怎么办？
答：正扫时把每个 `locked[i]=='0'` 的位置先记成 `(`，遇到 `balance` 不足再把最近的这类位置翻成 `)`，反扫同理修正，最后拼出字符串。
