## 一句话思路
把 arr2 排序后对每个 arr1[i] 二分找最近邻，只比较左右两个候选值即可判定是否远离。

## 怎么做
1. 对 arr2 排序，得到有序数组便于二分。
2. 对 arr1 中每个 x，用 `bisect_left(arr2, x)` 得到插入位置 pos。
3. 只需检查 `arr2[pos]` 和 `arr2[pos-1]`（越界则跳过），因为排序后最近邻必在这两个位置之一。
4. 若两个候选与 x 的距离都大于 d，则计数加一。

以示例 1 为例：arr2 排序为 `[1,8,9,10]`，d=2。对 x=4，`bisect_left` 返回 pos=1，候选是 `arr2[1]=8` 和 `arr2[0]=1`，距离分别为 4 和 3，都大于 2，所以 4 计入。对 x=8，pos=1，候选 `arr2[1]=8` 距离 0，不满足，跳过。

```python
from bisect import bisect_left

arr2.sort()
ans = 0
for x in arr1:
    pos = bisect_left(arr2, x)
    ok = True
    for j in (pos - 1, pos):
        if 0 <= j < len(arr2) and abs(x - arr2[j]) <= d:
            ok = False
            break
    if ok:
        ans += 1
```

## 复杂度
时间：排序 arr2 为 O(m log m)，每个 arr1 元素二分 O(log m)，共 O((n+m) log m)。
空间：排序额外 O(m)（或视排序实现而定），其余 O(1)。

## 易错点
- 只检查 `arr2[pos]` 而漏掉 `arr2[pos-1]`：例如 x=4、arr2 排序后 `[1,8,9,10]`，pos=1 时 `arr2[1]=8` 距离 4 看似远离，但 `arr2[0]=1` 距离 3 也大于 d=2 才安全；若 d=3，漏查 `arr2[0]` 会把 4 误判为远离。正确做法是两个候选都查。
- 边界越界未处理：x 小于 arr2 最小值时 pos=0，`arr2[pos-1]` 是 `arr2[-1]`（Python 负索引会取到最大值），导致误判。必须用 `0 <= j < len(arr2)` 显式判断。

## 如果面试官追问
问：若 arr1 和 arr2 都很大且需多次查询怎么办？
答：预处理 arr2 排序一次，后续每个查询仍是 O(log m)，或对 arr1 也排序后用双指针整体 O(n+m)。
