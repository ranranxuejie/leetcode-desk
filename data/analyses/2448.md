## 一句话思路
把每个 nums[i] 看成带权 cost[i] 的点，最优目标值是加权中位数，排序后找前缀权重首次过半的位置。

## 怎么做
1. 把 (nums[i], cost[i]) 按 nums 升序配对排序，得到有序的 `pairs`。
2. 总权重 `total = sum(cost)`，从左累加 `acc`，第一个满足 `acc * 2 >= total` 的 `pairs[k][0]` 就是加权中位数 `target`。
3. 再扫一遍 `pairs`，累加 `abs(x - target) * c` 得到答案。

以示例 1 为例：排序后 `pairs = [(1,2),(2,14),(3,3),(5,1)]`，`total = 20`。累加权重依次为 2、16、19、20，`16 * 2 >= 20` 首次成立，故 `target = 2`。回代得 `1*2 + 0*14 + 1*3 + 3*1 = 8`。

```python
pairs = sorted(zip(nums, cost))
total = sum(cost)
acc = 0
for x, c in pairs:
    acc += c
    if acc * 2 >= total:
        target = x
        break
ans = sum(abs(x - target) * c for x, c in pairs)
```

关键点：`acc * 2 >= total` 用乘法避免浮点；`target` 取到的是某个 `nums` 原值，不需要在整数区间上二分。

## 复杂度
时间：排序 O(n log n)，两次线性扫描 O(n)，n 来自数组长度。
空间：`pairs` 占 O(n)，其余为 O(1) 常数变量。

## 易错点
- 输入 `nums = [2,2,2,2,2]`、`cost = [4,2,8,1,3]`：若误用无权中位数或先对 nums 去重再取中位，会得到非 0 的答案；正确做法是保留重复元素、按 cost 加权累加，`acc` 首次过半时 `target = 2`，回代全为 0。
- 输入 `nums = [1,3,5,2]`、`cost = [2,3,1,14]`：若用 `acc >= total // 2` 判断，`total = 20` 时 `acc = 2` 不满足、`acc = 16` 才满足，结果碰巧对；但 `total` 为奇数如 21 时 `total // 2 = 10`，`acc = 10` 会提前触发取到偏小的 `target`，正确写法是 `acc * 2 >= total`。

## 如果面试官追问
问：若要求返回具体目标值而非开销？答：加权中位数落在 `acc * 2 >= total` 的那个 `x` 上，直接返回 `target` 即可，区间内任意整数等价。
