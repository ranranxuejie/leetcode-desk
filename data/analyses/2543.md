## 一句话思路
从 (targetX, targetY) 反向做「除以 2」和「大减小」，能退到 (1,1) 即可达；因为正向四种操作在反向唯一可判。

## 怎么做
1. 反向规则：若某坐标是偶数，唯一可能是由 `*2` 得来，直接除 2；否则只能由「大减小」得来，做减法。
2. 两个坐标都大于 1 时循环：先把偶数坐标反复除 2，直到它变成奇数。
3. 若此时两坐标相等且 >1，说明卡死在同一点，返回 `False`；否则让大的减小的。
4. 循环到某个坐标变成 1，检查另一个坐标是否也能退到 1。

拿示例 2 的 `targetX=4, targetY=7` 走一遍：`7` 是奇数、`4` 是偶数，先 `4//2=2`、`2//2=1`，得 `(1,7)`；`7` 奇数，`7-1=6`，`6//2=3`，`3-1=2`，`2//2=1`，得 `(1,1)`，返回 `True`。关键中间值是 `(1,7)` 之后一路减半到 `(1,1)`。

```python
def isReachable(targetX, targetY):
    x, y = targetX, targetY
    while x > 1 and y > 1:
        if x % 2 == 0:
            x //= 2
        elif y % 2 == 0:
            y //= 2
        elif x > y:
            x -= y
        elif y > x:
            y -= x
        else:
            return False
    return x == 1 or y == 1
```

注意 `x == y` 且都 >1 时必须立刻返回 `False`，否则减法会死循环（如 `(6,6)`）。

## 复杂度
时间：每轮至少让 `x+y` 减半或减一，`O(log(targetX + targetY))`。
空间：只存 `x, y` 两个整数，`O(1)`。

## 易错点
- 输入 `(6,6)` → 两坐标相等时若继续 `x -= y` 会得到 0 并死循环 → 必须在 `x == y and x > 1` 时直接返回 `False`。
- 输入 `(1, 10**9)` → 若只写「偶数除 2、奇数相减」而不先判 `x > 1 and y > 1`，会把 `1` 也拿去减，越界成负数 → 循环条件必须是两坐标都 >1，退出后判 `x == 1 or y == 1`。

## 如果面试官追问
问：若要求输出一条具体路径怎么办？
答：正向模拟反向过程，把每步的逆操作（乘 2 或加）倒序记录即可，长度 `O(log)`。
