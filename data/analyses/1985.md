## 一句话思路
按「长度优先、字典序次之」排序字符串，取倒数第 k 个，避免大整数转换。

## 怎么做
1. 用 `key=lambda s: (len(s), s)` 排序，长度短的数字小，同长度按字典序比。
2. 排序后升序，第 k 大即 `nums[-k]`。
3. 以示例 2 为例：`["2","21","12","1"]` 排序后为 `["1","2","12","21"]`，`k=3` 取 `nums[-3]="2"`。

```python
def kthLargestNumber(nums, k):
    nums.sort(key=lambda s: (len(s), s))
    return nums[-k]
```

关键中间值：`len("2")=1 < len("12")=2`，所以 `"2"` 排在 `"12"` 前；同长度时 `"12" < "21"` 靠字典序。

## 复杂度
时间：排序 O(n log n)，每次比较 O(L)，L 为字符串最大长度。
空间：O(n) 存排序结果（Python sort 原地但 key 缓存 O(n)）。

## 易错点
1. 直接按字符串字典序排 → `["3","6","7","10"]` 会排成 `["10","3","6","7"]`，`"10"` 被误判最小；正确做法是先比长度再比字典序。
2. 转 `int` 再排序 → `nums[i]` 长度可达 100 位，超出 64 位范围，Python 虽不溢出但大整数比较慢；正确做法保持字符串比较。

## 如果面试官追问
问：若 nums 长度到 10^6 且只需第 k 大，如何优化？
答：用大小为 k 的最小堆维护前 k 大，比较仍用 `(len, s)`，时间 O(n log k)。
