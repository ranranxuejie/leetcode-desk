## 一句话思路
按 patient_id 分组，用条件聚合分别取「首次阳性日期」和「该阳性之后的首次阴性日期」，两者相减即康复时间。

## 怎么做
1. 先按 `patient_id` 聚合 `covid_tests`，用 `MIN(CASE WHEN result='Positive' THEN test_date END)` 得到 `first_pos`。
2. 再取 `MIN(CASE WHEN result='Negative' AND test_date > first_pos THEN test_date END)` 作为 `first_neg`；`Inconclusive` 不参与任何聚合。
3. 用 `first_neg IS NOT NULL AND first_pos IS NOT NULL` 过滤，`DATEDIFF(first_neg, first_pos)` 得 `recovery_time`。
4. 关联 `patients` 取姓名年龄，按 `recovery_time, patient_name` 升序。

以 Bob（patient_id=2）为例：`first_pos=2023-02-01`，02-05 的 Inconclusive 被 CASE 排除，`first_neg=2023-02-12`，`DATEDIFF=11`。若把 Inconclusive 也当阴性，会错算成 4 天。

```python
# 伪 SQL 逻辑，落到 pandas 即：
pos = df[df.result == 'Positive'].groupby('patient_id').test_date.min()
neg = df[df.result == 'Negative'].merge(pos.rename('p'), on='patient_id')
neg = neg[neg.test_date > neg.p]
first_neg = neg.groupby('patient_id').test_date.min()
rec = (first_neg - pos).dt.days
```

关键点：`first_neg` 必须严格大于 `first_pos`，Carol 的 01-20 阴性在 02-10 阳性之前，被 `>` 排除。

## 复杂度
时间：O(n log n)，n 为 covid_tests 行数，排序/分组聚合贡献 log n。
空间：O(k)，k 为去重后的 patient_id 数，存首次阳性与首次阴性两张中间表。

## 易错点
- 把 `Inconclusive` 当阴性 → Bob 的 02-05 会被选为首次阴性，算出 4 天 → 正确做法是 CASE 里只认 `'Negative'`，让 02-05 落空。
- 用全局 `MIN(Negative)` 而不加 `test_date > first_pos` → Carol 的 01-20 阴性被选中，`DATEDIFF` 为负 → 正确做法是阴性聚合必须带「晚于首次阳性」的条件。

## 如果面试官追问
问：若要求「每次阳性-阴性配对都算一轮康复」怎么办？
答：改用窗口函数按 patient_id 排序，找阳性后第一条阴性，逐对输出而非只取首次。
