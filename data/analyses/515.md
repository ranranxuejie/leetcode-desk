## 一句话思路
用 BFS 逐层遍历，每层扫完取最大值；队列天然把同层节点聚在一起，层数就是答案下标。

## 怎么做
1. 空树直接返回 `[]`，否则 `queue = [root]`、`res = []`。
2. 外层 `while queue` 每轮记录 `size = len(queue)`，这就是当前层节点数。
3. 内层循环 `size` 次：`node = queue.pop(0)`，用 `level_max` 更新最大值，左右子非空则入队。
4. 内层结束把 `level_max` 追加进 `res`。

以示例 1 `[1,3,2,5,3,null,9]` 为例：第一轮 `size=1`，弹出 1，`level_max=1`，入队 3、2，`res=[1]`；第二轮 `size=2`，弹出 3 和 2，`level_max` 从 3 保持到 3（2 不更大），入队 5、3、9，`res=[1,3]`；第三轮 `size=3`，弹出 5、3、9，`level_max` 依次 5→5→9，`res=[1,3,9]`。关键中间值：第二轮 `level_max` 初值必须取该层第一个节点的值，不能沿用上一层的 1。

```python
from collections import deque
if not root:
    return []
queue, res = deque([root]), []
while queue:
    level_max = -2**31
    for _ in range(len(queue)):
        node = queue.popleft()
        level_max = max(level_max, node.val)
        if node.left:
            queue.append(node.left)
        if node.right:
            queue.append(node.right)
    res.append(level_max)
return res
```

`level_max` 初值用 `-2**31` 而不是 0，因为节点值可以全是负数。

## 复杂度
时间 O(n)：每个节点入队出队各一次，`max` 比较一次。
空间 O(w)：队列最多存一层宽度 w，`res` 存层数，最坏 O(n)。

## 易错点
- 输入 `root = [-1,-2,-3]` → 若 `level_max` 初值写 0，第二层返回 0 而不是 -2 → 初值取 `-2**31` 或该层第一个节点的值。
- 输入 `[1,3,2,5,3,null,9]` → 若内层循环写成 `while queue` 而不是 `for _ in range(len(queue))`，会把三层混成一层，输出 `[9]` → 必须先固定 `size = len(queue)` 再循环。

## 如果面试官追问
如果要求不用队列、只用 O(1) 额外空间？答：用 DFS 带层号，`res` 按层号懒扩展，遇到更深层就 append，否则取 max。
