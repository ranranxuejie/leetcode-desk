## 一句话思路
把 nums 转成 set，遍历链表时只在「当前值在 set 且前一个值不在 set」处计数，即每个组件的起点。

## 怎么做
1. 用 `s = set(nums)` 建哈希集合，后续每个节点 O(1) 判断是否属于 nums。
2. 维护 `prev_in = False`，表示前一个节点的值是否在 s 中；初始为 False（头节点前视为断开）。
3. 遍历链表，对每个节点算 `cur_in = node.val in s`；若 `cur_in and not prev_in`，说明这是新组件的第一个节点，`ans += 1`。
4. 每步结束把 `prev_in = cur_in`，指针后移。

以示例 1 `head = [0,1,2,3], nums = [0,1,3]` 为例，`s = {0,1,3}`。走到值 2 时 `cur_in = False`，`prev_in` 从 True 变 False，不计数；走到值 3 时 `cur_in = True` 而 `prev_in = False`，`ans` 从 1 变 2——这正是「2 把 0,1 和 3 隔开」的关键中间值。

```python
s = set(nums)
ans = 0
prev_in = False
node = head
while node:
    cur_in = node.val in s
    if cur_in and not prev_in:
        ans += 1
    prev_in = cur_in
    node = node.next
return ans
```

注意判断顺序：先算 `cur_in` 再比较 `prev_in`，最后才更新 `prev_in`，三者不能合并成一行，否则会用到已覆盖的旧值。

## 复杂度
时间 O(n + m)：n 为链表节点数（遍历一次），m 为 nums 长度（建集合）。
空间 O(m)：额外开了一个大小为 m 的 set，链表本身不计。

## 易错点
- 输入 `head = [0,1,2,3], nums = [0,1,3]`：若把「值在 nums 中就 ans += 1」，会得到 3 而不是 2，因为 0 和 1 被算成两个组件。正确做法是只在 `not prev_in` 时计数，让连续段只贡献一次。
- 输入 `head = [1,2,3], nums = [1,2,3]`（整条链都在 nums 里）：若把 `prev_in` 初始化为 True，会漏掉头节点这个组件起点，返回 0。正确做法是初始 `prev_in = False`，把链表头当作「前面断开」。

## 如果面试官追问
问：若 nums 很大且要求 O(1) 额外空间怎么办？
答：利用题面 `0 <= Node.val < n`，可原地用节点值做标记位，但会破坏链表，需先确认能否修改输入。
