## 一句话思路
只关心当前拼接串的首尾字符，用 DP 记录「首字符 + 尾字符」下的最小长度。

## 怎么做
1. 关键观察：join 只可能删掉 1 个字符，且删不删只取决于 `x` 的尾和 `y` 的首是否相等，所以拼接串的内部内容无关，只需记首尾字符。
2. 定义 `dp[c1][c2]` = 处理完前 i 个词后，拼接串首字符为 `c1`、尾字符为 `c2` 时的最小长度；初始只有 `words[0]`：`dp[words[0][0]][words[0][-1]] = len(words[0])`。
3. 对每个 `words[i]`，枚举 26×26 的状态，分别尝试「接在后面」和「接在前面」两种顺序，若首尾相同则长度减 1。
4. 答案取所有 `dp[c1][c2]` 的最小值。

以 `words = ["aa","ab","bc"]` 为例：初始 `dp['a']['a']=2`。处理 `"ab"`：接在后面 `'a'=='a'` 相等，得 `dp['a']['b']=2+2-1=3`；接在前面 `'b'!='a'`，得 `dp['b']['a']=2+2=4`。处理 `"bc"` 时从 `dp['a']['b']=3` 接在后面，`'b'=='b'`，得 `dp['a']['c']=3+2-1=4`，即答案 4。

```python
n = len(words)
INF = 10**9
dp = [[INF] * 26 for _ in range(26)]
dp[ord(words[0][0]) - 97][ord(words[0][-1]) - 97] = len(words[0])
for w in words[1:]:
    ndp = [[INF] * 26 for _ in range(26)]
    h, t, L = ord(w[0]) - 97, ord(w[-1]) - 97, len(w)
    for a in range(26):
        for b in range(26):
            if dp[a][b] == INF:
                continue
            ndp[a][t] = min(ndp[a][t], dp[a][b] + L - (b == h))
            ndp[h][b] = min(ndp[h][b], dp[a][b] + L - (t == a))
    dp = ndp
return min(min(row) for row in dp)
```

## 复杂度
时间：O(n × 26²)，n 为 words 长度，26² 是固定状态数。
空间：O(26²)，只开两张 26×26 的 dp 表。

## 易错点
- 输入 `["ab","b"]`：只考虑「接在后面」会得 `join("ab","b")="ab"` 长度 2，但若漏掉「接在前面」分支，遇到 `["b","ab"]` 这类词序就会错；必须两个方向都转移。
- 输入 `["aaa","c","aba"]`：`"aaa"` 首尾都是 `'a'`，若把首尾当成两个独立维度却忘了同一字符可同时充当首和尾，`dp['a']['a']` 的初始化和转移会漏；正确做法是首尾各自独立取 `words[i][0]`、`words[i][-1]`，允许相等。

## 如果面试官追问
问：要求输出具体拼接顺序怎么办？
答：dp 里额外存前驱（上一个状态和方向），最后从最优终态回溯即可。
