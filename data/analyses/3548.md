## 一句话思路
枚举每条分割线，用前缀和算出两侧和，再判断「移除一个格子后能否相等且保持连通」，连通性只需检查被移除格是否在部分内部。

## 怎么做
1. 先算总和 `total`，再分别枚举行分割和列分割，用前缀和 `pre` 得到两侧和 `a`、`b`。
2. 若 `a == b` 直接返回 `True`；否则令 `diff = abs(a - b)`，只有 `diff` 恰等于某侧某个格子值时才可能成立。
3. 关键：被移除的格子必须不是该部分的「割点」。对水平分割，若被移除格在部分内部（非首行/末行），只有该部分宽度为 1 时才断连；对垂直分割同理看高度。
4. 用哈希集合存每侧所有值，`diff in set` 且位置合法即返回 `True`。

以示例 2 `grid = [[1,2],[3,4]]` 为例：垂直分割后左和 `a = 1+3 = 4`，右和 `b = 2+4 = 6`，`diff = 2`。右侧集合含 `2`，且 `2` 位于右部分第 0 行（非内部行），移除后右部分剩 `[4]` 仍连通，返回 `True`。

```python
total = sum(map(sum, grid))
# 水平分割：前 i 行 vs 后 m-i 行
pre = 0
for i in range(m - 1):
    pre += sum(grid[i])
    a, b = pre, total - pre
    if a == b:
        return True
    d = abs(a - b)
    # 被移除格在较小侧；若该侧行数>1 且列数>1，内部格移除会断连

```

实际实现时，对每个分割线维护两侧的值集合，并单独记录「边界行/列」的值集合（这些位置移除不会断连），判断 `d` 是否落在安全集合里。

## 复杂度
时间：O(m·n)，每条分割线 O(1) 查询，预处理前缀和与值集合共 O(m·n)。
空间：O(m·n)，存两侧值集合与边界集合。

## 易错点
- 输入 `[[1,2,4],[2,3,5]]` 水平分割，`diff = 3` 出现在底部中间格，移除后底部裂成 `[2]` 和 `[5]` → 若只查值集合会误判 `True`；正确做法是额外判断该格是否在部分内部且部分宽/高大于 1。
- 输入单行或单列（如 `[[1,2]]`），任何格子移除都不会断连 → 若统一套用「内部格断连」规则会漏判；正确做法是对 `m == 1` 或 `n == 1` 的部分直接允许任意位置移除。

## 如果面试官追问
若要求输出具体分割线和被移除格坐标？答：在返回 `True` 处同时记录分割方向、索引和命中 `diff` 的格子坐标即可，逻辑不变。
