## 一句话思路
按 `+` 和 `i` 切出实部虚部，套 `(a+bi)(c+di)=(ac-bd)+(ad+bc)i` 直接算，字符串拼接输出。

## 怎么做
1. 用 `find('+')` 定位加号，`num1[:p]` 取实部，`num1[p+1:-1]` 去掉末尾 `i` 取虚部，`int()` 转成 `a, b`。
2. 对 `num2` 同样处理得到 `c, d`。
3. 算 `real = a*c - b*d`、`imag = a*d + b*c`。
4. 返回 `f"{real}+{imag}i"`，负虚部自然拼成 `"0+-2i"`，不用特判。

以 `num1 = "1+-1i"` 为例：`p = 1`，`num1[:1] = "1"` 得 `a=1`，`num1[2:-1] = "-1"` 得 `b=-1`。两个输入相同，`c=1, d=-1`，则 `real = 1*1 - (-1)*(-1) = 0`，`imag = 1*(-1) + (-1)*1 = -2`，拼出 `"0+-2i"`，与示例一致。

```python
def parse(s):
    p = s.find('+')
    return int(s[:p]), int(s[p+1:-1])

a, b = parse(num1)
c, d = parse(num2)
real = a * c - b * d
imag = a * d + b * c
return f"{real}+{imag}i"
```

关键点：`s[p+1:-1]` 的切片右端是 `-1`，正好砍掉末尾的 `i`；`find('+')` 只找第一个加号，所以 `"1+-1i"` 里虚部的负号不会被误当分隔符。

## 复杂度
时间 O(n)：n 是 `num1`、`num2` 的字符串长度，`find` 和切片各扫一遍。
空间 O(n)：切片和 `f-string` 各生成新字符串，无额外数组。

## 易错点
- 输入 `"1+-1i"` → 若用 `split('+')` 再对第二段 `int()`，`"-1i"` 带 `i` 会抛 `ValueError`；正确做法是切片 `s[p+1:-1]` 先剥掉 `i` 再转整数。
- 输入 `"0+-1i"` 或乘积虚部为负 → 若手动拼 `f"{real}+{imag}i"` 时对 `imag` 取绝对值再加 `-`，会得到 `"0-1i"` 这种非标准形式；正确做法是让 `imag` 带符号直接插入，输出 `"0+-1i"`。
