## 一句话思路
用异或：把 0..n 和 nums 全部异或起来，成对出现的数抵消，剩下的就是缺失值。

## 怎么做
1. 初始化 `ans = n`，因为 0..n 共 n+1 个数，nums 只有 n 个，先把多出来的 n 放进去。
2. 遍历 `i` 从 0 到 n-1，每步 `ans ^= i ^ nums[i]`，让下标 i 和元素 nums[i] 互相配对。
3. 遍历结束后 `ans` 就是那个没配对的数。

以 `nums = [3,0,1]`、n = 3 为例：`ans` 初值 3；i=0 时 `ans = 3^0^3 = 0`；i=1 时 `ans = 0^1^0 = 1`；i=2 时 `ans = 1^2^1 = 2`，输出 2。

```python
n = len(nums)
ans = n
for i in range(n):
    ans ^= i ^ nums[i]
return ans
```

等价写法是先求 `sum(range(n+1)) - sum(nums)`，但异或不用担心中间和的大小，面试里更稳。

## 复杂度
时间 O(n)：一趟遍历，n 是 `len(nums)`。
空间 O(1)：只开了 `ans` 一个变量。

## 易错点
- 漏掉初值 `ans = n`：`nums = [0,1]` 时若从 0 开始异或，i 和 nums[i] 全部抵消得 0，但正确答案是 2。n 这个数在数组里没有对应下标，必须单独补进去。
- 用求和法时把范围写成 `sum(nums)` 对 `sum(range(n))`：`nums = [3,0,1]` 会算成 `4 - 4 = 0`，实际应是 `sum(range(4)) - 4 = 2`。范围是 0..n 共 n+1 项，不是 0..n-1。

## 如果面试官追问
问：如果数组是只读的、且要求 O(1) 空间但不能改数组，还能用异或吗？
答：能，异或本来就不改数组；若禁止位运算，就用求和法，Python 整数无溢出问题。
