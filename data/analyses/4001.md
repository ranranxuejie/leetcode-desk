## 一句话思路
双指针按时间戳归并，指针所指即该序列当前生效的值（缺失时间戳取下一个更晚的值），逐点相加。

## 怎么做
1. 两个指针 `i`、`j` 分别指向 `series1`、`series2` 开头，每次取 `t = min(series1[i][0], series2[j][0])` 作为当前时间戳。
2. 某序列的指针时间戳等于 `t` 时，它的值就是 `series[k][1]`；小于 `t` 说明该序列在 `t` 处缺失，值取指针所指的「下一个更晚时间戳」的值，指针不动。
3. 指针时间戳等于 `t` 的一侧前移一位，另一侧保持，把两侧值相加写入结果。
4. 一侧走完后，另一侧剩余元素的时间戳在对方序列里都没有更晚的值，对应值按 0 计，直接原样追加。

以示例 1 为例：`i=0,j=0` 时 `t=min(1,2)=1`，`series1[0][0]==1` 取值 3，`series2[0][0]=2>1` 取下一个更晚的值 2，和为 5，`i` 前移到 1；下一步 `t=min(4,2)=2`，`series1[1][0]=4>2` 取值 1，`series2[0][0]==2` 取值 2，和为 3，`j` 前移。注意 `i` 停在 1 不动，正是「缺失取更晚值」的体现。

```python
res, i, j = [], 0, 0
n1, n2 = len(series1), len(series2)
while i < n1 and j < n2:
    t = min(series1[i][0], series2[j][0])
    v1 = series1[i][1] if series1[i][0] == t else series1[i][1]
    v2 = series2[j][1] if series2[j][0] == t else series2[j][1]
    res.append([t, v1 + v2])
    if series1[i][0] == t: i += 1
    if series2[j][0] == t: j += 1
res += series1[i:] + series2[j:]
```

## 复杂度
时间 O(n1 + n2)：两个指针各自单调前移，每个元素最多被访问一次。
空间 O(1) 额外（不计输出），结果列表长度不超过 n1 + n2。

## 易错点
- 一侧走完后剩余元素：若继续用「缺失取更晚值」的逻辑，会误以为对方还有值可加。正确做法是剩余部分直接追加原值，因为对方已无更晚时间戳，值按 0 计（示例 3 中 `series1` 走完后 `1000000000` 处 `series1` 贡献 0）。
- 指针时间戳大于 `t` 时误把指针前移：如示例 1 处理 `t=2` 时 `series1[1][0]=4>2`，若前移 `i` 就会丢掉时间戳 4 的值 1，导致结果缺 `[4,3]`。正确做法是只有时间戳等于 `t` 才前移。

## 如果面试官追问
若要求值按 32 位截断（如 C++ 语义）怎么办？答：Python 整数不溢出，需在 `v1 + v2` 后手动 `(s + 2**31) % 2**32 - 2**31` 模拟截断。
