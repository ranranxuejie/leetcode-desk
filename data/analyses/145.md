## 一句话思路
用「根-右-左」的迭代前序遍历，最后把结果整体反转，就得到后序的「左-右-根」。

## 怎么做
1. 建 `stack = [root]`、`out = []`，`root` 为 `None` 时直接返回 `[]`。
2. 循环弹栈：弹出节点就 `out.append(node.val)`，再先压左孩子、后压右孩子。
3. 因为栈后进先出，右孩子先被处理，`out` 实际顺序是「根-右-左」。
4. 返回 `out[::-1]`，反转后即「左-右-根」。

拿示例 1 `root = [1,null,2,3]` 走一遍：弹出 `1`，`out=[1]`，压左 `None`、压右 `2`；弹出 `2`，`out=[1,2]`，压左 `3`、压右 `None`；弹出 `3`，`out=[1,2,3]`。反转得 `[3,2,1]`，与期望一致。关键中间值是 `out` 在循环结束时为 `[1,2,3]`——它看着像前序，其实是「根右左」。

```python
if not root:
    return []
stack, out = [root], []
while stack:
    node = stack.pop()
    out.append(node.val)
    if node.left:
        stack.append(node.left)
    if node.right:
        stack.append(node.right)
return out[::-1]
```

压栈顺序不能反：先 `left` 后 `right`，才能让 `right` 先出栈。若写成先 `right` 后 `left`，`out` 会变成「根-左-右」的前序，反转后是「右-左-根」，示例 1 会输出 `[2,1,3]` 之类的错序。

## 复杂度
时间 O(n)：每个节点入栈出栈各一次，反转再扫 n 个。
空间 O(n)：`stack` 最坏存一层节点，`out` 存 n 个值。

## 易错点
- 输入 `root = []` → 若省掉开头的 `if not root`，`stack=[None]` 弹出后 `node.val` 抛 `AttributeError` → 先判空返回 `[]`。
- 输入示例 2 这种左右都深的树 → 若压栈写成先 `right` 后 `left`，`out` 变前序、反转后根跑到末尾，输出 `[...,3,1]` 而非 `[...,3,1]` 的正确「左-右-根」 → 固定先压 `left` 再压 `right`。
