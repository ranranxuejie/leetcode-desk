## 一句话思路
中序遍历 BST 天然升序，边遍历边用 `pre` 指针串起前驱后继，最后首尾相接成环。

## 怎么做
1. 用迭代栈做中序遍历，`cur` 从 `root` 出发一路压左孩子。
2. 弹栈得到当前最小未访问节点 `cur`，若 `pre` 非空则 `pre.right = cur; cur.left = pre`，再令 `pre = cur`。
3. 遍历结束后 `pre` 是最大值节点，把 `pre.right = head; head.left = pre` 闭环。
4. 返回 `head`（第一个被访问的节点，即最小值）。

以 `root = [4,2,5,1,3]` 为例：中序访问顺序是 1,2,3,4,5。访问到 2 时，`pre` 是 1，执行 `1.right = 2`、`2.left = 1`；全部走完后 `pre = 5`、`head = 1`，再补 `5.right = 1`、`1.left = 5`。

```python
head = pre = None
stack, cur = [], root
while stack or cur:
    while cur:
        stack.append(cur)
        cur = cur.left
    cur = stack.pop()
    if pre:
        pre.right, cur.left = cur, pre
    else:
        head = cur
    pre = cur
    cur = cur.right
if head:
    pre.right, head.left = head, pre
return head
```

关键：`head` 只在 `pre` 为空时赋值一次，即中序第一个节点；`pre` 每步都更新，最后停在最大值上。

## 复杂度
时间 O(n)：每个节点入栈出栈各一次，指针改写 O(1)。
空间 O(h)：栈深度等于树高，最坏链状树 O(n)，未额外开节点。

## 易错点
- 输入 `root = []` → 若直接执行 `pre.right = head` 会 `AttributeError`（`pre` 是 `None`）→ 闭环前必须判 `if head:`，空树直接返回 `None`。
- 输入 `root = [1]` → 只访问一个节点时 `pre` 和 `head` 是同一个，若漏掉闭环那两行，`1.left`/`1.right` 仍是原来的 `None`，返回的单节点不成环 → 闭环代码要放在循环外无条件执行（在非空前提下），不能只在 `pre != head` 时做。

## 如果面试官追问
追问：不允许用栈、要求 O(1) 空间怎么办？
答：用 Morris 中序遍历，借右空指针做线索，遍历中同样维护 `pre` 串链，最后闭环。
