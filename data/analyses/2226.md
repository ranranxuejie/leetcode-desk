## 一句话思路
对「每人分到的糖果数 x」二分，用 `sum(c // x for c in candies) >= k` 判断可行性，单调性保证二分正确。

## 怎么做
1. 答案区间取 `lo = 0`、`hi = max(candies)`，因为每人拿的糖果不可能超过最大那堆。
2. 每轮取 `mid = (lo + hi + 1) // 2`，向上取整避免死循环。
3. 统计 `total = sum(c // mid for c in candies)`，`total >= k` 则 `lo = mid`，否则 `hi = mid - 1`。
4. 循环到 `lo == hi` 返回 `lo`。

以 `candies = [5,8,6], k = 3` 为例：`hi = 8`，第一次 `mid = 4`，`total = 5//4 + 8//4 + 6//4 = 1+2+1 = 4 >= 3`，`lo = 4`；下一次 `mid = 6`，`total = 0+1+1 = 2 < 3`，`hi = 5`；再 `mid = 5`，`total = 1+1+1 = 3 >= 3`，`lo = 5`，收敛到 5。

```python
lo, hi = 0, max(candies)
while lo < hi:
    mid = (lo + hi + 1) // 2
    total = sum(c // mid for c in candies)
    if total >= k:
        lo = mid
    else:
        hi = mid - 1
return lo
```

关键点：一堆 `c` 最多能切出 `c // mid` 份大小为 `mid` 的糖果，因为不能合并，每堆独立贡献。

## 复杂度
时间：`O(n log(max(candies)))`，`n = len(candies)` 来自每轮求和，`log` 来自二分上界 `10^7`。
空间：`O(1)`，只开了 `lo/hi/mid/total` 几个标量。

## 易错点
- `k` 很大而糖果不够，如 `candies = [2,5], k = 11`：若把 `lo` 初值设成 1 会返回 1，但正确答案是 0。必须让 `lo = 0` 起步，`mid` 可能取到 0 时 `c // 0` 会崩，所以循环条件用 `lo < hi` 且 `mid` 向上取整，保证 `mid >= 1`。
- `mid = (lo + hi) // 2` 向下取整：当 `lo = 4, hi = 5` 时 `mid = 4`，若 `total >= k` 则 `lo = 4` 原地不动，死循环。必须写 `(lo + hi + 1) // 2`。

## 如果面试官追问
若要求输出具体分配方案（每堆切几份、每份多大）？答：二分出 `x` 后，对每堆取 `c // x` 份，前 `k` 份依次分给小孩，剩余糖果丢弃即可。
