## 一句话思路
从低位往高位取数，用 `sign` 交替翻转，最后按位数奇偶修正符号方向。

## 怎么做
1. 用 `while n:` 从个位开始取 `n % 10`，每取一位就 `n //= 10`。
2. 维护 `sign`，初始 `1`，每轮取完数字后 `sign = -sign`，这样低位到高位的符号是 `+,-,+,...`。
3. 累加 `total += sign * digit` 后翻转，循环结束时 `total` 的符号方向与题目要求相反（题目要求最高位为正）。
4. 用位数判断：若位数是偶数，低位起算的符号序列与题目要求正好相反，返回 `-total`；否则返回 `total`。

以 `n = 521` 为例：第一轮 `digit=1, sign=1, total=1`，翻转为 `-1`；第二轮 `digit=2, total=1+(-1)*2=-1`，翻转为 `1`；第三轮 `digit=5, total=-1+1*5=4`。位数 3 为奇数，返回 `4`，与示例一致。

```python
total = 0
sign = 1
count = 0
while n:
    digit = n % 10
    total += sign * digit
    sign = -sign
    n //= 10
    count += 1
return total if count % 2 == 1 else -total
```

关键中间值：`n=521` 三轮后 `total=4`、`count=3`，奇数位直接返回 `4`；若输入 `n=52`，两轮后 `total=2-5=-3`、`count=2`，返回 `-(-3)=3`，即 `(+5)+(-2)=3`。

## 复杂度
时间：O(log n)，循环次数等于十进制位数，`n //= 10` 每轮缩小 10 倍。
空间：O(1)，只开了 `total`、`sign`、`count`、`digit` 四个标量。

## 易错点
- 输入 `n = 52`（偶数位）→ 若直接返回 `total` 会得到 `-3`，符号方向反了 → 必须用 `count % 2` 判断，偶数位返回 `-total`。
- 输入 `n = 1`（单位数）→ 若把 `count` 初始化为 `0` 且忘记在循环内自增，会误判为偶数位返回 `-1` → `count` 必须在 `while` 体内每轮 `+= 1`，保证 `n=1` 时 `count=1` 走奇数分支。

## 如果面试官追问
问：若 n 是字符串形式（长度可达 10^5）怎么办？
答：直接按下标 `i` 取 `s[i]`，`i` 为偶数取正、奇数取负，一遍扫描 O(len) 时间、O(1) 空间，无需转整数。
