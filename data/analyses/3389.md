## 一句话思路
枚举目标频率 k 和保留的字母区间，区间内每个字母用「删/补/改」凑到 k，区间外全删，取最小。

## 怎么做
1. 统计 `cnt[26]`，把「保留哪些字母」枚举成一段连续区间 `[i, j]`（共 325 种）。
2. 对每个区间枚举目标频率 `k`，只取 `k ∈ {cnt[x] for x in 区间}`，因为最优 k 必等于某个原始计数。
3. 区间内每个字母 x 花 `abs(cnt[x]-k)`（少了补、多了删）；区间外每个字母花 `cnt[x]`（全删）。
4. 三者求和取全局最小。

以 `s = "aaabc"` 为例：`cnt = [3,1,1,0,...]`。取区间 `[0,2]`、`k=1`：a 花 `3-1=2`，b 花 0，c 花 0，区间外全 0，合计 2，与答案一致。注意这里 a 的 2 次是「删 1 个 + 改 1 个」，不是两次删除——改出来的 b 正好补上 b 的缺口，所以 `abs` 直接可用。

```python
cnt = [0] * 26
for ch in s:
    cnt[ord(ch) - 97] += 1
best = len(s)
for i in range(26):
    for j in range(i, 26):
        outside = sum(cnt[x] for x in range(26) if x < i or x > j)
        for k in set(cnt[x] for x in range(i, j + 1)):
            if k == 0:
                continue
            cost = outside + sum(abs(cnt[x] - k) for x in range(i, j + 1))
            best = min(best, cost)
```

## 复杂度
时间：O(26² · 26 · 26) 常数级，与 n 无关；n 只花在统计 cnt 上。
空间：O(26) 的 cnt 数组，无额外结构。

## 易错点
- 输入 `"aaabc"` 若只枚举「所有字母同频」而不枚举区间，会算出 3（把 b、c 都改成 a 或都删），错过 2。正确做法是必须枚举连续区间，因为「改」只能向字母表后方走，区间外的字母无法低成本补进来。
- 输入 `"acab"` 若允许 k 取任意 1..n 而不限于原始计数，会多算无用分支；更隐蔽的坑是 k=0 时区间内字母全删，与「区间外全删」重复计数，必须 `continue` 跳过 k=0。

## 如果面试官追问
问：若允许 'z' 变 'a'（环形）怎么做？
答：区间枚举失效，需改成对 26 个字母做环形 DP 或枚举断点，复杂度升到 O(26³)。
