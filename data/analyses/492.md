## 一句话思路
从 `isqrt(area)` 向下枚举第一个能整除 `area` 的 `w`，此时 `L=area//w` 与 `w` 差距最小。

## 怎么做
1. 令 `w = isqrt(area)`，从平方根开始向下找，因为差距最小的因子对必然夹在平方根两侧。
2. 每次 `w` 减 1，直到 `area % w == 0`，此时 `w` 是 ≤ 平方根的最大因子。
3. 返回 `[area // w, w]`，长度取大者，天然满足 `L >= W`。

以 `area = 122122` 为例：`isqrt(122122) = 349`，从 349 往下试，349、348… 都不整除，直到 `w = 286` 时 `122122 % 286 == 0`，得 `L = 122122 // 286 = 427`，输出 `[427, 286]`，与官方示例一致。中间跳过的每个 `w` 都只做一次取模，代价极低。

```python
from math import isqrt

def constructRectangle(area: int):
    w = isqrt(area)
    while area % w != 0:
        w -= 1
    return [area // w, w]
```

关键就三行：起点 `isqrt`、循环条件 `area % w != 0`、返回 `[area // w, w]`。不要从 1 往上枚举到 `area`，那样在 `area = 10**7` 且为质数附近会退化到上万次以上无谓循环；从平方根向下，质数情形只需从 `isqrt(area)` 走到 1。

## 复杂度
时间：O(√area) 最坏（如 area 为大质数时从 isqrt 走到 1），每次 O(1) 取模。
空间：O(1)，只存 `w` 和结果数组两个整数。

## 易错点
- 输入 `area = 4` 时若从 `w = area` 往下找，会先命中 `w = 4` 得 `[1, 4]`，违反 `L >= W`；正确做法是从 `isqrt(area) = 2` 起找，直接得 `[2, 2]`。
- 输入 `area = 37`（质数）时若循环写成 `while area % w != 0 and w > 1` 后忘记处理 `w = 1`，会返回错误或死循环；正确做法是让循环自然走到 `w = 1`（`37 % 1 == 0` 必成立），返回 `[37, 1]`。

## 如果面试官追问
问：若要求返回所有差距最小的方案（可能多组）怎么办？
答：差距最小的因子对唯一（≤√area 的最大因子唯一），无需多组；若改为「差距 ≤ k 的所有方案」，则从 isqrt 向下枚举到 `area // (w + k)` 边界即可。
