## 一句话思路
用两个栈把链表数字倒序压入，再从低位到高位逐位相加，头插法建结果链表。

## 怎么做
1. 遍历 `l1`、`l2`，把每个 `node.val` 分别压入 `s1`、`s2`，栈顶即最低位。
2. 循环条件写成 `while s1 or s2 or carry`，每轮 `x = s1.pop() if s1 else 0`，`y` 同理。
3. `total = x + y + carry`，`carry = total // 10`，新节点值 `total % 10`，用头插接到 `dummy` 之后。
4. 返回 `dummy.next`。

以示例 1 为例：`s1` 弹出顺序是 `3,4,2,7`，`s2` 是 `4,6,5`。第一轮 `x=3,y=4,carry=0`，`total=7`，`carry=0`，头插得 `[7]`；第二轮 `x=4,y=6`，`total=10`，`carry=1`，节点值 `0`，头插得 `[0,7]`；第三轮 `x=2,y=5,carry=1`，`total=8`，得 `[8,0,7]`；第四轮 `s2` 空，`x=7,y=0`，得 `[7,8,0,7]`。头插保证高位在前，正好对上输出。

```python
s1, s2 = [], []
while l1: s1.append(l1.val); l1 = l1.next
while l2: s2.append(l2.val); l2 = l2.next
dummy = ListNode(0)
carry = 0
while s1 or s2 or carry:
    x = s1.pop() if s1 else 0
    y = s2.pop() if s2 else 0
    total = x + y + carry
    carry = total // 10
    node = ListNode(total % 10)
    node.next = dummy.next
    dummy.next = node
return dummy.next
```

## 复杂度
时间 O(max(m,n))，两个栈各弹一遍，长度取 `l1`、`l2` 的较大者。
空间 O(m+n)，两个栈存全部节点值，结果链表另算 O(max(m,n))。

## 易错点
- 输入 `l1=[5], l2=[5]` → 若循环只写 `while s1 or s2`，最后一轮 `carry=1` 被丢掉，输出 `[0]` 而非 `[1,0]` → 条件必须带 `or carry`。
- 输入 `l1=[1], l2=[9,9]` → 若用尾插再反转，容易在反转时把 `dummy` 也带进去或漏掉进位节点 → 直接头插 `dummy.next`，天然高位在前，不用二次反转。

## 如果面试官追问
追问：不能翻转链表、也不能用额外栈怎么办？
答：先各遍历一次求长度差，长链表先走差值步，再同步递归/迭代相加，进位靠返回值向上传，空间降到 O(max(m,n)) 的递归栈。
