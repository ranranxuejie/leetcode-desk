## 一句话思路
按组遍历，用组内反转（头插法）处理偶数长度组，奇数长度组原样跳过。

## 怎么做
1. 用 `prev` 指向当前组前一个节点，`group_len` 从 1 递增，每组先数出实际长度 `cnt`（不超过 `group_len`）。
2. 若 `group_len` 为偶数，从 `prev.next` 开始把 `cnt` 个节点头插到 `prev` 后面实现反转；否则直接走 `cnt` 步。
3. 更新 `prev` 到本组最后一个节点，`group_len += 1`，直到 `prev.next` 为 `None`。

以示例 1 为例，处理到第 4 组时 `prev` 指向节点 1，`cnt = 4`，反转后 `prev.next` 从 7 变为 4，组内顺序 7→3→8→4 变成 4→8→3→7。

```python
dummy = ListNode(0, head)
prev, group_len = dummy, 1
while prev.next:
    node, cnt = prev.next, 0
    while node and cnt < group_len:
        node, cnt = node.next, cnt + 1
    if group_len % 2 == 0:
        cur = prev.next
        for _ in range(cnt - 1):
            nxt = cur.next
            cur.next = nxt.next
            nxt.next = prev.next
            prev.next = nxt
    for _ in range(cnt):
        prev = prev.next
    group_len += 1
return dummy.next
```

## 复杂度
时间 O(n)：每个节点被数一次、走一次，共两趟。
空间 O(1)：只用了 `dummy`、`prev`、`cur`、`nxt` 几个指针。

## 易错点
- 最后一组长度不足：如 `[1,1,0,6]` 第 3 组只剩 1 个节点，若按 `group_len=3` 硬走会访问 `None` 崩溃 → 必须先数出 `cnt = min(group_len, 剩余)` 再判断反转。
- 反转后 `prev` 位置：如示例 1 第 2 组反转后，`prev` 应停在节点 2（新组尾），若停在旧尾节点 6 会导致下一组起点错位 → 反转后统一用 `for _ in range(cnt): prev = prev.next` 推进。

## 如果面试官追问
若要求组长度从 0 开始（0,1,2,...）怎么办？答：`group_len` 初值改 0，偶数判断不变，第 0 组长度 0 直接跳过即可。
