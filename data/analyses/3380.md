## 一句话思路
n≤10，直接枚举四个点当矩形顶点，再用「矩形内无其他点」这一条件过滤，取最大面积。

## 怎么做
1. 把 points 转成集合 `S`，便于 O(1) 判断某个坐标是否存在。
2. 四重循环枚举 `(x1,y1),(x1,y2),(x2,y1),(x2,y2)` 四个顶点，要求 `x1<x2`、`y1<y2` 且四点都在 `S` 中。
3. 对每个候选矩形，遍历所有点，若存在点 `(x,y)` 满足 `x1<=x<=x2 and y1<=y<=y2` 且不是四个顶点之一，则淘汰。
4. 用 `(x2-x1)*(y2-y1)` 更新答案，初始 `ans=-1`。

以示例 3 为例：枚举到 `x1=1,x2=3,y1=2,y2=3` 时，四点 `(1,2),(1,3),(3,2),(3,3)` 都在 `S` 中；再扫其余点 `(1,1),(3,1)`，它们的 y 都小于 2，落在矩形外，于是面积 `(3-1)*(3-2)=2` 被采纳。而 `x1=1,x2=3,y1=1,y2=3` 这组会被 `(1,2)` 命中内部而淘汰。

```python
S = set(map(tuple, points))
ans = -1
for x1, y1 in points:
    for x2, y2 in points:
        if x2 <= x1 or y2 <= y1:
            continue
        if (x1, y2) not in S or (x2, y1) not in S:
            continue
        ok = True
        for x, y in points:
            if x1 <= x <= x2 and y1 <= y <= y2 and (x, y) not in ((x1,y1),(x1,y2),(x2,y1),(x2,y2)):
                ok = False
                break
        if ok:
            ans = max(ans, (x2 - x1) * (y2 - y1))
```

## 复杂度
时间：O(n^3)，枚举两对角点 O(n^2)，每个候选扫一遍点 O(n)。
空间：O(n)，集合 `S` 存全部坐标。

## 易错点
- 边界点也算「包含」：示例 3 中 `(1,2)` 落在 `x1=1` 这条边上，若只判严格内部 `x1<x<x2`，就会误把面积 4 的矩形判为合法，答案错成 4。必须用 `<=`。
- 四个顶点本身会被自己的扫描命中：若不排除 `(x1,y1)` 等四点，任何矩形都会被判非法，示例 1 会输出 -1 而非 4。判断时要显式跳过这四个坐标。

## 如果面试官追问
若 n 放大到 2000 怎么办？答：按 x 分组枚举左右两条竖边，用有序结构维护两列 y 的交集并检查区间内是否夹点，配合树状数组把 O(n^3) 降到 O(n^2 log n)。
