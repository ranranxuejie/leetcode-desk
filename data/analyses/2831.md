## 一句话思路
按值分组记录下标，对每组用滑动窗口找「下标跨度 − 元素个数 ≤ k」的最长窗口。

## 怎么做
1. 用字典 `pos` 把每个值映射到它出现的下标列表，遍历一次 `nums` 即可。
2. 对每个值的下标列表 `p`，维护窗口 `[l, r]`，窗口内元素个数是 `r-l+1`，需要删除的是 `p[r]-p[l]-(r-l)`。
3. 该值超过 `k` 就右移 `l`，否则更新答案 `r-l+1`。
4. 以示例 1 的 `nums = [1,3,2,3,1,3], k = 3` 为例，`pos[3] = [1,3,5]`：`r=2, l=0` 时跨度为 `5-1=4`，元素 3 个，需删 `4-2=2 ≤ 3`，窗口长 3，答案取 3。

```python
pos = {}
for i, x in enumerate(nums):
    pos.setdefault(x, []).append(i)

ans = 0
for p in pos.values():
    l = 0
    for r in range(len(p)):
        while p[r] - p[l] - (r - l) > k:
            l += 1
        ans = max(ans, r - l + 1)
```

## 复杂度
时间：O(n)，每个下标最多被 `l` 和 `r` 各扫一次，字典分组也是 O(n)。
空间：O(n)，`pos` 存下全部 n 个下标。

## 易错点
- 把「删除数」算成 `p[r]-p[l]+1-(r-l+1)` 之外的量，或直接用 `p[r]-p[l]` 当删除数 → 示例 1 的 `pos[3]=[1,3,5]` 会算成 4 而误判超限 → 正确是跨度减元素个数 `p[r]-p[l]-(r-l)`。
- 忘记 `k=0` 时窗口只能取连续相同元素 → 如 `nums=[1,2,1], k=0` 会错答 2 → 此时 `p=[0,2]`，跨度 2 减元素 1 得 1 > 0，必须收缩到长度 1。

## 如果面试官追问
若要求输出具体删除哪些下标？答：在最优窗口内，把 `p[l]` 到 `p[r]` 之间不属于该值的下标全部收集起来返回即可。
