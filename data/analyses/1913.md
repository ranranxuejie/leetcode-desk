## 一句话思路
排序后取最大的两个数相乘、最小的两个数相乘，两者相减即为答案。

## 怎么做
1. 对 `nums` 升序排序，最大值必在两端。
2. 最大乘积取 `nums[-1] * nums[-2]`，最小乘积取 `nums[0] * nums[1]`。
3. 返回两者之差。

以 `nums = [5,6,2,7,4]` 为例，排序后为 `[2,4,5,6,7]`，最大乘积 `7*6=42`，最小乘积 `2*4=8`，差 `42-8=34`，与示例一致。

```python
nums.sort()
return nums[-1] * nums[-2] - nums[0] * nums[1]
```

关键点：四个下标必须不同，取最大两个和最小两个天然满足；由于 `nums[i] >= 1`，全为正数，最小乘积一定来自最小的两个数，无需考虑负数配对。

## 复杂度
时间：O(n log n)，排序贡献。
空间：O(1) 额外（排序原地，不计排序栈）。

## 易错点
- 输入含负数时（本题约束 `nums[i] >= 1` 不会出现）→ 若照搬「最小两个相乘」会错，因为两个负数相乘可能很大 → 正确做法是同时比较 `nums[0]*nums[1]` 与 `nums[-1]*nums[-2]` 作为候选最大乘积。
- 数组长度恰为 4 时 → 若误以为要跳过重复值或去重，会漏掉合法下标 → 正确做法是直接用排序后首尾各两个，四个下标天然互异。

## 如果面试官追问
问：若要求返回具体的四个下标而非差值？答：排序前记录每个值的原始下标，取最大两个和最小两个对应的下标即可，注意去重。
