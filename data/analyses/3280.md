## 一句话思路
按 `-` 切出三段，各自 `int()` 后 `bin()[2:]`，因为 Python 的 `bin` 天然不带前导零。

## 怎么做
1. `date.split('-')` 得到 `['2080', '02', '29']`，注意月和日带前导零，必须转 `int` 才能去掉。
2. 对每段调 `int(x)`，`'02'` 变成 `2`，`'29'` 变成 `29`。
3. 用 `bin(n)[2:]` 取二进制，`bin(2080)` 是 `'0b100000100000'`，切片后 `'100000100000'`；`bin(2)` 是 `'0b10'` → `'10'`。
4. 用 `'-'.join(...)` 拼回，得到 `'100000100000-10-11101'`。

关键中间值：`int('02') == 2`，若跳过这步直接 `bin('02')` 会抛 `TypeError`；而 `bin(2)[2:] == '10'` 而不是 `'010'`，前导零由 `bin` 自动消除。

```python
def convertDateToBinary(date):
    y, m, d = date.split('-')
    return '-'.join(bin(int(x))[2:] for x in (y, m, d))
```

`bin(int('1900'))[2:]` 得 `'11101101100'`，`bin(int('01'))[2:]` 得 `'1'`，与示例 2 一致。

## 复杂度
时间：O(n)，n 为 `date` 长度 10，三次 `bin` 各处理 ≤11 位。
空间：O(1)，只开三个短字符串，输出长度 ≤ 11+1+7+1+7。

## 易错点
- 输入 `"1900-01-01"` → 若对 `'01'` 直接做 `bin('01')` 会 `TypeError`，或误以为要保留 `'01'` 的两位而输出 `'1-01-01'` → 正确做法是先 `int()` 再 `bin()`，`'01'` 必须变成 `1`。
- 输入 `"2080-02-29"` → 若用 `format(n, 'b')` 之外的 `'{:08b}'` 之类补零格式，会输出 `'00000010'` 而非 `'10'` → 正确做法是用 `bin(n)[2:]` 或 `format(n, 'b')`，两者都不补前导零。

## 如果面试官追问
问：若日期范围扩到公元 1 年，代码要改吗？
答：不用改，`bin` 对任意正整数都成立，只需保证 `int()` 解析不依赖固定两位。
