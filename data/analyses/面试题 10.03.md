## 一句话思路
在旋转数组上做二分，靠 `arr[mid]` 与 `arr[lo]`、`arr[hi]` 的大小关系判断哪半边有序，再决定收缩方向。

## 怎么做
1. 用 `lo, hi = 0, len(arr) - 1` 和 `ans = -1` 开区间二分，命中时记录 `ans = mid` 并继续向左找更小索引。
2. 每轮先处理重复：若 `arr[lo] == arr[mid] == arr[hi]`，则 `lo += 1; hi -= 1` 后 `continue`。
3. 若 `arr[lo] <= arr[mid]`，左半有序：`target` 落在 `[arr[lo], arr[mid])` 就 `hi = mid - 1`，否则 `lo = mid + 1`。
4. 否则右半有序：`target` 落在 `(arr[mid], arr[hi]]` 就 `lo = mid + 1`，否则 `hi = mid - 1`。

以示例 1 的 `arr = [15,16,19,20,25,1,3,4,5,7,10,14], target = 5` 为例：首轮 `lo=0, hi=11, mid=5`，`arr[mid]=1`，`arr[lo]=15 > arr[mid]` 走第 4 步，`5` 不在 `(1,14]` 里，于是 `lo = 6`；下一轮 `mid=8` 命中 `arr[8]=5`，`ans=8`，再向左收缩确认没有更小的 5。

```python
lo, hi, ans = 0, len(arr) - 1, -1
while lo <= hi:
    mid = (lo + hi) // 2
    if arr[lo] == arr[mid] == arr[hi]:
        lo += 1
        hi -= 1
    elif arr[lo] <= arr[mid]:
        if arr[lo] <= target < arr[mid]:
            hi = mid - 1
        else:
            lo = mid + 1
    else:
        if arr[mid] < target <= arr[hi]:
            lo = mid + 1
        else:
            hi = mid - 1
    if arr[mid] == target:
        ans = mid
```

## 复杂度
时间：平均 O(log n)，最坏 O(n)（全相同元素时靠 `lo += 1` 线性剥离）。
空间：O(1)，只开了 `lo/hi/mid/ans` 四个变量。

## 易错点
- 输入 `arr = [1,1,1,1,3,1], target = 3` → 若只写 `arr[lo] <= arr[mid]` 分支而不先判 `arr[lo]==arr[mid]==arr[hi]`，会误判左半有序、把 `hi` 收缩到 3 左边而漏掉答案 → 必须先做三值相等剥离。
- 输入 `arr = [5,5,5,1,5], target = 5` → 命中 `mid` 后直接 `return mid` 会返回索引 2 或 4，而正确答案是最小索引 0 → 命中只记 `ans = mid` 并继续 `hi = mid - 1` 向左找。

## 如果面试官追问
问：数组无重复元素时能否去掉剥离分支？答：能，`arr[lo] <= arr[mid]` 与 `arr[mid] <= arr[hi]` 必有一真，直接二分 O(log n)。
