## 一句话思路
用 WHERE 同时过滤 `id % 2 = 1` 和 `description != 'boring'`，再 ORDER BY rating DESC。

## 怎么做
1. 先筛 id 为奇数：`id % 2 = 1`，示例中 id=2、4 被排除，剩 1、3、5。
2. 再筛描述非 boring：`description != 'boring'`，id=3 的 `'boring'` 被剔除，剩 1、5。
3. 按 rating 降序：`ORDER BY rating DESC`，9.1 排在 8.9 前，输出 5、1。
4. 两个条件用 AND 连接，顺序不影响结果，但先写 id 条件更直观。

```python
# 伪 SQL 思路，落到具体列名
# SELECT * FROM cinema
# WHERE id % 2 = 1 AND description != 'boring'
# ORDER BY rating DESC;

# 若用 pandas 模拟：
# df[(df['id'] % 2 == 1) & (df['description'] != 'boring')].sort_values('rating', ascending=False)
```

关键中间值：对 id=3 这行，`id % 2 = 1` 为 True，但 `description != 'boring'` 为 False，AND 后整体 False，被丢弃；对 id=5，两个条件都为 True，保留并以 rating=9.1 排第一。

## 复杂度
时间：O(n log n)，n 为行数，排序贡献 log n。
空间：O(n)，排序/结果集额外占用。

## 易错点
- 用 `description = 'boring'` 取反 → 会把 id=3 的 boring 影片留下、把正常影片全删掉 → 正确写 `!= 'boring'` 或 `NOT LIKE '%boring%'`（若描述含 boring 子串需按题意判断）。
- 忘记 `id % 2 = 1` 只写排序 → 输出会包含 id=2、4 的偶数行（如 Science 8.5、Ice song 8.6）混进结果 → 必须同时加奇偶条件。

## 如果面试官追问
问：若 description 里出现 `'not boring'` 这种含 boring 子串但语义相反的情况怎么办？
答：改用精确匹配 `description != 'boring'`，不要用 `LIKE '%boring%'`，避免误杀。
