## 一句话思路
用集合存已见过的数，对每个 `x` 查 `2*x` 或 `x//2`（x 为偶数时）是否已在集合里。

## 怎么做
1. 建空集合 `seen`，遍历 `arr` 的每个元素 `x`。
2. 若 `2*x in seen` 或（`x % 2 == 0` 且 `x // 2 in seen`），立即返回 `True`。
3. 否则把 `x` 加入 `seen`，继续。
4. 遍历结束返回 `False`。

以 `arr = [10,2,5,3]` 为例：处理 `10` 时 `seen` 为空，存入 `{10}`；处理 `2` 时查 `4` 和 `1` 都不在，存入 `{10,2}`；处理 `5` 时查 `10 in seen` 命中，返回 `True`。注意这里 `10` 是先出现的，所以查 `2*x` 这一支才是关键——不能只查 `x//2`。

```python
seen = set()
for x in arr:
    if 2 * x in seen or (x % 2 == 0 and x // 2 in seen):
        return True
    seen.add(x)
return False
```

关键点：两个方向都要查。`x` 可能是那个「大数」（查 `x//2`），也可能是「小数」（查 `2*x`）。先查后存保证 `i != j`，同一个下标不会被自己匹配。

## 复杂度
时间 O(n)：一次遍历，每个元素做两次 O(1) 集合查询。
空间 O(n)：`seen` 最坏存下全部 n 个不同元素。

## 易错点
- 输入 `arr = [0,0]` → 若先 `add` 再查，`0` 会和自己匹配，错判 `True` 且违反 `i != j`；正确做法是先查后存，第一个 `0` 存入后第二个 `0` 查 `2*0=0` 命中，此时确实是两个不同下标，答案 `True` 合法。
- 输入 `arr = [3,1,7,11]` → 若只查 `x//2` 不查 `2*x`，或漏掉 `x % 2 == 0` 判断导致 `3//2=1` 误命中 `1`，会错判 `True`；正确做法是 `x` 为奇数时只查 `2*x`，偶数时两支都查。

## 如果面试官追问
问：若要求返回具体下标对而非布尔值？
答：集合改存 `值 -> 下标`，命中时返回 `(seen[2*x], i)` 或 `(i, seen[x//2])`，同样先查后存。
