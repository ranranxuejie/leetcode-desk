## 一句话思路
用数学结论：尽量拆成 3，余 1 时把 3+1 换成 2+2，避免出现因子 1。

## 怎么做
1. 特判 n=2、n=3，直接返回 1、2，因为必须拆成至少两个数。
2. 循环：n > 4 时不断取 `n -= 3`，把 3 累乘进 `res`。
3. 循环结束后返回 `res * n`，此时 n 只剩 2、3、4 三种情况。
4. 以 n=10 为例：10>4 取 3，res=3、n=7；7>4 取 3，res=9、n=4；4 不满足 >4 退出，返回 9*4=36。

```python
def integerBreak(n):
    if n == 2:
        return 1
    if n == 3:
        return 2
    res = 1
    while n > 4:
        res *= 3
        n -= 3
    return res * n
```

关键中间值：n=10 时循环两轮后 `res=9, n=4`，最后 `9*4=36`，正好对应 3+3+4。

## 复杂度
时间：O(n)，循环每轮 n 减 3，共约 n/3 轮。
空间：O(1)，只开了 res 和 n 两个变量。

## 易错点
- 输入 n=3 → 若直接套「全拆 3」会返回 3，但 k>=2 必须拆，正确是 1+2=2；n=2 同理返回 1，必须先特判。
- 输入 n=4 → 若循环条件写成 `n >= 4` 会继续拆成 3+1，乘积 3 小于 4；正确是 `n > 4` 时退出，让 4 整体保留（或拆 2+2）。

## 如果面试官追问
问：要求输出具体的拆分方案怎么办？
答：同样先贪心取 3，记录每轮减去的 3，最后把剩余的 2/3/4 作为一个因子加入列表即可。
