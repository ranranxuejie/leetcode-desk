## 一句话思路
用 `i` 表示 longer 的块数，长度是 `shorter*k + i*(longer-shorter)`，`i` 从 0 到 k 递增即天然有序。

## 怎么做
1. 先处理 `k == 0`，返回 `[]`（一块板都没有，长度无从谈起）。
2. 再处理 `shorter == longer`，此时所有组合长度都是 `shorter*k`，只返回这一个值，否则下面会生成 k+1 个重复值。
3. 令 `diff = longer - shorter`，枚举 `i in range(k+1)`，第 `i` 项为 `shorter*k + i*diff`。
4. 因为 `diff >= 0`，`i` 递增时结果单调不减，直接按序 append 即可，无需排序。

以官方示例 `shorter=1, longer=2, k=3` 为例：`diff=1`，基准 `shorter*k=3`；`i=0` 得 3，`i=1` 得 4，`i=2` 得 5，`i=3` 得 6，输出 `[3,4,5,6]`。

```python
if k == 0:
    return []
if shorter == longer:
    return [shorter * k]
diff = longer - shorter
base = shorter * k
return [base + i * diff for i in range(k + 1)]
```

关键点：`i` 是 longer 的块数而不是 shorter 的块数，两者只是差一个反向遍历，但用 longer 计数时 `diff` 为正，递增方向与「从小到大」一致。

## 复杂度
时间 O(k)：枚举 k+1 种 longer 块数，每项 O(1) 计算。
空间 O(k)：除返回列表外无额外结构，列表本身 k+1 个元素。

## 易错点
- 输入 `k = 0` → 若直接进循环会返回 `[0]` 或 `[shorter*0]`，但 0 块板不存在任何长度 → 必须先判 `k == 0` 返回 `[]`。
- 输入 `shorter == longer`（如 `shorter=2, longer=2, k=3`）→ 若照常枚举会返回 `[6,6,6,6]` 四个重复值 → 必须特判只返回 `[shorter*k]` 一个元素。

## 如果面试官追问
问：若 k 增大到 10^9，还能枚举吗？
答：不能，输出本身就有 10^9 项，只能改成按需返回第 i 项 `shorter*k + i*(longer-shorter)` 的生成器。
