## 一句话思路
用单调递减栈存 `(price, span)`，新价格弹出所有 ≤ 它的项并把跨度累加，栈顶即答案。

## 怎么做
1. 初始化 `self.stack = []`，元素是 `(price, span)` 二元组，保证栈内价格严格递减。
2. 每次 `next(price)` 先令 `span = 1`（今天自己算一天）。
3. 循环 `while self.stack and self.stack[-1][0] <= price`：弹出栈顶，`span += 弹出的 span`。
4. 把 `(price, span)` 压栈并返回 `span`。

用官方示例走关键一步：处理到 `next(75)` 时，栈内是 `[(100,1),(80,1),(70,2),(60,1)]`。`75` 依次弹出 `(60,1)`、`(70,2)`，`span = 1+1+2 = 4`；此时栈顶 `80 > 75` 停止，压入 `(75,4)` 返回 4。下一次 `next(85)` 弹出 `(75,4)`、`(80,1)`，`span = 1+4+1 = 6`，与输出一致。

```python
def next(self, price):
    span = 1
    while self.stack and self.stack[-1][0] <= price:
        span += self.stack.pop()[1]
    self.stack.append((price, span))
    return span
```

关键点：被弹出的那些天，其跨度已经「合并」进了 `span`，所以后面再也不用单独看它们——这正是每个元素只进栈出栈一次的原因。

## 复杂度
时间：均摊 O(1) 每次 `next`，n 次调用共 O(n)，每个元素最多入栈出栈一次。
空间：O(n)，栈最多存 n 个 `(price, span)` 二元组。

## 易错点
- 比较写成 `<` 而不是 `<=`：输入 `[100,80,60,70,60,75,85]` 处理 `next(70)` 时，若用 `<` 不会弹出 `(60,1)`，返回 1 而非 2。题目要求「小于或等于」，必须 `<=`。
- 只存价格不存跨度：输入 `[7,2,1,2]` 到最后一个 `2` 时，若栈里只有价格，弹出 `1`、`2` 后无法知道它们各自代表几天，会返回 2 而非 4。正确做法是压栈时把 `span` 一起存，弹出时累加。

## 如果面试官追问
问：如果要求支持「删除最近 k 天」怎么办？
答：单调栈无法回退，需改用可持久化栈或按天存前缀结构，代价是空间升到 O(n log n)。
