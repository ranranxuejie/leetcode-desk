## 一句话思路
一次线性扫描，用 `start` 记录当前分组起点，遇到字符变化时结算长度，长度 ≥3 就收进答案。

## 怎么做
1. 初始化 `start = 0`，答案 `res = []`，循环 `i` 从 1 到 `len(s)`（注意取到 `len(s)`，让末尾分组也能结算）。
2. 当 `i == len(s)` 或 `s[i] != s[start]` 时，当前分组是 `[start, i-1]`，长度 `i - start`。
3. 若 `i - start >= 3`，把 `[start, i-1]` 追加到 `res`；随后令 `start = i`。
4. 循环结束返回 `res`，天然按起点递增。

以 `s = "abbxxxxzzy"` 为例：`start=0`；`i=1` 时 `s[1]='b' != s[0]='a'`，长度 1 丢弃，`start=1`；`i=2` 时 `s[2]='b' == s[1]` 跳过；`i=3` 时 `s[3]='x' != s[1]='b'`，长度 `3-1=2` 丢弃，`start=3`；`i=7` 时 `s[7]='z' != s[3]='x'`，长度 `7-3=4 >= 3`，收 `[3,6]`，`start=7`。关键中间值就是 `i - start = 4` 和区间右端 `i-1 = 6`。

```python
res, start = [], 0
for i in range(1, len(s) + 1):
    if i == len(s) or s[i] != s[start]:
        if i - start >= 3:
            res.append([start, i - 1])
        start = i
return res
```

## 复杂度
时间 O(n)：`i` 从 1 走到 `len(s)`，每个下标只被比较一次。
空间 O(1)：除 `res` 外只用 `start`、`i` 两个整数，`res` 不计入额外空间。

## 易错点
- `s = "aaa"` → 若循环只写 `range(1, len(s))`，末尾分组永不结算，返回 `[]`；正确做法是把上界写成 `len(s) + 1`，用 `i == len(s)` 兜住最后一个分组，得到 `[[0,2]]`。
- `s = "aaabbb"` → 若在 `s[i] != s[start]` 分支里先 `start = i` 再算长度，长度会变成 0，两个分组都丢失；正确做法是先算 `i - start`、判断 ≥3、追加 `[start, i-1]`，最后才更新 `start = i`。

## 如果面试官追问
问：若要求返回每个较大分组的字符和长度而非区间？
答：结算时把 `[start, i-1]` 换成 `(s[start], i - start)` 即可，扫描逻辑和边界完全不变。
