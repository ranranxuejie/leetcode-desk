## 一句话思路
枚举被击破节点，用「原层和 + 子树整体上移一层的增量」O(1) 更新答案，增量靠每层前缀和预处理。

## 怎么做
1. 先 BFS 求出原树每层和 `base[d]`，答案初值取 `max(base)`。
2. 对每个节点 `u`（深度 `d`），击破它等价于把 `u` 的子树整体上移一层：第 `d+k` 层少掉 `u` 子树在第 `k` 层的贡献，第 `d+k-1` 层多出同一份贡献。
3. 所以只需知道 `u` 子树在每一层的节点值之和 `sub[u][k]`，用后序 DFS 合并左右儿子的层数组（右移一位再加 `u.val`）得到。
4. 对每个 `u` 逐层累加 `base[d+k-1] + sub[u][k]` 与 `base[d+k] - sub[u][k]` 的最大值，取全局最大。

以示例 2 的 `6` 节点（深度 1）为例：`sub = [6, 4]`（第 1 层 6，第 2 层 4）。击破后第 1 层变 `5+2+4=11` 的候选被第 2 层 `3+5+1=9` 压过，最终答案 9。

```python
def dfs(u, d):
    res = [u.val]                      # 第 d 层起的子树层和
    for v in (u.left, u.right):
        if v:
            t = dfs(v, d + 1)
            for k, x in enumerate(t):
                if k + 1 == len(res): res.append(0)
                res[k + 1] += x
    # 用 res 更新答案：res[k] 从第 d+k 层搬到第 d+k-1 层
    for k, x in enumerate(res):
        ans = max(ans, base[d + k - 1] + x if d + k else -10**18,
                       base[d + k] - x if d + k < len(base) else -10**18)
    return res
```

## 复杂度
时间：每个节点只在自己祖先链的层数上被合并一次，均摊 O(n log n)，链状树退化为 O(n²) 需注意。
空间：层数组总长 O(n log n)，递归栈 O(n)。

## 易错点
- 输入是长链（如 10^5 个节点全在左子树）→ 层数组长度 O(n)、合并 O(n²) 超时 → 用「小数组往大数组并」的启发式合并，或改用树上差分按层统计。
- 根节点被击破时 `d+k-1 = -1` → 下标越界或把第 0 层算进答案 → 单独判断 `d == 0` 时只更新 `base[k] - x` 那一项，且答案允许不击破（取 `max(base)` 兜底）。

## 如果面试官追问
要求输出具体击破哪个节点？答：在更新 `ans` 时同步记录 `(u, 层偏移)`，回溯即可还原方案。
