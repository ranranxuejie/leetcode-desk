## 一句话思路
用 `dp[i]` 表示「站到第 i 阶（尚未支付 cost[i]）的最小花费」，从 `dp[0]=dp[1]=0` 递推到 `dp[n]`。

## 怎么做
1. 定义状态：`dp[i]` 是到达下标 i 这个位置时已经花掉的钱，注意此时**还没付** `cost[i]`。
2. 起点：`dp[0] = dp[1] = 0`，因为可以直接从 0 或 1 起步，不需要先付钱。
3. 转移：`dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])`，即从 i-1 或 i-2 迈上来，付的是**离开那一阶**的钱。
4. 答案：`dp[n]`，n = len(cost)，顶部是下标 n，不需要付 `cost[n]`（不存在）。

拿 `cost = [10, 15, 20]` 走一遍关键一步：`dp[2] = min(dp[1] + cost[1], dp[0] + cost[0]) = min(0 + 15, 0 + 10) = 10`；再算 `dp[3] = min(dp[2] + cost[2], dp[1] + cost[1]) = min(10 + 20, 0 + 15) = 15`，输出 15，与示例一致。

```python
n = len(cost)
dp = [0] * (n + 1)
for i in range(2, n + 1):
    dp[i] = min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2])
return dp[n]
```

滚动变量版只需两个数：`prev2, prev1 = 0, 0`，循环里 `prev2, prev1 = prev1, min(prev1 + cost[i-1], prev2 + cost[i-2])`，最后返回 `prev1`。

## 复杂度
时间 O(n)：i 从 2 走到 n，每个下标做一次 min。
空间 O(n)：dp 数组长度 n+1；滚动变量版降到 O(1)。

## 易错点
- 把 `dp[i]` 理解成「付完 cost[i] 之后的花费」→ 转移会写成 `dp[i] = cost[i] + min(dp[i-1], dp[i-2])`，对 `[10,15,20]` 算出 `dp[2]=20`、答案 20 而非 15 → 正确做法是 `dp[i]` 表示到达 i 时未付 `cost[i]`，转移里加的是 `cost[i-1]` 和 `cost[i-2]`。
- 初始化写成 `dp[0]=cost[0], dp[1]=cost[1]` → 对 `[10,15,20]` 会得到 `dp[3]=min(10+20, 15+15)=30`，把起步费重复算了一次 → 正确做法是 `dp[0]=dp[1]=0`，起步免费，钱只在「离开某阶」时付。

## 如果面试官追问
问：要求返回具体走了哪些台阶怎么办？
答：dp 时额外存 `from[i]` 记录 i 是从 i-1 还是 i-2 转移来的，从 n 倒推回 0/1 即得路径。
