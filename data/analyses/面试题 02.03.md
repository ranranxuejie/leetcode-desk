## 一句话思路
把后继节点的值复制到当前节点，再跳过后继节点，等价于删掉自己。

## 怎么做
1. 把 `node.next.val` 赋给 `node.val`，让当前节点"变成"后继节点。
2. 把 `node.next` 指向 `node.next.next`，跳过原来的后继节点。
3. 传入节点被摘出链表，链表长度减一。

以官方示例 `4->5->1->9`、传入节点 `5` 为例：执行 `node.val = node.next.val` 后，节点 `5` 的值变成 `1`，链表逻辑上成为 `4->1->1->9`；再执行 `node.next = node.next.next`，第二个 `1` 被跳过，最终 `4->1->9`。

```python
def deleteNode(node, n):
    node.val = node.next.val
    node.next = node.next.next
```

关键中间值：赋值前 `node.val == 5`、`node.next.val == 1`；赋值后 `node.val == 1`，`node.next` 指向值为 `9` 的节点。整个过程没有改动 `4` 的 `next` 指针，`4` 仍然指向这个被"改头换面"的节点。

为什么成立：单链表只能从前往后走，拿不到前驱就无法改前驱的 `next`。但题目只要求"删除这个节点"的语义效果，不要求保留节点对象本身，所以把后继的值搬过来、再把后继摘掉，链表序列完全一致。注意题目保证传入的是中间节点，因此 `node.next` 一定非空，不需要判空。

## 复杂度
时间：O(1)，只做了两次指针/值操作，与链表长度 n 无关。
空间：O(1)，没有开任何额外结构。

## 易错点
- 传入的是尾节点（`node.next is None`）→ 执行 `node.next.val` 直接抛 `AttributeError` → 本题保证传入中间节点，若面试官放宽约束需先判 `node.next is None` 并说明无法用此法删除尾节点。
- 先改 `node.next = node.next.next` 再读 `node.next.val` → 读到的是后继的后继的值，示例中会把 `5` 改成 `9`，链表变成 `4->9->9` → 必须先赋值 `node.val`，再改指针，顺序不能颠倒。

## 如果面试官追问
问：如果要真正删除传入的节点对象（保留原节点值不被覆盖）怎么办？
答：必须拿到前驱，从头遍历到 `prev.next is node`，时间退化为 O(n)。
