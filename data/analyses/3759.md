## 一句话思路
排序后，合格元素必然是最小的 n-k 个位置里的值，用二分找第一个满足「严格大于它的元素数 ≥ k」的下标。

## 怎么做
1. 排序 `nums`，此时对下标 `i`，严格大于 `nums[i]` 的元素个数是 `n - bisect_right(nums, nums[i])`。
2. 这个个数随 `i` 增大单调不增，所以合格元素构成前缀，二分找第一个不合格的位置。
3. 用 `bisect_left` 在排序数组上定位阈值：合格条件等价于 `nums[i] < nums[n-k]`（`k>0` 时），答案就是 `bisect_left(nums, nums[n-k])`。

以 `nums=[3,1,2], k=1` 为例：排序得 `[1,2,3]`，`nums[n-k]=nums[2]=3`，`bisect_left([1,2,3], 3)=2`，返回 2。中间值 `n-k=2` 是关键下标，`3` 是分界值。

```python
from bisect import bisect_left

def countElements(nums, k):
    if k == 0:
        return len(nums)
    nums.sort()
    return bisect_left(nums, nums[len(nums) - k])
```

`k=0` 时任何元素都有至少 0 个更大元素，直接返回 `n`，避免 `nums[n]` 越界。

## 复杂度
时间 O(n log n)：排序主导，二分 O(log n)。
空间 O(1) 额外（不计排序栈），原地排序。

## 易错点
- 输入 `nums=[5,5,5], k=2` → 若用 `bisect_right` 或按「大于等于」计数，会误判 5 合格 → 正确用 `bisect_left(nums, nums[n-k])`，重复值整体落在分界右侧，返回 0。
- 输入 `k=0`（如 `nums=[1], k=0`）→ 直接取 `nums[n-k]=nums[1]` 越界 → 先判 `k==0` 返回 `len(nums)`。

## 如果面试官追问
问：不排序能否 O(n)？
答：可以，用快速选择找第 n-k 小作为阈值，再线性统计严格小于它的元素个数。
