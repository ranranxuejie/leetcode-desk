## 一句话思路
按位拼接：每步把当前结果左移 `len(bin(i))-2` 位再或上 `i`，边拼边取模。

## 怎么做
1. 维护 `ans`（已拼接结果对 `10**9+7` 取模）和 `shift`（下一个数要左移的位数）。
2. 遍历 `i` 从 1 到 n，`ans = (ans << shift | i) % MOD`。
3. `i` 是 2 的幂时（`i & (i-1) == 0`），二进制位数加一，`shift += 1`。

以 `n = 3` 为例：初始 `ans=0, shift=1`。`i=1`：`ans = (0<<1|1)=1`，`1&0==0` 故 `shift=2`；`i=2`：`ans = (1<<2|2)=6`，`2&1==0` 故 `shift=3`；`i=3`：`ans = (6<<3|3)=51`？注意 6 的二进制是 `110`，左移 3 位得 `110000`，或上 `11` 得 `110011`=51，但正确答案是 27。问题在于 `i=2` 时 `ans` 应为 `1` 拼 `10` = `110`=6 没错，`i=3` 应拼 `11` 得 `11011`=27。错在 `shift`：`i=3` 只有 2 位，`shift` 应为 2 而非 3。修正：`shift` 表示 `i` 的位数，在拼接 `i` 前用当前 `i` 的位数，即先判断再拼。

```python
MOD = 10**9 + 7
ans, shift = 0, 0
for i in range(1, n + 1):
    if i & (i - 1) == 0:
        shift += 1
    ans = ((ans << shift) | i) % MOD
```

`n=3`：`i=1` 时 `1&0==0` 使 `shift=1`，`ans=(0<<1|1)=1`；`i=2` 时 `2&1==0` 使 `shift=2`，`ans=(1<<2|2)=6`；`i=3` 时 `3&2!=0`，`shift` 仍 2，`ans=(6<<2|3)=27`。正确。

## 复杂度
时间 O(n)，循环 n 次，每次 O(1) 位运算。
空间 O(1)，只开 `ans`、`shift`、`i` 三个变量。

## 易错点
- `n=1` 时若把 `shift` 初值设为 0 且不先判断 2 的幂，`ans=(0<<0|1)=1` 恰好对；但 `n=2` 时若漏判 `i=2` 的位数增长，`ans=(1<<1|2)=4`，错成 4，正确是 6。必须先判 `i & (i-1)==0` 再拼。
- `n=12` 时结果 118505380540 远超 32 位，若中途不取模、最后才取模，Python 虽不溢出但数字巨大拖慢速度；正确做法是每步 `% MOD`，且取模要在移位或运算之后，不能先模 `ans` 再移位（会丢高位）。

## 如果面试官追问
问：n 扩大到 10^18 怎么办？答：不能逐个数，需按二进制位数分段，用等比数列公式一次算出每段整体左移量，O(log n)。
