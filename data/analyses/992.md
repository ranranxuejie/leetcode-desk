## 一句话思路
用「至多 k 个不同」减去「至多 k-1 个不同」，把恰好 k 的计数转成两次单调滑动窗口。

## 怎么做
1. 写辅助函数 `atMost(m)`：返回不同整数个数 ≤ m 的子数组数，用左右指针 `l`、`r` 和 `cnt` 字典维护窗口。
2. `r` 从 0 到 n-1 逐个右移，把 `nums[r]` 计入 `cnt`；当 `len(cnt) > m` 时不断右移 `l` 并减少 `cnt[nums[l]]`，减到 0 就删键。
3. 每个 `r` 处，以 `r` 结尾的合法子数组有 `r - l + 1` 个，累加进答案。
4. 返回 `atMost(k) - atMost(k-1)`。

以 `nums = [1,2,1,2,3], k = 2` 为例，`atMost(2)` 在 `r=4`（值 3）时窗口收缩到 `l=3`，贡献 `4-3+1=2`；`atMost(1)` 只数纯 1 段和纯 2 段，两者相减得 7。

```python
def atMost(m):
    cnt, l, res = {}, 0, 0
    for r, x in enumerate(nums):
        cnt[x] = cnt.get(x, 0) + 1
        while len(cnt) > m:
            y = nums[l]
            cnt[y] -= 1
            if cnt[y] == 0:
                del cnt[y]
            l += 1
        res += r - l + 1
    return res
return atMost(k) - atMost(k - 1)
```

注意 `m = 0` 时 `atMost` 返回 0（`len(cnt) > 0` 恒成立，窗口始终为空），所以 `k = 1` 时 `atMost(0)` 不会出错。

## 复杂度
时间 O(n)：`atMost` 调用两次，每个元素最多被 `l`、`r` 各扫一次。
空间 O(k)：`cnt` 字典最多存 k+1 个键，其余是常数。

## 易错点
- 输入 `nums = [1,2,1,2,3], k = 2` 时若直接用一个窗口数「恰好 k」，会在 `r=4` 遇到 3 时无法区分「丢掉 1 还是丢掉 2」，漏掉 `[2,3]` 这类子数组；正确做法是拆成两次「至多」再相减。
- `k = 1` 时若 `atMost` 里写成 `while len(cnt) >= m` 或忘记处理 `m = 0`，`atMost(0)` 会死循环或返回错误值；正确做法是条件写 `len(cnt) > m`，并让 `m = 0` 时窗口自然收缩到空。

## 如果面试官追问
问：若要求输出所有好子数组而非计数？答：在 `atMost` 里记录每个 `r` 对应的 `l` 区间，两次结果做区间差即可枚举。
