## 一句话思路
把平方值排序后，用「大数占正号位、小数占负号位」的贪心配对，正号位比负号位多一个。

## 怎么做
1. 先对 `nums` 每个元素取平方，得到 `sq`，此时符号信息全部消失，问题变成纯正数分配。
2. 把 `sq` 升序排序，正号位有 `(n+1)//2` 个，负号位有 `n//2` 个。
3. 让最大的 `(n+1)//2` 个数去正号位，剩下的去负号位，得分即两组平方和之差。
4. 用 `sum(sq[k:]) - sum(sq[:k])`（`k = n//2`）一次算出，避免逐个加减。

以 `nums = [1,2,3]` 为例：`sq = [1,4,9]`，`k = 1`，正号位取 `[4,9]` 和 13，负号位取 `[1]`，得分 `13 - 1 = 12`，与示例一致。示例 2 的 `sq = [1,1,4,4,9,9]`，`k = 3`，正号位 `[4,9,9]` 和 22，负号位 `[1,1,4]` 和 6，得分 16。

```python
sq = sorted(x * x for x in nums)
k = len(sq) // 2
return sum(sq[k:]) - sum(sq[:k])
```

关键点：正号位永远比负号位多一个（`n` 为奇数时），所以最大的那个平方值一定在正号位，不会被减掉。

## 复杂度
时间 O(n log n)：排序 `sq` 贡献 log n，取平方和两次求和贡献 n。
空间 O(n)：`sq` 新开一个长度 n 的列表（生成器进 `sorted` 也一样）。

## 易错点
- 输入 `nums = [-3,-1,-2,1,3,2]` 时若直接对原值排序再按正负号分配，会把 `-3` 放到负号位减掉 9；正确做法是先取平方 `sq = [1,1,4,4,9,9]`，符号只由位置决定，与元素原符号无关。
- `n` 为奇数时若写成 `sum(sq[k+1:]) - sum(sq[:k+1])`，会把最大平方值 `sq[-1]` 划进负号位，示例 1 会得 `9 - 5 = 4` 而非 12；正确做法是正号位取 `sq[k:]`，长度恰为 `(n+1)//2`。

## 如果面试官追问
要求输出具体重排方案怎么办？答：把 `sq[k:]` 的元素依次填正号位、`sq[:k]` 填负号位，再按原值符号还原即可，贪心结构不变。
