## 一句话思路
用 `stacks` 列表存各栈，加一个最小堆 `avail` 记录未满栈的下标，push 取堆顶、pop 从尾部回收空栈。

## 怎么做
1. `push(val)`：若 `avail` 非空，取 `i = heapq.heappop(avail)`；否则 `i = len(stacks)` 并新建栈。压入后若该栈未满，把 `i` 重新 push 回 `avail`。
2. `pop()`：先清掉尾部空栈（`while stacks and not stacks[-1]: stacks.pop()`），空则返回 `-1`，否则弹 `stacks[-1]` 顶。
3. `popAtStack(index)`：越界或空栈返回 `-1`；否则弹顶，并把 `index` 塞进 `avail`（它现在未满了）。
4. 关键：`avail` 里可能有已失效的旧下标（栈已被 pop 清空），所以 push 取堆顶后要校验 `len(stacks[i]) < capacity`，不满足就继续弹。

以官方示例走一遍：capacity=2，push 1..5 后 `stacks=[[1,2],[3,4],[5]]`，`avail` 里是 `[2]`（0、1 满）。`popAtStack(0)` 返回 2，`stacks[0]=[1]`，`avail` 变 `[0,2]`。接着 `push(20)` 弹出最小下标 0，压成 `stacks[0]=[1,20]`——这就是「从左往右第一个没满的栈」的正确落点。

```python
def push(self, val):
    while self.avail:
        i = heapq.heappop(self.avail)
        if len(self.stacks[i]) < self.capacity:
            self.stacks[i].append(val)
            if len(self.stacks[i]) < self.capacity:
                heapq.heappush(self.avail, i)
            return
    self.stacks.append([val])
    if self.capacity > 1:
        heapq.heappush(self.avail, len(self.stacks) - 1)
```

## 复杂度
时间：每次 push/popAtStack 均摊 O(log n)，n 为栈个数，堆操作贡献 log n；pop 清空栈均摊 O(1)。
空间：O(总元素数) 存 `stacks`，`avail` 最多 O(n) 个下标。

## 易错点
- `popAtStack(0)` 后再 `push`：若直接 `heappush` 新下标而不校验旧堆顶，会把值压进已满的 `stacks[0]`（示例中 `[1,2]` 已满）→ 必须循环弹出直到找到 `len < capacity` 的栈。
- 连续 `pop()` 把尾部栈清空后，`avail` 里仍留着这些下标 → 下次 push 弹到空栈下标会误判「未满」而压入一个本应被丢弃的位置，导致 `pop()` 从右往左的顺序错乱；正确做法是 push 时校验 `len(stacks[i]) < capacity`，且 `pop()` 里先 `while stacks and not stacks[-1]: stacks.pop()`。

## 如果面试官追问
问：若 `popAtStack` 的 index 可达 10^5 但实际栈数很少，怎么省空间？
答：`stacks` 用 dict 存 `index -> list`，`avail` 仍用堆，越界 index 直接返回 -1。
