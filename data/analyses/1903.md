## 一句话思路
从右往左找第一个奇数数字，它及其左边的整段前缀就是答案，因为奇数只由末位决定。

## 怎么做
1. 从 `num` 末尾往前扫，找第一个满足 `int(num[i]) % 2 == 1` 的下标 `i`。
2. 找不到就返回 `""`，说明整个串全是偶数。
3. 找到就返回 `num[:i+1]`，即从开头截到 `i`（含）。

以 `num = "35427"` 为例：从右扫，`num[4]='7'`，`7 % 2 == 1`，`i = 4`，直接返回 `num[:5]`，即 `"35427"`。再看 `num = "52"`：`num[1]='2'` 是偶数，继续；`num[0]='5'` 是奇数，`i = 0`，返回 `num[:1] = "5"`。

```python
def largestOddNumber(num: str) -> str:
    i = len(num) - 1
    while i >= 0 and int(num[i]) % 2 == 0:
        i -= 1
    return num[:i + 1]
```

关键点：为什么截到 `i` 而不是只取 `num[i]`？因为前缀越长数值越大（无前导零，位数多必大），而末位是 `i` 处的奇数就保证了整个前缀是奇数。所以「最靠右的奇数位」同时满足两个条件：位数最长、末位为奇。

## 复杂度
时间 O(n)：从右往左最多扫完整个 `num`，n 为串长。
空间 O(1)：只用了下标 `i`，返回的切片是结果本身，不算额外空间。

## 易错点
- 输入 `num = "4206"` → 若只判断 `num[-1]` 是否为奇数就返回，会错成 `""` 之外的东西或漏判；正确做法是循环回退到 `i = -1` 再返回 `""`。
- 输入 `num = "1010"` → 若误以为要取「最长的奇数子串」而去找连续段，会错成 `"1"` 之外的答案；正确做法是直接返回 `num[:2] = "10"`？不对——`"10"` 末位是 0 不是奇数。这里 `i = 2`（`num[2]='1'`），返回 `num[:3] = "101"`，它才是最大奇数。别把「前缀」和「连续奇数段」搞混。

## 如果面试官追问
问：如果要求返回所有最大奇数子串的个数怎么办？
答：最大奇数唯一由最右奇数位 `i` 决定，前缀固定，个数恒为 1（或 0），无需改动。
