## 一句话思路
用 `seen` 倒序存正整数、`k` 记连续 `-1` 个数，遇 `-1` 取 `seen[k-1]` 或补 `-1`。

## 怎么做
1. 遍历 `nums`，正整数 `append` 到 `seen` 尾部（等价于插头部，取时倒着数）。
2. 遇 `-1` 时 `k += 1`，否则 `k = 0` 重置。
3. `k <= len(seen)` 就取 `seen[-k]` 追加到 `ans`，否则追加 `-1`。

以 `nums = [1,2,-1,-1,-1]` 为例：处理完 `1,2` 后 `seen == [1,2]`；第三个元素 `-1` 使 `k=1`，取 `seen[-1] == 2`；第四个 `-1` 使 `k=2`，取 `seen[-2] == 1`；第五个 `-1` 使 `k=3`，此时 `len(seen)==2`，`3 > 2` 追加 `-1`，得 `[2,1,-1]`。

```python
seen, ans, k = [], [], 0
for x in nums:
    if x == -1:
        k += 1
        ans.append(seen[-k] if k <= len(seen) else -1)
    else:
        seen.append(x)
        k = 0
return ans
```

关键在 `seen[-k]`：`seen` 尾部是最近的正整数，`k=1` 取最后一个，正好对应题面「第 1 个元素」。

## 复杂度
时间 O(n)：`nums` 每个元素进出一次，`seen` 只追加不删除。
空间 O(n)：`seen` 最多存全部正整数，`ans` 最多存全部 `-1`。

## 易错点
- `nums = [1,-1,2,-1,-1]` → 若忘了遇正整数时 `k = 0`，第二个 `-1` 会当成 `k=2` 取 `seen[-2]`，越界或取错值；正确做法是每遇正整数立刻重置 `k`。
- `nums = [-1]` → 若先写 `seen[-k]` 再判长度，`k=1 > len(seen)=0` 会 `IndexError`；正确做法是先判 `k <= len(seen)` 再取下标，否则直接追加 `-1`。

## 如果面试官追问
若 `nums` 长度升到 10^6 且要求流式处理？答：`seen` 只增不减，内存 O(正整数个数)，无法再压；但可只存正整数、`ans` 边算边输出，省掉 `ans` 的 O(n)。
