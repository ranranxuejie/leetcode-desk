## 一句话思路
BFS 逐层遍历，每层从右往左入队，最后出队的节点就是最底层最左值。

## 怎么做
1. 用 `collections.deque` 初始化队列 `q = deque([root])`，维护 `ans = root.val`。
2. 每轮先记下当前层长度 `size = len(q)`，循环 `size` 次弹出队首节点赋给 `ans`。
3. 入队顺序固定为**先右后左**：`if node.right: q.append(node.right)`，再 `if node.left: q.append(node.left)`。
4. 队列空时 `ans` 即答案。

以示例 2 `[1,2,3,4,null,5,6,null,null,7]` 为例：第 1 层弹出 `1`，入队 `3`、`2`；第 2 层依次弹出 `3`、`2`，入队 `6`、`5`、`4`；第 3 层弹出 `6`、`5`、`4`，只有 `4` 有右孩子 `7`，入队后第 4 层弹出 `7`，`ans` 停在 `7`。关键中间值：第 3 层结束时 `q = deque([7])`，`size = 1`。

```python
from collections import deque

q = deque([root])
ans = root.val
while q:
    size = len(q)
    for _ in range(size):
        node = q.popleft()
        ans = node.val
        if node.right:
            q.append(node.right)
        if node.left:
            q.append(node.left)
return ans
```

先右后左入队，保证同一层里越靠左的节点越晚出队，所以每层最后一个弹出的就是该层最左节点；层数递增，最后一次覆盖的自然是底层。

## 复杂度
时间 O(n)：每个节点入队出队各一次，n 为节点数。
空间 O(w)：队列最多存一层节点，w 为最大层宽，最坏 O(n)。

## 易错点
- 入队写成先左后右 → 示例 2 第 3 层弹出顺序变成 `4,5,6`，`ans` 停在 `6`，错成 6。必须 `right` 先入队，让左节点最后弹出。
- 把 `ans = node.val` 写在 `for` 循环外（每层只更新一次）→ 示例 1 第 1 层弹出 `2` 后 `ans=2`，第 2 层只记第一个弹出的 `3`，错成 3。正确做法是每弹一个节点就更新 `ans`，靠「最后弹出」而非「第一个弹出」定位。

## 如果面试官追问
若要求 O(1) 额外空间怎么办？答：改 DFS，带深度参数，只在 `depth > max_depth` 时更新答案，且先递归左子树，同深度不覆盖。
