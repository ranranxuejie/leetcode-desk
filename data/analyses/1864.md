## 一句话思路
数出 `s` 中 0 和 1 的个数，只有两者差不超过 1 才可能交替；对两种合法目标串分别数「错位的 1」个数，交换次数就是它。

## 怎么做
1. 统计 `s.count('1')` 记为 `ones`，`n = len(s)`，`zeros = n - ones`；若 `abs(ones - zeros) > 1` 直接返回 -1。
2. 交替串只有两种：以 `'1'` 开头（奇数位全是 1）或以 `'0'` 开头；哪种开头合法由 `ones` 与 `zeros` 的大小关系决定。
3. 对每个合法目标串，统计「目标该放 1、但 `s` 这里是 0」的位置数 `mis`；一次交换能同时修正一个错位 0 和一个错位 1，所以交换次数就是 `mis`。
4. 取所有合法目标串的 `mis` 最小值。

以 `s = "111000"` 为例：`ones = 3, zeros = 3`，两种开头都合法。以 `'1'` 开头目标为 `"101010"`，逐位比对得 `mis = 1`（位置 1 该是 0、位置 4 该是 1），答案 1，与示例一致。

```python
n = len(s)
ones = s.count('1')
zeros = n - ones
if abs(ones - zeros) > 1:
    return -1
ans = n
for start in ('1', '0'):
    if start == '1' and ones < zeros:   # 1 不够开头
        continue
    if start == '0' and zeros < ones:
        continue
    mis = sum(1 for i in range(n)
              if s[i] == '0' and (i % 2 == 0) == (start == '1'))
    ans = min(ans, mis)
return ans
```

关键点：`mis` 只数「该是 1 却是 0」的位置，不必再数另一半，因为错位 0 与错位 1 数量必然相等。

## 复杂度
时间 O(n)：一次 `count` 加至多两遍逐位扫描，n 为 `len(s)`。
空间 O(1)：只用了 `ones`、`zeros`、`mis`、`ans` 几个整数。

## 易错点
- `s = "1110"`：`ones = 3, zeros = 1`，差为 2，若漏掉 `abs(ones - zeros) > 1` 的判断，会强行构造目标串并返回一个非 -1 的数；正确做法是先判差值再谈交换。
- `s = "10"`：`ones = zeros = 1`，两种开头都合法，若只试 `'1'` 开头就返回，会漏掉 `'0'` 开头（`"01"`）的 `mis = 1` 与 `'1'` 开头的 `mis = 0` 的比较；正确做法是两种开头都算一遍取 `min`，别提前 `return`。

## 如果面试官追问
问：要求输出具体交换方案（哪两个下标互换）怎么办？
答：把每个错位 0 的下标和错位 1 的下标各存一个列表，按下标顺序一一配对输出即可，交换次数不变。
