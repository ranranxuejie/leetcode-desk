## 一句话思路
数「前一个字符是空格、当前字符不是空格」的位置，每个这样的位置开启一个新单词。

## 怎么做
1. 在 `s` 前面补一个空格，避免单独处理首字符。
2. 遍历补后的字符串，维护 `prev` 表示上一个字符。
3. 当 `prev == ' '` 且 `cur != ' '` 时，`count += 1`。
4. 每轮结束把 `prev` 更新为 `cur`。

以 `"Hello, my name is John"` 为例，补空格后开头是 `' '` 接 `'H'`，命中一次，`count` 变 1；走到 `','` 后的空格再遇 `'m'`，`count` 变 2；依次在 `'n'`、`'i'`、`'J'` 前各命中一次，最终 `count == 5`。关键中间值：`'Hello,'` 内部 `prev` 一直是字母，`count` 不会因逗号增加。

```python
count = 0
prev = ' '
for cur in ' ' + s:
    if prev == ' ' and cur != ' ':
        count += 1
    prev = cur
```

等价写法是 `len(s.split())`，但面试里手写扫描更能体现边界处理；`split()` 无参数时按任意空白切分并丢弃空串，结果一致。

## 复杂度
时间 O(n)：n 为 `len(s)`，每个字符看一次。
空间 O(1)：只开 `count`、`prev`、`cur`；补的那个空格是常量。

## 易错点
- 输入 `"  hello   world  "`（前后多空格、中间连续空格）→ 若用「空格数 + 1」会数成 8 个 → 必须只在「空格转非空格」的跳变处加一，连续空格只算一次跳变。
- 输入 `""` 或 `"   "` → 若先判断 `s[0] != ' '` 再计数，空串会 `IndexError`，全空格会错成 1 → 补前导空格后循环体不执行或从不命中，返回 0 才对。

## 如果面试官追问
问：不允许补字符串、要求原地只读一遍怎么办？
答：把 `prev` 初始化为 `' '`，循环 `for cur in s`，逻辑不变，只是首字符靠初始 `prev` 兜住。
