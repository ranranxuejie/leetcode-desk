## 一句话思路
枚举「最多字符 a、最少字符 b」这一对，把 a 记 +1、b 记 -1、其他忽略，在扫描中维护最大子段和，同时强制子段里至少含一个 b。

## 怎么做
1. 外层双重循环枚举有序对 `(a, b)`，`a != b`，共 26×25 种。
2. 扫描 `s`，只对 `a`、`b` 更新状态：遇到 `a` 时 `cur += 1`，遇到 `b` 时 `cur -= 1`。
3. 关键约束：波动要求 b 真实出现过，所以用 `has_b` 标记当前子段是否含 b，只有含 b 时才用 `cur` 更新答案。
4. 当 `cur < 0` 且当前字符是 `b` 时，把 `cur` 重置为 0 并清空 `has_b`，因为以 b 结尾的负前缀不可能更优。

以 `s = "aababbb"`、`a='b'`、`b='a'` 为例：扫描到下标 3 时 `cur = 1`（前面 "aab" 里 b 一个、a 两个，但重置后从下标 2 起算），继续到下标 6 的 `cur = 3`，`has_b=True`，答案更新为 3，对应子串 "babbb"。

```python
ans = 0
for a in range(26):
    for b in range(26):
        if a == b:
            continue
        ca, cb = chr(97 + a), chr(97 + b)
        cur = 0
        has_b = False
        for ch in s:
            if ch == ca:
                cur += 1
            elif ch == cb:
                cur -= 1
                has_b = True
            if cur < 0:
                cur = 0
                has_b = False
            elif has_b:
                ans = max(ans, cur)
```

注意 `elif has_b` 必须挂在 `if cur < 0` 之后，否则重置当步就会用脏值更新答案。

## 复杂度
时间：O(26² · n)，外层 650 对、内层扫一遍 s，n = len(s) ≤ 10⁴。
空间：O(1)，只开了 `cur`、`has_b`、`ans` 几个标量。

## 易错点
1. 输入 `s = "ab"` 且枚举 `a='a', b='b'` 时，若不加 `has_b` 判断，`cur` 在遇到 'a' 后就是 1，会错答 1；但子串 "a" 里 b 出现 0 次，波动定义要求最少字符真实出现，正确答案是 0。正确做法是只在 `has_b=True` 时更新 `ans`。
2. 输入 `s = "ba"` 且枚举 `a='a', b='b'` 时，若在 `cur < 0` 时无条件重置却不区分字符，会漏掉「先遇 b 再遇 a」的合法子串。正确做法是只在当前字符为 b 造成 `cur < 0` 时重置，且重置后 `has_b` 必须同步清空，否则下一段会用旧的 `has_b` 误更新。

## 如果面试官追问
问：若 s 长度升到 10⁶ 怎么优化？
答：26×25 的枚举无法再降，但可预处理每个字符出现位置，只在这些位置上做状态转移，跳过无关字符，常数级提速。
