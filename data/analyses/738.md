## 一句话思路
从右往左找第一个 `s[i-1] > s[i]` 的位置，把 `s[i-1]` 减一、后面全填 9，再向左回退处理新的降序。

## 怎么做
1. 把 `n` 转成字符列表 `s`，从右往左扫描，找第一个 `s[i-1] > s[i]`。
2. 命中后 `s[i-1] = str(int(s[i-1]) - 1)`，并把 `i` 及其右侧全部置 `'9'`。
3. 因为减一可能让 `s[i-2] > s[i-1]` 重新出现，所以 `i` 要左移一位继续检查，不能一次扫完就停。
4. 扫到 `i == 0` 结束，`''.join(s)` 转回整数。

以 `n = 332` 为例：`s = ['3','3','2']`，`i = 2` 时 `s[1]='3' > s[2]='2'`，命中，`s[1]` 变 `'2'`，`s[2]` 置 `'9'`，得 `['3','2','9']`；`i` 左移到 1，此时 `s[0]='3' > s[1]='2'` 再次命中，`s[0]` 变 `'2'`，`s[1]`、`s[2]` 置 `'9'`，得 `['2','9','9']`，输出 299。这一步是整道题唯一会翻车的地方：只改一次 `s[1]` 会得到 329，仍然不单调。

```python
s = list(str(n))
i = len(s) - 1
while i > 0:
    if s[i - 1] > s[i]:
        s[i - 1] = str(int(s[i - 1]) - 1)
        for j in range(i, len(s)):
            s[j] = '9'
    i -= 1
return int(''.join(s))
```

注意循环里 `i -= 1` 放在 `if` 外面，保证无论是否命中都往左走；命中后不 `break`，才能处理 `332` 这种连续降序。

## 复杂度
时间：O(log n)，位数 d = log10(n)，每个位置最多被访问一次。
空间：O(log n)，字符列表 `s` 长度等于位数。

## 易错点
- 输入 `n = 332` → 只做一次替换得 329，仍不单调 → 必须让 `i` 继续左移，把 `s[0]` 也减一，得到 299。
- 输入 `n = 100` → 若把 `s[0]` 减成 `'0'` 后直接拼接，会得到 `099` 这种带前导零的串 → `int('099')` 在 Python 里是 99，结果正确，但若中途用字符串比较或输出字符串就会错；统一在最后 `int(...)` 收口。

## 如果面试官追问
问：如果 n 大到 10^100 呢？答：算法只依赖位数，字符串处理天然支持大数，复杂度仍是 O(位数)，不用改代码。
