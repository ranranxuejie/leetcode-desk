## 一句话思路
先给每个 1 连通块标 id 并记面积，再枚举每个 0 看四邻 id 去重求和，取最大。

## 怎么做
1. 一次 DFS 遍历，把每个岛屿的格子写成 `grid[i][j] = island_id`（从 2 起），面积存进 `area[id]`。
2. 若全图无 0（`len(area) == 1`），直接返回 `n*n`。
3. 枚举每个 0，收集上下左右四个格子的 id 进 `set`，`1 + sum(area[i] for i in ids)` 即翻转后的面积。
4. 全程维护 `best`，返回它。

以示例 1 `[[1,0],[0,1]]` 为例：DFS 后 `grid = [[2,0],[0,3]]`，`area = {2:1, 3:1}`。枚举 `(0,1)` 时四邻 id 集合是 `{2,3}`，面积 `1+1+1=3`，即答案。

```python
def dfs(i, j, idx):
    if not (0 <= i < n and 0 <= j < n) or grid[i][j] != 1:
        return 0
    grid[i][j] = idx
    return 1 + dfs(i+1,j,idx) + dfs(i-1,j,idx) + dfs(i,j+1,idx) + dfs(i,j-1,idx)

idx = 2
for i in range(n):
    for j in range(n):
        if grid[i][j] == 1:
            area[idx] = dfs(i, j, idx)
            idx += 1
for i in range(n):
    for j in range(n):
        if grid[i][j] == 0:
            ids = {grid[x][y] for x, y in ((i+1,j),(i-1,j),(i,j+1),(i,j-1))
                   if 0 <= x < n and 0 <= y < n and grid[x][y] > 1}
            best = max(best, 1 + sum(area[k] for k in ids))
```

## 复杂度
时间 O(n²)：DFS 每个格子一次，枚举 0 时每格查 4 邻。
空间 O(n²)：`area` 字典最多 n²/2 项，DFS 递归栈最深 n²。

## 易错点
- 全 1 输入 `[[1,1],[1,1]]` → 若只枚举 0 则 `best` 停在 0，错答 0；正确做法是先判 `len(area) == 1` 返回 `n*n`，或把 `best` 初始化为 `max(area.values())`。
- 一个 0 的上下左右属于同一岛屿（如 `[[1,1],[1,0]]` 中 `(1,1)` 的上和左都是 id 2）→ 不去重会把面积 3 加成 4 以上；必须用 `set` 收集 id 再求和。

## 如果面试官追问
若 n 到 5000、矩阵稀疏，怎么做？答：改用并查集只处理 1 的坐标，枚举 0 时查四邻根节点去重，空间降到 O(岛屿数)。
