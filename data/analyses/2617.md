## 一句话思路
按步数分层 BFS，每行每列用并查集维护「下一个未访问格子」，跳过的格子永久删除，保证每格只入队一次。

## 怎么做
1. 建 `row_next[i]`、`col_next[j]` 两个并查集，`find` 返回 ≥ 当前下标的最小未访问格子；初始 `parent[x] = x`。
2. 队列存 `(i, j, dist)`，起点 `(0,0,1)`；出队时若为 `(m-1,n-1)` 直接返回 `dist`。
3. 从 `(i,j)` 向右枚举 `k = find(j+1)`，只要 `k <= j + grid[i][j]` 就入队 `(i,k,dist+1)` 并 `union(k, k+1)`；向下同理用 `col_next`。
4. 队列空仍未到终点返回 `-1`。

以示例 1 为例：`(0,0)` 的 `grid[0][0]=3`，向右可达列 1、2、3，向下可达行 1、2、3，全部入队后 `row_next[0]` 的 1、2、3 被删，`find(1)` 直接跳到 4。第 2 层从 `(0,3)` 出发时 `grid[0][3]=1`，向右 `find(4)` 越界，无新格子；而 `(1,3)` 的 `grid=1` 向下到 `(2,3)`，第 3 层 `(2,3)` 的 `grid=0` 无路，真正到终点的是 `(2,2)→(3,2)` 这条，`dist=4`。

```python
def find(p, x):
    while p[x] != x:
        p[x] = p[p[x]]
        x = p[x]
    return x

row_next = [list(range(n + 1)) for _ in range(m)]
col_next = [list(range(m + 1)) for _ in range(n)]
q = deque([(0, 0, 1)])
while q:
    i, j, d = q.popleft()
    if i == m - 1 and j == n - 1:
        return d
    k = find(row_next[i], j + 1)
    while k <= min(n - 1, j + grid[i][j]):
        q.append((i, k, d + 1)); row_next[i][k] = k + 1
        k = find(row_next[i], k)
    k = find(col_next[j], i + 1)
    while k <= min(m - 1, i + grid[i][j]):
        q.append((k, j, d + 1)); col_next[j][k] = k + 1
        k = find(col_next[j], k)
return -1
```

## 复杂度
时间：`O(m*n*α)`，每个格子最多被删一次，并查集近似常数。
空间：`O(m*n)`，两个并查集数组加队列。

## 易错点
1. 用普通 BFS 不删已访问格子 → 示例 1 中 `(0,0)` 的 `grid=3` 会把列 1、2、3 反复入队，同一行被多个格子重复扫描，退化成 `O(m*n*max(grid))` 超时；正确做法是入队后立刻 `row_next[i][k] = k + 1` 把它从并查集摘掉。
2. 并查集上界只开到 `n`（列）和 `m`（行），`find` 返回 `n` 或 `m` 表示越界 → 若把 `row_next[i]` 长度写成 `n`，`find(j+1)` 在 `j=n-1` 时下标越界报错；正确做法是每行开 `n+1` 个、每列开 `m+1` 个哨兵。

## 如果面试官追问
问：要求输出具体路径而非步数？
答：BFS 入队时记录 `parent[(i,k)] = (i,j)`，到达终点后沿父指针回溯即可，并查集删除不影响父指针。
