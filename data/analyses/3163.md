## 一句话思路
从左到右扫一遍，每遇到一段连续相同字符就按 9 个一组切块，每块输出「块长 + 字符」。

## 怎么做
1. 用 `i` 指向当前段起点，`j` 向后探到第一个不等于 `word[i]` 的位置，得到整段长度 `run = j - i`。
2. 把 `run` 反复减 9：只要 `run > 9` 就追加 `"9" + c`，最后追加 `str(run) + c`。
3. `i = j` 继续下一段，直到 `i == len(word)`。

以 `word = "aaaaaaaaaaaaaabb"` 为例：第一段 `i=0` 探到 `j=14`，`run=14`；`14 > 9` 先输出 `"9a"`，`run` 变 `5`，再输出 `"5a"`；第二段 `run=2` 直接输出 `"2b"`，拼成 `"9a5a2b"`。

```python
res = []
i, n = 0, len(word)
while i < n:
    j = i
    while j < n and word[j] == word[i]:
        j += 1
    run = j - i
    while run > 9:
        res.append("9" + word[i])
        run -= 9
    res.append(str(run) + word[i])
    i = j
return "".join(res)
```

关键点：`run` 恰好等于 9 时不该进 `while run > 9`，否则会多出一个 `"0a"` 之类的空块；用 `>` 而不是 `>=` 就自然处理了。

## 复杂度
时间 O(n)：`i` 和 `j` 都只前进不后退，每个字符被访问常数次。
空间 O(n)：`res` 列表最多存 n 个片段，`"".join` 再开一份结果串。

## 易错点
- 输入 `word = "aaaaaaaaaa"`（10 个 a）→ 若写成 `while run >= 9` 会输出 `"9a1a"` 之外的错误切分，或在 `run == 9` 时多切一块 `"0a"` → 正确做法是 `while run > 9`，让 9 走最后的 `str(run)` 分支，输出 `"9a1a"`。
- 输入 `word = "a"` 或全不重复的 `"abcde"` → 若把内层探测写成 `while j < n and word[j] == word[j+1]` 会越界或漏掉最后一段 → 正确做法是拿 `word[j] == word[i]` 与段首比较，`j` 从 `i` 起探，保证单字符段 `run=1` 也能正常输出 `"1a"`。

## 如果面试官追问
问：如果允许前缀长度上限改成 k（不再是 9），怎么改？
答：把 `while run > 9` 换成 `while run > k`，追加 `str(k) + c`，其余不变，复杂度仍是 O(n)。
