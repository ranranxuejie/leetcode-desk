## 一句话思路
把「付费墙总时间 ≥ 免费墙数量」转成背包：选付费墙得 time[i] 点时间，其余墙每堵消耗 1 点，求最小 cost。

## 怎么做
1. 关键等价：若付费刷 k 堵墙、总耗时 T，免费刷 n-k 堵需 n-k 单位时间，可行当且仅当 T ≥ n-k，即 T+k ≥ n。
2. 于是定义 dp[t] = 已选付费墙「时间 + 数量」恰好为 t 时的最小开销，t 上限取 n（超过 n 一律压到 n，因为再多也没用）。
3. 对每堵墙做 0/1 背包：选它则 t 增加 time[i]+1，不选则不变；最后答案是 dp[n]。
4. 用示例 1 走一遍：cost=[1,2,3,2]、time=[1,2,3,2]，墙 0 选入后 dp[2]=1，墙 1 选入后 dp[5→压到 4]=3，此时 t=4=n 已达标，答案 3，与免费刷墙 2、3 吻合。

```python
n = len(cost)
INF = float('inf')
dp = [INF] * (n + 1)
dp[0] = 0
for c, t in zip(cost, time):
    ndp = dp[:]                      # 不选这堵墙
    for s in range(n + 1):
        if dp[s] == INF:
            continue
        ns = min(n, s + t + 1)       # 选：时间+1 个名额
        if dp[s] + c < ndp[ns]:
            ndp[ns] = dp[s] + c
    dp = ndp
return dp[n]
```

注意 `min(n, ...)` 这步压缩：示例 1 中 s=2、t=2 时算出 5，压成 4，否则 dp 数组越界且状态爆炸。

## 复杂度
时间：O(n²)，两层循环各 n，n ≤ 500 共 25 万次。
空间：O(n)，只开一个长度 n+1 的 dp 数组，滚动更新。

## 易错点
- 把状态写成「付费总时间 T」而不含墙数 → 示例 2 中 cost=[2,3,4,2]、time 全 1，选墙 0、3 得 T=2，但免费要刷 2 堵，T=2 恰好够；若只按 T 判断会漏掉「T 与 k 一起才够」的情形，正确做法是状态里带 +1 的墙数。
- 忘记把 s+t+1 截到 n → 示例 1 中 s=2、t=2 得 5 越界，Python 直接 IndexError；正确做法是 `min(n, s + t + 1)`，把「超额达标」合并到 dp[n]。

## 如果面试官追问
问：n 放大到 10⁵ 怎么办？
答：此时 time[i] ≤ 500 但 n 大，需换思路——按 time 排序后贪心或改用「总时间」维度的可行性剪枝，O(n²) 背包不再适用。
