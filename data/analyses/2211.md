## 一句话思路
从左到右扫，用栈记录还没被"消灭"的 `R`，遇到 `L` 就配对消掉一个 `R` 并计 2 分。

## 怎么做
1. 初始化 `ans = 0`，栈 `st = []`，只存 `'R'`。
2. 遍历 `directions`：遇 `'R'` 入栈；遇 `'L'` 且栈非空，弹栈并 `ans += 2`；遇 `'S'` 时栈清空（静止车挡住所有左侧 `R`）。
3. 关键中间值：以 `"RLRSLL"` 为例，i=0 入栈 `['R']`，i=1 遇 `'L'` 弹栈 `ans=2`；i=2 入栈 `['R']`，i=3 遇 `'S'` 清空栈，i=4、5 两个 `'L'` 栈空无配对，最终 `ans=2`。
4. 再单独统计"撞静止车"：对每个 `'S'`，若其左侧存在未被消掉的 `R` 或右侧存在未被消掉的 `L`，各加 1。

```python
ans, st = 0, []
for c in directions:
    if c == 'R':
        st.append(c)
    elif c == 'L' and st:
        st.pop()
        ans += 2
    elif c == 'S':
        st.clear()
# 静止车：左侧有 R 或右侧有 L 各计 1
for i, c in enumerate(directions):
    if c == 'S':
        if 'R' in directions[:i]:
            ans += 1
        if 'L' in directions[i+1:]:
            ans += 1
```

## 复杂度
时间：O(n)，一次扫描配对，静止车统计用前缀/后缀标记也是 O(n)。
空间：O(n)，栈最坏存全部 `'R'`。

## 易错点
1. 输入 `"RLL"` → 若遇 `'L'` 不检查栈空就弹栈，会 `IndexError` 或错配 → 必须先判 `st` 非空再 `pop`，`ans` 只在真正配对时加 2。
2. 输入 `"RLRSLL"` → 若把 `'S'` 当成普通障碍继续保留栈，i=3 的 `'S'` 后 i=4、5 的 `'L'` 会错误地与 i=2 的 `'R'` 配对 → 遇 `'S'` 必须 `st.clear()`，静止车截断所有左侧 `R` 的传播。

## 如果面试官追问
问：若要求输出每辆车的最终位置而非次数？答：在栈里存下标而非字符，配对时记录两车停在较小下标处，静止车同理。
