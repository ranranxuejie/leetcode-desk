## 一句话思路
把「两数乘积等于某平方」拆成两半：先枚举无序对算乘积频次，再拿每个平方值去哈希表里查。

## 怎么做
1. 写一个 `count(pairs_src, squares_src)`：对 `pairs_src` 枚举所有 `j < k`，把 `pairs_src[j] * pairs_src[k]` 计入 `Counter`。
2. 再遍历 `squares_src` 的每个 `x`，把 `x * x` 在 `Counter` 里的计数累加进答案。
3. 两次调用相加：`count(nums2, nums1) + count(nums1, nums2)`，分别对应类型 1 和类型 2。
4. 用示例 1 走一遍：`count(nums2, nums1)` 里 `nums2 = [5,2,8,9]` 的对乘积是 `{10,40,45,16,18,72}` 各 1 次；`nums1` 的平方是 `49` 和 `16`，只有 `16` 命中，答案 1。

```python
from collections import Counter

def count(pairs_src, squares_src):
    freq = Counter()
    m = len(pairs_src)
    for j in range(m):
        for k in range(j + 1, m):
            freq[pairs_src[j] * pairs_src[k]] += 1
    total = 0
    for x in squares_src:
        total += freq[x * x]
    return total

return count(nums2, nums1) + count(nums1, nums2)
```

注意 `j < k` 严格小于，所以 `[1,1]` 只产生一个对 `(0,1)`，乘积 1 计 1 次，而不是 2 次。

## 复杂度
时间：O(n² + m²)，n、m 分别是两数组长度，枚举对是平方级，查表是线性。
空间：O(n²) 存乘积频次，最坏约 50 万项。

## 易错点
- `nums2 = [1,1,1]` 这类重复值 → 若用 `set` 去重再乘，会把 `(0,1)`、`(0,2)`、`(1,2)` 三个对压成一个，答案从 9 掉到 3 → 必须用 `Counter` 按对计数，重复值各自成对。
- 类型 1 和类型 2 的数组角色容易写反 → 若两次都传 `count(nums1, nums2)`，示例 1 会得到 0（`nums1` 的对乘积 `{28}` 对不上 `nums2` 的平方 `{25,4,64,81}`）→ 记住「对乘积来自被乘的那一边」，即 `count(nums2, nums1)` 配类型 1。

## 如果面试官追问
问：数组长度到 10^5 怎么办？
答：平方级枚举不可行，改用「对每个平方值分解质因数」或按值域 10^5 建频次数组做卷积式统计。
