## 一句话思路
对每个位置预处理「改/不改」两种前缀分割数，用位掩码 DP 从右往左递推，取最大值。

## 怎么做
1. 从右往左扫描，维护当前段已出现的字符掩码 `mask` 和段数 `cnt`；当 `mask | (1<<c)` 的位数超过 k 时，说明 `c` 开启了新段，`cnt += 1`，`mask = 1<<c`。
2. 记 `suf[i]` 为从 `i` 开始、**不修改**任何字符时的分割数，`sufMask[i]` 为 `i` 所在段到结尾的字符掩码。
3. 再从左往右扫描，维护前缀段数 `pre` 和当前段掩码 `pmask`；枚举把 `s[i]` 改成 26 个字母之一，计算「前缀段数 + 修改后 `i` 所在段 + 后缀段数」。
4. 关键合并：若 `pmask | (1<<newc) | sufMask[i+1]` 的位数 ≤ k，则 `i` 所在段可与后缀首段合并，答案为 `pre + suf[i+1]`；否则为 `pre + 1 + suf[i+1]`。

以 `s="accca", k=2` 为例：`suf` 从右算得 `suf[3]=1`（"ca" 一段）、`suf[2]=2`（"c"+"ca"）、`suf[1]=2`、`suf[0]=2`。在 `i=2` 把 `c` 改成 `b`：`pmask={a,c}`，`sufMask[3]={c,a}`，合并后 `{a,c,b}` 有 3 个字符 > k=2，不能合并，答案 `pre(=1) + 1 + suf[3](=1) = 3`。

```python
def maxPartitionsAfterOperations(s, k):
    n = len(s)
    suf = [0] * (n + 1)
    sufMask = [0] * (n + 1)
    mask = cnt = 0
    for i in range(n - 1, -1, -1):
        b = 1 << (ord(s[i]) - 97)
        if (mask | b).bit_count() > k:
            cnt += 1
            mask = b
        else:
            mask |= b
        suf[i], sufMask[i] = cnt + 1, mask
    ans = pre = 0
    pmask = 0
    for i in range(n):
        b = 1 << (ord(s[i]) - 97)
        if (pmask | b).bit_count() > k:
            pre += 1
            pmask = b
        else:
            pmask |= b
        for c in range(26):
            nm = pmask | (1 << c)
            if (nm | sufMask[i + 1]).bit_count() <= k:
                ans = max(ans, pre + suf[i + 1])
            else:
                ans = max(ans, pre + 1 + suf[i + 1])
    return ans
```

## 复杂度
时间：O(26n)，n 为字符串长度，26 来自枚举替换字符。
空间：O(n)，`suf` 和 `sufMask` 两个数组。

## 易错点
- `s="xxyz", k=1`：若只枚举把 `s[i]` 改成**已出现**的字符，会漏掉改成 `w` 这种全新字符使段数从 2 变 4 的情况 → 必须枚举全部 26 个字母，不能只试原字符。
- `s="aabaab", k=3`：若忘记判断「修改后 `i` 所在段能否与后缀首段合并」，会把本应 1 段的结果算成 2 → 合并条件必须用 `pmask | (1<<c) | sufMask[i+1]` 的位数与 k 比较，而不是只看 `pmask`。

## 如果面试官追问
若允许改两处怎么办？→ 把「是否已用修改」加进 DP 状态，从右往左做 `dp[i][used]`，枚举 `s[i]` 的 26 种取值转移，复杂度乘 26。
