## 一句话思路
快慢指针把链表切成两半，后半段反转后与前半段逐节点相加取最大值。

## 怎么做
1. 用 `slow`、`fast` 双指针走，`fast` 每次两步、`slow` 一步，结束时 `slow` 指向后半段头节点。
2. 反转以 `slow` 为头的后半段，得到 `rev`。
3. 用 `head` 和 `rev` 同步前进，每步算 `head.val + rev.val` 更新 `ans`，直到 `rev` 为空。

以 `head = [4,2,2,3]` 为例：快慢指针走完后 `slow` 指向第二个 `2`（下标 2），反转 `[2,3]` 得 `rev = [3,2]`。第一轮 `head.val=4`、`rev.val=3`，和 `7`，`ans=7`；第二轮 `2+2=4`，`ans` 保持 `7`。

```python
slow = fast = head
while fast and fast.next:
    slow, fast = slow.next, fast.next.next
prev, cur = None, slow
while cur:
    cur.next, prev, cur = prev, cur, cur.next
ans, rev = 0, prev
while rev:
    ans = max(ans, head.val + rev.val)
    head, rev = head.next, rev.next
return ans
```

关键点：反转后 `prev` 是后半段的头（原链表尾），`rev` 从尾往中间走，`head` 从头往中间走，正好配对孪生节点。

## 复杂度
时间 O(n)：快慢指针走 n/2、反转走 n/2、求和走 n/2，合计线性。
空间 O(1)：只开了 `slow`、`fast`、`prev`、`cur`、`rev`、`ans` 几个指针变量。

## 易错点
- 输入 `[1,100000]`（n=2）→ 若快慢指针写成 `while fast.next and fast.next.next`，`fast` 走一步后 `fast.next` 为 `None` 会抛异常 → 正确写法是 `while fast and fast.next`，保证 `fast.next.next` 可访问。
- 输入 `[5,4,2,1]` → 若反转后忘记把 `slow` 前一个节点的 `next` 置空，前半段和后半段仍连着，求和循环会多走节点或死循环 → 反转前先断开，或让 `prev` 从 `None` 开始自然截断（上面代码靠 `cur.next = prev` 在第一步就把 `slow.next` 改掉，前半段尾部仍指向 `slow`，但求和只走 `rev` 链，不受影响）。

## 如果面试官追问
问：不反转链表能做吗？答：可以，用栈把前半段压栈，再和后半段从尾到头配对，代价是 O(n) 空间。
