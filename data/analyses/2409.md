## 一句话思路
把 "MM-DD" 转成一年中的第几天，两个闭区间取交集，长度就是 `max(0, min(leaveA, leaveB) - max(arriveA, arriveB) + 1)`。

## 怎么做
1. 写前缀和数组 `days = [0,31,59,90,120,151,181,212,243,273,304,334]`，`days[m-1]` 就是 m 月之前的天数。
2. 用 `int(s[:2])` 取月、`int(s[3:])` 取日，转成序数 `days[m-1] + d`。
3. 四个日期都转成序数后，交集左端 `lo = max(aA, aB)`，右端 `hi = min(lA, lB)`。
4. 返回 `max(0, hi - lo + 1)`，`+1` 是因为闭区间。

以示例 1 为例：`"08-15"` → `days[7] + 15 = 212 + 15 = 227`，`"08-18"` → 230，`"08-16"` → 228，`"08-19"` → 231。于是 `lo = max(227, 228) = 228`，`hi = min(230, 231) = 230`，答案 `230 - 228 + 1 = 3`。

```python
days = [0, 31, 59, 90, 120, 151, 181, 212, 243, 273, 304, 334]

def to_ord(s):
    return days[int(s[:2]) - 1] + int(s[3:])

aA, lA = to_ord(arriveAlice), to_ord(leaveAlice)
aB, lB = to_ord(arriveBob), to_ord(leaveBob)
lo, hi = max(aA, aB), min(lA, lB)
return max(0, hi - lo + 1)
```

## 复杂度
时间：O(1)，四个日期各做一次常数次字符串切片和加法，与输入规模无关。
空间：O(1)，只开了长度 12 的常量表 `days` 和四个序数变量。

## 易错点
- 忘记 `+1`：示例 1 若写成 `hi - lo` 会得 2 而不是 3，因为 8 月 16、17、18 是三天，闭区间长度是 `hi - lo + 1`。
- 交集为空时直接算 `hi - lo + 1`：示例 2 中 `lo = max(274, 305) = 305`、`hi = min(304, 365) = 304`，得 `304 - 305 + 1 = 0` 恰好对，但若换成 Alice 10-01~10-05、Bob 10-10~10-20，会得 `-4`，必须用 `max(0, ...)` 兜住。

## 如果面试官追问
问：如果日期跨年（比如 12-20 到次年 01-10）怎么办？
答：把序数按 365 取模展开，跨年区间拆成两段分别求交再相加。
