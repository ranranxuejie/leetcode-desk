## 一句话思路
把每种颜色的最小外接矩形当作它必须覆盖的范围，矩形内出现的其他颜色就是「后印」约束，建图跑拓扑排序判环。

## 怎么做
1. 遍历 `targetGrid`，对每种颜色 `c` 记录 `top[c]`、`bottom[c]`、`left[c]`、`right[c]` 四个边界。
2. 对每种颜色 `c`，扫描它的外接矩形内每个格子 `(i,j)`：若 `targetGrid[i][j] != c`，说明颜色 `targetGrid[i][j]` 必须比 `c` 先印，加边 `targetGrid[i][j] -> c`，并给 `c` 入度 +1（同一对颜色去重）。
3. 入度为 0 的颜色入队，BFS 拓扑排序，每弹出一个颜色就把它指向的颜色入度减 1，减到 0 入队。
4. 若弹出的颜色数等于出现过的颜色种数，返回 `True`，否则有环返回 `False`。

以示例 3 `[[1,2,1],[2,1,2],[1,2,1]]` 为例：颜色 1 的外接矩形是整张 3×3，里面全是 2，于是加边 `2 -> 1`；颜色 2 的外接矩形也是整张 3×3，里面全是 1，加边 `1 -> 2`。两个颜色入度都是 1，队列初始为空，弹出数 0 ≠ 2，返回 `False`。

```python
from collections import deque

top = [m] * 61; bottom = [-1] * 61
left = [n] * 61; right = [-1] * 61
for i in range(m):
    for j in range(n):
        c = targetGrid[i][j]
        top[c] = min(top[c], i); bottom[c] = max(bottom[c], i)
        left[c] = min(left[c], j); right[c] = max(right[c], j)

adj = [set() for _ in range(61)]
indeg = [0] * 61
for c in range(1, 61):
    if bottom[c] == -1: continue
    for i in range(top[c], bottom[c] + 1):
        for j in range(left[c], right[c] + 1):
            d = targetGrid[i][j]
            if d != c and c not in adj[d]:
                adj[d].add(c); indeg[c] += 1

q = deque(c for c in range(1, 61) if bottom[c] != -1 and indeg[c] == 0)
seen = 0
while q:
    u = q.popleft(); seen += 1
    for v in adj[u]:
        indeg[v] -= 1
        if indeg[v] == 0: q.append(v)
return seen == sum(1 for c in range(1, 61) if bottom[c] != -1)
```

## 复杂度
时间：O(60·m·n)，每种颜色扫一遍自己的外接矩形，最坏 60 倍。
空间：O(60²) 存邻接表 `adj`，外加 4 个长度 61 的边界数组。

## 易错点
- 颜色 1 的外接矩形里出现颜色 2，但 2 的外接矩形里没有 1 → 只加 `2 -> 1` 一条边。若误以为「矩形相交就互相约束」而加双向边，示例 2 会被判 `False`（实际 `True`）。
- 用 `adj` 存边时不去重 → 同一对颜色重复加边导致 `indeg` 虚高，拓扑排序永远弹不完，示例 1 会错成 `False`。正确做法是用 `set` 或加边前判 `c not in adj[d]`。

## 如果面试官追问
问：如果要求输出一种合法的打印顺序怎么办？
答：拓扑排序时把出队顺序记录下来即可，队列里颜色的弹出顺序就是自底向上的打印顺序。
