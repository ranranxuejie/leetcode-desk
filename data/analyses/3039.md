## 一句话思路
统计每个字母出现次数，取最大次数 mx，答案就是所有出现次数等于 mx 的字母按原串顺序拼起来。

## 怎么做
1. 用 `cnt = [0]*26` 扫一遍 `s`，记录每个字母出现次数。
2. 取 `mx = max(cnt)`，它是操作的总轮数。
3. 再扫一遍 `s`，把 `cnt[ord(ch)-97] == mx` 的字符按原顺序留下。
4. 拼成的字符串就是最后一次操作前的状态。

以 `s = "aabcbbca"` 为例：`cnt` 中 a=3、b=3、c=2，`mx = 3`。第二轮扫描时只有 a、b 满足 `cnt == 3`，按原串顺序取出位置 0 的 a、位置 1 的 a、位置 3 的 c 跳过、位置 4 的 b……最终得到 `"ba"`，与示例一致。

为什么成立：每轮操作对每个仍存在的字母恰好删掉一个（删它最早的那次出现）。所以出现 `cnt[ch]` 次的字母能活 `cnt[ch]` 轮，第 `mx` 轮结束时所有字母都被删光。最后一次操作前剩下的，正是那些「能撑到第 mx 轮」的字母，即 `cnt[ch] == mx` 的字母，且它们在原串中的相对顺序不变。

```python
cnt = [0] * 26
for ch in s:
    cnt[ord(ch) - 97] += 1
mx = max(cnt)
res = []
for ch in s:
    if cnt[ord(ch) - 97] == mx:
        res.append(ch)
return "".join(res)
```

注意 `mx` 一定 ≥ 1（`s` 非空），所以 `res` 不会为空。

## 复杂度
时间 O(n)：两遍扫描各 O(n)，`max(cnt)` 是常数 26。
空间 O(1)：`cnt` 固定 26 个槽，`res` 最多 n 个字符但那是输出本身。

## 易错点
- 误以为答案是「出现次数最多的字母去重后排序」。对 `"aabcbbca"` 会错成 `"ab"`，正确是 `"ba"`——必须按原串顺序保留，不能按字母序。
- 把条件写成 `cnt[ch] >= mx` 或漏掉 `mx` 的重新计算。对 `"abcd"` 四个字母各 1 次，`mx = 1`，答案应是完整 `"abcd"`；若误用「次数 > 1」筛选会得到空串。

## 如果面试官追问
问：如果要求返回每一轮操作后的字符串序列？
答：按轮次 t 从 mx 递减到 1，保留 `cnt[ch] >= t` 的字符按原序输出即可，总代价 O(26n)。
