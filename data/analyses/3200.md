## 一句话思路
枚举两种起始颜色，逐层累加所需球数，取能撑住的最大高度。

## 怎么做
1. 三角形高度 h 固定时，两种颜色的球数需求是确定的：起始色占第 1、3、5… 层，另一色占第 2、4、6… 层。
2. 对起始色为红、起始色为蓝各试一次，逐层加：第 i 层需要 i 个球，从对应颜色的余额里扣。
3. 一旦某层余额不足就停，记录当前高度，两次取 max。

以 `red = 2, blue = 4` 为例，起始红：第 1 层扣红 1 → red=1；第 2 层扣蓝 2 → blue=2；第 3 层扣红 3，red=1 不够，停在高度 2。起始蓝：第 1 层扣蓝 1 → blue=3；第 2 层扣红 2 → red=0；第 3 层扣蓝 3 → blue=0；第 4 层扣红 4，red=0 不够，停在高度 3。取 max 得 3，与示例一致。

```python
def maxHeightOfTriangle(red, blue):
    def calc(first, second):
        h = 0
        need = 1
        while True:
            if h % 2 == 0:
                if first < need:
                    break
                first -= need
            else:
                if second < need:
                    break
                second -= need
            h += 1
            need += 1
        return h
    return max(calc(red, blue), calc(blue, red))
```

注意 `calc` 里 `h % 2 == 0` 判断的是「当前要填的层由 first 色出」，因为 h 是已完成的层数，第 h+1 层是奇数层。

## 复杂度
时间：O(√(red+blue))，因为高度 h 的球数总和是 h(h+1)/2，不超过 red+blue。
空间：O(1)，只开了 h、need 两个整型变量。

## 易错点
- 只试一种起始颜色 → 对 `red = 10, blue = 1`，起始红会在第 2 层就卡住得高度 1，但起始蓝能到高度 2（蓝 1 个填第 1 层，红 2 个填第 2 层），漏掉就错成 1，必须两种都算。
- 把「相邻行颜色不同」理解成「每层颜色可以任意选」→ 会以为只要总球数够就能堆，对 `red = 2, blue = 1` 误判成高度 2 需要 3 个球刚好够、但若按贪心把红放第 1 层就只剩 1 红 1 蓝，第 2 层要 2 个同色球凑不出；正确做法是固定交替模式逐层扣减。

## 如果面试官追问
问：如果要求返回具体每层的颜色方案而不只是高度？
答：在 `calc` 里把每层选的颜色 append 进列表，最后返回高度最大的那个列表即可，逻辑不变。
