## 一句话思路
从左往右扫，维护当前后缀被翻转的奇偶次数 `flip`，`nums[i] ^ flip == 0` 就必须在此处翻一次。

## 怎么做
1. 设 `flip = 0` 表示当前元素实际值等于原值，`ans = 0` 记操作数。
2. 遍历 `nums`，实际值为 `nums[i] ^ flip`；若为 0，说明必须从 `i` 开始翻后缀，`ans += 1`、`flip ^= 1`。
3. 若为 1 则跳过，因为翻它只会破坏已修好的前缀。
4. 返回 `ans`。

以 `nums = [0,1,1,0,1]` 为例：`i=0` 时 `0^0=0`，翻，`flip=1`、`ans=1`；`i=1` 时 `1^1=0`，再翻，`flip=0`、`ans=2`；`i=2` 时 `1^0=1` 跳过；`i=3` 时 `0^0=0`，翻，`flip=1`、`ans=3`；`i=4` 时 `1^1=0`，翻，`flip=0`、`ans=4`。结果 4，与示例一致。

```python
flip = 0
ans = 0
for x in nums:
    if (x ^ flip) == 0:
        ans += 1
        flip ^= 1
return ans
```

关键点：`flip` 只记「从当前位置到末尾被翻过几次」的奇偶，不需要真的改数组；每次翻转都从当前 `i` 开始，所以之前的位置不再受影响，贪心选择唯一且最优。

## 复杂度
时间 O(n)：一次遍历，每个元素做一次异或比较。
空间 O(1)：只开 `flip` 和 `ans` 两个整型变量。

## 易错点
- 输入 `[1,0,0,0]` → 若按「遇到 0 就翻」而不维护 `flip`，会在 `i=1` 翻后仍把后面两个 0 当原值，多翻两次得 3 → 正确是 `flip` 变 1 后 `0^1=1` 直接跳过，答案 1。
- 输入 `[0]` 或全 0 数组 → 若把 `flip` 初值设成 1 或忘记在翻后更新 `flip`，会把已翻成 1 的元素再翻回 0 → 正确做法是 `flip` 初值 0，每次 `ans += 1` 后立刻 `flip ^= 1`。

## 如果面试官追问
问：如果要求输出具体操作的下标序列怎么办？
答：在 `ans += 1` 处把当前 `i` 追加进列表，顺序即为一种最优方案。
