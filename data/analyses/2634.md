## 一句话思路
新建空数组，按下标遍历 `arr`，把 `fn(arr[i], i)` 为真值的元素追加进去，一次遍历即可。

## 怎么做
1. 建 `res = []`，用 `for i in range(len(arr))` 拿下标而不是 `for x in arr`，因为 `fn` 可能用到第二个参数 `i`。
2. 调用 `fn(arr[i], i)`，把返回值直接放进 `if` 判断，靠 Python 的真值规则（`0`、`0.0`、`''`、`None`、`False` 为假）决定去留。
3. 为真就 `res.append(arr[i])`，为假跳过，不修改原数组。
4. 返回 `res`。

以示例 3 为例：`arr = [-2,-1,0,1,2]`，`fn = plusOne`。`i=0` 时 `fn(-2,0) = -1`，真值，收 `-2`；`i=1` 时 `fn(-1,1) = 0`，假值，跳过；`i=2` 时 `fn(0,2) = 1`，收 `0`；`i=3` 时 `fn(1,3) = 2`，收 `1`；`i=4` 时 `fn(2,4) = 3`，收 `2`。最终 `res = [-2,0,1,2]`，注意 `-1` 被丢是因为 `n+1` 恰好为 `0`，不是因为它本身是负数。

```python
def filter_arr(fn, arr):
    res = []
    for i in range(len(arr)):
        if fn(arr[i], i):
            res.append(arr[i])
    return res
```

关键就一行：`if fn(arr[i], i)` 不要写成 `if fn(arr[i], i) == True`，后者会把返回 `1`、`"a"` 这类真值误判为假。

## 复杂度
时间 O(n)：`fn` 对每个元素调用一次，`n = len(arr)`。
空间 O(n)：`res` 最坏存下全部元素，不计输出则 O(1)。

## 易错点
- 输入 `arr = [0,10,20,30]`、`fn = n => n > 10` → 若写成 `if fn(arr[i], i) is not False` 或与 `True` 比较，`0` 这类元素本身是假值但 `fn` 返回 `False` 时判断会混乱；正确做法是直接 `if fn(...)`，让 Python 真值规则统一裁决，示例 1 得 `[20,30]`。
- 输入 `arr = [1,2,3]`、`fn = (n,i) => i === 0` → 若用 `for x in arr` 拿不到下标，`i` 无从传入，会全部保留或报错；正确做法是 `for i in range(len(arr))` 显式传 `fn(arr[i], i)`，示例 2 只留 `[1]`。

## 如果面试官追问
问：`fn` 抛异常或返回对象怎么办？
答：真值判断照旧走 `bool()`，异常不捕获、直接向上抛，符合原生 `filter` 语义。
