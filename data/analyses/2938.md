## 一句话思路
从左往右扫，每个 `1` 都要跨过它左边所有 `0`，把这些 `0` 的个数累加即答案。

## 怎么做
1. 维护 `zeros`（已扫过的 `0` 的个数）和 `ans`（累计步数），初值都是 0。
2. 遍历 `s` 的每个字符：遇 `'0'` 就 `zeros += 1`。
3. 遇 `'1'` 就 `ans += zeros`——这个 `1` 左边有 `zeros` 个白球，它必须逐个越过它们才能到右侧。
4. 返回 `ans`。

以 `s = "100"` 为例：i=0 是 `'1'`，此时 `zeros = 0`，`ans` 仍为 0；i=1 是 `'0'`，`zeros = 1`；i=2 是 `'0'`，`zeros = 2`。但这样 `ans = 0`，与答案 2 不符——说明方向反了：`1` 要往右走，跨过的是它**右边**的 `0`。正确做法是反向扫描，或等价地：遇 `'1'` 时累加它右侧 `0` 的个数。用反向扫描：从右往左，遇 `'0'` 则 `zeros += 1`，遇 `'1'` 则 `ans += zeros`。对 `"100"`：i=2 `'0'`→`zeros=1`；i=1 `'0'`→`zeros=2`；i=0 `'1'`→`ans=2`，正确。对 `"101"`：i=2 `'1'`→`ans+=0`；i=1 `'0'`→`zeros=1`；i=0 `'1'`→`ans+=1`，得 1，正确。

```python
zeros = ans = 0
for ch in reversed(s):
    if ch == '0':
        zeros += 1
    else:
        ans += zeros
return ans
```

关键中间值：`"101"` 扫到 i=0 时 `zeros = 1`，`ans` 从 0 变 1。

## 复杂度
时间 O(n)：`reversed(s)` 单趟遍历，每个字符 O(1)。
空间 O(1)：只开 `zeros`、`ans` 两个整数，`reversed` 是迭代器不复制串。

## 易错点
- 正向扫描写成「遇 `1` 累加左侧 `0` 数」→ 对 `"100"` 得 0 而非 2 → 必须反向扫，或正向时改成遇 `1` 累加「右侧剩余 `0` 数」（需先统计总数再递减）。
- 用 `s.count('1')` 之类先算总数再逐位减，容易在 `'1'` 处多减一次 → 对 `"0111"` 得负数 → 直接反向累加 `zeros` 最稳，不依赖总数。

## 如果面试官追问
若要求输出具体交换方案而非步数？答：仍反向扫，每个 `1` 与右侧最近的 `0` 依次相邻交换，记录每次交换的下标对即可，步数不变。
