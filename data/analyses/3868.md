## 一句话思路
先统计每个值在 nums1、nums2 中的总出现次数，奇数即无解；再对每个值算「需要跨数组交换」的净对数，答案就是净对数的一半。

## 怎么做
1. 用 `Counter` 合并 `nums1` 和 `nums2`，任一值计数为奇数直接返回 `-1`（相同数组里每个值必须成对出现）。
2. 只统计 `nums1` 中比 `nums2` 多出来的部分：对每个值 `v`，`d = cnt1[v] - cnt2[v]`，若 `d > 0` 就累加 `d`。
3. 每次跨数组交换能消掉 2 个「多余」，所以答案是 `sum(d) // 2`。

以示例 2 为例：`nums1=[10,10], nums2=[20,20]`，`cnt1={10:2}`、`cnt2={20:2}`，只有 `10` 的 `d=2`，`sum(d)=2`，答案 `1`。

```python
from collections import Counter

def minCost(nums1, nums2):
    total = Counter(nums1) + Counter(nums2)
    if any(c % 2 for c in total.values()):
        return -1
    c1, c2 = Counter(nums1), Counter(nums2)
    extra = sum(max(0, c1[v] - c2[v]) for v in c1)
    return extra // 2
```

关键点：免费交换让同一数组内任意重排，所以只需关心「每个值在两个数组各有多少个」，位置完全无关。`extra` 是 nums1 里必须换出去的个数，一次花费 1 的交换同时修正 nums1 和 nums2 各一个位置，故除以 2。

## 复杂度
时间 O(n)：两次 Counter 遍历 n 个元素，值域 ≤ 8*10^4 不影响量级。
空间 O(k)：k 为不同值的个数，最多 8*10^4，开了两个 Counter 加一个合并 Counter。

## 易错点
- 输入 `nums1=[1,2], nums2=[1,2]` 时若只比较 `cnt1[v]-cnt2[v]` 的正负而不先判奇偶，会漏掉「某值总数为奇数」的无解情况；必须先对合并计数判 `% 2`，如 `[1,1], [2,3]` 中 3 出现 1 次应返回 -1。
- 输入 `nums1=[1,1,2,2], nums2=[2,2,1,1]` 时若把 `d` 的绝对值都累加再除以 2，会得到 0 但逻辑绕；正确做法是只累加 `d > 0` 的部分，因为 nums1 多出的必然等于 nums2 多出的，单边求和已足够。

## 如果面试官追问
问：如果要求输出具体交换方案怎么办？
答：按值配对，把 nums1 中多余的值与 nums2 中多余的值两两配对，每对输出一次下标交换即可。
