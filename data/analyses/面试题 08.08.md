## 一句话思路
排序后回溯，每层跳过与前一个相同且未使用的字符，避免重复排列。

## 怎么做
1. 先对 `S` 排序，让相同字符相邻，才能用「与前一个相同」判断重复。
2. 回溯时用 `used` 数组标记已选位置，每层遍历所有下标。
3. 剪枝条件：`i > 0 and S[i] == S[i-1] and not used[i-1]` 时跳过——相同字符必须按顺序使用。
4. 路径长度等于 `len(S)` 时收集结果。

以 `S = "qqe"` 为例，排序后 `S = "eqq"`。第一层选 `e`（下标 0）后，第二层遍历到下标 2 的 `q` 时，`S[2] == S[1]` 且 `used[1]` 为 `False`，跳过，所以 `q` 只能先选下标 1 再选下标 2，`"eqq"` 只出现一次。

```python
def dfs(path):
    if len(path) == len(S):
        res.append(''.join(path))
        return
    for i in range(len(S)):
        if used[i]:
            continue
        if i > 0 and S[i] == S[i-1] and not used[i-1]:
            continue
        used[i] = True
        path.append(S[i])
        dfs(path)
        path.pop()
        used[i] = False
```

关键中间值：处理 `"eqq"` 分支时，`used = [True, False, False]`，`i = 2` 处 `S[2] == S[1] == 'q'` 且 `used[1] == False`，触发 `continue`，该分支被剪掉。

## 复杂度
时间：O(n × n!)，n 为字符串长度，最坏无重复时全排列 n! 个，每个拼接 O(n)。
空间：O(n)，递归栈深度 n 加 `used` 数组和 `path`，结果集不计入。

## 易错点
- 输入 `"qqe"` 不排序直接回溯 → 相同字符不相邻，`S[i] == S[i-1]` 判断失效，输出含重复的 6 个排列 → 必须先 `S = ''.join(sorted(S))`。
- 剪枝写成 `S[i] == S[i-1]` 而不带 `not used[i-1]` → 输入 `"qqe"` 时连 `"qqe"` 本身都被剪掉，只剩 `"eqq"` → 必须加 `not used[i-1]`，保证相同字符按从左到右顺序使用。

## 如果面试官追问
追问：若要求按字典序输出且不能先排序怎么办？
答：用 `Counter` 统计字符频次，每层按字符升序遍历、频次减一递归，天然有序且自动去重。
