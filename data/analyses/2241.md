## 一句话思路
从 500 到 20 贪心试取，取完再验剩余金额是否为 0，为 0 才真正扣库存。

## 怎么做
1. 用 `cnt = [0]*5` 存五种面额张数，面额表 `vals = [20,50,100,200,500]`。
2. `withdraw` 里从下标 4 倒着扫到 0，每种面额取 `min(cnt[i], amount // vals[i])` 张，记进 `used`，并临时从 `amount` 里减掉。
3. 扫完后若 `amount != 0`，直接返回 `[-1]`，此时 `cnt` 一个都没动。
4. 若 `amount == 0`，才把 `used` 从 `cnt` 里扣掉并返回 `used`。

以示例第一次 `withdraw(600)` 为例，库存 `[0,0,1,2,1]`：500 取 1 张，`amount` 变 100；200 取 0 张（100//200=0）；100 取 1 张，`amount` 变 0；50、20 各取 0 张，返回 `[0,0,1,0,1]`。

```python
def withdraw(self, amount):
    used = [0] * 5
    for i in range(4, -1, -1):
        take = min(self.cnt[i], amount // self.vals[i])
        used[i] = take
        amount -= take * self.vals[i]
    if amount != 0:
        return [-1]
    for i in range(5):
        self.cnt[i] -= used[i]
    return used
```

关键点：`used` 只是草稿，`cnt` 的扣减必须放在 `amount == 0` 判定之后，否则第二次 `withdraw(600)` 会先把 500 扣掉再失败，库存被污染。

## 复杂度
时间：每次操作固定扫 5 种面额，O(1)，与 amount 大小无关。
空间：`cnt`、`used` 各 5 个元素，O(1) 额外空间。

## 易错点
1. 输入 `withdraw(600)` 且库存 `[0,1,0,3,1]` → 若边取边扣 `cnt`，500 被扣掉后 `amount` 剩 100 取不出，返回 `[-1]` 但库存已变成 `[0,1,0,3,0]` → 正确做法是先写 `used` 草稿，`amount != 0` 时直接返回，`cnt` 保持原样。
2. 输入 `withdraw(550)` 且库存 `[0,1,0,0,1]` → 若从 20 往上贪心或先取 200 再回头找零，会漏掉 50+500 的组合 → 正确做法是严格从 500 往下扫，`amount // vals[i]` 保证大面额优先，550 先取 500 剩 50，再取 1 张 50 归零。

## 如果面试官追问
问：面额改成任意 5 个不保证整除的数，贪心还成立吗？
答：不成立，需对 5 种面额做带记忆的搜索或 DP，状态是剩余金额与各面额张数。
