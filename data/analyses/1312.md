## 一句话思路
区间 DP：`dp[i][j]` 表示把 `s[i..j]` 变成回文的最少插入数，两端相等就剥掉，不等就补一边。

## 怎么做
1. 定义 `dp[i][j]` 为子串 `s[i..j]` 的最少插入次数，长度从 1 开始按区间长度递增填表。
2. 若 `s[i] == s[j]`，两端天然配对，`dp[i][j] = dp[i+1][j-1]`（长度 ≤2 时为 0）。
3. 若不等，必须在一侧补字符，`dp[i][j] = 1 + min(dp[i+1][j], dp[i][j-1])`。
4. 答案取 `dp[0][n-1]`。

以 `s = "mbadm"`（n=5）为例，关键中间值：`i=0, j=4` 时 `s[0]='m' == s[4]='m'`，直接继承 `dp[1][3]`；而 `dp[1][3]` 对应 `"bad"`，`s[1]='b' != s[3]='d'`，得 `1 + min(dp[2][3], dp[1][2]) = 1 + min(1, 1) = 2`。所以 `dp[0][4] = 2`，与示例输出一致。

```python
n = len(s)
dp = [[0] * n for _ in range(n)]
for length in range(2, n + 1):
    for i in range(n - length + 1):
        j = i + length - 1
        if s[i] == s[j]:
            dp[i][j] = dp[i + 1][j - 1] if length > 2 else 0
        else:
            dp[i][j] = 1 + min(dp[i + 1][j], dp[i][j - 1])
return dp[0][n - 1]
```

注意 `length == 2` 且两字符相等时，`dp[i+1][j-1]` 的区间是 `i+1 > j-1`，越界，必须特判成 0。

## 复杂度
时间 O(n²)：两层循环枚举所有区间，n = len(s) ≤ 500。
空间 O(n²)：`dp` 是 n×n 表，可滚动成一维降到 O(n)。

## 易错点
- 输入 `s = "ab"` → 若直接写 `dp[i][j] = dp[i+1][j-1]`，`i+1=1 > j-1=0` 会取到错误下标（Python 里 `dp[1][0]` 是 0 但语义错，换语言直接越界）→ 正确做法是长度 2 且相等时显式赋 0。
- 输入 `s = "leetcode"` → 若把不等分支写成 `1 + dp[i+1][j-1]`（漏掉补单边）→ 会得到 3 而非 5；正确做法是 `1 + min(dp[i+1][j], dp[i][j-1])`，因为补一个字符只能消掉左端或右端一个。

## 如果面试官追问
问：n 放大到 5000 怎么办？答：O(n²) 空间先滚成一维，时间仍是 O(n²)，若还不行就转成求 `s` 与 `reverse(s)` 的 LCS，答案 = n − LCS 长度。
