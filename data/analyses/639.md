## 一句话思路
用滚动变量做 DP：`dp[i]` 表示前 i 个字符的解码数，由「单字符 `s[i-1]`」和「双字符 `s[i-2..i-1]`」两类转移相加，`*` 按 1-9 或 10-26 的合法个数展开。

## 怎么做
1. 定义 `one(c)` 返回单字符解码数：`'*'` 返回 9，`'1'~'9'` 返回 1，`'0'` 返回 0。
2. 定义 `two(a, b)` 返回双字符解码数，按 a 是否为 `*`、b 是否为 `*` 分 4 种情况枚举合法组合数。
3. 滚动 `prev2, prev1`，`cur = prev1 * one(b) + prev2 * two(a, b)`，每步取模。
4. 返回 `prev1`。

以 `s = "2*"` 为例：初始 `prev2=1, prev1=one('2')=1`。处理 `'*'` 时 `one('*')=9`，`two('2','*')` 中 `'2'` 配 `1~6` 共 6 个合法，故 `cur = 1*9 + 1*6 = 15`，与示例一致。

```python
MOD = 10**9 + 7
def one(c):
    return 9 if c == '*' else (0 if c == '0' else 1)
def two(a, b):
    if a == '*' and b == '*': return 15
    if a == '*': return 2 if b <= '6' else 1
    if b == '*': return 9 if a == '1' else (6 if a == '2' else 0)
    return 1 if 10 <= int(a + b) <= 26 else 0
prev2, prev1 = 1, one(s[0])
for i in range(1, len(s)):
    cur = (prev1 * one(s[i]) + prev2 * two(s[i-1], s[i])) % MOD
    prev2, prev1 = prev1, cur
return prev1
```

## 复杂度
时间 O(n)：单次遍历，每步常数次判断。
空间 O(1)：只开 `prev2/prev1/cur` 三个变量。

## 易错点
- 输入 `"0"` 或 `"06"` → 若把 `one('0')` 写成 1 会得到 1，实际应为 0；`'0'` 只能作为 `10`/`20` 的第二位出现，`one` 必须返回 0。
- 输入 `"1*"` → 若 `two('1','*')` 直接返回 9，会漏掉 `'*'` 取 `1~9` 全部合法（10-19），正确是 9；而 `two('2','*')` 只有 `1~6` 合法，返回 6，两者不能混用同一个分支。

## 如果面试官追问
问：若要求输出所有解码方案而非计数？
答：把滚动变量换成 `dp[i]` 存列表，双字符转移时对每个合法组合拼接前缀，空间升到 O(方案数)。
