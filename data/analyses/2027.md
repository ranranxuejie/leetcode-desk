## 一句话思路
从左往右扫，遇到第一个 `'X'` 就把它当窗口左端连翻 3 个，贪心因为任何覆盖它的操作都必须从这里开始。

## 怎么做
1. 用下标 `i` 从 0 扫到 `n-1`，维护计数 `ans = 0`。
2. 遇到 `s[i] == 'X'` 时，说明位置 `i` 还没被覆盖，必须有一次操作以 `i` 为左端（或更左，但更左已被处理过），于是 `ans += 1`。
3. 这次操作覆盖 `i, i+1, i+2`，直接把 `i` 跳到 `i+3`，跳过已翻成 `'O'` 的三个位置。
4. 遇到 `'O'` 就 `i += 1` 继续。

以 `s = "XXOX"` 为例：`i=0` 是 `'X'`，`ans=1`，跳到 `i=3`；`s[3]='X'`，`ans=2`，跳到 `i=6` 结束，返回 2。注意 `i=1` 的 `'X'` 被第一次操作顺带覆盖，不需要单独计数。

```python
i, ans, n = 0, 0, len(s)
while i < n:
    if s[i] == 'X':
        ans += 1
        i += 3
    else:
        i += 1
return ans
```

关键点：跳 3 而不是跳 1，是因为这次操作已经把 `i+1`、`i+2` 变成 `'O'`，再检查它们是浪费；同时也不能跳更多，因为 `i+3` 之后的 `'X'` 这次没被覆盖。

## 复杂度
时间 O(n)：`i` 每次至少 +1，最多扫一遍字符串。
空间 O(1)：只用了 `i`、`ans`、`n` 三个变量，没开额外数组。

## 易错点
- 输入 `"XXOX"` → 若在 `i=0` 翻完后只 `i += 1`，会在 `i=1` 的 `'X'` 上再翻一次，得到 3 而非 2 → 正确做法是翻完直接 `i += 3`，因为 `i+1`、`i+2` 已被覆盖。
- 输入 `"XOXOX"`（长度 5）→ 若在 `i=0` 翻 `0..2` 后跳到 `i=3`，`s[3]='O'` 跳过，`i=4` 是 `'X'` 再翻一次，答案 2；但若误以为窗口必须对齐 3 的倍数、只检查 `i=0,3`，会漏掉 `i=4` 的 `'X'` 而返回 1 → 正确做法是逐个下标扫，不按步长 3 对齐。

## 如果面试官追问
问：若操作改为「翻转任意长度不超过 3 的连续段」怎么变？
答：仍贪心，遇到 `'X'` 就翻以它为左端的最长段（最多 3），答案不变，因为覆盖越靠右越不亏。
