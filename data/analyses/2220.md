## 一句话思路
把 start 和 goal 异或，结果里每个 1 就是一位需要翻转的位，数 1 的个数即可。

## 怎么做
1. 计算 `diff = start ^ goal`，异或后为 1 的位恰好是两数不同的位。
2. 统计 `diff` 二进制中 1 的个数，就是最少翻转次数。
3. 用 `bin(diff).count('1')` 或循环 `diff &= diff - 1` 统计。

以示例 1 为例：`start = 10`（1010），`goal = 7`（0111），`diff = 10 ^ 7 = 13`（1101）。`bin(13)` 是 `'0b1101'`，其中 1 的个数为 3，对应需要翻转第 1、3、4 位，答案 3。

```python
diff = start ^ goal
ans = 0
while diff:
    diff &= diff - 1   # 消掉最低位的 1
    ans += 1
return ans
```

也可一行：`return bin(start ^ goal).count('1')`。`diff &= diff - 1` 每执行一次消除一个 1，循环次数等于 1 的个数，比逐位扫描 30 次更省。

## 复杂度
时间：O(log(max(start, goal)))，即二进制位数，最多约 30 次循环。
空间：O(1)，只用了 `diff` 和 `ans` 两个变量。

## 易错点
- 输入 `start = 0, goal = 0` → 若用 `while diff:` 前忘了初始化 `ans = 0`，或误以为要返回 1 → 正确做法是 `diff = 0` 时直接返回 0，两数相同无需翻转。
- 输入 `start = 3, goal = 4` → 若只比较两者二进制长度相同的部分（如都看成 3 位），会漏掉前导 0 的差异 → 正确做法是异或后统计所有位，`3 ^ 4 = 7`（111），答案为 3，前导 0 也算一位。

## 如果面试官追问
问：如果要求输出具体翻转了哪些位怎么办？
答：遍历 `diff` 的每个为 1 的位，记录其下标 `i`（从 0 开始），即为需要翻转的位位置。
