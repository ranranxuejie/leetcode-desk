## 一句话思路
排序后做「以 i 结尾的最长整除链」DP，因为整除关系在升序下只需检查前驱，链上任意两元素自动满足整除。

## 怎么做
1. 先 `nums.sort()`，让整除关系只可能从小的指向大的，`dp[i]` 表示以 `nums[i]` 结尾的最长链长度。
2. 对每个 `i`，遍历 `j < i`，若 `nums[i] % nums[j] == 0` 且 `dp[j] + 1 > dp[i]`，则更新 `dp[i] = dp[j] + 1` 并记 `prev[i] = j`。
3. 记录全局最大长度 `best` 及其下标 `best_i`，从 `best_i` 沿 `prev` 回溯出答案。

以 `nums = [1,2,4,8]` 为例：排序后不变；`i=1`（值 2）时 `2 % 1 == 0`，`dp[1]=2, prev[1]=0`；`i=2`（值 4）时 `4 % 2 == 0`，`dp[2]=3, prev[2]=1`；`i=3`（值 8）时 `dp[3]=4, prev[3]=2`，`best=4`，回溯得 `[8,4,2,1]` 反转即 `[1,2,4,8]`。

```python
nums.sort()
n = len(nums)
dp = [1] * n
prev = [-1] * n
best, best_i = 1, 0
for i in range(n):
    for j in range(i):
        if nums[i] % nums[j] == 0 and dp[j] + 1 > dp[i]:
            dp[i] = dp[j] + 1
            prev[i] = j
    if dp[i] > best:
        best, best_i = dp[i], i
res = []
k = best_i
while k != -1:
    res.append(nums[k])
    k = prev[k]
res.reverse()
```

## 复杂度
时间：`O(n^2)`，双重循环每对 `(i, j)` 检查一次整除，排序的 `O(n log n)` 被吸收。
空间：`O(n)`，`dp` 和 `prev` 各开一个长度 n 的数组，答案列表最多 n 个元素。

## 易错点
- 输入 `[1,2,3]` → 若不排序直接按原顺序 DP，`3 % 2 != 0` 会漏掉 `1` 与 `3` 的整除关系，得到错误链长；正确做法是先 `sort()`，保证 `j < i` 时 `nums[j] < nums[i]`，整除只可能由小指向大。
- 输入 `[2,3,4,9]` → 若只更新 `dp[i]` 而不记 `prev[i]`，回溯时无法还原具体子集，只能拿到长度；正确做法是每次更新 `dp[i]` 时同步写 `prev[i] = j`，回溯从 `best_i` 沿 `prev` 走。

## 如果面试官追问
问：若 nums 含重复元素怎么办？答：先去重（`sorted(set(nums))`），重复值之间 `a % a == 0` 会错误地把同一值算进链两次。
