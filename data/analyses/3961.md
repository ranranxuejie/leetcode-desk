## 一句话思路
每个设备最多被抽一次，抽走它的最小值后评分升为次小值；把被抽设备的原最小值全部塞给评分最高的设备，其余设备各取次小值。

## 怎么做
1. 对每个设备排序，记 `mn = units[i][0]`（原评分）、`sec = units[i][1]`（抽走一个后的评分，n=1 时为空设备评分 0）。
2. 关键观察：被抽的设备评分变成 `sec`，没被抽的保持 `mn`；抽出的单元全给某个设备，它只会变大不会变小，所以「接收方」的评分不受损。
3. 枚举「哪个设备当接收方」，它不贡献自己的 `mn` 给池子，其余设备的 `mn` 全部可转移；被抽的设备取 `sec`，未被抽的取 `mn`。
4. 用 `sum(mn) - mn[i]` 表示除 i 外所有设备原评分之和，再对每个 j≠i 把 `mn[j]` 换成 `sec[j]`，取增益最大的那些。

以 `units = [[1,3],[2,2]]` 为例：`mn = [1,2]`，`sec = [3,2]`。选 i=0 当接收方，池子只有 `mn[1]=2`；设备 1 被抽后变 `sec[1]=2`，设备 0 收下 2 后评分 `min(1,3,2)=1`，总和 3。选 i=1 当接收方，池子 `mn[0]=1`，设备 0 变 `sec[0]=3`，设备 1 收下 1 后 `min(2,2,1)=1`，总和 4。

```python
mn = [min(row) for row in units]
sec = []
for row in units:
    s = sorted(row)
    sec.append(s[1] if len(s) > 1 else 0)
total = sum(mn)
best = total  # 零次操作
for i in range(len(units)):
    base = total - mn[i]
    gain = 0
    for j in range(len(units)):
        if j != i and sec[j] > mn[j]:
            gain += sec[j] - mn[j]
    best = max(best, base + gain)
return best
```

## 复杂度
时间：每个设备排序 O(n log n)，总计 O(m·n log n)，m 为设备数。
空间：`mn`、`sec` 各 O(m)，排序临时数组 O(n)。

## 易错点
- `n = 1` 的设备（如 `units = [[5],[3]]`）→ 抽走唯一单元后变空设备评分 0，`sec` 必须取 0 而不是越界或取 `mn` → 代码里 `s[1] if len(s) > 1 else 0` 要写对。
- 接收方自己也被抽（`i` 同时是源）→ 会误把 `mn[i]` 算进池子并让 `sec[i]` 生效，导致重复计算 → 枚举时 `j != i` 必须排除，接收方保持原 `mn[i]` 不变。

## 如果面试官追问
要求输出具体转移方案怎么办？答：记录最优的接收方 `i` 和所有满足 `sec[j] > mn[j]` 的源 `j`，把每个 `j` 的最小单元移给 `i` 即可。
