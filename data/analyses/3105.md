## 一句话思路
一次遍历同时维护以当前元素结尾的最长严格递增/递减长度，取全局最大值。

## 怎么做
1. 初始化 `inc = dec = ans = 1`，从下标 1 开始遍历。
2. 若 `nums[i] > nums[i-1]`，则 `inc += 1`、`dec = 1`；若 `<`，则 `dec += 1`、`inc = 1`；若相等，两者都重置为 1。
3. 每步用 `ans = max(ans, inc, dec)` 更新答案。

以 `nums = [1,4,3,3,2]` 为例：i=1 时 4>1，`inc=2, dec=1`，ans=2；i=2 时 3<4，`dec=2, inc=1`；i=3 时 3==3，两者都回到 1；i=4 时 2<3，`dec=2`。最终 ans=2。

```python
inc = dec = ans = 1
for i in range(1, len(nums)):
    if nums[i] > nums[i - 1]:
        inc += 1
        dec = 1
    elif nums[i] < nums[i - 1]:
        dec += 1
        inc = 1
    else:
        inc = dec = 1
    ans = max(ans, inc, dec)
return ans
```

## 复杂度
时间：O(n)，一次遍历，n 为 `nums` 长度。
空间：O(1)，只开了 `inc`、`dec`、`ans` 三个变量。

## 易错点
- 输入 `[3,3,3,3]` → 若把相等当成递增（用 `>=`）会错得 4，正确做法是相等时 `inc` 和 `dec` 都重置为 1，答案 1。
- 输入 `[3,2,1]` → 若只维护 `inc` 不维护 `dec`，会错得 1，正确做法是两条链各自独立计数，`dec` 在连续下降时累加到 3。

## 如果面试官追问
问：要求返回该子数组本身而非长度？
答：额外记录 `ans` 更新时的起点下标 `i - inc + 1`（或 `i - dec + 1`），最后切片返回。
