## 一句话思路
用 DataFrame 的 `rename(columns=映射字典)` 一次性替换四个列名，行数据原样不动。

## 怎么做
1. 构造映射字典，键是旧列名 `id/first/last/age`，值是 `student_id/first_name/last_name/age_in_years`。
2. 调用 `students.rename(columns=mapping)`，返回新 DataFrame，不改原对象。
3. 直接返回结果，无需 `reset_index` 或重排。

以示例第 1 行为例：`id=1, first="Mason", last="King", age=6`。`rename` 只改列标签，`columns` 从 `["id","first","last","age"]` 变成 `["student_id","first_name","last_name","age_in_years"]`，该行值仍是 `(1,"Mason","King",6)`，位置一一对应。

```python
mapping = {
    "id": "student_id",
    "first": "first_name",
    "last": "last_name",
    "age": "age_in_years",
}
return students.rename(columns=mapping)
```

关键点：`rename` 按列名匹配，不按位置，所以字典顺序无关；未列出的列保持原名。

## 复杂度
时间 O(n)：n 为行数，重命名只改列标签，但返回新对象需复制 n 行数据。
空间 O(n)：额外开一份与输入同规模的 DataFrame。

## 易错点
- 若写成 `students.columns = [...]` 直接赋值，会原地修改输入 `students`，调用方后续再读 `students["id"]` 会 KeyError；正确做法是用 `rename` 返回新对象，或先 `students.copy()` 再改 `columns`。
- 若映射字典键写错（如把 `"first"` 写成 `"firstname"`），`rename` 静默跳过、不报错，输出仍保留 `first` 列名，与期望的 `first_name` 不符；正确做法是逐字核对四个旧列名与题面一致。

## 如果面试官追问
问：若只重命名部分列、其余保持原样怎么办？
答：映射字典只放要改的键值对，`rename` 天然支持部分重命名，未命中的列原样保留。
