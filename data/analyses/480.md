## 一句话思路
用两个堆（大顶堆存较小半、小顶堆存较大半）加延迟删除，滑动时维持两堆大小差 ≤1，堆顶即中位数。

## 怎么做
1. 把窗口前 k 个元素按大小分进 `lo`（存负数模拟大顶堆）和 `hi`，保持 `len(lo) == len(hi)` 或 `len(lo) == len(hi)+1`。
2. 每次右移：新元素按与 `lo[0]` 的比较入堆，旧元素记入 `delayed` 哈希表延迟删除，再调平两堆。
3. 取中位数前先 `prune`：堆顶若在 `delayed` 里就弹出并减计数，直到堆顶是有效元素。
4. 偶数 k 取 `(-lo[0] + hi[0]) / 2`，奇数 k 取 `-lo[0]`。

以 `nums=[1,3,-1,-3,5,3,6,7], k=3` 为例：初始窗口 `[1,3,-1]` 排序后 `[-1,1,3]`，`lo=[-1]`（存 `1`）、`hi=[3]`，中位数 `-lo[0]=1`。滑到 `[3,-1,-3]` 时删 `1`、加 `-3`，`delayed={1:1}`，调平后 `lo` 顶仍是 `1` 但已失效，`prune` 弹出后 `lo[0]=-1`，中位数 `-1`。

```python
import heapq
lo, hi, delayed = [], [], {}
def prune():
    while lo and delayed.get(-lo[0], 0):
        delayed[-lo[0]] -= 1
        heapq.heappop(lo)
    while hi and delayed.get(hi[0], 0):
        delayed[hi[0]] -= 1
        heapq.heappop(hi)
def balance():
    if len(lo) > len(hi) + 1:
        heapq.heappush(hi, -heapq.heappop(lo))
    elif len(lo) < len(hi):
        heapq.heappush(lo, -heapq.heappop(hi))
```

## 复杂度
时间 O(n log k)：n 次滑动，每次堆操作 log k。
空间 O(k)：两堆加 `delayed` 最多存 k 个元素。

## 易错点
- 删除元素时若直接 `heap.remove` 或重建堆，`nums` 长、k 大时会退化成 O(nk)；正确做法是只往 `delayed` 记一笔，取中位数前 `prune` 惰性清理。
- 偶数 k 时 `(-lo[0] + hi[0]) / 2` 若写成 `//` 会丢小数，如 `[1,2]` 得 `1` 而非 `1.5`；必须用 `/` 得 float，题目允许 1e-5 误差。

## 如果面试官追问
问：k 固定但 nums 是流式输入怎么办？
答：堆结构不变，每来一个新元素就 push 再按窗口长度弹出最旧元素，`delayed` 照旧记录，中位数查询仍是 O(log k)。
