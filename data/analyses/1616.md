## 一句话思路
从两端向中间双指针比对 a 与 b，遇到第一处不匹配就检查中间剩余段本身是否回文。

## 怎么做
1. 用 `i=0, j=n-1` 从外向内扫，只要 `a[i]==b[j]` 就 `i+=1, j-=1`，这表示外层已由 `a_prefix + b_suffix` 拼成回文。
2. 扫到第一处 `a[i]!=b[j]` 时停下，此时 `[i, j]` 是还没配对的中间段，它必须整体是回文，且只能来自 a 或 b 之一。
3. 分别检查 `a[i:j+1]` 和 `b[i:j+1]` 是否回文，任一为真即返回 `True`。
4. 若指针交错（`i>=j`）说明全程匹配，直接 `True`；再对调 a、b 跑一遍，覆盖 `b_prefix + a_suffix` 的情形。

以示例 3 `a="ulacfd", b="jizalu"` 为例：`i=0,j=5` 时 `a[0]='u'==b[5]='u'`，`i=1,j=4` 时 `'l'=='l'`，`i=2,j=3` 时 `'a'=='a'`，指针交错返回 `True`。而示例 2 `a="xbdef", b="xecab"`：`i=0` 匹配 `'x'`，`i=1,j=3` 时 `a[1]='b'` 与 `b[3]='a'` 不等，检查 `a[1:4]="bde"` 非回文、`b[1:4]="eca"` 非回文，对调后同样失败，返回 `False`。

```python
def check(a, b):
    i, j = 0, len(a) - 1
    while i < j and a[i] == b[j]:
        i += 1
        j -= 1
    if i >= j:
        return True
    mid_a, mid_b = a[i:j+1], b[i:j+1]
    return mid_a == mid_a[::-1] or mid_b == mid_b[::-1]

return check(a, b) or check(b, a)
```

## 复杂度
时间 O(n)：两次扫描各走一遍，切片反转也是 O(n)。
空间 O(n)：`a[i:j+1]` 与 `[::-1]` 各复制一份中间段。

## 易错点
- 只跑 `check(a,b)` 不跑 `check(b,a)`：示例 3 恰好对称能过，但像 `a="ab", b="ba"` 这类只有 `b_prefix+a_suffix` 成立的输入会漏判成 `False`，必须两次都试。
- 停下后只检查 `a[i:j+1]`：若中间段回文只存在于 b 中（如 `a="abc", b="cba"` 之外的构造），会误判 `False`，正确做法是 a、b 的中间段各查一次，用 `or` 连接。

## 如果面试官追问
问：要求返回具体分割下标怎么办？
答：在 `check` 里记录停下时的 `i`，若 `a[i:j+1]` 回文则分割点为 `i`，否则为 `j+1`，对调时同理。
