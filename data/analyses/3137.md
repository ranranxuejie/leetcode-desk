## 一句话思路
把 word 按 k 切成 n/k 块，统计出现次数最多的块，其余块各用一次操作替换成它。

## 怎么做
1. 用切片 `word[i:i+k]` 遍历 `i = 0, k, 2k, ...`，得到全部 `n//k` 个块。
2. 用字典 `cnt` 统计每种块的出现次数。
3. 答案 = 总块数 − `max(cnt.values())`，因为保留最多的那种块不动，其余每种块各替换一次。

以 `word = "leetcodeleet", k = 4` 为例，切出 `["leet", "code", "leet"]`，`cnt = {"leet": 2, "code": 1}`，`max = 2`，答案 `3 - 2 = 1`，与示例一致。

```python
from collections import Counter

cnt = Counter(word[i:i + k] for i in range(0, len(word), k))
total = len(word) // k
return total - max(cnt.values())
```

关键点：一次操作能把任意一个块变成任意另一个块（因为 j 可以选任意 k 的倍数下标），所以「每个非目标块恰好一次操作」是可达的，也是下界。

## 复杂度
时间：O(n)，切片与哈希共扫描 n 个字符，每次切片长度 k 合计 n。
空间：O(n/k) 个块存入 Counter，最坏 O(n)。

## 易错点
- 误以为要模拟替换过程 → 对 `"leetcoleet", k=2` 会去逐次改字符串、算错成 4 或更多 → 正确做法是只数块频次，答案 `5 - 2 = 3`。
- 把 `max(cnt.values())` 写成 `cnt.most_common(1)[0][1]` 之外的错误下标，或对空 Counter 取 max → 本题 n≥1 且 k 整除 n，块数至少 1，不会空；但若写成 `len(cnt)` 当答案就错了，应为 `total - max`。

## 如果面试官追问
问：如果要求输出具体操作序列怎么办？
答：把众数块的下标记为 j，其余每个块下标 i 输出一次 `(i, j)`，顺序任意，共 `total - max` 对。
