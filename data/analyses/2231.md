## 一句话思路
按位拆成数字后，偶数位只能和偶数位互换、奇数位只能和奇数位互换，所以把两类数字各自降序填回原位置即可。

## 怎么做
1. 把 `num` 转成字符串 `s`，逐位取 `int(c)` 得到列表 `digits`。
2. 按奇偶把 `digits` 分成两组：`evens = sorted([d for d in digits if d % 2 == 0], reverse=True)`，`odds` 同理。
3. 从左到右扫 `digits`，遇到偶数位就弹出 `evens` 当前最大值填进去，遇到奇数位就弹 `odds` 的最大值。
4. 把填好的列表拼回整数返回。

以 `num = 65875` 为例，`digits = [6,5,8,7,5]`，`evens = [8,6]`，`odds = [7,5,5]`。第 0 位是偶数位，取 `evens` 最大 8；第 1 位是奇数位，取 `odds` 最大 7；第 2 位偶数位取 6；第 3、4 位奇数位依次取 5、5，得到 `[8,7,6,5,5]` 即 87655。

```python
s = str(num)
digits = [int(c) for c in s]
evens = sorted((d for d in digits if d % 2 == 0), reverse=True)
odds  = sorted((d for d in digits if d % 2 == 1), reverse=True)
res = []
for d in digits:
    if d % 2 == 0:
        res.append(evens.pop(0))
    else:
        res.append(odds.pop(0))
return int(''.join(map(str, res)))
```

关键点：判断某一位该填哪类数字，看的是**原位置**的奇偶性，不是当前剩余数字的奇偶性——因为交换不改变每一位的奇偶属性。

## 复杂度
时间：O(n log n)，n 为位数（≤10），排序两组数字贡献 log n。
空间：O(n)，`digits`、`evens`、`odds`、`res` 各存一份数字。

## 易错点
- 输入 `num = 1234` 时，若把 `evens` 和 `odds` 合并成一个降序列表再从左填，会得到 4321，但 4 和 1 奇偶不同不能换 → 必须分组各自排序，按原位置奇偶性回填。
- 输入 `num = 65875` 时，若用 `d % 2 == 0` 判断「当前要填的数字」而不是「原位置」，第 0 位原为 6（偶），却可能先弹 `odds` 的 7 填进去 → 判断依据必须是 `digits` 里原位置的奇偶，不是候选池。

## 如果面试官追问
问：如果要求返回所有能达到最大值的交换方案数怎么办？
答：最大值的每个位置取值唯一确定，方案数等于各奇偶组内相同数字的排列数之积，即对每组内每个重复数字计 `count!`。
