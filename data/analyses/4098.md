## 一句话思路
答案关于最大值 `M` 单调，二分 `M`，用「从 `value` 向两侧贪心取最小合法倍数」的可行性检查判定。

## 怎么做
1. 先判 `index` 两侧是否放得下：左侧要 `index` 个严格递增且都 `< value` 的正整数，右侧要 `n-1-index` 个严格递增且都 `> value` 的数，且每步 `gcd > 1`。
2. 检查函数 `ok(M)`：从 `value` 向左，每一步取「小于当前值、且与当前值 gcd>1 的最大数」，即 `cur - gcd(cur, ?)` 不行，正确做法是枚举 `cur` 的质因子 `p`，取 `cur - p` 中最大的那个（因为 `gcd(cur, cur-p) ≥ p > 1`）。
3. 右侧对称：取「大于当前值、且与当前值 gcd>1 的最小数」，即 `cur + p` 中最小的那个；同时右侧所有数不得超过 `M`。
4. 二分下界 `value`、上界取 `value * (n + 1)`（每步最多翻倍量级），`ok` 为真就收右界。

以 `n=4, index=2, value=8` 为例：右侧一步，`8` 的质因子是 `2`，候选 `8+2=10`，`M=9` 时 `10>9` 失败，`M=10` 成功；左侧一步取 `8-2=6`，再左一步 `6-2=4`，再左 `4-2=2`，都 `<8` 且递增，故答案 `10`。

```python
def factors(x):
    res, d = [], 2
    while d * d <= x:
        if x % d == 0:
            res.append(d)
            while x % d == 0:
                x //= d
        d += 1
    if x > 1:
        res.append(x)
    return res

def ok(M, n, index, value):
    cur = value
    for _ in range(index):                 # 向左 index 步
        ps = factors(cur)
        if not ps:
            return False
        cur -= max(ps)                     # 取最大质因子，下降最快
        if cur <= 0:
            return False
    cur = value
    for _ in range(n - 1 - index):         # 向右
        ps = factors(cur)
        if not ps:
            return False
        cur += min(ps)
        if cur > M:
            return False
    return True
```

## 复杂度
时间：二分 `O(log(value·n))` 次，每次 `O(n·√value)`，`n` 来自步数、`√value` 来自试除分解。
空间：`O(√value)` 存质因子列表，无额外数组。

## 易错点
- `n` 高达 `10^9` 而 `value` 只有 `10^9`：左侧最多只能放 `value-1` 个不同正整数，若 `index >= value` 直接返回 `-1`；同理右侧若 `n-1-index` 步内 `cur` 增长超过上界也要提前判死，否则循环 `10^9` 次超时。
- `value=1` 时 `factors(1)` 为空，任何一侧有邻居都无解；别把 `1` 当成「质因子为空但可以继续」处理，要显式返回 `-1`。

## 如果面试官追问
问：要求输出具体数组而非最大值怎么办？
答：二分出 `M` 后，从 `value` 向两侧按同一贪心规则（左取 `cur-max(p)`、右取 `cur+min(p)`）回填即可，步数与检查一致。
