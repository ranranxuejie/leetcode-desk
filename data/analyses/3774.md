## 一句话思路
排序后取首尾各 k 个求和相减，因为排序把「k 个最大/最小」变成连续的两段。

## 怎么做
1. 对 `nums` 原地排序，`nums.sort()`。
2. 最小 k 个是 `nums[0:k]`，最大 k 个是 `nums[n-k:n]`。
3. 两段分别求和后相减，取绝对值。

以 `nums = [5,2,2,4], k = 2` 为例：排序后 `nums = [2,2,4,5]`，`n = 4`，`n-k = 2`。最小段 `nums[0:2] = [2,2]` 和为 4，最大段 `nums[2:4] = [4,5]` 和为 9，`abs(9-4) = 5`。

```python
nums.sort()
n = len(nums)
small = sum(nums[:k])
large = sum(nums[n - k:])
return abs(large - small)
```

关键点：`nums[n-k:]` 而不是 `nums[n-k:n-1]`，切片右端省略才包含最后一个元素 `5`；写成 `n-1` 会漏掉最大值，示例 1 会错成 `abs(4-4)=0`。

## 复杂度
时间：排序 O(n log n) 主导，两次切片求和 O(k)，合计 O(n log n)。
空间：`sort()` 原地 O(1) 额外空间（不计切片临时列表，最多 O(k)）。

## 易错点
- `k == n` 时（如 `nums = [100], k = 1`）最大段和最小段是同一整段，两和相等，答案必须是 0；若把最大段写成 `nums[n-k:n-1]` 会漏元素，得到非 0 的错值。
- 有重复元素时（示例 1 的两个 `2`）不能用 `set(nums)` 去重再取 k 个，去重后只剩 `[2,4,5]`，最小段变成 `[2,4]` 和为 6，答案错成 3；必须保留重复，直接对原数组切片。

## 如果面试官追问
问：n 放大到 10^6、k 很小时还排序吗？
答：用 `heapq.nsmallest(k, nums)` 和 `nlargest(k, nums)`，O(n log k)，避免全排序。
