## 一句话思路
滑动窗口维护「至多含一个 0」的最长区间，答案取窗口长度减一。

## 怎么做
1. 用 `left` 和 `zero_cnt` 记录窗口左端与窗口内 0 的个数，`right` 从 0 扫到 `len(nums)-1`。
2. `nums[right] == 0` 时 `zero_cnt += 1`，随后 `while zero_cnt > 1` 就右移 `left`，移出 0 时 `zero_cnt -= 1`。
3. 每轮更新 `ans = max(ans, right - left + 1)`，最后返回 `max(ans - 1, 0)`。

拿示例 2 `nums = [0,1,1,1,0,1,1,0,1]` 走关键一步：`right` 到 4（第二个 0）时，窗口是 `[0,1,1,1,0]`，`zero_cnt = 2`，`left` 从 0 右移到 1，移出的正是 `nums[0] = 0`，`zero_cnt` 回到 1，此时窗口 `[1,1,1,0]` 长度 4；`right` 继续到 6 时窗口 `[1,1,1,0,1,1]` 长度 6，`ans = 6`，最后 `6 - 1 = 5`，与输出一致。

```python
left = zero_cnt = ans = 0
for right, x in enumerate(nums):
    if x == 0:
        zero_cnt += 1
    while zero_cnt > 1:
        if nums[left] == 0:
            zero_cnt -= 1
        left += 1
    ans = max(ans, right - left + 1)
return max(ans - 1, 0)
```

窗口长度减一是因为题目强制删掉一个元素：窗口里那个 0 被删掉，剩下的全是 1；若窗口本身全 1（示例 3），删掉任意一个 1 后剩 `ans - 1` 个。

## 复杂度
时间 O(n)：`right` 和 `left` 各单向走一遍，每个下标最多进出窗口一次。
空间 O(1)：只开了 `left`、`zero_cnt`、`ans` 三个整数。

## 易错点
- 输入 `nums = [1,1,1]` → 若直接返回 `ans` 会得 3，但题目要求必须删一个元素 → 正确做法是返回 `ans - 1`，且用 `max(ans - 1, 0)` 兜住全 0 的情况（如 `[0,0]` 得 0）。
- 输入 `nums = [0,1,1,1,0,1,1,0,1]` → 若 `while` 写成 `if`，`right` 到 4 时只把 `left` 挪一步，`zero_cnt` 仍为 2，后续窗口会带着两个 0 继续算，答案偏大 → 必须用 `while zero_cnt > 1` 收缩到窗口内只剩一个 0。

## 如果面试官追问
追问：改成「最多删 k 个元素」怎么改？
答：把 `zero_cnt > 1` 改成 `zero_cnt > k`，返回 `max(ans - k, 0)`，复杂度不变。
