## 一句话思路
用短除法反复对 -2 取余，余数为 -1 时改成 1 并把商加一，直到 n 为 0。

## 怎么做
1. 特判 `n == 0` 直接返回 `"0"`，否则循环 `while n != 0`。
2. 每轮取 `r = n % -2`，Python 的 `%` 结果符号跟除数走，所以 `r` 只会是 0 或 -1。
3. 若 `r == -1`，把 `r` 改成 1，同时 `n = n // -2 + 1`；否则 `n = n // -2`。
4. 把 `r` 追加到结果列表，最后反转拼接。

以 `n = 2` 为例：第一轮 `2 % -2 = 0`，`n = 2 // -2 = -1`，记下 `"0"`；第二轮 `-1 % -2 = -1`，改成 1，`n = -1 // -2 + 1 = 0 + 1 = 1`，记下 `"1"`；第三轮 `1 % -2 = -1`，改成 1，`n = 1 // -2 + 1 = -1 + 1 = 0`，记下 `"1"`。反转得 `"110"`。

```python
if n == 0:
    return "0"
digits = []
while n != 0:
    r = n % -2
    if r == -1:
        r = 1
        n = n // -2 + 1
    else:
        n = n // -2
    digits.append(str(r))
return "".join(reversed(digits))
```

关键点在第 3 步的 `+1`：`-1 // -2` 在 Python 里是 `0`（向下取整），而 `-1 = (-2) * 0 + (-1)`，余数 -1 不合法，必须借一位变成 `-1 = (-2) * 1 + 1`，所以商要加一。

## 复杂度
时间：O(log n)，每轮 n 的绝对值约减半，位数就是 log₂n。
空间：O(log n)，digits 列表存了每一位，无其他额外结构。

## 易错点
- 输入 `n = 1` → 若直接写 `n // -2` 而不处理余数 -1，会得到 `1 % -2 = -1` 却记成 `"-1"` 或死循环 → 正确做法是余数 -1 时改成 1 且商加一，得到 `"1"`。
- 输入 `n = 0` → 若进循环，`0 % -2 = 0`、`0 // -2 = 0`，`while n != 0` 不进，digits 为空，`"".join` 返回 `""` → 正确做法是开头特判返回 `"0"`。

## 如果面试官追问
问：如果要求返回的是负三进制呢？答：同样的短除法，余数范围是 0、-1、-2，把负余数统一加 3 并把商加一即可。
