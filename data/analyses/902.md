## 一句话思路
按位统计：先算所有短于 n 的位数贡献，再逐位比较 n 的每一位，遇到不在 digits 里的数字就提前结束。

## 怎么做
1. 设 `L = len(str(n))`，`k = len(digits)`。所有长度 `1..L-1` 的数字都小于 n，贡献 `sum(k**i for i in range(1, L))`。
2. 逐位扫描 n 的每一位 `d`，统计 digits 中小于 `d` 的个数 `cnt`，贡献 `cnt * k**(剩余位数)`。
3. 若 `d` 本身在 digits 中，继续下一位；否则立即 break，不再累加。
4. 若所有位都匹配，最后 `+1`（n 本身可生成）。

以 `digits=["1","3","5","7"], n=100` 为例：`L=3, k=4`，短位数贡献 `4+16=20`。第 0 位 `d='1'`，`cnt=0`（没有比 '1' 小的），'1' 在 digits 中继续；第 1 位 `d='0'`，`cnt=0`，'0' 不在 digits 中，break。最终答案 20。

```python
s = str(n)
k = len(digits)
ans = sum(k**i for i in range(1, len(s)))
for i, ch in enumerate(s):
    cnt = sum(1 for d in digits if d < ch)
    ans += cnt * k**(len(s) - i - 1)
    if ch not in digits:
        return ans
return ans + 1
```

## 复杂度
时间：O(L·k)，L 是 n 的位数（≤10），k 是 digits 长度（≤9）。
空间：O(1)，只用了几个标量变量。

## 易错点
- `n=100, digits=["1","3","5","7"]` → 若在第 1 位 `'0'` 处不 break 而是继续，会把 `'0'` 当作可匹配位，多算后续贡献 → 正确做法是 `ch not in digits` 时立即 return，因为前缀已经无法与 n 相等。
- `digits=["7"], n=8` → 若忘记短位数贡献（`L=1` 时 `range(1,1)` 为空），只算逐位部分得 0，漏掉数字 7 → 正确做法是短位数循环范围写 `range(1, len(s))`，且逐位部分对 `'8'` 得 `cnt=1`（'7'<'8'），贡献 1。

## 如果面试官追问
若 n 可达 10^18 且要求输出所有方案而非计数？答：计数仍用同样按位公式，输出方案则需 DFS 枚举，复杂度变为答案规模本身。
