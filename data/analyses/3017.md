## 一句话思路
把 x、y 归一化成 a<b，先按纯链算距离分布，再用差分数组把「走捷径更近」的那部分对从大距离搬到小距离。

## 怎么做
1. 令 a=min(x,y)、b=max(x,y)；若 a==b 直接返回纯链结果：距离 k 的对数是 2*(n-k)。
2. 纯链贡献用差分：对每个 k，`diff[1]+=2, diff[n-k+1]-=2`，前缀和后得到 base[k]。
3. 只枚举左侧房屋 i∈[1,a]，对每个 i 算它到右侧 j∈[b,n] 的「省下的距离」d = (j-i) - (i→a + 1 + b→j) = (j-i) - (i-a+1+j-b)，d>0 才值得走捷径。
4. 对固定 i，d 随 j 递减，是连续区间：j 从 b 到某个上界 J 时 d≥1。用二分或直接解不等式得 J，把这段区间整体从距离 (j-i) 搬到 (j-i-d)，用差分区间加完成。

以 n=5, x=2, y=4 为例：a=2,b=4。i=1 时 j=4 得 d=(4-1)-(1-2+1+4-4)=3-0=3，j=5 得 d=4-1=3，于是 (1,4)、(1,5) 各从 3、4 搬到 0、1，base 里 k=3 的 2 对消失、k=1 增加 2 对，正好对上输出 [10,8,2,0,0]。

```python
a, b = min(x, y), max(x, y)
diff = [0] * (n + 2)
for k in range(1, n):
    diff[1] += 2
    diff[n - k + 1] -= 2
for i in range(1, a + 1):
    # j 从 b 起，d = (j-i) - (i-a+1+j-b) = b-a+1-2*i 与 j 无关
    d = b - a + 1 - 2 * i
    if d <= 0:
        continue
    hi = min(n, b + d - 1)
    # 区间 [b, hi] 的对从 j-i 搬到 j-i-d
    diff[b - i] += 2
    diff[hi - i + 1] -= 2
    diff[b - i - d] += 2
    diff[hi - i - d + 1] -= 2
```

## 复杂度
时间 O(n)：枚举 i 共 a 次，每次 O(1) 区间加，前缀和 O(n)。
空间 O(n)：只开一个长度 n+2 的 diff 数组。

## 易错点
- x>y 时没交换 → 枚举区间写成 [1,x] 而 b 取错，i 越界或漏算左侧房屋，正确做法是先 `a,b=min,max` 再统一用 a、b。
- 忘记乘 2 → 只统计了 i<j 的无序对，输出恰好是答案的一半；本题按有序对计，每段区间加都要 `+=2`。
- 捷径本身可能不省 → 对 i 较大时 d≤0，若仍执行区间加会把距离搬到负数下标，必须先 `if d<=0: continue`。

## 如果面试官追问
问：n 放大到 10^9 怎么办？
答：枚举 i 的循环变成对 d>0 的 i 求前缀和公式，O(1) 段区间加，总复杂度仍是 O(n) 但 n 指答案长度，需按段压缩输出。
