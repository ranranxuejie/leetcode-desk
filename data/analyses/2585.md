## 一句话思路
按题型做分组背包：`dp[s]` 记恰好 s 分的方法数，每种题型枚举用几道，同型题目不可区分所以只按数量枚举。

## 怎么做
1. 初始化 `dp = [0]*(target+1)`，`dp[0] = 1`，其余为 0。
2. 对每个 `(cnt, mark)`，用上一轮的 `dp` 生成新数组 `ndp`，避免同一题型被重复累加。
3. 枚举该题型用 `k` 道，`k` 从 0 到 `min(cnt, target//mark)`，把 `dp[s]` 加到 `ndp[s + k*mark]`。
4. 全部题型处理完，返回 `dp[target] % (10**9+7)`。

以示例 1 `target=6, types=[[6,1],[3,2],[2,3]]` 为例，处理完 `[6,1]` 后 `dp = [1,1,1,1,1,1,1]`（0 到 6 分各 1 种）；再处理 `[3,2]`，`k=0..3`，`ndp[6]` 累加 `dp[6]+dp[4]+dp[2]+dp[0] = 4`；最后处理 `[2,3]` 时 `dp[6]` 再加 `dp[3]+dp[0]`，得 7。

```python
MOD = 10**9 + 7
dp = [0] * (target + 1)
dp[0] = 1
for cnt, mark in types:
    ndp = dp[:]                      # k = 0
    for s in range(target + 1):
        if dp[s] == 0:
            continue
        for k in range(1, min(cnt, (target - s) // mark) + 1):
            ndp[s + k * mark] = (ndp[s + k * mark] + dp[s]) % MOD
    dp = ndp
return dp[target] % MOD
```

## 复杂度
时间：O(n · target · target/mark)，最坏 O(n · target²)，n 为题型数。
空间：O(target)，只开 `dp` 和 `ndp` 两个长度 target+1 的数组。

## 易错点
- 直接在 `dp` 上原地累加（`dp[s+k*mark] += dp[s]`）→ 同一题型会被当成可重复使用，示例 1 的 7 会算大 → 必须用 `ndp` 承接上一轮结果，处理完再赋值回 `dp`。
- `k` 上界只写 `cnt` 不写 `(target-s)//mark` → 当 `mark=1, cnt=50, target=6` 时会越界访问 `ndp[50]` 报 IndexError → 上界取 `min(cnt, (target-s)//mark)`。

## 如果面试官追问
若 `target` 放大到 10^5 且 `marks` 很小，怎么做？答：把每种题型拆成二进制份数做 0/1 背包，复杂度降到 O(target · Σlog count)。
