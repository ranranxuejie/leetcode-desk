## 一句话思路
把 hBars、vBars 各自排序后求最长连续段长度 L，答案就是 (min(Lh, Lv) + 1)²。

## 怎么做
1. 分别对 hBars、vBars 排序。
2. 各自扫一遍，统计最长连续整数段的长度 Lh、Lv（相邻差 1 就续上，否则重开）。
3. 取 k = min(Lh, Lv) + 1，返回 k * k。

以示例 3 为例：hBars = [2,3] 排序后连续段长 Lh = 2；vBars = [2,4] 排序后 2 和 4 差 2 断开，Lv = 1。k = min(2,1)+1 = 2，答案 4。删掉水平线 3 和竖直线 4 后，空洞横跨 2 条可删线加 1 条固定边界，边长正好 2。

```python
def longest_run(bars):
    bars.sort()
    best = cur = 1
    for i in range(1, len(bars)):
        if bars[i] == bars[i-1] + 1:
            cur += 1
        else:
            cur = 1
        best = max(best, cur)
    return best

lh = longest_run(hBars)
lv = longest_run(vBars)
k = min(lh, lv) + 1
return k * k
```

关键点：连续段长 L 表示能删掉 L 条相邻线，删完后这 L 条线之间的 L+1 个间隔合并成一个空洞，所以边长是 L+1，不是 L。

## 复杂度
时间：排序 O(h log h + v log v)，扫描 O(h + v)，h、v 均 ≤ 100。
空间：排序额外 O(log h + log v) 栈空间，无其他数组。

## 易错点
- 把连续段长 L 直接当边长 → 示例 2 中 hBars=[2]、L=1，会算成面积 1；正确是 (1+1)²=4，因为删 1 条线合并出 2 个间隔。
- 只对 hBars 求连续段就返回 → 示例 3 中 Lh=2 会得 9；必须取 min(Lh, Lv)，正方形受短边约束，答案是 4。

## 如果面试官追问
若要求输出具体删除方案？答：记录最长段起止下标，删该段所有线，横竖各取一段即可。
