## 一句话思路
把等距约束折成「配对」：第 i 与第 n-1-i 个房屋颜色不同，逐对做 3×3 状态 DP。

## 怎么做
1. 只枚举前一半位置 i = 0..n//2-1，每对 (i, n-1-i) 一起决策，状态是这一对的两个颜色。
2. 转移时同时检查三条：i 与 i-1 不同色、n-1-i 与 n-i 不同色（相邻约束）、i 与 n-1-i 不同色（等距约束）。
3. 用 `dp[c1][c2]` 存到当前对为止的最小成本，每对用 9 种组合暴力转移，共 81 次比较。

以示例 1 的 n=4 为例：第 0 对是 (0,3)，`dp` 初值就是 `cost[0][c1]+cost[3][c2]`，c1≠c2。第 1 对是 (1,2)，取 c1=1(颜色2)、c2=2(颜色3) 时，要检查 1≠0 号的颜色 0、2≠3 号的颜色 1，成本 2+1 加上前一对的 3+3，得 9。

```python
INF = float('inf')
m = n // 2
dp = [[INF]*3 for _ in range(3)]
for a in range(3):
    for b in range(3):
        if a != b:
            dp[a][b] = cost[0][a] + cost[n-1][b]
for i in range(1, m):
    ndp = [[INF]*3 for _ in range(3)]
    for a in range(3):
        for b in range(3):
            if a == b or dp[a][b] == INF:
                continue
            for pa in range(3):
                for pb in range(3):
                    if pa == a or pb == b:
                        continue
                    v = dp[pa][pb] + cost[i][a] + cost[n-1-i][b]
                    if v < ndp[a][b]:
                        ndp[a][b] = v
    dp = ndp
return min(min(row) for row in dp)
```

## 复杂度
时间：O(n)，每对固定 81 次转移，n 只贡献对数 n/2。
空间：O(1)，只开两个 3×3 的 dp 表，与 n 无关。

## 易错点
- n=2 时循环体一次都不进，直接返回初值 `dp` 的最小值；若把初值写成 INF 或漏掉 `a != b` 判断，会返回 INF 或允许两端同色。
- 转移里漏掉 `pb == b`（右端相邻约束）只查 `pa == a`，示例 1 会算出 8 这种非法解；四条不等关系必须全写。

## 如果面试官追问
要求输出具体涂色方案怎么办？答：dp 里同时存前驱 (pa,pb)，回溯 m 对再镜像展开即可。
