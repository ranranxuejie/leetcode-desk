## 一句话思路
从后往前维护前缀最小值：answer[i] 就是 cost[0..i] 的最小值，因为付最便宜那个人的钱就能免费越过他后面所有人。

## 怎么做
1. 关键观察：想站到位置 i，只需付某个 j ≤ i 的 cost[j]，然后免费与 j 后面的人逐个交换，所以 answer[i] = min(cost[0..i])。
2. 用变量 `best` 从左到右滚动记录前缀最小值，每步先更新再写入。
3. 拿 `cost = [5,3,4,1,3,2]` 走一遍：i=0 时 best=5；i=1 时 best=min(5,3)=3；i=3 时 best=min(3,4,1)=1，此后 i=4、i=5 的 best 都停在 1，正好得到 `[5,3,3,1,1,1]`。

```python
best = float('inf')
ans = []
for c in cost:
    best = min(best, c)
    ans.append(best)
return ans
```

## 复杂度
时间：O(n)，一次遍历，每个 cost[i] 只比较一次。
空间：O(n)，只额外开了答案数组 ans，best 是常数。

## 易错点
- 误以为必须付 cost[i] 本人 → 对 `[5,3,4,1,3,2]` 的 i=2 会输出 4，正确是 3（付编号 1 再免费换到 2）。记住是前缀最小值，不是 cost[i]。
- 把「免费」理解成双向 → 会以为能从后面绕回前面，对 i=0 输出 1（先付 1 到位置 3 再免费回 0）。实际免费只能往后走，i=0 只能付 cost[0]=5。

## 如果面试官追问
问：如果要求输出具体方案（付给谁）？
答：再存一个 `argmin` 下标，answer[i] 对应付 cost[argmin[i]]，之后免费逐个换过去。
