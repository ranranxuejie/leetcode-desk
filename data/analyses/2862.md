## 一句话思路
把每个下标 i 的平方自由核作为分组键，同组内任意两下标乘积必为完全平方数，取各组元素和的最大值。

## 怎么做
1. 对下标 i（1 基）求平方自由核：把 i 中所有平方因子除掉，剩下的部分记为 key。
2. 用哈希表 `groups[key] += nums[i-1]` 累加同组元素和。
3. 返回所有组和的最大值。

关键中间值：示例 2 中 i=1→key=1，i=4=2²→key=1，i=9=3²→key=1，三者同组，和 8+8+4=20；i=2→key=2，i=8=2³→key=2，同组和 10+9=19，故答案 20。

```python
groups = {}
for i in range(1, len(nums) + 1):
    x, key = i, 1
    d = 2
    while d * d <= x:
        cnt = 0
        while x % d == 0:
            x //= d
            cnt += 1
        if cnt % 2 == 1:
            key *= d
        d += 1
    if x > 1:
        key *= x
    groups[key] = groups.get(key, 0) + nums[i - 1]
return max(groups.values())
```

## 复杂度
时间：O(n·√n)，每个下标试除到 √i，n 为数组长度。
空间：O(n)，哈希表最多存 n 个不同的核。

## 易错点
- 下标是 1 基而非 0 基：若用 `range(len(nums))` 从 0 开始，i=0 的核无意义且 i=4 会被当成 0 基的第 4 个元素，分组全错；正确做法是 `range(1, len(nums)+1)` 再取 `nums[i-1]`。
- 试除后剩余因子 x>1 必须乘进 key：如 i=6 试除 2 后剩 3，若漏掉则 key=2 而非 6，会把 6 和 2 错分到一组；正确做法是循环结束后 `if x > 1: key *= x`。

## 如果面试官追问
若 n 扩大到 10^6 怎么优化？答：预处理 1..n 的平方自由核（线性筛或对每个数只试除到 √n 并缓存），把每组求和降到 O(n log n) 级别。
