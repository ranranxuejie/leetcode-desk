## 一句话思路
从右往左找第一个 `'2'`，删掉它右边所有字符，剩下的就是最大偶数。

## 怎么做
1. 偶数末位只能是 `'2'`，所以结果串的最后一个字符必须是某个 `'2'`。
2. 位数越多数越大，因此要保留尽可能长的前缀，即选最靠右的 `'2'` 作末位。
3. 该 `'2'` 右侧的字符全部删除，左侧原样保留（`'1'` 和 `'2'` 都保留，删了只会变小）。
4. 找不到 `'2'` 就返回 `""`。

以 `s = "221"` 为例：从右往左扫，下标 2 是 `'1'` 跳过，下标 1 是 `'2'` 命中，`i = 1`，返回 `s[:2] = "22"`，右侧的 `'1'` 被丢弃。

```python
def largestEven(s: str) -> str:
    for i in range(len(s) - 1, -1, -1):
        if s[i] == '2':
            return s[:i + 1]
    return ""
```

关键点：`s[:i + 1]` 而不是 `s[:i]`，切片右端不含，必须 `+1` 才能把命中的 `'2'` 留下。对 `"1112"`，`i = 3`，返回 `s[:4] = "1112"`，原串不动。

## 复杂度
时间 O(n)：最坏扫完整个字符串找 `'2'`。
空间 O(n)：切片 `s[:i+1]` 新建了结果串。

## 易错点
- 输入 `"1"` 或 `"11"` → 循环结束没命中，若忘了 `return ""` 会返回 `None` 或原串 → 必须显式返回空字符串。
- 输入 `"221"` → 写成 `s[:i]` 会返回 `"2"`，丢掉末位 `'2'` 变成奇数 → 切片右端写 `i + 1`。

## 如果面试官追问
问：若字符集扩到 `'0'`–`'9'`，怎么改？
答：末位取最靠右的偶数字符（`'0','2','4','6','8'`），其余逻辑不变，仍是 O(n)。
