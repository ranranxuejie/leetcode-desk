## 一句话思路
先按 `reports_to` 分组聚合出下属数和平均年龄，再回连 Employees 取经理姓名，自连接一次搞定。

## 怎么做
1. 把 Employees 自身按 `reports_to` 分组，`reports_to` 非空的行才计入，得到每个经理的下属数 `count(*)` 和平均年龄。
2. 用 `reports_to` 去 join 原表取 `name`，join 键是 `e2.employee_id = e1.reports_to`。
3. 平均年龄用 `round(avg(age))`，Python 的 `round` 是银行家舍入，38.5 会得 38，所以要用 `floor(avg+0.5)` 或 `round(avg(age)+1e-9)`。
4. 按 `employee_id` 排序输出。

拿示例 1 走一遍：按 `reports_to` 分组后，`reports_to=9` 这组有 Alice(41)、Bob(36) 两行，`count=2`，`avg=38.5`。若直接 `round(38.5)` 在 Python 得 38，错；用 `floor(38.5+0.5)=39` 才对。`reports_to=None` 的 Hercy、Winston 不进入分组，所以不会出现下属数为 0 的经理行。

```python
from math import floor
# df: employee_id, name, reports_to, age
sub = df[df["reports_to"].notna()]
g = sub.groupby("reports_to").agg(
    reports_count=("employee_id", "count"),
    avg_age=("age", "mean"),
).reset_index()
g["average_age"] = (g["avg_age"] + 0.5).apply(floor)
res = g.merge(df[["employee_id", "name"]],
              left_on="reports_to", right_on="employee_id")
res = res[["employee_id", "name", "reports_count", "average_age"]]
res = res.sort_values("employee_id")
```

关键中间值：`g` 里 `reports_to=9` 那行是 `(9, 2, 38.5)`，加 0.5 取 floor 后变 39，再 merge 拿到 `name="Hercy"`。

## 复杂度
时间 O(n)：扫一遍表分组，n 是 Employees 行数，排序 O(m log m)，m 是经理数。
空间 O(m)：分组结果和 merge 后的结果各占 O(m)，m ≤ n。

## 易错点
- 输入含 `reports_to=None` 的行（如示例 1 的 Hercy、Winston）→ 若不过滤，`groupby` 会把 None 当成一组，输出一个 `employee_id` 为空的假经理行 → 先 `df[df["reports_to"].notna()]` 再分组。
- 平均年龄恰好 .5（示例 1 的 38.5）→ 直接 `round(avg)` 在 Python 得 38（银行家舍入），与期望 39 差 1 → 用 `floor(avg+0.5)`，别用内置 `round`。

## 如果面试官追问
问：如果要求同时列出下属数为 0 的员工怎么办？
答：改成从 Employees 左连接聚合结果，`reports_count` 用 `fillna(0)`，`average_age` 保持 NULL。
