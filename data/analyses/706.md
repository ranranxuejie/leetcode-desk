## 一句话思路
用「取模定桶 + 桶内链表」手写哈希表，key 落在哪个桶由 `key % 769` 决定，冲突的 key 串在同一条链上。

## 怎么做
1. 开 `769` 个桶（质数，减少聚集），每个桶初始为 `None`，桶内节点存 `(key, value)`。
2. `put` 先算 `i = key % 769`，沿 `buckets[i]` 找同 key 节点，找到就改 `value`，否则头插新节点。
3. `get` 同样定位到桶，遍历找 key，命中返回 `value`，走完返回 `-1`。
4. `remove` 定位到桶后按链表删除处理，注意删的是头节点时要改 `buckets[i]` 本身。

以示例 `put(2, 2)` 为例：`i = 2 % 769 = 2`，`buckets[2]` 为空，直接挂上 `(2, 2)`；随后 `put(2, 1)` 走到同一桶，命中 key 2，把节点值改成 `1`，桶里仍是单节点。

```python
def put(self, key, value):
    i = key % 769
    node = self.buckets[i]
    while node:
        if node[0] == key:
            node[1] = value
            return
        node = node[1]
    self.buckets[i] = [key, value, self.buckets[i]]

def get(self, key):
    node = self.buckets[key % 769]
    while node:
        if node[0] == key:
            return node[1]
        node = node[2]
    return -1
```

`remove` 用 `prev` 指针记前驱，命中时 `prev[2] = node[2]`，若 `prev is None` 则 `buckets[i] = node[2]`。

## 复杂度
时间：单次操作平均 O(1)，最坏 O(n)，n 为同桶链表长度。
空间：O(n + 769)，n 为已插入键值对数量，769 个桶头是固定开销。

## 易错点
- `remove` 删头节点：如先 `put(769, 5)` 再 `remove(769)`，`buckets[0]` 的头就是它，只写 `prev[2] = node[2]` 会因 `prev` 为 `None` 报错或漏删，必须单独判断并改 `buckets[i]`。
- 用 `-1` 当「不存在」的哨兵：`value` 取值含 `0`，`get` 返回 `0` 是命中，不能写成 `if value:` 判断；同理 `put` 更新时不能靠值判断是否已存在，只能比 `key`。

## 如果面试官追问
问：key 上限 10^6，能不能不用链表？
答：可以开长度 10^6+1 的数组直接下标寻址，`put/get/remove` 全 O(1)，代价是固定 10^6 空间。
