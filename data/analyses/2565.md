## 一句话思路
删掉 t 中间一段后，剩下的前缀和后缀必须分别匹配 s 的前段和后段，所以预处理前缀/后缀匹配位置再枚举分界点。

## 怎么做
1. 从左往右扫 s，对每个 t 的前缀 `t[:i]` 记录它在 s 中匹配完的最早位置 `pre[i]`（`pre[0] = -1`）。
2. 从右往左扫 s，对每个 t 的后缀 `t[j:]` 记录它在 s 中匹配完的最晚起始位置 `suf[j]`（`suf[n] = len(s)`）。
3. 枚举保留的 t 前缀长度 `i`（0..n），删掉的是 `t[i:n]`，得分 `suf[i] - pre[i] - 1`，取最小。
4. 特判 `i = n`：全保留，得分 0。

以 `s = "abacaba", t = "bzaa"` 为例：`pre = [-1, 1, 3, 5, 6]`，`suf = [0, 5, 5, 6, 7]`。取 `i = 1` 时，前缀 `"b"` 匹配到 s[1]，后缀 `"zaa"` 从 s[5] 开始匹配，得分 `5 - 1 - 1 = 3`；取 `i = 2` 时 `pre[2] = 3`、`suf[2] = 5`，得分 `5 - 3 - 1 = 1`，即删掉 t[1] 的 `'z'`。

```python
m, n = len(s), len(t)
pre = [-1] * (n + 1)
j = 0
for i in range(m):
    if j < n and s[i] == t[j]:
        pre[j + 1] = i
        j += 1
suf = [m] * (n + 1)
j = n - 1
for i in range(m - 1, -1, -1):
    if j >= 0 and s[i] == t[j]:
        suf[j] = i
        j -= 1
ans = n
for i in range(n + 1):
    if pre[i] < suf[i]:
        ans = min(ans, suf[i] - pre[i] - 1)
```

## 复杂度
时间 O(len(s) + len(t))：两趟扫描 s 各 O(m)，枚举分界点 O(n)。
空间 O(len(t))：`pre`、`suf` 两个长度 n+1 的数组。

## 易错点
- `s = "cde", t = "xyz"` 时 `pre` 全是 -1、`suf` 全是 3，若只枚举 `i` 到 n-1 会漏掉「全删」得 3 的答案；必须让 `i` 取到 n，且用 `pre[i] < suf[i]` 过滤掉前后缀在 s 中重叠的非法分界。
- `s = "abc", t = "abc"` 时 `pre[3] = 2`、`suf[3] = 3`，得分 `3 - 2 - 1 = 0` 正确；但若把 `suf[n]` 初始化成 `m - 1` 而非 `m`，会算成 -1，必须让空后缀的起始位置是 `len(s)`。

## 如果面试官追问
问：要求输出具体删除方案怎么办？
答：在枚举 `i` 时记录最优的 `i`，删除区间就是 `t[i:suf[i]]` 中未被匹配的那些下标，再回扫一遍定位即可。
