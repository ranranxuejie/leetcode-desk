## 一句话思路
用 Bellman-Ford 按「边数」分层松弛：第 i 轮只允许走 i 条边，k+1 轮后 dist[dst] 就是最多 k 站中转的最低价。

## 怎么做
1. 建 `dist = [inf]*n`，`dist[src] = 0`；外层循环 `k+1` 次，代表最多走 `k+1` 条边（k 站中转 = k+1 段航程）。
2. 每轮必须用上一轮的快照 `prev = dist[:]` 松弛，否则同一轮内会连续走多条边，等于放开了中转限制。
3. 遍历每条 `[u, v, w]`：若 `prev[u] + w < dist[v]` 则更新 `dist[v]`。
4. 结束后 `dist[dst]` 仍是 `inf` 就返回 `-1`。

以示例 1 为例（`k=1`，跑 2 轮）：第 1 轮后 `dist = [0, 100, inf, 600]`；第 2 轮用快照松弛，`dist[3]` 被 `dist[1]+600=700` 和 `dist[2]+200` 竞争，`dist[2]` 此时是 `inf`（第 1 轮才到 100，快照里没有），最终 `dist[3]=700`。若不用快照，第 2 轮内 `0→1→2→3` 会算出 400，错误。

```python
dist = [float('inf')] * n
dist[src] = 0
for _ in range(k + 1):
    prev = dist[:]
    for u, v, w in flights:
        if prev[u] + w < dist[v]:
            dist[v] = prev[u] + w
return -1 if dist[dst] == float('inf') else dist[dst]
```

## 复杂度
时间 O((k+1) * len(flights))，每轮扫全部航班。
空间 O(n)，只开 dist 和每轮快照 prev 两个长度 n 的数组。

## 易错点
- 示例 1 若省掉 `prev = dist[:]` 直接原地松弛 → 同一轮内 `0→1→2→3` 连走 3 条边算出 400 → 必须用快照，保证第 i 轮只走 i 条边。
- `k=0`（示例 3）时循环只跑 1 轮，只能取 `0→2` 直飞 500；若把循环写成 `range(k)` 会一轮都不跑，`dist[dst]` 仍是 inf 返回 -1 → 轮数必须是 `k+1`。

## 如果面试官追问
问：n 很大、k 也很大时怎么办？
答：改用 Dijkstra 变体，堆里存 `(cost, city, stops)`，按 cost 出堆，stops 超 k 就跳过，首次弹出 dst 即答案。
