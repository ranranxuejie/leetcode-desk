## 一句话思路
把每个 `nums[i]` 压成 `g = gcd(nums[i], k)`，问题变成「两个 g 的乘积能被 k 整除」，用哈希表按 g 计数后配对。

## 怎么做
1. 对每个 `nums[i]` 求 `g = gcd(nums[i], k)`，只保留 g 的分布，因为 `nums[i]*nums[j] % k` 只取决于两者与 k 的公共因子。
2. 用 `Counter` 统计每个 g 出现次数，键的个数不超过 k 的约数个数。
3. 对每个键 g 与已处理的键 h 配对，判据是 `(g * h) % k == 0`，累加 `cnt[g] * cnt[h]`；同键内部用组合数 `c*(c-1)//2`。
4. 返回累加结果。

以 `nums = [1,2,3,4,5], k = 2` 为例：g 序列为 `[1,2,1,2,1]`，`cnt = {1:3, 2:2}`。配对：`(1,2)` 满足 `1*2 % 2 == 0`，贡献 `3*2 = 6`；同键 `2` 内部贡献 `2*1//2 = 1`；`1` 与 `1` 不满足。合计 `6 + 1 = 7`。

```python
from math import gcd
from collections import Counter

cnt = Counter(gcd(x, k) for x in nums)
ans = 0
keys = list(cnt)
for i, g in enumerate(keys):
    c = cnt[g]
    ans += c * (c - 1) // 2 if (g * g) % k == 0 else 0
    for h in keys[i + 1:]:
        if (g * h) % k == 0:
            ans += c * cnt[h]
```

注意同键内部要先判 `(g*g) % k == 0`，否则 `g=1, k=2` 时会把 3 个 1 错算成 3 对。

## 复杂度
时间：O(n log k)，n 次 gcd 各 O(log k)，配对是 O(d²)，d 为 k 的约数个数。
空间：O(d)，Counter 只存 k 的约数级键，不随 n 增长。

## 易错点
- `nums = [1,1,1], k = 2`：若对同键不做 `(g*g) % k == 0` 判断，会把 3 个 g=1 算成 3 对，正确是 0，因为 `1*1=1` 不被 2 整除。
- `nums = [2,2,2], k = 4`：g 全是 2，`2*2=4` 可整除，答案应为 3；若只做跨键配对、漏掉同键组合数，会错成 0。

## 如果面试官追问
问：若要求输出所有满足条件的下标对而非计数？答：计数阶段不变，配对时按 g 分组展开下标列表做笛卡尔积，复杂度升到 O(答案规模)。
