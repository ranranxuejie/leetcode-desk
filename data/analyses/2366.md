## 一句话思路
从右往左贪心：每个数被切成若干份，让最大那份不超过右边已确定的最小值，份数越少越好。

## 怎么做
1. 从 `i = n-2` 往左扫，维护 `limit = nums[i+1]`（右侧已确定的最小首段值）。
2. 若 `nums[i] <= limit`，不用切，`limit = nums[i]` 继续。
3. 否则切成 `k = ceil(nums[i] / limit)` 份，操作数加 `k-1`，新 `limit = nums[i] // k`。
4. 累加返回。

以 `nums = [3,9,3]` 为例：`i=1`，`9 > 3`，`k = ceil(9/3) = 3`，操作 +2，`limit = 9//3 = 3`；`i=0`，`3 <= 3`，结束，答案 2。

```python
ans = 0
limit = nums[-1]
for i in range(len(nums) - 2, -1, -1):
    if nums[i] <= limit:
        limit = nums[i]
    else:
        k = (nums[i] + limit - 1) // limit
        ans += k - 1
        limit = nums[i] // k
return ans
```

关键在 `limit = nums[i] // k`：切成 `k` 份时，均分让最大份最小，取整除即得首段（也是最小段）的值，供左边比较。

## 复杂度
时间 O(n)：每个元素算一次除法，`k` 的累加不影响总次数上界。
空间 O(1)：只用了 `ans`、`limit`、`k` 三个变量。

## 易错点
- `nums = [5, 1]`：若从左往右贪心，会想把 5 切小去迁就 1，方向就错了。正确是从右往左，因为右侧元素只受左边影响、不受右边影响，先定右边才能定左边的上界。
- `nums = [10, 3]`：若用 `k = nums[i] // limit` 而非向上取整，`10//3 = 3`，切 3 份最大份是 4 > 3，仍不合法。必须 `(nums[i] + limit - 1) // limit` 得 4，`limit = 10//4 = 2`。

## 如果面试官追问
问：要输出具体切分方案怎么办？
答：每步记录 `k` 和 `nums[i] // k`，逆序回填每段的起止值即可，答案不变。
