## 一句话思路
把每行转成「与首元素异或」的规范串，同规范串的行可一起变全等，取众数计数。

## 怎么做
1. 对每行构造规范串：`row[0]` 为 0 时原样，为 1 时逐位取反，使首列统一为 0。
2. 用字典统计每个规范串出现次数，答案即最大频次。
3. 以示例 2 `[[0,1],[1,0]]` 为例：第 0 行规范串 `(0,1)`；第 1 行首元素为 1，取反得 `(0,1)`，两行同键，计数 2。

```python
from collections import Counter

def maxEqualRowsAfterFlips(matrix):
    cnt = Counter()
    for row in matrix:
        if row[0] == 0:
            key = tuple(row)
        else:
            key = tuple(1 - x for x in row)
        cnt[key] += 1
    return max(cnt.values())
```

关键中间值：示例 2 中两行都映射到 `(0, 1)`，`cnt[(0,1)] == 2`，返回 2。

## 复杂度
时间 O(m·n)：每行扫 n 列构造键，共 m 行。
空间 O(m·n)：字典最多存 m 个长度为 n 的元组。

## 易错点
- 输入 `[[0,1],[1,0]]` → 若直接按原行计数，两行键不同会错答 1 → 必须先按首元素归一化再计数。
- 输入 `[[1,1],[0,0]]` → 若只对首元素为 0 的行取反、为 1 的行原样，会得到 `(1,1)` 与 `(0,0)` 两个键错答 1 → 统一规则是「首元素为 1 才取反」，两行都归到 `(0,0)`。

## 如果面试官追问
问：n 很大（如 10^5）怎么办？答：仍逐行构造键，但用字符串/位压缩替代元组，时间仍是 O(m·n)，空间按不同键数计。
