## 一句话思路
用显式栈模拟中序遍历：栈里存「当前节点到最左叶」这条路径，`next()` 弹栈顶、再把右子树的左链压栈。

## 怎么做
1. 构造函数里从 `root` 一路往左走，把沿途节点压进 `self.stack`，栈顶就是最小值。
2. `next()` 弹出栈顶 `node`，返回 `node.val`，然后对 `node.right` 重复「一路向左压栈」。
3. `hasNext()` 只判断 `len(self.stack) > 0`。

以官方示例 `[7,3,15,null,null,9,20]` 为例：构造后 `stack = [7, 3]`（7 在底、3 在顶）。第一次 `next()` 弹出 3，`3.right` 为 `None`，栈变 `[7]`；第二次 `next()` 弹出 7，`7.right = 15`，向左压入 15、9，栈变 `[15, 9]`，栈顶 9 正是下一个值——这就是「弹一个、补一条左链」的中间状态。

```python
def _push_left(self, node):
    while node:
        self.stack.append(node)
        node = node.left

def next(self):
    node = self.stack.pop()
    self._push_left(node.right)
    return node.val

def hasNext(self):
    return bool(self.stack)
```

关键点：`_push_left` 只在 `next()` 里对右孩子调用，构造函数里对 `root` 调用一次，两处共用同一段逻辑，不要写成两套。

## 复杂度
时间：`next()` 单次最坏 O(h)，但每个节点只入栈出栈各一次，n 次调用均摊 O(1)。
空间：栈深度不超过树高 h，即 O(h)，没有额外存整个中序数组。

## 易错点
- 输入是链状 BST（如 `[1,null,2,null,3]`）→ 若在构造函数里一次性展开全部节点存成 list，空间退化成 O(n)，违背进阶要求 → 必须惰性压栈，只在 `next()` 时展开右子树的左链。
- 节点值含 `0`（题面允许 `0 <= Node.val`）→ 若用 `if node.val:` 或把哨兵值设成 0 来判断「栈空/无值」，会把合法的 0 当成结束 → 判空只认 `len(self.stack)`，不要拿节点值当哨兵。

## 如果面试官追问
问：要求 `next()` 严格 O(1) 最坏而非均摊怎么办？
答：改用 Morris 中序遍历，用右空指针做线索，空间降到 O(1)，代价是遍历中会临时改写树结构。
