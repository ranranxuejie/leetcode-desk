## 一句话思路
取 `nums[n // 2]` 作目标值，用 `count` 数它在整个数组里出现几次，等于 1 就返回 `True`。

## 怎么做
1. 由 `n = len(nums)` 算出中间下标 `mid = n // 2`，因为 n 是奇数，`//` 正好落在正中。
2. 取出 `target = nums[mid]`，这是唯一需要判断出现次数的值。
3. 用 `nums.count(target)` 统计它在全数组的出现次数，与 1 比较。

以示例 2 `nums = [1,2,2]` 为例：`n = 3`，`mid = 1`，`target = nums[1] = 2`；`nums.count(2)` 扫完整个数组返回 `2`，`2 == 1` 为假，输出 `False`。示例 1 `[1,2,3]` 中 `target = 2`，`count(2) = 1`，输出 `True`。

```python
n = len(nums)
mid = n // 2
target = nums[mid]
return nums.count(target) == 1
```

关键点：`count` 必须扫**整个** `nums`，不能只看 `mid` 左边或右边——中间元素可能在任意位置重复，比如 `[2,1,2]` 的 `target = 1` 只出现一次，而 `[2,2,1]` 的 `target = 1` 也只出现一次，但若写成 `[1,2,2]` 的 `target = 2` 在右侧重复，只扫左半边就会误判成 `True`。

## 复杂度
时间：`count` 扫一遍数组，O(n)，n 是 `len(nums)`。
空间：O(1)，只存 `mid`、`target` 两个标量，没开额外容器。

## 易错点
- 输入 `[1,2,2]` → 若把 `mid` 写成 `n // 2 + 1` 或 `(n - 1) // 2` 之外的偏移，取到 `nums[2] = 2` 看似也对，但换成 `[2,1,2]` 就会取错位置 → 正确做法是严格用 `mid = n // 2`，奇数长度下它唯一指向正中。
- 输入 `[1,1,2]` → 若只比较 `nums[mid]` 与左右邻居 `nums[mid-1]`、`nums[mid+1]` 就下结论，会漏掉远处重复 → 正确做法是统计全数组出现次数，不能只看相邻元素。

## 如果面试官追问
问：如果 n 大到 10**7，还能这么写吗？
答：能，`count` 仍是 O(n) 单遍扫描、O(1) 空间，瓶颈只在读入数组本身。
