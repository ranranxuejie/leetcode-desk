## 一句话思路
把每个值 `v` 与它的目标位置 `v` 连边，同一连通分量内可任意换位，答案就是所有「错位分量」里最小的按位与值。

## 怎么做
1. 用并查集把下标 `i` 和值 `nums[i]` 合并，因为值域恰好是 `[0, n-1]`，下标和值可以共用一套编号。
2. 对每个 `i`，若 `find(i) != find(nums[i])`，说明这个位置还没归位，该分量必须能交换。
3. 对每个错位分量，取分量内所有元素（下标和值都算）的按位与，得到该分量允许的最大 k。
4. 全局答案取这些分量 k 的最小值；若没有错位分量（已有序）返回 0。

以 `nums = [0,3,2,1]` 为例：`i=1` 时 `find(1)` 与 `find(3)` 不同，合并后分量 `{1,3}`，元素 `1 AND 3 = 1`；`i=0`、`i=2` 已归位跳过。答案 `1`。

```python
parent = list(range(n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
for i, v in enumerate(nums):
    a, b = find(i), find(v)
    if a != b:
        parent[a] = b
ans = None
for i, v in enumerate(nums):
    if find(i) != find(v):
        continue
    # 该分量内所有下标与值的 AND
```

实际实现时对每个根维护一个 `and_val`，合并时 `and_val[new] = and_val[a] & and_val[b]`，初始 `and_val[i] = i`（下标和值同号），最后对每个错位根取 `and_val[root]` 的最小值。

## 复杂度
时间：O(n α(n))，并查集路径压缩贡献近线性，遍历 n 个元素。
空间：O(n)，`parent` 和 `and_val` 各开长度 n 的数组。

## 易错点
- 只对「值」做 AND 而漏掉下标：`nums = [0,3,2,1]` 中分量 `{1,3}` 若只算 `3 AND 1 = 1` 恰好对，但 `nums = [1,0]` 时下标 `{0,1}` 与值 `{1,0}` 是同一集合，漏下标会算成 `1 AND 0 = 0`，正确应为 `0 AND 1 = 0`——关键是下标和值必须一起进分量，否则分量边界会错。
- 把「已有序」误判成需要返回某分量值：`nums = [0,1,2]` 每个 `find(i) == find(nums[i])`，此时 `ans` 保持 `None`，必须显式返回 0，不能返回 `and_val` 里的任意值。

## 如果面试官追问
若要求输出具体交换方案而非只给 k？答：在并查集分量内按目标位置做置换环分解，每个环用一次「与 k 相等的两元素」交换即可还原，环长减一次交换。
