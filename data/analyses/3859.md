## 一句话思路
用「至多 k 个不同整数」减去「至多 k-1 个不同整数」，每个窗口内再用 m 次频率门槛卡左边界。

## 怎么做
1. 定义 `atMost(limit)`：统计不同整数个数 ≤ limit 且每个整数出现 ≥ m 次的子数组数。
2. 右指针 `r` 逐个加入 `nums[r]`，维护 `cnt` 和 `distinct`。
3. 当 `distinct > limit` 或 `cnt[nums[l]] > m` 时右移 `l`——注意 `> m` 而不是 `>= m`，因为左边界要停在「刚好还能删」的位置。
4. 每个 `r` 累加 `r - l + 1`，答案 = `atMost(k) - atMost(k-1)`。

以 `nums = [1,2,1,2,2], k = 2, m = 2` 为例，算 `atMost(2)`：`r=3` 时窗口 `[1,2,1,2]`，`cnt={1:2,2:2}`，`l=0`，贡献 4；`r=4` 时 `cnt[2]=3 > m`，`l` 右移到 1，贡献 `4-1+1=4`。`atMost(1)` 对这段数组贡献为 0（单个值凑不满两个不同），故答案 4-2=2，与示例一致。

```python
def atMost(limit):
    cnt, distinct, l, res = {}, 0, 0, 0
    for r, x in enumerate(nums):
        cnt[x] = cnt.get(x, 0) + 1
        if cnt[x] == 1:
            distinct += 1
        while distinct > limit or cnt[nums[l]] > m:
            cnt[nums[l]] -= 1
            if cnt[nums[l]] == 0:
                distinct -= 1
            l += 1
        res += r - l + 1
    return res
return atMost(k) - atMost(k - 1)
```

## 复杂度
时间 O(n)：两个指针各走一遍，`atMost` 调两次仍是 O(n)。
空间 O(n)：`cnt` 最多存 n 个不同值。

## 易错点
- 把收缩条件写成 `cnt[nums[l]] >= m` → 对 `[1,2,1,2,2], m=2` 会在 `cnt[1]=2` 时就把 `l` 推过 0，丢掉 `[1,2,1,2]` 这个合法解 → 必须用 `> m`，让左边界停在「再删一个就违规」的位置。
- 忘记 `distinct > limit` 时也要收缩 → 对 `[3,1,2,4], k=2` 会算出超过 3 个不同整数的窗口 → 两个条件用 `or` 连起来，任一触发都右移 `l`。

## 如果面试官追问
问：如果要求输出所有合法子数组而非计数？答：把 `res += r-l+1` 换成枚举 `l..r` 的区间，复杂度退化到 O(n²) 最坏。
