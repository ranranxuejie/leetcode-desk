## 一句话思路
从左到右扫，用 `need` 记当前还欠几个 `)`，`ans` 记插入数，遇到不匹配就地补。

## 怎么做
1. 维护 `need`（当前未闭合的 `(` 还欠的右括号数）和 `ans`（插入次数），初值都为 0。
2. 遇 `(`：先看 `need` 是否为奇数，奇数说明上一个 `(` 只配到一个 `)`，补一个 `)`（`ans += 1`，`need -= 1`），再 `need += 2`。
3. 遇 `)`：`need -= 1`；若 `need < 0`，说明右括号多了，在它前面插一个 `(`（`ans += 1`，`need = 1`）。
4. 扫完返回 `ans + need`（末尾补齐剩余欠账）。

以 `s = "(()))"` 走一遍：`(` → need=2；`(` → need=4；`)` → need=3；`)` → need=2；`)` → need=1。结束 `ans=0`，返回 `0+1=1`，与官方一致。

```python
need = ans = 0
for ch in s:
    if ch == '(':
        if need % 2 == 1:
            ans += 1
            need -= 1
        need += 2
    else:
        need -= 1
        if need < 0:
            ans += 1
            need = 1
return ans + need
```

关键点：`need` 用「欠几个右括号」而不是「栈里几个左括号」，因为一个 `(` 要两个 `)`，奇数 `need` 就是「半配」状态，必须立刻补。

## 复杂度
时间 O(n)：一次遍历，n 为 `len(s)`。
空间 O(1)：只开 `need`、`ans` 两个整数。

## 易错点
1. 输入 `s = "())"` → 若把 `need` 当栈深度、遇 `)` 只减 1 不判奇偶，会算成 0 但逻辑上没检查「一个 `(` 配两个 `)`」的配对完整性；正确做法是 `(` 时 `need += 2`，让 `need` 天然编码「欠两个右括号」。
2. 输入 `s = "))())("` → 若遇多余 `)` 只 `ans += 1` 而不重置 `need = 1`，后面 `(` 的欠账会算错；正确做法是 `need < 0` 时插 `(` 后令 `need = 1`（这个新 `(` 还欠一个 `)`，因为已消耗一个）。

## 如果面试官追问
问：要求输出具体插入方案而非次数？答：在 `ans += 1` 的两处分别记录「在当前位置前插 `)`」或「插 `(`」，末尾按 `need` 补 `)`，顺序拼接即可。
