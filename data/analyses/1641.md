## 一句话思路
用 DP 记「以第 j 个元音结尾的长度 i 的串数」，转移是后缀和，因为 s[i] 只能取 ≥ s[i-1] 的元音。

## 怎么做
1. 定义 `dp[j]` = 当前长度下以第 j 个元音（j=0..4 对应 a,e,i,o,u）结尾的合法串数，初始 `dp = [1,1,1,1,1]`（n=1 时各 1 个）。
2. 每加一个字符，新的 `dp[j]` 等于旧 `dp[0..j]` 之和（前一位可以是 a..第 j 个元音），即对旧数组做前缀和。
3. 重复 n-1 次，最后返回 `sum(dp)`。

以 n=2 为例：旧 `dp=[1,1,1,1,1]`，前缀和得新 `dp=[1,2,3,4,5]`，`sum=15`，与示例 2 一致。n=1 时循环不执行，直接 `sum([1,1,1,1,1])=5`。

```python
dp = [1, 1, 1, 1, 1]
for _ in range(n - 1):
    for j in range(1, 5):
        dp[j] += dp[j - 1]   # 原地前缀和，dp[j] 变成旧 dp[0..j] 之和
return sum(dp)
```

原地前缀和能成立，是因为 `dp[j-1]` 在更新 `dp[j]` 时已经是新值（旧 `dp[0..j-1]` 之和），正好是需要的累加量。

## 复杂度
时间：O(5n)，外层 n-1 次、内层固定 4 次，n 贡献全部。
空间：O(1)，只开长度 5 的 `dp`，与 n 无关。

## 易错点
- n=1 时若写成先循环再返回，或把初始 `dp` 设成全 0 再在循环里累加，会得到 0 或 1；正确做法是初始 `dp=[1,1,1,1,1]` 且循环 `range(n-1)`，n=1 直接返回 5。
- 内层若写成 `new[j] = sum(dp[0:j+1])` 用旧数组另开新数组，逻辑对但多开 O(5) 空间且易把 `j` 范围写成 `range(5)` 导致 `dp[0]` 被重复累加；正确做法是原地从 `j=1` 开始前缀和，`dp[0]` 始终为 1。

## 如果面试官追问
问：n 很大（如 10^9）怎么办？
答：答案是 C(n+4,4)，用组合数公式 O(1) 算，注意按题目要求对 32 位范围处理。
