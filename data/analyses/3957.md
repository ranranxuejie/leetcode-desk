## 一句话思路
用 WQS 二分（拉格朗日松弛）给「选一个子数组」加惩罚 λ，把「至多 m 段」压成「不限段数」的 O(n) DP，再按段数单调性二分 λ。

## 怎么做
1. 设 `f[i]` 为前 i 个元素的最大收益、`g[i]` 为对应段数，转移时对每个右端点 i 枚举长度 d∈[l,r]，取 `f[i-d] + (pre[i]-pre[i-d]) - λ`，同时用单调队列维护 `f[i-d]-pre[i-d]` 在窗口 d∈[l,r] 上的最大值。
2. 对示例 1 `nums=[4,1,-5,2], m=2, l=1, r=3`，取 λ=0 时 DP 会选 `[4,1]` 与 `[2]` 得 7、段数 2；λ 增大到 5 时段数降到 1、收益 5-5=0，说明段数随 λ 单调不增。
3. 二分最小的 λ 使段数 ≤ m，答案 = `f[n] + λ*m`（用「恰好 m 段」的松弛值回代，注意取二分边界那一侧）。

```python
def solve(lam):
    f = [0]*(n+1); g = [0]*(n+1); dq = deque()
    for i in range(1, n+1):
        j = i - l
        if j >= 0:
            v = f[j] - pre[j]
            while dq and dq[-1][1] <= v: dq.pop()
            dq.append((j, v))
        while dq and dq[0][0] < i - r: dq.popleft()
        f[i], g[i] = f[i-1], g[i-1]
        if dq:
            cand = dq[0][1] + pre[i] - lam
            if cand > f[i] or (cand == f[i] and g[dq[0][0]]+1 > g[i]):
                f[i], g[i] = cand, g[dq[0][0]] + 1
    return f[n], g[n]
```

## 复杂度
时间：二分 O(log(值域·n)) 轮，每轮单调队列 O(n)，共 O(n log V)。
空间：`f/g/pre` 与队列各 O(n)，无额外二维表。

## 易错点
- `nums=[-3,-4,-1], m=2, l=1, r=2`：若把「至多 m 段」写成「必须选满 m 段」，会强行凑出 -3+-4=-7；正确做法是 DP 里保留 `f[i]=f[i-1]` 的「不选」分支，允许段数 < m。
- 二分回代时若用「段数恰好等于 m」的 λ 侧算 `f[n]+λ*m`，在段数跳变处会偏大；应取满足 `g[n] <= m` 的最小 λ，并用该 λ 下的 `f[n]+λ*m` 回代。

## 如果面试官追问
要求输出具体选了哪些子数组怎么办？答：在二分定下 λ 后重跑一次 DP 并记录每个 i 的转移来源，回溯出区间端点即可。
