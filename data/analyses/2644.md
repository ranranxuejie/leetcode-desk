## 一句话思路
双重循环枚举每个 `divisors[i]` 对 `nums` 计数整除个数，边算边用「得分更大，或得分相同但值更小」更新答案。

## 怎么做
1. 初始化 `best_score = -1`、`ans = 0`，保证第一个 divisor 一定被采纳。
2. 外层遍历 `divisors` 中的 `d`，内层用 `sum(1 for x in nums if x % d == 0)` 直接数得分。
3. 用 `score > best_score or (score == best_score and d < ans)` 更新，两个条件缺一不可。
4. 返回 `ans`。

以示例 1 的 `nums = [2,9,15,50]` 为例：处理 `d = 5` 时 `50 % 5 == 0`、`15 % 5 == 0`，`score = 2`，`ans = 5`；处理 `d = 3` 时 `score = 2`，但 `3 < 5`，`ans` 改成 `3`；处理 `d = 2` 时 `score = 2`，`2 < 3`，`ans` 改成 `2`。最终返回 `2`。

```python
best_score, ans = -1, 0
for d in divisors:
    score = 0
    for x in nums:
        if x % d == 0:
            score += 1
    if score > best_score or (score == best_score and d < ans):
        best_score, ans = score, d
return ans
```

关键点：`best_score` 初值必须是 `-1` 而不是 `0`，否则当所有 divisor 得分都是 0（如 `nums = [1], divisors = [2,3]`）时，`score > best_score` 永远不成立，`ans` 会停在初始值 `0`，而 `0` 根本不在 `divisors` 里。

## 复杂度
时间：`O(len(divisors) * len(nums))`，两层循环各贡献一个因子，最多 10^6 次取模。
空间：`O(1)`，只开了 `best_score`、`ans`、`score` 三个标量。

## 易错点
- 平局规则写反：`nums = [2,9,15,50], divisors = [5,3,7,2]` 三个 divisor 得分都是 2，若只写 `score > best_score` 就返回 `5`，正确做法是加上 `d < ans` 让 `2` 胜出。
- 初值取 0 而非 -1：`nums = [1], divisors = [2,3]` 时所有得分都是 0，`score > best_score` 恒为假，返回 `0`（不在 divisors 中）；正确做法是 `best_score = -1`，让第一个 divisor 无条件写入。

## 如果面试官追问
若 `nums` 长度涨到 10^5、`divisors` 涨到 10^5，双重循环 10^10 会超时，怎么办？
答：先对 `nums` 做频次统计，再对每个 `d` 枚举其倍数 `d, 2d, ...` 累加频次，复杂度降到 `O(M log M)`，`M` 为 `nums` 最大值。
