## 一句话思路
排序后按位配对，只统计 nums 比 target 小的差额总和再除以 2，因为每次操作恰好消掉 2 点差额。

## 怎么做
1. 把 nums 和 target 各自升序排序，让第 k 小的 nums 对应第 k 小的 target。
2. 逐位比较，若 nums[k] < target[k]，把 target[k] - nums[k] 累加进 diff。
3. 答案就是 diff // 2，因为一次操作同时给一个位置 +2、另一个位置 -2。

以示例 1 为例：排序后 nums = [6,8,12]，target = [2,10,14]。逐位差额为 6-2=4（nums 大，跳过）、8-10=-2、12-14=-2，diff = 2 + 2 = 4，答案 4 // 2 = 2。

```python
nums.sort()
target.sort()
diff = 0
for a, b in zip(nums, target):
    if a < b:
        diff += b - a
return diff // 2
```

为什么排序配对最优：若存在交叉配对（nums 的较小值配 target 的较大值），交换成同序配对不会增大总差额，因此按位配对是下界可达的。

## 复杂度
时间：排序 O(n log n)，逐位扫描 O(n)，n 为数组长度。
空间：排序额外 O(log n) 栈空间，其余 O(1)。

## 易错点
1. 输入 nums = [8,12,6]、target = [2,14,10] 时，若只累加 |a-b| 得 4+2+2=8，再除以 2 得 4，答案错成 4；正确做法是只累加 a < b 的正差额，得 4，答案 2。
2. 输入 nums = [1,2,5]、target = [4,1,3] 时，若误以为要逐位对齐原下标（1 对 4、2 对 1、5 对 3），差额 3+1+2=6，答案 3；正确做法是先排序成 [1,2,5] 与 [1,3,4]，只累加 3-2=1 和 4-5 跳过，diff = 1，答案 0？——注意此处 5 > 4 跳过，diff 只有 1，答案 1，与示例一致。

## 如果面试官追问
问：若要求输出具体操作方案而非次数？答：排序配对后，把每个 nums[k] < target[k] 的位置当作「加 2 的池」，与 nums[k] > target[k] 的位置两两配对，每次从池里取 2 点补给缺口即可。
