## 一句话思路
用 Counter 统计频次，再遍历去重后的键，只保留频次为 1 且 x-1、x+1 都不在计数表里的数。

## 怎么做
1. 用 `Counter(nums)` 得到频次表 `cnt`，键是数值本身。
2. 遍历 `cnt` 的键（不是原数组，避免重复判断同一个数）。
3. 对每个键 `x`，判断 `cnt[x] == 1 and x-1 not in cnt and x+1 not in cnt`。
4. 满足就 append 进结果。

以 `nums = [10,6,5,8]` 为例，`cnt = {10:1, 6:1, 5:1, 8:1}`。检查 `x=6` 时 `x-1=5 in cnt` 成立，直接淘汰；检查 `x=10` 时 `9 not in cnt and 11 not in cnt` 都为真，保留。最终 `[10, 8]`。

```python
from collections import Counter

cnt = Counter(nums)
res = []
for x in cnt:
    if cnt[x] == 1 and (x - 1) not in cnt and (x + 1) not in cnt:
        res.append(x)
```

关键点：`in cnt` 是哈希查找 O(1)，所以判断邻居不引入额外遍历；遍历 `cnt` 而非 `nums`，重复元素只判一次。

## 复杂度
时间 O(n)：建 Counter 扫一遍 n，遍历键最多 n 个，每次 O(1) 查找。
空间 O(n)：Counter 最多存 n 个不同键，结果列表最坏也是 n。

## 易错点
- 输入 `[1,1,3]` → 若遍历原数组 `nums` 而不是 `cnt`，会对 1 判断两次并可能重复 append → 正确做法是遍历 `cnt` 的键，每个不同值只判一次。
- 输入 `[2,2]` → 若只判 `x-1`、`x+1` 不在表里就返回，会漏掉频次条件，把 2 当成孤独数字 → 必须先卡 `cnt[x] == 1`，两个条件用 `and` 连接，缺一不可。

## 如果面试官追问
问：如果 nums 长度到 10^7、内存吃紧怎么办？
答：先排序再线性扫，用相邻元素差判断邻居，空间降到 O(1) 额外（不计结果），代价是时间 O(n log n)。
