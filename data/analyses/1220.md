## 一句话思路
按「以某元音结尾的长度为 k 的串有多少个」做 DP，因为下一步只依赖结尾字符，状态只有 5 个。

## 怎么做
1. 定义 `dp[c]` 为当前长度下以元音 `c` 结尾的合法串数，初始长度 1 时五个都是 1。
2. 按规则反推转移：新串结尾是 `a`，则前一位只能是 `e/i/u`；结尾 `e` 前一位只能是 `a/i`；`i` 前一位是 `e/o`；`o` 前一位是 `i`；`u` 前一位是 `i/o`。
3. 每轮用旧 `dp` 算出新 `dp`，取模 `10**9+7`，迭代 `n-1` 次。
4. 返回五个状态之和取模。

以 `n = 2` 为例：初始 `dp = [1,1,1,1,1]`（a,e,i,o,u）。新 `dp[a] = dp[e]+dp[i]+dp[u] = 3`，`dp[e] = dp[a]+dp[i] = 2`，`dp[i] = dp[e]+dp[o] = 2`，`dp[o] = dp[i] = 1`，`dp[u] = dp[i]+dp[o] = 2`，和为 `3+2+2+1+2 = 10`，与示例一致。

```python
MOD = 10**9 + 7
a = e = i = o = u = 1
for _ in range(n - 1):
    a, e, i, o, u = (e + i + u) % MOD, (a + i) % MOD, \
                    (e + o) % MOD, i, (i + o) % MOD
return (a + e + i + o + u) % MOD
```

注意元组赋值右侧用的是旧值，顺序不能拆成五行分别赋值，否则 `a` 更新后会影响 `e` 的计算。

## 复杂度
时间：O(n)，循环 n-1 次，每次常数次加法。
空间：O(1)，只维护 5 个标量，没有数组。

## 易错点
- `n = 1` 时若先循环再返回，或把初始值设成 0，会输出 0 而非 5；正确做法是初始五元组全为 1，循环 `range(n-1)` 次，n=1 时直接返回 5。
- 转移方向写反（把「a 后面只能跟 e」当成「a 前面是 e」）→ `n = 2` 会算出别的数；正确做法是按「新结尾由哪些旧结尾转移来」写，如 `dp[a] = dp[e]+dp[i]+dp[u]`，用示例 2 的 10 验证。

## 如果面试官追问
若 n 放大到 10^18 怎么办？答：五个状态写成 5×5 转移矩阵，快速幂 O(5³ log n)。
