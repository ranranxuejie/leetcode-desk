## 一句话思路
区间 DP：`f[i][j]` 表示子串 `s[i..j]` 能否被完全消空，能消空的位置就整段丢掉，剩下的拼起来取字典序最小。

## 怎么做
1. 预处理 `can[i][j]`：长度偶数且能两两配对消空，递推 `can[i][j] = any(can[i][k] and can[k+1][j] and 相邻(s[k],s[k+1]))`，注意配对的两字符是消空后相邻的。
2. 用 `dp[i]` 表示前缀 `s[0..i-1]` 的最优结果，转移时枚举「保留 `s[i-1]` 后接 `dp[j]`」或「整段 `s[j..i-1]` 消空」。
3. 比较候选串用字典序，长度 ≤250 直接字符串比较即可。

以 `s = "bcda"` 为例：`can[1][2]`（`"cd"`）为真，`can[0][3]` 由 `can[0][1]`（`"bc"` 不连续）失败，但 `can[0][3]` 经 `can[1][2]` 消 `"cd"` 后剩 `"ba"`，`'b'` 与 `'a'` 循环相邻，故整串消空，`dp[4] = ""`。

```python
n = len(s)
can = [[False]*n for _ in range(n)]
for L in range(2, n+1, 2):
    for i in range(n-L+1):
        j = i+L-1
        for k in range(i+1, j+1, 2):
            if (k == i+1 or can[i+1][k-1]) and can[k+1][j] and adj(s[i], s[k]):
                can[i][j] = True
                break
dp = [""]*(n+1)
for i in range(1, n+1):
    best = dp[i-1] + s[i-1]
    for j in range(i-1, -1, -1):
        if can[j][i-1]:
            best = min(best, dp[j])
    dp[i] = best
return dp[n]
```

## 复杂度
时间：`O(n^3)`，三层枚举区间与断点，`n ≤ 250` 可过。
空间：`O(n^2)`，`can` 表占主，`dp` 只存 `n+1` 个串。

## 易错点
- `s = "zdce"`：只看到 `"dc"` 可消就输出 `"ze"`，但 `"zdce" < "ze"`，正确做法是保留原串，因为消掉后首字符从 `'z'` 变 `'z'` 但第二字符 `'d'` 变 `'e'` 变大。
- 配对判断漏掉循环相邻：`s = "az"` 时 `'a'` 与 `'z'` 应视为连续可消，若只写 `abs(ord(a)-ord(b))==1` 会漏判，正确用 `(ord(a)-ord(b)) % 26 in (1, 25)`。

## 如果面试官追问
问：若要求输出所有最优串？答：`dp` 存集合而非单串，转移时合并同长度候选，最后按字典序取最小。
