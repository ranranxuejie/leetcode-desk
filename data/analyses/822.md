## 一句话思路
把 `fronts[i] == backs[i]` 的数记成「双面数」放进集合，答案就是所有卡片两面里最小的、不在这个集合中的数。

## 怎么做
1. 扫一遍，把每张 `fronts[i] == backs[i]` 的那个值加入 `same` 集合。
2. 再扫一遍，对每张卡片的 `fronts[i]` 和 `backs[i]` 分别检查是否不在 `same` 里，取最小。
3. 一个都没找到就返回 0。

以示例 1 为例：`fronts = [1,2,4,4,7]`，`backs = [1,3,4,1,3]`。第 0 张 `1==1`、第 2 张 `4==4`，所以 `same = {1, 4}`。第二遍扫到第 1 张时 `backs[1] = 3` 不在 `same`，但 `fronts[1] = 2` 也不在，`2 < 3`，最终 `ans = 2`。

为什么成立：双面数无论怎么翻，总有一面朝上，所以它永远不可能「与所有正面都不同」；反过来，任何非双面数 `x` 出现在某张卡片上时，把这张卡片翻成 `x` 朝下（背面），其余卡片随便翻，`x` 就不会出现在任何正面——因为唯一同时写着 `x` 的卡片已经被压到背面了。

```python
same = set()
for f, b in zip(fronts, backs):
    if f == b:
        same.add(f)

ans = 2001
for f, b in zip(fronts, backs):
    if f not in same:
        ans = min(ans, f)
    if b not in same:
        ans = min(ans, b)

return 0 if ans == 2001 else ans
```

`ans` 初值取 2001 是因为提示里 `fronts[i], backs[i] <= 2000`，比任何合法值都大。

## 复杂度
时间 O(n)：两遍线性扫描，集合查询 O(1)。
空间 O(n)：`same` 最多存 n 个不同的双面数。

## 易错点
- 输入 `fronts = [1], backs = [1]` → 若只判断「某面是否等于另一面」而不建集合，会漏掉这张卡两面相同、`1` 永远朝上的事实，错答 1 → 正确做法是先把所有 `f == b` 的值收进 `same`，再排除。
- 输入 `fronts = [2,2], backs = [2,3]` → 若只看第 1 张卡就返回 `3`，会忽略第 0 张双面 `2` 不影响 `3`、但若把 `3` 当答案前没检查 `2` 是否更小，会错答 3 → 正确做法是两遍扫描取全局最小，别在第一张非双面卡就提前返回。

## 如果面试官追问
问：如果要求输出具体翻哪些卡片，怎么改？
答：记录答案 `x` 来自哪张卡片的哪一面，把那张卡翻成 `x` 朝下，其余卡片保持原样即可。
