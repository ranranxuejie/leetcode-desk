## 一句话思路
模拟执行一遍指令，看终点是否回到原点或朝向是否改变；朝向变了就必然绕圈。

## 怎么做
1. 用 `(x, y)` 记录位置、`d` 记录朝向（0北1东2南3西），遍历 `instructions` 一遍。
2. 遇到 `G` 按 `d` 更新坐标，遇到 `L` 做 `d = (d + 3) % 4`，遇到 `R` 做 `d = (d + 1) % 4`。
3. 遍历结束后判断：若 `(x, y) == (0, 0)` 或 `d != 0`，返回 `True`，否则 `False`。

以 `"GGLLGG"` 为例：走完两个 `G` 得 `(0, 2)`、`d = 0`；两个 `L` 后 `d = 2`（朝南）；再两个 `G` 回到 `(0, 0)`、`d = 2`。位置归零，直接返回 `True`。

```python
x = y = 0
d = 0
dx = [0, 1, 0, -1]
dy = [1, 0, -1, 0]
for c in instructions:
    if c == 'G':
        x += dx[d]
        y += dy[d]
    elif c == 'L':
        d = (d + 3) % 4
    else:
        d = (d + 1) % 4
return (x == 0 and y == 0) or d != 0
```

关键在 `d != 0` 这一支：`"GL"` 走完是 `(0, 1)`、`d = 3`（朝西），位置没归零，但朝向变了，四次重复后必然回到原点，所以也是 `True`。

## 复杂度
时间：O(n)，n 为 `instructions` 长度，只扫一遍。
空间：O(1)，只开了 `x`、`y`、`d` 和两个长度 4 的方向数组。

## 易错点
- 输入 `"GL"` → 只看位置 `(0, 1)` 不归零就返回 `False`，错。正确做法是同时检查 `d != 0`：朝向非北时，最多 4 轮指令必然回到原点。
- 输入 `"GG"` → 位置 `(0, 2)` 不归零但 `d == 0`，若漏掉「朝向必须为北」这个条件，会误判成 `True`。正确做法是位置不归零时，只有 `d == 0` 才返回 `False`，因为朝北且每轮净位移为正，会一直往北走。

## 如果面试官追问
问：如果指令里出现 `"B"`（后退）怎么办？
答：加一个分支，`B` 时按 `d` 的反方向更新坐标，即 `x -= dx[d]; y -= dy[d]`，其余判断逻辑不变。
