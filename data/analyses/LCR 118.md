## 一句话思路
用并查集按 `edges` 顺序加边，第一条让两端已同根的边就是答案，因为它是成环的那条。

## 怎么做
1. 初始化 `parent = list(range(n+1))`，节点 1..n 各自成集合。
2. 按顺序遍历 `edges`，对每条 `[a, b]` 先查根 `find(a)`、`find(b)`。
3. 若两根相同，说明 `a`、`b` 已被之前的边连通，这条边加进去必成环，直接返回 `[a, b]`。
4. 否则合并两集合，继续下一条。

以示例 2 `edges = [[1,2],[2,3],[3,4],[1,4],[1,5]]` 为例：前三条把 1-2-3-4 连成一棵链，此时 `find(1) == find(4) == 1`；处理 `[1,4]` 时两根相同，立即返回 `[1,4]`，后面的 `[1,5]` 根本不用看。

```python
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

for a, b in edges:
    ra, rb = find(a), find(b)
    if ra == rb:
        return [a, b]
    parent[ra] = rb
```

关键点：返回的是**当前这条边**，不是之前某条。因为题目要求「多个答案取最后出现」，而按序加边时，第一条成环的边恰好就是删掉后能还原成树、且下标最大的那条——它之后的边都还没进图。

## 复杂度
时间 O(n·α(n))，n 为边数，α 是并查集近似常数。
空间 O(n)，`parent` 数组开 n+1 个。

## 易错点
- 输入 `[[1,2],[1,3],[2,3]]` → 若先建完整图再 DFS 找环，可能返回 `[1,3]` 或 `[1,2]` 这类非最后边 → 正确做法是按序加边，`[2,3]` 使 `find(2)==find(3)==1` 时立刻返回它。
- 输入 `[[1,2],[2,3],[3,4],[1,4],[1,5]]` → 若把 `parent[ra]=rb` 写成 `parent[a]=b`（不先查根），路径压缩后 `find(1)` 与 `find(4)` 可能不同根，漏判 `[1,4]` → 必须先 `find` 再按根合并。

## 如果面试官追问
问：若要求返回所有可删的边？
答：先并查集定位成环边，再在环上枚举每条边做删边判连通，O(n²) 可接受。
