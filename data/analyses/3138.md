## 一句话思路
枚举 n 的因子 L，用前缀计数判断每段长度 L 的字符频次是否全等于首段，取最小 L。

## 怎么做
1. 先统计整串 `s` 的总频次 `total`，答案 L 必须整除 n，且每段频次 = `total[c] // (n // L)`。
2. 枚举 n 的因子 L（从小到大），对每个 L 只需检查 `s[0:L]` 的频次 `base` 是否在每段重复出现。
3. 用前缀和 `pre[i][c]` 表示前 i 个字符中 c 的个数，则第 k 段 `[kL, (k+1)L)` 的频次为 `pre[(k+1)L][c] - pre[kL][c]`，与 `base[c]` 比较。
4. 第一个全部相等的 L 即答案。

以 `s = "abba"`，n=4 为例：因子 L=1 时 `base = {a:1}`，第二段 `s[1:2]="b"` 频次 `{b:1}` ≠ base，失败；L=2 时 `base = {a:1,b:1}`，第二段 `s[2:4]="ba"` 频次也是 `{a:1,b:1}`，通过，返回 2。

```python
n = len(s)
pre = [[0] * 26]
for ch in s:
    cur = pre[-1][:]
    cur[ord(ch) - 97] += 1
    pre.append(cur)
for L in range(1, n + 1):
    if n % L: continue
    base = [pre[L][c] - pre[0][c] for c in range(26)]
    ok = True
    for k in range(1, n // L):
        seg = [pre[(k+1)*L][c] - pre[k*L][c] for c in range(26)]
        if seg != base:
            ok = False
            break
    if ok:
        return L
```

## 复杂度
时间：枚举因子 O(√n) 个，每个因子检查 O(n/26·26)=O(n)，共 O(n√n)。
空间：前缀和 `pre` 是 (n+1)×26 的整数表，O(26n)。

## 易错点
- 输入 `s = "cdef"`（n=4，无重复字符）→ 若只枚举到 √n 就返回，会漏掉 L=4 本身；正确做法是因子枚举要覆盖到 n，或特判 L=n 必成立。
- 输入 `s = "abcbcacabbaccba"`（n=15）→ 若用 `total[c] % (n//L)` 判断而不逐段比对，会把 L=1 误判通过（总频次能整除但每段分布不同）；正确做法是逐段比较 `seg == base`。

## 如果面试官追问
问：n 到 10^6 怎么办？答：仍枚举因子，但把前缀和换成滚动 26 数组逐段累加，省掉 O(26n) 空间，时间不变。
