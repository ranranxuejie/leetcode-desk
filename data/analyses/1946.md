## 一句话思路
从左往右找第一处 `change[d] > d` 开始替换，一旦遇到 `change[d] < d` 立即停止，因为子串必须连续。

## 怎么做
1. 遍历 `num` 的每个字符，用 `d = int(num[i])` 取原数字，`m = change[d]` 取映射值。
2. 用状态 `started` 标记是否已进入替换区间：未开始时只在 `m > d` 处启动，已开始时遇到 `m < d` 就 `break`。
3. 替换时把 `num[i]` 换成 `str(m)`，其余位置原样保留。

以示例 2 `num = "021"`、`change = [9,4,3,5,7,2,1,9,0,6]` 为例：i=0 时 d=0、m=9，9>0 启动替换得 `"9"`；i=1 时 d=2、m=3，3>2 继续得 `"93"`；i=2 时 d=1、m=4，4>1 继续得 `"934"`，全程未触发 break。

```python
res = []
started = False
for ch in num:
    d = int(ch)
    m = change[d]
    if not started and m > d:
        started = True
    elif started and m < d:
        break
    res.append(str(m) if started else ch)
res.extend(num[len(res):])
return "".join(res)
```

关键在 `break` 后要把剩余部分原样接回：`res` 长度就是已处理的前缀长度，`num[len(res):]` 即未处理尾部。

## 复杂度
时间 O(n)：n 为 `num` 长度，每个字符最多访问一次，break 后直接切片拼接。
空间 O(n)：`res` 列表存 n 个字符，`"".join` 再开一个长度 n 的字符串。

## 易错点
- 输入 `num = "9"`、`change[9] = 3`：若不加 `m > d` 判断就替换，会得到 `"3"` 比原数小；正确做法是未启动时只接受严格变大的映射，`m == d` 也不启动（启动后遇到相等可以继续，因为不损失）。
- 输入 `num = "132"`、`change = [9,8,5,0,3,6,4,2,6,8]`：若把 `change[3]=0 < 3` 也替换，会得到 `"802"` 而非 `"832"`；正确做法是启动后遇到第一个 `m < d` 立刻 break，因为子串连续，越过这个位置再替换就不合法。

## 如果面试官追问
问：如果允许突变任意多个不连续子串呢？
答：那就逐位独立判断，`m > d` 就换、否则保留，不需要 `started` 和 `break`，贪心退化成逐位取 `max(d, change[d])`。
