## 一句话思路
对每个位置枚举「保留 s[i] 作为新段首字符」，用 DP 把同字符尽量聚到一段来省长度。

## 怎么做
1. 定义 `dp[i][j]` = 前 i 个字符删 j 个后的最小压缩长度，答案取 `min(dp[n][0..k])`。
2. 转移时固定 `s[i-1]` 作为当前段字符，向前扫 `p` 收集同字符，统计保留数 `same` 与删除数 `del`。
3. 段长 `same` 的编码代价是 `1 + (0 if same==1 else len(str(same)))`，即 1、2、3 位数字分界。
4. 用 `dp[p][j-del] + cost` 更新，`p` 是段前的位置。

以 `s="aaabcccd", k=2` 为例：取 `i=8`（末尾 `d`），向前扫到 `p=5` 时 `same=3`（三个 `c`）、`del=0`，代价 `1+1=2`，`dp[5][2]+2`；而删掉 `b`、`d` 后 `dp[8][2]` 收敛到 4。

```python
n = len(s)
dp = [[10**9]*(k+1) for _ in range(n+1)]
dp[0][0] = 0
for i in range(1, n+1):
    for j in range(k+1):
        same = 0
        for p in range(i-1, -1, -1):
            if s[p] == s[i-1]:
                same += 1
            else:
                if j == 0: break
                j -= 1
            cost = 1 if same == 1 else (2 if same < 10 else (3 if same < 100 else 4))
            dp[i][j] = min(dp[i][j], dp[p][j] + cost)
```

## 复杂度
时间 O(n²k)：外层 i、内层 j、再向前扫 p，n≤100 可过。
空间 O(nk)：dp 表 n×k，无其他额外结构。

## 易错点
- `s="aaaaaaaaaaa", k=0`：若把段代价写成固定 2，会得 2 而非 3；正确按 `same` 分档 1/2/3/4 位。
- `s="aabbaa", k=2`：若只允许删段内字符、不允许跨段合并，会得 4；正确做法是删两个 `b` 让 `a` 合并成 `a4`，代价 2。

## 如果面试官追问
若要求输出删除后的字符串而非长度？答：dp 额外存「上一段起点 p 和字符」，回溯重建每段即可。
