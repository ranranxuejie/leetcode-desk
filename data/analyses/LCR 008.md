## 一句话思路
用滑动窗口维护一个和 ≥ target 的区间，右指针扩张、左指针收缩，记录最短长度。

## 怎么做
1. 初始化 `left = 0`、`total = 0`、`ans = n + 1`，`ans` 用 `n + 1` 表示「还没找到」。
2. 右指针 `right` 从 0 遍历到 n-1，每步执行 `total += nums[right]`。
3. `while total >= target` 时更新 `ans = min(ans, right - left + 1)`，然后 `total -= nums[left]; left += 1`。
4. 遍历结束返回 `ans if ans <= n else 0`。

以 `target = 7, nums = [2,3,1,2,4,3]` 为例：`right` 走到 4（值为 4）时 `total = 2+3+1+2+4 = 12`，此时窗口 `[0,4]` 长度 5；收缩掉 `nums[0]=2` 后 `total=10`、`left=1`，长度 4；再收缩掉 `nums[1]=3` 后 `total=7`、`left=2`，长度 3；再收缩掉 `nums[2]=1` 后 `total=6 < 7` 停止。`right` 走到 5（值为 3）时 `total=9`，收缩掉 `nums[3]=2` 后 `total=7`、`left=4`，长度 `5-4+1=2`，即 `[4,3]`，这就是最终答案。

```python
left = total = 0
ans = len(nums) + 1
for right, x in enumerate(nums):
    total += x
    while total >= target:
        ans = min(ans, right - left + 1)
        total -= nums[left]
        left += 1
return ans if ans <= len(nums) else 0
```

## 复杂度
时间：O(n)，`right` 和 `left` 各最多前进 n 次，每个元素进出窗口各一次。
空间：O(1)，只用了 `left`、`total`、`ans` 三个变量。

## 易错点
- `nums = [1,1,1,1,1,1,1,1], target = 11` → 若 `ans` 初值设成 `n` 或 `float('inf')` 后直接返回 `ans`，会返回 8 或 `inf` 而不是 0 → 初值用 `n + 1`，返回前判断 `ans <= n`。
- `target = 4, nums = [1,4,4]` → 若写成 `if total >= target` 而非 `while`，收缩一次就退出，`right=1` 时窗口 `[0,1]` 长度 2 被记录，错过 `[1,1]` 长度 1 → 必须用 `while` 把窗口压到刚好不满足为止。

## 如果面试官追问
问：要求返回最短子数组本身而非长度？答：在 `ans` 更新处同时记下 `(left, right)`，最后切片 `nums[left:right+1]` 返回即可。
