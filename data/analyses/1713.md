## 一句话思路
把 target 的值映射成下标，arr 过滤后求最长严格递增子序列，答案 = len(target) 减去该长度。

## 怎么做
1. 建字典 `pos = {v: i for i, v in enumerate(target)}`，把 target 的值换成它在 target 中的位置。
2. 遍历 arr，只保留出现在 pos 里的元素，转成下标序列 `seq`。
3. 对 seq 求最长严格递增子序列（LIS），用 `tails` 数组加 `bisect_left`。
4. 返回 `len(target) - len(tails)`。

以示例 2 为例：`target = [6,4,8,1,3,2]`，pos 为 `{6:0,4:1,8:2,1:3,3:4,2:5}`。arr 过滤后 `seq = [1,0,5,4,2,0,3]`（7 被丢弃，两个 6 都保留）。对 seq 求 LIS 得长度 3（如 `0,2,3` 或 `1,4,5` 对应 target 的 `4,3,2` 等），答案 `6-3=3`。

```python
from bisect import bisect_left

pos = {v: i for i, v in enumerate(target)}
seq = [pos[x] for x in arr if x in pos]
tails = []
for v in seq:
    j = bisect_left(tails, v)
    if j == len(tails):
        tails.append(v)
    else:
        tails[j] = v
return len(target) - len(tails)
```

关键点：`bisect_left` 保证严格递增（重复下标不会延长 LIS），因为 target 无重复，arr 中重复元素映射到同一下标，必须用 left 而非 right。

## 复杂度
时间 O(n + m log m)，n = len(arr) 过滤，m = len(seq) 做 LIS 二分。
空间 O(len(target) + m)，pos 字典和 seq、tails 数组。

## 易错点
- arr 含重复元素（如示例 2 的两个 6）→ 若用 `bisect_right` 求 LIS，重复下标会被算进递增序列，得到偏大的 LIS、偏小的答案 → 必须用 `bisect_left`，严格递增才对应 target 中不同位置。
- arr 中大量元素不在 target 里（如示例 1 的 9、4、2）→ 若不过滤直接对 arr 求 LIS，会把无关元素算进子序列，答案错误 → 先 `if x in pos` 过滤，只保留下标序列再求 LIS。

## 如果面试官追问
要求输出具体插入方案怎么办？
答：LIS 时记录每个 tails 位置的前驱下标，回溯出选中的 target 下标集合，未选中的 target 元素即为需插入的值。
