## 一句话思路
把「子序列最长」转成 0/1 背包：`dp[s]` 存和为 s 时的最大长度，每个 `nums[i]` 倒序更新一次。

## 怎么做
1. 初始化 `dp = [-1] * (target + 1)`，`dp[0] = 0`；-1 表示该和不可达，避免用不可达状态去转移。
2. 外层遍历每个 `x = nums[i]`，内层 `s` 从 `target` 倒着走到 `x`。
3. 转移条件写成 `dp[s - x] != -1`，然后 `dp[s] = max(dp[s], dp[s - x] + 1)`。
4. 返回 `dp[target]`，它本身就是 -1 或最大长度，无需额外判断。

以示例 2 `nums = [4,1,3,2,1,5], target = 7` 为例：处理完前四个数 `4,1,3,2` 后 `dp[7]` 仍是 -1（4+3=7 只有长度 2，但 `dp[7]` 在 `x=3` 时由 `dp[4]+1=2` 得到，之后 `x=2` 时 `dp[7]` 由 `dp[5]+1` 更新为 3）；处理第二个 `1` 时 `dp[7] = dp[6] + 1 = 4`，对应子序列 `[1,3,2,1]`。

```python
dp = [-1] * (target + 1)
dp[0] = 0
for x in nums:
    for s in range(target, x - 1, -1):
        if dp[s - x] != -1:
            dp[s] = max(dp[s], dp[s - x] + 1)
return dp[target]
```

倒序是关键：`s` 从大到小，`dp[s - x]` 还是「没用过当前 x」的旧值，保证每个 `nums[i]` 最多选一次。

## 复杂度
时间：O(n · target)，n 是 `len(nums)`，内层固定扫 target 个状态。
空间：O(target)，只开一个长度 target+1 的 `dp` 数组。

## 易错点
- `nums = [1,2,3,4,5], target = 9` 若内层写成 `for s in range(x, target + 1)` 正序，`x=1` 时 `dp[1]` 会被反复用来更新 `dp[2]`、`dp[3]`…，等于把 1 用了多次，`dp[9]` 会错成 9 而不是 3。必须倒序。
- `nums = [1,1,5,4,5], target = 3` 若把 `dp` 初始化成 `0` 而不是 `-1`，`dp[3]` 会从不可达的 `dp[2]=0` 推出 `dp[3]=1`，错误返回 1 而不是 -1。用 -1 当哨兵，并在转移前判 `dp[s - x] != -1`。

## 如果面试官追问
问：如果要求输出具体子序列而不只是长度？
答：再开一个 `pre[s]` 记录更新 `dp[s]` 时用的下标 i，最后从 target 回溯即可。
