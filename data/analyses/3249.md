## 一句话思路
后序 DFS 一次返回每个子树的节点数，同时比较各子节点返回值是否全相等，相等即计数。

## 怎么做
1. 用 `edges` 建邻接表 `g`，`n = len(edges) + 1`，从 0 出发 DFS，传入 `parent` 防止走回父节点。
2. 对节点 `u`，递归拿到每个子节点 `v` 的子树大小 `s`，收集进 `sizes`。
3. 若 `sizes` 为空（叶子）或 `len(set(sizes)) == 1`，则 `u` 是好节点，`ans += 1`。
4. 返回 `1 + sum(sizes)` 给上层。

以示例 3 为例：节点 9 的子节点是 10 和 12，`dfs(10)` 返回 2（含 11），`dfs(12)` 返回 1，`sizes = [2, 1]`，`set` 大小为 2，故 9 不是好节点；而节点 0 的子节点 1、5、9 分别返回 4、4、4，全相等，0 是好节点。

```python
def dfs(u, p):
    sizes = []
    for v in g[u]:
        if v != p:
            sizes.append(dfs(v, u))
    if len(set(sizes)) <= 1:
        nonlocal ans
        ans += 1
    return 1 + sum(sizes)
```

`len(set(sizes)) <= 1` 同时覆盖了叶子节点（空列表）和单子节点的情况，不必单独判空。

## 复杂度
时间 O(n)：每条边在邻接表里被访问两次，每个节点进 `set` 一次。
空间 O(n)：邻接表 2(n-1) 个元素，递归栈最深 n 层。

## 易错点
- 不传 `parent` 只判 `v != p` 写成 `v != u` 的变体 → 在 `[[0,1],[1,2]]` 上从 1 回到 0 再回到 1 死循环 → 必须显式传父节点 `p` 并在循环里跳过它。
- 把「所有子节点子树大小相同」误判成「所有子节点都是好节点」→ 示例 3 的节点 9 两个子节点 10、12 都是好节点，但大小 2 和 1 不等，会多算成 13 → 比较的是返回值 `sizes` 的数值，不是布尔标记。

## 如果面试官追问
若 n 扩大到 10^6 导致递归爆栈怎么办？答：改成显式栈做后序，用 `order` 记录访问序再逆序累加子树大小，逻辑不变。
