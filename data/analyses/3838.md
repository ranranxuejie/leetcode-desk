## 一句话思路
逐词累加 `weights[ord(c)-97]`，对 26 取模后取 `chr(122 - r)` 拼成结果。

## 怎么做
1. 遍历 `words`，对每个单词用 `sum(weights[ord(c) - 97] for c in w)` 求权重。
2. 对 26 取模得到 `r`，用 `chr(122 - r)` 映射：`r=0` 得 `'z'`，`r=25` 得 `'a'`。
3. 把每个字符追加到结果列表，最后 `''.join(...)`。

以示例 1 的 `"abcd"` 为例：`ord('a')-97=0` 到 `ord('d')-97=3`，权重和 `5+3+12+14=34`，`34 % 26 = 8`，`chr(122-8) = chr(114) = 'r'`。同理 `"def"` 得 17→`'i'`，`"xyz"` 得 16→`'j'`，拼成 `"rij"`。

```python
res = []
for w in words:
    total = 0
    for c in w:
        total += weights[ord(c) - 97]
    r = total % 26
    res.append(chr(122 - r))
return ''.join(res)
```

关键就两行：`ord(c) - 97` 把字母转成 0..25 的下标，`chr(122 - r)` 完成倒序映射。注意不要写成 `chr(97 + r)`，那是正序。

## 复杂度
时间 O(n)，n 为所有单词字符总数，每个字符查一次 `weights`。
空间 O(m)，m 为 `words` 长度，结果列表开销；不计返回值。

## 易错点
- 映射方向写反：把 `chr(122 - r)` 写成 `chr(97 + r)`，示例 1 的 `r=8` 会得 `'i'` 而非 `'r'`，输出变成 `"iji"`。正确做法是记住 `r=0→'z'`、`r=25→'a'`，即 `122 - r`。
- 下标偏移漏减：用 `weights[ord(c)]` 而非 `weights[ord(c) - 97]`，`'a'` 的 `ord` 是 97，直接越界报 `IndexError`。正确做法是统一减 97 转成 0..25。

## 如果面试官追问
若 `weights[i]` 放大到 `10**9`、单词长度到 `10**5`，总和会超 32 位怎么办？答：Python 整数无溢出，直接累加即可；若题目规定按 32 位截断，则每步 `total = (total + w) % 26` 提前取模。
