## 一句话思路
从 node1、node2 各沿唯一出边走一遍记下距离，取两距离表都有的节点里 max 最小的那个。

## 怎么做
1. 写一个 `walk(start)`：沿 `edges` 一路走，用 `dist[start]=0` 起步，每步 `dist[nxt]=dist[cur]+1`，遇到 `-1` 或已访问节点就停。
2. 对 `node1`、`node2` 各调一次，得到 `d1`、`d2` 两张字典。
3. 遍历 `d1` 的键，只保留在 `d2` 里的，比较 `max(d1[v], d2[v])`，更小就更新答案；相等时取更小节点编号。
4. 没有交集返回 `-1`。

以示例 1 `edges=[2,2,3,-1]` 为例：`walk(0)` 得 `{0:0, 2:1, 3:2}`，`walk(1)` 得 `{1:0, 2:1, 3:2}`。交集 `{2,3}`，节点 2 的 max 是 `max(1,1)=1`，节点 3 是 `max(2,2)=2`，答案 2。

```python
def walk(start):
    dist, cur = {}, start
    while cur != -1 and cur not in dist:
        dist[cur] = len(dist)
        cur = edges[cur]
    return dist

d1, d2 = walk(node1), walk(node2)
best, ans = 10**9, -1
for v, a in d1.items():
    if v in d2:
        m = max(a, d2[v])
        if m < best or (m == best and v < ans):
            best, ans = m, v
return ans
```

关键点：`len(dist)` 当距离用，因为路径无分叉，第 k 个入表的节点距离就是 k；`cur not in dist` 同时挡住环和重复入表。

## 复杂度
时间 O(n)：两条链各走一遍，最多访问 n 个节点。
空间 O(n)：两张距离字典各存一条链上的节点。

## 易错点
- 输入 `edges=[2,2,3,-1]` 这类带环图（如 `edges=[1,2,0]`）→ 若只用 `cur != -1` 判停会死循环 → 必须加 `cur not in dist`，入表即视为已访问。
- 两链不相交（如 `edges=[1,-1,-1], node1=0, node2=2`）→ 若把 `ans` 初值设 0 或忘了判空会返回 0 → 初值设 `-1`，遍历完仍是 `-1` 就返回它。
- 平局时（示例 1 的节点 2 与 3 之外，构造 `max` 相等的两节点）→ 只写 `m < best` 会漏掉「取最小编号」→ 补 `m == best and v < ans`。

## 如果面试官追问
若要求返回所有最优节点而非单个？答：把更新条件从「严格更优」改成「不劣于」，用列表收集，最后排序返回。
