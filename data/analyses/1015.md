## 一句话思路
逐位构造余数 `r = (r * 10 + 1) % k`，用哈希表记录出现过的余数，重复即无解。

## 怎么做
1. 特判 `k % 2 == 0 or k % 5 == 0` 直接返回 `-1`，因为末尾是 1 的数不可能被 2 或 5 整除。
2. 维护余数 `r` 和长度 `length`，每轮先 `r = (r * 10 + 1) % k`，再 `length += 1`。
3. 若 `r == 0` 返回 `length`；若 `r` 已在 `seen` 中出现过，说明进入循环，返回 `-1`。
4. 否则把 `r` 加入 `seen` 继续。

以 `k = 3` 为例：初始 `r = 0, length = 0`。第一轮 `r = (0*10+1)%3 = 1`，`length = 1`，`seen = {1}`；第二轮 `r = (1*10+1)%3 = 2`，`length = 2`，`seen = {1,2}`；第三轮 `r = (2*10+1)%3 = 0`，`length = 3`，命中 `r == 0` 返回 3。对应 111。

```python
def smallestRepunitDivByK(k):
    if k % 2 == 0 or k % 5 == 0:
        return -1
    seen = set()
    r, length = 0, 0
    while r not in seen:
        seen.add(r)
        r = (r * 10 + 1) % k
        length += 1
        if r == 0:
            return length
    return -1
```

关键点：`r` 只保留模 `k` 的余数，不需要真的构造 111…，因为 `(a*10+1) % k` 只依赖 `a % k`。

## 复杂度
时间：O(k)，余数最多 k 种，循环至多 k+1 次。
空间：O(k)，`seen` 集合最多存 k 个余数。

## 易错点
- `k = 2` 或 `k = 5` → 若不特判，循环会一直跑，`r` 永远在 `{1}` 或 `{1,2,3,4}` 里打转，靠 `seen` 检测能返回 `-1`，但多绕一圈；正确做法是开头直接 `k % 2 == 0 or k % 5 == 0` 返回 `-1`。
- `k = 1` → 若先判断 `k % 2 == 0 or k % 5 == 0` 没问题，但若把 `seen` 初始化为 `{0}` 再进循环，第一轮 `r = 1`，`length = 1`，`r != 0`，第二轮 `r = (1*10+1)%1 = 0`，返回 2，错成 2；正确做法是 `seen` 初始为空，先算 `r` 再判 `r == 0`，`k = 1` 时第一轮 `r = 0` 返回 1。

## 如果面试官追问
问：如果要求输出那个 repunit 本身而不是长度？答：长度可能到 k，构造字符串会 O(k²)，应只返回长度或按需用大数库。
