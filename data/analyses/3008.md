## 一句话思路
先分别求出 a、b 在 s 中所有匹配起点，再用双指针判断每个 a 起点附近 k 内是否有 b 起点。

## 怎么做
1. 用 KMP 或 `str.find` 循环扫出 `posA`、`posB` 两个升序列表。
2. 对 `posA` 中每个 `i`，维护指针 `p` 指向 `posB` 中第一个 `>= i-k` 的位置。
3. 若 `p` 未越界且 `posB[p] <= i+k`，则 `i` 是美丽下标。
4. 因 `posA` 升序，`p` 只增不减，整体线性。

以示例 1 为例：`posA = [16, 33]`，`posB = [4, 18]`。处理 `i=16` 时 `i-k=1`，`p` 停在 0（`posB[0]=4 >= 1`），`4 <= 31` 成立，收 16；处理 `i=33` 时 `i-k=18`，`p` 推进到 1（`posB[1]=18`），`18 <= 48` 成立，收 33。

```python
def find_all(s, pat):
    res, start = [], s.find(pat)
    while start != -1:
        res.append(start)
        start = s.find(pat, start + 1)
    return res

posA, posB = find_all(s, a), find_all(s, b)
ans, p = [], 0
for i in posA:
    while p < len(posB) and posB[p] < i - k:
        p += 1
    if p < len(posB) and posB[p] <= i + k:
        ans.append(i)
```

## 复杂度
时间 O(|s| + |a| + |b| + |posA| + |posB|)，匹配与双指针各扫一遍。
空间 O(|posA| + |posB|)，存两组匹配起点。

## 易错点
- `a` 或 `b` 比 `s` 长（如 `s="ab"`, `a="abc"`）→ `find` 返回 -1，`posA` 为空，若忘了判空直接取 `posA[0]` 会崩；正确做法是空列表直接返回 `[]`。
- 重叠匹配（如 `s="aaa"`, `a="aa"`）→ 用 `s.find(a, start+1)` 而非 `start+len(a)`，否则漏掉起点 1；正确做法是每次只前进 1 位继续找。

## 如果面试官追问
若 k 很大且要求输出所有 (i,j) 配对方案？答：对每个 `i` 在 `posB` 上二分出 `[i-k, i+k]` 区间，枚举区间内全部 j，复杂度变为 O(答案规模 × log)。
