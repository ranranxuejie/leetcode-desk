## 一句话思路
在 `[1, num]` 上二分找整数 `mid` 使 `mid * mid == num`，因为平方在正数区间单调递增。

## 怎么做
1. 令 `lo, hi = 1, num`，闭区间搜索候选根。
2. 每轮取 `mid = (lo + hi) // 2`，比较 `mid * mid` 与 `num`。
3. `mid * mid == num` 直接返回 `True`；小于则 `lo = mid + 1`，大于则 `hi = mid - 1`。
4. 循环结束仍未命中返回 `False`。

拿 `num = 14` 走一遍关键一步：初始 `lo=1, hi=14`，`mid=7`，`7*7=49 > 14`，于是 `hi=6`；下一轮 `mid=3`，`9 < 14`，`lo=4`；再 `mid=5`，`25 > 14`，`hi=4`；最后 `mid=4`，`16 > 14`，`hi=3`，`lo=4 > hi=3` 退出，返回 `False`。注意 `mid=3` 时 `9` 与 `14` 差 5，`mid=4` 时 `16` 与 `14` 差 2，夹逼到相邻两数之间就说明不是平方数。

```python
lo, hi = 1, num
while lo <= hi:
    mid = (lo + hi) // 2
    sq = mid * mid
    if sq == num:
        return True
    if sq < num:
        lo = mid + 1
    else:
        hi = mid - 1
return False
```

`num = 1` 时 `lo=hi=1`，`mid=1`，`1*1==1` 首轮命中，不会漏掉下界。

## 复杂度
时间：二分 `num` 的根，约 `log(num)` 轮，每轮一次乘法，O(log num)。
空间：只存 `lo/hi/mid/sq` 四个整数，O(1)。

## 易错点
- `num = 2**31 - 1`（2147483647）→ 若把 `hi` 设成 `num // 2` 会漏掉 `num = 1` 的情况（`1//2 = 0`，区间空，直接返回 `False`）→ 正确做法是 `hi = num`，或单独判 `num == 1`。
- `num = 9` → 若循环条件写成 `lo < hi`，`lo=hi=3` 时退出，`3*3==9` 没被检查，错判 `False` → 必须用 `lo <= hi`，保证单点区间也被验证。

## 如果面试官追问
问：不用二分，怎么 O(1) 空间做？答：用牛顿迭代 `x = (x + num // x) // 2` 逼近根，收敛后验 `x*x == num`，注意初值取 `num` 且循环条件 `x*x > num`。
