## 一句话思路
把 dictionary 建成字典树，对 sentence 每个词沿树走，走到第一个词根结尾就截断替换，天然满足「最短词根」。

## 怎么做
1. 把 dictionary 全部插入字典树，节点用 `dict` 存子节点，末尾用 `end` 标记。
2. 按空格切分 sentence，对每个词从根开始逐字符下探。
3. 一旦命中 `end` 立刻停，用已走过的前缀替换；走不动则保留原词。
4. 用空格拼回结果。

以示例 1 为例：dictionary 建树后，处理 `"cattle"` 时依次走 `c→a→t`，在 `t` 节点命中 `end`（词根 `cat`），立即停，输出 `"cat"`，不再看后面的 `tle`；处理 `"battery"` 时走 `b→a→t` 命中 `bat`，输出 `"bat"`。

```python
trie = {}
for w in dictionary:
    node = trie
    for ch in w:
        node = node.setdefault(ch, {})
    node['#'] = True

def root_of(word):
    node, i = trie, 0
    while i < len(word) and word[i] in node:
        node = node[word[i]]
        i += 1
        if '#' in node:
            return word[:i]
    return word

return ' '.join(root_of(w) for w in sentence.split(' '))
```

## 复杂度
时间：O(总字符数)，建树 O(Σ|dictionary[i]|)，匹配 O(|sentence|)，每字符 O(1)。
空间：O(Σ|dictionary[i]|) 存字典树节点，输出串另占 O(|sentence|)。

## 易错点
- dictionary 含 `["catt","cat"]` 且句子有 `"cattle"`：若先插长词或匹配时不提前停，会返回 `"catt"`；正确做法是命中 `end` 立即 `return word[:i]`，保证取最短。
- 词根是整词前缀但词本身更短，如词根 `"abc"`、句子词 `"ab"`：若循环条件写成 `i <= len(word)` 或先判 `end` 再判越界，会越界或误配；正确做法是 `while i < len(word) and word[i] in node`，走完仍未命中就返回原词。

## 如果面试官追问
若 sentence 长到 10^8 且单词极多，怎么优化？答：仍用字典树，但按空格流式扫描、边扫边输出，避免 `split` 一次性生成全部子串占内存。
