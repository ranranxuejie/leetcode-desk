## 一句话思路
把 `nums` 相邻元素的升降关系压成 -1/0/1 数组 `diff`，问题变成在 `diff` 里数 `pattern` 出现几次，用滚动哈希 O(n+m) 做。

## 怎么做
1. 先构造 `diff`：`diff[i] = (nums[i+1] > nums[i]) - (nums[i+1] < nums[i])`，长度 n-1。
2. 对 `pattern` 和 `diff` 用同一个 base、同一个模数做前缀哈希，`pattern` 的哈希值只算一次。
3. 枚举 `diff` 中每个长度 m 的窗口，比较哈希值，相等则计数。
4. 用双哈希或大模数降低碰撞概率。

以示例 2 为例：`nums = [1,4,4,1,3,5,5,3]`，`diff = [1,0,-1,1,1,0,-1]`，`pattern = [1,0,-1]`。窗口 `diff[0..2] = [1,0,-1]` 和 `diff[4..6] = [1,0,-1]` 都匹配，答案 2。

```python
MOD1, MOD2 = 10**9+7, 10**9+9
BASE = 131
diff = [(nums[i+1] > nums[i]) - (nums[i+1] < nums[i]) for i in range(len(nums)-1)]
def build(arr):
    h1 = [0]*(len(arr)+1); h2 = [0]*(len(arr)+1)
    p1 = [1]*(len(arr)+1); p2 = [1]*(len(arr)+1)
    for i, v in enumerate(arr):
        h1[i+1] = (h1[i]*BASE + v+1) % MOD1
        h2[i+1] = (h2[i]*BASE + v+1) % MOD2
        p1[i+1] = p1[i]*BASE % MOD1
        p2[i+1] = p2[i]*BASE % MOD2
    return h1, h2, p1, p2
```

## 复杂度
时间：O(n+m)，构造 diff 和哈希各扫一遍，窗口枚举 O(n)。
空间：O(n)，存 diff 和两套前缀哈希数组。

## 易错点
- `pattern` 长度 m 可能等于 n-1，此时 `diff` 只有一个窗口，循环边界要写成 `range(len(diff)-m+1)`，否则会漏掉或越界。
- 单哈希在 n=10^6 时碰撞概率不可忽略，必须用双哈希或随机 base，否则示例能过但隐藏用例会 WA。

## 如果面试官追问
问：能不能不用哈希？答：可以，KMP 把 `pattern` 当模式串在 `diff` 上匹配，O(n+m) 且无碰撞风险。
