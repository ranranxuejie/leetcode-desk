## 一句话思路
正数找第一个小于 x 的位插前面，负数找第一个大于 x 的位插前面，一次扫描即可。

## 怎么做
1. 判断 `n[0] == '-'`，负数时从下标 1 开始扫，正数从 0 开始。
2. 正数：找第一个 `n[i] < x` 的位置，插在它前面；找不到就追加到末尾。
3. 负数：找第一个 `n[i] > x` 的位置，插在它前面；找不到就追加到末尾。
4. 用 `n[:i] + str(x) + n[i:]` 拼回字符串。

以 `n = "-13", x = 2` 为例：从 `i = 1` 起扫，`n[1] = '1'`，`1 > 2` 为 `False`，继续；`n[2] = '3'`，`3 > 2` 为 `True`，命中 `i = 2`，拼出 `"-1" + "2" + "3" = "-123"`。若误用正数规则（找 `< 2`），会在 `i = 1` 处插入得 `"-213"`，比 `-123` 小，这就是符号决定方向的原因。

```python
def maxValue(n, x):
    neg = n[0] == '-'
    start = 1 if neg else 0
    i = start
    while i < len(n):
        if (not neg and n[i] < x) or (neg and n[i] > x):
            break
        i += 1
    return n[:i] + str(x) + n[i:]
```

注意 `x` 是整数，比较时 `n[i]` 是字符，Python 里 `'3' < 2` 会抛 `TypeError`，所以要么先把 `x` 转成 `str(x)` 再比，要么比较 `int(n[i])`。上面代码里 `n[i] < x` 依赖 `x` 已转字符串，实际写时统一成 `x = str(x)` 最省事。

## 复杂度
时间 O(len(n))，一次线性扫描，插入拼接也是 O(len(n))。
空间 O(len(n))，结果字符串本身占 n 位，无额外辅助结构。

## 易错点
- 输入 `n = "-13", x = 2` → 若沿用正数的「找第一个小于 x」规则，会在 `'1'` 前插入得 `"-213"` → 负数要反过来找第一个**大于** x 的位，得 `"-123"`。
- 输入 `n = "99", x = 9` 或 `n = "-99", x = 9` → 若循环条件写成 `<=` / `>=`，会在第一个 `'9'` 前插入，虽然本题结果相同，但换成 `n = "98", x = 9` 时正数应得 `"998"`（追加），写成 `<=` 会得 `"998"` 也对，真正翻车在负数 `n = "-98", x = 9`：`9 > 9` 为 `False` 应追加得 `"-989"`，若写成 `>=` 会在 `'9'` 前插得 `"-998"`，更小 → 严格用 `<` / `>`，相等时继续往后走。

## 如果面试官追问
问：如果允许插入多个 x 呢？
答：正数把 x 插到第一个小于 x 的位前（连续插 k 个），负数插到第一个大于 x 的位前，仍是 O(len(n))。
