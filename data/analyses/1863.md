## 一句话思路
按位统计：第 k 位上，只要 nums 中有元素带这一位，就有 2^(n-1) 个子集异或后该位为 1，直接累加。

## 怎么做
1. 对每个二进制位 k（nums[i] ≤ 20，只需 k 从 0 到 4），统计 nums 中有多少元素第 k 位为 1。
2. 若该位在 nums 中出现过（count > 0），则所有 2^n 个子集中恰有一半（2^(n-1) 个）异或结果该位为 1。
3. 把 `(1 << k) * (1 << (n-1))` 累加到答案。
4. 若某位在 nums 中从未出现，则该位贡献为 0，跳过。

以 nums = [5,1,6] 为例，n=3，2^(n-1)=4。5=101、1=001、6=110，第 0 位有 5 和 1 出现，第 1 位有 6 出现，第 2 位有 5 和 6 出现。所以答案 = 1×4 + 2×4 + 4×4 = 4+8+16 = 28，与示例一致。

```python
n = len(nums)
ans = 0
for k in range(5):          # nums[i] <= 20，5 位足够
    if any((x >> k) & 1 for x in nums):
        ans += (1 << k) * (1 << (n - 1))
return ans
```

关键中间值：n=3 时 `1 << (n-1)` = 4，即每个出现过的位固定贡献 4 份。

## 复杂度
时间：O(n × 5)，n 为 nums 长度，5 是固定位数。
空间：O(1)，只用了 ans、k 两个变量。

## 易错点
- 输入 nums = [1]（n=1）→ 若写成 `1 << n` 会得到 2 份，答案错成 2；正确是 `1 << (n-1)` = 1 份，答案 1。空子集异或为 0 不贡献，只有 [1] 贡献 1。
- 输入 nums = [0,0] 或含 0 元素 → 若用「count > 0 才累加」但把 0 当成有效位，会多算；正确做法是判断 `(x >> k) & 1` 为 1 才算该位出现，0 的所有位都是 0，不贡献。

## 如果面试官追问
问：如果 nums 长度到 10^5 怎么办？
答：公式不变，仍是 O(n × 位数)，位数取 max(nums).bit_length()，n 大也只多扫一遍数组。
