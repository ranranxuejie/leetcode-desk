## 一句话思路
对每个节点只保留其邻居中值为正的前 k 大，取「vals[i] + 这些正值之和」的最大值；因为负邻居只会拉低星和，多选无益。

## 怎么做
1. 用邻接表 `adj` 把 `edges` 双向存好，`adj[a].append(b)`、`adj[b].append(a)`。
2. 对每个中心 `i`，把 `adj[i]` 里 `vals[j] > 0` 的邻居值收集起来，降序排序后取前 `k` 个求和。
3. 答案初值设为 `max(vals)`（对应 0 条边的星图），再对每个 `i` 用 `vals[i] + 正邻居前 k 大之和` 更新。
4. 返回该最大值。

以示例 1 为例，中心 `i=3` 的邻居是 `[1,4,5,6]`，对应值 `[2,10,-10,-20]`，过滤正值得 `[10,2]`，`k=2` 全取，和 `12`，加 `vals[3]=4` 得 `16`，正是答案。中心 `i=1` 的邻居值 `[1,3,4]` 取前 2 得 `7`，加 `vals[1]=2` 得 `9`，小于 16。

```python
adj = [[] for _ in range(n)]
for a, b in edges:
    adj[a].append(b)
    adj[b].append(a)
ans = max(vals)
for i in range(n):
    pos = sorted((vals[j] for j in adj[i] if vals[j] > 0), reverse=True)
    ans = max(ans, vals[i] + sum(pos[:k]))
return ans
```

## 复杂度
时间：建图 O(n + m)，每个节点排序其正邻居，总 O(m log m)，m 为边数。
空间：邻接表 O(n + m)，排序临时列表最坏 O(m)。

## 易错点
- `k = 0` 或全图无边（如示例 2 的 `vals = [-5]`）→ 若只对「有邻居的中心」求值会漏掉单点星图 → 答案初值必须取 `max(vals)`，保证 0 条边的情况被覆盖。
- 邻居值全为负（如中心 3 的邻居含 `-10`、`-20`）→ 若直接取「前 k 大」而不先过滤 `> 0`，会把 `-10` 加进去得到 `4 + 10 + 2 - 10 = 6` → 必须先过滤 `vals[j] > 0` 再取前 k，负值一律不选。

## 如果面试官追问
要求输出具体选了哪些邻居怎么办？
答：排序时存 `(vals[j], j)` 元组，取前 k 个后同时记录下标，返回 `(ans, i, 选中邻居列表)`。
