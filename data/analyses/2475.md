## 一句话思路
按值分组计数，枚举三个不同值，用「左边个数 × 中间个数 × 右边个数」累加，天然满足 i<j<k。

## 怎么做
1. 用 `Counter(nums)` 得到每个值出现次数，再按键排序得到 `vals` 和对应 `cnt`。
2. 枚举三个不同值的下标 `a < b < c`，把 `cnt[a] * cnt[b] * cnt[c]` 累加进答案。
3. 为什么成立：三组值互不相同，任取一个来自每组的下标，排序后必然满足 i<j<k，且不会重复计数。

以 `nums = [4,4,2,4,3]` 为例，`Counter` 得 `{4:3, 2:1, 3:1}`，排序后 `vals=[2,3,4]`、`cnt=[1,1,3]`。唯一的三值组合是 (2,3,4)，贡献 `1*1*3 = 3`，与输出 3 一致。

```python
from collections import Counter

def unequalTriplets(nums):
    cnt = Counter(nums)
    vals = sorted(cnt)
    ans = 0
    m = len(vals)
    for a in range(m):
        for b in range(a + 1, m):
            for c in range(b + 1, m):
                ans += cnt[vals[a]] * cnt[vals[b]] * cnt[vals[c]]
    return ans
```

也可以只枚举中间值 `b`，用前缀和 `left = sum(cnt[vals[:b]])`、`right = n - left - cnt[vals[b]]`，累加 `left * cnt[vals[b]] * right`，把三重循环降到两重。

## 复杂度
时间：O(n + d^3)，n 是数组长度用于计数，d 是不同值个数，d ≤ 100。
空间：O(d)，`Counter` 和排序后的 `vals` 各存 d 个元素。

## 易错点
1. 输入 `[1,1,1,1,1]` → 若按「下标三元组」暴力枚举再判不等，会得到 0 但循环量是 C(5,3)=10；若误把「值不同」写成「下标不同」，会错答 10。正确做法是先按值分组，`len(vals) < 3` 时直接返回 0。
2. 输入 `[4,4,2,4,3]` → 若对每个值只计 1 次（把 `cnt[4]` 当 1），会得 1 而非 3。正确做法是乘上各组出现次数 `cnt[vals[a]] * cnt[vals[b]] * cnt[vals[c]]`，因为 4 有三个下标可选。

## 如果面试官追问
若 n 放大到 10^5 且值域也大，怎么办？答：仍是 O(n + d^3)，d 最多 n，但可用前缀和把枚举降到 O(d^2)，实际 d 通常远小于 n。
