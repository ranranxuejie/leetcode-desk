## 一句话思路
枚举所有 (i, j) 组合，用 `nums2[j] * k % nums1[i] == 0` 判断整除，n、m ≤ 50 时 2500 次判断足够。

## 怎么做
1. 双重循环遍历 `nums1` 的下标 i 和 `nums2` 的下标 j。
2. 对每个组合算 `nums2[j] * k`，判断它能否被 `nums1[i]` 整除。
3. 能整除就 `count += 1`，最后返回 `count`。

以示例 2 为例：`nums1 = [1,2,4,12]`，`nums2 = [2,4]`，`k = 3`。当 i=3（`nums1[3]=12`）、j=0 时，`nums2[0]*k = 2*3 = 6`，`6 % 12 = 6 ≠ 0`，不计数；j=1 时 `4*3 = 12`，`12 % 12 = 0`，计数。i=0 时 `nums1[0]=1`，`6 % 1 = 0` 和 `12 % 1 = 0` 都成立——但示例 2 输出是 2 而不是 4，说明这里要按题面「nums1[i] 可以除尽 nums2[j]*k」理解为 `nums2[j]*k % nums1[i] == 0`，即 nums1 是除数。按此口径 i=0 的 1 确实能除尽 6 和 12，会多算——所以正确口径是 `nums1[i] % (nums2[j]*k) == 0`？示例 2 中只有 12 满足 `12 % 6 == 0` 和 `12 % 12 == 0`，正好 2 个，与输出一致。**采用 `nums1[i] % (nums2[j] * k) == 0`**。

```python
count = 0
for a in nums1:
    for b in nums2:
        if a % (b * k) == 0:
            count += 1
return count
```

示例 1 验证：`k=1`，`nums1=[1,3,4]`，`nums2=[1,3,4]`。a=1：`1%1=0`、`1%3≠0`、`1%4≠0`，计 1；a=3：`3%1=0`、`3%3=0`、`3%4≠0`，计 2；a=4：`4%1=0`、`4%3≠0`、`4%4=0`，计 2。合计 5，与输出一致。

## 复杂度
时间：O(n·m)，n、m 分别是两数组长度，本题上限 50×50。
空间：O(1)，只开 `count` 一个累加变量。

## 易错点
- 把整除方向写反成 `(b*k) % a == 0` → 示例 2 会得 4（a=1 时 6、12 都能被 1 除尽）→ 正确是 `a % (b*k) == 0`，只有 a=12 的两个组合成立。
- 忘记乘 k 或把 k 乘到 nums1 上 → 示例 2 中 `12 % 2 == 0`、`12 % 4 == 0` 会得 2 但纯属巧合，换 `k=3` 的其它数据立刻错 → 必须写成 `b * k` 整体作除数。

## 如果面试官追问
问：n、m 放大到 10^5 怎么办？
答：枚举 nums1 的每个值 a，只需检查 a 的约数 d 是否等于某个 `nums2[j]*k`，用哈希表存 nums2 频次，按约数枚举降到 O(n√max)。
