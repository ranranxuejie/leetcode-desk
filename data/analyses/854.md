## 一句话思路
从 s1 出发做 BFS，每层枚举「把第一个错位字符换对」的所有交换，首次到达 s2 的层数就是最小 k。

## 怎么做
1. 队列存字符串状态，`seen` 哈希集去重，`step` 记录层数。
2. 出队时先找第一个 `cur[i] != s2[i]` 的位置 `i`；若不存在说明已等于 s2，返回 `step`。
3. 只枚举 `j > i` 且 `cur[j] == s2[i]` 的位置交换——把 `i` 一次修好，不浪费步数。
4. 新串不在 `seen` 里就入队，层数加一继续。

以 `s1="abc", s2="bca"` 为例：第 0 层 `"abc"`，`i=0`，只有 `j=2` 满足 `cur[2]=='a'`，交换得 `"cba"`；第 1 层 `"cba"`，`i=0` 时 `cur[0]=='c'==s2[0]`，`i=1` 处 `cur[1]=='b'==s2[1]`，`i=2` 处 `cur[2]=='a'!=s2[2]=='a'`？实际 `"cba"` 与 `"bca"` 在 `i=1` 就不同，交换 `j=2` 得 `"cab"`… 关键中间值是第 1 层只产生 `"cba"` 一个状态，第 2 层才出现 `"bca"`，故返回 2。

```python
from collections import deque

def kSimilarity(s1, s2):
    q, seen, step = deque([s1]), {s1}, 0
    while q:
        for _ in range(len(q)):
            cur = q.popleft()
            if cur == s2:
                return step
            i = 0
            while cur[i] == s2[i]:
                i += 1
            for j in range(i + 1, len(cur)):
                if cur[j] == s2[i]:
                    nxt = cur[:i] + cur[j] + cur[i+1:j] + cur[i] + cur[j+1:]
                    if nxt not in seen:
                        seen.add(nxt)
                        q.append(nxt)
        step += 1
```

## 复杂度
时间：O(n! · n)，BFS 状态数最坏为错位字符的排列数，每次生成新串 O(n)。
空间：O(n! · n)，`seen` 存全部访问过的字符串，队列同阶。

## 易错点
- 输入 `s1="ab", s2="ba"`：若枚举所有 `j != i` 的交换（包括 `j < i`），会生成重复状态并多算层数；正确做法是只对 `j > i` 且 `cur[j] == s2[i]` 交换，保证每步至少修好位置 `i`。
- 输入 `s1="abc", s2="abc"`：若忘记在出队时先判 `cur == s2` 再找 `i`，`while cur[i] == s2[i]` 会越界；正确做法是先返回 `step`（此时为 0），或给 `i` 加 `i < n` 边界。

## 如果面试官追问
问：n 到 20 时 BFS 状态爆炸怎么办？答：改用带剪枝的 DFS + 记忆化，或对每个环单独计数（长度 L 的环需 L-1 次交换），按环分解求和。
