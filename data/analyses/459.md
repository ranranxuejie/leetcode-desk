## 一句话思路
把 `s` 拼成 `s+s` 后掐头去尾，若其中还能找到 `s`，说明 `s` 由某个子串重复而成。

## 怎么做
1. 令 `t = (s + s)[1:-1]`，即去掉首尾各一个字符，避免原串自身直接匹配造成误判。
2. 在 `t` 中查找 `s`，用 `s in t` 判断是否出现。
3. 出现则返回 `True`，否则 `False`。

以 `s = "abab"` 为例：`s+s = "abababab"`，掐头去尾得 `t = "bababa"`；`"abab" in "bababa"` 为真，因为 `t[1:5] = "abab"`，返回 `True`。若 `s = "aba"`，`t = "baab"`，找不到 `"aba"`，返回 `False`。

```python
def repeatedSubstringPattern(s):
    t = (s + s)[1:-1]
    return s in t
```

为什么掐头去尾有效：若 `s` 由长度 `k` 的子串重复 `m` 次构成（`m >= 2`），则 `s+s` 中 `s` 的第二次出现起点偏移为 `k`，落在 `[1, len(s)-1]` 内，掐掉首尾后仍完整保留。反之若 `s` 在 `t` 中出现，其起点偏移 `p` 满足 `1 <= p <= len(s)-1`，由周期性可推出 `s` 有长度 `p` 的循环节，即由子串重复构成。

## 复杂度
时间 O(n)：`s+s` 拼接与子串查找各 O(n)，n 为 `s` 长度。
空间 O(n)：额外开了长度约 `2n` 的字符串 `t`。

## 易错点
- 直接写 `s in s+s` → `"aba"` 会因原串自身匹配返回 `True` → 必须掐头去尾成 `(s+s)[1:-1]` 再查。
- 用 `len(s) % k == 0` 枚举因子但漏掉 `k < len(s)` 的约束 → 单字符 `s = "a"` 时 `k = 1` 等于全长，会误判为 `True` → 枚举时要求 `k` 是真因子，或直接用拼接法避开。

## 如果面试官追问
问：不用额外空间怎么做？答：用 KMP 求 `s` 的 `next` 数组，若 `n % (n - next[n-1]) == 0` 且 `next[n-1] > 0` 则为重复串。
