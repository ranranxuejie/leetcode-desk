## 一句话思路
把每个安检室看作对「逆序数」贡献 `cap-1` 或 `0`，问题变成从 `capacities` 里选若干项凑出 `k` 的 0/1 背包计数。

## 怎么做
1. 关键观察：LIFO 室容量为 `c` 时，内部恰好产生 `c-1` 个逆序对；FIFO 室产生 `0` 个，且室与室之间不产生逆序对。
2. 于是「总逆序数恰为 `k`」等价于「选出若干室设为 LIFO，使 `sum(c-1) == k`」，其余室设 FIFO。
3. 做 0/1 背包：`dp[j]` 表示凑出逆序数 `j` 的方案数，对每个 `w = c-1` 倒序更新 `dp[j] += dp[j-w]`。
4. 答案即 `dp[k]`；`w == 0`（容量 1 的室）不影响计数，跳过即可。

以 `capacities = [2,2,3], k = 2` 为例：权重为 `[1,1,2]`。处理完前两个 1 后 `dp = [1,2,1]`；再处理 `w=2` 倒序得 `dp[2] = 1 + dp[0] = 2`，与输出 `2` 一致。

```python
MOD = 10**9 + 7
dp = [0] * (k + 1)
dp[0] = 1
for c in capacities:
    w = c - 1
    if w == 0 or w > k:
        continue
    for j in range(k, w - 1, -1):
        dp[j] = (dp[j] + dp[j - w]) % MOD
return dp[k]
```

## 复杂度
时间：`O(n * k)`，`n = len(capacities)`，内层倒序扫到 `k`。
空间：`O(k)`，只开一维 `dp` 数组，无额外结构。

## 易错点
- `capacities = [3,3], k = 3`：权重都是 `2`，凑不出奇数 3，答案应为 `0`；若把 `w` 误写成 `c`，会算出非零。正确做法是权重取 `c-1`。
- `capacities = [1,1,1], k = 0`：所有 `w = 0`，若直接 `dp[j] += dp[j-0]` 会把 `dp[0]` 反复加倍成 `8`；正确做法是 `w == 0` 时 `continue`，答案保持 `1`。

## 如果面试官追问
问：若 `k` 可达 `sum(capacities)` 即 `4*10^4`，`n=200`，还能这么做吗？
答：能，`O(n*k) ≈ 8*10^6`，一维 `dp` 仍是正解；只需注意 `w > k` 时提前跳过。
