## 一句话思路
按格 DP，每格存「异或值 → 路径数」的 16 长度数组，因为 grid 值 < 16 所以异或值恒在 0..15。

## 怎么做
1. 状态 `dp[i][j][x]` = 走到 (i,j) 时异或值为 x 的路径数，x 只需 0..15。
2. 起点 `dp[0][0][grid[0][0]] = 1`，其余全 0。
3. 每格由上方和左方转移：`dp[i][j][x ^ grid[i][j]] += dp[i-1][j][x] + dp[i][j-1][x]`。
4. 答案取 `dp[m-1][n-1][k] % (10**9+7)`。

以示例 1 的 `grid[1][1] = 10` 为例：从 (0,1) 来异或为 `1^10 = 11`，从 (1,0) 来为 `7^10 = 13`，所以 `dp[1][1][11] += dp[0][1][1]`、`dp[1][1][13] += dp[1][0][7]`，两个下标都变了，不能只累加同一个 x。

```python
MOD = 10**9 + 7
m, n = len(grid), len(grid[0])
dp = [[[0] * 16 for _ in range(n)] for _ in range(m)]
dp[0][0][grid[0][0]] = 1
for i in range(m):
    for j in range(n):
        if i == 0 and j == 0:
            continue
        v = grid[i][j]
        for x in range(16):
            s = 0
            if i: s += dp[i-1][j][x]
            if j: s += dp[i][j-1][x]
            if s:
                dp[i][j][x ^ v] = (dp[i][j][x ^ v] + s) % MOD
return dp[m-1][n-1][k]
```

## 复杂度
时间 O(m·n·16)，每格扫 16 个异或值。
空间 O(m·n·16)，可滚动成两行降到 O(n·16)。

## 易错点
- 起点只写 `dp[0][0][grid[0][0]] = 1`，若误写成 `dp[0][0][0] = 1`，示例 1 里 (0,0) 的 2 就丢了，最终答案会少算成 0 而非 3。
- 转移时把 `x ^ v` 写成 `x`（忘记异或当前格），示例 1 中 (1,1) 的 10 不参与运算，`dp[2][2][11]` 会算成别的值；正确是「先取前驱异或值 x，再异或本格 v」。

## 如果面试官追问
问：若 grid 值上限从 16 提到 1024 怎么办？
答：异或值域变成 0..2047，把内层 16 换成 2048，时间 O(m·n·2048)，仍可接受；再大就用字典只存出现过的异或值。
