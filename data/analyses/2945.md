## 一句话思路
把 nums 从右往左贪心切块，用单调栈维护每块的和与长度，栈内和严格递增即得最长非递减段数。

## 怎么做
1. 从右往左扫描，把每个 nums[i] 当作一个独立块 `(和=nums[i], 长度=1)` 压栈。
2. 压栈后若栈顶块的和 ≤ 前一块的和，就合并：把栈顶弹出，累加到前一块的和与长度上。
3. 反复合并直到栈内和严格递增，最后栈的大小就是答案。

以 `nums = [4,3,2,6]` 为例：先压 6；压 2 得栈 `[(2,1),(6,1)]`；压 3 时 3>2 不合并，栈 `[(3,1),(2,1),(6,1)]`；压 4 时 4>3 不合并，栈 `[(4,1),(3,1),(2,1),(6,1)]`。此时 2<3，弹出 2 并入 3 得 `(5,2)`，栈变 `[(4,1),(5,2),(6,1)]`，和 4<5<6 严格递增，答案 3。

```python
stack = []  # (和, 长度)
for x in reversed(nums):
    s, c = x, 1
    while stack and stack[-1][0] <= s:
        ps, pc = stack.pop()
        s += ps
        c += pc
    stack.append((s, c))
return len(stack)
```

关键中间值：合并 `(3,1)` 与 `(2,1)` 后得到 `(5,2)`，正是示例里 `[3,2]→[5]` 的那一步。

## 复杂度
时间 O(n)：每个块最多入栈出栈一次，合并总次数 O(n)。
空间 O(n)：栈最多存 n 个块，每块两个整数。

## 易错点
- 输入 `[5,2,2]`：若只比较相邻原始元素、不做合并，会误判长度 2；正确做法是压 2 后栈 `[(2,1),(2,1)]`，因 2≤2 合并成 `(4,2)`，再压 5 得 `[(5,1),(4,2)]`，5>4 停，答案 1。
- 输入 `[1,2,3,4]`：若把合并条件写成 `<` 而非 `<=`，相等块不合并，遇到 `[2,2]` 这类会多算长度；本题要求非递减，相等必须合并，条件用 `stack[-1][0] <= s`。

## 如果面试官追问
问：要求输出具体的合并方案（每段的起止下标）怎么办？
答：栈里改存 `(和, 长度, 起始下标)`，合并时保留前一块的起始下标，最后反推每段区间即可。
