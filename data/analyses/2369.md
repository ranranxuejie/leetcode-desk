## 一句话思路
用 `dp[i]` 表示 `nums[:i]` 能否有效划分，从末尾回看 2 或 3 个元素转移，因为每个子数组长度只能是 2 或 3。

## 怎么做
1. 定义 `dp` 长度 `n+1`，`dp[0] = True`，其余 `False`，`dp[i]` 表示前 `i` 个元素可划分。
2. 对每个 `i` 从 2 到 `n`，先试长度 2：若 `dp[i-2]` 为真且 `nums[i-1] == nums[i-2]`，置 `dp[i] = True`。
3. 再试长度 3：若 `dp[i-3]` 为真，且「三元素全等」或「`nums[i-3]+1 == nums[i-2]` 且 `nums[i-2]+1 == nums[i-1]`」，置 `dp[i] = True`。
4. 返回 `dp[n]`。

以 `nums = [4,4,4,5,6]` 为例，关键一步在 `i = 5`：`dp[2] = True`（`[4,4]`），检查 `nums[2..4] = [4,5,6]`，`4+1==5` 且 `5+1==6` 成立，于是 `dp[5] = True`，返回 `True`。

```python
n = len(nums)
dp = [False] * (n + 1)
dp[0] = True
for i in range(2, n + 1):
    if dp[i - 2] and nums[i - 1] == nums[i - 2]:
        dp[i] = True
    if i >= 3 and dp[i - 3]:
        a, b, c = nums[i - 3], nums[i - 2], nums[i - 1]
        if (a == b == c) or (a + 1 == b and b + 1 == c):
            dp[i] = True
return dp[n]
```

注意 `dp[i]` 一旦被长度 2 置真，长度 3 的分支仍要执行，但不会改回 `False`，所以两个 `if` 是并列而非 `elif`。

## 复杂度
时间：`O(n)`，`i` 从 2 到 `n`，每个位置常数次比较。
空间：`O(n)`，开了长度 `n+1` 的 `dp` 数组。

## 易错点
- 输入 `[1,1,1,2]` → 若只判长度 2 会漏掉 `[1,1,1]` 这个合法前缀，导致 `dp[3]` 错成 `False`，进而 `dp[4]` 也错；正确做法是长度 2 和长度 3 两个转移都写，且 `i >= 3` 时才碰 `nums[i-3]`。
- 输入 `[4,4,4,5,6]` → 若把递增判断写成 `nums[i-1] - nums[i-2] == 1` 单看一对，会把 `[4,4,5]` 误判为递增；正确做法是同时校验 `a+1==b` 和 `b+1==c` 两个相邻差。

## 如果面试官追问
问：要求输出一种具体划分方案怎么办？
答：把 `dp` 换成记录「从哪个长度转移来」的 `choice[i] ∈ {2,3}`，从 `n` 倒推切分点即可。
