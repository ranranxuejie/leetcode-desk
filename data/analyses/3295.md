## 一句话思路
把 `bannedWords` 塞进 `set`，再遍历 `message` 数命中个数，凑到 2 就提前返回 `True`。

## 怎么做
1. 用 `set(bannedWords)` 建哈希集合，把「查某个词是否违禁」从 O(len) 降到 O(1)。
2. 遍历 `message`，对每个词查集合，命中就 `cnt += 1`。
3. `cnt` 一到 2 立刻 `return True`，不必扫完整个数组。
4. 循环结束还没到 2，返回 `False`。

拿示例 1 走一遍：`banned = {"world", "hello"}`。遍历到 `"hello"` 时命中，`cnt = 1`；遍历到 `"world"` 时命中，`cnt = 2`，此时直接返回 `True`，`"leetcode"` 根本没被检查。

```python
banned = set(bannedWords)
cnt = 0
for w in message:
    if w in banned:
        cnt += 1
        if cnt >= 2:
            return True
return False
```

关键点：`cnt >= 2` 而不是 `== 2`，虽然本题命中后立刻返回、`cnt` 不会超过 2，但写成 `>=` 更稳。另外 `message` 里同一个词出现两次也算两次命中，比如 `message = ["spam","spam"]`、`bannedWords = ["spam"]` 应返回 `True`——所以不能先把 `message` 去重再数。

## 复杂度
时间 O(len(message) + len(bannedWords))，建集合和遍历各扫一遍，单词比较按长度 ≤15 视为常数。
空间 O(len(bannedWords))，额外开的就是这个哈希集合。

## 易错点
- `message = ["spam","spam"]`、`bannedWords = ["spam"]` → 若先把 `message` 转成 `set` 去重，`cnt` 只会是 1，错返 `False` → 正确做法是直接遍历原 `message`，重复词各计一次。
- `message = ["a","b"]`、`bannedWords = ["a","b"]` 且两词都在前两位 → 若写成「先数完再判断」也能对，但若把判断条件写成 `cnt == 2` 放在循环外、又漏了提前返回，遇到 `message` 长度 10^5 全命中时会白扫 10^5 次 → 正确做法是命中即 `cnt += 1` 后立刻判 `>= 2` 返回，别攒到最后。

## 如果面试官追问
问：如果要求返回具体是哪两个词命中的下标怎么办？
答：把 `cnt` 换成记录命中下标的列表，凑满 2 个就返回这两个下标，逻辑不变。
