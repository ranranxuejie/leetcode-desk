## 一句话思路
右端点 r 固定时，好子数组的左端点构成后缀区间，用滑动窗口维护「对数」并累加 `l` 即可。

## 怎么做
1. 设 `cnt[x]` 为窗口内 x 的出现次数，`pairs` 为窗口内相等下标对数；把 x 加入窗口时，新增的对数正好是 `cnt[x]`（x 与之前每个 x 各配一对）。
2. 右指针 r 从 0 到 n-1 逐个加入 `nums[r]`，先 `pairs += cnt[x]` 再 `cnt[x] += 1`。
3. 当 `pairs >= k` 时，不断把左端点 l 右移（移出 y 时 `cnt[y] -= 1; pairs -= cnt[y]`），直到 `pairs < k`；此时对当前 r，合法的 l 有 `0..l-1` 共 `l` 个，累加 `ans += l`。
4. 返回 `ans`（Python 整数不溢出，答案规模最大约 n²/2 ≈ 5×10⁹，用 `int` 即可）。

以 `nums = [3,1,4,3,2,2,4], k = 2` 为例：r=5 加入第二个 2 时 `cnt[2]` 从 1 变 2，`pairs` 从 1 变 2 达到 k；左移 l 到 1（移出 3，`cnt[3]` 2→1，`pairs` 减 1 变 1 < 2），此时 `ans += 1`。r=6 加入 4 使 `pairs` 回到 2，左移到 l=2 后 `ans += 2`，累计 4。

```python
cnt = {}
pairs = l = ans = 0
for x in nums:
    pairs += cnt.get(x, 0)
    cnt[x] = cnt.get(x, 0) + 1
    while pairs >= k:
        y = nums[l]
        cnt[y] -= 1
        pairs -= cnt[y]
        l += 1
    ans += l
return ans
```

## 复杂度
时间 O(n)：每个元素最多被 l、r 各扫一次，哈希表操作均摊 O(1)。
空间 O(d)：d 为不同取值个数，最坏 O(n)。

## 易错点
- `nums = [1,1,1,1,1], k = 10`：若在 `pairs >= k` 时只加 1 而不是加 `l`，会漏掉左端点 0 以外的合法起点；正确做法是累加当前 l（左移后 `pairs < k`，`0..l-1` 全部合法）。
- 移出左端点时顺序写反：必须先 `cnt[y] -= 1` 再 `pairs -= cnt[y]`，因为移出后 y 与剩余 y 的配对数正是 `cnt[y]-1`；若先减 pairs 再减 cnt，`[3,1,4,3,2,2,4]` 在 r=5 会把 pairs 算成 1，答案少 1。

## 如果面试官追问
若 k 很大导致答案接近 n²/2，返回值类型怎么定？答：Python 用 `int` 天然支持，Java/C++ 需 `long`，因为最大约 5×10⁹ 超过 32 位。
