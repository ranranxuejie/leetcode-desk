## 一句话思路
按「剩余步数 × 格子」做 DP，把走出边界的那一步直接累加进答案，而不是记录界外状态。

## 怎么做
1. 定义 `dp[r][c]` 为「当前剩余 k 步时，从 (r,c) 出发能出界的路径数」，k 从 0 递推到 maxMove。
2. 边界：k=0 时任何格子都走不出去，`dp` 全 0。
3. 转移：`dp_new[r][c] = Σ 四个方向`，越界的方向贡献 1（这一步就出去了），界内方向贡献 `dp[邻居]`。
4. 答案取 `dp[startRow][startColumn]`（k=maxMove 那一层）。

以示例 1（m=2,n=2,maxMove=2,起点(0,0)）为例：k=1 时 `dp[0][0] = 1(上出界)+1(左出界)+dp[0][1]+dp[1][0] = 2`；k=2 时 `dp[0][0] = 2 + dp_k1[0][1] + dp_k1[1][0]`，其中 `dp_k1[0][1]=2`、`dp_k1[1][0]=2`，合计 6，与输出一致。

```python
MOD = 10**9 + 7
dp = [[0] * n for _ in range(m)]
for _ in range(maxMove):
    ndp = [[0] * n for _ in range(m)]
    for r in range(m):
        for c in range(n):
            s = 0
            for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n:
                    s += dp[nr][nc]
                else:
                    s += 1
            ndp[r][c] = s % MOD
    dp = ndp
return dp[startRow][startColumn]
```

## 复杂度
时间：O(maxMove · m · n)，每个格子每轮扫 4 个方向，常数 4。
空间：O(m · n)，只开 `dp` 和 `ndp` 两张表，滚动复用。

## 易错点
- `maxMove = 0` 且起点在界内 → 若把「越界贡献 1」写成无条件加，会错成 4 或非 0；正确做法是循环 `range(maxMove)` 一次都不进，直接返回初始 `dp[startRow][startColumn] = 0`。
- 每轮转移必须用上一轮的 `dp` 读、写进 `ndp`，若原地改 `dp[r][c]`，同一轮内 `dp[0][1]` 已被更新，示例 1 的 k=2 层会读到污染值，结果偏大；正确做法是每轮新建 `ndp` 再整体替换。

## 如果面试官追问
若 maxMove 放大到 10^9 怎么办？答：这是线性递推，可用矩阵快速幂把 O(maxMove·mn) 降到 O((mn)^3 log maxMove)，但 mn=2500 时不可行，实际应说明规模约束。
