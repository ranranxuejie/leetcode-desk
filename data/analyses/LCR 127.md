## 一句话思路
用滚动变量做斐波那契递推：跳到第 i 格的方案数等于前两格方案数之和，因为最后一步只能跨 1 格或 2 格。

## 怎么做
1. 设 `a = 1` 表示跳到第 0 格的方案数（原地不动算 1 种），`b = 1` 表示第 1 格。
2. 从 `i = 2` 循环到 `num`，每轮算 `c = (a + b) % 1000000007`，再令 `a, b = b, c`。
3. 循环结束返回 `b`（即第 `num` 格的方案数）。

以 `num = 5` 为例，中间值依次是：`i=2` 时 `c = 1+1 = 2`，`a,b = 1,2`；`i=3` 时 `c = 1+2 = 3`，`a,b = 2,3`；`i=4` 时 `c = 2+3 = 5`，`a,b = 3,5`；`i=5` 时 `c = 3+5 = 8`，返回 `b = 8`，与示例一致。

```python
MOD = 1000000007
a, b = 1, 1
for i in range(2, num + 1):
    a, b = b, (a + b) % MOD
return b
```

注意 `num = 0` 时循环不进入，直接返回 `b = 1`；`num = 1` 同理返回 1，这两个边界不用单独写 `if`。

## 复杂度
时间：O(num)，循环从 2 走到 num，每轮常数次加法取模。
空间：O(1)，只开了 `a`、`b`、`c` 三个变量，没有数组。

## 易错点
- 输入 `num = 0` → 若把 `a` 初始化成 0 或直接返回 `a`，会错成 0 → 正确做法是 `a = b = 1` 并返回 `b`，让 0 和 1 都落到 1。
- 输入 `num = 100` → 若忘了每轮取模，`b` 会涨到约 5.7e20，虽然 Python 不溢出但偏离题意 → 正确做法是每轮 `(a + b) % 1000000007`，而不是只在最后取一次模。

## 如果面试官追问
问：如果每次可以跳 1、2、3 格呢？
答：递推改成 `c = (a + b + d) % MOD`，用三个滚动变量保留前三格方案数，时间仍是 O(num)、空间 O(1)。
