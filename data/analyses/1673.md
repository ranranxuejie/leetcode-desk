## 一句话思路
用单调栈维护递增序列，每遇到更小的 `nums[i]` 就弹出栈顶，前提是剩余元素够凑满 k 个。

## 怎么做
1. 遍历 `nums`，设 `drop = len(nums) - k` 为最多可删除的元素数。
2. 当栈非空、栈顶 > `nums[i]`、且 `drop > 0` 时，弹出栈顶并 `drop -= 1`。
3. 将 `nums[i]` 压栈。
4. 遍历结束后取栈的前 k 个元素。

以 `nums = [2,4,3,3,5,4,9,6], k = 4` 为例，`drop = 4`。处理到 `3`（下标 2）时，栈为 `[2,4]`，弹出 `4`，`drop` 变 3，栈变 `[2,3]`；处理到下标 5 的 `4` 时，栈为 `[2,3,3,5]`，弹出 `5`，`drop` 变 2，压入 `4` 得 `[2,3,3,4]`。后续 `9`、`6` 因 `drop` 已用完不再弹出，最终取前 4 个即 `[2,3,3,4]`。

```python
stack = []
drop = len(nums) - k
for x in nums:
    while stack and drop > 0 and stack[-1] > x:
        stack.pop()
        drop -= 1
    stack.append(x)
return stack[:k]
```

关键在 `drop` 的语义：它表示「还能删几个」，而不是「栈里还能留几个」。每次弹出消耗一次删除额度，保证最终至少剩 k 个元素。

## 复杂度
时间 O(n)：每个元素最多入栈出栈各一次，`drop` 递减保证总弹出次数 ≤ n。
空间 O(n)：栈最多存 n 个元素，返回值另占 O(k)。

## 易错点
1. 输入 `nums = [3,5,2,6], k = 2`，若忘记 `drop` 限制，处理 `2` 时会连续弹出 `5` 和 `3`，栈变 `[2]` 只剩 1 个元素，凑不满 k。正确做法是 `drop = 4 - 2 = 2`，弹出 `5`、`3` 后 `drop` 归零，`2` 压栈得 `[2,6]`。
2. 输入 `nums = [1,2,3,4], k = 2`，若只写 `stack[-1] > x` 而不检查 `drop`，虽然不会误弹（因为递增），但若输入是 `[4,3,2,1], k = 2`，会一路弹到栈空再压，最终栈为 `[1]`，取 `stack[:2]` 只得 `[1]`。正确做法是 `drop` 耗尽后停止弹出，保留 `[3,2,1]` 的前 2 个 `[3,2]`——但实际最优是 `[2,1]`，需确认 `drop = 2` 时弹出 `4`、`3` 后栈为 `[2,1]`，取前 2 个正确。

## 如果面试官追问
若 k 等于 len(nums) 怎么办？答：`drop = 0`，while 条件直接短路，原样返回，无需特判。
