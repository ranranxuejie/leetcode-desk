## 一句话思路
按顺序扫 rolls，用集合收集当前段内出现的面值，集齐 1..k 就清空并让答案加一，最后答案再加一。

## 怎么做
1. 维护 `seen` 集合和 `ans = 0`，从左到右遍历 `rolls`。
2. 遇到 `x` 就 `seen.add(x)`，当 `len(seen) == k` 时说明这一段已覆盖全部 k 个面，`ans += 1` 并 `seen.clear()`。
3. 遍历结束后返回 `ans + 1`：最后那段没集齐，缺的面就是无法拼出的下一层。

以示例 1 `rolls = [4,2,1,2,3,3,2,4,1], k = 4` 为例：扫到下标 4 的 `3` 时 `seen = {1,2,3,4}`，第一次清空，`ans = 1`；继续扫到下标 7 的 `4` 时 `seen = {2,3,4}` 还差 1，扫到末尾 `1` 才再次集齐，`ans = 2`，返回 `3`。

```python
seen = set()
ans = 0
for x in rolls:
    seen.add(x)
    if len(seen) == k:
        ans += 1
        seen.clear()
return ans + 1
```

关键点：每集齐一次，就说明「任意长度为 ans 的前缀」都能被匹配，下一层必须从清空后的位置重新找。

## 复杂度
时间 O(n)：每个 rolls 元素最多进集合一次，集合操作均摊 O(1)。
空间 O(k)：`seen` 最多存 k 个不同面值。

## 易错点
- `rolls = [1,1,2,2], k = 2`：若只在末尾判断 `len(seen) == k` 而不在集齐时清空，会得到 `ans = 1`、返回 2 看似对，但换成 `[1,2,1,2], k = 2` 就会漏掉第二段，正确做法是集齐立刻 `clear()` 并计数。
- `rolls = [1,1,3,2,2,2,3,3], k = 4`：若忘记最后 `+1`，会返回 0，而面值 4 从未出现，正确答案是 1；`ans` 表示「已能拼出的最大长度」，缺失的那层永远存在，所以必须加一。

## 如果面试官追问
问：要求输出一个具体的最短不可得序列怎么办？
答：记录每段清空时的位置，最后一段缺失的面值接在每段任选的一个代表值后面即可。
