## 一句话思路
双指针逐段扫描两个字符串，边扫边把每段修订号转成整数比较，缺失段按 0 处理。

## 怎么做
1. 两个指针 `i`、`j` 分别指向 `version1`、`version2` 开头，循环条件是 `i < len(version1) or j < len(version2)`。
2. 每轮用内层 while 从 `i` 起读到 `'.'` 或串尾，把这段数字累加成 `num1`；`j` 同理得 `num2`。
3. 比较 `num1` 与 `num2`，不等就立即返回 `1` 或 `-1`；相等则两指针各跳过 `'.'` 继续。
4. 循环正常结束说明所有段都相等，返回 `0`。

以 `version1 = "1.2"`、`version2 = "1.10"` 为例：第一轮 `num1 = num2 = 1`，两指针都移到 `'.'` 后一位；第二轮 `i` 读到 `'2'` 得 `num1 = 2`，`j` 读到 `"10"` 得 `num2 = 10`，`2 < 10` 直接返回 `-1`。

```python
i = j = 0
n1, n2 = len(version1), len(version2)
while i < n1 or j < n2:
    num1 = num2 = 0
    while i < n1 and version1[i] != '.':
        num1 = num1 * 10 + int(version1[i]); i += 1
    while j < n2 and version2[j] != '.':
        num2 = num2 * 10 + int(version2[j]); j += 1
    if num1 != num2:
        return 1 if num1 > num2 else -1
    i += 1; j += 1
return 0
```

关键点：内层 while 结束时 `i` 停在 `'.'` 上，所以外层末尾的 `i += 1` 是跳过点号，不是跳过数字；`j` 越界时内层不执行，`num2` 保持 0，正好实现「缺失修订号视为 0」。

## 复杂度
时间 O(n + m)，n、m 为两串长度，每个字符只被读一次。
空间 O(1)，只用了 `i`、`j`、`num1`、`num2` 几个变量。

## 易错点
1. `version1 = "1.0"`、`version2 = "1.0.0.0"` → 若用 `split('.')` 后按 `zip` 遍历，会因长度不等而漏比尾部，错判成 0 或抛异常 → 正确做法是循环条件用 `or`，让短串越界后 `num` 自然为 0。
2. `version1 = "1.01"`、`version2 = "1.001"` → 若按字符串逐位比较 `"01"` 与 `"001"`，会因长度不同错判 → 必须累加成整数 `1 == 1`，前导零在 `num = num * 10 + digit` 里自动消掉。

## 如果面试官追问
问：修订号超过 32 位怎么办？答：Python 整数无溢出，直接累加即可；若换 C++ 需改用字符串去前导零后先比长度再比字典序。
