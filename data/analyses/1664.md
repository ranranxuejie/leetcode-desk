## 一句话思路
删掉 `nums[i]` 后，原下标 `i` 之后的元素奇偶性全部翻转，用前后缀奇偶和直接算出新数组的两侧和。

## 怎么做
1. 预处理 `pre_odd[i]`、`pre_even[i]` 表示 `nums[0..i-1]` 中奇数位、偶数位元素之和。
2. 遍历每个删除下标 `i`，新数组的偶数位和 = `pre_even[i] + (pre_odd[n] - pre_odd[i+1])`，奇数位和 = `pre_odd[i] + (pre_even[n] - pre_even[i+1])`。
3. 两者相等则计数加一。

以 `nums = [2,1,6,4]` 为例，删 `i=1`：`pre_even[1]=2`，`pre_odd[1]=0`，`pre_odd[4]-pre_odd[2]=6`，`pre_even[4]-pre_even[2]=4`。新偶数位和 `2+4=6`，奇数位和 `0+6=6`，相等，计数 1。

```python
n = len(nums)
pre_odd = [0] * (n + 1)
pre_even = [0] * (n + 1)
for i, x in enumerate(nums):
    pre_odd[i+1] = pre_odd[i] + (x if i % 2 else 0)
    pre_even[i+1] = pre_even[i] + (0 if i % 2 else x)
ans = 0
for i in range(n):
    even = pre_even[i] + (pre_odd[n] - pre_odd[i+1])
    odd = pre_odd[i] + (pre_even[n] - pre_even[i+1])
    if even == odd:
        ans += 1
```

## 复杂度
时间：O(n)，一次预处理加一次遍历，每个下标 O(1) 计算。
空间：O(n)，额外开了两个长度 n+1 的前缀和数组。

## 易错点
- `nums = [1,1,1]` 这类全等数组 → 若忘记删除后下标翻转，会把 `i` 之后元素仍按原奇偶累加，得到 0 而非 3 → 正确做法是 `i` 之后的奇数位和偶数位互换后再相加。
- `nums = [2,1,6,4]` 删 `i=0` → 若前缀区间写成 `pre_even[i+1]` 把被删元素也算进去，偶数位和变成 `2+4=6` 误判平衡 → 正确做法是前缀只取 `[0, i-1]`，即 `pre_even[i]`，后缀从 `i+1` 开始。

## 如果面试官追问
要求输出所有可行下标而非方案数？答：把 `ans += 1` 换成 `res.append(i)`，其余逻辑不变，仍是 O(n)。
