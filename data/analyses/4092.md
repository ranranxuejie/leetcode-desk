## 一句话思路
用 `bin(x).count('1')` 直接数置位数，再按 `s1` 与 `s2` 的大小关系选乘法或整除。

## 怎么做
1. 分别算出 `s1 = bin(a).count('1')` 和 `s2 = bin(b).count('1')`。
2. 判断 `s1 >= s2`，成立就返回 `s1 * s2`。
3. 否则返回 `s2 // s1`，注意用整除而非真除法。

以示例 2 的 `a = 5, b = 15` 为例：`bin(5)` 是 `'0b101'`，`count('1')` 得 `s1 = 2`；`bin(15)` 是 `'0b1111'`，得 `s2 = 4`。此时 `s1 < s2`，走除法分支，`4 // 2 = 2`。

```python
s1 = bin(a).count('1')
s2 = bin(b).count('1')
if s1 >= s2:
    return s1 * s2
return s2 // s1
```

关键点：`s1 >= s2` 这个条件把相等的情况归到乘法，和题面一致；除法分支里 `s1` 一定大于 0（`a >= 1` 保证至少一位是 1），不会除零。

## 复杂度
时间：O(log a + log b)，`bin` 遍历两个数的二进制位。
空间：O(log a + log b)，`bin` 生成的字符串长度。

## 易错点
- 输入 `a = 5, b = 15` → 若写成 `s2 / s1` 得到浮点 `2.0`，返回类型不符 → 必须用 `//` 整除。
- 输入 `a = 10, b = 12`（`s1 == s2 == 2`）→ 若把条件写成 `s1 > s2` 才走乘法，会误入除法分支得 `2 // 2 = 1` → 条件必须是 `>=`，相等时得 `2 * 2 = 4`。

## 如果面试官追问
问：若 `a, b` 上限提到 `10**18`，还能这样写吗？
答：能，`bin` 只产生约 60 位，仍是 O(log n)，Python 大整数无溢出问题。
