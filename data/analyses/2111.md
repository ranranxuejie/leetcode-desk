## 一句话思路
按 `i % k` 把数组切成 k 条链，每条链内求最长非递减子序列，答案 = n − 各链 LIS 长度之和。

## 怎么做
1. 对 `r in range(k)`，取出子序列 `arr[r], arr[r+k], arr[r+2k], ...`，链内元素必须非递减。
2. 每条链只需求「最长非递减子序列」，保留的元素不动，其余改值，改动数 = 链长 − LIS 长度。
3. 用 `bisect_right` 维护 tails 数组（非递减用 right，不是 left）。
4. 累加所有链的 LIS 长度，返回 `len(arr) - total`。

以 `arr = [4,1,5,2,6,2], k = 3` 为例：链 0 是 `[4,2]`，LIS=1；链 1 是 `[1,6]`，LIS=2；链 2 是 `[5,2]`，LIS=1。total=4，答案 6−4=2，与示例一致。

```python
from bisect import bisect_right

def kIncreasing(arr, k):
    total = 0
    for r in range(k):
        tails = []
        for i in range(r, len(arr), k):
            x = arr[i]
            p = bisect_right(tails, x)
            if p == len(tails):
                tails.append(x)
            else:
                tails[p] = x
        total += len(tails)
    return len(arr) - total
```

关键点：`bisect_right` 让相等元素可以接在后面，因为链内允许 `arr[i-k] <= arr[i]`。

## 复杂度
时间：每条链 O(m log m)，m ≈ n/k，总计 O(n log(n/k))。
空间：tails 最多 O(n/k)，各链复用，额外 O(n/k)。

## 易错点
- 用 `bisect_left` 代替 `bisect_right`：输入 `arr=[1,1], k=1` 时会把第二个 1 替换掉 tails[0]，LIS 算成 1，答案错成 1；正确是 0，因为非递减允许相等。
- 把整条数组直接求 LIS 而不分链：`arr=[4,1,5,2,6,2], k=3` 会得到全局 LIS=3，答案 3，但正确是 2；必须按 `i % k` 分组，链间互不影响。

## 如果面试官追问
若要求输出具体修改方案？答：在每条链 LIS 回溯时记录保留下标，其余位置填前一个保留值（或 1），保证非递减即可。
