## 一句话思路
用滑动窗口维护窗口内所有元素的按位或 `mask`，新元素与 `mask` 与为 0 才无冲突，否则左指针收缩。

## 怎么做
1. 初始化 `left = 0`、`mask = 0`、`ans = 0`，`mask` 表示窗口内所有元素的按位或。
2. 右指针 `right` 遍历 `nums`，当 `nums[right] & mask != 0` 时，说明窗口内已有元素与它共享某一位，必须收缩。
3. 收缩时执行 `mask ^= nums[left]` 并 `left += 1`，直到冲突消失；因为窗口内各元素两两与为 0，它们的置位互不重叠，所以异或等价于「移除该元素的位」。
4. 冲突消除后 `mask |= nums[right]`，更新 `ans = max(ans, right - left + 1)`。

以 `nums = [1,3,8,48,10]` 为例：处理到 `48` 时 `mask = 1|3|8 = 11`，`48 & 11 = 0` 无冲突，窗口扩为 `[3,8,48]`，长度 3；处理 `10` 时 `mask = 59`，`10 & 59 = 10 != 0`，收缩掉 `3`（`mask` 变 `56`）仍冲突，再收缩掉 `8`（`mask` 变 `48`），`10 & 48 = 0`，窗口为 `[48,10]`，`ans` 保持 3。

```python
left = mask = ans = 0
for right, x in enumerate(nums):
    while x & mask:
        mask ^= nums[left]
        left += 1
    mask |= x
    ans = max(ans, right - left + 1)
return ans
```

## 复杂度
时间：O(n)，`right` 和 `left` 各最多走 n 步，每次位运算是 O(1)。
空间：O(1)，只开了 `left`、`mask`、`ans` 三个变量。

## 易错点
- 收缩时写成 `mask &= ~nums[left]`：当窗口内某位被多个元素共享时（正常不会，但若前面逻辑已错）会误清其他元素的位；本题因两两与为 0，位互不重叠，用 `mask ^= nums[left]` 才正确，且必须用异或而非与取反。
- 判断条件写成 `x & mask == 0` 才进循环，或把 `while` 写成 `if`：`[3,1,5,11,13]` 中处理 `11` 时 `mask = 3|1|5 = 7`，`11 & 7 = 3`，收缩一次后 `mask` 变 `6`，`11 & 6 = 2` 仍冲突，必须继续收缩到 `mask = 0`，用 `if` 会漏掉第二次收缩，得到错误窗口。

## 如果面试官追问
若要求返回具体子数组而非长度？答：在更新 `ans` 时同步记录 `best_left = left` 和 `best_right = right`，最后切片 `nums[best_left:best_right+1]` 即可。
