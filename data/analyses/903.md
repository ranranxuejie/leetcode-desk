## 一句话思路
用 `dp[i][j]` 记前 i+1 个数、末位排第 j 小的方案数，靠前缀和把 O(n³) 压到 O(n²)。

## 怎么做
1. 状态定义：`dp[j]` 表示当前长度下，末位元素在已用集合中排第 `j` 小（0-indexed）的方案数，初始 `dp = [1]`。
2. 转移：`s[i-1] == 'I'` 时新末位要更大，`new[j] = sum(dp[0..j-1])`；`'D'` 时 `new[j] = sum(dp[j..])`。
3. 用前缀和/后缀和一次扫出所有 `new[j]`，每轮对 `10**9 + 7` 取模。
4. 答案是把最后一轮 `dp` 全部加起来。

以 `s = "DID"` 为例，长度从 1 长到 4。第一轮 `'D'`：`dp=[1]` → `new=[0,1]`（末位排第 0 小时没有更小的可接）。第二轮 `'I'`：`dp=[0,1]` → 前缀和 `new=[0,0,1]`。第三轮 `'D'`：`dp=[0,0,1]` → 后缀和 `new=[1,1,1,0]`，求和得 5，与示例一致。

```python
MOD = 10**9 + 7
dp = [1]
for ch in s:
    m = len(dp) + 1
    new = [0] * m
    if ch == 'I':
        run = 0
        for j in range(1, m):
            run = (run + dp[j-1]) % MOD
            new[j] = run
    else:
        run = 0
        for j in range(m-2, -1, -1):
            run = (run + dp[j]) % MOD
            new[j] = run
    dp = new
return sum(dp) % MOD
```

## 复杂度
时间：O(n²)，n = len(s)，每轮扫 O(n) 共 n 轮。
空间：O(n)，只保留 `dp` 和 `new` 两个长度 n+1 的数组。

## 易错点
- `s = "I"` 时若把 `new[0]` 也累加进前缀和 → 得到 2 而非 1 → 正确做法是 `'I'` 分支从 `j=1` 起累加，`new[0]` 恒为 0。
- `s = "D"` 时若后缀和从 `j=m-1` 起算 → `new[m-1]` 被错误赋非零 → 正确做法是 `'D'` 分支从 `j=m-2` 倒着扫，末位最大者无更大元素可接。

## 如果面试官追问
问：n 放大到 10⁵ 还能做吗？
答：不能，O(n²) 是本题标准解；更大规模需生成函数/组合计数，超出面试范围。
