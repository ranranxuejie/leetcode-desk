## 一句话思路
把「进入镜子后转向」折叠成一次跳跃，用 dp[i][j] 记录到达每个格子的路径数，按行列顺序递推。

## 怎么做
1. 定义 dp[i][j] 为到达 (i,j) 的路径数，dp[0][0]=1，其余从上方和左方转移。
2. 从 (i,j) 向右走：若 grid[i][j+1]==0 则到 (i,j+1)；若为 1 则被反射到 (i+1,j+1)，越界则丢弃。
3. 从 (i,j) 向下走：若 grid[i+1][j]==0 则到 (i+1,j)；若为 1 则反射到 (i+1,j+1)，越界则丢弃。
4. 注意反射落点 (i+1,j+1) 若本身是镜子，会立即再次反射，需继续按方向跳，直到落在空格或越界。

以示例 1 的 grid=[[0,1,0],[0,0,1],[1,0,0]] 为例：从 (0,0) 向右进入 (0,1) 是镜子，反射到 (1,1)，dp[1][1] 累加 1；从 (0,0) 向下到 (1,0) 是空格，dp[1][0]=1。最终 dp[2][2]=5。

```python
MOD = 10**9 + 7
m, n = len(grid), len(grid[0])
dp = [[0]*n for _ in range(m)]
dp[0][0] = 1
for i in range(m):
    for j in range(n):
        if dp[i][j] == 0:
            continue
        # 向右
        ni, nj = i, j+1
        while ni < m and nj < n and grid[ni][nj] == 1:
            ni, nj = ni+1, nj+1
        if ni < m and nj < n:
            dp[ni][nj] = (dp[ni][nj] + dp[i][j]) % MOD
        # 向下
        ni, nj = i+1, j
        while ni < m and nj < n and grid[ni][nj] == 1:
            ni, nj = ni+1, nj+1
        if ni < m and nj < n:
            dp[ni][nj] = (dp[ni][nj] + dp[i][j]) % MOD
```

## 复杂度
时间：O(m·n·(m+n))，最坏每次反射沿对角线走到底。
空间：O(m·n)，dp 表本身。

## 易错点
1. 反射落点仍是镜子时忘记继续反射。示例 3 中 (0,0) 向右进 (0,1) 镜子反射到 (1,1)，(1,1) 也是镜子，需再反射到 (1,2)；若只跳一次会漏掉这条唯一有效路径，输出 0 而非 1。
2. 反射越界判断用错边界。示例 3 中 (1,0) 向下进 (1,1) 镜子反射到 (2,1)，m=2 时 2>=m 越界，该路径应丢弃；若只判 nj<n 会错误计入。

## 如果面试官追问
问：若 m,n 扩大到 5000 怎么优化？答：预处理每个格子沿右/下方向反射的最终落点，用记忆化把每次跳跃降到 O(1)，总时间 O(m·n)。
