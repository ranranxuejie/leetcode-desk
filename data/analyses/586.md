## 一句话思路
按 `customer_number` 分组计数，取计数最大的那一组；题目保证唯一，所以直接排序取第一行即可。

## 怎么做
1. 用 `GROUP BY customer_number` 把同一客户的订单折叠成一行，`COUNT(*)` 得到该客户的订单数。
2. 按订单数降序排，取第一行——因为题面保证「恰好有一个客户订单最多」，不存在并列。
3. 只 `SELECT customer_number`，输出列名必须与示例一致。

拿官方示例走一遍：分组后得到 `{1: 1, 2: 1, 3: 2}`，`COUNT(*)` 分别是 1、1、2；降序排序后第一行是 `(3, 2)`，取 `customer_number` 得 `3`。

```python
# 思路等价写法（pandas 版，便于本地验证）
import pandas as pd

def largest_orders(orders: pd.DataFrame) -> pd.DataFrame:
    cnt = orders.groupby("customer_number").size().reset_index(name="cnt")
    cnt = cnt.sort_values("cnt", ascending=False)
    return cnt[["customer_number"]].head(1)
```

SQL 版关键三行：

```python
sql = """
SELECT customer_number
FROM Orders
GROUP BY customer_number
ORDER BY COUNT(*) DESC
LIMIT 1
"""
```

注意 `ORDER BY COUNT(*) DESC` 里的聚合函数是合法的，不需要额外子查询包一层。

## 复杂度
时间：分组 + 排序，O(n + k log k)，n 是 Orders 行数，k 是不同客户数。
空间：分组哈希表存 k 个计数，额外 O(k)。

## 易错点
- 输入里出现并列最多（如 `{1: 2, 2: 2}`）→ 用 `LIMIT 1` 会随机丢一个客户 → 本题保证唯一所以可接受，但若按进阶要求做，应改成 `WHERE cnt = (SELECT MAX(cnt) ...)` 或窗口函数 `RANK()`，别直接 `LIMIT 1`。
- 表里只有一行（如 `order_number=1, customer_number=7`）→ 若误写成 `HAVING COUNT(*) > 1` 会返回空集 → 正确做法是不加任何 `HAVING` 阈值，最大值就是 1，照样返回 `7`。

## 如果面试官追问
问：进阶要求返回所有并列最多的客户，怎么改？
答：把计数放进子查询或 CTE，再 `WHERE cnt = (SELECT MAX(cnt) FROM t)`，或 `RANK() OVER (ORDER BY cnt DESC) = 1` 后过滤。
