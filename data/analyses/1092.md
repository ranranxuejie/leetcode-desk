## 一句话思路
先求最长公共子序列（LCS），再把两串中不属于 LCS 的字符按原顺序插入，得到最短公共超序列。

## 怎么做
1. 建 `dp[i][j]` 表示 `str1[:i]` 与 `str2[:j]` 的 LCS 长度，转移：字符相等取 `dp[i-1][j-1]+1`，否则取 `max(dp[i-1][j], dp[i][j-1])`。
2. 从 `(m, n)` 反向回溯：相等则把该字符压栈并同时左移两指针；否则朝 `dp` 值更大的方向移动一格，把被跳过的字符压栈。
3. 回溯到边界后，把 `str1`、`str2` 剩余前缀压栈，最后整体反转即答案。

以 `str1="abac"`、`str2="cab"` 为例，LCS 是 `"ab"`，长度 2。回溯时 `i=4,j=3` 处 `str1[3]='c'` 与 `str2[2]='b'` 不等，`dp[3][3]=2 > dp[4][2]=1`，故把 `'c'` 压栈并 `i-=1`；继续走到 `i=2,j=2` 时 `'a'=='a'`，压入 `'a'` 并双指针左移。最终栈内逆序拼出 `"cabac"`。

```python
m, n = len(str1), len(str2)
dp = [[0] * (n + 1) for _ in range(m + 1)]
for i in range(1, m + 1):
    for j in range(1, n + 1):
        if str1[i - 1] == str2[j - 1]:
            dp[i][j] = dp[i - 1][j - 1] + 1
        else:
            dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
i, j, out = m, n, []
while i > 0 and j > 0:
    if str1[i - 1] == str2[j - 1]:
        out.append(str1[i - 1]); i -= 1; j -= 1
    elif dp[i - 1][j] >= dp[i][j - 1]:
        out.append(str1[i - 1]); i -= 1
    else:
        out.append(str2[j - 1]); j -= 1
out.append(str1[:i][::-1]); out.append(str2[:j][::-1])
return "".join(reversed(out))
```

## 复杂度
时间 O(m·n)：填 `dp` 表与回溯各扫一遍，`m=len(str1)`、`n=len(str2)`。
空间 O(m·n)：`dp` 二维表占满，`out` 栈额外 O(m+n)。

## 易错点
- 输入 `str1="a"`、`str2="a"`：若回溯时相等分支只压一次却漏了双指针同时左移，会重复输出 `"aa"`；正确做法是相等时 `i-=1; j-=1` 一起走。
- 输入 `str1="ab"`、`str2="ba"`：若回溯结束只补 `str1[:i]` 忘了 `str2[:j]`，会丢掉 `"b"` 或 `"a"` 导致某串不是子序列；正确做法是两段剩余前缀都反转后压栈。

## 如果面试官追问
问：只要求输出长度怎么办？答：直接返回 `m + n - dp[m][n]`，省掉回溯和栈，空间还能压到一维。
