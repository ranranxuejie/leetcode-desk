## 一句话思路
把等式建成带权无向图，边权是商，查询即求两点路径上边权连乘，DFS 搜不到返回 -1.0。

## 怎么做
1. 遍历 `equations`，建邻接表 `graph[A].append((B, v))` 和 `graph[B].append((A, 1/v))`，两个方向都要存。
2. 对每个查询 `[C, D]`，若 `C` 或 `D` 不在 `graph` 里直接给 `-1.0`（`a/e`、`x/x` 都走这条）。
3. 否则从 `C` 出发 DFS，携带累乘值 `prod`，找到 `D` 就返回 `prod`，回溯时用 `visited` 防环。
4. 以示例 1 为例：`graph = {a:[(b,2.0)], b:[(a,0.5),(c,3.0)], c:[(b,1/3)]}`，查 `a/c` 时 DFS 走 `a→b` 得 `prod=2.0`，再走 `b→c` 得 `prod=2.0*3.0=6.0`，命中 `c` 返回 6.0。

```python
def dfs(cur, dst, prod):
    if cur == dst:
        return prod
    visited.add(cur)
    for nxt, w in graph[cur]:
        if nxt not in visited:
            r = dfs(nxt, dst, prod * w)
            if r != -1.0:
                return r
    return -1.0

for c, d in queries:
    if c not in graph or d not in graph:
        ans.append(-1.0)
    else:
        visited = set()
        ans.append(dfs(c, d, 1.0))
```

## 复杂度
时间：建图 O(E)，每个查询 DFS 最坏 O(V+E)，共 O(Q·(V+E))，V 是不同变量数。
空间：邻接表 O(V+E)，DFS 递归栈与 `visited` 各 O(V)。

## 易错点
- 查询 `["a","a"]` 且 `a` 在图中 → 若先判 `c == d` 再判存在性会漏掉「`a` 不在图里」的情况；正确做法是先查 `c not in graph`，再让 DFS 在 `cur == dst` 时返回初始 `prod=1.0`，这样 `a/a=1.0`、`x/x=-1.0` 都对。
- 只存单向边 `graph[A].append((B, v))` → 查 `["b","a"]` 时 DFS 从 `b` 出发找不到 `a`，返回 -1.0；必须同时存 `(A, 1/v)`，示例 1 的 `b/a` 才能得 0.5。

## 如果面试官追问
若变量数涨到 10^5、查询 10^5，DFS 逐查会超时怎么办？答：用带权并查集，`find` 时压缩路径并累乘到根的比值，单次查询近似 O(α)。
