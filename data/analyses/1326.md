## 一句话思路
把每个水龙头转成「覆盖区间」，再对 [0,n] 做跳跃游戏的最少步数贪心。

## 怎么做
1. 预处理 `far[i]`：所有左端点 ≤ i 的水龙头里，能向右伸到的最远位置。
2. 从 `cur = 0` 出发，在当前已覆盖段内扫描，取最大 `far` 作为下一段的右端。
3. 每完成一次扩展就 `ans += 1`；若某轮 `nxt == cur` 说明卡住，返回 -1。

以 `n=5, ranges=[3,4,1,1,0,0]` 为例：水龙头 0 覆盖 [-3,3]、1 覆盖 [-3,5]，所以 `far[0]=3`、`far[1]=5`。第一轮在 `i=0` 时 `nxt=3`，`ans=1`；第二轮扫到 `i=1` 时 `nxt=5`，`ans=2`——但注意水龙头 1 的左端是 -3 ≤ 0，它本可以在第一轮就被选中，所以正确的 `far` 构造是 `far[0]=5`（左端 ≤0 的最大右端），第一轮直接 `nxt=5`，`ans=1`。

```python
far = [0] * (n + 1)
for i, r in enumerate(ranges):
    L, R = max(0, i - r), min(n, i + r)
    far[L] = max(far[L], R)
ans = cur = nxt = 0
while nxt < n:
    cur, nxt = nxt, max(far[cur:nxt + 1]) if nxt >= cur else nxt
    if nxt == cur:
        return -1
    ans += 1
return ans
```

关键点：`far` 按**左端点**存，不是按水龙头位置存；扫描时在 `[cur, nxt]` 窗口内取最大，这正是跳跃游戏的写法。

## 复杂度
时间 O(n)：构造 `far` 一遍，贪心扫描每个下标至多一次。
空间 O(n)：`far` 数组长度 n+1，无其他额外结构。

## 易错点
- 把 `far` 按水龙头位置 `i` 存而不是按左端点 `L` 存 → 对 `ranges=[3,4,1,1,0,0]` 会得到 `far[1]=5` 但 `far[0]=3`，第一轮只能到 3，答案错成 2 → 必须 `far[L] = max(far[L], R)`。
- 忘记把 `L` 截到 0、`R` 截到 n → 水龙头 0 的 `L=-3` 会写出负下标，Python 里 `far[-3]` 静默写到数组尾部，结果完全错乱 → 用 `max(0, i-r)` 和 `min(n, i+r)`。

## 如果面试官追问
问：要求输出具体选了哪些水龙头怎么办？
答：贪心时记录每轮取到最大 `far` 的那个下标，回溯即可，答案不唯一但数量仍最少。
