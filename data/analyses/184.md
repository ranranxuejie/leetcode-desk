## 一句话思路
按 `departmentId` 分组求 `max(salary)`，再回连 Employee 取所有等于该最大值的行，最后 join Department 拿部门名。

## 怎么做
1. 对 Employee 按 `departmentId` 分组，算出每组的最高工资，得到 `(departmentId, max_salary)` 集合。
2. 把 Employee 与这个集合按 `departmentId` 且 `salary == max_salary` 做内连接，筛出并列最高的人。
3. 再与 Department 按 `departmentId == Department.id` 连接，取出 `Department.name`。
4. 输出列重命名为 `Department / Employee / Salary`。

用官方示例：Employee 按部门分组后，部门 1 的 `max_salary = 90000`，部门 2 的 `max_salary = 80000`。回连时部门 1 命中 Jim(90000) 和 Max(90000) 两行，部门 2 只命中 Henry(80000)，所以输出三行——这正是「并列最高都要保留」的关键中间结果。

```python
emp = pd.DataFrame(Employee)
dept = pd.DataFrame(Department)
mx = emp.groupby("departmentId", as_index=False)["salary"].max()
mx.columns = ["departmentId", "max_salary"]
top = emp.merge(mx, on="departmentId")
top = top[top["salary"] == top["max_salary"]]
res = top.merge(dept, left_on="departmentId", right_on="id")
res = res[["name_y", "name_x", "salary"]]
res.columns = ["Department", "Employee", "Salary"]
```

## 复杂度
时间：O(n) 分组 + O(n) 两次 merge，n 为 Employee 行数。
空间：O(k) 存分组最大值，k 为部门数，另加 merge 结果 O(n)。

## 易错点
- 用 `groupby().max()` 后直接取 `.idxmax()` 只留一行 → 部门 1 会丢掉 Jim 或 Max 中的一个 → 必须用「等于组内最大值」的布尔过滤保留全部并列者。
- Employee 里存在 `departmentId` 在 Department 中查不到的行（如部门 3 无对应记录）→ 内连接会静默丢人，若题目要求保留则需 `how="left"`；本题按内连接处理，但要知道这是主动选择而非疏漏。

## 如果面试官追问
问：若要求每个部门只返回一人（并列时取 id 最小）？
答：在 `top` 上按 `departmentId` 分组取 `id` 最小的那行，再 join Department。
