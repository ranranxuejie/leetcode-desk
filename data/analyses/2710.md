## 一句话思路
从右往左跳过所有 `'0'`，找到第一个非零字符的下标，切片返回前缀即可。

## 怎么做
1. 令 `i = len(num) - 1`，从末位开始向左扫描。
2. 只要 `i >= 0 and num[i] == '0'` 就 `i -= 1`，跳过全部尾随零。
3. 返回 `num[:i+1]`，即保留到第一个非零字符为止的前缀。

以 `num = "51230100"` 为例：初始 `i = 7`，`num[7]='0'` 跳过，`i=6`，`num[6]='0'` 跳过，`i=5`，`num[5]='1'` 停止。此时 `i=5`，切片 `num[:6]` 得到 `"512301"`，正好砍掉两个零。

```python
i = len(num) - 1
while i >= 0 and num[i] == '0':
    i -= 1
return num[:i + 1]
```

第 2 步的循环条件是 `i >= 0` 在前，保证 `num[i]` 不会越界访问；第 3 步用 `i + 1` 是因为切片右端开区间，`i` 指向的是要保留的最后一个字符。

## 复杂度
时间：O(n)，n 为 `num` 长度，最坏从右扫到左。
空间：O(n)，切片 `num[:i+1]` 新建了一个字符串。

## 易错点
- 输入 `num = "1000"` → 若只 `rstrip('0')` 后不检查空串，或误以为结果可能为空，会返回 `""`；正确做法是保留第一个非零字符 `'1'`，返回 `"1"`，因为题面保证是正整数，至少有一个非零位。
- 输入 `num = "123"` → 若循环写成 `while num[i] == '0'` 而不判 `i >= 0`，会越界抛 `IndexError`；正确做法是把 `i >= 0` 放在 `and` 左侧短路，扫到 `i = -1` 时安全退出并返回原串。

## 如果面试官追问
追问：如果 `num` 长度到 10^7，还能这样切片吗？
答：能，但切片会复制 O(n) 内存；可改为返回 `i + 1` 作为有效长度，让调用方按长度截取，避免额外分配。
