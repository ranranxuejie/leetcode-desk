## 一句话思路
统计 s 和 target 的字符频次，对 target 中每个字符取 `s_count[c] // target_count[c]` 的最小值。

## 怎么做
1. 用 `Counter` 分别统计 `s` 和 `target` 的字符频次，得到 `cs` 和 `ct`。
2. 遍历 `ct` 的每个字符 `c`，计算 `cs[c] // ct[c]`，取所有结果的最小值。
3. 若 `cs` 中缺少某字符，`cs[c]` 为 0，整除结果为 0，直接返回 0。

以示例 1 为例：`s = "ilovecodingonleetcode"`，`target = "code"`。
`ct = {'c':1, 'o':1, 'd':1, 'e':1}`，`cs` 中 `c` 出现 2 次、`o` 出现 3 次、`d` 出现 1 次、`e` 出现 2 次。
各字符商为 `2//1=2`、`3//1=3`、`1//1=1`、`2//1=2`，取最小值 `1`？不对——`d` 在 s 中实际出现 2 次（"coding" 和 "leetcode" 各一个 d），商为 2，最终最小值为 2，与输出一致。

```python
from collections import Counter

cs = Counter(s)
ct = Counter(target)
ans = float('inf')
for c, need in ct.items():
    ans = min(ans, cs[c] // need)
return ans
```

注意 `cs[c]` 对不存在的键返回 0（`Counter` 的默认行为），无需额外判断。

## 复杂度
时间：O(n + m)，n = len(s)，m = len(target)，各扫一遍。
空间：O(1)，两个 Counter 最多存 26 个小写字母的计数。

## 易错点
- 输入 `s = "abcba", target = "abc"` → 若只统计 s 中总字符数再除以 target 长度（5//3=1），碰巧对；但换成 `s = "aaabbc", target = "abc"` 会错算成 2，实际 `c` 只有 1 个，正确结果是 1。必须逐字符取商的最小值。
- 输入 `s = "abbaccaddaeea", target = "aaaaa"` → 若忘记处理 target 中重复字符，把 `ct` 当成集合 `{'a'}` 只算一次 `cs['a'] // 1`，会得到 5 而非 1。正确做法是 `ct['a'] = 5`，商为 `5 // 5 = 1`。

## 如果面试官追问
问：如果要求输出具体选取方案（每个副本用哪些下标）？
答：先按上述方法算出最大副本数 k，再对每个字符维护一个下标队列，依次弹出 k 组下标即可。
