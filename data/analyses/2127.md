## 一句话思路
每个点出度恰为 1，图是「基环树森林」；答案只可能是某个纯环长度，或所有二元环各自挂链之和。

## 怎么做
1. 拓扑排序剥掉所有入度非零的链，剩下入度为 1 的点就是环上点，用 `indeg` 数组配合队列实现。
2. 对每个环求长度 `len`：若 `len == 2`，把这条二元环两侧的最长链长相加再加 2，累加到 `pair_sum`；否则用 `len` 更新 `best_cycle`。
3. 链长用反向图 `rev[favorite[i]].append(i)` 上的 DFS 求，`depth[u] = 1 + max(depth[v])`。

以 `favorite = [2,2,1,2]` 为例：`indeg = [0,0,1,3]`，队列初始只有 0，弹出 0 后 `indeg[2]` 变 0 入队，弹出 2 后 `indeg[1]` 变 0 入队，最后只剩 3 的 `indeg` 为 1，环是 `[3]` 自环——但题目保证 `favorite[i] != i`，所以真实环是 `1 -> 2 -> 1`，`len == 2`，两侧链长各为 1（点 0 挂在 2 上），`pair_sum = 1 + 1 + 2 = 4`？实际答案是 3，因为 0 和 3 都指向 2，只能取一条链，取 `max` 而非求和。

```python
indeg = [0] * n
for v in favorite:
    indeg[v] += 1
q = deque(i for i in range(n) if indeg[i] == 0)
while q:
    u = q.popleft()
    v = favorite[u]
    indeg[v] -= 1
    if indeg[v] == 0:
        q.append(v)
# 剩 indeg[i] == 1 的点在环上
```

## 复杂度
时间 O(n)：拓扑排序每条边一次，DFS 每个点一次。
空间 O(n)：`indeg`、`rev` 邻接表、`depth` 各 n 量级。

## 易错点
- 二元环两侧链长必须取 `max` 而不是相加：`favorite = [2,2,1,2]` 中 0 和 3 都指向 2，若把两条链都算进去得 4，正确是 `max(1,1)+2 = 3`。
- 多个二元环可以同时上桌（各自成一段弧），而长度 ≥3 的环只能选一个：`favorite = [1,0,3,2]` 答案是 4（两个二元环相加），若只取 `best_cycle` 会错成 2。

## 如果面试官追问
若要求输出具体邀请名单？答：在求 `pair_sum` 时记录每个二元环选中的那条链的路径，环长分支记录整环，最后拼接即可。
