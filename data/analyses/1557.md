## 一句话思路
统计所有入度为 0 的节点，它们就是答案——DAG 中每个点都能从某个入度为 0 的点到达。

## 怎么做
1. 开一个长度 n 的布尔数组 `has_in`，初始全 `False`。
2. 遍历 `edges`，对每条边 `[u, v]` 置 `has_in[v] = True`，只关心终点。
3. 最后扫一遍 `0..n-1`，把 `has_in[i] == False` 的下标收集起来返回。

以示例 1 为例：`edges = [[0,1],[0,2],[2,5],[3,4],[4,2]]`，处理完所有边后 `has_in` 中为 `True` 的是下标 1、2、5、4，剩下 `has_in[0]` 和 `has_in[3]` 仍是 `False`，输出 `[0,3]`。注意 2 虽然是 0 的后继，但它有入边 `4->2`，所以不算起点。

```python
has_in = [False] * n
for u, v in edges:
    has_in[v] = True
res = [i for i in range(n) if not has_in[i]]
return res
```

为什么成立：DAG 里任取一点 x，若入度非 0 就沿入边反向走，路径不可能成环（无环），必然停在某个入度为 0 的点，说明 x 被该点可达；而任何入度为 0 的点没有入边，别的点无法到达它，只能自己当起点。所以「入度为 0」既是充分也是必要，集合唯一且最小。

## 复杂度
时间 O(n + m)，m 为 `edges.length`，遍历边一次、扫节点一次。
空间 O(n)，只开了 `has_in` 这个长度 n 的布尔数组，未建邻接表。

## 易错点
- 把 `has_in` 写成对起点 `u` 置 `True`：示例 1 会得到 `[1,2,4,5]` 之类的错误集合，因为 0 和 3 被误判为「有入边」。正确做法是只标记终点 `v`。
- 用邻接表 + 从每个点 DFS 求可达性：n、m 都到 10^5，最坏 O(n·m) 直接超时；本题根本不需要遍历图，一次入度统计就够。

## 如果面试官追问
问：如果图不保证无环，答案还一样吗？
答：不一样，有环时环上点互相可达、可能都不需要选，得先缩点再取缩点后入度为 0 的强连通分量。
