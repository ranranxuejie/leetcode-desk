## 一句话思路
无向图邻接矩阵第 i 行的元素和就是顶点 i 的度，逐行求和即可。

## 怎么做
1. 取 `n = len(matrix)`，准备长度 n 的结果数组 `ans`。
2. 对每一行 `i`，直接 `sum(matrix[i])` 得到该顶点的度。
3. 把和写进 `ans[i]`，遍历完返回。

以示例 1 的 `matrix = [[0,1,1],[1,0,1],[1,1,0]]` 为例：第 0 行 `[0,1,1]` 求和得 `0+1+1=2`，第 1 行 `[1,0,1]` 得 2，第 2 行 `[1,1,0]` 得 2，所以 `ans = [2,2,2]`。关键中间值就是每行的 `sum`，不需要额外判断对角线。

```python
n = len(matrix)
ans = []
for i in range(n):
    ans.append(sum(matrix[i]))
return ans
```

也可以写成列表推导，但核心仍是「行和即度」。注意 `matrix[i][i] == 0` 保证对角线不会把顶点自己算进去；无向图对称性保证第 i 行和第 i 列一致，所以只读行就够，不用再扫列。

## 复杂度
时间：O(n²)，每行扫 n 个元素，共 n 行。
空间：O(n)，只开结果数组 `ans`，输入矩阵不计。

## 易错点
- 输入 `[[0]]` → 若先判断 `n > 1` 再处理，可能漏掉单顶点返回空数组 → 正确做法是直接对第 0 行求和得 `[0]`，不要加特判。
- 输入 `[[0,1,0],[1,0,0],[0,0,0]]` → 若误把列也累加一遍，顶点 0 会算成 2 而不是 1 → 正确做法是只对 `matrix[i]` 这一行求和，利用对称性，不要重复加列。

## 如果面试官追问
问：如果矩阵不是对称的（有向图）怎么办？
答：那时出度是行和、入度是列和，需要分别统计，不能只读一行。
