## 一句话思路
按长度做 DP，`dp[i]` 表示构造出长度恰为 `i` 的字符串方案数，由 `dp[i-zero]` 和 `dp[i-one]` 转移而来。

## 怎么做
1. 定义 `dp[i]` 为长度恰好等于 `i` 的不同字符串数，`dp[0] = 1`（空串一种）。
2. 对 `i` 从 1 到 `high` 递推：若 `i >= zero` 加上 `dp[i-zero]`，若 `i >= one` 加上 `dp[i-one]`，每步对 `10**9+7` 取余。
3. 答案是把 `dp[low..high]` 全部累加，而不是只取 `dp[high]`。

以示例 2（`low=2, high=3, zero=1, one=2`）为例，关键中间值：`dp[0]=1`；`dp[1]=dp[0]=1`（只能加一个 '0'）；`dp[2]=dp[1]+dp[0]=1+1=2`（"00" 与 "11"）；`dp[3]=dp[2]+dp[1]=2+1=3`（"000"、"110"、"011"）。累加 `dp[2]+dp[3]=2+3=5`，与输出一致。

```python
MOD = 10**9 + 7
dp = [0] * (high + 1)
dp[0] = 1
for i in range(1, high + 1):
    if i >= zero:
        dp[i] = (dp[i] + dp[i - zero]) % MOD
    if i >= one:
        dp[i] = (dp[i] + dp[i - one]) % MOD
ans = sum(dp[low:high + 1]) % MOD
```

注意 `zero == one` 时两个分支都要加，不能写成 `elif`，否则示例 1 里 `dp[1]` 只会得 1 而不是 2。

## 复杂度
时间 O(high)：单层循环跑 `high` 次，每次 O(1)。
空间 O(high)：`dp` 数组长度 `high+1`，无其他额外结构。

## 易错点
- `low=3, high=3, zero=1, one=1` → 若只返回 `dp[high]` 会漏掉长度 3 以外的贡献、或误把 `dp[3]` 当答案却忘了区间累加，正确做法是 `sum(dp[low:high+1])`，此例得 8。
- `zero == one`（如示例 1 的 `zero=one=1`）→ 若写成 `if/elif` 会漏掉一条转移，`dp[1]` 错成 1，最终答案错成 4；正确做法是两个 `if` 独立判断，`dp[1]=dp[0]+dp[0]=2`。

## 如果面试官追问
问：若 `high` 放大到 `10**9` 怎么办？
答：转移是常系数线性递推，用矩阵快速幂把 O(high) 降到 O(log high)，矩阵维度取 `max(zero, one)`。
