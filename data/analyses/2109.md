## 一句话思路
双指针扫 `s` 和 `spaces`，在 `spaces[j] == i` 时先塞空格再放字符，一次遍历拼出新串。

## 怎么做
1. 建 `res = []`，指针 `j = 0` 指向 `spaces` 当前待处理位置。
2. 遍历 `i, ch in enumerate(s)`，若 `j < len(spaces) and spaces[j] == i` 就先 `res.append(' ')` 并 `j += 1`。
3. 再 `res.append(ch)`，循环结束后 `return ''.join(res)`。

以示例 1 为例：`s = "LeetcodeHelpsMeLearn"`，`spaces = [8,13,15]`。走到 `i = 8` 时 `ch = 'H'`，此时 `spaces[0] == 8`，先追加空格再追加 `'H'`，`j` 变 1；`i = 13` 时 `ch = 'M'`，`spaces[1] == 13` 同样先空格后字符。因为 `spaces` 严格递增，`j` 只前进不回退，每个下标最多比较一次。

```python
res = []
j = 0
for i, ch in enumerate(s):
    if j < len(spaces) and spaces[j] == i:
        res.append(' ')
        j += 1
    res.append(ch)
return ''.join(res)
```

关键点：判断放在追加字符**之前**，这样空格落在下标 `i` 的字符前面；`spaces` 递增保证不用回头找。

## 复杂度
时间 O(n + m)：`n = len(s)` 遍历字符，`m = len(spaces)` 由 `j` 单调前进贡献，合计线性。
空间 O(n + m)：`res` 存 `n + m` 个元素，`join` 再开一个长度 `n + m` 的字符串。

## 易错点
- `spaces` 含 0（如示例 3 `spaces = [0,1,...,6]`）→ 若把判断写成 `if i > 0 and spaces[j] == i` 会漏掉首字符前的空格，输出 `"spacing"` 而非 `" s p a c i n g"`；正确做法是不加 `i > 0` 限制，`i = 0` 时照常先追加空格。
- 用 `s[:i] + ' ' + s[i:]` 逐个插入 → `spaces` 长度到 3e5 时每次拼接 O(n)，总 O(n·m) 超时；正确做法是单次遍历收集到 `res` 再 `join`，避免重复拷贝。

## 如果面试官追问
若 `spaces` 不保证递增怎么办？答：先 `spaces.sort()` 再套同一双指针，多 O(m log m)，逻辑不变。
