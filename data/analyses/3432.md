## 一句话思路
只看奇偶性：左和与右和同奇偶则差为偶数，而右和 = 总和 − 左和，故只需左和与总和同奇偶。

## 怎么做
1. 先算 `total = sum(nums)`，只关心它的奇偶 `total % 2`。
2. 从左往右累加 `left`，对每个切点 `i`（`0 <= i < n-1`）判断 `left % 2 == total % 2`。
3. 成立就 `ans += 1`，然后继续把 `nums[i+1]` 加进 `left`。

以 `nums = [10,10,3,7,6]` 为例，`total = 36`（偶）。切点 i=0 时 `left = 10`（偶）→ 计 1；i=1 时 `left = 20`（偶）→ 计 1；i=2 时 `left = 23`（奇）→ 不计；i=3 时 `left = 30`（偶）→ 计 1。这里只数到 3 个，但示例答案是 4——因为 `total` 是 36，`left` 为偶时右和 `36 - left` 也是偶，差为偶；`left = 23` 时右和 13 也是奇，奇−奇=偶，同样成立。所以判据应是 `left % 2 == (total - left) % 2`，等价于 `total % 2 == 0` 时恒成立、`total` 为奇时要求 `left` 为奇。用 `(left - (total - left)) % 2 == 0` 最直白，避免推错。

```python
total = sum(nums)
left = 0
ans = 0
for i in range(len(nums) - 1):
    left += nums[i]
    if (left - (total - left)) % 2 == 0:
        ans += 1
```

## 复杂度
时间 O(n)：一次求和加一次单层扫描，每个元素常数次运算。
空间 O(1)：只开 `total`、`left`、`ans` 三个标量。

## 易错点
- `nums = [1,2,2]`，`total = 5`（奇）：若只判 `left % 2 == total % 2`，i=0 时 `left=1` 奇、`total` 奇，会误计 1；实际右和 4 为偶，1−4=−3 是奇数，不该计。正确做法是判 `(left - (total - left)) % 2 == 0`。
- 循环写成 `range(len(nums))`：i 取到 `n-1` 时右子数组为空，`nums = [2,4,6,8]` 会多算 1 个变成 4。必须写 `range(len(nums) - 1)`，保证两侧非空。

## 如果面试官追问
若要求返回所有方案的下标 i 而非计数？答：把 `ans += 1` 换成 `ans.append(i)`，判据不变，仍是 O(n) 时间、O(k) 输出空间。
