## 一句话思路
逐行累加每列的连续 1 高度，排序后按「最矮的列决定宽度」扫一遍取最大面积。

## 怎么做
1. 维护 `heights[j]`：第 j 列从当前行往上连续 1 的个数，遇 0 清零。
2. 每处理完一行，把 `heights` 降序排序。
3. 排序后第 i 个位置（0 起）的列高 `heights[i]`，它和前面 i+1 列都能凑出高度 `heights[i]` 的矩形，面积 `heights[i] * (i + 1)`。
4. 对所有行、所有 i 取最大值。

以示例 1 `[[0,0,1],[1,1,1],[1,0,1]]` 为例，处理到第 2 行（下标 1）时 `heights = [1,1,2]`，降序后 `[2,1,1]`：i=0 得 `2*1=2`，i=1 得 `1*2=2`，i=2 得 `1*3=3`。再处理第 3 行，`heights = [2,0,3]`，降序 `[3,2,0]`：i=0 得 3，i=1 得 `2*2=4`，i=2 得 0，答案 4。

```python
m, n = len(matrix), len(matrix[0])
heights = [0] * n
ans = 0
for row in matrix:
    for j in range(n):
        heights[j] = heights[j] + 1 if row[j] == 1 else 0
    for i, h in enumerate(sorted(heights, reverse=True)):
        ans = max(ans, h * (i + 1))
return ans
```

关键点：排序把「哪些列能并排」这个自由度用掉了——列可以任意重排，所以只要高度够的列就能挨在一起，宽度就是满足条件的列数。

## 复杂度
时间：O(m·n log n)，每行排序 n 个高度贡献 log n。
空间：O(n)，只开 `heights` 和排序临时数组。

## 易错点
- 遇到 0 忘记把 `heights[j]` 清零，写成 `heights[j] += 1` 无条件累加 → 示例 1 第 3 行第 2 列（`matrix[2][1]=0`）会残留 1，算出面积 6 而非 4 → 必须 `heights[j] = heights[j] + 1 if row[j] == 1 else 0`。
- 排序后按升序扫、却仍用 `h * (i + 1)` → 示例 1 第 3 行升序 `[0,2,3]`，i=1 得 `2*2=4` 碰巧对，但 i=2 得 `3*3=9` 直接错 → 必须降序，让 `i+1` 表示「高度 ≥ h 的列数」。

## 如果面试官追问
问：如果列不能重排，只能整行整列交换呢？
答：那就退化成最大全 1 矩形，用单调栈按行求柱状图最大矩形，O(m·n)。
