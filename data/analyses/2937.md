## 一句话思路
三个串只能删尾部，所以相等结果必是三者公共前缀，取最长公共前缀长度 L，答案是三串长度和减 3L。

## 怎么做
1. 从下标 0 开始逐位比较 `s1[i]`、`s2[i]`、`s3[i]`，同时要求 `i` 不超过任一串长度。
2. 一旦三者字符不全相同或越界，立即停止，此时的 `i` 就是最长公共前缀长度 L。
3. 若 L 为 0，说明首字符就不同，直接返回 -1。
4. 否则返回 `len(s1) + len(s2) + len(s3) - 3 * L`。

以示例 1 为例：`s1="abc"`、`s2="abb"`、`s3="ab"`。i=0 时三者都是 `'a'`，i=1 时都是 `'b'`，i=2 时 `s3` 已越界（长度 2），循环停止，L=2。答案 = 3+3+2-3×2 = 2，与官方输出一致。

```python
i = 0
while i < len(s1) and i < len(s2) and i < len(s3):
    if s1[i] != s2[i] or s2[i] != s3[i]:
        break
    i += 1
if i == 0:
    return -1
return len(s1) + len(s2) + len(s3) - 3 * i
```

关键点：循环条件里的三个 `i < len(...)` 缺一不可，否则 `s3="ab"` 在 i=2 时会抛 IndexError；而 `i==0` 的判断必须放在循环之后，因为首字符相同但第二字符不同时 L=1，仍合法。

## 复杂度
时间 O(min(len(s1), len(s2), len(s3)))，由最短串长度决定循环次数。
空间 O(1)，只用了下标 `i`，没有额外字符串。

## 易错点
- 输入 `s1="a"`、`s2="a"`、`s3="a"`：若把循环条件写成 `i < len(s1)` 单串判断，会在 i=1 时越界；正确做法是三个长度条件用 `and` 串联，任一串到头就停。
- 输入 `s1="ab"`、`s2="ab"`、`s3="ac"`：若先求两两公共前缀再取交集，容易把 L 算成 2；正确做法是同一轮同时比较三个字符，i=1 时 `'b' != 'c'` 立刻 break，L=1，答案 2+2+2-3=3。

## 如果面试官追问
问：若允许在任意位置删除字符而非仅尾部，答案怎么变？
答：那就变成求三串最长公共子序列，需 O(n³) 动态规划，不再是前缀问题。
