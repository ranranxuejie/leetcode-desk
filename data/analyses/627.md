## 一句话思路
用一条 `UPDATE` 配合 `CASE WHEN sex='m' THEN 'f' ELSE 'm' END` 原地翻转，因为 ENUM 只有两个取值，非 m 即 f。

## 怎么做
1. 只写一条 `UPDATE Salary SET sex = ...`，不写 `SELECT`、不建临时表。
2. 用 `CASE` 表达式做二值翻转，`WHEN sex = 'm' THEN 'f'`，`ELSE 'm'`。
3. 拿官方示例第 1 行验证：`id=1, sex='m'` 命中 `WHEN` 分支，赋值 `'f'`；第 2 行 `id=2, sex='f'` 落到 `ELSE`，赋值 `'m'`。
4. 执行后 4 行 sex 依次为 `f, m, f, m`，与期望输出一致。

```python
# 伪代码：一条 UPDATE，无 SELECT
sql = """
UPDATE Salary
SET sex = CASE WHEN sex = 'm' THEN 'f' ELSE 'm' END
"""
# 逐行求值：id=1 'm'->'f'，id=2 'f'->'m'，id=3 'm'->'f'，id=4 'f'->'m'
```

关键中间值：对 `id=1` 这一行，`CASE` 的判定输入是 `sex='m'`，返回 `'f'`，写回后该行变成 `(1, A, f, 2500)`。

## 复杂度
时间：O(n)，n 为 Salary 行数，每行做一次 CASE 判定。
空间：O(1)，原地更新，不额外开表或临时列。

## 易错点
- 写成两条 `UPDATE`（先 m→f 再 f→m）→ 第一批被改成 f 的行会被第二条再改回 m，结果全表变 m → 必须用单条 `CASE` 一次性判定，避免二次污染。
- 用 `IF(sex='m','f','m')` 之外的写法如 `sex = 'f' WHERE sex='m'` 再补一条 → 违反「仅一条 UPDATE」约束，且同样踩上面的覆盖坑 → 统一收敛到一条带 `CASE`/`IF` 的语句。

## 如果面试官追问
问：若 sex 允许第三个值 `'unknown'` 怎么办？
答：`CASE` 加显式分支，`WHEN 'm' THEN 'f' WHEN 'f' THEN 'm' ELSE sex END`，保留 unknown 不动。
