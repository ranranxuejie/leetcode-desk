## 一句话思路
按十进制位拆解，每位数字 d 生成 d×10^k，非零位各出一个分量，个数即最少。

## 怎么做
1. 从低位起用 `place = 1` 记录当前位权，循环条件 `while n > 0`。
2. 每轮取 `d = n % 10`，若 `d != 0` 就把 `d * place` 追加进结果。
3. 更新 `n //= 10`、`place *= 10`，继续处理下一位。
4. 因为从低位往高位追加，结果天然是升序，最后 `reverse` 一次得到降序。

以 `n = 537` 为例：第一轮 `d = 7`、`place = 1`，追加 `7`；第二轮 `d = 3`、`place = 10`，追加 `30`；第三轮 `d = 5`、`place = 100`，追加 `500`。此时列表是 `[7, 30, 500]`，反转后为 `[500, 30, 7]`。

```python
res = []
place = 1
while n > 0:
    d = n % 10
    if d != 0:
        res.append(d * place)
    n //= 10
    place *= 10
res.reverse()
return res
```

关键中间值：`n = 102` 时，第一轮 `d = 2` 追加 `2`，第二轮 `d = 0` 跳过（不产生 `0` 分量），第三轮 `d = 1`、`place = 100` 追加 `100`，反转得 `[100, 2]`。

为什么最少：每个非零位 d 至少需要 d 个同量级分量才能凑出该位的值，而 d ≤ 9 恰好可用一个 `d * place` 覆盖，所以非零位个数就是下界，也是答案。

## 复杂度
时间 O(log n)：循环次数等于 n 的十进制位数，每轮常数操作。
空间 O(log n)：结果数组最多存位数个元素，`place`、`d` 是常数级额外变量。

## 易错点
- 输入 `n = 1000` → 若把 `d == 0` 的位也追加 `0 * place`，会输出 `[0, 0, 0, 1000]` 这种含 0 的非法分量 → 正确做法是 `if d != 0` 才 append，0 分量不是正整数。
- 输入 `n = 10` → 若循环写成 `while n > 1` 或先 `n //= 10` 再取位，会漏掉最高位或最低位，输出 `[1]` 或 `[10]` 错位 → 正确做法是每轮先 `d = n % 10` 再 `n //= 10`，保证 `n = 10` 时第一轮取到 `d = 0` 跳过、第二轮取到 `d = 1` 得 `10`。

## 如果面试官追问
若 n 上限提到 10^18 甚至用字符串给超大数怎么办？答：按字符从右往左扫，第 i 位字符 c 非 `'0'` 就生成 `int(c) * 10**i`，位数即循环次数，逻辑不变。
