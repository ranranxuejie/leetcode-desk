## 一句话思路
带权并查集维护每个点到根的距离奇偶性，加边前检查两端奇偶差是否与边权一致。

## 怎么做
1. 把每条边 `[u, v, w]` 看成约束 `parity(u) xor parity(v) == w`，用带权并查集维护。
2. `find(x)` 返回根，同时把 `d[x]` 更新为 x 到根的异或和（路径压缩时累加）。
3. 若 `u`、`v` 同根，检查 `d[u] ^ d[v] == w`，成立才加边；否则合并，`d[ru] = d[u] ^ d[v] ^ w`。

以示例 1 的第三条边 `[0,2,1]` 为例：前两条边已合并成一条链，`find(0)` 得 `d[0]=0`，`find(2)` 得 `d[2]=1^1=0`，`d[0]^d[2]=0 != 1`，故拒绝，答案停在 2。

```python
def find(x):
    if parent[x] != x:
        r = find(parent[x])
        d[x] ^= d[parent[x]]
        parent[x] = r
    return parent[x]

for u, v, w in edges:
    ru, rv = find(u), find(v)
    if ru == rv:
        if d[u] ^ d[v] == w:
            ans += 1
    else:
        parent[ru] = rv
        d[ru] = d[u] ^ d[v] ^ w
        ans += 1
```

注意 `find` 里必须先递归拿到新根、再异或 `d[parent[x]]`，顺序反了会把旧父的旧值算进去。

## 复杂度
时间：O(m·α(n))，m 为 edges 长度，α 来自并查集路径压缩。
空间：O(n)，parent 与 d 各开 n 个，递归栈最坏 O(n)。

## 易错点
- 输入 `[[0,1,1],[1,2,1],[0,2,1]]` → 若只判连通性不判奇偶，会把第三条边错误加入得 3 → 必须比较 `d[u]^d[v]` 与 `w`。
- 合并时写成 `d[ru] = d[u] ^ d[v]` 漏掉 `w` → 示例 2 的 `[0,2,0]` 会算成 `d[0]^d[2]=0` 恰好蒙对，但换成 `w=1` 的合并边就错 → 正确式子是 `d[u]^d[v]^w`。

## 如果面试官追问
若要求输出最终保留的边编号？答：在 `ans += 1` 处同步记录当前下标即可，其余逻辑不变。
