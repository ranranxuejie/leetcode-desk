## 一句话思路
把「已收集垃圾集合 + 当前位置 + 剩余能量」压成状态做 BFS，因为能量上限 50、垃圾 ≤10，状态数可控。

## 怎么做
1. 先给每个 `'L'` 编号 0..k-1，`S` 记为起点，状态用 `(mask, r, c, e)` 表示。
2. BFS 队列里存 `(mask, r, c, e, dist)`，`visited` 是四元组集合；每步向四邻移动，`e-1`，若落到 `'R'` 则 `e` 重置为 `energy`。
3. 移动前判断：`e == 0` 且当前格不是 `'R'` 就不能走；到达 `'L'` 时 `mask |= 1 << id`。
4. 第一次弹出 `mask == (1<<k)-1` 的 `dist` 即答案，队列空返回 `-1`。

以示例 2 `["LS","RL"], energy=4` 为例：起点 `(0,1)` 状态 `(mask=0, e=4)`；走到 `(0,0)` 收集 `L#0`，状态变 `(mask=1, e=3)`；再走到 `(1,0)` 是 `'R'`，`e` 重置回 4，状态 `(mask=1, e=4)`；最后到 `(1,1)` 得 `mask=3`，`dist=3`。

```python
from collections import deque
k = sum(ch == 'L' for row in classroom for ch in row)
full = (1 << k) - 1
# 起点
for i, row in enumerate(classroom):
    for j, ch in enumerate(row):
        if ch == 'S': sr, sc = i, j
q = deque([(0, sr, sc, energy, 0)])
seen = {(0, sr, sc, energy)}
while q:
    mask, r, c, e, d = q.popleft()
    if mask == full: return d
    for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
        nr, nc = r+dr, c+dc
        if not (0 <= nr < m and 0 <= nc < n) or classroom[nr][nc] == 'X': continue
        if e == 0 and classroom[r][c] != 'R': continue
        ne = energy if classroom[nr][nc] == 'R' else e - 1
        nmask = mask
        if classroom[nr][nc] == 'L': nmask |= 1 << lid[nr][nc]
        st = (nmask, nr, nc, ne)
        if st not in seen:
            seen.add(st); q.append((nmask, nr, nc, ne, d+1))
return -1
```

## 复杂度
时间：`O(m*n*2^k*energy)`，每个状态四邻扩展一次。
空间：`visited` 存同样规模四元组，队列同阶。

## 易错点
- 示例 2 中 `(0,0)` 是 `'L'` 不是 `'R'`，若把「能量为 0 才能重置」写成「到 `'R'` 才允许移动」，会在 `e=3` 时误判 `(1,0)` 不可达 → 正确做法是 `'R'` 无条件重置 `ne=energy`，与当前 `e` 无关。
- 示例 1 中 `(1,0)` 是 `'X'`，若 BFS 只判边界不判 `'X'`，会从 `(0,0)` 直接下到 `(1,0)` 得到 `dist=1` 的错误答案 → 入队前必须 `classroom[nr][nc] != 'X'`。

## 如果面试官追问
问：若 `energy` 上限提到 10^9 怎么办？
答：能量只影响「能否走到下一个 `R`」，可预计算任意两点间最短路，状态退化为 `(mask, 位置)`，用 `R` 做中转。
