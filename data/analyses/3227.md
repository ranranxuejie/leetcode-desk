## 一句话思路
数元音个数：只要元音数 ≥ 1，小红先手就能一次清空，直接赢。

## 怎么做
1. 遍历 `s`，统计元音字母个数 `cnt`。
2. 若 `cnt == 0`，小红第一回合找不到含奇数个元音的非空子串，直接输，返回 `False`。
3. 若 `cnt >= 1`，小红直接移除整个字符串（含 `cnt` 个元音，奇数），返回 `True`。

以 `s = "leetcoder"` 为例：元音是 `e,e,o,e` 共 4 个，`cnt = 4`。但注意——4 是偶数，小红不能一次移除整串。此时她移除 `"leetco"`（含 `e,e,o` 共 3 个元音，奇数），剩下 `"der"`，`cnt` 变为 1，小明面对 1 个元音无法取偶数个，只能取 0 个元音的子串，最终小红取走 `"er"` 获胜。

关键结论：只要 `cnt >= 1`，小红总能构造出含奇数个元音的子串（取整个串若 `cnt` 为奇数；否则去掉一个元音字符，剩 `cnt-1` 个元音为奇数），所以答案就是 `cnt > 0`。

```python
vowels = set("aeiou")
cnt = sum(1 for ch in s if ch in vowels)
return cnt > 0
```

## 复杂度
时间：O(n)，n 为 `s` 长度，遍历一次统计元音。
空间：O(1)，只开了固定大小的元音集合和计数器。

## 易错点
- 输入 `s = "bbcd"` → 若误判为「长度非空就能玩」返回 `True` → 实际 `cnt = 0`，小红无子串可取，必须返回 `False`。
- 输入 `s = "leetcoder"`（`cnt = 4` 偶数）→ 若以为「元音数为偶数小红就输」返回 `False` → 实际小红可移除含 3 个元音的子串 `"leetco"`，仍能赢，正确判据只看 `cnt > 0`。

## 如果面试官追问
问：若要求输出小红的第一步具体移除方案怎么办？
答：`cnt` 为奇数就移除整串，为偶数就移除「整串去掉任意一个元音字符」得到的子串，两者元音数都是奇数。
