## 一句话思路
用容斥/莫比乌斯反演：统计每行能被 d 整除的个数，累乘得「gcd 是 d 的倍数」的方案数，再反演回 gcd 恰为 1。

## 怎么做
1. 对每个 d ∈ [1,150]，统计每行中 d 的倍数个数 `cnt[i][d]`，则 `f[d] = ∏ cnt[i][d]` 表示所有选中数都是 d 的倍数的方案数。
2. 从大到小反演：`g[d] = f[d] - Σ_{k≥2} g[k*d]`，`g[d]` 就是 gcd 恰为 d 的方案数。
3. 答案取 `g[1] mod 10**9+7`。

以 `mat = [[1,2],[3,4]]` 为例：`f[1]=2*2=4`，`f[2]=1*1=1`（第一行只有 2，第二行只有 4），其余 d 的 f 为 0。反演时 `g[2]=f[2]=1`，`g[1]=f[1]-g[2]=4-1=3`，与输出一致。

```python
MOD = 10**9 + 7
mx = max(max(row) for row in mat)
f = [0] * (mx + 1)
for d in range(1, mx + 1):
    prod = 1
    for row in mat:
        c = sum(1 for x in row if x % d == 0)
        prod = prod * c % MOD
    f[d] = prod
g = f[:]
for d in range(mx, 0, -1):
    for k in range(2, mx // d + 1):
        g[d] = (g[d] - g[d * k]) % MOD
return g[1] % MOD
```

关键点：`f[d]` 里若某行 `c == 0`，`prod` 直接为 0，无需特判；反演必须从大到小，保证 `g[d*k]` 已算好。

## 复杂度
时间：O(mx · m · n + mx log mx)，mx=150，m·n 是逐行数倍数的代价。
空间：O(mx)，只开 f、g 两个长度 151 的数组。

## 易错点
- 输入 `mat = [[2,2],[2,2]]` → 若只算 `f[1]` 就返回，会得 4 而非 0 → 必须做反演，`g[1]=f[1]-g[2]=4-4=0`。
- 反演方向写反（从小到大）→ `g[d*k]` 还是未减过的 `f[d*k]`，示例 1 会得 `4-1=3` 碰巧对，但 `mat=[[6],[10],[15]]` 这类会算错 → 必须 `for d in range(mx, 0, -1)`。

## 如果面试官追问
问：若 mat 元素上限改成 10^5 怎么办？
答：mx 变大后 O(mx log mx) 仍可，但每行数倍数要改成对每行做倍数桶统计，避免 O(mx·m·n)。
