## 一句话思路
按「前 i 项工作分给前 k 天」做区间 DP，枚举最后一天切点 j，用后缀最大值把当天难度 O(1) 取出。

## 怎么做
1. 先判 `d > n` 直接返回 -1，因为每天至少一项。
2. 定义 `dp[k][i]`：前 i 项工作（下标 0..i-1）分给 k 天的最小总难度，`dp[0][0]=0`，其余 `inf`。
3. 转移 `dp[k][i] = min(dp[k-1][j] + max(jobDifficulty[j:i]))`，j 从 k-1 到 i-1。
4. 内层从 i-1 往左扫 j，边扫边维护 `cur_max`，省掉重复求区间最大值。

拿示例 1 `[6,5,4,3,2,1], d=2` 走关键一步：算 `dp[2][6]` 时，j 从 5 往左扫，`cur_max` 依次是 1、2、3、4、5、6，对应 `dp[1][j] + cur_max` 取最小，j=5 时 `dp[1][5]=6`、`cur_max=1`，得 7，即答案。

```python
n = len(jobDifficulty)
if d > n:
    return -1
INF = 2**31 - 1
dp = [[INF] * (n + 1) for _ in range(d + 1)]
dp[0][0] = 0
for k in range(1, d + 1):
    for i in range(k, n + 1):
        cur_max = 0
        for j in range(i - 1, k - 2, -1):
            cur_max = max(cur_max, jobDifficulty[j])
            if dp[k - 1][j] != INF:
                dp[k][i] = min(dp[k][i], dp[k - 1][j] + cur_max)
return dp[d][n]
```

## 复杂度
时间：O(d·n²)，d 层、每层枚举 (i, j) 对，n=300、d=10 约 9e5 次。
空间：O(d·n) 的 dp 表，可压成两行降到 O(n)。

## 易错点
- `d > n` 时若不提前返回 -1，DP 里 `dp[d][n]` 会停在 `INF`，直接返回 `2**31 - 1` 而不是 -1，示例 2 就翻车。
- 内层 j 的下界写成 0 而不是 `k-1`：`dp[k-1][j]` 在 j < k-1 时是 `INF`，虽然结果不错但会多算；更危险的是 `cur_max` 从 i-1 往左扫时若忘记 `max` 累积，会把当天难度算成单个 `jobDifficulty[j]`，示例 1 的 j=0 会得 6+6=12 而非 7。

## 如果面试官追问
问：n 放大到 1e5 怎么办？答：这题结构下区间最大值不可加，O(d·n²) 已是最直接的；可提单调栈预处理每段最大值再配合决策单调性优化，但需额外证明。
