## 一句话思路
每轮扫一遍找相邻和最小的对（并列取最左），合并后重扫，直到数组非递减。

## 怎么做
1. 写 `ok(a)`：遍历 `a`，一旦 `a[i] < a[i-1]` 返回 `False`。
2. 主循环：`ok(nums)` 为真就停；否则线性扫 `i in range(len(nums)-1)`，用 `(nums[i]+nums[i-1], i)` 维护最小对，严格小于才更新，保证并列取最左。
3. 用 `nums[i-1:i+1] = [nums[i-1]+nums[i]]` 原地替换，`ans += 1`。

以 `[5,2,3,1]` 为例：第一轮相邻和是 `7,5,4`，最小对下标 `i=3`（`3+1=4`），替换后 `[5,2,4]`；第二轮和是 `7,6`，最小对 `i=2`（`2+4=6`），替换后 `[5,6]`，`ok` 通过，返回 `2`。

```python
def ok(a):
    return all(a[i] >= a[i-1] for i in range(1, len(a)))

ans = 0
while not ok(nums):
    best, bi = None, -1
    for i in range(1, len(nums)):
        s = nums[i-1] + nums[i]
        if best is None or s < best:
            best, bi = s, i
    nums[bi-1:bi+1] = [best]
    ans += 1
return ans
```

`best is None` 这个初值不能写成 `best = 2**31 - 1`：`nums[i]` 可到 `-1000`，相邻和最小可到 `-2000`，用大常数初始化会让第一对永远选不上，`bi` 停在 `-1` 直接崩。

## 复杂度
时间：每轮 O(n) 扫描，最多 n-1 轮，共 O(n²)，n 是当前数组长度。
空间：O(1) 额外，只用了 `best`、`bi`、`ans` 几个标量。

## 易错点
- 输入 `[2,1,1]` → 若用 `<=` 更新最小对，会选到右边的 `(1,1)` 而非最左的 `(2,1)`，合并顺序错、答案偏 → 必须用严格 `<`，只在更小时更新 `bi`。
- 输入 `[-5,-3,-1]` → 若把 `best` 初始化成 `0` 或大正数，第一对 `-8` 比不过初值，`bi` 保持 `-1`，切片 `nums[-2:0]` 静默出错 → 用 `None` 哨兵或 `best = nums[0] + nums[1]`、`bi = 1` 起步。

## 如果面试官追问
若 n 放大到 1e5 怎么办？答：用双向链表 + 堆存相邻和，合并只影响左右两个邻居，O(n log n)。
