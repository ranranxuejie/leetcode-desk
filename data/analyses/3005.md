## 一句话思路
用哈希表统计每个值的出现次数，再取最大次数并把所有等于它的次数相加。

## 怎么做
1. 用 `Counter(nums)` 得到 `cnt`，键是元素值，值是出现次数。
2. 取 `mx = max(cnt.values())`，这是最大频率。
3. 遍历 `cnt.values()`，把等于 `mx` 的值累加进 `ans`。
4. 返回 `ans`。

以 `nums = [1,2,2,3,1,4]` 为例，`cnt = {1:2, 2:2, 3:1, 4:1}`，`mx = 2`；遍历时只有 1 和 2 的次数等于 2，`ans = 2 + 2 = 4`。

```python
from collections import Counter

cnt = Counter(nums)
mx = max(cnt.values())
ans = 0
for v in cnt.values():
    if v == mx:
        ans += v
return ans
```

注意累加的是**频率**而不是元素个数：示例 1 里最大频率元素有 2 个，但答案是 4，因为 2+2。若写成 `ans += 1` 会得到 2。

## 复杂度
时间：O(n)，`Counter` 扫一遍 nums，再扫一遍至多 n 个不同值。
空间：O(n)，`cnt` 最多存 n 个键值对。

## 易错点
- 输入 `[1,2,3,4,5]` → 若把「最大频率元素的个数」当答案，会返回 5 个元素里数出 5 个元素但误写成 `ans += 1` 得 5 看似对，换成 `[1,1,2,2,3]` 就错成 2 而非 4 → 正确做法是累加频率值 `ans += v`。
- 输入 `[7]` → 若先 `max` 再遍历时把 `mx` 初始化为 0 且漏掉单元素分支，可能返回 0 → 正确做法是 `mx = max(cnt.values())` 直接从计数结果取，单元素时 `mx = 1`、`ans = 1`。

## 如果面试官追问
问：nums 长度到 10^7 且值域很大怎么办？
答：仍用哈希表 O(n)，但改用 `dict.get` 手动计数避免 `Counter` 的额外开销，或值域小时换数组计数。
