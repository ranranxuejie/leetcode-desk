## 一句话思路
从所有 0 同时出发做多源 BFS，第一次到达某格时的层数就是它到最近 0 的距离。

## 怎么做
1. 建 `dist` 矩阵，0 处填 0，1 处填 `-1` 表示未访问，并把所有 0 的坐标压入 `deque`。
2. 以队列为第 0 层，逐层向外扩展，只把 `dist == -1` 的邻居入队。
3. 邻居的距离写成 `dist[x][y] + 1`，因为 BFS 保证首次到达即最短。

以示例 2 的 `mat = [[0,0,0],[0,1,0],[1,1,1]]` 为例：初始队列是 7 个 0 的坐标，`dist[1][1]` 和 `dist[2][0]`、`dist[2][1]`、`dist[2][2]` 都是 `-1`。第一层扩展后 `dist[1][1] = 1`；第二层从 `(1,1)` 出发把 `(2,1)` 置为 2，从 `(2,0)` 出发时 `(2,1)` 已是 2 不再入队——这正是多源 BFS 与「对每个 1 单独 BFS」的区别。

```python
from collections import deque

m, n = len(mat), len(mat[0])
dist = [[-1] * n for _ in range(m)]
q = deque()
for i in range(m):
    for j in range(n):
        if mat[i][j] == 0:
            dist[i][j] = 0
            q.append((i, j))
while q:
    x, y = q.popleft()
    for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
        nx, ny = x + dx, y + dy
        if 0 <= nx < m and 0 <= ny < n and dist[nx][ny] == -1:
            dist[nx][ny] = dist[x][y] + 1
            q.append((nx, ny))
```

## 复杂度
时间 O(m·n)：每个格子最多入队一次，四条边各查一次。
空间 O(m·n)：`dist` 矩阵加队列，最坏全 1 时队列同时存 O(m·n) 个坐标。

## 易错点
- 全 1 的边界行如 `[[1,1],[1,1]]` 不满足「至少一个 0」，但若把 `dist` 初值写成 `0` 而非 `-1`，示例 2 中 `(2,1)` 会被 `(2,0)` 重复入队，距离被覆盖成 1 而非 2；必须用 `-1` 做未访问标记。
- 用 `mat` 原地改距离时，0 和「未访问的 1」都可能是 0 值，无法区分；示例 2 里 `mat[1][1]` 改成 1 后，下一轮会被误判成已访问的源点，正确做法是另开 `dist` 或把未访问写成 `-1`。

## 如果面试官追问
问：若矩阵是 10^5 × 10^5 稀疏 0，怎么省空间？
答：不存 `dist` 全矩阵，改用哈希表只记已确定距离的格子，或按行滚动做两遍 DP。
