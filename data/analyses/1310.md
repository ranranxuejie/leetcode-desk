## 一句话思路
用前缀异或数组 `pre`，区间 `[L,R]` 的异或等于 `pre[R+1] ^ pre[L]`，因为相同部分异或两次抵消。

## 怎么做
1. 构造 `pre`，长度 `n+1`，`pre[0]=0`，`pre[i+1]=pre[i]^arr[i]`。
2. 对每个查询 `[L,R]`，取 `pre[R+1] ^ pre[L]`。
3. 按查询顺序收集结果返回。

以 `arr=[1,3,4,8]` 为例，`pre=[0,1,2,6,14]`。查询 `[1,2]` 时 `pre[3]^pre[1]=6^1=7`，正好是 `3^4`；`pre[1]` 里的 `1` 被异或两次消掉。

```python
pre = [0] * (len(arr) + 1)
for i, x in enumerate(arr):
    pre[i + 1] = pre[i] ^ x
res = []
for L, R in queries:
    res.append(pre[R + 1] ^ pre[L])
return res
```

关键点：`pre` 的下标偏移一位，`pre[i]` 表示 `arr[0..i-1]` 的异或，所以右端点要写 `R+1` 而不是 `R`。

## 复杂度
时间：O(n + q)，n 是 arr 长度、q 是查询数，各扫一遍。
空间：O(n)，额外开了长度 n+1 的 `pre`，结果数组 O(q) 不计入。

## 易错点
- 查询 `[3,3]`（单元素）时若写成 `pre[R] ^ pre[L]`，会得到 `pre[3]^pre[3]=0`，正确应是 `pre[4]^pre[3]=14^6=8`。右端点统一用 `R+1`。
- 查询 `[0,1]` 时若漏掉 `pre[0]=0` 的初始化，或把 `pre` 长度设成 `n`，`pre[R+1]` 会越界。`pre` 必须长 `n+1` 且首元素为 0。

## 如果面试官追问
若 arr 支持单点修改、查询不变，怎么做？答：改用线段树或树状数组维护异或，单点更新 O(log n)、区间查询 O(log n)。
