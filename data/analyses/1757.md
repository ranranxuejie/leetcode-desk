## 一句话思路
用布尔条件同时过滤 `low_fats` 和 `recyclable` 两列，只保留两列都为 `'Y'` 的行，再投影出 `product_id`。

## 怎么做
1. 在 `WHERE` 里用 `AND` 连接两个等值条件，分别锁定 `low_fats = 'Y'` 和 `recyclable = 'Y'`。
2. 用 `SELECT product_id` 只投影主键列，避免带出枚举列。
3. 无需 `ORDER BY`，题目声明结果无顺序要求。

拿官方示例走一遍：第 0 行 `low_fats='Y'` 但 `recyclable='N'`，被第二个条件挡掉；第 2 行 `low_fats='N'`，被第一个条件挡掉；第 1 行 `('Y','Y')` 和第 3 行 `('Y','Y')` 两个条件同时为真，进入结果集；第 4 行 `('N','N')` 两个条件都不满足。最终 `product_id` 为 `1`、`3`。

```python
# 核心过滤逻辑（伪 SQL 对应 Python 写法）
rows = [
    (0, 'Y', 'N'), (1, 'Y', 'Y'), (2, 'N', 'Y'),
    (3, 'Y', 'Y'), (4, 'N', 'N'),
]
result = [
    pid for pid, low_fats, recyclable in rows
    if low_fats == 'Y' and recyclable == 'Y'
]
# result == [1, 3]
```

如果按 pandas 写，等价于：

```python
mask = (df['low_fats'] == 'Y') & (df['recyclable'] == 'Y')
result = df.loc[mask, 'product_id']
```

关键点：两个条件必须用 `and` / `&` 连接，不能写成 `or`——用 `or` 时第 0 行（`'Y','N'`）和第 2 行（`'N','Y'`）都会被放进来，结果变成 `[0, 1, 2, 3]`，多出两个错误行。

## 复杂度
时间：O(n)，n 为 `Products` 行数，每行做两次枚举比较。
空间：O(1) 额外空间（不计结果集），只维护过滤条件。

## 易错点
- 把两个条件写成 `OR`：输入示例第 0 行 `('Y','N')` 和第 2 行 `('N','Y')` 会被误收，输出变成 `[0,1,2,3]`；正确做法是 `low_fats = 'Y' AND recyclable = 'Y'`，只留 `1`、`3`。
- 枚举值写成小写 `'y'` 或布尔 `True`：`low_fats` 是枚举，取值严格为 `'Y'`/`'N'`，写成 `'y'` 时第 1 行 `('Y','Y')` 匹配失败，结果为空；必须用大写字符字面量比较。

## 如果面试官追问
追问：如果要求结果按 `product_id` 升序且去重怎么办？
答：加 `ORDER BY product_id`；主键唯一已保证无重复，无需 `DISTINCT`。
