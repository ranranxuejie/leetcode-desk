## 一句话思路
把每个词拼成 `word + "#" + word`，用字典树边插入边查询，前缀路径上的计数就是能与当前词配对的前词数量。

## 怎么做
1. 按顺序遍历 `words`，对每个 `w` 构造 `s = w + "#" + w`，在字典树里走这条路径。
2. 走路径时，每到一个节点就累加该节点的 `cnt`（表示有多少个已插入的词恰好是当前词的前缀兼后缀），走完把答案加上这个累加值。
3. 走完后，在 `s` 的末尾节点把 `cnt` 加一，表示 `w` 已插入，供后面的词查询。
4. 关键中间值：以示例 1 的 `words = ["a","aba","ababa","aa"]` 为例，插入 `"a"` 后，处理 `"aba"` 时路径 `"aba#aba"` 上只有节点 `"a"` 的 `cnt=1`，故贡献 1；处理 `"ababa"` 时路径上 `"a"` 和 `"aba"` 的 `cnt` 都是 1，贡献 2；处理 `"aa"` 时路径 `"aa#aa"` 上只有 `"a"` 的 `cnt=1`，贡献 1，合计 4。

```python
trie = {}
ans = 0
for w in words:
    s = w + "#" + w
    node, hit = trie, 0
    for ch in s:
        if ch not in node:
            node[ch] = {"cnt": 0}
        node = node[ch]
        hit += node["cnt"]
    ans += hit
    node["cnt"] += 1
```

注意 `"#"` 是分隔符，保证前缀匹配不会跨过 `w` 的边界去匹配到 `w` 的后半段。

## 复杂度
时间：O(Σ|w|)，每个词走 `2|w|+1` 步，字典树单步 O(1)。
空间：O(Σ|w|)，字典树节点数不超过所有 `w+"#"+w` 的总长度。

## 易错点
- 输入 `words = ["abab","ab"]`：若只把 `w` 本身插入字典树而不加 `"#"` 分隔，处理 `"ab"` 时路径 `"abab"` 会误匹配到 `"abab"` 的前缀 `"ab"`，错误地贡献 1；正确做法是插入 `w+"#"+w`，让 `"ab"` 的路径 `"ab#ab"` 在 `"#"` 处与 `"abab"` 分叉，答案为 0。
- 输入 `words = ["a","a","a"]`：若在查询前就把当前词插入，会把 `i=j` 的自配对算进去，得到 6 而非 3；正确顺序是先查询累加 `hit`、再 `node["cnt"] += 1`，保证只统计 `i < j`。

## 如果面试官追问
问：若 `words` 长度到 10^6 且总长不变，字典树还合适吗？
答：合适，时间仍是 O(Σ|w|)，只是节点字典的哈希开销变大，可换数组或滚动哈希。
