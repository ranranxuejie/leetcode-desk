## 一句话思路
按行做状态压缩 DP，每行用三进制掩码记录「空/内向/外向」，只和上一行交互，逐行转移取最大。

## 怎么做
1. 把列数取小的一维当宽度 `w = min(m, n)`，行数 `h = max(m, n)`，每行状态用三进制数 `0..3**w-1` 编码，第 `i` 位 0=空、1=内向、2=外向。
2. 预处理每个状态的行内幸福（含左右相邻）和该状态用掉的内向/外向人数。
3. `dfs(row, prev_mask, intro_left, extro_left)` 记忆化：枚举当前行 `cur_mask`，加上行内分、与 `prev_mask` 的上下相邻分，递归下一行。
4. 相邻分按人类型查表：内向-内向 -60，内向-外向 -10，外向-外向 +40（每对相邻各算一次）。

以示例 1 `m=2,n=3,intro=1,extro=2` 为例：`w=3`，最优 `prev_mask` 行是 `(1,0,2)`（内向、空、外向），`cur_mask` 是 `(0,0,2)`。行内分 = 120 + 40 + 40 = 200；上下相邻只有第 3 列外向-外向一对，+40，合计 240。

```python
from functools import lru_cache
w, h = min(n, m), max(n, m)
P = 3 ** w
cnt = [[0, 0] for _ in range(P)]   # [内向数, 外向数]
inner = [0] * P                    # 行内幸福
for s in range(P):
    x, t = s, 0
    row = []
    while t < w:
        row.append(x % 3); x //= 3; t += 1
    for i, v in enumerate(row):
        if v == 1: cnt[s][0] += 1; inner[s] += 120
        elif v == 2: cnt[s][1] += 1; inner[s] += 40
        if i and v and row[i-1]:
            inner[s] += -60 if v == row[i-1] == 1 else (40 if v == row[i-1] == 2 else -10)
```

## 复杂度
时间：`O(h * 3^w * 3^w * intro * extro)`，`w = min(m,n)` 决定指数，`h` 是行数。
空间：记忆化表 `O(h * 3^w * intro * extro)`，另开 `3^w` 大小的预处理数组。

## 易错点
- `m=3,n=1` 时若不交换维度，`w=3` 状态数 27 而 `h=1`，白算；正确做法是 `w=min(m,n)`，让指数落在小的一维上。
- 上下相邻分容易只算一次：外向-外向 +40 是**两人各得 20**，若写成 +20 则示例 1 得 220 而非 240；正确做法是查表值直接取 -60/-10/+40。
- 允许不填满网格，`dfs` 里枚举 `cur_mask` 必须包含 0（空行），否则 `intro=0,extro=0` 的边界会漏解。

## 如果面试官追问
问：要求输出具体摆放方案怎么办？
答：记忆化时额外存「选了哪个 `cur_mask`」，回溯时从 `(0, 0, intro, extro)` 顺着记录逐行还原三进制位即可。
