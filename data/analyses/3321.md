## 一句话思路
用两个懒删除堆把窗口内元素按「(频次, 数值)」分成前 x 大和其余，滑动时只增量维护两个堆与一个答案和。

## 怎么做
1. 维护 `cnt`（窗口内各值频次）、`top`（前 x 大的 (频次, 值) 小顶堆）、`rest`（其余的大顶堆）、`sum_top`（top 中元素的频次和）。
2. 每次进出一个值，先改 `cnt`，再把该值的新旧状态各推一次堆（旧状态靠懒删除失效）。
3. 用 `while` 把 `top` 大小修到 x：多了就弹到 `rest`，少了就从 `rest` 补；弹出时用 `cnt` 校验堆顶是否过期。
4. 修完后 `sum_top` 即当前窗口 x-sum。

以 `nums=[1,1,2,2,3,4,2,3], k=6, x=2` 首个窗口为例：`cnt={1:2,2:2,3:1,4:1}`，`top` 取 (2,2)、(2,1)，`sum_top=4`，但 x-sum 要按频次加权，实际是 `2*2+1*2=6`，所以 `sum_top` 应存「频次×数值」而非频次。

```python
import heapq
from collections import defaultdict

def push(v, c):
    heapq.heappush(top, (c, v)) if len(top) < x else heapq.heappush(rest, (-c, -v))

def clean(h, is_top):
    while h:
        c, v = h[0]
        v = v if is_top else -v
        c = c if is_top else -c
        if cnt[v] == c and ((v in top_set) == is_top):
            break
        heapq.heappop(h)
```

（`top_set` 用集合记录当前在 top 中的值，`sum_top` 在 push/pop 时同步加减 `c*v`。）

## 复杂度
时间 O(n log k)：每个元素进出堆各 O(log k)，共 n 次滑动。
空间 O(k)：`cnt`、两个堆、`top_set` 各存至多 k 个不同值。

## 易错点
- `nums=[3,8,7,8,7,5], k=2, x=2` 时若把 `sum_top` 存成频次和而非 `频次×数值`，首窗口会得 2 而非 11 → 正确做法是 push 时累加 `c*v`。
- 懒删除堆顶过期判断若只看 `cnt[v]==c`，当值 v 已移出窗口但 `cnt[v]` 恰好等于堆里旧频次时会误留 → 必须同时校验 `v in top_set` 与堆归属一致。

## 如果面试官追问
若 x 随查询变化（多次询问不同 x）怎么办？答：改用按 (频次,值) 排序的平衡树/有序容器，每次查询取前 x 大，单次 O(x) 或 O(log n + x)。
