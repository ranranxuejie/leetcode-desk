## 一句话思路
用 `run` 记录以 `i` 结尾的连续上升段长度，`run >= k` 时该窗口能量值就是 `nums[i]`。

## 怎么做
1. 初始化 `run = 1`，结果数组 `res` 长度 `n - k + 1`。
2. 遍历 `i` 从 0 到 n-1：若 `i > 0 and nums[i] == nums[i-1] + 1` 则 `run += 1`，否则 `run = 1`。
3. 当 `i >= k - 1` 时，若 `run >= k` 则 `res[i-k+1] = nums[i]`，否则填 `-1`。
4. 返回 `res`。

以 `nums = [1,2,3,4,3,2,5], k = 3` 为例：`i=2` 时 `run=3`，`res[0]=nums[2]=3`；`i=3` 时 `run=4`，`res[1]=nums[3]=4`；`i=4` 时 `nums[4]=3 != 4+1`，`run` 重置为 1，`res[2]=-1`。

```python
n = len(nums)
res = [-1] * (n - k + 1)
run = 1
for i in range(n):
    if i > 0 and nums[i] == nums[i - 1] + 1:
        run += 1
    else:
        run = 1
    if i >= k - 1 and run >= k:
        res[i - k + 1] = nums[i]
return res
```

## 复杂度
时间：O(n)，每个元素只被访问一次，`run` 的更新是 O(1)。
空间：O(n - k + 1) 存结果数组，`run` 是 O(1) 额外变量。

## 易错点
- 输入 `nums = [2,2,2,2,2], k = 4` → 若只判断 `nums[i] > nums[i-1]` 会漏掉「连续」要求，把相等元素误判为上升 → 必须用 `nums[i] == nums[i-1] + 1` 严格判断差值为 1。
- 输入 `nums = [3,2,3,2,3,2], k = 2` → 若在 `run >= k` 时填 `nums[i-1]` 而非 `nums[i]`，会错成 `[2,2,2,2,2]` → 窗口末尾是 `i`，最大元素就是 `nums[i]`，因为上升段严格递增。

## 如果面试官追问
若 k 很大而 n 到 10^5，还能 O(n) 吗？答：能，`run` 只依赖相邻差，与 k 无关，仍是 O(n)。
