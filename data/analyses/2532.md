## 一句话思路
用四个堆分别维护「左侧待出发」「右侧待过桥」「右侧取箱中」「左侧放箱中」的工人，按时间推进模拟桥的调度。

## 怎么做
1. 预处理：把工人按效率从低到高排序（`left+right` 降序，相等时下标降序），得到优先级 `order`，堆里存 `(优先级, 下标)`。
2. 初始所有工人都在左岸空闲堆 `wait_left`，时间 `t = 0`，已派往右侧的人数 `sent = 0`。
3. 循环直到 `sent == n` 且 `wait_right` 为空：先把所有 `finish <= t` 的工人从「取箱中」「放箱中」移回对应空闲堆；若 `wait_right` 非空则派它过桥（`t += left`，进入放箱堆），否则若 `sent < n` 且 `wait_left` 非空则派它去右侧（`t += right`，`sent += 1`，进入取箱堆）；否则 `t` 跳到最近一个 `finish`。
4. 每次有人从右侧过桥到左侧时，记录 `t` 作为答案（最后一个箱子到达左侧的时刻）。

以示例 1 为例：`order = [2,1,0]`（效率最低是工人 2）。`t=0` 派工人 2 去右侧，`t=1` 到达；`t=1` 取箱，`t=2` 开始过桥，`t=2+4=6` 到达左侧，答案 `6`。

```python
import heapq
order = sorted(range(k), key=lambda i: (-(time[i][2]+time[i][0]), -i))
wait_left = [(order.index(i), i) for i in range(k)]
heapq.heapify(wait_left)
wait_right, picking, putting = [], [], []
t = sent = ans = 0
while sent < n or wait_right:
    for h, i in picking:
        if h <= t: heapq.heappush(wait_right, (order.index(i), i))
    picking = [(h, i) for h, i in picking if h > t]
    for h, i in putting:
        if h <= t: heapq.heappush(wait_left, (order.index(i), i))
    putting = [(h, i) for h, i in putting if h > t]
    if wait_right:
        _, i = heapq.heappop(wait_right)
        t += time[i][2]; ans = t
        heapq.heappush(putting, (t + time[i][3], i))
    elif sent < n and wait_left:
        _, i = heapq.heappop(wait_left)
        t += time[i][0]; sent += 1
        heapq.heappush(picking, (t + time[i][1], i))
    else:
        t = min([h for h, _ in picking + putting] or [t])
```

## 复杂度
时间：每个工人最多进出堆 O(1) 次，堆操作 O(log k)，总 O((n+k) log k)。
空间：四个堆各存 O(k) 个元素，额外 O(k)。

## 易错点
- 输入 `n=3, k=2, time=[[1,5,1,8],[10,10,10,10]]`：若在 `sent == n` 后立刻退出，会漏掉最后一个箱子还在右侧过桥的工人，答案偏小；正确做法是循环条件写成 `sent < n or wait_right`，等右侧清空。
- 输入 `n=1, k=3`：若按 `left+right` 升序排优先级，会先派工人 0（效率最高）过桥，答案变成 `1+1+2=4` 而非 `6`；正确做法是按 `left+right` 降序、相等时下标降序，让效率最低的工人 2 先走。

## 如果面试官追问
问：若要求输出每个箱子由谁搬运？答：在每次从 `wait_right` 弹出工人过桥时记录 `(t, i)`，按时间顺序即为搬运方案。
