## 一句话思路
把「加正负号」转成「选一个子集取正」，用 0/1 背包数方案数。

## 怎么做
1. 设取正号的元素和为 `P`，总和 `S = sum(nums)`，则取负号的和为 `S - P`，要求 `P - (S - P) = target`，即 `P = (S + target) // 2`。
2. 若 `S + target` 为奇数或 `S < abs(target)`，直接返回 0（无解）。
3. 问题变成：从 `nums` 中选若干元素（每个最多用一次）使其和恰为 `P`，求方案数，用一维滚动数组 `dp[j]` 表示凑出和 `j` 的方案数。
4. 逆序遍历 `j` 从 `P` 到 `num`，执行 `dp[j] += dp[j - num]`，保证每个元素只用一次。

以 `nums = [1,1,1,1,1], target = 3` 为例：`S = 5`，`P = (5+3)//2 = 4`。初始化 `dp[0] = 1`，其余为 0。处理完 5 个 1 后，`dp[4] = 5`，即答案 5。

```python
S = sum(nums)
if S < abs(target) or (S + target) % 2:
    return 0
P = (S + target) // 2
dp = [0] * (P + 1)
dp[0] = 1
for num in nums:
    for j in range(P, num - 1, -1):
        dp[j] += dp[j - num]
return dp[P]
```

关键点：`dp[0] = 1` 是「什么都不选」这一种方案，不是 0；内层必须逆序，否则同一个 `num` 会被重复使用。

## 复杂度
时间：`O(n * P)`，`n = len(nums)`，`P = (S + target) // 2`，两层循环各贡献一维。
空间：`O(P)`，只开一个长度 `P + 1` 的 `dp` 数组，无额外结构。

## 易错点
- `nums = [0], target = 0` → 若把 `dp[0]` 初始化为 0 或跳过 `num = 0` 的处理，会错成 0 → 正确做法是 `dp[0] = 1`，且 `num = 0` 时内层 `range(P, -1, -1)` 仍执行 `dp[j] += dp[j]`，方案数翻倍，答案应为 2（`+0` 和 `-0`）。
- `nums = [1], target = 2` → 若不先判 `S < abs(target)`，会算出 `P = (1+2)//2 = 1` 并返回 1，实际无解 → 正确做法是先检查 `S < abs(target)` 或 `(S + target) % 2 != 0` 直接返回 0。

## 如果面试官追问
问：若 `nums` 长度增到 40、`sum` 到 10^5，还能用背包吗？
答：`O(n * P)` 会到 4×10^6 仍可接受；若 `P` 更大则改用 meet-in-the-middle，折半枚举 2^20 种子集和再配对。
