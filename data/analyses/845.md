## 一句话思路
枚举每个峰顶，向左右各扩一次找坡长，取最大值；因为山脉的峰顶唯一，枚举峰顶不重不漏。

## 怎么做
1. 遍历 `i` 从 1 到 `n-2`，只把 `arr[i-1] < arr[i] > arr[i+1]` 的位置当峰顶。
2. 从 `i` 向左走，只要 `arr[j-1] < arr[j]` 就 `j -= 1`，得到左端点。
3. 从 `i` 向右走，只要 `arr[k] > arr[k+1]` 就 `k += 1`，得到右端点。
4. 长度 `k - j + 1` 更新答案；左右都至少走一步才算真山脉。

以 `arr = [2,1,4,7,3,2,5]` 为例，`i = 3`（值 7）满足 `4 < 7 > 3`。向左：`arr[2]=4 < 7`、`arr[1]=1 < 4`、`arr[0]=2 > 1` 停，`j = 1`；向右：`7 > 3 > 2`，`arr[3]=2 < 5` 停，`k = 5`。长度 `5 - 1 + 1 = 5`，即 `[1,4,7,3,2]`。

```python
n = len(arr)
best = 0
for i in range(1, n - 1):
    if arr[i - 1] < arr[i] > arr[i + 1]:
        j = i
        while j > 0 and arr[j - 1] < arr[j]:
            j -= 1
        k = i
        while k < n - 1 and arr[k] > arr[k + 1]:
            k += 1
        best = max(best, k - j + 1)
return best
```

## 复杂度
时间：每个峰顶向两侧扩，最坏 O(n²)，n 为 `len(arr)`。
空间：O(1)，只用了 `i/j/k/best` 四个变量。

## 易错点
- `arr = [2,2,2]` → 若只判 `arr[i-1] <= arr[i] >= arr[i+1]` 就当成峰顶，会算出长度 1 甚至 3 → 必须用严格不等号，且左右各至少走一步，否则 `best` 会被单点污染。
- `arr = [0,1,2,3,4,5]` 纯递增 → 若从 `i=1` 起无条件向左扩，会把整段当山脉返回 6 → 峰顶条件 `arr[i] > arr[i+1]` 不成立就不进循环，答案应为 0。

## 如果面试官追问
问：能否一趟扫描做到 O(n)？
答：维护 `up`/`down` 两个计数器，上升时 `up += 1` 并清 `down`，下降时 `down += 1`，两者都非零时用 `up + down + 1` 更新答案。
