## 一句话思路
把路径拆成 u→lca 和 lca→v 两段，用倍增表在祖先链上二分出第一个前缀和 ≥ 总权一半的节点。

## 怎么做
1. 以 0 为根 DFS，记录 `dep`、`par[k][x]`（2^k 级祖先）和 `dist[x]`（根到 x 的边权和）。
2. 查询时 `w = dist[u] + dist[v] - 2*dist[lca]`，目标阈值 `half = (w + 1) // 2`（整数上取整，等价于 ≥ w/2）。
3. 先在 u→lca 段找：从 u 向上跳，若跳到 y 后 `dist[u] - dist[y] < half` 就继续跳，最终 `x` 是 u 侧最后一个不满足的节点，答案候选是 `par[0][x]`；若 `dist[u] - dist[lca] >= half` 则答案落在 u 侧。
4. 否则在 lca→v 段找：从 v 向上跳，条件改成 `dist[v] - dist[y] < w - half`，即从 v 侧往回退，退到第一个使 v 侧剩余量 < w-half 的位置，其父节点即答案。

示例 3 的 `[3,4]`：`lca=0`，`dist[3]=3`、`dist[4]=8`、`w=11`、`half=6`。u 侧 `dist[3]-dist[0]=3 < 6`，转 v 侧；从 4 向上跳，`dist[4]-dist[2]=3 < 11-6=5`，继续跳到 2 的父 0，`dist[4]-dist[0]=8 ≥ 5`，答案取 2。

```python
def kth_up(x, k):
    for b in range(LOG):
        if k >> b & 1:
            x = par[b][x]
    return x

# u 侧：找最远的 y 使 dist[u]-dist[y] < half
x = u
for b in range(LOG - 1, -1, -1):
    y = par[b][x]
    if y != -1 and dist[u] - dist[y] < half:
        x = y
ans = par[0][x] if dist[u] - dist[x] < half else x
```

## 复杂度
时间：预处理 O(n log n)，每个查询 O(log n)，共 O((n+q) log n)。
空间：`par` 表 O(n log n)，`dist`/`dep` 各 O(n)。

## 易错点
- 阈值写成 `w // 2`：`w=7` 时得 3，而 `dist[1]-dist[0]=7 ≥ 3` 仍对，但 `w=11` 时 `w//2=5`，节点 2 处 `8 ≥ 5` 也对——真正翻车在 `w` 为奇数且恰好卡在边界，如 `w=5` 时 `w//2=2`，前缀和 2 会被误判为满足。必须用 `(w+1)//2`。
- 忘记判断答案是否落在 u 侧：示例 3 的 `[1,2]`，`dist[1]-dist[0]=2 < 3`（half=3），若直接返回 `par[0][x]` 而不检查 `dist[u]-dist[x] < half` 的边界，会把 lca=0 当成答案，正确是 2。

## 如果面试官追问
问：若查询要求返回路径上所有满足条件的节点？答：中位节点唯一（前缀和单调递增），多解只可能出现在等号边界，需额外规定取靠 u 侧的第一个。
