## 一句话思路
用字典按 `id` 建索引，先放 `arr1` 再让 `arr2` 覆盖同名键，最后按 `id` 排序输出。

## 怎么做
1. 遍历 `arr1`，以 `obj["id"]` 为键把整个对象存进字典 `merged`。
2. 遍历 `arr2`，若 `id` 已在 `merged` 中，用 `{**merged[id], **obj}` 合并（`arr2` 的键覆盖）；否则直接存入。
3. 取 `merged.values()`，按 `id` 升序排序后返回。

以示例 2 为例：`arr1` 处理后 `merged = {1: {"id":1,"x":2,"y":3}, 2: {"id":2,"x":3,"y":6}}`；处理 `arr2` 的 `{"id":2,"x":10,"y":20}` 时，合并结果为 `{"id":2,"x":10,"y":20}`，`x`、`y` 都被覆盖；`id=3` 不在字典中，直接插入。最终排序得到 `id` 为 1、2、3 的三项。

```python
merged = {}
for obj in arr1:
    merged[obj["id"]] = obj
for obj in arr2:
    i = obj["id"]
    merged[i] = {**merged[i], **obj} if i in merged else obj
return sorted(merged.values(), key=lambda o: o["id"])
```

关键点：`{**a, **b}` 是浅合并，`b` 的同名键整体替换 `a` 的值，不做递归合并——示例 3 中 `b` 从 `{"b":94}` 变成 `{"c":84}` 正是这个语义，不是把两个字典拼起来。

## 复杂度
时间：O((n+m) + k log k)，n、m 为两数组长度，k 为唯一 id 数，排序贡献 log。
空间：O(k)，字典存 k 个对象引用，排序结果另开 O(k)。

## 易错点
- 合并顺序写反：若先遍历 `arr2` 再遍历 `arr1`，示例 2 中 `id=2` 会得到 `x=3, y=6`（`arr1` 覆盖了 `arr2`），与要求相反。正确做法是固定「先 `arr1` 后 `arr2`」，让后写入的 `arr2` 覆盖。
- 把嵌套对象当深合并：示例 3 的 `b` 若递归合并会得到 `{"b":94,"c":84}`，但期望是 `{"c":84}`。正确做法是用 `{**a, **b}` 浅合并，`arr2` 的键值整体替换。

## 如果面试官追问
若 `id` 不保证唯一、同数组内重复怎么办？答：改成按 `id` 分组后依次合并，同数组内后出现的覆盖先出现的，语义需先与面试官确认。
