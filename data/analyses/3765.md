## 一句话思路
按位拆出所有前缀和后缀，逐个用试除法判质数，任一非质数即返回 `False`。

## 怎么做
1. 把 `num` 转成字符串 `s`，长度 `n`，前缀是 `s[:k]`、后缀是 `s[n-k:]`，`k` 从 1 到 `n`。
2. 写一个 `is_prime(x)`：`x < 2` 直接 `False`，否则从 2 试到 `isqrt(x)`。
3. 对每个 `k` 同时检查前缀和后缀，一旦某个不是质数就返回 `False`。
4. 全部通过返回 `True`。

以 `num = 39` 为例：`s = "39"`，`k=1` 时前缀 `3` 是质数、后缀 `9` 不是（`9 % 3 == 0`），立刻返回 `False`，不必再算 `k=2` 的 `39`。反过来 `num = 23`：`k=1` 得 `2` 和 `3` 都是质数，`k=2` 得 `23`，试除到 `isqrt(23)=4`，`23%2`、`23%3` 都不为 0，返回 `True`。

```python
from math import isqrt

def is_prime(x):
    if x < 2:
        return False
    for d in range(2, isqrt(x) + 1):
        if x % d == 0:
            return False
    return True

s = str(num)
n = len(s)
for k in range(1, n + 1):
    if not is_prime(int(s[:k])) or not is_prime(int(s[n-k:])):
        return False
return True
```

注意 `k = n` 时前缀和后缀都是 `num` 本身，所以 `num` 自身非质数时必然被这一步拦下，不需要单独判断。

## 复杂度
时间：O(log num · √num)，`n ≤ 10` 个前缀后缀，每个试除到 `isqrt`。
空间：O(log num)，字符串 `s` 和切片产生的临时串。

## 易错点
- `num = 1` → 若 `is_prime` 只写 `x % d` 循环而漏掉 `x < 2` 判断，`1` 会被误判为质数返回 `True`；正确做法是函数第一行就 `if x < 2: return False`。
- `num = 10^9`（`s = "1000000000"`）→ 若只检查前缀不检查后缀，会漏掉末尾的 `0`、`00` 等非质数后缀而错答 `True`；正确做法是同一个 `k` 循环里前缀后缀都判，且 `k` 必须取到 `n`。

## 如果面试官追问
若 `num` 上限提到 `10^18`，试除法还够吗？答：单个前缀最大 `10^18`，试除到 `10^9` 太慢，需换 Miller-Rabin 判质数，其余枚举逻辑不变。
