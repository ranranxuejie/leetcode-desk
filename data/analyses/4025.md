## 一句话思路
把 lights 排序后，对每辆车只需看「能容纳它的最小灯」，答案就是所有车这个最小灯对应等待时间的最大值。

## 怎么做
1. 对 `lights` 升序排序，得到 `L`；对每辆车算 `r = t % period`。
2. 若 `r < L[0]`，这辆车任何灯都等 0，跳过。
3. 否则二分找第一个 `L[i] > r` 的下标 `i`（`bisect_right(L, r)`），该车最小等待是 `period - r`，且只有 `L[i]` 及更大的灯能做到；取 `L[i]` 即最优。
4. 对所有车取 `period - r` 的最大值。

以示例 1 为例：`period=8, L=[2,3]`。车 `t=11` 得 `r=3`，`bisect_right([2,3],3)=2` 越界，说明没有灯能容下它，等待只能是 `8-3=5`；车 `t=5` 得 `r=5`，同样越界，等待 `3`。最大值为 `5`。

```python
from bisect import bisect_right

L = sorted(lights)
ans = 0
for t in arrivalTime:
    r = t % period
    i = bisect_right(L, r)
    if i == len(L):
        ans = max(ans, period - r)
    # i < len(L) 时该车等待 0，不影响 ans
```

关键点：`i < len(L)` 时车能等到 0，直接忽略；只有越界（所有灯都 ≤ r）才产生 `period - r` 的等待。

## 复杂度
时间：排序 `O(m log m)`，`n` 辆车各二分 `O(n log m)`，`m = len(lights)`、`n = len(arrivalTime)`。
空间：`O(m)` 存排序后的 `L`，其余常数。

## 易错点
- 忘记排序直接按原顺序二分 → `lights=[3,6,8]` 时 `bisect_right` 结果错乱，把 `r=4` 判成越界。必须先 `sorted(lights)`。
- 把「能等到 0」的车也算进答案 → 示例 2 中 `t=4, r=4`，`L=[3,6,8]` 有 `6>4`，等待应为 0；若误取 `period-r=6` 会得 6 而非 1。判据是 `i == len(L)` 才计入。

## 如果面试官追问
问：若要求输出每辆车的具体分配方案？
答：二分得到 `i` 后，`i < len(L)` 就分给 `L[i]`，否则分给 `L[-1]`（最大灯），记录下标即可。
