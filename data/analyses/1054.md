## 一句话思路
按出现次数从多到少填偶数位再填奇数位，最多次数的元素被隔开，必然不相邻。

## 怎么做
1. 用 `Counter(barcodes)` 统计频次，按频次降序得到 `items`。
2. 先填偶数下标 `0,2,4,...`，填满后接着填奇数下标 `1,3,5,...`，用 `res` 数组按位置写入。
3. 以示例 2 `[1,1,1,1,2,2,3,3]` 为例：频次 `{1:4, 2:2, 3:2}`，排序后 `items=[(1,4),(2,2),(3,2)]`。先写偶数位得 `res[0]=1,res[2]=1,res[4]=1,res[6]=1`，再写奇数位得 `res[1]=2,res[3]=2,res[5]=3,res[7]=3`，结果 `[1,2,1,2,1,3,1,3]`，相邻均不同。
4. 关键点：最多次数的元素先占偶数位，偶数位之间至少隔一个奇数位，所以不会相邻。

```python
from collections import Counter

cnt = Counter(barcodes)
items = sorted(cnt.items(), key=lambda x: -x[1])
n = len(barcodes)
res = [0] * n
idx = 0
for val, freq in items:
    for _ in range(freq):
        res[idx] = val
        idx += 2
        if idx >= n:
            idx = 1
```

## 复杂度
时间：O(n + k log k)，n 为数组长度，k 为不同元素个数，排序贡献 log k。
空间：O(n + k)，`res` 占 n，`Counter` 占 k。

## 易错点
- 输入 `[1,1,1,2,2,2]`：若按原顺序直接填偶数位再奇数位，可能得到 `[1,1,...]` 相邻相等；必须先按频次降序排 `items`，让 `1` 先占满偶数位。
- 输入 `[1,1,1,1,2,2,3,3]`：填完偶数位后 `idx` 会超过 n，若忘记 `idx = 1` 重置，会越界或漏填奇数位；正确做法是 `idx >= n` 时切到 1。

## 如果面试官追问
追问：若要求返回字典序最小的合法排列？
答：不能只按频次贪心，需用堆每次取剩余最多且不等于前一个的元素，才能保证字典序最小。
