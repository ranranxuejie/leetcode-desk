## 一句话思路
按连续相同数字分段，每段长度 L 独立贡献方案数，答案就是各段方案数之积。

## 怎么做
1. 预处理两个 DP 数组：`f[i]` 表示长度 i 的连续串（按键含 3 个字母，如 '2'）的拆法数，`g[i]` 表示按键含 4 个字母（'7'、'9'）的拆法数。
2. 递推式：`f[i] = f[i-1] + f[i-2] + f[i-3]`，`g[i] = g[i-1] + g[i-2] + g[i-3] + g[i-4]`，因为一段可以拆成 1~3（或 1~4）个字母。
3. 扫描 `pressedKeys`，用双指针找出每段连续相同数字的长度 L，按该数字是否属于 `{'7','9'}` 取 `f[L]` 或 `g[L]`。
4. 把每段结果累乘，每步对 `10**9 + 7` 取余。

以 `pressedKeys = "22233"` 为例：第一段 `"222"` 长度 3，`f[3] = f[2]+f[1]+f[0] = 2+1+1 = 4`；第二段 `"33"` 长度 2，`f[2] = 2`；乘积 `4 * 2 = 8`，与输出一致。

```python
MOD = 10**9 + 7
n = len(pressedKeys)
f = [0] * (n + 1)
g = [0] * (n + 1)
f[0] = g[0] = 1
for i in range(1, n + 1):
    for k in range(1, 4):
        if i >= k: f[i] = (f[i] + f[i-k]) % MOD
    for k in range(1, 5):
        if i >= k: g[i] = (g[i] + g[i-k]) % MOD
ans, i = 1, 0
while i < n:
    j = i
    while j < n and pressedKeys[j] == pressedKeys[i]: j += 1
    L = j - i
    ans = ans * (g[L] if pressedKeys[i] in '79' else f[L]) % MOD
    i = j
```

## 复杂度
时间：O(n)，预处理 DP 与双指针扫描各一遍，n 为 `pressedKeys` 长度。
空间：O(n)，开了 `f`、`g` 两个长度 n+1 的数组。

## 易错点
- 把 `'7'` 和 `'9'` 也按 3 字母处理 → `"7777"` 会算成 `f[4] = 7`，实际 `g[4] = 8`（"s" 单独一种）→ 必须用 `in '79'` 分支选 `g`。
- 段与段之间用加法而非乘法 → `"22233"` 会算成 `4 + 2 = 6` 而非 8 → 各段是独立选择，必须累乘。

## 如果面试官追问
问：若要求输出所有具体文字信息而非只计数？
答：把 DP 的计数换成列表存前缀方案，回溯时对每段枚举 1~3（或 1~4）个字母拼接，复杂度变为 O(答案总数)。
