## 一句话思路
把每个字符展开成 8 位二进制后拼成串，再用双指针从两端向中间比对。

## 怎么做
1. 对 `s` 中每个字符 `c`，用 `format(ord(c), '08b')` 得到定长 8 位串，`join` 成 `bits`。
2. 设 `i = 0`、`j = len(bits) - 1`，循环条件 `i < j`。
3. 每轮比较 `bits[i]` 与 `bits[j]`，不等立即返回 `False`，相等则 `i += 1`、`j -= 1`。
4. 循环走完返回 `True`。

以 `s = "ff"` 为例：`ord('f') = 102`，`format(102, '08b')` 得 `'01100110'`，`bits = '0110011001100110'`，长度 16。首轮 `bits[0] = '0'` 与 `bits[15] = '0'` 相等，`i` 增到 1、`j` 减到 14；继续比对到 `i = 8`、`j = 7` 时退出，返回 `True`。

```python
bits = ''.join(format(ord(c), '08b') for c in s)
i, j = 0, len(bits) - 1
while i < j:
    if bits[i] != bits[j]:
        return False
    i += 1
    j -= 1
return True
```

关键点：`'08b'` 的 `0` 不能省。若写成 `'b'`，`ord('a') = 97` 只得到 `'1100001'` 七位，整串长度错位，回文判断全乱。

## 复杂度
时间 O(n)：n 为 `s` 长度，展开后串长 8n，双指针扫一半即 4n 次比较。
空间 O(n)：`bits` 占 8n 个字符，其余只有 `i`、`j` 两个整数。

## 易错点
- 输入 `s = "a"`（单字符）→ 若误以为长度 1 的串必然回文而跳过展开，会漏掉 `'01100001'` 本身不对称、应返回 `False` 的事实 → 正确做法是照常展开成 8 位再双指针，`bits[0]='0'` 与 `bits[7]='1'` 不等即返回 `False`。
- 输入 `s = "ff"` → 若用 `bin(ord(c))[2:]` 去掉前导零，`102` 得 `'1100110'` 七位，两字符拼成 14 位，`bits[0]='1'` 与 `bits[13]='0'` 不等，把正确答案 `True` 判成 `False` → 必须用 `format(..., '08b')` 补齐到 8 位。

## 如果面试官追问
问：若 `s` 长度到 10^6，怎么省空间？答：不建 `bits`，用 `(k // 8, 7 - k % 8)` 把二进制下标映射回字符位，逐位现算比较，空间降到 O(1)。
