## 一句话思路
用线段树维护每个区间的「前缀同字符长度、后缀同字符长度、最大同字符长度、左右端字符」，单点更新后根节点的最大值即答案。

## 怎么做
1. 每个节点存 `(pre, suf, best, lc, rc, len)`，`pre` 是从左端开始的同字符连续长度，`suf` 从右端，`best` 是区间内最长。
2. 合并左右孩子时，若 `left.rc == right.lc`，则 `pre` 可能跨过中点，`suf` 同理，`best` 取三者最大。
3. 每次查询做一次单点更新，取根节点 `best`。

以 `s = "babacc"` 第一次查询 `s[1] = 'b'` 为例：更新后 `s = "bbbacc"`。合并时左半 `"bbb"` 的 `rc = 'b'`，右半 `"acc"` 的 `lc = 'a'`，不相等，所以 `pre` 不跨中点，根节点 `best = max(3, 1, 1) = 3`。

```python
def merge(L, R):
    pre = L.pre
    if L.pre == L.len and L.lc == R.lc:
        pre = L.len + R.pre
    suf = R.suf
    if R.suf == R.len and R.rc == L.rc:
        suf = R.len + L.suf
    best = max(L.best, R.best)
    if L.rc == R.lc:
        best = max(best, L.suf + R.pre)
    return Node(pre, suf, best, L.lc, R.rc, L.len + R.len)
```

## 复杂度
时间：建树 `O(n)`，每次查询 `O(log n)`，共 `O((n + k) log n)`，`n` 来自字符串长度，`log n` 来自线段树高度。
空间：线段树数组 `O(n)`，额外只开了递归栈 `O(log n)`。

## 易错点
- 合并时 `pre` 跨中点的条件是 `L.pre == L.len and L.lc == R.lc`，漏掉 `L.lc == R.lc` 会把 `"ab"` 判成前缀长度 2；正确做法是两个条件都要判。
- 叶子节点 `len = 1`，`pre = suf = best = 1`；若把 `len` 初始化为 0，`L.pre == L.len` 恒成立，合并时前缀会错误地无限延伸。

## 如果面试官追问
问：如果查询是区间赋值而非单点更新怎么办？
答：线段树节点再加懒标记，合并逻辑不变，但下推时要重置子节点的 `pre/suf/best` 为区间长度。
