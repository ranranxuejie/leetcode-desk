## 一句话思路
对每个位置 i 求「以 i 结尾的最长上升子序列长度」和「以 i 开头的最长下降子序列长度」，两者之和最大的 i 就是山峰，答案 = n − (left[i] + right[i] − 1)。

## 怎么做
1. 从左往右扫，用 `tails` 数组维护上升子序列的最小结尾，`left[i] = bisect_left(tails, nums[i]) + 1`，再把 `nums[i]` 写进 `tails` 对应位置。
2. 从右往左扫同样一遍，得到 `right[i]`，表示从 i 出发向右的最长严格下降序列长度。
3. 枚举 i ∈ [1, n−2]，只保留 `left[i] > 1 and right[i] > 1` 的位置（保证山峰两侧都非空），取 `left[i] + right[i] − 1` 的最大值 `best`，返回 `n − best`。

以 `nums = [2,1,1,5,6,2,3,1]` 为例，关键中间值：`left = [1,1,1,2,3,2,3,1]`，`right = [1,1,1,3,3,2,2,1]`。i=4 时 `left[4]=3`（2,5,6）、`right[4]=3`（6,3,1），`best = 3+3−1 = 5`，答案 `8−5 = 3`，与示例一致。注意 i=3 处 `left[3]+right[3]−1 = 2+3−1 = 4`，比 i=4 小，说明山峰要选在 6 而不是 5。

```python
from bisect import bisect_left

def lis_len(seq):
    tails, res = [], []
    for x in seq:
        p = bisect_left(tails, x)
        if p == len(tails):
            tails.append(x)
        else:
            tails[p] = x
        res.append(p + 1)
    return res

left = lis_len(nums)
right = lis_len(nums[::-1])[::-1]
best = max(left[i] + right[i] - 1
           for i in range(1, len(nums) - 1)
           if left[i] > 1 and right[i] > 1)
return len(nums) - best
```

## 复杂度
时间 O(n log n)：两次 LIS 各 n 次二分，每次 log n。
空间 O(n)：`tails`、`left`、`right` 三个长度 n 的数组。

## 易错点
- 输入 `[1,3,1]` 时若不加 `left[i] > 1 and right[i] > 1` 过滤，i=0 或 i=2 会被当成山峰（`left[0]+right[0]−1 = 1`），`best` 可能取到 1 甚至更小的无效值；正确做法是只在 1 ≤ i ≤ n−2 且两侧长度都 ≥ 2 的位置更新 `best`。
- 输入 `[2,1,1,5,6,2,3,1]` 中下标 1、2 的值都是 1，若用 `bisect_right` 求 LIS，会把相等元素算进上升序列，`left` 变成 `[1,1,2,...]`，`best` 偏大、答案偏小；必须用 `bisect_left` 保证严格递增。

## 如果面试官追问
问：n 放大到 10^5 还能这么做吗？答：能，O(n log n) 的 LIS 二分解法与 n 无关，只需把 `left`/`right` 换成滚动数组省空间，时间不变。
