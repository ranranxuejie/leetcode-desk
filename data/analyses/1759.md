## 一句话思路
按连续相同字符分段，长度 L 的段贡献 L(L+1)/2 个同质子串，累加取模。

## 怎么做
1. 用 `i` 扫 `s`，`j` 从 `i` 往后推进到第一个 `s[j] != s[i]` 的位置，得到段长 `L = j - i`。
2. 该段贡献 `L * (L + 1) // 2`，累加进 `ans`，然后 `i = j`。
3. 每步对 `10**9 + 7` 取模，防止 `ans` 过大。

以 `s = "abbcccaa"` 为例：第一段 `i=0`，`j` 停在 1，`L=1`，贡献 1；第二段 `i=1`，`j` 停在 3，`L=2`，贡献 3；第三段 `i=3`，`j` 停在 6，`L=3`，贡献 6；第四段 `i=6`，`j` 到 8，`L=2`，贡献 3。合计 `1+3+6+3 = 13`。

```python
MOD = 10**9 + 7
n, i, ans = len(s), 0, 0
while i < n:
    j = i
    while j < n and s[j] == s[i]:
        j += 1
    L = j - i
    ans = (ans + L * (L + 1) // 2) % MOD
    i = j
return ans
```

关键点：`L * (L + 1) // 2` 必须先乘后除，`L` 最大 10^5，乘积约 10^10，Python 整数无溢出问题；若在 C++ 里需注意 `L*(L+1)` 用 `long long`。

## 复杂度
时间：O(n)，`i` 和 `j` 都只前进不回退，每个字符被访问常数次。
空间：O(1)，只用了 `i`、`j`、`L`、`ans` 几个变量。

## 易错点
1. 输入 `s = "zzzzz"` → 若按「每个字符单独算 1 个」会得 5，漏掉长度 ≥2 的子串 → 正确做法是整段长度 5 贡献 `5*6//2 = 15`，即段内所有长度 1..5 的子串都要算。
2. 输入 `s = "abbcccaa"` → 若在 `s[j] != s[i]` 时忘记把 `i` 跳到 `j`，会重复统计同一段 → 正确做法是每段处理完立即 `i = j`，保证每段只算一次。

## 如果面试官追问
问：若要求返回所有同质子串的起始下标列表而非计数？
答：在每段 `[i, j)` 内枚举起点 `p` 和长度 `len`，输出 `(p, p+len)`，总数仍是 O(n²) 级别，需按段分别展开。
