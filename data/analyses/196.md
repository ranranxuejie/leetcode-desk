## 一句话思路
按 email 分组取最小 id，再删掉 id 不在这个集合里的行，原地改 Person。

## 怎么做
1. 用 `groupby('email')['id'].min()` 得到每个邮箱要保留的最小 id，官方示例里得到 `{john:1, bob:2}`。
2. 用 `isin` 生成布尔掩码，标记哪些行该留：id=1 留、id=2 留、id=3 删。
3. 用 `drop` 配合 `inplace=True` 原地删除，保证直接修改 Person 表而不是返回新表。
4. 不要重新赋值 `Person = ...`，否则外部引用看不到变化。

```python
keep = Person.groupby('email', as_index=False)['id'].min()
mask = Person['id'].isin(keep['id'])
Person.drop(Person[~mask].index, inplace=True)
```

关键中间值：`keep` 是两行 `(1, john@example.com)`、`(2, bob@example.com)`；`mask` 为 `[True, True, False]`，`~mask` 取反后只删 index=2 那一行。

## 复杂度
时间 O(n)：groupby 扫一遍 n 行，isin 再扫一遍。
空间 O(k)：k 是不同邮箱数，额外存了 keep 这张小表。

## 易错点
- 输入里同一邮箱出现三次（id=1,3,5）→ 若用 `drop_duplicates(subset='email')` 默认保留首次出现，虽然本例恰好对，但表未按 id 排序时会留错行 → 正确做法是先 `sort_values('id')` 或直接用 `groupby.min()` 锁定最小 id。
- 写成 `Person = Person[mask]` → 局部变量指向新对象，驱动显示的 Person 表没变，判错 → 必须 `inplace=True` 或 `Person.drop(..., inplace=True)`。

## 如果面试官追问
问：如果要求保留最大 id 呢？
答：把 `min()` 换成 `max()`，其余掩码逻辑不变。
