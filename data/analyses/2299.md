## 一句话思路
一次遍历同时维护四个布尔标记和「当前字符是否等于前一字符」，任一条件不满足即返回 `False`。

## 怎么做
1. 先判 `len(password) < 8`，直接返回 `False`。
2. 初始化 `lower = upper = digit = special = False`，`prev = ""`。
3. 遍历每个字符 `c`：若 `c == prev` 立即返回 `False`；否则按类别置位对应标记，并令 `prev = c`。
4. 遍历结束后返回四个标记的与。

以示例 2 `"Me+You--IsMyDream"` 为例：扫到第二个 `-` 时 `c == prev == '-'`，此处直接返回 `False`，根本走不到结尾去检查 `digit` 仍为 `False`——两个缺陷中先撞上的是连续重复。

```python
special = set("!@#$%^&*()-+")
lower = upper = digit = sp = False
prev = ""
for c in password:
    if c == prev:
        return False
    if c.islower(): lower = True
    elif c.isupper(): upper = True
    elif c.isdigit(): digit = True
    elif c in special: sp = True
    prev = c
return lower and upper and digit and sp
```

注意 `c.islower()` 对 `'1'`、`'!'` 都返回 `False`，所以四个分支互不干扰，不需要额外排除。

## 复杂度
时间 O(n)：n 为 `password` 长度，每个字符只做常数次比较。
空间 O(1)：只开了 `special` 这个 12 元素的集合和 5 个标量。

## 易错点
- 输入 `"aA1!aaaa"` → 若先判完四类标记再单独扫重复，容易漏掉「重复检查要提前返回」而继续累加标记，逻辑上仍对但代码冗长易错 → 正确做法是遍历中一旦 `c == prev` 立刻 `return False`，与标记检查同轮完成。
- 输入 `"1aB!"` → 若把长度检查放在遍历之后，会先跑完循环再返回 `False`，结果虽对但掩盖了「长度不足时其余条件无意义」的语义 → 正确做法是函数第一行就判 `len(password) < 8`，示例 3 由此直接短路。

## 如果面试官追问
问：若特殊字符集合改成可配置参数怎么办？
答：把 `special` 从常量改成入参 `Set[str]`，其余逻辑不变，仍是 O(n) 单趟。
