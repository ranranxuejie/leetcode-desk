## 一句话思路
对每个 `w` 用 `w.startswith(pref)` 判断，计数即可；前缀匹配只看开头，无需遍历整串。

## 怎么做
1. 初始化计数器 `cnt = 0`。
2. 遍历 `words` 中每个字符串 `w`。
3. 若 `w.startswith(pref)` 为真，则 `cnt += 1`。
4. 返回 `cnt`。

以示例 1 为例：`words = ["pay","attention","practice","attend"]`，`pref = "at"`。遍历时 `"pay"` 的 `startswith("at")` 为 `False`；`"attention"` 前两字符正是 `"at"`，返回 `True`，`cnt` 从 0 变 1；`"practice"` 为 `False`；`"attend"` 为 `True`，`cnt` 变 2。最终返回 2。

```python
def prefix_count(words, pref):
    cnt = 0
    for w in words:
        if w.startswith(pref):
            cnt += 1
    return cnt
```

也可写成生成器求和，一行完成：

```python
def prefix_count(words, pref):
    return sum(w.startswith(pref) for w in words)
```

`startswith` 内部只比较前 `len(pref)` 个字符，遇到第一个不同字符立即返回 `False`，所以 `"practice"` 在比较第 1 个字符 `'p'` 与 `'a'` 时即终止，不会扫完 8 个字符。

## 复杂度
时间：O(Σ min(len(w), len(pref)))，最坏每个 `w` 比 `len(pref)` 个字符。
空间：O(1)，只用了 `cnt` 一个整型变量，未开额外数组。

## 易错点
1. 误用 `pref in w` 代替 `w.startswith(pref)`。输入 `words = ["practice"]`、`pref = "at"` 时，`"at" in "practice"` 为 `True`，会错计为 1；正确做法是用 `startswith`，它只匹配开头，返回 `False`。
2. 误用 `w[:len(pref)] == pref` 却写错切片边界，如写成 `w[:len(pref)-1]`。输入 `pref = "at"`、`w = "attend"` 时取到 `"a"` 与 `"at"` 不等，会漏计；正确做法是切片长度取 `len(pref)`，或直接用 `startswith` 避免手算边界。

## 如果面试官追问
若 `words` 规模升到 10^5 且需多次查询不同 `pref`，怎么办？答：把所有 `words` 建成字典树，每次查询沿 `pref` 走，路径末端节点的子树单词数即为答案，单次查询 O(len(pref))。
