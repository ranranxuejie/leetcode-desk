## 一句话思路
维护已覆盖区间 `[1, reach]`，用贪心：`nums[i] <= reach+1` 就并入扩展，否则补 `reach+1` 使区间翻倍。

## 怎么做
1. 初始化 `reach = 0`（当前能连续表示 `[1, reach]`）、`i = 0`、`ans = 0`。
2. 若 `i < len(nums) and nums[i] <= reach + 1`，则 `reach += nums[i]`、`i += 1`（该数能无缝接上）。
3. 否则补 `reach + 1`：`reach += reach + 1`、`ans += 1`（新区间变 `[1, 2*reach+1]`）。
4. 循环直到 `reach >= n`，返回 `ans`。

以 `nums = [1,3], n = 6` 为例：`reach=0` 时 `nums[0]=1 <= 1`，并入得 `reach=1`；`nums[1]=3 > 2`，补 `2`，`reach=1+2=3`、`ans=1`；`3 <= 4` 并入得 `reach=6`，已达 `n`，返回 `1`。关键中间值是补 `2` 后 `reach` 从 `1` 跳到 `3`。

```python
reach, i, ans = 0, 0, 0
while reach < n:
    if i < len(nums) and nums[i] <= reach + 1:
        reach += nums[i]
        i += 1
    else:
        reach += reach + 1
        ans += 1
return ans
```

## 复杂度
时间：`O(len(nums) + log n)`，每个数并入一次，补数使 `reach` 至少翻倍。
空间：`O(1)`，只开 `reach / i / ans` 三个变量。

## 易错点
- `nums = [1,5,10], n = 20`：若写成 `nums[i] <= reach` 才并入，`5 > 1` 会先补 `2`，多算一次；正确条件是 `nums[i] <= reach + 1`，因为 `reach+1` 正好能被新数接上。
- `nums = [1,2,2], n = 5`：若循环条件写成 `reach < n and i < len(nums)`，`reach=5` 后仍可能继续补数；正确做法是外层只判 `reach < n`，`i` 越界后走补数分支。

## 如果面试官追问
要求输出具体补了哪些数？答：在补数分支里把 `reach + 1` 追加到结果列表，其余逻辑不变。
