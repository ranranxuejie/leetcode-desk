## 一句话思路
前序遍历递归拼接，只在「有右无左」时补一对 `()`，其余空括号一律不输出。

## 怎么做
1. 空节点返回空串，作为递归出口。
2. 先写 `str(root.val)`，再判断左右子节点是否存在。
3. 左子节点存在就拼 `"(" + 左递归 + ")"`；否则若右子节点存在，必须拼 `"()"`。
4. 右子节点存在就拼 `"(" + 右递归 + ")"`。

以示例 2 `root = [1,2,3,null,4]` 为例：递归到节点 2 时，`left` 为 `None`、`right` 是值为 4 的节点，此时 `str(2)` 后先追加 `"()"`，再追加 `"(4)"`，得到 `"2()(4)"`；回到根节点 1，左串 `"2()(4)"`、右串 `"3"`，拼成 `"1(2()(4))(3)"`。

```python
def dfs(node):
    if not node:
        return ""
    s = str(node.val)
    if node.left:
        s += "(" + dfs(node.left) + ")"
    elif node.right:
        s += "()"
    if node.right:
        s += "(" + dfs(node.right) + ")"
    return s
```

关键在 `elif node.right` 这一支：它只在左空右非空时触发，正好对应题面要求保留的那一对空括号。

## 复杂度
时间 O(n)：每个节点恰好被访问一次，字符串拼接总量与节点数同阶。
空间 O(n)：递归栈深度最坏为链状 n，另加输出串本身 O(n)。

## 易错点
- 输入 `[1,2,3,null,4]` 时若写成「左空就跳过、右非空直接拼 `(4)`」，会得到 `"1(2(4))(3)"`，与示例 1 撞车、丢失结构信息；正确做法是左空且右非空时先补 `"()"` 再拼右子树。
- 输入 `[1,2,3,4]`（节点 2 只有左子 4）时若对每个空子节点都补括号，会输出 `"1(2(4)())(3()())"`；正确做法是只在 `node.left is None and node.right is not None` 时补 `()`，叶子节点和只有左子的节点都不补。

## 如果面试官追问
问：节点数到 10^5、递归会爆栈怎么办？
答：改成显式栈迭代，用栈保存 `(节点, 是否已展开)` 状态，按前序顺序压栈，拼接逻辑与递归版一致。
