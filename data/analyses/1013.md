## 一句话思路
先求总和，若不能被 3 整除直接返回 `False`；否则用一次前缀和扫描找两个等于 `total // 3` 的切点。

## 怎么做
1. 求 `total = sum(arr)`，若 `total % 3 != 0` 立即返回 `False`。
2. 令 `target = total // 3`，用 `cur` 累加前缀和，`cnt` 记录命中 `target` 的次数。
3. 从左往右扫，`cur == target` 时 `cnt += 1` 并把 `cur` 归零，`cnt == 2` 且还没到末尾就返回 `True`。
4. 扫完仍未凑够两段则返回 `False`。

以示例 1 的 `arr = [0,2,1,-6,6,-7,9,1,2,0,1]` 为例：`total = 9`，`target = 3`。扫到下标 2 时 `cur = 0+2+1 = 3`，`cnt = 1`，`cur` 归零；继续扫到下标 6 时 `cur = -6+6-7+9 = 2` 还不够，到下标 8 时 `cur = 2+1+2 = 5`……实际命中第二段是在下标 8 之前：`-6+6-7+9+1 = 3`，`cnt = 2`，剩余 `2+0+1 = 3`，返回 `True`。

```python
total = sum(arr)
if total % 3 != 0:
    return False
target = total // 3
cur = cnt = 0
for i, x in enumerate(arr):
    cur += x
    if cur == target:
        cnt += 1
        cur = 0
        if cnt == 2 and i < len(arr) - 1:
            return True
return False
```

关键在 `i < len(arr) - 1`：第三段必须非空，第二段命中后若已到末尾，说明第三段是空的，不能算成功。

## 复杂度
时间：O(n)，一次求和加一次扫描，各扫 n 个元素。
空间：O(1)，只用了 `total`、`target`、`cur`、`cnt` 四个变量。

## 易错点
- `arr = [0,0,0,0]` 这类全零输入 → 若不加 `i < len(arr) - 1` 判断，会在下标 1 就 `cnt == 2` 返回 `True`，但此时第三段为空 → 正确做法是命中第二段后必须确认后面还有元素。
- `arr = [1,-1,1,-1,1,-1]` → `total = 0`，`target = 0`，前缀和频繁归零，容易把 `cnt` 数多或提前返回 → 正确做法是严格只在 `cur == target` 时计数，且 `cnt` 到 2 就停，不要继续累加。

## 如果面试官追问
要求输出具体切分下标而非布尔值？答：把 `cnt == 1` 和 `cnt == 2` 时的 `i` 记下来，返回 `(i1, i2)`，判断条件不变。
