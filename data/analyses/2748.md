## 一句话思路
从左到右扫，用长度 10 的计数数组记「已出现过的 nums[i] 首位」，对每个 nums[j] 的末位累加互质计数。

## 怎么做
1. 预处理 `first[d]`：把每个数 `x` 的首位取出来（`while x >= 10: x //= 10`），末位是 `x % 10`。
2. 维护 `cnt[1..9]`，表示当前 j 之前所有元素的首位出现次数。
3. 对每个 j，先枚举 d=1..9，若 `gcd(d, nums[j] % 10) == 1` 就累加 `cnt[d]`，再把 `nums[j]` 的首位计入 `cnt`。
4. 顺序不能反：先统计后加入，保证 i < j。

以 `nums = [2,5,1,4]` 为例：j=0 时 cnt 全 0，加首位 2；j=1 末位 5，d=2 时 gcd(2,5)=1，ans=1，加首位 5；j=2 末位 1，d=2、5 都互质，ans=3，加首位 1；j=3 末位 4，d=1、5 互质（gcd(2,4)=2 不算），ans=5。

```python
from math import gcd

cnt = [0] * 10
ans = 0
for x in nums:
    last = x % 10
    first = x
    while first >= 10:
        first //= 10
    for d in range(1, 10):
        if cnt[d] and gcd(d, last) == 1:
            ans += cnt[d]
    cnt[first] += 1
```

## 复杂度
时间：O(n × 9 × log 10)，n 来自遍历 nums，log 来自 gcd 与取首位。
空间：O(1)，只开了长度 10 的 cnt。

## 易错点
- 把 `cnt[first] += 1` 写在累加之前 → 对 `[2,5,1,4]` 的 j=0 会把自己算进去，答案偏大；必须先查后加。
- 首位取法写成 `x % 10` 或 `str(x)[0]` 混用 → 对 `11` 首位末位都是 1 看不出错，但 `21` 首位是 2 末位是 1，写成末位会漏掉 i=0,j=1 这组；用 `while first >= 10: first //= 10`。

## 如果面试官追问
若 nums 长度放大到 10^5 且值域不变？答：本解法已是 O(9n)，瓶颈只在遍历，直接可用，无需改结构。
