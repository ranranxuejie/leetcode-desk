## 一句话思路
把「选一段乘 k / 除 k」拆成对每个位置独立选三种取值，再用 Kadane 求最大子段和。

## 怎么做
1. 对每个 `nums[i]` 算出三个候选值：原值 `x`、`x*k`、`x//k`（Python 的 `//` 对负数正是向下取整，但题目要求负数向上取整，所以负数要用 `-((-x)//k)`）。
2. 关键观察：操作子数组必须连续，但求和子数组可以不同，所以只要每个位置能独立取到最优值，全局最大子段和就等于在「逐位取最优」的数组上跑 Kadane——因为对任意求和区间，逐位取最大值不会让区间和变小。
3. 于是构造 `best[i] = max(x, x*k, div(x))`，再跑标准 Kadane：`cur = max(best[i], cur + best[i])`，`ans = max(ans, cur)`。
4. 用示例 1 验证：`nums=[1,-2,3,4,-5], k=2`，`best=[2,-1,6,8,-5]`（-2 除 2 向上取整得 -1，乘 2 得 -4，原值 -2 最大是 -1），Kadane 跑到 `6,8` 时 `cur=14`，答案 14。

```python
def div(x, k):
    return x // k if x >= 0 else -((-x) // k)

cur = ans = None
for x in nums:
    b = max(x, x * k, div(x, k))
    cur = b if cur is None else max(b, cur + b)
    ans = b if ans is None else max(ans, cur)
return ans
```

注意 `cur` 初值不能设 0，否则全负数数组（示例 2）会错答 0；示例 2 的 `best=[-2,-2,-1]`，Kadane 得 -1。

## 复杂度
时间 O(n)：每个元素算 3 个候选值加一次 Kadane，k 不参与循环。
空间 O(1)：只维护 `cur`、`ans`，不建 `best` 数组。

## 易错点
- 输入 `nums=[-5,-4,-3], k=2` → 若用 `x//k` 直接除，-3//2 得 -2（向下取整），而题目要求负数向上取整得 -1，答案会错成 -2；正确写法是 `-((-x)//k)`。
- 输入全负数如 `[-1,-1], k=1` → 若 `cur` 初值设 0 或 `ans` 初值设 0，会返回 0，但子数组非空，正确答案是 -1；正确做法是 `cur`、`ans` 都用第一个 `best` 值初始化。

## 如果面试官追问
问：如果要求输出具体操作区间和求和区间怎么办？
答：Kadane 时记录 `cur` 的起点，`ans` 更新时记下求和区间；操作区间取每个 `best[i]` 对应 `max` 的那个候选来源，合并相邻同源位置即可。
