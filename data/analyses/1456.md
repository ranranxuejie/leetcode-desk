## 一句话思路
定长窗口滑动，窗口内元音数只随进出两个字符变化，故一次遍历即可取最大。

## 怎么做
1. 先统计 `s[0:k]` 的元音数作为初始 `cur`，`ans = cur`。
2. 窗口右移一位：新进 `s[i]`、移出 `s[i-k]`，各自判断是否元音，`cur += 进 - 出`。
3. 每步用 `cur` 更新 `ans`，遍历到 `i = len(s)-1` 结束。

以 `s = "abciiidef", k = 3` 为例：初始窗口 `"abc"` 只有 `a` 是元音，`cur = 1`。移到 `i=3` 时进 `i`（元音）、出 `a`（元音），`cur = 1 + 1 - 1 = 1`；再移到 `i=4` 进 `i`、出 `b`，`cur = 1 + 1 - 0 = 2`；`i=5` 进 `i`、出 `c`，`cur = 3`，此时 `ans` 被更新为 3。

```python
vowels = set("aeiou")
cur = sum(c in vowels for c in s[:k])
ans = cur
for i in range(k, len(s)):
    cur += (s[i] in vowels) - (s[i - k] in vowels)
    ans = max(ans, cur)
return ans
```

注意 `(s[i] in vowels)` 是 `bool`，Python 里 `True - False` 直接当 1/0 用，省掉 if 分支。

## 复杂度
时间：O(n)，`n = len(s)`，每个字符最多被进、出各判一次。
空间：O(1)，`vowels` 是固定 5 元素集合，`cur`/`ans` 两个整数。

## 易错点
1. `k == len(s)` 时 → 若把循环写成 `for i in range(k, len(s))` 却忘了先算初始窗口，会直接返回未定义的 `ans` 或 0；正确做法是先算 `s[:k]` 的 `cur` 并赋给 `ans`，循环体一次不执行也能返回正确答案（如 `s="aeiou", k=5` 返回 5）。
2. 移出字符的下标写成 `s[i-k+1]` → 窗口长度会变成 `k+1`，在 `s="leetcode", k=3` 上会多算一个字符导致结果偏大；正确下标是 `s[i-k]`，因为新窗口是 `[i-k+1, i]`，被挤出的正是 `i-k`。

## 如果面试官追问
问：若要求返回元音数最大的那个子串本身？
答：`ans` 更新时同步记下 `i-k+1` 作为起点，最后切片 `s[start:start+k]` 即可，复杂度不变。
