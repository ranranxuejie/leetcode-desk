## 一句话思路
num ≤ 1000，直接枚举 1..num，对每个数反复取模求各位数字和，判断奇偶即可。

## 怎么做
1. 外层 `for x in range(1, num + 1)` 枚举每个正整数。
2. 内层用 `t = x` 拷贝一份，`while t: s += t % 10; t //= 10` 累加各位数字。
3. `s % 2 == 0` 时计数加一。

以 `num = 30` 为例：枚举到 `x = 19` 时，`t` 依次取 19→1→0，`s = 9 + 1 = 10`，`10 % 2 == 0`，计入；枚举到 `x = 21` 时 `s = 1 + 2 = 3`，奇数，跳过。最终累加得 14。

```python
count = 0
for x in range(1, num + 1):
    t, s = x, 0
    while t:
        s += t % 10
        t //= 10
    if s % 2 == 0:
        count += 1
return count
```

关键点：`t = x` 必须另开变量，直接改 `x` 会破坏外层循环的枚举值。

## 复杂度
时间：O(num · log num)，每个数拆位代价是位数，num ≤ 1000 时约 4000 次内层迭代。
空间：O(1)，只用了 `count`、`t`、`s` 三个标量。

## 易错点
- `num = 1` → 若循环写成 `range(1, num)` 会漏掉 1 本身，返回 0；正确是 `range(1, num + 1)`，1 的 digit sum 为 1（奇数）不计入，答案 0 但路径要对。
- 内层写成 `while x:` 直接改 `x` → 外层 `range` 虽不受影响（range 已生成序列），但若改成 `while` 外层或复用 `x` 做后续判断就会拿到 0；正确做法是 `t = x` 单独拆位。

## 如果面试官追问
若 num 放大到 10^9 怎么优化？答：按数位 DP 统计「digit sum 奇偶」两种状态，O(log num) 出结果，不必枚举。
