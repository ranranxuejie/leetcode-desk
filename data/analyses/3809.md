## 一句话思路
一次线性扫描，对每座塔算曼哈顿距离筛出可到达的，再用 (q, -x, -y) 三元组比较取最优。

## 怎么做
1. 初始化 `best_q = -1`、`best = [-1, -1]`，用 `best_q = -1` 表示「还没有可到达的塔」。
2. 遍历 `towers`，对每个 `[x, y, q]` 算 `d = abs(x - cx) + abs(y - cy)`。
3. 若 `d <= radius`，用 `(q, -x, -y)` 与当前最优的 `(best_q, -best[0], -best[1])` 比较，更大就更新。
4. 扫描结束返回 `best`；若从未更新过，`best` 仍是 `[-1, -1]`。

以示例 2 为例：`center = [0,0]`、`radius = 5`。塔 `[1,3,4]` 的 `d = 1+3 = 4`，可到达，`best` 变为 `[1,3]`、`best_q = 4`；塔 `[2,2,4]` 的 `d = 4`，比较 `(4,-2,-2)` 对 `(4,-1,-3)`，前者更小，不更新；塔 `[4,4,7]` 的 `d = 8 > 5`，直接跳过。最终返回 `[1,3]`。

```python
best_q, best = -1, [-1, -1]
for x, y, q in towers:
    if abs(x - center[0]) + abs(y - center[1]) <= radius:
        if (q, -x, -y) > (best_q, -best[0], -best[1]):
            best_q, best = q, [x, y]
return best
```

关键在 `(q, -x, -y)` 这个元组：`q` 大者优先，`q` 相同时 `-x` 大意味着 `x` 小，`-x` 也相同则 `-y` 大意味着 `y` 小，正好是字典序最小。

## 复杂度
时间 O(n)，n 为 `towers` 长度，每座塔只做常数次比较。
空间 O(1)，只存 `best_q` 和 `best` 两个变量。

## 易错点
- 并列时直接写 `if q > best_q` 更新 → 示例 2 中 `[2,2,4]` 会覆盖 `[1,3]`，返回 `[2,2]` → 必须把坐标纳入比较，用 `(q, -x, -y)` 或显式写 `q > best_q or (q == best_q and (x, y) < tuple(best))`。
- 用 `best_q = 0` 初始化 → 若所有可到达塔的 `q` 都是 0（`q` 允许为 0），条件 `q > best_q` 永不成立，返回 `[-1,-1]` 而非真实坐标 → 用 `-1` 初始化，因为 `q >= 0`。

## 如果面试官追问
若 `towers` 涨到 10^7 且多次查询不同 `center`/`radius`，怎么办？
答：预处理按 `x+y` 和 `x-y` 建结构，把曼哈顿菱形转成切比雪夫方形做范围查询，单次查询 O(log n)。
