## 一句话思路
用栈模拟：新字符与栈顶能配对就弹出栈顶，否则入栈，因为「最左」的删除顺序恰好等价于从左到右扫描。

## 怎么做
1. 初始化空栈 `st`，从左到右遍历 `s` 的每个字符 `c`。
2. 若 `st` 非空且 `st[-1]` 与 `c` 在字母表上相邻（含 `a`/`z` 环绕），弹出 `st[-1]`，否则把 `c` 压栈。
3. 遍历结束后 `''.join(st)` 即答案。

以 `s = "adcb"` 为例：`a` 入栈 → `d` 入栈 → `c` 与栈顶 `d` 相邻，弹出，栈变 `['a']` → `b` 与栈顶 `a` 相邻，弹出，栈变空，返回 `""`。关键中间值：处理到 `c` 时栈从 `['a','d']` 变成 `['a']`，说明删除后新暴露的相邻对会被后续字符自然接上，无需回头重扫。

判断相邻用 `abs(ord(st[-1]) - ord(c))` 是否为 `1` 或 `25`（`25` 对应 `a`/`z`）。

```python
st = []
for c in s:
    if st and abs(ord(st[-1]) - ord(c)) in (1, 25):
        st.pop()
    else:
        st.append(c)
return ''.join(st)
```

## 复杂度
时间 O(n)：每个字符最多入栈、出栈各一次，n 为 `s` 长度。
空间 O(n)：`st` 最坏存下全部字符。

## 易错点
- 输入 `"za"` → 若只判断 `abs` 差为 `1`，会漏掉环绕对，错成 `"za"`；正确做法是把差值 `25` 也算相邻，返回 `""`。
- 输入 `"abba"` → 若先删最左 `"ab"` 后不重新检查新相邻对，会错成 `"ba"`；栈写法在 `b` 入栈后遇到第二个 `b` 时差值为 `0` 不弹，再遇 `a` 与栈顶 `b` 相邻弹出，最终 `""`，靠「弹栈后栈顶自动成为新邻居」保证正确。

## 如果面试官追问
若要求输出所有删除顺序的方案数？答：删除结果唯一但顺序可不同，可用区间 DP 统计，规模需降到 n ≤ 500。
