## 一句话思路
定长窗口滑动：维护长度 k 的窗口和，最大和除以 k 就是最大平均数。

## 怎么做
1. 先算 `nums[0:k]` 的和作为初始窗口和 `window`，同时记 `best = window`。
2. 从 `i = k` 开始右移：`window += nums[i] - nums[i-k]`，一次加减完成进出。
3. 每步用 `best = max(best, window)` 更新，最后返回 `best / k`。

以 `nums = [1,12,-5,-6,50,3], k = 4` 为例：初始 `window = 1+12-5-6 = 2`，`best = 2`；`i = 4` 时 `window = 2 + 50 - 1 = 51`，`best` 变 51；`i = 5` 时 `window = 51 + 3 - 12 = 42`，`best` 仍为 51；返回 `51/4 = 12.75`。

```python
window = sum(nums[:k])
best = window
for i in range(k, len(nums)):
    window += nums[i] - nums[i - k]
    if window > best:
        best = window
return best / k
```

关键点：比较的是**和**不是平均数，省掉 k 次除法；只在最后除一次，避免浮点误差累积。

## 复杂度
时间 O(n)：每个元素最多进出窗口各一次。
空间 O(1)：只开了 `window`、`best`、`i` 三个变量。

## 易错点
- `nums = [-1]`、`k = 1` → 若把 `best` 初始化为 0，会错答 0.0 → 必须用 `best = sum(nums[:k])` 初始化，负数数组才不会被 0 压住。
- `nums` 全为 `-10^4`、`k = n = 10^5` → 若用 `window / k` 逐步比较平均数，浮点误差在 10^-5 边界可能翻转判断 → 全程用整数和比较，最后才做一次除法。

## 如果面试官追问
追问：要求返回该子数组的起始下标怎么办？
答：把 `best` 换成 `best_start`，在 `window > best` 时同步记 `i - k + 1`。
