## 一句话思路
先求每行最小值、每列最大值，再扫一遍矩阵找同时满足两者的元素。

## 怎么做
1. 用 `row_min[i] = min(matrix[i])` 记录第 i 行最小值。
2. 用 `col_max[j] = max(matrix[i][j] for i in range(m))` 记录第 j 列最大值。
3. 双重循环遍历 `matrix[i][j]`，若 `matrix[i][j] == row_min[i] and matrix[i][j] == col_max[j]`，加入答案。

以示例 1 `[[3,7,8],[9,11,13],[15,16,17]]` 为例：`row_min = [3, 9, 15]`，`col_max = [15, 16, 17]`。扫到 `matrix[2][0] = 15` 时，`15 == row_min[2]` 且 `15 == col_max[0]`，命中；其余位置如 `matrix[0][0] = 3` 虽等于 `row_min[0]`，但 `3 != col_max[0] = 15`，不成立。

```python
m, n = len(matrix), len(matrix[0])
row_min = [min(matrix[i]) for i in range(m)]
col_max = [max(matrix[i][j] for i in range(m)) for j in range(n)]
ans = []
for i in range(m):
    for j in range(n):
        if matrix[i][j] == row_min[i] and matrix[i][j] == col_max[j]:
            ans.append(matrix[i][j])
return ans
```

关键点：因为元素各不相同，每行最小值唯一、每列最大值唯一，所以一个位置只需比较值是否相等，不用额外记录下标。

## 复杂度
时间 O(m·n)：求行最小 O(m·n)、求列最大 O(m·n)、扫描 O(m·n)。
空间 O(m+n)：`row_min` 长 m、`col_max` 长 n，答案列表最多 min(m,n) 个。

## 易错点
- 输入 `[[7,8],[1,2]]`：若只判断「行最小」就返回，会把 7 和 1 都算进去，但 1 所在列 `[8,2]` 的最大值是 8，1 不是列最大。必须两个条件同时用 `and` 连接，缺一不可。
- 输入 `[[3,7,8],[9,11,13],[15,16,17]]`：若把列最大值误写成「当前行之前的最大值」或按行方向取 max，`col_max[0]` 会算成 9 而非 15，导致 15 被漏掉。求列最大必须固定 j、遍历所有 i。

## 如果面试官追问
问：若矩阵元素允许重复，还能这样写吗？
答：不能直接比值，需先记录每行最小值的列下标集合，再验证该列最大值是否等于它，且重复时可能一行有多个最小值。
