## 一句话思路
用 `len[i]` 记以 `i` 结尾的 LIS 长度、`cnt[i]` 记其条数，O(n²) 双指针转移，最后按最大长度汇总。

## 怎么做
1. 初始化 `len = [1]*n`、`cnt = [1]*n`，每个元素自成长度 1 的序列。
2. 对每个 `i`，扫 `j < i`，只处理 `nums[j] < nums[i]`（严格递增，等号排除）。
3. 若 `len[j] + 1 > len[i]`，则 `len[i] = len[j] + 1`、`cnt[i] = cnt[j]`；若相等则 `cnt[i] += cnt[j]`。
4. 取 `best = max(len)`，返回所有 `len[i] == best` 的 `cnt[i]` 之和。

以 `[1,3,5,4,7]` 为例：处理 `i=3`（值 4）时，`j=0`（1）给出 `len=2,cnt=1`，`j=1`（3）给出 `len=3,cnt=1`，`j=2`（5）不满足 `5<4` 跳过，故 `len[3]=3, cnt[3]=1`。处理 `i=4`（7）时，`j=1` 与 `j=2` 都给出 `len=4`，`cnt[4]` 累加成 2，正是答案。

```python
n = len(nums)
len_ = [1] * n
cnt = [1] * n
for i in range(n):
    for j in range(i):
        if nums[j] < nums[i]:
            if len_[j] + 1 > len_[i]:
                len_[i] = len_[j] + 1
                cnt[i] = cnt[j]
            elif len_[j] + 1 == len_[i]:
                cnt[i] += cnt[j]
best = max(len_)
return sum(cnt[i] for i in range(n) if len_[i] == best)
```

## 复杂度
时间 O(n²)：外层 `i` 与内层 `j` 各贡献 n，n ≤ 2000 可过。
空间 O(n)：只开 `len_`、`cnt` 两个长度 n 的数组。

## 易错点
- 输入 `[2,2,2,2,2]` → 若写成 `nums[j] <= nums[i]`，会把相等的 2 串成一条长度 5 的「递增」序列，答案错成 1；必须用严格 `<`，此时每个 `len[i]` 停在 1，`cnt` 全为 1，求和得 5。
- 输入 `[1,3,5,4,7]` → 若在 `len_[j]+1 == len_[i]` 时只保留 `cnt[j]` 而不累加，`cnt[4]` 会停在 1，答案错成 1；相等分支必须 `cnt[i] += cnt[j]`，才能把经 5 和经 4 的两条路径都算上。

## 如果面试官追问
问：n 放大到 10⁵ 怎么办？
答：把 `len`/`cnt` 挂到按值离散化后的树状数组上，查询前缀最大值及其计数，O(n log n)。
