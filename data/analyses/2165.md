## 一句话思路
把数字拆成字符排序，正数把最小非零位提到首位、负数降序拼接，符号单独处理。

## 怎么做
1. 取绝对值转字符串 `s = str(abs(num))`，排序得 `digits`。
2. 正数：升序后找第一个非 `'0'` 的字符换到下标 0，其余保持升序。
3. 负数：直接 `sorted(s, reverse=True)` 拼接，因为绝对值越大原数越小。
4. 结果乘回符号，`int()` 转换后返回。

以 `num = -7605` 为例：`s = "7605"`，降序得 `['7','6','5','0']`，拼接 `"7650"`，乘 `-1` 得 `-7650`。正数 `310`：升序 `['0','1','3']`，第一个非零是 `'1'`（下标 1），与下标 0 交换得 `['1','0','3']`，拼成 `103`。

```python
s = str(abs(num))
if num >= 0:
    d = sorted(s)
    i = next(i for i, c in enumerate(d) if c != '0')
    d[0], d[i] = d[i], d[0]
    res = int(''.join(d))
else:
    res = -int(''.join(sorted(s, reverse=True)))
return res
```

注意 `num = 0` 时走正数分支，`d = ['0']`，`next` 找不到非零字符会抛 `StopIteration`，需特判 `if num == 0: return 0`。

## 复杂度
时间：O(L log L)，L 为位数（≤16），排序主导。
空间：O(L)，存字符列表和拼接字符串。

## 易错点
- 输入 `num = 0` → `next(...)` 抛 `StopIteration` → 开头加 `if num == 0: return 0`。
- 输入 `num = -10` → 降序拼成 `"-10"` 看似有前导零问题，实际 `-10` 的 `'0'` 在末尾合法；但若误用正数逻辑对负数做「非零前置」，会得到 `-01` 即 `-1`，错。负数分支绝不能做前导零交换。

## 如果面试官追问
问：若要求返回字符串而非整数，且 num 可达 10^1000？
答：跳过 `int()` 转换，直接返回拼接后的字符串，正数分支逻辑不变。
