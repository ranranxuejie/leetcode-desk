## 一句话思路
对每个左端点，用前缀和余数判断「删掉任一元素后剩余和 ≡ 0 (mod k)」是否恒成立，滑动窗口取最长。

## 怎么做
1. 设前缀和 `pre[i] = sum(nums[:i])`，子数组 `[l, r)` 的和为 `S = pre[r] - pre[l]`。
2. 删掉 `nums[i]` 后剩余和为 `S - nums[i]`，要求 `(S - nums[i]) % k == 0`，即 `nums[i] % k == S % k` 对所有 `i in [l, r)` 成立。
3. 于是条件等价于：子数组内所有元素模 k 的余数都等于 `S % k`——即子数组内元素余数全相同，且该余数等于子数组和的余数。
4. 枚举左端点 `l`，向右扩展 `r`，维护当前余数 `rem = nums[l] % k` 和和 `S`；一旦 `nums[r] % k != rem` 就停，检查 `S % k == rem` 更新答案。

以示例 1 `nums = [2,4,6,3], k = 2` 为例：`l=0` 时余数全为 0，`S=12`，`12 % 2 == 0`，长度 3 成立；扩到 `3` 时 `3 % 2 = 1 != 0` 停止，答案 3。

```python
n = len(nums)
ans = 1
for l in range(n):
    rem = nums[l] % k
    S = 0
    for r in range(l, n):
        if nums[r] % k != rem:
            break
        S += nums[r]
        if S % k == rem:
            ans = max(ans, r - l + 1)
```

注意内层 `break` 后不再检查，因为余数一旦不同，更长的窗口必然也含该异类元素。

## 复杂度
时间：O(n²)，外层 n 个左端点，内层最多扩到 n，`n ≤ 2500` 可过。
空间：O(1)，只用了 `rem`、`S`、`ans` 几个标量，没开额外数组。

## 易错点
- 输入 `nums = [5,5,4,8], k = 4`：若只判断「子数组和能被 k 整除」就返回 4，错；`[5,5]` 的和 10 不被 4 整除但真正卡住的是删掉一个 5 剩 5 不被 4 整除。正确做法是逐元素比 `nums[i] % k == S % k`，`5 % 4 = 1` 而 `10 % 4 = 2`，不等即淘汰。
- 输入 `nums = [1], k = 3`：若把长度 1 当特例跳过，会返回 0；题面规定剩余和为 0 可整除，`ans` 初值必须设 1，且 `S % k == rem` 对单元素恒成立（`1 % 3 == 1`）。

## 如果面试官追问
若 n 放大到 10^5 怎么办？答：按余数分组，每组内用前缀和余数相等找最长区间，O(n) 扫一遍。
