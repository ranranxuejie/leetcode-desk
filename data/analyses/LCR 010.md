## 一句话思路
用前缀和加哈希表：`pre[j] - pre[i] == k` 等价于 `pre[i] == pre[j] - k`，边扫边查表计数。

## 怎么做
1. 维护 `pre`（当前前缀和）和 `cnt = {0: 1}`（空前缀出现 1 次，覆盖从下标 0 开始的子数组）。
2. 遍历 `nums`，先 `pre += x`，再 `ans += cnt.get(pre - k, 0)`。
3. 最后 `cnt[pre] = cnt.get(pre, 0) + 1`，把当前前缀和登记进表。

以 `nums = [1,1,1], k = 2` 为例：扫到第 2 个 1 时 `pre = 2`，查 `pre - k = 0`，表里 `cnt[0] = 1`，`ans` 变 1；扫到第 3 个 1 时 `pre = 3`，查 `pre - k = 1`，表里 `cnt[1] = 1`（第 1 个 1 之后登记过），`ans` 变 2。

```python
cnt = {0: 1}
pre = ans = 0
for x in nums:
    pre += x
    ans += cnt.get(pre - k, 0)
    cnt[pre] = cnt.get(pre, 0) + 1
return ans
```

关键顺序：**先查表再登记**。若先登记 `cnt[pre]`，当 `k == 0` 时会把当前前缀和自己配对，凭空多算一个空子数组。

## 复杂度
时间 O(n)：一次遍历，哈希表均摊 O(1) 查询插入。
空间 O(n)：最坏 `cnt` 存 n+1 个不同前缀和。

## 易错点
1. `nums = [1,-1,1], k = 0` → 若漏掉 `cnt = {0: 1}` 的初始化，会漏掉 `[1,-1]` 这个从头开始的子数组，答案错成 0 而非 1；正确做法是循环前就把空前缀和 0 记一次。
2. `nums = [1], k = 0` → 若把 `cnt[pre] += 1` 写在 `ans += ...` 之前，当前前缀会和自己匹配，答案错成 1 而非 0；正确做法是严格保持「查表 → 累加 → 登记」的顺序。

## 如果面试官追问
问：要求输出所有和为 k 的子数组下标区间怎么办？
答：哈希表 value 从计数改成存前缀和出现的下标列表，命中时枚举列表里每个 `i`，输出 `[i, j-1]`。
