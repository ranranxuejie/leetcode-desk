## 一句话思路
从 1 到 n 顺序枚举 i，用 `n % i == 0` 计数，第 k 次命中就返回 i。

## 怎么做
1. 令 `cnt = 0`，`i` 从 1 遍历到 n。
2. 若 `n % i == 0`，则 `cnt += 1`。
3. 一旦 `cnt == k`，立即返回 `i`。
4. 循环结束仍未返回，说明因子不足 k 个，返回 `-1`。

以 `n = 12, k = 3` 为例：i=1 时 `12 % 1 == 0`，cnt 变 1；i=2 时 cnt 变 2；i=3 时 cnt 变 3，恰好等于 k，直接返回 3。后面 4、6、12 根本不用看，这就是提前返回省下的工作。

```python
cnt = 0
for i in range(1, n + 1):
    if n % i == 0:
        cnt += 1
        if cnt == k:
            return i
return -1
```

进阶版用 `i * i <= n` 只枚举到 `isqrt(n)`：小因子按升序先数，若 k 落在前半段直接返回；否则把大因子 `n // i` 收集起来，注意完全平方数时 `i == n // i` 只算一次，再从大到小取第 `k - cnt` 个。n ≤ 1000 时两种写法都过，但进阶版是面试官真正想听的。

## 复杂度
时间：基础版 O(n)，进阶版 O(√n)，来自枚举因子候选。
空间：基础版 O(1)；进阶版存大因子列表，最坏 O(√n)。

## 易错点
- `n = 4, k = 4` → 若只数到 `i * i <= n` 就结束并返回 -1，会漏掉因子 4 本身，错成 -1 而正确答案也是 -1 但原因不对；更危险的是 `n = 16, k = 5`，前半段只数到 1、2、4 共 3 个，必须把 8、16 补上才能取到第 5 个，正确做法是显式处理 `i * i == n` 时大因子不重复计数。
- `n = 1, k = 1` → 若循环写成 `range(2, n + 1)` 或从 2 开始枚举，会直接返回 -1；正确做法是从 1 开始，因为 1 是任何正整数的因子，`1 % 1 == 0` 成立。

## 如果面试官追问
问：n 放大到 10^12 还能这么做吗？
答：不能枚举到 n，改用 `i * i <= n` 的 O(√n) 版本，10^12 只需 10^6 次取模。
