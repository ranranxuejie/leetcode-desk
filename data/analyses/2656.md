## 一句话思路
每次取当前最大值 m 得 m 分，取完变成 m+1 仍是最大值，所以答案只由 `max(nums)` 决定，与其余元素无关。

## 怎么做
1. 取 `m = max(nums)`，这是第一次能拿到的分。
2. 之后每次选中的都是上一轮加一后的值，得分序列是 `m, m+1, ..., m+k-1`。
3. 用等差数列求和：`k * m + k * (k - 1) // 2`，一次算完，不用真的循环 k 次。

以 `nums = [1,2,3,4,5], k = 3` 为例：`m = 5`，得分序列 `5, 6, 7`，中间值 `k*(k-1)//2 = 3`，结果 `3*5 + 3 = 18`，和示例一致。注意 `nums` 里其余元素 `1,2,3,4` 全程没被碰过，因为任何一次改选它们都会让当轮得分变小，而它们也不会因为别人变大而变得更有用。

```python
m = max(nums)
return k * m + k * (k - 1) // 2
```

如果面试官要求真的模拟，也可以写成循环，但没必要：

```python
m = max(nums)
score = 0
for i in range(k):
    score += m + i
return score
```

两版结果相同，第一版是 O(1) 加法，第二版是 O(k)。

## 复杂度
时间：O(n)，`max(nums)` 扫一遍数组，n 是 `len(nums)`；求和是 O(1)。
空间：O(1)，只用了 `m` 和结果两个变量，没有额外数组。

## 易错点
- `nums = [5,5,5], k = 2` → 若误以为每次只能从「原数组剩余元素」里选，会算成 5+5=10，漏掉第二轮已经变成 6 的那个元素 → 正确做法是记住被选元素加一后仍在数组中，第二轮取 6，答案 11。
- `k = 100, nums = [100]` → 若用 `k * m + k * (k - 1) // 2` 但把 `// 2` 写成 `/ 2`，会得到浮点数 `10000 + 4950.0`，返回类型不是整数 → 用整除 `//`，且先乘后除保证不丢精度。

## 如果面试官追问
问：如果要求返回每次选中的下标序列怎么办？
答：始终选当前最大值所在位置，用堆维护 `(-值, 下标)`，每轮弹出后把 `值+1` 重新入堆，O(k log n)。
