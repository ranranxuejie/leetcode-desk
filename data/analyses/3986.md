## 一句话思路
把两个时间各自换算成从 00:00:00 起的绝对秒数，相减即得，因为时间轴是线性的、秒数可加。

## 怎么做
1. 写一个 `to_seconds(t)`，按 `:` 切出三段，分别转成整数。
2. 用 `h * 3600 + m * 60 + s` 合成绝对秒数。
3. 返回 `to_seconds(endTime) - to_seconds(startTime)`。

拿示例 2 走一遍：`"12:34:56"` 切成 `["12","34","56"]`，得 `12*3600 + 34*60 + 56 = 43200 + 2040 + 56 = 45296`；`"13:00:00"` 得 `46800`。相减 `46800 - 45296 = 1504`，与输出一致。关键中间值就是这两个绝对秒数，差值直接是答案，不需要处理进位或借位。

```python
def to_seconds(t):
    h, m, s = map(int, t.split(":"))
    return h * 3600 + m * 60 + s

return to_seconds(endTime) - to_seconds(startTime)
```

注意 `split(":")` 返回的正好是 3 段，`map(int, ...)` 一次解包给 `h, m, s`，不用下标访问。题目保证 `endTime` 不早于 `startTime`，所以差值非负，不必加绝对值。

## 复杂度
时间：O(1)，固定 8 个字符、两次 split 和常数次算术。
空间：O(1)，只开了长度为 3 的临时列表和几个整数。

## 易错点
- 把 `"01:00:00"` 到 `"01:00:25"` 当成 24 秒（误以为不含端点）→ 输出 24。题面明确「包含两个端点」，直接相减得 25 才对，不要额外 `+1` 也不要 `-1`。
- 用字符串直接比较或逐位相减 → 遇到 `"12:34:56"` 到 `"13:00:00"` 时秒位 `00 - 56` 变负数、分位 `00 - 34` 也变负数，借位逻辑写错就得到 1504 以外的值。正确做法是先各自转成绝对秒数再减，把借位交给算术。

## 如果面试官追问
问：若时间格式改成 `"HH:MM:SS"` 但允许跨天（`endTime` 可能早于 `startTime`）怎么办？
答：差值加 `86400` 再对 `86400` 取模，即 `(end - start) % 86400`。
