## 一句话思路
用栈保存「当前已展开的字符串集合」，遇 `{` 压栈、遇 `}` 与逗号做集合并、相邻元素做笛卡尔积拼接。

## 怎么做
1. 维护栈 `st`，栈顶是当前层已累积的集合；另设 `cur` 表示当前正在拼接的乘积项，初值 `{""}`。
2. 遇小写字母 `c`：`cur = {s + c for s in cur}`，即把字符接到每个已拼好的串后面。
3. 遇 `{`：把 `cur` 压栈并重置 `cur = {""}`；遇 `,`：把 `cur` 并入栈顶集合并重置 `cur`；遇 `}`：先并入 `cur`，再弹出该层集合作为新的 `cur`。
4. 扫描结束后把 `cur` 并入栈顶，返回 `sorted(st[0])`。

以 `"{a,b}{c,{d,e}}"` 为例：读到第一个 `}` 时栈顶集合为 `{"a","b"}`；随后 `{c,{d,e}}` 展开成 `{"c","d","e"}`；最后一步做笛卡尔积，`cur` 变成 `{"ac","ad","ae","bc","bd","be"}`，排序即答案。

```python
st = [set()]
cur = {""}
for ch in expression:
    if ch == "{":
        st.append(cur)
        cur = {""}
    elif ch == "}":
        st[-1] |= cur
        cur = st.pop()
    elif ch == ",":
        st[-1] |= cur
        cur = {""}
    else:
        cur = {s + ch for s in cur}
st[-1] |= cur
return sorted(st[0])
```

关键点：`{` 时压入的是**已经拼好的 `cur`**，而不是空集，这样 `a{b,c}` 里的 `a` 不会丢；`}` 时先并入再弹出，保证 `{c,{d,e}}` 的内层结果回到外层继续参与拼接。

## 复杂度
时间 O(L · S)，L 为表达式长度，S 为结果集合总规模（拼接与去重都按集合大小计）。
空间 O(S)，栈深度最多 O(L)，每层存一个字符串集合。

## 易错点
- 输入 `"a{b,c}"` → 若在 `{` 处把 `cur` 重置为 `{""}` 却不压栈，`a` 会丢失，输出变成 `["b","c"]` → 正确做法是 `st.append(cur)` 保存已拼部分，`}` 时再与内层结果做笛卡尔积。
- 输入 `"{{a,z},a{b,c},{ab,z}}"` → 若用列表不去重，`"a"` 会重复出现（来自 `{a,z}` 和 `a{b,c}`）→ 全程用 `set` 并在 `,` 和 `}` 处做 `|=` 合并，最后才 `sorted`。

## 如果面试官追问
问：若表达式长度到 10^4 且结果规模爆炸怎么办？答：结果本身是指数级，只能改为惰性生成器逐条产出，或按题目要求只返回前 k 个。
