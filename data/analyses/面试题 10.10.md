## 一句话思路
用树状数组维护值域 `[0, 50000]` 上的计数前缀和，`getRankOfNumber(x)` 就是 `query(x+1)`。

## 怎么做
1. 值域上界取 `MAXV = 50001`，树状数组 `tree` 长度 `MAXV+1`，下标从 1 开始，数字 `x` 存到 `x+1` 位置，避开 0 下标。
2. `track(x)`：从 `i = x+1` 开始，`while i <= MAXV: tree[i] += 1; i += i & -i`。
3. `getRankOfNumber(x)`：从 `i = x+1` 开始累加 `tree[i]`，`i -= i & -i`，得到 ≤ x 的个数。
4. 按 `inputs` 里的操作名分发，`"StreamRank"` 返回 `None`，其余返回整数。

用官方示例走一遍：`getRankOfNumber(1)` 时 `tree` 全 0，`i=2` 累加得 0，输出 0；接着 `track(0)` 把 `tree[1]` 置 1；再 `getRankOfNumber(0)` 时 `i=1` 取到 `tree[1]=1`，输出 1。关键中间值就是 `x+1` 这个偏移，少了它 `track(0)` 会死循环在 `i += 0`。

```python
MAXV = 50001
tree = [0] * (MAXV + 1)

def track(x):
    i = x + 1
    while i <= MAXV:
        tree[i] += 1
        i += i & -i

def get_rank(x):
    i, s = x + 1, 0
    while i > 0:
        s += tree[i]
        i -= i & -i
    return s
```

分发时注意 `"StreamRank"` 只占位不做事，返回列表第一个元素是 `None`。

## 复杂度
时间：`track` 和 `getRankOfNumber` 各 O(log 50001) ≈ 16 次循环，总 O(q log V)。
空间：`tree` 固定 50002 个 int，O(V)，与调用次数无关。

## 易错点
- 输入含 `x = 0`（示例就有）→ 若直接把 `x` 当下标，`i += i & -i` 中 `i=0` 使 `0 & 0 = 0` 死循环 → 统一用 `x+1` 做下标，`getRank` 也从 `x+1` 起查。
- 查询 `getRankOfNumber(50000)` → 若 `MAXV` 取 50000，`i = 50001 > MAXV` 直接跳过循环返回 0 → `MAXV` 必须 ≥ 50001，且 `tree` 长度开到 `MAXV+1`。

## 如果面试官追问
问：若 `x` 范围放大到 10^9 怎么办？答：先离线收集所有 `track` 和查询值做离散化，树状数组只开不同取值个数大小。
