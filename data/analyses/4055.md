## 一句话思路
对每个 j 找它左边「单调栈维护的递减后缀」里第一个大于 nums[j] 的位置，用树状数组统计影子对数。

## 怎么做
1. 影子对 (i,j) 的充要条件：i 是 j 左侧第一个满足 nums[i] < nums[j] 且中间无值落在 (nums[i], nums[j]) 的位置，等价于 i 是 j 左边「从 j-1 往左扫，遇到第一个比 nums[j] 小的位置」。
2. 用单调递减栈维护候选左端点：栈内下标递增、值递减。对每个 j，弹出栈顶所有 nums[top] > nums[j] 的元素，此时栈顶就是最近的 nums[top] < nums[j] 的 i。
3. 但影子对可能不止一个 i：所有被弹出的元素中，值 < nums[j] 的也可能构成影子对。用树状数组按值域统计弹出元素里 < nums[j] 的个数，累加进答案。

以 `nums = [3,1,4,2,5]` 为例：j=2 时栈为 [1(值1),0(值3)]，nums[2]=4，栈顶 0 值 3<4，i=0 成立；j=3 时 nums[3]=2，弹出 2(值4)，栈顶 1 值 1<2，i=1 成立，同时弹出元素 4>2 不计；j=4 时 nums[4]=5，栈为 [3(值2),1(值1)]，全部 <5，i=3 和 i=1 都成立，累计 5。

```python
stack = []          # 下标，值递减
bit = [0] * (m + 1) # 值域树状数组
ans = 0
for j, x in enumerate(nums):
    while stack and nums[stack[-1]] > x:
        v = stack.pop()
        bit_add(rank[v], 1)   # 弹出元素进入 BIT
    ans += bit_query(rank[x] - 1)  # 弹出元素中值 < x 的个数
    if stack and nums[stack[-1]] < x:
        ans += 1                    # 栈顶这个 i 也成立
    stack.append(j)
```

## 复杂度
时间 O(n log n)：每个下标入栈出栈各一次，树状数组操作 O(log n)。
空间 O(n)：栈和树状数组各 O(n)，值域离散化另开 O(n)。

## 易错点
- 输入 `[6,7,8,9]` 严格递增 → 若只统计栈顶一个 i，会漏掉前面所有更小的 i，得 3 而非正确值；正确做法是弹出元素全部进 BIT 再查询。
- 输入 `[3,1,4,2,5]` 中 j=3 时 nums[3]=2 → 若把弹出的 4 也当成合法 i（4>2 不满足 nums[i]<nums[j]），会多算；正确做法是弹出后只对值 < nums[j] 的查询 BIT。

## 如果面试官追问
问：若要求输出所有影子对而非计数？
答：把 BIT 换成按值域挂链表的栈，弹出时遍历链表输出 (i,j)，复杂度不变。
