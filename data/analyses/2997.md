## 一句话思路
先求整个数组的异或和 `x`，答案就是 `x ^ k` 的二进制中 1 的个数，因为每次翻转恰好能修正一位。

## 怎么做
1. 用 `reduce` 或循环把 `nums` 全部异或起来，得到 `x`。
2. 计算 `d = x ^ k`，`d` 的第 `i` 位为 1 表示最终异或和的第 `i` 位与 `k` 不符。
3. 翻转数组中任意一个元素的第 `i` 位，会让总异或和的第 `i` 位翻转一次，所以每一位只需一次操作。
4. 返回 `bin(d).count("1")`（或 `d.bit_count()`）。

以 `nums = [2,1,3,4], k = 1` 为例：`x = 2^1^3^4 = 4`（二进制 `100`），`d = 4 ^ 1 = 5`（`101`），`bit_count` 为 2，与示例输出一致。

```python
from functools import reduce

def min_operations(nums, k):
    x = reduce(lambda a, b: a ^ b, nums, 0)
    d = x ^ k
    return bin(d).count("1")
```

关键中间值：`x = 4`，`d = 5`，`5` 的二进制 `101` 有 2 个 1，答案 2。

## 复杂度
时间：O(n)，遍历 `nums` 求异或；`bit_count` 只处理 O(log(max)) 位。
空间：O(1)，只存 `x` 和 `d` 两个整数。

## 易错点
1. 输入 `nums = [0], k = 0` → 若误以为必须操作一次，会返回 1 → 正确做法是 `d = 0 ^ 0 = 0`，`bit_count` 为 0，直接返回 0。
2. 输入 `nums = [1], k = 2**20` → 若只按 `nums` 中已有位宽统计会漏高位 → 正确做法是对 `x ^ k` 整体取 `bit_count`，前导 0 翻转合法，高位 1 也要计入。

## 如果面试官追问
问：如果要求输出具体操作方案（选哪个下标、翻哪一位）？
答：对 `d` 中每个为 1 的位 `i`，任选 `nums[0]` 翻转第 `i` 位即可，因为异或和只关心该位翻转次数为奇数。
