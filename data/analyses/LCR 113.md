## 一句话思路
用 Kahn 拓扑排序（BFS）按入度剥点，剥出的顺序就是修课顺序，剥不完说明有环。

## 怎么做
1. 建邻接表 `graph[b].append(a)`，同时 `indeg[a] += 1`，注意方向是 b→a（先修指向后修）。
2. 把所有 `indeg[i] == 0` 的课压入 `deque`。
3. 每次弹出队首 `cur` 追加到 `order`，遍历 `graph[cur]` 把邻居入度减 1，减到 0 就入队。
4. 最后 `len(order) == numCourses` 才返回 `order`，否则返回 `[]`。

以示例 2 为例：`prerequisites = [[1,0],[2,0],[3,1],[3,2]]`，初始 `indeg = [0,1,1,2]`，队列只有 `[0]`。弹出 0 后 `indeg[1]`、`indeg[2]` 都变 0，队列变 `[1,2]`；弹出 1 后 `indeg[3]` 从 2 变 1，弹出 2 后 `indeg[3]` 变 0 入队，最终 `order = [0,1,2,3]`。

```python
from collections import deque
graph = [[] for _ in range(numCourses)]
indeg = [0] * numCourses
for a, b in prerequisites:
    graph[b].append(a)
    indeg[a] += 1
q = deque(i for i in range(numCourses) if indeg[i] == 0)
order = []
while q:
    cur = q.popleft()
    order.append(cur)
    for nxt in graph[cur]:
        indeg[nxt] -= 1
        if indeg[nxt] == 0:
            q.append(nxt)
return order if len(order) == numCourses else []
```

## 复杂度
时间 O(numCourses + len(prerequisites))：每条边被遍历一次，每个点入队一次。
空间 O(numCourses + len(prerequisites))：邻接表存全部边，`indeg`、`order`、队列各 O(numCourses)。

## 易错点
1. 边方向写反 → 对 `[[1,0]]` 建成 `graph[1].append(0)`、`indeg[0] += 1`，队列里只有 1，输出 `[1,0]`，先修课后修课颠倒。正确做法是 `graph[b].append(a)`，让 0 的入度为 0 先出队。
2. 有环时直接返回 `order` → 对 `numCourses = 2, prerequisites = [[1,0],[0,1]]` 会返回 `[]` 之外的残缺序列（实际 `order` 为空但长度判断缺失时可能返回部分点）。必须用 `len(order) == numCourses` 判定，否则返回 `[]`。

## 如果面试官追问
问：要求返回字典序最小的修课序列怎么办？
答：把 `deque` 换成小根堆 `heapq`，每次弹出最小编号的零入度课，其余逻辑不变。
