## 一句话思路
利用 BST 有序性从根往下走，p、q 第一次分居当前节点两侧（或当前节点就是其一）时，该节点即 LCA。

## 怎么做
1. 令 `cur = root`，循环直到 `cur` 为 `None`。
2. 若 `p.val` 和 `q.val` 都小于 `cur.val`，说明两者都在左子树，`cur = cur.left`。
3. 若两者都大于 `cur.val`，`cur = cur.right`。
4. 否则（一左一右，或 `cur` 等于 `p`/`q`），`cur` 就是分叉点，直接返回。

以示例 1 为例：`cur=6`，`p.val=2 < 6`、`q.val=8 > 6`，不满足同侧条件，第一次就返回 6。示例 2：`cur=6` 时 2、4 都小于 6，走左到 `cur=2`；此时 `p.val=2` 等于 `cur.val`，不满足「都小于」也不满足「都大于」，返回 2——正好体现「节点可以是自己的祖先」。

```python
cur = root
while cur:
    if p.val < cur.val and q.val < cur.val:
        cur = cur.left
    elif p.val > cur.val and q.val > cur.val:
        cur = cur.right
    else:
        return cur
```

关键点：判断「同侧」必须两个条件同时成立，用 `and` 而不是 `or`；一旦不同侧就停，不要继续往下走。

## 复杂度
时间 O(h)：h 为树高，只沿一条路径下降，最坏 O(n)（退化成链）。
空间 O(1)：迭代写法只用了 `cur` 一个指针，没有递归栈。

## 易错点
- 输入 `root=[6,2,8,...], p=2, q=4`：若用 `or` 判断同侧（`p.val < cur.val or q.val < cur.val` 就走左），在 `cur=6` 时 2<6 成立会误走左，之后在 `cur=2` 又因 4>2 误走右，最终返回 `None`。正确做法是 `and`，两者都小才走左。
- 输入 `p=2, q=4` 且把终止条件写成「`cur.val` 严格在 p、q 之间」：`cur=2` 时 2 不在 (2,4) 开区间内，会继续走到 4 返回 4，错成 4。正确做法是允许 `cur` 等于 `p` 或 `q`，即用 `else` 兜住相等情形。

## 如果面试官追问
问：若树不是 BST 而是普通二叉树怎么办？
答：改用后序遍历，左右子树各返回是否找到 p/q，第一个两侧都非空的节点即 LCA，时间 O(n)、空间 O(h)。
