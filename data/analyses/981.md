## 一句话思路
每个 key 挂一条按时间戳递增的列表，get 时二分找最后一个 ≤ timestamp 的位置。

## 怎么做
1. 用 `dict[str, list[tuple[int, str]]]` 存，set 直接 append，因为题面保证同一 key 的时间戳严格递增。
2. get 先查 key 是否存在，不存在直接返回 `""`。
3. 对该 key 的时间戳列表做二分，找最后一个 `<= timestamp` 的下标。
4. 下标为 -1 说明所有时间戳都更大，返回 `""`；否则返回该下标的值。

以官方示例为例：`set("foo","bar",1)` 后 `store["foo"] = [(1,"bar")]`；再 `set("foo","bar2",4)` 变成 `[(1,"bar"),(4,"bar2")]`。此时 `get("foo",3)` 二分得到 `idx=0`（`ts[0]=1<=3`，`ts[1]=4>3`），返回 `"bar"`；`get("foo",5)` 得到 `idx=1`，返回 `"bar2"`。

```python
import bisect

def set(self, key, value, timestamp):
    self.store.setdefault(key, []).append((timestamp, value))

def get(self, key, timestamp):
    arr = self.store.get(key)
    if not arr:
        return ""
    ts = [t for t, _ in arr]
    i = bisect.bisect_right(ts, timestamp) - 1
    return arr[i][1] if i >= 0 else ""
```

关键点：`bisect_right` 返回第一个 `> timestamp` 的位置，减 1 才是「最后一个 ≤」。用 `bisect_left` 会漏掉恰好等于 timestamp 的那条。

## 复杂度
时间：set 均摊 O(1)；get 为 O(log k)，k 是该 key 的版本数，建 `ts` 列表额外 O(k)。
空间：O(n)，n 为 set 总调用次数，全部存进 store。

## 易错点
- `get("foo", 0)` 这类比所有已存时间戳都小的查询 → 若直接取 `arr[-1]` 会错返回 `"bar2"` → 必须先判 `i >= 0`，否则返回 `""`。
- 查询一个从未 set 过的 key，如 `get("bar", 5)` → 若对空列表二分或直接索引会抛异常 → 用 `self.store.get(key)` 拿到 `None` 就提前返回 `""`。

## 如果面试官追问
若同一 key 的时间戳不再严格递增、可能乱序 set，怎么办？答：append 后需保持有序，可改为插入时二分定位插入点，get 逻辑不变。
