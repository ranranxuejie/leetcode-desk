## 一句话思路
用 10 位掩码记录每个前缀的奇偶状态，两前缀异或后 popcount≤1 即构成最美子串，哈希表计数配对。

## 怎么做
1. 定义 `mask` 为前 i 个字符中每个字母出现次数的奇偶性，第 k 位为 1 表示字母 `chr(97+k)` 出现奇数次。
2. 用 `cnt = {0: 1}` 记录各 mask 出现次数，`0:1` 代表空前缀。
3. 遍历 `word`，每读一个字符 `c` 就 `mask ^= 1 << (ord(c) - 97)`，然后累加 `cnt[mask]`（异或为 0，即所有字母偶数次）和 `cnt[mask ^ (1 << k)]`（k 取 0..9，异或后只剩一位，即恰好一个字母奇数次）。
4. 把当前 `mask` 计入 `cnt`，继续。

以 `word = "aba"` 为例：初始 `mask=0, cnt={0:1}`。读 `'a'` 后 `mask=1`，查 `cnt[1]=0`、`cnt[1^1]=cnt[0]=1`，答案 +1；`cnt={0:1,1:1}`。读 `'b'` 后 `mask=3`，查 `cnt[3]=0`、`cnt[3^2]=cnt[1]=1`，答案 +1；`cnt` 加 `3:1`。读第二个 `'a'` 后 `mask=2`，查 `cnt[2]=0`、`cnt[2^2]=cnt[0]=1`、`cnt[2^1]=cnt[3]=1`，答案 +2，累计 4。

```python
cnt = {0: 1}
mask = 0
ans = 0
for c in word:
    mask ^= 1 << (ord(c) - 97)
    ans += cnt.get(mask, 0)
    for k in range(10):
        ans += cnt.get(mask ^ (1 << k), 0)
    cnt[mask] = cnt.get(mask, 0) + 1
return ans
```

## 复杂度
时间：O(10n)，n 为 `word` 长度，每字符固定查 11 次哈希表。
空间：O(min(2^10, n))，哈希表最多存 1024 个不同 mask。

## 易错点
1. 输入 `"aabb"` → 忘记把 `0:1` 放进 `cnt` 初始值 → 会漏掉从下标 0 开始的子串（如 `"aa"`、`"aabb"`），答案从 9 错成 7。正确做法是初始化 `cnt = {0: 1}`，让空前缀参与配对。
2. 输入 `"aba"` → 只查 `cnt[mask]` 不查 `mask ^ (1<<k)` → 会漏掉恰好一个字母奇数次的情况（如 `"b"`、`"aba"`），答案从 4 错成 1。正确做法是 10 个单比特翻转全部查一遍。

## 如果面试官追问
若字母表扩到 26 个字母，怎么做？答：思路不变，但每步要查 27 次（自身 + 26 个单比特翻转），时间变 O(26n)，哈希表最多 2^26 个键，空间压力显著上升。
