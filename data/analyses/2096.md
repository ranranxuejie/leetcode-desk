## 一句话思路
分别从根 DFS 记录到 startValue 和 destValue 的路径，去掉公共前缀后，起点剩余路径全转 `'U'`，再接上终点剩余路径。

## 怎么做
1. 一次 DFS 同时求出 `path_s` 和 `path_t`，路径用 `'L'`/`'R'` 字符列表表示。
2. 用双指针找两条路径的最长公共前缀长度 `i`，即 LCA 之前的深度。
3. 答案 = `'U' * (len(path_s) - i)` + `''.join(path_t[i:])`。

以示例 1 为例：`path_s = ['L','L']`（5→1→3），`path_t = ['R','L']`（5→2→6），公共前缀长度 `i = 0`，所以 `'U'*2 + 'RL' = "UURL"`。

```python
def dfs(node, target, path):
    if node is None:
        return False
    if node.val == target:
        return True
    path.append('L')
    if dfs(node.left, target, path):
        return True
    path.pop()
    path.append('R')
    if dfs(node.right, target, path):
        return True
    path.pop()
    return False

path_s, path_t = [], []
dfs(root, startValue, path_s)
dfs(root, destValue, path_t)
i = 0
while i < len(path_s) and i < len(path_t) and path_s[i] == path_t[i]:
    i += 1
return 'U' * (len(path_s) - i) + ''.join(path_t[i:])
```

## 复杂度
时间 O(n)：两次 DFS 各遍历至多 n 个节点，路径拼接 O(n)。
空间 O(n)：递归栈最坏 n 层，`path_s`/`path_t` 各存一条路径。

## 易错点
- 示例 2 `root=[2,1], startValue=2, destValue=1`：若先转 `'U'` 再拼 `path_t` 而不去公共前缀，会得到 `"UL"`；正确是公共前缀为空、`path_s` 为空，答案 `"L"`。必须先算 `i` 再拼接。
- 当 startValue 是 destValue 的祖先（如 `root=[5,1,2,3,null,6,4]`，start=5，dest=6）：`path_s=[]`、`path_t=['R','L']`，`i=0`，答案 `"RL"`；若误把 `len(path_s)-i` 写成 `len(path_s)` 之外的东西或漏掉 `i` 的边界，会多出 `'U'`。

## 如果面试官追问
若节点数扩到 10^6 且递归栈溢出，怎么办？答：改迭代 DFS 显式维护栈和路径，逻辑不变。
