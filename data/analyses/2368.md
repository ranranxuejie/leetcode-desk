## 一句话思路
从 0 出发做 DFS，遇到 `restricted` 里的节点直接跳过不计数，树无环所以每个可达节点只访问一次。

## 怎么做
1. 把 `restricted` 转成 `set`，判断 O(1)。
2. 用 `edges` 建邻接表 `g`，长度 n 的列表套列表。
3. 从 0 起 DFS，进入节点先判是否在 `restricted`，是则返回 0，否则计数 1 并递归未访问邻居。
4. 用 `visited` 数组防重复（树里其实靠父节点也行，但显式数组更稳）。

拿示例 1：`edges` 建表后 `g[0]=[1,4,5]`，`restricted={4,5}`。从 0 出发，邻居 1 不在受限集，递归进 1；`g[1]=[0,2,3]`，2、3 都可达，累计 `[0,1,2,3]` 共 4 个。邻居 4、5 命中 `restricted`，直接剪掉，5 后面的 6 也就到不了。

```python
blocked = set(restricted)
g = [[] for _ in range(n)]
for a, b in edges:
    g[a].append(b)
    g[b].append(a)

seen = [False] * n
def dfs(u):
    if u in blocked or seen[u]:
        return 0
    seen[u] = True
    return 1 + sum(dfs(v) for v in g[u])

return dfs(0)
```

关键点：`seen[u] = True` 要在递归前设，否则树里父子互指会无限递归（虽然靠 `blocked` 剪枝能挡住部分，但 0 和 1 之间没受限就会栈溢出）。

## 复杂度
时间 O(n)：建表遍历 n-1 条边，DFS 每个节点最多进一次。
空间 O(n)：邻接表存 2(n-1) 个整数，`seen` 和递归栈各 O(n)。

## 易错点
- 输入 `restricted=[4,5]` 时若只在 DFS 入口判 `blocked` 而不判 `seen`，节点 0 的邻居 1 会经由 1→0 再回到 0，形成 0↔1 死循环 → 正确做法是进节点先查 `seen[u]`，设 True 再递归。
- 若把 `restricted` 当列表用 `u in restricted` 判断，n=10^5 且受限节点多时每次 O(|restricted|)，总退化成 O(n·|restricted|) → 正确做法是先 `set(restricted)`，把单次判断压到 O(1)。

## 如果面试官追问
问：如果要求输出具体可达节点列表而不只是数目？
答：DFS 里把 `u` 追加进 `res` 再返回，最后返回 `res` 即可，复杂度不变。
