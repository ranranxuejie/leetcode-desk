## 一句话思路
枚举中间两个下标 j、k，用树状数组分别统计左侧小于 `nums[k]` 的个数和右侧大于 `nums[j]` 的个数，两者相乘累加。

## 怎么做
1. 固定 j、k（j < k），四元组数量 = 左侧满足 `nums[i] < nums[k]` 的 i 个数 × 右侧满足 `nums[l] > nums[j]` 的 l 个数。
2. 先预处理 `right[j]`：从右往左扫，用树状数组统计已扫过的元素中大于 `nums[j]` 的个数。
3. 再从左往右扫 k，维护左侧树状数组，对每个 j < k 累加 `left_less(nums[k]) * right[j]`。

以 `nums = [1,3,2,4,5]` 为例，j=1（值 3）、k=2（值 2）时，左侧小于 2 的只有 `nums[0]=1`，计数 1；右侧大于 3 的有 4、5，计数 2；贡献 1×2=2，正是答案。

```python
# right[j] = 右侧比 nums[j] 大的个数
right = [0] * n
bit = [0] * (n + 2)
for j in range(n - 1, -1, -1):
    right[j] = query(n) - query(nums[j])   # 已插入的总数 - ≤nums[j] 的个数
    update(nums[j], 1)

ans = 0
bit = [0] * (n + 2)
for k in range(n):
    for j in range(k):                     # 这里可优化，见易错点
        ans += query(nums[k] - 1) * right[j]
    update(nums[k], 1)
```

## 复杂度
时间：O(n² log n)，外层 k、内层 j 各一层，每次树状数组查询 O(log n)。
空间：O(n)，两个树状数组和 `right` 数组各占 n。

## 易错点
1. 内层 `for j in range(k)` 直接对每个 j 查一次树状数组，是 O(n² log n)；n=4000 时约 1.6×10⁷ 次操作，Python 会超时。正确做法是把 `right[j]` 按 j 顺序累加进一个变量 `s`，每步 `ans += s * query(nums[k]-1)`，把内层降为 O(1)，总复杂度 O(n log n)。
2. 树状数组查询用 `query(nums[k]-1)` 而非 `query(nums[k])`，因为要严格小于 `nums[k]`；同理右侧统计用 `query(n) - query(nums[j])` 排除等于的情况。虽然本题是排列不会相等，但写成 `query(nums[k])` 在含重复值的变体里会多算。

## 如果面试官追问
若 nums 允许重复值，怎么改？答：把「严格小于」改成 `query(nums[k]-1)`、右侧改成 `query(n)-query(nums[j])`，并先对值离散化去重。
