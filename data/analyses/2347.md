## 一句话思路
先判花色是否全同（Flush 优先级最高），否则统计 ranks 中每个点数出现次数，按最大频次 3/2/1 映射到三种牌型。

## 怎么做
1. 用 `len(set(suits)) == 1` 判断五张花色是否全同，是则直接返回 `"Flush"`。
2. 用 `Counter(ranks)` 统计点数频次，取 `max(cnt.values())` 作为最高重复次数。
3. 按最高频次映射：`3` → `"Three of a Kind"`，`2` → `"Pair"`，否则 `"High Card"`。

以示例 2 为例：`ranks = [4,4,2,4,4]`，`Counter` 得到 `{4:4, 2:1}`，`max(cnt.values()) == 4`。注意 4 张相同也满足"至少 3 张相同"，所以判定条件应是 `>= 3` 而非 `== 3`，返回 `"Three of a Kind"`。

```python
from collections import Counter

if len(set(suits)) == 1:
    return "Flush"
cnt = Counter(ranks)
best = max(cnt.values())
if best >= 3:
    return "Three of a Kind"
if best == 2:
    return "Pair"
return "High Card"
```

关键点：Flush 判定必须在点数统计之前，因为示例 1 中 `ranks` 五个点数互不相同，若先算频次会得到 `best == 1` 而误判为 High Card。

## 复杂度
时间：O(5)，固定 5 张牌，建 set 和 Counter 都是常数次操作。
空间：O(5)，`set(suits)` 最多 4 个花色，`Counter(ranks)` 最多 5 个键。

## 易错点
- 输入 `ranks = [4,4,2,4,4]` → 若写成 `best == 3` 会漏判，落到 `best == 2` 分支返回 `"Pair"`；正确做法是用 `best >= 3`，因为 4 张相同也构成三条。
- 输入 `ranks = [13,2,3,1,9], suits = ["a","a","a","a","a"]` → 若先统计点数再判花色，`best == 1` 会返回 `"High Card"`；正确做法是把 `len(set(suits)) == 1` 放在最前面短路返回。

## 如果面试官追问
问：如果牌数从 5 张扩展到 n 张，怎么改？
答：Flush 仍判花色集合大小为 1；点数频次取 `max(cnt.values())`，按 `>=5` 同花顺、`>=4` 四条、`>=3` 三条、`>=2` 对子依次降级判断即可。
