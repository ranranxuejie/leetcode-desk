## 一句话思路
用长度 26 的计数数组分别统计两串字母频次，逐位比较差值是否超过 3。

## 怎么做
1. 建两个长度 26 的列表 `cnt1`、`cnt2`，初值全 0。
2. 遍历 `word1`，用 `ord(ch) - ord('a')` 作下标给 `cnt1` 累加；`word2` 同理累加到 `cnt2`。
3. 对 `i` 从 0 到 25，若 `abs(cnt1[i] - cnt2[i]) > 3` 立即返回 `False`。
4. 循环走完没触发就返回 `True`。

以示例 1 `word1 = "aaaa"`、`word2 = "bccb"` 为例：统计后 `cnt1[0] = 4`（'a' 出现 4 次），`cnt2[0] = 0`，`cnt2[1] = 1`（'b'），`cnt2[2] = 2`（'c'）。第一轮 `i = 0` 时 `abs(4 - 0) = 4 > 3`，直接返回 `False`，后面 25 个字母根本不用看。

```python
cnt1 = [0] * 26
cnt2 = [0] * 26
for ch in word1:
    cnt1[ord(ch) - ord('a')] += 1
for ch in word2:
    cnt2[ord(ch) - ord('a')] += 1
for i in range(26):
    if abs(cnt1[i] - cnt2[i]) > 3:
        return False
return True
```

关键点：比较的是**同一个字母在两个串里的次数差**，不是两个串总长度的差。示例 2 里 'a' 是 1 对 4、差 3 刚好卡在边界上，`> 3` 不能写成 `>= 3`。

## 复杂度
时间：O(n + 26)，n 为串长，两趟遍历加一趟固定 26 次比较。
空间：O(1)，两个长度 26 的定长数组，与 n 无关。

## 易错点
- 输入 `word1 = "aaaa"`、`word2 = "bccb"` → 若只比较两串长度（都是 4）就返回 `True`，错；必须按字母逐位比，'a' 的 4 对 0 才是判据。
- 输入 `word1 = "abcdeef"`、`word2 = "abaaacc"` → 若把判断写成 `abs(...) >= 3`，'a' 的差正好是 3 会被误判成 `False`；题目要求「不超过 3」，边界值 3 合法，必须用 `> 3`。

## 如果面试官追问
问：如果阈值不是固定 3，而是每个字母给一个上限数组怎么办？
答：把 `> 3` 换成 `> limit[i]`，其余不变，仍是 O(n + 26)。
