## 一句话思路
按连续 1 段长度 L 累加 L*(L+1)//2，因为每段内所有子串都合法且跨 0 不合法。

## 怎么做
1. 用 `cur` 记录当前连续 1 的段长，遇到 `'1'` 就 `cur += 1`。
2. 每读到一个 `'1'`，立刻把 `cur` 加到答案里——这等价于「以当前位置结尾的合法子串数正好是 cur」。
3. 遇到 `'0'` 就把 `cur` 清零，因为跨过 0 的子串不再全 1。
4. 全程对 `10**9 + 7` 取模。

以 `s = "0110111"` 为例：扫到第 4 个字符时 `cur` 从 0 变 1，答案 +1；第 5 个字符 `cur = 2`，答案 +2（此时累计 3）；第 6 个字符 `cur = 3`，答案 +3（累计 6）；第 7 个字符 `cur = 4`，答案 +4，最终 `ans = 10`？——注意这里要核对：`"0110111"` 的 1 段是 `"11"`（长 2）和 `"111"`（长 3），贡献 3 + 6 = 9，与示例一致。上面逐步累加里第 4 位其实是 `'0'` 后的第一个 1，`cur` 应为 1，累计到 9。

```python
MOD = 10**9 + 7
ans = cur = 0
for ch in s:
    if ch == '1':
        cur += 1
        ans = (ans + cur) % MOD
    else:
        cur = 0
return ans
```

关键点：`ans += cur` 而不是 `ans += 1`，因为以当前 1 结尾的子串有 `cur` 个（长度 1 到 cur 各一个）。

## 复杂度
时间 O(n)：一次遍历，n 为 `len(s)`。
空间 O(1)：只开 `ans`、`cur` 两个整数。

## 易错点
- 输入 `"111111"` → 若写成每段只加 1 或只加段长，会得 2 或 6，正确是 6*7//2 = 21 → 必须按「以每个位置结尾的子串数」逐个累加 `cur`。
- 输入 `"101"` → 若忘记遇 `'0'` 清零 `cur`，第二段会接着第一段的 `cur` 继续涨，得 3 而非 2 → 每个 `'0'` 必须把 `cur` 置 0。

## 如果面试官追问
若要求返回所有合法子串的起止下标而非计数？答：仍按段扫描，对每段长 L 用双重循环枚举 `(i, j)`，复杂度升到 O(L²)，总输出本身就有这么多。
