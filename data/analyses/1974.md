## 一句话思路
逐字符贪心：每步取顺时针与逆时针距离的较小值，加上固定的 1 秒键入时间。

## 怎么做
1. 用 `prev = 0` 记录指针当前字母（`'a'` 记为 0），`ans = 0` 累计秒数。
2. 对 `word` 中每个字符 `ch`，算出 `cur = ord(ch) - ord('a')`。
3. 环上距离取 `d = abs(cur - prev)`，实际移动代价是 `min(d, 26 - d)`，累加进 `ans`。
4. 每个字符键入固定花 1 秒，最后 `ans += len(word)`。

以 `word = "bza"` 为例：`prev=0` 到 `cur=1`，`d=1`，`min(1,25)=1`；`prev=1` 到 `cur=25`，`d=24`，`min(24,2)=2`（逆时针走 z 更近）；`prev=25` 到 `cur=0`，`d=25`，`min(25,1)=1`。移动合计 `1+2+1=4`，键入 3 秒，答案 7。

```python
prev = 0
ans = 0
for ch in word:
    cur = ord(ch) - ord('a')
    d = abs(cur - prev)
    ans += min(d, 26 - d)
    prev = cur
ans += len(word)
```

关键点：`26 - d` 就是反向绕行的步数，`d` 与 `26 - d` 之和恒为 26，所以取小即可，不需要真的模拟指针转动方向。

## 复杂度
时间 O(n)，n 为 `word` 长度，每个字符常数次运算。
空间 O(1)，只用了 `prev`、`ans`、`cur`、`d` 四个变量。

## 易错点
- `word = "z"` → 若只写 `abs(cur - prev)` 会得 25，正确是 `min(25, 1) = 1`，因为从 `'a'` 逆时针一步就到 `'z'`。
- `word = "az"` 或任何跨过 `'a'`/`'z'` 边界的相邻字符 → 忘记 `26 - d` 会多算 24 秒；必须对每对相邻字母都做 `min(d, 26 - d)`，不能只在首字符判断。

## 如果面试官追问
若要求输出每次移动的方向和步数？答：在取 `min` 时比较 `d` 与 `26 - d`，前者小记顺时针，后者小记逆时针，同步追加到结果列表即可。
