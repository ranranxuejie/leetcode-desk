## 一句话思路
排序 nums1 后对每个 nums2[i] 二分找最近值，用最大收益替换一次。

## 怎么做
1. 先算原始总和 `total = sum(abs(a - b) for a, b in zip(nums1, nums2))`，同时把 nums1 排序得到 `s`。
2. 对每个 `nums2[i]`，在 `s` 中二分找第一个 ≥ `nums2[i]` 的位置 `p`，候选值是 `s[p]` 和 `s[p-1]`（越界则跳过）。
3. 收益 = `abs(nums1[i] - nums2[i]) - abs(候选 - nums2[i])`，取所有收益的最大值 `best`（不小于 0）。
4. 返回 `(total - best) % (10**9 + 7)`。

以示例 3 为例：`nums1=[1,10,4,4,2,7]`，`nums2=[9,3,5,1,7,4]`，`total = 8+7+1+3+5+3 = 27`。排序后 `s=[1,2,4,4,7,10]`。对 `i=0`，`nums2[0]=9`，二分得 `p=5`（`s[5]=10`），候选 10 和 7，收益 `8 - |10-9| = 7`，这是最大收益，`27 - 7 = 20`。

```python
import bisect
s = sorted(nums1)
total = sum(abs(a - b) for a, b in zip(nums1, nums2))
best = 0
for i, b in enumerate(nums2):
    p = bisect.bisect_left(s, b)
    for j in (p - 1, p):
        if 0 <= j < len(s):
            best = max(best, abs(nums1[i] - b) - abs(s[j] - b))
return (total - best) % (10**9 + 7)
```

注意 `best` 初值取 0，表示「不替换」也是合法方案，避免所有收益为负时反而变大。

## 复杂度
时间 O(n log n)：排序一次，n 次二分各 O(log n)。
空间 O(n)：排序副本 `s`，其余是常数。

## 易错点
- `nums1=[1,7,5]`、`nums2=[2,3,5]` 时，若只查 `bisect_left` 返回的 `s[p]` 而不查 `s[p-1]`，`i=1` 会漏掉候选 1（`p=2` 指向 5），收益算成 `4-2=2` 而非 `4-2=2`…实际漏掉 1 会得 4 而非 3。必须同时看左右邻居。
- 当 `p == len(s)` 或 `p == 0` 时直接取 `s[p]`/`s[p-1]` 会越界或取错，示例 3 的 `i=0` 中 `p=5` 正好是末尾，`s[5]` 合法但 `s[6]` 不存在，必须加 `0 <= j < len(s)` 判断。

## 如果面试官追问
问：如果允许替换 k 个元素呢？
答：每个位置独立取最近值即可，收益可加，取前 k 大收益之和，仍是 O(n log n)。
