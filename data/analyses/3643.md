## 一句话思路
只交换子矩阵内上下对称的两行，用双指针 `i = x`、`j = x + k - 1` 向中间夹，行内整段 `[y, y+k)` 互换。

## 怎么做
1. 令 `i = x`、`j = x + k - 1`，分别指向子矩阵的首行和末行。
2. 当 `i < j` 时，把 `grid[i][y:y+k]` 与 `grid[j][y:y+k]` 整体交换，然后 `i += 1`、`j -= 1`。
3. 循环结束时 `i >= j`，中间那行（`k` 为奇数时）原地不动，直接返回 `grid`。

以示例 1 为例：`x=1, y=0, k=3`，初始 `i=1, j=3`。第一次交换 `grid[1][0:3] = [5,6,7]` 与 `grid[3][0:3] = [13,14,15]`，得到第 1 行 `[13,14,15,8]`、第 3 行 `[5,6,7,16]`；随后 `i=2, j=2`，循环终止，第 2 行 `[9,10,11,12]` 保持原样。注意第 0 列到第 2 列被换，第 3 列（`8` 和 `16`）在子矩阵外，绝不能碰。

```python
i, j = x, x + k - 1
while i < j:
    grid[i][y:y + k], grid[j][y:y + k] = grid[j][y:y + k], grid[i][y:y + k]
    i += 1
    j -= 1
return grid
```

切片赋值是 Python 里最省事的整行交换写法，等价于对 `c in range(y, y+k)` 逐个 `swap(grid[i][c], grid[j][c])`。行数只有 `k//2` 次交换，`k <= 50`，直接原地改。

## 复杂度
时间：O(k²)，共 `k//2` 对行、每对交换 `k` 个元素。
空间：O(1)，切片赋值会临时建两个长度 `k` 的列表，但只与 `k` 有关，不随 `m`、`n` 增长。

## 易错点
- 把 `y:y+k` 写成 `y:k` 或 `0:k`：示例 1 中 `y=0` 时看不出差别，但示例 2 的 `y=2, k=2` 会错把第 0、1 列也换掉，正确是只动 `grid[i][2:4]`。
- 行指针写成 `0` 到 `k-1` 而不是 `x` 到 `x+k-1`：示例 1 中 `x=1`，若从第 0 行开始翻，第 0 行 `[1,2,3,4]` 会被卷进去，正确起点是 `x`。

## 如果面试官追问
问：如果要求水平翻转而不是垂直翻转？
答：行指针不动，改成对每行 `i in range(x, x+k)` 反转 `grid[i][y:y+k]`，即 `grid[i][y:y+k] = grid[i][y:y+k][::-1]`。
