## 一句话思路
设操作 k 次，则 num1 - k·num2 必须能拆成恰好 k 个 2 的幂（i 可重复），枚举 k 用 popcount 判定。

## 怎么做
1. 把等式改写：k 次操作后 num1 减去 k·num2 再减去 Σ2^i = 0，即 `target = num1 - k * num2` 必须等于 k 个 2 的幂之和。
2. 判定条件：`target >= k` 且 `popcount(target) <= k`。下界是 k 个 2 的幂至少和为 k（每个 ≥1），上界是 target 的二进制 1 的个数就是最少需要的项数，项数不够可以拆分（2^i = 2^(i-1)+2^(i-1)）补到 k 个。
3. 从 k = 1 往上枚举，第一个满足的 k 就是答案；k 超过 60 左右还没解就返回 -1（target 增长太快，实际枚举到 60 足够）。

以 `num1 = 3, num2 = -2` 为例：k=1 时 target = 3-(-2) = 5，popcount(5)=2 > 1，不行；k=2 时 target = 3+4 = 7，popcount(7)=3 > 2，不行；k=3 时 target = 3+6 = 9，popcount(9)=2 ≤ 3 且 9 ≥ 3，成立，返回 3。

```python
k = 1
while k <= 60:
    target = num1 - k * num2
    if target >= k and bin(target).count('1') <= k:
        return k
    k += 1
return -1
```

注意 `target` 可能为负，`bin()` 对负数给的是 `-0b...`，所以必须先判 `target >= k`（k ≥ 1 保证 target 为正）再算 popcount。

## 复杂度
时间：枚举 k 到 60，每次 popcount 是 O(log target)，总计 O(60·log num1)。
空间：只用了 k、target 两个整数，O(1)。

## 易错点
- `num1 = 5, num2 = 7`：k=1 时 target = -2，若直接 `bin(-2).count('1')` 会得到 1 而误判成立；正确做法是先判 `target >= k`，负数直接跳过，最终返回 -1。
- `num1 = 1, num2 = 0`：k=1 时 target = 1，popcount=1 ≤ 1 成立返回 1；若把条件写成 `popcount(target) == k` 会漏掉「项数可以拆分补足」的情况，比如 `num1 = 3, num2 = -2` 的 k=3 时 popcount(9)=2 ≠ 3 却合法。

## 如果面试官追问
问：要求输出具体每步选的 i 怎么办？答：从 target 的二进制位出发，把高位不断拆成两个低位，直到项数等于 k，每项对应一个 i。
