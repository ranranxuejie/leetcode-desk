## 一句话思路
最大值的格子必是所有操作的交集，即 `min(ai) × min(bi)`，无操作时退化为整个矩阵。

## 怎么做
1. 若 `ops` 为空，直接返回 `m * n`。
2. 否则取所有 `ops[i][0]` 的最小值记为 `min_a`，所有 `ops[i][1]` 的最小值记为 `min_b`。
3. 返回 `min_a * min_b`。

以示例 1 为例：`m = 3, n = 3, ops = [[2,2],[3,3]]`。遍历后 `min_a = min(2,3) = 2`，`min_b = min(2,3) = 2`，答案 `2 * 2 = 4`。原因：`[2,2]` 只覆盖左上 2×2，`[3,3]` 覆盖整个 3×3，交集就是 2×2，这 4 个格子被加了 2 次，其余格子只被加 1 次。

```python
min_a, min_b = m, n
for a, b in ops:
    if a < min_a:
        min_a = a
    if b < min_b:
        min_b = b
return min_a * min_b
```

注意 `min_a` 初值取 `m`、`min_b` 初值取 `n`，这样 `ops` 为空时循环不执行，直接返回 `m * n`，示例 3 得 9，无需单独写 if 分支。

## 复杂度
时间 O(len(ops))，一次遍历取两个最小值。
空间 O(1)，只开 `min_a`、`min_b` 两个变量，不建矩阵。

## 易错点
- 输入 `ops = []` → 若把 `min_a` 初值设成 `float('inf')` 再乘，会得到 `inf` 而非 9 → 初值必须取 `m` 和 `n`，空操作时自然返回 `m * n`。
- 输入 `ops = [[1,1]]`、`m = n = 3` → 若误以为答案是 `m * n` 或 `a * b` 的累加 → 正确是 `1 * 1 = 1`，只有左上角一个格子被加 1 次，它就是最大值。

## 如果面试官追问
问：若要求返回最大值本身而非个数？
答：最大值就是 `len(ops)`，因为每个操作都覆盖左上角 `(0,0)`，它被加了 `len(ops)` 次，且没有任何格子能超过它。
