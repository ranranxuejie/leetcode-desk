## 一句话思路
用回溯：每层从剩余数字里挑一个放进 path，选满 n 个就收割，靠 used 数组保证不重复选。

## 怎么做
1. 开 `used = [False]*n` 和 `path = []`，答案存 `res`。
2. 每层遍历 `i in range(n)`，`used[i]` 为 `True` 就跳过。
3. 选中则 `used[i]=True; path.append(nums[i])`，递归下一层，回来后 `path.pop(); used[i]=False`。
4. `len(path)==n` 时把 `path[:]` 拷进 `res` 并返回。

以 `nums=[1,2,3]` 为例，走到 `path=[1,3]` 时 `used=[True,False,True]`，下一层只剩 `i=1`，追加 `nums[1]=2` 得 `[1,3,2]`，收割后 `pop` 回 `[1,3]`，`used[1]` 复位为 `False`。

```python
def dfs(path, used):
    if len(path) == n:
        res.append(path[:])
        return
    for i in range(n):
        if used[i]:
            continue
        used[i] = True
        path.append(nums[i])
        dfs(path, used)
        path.pop()
        used[i] = False
dfs([], [False] * n)
```

关键点：`res.append(path[:])` 必须拷贝，直接 append `path` 会让所有结果指向同一个被清空的列表。

## 复杂度
时间 O(n·n!)：共 n! 个叶子，每个叶子拷贝长度 n 的 path。
空间 O(n)：递归栈深 n，`used` 和 `path` 各 n，不计输出。

## 易错点
- `nums=[1,2,3]` 时若写 `res.append(path)`，最终 `res` 里 6 个元素全是 `[]`（回溯把 path 清空了）→ 必须 `path[:]` 或 `list(path)` 拷贝。
- `nums=[0,1]` 时若用 `if nums[i] in path: continue` 判重，虽然本题数字互不相同能过，但一旦有 0 或负数做哨兵判断会误伤；正确做法是用下标 `used[i]` 判重，与数值无关。

## 如果面试官追问
问：数组含重复数字（如 `[1,1,2]`）怎么改？
答：先 `nums.sort()`，同层加 `if i>0 and nums[i]==nums[i-1] and not used[i-1]: continue`，跳过同层重复。
