## 一句话思路
把边按 time 从大到小加回并查集，分量数首次达到 k 时的 time 就是答案；等价于二分 t 后只保留 time > t 的边。

## 怎么做
1. 先算初始分量数：只把 `time > 0` 的边并起来，若 `n - 合并次数 >= k` 直接返回 0。
2. 否则把 edges 按 time 降序排序，从大到小逐条 union，每成功合并一次分量数减 1。
3. 分量数第一次 `>= k` 时，当前这条边的 time 就是最小 t（因为 t 再小一点这条边就还在，分量数不够）。

以示例 2 为例：`n=3, edges=[[0,1,2],[1,2,4]], k=3`。降序先加 `(1,2,4)`，`parent` 合并 1、2，分量数 3→2；再加 `(0,1,2)`，分量数 2→1，始终没到 3。注意这里 k=3 要求全拆开，所以答案取最后一条边的 time 4——实现上应在「加边前」判断：加 `(1,2,4)` 前分量数已是 3（初始 n=3 且无 time>0 的边），故返回 4。更稳的写法是记录「当前分量数 >= k 时已加入的最大 time」，即答案 = 使分量数达到 k 的那条边的 time。

```python
edges.sort(key=lambda e: -e[2])
parent = list(range(n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
comp = n
for u, v, t in edges:
    if comp >= k:
        return t  # 上一条加完就够 k 了，t 是当前这条的 time
    ru, rv = find(u), find(v)
    if ru != rv:
        parent[ru] = rv
        comp -= 1
return 0
```

## 复杂度
时间：排序 O(m log m)，并查集 O(m α(n))，m = len(edges)。
空间：`parent` 数组 O(n)，排序额外 O(log m) 栈。

## 易错点
- 输入 `n=3, edges=[[0,2,5]], k=2`：若从 time 小到大加边会得到错误方向，必须降序加边（或二分时保留 `time > t` 的边），因为边是「被移除」而非「被加入」。
- 输入 `k=1` 或图初始就连通：若循环里先 union 再判断 `comp >= k`，会在多加一条边后返回偏大的 time；正确做法是每轮开头先判 `comp >= k` 再 union，或单独处理初始分量数 `>= k` 返回 0。

## 如果面试官追问
问：若要求输出具体是哪条边被移除导致达标？答：在返回 t 时同时记录该边的 `(u, v, t)`，即循环中触发 `comp >= k` 前最后成功 union 的那条边。
