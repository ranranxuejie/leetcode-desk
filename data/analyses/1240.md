## 一句话思路
回溯枚举每个空位的正方形边长，用剩余面积下界剪枝，因为 n,m≤13 搜索空间可接受。

## 怎么做
1. 用 `grid` 记录已覆盖格子，每次找第一个未覆盖位置 `(r, c)`。
2. 从最大可行边长 `size = min(n-r, m-c)` 向下枚举，且不超过当前最优解剩余量。
3. 剪枝：若 `used + 1 >= best` 直接返回；用剩余空格数除以最大正方形面积做下界。
4. 递归填格，回溯时撤销 `grid` 标记。

以 `n=5, m=8` 为例：首次在 `(0,0)` 尝试 `size=5`，填满左侧 5×5 后剩余 5×3 区域，继续递归得总数为 5，更新 `best=5`；后续分支若 `used+1>=5` 立即剪掉。

```python
def dfs(used):
    nonlocal best
    if used >= best: return
    # 找第一个空格
    for r in range(n):
        for c in range(m):
            if not grid[r][c]:
                size = min(n - r, m - c)
                while size > 0:
                    if can_place(r, c, size):
                        fill(r, c, size, True)
                        dfs(used + 1)
                        fill(r, c, size, False)
                    size -= 1
                return
    best = used
```

## 复杂度
时间：O(指数级分支)，最坏约 O(2^(n*m))，实际剪枝后远小于此。
空间：O(n*m) 递归栈与 `grid` 数组。

## 易错点
- 输入 `n=2, m=3` → 若只从 `size=min(n,m)=2` 开始枚举而忽略 `(0,0)` 处实际可用边长，会漏掉 1×1 组合 → 正确做法是每步用 `min(n-r, m-c)` 动态计算。
- 输入 `n=11, m=13` → 若不剪枝会超时 → 必须在 `used >= best` 时提前返回，并用剩余空格数下界剪枝。

## 如果面试官追问
问：n,m 扩大到 30 怎么办？答：回溯不可行，需改用数学公式或 DP 预处理小规模结果。
