## 一句话思路
枚举四个方向符号组合，把每步投影到该方向上累加，用 `min(k, 抵消数)` 修正后取最大。

## 怎么做
1. 曼哈顿距离可拆成四个线性式 `±x ±y` 的最大值，枚举 `(sx, sy) ∈ {1,-1}²`。
2. 对每个符号组合，维护 `pos`（同向步数）和 `neg`（反向步数），每读一个字符就更新。
3. 关键修正：把反向步改成同向，最多改 `k` 个，且只能改 `min(k, neg)` 个，故该前缀贡献为 `pos + min(k, neg)`。
4. 对每个前缀取四组符号下的最大值，再对前缀取最大。

以 `s = "NWSE", k = 1` 为例，取 `(sx, sy) = (1, 1)`：读到 `s[2]='S'` 时 `pos=1`（N 计 1）、`neg=2`（W、S 各计 1），贡献 `1 + min(1,2) = 2`；但取 `(sx, sy) = (1, -1)` 时 N、S 都算正向，`pos=2, neg=1`，贡献 `2 + min(1,1) = 3`，正是答案。

```python
best = 0
for sx, sy in ((1,1),(1,-1),(-1,1),(-1,-1)):
    pos = neg = 0
    for ch in s:
        if ch == 'N': d = sy
        elif ch == 'S': d = -sy
        elif ch == 'E': d = sx
        else: d = -sx
        if d > 0: pos += 1
        else: neg += 1
        best = max(best, pos + min(k, neg))
return best
```

注意 `d` 只取 `±1`，`neg` 统计的是「投影为负」的步数，不是字符种类数。

## 复杂度
时间 O(4n)：四组符号各扫一遍字符串，n 为 `len(s)`。
空间 O(1)：只开 `pos`、`neg`、`best` 几个整数。

## 易错点
- `s = "NNNN", k = 0` 时若把 `neg` 也当可改，会算出 `4 + 0` 之外的虚高值；正确做法是 `min(k, neg)`，`neg=0` 时修正量为 0。
- `s = "NS", k = 1` 若只枚举 `(1,1)` 一组符号，`pos=1, neg=1`，得 `1+1=2`；但取 `(1,-1)` 时 N、S 同向，`pos=2, neg=0`，得 2，说明单组符号会漏掉「南北同向」的配置，必须四组全枚举。

## 如果面试官追问
若要求输出修改后的字符串方案？答：在取到最大值的符号组与前缀处，把前 `min(k, neg)` 个反向字符改成该组正向字符即可。
