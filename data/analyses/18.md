## 一句话思路
排序后固定前两个数，后两个数用左右双指针夹逼，靠跳过相邻重复值去重。

## 怎么做
1. 先 `nums.sort()`，让相同值相邻，双指针和去重都依赖有序。
2. 外层 `i` 从 0 到 n-4，若 `i>0 and nums[i]==nums[i-1]` 则跳过。
3. 内层 `j` 从 i+1 到 n-3，同样跳过 `nums[j]==nums[j-1]`，然后 `l=j+1, r=n-1` 双指针。
4. 每轮算 `s = nums[i]+nums[j]+nums[l]+nums[r]`：`s<target` 则 `l+=1`，`s>target` 则 `r-=1`，相等则记录后 `l+=1; r-=1` 并各自跳过重复。

以 `nums=[1,0,-1,0,-2,2], target=0` 为例，排序得 `[-2,-1,0,0,1,2]`。取 `i=0`（-2）、`j=1`（-1）时，`l=2`（0）、`r=5`（2），`s=-2-1+0+2=-1<0`，`l` 移到 3；此时 `s=-2-1+0+2` 仍为 -1，`l` 移到 4，`s=-2-1+1+2=0`，记录 `[-2,-1,1,2]`。

```python
nums.sort()
n, res = len(nums), []
for i in range(n - 3):
    if i > 0 and nums[i] == nums[i - 1]:
        continue
    for j in range(i + 1, n - 2):
        if j > i + 1 and nums[j] == nums[j - 1]:
            continue
        l, r = j + 1, n - 1
        while l < r:
            s = nums[i] + nums[j] + nums[l] + nums[r]
            if s < target:
                l += 1
            elif s > target:
                r -= 1
            else:
                res.append([nums[i], nums[j], nums[l], nums[r]])
                l += 1
                r -= 1
                while l < r and nums[l] == nums[l - 1]:
                    l += 1
```

## 复杂度
时间：O(n³)，两层固定循环 O(n²) 各配一次 O(n) 双指针扫描。
空间：O(log n) 排序栈开销，结果集 `res` 不计入。

## 易错点
- 输入 `[2,2,2,2,2], target=8` → 若只在 `i`、`j` 层去重而相等分支里不跳过 `l` 的重复，会重复记录多个 `[2,2,2,2]` → 相等后必须 `l+=1; r-=1` 再 `while nums[l]==nums[l-1]` 跳过。
- 输入含 `10^9` 量级四数相加 → 若用 C++/Java 的 32 位 int 会溢出成错误比较 → Python 整数无溢出，直接比较 `s` 与 `target` 即可，不要人为截断。

## 如果面试官追问
问：n 放大到 1000 怎么办？答：改用两两求和存哈希表，O(n²) 时间 O(n²) 空间，注意同下标组合与重复四元组去重。
