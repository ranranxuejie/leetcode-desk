## 一句话思路
枚举所有非空连续子数组，用前缀积模 k 的哈希表 O(n·k) 统计每个余数出现次数。

## 怎么做
1. 操作等价于保留 nums 的一个非空连续子数组，所以答案是「所有非空子数组的乘积模 k 的余数分布」。
2. 维护 `pre[i] = nums[0]*...*nums[i-1] mod k`，则子数组 `[l, r)` 的余数是 `pre[r] * inv(pre[l]) mod k`——但 k 不一定是质数，逆元不存在，所以改用「以 r 结尾的余数分布」滚动更新。
3. 令 `dp[x]` 表示以当前元素结尾、余数为 x 的子数组个数，转移为 `new[(x * nums[i]) % k] += dp[x]`，再加上单独 `[nums[i]]` 这一项。
4. 每步把 `new` 累加进 `result`。

以示例 1 `nums = [1,2,3,4,5], k = 3` 为例：处理到 `nums[2] = 3` 时，`dp` 为 `{0:1, 1:1, 2:1}`（对应子数组 `[3]`、`[2,3]`、`[1,2,3]` 的余数 0/0/0 之外还要算上前面），乘 3 后全部落到余数 0，`new[0] = 3`，`result[0]` 累加到 9，与输出 `[9,2,4]` 一致。

```python
result = [0] * k
dp = [0] * k
for v in nums:
    ndp = [0] * k
    ndp[v % k] += 1
    for x in range(k):
        if dp[x]:
            ndp[(x * v) % k] += dp[x]
    for x in range(k):
        result[x] += ndp[x]
    dp = ndp
```

## 复杂度
时间 O(n·k)：n 是 nums 长度，内层固定循环 k 次，k ≤ 5。
空间 O(k)：只开 `dp`、`ndp`、`result` 三个长度 k 的数组。

## 易错点
- `nums = [1,2,4,8,16,32], k = 4` 时若用「前缀积 + 逆元」会翻车：`pre` 里出现 0（如 `1*2*4=8 ≡ 0`），0 没有逆元，除法失效。正确做法是用 `dp` 滚动转移，不做除法。
- 忘记 `ndp[v % k] += 1` 这一项：单独成段 `[nums[i]]` 的子数组不会被 `dp` 转移覆盖，示例 3 `nums=[1,1,2,1,1], k=2` 会少算 5 个单元素子数组，输出变成 `[4,6]` 而非 `[9,6]`。

## 如果面试官追问
问：若 k 放大到 10^9 怎么办？答：`dp` 数组开不下，改用字典只存出现过的余数，复杂度变成 O(n·不同余数数)，最坏仍 O(n·k)。
