## 一句话思路
从 A 的尾部（下标 m+n-1）倒着放最大值，用双指针 i=m-1、j=n-1 比较，避免覆盖 A 前段未处理元素。

## 怎么做
1. 令 `i = m - 1`、`j = n - 1`、`k = m + n - 1`，三个指针都指向各自有效区的末尾。
2. 每轮比较 `A[i]` 与 `B[j]`，把较大者写到 `A[k]`，对应指针左移，`k` 左移。
3. 当 `j < 0` 时 B 已放完，A 前段本来有序，直接结束；当 `i < 0` 时把 B 剩余部分逐个搬到 A 前段。

拿官方示例走关键一步：`A=[1,2,3,0,0,0], m=3, B=[2,5,6], n=3`，初始 `i=2, j=2, k=5`。第一轮 `A[2]=3 < B[2]=6`，写 `A[5]=6`，`j=1, k=4`；第二轮 `3 > B[1]=5` 不成立，写 `A[4]=5`，`j=0, k=3`；第三轮 `A[2]=3 > B[0]=2`，写 `A[3]=3`，`i=1, k=2`。此时 `A=[1,2,3,3,5,6]`，`j=0` 还没放完，继续把 `B[0]=2` 写到 `A[2]`，最终 `[1,2,2,3,5,6]`。

```python
i, j, k = m - 1, n - 1, m + n - 1
while j >= 0:
    if i >= 0 and A[i] > B[j]:
        A[k] = A[i]
        i -= 1
    else:
        A[k] = B[j]
        j -= 1
    k -= 1
```

循环条件只写 `j >= 0`：B 放完就收工，A 剩下的元素已在正确位置，不需要再搬。

## 复杂度
时间 O(m+n)：i 和 j 各最多走 m、n 步，每步 O(1)。
空间 O(1)：只在 A 原地写，没开额外数组。

## 易错点
- 输入 `A=[4,5,6,0,0,0], m=3, B=[1,2,3], n=3` → 若从前往后正序合并，写 `A[0]=1` 会覆盖掉 `A[0]=4`，后面 `4` 就丢了 → 必须从 `k=m+n-1` 倒着写，先落最大值。
- 输入 `A=[1,2,3,0,0,0], m=3, B=[4,5,6], n=3` → 若循环条件写成 `while i >= 0 and j >= 0`，B 全大于 A 时 `j` 一直没减，B 的三个元素一个都没写进去，输出仍是 `[1,2,3,0,0,0]` → 条件只判 `j >= 0`，`i >= 0` 放进 `if` 里当守卫。

## 如果面试官追问
问：若 A 没有尾部缓冲、要求返回新数组怎么办？
答：正序双指针从 0 开始，每次取 `A[i]`、`B[j]` 较小者追加到新数组，空间变 O(m+n)。
