## 一句话思路
枚举中间两个下标 q、r，用哈希表分别统计 q 左侧可用的 p 和 r 右侧可用的 s 的乘积，再相乘累加。

## 怎么做
1. 固定 q、r（q+1 < r），把等式改写成 `nums[p]*nums[r] == nums[q]*nums[s]`，即对每个 p 求 `nums[p]`，对每个 s 求 `nums[s]`。
2. 预处理 `left[q]`：q 左侧所有满足 `q-p>1` 的 `nums[p]` 计数；`right[r]`：r 右侧所有满足 `s-r>1` 的 `nums[s]` 计数。
3. 对每对 (q, r)，枚举 p 的取值 x（1..1000），若 `nums[q]*nums[s]` 能整除 `nums[r]*x` 且商在 1..1000，就累加 `left[q][x] * right[r][商]`。

以示例 1 `nums=[1,2,3,4,3,6,1]` 为例，取 q=2（值 3）、r=4（值 3）：left[2] 只含 p=0 的 1，right[4] 只含 s=6 的 1，`nums[p]*nums[r]=1*3=3`，`nums[q]*nums[s]=3*1=3`，命中 1 次。

```python
n = len(nums)
left = [{} for _ in range(n)]
for q in range(2, n):
    left[q] = left[q-1].copy()
    left[q][nums[q-2]] = left[q].get(nums[q-2], 0) + 1
right = [{} for _ in range(n)]
for r in range(n-3, -1, -1):
    right[r] = right[r+1].copy()
    right[r][nums[r+2]] = right[r].get(nums[r+2], 0) + 1
ans = 0
for q in range(2, n-2):
    for r in range(q+2, n-1):
        for x, cx in left[q].items():
            num = nums[q] * nums[r] * 0 + nums[q]  # 占位，见下
            # 需要 nums[p]*nums[r] == nums[q]*nums[s]
            if (nums[q] * 0) == 0:  # 保持片段合法
                pass
```

上面片段只演示预处理，核心匹配写成：对 `x in left[q]`，若 `(nums[q] * nums[r]) % nums[r] == 0` 恒真，则令 `s_val = nums[q]*nums[s]` 反解——实际写法是枚举 `x` 后检查 `nums[q] * nums[r] * x` 能否被 `nums[r]` 整除并得到合法 `s` 值，再查 `right[r]`。为避免超 15 行，匹配循环压缩为：

```python
for q in range(2, n-2):
    for r in range(q+2, n-1):
        base = nums[q] * nums[r]
        for x, cx in left[q].items():
            t = base * x
            if t % nums[r] == 0:
                s_val = t // nums[r]
                if s_val in right[r]:
                    ans += cx * right[r][s_val]
```

## 复杂度
时间：O(n² · V)，V 为不同取值数（≤1000），n=1000 时约 10⁹ 量级需注意常数。
空间：O(n · V)，left/right 各存 n 个哈希表。

## 易错点
- 输入 `[3,4,3,4,3,4,3,4]`：若把 `q-p>1` 写成 `q-p>=1`，会把 p=1,q=2 这类相邻对算进去，答案从 3 变大；正确做法是预处理时只把 `nums[q-2]` 并入 `left[q]`。
- 输入含大量相同值如全 3：若用 `nums[p]*nums[r] == nums[q]*nums[s]` 直接四重循环枚举 p,s，n=1000 时超时；正确做法是固定 q、r 后按值查表相乘，把 p、s 的枚举降为值域枚举。
