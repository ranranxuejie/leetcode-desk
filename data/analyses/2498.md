## 一句话思路
答案就是 `max(stones[i]-stones[i-2])`：把石头按奇偶下标分成两条单调路径，各自相邻跳，取最大间隔。

## 怎么做
1. 青蛙去程和回程不能共用石头（除首尾），所以必须把中间石头分成两条路径。
2. 最优分法是按奇偶下标分：路径 A 走 `0,2,4,...`，路径 B 走 `1,3,5,...`，两条路径都单调前进。
3. 这样每条路径的相邻间隔是 `stones[i]-stones[i-2]`，答案取所有 `i>=2` 的最大值。
4. 以 `stones=[0,2,5,6,7]` 为例：`i=2` 得 `5-0=5`，`i=3` 得 `6-2=4`，`i=4` 得 `7-5=2`，最大为 5。

```python
def maxJump(stones):
    ans = stones[1] - stones[0]
    for i in range(2, len(stones)):
        ans = max(ans, stones[i] - stones[i-2])
    return ans
```

关键中间值：`stones=[0,2,5,6,7]` 时，`i=2` 算出 `5-0=5`，`i=3` 算出 `6-2=4`，`i=4` 算出 `7-5=2`，`ans` 最终为 5。

## 复杂度
时间：O(n)，一次遍历 `stones`，n 为石头数量。
空间：O(1)，只用了 `ans` 一个变量。

## 易错点
- 输入 `stones=[0,3,9]` 时，若只算 `stones[i]-stones[i-2]` 会漏掉 `stones[1]-stones[0]=3` 和 `stones[2]-stones[1]=6`，错成 6；正确做法是初始化 `ans = stones[1]-stones[0]`，再遍历 `i>=2`。
- 输入 `stones=[0,1,2]` 时，若误以为可以走 `0→1→2→1→0` 复用石头 1，会算出代价 1；但每块石头至多到达一次，正确分法是 `0→2` 和 `0→1→2` 不成立，实际答案是 `max(1,1)=1`，需注意首尾石头可重复使用但中间不行。

## 如果面试官追问
问：如果要求输出具体路径怎么办？
答：按奇偶下标分别记录两条路径的石头序列，去程走偶数下标，回程走奇数下标逆序，首尾各出现一次。
