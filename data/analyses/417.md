## 一句话思路
从四边反向 DFS 往高处爬，分别标记能到太平洋、大西洋的格子，取交集。

## 怎么做
1. 建两个 `m×n` 布尔矩阵 `pac`、`atl`，分别从太平洋边（第 0 行、第 0 列）和大西洋边（第 m-1 行、第 n-1 列）出发做 DFS。
2. DFS 的进入条件是 `heights[nr][nc] >= heights[r][c]`——反向走，水能往下流等价于我们往上爬。
3. 两轮 DFS 结束后，遍历所有格子，`pac[r][c] and atl[r][c]` 为真就收进结果。

以示例 1 为例，从 `(0,4)=5` 出发向大西洋侧爬，`(1,4)=4`、`(1,3)=4`、`(2,2)=5` 依次被标记进 `atl`；而 `(0,4)` 本身也在太平洋边界上，所以 `pac[0][4]` 也为真，它进答案。反过来 `(2,4)=1` 只被 `atl` 标记，`pac` 为假，被排除。

```python
def dfs(r, c, seen):
    seen[r][c] = True
    for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
        nr, nc = r + dr, c + dc
        if 0 <= nr < m and 0 <= nc < n and not seen[nr][nc] \
           and heights[nr][nc] >= heights[r][c]:
            dfs(nr, nc, seen)

pac = [[False]*n for _ in range(m)]
atl = [[False]*n for _ in range(m)]
for r in range(m):
    dfs(r, 0, pac); dfs(r, n-1, atl)
for c in range(n):
    dfs(0, c, pac); dfs(m-1, c, atl)
return [[r, c] for r in range(m) for c in range(n) if pac[r][c] and atl[r][c]]
```

## 复杂度
时间 O(m·n)：每个格子最多被两轮 DFS 各访问一次。
空间 O(m·n)：两个布尔矩阵加递归栈，最坏栈深 m·n。

## 易错点
- 把比较写成 `heights[nr][nc] < heights[r][c]` 才继续：反向爬必须允许**相等**，示例 1 中 `(1,3)=4 → (1,4)=4` 高度相同仍要连通，写成严格小于会漏掉 `[1,3]` 这个答案。
- 只从 `(0,0)` 或四个角出发：太平洋边是整条第 0 行加第 0 列，示例 1 的 `(0,4)=5` 只在上边界、不在角上，漏掉它就会少 `[0,4]`；必须对 `range(m)` 和 `range(n)` 全边起 DFS。

## 如果面试官追问
问：m、n 到 2000 递归会爆栈怎么办？
答：把 `dfs` 换成显式栈的迭代版，`stack = [(r, c)]` 弹出后压入未访问的合法邻居，逻辑不变。
