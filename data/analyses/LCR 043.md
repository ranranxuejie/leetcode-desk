## 一句话思路
用 BFS 队列维护「还缺孩子」的节点，队首就是下一个新节点的父节点，插完两个孩子才出队。

## 怎么做
1. 初始化时 BFS 整棵树，把**孩子未满**的节点按层序入队（左空或右空都算）。
2. `insert(v)` 取 `q[0]` 作父节点：左孩子空就挂左边，否则挂右边。
3. 挂完检查该父节点是否已满，满了 `popleft()`。
4. 新节点自身孩子为空，`append` 进队尾。

以示例 2 的 `[1,2,3,4,5,6]` 为例：BFS 后队列是 `[3,4,5,6]`（1、2 已满被跳过）。第一次 `insert(7)` 取队首 `3`，左孩子空 → `3.left = 7`，返回 `3`；`3` 仍缺右孩子，留在队首。第二次 `insert(8)` 仍取 `3`，挂到 `3.right`，此时 `3` 满，`popleft()`，返回 `3`？——注意返回的是父节点值，第二次返回 `3`，但官方输出是 `4`，说明初始化时 `3` 的左孩子已存在（`6` 是 `3` 的左孩子），所以第一次 `insert(7)` 应挂 `3.right` 并返回 `3`，第二次取队首 `4` 挂左孩子返回 `4`。核对：`[1,2,3,4,5,6]` 中 6 是 3 的左孩子，故 3 只缺右孩子。

```python
from collections import deque

def _init(root):
    q = deque()
    dq = deque([root])
    while dq:
        node = dq.popleft()
        if node.left: dq.append(node.left)
        if node.right: dq.append(node.right)
        if not node.left or not node.right:
            q.append(node)
    return q

def _insert(q, v):
    parent = q[0]
    node = TreeNode(v)
    if not parent.left:
        parent.left = node
    else:
        parent.right = node
        q.popleft()
    q.append(node)
    return parent.val
```

## 复杂度
时间：初始化 O(n)，每次 insert O(1)（摊还），n 为初始节点数。
空间：队列最多存一层节点，O(n) 最坏，另存新节点本身。

## 易错点
- 初始化只把「左孩子空」的节点入队 → 像 `[1,2,3,4,5,6]` 里 `3` 左孩子是 `6`、右孩子空，会被漏掉，`insert(7)` 错挂到 `4` 上。正确做法是 `not node.left or not node.right` 都入队。
- 挂完右孩子忘记 `popleft()` → 队列里 `3` 一直留在队首，后续 `insert(8)` 又挂到已满的 `3` 上，覆盖或报错。正确做法是右孩子挂上后立刻出队。

## 如果面试官追问
若 insert 调用达 10^7 次、初始树 10^5 节点，队列方案还够吗？答：够，每次 insert 仍是 O(1) 摊还，队列长度不超过 O(n)，瓶颈只在初始化 BFS。
