## 一句话思路
用总方案数减乘积为奇数的方案数，奇数方案等价于 k 个正奇数求和为 n，用隔板法算。

## 怎么做
1. 总方案数：k 个正整数和为 n，即 C(n-1, k-1)。
2. 乘积为奇数 ⟺ 每个数都是奇数，令 a_i = 2b_i - 1（b_i ≥ 1），则 2·Σb_i - k = n，即 Σb_i = (n+k)/2。
3. 若 n+k 为奇数（即 n、k 奇偶性不同）则奇数方案为 0；否则奇数方案 = C((n+k)/2 - 1, k-1)。
4. 答案 = C(n-1,k-1) - 奇数方案，取模。

以 n=5, k=3 为例：总方案 C(4,2)=6；n+k=8 为偶数，Σb_i=4，奇数方案 C(3,2)=3；答案 6-3=3。

```python
MOD = 10**9 + 7
def countValidSequences(n, k):
    # 预处理阶乘与逆元（略），comb(a,b) 返回 C(a,b) mod MOD
    total = comb(n - 1, k - 1)
    if (n + k) % 2 == 1:
        return total
    odd = comb((n + k) // 2 - 1, k - 1)
    return (total - odd) % MOD
```

## 复杂度
时间：预处理阶乘 O(n)，每次查询 O(1)（n 贡献）。
空间：阶乘与逆元数组 O(n)。

## 易错点
- n=5, k=5：n+k=10 为偶数，奇数方案 C(4,4)=1，总方案 C(4,4)=1，答案 0；若漏判 n+k 奇偶性会算出负数或错值。
- n=3, k=2：总方案 C(2,1)=2，n+k=5 为奇数直接返回 2；若强行套奇数公式会得到 C(1,1)=1 的错误减数。
