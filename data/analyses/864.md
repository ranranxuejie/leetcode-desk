## 一句话思路
把「位置 + 已持钥匙集合」当作 BFS 状态，因为同一格带不同钥匙能走的路不同，必须分开记。

## 怎么做
1. 先扫一遍 grid，数出钥匙总数 `k`，并记下 `@` 的坐标作为起点。
2. 状态用 `(r, c, mask)`，`mask` 的 bit i 表示是否已拿到第 i 把钥匙；起点 mask 为 0。
3. BFS 逐层扩展，遇到小写字母就 `mask | (1 << (ord(ch) - 97))`，遇到大写字母先检查 `mask >> (ord(ch) - 65) & 1` 是否为 1。
4. 当 `mask == (1 << k) - 1` 时返回当前步数，队列空了返回 -1。

以示例 1 `["@.a..","###.#","b.A.B"]` 为例，k=2，起点 (0,0)。第 1 步到 (0,1) 时 mask 仍是 0；第 2 步踩到 `a`，mask 变成 `0b01`；此时 (0,2) 这个状态是 `(0,2,1)`，而如果之前以 mask=0 到过 (0,2) 也不能算重复，因为钥匙不同。

```python
from collections import deque
k = sum(ch.islower() for row in grid for ch in row)
full = (1 << k) - 1
q = deque([(sr, sc, 0, 0)])
seen = {(sr, sc, 0)}
while q:
    r, c, mask, d = q.popleft()
    for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
        nr, nc = r + dr, c + dc
        if not (0 <= nr < m and 0 <= nc < n) or grid[nr][nc] == '#':
            continue
        ch, nm = grid[nr][nc], mask
        if ch.islower():
            nm |= 1 << (ord(ch) - 97)
        elif ch.isupper() and not (mask >> (ord(ch) - 65) & 1):
            continue
        if nm == full:
            return d + 1
        if (nr, nc, nm) not in seen:
            seen.add((nr, nc, nm))
            q.append((nr, nc, nm, d + 1))
return -1
```

## 复杂度
时间 O(m·n·2^k)，每个格子最多配 2^k 种钥匙状态各入队一次。
空间 O(m·n·2^k)，`seen` 集合存三元组，队列同阶。

## 易错点
- 输入 `["@Aa"]`：若把 `seen` 只按 `(r,c)` 去重，走到 `A` 时 mask=0 被挡，返回 -1 是对的；但若在 `["@aA"]` 里漏了 mask 维度，会误判 `a` 之后的位置已访问而提前剪枝，正确做法是 `seen` 必须含 mask。
- 输入 `["@.a..","###.#","b.A.B"]`：若一拿到钥匙就返回，会在拿到 `a` 后立刻返回 2，而目标是拿全两把钥匙，正确做法是只在 `nm == full` 时返回。

## 如果面试官追问
问：k 增大到 20 怎么办？答：2^k 状态爆炸，需换思路，比如先求钥匙间最短路再状压 DP，仍是 2^k 但常数更小。
