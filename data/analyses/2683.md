## 一句话思路
把 derived 全部异或起来，等于 0 就存在 original，因为每个 original[i] 恰好出现两次。

## 怎么做
1. 设 original 为 `o[0..n-1]`，把 derived 的 n 个式子全部异或。
2. 每个 `o[i]` 在 `derived[i-1]` 和 `derived[i]` 里各出现一次，两两抵消，左边恒为 0。
3. 所以 `derived[0] ^ derived[1] ^ ... ^ derived[n-1] == 0` 是充要条件，直接判它。
4. 以 `derived = [1,1,0]` 为例：`1 ^ 1 = 0`，`0 ^ 0 = 0`，结果为 0，返回 `True`；`[1,0]` 得 `1 ^ 0 = 1`，返回 `False`。

```python
def doesValidArrayExist(derived):
    x = 0
    for v in derived:
        x ^= v
    return x == 0
```

关键中间值：`[1,1,0]` 累到 `x = 0`；`[1,0]` 累到 `x = 1`，非 0 即无解。

## 复杂度
时间：O(n)，遍历 derived 一次，异或累加。
空间：O(1)，只开一个累加变量 `x`。

## 易错点
- 只检查 `derived` 里 1 的个数是否为偶数 → 对 `[1,1,0]` 会算成 2 个 1、判 `True` 碰巧对，但 `[1,1,1,1]` 也是偶数个 1 却同样成立，真正判据是异或和为 0，别用计数代替。
- 试图真的构造 original 再验证 → n 到 10^5 时多写一层循环和数组，且构造时若从 `o[0]=0` 出发推到最后一位不闭合会误判，正确做法是只判异或和，不构造。

## 如果面试官追问
问：要求输出一个合法 original 怎么办？
答：令 `o[0]=0`，递推 `o[i+1]=o[i]^derived[i]`，异或和为 0 时最后一位必闭合。
