## 一句话思路
枚举左端点，向右扩展时用哈希表维护每个值的频次，并实时判断「频次只有 f 和 2f 两种且都出现」是否成立。

## 怎么做
1. 外层枚举左端点 `i`，内层 `j` 从 `i` 向右扫，`cnt[nums[j]] += 1`。
2. 维护 `freq` 字典：键是「出现次数」，值是「有多少个不同值恰好出现这么多次」，每次 `cnt` 变化时同步更新。
3. 判定条件：`freq` 的键集合只能是 `{f}` 或 `{f, 2*f}`；前者要求只有一个不同值（单元素子数组），后者要求两个键都存在。
4. 满足就更新 `ans = max(ans, j - i + 1)`。

以 `nums = [1,2,2,1,2,3,3,3]`、`i = 1` 为例：扫到 `j = 5` 时子数组是 `[2,2,1,2,3,3]`，`cnt = {2:3, 1:1, 3:2}`，`freq = {3:1, 1:1, 2:1}`，键集合 `{1,2,3}` 不合法；退到 `j = 4` 时 `cnt = {2:3, 1:1, 3:1}`，`freq = {3:1, 1:2}`，键集合 `{1,3}` 也不是 `{f,2f}` 形式，继续左移才命中 `[2,1,2,3,3]`（`i=1,j=5` 的另一种切法）——真正答案是 `i=1` 起 `[2,1,2,3,3]` 长度 5，此时 `cnt = {2:2,1:1,3:2}`，`freq = {2:2, 1:1}`，键集合 `{1,2}` 恰为 `f=1` 与 `2f=2`，合法。

```python
for i in range(n):
    cnt, freq = {}, {}
    for j in range(i, n):
        x = nums[j]
        old = cnt.get(x, 0)
        if old:
            freq[old] -= 1
            if freq[old] == 0:
                del freq[old]
        cnt[x] = old + 1
        freq[old + 1] = freq.get(old + 1, 0) + 1
        keys = freq.keys()
        if len(keys) == 1:
            f = next(iter(keys))
            if f == 1 and len(cnt) == 1 or len(cnt) == 1:
                ans = max(ans, j - i + 1)
        elif len(keys) == 2:
            a, b = sorted(keys)
            if b == 2 * a:
                ans = max(ans, j - i + 1)
```

## 复杂度
时间：O(n²)，外层 n 个左端点，内层均摊 O(1) 更新哈希表。
空间：O(n)，`cnt` 与 `freq` 最多各存 n 个键。

## 易错点
- 输入 `[5,5,5,5]`：只出现一种值，`freq` 键集合是 `{4}`，若只判 `{f,2f}` 会漏掉，必须单独放行「只有一个不同值」的情形，答案才是 4 而不是 1。
- 输入 `[1,2,3,4]`：`freq` 键集合是 `{1}` 但 `len(cnt) == 4`，若把「键集合只有一个」直接当合法会错答 4；正确做法是键集合为 `{1}` 时还要求 `len(cnt) == 1`，答案才是 1。

## 如果面试官追问
问：n 放大到 10^5 怎么办？答：O(n²) 不可行，需按 f 分块枚举频次上界并配合前缀计数，或改用双指针加频次直方图剪枝。
