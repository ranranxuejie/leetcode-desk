## 一句话思路
把二维网格按行优先拉成一维数组，右移 `k % (m*n)` 位再按原形状填回。

## 怎么做
1. 算出总格数 `total = m * n`，令 `k %= total`，因为迁移 `total` 次回到原样。
2. 把 `grid` 按行优先展平成 `flat`，长度 `total`。
3. 新位置 `i` 上的元素来自 `flat[(i - k) % total]`，等价于整体右移 `k`。
4. 按 `m` 行 `n` 列切回二维。

以示例 1 为例：`grid = [[1,2,3],[4,5,6],[7,8,9]]`，`m=3, n=3, total=9, k=1`。展平后 `flat = [1,2,3,4,5,6,7,8,9]`；新数组第 0 位取 `flat[(0-1)%9] = flat[8] = 9`，第 1 位取 `flat[0] = 1`，第 2 位取 `flat[1] = 2`，前三格正好是 `[9,1,2]`，与输出首行一致。

```python
m, n = len(grid), len(grid[0])
total = m * n
k %= total
flat = [grid[i][j] for i in range(m) for j in range(n)]
res = [[0] * n for _ in range(m)]
for i in range(total):
    res[i // n][i % n] = flat[(i - k) % total]
return res
```

关键就一行：`flat[(i - k) % total]`。`i - k` 可能为负，Python 的 `%` 会返回非负余数，正好处理回绕，不用额外加 `total`。

## 复杂度
时间：O(m·n)，展平一次、填回一次，`k` 已取模不参与循环。
空间：O(m·n)，额外开了 `flat` 和 `res` 两个数组。

## 易错点
- `k` 不取模直接算：如示例 3 的 `k=9`、`total=9`，`(i-9)%9` 虽也对，但若 `k=100`、`total=9` 时 `i-k` 绝对值变大，逻辑仍对却多绕；正确做法是先 `k %= total`，让 `k` 落在 `[0, total)`。
- 把「右移」写成「左移」：示例 1 中若用 `flat[(i + k) % total]`，第 0 位会取 `flat[1] = 2`，得到 `[[2,3,4],...]`，与期望 `[[9,1,2],...]` 相反；迁移是元素往后挪，新位置 `i` 应取旧位置 `i - k`。

## 如果面试官追问
问：若 `k` 可达 `10**9` 且要求原地迁移？
答：仍先 `k %= total`，再对一维下标做三次反转（整体、前 `k`、后 `total-k`），空间降到 O(1)。
