## 一句话思路
答案就是 `n - 1`（n=1 时为 1），因为 n 能推出 2..n-1 全部数字，而 1 永远不出现。

## 怎么做
1. 先看 n=1 的边界：桌上只有 1，`1 % i == 1` 要求 i 整除 0 且 i≤1，只有 i=1，但 1 已在桌上，所以答案是 1。
2. n≥2 时，n 本身满足 `n % (n-1) == 1`，所以 n-1 一定进桌。
3. 关键递推：若 x 在桌上且 x≥3，则 `x % (x-1) == 1`，x-1 也进桌。以 n=5 为例，5→4→3→2 逐天全部出现，中间值就是这条链 5,4,3,2。
4. 1 永远不出现：任何 x 都满足 `x % 1 == 0`，不满足余 1。所以最终集合恰为 {2,...,n}，共 n-1 个。

```python
def distinctIntegers(n):
    return 1 if n == 1 else n - 1
```

不用真的模拟 10^9 天，链长最多 n-1 天就稳定了。

## 复杂度
时间 O(1)，只做一次判断和减法，与 n 无关。
空间 O(1)，不建集合、不模拟天数。

## 易错点
- 输入 n=1 → 若直接返回 `n-1` 得 0，错；正确做法是特判返回 1，因为 1 本身就在桌上。
- 输入 n=2 → 若以为要模拟多天或漏掉 2，可能返回 1；实际 `2 % 1 == 0` 不产生新数，桌上只有 {2}，答案 1，恰好等于 `n-1`，别把这条当成反例去特判。

## 如果面试官追问
问：若规则改成 `x % i == 0` 呢？答：那 1 会立刻出现，且所有因子链会扩散，答案不再是 n-1，需要真正用集合模拟到不动点。
