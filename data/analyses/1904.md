## 一句话思路
把两个时刻换算成分钟数，答案就是 `finish // 15 - ceil(start / 15)`，跨夜时给 finish 加 1440。

## 怎么做
1. 写 `to_min(t)` 把 `"HH:MM"` 转成 `int(t[:2]) * 60 + int(t[3:])`。
2. 若 `finish < start`，令 `finish += 1440` 表示通宵。
3. 起点向上取整到下一个刻钟：`first = (start + 14) // 15`。
4. 终点向下取整：`last = finish // 15`，返回 `max(0, last - first)`。

以示例 1 为例：`start = 721`，`finish = 764`。`first = (721 + 14) // 15 = 735 // 15 = 49`，对应 12:15；`last = 764 // 15 = 50`，对应 12:30。`50 - 49 = 1`，正好是 12:15–12:30 那一局。

```python
def to_min(t):
    return int(t[:2]) * 60 + int(t[3:])

s, f = to_min(startTime), to_min(finishTime)
if f < s:
    f += 1440
first = (s + 14) // 15
last = f // 15
return max(0, last - first)
```

关键在 `(s + 14) // 15`：`s` 恰好是 15 的倍数时（如 12:15 = 735），`(735 + 14) // 15 = 49`，不会把自己那一局漏掉；`s = 721` 时得 49，跳过 12:00 那局。

## 复杂度
时间：O(1)，只做常数次整数运算和两次长度 5 的字符串切片。
空间：O(1)，只开了 `s`、`f`、`first`、`last` 四个整数。

## 易错点
- `startTime = "12:15"` 时若写成 `start // 15 + 1`，会得 50，把 12:15–12:30 这局整局丢掉，输出 0 而非 1；正确做法是向上取整 `(s + 14) // 15`，整除时结果不变。
- `startTime = "20:00", finishTime = "06:00"` 时若不加 1440，`f = 360 < s = 1200`，`last - first` 为负，`max(0, ...)` 会返回 0 而非 40；正确做法是先判 `f < s` 再 `f += 1440`，此时 `first = 80`、`last = 1800 // 15 = 120`，差为 40。

## 如果面试官追问
问：若对局周期改成任意 `k` 分钟且起点偏移 `off`，怎么改？
答：把 15 换成 `k`，`first = ceil((s - off) / k)`、`last = floor((f - off) / k)`，其余不变。
