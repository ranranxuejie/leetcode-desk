## 一句话思路
用三个布尔量 `seen_digit`、`seen_dot`、`seen_e` 从左到右扫一遍，每类字符只允许在特定状态下出现。

## 怎么做
1. 初始化 `seen_digit = seen_dot = seen_e = False`，遍历 `s` 的每个字符 `c`。
2. 遇到数字：置 `seen_digit = True`。
3. 遇到 `.`：若 `seen_dot or seen_e` 为真则返回 `False`，否则置 `seen_dot = True`。
4. 遇到 `e/E`：若 `seen_e or not seen_digit` 为真则返回 `False`，否则置 `seen_e = True` 并把 `seen_digit` 重置为 `False`（指数部分必须重新有数字）。
5. 遇到 `+/-`：只有当它是首字符，或前一个字符是 `e/E` 时才合法，否则返回 `False`。
6. 遍历结束返回 `seen_digit`。

以 `s = "e"` 为例：第 0 个字符是 `e`，此时 `seen_digit` 仍为 `False`，触发第 4 步的 `not seen_digit` 条件，直接返回 `False`。以 `s = "."` 为例：扫完只有 `seen_dot = True`、`seen_digit = False`，末尾返回 `False`。

```python
seen_digit = seen_dot = seen_e = False
for i, c in enumerate(s):
    if c.isdigit():
        seen_digit = True
    elif c in "+-":
        if i > 0 and s[i-1] not in "eE":
            return False
    elif c == ".":
        if seen_dot or seen_e:
            return False
        seen_dot = True
    elif c in "eE":
        if seen_e or not seen_digit:
            return False
        seen_e, seen_digit = True, False
    else:
        return False
return seen_digit
```

## 复杂度
时间 O(n)：`n = len(s)`，每个字符常数次判断，无嵌套。
空间 O(1)：只开了三个布尔量和循环变量 `i`、`c`。

## 易错点
- 输入 `"4."` 或 `"-.9"` → 若要求小数点两侧都有数字就会误判为 `False` → 正确做法是小数点只检查 `seen_dot` 和 `seen_e`，不检查 `seen_digit`，末尾统一用 `seen_digit` 兜底。
- 输入 `"1e"` 或 `"3e+7"` → 若遇到 `e` 后不重置 `seen_digit`，`"1e"` 会被判成 `True` → 正确做法是置 `seen_e = True` 的同时把 `seen_digit` 清成 `False`，让指数部分必须重新攒出数字。

## 如果面试官追问
问：如果允许 `s` 里出现空格或下划线怎么办？
答：在 `else` 分支前加一条 `elif c in " _": return False`，其余状态机不变。
