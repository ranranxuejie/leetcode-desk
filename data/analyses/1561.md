## 一句话思路
排序后从最大端每隔一个取一个，取 n 次，因为每轮你只能拿中间那堆，最大堆必然被 Alice 拿走。

## 怎么做
1. 对 `piles` 升序排序，长度记为 `m = 3n`。
2. 你每轮拿的是「第二大」，所以最大的那堆永远归 Alice，你只能从剩余里挑次大。
3. 把最小的 n 堆全部留给 Bob（他拿最少的，不占你的份额），剩下的 2n 堆里 Alice 和你交替拿。
4. 从下标 `m-2` 开始，每次减 2，取 n 个，累加。

以 `piles = [2,4,1,2,7,8]` 为例：排序后 `[1,2,2,4,7,8]`，`m=6`，`n=2`。从下标 `4` 取值 `7`，再取下标 `2` 的值 `2`，和 `9`。中间变量：`sorted = [1,2,2,4,7,8]`，取的索引是 `4, 2`。

```python
piles.sort()
m = len(piles)
n = m // 3
total = 0
for i in range(m - 2, m - 2 - 2 * n, -2):
    total += piles[i]
return total
```

等价写法：`sum(piles[m-2-2*k] for k in range(n))`。

关键点：Bob 拿最小的 n 堆，Alice 拿最大的 n 堆，你拿中间夹着的 n 个「次大」。排序后这三段是连续的，你的那段正好是 `[n, 2n)` 区间里从大到小隔一个取。

## 复杂度
时间：排序 `O(m log m)`，`m = 3n`，遍历 `O(n)`，总体 `O(n log n)`。
空间：排序原地 `O(1)` 额外（Python `sort` 是 Timsort，最坏 `O(n)` 辅助）。

## 易错点
- 输入 `[2,4,5]`：如果从下标 `m-1` 开始取，会拿到 `5`（Alice 的），正确应从 `m-2=1` 取 `4`。起点必须是 `m-2`，不是 `m-1`。
- 输入 `[9,8,7,6,5,1,2,3,4]`：若只取最大的 n 个（`9,8,7` 里的次大），会错成 `8+7+6=21`；正确是排序后 `[1,2,3,4,5,6,7,8,9]`，从下标 `7` 取 `8`、下标 `5` 取 `6`、下标 `3` 取 `4`，和 `18`。必须跳过 Alice 的最大堆，隔一个取。

## 如果面试官追问
问：如果要求输出每轮具体选哪三堆怎么办？
答：排序后第 k 轮取 `piles[k]`（给 Bob）、`piles[m-2-2k]`（给你）、`piles[m-1-k]`（给 Alice），三段各取一个即可。
