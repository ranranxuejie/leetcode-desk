## 一句话思路
对每个格子做 DFS 求「以它为起点的最长递增路径」，用 `memo` 缓存结果，因为递增约束让图无环，重复子问题可复用。

## 怎么做
1. 建 `memo = [[0]*n for _ in range(m)]`，`0` 表示未算过。
2. 对每个 `(i,j)` 调 `dfs(i,j)`，取全局最大值。
3. `dfs` 内先查 `memo[i][j]`，非 0 直接返回；否则对四个邻居中 `matrix[ni][nj] > matrix[i][j]` 的取 `1 + dfs(ni,nj)` 的最大值，写回 `memo`。
4. 递增条件保证不会回到自己，无需 `visited`。

以示例 1 `[[9,9,4],[6,6,8],[2,1,1]]` 为例，从 `(2,1)` 值 `1` 出发：邻居 `(1,1)=6`、`(2,0)=2`、`(2,2)=1` 中只有 `6`、`2` 更大；`dfs(1,1)` 又只能走向 `(0,1)=9`，于是 `memo[1][1]=2`、`memo[2][1]=3`，最终 `dfs(2,0)` 得 `1+3=4`，对应路径 `1→2→6→9`。

```python
def dfs(i, j):
    if memo[i][j]:
        return memo[i][j]
    best = 1
    for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
        ni, nj = i+di, j+dj
        if 0 <= ni < m and 0 <= nj < n and matrix[ni][nj] > matrix[i][j]:
            best = max(best, 1 + dfs(ni, nj))
    memo[i][j] = best
    return best
```

外层 `ans = max(dfs(i,j) for i in range(m) for j in range(n))`。

## 复杂度
时间：`O(m*n)`，每个格子只算一次，四邻居常数。
空间：`O(m*n)` 的 `memo` 加递归栈，栈深最坏 `m*n`。

## 易错点
- 全相等矩阵如 `[[1,1],[1,1]]` → 若把 `>=` 当递增条件会死循环或错算成 4 → 必须严格 `matrix[ni][nj] > matrix[i][j]`，答案应为 1。
- 忘记写回 `memo[i][j] = best` 只查不存 → 示例 1 中 `(1,1)` 会被反复展开，退化成指数级 → 每次 `dfs` 返回前必须赋值。

## 如果面试官追问
问：要求输出具体路径而不只是长度？答：`memo` 改存 `(长度, 下一格坐标)`，从最大值格子顺着指针走即可还原。
