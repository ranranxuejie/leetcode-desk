## 一句话思路
预处理 `bad[i]` 表示 `nums[i]` 与 `nums[i-1]` 奇偶相同，再用前缀和判断区间内是否有 `bad`。

## 怎么做
1. 构造 `bad`：`bad[i] = (nums[i] - nums[i-1]) % 2 == 0`，`bad[0] = 0`。
2. 对 `bad` 做前缀和 `pre`，`pre[i+1] = pre[i] + bad[i]`。
3. 查询 `[l, r]`：区间内 `bad` 之和为 `pre[r+1] - pre[l+1]`，等于 0 则 `True`。

以 `nums = [3,4,1,2,6]` 为例：`bad = [0,0,0,0,1]`（`2` 和 `6` 同为偶数），`pre = [0,0,0,0,0,1]`。查询 `[0,4]` 得 `pre[5] - pre[1] = 1 - 0 = 1 > 0`，返回 `False`。

```python
n = len(nums)
bad = [0] * n
for i in range(1, n):
    bad[i] = 1 if (nums[i] - nums[i - 1]) % 2 == 0 else 0
pre = [0] * (n + 1)

    pre[i + 1] = pre[i] + bad[i]

```

注意 `pre[l+1]` 而非 `pre[l]`：`bad[l]` 描述的是 `nums[l-1]` 与 `nums[l]` 的关系，不属于子数组内部。

## 复杂度
时间：O(n + q)，n 为 `nums` 长度、q 为 `queries` 长度，每次查询 O(1)。
空间：O(n)，额外开了 `bad` 和 `pre` 两个长度 n 的数组。

## 易错点
- 查询 `[l, r]` 写成 `pre[r+1] - pre[l]` → 把 `bad[l]`（`nums[l-1]` 与 `nums[l]` 的奇偶关系）算进区间，`nums = [4,3,1,6]`、查询 `[2,3]` 时 `bad[2]=1` 被误算，返回 `False`，正确应为 `True`。正确做法是减 `pre[l+1]`。
- 用 `nums[i] % 2 != nums[i-1] % 2` 判特殊却漏掉 `l == r` 的单元素区间 → 单元素子数组没有相邻对，应恒为 `True`；前缀和写法下 `pre[r+1] - pre[l+1] = 0` 自然成立，但若改成逐对循环判断需特判 `l == r` 直接返回 `True`。

## 如果面试官追问
追问：如果 `nums` 会动态修改（单点更新），怎么答查询？
答：用线段树维护每个位置的 `bad` 值，区间求和为 0 即特殊，更新 O(log n)、查询 O(log n)。
