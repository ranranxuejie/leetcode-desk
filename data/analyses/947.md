## 一句话思路
把每块石头的 x、y 当作图节点，同行同列即连边，答案 = n − 连通分量数。

## 怎么做
1. 用并查集，节点是坐标值；为避免 x 与 y 撞号，把 y 映射成 `y + 10001`（或 `~y`）。
2. 遍历 `stones`，对每块石头 `union(x, y+10001)`，同一次 union 就把同行同列串起来。
3. 统计根节点个数 `roots`，返回 `len(stones) - roots`。

以示例 1 为例：`stones = [[0,0],[0,1],[1,0],[1,2],[2,1],[2,2]]`，6 块石头全部通过 x=0/1/2 与 y=0/1/2 连成一张图，`roots = 1`，答案 `6 - 1 = 5`。示例 2 中 `[1,1]` 的 x=1、y=1 都只出现一次，自成一个分量，`roots = 2`，答案 `5 - 2 = 3`。

```python
parent = {}
def find(a):
    parent.setdefault(a, a)
    while parent[a] != a:
        parent[a] = parent[parent[a]]
        a = parent[a]
    return a
def union(a, b):
    ra, rb = find(a), find(b)
    if ra != rb:
        parent[ra] = rb

for x, y in stones:
    union(x, y + 10001)
roots = len({find(k) for k in parent})
return len(stones) - roots
```

关键中间值：示例 1 跑完后 `parent` 里所有键的 `find` 结果都是同一个根，`roots` 恰为 1。

## 复杂度
时间 O(n·α(n))，n 为石头数，α 为并查集近似常数。
空间 O(n)，`parent` 最多存 2n 个坐标键。

## 易错点
- 输入 `[[0,0],[0,2],[1,1],[2,0],[2,2]]` → 若直接把 x、y 当同一命名空间，`[1,1]` 会自己 union 自己、`x=1` 与 `y=1` 混为一谈，`roots` 算成 1、答案错成 4 → 必须给 y 加偏移（如 `y + 10001`）区分行列。
- 输入 `[[0,0]]` → 若返回 `len(stones) - roots` 前忘了每块石头至少占一个分量，或误把单点也算可移除，会输出 1 → 单块石头 `roots = 1`，答案 0，公式本身正确，别额外加特判。

## 如果面试官追问
要求输出具体移除顺序怎么办？答：在并查集基础上对每个分量建生成树，按叶子到根的顺序输出即可，答案数不变。
