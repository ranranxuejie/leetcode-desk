## 一句话思路
用前缀和 + 二维 DP：`dp[j][i]` 表示前 i 个数分 j 段的最大平均和，枚举最后一段起点转移。

## 怎么做
1. 先算前缀和 `pre[i]`，任意区间 `[t, i)` 的平均值就是 `(pre[i]-pre[t])/(i-t)`。
2. `dp[j][i]` 只依赖 `dp[j-1][t]`（t < i），所以按段数 j 从小到大、i 从小到大填表。
3. 转移：`dp[j][i] = max(dp[j-1][t] + (pre[i]-pre[t])/(i-t))`，t 从 j-1 到 i-1。
4. 答案取 `dp[k][n]`；注意「最多 k 段」时最优一定用满 k 段（拆开只会增大或持平），所以直接用 k。

以 `nums=[9,1,2,3,9], k=3` 为例，`pre=[0,9,10,12,15,24]`。填到 `dp[2][4]` 时，t=1 得 `dp[1][1]+(15-9)/3 = 9+2 = 11`，t=2 得 `dp[1][2]+(15-10)/2 = 9+2.5 = 11.5`，t=3 得 `dp[1][3]+(15-12)/1 = 9+3 = 12`，取 12。最终 `dp[3][5] = dp[2][4] + 9 = 12+9 = 21`？实际最优是 `[9],[1,2,3],[9]`，`dp[2][4]=11`，加 9 得 20——说明 t 要枚举到让第二段是 `[1,2,3]`，即 `dp[1][1]=9` 配 `(15-9)/3=2`，得 11，再加末段 9 得 20。

```python
n = len(nums)
pre = [0] * (n + 1)
for i, x in enumerate(nums):
    pre[i + 1] = pre[i] + x
dp = [[0.0] * (n + 1) for _ in range(k + 1)]
for i in range(1, n + 1):
    dp[1][i] = pre[i] / i
for j in range(2, k + 1):
    for i in range(j, n + 1):
        best = 0.0
        for t in range(j - 1, i):
            cand = dp[j - 1][t] + (pre[i] - pre[t]) / (i - t)
            if cand > best:
                best = cand
        dp[j][i] = best
return dp[k][n]
```

## 复杂度
时间：O(k·n²)，三层循环 j、i、t 各贡献一维。
空间：O(k·n)，dp 表；前缀和 O(n)。

## 易错点
1. 输入 `nums=[9,1,2,3,9], k=3` 时，若把「最多 k 段」理解成可以少于 k 段并只填 `dp[1..k]` 取最大，会漏掉必须用满的情况；正确做法是直接返回 `dp[k][n]`，因为拆段不会让平均值和变小。
2. 内层 t 的下界写成 0 而非 `j-1`，会让 `dp[j-1][t]` 在 t 太小时无意义（前 t 个数不够分 j-1 段），得到 0 参与比较污染结果；正确做法是 `range(j-1, i)`。

## 如果面试官追问
问：n 放大到 10⁴ 怎么办？答：O(kn²) 会超时，需用斜率优化或凸包把内层 t 的枚举降到均摊 O(1)。
