## 一句话思路
排序后让最小配最大、次小配次大，最大数对和即为首尾配对和的最大值。

## 怎么做
1. 对 `nums` 升序排序，得到 `s`。
2. 用双指针 `i=0`、`j=n-1`，每次取 `s[i] + s[j]`，然后 `i += 1`、`j -= 1`。
3. 在所有配对和中取最大值返回。

以 `nums = [3,5,2,3]` 为例：排序后 `s = [2,3,3,5]`。第一对 `s[0]+s[3] = 2+5 = 7`，第二对 `s[1]+s[2] = 3+3 = 6`，`max(7,6) = 7`，与示例一致。

关键中间值：排序后 `s[0]=2` 与 `s[3]=5` 配对得 7，这是本题的答案来源；若把 2 和 3 配对、3 和 5 配对，则最大和变成 8，更差。

```python
s = sorted(nums)
i, j = 0, len(s) - 1
ans = 0
while i < j:
    ans = max(ans, s[i] + s[j])
    i += 1
    j -= 1
return ans
```

为什么首尾配对最优：若存在两对 `(a,d)`、`(b,c)` 满足 `a≤b≤c≤d` 却配成 `(a,b)`、`(c,d)`，则 `c+d ≥ a+d`，交换成 `(a,d)`、`(b,c)` 不会让最大和变大。反复交换即可把方案变成首尾配对，且不劣于原方案。

## 复杂度
时间：排序 `O(n log n)`，双指针扫描 `O(n)`，总 `O(n log n)`。
空间：排序额外 `O(n)`（Python `sorted` 返回新列表），双指针只用两个下标。

## 易错点
- 输入 `nums = [3,5,2,3]` 若只取相邻配对 `(2,3)`、`(3,5)`，最大和得 8 而非 7 → 必须首尾配对，不能顺序两两切。
- 输入 `nums = [4,1,5,2]` 若忘记排序直接首尾取 `4+2=6`、`1+5=6`，看似也对，但换成 `[1,100,2,3]` 不排序会得 `1+3=4`、`100+2=102`，答案 102 远大于正确值 101（排序后 `1+100=101`、`2+3=5`）→ 排序是前提，不能省。

## 如果面试官追问
问：要求输出具体配对方案怎么办？
答：排序后按 `(s[i], s[j])` 依次输出即可，同一最大和下方案可能不唯一，任一组都合法。
