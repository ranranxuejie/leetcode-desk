## 一句话思路
BFS 层序入队（空节点也入队），一旦弹出 `None`，之后若再弹出非空节点就说明有洞，返回 `False`。

## 怎么做
1. 用 `collections.deque` 存节点，初始 `q = deque([root])`，空节点用 `None` 占位。
2. 循环 `popleft`：弹出 `None` 就把 `seen_none = True` 置位；弹出非空节点时若 `seen_none` 已为真，直接返回 `False`。
3. 非空节点照常把 `p.left`、`p.right` 入队（`None` 也入），保证层序位置信息不丢。
4. 队列耗尽返回 `True`。

以示例 2 `[1,2,3,4,5,null,7]` 为例：队列依次弹出 `1,2,3,4,5`，此时 `seen_none` 仍为 `False`；接着弹出 `None`（3 的左孩子），置 `seen_none = True`；再弹出 `7`（3 的右孩子），非空且 `seen_none` 已真 → 返回 `False`。关键中间值就是 `seen_none` 在弹出 `7` 前已经变成 `True`。

```python
from collections import deque

def isCompleteTree(root):
    q = deque([root])
    seen_none = False
    while q:
        node = q.popleft()
        if node is None:
            seen_none = True
        else:
            if seen_none:
                return False
            q.append(node.left)
            q.append(node.right)
    return True
```

注意 `q.append(node.left)` 不判空，正是靠 `None` 占位才能区分「最后一层左对齐」和「中间缺洞」。

## 复杂度
时间 O(n)：每个节点及其两个空孩子各入队一次，共约 3n 次操作。
空间 O(n)：队列最宽时约存一层节点加空位，最坏 n/2 量级。

## 易错点
- 输入 `[1,2,3,4,5,null,7]`：若只判「遇到第一个空孩子就停」，会漏掉后面的 `7`，错判成 `True`；正确做法是空节点也入队，让 `7` 有机会被弹出并触发 `seen_none` 检查。
- 输入 `[1,2,3,4,5,6]`（示例 1）：若把 `None` 直接跳过不入队，队列里只剩非空节点，`seen_none` 永远为 `False`，任何树都返回 `True`；必须显式 `append(None)` 保留位置。

## 如果面试官追问
问：节点数放大到 10^5 且要求 O(1) 额外空间怎么办？
答：改用「节点编号」法，根编号 1，左孩子 `2i`、右孩子 `2i+1`，DFS 记录最大编号与节点总数，判 `max_idx == n` 即可，递归栈 O(h)。
