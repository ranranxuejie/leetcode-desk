## 一句话思路
固定首轮三种取法之一得到的分数 `target`，在剩余区间上做记忆化搜索，返回最多操作数。

## 怎么做
1. 首轮只有三种可能：`nums[0]+nums[1]`、`nums[-2]+nums[-1]`、`nums[0]+nums[-1]`，答案必是其中之一的最优值。
2. 对每个 `target`，定义 `dfs(l, r)`：区间 `[l, r]` 内所有操作分数都等于 `target` 时最多还能做几次。
3. 三种删法分别检查 `nums[l]+nums[l+1]`、`nums[r-1]+nums[r]`、`nums[l]+nums[r]` 是否等于 `target`，等于就 `1 + dfs(...)` 取最大。
4. 用 `(l, r)` 做记忆化键，`l >= r` 返回 0。

以 `nums = [3,2,1,2,3,4]` 为例，取 `target = nums[0]+nums[1] = 5`：`dfs(0,5)` 里 `nums[0]+nums[5]=3+4=7` 不等于 5，`nums[4]+nums[5]=3+4=7` 也不等于 5，只有删前两个 `3+2=5` 合法，转入 `dfs(2,5)`；此时 `nums[2]+nums[5]=1+4=5`，继续删首尾，最终得 3。

```python
from functools import lru_cache

def solve(target):
    @lru_cache(None)
    def dfs(l, r):
        if l >= r:
            return 0
        best = 0
        if nums[l] + nums[l+1] == target:
            best = max(best, 1 + dfs(l+2, r))
        if nums[r-1] + nums[r] == target:
            best = max(best, 1 + dfs(l, r-2))
        if nums[l] + nums[r] == target:
            best = max(best, 1 + dfs(l+1, r-1))
        return best
    return dfs(0, len(nums)-1)

n = len(nums)
return max(solve(nums[0]+nums[1]), solve(nums[-2]+nums[-1]), solve(nums[0]+nums[-1]))
```

## 复杂度
时间：每个 `target` 有 O(n²) 个区间状态，三种取法共 O(n²)。
空间：记忆化表存 O(n²) 个 `(l, r)` 结果，递归栈 O(n)。

## 易错点
- `nums = [1,1,1,1]` 这类全等数组：若只跑 `nums[0]+nums[1]` 一种 `target` 就返回，会漏掉首尾配对更优的情况；必须三种首轮分数都跑一遍取 `max`。
- `nums = [3,2,6,1,4]`：`target=5` 时 `dfs(0,4)` 里 `nums[0]+nums[4]=7`、`nums[3]+nums[4]=5` 合法删尾两个，但若写成 `nums[r]+nums[r-1]` 越界或写成 `nums[l]+nums[l+1]` 误判，会多算一次；删尾必须用 `r-1` 和 `r`。

## 如果面试官追问
问：n 涨到 10⁵ 怎么办？
答：区间 DP 的 O(n²) 状态撑不住，需要利用「分数固定」把可行区间收缩成线性扫描或哈希计数。
