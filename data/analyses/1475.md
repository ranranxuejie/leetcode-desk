## 一句话思路
用单调栈存「还没找到折扣的下标」，栈内价格从底到顶单调不增，遇到 `prices[i]` 不大于栈顶价格就弹栈结算。

## 怎么做
1. 建 `ans = prices[:]`，栈 `st = []`，从左到右扫 `i`。
2. 每轮先 `while st and prices[st[-1]] >= prices[i]`，弹出 `j` 并令 `ans[j] = prices[j] - prices[i]`。
3. 再把 `i` 压栈，扫完栈里剩下的下标保持原价。

以 `prices = [8,4,6,2,3]` 为例：`i=0` 压 0；`i=1` 时 `prices[0]=8 >= 4`，弹出 0，`ans[0]=8-4=4`，压 1；`i=2` 时 `prices[1]=4 < 6` 不弹，压 2；`i=3` 时 `prices[2]=6 >= 2` 弹 2 得 `ans[2]=4`，再 `prices[1]=4 >= 2` 弹 1 得 `ans[1]=2`，压 3；`i=4` 时 `prices[3]=2 < 3` 不弹。结果 `[4,2,4,2,3]`。

```python
ans = prices[:]
st = []
for i, p in enumerate(prices):
    while st and prices[st[-1]] >= p:
        j = st.pop()
        ans[j] = prices[j] - p
    st.append(i)
return ans
```

关键在 `>=`：示例 3 的 `[10,1,1,6]` 里 `i=2` 的 `1` 必须弹掉 `i=1` 的 `1`，否则 `ans[1]` 会错留成 1 而不是 0。

## 复杂度
时间 O(n)：每个下标最多进栈一次、出栈一次，`while` 总弹栈次数不超过 n。
空间 O(n)：`st` 最坏存 n 个下标（如 `[1,2,3,4,5]` 全程不弹），`ans` 另占 n。

## 易错点
- 写成 `prices[st[-1]] > p`（严格大于）→ 对 `[10,1,1,6]` 会得 `[9,1,1,6]`，`ans[1]` 错成 1；题面要求 `prices[j] <= prices[i]`，必须用 `>=` 才让后面的等值价格成为折扣。
- 直接原地改 `prices[j]` 再拿它和栈顶比 → 对 `[8,4,6,2,3]` 处理 `i=3` 时栈里 `prices[1]` 已被改成 2，比较基准就错了；正确做法是保留原 `prices` 只读，折扣写进 `ans`。

## 如果面试官追问
若要求返回每个商品对应的折扣下标而非价格？答：把 `ans[j] = prices[j] - p` 换成记录 `i`，栈逻辑不变，仍是 O(n)。
