## 一句话思路
用线段树维护 nums1 的区间 1 的个数，操作 2 只需把 `p * 当前1的总数` 累加到 nums2 总和上，不必真的改 nums2。

## 怎么做
1. 先算 `base = sum(nums2)`，线段树只存 nums1 每个区间的 1 的个数，根节点即当前 1 的总数。
2. 操作 1 对 `[l, r]` 做区间翻转：懒标记取反，节点值改为 `区间长度 - 原值`。
3. 操作 2 不碰 nums2，直接 `base += p * 根节点值`。
4. 操作 3 把 `base` 追加进答案。

以示例 1 为例：`nums1=[1,0,1]`，初始根节点值 = 2，`base = 0`。执行 `[1,1,1]` 翻转下标 1 后，根节点值变为 3；再执行 `[2,1,0]`，`base += 1 * 3 = 3`；`[3,0,0]` 输出 3。

```python
def apply(node, lo, hi):
    cnt[node] = (hi - lo + 1) - cnt[node]
    lazy[node] ^= 1

def push(node, lo, hi):
    if lazy[node]:
        mid = (lo + hi) // 2
        apply(node*2, lo, mid)
        apply(node*2+1, mid+1, hi)
        lazy[node] = 0

def update(node, lo, hi, l, r):
    if l <= lo and hi <= r:
        apply(node, lo, hi); return
    push(node, lo, hi)
    mid = (lo + hi) // 2
    if l <= mid: update(node*2, lo, mid, l, r)
    if r > mid: update(node*2+1, mid+1, hi, l, r)
    cnt[node] = cnt[node*2] + cnt[node*2+1]
```

## 复杂度
时间：建树 O(n)，每次操作 1 是 O(log n)，操作 2/3 是 O(1)，总计 O(n + q log n)。
空间：线段树 `cnt` 和 `lazy` 各开 4n，额外 O(n)。

## 易错点
1. 操作 2 的 `p` 可以到 10^6、n 到 10^5，单次累加可达 10^11，多次叠加后 `base` 会超过 2^31-1。题目要求答案按 32 位截断时，Python 里不会溢出但结果会偏大，需在追加答案时处理；若题目不要求截断则直接用 Python 大整数即可，别照搬 C++ 的 `long long` 思维去手动取模。
2. 翻转区间时忘记用 `区间长度 - cnt[node]` 而是写成 `1 - cnt[node]`，对长度大于 1 的节点（如示例 1 翻转 `[1,1]` 后根节点应为 3 而非 2）会算错，必须用 `hi - lo + 1`。

## 如果面试官追问
问：如果操作 2 的 `p` 每次不同且要求输出 nums2 每个元素？答：需对 nums1 做区间加 `p` 的懒标记并维护 nums2 的区间和，线段树要同时存两个数组的聚合值。
