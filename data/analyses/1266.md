## 一句话思路
相邻两点间耗时等于切比雪夫距离 `max(|dx|, |dy|)`，逐段累加即可。

## 怎么做
1. 遍历 `points` 的相邻点对 `(points[i-1], points[i])`。
2. 对每对算 `dx = abs(x2 - x1)`、`dy = abs(y2 - y1)`。
3. 累加 `max(dx, dy)`，因为斜走能同时消掉两个方向的差，剩下的直线补足。
4. 返回总和。

以示例 1 的 `[[1,1],[3,4],[-1,0]]` 为例：第一段 `dx=2, dy=3`，取 `max=3`；第二段从 `[3,4]` 到 `[-1,0]`，`dx=4, dy=4`，取 `max=4`；累加得 `3+4=7`。关键中间值就是这两段的 `max` 值，而不是 `dx+dy`（那会得 5 和 8，总和 13）。

```python
total = 0
for i in range(1, len(points)):
    x1, y1 = points[i - 1]
    x2, y2 = points[i]
    total += max(abs(x2 - x1), abs(y2 - y1))
return total
```

注意 `points` 长度可能为 1，此时循环不执行，直接返回 0，符合「已在起点」的语义。

## 复杂度
时间：O(n)，n 为点数，每对点做常数次运算。
空间：O(1)，只开 `total`、`dx`、`dy` 等标量。

## 易错点
- 输入 `[[3,2],[-2,2]]` → 若误用欧氏距离 `sqrt(dx²+dy²)` 会得 5.0 但语义错，若误用 `dx+dy` 会得 5 恰好对，但换成 `[[1,1],[3,4]]` 就错成 5（正确 3）→ 必须用 `max(abs(dx), abs(dy))`。
- 输入 `points` 只有 1 个点 → 若循环写成 `range(len(points))` 并访问 `points[i-1]`，`i=0` 时取到 `points[-1]` 自己，虽然差为 0 不报错，但若改成 `points[i+1]` 会越界 → 循环起点固定为 `1`，终点 `len(points)`。

## 如果面试官追问
问：若要求输出具体路径而非总时间？答：每段先斜走 `min(dx,dy)` 步，再沿剩余方向直走 `|dx-dy|` 步，按此顺序生成坐标序列即可。
