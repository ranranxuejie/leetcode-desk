## 一句话思路
枚举中间人 j，用树状数组分别统计 j 左侧比它小的个数和右侧比它大的个数，两者相乘即递增三元组数，递减同理。

## 怎么做
1. 对 rating 做离散化，把值域压到 1..n，便于树状数组下标。
2. 从左往右扫，`left_small[j]` = 已插入的（即 j 左侧）比 rating[j] 小的个数；插入 rating[j]。
3. 从右往左扫，`right_greater[j]` = 已插入的（即 j 右侧）比 rating[j] 大的个数；插入 rating[j]。
4. 递增方案 = Σ left_small[j] * right_greater[j]；递减方案把两次查询换成「左侧比它大」「右侧比它小」，同样相乘求和。

以 rating = [2,5,3,4,1] 为例，j=2（rating[2]=3）时，左侧比 3 小的只有 2，`left_small[2]=1`；右侧比 3 大的只有 4，`right_greater[2]=1`，贡献 1，对应 (2,3,4)。

```python
def numTeams(rating):
    n = len(rating)
    rank = {v: i + 1 for i, v in enumerate(sorted(rating))}
    def count(smaller_left):
        bit = [0] * (n + 1)
        def add(i):
            while i <= n:
                bit[i] += 1; i += i & -i
        def query(i):
            s = 0
            while i > 0:
                s += bit[i]; i -= i & -i
            return s
        res = [0] * n
        order = range(n) if smaller_left else range(n - 1, -1, -1)
        for j in order:
            r = rank[rating[j]]
            res[j] = query(r - 1) if smaller_left else query(n) - query(r)
            add(r)
        return res
    ls, rg = count(True), count(False)
    lg, rs = count(False), count(True)  # 复用：左侧更大 / 右侧更小
    return sum(ls[j] * rg[j] + lg[j] * rs[j] for j in range(n))
```

## 复杂度
时间：O(n log n)，n 次扫描每次树状数组查询/更新 O(log n)。
空间：O(n)，离散化字典 rank 与树状数组 bit 各占 O(n)。

## 易错点
- rating = [1,2,3,4] 时若只算递增忘了递减，会得 4 而非正确答案 4（本例恰好递减为 0），但换成 [4,3,2,1] 就漏成 0；必须两方向都累加。
- 离散化时若直接用 rating 值当下标（最大 10^5），树状数组开到 10^5 虽可行但浪费；更隐蔽的坑是查询写成 `query(r)` 而非 `query(r-1)`，把自身算进「比它小」，[2,5,3,4,1] 会多算。

## 如果面试官追问
问：n 放大到 10^5 还能这么做吗？
答：能，O(n log n) 不变，只需把离散化换成排序去重，树状数组大小取 n。
