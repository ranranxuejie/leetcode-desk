## 一句话思路
用滚动哈希从右往左滑窗，O(1) 更新每个长度 k 子串的哈希值，边滑边比 `hashValue`。

## 怎么做
1. 先算最右窗口 `s[n-k:]` 的哈希：`h = sum(val(s[n-k+i]) * power**i) % modulo`，同时记下 `power**(k-1) % modulo` 备用。
2. 从 `i = n-k-1` 往左滑到 0，每次把新字符 `s[i]` 放到最低位、旧窗口整体乘 `power`、再减掉溢出窗口的最高位。
3. 每滑一步先判 `h == hashValue`，命中就更新答案（因为从右往左，最后命中的就是最左的）。
4. 循环结束后返回答案。

以示例 2 `s="fbxzaad", power=31, modulo=100, k=3` 为例：最右窗口 `"aad"` 的 `h = (1 + 1*31 + 4*961) % 100 = 3876 % 100 = 76`。滑到 `"xza"` 时，`h = (24 + 76*31 - 4*31**2) % 100`，其中 `31**2 % 100 = 61`，得 `(24 + 2356 - 244) % 100 = 36`。继续滑到 `"bxz"` 得 32，最后到 `"fbx"` 也是 32，答案取最左的 `"fbx"`。

```python
n = len(s)
p = power % modulo
pk = pow(power, k - 1, modulo)
h = 0
for i in range(n - k, n):
    h = (h + (ord(s[i]) - 96) * pow(power, i - (n - k), modulo)) % modulo
ans = ""
for i in range(n - k, -1, -1):
    if h == hashValue:
        ans = s[i:i + k]
    if i > 0:
        h = (h * p - (ord(s[i + k - 1]) - 96) * pk + (ord(s[i - 1]) - 96)) % modulo
return ans
```

## 复杂度
时间 O(n)：一次预处理加 n 次 O(1) 滚动更新，`pow` 只算常数次。
空间 O(1)：只存 `h`、`pk`、`ans`，返回的切片长度 k 不计入额外空间。

## 易错点
- `power` 或 `power**(k-1)` 很大时直接算会爆慢：`power` 可达 1e9、`k` 可达 2e4，必须用 `pow(power, k-1, modulo)` 取模，且滚动时用 `p = power % modulo`，否则中间值巨大。
- 减法后 Python 的 `%` 返回非负，但若照搬 C++ 写法 `h = h*p - ...` 不取模，`h` 会变负导致比较失败：每次更新后必须 `% modulo`，别只在最后取模。

## 如果面试官追问
问：如果要求返回所有匹配子串的起始下标怎么办？
答：把 `ans = s[i:i+k]` 换成 `ans.append(i)`，仍从右往左扫，最后反转列表即可，复杂度不变。
