## 一句话思路
用滚动变量做 DP：`dp[i]` 表示前 i 位数字的解密方案数，每次只看最后一位单独成码、最后两位合并成码两种转移。

## 怎么做
1. 把 `ciphertext` 转成字符串 `s`，令 `a = 1`（空串方案数）、`b = 1`（首字符方案数）。
2. 从 `i = 1` 遍历到 `len(s)-1`，每轮先算 `cur = b`（`s[i]` 单独成码，只要不是前导 0 就合法）。
3. 若 `s[i-1]` 与 `s[i]` 组成的两位数在 10~25 之间，则 `cur += a`（两位合并成码）。
4. 滚动更新 `a, b = b, cur`，循环结束返回 `b`。

以 `ciphertext = 216612` 为例，`s = "216612"`。走到 `i = 2`（字符 `'6'`）时，`a = 2`（对应 `"21"` 的两种解法：`"ba"`、`"u"`），`b = 3`（对应 `"216"`）；`s[1:3] = "16"` 落在 10~25，所以 `cur = 3 + 2 = 5`，即 `"2166"` 有 5 种解法。继续到 `i = 5` 得 `b = 6`，与示例输出一致。

```python
s = str(ciphertext)
a, b = 1, 1
for i in range(1, len(s)):
    cur = b if s[i] != '0' else 0
    two = int(s[i-1:i+1])
    if 10 <= two <= 25:
        cur += a
    a, b = b, cur
return b
```

注意 `s[i] != '0'` 这个判断：`'0'` 不能单独成码，只能和前一位拼成 `"10"` 或 `"20"`，这正是 `two` 区间判断要覆盖的情况。

## 复杂度
时间 O(n)：n 为 `ciphertext` 的十进制位数，每位做一次常数比较。
空间 O(n)：`str(ciphertext)` 额外开了长度 n 的字符串，DP 本身只用两个变量。

## 易错点
- 输入 `ciphertext = 0`（或 `10`、`100`）→ 若把 `b` 初值写成 0 或漏掉 `s[i] != '0'` 判断，会把 `"0"` 当成可单独成码，`10` 错算成 2 种 → 正确做法是 `'0'` 单独成码时 `cur` 记 0，只允许 `"10"`/`"20"` 走两位转移。
- 输入 `ciphertext = 106` → 若两位判断写成 `two <= 25` 而漏掉下界 10，`"06"` 会被当成合法两位码，答案从 1 错成 2 → 必须写 `10 <= two <= 25`，前导 0 的两位数一律不合法。

## 如果面试官追问
问：要输出所有解密方案而不只是数量怎么办？
答：把滚动变量换成 `dp[i]` 存字符串列表，转移时对每个前缀方案追加 `chr(int(s[i])+97)` 或 `chr(int(s[i-1:i+1])+97)`，空间升到方案总数级别。
