## 一句话思路
按结束日排序后做 DP：`dp[i][j]` 表示前 i 个会议选 j 个的最大价值，用二分找与第 i 个会议不冲突的最后一个会议，转移时在「选」和「不选」间取大。

## 怎么做
1. 把 `events` 按 `endDay` 升序排序，这样处理到第 i 个会议时，所有可能与之兼容的会议都在它前面。
2. 预处理 `prev[i]`：在 `events[0..i-1]` 中二分查找满足 `endDay <= startDay_i` 的最大下标，找不到记 -1。
3. 定义 `dp[i][j]` 为前 i 个会议（下标 0..i-1）中选至多 j 个的最大价值，`dp[0][*] = 0`。
4. 转移：`dp[i][j] = max(dp[i-1][j], dp[prev[i-1]+1][j-1] + value)`，注意 `prev` 存的是 0-based 下标，加 1 才是「前多少个」。

以示例 1 为例：排序后 `events = [[1,2,4],[2,3,1],[3,4,3]]`。处理第 3 个会议 `[3,4,3]` 时，`startDay=3`，前面 `endDay <= 3` 的有 `[1,2,4]`（end=2）和 `[2,3,1]`（end=3），二分得 `prev[2] = 1`。于是 `dp[3][2] = max(dp[2][2], dp[2][1] + 3) = max(5, 4+3) = 7`。

```python
events.sort(key=lambda e: e[1])
ends = [e[1] for e in events]
prev = [bisect_right(ends, e[0], 0, i) - 1 for i, e in enumerate(events)]
dp = [[0] * (k + 1) for _ in range(n + 1)]
for i in range(1, n + 1):
    p = prev[i - 1] + 1
    for j in range(1, k + 1):
        dp[i][j] = max(dp[i - 1][j], dp[p][j - 1] + events[i - 1][2])
return dp[n][k]
```

## 复杂度
时间：排序 O(n log n)，每个会议对 k 做一次转移共 O(nk)，二分 O(n log n)。
空间：`dp` 是 (n+1)×(k+1) 的二维表，`prev`/`ends` 各 O(n)。

## 易错点
1. 用 `bisect_left` 而非 `bisect_right`：示例 1 中 `[2,3,1]` 的 `endDay=3` 与 `[3,4,3]` 的 `startDay=3` 相等，题目规定结束日包含在内、不能相接，必须用 `bisect_right` 才能把 end=3 的会议算作兼容，用 `bisect_left` 会漏掉它，`dp[3][2]` 错算成 4。
2. `prev` 存 0-based 下标、`dp` 是 1-based 前缀，转移时忘了 `+1`：示例 1 中 `prev[2]=1`，若直接写 `dp[1][j-1]` 就只算了 `[1,2,4]` 一个会议，正确应是 `dp[2][j-1]` 覆盖前两个会议。

## 如果面试官追问
问：k 很大（如 k ≥ n）时能否省掉一维？答：可以，此时等价于「加权区间调度」一维 DP，`dp[i] = max(dp[i-1], dp[prev[i-1]+1] + value)`，O(n log n)。
