## 一句话思路
Y 的格子集合是固定的，只需枚举「Y 涂 a、非 Y 涂 b」这 6 种 (a≠b)，用计数矩阵算代价取最小。

## 怎么做
1. 先按几何条件把每个格子标成 `inY`：`r == c` 或 `r + c == n - 1` 且 `r <= mid`，或 `c == mid` 且 `r >= mid`，其中 `mid = n // 2`。
2. 用两个长度 3 的数组 `cntY`、`cntO` 分别统计 Y 内、Y 外各值出现次数。
3. 对 6 组 `(a, b)`，`a != b`，代价 = `(sizeY - cntY[a]) + (sizeO - cntO[b])`，取最小。
4. 以示例 1 `grid = [[1,2,2],[1,1,0],[0,1,0]]`，`n=3, mid=1`：Y 格是 (0,0)=1、(0,2)=2、(1,1)=1、(2,1)=1，共 4 格，`cntY = [0,3,1]`；非 Y 5 格 `cntO = [2,2,1]`。取 `a=1, b=0`：`(4-3) + (5-2) = 3`，与输出一致。

```python
mid = n // 2
cntY, cntO = [0]*3, [0]*3
for r in range(n):
    for c in range(n):
        inY = (r == c or r + c == n - 1) and r <= mid or (c == mid and r >= mid)
        (cntY if inY else cntO)[grid[r][c]] += 1
sizeY = sum(cntY); sizeO = n*n - sizeY
ans = min((sizeY - cntY[a]) + (sizeO - cntO[b])
          for a in range(3) for b in range(3) if a != b)
```

## 复杂度
时间 O(n²)：遍历整个矩阵一次，之后 6 组常数枚举。
空间 O(1)：只开 `cntY`、`cntO` 两个长度 3 的数组。

## 易错点
- 中心格 (mid, mid) 同时满足三条线，若三条线分别累加会把中心算 3 次，`sizeY` 偏大、代价算错；正确做法是用 `inY` 布尔判断，每格只加一次。
- 忘记 `a != b` 约束：若允许 `a == b`，示例 1 会得到 `(4-3)+(5-3)=3` 看似对，但示例 2 会选出 Y 与非 Y 同值，违反「两者不同」条件而偏小；必须显式排除 `a == b`。

## 如果面试官追问
若 n 大到 10⁵ 且只给稀疏 Y 坐标？答：仍只需统计 Y 内计数，非 Y 用全局计数减 Y 计数得到，O(|Y|) 即可。
