## 一句话思路
遍历链表，对每对相邻结点用 `math.gcd` 求值，就地在其间插入新结点。

## 怎么做
1. 用 `cur = head` 从第一个结点开始走，循环条件写 `while cur and cur.next`，这样单结点链表（示例 2 的 `[7]`）直接跳过循环返回原链表。
2. 每轮先算 `g = math.gcd(cur.val, cur.next.val)`，再建 `node = ListNode(g)`。
3. 插入顺序不能反：先 `node.next = cur.next`，再 `cur.next = node`，最后 `cur = node.next` 跳到原来的下一个结点。
4. 以 `[18,6,10,3]` 为例，第一轮 `cur.val=18`、`cur.next.val=6`，`g=6`，插入后链变 `18→6(新)→6`，`cur` 移到原 `6`；第二轮 `gcd(6,10)=2`，第三轮 `gcd(10,3)=1`，得到 `[18,6,6,2,10,1,3]`。

```python
import math

cur = head
while cur and cur.next:
    g = math.gcd(cur.val, cur.next.val)
    node = ListNode(g)
    node.next = cur.next
    cur.next = node
    cur = node.next
return head
```

关键在 `cur = node.next`：`node.next` 就是原来的 `cur.next`，所以下一轮比较的是原链表里紧挨着的两个结点，新插入的 `g` 不会被再次拿去求 gcd。

## 复杂度
时间 O(n log V)：n 个结点各做一次 gcd，单次 gcd 代价 O(log V)，V ≤ 1000。
空间 O(1)：只开了 `cur`、`g`、`node` 几个变量，新结点是题目要求的输出本身。

## 易错点
- 输入 `[18,6,10,3]` 若写成 `cur = cur.next` 而不是 `cur = node.next`，指针会停在刚插入的 gcd 结点上，下一轮变成 `gcd(6,6)=6`，输出多出错误结点；必须跳到 `node.next`。
- 输入 `[7]`（单结点）若循环条件写成 `while cur.next`，`cur.next` 为 `None` 时判断本身不报错但语义上漏了 `cur` 判空，遇到空链表 `head=None` 会直接 `AttributeError`；统一写 `while cur and cur.next` 才两种边界都安全。

## 如果面试官追问
问：不新建结点、只改指针能做到吗？
答：不能，插入必然增加 n-1 个结点，只能新建；能优化的是把 `math.gcd` 换成手写欧几里得，避免 import。
