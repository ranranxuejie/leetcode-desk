## 一句话思路
从右往左扫，遇到 `#` 就取前两位数字拼成两位数，否则取一位，倒序拼接后反转。

## 怎么做
1. 初始化 `i = len(s) - 1`、`res = []`，指针从末尾开始。
2. 若 `s[i] == '#'`，则 `num = int(s[i-2:i])`，`i -= 3`；否则 `num = int(s[i])`，`i -= 1`。
3. 用 `chr(ord('a') + num - 1)` 转成字母，`append` 进 `res`。
4. 循环结束后 `return ''.join(reversed(res))`。

以 `s = "10#11#12"` 为例：`i=8` 是 `'2'`，取一位得 `num=2` → `'b'`，`i=7`；`i=7` 是 `'1'`，得 `'a'`，`i=6`；`i=6` 是 `'#'`，取 `s[4:6]="11"` 得 `'k'`，`i=3`；`i=3` 是 `'#'`，取 `s[1:3]="10"` 得 `'j'`，`i=0` 结束。`res = ['b','a','k','j']`，反转后 `"jkab"`。

```python
i, res = len(s) - 1, []
while i >= 0:
    if s[i] == '#':
        num = int(s[i-2:i])
        i -= 3
    else:
        num = int(s[i])
        i -= 1
    res.append(chr(ord('a') + num - 1))
return ''.join(reversed(res))
```

关键点：`#` 一定跟在两位数字后面，所以从右往左时 `#` 的位置是确定的，不会出现「先看到 `1` 却不知道它是不是 `10#` 的开头」的歧义——这正是倒序扫描成立的原因。

## 复杂度
时间 O(n)：`i` 每次至少减 1，最多扫 n 个字符。
空间 O(n)：`res` 存 n/2 到 n 个字符，`join` 再开一份结果串。

## 易错点
- 输入 `"10#11#12"` 若从左往右贪心取一位，会把 `'1'` 先解成 `'a'`，剩下 `"0#..."` 直接崩掉 → 必须靠 `#` 反向定位，或正向时先看 `s[i+2]` 是否为 `'#'`。
- 输入 `"26#"` 若切片写成 `s[i-2:i+1]` 会多带 `#`，`int("26#")` 抛 `ValueError` → 切片右端必须是 `i`（不含 `#`），即 `s[i-2:i]`。

## 如果面试官追问
问：若允许 `#` 表示三位数（如 `100#`）怎么改？
答：把 `i -= 3` 和切片改成按 `#` 前连续数字个数动态取，或正向扫时先探测 `#` 位置再回退。
