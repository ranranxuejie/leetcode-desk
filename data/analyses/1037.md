## 一句话思路
用叉积判断三点是否共线：向量 (p1-p0) 与 (p2-p0) 的叉积为 0 则共线，非 0 才是回旋镖。

## 怎么做
1. 取 `p0, p1, p2 = points`，把三个点拆成坐标。
2. 算两个向量 `v1 = (p1[0]-p0[0], p1[1]-p0[1])`、`v2 = (p2[0]-p0[0], p2[1]-p0[1])`。
3. 算叉积 `cross = v1[0]*v2[1] - v1[1]*v2[0]`，返回 `cross != 0`。

以示例 1 `[[1,1],[2,3],[3,2]]` 为例：`v1 = (1,2)`，`v2 = (2,1)`，`cross = 1*1 - 2*2 = -3`，非 0，返回 `True`。示例 2 `[[1,1],[2,2],[3,3]]`：`v1 = (1,1)`，`v2 = (2,2)`，`cross = 1*2 - 1*2 = 0`，返回 `False`。

```python
p0, p1, p2 = points
v1x, v1y = p1[0] - p0[0], p1[1] - p0[1]
v2x, v2y = p2[0] - p0[0], p2[1] - p0[1]
cross = v1x * v2y - v1y * v2x
return cross != 0
```

叉积非 0 同时蕴含了「三点不共线」，而三点不共线必然蕴含「三点互不相同」——若 `p0 == p1`，则 `v1 = (0,0)`，叉积恒为 0。所以一个 `cross != 0` 就同时覆盖了「各不相同」和「不在一条直线上」两个条件，不需要额外写去重判断。

## 复杂度
时间：O(1)，固定三个点，只做常数次减法与乘法。
空间：O(1)，只开了 `v1x/v1y/v2x/v2y/cross` 几个标量。

## 易错点
- 输入 `[[0,0],[0,0],[1,1]]` → 若只判共线不判重合，`v1=(0,0)` 会让 `cross=0` 恰好返回 `False`，看似对；但 `[[0,0],[1,1],[1,1]]` 里 `v2=(1,1)`、`v1=(1,1)` 也是 `cross=0`，同样返回 `False`。真正危险的是**先做去重再判共线**的写法：去重后只剩两个点，索引会越界。正确做法是直接算叉积，靠 `cross != 0` 一并排除重合。
- 输入 `[[0,0],[1,0],[2,0]]` → 若用斜率 `(y1-y0)/(x1-x0) == (y2-y0)/(x2-x0)` 判断，水平线时分母为 0 会抛 `ZeroDivisionError`；竖直线同理。正确做法是用乘法形式的叉积，不做除法。

## 如果面试官追问
问：如果 points 长度是 n，要数出所有回旋镖三元组怎么办？
答：枚举 `i<j<k` 算叉积非 0 计数，O(n³)；可用哈希按斜率分组优化，但重合点要单独处理。
