## 一句话思路
把 val 拆成质因子指数向量，用记忆化 DFS 按位枚举乘/除/留，指数向量相等即值相等。

## 怎么做
1. 预处理：把 k 和每个 nums[i] 分解成 2、3、5 的指数向量（nums[i]≤6，质因子只可能是这三个），k 含其他质因子则直接返回 0。
2. 状态定义为 `(i, e2, e3, e5)`，表示处理到下标 i 时 val 的指数向量；目标向量是 k 的指数向量。
3. 每个位置三选一：指数分别加、减、不变，递归到 i+1，用 `lru_cache` 记忆化。
4. 以 `nums=[2,3,2], k=6` 为例：k 的向量是 (1,1,0)；走到 i=2 时若已选乘 2、乘 3，则当前向量 (1,1,0) 已等于目标，第三位选「留」即计数 +1。

```python
from functools import lru_cache

def countSequences(nums, k):
    def fac(x):
        res = [0, 0, 0]
        for idx, p in enumerate((2, 3, 5)):
            while x % p == 0:
                res[idx] += 1
                x //= p
        return res if x == 1 else None
    target = fac(k)
    if target is None:
        return 0
    vecs = [fac(v) for v in nums]

    @lru_cache(maxsize=None)
    def dfs(i, e2, e3, e5):
        if i == len(nums):
            return int((e2, e3, e5) == tuple(target))
        a, b, c = vecs[i]
        return (dfs(i + 1, e2 + a, e3 + b, e5 + c)
                + dfs(i + 1, e2 - a, e3 - b, e5 - c)
                + dfs(i + 1, e2, e3, e5))
    return dfs(0, 0, 0, 0)
```

## 复杂度
时间：O(n · E2 · E3 · E5)，指数上界由 nums 总和与 k 的指数决定，n≤19。
空间：记忆化表同阶，递归栈 O(n)。

## 易错点
- `nums` 含 1 时，乘 1 和除 1 是两个不同序列但指数向量不变 → 若把「乘/除」合并成一种会少算，示例 3 应得 3 而非 2，必须保留三个分支各自计数。
- k 含 7 等非 2/3/5 质因子（如 k=7）→ 任何操作都凑不出，若分解后不检查余数会错误地继续搜索并返回非 0，正确做法是 `fac` 返回 None 时直接返回 0。

## 如果面试官追问
若 nums[i] 上限放大到 100 呢？答：质因子集合扩到 25 以内素数，向量维度变长但思路不变，只是状态数上升。
