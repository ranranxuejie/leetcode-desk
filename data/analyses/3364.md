## 一句话思路
枚举右端点 `i`，用前缀和加有序结构维护长度窗口 `[l, r]` 内的最小前缀和，取最小正差。

## 怎么做
1. 预处理前缀和 `pre[0]=0`，`pre[i]=pre[i-1]+nums[i-1]`，子数组和即 `pre[i]-pre[j]`。
2. 对每个右端点 `i`，合法左端点 `j` 满足 `i-r <= j <= i-l`，把 `pre[j]` 放进有序容器。
3. 在容器里找严格小于 `pre[i]` 的最大值，差值即为以 `i` 结尾的最小正和。
4. 滑动窗口：`i` 增大时加入 `pre[i-l]`，删除 `pre[i-r-1]`，容器用 `SortedList` 或手写有序结构。

以示例 1 `nums=[3,-2,1,4], l=2, r=3` 为例：`pre=[0,3,1,2,6]`。`i=2` 时窗口 `j∈[0,0]`，容器 `{0}`，`pre[2]=1`，差 `1-0=1`，更新答案 `ans=1`。

```python
from sortedcontainers import SortedList
pre = [0]
for x in nums:
    pre.append(pre[-1] + x)
sl = SortedList()
ans = float('inf')
for i in range(1, len(pre)):
    lo, hi = i - r, i - l
    if hi >= 0:
        sl.add(pre[hi])
    if lo - 1 >= 0 and lo - 1 in sl:
        sl.remove(pre[lo - 1])
    pos = sl.bisect_left(pre[i]) - 1
    if pos >= 0:
        ans = min(ans, pre[i] - sl[pos])
return -1 if ans == float('inf') else ans
```

## 复杂度
时间：每个 `i` 做一次有序插入/删除/二分，共 O(n log n)。
空间：`pre` 数组 O(n)，有序容器最多存 `r-l+1` 个元素。

## 易错点
- 窗口边界差一：`i=2, l=2, r=3` 时合法 `j` 只有 `0`，若写成 `j <= i-l+1` 会把 `pre[1]=3` 也放进容器，`pre[2]-pre[1]` 得负数被误判。正确是 `hi = i-l`，加入后立即二分。
- 删除时机：`lo-1 = i-r-1`，示例 1 中 `i=3` 时 `lo-1=0`，必须删掉 `pre[0]=0`，否则 `pre[3]-pre[0]=2` 对应长度 3 仍合法但会漏掉更优解；若 `i=4` 不删 `pre[0]`，会算出长度 4 的非法子数组。

## 如果面试官追问
若 `n` 放大到 10^5 且要求输出子数组起止下标？答：在更新 `ans` 时同步记录 `(j, i)`，`j` 取 `sl[pos]` 对应的原始下标，容器改存 `(pre值, 下标)` 即可。
