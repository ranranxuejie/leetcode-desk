## 一句话思路
设 z 为 '0' 的个数，枚举操作次数 t，判断 t 次操作能否把 z 个 0 全翻成 1，取最小可行 t。

## 怎么做
1. 关键观察：t 次操作共翻转 t·k 个位置，其中每个 0 必须被翻奇数次、每个 1 必须被翻偶数次，所以 t·k 与 z 同奇偶，且 t·k ≥ z。
2. 再补一个上界：t·k ≤ z + 2·(n - z)·? 不对——正确约束是「多翻的偶数次翻转必须落在 1 上」，而每个 1 最多被翻 t 次，故 t·k - z ≤ (n - z)·t 且必须为偶数，即 t·k ≥ z 且 (t·k - z) 为偶数且 t·k - z ≤ t·(n - z)。
3. 于是从小到大枚举 t（t 从 1 到 n 足够，因为 t > n 时答案必已出现或不可能），第一个满足上述三条的 t 就是答案；枚举完返回 -1。
4. 以 s = "0101", k = 3 为例：z = 2, n = 4。t = 1 时 t·k = 3，3 - 2 = 1 为奇数，不行；t = 2 时 t·k = 6，6 - 2 = 4 为偶数且 4 ≤ 2·(4-2) = 4，成立，返回 2。

```python
z = s.count('0')
n = len(s)
if z == 0:
    return 0
for t in range(1, n + 1):
    total = t * k
    if total >= z and (total - z) % 2 == 0 and total - z <= t * (n - z):
        return t
return -1
```

## 复杂度
时间 O(n)：枚举 t 最多 n 次，每次 O(1)，`s.count` 一次 O(n)。
空间 O(1)：只存 z、n、t、total 四个整数。

## 易错点
- s = "101", k = 2：只判 t·k ≥ z 会得 t = 1（2 ≥ 1），但 2 - 1 = 1 是奇数，翻不出全 1，会错答 1；必须加奇偶校验，正确返回 -1。
- s = "110", k = 1：z = 1，t = 1 时 total - z = 0 ≤ 1·(3-1) = 2 成立，返回 1 正确；但若漏掉上界条件，遇到 z 很小而 k 很大（如 s = "0", k = 1 之外的 s = "0111", k = 4）会误判可行，实际 t·k - z 超过 1 的容量，需靠 `total - z <= t * (n - z)` 拦住。

## 如果面试官追问
要求输出具体操作方案怎么办？答：按 t 次操作构造——先把 z 个 0 各翻一次，剩余 t·k - z 次翻转成对地摊到 1 上（每个 1 每轮最多翻一次），逐轮贪心分配即可。
