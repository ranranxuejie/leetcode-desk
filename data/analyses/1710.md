## 一句话思路
按每箱单元数从大到小排序，先装满单位价值最高的箱子，贪心即最优。

## 怎么做
1. 把 `boxTypes` 按 `numberOfUnitsPerBox`（第二列）降序排序。
2. 遍历每个 `[cnt, units]`，取 `take = min(cnt, truckSize)`，累加 `take * units`，并从 `truckSize` 中扣掉 `take`。
3. `truckSize` 减到 0 时提前 `break`，剩下的箱子装不下。

用示例 1：`boxTypes = [[1,3],[2,2],[3,1]]`，排序后仍是 `[[1,3],[2,2],[3,1]]`。第一轮 `take = min(1,4) = 1`，`ans = 3`，`truckSize = 3`；第二轮 `take = min(2,3) = 2`，`ans = 3+4 = 7`，`truckSize = 1`；第三轮 `take = min(3,1) = 1`，`ans = 7+1 = 8`，`truckSize = 0` 退出，返回 8。

```python
boxTypes.sort(key=lambda x: -x[1])
ans = 0
for cnt, units in boxTypes:
    take = min(cnt, truckSize)
    ans += take * units
    truckSize -= take
    if truckSize == 0:
        break
return ans
```

关键点：`take` 必须用 `min(cnt, truckSize)`，不能直接 `ans += cnt * units` 再判断——那样会多装超出容量的箱子。

## 复杂度
时间：排序 O(n log n)，n 是 `boxTypes` 长度；遍历 O(n)。
空间：排序原地 O(1) 额外空间（Python 的 `sort` 内部 O(n) 辅助，不计入算法空间）。

## 易错点
- 输入 `boxTypes = [[5,10],[2,5],[4,7],[3,9]], truckSize = 10`：若按原顺序装，先拿 5 个 10 单元、再拿 2 个 5 单元、再拿 3 个 7 单元，得 50+10+21=81；正确排序后是 10、9、7、5，装 5 个 10 + 3 个 9 + 2 个 7 = 50+27+14=91。顺序错就少 10。
- 输入 `boxTypes = [[1,3]], truckSize = 100`：若循环里写 `truckSize -= cnt` 而不做 `min`，`truckSize` 变成 99 不会触发 `== 0` 退出，但 `ans` 仍对；真正翻车的是 `truckSize` 小于某类箱子数时直接乘 `cnt`，会多算。必须 `take = min(cnt, truckSize)`。

## 如果面试官追问
问：如果要求输出具体装了哪些箱子（每类各几个）？答：在循环里记录 `(类型下标, take)`，`take` 为 0 的跳过，最后按原下标返回即可。
