## 一句话思路
按下标步长 2k 跳跃，每段只反转 `[i, min(i+k, n))`，用切片赋值一步到位。

## 怎么做
1. 把 `s` 转成列表 `a`，因为字符串不可变，切片反转必须落到可变序列上。
2. 用 `for i in range(0, n, 2*k)` 枚举每段起点，步长是 `2*k` 而不是 `k`。
3. 每段反转区间右端取 `min(i+k, n)`，这一步同时覆盖「剩余不足 k 全反转」和「剩余在 k 到 2k 之间只反转前 k」两种边界。
4. 用 `a[i:j] = a[i:j][::-1]` 原地写回，最后 `''.join(a)`。

以 `s = "abcdefg", k = 2` 为例：`n = 7`，`i` 依次取 0、4。`i = 0` 时 `j = min(2, 7) = 2`，反转 `a[0:2]` 得 `"ba"`；`i = 4` 时 `j = min(6, 7) = 6`，反转 `a[4:6]` 即 `"ef"` 得 `"fe"`；`i = 6` 时 `j = min(8, 7) = 7`，反转 `a[6:7]` 只有一个字符 `"g"`，不变。结果 `"bacdfeg"`。

```python
n = len(s)
a = list(s)
for i in range(0, n, 2 * k):
    j = min(i + k, n)
    a[i:j] = a[i:j][::-1]
return ''.join(a)
```

关键点：`range` 的步长写 `2*k`，`j` 用 `min` 截断，这两处合起来就不需要任何 `if` 分支判断剩余长度。

## 复杂度
时间 O(n)：每个字符最多被切片复制一次，`join` 再扫一遍。
空间 O(n)：`a` 列表和每段切片各占 O(n) 量级。

## 易错点
- `s = "abcd", k = 2` 时若把步长写成 `k`，会得到 `"badc"` 而不是 `"bacd"`；正确做法是 `range(0, n, 2*k)`，让 `i` 只落在 0、4 上。
- `s = "abc", k = 5` 时若右端直接写 `i+k`，切片 `a[0:5]` 在 Python 里虽不报错但语义靠隐式截断，换成手写双指针就会越界；正确做法是显式 `j = min(i+k, n)`，让 `j = 3` 把整串反转成 `"cba"`。

## 如果面试官追问
追问：如果要求返回反转后的字符数组而不是字符串？
答：直接返回 `a`，省掉 `join` 的 O(n) 复制，空间仍是 O(n) 但少一次分配。
