## 一句话思路
把每个连续 0 段单独算「能坐多远」，中间段取 `(长度+1)//2`，两端段取整段长度，再取最大值。

## 怎么做
1. 从左往右扫 `seats`，用 `i` 记录当前 0 段的起点，遇到 `seats[j] == 1` 时结算这一段。
2. 结算规则分三种：段在开头（`i == 0`）取 `j - i`；段在结尾（扫完还没遇到 1）取 `n - i`；中间段取 `(j - i + 1) // 2`。
3. 用 `ans` 维护最大值，扫完返回 `ans`。

拿示例 1 `seats = [1,0,0,0,1,0,1]` 走一遍：`i=1` 起一段，`j=4` 遇到 1，中间段长度 `j-i=3`，候选 `(3+1)//2 = 2`，`ans=2`；接着 `i=5`，`j=6` 遇到 1，中间段长度 1，候选 `(1+1)//2 = 1`，`ans` 仍是 2。返回 2。

```python
n = len(seats)
ans = i = 0
while i < n:
    if seats[i] == 1:
        i += 1
        continue
    j = i
    while j < n and seats[j] == 0:
        j += 1
    if i == 0 or j == n:
        ans = max(ans, j - i)
    else:
        ans = max(ans, (j - i + 1) // 2)
    i = j
return ans
```

关键在 `(j - i + 1) // 2` 这个上取整：长度 3 的中间段能坐出距离 2，长度 2 的只能坐出 1，写成 `(j-i)//2` 会把长度 3 算成 1，直接错。

## 复杂度
时间 O(n)：`i` 和 `j` 都只前进不后退，每个下标最多被访问两次。
空间 O(1)：只开了 `ans`、`i`、`j`、`n` 四个变量，没有额外数组。

## 易错点
- 输入 `seats = [1,0,0,0]`（示例 2）→ 若把结尾段也套 `(len+1)//2`，长度 3 得 2，但正确答案是 3，因为亚历克斯可以坐到最右端，离最近的人 3 个座位 → 结尾段（以及开头段）必须用整段长度 `j - i`，只有两侧都有人的中间段才折半。
- 输入 `seats = [0,1]`（示例 3）→ 若开头段也用折半，长度 1 得 `(1+1)//2 = 1` 恰好对，但换成 `[0,0,1]` 就会得 1 而正确是 2 → 判断条件要写 `i == 0 or j == n`，不能只判 `j == n`，开头段同样不折半。

## 如果面试官追问
问：要返回具体坐哪个下标怎么办？
答：结算时同时记下最优段和它的起点，中间段取 `i + (j - i - 1) // 2`，两端段取 0 或 `n - 1`。
