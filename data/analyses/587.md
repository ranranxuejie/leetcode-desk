## 一句话思路
Andrew 单调链：按 (x, y) 排序后分别扫出下凸壳和上凸壳，叉积 ≤0 就弹栈，两壳并集即凸包边界点。

## 怎么做
1. 先 `trees.sort()`，让点按 x 升序、x 相同按 y 升序，这样左右端点天然是首尾元素。
2. 用叉积 `cross(o,a,b) = (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])` 判断转向，`<= 0` 说明 a 不在凸壳上（共线也要弹，因为共线中间点不算边界顶点，但最后要补回来）。
3. 正序扫一遍得下壳 `lower`，逆序扫一遍得上壳 `upper`，去掉各自末尾重复的端点后拼接。
4. 关键坑：共线点必须保留。做法是弹栈条件用 `< 0` 而不是 `<= 0`，或者弹完后再把共线点补回。

以示例 1 为例，排序后为 `[[1,1],[2,0],[2,2],[2,4],[3,3],[4,2]]`。扫下壳时处理到 `[2,4]`：栈内 `[[1,1],[2,0],[2,2]]`，`cross([1,1],[2,0],[2,4]) = 1*3 - (-1)*1 = 4 > 0`，保留；接着 `[3,3]` 使 `[2,2]` 的叉积为 0，若用 `<=0` 会误删 `[2,2]`，而它恰在边界上。

```python
def cross(o, a, b):
    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])

def half(pts):
    st = []
    for p in pts:
        while len(st) >= 2 and cross(st[-2], st[-1], p) < 0:
            st.pop()
        st.append(p)
    return st

pts = sorted(trees)
if len(pts) <= 2:
    return pts
lower = half(pts)
upper = half(pts[::-1])
return list({tuple(p) for p in lower[:-1] + upper[:-1]})
```

## 复杂度
时间 O(n log n)：排序主导，两次扫描各 O(n)。
空间 O(n)：栈 `lower`/`upper` 最坏存全部点，外加去重集合。

## 易错点
- 输入 `[[1,2],[2,2],[4,2]]` 三点共线 → 用 `cross <= 0` 弹栈会把中间点 `[2,2]` 删掉，输出只剩两端 → 弹栈条件写 `cross < 0`，让共线点留在栈里。
- 输入只有 1 或 2 个点（如 `[[0,0]]`）→ 直接跑单调链会因 `lower[:-1] + upper[:-1]` 为空返回 `[]` → 先判 `len(pts) <= 2` 直接返回原列表。

## 如果面试官追问
问：若要求返回围栏的周长而非顶点？
答：按凸包顶点顺序相邻两点算欧氏距离累加，最后一点连回第一点即可。
