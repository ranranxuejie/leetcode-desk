## 一句话思路
把 p 按两个 `*` 切成三段 A、B、C，枚举 B 在 s 中的每个出现位置，用二分找最近的 A 结尾和 C 开头，取最短窗口。

## 怎么做
1. 切分：`a, b, c = p.split('*')`，注意 `p="**"` 时三段都是空串。
2. 预处理：用 KMP 或 `str.find` 循环求出 b 在 s 中所有起始下标 `occ`；再对 a 求「每个位置 i 结尾处 a 的最晚起始」`lastA[i]`，对 c 求「每个位置 i 开头处 c 的最早结束」`firstC[i]`。
3. 枚举 `occ` 中每个起点 `j`，b 占 `[j, j+len(b))`；在 `lastA` 上二分找 `≤ j-1` 的最大值得到 a 的起点，在 `firstC` 上二分找 `≥ j+len(b)` 的最小值得到 c 的终点，窗口长 `end - start`。
4. 全程取最小值，无解返回 -1。

以示例 1 `s="abaacbaecebce", p="ba*c*ce"` 为例：a=`"ba"`, b=`"c"`, c=`"ce"`。b 的出现位置 `occ=[5,8,11]`。取 `j=8` 时，`lastA[7]` 给出 a 起点 6（`s[6:8]="ba"`），`firstC` 从 9 起找到 c 终点 11（`s[9:11]="ce"`），窗口 `[6,11)` 长 5？实际答案 8 来自 `j=5`：a 起点 0，c 终点 8，长 8。枚举全部取最小即 8。

```python
a, b, c = p.split('*')
occ = []
i = s.find(b)
while i != -1:
    occ.append(i)
    i = s.find(b, i + 1)
# lastA[i]: 以 i 结尾的 a 的最晚起点; firstC[i]: 从 i 起的 c 的最早终点
ans = 10**9
for j in occ:
    la = lastA[j - 1] if j > 0 else -1
    fc = firstC[j + len(b)] if j + len(b) <= len(s) else -1
    if la != -1 and fc != -1:
        ans = min(ans, fc - la)
return -1 if ans == 10**9 else ans
```

## 复杂度
时间 O(n + m + |occ| log n)，n=|s|，m=|p|，log n 来自每个 b 出现位置的两次二分。
空间 O(n)，存 `lastA`、`firstC` 两个长度 n 的数组和 `occ`。

## 易错点
- `p="**"`（示例 3）→ 三段全空，若把空串当「找不到」会返回 -1 → 空串匹配长度 0，需特判 `a==b==c==""` 直接返回 0。
- b 为空串时 `s.find("")` 永远返回 0 造成死循环 → 空 b 应让 `occ = range(len(s)+1)`，即每个位置都可作为分割点，而不是走 find 循环。

## 如果面试官追问
若 `*` 数量不固定为 2 个怎么办？答：变成多段匹配，需在每两个相邻段之间做同样的「最近衔接」贪心，用 DP 或逐段推进，复杂度升到 O(k·n log n)。
