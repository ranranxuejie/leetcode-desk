## 一句话思路
把每个 1 的下标减去它的序号，问题变成「在数组里选 k 个点使距离和最小」，中位数即最优。

## 怎么做
1. 扫描 `nums`，把第 i 个 1 的下标 `p` 记成 `p - i`，得到新数组 `pos`（这一步把「相邻 1 之间至少隔 1 格」的约束消掉了）。
2. 在 `pos` 上滑一个长度 k 的窗口，窗口内代价 = 全部搬到中位数 `pos[l + k//2]` 的距离和。
3. 用前缀和 `pre` 把代价 O(1) 算出：左半 `mid*(mid-l) - (pre[mid]-pre[l])`，右半 `(pre[r+1]-pre[mid+1]) - mid*(r-mid)`。
4. 对所有窗口取最小值。

以示例 2 `nums = [1,0,0,0,0,0,1,1], k = 3` 为例：1 的下标是 0,6,7，减序号后 `pos = [0,5,5]`。窗口就是全部，中位数 `pos[1] = 5`，代价 = (5-0) + 0 + 0 = 5，与答案一致。

```python
pos = [p - i for i, p in enumerate(nums) if p == 1]
pre = [0]
for v in pos:
    pre.append(pre[-1] + v)
ans = float('inf')
for l in range(len(pos) - k + 1):
    r = l + k - 1
    mid = l + k // 2
    m = pos[mid]
    left = m * (mid - l) - (pre[mid] - pre[l])
    right = (pre[r + 1] - pre[mid + 1]) - m * (r - mid)
    ans = min(ans, left + right)
```

## 复杂度
时间 O(n)：扫描建 `pos` 一次，窗口滑一遍，前缀和查询 O(1)。
空间 O(n)：`pos` 与 `pre` 各存至多 n 个元素。

## 易错点
- 忘记减序号：`nums = [1,0,0,1,0,1], k = 2` 直接用原始下标 `[0,3,5]` 算窗口 `[3,5]` 得 2，正确答案是 1；必须先变成 `pos = [0,2,3]`，窗口 `[2,3]` 代价才是 1。
- 中位数取错位置：k 为偶数时取 `l + k//2`（偏右那个），若写成 `l + (k-1)//2`，示例 1 的 `pos = [0,2,3]`、k=2 时窗口 `[2,3]` 取左中位数 2 得 1 仍对，但窗口 `[0,2]` 会算成 2 而非 2，边界窗口容易多算；统一用 `k//2` 保证左右两段公式的 `mid` 与 `pre` 下标对齐。

## 如果面试官追问
要求输出最终数组而非次数怎么办？答：中位数确定后，把窗口内 k 个 1 依次放到 `pos[mid]` 展开的连续区间上，再按原下标回填即可。
