## 一句话思路
用哈希表只存被 setCell 过的非零单元格，getValue 时把两个操作数分别解析成「数字」或「查表得值」再相加。

## 怎么做
1. 构造函数只记 `rows`，并建空字典 `cells = {}`，键用原始字符串如 `"A1"`。
2. `setCell` 直接 `cells[cell] = value`；`resetCell` 用 `cells.pop(cell, None)` 删键，等价于归零。
3. `getValue` 去掉开头的 `=`，按 `+` 切成两段 `x, y`。
4. 对每段判断首字符是否为字母：是则 `cells.get(s, 0)`，否则 `int(s)`。

以官方示例 `getValue("=A1+B2")` 为例：切分得 `x="A1"`、`y="B2"`，此时 `cells = {"A1": 10, "B2": 15}`，两次查表得 10 和 15，返回 25。随后 `resetCell("A1")` 删掉键，再算同一公式时 `cells.get("A1", 0)` 得 0，返回 15。

```python
def getValue(self, formula: str) -> int:
    x, y = formula[1:].split("+")
    def val(s):
        if s[0].isalpha():
            return self.cells.get(s, 0)
        return int(s)
    return val(x) + val(y)

def resetCell(self, cell: str) -> None:
    self.cells.pop(cell, None)
```

关键点：`split("+")` 恰好两段，因为题面保证格式 `=X+Y` 且操作数不含 `+`；`isalpha()` 比 `s[0] >= 'A'` 更稳，数字段首字符必是数字。

## 复杂度
时间：每次操作 O(1)，`getValue` 的 `split` 与 `int` 只处理常数长度字符串。
空间：O(k)，k 为被 setCell 且未 reset 的单元格数，最多 26×rows 但实际受 10^4 次调用限制。

## 易错点
1. 输入 `resetCell("A1")` 后紧跟 `getValue("=A1+B2")` → 若 reset 写成 `cells[cell] = 0` 也能对，但若写成只置标志位而 getValue 仍读旧值就会错成 25 → 正确做法是删键或置 0 后统一用 `get` 读，保证默认 0。
2. 输入 `getValue("=5+7")` → 若对两段都无条件 `cells.get(s, 0)`，`"5"` 查不到会返回 0，错成 0 → 必须先判首字符是否字母，数字段走 `int(s)`。

## 如果面试官追问
问：若公式支持 `=A1+B2+C3` 多操作数怎么办？
答：把 `split("+")` 结果遍历求和，每个元素套同一个 `val` 函数，逻辑不变。
