## 一句话思路
排序后取 `max(a[2], (a[0]+a[1]+a[2]+1)//2)`：最大堆决定下限，总杯数的一半决定另一下限。

## 怎么做
1. 对 `amount` 排序，令 `a = sorted(amount)`，则 `a[2]` 是最大需求。
2. 答案下界一：最大类型每秒最多消耗 1 杯，故至少 `a[2]` 秒。
3. 答案下界二：每秒最多装 2 杯，故至少 `ceil(total/2) = (total+1)//2` 秒。
4. 两个下界都能同时达到，取较大值即为答案。

以 `amount = [1,4,2]` 为例：排序后 `a = [1,2,4]`，`total = 7`，`a[2] = 4`，`(7+1)//2 = 4`，`max(4,4) = 4`，与示例一致。再看 `[5,4,4]`：`a = [4,4,5]`，`total = 13`，`a[2] = 5`，`(13+1)//2 = 7`，`max(5,7) = 7`。

```python
a = sorted(amount)
total = a[0] + a[1] + a[2]
return max(a[2], (total + 1) // 2)
```

为什么两个下界能同时达到：若 `a[2] >= a[0]+a[1]`，则每秒用最大类型配一个其他类型（或单独装最大类型），恰好 `a[2]` 秒；否则总杯数的一半是瓶颈，可以每两秒凑一对不同类型，剩余 1 杯单独一秒，恰好 `(total+1)//2` 秒。

## 复杂度
时间：O(1)，只有 3 个元素，排序常数级。
空间：O(1)，只开了 `a` 和 `total` 两个变量。

## 易错点
- 输入 `[5,0,0]` → 若只算 `(total+1)//2 = 3` 就返回，会错成 3，实际需要 5 秒（每秒只能装 1 杯冷水）。正确做法是取 `max(a[2], (total+1)//2)`，让最大堆的下界生效。
- 输入 `[1,1,1]` → 若用 `total//2 = 1` 会错成 1，实际需要 2 秒（第 1 秒装两杯不同类型，第 2 秒装剩下 1 杯）。正确做法是向上取整 `(total+1)//2`，奇数总杯数要多一秒。

## 如果面试官追问
问：如果 amount 长度变成 n 种水，怎么改？
答：排序后取 `max(max(amount), (sum(amount)+1)//2)`，结论不变，只是最大值和总和要遍历一遍。
