## 一句话思路
按四元组 (i,j)、(i,n-1-j)、(m-1-i,j)、(m-1-i,n-1-j) 分组，组内统一取值，再单独处理中心行/列。

## 怎么做
1. 只遍历左上四分之一区域 `i < m//2 and j < n//2`，每组四个格子必须同值，代价取 `min(ones, 4-ones)`，累加进 `ans`。
2. 若 m、n 都是奇数，正中心格子 `grid[m//2][n//2]` 孤立，它必须是 0，是 1 就 `ans += 1`。
3. 若 m 为奇数，中心行左右对称的两格 `(m//2, j)` 与 `(m//2, n-1-j)` 必须相等，统计「这两格一 0 一 1」的组数 `diff`。
4. 若 n 为奇数，中心列同理统计 `diff`；最后 `ans += diff`，若 `diff == 0` 且中心行/列里 1 的个数模 4 不为 0，再 `ans += 2`。

以示例 1 的 `grid = [[1,0,0],[0,1,0],[0,0,1]]` 为例：m=n=3，左上四分之一只有 (0,0) 一组，四格是 1,0,0,1，`ones=2`，代价 `min(2,2)=2`；中心格 `grid[1][1]=1`，`ans=3`；中心行 (1,0)=0 与 (1,2)=0 相同，中心列 (0,1)=0 与 (2,1)=0 相同，`diff=0`，中心行/列 1 的个数为 0，模 4 为 0，不再加，答案 3。

```python
ans = 0
for i in range(m // 2):
    for j in range(n // 2):
        ones = grid[i][j] + grid[i][n-1-j] + grid[m-1-i][j] + grid[m-1-i][n-1-j]
        ans += min(ones, 4 - ones)
if m % 2 and n % 2:
    ans += grid[m//2][n//2]
diff = one_cnt = 0
if m % 2:
    for j in range(n // 2):
        a, b = grid[m//2][j], grid[m//2][n-1-j]
        diff += a != b
        one_cnt += a + b
if n % 2:
    for i in range(m // 2):
        a, b = grid[i][n//2], grid[m-1-i][n//2]
        diff += a != b
        one_cnt += a + b
ans += diff
if diff == 0 and one_cnt % 4:
    ans += 2
```

## 复杂度
时间：O(m·n)，每个格子只被访问常数次。
空间：O(1)，只用了 `ans`、`diff`、`one_cnt` 等几个标量。

## 易错点
- 中心行/列里出现「一 0 一 1」的对（`diff > 0`）时，若只把其中一格翻转成相等就结束，会漏掉 1 的个数模 4 的约束；正确做法是每对先花 1 次翻成相同，此时 `diff` 对贡献的 1 的个数是 2 的倍数，模 4 自动满足，所以 `diff > 0` 时不必再加 2。
- `diff == 0` 但中心行/列里 1 的个数 `one_cnt % 4 == 2` 时，若直接返回 `ans`，1 的个数不能被 4 整除；正确做法是把某一对同时翻成 1 或同时翻成 0，多花 2 次，即 `ans += 2`。

## 如果面试官追问
问：如果要求输出具体翻转方案而不只是次数？
答：每组记录 `ones` 与 `4-ones` 谁小，决定统一成 0 还是 1，把该组四个坐标写进结果列表即可。
