## 一句话思路
反复对 7 取余收集低位、整除 7 收缩，最后反转余数序列；符号单独处理。

## 怎么做
1. 先处理 `num == 0`，直接返回 `"0"`，否则循环一次都不进会得到空串。
2. 记下符号 `neg = num < 0`，把 `num` 取绝对值 `num = abs(num)`，避免 Python 负数取余的符号纠缠。
3. 循环 `while num:`，每轮 `num, r = divmod(num, 7)` 把余数 `r` 追加进列表 `digits`。
4. 循环结束后 `"".join(map(str, reversed(digits)))`，若 `neg` 为真则前面拼 `"-"`。

以 `num = 100` 为例：第一轮 `divmod(100, 7)` 得 `num = 14, r = 2`，`digits = [2]`；第二轮得 `num = 2, r = 0`，`digits = [2, 0]`；第三轮得 `num = 0, r = 2`，`digits = [2, 0, 2]`，反转拼起来正好 `"202"`。

```python
if num == 0:
    return "0"
neg = num < 0
num = abs(num)
digits = []
while num:
    num, r = divmod(num, 7)
    digits.append(r)
s = "".join(map(str, reversed(digits)))
return "-" + s if neg else s
```

注意 `divmod` 一次拿到商和余数，比先 `%` 再 `//` 少写一行，也避免两次除法。

## 复杂度
时间 O(log₇|num|)：循环次数是 7 进制位数，`num = 100` 只转 3 轮。
空间 O(log₇|num|)：`digits` 列表存每位余数，另加拼接出的字符串。

## 易错点
- 输入 `num = 0` → 若直接进 `while num:` 循环，一次都不执行，`digits` 为空，`"".join(...)` 返回 `""` 而不是 `"0"` → 必须在循环前单独返回 `"0"`。
- 输入 `num = -7` → 若先取余再判符号，Python 里 `-7 % 7 == 0`、`-8 % 7 == 6`，余数会带出负数位，拼出 `"-1-0"` 之类怪串 → 正确做法是先 `abs(num)` 转正数再取余，符号最后统一补 `"-"`。

## 如果面试官追问
问：如果要求支持任意进制（2 到 36）怎么办？
答：把常量 7 换成参数 `base`，余数大于 9 时映射成 `'a'`-`'z'` 即可，框架不变。
