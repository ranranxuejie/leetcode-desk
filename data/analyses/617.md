## 一句话思路
同步递归两棵树，节点重叠就相加、单边为空就返回另一边，天然得到合并树。

## 怎么做
1. 递归函数接收 `(a, b)`，先处理终止：`a is None` 返回 `b`，`b is None` 返回 `a`。
2. 两边都非空时，把 `b.val` 加到 `a.val` 上，直接复用 `a` 作为结果节点。
3. 递归 `a.left = f(a.left, b.left)`、`a.right = f(a.right, b.right)`，最后返回 `a`。

以示例 1 为例：根 `1+2=3`；左子树 `(3,1)` 得 `4`，其左 `(5,None)` 直接返回 `5`、右 `(None,4)` 返回 `4`；右子树 `(2,3)` 得 `5`，其左 `(None,None)` 返回 `None`、右 `(None,7)` 返回 `7`。结果 `[3,4,5,5,4,None,7]`，与输出一致。

```python
def merge(a, b):
    if a is None:
        return b
    if b is None:
        return a
    a.val += b.val
    a.left = merge(a.left, b.left)
    a.right = merge(a.right, b.right)
    return a
```

关键在终止条件的位置：先判空再相加，否则 `b.val` 在 `b is None` 时会抛 `AttributeError`。

## 复杂度
时间 O(min(m, n)) 到 O(m+n)：两树重叠部分逐节点访问，单边节点直接挂接不再深入。
空间 O(h1+h2)：递归栈深度取两树高度较小者，未额外建节点。

## 易错点
- 输入 `root1=[1], root2=[1,2]` → 若只写 `a.val += b.val` 而不判空，递归到 `b.left` 为 `None` 时崩 → 必须先 `if b is None: return a`，让 `2` 整棵挂到结果左孩子。
- 输入 `root1=[1,3,2,5]`、`root2=[2,1,3,None,4,None,7]` → 若在 `a is None` 时返回 `None` 而非 `b`，会丢掉 `4` 和 `7`，输出变成 `[3,4,5,5]` → 单边为空必须返回另一边整棵子树。

## 如果面试官追问
问：不允许修改原树、要返回全新节点怎么办？
答：把 `a.val += b.val` 换成 `node = TreeNode(a.val + b.val)`，左右递归结果赋给 `node.left/right`，空间多 O(m+n) 个新节点。
