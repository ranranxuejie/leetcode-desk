## 一句话思路
只需枚举长度 `minSize` 的子串：更长的合法子串必然包含一个合法的 `minSize` 前缀，出现次数不会更多。

## 怎么做
1. 窗口长度固定为 `minSize`，用滑动窗口维护窗口内各字母计数和不同字母数 `distinct`。
2. 右端加入 `s[i]`，计数从 0 变 1 时 `distinct += 1`；左端移出 `s[i-minSize]`，计数归 0 时 `distinct -= 1`。
3. 当 `distinct <= maxLetters` 时，把 `s[i-minSize+1:i+1]` 放进字典 `cnt` 累加。
4. 返回 `cnt` 中的最大值，空字典返回 0。

以 `s = "aababcaab", maxLetters = 2, minSize = 3` 为例：窗口滑到下标 2 时窗口是 `"aab"`，`distinct = 2` 合法，`cnt["aab"] = 1`；滑到下标 4 时窗口是 `"abc"`，`distinct = 3 > 2` 被跳过；最后 `cnt["aab"] = 2`，答案 2。

```python
cnt = {}
freq = [0] * 26
distinct = 0
for i, ch in enumerate(s):
    c = ord(ch) - 97
    if freq[c] == 0:
        distinct += 1
    freq[c] += 1
    if i >= minSize:
        d = ord(s[i - minSize]) - 97
        freq[d] -= 1
        if freq[d] == 0:
            distinct -= 1
    if i >= minSize - 1 and distinct <= maxLetters:
        sub = s[i - minSize + 1:i + 1]
        cnt[sub] = cnt.get(sub, 0) + 1
return max(cnt.values(), default=0)
```

## 复杂度
时间 O(n · minSize)：n 个窗口，每个切出长度 `minSize` 的子串做哈希。
空间 O(n · minSize)：`cnt` 最多存 n 个键，每个键长 `minSize`。

## 易错点
- `s = "aaaa", maxLetters = 1, minSize = 3`：若只统计不重叠子串会得 1，正确是滑动窗口逐位移动，`"aaa"` 在下标 0 和 1 各出现一次，答案 2。
- `s = "abcde", maxLetters = 2, minSize = 3`：若忘了 `distinct <= maxLetters` 判断，会把 `"abc"` 计入得 1，正确是所有窗口 `distinct = 3 > 2`，`cnt` 为空返回 0。

## 如果面试官追问
问：为什么不用枚举 `maxSize` 长度的子串？答：长度 L > minSize 的合法子串，其前 `minSize` 个字符仍合法且出现次数不少于它，枚举长的只会更慢。
