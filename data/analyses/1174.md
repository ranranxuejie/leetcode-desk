## 一句话思路
先用 `ROW_NUMBER()` 按 `customer_id` 分组、`order_date` 升序取 `rn = 1` 的首次订单，再对这批行算即时比例。

## 怎么做
1. 子查询里对每行打 `ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY order_date) AS rn`。
2. 外层只保留 `rn = 1`，得到每个顾客唯一一条首次订单。
3. 用 `AVG(order_date = customer_pref_delivery_date)` 求即时占比，`ROUND(..., 2)` 保留两位。

拿官方示例走一遍：顾客 3 有 `delivery_id` 5（08-21）和 4（08-24），按 `order_date` 升序，`rn=1` 落在 5 号行，它是计划订单；顾客 1 的 `rn=1` 是 1 号行。四个首次订单里 2 号、7 号即时，`AVG` 得 `2/4 = 0.5`，乘 100 后 `ROUND` 出 `50.00`。

```python
# 子查询：首次订单
"""
SELECT customer_id, order_date, customer_pref_delivery_date,
       ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY order_date) AS rn
FROM Delivery
"""
# 外层聚合
"""
SELECT ROUND(AVG(order_date = customer_pref_delivery_date) * 100, 2)
       AS immediate_percentage
FROM (...) t
WHERE rn = 1
"""
```

若用 pandas 写，等价于 `df.sort_values('order_date').groupby('customer_id').head(1)` 后再算 `(order_date == customer_pref_delivery_date).mean() * 100`。

## 复杂度
时间：`ROW_NUMBER` 排序，n 为行数，约 O(n log n)。
空间：窗口排序额外开 O(n) 缓冲，结果集只 1 行。

## 易错点
- 用 `MIN(order_date)` 直接 join 回原表 → 同一顾客同一天有两单时（如顾客 3 若 5、4 号都是 08-21）会匹配出 2 行，分母被放大；正确做法是用 `ROW_NUMBER` 只取一行，或 join 时再按 `delivery_id` 去重。
- 忘了 `* 100` 或写成 `AVG(...)` 直接输出 → 得到 `0.5` 而非 `50.00`；`ROUND` 只保留两位小数，不补零，需确认输出格式为 `50.00` 而非 `50.0`。

## 如果面试官追问
问：若一个顾客同一天下多单，首次订单怎么定？答：题面保证首次订单唯一，若放开则需再按 `delivery_id` 升序做第二排序键，取最小者。
