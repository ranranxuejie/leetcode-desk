## 一句话思路
用「至多 k 个辅音」的计数减去「至多 k-1 个辅音」的计数，每个计数用滑动窗口统计含全部 5 个元音的子串数。

## 怎么做
1. 写辅助函数 `at_most(limit)`：返回辅音数 ≤ limit 且含全部元音的窗口数。
2. 右指针 `r` 逐个吞入字符，`cnt` 记辅音数，`vowel` 记元音种类数（用长度 5 的数组或集合）。
3. 当 `cnt > limit` 时左指针 `l` 收缩，直到 `cnt <= limit`；此时以 `r` 结尾的合法左端点有 `l` 个（即 `0..l-1`），累加 `l`。
4. 答案 = `at_most(k) - at_most(k-1)`。

以 `word = "ieaouqqieaouqq", k = 1` 为例：`at_most(1)` 在 `r=5`（字符 `q`）时窗口 `[0..5]` 含 5 元音 1 辅音，`l=0`，累加 0；`r=6` 再进 `q`，`cnt=2>1`，`l` 移到 1，累加 1……最终 `at_most(1)=4`，`at_most(0)=1`，差为 3。

```python
def at_most(limit):
    cnt = 0
    freq = [0] * 5
    kinds = 0
    l = 0
    total = 0
    for r, ch in enumerate(word):
        if ch in "aeiou":
            i = "aeiou".index(ch)
            if freq[i] == 0:
                kinds += 1
            freq[i] += 1
        else:
            cnt += 1
        while cnt > limit:
            if word[l] in "aeiou":
                i = "aeiou".index(word[l])
                freq[i] -= 1
                if freq[i] == 0:
                    kinds -= 1
            else:
                cnt -= 1
            l += 1
        if kinds == 5:
            total += l
    return total
return at_most(k) - at_most(k - 1)
```

## 复杂度
时间：O(n)，两个 `at_most` 各扫一遍，`l`、`r` 均单调右移。
空间：O(1)，只有长度 5 的 `freq` 和几个计数器。

## 易错点
- `k = 0` 时若直接调 `at_most(-1)`，`cnt > -1` 恒真，`l` 会一路推到 `r+1`，`total` 永远加 0，结果错成 0；正确做法是让 `at_most(-1)` 返回 0，或特判 `k == 0` 时只算 `at_most(0)`。
- 收缩窗口时只减辅音不减元音，`kinds` 不会回落，导致 `kinds == 5` 判断失效；必须对 `word[l]` 是元音的情况同步 `freq[i] -= 1` 并在归零时 `kinds -= 1`。

## 如果面试官追问
问：若要求输出所有合法子串而非计数？答：把 `total += l` 换成枚举 `0..l-1` 的起点，复杂度升到 O(n·答案数)，需按输出规模接受。
