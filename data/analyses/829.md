## 一句话思路
设连续段长 k、首项 a，则 n = k(2a+k-1)/2，枚举 k 并检查 2n 能否被 k 整除且商与 k 奇偶不同。

## 怎么做
1. 把 n = a + (a+1) + … + (a+k-1) 化成 2n = k(2a+k-1)，k 是段长、a 是首项。
2. 因为 a ≥ 1，必有 k(2a+k-1) ≥ k(k+1)，即 k(k+1) ≤ 2n，所以 k 只需枚举到约 sqrt(2n)。
3. 对每个 k，令 `q = 2*n // k`，要求 `2*n % k == 0` 且 `q - k + 1` 为正偶数（这样 a = (q-k+1)/2 是正整数）。
4. 计数加一即可。

拿 n = 15 走一遍：2n = 30。k=1 时 q=30，q-k+1=30 偶且正，a=15，计 1；k=2 时 30%2=0，q=15，q-k+1=14，a=7，计 2；k=3 时 q=10，q-k+1=8，a=4，计 3；k=5 时 q=6，q-k+1=2，a=1，计 4；k=4 时 30%4=2 跳过。答案 4，与示例一致。

```python
n2 = 2 * n
ans = 0
k = 1
while k * (k + 1) <= n2:
    if n2 % k == 0:
        q = n2 // k
        if (q - k + 1) % 2 == 0 and q - k + 1 > 0:
            ans += 1
    k += 1
return ans
```

关键点：循环条件是 `k*(k+1) <= n2` 而不是 `k*k <= n2`，因为 a ≥ 1 给出的是 k(k+1) ≤ 2n 这个更紧的界。

## 复杂度
时间：O(sqrt(n))，k 从 1 枚举到约 sqrt(2n)，每次 O(1) 判断。
空间：O(1)，只用了 n2、ans、k、q 四个整数。

## 易错点
- 循环写成 `k*k <= n2`：n = 1 时 k=1 仍成立没问题，但 n = 2 时 k=2 会多进一轮，此时 q=2、q-k+1=1 为奇数被过滤，恰好不出错；真正翻车在 n = 3，k=2 时 q=3、q-k+1=2 偶且正，误判 3 = 1+2 之外多算一组。正确做法是用 `k*(k+1) <= n2`。
- 只判整除不判奇偶：n = 4 时 k=2，2n=8，8%2=0，q=4，若直接算 a=(4-2+1)/2=1.5 就错了；必须要求 `(q-k+1) % 2 == 0`，否则 a 不是整数。

## 如果面试官追问
要求输出所有方案而非计数怎么办？答：把 `ans += 1` 换成记录 `a = (q-k+1)//2` 和 `k`，最后按 a 升序输出区间 [a, a+k-1]。
