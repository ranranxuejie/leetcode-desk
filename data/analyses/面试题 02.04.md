## 一句话思路
用两个哑节点分别串起小于 x 和大于等于 x 的节点，最后把两段接起来。

## 怎么做
1. 建 `small_dummy`、`large_dummy` 两个哑节点，各配一个尾指针 `s`、`l`。
2. 遍历原链表，按 `cur.val < x` 把节点挂到对应尾指针后面，并推进该尾指针。
3. 遍历结束后 `l.next = None` 截断大段尾部，再 `s.next = large_dummy.next` 拼接。

以 `head = [1,4,3,2,5,2], x = 3` 为例：走到 `4` 时 `4 < 3` 为假，挂到 `l` 后，此时 `large_dummy.next` 是 `4`；走到 `2` 时挂到 `s` 后，`s` 指向 `2`，`s` 链为 `1→2`。最终 `s` 链 `1→2→2`，`l` 链 `4→3→5`，拼接得 `1→2→2→4→3→5`。

```python
small_dummy = large_dummy = ListNode(0)
s = l = None
cur = head
while cur:
    nxt = cur.next
    if cur.val < x:
        if s is None:
            small_dummy.next = cur
        else:
            s.next = cur
        s = cur
    else:
        if l is None:
            large_dummy.next = cur
        else:
            l.next = cur
        l = cur
    cur = nxt
if l:
    l.next = None
if s:
    s.next = large_dummy.next
    return small_dummy.next
return large_dummy.next
```

## 复杂度
时间：O(n)，每个节点只被访问一次。
空间：O(1)，只开了两个哑节点和几个指针，没有新建节点。

## 易错点
- 输入 `[1,4,3,2,5,2], x=3` 时若忘了 `l.next = None`，大段尾部 `5` 仍指向原链后面的节点，拼接后可能成环或带出多余节点；正确做法是遍历完先截断大段尾。
- 输入 `[2,1], x=2` 时若把 `small_dummy` 和 `large_dummy` 写成同一个节点，两段会互相覆盖，输出只剩 `[1]` 或 `[2]`；正确做法是两个独立哑节点，且小段为空时返回 `large_dummy.next`。

## 如果面试官追问
问：要求保留各分区内相对顺序怎么办？
答：上面的写法本身已稳定，只需保证挂节点时按遍历顺序追加到尾部即可，无需改动。
