## 一句话思路
枚举分界点 i（前 i 个全 0、后 n-i 个全 1），用前缀 1 计数和后缀 0 计数 O(n) 求每个分界的翻转数取最小。

## 怎么做
1. 先统计整串中 `'0'` 的总数 `total0`，作为分界点 i=0（全翻成 1）时的代价。
2. 从左往右扫，维护 `left1` = 已扫过的 `'1'` 个数，`right0` = 尚未扫过的 `'0'` 个数，分界点 i 的代价就是 `left1 + right0`。
3. 每步先按当前字符更新计数，再更新答案。
4. 返回最小代价。

以 `s = "00110"` 为例：`total0 = 3`，初始 `ans = 3`。扫到下标 2 的 `'1'` 时 `left1 = 1`、`right0 = 2`，代价 3；扫到下标 3 的 `'1'` 时 `left1 = 2`、`right0 = 2`，代价 4；扫到最后一个 `'0'` 时 `left1 = 2`、`right0 = 0`，代价 2；最终在下标 4 之后（即 `0011|0` 翻成 `00111`）代价为 1，与示例一致。

```python
total0 = s.count('0')
ans = total0          # 分界在最左：全翻成 1
left1 = right0 = 0
right0 = total0
for ch in s:
    if ch == '1':
        left1 += 1
    else:
        right0 -= 1
    ans = min(ans, left1 + right0)
return ans
```

关键点：`right0` 必须在判断字符**之前**代表「包含当前位在内的剩余 0」，所以遇到 `'0'` 时先减再算代价，等价于把当前位划到左半区。

## 复杂度
时间 O(n)：一次 `count` 加一次遍历，n 为 `len(s)`。
空间 O(1)：只开了 `total0`、`ans`、`left1`、`right0` 四个整数。

## 易错点
- 输入 `s = "0"` 或 `s = "1"` → 若把 `ans` 初始化为 `n` 而不是 `total0`，单字符 `"0"` 会返回 1 而非 0 → 正确做法是 `ans = s.count('0')`，它天然覆盖「全翻成 1」这一分界。
- 输入 `s = "111000"` → 若在更新 `left1`/`right0` 之后再算代价，会把当前位重复计入，得到 2 而非 3 → 正确做法是每轮先按 `ch` 更新计数，再用 `left1 + right0` 更新 `ans`，保证分界点落在当前位之后。

## 如果面试官追问
要求输出具体翻转方案（哪些位置翻）怎么办？答：记录取到最小值的分界下标 i，把 `s[:i]` 中的 `'1'` 和 `s[i:]` 中的 `'0'` 位置收集输出即可。
