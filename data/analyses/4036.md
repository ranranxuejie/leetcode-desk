## 一句话思路
从低位往高位贪心：能凑出 `'z'` 就整块凑 `'z'`，剩余部分按二进制拆成 `'a'` 和 `'b'` 的降序串。

## 怎么做
1. 把 `x` 看成二进制：`x = q*32 + r`，其中 `q = x // 32` 是能凑出的 `'z'` 个数，`r = x % 32` 是余数。
2. 余数 `r` 用 `'a'`（值 1）和 `'b'`（值 2）表示：`r` 的二进制第 `i` 位为 1 就放一个值为 `2**i` 的字母，即 `chr(ord('a') + i)`。
3. 字典序要求大的字母在前，所以把 `'z'*q` 放最前，后面接按值从大到小排列的余数字母。
4. 特判 `r == 0` 时只输出 `'z'*q`。

以 `nums[1] = 9` 为例：`q = 9 // 32 = 0`，`r = 9 = 0b1001`，第 0 位和第 3 位为 1，对应 `'a'` 和 `'d'`，降序拼成 `"da"`，与官方输出一致。再看 `nums[0] = 3`：`q = 0`，`r = 3 = 0b11`，第 0、1 位为 1，对应 `'a'`、`'b'`，降序为 `"ba"`。

```python
def solve(x):
    q, r = divmod(x, 32)
    tail = []
    i = 0
    while r:
        if r & 1:
            tail.append(chr(ord('a') + i))
        r >>= 1
        i += 1
    return 'z' * q + ''.join(reversed(tail))
```

关键点：`'z'` 的值是 26，但两个 `'z'` 无法再合并，所以每 32 个 `'a'` 恰好换一个 `'z'`（因为 `2**5 = 32`，第 5 位对应 `'z'` 之上的进位被截断）。余数部分最多用到第 4 位，即 `'e'`，不会产生 `'z'` 冲突。

## 复杂度
时间：每个 `nums[i]` 处理 `O(log nums[i])` 位，总 `O(n log max)`，`n = len(nums)`。
空间：输出字符串本身占 `O(x)` 量级，额外只开常数个变量。

## 易错点
- 输入 `nums = [32]` → 若按 `r = 32` 继续拆位会得到第 5 位即 `'z'`，与 `q` 重复 → 正确做法是 `divmod(x, 32)` 先把整块 `'z'` 拿走，余数严格小于 32。
- 输入 `nums = [2]` → 若把余数按升序拼成 `"ab"` 会得到 `"ab"`，但 `"b"` 字典序更大 → 必须降序，且 `r` 只有一位时直接输出该字母，不能补 `'a'`。

## 如果面试官追问
问：若允许 `'z'` 继续合并成 `'A'`（大写）怎么办？答：把进制从 32 改成 2 的更高次幂，`q` 的阈值随字母表扩展同步上调即可。
