## 一句话思路
按千位把数字切成不超过 3 位的段，每段用同一套 `_three` 递归拼词，再补上 Thousand/Million/Billion。

## 怎么做
1. 把 `num` 从低位起每 3 位切一段，段下标 `i` 决定后缀 `["", "Thousand", "Million", "Billion"][i]`。
2. 写 `_three(n)` 处理 0–999：`n // 100` 出百位，`n % 100` 交给 `_two`。
3. `_two(n)` 分三支：`n < 20` 查表、`n < 100` 查十位表加个位、否则递归回 `_three`。
4. 从高位段往低位段拼，跳过空段，最后 `" ".join`。

以 `num = 12345` 为例：切成 `[12, 345]`，`i=1` 段得 `"Twelve" + " Thousand"`，`i=0` 段 `_three(345)` 得 `"Three Hundred Forty Five"`，中间变量 `parts = ["Twelve Thousand", "Three Hundred Forty Five"]`。

```python
ONES = ["", "One", "Two", ..., "Nineteen"]
TENS = ["", "", "Twenty", "Thirty", ..., "Ninety"]
SUFFIX = ["", "Thousand", "Million", "Billion"]

def _two(n):
    if n < 20: return ONES[n]
    return TENS[n // 10] + (" " + ONES[n % 10] if n % 10 else "")

def _three(n):
    if n < 100: return _two(n)
    rest = n % 100
    return ONES[n // 100] + " Hundred" + (" " + _two(rest) if rest else "")
```

主循环：`while num: chunk = num % 1000; if chunk: parts.append((_three(chunk) + " " + SUFFIX[i]).strip()); num //= 1000; i += 1`，最后 `" ".join(reversed(parts)) or "Zero"`。

## 复杂度
时间：O(log n)，n 是数值，最多 4 段、每段常数次查表。
空间：O(log n)，`parts` 最多 4 个字符串，递归深度 ≤ 2。

## 易错点
- `num = 0` → 主循环一次不进，`parts` 为空，`" ".join` 得 `""` → 必须显式返回 `"Zero"`，别指望循环兜底。
- `num = 1000000` → 中间段 `chunk = 0` 若不过滤，会拼出 `"One Million  Thousand"` 这种双空格 → 加 `if chunk:` 再 append，且用 `strip()` 去掉段尾空格。

## 如果面试官追问
问：改成支持负数？答：入口判 `num < 0` 先取 `"Negative "` 前缀，再对 `-num` 走原流程，注意 `-2**31` 取反在 Python 里安全。
