## 一句话思路
逐行合并：把「前 i 行所有组合和」截断到前 k 小，再与第 i+1 行做两两配对取前 k 小，最终第 k 个即答案。

## 怎么做
1. 初始化 `sums = [0]`，表示 0 行时的唯一组合和。
2. 对每一行 `row`，把 `sums` 中每个值与 `row` 中每个值相加，得到至多 `k*n` 个候选。
3. 用最小堆只取前 `k` 个候选，避免全排序；`sums` 长度始终 ≤ k。
4. 处理完所有行，`sums[k-1]` 就是答案。

以示例 1 `mat = [[1,3,11],[2,4,6]], k = 5` 为例：第一行后 `sums = [1,3,11]`；与 `[2,4,6]` 配对得候选 `[3,5,13,5,7,15,13,15,21]`，取前 5 小为 `[3,5,5,7,13]`，`sums[4] = 13`？注意这里要按「第 k 个最小数组和」定义，实际前 5 个和是 `3,5,5,7,13`，但示例输出 7，说明第 5 个是 7——因为 `[1,6]` 的和 7 排在 `[3,4]` 的 7 之后，前 5 个是 `3,5,5,7,7`，第 5 个为 7。堆取前 k 时需保留重复值。

```python
import heapq
sums = [0]
for row in mat:
    cand = []
    for s in sums:
        for x in row:
            cand.append(s + x)
    sums = heapq.nsmallest(k, cand)
return sums[k - 1]
```

关键中间值：处理完第一行 `sums = [1,3,11]`；第二行候选含 `1+2=3, 1+4=5, 3+2=5, 3+4=7, 1+6=7`，`nsmallest(5)` 得 `[3,5,5,7,7]`，`sums[4]=7`。

## 复杂度
时间：每行生成 `len(sums)*n ≤ k*n` 个候选，堆取前 k 为 `O(k*n*log k)`，共 m 行。
空间：`sums` 与候选列表各至多 `k*n`，即 `O(k*n)`。

## 易错点
- 输入 `mat=[[1,3,11],[2,4,6]], k=5` → 若用 `set` 去重候选和，会把两个 7 合并成一个，`sums` 变成 `[3,5,7,13,...]`，第 5 个错成 13 → 必须保留重复和，用列表不去重。
- 输入 `k=1` 或某行只有 1 列 → 若在配对时假设 `row` 长度 ≥2 或 `sums` 非空才进入循环，会漏掉单元素行 → 循环条件只依赖 `sums` 和 `row` 本身，`nsmallest(1, ...)` 也要正常返回。

## 如果面试官追问
问：若 k 放大到 10^5 且 m,n 仍 40，还能这样做吗？
答：不能，`k*n` 候选过大；改用二分答案 + 逐行计数 ≤ mid 的组合数，复杂度 `O(m*n*log(值域))`。
