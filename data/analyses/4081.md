## 一句话思路
按质数从大到小做可行性 DP，先定最大和，再定最少个数，最后贪心从大到小剔除元素得到字典序最小。

## 怎么做
1. 筛出 ≤ n 的质数 `ps`，记 `m = len(ps)`。
2. 从大到小遍历 `ps`，用 `dp[j]` 表示「已处理的后缀能否凑出和 j」，`dp` 是布尔数组，长度 `s+1`；每处理一个质数 `p`，倒序更新 `dp[j] |= dp[j-p]`。
3. 找最大可达和 `best = max(j for j in range(s+1) if dp[j])`；若 `best == 0` 返回 `[]`。
4. 再跑一遍 DP 求「凑出 `best` 的最少个数」：`cnt[j]` 初始 `inf`，`cnt[0]=0`，同样倒序更新 `cnt[j] = min(cnt[j], cnt[j-p]+1)`。
5. 贪心构造：从大到小扫 `ps`，若 `p <= best` 且 `cnt[best-p] == cnt[best]-1`，就选 `p`、`best -= p`；否则跳过。这样每次优先剔除大质数，剩下的数组字典序最小。

以 `n=15, s=18` 为例：`ps=[2,3,5,7,11,13]`，`dp` 在 `j=18` 处为 `True`，`best=18`；`cnt[18]=2`（`5+13` 或 `7+11`）。贪心从 13 开始：`cnt[5]=1=cnt[18]-1`，选 13，`best=5`；再扫到 5，`cnt[0]=0=cnt[5]-1`，选 5，得 `[5,13]`。

```python
ps = [p for p in range(2, n+1) if all(p % d for d in range(2, int(p**0.5)+1))]
dp = [False]*(s+1); dp[0] = True
for p in reversed(ps):
    for j in range(s, p-1, -1):
        dp[j] = dp[j] or dp[j-p]
best = max((j for j in range(s+1) if dp[j]), default=0)
if best == 0: return []
INF = 10**9
cnt = [INF]*(s+1); cnt[0] = 0
for p in reversed(ps):
    for j in range(s, p-1, -1):
        if cnt[j-p] + 1 < cnt[j]: cnt[j] = cnt[j-p] + 1
res = []
for p in reversed(ps):
    if p <= best and cnt[best-p] == cnt[best]-1:
        res.append(p); best -= p
return sorted(res)
```

## 复杂度
时间：`O(m·s)`，`m` 为质数个数（≤168），筛法 `O(n log log n)`。
空间：`O(s)` 两个数组 `dp`、`cnt`，外加 `ps` 的 `O(m)`。

## 易错点
- `n=1000, s=1000` 时若正序更新 `dp[j]`，同一质数会被重复使用，`dp[4]` 会因 `2+2` 误判为可达 → 必须倒序 `for j in range(s, p-1, -1)`。
- 贪心若从**小到大**扫 `ps`，`n=15, s=18` 会先选 2、3 再凑 13，得到 `[2,3,13]` 三个元素，违反「数量最少」→ 必须从大到小扫，靠 `cnt[best-p] == cnt[best]-1` 保证个数最优。

## 如果面试官追问
问：若要求返回所有最优子集？
答：把贪心换成在 `cnt` 上回溯枚举，每个 `p` 分支选/不选，收集所有 `cnt[best]` 条路径，复杂度升到指数级。
