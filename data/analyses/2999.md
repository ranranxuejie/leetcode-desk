## 一句话思路
用数位 DP 求 `count(finish) - count(start-1)`，其中 `count(n)` 统计 ≤ n 的合法数；后缀固定为 `s`，只需对前缀做数位 DP。

## 怎么做
1. 把 `count(n)` 拆成两部分：长度小于 `len(n)` 的，和长度等于 `len(n)` 的。
2. 长度小于 `len(n)` 时，若长度 `L < len(s)` 直接为 0；否则前缀长度 `L - len(s)`，每位可选 `0..limit`，首位不能为 0，共 `limit^(k-1) * (limit+1)` 类计数。
3. 长度等于 `len(n)` 时，先判断 `n` 的后缀是否 ≥ `s`（决定前缀能否取到上界），再对前缀逐位做数位 DP。
4. 用示例 1 验证：`count(6000)`，`s="124"`，`limit=4`。长度 3 的只有 `124` 本身（前缀空）；长度 4 的前缀 1 位，首位可取 1..4 共 4 个，加上 `124` 共 5；`count(0)=0`，答案 5。

```python
def count(n):
    if n <= 0: return 0
    t = str(n)
    if len(t) < len(s): return 0
    # 长度 < len(t) 的部分
    res = 0
    for L in range(len(s), len(t)):
        k = L - len(s)
        res += (limit + 1) ** k if k == 0 else limit * (limit + 1) ** (k - 1)
    # 长度 == len(t)：前缀逐位
    k = len(t) - len(s)
    pre = t[:k]
    for i, c in enumerate(pre):
        d = int(c)
        lo = 1 if i == 0 else 0
        res += max(0, min(d - 1, limit) - lo + 1) * (limit + 1) ** (k - i - 1)
        if d > limit or d < lo: return res
    if t[k:] >= s: res += 1
    return res
```

## 复杂度
时间：`O(len(finish))`，逐位扫描两次（start-1 与 finish），每位数位 DP 只做常数次幂运算。
空间：`O(1)`，只存字符串和几个整数，无额外数组。

## 易错点
1. `start=1, finish=6000, limit=4, s="124"`：若忘记 `count(start-1)` 而直接 `count(finish)`，会把区间外的小于 start 的数也算进去；必须做差 `count(finish) - count(start-1)`。
2. `s="3000", start=1000, finish=2000`：若在长度相等分支不检查 `t[k:] >= s` 就直接加 1，会把 `2000` 误判为合法；正确做法是后缀比较 `t[k:] >= s` 才 `res += 1`，否则前缀取到上界时该数不合法。

## 如果面试官追问
问：若 `limit` 很大（如 10^9）怎么办？答：`limit` 只影响每位的可选个数，公式 `limit * (limit+1)^(k-1)` 仍成立，无需枚举，复杂度不变。
