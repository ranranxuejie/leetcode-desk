## 一句话思路
把「轮转 + 奇位累加」看成状态图，BFS/DFS 枚举所有可达字符串取最小；状态数被 `b` 与 `a` 的周期卡死，规模可控。

## 怎么做
1. 状态就是字符串本身，用 `seen` 集合去重，从 `s` 出发做 BFS。
2. 每次从队列取出 `cur`，生成两个后继：`cur[-(b%n):] + cur[:-(b%n)]` 和奇位 `(int(c)+a)%10` 的新串。
3. 每个后继若不在 `seen` 里就入队，同时用 `min` 维护答案。

以示例 1 `s="5525", a=9, b=2` 为例：首轮轮转得 `"2555"`，对奇数下标 1、3 累加 9 得 `"2454"`（`5+9=14→4`，`5+9=14→4`），这两个后继都进 `seen`；继续扩展直到队列空，最小值为 `"2050"`。

```python
from collections import deque
n = len(s)
seen = {s}
q = deque([s])
best = s
while q:
    cur = q.popleft()
    best = min(best, cur)
    rot = cur[-b:] + cur[:-b] if b % n else cur
    add = ''.join(str((int(c) + a) % 10) if i % 2 else c
                  for i, c in enumerate(cur))
    for nxt in (rot, add):
        if nxt not in seen:
            seen.add(nxt)
            q.append(nxt)
```

注意 `b % n` 为 0 时轮转是恒等变换，别把 `cur[-0:]` 当成空串。

## 复杂度
时间 O(S·n)，S 为可达状态数（≤ 10^n 但实际被周期压到很小），每状态 O(n) 造串。
空间 O(S·n)，`seen` 存全部可达字符串，队列同阶。

## 易错点
- `b` 与 `n` 不互素时（如 `s="0011", a=4, b=2`），轮转只在偶数位子集上循环，可达状态远少于直觉；若按 `n` 位全排列估算会误判规模、写错剪枝。
- `b % n == 0` 时 `cur[-b:] + cur[:-b]` 在 Python 里 `cur[-0:]` 是整串、`cur[:-0]` 是空串，结果恰好等于 `cur`，看似无害；但若写成 `cur[n-b:]` 之类索引就会越界或错位，正确做法是先判 `b % n` 再轮转。

## 如果面试官追问
问：`n` 放大到 10^5 还能 BFS 吗？答：不能，需利用「轮转只改变位置、累加只作用于固定奇偶类」把问题拆成两个独立循环群求最小表示。
