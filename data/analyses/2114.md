## 一句话思路
每个句子的单词数等于空格数加一，逐句数空格取最大值即可。

## 怎么做
1. 初始化 `best = 0`，遍历 `sentences` 中每个句子 `s`。
2. 对每个 `s`，用 `s.count(' ') + 1` 得到单词数，因为题目保证首尾无空格、单词间单个空格。
3. 用 `max` 更新 `best`，遍历结束返回 `best`。

以示例 1 为例：`"alice and bob love leetcode"` 有 4 个空格，得 5；`"i think so too"` 有 3 个空格，得 4；`"this is great thanks very much"` 有 5 个空格，得 6，`best` 最终为 6。

```python
best = 0
for s in sentences:
    cnt = s.count(' ') + 1
    if cnt > best:
        best = cnt
return best
```

若想更短，可写成 `return max(s.count(' ') + 1 for s in sentences)`，逻辑完全等价。

## 复杂度
时间：O(n)，n 为所有句子字符总数，每个字符被 `count` 扫一次。
空间：O(1)，只开了 `best`、`cnt` 两个整数。

## 易错点
- 输入 `["please wait"]` 这类只有一个空格的句子 → 若写成 `s.count(' ')` 直接返回会得 1，实际应为 2 → 必须加一，因为单词数 = 空格数 + 1。
- 输入 `["a"]` 这种无空格单句 → 若用 `s.split(' ')` 后取长度虽然也对，但若误用 `s.split()` 再对空串处理会多出边界判断 → 直接用 `count(' ') + 1` 最稳，无需处理空串分支。

## 如果面试官追问
问：若句子首尾可能有多余空格怎么办？
答：改用 `len(s.split())`，`split()` 无参时自动忽略连续空白，不再依赖「单个空格」的保证。
