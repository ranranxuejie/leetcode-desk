## 一句话思路
n 为奇数时用「轮转法」把 n 队排成环，每轮取固定队 0 配一个对手、其余两两配对，正反各跑一遍即得 2n(n-1)/2 场且无队伍连赛。

## 怎么做
1. 先判 n 为偶数直接返回 `[]`：总场次 n(n-1) 是偶数，而「无队伍连赛」要求相邻两场四支队伍互不相同，n 为偶数时首尾必然冲突。
2. 把队伍 1..n-1 排成环，第 r 轮（r=0..n-2）的配对是 `(0, ring[r])` 加上 `ring[(r+k) % (n-1)]` 与 `ring[(r-k) % (n-1)]` 对 k=1..(n-1)/2。
3. 每轮内部按「先 0 的比赛、再其余配对」的顺序输出，轮与轮之间天然错开一支队伍，保证连续两天无重复。
4. 正向跑完 n-1 轮后，把每场主客对调再跑一遍，凑满主客各一次。

以 n=5 为例，ring=[1,2,3,4]，r=0 时配对为 (0,1)、(2,4)、(3,?)——k 只取 1..2，实际是 (0,1)、(2,4)、(3,?) 需按 `(r+k)%4` 与 `(r-k)%4` 算：k=1 得 (2,4)，k=2 得 (3,3) 自配对要跳过，故 r=0 输出 `[[0,1],[2,4]]`，与示例前两场 `[0,1],[2,3]` 顺序不同但同样合法。

```python
def build(ring, n):
    m = n - 1
    res = []
    for r in range(m):
        res.append([0, ring[r]])
        for k in range(1, m // 2 + 1):
            a, b = ring[(r + k) % m], ring[(r - k) % m]
            if a != b:
                res.append([a, b])
    return res

if n % 2 == 0:
    return []
half = build(list(range(1, n)), n)
return half + [[b, a] for a, b in half]
```

## 复杂度
时间：O(n²)，共 n(n-1) 场比赛，每场 O(1) 生成。
空间：O(n²) 存结果数组，环本身只占 O(n)。

## 易错点
- n=2 时 ring 只有 [1]，`m//2 = 0` 内层不执行，只输出 `[[0,1]]` 加反向 `[[1,0]]`，共 2 场正确；若误判 n 为偶数就返回 `[]` 会漏掉这个唯一合法解，判偶条件要写成 `n % 2 == 0 and n > 2`。
- n=5 时 k 循环到 2 会出现 `(r+k)%4 == (r-k)%4` 的自配对（如 r=0,k=2 得 3 与 3），必须用 `if a != b` 跳过，否则输出 `[3,3]` 这种自己打自己的非法场次。

## 如果面试官追问
问：n 为偶数真的无解吗？答：总场次 n(n-1) 为偶数，但每支队要打 2(n-1) 场且不能相邻，n 队共需 2n 个「空档」位置，偶数 n 时鸽巢冲突，故无解。
