## 一句话思路
把第二个线段固定为右端点，用滑动窗口预处理「以 i 结尾的单线段最多覆盖数」，再与左侧不重叠部分相加取最大。

## 怎么做
1. 对每个右端点 `r`，用双指针找最小的 `l` 使 `prizePositions[r] - prizePositions[l] <= k`，窗口长度 `r-l+1` 即单线段覆盖数。
2. 记 `best[r] = max(best[r-1], r-l+1)`，表示「右端点不超过 r 的任意单线段」最多能拿多少。
3. 枚举第二个线段右端点 `r`，其左端 `l` 由同一双指针给出，答案候选为 `(r-l+1) + best[l-1]`（`l=0` 时取 0）。
4. 取所有候选最大值。

以示例 1 `[1,1,2,2,3,3,5], k=2` 为例：`r=5`（位置 3）时 `l=2`（位置 2），窗口 `[2,3]` 得 4 件；`best[1]=2`（`[1,1]`），候选 6。`r=6`（位置 5）时 `l=4`（位置 3），窗口 3 件，`best[3]=4`，候选 7，即答案。

```python
n = len(prizePositions)
best = [0] * n
l = 0
for r in range(n):
    while prizePositions[r] - prizePositions[l] > k:
        l += 1
    cnt = r - l + 1
    best[r] = max(best[r - 1], cnt) if r else cnt

ans = 0
l = 0
for r in range(n):
    while prizePositions[r] - prizePositions[l] > k:
        l += 1
    left = best[l - 1] if l else 0
    ans = max(ans, r - l + 1 + left)
```

## 复杂度
时间：O(n)，两个双指针各扫一遍，`l` 单调不回退。
空间：O(n)，`best` 数组存每个右端点的前缀最优值。

## 易错点
- `k=0` 且位置有重复，如 `[1,2,3,4]`：若把窗口条件写成 `< k` 会得到空窗口，答案错成 0；正确是 `> k` 才收缩，单点窗口长度 1，两线段各取一点得 2。
- 两线段允许重叠，如示例 1 的 `[1,3]` 与 `[3,5]` 共享位置 3：若强制 `best[l-1]` 与当前窗口严格不相交（用 `l` 而非 `l-1` 之外的边界）会漏掉共享端点的情况，答案错成 6；正确是左侧取 `best[l-1]`，允许端点重合。

## 如果面试官追问
问：若要求输出两个线段的具体端点而非数量？
答：在更新 `ans` 时同步记录当前 `r`、`l` 和 `best[l-1]` 对应的那个右端点，回溯 `best` 数组即可还原。
