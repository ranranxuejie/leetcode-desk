## 一句话思路
只统计 26 个字母各出现几次，按「z 分裂成 a、b，其余字母 +1」逐轮推进计数，t 轮后求和。

## 怎么做
1. 用长度 26 的数组 `cnt` 记录 `s` 中每个字母的出现次数，`cnt[ord(c) - 97] += 1`。
2. 每轮先记下 `z` 的数量 `z = cnt[25]`，再把 `cnt[1..25]` 整体右移一位（`cnt[i] = cnt[i-1]`），`cnt[0] = z`，`cnt[1] += z`。
3. 重复 t 轮，最后 `sum(cnt) % (10**9 + 7)`。

以 `s = "abcyy", t = 2` 为例：初始 `cnt` 中 a、b、c、y 各 1，y 有 2 个，即 `cnt[24] = 2`。第一轮 `z = cnt[25] = 0`，右移后 a→b、b→c、c→d、y→z，`cnt[25]` 变成 2。第二轮 `z = 2`，右移后 `cnt[0] = 2`、`cnt[1] = 2`（原来的 a 变 b 得 1，加上 z 分裂出的 b 得 1），其余各 1，总和 7。

```python
MOD = 10**9 + 7
cnt = [0] * 26
for ch in s:
    cnt[ord(ch) - 97] += 1
for _ in range(t):
    z = cnt[25]
    for i in range(25, 0, -1):
        cnt[i] = cnt[i - 1]
    cnt[0] = z
    cnt[1] = (cnt[1] + z) % MOD
return sum(cnt) % MOD
```

注意右移必须从 `i = 25` 倒着走，否则 `cnt[i-1]` 已被覆盖。

## 复杂度
时间 O(26·t + |s|)：每轮固定扫 26 个格子，t 最多 1e5，约 2.6e6 次操作。
空间 O(26)：只开一个定长计数数组，与 |s|、t 无关。

## 易错点
- `s = "z", t = 1` 时若写成 `cnt[0] = z; cnt[1] += z` 但先做了右移，`cnt[1]` 会拿到旧的 `cnt[0]`（0）再加 z，结果对；但若顺序写成先 `cnt[1] += z` 再右移，z 分裂出的 b 会被右移覆盖掉，长度少 1。正确做法是先存 `z`，右移完再写 `cnt[0]` 和 `cnt[1]`。
- `t = 1e5` 且 `s` 全是 `"z"` 时，长度按斐波那契式增长，数值巨大；若在循环里忘了对 `cnt[1]` 取模，Python 虽不溢出但大整数加法会拖慢。正确做法是每轮对 `cnt[1]` 取模，最后 `sum` 再取一次。

## 如果面试官追问
若 t 放大到 1e9 怎么办？答：把 26 维计数向量看成状态，用 26×26 转移矩阵做快速幂，O(26³ log t)。
