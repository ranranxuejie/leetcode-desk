## 一句话思路
从 start 做 BFS 得到每个格子的最短距离，把价格落在 [low, high] 的物品按 (距离, 价格, 行, 列) 排序取前 k 个。

## 怎么做
1. 从 `start` 出发 BFS，`dist` 二维数组初始化为 -1，只走 `grid[r][c] != 0` 的格子，遇到 0 不扩展。
2. BFS 出队时若 `low <= grid[r][c] <= high`，把 `(dist, grid[r][c], r, c)` 塞进候选列表。
3. 对候选列表排序，取前 `k` 个，只保留 `[r, c]`。

以示例 1 为例：`start=(0,0)`，BFS 得到 `(0,1)` 距离 1、`(1,1)` 距离 2、`(2,1)` 距离 3、`(2,2)` 距离 4。候选为 `[(1,2,0,1),(2,3,1,1),(3,2,2,1),(4,5,2,2)]`，排序后前 3 个是 `(0,1),(1,1),(2,1)`。

```python
from collections import deque
m, n = len(grid), len(grid[0])
dist = [[-1] * n for _ in range(m)]
dist[start[0]][start[1]] = 0
q = deque([tuple(start)])
cand = []
while q:
    r, c = q.popleft()
    if low <= grid[r][c] <= high:
        cand.append((dist[r][c], grid[r][c], r, c))
    for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
        nr, nc = r + dr, c + dc
        if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] != 0 and dist[nr][nc] == -1:
            dist[nr][nc] = dist[r][c] + 1
            q.append((nr, nc))
cand.sort()
return [[r, c] for _, _, r, c in cand[:k]]
```

## 复杂度
时间：BFS 是 O(m·n)，排序是 O(P log P)，P 为价格区间内物品数，P ≤ m·n。
空间：`dist` 是 O(m·n)，队列和候选列表各 O(m·n)。

## 易错点
1. 起点本身是物品时（如 `start=(2,3)`、`grid[2][3]=1` 不是，但若 `grid[start]=5` 且在区间内）→ 若只在扩展邻居时收集，会漏掉距离 0 的起点 → 正确做法是在出队时判断当前格子，而不是在入队邻居时判断。
2. 价格区间判断写成 `low < grid < high` 开区间 → 示例 1 中 `grid[0][1]=2` 等于 low 会被漏掉，输出变成 `[[1,1],[2,1]]` 少一个 → 必须用 `low <= grid[r][c] <= high`。

## 如果面试官追问
若 m·n 到 10^7、k 很小，怎么优化？答：BFS 按层扩展，距离天然递增，用大小为 k 的最大堆按 (价格,行,列) 维护，凑满 k 个且当前层距离更大时即可提前终止。
