## 一句话思路
按树高排序后，依次对相邻两棵树（起点算第一站）做 BFS 求最短路，累加；任一段不可达即 -1。

## 怎么做
1. 扫描 `forest`，把所有 `forest[i][j] > 1` 的格子收进 `trees`，按高度升序排；把起点 `(0,0)` 插到最前面当第 0 站。
2. 对每对相邻站点 `(sr,sc) -> (tr,tc)` 跑一次 BFS，只走 `forest[r][c] != 0` 的格子，返回步数。
3. 任一段 BFS 返回 -1，立刻返回 -1；否则把各段步数累加。

以示例 1 为例，`trees` 排序后是 `(0,0)高1 → (0,1)高2 → (0,2)高3 → (1,2)高4 → (2,2)高5 → (2,1)高6 → (2,0)高7`。第一段 `(0,0)->(0,1)` BFS 得 1；关键一段 `(0,2)->(1,2)` 得 1，因为 `forest[1][2]=4` 可走；而 `(0,1)->(0,2)` 之间 `forest[1][1]=0` 不影响，走的是上边一行。累加 1+1+1+1+1+1=6。

```python
from collections import deque
def bfs(sr, sc, tr, tc):
    if (sr, sc) == (tr, tc): return 0
    q, seen = deque([(sr, sc, 0)]), {(sr, sc)}
    while q:
        r, c, d = q.popleft()
        for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
            nr, nc = r+dr, c+dc
            if 0<=nr<m and 0<=nc<n and forest[nr][nc]!=0 and (nr,nc) not in seen:
                if (nr, nc) == (tr, tc): return d+1
                seen.add((nr, nc)); q.append((nr, nc, d+1))
    return -1
```

主循环里 `total += d`，`d == -1` 时直接 `return -1`。

## 复杂度
时间：设树数 k，每段 BFS 是 O(m·n)，共 O(k·m·n)；排序 O(k log k)。
空间：每次 BFS 的 `seen` 与队列 O(m·n)，复用不累积。

## 易错点
- 起点 `(0,0)` 本身是树（示例 3 的 `forest[0][0]=2`）→ 若把起点也当普通树去 BFS 找它，会多算或死循环 → 正确做法是把 `(0,0)` 直接作为第 0 站，砍它不算步数，从它出发去下一棵。
- 只按「高度升序」排但漏了起点插入 → 示例 3 会从 `(0,0)` 高 2 开始却先去找高 3 的 `(0,1)`，步数算成 1 而非 0 起步 → 正确做法是 `trees = [(0,0)] + sorted(...)`，且排序键只取 `forest[r][c]`。
- 障碍判断写成 `forest[nr][nc] == 1` 才可走 → 树格（值 >1）被当成墙，示例 1 的 `(1,2)=4` 走不通，输出 -1 → 正确条件是 `!= 0`。

## 如果面试官追问
问：若允许任意顺序砍树（不按高度）？答：变成在树集合上的最短哈密顿路径，k 小可状压 DP，k 大则 NP-hard，需说明近似或限制。
