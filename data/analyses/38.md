## 一句话思路
迭代生成：从 `"1"` 出发，对当前串做一次行程长度编码，重复 `n-1` 次，因为第 n 项只依赖第 n-1 项。

## 怎么做
1. 令 `s = "1"`，外层循环 `for _ in range(n - 1)`，每轮把 `s` 重写成它的 RLE。
2. 内层用双指针 `i` 扫描 `s`，`j = i` 向后推进直到 `s[j] != s[i]`，此时组长为 `j - i`、字符为 `s[i]`。
3. 把 `str(j - i) + s[i]` 追加到 `parts`，然后 `i = j` 继续下一组。
4. 每轮结束 `s = "".join(parts)`，循环完返回 `s`。

以 `n = 4` 为例，关键那步是 `s = "21"` 时：`i = 0`，`s[0] = '2'`，`j` 停在 1，组长 1，写入 `"12"`；`i = 1`，`s[1] = '1'`，`j` 走到 2（越界），组长 1，写入 `"11"`；拼起来 `"1211"`，正是答案。

```python
s = "1"
for _ in range(n - 1):
    parts = []
    i = 0
    while i < len(s):
        j = i
        while j < len(s) and s[j] == s[i]:
            j += 1
        parts.append(str(j - i) + s[i])
        i = j
    s = "".join(parts)
return s
```

注意 `j - i` 可能 ≥ 10（如 `"1111111111"` 的组长为 10），`str()` 会自然输出 `"10"`，不要假设组数是一位数字。

## 复杂度
时间：O(n · L)，L 为第 n 项长度（约 1.3 倍增长），每轮线性扫描一次。
空间：O(L) 存 `parts` 和 `s`，与 n 无关的额外常数。

## 易错点
- `n = 1` 时若把循环写成 `for _ in range(n)`，会多编码一次得到 `"11"`，返回错误；正确是 `range(n - 1)`，直接返回初始 `"1"`。
- 内层 `while` 漏掉 `j < len(s)` 边界判断，遇到 `s = "1"` 这种单字符结尾会 `IndexError`；正确写法是 `while j < len(s) and s[j] == s[i]`，让 `j` 停在 `len(s)` 上。

## 如果面试官追问
问：n 大到 10^5 怎么办？答：项长指数增长，无法真算，只能返回长度或按模运算，需换思路而非迭代。
