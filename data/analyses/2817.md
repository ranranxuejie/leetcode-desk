## 一句话思路
按右端点 j 递增，把下标 ≤ j-x 的 nums 值塞进有序集合，对每个 nums[j] 二分找最近值。

## 怎么做
1. 维护一个有序结构 `sl`，只放「已经满足距离条件」的左端点值。
2. 遍历 j 从 x 到 n-1，每步先把 `nums[j-x]` 插入 `sl`（此时它和 j 的距离恰好是 x，往后都合法）。
3. 在 `sl` 里用 `bisect_left(nums[j])` 找插入位置 p，答案只可能来自 `sl[p]` 或 `sl[p-1]`。
4. 用这两个候选更新 `ans = min(ans, abs(...))`。

以示例 2 `nums = [5,3,2,10,15], x = 1` 为例：j=1 时先插入 `nums[0]=5`，`sl=[5]`，对 `nums[1]=3` 二分得 p=0，候选只有 5，`ans=2`；j=2 时插入 `nums[1]=3`，`sl=[3,5]`，对 `nums[2]=2` 得 p=0，候选 3，`ans=min(2,1)=1`。

```python
from bisect import bisect_left, insort
n = len(nums)
ans = float('inf')
sl = []
for j in range(x, n):
    insort(sl, nums[j - x])
    p = bisect_left(sl, nums[j])
    if p < len(sl):
        ans = min(ans, sl[p] - nums[j])
    if p > 0:
        ans = min(ans, nums[j] - sl[p - 1])
return ans
```

注意 `insort` 是 O(n) 搬移，n=1e5 时最坏 1e10 次操作会超时，实际应换成 `SortedList`（`from sortedcontainers import SortedList`，`sl.add(...)`、`sl.bisect_left(...)`），逻辑完全一致。

## 复杂度
时间：外层 n 次，每次插入 + 二分各 O(log n)，共 O(n log n)。
空间：有序集合最多存 n-x 个元素，O(n)。

## 易错点
- `x = 0` 时：循环从 j=0 开始，先插入 `nums[0]` 再对 `nums[0]` 自己二分，会得到差值 0 并直接返回，但题目要求两个不同下标。正确做法是 x=0 时答案恒为 0（任意相邻同值或直接取 nums 中最小间隔），或先插入再查时排除自身下标。
- 只查 `sl[p]` 不查 `sl[p-1]`：如 `nums=[10,1,9], x=1`，j=2 时 `sl=[10,1]` 排序后 `[1,10]`，`nums[2]=9` 的 p=1，`sl[1]-9=1` 正确；但若 `nums[2]=2`，p=1，`sl[1]-2=8` 而 `2-sl[0]=1` 才是答案，漏查左侧会偏大。

## 如果面试官追问
要求输出具体下标对而非差值？答：二分时同时记录 `sl` 中元素的原下标，取到更优候选时一并更新 `(i, j)`。
