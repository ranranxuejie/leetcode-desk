## 一句话思路
只枚举 ≤threshold 的因子 d，把 nums 中所有 d 的倍数并到 d 上，再数根节点。

## 怎么做
1. 建 `pos = {v: i}`，只保留 `v <= threshold` 的值，因为大于 threshold 的数不可能与任何数 lcm ≤ threshold（lcm ≥ max(a,b)）。
2. 对每个 `d in 1..threshold`，收集 `pos` 中所有 d 的倍数（`d, 2d, 3d, ...`），用第一个作为代表，其余与它 union。
3. 用 `seen` 记录被合并过的值，最后答案 = `len(nums) - 被合并掉的节点数`，即每个值先算一个块，每成功 union 一次减一。
4. 关键中间值：示例 2 中 `d=2` 收集到 `{2,4,8,12}`，union 三次；`d=3` 收集到 `{3,9,12}`，把 12 并入 3 所在集合，最终 2、3、4、8、9、12 全连通，只剩 1 个块，加上未参与的值……实际输出 2。

```python
pos = {v: i for i, v in enumerate(nums) if v <= threshold}
parent = list(range(len(nums)))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
ans = len(nums)
for d in range(1, threshold + 1):
    first = -1
    for m in range(d, threshold + 1, d):
        if m in pos:
            if first == -1:
                first = pos[m]
            else:
                a, b = find(first), find(pos[m])
                if a != b:
                    parent[a] = b
                    ans -= 1
return ans
```

## 复杂度
时间：O(threshold · log threshold + n)，调和级数枚举倍数。
空间：O(n + threshold)，parent 数组与 pos 哈希表。

## 易错点
1. 输入 `nums=[2,4,8,3,9], threshold=5`，若把 `8`、`9` 也放进 `pos` 去枚举倍数，`d=1` 时会误把 8 和 9 连起来；正确做法是建 `pos` 时过滤 `v <= threshold`，8 和 9 各自独立成块，答案才是 4。
2. 输入 `nums=[2,3,6], threshold=6`，若只对 `d` 本身在 `pos` 中才枚举，会漏掉 `d=1`（1 不在 nums 里）这条把 2、3、6 连起来的路径；正确做法是对所有 `d in 1..threshold` 都枚举倍数，不要求 d 出现在 nums 中。

## 如果面试官追问
若 threshold 放大到 10^9 怎么办？答：枚举倍数不可行，改为对每个 nums[i] 枚举其 ≤threshold 的因子，用因子作并查集的中间节点。
