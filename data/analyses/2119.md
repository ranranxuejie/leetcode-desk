## 一句话思路
只有末尾带 0 的 num（且 num≠0）会丢位，所以答案就是 `num == 0 or num % 10 != 0`。

## 怎么做
1. 反转会吃掉末尾的 0，第二次反转无法把 0 补回来，所以丢位只发生在 num 的末位是 0 时。
2. 特判 num = 0：它反转仍是 0，两次反转后相等，返回 True。
3. 其余情况看 `num % 10`：非 0 则末位在两次反转后原样回到末尾，返回 True；为 0 则返回 False。

以 num = 1800 为例：第一次反转得 reversed1 = 81（两个 0 被吃掉），第二次反转得 reversed2 = 18，与 1800 不等，返回 False。关键中间值是 reversed1 = 81，它已经丢了两位。

```python
def isSameAfterReversals(num):
    if num == 0:
        return True
    return num % 10 != 0
```

若想按题面模拟，也可写 `rev1 = int(str(num)[::-1])`，再 `rev2 = int(str(rev1)[::-1])`，比较 `rev2 == num`；但判断末位是 O(1)，模拟是 O(log num)。

## 复杂度
时间：O(1)，只做一次取模和比较，与 num 的位数无关。
空间：O(1)，没有开数组或字符串。

## 易错点
- num = 0 → 若直接写 `num % 10 != 0` 会返回 False，错判；0 的末位是 0 但它反转不丢位，必须先特判返回 True。
- num = 1800 → 若只判断「num 含 0」就返回 False，会误伤 526 这类中间含 0 的数；正确做法只看末位 `num % 10`，526 末位是 6 应返回 True。

## 如果面试官追问
问：num 上限放大到 10^18 还一样吗？答：一样，判断只看末位，O(1) 不受位数影响。
