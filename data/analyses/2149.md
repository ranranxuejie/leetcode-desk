## 一句话思路
正负数量相等且要保序，就把正数、负数各按原序收集，再交替写入结果，正数占偶数位。

## 怎么做
1. 一次遍历 `nums`，正数 append 到 `pos`，负数 append 到 `neg`，两者内部顺序天然保持。
2. 结果数组长度 `n = len(nums)`，正数放偶数下标 `0,2,4...`，负数放奇数下标 `1,3,5...`。
3. 用 `for i in range(n // 2)` 同时写 `res[2*i] = pos[i]`、`res[2*i+1] = neg[i]`。

以 `nums = [3,1,-2,-5,2,-4]` 为例，收集后 `pos = [3,1,2]`、`neg = [-2,-5,-4]`；`i=0` 写 `res[0]=3, res[1]=-2`，`i=1` 写 `res[2]=1, res[3]=-5`，`i=2` 写 `res[4]=2, res[5]=-4`，得 `[3,-2,1,-5,2,-4]`。

```python
pos, neg = [], []
for x in nums:
    if x > 0:
        pos.append(x)
    else:
        neg.append(x)

n = len(nums)
res = [0] * n
for i in range(n // 2):
    res[2 * i] = pos[i]
    res[2 * i + 1] = neg[i]
```

关键点：`pos` 和 `neg` 的长度都是 `n // 2`，所以循环上界直接用 `n // 2`，不需要 `min(len(pos), len(neg))`。

## 复杂度
时间 O(n)：一次遍历分桶加一次写结果，各扫 n 个元素。
空间 O(n)：`pos`、`neg`、`res` 合计约 2n 个槽位。

## 易错点
- 输入 `nums = [-1,1]` → 若按「先遇到的符号先放」直接交替，会得到 `[-1,1]`，违反「以正整数开头」→ 必须固定正数占偶数位、负数占奇数位，与出现顺序无关。
- 输入 `nums = [1,2,-3,-4]` → 若用两个指针在原数组上原地交换，交换会打乱 `pos` 内的相对顺序，得到 `[1,-3,2,-4]` 看似对，但换成 `[2,1,-3,-4]` 就可能把 `2,1` 换乱 → 题目允许额外空间，直接分桶保序最稳，别原地折腾。

## 如果面试官追问
问：若正负数数量不相等（比如正数多 2 个），怎么改？
答：仍按偶数位放正、奇数位放负，多出的正数顺序追加到尾部，循环上界取 `min(len(pos), len(neg))` 后再拼接剩余部分。
