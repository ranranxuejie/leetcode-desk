## 一句话思路
快慢指针找中点后反转后半段，再与前半段逐节点比对，做到 O(1) 空间。

## 怎么做
1. 用 `slow`、`fast` 从 `head` 出发，`fast` 每次走两步，循环结束时 `slow` 落在后半段起点。
2. 从 `slow` 起把后半段就地反转，得到新头 `p2`。
3. 用 `p1 = head` 与 `p2` 同步前进，值不等即返回 `False`。
4. 全部相等返回 `True`（面试中可再把后半段反转回去）。

以 `1->2->2->1` 为例：`fast` 走完时 `slow` 指向第二个 `2`（下标 2），反转后 `p2` 链为 `1->2`，与 `p1` 的 `1->2` 逐位相等，返回 `True`。若输入 `1->2`，`slow` 停在 `2`，反转后 `p2` 是 `2`，`p1` 的 `1` 与 `2` 不等，返回 `False`。

```python
slow = fast = head
while fast and fast.next:
    slow, fast = slow.next, fast.next.next
p2, prev = slow, None
while p2:
    p2.next, prev, p2 = prev, p2, p2.next
p1, p2 = head, prev
while p2:
    if p1.val != p2.val:
        return False
    p1, p2 = p1.next, p2.next
return True
```

关键点：反转循环里 `p2.next, prev, p2 = prev, p2, p2.next` 的右值先整体求值，所以 `p2.next` 用的是旧值，不会断链。

## 复杂度
时间 O(n)：找中点、反转、比对各扫一遍，常数倍仍是 n。
空间 O(1)：只开了 `slow/fast/p1/p2/prev` 五个指针，没有额外容器。

## 易错点
- 输入 `1->2->1`（奇数长度）→ 若把 `slow` 直接当后半段起点，中点 `2` 会被拿来和 `1` 比，错判 `False` → 正确做法是让 `p2` 从 `slow` 开始、`p1` 从 `head` 开始，比对循环以 `p2` 走完为界，中点自然被跳过。
- 输入 `1->1` 或单节点 `1` → 若反转前没判 `fast and fast.next`，`fast.next.next` 会抛 `AttributeError` → 循环条件必须写成 `while fast and fast.next`，保证 `fast.next` 非空才取 `.next`。

## 如果面试官追问
问：不允许修改链表怎么办？
答：改用递归或把前半段值压栈，空间退到 O(n)，时间仍是 O(n)。
