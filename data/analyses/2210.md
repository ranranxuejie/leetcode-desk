## 一句话思路
先把连续相等的数压成一个，再数压缩后序列里严格大于或严格小于左右邻居的位置。

## 怎么做
1. 从左到右扫 `nums`，只把和上一个保留值不同的元素追加进 `a`，得到去重相邻重复后的序列。
2. 对 `a` 中下标 `i` 从 1 到 `len(a)-2`，判断 `a[i] > a[i-1] and a[i] > a[i+1]` 或 `a[i] < a[i-1] and a[i] < a[i+1]`，成立就计数加一。
3. 首尾元素天然没有两侧不相等邻居，循环范围排除它们即可。

以 `nums = [2,4,1,1,6,5]` 为例，压缩后 `a = [2,4,1,6,5]`。`i=1` 时 `4 > 2 and 4 > 1`，计数 1；`i=2` 时 `1 < 4 and 1 < 6`，计数 2；`i=3` 时 `6 > 1 and 6 > 5`，计数 3。原来下标 2、3 的两个 1 被压成一个，只算一次谷。

```python
a = []
for x in nums:
    if not a or a[-1] != x:
        a.append(x)

ans = 0
for i in range(1, len(a) - 1):
    if (a[i] > a[i-1] and a[i] > a[i+1]) or \
       (a[i] < a[i-1] and a[i] < a[i+1]):
        ans += 1
return ans
```

## 复杂度
时间 O(n)：一次扫描压缩，一次扫描计数，n 为 `nums` 长度。
空间 O(n)：额外开了压缩数组 `a`，最坏情况无相邻重复时长度等于 n。

## 易错点
- 输入 `[2,4,1,1,6,5]` → 若直接在原数组上判断 `nums[i]` 与 `nums[i-1]`、`nums[i+1]`，下标 3 的 1 会因右邻是 6 被重复算成第二个谷 → 必须先压缩相邻重复，让 `a` 中每个平台只留一个代表。
- 输入 `[6,6,5,5,4,1]` → 若压缩后仍从 `i=0` 或 `i=len(a)-1` 开始判断，会因越界或把端点误判为峰谷 → 循环范围严格取 `range(1, len(a)-1)`，端点直接跳过。

## 如果面试官追问
若要求返回所有峰谷的下标区间而非数量，怎么改？答：压缩时记录每个值对应的原始下标区间，判断成立时把该区间加入结果。
