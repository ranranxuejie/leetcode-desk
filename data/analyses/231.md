## 一句话思路
用 `n > 0 and n & (n - 1) == 0`：2 的幂的二进制只有一个 1，减一后低位全变 1、与原数按位与必为 0。

## 怎么做
1. 先排除 `n <= 0`：负数最高位是 1，`-2**31` 这类值会让位运算误判，且 2 的幂不可能 ≤ 0。
2. 对正整数取 `n & (n - 1)`，若结果为 0 则 `n` 只有一个二进制 1，即 2 的幂。
3. 直接返回这个布尔结果，不写循环。

以 `n = 16` 为例：`16` 的二进制是 `10000`，`n - 1 = 15` 是 `01111`，`16 & 15 = 0`，返回 `True`。换成 `n = 3`：`3 & 2 = 0b11 & 0b10 = 0b10 = 2 ≠ 0`，返回 `False`。

```python
def isPowerOfTwo(n: int) -> bool:
    return n > 0 and (n & (n - 1)) == 0
```

关键就一行：`n > 0` 挡住 `0` 和负数，`(n & (n - 1)) == 0` 挡住所有「二进制里 1 的个数 ≥ 2」的数。注意 `n = 0` 时 `0 & -1 == 0` 也成立，所以 `n > 0` 不能省。

## 复杂度
时间：O(1)，只做一次减法、一次按位与、一次比较，与 `n` 的大小无关。
空间：O(1)，没有额外数组或递归栈。

## 易错点
- 输入 `n = 0` → 只写 `n & (n - 1) == 0` 会返回 `True`（`0 & -1 = 0`）→ 必须前置 `n > 0`。
- 输入 `n = -2**31` → 漏掉正数判断时，负数在补码下可能凑出「只有一个 1」的形态而被误判 → 同样靠 `n > 0` 短路挡掉，不要试图对负数做位运算修正。

## 如果面试官追问
问：不用位运算还能怎么做？
答：循环 `while n % 2 == 0: n //= 2`，最后看 `n == 1`，时间 O(log n)，但要先判 `n > 0`。
