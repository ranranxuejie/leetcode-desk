## 一句话思路
先反转链表从低位乘 2，再反转回来；这样进位方向与遍历方向一致，无需栈或递归。

## 怎么做
1. 反转 `head` 得到 `rev`，此时 `rev` 从个位开始。
2. 遍历 `rev`，维护 `carry`，每位算 `v = node.val * 2 + carry`，新节点值 `v % 10`，`carry = v // 10`。
3. 遍历结束后若 `carry == 1`，在尾部补一个值为 1 的节点。
4. 把结果链表再反转一次返回。

以 `head = [1,8,9]` 为例：反转后 `rev = [9,8,1]`。第一位 `9*2+0=18`，新节点 `8`，`carry=1`；第二位 `8*2+1=17`，新节点 `7`，`carry=1`；第三位 `1*2+1=3`，新节点 `3`，`carry=0`。结果链 `[8,7,3]`，反转得 `[3,7,8]`。

```python
def reverse(node):
    prev = None
    while node:
        node.next, prev, node = prev, node, node.next
    return prev

rev = reverse(head)
dummy = tail = ListNode(0)
carry = 0
while rev:
    v = rev.val * 2 + carry
    tail.next = ListNode(v % 10)
    tail, carry, rev = tail.next, v // 10, rev.next
if carry:
    tail.next = ListNode(carry)
return reverse(dummy.next)
```

## 复杂度
时间 O(n)：反转两次各 n，乘法遍历一次 n。
空间 O(1)：只开了 `dummy`、`tail`、`carry` 和新建的 n 个结果节点（输出本身不计额外空间）。

## 易错点
- 输入 `[9,9,9]` → 若忘记遍历结束后补进位，会输出 `[9,9,8]` 而不是 `[1,9,9,8]`；正确做法是 `while` 结束后检查 `carry`，为 1 就 `tail.next = ListNode(1)`。
- 输入 `[5]` → 若直接在原链表上改 `node.val` 而不新建节点，反转后指针关系会被破坏，且首位进位无处安放；正确做法是用 `dummy` 挂新节点，原链表只读不改。

## 如果面试官追问
问：不允许反转链表怎么办？
答：用递归先走到尾再回溯乘 2，或先遍历一遍把节点压栈，效果等价但空间 O(n)。
