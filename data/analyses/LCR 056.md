## 一句话思路
中序遍历得到升序数组，再用双指针从两端夹逼，因为 BST 中序有序，两数之和才能单调收缩。

## 怎么做
1. 中序遍历 `root`，把节点值依次 append 进 `nums`，得到升序序列。
2. 设 `i = 0`、`j = len(nums) - 1`，循环 `while i < j`。
3. 算 `s = nums[i] + nums[j]`：`s == k` 返回 `True`；`s < k` 则 `i += 1`；`s > k` 则 `j -= 1`。
4. 循环结束返回 `False`。

以示例 1 为例，`root = [8,6,10,5,7,9,11]` 中序后 `nums = [5,6,7,8,9,10,11]`，`k = 12`。初始 `i=0, j=6`，`s = 5 + 11 = 16 > 12`，`j` 减到 5；`s = 5 + 10 = 15 > 12`，`j` 减到 4；`s = 5 + 9 = 14 > 12`，`j` 减到 3；`s = 5 + 8 = 13 > 12`，`j` 减到 2；`s = 5 + 7 = 12`，返回 `True`。关键中间值就是 `nums[0]=5` 固定不动、`j` 从 6 一路退到 2 才命中。

```python
def inorder(node, nums):
    if not node:
        return
    inorder(node.left, nums)
    nums.append(node.val)
    inorder(node.right, nums)

nums = []
inorder(root, nums)
i, j = 0, len(nums) - 1
while i < j:
    s = nums[i] + nums[j]
    if s == k:
        return True
    if s < k:
        i += 1
    else:
        j -= 1
return False
```

## 复杂度
时间 O(n)：中序遍历访问每个节点一次，双指针最多走 n 步。
空间 O(n)：`nums` 存 n 个值，递归栈最坏 O(n)（链状树）。

## 易错点
- 输入 `root = [2,1,3], k = 4`：若误用「先序 + 哈希」但把当前节点先塞进 set 再查 `k - val`，节点 2 会自己配自己（`2 + 2 = 4`）返回 `True`。正确做法是先查 `k - val` 是否已在 set 中，再插入 `val`，保证两节点不同。
- 输入 `root = [1], k = 2`：单节点树，双指针 `i < j` 直接不成立返回 `False`；若写成 `i <= j` 会让 `nums[0] + nums[0] = 2` 误判 `True`。边界必须严格 `i < j`。

## 如果面试官追问
问：要求空间 O(h)（h 为树高）怎么做？
答：用两个栈分别做正向和反向中序迭代器，各取当前最小/最大值，按 `s` 与 `k` 比较推进对应迭代器，栈深即树高。
