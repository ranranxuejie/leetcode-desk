## 一句话思路
用前序遍历，空节点写成 `#`，节点值之间用逗号分隔；因为空位也记下来了，反序列化时按同一顺序消费就能唯一还原。

## 怎么做
1. 序列化走前序 DFS，遇到 `None` 追加 `"#"`，否则追加 `str(node.val)`，再递归左右。
2. 反序列化把字符串 `split(",")` 成列表，用下标 `i` 顺序消费。
3. 取到 `"#"` 就返回 `None` 并让 `i` 前进；否则建节点、`i += 1`，再递归建左右。

以 `root = [1,2,3,null,null,4,5]` 为例，序列化结果是 `"1,2,#,#,3,4,#,#,5,#,#"`；反序列化读到第 3 个 token `"#"` 时，`2` 的左孩子确定为 `None`，`i` 从 2 走到 3。

```python
def ser(node):
    if not node:
        return "#"
    return f"{node.val},{ser(node.left)},{ser(node.right)}"

def de(tokens):
    val = tokens.pop(0)
    if val == "#":
        return None
    node = TreeNode(int(val))
    node.left = de(tokens)
    node.right = de(tokens)
    return node
```

`tokens.pop(0)` 是 O(n)，实际写用下标 `i` 或 `collections.deque` 的 `popleft()`。

## 复杂度
时间 O(n)：序列化和反序列化各访问每个节点一次，`#` 占位符共 n+1 个。
空间 O(n)：递归栈最坏 n 层（链状树），字符串和 token 列表各存 O(n)。

## 易错点
- 输入 `[1,2]`（只有左孩子）→ 若省略空节点只写 `"1,2"`，反序列化无法判断 `2` 是左还是右 → 必须把 `2` 的两个 `None` 都写成 `#`，得到 `"1,2,#,#,#"`。
- 输入 `[]` → 若序列化返回空串 `""`，`"".split(",")` 得到 `[""]`，反序列化会去 `int("")` 报错 → 空树也要输出 `"#"`，让 `split` 后是 `["#"]`。

## 如果面试官追问
问：节点数到 10^6、字符串很长怎么办？
答：改用 BFS 层序 + 定长二进制编码，避免递归栈溢出和逗号分隔的额外开销。
