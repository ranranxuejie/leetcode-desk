## 一句话思路
用总和减当前元素得到右侧和，边走边维护左侧和，第一个左右相等的位置就是答案。

## 怎么做
1. 先算 `total = sum(nums)`，把「右侧和」变成可 O(1) 求的量。
2. 令 `left = 0`，从左往右遍历 `i`。
3. 每个 `i` 上算 `right = total - left - nums[i]`，比较 `left == right`。
4. 相等就立即返回 `i`（保证最左）；否则 `left += nums[i]` 继续。

以 `nums = [2,3,-1,8,4]` 为例，`total = 16`。走到 `i = 3` 时 `left = 2+3-1 = 4`，`right = 16 - 4 - 8 = 4`，相等，返回 3。注意 `i = 0` 时 `left = 0`、`right = total - nums[0]`，天然覆盖左端边界，不需要特判。

```python
total = sum(nums)
left = 0
for i, x in enumerate(nums):
    right = total - left - x
    if left == right:
        return i
    left += x
return -1
```

关键点：`right` 里必须减掉 `nums[i]` 本身，因为题目比较的是 `i` 两侧，不含 `i`。

## 复杂度
时间 O(n)：一次求和加一次遍历，各扫 n 个元素。
空间 O(1)：只开了 `total`、`left`、`right` 三个标量。

## 易错点
- `nums = [1]` → 若把 `right` 写成 `total - left`，会得到 `right = 1`、`left = 0`，判不等返回 -1；正确是减掉 `nums[i]` 得 `right = 0`，返回 0。
- `nums = [1,-1,4]` → 若先 `left += x` 再比较，`i = 2` 时 `left` 已含 4 变成 4，与 `right = 0` 不等，漏掉答案；正确是先比较、后累加，返回 2。

## 如果面试官追问
问：数组很大且要返回所有中间位置怎么办？
答：把 `left` 和 `right` 存进两个前缀数组，一次遍历收集全部满足的下标，时间仍 O(n)，空间升到 O(n)。
