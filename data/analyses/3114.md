## 一句话思路
逐位贪心：HH 位优先取最大合法值，MM 位独立取 9 或 5，因为小时与分钟互不约束。

## 怎么做
1. 先处理 `s[0]`：若为 `?`，看 `s[1]` 是否为 `?` 或 ≤1，是则填 `1`，否则填 `0`。
2. 再处理 `s[1]`：若为 `?`，`s[0]` 已是 `1` 就填 `1`，否则填 `9`（上限 11）。
3. 处理 `s[3]`：为 `?` 直接填 `5`（分钟十位上限 5）。
4. 处理 `s[4]`：为 `?` 直接填 `9`（分钟个位上限 9）。

以 `s = "1?:?4"` 为例：`s[0]='1'` 不动；`s[1]='?'` 且 `s[0]=='1'`，填 `1`，HH 得 `"11"`；`s[3]='?'` 填 `5`；`s[4]='4'` 不动，结果 `"11:54"`。关键中间值是 `s[1]` 的判定依赖 `s[0]` 的最终值，所以第 1 步必须先落定 `s[0]`。

```python
def findLatestTime(s):
    t = list(s)
    if t[0] == '?':
        t[0] = '1' if t[1] == '?' or t[1] <= '1' else '0'
    if t[1] == '?':
        t[1] = '1' if t[0] == '1' else '9'
    if t[3] == '?':
        t[3] = '5'
    if t[4] == '?':
        t[4] = '9'
    return ''.join(t)
```

## 复杂度
时间：O(1)，固定 5 个字符各看一次，与输入规模无关。
空间：O(1)，只开了长度 5 的 `t` 列表。

## 易错点
- `s = "?3:00"` → 若先无脑把 `s[0]` 填 `1`，得 `"13:00"` 非法 → 正确做法是先看 `s[1]`：`'3' > '1'`，`s[0]` 只能填 `0`，结果 `"03:00"`。
- `s = "??:00"` → 若把 `s[1]` 也填 `9`，得 `"09:00"` 但漏了更晚的 `"11:00"` → 正确做法是 `s[0]` 填 `1` 后 `s[1]` 必须跟着填 `1`，两步有依赖顺序。

## 如果面试官追问
问：若改成 24 小时制 `"HH:MM"`（HH 取 00–23）怎么改？
答：`s[0]` 为 `?` 时看 `s[1]` 是否 ≤3 决定填 `2` 还是 `1`，`s[1]` 为 `?` 时 `s[0]=='2'` 填 `3` 否则填 `9`。
