## 一句话思路
每秒左移 k 位，恢复初始状态等价于找最小的 t 使 `word[t*k:]` 是 `word` 的前缀，用 Z 函数一次扫描。

## 怎么做
1. 观察：t 秒后原串剩余部分 `word[t*k:]` 被推到开头，后面补的字符可任意，所以只要这段是 `word` 的前缀就能补齐回原串。
2. 对 `word` 求 Z 数组，`z[i]` 表示 `word[i:]` 与 `word` 的最长公共前缀长度。
3. 从 `i = k, 2k, 3k, ...` 递增检查，第一个满足 `z[i] >= n - i` 的 `i` 即为答案，返回 `i // k`。
4. 若所有 i 都不满足，返回 `(n + k - 1) // k`（即 ceil(n/k)，此时剩余部分为空，必然恢复）。

以 `word = "abacaba", k = 3, n = 7` 为例：z 数组在 i=3 处 `z[3]=0`（`"caba"` 与 `"abacaba"` 首字符不同），`0 >= 7-3=4` 不成立；i=6 处 `z[6]=1`（`"a"` 匹配），`1 >= 7-6=1` 成立，返回 `6 // 3 = 2`，与示例一致。

```python
n = len(word)
z = [0] * n
l = r = 0
for i in range(1, n):
    if i < r:
        z[i] = min(r - i, z[i - l])
    while i + z[i] < n and word[z[i]] == word[i + z[i]]:
        z[i] += 1
    if i + z[i] > r:
        l, r = i, i + z[i]
for i in range(k, n, k):
    if z[i] >= n - i:
        return i // k
return (n + k - 1) // k
```

## 复杂度
时间 O(n)：Z 函数线性扫描，检查步长 k 的 i 共 n/k 个，总 O(n)。
空间 O(n)：z 数组长度 n，其余仅常数个指针。

## 易错点
- `word = "aaaa", k = 2`：若从 i=0 开始检查或漏掉 `i < n` 边界，会误判 t=0；正确做法是从 `i = k` 起、步长 k，且答案必须大于零。
- `word = "abacaba", k = 4`：若只检查 `z[i] == n - i` 而忽略 `z[i] >= n - i`，当剩余长度小于 k 时（如 i=4 剩 3 字符）会漏判；正确用 `>=`，因为补的字符可任意，前缀匹配够长即可。

## 如果面试官追问
若要求输出每秒添加的具体字符方案？答：对每个 t 找到的 i，把 `word[:i]` 补到剩余部分之后即可，即添加 `word[n-i:]` 的前 i 个字符。
