## 一句话思路
树上 DP：每个节点向父节点最多留 1 条边，向儿子最多留 k 条，用「选/不选父边」两套值做贪心取舍。

## 怎么做
1. 以 0 为根做一次 DFS，返回 `(dp0, dp1)`：`dp0` 表示不连父边时子树最大和，`dp1` 表示连父边时子树最大和（此时自身只剩 k-1 个名额给儿子）。
2. 对每个儿子 `v`，边权 `w`：不选这条边贡献 `dp0[v]`，选它贡献 `dp1[v] + w`，增益 `gain = dp1[v] + w - dp0[v]`。
3. 把所有 `gain > 0` 的降序排，`dp0[u] = base + sum(前 k 个)`，`dp1[u] = base + sum(前 k-1 个)`，`base = Σ dp0[v]`。
4. 答案就是 `dp0[0]`（根没有父边）。

用示例 1，根取 0：节点 2 的儿子 3、4 增益为 12、6，`dp0[2] = 18`；节点 0 的儿子 1、2 增益为 4、`18-0=18`，k=2 全取，得 `4+18=22`，与输出一致。

```python
def dfs(u, p):
    base, gains = 0, []
    for v, w in g[u]:
        if v == p: continue
        d0, d1 = dfs(v, u)
        base += d0
        gains.append(d1 + w - d0)
    gains.sort(reverse=True)
    pos = [x for x in gains if x > 0]
    dp0 = base + sum(pos[:k])
    dp1 = base + sum(pos[:k-1])
    return dp0, dp1
```

## 复杂度
时间 `O(n log n)`：n 个节点各排一次儿子增益，总排序量 O(n log n)。
空间 `O(n)`：邻接表 + 递归栈，深度最坏 n。

## 易错点
- 链状树 `0-1-2-...`，n=10^5 时递归深度爆栈 → 报 `RecursionError` → 改用显式栈做后序，或 `sys.setrecursionlimit(300000)` 并确认栈够。
- 忘记 `dp1` 只给 k-1 个名额：k=1 时若 `dp1` 也取前 1 个增益，节点会同时连父边和一个儿子，度数变 2 → 必须写 `pos[:k-1]`，k=1 时切片为空。

## 如果面试官追问
要求输出保留哪些边怎么办？答：DFS 时把选中的 `(u,v)` 记进集合，`dp0` 取前 k 个、`dp1` 取前 k-1 个时同步记录即可。
