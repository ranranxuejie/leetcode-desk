## 一句话思路
用 `dp[i][j]` 表示 `s[:i]` 能否被 `p[:j]` 匹配，按 `p[j-1]` 是否为 `*` 分两类转移。

## 怎么做
1. 建 `(m+1) x (n+1)` 的布尔表，`dp[0][0] = True`，`m=len(s)`、`n=len(p)`。
2. 先填 `i=0` 行：`p[j-1]=='*'` 时 `dp[0][j] = dp[0][j-2]`，因为 `x*` 可匹配空串。
3. 外层 `i` 从 1 到 `m`，内层 `j` 从 1 到 `n`；`p[j-1]` 不是 `*` 时看 `dp[i-1][j-1] and (s[i-1]==p[j-1] or p[j-1]=='.')`。
4. 是 `*` 时取两路或：`dp[i][j-2]`（星号匹配零次），或 `dp[i-1][j] and (s[i-1]==p[j-2] or p[j-2]=='.')`（星号再吃一个字符）。

以 `s="aa", p="a*"` 为例：`dp[0][2] = dp[0][0] = True`；`i=1,j=2` 时 `p[1]=='*'`，`dp[1][2] = dp[1][0] or (dp[0][2] and s[0]=='a') = False or True = True`；`i=2,j=2` 同理得 `True`，答案 `dp[2][2]`。

```python
m, n = len(s), len(p)
dp = [[False] * (n + 1) for _ in range(m + 1)]
dp[0][0] = True
for j in range(2, n + 1):
    if p[j - 1] == '*':
        dp[0][j] = dp[0][j - 2]
for i in range(1, m + 1):
    for j in range(1, n + 1):
        if p[j - 1] == '*':
            dp[i][j] = dp[i][j - 2] or (
                dp[i - 1][j] and (s[i - 1] == p[j - 2] or p[j - 2] == '.'))
        elif s[i - 1] == p[j - 1] or p[j - 1] == '.':
            dp[i][j] = dp[i - 1][j - 1]
```

## 复杂度
时间：`O(m*n)`，`i`、`j` 各扫一遍，每格 O(1) 转移。
空间：`O(m*n)` 的 `dp` 表；可压成一维 `O(n)`，但 `dp[i-1][j]` 需保留旧值。

## 易错点
1. `s="a", p="a*"` → 若漏掉 `dp[0][j] = dp[0][j-2]` 的初始化，`dp[1][2]` 会算成 `False`；正确做法是先把第 0 行按 `*` 递推填好，让 `a*` 能匹配空串。
2. `s="ab", p=".*c"` → 若把 `*` 的零次分支写成 `dp[i][j-1]` 而非 `dp[i][j-2]`，会把 `*` 当成独立字符，`.*` 无法整体跳过；正确做法是零次分支固定回退两列到 `dp[i][j-2]`。

## 如果面试官追问
问：`s` 长度到 10^4 怎么办？答：这题状态数 `O(m*n)` 无法避免，需换 NFA/双指针回溯加记忆化，或说明正则匹配本身是 O(mn) 下界。
