## 一句话思路
从右往左扫 nums2，用单调递减栈维护「右侧候选更大值」，栈顶就是每个元素的下一个更大元素，结果存进哈希表供 nums1 查。

## 怎么做
1. 建空栈 `st` 和空字典 `nxt`，倒序遍历 `nums2`。
2. 每到一个 `x`，先 `while st and st[-1] <= x: st.pop()` 弹掉不可能成为答案的元素。
3. 弹完后 `nxt[x] = st[-1] if st else -1`，再把 `x` 压栈。
4. 最后按 `nums1` 顺序取 `nxt[v]` 拼成答案。

以 `nums2 = [1,3,4,2]` 为例：处理 `2` 时栈空，`nxt[2] = -1`，栈变 `[2]`；处理 `4` 时 `2 <= 4` 被弹出，栈空，`nxt[4] = -1`，栈变 `[4]`；处理 `3` 时栈顶 `4 > 3`，`nxt[3] = 4`，栈变 `[4,3]`；处理 `1` 时栈顶 `3 > 1`，`nxt[1] = 3`。查表得 `[-1,3,-1]`。

```python
st, nxt = [], {}
for x in reversed(nums2):
    while st and st[-1] <= x:
        st.pop()
    nxt[x] = st[-1] if st else -1
    st.append(x)
return [nxt[v] for v in nums1]
```

关键点：栈里存的是「还没找到更大值的元素」，且从栈底到栈顶严格递减，所以栈顶天然是最近的那个更大值。

## 复杂度
时间：O(len(nums2) + len(nums1))，每个元素进出栈各一次，查表 O(1)。
空间：O(len(nums2))，栈最多存全部元素，`nxt` 字典存 len(nums2) 个键值对。

## 易错点
- 写成 `st[-1] < x` 而不是 `<= x`：本题元素互不相同，两种写法结果一样，但换成有重复的变体（如「下一个更大或相等」）就会漏弹，栈里残留等值元素导致答案错位。统一用 `<=` 更稳。
- 正序遍历 nums2 想直接填答案：遇到 `[1,3,4,2]` 的 `1` 时你还不知道右边有没有更大值，只能先记「待定」，容易写成对每个 nums1 元素二次扫描 nums2，退化成 O(m·n)。正确做法是倒序 + 栈，一次扫完。

## 如果面试官追问
问：nums2 长度到 10^5 且允许重复元素怎么办？
答：栈里改存下标而非值，比较用 `nums2[st[-1]]`，弹栈条件按「严格大于」还是「大于等于」按题意定，哈希表键改成下标映射。
