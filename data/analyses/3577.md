## 一句话思路
对每个 i≥1，统计前面有多少个 j 满足 `complexity[j] < complexity[i]`，答案就是这些计数的乘积（有 0 则整体为 0）。

## 怎么做
1. 先判可行性：若存在 i≥1 使 `complexity[i] <= complexity[0]`，则 i 永远无法解锁，直接返回 0。
2. 对每个 i 从 1 到 n-1，数出 `cnt[i] = #{j < i : complexity[j] < complexity[i]}`。
3. 答案 = `cnt[1] * cnt[2] * ... * cnt[n-1] mod 10**9+7`。

以 `complexity = [1,2,3]` 为例：i=1 时前面只有 j=0，`1 < 2` 成立，cnt=1；i=2 时 j=0、1 都满足 `1<3`、`2<3`，cnt=2；乘积 `1*2 = 2`，与输出一致。

为什么是乘积：解锁顺序中，i 必须排在某个"能解锁它的 j"之后，而所有比 i 小的 j 中满足条件的那些，在排列里谁先谁后都行——i 只需落在"至少一个合法 j 已出现"的位置。逐位独立计数相乘即得。

```python
MOD = 10**9 + 7
n = len(complexity)
ans = 1
for i in range(1, n):
    cnt = 0
    for j in range(i):
        if complexity[j] < complexity[i]:
            cnt += 1
    if cnt == 0:
        return 0
    ans = ans * cnt % MOD
return ans
```

上面是 O(n²) 直译。n 到 10^5 时需换成"按值排序 + 树状数组/有序结构"统计前缀个数，或观察到只需维护已见元素中比当前小的个数：把 `(complexity[i], i)` 按值升序、值相同按 i 升序处理，用树状数组查下标 < i 的已插入个数。

## 复杂度
时间：O(n log n)，排序与树状数组各贡献一个 log n，n 来自遍历。
空间：O(n)，树状数组与排序后的下标数组。

## 易错点
- 输入 `[3,3,3,4,4,4]` → 若只判 `complexity[i] <= complexity[0]` 就返回 0，会漏掉 i=3 处 `4 > 3` 但前面三个 3 都不小于 4 的情况；正确做法是对每个 i 单独算 cnt，cnt=0 即返回 0。
- 输入 `[1,2,3]` 且用 O(n²) 直译 → n=10^5 时超时；正确做法是换成树状数组按值排序统计，别在双重循环里硬扛。

## 如果面试官追问
要求输出所有合法排列而非计数？答：计数是乘积，枚举则需按 cnt 做回溯，规模大时不可行，只能给计数。
