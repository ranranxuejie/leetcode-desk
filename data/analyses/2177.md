## 一句话思路
设中间数为 `x`，三数和恒为 `3x`，故 `num % 3 == 0` 时返回 `[num//3-1, num//3, num//3+1]`，否则空数组。

## 怎么做
1. 先判 `num % 3 != 0`，直接返回 `[]`，因为 `3x` 必是 3 的倍数。
2. 令 `x = num // 3`，这是三个连续整数的中间那个。
3. 返回 `[x - 1, x, x + 1]`，用 Python 整数，`num` 到 `10**15` 也不会溢出。

以 `num = 33` 为例：`33 % 3 == 0`，`x = 33 // 3 = 11`，结果 `[10, 11, 12]`，验证 `10+11+12 = 33`。以 `num = 4` 为例：`4 % 3 == 1`，直接返回 `[]`，因为 `3x = 4` 无整数解。

```python
def sumOfThree(num):
    if num % 3 != 0:
        return []
    x = num // 3
    return [x - 1, x, x + 1]
```

关键点：不要用循环枚举起点，`num` 上限 `10**15`，枚举会超时；直接由 `3x = num` 反解 `x` 是 O(1)。

## 复杂度
时间：O(1)，只做一次取模和一次整除，与 `num` 大小无关。
空间：O(1)，除返回的三元素列表外不额外开数组。

## 易错点
- `num = 0` → 若误判 `0` 不能表示而返回 `[]`，会错；正确做法是 `0 % 3 == 0`，`x = 0`，返回 `[-1, 0, 1]`，和为 0，符合题意。
- `num = 10**15` → 若用 C++/Java 的 32 位 `int` 存 `num` 或 `x` 会溢出，答案被截断；Python 整数无此问题，但若移植到其他语言需用 `long`，本题按 32 位截断的约束不适用于 Python 实现。

## 如果面试官追问
问：若要求返回所有可能的三个连续整数方案（不限于一组）？
答：三数和为 `3x` 只有唯一中间数，方案至多一组，仍是判 `num % 3` 后反解 `x`。
