## 一句话思路
n≤40 且异或值域小，用「前 i 个数凑出异或 x 的最少删除数」做 DP，答案取 dp[n][target]。

## 怎么做
1. 先算全部元素的异或和 `total`；若 `total == target`，直接返回 0（示例 3 的 `[7]` 就是这种）。
2. 定义 `dp[x]` = 用已扫过的元素凑出异或和 x 所需的最少删除次数，初始 `dp = {0: 0}`，其余不可达。
3. 对每个 `v in nums` 倒序更新：保留 v 时新异或为 `x ^ v`，删除 v 时次数 +1，两者取小。
4. 扫完看 `dp.get(target, -1)`。

以示例 1 `nums = [1,2,3], target = 2` 为例：`total = 1^2^3 = 0`，不等于 2，进入 DP。处理完 1、2 后，`dp` 中已有 `{0:0, 1:1, 2:1, 3:2}`；再处理 3 时，`x = 1` 保留 3 得 `1^3 = 2`，次数仍为 1，于是 `dp[2] = 1`，返回 1。

```python
total = 0
for v in nums:
    total ^= v
if total == target:
    return 0
INF = len(nums) + 1
dp = {0: 0}
for v in nums:
    ndp = dict(dp)
    for x, c in dp.items():
        y = x ^ v
        if c + 1 < ndp.get(y, INF):
            ndp[y] = c + 1
    dp = ndp
return dp.get(target, -1)
```

注意这里 `dp` 用字典而非定长数组：`nums[i] ≤ 10^4`，异或值不超过 `2**14 - 1`，但字典写法不必纠结上界，且天然跳过不可达状态。

## 复杂度
时间 O(n · 2^14)，n 来自元素个数，2^14 来自异或值域上界。
空间 O(2^14)，字典最多存这么多可达异或值。

## 易错点
- `nums = [2,4], target = 1`：若只判断 `total != target` 就返回 -1，会漏掉「删部分元素能凑出」的情况；必须先跑完 DP 再取 `dp.get(target, -1)`。
- `nums = [1,2,3], target = 0`：空数组异或为 0，但删光要 3 次；而 `total = 0` 时直接返回 0 才是最优，别把「空数组」当成唯一凑 0 的方式。

## 如果面试官追问
问：n 放大到 10^5 怎么办？
答：值域只有 2^14，DP 状态数不变，时间仍是 O(n · 2^14)，瓶颈在 n 次遍历，可接受；若值域也放大则需线性基。
