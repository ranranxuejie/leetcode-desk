## 一句话思路
对答案长度 L 二分，用滚动哈希把每条路径的 L 长子串压成集合，判断所有集合是否有交集。

## 怎么做
1. 二分下界 lo=0、上界 hi=min(len(p) for p in paths)，因为公共子路径不可能比最短路径还长。
2. 对给定 L，先算 base 的 L 次幂 `pw`，再对每条路径用 `h = h*base + x` 滑窗，每步减去 `paths[i][j-L]*pw`，得到该路径所有 L 长子串的哈希集合。
3. 从第一条路径的集合出发，与后续每条路径的集合取交集，交集非空则 L 可行。
4. 以示例 1 的 L=2 为例：paths[0] 得 {h(0,1),h(1,2),h(2,3),h(3,4)}，paths[1] 得 {h(2,3),h(3,4)}，paths[2] 得 {h(4,0),h(0,1),h(1,2),h(2,3)}，三者交集含 h(2,3)，故 L=2 可行。

```python
def ok(L):
    base, mod = 131, 2**61 - 1
    pw = pow(base, L, mod)
    common = None
    for p in paths:
        if len(p) < L: return False
        h = 0
        for x in p[:L]: h = (h * base + x) % mod
        s = {h}
        for j in range(L, len(p)):
            h = (h * base - p[j-L] * pw + p[j]) % mod
            s.add(h)
        common = s if common is None else (common & s)
        if not common: return False
    return True
```

## 复杂度
时间：二分 log(minLen) 层，每层扫全部城市 O(sum(len))，共 O(sum(len)·log(minLen))。
空间：每层为一条路径开哈希集合，最坏 O(max(len))。

## 易错点
- 单哈希在 sum(len) 达 1e5 量级时，模 2**61-1 仍可能被构造碰撞，导致把不存在的公共子路径判为存在；应改用双哈希（两个不同 base/mod）或对候选哈希回查实际子串。
- 二分上界若取 max(len) 而非 min(len)，当某条路径极短时会在该路径上反复返回 False，浪费 log 层；正确做法是 `hi = min(map(len, paths))`，且 L=0 时直接返回 0 避免空串被误判为公共。

## 如果面试官追问
要求输出具体子路径而非长度怎么办？
答：二分收敛后，用第一条路径的哈希表反查该哈希对应的起始下标，取 `paths[0][i:i+L]` 即为答案。
