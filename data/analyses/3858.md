## 一句话思路
从高位到低位逐位贪心：能通过每行选一个数把该位压成 0 就压，用 `mask` 记录已确定必须为 1 的位。

## 怎么做
1. 设 `ans = 0`，从第 17 位（`2**17 > 10**5`）往下扫到第 0 位。
2. 对当前位 `b`，尝试令 `cand = ans | ((1 << b) - 1)`，即「高位保持已定的 1，当前位及以下全放 0」。
3. 检查每一行是否存在某个 `x` 满足 `(x | cand) == cand`，即 `x` 的 1 位全被 `cand` 覆盖；只要有一行不存在，当前位就必须是 1，`ans |= 1 << b`。
4. 全部位扫完，`ans` 即答案。

以 `grid = [[1,5],[2,4]]` 为例：第 1 位时 `ans = 0`，`cand = 1`；第一行 `1|1==1` 成立，第二行 `2|1=3 != 1`、`4|1=5 != 1`，都不成立，故第 1 位必须为 1，`ans = 2`。第 0 位 `cand = 3`：第一行 `1|3==3`，第二行 `2|3==3`，都成立，第 0 位留 0，最终 `ans = 3`。

```python
ans = 0
for b in range(17, -1, -1):
    cand = ans | ((1 << b) - 1)
    ok = True
    for row in grid:
        if not any((x | cand) == cand for x in row):
            ok = False
            break
    if not ok:
        ans |= 1 << b
return ans
```

关键点：`cand` 里当前位是 0，所以「某行存在 `x` 被 `cand` 覆盖」等价于「这一位可以不放 1」。贪心成立是因为高位一旦确定为 1，任何更小的低位组合都无法弥补，逐位决策互不干扰。

## 复杂度
时间：`O(18 * m * n)`，每行每元素被扫 18 次，`m*n <= 10^5`。
空间：`O(1)`，只开 `ans`、`cand`、`ok` 几个标量。

## 易错点
- 位上限取错：`grid[i][j] <= 10**5 < 2**17`，若只扫到第 16 位，输入 `[[100000]]` 会漏掉第 17 位的 1，答案偏小；应从 `range(17, -1, -1)` 起扫。
- 判定条件写成 `(x & cand) == x` 之外的形式：若误写成 `(x | cand) == x` 的反面或 `x & cand != 0`，`grid = [[3,5],[6,4]]` 第 2 位会误判可压成 0；正确是 `(x | cand) == cand`，即 `x` 的 1 位是 `cand` 的子集。

## 如果面试官追问
要求输出每行具体选了哪个数怎么办？答：贪心定下 `ans` 后，每行取第一个满足 `(x | ans) == ans` 的 `x` 即可，因为 `ans` 已是最小可行上界。
