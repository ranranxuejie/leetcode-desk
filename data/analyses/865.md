## 一句话思路
后序 DFS 返回 `(最深深度, 该子树答案)`，左右深度相等时当前节点就是最小子树。

## 怎么做
1. 定义 `dfs(node)` 返回 `(depth, ans)`：`depth` 是 `node` 子树内的最大深度，`ans` 是覆盖该子树全部最深节点的最小子树根。
2. 空节点返回 `(0, None)`；叶子返回 `(1, node)`。
3. 递归拿到 `(ld, la)` 和 `(rd, ra)` 后，按深度比较决定 `ans`。
4. 关键中间值：示例 1 中节点 2 的左右子 7、4 都返回 `(1, 自己)`，故节点 2 返回 `(2, 节点2)`；节点 5 左子 6 返回 `(1,6)`、右子 2 返回 `(2,2)`，右更深，节点 5 返回 `(3, 节点2)`；根 3 右子 1 返回 `(2,8)`，左 `(3,2)` 更深，最终返回节点 2。

```python
def dfs(node):
    if not node:
        return 0, None
    ld, la = dfs(node.left)
    rd, ra = dfs(node.right)
    if ld > rd:
        return ld + 1, la
    if rd > ld:
        return rd + 1, ra
    return ld + 1, node   # 左右同深，node 才是最小
```

## 复杂度
时间 O(n)：每个节点访问一次，n 为节点数。
空间 O(h)：递归栈深度 h，最坏链状为 n，未额外开哈希表。

## 易错点
- 输入 `[0,1,3,null,2]`：若只比较左右子树深度而忽略「只有一侧有最深节点」，会在节点 1 处误返回 1；正确做法是 `ld > rd` 时直接返回 `la`，让节点 2 一路传上去。
- 输入 `[1]`：若把空节点深度记成 1 或把叶子判成 `ld == rd == 0` 就返回 `None`，会输出空；正确做法是空节点返回 `(0, None)`，叶子因左右都 0 而返回 `(1, node)`。

## 如果面试官追问
问：不用递归、改成 BFS 行不行？答：先 BFS 求最大深度并记下该层所有节点，再自底向上找它们的最近公共祖先，时间仍 O(n)，但要多存一层节点。
