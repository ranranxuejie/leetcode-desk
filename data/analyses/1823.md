## 一句话思路
用约瑟夫环递推 `f(i) = (f(i-1) + k) % i`，从 1 人规模倒推到 n 人，O(n) 时间 O(1) 空间。

## 怎么做
1. 定义 `f(i)` 为「i 人围成圈、从编号 0 开始数」时幸存者的 0-based 编号，`f(1) = 0`。
2. 每轮删掉第 `k` 个人后，剩下 `i-1` 人重新从被删者的下一位开始编号，所以规模 `i` 的答案等于规模 `i-1` 的答案整体偏移 `k` 位：`f(i) = (f(i-1) + k) % i`。
3. 从 `i = 2` 循环到 `n`，最后 `f(n)` 是 0-based，加 1 转成题目要求的 1-based 编号。

拿 `n = 5, k = 2` 走一遍：`f(1)=0`；`f(2)=(0+2)%2=0`；`f(3)=(0+2)%3=2`；`f(4)=(2+2)%4=0`；`f(5)=(0+2)%5=2`，加 1 得 3，与示例一致。关键中间值是 `f(3)=2`——它说明 3 人时幸存者 0-based 编号是 2，后面两步都基于它偏移。

```python
def findTheWinner(n, k):
    pos = 0                      # f(1)
    for i in range(2, n + 1):
        pos = (pos + k) % i      # f(i)
    return pos + 1               # 转 1-based
```

模拟法（队列）也能过，因为 `n <= 500`：把 `1..n` 放进 `collections.deque`，每轮 `rotate(-(k-1))` 后 `popleft()`，剩一个就是答案。但递推法才是进阶要求的线性时间常数空间。

## 复杂度
时间 O(n)：循环 `i` 从 2 到 n 共 n-1 次，每次一次取模。
空间 O(1)：只存 `pos` 一个整数，没有队列或数组。

## 易错点
- `k = 1` 时 → 若写成 `(pos + k - 1) % i` 会整体错位，`n=5,k=1` 应输出 5 却得 4 → 递推式里偏移量就是 `k`，不要减 1，减 1 只出现在「先定位再删除」的模拟写法里。
- `n = 1` 时 → 若循环写成 `range(1, n+1)` 会把 `f(1)` 再算一遍得 `(0+k)%1=0`，虽然结果碰巧对，但 `k` 参与取模的语义已错 → 循环必须从 `i = 2` 开始，`n=1` 直接返回 `pos+1 = 1`。

## 如果面试官追问
问：要求输出每轮被淘汰者的编号序列怎么办？
答：递推只给幸存者，需改用队列模拟，每轮 `rotate(-(k-1))` 后 `popleft()` 记录，时间 O(nk) 最坏。
