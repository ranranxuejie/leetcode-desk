## 一句话思路
只有基因值 1 所在的那条祖先链答案可能大于 1，其余节点答案恒为 1，沿链自底向上增量维护缺失值。

## 怎么做
1. 先找 `nums` 中值为 1 的节点 `cur`；若不存在，全部答案为 1，直接返回。
2. 从 `cur` 沿 `parents` 走到根，把这条链上的节点记入 `path`（顺序为底→顶），链外节点答案填 1。
3. 自底向上遍历 `path`，每到一个节点就把它的整棵子树（用迭代 DFS 收集）的 `nums` 值塞进 `seen` 集合，然后 `while seen[mex]: mex += 1`。
4. 把当前 `mex` 写入 `ans[node]`；因为父节点子树包含子节点子树，`mex` 只增不减，无需回退。

以示例 2 为例：`nums = [5,4,6,2,1,3]`，值为 1 的节点是 4，链为 `4→3→0`。处理节点 4 时 `seen={1}`，`mex` 从 1 涨到 2，`ans[4]=2`；处理节点 3 时并入 `{2,3}`，`seen={1,2,3}`，`mex` 涨到 4，`ans[3]=4`；处理节点 0 时并入 `{5,4,6}`，`seen={1,2,3,4,5,6}`，`mex=7`，`ans[0]=7`。链外节点 1、2、5 直接为 1。

```python
cur = nums.index(1) if 1 in nums else -1
ans = [1] * n
if cur == -1:
    return ans
path, x = [], cur
while x != -1:
    path.append(x)
    x = parents[x]
seen, mex = set(), 1
for node in path:                      # 底 → 顶
    stack = [node]
    while stack:
        u = stack.pop()
        seen.add(nums[u])
        stack.extend(children[u])
    while mex in seen:
        mex += 1
    ans[node] = mex
return ans
```

## 复杂度
时间：每个节点只被 DFS 收集一次，`mex` 单调递增到 n+1，总 O(n)。
空间：`children` 邻接表 O(n)，`seen` 最多 O(n)，递归栈改迭代避免爆栈。

## 易错点
- 若 `nums` 中没有 1（如 `nums=[2,3]`），链不存在，此时若仍去找 `index(1)` 会抛 `ValueError`；正确做法是先判断，直接返回全 1 数组。
- 链外节点误算：如示例 1 中节点 1 的子树只有 `{2}`，缺失值是 1 而非 2；只有链上节点才需要跑 `seen`/`mex`，其余位置必须保持初值 1，不能统一按子树重算。

## 如果面试官追问
若 `nums` 允许重复，思路还成立吗？答：不成立，`seen` 是集合会丢重数，且「只有含 1 的链」这一前提依赖值互不相同，需改回对每棵子树做 DSU on tree。
