## 一句话思路
参数在 Python 里以元组 `args` 传入，直接取 `len(args)` 就是参数个数，无需遍历。

## 怎么做
1. 函数签名 `argumentsLength(args)` 中的 `args` 已经是把所有实参打包成的元组，长度即个数。
2. 直接返回 `len(args)`，不做任何类型判断或循环。
3. 用示例 2 验证：调用 `argumentsLength({}, None, "3")` 时，`args` 的值为 `({}, None, '3')`，`len(args)` 得 3，与输出一致。
4. 边界 `args = ()` 时 `len(args)` 为 0，符合 `0 <= args.length` 的提示。

```python
def argumentsLength(args):
    return len(args)

print(argumentsLength(5))                 # 1
print(argumentsLength({}, None, "3"))     # 3
print(argumentsLength())                  # 0
```

关键中间值：示例 2 里 `args` 不是列表 `[{}, None, "3"]`，而是元组 `({}, None, '3')`，两者 `len` 都是 3，但别误以为要处理列表元素。

## 复杂度
时间：O(1)，`len` 读元组的已存长度，与参数个数 n 无关。
空间：O(1)，不额外开容器，元组本身由调用方创建。

## 易错点
- 把 `args` 当成题目里的 JSON 数组去遍历计数 → 写成 `sum(1 for _ in args)`，虽然结果对但多此一举，且对 `None` 元素做判断时容易误判 → 正确做法是直接 `len(args)`。
- 误以为要处理 `args = [{}]` 这种「列表套一个字典」的输入 → 实际调用 `argumentsLength({})` 时 `args` 是 `({},)`，长度 1；若按列表元素再展开会错成 0 或报错 → 认准 `args` 是元组，`len` 一次到位。

## 如果面试官追问
问：如果要求不能用 `len` 呢？
答：用 `for _ in args: count += 1` 手动计数，时间 O(n)，其余不变。
