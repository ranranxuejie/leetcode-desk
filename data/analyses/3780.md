## 一句话思路
按模 3 把数分三桶并各取最大的三个，枚举三种合法余数组合取最大和。

## 怎么做
1. 把 `nums` 按 `x % 3` 分进 `b0`、`b1`、`b2` 三个桶，每桶降序排序后只保留前 3 个。
2. 合法组合只有三种：`(0,0,0)`、`(1,1,1)`、`(2,2,2)`、`(0,1,2)`——即三个同余或三个余数各一个。
3. 对每种组合检查桶里够不够数，够就求和，取最大值；一个都不成立返回 0。

以 `nums = [4,2,3,1]` 为例：`b0 = [3]`，`b1 = [4,1]`，`b2 = [2]`。`(0,1,2)` 取 `3+4+2 = 9`，其余组合桶内数量不足，答案 9。

```python
b = [[], [], []]
for x in nums:
    b[x % 3].append(x)
for i in range(3):
    b[i] = sorted(b[i], reverse=True)[:3]

ans = 0
for i in range(3):
    if len(b[i]) >= 3:
        ans = max(ans, sum(b[i]))
if b[0] and b[1] and b[2]:
    ans = max(ans, b[0][0] + b[1][0] + b[2][0])
return ans
```

关键点：每桶只需前 3 个，因为任何合法组合对同一余数最多取 3 个数，第 4 大的数永远进不了最优解。

## 复杂度
时间 O(n + 3·3log3)，n 来自遍历分桶，排序只排每桶前 3 个。
空间 O(1) 额外，三个桶各存至多 3 个元素。

## 易错点
- 输入 `nums = [3,3,3,1,1]` → 若只取每桶最大值而不保留前三个，`(0,0,0)` 会漏算 `3+3+3=9` → 每桶必须留前 3 个。
- 输入 `nums = [2,1,5]` → 若忘记 `(0,1,2)` 组合或桶空判断写成 `len(b[i]) > 0` 却直接索引 `b[i][2]` → 会越界或返回错误值 → 组合前先检查三个桶都非空，否则返回 0。

## 如果面试官追问
问：如果要求返回具体三元组下标而不是和？
答：每桶存 `(值, 下标)` 对，排序后取前 3，组合时把对应下标拼出来即可，逻辑不变。
