## 一句话思路
区间 DP：`dp[i][j][c]` 表示把 s[i..j] 变成以字符 c 为两端的最长回文子序列长度，配对时按循环距离扣 k。

## 怎么做
1. 定义 `dp[i][j][c]`：在 s[i..j] 内、两端字符都改成 c 时能凑出的最长回文长度；`i > j` 时为 0，单字符时为 1。
2. 转移只考虑 s[i] 和 s[j]：要么丢掉 i，要么丢掉 j，要么把两者都改成同一个 c 并配对。
3. 配对代价是循环距离 `d = min(|a-c|, 26-|a-c|)`，两端各付一次，所以要求 `2*d <= 剩余 k`。
4. 答案取 `dp[0][n-1][c]` 对所有 c 的最大值。

以 `s = "abced", k = 2` 为例：i=1 的 `'b'` 与 i=4 的 `'e'` 都改成 `'c'`，`d('b','c')=1`、`d('e','c')=2`，合计 3 > 2，不能直接配；但 `'b'` 改 `'c'` 花 1，`'e'` 改 `'c'` 花 2 超了，实际是 `'e'` 改 `'c'` 走 `e→d→c` 两步——所以示例里先把 `'e'` 改成 `'c'` 只用了 1 步（`e→d` 再 `d→c` 是 2 步，示例用的是 `'e'→'c'` 反向 2 步？注意示例实际把 s[4] 改成 `'c'` 后得到 `"accec"`，`'e'` 到 `'c'` 距离 2，加上 `'b'→'c'` 的 1 共 3 > 2，故示例真正配的是 `'c'`(i=2) 与 `'c'`(i=4)，`'b'` 被丢弃）。关键中间值：`dp[2][4]['c'] = 2`（s[2]='c' 与 s[4]='e'→'c' 花 2 步），再并上 s[1]='b'→'c' 花 1 步已无预算，最终长度 3。

```python
def dist(a, b):
    d = abs(ord(a) - ord(b))
    return min(d, 26 - d)

# dp[i][j][c] 用滚动/记忆化均可，这里写转移核心
for c in range(26):
    cost = dist(s[i], chr(c + 97)) + dist(s[j], chr(c + 97))
    if cost <= k:
        best = max(best, dp[i+1][j-1][c] + 2)
best = max(best, dp[i+1][j][c], dp[i][j-1][c])
```

## 复杂度
时间：O(n² · 26 · 26)，n=200 时约 2.7e7，区间对 × 目标字符 × 配对字符。
空间：O(n² · 26)，即 200×200×26 的 DP 表，约 1e6 个 int。

## 易错点
- 距离用 `abs(ord(a)-ord(b))` 而非循环距离 → 对 `s="az"` 会算成 25 而非 1，k=1 时错判不能配对；必须 `min(d, 26-d)`。
- 配对时只扣一端代价 → `s="abced", k=2` 会把 `'b'`、`'e'` 都改成 `'c'` 认为花 2 步得长度 3，实际两端各付，正确是 3 步超预算；要 `dist(s[i],c)+dist(s[j],c) <= k`。

## 如果面试官追问
问：k 很大（如 1e9）怎么办？答：k ≥ 26·n/2 时任意字符都能配对，答案退化为 n 的奇偶性判断，直接返回 n。
