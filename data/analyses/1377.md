## 一句话思路
从 1 出发 DFS，沿路径把每层「可选子节点数」的倒数连乘，到 target 时按剩余时间判断是否停住。

## 怎么做
1. 用 `edges` 建邻接表 `g`，DFS 时传 `parent` 防止走回头路，`p` 累积概率。
2. 进入节点 `u` 时，先算 `children = [v for v in g[u] if v != parent]`，若 `u == target` 就按 `len(children)` 和 `t` 结算。
3. 结算规则：`u == target` 时，若 `len(children) == 0`（叶子）则只要 `t >= 0` 就返回 `p`（原地停留）；否则必须 `t == 0` 才返回 `p`，`t > 0` 说明青蛙已跳走，返回 0。
4. 否则若 `t == 0` 直接返回 0，否则对每个子节点递归 `p / len(children)`、`t - 1`。

以示例 1 为例：`n=7, t=2, target=4`。到 1 时 `children=[2,3,7]`，`p=1/3` 进 2；到 2 时 `children=[4,6]`，`p=1/3/2=1/6` 进 4；到 4 时 `children=[]` 且 `t=0`，返回 `1/6`。

```python
def dfs(u, parent, t, p):
    children = [v for v in g[u] if v != parent]
    if u == target:
        if not children:
            return p
        return p if t == 0 else 0.0
    if t == 0:
        return 0.0
    return sum(dfs(v, u, t - 1, p / len(children)) for v in children)
```

注意 `target == 1` 时根节点也要走同一套结算逻辑，不能直接返回 1。

## 复杂度
时间 O(n)：每个节点最多被访问一次，`children` 列表总长 2(n-1)。
空间 O(n)：邻接表存 2(n-1) 条边，递归栈深最多 n。

## 易错点
- 输入 `n=1, edges=[], t=5, target=1` → 若只写「`t==0` 才返回 `p`」会错成 0 → 根无子节点应视为叶子，`t>=0` 都返回 1.0。
- 输入 `target` 是内部节点且 `t` 大于到达它的深度，如示例 1 改 `t=3, target=4` → 若忽略「到 target 后还能不能停」会错成 1/6 → 4 是叶子会原地停留，正确答案仍是 1/6；但若 `target=2, t=3`，2 有子节点，青蛙第 3 秒已跳走，必须返回 0。

## 如果面试官追问
问：若 `t` 很大（如 10^9）怎么办？
答：树深最多 n，`t` 超过深度后只有叶子能停留，先算深度再判 `t` 与深度关系即可，无需模拟。
