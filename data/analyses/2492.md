## 一句话思路
答案等于「只保留距离 ≥ x 的边时 1 与 n 是否连通」的最大可行 x，用并查集从大到小加边，首次连通时的边权即答案。

## 怎么做
1. 把 `roads` 按 `distance` 降序排序，初始化 `parent = list(range(n+1))`。
2. 依次取出每条边 `[a, b, d]`，`union(a, b)`，然后检查 `find(1) == find(n)`。
3. 第一次成立时立刻返回 `d`，因为此时所有已加入的边权都 ≥ d，路径上最小边权就是 d。

以示例 1 为例：排序后边序为 `(1,2,9), (1,4,7), (2,3,6), (2,4,5)`。加入 9 后 1 与 4 不连通；加入 7 后仍不连通（1 的集合 {1,2}，4 的集合 {1,4} 尚未合并，`find(1)=1`、`find(4)=4`）；加入 5 时 `union(2,4)` 把两个集合合并，`find(1)==find(4)` 成立，返回 5。

```python
def minScore(n, roads):
    parent = list(range(n + 1))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    roads.sort(key=lambda e: -e[2])
    for a, b, d in roads:
        ra, rb = find(a), find(b)
        if ra != rb:
            parent[ra] = rb
        if find(1) == find(n):
            return d
```

## 复杂度
时间：排序 O(m log m)，并查集 O(m α(n))，m = len(roads)。
空间：`parent` 数组 O(n)，排序额外 O(log m) 栈。

## 易错点
- 输入 `n=4, roads=[[1,2,9],[2,3,6],[2,4,5],[1,4,7]]`：若按升序加边，第一次连通时返回的是 5 但中间可能先返回 6 或 7，得到错误答案。必须降序，且**每加一条边就判一次连通**，不能等全部加完。
- 输入 `n=4, roads=[[1,2,2],[1,3,4],[3,4,7]]`：若只沿简单路径搜索（不允许重复走边），会漏掉 `1->2->1->3->4` 这条分数为 2 的路径，误答 4。并查集天然允许重复经过，不受此限。

## 如果面试官追问
问：要求输出这条最优路径的具体城市序列怎么办？
答：并查集只给分数，需改回按边权降序加边后，在「边权 ≥ 答案」的子图上从 1 做一次 BFS 到 n，记录前驱还原路径。
