## 一句话思路
count 只有 256 项，直接扫一遍累加总数、总和、众数，再二次扫描定位中位数下标。

## 怎么做
1. 一次遍历 `count`，累加 `total = sum(count)`、`s = sum(k*count[k])`，同时记录 `minimum`（第一个 count>0 的 k）、`maximum`（最后一个）、`mode`（count[k] 最大者）。
2. 均值 `mean = s / total`，注意用浮点除。
3. 中位数按下标定位：奇数取第 `total//2` 个（0-indexed），偶数取第 `total//2 - 1` 和 `total//2` 个的平均。
4. 二次遍历 `count`，用累加计数 `acc` 跨过每个值，`acc` 首次 ≥ 目标下标时该 k 就是中位数元素。

以示例 1 的 `count = [0,1,3,4,...]` 为例：`total = 8`，`s = 1*1+2*3+3*4 = 19`，`mean = 2.375`；偶数取下标 3 和 4，累加 `acc`：k=1 后 acc=1，k=2 后 acc=4（跨过 3），k=3 后 acc=8（跨过 4），所以两个中位元素是 2 和 3，`median = 2.5`。

```python
total = sum(count)
s = sum(k * c for k, c in enumerate(count))
lo, hi = (total - 1) // 2, total // 2   # 奇偶统一
acc = 0
med = []
for k, c in enumerate(count):
    if c and acc <= hi and acc + c > lo:
        # 该区间覆盖了 lo 或 hi
        for idx in (lo, hi):
            if acc <= idx < acc + c:
                med.append(k)
    acc += c
median = sum(med) / len(med)
```

## 复杂度
时间：O(256)，两次定长扫描，与样本总量 total 无关。
空间：O(1)，只开了 total、s、acc、med 等常数个变量。

## 易错点
- `count` 里大量 0 而 `total` 达 10^9：若按样本展开成列表会 MLE，必须用下标累加 `acc` 定位，不能真构造样本。
- 偶数中位数两个下标可能落在同一个 k 上（如 count=[0,2,0...] 时 lo=0、hi=1 都在 k=1）：用 `acc <= idx < acc+c` 判断，别写成 `acc == idx`，否则漏取导致 med 长度不足。

## 如果面试官追问
若 count 长度不是 256 而是 10^9 且稀疏给出 (值, 次数) 对？答：先按值排序，再前缀和定位中位数，O(m log m)。
