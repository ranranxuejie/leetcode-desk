## 一句话思路
自底向上逐层枚举，用 `(行字符串)` 记忆化 DFS 剪掉重复子问题，因为每层只由下一层相邻两字符决定。

## 怎么做
1. 把 `allowed` 预处理成字典 `mp`，键是底部两字符 `p[:2]`，值是能叠上去的顶部字符集合。
2. 写 `dfs(row)`：`len(row)==1` 返回 `True`；否则枚举下一层每个位置的所有候选字符，拼成 `nxt` 再递归。
3. 用 `memo` 记录已经失败过的 `row`，避免同一行被重复展开。

以示例 1 `bottom="BCD"` 为例，`mp` 含 `"BC"->{"C"}`、`"CD"->{"E"}`、`"CE"->{"A"}`。第一层相邻对是 `BC`、`CD`，候选唯一，得 `nxt="CE"`；再对 `CE` 查表得 `"A"`，长度 1，返回 `True`。

```python
mp = {}
for p in allowed:
    mp.setdefault(p[:2], set()).add(p[2])

memo = set()
def dfs(row):
    if len(row) == 1:
        return True
    if row in memo:
        return False
    cand = [mp.get(row[i:i+2], set()) for i in range(len(row)-1)]
    for nxt in product(*cand):
        if dfs(''.join(nxt)):
            return True
    memo.add(row)
    return False
```

关键点：`cand` 里任一位置为空集时 `product` 直接无解，等价于提前剪枝；`memo` 只存失败行，成功路径不必缓存。

## 复杂度
时间：O(6^n) 上界，n 为 `bottom` 长度，记忆化后实际远小于此。
空间：O(6^n) 存 `memo` 中的行字符串，递归深度 O(n)。

## 易错点
- `allowed` 为空（如 `bottom="AB"`, `allowed=[]`）→ 若直接对 `mp.get(...)` 返回 `None` 做 `product` 会抛 `TypeError` → 必须用 `mp.get(key, set())` 兜底空集。
- 示例 2 `bottom="AAAA"` → 若只贪心取每个位置第一个候选（`"AAB"` 给出 `B`）会误判，实际 `AA` 还有 `AAC` 给出 `C`，两条分支都走不通才返回 `False` → 必须全枚举并靠 `memo` 剪枝，不能取单一路径。

## 如果面试官追问
要求输出整座金字塔而非布尔值？答：把 `dfs` 改成返回 `nxt` 列表或 `None`，成功时逐层拼接，`memo` 改存 `row -> 可行上层或 None`。
