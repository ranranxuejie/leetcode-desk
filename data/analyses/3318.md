## 一句话思路
对每个长度为 k 的窗口重数频次，按（频次降序，数值降序）取前 x 个元素，把它们的频次乘数值累加。

## 怎么做
1. 外层枚举窗口起点 `i`，范围 `0..n-k`，每次用 `Counter(nums[i:i+k])` 重建频次表。
2. 对频次表按 `key=lambda v: (cnt[v], v)` 降序排序，取前 `x` 个元素。
3. 累加 `sum(v * cnt[v] for v in top)` 即为该窗口的 x-sum。
4. 若 `len(cnt) <= x`，直接返回窗口总和（等价于全部保留）。

以示例 1 的 `i=1` 为例：窗口 `[1,2,2,3,4,2]`，`cnt = {2:3, 1:1, 3:1, 4:1}`。排序键为 `(3,2),(1,4),(1,3),(1,1)`，取前 2 得 `2` 和 `4`，和 `2*3 + 4*1 = 10`，与 `answer[1]` 一致。注意 `4` 压过 `3` 和 `1`，靠的是数值大而非频次高。

```python
from collections import Counter

def findXSum(nums, k, x):
    ans = []
    for i in range(len(nums) - k + 1):
        cnt = Counter(nums[i:i + k])
        if len(cnt) <= x:
            ans.append(sum(nums[i:i + k]))
            continue
        top = sorted(cnt, key=lambda v: (cnt[v], v), reverse=True)[:x]
        ans.append(sum(v * cnt[v] for v in top))
    return ans
```

## 复杂度
时间：O((n-k+1) · k log k)，每个窗口重建频次 O(k)、排序 O(k log k)。
空间：O(k)，`cnt` 与 `top` 最多存 k 个不同元素。

## 易错点
- 排序键写成 `key=lambda v: cnt[v]` 只按频次排 → 示例 1 的 `i=1` 窗口里 `1/3/4` 频次都是 1，排序不稳定会随机取到 `1` 或 `3`，得到 `2*3+1*1=7` 而非 10 → 必须用 `(cnt[v], v)` 元组让数值参与比较。
- 忘记 `len(cnt) <= x` 的短路 → 当窗口内不同元素不足 x 个时，`[:x]` 切片虽不报错，但若后续改成「补零」逻辑就会把不存在的元素算进去 → 显式判断后直接返回窗口总和。

## 如果面试官追问
问：n 放大到 10^5 怎么办？
答：用两个有序结构维护「前 x 大」与「其余」，滑动时只增量更新进出窗口的两个元素，单窗口 O(log k)。
