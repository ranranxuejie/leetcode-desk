## 一句话思路
枚举子数组区间，用「区间外最大 k 个数替换区间内最小 k 个数」的贪心，配合有序结构求增量。

## 怎么做
1. 固定子数组 `[l, r]`，其和 `base = sum(nums[l:r+1])`；交换只能把区间外的值换进来，所以增量 = 区间外最大的至多 k 个数之和 − 区间内最小的至多 k 个数之和（只取正贡献的对）。
2. 对每个 `r` 递增，用两个有序容器维护：`inside` 存 `nums[l..r]`，`outside` 存其余元素；`l` 从 0 扫到 `r`。
3. 关键中间值：以 `nums = [1,-1,0,2], k = 1` 为例，取 `[l,r]=[0,1]`，`base = 0`，`inside` 最小是 `-1`，`outside` 最大是 `2`，增量 `2-(-1)=3`，得 `3`。
4. 每个 `(l,r)` 取 `base + gain` 的最大值；`gain` 用「区间外前 k 大之和」减「区间内前 k 小之和」，只累加正的差。

```python
# 对固定 [l, r]，用两个堆/有序数组求 gain
def gain(inside_sorted, outside_sorted, k):
    # inside 升序取前 k 小，outside 降序取前 k 大
    lo = inside_sorted[:k]
    hi = outside_sorted[::-1][:k]
    return max(0, sum(hi) - sum(lo))
# 枚举 l, r 时增量更新 base 与两个容器，O(n^2 log n)
```

实际实现用 `sortedcontainers` 或手写树状数组按值域统计个数与前缀和，`n ≤ 1500` 时 `O(n^2 log n)` 可过。

## 复杂度
时间：`O(n^2 log n)`，`n^2` 个区间，每次有序结构操作 `log n`。
空间：`O(n)`，两个容器各存至多 `n` 个元素。

## 易错点
- `k = 0` 或全负数组如 `[-1,-2]`：若默认「总能换进大数」会返回正数，实际 `gain` 必须取 `max(0, ...)`，答案应为 `-1`。
- `k` 大于区间外元素个数（如整个数组就是子数组，`outside` 为空）：取前 k 大时越界或误把区间内元素算进 `outside`，正确做法是 `hi` 只从 `outside` 取，长度不足就取全部。

## 如果面试官追问
问：`n` 放大到 `10^5` 怎么办？
答：放弃枚举 `l`，改用分治或对每个 `r` 维护「最优左端点」的单调结构，把 `n^2` 降下来。
