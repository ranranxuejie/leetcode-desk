## 一句话思路
用约瑟夫环递推 `f(i) = (f(i-1) + target) % i`，从 1 人规模倒推到 num 人，避免模拟链表删除。

## 怎么做
1. 只剩 1 人时，幸存者编号必为 0，令 `ans = 0`。
2. 从 `i = 2` 枚举到 `num`，每轮把上一轮答案在长度为 i 的环里后移 `target` 位并取模：`ans = (ans + target) % i`。
3. 循环结束返回 `ans`。

以 `num = 7, target = 4` 为例，关键中间值是 `i = 4` 时：`ans` 从 `i=3` 的 `(1+4)%3 = 2` 推进为 `(2+4)%4 = 2`；继续到 `i=7` 得 `(0+4)%7 = 4` 后下一轮 `(4+4)%6 = 2`、`(2+4)%7 = 6`… 最终收敛到 1，与示例一致。

```python
ans = 0
for i in range(2, num + 1):
    ans = (ans + target) % i
return ans
```

注意 `target` 可远大于 `num`（最大 10^6），取模每轮都做，不能只在最后做一次。

## 复杂度
时间：O(num)，循环 num-1 次，每次一次加法和取模。
空间：O(1)，只存 `ans` 和循环变量 `i`，没有递归栈和数组。

## 易错点
- `num = 1` 时循环 `range(2, 2)` 不执行，直接返回 0，这是对的；若把初值写成 1 或从 `i = 1` 起循环，会返回错误编号。
- `target` 很大（如 `num = 3, target = 10^6`）时，若先累加再取模或漏取模，中间值会膨胀到 10^11 量级；虽然 Python 不溢出，但语义上必须每轮 `% i`，否则等价于没做环内回绕。
