## 一句话思路
按位独立求和：第 i 位的贡献 = 该位数字之和 × 10^i × 其余位的组合数，用等比数列公式处理 k 到 10^9。

## 怎么做
1. 设 `cnt = r - l + 1`，`s = (l + r) * cnt // 2`，则所有 k 位数之和 = `s * cnt^(k-1) * (10^k - 1) / 9`。
2. 用快速幂算 `cnt^(k-1)` 和 `10^k`，`/9` 换成乘 9 的模逆元 `pow(9, MOD-2, MOD)`。
3. 以示例 1 `l=1, r=2, k=2` 验证：`cnt=2, s=3`，`cnt^(k-1)=2`，`(10^2-1)/9=11`，得 `3*2*11=66`，与输出一致。
4. 示例 3 `l=r=5, k=10`：`cnt=1, s=5`，`cnt^9=1`，`(10^10-1)/9` 取模后乘 5，得 555555520。

```python
MOD = 10**9 + 7
cnt = r - l + 1
s = (l + r) * cnt // 2
inv9 = pow(9, MOD - 2, MOD)
rep = (pow(10, k, MOD) - 1) * inv9 % MOD
ans = s % MOD * pow(cnt, k - 1, MOD) % MOD * rep % MOD
```

## 复杂度
时间：O(log k)，两次快速幂各 O(log k)，其余 O(1)。
空间：O(1)，只存 cnt、s、inv9、rep 几个标量。

## 易错点
- `l=0, r=1, k=3` 时若把前导零当无效位剔除，会漏算 000~011 这些数，错成 100+101+110+111=422；题面明确允许前导零，必须按 k 位全排列算，答案 444。
- `cnt=1`（如示例 3）时 `pow(cnt, k-1)` 恒为 1，若误用 `cnt^k` 会多乘一个 1 看似无碍，但 `s` 若写成 `(l+r)*cnt//2` 之外的浮点除法会丢精度；正确做法是全程整数运算，`s` 用整除。

## 如果面试官追问
问：k 缩小到 10^5 但要求输出所有数之和的十进制表示？
答：仍需大数，用 Python 原生大整数直接算 `s * cnt**(k-1) * (10**k-1)//9`，不取模。
