## 一句话思路
反复剥掉所有叶子节点（拓扑排序），最后剩下的 1 或 2 个节点就是最小高度树的根。

## 怎么做
1. 建邻接表 `adj`，同时记录每个节点的度数 `deg`，把 `deg == 1` 的节点全部入队。
2. 每轮取出当前队列里的**全部**叶子（记下这一轮的数量 `size`），把 `n` 减去 `size`；若 `n <= 2`，队列里剩下的就是答案。
3. 对每个弹出的叶子 `u`，遍历 `adj[u]` 里的邻居 `v`，`deg[v] -= 1`，若 `deg[v] == 1` 就入队。
4. 循环直到 `n <= 2`，返回队列中的节点。

以示例 2 为例：`n = 6`，`edges = [[3,0],[3,1],[3,2],[3,4],[5,4]]`。初始 `deg = [1,1,1,4,2,1]`，叶子队列是 `[0,1,2,5]`。第一轮剥掉这 4 个，`n` 变成 2，`deg[3]` 从 4 降到 1、`deg[4]` 从 2 降到 1，两者入队，返回 `[3,4]`。

```python
from collections import deque
adj = [[] for _ in range(n)]
deg = [0] * n
for a, b in edges:
    adj[a].append(b); adj[b].append(a)
    deg[a] += 1; deg[b] += 1
q = deque(i for i in range(n) if deg[i] <= 1)
while n > 2:
    size = len(q)
    n -= size
    for _ in range(size):
        u = q.popleft()
        for v in adj[u]:
            deg[v] -= 1
            if deg[v] == 1:
                q.append(v)
return list(q)
```

## 复杂度
时间 O(n)：每条边在剥叶子时被访问两次，`n` 个节点各入队一次。
空间 O(n)：`adj` 存 2(n-1) 条边，`deg` 和队列各 O(n)。

## 易错点
- `n == 1` 且 `edges == []`：若用 `deg[i] == 1` 筛初始叶子，队列为空直接返回 `[]`。正确做法是初始条件写 `deg[i] <= 1`，让孤立节点 0 入队，返回 `[0]`。
- 每轮必须整层剥完再判断 `n <= 2`：若在示例 2 中剥到 `n == 3` 就停（比如逐个节点判断），会多留一个叶子，返回 `[3,4,5]` 之类的错误集合。正确做法是先 `size = len(q)`、`n -= size`，再统一处理这一层。

## 如果面试官追问
若要求返回最小高度树的具体高度值而非根列表？答：剥叶子的轮数就是最小高度，每轮 `n -= size` 时计数器加一即可。
