## 一句话思路
用哈希表存 tokenId→过期时刻，惰性删除：只在 renew/count 时按当前时间清理过期项。

## 怎么做
1. `generate` 直接写 `self.d[tokenId] = currentTime + self.ttl`，因为题目保证 tokenId 唯一，不用判重。
2. `renew` 先查表，命中且 `self.d[tokenId] > currentTime` 才更新，否则忽略。
3. `countUnexpiredTokens` 遍历字典，删掉所有 `expire <= currentTime` 的键，返回剩余长度。
4. 关键中间值：示例中 `generate("aaa", 2)` 后 `d["aaa"] = 7`；`renew("aaa", 8)` 时 `7 > 8` 为假，忽略；`renew("bbb", 10)` 时 `d["bbb"] = 12`，`12 > 10` 成立，改成 `15`；`count(15)` 时 `7 <= 15`、`15 <= 15` 都删，返回 0。

```python
def renew(self, tokenId, currentTime):
    exp = self.d.get(tokenId)
    if exp is not None and exp > currentTime:
        self.d[tokenId] = currentTime + self.ttl

def countUnexpiredTokens(self, currentTime):
    for k in [k for k, v in self.d.items() if v <= currentTime]:
        del self.d[k]
    return len(self.d)
```

## 复杂度
时间：count 每次 O(n)，n 为字典中 token 数，总调用 ≤2000 可接受。
空间：O(n)，哈希表存每个未清理的 tokenId 及其过期时刻。

## 易错点
- `countUnexpiredTokens(15)` 时 `d["bbb"] = 15`：若用 `v < currentTime` 判过期，会漏删 bbb 返回 1，正确是 `v <= currentTime`，因为过期事件优先于同时刻操作。
- `renew("aaa", 8)` 时 `d["aaa"] = 7`：若只判 `tokenId in self.d` 就更新，会把已过期的 aaa 复活成 13，正确必须先判 `exp > currentTime` 才更新。

## 如果面试官追问
若 currentTime 不严格递增、需要 O(1) 均摊清理怎么办？答：改用按过期时刻排序的双向链表加哈希表，每次操作前从表头弹出所有已过期节点。
