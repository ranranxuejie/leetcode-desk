## 一句话思路
第一个子数组必以 `nums[0]` 开头，代价固定为 `nums[0]`，剩下只需在 `nums[1:]` 里挑两个最小的数当后两段的首元素。

## 怎么做
1. 答案先记 `nums[0]`，因为任何分法的第一段首元素都是它。
2. 后两段的首元素只能从 `nums[1:]` 里选，且下标越大越靠后，选谁都不影响可行性。
3. 所以取 `nums[1:]` 中最小的两个值相加即可，用排序或一次遍历找两个最小值。

以 `nums = [10,3,1,1]` 为例：`nums[0] = 10`，`nums[1:] = [3,1,1]`，最小两个是 `1` 和 `1`，答案 `10 + 1 + 1 = 12`，对应切法 `[10,3] [1] [1]`。

```python
def minimumCost(nums):
    a = b = 51          # nums[i] <= 50
    for x in nums[1:]:
        if x < a:
            a, b = x, a
        elif x < b:
            b = x
    return nums[0] + a + b
```

注意 `a, b = x, a` 的顺序：旧 `a` 要降级成 `b`，不能写成 `a = x; b = a`。

## 复杂度
时间 O(n)：一次遍历 `nums[1:]`，n 是数组长度。
空间 O(1)：只开了 `a`、`b` 两个变量，没有额外数组。

## 易错点
- 把 `nums[0]` 也丢进候选池排序：`nums = [5,4,3]` 会算成 `3+4+5` 里挑两个加 `5`，得 `12` 碰巧对，但 `nums = [1,2,3,12]` 若从全数组挑两个最小得 `1+2+1=4`，正确是 `1+2+3=6`。候选范围必须严格是 `nums[1:]`。
- 用 `min` 加 `remove` 的写法：`nums = [10,3,1,1]` 里两个 `1` 相等，`remove(1)` 删掉的是第一个 `1`，若再对原列表操作容易把 `nums[0]` 也卷进去，或删错位置。正确做法是遍历 `nums[1:]` 维护 `a`、`b` 两个最小值，不修改原数组。

## 如果面试官追问
问：如果要求分成 k 段（k 由输入给出）呢？
答：答案仍是 `nums[0]` 加上 `nums[1:]` 中最小的 `k-1` 个数，用大小为 `k-1` 的堆或排序取前 `k-1` 小，复杂度 O(n log k)。
