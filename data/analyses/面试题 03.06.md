## 一句话思路
用两条队列分别存猫和狗，元素带全局自增序号，`dequeueAny` 比较两队列队首序号取小者。

## 怎么做
1. 维护 `cats`、`dogs` 两个 `deque`，元素为 `(seq, id)`，`seq` 是 `enqueue` 时自增的全局计数器。
2. `enqueue` 按 `animal[1]` 分流：0 进 `cats`，1 进 `dogs`，都追加 `(self.seq, animal[0])`。
3. `dequeueCat`/`dequeueDog` 直接 `popleft` 对应队列，空则返回 `[-1, -1]`。
4. `dequeueAny` 比较两队列队首的 `seq`，谁小弹谁；某队列空则弹另一条。

以示例 2 为例：三次 `enqueue` 后 `cats = [(0,0),(1,0)]`，`dogs = [(2,2)]`。`dequeueDog` 弹出 `(2,2)` 返回 `[2,1]`；接着 `dequeueCat` 弹 `(0,0)` 返回 `[0,0]`；`dequeueAny` 时 `cats` 队首 `seq=1`、`dogs` 已空，返回 `[1,0]`。

```python
from collections import deque

def enqueue(self, animal):
    q = self.cats if animal[1] == 0 else self.dogs
    q.append((self.seq, animal[0]))
    self.seq += 1

def dequeueAny(self):
    if not self.cats: return self.dequeueDog()
    if not self.dogs: return self.dequeueCat()
    if self.cats[0][0] < self.dogs[0][0]:
        return self.dequeueCat()
    return self.dequeueDog()
```

关键点：`seq` 必须全局唯一且单调，不能各队列独立计数，否则跨种类比较会错。

## 复杂度
时间：`enqueue` 与三个 `dequeue` 均 O(1)，n 次操作共 O(n)。
空间：O(n)，两条队列各存元素，额外只有计数器 `seq`。

## 易错点
- 若两条队列各自从 0 计数，示例 2 中猫 `(0,0)` 与狗 `(0,2)` 的 `seq` 都是 0，`dequeueAny` 用 `<` 比较会误判顺序 → 必须用同一个全局 `seq` 自增。
- `dequeueAny` 在一条队列为空时若仍去取 `self.cats[0][0]`，空队列会抛 `IndexError` → 先判空再比较，空则直接走另一条队列的 `dequeue`。

## 如果面试官追问
若要求 `dequeueAny` 也 O(1) 且不许用全局计数器？答：仍用两条队列，但 `dequeueAny` 需比较队首时间戳，无计数器时只能靠入队顺序，等价于必须维护序号，故计数器是必要信息。
