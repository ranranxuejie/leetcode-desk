## 一句话思路
用正则 `^[A-Za-z][A-Za-z0-9_.-]*@leetcode\.com$` 对 `mail` 做全串匹配，锚定首尾才能排除 `.shapo@...` 这类前缀非法的情况。

## 怎么做
1. 在 `WHERE` 里对 `mail` 用 `REGEXP`，模式串首尾都加 `^` 和 `$`。
2. 前缀部分写成 `[A-Za-z][A-Za-z0-9_.-]*`：第一个字符单独限定为字母，后面才放开点、破折号。
3. 域部分直接写死 `@leetcode\.com`，点要转义，且不能加 `i` 忽略大小写。
4. 用 `SELECT *` 返回整行，顺序无所谓。

拿示例第 7 行 `mail = '.shapo@leetcode.com'` 看关键中间值：若模式写成 `[A-Za-z0-9_.-]*@leetcode\.com$`（漏掉首字母约束），`.` 能匹配首字符，这行会被误选；加上 `^[A-Za-z]` 后首字符 `.` 不满足，整串匹配失败，正确排除。

```python
import re

pat = re.compile(r'^[A-Za-z][A-Za-z0-9_.-]*@leetcode\.com$')

def valid_emails(users):
    return [u for u in users if pat.match(u['mail'])]
```

SQL 版核心一行：

```python
sql = """
SELECT user_id, name, mail FROM Users
WHERE mail REGEXP '^[A-Za-z][A-Za-z0-9_.-]*@leetcode\\\\.com$'
"""
```

注意 Python 字符串里 `\\\\.` 最终传给 MySQL 的是 `\\.`，MySQL 再解析成字面点；若用原生字符串 `r'...@leetcode\.com$'` 则只需一层。

## 复杂度
时间：O(n·m)，n 是 `Users` 行数，m 是 `mail` 平均长度，每行跑一次线性正则匹配。
空间：O(k)，k 是命中行数，仅存结果集，正则本身 O(m)。

## 易错点
- 输入 `mail = 'winston@leetcode.com'` 但模式漏写 `$` → 会把 `winston@leetcode.com.cn` 或 `winston@leetcode.comX` 也判有效 → 必须用 `$` 锚定结尾，域部分写死 `@leetcode\.com` 且点转义。
- 输入 `mail = 'David@leetcode.com'` 或 `'david@LeetCode.com'` → 若给正则加 `i` 标志或写成 `[A-Za-z]` 匹配域 → 域必须全小写，模式里域段只用小写字面量、不加忽略大小写；前缀大小写才允许。

## 如果面试官追问
问：如果 `mail` 上有百万行且要频繁查？
答：把正则条件下推到数据库层用 `REGEXP` 走索引不现实，可加生成列 `is_valid` 建索引，或写入时校验。
