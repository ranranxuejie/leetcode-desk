## 一句话思路
只有 5 种字符，枚举有序字符对 (a,b)，用前缀和 + 按奇偶分桶的最小前缀值，O(25n) 扫出最大 `freq[a]-freq[b]`。

## 怎么做
1. 对每个字符 c 建前缀计数 `pre[c][i]`，`pre[c][i]` 表示 s[:i] 中 c 的个数。
2. 枚举有序对 (a,b)，a≠b，把问题变成在区间 [l,r] 上最大化 `(pre[a][r]-pre[a][l]) - (pre[b][r]-pre[b][l])`，且 r-l≥k。
3. 固定 r，需要 l≤r-k 里让 `pre[a][l]-pre[b][l]` 最小；但 a 的出现次数要奇数、b 要非 0 偶数，所以按 `(pre[a][l]%2, pre[b][l]%2)` 分 4 桶存最小 `pre[a][l]-pre[b][l]`。
4. 扫 r 时先把这个 l=r-k 的桶更新进去，再查 `(1-pre[a][r]%2, pre[b][r]%2)` 桶，得到候选差值。

以 `s="1122211", k=3` 为例，枚举 (a,b)=('2','1')：r=5 时 `pre[2][5]=3, pre[1][5]=2`，需要桶 `(0,0)`；l=2 时 `pre[2][2]=1, pre[1][2]=2`，差值 -1 入桶，候选 `(3-2)-(-1)=2`？实际取 l=2 得子串 "22211" 中 2 出现 3 次、1 出现 2 次，差 1——注意桶里存的是 `pre[a][l]-pre[b][l]`，候选为 `(pre[a][r]-pre[b][r]) - minv`，此处 `1-(-1)=2` 对应区间 [2,5) 即 "2221"，2 出现 3 次、1 出现 1 次，1 是奇数不合法，故桶键必须严格匹配奇偶。

```python
n = len(s)
pre = [[0]*(n+1) for _ in range(5)]
for i, ch in enumerate(s):
    for c in range(5):
        pre[c][i+1] = pre[c][i] + (ord(ch)-48 == c)
ans = -10**9
for a in range(5):
    for b in range(5):
        if a == b: continue
        best = [[10**9]*2 for _ in range(2)]
        for r in range(k, n+1):
            l = r - k
            key = (pre[a][l] & 1, pre[b][l] & 1)
            best[key[0]][key[1]] = min(best[key[0]][key[1]], pre[a][l]-pre[b][l])
            need = (1 - (pre[a][r] & 1), pre[b][r] & 1)
            if best[need[0]][need[1]] < 10**9:
                ans = max(ans, pre[a][r]-pre[b][r]-best[need[0]][need[1]])
```

## 复杂度
时间：O(25·n)，25 个字符对各自扫一遍 n，前缀和预处理 O(5n)。
空间：O(5n) 存前缀表，桶只有常数 4 个。

## 易错点
- 桶键写成只看 `pre[a][l]%2` 而漏掉 b 的奇偶 → 对 `s="12233",k=4` 会把 b 出现奇数次的区间也计入，得到比 -1 大的非法值；必须同时锁 `(pre[a]%2, pre[b]%2)` 两个维度。
- 忘记 b 必须非 0 偶数 → 对 `s="110",k=3` 会取 b 出现 0 次的区间算出 0 或正数；正确做法是查桶时额外保证 `pre[b][r]-pre[b][l] > 0`，或在候选处判 `pre[b][r] > best 对应 l 的 pre[b][l]`。

## 如果面试官追问
问：字符集扩到 26 个字母怎么办？答：外层枚举变成 26×25=650 对，仍是 O(650n)，桶结构不变，只是常数变大。
