## 一句话思路
用哈希表 `cnt` 维护每个 ID 的当前频率，再用大顶堆存 `(-频率, ID)`，每步弹出堆顶并校验频率是否与 `cnt` 一致，惰性删除过期项。

## 怎么做
1. 建 `cnt = {}` 记录 ID→频率，建空堆 `heap`。
2. 每步先更新 `cnt[nums[i]] += freq[i]`，再把 `(-cnt[nums[i]], nums[i])` 压入堆。
3. 循环弹出堆顶，若 `-heap[0][0] != cnt[heap[0][1]]` 说明是旧值，`heappop` 丢弃；否则它就是当前最大频率。
4. 把 `-heap[0][0]` 写入 `ans[i]`；堆空则写 0。

以示例 1 为例，第 2 步 `nums[2]=2, freq[2]=-3`，`cnt[2]` 从 3 变成 0，压入 `(0, 2)`；堆顶仍是第 1 步压入的 `(-3, 2)`，但 `cnt[2]=0 != 3`，弹出丢弃，新堆顶是 `(-2, 3)`，`cnt[3]=2` 匹配，答案 2。

```python
import heapq
cnt = {}
heap = []
ans = []
for x, d in zip(nums, freq):
    cnt[x] = cnt.get(x, 0) + d
    heapq.heappush(heap, (-cnt[x], x))
    while heap and -heap[0][0] != cnt[heap[0][1]]:
        heapq.heappop(heap)
    ans.append(-heap[0][0] if heap else 0)
```

## 复杂度
时间：每步一次 push 加均摊一次 pop，共 O(n log n)，n 为操作数。
空间：`cnt` 存至多 n 个 ID，堆最多累积 n 个元素，O(n)。

## 易错点
- 频率减到 0 的 ID 仍留在 `cnt` 里（如示例 2 第 1 步 `cnt[5]=0`），若只判 `cnt[x] > 0` 才压堆，会漏掉「集合为空返回 0」；正确做法是照常压 `(0, 5)`，靠堆顶校验自然得到 0。
- 同一 ID 反复增减会往堆里塞大量过期项（如 `nums=[1,1,1], freq=[5,-5,5]`），若只弹一次堆顶就取答案，可能拿到 `(-5,1)` 这个旧值；必须用 `while` 循环弹到堆顶频率与 `cnt` 相等为止。

## 如果面试官追问
若要求返回最高频 ID 本身而非频率，怎么改？答：堆元素已是 `(-频率, ID)`，直接取 `heap[0][1]`，频率相同时按 ID 升序由元组比较自动保证。
