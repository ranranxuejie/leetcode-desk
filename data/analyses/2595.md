## 一句话思路
用 `n & 1` 取最低位、`n >>= 1` 逐位右移，同时用下标 `i` 的奇偶决定累加到 `even` 还是 `odd`。

## 怎么做
1. 初始化 `even = odd = 0`，下标 `i = 0`。
2. 循环条件写 `while n:`，每轮先看 `n & 1` 是否为 1。
3. 若为 1，按 `i % 2` 累加：`i` 偶则 `even += 1`，否则 `odd += 1`。
4. 每轮末尾 `n >>= 1`、`i += 1`，返回 `[even, odd]`。

以 `n = 50` 为例，二进制 `110010`。第 0 轮 `n & 1 = 0`，`i = 0` 不累加，`n` 变 25；第 1 轮 `n & 1 = 1`、`i = 1` 为奇，`odd` 变 1，`n` 变 12；第 4 轮 `n & 1 = 1`、`i = 4` 为偶，`even` 变 1；第 5 轮 `n & 1 = 1`、`i = 5` 为奇，`odd` 变 2，`n` 归零退出，得 `[1, 2]`。

```python
even = odd = 0
i = 0
while n:
    if n & 1:
        if i % 2 == 0:
            even += 1
        else:
            odd += 1
    n >>= 1
    i += 1
return [even, odd]
```

关键点：`i` 必须和 `n` 同步右移，`i` 就是当前最低位在原始二进制里的下标；`n` 归零后高位全是 0，不必再扫。

## 复杂度
时间：O(log n)，循环次数等于 `n` 的二进制位数，`n ≤ 1000` 时最多 10 轮。
空间：O(1)，只开了 `even`、`odd`、`i` 三个整数。

## 易错点
- 输入 `n = 2`（二进制 `10`）→ 若把下标从左往右数，会把唯一的 1 记到下标 0 上，错成 `[1, 0]` → 必须从右往左数，最低位是下标 0，答案应为 `[0, 1]`。
- 输入 `n = 1`（二进制 `1`）→ 若循环写成 `while n > 1` 或先 `n >>= 1` 再判断，会漏掉下标 0 的这个 1，错成 `[0, 0]` → 先判 `n & 1` 再右移，答案应为 `[1, 0]`。

## 如果面试官追问
问：若 `n` 大到 `2**31 - 1`，写法要改吗？
答：不用，循环仍是 O(log n) 即 31 轮，Python 整数无溢出，`i` 最大到 30。
