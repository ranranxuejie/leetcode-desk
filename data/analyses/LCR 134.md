## 一句话思路
快速幂：把 n 按二进制拆成若干 2 的幂次，逐位平方底数、按位乘入结果，把 O(n) 次乘法压到 O(log n)。

## 怎么做
1. 先把 n 转成非负：`if n < 0: x, n = 1 / x, -n`，负指数等价于底数取倒数。
2. 维护 `ans = 1.0` 和 `base = x`，循环条件 `while n > 0`。
3. 每轮看最低位：`if n & 1: ans *= base`，然后 `base *= base`、`n >>= 1`。
4. 循环结束返回 `ans`。

以 `x = 2.0, n = 10` 为例，10 的二进制是 `1010`。第 1 轮 `n & 1 == 0`，`ans` 仍为 1.0，`base` 从 2.0 平方成 4.0，`n` 变 5；第 2 轮 `n & 1 == 1`，`ans` 变 4.0，`base` 变 16.0，`n` 变 2；第 3 轮跳过，`base` 变 256.0，`n` 变 1；第 4 轮 `ans = 4.0 * 256.0 = 1024.0`，`n` 变 0 退出。关键中间值就是 `ans` 只在 n 的置位（第 1、3 位，即 2 和 8）上累乘，得到 4.0 × 256.0。

```python
if n < 0:
    x, n = 1 / x, -n
ans, base = 1.0, x
while n > 0:
    if n & 1:
        ans *= base
    base *= base
    n >>= 1
return ans
```

注意 `n = -2**31` 取负后是 `2**31`，Python 整数无溢出，`-n` 直接可用；若用 C++ 的 int 就会溢出，这是本题最隐蔽的一处。

## 复杂度
时间 O(log n)：循环次数等于 n 的二进制位数，每轮常数次乘法。
空间 O(1)：只开 `ans`、`base` 两个变量，递归写法才有 O(log n) 栈。

## 易错点
- 输入 `x = 2.0, n = -2**31` → 若先算 `-n` 再判断符号，或在 32 位整型里取负，会溢出成 `-2**31` 导致死循环或错值 → 正确做法是先判断 `n < 0` 再取 `x = 1 / x, n = -n`，Python 下 `-n` 得 `2**31` 安全。
- 输入 `x = 2.0, n = 0` 或 `x = 1.0, n = -2**31` → 若把 `n == 0` 的返回写成 `0` 而非 `1.0`，或漏掉 `n = 0` 分支直接进循环，会返回 0 或死循环 → 正确做法是让 `ans` 初值 `1.0`，`while n > 0` 自然跳过，返回 1.0。

## 如果面试官追问
问：若要求返回精确的分数形式（如 `x = 2, n = -2` 返回 `1/4` 而非 0.25）怎么办？
答：把 `ans`、`base` 换成 `(分子, 分母)` 二元组，乘法改为交叉相乘，最后约分。
