## 一句话思路
把 target 记 +1、非 target 记 −1，子数组和 > 0 即 target 占多数，用线段树/归并统计前缀和的顺序对数。

## 怎么做
1. 令 `a[i] = 1 if nums[i]==target else -1`，前缀和 `p[0]=0, p[i]=p[i-1]+a[i-1]`；子数组 `(l,r]` 满足 `p[r] > p[l]`。
2. 答案就是满足 `l < r` 且 `p[l] < p[r]` 的下标对数，即前缀和数组的「顺序对」个数。
3. 用归并排序统计：分治左右两半，递归后双指针数跨区顺序对，再合并。
4. 以 `nums=[1,2,2,3], target=2` 为例：`a=[-1,1,1,-1]`，`p=[0,-1,0,1,0]`；跨区统计时左半 `[0,-1,0]`、右半 `[1,0]`，`p[l]<p[r]` 的对数贡献 4，加递归内部 1，共 5。

```python
def count(p):
    if len(p) <= 1:
        return p, 0
    m = len(p) // 2
    L, cl = count(p[:m])
    R, cr = count(p[m:])
    i = j = 0
    cross = 0
    while i < len(L):
        while j < len(R) and R[j] <= L[i]:
            j += 1
        cross += len(R) - j
        i += 1
    return sorted(L + R), cl + cr + cross
```

## 复杂度
时间：归并每层 O(n)，共 O(n log n)，n 为 nums 长度。
空间：递归栈与合并临时数组 O(n)，前缀和数组另占 O(n)。

## 易错点
- 用 `p[r] > p[l]` 时若写成 `>=`，`nums=[1,2,2,3]` 会把 `[1,2]` 这类平局子数组算进去，答案变 6；必须严格大于。
- 前缀和含 `p[0]=0` 共 n+1 项，漏掉它会让 `nums=[2], target=2` 返回 0 而非 1；构造 `p` 时先放 0 再累加。

## 如果面试官追问
问：n 到 10^7 内存吃紧怎么办？
答：改用树状数组按前缀和值域离散化统计，边扫边查，空间降到 O(不同前缀和个数)。
