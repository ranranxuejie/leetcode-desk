## 一句话思路
把 n 的二进制最高位以下全部填 1，用「不断右移或」把最高位 1 向右铺满，得到全 1 掩码。

## 怎么做
1. 令 `x = n`，对 `x` 反复执行 `x |= x >> 1`、`x >>= 2`、`x >>= 4`……直到位移量超过位数，把最高位 1 向右「传染」成一段连续的 1。
2. 此时 `x` 是「不小于 n 的最小全 1 数」的候选，但若 n 本身已是全 1（如 3），`x` 就等于 n，直接返回即可。
3. 若 n 不是全 1，`x` 会比 n 大且全 1，正是答案；用 `x` 与 `x+1` 判断：`x & (x+1) == 0` 说明 x 全 1。

以 n = 5（二进制 `101`）为例：`x=5`，`x |= x>>1` 得 `111`（7），`x |= x>>2` 仍 `111`。此时 `x=7`，`7 & 8 == 0`，7 全 1，返回 7。关键中间值就是 `x` 从 `101` 变成 `111` 那一步。

```python
x = n
x |= x >> 1
x |= x >> 2
x |= x >> 4
x |= x >> 8
x |= x >> 16
# 此时 x 是 >= n 的最小全 1 数（n<=1000，5 次移位足够覆盖 10 位）
return x
```

对 n = 10（`1010`）：`x>>1` 后 `1111`（15），后续移位不变，返回 15，与示例一致。n = 3（`11`）时 `x` 保持 3，返回 3。

## 复杂度
时间：O(log n)，移位次数由 n 的二进制位数决定，每次 O(1)。
空间：O(1)，只用了 `x` 一个整型变量，无额外数组。

## 易错点
- 输入 n = 1（`1`）→ 若误以为要「严格大于」会返回 3 → 正确是 1，因为 1 本身已是全 1 且 ≥ n，直接返回。
- 输入 n = 1000（`1111101000`，10 位）→ 若只写 `x |= x>>1` 一次，高位 1 没铺满，得到 `1111111100`（非全 1）→ 必须连续移位 1、2、4、8，覆盖到最高位。

## 如果面试官追问
问：若 n 可达 2**31 - 1，移位怎么写？
答：补到 `x |= x >> 16` 后再加 `x >> 32` 不必要，32 位内 1/2/4/8/16 五次已覆盖，直接复用同一段即可。
