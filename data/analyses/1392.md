## 一句话思路
用 KMP 的 next 数组（前缀函数）求 `s` 的最长真前后缀，`next[n-1]` 就是答案长度。

## 怎么做
1. 对 `s` 求前缀函数 `pi`，`pi[i]` 表示 `s[0..i]` 的最长真前后缀长度。
2. 递推时用 `j` 记录当前匹配长度，失配就沿 `pi[j-1]` 回退。
3. 返回 `s[:pi[n-1]]`。

以 `s = "ababab"` 为例：`pi = [0,0,1,2,3,4]`，`pi[5] = 4`，所以答案是 `s[:4] = "abab"`。关键中间值出现在 `i=5`：此时 `j=3`，`s[3]=='b' == s[5]=='b'`，于是 `j` 加到 4，`pi[5]=4`。

```python
n = len(s)
pi = [0] * n
j = 0
for i in range(1, n):
    while j > 0 and s[i] != s[j]:
        j = pi[j - 1]
    if s[i] == s[j]:
        j += 1
    pi[i] = j
return s[:pi[n - 1]]
```

注意 `pi[n-1]` 天然小于 `n`（真前后缀），不用额外排除原串自身。

## 复杂度
时间 O(n)：`i` 单调前进，`j` 每次回退至少减 1，总回退不超过 n。
空间 O(n)：`pi` 数组长度 n，返回值切片另占答案长度。

## 易错点
- 输入 `s = "a"` → 若直接返回 `s[:pi[0]]` 而 `pi[0]` 未初始化或误写成 1，会返回 `"a"` 而非 `""` → 正确做法是 `pi[0] = 0`，返回 `s[:0] = ""`。
- 输入 `s = "aaaa"` → 若把 `pi[n-1]` 当成「包含自身的匹配」而额外减 1，会错成 `"aa"` → 正确做法是前缀函数定义本身就是真前后缀，`pi[3]=3`，答案 `"aaa"`，不要再减。

## 如果面试官追问
问：不用 KMP，用滚动哈希怎么做？
答：从长到短枚举长度 `L`，比较前缀哈希与后缀哈希，取第一个相等；单次 O(1)，最坏 O(n)，需双哈希防碰撞。
