## 一句话思路
按右端点 r 滚动维护「以 r 结尾的所有区间 AND 值」去重集合，集合大小不超过 30，逐个与 target 比差值。

## 怎么做
1. 记 `cur` 为以当前 r 结尾的所有区间 AND 值集合，初始为空；对每个 `x = arr[r]`，新集合 `nxt = {x} ∪ {v & x for v in cur}`。
2. 去重后 `cur = nxt`，因为 AND 只会让二进制 1 的个数单调不增，不同值最多 30 个（arr[i] ≤ 10^6 < 2^20）。
3. 每轮对 `cur` 中每个 v 更新 `ans = min(ans, abs(v - target))`。
4. 以示例 1 的 `arr = [9,12,3,7,15]` 为例：r=1 时 `cur = {12, 8}`（9&12=8）；r=2 时 `nxt = {3, 0, 0}` 去重为 `{3, 0}`，其中 3 与 target=5 差 2，即答案。

```python
ans = 2**31 - 1
cur = set()
for x in arr:
    nxt = {x}
    for v in cur:
        nxt.add(v & x)
    cur = nxt
    for v in cur:
        d = v - target
        if d < 0:
            d = -d
        if d < ans:
            ans = d
return ans
```

关键中间值：r=2 时 `cur` 从 `{12, 8}` 变成 `{3, 0}`，集合规模从 2 掉到 2，说明去重确实压住了规模。

## 复杂度
时间 O(n · 30)，n 来自遍历 arr，30 来自每个右端点去重后的 AND 值上界。
空间 O(30)，只存当前集合 `cur` 和 `nxt`，与 n 无关。

## 易错点
- 输入 `arr = [1000000,1000000,1000000]`、target=1：若忘记把 `x` 本身放进 `nxt`，会漏掉单元素区间，答案错成 0 附近；正确做法是 `nxt = {x}` 起手再并入 `v & x`。
- 输入 `arr = [1,2,4,8,16]`、target=0：若用 `abs(v - target)` 之外的写法（如只比较 `v >= target` 一侧）会漏掉 v=0 的区间；正确做法是对 `cur` 里每个 v 都取绝对差，示例 3 的 0 来自 `1&2&4&8&16 = 0`。

## 如果面试官追问
问：若要求返回具体的 (l, r) 而不只是差值？
答：集合里每个值额外存一个最靠右的起点下标，更新答案时同步记录该下标与当前 r 即可。
