## 一句话思路
贪心：从左往右扫，当前累积 AND 一旦变成 0 就立刻切一刀，因为 0 已是单段分数下界，切得越早段数越多。

## 怎么做
1. 维护 `cur` 表示当前未切段的 AND，初值取 `nums[0]`，`ans = 0`。
2. 遍历每个 `x`：`cur &= x`，若 `cur == 0` 则 `ans += 1`，并把 `cur` 重置为「全 1」掩码（Python 里用 `~0` 即可，因为 `~0 & x == x`）。
3. 扫完返回 `ans`；若 `ans == 0`（全程没出现过 0），说明最小总分数就是整段 AND，只能切成 1 段，返回 1。

以 `nums = [1,0,2,0,1,2]` 为例：`cur=1`；遇 0 → `cur=0`，`ans=1`，重置；遇 2 → `cur=2`；遇 0 → `cur=0`，`ans=2`，重置；遇 1 → `cur=1`；遇 2 → `cur=1&2=0`，`ans=3`。返回 3。

```python
cur = nums[0]
ans = 0
for x in nums:
    cur &= x
    if cur == 0:
        ans += 1
        cur = ~0          # 全 1 掩码，等价于「重新开始」
return ans if ans else 1
```

关键点：`cur` 重置成 `~0` 而不是 `nums[i+1]`，这样循环体不用特判下标，`~0 & x` 恒等于 `x`。

## 复杂度
时间 O(n)：每个 `nums[i]` 只做一次 `&=` 和一次比较。
空间 O(1)：只开了 `cur`、`ans` 两个整数。

## 易错点
- 输入 `[5,7,1,3]` → 若循环结束直接返回 `ans`（此时为 0）会输出 0，但答案至少是 1 → 必须写 `return ans if ans else 1`。
- 输入 `[0,0,0]` → 若把重置写成 `cur = nums[i+1]` 且没处理越界，最后一段会漏算或数组越界 → 用 `~0` 重置，`[0,0,0]` 正确得到 3。

## 如果面试官追问
问：要求输出具体切分方案怎么办？
答：在 `cur == 0` 处记录当前下标 `i` 作为切点，最后把切点列表转成区间即可，逻辑不变。
