## 一句话思路
用 dp[i] 表示「站到第 i 阶时已花的最小体力」，转移取前两阶的较小值，因为每步只能跨 1 或 2 阶。

## 怎么做
1. 定义 dp 长度 n+1，dp[i] 是**到达**第 i 阶（尚未支付 cost[i]）的最小花费，dp[0]=dp[1]=0，因为起点可任选 0 或 1。
2. 对 i 从 2 到 n，dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])：从 i-1 迈上来要付 cost[i-1]，从 i-2 迈上来要付 cost[i-2]。
3. 答案是 dp[n]，即站到「顶部」这一虚拟位置的花费，不需要再付任何 cost。

拿示例 1 `cost = [10, 15, 20]` 走一遍：dp[0]=0，dp[1]=0；dp[2] = min(0+10, 0+15) = 10；dp[3] = min(dp[2]+cost[2], dp[1]+cost[1]) = min(10+20, 0+15) = 15。返回 15，与官方一致。

```python
n = len(cost)
prev2, prev1 = 0, 0          # dp[0], dp[1]
for i in range(2, n + 1):
    cur = min(prev1 + cost[i - 1], prev2 + cost[i - 2])
    prev2, prev1 = prev1, cur
return prev1
```

关键点：`cost[i-1]` 和 `cost[i-2]` 的下标是「迈出的那一阶」，不是目标阶；写成 `cost[i]` 会越界（i 最大到 n）。

## 复杂度
时间：O(n)，循环 n-1 次，每次常数次比较。
空间：O(1)，只滚动保留 prev2、prev1 两个值，没有开长度 n+1 的数组。

## 易错点
- 把 dp 定义成「离开第 i 阶的花费」→ 初值会写成 dp[0]=cost[0]、dp[1]=cost[1]，示例 1 得 10 而非 15。正确做法是 dp 表示「到达」，dp[0]=dp[1]=0，cost 只在转移时加。
- 循环上界写成 `range(2, n)` → 漏算 dp[n]，示例 1 返回 dp[2]=10。正确做法是 `range(2, n + 1)`，因为顶部是第 n 个虚拟位置。

## 如果面试官追问
问：要输出具体走法（经过哪些下标）怎么办？
答：dp 数组保留全量，转移时记录每步来自 i-1 还是 i-2，从 n 回溯到 0/1 即得路径，空间升到 O(n)。
