## 一句话思路
用哈希表累加每个后缀域名，按 `.` 从右往左切出所有父域名，同一域名多次出现直接相加。

## 怎么做
1. 对每条 `cpdomains[i]` 用 `split()` 拆成次数 `rep` 和域名 `domain`。
2. 把 `domain` 按 `.` 切成 `parts`，从右往左拼后缀，每拼一层就累加一次。
3. 用 `dict` 存 `后缀 -> 累计次数`，最后格式化成 `"次数 域名"`。

以示例 2 的 `"900 google.mail.com"` 为例：`parts = ["google","mail","com"]`，从右往左依次得到 `"com"`、`"mail.com"`、`"google.mail.com"`，三者各加 900；处理 `"1 intel.mail.com"` 时 `"mail.com"` 变成 901，`"com"` 变成 951。

```python
cnt = {}
for item in cpdomains:
    rep, domain = item.split()
    rep = int(rep)
    parts = domain.split(".")
    for i in range(len(parts)):
        sub = ".".join(parts[i:])
        cnt[sub] = cnt.get(sub, 0) + rep
return [f"{v} {k}" for k, v in cnt.items()]
```

关键在 `parts[i:]`：`i` 从 0 走到 `len(parts)-1`，正好覆盖 `google.mail.com`、`mail.com`、`com` 三层，不会漏也不会多。

## 复杂度
时间 O(n·L)：n 是 cpdomains 条数，L 是单条域名层数（≤3），每层拼接是 O(L)。
空间 O(n·L)：哈希表最多存 n·L 个不同后缀，外加输出列表。

## 易错点
- 输入 `"50 yahoo.com"` 这种两层域名 → 若固定按三层切会拼出 `"yahoo.com"` 之外的错误后缀或越界 → 必须用 `len(parts)` 动态决定循环次数，两层只产生 `"yahoo.com"` 和 `"com"`。
- 输入 `"900 google.mail.com"` 和 `"1 intel.mail.com"` 同时出现 → 若用 `cnt[sub] = rep` 覆盖赋值，`"mail.com"` 会错成 1 而不是 901 → 必须用 `cnt.get(sub, 0) + rep` 累加。

## 如果面试官追问
问：如果 cpdomains 长度到 10^5、域名层数到 10 呢？
答：方法不变，仍是 O(n·L) 哈希累加，只是拼接字符串的常数变大，可改用 `domain.find('.')` 逐步截断避免反复 `join`。
