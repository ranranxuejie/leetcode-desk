## 一句话思路
枚举「先加到 x 再复制 m 次」的 x，和 = x·(m+1)，代价 = (x−1)+m，取最小。

## 怎么做
1. 设先把唯一的 1 加到 x（花 x−1 次），再复制 m 次，数组变成 m+1 个 x，和 = x·(m+1)。
2. 对每个 x 从 1 到 k，m 取 `ceil(k/x) - 1`，即最少复制次数。
3. 代价 `(x-1) + (k-1)//x`，取全局最小。

以 k=11 为例：x=4 时 m = ceil(11/4)−1 = 2，代价 3+2=5；x=3 时 m=3，代价 2+3=5；x=6 时 m=1，代价 5+1=6。最小为 5。

```python
best = k - 1          # 只加不复制
for x in range(1, k + 1):
    m = (k + x - 1) // x - 1   # ceil(k/x) - 1
    best = min(best, (x - 1) + m)
return best
```

注意 `(k + x - 1) // x` 是向上取整，别写成 `k // x`，否则 k=11、x=4 时得 2 而非 3，m 少算一次。

## 复杂度
时间：O(k)，枚举 x 从 1 到 k，每次 O(1)。
空间：O(1)，只存 best 和循环变量。

## 易错点
- k=1 时若从 x=2 开始枚举会漏掉 0 次操作的情况 → 返回 1 → 正确做法是 best 初值设 `k-1`，x 从 1 开始，x=1 时 m=k−1、代价 k−1，与初值一致，返回 0。
- 向上取整写成 `k // x` → k=11、x=4 时 m=1，和只有 8 < 11，代价算成 4 偏小 → 必须用 `(k + x - 1) // x - 1`。

## 如果面试官追问
若 k 扩大到 10^9 怎么办？答：x 只需枚举到 ⌈√k⌉ 附近，因为 x 与 m 对称，最优解在 x≈√k 处取得，可 O(√k) 求解。
