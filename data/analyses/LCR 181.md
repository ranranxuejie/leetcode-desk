## 一句话思路
用 `split()` 按空白切分自动吞掉所有多余空格，再倒序拼接，天然满足「单词间单空格、首尾无空格」。

## 怎么做
1. 对 `message` 调用 `split()`，得到单词列表 `words`；无参 `split()` 会把连续空格、前导尾随空格全部吃掉。
2. 用 `words[::-1]` 反转列表顺序。
3. 用 `" ".join(...)` 以单个空格连接，得到结果。

以示例 1 `message = " the sky is blue "` 为例：`split()` 后 `words = ['the', 'sky', 'is', 'blue']`，反转得 `['blue', 'is', 'sky', 'the']`，`join` 后是 `"blue is sky the"`——注意原串首尾各一个空格、单词间各一个空格，共 5 个空格，输出只剩 3 个。

```python
words = message.split()          # 无参 split 自动丢弃空串
words.reverse()                  # 原地反转，等价 words[::-1]
return " ".join(words)
```

若面试官要求不用 `split`/`join`（主站 151 的常见追问），双指针版本：先整体反转字符串，再逐个单词内部反转，最后压缩空格。关键在压缩那步——用 `slow` 写指针、`fast` 读指针，遇到空格时只在 `slow > 0` 且前一字符非空格时写入一个空格，这样 `"  a  b  "` 会被压成 `"a b"`。

## 复杂度
时间 O(n)：`split` 扫一遍、`join` 扫一遍，n 为 `message` 长度。
空间 O(n)：`words` 列表存了全部单词，加上结果串本身。

## 易错点
- 输入 `"  "`（全空格）或 `""` → 若手写双指针压缩空格，容易在 `slow > 0` 判断上漏掉，输出 `" "` 而非 `""` → 用 `split()` 时 `words` 为空列表，`join` 直接返回 `""`，天然正确。
- 输入 `"a good   example"`（词间三个空格）→ 若用 `message.split(" ")` 会得到 `['a','good','','','example']`，反转后 `join` 出现连续空格 → 必须用无参 `split()`，它把任意长度空白当分隔符。

## 如果面试官追问
问：要求 O(1) 额外空间（不计返回串）怎么办？
答：先整体反转，再逐词反转，最后用读写双指针原地压缩空格，只用一个临时变量。
