## 一句话思路
按「最后一步加的是哪个数」做完全背包式 DP，`dp[s]` 累加所有 `nums[i]` 的来源，顺序自然被计入。

## 怎么做
1. 定义 `dp[s]` 为凑出和 `s` 的有序序列个数，`dp[0] = 1`（空序列是唯一底）。
2. 外层枚举和 `s` 从 1 到 `target`，内层枚举 `nums` 中的 `x`。
3. 若 `s >= x`，则 `dp[s] += dp[s - x]`；否则跳过。
4. 返回 `dp[target]`。

以 `nums = [1,2,3], target = 4` 为例，关键中间值：
- `dp[1] = dp[0] = 1`（序列 `(1)`）
- `dp[2] = dp[1] + dp[0] = 2`（`(1,1)`、`(2)`）
- `dp[3] = dp[2] + dp[1] + dp[0] = 4`（`(1,1,1)`、`(1,2)`、`(2,1)`、`(3)`）
- `dp[4] = dp[3] + dp[2] + dp[1] = 4 + 2 + 1 = 7`

```python
dp = [0] * (target + 1)
dp[0] = 1
for s in range(1, target + 1):
    for x in nums:
        if s >= x:
            dp[s] += dp[s - x]
return dp[target]
```

注意外层是 `s`、内层是 `nums`：这样 `dp[s-x]` 里已经包含「以任意数结尾」的序列，把 `x` 接在后面就得到新的有序序列，`(1,2)` 和 `(2,1)` 会被分别统计。若把两层循环对调（外层 `nums`、内层 `s`），就退化成组合数，示例 1 会得到 4 而不是 7。

## 复杂度
时间：`O(target * len(nums))`，两层循环各贡献一个因子。
空间：`O(target)`，只开一个长度 `target + 1` 的 `dp` 数组。

## 易错点
- 输入 `nums = [1,2,3], target = 4` → 若外层写 `nums`、内层写 `s`，得到 4（组合数），漏掉 `(1,2,1)`、`(2,1,1)`、`(3,1)` → 正确做法是外层枚举 `s`、内层枚举 `x`，让 `dp[s-x]` 已含全部顺序。
- 输入 `nums = [9], target = 3` → 若忘记 `if s >= x` 判断，`dp[s - 9]` 会取到负下标，Python 里变成从尾部取值，结果变成非 0 的垃圾数 → 必须先判 `s >= x` 再累加。

## 如果面试官追问
问：若 `nums` 含负数会怎样？
答：`dp` 会沿负方向无限展开、答案可能无穷，需额外限制每个数使用次数或序列长度上界。
