## 一句话思路
按「用了几个字母、每个字母用了几次」做多重集计数，再乘排列数，用 DP 逐字母累加。

## 怎么做
1. 状态 `dp[i][j]`：前 `i` 个字母共按了 `j` 次的不同内容数，初值 `dp[0][0] = 1`。
2. 枚举第 `i` 个字母按 `t` 次（`0 ≤ t ≤ min(k, j)`），转移 `dp[i][j] += dp[i-1][j-t] * C(j, t)`。
3. `C(j, t)` 是「这 `t` 个位置从 `j` 个位置里选」，因为新字母插入后相对顺序由组合数决定，不乘阶乘。
4. 答案取 `dp[26][n]`。

以 `k=1, n=2` 为例：`dp[1][1] = C(1,1) = 1`；处理第 2 个字母时 `dp[2][2] += dp[1][1] * C(2,1) = 2`，每个字母对贡献 2，26 个字母两两组合共 `C(26,2)*2 = 650`，与示例一致。

```python
MOD = 10**9 + 7
# 预处理组合数 C[j][t]，j 到 n
C = [[0]*(n+1) for _ in range(n+1)]
for j in range(n+1):
    C[j][0] = 1
    for t in range(1, j+1):
        C[j][t] = (C[j-1][t-1] + C[j-1][t]) % MOD

dp = [0]*(n+1)
dp[0] = 1
for _ in range(26):
    ndp = [0]*(n+1)
    for j in range(n+1):
        if dp[j] == 0:
            continue
        for t in range(min(k, n-j)+1):
            ndp[j+t] = (ndp[j+t] + dp[j]*C[j+t][t]) % MOD
    dp = ndp
return dp[n]
```

## 复杂度
时间：`O(26 * n * k)`，`n` 来自按键次数，`k ≤ 5` 是常数因子。
空间：`O(n^2)` 存组合数表，DP 数组额外 `O(n)`。

## 易错点
- `k=1, n=2` 时若转移写成 `dp[j]*C(j,t)` 而非 `C(j+t,t)`，会把「新字母放末尾」漏算，得到 26 而非 650；正确是插入到已有 `j+t` 个位置中选 `t` 个。
- `n=26*k` 时 26 个字母全用满，若循环上界写成 `range(26)` 但 `dp` 只开到 `n`，`j+t` 会越界；正确是内层 `t` 上界取 `min(k, n-j)`。

## 如果面试官追问
问：若要求输出所有方案而非计数？答：把 DP 值换成列表存字符串前缀，回溯时按 `C(j+t,t)` 展开，复杂度指数级。
