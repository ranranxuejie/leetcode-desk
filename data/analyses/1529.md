## 一句话思路
从左往右扫，当前位与「已翻转次数奇偶」不符就翻一次，翻转次数即答案。

## 怎么做
1. 维护 `flips`（已翻转次数），当前位的实际值 = `int(target[i]) ^ (flips & 1)`。
2. 从左到右遍历 `target`，若实际值与 `target[i]` 不等，则 `flips += 1`。
3. 遍历结束返回 `flips`。

以 `target = "10111"` 为例：i=0 时 `flips=0`，实际值 0 ≠ 1，翻一次 `flips=1`；i=1 时实际值 `1^1=0` 等于 target[1]=0，不翻；i=2 时实际值 `1^1=0` ≠ 1，`flips=2`；i=3 时实际值 `1^0=1` 等于 1，不翻；i=4 同理不翻，最终 `flips=3`。

```python
flips = 0
for ch in target:
    if int(ch) ^ (flips & 1):
        continue
    flips += 1
return flips
```

等价写法：只需比较相邻字符是否变化，`flips = (target[0] == '1') + sum(target[i] != target[i-1] for i in range(1, len(target)))`。两种写法结果一致，前者更直观。

## 复杂度
时间：O(n)，一次遍历，每个字符做一次异或比较。
空间：O(1)，只存 `flips` 一个整数。

## 易错点
- `target = "00000"` → 若初始就翻一次，会错成 1 → 正确做法是首位为 '0' 时不翻，`flips` 保持 0。
- `target = "101"` → 若只数 '1' 的个数会错成 2 → 正确做法是数「相邻位变化次数 + 首位是否为 1」，得 3。

## 如果面试官追问
问：若要求输出每次翻转的下标序列？答：在 `flips` 递增时记录当前下标 i，序列即为所有「实际值与 target 不符」的位置，按从左到右顺序。
