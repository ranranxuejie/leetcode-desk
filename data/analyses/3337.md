## 一句话思路
把 26 个字母的长度向量做 t 次线性变换，用矩阵快速幂加速，因为 t 可达 1e9。

## 怎么做
1. 定义 `cnt[26]` 为当前各字母出现次数，初始由 `s` 统计得到。
2. 一次转换的转移矩阵 `M`：字母 `i` 会拆成 `nums[i]` 个后续字母，故 `M[j][i] += 1` 对所有 `j = (i+1)..(i+nums[i])` 回绕后成立（列 `i` 是 `i` 的产出分布）。
3. 用快速幂算 `M^t`，再乘 `cnt` 得最终各字母计数，求和取模。
4. 关键中间值：示例 1 中 `nums[25]=2`，故 `M[0][25]=M[1][25]=1`，`z` 的计数会流向 `a`、`b`。

```python
MOD = 10**9 + 7
def mat_mul(A, B):
    C = [[0]*26 for _ in range(26)]
    for i in range(26):
        for k in range(26):
            if A[i][k]:
                for j in range(26):
                    C[i][j] = (C[i][j] + A[i][k]*B[k][j]) % MOD
    return C

M = [[0]*26 for _ in range(26)]
for i in range(26):
    for d in range(1, nums[i]+1):
        M[(i+d) % 26][i] += 1
R = [[1 if i == j else 0 for j in range(26)] for i in range(26)]
e = t
while e:
    if e & 1: R = mat_mul(R, M)
    M = mat_mul(M, M)
    e >>= 1
```

## 复杂度
时间：`O(26^3 log t + |s|)`，`log t` 来自快速幂，`|s|` 来自初始统计。
空间：`O(26^2)`，只存三个 26×26 矩阵。

## 易错点
- `nums[i]` 可能使 `i+d` 超过 25，必须 `% 26` 回绕；若写成 `M[i+d][i]` 会数组越界或漏掉 `z→a` 的转移，示例 1 的 `z` 就少算。
- 矩阵乘法顺序：`M^t * cnt` 中 `cnt` 是列向量，若把 `cnt` 当行向量左乘会得到转置结果，长度对但分布错，后续再乘就全错。

## 如果面试官追问
若 `t` 降到 1e5 但 `nums` 每次不同，怎么办？答：放弃矩阵幂，直接按 `cnt` 逐轮转移，`O(26t + |s|)` 即可。
