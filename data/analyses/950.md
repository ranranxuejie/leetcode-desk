## 一句话思路
把 deck 升序排好，用队列模拟「抽一张、下一张挪底」的下标序列，按该序列回填即可。

## 怎么做
1. 对 deck 升序排序，得到按显示顺序排列的值 `sorted_deck`。
2. 用 `deque(range(n))` 模拟下标牌堆，反复执行「弹出队首记入 `order`，若队列非空则把新队首挪到队尾」。
3. 把 `sorted_deck[i]` 填到 `ans[order[i]]` 的位置上。

以 `[17,13,11,2,3,5,7]` 为例，排序后是 `[2,3,5,7,11,13,17]`。下标队列初始 `[0,1,2,3,4,5,6]`：弹出 0，1 挪底 → `[2,3,4,5,6,1]`；弹出 2，3 挪底 → `[4,5,6,1,3]`；继续得到 `order = [0,2,4,6,3,1,5]`。于是 `ans[0]=2, ans[2]=3, ans[4]=5, ans[6]=7, ans[3]=11, ans[1]=13, ans[5]=17`，即 `[2,13,3,11,5,17,7]`，与官方输出一致。

```python
from collections import deque

n = len(deck)
sorted_deck = sorted(deck)
q = deque(range(n))
order = []
while q:
    order.append(q.popleft())
    if q:
        q.append(q.popleft())

ans = [0] * n
for i, pos in enumerate(order):
    ans[pos] = sorted_deck[i]
```

关键点：`order` 记录的是「第 i 个被显示的值应该放在原牌堆的哪个下标」，所以回填方向是 `ans[order[i]] = sorted_deck[i]`，不是 `ans[i] = sorted_deck[order[i]]`。

## 复杂度
时间 O(n log n)：排序占主导，队列模拟 O(n)。
空间 O(n)：`q`、`order`、`ans` 各开一个长度 n 的容器。

## 易错点
- 回填方向写反：若写成 `ans[i] = sorted_deck[order[i]]`，对示例会得到 `[2,5,3,13,11,17,7]`，第 2、4、6 位全错。正确是 `ans[order[i]] = sorted_deck[i]`，即用下标序列去定位值。
- 最后一张牌后仍执行挪底：当 `q` 只剩一个元素时弹出后若不加 `if q` 判断，`popleft()` 会抛 `IndexError`（n=1 时直接崩）。正确做法是挪底前判空，或循环条件写成「弹出后队列非空才挪」。

## 如果面试官追问
若 n 放大到 10^7、内存吃紧，怎么省掉 `order` 数组？答：不存下标序列，直接反向构造——从空的双端队列按 `order` 逆序把值塞回队首/队尾，空间仍是 O(n) 但少一个数组。
