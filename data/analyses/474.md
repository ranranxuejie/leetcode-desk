## 一句话思路
把每个字符串压成 (0 的个数, 1 的个数) 两个代价，做二维 0-1 背包，dp[j][k] 表示用 j 个 0、k 个 1 能选的最多字符串数。

## 怎么做
1. 先对每个 s 统计 `zeros = s.count('0')`、`ones = len(s) - zeros`，得到代价对。
2. 建 `dp = [[0]*(n+1) for _ in range(m+1)]`，dp[j][k] 是容量 (j,k) 下的最大子集长度。
3. 对每个字符串，j 从 m 倒序到 zeros、k 从 n 倒序到 ones，做 `dp[j][k] = max(dp[j][k], dp[j-zeros][k-ones] + 1)`。
4. 返回 `dp[m][n]`。

以示例 1 为例，处理到 `"0001"`（zeros=3, ones=1）时，j=5,k=3 处 `dp[5][3]` 由 `dp[2][2]+1` 更新为 2；再处理 `"1"`（0,1）后 `dp[5][3]` 变 3；最后 `"0"`（1,0）把它推到 4。

```python
dp = [[0] * (n + 1) for _ in range(m + 1)]
for s in strs:
    zeros = s.count('0')
    ones = len(s) - zeros
    if zeros > m or ones > n:
        continue
    for j in range(m, zeros - 1, -1):
        for k in range(n, ones - 1, -1):
            dp[j][k] = max(dp[j][k], dp[j - zeros][k - ones] + 1)
return dp[m][n]
```

关键在倒序：j、k 都从大往小走，保证 `dp[j-zeros][k-ones]` 还是「没放当前字符串」的旧值，每个字符串只用一次。

## 复杂度
时间 O(len(strs) · m · n)，每个字符串扫一遍 m×n 的状态格。
空间 O(m · n)，只开一个二维 dp 表，字符串计数是 O(1) 临时变量。

## 易错点
- 内层 j、k 写成正序（`range(zeros, m+1)`）→ 同一个字符串被重复计入，示例 2 的 `["10","0","1"]` 会错成 3 而不是 2 → 必须倒序，让 `dp[j-zeros][k-ones]` 读到上一轮的值。
- 漏掉 `if zeros > m or ones > n: continue` → 对 `"111001"`（zeros=2, ones=4，n=3）会去访问 `dp[j-2][k-4]`，k-4 为负，Python 负索引会静默读到表尾，答案偏大 → 先剪掉单串就超容量的项。

## 如果面试官追问
问：要求输出具体选了哪些字符串怎么办？
答：再开一个 `(m+1)×(n+1)` 的列表存每格选中的下标，更新 dp 时同步拷贝，最后从 `dp[m][n]` 回溯。
