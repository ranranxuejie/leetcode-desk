## 一句话思路
用滑动窗口维护当前斐波那契段，窗口右端每扩一格就检查 `nums[r] == nums[r-1] + nums[r-2]`，不成立就重置窗口起点。

## 怎么做
1. 长度小于 3 直接返回 `len(nums)`，因为长度 1、2 恒为斐波那契。
2. 令 `ans = 2`，`start = 0`，从 `r = 2` 开始向右扫描。
3. 若 `nums[r] == nums[r-1] + nums[r-2]`，窗口继续延伸，更新 `ans = max(ans, r - start + 1)`。
4. 否则窗口断裂，把 `start` 移到 `r - 1`（保留最后两个数作为新窗口的前两项），再继续。

以示例 1 `nums = [1,1,1,1,2,3,5,1]` 为例：`r=2` 时 `1 != 1+1`，`start` 变成 1；`r=3` 时 `1 != 1+1`，`start` 变成 2；`r=4` 时 `2 == 1+1` 成立，窗口 `[2..4]` 长度 3；`r=5` 时 `3 == 1+2`，长度 4；`r=6` 时 `5 == 2+3`，长度 5，`ans` 定格在 5；`r=7` 时 `1 != 3+5`，`start` 变成 6。

```python
n = len(nums)
if n < 3:
    return n
ans, start = 2, 0
for r in range(2, n):
    if nums[r] == nums[r - 1] + nums[r - 2]:
        ans = max(ans, r - start + 1)
    else:
        start = r - 1
return ans
```

关键点：断裂时 `start = r - 1` 而不是 `r`，因为 `nums[r-1]` 和 `nums[r]` 这两个数本身仍可能作为下一段的前两项。

## 复杂度
时间 O(n)：`r` 从 2 到 n-1 单趟扫描，`start` 只增不减。
空间 O(1)：只用了 `ans`、`start`、`r` 三个变量。

## 易错点
- 输入 `[1,1,1,1,2,3,5,1]` → 若断裂时写 `start = r`，会丢掉 `nums[r-1]` 这个潜在首项，示例 1 只能得到 4 而非 5 → 正确做法是 `start = r - 1`，让新窗口从 `r-1` 起算。
- 输入 `[1000000000,1000000000,1000000000]` → 若把 `ans` 初值设成 0 或 1，或忘记 `n < 3` 的提前返回，会输出 1 或 0 → 正确做法是 `ans` 初值取 2，并对 `n < 3` 直接返回 `n`。

## 如果面试官追问
问：如果要求返回最长斐波那契子数组本身而不是长度？
答：在更新 `ans` 时同步记录 `best_start = start`、`best_end = r`，最后返回 `nums[best_start:best_end+1]`，空间仍是 O(1) 额外变量。
