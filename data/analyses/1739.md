## 一句话思路
贴着墙角堆，第 k 层最多放 k(k+1)/2 个盒子，用二分找能装下 n 的最大层数，再补剩余。

## 怎么做
1. 把盒子堆成靠墙角的阶梯：第 i 层（从 1 数）最多放 i(i+1)/2 个，前 k 层累计 f(k)=k(k+1)(k+2)/6。
2. 二分找最大的 k 使 f(k) ≤ n，这 k 层全部堆满。
3. 剩余 r = n - f(k)，在第 k+1 层从 1 开始往上补，每多放一个盒子需要多一个地面盒子，直到 r 用完。
4. 答案 = f(k) 对应的地面盒子数（即 k(k+1)/2）加上补 r 时新增的地面盒子。

以 n=10 为例：f(2)=4，f(3)=10，所以 k=3 时恰好装满，地面盒子 = 3·4/2 = 6，与示例一致。若 n=11，f(3)=10，r=1，第 4 层放 1 个，需新增 1 个地面盒子，答案 7。

```python
def minimumBoxes(n):
    # 二分找最大 k 使 k(k+1)(k+2)/6 <= n
    lo, hi = 1, 2000
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if mid * (mid + 1) * (mid + 2) // 6 <= n:
            lo = mid
        else:
            hi = mid - 1
    k = lo
    used = k * (k + 1) * (k + 2) // 6
    floor_boxes = k * (k + 1) // 2
    r = n - used
    # 第 k+1 层补 r 个，需要额外地面盒子
    i = 1
    while r > 0:
        r -= i
        floor_boxes += 1
        i += 1
    return floor_boxes
```

## 复杂度
时间：二分 O(log n)，补剩余最多 O(√n)，总 O(log n + √n)。
空间：O(1)，只用了几个整型变量。

## 易错点
- n=1 时二分下界 lo=1 直接返回 k=1，f(1)=1，floor_boxes=1，正确；但若把 lo 初始化为 0 且 hi 设太小（如 100），大 n 会漏解，hi 要取到约 2000（f(2000)≈1.3e9 > 1e9）。
- 补剩余时用 while r>0 每次减 i 并 floor_boxes+=1，i 从 1 递增；若写成 r -= k+1 固定步长，n=11 时 r=1 会多算地面盒子，正确答案 7 会错成 8。

## 如果面试官追问
问：n 到 1e18 怎么办？答：二分上界改成约 2e6，公式用 Python 大整数直接算，O(log n) 不变。
