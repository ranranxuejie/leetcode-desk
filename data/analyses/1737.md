## 一句话思路
对 26 个字母做计数，枚举分界点 k，用前缀和算出「a 全 ≤k、b 全 >k」的改动量，取三种条件最小值。

## 怎么做
1. 统计 `ca[26]`、`cb[26]`，并求前缀和 `pa[i]`、`pb[i]`（表示字母 ≤ i 的字符数）。
2. 条件一：枚举分界 k（0..24），a 中 >k 的字符要改小、b 中 ≤k 的字符要改大，代价 = `(len(a)-pa[k]) + pb[k]`。
3. 条件二对称：代价 = `(len(b)-pb[k]) + pa[k]`，同样取最小。
4. 条件三：枚举目标字母 c，代价 = `len(a)-ca[c] + len(b)-cb[c]`，取最小。

以 `a="aba", b="caa"` 为例：`ca=[2,1,0...]`、`cb=[2,0,1,...]`。k=2 时 `pa[2]=3`、`pb[2]=2`，条件一代价 = `(3-3)+2=2`，正好对上示例答案 2（把 b 的两个 'a' 改成 'c' 之外的大字母，实际是把 b 的 'a' 提到 'c' 以上）。

```python
ca, cb = [0]*26, [0]*26
for ch in a: ca[ord(ch)-97] += 1
for ch in b: cb[ord(ch)-97] += 1
pa, pb = ca[:], cb[:]
for i in range(1, 26):
    pa[i] += pa[i-1]; pb[i] += pb[i-1]
ans = min(len(a)-ca[c] + len(b)-cb[c] for c in range(26))
for k in range(25):
    ans = min(ans, len(a)-pa[k] + pb[k], len(b)-pb[k] + pa[k])
return ans
```

注意 k 只到 24：k=25 时条件一要求 a 全 ≤ 'z' 且 b 全 > 'z'，后者不可能，所以不枚举。

## 复杂度
时间 O(n + m + 26)，n、m 分别是 a、b 长度，26 是常数。
空间 O(1)，只开了 4 个长度 26 的数组。

## 易错点
- 分界 k 枚举到 25 → 条件一算出 `len(a)-pa[25] + pb[25] = 0 + len(b)`，看似合法其实要求 b 全 > 'z' 不存在，会漏掉正确分界；正确做法是 `range(25)`。
- 条件三只改一边 → 比如只算 `len(a)-ca[c]`，忘了 b 也要统一到 c；正确做法是两边代价相加，示例 1 中 c='a' 时是 `1+2=3`，而 c='c' 时 `3+2=5`，最小值 2 来自条件一而非条件三。

## 如果面试官追问
问：如果要求输出具体改动方案怎么办？
答：记录取得最小值的分支类型和 k（或 c），再遍历原串，把不满足该分支的字符逐个替换成边界字母即可。
