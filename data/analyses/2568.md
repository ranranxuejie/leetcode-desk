## 一句话思路
从小到大枚举 2 的幂 `p`，只要 `p` 在 `nums` 里就继续，第一个不在的就是答案。

## 怎么做
1. 把 `nums` 转成 `set`，后面只做 `in` 判断。
2. 令 `p = 1`，循环检查 `p` 是否在集合里。
3. 在就 `p *= 2`，不在就返回 `p`。
4. 循环必然终止：`nums` 最多 10^5 个数，而 2 的幂超过 10^9 后一定不在集合里。

以 `nums = [2,1]` 为例：`p=1` 在集合中 → `p=2`；`p=2` 在集合中 → `p=4`；`p=4` 不在，返回 4。中间值只有 `p` 这一个变量，从 1 走到 4。

为什么只看 2 的幂：任何数 `x` 的二进制最低位 1 对应某个 `2^k`，而 `x` 的或值里要出现这一位，必须由某个含该位的 `nums[i]` 提供。若 `2^k` 本身不在数组里，比它小的所有数都能表达时，`2^k` 就是第一个缺口——因为小于 `2^k` 的数只用到低 `k` 位，而低 `k` 位的每个 2 的幂都在数组里，任意组合都能或出来。

```python
s = set(nums)
p = 1
while p in s:
    p *= 2
return p
```

注意 `p` 用 Python 整数，`10^9` 以上的 2 的幂（如 `2**30`）不会溢出，循环最多约 31 次。

## 复杂度
时间：O(n + log(max(nums)))，n 来自建集合，log 来自枚举 2 的幂。
空间：O(n)，集合存全部元素。

## 易错点
- 输入 `nums = [5,3,2]` → 若从 1 开始但误判「数组里有 2 就能凑出 1」会返回 2 或更大 → 正确做法是直接查 `1 in s`，1 不在就返回 1，因为或运算只会让位变多不会变少。
- 输入 `nums = [1,1,1]` → 若用 `for x in nums` 逐个乘 2 累加会算错 → 正确做法是固定 `p` 从 1 起翻倍，与数组元素个数无关，重复元素被集合去重后不影响结果。

## 如果面试官追问
问：如果要求返回所有不可表达的 2 的幂？答：循环不提前返回，把每个缺失的 `p` 收集进列表，直到 `p > 2**31 - 1` 为止。
