## 一句话思路
用哈希表把每个值映射到它的下标列表，只对长度恰为 3 的列表检查 `pos[2]-pos[1] == pos[1]-pos[0]`。

## 怎么做
1. 遍历 `nums`，用 `defaultdict(list)` 把值 `v` 的下标 `i` 追加进 `pos[v]`。
2. 遍历 `pos` 的每个 `(v, idxs)`，先筛掉 `len(idxs) != 3` 的。
3. 对剩下的只比较两个差值是否相等，相等则计数加一。

以示例 1 `nums = [1,8,1,5,1,5,8,5]` 为例，建表后 `pos[1] = [0,2,4]`、`pos[5] = [3,5,7]`、`pos[8] = [0,6]`。`8` 因长度 2 被筛掉；`1` 的 `2-0 == 4-2` 成立，`5` 的 `5-3 == 7-5` 成立，答案 2。

```python
from collections import defaultdict

pos = defaultdict(list)
for i, v in enumerate(nums):
    pos[v].append(i)

ans = 0
for idxs in pos.values():
    if len(idxs) == 3 and idxs[2] - idxs[1] == idxs[1] - idxs[0]:
        ans += 1
```

关键点：`len(idxs) == 3` 必须写在前面，`and` 短路保证不会对长度 2 的列表取 `idxs[2]`。

## 复杂度
时间 O(n)：一次遍历建表，再扫一遍总长 n 的下标列表。
空间 O(n)：`pos` 存了全部 n 个下标，外加至多 n 个键。

## 易错点
- 输入 `[8,8,8,8]` → 若只判断「前三个下标等间隔」就计数，会错答 1 → 必须先卡 `len(idxs) == 3`，四次出现直接排除。
- 输入 `[8,6,6,8,8]` → 若用 `idxs[1]-idxs[0] == idxs[2]-idxs[1]` 但漏了长度检查，`6` 的 `[1,2]` 会越界或误判 → 长度过滤和差值比较缺一不可，`8` 的 `[0,3,4]` 差值是 3 和 1，正确判否。

## 如果面试官追问
若要求返回这些特别整数本身而非个数？答：把 `ans += 1` 换成 `ans.append(v)`，其余逻辑不变，输出顺序即字典遍历顺序。
