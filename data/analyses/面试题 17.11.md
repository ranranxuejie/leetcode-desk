## 一句话思路
一次线性扫描，用两个下标分别记住最近一次见到的 `word1`、`word2` 位置，每遇到其中一个就更新答案。

## 怎么做
1. 初始化 `p1 = p2 = -1`，`ans = len(words)`（上界，比任何真实距离都大）。
2. 从左到右遍历 `i, w`，`w == word1` 就更新 `p1 = i`，`w == word2` 就更新 `p2 = i`。
3. 每次更新后若两个下标都非 -1，用 `abs(p1 - p2)` 更新 `ans`。
4. 扫完返回 `ans`。

拿官方示例走一遍：`words = ["I","am","a","student",...]`，`word1="a"`，`word2="student"`。扫到 `i=2` 时 `p1=2`，`p2` 仍是 -1，跳过；扫到 `i=3` 时 `p2=3`，此时 `abs(2-3)=1`，`ans` 从 10 降到 1。后面 `i=5`、`i=8` 的 `"a"` 只会把 `p1` 推远，`abs(5-3)=2`、`abs(8-3)=5` 都打不破 1，最终返回 1。

```python
p1 = p2 = -1
ans = len(words)
for i, w in enumerate(words):
    if w == word1:
        p1 = i
    elif w == word2:
        p2 = i
    if p1 != -1 and p2 != -1:
        ans = min(ans, abs(p1 - p2))
return ans
```

关键点：`elif` 不能写成两个独立 `if` 也无所谓，因为题目保证 `word1 != word2`，同一个 `i` 不可能同时命中两者；但保留 `elif` 更省一次比较。真正不能省的是「更新下标后立刻算距离」——若把算距离挪到循环外，就只剩最后一对位置，示例会错成 5。

## 复杂度
时间 O(n)：n 为 `words.length`，每个单词只被看一次。
空间 O(1)：只开了 `p1`、`p2`、`ans`、`i` 四个标量。

## 易错点
- 输入 `words = ["a","b"]`、`word1="a"`、`word2="b"` → 若 `ans` 初值写成 `0`，`min(0, 1)` 永远是 0，返回错误 → 初值必须取 `len(words)` 或 `2**31 - 1` 这类严格上界。
- 输入 `words = ["a","x","a","b"]`、`word1="a"`、`word2="b"` → 若只在「第一次见到」时记录下标，`p1` 停在 0，算出 `abs(0-3)=3`，而正确答案是 `abs(2-3)=1` → 必须每次命中都覆盖下标，保留最近一次。

## 如果面试官追问
问：多次查询不同单词对怎么优化？
答：预处理成 `{单词: [出现下标]}`，查询时对两个有序下标表做双指针归并，O(len1+len2) 而非 O(n)。
