## 一句话思路
用 `dp[i][j]` 记录以 `arr[i], arr[j]` 结尾的斐波那契子序列长度，靠哈希表 O(1) 找前驱 `arr[j]-arr[i]`。

## 怎么做
1. 建 `pos = {v: idx}`，把每个值映射到下标，用于反查前驱。
2. 枚举结尾对 `(i, j)`，`i < j`，令 `need = arr[j] - arr[i]`。
3. 若 `need` 在 `pos` 且 `pos[need] < i`，则 `dp[i][j] = dp[pos[need]][i] + 1`，否则 `dp[i][j] = 2`。
4. 全程维护 `best`，最后 `best >= 3` 返回 `best`，否则返回 0。

以 `arr = [1,2,3,4,5,6,7,8]` 为例，处理 `(i=2, j=4)` 即 `arr[i]=3, arr[j]=5` 时，`need = 5-3 = 2`，`pos[2]=1 < 2`，于是 `dp[2][4] = dp[1][2] + 1`；而 `dp[1][2]` 对应 `(2,3)`，`need=1`，`pos[1]=0`，得 `dp[1][2]=3`，故 `dp[2][4]=4`，继续到 `(3,7)` 即 `(5,8)` 得 5。

```python
pos = {v: i for i, v in enumerate(arr)}
dp = [[2] * n for _ in range(n)]
best = 0
for j in range(n):
    for i in range(j):
        need = arr[j] - arr[i]
        k = pos.get(need, -1)
        if k != -1 and k < i:
            dp[i][j] = dp[k][i] + 1
            best = max(best, dp[i][j])
return best if best >= 3 else 0
```

## 复杂度
时间 O(n²)：枚举 `(i, j)` 对，每次哈希查找 O(1)。
空间 O(n²)：`dp` 二维表占 n²，`pos` 占 n。

## 易错点
- `arr = [1,2,3]` 这类只有三项的输入 → 若直接返回 `best` 而 `best` 初值为 0 且从不更新到 3，会错成 0 或 2 → 正确做法是初值设 2、最后判 `best >= 3`，因为任意两项都构成长度 2 的平凡序列，但题目要求 n≥3。
- `arr = [1,3,7,11,12,14,18]` → 若只判 `need in pos` 而不判 `pos[need] < i`，会把 `need` 落在 `i` 之后的下标当成前驱，导致 `dp` 引用未算好的状态、长度虚高 → 必须加 `k < i` 保证前驱在 `i` 左侧，顺序才合法。

## 如果面试官追问
问：要求输出最长序列本身而非长度？答：在 `dp` 更新时额外存前驱下标 `(k, i)`，最后从 `best` 对应的 `(i, j)` 沿链回溯即可。
