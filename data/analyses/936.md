## 一句话思路
逆向做：从 target 出发，把能整段匹配 stamp 的位置「擦成 ?」，用队列维护可擦位置，最后反转顺序。

## 怎么做
1. 预处理 `match[i]` = 以 i 为起点、长度 m 的窗口里与 stamp 逐位相等或为 `?` 的位数，初始扫描一遍。
2. 队列存所有 `match[i] == m` 的起点，逐个出队：若该窗口还没被擦过，就把它整段置 `?`，记录 i。
3. 擦完后更新受影响窗口 `i-m+1 .. i+m-1` 的 `match`，新满 m 的入队。
4. 全部擦完则答案逆序，否则返回 `[]`。

以 `stamp="abc", target="ababc"` 为例：初始 `match[0]=3`（"aba" 中 a、b 对，第三位 a≠c 但…实际 `match[0]=2`），`match[2]=3`（"abc" 全对）。先出队 2，把 `target[2:5]` 擦成 `"ab???"`，此时 `match[0]` 因第三位变 `?` 升到 3，入队；再出队 0，全擦完，答案逆序得 `[0,2]`。

```python
from collections import deque
m, n = len(stamp), len(target)
match = [0] * (n - m + 1)
for i in range(n - m + 1):
    match[i] = sum(stamp[j] == target[i + j] for j in range(m))
q = deque(i for i in range(n - m + 1) if match[i] == m)
done = [False] * (n - m + 1)
ans = []
while q:
    i = q.popleft()
    if done[i]:
        continue
    done[i] = True
    ans.append(i)
    for j in range(i, i + m):
        if target[j] != '?':
            target = target[:j] + '?' + target[j+1:]
            for k in range(max(0, j - m + 1), min(j, n - m) + 1):
                if not done[k]:
                    match[k] += 1
                    if match[k] == m:
                        q.append(k)
return ans[::-1] if len(ans) == n - m + 1 else []
```

## 复杂度
时间 O(n·m)：每个位置最多被擦一次，每次擦更新 O(m) 个窗口。
空间 O(n)：`match`、`done`、队列各 O(n)，target 原地改。

## 易错点
- `stamp="abca", target="aabcaca"`：若只按「窗口完全等于 stamp」判断可擦，`match[3]` 的 "caca" 永远不满 4，卡死。正确做法是把已擦成 `?` 的位算作匹配，`match` 才涨得上去。
- 同一窗口可能被多次入队（如 `stamp="aa", target="aaa"` 中 0、1 互相触发）。若不判 `done[i]` 就重复擦、重复 append，答案长度超过 `n-m+1`，被误判为无解。正确做法是出队先查 `done`。

## 如果面试官追问
问：target 长度到 10^5 怎么办？答：把逐位改字符串换成并查集「下一个未擦位置」跳指针，更新窗口时只碰真正变 `?` 的位，摊还 O(n·m) 降到 O(n α)。
