## 一句话思路
按值从小到大处理下标，用单调栈维护「右侧更小」和「左侧更大」的可达链，答案沿链传递。

## 怎么做
1. 把下标按 `nums` 值升序排序，值相同的下标一起处理，避免同值互相跳（题面要求严格不等）。
2. 对每个下标 `i`，在它右侧找所有 `nums[j] < nums[i]` 的 `j`，取 `ans[j]` 的最大值；用单调栈从右往左扫，栈里存「右侧已处理且值更小」的下标。
3. 同理对左侧找 `nums[j] > nums[i]` 的 `j`，从左往右扫一遍。
4. `ans[i] = max(nums[i], 右侧链最大值, 左侧链最大值)`。

以 `nums = [2,3,1]` 为例：先处理值 1 的下标 2，右侧无更小、左侧下标 1 值 3 更大，`ans[2] = max(1,3) = 3`；再处理值 2 的下标 0，右侧下标 2 值 1 更小，取 `ans[2] = 3`，得 `ans[0] = 3`；最后下标 1 值 3 最大，`ans[1] = 3`。

```python
order = sorted(range(n), key=lambda i: nums[i])
ans = nums[:]
for i in order:
    # 右侧更小：栈顶是已处理过的更小值下标
    while st and nums[st[-1]] < nums[i]:
        ans[i] = max(ans[i], ans[st.pop()])
    st.append(i)
```

## 复杂度
时间：排序 `O(n log n)`，两次单调栈各 `O(n)`，总 `O(n log n)`。
空间：`ans`、`order`、栈各 `O(n)`。

## 易错点
- 输入 `[2,2,2]` → 若按值排序后同值下标互相传递，会错成 `[2,2,2]` 之外的假链 → 正确做法是值相同的下标批量处理，同值之间不建边。
- 输入 `[1,2,3]` → 只做「右侧更小」会漏掉向左跳更大值，`ans[0]` 错成 1 → 必须补一遍「左侧更大」的扫描，`ans[0]` 应为 3。

## 如果面试官追问
问：能否做到 `O(n)`？答：可以，用并查集按值从小到大合并相邻可达下标，均摊近线性。
