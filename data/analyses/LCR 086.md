## 一句话思路
从下标 0 开始 DFS，每层枚举下一个切点 j，只要 `s[start:j+1]` 是回文就切下去，走到 `len(s)` 就收一份方案。

## 怎么做
1. 用 `path` 存当前已切好的回文段，`start` 表示下一段从哪开始。
2. 每层枚举终点 `j` 从 `start` 到 `n-1`，判断 `s[start:j+1]` 是否回文。
3. 是回文就 `path.append(s[start:j+1])`，递归 `dfs(j+1)`，返回后 `pop` 回溯。
4. `start == n` 时把 `path[:]` 拷进答案，必须拷贝，否则后续 pop 会改掉已存结果。

以 `s = "aab"` 为例：`start=0` 时 `j=0` 得 `"a"` 是回文，进入 `start=1`；`j=1` 得 `"aa"` 也是回文，进入 `start=2`，此时 `j=2` 取 `"b"`，走到 `start=3` 收下 `["aa","b"]`。关键中间值是 `start=1, j=1` 时 `s[1:2] == "a"` 为真，所以 `"aa"` 这条分支能继续。

```python
def dfs(start):
    if start == n:
        res.append(path[:])
        return
    for j in range(start, n):
        sub = s[start:j + 1]
        if sub == sub[::-1]:
            path.append(sub)
            dfs(j + 1)
            path.pop()
```

`sub == sub[::-1]` 是最省事的回文判断，n ≤ 16 时切片反转的开销可以忽略；想更快可预处理 `dp[i][j]` 表示 `s[i:j+1]` 是否回文。

## 复杂度
时间：O(n · 2^n)，共 2^(n-1) 种切法，每种切法每段判回文最多 O(n)。
空间：O(n) 递归栈加 `path`，答案本身占 O(n · 2^n)。

## 易错点
- `s = "aab"` 时若在 `start == n` 处写 `res.append(path)` 而不拷贝，最终所有结果都会变成空列表：因为回溯的 `path.pop()` 把同一份列表清空了，正确做法是 `path[:]`。
- `s = "google"` 时若只枚举「最长回文前缀」再递归，会漏掉 `["g","oo","g","l","e"]`：`j` 必须从 `start` 一路枚举到 `n-1`，每个回文终点都是一条独立分支，不能只取一个。

## 如果面试官追问
问：n 放大到 2000，只要方案数不要具体方案怎么办？
答：DFS 改成记忆化，`f(start)` 返回从 start 起的方案数，累加所有回文终点的 `f(j+1)`，回文判断用预处理 dp 或中心扩展。
