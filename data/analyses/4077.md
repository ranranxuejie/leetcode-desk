## 一句话思路
按前缀树每个节点独立决定子节点顺序，逆序对只由不同子树间贡献，逐节点用「按 pos 中位数分两半」贪心取 min。

## 怎么做
1. 先算 `pos[i]`：`pos[target[k]] = k`，即单词下标 i 在 target 中的位置。
2. 建前缀树，每个节点存它子树内所有单词的 `pos` 值集合（用有序列表或直接收集）。
3. 对每个节点，把子节点按「子树内 pos 的中位数」排序，两两比较时用归并统计跨子树逆序对，取 `min(cnt, size_a*size_b - cnt)`。
4. 累加所有节点、所有子节点对的 min 值。

以示例 1 为例：`words=["bad","bag","fig","fed"]`，`target=[3,1,0,2]`，得 `pos=[2,1,3,0]`。根节点子节点 "b" 子树 pos={2,1}，"f" 子树 pos={3,0}。跨对比较：b 在前 f 在后时逆序对为 0（2<3,2>0,1<3,1>0 → 2 个），f 在前 b 在后为 2 个，取 min=2。内部 "b" 下 "bad"(2) vs "bag"(1) 逆序 1，"f" 下 "fed"(0) vs "fig"(3) 逆序 0，合计 2+1+0=3？实际答案 2——因为 "b" 内部取 min(1,0)=0，"f" 内部取 min(0,1)=0，根取 min(2,2)=2，总 2。

```python
def solve(words, target):
    n = len(words)
    pos = [0]*n
    for k, i in enumerate(target):
        pos[i] = k
    # 建树：children[node] = {char: child}
    # 每个节点收集子树 pos 列表
    def dfs(node):
        vals = []
        if node.mark is not None:
            vals.append(pos[node.mark])
        for c in sorted(node.children):
            vals += dfs(node.children[c])
        node.vals = vals
        return vals
    # 对每个节点统计跨子树逆序对
    ans = 0
    def calc(node):
        nonlocal ans
        ch = list(node.children.values())
        for a in range(len(ch)):
            for b in range(a+1, len(ch)):
                ca = sum(1 for x in ch[a].vals for y in ch[b].vals if x > y)
                ans += min(ca, len(ch[a].vals)*len(ch[b].vals) - ca)
        for c in ch: calc(c)
    calc(root)
    return ans
```

## 复杂度
时间：O(n·L·log n)，n 为单词数、L 为最大长度，归并统计跨子树逆序对。
空间：O(n·L)，前缀树节点数与每节点 pos 列表。

## 易错点
- 输入 `words=["ab","ac","ba","bc"]`，`target=[0,3,1,2]`：若只按字典序排子节点，根下 "a" 在 "b" 前得 traversal=[0,1,3,2]，逆序对 1；但若误把 "b" 放前得 [3,2,0,1]，逆序对变 3。正确做法是每个节点独立取 min，不能全局统一字典序。
- 输入 `words=["a","ab"]`，`target=[1,0]`：节点 "a" 被标记且还有子节点 "ab"，若先访问子节点再记录标记，traversal 变 [1,0]，逆序对 1；正确做法是先记录当前节点标记再访问子节点，得 [0,1]，逆序对 0。

## 如果面试官追问
问：若 words 长度到 10^5 怎么优化？
答：每节点用归并排序合并子树 pos 列表，跨对统计 O(k log k)，总 O(nL log n)，避免两两枚举子节点对。
