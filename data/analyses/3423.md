## 一句话思路
遍历 `i` 从 0 到 n-1，用 `abs(nums[i] - nums[(i+1) % n])` 取最大，取模把首尾接上。

## 怎么做
1. 初始化 `best = 0`，`n = len(nums)`。
2. 循环 `i in range(n)`，下标 `(i+1) % n` 让 `i = n-1` 时回到 0。
3. 每轮算 `d = abs(nums[i] - nums[(i+1) % n])`，用 `best = max(best, d)` 更新。
4. 返回 `best`。

以 `nums = [1,2,4]` 为例：`i=0` 得 `|1-2|=1`，`best=1`；`i=1` 得 `|2-4|=2`，`best=2`；`i=2` 时 `(2+1)%3=0`，得 `|4-1|=3`，`best=3`，正是首尾这一对贡献了答案。

```python
n = len(nums)
best = 0
for i in range(n):
    d = abs(nums[i] - nums[(i + 1) % n])
    if d > best:
        best = d
return best
```

也可以先算 `range(n-1)` 的普通相邻对，再单独补一次 `abs(nums[-1] - nums[0])`，两种写法等价；取模版少写一行，但 `% n` 每轮都要算一次，n ≤ 100 时无差别。

## 复杂度
时间 O(n)：一次遍历，每个元素访问两次。
空间 O(1)：只开了 `best`、`d`、`n` 三个变量。

## 易错点
- 只写 `range(n-1)` 而漏掉首尾对：`nums = [1,2,4]` 会返回 2 而不是 3，因为 `|4-1|` 这一对根本没被算到。正确做法是循环到 `n` 并用 `(i+1) % n`，或循环后补一行 `abs(nums[-1] - nums[0])`。
- 把 `best` 初始化成 0 后忘了负数情形：`nums = [-5,-10,-5]` 的差值都是非负的所以没事，但若误写成 `best = nums[0]` 再拿它和差值比，就会把元素值当差值用，`[-5,-10,-5]` 会错成 -5。正确做法是 `best` 初值取 0（差值绝对值恒 ≥ 0），或初值取第一对差值。

## 如果面试官追问
问：如果要求返回产生最大差值的下标对而不是差值本身？
答：在更新 `best` 时同步记下 `i` 和 `(i+1) % n`，返回 `(i, j)`，逻辑不变。
