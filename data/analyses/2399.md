## 一句话思路
用长度 26 的数组 `first` 记录每个字母首次出现的下标，第二次遇到时算间隔与 `distance` 比对。

## 怎么做
1. 初始化 `first = [-1] * 26`，`-1` 表示该字母还没出现过。
2. 从左到右遍历 `s`，用 `i` 作下标、`c = ord(ch) - ord('a')` 作字母编号。
3. 若 `first[c] == -1`，把 `first[c] = i`；否则当前是第二次出现，检查 `i - first[c] - 1 == distance[c]`，不等直接返回 `False`。
4. 全部遍历完返回 `True`。

拿示例 1 的 `s = "abaccb"` 走一遍关键中间值：`i=0` 时 `first[0]=0`；`i=2` 再次遇到 `'a'`，`2 - 0 - 1 = 1`，等于 `distance[0]=1`，通过；`i=4` 遇到第二个 `'c'`，`4 - 3 - 1 = 0`，等于 `distance[2]=0`，通过；`i=5` 遇到第二个 `'b'`，`5 - 1 - 1 = 3`，等于 `distance[1]=3`，通过。三个字母全过，返回 `True`。

```python
first = [-1] * 26
for i, ch in enumerate(s):
    c = ord(ch) - ord('a')
    if first[c] == -1:
        first[c] = i
    elif i - first[c] - 1 != distance[c]:
        return False
return True
```

注意间隔是「两次出现之间的字母数量」，所以减 1；示例 2 的 `"aa"` 中 `1 - 0 - 1 = 0`，而 `distance[0]=1`，立刻返回 `False`。

## 复杂度
时间：O(n)，n 为 `s` 长度，每个字符只处理一次，`distance` 的 26 项不参与遍历。
空间：O(1)，额外只开 `first` 这 26 个槽位，与 n 无关。

## 易错点
- 把间隔写成 `i - first[c]` 而不是 `i - first[c] - 1` → 示例 2 的 `"aa"` 会算成 1 与 `distance[0]=1` 相等，错误返回 `True`；正确做法是减 1 得到「中间字母数」。
- 对 `s` 中没出现的字母也去校验 `distance` → 示例 1 里 `'d'` 未出现但 `distance[3]=5`，若遍历 `distance` 找非零项就会误判 `False`；正确做法是只遍历 `s`，`first[c] == -1` 的字母直接跳过。

## 如果面试官追问
问：若 `s` 中字母出现次数不保证恰好两次，怎么改？
答：用 `first` 记首次下标、`cnt` 记次数，第三次出现即返回 `False`，最后再校验出现两次的字母间隔。
