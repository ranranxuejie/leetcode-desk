## 一句话思路
前缀能重排成交替串，当且仅当 0 和 1 的个数差不超过 1；边扫边计数即可。

## 怎么做
1. 维护 `cnt0`、`cnt1`，遍历 `s` 的每个字符并累加。
2. 每步判断 `abs(cnt0 - cnt1) <= 1`，成立则 `ans += 1`。
3. 返回 `ans`。

以 `s = "00101"` 为例：扫到第 1 个 `'0'` 时 `cnt0=1, cnt1=0`，差 1，有效；扫到第 2 个 `'0'` 时 `cnt0=2, cnt1=0`，差 2，无效；扫到第 3 个 `'1'` 时 `cnt0=2, cnt1=1`，差 1，有效；第 4 个 `'1'` 时 `cnt0=2, cnt1=2`，差 0，有效；第 5 个 `'1'` 时 `cnt0=2, cnt1=3`，差 1，有效。共 3 个，与示例一致。

```python
cnt0 = cnt1 = ans = 0
for ch in s:
    if ch == '0':
        cnt0 += 1
    else:
        cnt1 += 1
    if abs(cnt0 - cnt1) <= 1:
        ans += 1
return ans
```

关键点：交替串长度为 L 时，两种字符的个数只能是 `L//2` 与 `L - L//2`，差值恰为 `L % 2`，即 0 或 1。反过来，只要差值 ≤ 1，把多的那种字符放在奇数位（或偶数位）就一定能排成交替串，所以这个条件是充要的。

## 复杂度
时间：O(n)，n 为 `s` 长度，每个字符只扫一次。
空间：O(1)，只开了 `cnt0`、`cnt1`、`ans` 三个整型变量。

## 易错点
- 把条件写成 `cnt0 == cnt1`：输入 `s = "0"` 时 `cnt0=1, cnt1=0`，会判为无效输出 0，正确答案是 1。长度奇数时两字符数必然差 1，必须用 `abs(cnt0 - cnt1) <= 1`。
- 只统计整个串而不统计每个前缀：输入 `s = "00101"` 时只看全长会得 1，正确答案是 3。必须在循环体内每步判断，不能等循环结束后统一判断。

## 如果面试官追问
问：如果要求返回所有有效前缀的结束下标列表呢？
答：把 `ans += 1` 换成 `ans.append(i)`，i 为当前字符下标，其余逻辑不变。
