## 一句话思路
设爱丽丝给出 x、鲍勃给出 y，交换后总和相等推出 `y = x + (sumB - sumA) // 2`，用哈希集合查鲍勃的盒子里有没有这个 y。

## 怎么做
1. 先算 `sumA = sum(aliceSizes)`、`sumB = sum(bobSizes)`，差值 `diff = (sumB - sumA) // 2`。
2. 把 `bobSizes` 全部放进 `set`，这样查 y 是 O(1)。
3. 遍历 `aliceSizes` 里的每个 x，算 `y = x + diff`，若 y 在集合里就返回 `[x, y]`。

以示例 4 为例：`aliceSizes = [1,2,5]`，`bobSizes = [2,4]`。`sumA = 8`，`sumB = 6`，`diff = (6 - 8) // 2 = -1`。遍历 x=1 得 y=0 不在集合；x=2 得 y=1 不在；x=5 得 y=4 在集合，返回 `[5,4]`。验证：爱丽丝 8-5+4=7，鲍勃 6-4+5=7，相等。

```python
sumA, sumB = sum(aliceSizes), sum(bobSizes)
diff = (sumB - sumA) // 2
bob_set = set(bobSizes)
for x in aliceSizes:
    y = x + diff
    if y in bob_set:
        return [x, y]
```

关键点：`diff` 是「鲍勃给出的减去爱丽丝给出的」的固定差，与具体选哪盒无关，所以只需一次遍历。

## 复杂度
时间 O(m + n)：m = len(aliceSizes)、n = len(bobSizes)，建集合 O(n)、遍历 O(m)。
空间 O(n)：额外开了 `bob_set`，规模等于鲍勃的盒子数。

## 易错点
- 把 `diff` 写成 `(sumA - sumB) // 2` 或漏掉 `// 2` → 示例 4 会算出 y = x + 1，x=5 时得 y=6 不在集合，遍历完返回空 → 正确是 `(sumB - sumA) // 2`，符号跟着「鲍勃多还是爱丽丝多」走。
- 用 `bobSizes` 列表做 `in` 判断而不是 `set` → 示例 1 这种小数据能过，但 `bobSizes` 长度到 10^4 时每次查找 O(n)，总复杂度退化成 O(m·n) 可能超时 → 先 `set(bobSizes)` 再查。

## 如果面试官追问
问：如果要求返回所有可行交换方案怎么办？
答：不提前 return，遍历时把每个命中的 `[x, y]` 收进结果列表，最后整体返回；复杂度不变，仍是 O(m + n)。
