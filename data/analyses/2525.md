## 一句话思路
分别算出 `bulky` 和 `heavy` 两个布尔值，再用四分支映射到四个字符串，避免条件嵌套写错。

## 怎么做
1. 先判 `bulky`：三个维度任一 `>= 10**4`，或 `length * width * height >= 10**9`。
2. 再判 `heavy`：`mass >= 100`。
3. 用 `(bulky, heavy)` 的四种组合直接查表返回。

拿示例 1 走一遍：`length=1000, width=35, height=700` 都小于 `10**4`，体积 `1000*35*700 = 24500000 < 10**9`，所以 `bulky = False`；`mass=300 >= 100`，`heavy = True`，落到 `"Heavy"`。

```python
bulky = (length >= 10**4 or width >= 10**4 or height >= 10**4
         or length * width * height >= 10**9)
heavy = mass >= 100
if bulky and heavy:
    return "Both"
if bulky:
    return "Bulky"
if heavy:
    return "Heavy"
return "Neither"
```

关键点：体积判断必须用 `>=`，`10**9` 本身算 Bulky；维度判断也是 `>=`，`10000` 算 Bulky。两个阈值方向一致，别一个写 `>` 一个写 `>=`。

## 复杂度
时间：O(1)，只做三次乘法和常数次比较，与输入数值大小无关。
空间：O(1)，只存 `bulky`、`heavy` 两个布尔值。

## 易错点
- 输入 `length=10000, width=1, height=1, mass=1` → 若维度写成 `> 10**4` 会错判成 `"Neither"` → 题目是「大于等于」，必须 `>= 10**4`。
- 输入 `length=1000, width=1000, height=1000, mass=1` → 体积正好 `10**9`，若写成 `> 10**9` 会错判成 `"Neither"` → 体积条件同样是 `>=`，边界值本身就算 Bulky。

## 如果面试官追问
问：如果维度上限放大到 `10**18`，体积会溢出吗？
答：Python 整数无溢出，直接乘即可；若换 C++/Java 需先判维度再判体积或用 128 位。
