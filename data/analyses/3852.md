## 一句话思路
用哈希表统计每个值的频率，再按值升序枚举 x 和 y，第一个频率不同的数对就是答案。

## 怎么做
1. 用 `Counter(nums)` 统计频率，得到 `freq`，键是值、值是出现次数。
2. 把 `freq` 的键升序排序得到 `vals`，因为题目要求 x 尽可能小。
3. 外层枚举 `x`，内层从 `x` 之后枚举 `y`，遇到 `freq[x] != freq[y]` 立刻返回 `[x, y]`。
4. 双重循环走完都没找到，返回 `[-1, -1]`。

以 `nums = [1,1,2,2,3,4]` 为例，`freq = {1:2, 2:2, 3:1, 4:1}`，`vals = [1,2,3,4]`。x=1 时 y=2 频率都是 2 跳过，y=3 时 `freq[1]=2 != freq[3]=1`，直接返回 `[1,3]`。

```python
from collections import Counter

freq = Counter(nums)
vals = sorted(freq)
for i, x in enumerate(vals):
    for y in vals[i + 1:]:
        if freq[x] != freq[y]:
            return [x, y]
return [-1, -1]
```

内层从 `i+1` 开始保证 x < y，排序保证 x 最小、同 x 时 y 最小，第一个命中即最优。

## 复杂度
时间 O(n + k²)，n 是数组长度用于计数，k 是不同值个数用于双重枚举。
空间 O(k)，`freq` 和 `vals` 各存 k 个不同值。

## 易错点
- 输入 `[1,5]` → 两个值频率都是 1，若只判断「x < y 就返回」会错成 `[1,5]` → 必须先比较 `freq[x] != freq[y]` 再返回。
- 输入 `[1,1,2,2,3,4]` → 若内层从 `vals[0]` 开始枚举，x=1 时 y 会取到 1 自身，`freq[1]==freq[1]` 跳过但浪费一轮，且可能误配同值 → 内层必须从 `vals[i+1:]` 起，保证 x 和 y 是不同值。

## 如果面试官追问
若 nums 长度放大到 10^5 且值域也大，怎么做？答：仍用 Counter 加排序，k 最多 10^5，双重枚举退化为 O(k²) 不可接受，可先按频率分组，取最小值和「频率与它不同的最小值」两两比较，O(k) 即可。
