## 一句话思路
按左端点排序后，用最小堆维护每组当前的右端点，新区间左端点大于堆顶就复用该组，否则新开一组。

## 怎么做
1. 把 `intervals` 按 `left` 升序排序，保证处理时左端点单调不减。
2. 用最小堆 `heap` 存每个已开组当前的右端点，堆顶就是最早能接上新区间的组。
3. 遍历每个 `[l, r]`：若 `heap` 非空且 `heap[0] < l`，弹出堆顶并压入 `r`（复用该组）；否则直接压入 `r`（新开一组）。
4. 遍历结束，`len(heap)` 即最少组数。

以示例 1 为例，排序后为 `[[1,5],[1,10],[2,3],[5,10],[6,8]]`。处理 `[1,5]` 堆为 `[5]`；`[1,10]` 时 `heap[0]=5` 不小于 `1`，压入得 `[5,10]`；`[2,3]` 同理得 `[3,5,10]`；`[5,10]` 时 `heap[0]=3 < 5`，弹出 3 压入 10，堆变 `[5,10,10]`；`[6,8]` 时 `heap[0]=5 < 6`，弹出 5 压入 8，堆变 `[8,10,10]`，长度 3。

```python
intervals.sort(key=lambda x: x[0])
heap = []
for l, r in intervals:
    if heap and heap[0] < l:
        heapq.heapreplace(heap, r)
    else:
        heapq.heappush(heap, r)
return len(heap)
```

关键在 `heap[0] < l` 而非 `<=`：闭区间 `[1,5]` 与 `[5,8]` 在 5 处相交，不能同组，所以必须严格小于才复用。

## 复杂度
时间：排序 O(n log n)，每个区间一次堆操作 O(log n)，共 O(n log n)。
空间：堆最多存 n 个右端点，O(n)。

## 易错点
1. 输入含 `[1,5]` 和 `[5,8]` 这类端点相接的区间 → 若写成 `heap[0] <= l` 会误判为可同组，输出偏小 → 闭区间必须用严格 `<`，相接即相交。
2. 输入 `[[1,10],[2,3],[4,5]]` → 若只按左端点贪心分配而不看右端点，会把 `[2,3]` 塞进 `[1,10]` 所在组导致冲突 → 必须用最小堆取最早结束的组，`[1,10]` 的右端点 10 一直占着堆，`[2,3]`、`[4,5]` 只能各开新组，答案 3。

## 如果面试官追问
若要求输出具体分组方案？答：堆里改存 `(右端点, 组号)`，复用或新建时把区间下标追加到对应组的列表，最后返回各组列表即可。
