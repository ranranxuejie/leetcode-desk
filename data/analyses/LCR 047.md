## 一句话思路
后序 DFS：先剪左右子树，再判断当前节点是否「值为 0 且左右都空」，是则返回 `None` 把它摘掉。

## 怎么做
1. 递归函数返回「剪完后的子树根」，空节点直接返回 `None`。
2. 先递归 `root.left = dfs(root.left)`、`root.right = dfs(root.right)`，让子树先剪干净。
3. 再判断 `root.val == 0 and root.left is None and root.right is None`，成立就 `return None`。
4. 否则 `return root`，把节点交还给父节点。

拿示例 1 的 `[1,null,0,0,1]` 走一遍：根 1 的右孩子是 0，它的左孩子 0 无子节点 → 返回 `None`；右孩子 1 保留。回到那个 0，此时 `root.left is None`、`root.right.val == 1`，条件不成立，所以这个 0 **保留**，最终 `[1,null,0,null,1]`。关键中间值就是「0 的右孩子非空」这一步，它挡住了误删。

```python
def dfs(root):
    if root is None:
        return None
    root.left = dfs(root.left)
    root.right = dfs(root.right)
    if root.val == 0 and root.left is None and root.right is None:
        return None
    return root
```

顺序不能反：若先判断再递归，示例 1 里那个 0 的右孩子 1 还没被处理，判断时 `root.right` 非空，结论虽然对，但示例 3 的 `[1,1,0,1,1,0,1,0]` 里节点 0（下标 2）的右孩子 1 下面挂着 0，必须先剪掉那个叶子 0 才能让父节点 0 的右孩子变成 `None`——不过这里父节点 0 的左孩子 1 非空，仍然保留，输出 `[1,1,0,1,1,null,1]` 与官方一致。

## 复杂度
时间 O(n)：每个节点恰好被访问一次，n 为节点数。
空间 O(h)：递归栈深度等于树高 h，最坏链状 O(n)，未额外开数组。

## 易错点
- 输入 `[0]`（单节点全 0）→ 若只写 `if root.val == 0: return None` 会连「0 但有 1 后代」的节点一起删，示例 1 的 0 就被误删 → 必须加上 `root.left is None and root.right is None` 两个条件。
- 输入 `[1,0,1,0,0,0,1]` → 若先判断当前节点再递归子树，节点 0（下标 1）在子节点还没剪时看到左孩子 0 存在，判断结果依赖未更新的状态，容易漏删 → 正确做法是后序，先 `dfs` 左右再判断。

## 如果面试官追问
问：改成「删除所有值全为 0 的子树但保留根」怎么改？答：加一个 `is_root` 标志，根节点即使满足条件也返回 `root` 而非 `None`。
