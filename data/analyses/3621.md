## 一句话思路
先枚举 popcount 值 c（≤50），用数位 DP 统计 [1,n] 中 popcount 恰为 c 的个数，再按深度表累加。

## 怎么做
1. 预处理深度表 `dep[c]`：`dep[1]=0`，其余 `dep[c]=dep[popcount(c)]+1`，c 最大只需到 50（因为 n≤10^15<2^50）。
2. 数位 DP 统计 popcount 恰为 c 的数的个数，返回数组 `cnt[c]`。
3. 答案 = `sum(cnt[c] for c if dep[c]==k)`。

以 n=7, k=2 为例：`cnt[1]=1`（即 1），`cnt[2]=3`（3,5,6），`cnt[3]=3`（7 及…实际 7 的 popcount 是 3）。`dep[1]=0`，`dep[2]=1`，`dep[3]=2`，故 k=2 时取 c=3 的个数，得 3。

数位 DP 关键：从高位到低位枚举，状态 `(pos, ones, tight)`，`ones` 是已选 1 的个数。

```python
def count_by_popcount(n):
    bits = bin(n)[2:]
    L = len(bits)
    cnt = [0] * (L + 1)
    # dp[pos][ones][tight]
    from functools import lru_cache
    @lru_cache(None)
    def dfs(pos, ones, tight):
        if pos == L:
            return {ones: 1}
        res = {}
        up = int(bits[pos]) if tight else 1
        for d in range(up + 1):
            sub = dfs(pos + 1, ones + d, tight and d == up)
            for k2, v in sub.items():
                res[k2] = res.get(k2, 0) + v
        return res
    for k2, v in dfs(0, 0, True).items():
        if k2 <= L:
            cnt[k2] += v
    return cnt
```

（实际实现可改成返回 list 避免 dict 开销；此处只示关键逻辑。）

## 复杂度
时间：O(log n · log n · 2)，数位 DP 状态数约 50×50×2。
空间：O(log n · log n) 的记忆化表，外加长度 51 的深度数组。

## 易错点
- n=1, k=0 → 若把 1 的深度算成 1 会得 0，正确是 `dep[1]=0`，答案 1。
- k 大于最大可能深度（如 n=10^15, k=5）→ 若深度表只算到 popcount(n) 会漏，正确是深度表算到 50（因为 10^15 的 popcount ≤50），再判断 `dep[c]==k`。

## 如果面试官追问
问：n 扩大到 10^18 怎么办？答：位数上限从 50 变 60，深度表扩到 60 即可，其余不变。
