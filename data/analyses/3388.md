## 一句话思路
用 LCP 表预处理任意两位置的最长公共前缀，枚举两个切点 i、j，O(1) 判定前缀关系。

## 怎么做
1. 定义 `lcp[a][b]` 为 `nums[a:]` 与 `nums[b:]` 的最长公共前缀长度，从后往前填：`nums[a]==nums[b]` 时 `lcp[a][b]=lcp[a+1][b+1]+1`，否则 0。
2. 枚举切点 `i`（nums1 结束于 i-1）和 `j`（nums2 结束于 j-1），三段长度 `L1=i`、`L2=j-i`、`L3=n-j`。
3. 判定条件一：`lcp[0][i] >= L1` 表示 nums1 是 nums2 的前缀（需 `L1<=L2`）。
4. 判定条件二：`lcp[i][j] >= L2` 表示 nums2 是 nums3 的前缀（需 `L2<=L3`）；两者任一成立即计数加一。

以 `nums=[1,1,2,1]`、n=4 为例：`i=1, j=2` 时 `L1=1,L2=1,L3=2`，`lcp[0][1]=1>=1` 成立，计一个；`i=1, j=3` 时 `L1=1,L2=2,L3=1`，`lcp[1][3]=0`，但 `lcp[0][1]=1>=1` 仍成立，计第二个，共 2。

```python
n = len(nums)
lcp = [[0] * (n + 1) for _ in range(n + 1)]
for a in range(n - 1, -1, -1):
    for b in range(n - 1, -1, -1):
        if nums[a] == nums[b]:
            lcp[a][b] = lcp[a + 1][b + 1] + 1
ans = 0
for i in range(1, n - 1):
    for j in range(i + 1, n):
        L1, L2, L3 = i, j - i, n - j
        if (L1 <= L2 and lcp[0][i] >= L1) or (L2 <= L3 and lcp[i][j] >= L2):
            ans += 1
```

## 复杂度
时间：O(n²) 填 lcp 表 + O(n²) 枚举切点，n 为 nums 长度。
空间：O(n²) 的 lcp 二维表，无其他额外结构。

## 易错点
- 输入 `nums=[1,1]`（n=2）→ 若循环写成 `range(1, n-1)` 会漏掉或越界，实际三段非空要求 n≥3，n<3 直接返回 0，否则 `j` 从 `i+1` 起会取到空段。
- 输入 `nums=[1,1,2,1]` 中 `i=1,j=3` → 若只判 `lcp[i][j]>=L2` 会漏掉 nums1 是 nums2 前缀这一支，必须用 `or` 连接两个条件，且各自带上长度约束 `L1<=L2` / `L2<=L3`，否则 `lcp` 值可能超过短段长度造成误判。

## 如果面试官追问
若 n 放大到 10⁵ 怎么办？答：O(n²) 的 lcp 表放不下，改用滚动哈希 + 二分求 LCP，枚举切点仍需优化，可考虑按段长分块统计。
