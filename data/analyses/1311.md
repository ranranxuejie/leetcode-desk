## 一句话思路
从 `id` 出发做 BFS 分层，取距离恰为 `level` 的那层人，统计他们 `watchedVideos` 里的视频频次，再按 (频次, 视频名) 排序。

## 怎么做
1. BFS 用 `dist` 数组记录到 `id` 的最短距离，`dist[id] = 0`，队列初始为 `[id]`。
2. 每弹出一个 `u`，遍历 `friends[u]`，未访问的邻居 `v` 记 `dist[v] = dist[u] + 1` 并入队。
3. BFS 结束后筛出所有 `dist[v] == level` 的 `v`，把 `watchedVideos[v]` 里的每个视频累加进 `Counter`。
4. 对 `Counter` 的键按 `(cnt, name)` 排序返回。

以示例 1 为例：`id = 0, level = 1`。BFS 后 `dist = [0, 1, 1, 2]`，距离为 1 的是 `{1, 2}`，它们看的视频合并为 `["C", "B", "C"]`，`Counter` 得 `{"C": 2, "B": 1}`，排序输出 `["B", "C"]`。

```python
from collections import deque, Counter

dist = [-1] * n
dist[id] = 0
q = deque([id])
while q:
    u = q.popleft()
    for v in friends[u]:
        if dist[v] == -1:
            dist[v] = dist[u] + 1
            q.append(v)

cnt = Counter()
for v in range(n):
    if dist[v] == level:
        cnt.update(watchedVideos[v])
return sorted(cnt, key=lambda x: (cnt[x], x))
```

## 复杂度
时间：BFS 走 O(n + E)，E 为好友边数；统计视频 O(V)，排序 O(V log V)，V 为该层视频种类数。
空间：`dist` 与队列 O(n)，`Counter` O(V)。

## 易错点
- 若把 `dist[v] == level` 写成 `dist[v] <= level`，示例 1 中 `id = 3` 的 `"D"` 会被算进 level 1，输出多出 `"D"`；必须严格等于 `level`。
- 若用 DFS 代替 BFS，示例 1 中从 0 经 1 到 3 的路径长度会被记成 2 或更深，`dist[3]` 不再是 2；必须用 BFS 保证最短距离。

## 如果面试官追问
问：如果要求返回每个视频及其观看者 id 列表呢？
答：把 `Counter` 换成 `dict[str, list[int]]`，遍历该层每个人时 append 其 id，排序键不变。
