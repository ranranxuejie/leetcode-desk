## 一句话思路
从右往左找第一个「左小右大」的相邻位，交换后把后缀反转成升序，就是最小增量。

## 怎么做
1. 把 `n` 转成字符列表 `d`，从右往左找第一个 `d[i] < d[i+1]` 的位置 `i`。
2. 若找不到（如 `n=21`，全程 `d[i] >= d[i+1]`），说明已是降序最大排列，直接返回 `-1`。
3. 在 `d[i+1:]` 里从右往左找第一个大于 `d[i]` 的 `d[j]`，交换 `d[i]` 与 `d[j]`。
4. 把 `d[i+1:]` 反转（它原本是降序，反转即升序），拼回整数，超过 `2**31 - 1` 返回 `-1`。

以 `n=12` 为例：`d=['1','2']`，`i=0` 满足 `'1'<'2'`；后缀只有 `'2'`，`j=1`，交换得 `['2','1']`，后缀 `['1']` 反转不变，结果 `21`。

关键中间值：`n=230` 时 `d=['2','3','0']`，`i=1`（`'3'>'0'` 不满足，`'2'<'3'` 满足），后缀 `['3','0']` 中从右找第一个 `>'2'` 的是 `'3'`，交换得 `['3','2','0']`，反转后缀得 `['3','0','2']` → `302`。

```python
d = list(str(n))
i = len(d) - 2
while i >= 0 and d[i] >= d[i + 1]:
    i -= 1
if i < 0:
    return -1
j = len(d) - 1
while d[j] <= d[i]:
    j -= 1
d[i], d[j] = d[j], d[i]
d[i + 1:] = d[i + 1:][::-1]
ans = int(''.join(d))
return ans if ans <= 2**31 - 1 else -1
```

## 复杂度
时间：O(log n)，`n` 的位数决定扫描与反转长度。
空间：O(log n)，`d` 列表存了每一位数字。

## 易错点
- `n=21` 这类全降序输入 → 若漏掉 `i < 0` 的判断，`d[-1]` 会被当成合法下标去交换，得到错误答案 → 必须先判 `i < 0` 返回 `-1`。
- `n=2147483486` 这类交换后超过 `2**31 - 1` 的输入 → 若直接返回 `int(''.join(d))`，会给出题目不允许的 33 位结果 → 题目规定答案按 32 位截断，拼完必须与 `2**31 - 1` 比较再返回。

## 如果面试官追问
问：如果要求返回所有比 `n` 大的排列个数？答：先按同样方法定位 `i`，后缀长度 `L = len(d)-i-1`，个数由后缀中比 `d[i]` 大的数字种类数乘以 `L!` 累加得到。
