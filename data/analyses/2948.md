## 一句话思路
按值排序后，相邻差 ≤ limit 的元素连成可互换的连通块，块内把最小值依次填回块内最小的下标。

## 怎么做
1. 把 `(值, 原下标)` 按值升序排序，得到 `pairs`。
2. 顺序扫描 `pairs`，若 `pairs[i][0] - pairs[i-1][0] <= limit` 则归入同一块，否则开新块；块内记录下标集合。
3. 每块内把值升序、下标升序后一一配对写回 `ans`。

以 `nums = [1,5,3,9,8], limit = 2` 为例：排序后 `pairs = [(1,0),(3,2),(5,1),(8,4),(9,3)]`，差值 2、2、3、1，第三处 8-5=3 > 2 断开，得到块 `{(1,0),(3,2),(5,1)}` 与 `{(8,4),(9,3)}`。第一块下标 `[0,2,1]` 排序为 `[0,1,2]`，值 `[1,3,5]` 依次填入 → `ans[0]=1, ans[1]=3, ans[2]=5`；第二块下标 `[4,3]` 排序为 `[3,4]`，值 `[8,9]` 填入 → `ans[3]=8, ans[4]=9`。

```python
pairs = sorted((v, i) for i, v in enumerate(nums))
ans = [0] * len(nums)
start = 0
for end in range(1, len(pairs) + 1):
    if end == len(pairs) or pairs[end][0] - pairs[end - 1][0] > limit:
        idx = sorted(pairs[k][1] for k in range(start, end))
        for pos, k in zip(idx, range(start, end)):
            ans[pos] = pairs[k][0]
        start = end
```

关键点：块内值已升序，只需把下标排序后按位填，就保证字典序最小。

## 复杂度
时间：排序 `O(n log n)`，扫描与块内下标排序合计 `O(n log n)`。
空间：`pairs` 与 `ans` 各 `O(n)`，块内下标列表最坏 `O(n)`。

## 易错点
- 用 `nums[i] - nums[i-1] <= limit` 在原数组顺序上判断连通 → 示例 2 中 `1,7,6` 会漏掉 `1` 与 `2` 的连通（值差 1 但下标隔了 4 位）→ 必须先按值排序再判相邻差。
- 块内只把值排序、下标按原顺序填 → 示例 1 第一块会得到 `ans[0]=1, ans[2]=3, ans[1]=5` 即 `[1,5,3,...]`，比答案大 → 下标也要升序，`zip(sorted_idx, sorted_vals)` 配对。

## 如果面试官追问
若要求输出具体交换方案而非最终数组？答：块内对每个目标位置做一次「把该值换到该下标」的交换即可，块内任意两元素可经中间值传递互换，交换次数不超过块大小。
