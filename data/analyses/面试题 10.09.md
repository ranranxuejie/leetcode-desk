## 一句话思路
从右上角出发，利用「左小下大」的单调性，每步排除一行或一列，O(M+N) 收敛到目标。

## 怎么做
1. 令 `r = 0`、`c = n - 1`，从右上角 `matrix[0][n-1]` 起步。
2. 若 `matrix[r][c] == target` 直接返回 `True`。
3. 若 `matrix[r][c] > target`，说明这一列下方都更大，`c -= 1` 左移。
4. 若 `matrix[r][c] < target`，说明这一行左侧都更小，`r += 1` 下移；越界即 `False`。

用官方示例 `target = 5`：起点 `matrix[0][4] = 15 > 5`，左移到 `c=3` 得 `11 > 5`，再到 `c=2` 得 `7 > 5`，再到 `c=1` 得 `4 < 5`，于是 `r=1`；此时 `matrix[1][1] = 5` 命中返回 `True`。关键中间值是 `r=0, c=1` 时的 `4`，它把搜索区间从「第 0 行左侧」整体切掉。

```python
r, c = 0, len(matrix[0]) - 1
while r < len(matrix) and c >= 0:
    v = matrix[r][c]
    if v == target:
        return True
    if v > target:
        c -= 1
    else:
        r += 1
return False
```

注意 `matrix` 为空或 `matrix[0]` 为空时要先返回 `False`，否则 `len(matrix[0])` 直接抛 `IndexError`。

## 复杂度
时间 O(M+N)：`r` 最多加 M 次、`c` 最多减 N 次，每步只走一格。
空间 O(1)：只开了 `r`、`c`、`v` 三个变量，没开额外矩阵。

## 易错点
- 输入 `matrix = []` 或 `matrix = [[]]` → 直接取 `len(matrix[0])` 会抛 `IndexError` → 循环前先判 `if not matrix or not matrix[0]: return False`。
- 起点选左上角 `matrix[0][0]` → 当 `matrix[0][0] < target` 时无法判断该右移还是下移，会退化成暴力扫描 → 必须从右上角（或左下角）起步，那里两个方向一大一小才可判定。

## 如果面试官追问
问：若矩阵只保证每行升序、列不保证呢？
答：逐行二分，O(M log N)，右上角单调性不再成立。
