## 一句话思路
把 s 按「y 优先、其余字符居中、x 最后」的键排序，一次 `sorted` 即得合法排列。

## 怎么做
1. 给每个字符定一个排序键：`y` 记 0，`x` 记 2，其他字母记 1。
2. 用这个键对 s 做稳定排序，得到 t。
3. 因为键 0 的字符全排在键 2 之前，所以所有 y 必在所有 x 之前；键 1 的字符夹在中间不影响约束。

以示例 1 `s = "aabc", x = "a", y = "c"` 为例：键映射为 `a→2, b→1, c→0`，各字符键值是 `[2,2,1,0]`，排序后顺序为 `c(0), b(1), a(2), a(2)`，输出 `"cbaa"`，与官方答案一致。

```python
def key(ch):
    if ch == y:
        return 0
    if ch == x:
        return 2
    return 1

t = ''.join(sorted(s, key=key))
```

关键点：`sorted` 是稳定的，键相同的字符（比如两个 `a`）保持原相对顺序，但这题不要求，稳定只是顺带。

## 复杂度
时间 O(n log n)：n = len(s)，排序贡献 n log n，键函数 O(1)。
空间 O(n)：`sorted` 返回新列表，`join` 再开一个长度 n 的字符串。

## 易错点
- 输入 `s = "axe", x = "o", y = "x"`：若先判断「x 是否在 s 中」再决定要不要排序，会漏掉 y 存在但 x 不存在的情况，仍要保证 y 在前；正确做法是不做存在性判断，直接按三档键排序，`o` 不在 s 里自然无影响。
- 输入 `s = "dcab", x = "d", y = "b"`：若把键写成「x 记 0、y 记 2」就反了，输出会变成 `"abdc"` 之类，`b` 跑到 `d` 后面；正确做法是 y 必须拿最小键 0、x 拿最大键 2，别把 x/y 的先后写反。

## 如果面试官追问
问：若要求输出字典序最小的合法排列怎么办？
答：键改成 `(档位, 字符本身)` 二元组，同档内按字母升序，`sorted` 一次即可。
