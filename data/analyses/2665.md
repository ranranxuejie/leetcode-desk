## 一句话思路
用闭包保存一个可变变量 `cur`，三个方法都读写同一个 `cur`，`reset` 把它写回 `init`。

## 怎么做
1. 在 `createCounter` 里定义局部变量 `cur = init`，它被三个内层函数共同引用。
2. `increment` 执行 `cur += 1` 后返回 `cur`；`decrement` 执行 `cur -= 1` 后返回 `cur`。
3. `reset` 执行 `cur = init` 后返回 `cur`，注意 `init` 是外层参数，不能被覆盖。
4. 按 `calls` 顺序逐个调用同名方法，把返回值收集进结果列表。

以示例 1 为例：`init = 5`，`cur` 初始为 5。调用 `increment` 后 `cur = 6` 返回 6；接着 `reset` 把 `cur` 写回 `init` 即 5 返回 5；最后 `decrement` 得 `cur = 4` 返回 4，输出 `[6,5,4]`。关键中间值是 `reset` 之后 `cur` 必须回到 5 而不是 4。

```python
def create_counter(init):
    cur = init
    def increment():
        nonlocal cur
        cur += 1
        return cur
    def decrement():
        nonlocal cur
        cur -= 1
        return cur
    def reset():
        nonlocal cur
        cur = init
        return cur
    return {"increment": increment, "decrement": decrement, "reset": reset}
```

## 复杂度
时间：O(n)，n 为 `calls.length`，每个调用 O(1)。
空间：O(1) 额外空间，只存一个 `cur` 和结果列表。

## 易错点
1. 内层函数写 `cur += 1` 却漏了 `nonlocal cur` → Python 会把它当成新的局部变量，抛 `UnboundLocalError`，或读到外层未定义值 → 三个方法里凡修改 `cur` 的都必须声明 `nonlocal cur`。
2. `reset` 里写成 `cur = cur` 或先改 `init` → 示例 2 中连续两次 `reset` 会输出 `[1,2,1,1,1]` 而非 `[1,2,1,0,0]` → `reset` 必须写 `cur = init`，且 `init` 全程只读。

## 如果面试官追问
问：如果 `calls` 规模到 10^7 且要求流式返回怎么办？
答：仍用闭包，逐个调用即时产出，不预先建结果列表，空间保持 O(1)。
