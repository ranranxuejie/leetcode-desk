## 一句话思路
从后往前倒推：`cnt[i]` 表示从第 i 条指令开始能走几步，`cnt[i] = cnt[i+1] + 1` 当且仅当第 i 步不越界。

## 怎么做
1. 从 `m-1` 倒序枚举 `i`，维护「执行完 `s[i+1:]` 后机器人所在位置」`(r, c)`，初始为 `startPos`。
2. 对 `s[i]` 算出移动后的 `(nr, nc)`，若在 `[0, n-1]` 内则 `ans[i] = ans[i+1] + 1`，否则 `ans[i] = 0`。
3. 只有 `ans[i] > 0` 时才把 `(r, c)` 更新为 `(nr, nc)`，否则位置保持不变（因为从 i 开始就停了，不影响更早的起点）。

以 `n=3, startPos=[0,1], s="RRDDLU"` 为例：`i=5` 时 `s[5]='U'`，`nr = 0-1 = -1` 越界，`ans[5]=0`，位置仍 `(0,1)`；`i=4` 时 `s[4]='L'`，`nc = 1-1 = 0` 合法，`ans[4] = ans[5]+1 = 1`，位置更新为 `(0,0)`。

```python
m = len(s)
ans = [0] * m
r, c = startPos
for i in range(m - 1, -1, -1):
    nr, nc = r, c
    if s[i] == 'L': nc -= 1
    elif s[i] == 'R': nc += 1
    elif s[i] == 'U': nr -= 1
    else: nr += 1
    if 0 <= nr < n and 0 <= nc < n:
        ans[i] = ans[i + 1] + 1 if i + 1 < m else 1
        r, c = nr, nc
```

## 复杂度
时间 O(m)：倒序扫一遍 `s`，每个字符 O(1)。
空间 O(m)：除返回数组 `ans` 外只用了 `r, c, nr, nc` 四个变量。

## 易错点
- 写成从每个 `i` 正向模拟：`n=m=500` 时是 O(m²)=25 万次，虽然能过但面试官会追问优化；正确做法是倒推复用 `ans[i+1]`，把「后缀能走多远」变成一次扫描。
- 越界时仍更新 `(r, c)`：比如示例 1 的 `i=5`，`U` 越界后若把 `r` 改成 `-1`，`i=4` 的 `L` 就会在错误起点上判断，导致 `ans[4]` 算错；正确做法是越界时位置不动。

## 如果面试官追问
问：如果要求输出每个起点的终止坐标而不只是步数？
答：把 `ans` 换成 `(步数, 终点)` 二元组，倒推时同样只在合法时继承 `i+1` 的终点。
