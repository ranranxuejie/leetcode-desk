## 一句话思路
一次遍历把每个源节点编号累加到它的出边终点上，再线性扫描取最大值、同分取小编号。

## 怎么做
1. 开长度 n 的数组 `score`，初值全 0，`score[v]` 表示节点 v 当前的边积分。
2. 遍历 `i` 从 0 到 n-1，执行 `score[edges[i]] += i`，因为节点 i 的编号要加到它指向的节点上。
3. 用 `best = 0` 记录当前最优节点，从 1 到 n-1 比较 `score[i] > score[best]`，严格大于才更新，这样同分自动保留小编号。
4. 返回 `best`。

拿示例 1 的 `edges = [1,0,0,0,0,7,7,5]` 走一遍关键中间值：i=1、2、3、4 时 `edges[i]` 都是 0，`score[0]` 依次变成 1、3、6、10；i=5、6 时 `edges[i]` 都是 7，`score[7]` 变成 5 再变成 11。扫描时 `score[0]=10` 先当 best，到 7 时 11>10 更新，最终返回 7。

```python
n = len(edges)
score = [0] * n
for i in range(n):
    score[edges[i]] += i
best = 0
for i in range(1, n):
    if score[i] > score[best]:
        best = i
return best
```

注意 `score[edges[i]] += i` 里的 `i` 是源节点编号，不是 1；示例 1 中 `score[0]=1+2+3+4=10` 而不是 4，就是靠这个。

## 复杂度
时间 O(n)：一次累加遍历加一次扫描，各 n 次。
空间 O(n)：额外开 `score` 数组存 n 个积分，其余是常数。

## 易错点
- 同分时更新条件写成 `>=` → 示例 2 的 `edges=[2,0,0,2]` 中 `score[0]=score[2]=3`，用 `>=` 会返回 2 → 必须用严格 `>`，让小编号 0 留下。
- 把累加值写成 `score[edges[i]] += 1` 或累加 `edges[i]` → 示例 1 中 `score[0]` 会变成 4 或 0，节点 7 的 11 也变成 2 → 累加的必须是源节点编号 `i`，因为积分定义是「指向它的节点编号总和」。

## 如果面试官追问
问：若 n 扩大到 10^9 但边数只有 10^5 怎么办？
答：改用哈希表只记被指向节点的积分，最后在哈希表里按「积分降序、编号升序」取首项。
