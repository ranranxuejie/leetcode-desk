## 一句话思路
用两棵线段树分别维护「以某值结尾、上一步是下降/上升」的最大和，按值域查询前缀/后缀最优转移。

## 怎么做
1. 定义 `up[v]` = 以值 v 结尾且最后一步是上升（前一个值 < v）的最大和，`down[v]` 同理最后一步下降。
2. 处理下标 i 时，只允许用 `i-k` 及更早的状态，所以先把 `nums[i-k]` 的两个状态插入线段树。
3. 新 `up[nums[i]] = nums[i] + max(down[1..nums[i]-1])`，新 `down[nums[i]] = nums[i] + max(up[nums[i]+1..maxV])`，两者都还要和单独取 `nums[i]` 比较。
4. 答案取所有状态最大值。

以示例 2 `nums=[3,5,4,2,4], k=1` 为例：处理 i=1（值 5）时，已插入 i=0 的 `up[3]=down[3]=3`，于是 `up[5] = 5 + max(down[1..4]) = 5+3 = 8`；处理 i=3（值 2）时插入 i=2 的 `down[4]=4+max(up[5..])=4+8=12`，得 `down[2]=2+max(up[3..])=2+8=10`。最终 i=4 值 4 得 `up[4]=4+max(down[..3])=4+10=14`。

```python
# 值域线段树：单点取 max，区间查 max
for i, x in enumerate(nums):
    if i >= k:
        y = nums[i - k]
        seg_up.update(y, up[y])
        seg_down.update(y, down[y])
    best_down = seg_down.query(1, x - 1)   # 前一个更小
    best_up = seg_up.query(x + 1, MAXV)    # 前一个更大
    up[x] = max(up[x], x, x + best_down)
    down[x] = max(down[x], x, x + best_up)
    ans = max(ans, up[x], down[x])
```

## 复杂度
时间 O(n log V)，n 次单点更新 + 区间查询，V 为值域 10^5。
空间 O(V)，两棵线段树各 4V 个节点，外加 up/down 数组。

## 易错点
1. 忘记「延迟 k 插入」：若在处理 i 时把 `nums[i]` 立刻插入，示例 1 `nums=[5,4,2], k=2` 会错误地用下标 1 的值 4 去接下标 0 的 5，得到 9 而非正确答案 7。正确做法是只插入 `i-k` 的状态，保证下标差 ≥ k。
2. 把「严格交替」写成非严格：示例 2 中若允许相等，`[3,5,4,4]` 之类会被误判合法。查询区间必须是 `[1, x-1]` 和 `[x+1, MAXV]`，不能包含 x 本身。

## 如果面试官追问
问：如果 k 很大接近 n 怎么办？
答：算法不变，只是可转移的状态更少，线段树查询次数仍是 n 次，复杂度不受 k 影响。
