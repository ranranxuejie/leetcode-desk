## 一句话思路
值域只有 -50..50，用长度 101 的计数数组维护窗口内每个值的出现次数，再从小到大累加到第 x 个即为第 x 小。

## 怎么做
1. 把 `nums[i]` 映射到下标 `nums[i] + 50`，用 `cnt` 记录当前窗口的频次分布。
2. 先统计 `nums[0:k]`，之后每次右移：`cnt[nums[r]+50] += 1`，`cnt[nums[r-k]+50] -= 1`。
3. 对每个窗口，从 `v = -50` 开始累加 `cnt[v+50]`，累计次数首次 `>= x` 时 `v` 就是第 x 小。
4. 若 `v < 0` 输出 `v`，否则输出 `0`。

以示例 1 的 `nums = [1,-1,-3,-2,3], k = 3, x = 2` 为例：第一个窗口 `[1,-1,-3]` 的 `cnt` 在 -3、-1、1 处各为 1；从 -50 累加，到 `v = -3` 时累计 1（< 2），到 `v = -1` 时累计 2（>= 2），故第 2 小是 -1，输出 -1。

```python
cnt = [0] * 101
for v in nums[:k]:
    cnt[v + 50] += 1
res = []
for r in range(k - 1, len(nums)):
    if r >= k:
        cnt[nums[r] + 50] += 1
        cnt[nums[r - k] + 50] -= 1
    acc = 0
    for v in range(-50, 51):
        acc += cnt[v + 50]
        if acc >= x:
            res.append(v if v < 0 else 0)
            break
```

## 复杂度
时间：O((n-k+1) * 101)，即 O(101n)，101 是值域宽度常数。
空间：O(101) 的 `cnt` 加 O(n-k+1) 的结果数组，无额外结构。

## 易错点
- `x` 可能大于窗口内负数的个数，例如示例 3 的 `[1,2]`（k=2, x=1）：若只扫负数区间 -50..-1 就找不到答案，会漏输出或越界；必须扫到 50，命中正数时输出 0。
- 窗口右移时先加新元素再减旧元素，若顺序写反且新旧下标相同（`nums[r] == nums[r-k]`），频次会短暂错乱；按上面代码先 `+=` 后 `-=` 即可，别在中间取答案。

## 如果面试官追问
若 `nums[i]` 范围放大到 -10^9..10^9 怎么办？答：计数数组失效，改用两个有序容器（如 sortedcontainers 的 SortedList）维护窗口，插入删除 O(log k)，取第 x 小 O(log k)。
