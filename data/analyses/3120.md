## 一句话思路
用两个 26 位布尔数组分别记录出现过的小写和大写字母，逐位与运算后统计为真的位数。

## 怎么做
1. 开 `lower = [False]*26` 和 `upper = [False]*26`，下标是 `ord(ch) - ord('a')` 或 `ord(ch) - ord('A')`。
2. 遍历 `word`，按 `ch.islower()` 分派到对应数组置 `True`。
3. 对 `i in range(26)` 统计 `lower[i] and upper[i]` 的个数。

以 `word = "aaAbcBC"` 为例：扫完后 `lower` 在 a、b、c 三位为 `True`，`upper` 在 A、B、C 三位为 `True`；逐位与得到 3 个 `True`，返回 3。注意 `'a'` 和 `'A'` 必须落到同一个下标 0，这是整个解法的关键——大小写映射到同一索引才能对齐比较。

```python
lower = [False] * 26
upper = [False] * 26
for ch in word:
    if ch.islower():
        lower[ord(ch) - ord('a')] = True
    else:
        upper[ord(ch) - ord('A')] = True
return sum(1 for i in range(26) if lower[i] and upper[i])
```

也可以用一个 26 位整数位掩码：小写置 `1 << i`，大写置 `1 << (i + 26)`，最后 `mask & (mask >> 26)` 的 popcount 就是答案。但两个数组更直白，`word.length <= 50` 时性能差异可忽略，面试里优先写不易错的版本。

## 复杂度
时间 O(n + 26)，n 为 `word` 长度，26 是固定常数。
空间 O(26)，两个长度 26 的布尔数组，与 n 无关。

## 易错点
- 输入 `"abc"` → 若只用一个数组且不区分大小写地置位，会把小写 a、b、c 误判为特殊字母，错答 3 → 必须用两个独立数组（或位掩码的高低 26 位）分别记录，最后取交集。
- 输入 `"abBCab"` → 若把 `'b'` 和 `'B'` 映射到不同下标（比如直接用 `ord(ch) - ord('a')` 处理大写，`'B'` 会得到 -31 越界或落到错误位置），交集算不出 b → 大写必须用 `ord(ch) - ord('A')` 归一到 0..25，与小写共用同一套下标。

## 如果面试官追问
追问：如果 word 长度到 10^7 且要求 O(1) 额外空间怎么办？
答：仍用两个 26 位整数掩码，空间是常数级，扫描一遍即可，与长度无关。
