## 一句话思路
按对角线分组，每条对角线从左到右扫一遍，用哈希集合维护「已出现值」得到左上计数，再反向扫一遍得到右下计数。

## 怎么做
1. 每条对角线由 `r - c` 唯一确定，枚举所有起点（第一行和第一列），沿 `(r+1, c+1)` 走到底。
2. 正向扫：进入 `(r,c)` 前把 `grid[r][c]` 加入集合，集合大小即 `topLeft[r][c]`。
3. 反向扫：清空集合，从对角线末尾往回走，同样先加后记，得到 `bottomRight[r][c]`。
4. 最后 `answer[r][c] = abs(topLeft - bottomRight)`。

以 `grid = [[1,2,3],[3,1,5],[3,2,1]]` 中 `r-c=0` 这条对角线 `(0,0)=1,(1,1)=1,(2,2)=1` 为例：正向扫到 `(1,1)` 时集合仍是 `{1}`，`topLeft[1][1]=1`；反向扫到 `(1,1)` 时集合也是 `{1}`，`bottomRight[1][1]=1`，答案 `0`。

```python
m, n = len(grid), len(grid[0])
top = [[0]*n for _ in range(m)]
bot = [[0]*n for _ in range(m)]
starts = [(0, c) for c in range(n)] + [(r, 0) for r in range(1, m)]
for r0, c0 in starts:
    cells, r, c, seen = [], r0, c0, set()
    while r < m and c < n:
        cells.append((r, c)); r += 1; c += 1
    for r, c in cells:
        seen.add(grid[r][c]); top[r][c] = len(seen)
    seen.clear()
    for r, c in reversed(cells):
        seen.add(grid[r][c]); bot[r][c] = len(seen)
return [[abs(top[r][c] - bot[r][c]) for c in range(n)] for r in range(m)]
```

## 复杂度
时间 O(m·n)：每个格子被正反各访问一次，集合操作均摊 O(1)。
空间 O(m·n)：`top`、`bot` 两个矩阵，加单条对角线的集合（≤ min(m,n)）。

## 易错点
- 起点枚举漏掉第一列：只写 `(0,c)` 会漏掉 `(1,0)`、`(2,0)` 这类起点，`r-c<0` 的对角线全为 0，示例 1 的 `(2,0)` 会错算成 `|0-0|=0` 而非 `1`。正确做法是 `range(1,m)` 补上第一列。
- 集合忘记清空：正反两趟共用 `seen` 时若不清空，`bottomRight` 会混入左上元素，`(1,1)` 会得到 `2` 而不是 `1`。正确做法是反向扫前 `seen.clear()`。

## 如果面试官追问
若 m、n 放大到 10^5 且只要求单点答案？答：只沿该点所在对角线走两趟，时间 O(min(m,n))，空间 O(min(m,n))。
