## 一句话思路
把每条特殊路径的起点和终点当作图节点跑 Dijkstra，边权是曼哈顿距离或特殊路径 cost。

## 怎么做
1. 收集所有特殊路径的起点 `(x1,y1)` 和终点 `(x2,y2)` 作为节点，加上 `start` 和 `target`，共至多 `2n+2` 个点。
2. 任意两点 `u,v` 之间有一条权为曼哈顿距离的边；对每条特殊路径额外加一条从 `(x1,y1)` 到 `(x2,y2)`、权为 `cost` 的有向边。
3. 从 `start` 出发跑 Dijkstra，`dist[target]` 即答案；`start` 到 `target` 的直连边保证至少有一条路。

以示例 1 为例：节点含 `(1,1)`、`(1,2)`、`(3,3)`、`(3,4)`、`(4,5)`。从 `(1,1)` 出发，到 `(1,2)` 距离 1；走特殊路径 0 到 `(3,3)` 累计 1+2=3；再到 `(3,4)` 累计 4；走特殊路径 1 到 `(4,5)` 累计 5，即 `dist[target]=5`。

```python
import heapq
pts = [tuple(start), tuple(target)]
for x1, y1, x2, y2, c in specialRoads:
    pts += [(x1, y1), (x2, y2)]
pts = list(dict.fromkeys(pts))          # 去重
idx = {p: i for i, p in enumerate(pts)}
n = len(pts)
dist = [float('inf')] * n
dist[idx[tuple(start)]] = 0
pq = [(0, idx[tuple(start)])]
while pq:
    d, u = heapq.heappop(pq)
    if d > dist[u]: continue
    ux, uy = pts[u]
    for v in range(n):
        vx, vy = pts[v]
        nd = d + abs(ux - vx) + abs(uy - vy)
        if nd < dist[v]:
            dist[v] = nd; heapq.heappush(pq, (nd, v))
    # 特殊路径的有向边在下面单独松弛
```

特殊路径边在循环内按 `u == idx[(x1,y1)]` 时松弛到 `idx[(x2,y2)]`，权为 `cost`，与上面曼哈顿松弛并列即可。

## 复杂度
时间：`O(n^2 log n)`，`n = 2*len(specialRoads)+2`，堆操作贡献 `log n`。
空间：`O(n)`，存 `pts`、`dist`、堆。

## 易错点
- 特殊路径是**有向**的：示例 2 中 `specialRoads[0]` 是 `(5,7)→(3,2)`，若当成无向边会得到比 7 更小的错误答案；正确做法是只加 `(x1,y1)→(x2,y2)` 一条有向边。
- 特殊路径可能比曼哈顿距离还贵：如 `cost=10^5` 而两点相邻，若无条件用 `cost` 覆盖距离会偏大；正确做法是两种边都保留，让 Dijkstra 自己选小的。

## 如果面试官追问
问：若 `specialRoads` 规模涨到 `10^5`，`O(n^2)` 建边还行吗？
答：不行，需按坐标分桶或 KD 树做最近邻松弛，把曼哈顿边从全连接降为局部候选。
