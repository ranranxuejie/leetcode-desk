## 一句话思路
枚举每个沙漏的左上角，用行前缀和把 7 格求和压到 O(1)，避免重复加中间行。

## 怎么做
1. 对每行建前缀和 `pre[i][j+1] = pre[i][j] + grid[i][j]`，之后任意行区间可 O(1) 求和。
2. 枚举沙漏顶部所在行 `i` 从 0 到 `m-3`，左列 `j` 从 0 到 `n-3`。
3. 每个沙漏 = 第 `i` 行 `[j, j+2]` 三格 + `grid[i+1][j+1]` + 第 `i+2` 行 `[j, j+2]` 三格。
4. 取所有候选的最大值。

以示例 1 的 `grid` 为例，`i=0, j=0` 时：上排 `pre[0][3]-pre[0][0] = 9`，中间 `grid[1][1] = 2`，下排 `pre[2][3]-pre[2][0] = 19`，合计 30，正好是答案。注意 `i=1, j=0` 时上排是 `4+2+1=7`、中间 `grid[2][1]=2`、下排 `4+1+2=7`，只有 16，说明最大值确实出现在顶部行。

```python
m, n = len(grid), len(grid[0])
pre = [[0] * (n + 1) for _ in range(m)]
for i in range(m):
    for j in range(n):
        pre[i][j + 1] = pre[i][j] + grid[i][j]

best = 0
for i in range(m - 2):
    for j in range(n - 2):
        top = pre[i][j + 3] - pre[i][j]
        bot = pre[i + 2][j + 3] - pre[i + 2][j]
        best = max(best, top + grid[i + 1][j + 1] + bot)
```

## 复杂度
时间 O(m·n)：枚举 (m-2)(n-2) 个左上角，每次 O(1) 求和。
空间 O(m·n)：额外开了 m 行、n+1 列的前缀和表。

## 易错点
- 边界写成 `range(m-2)` 之外的范围（如 `range(m-1)`）→ `i+2` 越界或漏掉最后一行可用的沙漏 → 上界必须是 `m-2`、`n-2`，因为沙漏占 3 行 3 列。
- 中间格误写成 `grid[i+1][j]` 或 `grid[i+1][j+2]` → 示例 1 的 `i=0,j=0` 会算成 9+4+19=32，比正确答案 30 还大，直接错 → 中间格固定是 `grid[i+1][j+1]`，即列偏移 +1。

## 如果面试官追问
问：如果要求返回最大沙漏的左上角坐标而不是和？
答：把 `best = max(...)` 改成记录 `(top+mid+bot, i, j)` 的元组比较，返回时取后两项即可。
