## 一句话思路
按 `growTime` 从大到小排序后依次播种，累加 `plantTime` 得到完成时刻，答案取 `完成时刻 + growTime` 的最大值。

## 怎么做
1. 把下标按 `growTime` 降序排列，生长越久的越先种。
2. 用 `day` 记录当前已用掉的播种天数，每处理一枚种子先 `day += plantTime[i]`。
3. 该种子开花时刻是 `day + growTime[i]`，用它更新答案 `ans`。
4. 返回 `ans`。

以示例 1 为例：`plantTime = [1,4,3]`，`growTime = [2,3,1]`，按 growTime 降序是下标 `1,0,2`。处理下标 1：`day = 0+4 = 4`，开花 `4+3 = 7`，`ans = 7`；处理下标 0：`day = 4+1 = 5`，开花 `5+2 = 7`，`ans` 仍 7；处理下标 2：`day = 5+3 = 8`，开花 `8+1 = 9`，`ans = 9`。

```python
order = sorted(range(n), key=lambda i: -growTime[i])
day = 0
ans = 0
for i in order:
    day += plantTime[i]
    ans = max(ans, day + growTime[i])
return ans
```

关键点：`day` 是「这枚种子播种完成的那一天」，因为播种从第 0 天开始算，所以第 `day` 天完成播种、再生长 `growTime[i]` 天，开花就是 `day + growTime[i]`。示例 1 里下标 2 的种子在第 8 天播完，生长 1 天，第 9 天开花，与输出一致。

## 复杂度
时间：排序 `O(n log n)`，遍历 `O(n)`，共 `O(n log n)`。
空间：`order` 列表占 `O(n)`，其余是常数。

## 易错点
- 把 `growTime` 升序排 → 示例 1 会得到 `day` 累加后长生长种子排在最后，答案偏大（如按 `0,2,1` 顺序算得 10 而非 9）→ 必须降序，让 `growTime` 大的先占用 `day`。
- 开花时刻写成 `day + growTime[i] - 1` 或漏加 `plantTime` → 示例 3 单元素会输出 1 而非 2 → 记住 `day` 在累加后已是「播种完成日」，开花日直接是 `day + growTime[i]`，不减一。

## 如果面试官追问
问：如果要求输出具体播种顺序怎么办？
答：排序后的 `order` 就是最优顺序，直接返回它即可，因为任意同 `growTime` 的排列都不影响答案。
