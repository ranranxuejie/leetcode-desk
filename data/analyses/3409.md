## 一句话思路
按末尾元素值和最后一个差值做二维 DP，值域只有 300，直接开表枚举。

## 怎么做
1. 定义 `dp[v][d]`：以值 `v` 结尾、最后一步绝对差为 `d` 的子序列最大长度。
2. 遍历 `nums` 的每个 `x`，枚举前一个值 `v`（1..300），差值 `d = abs(x - v)`。
3. 转移 `dp[x][d] = max(dp[x][d], dp[v][d'] + 1)`，其中 `d' >= d`，用后缀最大值 `best[v][d] = max(dp[v][d..300])` 加速。
4. 答案取所有 `dp` 的最大值。

以示例 2 `nums = [6,5,3,4,2,1]` 为例：处理到 `x=4`、前值 `v=6` 时 `d=2`，`best[6][2]` 已包含 `dp[6][2]=2`（序列 `[6,4]` 之前是 `[6]` 加差 2），于是 `dp[4][2]=3`，对应 `[6,4]` 再接 `4` 得 `[6,4]`… 实际最终 `[6,4,2,1]` 长度 4。

```python
M = 300
dp = [[0] * (M + 1) for _ in range(M + 1)]
best = [[0] * (M + 2) for _ in range(M + 1)]
ans = 1
for x in nums:
    for v in range(1, M + 1):
        d = abs(x - v)
        if best[v][d] + 1 > dp[x][d]:
            dp[x][d] = best[v][d] + 1
    for d in range(M, -1, -1):
        best[x][d] = max(dp[x][d], best[x][d + 1])
    ans = max(ans, best[x][0])
```

## 复杂度
时间：O(n · 300)，n 来自 `nums` 长度，300 是值域枚举。
空间：O(300²)，开了 `dp` 和 `best` 两张 301×302 表。

## 易错点
- 输入 `nums = [16,6,3]`：若只按 `dp[x][d]` 直接查 `dp[v][d]` 而不查 `d' >= d` 的后缀最大值，会漏掉 `[16,6,3]`（差 10 后接差 3），错成 2；必须用 `best[v][d]` 覆盖所有 `d' >= d`。
- 输入 `nums = [10,20,10,19,10,20]`：若把 `best` 更新放在内层循环之前，`x` 自己刚写入的 `dp[x][d]` 还没进 `best`，后续同值转移会少一层；正确做法是每处理完一个 `x` 立刻从 `d=300` 倒序刷新 `best[x]`。

## 如果面试官追问
问：值域放大到 10^9 怎么办？
答：改用按 `nums` 中出现的值离散化 + 对每个末尾值维护差值的单调结构，或换 O(n²) 枚举前驱。
