## 一句话思路
先贪心用类型 3 边给两人共用，再各自用类型 1/2 边补连通，能合并的边就是可删的。

## 怎么做
1. 建两个并查集 `uf_a`、`uf_b`，`ans = 0`。
2. 先扫所有 `type == 3` 的边：若 `uf_a.union(u,v)` 成功则 `ans += 1`，同时 `uf_b.union(u,v)`（两边都并，因为这条边两人都能用）。
3. 再扫 `type == 1` 的边只并 `uf_a`，`type == 2` 的边只并 `uf_b`，每次 union 成功就 `ans += 1`。
4. 最后检查 `uf_a` 和 `uf_b` 是否都只剩一个连通块（即合并次数各达 `n-1`），否则返回 `-1`。

以示例 1 为例：`n=4`，先处理三条 type 3 边 `[3,1,2]`、`[3,2,3]`，`uf_a` 合并两次得 `{1,2,3}`，`ans=2`；再处理 type 1 边 `[1,1,3]` 时 1、3 已连通，union 失败，这条边可删，`ans` 不变；`[1,2,4]` 合并成功 `ans=3`；`[1,1,2]` 失败；type 2 边 `[2,3,4]` 合并成功 `ans=4`。最终 `ans=4`，可删边数 `len(edges)-ans = 6-4 = 2`。

```python
# 关键循环
for t, u, v in edges:
    if t == 3:
        if uf_a.union(u, v):
            ans += 1
            uf_b.union(u, v)
for t, u, v in edges:
    if t == 1 and uf_a.union(u, v):
        ans += 1
    elif t == 2 and uf_b.union(u, v):
        ans += 1
if uf_a.count != 1 or uf_b.count != 1:
    return -1
return len(edges) - ans
```

## 复杂度
时间：`O(m α(n))`，`m = len(edges)`，每条边两次 find，α 近似常数。
空间：`O(n)`，两个并查集的 parent 和 size 数组。

## 易错点
1. 类型 3 边只并了 `uf_a` 忘了并 `uf_b` → 示例 1 中 Bob 会少一条 `[3,1,2]` 的连通，导致 `uf_b` 连通块数 >1 误返回 -1 → 正确做法是 type 3 边在两个并查集里都要 union，但 `ans` 只加一次。
2. 先处理 type 1/2 再处理 type 3 → 示例 1 中 `[1,1,3]` 会先被 union 成功计入 `ans`，之后 type 3 边 `[3,1,2]` 无法合并 1 和 3，`ans` 偏大导致结果偏小 → 正确做法是必须让 type 3 边优先，因为它能同时服务两人，复用价值最高。

## 如果面试官追问
问：如果要求输出具体删除哪些边怎么办？
答：在 union 失败时把该边的下标记入删除列表，成功时记入保留列表，最后返回删除列表即可。
