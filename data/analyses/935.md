## 一句话思路
按「最后落在哪个数字」做 DP，因为每个数字的下一步只由骑士跳法决定，与之前路径无关。

## 怎么做
1. 先手写邻接表 `nxt`：0→{4,6}，1→{6,8}，2→{7,9}，3→{4,8}，4→{0,3,9}，5→{}，6→{0,1,7}，7→{2,6}，8→{1,3}，9→{2,4}。注意 5 是死格。
2. 定义 `dp[d]` = 长度为当前步数、末位是 d 的号码个数，初始 `dp = [1]*10`（n=1 时每个数字各算一种）。
3. 每轮新建 `ndp = [0]*10`，对每个 d 把 `dp[d]` 累加到 `nxt[d]` 的每个目标上，再整体取模。
4. 重复 n-1 轮后返回 `sum(dp) % (10**9+7)`。

以 n=2 为例：初始 `dp=[1]*10`。处理 d=0 时把 1 加到 `ndp[4]` 和 `ndp[6]`；处理 d=1 时加到 `ndp[6]`、`ndp[8]`。全部跑完后 `ndp[6]=2`（来自 0 和 1），`ndp[4]=2`（来自 0 和 3），`ndp[5]=0`，`sum(ndp)=20`，与示例一致。

```python
MOD = 10**9 + 7
nxt = [[4,6],[6,8],[7,9],[4,8],[0,3,9],[],[0,1,7],[2,6],[1,3],[2,4]]
dp = [1] * 10
for _ in range(n - 1):
    ndp = [0] * 10
    for d in range(10):
        v = dp[d]
        for t in nxt[d]:
            ndp[t] = (ndp[t] + v) % MOD
    dp = ndp
return sum(dp) % MOD
```

## 复杂度
时间 O(n × 10 × 平均出度) = O(n)，出度最多 3，常数极小。
空间 O(10)，只开 `dp` 和 `ndp` 两个长度 10 的数组。

## 易错点
- n=1 时若先做一轮转移再求和，会得到 20 而不是 10 → 循环必须写 `range(n-1)`，初始 `dp` 全 1 直接对应长度 1。
- 数字 5 没有合法跳法 → 若把 `nxt[5]` 写成 `[5]` 或漏掉、或对 5 做自环，n=2 会多出 5 结尾的号码，答案从 20 变大；正确做法是 `nxt[5] = []`，它只在 n=1 时贡献 1。
- n=3131 时累加会远超模数 → 若只在最后 `sum(dp) % MOD` 而不在每轮取模，中间值会膨胀到几千位；正确做法是 `ndp[t] = (ndp[t] + v) % MOD` 每步取模。

## 如果面试官追问
问：n 大到 10^9 怎么办？
答：转移是固定 10×10 矩阵，用矩阵快速幂把 O(n) 降到 O(10^3 log n)。
