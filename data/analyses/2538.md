## 一句话思路
两次换根 DP：先求以 0 为根时每棵子树的「向下最大/最小路径和」，再换根求出每个节点作为根时的全局最大/最小路径和。

## 怎么做
1. 以 0 为根建树，后序 DFS 求 `down_max[u]` = 从 u 出发向下的最大路径和（至少含 u 本身），`down_min[u]` 同理。
2. 换根：`up_max[u]` 表示从 u 出发、经过父节点方向的最大路径和；用父节点 p 的 `up_max[p]` 和 p 的其他孩子 `down_max` 拼出。
3. 对每个 u，`best_max[u] = max(down_max[u], up_max[u])`，`best_min[u]` 同理，答案取 `max(best_max[u] - best_min[u])`。

以示例 1 为例，根为 2 时：`down_max[1]` 取孩子 3 方向得 `8+6+10=24`，加上 2 的 7 得 31；`down_min[2]=7`，差 24。

```python
def dfs(u, p):
    dmx = dmn = price[u]
    for v in g[u]:
        if v == p: continue
        dfs(v, u)
        dmx = max(dmx, price[u] + down_max[v])
        dmn = min(dmn, price[u] + down_min[v])
    down_max[u], down_min[u] = dmx, dmn

def reroot(u, p, up_mx, up_mn):
    best_max[u] = max(down_max[u], up_mx)
    best_min[u] = min(down_min[u], up_mn)
    for v in g[u]:
        if v == p: continue
        # 用 u 的其他分支拼出 v 的 up 值
        cand = [up_mx] + [price[u] + down_max[w] for w in g[u] if w not in (p, v)]
        cand2 = [up_mn] + [price[u] + down_min[w] for w in g[u] if w not in (p, v)]
        reroot(v, u, price[v] + max(cand), price[v] + min(cand2))
```

## 复杂度
时间：O(n)，每个节点在换根时枚举邻居，总边数 2(n-1)。
空间：O(n)，邻接表 + 4 个 DP 数组。

## 易错点
- 换根时若只取 `up_max[p]` 而漏掉 p 的其他孩子分支，示例 1 中根为 4 时会少算 3→1→2 这条链，答案偏小；正确做法是枚举 p 除 v 外的所有邻居取 max。
- `down_min` 初值必须设为 `price[u]` 而非 0 或无穷，因为路径至少含 u 本身；示例 2 全为 1 时若初值 0，`best_min` 会算成 0，答案错成 3 而非 2。

## 如果面试官追问
要求输出取得最大开销的根节点编号？答：在 `best_max[u]-best_min[u]` 取最大时记录 u 即可，换根过程已算出所有 u 的值。
