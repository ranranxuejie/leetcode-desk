## 一句话思路
先对 salary 去重降序，用 `LIMIT 1 OFFSET n-1` 取第 n 个；取不到就返回 None。

## 怎么做
1. 用 `DISTINCT` 去重，因为题目要的是第 n 高的**不同**工资，重复的 200 不能占两个名次。
2. 按 `salary DESC` 排序，让第 1 高排在第 0 位，第 n 高就落在偏移 `n-1`。
3. 用 `LIMIT 1 OFFSET n-1` 取那一行；行不存在时游标返回空，映射成 `None`。
4. 把结果作为单列 `getNthHighestSalary(n)` 返回。

拿示例 1 走一遍：去重降序后是 `[300, 200, 100]`，n=2 时 `OFFSET 1` 跳过 300，取到 `200`。示例 2 去重后只有 `[100]`，`OFFSET 1` 越界，游标 `fetchone()` 返回 `None`，正好对上题面要求的 null。

```python
def nth_highest_salary(conn, n):
    cur = conn.cursor()
    cur.execute(
        "SELECT DISTINCT salary FROM Employee "
        "ORDER BY salary DESC LIMIT 1 OFFSET %s",
        (n - 1,),
    )
    row = cur.fetchone()
    return row[0] if row else None
```

关键点：`OFFSET` 绑定的是 `n - 1` 而不是 `n`，这是本题唯一容易写反的算术；`LIMIT 1` 保证只返回一个标量而不是列表。

## 复杂度
时间：O(m log m)，m 是去重后的工资数，排序贡献 log m，OFFSET 扫描贡献 n。
空间：O(m)，去重排序的中间结果；若走索引可降到 O(1) 额外空间。

## 易错点
- 忘了 `DISTINCT`：输入 salary 为 `[300, 300, 200]`、n=2 时，不去重会返回 300，正确答案是 200。必须先对 salary 去重再排序。
- 把 `OFFSET` 写成 `n`：示例 1 中 n=2、`OFFSET 2` 会跳过 300 和 200 直接取到 100，答案错成 100。偏移量恒为 `n-1`。
- 用 `fetchone()` 后直接取 `row[0]`：示例 2 中 row 是 `None`，会抛 `TypeError`。要先判空再取值，返回 `None`。

## 如果面试官追问
问：n 可能为 0 或负数怎么办？
答：先判 `n < 1` 直接返回 `None`，否则 `OFFSET n-1` 为负会报语法错误。
