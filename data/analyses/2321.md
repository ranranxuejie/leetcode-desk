## 一句话思路
把交换看成「用 nums2 的一段替换 nums1 的一段」，收益是逐位差 `nums2[i]-nums1[i]`，求最大子段和即可。

## 怎么做
1. 先算 `s1 = sum(nums1)`、`s2 = sum(nums2)`，答案至少是 `max(s1, s2)`（不交换）。
2. 若把 nums2 的 `[left,right]` 换进 nums1，新和 = `s1 + sum(nums2[i]-nums1[i] for i in 区间)`，所以只需在差数组 `d = nums2[i]-nums1[i]` 上求最大子段和。
3. 反向同理：在 `-d` 上求最大子段和，加到 `s2` 上。
4. 取三者最大。用 Kadane：`cur = max(d[i], cur + d[i])`，`best = max(best, cur)`。

以示例 1 为例：`s1=180, s2=110`，`d = [-50, 30, -50]`。Kadane 到 i=1 时 `cur = max(30, -50+30) = 30`，`best = 30`，得 `180+30 = 210`；反向 `-d` 的最大子段和是 `-50`（单元素），`110-50=60`，最终 `max(180,110,210,60)=210`。

```python
def best_gain(a, b):          # 把 b 的一段换进 a 的最大增量
    cur = best = 0
    for x, y in zip(a, b):
        cur = max(y - x, cur + y - x)
        best = max(best, cur)
    return best

s1, s2 = sum(nums1), sum(nums2)
return max(s1 + best_gain(nums1, nums2),
           s2 + best_gain(nums2, nums1))
```

注意 `best` 初值取 0，等价于「允许不交换」，正好覆盖示例 3（`d = [-6,-10,-12]`，`best` 保持 0，返回 31）。

## 复杂度
时间 O(n)：两趟 Kadane 各扫一遍，n 为数组长度。
空间 O(1)：只存 `cur/best/s1/s2`，不额外开差数组。

## 易错点
- 只做单向（只算把 nums2 换进 nums1）→ 示例 2 会错成 `140+30=170`，正确是反向：`s2=180`，`-d=[30,-20,30,-30,10]` 最大子段和 40，得 220。必须两个方向都算。
- 把 `best` 初始化成 `-inf` 或 `d[0]` → 示例 3 这种全负差数组会返回 `s1-6=25`，而正确是允许不交换的 31。`best` 初值必须是 0。

## 如果面试官追问
要求输出具体的 left/right 怎么办？答：Kadane 里记下当前段的起点，`best` 更新时同步记 `(start, i)`，反向再跑一次取更优的那组即可。
