## 一句话思路
把三行字母映射成行号 0/1/2，每个单词统一小写后看所有字符行号是否相同。

## 怎么做
1. 建一个字典 `row`，把 `"qwertyuiop"`、`"asdfjkl"`、`"zxcvbnm"` 的每个字符映射到 0、1、2。
2. 对每个 `w`，取 `w.lower()` 首字符的行号 `r`，作为该词的基准行。
3. 遍历 `w.lower()` 的每个字符，若某个字符行号不等于 `r` 就判为不合格，跳出。
4. 全部字符同行的 `w` 追加进结果。

以 `words = ["Hello","Alaska","Dad","Peace"]` 为例：`"Hello".lower()` 首字符 `h` 在 `"qwertyuiop"` 中，`r = 0`；继续看 `e`（0）、`l`（1）——`l` 行号 1 ≠ 0，立刻淘汰。`"Alaska".lower()` 首字符 `a` 行号 1，后续 `l`、`a`、`s`、`k`、`a` 全是 1，保留。`"Dad"` 首字符 `d` 行号 1，`a`、`d` 也都是 1，保留。`"Peace"` 首字符 `p` 行号 0，`e` 是 0，但 `a` 是 1，淘汰。最终 `["Alaska","Dad"]`。

```python
row = {}
for i, line in enumerate(["qwertyuiop", "asdfghjkl", "zxcvbnm"]):
    for ch in line:
        row[ch] = i

res = []
for w in words:
    low = w.lower()
    r = row[low[0]]
    if all(row[ch] == r for ch in low):
        res.append(w)
```

关键点：`row[low[0]]` 只算一次，避免每个字符都重新取首字符行号；`all(...)` 短路，遇到第一个异行字符就停。

## 复杂度
时间：O(总字符数)，每个单词的每个字符最多查一次字典。
空间：O(1)，`row` 固定 26 项，`res` 不计入额外空间。

## 易错点
- 输入 `["Hello"]` → 若忘记 `.lower()`，`'H'` 不在 `row` 里会抛 `KeyError`；正确做法是先 `low = w.lower()` 再查表，或建表时同时放大小写两套键。
- 输入 `["adsdf","sfd"]` → 若只比较首尾字符或只比较首字符，`"adsdf"` 会因首字符 `a` 行号 1 被误判通过，但若单词是 `"az"` 这种首尾同行中间异行的会漏判；正确做法是遍历全部字符，不能只看首尾。

## 如果面试官追问
若键盘布局作为参数传入（多组布局、每组三行），怎么改？答：把建 `row` 的循环抽成函数，对每组布局各建一次表，再对 `words` 逐词判定。
