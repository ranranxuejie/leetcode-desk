## 一句话思路
用根到每个节点的字符奇偶掩码，路径可重排成回文当且仅当两端掩码异或后 popcount ≤ 1，DFS 时用哈希表边遍历边配对。

## 怎么做
1. 定义 `mask[v]` 为根到 v 路径上各字符出现次数的奇偶性（26 位），`mask[0] = 0`，子节点 `mask[v] = mask[parent[v]] ^ (1 << (ord(s[v]) - 97))`。
2. 路径 u→v 的字符奇偶 = `mask[u] ^ mask[v]`，可重排成回文 ⟺ 该值 popcount 为 0 或 1。
3. DFS 到节点 v 时，先查哈希表里已有多少 `mask[u]` 满足 `mask[u] == mask[v]` 或 `mask[u] == mask[v] ^ (1 << k)`（k 取 0..25），累加进答案，再把 `mask[v]` 计数加一。
4. 用 `parent` 数组建子节点列表后从 0 迭代或递归遍历；n 达 1e5，递归需 `sys.setrecursionlimit` 或改显式栈。

以示例 1 为例：`parent = [-1,0,0,1,1,2]`，`s = "acaabc"`。算到节点 3 时 `mask[3] = mask[1] ^ bit('a') = (1<<2) ^ (1<<0) = 5`；节点 5 的 `mask[5] = mask[2] ^ bit('c') = (1<<0) ^ (1<<2) = 5`，两者相等，popcount 为 0，配对成功，对应路径 "acac"。

```python
cnt = {0: 1}
ans = 0
for v in order:                      # order 为 BFS/DFS 序，父先于子
    m = mask[v]
    ans += cnt.get(m, 0)
    for k in range(26):
        ans += cnt.get(m ^ (1 << k), 0)
    cnt[m] = cnt.get(m, 0) + 1
```

## 复杂度
时间 O(26n)：每个节点查 27 次哈希表，建树 O(n)。
空间 O(n)：`mask`、`cnt`、子节点列表各占 O(n)，26 是常数。

## 易错点
- 只查 `mask[u] == mask[v]` 漏掉奇数长度路径：如示例 1 的 (0,1)，`mask[0]=0`、`mask[1]=4`，异或 popcount 为 1 也算回文，必须补查 26 个 `m ^ (1<<k)`。
- 边遍历边配对而非先统计全部再配对：若先把所有 `mask` 塞进 `cnt` 再查，会把 v 自己和祖先/后代重复计入且方向混乱；正确做法是 DFS 进入节点时先查已有计数、再插入自身，保证只统计已访问的祖先侧节点，天然满足 u < v 不重不漏。

## 如果面试官追问
若要求输出所有合法节点对而非计数？答：哈希表 value 从计数改成节点列表，配对时逐个产出，空间升到 O(答案规模)。
