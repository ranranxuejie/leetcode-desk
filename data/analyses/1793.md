## 一句话思路
从 `k` 向两侧扩张，每次把当前最小值那一侧继续扩，用单调栈预处理每个位置能扩到的左右边界。

## 怎么做
1. 单调栈求 `left[i]`：`nums[i]` 作为最小值时最左能到的下标（左边第一个严格小于它的位置 +1）。
2. 同理求 `right[i]`：最右能到的下标（右边第一个严格小于它的位置 -1）。
3. 枚举每个 `i`，若 `left[i] <= k <= right[i]`，则候选分数为 `nums[i] * (right[i] - left[i] + 1)`，取最大。

以 `nums = [1,4,3,7,4,5], k = 3` 为例：`i=2`（值 3）时 `left[2]=1`、`right[2]=5`，区间 `[1,5]` 含 `k=3`，分数 `3*5=15`；`i=3`（值 7）区间只有 `[3,3]`，分数 7，被 15 压过。

```python
n = len(nums)
left, right = [0]*n, [0]*n
st = []
for i in range(n):
    while st and nums[st[-1]] >= nums[i]:
        st.pop()
    left[i] = st[-1] + 1 if st else 0
    st.append(i)
st = []
for i in range(n-1, -1, -1):
    while st and nums[st[-1]] >= nums[i]:
        st.pop()
    right[i] = st[-1] - 1 if st else n-1
    st.append(i)
ans = 0
for i in range(n):
    if left[i] <= k <= right[i]:
        ans = max(ans, nums[i] * (right[i] - left[i] + 1))
```

## 复杂度
时间 O(n)：两遍单调栈各 O(n)，枚举 O(n)。
空间 O(n)：`left`、`right`、栈各占 n。

## 易错点
- 栈弹出条件写成 `>` 而非 `>=`：`nums = [5,5,4,5,4,1,1,1], k = 0` 时，相等的 5 会互相挡住，`i=0` 的 `right[0]` 只到 0，分数算成 5，正确是 20。必须用 `>=` 让相等元素共享边界。
- 枚举时漏判 `left[i] <= k <= right[i]`：如 `nums=[1,4,3,7,4,5], k=3`，`i=0`（值 1）区间 `[0,5]` 也含 k，分数 6 无害；但若 `k=0` 而某元素区间不含 k，直接乘会得到非法子数组的分数，必须过滤。

## 如果面试官追问
问：不用单调栈，双指针从 k 往外扩行不行？
答：行，每次扩当前较小值那一侧，O(n) 且常数更小，但正确性要论证「最小值只降不升」。
