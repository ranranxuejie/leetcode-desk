## 一句话思路
只有 4! = 24 种排列，全枚举出 `HH:MM` 并筛掉非法值，取最大字符串即可。

## 怎么做
1. 用 `itertools.permutations(arr)` 生成全部 24 个排列，每个排列 `p` 直接按 `p[0]p[1]:p[2]p[3]` 拼成时间。
2. 合法性只看两个数：`p[0]*10+p[1] <= 23` 且 `p[2]*10+p[3] <= 59`。
3. 合法就转成 `"%d%d:%d%d"` 字符串，与当前 `best` 比较取较大者（等长字符串字典序即时间序）。
4. 循环结束若 `best` 仍为空串，说明 24 种全非法，返回 `""`。

以 `arr = [1,2,3,4]` 为例，排列 `(2,3,4,1)` 时 `p[0]*10+p[1] = 23 <= 23`、`p[2]*10+p[3] = 41 <= 59`，得到 `"23:41"`；而 `(4,3,2,1)` 的 `43 > 23` 被直接丢弃。最终 `best` 停在 `"23:41"`。

```python
from itertools import permutations

best = ""
for p in permutations(arr):
    hh = p[0] * 10 + p[1]
    mm = p[2] * 10 + p[3]
    if hh <= 23 and mm <= 59:
        t = f"{p[0]}{p[1]}:{p[2]}{p[3]}"
        if t > best:
            best = t
return best
```

关键点：`permutations` 会把重复数字也当成不同元素重复枚举（`[5,5,5,5]` 出 24 个相同排列），但 24 次判断的代价可以忽略，不必去重。

## 复杂度
时间：O(4!) = O(1)，24 个排列各做常数次比较，与输入规模无关。
空间：O(1)，只存 `best` 和一个排列元组，`permutations` 是惰性生成器不占额外数组。

## 易错点
- 输入 `[0,0,1,0]` → 若只按「小时位优先取最大」贪心，会先选 `1` 当十位、再选 `0` 当个位得 `10`，但若贪心顺序写反（先选 `0` 当十位）就得到 `01:00`，错成 `"01:00"` 而非 `"10:00"`；正确做法是枚举全部排列后比字符串，不做局部贪心。
- 输入 `[5,5,5,5]` → 若只校验 `hh <= 23` 忘了 `mm <= 59`，或把 `55` 误判成合法小时，会返回 `"55:55"`；正确做法是两个条件都必须满足，且 `best` 初值为空串，全非法时原样返回 `""` 而不是 `"00:00"`。

## 如果面试官追问
问：如果 arr 长度变成 6，要求组成 `HH:MM:SS` 的最大时间？
答：仍是全排列枚举，6! = 720 次判断，把合法性拆成三组 `<= 23 / 59 / 59` 即可，复杂度 O(n!)。
