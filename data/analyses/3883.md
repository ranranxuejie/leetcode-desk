## 一句话思路
先枚举 0..5000 中每个数位和对应的有序数字列表，再用前缀和 DP 逐位累加「上一位不超过当前值」的方案数。

## 怎么做
1. 预处理 `vals[s]`：遍历 `x` 从 0 到 5000，按数位和 `s` 分桶，桶内天然升序。
2. 若任一 `digitSum[i]` 的桶为空（如 49），直接返回 0。
3. DP 定义 `f[v]` = 以值 `v` 结尾的合法前缀数；初始 `f[v]=1` 对所有 `v in vals[digitSum[0]]`。
4. 逐位转移：对 `vals[digitSum[i]]` 中每个 `v`，`new_f[v] = sum(f[u] for u <= v)`，用前缀和一次扫完。

以 `digitSum=[25,1]` 为例：`vals[25]=[799,889,898,979,988,997]`，`vals[1]=[1,10,100,1000]`。转移时对 `v=1000`，前缀和覆盖全部 6 个 `u`，得 `new_f[1000]=6`；对 `v=1` 前缀和为 0。最终答案 6。

```python
MOD = 10**9 + 7
vals = [[] for _ in range(51)]
for x in range(5001):
    vals[sum(map(int, str(x)))].append(x)
if any(not vals[s] for s in digitSum):
    return 0
f = {v: 1 for v in vals[digitSum[0]]}
for s in digitSum[1:]:
    nf, run = {}, 0
    for v in vals[s]:
        run = (run + f.get(v, 0)) % MOD
        nf[v] = run
    f = nf
return sum(f.values()) % MOD
```

## 复杂度
时间：预处理 O(5000·4)，DP 为 O(n·|vals|) ≤ O(n·5000)，n 来自 `digitSum` 长度。
空间：`vals` 存 5001 个数，DP 字典最多 5001 项。

## 易错点
- `digitSum=[2,49,23]`：若跳过空桶检查，`vals[49]` 为空会让 `f` 变成空字典，后续 `sum` 得 0 看似对，但若空桶在中间而后面有值，会误算出非零。正确做法是开头 `any(not vals[s])` 直接返回 0。
- `digitSum=[1]`：若把 `f` 初始化成 `{v:1 for v in range(5001)}` 而非只取 `vals[1]`，会把数位和不为 1 的数也算进去，答案变成 5001 而非 4。正确做法是初始只填 `vals[digitSum[0]]`。

## 如果面试官追问
若把上界 5000 改成 10^9，怎么办？答：数位和相同的数不再连续，需按数位 DP 分段统计「≤v 且数位和为 s」的个数，转移用该计数函数做前缀和。
