## 一句话思路
先按 `num` 分组计数，筛出计数为 1 的行，再取 `MAX`；没有这样的行时聚合返回 `NULL`。

## 怎么做
1. 用 `GROUP BY num` 把相同数字聚成一组，`COUNT(*)` 得到每个数字出现次数。
2. 用 `HAVING COUNT(*) = 1` 只留下单一数字。
3. 外层对结果取 `MAX(num)`，聚合在空集上返回 `NULL`，正好满足示例 2。

以示例 1 为例，分组后 `8→2, 3→2, 1→1, 4→1, 5→1, 6→1`；`HAVING` 过滤后剩 `{1,4,5,6}`，`MAX` 得 `6`。示例 2 过滤后集合为空，`MAX` 返回 `NULL`。

```python
# 思路等价写法（非提交代码）
from collections import Counter

def biggest_single_number(nums):
    cnt = Counter(nums)                      # 8:2, 3:2, 1:1, 4:1, 5:1, 6:1
    singles = [x for x, c in cnt.items() if c == 1]  # [1, 4, 5, 6]
    return max(singles) if singles else None  # 6 / None
```

SQL 版本关键三行：

```python
# SELECT MAX(num) AS num
# FROM (SELECT num FROM MyNumbers GROUP BY num HAVING COUNT(*) = 1) t
```

注意 `MAX` 必须写在外层，不能写成 `SELECT num ... ORDER BY num DESC LIMIT 1` 再指望空集返回 `NULL`——那样空集返回 0 行，不是一行 `NULL`。

## 复杂度
时间：O(n)，扫描全表计数，分组与取最大值都是线性。
空间：O(d)，d 为不同 `num` 的个数，即哈希表/分组结果的大小。

## 易错点
- 输入全是重复数字（示例 2 的 `8,8,7,7,3,3,3`）→ 用 `ORDER BY num DESC LIMIT 1` 会返回 0 行，判题认为结果为空而非 `NULL` → 必须用 `MAX(num)` 聚合，空集自动给一行 `NULL`。
- 输入含负数或 0（如 `-5,-5,0`）→ 若用 `MAX` 前先 `WHERE num > 0` 过滤会漏掉 0 这个单一数字 → 不要加任何数值范围条件，只按 `COUNT(*) = 1` 筛。

## 如果面试官追问
问：如果要求返回所有单一数字而非最大？
答：去掉外层 `MAX`，直接 `SELECT num FROM MyNumbers GROUP BY num HAVING COUNT(*) = 1 ORDER BY num`，空集返回 0 行。
