## 一句话思路
答案关于峰值单调，二分峰值 x，用 O(1) 公式算「以 x 为峰、两侧每步降 1 且不低于 1」的最小总和，与 maxSum 比较。

## 怎么做
1. 写 `cost(x)`：峰值为 x 时，左侧 index 个位置的最小和 + 右侧 n-1-index 个位置的最小和 + x。
2. 单侧长度 L、峰值 x 的最小和：若 `x > L`，是 `(x-1 + x-L) * L // 2`；否则是 `(x-1 + 1) * (x-1) // 2 + (L - (x-1))`（降到 1 后剩下的位置全填 1）。
3. 在 `[1, maxSum]` 上二分最大的满足 `cost(x) <= maxSum` 的 x。

以示例 1（n=4, index=2, maxSum=6）为例，试 x=2：左侧 L=2，x-1=1 ≤ L，左和 = `(1+1)*1//2 + (2-1)` = 2；右侧 L=1，x-1=1 ≤ 1，右和 = `(1+1)*1//2 + 0` = 1；总 = 2+1+2 = 5 ≤ 6，可行。试 x=3：左和 = `(2+1)*2//2` = 3，右和 = `(2+1)*1//2` = 1，总 = 3+1+3 = 7 > 6，不可行，故答案 2。

```python
def side(L, x):
    if x - 1 >= L:
        return (x - 1 + x - L) * L // 2
    return (x - 1 + 1) * (x - 1) // 2 + (L - (x - 1))

def cost(x):
    return side(index, x) + side(n - 1 - index, x) + x

lo, hi = 1, maxSum
while lo < hi:
    mid = (lo + hi + 1) // 2
    if cost(mid) <= maxSum:
        lo = mid
    else:
        hi = mid - 1
return lo
```

## 复杂度
时间：二分 log(maxSum) 次，每次 cost 是 O(1)，与 n 无关。
空间：只开 lo/hi/mid 几个整数，O(1)。

## 易错点
- n=1 时 index=0，两侧长度都是 0，`side(0, x)` 必须返回 0；若公式写成 `(x-1+1)*(x-1)//2` 会算出正数，导致 cost 偏大、答案偏小。正确做法是先判 `L == 0` 直接返回 0。
- 峰值很大时（如 n=1, maxSum=10^9），`(x-1+x-L)*L//2` 中间值可达 10^18 量级；Python 不会溢出，但若把这段逻辑照搬到 32 位语言需用 64 位。本题只需保证 `cost(mid) <= maxSum` 比较时不被截断，Python 直接比即可。

## 如果面试官追问
问：要求输出整个数组而不只是峰值？
答：二分定出峰值后，从 index 向两侧各按 `min(前一个-1, 峰值)` 且不低于 1 填，多余预算全塞到最远端。
