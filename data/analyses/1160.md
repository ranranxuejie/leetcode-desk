## 一句话思路
用长度为 26 的计数数组记录 `chars` 每个字母的可用次数，再逐个 `words` 消耗计数，能消耗完就累加长度。

## 怎么做
1. 建 `need = [0]*26`，遍历 `chars` 做 `need[ord(c)-97] += 1`。
2. 对每个 `word`，复制一份 `need` 为 `cnt`，逐字符 `cnt[ord(ch)-97] -= 1`。
3. 若某步 `cnt[i] < 0`，该词不合格，直接跳过。
4. 全部字符消耗成功，`ans += len(word)`。

以示例 1 为例：`chars = "atach"` 得到 `need` 中 a=2、t=1、c=1、h=1。处理 `"cat"` 时依次扣减 c→0、a→1、t→0，无负数，累加 3；处理 `"bt"` 时 b 扣成 -1，跳过；`"hat"` 扣 h→0、a→0、t→0，累加 3；`"tree"` 第二个 e 扣成 -1，跳过。最终 `ans = 6`。

```python
need = [0] * 26
for c in chars:
    need[ord(c) - 97] += 1
ans = 0
for w in words:
    cnt = need[:]
    ok = True
    for ch in w:
        i = ord(ch) - 97
        cnt[i] -= 1
        if cnt[i] < 0:
            ok = False
            break
    if ok:
        ans += len(w)
```

关键点：`cnt = need[:]` 必须每个词重新复制，否则前一个词的消耗会污染后一个词。

## 复杂度
时间 O(len(chars) + 所有 words 字符总数)，每个字符 O(1) 查表。
空间 O(1)，只开了两个长度 26 的数组。

## 易错点
- 输入 `words = ["cat","bt","hat","tree"]` 时若忘记 `cnt = need[:]` 复制，`"cat"` 扣掉 a 后 `"hat"` 的 a 会不够，把 `"hat"` 误判为不合格，答案错成 3。正确做法是每个词开头重新复制 `need`。
- 输入 `words = ["hello"]`、`chars = "helo"` 时，若只判断「字符是否出现在 chars 中」而不看次数，`"hello"` 的两个 l 会被误判通过，答案错成 5。正确做法是扣减后检查 `cnt[i] < 0`，l 第二次扣减即为 -1。

## 如果面试官追问
若 `chars` 长度到 10^5 且 `words` 数量到 10^5，还能用计数数组吗？
能，26 个桶与规模无关，瓶颈变成所有词的总字符数，仍是线性。
