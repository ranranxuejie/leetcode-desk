## 一句话思路
双指针分别扫描偶数位和奇数位，发现错位就交换，因为奇偶各占一半，交换后双方必然同时归位。

## 怎么做
1. 令 `i = 0` 扫偶数下标、`j = 1` 扫奇数下标，各自只在自己奇偶性上走。
2. `i` 停在「偶数位却放了奇数」的位置，`j` 停在「奇数位却放了偶数」的位置。
3. 此时 `nums[i]` 是奇数、`nums[j]` 是偶数，直接交换，两个位置同时修好。
4. 交换后 `i += 2`、`j += 2` 继续，直到越界。

以 `nums = [4,2,5,7]` 为例：`i=0` 时 `nums[0]=4` 是偶数，合法，`i` 走到 2；`nums[2]=5` 是奇数，`i` 停在 2。`j=1` 时 `nums[1]=2` 是偶数，`j` 停在 1。交换 `nums[2]` 与 `nums[1]`，数组变成 `[4,5,2,7]`，两个指针各 +2 后都越界，结束。

```python
i, j = 0, 1
n = len(nums)
while i < n and j < n:
    while i < n and nums[i] % 2 == 0:
        i += 2
    while j < n and nums[j] % 2 == 1:
        j += 2
    if i < n and j < n:
        nums[i], nums[j] = nums[j], nums[i]
        i += 2
        j += 2
return nums
```

关键点：内层 `while` 只跳过「已经合法」的位置，所以停下时一定是错位；`i` 和 `j` 的错位类型必然互补（一个奇数放偶数位，一个偶数放奇数位），交换才成立。这依赖题面「一半奇数一半偶数」，否则可能一方先越界而另一方还错着。

## 复杂度
时间 O(n)：`i`、`j` 各自单调前进，每个下标最多被访问一次。
空间 O(1)：只开了 `i`、`j`、`n` 三个变量，原地交换。

## 易错点
- 输入 `[4,2,5,7]` 若写成「遇到错位就往后找任意一个异类交换」而不区分奇偶位，可能把 `nums[1]=2` 换到 `nums[2]` 后又在 `nums[1]` 放回奇数，来回震荡；正确做法是 `i` 只找偶数位上的奇数、`j` 只找奇数位上的偶数，两者类型天然互补。
- 输入 `[2,3]` 这类已经合法的数组，若内层 `while` 漏了 `i < n` 边界判断，`i` 会一路加到 2 后继续访问 `nums[2]` 越界报错；正确做法是两个内层循环都带 `i < n` / `j < n` 条件，外层再判一次才交换。

## 如果面试官追问
问：如果奇数比偶数多一个（长度奇数）怎么办？
答：先按同样逻辑配对交换，多出的那个奇数放最后一位即可，指针越界判断改成 `i < n` 单独处理。
