## 一句话思路
两个子序列的 XOR 之差等价于从 nums 中挑任意子集做 XOR，求线性基能张成的最大值。

## 怎么做
1. 把问题化简：X XOR Y 中，同一元素若同时出现在两个子序列里就抵消，只出现一次就保留，所以答案就是 nums 某个子集的 XOR 最大值。
2. 用线性基（二进制高斯消元）维护一组「最高位互不相同」的基向量，逐个数插入。
3. 插入时从高位到低位扫，若当前位已有基就异或掉，否则占位并退出。
4. 最后把基从高到低贪心异或进答案，能变大就异或。

以 `nums = [1,2,3]` 为例：插入 1 得 `basis[0]=1`；插入 2 得 `basis[1]=2`；插入 3 时第 1 位已有 2，`3^2=1`，第 0 位已有 1，`1^1=0` 丢弃。贪心：`ans=0^2=2`，再 `2^1=3`，输出 3。

```python
basis = [0] * 31
for x in nums:
    for b in range(30, -1, -1):
        if not (x >> b) & 1:
            continue
        if basis[b]:
            x ^= basis[b]
        else:
            basis[b] = x
            break
ans = 0
for b in range(30, -1, -1):
    ans = max(ans, ans ^ basis[b])
return ans
```

## 复杂度
时间 O(n·30)：n 个数各扫 31 位，位宽 log(max(nums)) 是常数。
空间 O(31)：只开一个长度 31 的 basis 数组。

## 易错点
- `nums = [0,0]` 或全零输入 → 若把 `basis` 初始化成 `-1` 再判空，`0` 会被当成「已占位」而漏插，答案错成 0 之外的值 → 用 `0` 作哨兵，因为 0 本身对基无贡献，插入时 `x=0` 自然被丢弃。
- `nums = [5,2]` 这类最高位分散的输入 → 若贪心阶段从低位往高位扫，会先异或小基导致高位被破坏，得到 5 而非 7 → 必须从 `b=30` 递减到 0，保证高位优先。

## 如果面试官追问
问：要求输出具体是哪两个子序列怎么办？
答：在线性基里记录每个基向量由哪些下标异或而来，贪心时同步合并下标集合，再按奇偶分到两个子序列。
