## 一句话思路
按编号顺序贪心：每个花园从 1~4 里挑一个与已染色邻居都不同的花，因为度数 ≤3，四种花必有空位。

## 怎么做
1. 用 `paths` 建邻接表 `adj`，节点编号 1..n，`adj[x].append(y)` 双向加。
2. 开 `ans = [0] * (n + 1)`，`ans[i]` 表示花园 i 的花，0 表示未种。
3. 从 `i = 1` 到 `n` 顺序处理，收集 `adj[i]` 中已确定的 `ans[v]` 进集合 `used`。
4. 从 `c = 1..4` 找第一个不在 `used` 里的 `c` 赋给 `ans[i]`，最后返回 `ans[1:]`。

以示例 1 `n=3, paths=[[1,2],[2,3],[3,1]]` 为例：`i=1` 时 `used=set()`，取 `c=1`；`i=2` 时邻居 1 已种 1，`used={1}`，取 `c=2`；`i=3` 时邻居 1、2 分别是 1、2，`used={1,2}`，取 `c=3`，得 `[1,2,3]`。

```python
adj = [[] for _ in range(n + 1)]
for x, y in paths:
    adj[x].append(y)
    adj[y].append(x)
ans = [0] * (n + 1)
for i in range(1, n + 1):
    used = {ans[v] for v in adj[i] if ans[v]}
    for c in range(1, 5):
        if c not in used:
            ans[i] = c
            break
return ans[1:]
```

关键点：只检查**已染色**的邻居，未染色的邻居（编号更大）留到后面处理，它们反过来会避开 `ans[i]`，所以不会冲突。度数 ≤3 保证 `used` 最多 3 个元素，`range(1,5)` 里必有一个可用。

## 复杂度
时间 O(n + m)，m = len(paths)，每条边建表两次、每个节点扫一遍邻居。
空间 O(n + m)，邻接表存 2m 个整数，`ans` 和 `used` 各 O(n)、O(4)。

## 易错点
- 输入 `paths = []`（n=1 或孤立点）→ 若把 `adj` 建成 `[[]] * (n+1)` 会因列表别名共享导致所有邻居混在一起 → 必须用列表推导 `[[] for _ in range(n+1)]` 逐行新建。
- 输入含自环或重复边（题面保证 `xi != yi`，但重复边可能出现）→ 若用 `used` 计数而非集合，重复邻居会让某花色被误判占用两次 → 用 `set` 收集 `ans[v]`，天然去重。

## 如果面试官追问
问：若花的种类只有 3 种怎么办？
答：度数 ≤3 时不一定有解（如 K4 需 4 色），需先判连通分量是否含奇环以外的 4-团，本题约束下不能直接套贪心。
