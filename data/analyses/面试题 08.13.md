## 一句话思路
按底面积排序后做最长上升子序列式 DP，`dp[i]` 表示以第 i 个箱子为顶时的最大高度。

## 怎么做
1. 先按 `(w, d, h)` 排序，保证任何能叠在 i 下面的箱子都排在 i 前面。
2. 对每个 i，枚举 j < i，若 `box[j]` 三维都严格大于 `box[i]`，则 `dp[i] = max(dp[i], dp[j] + h_i)`。
3. 答案是所有 `dp[i]` 的最大值。

以示例 2 为例，排序后 `[[1,1,1],[2,3,4],[2,6,7],[3,4,5]]`。算到 `[3,4,5]` 时，`[2,3,4]` 三维都小于它，`dp = 4+5 = 9`；`[1,1,1]` 也可叠，但 `dp[0]+5 = 6` 更小，最终 `dp[3]=9`。而 `[2,6,7]` 只能接 `[1,1,1]`，`dp=8`。最大值 9 不是答案——注意 `[2,3,4]` 上还能叠 `[1,1,1]`，`dp[1]=4+1=5`，所以 `[3,4,5]` 实际是 `5+5=10`。

```python
box.sort()
n = len(box)
dp = [b[2] for b in box]
for i in range(n):
    for j in range(i):
        if box[j][0] < box[i][0] and box[j][1] < box[i][1] and box[j][2] < box[i][2]:
            dp[i] = max(dp[i], dp[j] + box[i][2])
return max(dp)
```

## 复杂度
时间 O(n²)，n 为箱子数，双重循环枚举 (j, i) 对。
空间 O(n)，dp 数组长度 n，排序原地。

## 易错点
- 输入含相同尺寸箱子如 `[[2,2,2],[2,2,2]]` → 若用 `<=` 判断会误叠，答案翻倍 → 必须三维都严格小于才转移。
- 只按宽度排序 → 示例 2 中 `[2,6,7]` 和 `[2,3,4]` 宽度相同，若排序后深度乱序，`[2,6,7]` 可能排在 `[2,3,4]` 前导致漏解 → 用 `box.sort()` 全字段排序，保证同宽时深度递增。

## 如果面试官追问
若 n 扩大到 10⁵ 怎么办？答：三维偏序需 CDQ 分治或树套树，把 O(n²) 降到 O(n log² n)，但要注意严格不等号的去重处理。
