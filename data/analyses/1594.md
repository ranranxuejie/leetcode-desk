## 一句话思路
同时维护每个格子的最大积和最小积，因为负数乘最小积可能翻成最大积。

## 怎么做
1. 建两个 m×n 表 `hi`、`lo`，`hi[i][j]`/`lo[i][j]` 表示到 (i,j) 的最大/最小积。
2. 初始化 `hi[0][0] = lo[0][0] = grid[0][0]`，第一行第一列只能单向累乘。
3. 其余格子从上方和左方各取 `hi`、`lo` 共 4 个候选值，乘上 `grid[i][j]` 后取最大进 `hi`、最小进 `lo`。
4. 若 `hi[m-1][n-1] < 0` 返回 -1，否则返回它对 `10**9+7` 取余。

以示例 2 的 `grid = [[1,-2,1],[1,-2,1],[3,-4,1]]` 为例，关键在 (2,1) 即 `-4` 处：上方 (1,1) 的 `hi=-2, lo=-2`，左方 (2,0) 的 `hi=3, lo=3`，四个候选乘 `-4` 得 `8, 8, -12, -12`，于是 `hi[2][1]=8`、`lo[2][1]=-12`。这个 8 一路传到终点，正是答案。

```python
m, n = len(grid), len(grid[0])
hi = [[0]*n for _ in range(m)]
lo = [[0]*n for _ in range(m)]
hi[0][0] = lo[0][0] = grid[0][0]
for i in range(m):
    for j in range(n):
        if i == 0 and j == 0:
            continue
        cand = []
        if i > 0:
            cand += [hi[i-1][j]*grid[i][j], lo[i-1][j]*grid[i][j]]
        if j > 0:
            cand += [hi[i][j-1]*grid[i][j], lo[i][j-1]*grid[i][j]]
        hi[i][j], lo[i][j] = max(cand), min(cand)
ans = hi[m-1][n-1]
return -1 if ans < 0 else ans % (10**9 + 7)
```

## 复杂度
时间 O(m·n)，每个格子常数次比较。
空间 O(m·n)，开了 `hi`、`lo` 两张表。

## 易错点
- 输入含 0（如示例 3 的 `grid[1][0]=0`）→ 只维护最大积会漏掉「0 之后接负数」的路径，把 `hi[1][0]` 算成 0 却丢掉 `lo` 信息 → 必须同时维护 `lo`，让 0 作为合法候选参与 `max/min`。
- 终点 `hi[m-1][n-1]` 为负时直接取余 → 得到正数而非 -1 → 先判 `ans < 0` 返回 -1，再取余；注意取余只在最后一步做，中间值不取模。

## 如果面试官追问
问：若要求输出具体路径而非积？
答：在 `hi`/`lo` 表里额外存「该值来自上方还是左方」，从终点回溯即可。
