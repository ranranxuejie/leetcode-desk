## 一句话思路
枚举所有矩形对，交集宽高取 min 后求最大边长平方，因为最优正方形必由某两个矩形的交集决定。

## 怎么做
1. 双重循环枚举 `i < j` 的每一对矩形，共 O(n²) 对。
2. 交集左下角取 `max(bottomLeft[i], bottomLeft[j])`，右上角取 `min(topRight[i], topRight[j])`，逐坐标算。
3. 宽 `w = min(topRight[i][0], topRight[j][0]) - max(bottomLeft[i][0], bottomLeft[j][0])`，高同理；若 `w <= 0 or h <= 0` 无交集跳过。
4. 边长取 `min(w, h)`，用 `ans = max(ans, side * side)` 更新。

以示例 1 的矩形 0 `[1,1]-[3,3]` 与矩形 1 `[2,2]-[4,4]` 为例：交集左下 `(2,2)`、右上 `(3,3)`，`w = 3-2 = 1`、`h = 1`，边长 1，面积 1；矩形 1 与矩形 2 交集 `[3,3]-[4,4]` 同样得 1，最终 `ans = 1`。

```python
ans = 0
for i in range(n):
    for j in range(i + 1, n):
        w = min(topRight[i][0], topRight[j][0]) - max(bottomLeft[i][0], bottomLeft[j][0])
        h = min(topRight[i][1], topRight[j][1]) - max(bottomLeft[i][1], bottomLeft[j][1])
        if w > 0 and h > 0:
            side = min(w, h)
            ans = max(ans, side * side)
return ans
```

注意 `w`、`h` 必须严格大于 0 才算有交集，等于 0 表示只贴边不相交。

## 复杂度
时间 O(n²)：双重循环枚举矩形对，每对 O(1)。
空间 O(1)：只开 `ans`、`w`、`h`、`side` 几个标量。

## 易错点
- 输入 `bottomLeft=[[1,1],[3,3],[3,1]]`、`topRight=[[2,2],[4,4],[4,2]]`（示例 3）→ 若用 `w >= 0` 判断，矩形 0 与矩形 2 在 x 上贴边 `w=0` 会被误判为有交集 → 必须用 `w > 0 and h > 0`。
- 坐标上限 10⁷，边长最大约 10⁷，面积约 10¹⁴ → 若用 32 位整型存 `side * side` 会溢出 → Python 整数天然安全，但若移植到 C++/Java 需用 `long`，题目答案按 32 位截断的说法不适用于本题（答案本身可达 10¹⁴）。

## 如果面试官追问
问：n 增大到 10⁵ 怎么办？答：不能枚举所有对，需按 x 排序后扫描候选交集，或利用答案单调性二分边长再判可行性。
