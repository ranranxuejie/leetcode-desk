## 一句话思路
用集合记录当前亮着的灯号，遍历 bulbs 时灯号在集合里就删、不在就加，最后排序输出。

## 怎么做
1. 建一个空集合 `on`，表示当前处于打开状态的灯泡编号。
2. 遍历 `bulbs` 的每个 `b`：若 `b in on` 则 `on.remove(b)`，否则 `on.add(b)`。
3. 遍历结束后 `sorted(on)` 即为升序结果，集合为空时自然返回 `[]`。

以 `bulbs = [10,30,20,10]` 为例，走完前三个元素后 `on = {10,30,20}`；处理最后一个 `10` 时 `10 in on` 为真，执行 `on.remove(10)`，集合变成 `{30,20}`，`sorted` 后得到 `[20,30]`。

```python
on = set()
for b in bulbs:
    if b in on:
        on.remove(b)
    else:
        on.add(b)
return sorted(on)
```

关键点：同一个灯号出现偶数次就回到关闭，奇数次才留在集合里，所以用集合的增删天然处理了「切换」语义，不需要开 101 长度的布尔数组再扫一遍。

## 复杂度
时间：遍历 bulbs 是 O(n)，每个元素集合增删均摊 O(1)，最后排序 O(k log k)，k 为亮灯数。
空间：集合 `on` 最多存 100 个灯号，O(k)，与 bulbs 长度无关。

## 易错点
- 输入 `bulbs = [100,100]` → 若用布尔数组但忘记初始化为 `False`，或误写成「出现即打开」，会输出 `[100]` → 正确做法是每次取反，两次出现后 `on` 为空，返回 `[]`。
- 输入 `bulbs = [10,30,20,10]` → 若直接 `return list(on)`，集合无序会输出 `[10,20,30]` 或乱序 → 必须 `sorted(on)`，题目要求升序。

## 如果面试官追问
问：如果 bulbs 长度到 10^5 且灯号范围到 10^9 呢？
答：集合方案不变，仍是 O(n) 时间、O(k) 空间，只是不能再用 101 长度的数组。
