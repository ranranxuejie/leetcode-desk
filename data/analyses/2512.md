## 一句话思路
把正负词表转成哈希集合，逐条评语按空格切词查表累加得分，再按 `(-score, id)` 排序取前 k。

## 怎么做
1. 用 `pos = set(positive_feedback)`、`neg = set(negative_feedback)` 建两个集合，查词 O(1)。
2. 遍历 `report` 与 `student_id`，对每条评语 `report[i].split()` 切词，命中 `pos` 加 3、命中 `neg` 减 1，累加进 `score[student_id[i]]`。
3. 以 `sorted(score.items(), key=lambda x: (-x[1], x[0]))` 排序，分数降序、同分 ID 升序。
4. 取前 `k` 个的 ID 返回。

以示例 2 为例：`report[0] = "this student is not studious"` 切出 `["this","student","is","not","studious"]`，`not` 命中负表 −1、`studious` 命中正表 +3，学生 1 得 2 分；`report[1]` 只有 `smart` 命中，学生 2 得 3 分。排序键为 `(-3,2)` 与 `(-2,1)`，学生 2 在前，输出 `[2,1]`。

```python
pos, neg = set(positive_feedback), set(negative_feedback)
score = {}
for r, sid in zip(report, student_id):
    s = 0
    for w in r.split():
        if w in pos:
            s += 3
        elif w in neg:
            s -= 1
    score[sid] = s
rank = sorted(score.items(), key=lambda x: (-x[1], x[0]))
return [sid for sid, _ in rank[:k]]
```

## 复杂度
时间：O(P + N + W + n log n)，P 为词表总长、W 为所有评语总词数、n 为学生数，排序贡献 log n。
空间：O(P + n)，两个集合存词表、`score` 字典存 n 个学生的分数。

## 易错点
- 用 `w in r` 做子串匹配 → `"not"` 会命中 `"nothing"` 里的 `not`，示例 2 学生 1 被多扣 1 分变成 1 分 → 必须 `r.split()` 后按整词查集合。
- 排序只写 `key=lambda x: -x[1]` → 示例 1 两学生同为 3 分时顺序取决于字典插入序，可能输出 `[2,1]` → 必须补第二关键字 `x[0]` 保证 ID 升序。

## 如果面试官追问
若 `report[i]` 长度涨到 10^5、n 也到 10^5，还全排序吗？答：改用大小为 k 的小顶堆，键取 `(score, -id)`，只保留前 k，复杂度降到 O(n log k)。
