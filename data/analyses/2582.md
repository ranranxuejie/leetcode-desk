## 一句话思路
把往返折线拉直成周期 `2*(n-1)`，用 `time % 周期` 定位方向，再按位置算编号。

## 怎么做
1. 记 `period = 2 * (n - 1)`，这是枕头从 1 号出发再回到 1 号所需的秒数。
2. 取 `t = time % period`，把 time 压缩到一个周期内，方向只由 t 决定。
3. 若 `t <= n - 1`，枕头在去程，编号为 `1 + t`；否则在回程，编号为 `2 * n - 1 - t`。
4. 直接返回该编号。

以 `n = 4, time = 5` 为例：`period = 6`，`t = 5 % 6 = 5`。因为 `5 > 3`，走回程分支，编号 `2*4 - 1 - 5 = 2`，与示例一致。

```python
def passThePillow(n, time):
    period = 2 * (n - 1)
    t = time % period
    if t <= n - 1:
        return 1 + t
    return 2 * n - 1 - t
```

关键点：`t == n - 1` 时落在第 n 人，归入去程分支；`t == 0` 时回到 1 号，也归入去程分支，两者都正确。

## 复杂度
时间：O(1)，只做取模和一次比较，与 n、time 无关。
空间：O(1)，没有开数组，只用了 period、t 两个整数。

## 易错点
- `time` 恰好是 `period` 的整数倍（如 `n = 4, time = 6`）→ 若用 `t = time % period` 后误判 `t == 0` 为回程 → 正确做法是让 `t <= n - 1` 覆盖 0，返回 `1 + 0 = 1`。
- 边界 `t == n - 1`（如 `n = 4, time = 3`）→ 若写成 `t < n - 1` 走回程，会算出 `2*4-1-3 = 4` 碰巧对，但 `n = 3, time = 2` 时回程公式给 `2*3-1-2 = 3` 也对，真正翻车在 `t = 0` 被误判回程得 `2n-1` → 正确做法是用 `<=` 把端点归去程。

## 如果面试官追问
若 n 和 time 放大到 10^18，取模还成立吗？答：成立，`period` 和 `t` 都是 Python 大整数，O(1) 不变，无需模拟。
