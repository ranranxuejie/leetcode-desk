## 一句话思路
用前缀和记盘子数、用两个数组记每个位置左右最近的蜡烛，查询时把区间收缩到蜡烛之间再作差。

## 怎么做
1. 预处理 `pre[i]` = `s[:i]` 中 `'*'` 的个数，`pre[i+1] = pre[i] + (s[i] == '*')`。
2. 预处理 `left_c[i]` = 下标 ≤ i 的最近蜡烛位置（没有则 -1），`right_c[i]` = 下标 ≥ i 的最近蜡烛位置（没有则 n）。
3. 对每个 `[l, r]`：取 `a = right_c[l]`、`b = left_c[r]`，若 `a >= b` 说明区间内蜡烛不足两支，答案为 0。
4. 否则答案是 `pre[b] - pre[a+1]`，即 `(a, b)` 开区间内的盘子数。

以 `s = "**|**|***|"`、`queries[0] = [2,5]` 为例：`right_c[2] = 2`，`left_c[5] = 5`，`pre[5] - pre[3] = 3 - 1 = 2`，与输出 2 一致。

```python
n = len(s)
pre = [0] * (n + 1)
for i, ch in enumerate(s):
    pre[i + 1] = pre[i] + (ch == '*')
left_c = [-1] * n
last = -1
for i in range(n):
    if s[i] == '|':
        last = i
    left_c[i] = last
right_c = [n] * n
nxt = n
for i in range(n - 1, -1, -1):
    if s[i] == '|':
        nxt = i
    right_c[i] = nxt
ans = []
for l, r in queries:
    a, b = right_c[l], left_c[r]
    ans.append(pre[b] - pre[a + 1] if a < b else 0)
```

## 复杂度
时间：预处理 O(n)，每个查询 O(1)，共 O(n + q)，n 为 `len(s)`、q 为 `len(queries)`。
空间：`pre`、`left_c`、`right_c` 各 O(n) 额外数组。

## 易错点
- 查询区间两端就是蜡烛，如 `s = "|*|"`、`[0,2]`：若用 `pre[b+1] - pre[a]` 会把端点蜡烛当盘子算错，正确是 `pre[b] - pre[a+1]`，只数开区间。
- 区间内蜡烛不足两支，如示例 2 的 `[4,5]`（子串 `"*|"`）：若直接套前缀和会得到 1，正确做法是先判 `a < b`，否则返回 0。

## 如果面试官追问
若要求在线回答、`s` 还会被单点修改怎么办？答：改用有序集合存蜡烛下标，查询时二分找 `l` 的后继和 `r` 的前驱，配合树状数组数盘子。
