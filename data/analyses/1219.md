## 一句话思路
对每个非零格做 DFS 回溯，枚举所有不重复经过格子的路径，取路径和最大值。

## 怎么做
1. 遍历 `grid` 每个 `grid[i][j] > 0` 的格子，作为起点调用 `dfs(i, j)`。
2. `dfs` 先把当前格置 0（标记已采），再向四邻中 `> 0` 的格子递归，返回 `grid[i][j] + max(子结果)`。
3. 回溯时把 `grid[i][j]` 恢复原值，保证别的起点还能走这条格。
4. 全局答案取所有起点 `dfs` 的最大值。

以示例 1 为例，从 `grid[2][1]=9` 出发：置 0 后邻居只有 `grid[1][1]=8`，进入后置 0，邻居 `grid[1][2]=7`，再进入得 7；回溯链返回 `7 → 8+7=15 → 9+15=24`。而 `grid[1][1]=8` 的邻居是 6、5、7、9 四个，`dfs` 会取其中最大分支，不会把 6 和 5 同时算进去——这正是「一条路径」而非「连通块求和」的关键。

```python
def dfs(i, j):
    cur = grid[i][j]
    grid[i][j] = 0
    best = 0
    for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
        ni, nj = i+di, j+dj
        if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] > 0:
            best = max(best, dfs(ni, nj))
    grid[i][j] = cur
    return cur + best
```

外层 `ans = max(ans, dfs(i, j))` 对每个 `grid[i][j] > 0` 执行。

## 复杂度
时间：O(m·n·4^K)，K 为黄金格数（≤25），每个起点最多展开 4 叉路径。
空间：O(K) 递归栈，无额外数组，靠原地置 0 标记。

## 易错点
- 输入 `[[0,6,0],[5,8,7],[0,9,0]]` → 若把 8 的四个邻居 6、5、7、9 全加起来当收益，会错成 35 → 正确做法是 `dfs` 只返回 `cur + max(单个子分支)`，路径不能分叉。
- 输入含 `grid[i][j] = 0` 的格子 → 若从 0 格起手或递归进 0 格，会把 0 计入路径并多走一步 → 正确做法是外层只对 `> 0` 起手，递归条件写 `grid[ni][nj] > 0`，且回溯必须恢复原值否则后续起点少算。

## 如果面试官追问
若要求输出具体路径而不只是最大值？答：`dfs` 额外返回路径列表，`max` 时同步保留对应子路径，回溯前 `path.append((i,j))`、返回前 `pop`。
