## 一句话思路
从 `(sr, sc)` 出发做 DFS/BFS，只向颜色等于起始色 `old = image[sr][sc]` 的相邻格扩散并染成 `newColor`。

## 怎么做
1. 先取 `old = image[sr][sc]`，若 `old == newColor` 直接返回 `image`，否则会死循环。
2. 把起点压栈，循环弹出 `(r, c)`，越界或 `image[r][c] != old` 就跳过。
3. 命中则写 `image[r][c] = newColor`，再把上下左右四个邻居入栈。
4. 栈空返回 `image`，原地修改即可。

以官方示例为例：`old = image[1][1] = 1`，`newColor = 2`。从 `(1,1)` 扩散到 `(0,1)`、`(1,0)`、`(2,0)`，再到 `(0,0)`、`(0,2)`，这 6 格全变 2；`(1,2)` 和 `(2,2)` 值为 0，`(2,1)` 虽为 0 也不连通，均不动。

```python
old = image[sr][sc]
if old == newColor:
    return image
stack = [(sr, sc)]
while stack:
    r, c = stack.pop()
    if not (0 <= r < len(image) and 0 <= c < len(image[0])):
        continue
    if image[r][c] != old:
        continue
    image[r][c] = newColor
    stack += [(r+1, c), (r-1, c), (r, c+1), (r, c-1)]
return image
```

## 复杂度
时间 O(m·n)：每个格子最多入栈一次，m、n 为行列数。
空间 O(m·n)：栈最坏存下全部格子，原地修改无额外矩阵。

## 易错点
- `image = [[0,0,0],[0,0,0]]`、`sr=0, sc=0, newColor=0` → 不判 `old == newColor` 就无限入栈、超时或爆内存 → 开头先比较，相等直接返回。
- `image = [[1,1,1],[1,1,0],[1,0,1]]`、`sr=1, sc=1` → 若把「颜色相同」理解成「值等于 newColor」或漏判 `image[r][c] != old`，会把右下角 `(2,2)=1` 也染成 2 → 判据必须是 `image[r][c] == old`，且只走四连通。

## 如果面试官追问
问：图像 50×50 但要求不修改原数组怎么办？
答：先 `copy.deepcopy(image)` 或逐行 `[row[:] for row in image]`，在副本上填，返回副本。
