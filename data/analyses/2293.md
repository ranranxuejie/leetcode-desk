## 一句话思路
逐层原地折叠：每轮把 `nums` 前 `n//2` 个位置按奇偶下标填 min/max，长度减半直到 1。

## 怎么做
1. 用 `n = len(nums)` 控制当前有效长度，循环条件 `while n > 1`。
2. 对 `i in range(n // 2)`：偶数 `i` 写 `min(nums[2*i], nums[2*i+1])`，奇数 `i` 写 `max(...)`，直接覆盖到 `nums[i]`。
3. 每轮结束 `n //= 2`，最后返回 `nums[0]`。

关键中间值（示例 1，`nums = [1,3,5,2,4,8,2,2]`，`n=8`）：`i=0` 得 `min(1,3)=1` 写入 `nums[0]`；`i=1` 得 `max(5,2)=5` 写入 `nums[1]`；`i=2` 得 `min(4,8)=4`；`i=3` 得 `max(2,2)=2`，此时 `nums[:4] == [1,5,4,2]`，`n` 变 4。第二轮 `i=0` 取 `min(1,5)=1`、`i=1` 取 `max(4,2)=4`，得 `[1,4]`；第三轮 `min(1,4)=1`。

```python
n = len(nums)
while n > 1:
    half = n // 2
    for i in range(half):
        a, b = nums[2 * i], nums[2 * i + 1]
        nums[i] = min(a, b) if i % 2 == 0 else max(a, b)
    n = half
return nums[0]
```

注意 `i % 2` 判的是**新数组下标**，不是 `2*i` 的奇偶；`2*i` 永远是偶数，用它判会全取 min。

## 复杂度
时间 O(n)：每轮处理 n/2 对，总工作量 n/2 + n/4 + … < n。
空间 O(1)：原地覆盖 `nums` 前段，没开 newNums。

## 易错点
- 用 `nums[2*i] % 2` 或 `2*i` 的奇偶决定 min/max → 示例 1 第一轮会得到 `[1,2,4,2]` 而非 `[1,5,4,2]`，最终答案错 → 必须按新下标 `i` 的奇偶判断。
- 每轮新建 `newNums` 再 `nums = newNums` → 逻辑对但多开 O(n) 空间，且长度 1024 时反复分配；正确做法是写回 `nums[i]`（`i < n//2`，不会读到本轮已覆盖的 `2*i`，因为 `2*i >= i` 且 `2*i` 位置本轮尚未被写）。

## 如果面试官追问
问：长度不是 2 的幂怎么办？
答：题面保证是 2 的幂；若不是，最后一轮会剩单元素，需在 `n` 为奇数时把末尾元素直接带入下一层，否则 `2*i+1` 越界。
