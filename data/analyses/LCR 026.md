## 一句话思路
快慢指针找中点、反转后半段、再交替合并，因为重排本质是前半段正序与后半段逆序的拉链式穿插。

## 怎么做
1. 快慢指针找中点：`slow` 每步 1、`fast` 每步 2，结束时 `slow` 指向后半段起点。
2. 反转从 `slow` 开始的后半段，得到逆序头 `rev`。
3. 把 `head` 与 `rev` 交替拼接，前半段走完即停。

以 `[1,2,3,4]` 为例：快慢指针结束后 `slow` 指向 `3`，反转得 `rev = 4 -> 3`；合并时先接 `1 -> 4`，再 `4 -> 2`，最后 `2 -> 3`，输出 `1,4,2,3`。

```python
slow = fast = head
while fast.next and fast.next.next:
    slow, fast = slow.next, fast.next.next
rev, cur = None, slow.next
slow.next = None                      # 切断，否则合并时成环
while cur:
    cur.next, rev, cur = rev, cur, cur.next
p, q = head, rev
while q:                              # 后半段不长于前半段，用 q 判空
    p.next, q.next, p, q = q, p.next, q, p.next
```

关键在最后一行：`p.next, q.next = q, p.next` 必须同时赋值，先存下 `p.next` 再改 `p.next`，否则丢链。

## 复杂度
时间 O(n)：找中点、反转、合并各扫一遍，常数 3 次。
空间 O(1)：只用了 `slow/fast/rev/cur/p/q` 几个指针，没开数组或栈。

## 易错点
- 输入 `[1,2,3,4]` 时若忘了 `slow.next = None`，反转后 `2` 仍指向 `3`，合并到 `2 -> 3` 时 `3` 又指回 `4`，形成环导致死循环或超时；正确做法是反转前先切断。
- 输入 `[1,2,3]` 时若合并循环写成 `while p and q`，`p` 先走完会提前退出，末尾 `3` 丢失；正确做法是用 `while q`，因为后半段长度恒 ≤ 前半段，`p` 不会先耗尽。

## 如果面试官追问
追问：不允许改指针、只能改 `val` 怎么做？
答：把节点值读进数组，双指针从两端取，再顺序写回，时间 O(n)、空间 O(n)，但违反题面「实际交换」的要求。
