## 一句话思路
把 `brokenLetters` 转成集合，逐词判断是否有字符落在集合里，没有就计数。

## 怎么做
1. 用 `set(brokenLetters)` 建坏键集合，`brokenLetters` 长度最多 26，查一次是 O(1)。
2. 用 `text.split()` 切词，题目保证单个空格、无前后空格，所以不会出现空串。
3. 对每个词 `w`，用 `any(c in broken for c in w)` 判断是否含坏键；不含则 `ans += 1`。

以示例 1 `text = "hello world"`, `brokenLetters = "ad"` 为例：`broken = {'a','d'}`。切出 `["hello","world"]`。`"hello"` 里 h/e/l/o 都不在集合中，`any(...)` 为 `False`，计数 +1；`"world"` 扫到 `'d'` 时 `any` 立刻返回 `True`，跳过。最终 `ans = 1`。

```python
broken = set(brokenLetters)
ans = 0
for w in text.split():
    ok = True
    for c in w:
        if c in broken:
            ok = False
            break
    if ok:
        ans += 1
```

也可以写成一行生成器：`ans = sum(1 for w in text.split() if not any(c in broken for c in w))`。注意 `any` 短路，遇到第一个坏键就停，不会白扫完整个词。

## 复杂度
时间 O(n)：n 是 `text` 总长度，每个字符最多被查一次集合。
空间 O(1)：额外只开了大小 ≤26 的 `broken` 集合和切词结果。

## 易错点
- `brokenLetters = ""`（长度可为 0）→ 若写成 `if brokenLetters and ...` 或误判空串为「所有键都坏」→ 会错成 0；正确做法是 `set("")` 得到空集，`any` 恒为 `False`，所有词都可输入，答案等于词数。
- 用 `text.split(" ")` 而不是 `split()` → 本题虽保证单空格，但一旦输入有连续空格会切出空串，空串不含坏键被误计 +1；正确做法用无参 `split()`，它按任意空白切分且丢弃空串。

## 如果面试官追问
问：若 `brokenLetters` 很长、`text` 也很大，怎么再快一点？
答：把坏键集合换成 26 位 bitmask，判断单词时对字符做位与，省掉哈希开销。
