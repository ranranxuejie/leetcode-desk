## 一句话思路
把「以 i 结尾、高度非降的最长路线」转成前缀最大值查询，用树状数组按高度存 dp 值，查询 ≤obstacles[i] 的最大 dp。

## 怎么做
1. 对 obstacles 去重排序得到高度坐标，树状数组下标从 1 开始，`tree[k]` 维护高度排名 ≤k 的最大 dp 值。
2. 从左到右扫，对每个 `h = obstacles[i]`，先求它在坐标里的排名 `r`（`bisect_right` 得到的是「≤h 的个数」，正好当树状数组下标）。
3. `dp = query(r) + 1`，把 `dp` 写回 `update(r, dp)`，答案数组追加 `dp`。
4. 关键中间值：示例 1 `[1,2,3,2]`，处理到 i=3、h=2 时，排名 r=2（高度 1、2 都 ≤2），query(2) 返回 2（来自 i=1 的 dp=2），故 dp=3，与输出 `[1,2,3,3]` 一致。

```python
from bisect import bisect_right
vals = sorted(set(obstacles))
m = len(vals)
tree = [0] * (m + 1)
ans = []
for h in obstacles:
    r = bisect_right(vals, h)          # ≤h 的个数，即树状数组下标
    best = 0
    j = r
    while j > 0:
        best = max(best, tree[j]); j -= j & -j
    dp = best + 1
    j = r
    while j <= m:
        tree[j] = max(tree[j], dp); j += j & -j
    ans.append(dp)
```

## 复杂度
时间：O(n log n)，n 次查询 + n 次更新，每次 O(log m)，m ≤ n。
空间：O(n)，vals 去重数组 + tree 长度 m+1 + 答案数组。

## 易错点
- 用 `bisect_left` 取排名 → 对 `[2,2,1]` 的 i=1、h=2 会得到 r=1，query(1) 只覆盖高度 1，返回 0，dp 错成 1，正确输出应是 2。必须用 `bisect_right`，因为「相同高度可接」要求查询包含 h 本身。
- 树状数组下标从 0 开始写 → `j -= j & -j` 在 j=0 时死循环或漏更新。排名 r 天然 ≥1（bisect_right 至少返回 1），update 从 r 起跳，别写成 `r-1`。

## 如果面试官追问
要求输出具体路线而非长度？答：树状数组改存 `(dp, 前驱下标)`，查询时取最大 dp 并记录来源，最后从每个 i 沿前驱回溯即可。
