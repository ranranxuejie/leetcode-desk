## 一句话思路
从 `(tx, ty)` 反向做减法回退到 `(sx, sy)`，因为正向每步只有一个坐标变大，反向唯一确定。

## 怎么做
1. 若 `tx < sx or ty < sy`，直接返回 `False`，反向只会越减越小。
2. 循环中每次用大坐标减小坐标：`tx > ty` 时减 `ty`，否则减 `tx`。
3. 用整除一次跳多步：`tx > ty` 时 `tx %= ty`，但若 `ty == sy` 且 `tx` 能落到 `sx` 需特判。
4. 终止条件：`tx == sx and ty == sy` 返回 `True`；`tx == sx` 时检查 `ty` 能否由 `sy` 加若干次 `sx` 得到。

以示例 1 `(1,1)->(3,5)` 为例：`tx=3,ty=5`，`ty>tx`，`ty %= tx` 得 `ty=2`；此时 `tx=3,ty=2`，`tx %= ty` 得 `tx=1`；`tx=1,ty=2`，`ty %= tx` 得 `ty=0`，需回退一步得 `ty=2`，再判 `tx==sx` 且 `ty` 可由 `sy` 加 `sx` 倍数得到，返回 `True`。

```python
def reachingPoints(sx, sy, tx, ty):
    while tx >= sx and ty >= sy:
        if tx == sx and ty == sy:
            return True
        if tx > ty:
            if ty == sy:
                return tx >= sx and (tx - sx) % ty == 0
            tx %= ty
        else:
            if tx == sx:
                return ty >= sy and (ty - sy) % tx == 0
            ty %= tx
    return False
```

## 复杂度
时间：O(log(max(tx, ty)))，每次取模至少减半。
空间：O(1)，只用了几个整型变量。

## 易错点
- 输入 `sx=1, sy=1, tx=1, ty=10**9` → 若逐次减 1 会超时 → 必须用 `ty %= tx` 一次跳完，且 `tx==sx` 时用 `(ty-sy)%tx==0` 判断。
- 输入 `sx=1, sy=1, tx=2, ty=2` → 若循环条件写成 `tx>sx and ty>sy` 会漏判相等 → 循环条件应为 `tx>=sx and ty>=sy`，并在内部先判 `tx==sx and ty==sy`。

## 如果面试官追问
问：若要求输出具体转换序列怎么办？
答：反向记录每次减去的坐标和步数，再逆序展开成 `(x, x+y)` 或 `(x+y, y)` 即可。
