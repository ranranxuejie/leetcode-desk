## 一句话思路
按年龄升序、同龄按分数升序排序后，问题变成在分数序列上求最大和递增子序列（LIS 变体），因为排序保证年龄不降、分数不降才无矛盾。

## 怎么做
1. 把 `(age, score)` 配对后按 `(age, score)` 升序排序，得到新数组 `players`。
2. 定义 `dp[i]` 为以第 `i` 名球员结尾的无矛盾球队最高总分，初值 `dp[i] = players[i][1]`。
3. 对每个 `i`，遍历 `j < i`，若 `players[j][1] <= players[i][1]` 则 `dp[i] = max(dp[i], dp[j] + players[i][1])`。
4. 返回 `max(dp)`。

以示例 2 为例：`scores=[4,5,6,5], ages=[2,1,2,1]`，配对排序后 `players=[(1,5),(1,5),(2,4),(2,6)]`。计算到 `i=3`（分数 6）时，`dp[3]` 从 `dp[0]+6=11`、`dp[1]+6=11`、`dp[2]+6=10` 中取最大 11，最终 `max(dp)=11`？注意这里排序后分数序列是 `[5,5,4,6]`，`dp` 依次为 `[5,10,4,16]`，答案 16，对应后三名球员。

```python
players = sorted(zip(ages, scores))
n = len(players)
dp = [p[1] for p in players]
for i in range(n):
    for j in range(i):
        if players[j][1] <= players[i][1]:
            dp[i] = max(dp[i], dp[j] + players[i][1])
return max(dp)
```

关键：同龄球员按分数升序排，保证同龄之间 `players[j][1] <= players[i][1]` 恒成立，可以全部累加，不会误判矛盾。

## 复杂度
时间：O(n²)，双重循环枚举 `(j, i)` 对，n 为球员数。
空间：O(n)，`dp` 数组和排序后的 `players` 各占 n。

## 易错点
- 同龄球员排序方向搞反：若按 `(age, -score)` 排，示例 2 中同龄的 5 和 4 会变成 `[5,4]`，`dp` 无法把两个同龄球员都选上，答案错成 11 而非 16。正确做法是同龄按分数升序。
- 判断条件写成严格小于 `players[j][1] < players[i][1]`：示例 2 中两个年龄 1、分数都是 5 的球员无法同时入选，`dp[1]` 只等于 5 而非 10，最终答案偏小。正确做法是用 `<=`，同龄同分可累加。

## 如果面试官追问
若 n 扩大到 10⁵ 怎么优化？答：把分数离散化后用树状数组维护前缀最大值，按年龄分组批量更新，O(n log n)。
