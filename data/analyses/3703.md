## 一句话思路
用栈存字符，每步检查栈顶是否凑成 `'('*k + ')'*k`，是就弹出，等价于反复删除直到不动。

## 怎么做
1. 从左到右扫 `s`，把每个字符 `push` 进栈 `st`。
2. 每次 `push` 后检查栈顶 `2k` 个字符是否恰好是 `k` 个 `'('` 接 `k` 个 `')'`。
3. 若是，`pop` 掉这 `2k` 个字符；否则继续扫下一个字符。
4. 扫完 `''.join(st)` 即答案。

以 `s = "(())", k = 1` 为例：扫到第 2 个字符 `')'` 时，栈为 `['(', ')']`，栈顶 2 个是 `"()"`，弹出后栈变空；扫到第 4 个 `')'` 时栈又是 `['(', ')']`，再弹出，最终 `""`。关键中间值：第一次弹出后 `st == []`，而不是 `['(']`。

```python
st = []
need = '(' * k + ')' * k
for ch in s:
    st.append(ch)
    if len(st) >= 2 * k and ''.join(st[-2*k:]) == need:
        del st[-2*k:]
return ''.join(st)
```

为什么一次扫描就够：删除后新拼接处可能又形成 k-平衡串，但栈顶检查在每次 `push` 后都做，等价于「删完立刻回看」，所以不会漏。示例 1 的第二次删除正是靠这个回看触发的。

## 复杂度
时间 O(n·k)：每个字符入栈一次，每次比较栈顶 `2k` 个字符，最坏 O(nk)。
空间 O(n)：栈 `st` 最多存 n 个字符，`need` 占 2k。

## 易错点
- `s = "((()))", k = 3` 若只比较栈顶 `k` 个字符，会把 `")))"` 误判，正确是比较完整 `2k` 个且前半全 `'('`、后半全 `')'`。
- `s = "()()", k = 1` 若用「先找所有不重叠子串再统一删」的一次性做法，删完 `"()()"` 变 `""` 没问题，但 `s = "(())"` 一次扫描只删中间 `"()"` 得 `"()"`，必须回看再删，所以要在每次 `push` 后检查而非扫完统一处理。

## 如果面试官追问
问：k 很大时比较 `2k` 个字符太慢怎么办？
答：维护栈顶连续 `'('` 计数和连续 `')'` 计数，O(1) 判断，总时间降到 O(n)。
