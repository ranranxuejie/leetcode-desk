## 一句话思路
枚举百位、十位、个位三个下标，用集合去重后排序，因为 digits 长度最多 100 但数字只有 0-9，枚举 10³ 种组合即可。

## 怎么做
1. 用 `Counter(digits)` 统计每个数字出现次数，避免重复枚举相同数字组合。
2. 三重循环枚举百位 `a`、十位 `b`、个位 `c`，各取 0-9，检查 `a != 0`、`c % 2 == 0`、且三者计数不超过 `Counter` 中的值。
3. 把 `a*100 + b*10 + c` 加入集合 `res`，最后 `sorted(res)` 返回。

以 `digits = [2,1,3,0]` 为例：`Counter` 为 `{2:1, 1:1, 3:1, 0:1}`。枚举到 `a=1, b=0, c=2` 时，计数 1、0、2 各用一次均不超限，且 `c=2` 为偶数，得到 `102` 入集合；枚举到 `a=0` 全部跳过，因为百位不能为 0。

```python
from collections import Counter

cnt = Counter(digits)
res = set()
for a in range(1, 10):
    for b in range(10):
        for c in range(0, 10, 2):
            need = Counter({a: 1, b: 1, c: 1})
            if all(cnt[d] >= need[d] for d in need):
                res.add(a * 100 + b * 10 + c)
return sorted(res)
```

关键点：`c` 直接从 `range(0, 10, 2)` 取偶数，省掉一次判断；`need` 用 `Counter` 合并重复数字（如 `a==b`）的计数需求。

## 复杂度
时间：O(10³ × 10) 枚举组合，与 n 无关，n 只影响建 `Counter` 的 O(n)。
空间：O(10³) 存结果集合，`Counter` 额外 O(10)。

## 易错点
- 输入 `digits = [0, 0, 2]` → 若百位从 0 开始枚举会得到 `002`、`020` 等非法值 → 百位必须从 1 开始，且 `020` 这种前导零也要排除。
- 输入 `digits = [2, 2, 8, 8, 2]` → 若只用 `set(digits)` 去重枚举会漏掉 `222`、`288` 这类需要重复数字的组合 → 必须用 `Counter` 按出现次数判断，不能简单去重。

## 如果面试官追问
问：如果 digits 长度扩到 10⁵ 怎么办？
答：数字种类仍只有 10 种，先 `Counter` 压缩，枚举 10³ 组合不变，复杂度仍是 O(n + 10³)。
