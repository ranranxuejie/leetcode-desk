## 一句话思路
多源 BFS 按时间层扩散，同一格被多色同时到达时取最大色，用「先到先占、同层比色」的队列实现。

## 怎么做
1. 建 `grid = [[0]*m for _ in range(n)]`，把所有源入队 `q`，并写入 `grid`。
2. 按层 BFS：每轮先取 `len(q)` 作为本层大小，逐个弹出处理，保证同层同时扩散。
3. 对每个弹出的 `(r, c)`，向四邻扩展；邻居若 `grid[nr][nc] == 0` 则着色入队，若已被同层其他色占用则取 `max`。
4. 队列空时返回 `grid`。

以示例 1 为例：源 `(0,0)=1`、`(2,2)=2`。第 1 层扩散后 `(0,1)=1`、`(1,0)=1`、`(1,2)=2`、`(2,1)=2`。第 2 层时 `(0,2)` 同时被 `(0,1)` 的 1 和 `(1,2)` 的 2 到达，取 `max(1,2)=2`；`(1,1)` 同理得 2；`(2,0)` 得 2。最终 `[[1,1,2],[1,2,2],[2,2,2]]`。

关键点：同层冲突必须比较颜色，不能简单「先到先得」。用层序遍历天然把「同一时间步」聚在一起。

```python
from collections import deque
q = deque()
for r, c, col in sources:
    grid[r][c] = col
    q.append((r, c))
while q:
    for _ in range(len(q)):
        r, c = q.popleft()
        for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
            nr, nc = r+dr, c+dc
            if 0 <= nr < n and 0 <= nc < m:
                if grid[nr][nc] == 0:
                    grid[nr][nc] = grid[r][c]
                    q.append((nr, nc))
                elif grid[nr][nc] < grid[r][c] and (nr, nc) in q:
                    grid[nr][nc] = grid[r][c]
```

## 复杂度
时间：O(n*m)，每个格子至多入队一次。
空间：O(n*m)，`grid` 加队列，队列最坏存整层。

## 易错点
1. 源颜色可能为 0？题目保证 `color_i >= 1`，所以 `grid == 0` 可安全表示未着色。但若把「已着色」判断写成 `grid[nr][nc] != 0` 而源色恰为 0 会漏判——本题不会，但换题要小心。
2. 同层冲突处理：若用普通 BFS 不分层，`(0,2)` 可能先被 1 占住，后到的 2 因「已着色」被跳过，输出 `[[1,1,1],...]` 错。必须按层处理并在同层内比较颜色取 `max`。

## 如果面试官追问
若要求输出每个格子的到达时间？答：在 `grid` 旁再开 `dist` 数组，入队时记 `dist[nr][nc] = dist[r][c] + 1`，冲突时同层取色大者、时间相同。
