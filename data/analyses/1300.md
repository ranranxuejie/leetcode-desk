## 一句话思路
排序后前缀和 + 二分答案 value：变换后的和随 value 单调不减，故可二分找最接近 target 的 value。

## 怎么做
1. 对 arr 排序，求前缀和 `pre`，`pre[i]` 表示前 i 个元素之和。
2. 对给定 value，用 `bisect_right(arr, value)` 得下标 k，则变换后和 = `pre[k] + value * (n - k)`。
3. 在 `[0, max(arr)]` 上二分，找第一个使和 ≥ target 的 value，记作 hi；答案在 hi 与 hi-1 中取差值更小者（相等取小）。
4. 用示例 1 `arr=[4,9,3], target=10`：排序后 `[3,4,9]`，`pre=[0,3,7,16]`。value=3 时 k=1，和 = `3 + 3*2 = 9`，差 1；value=4 时 k=2，和 = `7 + 4*1 = 11`，差 1，取小者 3。

```python
from bisect import bisect_right
arr.sort()
n = len(arr)
pre = [0] * (n + 1)
for i, x in enumerate(arr):
    pre[i + 1] = pre[i] + x

def total(v):
    k = bisect_right(arr, v)
    return pre[k] + v * (n - k)

lo, hi = 0, arr[-1]
while lo < hi:
    mid = (lo + hi) // 2
    if total(mid) < target:
        lo = mid + 1
    else:
        hi = mid
# lo 是第一个和 >= target 的 value
cand = [lo]
if lo > 0:
    cand.append(lo - 1)
ans = min(cand, key=lambda v: (abs(total(v) - target), v))
```

## 复杂度
时间：排序 O(n log n)，二分 O(log(max(arr)) · log n)，n 为数组长度。
空间：前缀和数组 O(n)，其余 O(1)。

## 易错点
- `arr=[2,3,5], target=10`：若只在 `[0, max(arr)]` 二分后直接返回 lo=5，看似对；但当 target 大于全部元素和（如 `arr=[1,1], target=100`），二分收敛到 max(arr)=1，和=2 远小于 100，正确 value 应是 1（无法再大），此时 hi-1 越界需特判 lo>0 才加候选。
- 差值相等时（示例 1 中 value=3 与 value=4 差都为 1）：若用 `min` 只按差值比较会返回 4，必须把 value 作为第二关键字 `(diff, v)` 才能取到最小值 3。

## 如果面试官追问
问：若要求返回所有最优 value？答：二分定位 hi 后，检查 hi-1、hi 两处差值，相等则都收集，否则只留差值小的那个。
