## 一句话思路
先抽出所有非负元素成列表 `a`，对 `a` 做左移 `k % len(a)` 的切片重排，再按原位置回填。

## 怎么做
1. 遍历 `nums`，把 `nums[i] >= 0` 的值依次追加到 `a`，同时记下这些下标（或回填时再扫一遍）。
2. 令 `m = len(a)`；若 `m == 0` 直接返回 `nums`，否则 `k %= m`。
3. 左移 k 位等价于 `a[k:] + a[:k]`，得到新顺序 `b`。
4. 再扫一遍 `nums`，遇到非负位置就取 `b` 的下一个元素填回去，负数原样跳过。

以 `nums = [1,-2,3,-4], k = 3` 为例：`a = [1,3]`，`m = 2`，`k % 2 = 1`，`b = a[1:] + a[:1] = [3,1]`；回填时下标 0 填 3、下标 2 填 1，得 `[3,-2,1,-4]`。

```python
a = [x for x in nums if x >= 0]
m = len(a)
if m:
    k %= m
    b = a[k:] + a[:k]
    j = 0
    for i in range(len(nums)):
        if nums[i] >= 0:
            nums[i] = b[j]
            j += 1
return nums
```

关键点：`k %= m` 必须用非负元素个数取模，不是用 `len(nums)`。示例 1 里 `k=3`、`m=2`，若对 4 取模得 3，切片 `a[3:]` 为空，结果就错成 `[1,-2,3,-4]`。

## 复杂度
时间 O(n)：两次扫描 `nums` 加一次切片拼接，n 为数组长度。
空间 O(m)：`a` 和 `b` 各存 m 个非负元素，m ≤ n。

## 易错点
- `nums` 全为负数（如 `[-3,-2,7]` 去掉 7 的情形）→ 若直接 `k %= len(a)` 会除零崩溃 → 先判 `if m == 0: return nums`，或把取模包在 `if m:` 里。
- `k` 大于非负元素个数（示例 1 的 `k=3, m=2`）→ 若对 `len(nums)=4` 取模，`a[3:]` 越界成空、顺序全乱 → 必须 `k %= m`，用非负元素个数而非数组长度。

## 如果面试官追问
若要求原地 O(1) 额外空间怎么做？答：对非负元素所在的下标序列做三次反转（整体、前 k、后 m-k），再按下标回填，空间降到 O(1)。
