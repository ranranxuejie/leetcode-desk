## 一句话思路
用单指针 i 顺序走完「跳空格 → 读符号 → 读数字」三段，边读边累加，越界就按 32 位范围截断。

## 怎么做
1. 用 `i` 跳过所有 `s[i] == ' '`，停下时 `i` 指向第一个非空格。
2. 读 `s[i]` 若为 `'-'` 或 `'+'`，记 `sign = -1 / 1` 并 `i += 1`；否则 `sign = 1`。
3. 循环 `while i < len(s) and s[i].isdigit()`，每轮 `num = num * 10 + int(s[i])`，`i += 1`。
4. 循环结束后返回 `sign * num`，但先按 `-2**31` 和 `2**31 - 1` 截断。

以 `s = " -042"` 为例：跳空格后 `i = 1`，读到 `'-'` 得 `sign = -1`、`i = 2`；随后读 `'0'` 时 `num = 0`，读 `'4'` 时 `num = 4`，读 `'2'` 时 `num = 42`，`i` 到末尾，返回 `-42`。前导零自然被 `num * 10 + 0` 吃掉，不用特判。

```python
i, n = 0, len(s)
while i < n and s[i] == ' ':
    i += 1
sign = 1
if i < n and s[i] in '+-':
    sign = -1 if s[i] == '-' else 1
    i += 1
num = 0
while i < n and s[i].isdigit():
    num = num * 10 + int(s[i])
    i += 1
num *= sign
return max(-2**31, min(2**31 - 1, num))
```

关键在最后一行：题目规定答案按 32 位截断，所以 `"9999999999"` 必须返回 `2147483647` 而不是原值。Python 整数本身不会溢出，截断是题意要求，不是语言限制。

## 复杂度
时间 O(n)：`i` 只前进不后退，n 是 `len(s)`，三段扫描合计不超过 n。
空间 O(1)：只开了 `i`、`sign`、`num` 三个标量，没有额外字符串或数组。

## 易错点
- 输入 `"words and 987"` → 若先 `strip()` 再找数字，会错成 987 → 正确做法是跳空格后立刻检查 `s[i]` 是否为符号或数字，不是就直接返回 0，绝不向后搜索。
- 输入 `"0-1"` → 若把 `'-'` 当成符号继续读，会错成 -1 → 正确做法是符号只在跳空格后读一次，`num` 一旦开始累加，遇到非数字立即停，返回 0。

## 如果面试官追问
问：如果要求返回截断前的完整大整数怎么办？
答：去掉最后的 `max/min`，直接返回 `sign * num`，Python 大整数天然支持，复杂度不变。
