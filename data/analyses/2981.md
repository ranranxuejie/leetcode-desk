## 一句话思路
按字符分组统计每段连续相同字符的长度，对每个字符取其最长三段长度算能凑出的最大公共长度。

## 怎么做
1. 扫描 `s`，把每个极大连续相同字符段的长度按字符收集进字典 `groups`，例如 `s = "aaaa"` 得到 `groups = {'a': [4]}`。
2. 对每个字符的长度列表降序排序，只保留前三个（第四段及以后不可能贡献更长答案）。
3. 三段长度 `a >= b >= c` 时，长度 L 能出现三次当且仅当 `a >= L`、`b >= L`、`c >= L` 或 `a >= 2L`（同一段里取两个不重叠的 L），故候选为 `max(c, a // 2)`。
4. 对所有字符取最大值，全程无候选则返回 -1。

关键中间值：`s = "abcaba"` 时 `groups = {'a': [1,1,1], 'b': [1], 'c': [1]}`，对 `'a'` 排序后 `a=b=c=1`，候选 `max(1, 1//2) = 1`，即答案 1。

```python
from collections import defaultdict

groups = defaultdict(list)
i = 0
while i < len(s):
    j = i
    while j < len(s) and s[j] == s[i]:
        j += 1
    groups[s[i]].append(j - i)
    i = j

ans = -1
for lens in groups.values():
    lens.sort(reverse=True)
    a = lens[0]
    b = lens[1] if len(lens) > 1 else 0
    c = lens[2] if len(lens) > 2 else 0
    ans = max(ans, max(c, a // 2))
return ans
```

注意 `a // 2` 这一项：`s = "aaaa"` 只有一段长度 4，`b = c = 0`，候选 `max(0, 4//2) = 2`，正是答案；若只写 `c` 会错得 0。

## 复杂度
时间 O(n + 26·k log k)，n 是 `s` 长度，排序只排每字符至多几段。
空间 O(n)，`groups` 存所有段长度，最坏全同字符时只有一个键。

## 易错点
- 输入 `s = "aaaa"` → 只按「三段不同段」算会得 0，漏掉同一段内取两个不重叠子串的情况 → 必须补 `a // 2` 这一项，且它和 `c` 取 max 而非相加。
- 输入 `s = "aaabbb"` → 若把不同字符的段混在一起统计会误判 → 特殊子串必须单一字符，`groups` 必须按字符分键，`'a'` 的段和 `'b'` 的段不能合并计数。

## 如果面试官追问
问：n 放大到 10^5 还这么做吗？
答：一样，扫描 O(n)，每字符段数虽多但只需保留最大三段，排序可换成维护 top3，总体 O(n)。
