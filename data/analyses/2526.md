## 一句话思路
维护「末尾连续等于 value 的个数」`streak`，每次 `consec` 遇到非 value 就清零，`streak >= k` 即返回 `True`。

## 怎么做
1. 构造函数里存下 `self.value = value`、`self.k = k`、`self.streak = 0`。
2. `consec(num)` 先判断：`num == self.value` 则 `streak += 1`，否则 `streak = 0`。
3. 返回 `self.streak >= self.k`，不足 k 个时 streak 必然小于 k，自动返回 `False`。

用官方示例走一遍：`value=4, k=3`。第 3 次调用 `consec(4)` 时，前两次已让 `streak=2`，这次 `num==4` 使 `streak=3`，`3 >= 3` 返回 `True`；第 4 次 `consec(3)`，`3 != 4` 直接把 `streak` 打回 `0`，返回 `False`。关键中间值就是这一次清零——它同时抹掉了前面所有 4 的累积。

```python
class DataStream:
    def __init__(self, value: int, k: int):
        self.value = value
        self.k = k
        self.streak = 0

    def consec(self, num: int) -> bool:
        if num == self.value:
            self.streak += 1
        else:
            self.streak = 0
        return self.streak >= self.k
```

不需要真的存队列：只要「最后 k 个全是 value」等价于「末尾连续 value 的长度 ≥ k」，而长度只需一个计数器。队列写法要 `deque` + 每次 `len` 判断，多占 O(k) 空间且无收益。

## 复杂度
时间：每次 `consec` 均摊 O(1)，共 n 次调用即 O(n)，无 log 项。
空间：O(1)，只存 `value`、`k`、`streak` 三个标量，不开队列。

## 易错点
- 输入 `k=1` 且首次 `consec(value)` → 若把判断写成 `streak > k` 会错成 `False`，正确是 `streak >= k`，此时 `1 >= 1` 返回 `True`。
- 输入序列 `[4,4,3,4,4]`（value=4, k=3）→ 若只统计「总共出现过几个 4」而不清零，会在末尾错成 `True`；正确做法是遇到 `3` 时 `streak = 0`，之后重新从 0 累加，末尾只有 2 个连续 4，返回 `False`。

## 如果面试官追问
问：若要求返回「最后 k 个整数的和」而非布尔值？
答：把 `streak` 换成滑动窗口和，进一个减一个，仍需 O(1) 空间但要多存一个长度为 k 的队列。
