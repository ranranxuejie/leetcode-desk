## 一句话思路
用哈希集合存已出现段，从每个起点贪心扩展直到当前子串不在集合中，即得最短唯一段。

## 怎么做
1. 初始化 `seen = set()`、`res = []`、`i = 0`。
2. 外层循环：`j = i`，内层不断 `j += 1` 直到 `s[i:j] not in seen`。
3. 把 `s[i:j]` 加入 `seen` 和 `res`，`i = j`。
4. 循环直到 `i == len(s)`。

以 `s = "abbccccd"` 为例：`i=0` 时 `j` 从 1 扩到 1，`s[0:1]="a"` 不在 `seen`，收段；`i=1` 时 `s[1:2]="b"` 不在，收段；`i=2` 时 `s[2:3]="b"` 已在 `seen`，继续扩到 `j=4`，`s[2:4]="bc"` 不在，收段。关键中间值：`i=2` 时 `j` 必须从 3 走到 4，因为 `"b"` 命中集合。

```python
seen = set()
res = []
i = 0
n = len(s)
while i < n:
    j = i + 1
    while s[i:j] in seen:
        j += 1
    seg = s[i:j]
    seen.add(seg)
    res.append(seg)
    i = j
```

注意 `j` 初值取 `i+1` 而非 `i`，保证段非空；内层 `while` 条件用 `in seen`，一旦不命中立即停，这就是「最短唯一段」。

## 复杂度
时间：每个字符最多被内层扫描常数次，但 `s[i:j]` 切片与哈希各 O(段长)，总 O(n²) 最坏（如 `"aaaa..."` 段长递增）。
空间：`seen` 存所有段共 O(n) 字符，`res` 同量级。

## 易错点
- 输入 `"aaaa"`：若内层写成 `while s[i:j] in seen or j == i`，`j` 初值错成 `i` 会产出空串死循环；正确是 `j = i + 1` 起步，`"a"` 命中后扩到 `"aa"` 才收。
- 输入 `"abbccccd"`：若把 `seen.add` 放在内层循环里每扩一步就加，`"b"` 会被提前污染，导致 `i=2` 时误判 `"bc"` 已存在；正确是只在收段后 `seen.add(seg)` 一次。

## 如果面试官追问
若 n 放大到 10^6 且要求 O(n log n)，怎么办？答：用字典树存已出现段，扩展时沿树走，命中即停，把切片哈希的 O(段长) 降到 O(1) 摊还。
