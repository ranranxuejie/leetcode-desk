## 一句话思路
对每个树节点做一次「同步下行」的 DFS：树指针和链表指针同时走，链表走完即命中。

## 怎么做
1. 外层遍历树：对 `root` 的每个节点都调用一次匹配函数 `dfs(t, h)`，因为路径起点可以是任意节点。
2. `dfs` 的终止条件先判链表：`h is None` 返回 `True`（整条链表已对上），`t is None` 返回 `False`。
3. 值不等直接 `False`，相等才递归 `dfs(t.left, h.next) or dfs(t.right, h.next)`——注意两个分支都要试，不能只走一边。
4. 外层用 `dfs(root, head) or isSubPath(head, root.left) or isSubPath(head, root.right)`。

以示例 1 的 `head = [4,2,8]` 为例：外层扫到根右子 `4`（第二层）时，`dfs` 里 `h.val=4` 与 `t.val=4` 相等，进入 `t.left`（值 2）匹配 `h.next`（值 2），再进 `t.left.left`（值 8）匹配 `h.next.next`（值 8），此时 `h.next.next.next is None`，返回 `True`。关键中间值：走到第三层时 `h` 已为 `None`，而 `t` 还有子节点，仍算成功——链表短于路径是允许的。

```python
def dfs(t, h):
    if h is None:
        return True
    if t is None or t.val != h.val:
        return False
    return dfs(t.left, h.next) or dfs(t.right, h.next)

def isSubPath(head, root):
    if root is None:
        return False
    return dfs(root, head) or isSubPath(head, root.left) or isSubPath(head, root.right)
```

## 复杂度
时间 O(n·m)：n 为树节点数 2500，m 为链表长度 100，每个树节点最多向下匹配 m 层。
空间 O(m)：递归栈深度受链表长度限制，最坏 m=100，未额外开数组。

## 易错点
- 链表只剩一个节点且已匹配、树节点还有孩子时，若把终止条件写成「`t is None` 才返回 True」，示例 1 的 `[4,2,8]` 会在第三层 `8` 处因 `t` 非空而误判 False；必须先判 `h is None`。
- 外层只对 `root` 调一次 `dfs` 就返回，示例 2 的 `head=[1,4,2,6]` 起点在根（值 1）能对上，但若链表改成 `[4,2,6]` 起点在第二层，只调一次会漏掉；必须对每个节点都作为起点尝试。

## 如果面试官追问
若要求返回具体路径（节点列表）而非布尔值？答：`dfs` 改为返回「匹配成功时收集的节点列表」，失败返回 `None`，外层命中即返回该列表。
