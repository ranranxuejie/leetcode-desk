## 一句话思路
从右往左累加 shifts 得到每个位置的真实移位量，再对 26 取模映射到字母。

## 怎么做
1. 逆序遍历 shifts，用变量 `total` 累加后缀和，`total` 就是 `s[i]` 需要移位的总次数。
2. 对 `total` 取 `% 26`，避免 `shifts[i]` 高达 1e9 时数值膨胀。
3. 用 `(ord(s[i]) - ord('a') + total) % 26 + ord('a')` 算出新字符。

以 `s = "abc", shifts = [3,5,9]` 为例：i=2 时 `total=9`，`'c'` 移 9 位得 `'l'`；i=1 时 `total=14`，`'b'` 移 14 位得 `'p'`；i=0 时 `total=17`，`'a'` 移 17 位得 `'r'`，拼出 `"rpl"`。

```python
def shiftingLetters(s, shifts):
    res = []
    total = 0
    for i in range(len(s) - 1, -1, -1):
        total = (total + shifts[i]) % 26
        code = (ord(s[i]) - ord('a') + total) % 26
        res.append(chr(code + ord('a')))
    return ''.join(reversed(res))
```

关键在 `total` 只保留模 26 的余数：`shifts = [10**9, 10**9]` 时若直接累加会得到 2e9，取模后仍是正确位移量，因为字母表周期是 26。

## 复杂度
时间 O(n)：一次逆序遍历，n 为 `len(s)`。
空间 O(n)：`res` 列表存 n 个字符，`total` 是常数。

## 易错点
- 正序遍历 shifts → 把 `shifts[i]` 当成 `s[i]` 的移位量，得到 `"abc"` 变 `"dfi"` 而非 `"rpl"` → 必须逆序累加后缀和，因为 `shifts[i]` 影响的是前 `i+1` 个字母。
- 累加 `total` 时不取模 → `shifts` 元素达 1e9、长度 1e5 时 `total` 到 1e14，虽 Python 不溢出但没必要 → 每步 `total = (total + shifts[i]) % 26`，结果不变且数值可控。

## 如果面试官追问
问：若 shifts 长度小于 s 长度怎么处理？答：题面保证等长，若不等则缺失位置按 0 处理，逆序遍历时用 `shifts[i] if i < len(shifts) else 0`。
