## 一句话思路
以每个节点为根做换根 DP：先自底向上算「子树内全部标记完的时刻」，再自顶向下把父方向的结果并进来，两次 DFS 得到全部答案。

## 怎么做
1. 定义 `down[u]` = 只考虑 u 的子树、u 在时刻 0 被标记时，子树全部标记完的时刻；转移 `down[u] = max(down[v] + (1 if v 是奇数 else 2))`，v 取 u 的所有子节点。
2. 定义 `up[u]` = 只考虑 u 的父方向、u 在时刻 0 被标记时，父方向全部标记完的时刻；对根 `up[root] = 0`。
3. 换根：把 u 的父方向当成一条「虚拟子树」，其贡献是 `up[u] + (1 if u 是奇数 else 2)`，与 u 的其他子节点一起取 max，得到 `up[v]`。
4. 答案 `times[u] = max(down[u], up[u])`。

以示例 1 `edges = [[0,1],[0,2]]` 为例，根取 0：`down[1]=0, down[2]=0`，`down[0] = max(0+1, 0+2) = 2`。换根到 1 时，父方向贡献 `up[0] + (1 if 0 是偶数 else 2) = 0 + 2 = 2`，再与兄弟 2 的贡献 `0 + 2 = 2` 取 max，得 `up[1] = 2`，故 `times[1] = max(0, 2) = 2`？实际应为 4——注意 `up[1]` 要算的是「从 1 出发标记父方向」，父方向里 0 被标记需 2 时刻，0 再标记 2 需再 2 时刻，所以是 `2 + 2 = 4`，即 `up[1] = max(up[0] + 2, down[2] + 2) = 4`。

```python
def dfs1(u, p):
    down[u] = 0
    for v in g[u]:
        if v != p:
            dfs1(v, u)
            down[u] = max(down[u], down[v] + (1 if v % 2 else 2))

def dfs2(u, p):
    best1 = best2 = -1  # 最大、次大贡献
    for v in g[u]:
        if v != p:
            c = down[v] + (1 if v % 2 else 2)
            if c > best1: best2, best1 = best1, c
            elif c > best2: best2 = c
    for v in g[u]:
        if v != p:
            sib = best2 if down[v] + (1 if v % 2 else 2) == best1 else best1
            up[v] = max(up[u], sib) + (1 if u % 2 else 2)
            dfs2(v, u)
```

## 复杂度
时间：两次 DFS 各遍历每条边一次，O(n)。
空间：邻接表 O(n)，`down/up` 数组 O(n)，递归栈最坏 O(n)。

## 易错点
1. 换根时用「最大值减自身」求兄弟最大值 → 当 u 有多个子节点贡献相同最大值时会算错，如示例 3 中节点 2 的两个子节点贡献相同；正确做法是同时维护最大和次大贡献，按值判断取哪个。
2. 边权方向搞反 → 把「v 是奇数加 1、偶数加 2」写成「u 是奇数加 1」，示例 2 中 `edges=[[0,1]]` 会得 `[2,1]` 而非 `[1,2]`；正确做法是转移时看**被标记的那个节点**的奇偶性。

## 如果面试官追问
若 n 扩大到 10^6 导致递归爆栈，怎么办？答：把两次 DFS 改成显式栈的迭代后序遍历，或先 BFS 求拓扑序再逆序算 `down`、正序算 `up`。
