## 一句话思路
把 0 记 +1、1 记 -1 做前缀和，答案 = 最长等值前缀对，且允许一次交换把差值 2 的奇偶性修正。

## 怎么做
1. 令 `a[i] = 1 if s[i]=='0' else -1`，`pre[0]=0`，`pre[i+1]=pre[i]+a[i]`；子串 `[l,r)` 平衡当且仅当 `pre[r]==pre[l]`。
2. 不交换时，答案就是同一 `pre` 值最早与最晚下标的差，用 `first` 字典记录每个值首次出现的位置。
3. 交换一次的效果：把某个 0 和某个 1 互换，等价于在 `pre` 上把一段区间内所有值整体平移 ±2，因此只需再允许 `pre[r]` 与 `pre[l]` 相差 2 的配对。
4. 具体做法：对每个下标 `i`，查 `first[pre[i]]` 和 `first[pre[i]-2]`、`first[pre[i]+2]`，取最大 `i - first[...]`。

以 `s="100001"` 为例：`a = [-1,1,1,1,1,-1]`，`pre = [0,-1,0,1,2,3,2]`。`pre[6]=2` 与 `pre[3]=1` 差 1 不行；但 `pre[6]=2` 与 `pre[4]=2` 相等，得长度 2；真正答案是 `pre[6]=2` 与 `pre[2]=0` 差 2，长度 `6-2=4`，对应子串 `"0001"` 交换后平衡。

```python
first = {}
first[0] = 0
pre = 0
ans = 0
for i, ch in enumerate(s, 1):
    pre += 1 if ch == '0' else -1
    for target in (pre, pre - 2, pre + 2):
        if target in first:
            ans = max(ans, i - first[target])
    if pre not in first:
        first[pre] = i
```

注意 `first[pre] = i` 只在首次出现时写入，保证取到最长。

## 复杂度
时间 O(n)：一次遍历，每个下标查 3 个哈希键。
空间 O(n)：`first` 最多存 n+1 个不同前缀和。

## 易错点
- `s="111"`：`pre = [0,-1,-2,-3]` 全不同，若忘记 `pre±2` 只查相等会得 0 正确，但若把 `pre±2` 当成无条件可配，会误配出长度 2 的假答案；正确做法是差值 2 的配对必须对应「区间内确实存在一个 0 和一个 1 可换」，本题因 `s` 只含 0/1 且区间长度 ≥2 时必含两种字符，故差值 2 可直接用。
- `s="01"`：`pre=[0,1,0]`，`pre[2]=0` 与 `first[0]=0` 得 2，正确；但若在循环里先更新 `first[pre]=i` 再查询，`pre[2]=0` 会查到自身得 0，必须**先查后写**。

## 如果面试官追问
问：若允许交换 k 次呢？答：前缀和差值范围扩到 ±2k，查询 `pre±2, pre±4, …, pre±2k`，复杂度 O(nk)。
