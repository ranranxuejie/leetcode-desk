## 一句话思路
边遍历边用哈希表记每个值已出现的次数，遇到 nums[j] 就把该值此前的出现次数累加进答案。

## 怎么做
1. 建一个字典 `cnt`，键是 `nums` 里的值，值是它到目前为止出现的次数。
2. 遍历 `nums`，对当前元素 `x`，先把 `cnt.get(x, 0)` 加到答案 `ans` 上——这正好是能和 `x` 组成好数对的、下标更小的同值元素个数。
3. 再把 `cnt[x]` 加 1，供后面的元素使用。

以 `nums = [1,2,3,1,1,3]` 为例，走到下标 4 的第二个 `1` 时，`cnt[1]` 已经是 2（下标 0 和 3），`ans` 从 1 变成 3；走到下标 5 的 `3` 时 `cnt[3]` 是 1，`ans` 变成 4，与输出一致。

```python
cnt = {}
ans = 0
for x in nums:
    ans += cnt.get(x, 0)
    cnt[x] = cnt.get(x, 0) + 1
return ans
```

等价写法是先统计频次再算组合数：某个值出现 `c` 次，贡献 `c * (c - 1) // 2`。两种写法结果相同，但边遍历边累加只需一趟，且不用处理 `c < 2` 的边界。

## 复杂度
时间 O(n)：遍历 `nums` 一次，字典单次操作均摊 O(1)。
空间 O(k)：`cnt` 最多存 k 个不同值，k ≤ min(n, 100)。

## 易错点
- `nums = [1,1,1,1]` → 若写成「每遇到一个值就把 `cnt[x]` 直接加上去再自增」的顺序颠倒，或漏掉自增，会得到 0 或 4 而不是 6 → 必须先累加旧计数、再自增，顺序不能换。
- `nums = [1,2,3]` → 若用 `cnt[x] += 1` 而不先 `get(x, 0)`，会抛 `KeyError` → 统一用 `cnt.get(x, 0)` 取值，别依赖字典默认值。

## 如果面试官追问
问：如果要求返回所有好数对的下标方案而不是个数？
答：把 `ans += cnt.get(x, 0)` 换成遍历该值已存的下标列表逐个配对，空间从 O(k) 升到 O(n)。
