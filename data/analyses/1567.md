## 一句话思路
用 `pos`/`neg` 记录以当前元素结尾的乘积为正/负的最长子数组长度，遇到 0 时两者清零。

## 怎么做
1. 初始化 `pos = neg = ans = 0`，遍历 `nums` 中的每个 `x`。
2. `x > 0`：`pos += 1`，`neg = neg + 1 if neg else 0`（负子数组延长后仍为负，没有则保持 0）。
3. `x < 0`：`new_pos = neg + 1 if neg else 0`，`new_neg = pos + 1`，再同时赋值回 `pos, neg`。
4. `x == 0`：`pos = neg = 0`；每步用 `ans = max(ans, pos)` 更新答案。

以 `nums = [0,1,-2,-3,-4]` 为例：`x=0` 后 `pos=neg=0`；`x=1` 得 `pos=1, neg=0`；`x=-2` 得 `pos=0, neg=2`；`x=-3` 得 `pos=3, neg=1`，此时 `ans=3`；`x=-4` 得 `pos=2, neg=4`，最终返回 3。

```python
pos = neg = ans = 0
for x in nums:
    if x > 0:
        pos += 1
        neg = neg + 1 if neg else 0
    elif x < 0:
        pos, neg = (neg + 1 if neg else 0), pos + 1
    else:
        pos = neg = 0
    ans = max(ans, pos)
return ans
```

## 复杂度
时间：O(n)，一次遍历 `nums`，每个元素常数次比较与赋值。
空间：O(1)，只开了 `pos`、`neg`、`ans` 三个整型变量。

## 易错点
- 输入 `nums = [-1]` → 若把 `neg` 初始化为 0 后直接 `pos = neg + 1`，会得到 `pos = 1` 而错答 1 → 正确做法是 `x < 0` 时 `pos` 取 `neg + 1 if neg else 0`，单个负数时 `pos` 必须为 0。
- 输入 `nums = [1,-2]` → 若在 `x < 0` 时先改 `pos` 再算 `neg`，`neg` 会用到已被覆盖的 `pos`，错成 1 → 正确做法是用元组同时赋值 `pos, neg = ..., pos + 1`，让 `neg` 读到旧的 `pos`。

## 如果面试官追问
问：要求返回具体子数组的下标区间怎么办？
答：额外记 `pos_start`/`neg_start`，在 `x < 0` 交换时同步交换起点，`ans` 更新时一并存下 `[start, i]`。
