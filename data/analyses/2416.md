## 一句话思路
把 words 建成字典树，每个节点记「经过它的单词数」，再对每个 word 沿路径累加这些计数即得答案。

## 怎么做
1. 建树时对每个字符经过的节点 `cnt += 1`，这样节点值就是「以该节点前缀开头的单词数」。
2. 对每个 word 从根走一遍，把沿途每个节点的 `cnt` 累加进 `answer[i]`。
3. 走完即得该词所有非空前缀的分数和（根节点不计）。

以 `words = ["abc","ab","bc","b"]` 为例：插入 "abc" 后路径 a→b→c 的 cnt 为 1,1,1；插入 "ab" 后 a、ab 节点变 2,2；插入 "bc"、"b" 后 b 节点变 2、bc 节点为 1。查 "abc" 时累加 2+2+1=5，与示例一致。

```python
cnt = {}
for w in words:
    node = ""
    for ch in w:
        node += ch
        cnt[node] = cnt.get(node, 0) + 1
ans = []
for w in words:
    s, node = 0, ""
    for ch in w:
        node += ch
        s += cnt[node]
    ans.append(s)
```

上面用字符串当 key 最省事；若担心拼接开销，可换成 `(节点编号, 字符)` 的字典树，逻辑不变。

## 复杂度
时间：O(总字符数)，建树和查询各扫一遍所有字符。
空间：O(总字符数)，存每个前缀节点的计数。

## 易错点
- 把根节点（空前缀）的计数也算进去 → 每个答案多出 n。空前缀不是合法前缀，累加必须从第一个字符后开始。
- 用 `words.count` 或对每个前缀重新扫一遍 words 求分数 → 在 n=1000、长度 1000 时退化成 O(n²·L)。必须先建一次树，让每个节点只被写一次。

## 如果面试官追问
问：若 words 里有重复字符串怎么办？
答：计数天然按出现次数累加，重复词各自贡献一次，答案数组按位置分别输出即可，无需去重。
