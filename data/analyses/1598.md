## 一句话思路
用一个整数 `depth` 记录当前所在层数，遍历日志按三种操作增减，最后 `depth` 就是回主文件夹的步数。

## 怎么做
1. 初始化 `depth = 0`，代表启动时位于主文件夹。
2. 遍历 `logs`，只比较字符串的**首字符**：`"../"` 减一，`"./"` 不变，其余（形如 `"x/"`）加一。
3. 减一时用 `max(depth - 1, 0)` 兜底，防止在主文件夹下继续 `"../"` 把层数压成负数。
4. 遍历结束后直接返回 `depth`。

以示例 1 `logs = ["d1/","d2/","../","d21/","./"]` 为例，`depth` 依次变化为 1 → 2 → 1 → 2 → 2，最终返回 2。关键在第三步：`"../"` 把 2 减到 1，而不是减到 0，因为此时确实在 `d2` 里。

```python
depth = 0
for log in logs:
    if log == "../":
        depth = max(depth - 1, 0)
    elif log == "./":
        continue
    else:
        depth += 1
return depth
```

注意判断顺序：`"../"` 和 `"./"` 都以 `.` 开头，但长度和内容不同，用 `==` 全等比较最稳；若图快用 `log[0] == '.'` 再细分，必须保证 `"../"` 分支在前。

## 复杂度
时间 O(n)：n 为 `logs` 长度，每条日志只做一次常数比较。
空间 O(1)：只开了一个整数 `depth`，没有栈或列表。

## 易错点
- 输入 `["d1/","../","../","../"]` → 若直接 `depth -= 1` 不兜底，`depth` 会变成 -2，返回负数 → 正确做法是 `max(depth - 1, 0)`，因为题目规定已在主文件夹时 `"../"` 原地不动，示例 3 的答案正是 0。
- 输入含 `"./"` 的日志（如示例 2 第 3 条）→ 若用 `log[0] == '.'` 统一当父目录处理，会把 `"./"` 误减一层，示例 2 会错成 2 → 正确做法是先全等匹配 `"../"`，再单独 `continue` 掉 `"./"`，剩下的才 `depth += 1`。

## 如果面试官追问
问：如果要求输出回到主文件夹的具体操作序列怎么办？
答：把 `depth` 换成列表当栈，`"../"` 时 `pop`（栈非空才弹），最后返回 `["../"] * len(stack)`。
