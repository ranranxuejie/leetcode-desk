## 一句话思路
把两个不等式平方后化简，发现完美对等价于 `|a|` 与 `|b|` 的二进制最高位相同，于是按最高位分组计数。

## 怎么做
1. 令 `x=|a|, y=|b|`，设 `x<=y`。条件一 `min(|a-b|,|a+b|) <= x` 恒成立（因为 `|a-b|` 与 `|a+b|` 中较小者不超过 `2x`，而实际可证不超过 `x` 当且仅当…），关键是条件二。
2. 用恒等式 `max(|a-b|,|a+b|) = x + y`（当 `a,b` 同号取 `|a+b|`，异号取 `|a-b|`，两者都等于 `x+y`）。于是条件二变成 `x + y >= y`，即 `x >= 0`，恒成立——所以真正起约束的是条件一。
3. 条件一化简：`min(|a-b|,|a+b|) = |x - y|`（同号时 `|a-b|=|x-y|`，异号时 `|a+b|=|x-y|`）。于是要求 `|x-y| <= x`，即 `y <= 2x`。
4. 所以完美对 ⟺ `max(x,y) <= 2*min(x,y)`，即两数绝对值之比不超过 2。按绝对值排序后双指针/二分统计即可。

以 `nums=[0,1,2,3]` 为例：绝对值 `[0,1,2,3]`。`(1,2)`：`2<=2*1` ✓；`(2,3)`：`3<=2*2` ✓；`(1,3)`：`3<=2*1` ✗。得 2，与示例一致。注意 `0` 只能和 `0` 配对（`0<=0` 成立，`y<=0` 要求 `y=0`）。

```python
def perfectPairs(nums):
    a = sorted(abs(v) for v in nums)
    ans, j = 0, 0
    for i, x in enumerate(a):
        if j < i:
            j = i
        while j + 1 < len(a) and a[j + 1] <= 2 * x:
            j += 1
        ans += j - i
    return ans
```

## 复杂度
时间 O(n log n)：排序主导，双指针 O(n)。
空间 O(n)：排序后新开的绝对值数组（原地排序可降到 O(log n) 栈）。

## 易错点
- 输入含 `0`，如 `[0,0,1]`：若把 `0` 当普通值用 `y<=2x` 判，`(0,1)` 会因 `1<=0` 被正确排除，但若先取对数/位运算会因 `log(0)` 或最高位未定义而崩，需单独处理 `x==0` 只与 `0` 配对。
- 输入 `[-3,2,-1,4]`：忘记取绝对值直接排序，`-3` 排最前导致 `(-3,2)` 被判 `2<=2*(-3)` 失败而漏掉，正确是先 `abs` 再排序，得 4 对。

## 如果面试官追问
若要求输出所有完美对的下标而非计数？答：排序会丢下标，需存 `(abs值, 原下标)` 再双指针枚举，最坏 O(n²) 对输出本身即 O(n²)。
