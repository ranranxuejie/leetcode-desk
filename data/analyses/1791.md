## 一句话思路
星型图里中心节点出现在每条边上，所以只需比较前两条边，取它们的公共端点。

## 怎么做
1. 取 `edges[0] = [a, b]` 和 `edges[1] = [c, d]` 两个端点集合。
2. 星型图保证中心与所有节点相连，因此前两条边必然共享中心节点。
3. 返回这两个集合的交集里唯一的那个元素。

以示例 1 `edges = [[1,2],[2,3],[4,2]]` 为例：`edges[0]` 是 `{1,2}`，`edges[1]` 是 `{2,3}`，交集为 `{2}`，所以中心是 `2`。注意第三条边 `[4,2]` 完全没参与计算，这正是本解法的价值：不需要遍历全部 `n-1` 条边。

```python
def findCenter(edges):
    a, b = edges[0]
    c, d = edges[1]
    if a == c or a == d:
        return a
    return b
```

也可以写成集合交集 `return list(set(edges[0]) & set(edges[1]))[0]`，但上面这版不建集合、不分配额外对象，常数更小。核心判断只有一次比较：`a` 是否等于 `c` 或 `d`；若不等，`b` 必是中心，因为 `edges[0]` 的两个端点里至少有一个落在 `edges[1]` 上。

## 复杂度
时间 O(1)：只读 `edges[0]` 和 `edges[1]` 共 4 个整数，与 `n` 无关。
空间 O(1)：只用了 `a, b, c, d` 四个变量，没有开集合或哈希表。

## 易错点
- 输入 `edges = [[1,2],[5,1],[1,3],[1,4]]` 时，若只拿 `edges[0][0] = 1` 直接返回，示例 1 会错成 `1`（正确答案 `2`）→ 必须先做一次端点比对，不能默认第一条边的首元素就是中心。
- 输入 `edges = [[2,1],[2,3]]` 时，若写成 `if a == c: return a else: return c`，会错成 `3` → 中心可能出现在 `edges[1]` 的第二个位置，判断条件要覆盖 `a == c or a == d` 两种情况。

## 如果面试官追问
追问：如果图不是星型图，而是任意连通无向图，怎么找「度数最高的节点」？
答：用哈希表统计每个端点出现次数，取最大值对应节点，时间 O(n)、空间 O(n)。
