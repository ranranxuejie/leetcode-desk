## 一句话思路
坐标范围只有 0..50，直接枚举 51×51 个整数点，逐塔累加可达信号取最大。

## 怎么做
1. 由 towers 求出所有塔坐标的最大值 `mx, my`，枚举范围就是 `0..mx` × `0..my`。
2. 对每个候选点 `(x, y)`，遍历每座塔，先算平方距离 `d2 = (x-tx)**2 + (y-ty)**2`，与 `radius*radius` 比较判断是否可达。
3. 可达时用 `math.isqrt(d2)` 取整数部分，累加 `q // (1 + d)`；不可达直接跳过。
4. 按 `x` 外层、`y` 内层升序枚举，只有严格大于当前最大值才更新，天然满足字典序最小。

以示例 1 为例，枚举到 `(2,1)` 时：塔 `(2,1,7)` 的 `d2=0`，贡献 `7//1=7`；塔 `(1,2,5)` 的 `d2=2`，`isqrt(2)=1`，贡献 `5//2=2`；塔 `(3,1,9)` 的 `d2=1`，贡献 `9//2=4`，合计 13，成为当前最优。

```python
import math
mx = max(t[0] for t in towers)
my = max(t[1] for t in towers)
best, ans = -1, [0, 0]
for x in range(mx + 1):
    for y in range(my + 1):
        s = 0
        for tx, ty, q in towers:
            d2 = (x - tx) ** 2 + (y - ty) ** 2
            if d2 <= radius * radius:
                s += q // (1 + math.isqrt(d2))
        if s > best:
            best, ans = s, [x, y]
```

## 复杂度
时间 O(mx·my·n)，n 为塔数，mx、my ≤ 50，约 51×51×50 次。
空间 O(1)，只存 best 和 ans，无额外数组。

## 易错点
- 用 `d2 <= radius*radius` 判可达，别开方后比较：`sqrt` 浮点误差会让恰好等于 radius 的点（如 d2=4、radius=2）被判成不可达，漏掉贡献。
- 枚举上界取塔坐标最大值而非固定 50：示例 2 只有塔 `(23,11)`，若枚举到 50 会多算大量空点，虽不影响答案但白跑；同时别把上界写成 `max(x)+radius`，超出塔覆盖范围的点信号恒为 0，只会拖慢。
- 更新条件必须是 `s > best` 而非 `>=`：示例 3 中 `(1,2)` 与 `(0,1)` 附近若并列，用 `>=` 会返回字典序更大的坐标。

## 如果面试官追问
若坐标范围放大到 10^9 怎么办？答：最优解必在某塔的覆盖圆内，可只枚举各塔周围半径 radius 内的整数点，或按信号函数单调性剪枝，规模从 51² 降到 n·(2r)²。
