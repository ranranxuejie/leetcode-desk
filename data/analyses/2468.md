## 一句话思路
枚举总段数 b，用「每段净容量 = limit - len("<a/b>")」反推能否装下 message，第一个可行的 b 就是最短答案。

## 怎么做
1. 从 b = 1 往上枚举，对每个 b 算出编号位数 d = len(str(b))，则每段净容量 cap = limit - d - 3（`<`、`/`、`>` 占 3 位，`a` 占 d 位，`b` 也占 d 位）。
2. 前 b-1 段必须满长，各吃 cap 个字符；最后一段只需 ≤ cap，所以总容量区间是 `[(b-1)*cap, b*cap]`，判断 `len(message)` 是否落在这个区间内。
3. 命中后按 cap 切片，第 i 段拼上 `f"<{i+1}/{b}>"`；最后一段取剩余字符即可。

以示例 1 为例：message 长 38，limit = 9。b = 13 时 d = 2，cap = 9 - 2 - 3 = 4，容量区间 [48, 52]，38 不在内；b = 14 时 d = 2，cap = 4，区间 [52, 56] 仍不含 38——注意这里 cap 是 4 但实际每段只放 3 个字符，因为 b = 14 时 `a` 从 1 到 14 位数不同，前 9 段 `a` 是 1 位、后 5 段是 2 位，所以真正要按「每段实际可用 = limit - len(str(i)) - len(str(b)) - 3」逐段算，不能统一用 d。

```python
def splitMessage(message, limit):
    n = len(message)
    for b in range(1, n + 1):
        total = 0
        ok = True
        for i in range(1, b + 1):
            cap = limit - len(str(i)) - len(str(b)) - 3
            if cap <= 0:
                ok = False
                break
            total += cap
            if i < b and cap == 0:
                ok = False
                break
        if ok and total >= n:
            res, pos = [], 0
            for i in range(1, b + 1):
                cap = limit - len(str(i)) - len(str(b)) - 3
                take = cap if i < b else n - pos
                res.append(message[pos:pos + take] + f"<{i}/{b}>")
                pos += take
            return res
    return []
```

## 复杂度
时间：外层 b 最多 n 次、内层累加最多 n 次，最坏 O(n²)，n = len(message)。
空间：结果数组存 n 个字符加每段标签，O(n)。

## 易错点
- 把 cap 当成全局常量：b = 14、limit = 9 时若统一用 d = 2 算 cap = 4，会以为每段能放 4 个字符，实际第 1 段 `<1/14>` 占 6 位只剩 3 位，切片会错位、拼出的串对不上 message。必须逐段用 `len(str(i))` 算。
- 只判 `total >= n` 不判最后一段：b = 1、limit = 5、message = "abcde" 时 cap = 5 - 1 - 1 - 3 = 0，`<1/1>` 就占满 5 位，没有字符位置，应返回空数组；漏判 cap ≤ 0 会切出空串或负长度。

## 如果面试官追问
问：message 长度到 10^6 还这么枚举吗？
答：b 的上界可先由 `n / (limit - 2*len(str(b)) - 3)` 估出量级，再在候选 b 附近二分或直接按位数分段枚举，避免 O(n²)。
