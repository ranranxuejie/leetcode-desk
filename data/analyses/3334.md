## 一句话思路
n≤100 且值≤30，直接枚举「移除第 i 个」和「不移除」共 n+1 种情况，各自重算 GCD 与 LCM 取最大。

## 怎么做
1. 先算不移除时的整体 GCD 与 LCM，作为基准答案。
2. 对每个下标 i，把除 nums[i] 外的元素重新扫一遍求 GCD 和 LCM。
3. 用 `gcd` 和 `lcm = a // gcd(a,b) * b` 逐元素合并，注意先除后乘。
4. 所有候选取最大值返回。

以 `nums = [2,4,8,16]` 为例：不移除时 GCD=2、LCM=16，得分 32；移除 nums[0]=2 后剩余 `[4,8,16]`，GCD 从 4 起、LCM 从 4 起合并 8 得 8、合并 16 得 16，得分 4*16=64，超过基准，最终返回 64。

```python
from math import gcd

def score(arr):
    g, l = 0, 1
    for x in arr:
        g = gcd(g, x)
        l = l // gcd(l, x) * x
    return g * l

best = score(nums)                      # 不移除
for i in range(len(nums)):
    rest = nums[:i] + nums[i+1:]
    best = max(best, score(rest))       # 空数组时 score 返回 0*1=0
return best
```

关键点：`score` 里 `g` 初值 0（gcd(0,x)=x）、`l` 初值 1（lcm(1,x)=x），空数组自然得 0，正好对上题面「空数组得分为 0」。

## 复杂度
时间：O(n² log M)，外层 n 次移除 × 内层 n 个元素 × 每次 gcd 的 log M（M≤30）。
空间：O(1)，只用了 g、l、best 几个标量，`rest` 切片是 O(n) 但可改成跳过下标。

## 易错点
- 输入 `nums = [3]`：移除唯一元素后是空数组，若把空数组的 GCD 当 1、LCM 当 1 会得 1，正确是 score 返回 0，最终答案取不移除的 3*3=9。
- 输入 `[2,4,8,16]`：若先乘后除写 `l * x // gcd(l,x)`，在值域放大时中间积可能超范围；本题值≤30 不会炸，但换成大值域就翻车，正确写法是 `l // gcd(l, x) * x`。

## 如果面试官追问
问：nums 长度放大到 10^5 怎么办？
答：用前缀/后缀 GCD 与 LCM 数组，O(n log M) 枚举移除点，避免每次重扫。
