## 一句话思路
用前缀和原地累加：`nums[i] += nums[i-1]`，因为第 i 项等于前一项的动态和加上当前元素。

## 怎么做
1. 从下标 1 开始遍历，跳过 `nums[0]`（它本身就是第一项动态和）。
2. 对每个 i，执行 `nums[i] += nums[i-1]`，把前一项的动态和直接叠进当前元素。
3. 遍历结束返回 `nums`，此时它已被改写成动态和数组。

以 `nums = [1,2,3,4]` 为例，关键一步是 i=2 时：`nums[1]` 已经是 3，执行 `nums[2] = 3 + 3 = 6`，而不是 `2+3`——这正是原地累加与「另开数组存原始值」的区别。

```python
def runningSum(nums):
    for i in range(1, len(nums)):
        nums[i] += nums[i - 1]
    return nums
```

注意 `range` 从 1 起，`nums[0]` 不动；若从 0 起会变成 `nums[0] += nums[-1]`，把末元素错误地加进首元素。

## 复杂度
时间 O(n)：一次遍历，n 为 `len(nums)`。
空间 O(1)：原地改写，除返回值外没开额外数组。

## 易错点
- 输入 `nums = [1]`（长度 1）→ 若循环写成 `range(len(nums))` 且访问 `nums[i-1]`，i=0 时取到 `nums[-1]` 即自身，结果翻倍成 `[2]` → 正确做法是 `range(1, len(nums))`，单元素直接返回原数组。
- 输入含负数如 `nums = [3,-1,2]` → 若误以为动态和单调递增、用「当前和小于前一项就报错」之类的判断，会误判 → 动态和允许下降，正确输出是 `[3,2,4]`，只需无条件累加，不做任何大小比较。

## 如果面试官追问
问：不允许修改原数组怎么办？
答：新建 `res = [0]*len(nums)`，`res[0] = nums[0]`，之后 `res[i] = res[i-1] + nums[i]`，空间升到 O(n)。
