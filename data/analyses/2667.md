## 一句话思路
用闭包返回一个忽略入参、恒定返回 `"Hello World"` 的内层函数，因为返回值只由字面量决定。

## 怎么做
1. 外层函数 `createHelloWorld` 只负责「造」函数，不读 `args`。
2. 内层函数用 `*args` 接收任意个位置参数，保证 `f({}, None, 42)` 这种调用不报 `TypeError`。
3. 内层函数体只有一句 `return "Hello World"`，不引用任何外部变量。
4. 外层 `return` 内层函数本身（不加括号），交出去的是函数对象而非调用结果。

以示例 2 为例：调用 `f({}, None, 42)` 时，内层形参 `args` 绑定为 `({}, None, 42)`，长度 3，但函数体不读它，直接返回 `"Hello World"`。

```python
def createHelloWorld():
    def inner(*args):
        return "Hello World"
    return inner

f = createHelloWorld()
print(f({}, None, 42))   # Hello World
print(f())               # Hello World
```

关键差别在 `return inner` 与 `return inner()`：前者交出函数，后者在创建时就执行并交出字符串，之后 `f()` 会报 `'str' object is not callable`。

## 复杂度
时间 O(1)：每次调用只做一次字符串返回，与 `args` 长度无关。
空间 O(1)：只多一个闭包对象，不复制 `args`。

## 易错点
- 写成 `def inner(args)` 而非 `*args` → 传 `f({}, None, 42)` 时抛 `TypeError: inner() takes 1 positional argument but 3 were given` → 用 `*args` 或 `*_` 吞掉全部参数。
- 写成 `return inner()` → `f = createHelloWorld()` 得到的是字符串 `"Hello World"`，再调 `f()` 报 `'str' object is not callable` → 返回函数对象本身，括号留给调用方。

## 如果面试官追问
问：若要求返回的函数能记住首次调用时的参数并回显？
答：把 `*args` 存进闭包变量（如 `first = args`），内层首次调用时赋值、之后返回它，注意用 `nonlocal` 声明。
