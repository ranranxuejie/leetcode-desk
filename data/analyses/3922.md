## 一句话思路
连贯串只有「全 0 前缀 + 全 1 后缀」或「全 1 前缀 + 全 0 后缀」两种形态，枚举分界点取最小翻转数。

## 怎么做
1. 先证形态：若存在 `0…0 1…1 0…0` 这种「0 夹 1」结构，中间的 1 与右侧的 0 就构成 `110` 子序列；对称地「1 夹 0」会构成 `011`。所以连贯串至多一次 0/1 切换。
2. 于是答案 = min(切成 `0^a 1^b` 的代价, 切成 `1^a 0^b` 的代价)，a 从 0 到 n 枚举。
3. 用前缀和 `pre[i]` = s[:i] 中 `'1'` 的个数，则 `0^a 1^b` 的代价 = (前 a 位里的 1 全翻成 0) + (后 n-a 位里的 0 全翻成 1) = `pre[a] + ((n-a) - (pre[n]-pre[a]))`。
4. 对 `1^a 0^b` 同理，代价 = `(a - pre[a]) + (pre[n]-pre[a])`，两者取 min。

以 s = "1010" 为例，n=4，pre = [0,1,1,2,2]。a=1 时第一种代价 = `pre[1] + (3 - (2-1))` = 1+2 = 3；第二种代价 = `(1-1) + (2-1)` = 1，正好对应示例翻 s[0] 得 "0010"。

```python
n = len(s)
pre = [0] * (n + 1)
for i, ch in enumerate(s):
    pre[i + 1] = pre[i] + (ch == '1')
ans = n
for a in range(n + 1):
    ones_right = pre[n] - pre[a]
    cost01 = pre[a] + (n - a - ones_right)   # 0^a 1^b
    cost10 = (a - pre[a]) + ones_right       # 1^a 0^b
    ans = min(ans, cost01, cost10)
```

## 复杂度
时间 O(n)：一次前缀和 + 一次枚举分界点，n 为 len(s)。
空间 O(n)：pre 数组长度 n+1；若边扫边维护左侧 1 的个数可降到 O(1)。

## 易错点
- 分界点 a 必须取到 0 和 n：s = "1000" 的最优是 a=1 的 `1^1 0^3`，代价 0；若循环写 `range(1, n)` 会漏掉 a=n 的全 0 串，对 "1111" 返回 1 而非 0。
- 把「子序列」当成「子串」：s = "1010" 里 `110` 不是连续子串，但取下标 0,2,3 就是子序列，所以答案不是 0；判断时必须按子序列理解，不能只查相邻三位。

## 如果面试官追问
要求输出具体翻转方案怎么办？答：记录取到 min 的那个 a 和形态，前 a 位按目标字符逐位比对翻转，后 n-a 位同理，O(n) 输出。
