## 一句话思路
用快速选择把 arr 划分到「前 k 小都在左侧」，只递归含第 k 位的那一半，平均 O(n)。

## 怎么做
1. 选 `arr[lo]` 作 pivot，用双指针把小于 pivot 的换到左边，返回 pivot 最终落点 `p`。
2. 若 `p == k`，左侧 `arr[:k]` 就是答案，直接返回。
3. 若 `p > k`，只对 `[lo, p-1]` 继续划分；若 `p < k`，只对 `[p+1, hi]` 继续。
4. 循环到 `p == k` 为止，返回 `arr[:k]`。

以 `arr = [1,3,5,7,2,4,6,8], k = 4` 为例：第一轮 pivot=1，`p=0`，因 `p < k` 转去划分 `[1,7]`；第二轮 pivot=3，小于 3 的只有 2，`p=1`，仍 `p < k`；继续划分 `[2,7]`，pivot=5 时 `p=3`，再划分 `[3,7]`，pivot=7 时 `p=4 == k`，此时 `arr[:4]` 已是 `[1,2,3,4]`。

```python
def partition(a, lo, hi):
    pivot, i = a[lo], lo
    for j in range(lo + 1, hi + 1):
        if a[j] < pivot:
            i += 1
            a[i], a[j] = a[j], a[i]
    a[lo], a[i] = a[i], a[lo]
    return i

lo, hi = 0, len(arr) - 1
while lo < hi:
    p = partition(arr, lo, hi)
    if p == k: break
    if p < k: lo = p + 1
    else: hi = p - 1
return arr[:k]
```

注意 `k == 0` 时循环不进入，`arr[:0]` 返回空列表，正好符合要求。

## 复杂度
时间：平均 O(n)，每轮只处理一半，n 由数组长度贡献，无 log n 项。
空间：O(1) 额外（原地交换），递归改写成循环后无栈开销。

## 易错点
- `arr` 全为相同元素（如 `[2,2,2,2], k=2`）→ 用 `a[j] < pivot` 严格小于时，pivot 落在 `lo`，每轮只缩一格，退化成 O(n²) → 正确做法是三路划分（`<`、`==`、`>` 分三段），或随机选 pivot 打散。
- `k == len(arr)` → 若循环条件写成 `while lo <= hi` 且 `p == k` 永不成立（p 最大为 `len-1`），会越界访问 `arr[hi+1]` → 正确做法是循环条件用 `lo < hi`，并在 `k == len(arr)` 时直接返回整个 `arr`。

## 如果面试官追问
问：数据是流式的、k 很小怎么办？
答：改用大小为 k 的最大堆，O(n log k) 时间、O(k) 空间，且只需单遍扫描。
