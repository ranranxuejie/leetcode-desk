## 一句话思路
在 `[0, x]` 上二分答案 `mid`，找最大的满足 `mid * mid <= x` 的 `mid`，因为平方函数单调。

## 怎么做
1. 把搜索区间设为 `lo, hi = 0, x`，答案一定落在这个闭区间里。
2. 每轮取 `mid = (lo + hi + 1) // 2`，**上取整**，否则 `lo = mid` 会死循环。
3. 若 `mid * mid <= x` 则 `lo = mid`，否则 `hi = mid - 1`。
4. 循环结束 `lo == hi`，返回 `lo`。

以 `x = 8` 为例：初始 `lo=0, hi=8`；`mid=(0+8+1)//2=4`，`16 > 8` 所以 `hi=3`；`mid=(0+3+1)//2=2`，`4 <= 8` 所以 `lo=2`；`mid=(2+3+1)//2=3`，`9 > 8` 所以 `hi=2`；此时 `lo==hi==2`，返回 `2`。关键中间值是第一次的 `mid=4` 被 `16 > 8` 淘汰，区间直接砍到 `[0,3]`。

```python
lo, hi = 0, x
while lo < hi:
    mid = (lo + hi + 1) // 2
    if mid * mid <= x:
        lo = mid
    else:
        hi = mid - 1
return lo
```

`x = 0` 时 `lo == hi == 0`，循环不进，直接返回 `0`，无需特判。

## 复杂度
时间：二分区间长度 `x`，每轮折半，共 `O(log x)` 次比较。
空间：只开 `lo/hi/mid` 三个整数，`O(1)`。

## 易错点
- `x = 1` 或 `x = 2` 时若用下取整 `mid = (lo + hi) // 2` 配 `lo = mid`，会卡在 `lo=0, hi=1, mid=0` 无限循环 → 必须上取整 `(lo + hi + 1) // 2`，或改用 `lo = mid + 1` 的写法。
- `x = 2**31 - 1` 时若把 `hi` 设成 `x // 2` 想省范围，`x = 1` 会得到 `hi = 0` 直接返回 `0`（正确答案是 `1`）→ 老老实实 `hi = x`，Python 大整数不会溢出，`mid * mid` 可以放心算。

## 如果面试官追问
问：要求返回浮点平方根、精度 `1e-6` 怎么办？
答：区间改成 `[0, x]` 浮点，循环 `while hi - lo > 1e-7`，比较 `mid * mid <= x` 后 `lo = mid` 或 `hi = mid`，返回 `lo`。
