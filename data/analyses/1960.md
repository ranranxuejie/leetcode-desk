## 一句话思路
马拉车求出每个中心的最长奇回文半径，再用前后缀最大值数组拼出「左段最长」与「右段最长」，枚举分割点取乘积最大。

## 怎么做
1. 对 `s` 跑马拉车，得到 `d1[i]` = 以 `i` 为中心的最长奇回文半径（长度 = `2*d1[i]-1`）。
2. 把每个回文的长度摊到它的右端点：`right[i]` 记录「右端点 ≤ i 的最长奇回文长度」，从左往右取 `max`。
3. 同理从右往左得 `left[i]` = 「左端点 ≥ i 的最长奇回文长度」。
4. 枚举分割点 `i`（左段结束于 `i`，右段起于 `i+1`），答案 = `max(right[i] * left[i+1])`。

以 `s = "ababbb"` 为例：`d1 = [1,2,1,1,2,1]`，中心 1 给出 `"aba"` 长 3（右端点 2），中心 4 给出 `"bbb"` 长 3（右端点 5）。于是 `right = [1,1,3,3,3,3]`，`left = [3,3,3,3,3,1]`。分割点 `i=2` 时 `right[2]=3`、`left[3]=3`，乘积 9。

```python
n = len(s)
d1 = [0] * n
l, r = 0, -1
for i in range(n):
    k = 1 if i > r else min(d1[l + r - i], r - i + 1)
    while i - k >= 0 and i + k < n and s[i - k] == s[i + k]:
        k += 1
    d1[i] = k
    if i + k - 1 > r:
        l, r = i - k + 1, i + k - 1

right = [0] * n
for i in range(n):
    right[i + d1[i] - 1] = max(right[i + d1[i] - 1], 2 * d1[i] - 1)
for i in range(1, n):
    right[i] = max(right[i], right[i - 1])
```

`left` 数组对称构造：把 `d1[i]` 的长度写到左端点 `i - d1[i] + 1`，再从右往左取 `max`。

## 复杂度
时间 O(n)：马拉车线性，两遍前缀/后缀 max 各 O(n)，枚举分割点 O(n)。
空间 O(n)：`d1`、`right`、`left` 三个长度 n 的数组。

## 易错点
- 只记「以 i 结尾的最长回文」而漏掉更早结束但更长的回文：如 `"abaccc"`，中心 1 的 `"aba"` 结束于 2，若只在 `right[2]` 写 3 而 `right[3..]` 不继承，分割点 3 会取到 1 而非 3。正确做法是 `right[i] = max(right[i], right[i-1])` 逐位继承。
- 分割点写成 `right[i] * left[i]`：两段会共用下标 `i`，违反 `j < k`。`"ababbb"` 在 `i=2` 会算出 `3*3=9` 看似对，但 `"aaa"` 这类单串会被重复计数。必须用 `right[i] * left[i+1]`，保证左段结束严格小于右段开始。

## 如果面试官追问
问：若允许偶数长度回文怎么办？
答：改用 `d2`（偶回文半径），长度 `2*d2[i]`，前缀后缀 max 逻辑不变，分割点仍取 `i` 与 `i+1`。
