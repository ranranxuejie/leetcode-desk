## 一句话思路
用 `dp[mask][i]` 记录已选集合 `mask` 且以 `nums[i]` 结尾的合法排列数，按位掩码逐层转移。

## 怎么做
1. 预处理 `ok[i][j]`：`nums[i] % nums[j] == 0 or nums[j] % nums[i] == 0`，避免转移时反复取模。
2. 初始化 `dp[1 << i][i] = 1`，即每个单元素排列都合法。
3. 枚举 `mask`，对每个结尾 `i`，把 `nums[j]`（`j` 不在 `mask` 中且 `ok[i][j]`）接到后面，累加到 `dp[mask | (1 << j)][j]`。
4. 答案是 `sum(dp[(1 << n) - 1][i]) % (10**9 + 7)`。

以 `nums = [2,3,6]` 为例，`ok` 中 `2-6`、`3-6` 为真，`2-3` 为假。`mask = 0b011`（选了 2、3）时，结尾 `i=0`（值 2）无法接 3，`dp[0b011][0]` 只能来自 `dp[0b001][0]` 接 3 的失败路径，实际为 0；而 `mask = 0b101`（2、6）结尾 6 可接 3，得到 `dp[0b111][1] = 1`，对应 `[2,6,3]`。

```python
MOD = 10**9 + 7
n = len(nums)
ok = [[nums[i] % nums[j] == 0 or nums[j] % nums[i] == 0
       for j in range(n)] for i in range(n)]
dp = [[0] * n for _ in range(1 << n)]
for i in range(n):
    dp[1 << i][i] = 1
for mask in range(1 << n):
    for i in range(n):
        if not dp[mask][i]:
            continue
        for j in range(n):
            if not (mask >> j) & 1 and ok[i][j]:
                dp[mask | (1 << j)][j] = (dp[mask | (1 << j)][j] + dp[mask][i]) % MOD
return sum(dp[(1 << n) - 1]) % MOD
```

## 复杂度
时间：`O(2^n * n^2)`，`n` 来自结尾枚举，`n` 来自下一个元素枚举。
空间：`O(2^n * n)` 的 `dp` 表，`ok` 额外 `O(n^2)`。

## 易错点
- `nums = [1,4,3]`：若只判 `nums[i] % nums[j] == 0` 单向，会漏掉 `1-4`（4%1 才为 0）和 `1-3`，答案错成 0；必须双向取或。
- `nums = [2,3,6]`：若在 `mask` 已含 `j` 时仍转移，会把 `[2,6,3]` 重复计数成 4；转移前必须检查 `not (mask >> j) & 1`。

## 如果面试官追问
若 `n` 放宽到 20 且要求输出所有方案，怎么做？答：`dp` 只存计数会丢路径，需在转移时记录前驱或回溯枚举，复杂度升到方案数级别。
