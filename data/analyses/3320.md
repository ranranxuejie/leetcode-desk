## 一句话思路
按回合推进，用「Bob 当前出招 + 分差」做状态 DP，分差偏移后存数组，滚动更新。

## 怎么做
1. 定义 `dp[last][d]`：处理完前 i 回合、Bob 第 i 回合出 `last`、Bob 得分减 Alice 得分为 `d` 的序列数；`d` 范围 `[-n, n]`，整体加 `n` 偏移成下标。
2. 每回合枚举 Bob 的三种出招 `b`，跳过 `b == last`，用 `score(b, s[i])` 算出本回合分差增量 `delta`（Bob 赢 +1、平 0、输 -1），累加到 `ndp[b][d+delta]`。
3. 最后把 `dp[b][d]` 中 `d > 0`（即下标 `> n`）的全部加起来取模。

以 `s = "FFF"` 为例：第 1 回合 Bob 出 `W` 赢 Alice 的 `F`，`delta = +1`，`dp['W'][n+1] = 1`；第 2 回合只能出 `F` 或 `E`，出 `F` 对 `F` 平 `delta = 0`，出 `E` 输 `delta = -1`；第 3 回合再各展开一次，最终 `d > 0` 的只有 `WFW`、`FWF`、`WEW` 三条，答案 3。

```python
MOD = 10**9 + 7
n = len(s)
dp = [[0] * (2 * n + 1) for _ in range(3)]
for b in range(3):
    dp[b][n + delta(b, s[0])] = 1
for i in range(1, n):
    ndp = [[0] * (2 * n + 1) for _ in range(3)]
    for last in range(3):
        for d in range(2 * n + 1):
            v = dp[last][d]
            if not v:
                continue
            for b in range(3):
                if b == last:
                    continue
                nd = d + delta(b, s[i])
                if 0 <= nd <= 2 * n:
                    ndp[b][nd] = (ndp[b][nd] + v) % MOD
    dp = ndp
ans = sum(dp[b][n + 1:] for b in range(3)) % MOD
```

`delta(b, a)`：`b` 赢 `a` 返回 1，平返回 0，输返回 -1；胜负关系是 `F > E > W > F`。

## 复杂度
时间：`O(n * 3 * 3 * 2n) = O(n^2)`，n 来自回合数与分差维度。
空间：`O(3 * 2n) = O(n)`，只开两层滚动数组，无额外结构。

## 易错点
- `s = "FFF"` 若把「Bob 不能连续相同」漏判，会把 `FFF`、`WWW` 这类非法序列算进去，答案偏大；正确做法是在内层循环里 `if b == last: continue`，且 `last` 必须是上一回合真实出招而非 Alice 的。
- 分差下标越界：`d` 从 `-n` 到 `n`，若不加 `n` 偏移直接用负下标，Python 会静默取到数组尾部，结果错得毫无报错；正确做法是统一用 `n + delta` 并检查 `0 <= nd <= 2*n`。

## 如果面试官追问
问：n 放大到 10^5 怎么办？答：分差维度压不掉，需换生成函数或矩阵快速幂按回合块转移，单步 O(1) 但状态数仍随 n 增长，实际要利用三种出招的对称性合并状态。
