## 一句话思路
按左子树节点数 k 枚举（k 取奇数），递归生成左右子树再笛卡尔积拼接，用字典缓存 n 的结果。

## 怎么做
1. n 为偶数直接返回 `[]`，因为真二叉树节点数必为奇数。
2. 记忆化字典 `memo`，`memo[1] = [TreeNode(0)]` 作为递归基。
3. 对给定 n，令 k 从 1 到 n-2 步长 2，左子树 k 个节点、右子树 n-1-k 个节点，两者都必为奇数。
4. 取 `memo[k]` 与 `memo[n-1-k]` 做双重循环，每个组合新建根 `TreeNode(0)` 挂上左右子树。

以 n=7 为例，k 取 1、3、5：k=1 时左子树只有单节点，右子树是 n-1-k=5 的全部 2 种形态，贡献 2 棵；k=3 时左右各 1 种，贡献 1 棵；k=5 时对称，贡献 2 棵，合计 5 棵，与示例一致。

```python
memo = {1: [TreeNode(0)]}
def build(n):
    if n in memo:
        return memo[n]
    res = []
    for k in range(1, n - 1, 2):
        for l in build(k):
            for r in build(n - 1 - k):
                res.append(TreeNode(0, l, r))
    memo[n] = res
    return res
return build(n) if n % 2 == 1 else []
```

注意 `TreeNode(0, l, r)` 每次新建根，不能复用 `l` 或 `r` 当根，否则同一棵树会被多个父节点共享，输出结构错乱。

## 复杂度
时间：O(C(n/2))，即第 n/2 个卡特兰数，每棵输出树都要实际构造一次。
空间：O(C(n/2)) 存所有树，递归栈深度 O(log n)（每次 n 减至少 2 且分治）。

## 易错点
- 输入 n=2 或任意偶数 → 若不加 `n % 2` 判断，`range(1, 1, 2)` 为空返回 `[]` 看似对，但 n=2 时 `build(2)` 会先查 memo 未命中再空循环，逻辑侥幸正确；真正翻车在 n=4 时若误把 k 步长写成 1，会生成含单子节点的非法树。正确做法是 k 严格从 1 起、步长 2。
- 输入 n=7 → 若在双重循环里写 `res.append(TreeNode(0, l, r))` 但把 `memo[n] = res` 放在 `return` 之后，递归重复计算导致同一形态被多次构造，列表里出现重复树。正确做法是先赋值 `memo[n]` 再返回。

## 如果面试官追问
问：n 上限提到 25 会怎样？
答：卡特兰数 C(12)=208012，输出规模本身爆炸，瓶颈在必须构造全部树，记忆化已是最优，只能靠剪枝或改输出计数。
