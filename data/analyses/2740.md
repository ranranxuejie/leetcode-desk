## 一句话思路
排序后取相邻元素差的最小值，因为最优切分必然发生在排序序列的某个相邻缝隙上。

## 怎么做
1. 对 `nums` 升序排序，得到 `s`。
2. 遍历 `i` 从 1 到 `len(s)-1`，计算 `s[i] - s[i-1]`。
3. 返回这些差值中的最小值。

以 `nums = [1,3,2,4]` 为例：排序后 `s = [1,2,3,4]`，相邻差为 `1,1,1`，最小值为 `1`。切分点取 `i=2` 时，`nums1 = [1,2]`（max=2），`nums2 = [3,4]`（min=3），分区值 `|2-3| = 1`。

```python
s = sorted(nums)
ans = s[1] - s[0]
for i in range(2, len(s)):
    ans = min(ans, s[i] - s[i-1])
return ans
```

关键论证：任意分区方案中，`max(nums1)` 和 `min(nums2)` 在排序序列里必然分属两个不同位置，且 `max(nums1) < min(nums2)` 或反之。若 `max(nums1) < min(nums2)`，则两者之间至少隔着一个排序缝隙，差值不小于该缝隙的相邻差；若 `max(nums1) > min(nums2)`，差值只会更大。因此最小值一定来自某个相邻差。

## 复杂度
时间：排序贡献 O(n log n)，遍历贡献 O(n)。
空间：排序额外 O(n)（Python `sorted` 返回新列表），不计输入本身。

## 易错点
- 输入 `nums = [100,1,10]` → 若误以为要枚举所有子集划分，会写成指数级或 O(n²) 的暴力 → 正确做法是排序后只扫相邻差，答案 `9` 来自 `10-1`。
- 输入 `nums = [1,2]` → 若循环从 `i=2` 开始且没初始化 `ans`，会漏掉唯一一对相邻差 → 正确做法是先把 `s[1]-s[0]` 赋给 `ans` 再进入循环。

## 如果面试官追问
要求输出具体划分方案怎么办？
答：记录取到最小差时的下标 `i`，`nums1 = s[:i]`，`nums2 = s[i:]`，直接切片返回即可。
