## 一句话思路
排序后取下标 0、2、4… 的元素求和：把相邻两数配对，每对的最小值就是较小的那个，这样每个「牺牲品」只牺牲掉紧邻它的一个数。

## 怎么做
1. 对 `nums` 升序排序。
2. 取所有偶数下标 `nums[0], nums[2], ..., nums[2n-2]` 累加。
3. 返回累加值。

以 `nums = [1,4,3,2]` 为例：排序得 `[1,2,3,4]`，取下标 0 和 2，即 `nums[0]=1`、`nums[2]=3`，和 `1+3=4`。若配成 `(1,4),(2,3)`，则 `min` 为 `1+2=3`，比 4 小——因为 2 被 3「吃掉」了，而 3 本可以当某一对的较小值。

```python
def arrayPairSum(nums):
    nums.sort()
    total = 0
    for i in range(0, len(nums), 2):
        total += nums[i]
    return total
```

关键点：排序后相邻配对，`nums[2k]` 与 `nums[2k+1]` 一组，`min` 必为 `nums[2k]`。任何跨位配对都会让某个较大的数去当 `min`，同时把 `nums[2k]` 这种「本可贡献的值」浪费掉，所以相邻配对最优。

## 复杂度
时间：排序 `O(n log n)`，n 为数组长度（2n 个元素），遍历 `O(n)`。
空间：排序额外 `O(log n)` 栈空间（Python Timsort），不计返回值。

## 易错点
- 输入含负数如 `nums = [-1,-2,-3,-4]` → 若误以为「取奇数下标」或按绝对值排序，会得到错误结果；正确做法是直接升序排序取偶数下标，得 `-4 + -2 = -6`。
- 输入有重复值如 `nums = [6,2,6,5,1,2]` → 若用集合去重再配对，长度变成 4 而非 6，配对数错、和也错；正确做法是保留全部元素排序，取 `nums[0]+nums[2]+nums[4] = 1+2+6 = 9`。

## 如果面试官追问
问：要求输出具体配对方案怎么办？
答：排序后按 `(nums[2k], nums[2k+1])` 依次输出即可，和不变。
