## 一句话思路
用差分数组在年份轴上做「出生 +1、死亡后一年 -1」，前缀和还原每年人数，取最大值的最早年份。

## 怎么做
1. 开长度 102 的差分数组 `diff`，下标 `y - 1900` 对应年份 y，覆盖 1900..2001（2001 是死亡后一年的哨兵位）。
2. 对每个人：`diff[birth[i] - 1900] += 1`，`diff[death[i] - 1900 + 1] -= 1`。
3. 从 1900 扫到 2000，累加 `cur += diff[y - 1900]`，用 `cur > best` 严格大于来更新，保证并列时保留最早年份。

以官方示例为例，`birth = [1900, 1901, 1950]`、`death = [1948, 1951, 2000]`：处理完三个人后 `diff[0] = 1`、`diff[1] = 1`、`diff[49] = -1`、`diff[50] = 1`、`diff[52] = -1`、`diff[101] = -1`。前缀和扫到 1900 时 `cur = 1`，1901 时 `cur = 2` 刷新 `best = 2, ans = 1901`，1950 时 `cur` 回落到 1，之后再没超过 2，最终返回 1901。

```python
diff = [0] * 102
for b, d in zip(birth, death):
    diff[b - 1900] += 1
    diff[d - 1900 + 1] -= 1

cur = best = 0
ans = 1900
for y in range(1900, 2001):
    cur += diff[y - 1900]
    if cur > best:
        best, ans = cur, y
```

关键在 `d - 1900 + 1` 这个 `+1`：死亡当年仍算生存，减一必须落在下一年。

## 复杂度
时间 O(n + 101)：n 次差分更新加固定 101 年扫描。
空间 O(1)：只开了长度 102 的 `diff`，与 n 无关。

## 易错点
- 死亡年写成 `diff[d - 1900] -= 1` → 示例中 1900 年出生、1948 年死亡的人会在 1948 年被提前剔除，1901 年计数仍是 2 但 1948 年附近会少算 → 必须 `+1` 落到死亡后一年。
- 更新条件写成 `cur >= best` → 示例里 1951 年 `cur` 回到 1，若用 `>=` 且后面出现并列最大值，会返回较晚年份 → 用严格 `>`，只在首次达到最大值时记录。

## 如果面试官追问
若年份范围放大到 1 到 10^9 怎么办？答：改用「出生年 +1、死亡年 +1 记 -1」的事件排序，按年份排序后扫描，时间 O(n log n)、空间 O(n)。
