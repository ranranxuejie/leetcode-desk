## 一句话思路
把每个串的所有子串按「长度升序、字典序升序」枚举，第一个只属于它自己的就是答案；用哈希表记录每个子串出现在哪些下标里。

## 怎么做
1. 遍历 `arr`，对每个 `arr[i]` 枚举所有 `arr[i][l:r]`，把子串作为 key 存进 `owner` 字典，value 是出现过的下标集合。
2. 对每个 `i`，再枚举一遍它的子串，按 `(长度, 字典序)` 排序后取第一个 `owner[s] == {i}` 的。
3. 找不到就填 `""`。

以 `arr = ["cab","ad","bad","c"]` 为例，`"ab"` 出现在 `"cab"`（下标 0）和 `"bad"`（下标 2），所以 `owner["ab"] = {0, 2}`，对下标 0 不合法；而 `"ca"` 只在 `"cab"` 里，`owner["ca"] = {0}`，合法。下标 0 的候选是 `"ca"` 和 `"ab"`，长度都是 2，字典序 `"ab" < "ca"`，所以答案是 `"ab"`。

```python
from collections import defaultdict

owner = defaultdict(set)
for i, s in enumerate(arr):
    for l in range(len(s)):
        for r in range(l + 1, len(s) + 1):
            owner[s[l:r]].add(i)

ans = []
for i, s in enumerate(arr):
    cand = [s[l:r] for l in range(len(s)) for r in range(l + 1, len(s) + 1)
            if owner[s[l:r]] == {i}]
    ans.append(min(cand, key=lambda t: (len(t), t)) if cand else "")
```

注意 `min` 的 key 是 `(len(t), t)`，先比长度再比字典序，正好对应题目要求。

## 复杂度
时间：每个串长度 ≤20，子串数 O(L²)，总 O(n·L³) 来自排序/比较，L=20 可忽略。
空间：`owner` 存 O(n·L²) 个不同子串，每个 value 是下标集合。

## 易错点
- 输入 `["abc","bcd","abcd"]` 时，若只检查「子串是否出现在别的串里」而漏掉同一串内的重复出现，`"abc"` 的 `"a"` 会被误判为合法；正确做法是 `owner[s] == {i}` 严格判断集合只含自己。
- 输入 `["cab","ad","bad","c"]` 时，若按枚举顺序取第一个合法子串而不排序，可能返回 `"ca"` 而不是 `"ab"`；正确做法是按 `(len, 字典序)` 取最小。

## 如果面试官追问
问：如果 `arr[i]` 长度放宽到 1000 怎么办？
答：O(L²) 子串枚举会爆，改用后缀自动机或对每个串建 Trie 统计出现次数，按长度递增 BFS 找第一个计数为 1 的节点。
