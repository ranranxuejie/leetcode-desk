## 一句话思路
一次遍历，用哈希表统计每个 `nums[i+1]` 在 `nums[i] == key` 时出现的次数，取计数最大者。

## 怎么做
1. 建空字典 `cnt`，遍历 `i` 从 `0` 到 `len(nums) - 2`。
2. 若 `nums[i] == key`，则 `cnt[nums[i+1]] += 1`。
3. 遍历结束后返回 `max(cnt, key=cnt.get)`。

以 `nums = [1,100,200,1,100], key = 1` 为例：`i=0` 时 `nums[0]==1`，`cnt[100]=1`；`i=3` 时 `nums[3]==1`，`cnt[100]=2`；其余 `i` 的 `nums[i]` 是 100、200、100，都不等于 1，跳过。最终 `cnt = {100: 2}`，返回 100。

```python
cnt = {}
for i in range(len(nums) - 1):
    if nums[i] == key:
        nxt = nums[i + 1]
        cnt[nxt] = cnt.get(nxt, 0) + 1
return max(cnt, key=cnt.get)
```

注意 `range(len(nums) - 1)` 而不是 `len(nums)`：最后一个下标 `n-1` 没有后继，若 `nums[n-1] == key` 却去读 `nums[n]` 会越界。示例 1 中 `nums[4] = 100`，不是 key，所以即使写错范围也碰巧不崩；但换成 `nums = [1, 2, 1], key = 1`，末尾的 1 就会触发 `IndexError`。

## 复杂度
时间 O(n)：一次遍历，每个下标最多做一次字典写入。
空间 O(k)：`cnt` 只存 key 后继出现的不同值，k ≤ n。

## 易错点
- 输入 `nums = [2,2,2,2,3], key = 2` → 若把 `nums[i] == key` 写成 `nums[i] != key` 或漏判，会把 2 的计数算成 0 → 正确做法是只在 `nums[i] == key` 时统计 `nums[i+1]`，得到 `cnt = {2: 3, 3: 1}`，返回 2。
- 输入 `nums = [1, 2, 1], key = 1` → 若循环写成 `range(len(nums))`，`i=2` 时读 `nums[3]` 抛 `IndexError` → 正确做法是上界取 `len(nums) - 1`，只处理有后继的下标。

## 如果面试官追问
若要求返回所有并列最多的 target 而非唯一答案？答：把 `max` 换成先求最大计数，再收集 `cnt` 中计数等于该值的所有键。
