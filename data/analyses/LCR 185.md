## 一句话思路
用滚动 DP 求「和为 s 的方案数」，再除以 6^num 转成概率；因为骰子独立同分布，方案数可逐颗累加。

## 怎么做
1. 设 `dp[s]` 为当前已掷骰子得到总和 s 的方案数，初始 `dp[0] = 1`。
2. 每加一颗骰子，新状态 `ndp[s] = sum(dp[s-k] for k in 1..6)`，即上一轮所有能一步到 s 的和。
3. 掷完 num 颗后，总和范围是 `[num, 6*num]`，共 `5*num+1` 个值，按顺序除以 `6**num`。
4. 用 `float` 除法输出，Python 的 `/` 直接得 float，无需额外转换。

以 num = 3 为例，掷完 2 颗时 `dp[2..12] = [1,2,3,4,5,6,5,4,3,2,1]`；再掷第 3 颗，`ndp[10] = dp[9]+dp[8]+...+dp[4] = 4+5+6+5+4+3 = 27`，除以 `6**3 = 216` 得 0.125，正是示例中第 9 个元素。

```python
dp = [0] * (6 * num + 1)
dp[0] = 1
for _ in range(num):
    ndp = [0] * (6 * num + 1)
    for s in range(1, 6 * num + 1):
        ndp[s] = sum(dp[s - k] for k in range(1, 7) if s - k >= 0)
    dp = ndp
total = 6 ** num
return [dp[s] / total for s in range(num, 6 * num + 1)]
```

## 复杂度
时间：O(num × 6num × 6) = O(num²)，num ≤ 11 时约 4000 次加法。
空间：O(6num)，只开 `dp` 和 `ndp` 两个长度 6num+1 的数组。

## 易错点
- 输出长度写成 `6*num` 而非 `5*num+1`：num=3 时会多出 3 个尾部 0，正确起点是 `num`、终点是 `6*num`，共 16 个元素。
- 用整数除法 `//` 或先乘后除的顺序搞反：`dp[s] // total` 在 num=3 时把 1/216 截成 0；必须写 `dp[s] / total` 让 Python 走真除法。

## 如果面试官追问
问：num 放大到 10^5 怎么办？
答：DP 不可行，改用正态近似或 FFT 卷积求分布，再按需截断区间。
