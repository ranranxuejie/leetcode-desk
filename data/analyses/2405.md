## 一句话思路
从左到右扫描，当前字符已在当前段出现过就立刻切段并重置集合——因为任何包含重复字符的前缀都必须在此处断开。

## 怎么做
1. 维护一个集合 `seen` 表示当前子串已用字符，计数器 `ans` 从 1 开始。
2. 遍历 `s` 的每个字符 `c`：若 `c in seen`，则 `ans += 1` 并清空 `seen`。
3. 把 `c` 加入 `seen`，继续下一个字符。

以 `s = "abacaba"` 为例：扫到第 3 个字符 `a` 时，`seen = {'a','b'}` 已含 `a`，于是 `ans` 从 1 变 2、`seen` 清空后加入 `a`；继续扫到第二个 `b`（下标 5）时 `seen = {'a','c'}` 不含 `b`，不切；扫到下标 6 的 `a` 时 `seen = {'a','b','c'}` 含 `a`，`ans` 变 3；最后一个 `a` 又触发一次，`ans` 变 4，与输出一致。

```python
seen = set()
ans = 1
for c in s:
    if c in seen:
        ans += 1
        seen.clear()
    seen.add(c)
return ans
```

关键点：切段后**当前字符 `c` 必须放进新段**，不能丢掉；`ans` 初值为 1 是因为至少有一段。

## 复杂度
时间 O(n)：每个字符最多被 `in` 检查和 `add` 各一次，集合操作 O(1)。
空间 O(1)：`seen` 最多存 26 个小写字母，与 n 无关。

## 易错点
- 输入 `s = "ssssss"` → 若切段后忘记把当前 `s` 放回新集合，会得到 1 而不是 6 → 正确做法是 `clear()` 之后无条件 `seen.add(c)`。
- 输入 `s = "abacaba"` → 若把 `ans` 初值设为 0，或只在循环结束后才 +1，会少算一段得 3 → 正确做法是初值 1，且每次冲突时立即 +1，循环结束后不再补加。

## 如果面试官追问
问：若要求输出具体划分方案而非段数？答：把 `ans += 1` 处换成记录切点下标，最后按切点切片即可，时间空间不变。
