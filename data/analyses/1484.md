## 一句话思路
先按 `(sell_date, product)` 去重，再按日期聚合，用 `GROUP_CONCAT` 排序拼接产品名。

## 怎么做
1. 用 `DISTINCT sell_date, product` 去掉同一天重复出现的产品，比如 2020-06-02 的两行 Mask 只留一行。
2. 按 `sell_date` 分组，`COUNT(product)` 得到 `num_sold`。
3. 用 `GROUP_CONCAT(product ORDER BY product SEPARATOR ',')` 生成 `products`，`ORDER BY` 保证词典序。
4. 最后 `ORDER BY sell_date` 输出。

关键中间值：去重后 2020-05-30 剩 `Basketball, Headphone, T-Shirt` 三行，`COUNT` 得 3，`GROUP_CONCAT` 按字典序拼成 `Basketball,Headphone,T-shirt`。

```python
# 伪代码：SQL 逻辑映射到 Python
from collections import defaultdict

def categorize_products(rows):
    seen = set()
    for d, p in rows:
        seen.add((d, p))          # 去重
    groups = defaultdict(list)
    for d, p in seen:
        groups[d].append(p)
    return [
        (d, len(groups[d]), ",".join(sorted(groups[d])))
        for d in sorted(groups)
    ]
```

注意 `sorted` 是区分大小写的字典序，`T-Shirt` 排在 `Headphone` 之后、`Basketball` 之后，与示例一致。

## 复杂度
时间：O(n log n)，n 为去重后行数，排序贡献 log n。
空间：O(n)，`seen` 集合和 `groups` 字典各存一份去重结果。

## 易错点
- 不去重直接 `COUNT`：2020-06-02 的 Mask 出现两次 → `num_sold` 错成 2、`products` 变成 `Mask,Mask` → 必须先 `DISTINCT (sell_date, product)`。
- 拼接时不加 `ORDER BY`：2020-05-30 可能输出 `Headphone,Basketball,T-Shirt` → 必须显式 `ORDER BY product`，不能依赖插入顺序。

## 如果面试官追问
问：如果产品名含逗号怎么办？答：换分隔符或改用 JSON 数组聚合，避免歧义。
