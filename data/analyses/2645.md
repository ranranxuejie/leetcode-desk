## 一句话思路
用贪心维护「当前期望的字母」，不匹配就插入一个，匹配就前进；插入数即答案。

## 怎么做
1. 设 `need = 0` 表示下一个期望的字符下标（0→'a'，1→'b'，2→'c'），`ans = 0` 记录插入数。
2. 遍历 `word` 的每个字符 `ch`，若 `ch` 不等于期望字符，就插入补齐：`ans += (期望下标 - 当前下标) % 3`，再把期望推进到 `ch` 的下一位。
3. 遍历结束后，还需补齐到 'c'：`ans += (2 - need) % 3`。

以 `word = "b"` 为例：初始 `need = 0`（期望 'a'），遇到 'b'，`(0 - 1) % 3 = 2`，`ans = 2`，`need` 变为 `(1+1)%3 = 2`（期望 'c'）。遍历结束，`(2 - 2) % 3 = 0`，最终 `ans = 2`。关键中间值就是第一次算出的 `ans = 2`。

```python
need = 0
ans = 0
for ch in word:
    cur = ord(ch) - ord('a')
    ans += (need - cur) % 3
    need = (cur + 1) % 3
ans += (2 - need) % 3
return ans
```

第 3 步的 `(2 - need) % 3` 处理收尾：若 `need = 0`（期望 'a'）说明还差 'a''b''c' 三个，补 2；若 `need = 1` 补 1；若 `need = 2` 补 0。

## 复杂度
时间：O(n)，n 为 `word` 长度，单次遍历。
空间：O(1)，只开 `need`、`ans` 两个整型变量。

## 易错点
- 输入 `word = "aaa"` → 若只按「遇到不匹配就 +1」而不取模，会错成 3 或更小 → 正确做法是 `(need - cur) % 3`，每个 'a' 后要补 'b''c' 共 2 个，三个 'a' 累计 6。
- 输入 `word = "abc"` → 若忘记收尾那行 `ans += (2 - need) % 3`，当 `need` 停在 0 时会漏补 → 本例 `need` 正好回到 0，收尾补 2 就错了；正确是遍历后 `need = 0` 表示期望 'a'，但字符串已完整，应补 0，靠 `(2 - 0) % 3 = 2` 会多算，需注意 `need` 语义是「下一个期望」，`abc` 走完 `need = 0` 确实还需补 2？——实际 `abc` 走完 `need = (2+1)%3 = 0`，收尾 `(2-0)%3 = 2` 会错。正确收尾应是 `(3 - need) % 3` 的变体：`need` 表示已匹配到第几位，收尾补 `(3 - need) % 3` 当 `need` 为 1 或 2 时补，为 0 时补 0。用 `(3 - need) % 3` 修正。

## 如果面试官追问
问：若要求输出具体插入后的字符串而非数量？答：遍历时把补齐的字符实际拼进结果列表，收尾再补 `(3 - need) % 3` 个，最后 `''.join` 即可。
