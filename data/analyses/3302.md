## 一句话思路
预处理 `suf[i]`＝word2 从 i 起能在 word1 的 `[i..]` 后缀里匹配到的最远起点，再从左贪心取最小下标，把唯一的「改字符」额度留给最需要的位置。

## 怎么做
1. 倒序双指针算 `suf`：`suf[j]` 表示 word2[j:] 能在 word1 的哪个最小起点之后被完全匹配（不花额度）。
2. 正序贪心：对 word2 的第 j 个字符，从当前位置 `p` 起找第一个 `word1[p] == word2[j]` 的下标，能取就取，不花额度。
3. 若找不到，且额度未用，则取 `p` 本身（把 `word1[p]` 改成 `word2[j]`），花掉额度。
4. 取下标前必须验证：`suf[j+1]` 存在且 `> p`，否则这个选择会让后面无法完成，直接返回 `[]`。

以 `word1 = "bacdc", word2 = "abc"` 为例：`suf = [1, 2, 4]`。j=0 时 `p=0`，`word1[0]='b'≠'a'`，额度还在且 `suf[1]=2 > 0`，于是取 0？——不对，取 0 会花额度，但 `suf[1]=2>0` 成立，贪心会取 0 得到 `[0,2,4]`，而正确答案是 `[1,2,4]`。所以第 2 步要改成：先尝试「不花额度」的匹配，找不到才花额度；j=0 时 `word1[1]='a'` 匹配，取 1。

```python
n, m = len(word1), len(word2)
suf = [n] * (m + 1)
suf[m] = n
i = n - 1
for j in range(m - 1, -1, -1):
    while i >= 0 and word1[i] != word2[j]:
        i -= 1
    if i >= 0:
        suf[j] = i
        i -= 1
    else:
        suf[j] = -1
```

## 复杂度
时间 O(n + m)：`suf` 的倒序双指针各扫一遍，正序贪心再扫一遍。
空间 O(m)：只开了长度 m+1 的 `suf` 数组和答案数组。

## 易错点
- `word1 = "bacdc", word2 = "abc"`：若正序时先花额度取 0，会得到 `[0,2,4]`，比正确答案 `[1,2,4]` 字典序更大。正确做法是每步优先找不花额度的匹配，找不到才花。
- `word1 = "vbcca", word2 = "abc"`：j=0 时 `word1[0]='v'` 不匹配，若直接返回 `[]` 就错了；此时 `suf[1]=1 > 0` 成立，应花额度取 0。判断依据是 `suf[j+1] > p`，不是字符是否相等。

## 如果面试官追问
问：若允许改 k 个字符而非 1 个？
答：把「额度」换成计数 k，`suf` 改为 `suf[j][t]` 表示用 t 次修改能匹配的最小起点，贪心时按剩余额度查表即可。
