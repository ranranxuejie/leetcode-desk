## 一句话思路
在「(节点, 到达时间奇偶性)」状态上跑 BFS 求严格第二短时间，因为等灯只取决于到达时刻落在哪个 change 区间。

## 怎么做
1. 把状态扩成 `(u, parity)`，`parity = (t // change) % 2`，0 表示绿灯可走，1 表示红灯要等。
2. 用 BFS 按时间递增出队，每个状态记录最小和次小两个时间，第二次以严格更大值到达 `n` 时即为答案。
3. 转移时算等待：若 `parity == 1`，等到下一个 `change` 的整数倍再出发。

以示例 1 为例，`time=3, change=5`：从 1 出发 `t=0`，`0//5%2=0` 绿灯，走 1→4 得 `t=3`；`3//5%2=0` 仍绿灯，走 4→5 得 `t=6`，这是最短。第二短走 1→3→4，到 4 时 `t=6`，`6//5%2=1` 红灯，等到 `t=10` 才能走 4→5，得 `t=13`。

```python
from collections import deque
dist = [[-1, -1] for _ in range(n + 1)]  # 每个状态存最小/次小
dist[1][0] = 0
q = deque([(1, 0, 0)])  # (节点, 奇偶, 时间)
while q:
    u, p, t = q.popleft()
    for v in adj[u]:
        nt = t
        if (nt // change) % 2 == 1:          # 红灯，等到绿灯
            nt = (nt // change + 1) * change
        nt += time
        np = (nt // change) % 2
        if dist[v][0] == -1:
            dist[v][0] = nt
            q.append((v, np, nt))
        elif dist[v][1] == -1 and nt > dist[v][0]:
            dist[v][1] = nt
            q.append((v, np, nt))
```

## 复杂度
时间 O(n + m)，每条边最多被两个奇偶状态各松弛一次。
空间 O(n + m)，邻接表存 m 条边，`dist` 是 2n 的二维数组。

## 易错点
- 示例 2 的 `n=2, edges=[[1,2]], time=3, change=2`：若只按节点去重（不区分奇偶），1→2→1→2 会被判成重复路径而漏掉，答案错成 3 而非 11；必须用 `(u, parity)` 做状态键。
- 到达时刻恰好是 `change` 整数倍时（如示例 1 的 `t=10`），`10//5%2=0` 是绿灯，可以直接走；若写成 `t % change == 0` 就判红灯，会多等一个 `change`，示例 1 输出变成 18。

## 如果面试官追问
问：若要求输出第二短路径本身而非时间？
答：在 `dist` 里额外存前驱 `(prev_node, prev_parity)`，第二次更新 `n` 时沿前驱回溯即可。
