## 一句话思路
用有序字典维护互不相交的已跟踪区间，add/remove 时合并或切分相邻区间，query 只需检查覆盖它的那一个区间。

## 怎么做
1. 用 `sortedcontainers.SortedDict` 存 `{left: right}`，保证按左端点有序且区间两两不相交。
2. `addRange`：先删掉所有与 `[left, right)` 相交或相邻的区间，边删边把它们的端点并入 `left`/`right`，最后插入合并后的区间。
3. `removeRange`：找到左端点 ≤ `left` 的最后一个区间，若它覆盖 `left` 就切出左半段；再删掉所有被 `[left, right)` 覆盖的区间，若某区间右端 > `right` 就保留右半段。
4. `queryRange`：取左端点 ≤ `left` 的最后一个区间，判断它的 `right >= right` 即可。

以官方示例为例：`addRange(10,20)` 后字典是 `{10:20}`；`removeRange(14,16)` 时左端点 ≤14 的区间是 `{10:20}`，它覆盖 14，于是切成 `{10:14}`，再删掉被覆盖部分，右端 20>16 保留 `{16:20}`，最终 `{10:14, 16:20}`。此时 `queryRange(13,15)` 取到 `{10:14}`，`14 >= 15` 为假，返回 `False`。

```python
from sortedcontainers import SortedDict

def addRange(self, left, right):
    keys = list(self.d.keys())
    for k in keys:
        r = self.d[k]
        if r < left or k > right:
            continue
        left, right = min(left, k), max(right, r)
        del self.d[k]
    self.d[left] = right

def queryRange(self, left, right):
    i = self.d.bisect_right(left) - 1
    return i >= 0 and self.d.peekitem(i)[1] >= right
```

## 复杂度
时间：每次操作 O(k + log n)，k 是被合并/删除的区间数，均摊到全部 10^4 次调用为 O(n log n)。
空间：O(n)，字典里最多存 n 个互不相交区间，n 为调用次数。

## 易错点
1. `addRange` 只合并「相交」不合并「相邻」→ 输入 `addRange(10,20)` 后再 `addRange(20,30)`，会留下 `{10:20, 20:30}` 两个区间，虽不影响 query 正确性但区间数膨胀，后续 remove 切分时容易漏删；正确做法是判断条件写成 `r < left or k > right`（用严格不等号，相邻也算重叠）。
2. `removeRange` 忘记处理「区间跨越 right」→ 输入 `{10:20}` 执行 `removeRange(14,16)`，若只删整个区间会丢掉 `[16,20)`，导致 `queryRange(16,17)` 错返回 `False`；正确做法是切分后把 `{16:20}` 重新插回。

## 如果面试官追问
问：不允许用 `sortedcontainers` 怎么办？
答：手写线段树，坐标先离线离散化所有 left/right 端点，节点存「是否被完全覆盖」标记，add/remove 做区间赋值，query 查区间最小值是否为 1。
