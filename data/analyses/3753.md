## 一句话思路
数位 DP 按「前一位、当前位、是否已出现峰谷」转移，用 `f(x)` 求 `[1,x]` 的波动值总和，答案取 `f(num2)-f(num1-1)`。

## 怎么做
1. 把 `x` 拆成数位列表 `d`，从高位往低位做记忆化搜索，状态是 `(pos, prev, prev2, started, tight)`。
2. `prev2` 是上一位、`prev` 是当前位；当 `prev2` 存在且 `prev` 严格大于/小于两侧时，累加 1 并继续。
3. 用 `started` 跳过前导零，保证 `120` 的 `1` 不会被当成谷。
4. 对 `num1-1` 和 `num2` 各跑一次，相减。

以 `num2=130` 为例，走到 `pos=2` 时 `prev2=1, prev=3`，下一位 `0` 使 `3` 成为峰，贡献 1；`120` 同理在 `prev2=1, prev=2, cur=0` 时贡献 1。

```python
from functools import lru_cache

def f(x):
    if x < 0: return 0
    d = list(map(int, str(x)))
    @lru_cache(None)
    def dfs(pos, prev2, prev, started, tight):
        if pos == len(d):
            return 0
        hi = d[pos] if tight else 9
        res = 0
        for cur in range(hi + 1):
            nt = tight and cur == hi
            if not started and cur == 0:
                res += dfs(pos + 1, -1, -1, False, nt)
            else:
                add = 0
                if prev2 != -1 and ((prev2 < prev > cur) or (prev2 > prev < cur)):
                    add = 1
                res += add + dfs(pos + 1, prev, cur, True, nt)
        return res
    return dfs(0, -1, -1, False, True)

return f(num2) - f(num1 - 1)
```

## 复杂度
时间：`O(位数 × 10 × 10 × 2 × 2)`，位数最多 16，常数极小。
空间：`O(位数 × 10 × 10 × 2 × 2)` 的记忆化表，约几千项。

## 易错点
- 输入 `100`：若不用 `started` 跳过前导零，会把 `1` 当成谷，多算 1；正确做法是前导零阶段不更新 `prev2/prev`，也不判峰谷。
- 输入 `4848`：若只记 `prev` 不记 `prev2`，`8` 和 `4` 的峰谷无法判定；必须同时保留两位，且 `prev2 == -1` 时直接跳过判定。
