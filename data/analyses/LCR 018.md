## 一句话思路
左右双指针跳过非字母数字字符，逐对比较小写形式，任一对不等即返回 `False`。

## 怎么做
1. 初始化 `i = 0`、`j = len(s) - 1`，两指针向中间夹逼。
2. 每轮先让 `i` 跳过非字母数字字符（`while i < j and not s[i].isalnum(): i += 1`），`j` 同理。
3. 比较 `s[i].lower()` 与 `s[j].lower()`，不等直接返回 `False`，相等则 `i += 1; j -= 1`。
4. 循环结束（`i >= j`）返回 `True`。

以 `s = "A man, a plan, a canal: Panama"` 为例：`i=0` 指向 `'A'`，`j=29` 指向 `'a'`，`'a' == 'a'` 通过；随后 `i=1` 是空格，`i` 一路跳到 `2` 的 `'m'`，`j=28` 是 `'m'`，继续通过。真正决定结果的是中间那对 `'a'`（`i` 落在 `"canal"` 的 `a`，`j` 落在 `"canal"` 的 `a`），全部匹配才走到 `i >= j`。

```python
i, j = 0, len(s) - 1
while i < j:
    while i < j and not s[i].isalnum():
        i += 1
    while i < j and not s[j].isalnum():
        j -= 1
    if s[i].lower() != s[j].lower():
        return False
    i += 1
    j -= 1
return True
```

注意内层两个 `while` 都带 `i < j` 条件，否则 `s = ".,"` 这类全标点串会让 `i` 越过 `j` 后继续访问，或让 `i`、`j` 交叉后误比较。

## 复杂度
时间 O(n)：`i`、`j` 各只前进/后退，每个字符最多被访问常数次。
空间 O(1)：只开了 `i`、`j` 两个下标，没有额外字符串。

## 易错点
- 输入 `s = ".,"`（全非字母数字）→ 若内层 `while` 不写 `i < j`，`i` 会一路加到 `len(s)` 触发越界，或 `i`、`j` 交叉后拿 `s[i]` 和 `s[j]` 比较得到错误结果 → 正确做法是两个内层循环都加 `i < j` 守卫，循环退出后直接返回 `True`。
- 输入 `s = "0P"` → 若用 `s[i].lower() == s[j].lower()` 之外的方式（比如只判 `isalpha` 而漏掉数字，或忘记 `lower()`）→ `'0'` 与 `'P'` 会被判成回文或直接跳过数字 → 正确做法是用 `isalnum()` 判字符有效性、比较前统一 `.lower()`，`"0P"` 应返回 `False`。

## 如果面试官追问
追问：如果要求返回第一个不匹配的位置而不是布尔值？
答：在 `s[i].lower() != s[j].lower()` 分支里直接 `return (i, j)`，其余逻辑不变。
