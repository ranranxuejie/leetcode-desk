## 一句话思路
按值统计频次，每轮把当前所有频次非零的值升序各取一个，直到取空。

## 怎么做
1. 用 `Counter(nums)` 得到每个值的剩余次数，键集合就是「当前不同值」。
2. 每轮对剩余次数非零的键升序排序，依次各取一个追加到 `ans`，并把该键计数减 1。
3. 计数减到 0 的键从候选里剔除，重复直到 `ans` 长度等于 `len(nums)`。

以 `nums = [3,1,3,2,1,3]` 为例，初始 `cnt = {3:3, 1:2, 2:1}`。第 1 轮升序键 `[1,2,3]`，各取一个后 `cnt = {3:2, 1:1, 2:0}`，`ans = [1,2,3]`；第 2 轮只剩 `[1,3]`，`ans = [1,2,3,1,3]`；第 3 轮只剩 `[3]`，得 `[1,2,3,1,3,3]`。

```python
from collections import Counter

cnt = Counter(nums)
ans = []
while len(ans) < len(nums):
    for v in sorted(k for k in cnt if cnt[k] > 0):
        ans.append(v)
        cnt[v] -= 1
```

关键点：每轮必须重新取「计数 > 0」的键，不能沿用上一轮的键列表，否则会把已经取完的值再塞进 `ans`。

## 复杂度
时间：每轮排序 O(d log d)，d 为不同值个数，总轮数不超过最大频次，整体 O(n·d log d)，n ≤ 100 足够。
空间：`Counter` 存 d 个键值对，`ans` 存 n 个元素，额外 O(n + d)。

## 易错点
- 输入 `[7,7,4,4,4]`：若第一轮后不剔除计数为 0 的键，第二轮仍会输出 `4,7`，得到 `[4,7,4,7,...]` 多出一个 4；正确做法是每轮只遍历 `cnt[k] > 0` 的键。
- 输入 `[3,1,3,2,1,3]`：若按原数组顺序而非升序输出，第一轮会得到 `[3,1,2]`；正确做法是每轮对键 `sorted(...)` 后再追加。

## 如果面试官追问
若 nums 长度放大到 10^5、值域也变大，怎么做？答：用最小堆维护（值, 剩余次数），每轮弹出所有堆顶各取一个再压回，避免每轮全量排序。
