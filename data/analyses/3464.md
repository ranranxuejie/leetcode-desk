## 一句话思路
二分答案 `d`，把每个点按边界位置映射到一维坐标，用「选 k 个点两两曼哈顿距离 ≥ d」的贪心判定可行性。

## 怎么做
1. 把边界上的点按逆时针展开成一维坐标 `pos`：底边 `x`，右边 `side + y`，顶边 `3*side - x`，左边 `4*side - y`，总周长 `4*side`。
2. 二分 `d ∈ [0, 2*side]`，判定函数 `check(d)`：枚举起点 `i`，从 `pos[i]` 出发贪心往后跳，每次跳到第一个 `pos[j] - pos[last] >= d` 的位置，累计能选的点数。
3. 关键：正方形是环，起点 `i` 之后还要能绕回 `pos[i] + 4*side`，所以把 `pos` 复制一份加 `4*side` 拼在后面，长度 `2n`，只在 `j < i + n` 范围内跳。
4. 若某个起点能选满 `k` 个，`d` 可行。

以示例 2 为例：`side=2`，点 `(0,0),(1,2),(2,0),(2,2),(2,1)` 映射为 `pos = [0, 5, 2, 6, 3]`，排序后 `[0,2,3,5,6]`，拼成 `[0,2,3,5,6,8,10,11,13,14]`。取 `d=1`，从 `pos[0]=0` 起贪心跳到 `2,3,5,6` 得 5 个点 ≥ k=4，可行；`d=2` 时从 0 只能跳到 `2,5`（3 到 5 差 2 但 2→3 差 1 被跳过），凑不满 4 个，不可行，答案 1。

```python
def check(d):
    for i in range(n):
        cnt, last = 1, i
        for j in range(i + 1, i + n):
            if pos2[j] - pos2[last] >= d:
                cnt += 1
                last = j
                if cnt >= k:
                    return True
    return False
```

## 复杂度
时间：`O(n log n + n * n * log side)`，排序 `n log n`，每次判定 `O(n^2)`，二分 `log(2*side)`。
空间：`O(n)`，`pos2` 长度 `2n`。

## 易错点
- 忘记环形闭合：只按 `pos` 线性扫，示例 1 的 `[0,2,4,6]`（周长 8）在 `d=2` 时从 0 出发能选 4 个，但若起点选在 `pos=6` 附近就漏解 → 必须复制数组加 `4*side` 并限制 `j < i+n`。
- 贪心跳跃写成「相邻差 ≥ d」而非「与上一个选中点差 ≥ d」：示例 2 的 `pos=[0,2,3,5,6]`，`d=2` 时若只比相邻，`2→3` 差 1 会误判不可行 → 必须维护 `last` 记录上一个被选中的下标。

## 如果面试官追问
问：若要求输出具体选中的 k 个点怎么办？
答：`check` 里记录 `last` 序列，二分成功后重跑一次 `d` 的判定，把该起点的选中下标映射回原 `points` 即可。
