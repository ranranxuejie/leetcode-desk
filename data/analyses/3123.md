## 一句话思路
从 0 和 n-1 各跑一次 Dijkstra 得 `d1`、`d2`，边 `(a,b,w)` 满足 `d1[a]+w+d2[b]==D` 或反向即在最短路树上。

## 怎么做
1. 建邻接表，边带原始下标 `i`，方便回填 `answer[i]`。
2. 从 0 跑 Dijkstra 得 `d1`，从 n-1 跑得 `d2`，记 `D = d1[n-1]`；若 `D` 为无穷直接全 `False`。
3. 枚举每条边，判断 `d1[a]+w+d2[b]==D or d1[b]+w+d2[a]==D`，成立则 `answer[i]=True`。

以示例 1 为例：`d1 = [0,4,1,2,7,5]`，`d2 = [5,1,4,3,2,0]`，`D=5`。边 `[1,4,3]`：`d1[1]+3+d2[4]=4+3+7=14≠5`，反向 `d1[4]+3+d2[1]=7+3+1=11≠5`，故 `answer[3]=False`；边 `[1,5,1]`：`4+1+0=5`，为 `True`。

```python
import heapq
def dijkstra(src):
    dist = [float('inf')] * n
    dist[src] = 0
    pq = [(0, src)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w, _ in adj[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist

d1, d2 = dijkstra(0), dijkstra(n - 1)
```

## 复杂度
时间：两次 Dijkstra 各 `O((n+m) log n)`，枚举边 `O(m)`，堆贡献 `log n`。
空间：`adj` 存 `2m` 条边、两个 `dist` 数组各 `n`，共 `O(n+m)`。

## 易错点
- 图不连通时 `D = inf`，若直接比较 `d1[a]+w+d2[b]==D`，`inf+w` 仍是 `inf`，会把所有边误判为 `True`；必须先判 `D == inf` 则直接返回全 `False`。
- 只判 `d1[a]+w+d2[b]==D` 会漏掉方向：示例 2 中边 `[2,0,1]` 存的是 `a=2,b=0`，需靠 `d1[0]+1+d2[2]=0+1+2=3` 的反向判断才为 `True`，漏写反向会输出 `[False,...]`。

## 如果面试官追问
问：若要求输出所有最短路的具体路径而非边标记？
答：在松弛时记录前驱，沿 `d1[a]+w+d2[b]==D` 的边做 DFS 回溯枚举，注意指数级路径数需按题意限流。
