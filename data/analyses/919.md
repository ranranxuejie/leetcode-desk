## 一句话思路
用 BFS 队列只保留「还缺孩子」的节点，插入时取队首当父节点，插满两个孩子就出队。

## 怎么做
1. 初始化时 BFS 整棵树，把左孩子或右孩子为 `None` 的节点按层序入队 `q`。
2. `insert(v)` 取 `q[0]` 作父节点 `p`，若 `p.left is None` 挂左边，否则挂右边。
3. 挂完检查：`p` 两个孩子都齐了就 `q.pop(0)`，新节点 `v` 本身缺孩子，`q.append(v)`。
4. 返回 `p.val`；`get_root()` 直接返回构造时存的 `self.root`。

以示例 `root=[1,2]` 为例：初始化 BFS 得 `q=[1,2]`（1 缺右孩子，2 缺左右孩子）。第一次 `insert(3)`：`p=q[0]=1`，`p.left=2` 非空，故挂 `p.right=3`，此时 1 两孩子齐，`q.pop(0)` 后 `q=[2,3]`，返回 `1`。第二次 `insert(4)`：`p=q[0]=2`，`p.left` 为空挂左边，2 仍缺右孩子不出队，`q=[2,3,4]`，返回 `2`。

```python
from collections import deque

def __init__(self, root):
    self.root = root
    self.q = deque()
    dq = deque([root])
    while dq:
        node = dq.popleft()
        if node.left is None or node.right is None:
            self.q.append(node)
        if node.left: dq.append(node.left)
        if node.right: dq.append(node.right)

def insert(self, v):
    p = self.q[0]
    node = TreeNode(v)
    if p.left is None:
        p.left = node
    else:
        p.right = node
        self.q.popleft()
    self.q.append(node)
    return p.val
```

## 复杂度
时间：初始化 O(n) 遍历全树，每次 insert 均摊 O(1)，共 m 次插入即 O(n+m)。
空间：队列最多存一层节点 O(n)，`self.root` 只是引用不额外占。

## 易错点
1. 初始化只把「左孩子为空」的节点入队 → 对 `[1,2]` 这种 1 有左无右的树，1 被漏掉，`insert(3)` 会错误地挂到 2 的左边返回 2；正确判断是 `left is None or right is None`。
2. 挂右孩子后忘记 `popleft` → 对 `[1,2]` 插完 3 后 `q[0]` 仍是 1，第二次 `insert(4)` 又去改 1 的右孩子，覆盖掉 3；必须在「挂右边」分支里出队。

## 如果面试官追问
问：若允许删除任意节点并保持完全二叉树？答：仍需层序队列定位最后一个节点，删除时用末尾节点顶替再下沉/上浮修正，单次 O(log n)。
