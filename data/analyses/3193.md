## 一句话思路
按前缀长度递增做 DP，插入第 i 个数时新增逆序对数恰为它在已排好前缀中的插入位置，用前缀和把 O(k) 转移压成 O(1)。

## 怎么做
1. 把 requirements 转成字典 `req`，`req[end] = cnt`；若某个 end 缺失则视为无约束，但 `req[n-1]` 一定存在。
2. 定义 `dp[j]` = 当前长度前缀恰好 j 个逆序对的排列数，初始 `dp = [1]`（长度 0，0 个逆序对）。
3. 从长度 `i = 1` 到 `n`，新 dp 满足 `ndp[j] = sum(dp[j-k] for k in 0..i-1)`，即插入位置贡献 0..i-1 个逆序对；用滑动窗口前缀和实现。
4. 若 `i-1` 在 `req` 中，把 `ndp` 中下标不等于 `req[i-1]` 的项清零（保留该位置的值）。

以 `n=3, requirements=[[2,2],[0,0]]` 为例，`req={2:2, 0:0}`。长度 1 后 `dp=[1]`，因 `req[0]=0` 保留；长度 2 得 `dp=[1,1]`；长度 3 得 `[1,2,2]`，`req[2]=2` 只留 `dp[2]=2`，答案 2。

```python
MOD = 10**9 + 7
req = {e: c for e, c in requirements}
dp = [1]
for i in range(1, n + 1):
    m = len(dp) + i - 1
    ndp = [0] * m
    window = 0
    for j in range(m):
        window += dp[j] if j < len(dp) else 0
        if j - i >= 0 and j - i < len(dp):
            window -= dp[j - i]
        ndp[j] = window % MOD
    if i - 1 in req:
        c = req[i - 1]
        ndp = [ndp[c] if j == c else 0 for j in range(m)]
    dp = ndp
return dp[req[n - 1]] % MOD
```

## 复杂度
时间：O(n · maxCnt)，每层窗口长度受 `cnt ≤ 400` 限制，共 n 层。
空间：O(maxCnt)，只保留当前 dp 数组，无额外二维表。

## 易错点
- `requirements` 里 `end` 不连续（如示例 1 缺 `end=1`）→ 若按数组下标硬套会越界或错位 → 必须用字典 `req` 按 `end` 查，缺失层不清零。
- 某层约束 `cnt` 大于该长度最大逆序对数 `i*(i-1)//2` → 直接返回 0，否则窗口会算出全零却继续跑，浪费且易在取 `dp[c]` 时下标越界。

## 如果面试官追问
若 n 放大到 1e5 且 cnt 仍 ≤400，怎么做？答：每层只保留窗口内 400 个状态，用滚动数组 + 前缀和，时间 O(n·400) 不变，空间 O(400)。
