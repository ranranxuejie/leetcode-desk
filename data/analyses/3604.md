## 一句话思路
把「到达节点 u 的最早时间」当距离跑 Dijkstra，边权是等待时间，因为早到一定不劣于晚到。

## 怎么做
1. 建邻接表 `adj[u]` 存 `(v, start, end)`，`dist[0] = 0`，其余 `inf`。
2. 堆里弹 `(t, u)`，若 `t > dist[u]` 跳过；若 `u == n-1` 直接返回 `t`。
3. 对每条出边算到达时间：`t <= end` 时 `nt = max(t, start) + 1`，否则这条边此刻用不了，跳过。
4. `nt < dist[v]` 就更新并入堆。

拿示例 2 走一遍关键一步：`n=4`，从 `(0,0)` 弹出，边 `[0,2,1,5]` 得 `nt = max(0,1)+1 = 2`，`dist[2]=2`；边 `[0,1,0,3]` 得 `nt=1`，`dist[1]=1`。之后弹出 `(2,2)`，边 `[2,3,4,7]` 得 `nt = max(2,4)+1 = 5`，答案 5。注意 `max(t,start)` 就是「在 u 干等到窗口开门」的那段等待。

```python
import heapq
adj = [[] for _ in range(n)]
for u, v, s, e in edges:
    adj[u].append((v, s, e))
dist = [float('inf')] * n
dist[0] = 0
pq = [(0, 0)]
while pq:
    t, u = heapq.heappop(pq)
    if t > dist[u]:
        continue
    if u == n - 1:
        return t
    for v, s, e in adj[u]:
        if t <= e:
            nt = max(t, s) + 1
            if nt < dist[v]:
                dist[v] = nt
                heapq.heappush(pq, (nt, v))
return -1
```

## 复杂度
时间 `O((n + E) log n)`，E 条边各松弛一次、堆操作贡献 log n。
空间 `O(n + E)`，邻接表存 E 条边，dist 和堆各 O(n)。

## 易错点
- 边窗口已过（`t > end`）时若仍写 `nt = max(t, start)+1`，示例 1 里在 t=1 到节点 1 后会用 `[1,2,2,5]` 算出 `nt=3` 直接到终点，漏掉等待，答案错成 3 之外的更小值；正确是先判 `t <= end` 再算。
- 用 `dist[u] != t` 判重而非 `t > dist[u]`：同一节点可能先以较大时间入堆、后被更小时间覆盖，`!=` 会把有效条目误丢；写成 `t > dist[u]: continue` 才稳。

## 如果面试官追问
要求输出具体路径怎么办？在松弛成功时记 `parent[v] = u`，终点弹出后沿 parent 回溯，注意同一节点可能被多次更新，取最后一次即可。
