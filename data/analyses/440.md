## 一句话思路
把 [1,n] 看成十叉字典树，逐层数子树节点数，用 k 决定「下钻」还是「右移」。

## 怎么做
1. 从 `cur = 1` 出发，`k` 表示当前子树内还差第几小（初始 k 含 cur 本身）。
2. 写 `count(cur, n)`：用 `first, last = cur, cur` 逐层把区间 `[first, last]` 累加，`first *= 10`、`last = last*10+9`，每层取 `min(last, n) - first + 1`。
3. 若 `count(cur) < k`，说明整棵 cur 子树不够，`k -= count`，`cur += 1` 右移。
4. 否则 `k -= 1`（cur 自己占一位），若 `k == 0` 返回 cur，否则 `cur *= 10` 下钻。

以 n=13, k=2 为例：`cur=1`，`count(1,13)` 第一层 first=1,last=1 得 1；第二层 first=10,last=19，`min(19,13)-10+1=4`，合计 5。5 ≥ 2，故 `k=1`，`cur=10`；再 `count(10,13)=1`（10..13 只 4 个？注意 first=10,last=10 得 1，下一层 first=100>13 停），1 ≥ 1 且 `k-1=0`，返回 10。

```python
def count(cur, n):
    cnt, first, last = 0, cur, cur
    while first <= n:
        cnt += min(last, n) - first + 1
        first *= 10
        last = last * 10 + 9
    return cnt

cur, k = 1, k
while k > 1:
    c = count(cur, n)
    if c < k:
        k -= c
        cur += 1
    else:
        k -= 1
        cur *= 10
return cur
```

## 复杂度
时间：O((log n)^2)，外层最多 log n 次移动，每次 count 走 log n 层。
空间：O(1)，只用 cur、k、first、last 几个整数。

## 易错点
1. n=13, k=2 时若把 `count` 的循环条件写成 `first <= n` 却漏掉 `min(last, n)`，第二层会算成 19-10+1=10，总数变 11，误判 1 的子树够大而直接下钻到 10 后继续错走。正确做法是每层都取 `min(last, n)` 截断。
2. k=1 时若先算 `count(1)` 再判断，会走 `k -= 1` 分支把 k 变 0 却仍下钻 `cur *= 10`，返回 10 而非 1。正确做法是循环条件写 `while k > 1`，k=1 直接返回 cur=1。

## 如果面试官追问
问：n 到 10^18 还行吗？答：行，count 每层只做乘 10 和取 min，层数变 18，复杂度仍是 O((log n)^2)，Python 整数无溢出问题。
