## 一句话思路
把 `a*x` 和 `b*y` 都截断到长度 `len(a)+len(b)` 以内再判断子串，因为更长的部分不可能改变结论。

## 怎么做
1. 若 `len(b)*y > len(a)*x`，直接返回 `False`（长的串不可能是短的串的子串）。
2. 否则构造 `A = (a * min(x, (len(a)+len(b))//len(a) + 1))`，即只重复到够长为止，不必真乘 `x` 次。
3. 同理构造 `B = b * y`，但 `y` 也可能到 1e9，所以只重复 `min(y, (len(A))//len(b) + 1)` 次。
4. 返回 `B in A`。

关键中间值：示例 3 中 `a="abcd", b="cdab", x=2, y=1`，`len(a)+len(b)=8`，`A` 重复 `min(2, 8//4+1)=2` 次得 `"abcdabcd"`，`B` 重复 `min(1, 8//4+1)=1` 次得 `"cdab"`，`"cdab" in "abcdabcd"` 为 `True`。

```python
la, lb = len(a), len(b)
if lb * y > la * x:
    return False
need = la + lb
A = a * min(x, need // la + 1)
B = b * min(y, len(A) // lb + 1)
return B in A
```

注意 `min` 的上界用 `need // la + 1` 而不是 `need // la`，保证 `A` 长度严格超过 `need`，覆盖跨边界匹配。

## 复杂度
时间：`O((la+lb) * min(x, (la+lb)//la))`，实际是 `O(la+lb)` 量级的字符串匹配，`n` 来自 `la+lb`。
空间：`O(la+lb)`，额外开了截断后的 `A` 和 `B`。

## 易错点
- 输入 `a="ab", b="abab", x=2, y=1`：若只重复 `x` 次得 `"abab"`，`B="abab"` 匹配成功；但若 `x` 很大而 `y` 很小，直接 `a*x` 会内存爆炸 → 必须用 `min` 截断，不能真乘。
- 输入 `a="a", b="aa", x=1, y=1`：`len(b)*y=2 > len(a)*x=1`，若漏掉第一步长度判断，`B in A` 会返回 `False` 恰好正确，但换成 `a="aa", b="a", x=1, y=2` 时 `len(b)*y=2 == len(a)*x=2`，若截断上界写成 `need//la` 而非 `+1`，`A` 可能不够长导致漏匹配 → 上界必须 `+1`。

## 如果面试官追问
问：如果 `x, y` 都到 1e18 且 `a, b` 长度 1e5 呢？
答：结论不变，仍只需截断到 `la+lb` 量级，复杂度 `O(la+lb)`，与 `x, y` 无关。
