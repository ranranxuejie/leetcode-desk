## 一句话思路
把每个多余石头和每个空格都列出来，用状压 DP 做二分图最小权匹配，权值是曼哈顿距离。

## 怎么做
1. 扫描 9 个格子，`src` 收集多出的石头坐标（`grid[i][j]-1` 个），`dst` 收集空格坐标（`grid[i][j]==0` 一个）。两者长度必相等，记作 `k`。
2. 预处理 `cost[i][j] = |src[i]行-dst[j]行| + |src[i]列-dst[j]列|`。
3. `dp[mask]` 表示已给 `mask` 中这些空格各配了一个石头的最小代价，`mask` 的位数就是当前处理到第几个 `src`。
4. 转移：`dp[mask | 1<<j] = min(dp[mask] + cost[popcount(mask)][j])`，`j` 取 `mask` 中为 0 的位。

以示例 2 `[[1,3,0],[1,0,0],[1,0,3]]` 为例：`src = [(0,1),(0,1),(2,2),(2,2)]`，`dst = [(0,2),(1,1),(1,2),(2,1)]`。`cost[0][0]=1`、`cost[0][1]=1`，所以 `dp[0b0011]` 会取到 2；最终 `dp[0b1111]=4`，与输出一致。

```python
k = len(src)
cost = [[abs(a-c)+abs(b-d) for c,d in dst] for a,b in src]
INF = 10**9
dp = [INF] * (1 << k)
dp[0] = 0
for mask in range(1 << k):
    i = bin(mask).count("1")          # 已配好的 src 个数
    for j in range(k):
        if not (mask >> j) & 1:
            nm = mask | (1 << j)
            dp[nm] = min(dp[nm], dp[mask] + cost[i][j])
return dp[(1 << k) - 1]
```

## 复杂度
时间：`O(2^k · k)`，`k` 是多余石头数，最多 8，约 2000 次转移。
空间：`O(2^k)` 的 `dp` 数组加 `k×k` 的 `cost` 表。

## 易错点
- 把 `src` 里同一格的多颗石头只记一次 → 示例 2 的 `(0,1)` 有 2 颗、`(2,2)` 有 2 颗，漏记后 `k` 变小、`dp` 长度不对，答案偏小；必须按 `grid[i][j]-1` 重复 append。
- 用 `i = mask.bit_count()` 之外的量当行号，比如用循环次数或 `j` → 转移时 `cost` 行错位，示例 2 会算出 3 而非 4；行号只能是 `mask` 中 1 的个数。

## 如果面试官追问
问：如果网格不是 3×3 而是 n×n 呢？
答：`k` 会涨到 `n²-1`，状压 `O(2^k·k)` 直接爆，得换成 KM 或最小费用流求二分图匹配。
