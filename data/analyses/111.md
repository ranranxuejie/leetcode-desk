## 一句话思路
用 BFS 逐层扫描，第一个遇到的叶子节点所在层数就是最小深度，因为 BFS 保证按深度递增访问。

## 怎么做
1. 空树直接返回 0。
2. 用队列存 `(node, depth)`，初始 `(root, 1)`。
3. 每次出队检查：若 `node.left` 和 `node.right` 都为 `None`，立即返回当前 `depth`。
4. 否则把非空子节点连同 `depth + 1` 入队。

以示例 1 `root = [3,9,20,null,null,15,7]` 为例：队列初始 `[(3,1)]`；出队 `(3,1)`，左右都非空，入队 `(9,2)`、`(20,2)`；出队 `(9,2)`，`9` 左右均为 `None`，是叶子，直接返回 `2`。关键中间值就是 `depth=2` 时命中叶子 `9`。

```python
from collections import deque

def minDepth(root):
    if not root:
        return 0
    q = deque([(root, 1)])
    while q:
        node, depth = q.popleft()
        if not node.left and not node.right:
            return depth
        if node.left:
            q.append((node.left, depth + 1))
        if node.right:
            q.append((node.right, depth + 1))
```

DFS 写法也行，但要在单边子树时特殊处理：`node.left` 为空则返回 `1 + minDepth(node.right)`，反之亦然，两边都有才取 `min`。

## 复杂度
时间 O(n)：最坏访问全部 n 个节点，但通常提前命中叶子。
空间 O(n)：队列最多存一层节点，最坏（满二叉树底层）约 n/2。

## 易错点
- 输入 `root = [2,null,3,null,4,null,5,null,6]`（示例 2）→ 若直接写 `1 + min(minDepth(left), minDepth(right))`，空子树返回 0 会得到 1，错成 1 → 正确做法是单边为空时只递归非空那侧，返回 `1 + minDepth(node.right)`。
- 输入 `root = [1,2]`（只有左孩子）→ 若把根节点当叶子提前返回，会错成 1 → 正确做法是判断 `not node.left and not node.right` 才算叶子，`1` 有左孩子不算。

## 如果面试官追问
问：若要求返回最小深度对应的叶子节点值而非深度？
答：BFS 出队时命中叶子就同时返回 `node.val`，队列元素改成 `(node, depth)` 即可，逻辑不变。
