## 一句话思路
把 arr2 消掉，只对 arr1 做 DP：arr1 非递减且 arr1[i] ≤ nums[i] 且 arr1[i] ≤ nums[i]-arr2[i+1] 的约束可化为上界前缀和。

## 怎么做
1. 令 arr2[i] = nums[i] - arr1[i]，arr2 非递增等价于 arr1[i+1] - arr1[i] ≥ nums[i+1] - nums[i]，即 arr1 的增量有下界。
2. 定义 dp[i][v] = 前 i 个位置、arr1[i] = v 的方案数，转移 dp[i][v] = sum_{u ≤ v - (nums[i]-nums[i-1])} dp[i-1][u]，用前缀和 O(1) 取。
3. 上界：arr1[i] ≤ nums[i] 且 arr1[i] ≤ nums[i] - arr2[i+1] 的最小可行值，实际只需 v 从 0 到 nums[i]，且 v 满足 v ≤ nums[i] 且 v ≥ 0。
4. 以 nums=[2,3,2] 为例：i=0 时 dp[0][0..2]=1；i=1 时增量下界 nums[1]-nums[0]=1，dp[1][v]=sum_{u≤v-1}dp[0][u]，得 dp[1]=[0,1,2]；i=2 时增量下界 -1，dp[2][v]=sum_{u≤v+1}dp[1][u]，v=0→1, v=1→3, v=2→3，合计 4。

```python
MOD = 10**9 + 7
m = max(nums)
dp = [1] * (nums[0] + 1) + [0] * (m - nums[0])
for i in range(1, n):
    d = nums[i] - nums[i-1]
    pre = [0] * (m + 1)
    for v in range(m + 1):
        pre[v] = (pre[v-1] + dp[v]) % MOD if v else dp[v]
    ndp = [0] * (m + 1)
    for v in range(nums[i] + 1):
        hi = v - d
        ndp[v] = pre[hi] if hi >= 0 else 0
    dp = ndp
return sum(dp) % MOD
```

## 复杂度
时间：O(n · max(nums))，n 来自外层，max(nums) 来自内层枚举 v。
空间：O(max(nums))，只保留 dp 和前缀和数组。

## 易错点
- nums=[2,3,2] 时若忽略增量下界 d=1，会把 arr1=[0,0,0] 这类非法解算进去，得 6 而非 4；正确做法是转移时 hi = v - d，hi<0 直接取 0。
- nums=[5,5,5,5] 时若把上界写成固定 max(nums) 而非 nums[i]，会多算 v>nums[i] 的非法状态；正确做法是内层只枚举 v ∈ [0, nums[i]]。

## 如果面试官追问
问：n 扩到 10^5 怎么办？答：把 v 的枚举换成对 nums[i] 值域做离散化 + 前缀和，或观察到 d 单调时用差分维护，复杂度降到 O(n log n)。
