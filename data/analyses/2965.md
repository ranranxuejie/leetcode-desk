## 一句话思路
用长度为 n²+1 的计数数组统计每个数出现次数，出现 2 次的是 a，出现 0 次的是 b。

## 怎么做
1. 令 `m = n * n`，开 `cnt = [0] * (m + 1)`，下标直接对应数值 1..m。
2. 双层遍历 `grid`，对每个 `x` 执行 `cnt[x] += 1`。
3. 从 1 扫到 m，`cnt[v] == 2` 记为 a，`cnt[v] == 0` 记为 b，返回 `[a, b]`。

以示例 1 `grid = [[1,3],[2,2]]` 为例，n=2、m=4，统计后 `cnt = [0,1,2,1,0]`：下标 2 的值是 2 → a=2，下标 4 的值是 0 → b=4，返回 `[2,4]`。关键中间值就是 `cnt[2]=2` 和 `cnt[4]=0` 这两个位置，其余都是 1。

```python
n = len(grid)
m = n * n
cnt = [0] * (m + 1)
for row in grid:
    for x in row:
        cnt[x] += 1
a = b = 0
for v in range(1, m + 1):
    if cnt[v] == 2:
        a = v
    elif cnt[v] == 0:
        b = v
return [a, b]
```

也可以用数学法：总和 `S = sum(所有元素)`、平方和 `Q = sum(x*x)`，与 `1..m` 的理论值相减得 `a - b = S - m(m+1)/2`、`a² - b² = Q - m(m+1)(2m+1)/6`，再除一下得 `a + b`，联立解出 a、b。代码更短但推导容易写错，面试时计数法更稳。

## 复杂度
时间 O(n²)：遍历矩阵 n² 个格子，再扫一遍长度 n² 的 cnt。
空间 O(n²)：额外开了 cnt 数组，长度 n²+1。

## 易错点
- 计数数组开成 `[0] * m` 而不是 `[0] * (m + 1)`：当 `grid` 里出现 `n*n`（如示例 2 的 m=9 时若含 9）会 `IndexError`，因为合法值上界是 m，下标必须能取到 m。
- 用集合 `set` 找重复时只拿到 a，忘了 b：`set` 只能告诉你谁重复，缺失值必须靠 `1..m` 全集减去出现集合，或像上面那样扫 cnt 找 0，否则示例 1 会只返回 `[2]` 或错填 b。

## 如果面试官追问
问：如果 n 大到 10⁵、矩阵放不进内存怎么办？
答：改成流式读入，只维护 cnt 数组（或总和与平方和两个标量），空间仍是 O(n²) 但不需要存整个矩阵。
