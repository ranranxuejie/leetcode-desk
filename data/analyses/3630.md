## 一句话思路
n≤19 直接枚举 3^n 种「每个元素进 A/B/C」的分配，逐组算 XOR(A)+AND(B)+XOR(C) 取最大，规模够小无需剪枝。

## 怎么做
1. 用三进制枚举：把 0..3^n-1 的每个数拆成 n 位三进制，第 i 位 0/1/2 表示 nums[i] 进 A/B/C。
2. 对每种分配，A 组元素异或、B 组元素按位与、C 组元素异或，三者相加更新答案。
3. 空组按定义贡献 0：XOR 初值 0，AND 初值用 `(1<<31)-1` 或首个元素特判。

以 `nums=[2,3,6,7]` 为例，分配 `A=[7], B=[2,3], C=[6]` 对应三进制码，算出 `XOR(A)=7`、`AND(B)=2&3=2`、`XOR(C)=6`，和 `15`，即最优。

```python
n = len(nums)
best = 0
for mask in range(3 ** n):
    xa = xc = 0
    ab = None
    m = mask
    for i in range(n):
        g = m % 3
        m //= 3
        if g == 0:
            xa ^= nums[i]
        elif g == 1:
            ab = nums[i] if ab is None else ab & nums[i]
        else:
            xc ^= nums[i]
    best = max(best, xa + (ab or 0) + xc)
```

`ab or 0` 处理 B 为空（`ab` 为 `None`）的情况，此时 AND 贡献 0。

## 复杂度
时间：O(3^n · n)，3^n 种分配，每种扫 n 个元素。
空间：O(1)，只存 `best/xa/xc/ab` 几个标量。

## 易错点
- B 组为空时 `ab` 是 `None`，直接 `xa + ab + xc` 会 TypeError → 必须用 `(ab or 0)` 或初值 `(1<<31)-1` 再特判，因为空 AND 定义为 0 而非全 1。
- 三进制拆位写成 `mask // (3**i) % 3` 与循环内 `m % 3; m //= 3` 混用会错位 → 固定一种写法，循环内自除最省事，别在同一个 mask 上既除又取幂。

## 如果面试官追问
问：n 放大到 10^5 怎么办？答：3^n 枚举失效，需按位贪心，从高位到低位尝试让答案该位为 1，用可行性判定（每组元素个数与位约束）决定取舍。
