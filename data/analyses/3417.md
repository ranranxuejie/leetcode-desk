## 一句话思路
按行之字形走，用一个布尔量记录「当前是否该取」，取一个就翻转一次。

## 怎么做
1. 外层 `for i, row in enumerate(grid)`，`i % 2 == 0` 时用 `row`，否则用 `row[::-1]`，得到本行的访问顺序。
2. 维护 `take = True`，表示下一个访问到的格子要不要收进 `result`。
3. 遍历本行每个值 `v`：若 `take` 为真就 `result.append(v)`，然后无条件 `take = not take`——跳过与否只跟「第几个被访问」有关，跟行列坐标无关。
4. 行与行之间不重置 `take`，它跨行连续翻转。

以示例 3 `[[1,2,3],[4,5,6],[7,8,9]]` 为例：第 0 行顺序 `1,2,3`，`take` 依次 True/False/True，收 `1,3`，行末 `take` 变回 False；第 1 行反序 `6,5,4`，`take` 为 False 跳过 6、收 5、跳过 4，`take` 变 True；第 2 行顺序 `7,8,9`，收 7、跳 8、收 9，得 `[1,3,5,7,9]`。

```python
result = []
take = True
for i, row in enumerate(grid):
    seq = row if i % 2 == 0 else row[::-1]
    for v in seq:
        if take:
            result.append(v)
        take = not take
```

关键点：`take` 的翻转放在 `if` 外面，否则被跳过的格子不会推进奇偶性，示例 3 会错成 `[1,3,5,9]`。

## 复杂度
时间 O(m·n)：每个格子被访问一次，m 行 n 列。
空间 O(1) 额外（不计 `result` 本身），`row[::-1]` 每行最多 O(n) 临时拷贝。

## 易错点
- 输入 `[[1,2],[3,4]]`：若在每行开头把 `take` 重置为 True，会得到 `[1,3]`；正确是跨行连续翻转，第 1 行反序 `4,3` 且 `take` 为 False，收 `4`，输出 `[1,4]`。
- 输入 `[[2,1],[2,1],[2,1]]`：若把 `take` 的翻转写在 `if take:` 内部，被跳过的格子不推进计数，输出会变成 `[2,2,2]`；正确是每次访问都翻转，得 `[2,1,2]`。

## 如果面试官追问
若要求返回被跳过格子的坐标而非值？答：同样维护 `take`，在 `else` 分支里按 `(i, j)` 记录，j 由 `i % 2` 决定是正序还是 `n-1-正序`。
