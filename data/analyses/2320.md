## 一句话思路
两侧独立，单侧合法方案数是斐波那契式递推，答案即其平方。

## 怎么做
1. 设 `f[i]` 为单侧前 `i` 个地块的合法放置数，第 `i` 块不放则继承 `f[i-1]`，放则第 `i-1` 块必须空，贡献 `f[i-2]`。
2. 得 `f[i] = f[i-1] + f[i-2]`，初值 `f[0] = 1`（空街）、`f[1] = 2`（放或不放）。
3. 两侧互不影响，总方案数 `= f[n] * f[n]`，边算边对 `10**9 + 7` 取余。
4. 用滚动变量代替数组，只留 `a, b` 两个值。

以 `n = 2` 为例：`a = f[0] = 1`，`b = f[1] = 2`；循环一次得 `f[2] = 3`，答案 `3 * 3 = 9`，与示例一致。

```python
MOD = 10**9 + 7
a, b = 1, 2          # f[0], f[1]
for _ in range(n - 1):
    a, b = b, (a + b) % MOD
f = b if n >= 1 else a
return f * f % MOD
```

注意 `n = 1` 时循环不执行，`f = b = 2`，答案 `4`。

## 复杂度
时间：O(n)，循环 n-1 次，每次常数次加法取模。
空间：O(1)，只用 `a, b` 两个变量，没有开长度 n 的数组。

## 易错点
- `n = 1` 时若把循环写成 `range(n)` 或初值设成 `a, b = 1, 1`，会得到 `f = 1` 或 `f = 3`，答案错成 1 或 9；正确是 `f[1] = 2`、答案 4，务必让 `n = 1` 走零次循环。
- 先算 `f * f` 再取余，`n = 10^4` 时 `f` 已达 `10^9` 量级，平方约 `10^18`，Python 虽不溢出但结果错；应在每步 `(a + b) % MOD`，最后 `f * f % MOD`。

## 如果面试官追问
若 n 放大到 `10^18` 怎么算？答：递推是二阶线性，用矩阵快速幂 `[[1,1],[1,0]]` 的幂，O(log n)。
