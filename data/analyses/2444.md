## 一句话思路
用滑动窗口维护「不含越界元素」的极大区间，窗口内用 `lastMin`/`lastMax` 记录最近一次出现 minK/maxK 的位置，累加合法左端点个数。

## 怎么做
1. 遍历 `nums`，用 `left` 标记当前窗口左边界；遇到 `nums[i] < minK or nums[i] > maxK` 时，该元素不能出现在任何合法子数组中，令 `left = i + 1`，并重置 `lastMin = lastMax = -1`。
2. 若 `nums[i] == minK` 更新 `lastMin = i`；若 `nums[i] == maxK` 更新 `lastMax = i`。
3. 以 `i` 为右端点，合法左端点必须同时 ≤ `lastMin` 和 ≤ `lastMax`，且 ≥ `left`，故贡献为 `max(0, min(lastMin, lastMax) - left + 1)`。
4. 累加所有 `i` 的贡献。

以示例 1 `nums = [1,3,5,2,7,5], minK=1, maxK=5` 为例：`i=2` 时 `lastMin=0, lastMax=2, left=0`，贡献 `min(0,2)-0+1 = 1`（对应 `[1,3,5]`）；`i=3` 时 `lastMin=0, lastMax=2`，贡献 `0-0+1 = 1`（对应 `[1,3,5,2]`）；`i=4` 遇 `7` 越界，`left=5` 重置；`i=5` 时 `lastMax=5, lastMin=-1`，贡献 0。总计 2。

```python
left = lastMin = lastMax = -1
ans = 0
for i, x in enumerate(nums):
    if x < minK or x > maxK:
        left = i
        lastMin = lastMax = -1
    if x == minK:
        lastMin = i
    if x == maxK:
        lastMax = i
    if lastMin != -1 and lastMax != -1:
        ans += min(lastMin, lastMax) - left
```

## 复杂度
时间 O(n)：每个元素只被访问一次，`left`/`lastMin`/`lastMax` 均单调右移。
空间 O(1)：只开三个整型变量，无额外数组或队列。

## 易错点
1. 输入 `nums = [1,1,1,1], minK = maxK = 1` → 若把 `lastMin` 和 `lastMax` 当成两个独立条件分别判断「都出现过才累加」，会漏掉 `minK == maxK` 时同一位置同时更新两者的情形，错算成 4 而非 10 → 正确做法是每次 `i` 都无条件检查 `lastMin != -1 and lastMax != -1`，同一元素可同时刷新两个指针。
2. 输入 `nums = [1,3,5,2,7,5]` → 若越界时只令 `left = i + 1` 而不重置 `lastMin/lastMax`，`i=5` 时仍会用旧的 `lastMin=0` 算出 `min(0,5)-5 = -5` 的负贡献或错误正值 → 正确做法是越界分支里同时把 `lastMin = lastMax = -1`，并在累加前用 `lastMin != -1 and lastMax != -1` 兜底。

## 如果面试官追问
问：若要求返回所有定界子数组而非计数？答：在累加处枚举左端点 `j ∈ [left, min(lastMin,lastMax)]` 逐个输出 `nums[j:i+1]`，复杂度升为 O(n·答案长度)。
