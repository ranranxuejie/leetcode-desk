## 一句话思路
枚举 s 中回文中心向两侧扩展，用 t 的某段前缀去补 s 剩下的半段，答案取最大。

## 怎么做
1. 先算 `t` 的任意子串与 `s` 任意子串能拼出的最长回文，核心是预处理 `t` 的每个后缀与 `s` 的每个前缀的最长公共前缀 `lcp[i][j]`。
2. 枚举 s 的回文中心（奇数、偶数两种），向两侧扩展得到 s 内的回文半径。
3. 扩展停止时，用 `lcp` 查 s 左侧剩余部分能在 t 中匹配多长，拼成完整回文。
4. 单独考虑完全取自 s 或完全取自 t 的回文。

以 `s="abcde", t="ecdba"` 为例：中心在 `c`，s 内扩展得 `"c"`，左侧剩 `"ab"`，`lcp` 查得 t 中 `"ba"` 反向匹配长度 2，拼成 `"abcba"` 长度 5。

```python
# lcp[i][j] = s[i:] 与 t[j:] 的最长公共前缀长度
for i in range(n - 1, -1, -1):
    for j in range(m - 1, -1, -1):
        if s[i] == t[j]:
            lcp[i][j] = lcp[i + 1][j + 1] + 1
# 枚举中心扩展时，左侧剩余 s[l..i-1] 需与 t 的某段反向匹配
```

## 复杂度
时间 O(n·m + (n+m)²)，n、m 分别为 s、t 长度，lcp 表 O(n·m)，中心扩展 O((n+m)²)。
空间 O(n·m)，lcp 二维表。

## 易错点
- 输入 `s="b", t="aaaa"` → 只枚举 s 中心会漏掉纯 t 的 `"aaaa"` → 必须单独对 t 求最长回文子串，答案取 max。
- 输入 `s="abcde", t="ecdba"` → 忘记 t 段要反向匹配 s 左侧 → 扩展停止后要用 `lcp[l][j]` 而非正向查，且 t 段取的是 `t[j:j+len]` 的反向。

## 如果面试官追问
问：若 s、t 长度到 10⁵ 怎么办？
答：lcp 二维表存不下，改用哈希+二分或 Manacher 预处理，中心扩展改 O(1) 查询。
