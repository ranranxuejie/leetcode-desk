## 一句话思路
用长度为 rowIndex+1 的数组原地滚动，从右往左更新 `row[j] += row[j-1]`，避免覆盖上一轮还要用的值。

## 怎么做
1. 初始化 `row = [1] * (rowIndex + 1)`，第 0 列和第 i 列恒为 1。
2. 外层 `i` 从 2 遍历到 rowIndex，表示正在构造第 i 行。
3. 内层 `j` 从 `i - 1` 递减到 1，执行 `row[j] += row[j - 1]`。
4. 返回 `row`。

以 `rowIndex = 3` 为例，初始 `row = [1,1,1,1]`。`i = 2` 时 `j = 1`：`row[1] = 1 + 1 = 2`，得 `[1,2,1,1]`；`i = 3` 时 `j = 2`：`row[2] = 1 + 2 = 3`，`j = 1`：`row[1] = 2 + 1 = 3`，最终 `[1,3,3,1]`。

```python
row = [1] * (rowIndex + 1)
for i in range(2, rowIndex + 1):
    for j in range(i - 1, 0, -1):
        row[j] += row[j - 1]
return row
```

关键在倒序：`row[j]` 依赖的是上一行的 `row[j-1]`，倒着走时 `row[j-1]` 还没被本轮改过。若正序，`row[1]` 先变成 2，`row[2]` 就会用 2 而不是 1，算出 3 而非 2。

## 复杂度
时间：O(rowIndex²)，双层循环共约 rowIndex²/2 次加法。
空间：O(rowIndex)，只开一个长度为 rowIndex+1 的结果数组，无额外表。

## 易错点
- `rowIndex = 0` → 若循环写成 `range(1, rowIndex+1)` 或先算 `row[1]` 会越界/返回 `[1,1]` → 正确做法是初始化 `[1]*(rowIndex+1)` 后从 `i = 2` 起，`rowIndex = 0` 直接返回 `[1]`。
- 内层写成正序 `range(1, i)` → `rowIndex = 3` 时 `row[2]` 用已被改的 `row[1] = 2` 得 3，最终输出 `[1,3,4,1]` 而非 `[1,3,3,1]` → 必须 `range(i-1, 0, -1)` 倒序。

## 如果面试官追问
问：要求 O(1) 额外空间怎么做？
答：用组合数 `C(rowIndex, j) = C(rowIndex, j-1) * (rowIndex-j+1) // j` 逐个算，只存当前值。
