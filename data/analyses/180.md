## 一句话思路
用窗口函数 `LAG` 取前两行的 `num`，三行相等即命中，再 `DISTINCT` 去重。

## 怎么做
1. 先按 `id` 排序，用 `LAG(num, 1)` 和 `LAG(num, 2)` 各取前一行、前两行的值，得到三列并排。
2. 三列同时相等的那一行，说明它和它前面两行构成连续三次。
3. 外层 `SELECT DISTINCT` 去重，因为一个数字可能连续出现 4 次、5 次，会被命中多次。

以官方示例为例，`id=3` 那行 `num=1`，`LAG(num,1)=1`、`LAG(num,2)=1`，三值相等，命中；`id=5` 那行 `num=1`，但 `LAG(num,1)=2`，不命中。所以只有 `1` 进结果。

```python
# 逻辑等价写法（pandas 演示窗口语义）
df = logs.sort_values("id")
df["p1"] = df["num"].shift(1)
df["p2"] = df["num"].shift(2)
hit = df[(df["num"] == df["p1"]) & (df["num"] == df["p2"])]
result = hit["num"].drop_duplicates()
```

SQL 版核心就三行：

```python
# SELECT DISTINCT num AS ConsecutiveNums
# FROM (SELECT num, LAG(num,1) OVER (ORDER BY id) AS p1,
#              LAG(num,2) OVER (ORDER BY id) AS p2 FROM Logs) t
# WHERE num = p1 AND num = p2
```

## 复杂度
时间：窗口排序 O(n log n)，n 为 `Logs` 行数。
空间：窗口缓冲 O(n)，`DISTINCT` 结果集另算。

## 易错点
- 用 `id` 直接做 `id, id+1, id+2` 三表自连接 → 遇到 `id` 不连续（删过行）就漏判，比如 `id` 为 1、2、4 时 `1,1,1` 会被判成不连续；正确做法是按 `id` 排序后用 `LAG` 取行，不依赖 `id` 数值差。
- 忘记 `DISTINCT` → 输入 `1,1,1,1` 时 `id=3` 和 `id=4` 两行都命中，结果表出现两个 `1`；正确做法是外层加 `DISTINCT num`。

## 如果面试官追问
问：如果要求连续出现恰好三次（四次不算）怎么办？
答：在命中行上再取 `LEAD(num,1)`，加条件 `num != 下一行` 即可排除四次。
