## 一句话思路
用埃拉托斯特尼筛：从 2 起把每个质数的倍数标记为合数，剩下的就是质数。

## 怎么做
1. 开一个长度 n 的布尔数组 `is_prime`，全部置 `True`，再把下标 0、1 置 `False`。
2. 外层 `p` 从 2 枚举到 `isqrt(n-1)`，只处理 `is_prime[p]` 为真的 p。
3. 内层从 `p*p` 开始，步长 p，把 `is_prime[p*p::p]` 全部置 `False`。
4. 最后返回 `sum(is_prime)`。

以 n = 10 为例：数组下标 0..9。p=2 时 `is_prime[2]` 为真，从 4 起把 4、6、8 置 False；p=3 时从 9 起把 9 置 False；p=4 已越界（`isqrt(9)=3`），循环结束。此时为 True 的下标是 2、3、5、7，`sum` 得 4。

```python
from math import isqrt

def count_primes(n):
    if n < 3:
        return 0
    is_prime = [True] * n
    is_prime[0] = is_prime[1] = False
    for p in range(2, isqrt(n - 1) + 1):
        if is_prime[p]:
            is_prime[p * p:n:p] = [False] * len(range(p * p, n, p))
    return sum(is_prime)
```

关键在 `p*p` 起点：小于 p² 的 p 的倍数一定已被更小的质数筛掉，从 p² 开始才不重复。

## 复杂度
时间：O(n log log n)，每个合数被其最小质因子筛一次，外层只到 √n。
空间：O(n)，`is_prime` 数组占 n 个布尔位。

## 易错点
- n = 0 或 1 → 若直接 `[True]*n` 再访问 `is_prime[1]` 会 IndexError，或返回 1。正确做法是先判 `n < 3` 返回 0。
- n = 2 → 数组只有下标 0、1，若循环上界写成 `isqrt(n)` 会漏掉边界。正确做法是上界用 `isqrt(n-1)`，且 `n < 3` 提前返回，n=2 时返回 0（小于 2 的质数没有）。

## 如果面试官追问
问：n 到 10^9 怎么办？答：筛法内存爆，改用分段筛，按 √n 内的质数逐段标记，空间降到 O(√n)。
