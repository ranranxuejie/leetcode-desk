## 一句话思路
用 `dp[i][j]` 表示 `article` 前 i 个字符能否被 `input` 前 j 个字符匹配，按 `*` 的两种用法（吃掉一个字符 / 消掉前一个元素）转移。

## 怎么做
1. 建 `(n+1) x (m+1)` 的布尔表，`dp[0][0] = True`，先单独处理 `dp[0][j]`：只有 `p[j-1] == '*'` 时 `dp[0][j] = dp[0][j-2]`。
2. 外层遍历 `i` 从 1 到 n，内层 `j` 从 1 到 m。
3. 若 `p[j-1]` 不是 `*`：`dp[i][j] = dp[i-1][j-1] and (p[j-1] == '.' or p[j-1] == s[i-1])`。
4. 若是 `*`：先取「消掉」分支 `dp[i][j-2]`，再看 `p[j-2]` 能否吃掉 `s[i-1]`，能则或上 `dp[i-1][j]`。

以 `s = "aa", p = "a*"` 为例：`dp[0][2] = dp[0][0] = True`（`*` 消掉 `a`）；`i=1` 时 `p[1] == '*'`，`p[0] == 'a'` 吃掉 `s[0]`，`dp[1][2] = dp[0][2] = True`；`i=2` 同理得 `dp[2][2] = dp[1][2] = True`，返回 `True`。

```python
n, m = len(article), len(input)
dp = [[False] * (m + 1) for _ in range(n + 1)]
dp[0][0] = True
for j in range(2, m + 1):
    if input[j - 1] == '*':
        dp[0][j] = dp[0][j - 2]
for i in range(1, n + 1):
    for j in range(1, m + 1):
        if input[j - 1] == '*':
            dp[i][j] = dp[i][j - 2]
            if input[j - 2] == '.' or input[j - 2] == article[i - 1]:
                dp[i][j] = dp[i][j] or dp[i - 1][j]
        elif input[j - 1] == '.' or input[j - 1] == article[i - 1]:
            dp[i][j] = dp[i - 1][j - 1]
return dp[n][m]
```

## 复杂度
时间 O(n·m)：n 是 `article` 长度、m 是 `input` 长度，两层循环各走一遍。
空间 O(n·m)：开了整张 `(n+1)×(m+1)` 布尔表，可滚动到 O(m)。

## 易错点
- `s = "aa", p = "a*"` 若漏掉 `dp[0][j]` 的初始化，`dp[0][2]` 会是 `False`，导致 `*` 消掉前驱的分支全断，正确答案 `True` 被算成 `False`；正确做法是先单独填第 0 行。
- `s = "ab", p = ".*"` 若在 `*` 分支只写 `dp[i][j-2]` 而忘了 `dp[i-1][j]`，`.*` 只能匹配空串，`"ab"` 会错成 `False`；正确做法是「消掉」和「吃掉一个字符」两个分支取或。

## 如果面试官追问
问：能否把空间压到 O(m)？答：可以，`dp[i][j]` 只依赖上一行和本行左侧，用一维数组从右往左更新，`*` 分支的 `dp[i-1][j]` 正好是更新前的旧值。
