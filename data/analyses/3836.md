## 一句话思路
按 nums1 下标顺序做 DP，状态记「已选对数 + nums2 用到的最右下标」，转移时枚举新配对的 j。

## 怎么做
1. 定义 `dp[t][j]` = 处理完 nums1 前 i 个元素、恰好选了 t 对、且第 t 对的 nums2 下标是 j 时的最大得分；i 这一维滚动掉。
2. 对每个 i，先复制上一轮的 `dp` 到 `ndp`（表示不选 nums1[i]），再对所有 `t < k`、`j' < j` 尝试把 (i, j) 接在第 t 对后面。
3. 转移式 `ndp[t+1][j] = max(ndp[t+1][j], dp[t][j'] + nums1[i]*nums2[j])`，j' 从 0 到 j-1。
4. 答案是 `max(dp[k][j] for j in range(m))`，初值 `dp[0][j] = 0`（t=0 时无最右下标约束，用一维哨兵即可）。

以示例 1 `nums1=[1,3,2], nums2=[4,5,1], k=2` 为例：i=1（值 3）时，`dp[0][*]=0`，对 j=0 得 `ndp[1][0]=12`、j=1 得 `ndp[1][1]=15`；i=2（值 2）时从 `dp[1][0]=12` 接 j=1 得 `12+2*5=22`，这就是最终答案。

```python
NEG = -10**18
dp = [[NEG] * m for _ in range(k + 1)]
for j in range(m):
    dp[0][j] = 0
for i in range(n):
    ndp = [row[:] for row in dp]
    for t in range(k):
        best = NEG
        for j in range(m):
            if best != NEG:
                ndp[t + 1][j] = max(ndp[t + 1][j], best + nums1[i] * nums2[j])
            best = max(best, dp[t][j])
    dp = ndp
return max(dp[k])
```

## 复杂度
时间 O(n·k·m)：外层 n 个 nums1 元素，内层 k 层 × m 个 nums2 下标。
空间 O(k·m)：滚动数组只留两层 dp，无其他额外结构。

## 易错点
- 全负数输入（如示例 3 `[-3,-2]` 配 `[1,2]`）→ 若把 `NEG` 初值设成 0 或忘记「恰好 k 对」，会返回 0 而不是 -7 → 必须用足够小的哨兵（如 `-10**18`），且只从合法状态转移。
- 忘记「i 严格递增」→ 若在同一轮 i 里既更新 `dp` 又读 `dp`，会把同一个 nums1[i] 用两次 → 必须先 `ndp = [row[:] for row in dp]` 再只写 `ndp`，本轮结束才 `dp = ndp`。

## 如果面试官追问
问：n、m 放大到 10^5 还能这么做吗？
答：不能，O(nkm) 会爆；需要按值排序后贪心或凸优化，本题规模只支持三维 DP。
