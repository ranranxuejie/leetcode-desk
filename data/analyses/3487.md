## 一句话思路
因为可以任意删除元素，所以只需把所有**正数**去重后求和；若没有正数则取最大单元素。

## 怎么做
1. 用 `set(nums)` 去重，得到所有互不相同的候选值。
2. 筛出其中 `> 0` 的元素求和，记为 `s`。
3. 若 `s > 0` 返回 `s`，否则返回 `max(nums)`（全非正时只能选一个最大元素）。

以示例 3 `nums = [1,2,-1,-2,1,0,-1]` 为例：去重后 `{1,2,-1,-2,0}`，正数只有 `1` 和 `2`，`s = 3`，返回 3。注意原数组里 `1` 出现两次，去重后只算一次，这正是「互不相同」的约束。

```python
def maxSum(nums):
    s = sum(x for x in set(nums) if x > 0)
    return s if s > 0 else max(nums)
```

关键点：删除操作让「连续」这个限制失效——任何去重后的正数集合都能通过删掉中间元素拼成一个子数组。所以问题退化为「正数去重求和」，不需要滑动窗口。

## 复杂度
时间：O(n)，`set(nums)` 遍历一次数组。
空间：O(n)，哈希集合存去重后的元素。

## 易错点
- 输入 `[1,1,0,1,1]` → 若直接对原数组求正数和会得 4，错；必须先去重，正确答案是 1。
- 输入 `[-3,-1,-2]` → 若返回 0 就错了，题目要求子数组非空，正确做法是返回 `max(nums) = -1`。

## 如果面试官追问
若要求输出具体子数组而非和？答：记录去重后的正数集合，按原数组顺序扫描并跳过重复值即可构造。
