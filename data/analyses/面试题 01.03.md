## 一句话思路
从 `length-1` 倒着往 `S` 里填，先数空格算出最终长度，双指针从后往前写，避免正序移动字符。

## 怎么做
1. 只扫 `S[:length]`，数出空格数 `spaces`，最终长度 `end = length + 2 * spaces`。
2. 令 `i = length - 1`、`j = end - 1`，从后往前遍历。
3. `S[i]` 是空格就往 `j-2..j` 写 `%20` 并让 `j -= 3`，否则把 `S[i]` 搬到 `S[j]` 并让 `j -= 1`。
4. 循环结束时 `S[:end]` 就是答案。

以 `S = "Mr John Smith "`、`length = 13` 为例：`S[:13]` 里有 2 个空格，`end = 13 + 4 = 17`。`i` 从 12 开始，`S[12]='h'` 搬到 `S[16]`；走到 `i=5` 的 `' '` 时，`j` 已退到 8，写入 `S[6:9] = "%20"`，`j` 变 5。最终 `S[:17]` 为 `"Mr%20John%20Smith"`。

```python
def replace_spaces(S, length):
    s = list(S)
    spaces = sum(1 for c in s[:length] if c == ' ')
    end = length + 2 * spaces
    i, j = length - 1, end - 1
    while i >= 0:
        if s[i] == ' ':
            s[j-2:j+1] = ['%', '2', '0']
            j -= 3
        else:
            s[j] = s[i]
            j -= 1
        i -= 1
    return ''.join(s[:end])
```

注意 `S` 尾部那格 `' '` 在 `length=13` 之外，不能算进 `spaces`，否则 `end` 会多 2。

## 复杂度
时间 O(n)：`n = length`，数空格和倒填各扫一遍。
空间 O(n)：`list(S)` 开了长度 `len(S)` 的字符数组，`end` 之外不额外开。

## 易错点
- 输入 `"Mr John Smith "`、`length=13` → 若对整串 `S` 数空格会得到 3 个，`end` 算成 19，输出尾部多出 `%20` → 必须只统计 `S[:length]`。
- 输入 `" "`、`length=5` → 若正序边扫边插，每次插入都要把后面字符整体右移，且 `i` 与写入位置互相干扰 → 倒序写，`j` 始终 ≥ `i`，不会覆盖还没读的字符。

## 如果面试官追问
问：不允许额外开数组、只能原地改传入的字符数组怎么办？
答：上面 `list(S)` 换成传入的 `char[]` 即可，倒序写保证 `j >= i`，天然原地。
