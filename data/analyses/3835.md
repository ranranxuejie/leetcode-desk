## 一句话思路
固定右端点 r，用两个单调队列维护窗口 [l,r] 的 max/min，二分/双指针找最小的合法 l，因为 cost 随窗口变长单调不减。

## 怎么做
1. 枚举右端点 r，用单调队列 `maxq`（递减）和 `minq`（递增）维护以 r 结尾的候选窗口的极值。
2. 对每个 r，用左指针 l 单调右移，直到 `(max-min)*(r-l+1) <= k` 成立；此时所有以 r 结尾、起点 ≥ l 的子数组都合法。
3. 累加 `r - l + 1` 到答案。
4. 关键中间值：以 `nums=[1,3,2], k=4` 为例，r=1 时窗口 [0,1] 的 max=3、min=1，cost=(3-1)*2=4 ≤ 4，l 停在 0，贡献 2；r=2 时 [0,2] cost=6>4，l 右移到 1，[1,2] cost=2≤4，贡献 2。

```python
from collections import deque
maxq, minq = deque(), deque()
l = ans = 0
for r, x in enumerate(nums):
    while maxq and nums[maxq[-1]] <= x: maxq.pop()
    maxq.append(r)
    while minq and nums[minq[-1]] >= x: minq.pop()
    minq.append(r)
    while (nums[maxq[0]] - nums[minq[0]]) * (r - l + 1) > k:
        l += 1
        if maxq[0] < l: maxq.popleft()
        if minq[0] < l: minq.popleft()
    ans += r - l + 1
```

## 复杂度
时间：O(n)，每个下标最多进出两个队列各一次，l 也只右移 n 次。
空间：O(n)，两个双端队列最多各存 n 个下标。

## 易错点
- 输入 `nums=[5,5,5,5], k=0`：若用 `<=` 去重或漏掉等值元素，队列长度会错，导致 cost 算成 0 但窗口判断失效；正确做法是弹出条件用 `<=`/`>=` 保留一个等值即可，cost 仍为 0，答案 10。
- 输入 `nums=[1,2,3], k=0`：若在 l 右移时忘记同步弹出队首过期下标（`maxq[0] < l`），max/min 会停留在旧窗口，cost 恒为 0，错误输出 6 而非 3；正确做法是每次 l 自增后立即检查并 popleft 过期队首。

## 如果面试官追问
问：若 k 很大导致所有子数组都合法，能否 O(1) 直接返回？答：可以，先判 `(max(nums)-min(nums))*n <= k` 则返回 `n*(n+1)//2`，省去队列开销。
