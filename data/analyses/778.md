## 一句话思路
把每个格子看作带权节点，答案就是起点到终点所有路径中「最大格子值」的最小值，用 Dijkstra 变体（堆按当前路径最大值排序）求。

## 怎么做
1. 用 `dist[i][j]` 记录到达该格子的最小水位，初始 `dist[0][0] = grid[0][0]`，其余为无穷大。
2. 用小根堆存 `(当前水位, i, j)`，每次弹出水位最小的格子，若已访问则跳过。
3. 对四个邻居 `(ni, nj)`，新水位 `nd = max(d, grid[ni][nj])`，若 `nd < dist[ni][nj]` 则更新并入堆。
4. 弹出 `(n-1, n-1)` 时直接返回该水位。

以示例 1 `[[0,2],[1,3]]` 为例：初始堆 `(0,0,0)`，弹出后邻居 `(0,1)` 得 `max(0,2)=2`、`(1,0)` 得 `max(0,1)=1`；弹出 `(1,1,0)` 后邻居 `(1,1)` 得 `max(1,3)=3`，最终弹出 `(3,1,1)` 返回 3。

```python
import heapq
n = len(grid)
dist = [[float('inf')] * n for _ in range(n)]
dist[0][0] = grid[0][0]
pq = [(grid[0][0], 0, 0)]
while pq:
    d, i, j = heapq.heappop(pq)
    if (i, j) == (n - 1, n - 1):
        return d
    if d > dist[i][j]:
        continue
    for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
        ni, nj = i + di, j + dj
        if 0 <= ni < n and 0 <= nj < n:
            nd = max(d, grid[ni][nj])
            if nd < dist[ni][nj]:
                dist[ni][nj] = nd
                heapq.heappush(pq, (nd, ni, nj))
```

## 复杂度
时间：O(n² log n)，n² 个格子各入堆一次，堆操作 log(n²)=2log n。
空间：O(n²)，dist 矩阵和堆各占 O(n²)。

## 易错点
- 初始 `dist[0][0]` 写成 0 而非 `grid[0][0]`：示例 1 中起点高度为 0 时无影响，但若起点高度非 0（如 `[[5,...]]`），会低估答案。正确做法是初始化为 `grid[0][0]`。
- 用普通 BFS 按层扩展而非按水位排序：示例 2 中会先走高度 1、2、3 的路径，但正确答案 16 需要绕行，BFS 会得到错误的小值。必须用堆保证每次扩展当前水位最小的格子。

## 如果面试官追问
问：如果要求输出具体路径而非仅时间？
答：在 dist 更新时额外记录每个格子的前驱 `prev[ni][nj] = (i, j)`，到达终点后从 `(n-1,n-1)` 回溯即可。
