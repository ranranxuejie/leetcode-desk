## 一句话思路
用三指针 DP：`dp[i]` 是第 i+1 个丑数，每个丑数由前面某个丑数乘 2/3/5 得到，取三者最小。

## 怎么做
1. 初始化 `dp = [1]`，三个指针 `p2 = p3 = p5 = 0`。
2. 每轮算 `nxt = min(dp[p2]*2, dp[p3]*3, dp[p5]*5)`，追加到 `dp`。
3. 哪个指针的乘积等于 `nxt`，就把该指针加一（可能同时加多个，去重）。
4. 循环到 `len(dp) == n`，返回 `dp[-1]`。

以 `n = 10` 为例，前几步 `dp` 依次为 `[1,2,3,4,5,6,8,9,10,12]`。关键一步：当 `dp = [1,2,3,4,5]` 时，`p2=2`（`dp[2]*2=6`）、`p3=1`（`dp[1]*3=6`）、`p5=1`（`dp[1]*5=5`），`nxt = min(6,6,5) = 5`，追加 5 后 `p5` 从 1 变 2；下一轮 `p5` 指向 `dp[2]=3`，`3*5=15`，避免重复。

```python
dp = [1]
p2 = p3 = p5 = 0
while len(dp) < n:
    nxt = min(dp[p2] * 2, dp[p3] * 3, dp[p5] * 5)
    dp.append(nxt)
    if nxt == dp[p2] * 2:
        p2 += 1
    if nxt == dp[p3] * 3:
        p3 += 1
    if nxt == dp[p5] * 5:
        p5 += 1
return dp[-1]
```

注意三个 `if` 是并列的，不是 `elif`——当 `nxt` 同时等于两个乘积时（如 `nxt=6` 时 `dp[2]*2` 和 `dp[1]*3` 都等于 6），两个指针都要前进，否则会重复追加 6。

## 复杂度
时间：O(n)，每轮只做常数次乘法和比较，共 n 轮。
空间：O(n)，`dp` 数组存 n 个丑数，三个指针是 O(1)。

## 易错点
- `n = 6` 时，`dp` 应为 `[1,2,3,4,5,6]`。若把三个 `if` 写成 `elif`，`nxt=6` 时只前进 `p2`，`p3` 停在 `dp[1]=2`，下一轮 `dp[p3]*3` 仍是 6，会重复追加 6，得到 `[1,2,3,4,5,6,6]`，第 6 个变成 6 而非正确值。正确做法是三个独立 `if`。
- `n = 1` 时，`while len(dp) < 1` 不进入循环，直接返回 `dp[-1] = 1`。若把循环条件写成 `while len(dp) <= n`，会多算一个丑数，返回第 n+1 个。正确做法是 `< n`，且 `dp` 初始已含 1。

## 如果面试官追问
问：n 上限提到 10^6 怎么办？答：DP 仍 O(n)，但 `dp` 占 8MB 左右可接受；若要 O(1) 空间需用堆+哈希去重，时间变 O(n log n)。
