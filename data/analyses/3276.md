## 一句话思路
按值从大到小做 0/1 背包式状压 DP，`dp[mask]` 表示已占用行集合为 mask 时的最大得分。

## 怎么做
1. 把每个值映射到它能放的行集合 `rows[v]`（bit i 表示第 i 行含值 v），值域 1..100。
2. 值从 100 倒序到 1，对每个值尝试放进 mask 中尚未占用的行。
3. 转移 `dp[mask | (1<<i)] = max(..., dp[mask] + v)`，要求 `rows[v]` 含 i 且 mask 不含 i。
4. 答案取所有 dp 值的最大值（可只选一个单元格）。

以示例 1 为例：`rows[4]={1}`，`rows[3]={0,1}`，`rows[2]={0,2}`，`rows[1]={0,1,2}`。处理值 4 时 `dp[{1}]=4`；处理值 3 时从 `mask={1}` 出发只能放行 0，得 `dp[{0,1}]=7`；处理值 1 时从 `mask={0,1}` 出发放行 2，得 `dp[{0,1,2}]=8`。

```python
n = len(grid)
rows = {}
for i in range(n):
    for v in grid[i]:
        rows[v] = rows.get(v, 0) | (1 << i)
dp = [-1] * (1 << n)
dp[0] = 0
for v in range(100, 0, -1):
    if v not in rows:
        continue
    for mask in range((1 << n) - 1, -1, -1):
        if dp[mask] < 0:
            continue
        avail = rows[v] & ~mask
        while avail:
            b = avail & -avail
            nm = mask | b
            if dp[nm] < dp[mask] + v:
                dp[nm] = dp[mask] + v
            avail ^= b
return max(dp)
```

## 复杂度
时间：O(100 · 2^n · n)，n = 行数 ≤ 10，值域 100 是常数因子。
空间：O(2^n)，dp 数组大小 2^n，rows 字典最多 100 项。

## 易错点
- 值有重复时若按「每个单元格」而非「每个值」建 rows，会把同一值在不同行的信息合并错：例如 grid 中值 3 出现在行 0 和行 1，`rows[3]` 必须是 `0b11` 而非只记一行，否则漏掉可选行。
- 内层 mask 必须从大到小遍历，否则同一值会被重复使用（一个值只能用一次）；写成从小到大会让 `dp[mask]` 被本值更新后再转移，得分虚高。

## 如果面试官追问
问：若要求输出具体选了哪些单元格？
答：额外开 `parent[mask]` 记录转移来源的行和值，从最优 mask 回溯即可。
