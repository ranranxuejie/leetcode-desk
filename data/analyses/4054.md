## 一句话思路
用单调栈维护「从栈底到栈顶严格递增」的下标序列，每个新元素弹掉比它大的，剩下的栈顶就是它唯一的影子前驱。

## 怎么做
1. 从左到右扫 `nums`，栈 `st` 存下标，保证 `nums[st[0]] < nums[st[1]] < ...`（严格递增）。
2. 对每个 `j`，先 `while st and nums[st[-1]] >= nums[j]: st.pop()`，把「不小于 `nums[j]`」的候选全清掉。
3. 弹完后若 `st` 非空，`st[-1]` 就是唯一合法的 `i`，答案 `+1`；然后 `st.append(j)`。
4. 关键中间值：以 `nums = [3,1,4,1,5]` 为例，扫到 `j=4`（值 5）时栈是 `[1,3]`（值 1,1），`nums[2]=4` 早被 `j=3` 的 1 弹掉，所以 `st[-1]=3` 贡献 `(3,4)`，而不是 `(1,4)` 之外的任何对。

```python
st = []
ans = 0
for j, x in enumerate(nums):
    while st and nums[st[-1]] >= x:
        st.pop()
    if st:
        ans += 1
    st.append(j)
return ans
```

为什么「只剩栈顶一个」：条件要求 `i` 与 `j` 之间没有比 `nums[i]` 更小的元素，即 `nums[i]` 是区间 `(i, j)` 的最小值；而栈里保留下来的下标，恰好是「到当前位置为止的严格递增后缀最小值链」，链上每个元素都满足「其后到 `j` 之间无更小值」，但只有最靠右的那个（栈顶）与 `j` 之间没有别的链上元素，其余都会被中间那个更小的值挡住。

## 复杂度
时间 O(n)：每个下标入栈出栈各一次，`while` 总弹出次数 ≤ n。
空间 O(n)：`st` 最坏存 n 个下标（如 `[1,2,3,4]` 全递增时）。

## 易错点
- 写成 `nums[st[-1]] > x` 才弹：`nums = [6,7,6,6,7]` 扫到 `j=2`（值 6）时栈顶 `nums[1]=7` 不弹，`st[-1]=1` 贡献 `(1,2)`，但 `6 < 7` 不成立，答案多算。必须用 `>=`，等值也要弹。
- 弹完不判空直接取 `st[-1]`：`nums = [3,1,4,1,5]` 扫到 `j=1`（值 1）时栈被清空，`st[-1]` 抛 `IndexError` 或（若用 `st[-1] if st else -1`）把 `i=-1` 算进去。正确做法是先 `if st: ans += 1` 再 `append`。

## 如果面试官追问
若要求输出所有影子对而非计数，怎么改？答：把 `ans += 1` 换成 `res.append((st[-1], j))`，栈结构不变，输出规模可能 O(n²)，需按输出量计复杂度。
