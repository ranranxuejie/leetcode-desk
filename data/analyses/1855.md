## 一句话思路
两个数组都非递增，用双指针 i、j 单向扫描，i 只在 nums1[i] > nums2[j] 时前进，j 始终前进，一次遍历取最大 j-i。

## 怎么做
1. 初始化 `i = j = ans = 0`。
2. 当 `i < len(nums1) and j < len(nums2)` 时循环：若 `nums1[i] <= nums2[j]`，更新 `ans = max(ans, j - i)` 并 `j += 1`；否则 `i += 1`。
3. 循环结束返回 `ans`。

以示例 1 为例，`nums1 = [55,30,5,4,2]`、`nums2 = [100,20,10,10,5]`：`i=0,j=0` 时 `55<=100`，`ans=0`，`j=1`；`55>20`，`i=1`；`30>20`，`i=2`；`5<=20`，`ans=1`，`j=2`；`5<=10`，`ans=1`，`j=3`；`5<=10`，`ans=1`，`j=4`；`5<=5`，`ans=max(1,4-2)=2`，`j=5` 结束。关键中间值是 `i=2` 时 `j` 一路推到 4，距离 2。

```python
i = j = ans = 0
n1, n2 = len(nums1), len(nums2)
while i < n1 and j < n2:
    if nums1[i] <= nums2[j]:
        ans = max(ans, j - i)
        j += 1
    else:
        i += 1
return ans
```

为什么 i 只增不回退：`nums1` 非递增，`nums1[i] > nums2[j]` 说明当前 i 对任何 `j' >= j` 都更不可能满足（`nums2[j']` 只会更小），所以 i 可以永久丢弃。

## 复杂度
时间 O(n1 + n2)：i、j 各自单调前进，总步数不超过两数组长度之和。
空间 O(1)：只开了 i、j、ans 三个变量。

## 易错点
1. 输入 `nums1 = [2,2,2]`、`nums2 = [10,10,1]`：若在 `nums1[i] <= nums2[j]` 时只更新 ans 不推进 j，会卡在 `(0,0)` 得 0；正确做法是满足条件就 `j += 1`，让 j 继续右移找更远距离，得 1。
2. 输入 `nums1 = [30,29,19,5]`、`nums2 = [25,25,25,25,25]`：若写成 `nums1[i] < nums2[j]` 用严格小于，`i=2,j=2` 时 `19<25` 成立但 `i=3,j=4` 时 `5<25` 也成立，看似没事，但遇到相等值如示例 1 的 `5<=5` 会漏掉 `(2,4)` 得 1；必须用 `<=`，得 2。

## 如果面试官追问
问：若 nums2 不是非递增，还能双指针吗？
答：不能，j 无法单调推进，需对每个 i 在 nums2 上二分找最右满足 `nums2[j] >= nums1[i]` 的位置，复杂度 O(n1 log n2)。
