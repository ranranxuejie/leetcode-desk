## 一句话思路
先统计冲突位置（nums1[i]==nums2[i]）里各值的频次，用「冲突内配对交换」消掉大部分，剩下的用最小下标 0 兜底。

## 怎么做
1. 扫描所有 i，把 `nums1[i]==nums2[i]` 的下标计入冲突集合，同时用 `cnt` 统计冲突位置上 nums1 的值频次，记冲突总数 `m`、最大频次 `mx`。
2. 若 `mx > m - mx`，说明某值占多数，无法在冲突内部两两配对，返回 -1（示例 3：值 2 出现 2 次，m=3，2 > 1，无解）。
3. 否则冲突内部可两两交换消解，每对代价为两下标之和；把冲突下标排序，用最小的一半与最大的一半配对（小配大，总和最小）。
4. 若 m 为奇数，剩一个冲突下标 j，必须借一个非冲突下标 k 中转：交换 (j,k) 再 (k,某冲突位)，代价 `j + 2k`，取最小可用 k（通常是 0 或最小的非冲突下标）。

以示例 1 为例：冲突下标 `[0,1,2,3,4]`，m=5，排序后配对 (0,4)、(1,3)，剩 2；非冲突下标不存在，只能借 0 中转，代价 `2 + 2*0 = 2`，总计 `(0+4)+(1+3)+2 = 10`。

```python
conflict = [i for i in range(n) if nums1[i] == nums2[i]]
m = len(conflict)
cnt = {}
for i in conflict:
    cnt[nums1[i]] = cnt.get(nums1[i], 0) + 1
mx = max(cnt.values(), default=0)
if mx > m - mx:
    return -1
conflict.sort()
cost = 0
half = m // 2
for t in range(half):
    cost += conflict[t] + conflict[m - 1 - t]
if m % 2:
    j = conflict[half]
    free = [i for i in range(n) if nums1[i] != nums2[i]]
    k = min(free) if free else 0
    cost += j + 2 * k
return cost
```

## 复杂度
时间：O(n + m log m)，排序冲突下标贡献 log m，扫描贡献 n。
空间：O(m)，存冲突下标列表与频次哈希表。

## 易错点
- 示例 2 中冲突下标是 `[1,2]`（值 2 出现两次），若只按值配对而不看下标，会漏掉「值 2 占多数但 m=2 恰好可配」的判断，误返回 -1；正确做法是比 `mx` 与 `m-mx`，2 不大于 0 才继续。
- m 为奇数时若直接返回 -1 或忽略余项，示例 1 会算成 8；正确做法是补 `j + 2k`，且 k 要取最小非冲突下标，k=0 时该项退化为 j。

## 如果面试官追问
问：若要求输出具体交换序列而非仅代价？
答：配对时记录每对 (小下标, 大下标) 的交换，奇数余项记录 (j,k) 与 (k,冲突位) 两次交换，按序输出即可。
