## 一句话思路
用二维 DP：`dp[i][j]` 表示走到 `(i,j)` 能拿到的最大价值，因为只能从上方或左方来，取两者较大值加当前格即可。

## 怎么做
1. 原地复用 `frame` 作为 DP 表，避免额外开矩阵。
2. 先处理第一行：`frame[0][j] += frame[0][j-1]`，因为只能一路从左边来。
3. 再处理第一列：`frame[i][0] += frame[i-1][0]`，因为只能一路从上边来。
4. 其余格子按行优先遍历，`frame[i][j] += max(frame[i-1][j], frame[i][j-1])`。

以官方示例 `[[1,3,1],[1,5,1],[4,2,1]]` 为例，处理到 `(1,1)` 时，`frame[0][1]=4`、`frame[1][0]=2`，取较大值 4 加上原值 5，得 `frame[1][1]=9`；最终 `frame[2][2]=12`。

```python
rows, cols = len(frame), len(frame[0])
for j in range(1, cols):
    frame[0][j] += frame[0][j - 1]
for i in range(1, rows):
    frame[i][0] += frame[i - 1][0]
for i in range(1, rows):
    for j in range(1, cols):
        frame[i][j] += max(frame[i - 1][j], frame[i][j - 1])
return frame[rows - 1][cols - 1]
```

## 复杂度
时间：O(rows × cols)，每个格子访问一次。
空间：O(1) 额外空间，原地修改 `frame`。

## 易错点
1. 输入 `frame = [[0]]`（单格）→ 若循环从 `range(1, rows)` 开始且没单独返回，会漏掉起点值 → 正确做法是直接返回 `frame[0][0]`，或保证边界循环不越界后统一返回右下角。
2. 输入只有一行如 `[[1,3,1]]` → 若先跑双重循环再补边界，`frame[i-1]` 会索引到 `-1` 取到最后一行 → 正确做法是先处理第一行和第一列，再进入 `i,j` 都从 1 开始的主循环。

## 如果面试官追问
问：要求输出具体路径而不只是最大值怎么办？
答：另开 `parent` 矩阵记录每格来自上还是左，从右下角回溯到左上角即可。
