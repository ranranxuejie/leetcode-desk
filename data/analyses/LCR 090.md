## 一句话思路
环形约束只需拆成「不偷首」和「不偷尾」两条线性链，各跑一遍打家劫舍取较大值。

## 怎么做
1. 特判 `len(nums) == 1`，直接返回 `nums[0]`，否则下面的切片会得到空数组。
2. 写一个线性辅助函数 `line(arr)`：用 `prev2, prev1` 滚动，`cur = max(prev1, prev2 + x)`。
3. 答案取 `max(line(nums[1:]), line(nums[:-1]))`，两条链分别排除了首尾相邻冲突。

以 `nums = [2,3,2]` 为例：`line([3,2])` 得 3，`line([2,3])` 得 3，取 max 为 3。关键中间值在 `line([3,2])`：处理 3 时 `prev2=0, prev1=3`，处理 2 时 `cur = max(3, 0+2) = 3`，所以返回 3，而不是 5。

```python
def line(arr):
    prev2 = prev1 = 0
    for x in arr:
        prev2, prev1 = prev1, max(prev1, prev2 + x)
    return prev1

n = len(nums)
if n == 1:
    return nums[0]
return max(line(nums[1:]), line(nums[:-1]))
```

注意 `line` 里 `prev2, prev1 = prev1, max(...)` 是同时赋值，右边用的都是旧值，顺序不能拆成两行写反。

## 复杂度
时间：O(n)，两条链各扫一遍，共 2n 次迭代。
空间：O(n)，`nums[1:]` 和 `nums[:-1]` 各复制一份；若改成传下标区间可降到 O(1)。

## 易错点
- 输入 `nums = [2,3,2]` → 若只跑一条链或忘记排除首尾相邻，会返回 5（偷首尾）→ 正确做法是分别排除首和尾，取 `max(line(nums[1:]), line(nums[:-1]))`。
- 输入 `nums = [0]` 或长度 1 的数组 → 切片后 `line([])` 返回 0，若没特判会漏掉唯一元素 → 先判 `n == 1` 直接返回 `nums[0]`。

## 如果面试官追问
问：要求输出具体偷了哪几间房怎么办？
答：在 `line` 里额外记录每步是否选了当前房屋，回溯得到下标集合，再对两条链的结果分别还原后比较。
