## 一句话思路
左右双指针 `i`、`j` 相向走，遇到非字母就跳过，两边都是字母才交换，这样字母相对顺序反转、非字母原地不动。

## 怎么做
1. 把 `s` 转成列表 `a`（Python 字符串不可变），`i = 0`，`j = len(s) - 1`。
2. `while i < j`：若 `a[i]` 不是字母则 `i += 1` 继续；若 `a[j]` 不是字母则 `j -= 1` 继续。
3. 两边都是字母时交换 `a[i], a[j]`，然后 `i += 1; j -= 1`。
4. 循环结束 `return ''.join(a)`。

用示例 2 `s = "a-bC-dEf-ghIj"` 走关键一步：初始 `i=0`（`'a'`）、`j=12`（`'j'`），都是字母，交换后 `a[0]='j'`、`a[12]='a'`，`i=1`、`j=11`；此时 `a[1]='-'` 非字母，`i` 连跳到 2（`'b'`），`j=11` 是 `'I'`，交换得 `a[2]='I'`、`a[11]='b'`。注意 `'-'` 始终没被移动过，位置 1 和 4 的 `-` 原样保留。

```python
a = list(s)
i, j = 0, len(a) - 1
while i < j:
    if not a[i].isalpha():
        i += 1
    elif not a[j].isalpha():
        j -= 1
    else:
        a[i], a[j] = a[j], a[i]
        i += 1
        j -= 1
return ''.join(a)
```

判断字母用 `a[i].isalpha()` 即可：题面保证字符 ASCII 在 [33,122] 且不含 `"`、`\`，不会出现 Unicode 字母干扰；若想更保险可写 `'a' <= c <= 'z' or 'A' <= c <= 'Z'`。

## 复杂度
时间 O(n)：`i`、`j` 各自最多走 n 步，每个字符被访问常数次。
空间 O(n)：`list(s)` 和 `''.join` 各开一份长度 n 的副本，指针只占 O(1)。

## 易错点
- 输入 `"ab-cd"` 时若写成「先过滤出所有字母反转再按原位置填回」，容易把 `-` 的位置也算进字母序列，得到 `"dc-b-a"` 之类；正确做法是双指针只在 `isalpha()` 为真的位置交换，`-` 从头到尾不参与。
- 输入 `"a-bC-dEf-ghIj"` 时若在 `a[i]` 非字母时同时推进 `j`（或反之），会让 `i`、`j` 越过彼此、漏交换中间的字母对；正确做法是 `if/elif` 分支，一次循环只动一个指针，只有交换那一步才同时 `i += 1; j -= 1`。

## 如果面试官追问
问：如果要求 O(1) 额外空间怎么办？答：Python 字符串不可变做不到原地，只能返回新串；换 C 系语言可用 `char*` 原地双指针交换，空间降到 O(1)。
