## 一句话思路
按结束时间排序后，对每个活动二分找「结束时间 < 它开始时间」的最优前缀，拼出两活动最大和。

## 怎么做
1. 把 `events` 按 `endTime` 升序排序，得到 `ev`。
2. 预处理 `best[i]` = 前 `i+1` 个活动（即 `ev[0..i]`）里单个活动的最大 `value`，递推 `best[i] = max(best[i-1], ev[i][2])`。
3. 对每个 `ev[i]`，在 `ev[0..i-1]` 的结束时间上二分找最后一个 `endTime < ev[i][0]` 的下标 `j`（注意是严格小于，因为结束时刻当天不能接）。
4. 若 `j >= 0`，用 `ev[i][2] + best[j]` 更新答案；同时答案初值取 `max(value)` 覆盖只选一个的情况。

以示例 1 `[[1,3,2],[4,5,2],[2,4,3]]` 为例：按结束排序后 `ev = [[1,3,2],[2,4,3],[4,5,2]]`，`best = [2,3,3]`。处理 `ev[2]=[4,5,2]` 时，在 `[3,4]` 里二分找 `< 4` 的最后一个，得 `j=0`，候选 `2 + best[0] = 4`，即答案。

```python
ev = sorted(events, key=lambda e: e[1])
best = []
for s, e, v in ev:
    best.append(max(best[-1], v) if best else v)
ans = best[-1]
ends = [e for _, e, _ in ev]
for i in range(1, len(ev)):
    j = bisect_left(ends, ev[i][0], 0, i) - 1
    if j >= 0:
        ans = max(ans, ev[i][2] + best[j])
```

## 复杂度
时间：排序 `O(n log n)`，每个活动一次二分共 `O(n log n)`，n 为 `events.length`。
空间：`best`、`ends` 各 `O(n)`，二分本身 `O(1)`。

## 易错点
- 输入 `[[1,3,2],[3,5,4]]` → 若二分用 `bisect_right(ends, start)` 会把结束时间等于开始时间的活动算进来，得 6；正确是 `bisect_left(ends, start) - 1`，严格 `< start`，答案 4。
- 输入 `[[1,5,5],[1,5,3]]` → 若只算两活动组合、不把单活动作为初值，会漏掉只选一个的 5；正确做法是 `ans` 初值取 `best[-1]`（全体最大单值）。

## 如果面试官追问
问：要求输出具体是哪两个活动怎么办？
答：`best` 改存下标而非值，二分命中 `j` 时记录 `(j, i)`，最后回溯 `best` 的来源下标即可。
