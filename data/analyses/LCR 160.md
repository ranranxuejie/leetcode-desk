## 一句话思路
用大顶堆存较小的一半、小顶堆存较大的一半，保持两堆大小差不超过 1，中位数只由堆顶决定。

## 怎么做
1. 维护 `lo`（大顶堆，存负数）和 `hi`（小顶堆），约定 `len(lo) == len(hi)` 或 `len(lo) == len(hi) + 1`。
2. `addNum` 先压 `lo`，再把 `lo` 的最大值弹给 `hi`，若 `len(hi) > len(lo)` 再把 `hi` 最小值弹回 `lo`。
3. `findMedian` 按两堆大小分情况取堆顶。
4. 以示例 1 为例：加入 1 后 `lo=[-1]`、`hi=[]`；加入 2 时先压 `lo` 得 `[-2,-1]`，弹出 `-1` 给 `hi`，此时 `lo=[-2]`、`hi=[1]`，`findMedian` 返回 `(-(-2)+1)/2 = 1.5`。

```python
import heapq

def addNum(self, num):
    heapq.heappush(self.lo, -num)
    heapq.heappush(self.hi, -heapq.heappop(self.lo))
    if len(self.hi) > len(self.lo):
        heapq.heappush(self.lo, -heapq.heappop(self.hi))

def findMedian(self):
    if len(self.lo) > len(self.hi):
        return float(-self.lo[0])
    return (-self.lo[0] + self.hi[0]) / 2.0
```

## 复杂度
时间：`addNum` 为 O(log n)（三次堆操作），`findMedian` 为 O(1)。
空间：O(n)，两个堆合计存 n 个元素。

## 易错点
- 只往 `lo` 压不往 `hi` 转移 → 输入 `[1,2,3]` 时 `lo=[-3,-2,-1]`、`hi=[]`，`findMedian` 返回 3 而不是 2；正确做法是每次压完立刻把 `lo` 堆顶弹给 `hi`，再按大小差回补。
- 回补条件写成 `len(hi) >= len(lo)` → 输入 `[1,2]` 时两堆变成 `lo=[]`、`hi=[1,2]`，取 `lo[0]` 直接 IndexError；正确做法是只在 `len(hi) > len(lo)` 时回弹，保证 `lo` 永不为空。

## 如果面试官追问
问：数据全部给定、要求一次返回所有前缀的中位数？答：先离线离散化 + 树状数组求第 k 小，O(n log n) 一次扫完，省掉堆的常数。
