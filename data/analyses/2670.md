## 一句话思路
正序扫一遍记前缀去重数、倒序扫一遍记后缀去重数，两次哈希表各 O(n)，再逐位相减。

## 怎么做
1. 正序扫 `nums`，用 `seen` 集合维护已见元素，`pre[i] = len(seen)` 表示 `nums[0..i]` 的去重数。
2. 倒序扫 `nums`，清空 `seen`，`suf[i] = len(seen)` 表示 `nums[i..n-1]` 的去重数（注意含 `i` 本身）。
3. 答案 `diff[i] = pre[i] - suf[i+1]`，`i = n-1` 时 `suf[n]` 视为 0（空后缀）。

以 `nums = [3,2,3,4,2]` 为例：正序得 `pre = [1,2,2,3,3]`；倒序时 `i=2` 扫到 `nums[2..4]=[3,4,2]`，`seen={3,4,2}`，`suf[2]=3`，而 `suf[3]=2`（`{4,2}`）。于是 `diff[2] = pre[2] - suf[3] = 2 - 2 = 0`，与示例一致。

```python
n = len(nums)
pre = [0] * n
seen = set()
for i, x in enumerate(nums):
    seen.add(x)
    pre[i] = len(seen)

suf = [0] * (n + 1)          # suf[n] = 0，空后缀
seen.clear()
for i in range(n - 1, -1, -1):
    seen.add(nums[i])
    suf[i] = len(seen)

return [pre[i] - suf[i + 1] for i in range(n)]
```

关键点：`suf` 开 `n+1` 长度，把「空后缀」这个边界直接变成数组下标 `n`，省掉 `if i == n-1` 的分支。

## 复杂度
时间 O(n)：正序、倒序各扫一次，集合插入均摊 O(1)。
空间 O(n)：`pre`、`suf` 各 n+1，`seen` 最多 n 个不同值。

## 易错点
- `nums = [1,1,1]`：若把后缀定义成 `nums[i+1..n-1]` 却仍用 `suf[i]` 去减，`diff[0]` 会算成 `1-1=0`，正确是 `1-0=1`（`i=0` 的后缀是 `[1,1]`，去重后 1 个，`diff[0]=1-1=0`… 注意 `i=2` 时后缀为空，必须取 `suf[3]=0`）。统一用 `suf[i+1]` 并让 `suf[n]=0` 就不会错。
- `nums = [3,2,3,4,2]`：倒序扫时若在 `i=2` 处忘记把 `nums[2]=3` 加进 `seen`，`suf[2]` 会得 2 而非 3，`diff[1]` 就从 `-1` 错成 `0`。后缀是闭区间 `[i, n-1]`，`i` 本身必须计入。

## 如果面试官追问
问：n 放大到 10^5、nums[i] 到 10^9 还这么做吗？
答：一样，哈希表与值域无关，仍是 O(n) 时间 O(n) 空间，只是别用计数数组。
