## 一句话思路
一次遍历同时求总和、最小值、最大值，用 `(总和 - 最小 - 最大) / (n - 2)` 直接得答案，无需排序。

## 怎么做
1. 初始化 `total = 0`、`lo = 10**6 + 1`、`hi = 10**3 - 1`（用提示里的边界外扩一格，避免依赖 `salary[0]`）。
2. 遍历 `salary`，每个 `x` 累加进 `total`，并用 `min`/`max` 更新 `lo`、`hi`。
3. 返回 `(total - lo - hi) / (len(salary) - 2)`，Python 的 `/` 已是浮点除法，直接满足 1e-5 误差。

以示例 1 `salary = [4000,3000,1000,2000]` 为例，遍历结束 `total = 10000`、`lo = 1000`、`hi = 4000`，`(10000 - 1000 - 4000) / 2 = 2500.0`。

```python
total = 0
lo, hi = 10**6 + 1, 10**3 - 1
for x in salary:
    total += x
    if x < lo:
        lo = x
    if x > hi:
        hi = x
return (total - lo - hi) / (len(salary) - 2)
```

关键点：只减一次最小、一次最大。题目保证 `salary[i]` 唯一，所以不存在「最小值出现两次该减几次」的歧义；若改成允许重复，这个写法依然正确，因为减的是值不是下标。

## 复杂度
时间 O(n)：一次遍历，n 为 `salary` 长度，无排序的 O(n log n)。
空间 O(1)：只开了 `total`、`lo`、`hi` 三个标量。

## 易错点
- 用 `sorted(salary)[1:-1]` 再求平均：示例 3 的 6 个元素会多一次 O(n log n) 排序，n=100 虽不超时，但面试官会追问能否 O(n)；正确做法是单次遍历维护 `lo`/`hi`。
- 把 `lo`/`hi` 初始化成 `0`：`salary[i]` 最小是 1000，若写 `lo = 0` 则 `lo` 永远不被更新，示例 1 会算成 `(10000 - 0 - 4000)/2 = 3000`，错成 3000 而非 2500；正确做法是用 `10**6 + 1` 和 `10**3 - 1` 这种严格越界的初值。
- 分母写成 `len(salary)`：示例 2 三个元素会得 `(6000-1000-3000)/3 ≈ 666.67`，正确是除以 `n - 2 = 1` 得 2000。

## 如果面试官追问
若 `salary` 长度放大到 10^7 且内存受限、只能流式读入，怎么办？答：本解法本来就是单遍流式，只需维护 `total`、`lo`、`hi` 和计数，O(1) 空间不变。
