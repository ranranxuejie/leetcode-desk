## 一句话思路
排序后固定第一个数，用左右双指针夹逼逼近 target，因为有序数组里和的大小随指针移动单调变化。

## 怎么做
1. 先 `nums.sort()`，让双指针的移动方向有单调性。
2. 外层 `i` 从 0 到 n-3，内层 `l = i+1`、`r = n-1`，每次算 `s = nums[i] + nums[l] + nums[r]`。
3. `s < target` 时 `l += 1`（增大和），`s > target` 时 `r -= 1`（减小和），`s == target` 直接返回。
4. 每步用 `abs(s - target)` 更新 `best`，最后返回 `best`。

以 `nums = [-1,2,1,-4], target = 1` 为例：排序后 `[-4,-1,1,2]`。`i=0` 取 `-4`，`l=1` 得 `-1`，`r=3` 得 `2`，`s = -4 + (-1) + 2 = -3`，`abs(-3-1)=4`，`best=-3`；`s < target` 故 `l` 右移到 `1`，`s = -4+1+2 = -1`，`abs(-1-1)=2`，`best=-1`；`l` 再右移到 `2`，`l == r` 停。`i=1` 取 `-1`，`l=2`、`r=3`，`s = -1+1+2 = 2`，`abs(2-1)=1`，`best=2`，返回 2。

```python
nums.sort()
best = nums[0] + nums[1] + nums[2]
for i in range(len(nums) - 2):
    l, r = i + 1, len(nums) - 1
    while l < r:
        s = nums[i] + nums[l] + nums[r]
        if abs(s - target) < abs(best - target):
            best = s
        if s < target:
            l += 1
        elif s > target:
            r -= 1
        else:
            return s
return best
```

## 复杂度
时间 O(n²)：排序 O(n log n)，外层 n 乘内层双指针 n。
空间 O(1)：只开了 `best`、`l`、`r` 几个变量，排序原地。

## 易错点
- `best` 初始化成 `0` 或 `2**31 - 1` → 当所有三数和都远离 target（如 `nums=[1,1,1], target=100`）时，`abs(0-100)=100` 可能被误判更近，或返回哨兵值。正确做法是用真实存在的 `nums[0]+nums[1]+nums[2]` 初始化。
- 内层写成 `while l <= r` → `l == r` 时 `nums[l]` 和 `nums[r]` 是同一元素，三数里出现重复下标，和偏小。正确做法是 `while l < r`，保证三个下标互不相同。

## 如果面试官追问
问：要求返回所有和最接近 target 的三元组方案怎么办？
答：`best` 改成记录最小差值，命中时把 `(nums[i],nums[l],nums[r])` 收进集合，差值更小时清空重收，最后去重输出。
