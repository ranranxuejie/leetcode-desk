## 一句话思路
把 m×n 个格子压成一维下标，用哈希表把「已翻转位置」映射到「末尾未翻转位置」，实现 O(1) 等概率抽样。

## 怎么做
1. 维护 `total = m * n` 表示当前剩余空格数，`used = {}` 记录被占位的一维下标到替换值的映射。
2. 每次 flip 取 `k = random.randrange(total)`，若 `k` 在 `used` 中则用 `used[k]` 替换。
3. 把 `used[k]` 指向 `total - 1`（末尾元素），然后 `total -= 1`，相当于把末尾元素搬到 k 的位置。
4. 返回 `[k // n, k % n]`；reset 时清空 `used` 并恢复 `total = m * n`。

以官方示例 `m=3, n=1` 为例：第一次 flip 取 `k=1`，`used` 为空，令 `used[1]=2`，`total` 变 2，返回 `[1,0]`；第二次取 `k=1`，命中 `used[1]=2`，令 `used[1]=1`（即 `total-1`），`total` 变 1，返回 `[2,0]`；第三次只能取 `k=0`，返回 `[0,0]`。

```python
import random

def flip(self):
    k = random.randrange(self.total)
    real = self.used.get(k, k)
    self.used[k] = self.used.get(self.total - 1, self.total - 1)
    self.total -= 1
    return [real // self.n, real % self.n]

def reset(self):
    self.used.clear()
    self.total = self.m * self.n
```

关键在 `self.used[k] = self.used.get(self.total - 1, self.total - 1)`：末尾元素可能本身也被映射过，必须取它的真实值再写入，否则会指向一个已翻转的格子。

## 复杂度
时间：flip 均摊 O(1)，哈希表单次查找；reset O(1) 清空。
空间：`used` 最多存 min(flip 次数, m*n) 个键值对，额外 O(k)。

## 易错点
- 当 `total - 1` 本身已在 `used` 中时，直接写 `used[k] = total - 1` 会让 k 指向一个已翻转格子，导致重复返回。正确做法是先 `used.get(total-1, total-1)` 取真实值。
- 当 `k == total - 1` 时（抽中末尾），`used[k]` 会写成自己，虽然结果正确但会多占一个键；更隐蔽的是若此时 `total-1` 已被映射，仍要取真实值，否则后续抽样会拿到错误下标。

## 如果面试官追问
若 m、n 都到 10^9 但 flip 次数仍很小，怎么办？答：一维压缩 + 哈希表方案不变，空间只与 flip 次数相关，与 m*n 无关。
