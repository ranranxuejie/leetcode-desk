## 一句话思路
反复用 2、3、5 整除 n，除完若剩 1 则是丑数，否则含其他质因数。

## 怎么做
1. 先判 `n <= 0`：丑数定义是正整数，负数与 0 直接返回 `False`。
2. 对 `d in (2, 3, 5)` 依次用 `while n % d == 0: n //= d` 剥掉这个质因数。
3. 循环结束后看 `n == 1`：是则所有质因数都在 {2,3,5} 内，返回 `True`；否则残留了别的质因数，返回 `False`。

以 `n = 14` 为例：`14 % 2 == 0`，`n` 变成 `7`；`7 % 2 != 0` 跳出，`7 % 3`、`7 % 5` 都不为 0，最后 `n == 7 != 1`，返回 `False`，残留的 7 就是那个非法质因数。再以 `n = 6` 为例：被 2 除一次得 `3`，被 3 除一次得 `1`，返回 `True`。

```python
if n <= 0:
    return False
for d in (2, 3, 5):
    while n % d == 0:
        n //= d
return n == 1
```

关键点：`while` 而不是 `if`。`n = 8` 要连除三次 2 才到 1，用 `if` 只除一次会剩 4，误判成 `False`。

## 复杂度
时间：O(log n)，每轮除法至少把 n 减半，最多约 log₂n 次。
空间：O(1)，只用 n 和循环变量 d，没开额外容器。

## 易错点
- 输入 `n = 0` 或 `n = -6` → 若省掉 `n <= 0` 的判断，`0 % 2 == 0` 会进死循环（0 永远除不完），负数则 `-6 // 2 = -3` 一路除下去结果不可控 → 正确做法是第一行就 `return False`。
- 输入 `n = 8` → 若把内层写成 `if n % d == 0: n //= d`，只除一次剩 4，最后 `4 != 1` 误判 `False` → 必须用 `while` 把同一质因数除干净。

## 如果面试官追问
问：如果要判断 1 到 n 里有多少个丑数？
答：改用三指针 DP，`dp[i] = min(dp[p2]*2, dp[p3]*3, dp[p5]*5)`，谁被选中谁指针后移，O(n) 时间。
