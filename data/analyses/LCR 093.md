## 一句话思路
用哈希表存值到下标的映射，枚举前两项 `(i, j)` 并沿 `arr[i]+arr[j]` 往后跳，边跳边计数。

## 怎么做
1. 建 `pos = {v: i for i, v in enumerate(arr)}`，把每个值映射到下标。
2. 枚举所有 `i < j` 作为序列的前两项，`length = 2`，`a, b = arr[i], arr[j]`。
3. 循环：若 `a + b` 在 `pos` 中且下标大于 `j`，则 `length += 1`，`a, b = b, a + b`，否则跳出。
4. 用 `best = max(best, length)` 记录，最后返回 `best if best >= 3 else 0`。

以 `arr = [1,2,3,4,5,6,7,8]` 为例，取 `i=0, j=1` 即 `a=1, b=2`：`a+b=3` 在 `pos` 中，`length` 变 3，`a,b` 变 `2,3`；再得 `5`、`8`，`length` 到 5；下一步 `13` 不在表里，停。这条链就是 `[1,2,3,5,8]`。

```python
pos = {v: i for i, v in enumerate(arr)}
best = 0
for i in range(len(arr)):
    for j in range(i + 1, len(arr)):
        a, b, length = arr[i], arr[j], 2
        while a + b in pos and pos[a + b] > j:
            a, b = b, a + b
            length += 1
        best = max(best, length)
return best if best >= 3 else 0
```

关键在 `pos[a + b] > j` 这个下标检查：`arr` 严格递增，所以值在表里就说明下标唯一，但必须保证新元素排在 `b` 之后，否则拼出来的不是子序列。

## 复杂度
时间：外层 `O(n^2)` 对，每对最多跳 `O(log(max arr))` 步，总计 `O(n^2 log max)`。
空间：`pos` 字典存 `n` 个键值对，`O(n)`。

## 易错点
- 输入 `arr = [1,3,7,11,12,14,18]`：只写 `a + b in pos` 而不检查 `pos[a+b] > j`，会把 `[12, ...]` 这类逆序拼接算进去，长度虚高；正确做法是加上下标单调性判断。
- 输入 `arr = [1,2,4,8]`：没有任何三项满足 `x+y=z`，`best` 停在 2，直接返回 `best` 会输出 2；题目要求不存在时返回 0，必须 `best if best >= 3 else 0`。

## 如果面试官追问
问：`n` 放大到 `10^5` 怎么办？
答：枚举前两项的 `O(n^2)` 不可行，改用 `dp[j][k]` 以最后两项为状态、配合哈希回查，仍是 `O(n^2)` 下界，需换思路或接受近似。
