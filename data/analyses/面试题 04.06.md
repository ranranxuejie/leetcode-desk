## 一句话思路
利用 BST 中序有序，从根往下走，记录最后一个大于 p 的节点即为后继。

## 怎么做
1. 初始化 `succ = None`，`cur = root`，进入循环。
2. 若 `cur.val > p.val`，说明 `cur` 可能是后继，先记 `succ = cur`，再往左找更贴近的。
3. 否则 `cur.val <= p.val`，`cur` 及其左子树都不可能是后继，往右走。
4. 循环结束返回 `succ`。

以示例 1 `root = [2,1,3], p = 1` 为例：`cur=2`，`2 > 1`，记 `succ=2`，`cur` 左移到 1；`1 > 1` 不成立，右移到 `None`，返回 `succ=2`。关键中间值是第一次比较后 `succ` 就被置为 2，之后左子树里没有更大的节点能覆盖它。

```python
succ, cur = None, root
while cur:
    if cur.val > p.val:
        succ = cur
        cur = cur.left
    else:
        cur = cur.right
return succ
```

注意 `p` 是节点引用而非值，比较用 `p.val`；当 `p` 有右子树时，这个循环依然正确——因为 `p` 的右子树所有值都大于 `p.val`，循环会在右子树里一路向左，最终停在右子树最小值，也就是真正的后继。

## 复杂度
时间 O(h)，h 为树高，只沿一条根到叶路径走。
空间 O(1)，只用 `succ`、`cur` 两个指针，无递归栈。

## 易错点
- 输入 `root = [5,3,6,2,4,null,null,1], p = 6` → 若写成「找到 p 就返回其右子树最小值」，`p=6` 无右子树会错返 `None` 之外的祖先；正确做法是全程用 `succ` 记录最后一个大于 `p.val` 的祖先，本例 `succ` 始终为 `None`，返回 `None`。
- 输入 `p` 是叶子且是某祖先的左孩子（如 `p=1` 在 `[2,1,3]`）→ 若只比较 `cur.val == p.val` 就停，会漏掉祖先 `2`；正确做法是不做等值判断，靠 `cur.val > p.val` 分支自然把祖先记进 `succ`。

## 如果面试官追问
追问：若树不是 BST 而是普通二叉树怎么办？
答：中序遍历整棵树，用 `prev` 记录前驱，遍历到 `p` 时把 `prev` 存下，`prev` 即为后继，时间 O(n)。
