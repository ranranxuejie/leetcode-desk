## 一句话思路
逐位取三个数对应位的最小值，用整除和取模从低位到高位拼出结果。

## 怎么做
1. 循环 4 次，每次用 `% 10` 取出 num1、num2、num3 的当前最低位。
2. 对三个位取 `min`，乘上当前权重 `place`（1、10、100、1000）累加到 `key`。
3. 三个数各自 `//= 10`，权重 `place *= 10`，进入下一位。
4. 循环结束返回 `key`；不足四位的数在高位自然取到 0，等价于补前导 0。

以示例 2 的 `num1=987, num2=879, num3=798` 为例：第一轮取位得 `7, 9, 8`，`min=7`，`key=7`，三数变为 `98, 87, 79`；第二轮取位 `8, 7, 9`，`min=7`，`key=77`；第三轮 `9, 8, 7`，`min=7`，`key=777`；第四轮三数都是 0，`min=0`，`key` 仍为 777。

```python
key = 0
place = 1
for _ in range(4):
    d = min(num1 % 10, num2 % 10, num3 % 10)
    key += d * place
    num1 //= 10
    num2 //= 10
    num3 //= 10
    place *= 10
return key
```

关键点：`num1 % 10` 在数被除到 0 之后恒为 0，所以 `num1=1` 时第 2、3、4 轮取到的位都是 0，正好对应 `"0001"` 的高位补零，不需要真的做字符串补零。

## 复杂度
时间：固定 4 轮，每轮常数次取模整除，O(1)。
空间：只用 `key`、`place`、`d` 几个整数，O(1)。

## 易错点
- 输入 `num1=1, num2=10, num3=1000` → 若先把数字转成字符串再按长度对齐，容易把 `"1"` 和 `"1000"` 的左端对齐，得到错误的位组合 → 正确做法是统一从最低位往高位取，短数字高位自动为 0。
- 输入 `num1=1, num2=2, num3=3` → 若只循环到某个数的位数（比如 1 轮）就停，会漏掉高位，但本题高位全是 0 不影响；真正会错的是把结果当字符串 `"0001"` 直接返回 → 题目要求返回整数，必须累加成 `1`，前导 0 不能保留。

## 如果面试官追问
问：如果要求返回补满四位的字符串 `"0001"` 怎么办？
答：把 `key` 累加改成列表收集 4 个 `min` 位，再 `"".join` 反转，或直接 `f"{key:04d}"`。
