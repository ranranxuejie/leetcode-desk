## 一句话思路
最优圆心必可平移到某支飞镖上，故枚举每支飞镖作圆心，统计半径 r 内飞镖数取最大。

## 怎么做
1. 对每支飞镖 `darts[i]` 作为候选圆心，遍历所有飞镖算距离平方。
2. 距离平方 `<= r*r` 即落在靶内，计数。
3. 取所有候选圆心的最大计数返回。

以示例 1 为例，`darts = [[-2,0],[2,0],[0,2],[0,-2]]`，`r = 2`。取 `darts[0] = (-2,0)` 作圆心时，到 `(2,0)` 的距离平方是 `(2-(-2))**2 + 0 = 16`，而 `r*r = 4`，`16 > 4` 不计入；到 `(0,2)` 距离平方 `4+4=8 > 4` 也不计入，只数到自己 1 支。取 `(0,0)` 附近时四支都在 `r=2` 内，得 4。

```python
best = 1
for cx, cy in darts:
    cnt = 0
    for x, y in darts:
        if (x - cx) ** 2 + (y - cy) ** 2 <= r * r:
            cnt += 1
    best = max(best, cnt)
return best
```

关键点：为什么圆心能限制在飞镖上？若最优圆内含 k 支飞镖，把圆心朝其中一支飞镖平移，直到该飞镖落在圆周上，其余飞镖不会因此移出圆（圆在移动中始终覆盖原集合的一个子集边界），故存在以某飞镖为圆心的等优解。因此只需枚举 n 个圆心，每个 O(n) 统计，总 O(n²)。

## 复杂度
时间：O(n²)，外层枚举 n 个圆心，内层扫 n 支飞镖。
空间：O(1)，只用了 `best`、`cnt` 几个标量。

## 易错点
- 用 `sqrt` 比较距离 → 浮点误差导致边界飞镖（距离恰为 r）被误判出界 → 改用距离平方与 `r*r` 比较，全程整数。
- 只枚举飞镖作圆心时漏掉「圆心不在任何飞镖上但覆盖更多」的直觉 → 本题已证明最优解可平移到飞镖上，无需枚举其他点；但若误以为要枚举两圆交点会写复杂且易错。

## 如果面试官追问
问：若 r 很大、n 到 10^5 怎么办？答：此时几乎全覆盖，可先按坐标网格分桶或直接返回 n（当包围盒直径 ≤ 2r 时），否则退化为 O(n²) 不可行，需几何数据结构。
