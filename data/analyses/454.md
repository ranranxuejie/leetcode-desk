## 一句话思路
把四数拆成两对，用哈希表存 `nums1[i]+nums2[j]` 的出现次数，再对 `nums3[k]+nums4[l]` 查相反数。

## 怎么做
1. 先枚举 `nums1` 和 `nums2` 的所有组合，把两数之和作为 key、出现次数作为 value 存进字典 `cnt`。
2. 再枚举 `nums3` 和 `nums4` 的所有组合，对每个和 `s` 去 `cnt` 里查 `-s` 的次数。
3. 把查到的次数累加进 `ans`，返回 `ans`。

以示例 1 为例：`nums1=[1,2]`、`nums2=[-2,-1]`，两两求和得到 `1+(-2)=-1`、`1+(-1)=0`、`2+(-2)=0`、`2+(-1)=1`，所以 `cnt = {-1:1, 0:2, 1:1}`。接着枚举 `nums3=[-1,2]`、`nums4=[0,2]`：`-1+0=-1` 查 `cnt[1]=1`，`-1+2=1` 查 `cnt[-1]=1`，`2+0=2` 查 `cnt[-2]=0`，`2+2=4` 查 `cnt[-4]=0`，累加得 `1+1+0+0=2`，与输出一致。

```python
from collections import defaultdict

cnt = defaultdict(int)
for a in nums1:
    for b in nums2:
        cnt[a + b] += 1

ans = 0
for c in nums3:
    for d in nums4:
        ans += cnt[-(c + d)]
return ans
```

关键点：`cnt` 存的是「和 → 组合个数」，不是集合，因为不同 `(i,j)` 可能算出同一个和，这些都要分别计数。

## 复杂度
时间：O(n²)，两轮双重循环各 n² 次，字典查询 O(1)。
空间：O(n²)，`cnt` 最多存 n² 个不同的和。

## 易错点
1. 用 `set` 存 `nums1[i]+nums2[j]` → 示例 1 中 `0` 出现两次却只算一次，答案得 1 而非 2 → 必须用 `defaultdict(int)` 计次数。
2. 把 `nums1+nums2` 和 `nums3+nums4` 都建成字典再遍历 → 白白多开一个 O(n²) 字典，且要处理 key 不存在的分支 → 只需建一个字典，另一侧边枚举边查 `-(c+d)`。

## 如果面试官追问
问：如果要求输出所有满足条件的元组下标而不是计数？
答：字典 value 改存下标对列表，查到 `-s` 时把两侧下标对做笛卡尔积展开，复杂度升到 O(n² + 答案数)。
