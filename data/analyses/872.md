## 一句话思路
对两棵树各做一次 DFS，把叶子值按左到右顺序收集成列表，再比较两个列表是否相等。

## 怎么做
1. 写一个 `collect(node, out)`：`node` 为 `None` 直接返回，`node.left` 和 `node.right` 都为 `None` 时把 `node.val` 追加进 `out`。
2. 先递归左子树再递归右子树，保证叶子按从左到右的顺序进入 `out`。
3. 分别对 `root1`、`root2` 调用 `collect`，得到 `leaves1`、`leaves2`。
4. 返回 `leaves1 == leaves2`。

以示例 1 的 `root1 = [3,5,1,6,2,9,8,null,null,7,4]` 为例：DFS 走到 `6` 时左右皆空，`leaves1` 变成 `[6]`；接着走到 `2` 的左孩子 `7`、右孩子 `4`，最终 `leaves1 = [6,7,4,9,8]`。`root2` 的叶子顺序也是 `[6,7,4,9,8]`，两列表相等，返回 `True`。

```python
def collect(node, out):
    if node is None:
        return
    if node.left is None and node.right is None:
        out.append(node.val)
        return
    collect(node.left, out)
    collect(node.right, out)

leaves1, leaves2 = [], []
collect(root1, leaves1)
collect(root2, leaves2)
return leaves1 == leaves2
```

注意 `collect` 里叶子判断必须写在两次递归之前并 `return`，否则叶子节点会继续对 `None` 递归（虽然无害，但多一层调用）。

## 复杂度
时间：O(n1 + n2)，两棵树每个结点各访问一次，n 是结点总数。
空间：O(h1 + h2) 递归栈加两个叶子列表，最坏链状树 h = n。

## 易错点
- 把「叶子」误判成「`node` 为空」→ 对 `[1,2,3]` 和 `[1,3,2]` 会收集出空列表或错位值，错判成 `True`；正确做法是只在 `node.left is None and node.right is None` 时取值。
- 先递归右子树再递归左子树 → 示例 1 的 `root1` 会得到 `[8,9,4,7,6]` 这类逆序序列，与 `root2` 比对失败；正确做法是固定「先左后右」，两棵树用同一个 `collect`。

## 如果面试官追问
问：结点数涨到 10^6、内存吃紧怎么办？
答：不建两个列表，用两个显式栈同步做中序式遍历，边出叶子边比对，空间降到 O(h)。
