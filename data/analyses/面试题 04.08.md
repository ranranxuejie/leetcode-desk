## 一句话思路
后序 DFS 返回「子树里找到的 p 或 q」，左右都非空的那个节点就是答案。

## 怎么做
1. 递归函数 `dfs(node)`：`node` 为 `None` 或等于 `p`/`q` 时直接返回 `node`。
2. 分别递归左右子树，拿到 `left` 和 `right`。
3. `left` 和 `right` 都非空 → 当前 `node` 就是分叉点，返回它；否则返回非空的那一个。

以示例 2（`p=5, q=4`）为例：走到 `node=5` 时命中 `p` 直接返回 5，不再往下探 2、7、4；回到 `node=3` 时 `left=5`、`right=None`，返回 5。关键中间值就是 `node=3` 处的 `(left, right) = (5, None)`。

```python
def dfs(node):
    if node is None or node is p or node is q:
        return node
    left = dfs(node.left)
    right = dfs(node.right)
    if left and right:
        return node
    return left or right
```

示例 1 里 `node=3` 处 `(left, right) = (5, 1)`，两者都非空，返回 3。

## 复杂度
时间 O(n)：最坏遍历全部 n 个节点，命中 p/q 后剪枝只是常数优化。
空间 O(h)：递归栈深度等于树高 h，最坏链状树 O(n)，未开额外容器。

## 易错点
- 输入 `p=5, q=4` 且 5 是 4 的祖先 → 若在 `node=5` 处继续往下递归找 4，会误把 4 当分叉点返回 → 正确做法是命中 `p`/`q` 立即返回，靠「祖先节点本身可以是答案」这条定义兜住。
- 输入 `p=5, q=1` → 若用 `left or right` 先于 `left and right` 判断，会在 `node=3` 处直接返回 5 → 必须先判 `if left and right: return node`，再返回单边。

## 如果面试官追问
问：节点值可能重复怎么办？
答：题面保证值唯一，比较用 `is` 比对象身份而非 `==` 比值，重复值也不受影响。
