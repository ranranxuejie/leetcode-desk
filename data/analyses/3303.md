## 一句话思路
用 Z 函数把「s 的每个后缀与 pattern 的公共前缀长度」求出来，再对每个起点检查「前缀匹配 + 跳过 1 位 + 后缀匹配」是否覆盖整个 pattern。

## 怎么做
1. 构造 `t = pattern + '#' + s`，对 `t` 求 Z 数组，则 `z[len(pattern)+1+i]` 就是 `s[i:]` 与 `pattern` 的公共前缀长度。
2. 对每个起点 `i`，令 `p = z[len(pattern)+1+i]`；若 `p == m` 直接返回 `i`（完全相同，改 0 个字符）。
3. 否则看 `s[i+p]` 与 `pattern[p]` 这一位是否不同（不同则相当于在这里改 1 个字符），再要求 `s[i+p+1:]` 与 `pattern[p+1:]` 的公共前缀长度 ≥ `m-p-1`。
4. 第 3 步的后缀匹配用反向串再求一次 Z：对 `pattern[::-1] + '#' + s[::-1]` 求 Z，`zr[len(pattern)+1+(n-i-p-1)]` 即 `s[i+p+1:]` 与 `pattern[p+1:]` 的公共前缀长度。

以 `s = "abcdefg"`, `pattern = "bcdffg"` 为例：`i=1` 时 `p = 4`（`"bcde"` 匹配），`s[5]='f'` 与 `pattern[4]='f'` 相同，说明第 4 位不是「改」的那一位，需继续往后找第一个不同位——所以实际实现里要取「第一个不匹配位置」而非直接取 `p`。更稳的写法：令 `p` 为第一个 `s[i+k] != pattern[k]` 的 `k`，再验证 `s[i+p+1:]` 与 `pattern[p+1:]` 前缀长度 ≥ `m-p-1`。

```python
def zfunc(t):
    n, z = len(t), [0] * len(t)
    l = r = 0
    for i in range(1, n):
        if i < r:
            z[i] = min(r - i, z[i - l])
        while i + z[i] < n and t[z[i]] == t[i + z[i]]:
            z[i] += 1
        if i + z[i] > r:
            l, r = i, i + z[i]
    return z

m, n = len(pattern), len(s)
zf = zfunc(pattern + '#' + s)
zr = zfunc(pattern[::-1] + '#' + s[::-1])
for i in range(n - m + 1):
    p = zf[m + 1 + i]
    if p == m:
        return i
    if p < m and i + p + 1 <= n and zr[m + 1 + (n - i - p - 1)] >= m - p - 1:
        return i
return -1
```

## 复杂度
时间 O(n + m)：两次 Z 函数各扫一遍拼接串，长度分别为 n+m+1。
空间 O(n + m)：两个 Z 数组加两个拼接串，均为线性。

## 易错点
- `s = "dde"`, `pattern = "d"`：若只判断 `p == m` 就返回，会漏掉「子串比 pattern 长、改一位后相等」的情形；本题要求子串长度必须等于 `m`，循环上界必须是 `n - m + 1`，不能是 `n`。
- `s = "ababbababa"`, `pattern = "bacaba"`：若把 `p` 当成「已匹配长度」直接跳过 `p+1` 位，会漏掉 `p` 之后还有连续相同字符的情况；必须显式找第一个不同位，且验证剩余长度 `m-p-1` 时反向 Z 的下标要算成 `n - i - p - 1`，差一位就会越界或错配。

## 如果面试官追问
问：改成「至多 k 个连续字符可改」怎么办？答：把「跳 1 位」换成「跳一段长度 ≤ k 的窗口」，用滑动窗口维护第一个不匹配位置，其余 Z 函数逻辑不变。
