## 一句话思路
排序后从左到右贪心切段：每段从当前最小值起，只要 `nums[i] - nums[start] <= k` 就并入同一段，否则必须新开一段。

## 怎么做
1. 先 `nums.sort()`，把「子序列」的顺序约束消掉——排序后任意连续区间都能按原顺序还原成子序列。
2. 令 `start = 0`、`ans = 1`，`start` 是当前段的段首下标，也是该段最小值。
3. 从 `i = 1` 扫到末尾：若 `nums[i] - nums[start] > k`，说明 `nums[i]` 塞不进当前段，`ans += 1` 并令 `start = i`。
4. 扫完返回 `ans`。

以示例 1 `nums = [3,6,1,2,5], k = 2` 为例：排序得 `[1,2,3,5,6]`。`start=0`（值 1），`i=1` 时 `2-1=1<=2` 并入；`i=2` 时 `3-1=2<=2` 并入；`i=3` 时 `5-1=4>2`，`ans` 变 2、`start=3`（值 5）；`i=4` 时 `6-5=1<=2` 并入。返回 2。

```python
nums.sort()
ans, start = 1, 0
for i in range(1, len(nums)):
    if nums[i] - nums[start] > k:
        ans += 1
        start = i
return ans
```

关键点：比较对象始终是**段首** `nums[start]`，不是前一个元素 `nums[i-1]`。因为段内极差由最小值和最大值决定，段首就是最小值。

## 复杂度
时间：排序 `O(n log n)` 主导，扫描 `O(n)`，合计 `O(n log n)`。
空间：排序栈开销 `O(log n)`，其余只用了 `ans`、`start` 两个变量。

## 易错点
- 输入 `nums = [1,2,3], k = 1`：若拿 `nums[i] - nums[i-1]` 判断，`2-1=1`、`3-2=1` 都通过，会错答 1；正确是比段首，`3-1=2>1` 必须切段，答案 2。
- 输入 `nums = [2,2,4,5], k = 0`：若把「差值 ≤ k」写成 `< k`，`2-2=0` 不满足会多切一段；正确用 `> k` 才切，两个 2 同段，答案 3。

## 如果面试官追问
要求输出具体划分方案怎么办？答：记录每段的 `[start, i)` 下标区间，排序后按区间取原值即可，答案段数不变。
