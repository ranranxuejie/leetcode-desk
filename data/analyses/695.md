## 一句话思路
从每个未访问的 `1` 出发做 DFS，把整块连通陆地染色并计数，取最大值。

## 怎么做
1. 双重循环扫 `grid`，遇到 `grid[i][j] == 1` 就以它为起点启动一次 DFS。
2. DFS 进入格子先把它改成 `0`（原地标记已访问），再向上下左右四个方向递归，返回 `1 + 四个方向返回值之和`。
3. 用 `max_area = max(max_area, dfs(i, j))` 收口，全图扫完返回 `max_area`。

以官方示例 1 为例：扫到 `grid[2][1]`（第 3 行第 2 列那个孤立的 `1`）时，DFS 只返回 1；真正决定答案的是 `grid[3][8]` 那一块——从它出发会依次吞掉 `(3,8)(4,8)(4,9)(4,10)(5,10)` 和 `(3,9)` 共 6 格，`max_area` 从 3 跳到 6。注意 `(2,4)(3,4)(4,4)(3,5)(4,5)` 那块是 5 格，别和 6 搞混。

```python
def dfs(i, j):
    if i < 0 or i >= m or j < 0 or j >= n or grid[i][j] == 0:
        return 0
    grid[i][j] = 0
    return 1 + dfs(i+1, j) + dfs(i-1, j) + dfs(i, j+1) + dfs(i, j-1)

max_area = 0
for i in range(m):
    for j in range(n):
        if grid[i][j] == 1:
            max_area = max(max_area, dfs(i, j))
```

## 复杂度
时间 O(m·n)：每个格子最多被访问一次，越界判断是常数。
空间 O(m·n)：最坏情况（全 1 的蛇形岛）递归栈深度可达 m·n，原地改 `grid` 不额外开 visited。

## 易错点
- 输入 `[[1,1],[1,1]]` → 若只在进入时标记而不在递归前标记，四个格子会互相反复调用导致栈溢出或重复计数 → 必须在 `grid[i][j] = 0` 之后再递归，且越界/为 0 的判断放在最前面。
- 输入全 0 的 `[[0,0,0,0,0,0,0,0]]` → 若把 `max_area` 初始化为 1 或忘了在循环里取 max，会返回 1 → 初始值必须是 0，且只有真正进入 DFS 才更新。

## 如果面试官追问
问：m、n 放大到 10^3 且不允许改原矩阵怎么办？
答：DFS 递归深度会爆栈，改用 BFS 队列 + 额外 `visited` 布尔矩阵，空间仍是 O(m·n) 但栈安全。
