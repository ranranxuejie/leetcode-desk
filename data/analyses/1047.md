## 一句话思路
用栈：新字符与栈顶相同就弹出栈顶（抵消一对），否则压入，扫完栈里剩下的就是答案。

## 怎么做
1. 开一个空列表 `st` 当栈，遍历 `s` 的每个字符 `c`。
2. 若 `st` 非空且 `st[-1] == c`，`st.pop()`；否则 `st.append(c)`。
3. 遍历结束后 `''.join(st)` 即为结果。

以 `s = "abbaca"` 为例，逐个字符走一遍关键中间值：

- `'a'` → `st = ['a']`
- `'b'` → `st = ['a','b']`
- 第二个 `'b'` → 与栈顶 `'b'` 相同，弹出 → `st = ['a']`
- `'a'` → 与栈顶 `'a'` 相同，弹出 → `st = []`
- `'c'` → `st = ['c']`
- `'a'` → `st = ['c','a']`

最终 `''.join(['c','a']) == "ca"`，与示例一致。注意第 4 步：`"abb"` 删掉 `bb` 后，新露出的 `a` 与前面的 `a` 又相邻了，栈的「弹出后栈顶自动变成新邻居」正好处理这种连锁消除，不需要回退指针。

```python
st = []
for c in s:
    if st and st[-1] == c:
        st.pop()
    else:
        st.append(c)
return ''.join(st)
```

关键点：判断条件是 `st and st[-1] == c`，`st` 为空时短路，不会去取 `st[-1]`。栈里存的始终是「当前已扫描前缀消除完毕后的结果」，所以扫到末尾时栈内容就是全局答案。

## 复杂度
时间 O(n)：每个字符最多进栈一次、出栈一次，`n = len(s)`。
空间 O(n)：最坏情况（如 `"abcd"` 无重复）栈里存满 n 个字符。

## 易错点
- 输入 `"abba"` → 若只用「相邻两两比较后拼接再重扫」的朴素做法，删掉 `bb` 得到 `"aa"` 后若忘记再扫一轮，会错成 `"aa"`；正确做法是栈，弹出 `b` 后栈顶 `a` 与新字符 `a` 立刻比较，一步得到 `""`。
- 输入 `"aaaa"` → 若写成 `if st[-1] == c` 而漏掉 `st` 非空判断，第一个字符就会 `IndexError`；正确做法是先 `st and st[-1] == c`，空栈直接 `append`。

## 如果面试官追问
问：若允许删除「任意两个相同字符」（不限相邻），答案怎么变？
答：统计每个字母出现次数的奇偶，奇数个的字母各留一个，按原串顺序拼接即可。
