## 一句话思路
DFS 维护「当前路径上每个值最近出现的深度」，用前缀和差值算长度，回溯时撤销。

## 怎么做
1. 建邻接表，边权存进 `adj[u].append((v, w))`，从 0 出发 DFS，参数带 `(u, parent, depth, dist)`，`dist` 是根到 u 的边权和。
2. 用 `last[val] = 深度` 记录值 val 在当前路径上最深出现位置；进入 u 时，若 `nums[u]` 已出现，则合法路径起点深度被抬到 `last[nums[u]] + 1`，用 `start` 变量维护这个下界（取 max，回溯时恢复旧值）。
3. 当前路径长度 = `dist - prefix[start]`，其中 `prefix[d]` 是深度 d 处节点的根距离；节点数 = `depth - start + 1`。拿它和全局最优比较，长度更大则更新，长度相等则取更少节点数。
4. 递归子节点后，把 `last[nums[u]]` 和 `start` 恢复成进入前的值。

以示例 1 为例，走到节点 5 时路径 0→1→2→5，`nums` 为 2,1,2,1，节点 2 的值 2 与根重复，`start` 被抬到 1，`dist=11`、`prefix[1]=2`，长度 9？不对——实际最长是 2→5 长度 6，说明起点应是节点 2 的深度 2，即 `start = last[2]+1 = 2`，`dist(5)=11`、`prefix[2]=5`，得 6，节点数 `3-2+1=2`，与答案吻合。

```python
def dfs(u, p, depth, dist):
    nonlocal best_len, best_cnt
    old = last.get(nums[u], -1)
    nonlocal_start = start
    if old >= 0:
        start = max(start, old + 1)
    last[nums[u]] = depth
    cur_len = dist - prefix[start]
    cur_cnt = depth - start + 1
    if cur_len > best_len or (cur_len == best_len and cur_cnt < best_cnt):
        best_len, best_cnt = cur_len, cur_cnt
    for v, w in adj[u]:
        if v != p:
            prefix[depth + 1] = dist + w
            dfs(v, u, depth + 1, dist + w)
    last[nums[u]] = old
    start = nonlocal_start
```

## 复杂度
时间 O(n)：每个节点进出各一次，哈希表操作均摊 O(1)。
空间 O(n)：邻接表、`prefix` 数组、`last` 哈希表、递归栈各占 O(n)。

## 易错点
- 输入 `nums = [2,2]`、`edges = [[1,0,8]]`：若忘记「单节点路径长度 0」这一基准，`best_len` 初值设成 -1 或只从子边开始算，会漏掉答案 `[0,1]`；正确做法是初值 `best_len=0, best_cnt=1`，且 DFS 从根 0 进入时就比较一次。
- 回溯时只恢复 `last[nums[u]]` 却忘了恢复 `start`：在示例 1 中从节点 2 的子树退回节点 1 后，`start` 仍停在 2，导致路径 0→1→4 被算成从深度 2 起，长度从 6 缩成 4；正确做法是进入前存 `old_start = start`，退出时一并还原。

## 如果面试官追问
若要求输出具体路径而非长度？答：在更新最优时同步记录 `(u, start)`，回溯后沿 parent 指针从 u 上溯到深度 start 即为路径。
