## 一句话思路
逐层 BFS 收集每层值，每层答案等于「长度 − 置换环个数」，因为一个长度 k 的环最少 k−1 次交换。

## 怎么做
1. BFS 按层遍历，把每层节点的 `val` 收进 `level` 列表。
2. 对 `level` 排序得到 `sorted_level`，建立「值 → 排序后下标」的映射 `pos`。
3. 在 `pos` 上按 `level` 的原始顺序找置换环：`visited` 标记，每找到一个未访问下标就沿 `pos[level[i]]` 走一圈，环长 `c` 贡献 `c-1`。
4. 累加所有层的贡献。

以示例 1 第 3 层为例：`level = [7,6,8,5]`，`sorted_level = [5,6,7,8]`，`pos = {5:0,6:1,7:2,8:3}`。从下标 0 出发：`level[0]=7 → pos[7]=2 → level[2]=8 → pos[8]=3 → level[3]=5 → pos[5]=0`，回到起点，环长 4，贡献 3；下标 1 自环贡献 0。该层共 3 次，与题解一致。

```python
from collections import deque

def layer_cost(level):
    sorted_level = sorted(level)
    pos = {v: i for i, v in enumerate(sorted_level)}
    visited = [False] * len(level)
    cost = 0
    for i in range(len(level)):
        if visited[i]:
            continue
        c, j = 0, i
        while not visited[j]:
            visited[j] = True
            j = pos[level[j]]
            c += 1
        cost += c - 1
    return cost
```

BFS 主体用 `deque`，每层弹出 `len(q)` 个节点，把子节点值入队并同时记入 `level`。

## 复杂度
时间 O(n log n)：每层排序，最坏一层 n 个节点，BFS 本身 O(n)。
空间 O(n)：队列、`level`、`pos`、`visited` 各 O(层宽)，最坏 O(n)。

## 易错点
- 把「交换次数」当成「逆序对个数」→ 示例 1 第 3 层 `[7,6,8,5]` 逆序对是 5，但答案是 3。正确做法是数置换环，`c-1` 才是该环最少交换数。
- 用节点对象而非 `val` 建映射 → 值互不相同才能用 `pos` 字典，若误用 `id(node)` 或节点下标当键，环会断裂。必须用 `level` 里的值本身做键。

## 如果面试官追问
问：如果允许跨层交换呢？
答：跨层交换会破坏层内有序性约束，问题变成全局排序，答案退化为整棵树值的置换环数减层数修正，需重新建模。
