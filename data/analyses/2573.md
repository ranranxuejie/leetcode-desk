## 一句话思路
先按 `lcp[i][j] > 0` 把字符相等的下标并成一组，再逐位贪心取最小可用字母，最后用 DP 校验矩阵。

## 怎么做
1. 合法性初筛：`lcp[i][i]` 必须等于 `n - i`，且 `lcp[i][j] != lcp[j][i]` 直接返回 `""`。
2. 并查集合并：对所有 `i < j` 且 `lcp[i][j] > 0` 的 `(i, j)` 执行 `union(i, j)`，表示 `word[i] == word[j]`。
3. 按 `i` 从 0 到 n-1 贪心：若 `i` 是某组第一个出现的下标，给它分配当前组还没用过的最小字母；否则沿用组内已分配的字母。
4. 用 `f[i][j] = lcp[i][j] + 1 if word[i] == word[j] else 0` 从后往前推，逐格比对 `f[i][j] == lcp[i][j]`，不等则返回 `""`。

以示例 1 的 `lcp` 为例：`lcp[0][2] = 2 > 0` 合并 0 和 2，`lcp[1][3] = 1 > 0` 合并 1 和 3。贪心时 `i=0` 分配 `'a'`，`i=1` 分配 `'b'`，`i=2` 已在 0 的组里沿用 `'a'`，`i=3` 沿用 `'b'`，得到 `"abab"`。

```python
parent = list(range(n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
for i in range(n):
    for j in range(i + 1, n):
        if lcp[i][j] > 0:
            parent[find(i)] = find(j)
word = [''] * n
used = {}
for i in range(n):
    r = find(i)
    if r not in used:
        used[r] = 'a'
    word[i] = used[r]
```

## 复杂度
时间：并查集 O(n² α(n))，DP 校验 O(n²)，总计 O(n²)。
空间：`parent`、`word`、`used` 各 O(n)，DP 若滚动两行则 O(n)，否则 O(n²)。

## 易错点
- 输入 `lcp[3][3] = 3`（示例 3）→ 若不检查对角线就继续贪心，会输出非空串 → 必须先验证 `lcp[i][i] == n - i`，否则直接返回 `""`。
- 输入 `lcp[i][j] > 0` 但 `lcp[i+1][j+1] != lcp[i][j] - 1` → 贪心得到的 `word` 看似合法，DP 校验时才发现不匹配 → 必须用 `f[i][j]` 递推逐格比对，不能只靠并查集。

## 如果面试官追问
问：若 n 扩大到 10⁵ 怎么办？
答：矩阵本身已是 O(n²) 输入，无法再优化，只能按行流式读入并即时校验。
