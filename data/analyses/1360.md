## 一句话思路
把两个日期各自换算成「距 1971-01-01 的天数」再相减，闰年规则用 `y % 4 == 0 and (y % 100 != 0 or y % 400 == 0)` 判定。

## 怎么做
1. 写 `to_days(s)`：`y, m, d = map(int, s.split('-'))`，把年月日拆成三个整数。
2. 累加整年天数：`sum(366 if leap(i) else 365 for i in range(1971, y))`，起点固定 1971 省掉负数处理。
3. 累加当年已过整月天数：用 `[31,28,31,30,31,30,31,31,30,31,30,31]` 逐月加，`m > 2 and leap(y)` 时补 1 天。
4. 最后加 `d`，返回 `abs(to_days(date1) - to_days(date2))`。

以 `date2 = "2019-12-31"` 为例：整年部分从 1971 到 2018 共 48 年，其中闰年 12 个（1972…2016），得 `48*365 + 12 = 17532`；当年 1–11 月累加得 334；再加 31 得 `to_days = 17897`。`date1 = "2020-01-15"` 得 `17912`，差 15，与示例一致。

```python
def leap(y):
    return y % 4 == 0 and (y % 100 != 0 or y % 400 == 0)

def to_days(s):
    y, m, d = map(int, s.split('-'))
    days = sum(366 if leap(i) else 365 for i in range(1971, y))
    md = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
    days += sum(md[:m - 1]) + (1 if m > 2 and leap(y) else 0)
    return days + d

return abs(to_days(date1) - to_days(date2))
```

## 复杂度
时间：O(Y)，Y 为年份跨度，本题 Y ≤ 129，`to_days` 调用两次。
空间：O(1)，只开了长度 12 的月份表 `md`。

## 易错点
- 输入 `"2020-03-01"` → 若只判 `y % 4 == 0` 就把 1900 年当闰年（本题范围含 1900），2 月多算 1 天 → 必须补 `y % 100 != 0 or y % 400 == 0`。
- 输入 `"2020-01-15"` 与 `"2019-12-31"` → 若直接 `to_days(date1) - to_days(date2)` 得负数 → 外层套 `abs`，因为题目不保证 date1 早于 date2。

## 如果面试官追问
问：日期范围扩到 1 年到 9999 年怎么办？
答：整年循环换成公式 `365*(y-1) + (y-1)//4 - (y-1)//100 + (y-1)//400`，O(1) 出结果。
