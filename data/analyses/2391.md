## 一句话思路
总时间 = 所有垃圾字符总数 + 三种垃圾各自「最后一次出现的下标」之前那段 travel 之和，因为每辆车只需开到该种垃圾的最后一站。

## 怎么做
1. 遍历 `garbage`，把每个字符串长度累加进 `ans`，这是收拾垃圾的固定开销，与车怎么开无关。
2. 对 `'M'`、`'P'`、`'G'` 各记一个 `last` 下标，扫一遍 `garbage` 时更新。
3. 对每种垃圾，把 `travel[0:last]` 求和加到 `ans`；`last == 0` 时前缀和为 0，正好表示这辆车不用动。
4. 用前缀和数组 `pre[i] = travel[0]+...+travel[i-1]`，则第 3 步的求和就是 `pre[last]`，避免每种垃圾重复扫 travel。

以示例 1 `garbage = ["G","P","GP","GG"], travel = [2,4,3]` 为例：垃圾总数 = 1+1+2+2 = 6。`'G'` 的 `last = 3`，`pre[3] = 2+4+3 = 9`；`'P'` 的 `last = 2`，`pre[2] = 6`；`'M'` 不存在，`last` 保持 0，贡献 0。合计 6+9+6 = 21。

```python
n = len(garbage)
pre = [0] * n
for i in range(1, n):
    pre[i] = pre[i - 1] + travel[i - 1]

ans = 0
last = {'M': 0, 'P': 0, 'G': 0}
for i, s in enumerate(garbage):
    ans += len(s)
    for c in s:
        last[c] = i

for c in 'MPG':
    ans += pre[last[c]]
```

## 复杂度
时间 O(n + 总字符数)，n 为房子数，每个字符只被看一次。
空间 O(n)，`pre` 数组占 n 个整数，`last` 字典常数大小。

## 易错点
- `garbage = ["G","P","GP","GG"]` 中 `'M'` 从未出现，若把 `last['M']` 初始化成 `n-1` 或漏判，会凭空加上 `pre[3] = 9`，答案错成 30。正确做法是三种垃圾的 `last` 都初始化为 0，`pre[0] = 0` 自动兜底。
- 把 `travel` 当成「每辆车都走完全程」来累加，示例 1 会算成 6 + 9×3 = 33。正确做法是每辆车只加到自己的 `last`，即 `pre[last[c]]`，而不是 `pre[n-1]`。

## 如果面试官追问
问：如果垃圾种类扩展到 k 种（k 很大），怎么做？
答：仍是一次扫描维护 `last` 字典，最后对每个出现过的种类加 `pre[last[c]]`，复杂度 O(n + 总字符数 + k)，与 k 无关的部分不变。
