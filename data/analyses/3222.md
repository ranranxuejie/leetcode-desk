## 一句话思路
每轮固定消耗 1 枚 75 和 4 枚 10，能进行的轮数就是 `min(x, y // 4)`，看奇偶定赢家。

## 怎么做
1. 先确定单轮消耗：115 = 75 + 4×10，所以每轮必须拿 1 枚 75 和 4 枚 10，没有别的组合。
2. 因此可进行的总轮数 `turns = min(x, y // 4)`，与策略无关，双方没有选择空间。
3. Alice 先手，`turns` 为奇数则 Alice 赢，偶数则 Bob 赢。

以示例 2 的 `x = 4, y = 11` 为例：`y // 4 = 2`，`min(4, 2) = 2`，`turns = 2` 是偶数，所以 Bob 赢。关键中间值就是 `turns = 2`，它同时受 `x = 4` 和 `y // 4 = 2` 约束，这里 `y` 是瓶颈。

```python
def winningPlayer(x: int, y: int) -> str:
    turns = min(x, y // 4)
    return "Alice" if turns % 2 == 1 else "Bob"
```

注意 `y // 4` 而不是 `y / 4`，整除才能得到真实可拿的组数。示例 1 的 `x = 2, y = 7`：`y // 4 = 1`，`min(2, 1) = 1`，奇数，Alice 赢，与官方一致。

## 复杂度
时间：O(1)，只做一次整除和一次比较，与 x、y 大小无关。
空间：O(1)，没有开任何额外容器。

## 易错点
- 输入 `x = 1, y = 3` → 若误用 `y / 4` 得 0.75 再取整可能算成 1 轮，实际 `y // 4 = 0`，`turns = 0`，Bob 直接赢 → 正确做法是全程用 `//` 整除。
- 输入 `x = 100, y = 100` → 若只看 `x` 或只看 `y // 4` 会算成 100 或 25 轮，实际 `min(100, 25) = 25`，奇数 Alice 赢 → 正确做法是两者取 min，别漏掉任一硬币的约束。

## 如果面试官追问
问：如果每轮可以拿 0 枚 75 加若干 10 的组合呢？
答：那 115 无法由纯 10 组成，仍需至少 1 枚 75，结论不变。
