## 一句话思路
三指针迭代原地反转：`prev` 记住已反转段头，`cur` 逐个摘下节点插到最前。

## 怎么做
1. 初始化 `prev = None`，`cur = head`，`prev` 始终指向已反转链表的头。
2. 循环中先用 `nxt = cur.next` 暂存后继，否则改完 `cur.next` 就丢了剩余链表。
3. 执行 `cur.next = prev` 把当前节点接到反转段前面，再 `prev, cur = cur, nxt` 双指针前移。
4. `cur` 为 `None` 时循环结束，返回 `prev`（此时它是原链表尾节点）。

以 `head = [1,2,3,4,5]` 为例，第一轮：`nxt = 2`，`cur.next = None`，`prev = 1`，`cur = 2`；第二轮：`nxt = 3`，`2.next = 1`，`prev = 2`，`cur = 3`。走完五轮后 `prev` 指向 5，链为 `5→4→3→2→1`。

```python
prev, cur = None, head
while cur:
    nxt = cur.next
    cur.next = prev
    prev, cur = cur, nxt
return prev
```

空链表时 `while cur` 直接不进入，返回 `prev = None`，正好对应示例 3 的 `[]`。

## 复杂度
时间 O(n)：`cur` 从 head 走到 None，每个节点只被访问一次。
空间 O(1)：只开了 `prev`、`cur`、`nxt` 三个指针，没有新建节点。

## 易错点
- 输入 `[1,2]` 时若先写 `cur.next = prev` 再取后继，`nxt` 已被覆盖成 `None`，第二轮 `cur` 变成 `None` 提前结束，结果只剩 `[1]`。正确做法是先 `nxt = cur.next` 再改指针。
- 输入 `[1]` 时若返回 `head` 而不是 `prev`，返回的是原头节点，其 `next` 已被改成 `None`，看似也对；但输入 `[1,2,3]` 时返回 `head` 得到的是 `1→None`，只剩一个节点。正确做法是循环结束后返回 `prev`，它才是新头。

## 如果面试官追问
追问：要求递归实现怎么办？
答：递归到 `head.next` 为 `None` 时返回该尾节点作新头，回溯时令 `head.next.next = head`、`head.next = None`，空间变 O(n) 栈深。
