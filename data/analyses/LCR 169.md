## 一句话思路
先统计每个字母出现次数，再按原串顺序找第一个计数为 1 的字母，顺序扫描保证「第一个」。

## 怎么做
1. 用 `Counter(arr)` 或长度 26 的数组统计每个字母出现次数。
2. 从左到右遍历 `arr`，遇到 `cnt[ch] == 1` 立即返回 `ch`。
3. 遍历结束仍未返回，则返回 `' '`。

以 `arr = "abbccdeff"` 为例：统计后 `cnt['a']=1, cnt['b']=2, cnt['c']=2, cnt['d']=1, cnt['e']=1, cnt['f']=2`。从头扫描，`arr[0]='a'` 且 `cnt['a']==1`，直接返回 `'a'`，后面的 `'d'`、`'e'` 虽然也只出现一次，但位置更靠后，不会被选中。

```python
from collections import Counter

cnt = Counter(arr)
for ch in arr:
    if cnt[ch] == 1:
        return ch
return ' '
```

关键点：**统计和查找必须分两趟**。如果边遍历边判断，遇到 `'a'` 时还不知道它后面会不会再出现，会误判。两趟扫描把「全局次数」和「首次出现位置」解耦，这是本题的核心结构。

## 复杂度
时间 O(n)：统计一趟 n，查找最坏再一趟 n，n 为 `len(arr)`。
空间 O(1)：字母表仅 26 个小写字母，计数结构大小恒定，与 n 无关。

## 易错点
- 输入 `arr = "ccdd"` → 若只统计不检查返回值，容易返回 `None` 或抛异常 → 正确做法是循环结束后显式 `return ' '`（一个空格字符），不是空字符串 `''`。
- 输入 `arr = "aabb"` 或 `arr = ""` → 若把「没找到」写成返回 `arr[0]` 或依赖默认值，会错成 `'a'` 或下标越界 → 正确做法是空串和全重复串都走同一条兜底路径返回 `' '`，不要对 `arr` 做任何下标访问。

## 如果面试官追问
问：如果 `arr` 长度到 10^7、内存吃紧怎么办？
答：仍用 26 长度的定长数组代替 `Counter`，空间不变，只是常数更小；时间无法低于 O(n)，因为最坏要看完整个串才能确认某字母唯一。
