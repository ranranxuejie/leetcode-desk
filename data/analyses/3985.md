## 一句话思路
用 Manacher 求出每个中心的最长回文半径，再用前缀和取「以该中心能覆盖的最大回文」的和，取最大。

## 怎么做
1. 预处理 `pre[i] = nums[0..i-1]` 的前缀和，`sum(l,r) = pre[r+1]-pre[l]`。
2. 对 `nums` 做 Manacher（奇偶统一插 `#`），得到每个中心的回文半径 `p[i]`。
3. 半径 `p[i]` 对应原数组区间 `[l, r]`，用前缀和算和，更新答案。
4. 单元素回文天然被覆盖（半径至少 1），无需特判。

以 `nums = [1,2,3,2,1,5,6]` 为例：中心在 `3`（原下标 2），Manacher 得半径覆盖 `[0,4]`，`pre = [0,1,3,6,8,9,14,20]`，`sum(0,4)=pre[5]-pre[0]=9`，即答案。

```python
def getSum(nums):
    n = len(nums)
    pre = [0] * (n + 1)
    for i, x in enumerate(nums):
        pre[i + 1] = pre[i] + x
    t = ['#']
    for x in nums:
        t += [str(x), '#']
    m = len(t)
    p = [0] * m
    c = r = 0
    ans = 0
    for i in range(m):
        if i < r:
            p[i] = min(r - i, p[2 * c - i])
        while i - p[i] - 1 >= 0 and i + p[i] + 1 < m and t[i - p[i] - 1] == t[i + p[i] + 1]:
            p[i] += 1
        if i + p[i] > r:
            c, r = i, i + p[i]
        l = (i - p[i]) // 2
        rr = (i + p[i]) // 2
        ans = max(ans, pre[rr + 1] - pre[l])
    return ans
```

## 复杂度
时间：Manacher 线性 O(n)，前缀和 O(n)，共 O(n)。
空间：`p` 与 `t` 各 O(n)，前缀和 O(n)，额外 O(n)。

## 易错点
- 输入 `[1,2,3,4,5]` → 若只按最长回文半径取和，会漏掉单元素 `5` 这个最大和 → 必须让每个中心（含单元素）都参与 `ans` 更新。
- 输入 `[7,1,2,1,7,3,4,3,4]` → 若把 `#` 也当前缀和下标算，`sum` 会错位 → 半径换算回原下标用 `(i±p[i])//2`，前缀和只对原数组建。

## 如果面试官追问
问：若要求输出该最大和对应的子数组下标？
答：在更新 `ans` 时同步记录 `l, rr`，Manacher 已给出区间端点，直接返回即可。
