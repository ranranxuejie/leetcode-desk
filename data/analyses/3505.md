## 一句话思路
先对每个长度 x 的窗口算出「全部变成中位数」的代价，再用 DP 在互不重叠约束下挑 k 个最小代价窗口。

## 怎么做
1. 对每个起点 i，取 `w = sorted(nums[i:i+x])`，代价 `cost[i] = sum(w[x//2] - v for v in w[:x//2]) + sum(v - w[x//2] for v in w[x//2+1:])`，即变成中位数最省。
2. 记 `m = len(nums) - x + 1` 个窗口，`dp[j][i]` = 前 i 个窗口里选 j 个的最小代价，转移 `dp[j][i] = min(dp[j][i-1], dp[j-1][i-x] + cost[i-1])`（选第 i 个窗口则前一个必须结束在 i-x 之前）。
3. 答案 `dp[k][m]`。

以示例 1 为例，`x=3`，窗口起点 1 的 `[−2,1,3]` 排序后中位数 1，代价 `3+0+2=5`；起点 5 的 `[3,6,4]` 中位数 4，代价 `1+2+0=3`；两者不重叠（1..3 与 5..7），合计 8，正是答案。

```python
w = len(nums) - x + 1
cost = []
for i in range(w):
    s = sorted(nums[i:i + x])
    mid = s[x // 2]
    cost.append(sum(abs(v - mid) for v in s))
INF = float('inf')
dp = [[INF] * (w + 1) for _ in range(k + 1)]
for i in range(w + 1):
    dp[0][i] = 0
for j in range(1, k + 1):
    for i in range(1, w + 1):
        dp[j][i] = dp[j][i - 1]
        if i >= x:
            dp[j][i] = min(dp[j][i], dp[j - 1][i - x] + cost[i - 1])
return dp[k][w]
```

## 复杂度
时间：每个窗口排序 `O(x log x)`，共 `O(n x log x)`；DP 是 `O(k n)`。
空间：`cost` 数组 `O(n)`，DP 表 `O(k n)`（可滚动到 `O(n)`）。

## 易错点
- 窗口重叠判断写成 `i - 1` 而非 `i - x`：示例 2 中 `x=2`，窗口 [1,2] 与 [3,4] 相邻不重叠，若用 `i-1` 会误判为重叠，漏掉代价 3 的解，正确是前一个窗口必须整体落在 `i-x` 之前。
- 代价用平均值而非中位数：`[5,-2,1]` 用均值 4/3 算得约 6.67，中位数 1 只需 5，绝对值之和在中位数处最小，用均值会偏大。

## 如果面试官追问
若 k 放大到与 n 同阶怎么办？答：DP 的 `O(kn)` 会退化，需换成分组背包或贪心+堆的窗口选择，本题 k≤15 正是为 DP 留的口子。
