## 一句话思路
排序后双指针模拟每辆车的载客，再回退到最后一辆车的最后一个空位，避开已有乘客的时刻。

## 怎么做
1. 对 `buses` 和 `passengers` 升序排序，指针 `j` 指向下一位待上车乘客。
2. 遍历每辆车 `b`，在 `j < m and passengers[j] <= b` 且未满 `capacity` 时让 `j` 前进，记录最后一辆车装完后 `j` 的位置。
3. 处理最后一辆车：若它没坐满，答案初值取 `buses[-1]`；若坐满了，答案初值取 `passengers[j-1] - 1`。
4. 若该初值恰好等于某位乘客的到达时间（即 `j-1 >= 0 and ans == passengers[j-1]`），再减 1。

以示例 1 为例：`buses=[10,20]`，`passengers=[2,17,18,19]`，`capacity=2`。第一辆车 10 只装下 2，`j=1`；第二辆车 20 装下 17、18，`j=3`，此时车满，答案初值 `passengers[2]-1 = 17`，但 17 是乘客时刻，再减 1 得 16。

```python
buses.sort(); passengers.sort()
j = 0
for b in buses:
    cnt = 0
    while j < len(passengers) and passengers[j] <= b and cnt < capacity:
        j += 1; cnt += 1
    last_full = (cnt == capacity)
ans = buses[-1] if not last_full else passengers[j-1] - 1
if j > 0 and ans == passengers[j-1]:
    ans -= 1
```

## 复杂度
时间：排序 `O(n log n + m log m)`，双指针扫描 `O(n + m)`。
空间：`O(1)` 额外，仅排序栈空间。

## 易错点
- 最后一辆车没坐满时，答案直接取 `buses[-1]`，但若 `buses[-1]` 恰好等于某乘客到达时刻（如 `passengers` 含 20、车 20 出发），会撞车 → 必须再检查 `ans == passengers[j-1]` 并减 1。
- 车满时用 `passengers[j-1]-1`，若 `j-1` 指向的乘客其实没上最后一辆车（前面车已装满导致 `j` 停在别处），会取错基准 → 要确保 `j` 是「最后一辆车装完后」的全局指针，而非每辆车重置。

## 如果面试官追问
若要求输出具体方案（哪几位乘客上哪辆车）？答：双指针时用列表记录每辆车装入的乘客下标即可，空间升到 `O(m)`。
