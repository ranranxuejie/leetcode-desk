## 一句话思路
先用区间 DP 预处理 `is_pal[i][j]`，再对前缀做线性 DP 求最少切割数，因为每段切割只依赖更短前缀。

## 怎么做
1. 建二维布尔表 `is_pal`，按长度从 1 到 n 枚举，`s[i]==s[j] and (j-i<2 or is_pal[i+1][j-1])` 判定回文。
2. 建 `dp[i]` 表示 `s[:i]` 的最少切割数，初始化 `dp[i]=i-1`（全切成单字符）。
3. 对每个 `i`，枚举最后一段起点 `j`，若 `is_pal[j][i-1]` 则 `dp[i]=min(dp[i], dp[j]+1)`，`j==0` 时取 0。
4. 返回 `dp[n]`。

以 `s="aab"` 为例：`is_pal[0][1]` 为 `True`（"aa"），算 `dp[2]` 时 `j=0` 命中，`dp[2]=0+1=1`；`dp[3]` 枚举到 `j=2` 时 `is_pal[2][2]` 为 `True`，`dp[3]=dp[2]+1=2`，但 `j=0` 时 "aab" 非回文，最终 `dp[3]=2`？实际正确答案是 1——因为 `dp[2]=1` 对应切 "aa"，再加 "b" 得 2 段即 1 次切割，`dp` 语义是段数减一，故 `dp[3]=min(dp[2]+1)=2` 是段数，需返回 `dp[n]-1`。修正：令 `dp[i]` 为 `s[:i]` 最少段数，`dp[0]=0`，转移 `dp[i]=min(dp[j]+1)`，答案 `dp[n]-1`。

```python
n = len(s)
is_pal = [[False]*n for _ in range(n)]
for length in range(1, n+1):
    for i in range(n-length+1):
        j = i+length-1
        is_pal[i][j] = s[i]==s[j] and (length<=2 or is_pal[i+1][j-1])
dp = [0] + [n]*n
for i in range(1, n+1):
    for j in range(i):
        if is_pal[j][i-1]:
            dp[i] = min(dp[i], dp[j]+1)
return dp[n]-1
```

## 复杂度
时间：O(n²)，回文表与 DP 各两层循环，n 为串长。
空间：O(n²)，`is_pal` 二维表占主导，`dp` 仅 O(n)。

## 易错点
- `s="aab"` 若把 `dp[i]` 直接当切割数、初始化 `dp[i]=i-1` 又用 `dp[j]+1` 转移，会得 2 而非 1：段数与切割数差一，统一用段数再减一。
- `s="ab"` 若回文判定漏掉 `length<=2` 的短路，`is_pal[0][1]` 会去访问 `is_pal[1][0]`（未计算或越界），单字符与双字符必须单独放行。

## 如果面试官追问
要求输出具体分割方案而非次数？答：在 `dp` 转移时记录每个 `i` 的最优 `j`（`pre[i]=j`），从 `n` 回溯 `pre` 即得切点序列。
