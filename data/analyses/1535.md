## 一句话思路
只需扫描到第一个「后面 k 个元素都打不过它」的数，因为最大值一旦登场就永不再输。

## 怎么做
1. 维护 `champ = arr[0]` 和 `streak = 0`，从 `arr[1]` 开始逐个挑战。
2. 挑战者 `x > champ` 时，`champ = x`、`streak = 1`；否则 `streak += 1`。
3. 一旦 `streak == k` 立即返回 `champ`；扫完整个数组还没到 k，返回 `champ`（此时它必是全局最大值）。

以 `arr = [2,1,3,5,4,6,7], k = 2` 为例：`champ=2` 胜 `1` 得 `streak=1`；`3` 击败 `2`，`champ=3, streak=1`；`5` 击败 `3`，`champ=5, streak=1`；`4` 打不过 `5`，`streak=2 == k`，返回 `5`。注意第 4 回合的 `streak` 是 `2` 而不是 `3`，因为 `5` 只连赢了 `3` 和 `4` 两场。

```python
champ, streak = arr[0], 0
for x in arr[1:]:
    if x > champ:
        champ, streak = x, 1
    else:
        streak += 1
    if streak == k:
        return champ
return champ
```

关键点：不需要真的把败者搬到数组末尾。败者被移到尾部后，要等前面所有元素都比完才可能再上场，而那时 `champ` 已是它之前所有元素的最大值，它若打不过当前 `champ`，就更打不过后面更大的数，永远不会翻盘。所以「移到末尾」这个动作对胜负判定完全无影响，可以整段跳过。

## 复杂度
时间 O(n)：每个元素最多被比较一次，n = len(arr)。
空间 O(1)：只开了 `champ`、`streak` 两个变量。

## 易错点
- `arr = [3,2,1], k = 10` → 若写成「必须凑满 k 次胜利才返回」会在循环结束后返回错误值或越界 → 正确做法是循环自然结束后直接 `return champ`，因为此时 `champ` 已是全局最大值，它会一直赢下去。
- `arr = [1,9,8,2,3,7,6,4,5], k = 7` → 若把 `streak` 在换冠军时写成 `+= 1` 或清零，会得到 `9` 之外的错误答案或提前返回 → 换冠军时必须重置为 `1`（新冠军已经赢了这一场），而不是 `0`。

## 如果面试官追问
若要求输出赢家是在第几回合产生的？答：把 `streak == k` 的判断处记下当前已进行的回合数 `i`（从 1 开始计），返回 `(champ, i)` 即可，逻辑不变。
