## 一句话思路
按 `nums[i] % space` 分组计数，同余的位置必在同一条等差链上，取计数最大组里的最小值。

## 怎么做
1. 遍历 `nums`，用哈希表 `cnt` 统计每个余数 `r = x % space` 出现的次数。
2. 同时用 `best[r]` 记录该余数下出现过的最小 `x`（因为输入值可能重复，计数和最小值要分开维护）。
3. 遍历 `cnt`，找计数最大的余数；计数并列时比较 `best[r]` 取更小者。
4. 返回该余数对应的 `best[r]`。

以示例 1 `nums = [3,7,8,1,1,5], space = 2` 为例：余数分组为
`1 -> {3,7,1,1,5}` 共 5 个、最小 1；`0 -> {8}` 共 1 个。
最大计数 5 只属于余数 1，答案 `best[1] = 1`。

关键点：机器输入 `x` 能摧毁的是 `x, x+space, x+2*space, ...`，这些数模 `space` 全等于 `x % space`；反过来，同余的两个数 `a < b` 满足 `b - a` 是 `space` 的正整数倍，所以从 `a` 出发一定能打到 `b`。因此「一条链」等价于「一个余数类」，且链上最小值就是该类的 `best`。

```python
cnt = {}
best = {}
for x in nums:
    r = x % space
    cnt[r] = cnt.get(r, 0) + 1
    if r not in best or x < best[r]:
        best[r] = x

ans = None
for r, c in cnt.items():
    if ans is None or c > cnt[ans_r] or (c == cnt[ans_r] and best[r] < best[ans_r]):
        ans_r = r
return best[ans_r]
```

（上面循环里 `ans_r` 需先初始化，实际写时用 `max(cnt, key=lambda r: (cnt[r], -best[r]))` 一行更稳。）

## 复杂度
时间 O(n)：一次遍历建表，一次遍历余数类，余数类数 ≤ n。
空间 O(n)：`cnt` 和 `best` 各存至多 n 个余数键。

## 易错点
- 输入 `nums = [1,1,1], space = 1`：若只用 `cnt` 存「余数 → 最小值」并在遍历中覆盖，会把重复值当成不同链，或把最小值写错。正确做法是计数与最小值分两个字典维护，重复值只加计数不改 `best`。
- 输入 `nums = [6,2,5], space = 100`：三个余数 6、2、5 各不相同，计数全为 1。若按「先遇到先保留」取第一个余数会返回 6，正确做法是计数并列时比较 `best[r]`，取最小 2。

## 如果面试官追问
问：若要求返回能摧毁最多目标的所有 `nums[i]` 而非最小值？
答：把 `best[r]` 换成该余数下的值集合，最后收集最大计数余数的整个集合即可。
