## 一句话思路
用多层有序链表加随机层数，从最高层向右贪心、向下退层，把查找路径压到 O(log n)。

## 怎么做
1. 节点存 `val` 和 `next` 列表，`next[i]` 是第 i 层的后继；头节点层数取 `MAX_LEVEL=16`（2*10^4 个元素够用）。
2. `add` 时先自顶向下记录每层「最后一个小于 num 的节点」到 `update` 数组，再随机抛硬币决定新节点层数。
3. `search`/`erase` 复用同一套下降逻辑，`erase` 靠 `update[i].next[i] is node` 判断是否真的摘链。
4. 具体走一遍：已有 1,2,3，`add(4)` 时从第 15 层往下，`update` 在低层记到 3 这个节点，新节点插在 3 之后。

```python
def _find(self, num):
    cur, update = self.head, [None] * (MAX_LEVEL + 1)
    for i in range(MAX_LEVEL, -1, -1):
        while cur.next[i] and cur.next[i].val < num:
            cur = cur.next[i]
        update[i] = cur
    return update

def add(self, num):
    update = self._find(num)
    level = 0
    while level < MAX_LEVEL and random.random() < 0.5:
        level += 1
    node = Node(num, level)
    for i in range(level + 1):
        node.next[i] = update[i].next[i]
        update[i].next[i] = node
```

## 复杂度
时间：`search`/`add`/`erase` 期望 O(log n)，n 是元素个数，log n 来自层数期望。
空间：O(n)，每个元素期望占 2 层，额外只开了 `update` 这个长度 17 的数组。

## 易错点
- 重复值：`add(1)` 两次后 `erase(1)` 只删一个。若 `_find` 用 `<=` 前进，`update` 会跳过等值节点，删链时 `update[i].next[i] is node` 判假，返回 `False`。必须用严格 `<`。
- 层数越界：`random` 连出 17 次 0.5 时 `level` 会到 `MAX_LEVEL`，`Node(num, level)` 的 `next` 长度不够，`node.next[level]` 越界。循环条件要写 `level < MAX_LEVEL`，别写 `<=`。

## 如果面试官追问
问：要求 `search` 返回第几个重复值怎么办？
答：节点加 `cnt` 计数，`_find` 用 `<=` 走到最右等值节点，按 `cnt` 累加排名。
