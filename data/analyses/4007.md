## 一句话思路
枚举目标高度 h，用哈希表统计每个 h 能凑出多少块，取最大；h 只需取单块高度或两两之和。

## 怎么做
1. 用 `Counter(planks)` 得到每个高度的出现次数 `cnt`，单块木板直接贡献 `cnt[h]` 块高度 h。
2. 枚举所有 `h`（候选集 = 所有单块高度 ∪ 所有两两之和），对每个 h 统计能凑出的块数。
3. 统计时对每个 `v < h`，配对数为 `min(cnt[v], cnt[h-v])`，但 `v == h-v` 时要除以 2，避免同一批木板被用两次。
4. 取所有 h 中的最大块数。

以 `planks = [1,3,2,5,7,5,4,2,1]` 为例，`cnt = {1:2, 2:2, 3:1, 4:1, 5:2, 7:1}`。取 `h = 5`：单块贡献 `cnt[5] = 2`；配对 `1+4` 得 `min(2,1)=1`，`2+3` 得 `min(2,1)=1`，合计 `2+1+1 = 4`，即答案。

```python
from collections import Counter
cnt = Counter(planks)
vals = list(cnt)
cand = set(vals)
for i in range(len(vals)):
    for j in range(i, len(vals)):
        cand.add(vals[i] + vals[j])
best = 0
for h in cand:
    cur = cnt.get(h, 0)
    for v in vals:
        if v * 2 > h:
            break
        w = h - v
        if w not in cnt:
            continue
        if v == w:
            cur += cnt[v] // 2
        else:
            cur += min(cnt[v], cnt[w])
    best = max(best, cur)
```

注意 `vals` 需先 `sort()` 才能让 `v * 2 > h` 的 `break` 成立。

## 复杂度
时间 O(U²)，U 是不同高度个数（≤1000），枚举候选与配对都是 U² 量级。
空间 O(U)，`cnt` 与候选集各存 U 个键。

## 易错点
- 输入 `[2,2,2]` 取 `h = 4`：若对 `v == h-v` 不除以 2，会把 3 块 2 算成 `min(3,3)=3` 对，实际只能配 1 对。正确做法是 `cnt[2] // 2 = 1`。
- 输入 `[5,5,5]` 取 `h = 5`：若把 `v == h-v` 分支也走 `min`，`cnt[5]//2` 会漏掉单块，正确是单块 `cnt[5] = 3` 直接全用，配对分支只在 `v*2 == h` 且 `v != h` 时生效。

## 如果面试官追问
若要求输出具体方案（哪些木板组成哪块）？答：统计时记录每对 `(v, h-v)` 消耗的下标，按 `cnt` 顺序取用即可，复杂度不变。
