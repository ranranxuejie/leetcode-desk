## 一句话思路
DFS 维护根到当前点的前缀和与「值→深度」哈希表，用双指针式窗口把路径压到最多一个值重复两次。

## 怎么做
1. 建邻接表，`dfs(u, p, dep, dist)` 中 `dist` 是根到 `u` 的边权和，`dep` 是节点数（根为 1）。
2. 用 `last[val]` 记录值 `val` 在当前路径上最近出现的深度；进入 `u` 时若 `nums[u]` 已出现，就把窗口下界 `low` 抬到 `last[nums[u]] + 1`，并记下「已用掉一次重复」。
3. 关键：允许一个值出现两次，所以不能简单取 `max(low)`，而要维护「第二近的重复深度」——即路径上出现次数 ≥2 的值里，最靠后的那个的**第一次**出现位置 +1。用 `cnt` 计数，`low2` 表示「删掉它之后路径才合法」的深度。
4. 每次到 `u`，若当前窗口 `[low2, dep]` 合法，用 `dist - prefix[low2-1]` 更新答案，长度相同则取更小节点数 `dep - low2 + 1`。

以示例 1 为例：走到节点 8 时路径 0→1→3→6→8，`nums` 为 `[1,1,3,1,0]`，值 1 出现三次（节点 0、1、6），`low2` 被抬到节点 6 的深度 4，窗口只剩 `[4,5]`，长度 `dist[8]-dist[3]=9`，节点数 2——但真正答案是 1→3→6→8 长度 9 节点 4，说明 `low2` 应取「第二次出现位置 +1」而非第一次，即值 1 的第二次出现在节点 1（深度 2），窗口 `[3,5]` 才对。

```python
def dfs(u, p, dep, dist):
    nonlocal ans_len, ans_cnt
    v = nums[u]
    old = last.get(v, 0)
    if old:
        cnt[v] = cnt.get(v, 0) + 1
        if cnt[v] == 2:
            low2 = max(low2, old + 1)
    last[v] = dep
    if dep >= low2:
        L = dist - pref[low2 - 1]
        if L > ans_len or (L == ans_len and dep - low2 + 1 < ans_cnt):
            ans_len, ans_cnt = L, dep - low2 + 1
    for w, c in adj[u]:
        if w != p:
            pref[dep] = dist + c
            dfs(w, u, dep + 1, dist + c)
    last[v] = old
    if old:
        cnt[v] -= 1
```

## 复杂度
时间 O(n)：每个节点进出各一次，哈希表操作均摊 O(1)。
空间 O(n)：邻接表、`pref` 数组、`last`/`cnt` 哈希表各占 O(n)。

## 易错点
- 值出现三次以上时，`low2` 只按「第二次出现」抬升会漏掉更靠后的重复：如示例 1 节点 8 路径上值 1 出现三次，若只记第一次重复位置会得到节点数 2 的错误答案，正确做法是每次 `cnt[v]` 达到 2 时用该次出现位置更新 `low2`，第三次出现不再抬升（因为已允许一次重复）。
- 回溯时忘记恢复 `last[v] = old` 和 `cnt[v] -= 1`：兄弟子树会继承错误的历史深度，导致 `low2` 被抬得过高、路径被截断，答案偏小。

## 如果面试官追问
若要求输出具体路径而非长度？答：在更新答案时同步记录 `low2` 对应的祖先节点，回溯时沿 `parent` 数组还原窗口两端即可。
