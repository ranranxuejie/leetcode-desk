## 一句话思路
用 `dp[r][c]` 表示「走完当前步数后骑士在 (r,c) 的概率」，每步把概率按 8 个方向摊出去，越界的不接收。

## 怎么做
1. 初始 `dp[row][column] = 1.0`，其余为 0；`k = 0` 时直接返回 1.0。
2. 每轮新建全 0 的 `ndp`，对每个 `dp[r][c] > 0` 的格子，把 `dp[r][c] / 8` 累加到 8 个落点（越界的丢弃）。
3. 用 `ndp` 覆盖 `dp`，重复 k 轮。
4. 最后把 `dp` 所有格子求和返回。

以 `n=3, k=2, row=0, column=0` 为例：第 1 轮后只有 `dp[1][2]` 和 `dp[2][1]` 各为 `1/8 = 0.125`，其余全 0（8 个方向里 6 个越界）。第 2 轮从 `dp[1][2]` 出发，8 个落点中留在盘内的只有 `(0,0)` 和 `(2,0)` 两个，各得 `0.125/8 = 0.015625`；`dp[2][1]` 同理贡献 `(0,0)` 和 `(0,2)`。最终 `dp[0][0] = 0.03125`，全盘求和 = `0.0625`。

```python
moves = [(1,2),(2,1),(-1,2),(-2,1),(1,-2),(2,-1),(-1,-2),(-2,-1)]
dp = [[0.0]*n for _ in range(n)]
dp[row][column] = 1.0
for _ in range(k):
    ndp = [[0.0]*n for _ in range(n)]
    for r in range(n):
        for c in range(n):
            if dp[r][c] == 0.0:
                continue
            p = dp[r][c] / 8
            for dr, dc in moves:
                nr, nc = r + dr, c + dc
                if 0 <= nr < n and 0 <= nc < n:
                    ndp[nr][nc] += p
    dp = ndp
return sum(map(sum, dp))
```

## 复杂度
时间：`O(k * n^2 * 8)`，k 步 × n² 个格子 × 8 个方向。
空间：`O(n^2)`，两张 n×n 的浮点表 `dp` 和 `ndp`。

## 易错点
- `n = 1` 且 `k > 0`：任何一步都必然越界，答案应为 0.0。若循环里没跳过 `dp[r][c] == 0.0` 或误把越界落点也累加，会算出非零值；正确做法是越界直接 `continue`，不写 `ndp`。
- 用「留在盘内的走法数 / 8」逐层相乘：`n=3, k=2, (0,0)` 起点第一步只有 2 种合法走法，但第二步两个落点各自合法走法数不同，不能统一乘 `(2/8)^2`；正确做法是逐格累加概率，让每个格子的合法出边数自然体现在 `ndp` 里。

## 如果面试官追问
问：k 很大（比如 10^9）怎么办？
答：这是马尔可夫链，把 n² 个状态写成转移矩阵做快速幂，`O(n^6 log k)`，n=25 时不可行，实际要靠稀疏迭代或直接说 k≤100 的 DP 已够。
