## 一句话思路
先对每个串算 f 值，把 words 的 f 值排序后二分，用 `bisect_right` 一次得到每个查询的答案。

## 怎么做
1. 写 `f(s)`：`c = min(s)`，返回 `s.count(c)`，因为字典序最小字母就是 `min`。
2. 对 `words` 每个词算 f，得到列表 `wf` 并 `sort()`。
3. 对每个 `q in queries`，算 `v = f(q)`，在 `wf` 中二分找第一个 `> v` 的位置，该位置即「严格大于 v 的个数」。
4. 用 `len(wf) - bisect_right(wf, v)` 收集进 `answer`。

以示例 2 为例：`words = ["a","aa","aaa","aaaa"]` → `wf = [1,2,3,4]`。查询 `"bbb"` 的 `v = 3`（最小字母 `b` 出现 3 次），`bisect_right([1,2,3,4], 3) = 3`，`4 - 3 = 1`；查询 `"cc"` 的 `v = 2`，`bisect_right(..., 2) = 2`，`4 - 2 = 2`，输出 `[1,2]`。

```python
from bisect import bisect_right

def f(s):
    c = min(s)
    return s.count(c)

wf = sorted(f(w) for w in words)
ans = []
for q in queries:
    v = f(q)
    ans.append(len(wf) - bisect_right(wf, v))
```

关键点：`bisect_right` 而非 `bisect_left`，因为要求严格大于 `f(q)`；用 `bisect_left` 会把等于 `v` 的词也算进去，示例 2 中 `"cc"` 会错成 3。

## 复杂度
时间：O((|queries|+|words|)·L + |words| log |words| + |queries| log |words|)，L 为串长，来自 `min` 和 `count` 的扫描。
空间：O(|words|) 存 `wf`，二分本身 O(1)。

## 易错点
- 输入 `queries = ["cc"]`、`words = ["cc"]` → 若用 `bisect_left` 会返回 1，错把相等频次算作「大于」→ 必须用 `bisect_right`，答案应为 0。
- 输入 `words = ["zaaaz"]`（f=3）而查询 `"cbd"`（f=1）→ 若把 `f` 写成「最小字母本身」而非「其出现次数」，会拿 `'c'` 和 `'z'` 比较 → 正确做法是先 `min(s)` 再 `count`，返回整数 3 与 1。

## 如果面试官追问
若 queries 规模涨到 10^5 且 words 固定，怎么优化？答：预处理 `wf` 的频次前缀和数组（f 值上界为串长），把每次查询降到 O(1)。
