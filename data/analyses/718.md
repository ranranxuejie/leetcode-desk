## 一句话思路
用 `dp[i][j]` 记以 `nums1[i-1]`、`nums2[j-1]` 结尾的最长公共子数组长度，相等时由左上角加一。

## 怎么做
1. 建 `(m+1) x (n+1)` 的 `dp`，多出的一行一列全 0，作为「前面没有元素」的边界。
2. 双重循环 `i` 从 1 到 m、`j` 从 1 到 n，只比较 `nums1[i-1]` 和 `nums2[j-1]`。
3. 相等则 `dp[i][j] = dp[i-1][j-1] + 1`，否则置 0——子数组必须连续，断了就归零。
4. 每次赋值后更新 `best`，最后返回 `best`。

拿示例 1 走关键一步：`nums1 = [1,2,3,2,1]`、`nums2 = [3,2,1,4,7]`。当 `i=3, j=1` 时 `nums1[2]=3 == nums2[0]=3`，`dp[3][1] = dp[2][0] + 1 = 1`；接着 `i=4, j=2` 比 `2==2`，`dp[4][2] = dp[3][1] + 1 = 2`；再 `i=5, j=3` 比 `1==1`，`dp[5][3] = dp[4][2] + 1 = 3`，`best` 停在 3。这条对角线就是 `[3,2,1]`。

```python
m, n = len(nums1), len(nums2)
dp = [[0] * (n + 1) for _ in range(m + 1)]
best = 0
for i in range(1, m + 1):
    for j in range(1, n + 1):
        if nums1[i - 1] == nums2[j - 1]:
            dp[i][j] = dp[i - 1][j - 1] + 1
            best = max(best, dp[i][j])
return best
```

空间可压成一维：内层 `j` 必须**从大到小**遍历，否则 `dp[j-1]` 已被本轮覆盖，读到的是 `dp[i][j-1]` 而不是 `dp[i-1][j-1]`。

## 复杂度
时间 O(m·n)：`i`、`j` 两层各扫一遍，m、n 分别是两数组长度。
空间 O(m·n)：`dp` 表大小；压成一维后是 O(n)，只留一行。

## 易错点
- 输入 `nums1=[1,2,3]`、`nums2=[2,3,4]` 时，若把「相等才更新、不等不处理」写成「不等也保留旧值」，`dp[3][3]` 会残留 2 而不是 0，答案虚高。不等时必须显式置 0，因为子数组要求连续。
- 一维压缩时若内层 `j` 从小到大扫，示例 2 全零数组会算出 10 而不是 5：`dp[j-1]` 已被本轮写成 `dp[i][j-1]`，等于把同一元素重复计数。必须 `for j in range(n, 0, -1)`。

## 如果面试官追问
问：数组长度涨到 10^5 怎么办？
答：DP 的 O(m·n) 撑不住，改用滚动哈希 + 二分答案长度，对每个长度查两数组长度相等的子串哈希集合是否有交集，O((m+n)·log min(m,n))。
