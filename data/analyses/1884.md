## 一句话思路
用「k 次操作、2 枚蛋最多能覆盖多少层」反推：k 次能覆盖 k(k+1)/2 层，找最小 k 使覆盖数 ≥ n。

## 怎么做
1. 设答案为 k，第一枚蛋第一次扔在第 k 层。
2. 若碎了，剩 1 枚蛋只能从 1 层逐层往上试，最多 k-1 层，加上已确认的区间共 k 层。
3. 若没碎，第二次扔在 k+(k-1) 层，每次步长递减 1，总覆盖 k+(k-1)+...+1 = k(k+1)/2。
4. 从 k=1 递增，第一个满足 k(k+1)//2 >= n 的 k 就是答案。

以 n=100 为例：k=13 时 13*14//2=91 < 100，k=14 时 14*15//2=105 >= 100，故返回 14，与示例一致。

```python
def twoEggDrop(n):
    k = 1
    while k * (k + 1) // 2 < n:
        k += 1
    return k
```

也可用闭式解：k = ceil((sqrt(8n+1)-1)/2)，但循环到 k≤45（n≤1000）足够快，不必引入浮点误差。

## 复杂度
时间：O(√n)，循环次数约为 √(2n)，n=1000 时最多 45 次。
空间：O(1)，只用了 k 一个整型变量。

## 易错点
- n=1 时若从 k=0 开始循环，k*(k+1)//2=0 < 1 会继续加到 k=1 返回 1，结果对但逻辑绕；正确做法是 k 从 1 起，直接返回 1。
- 用浮点 sqrt 求闭式解时，n=2 得 (sqrt(17)-1)/2≈1.56，ceil 得 2 正确，但 n 接近完全平方边界时浮点可能算出 1.9999999 被 ceil 成 2 而非 3；正确做法是用整数循环或 math.isqrt 配合校正。

## 如果面试官追问
问：若鸡蛋数改为 m 枚怎么做？
答：改成 DP，dp[k][m] = dp[k-1][m-1] + dp[k-1][m] + 1，找最小 k 使 dp[k][m] >= n。
