## 一句话思路
用哈希表统计每个元素的频次，再对每个频次做质数判定，任一为质数即返回 `True`。

## 怎么做
1. 用 `Counter(nums)` 一次遍历得到 `{元素: 频次}` 映射。
2. 写一个 `is_prime(k)`：`k < 2` 直接 `False`，否则从 `2` 试到 `isqrt(k)`。
3. 遍历 `Counter` 的 values，任一 `is_prime` 为真就 `return True`，全不满足返回 `False`。

以示例 1 `nums = [1,2,3,4,5,4]` 为例，`Counter` 得到 `{1:1, 2:1, 3:1, 4:2, 5:1}`；遍历到 `4` 的频次 `2` 时，`is_prime(2)` 中 `2 < 2` 为假，循环 `range(2, isqrt(2)+1) = range(2, 2)` 为空，直接返回 `True`，函数立即返回。

```python
from collections import Counter
from math import isqrt

def is_prime(k):
    if k < 2:
        return False
    for d in range(2, isqrt(k) + 1):
        if k % d == 0:
            return False
    return True

cnt = Counter(nums)
for v in cnt.values():
    if is_prime(v):
        return True
return False
```

关键点：`isqrt(k)` 而不是 `k ** 0.5`，避免浮点误差在 `k = 4` 这类完全平方数上把上界算成 `1.9999` 漏掉因子 `2`。

## 复杂度
时间：`O(n + d·√m)`，`n` 是数组长度贡献计数，`d` 是不同元素个数、`m` 是最大频次贡献试除。
空间：`O(d)`，`Counter` 存不同元素及其频次。

## 易错点
- 输入 `nums = [1,2,3,4,5]`（全频次 1）→ 若把 `is_prime` 写成 `k > 1` 就返回 `True`，错成 `true` → 必须显式排除 `k < 2`，因为 1 不是质数。
- 输入 `nums = [2,2,2,4,4]`（频次 3 和 2）→ 若试除上界写成 `range(2, k)` 全量扫，虽然答案对但 `n=100` 时最坏频次 100 会多跑约 100 次除法；更隐蔽的是用 `k ** 0.5` 时 `k=4` 可能因浮点得到 `1.999...` 而漏判 `2` 这个因子，把 4 误判为质数 → 用 `isqrt(k) + 1` 作上界。

## 如果面试官追问
问：若 `nums` 长度放大到 `10**6`、元素值到 `10**9`，怎么优化？
答：频次上界仍是 `n`，可先筛出 `1..n` 的质数表，判定降为 `O(1)` 查表，总时间 `O(n + n log log n)`。
