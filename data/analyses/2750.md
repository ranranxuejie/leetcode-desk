## 一句话思路
相邻两个 1 之间的空隙长度决定切法，答案就是这些空隙长度（含两端 0 的个数+1）的乘积。

## 怎么做
1. 先扫一遍找所有 1 的下标，若一个 1 都没有则返回 0（无法划分成好子数组）。
2. 对每对相邻的 1，设它们下标差为 `gap`，则切点可以落在两者之间的任意位置，共 `gap` 种选择。
3. 把所有 `gap` 累乘，边乘边对 `10**9 + 7` 取余。

以 `nums = [0,1,0,0,1]` 为例：1 的下标是 `[1, 4]`，`gap = 4 - 1 = 3`，答案就是 3，与示例一致。再如 `[0,1,0]`：只有一个 1，没有相邻对，乘积为 1。

```python
MOD = 10**9 + 7
ones = [i for i, v in enumerate(nums) if v == 1]
if not ones:
    return 0
ans = 1
for a, b in zip(ones, ones[1:]):
    ans = ans * (b - a) % MOD
return ans
```

关键点：`b - a` 就是两个 1 之间可插入切点的位置数，因为切点必须严格在 `a` 和 `b` 之间（含 `a+1` 到 `b` 共 `b-a` 个位置）。

## 复杂度
时间 O(n)：一次遍历收集 1 的下标，再遍历一次相邻对。
空间 O(k)：`ones` 列表存 k 个 1 的下标，k ≤ n。

## 易错点
- 输入 `nums = [0,0,0]`（没有 1）→ 若直接返回 `ans = 1` 会错成 1 → 正确做法是先判断 `ones` 为空则返回 0，因为无法划分出任何好子数组。
- 输入 `nums = [1,0,0,0,1,0,0,1]` → 若把两端 0 也算进乘积会错 → 正确做法是只乘相邻 1 之间的 `b - a`，首尾的 0 不影响切法数量（它们只能被并入最近的好子数组）。

## 如果面试官追问
问：如果要求返回所有具体划分方案而非数量？
答：用回溯，在每个相邻 1 之间的 `b-a` 个切点位置逐一枚举，递归拼接子数组，复杂度变为方案数级别。
