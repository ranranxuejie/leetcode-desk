## 一句话思路
对原始图跑 Dijkstra 求到各原始节点的最短距离，再逐条边算两端各能往链内延伸多少新节点。

## 怎么做
1. 建邻接表时把 `cnt` 一起存：`adj[u].append((v, cnt+1))`，边权是 `cnt+1`（细分后这条链的长度）。
2. 从 0 跑堆优化 Dijkstra，得到 `dist` 数组，`dist[i]` 是到原始节点 i 的最少步数。
3. 答案先加上所有 `dist[i] <= maxMoves` 的原始节点个数。
4. 对每条 `[u, v, cnt]`，两端剩余步数 `ru = maxMoves - dist[u]`、`rv = maxMoves - dist[v]`（不可达时按 -1 处理），这条边贡献 `min(cnt, ru) + min(cnt, rv)`，但两者之和不能超过 `cnt`，取 `min(cnt, ru+rv)` 更省事。

以示例 1 为例：`edges = [[0,1,10],[0,2,1],[1,2,2]]`，`maxMoves = 6`。Dijkstra 得 `dist = [0, 2, 1]`（0→2 走 cnt=1 的边只要 1 步，0→1 经 2 中转是 1+3=4？实际 0→1 直接走要 11 步，经 2 是 1+3=4，故 `dist[1]=4`）。原始节点 3 个全可达。边 `[0,1,10]`：`ru=6, rv=2`，贡献 `min(10, 8)=8`；边 `[0,2,1]`：`ru=6, rv=5`，贡献 `min(1, 11)=1`；边 `[1,2,2]`：`ru=2, rv=5`，贡献 `min(2, 7)=2`。合计 `3+8+1+2=13`。

```python
import heapq
adj = [[] for _ in range(n)]
for u, v, c in edges:
    adj[u].append((v, c + 1))
    adj[v].append((u, c + 1))
dist = [2**31 - 1] * n
dist[0] = 0
pq = [(0, 0)]
while pq:
    d, u = heapq.heappop(pq)
    if d > dist[u]:
        continue
    for v, w in adj[u]:
        if d + w < dist[v]:
            dist[v] = d + w
            heapq.heappush(pq, (d + w, v))
ans = sum(1 for d in dist if d <= maxMoves)
for u, v, c in edges:
    ru = maxMoves - dist[u] if dist[u] <= maxMoves else -1
    rv = maxMoves - dist[v] if dist[v] <= maxMoves else -1
    ans += min(c, max(0, ru) + max(0, rv))
```

## 复杂度
时间：Dijkstra `O((n + E) log n)`，E 为原始边数，堆贡献 log n。
空间：`adj` 存 2E 条带权边，`dist` 与堆各 O(n)，共 O(n + E)。

## 易错点
- 边权写成 `cnt` 而非 `cnt+1`：示例 1 中 `[0,2,1]` 若按 1 算，`dist[2]=1` 看似对，但 `[0,1,10]` 按 10 算会让 `dist[1]` 偏小，边贡献被高估。细分后链长是 `cnt+1`，必须加一。
- 两端延伸量直接相加不封顶：示例 1 的 `[0,1,10]` 若写 `min(cnt,ru)+min(cnt,rv)=6+2=8` 恰好没超，但 `maxMoves` 很大时 `ru+rv` 会超过 `cnt`，把同一条链上的新节点数重复计。正确是 `min(cnt, ru+rv)`（ru、rv 先截到非负）。

## 如果面试官追问
若 `maxMoves` 大到 `10^18` 且 `cnt` 也到 `10^9`，答案会超 32 位怎么办？
答：Python 整数无溢出，直接返回大整数；若要求按 32 位截断，返回前对 `2**31` 取模或按题意截断。
