## 一句话思路
枚举三个串的 6 种拼接顺序，每种顺序里贪心求最大重叠，取最短、同长取字典序最小。

## 怎么做
1. 把 `a,b,c` 的 6 种排列都列出来，每种按顺序合并成一个串。
2. 合并两个串 `x,y` 时，从大到小试重叠长度 `k`（`k` 从 `min(len(x),len(y))` 降到 0），第一个满足 `x[-k:] == y[:k]` 的 `k` 就是最大重叠，拼成 `x + y[k:]`。
3. 三个串两两合并两次，得到该排列的候选串；6 个候选里按 `(len, 字典序)` 取最小。

以示例 1 为例，排列 `(c,a,b)`：先合 `c="aaa"` 与 `a="abc"`，`k` 从 3 试到 0，`k=1` 时 `"a"=="a"` 成立，得 `"aaabc"`；再与 `b="bca"` 合，`k=2` 时 `"bc"=="bc"` 成立，得 `"aaabca"`，长度 6，正是答案。

```python
def merge(x, y):
    for k in range(min(len(x), len(y)), -1, -1):
        if x[-k:] == y[:k] if k else True:
            return x + y[k:]

best = None
for p, q, r in permutations([a, b, c]):
    cand = merge(merge(p, q), r)
    if best is None or (len(cand), cand) < (len(best), best):
        best = cand
```

注意 `k=0` 时 `x[-0:]` 是整串 `x`，不能直接比，代码里用 `if k else True` 兜住。

## 复杂度
时间：6 种排列 × 每次合并 O(L²) 字符比较，L 为串长上限 100，可视为常数级。
空间：只存 6 个候选串，每个长度 ≤ 3L。

## 易错点
- 输入 `a="ab", b="ba"`：只试 `k=min` 往下第一个匹配就返回，若写成从小到大试会得到 `k=0` 拼成 `"abba"`，长度 4 而非 `"aba"` 的 3。必须从大到小找最大重叠。
- 输入 `a="abc", b="bca", c="aaa"`：若只枚举「谁在最前」3 种而漏掉中间顺序，会拿不到 `"aaabca"`；且同长度时若用 `min(cand)` 单独比而不带长度，可能选到更长的串。比较键必须是 `(len, 字典序)` 二元组。

## 如果面试官追问
问：串长涨到 10⁵ 还枚举 6 种吗？答：仍枚举 6 种，但重叠要用 KMP 的 `next` 数组在 O(L) 内求最大 border，总 O(L)。
