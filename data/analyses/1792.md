## 一句话思路
用大根堆每次挑「加一个学生后通过率增量最大」的班级，因为总增量是各次增量之和，贪心选最大增量即最优。

## 怎么做
1. 对每个班算增量 `(p+1)/(t+1) - p/t`，把 `(-增量, p, t)` 压进堆（Python 是小根堆，取负）。
2. 循环 `extraStudents` 次：弹出堆顶，`p, t` 各加 1，重算增量再压回。
3. 最后把堆里所有 `p/t` 求和除以 `len(classes)`。

以示例 1 的 `[[1,2],[3,5],[2,2]]` 为例，初始增量分别是 `2/3-1/2≈0.1667`、`4/6-3/5≈0.0667`、`3/3-2/2=0`，堆顶是第一个班。第一次弹出后变成 `[2,3]`，新增量 `3/4-2/3≈0.0833`，仍大于第二个班的 `0.0667`，所以第二次还是给它，最终 `[3,4]`。

```python
import heapq
heap = []
for p, t in classes:
    heapq.heappush(heap, (-((p + 1) / (t + 1) - p / t), p, t))
for _ in range(extraStudents):
    _, p, t = heapq.heappop(heap)
    p, t = p + 1, t + 1
    heapq.heappush(heap, (-((p + 1) / (t + 1) - p / t), p, t))
return sum(p / t for _, p, t in heap) / len(classes)
```

注意增量必须用浮点算，别写成整数比较 `(p+1)*t` 与 `p*(t+1)` 的交叉相乘——虽然那样也能比大小，但堆里存元组时混用会出错，统一用 float 最省事。

## 复杂度
时间：`O(n + extraStudents * log n)`，n 是班级数，每次堆操作 log n。
空间：`O(n)`，堆里存 n 个三元组。

## 易错点
- 输入 `[[1,2],[3,5],[2,2]]` 且 `extraStudents=2` 时，若按「当前通过率最低的班优先」分配，会先给 `[1,2]` 再给 `[3,5]`，得到 `(2/3+4/6+2/2)/3≈0.7778`，小于正确答案 `0.78333`。正确做法是按增量而非当前通过率排序。
- 输入 `[[2,2],[2,2]]` 且 `extraStudents=1` 时，两个班增量都是 `3/3-2/2=0`，堆里元组比较会退到比较 `p` 和 `t`，结果仍然正确但顺序不确定；若把增量写成整数交叉相乘再取负，可能出现 `-0` 与 `0` 混用导致堆序错乱。统一用 float 增量即可避免。

## 如果面试官追问
问：如果 `extraStudents` 大到 10^9 怎么办？
答：不能逐次模拟，要按增量单调递减的性质做二分或按班级批量分配，单次增量随 t 增大而减小，可对每个班解出分配 k 个后的边际增量做阈值二分。
