## 一句话思路
按行做状压 DP，每行枚举合法座位掩码，用上一行掩码校验斜向冲突，取最大人数。

## 怎么做
1. 把每行 `seats[i]` 转成可用位掩码 `avail[i]`（`.` 为 1），并预处理所有无左右相邻的掩码 `masks`。
2. `dp[prev]` 表示上一行坐法为 `prev` 时的最大人数，初始 `dp = {0: 0}`。
3. 对每行枚举 `cur`，要求 `cur & ~avail[i] == 0` 且 `cur & (cur << 1) == 0`；再对每个 `prev` 检查 `cur & (prev << 1)` 和 `cur & (prev >> 1)` 都为 0。
4. 转移 `ndp[cur] = max(ndp[cur], dp[prev] + popcount(cur))`，滚动更新。

以示例 1 第 0 行 `#.##.#` 为例，`avail[0] = 0b010010`（第 1、4 列）。候选 `cur` 只有 `0b010010` 和 `0`；选 `0b010010` 时 `popcount = 2`，与空 `prev=0` 无冲突，`dp` 变为 `{0b010010: 2, 0: 0}`。第 1 行 `avail[1] = 0b100001`，若取 `cur = 0b100001`，需检查 `cur & (prev << 1)`：`prev = 0b010010` 左移得 `0b100100`，与 `cur` 无交集，合法，人数累加到 4。

```python
for i in range(m):
    ndp = {}
    for cur in masks:
        if cur & ~avail[i]: continue
        for prev, val in dp.items():
            if cur & (prev << 1) or cur & (prev >> 1): continue
            ndp[cur] = max(ndp.get(cur, 0), val + bin(cur).count('1'))
    dp = ndp
return max(dp.values())
```

## 复杂度
时间：O(m · 4^n)，每行枚举 cur 与 prev 两个 n 位掩码。
空间：O(2^n)，只存一行 dp 字典。

## 易错点
- 只检查左右相邻却漏掉斜向：示例 1 第 0 行取 `0b010010`、第 1 行取 `0b100001` 时，若只判 `cur & prev` 会误判合法，实际第 1 行第 5 列与第 0 行第 4 列斜向冲突，必须用 `prev << 1` 和 `prev >> 1` 双向校验。
- 把 `#` 位当成可坐：示例 2 第 0 行 `.#` 的 `avail[0] = 0b01`，若漏掉 `cur & ~avail[i]` 过滤，会允许 `cur = 0b10` 坐到坏座位上，答案从 3 虚增。

## 如果面试官追问
要求输出具体座位方案怎么办？答：dp 值改存 `(人数, 前驱掩码)`，最后从最优末行回溯每行掩码即可。
