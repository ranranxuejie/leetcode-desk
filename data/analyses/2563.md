## 一句话思路
排序后对每个 `nums[i]` 二分出满足 `lower - nums[i] <= nums[j] <= upper - nums[i]` 的 `j` 区间，累加区间长度。

## 怎么做
1. 先 `nums.sort()`，把「两数之和落在区间」变成对有序数组的区间计数。
2. 对每个下标 `i`，只需在 `i+1` 到 `n-1` 里找 `j`，用 `bisect_left` 求第一个 `>= lower - nums[i]` 的位置 `lo`。
3. 用 `bisect_right` 求第一个 `> upper - nums[i]` 的位置 `hi`，贡献 `hi - lo`。
4. 累加所有 `i` 的贡献即为答案。

以示例 1 为例：`nums` 排序后为 `[0,1,4,4,5,7]`，`lower=3, upper=6`。当 `i=0`（`nums[i]=0`）时，需要在 `[1,4,4,5,7]` 中找和落在 `[3,6]` 的数，即 `nums[j]` 在 `[3,6]`，`lo` 指向下标 2（值 4），`hi` 指向下标 5（值 7），贡献 `5-2=3`，对应数对 `(0,2)、(0,3)、(0,4)`。同理 `i=1`（`nums[i]=1`）时 `nums[j]` 需在 `[2,5]`，贡献 3。其余 `i` 贡献为 0，总计 6。

```python
from bisect import bisect_left, bisect_right

nums.sort()
n = len(nums)
ans = 0
for i in range(n - 1):
    lo = bisect_left(nums, lower - nums[i], i + 1)
    hi = bisect_right(nums, upper - nums[i], i + 1)
    ans += hi - lo
return ans
```

关键点：`bisect_left/right` 的 `lo` 参数传 `i+1`，保证只统计 `j > i`，避免重复计数和自配对。

## 复杂度
时间：排序 `O(n log n)`，每个 `i` 两次二分共 `O(n log n)`，总计 `O(n log n)`。
空间：排序原地 `O(log n)` 栈空间，无额外数组。

## 易错点
1. 输入 `nums = [0,0,0], lower = 0, upper = 0` → 若二分时 `lo` 从 0 开始而非 `i+1`，会把 `(i,i)` 自配对和重复对算进去，得到 9 而非 3 → 必须传 `i+1` 作为二分下界。
2. 输入 `nums = [-10**9, 10**9], lower = -10**9, upper = 10**9` → 若用 `lower - nums[i]` 时误写成 `nums[i] - lower`，区间方向反了，`lo > hi` 贡献为负 → 正确写法是 `lower - nums[i]` 和 `upper - nums[i]`，且 `bisect_left` 配下界、`bisect_right` 配上界。

## 如果面试官追问
问：若要求输出所有公平数对而非计数？答：排序后对每个 `i` 二分出 `[lo, hi)`，直接切片枚举 `j`，复杂度变为 `O(n log n + k)`，`k` 为答案对数。
