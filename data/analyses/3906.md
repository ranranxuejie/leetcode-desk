## 一句话思路
数位 DP 按 16 位从高位填，状态只需记录路径上已填位置的最大值，非递减即新数字 ≥ 该最大值。

## 怎么做
1. 把 `directions` 展开成路径上 7 个格子的下标 `pos[0..6]`（`pos[0]=0`，遇 `D` 加 4、遇 `R` 加 1），再记 `order` = 这些下标按从小到大排序后的顺序，即「填数顺序」。
2. 数位 DP：`dfs(i, last, tight)`，`i` 是已填的路径格子数（0..7），`last` 是已填格子的最大数字，`tight` 表示前缀是否贴着上界。
3. 转移时枚举当前格子 `pos[order[i]]` 填 `d`，要求 `d >= last`，否则剪掉；`tight` 时 `d` 上限是 `limit[pos[order[i]]]`。
4. 答案 = `f(r) - f(l-1)`，`f(x)` 把 `x` 补零成 16 位字符串后跑 DP。

以示例 2 `directions="DDRRDR"` 为例：路径为 `(0,0)→(1,0)→(2,0)→(2,1)→(2,2)→(3,2)→(3,3)`，对应下标 `[0,4,8,9,10,14,15]`。对 `x=123456789` 补零后第 15 位是 `9`、第 14 位是 `8`，填到 `i=5` 时 `last=8`，第 15 位取 `9` 满足 `9>=8`，故计入；而 `x=123456790` 第 15 位是 `0`，`0>=9` 不成立，被剪掉。

```python
def f(x):
    s = str(x).zfill(16)
    lim = [int(c) for c in s]
    from functools import lru_cache
    @lru_cache(None)
    def dfs(i, last, tight):
        if i == 7: return 1
        p = order[i]
        hi = lim[p] if tight else 9
        res = 0
        for d in range(last, hi + 1):
            res += dfs(i + 1, d, tight and d == hi)
        return res
    return dfs(0, 0, True)
```

## 复杂度
时间：`O(7 * 10 * 2 * 10)` 每位数位 DP，即常数级，与 `r-l` 无关。
空间：`O(7 * 10 * 2)` 记忆化表，外加 16 位字符串。

## 易错点
- 忘记补前导零：`x=8` 若不补零直接按位数放网格，`8` 会落在 `(0,0)` 而非 `(3,3)`，路径序列变成 `[8,0,...]` 被判非递减失败；必须 `zfill(16)` 后再取 `lim`。
- `tight` 传参写错：转移里应传 `tight and d == hi`，若写成 `tight and d == lim[p]`，当 `tight=False` 时 `hi=9` 而 `lim[p]` 可能更小，会把不贴界的合法分支误判为贴界，导致 `f(r)` 偏小。

## 如果面试官追问
问：若 `directions` 长度不是 6 而是任意 2n，怎么做？
答：路径格子数变成 `2n+1`，DP 状态数从 7 涨到 `2n+1`，其余不变，仍是 `O(n * 10 * 2 * 10)`。
