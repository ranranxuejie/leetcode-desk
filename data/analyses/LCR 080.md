## 一句话思路
用回溯按递增顺序选数，每层从 `start` 开始枚举，选够 `k` 个就收集，天然去重且不重复。

## 怎么做
1. 维护 `path`（当前已选）和 `start`（下一个可选的起点），`start` 从 1 开始。
2. 每层 `for i in range(start, n + 1)`，把 `i` 加入 `path` 后递归，下一层起点传 `i + 1`。
3. 递归返回后 `path.pop()` 撤销选择。
4. 剪枝：若 `len(path) + (n - i + 1) < k`，剩余数不够凑满 `k`，直接 `break`。

以 `n = 4, k = 2` 为例：第一层 `i = 1`，`path = [1]`，递归 `start = 2`；第二层 `i = 2` 时 `path = [1, 2]`，长度到 2，收集 `[1, 2]`；`pop` 后 `i = 3` 得 `[1, 3]`，`i = 4` 得 `[1, 4]`。回到第一层 `i = 2`，`path = [2]`，此时 `len(path) + (4 - 2 + 1) = 1 + 3 = 4 >= 2` 继续，最终得到 `[2, 3]`、`[2, 4]`。

```python
def dfs(start):
    if len(path) == k:
        res.append(path[:])
        return
    for i in range(start, n + 1):
        if len(path) + (n - i + 1) < k:
            break
        path.append(i)
        dfs(i + 1)
        path.pop()
```

关键点：`dfs(i + 1)` 而不是 `dfs(start + 1)`，保证后续只选比 `i` 大的数，避免 `[2, 1]` 这种重复。

## 复杂度
时间：`O(C(n, k) * k)`，共 `C(n, k)` 个方案，每个方案复制长度 `k` 的 `path`。
空间：递归栈深度 `k`，`path` 长度 `k`，不计结果集则额外 `O(k)`。

## 易错点
- `n = 4, k = 2` 时若递归传 `dfs(start + 1)` 而非 `dfs(i + 1)`，会漏掉 `[1, 3]`、`[1, 4]` 这类跨步组合，正确做法是下一层起点固定为 `i + 1`。
- `n = 4, k = 3` 时若不加剪枝，`i = 3` 后仍会进入 `path = [3]` 的分支，但剩余 `4` 只有一个数，凑不满 3 个，白跑一趟；正确做法是在 `for` 里判断 `len(path) + (n - i + 1) < k` 就 `break`。

## 如果面试官追问
若 `n` 放大到 30 且只要方案数不要具体组合，怎么改？答：放弃回溯，直接用组合数公式 `C(n, k) = C(n-1, k-1) + C(n-1, k)` 记忆化递推，`O(nk)` 时间。
