## 一句话思路
把「剩余和能被 p 整除」转成「被删子数组的和 ≡ 总和 mod p」，用前缀和取模 + 哈希表找最近同余位置。

## 怎么做
1. 先算 `total = sum(nums) % p`，若为 0 直接返回 0。
2. 维护 `pre`（当前前缀和 mod p），哈希表 `pos` 记录每个余数**最后一次**出现的下标，初始 `pos[0] = -1`。
3. 对每个下标 `i`，更新 `pre`，要找的子数组余数是 `need = (pre - total) % p`；若 `need in pos`，候选长度 `i - pos[need]`。
4. 把 `pos[pre] = i` 覆盖写入（保留最靠右的位置，才能让长度最短）。

以示例 1 `nums = [3,1,4,2], p = 6` 为例：`total = 10 % 6 = 4`。走到 `i=2` 时 `pre = (3+1+4) % 6 = 2`，`need = (2 - 4) % 6 = 4`，`pos[4]` 是 `i=1` 时的前缀余数 4，候选长度 `2 - 1 = 1`，对应删掉 `[4]`，答案 1。

```python
total = sum(nums) % p
if total == 0:
    return 0
pos = {0: -1}
pre = 0
ans = len(nums)
for i, x in enumerate(nums):
    pre = (pre + x) % p
    need = (pre - total) % p
    if need in pos:
        ans = min(ans, i - pos[need])
    pos[pre] = i
return ans if ans < len(nums) else -1
```

注意 `ans` 初值取 `len(nums)`：题目禁止删掉整个数组，所以只有找到严格更短的才有效，否则返回 -1。

## 复杂度
时间 O(n)：一次遍历，每个元素做常数次取模和哈希查询。
空间 O(min(n, p))：哈希表最多存 n 个不同余数。

## 易错点
- `nums = [1,2,3], p = 7`：`total = 6`，全程找不到 `need`，若把 `ans` 初值设成 0 或直接返回 `ans` 会输出 0 或 6；正确做法是初值 `len(nums)`，最后判 `ans < len(nums)` 才返回，否则 -1。
- 前缀和直接累加 `nums[i]` 到 1e14 量级再取模，Python 不会溢出但会拖慢；正确做法是每步 `pre = (pre + x) % p`，且 `need` 用 `(pre - total) % p` 而不是 `pre - total`，否则负数余数在字典里永远查不到。

## 如果面试官追问
要求输出被删子数组的具体下标区间怎么办？
答：`pos` 里存下标而非只存布尔，命中时记下 `(pos[need]+1, i)`，最后返回该区间即可。
