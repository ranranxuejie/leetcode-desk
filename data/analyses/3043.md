## 一句话思路
把 arr1 每个数的所有数字前缀塞进哈希集合，再对 arr2 每个数逐位截前缀查表，取最长命中。

## 怎么做
1. 遍历 arr1，对每个 x 反复 `x //= 10`，把每个中间值（含 x 本身）加入集合 `pref`。
2. 遍历 arr2，对每个 y 从完整值开始逐位去掉末位，一旦命中 `pref` 就停止。
3. 命中时用当前位数更新答案，位数可由 `len(str(y))` 或循环计数得到。

以 `arr1 = [1,10,100]` 为例：`pref = {1, 10, 100}`。处理 `arr2[0] = 1000` 时依次查 1000（未命中）、100（命中），长度 3，答案更新为 3。

```python
pref = set()
for x in arr1:
    while x:
        pref.add(x)
        x //= 10

ans = 0
for y in arr2:
    while y:
        if y in pref:
            ans = max(ans, len(str(y)))
            break
        y //= 10
return ans
```

关键点：arr1 侧必须把 x 本身也加进去（`100` 是 `100` 的前缀），否则示例 1 只能得到 2。

## 复杂度
时间 O((n + m) · 8)：每个数最多 8 位（10^8），哈希查询 O(1)。
空间 O(n · 8)：`pref` 最多存 8n 个不同前缀。

## 易错点
- 只把「真前缀」加入集合、漏掉 x 本身 → 输入 `arr1=[100], arr2=[100]` 会返回 0 → 循环里先 `add(x)` 再 `x //= 10`。
- 在 arr2 侧从低位往高位截（`y % 10**k`）→ 拿到的是后缀不是前缀，`arr1=[1], arr2=[21]` 会误判命中 1 → 必须用 `y //= 10` 从高位往低位剥。

## 如果面试官追问
问：arr1 很大、arr2 很小，还建全量集合吗？
答：反过来枚举 arr2 的前缀建集合、扫 arr1，集合规模由较小一侧决定。
