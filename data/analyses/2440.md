## 一句话思路
枚举连通块价值 `k`（必整除总和 `S`），DFS 自底向上累加子树和，凑满 `k` 就切一刀，看能否切出 `S//k` 块。

## 怎么做
1. 先算 `S = sum(nums)`，答案的上界是 `n-1`；若 `S % k != 0` 直接跳过这个 `k`。
2. 对每个候选 `k`，从根 0 做一次后序 DFS，返回「当前子树尚未被切走的部分和」。
3. 若某子树返回值和恰好等于 `k`，就把它整块切掉（返回 0），计数器 `cnt += 1`。
4. 遍历完若 `cnt == S // k` 且根返回 0，说明 `k` 可行，答案取 `max(ans, cnt - 1)`。

以示例 1 为例，`nums = [6,2,2,2,6]`，`S = 18`。试 `k = 6`：节点 2 返回 2、节点 1 收齐 `2+2+2 = 6` 切一刀；节点 4 返回 6 切一刀；节点 0 返回 6 切一刀。`cnt = 3`，`S//k = 3`，可行，删边数 `3-1 = 2`。

```python
def dfs(u, p):
    s = nums[u]
    for v in g[u]:
        if v != p:
            s += dfs(v, u)
    if s == k:
        nonlocal cnt
        cnt += 1
        return 0
    return s

for k in range(1, S + 1):
    if S % k: continue
    cnt = 0
    if dfs(0, -1) == 0 and cnt == S // k:
        ans = max(ans, cnt - 1)
```

注意 `k` 只需枚举 `S` 的因子，且 `k <= S`；`cnt - 1` 是因为最后一块不需要再切边。

## 复杂度
时间：枚举 `S` 的因子个数 `d(S)`，每个因子一次 O(n) DFS，共 O(n·d(S))，`S ≤ 50n`。
空间：邻接表 O(n)，DFS 递归栈最坏 O(n)（链状树）。

## 易错点
- 输入 `nums = [2]`、`edges = []`：若没特判单节点，`cnt - 1 = 0` 恰好对，但若写成 `cnt` 会输出 1；正确做法是删边数恒为 `cnt - 1`，单节点时 `cnt = 1` 得 0。
- 输入链状树如 `nums = [1,1,1,1]`、`edges = [[0,1],[1,2],[2,3]]`：递归深度达 `2*10^4`，Python 默认递归上限 1000 会 `RecursionError`；正确做法是 `sys.setrecursionlimit(30000)` 或改迭代后序。

## 如果面试官追问
问：要求输出具体删哪些边怎么办？
答：DFS 切块时记录触发 `s == k` 的那条父边 `(u, p)`，收集起来即为答案。
