## 一句话思路
用三个状态滚动 DP：持有、冷冻、可买，每天只依赖前一天，把「卖后隔一天才能买」编码进状态转移。

## 怎么做
1. 定义 `hold`（今天收盘持股的最大收益）、`sold`（今天刚卖出的最大收益）、`rest`（今天空仓且不在冷冻期的最大收益）。
2. 每天按「昨天状态 → 今天状态」转移，注意买入只能从 `rest` 来，不能从 `sold` 来。
3. 用临时变量保存旧值，避免同一天内状态互相污染。

以 `prices = [1,2,3,0,2]` 为例，初始 `hold=-1, sold=0, rest=0`。第 2 天价格 2：`hold=max(-1, 0-2)=-1`，`sold=-1+2=1`，`rest=max(0,0)=0`；第 3 天价格 3：`sold=-1+3=2`；第 4 天价格 0：`hold=max(-1, 2-0)=2`（从第 3 天卖出后的 `sold=2` 买入），`sold=-1+0=-1`，`rest=max(0,1)=1`；第 5 天价格 2：`sold=2+2=4`？这里要小心，实际 `hold` 在第 4 天变成 2 后，第 5 天 `sold=2+2=4` 会超过答案 3——原因是第 4 天 `hold` 从 `sold=2` 买入时，`sold=2` 对应的是第 3 天卖出，第 4 天正是冷冻期，不能买。所以买入必须从 `rest` 来，而第 3 天卖出后第 4 天 `rest` 应为 0（第 3 天 `sold=2` 不能直接进 `rest`，要等一天）。正确转移是 `hold = max(hold, rest - p)`，`rest` 是「前天或更早空仓」的值。

```python
hold, sold, rest = -prices[0], 0, 0
for p in prices[1:]:
    prev_sold = sold
    sold = hold + p
    hold = max(hold, rest - p)
    rest = max(rest, prev_sold)
return max(sold, rest)
```

## 复杂度
时间：O(n)，n 为 `prices` 长度，每天常数次转移。
空间：O(1)，只开 `hold/sold/rest` 三个变量。

## 易错点
- 输入 `[1,2,3,0,2]` → 若写成 `hold = max(hold, sold - p)`，第 4 天会用第 3 天 `sold=2` 在冷冻期买入，得到 4 而非 3 → 买入只能从 `rest` 转移。
- 输入 `[1]` → 若循环从 `prices[0]` 开始或初始化 `hold=0`，会把「没买」当成持股 → 初始 `hold=-prices[0]`，循环从 `prices[1:]` 起。

## 如果面试官追问
若冷冻期改为 k 天？答：把 `rest` 换成队列存最近 k 天 `sold` 的最大值，空间 O(k)。
