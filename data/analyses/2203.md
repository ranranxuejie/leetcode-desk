## 一句话思路
枚举汇合点 v，答案 = dist(src1→v) + dist(src2→v) + dist(v→dest)，后两项靠反图一次 Dijkstra 得到。

## 怎么做
1. 建正图 `g` 和反图 `rg`（把每条 `[u,v,w]` 反向存进 `rg`）。
2. 从 `src1`、`src2` 在正图上各跑一次 Dijkstra，得 `d1`、`d2`。
3. 从 `dest` 在反图上跑一次 Dijkstra，得 `d3[v]` = 原图中 v→dest 的最短距离。
4. 遍历所有 v，取 `d1[v]+d2[v]+d3[v]` 的最小值；任一为 INF 则跳过，全 INF 返回 -1。

以示例 1 为例：`d1` 从 0 出发得 `d1[2]=2`、`d1[1]=3`；`d2` 从 1 出发得 `d2[0]=3`、`d2[2]=4`；反图从 5 出发得 `d3[4]=1`、`d3[2]=4`。取 v=2：2+4+4=10；取 v=0：0+3+6=9，即答案 9（路径 1→0→5）。

```python
import heapq
def dij(start, graph):
    dist = [INF] * n
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            if d + w < dist[v]:
                dist[v] = d + w
                heapq.heappush(pq, (d + w, v))
    return dist

d1 = dij(src1, g)
d2 = dij(src2, g)
d3 = dij(dest, rg)
ans = min((d1[v] + d2[v] + d3[v] for v in range(n)), default=INF)
return -1 if ans >= INF else ans
```

## 复杂度
时间：三次 Dijkstra 各 O((n+m) log n)，m = len(edges)，堆贡献 log n。
空间：正反图各 O(n+m)，三个 dist 数组 O(n)。

## 易错点
- 反图方向写反：把 `rg[v].append((u,w))` 写成 `rg[u].append((v,w))`，则 `d3` 算的是 dest→v 而非 v→dest，示例 1 会得到 0+3+6 之外的错值。正确做法是每条边 `[u,v,w]` 存 `rg[v].append((u,w))`。
- 只枚举 src1、src2、dest 三点：示例 1 的最优汇合点是 0（src1 本身），若只试中间点会漏掉 9 这个答案。必须遍历全部 n 个节点。
- 用 `INF = 2**31 - 1` 做加法：`d1[v]+d2[v]+d3[v]` 三个 INF 相加在 Python 不会溢出，但若先判 `d1[v]+d2[v] < INF` 再算，仍可能把不可达当可达。正确做法是三项分别判 `< INF` 或统一用 `10**18` 当 INF。

## 如果面试官追问
问：若要求输出具体子图边集而非权值？
答：在三次 Dijkstra 里记录每个点的前驱 `pre[v]`，选定最优汇合点后沿 `pre` 回溯三条路径并去重合并即可。
