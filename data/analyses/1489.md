## 一句话思路
对每条边做两次 Kruskal 判定：强制先选它看能否成 MST，再删掉它看权值和是否变大。

## 怎么做
1. 先对 `edges` 按 `weight` 排序得到 `order`，用一次 Kruskal 算出基准 MST 权值 `base`（示例 1 中 `base = 1+1+2+3 = 7`）。
2. 对 `order` 中每条边 `i`：跳过它跑 Kruskal，若连通后权值和 `> base` 或无法连通，则 `i` 是关键边。
3. 否则强制先加入 `i`（`union` 一次、累加权值），再跑剩余 Kruskal，若总权值 `== base`，则 `i` 是伪关键边。
4. 关键边判定优先，命中后不再判伪关键边。

关键中间值：示例 1 中删掉边 0（0-1，权 1）后，Kruskal 只能用边 1、2、3、4 连通，权值和升到 8 > 7，故边 0 关键；而边 2（2-3，权 2）强制先选后仍能凑出 7，故为伪关键边。

```python
def kruskal(skip=-1, force=-1):
    uf = DSU(n); total = 0; cnt = 0
    if force != -1:
        a, b, w = edges[force]
        uf.union(a, b); total += w; cnt += 1
    for idx in order:
        if idx == skip or idx == force: continue
        a, b, w = edges[idx]
        if uf.union(a, b):
            total += w; cnt += 1
    return total if cnt == n - 1 else float('inf')
```

## 复杂度
时间：O(m log m + m·m·α(n))，排序贡献 log m，每条边跑一次 Kruskal 贡献 m。
空间：O(n + m)，并查集 parent 数组 O(n)，order 与结果列表 O(m)。

## 易错点
- 删边后图可能不连通：示例 1 若删的是桥边，Kruskal 只连出 n-2 条边，此时 `total` 不是 inf 而是偏小值，必须用 `cnt == n-1` 判断连通，否则会把桥边误判成非关键边。
- 伪关键边判定必须先强制选它再跑：示例 2 四条边权都为 1，若只判「删掉它 base 不变」就把 4 条全判成伪关键边看似对，但换到示例 1 的边 6（1-4，权 6），删掉它 base 仍为 7，会误判为伪关键边；正确做法是强制选边 6 后总权值变 13 ≠ 7，才能排除。

## 如果面试官追问
问：n 扩大到 10^5 怎么办？答：按权值分组，同权边在缩点后的并查集上判桥（Tarjan），组内一次处理完，复杂度降到 O(m log m)。
