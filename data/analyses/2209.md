## 一句话思路
用 `dp[i][j]` 表示前 `i` 块砖用 `j` 条地毯覆盖后的最少白砖数，靠「不铺」和「铺在第 i 块结尾」两种转移。

## 怎么做
1. 前缀和 `pre[i]` 存 `floor[0..i-1]` 的白砖数，方便 O(1) 求任意区间白砖。
2. 状态 `dp[i][j]`：只考虑前 `i` 块砖、用掉 `j` 条地毯时，剩余白砖最少多少。
3. 转移二选一：第 `i` 块不铺地毯 → `dp[i-1][j] + (floor[i-1]=='1')`；用第 `j` 条地毯盖住以 `i` 结尾的 `carpetLen` 块 → `dp[max(0,i-carpetLen)][j-1]`（这段全黑，白砖贡献 0）。
4. 答案 `dp[n][numCarpets]`，`j` 从 0 到 `numCarpets` 递推。

以 `floor="10110101", numCarpets=2, carpetLen=2` 为例：`n=8`，`pre=[0,1,1,2,3,3,4,4,5]`。算到 `i=8, j=2` 时，不铺得 `dp[7][2]+1`，铺地毯得 `dp[6][1]`；`dp[6][1]` 已把 `"101101"` 用一条盖住 `"11"`（位置 3-4），剩 2 块白砖，故最终 `dp[8][2]=2`。

```python
n = len(floor)
pre = [0] * (n + 1)
for i, ch in enumerate(floor):
    pre[i + 1] = pre[i] + (ch == '1')
INF = 10**9
dp = [[INF] * (numCarpets + 1) for _ in range(n + 1)]
for j in range(numCarpets + 1):
    dp[0][j] = 0
for i in range(1, n + 1):
    for j in range(numCarpets + 1):
        dp[i][j] = dp[i - 1][j] + (floor[i - 1] == '1')
        if j > 0:
            s = max(0, i - carpetLen)
            dp[i][j] = min(dp[i][j], dp[s][j - 1])
return dp[n][numCarpets]
```

## 复杂度
时间：`O(n * numCarpets)`，`n = len(floor)`，两层循环各一遍。
空间：`O(n * numCarpets)` 的 `dp` 表，外加 `O(n)` 的 `pre`。

## 易错点
- `carpetLen > i` 时 → 若写成 `dp[i-carpetLen][j-1]` 会下标为负 → 必须 `max(0, i-carpetLen)`，地毯从 0 号砖开始盖。
- `numCarpets * carpetLen >= n` 时 → 若仍逐格算会白算，但更隐蔽的错是 `j` 只枚举到 `numCarpets` 却忘了 `dp[0][j]=0` 初始化 → 全 INF 传下去答案错，先把第 0 行全置 0。

## 如果面试官追问
问：要输出具体铺哪几段怎么办？
答：在 `dp` 里额外记 `choice[i][j]` 标记是否铺，从 `dp[n][numCarpets]` 倒推回 `i=0` 即得各段起点。
