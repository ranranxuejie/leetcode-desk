## 一句话思路
按值升序 DP，`dp[x]` 记以 x 为根的树数，枚举 x 的因子对 (a, b) 累加 `dp[a]*dp[b]`。

## 怎么做
1. 对 arr 排序，用哈希表 `idx` 存「值 → 下标」，保证枚举因子时 O(1) 查存在性。
2. 外层按升序遍历 x = arr[i]，内层遍历已处理过的 arr[j]（j < i，即 a ≤ b 的那一半）。
3. 若 `x % a == 0` 且 `b = x // a` 在 `idx` 里，就累加；a ≠ b 时左右可互换，乘 2。
4. 每个 x 自身单独成树，`dp[i]` 初值 1。

以 `arr = [2, 4, 5, 10]` 为例：处理 10 时，a=2 得 b=5 在表内，`dp[2]*dp[5]=1`，a≠b 乘 2 得 2；a=5 时 b=2 但 5>2 已跳过（内层只到 `a*a <= x`）。加上初值 1，`dp[10]=3`。四个值合计 1+2+1+3=7。

```python
MOD = 10**9 + 7
arr.sort()
idx = {v: i for i, v in enumerate(arr)}
dp = [1] * len(arr)
for i, x in enumerate(arr):
    for j in range(i):
        a = arr[j]
        if a * a > x:
            break
        if x % a:
            continue
        b = x // a
        if b not in idx:
            continue
        k = idx[b]
        ways = dp[j] * dp[k] % MOD
        dp[i] = (dp[i] + ways * (1 if a == b else 2)) % MOD
return sum(dp) % MOD
```

关键在 `a * a > x` 就 `break`：因为 arr 升序，后面的 a 只会更大，`b = x // a` 必然小于 a，那对 (b, a) 已在 j 更小时被算过，再算就重复。

## 复杂度
时间 O(n²)：外层 n 个 x，内层最多 n 次因子试探，哈希查 O(1)。
空间 O(n)：`idx` 与 `dp` 各开长度 n 的数组/字典。

## 易错点
- `arr = [2, 4]` 处理 4 时，a=2 得 b=2，若漏了 `a == b` 判断而一律乘 2，`dp[4]` 会算成 1+2=3，答案变 4；正确是 a==b 只加一次，`dp[4]=2`，总和 3。
- `arr = [2, 4, 8]` 处理 8 时，若内层不 break 而遍历全部 j，a=2 配 b=4、a=4 配 b=2 各算一遍，`dp[8]` 翻倍成 1+2+2=5；正确只算 a=2 那一对（乘 2 已含左右互换），`dp[8]=1+2*2=5`… 注意这里 a=2,b=4 时 a≠b 乘 2 得 4，加初值 1 才是 5，别把「乘 2」和「重复枚举」混为一谈。

## 如果面试官追问
问：arr 长度放大到 10⁵ 怎么办？
答：O(n²) 撑不住，改成对每个 x 枚举其质因子组合生成因子对，或用「枚举 a 再查 x//a」的稀疏做法，复杂度降到 O(n·√max)。
