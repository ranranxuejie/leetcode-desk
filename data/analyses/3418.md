## 一句话思路
在普通网格 DP 上加一维「已感化次数」k∈{0,1,2}，逐格取 max 转移，因为感化只影响当前格取值、不影响后续可达性。

## 怎么做
1. 定义 `dp[i][j][k]` 为走到 `(i,j)` 且已用 k 次感化时的最大金币，起点 `dp[0][0][0]=coins[0][0]`，若 `coins[0][0]<0` 则 `dp[0][0][1]=0` 更优。
2. 每格从上方 `dp[i-1][j]` 和左方 `dp[i][j-1]` 取 max，再叠加当前格。
3. 叠加分两支：不感化则 `+coins[i][j]`；感化则从 `k-1` 转移且 `+max(coins[i][j],0)`（正数格感化无收益，等价于不感化）。
4. 答案取 `max(dp[m-1][n-1][0..2])`。

以示例 1 的 `(1,1)=-2` 为例：从 `(0,1)` 来，`dp[0][1][0]=1`；不感化得 `1+(-2)=-1`，感化得 `dp[0][1][0]→k=1` 时 `1+0=1`，故 `dp[1][1][1]=1`，正是题解路径的中间值。

```python
NEG = -10**18
dp = [[[NEG]*3 for _ in range(n)] for _ in range(m)]
dp[0][0][0] = coins[0][0]
if coins[0][0] < 0:
    dp[0][0][1] = 0
for i in range(m):
    for j in range(n):
        if i == 0 and j == 0:
            continue
        for k in range(3):
            best = NEG
            for pi, pj in ((i-1, j), (i, j-1)):
                if pi >= 0 and pj >= 0:
                    best = max(best, dp[pi][pj][k] + coins[i][j])
                    if k > 0:
                        best = max(best, dp[pi][pj][k-1] + max(coins[i][j], 0))
            dp[i][j][k] = best
return max(dp[m-1][n-1])
```

## 复杂度
时间 O(m·n·3)，每格常数次转移，3 是感化次数上限。
空间 O(m·n·3)，可滚动成一维 `dp[j][k]` 降到 O(n·3)。

## 易错点
- 全负网格如 `[[-1,-1],[-1,-1]]`：若把 `NEG` 设成 `-1` 或 `0` 当哨兵，未达状态会被误当成合法值参与 max，答案偏大；必须用 `-10**18` 这类远小于 `-1000*1000` 的哨兵。
- 感化正数格：若写成「感化就 `+abs(coins[i][j])`」，在 `coins=10` 的格子上会白送 10 金币，示例 2 会算出 50 而非 40；正确是感化后加 `max(coins[i][j], 0)`。

## 如果面试官追问
问：要求输出具体路径怎么办？
答：DP 时额外存每格的 `(来源方向, 是否感化)`，从终点回溯到 `(0,0)` 即可还原。
