## 一句话思路
把每个数除以 p 后，好子序列存在当且仅当存在至少两个「p 的倍数」且它们的 gcd 为 1，用线段树维护区间 gcd 判断。

## 怎么做
1. 先把 nums 中所有数除以 p，非 p 倍数记为 0（无效），问题转化为：是否存在长度 < n 的子序列 gcd 恰为 1。
2. 关键观察：若存在两个数 gcd 为 1，则它们构成的子序列长度 2 < n（n≥2），直接满足；若所有 p 倍数整体 gcd 为 1 但任意两两 gcd 都 > 1，则需长度 ≥3，此时要检查是否长度 < n。
3. 用线段树维护区间 gcd，每次查询更新后取全局 gcd，若为 1 则进一步判断：p 倍数个数 cnt，若 cnt ≥ 2 且存在两两 gcd=1 或 cnt ≥ 3 且全局 gcd=1 即可。
4. 实际简化：只需维护所有 p 倍数的 gcd，若全局 gcd=1 且 p 倍数个数 ≥ 2 且 (个数 < n 或存在两两互质对)，则存在。

```python
from math import gcd
# 维护所有 p 倍数（除以 p 后）的 gcd
g = 0
cnt = 0
for x in nums:
    if x % p == 0:
        g = gcd(g, x // p)
        cnt += 1
# 存在好子序列条件
ok = (g == 1 and cnt >= 2 and (cnt < n or has_coprime_pair))
```

以示例1 `nums=[4,8,12,16], p=2`：除以2得 `[2,4,6,8]`，全局 gcd=2≠1，无好子序列。更新 `nums[0]=3` 后 p 倍数变为 `[4,6,8]`，gcd=2，仍无。再更新 `nums[2]=6` 后 p 倍数 `[4,3,8]`，gcd=1，cnt=3<4，存在。

## 复杂度
时间：每次查询 O(log n) 线段树更新 + O(1) 判断，共 O((n+q) log n)。
空间：线段树 O(n)，额外存 gcd 数组 O(n)。

## 易错点
- 输入 `nums=[4,8,12,16], p=2` 时若只判断全局 gcd==1 会漏掉「长度必须 < n」约束，正确做法是同时检查 p 倍数个数 cnt 是否 < n，或存在两两互质对使长度 2 就够。
- 输入 `nums=[6,9,7,8], p=3` 时若把非 p 倍数也纳入 gcd 计算，全局 gcd 会变成 1 误判为存在，正确做法是只对 `x % p == 0` 的数取 gcd（除以 p 后）。

## 如果面试官追问
问：若要求输出具体子序列而非仅判断？答：记录每个 gcd 值对应的最小下标集合，回溯构造即可，复杂度不变。
