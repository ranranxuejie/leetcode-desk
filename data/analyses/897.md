## 一句话思路
中序遍历 BST 得到升序序列，边遍历边把节点接到 `prev.right` 上，天然满足「只有右链」。

## 怎么做
1. 设 `dummy = TreeNode(0)`、`prev = dummy`，`prev` 始终指向已接好链的最后一个节点。
2. 递归中序：先 `dfs(node.left)`，再处理 `node`，最后 `dfs(node.right)`。
3. 处理 `node` 时执行 `prev.right = node; node.left = None; prev = node`，三步顺序不能换。
4. 返回 `dummy.right`。

以示例 1 的 `root = [5,3,6,2,4,null,8,1,null,null,null,7,9]` 为例：中序访问到 `1` 时，`prev` 还是 `dummy`，于是 `dummy.right = 1`、`1.left = None`、`prev = 1`；接着访问 `2`，`1.right = 2`、`2.left = None`、`prev = 2`。走完全树后 `dummy.right` 就是 `1`，右链依次是 `1→2→3→…→9`。

```python
def dfs(node):
    nonlocal prev
    if not node:
        return
    dfs(node.left)
    prev.right = node
    node.left = None
    prev = node
    dfs(node.right)

dummy = TreeNode(0)
prev = dummy
dfs(root)
return dummy.right
```

关键点：`node.left = None` 必须在 `prev = node` 之前、在 `prev.right = node` 之后执行，否则原左子树会把链断掉。

## 复杂度
时间 O(n)：每个节点被中序访问一次，接线是 O(1)。
空间 O(h)：递归栈深度等于树高 h，最坏链状树 h=n；额外只开了 `dummy` 和 `prev` 两个指针。

## 易错点
- 输入 `[5,1,7]`：若先写 `prev = node` 再写 `prev.right = node`，`prev.right` 会指回自己，输出成 `[1,null,1,...]` 死循环。正确顺序是 `prev.right = node` → `node.left = None` → `prev = node`。
- 输入 `[5,3,6,2,4,null,8,1,...]`：若漏掉 `node.left = None`，节点 `2` 的左指针仍指向 `1`，返回的树带左子树，判题按「每个节点无左子节点」校验会失败。必须显式清空左指针。

## 如果面试官追问
问：不用递归、要求 O(1) 额外空间怎么办？
答：用 Morris 中序遍历，借叶子节点的空右指针做线索，遍历中同样执行三步接线，空间降到 O(1)。
