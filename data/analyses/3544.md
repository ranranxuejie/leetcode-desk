## 一句话思路
自底向上 DFS，用 `f[v][d]` 记录「v 的祖先链上最近一次反转在距离 d 处」时的子树最大贡献，按 d 分桶做 DP。

## 怎么做
1. 把 `edges` 建成邻接表，从 0 出发 DFS，记录父节点避免回头。
2. 定义 `f[v][d]`：v 子树内已处理完，且 v 往上最近的已反转祖先距离为 d（d ∈ [0, k-1]，k 表示「无约束/无祖先」）时的最大和。
3. 在 v 处枚举「反转 v」或「不反转 v」：反转时 v 子树所有值取反，贡献变成 `-sub[v]`，且对子节点而言最近反转距离变为 0；不反转时贡献 `sub[v]`，子节点距离 +1。
4. 子节点合并时，若距离 d+1 达到 k 才能再次反转，用 `max` 合并各子树的同距离状态。

以示例 1 为例，`nums=[4,-8,-6,3,7,-2,5]`，k=2。反转 0、3、4、6 后，节点 0 的 `sub[0]` 从 3 变为 -3（子树和取反），节点 3、4 各自取反后贡献 +3+7=10 变 -10，节点 6 从 5 变 -5，最终总和 27。

```python
def dfs(v, p):
    sub[v] = nums[v]
    for u in adj[v]:
        if u != p:
            dfs(u, v)
            sub[v] += sub[u]
    # f[v][d]: 最近反转祖先距离 d 时的最大子树和
    for d in range(k + 1):
        best = -sub[v] if d == 0 else sub[v]  # d==0 表示 v 自己刚被反转
        for u in adj[v]:
            if u != p:
                nd = min(d + 1, k)
                best += f[u][nd]
        f[v][d] = best
```

## 复杂度
时间：O(n·k)，每个节点对每个距离 d 扫一遍子节点，k ≤ 50。
空间：O(n·k) 存 `f` 表，加 O(n) 邻接表和递归栈。

## 易错点
- 距离 d 的语义搞反：`f[v][d]` 里 d 是「v 到最近已反转祖先的边数」，不是「v 到最近已反转节点的距离」。若把子节点传 `d` 而非 `d+1`，示例 1 中反转 0 后节点 3 会被误判为距离 0 而允许再反转，答案偏大。
- 反转 v 时子树和取反要用 `-sub[v]`，但 `sub[v]` 是原始 nums 的子树和，不能边 DFS 边改 `nums`。若在递归中直接 `nums[u] *= -1`，示例 2 链上反转 4 后回溯会污染 3 的 `sub` 值，输出错成 5 而非 9。

## 如果面试官追问
问：k 很大（如 k=n）时怎么优化？
答：此时任意祖先-后代对距离都 < k，等价于「反转集合中不能有祖先关系」，退化成树上最大权独立集，O(n) 树形 DP 即可，不必开 k 维表。
