## 一句话思路
把每个单词压成 26 位掩码，两两按位与为 0 即无公共字母，取长度乘积最大值。

## 怎么做
1. 对每个 `words[i]` 扫一遍字符，`mask |= 1 << (ord(c) - ord('a'))`，得到该词的字母集合。
2. 双重循环枚举 `i < j`，判断 `masks[i] & masks[j] == 0`。
3. 成立则用 `len(words[i]) * len(words[j])` 更新 `best`，初始为 0。
4. 返回 `best`。

以示例 1 为例，`"abcw"` 的掩码是 `0b10000000000000000000000111`（a、b、c、w 位为 1），`"fxyz"` 的掩码只含 f、x、y、z 四位；两者按位与得 0，乘积 `4 * 4 = 16`，成为最终答案。而 `"abcw"` 与 `"baz"` 按位与在 b、a 位上非 0，直接跳过。

```python
masks = []
for w in words:
    m = 0
    for c in w:
        m |= 1 << (ord(c) - ord('a'))
    masks.append(m)

best = 0
for i in range(len(words)):
    for j in range(i + 1, len(words)):
        if masks[i] & masks[j] == 0:
            best = max(best, len(words[i]) * len(words[j]))
return best
```

注意 `masks` 与 `words` 下标一一对应，长度信息仍从原字符串取，不要试图从掩码里数位数——`"aa"` 和 `"a"` 掩码相同但长度不同。

## 复杂度
时间：O(L + n²)，L 为所有单词字符总数，负责建掩码；n² 负责两两比较。
空间：O(n)，只存 n 个整数掩码，每个不超过 2²⁶。

## 易错点
- 输入 `["a","aa","aaa","aaaa"]` → 若用掩码去重或按掩码分组，会把四个词当成同一个而漏判，错答非 0；正确做法是掩码只用于判交集，长度和下标始终按原数组走，这里任意两词都含 a，答案应为 0。
- 输入 `["abcw","baz","foo","bar","fxyz","abcdef"]` → 若把 `masks[i] & masks[j] == 0` 写成 `!= 0` 或漏掉括号优先级，会把有公共字母的对当成合法对，算出 `"abcw"` 与 `"abcdef"` 的 24；正确做法是只在按位与等于 0 时更新 `best`。

## 如果面试官追问
问：单词数涨到 10⁵ 怎么办？答：按掩码去重，每个掩码只保留最长长度，再对去重后的集合两两比较，实际不同掩码数远小于 n。
