## 一句话思路
把每个格子映射成 +1（X）、-1（Y）、0（.），问题变成统计以 (0,0) 为左上角、和为 0 且含至少一个 X 的子矩阵数。

## 怎么做
1. 先算二维前缀和 `pre[i][j]`，值域是 `-n*m` 到 `n*m`，用 `dict` 或偏移数组存频数。
2. 枚举右下角 `(i,j)`，子矩阵和 `s = pre[i][j]`，答案累加此前出现过的 `s` 的次数。
3. 用 `cnt` 记录每个前缀和出现次数，`cnt[0] = 1` 表示空前缀。
4. 额外维护 `hasX` 前缀计数，排除全为 `.` 的子矩阵。

以示例 1 为例：`grid = [["X","Y","."],["Y",".","."]]`，映射后 `pre[0][0]=1`，`pre[0][1]=0`，`pre[1][0]=0`，`pre[1][1]=-1`。枚举到 `(0,1)` 时 `s=0`，`cnt[0]` 已有 1 次（空前缀），答案 +1；枚举到 `(1,0)` 同理 +1；枚举到 `(1,1)` 时 `s=-1`，此前 `cnt[-1]=0`，不加。最终 3。

```python
n, m = len(grid), len(grid[0])
pre = [[0]*(m+1) for _ in range(n+1)]
for i in range(n):
    for j in range(m):
        v = 1 if grid[i][j]=='X' else (-1 if grid[i][j]=='Y' else 0)
        pre[i+1][j+1] = pre[i][j+1] + pre[i+1][j] - pre[i][j] + v
cnt = {0: 1}
ans = 0
for i in range(1, n+1):
    for j in range(1, m+1):
        s = pre[i][j]
        ans += cnt.get(s, 0)
        cnt[s] = cnt.get(s, 0) + 1
```

注意：上面代码没处理「至少一个 X」，需在累加前判断子矩阵内 X 数 > 0，可用另一个前缀数组 `xc[i][j]` 判断 `xc[i][j] > 0`。

## 复杂度
时间 O(n*m)，每个格子一次哈希查询。
空间 O(n*m)，前缀和表加哈希表，最坏 n*m 个不同前缀和。

## 易错点
- 示例 3 全 `.` 输入 → 若只判 `s==0` 会把全 `.` 子矩阵算进去 → 必须额外判子矩阵内 X 数 > 0。
- 示例 2 `[["X","X"],["X","Y"]]` → 若忘记 `cnt[0]=1` 会漏掉从 (0,0) 开始的子矩阵 → 初始化时显式写入 `cnt[0]=1`。

## 如果面试官追问
若要求输出所有满足条件的子矩阵坐标？答：把 `cnt` 改成存下标列表，枚举右下角时遍历列表还原左上角，复杂度升到 O(答案数)。
