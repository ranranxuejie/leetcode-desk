## 一句话思路
把点按 x 升序、x 相同按 y 降序排序后，问题变成在 y 序列上求「必须经过 k 号点」的最长严格上升子序列。

## 怎么做
1. 排序：`coordinates.sort(key=lambda p: (p[0], -p[1]))`，x 相同按 y 降序，保证同 x 的点不会被选进同一条上升路径。
2. 记 `kx, ky = coordinates[k]`，排序后 k 号点的新位置记为 `pos`。
3. 对 `pos` 左边的点，只保留 `y < ky` 的，求以它们结尾的最长上升子序列长度 `left`；对右边只保留 `y > ky` 的，求以它们开头的最长上升子序列长度 `right`。
4. 答案是 `left + 1 + right`。

以示例 1 为例：排序后为 `[[0,0],[2,2],[3,1],[4,1],[5,3]]`，k 号点 `(2,2)` 落在下标 1。左边只有 `(0,0)`，`y=0 < 2`，`left=1`；右边 `(3,1)` 的 y 不满足 `>2`，`(4,1)` 也不满足，只有 `(5,3)` 满足，`right=1`。答案 `1+1+1=3`。

```python
from bisect import bisect_left
pts = sorted(coordinates, key=lambda p: (p[0], -p[1]))
pos = pts.index(coordinates[k])
kx, ky = coordinates[k]
def lis(seq):
    tails = []
    for y in seq:
        i = bisect_left(tails, y)
        if i == len(tails): tails.append(y)
        else: tails[i] = y
    return len(tails)
left  = lis([y for x, y in pts[:pos] if y < ky])
right = lis([-y for x, y in pts[pos+1:] if y > ky])
return left + 1 + right
```

右边求的是「以 k 开头」的上升链，等价于把 `y > ky` 的点取负后求 LIS，长度相同。

## 复杂度
时间 O(n log n)：排序 O(n log n)，两次 LIS 各 O(n log n)。
空间 O(n)：`pts` 和 `tails` 各占 O(n)。

## 易错点
- 排序时 x 相同若按 y 升序（`key=lambda p: p[0]`），示例 1 中 `(3,1)` 和 `(4,1)` 这类同 x 点会被误判成可连续上升，导致 `left` 偏大；必须写成 `(p[0], -p[1])`。
- 过滤条件写成 `y <= ky` 或 `y >= ky`：示例 1 里 `(3,1)` 的 y=1 会被错误纳入右侧候选，`right` 变成 2，答案错成 4；严格上升要求左边 `y < ky`、右边 `y > ky`。

## 如果面试官追问
要求输出具体路径而非长度？答：在 LIS 里额外存每个 `tails[i]` 对应的前驱下标，最后从 k 号点向两侧回溯即可。
