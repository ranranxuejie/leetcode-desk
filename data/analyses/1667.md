## 一句话思路
用 `UPPER(LEFT(name,1))` 拼 `LOWER(SUBSTRING(name,2))`，SQL 里逐行字符串函数即可完成首字母大写、其余小写。

## 怎么做
1. 取首字符并转大写：`UPPER(LEFT(name, 1))`。
2. 取第二个字符到末尾并转小写：`LOWER(SUBSTRING(name, 2))`。
3. 两段用 `CONCAT` 拼接，别名仍叫 `name`。
4. 外层 `ORDER BY user_id` 保证输出顺序。

以官方示例 `user_id=1, name='aLice'` 为例：`LEFT('aLice',1)` 得到 `'a'`，`UPPER` 后是 `'A'`；`SUBSTRING('aLice',2)` 得到 `'Lice'`，`LOWER` 后是 `'lice'`；拼接得 `'Alice'`。第二行 `'bOB'` 同理得 `'Bob'`。

```python
# 伪代码：SQL 逻辑映射到 Python 表达
def fix_one(name):
    return name[:1].upper() + name[1:].lower()

# 对每行执行，再按 user_id 升序
rows.sort(key=lambda r: r["user_id"])
result = [(r["user_id"], fix_one(r["name"])) for r in rows]
```

关键点：`SUBSTRING(name, 2)` 在名字长度为 1 时返回空串，`LOWER('')` 仍是空串，拼接不会报错，所以单字符名字 `'a'` 会正确变成 `'A'`。

## 复杂度
时间：O(n·m)，n 为行数，m 为名字平均长度，每行做两次字符串扫描。
空间：O(n·m) 存结果集，排序额外 O(n log n) 比较（若数据库内部排序）。

## 易错点
- 输入 `name='a'`（单字符）→ 若写成 `SUBSTRING(name, 2, LENGTH(name)-1)` 且长度算错，可能截出 `NULL` 或异常 → 直接用 `SUBSTRING(name, 2)`，越界自动为空串。
- 输入 `name='aLice'` → 若只写 `UPPER(name)` 会得到 `'ALICE'`，若只写 `LOWER(name)` 会得到 `'alice'` → 必须首字符单独 `UPPER`、其余单独 `LOWER`，两段拼接。

## 如果面试官追问
问：如果名字含空格或连字符，比如 `'mary-jane'`，怎么处理？
答：题目保证仅字母，若扩展则需按分隔符拆分，每段首字母大写，用正则或 `split` 后逐段处理。
