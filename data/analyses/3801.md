## 一句话思路
对 lists 下标做状压 DP：合并结果只由「哪些原列表进了这一堆」决定，中位数和长度可预计算。

## 怎么做
1. 预处理每个子集 mask 的长度 `L[mask]` 和中位数 `M[mask]`：把 mask 内所有元素收集排序，取下标 `(L[mask]-1)//2`。
2. `dp[mask]` = 把 mask 内列表合成一个的最小成本，`dp[单个] = 0`。
3. 转移：枚举 mask 的**真子集** sub，`dp[mask] = min(dp[sub] + dp[mask^sub] + L[mask] + abs(M[sub] - M[mask^sub]))`。
4. 答案 `dp[(1<<n)-1]`。

以示例 1 为例，`mask = 0b011`（前两个列表）：`L = 5`，收集 `[1,3,5,2,4]` 排序后 `[1,2,3,4,5]`，`M = 3`；拆成 `sub=0b001` 与 `0b010`，`M` 分别为 3 和 2，成本 `0+0+5+abs(3-2)=6`，与题面一致。

```python
n = len(lists)
size = 1 << n
L = [0] * size
M = [0] * size
for mask in range(1, size):
    arr = []
    for i in range(n):
        if mask >> i & 1:
            arr.extend(lists[i])
    arr.sort()
    L[mask] = len(arr)
    M[mask] = arr[(len(arr) - 1) // 2]

INF = float('inf')
dp = [INF] * size
for mask in range(1, size):
    if mask & (mask - 1) == 0:
        dp[mask] = 0
        continue
    sub = (mask - 1) & mask
    while sub:
        other = mask ^ sub
        cost = dp[sub] + dp[other] + L[mask] + abs(M[sub] - M[other])
        if cost < dp[mask]:
            dp[mask] = cost
        sub = (sub - 1) & mask
```

## 复杂度
时间：`O(3^n + 2^n * S log S)`，`S` 为元素总数，子集枚举是 `3^n` 的主项。
空间：`O(2^n)` 存 `dp/L/M`，预处理时临时数组最多 `S` 个元素。

## 易错点
- 偶数长度取左中位数：`[1,4,7,8]` 若写成 `arr[len//2]` 得 7，正确是 `arr[(len-1)//2] = 4`，示例 2 会算成 13 而非 10。
- 枚举子集时把 `sub = mask` 也枚举进去：此时 `other = 0`，`M[0]` 无意义且 `dp[0] = INF`，结果全变 `INF`；必须从 `(mask-1) & mask` 起，且只取真子集。

## 如果面试官追问
问：n 放大到 20 还能这么做吗？
答：不能，`3^20` 约 35 亿；需要利用「合并顺序等价于构造一棵二叉树」的结构另找贪心或区间性质。
