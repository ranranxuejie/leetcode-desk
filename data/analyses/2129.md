## 一句话思路
按空格切词，对每个词按长度分流：长度 ≤2 全小写，否则首字母大写其余小写，再拼回。

## 怎么做
1. 用 `title.split(' ')` 切出单词列表，注意题面保证单空格且无前后空格，所以不用处理空串。
2. 对每个词 `w` 判断 `len(w) <= 2`，是则 `w.lower()`，否则 `w[0].upper() + w[1:].lower()`。
3. 用 `' '.join(...)` 拼回结果。

拿示例 2 的 `"First leTTeR of EACH Word"` 走一遍：切出 `["First","leTTeR","of","EACH","Word"]`；`"leTTeR"` 长度 6，走大写分支得 `"L" + "etter"` = `"Letter"`；`"of"` 长度 2，走小写得 `"of"`；`"EACH"` 长度 4，得 `"Each"`。最终 `"First Letter of Each Word"`。

```python
words = title.split(' ')
res = []
for w in words:
    if len(w) <= 2:
        res.append(w.lower())
    else:
        res.append(w[0].upper() + w[1:].lower())
return ' '.join(res)
```

关键点：`w[1:].lower()` 对长度 3 的词也安全（`w[1:]` 非空），不需要额外判空。

## 复杂度
时间 O(n)：n 为 `title` 总字符数，每个字符最多被 lower/upper 处理一次。
空间 O(n)：`res` 列表和 join 结果各占 O(n)，切词列表也是 O(n)。

## 易错点
- 输入 `"i lOve leetcode"` → 若对长度 1 的词也做 `w[0].upper() + w[1:].lower()`，`"i"` 会变成 `"I"`，错成 `"I Love Leetcode"`；正确做法是先判 `len(w) <= 2` 直接 `lower()`，长度 1 和 2 走同一分支。
- 输入 `"capiTalIze tHe titLe"` → 若只做 `w[0].upper() + w[1:]`（忘了对剩余部分 `lower()`），`"capiTalIze"` 会变成 `"CapiTalIze"`，中间的大写 `T`、`I` 残留；正确做法是 `w[1:].lower()` 把尾部全部压成小写。

## 如果面试官追问
问：如果单词间可能有多个空格或前后空格怎么办？
答：改用 `title.split()` 无参切分自动吞掉连续空白，再用 `' '.join` 拼回，输出即为单空格规范化形式。
