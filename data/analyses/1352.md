## 一句话思路
维护前缀积数组 `pre`，遇 0 就清空重开，`getProduct(k)` 用两次前缀积相除得答案。

## 怎么做
1. `pre` 初始为 `[1]`，表示空前缀积；`add(num)` 时若 `num == 0` 则把 `pre` 重置为 `[1]`，否则 `pre.append(pre[-1] * num)`。
2. 重置的意义是：0 之后的所有查询都不可能跨过这个 0，前缀积从 0 之后重新起算。
3. `getProduct(k)` 先判断 `k >= len(pre)`，是则说明最后 k 个数里含 0，直接返回 0。
4. 否则返回 `pre[-1] // pre[-1 - k]`，两个前缀积相除正好约掉前 `len(pre)-1-k` 个数。

以官方示例走一遍：`add(3)` 后 `pre=[1,3]`；`add(0)` 触发重置 `pre=[1]`；再 `add(2),add(5),add(4)` 得 `pre=[1,2,10,40]`。此时 `getProduct(2)`：`k=2 < len(pre)=4`，返回 `pre[-1]//pre[-3] = 40//2 = 20`，与输出 20 一致。`getProduct(4)`：`k=4 >= 4`，返回 0，对应 `[0,2,5,4]` 含 0。

```python
def add(self, num):
    if num == 0:
        self.pre = [1]
    else:
        self.pre.append(self.pre[-1] * num)

def getProduct(self, k):
    if k >= len(self.pre):
        return 0
    return self.pre[-1] // self.pre[-1 - k]
```

关键点：`pre` 的长度是「自最近一个 0 之后的元素个数 + 1」，所以 `k >= len(pre)` 恰好等价于「最后 k 个数跨过了 0」。

## 复杂度
时间：`add` 和 `getProduct` 均 O(1)，只有一次乘法或一次整除。
空间：O(n)，`pre` 最多存 n+1 个前缀积，n 为自最近 0 之后的元素数。

## 易错点
- 输入 `add(0)` 后紧跟 `getProduct(1)`：若只在 `pre` 末尾追加 0 而不重置，`pre[-1]//pre[-2]` 会变成 `0//x = 0` 看似对，但再 `add(5)` 后 `getProduct(1)` 会算成 `0//0` 直接除零崩溃；正确做法是遇 0 立刻把 `pre` 重置为 `[1]`。
- 输入 `[3,0,2,5,4]` 查 `getProduct(4)`：若忘记 `k >= len(pre)` 这个判断，会去取 `pre[-5]`，而重置后 `pre` 只有 4 个元素，索引越界；正确做法是先比 `k` 与 `len(pre)`，跨 0 直接返回 0。

## 如果面试官追问
问：如果 `num` 允许负数，前缀积相除还成立吗？
答：不成立，除法会丢符号信息，需改存前缀积的绝对值加负号计数，或直接上线段树。
