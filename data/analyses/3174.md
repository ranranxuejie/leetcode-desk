## 一句话思路
用栈从左到右扫 `s`：字母入栈，遇数字就弹出栈顶字母，栈里剩下的就是答案。

## 怎么做
1. 建空列表 `st`，遍历 `s` 的每个字符 `ch`。
2. `ch` 是字母就 `st.append(ch)`。
3. `ch` 是数字就 `st.pop()`，因为题面保证每个数字左边必有可删的字母，不用判空。
4. 遍历完 `"".join(st)` 即结果。

拿 `s = "cb34"` 走一遍：`'c'`、`'b'` 入栈得 `st = ['c','b']`；读到 `'3'` 弹出 `'b'`，`st = ['c']`；读到 `'4'` 弹出 `'c'`，`st = []`；返回 `""`。关键中间值是第二次 pop 后栈变空，正好对上示例输出。

```python
st = []
for ch in s:
    if ch.isdigit():
        st.pop()
    else:
        st.append(ch)
return "".join(st)
```

为什么等价于题面的「删第一个数字和它左边最近的非数字」：从左扫时，栈顶永远是当前数字左边最近、还没被消耗掉的字母，弹它正好就是题面那一步。数字被删后左右拼接，不会产生新的「最近字母」关系，所以一遍扫描就够，不用真的模拟字符串删除。

## 复杂度
时间 O(n)：n 是 `len(s)`，每个字符入栈或出栈各一次。
空间 O(n)：`st` 最坏存下全部字母，即 `s` 无数字时。

## 易错点
- 输入 `s = "abc"` 无数字 → 若在数字分支里先 `if st:` 再 pop 倒不会错，但若写成「遇数字就 `st = st[:-1]`」且不判空，空栈切片虽不报错却掩盖了逻辑；正确做法是直接 `st.pop()`，靠题面「所有数字都可被删除」的保证兜底。
- 输入 `s = "a1b2"` → 若误以为数字只删它紧邻的前一个原始字符（即固定位置配对），会算成删 `'a'` 和 `'1'` 之外的东西；正确做法是动态看栈顶：`'a'` 入栈、`'1'` 弹 `'a'`、`'b'` 入栈、`'2'` 弹 `'b'`，结果 `""`。

## 如果面试官追问
问：若数字可能出现在最左边、无法删除，怎么办？
答：pop 前判 `if st:`，否则跳过该数字，其余逻辑不变。
