## 一句话思路
用回溯 + 位掩码记录已访问格，走满所有非障碍格且落在终点才计数。

## 怎么做
1. 先扫一遍 grid，把 `1` 记为 `start`、`2` 记为 `end`，同时统计非障碍格总数 `total`（含起点终点）。
2. 把每个格子映射成位下标 `r * C + c`，起点已访问，掩码初值 `1 << (sr * C + sc)`。
3. 从 `start` 做 DFS：每步只走 `grid[nr][nc] != -1` 且掩码对应位为 0 的邻居，进入时置位。
4. 到达 `end` 时，只有 `mask.bit_count() == total` 才 `ans += 1`，否则直接返回（终点不能再往外走）。

以示例 1 为例，`total = 11`（12 格减 1 个 `-1`）。走到 `(2,2)` 时掩码里恰好 11 位为 1，`bit_count() == 11` 成立，计 1；若提前踩到 `(2,2)` 而只访问了 9 格，`bit_count() == 9 != 11`，这条分支作废。

```python
def dfs(r, c, mask):
    if (r, c) == end:
        return 1 if mask.bit_count() == total else 0
    res = 0
    for dr, dc in dirs:
        nr, nc = r + dr, c + dc
        if 0 <= nr < R and 0 <= nc < C and grid[nr][nc] != -1:
            bit = 1 << (nr * C + nc)
            if not mask & bit:
                res += dfs(nr, nc, mask | bit)
    return res
```

## 复杂度
时间：O(4^total)，每个非障碍格最多被四条分支尝试，total ≤ 20。
空间：O(total)，递归栈深度加一个整数掩码，无额外矩阵。

## 易错点
- 输入 `[[1,2]]`（起点终点相邻、无空格）→ 若在 `(r,c)==end` 时无条件返回 1，会漏判 `total`，正确做法是仍比较 `mask.bit_count() == total`，此处 total=2、掩码两位为 1，返回 1。
- 输入示例 3 `[[0,1],[2,0]]` → 若允许从 `end` 继续走，会绕出重复路径把答案算成非 0；正确做法是到达 `end` 立即结算并 return，不再扩展邻居。

## 如果面试官追问
问：total 到 25 以上怎么办？
答：状压 DP 存 `(r, c, mask)` 会爆内存，只能靠剪枝或改判可达性，本题 20 的上限正是为回溯留的口子。
