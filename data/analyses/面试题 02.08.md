## 一句话思路
快慢指针先判环并相遇，再让一个指针回到 head，两指针同速走，相遇点即环入口。

## 怎么做
1. 快指针 `fast` 每次走两步、慢指针 `slow` 每次走一步，直到 `fast is None or fast.next is None` 返回 `None`。
2. 相遇后把 `slow` 重置为 `head`，`fast` 留在相遇点。
3. 两指针每次各走一步，再次相遇的节点就是入口。

以 `head = [3,2,0,-4], pos = 1` 为例：节点依次是 3→2→0→-4→2。`slow` 走 3,2,0；`fast` 走 2,-4,2，在节点 `2`（索引 1）相遇。此时 `slow` 回 `head`（节点 3），`fast` 在节点 2；各走一步：`slow`→2，`fast`→0，未遇；再走：`slow`→0，`fast`→-4；再走：`slow`→-4，`fast`→2；再走：`slow`→2，`fast`→0……这里要按标准推导：设头到入口距离 a、入口到相遇点距离 b、环长 c，则 `a = c - b`，所以 `slow` 从 head 走 a 步、`fast` 从相遇点走 c-b 步恰好同时到入口。

```python
slow = fast = head
while fast and fast.next:
    slow, fast = slow.next, fast.next.next
    if slow is fast:
        slow = head
        while slow is not fast:
            slow, fast = slow.next, fast.next
        return slow
return None
```

关键中间值：示例 1 中第一次相遇在索引 1 的节点（值 2），第二次相遇也在该节点，返回它。

## 复杂度
时间：O(n)，`slow` 与 `fast` 合计走过的节点数线性于链表长度。
空间：O(1)，只用了 `slow`、`fast` 两个指针，没有额外容器。

## 易错点
- 输入 `head = [1], pos = -1`（单节点无环）→ 若循环条件写成 `while fast.next`，`fast.next` 为 `None` 时访问 `.next.next` 抛异常 → 正确写法是 `while fast and fast.next`，先判 `fast` 再判 `fast.next`。
- 输入 `head = [1,2], pos = 0`（入口就是头节点）→ 若第二次循环写成先移动再比较，会跳过入口节点、绕一圈才返回 → 正确做法是 `slow = head` 后先比较 `slow is not fast` 再移动，让头节点本身参与第一次比较。

## 如果面试官追问
问：不用双指针、允许额外空间怎么做？
答：用 `set` 存已访问节点，第一个重复出现的节点即入口，时间 O(n)、空间 O(n)。
