## 一句话思路
把 columnNumber 看成 26 进制，但每位取值是 1..26 而非 0..25，所以每轮先减 1 再取模。

## 怎么做
1. 循环条件用 `columnNumber > 0`，每轮先执行 `columnNumber -= 1`，把 1..26 的偏移压成 0..25。
2. 用 `columnNumber % 26` 取当前最低位，映射到 `chr(ord('A') + r)`。
3. 用 `columnNumber //= 26` 去掉这一位，继续处理高位。
4. 结果按低位到高位生成，最后 `[::-1]` 反转。

以 `columnNumber = 701` 为例：第一轮 `701 - 1 = 700`，`700 % 26 = 24` 得 `'Y'`，`700 // 26 = 26`；第二轮 `26 - 1 = 25`，`25 % 26 = 25` 得 `'Z'`，`25 // 26 = 0` 结束，反转得 `"ZY"`。

```python
def convertToTitle(columnNumber):
    res = []
    while columnNumber > 0:
        columnNumber -= 1
        res.append(chr(ord('A') + columnNumber % 26))
        columnNumber //= 26
    return ''.join(reversed(res))
```

关键在 `-1` 的位置：它必须在取模之前，且每轮都做。若写成先取模再减一，`701` 第一轮会得到 `701 % 26 = 25` 即 `'Z'`，直接错位。

## 复杂度
时间：O(log₂₆ columnNumber)，循环次数等于结果的位数。
空间：O(log₂₆ columnNumber)，`res` 列表存每一位字符。

## 易错点
- 输入 `columnNumber = 26` → 不减 1 直接 `26 % 26 = 0` 得 `'A'`，错成 `"A"` 而非 `"Z"` → 必须先 `columnNumber -= 1` 再取模。
- 输入 `columnNumber = 52` → 若用 `while columnNumber:` 但在循环末尾才减 1，`52` 会先算出 `52 % 26 = 0` 得 `'A'`，错成 `"AZ"` 而非 `"AZ"` 的正确值 `"AZ"` 之外的 `"BA"` 类错位 → 减 1 必须紧跟循环入口，保证每轮取模前数值已偏移。

## 如果面试官追问
问：如果要求返回从 `"A"` 开始的第 n 个名称的序号（反向转换）？答：逐位 `ord(c) - ord('A') + 1` 累加 `total = total * 26 + v`，同样注意每位是 1..26。
