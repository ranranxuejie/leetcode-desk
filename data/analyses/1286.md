## 一句话思路
预处理阶段用回溯一次性生成全部组合（天然字典序），存进列表加下标指针，`next` 取指针处元素后指针加一。

## 怎么做
1. 构造函数里对 `characters` 做 DFS：从下标 `start` 起选字符，选满 `combinationLength` 个就拼成字符串追加到 `self.combos`。
2. 因为每层都从 `start` 递增枚举，`"abc"` 取 2 个得到的顺序必然是 `["ab","ac","bc"]`，无需额外排序。
3. `next()` 返回 `self.combos[self.idx]` 后 `self.idx += 1`；`hasNext()` 返回 `self.idx < len(self.combos)`。

以 `characters="abc"`、`combinationLength=2` 为例，DFS 第一层选 `'a'`（`start=0`），第二层只能从 `start=1` 选，得 `"ab"`、`"ac"`；回溯后第一层选 `'b'`（`start=1`），第二层从 `start=2` 选，得 `"bc"`。三次 `next` 依次返回 `"ab"`、`"ac"`、`"bc"`，此时 `idx=3` 等于 `len(combos)=3`，`hasNext()` 返回 `False`。

```python
def dfs(start, path):
    if len(path) == self.k:
        self.combos.append("".join(path))
        return
    for i in range(start, len(self.chars)):
        path.append(self.chars[i])
        dfs(i + 1, path)
        path.pop()

dfs(0, [])
self.idx = 0
```

## 复杂度
时间：预处理 O(C(n,k)·k)，n 为 `characters` 长度，每次 `next`/`hasNext` 均 O(1)。
空间：`self.combos` 存 C(n,k) 个长度 k 的字符串，共 O(C(n,k)·k)。

## 易错点
1. 递归里写成 `dfs(start + 1, path)` 而不是 `dfs(i + 1, path)` → `"abc"` 取 2 会漏掉 `"ac"`、`"bc"` 只留 `"ab"` → 下一层起点必须跟着当前选中的下标 `i` 走。
2. 用 `itertools.combinations` 后忘记 `"".join`，或把 `next` 写成先加指针再取值 → 首次 `next()` 返回 `"ac"` 而非 `"ab"` → 先取 `self.combos[self.idx]` 再自增。

## 如果面试官追问
若 `characters` 长度升到 10^3 且只调少量 `next`，还预处理吗？答：改用「下一个组合」原地推进，O(k) 找最右可增位，避免 C(n,k) 爆炸。
