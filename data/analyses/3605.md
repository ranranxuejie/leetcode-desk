## 一句话思路
二分答案 L，用线段树维护区间 gcd，贪心判断能否用 ≤ maxC 次修改把每个长度 L 的窗口都打破。

## 怎么做
1. 二分稳定性因子 L（范围 1..n），判定「能否让最长稳定子数组 ≤ L-1」。
2. 判定时从左往右扫，维护当前稳定段起点 `start`；若 `[start, i]` 的 gcd ≥ 2 且长度 = L，就必须改一个元素。
3. 贪心改最右端 `nums[i]`（改成 1 或质数），`count++`，并把 `start` 重置为 `i+1`。
4. 用线段树 O(log n) 查区间 gcd，避免每次重算。

以 `nums=[2,4,9,6], maxC=1` 判 L=2：i=1 时 gcd(2,4)=2 长度 2，改 nums[1]，count=1，start=2；i=3 时 gcd(9,6)=3 长度 2，count=2 > maxC，判定失败，故答案 ≥ 2。

```python
def check(L):
    cnt, start = 0, 0
    for i in range(n):
        if i - start + 1 == L:
            if query(start, i) >= 2:
                cnt += 1
                start = i + 1
            else:
                start += 1
    return cnt <= maxC
```

## 复杂度
时间：二分 O(log n) × 判定 O(n log n) = O(n log² n)，线段树查询贡献 log n。
空间：线段树 4n 数组，O(n)。

## 易错点
- `nums=[1,1,1], maxC=0` → 误判 gcd=1 的段稳定 → 正确做法是 gcd < 2 直接跳过，`start` 前移。
- `nums=[2,4,9,6], maxC=1` 判 L=2 → 只改一个就以为够 → 实际两段独立稳定段各需一次修改，count=2 超限，必须返回 2 而非 1。

## 如果面试官追问
若要求输出具体修改方案？答：判定时记录每次贪心改的下标 i，改成 1 即可，回放这些下标就是方案。
