## 一句话思路
有序数组中超过 25% 的元素必然占据某个长度为 `n//4` 的窗口，只需检查 `arr[i]` 与 `arr[i + n//4]` 是否相等。

## 怎么做
1. 令 `step = len(arr) // 4`，任何出现次数超过 25% 的值，其第 `step` 个后继仍是它自己。
2. 从 `i = 0` 遍历到 `len(arr) - step - 1`，比较 `arr[i]` 和 `arr[i + step]`。
3. 一旦相等就返回 `arr[i]`，因为题目保证恰好有一个这样的整数。
4. 用官方示例验证：`arr = [1,2,2,6,6,6,6,7,10]`，`n = 9`，`step = 2`。当 `i = 3` 时，`arr[3] = 6`，`arr[3+2] = arr[5] = 6`，两者相等，返回 `6`。

```python
def findSpecialInteger(arr):
    step = len(arr) // 4
    for i in range(len(arr) - step):
        if arr[i] == arr[i + step]:
            return arr[i]
    return arr[-1]
```

关键中间值：`step = 9 // 4 = 2`；`i = 3` 时 `arr[3] = 6`、`arr[5] = 6`，命中返回。

## 复杂度
时间：O(n)，一次线性扫描，`n = len(arr)`。
空间：O(1)，只用了 `step` 和循环变量 `i`。

## 易错点
- 输入 `arr = [1,2,2,6,6,6,6,7,10]` 时，若把 `step` 写成 `len(arr) // 4 + 1 = 3`，会漏掉 `arr[3]` 与 `arr[6]` 的匹配，正确做法是严格用 `n // 4`，因为超过 25% 意味着至少 `n//4 + 1` 个连续相同。
- 输入 `arr = [1,1,2,3,4]`（`n = 5`，`step = 1`）时，若循环写成 `range(len(arr) - step + 1)`，`i` 会取到 `4`，访问 `arr[5]` 越界；正确上界是 `len(arr) - step`，即 `range(4)`。

## 如果面试官追问
问：若数组未排序怎么办？答：先排序再套本方法，时间变 O(n log n)；或用哈希计数 O(n) 空间找超过 `n//4` 的值。
