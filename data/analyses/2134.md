## 一句话思路
数出 1 的个数 k，在环形数组上滑一个长度 k 的窗口，窗口内 0 最少即答案。

## 怎么做
1. 先统计 `nums` 中 1 的总数 `k`；若 `k <= 1` 直接返回 0。
2. 把数组首尾相接，用 `nums[i % n]` 取元素，窗口长度固定为 `k`。
3. 初始窗口 `[0, k-1]` 内 0 的个数记为 `zeros`，`ans = zeros`。
4. 窗口右移一格：右端进 `nums[(i+k) % n]`，左端出 `nums[i % n]`，同步增减 `zeros`，取最小值。

以示例 1 `nums = [0,1,0,1,1,0,0]` 为例，`n=7`，1 的个数 `k=3`。初始窗口下标 0..2 是 `[0,1,0]`，`zeros=2`，`ans=2`；右移一格窗口变 `[1,0,1]`，`zeros=1`，`ans=1`；再右移窗口 `[0,1,1]`，`zeros=1`。最终 `ans=1`，与输出一致。

```python
n = len(nums)
k = sum(nums)
if k <= 1:
    return 0
zeros = nums[:k].count(0)
ans = zeros
for i in range(1, n):
    if nums[(i + k - 1) % n] == 0:
        zeros += 1
    if nums[i - 1] == 0:
        zeros -= 1
    ans = min(ans, zeros)
return ans
```

关键点：窗口长度必须恰好是 `k`，因为最终那堆 1 占 `k` 个位置，窗口里已有的 1 不用动，剩下的 0 每个都要和窗口外的 1 换一次，所以交换次数就是窗口内 0 的个数。

## 复杂度
时间 O(n)：`k` 次初始统计加 n 次滑动，每次 O(1)。
空间 O(1)：只用了 `k`、`zeros`、`ans` 几个变量，没开新数组。

## 易错点
- `nums = [1,1,0,0,1]` 这类首尾相接已聚集的输入 → 若只扫 `0..n-k` 不取模，会漏掉跨界的窗口 `[1,0,0,1,1]` 而返回 1 → 必须用 `(i+k-1) % n` 和 `i % n` 取模，让窗口绕回。
- `nums` 全 0 或只有 1 个 1 → 若直接进循环，`k=0` 时窗口长度为 0、`zeros` 逻辑失效，可能返回负数或死循环 → 开头加 `if k <= 1: return 0` 挡住。

## 如果面试官追问
问：要求输出具体交换方案怎么办？
答：记录 `zeros` 最小的窗口起点，把窗口内每个 0 与窗口外最近的 1 配对交换，按配对顺序输出即可。
