## 一句话思路
从右往左找最长的严格递增后缀，再从左往右找能接上它的最短前缀长度。

## 怎么做
1. 从末尾往前扫，找到最长的严格递增后缀起点 `i`，即 `nums[i] < nums[i+1]` 一直成立的最左位置。
2. 若 `i == 0`，整个数组已递增，直接返回 0。
3. 否则从左往右找第一个满足 `nums[j] < nums[i]` 的位置 `j`，答案就是 `j`（保留 `nums[j:]` 接上后缀）。
4. 边界：若找不到这样的 `j`，说明要删掉整个前缀，返回 `i`。

以 `nums = [1,-1,2,3,3,4,5]` 为例：从右扫，`3 < 4 < 5` 成立，但 `nums[3]=3` 与 `nums[4]=3` 不满足严格小于，所以最长递增后缀起点 `i = 4`（后缀 `[3,4,5]`）。再从 `j=0` 往右找第一个 `nums[j] < nums[4]=3` 的位置，`j=3` 时 `nums[3]=3` 不满足，`j=4` 时 `nums[4]=3` 也不满足……实际第一个满足的是 `j=4` 本身？注意 `nums[3]=3` 不小于 3，`j` 需满足 `nums[j] < nums[i]`，`j=3` 时 `3<3` 假，`j=4` 时 `3<3` 假，继续到 `j=4` 之后没有更小值，故返回 `i=4`，与答案一致。

```python
i = len(nums) - 1
while i > 0 and nums[i-1] < nums[i]:
    i -= 1
if i == 0:
    return 0
j = 0
while j < i and nums[j] >= nums[i]:
    j += 1
return j if j < i else i
```

## 复杂度
时间：O(n)，两次线性扫描，`i` 和 `j` 各走一遍。
空间：O(1)，只用了 `i`、`j` 两个下标变量。

## 易错点
- 输入 `[4,3,-2,-5]`：从右扫时 `-5 < -2` 成立、`-2 < 3` 成立、`3 < 4` 不成立，`i=1`；若误把 `i` 初始化为 `len-1` 后不检查 `nums[i-1] < nums[i]` 就停，会错成 0。正确做法是循环条件必须带 `nums[i-1] < nums[i]`。
- 输入 `[1,2,3,4]`：`i` 会一路减到 0，必须显式 `return 0`；若漏掉这个分支，`j` 循环里 `nums[j] >= nums[0]` 对 `j=0` 为假，`j` 停在 0 返回 0 恰好对，但换成 `[1,1,2]` 就会错——`i=1`，`j` 需找 `nums[j] < nums[1]=1`，`j=0` 时 `1<1` 假，`j` 走到 1 返回 1，正确；真正坑是 `[2,1]`：`i=1`，`j` 找 `nums[j] < 1`，`j=0` 时 `2<1` 假，`j` 到 1 返回 1，正确。所以关键是 `j` 循环条件用 `>=` 而非 `>`。

## 如果面试官追问
若要求输出被移除的前缀本身而非长度，答：返回 `nums[:j]`，`j` 的求法不变，只是把返回值从下标换成切片。
