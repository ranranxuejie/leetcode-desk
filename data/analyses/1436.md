## 一句话思路
终点站只出现在 `cityB` 位置、从不出现在 `cityA` 位置，所以把每个 `cityB` 收进集合，再找不在 `cityA` 集合里的那个。

## 怎么做
1. 遍历 `paths`，把所有 `cityA`（`p[0]`）放进 `starts` 集合。
2. 同一趟遍历里把所有 `cityB`（`p[1]`）放进 `ends` 集合。
3. 返回 `ends - starts` 里唯一的那个元素。

以示例 2 `[["B","C"],["D","B"],["C","A"]]` 为例：`starts = {"B","D","C"}`，`ends = {"C","B","A"}`，差集只剩 `"A"`，正是答案。注意 `"B"`、`"C"` 同时出现在两边，被差集消掉，这就是为什么不能只看「出现过几次」。

```python
starts, ends = set(), set()
for a, b in paths:
    starts.add(a)
    ends.add(b)
return (ends - starts).pop()
```

也可以只用一个集合做加减：遇到 `cityA` 就 `discard`，遇到 `cityB` 就 `add`，最后剩下的就是终点站。但两集合差集更直白，且 `ends - starts` 天然只留一个元素，`.pop()` 不会取错。

## 复杂度
时间 O(n)：n 是 `paths` 长度，每个城市名做一次哈希插入/查找，字符串长度 ≤10 视为常数。
空间 O(n)：`starts` 和 `ends` 各最多存 n 个城市名。

## 易错点
1. 用「计数」思路时把 `cityA` 和 `cityB` 混在一个字典里加减 → 对示例 2 会得到 `"D"` 或 `"A"` 两个候选（`"D"` 只出现在 `cityA`，`"A"` 只出现在 `cityB`），分不清起点和终点 → 必须区分方向：只有「出现在 `cityB` 且从未出现在 `cityA`」才是终点。
2. 直接返回 `ends` 里第一个元素或 `paths[-1][1]` → 示例 2 的 `paths[-1][1]` 恰好是 `"A"` 蒙对，但示例 1 若把路径顺序打乱成 `[["Lima","Sao Paulo"],["London","New York"],["New York","Lima"]]`，`paths[-1][1]` 是 `"Lima"` 就错了 → 必须用集合差集，不能依赖输入顺序。

## 如果面试官追问
问：如果线路图允许有多个终点站（不保证唯一）怎么办？
答：把返回值改成 `list(ends - starts)`，逻辑不变，只是不再 `.pop()` 取单个。
