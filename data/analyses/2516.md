## 一句话思路
正难则反：取走的两端最少，等价于**中间留下的连续子串最长**，且留下的部分每种字符不超过 `total[c] - k` 个。

## 怎么做
1. 先统计 `s` 中 `'a'/'b'/'c'` 的总数，任一字符总数 `< k` 直接返回 `-1`。
2. 记 `need[c] = total[c] - k`，即中间子串里字符 `c` 最多能出现的次数。
3. 用滑动窗口在 `s` 上找**满足 `cnt[c] <= need[c]` 的最长连续子串**，窗口右端扩张、越界时左端收缩。
4. 答案是 `n - 最长窗口长度`。

以 `s = "aabaaaacaabc", k = 2` 为例：`total = {a:8, b:2, c:2}`，`need = {a:6, b:0, c:0}`。窗口里 `'b'`、`'c'` 一个都不能有，最长合法窗口是 `"aaaaaa"`（长度 6，位置 3..8），答案 `12 - 6 = 8`。

```python
total = {c: s.count(c) for c in 'abc'}
if any(total[c] < k for c in 'abc'):
    return -1
need = {c: total[c] - k for c in 'abc'}
cnt = {'a': 0, 'b': 0, 'c': 0}
left = best = 0
for right, ch in enumerate(s):
    cnt[ch] += 1
    while cnt[ch] > need[ch]:
        cnt[s[left]] -= 1
        left += 1
    best = max(best, right - left + 1)
return len(s) - best
```

注意 `while` 条件只判 `cnt[ch] > need[ch]`：只有刚进来的字符可能越界，其余字符在上一轮已合法。

## 复杂度
时间 O(n)：`right` 和 `left` 各单调走一遍，`s.count` 也是 O(n)。
空间 O(1)：只有两个长度 3 的字典 `total`、`need` 和 `cnt`。

## 易错点
- `k = 0` 时 `need[c] = total[c]`，整个串都合法，`best` 应为 `n`、答案 0。若把 `while` 写成 `cnt[ch] >= need[ch]`，窗口会被压到 0，返回 `n`。
- 收缩窗口时若只减 `cnt[ch]` 而不减 `cnt[s[left]]`，`"aabaaaacaabc"` 里 `'b'` 的计数永远不归零，`left` 会一路推到 `right`，`best` 偏小、答案偏大。

## 如果面试官追问
若字符集从 `'a'~'c'` 扩到 26 个小写字母？答：代码不用改，把 `'abc'` 换成 `string.ascii_lowercase`，仍是 O(26n) = O(n)。
