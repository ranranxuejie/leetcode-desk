## 一句话思路
先在原矩阵内按列做「石头下沉」，再整体顺时针旋转 90 度，顺序不能反。

## 怎么做
1. 逐列处理，用 `bottom` 记录当前可落位置的行下标，从 `m-1` 往上扫。
2. 遇到 `'*'` 就把 `bottom` 重置为 `i-1`，遇到 `'#'` 就交换到 `bottom` 并让 `bottom` 减一。
3. 旋转：新矩阵 `res[j][m-1-i] = boxGrid[i][j]`，尺寸 `n x m`。

以示例 2 的 `boxGrid` 为例，第 0 列是 `['#','#']`，`bottom` 从 1 开始，两个 `'#'` 都不动；第 3 列是 `['.','.']`，无石头。关键中间值在第 1 列 `['.','#']`：`i=1` 是 `'#'`，交换到 `bottom=1` 后 `bottom` 变 0，`i=0` 是 `'.'` 跳过，结果仍是 `['.','#']`。

```python
m, n = len(boxGrid), len(boxGrid[0])
for j in range(n):
    bottom = m - 1
    for i in range(m - 1, -1, -1):
        if boxGrid[i][j] == '*':
            bottom = i - 1
        elif boxGrid[i][j] == '#':
            boxGrid[i][j], boxGrid[bottom][j] = '.', '#'
            bottom -= 1
res = [['.'] * m for _ in range(n)]
for i in range(m):
    for j in range(n):
        res[j][m - 1 - i] = boxGrid[i][j]
```

注意 `bottom` 只在遇到 `'*'` 或落下一颗石头时移动，空位 `'.'` 不消耗它，这正是「石头垂直掉落」的语义。

## 复杂度
时间：O(m·n)，每格被列扫描和旋转各访问一次。
空间：O(m·n)，额外开了 `n x m` 的结果矩阵 `res`。

## 易错点
- 输入 `[["#",".","#"]]`（单行）→ 若先旋转再落石，石头会横向挤到一列，输出错成 `[["#"],["#"],["."]]`；正确做法是先按原列下沉再旋转，得到 `[["."],["#"],["#"]]`。
- 列内 `['#','.','*','#']` 这类含障碍的列 → 若 `bottom` 遇到 `'.'` 也减一，上方石头会穿过 `'*'`；正确做法是只在 `'*'` 处把 `bottom` 重置为 `i-1`，`'.'` 不动 `bottom`。

## 如果面试官追问
若要求原地旋转、不许开 `res`？答：`n x m` 与 `m x n` 形状不同，原地不可行，只能开新矩阵，空间 O(m·n) 已是下界。
