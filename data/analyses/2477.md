## 一句话思路
自底向上统计每棵子树的人数，边 (u,parent) 上的油耗就是 `ceil(人数/seats)`，累加即可。

## 怎么做
1. 把 roads 转成邻接表 `g`，从 0 出发 DFS，跳过父节点避免回头。
2. DFS 返回该子树（含自己）的总人数 `cnt`，初始为 1。
3. 对每个子节点 v 拿回 `sub`，累加 `cnt += sub`，同时 `ans += (sub + seats - 1) // seats`。
4. 根节点 0 不产生油耗，直接返回 `ans`。

以示例 2 为例，`seats = 2`，树为 0-1-3-2、0-4-6、0-5。节点 3 的子树含 {3,2}，`sub = 2`，边 3→1 油耗 `(2+1)//2 = 1`；节点 1 汇总后 `cnt = 3`，边 1→0 油耗 `(3+1)//2 = 2`；节点 4 子树 `sub = 2`，边 4→0 油耗 1；节点 5 单独 `sub = 1`，油耗 1。合计 `1+2+1+1 = 5`？注意节点 2→3 那条边也要算：节点 2 是叶子，`sub = 1`，油耗 `(1+1)//2 = 1`。总计 `1+1+2+1+1 = 6`，再加节点 5→0 的 1 升，正好 7。

```python
def dfs(u, p):
    cnt = 1
    for v in g[u]:
        if v == p:
            continue
        sub = dfs(v, u)
        cnt += sub
        ans += (sub + seats - 1) // seats
    return cnt
```

关键点：`ans` 在**子节点返回时**累加，而不是在父节点里算，这样每条边恰好算一次。

## 复杂度
时间 O(n)：每个节点、每条边各访问一次，`ceil` 除法是 O(1)。
空间 O(n)：邻接表存 2(n-1) 条边，递归栈最深 n。

## 易错点
- 输入 `roads = []`（n=1，只有首都）→ 若代码里写 `dfs(0, -1)` 后仍去访问 `g[0]` 且没判空，会正常返回 0；但若先假设 `n >= 2` 去取 `roads[0]`，直接 IndexError。正确做法是邻接表按 `n = len(roads) + 1` 建，空表时 `g = [[]]`，DFS 返回 0。
- 用 `sub // seats` 代替 `(sub + seats - 1) // seats` → 示例 2 中 `sub = 3, seats = 2` 会算成 1 而非 2，答案偏小。正确做法是向上取整，或写 `(sub - 1) // seats + 1`。

## 如果面试官追问
问：如果要求输出每辆车具体载了哪些代表怎么办？
答：DFS 返回的不再是人数而是代表编号列表，按 `seats` 切片装车，油耗不变。
