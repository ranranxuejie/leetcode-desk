## 一句话思路
把「两人之间有几个、两侧各几个」压成状态 `(l, r, k)` 做记忆化搜索，因为每回合只有这三段人数影响两人何时相遇。

## 怎么做
1. 记 `l = firstPlayer - 1`（左侧人数）、`r = n - secondPlayer`（右侧人数）、`k = secondPlayer - firstPlayer - 1`（中间人数），两人相遇当且仅当 `k == 0`。
2. 每回合中间 `k` 人两两配对，`l` 与 `r` 配对，剩余的人轮空；枚举中间 `k` 人里有多少人晋级（`i` 个），左侧 `l` 人里有多少人晋级（`j` 个）。
3. 新状态为 `(j, l + r - j - i, i)`，递归取所有合法 `(i, j)` 的最小/最大值再加 1。
4. 用 `lru_cache` 记忆化，`k == 0` 时返回 `(0, 0)`。

以 `n = 11, firstPlayer = 2, secondPlayer = 4` 为例：初始 `l = 1, r = 7, k = 1`。中间只有运动员 3，若他晋级则 `i = 1`；左侧运动员 1 若被淘汰则 `j = 0`，新状态 `(0, 7 + 1 - 0 - 1, 1) = (0, 7, 1)`，继续递归。

```python
from functools import lru_cache

@lru_cache(None)
def dfs(l, r, k):
    if k == 0:
        return (0, 0)
    lo, hi = 10**9, -1
    for i in range(k + 1):          # 中间晋级人数
        for j in range(l + 1):      # 左侧晋级人数
            if i + j > (l + r + k) // 2:
                continue
            a, b = dfs(j, l + r - j - i, i)
            lo, hi = min(lo, a), max(hi, b)
    return (lo + 1, hi + 1)
```

## 复杂度
时间：状态数 `O(n^3)`，每状态枚举 `O(n^2)`，总 `O(n^5)`，`n ≤ 28` 可过。
空间：`lru_cache` 存 `O(n^3)` 个状态，每状态一个二元组。

## 易错点
- 输入 `n = 5, firstPlayer = 1, secondPlayer = 5`：若忘记 `k == 0` 时返回 `(0, 0)` 而非继续递归，会死循环或返回 `[2,2]`；正确做法是相遇即终止，答案为 `[1,1]`。
- 输入 `n = 11, firstPlayer = 2, secondPlayer = 4`：若枚举 `i` 时允许 `i > k` 或 `j > l`，会造出非法状态导致答案偏小；正确做法是 `i` 取 `0..k`、`j` 取 `0..l`，且 `i + j` 不超过本回合总晋级数。

## 如果面试官追问
问：若 `n` 扩大到 `10^9` 怎么办？
答：状态只依赖 `l, r, k` 的相对大小，可对三段做对称压缩并加公式化剪枝，避免枚举全部 `(i, j)`。
