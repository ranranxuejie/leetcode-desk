## 一句话思路
双指针 i、j 同步推进，每轮先取 word1[i] 再取 word2[j]，谁先走完就把另一个的剩余部分整段拼上。

## 怎么做
1. 初始化 `i = j = 0`，结果用列表 `res = []` 收集，避免字符串反复拼接。
2. 当 `i < len(word1) and j < len(word2)` 时，依次 `res.append(word1[i])`、`res.append(word2[j])`，然后 `i += 1`、`j += 1`。
3. 循环结束后，把没走完的那个字符串从当前下标切片追加：`res.append(word1[i:])` 和 `res.append(word2[j:])`（两者最多一个非空）。
4. 返回 `"".join(res)`。

以示例 2 `word1 = "ab"`、`word2 = "pqrs"` 为例：循环跑两轮后 `i = 2`、`j = 2`，`res = ['a','p','b','q']`；此时 `i < len(word1)` 为假，退出循环，`word1[2:]` 是空串、`word2[2:]` 是 `"rs"`，最终拼出 `"apbqrs"`。

```python
i = j = 0
res = []
while i < len(word1) and j < len(word2):
    res.append(word1[i])
    res.append(word2[j])
    i += 1
    j += 1
res.append(word1[i:])
res.append(word2[j:])
return "".join(res)
```

关键点：循环条件用 `and` 而不是 `or`，剩余部分交给切片，这样不用在循环里判断越界。

## 复杂度
时间 O(m + n)：每个字符恰好被 append 一次，m、n 分别是 word1、word2 长度。
空间 O(m + n)：res 列表和最终 join 出的字符串各占一份，均为线性。

## 易错点
- 输入 `word1 = "abcd"`、`word2 = "pq"` → 若循环条件写成 `or` 并在循环体内直接取 `word2[j]`，`j = 2` 时会 IndexError → 正确做法是条件用 `and`，剩余部分用 `word1[i:]` 切片追加。
- 输入 `word1 = "a"`、`word2 = "p"` → 若在循环里先判断 `if i < len(word1)` 再判断 `if j < len(word2)` 却忘了同步自增，会死循环或重复追加同一字符 → 正确做法是每轮两个 append 后无条件 `i += 1`、`j += 1`，保证指针严格前进。

## 如果面试官追问
问：如果要求原地合并、不许开新字符串怎么办？
答：Python 字符串不可变，只能退到字符数组（`list(word1)` 扩容后双指针从后往前填），空间降到 O(1) 额外。
