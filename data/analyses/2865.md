## 一句话思路
枚举每个位置当峰值，用单调栈分别求左右两侧「被压平」后的最大高度和，取最大。

## 怎么做
1. 对每个下标 `i`，把 `heights[i]` 当作峰值，左侧必须非递减、右侧必须非递增。
2. 从左往右扫，维护单调递增栈，求 `left[i]` = 以 `i` 结尾的左侧最大高度和。
3. 从右往左扫同样求 `right[i]`，答案取 `max(left[i] + right[i] - heights[i])`。

以 `maxHeights = [6,5,3,9,2,7]` 为例，峰值取 `i=3`（值 9）：左侧被压成 `[3,3,3]`，`left[3]=9`；右侧压成 `[2,2]`，`right[3]=4`；总和 `9+4+9-9=22`。

```python
n = len(heights)
left = [0] * n
st = []
for i, h in enumerate(heights):
    while st and heights[st[-1]] > h:
        st.pop()
    if not st:
        left[i] = h * (i + 1)
    else:
        j = st[-1]
        left[i] = left[j] + h * (i - j)
    st.append(i)
```

右侧同理，把 `heights` 反转后跑一遍再反转结果即可。

## 复杂度
时间：O(n)，每个下标入栈出栈各一次，左右各扫一遍。
空间：O(n)，`left`、`right` 两个数组加一个栈。

## 易错点
- 输入 `[5,3,4,1,1]` 若峰值只试 `i=0`，会漏掉 `i=2` 时 `[3,3,4,1,1]` 的和 12，必须枚举全部 n 个峰值取最大。
- 栈弹出条件写成 `>=` 而非 `>`，遇到 `[3,2,5,5,2,3]` 中相邻相等高度 5 时会多弹一次，导致 `left` 计算基准下标错位，正确写法是 `heights[st[-1]] > h` 才弹。

## 如果面试官追问
若 n 扩大到 10^5 并要求输出具体高度方案，怎么改？答：单调栈 O(n) 已够，额外记录每个位置的「压平来源下标」，最后从峰值向两侧回溯填值即可。
