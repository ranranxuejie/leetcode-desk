## 一句话思路
枚举 n 的每个因数 k，检查每段长度 k 的块是否恰好是排序后对应位置的元素集合，且块内能循环移位成有序。

## 怎么做
1. 先对 `nums` 排序得到 `target`，枚举 n 的所有因数 k（`n % k == 0`）。
2. 对每个 k，把 `nums` 切成 `n//k` 段，逐段与 `target` 同位置段比较：元素多重集必须相同，否则该 k 不可行。
3. 多重集相同还不够，段内必须能通过循环移位变成非递减，即段内至多有一个「下降点」（`nums[i] > nums[i+1]` 的位置数 ≤ 1）。
4. 两个条件都满足就把 k 累加。

以 `nums = [3,1,2]` 为例，`target = [1,2,3]`。k=1 时每段长度 1，段内无下降点，但段 `[3]` 与 `target` 段 `[1]` 多重集不同，淘汰；k=3 时整段 `[3,1,2]` 与 `[1,2,3]` 多重集相同，段内下降点只有 `3>1` 一处，可行，答案 3。

```python
target = sorted(nums)
ans = 0
for k in range(1, n + 1):
    if n % k: continue
    ok = True
    for s in range(0, n, k):
        seg, ref = nums[s:s+k], target[s:s+k]
        if sorted(seg) != ref: ok = False; break
        drops = sum(seg[i] > seg[i+1] for i in range(k-1))
        if drops > 1: ok = False; break
    if ok: ans += k
```

上面每段都 `sorted(seg)` 会退化，实际用计数或直接比较排序后切片即可；n ≤ 1e5 时因数个数很少，总代价可控。

## 复杂度
时间：枚举因数 O(√n)，每个因数扫一遍数组 O(n)，共 O(n·d(n))，d(n) 为因数个数。
空间：`target` 占 O(n)，段切片额外 O(k)，最坏 O(n)。

## 易错点
- `nums = [5,8]` 已有序：k=1 时每段长度 1，若只查「段内下降点 ≤ 1」会误判 k=1 可行，但段 `[5]` 与 `target` 段 `[5]` 多重集相同、k=1 其实可行——真正会错的是 `[3,1,2]` 的 k=1，段 `[3]` 与 `[1]` 多重集不同，必须做多重集比较，不能只看下降点。
- `nums = [2,1,4,3]`，k=2：段 `[2,1]` 下降点 1 个、段 `[4,3]` 下降点 1 个，若只统计全局下降点会误判；必须逐段独立判断，且每段多重集要等于 `target` 对应段。

## 如果面试官追问
若要求输出所有可行的 k 而非求和？答：把 `ans += k` 换成 `res.append(k)`，其余逻辑不变，返回列表即可。
