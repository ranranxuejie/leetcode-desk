## 一句话思路
k 只能等于 target 首段连续偶位前缀长度，先模拟一遍求出这个 k，再完整模拟校验。

## 怎么做
1. 对初始 `[1..N]` 做一次洗牌，取偶数位在前，得到第一轮序列 `cur`。
2. 从 `cur[0]` 开始与 `target` 逐位比对，记下最长匹配长度 `k`；若 `k == 0` 直接返回 `False`。
3. 用这个 `k` 从头重跑：每轮洗牌后取前 `k` 张（不足则全取），拼成 `res`。
4. 最后比较 `res == target`。

以 `target = [2,4,3,1,5]` 为例：初始洗牌得 `cur = [2,4,1,3,5]`，与 target 前两位 `2,4` 相同、第三位 `1 != 3`，所以 `k = 2`。用 k=2 重跑：第一轮取 `[2,4]`，剩 `[1,3,5]`；洗牌得 `[3,1,5]`，取 `[3,1]`，剩 `[5]`；最后取 `[5]`，拼出 `[2,4,3,1,5]` 命中。

```python
def shuffle(a):
    return a[1::2] + a[0::2]

cur = list(range(1, n + 1))
cur = shuffle(cur)
k = 0
while k < n and cur[k] == target[k]:
    k += 1
if k == 0:
    return False

res, cur = [], list(range(1, n + 1))
while cur:
    cur = shuffle(cur)
    res += cur[:k]
    cur = cur[k:]
return res == target
```

关键点：`k` 不能猜，必须由第一轮洗牌结果与 target 的最长公共前缀唯一确定——因为第一轮取出的前 k 张就是 `cur[:k]`，一旦某位不等，k 再大也救不回来。

## 复杂度
时间 O(n²/k)：每轮洗牌 O(剩余长度)，共约 n/k 轮，最坏 k=1 时 O(n²)。
空间 O(n)：`cur`、`res` 各存一份排列，无额外结构。

## 易错点
- `target` 首元素不在第一轮洗牌的偶数位集合里（如 `[5,4,3,2,1]`，第一轮 `cur=[2,4,1,3,5]`，`cur[0]=2 != 5`）→ 若直接令 `k=1` 硬跑会误判 → 必须先求最长匹配前缀，`k=0` 立即返回 `False`。
- 剩余牌数小于 `k` 时（如 N=5、k=2 的第三轮只剩 `[5]`）→ 若仍按 `cur[:k]` 取会越界或漏取 → 用 `cur[:k]` 天然截断，随后 `cur = cur[k:]` 变空，循环正常结束。

## 如果面试官追问
问：N 放大到 10^5 还能这么做吗？
答：不能，O(n²) 会超时；但 k 仍由首轮前缀唯一确定，只需模拟到 target 耗尽即可，实际轮数是 n/k，k 小时才退化。
