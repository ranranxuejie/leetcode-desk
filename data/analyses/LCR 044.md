## 一句话思路
BFS 逐层遍历，每层扫完取最大值，层数即结果下标。

## 怎么做
1. 空树直接返回 `[]`，否则把 `root` 放进队列 `q`。
2. 外层 `while q` 每轮先记下 `size = len(q)`，这个 `size` 就是当前层的节点数。
3. 内层循环 `size` 次：弹出节点，用 `max` 更新本层最大值，左右子节点非空就入队。
4. 内层结束后把本层最大值 append 进结果。

以示例 1 `[1,3,2,5,3,null,9]` 为例：第一轮 `size=1`，弹出 1，`cur=1`，入队 3、2，结果 `[1]`；第二轮 `size=2`，弹出 3（`cur=3`，入队 5、3）、弹出 2（`cur=max(3,2)=3`，入队 9），结果 `[1,3]`；第三轮 `size=3`，依次弹出 5、3、9，`cur` 最终为 9，结果 `[1,3,9]`。

```python
from collections import deque
if not root:
    return []
q, res = deque([root]), []
while q:
    size, cur = len(q), -2**31
    for _ in range(size):
        node = q.popleft()
        cur = max(cur, node.val)
        if node.left: q.append(node.left)
        if node.right: q.append(node.right)
    res.append(cur)
return res
```

关键点：`size` 必须在进入内层循环前固定，否则边弹边入队会让 `len(q)` 变化，把下一层的节点混进本层。

## 复杂度
时间 O(n)：每个节点入队出队各一次，`max` 比较也是每节点一次。
空间 O(w)：队列最多存一层节点，w 为最大层宽，最坏（满二叉树底层）O(n)。

## 易错点
- 输入 `[1,null,2]`：若用 DFS 按「深度」写结果数组、但没处理左子树为空导致深度错位，会把 2 记到第 1 层，输出 `[1]` 或 `[1,2]` 位置错乱；正确做法是 BFS 用 `size` 严格分层，或 DFS 用 `depth` 作下标并先判断 `depth == len(res)` 再 append。
- 输入节点值全为负数如 `[-1,-2,-3]`：若把 `cur` 初始化成 0，第一层最大值会错成 0；必须初始化成 `-2**31`（题目下界），或直接用该层第一个弹出的 `node.val` 初始化。

## 如果面试官追问
问：不用队列，能否 O(1) 额外空间？答：可以，用 Morris 遍历按层处理，但要在遍历中临时改指针并记录每层边界，代码复杂度明显上升，面试中一般先给 BFS。
