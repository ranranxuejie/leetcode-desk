## 一句话思路
枚举全部 O(n²) 个子串转成整数去重，再逐个试除判质数，排序取最大三个相加。

## 怎么做
1. 用双重循环枚举所有 `s[i:j+1]`，`int()` 转换自动忽略前导零，塞进 `set` 去重。
2. 对集合里每个数 `x` 用试除法判质数：`x < 2` 直接排除，否则只试到 `isqrt(x)`。
3. 把质数收集进列表，降序排序，取前 3 个求和（不足 3 个就全加）。

以 `s = "12234"` 为例，子串去重后得到 `{1,2,3,12,22,23,34,122,223,234,1223,2234,12234,...}`，其中质数集合是 `{2,3,23,223,1223}`；排序后前三是 `1223,223,23`，和 `1469`。

```python
from math import isqrt

def is_prime(x):
    if x < 2:
        return False
    for d in range(2, isqrt(x) + 1):
        if x % d == 0:
            return False
    return True

n = len(s)
seen = {int(s[i:j + 1]) for i in range(n) for j in range(i, n)}
primes = sorted((x for x in seen if is_prime(x)), reverse=True)
return sum(primes[:3])
```

注意 `s[i:j+1]` 的切片边界：`j` 取到 `n-1`，写成 `range(i, n)` 才不漏最后一个字符。

## 复杂度
时间 O(n² · √M)，n² 个子串、每个试除到 √M（M 为最大子串值，n≤10 时 M<10¹⁰）。
空间 O(n²)，`seen` 集合存全部不同子串值。

## 易错点
- 输入 `s = "111"` → 若不去重会把 `1`、`11`、`111` 里重复出现的 `11` 算两次，或把 `1` 当质数 → 正确做法是 `set` 去重且 `x < 2` 直接判非质数，结果只留 `11`。
- 输入 `s = "103"` → 子串 `"03"` 若按字符串比较或保留前导零会得到错误值 → 用 `int("03")` 得 `3`，与子串 `"3"` 合并成同一个质数，只计一次。

## 如果面试官追问
问：n 放大到 10⁵ 怎么办？
答：子串数爆炸，得改用「长度受限 + 大数质数判定（Miller-Rabin）」并只保留长度 ≤ 某阈值的候选，不能全枚举。
