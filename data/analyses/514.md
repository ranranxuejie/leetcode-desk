## 一句话思路
按 key 逐字符做 DP，状态是「拼完 key[i] 后指针停在 ring 的哪个下标」，因为同一字符在 ring 上可能有多个位置。

## 怎么做
1. 预处理 `pos[c]`：把 ring 中每个字符出现的下标收集起来，只在这些下标上转移。
2. 定义 `dp[j]` = 拼完当前 key 字符后，指针停在 ring 下标 j 的最小步数；初始 `dp = {0: 0}`（12:00 对齐 ring[0]）。
3. 对 key 的每个字符 c，枚举 `j in pos[c]`，从上一层的每个 `i` 转移：`dist = min(|i-j|, n-|i-j|)`，代价 `dist + 1`（+1 是按键）。
4. 取最后一层 `dp` 的最小值。

以 `ring="godding", key="gd"` 为例：`pos['g']=[0,6]`，`pos['d']=[2,3]`。第一层 `dp={0:1, 6:1}`（从 0 出发到 6 距离 1，加按键）。第二层算 `j=2`：从 0 来 `min(2,5)+1=3`，从 6 来 `min(4,3)+1=4`，取 3；`j=3`：从 0 来 `min(3,4)+1=4`，从 6 来 `min(3,4)+1=4`，取 4。最终 `min(3,4)=4`。

```python
n = len(ring)
pos = {}
for i, ch in enumerate(ring):
    pos.setdefault(ch, []).append(i)
dp = {0: 0}
for ch in key:
    ndp = {}
    for j in pos[ch]:
        best = 2**31 - 1
        for i, cost in dp.items():
            d = abs(i - j)
            best = min(best, cost + min(d, n - d) + 1)
        ndp[j] = best
    dp = ndp
return min(dp.values())
```

## 复杂度
时间：O(len(key) · |pos[c]|²)，最坏 O(m·n²)，n 为 ring 长度。
空间：O(n)，dp 字典最多存 n 个下标。

## 易错点
- `ring="aaaa", key="a"`：若把「已对齐」当成 0 步，会输出 0；实际必须按中心按钮，正确是 1 步，转移里那个 `+1` 不能漏。
- `ring="godding", key="gd"`：若只取 ring 中该字符第一次出现的下标（g 只取 0），第二层从 0 到 d 要 3 步；但正确答案允许 g 停在 6，说明必须保留所有同字符下标做状态，不能贪心选最近的一个。

## 如果面试官追问
问：要输出具体旋转方案（每步顺/逆时针转几格）怎么办？
答：dp 里额外存 `(cost, prev_index)`，回溯每层选中的下标，相邻下标差 d 与 n-d 比较决定方向。
