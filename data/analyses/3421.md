## 一句话思路
按 `(student_id, subject)` 分组，用窗口函数按 `exam_date` 排序取首尾分数，再筛首尾比较。

## 怎么做
1. 用 `ROW_NUMBER()` 按 `exam_date` 升序给每组编号 `rn`，同时用 `COUNT(*) OVER` 得到该组考试次数 `cnt`。
2. 只保留 `rn = 1`（第一次）和 `rn = cnt`（最近一次）两行，其余丢弃。
3. 把这两行透视成 `first_score` / `latest_score` 两列，按 `(student_id, subject)` 聚合。
4. 过滤 `latest_score > first_score`，按 `student_id, subject` 升序输出。

以学生 101 的 Math 为例：两行 `(70, 2023-01-15)`、`(85, 2023-02-15)`，升序编号后 `rn=1` 得 70、`rn=cnt=2` 得 85，透视后 `first_score=70, latest_score=85`，满足 `85 > 70` 入选。学生 101 的 Physics 则是 `first_score=65, latest_score=60`，`60 > 65` 为假被剔除；学生 103 的 Math 只有一行，`cnt=1`，`rn=1` 同时是首也是尾，`90 > 90` 为假，自然排除。

```python
# df: student_id, subject, score, exam_date
w = Window.partitionBy("student_id", "subject").orderBy("exam_date")
df = df.withColumn("rn", row_number().over(w)) \
       .withColumn("cnt", count("*").over(Window.partitionBy("student_id", "subject")))
edge = df.filter((col("rn") == 1) | (col("rn") == col("cnt")))
res = edge.groupBy("student_id", "subject").agg(
    max(when(col("rn") == 1, col("score"))).alias("first_score"),
    max(when(col("rn") == col("cnt"), col("score"))).alias("latest_score"),
).filter(col("latest_score") > col("first_score")) \
 .orderBy("student_id", "subject")
```

## 复杂度
时间 O(n log n)：n 为行数，窗口排序每组贡献 log。
空间 O(n)：窗口与透视各存一份中间结果。

## 易错点
- 用 `MIN(exam_date)`/`MAX(exam_date)` 关联回原表取分数：若同一学生同一科目同一天有两条记录（主键含 exam_date，理论上不会，但脏数据常见），会一对多放大行数，`first_score` 取错。正确做法是用 `ROW_NUMBER()` 定位行，不靠日期回连。
- 只写 `HAVING COUNT(*) >= 2` 却忘了比较首尾：学生 103 的 Math 单行会被 `90 > 90` 挡掉没问题，但若写成 `>=` 就会把「首尾相等」误判为进步。必须严格 `latest_score > first_score`。

## 如果面试官追问
问：若同一科目同一天有多场考试怎么定「第一次」？
答：主键已保证 `(student_id, subject, exam_date)` 唯一，无需处理；若放开，则在 `orderBy` 里追加 `score` 作为次序键并明确取哪场。
