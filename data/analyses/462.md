## 一句话思路
排序后取中位数作为目标值，因为中位数使绝对偏差之和最小，答案就是各元素到中位数的距离总和。

## 怎么做
1. 对 `nums` 排序，让相同值的元素聚在一起，便于定位中位数。
2. 取 `nums[n // 2]` 作为目标值 `mid`（偶数长度取上中位数，结果与取下中位数相同）。
3. 遍历数组累加 `abs(x - mid)`，即为最小操作数。

以 `nums = [1,10,2,9]` 为例：排序得 `[1,2,9,10]`，`n=4`，`mid = nums[2] = 9`；累加 `|1-9| + |2-9| + |9-9| + |10-9| = 8 + 7 + 0 + 1 = 16`，与示例输出一致。

```python
nums.sort()
mid = nums[len(nums) // 2]
ans = 0
for x in nums:
    ans += abs(x - mid)
return ans
```

关键中间值：`mid = 9`，`ans` 依次变为 8、15、15、16。

## 复杂度
时间：排序 O(n log n)，遍历 O(n)，总体 O(n log n)。
空间：排序额外 O(log n) 栈空间，其余 O(1)。

## 易错点
- 输入 `[1,2,3]` 时若误取平均值 `2` 恰好正确，但 `[1,10,2,9]` 平均值 `5.5` 会算出 `|1-5.5|+|10-5.5|+|2-5.5|+|9-5.5| = 4.5+4.5+3.5+3.5 = 16` 看似也对，实际是巧合；正确做法是取中位数 `nums[n//2]`，不要用 `sum(nums)/n`。
- 输入含负数如 `[-5,-1,0,3]` 时，若用 `min(nums)` 或 `max(nums)` 作目标，会得到偏大的结果；正确做法仍是排序后取 `nums[n//2]`，`abs` 对负数同样适用。

## 如果面试官追问
问：若要求返回具体的目标值和操作方案？
答：目标值取 `nums[n//2]`，对每个 `x` 输出 `(x, mid)` 的增减方向和步数即可。
