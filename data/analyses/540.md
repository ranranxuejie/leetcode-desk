## 一句话思路
对下标二分：用 `mid` 的奇偶性判断单一元素在左半还是右半，因为成对元素在单一元素左侧是「偶奇」配对、右侧是「奇偶」配对。

## 怎么做
1. 令 `lo, hi = 0, len(nums) - 1`，循环条件 `lo < hi`。
2. 取 `mid = (lo + hi) // 2`，先看 `nums[mid] == nums[mid ^ 1]`（`^1` 把偶数变 +1、奇数变 -1，即取配对下标）。
3. 若相等，说明 `mid` 落在「配对完整」的一侧，单一元素在右边：`lo = mid + 1`；否则 `hi = mid`。
4. 循环结束时 `lo == hi`，返回 `nums[lo]`。

以 `nums = [1,1,2,3,3,4,4,8,8]` 为例：`lo=0, hi=8`，`mid=4`，`nums[4]=3`，`mid^1=5`，`nums[5]=4`，不相等 → `hi=4`；下一轮 `lo=0, hi=4`，`mid=2`，`nums[2]=2`，`mid^1=3`，`nums[3]=3`，不相等 → `hi=2`；再一轮 `lo=0, hi=2`，`mid=1`，`nums[1]=1`，`mid^1=0`，`nums[0]=1`，相等 → `lo=2`；`lo==hi==2`，返回 `nums[2]=2`。

```python
lo, hi = 0, len(nums) - 1
while lo < hi:
    mid = (lo + hi) // 2
    if nums[mid] == nums[mid ^ 1]:
        lo = mid + 1
    else:
        hi = mid
return nums[lo]
```

关键点：`mid ^ 1` 在 `mid` 为偶数时给 `mid+1`（向右找搭档），为奇数时给 `mid-1`（向左找搭档），所以不用写 `if mid % 2` 分支。

## 复杂度
时间：二分 `log n` 次，每次 O(1) 比较，共 O(log n)。
空间：只用 `lo/hi/mid` 三个变量，O(1) 额外空间。

## 易错点
- 输入 `nums = [1]`（长度 1）→ 若写成 `while lo <= hi` 并在循环内访问 `nums[mid ^ 1]`，`mid=0` 时 `mid^1=1` 越界 → 用 `lo < hi`，单元素直接返回 `nums[0]`。
- 输入 `nums = [3,3,7,7,10,11,11]`，`mid=3` 时 `nums[3]=7`、`mid^1=2`、`nums[2]=7` 相等 → 若误判为「单一元素在左」而写 `hi = mid - 1`，会跳过答案 10 → 相等时必须 `lo = mid + 1`，不等时 `hi = mid`（不是 `mid - 1`）。

## 如果面试官追问
问：若数组无序、其余元素仍成对，怎么办？
答：丢掉二分，用异或全部元素，O(n) 时间 O(1) 空间，`reduce(xor, nums)` 即可。
