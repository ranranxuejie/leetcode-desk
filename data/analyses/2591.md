## 一句话思路
先给每个儿童 1 美元，剩下的钱尽量凑 8 美元，最后处理"不能有 4 美元"这个约束。

## 怎么做
1. 先判断 `money < children`，直接返回 -1（每人至少 1 美元都不够）。
2. 每人先分 1 美元，剩余 `rest = money - children`，此时每个儿童手里都是 1 美元。
3. 贪心：尽量让更多儿童从 1 美元补到 8 美元，每人需要再给 7 美元，所以 `k = min(rest // 7, children)`。
4. 处理剩余：`rest -= k * 7`，此时有 `k` 个儿童是 8 美元，其余 `children - k` 个是 1 美元。若 `rest > 0`，把剩余钱加到某个儿童身上；若这个儿童原本是 1 美元且加完后恰好变成 4 美元（即 `rest == 3` 且 `children - k > 0`），需要调整。

以 `money = 20, children = 3` 为例：`rest = 17`，`k = min(17 // 7, 3) = 2`，`rest = 17 - 14 = 3`。此时 2 个儿童各 8 美元，1 个儿童 1 美元，剩余 3 美元。若给那个 1 美元的儿童加 3 美元变成 4 美元，违规。正确做法是让一个 8 美元儿童变成 11 美元（8+3），这样 8 美元儿童数变成 1，答案 1。

```python
if money < children:
    return -1
rest = money - children
k = min(rest // 7, children)
rest -= k * 7
if rest > 0:
    if children - k > 0 and rest == 3:
        k -= 1
    # 否则剩余钱加到某个儿童身上，不影响 8 美元人数
return k
```

关键中间值：`rest == 3` 且还有非 8 美元儿童时，必须牺牲一个 8 美元儿童来吸收这 3 美元。

## 复杂度
时间：O(1)，只做常数次算术运算。
空间：O(1)，没有额外数组。

## 易错点
- `money = 20, children = 3` → 若直接返回 `k = 2` 就错了，因为剩余 3 美元加到 1 美元儿童身上变成 4 美元违规 → 正确做法是检查 `rest == 3` 且存在非 8 美元儿童时，`k` 减 1。
- `money = 16, children = 2` → 若先判断 `rest == 3` 再减 k 会误伤，因为 `rest = 14`，`k = 2`，`rest = 0`，不触发调整 → 正确做法是只在 `rest > 0` 且 `rest == 3` 时才调整。

## 如果面试官追问
若要求输出具体分配方案？答：记录每个儿童初始 1 美元，前 k 个补到 8 美元，剩余钱加到第 k+1 个儿童；若触发调整，则第 k 个儿童拿 11 美元，第 k+1 个拿 1 美元。
