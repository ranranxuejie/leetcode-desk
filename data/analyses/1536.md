## 一句话思路
把每行压缩成「右侧连续 0 的个数」，再贪心：第 i 行必须找到第一个 `zeros >= n-1-i` 的行，把它冒泡上来，代价就是它下移的距离。

## 怎么做
1. 对每行从右往左数连续 0，存进 `zeros` 数组；遇到第一个 1 就停。
2. 从 `i = 0` 到 `n-1`，在第 `i` 行及之后找第一个满足 `zeros[j] >= n-1-i` 的 `j`。
3. 找不到就返回 `-1`；找到就把 `zeros[j]` 一路交换到位置 `i`，累加 `j - i`。
4. 交换后 `i` 之前的行已固定，不再动。

以示例 1 的 `grid = [[0,0,1],[1,1,0],[1,0,0]]` 为例：`zeros = [0, 1, 2]`。`i=0` 需要 `>=2`，只有 `j=2` 满足，代价 `2`，数组变 `[2,0,1]`；`i=1` 需要 `>=1`，`j=2` 满足，代价 `1`，数组变 `[2,1,0]`；`i=2` 需要 `>=0`，`j=2`，代价 `0`。总计 `3`。

```python
n = len(grid)
zeros = []
for row in grid:
    c = 0
    for x in reversed(row):
        if x == 1:
            break
        c += 1
    zeros.append(c)

ans = 0
for i in range(n):
    need = n - 1 - i
    j = i
    while j < n and zeros[j] < need:
        j += 1
    if j == n:
        return -1
    while j > i:
        zeros[j], zeros[j - 1] = zeros[j - 1], zeros[j]
        j -= 1
        ans += 1
return ans
```

## 复杂度
时间：`O(n^2)`，外层 `n` 次、内层最多扫 `n` 行并冒泡 `n` 步。
空间：`O(n)`，只开了长度 `n` 的 `zeros`，没复制矩阵。

## 易错点
- 示例 2 四行全是 `[0,1,1,0]`，`zeros` 全为 `1`：`i=0` 需要 `>=3`，扫到 `j=4` 仍不满足，必须返回 `-1`。若把条件写成 `zeros[j] >= n-1-i` 的 `>=` 误写成 `>`，或忘了 `j == n` 的判空，会越界或错判成可行。
- 示例 3 的 `grid = [[1,0,0],[1,1,0],[1,1,1]]`，`zeros = [2,1,0]` 已满足 `i=0` 需 `2`、`i=1` 需 `1`、`i=2` 需 `0`，答案应为 `0`。若从右往左数 0 时把「遇到 1 就 break」写成「数所有 0」，第一行会得 `2` 但第三行会得 `0` 之外的错值，导致多算交换。

## 如果面试官追问
若要求输出具体交换序列而非次数？答：在冒泡时记录每次 `(j-1, j)` 的相邻行交换，按顺序输出即可，次数不变。
