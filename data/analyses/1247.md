## 一句话思路
按位置统计两类错配（s1 有 x/s2 有 y 记 a，反向记 b），同类两两配对一次交换消掉，剩下的跨类各需两次。

## 怎么做
1. 逐位比较 s1[i] 与 s2[i]，只统计不相等的位置：`s1[i]=='x'` 计入 a，否则计入 b。
2. 同类错配两两配对：每对 (x,y)+(x,y) 只需 1 次交换，贡献 `a//2 + b//2`。
3. 若 a、b 都是奇数，剩下一对异类错配，需 2 次交换，答案再加 2；若一奇一偶则无解返回 -1。
4. 用示例 2 走一遍：s1="xy", s2="yx"，i=0 得 a=1，i=1 得 b=1，`1//2+1//2=0`，a、b 同为奇数故 +2，答案 2。

```python
a = b = 0
for c1, c2 in zip(s1, s2):
    if c1 != c2:
        if c1 == 'x':
            a += 1
        else:
            b += 1
if (a + b) % 2:
    return -1
return a // 2 + b // 2 + (a % 2) * 2
```

关键中间值：示例 1 中 s1="xx", s2="yy"，两位都满足 `c1=='x'`，a=2、b=0，`2//2=1`，a 为偶数不加 2，返回 1。

## 复杂度
时间 O(n)：n 为字符串长度，一次 zip 遍历。
空间 O(1)：只开 a、b 两个计数器。

## 易错点
- s1="xx", s2="xy" → 若只判断 `(a+b)%2` 就返回 -1 会漏掉「a=1,b=0 一奇一偶」这种真正无解的情形，正确做法是 a、b 奇偶必须一致，否则 -1。
- s1="xy", s2="yx" → 若把 a、b 直接相加除以 2 得 1，会错成 1 次，正确做法是异类错配一对要 2 次交换，即 `(a%2)*2` 不能省。

## 如果面试官追问
要求输出具体交换方案怎么办？答：先把同类错配按 (i,j) 配对交换 s1[i] 与 s2[j]，剩余异类错配用两次交换中转，按配对顺序记录下标即可。
