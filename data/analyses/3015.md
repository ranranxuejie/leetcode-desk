## 一句话思路
n≤100，对每个起点跑一次 BFS 求到所有点的最短路，累加进 `result[dist]`，因为图只有 n+1 条边、规模小到暴力完全够。

## 怎么做
1. 建邻接表：对 `i in range(1, n)` 加边 `i—i+1`，再额外加 `x—y`（`x == y` 时这条边是自环，加不加都不影响最短路）。
2. 对每个起点 `s` 从 1 到 n 跑 BFS，`dist` 数组初始化为 -1，`dist[s] = 0`。
3. 每弹出一个点 `u`，对每个邻居 `v`，若 `dist[v] == -1` 则 `dist[v] = dist[u] + 1` 并入队。
4. BFS 结束后把 `dist[t]`（`t != s`）累加到 `result[dist[t]]`，因为题目统计的是有序对，`(s,t)` 和 `(t,s)` 各算一次。

以示例 2 `n=5, x=2, y=4` 为例，起点 `s=1` 时 BFS 得到 `dist = [0,1,2,2,3]`（下标 1..5），于是 `result[1] += 1`（到 2）、`result[2] += 2`（到 3、4）、`result[3] += 1`（到 5）。五个起点跑完正好凑出 `[10,8,2,0,0]`。

```python
from collections import deque

adj = [[] for _ in range(n + 1)]
for i in range(1, n):
    adj[i].append(i + 1)
    adj[i + 1].append(i)
adj[x].append(y)
adj[y].append(x)

result = [0] * (n + 1)
for s in range(1, n + 1):
    dist = [-1] * (n + 1)
    dist[s] = 0
    q = deque([s])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    for t in range(1, n + 1):
        if t != s:
            result[dist[t]] += 1
```

## 复杂度
时间：`n` 个起点各跑一次 BFS，每次 O(n) 点 + O(n) 边，共 O(n²)。
空间：`adj` 存 2(n-1)+2 条边、`dist` 与队列各 O(n)，总计 O(n)。

## 易错点
- `x == y`（示例 3 的 `x=y=1`）→ 若把 `adj[x].append(y)` 当成新增一条有效街道，会误以为 1 号房有自环从而多算距离 → 正确做法是照常加边，BFS 里 `dist[v] == -1` 的判断天然屏蔽自环，结果仍是 `[6,4,2,0]`。
- 只累加 `t > s` 的一半 → 输出会整体减半，示例 1 得到 `[3,0,0]` 而非 `[6,0,0]` → 正确做法是遍历全部 `t != s`，让每对有序房屋各计一次。

## 如果面试官追问
问：n 放大到 10⁵ 怎么办？
答：不能逐点 BFS，改为按 `x<y` 分三段（`[1,x]`、`[x,y]`、`[y,n]`）用前缀和公式直接算每段内部及跨段的距离分布，O(n)。
