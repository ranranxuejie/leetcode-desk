## 一句话思路
用哈希集合边扫边查：重复 n 次的元素第二次出现时必被集合命中，因为 n≥2 保证它至少出现两次。

## 怎么做
1. 建空集合 `seen`，遍历 `nums` 的每个 `x`。
2. 若 `x in seen` 立即返回 `x`，否则 `seen.add(x)`。
3. 以 `nums = [2,1,2,5,3,2]` 为例：扫到下标 0 存 2，下标 1 存 1，下标 2 的 `x = 2` 已在 `seen` 中，直接返回 2，后面三个元素不用看。
4. 循环结束仍无命中说明输入违反约束，返回 `-1` 兜底（正常用例走不到）。

```python
seen = set()
for x in nums:
    if x in seen:
        return x
    seen.add(x)
return -1
```

关键中间值：`nums = [2,1,2,5,3,2]` 时，`seen` 在下标 2 之前是 `{2, 1}`，`x = 2` 命中，返回 2。重复元素出现位置最坏在末尾，但 n≥2 保证它至少出现两次，所以最迟第二次出现就被抓到，不需要扫完 2n 个。

## 复杂度
时间：O(n)，最坏扫 2n 个元素，每个元素集合查询 O(1)。
空间：O(n)，`seen` 最多存 n+1 个不同值。

## 易错点
- 输入 `nums = [1,2,3,3]`（n=2）时，若误以为重复元素一定在数组前半段、只扫 `nums[:n]`，会漏掉下标 3 的 3；正确做法是扫全数组，靠集合命中判断。
- 输入 `nums = [5,1,5,2,5,3,5,4]`（n=4）时，若用「排序后取相邻相等」会先花 O(n log n) 排序，且要额外处理 `nums[i] == nums[i+1]` 的边界；正确做法是哈希集合一次遍历，O(n) 且无排序开销。

## 如果面试官追问
问：若不允许额外空间怎么办？
答：利用 n≥2，重复元素在 `nums[0..3]` 四个位置中必出现两次，两两比较这 4 个值即可，O(1) 空间。
