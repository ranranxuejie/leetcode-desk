## 一句话思路
用栈做表达式树 DP，每个子表达式维护「值为 0 的最少操作」和「值为 1 的最少操作」两个数，合并时按运算符枚举翻转方式。

## 怎么做
1. 扫描 `expression`，遇 `'0'`/`'1'` 压入 `(0,1)` 或 `(1,0)`（前者是变 0 的代价，后者是变 1 的代价）。
2. 遇 `'('` 压占位符，遇 `')'` 弹出到占位符为止，把括号内结果留在栈顶。
3. 遇运算符先存起来，等右操作数到栈顶时合并：设左 `(l0,l1)`、右 `(r0,r1)`。
4. `&` 时 `cur0 = min(l0+r0, l0+r1, l1+r0)`，`cur1 = min(l1+r1, 1+l0+r1, 1+l1+r0)`；`|` 对称。

以 `"1&(0|1)"` 为例：`(0|1)` 合并得 `(1,0)`（变 0 需把 `'1'` 翻成 `'0'`，代价 1；变 1 已成立，代价 0）。再与左 `1` 做 `&`：`cur0 = min(0+1, 0+0, 1+1) = 0`？注意左 `1` 是 `(1,0)`，`l0=1,l1=0`，右 `r0=1,r1=0`，`cur0 = min(1+1, 1+0, 0+1) = 1`，`cur1 = min(0+0, 1+1+0, 1+0+1) = 0`。最终栈顶 `(1,0)`，答案取「反转原值」那一项：原值 1，故取 `cur0 = 1`。

```python
def merge(l, r, op):
    l0, l1 = l; r0, r1 = r
    if op == '&':
        c0 = min(l0 + r0, l0 + r1, l1 + r0)
        c1 = min(l1 + r1, 1 + l0 + r1, 1 + l1 + r0)
    else:
        c0 = min(l0 + r0, 1 + l0 + r1, 1 + l1 + r0)
        c1 = min(l1 + r1, l0 + r1, l1 + r0)
    return (c0, c1)
```

## 复杂度
时间 O(n)：每个字符进出栈各一次，合并是常数次加法取 min。
空间 O(n)：栈最深存 n/2 个二元组，括号占位符另算。

## 易错点
- 输入 `"1"` 或 `"0"`：栈里只有一个 `(0,1)` 或 `(1,0)`，若直接返回 `cur0` 会错——原值 1 要返回 `cur0`，原值 0 要返回 `cur1`，必须按原值选。
- 输入 `"(0&0)&(0&0&0)"`：`&` 的 `cur1` 里 `1 + l0 + r1` 这类「翻运算符」项容易漏写，漏了会把答案算成 4 而非 3；三个候选必须齐全。

## 如果面试官追问
问：要求输出具体操作方案怎么办？
答：DP 时同时记录每个候选来自哪个分支（翻左/翻右/翻运算符），回溯表达式树即可还原。
