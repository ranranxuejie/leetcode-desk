## 一句话思路
枚举切分点 k，把 target 劈成前后两段，用哈希表查 nums 里各段出现次数，相乘累加。

## 怎么做
1. 用 `Counter(nums)` 统计每个字符串出现次数，记作 `cnt`。
2. 枚举 `k = 1 .. len(target)-1`，左段 `a = target[:k]`，右段 `b = target[k:]`。
3. 若 `a`、`b` 都在 `cnt` 里，贡献 `cnt[a] * cnt[b]`；当 `a == b` 时贡献改为 `cnt[a] * (cnt[a] - 1)`，因为 i != j。
4. 累加所有 k 的贡献即为答案。

以示例 1 为例：`target = "7777"`。`cnt = {"777":1, "7":1, "77":2}`。
- k=1：a="7", b="777"，贡献 1*1=1
- k=2：a="77", b="77"，a==b，贡献 2*1=2
- k=3：a="777", b="7"，贡献 1*1=1
合计 1+2+1=4，与输出一致。

```python
from collections import Counter

cnt = Counter(nums)
ans = 0
for k in range(1, len(target)):
    a, b = target[:k], target[k:]
    if a in cnt and b in cnt:
        if a == b:
            ans += cnt[a] * (cnt[a] - 1)
        else:
            ans += cnt[a] * cnt[b]
```

关键点：`a == b` 时不能直接用 `cnt[a] * cnt[b]`，否则会把同一个下标自己配自己算进去，示例 1 的 k=2 会错算成 4 而不是 2。

## 复杂度
时间：O(L²)，L = len(target)，每个切分点做一次长度 O(L) 的切片比较，n 是 nums 长度只影响建表。
空间：O(n·m)，Counter 存下所有 nums 字符串，m 为字符串平均长度。

## 易错点
- 输入 `nums = ["1","1","1"], target = "11"`：若对 a==b 仍用 `cnt[a]*cnt[b]`，会得 9 而非 6，因为把 (0,0)、(1,1)、(2,2) 三个自配对算进去了；正确做法是 `cnt[a]*(cnt[a]-1)`。
- 输入 `nums = ["777","7","77","77"], target = "7777"`：若只枚举到 `len(target)-1` 之外的边界，或漏掉 k=2 这种前后等长的情况，会少算 2；正确做法是 `range(1, len(target))` 覆盖所有非空切分。

## 如果面试官追问
若 nums 长度升到 10^5 且 target 很长，怎么优化？答：仍按切分点枚举，但用长度分桶 + 只查长度匹配的桶，避免全表扫描。
