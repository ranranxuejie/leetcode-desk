## 一句话思路
用并查集把 pairs 连成若干连通块，块内字符可任意重排，故每块排序后按索引升序填回即得字典序最小。

## 怎么做
1. 对每个 `pairs[i] = [a, b]` 做 `union(a, b)`，把可交换的索引并成一组。
2. 遍历 `i in range(len(s))`，用 `find(i)` 作 key，把 `s[i]` 收进 `groups[key]` 列表。
3. 每个 `groups[key]` 排序（升序），并记录该组包含的索引（也升序）。
4. 按索引顺序把排序后的字符依次写回结果数组。

以示例 2 `s = "dcab"`, `pairs = [[0,3],[1,2],[0,2]]` 为例：三次 union 后 0、1、2、3 全在同一组，`groups` 里只有一个 key，收集到 `['d','c','a','b']`，排序成 `['a','b','c','d']`，按索引 0..3 填回得 `"abcd"`。

```python
parent = list(range(n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
for a, b in pairs:
    ra, rb = find(a), find(b)
    if ra != rb:
        parent[ra] = rb

groups = {}
for i, ch in enumerate(s):
    groups.setdefault(find(i), []).append(ch)
res = list(s)
for root, chars in groups.items():
    chars.sort()
    idxs = sorted(i for i in range(n) if find(i) == root)
    for i, ch in zip(idxs, chars):
        res[i] = ch
```

上面最后那段 `idxs` 用 `find(i)` 全扫是 O(n) 每组，实际应把索引和字符一起存进 `groups`（`append((i, ch))`），排序后直接按元组顺序写回，避免二次扫描。

## 复杂度
时间：并查集近似 O(n α(n))，各组排序合计 O(n log n)，n 为 `len(s)`。
空间：`parent`、`groups`、`res` 各 O(n)，排序临时空间 O(n)。

## 易错点
- `pairs` 为空（如 `s = "cba"`, `pairs = []`）→ 若误以为所有索引连通、把整串排序成 `"abc"` → 正确做法是每个索引自成一組，原样返回 `"cba"`。
- 只按字符排序却按原始索引顺序写回 → 例如示例 1 中组 `{0,3}` 字符 `['d','b']` 排序成 `['b','d']`，必须填到索引 0、3 而非 0、1 → 正确做法是把索引和字符绑定成 `(i, ch)` 一起排序，保证字符落到本组自己的位置上。

## 如果面试官追问
若要求输出具体交换序列而非最终字符串？答：在每组内做选择排序式交换，把最小字符逐步换到组内最小索引，交换次数不超过组大小。
