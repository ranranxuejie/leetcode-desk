## 一句话思路
逐位贪心：每位按 `a,b,c` 试，用「剩余位数的合法串数」判断第 k 个落在哪个分支，直接定位而不枚举。

## 怎么做
1. 记 `cnt(m)` 为长度 m、首位已定且与前一字符不同的合法串数：`cnt(0)=1`，`cnt(m)=2*cnt(m-1)`，即 `2**(m-1)`（m≥1）。
2. 从第 0 位开始，按 `'a','b','c'` 顺序跳过等于前一字符的字母，每个候选分支含 `2**(剩余位数-1)` 个串。
3. 若 `k > 分支数`，`k -= 分支数` 继续试下一个字母；否则选定该字母，进入下一位。
4. 若某位三个字母都试完仍没选中，说明总数不足 k，返回 `""`。

以 `n=3, k=9` 为例：第 0 位每个分支 `2**2=4` 个，`k=9 > 4` 减为 5，`> 4` 减为 1，选 `'c'`；第 1 位候选 `a,b`，各 `2**1=2` 个，`k=1 ≤ 2` 选 `'a'`；第 2 位候选 `b,c`，各 `2**0=1`，`k=1` 选 `'b'`，得 `"cab"`。

```python
res = []
prev = ''
for pos in range(n):
    for ch in 'abc':
        if ch == prev:
            continue
        block = 2 ** (n - pos - 1)   # 该分支下的串数
        if k > block:
            k -= block
        else:
            res.append(ch)
            prev = ch
            break
    else:
        return ''
return ''.join(res)
```

## 复杂度
时间 O(n·3)，每位最多试 3 个字母，n ≤ 10。
空间 O(n)，只存结果串 `res`，无递归栈。

## 易错点
- `n=1, k=4`：若只按 `2**(n-pos-1)` 判断而不处理「三个字母都试完」的 `else`，会越界或返回残缺串；正确做法是 for-else 里直接 `return ''`。
- `n=10, k=100`：若把 `block` 写成 `2**(n-pos)`（多算一位），第 0 位分支变成 1024，`k=100` 直接选 `'a'`，结果错成 `"abacbabac"` 之类；正确是 `2**(n-pos-1)`，`n=10` 时首位每分支 512。

## 如果面试官追问
若 n 放大到 10^5、k 仍 ≤ 100：还能逐位贪心吗？答：能，但 `2**(n-pos-1)` 会爆大整数，只需在 `block > k` 时截断为 `k`（因为 k 只减不增），复杂度仍是 O(n)。
