## 一句话思路
后序 DFS 返回 `(最深叶子深度, 该子树内最深叶子的 LCA)`，左右深度相等时当前节点就是答案。

## 怎么做
1. 定义 `dfs(node)` 返回 `(depth, lca)`：`depth` 是子树内最深叶子的相对深度，`lca` 是这些叶子的最近公共祖先。
2. 空节点返回 `(-1, None)`；叶子返回 `(0, node)`。
3. 递归左右子树，比较 `ld` 与 `rd`：相等则 `lca` 取 `node`，否则取更深一侧的 `lca`，深度取 `max(ld, rd) + 1`。
4. 根节点调用 `dfs(root)[1]`。

以示例 1 的 `root = [3,5,1,6,2,0,8,null,null,7,4]` 为例：节点 7、4 各返回 `(0, 7)`、`(0, 4)`；节点 2 收到 `ld == rd == 0`，返回 `(1, 2)`；节点 5 左子 6 返回 `(0, 6)`、右子 2 返回 `(1, 2)`，`ld=0 < rd=1`，返回 `(2, 2)`；根 3 左 `(2, 2)`、右 `(1, 1)`，取左，最终 `lca` 是节点 2。

```python
def dfs(node):
    if not node:
        return -1, None
    if not node.left and not node.right:
        return 0, node
    ld, ll = dfs(node.left)
    rd, rl = dfs(node.right)
    if ld == rd:
        return ld + 1, node
    if ld > rd:
        return ld + 1, ll
    return rd + 1, rl
```

## 复杂度
时间 O(n)：每个节点访问一次，比较与返回都是常数操作。
空间 O(h)：递归栈深度为树高 h，最坏链状树 O(n)，无额外哈希表。

## 易错点
- 输入 `root = [0,1,3,null,2]`（示例 3）→ 若把「最深叶子」理解成必须有两个叶子才返回祖先，会错成返回 1 或 0 → 正确做法是单叶子时 `ld == rd == -1` 在父节点处自然让该叶子自己成为 `lca`，即返回节点 2。
- 输入 `root = [1]`（示例 2）→ 若空节点返回 `(0, None)` 而非 `(-1, None)`，叶子深度基准偏移，单节点树会错判 → 正确做法是空返回 `-1`、叶子返回 `0`，保证 `max(ld, rd) + 1` 与题面「根深度 0」一致。

## 如果面试官追问
若要求返回所有最深叶子节点列表而非 LCA？答：DFS 同时带回 `(depth, lca, leaves)`，深度相等时合并列表，O(n) 不变。
