## 一句话思路
用前序遍历序列化，空节点写成 `#`，反序列化时按同一顺序消费 token 递归重建，因为前序加空标记能唯一确定一棵树。

## 怎么做
1. 序列化：前序遍历，节点值转字符串，`None` 写 `#`，用 `,` 拼接。
2. 反序列化：把字符串 `split(',')` 成列表，用下标 `i` 从左往右消费。
3. 遇到 `#` 返回 `None` 并让 `i` 前进；否则建节点，先递归左再递归右。

以 `root = [1,2,3,null,null,4,5]` 为例，序列化得到 `"1,2,#,#,3,4,#,#,5,#,#"`。反序列化时 `i=0` 取 `"1"` 建根，`i=1` 取 `"2"`，`i=2`、`i=3` 都是 `#`，于是 2 的左右孩子都是 `None`，`i=4` 取 `"3"` 继续。

```python
def serialize(root):
    if not root:
        return "#"
    return f"{root.val},{serialize(root.left)},{serialize(root.right)}"

def deserialize(data):
    tokens = data.split(",")
    i = 0
    def build():
        nonlocal i
        if tokens[i] == "#":
            i += 1
            return None
        node = TreeNode(int(tokens[i]))
        i += 1
        node.left = build()
        node.right = build()
        return node
    return build()
```

关键点：`i` 必须是共享游标（`nonlocal`），左右子树各自消费自己那段 token，不能各传一份拷贝。

## 复杂度
时间：序列化和反序列化各 O(n)，n 是节点数，每个节点和每个 `#` 只处理一次。
空间：递归栈 O(h)，h 是树高，最坏链状 O(n)；序列化字符串 O(n)。

## 易错点
- 空树 `root = []`：序列化若返回 `""`，反序列化 `split(",")` 得到 `[""]`，`tokens[0]` 不是 `"#"` 会 `int("")` 报错。正确做法是空树也返回 `"#"`，保证 token 列表非空。
- 节点值为负数如 `-1000`：若用 `str(root.val)` 拼接没问题，但若自己写解析、用 `isdigit()` 判断会漏掉负号。正确做法是直接 `int(token)`，Python 能处理负号。

## 如果面试官追问
问：节点数到 10^5、递归会爆栈怎么办？
答：改用显式栈做前序迭代，序列化和反序列化都用栈模拟，空间仍是 O(h) 但不吃调用栈。
