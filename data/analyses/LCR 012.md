## 一句话思路
用总和减当前元素得到右侧和，边走边维护左侧和，第一个相等处即最左中心下标。

## 怎么做
1. 先求 `total = sum(nums)`，把「右侧和」变成可 O(1) 算出的量。
2. 令 `left = 0`，从左到右遍历 `i`，此时 `right = total - left - nums[i]`。
3. 若 `left == right` 立即返回 `i`，保证拿到最靠左的那个。
4. 否则 `left += nums[i]` 继续，遍历完返回 `-1`。

以 `nums = [1,7,3,6,5,6]` 为例，`total = 28`。走到 `i = 3` 时 `left = 1+7+3 = 11`，`right = 28 - 11 - 6 = 11`，相等，返回 `3`。注意 `right` 里减掉的是 `nums[3]` 本身，不是 `left` 的一部分。

```python
total = sum(nums)
left = 0
for i, x in enumerate(nums):
    if left == total - left - x:
        return i
    left += x
return -1
```

关键在判断顺序：先比较再累加，否则 `left` 会把 `nums[i]` 算进去，`i = 0` 的边界就错了。

## 复杂度
时间 O(n)：一次求和加一次遍历，各扫 n 个元素。
空间 O(1)：只开了 `total`、`left`、`i`、`x` 四个变量。

## 易错点
- `nums = [2,1,-1]` → 若先把 `left += nums[i]` 再比较，`i = 0` 时 `left` 变成 2，`right = 0`，判不相等，漏掉正确答案 0 → 必须先比较后累加。
- `nums = [1,2,3]` 或全负数如 `[-1,-1,-1,-1,-1]` → 若用「左右和都为正才继续」之类的剪枝，或误以为中心下标一定在中间，会提前返回 -1 → 本题元素可为负，`left` 不单调，只能老老实实每个下标都验一遍。

## 如果面试官追问
问：要求返回所有中心下标怎么办？
答：把 `return i` 换成 `append` 到结果列表，继续累加走完全程，时间仍是 O(n)。
