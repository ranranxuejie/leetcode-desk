## 一句话思路
用长度 26 的计数数组统计频次，取「奇数频次最大值 − 偶数频次最小值」。

## 怎么做
1. 用 `cnt = [0]*26` 扫一遍 `s`，`cnt[ord(ch)-97] += 1`。
2. 遍历 `cnt`，把 `>0` 且为奇数的放进 `odd_max`（取最大），`>0` 且为偶数的放进 `even_min`（取最小）。
3. 返回 `odd_max - even_min`。

以 `s = "aaaaabbc"` 为例，扫完得到 `cnt[0]=5, cnt[1]=2, cnt[2]=1`，其余为 0。遍历时 `5` 是奇数更新 `odd_max=5`，`2` 是偶数更新 `even_min=2`，`1` 是奇数但小于 5 不更新；最终 `5-2=3`。

关键中间值：`even_min` 的初值要设成 `10**9`（或 `s` 长度 +1），因为频次最小可能是 2，用 0 当哨兵会让 `odd_max - 0` 永远偏大。

```python
cnt = [0] * 26
for ch in s:
    cnt[ord(ch) - 97] += 1
odd_max, even_min = 0, 10**9
for c in cnt:
    if c == 0:
        continue
    if c % 2 == 1:
        odd_max = max(odd_max, c)
    else:
        even_min = min(even_min, c)
return odd_max - even_min
```

注意 `c == 0` 必须跳过：0 是偶数，若参与 `even_min` 计算，`even_min` 会被压成 0，答案变成 `odd_max`，对 `"aaaaabbc"` 会错答 5。

## 复杂度
时间 O(n + 26)，n 是 `s` 长度，扫字符串贡献 n，扫计数数组是常数 26。
空间 O(1)，只开了固定 26 长的 `cnt` 和两个标量。

## 易错点
- 输入 `s = "aaaaabbc"` 时若把 `cnt` 里的 0 也当偶数参与 `even_min`，`even_min` 变 0，输出 5 而非 3 → 遍历时先 `if c == 0: continue`，只统计真实出现过的字符。
- 输入 `s = "abcabcab"` 时若只记录「第一个奇数」和「第一个偶数」而不取极值，可能拿到 `a=3` 与 `b=3`（3 是奇数，不是偶数候选）之外的错配 → 必须对奇数取 `max`、对偶数取 `min`，本题正确配对是 3 与 2 得 1。

## 如果面试官追问
若要求返回具体的 `a1`、`a2` 而不只是差值？答：在更新 `odd_max`/`even_min` 时同步记下对应下标 `i`，最后 `chr(i+97)` 还原字符即可，逻辑不变。
