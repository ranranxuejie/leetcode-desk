## 一句话思路
利用 `next` 指针本身当"层链"，每层从最左节点出发，用父层已建好的 `next` 把子层串起来，O(1) 空间。

## 怎么做
1. 从 `root` 开始，`leftmost` 指向当前层最左节点，逐层向下。
2. 遍历当前层：对每个节点 `cur`，把 `cur.left.next = cur.right`。
3. 若 `cur.next` 存在，则 `cur.right.next = cur.next.left`，把跨父节点的两个子节点接上。
4. 本层走完，`leftmost = leftmost.left` 进入下一层。

以 `[1,2,3,4,5,6,7]` 为例：`leftmost=1` 时，处理 `cur=1` 得 `2.next=3`；`leftmost=2` 时，`cur=2` 得 `4.next=5`，因 `2.next=3` 存在，再得 `5.next=6`；`cur=3` 得 `6.next=7`，`3.next` 为 `None` 故跳过跨接。

```python
leftmost = root
while leftmost and leftmost.left:
    cur = leftmost
    while cur:
        cur.left.next = cur.right
        if cur.next:
            cur.right.next = cur.next.left
        cur = cur.next
    leftmost = leftmost.left
```

## 复杂度
时间 O(n)：每个节点被 `cur` 访问一次，n 为节点总数。
空间 O(1)：只用了 `leftmost`、`cur` 两个指针，未开队列。

## 易错点
- 输入 `[1,2,3]` 时若只写 `cur.left.next = cur.right` 而漏掉 `if cur.next` 分支，`2.right`（即节点 3）的 `next` 不会被置空以外的处理影响，但换成 `[1,2,3,4,5,6,7]` 时 `5.next` 就接不到 `6`，输出层内断裂。正确做法是每层都检查 `cur.next` 再跨接。
- 循环条件写成 `while leftmost:` 而非 `while leftmost and leftmost.left:`，到叶子层时 `leftmost.left` 为 `None`，`cur.left.next` 会抛 `AttributeError`。正确做法是用 `leftmost.left` 判断是否还有下一层。

## 如果面试官追问
若树不是完美二叉树（节点可缺）？答：本解法失效，需改用 BFS 队列按层连接，空间 O(宽度)。
