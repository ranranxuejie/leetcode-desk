## 一句话思路
先按列求最大值存进 `col_max`，再遍历把 `-1` 换成对应列的最大值，因为每列最大值与替换位置无关。

## 怎么做
1. 用 `n = len(matrix[0])` 初始化 `col_max = [0] * n`，逐列扫描取最大。
2. 扫描时跳过 `-1`，只让非负值参与比较（题目保证每列至少一个非负值）。
3. 再遍历一次矩阵，`matrix[i][j] == -1` 时写成 `col_max[j]`。
4. 原地改 `matrix` 即可，返回值就是它。

以示例 1 为例，第一遍扫完得到 `col_max = [7, 8, 9]`：列 1 的候选是 `2, -1, 8`，跳过 `-1` 后最大是 `8`；列 2 是 `-1, 6, 9`，最大 `9`。第二遍把 `[0][2]` 改成 `col_max[2] = 9`、`[1][1]` 改成 `col_max[1] = 8`，其余不动。

```python
n = len(matrix[0])
col_max = [0] * n
for j in range(n):
    for i in range(len(matrix)):
        if matrix[i][j] != -1:
            col_max[j] = max(col_max[j], matrix[i][j])
for i in range(len(matrix)):
    for j in range(n):
        if matrix[i][j] == -1:
            matrix[i][j] = col_max[j]
return matrix
```

关键点：`col_max` 初值写 `0` 而不是 `-1`，因为列里可能有 `0`，且 `-1` 本身不该参与取最大。

## 复杂度
时间：O(m·n)，两遍完整扫描，每格常数次比较。
空间：O(n)，只开了长度为列数的 `col_max`，原地改矩阵不算额外空间。

## 易错点
- 输入 `[[3,-1],[5,2]]`：若把 `-1` 也丢进 `max` 比较，列 0 会得到 `5` 没问题，但列 1 的 `-1` 会让 `col_max[1]` 停在 `-1`，`[0][1]` 被替换成 `-1` 而非 `2`。正确做法是 `if matrix[i][j] != -1` 才更新。
- 输入 `[[0,-1],[-1,2]]`：若 `col_max` 初值写成 `-1`，列 0 的 `0` 与 `-1` 比较后仍是 `-1`，`[1][0]` 被填成 `-1`。初值必须取 `0`（或先取该列第一个非负值）。

## 如果面试官追问
问：如果要求返回新矩阵而不改原矩阵怎么办？
答：先 `answer = [row[:] for row in matrix]` 深拷贝一份，再在 `answer` 上做第二遍替换，`col_max` 逻辑不变。
