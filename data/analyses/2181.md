## 一句话思路
用哑节点 `dummy` 加游标 `tail` 边遍历边累加，遇 0 就把和接到 `tail` 后面并清零。

## 怎么做
1. 建 `dummy = ListNode(0)`，`tail = dummy`，`cur = head.next`（跳过开头的 0），`s = 0`。
2. 遍历 `cur`：`val != 0` 就 `s += cur.val`；`val == 0` 就新建节点挂到 `tail.next`、`tail` 前移、`s = 0`。
3. 返回 `dummy.next`。

以 `[0,3,1,0,4,5,2,0]` 为例：走到第二个 0 时 `s = 3 + 1 = 4`，挂一个值为 4 的节点；继续累加到 `s = 4 + 5 + 2 = 11`，末尾 0 处再挂一个 11，结果 `[4,11]`。

```python
dummy = tail = ListNode(0)
cur, s = head.next, 0
while cur:
    if cur.val:
        s += cur.val
    else:
        tail.next = ListNode(s)
        tail = tail.next
        s = 0
    cur = cur.next
return dummy.next
```

关键点：末尾那个 0 是「收尾信号」，不是「跳过信号」——它必须触发一次挂节点，否则最后一组和（示例里的 11）会丢。所以循环体里 `else` 分支不能写成 `if cur.next`。

## 复杂度
时间 O(n)：`cur` 走完 n 个节点一次，每个节点常数操作。
空间 O(1)：只开了 `dummy`、`tail`、`cur`、`s` 四个变量，新节点数等于结果长度，不算额外辅助空间。

## 易错点
- 输入 `[0,3,1,0]`（只有一组）→ 若把末尾 0 当跳过处理，返回空链表 → 正确做法是每个 0 都挂节点，末尾 0 挂的是最后一组的和。
- 输入 `[0,1,0,3,0,2,2,0]` → 若从 `head` 而不是 `head.next` 开始遍历，第一个 0 会先挂一个 `s = 0` 的空节点，输出变成 `[0,1,3,4]` → 正确做法是 `cur = head.next` 跳过开头 0。

## 如果面试官追问
追问：不许新建节点，原地改链表怎么做？
答：把每组和写回该组第一个非零节点，再让前一组末尾指向它，最后把 `tail.next` 置 `None`。
