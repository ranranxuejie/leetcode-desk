## 一句话思路
从左往右扫 `s`，数到第 `k` 个空格就切掉，因为前 `k` 个单词正好被第 `k` 个空格与后面隔开。

## 怎么做
1. 遍历 `s` 的下标 `i`，遇到 `' '` 就把计数器 `cnt` 加一。
2. `cnt` 第一次等于 `k` 时，`s[:i]` 就是答案，直接返回。
3. 扫完都没凑够 `k` 个空格，说明单词数 ≤ `k`，原样返回 `s`。

以示例 1 的 `s = "Hello how are you Contestant"`、`k = 4` 为例：空格出现在下标 5、9、13、18、23。数到第 4 个空格时 `i = 18`，`s[:18]` 得到 `"Hello how are you"`，正好是前 4 个单词。

```python
cnt = 0
for i, ch in enumerate(s):
    if ch == ' ':
        cnt += 1
        if cnt == k:
            return s[:i]
return s
```

关键点：第 `k` 个空格本身不进入结果，所以切片右端是 `i` 而不是 `i + 1`。

## 复杂度
时间 O(n)：`n` 是 `s` 长度，最坏扫到末尾，切片再花 O(n)。
空间 O(n)：`s[:i]` 新建了一个长度至多 `n` 的字符串。

## 易错点
- `k` 等于单词总数（示例 3，`k = 5`）→ 循环里 `cnt` 永远到不了 5，若在循环内 `return` 就会漏返回 → 必须在循环外补 `return s`。
- 用 `s.split(' ')` 再 `' '.join(words[:k])` → 结果虽对，但多开了整个单词列表，且 `k` 很大时白切了后半段 → 用下标扫描，命中第 `k` 个空格立刻停，后半段一个字符都不碰。

## 如果面试官追问
问：如果 `s` 有前导/尾随空格或多个连续空格怎么办？
答：先按空白切词再拼前 `k` 个，即 `' '.join(s.split()[:k])`，下标法失效。
