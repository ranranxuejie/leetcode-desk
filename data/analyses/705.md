## 一句话思路
用「取模分桶 + 桶内链表」手写哈希集合，key 落在 `key % 769` 号桶，桶内线性查找。

## 怎么做
1. 开 769 个空桶（质数，减少聚集），`buckets = [[] for _ in range(769)]`。
2. `add(key)`：算出 `i = key % 769`，若 `key not in buckets[i]` 才 `append`，保证集合语义。
3. `contains(key)`：同样算 `i`，返回 `key in buckets[i]`。
4. `remove(key)`：算 `i`，若 `key in buckets[i]` 则 `buckets[i].remove(key)`，不在就什么都不做。

以官方示例为例：`add(1)` 时 `i = 1 % 769 = 1`，`buckets[1] = [1]`；`add(2)` 时 `i = 2`，`buckets[2] = [2]`。随后 `contains(3)` 查 `buckets[3]`，是空列表，返回 `False`。`remove(2)` 后 `buckets[2]` 变回 `[]`，再 `contains(2)` 返回 `False`。

```python
B = 769

def add(self, key):
    b = self.buckets[key % B]
    if key not in b:
        b.append(key)

def contains(self, key):
    return key in self.buckets[key % B]

def remove(self, key):
    b = self.buckets[key % B]
    if key in b:
        b.remove(key)
```

## 复杂度
时间：单次操作平均 O(1)，最坏 O(n/B)，n 为桶内元素数。
空间：O(B + k)，B=769 个桶加 k 个已存 key，与调用次数同阶。

## 易错点
- `add(2)` 连续调用两次：若直接 `append` 不判重，`buckets[2]` 变成 `[2, 2]`，之后 `remove(2)` 只删一个，`contains(2)` 仍返回 `True`。正确做法是先 `if key not in b` 再插入。
- `remove(3)` 而 3 从未加入：若写成 `buckets[key % B].remove(key)`，Python 抛 `ValueError`。正确做法是先判 `if key in b`，不在就静默返回。

## 如果面试官追问
问：key 范围扩到 10^9 怎么办？
答：桶数不变，只靠取模分桶，桶内链表长度仍是 O(n/B)，无需按 key 上界开数组。
