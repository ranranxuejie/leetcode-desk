## 一句话思路
按位从低到高凑 target 的二进制位，缺位就向上借一个最近的 2 的幂拆下来，拆的次数即操作数。

## 怎么做
1. 用 `cnt[31]` 统计 nums 中每个 2 的幂的个数，`cnt[i]` 表示值 `2**i` 的个数。
2. 从 `i = 0` 到 30 逐位处理：先把 `cnt[i]` 个 `2**i` 累进 `have`，若 target 的第 i 位是 1 且 `have` 不够，就向上找最小的 `j > i` 使 `cnt[j] > 0`。
3. 找到后把 `2**j` 一路对半拆到 `2**i`：`cnt[j] -= 1`，中间每层 `cnt[k] += 1`，操作数加 `j - i`，同时 `have` 增加 `2**i`。
4. 若向上找不到任何 `cnt[j] > 0`，返回 -1。

以 `nums = [1,2,8], target = 7` 为例：`cnt = [1,1,0,1]`。i=0 时 `have=1`，target 位 1 满足；i=1 时 `have=3`，位 1 满足；i=2 时 target 位为 1 但 `have=3 < 4`，向上找到 `j=3`，拆一次得 `cnt[2]=1`，`have=4`，答案 1。

```python
cnt = [0] * 31
for x in nums:
    cnt[x.bit_length() - 1] += 1
ans, have = 0, 0
for i in range(31):
    have += cnt[i] * (1 << i)
    if (target >> i) & 1 and have < (1 << i):
        j = i + 1
        while j < 31 and cnt[j] == 0:
            j += 1
        if j == 31:
            return -1
        cnt[j] -= 1
        for k in range(j - 1, i - 1, -1):
            cnt[k] += 1
        ans += j - i
        have += 1 << i
return ans
```

## 复杂度
时间 O(n + 31·31)，n 为 nums 长度，拆位循环最多 31 层。
空间 O(31)，只开定长计数数组。

## 易错点
- `nums = [1,32,1], target = 35`：若只按位累加 `have` 而不检查 target 高位，会误判可行；实际 `have` 最大 34 < 35，必须返回 -1，靠 `j == 31` 兜住。
- `nums = [4], target = 3`：i=0 时 `have=0`，向上找到 `j=2`，拆两次得 `cnt=[1,1,0]`，答案 2；若只拆一层（`j-i` 写成 1）会少算，必须累加 `j - i`。

## 如果面试官追问
要求输出具体拆了哪些元素怎么办？答：在拆位循环里记录每次 `(j, i)` 对，按顺序还原即可。
