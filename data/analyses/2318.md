## 一句话思路
用 `dp[i][a][b]` 表示前 i 位、末两位为 a、b 的合法序列数，靠「只看末两位」把约束局部化。

## 怎么做
1. 状态取末两位而非全部历史：GCD 约束只看相邻，间隔约束只看隔一位，`dp[i][a][b]` 足够。
2. 转移枚举下一位 c：要求 `gcd(b,c)==1` 且 `c != a`（c 与 i-1 位相隔 2，不能相等）。
3. 初始化 `dp[2][a][b] = 1`（a≠b 且 gcd(a,b)==1），n=1 直接返回 6。
4. 逐层累加，答案是对所有 (a,b) 的 `dp[n][a][b]` 求和。

以 n=4 为例，`dp[2][1][2]=1`；到 i=3 时 c 可取 3,4,5,6（不能是 1，不能与 2 不互素），故 `dp[3][2][3]` 等各得 1；i=4 时 c=1 对 `dp[3][2][3]` 合法（1≠2 且 gcd(3,1)=1），贡献进 `dp[4][3][1]`，最终求和 184。

```python
MOD = 10**9 + 7
if n == 1: return 6
dp = [[0]*7 for _ in range(7)]
for a in range(1, 7):
    for b in range(1, 7):
        if a != b and gcd(a, b) == 1:
            dp[a][b] = 1
for _ in range(3, n+1):
    ndp = [[0]*7 for _ in range(7)]
    for a in range(1, 7):
        for b in range(1, 7):
            if dp[a][b]:
                for c in range(1, 7):
                    if c != a and gcd(b, c) == 1:
                        ndp[b][c] = (ndp[b][c] + dp[a][b]) % MOD
    dp = ndp
return sum(sum(row) for row in dp) % MOD
```

## 复杂度
时间：O(n·6³)，n 由层数贡献，6³ 是常数枚举。
空间：O(6²)，只滚动保留相邻两层。

## 易错点
- n=1 时若直接进循环会返回 0：单次掷骰无相邻无重复，答案应为 6，需在开头单独返回。
- 把间隔约束写成 `c != b`：`c != a` 才是隔两位比较，写成 b 会漏掉 (1,2,3,1) 这类合法序列，n=4 会少算。

## 如果面试官追问
若 n 放大到 10^9 怎么办？答：6×6 转移矩阵快速幂，O(6³ log n)。
