## 一句话思路
把 big_nums 的前缀乘积拆成「每个数贡献的 2 的幂次之和」，用二分定位第 k 个元素落在哪个数、哪一位，再用快速幂合并。

## 怎么做
1. 定义 `cnt(x)` = 1..x 的强数组总长度 = Σ popcount(i)，用逐位统计在 O(log x) 内算出：第 b 位在 1..x 中出现 `(x+1)//(2**(b+1))*2**b + max(0, (x+1)%(2**(b+1)) - 2**b)` 次。
2. 对查询 `[l, r, m]`，答案 = `pow2exp(r+1) * inv(pow2exp(l))`，但 mod 不保证互素，所以改成算「指数前缀和」：`E(k)` = big_nums[0..k-1] 中所有 2 的幂的指数之和，答案 = `pow(2, E(r+1)-E(l), m)`。
3. `E(k)`：二分出最大的 x 使 `cnt(x) <= k`，累加 1..x 每个数所有置位的位号之和（同样逐位统计：第 b 位贡献 `b * 出现次数`），再处理 x+1 中剩余 `k - cnt(x)` 个元素——即 x+1 的二进制里最低的若干个 1 的位号。
4. 用示例 `queries=[[1,3,7]]` 验证：`E(4)-E(1)`，1..3 的强数组是 [1],[2],[1,2]，指数和 = 0+1+0+1 = 2，`pow(2,2,7)=4`，与输出一致。

```python
def cnt(x):  # 1..x 的强数组总长度
    s = 0
    for b in range(x.bit_length()):
        p = 1 << b
        s += (x + 1) // (p << 1) * p + max(0, (x + 1) % (p << 1) - p)
    return s

def E(k):  # big_nums[0..k-1] 的指数和
    lo, hi = 0, 1
    while cnt(hi) < k: hi <<= 1
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if cnt(mid) <= k: lo = mid
        else: hi = mid - 1
    x, s = lo, 0
    for b in range(x.bit_length()):
        p = 1 << b
        s += b * ((x + 1) // (p << 1) * p + max(0, (x + 1) % (p << 1) - p))
    rest = k - cnt(x)          # x+1 中还要取的位数
    y = x + 1
    for b in range(y.bit_length()):
        if rest == 0: break
        if y >> b & 1:
            s += b; rest -= 1
    return s
```

## 复杂度
时间：每个查询二分 O(log²(10^15)) 次 cnt 调用，每次 cnt 是 O(log)，共约 O(q·log³)；实际 log 只有 50。
空间：只用了几个整数变量，O(1) 额外空间。

## 易错点
- `k=0` 时（如 `from=0`）：若二分下界写成 `lo=1`，`cnt(1)=1>0` 会死循环或返回错误 x；正确做法是 `lo=0`，`cnt(0)=0` 天然满足。
- `rest` 取 x+1 的位时：若按从高到低取位，会得到错误的指数和（强数组是升序，低位在前）；必须从 `b=0` 往上扫，取最低的 `rest` 个置位。
- mod 不互素时想用「前缀积相除」：`pow2exp(l)` 可能不被 m 整除，逆元不存在；必须走指数差再 `pow(2, diff, m)`。

## 如果面试官追问
问：若 queries 的 to 放大到 10^18 呢？
答：cnt 和 E 的位循环只到 `bit_length()`，约 60 次，二分 60 次，单查询仍可接受，无需改结构。
