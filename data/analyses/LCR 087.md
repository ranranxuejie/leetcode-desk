## 一句话思路
回溯枚举每个 IP 段的长度（1~3 位），边切边校验 0~255 与前导 0，凑满 4 段且恰好用完 s 即得一个解。

## 怎么做
1. 递归参数用 `(start, parts)`：`start` 是当前待切的下标，`parts` 是已切出的段列表。
2. 每层枚举 `end` 从 `start` 到 `min(start+3, len(s))`，取子串 `seg = s[start:end]`。
3. 剪枝三条：`len(seg) > 1 and seg[0] == '0'` 跳过；`int(seg) > 255` 跳过；剩余字符数不够或超过剩余段能覆盖的范围也跳过。
4. `len(parts) == 4` 时若 `start == len(s)` 就 `'.'.join(parts)` 收进答案。

以 `s = "25525511135"` 为例，第一段取 `"255"`（`start=0, end=3`），第二段再取 `"255"`（`start=3, end=6`），此时 `parts=["255","255"]`、`start=6`，剩余 `"11135"` 共 5 位要切成 2 段，只能 2+3 或 3+2，于是得到 `255.255.11.135` 和 `255.255.111.35` 两条。

```python
def dfs(start, parts):
    if len(parts) == 4:
        if start == len(s):
            res.append('.'.join(parts))
        return
    for end in range(start + 1, min(start + 4, len(s) + 1)):
        seg = s[start:end]
        if len(seg) > 1 and seg[0] == '0':
            continue
        if int(seg) > 255:
            continue
        dfs(end, parts + [seg])
```

关键剪枝：进入 `dfs` 前可加 `if len(s) - start > 3 * (4 - len(parts)) or len(s) - start < (4 - len(parts)): return`，否则 `"0000"` 这类会白跑很多分支。

## 复杂度
时间：O(3^4 × n)，每段最多 3 种长度、共 4 段，`'.'.join` 与切片各 O(n)。
空间：递归深度固定 4，栈 O(1)；答案列表存全部解，每个解长 O(n)。

## 易错点
- 输入 `"010010"` → 若只判 `int(seg) > 255` 不判前导 0，会把 `"01"` 当合法段，多出 `0.1.0.0.10` 之类的错解 → 必须加 `len(seg) > 1 and seg[0] == '0'` 直接 `continue`。
- 输入 `"0000"` → 若允许段长 0 或忘记校验 `start == len(s)`，会返回空或重复 → 段长从 1 起，且收答案时必须 `start` 正好走到末尾，四段用完但字符没用完（如 `"11111"`）要丢弃。

## 如果面试官追问
问：s 长度到 3000 怎么办？
答：合法 IP 最多 12 位数字，`len(s) > 12` 直接返回 `[]`，剪枝后仍是常数级搜索。
