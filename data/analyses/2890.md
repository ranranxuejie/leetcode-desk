## 一句话思路
用 `pd.melt` 把 `quarter_1..4` 四列压成 `quarter`/`sales` 两列，宽表转长表一行搞定。

## 怎么做
1. 确定保留列：`id_vars=["product"]`，它不参与压平。
2. 确定被压平的列：`value_vars=["quarter_1","quarter_2","quarter_3","quarter_4"]`，顺序决定输出行序。
3. 指定新列名：`var_name="quarter"`、`value_name="sales"`。
4. 调用 `melt` 返回新 DataFrame。

以官方输入为例，`melt` 内部先取 `product` 列 `["Umbrella","SleepingBag"]`，再对 `quarter_1` 列取值 `[417,800]` 拼成两行；四列依次展开后共 `2*4=8` 行。关键中间值：`quarter_1` 这一组产出 `(Umbrella, quarter_1, 417)` 和 `(SleepingBag, quarter_1, 800)`，正好是输出前两行。

```python
import pandas as pd

def melt_table(report: pd.DataFrame) -> pd.DataFrame:
    return report.melt(
        id_vars=["product"],
        value_vars=["quarter_1", "quarter_2", "quarter_3", "quarter_4"],
        var_name="quarter",
        value_name="sales",
    )
```

注意 `value_vars` 不写时 `melt` 会把除 `id_vars` 外的所有列都压平，本题恰好只有四列季度，结果相同；但显式写出可防止 `report` 多出无关列时行数翻倍。

## 复杂度
时间：O(n)，n 为输出行数 = 原行数 × 4，每格读写一次。
空间：O(n)，新建 `quarter`/`sales` 两列共 2n 个单元格，原表不动。

## 易错点
- 漏写 `var_name`/`value_name` → 输出列名变成 `variable`/`value`，与期望的 `quarter`/`sales` 不符 → 必须显式指定这两个参数。
- 把 `product` 也放进 `value_vars` → `product` 列被当数值压平，行数变 10 行且 `sales` 混入字符串 → `id_vars` 只放 `product`，`value_vars` 只放四个季度列。

## 如果面试官追问
问：若季度列有上百个、列名不规则怎么办？
答：用 `report.columns.drop("product")` 动态取 `value_vars`，避免手写列名。
