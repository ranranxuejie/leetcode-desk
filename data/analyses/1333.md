## 一句话思路
先按三个条件筛出候选，再用 `sorted` 的 key 对 `(rating, id)` 双降序排，最后只取 id。

## 怎么做
1. 遍历 `restaurants`，对每个 `r = [id, rating, vegan, price, distance]` 判断是否保留。
2. 保留条件：`price <= maxPrice and distance <= maxDistance`，且 `veganFriendly == 0 or vegan == 1`。
3. 把保留的整行收进列表，用 `key=lambda r: (r[1], r[0])` 加 `reverse=True` 排序。
4. 列表推导取 `r[0]` 返回。

以示例 1 为例，`veganFriendly = 1`：餐馆 2（vegan=0）和餐馆 4（vegan=0）被剔除；餐馆 1、3、5 价格距离都达标，全部保留。排序时餐馆 3 和餐馆 1 的 rating 分别是 8 和 4，所以 3 在前；餐馆 5 rating=1 垫底，得到 `[3, 1, 5]`。

```python
res = []
for r in restaurants:
    if r[3] <= maxPrice and r[4] <= maxDistance:
        if veganFriendly == 0 or r[2] == 1:
            res.append(r)
res.sort(key=lambda r: (r[1], r[0]), reverse=True)
return [r[0] for r in res]
```

关键点：`reverse=True` 同时作用于元组的两个分量，rating 和 id 都降序，正好符合题意，不用写 `-r[1]` 那种取负技巧。

## 复杂度
时间：O(n log n)，n 为餐馆数，排序主导，过滤是 O(n)。
空间：O(n)，`res` 最坏存下全部餐馆。

## 易错点
- `veganFriendly = 0` 时误加 `r[2] == 0` 条件 → 示例 2 会漏掉餐馆 1、3、5，输出变成 `[4, 2]`。正确写法是 `veganFriendly == 0 or r[2] == 1`，0 表示「不筛素食」而非「只要非素食」。
- 排序只写 `key=lambda r: r[1]` → 示例 2 中餐馆 2 和餐馆 3 的 rating 都是 8，稳定排序会保留输入顺序得 `[4, 2, 3, 1, 5]`，而正确答案要求 id 降序 `[4, 3, 2, 1, 5]`。必须把 `r[0]` 放进 key 元组。

## 如果面试官追问
若 `restaurants` 涨到 10^7 且只要前 k 个 id，怎么办？
答：过滤后用 `heapq.nlargest(k, res, key=lambda r: (r[1], r[0]))`，时间降到 O(n log k)。
