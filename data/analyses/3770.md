## 一句话思路
先筛出 ≤n 的所有质数，再对「从 2 开始的连续质数和」逐个累加，取其中 ≤n 且为质数的最大值。

## 怎么做
1. 用埃氏筛在 `[0, n]` 上建布尔表 `is_prime`，`is_prime[0]=is_prime[1]=False`。
2. 按顺序收集质数到列表 `primes`，累加时天然从 2 开始。
3. 从 `primes[0]=2` 起累加 `s`，每加一个就判断 `s <= n and is_prime[s]`，成立则更新 `ans`。
4. 一旦 `s > n` 立即 `break`，因为后续只会更大。

以 `n = 20` 为例：`primes = [2,3,5,7,11,13,17,19]`。累加过程 `s` 依次为 2、5、10、17、28；其中 2、5、17 是质数且 ≤20，`ans` 最终为 17；加到 28 时超过 20，跳出。

```python
is_prime = [True] * (n + 1)
is_prime[0] = is_prime[1] = False
for i in range(2, int(n ** 0.5) + 1):
    if is_prime[i]:
        for j in range(i * i, n + 1, i):
            is_prime[j] = False

ans, s = 0, 0
for p in range(2, n + 1):
    if not is_prime[p]:
        continue
    s += p
    if s > n:
        break
    if is_prime[s]:
        ans = s
```

注意 `s` 的初值是 0，第一次加 2 得 2，正好覆盖「单个质数 2」这一项，不需要特判。

## 复杂度
时间：筛法 O(n log log n)，累加 O(π(n)) 且提前 break，总体 O(n log log n)。
空间：`is_prime` 长度 n+1，O(n)。

## 易错点
- `n = 1` 时若直接 `is_prime[1] = False` 前没建够长度会越界；正确做法是先建 `n+1` 长度的表再置 `is_prime[0]=is_prime[1]=False`，此时循环不进入，返回 0。
- 累加时若在 `s > n` 后仍继续加，`s` 会一直增大且永远不满足 `s <= n`，虽然结果不变但白跑；正确做法是 `s > n` 立刻 `break`，因为质数递增、部分和单调递增。

## 如果面试官追问
问：n 放大到 10^7 怎么办？答：筛法仍可行但内存吃紧，可改用分段筛只保留 ≤n 的质数表，累加部分不变。
