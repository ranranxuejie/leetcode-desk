## 一句话思路
对每个 groups[i] 枚举其约数 d，查哈希表 `first[d]` 得到最小下标，取所有约数中的最小下标。

## 怎么做
1. 预处理 elements：`first[v]` 记录值 v 在 elements 中**首次出现**的下标，重复值只留最小下标。
2. 对每个 groups[i] = g，枚举 d 从 1 到 ⌊√g⌋，若 g % d == 0 则同时检查 d 和 g // d 两个约数。
3. 每个约数查 `first`，取最小下标；全查不到则 -1。

以示例 1 为例：`elements = [4,2]`，`first = {4:0, 2:1}`。groups[0] = 8，约数为 1、2、4、8，其中 2 和 4 命中，下标 1 和 0，取 min 得 **0**。groups[2] = 3，约数 1、3 都不在 `first` 中，得 **-1**。

```python
first = {}
for j, v in enumerate(elements):
    if v not in first:
        first[v] = j

res = []
for g in groups:
    best = -1
    d = 1
    while d * d <= g:
        if g % d == 0:
            for k in (d, g // d):
                if k in first:
                    j = first[k]
                    if best == -1 or j < best:
                        best = j
        d += 1
    res.append(best)
```

关键点：`first` 只存首次下标，所以查表直接得到「最小下标 j」，无需再比较同值元素。

## 复杂度
时间：O(n·√max(groups) + m)，n = len(groups)，m = len(elements)，每个组枚举约数。
空间：O(m) 的 `first` 哈希表，结果数组 O(n)。

## 易错点
- `elements` 有重复值（如示例 2 的 `[5,3,3]`）→ 若用 `first[v] = j` 覆盖写，会把 3 的下标记成 2，组 1 输出 2 而非 1 → 必须 `if v not in first` 才写入。
- 枚举约数只写 `d` 不写 `g // d` → 组大小 8 只查到 1、2，漏掉 4 和 8，示例 1 的 groups[0] 会错成 1 而非 0 → 两个约数都要查，且 `d == g // d` 时重复查一次无害。

## 如果面试官追问
若 groups 和 elements 都放大到 10^9 且元素个数少？答：仍按 groups 枚举约数 O(√g)，但可先对 elements 排序去重，用二分或预筛小值加速。
