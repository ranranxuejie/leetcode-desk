## 一句话思路
从左扫到第一个 `nums[i] >= nums[i+1]` 的断点，只需判断删 `nums[i]` 还是删 `nums[i+1]`，其余位置已递增。

## 怎么做
1. 用 `i` 找第一个满足 `nums[i] >= nums[i+1]` 的位置，找不到直接返回 `True`。
2. 删 `nums[i]`：检查 `nums[i-1] < nums[i+1]`（`i==0` 视为成立）。
3. 删 `nums[i+1]`：检查 `nums[i] < nums[i+2]`（`i+2==len` 视为成立）。
4. 两者任一成立即 `True`，否则 `False`。

以 `nums = [1,2,10,5,7]` 为例，`i=2`（`10 >= 5`）。删 `10`：`nums[1]=2 < nums[3]=5` 成立，返回 `True`。若换成 `[2,3,1,2]`，`i=1`（`3 >= 1`）：删 `3` 要 `nums[0]=2 < nums[2]=1` 假；删 `1` 要 `nums[1]=3 < nums[3]=2` 假，返回 `False`。

```python
i = 0
while i + 1 < len(nums) and nums[i] < nums[i + 1]:
    i += 1
if i + 1 == len(nums):
    return True
drop_left = i == 0 or nums[i - 1] < nums[i + 1]
drop_right = i + 2 == len(nums) or nums[i] < nums[i + 2]
return drop_left or drop_right
```

## 复杂度
时间：O(n)，`while` 最多扫一遍 `nums`，断点后只做 O(1) 比较。
空间：O(1)，只用了 `i`、`drop_left`、`drop_right` 三个变量。

## 易错点
- `nums = [1,1,1]` → 若只判断「删掉断点元素后局部有序」就返回 `True`，会错成 `True`；实际删任意一个都剩 `[1,1]`，`nums[i-1] < nums[i+1]` 与 `nums[i] < nums[i+2]` 全为假，必须两个条件都判。
- `nums = [1,2,3]` 或 `[1,2,10]` → 若把「没找到断点」当成失败返回 `False`，会错；`i+1 == len(nums)` 时必须先返回 `True`，因为题面允许本身已严格递增。

## 如果面试官追问
问：改成「最多删 k 个」怎么办？
答：断点计数，每遇一个断点尝试删左或删右并消耗一次配额，用贪心加回溯或 DP 记剩余次数。
