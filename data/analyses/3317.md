## 一句话思路
按「实际有人的节目数 k」分类，方案数 = C(x,k)·k!·S(n,k)·y^k，其中 S(n,k) 是第二类斯特林数。

## 怎么做
1. 枚举 k 从 1 到 min(n,x)：从 x 个节目里选 k 个、把 n 个表演者满射到这 k 个节目上，方案数是 C(x,k)·k!·S(n,k)。
2. 每个有人的节目独立打分 y 种，乘 y^k。
3. S(n,k) 用递推 S(i,j)=S(i-1,j-1)+j·S(i-1,j) 打表，边界 S(0,0)=1。
4. 组合数 C(x,k) 用阶乘与逆元，或直接递推 C(x,k)=C(x,k-1)·(x-k+1)/k。

以 n=3, x=3, y=4 为例，k=2 时 S(3,2)=3，C(3,2)·2!·3·4^2 = 3·2·3·16 = 288；k=1 得 3·1·1·4=12，k=3 得 1·6·1·64=384，合计 684。

```python
MOD = 10**9 + 7
m = min(n, x)
S = [[0]*(m+1) for _ in range(n+1)]
S[0][0] = 1
for i in range(1, n+1):
    for j in range(1, min(i, m)+1):
        S[i][j] = (S[i-1][j-1] + j*S[i-1][j]) % MOD
ans, comb, fact, yk = 0, 1, 1, 1
for k in range(1, m+1):
    comb = comb * (x-k+1) % MOD * pow(k, MOD-2, MOD) % MOD
    fact = fact * k % MOD
    yk = yk * y % MOD
    ans = (ans + comb * fact % MOD * S[n][k] % MOD * yk) % MOD
```

## 复杂度
时间：O(n·min(n,x))，由斯特林表双重循环贡献。
空间：O(n·min(n,x)) 存 S 表，其余 O(1)。

## 易错点
- n=5, x=2, y=1 时若漏掉 y^k 因子（或误以为 y=1 时 k 必须为 1），会算成 30 而非 32；正确做法是 y=1 时 y^k 恒为 1，答案退化为满射总数 2^5=32。
- x 远大于 n（如 n=1, x=1000）时若循环 k 到 x，会访问 S[1][k>1] 得到 0 并多算组合数；正确做法是上界取 min(n,x)，因为 k>n 时 S(n,k)=0。

## 如果面试官追问
问：n 到 10^9、x,y 到 1000 怎么办？
答：k 上界仍是 min(n,x)≤1000，但 S(n,k) 不能打表，需用容斥 S(n,k)=1/k!·Σ(-1)^j C(k,j)(k-j)^n 快速幂求。
