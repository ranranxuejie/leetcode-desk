## 一句话思路
把「取反一个元素」转成「子数组和 ≡ ±nums[i] (mod k)」，用前缀和余数 + 二分查最早出现位置。

## 怎么做
1. 设前缀和 `pre[j] = sum(nums[:j])`，子数组 `(i, j]` 的和为 `pre[j] - pre[i]`；取反 `nums[t]`（`i <= t < j`）后和变为 `pre[j] - pre[i] - 2*nums[t]`。
2. 有效条件即 `(pre[j] - pre[i]) % k == 0` 或存在 `t` 使 `(pre[j] - pre[i] - 2*nums[t]) % k == 0`，即 `pre[i] % k == (pre[j] - 2*nums[t]) % k`。
3. 对每个 `j`，枚举 `t` 太慢；改为对每个余数 `r` 维护前缀下标列表，二分找 `< j` 的最小下标。
4. 用官方示例 1 `nums=[4,1,2], k=3`：`pre=[0,4,5,7]`，`pre%3=[0,1,2,1]`。`j=3` 时 `pre[3]%3=1`，余数 1 最早出现在 `i=1`，长度 `3-1=2`；再看取反 `nums[2]=2`，需 `pre[i]%3=(1-4)%3=0`，余数 0 在 `i=0`，长度 `3-0=3`，取最大得 3。

```python
from bisect import bisect_left
pos = [[] for _ in range(k)]
pos[0].append(0)
pre = ans = 0
for j, x in enumerate(nums, 1):
    pre += x
    r = pre % k
    for rr in {r, (r - 2 * x) % k}:
        lst = pos[rr]
        idx = bisect_left(lst, j)
        if idx:
            ans = max(ans, j - lst[idx - 1])
    pos[r].append(j)
```

## 复杂度
时间 O(n log n)：n 个元素各做两次二分，每次 O(log n)。
空间 O(n + k)：`pos` 存 n 个下标，外层 k 个列表。

## 易错点
- `nums` 含负数时，Python 的 `%` 返回非负余数（`-4 % 3 == 2`），与 C++ 不同；若照搬 C++ 写法用 `pre % k` 再手动加 k，会得到 `2+k` 越界。直接用 Python `%` 即可，`pos` 大小开 `k`。
- 取反项 `(r - 2*x) % k` 中 `x` 是当前元素 `nums[j-1]`，不是前缀和；写成 `(r - 2*pre) % k` 会让示例 1 的 `j=3` 算出余数 `(1-14)%3=2`，长度错成 2 而非 3。

## 如果面试官追问
若 k 放大到 10^9 无法开数组怎么办？答：改用哈希表存 `余数 -> 下标列表`，时间不变，空间降到 O(n)。
