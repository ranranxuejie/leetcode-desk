## 一句话思路
用度数数组 + 排序双指针数出「度数和 > q」的点对，再减去被多重边重复计入的部分。

## 怎么做
1. 统计 `deg[v]`（含多重边）和 `cnt[(u,v)]`（u<v 的边数）。
2. 对 `deg` 排序得 `d`，双指针求 `S(q)` = 满足 `d[i]+d[j] > q` 的点对数。
3. 遍历所有有边的点对 `(u,v)`，若 `deg[u]+deg[v] > q` 但 `deg[u]+deg[v]-cnt[(u,v)] <= q`，说明该对被多算，减 1。
4. 对每个 query 重复步骤 2-3。

以示例 1 为例：`edges=[[1,2],[2,4],[1,3],[2,3],[2,1]]`，`deg=[0,3,3,2,1]`（下标 0 空），排序后 `d=[1,2,3,3]`。q=2 时双指针得 S=6；检查有边点对 (1,2)：`3+3-2=4>2` 不减；(2,3)：`3+2-1=4>2` 不减；全部保留，答案 6。

```python
from collections import Counter
deg = [0]*(n+1)
cnt = Counter()
for u, v in edges:
    deg[u] += 1; deg[v] += 1
    cnt[(min(u,v), max(u,v))] += 1
d = sorted(deg[1:])
for q in queries:
    ans, j = 0, n-1
    for i in range(n):
        while j > i and d[i]+d[j] > q: j -= 1
        ans += n-1-max(i,j)
    for (u,v), c in cnt.items():
        if deg[u]+deg[v] > q and deg[u]+deg[v]-c <= q:
            ans -= 1
```

## 复杂度
时间：排序 O(n log n)，每个 query 双指针 O(n) + 遍历边 O(m)，共 O(n log n + q(n+m))。
空间：`deg` O(n)、`cnt` O(m)，排序副本 O(n)。

## 易错点
- 输入含多重边如 `[[1,5],[1,5]]` → 若用 `set` 去重统计 `deg`，度数会少算 → 必须用 `Counter` 累加，`deg[1]=deg[5]=2`。
- 双指针边界写成 `d[i]+d[j] >= q` → 示例 1 中 q=2 时 (3,4) 度数和 3 会被误判为不满足 → 题目要求严格大于，必须用 `>`。

## 如果面试官追问
若 queries 数量从 20 增到 10^5 怎么办？答：把 `d` 的答案预计算成前缀和数组，每个 query 二分查找 O(log n)。
