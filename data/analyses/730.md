## 一句话思路
按首尾字符分类的区间 DP：`dp[i][j]` 记 `s[i..j]` 的不同回文子序列数，用首尾字符是否相同分四种情况转移。

## 怎么做
1. 定义 `dp[i][j]` 为 `s[i..j]` 的不同非空回文子序列个数，长度从 1 递推到 n。
2. 若 `s[i] != s[j]`，则 `dp[i][j] = dp[i+1][j] + dp[i][j-1] - dp[i+1][j-1]`（容斥，减去重复计的部分）。
3. 若 `s[i] == s[j] == c`，在 `(i, j)` 内找 c 的最左位置 `l` 和最右位置 `r`：`l > r` 说明内部无 c，`dp = 2*dp[i+1][j-1] + 2`（新增 `c`、`cc`）；`l == r` 说明只有一个 c，`dp = 2*dp[i+1][j-1] + 1`；`l < r` 说明有多个 c，`dp = 2*dp[i+1][j-1] - dp[l+1][r-1]`。
4. 全程对 `10**9 + 7` 取模，负数补模。

以 `s = 'bccb'` 为例，`i=0, j=3`，`s[0]==s[3]=='b'`，内部 `s[1..2]='cc'`，b 的最左最右都在区间外，即 `l>r`，故 `dp[0][3] = 2*dp[1][2] + 2`。而 `dp[1][2]`（`'cc'`）首尾相同且内部无 c，得 `2*0+2=2`（`'c'`、`'cc'`），所以 `dp[0][3] = 2*2+2 = 6`，与答案一致。

```python
MOD = 10**9 + 7
n = len(s)
dp = [[0]*n for _ in range(n)]
for i in range(n):
    dp[i][i] = 1
for length in range(2, n+1):
    for i in range(n-length+1):
        j = i + length - 1
        if s[i] != s[j]:
            dp[i][j] = (dp[i+1][j] + dp[i][j-1] - dp[i+1][j-1]) % MOD
        else:
            l, r = i+1, j-1
            while l <= r and s[l] != s[i]: l += 1
            while l <= r and s[r] != s[i]: r -= 1
            if l > r:
                dp[i][j] = (2*dp[i+1][j-1] + 2) % MOD
            elif l == r:
                dp[i][j] = (2*dp[i+1][j-1] + 1) % MOD
            else:
                dp[i][j] = (2*dp[i+1][j-1] - dp[l+1][r-1]) % MOD
```

## 复杂度
时间：O(n²) 状态数，每个状态内层 while 最坏 O(n)，实际因只有 4 种字符可视为 O(n²)。
空间：O(n²) 的 `dp` 二维表，n ≤ 1000 约 10⁶ 个整数。

## 易错点
- 输入 `s = 'aaa'`：若首尾相同就一律用 `2*dp[i+1][j-1]+2`，会把 `'a'` 重复计数，得 5 而非 3。正确做法是先用 `l`、`r` 判断内部是否还有 `'a'`，`l==r` 时只能 `+1`。
- 输入 `s = 'abba'`：`s[0]==s[3]=='a'`，内部 `'bb'` 含 a 吗？不含，`l>r`，得 `2*dp[1][2]+2`。若误判成 `l<r` 去减 `dp[l+1][r-1]`，会减到越界或错误区间。必须先扫出 `l`、`r` 再分支。

## 如果面试官追问
问：n 放大到 10⁵ 怎么办？答：本题依赖 4 种字符的区间 DP，n 大时需换思路，如按字符分别统计贡献或用回文自动机，O(n²) 不可行。
