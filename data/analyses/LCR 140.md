## 一句话思路
快指针先走 cnt 步，再与慢指针同步前进，快指针到 None 时慢指针正好落在倒数第 cnt 个节点。

## 怎么做
1. 令 `fast = head`、`slow = head`，先让 `fast` 单独前进 `cnt` 步。
2. 以官方示例 `head = [2,4,7,8]`、`cnt = 1` 为例，`fast` 走 1 步后停在节点 `4`，此时 `slow` 仍在 `2`。
3. 然后 `fast` 和 `slow` 同时每次走一步，直到 `fast` 为 `None` 为止。
4. 循环结束时返回 `slow`。

关键中间值：示例中 `fast` 从 `4` 出发，依次经过 `7`、`8`、`None`，共走 3 步；`slow` 同步从 `2` 走到 `4`、`7`、`8`，`fast` 变成 `None` 时 `slow` 停在 `8`，正是倒数第 1 个。

```python
fast = slow = head
for _ in range(cnt):
    fast = fast.next
while fast:
    fast = fast.next
    slow = slow.next
return slow
```

`cnt = head.length` 时，`fast` 走完全程变为 `None`，`while` 一次都不进，直接返回 `head`，即倒数第 n 个就是头节点，逻辑自洽。

## 复杂度
时间：O(n)，`fast` 走 n 步，`slow` 走 n-cnt 步，合计不超过 2n。
空间：O(1)，只开了 `fast`、`slow` 两个指针，没有额外容器。

## 易错点
- `cnt = head.length`（如 `head = [2,4,7,8]`、`cnt = 4`）→ 若把 `while fast` 写成 `while fast.next`，`fast` 会停在 `8`，`slow` 只走到 `7`，返回倒数第 2 个 → 正确做法是循环条件用 `while fast`，让 `fast` 走到 `None` 而非最后一个节点。
- `cnt = 1`（示例）→ 若先同步走再让 `fast` 补步，或把 `for _ in range(cnt)` 写成 `range(cnt - 1)`，`slow` 会停在 `7` 而非 `8` → 正确做法是 `fast` 严格先走 `cnt` 步，差值恰好为 `cnt`，`slow` 才落在倒数第 `cnt` 位。

## 如果面试官追问
若要求一次遍历且不许先数长度怎么办？答：本题双指针本身就是一次遍历，先走 cnt 步不算额外遍历，仍是 O(n)。
