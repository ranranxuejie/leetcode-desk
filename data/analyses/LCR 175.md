## 一句话思路
用 DFS 递归求左右子树深度取较大值加一，因为整棵树的深度等于根到最深叶的节点数。

## 怎么做
1. 空节点返回 0，作为递归的终止条件。
2. 递归求 `root.left` 和 `root.right` 的深度。
3. 返回 `max(左深度, 右深度) + 1`，加一计入当前根节点。

以示例 `root = [1, 2, 2, 3, null, null, 5, 4, null, null, 4]` 为例：走到节点 `3` 时，它的左孩子是 `4`、右孩子是 `None`，返回 `max(1, 0) + 1 = 2`；节点 `2`（左子树根）再返回 `max(2, 0) + 1 = 3`；根节点 `1` 左支得 3、右支经 `5 -> 4` 也得 3，最终 `max(3, 3) + 1 = 4`。

```python
def depth(node):
    if node is None:
        return 0
    left = depth(node.left)
    right = depth(node.right)
    return max(left, right) + 1
```

关键中间值：节点 `3` 处 `left=1, right=0`，返回 2；根处 `left=3, right=3`，返回 4。

## 复杂度
时间 O(n)：每个节点恰好访问一次，n 为节点总数。
空间 O(h)：递归栈深度等于树高 h，最坏链状树 O(n)，平衡树 O(log n)。

## 易错点
- 输入 `root = []`（空树）→ 若没写 `node is None` 的终止条件会直接报错或返回 1 → 正确做法是空节点返回 0，答案才是 0 而非 1。
- 输入链状树（如一直往左挂 10000 个节点）→ 递归深度达到 10000，Python 默认递归上限约 1000 会 `RecursionError` → 正确做法是改用 BFS 按层计数，或 `sys.setrecursionlimit(20000)`。

## 如果面试官追问
问：节点数涨到 10^6 且树退化成链怎么办？
答：递归栈会爆，改用 BFS 队列逐层遍历，每弹完一层 `depth += 1`，空间 O(宽度)。
