## 一句话思路
把状态扩成 `(节点, 当前标签连续长度)` 跑 Dijkstra，因为边权为正且「连续长度」只由前驱标签决定，最短路可分层求解。

## 怎么做
1. 状态定义为 `(dist, u, run)`，`run` 是到达 `u` 时末尾连续相同标签的个数，范围 `1..k`。
2. 起点入堆 `(0, 0, 1)`，因为 `labels[0]` 本身算 1 个连续字符。
3. 弹出时若 `u == n-1` 直接返回 `dist`；否则对每条出边 `(u, v, w)` 算 `nr = run+1 if labels[v]==labels[u] else 1`，`nr <= k` 才入堆。
4. 用 `best[u][run]` 剪枝，堆里存的是已确定最小的 `dist`。

以示例 2（`labels="aab"`, `k=2`）为例：起点 `(0,0,1)`，走 `0→1` 得 `nr=2`（`a==a`），状态 `(1,1,2)`；再走 `1→2` 时 `labels[2]='b' != 'a'`，`nr=1`，状态 `(2,2,1)`，弹出 `u=2` 返回 2。若 `k=1`，`0→1` 的 `nr=2>1` 被丢弃，只剩 `0→2` 权重 3。

```python
import heapq
best = [[float('inf')] * (k + 1) for _ in range(n)]
best[0][1] = 0
pq = [(0, 0, 1)]
while pq:
    d, u, run = heapq.heappop(pq)
    if d > best[u][run]:
        continue
    if u == n - 1:
        return d
    for v, w in adj[u]:
        nr = run + 1 if labels[v] == labels[u] else 1
        if nr <= k and d + w < best[v][nr]:
            best[v][nr] = d + w
            heapq.heappush(pq, (d + w, v, nr))
return -1
```

## 复杂度
时间：`O((n*k + m*k) log(n*k))`，堆里最多 `n*k` 个状态，每条边对每个 `run` 松弛一次。
空间：`O(n*k + m)`，`best` 表 `n*(k+1)`，邻接表存 `m` 条边。

## 易错点
- 起点 `run` 写成 0：`labels="aaa"`、`k=2` 时会把 `0→1→2` 误判为合法（`run` 从 0 起算只累计到 2），实际应返回 -1。正确做法是起点 `run=1`，`0→1` 后 `run=2`，`1→2` 后 `run=3>2` 被剪。
- 只按节点去重（`best[u]` 单值）：示例 1 中 `k=1` 时先松弛 `0→1` 得 `best[1]=1`，再走 `1→2` 时 `run=2>1` 被丢，但 `0→1` 这条路径本身合法，若用单值 `best[1]` 覆盖会漏掉后续不同 `run` 的更优组合。必须用 `best[u][run]` 二维去重。

## 如果面试官追问
问：若要求输出具体路径而非仅最小权值？
答：在 `best[v][nr]` 更新时额外记 `pre[v][nr] = (u, run)`，从终点状态沿 `pre` 回溯即可。
