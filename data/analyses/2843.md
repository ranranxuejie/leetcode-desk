## 一句话思路
直接枚举 `[low, high]` 每个数，转字符串后判断长度是否为偶数、前后两半数字和是否相等。

## 怎么做
1. 循环 `x` 从 `low` 到 `high`，把 `x` 转成字符串 `s`。
2. 若 `len(s) % 2 == 1`，跳过（奇数位不可能是对称整数）。
3. 取 `n = len(s) // 2`，比较 `sum(s[:n])` 与 `sum(s[n:])`。
4. 相等则计数加一，最后返回计数。

以示例 2 的 `x = 1203` 为例：`s = "1203"`，`n = 2`，前半 `"12"` 数字和 `1+2 = 3`，后半 `"03"` 数字和 `0+3 = 3`，相等，计入。而 `x = 1201` 后半是 `"01"` 和为 1，不等，不计。

```python
def count(low, high):
    ans = 0
    for x in range(low, high + 1):
        s = str(x)
        n = len(s) // 2
        if len(s) % 2:
            continue
        if sum(map(int, s[:n])) == sum(map(int, s[n:])):
            ans += 1
    return ans
```

注意 `sum(s[:n])` 直接对字符求和会报错，必须 `map(int, ...)` 或 `sum(int(c) for c in s[:n])`。

## 复杂度
时间：O((high-low+1) · log high)，每个数转字符串和求和都是位数级别。
空间：O(log high)，每个数的字符串临时占用，无额外数组。

## 易错点
- 输入 `low = 1, high = 100`：若忘记跳过奇数位，`1`、`100` 这类会被误判或下标错位；正确做法是先判 `len(s) % 2`，奇数直接 `continue`。
- 输入 `x = 1203`：若写成 `sum(s[:n])` 对字符求和，Python 会抛 `TypeError`；必须 `map(int, ...)` 转成数字再求和，否则 `"12"` 的和不是 3。

## 如果面试官追问
问：high 放大到 10^9 怎么办？答：不能逐个枚举，改为按位数构造前 n 位、用数字和配对后 n 位，或直接数位 DP 统计。
