## 一句话思路
把大于 k 记 +1、小于 k 记 -1，中位数为 k 等价于含 k 且左右两侧和相等，用哈希表配前缀和计数。

## 怎么做
1. 先扫一遍找到 k 的下标 `pos`，因为任何合法子数组必须包含它。
2. 从 `pos` 向左累加符号和，用 `dict` 记录每个左半和出现的次数（含空前缀 0 记 1 次）。
3. 从 `pos` 向右累加符号和，每到一个位置就查 `dict[-right_sum]` 累加答案。
4. 符号规则：`nums[i] > k` 记 +1，`nums[i] < k` 记 -1，`nums[i] == k` 记 0。

以 `nums = [3,2,1,4,5], k = 4` 为例，`pos = 3`。左半从 pos 往左：`nums[3]=4` 记 0，`nums[2]=1` 记 -1，`nums[1]=2` 记 -1，`nums[0]=3` 记 -1，左前缀和依次是 `0, -1, -2, -3`，`dict = {0:1, -1:1, -2:1, -3:1}`。右半从 pos 往右：`nums[3]=4` 记 0，右和 0，查 `dict[0]=1`；`nums[4]=5` 记 +1，右和 1，查 `dict[-1]=1`。再往左延伸时 `nums[2]=1` 记 -1，右和 0，查 `dict[0]=1`，累计 3。

```python
pos = nums.index(k)
cnt = {0: 1}
s = 0
for i in range(pos - 1, -1, -1):
    s += 1 if nums[i] > k else -1
    cnt[s] = cnt.get(s, 0) + 1
ans = s = 0
for i in range(pos, len(nums)):
    if nums[i] != k:
        s += 1 if nums[i] > k else -1
    ans += cnt.get(-s, 0)
```

## 复杂度
时间：O(n)，找 pos 一次、左右各扫一遍，哈希查询均摊 O(1)。
空间：O(n)，`cnt` 最多存 n 个不同前缀和。

## 易错点
- 左半循环从 `pos - 1` 开始、右半从 `pos` 开始，若两边都从 `pos` 起算，`nums[pos]=k` 会被重复计入符号 0，导致 `[4]` 这类单元素子数组被算两次。正确做法是 k 只在右半起点出现一次。
- 偶数长度取中间靠左，等价于「大于 k 的个数 == 小于 k 的个数」，不是「大于等于」。若把 `nums[i] == k` 也记 +1，`[1,4,5]` 会被判成不合法，答案从 3 掉到 2。符号必须严格按 `>` 和 `<` 分。

## 如果面试官追问
问：若 nums 允许重复且 k 出现多次怎么办？
答：每个 k 位置单独作为锚点，左右前缀和分别统计后相乘再求和，注意去重区间。
