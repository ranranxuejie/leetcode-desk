## 一句话思路
用 Dijkstra 求到每个格子的最小累计扣血，看终点最小扣血是否小于 health。

## 怎么做
1. 把「健康值」转成「扣血」：进入格子 (i,j) 扣 `grid[i][j]`，起点 (0,0) 也要扣，求到终点最小总扣血。
2. 用堆做 Dijkstra，`dist[i][j]` 记录到达该格的最小扣血，初始 `dist[0][0] = grid[0][0]`。
3. 每次弹出最小扣血状态，若已到 `(m-1, n-1)` 直接比较 `dist < health`；否则向四邻松弛 `nd = d + grid[ni][nj]`。
4. 松弛时若 `nd < dist[ni][nj]` 才更新入堆，避免重复。

以示例 1 为例，`grid` 为 3x5、`health = 1`。起点 `grid[0][0]=0`，`dist[0][0]=0`。沿第一列向下到 `(2,0)` 扣血仍为 0，再沿底行向右，途中 `(2,3)` 是 1，扣血变 1，到终点 `(2,4)` 时 `dist=1`。判断 `1 < 1` 为假——但示例输出是 `true`，说明题意是「到达终点时健康值 ≥ 1」，即扣血 `< health` 才安全，此处 `1 < 1` 不成立。按示例 1 实际路径应绕开 `(2,3)`：从 `(1,2)` 下到 `(2,2)` 再右行，全程只扣 `(0,1)` 之外……关键中间值：走 `(0,0)→(1,0)→(2,0)→(2,1)→(2,2)→(1,2)→(0,2)→(0,3)→(0,4)→(1,4)→(2,4)`，只经过 `(0,1)` 一个 1 吗？该路径避开所有 1，`dist[2][4]=0 < 1`，返回 `True`。

```python
import heapq
m, n = len(grid), len(grid[0])
dist = [[float('inf')] * n for _ in range(m)]
dist[0][0] = grid[0][0]
pq = [(dist[0][0], 0, 0)]
while pq:
    d, i, j = heapq.heappop(pq)
    if d > dist[i][j]:
        continue
    if (i, j) == (m - 1, n - 1):
        return d < health
    for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
        ni, nj = i + di, j + dj
        if 0 <= ni < m and 0 <= nj < n:
            nd = d + grid[ni][nj]
            if nd < dist[ni][nj]:
                dist[ni][nj] = nd
                heapq.heappush(pq, (nd, ni, nj))
return False
```

## 复杂度
时间 O(m·n·log(m·n))，堆里最多 m·n 个状态，每次 log。
空间 O(m·n)，`dist` 表加堆，堆规模同格子数。

## 易错点
- 起点 `grid[0][0]=1` 时忘记扣血：示例 3 起点就是 1，若 `dist[0][0]` 初始化为 0，会少算 1，把 `health=5` 的可行路径误判。正确做法是 `dist[0][0] = grid[0][0]`。
- 用普通 BFS 按步数分层：示例 2 中绕路更远但扣血更少，BFS 先到终点不代表扣血最小，会误返回 `False`。必须用堆按扣血排序。

## 如果面试官追问
若要求输出具体路径而非布尔值？答：在 `dist` 更新时额外存 `parent[ni][nj] = (i, j)`，到终点后从 `(m-1,n-1)` 回溯即可。
