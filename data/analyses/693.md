## 一句话思路
把 `n` 与 `n >> 1` 异或，交替位会变成全 1，再用 `x & (x + 1) == 0` 判定。

## 怎么做
1. 令 `x = n ^ (n >> 1)`，这一步把「相邻位是否相同」压成「每一位是否为 1」。
2. 若 `n` 的二进制严格交替，则 `x` 的二进制必为连续的若干个 1。
3. 用 `x & (x + 1) == 0` 判断 `x` 是否全 1：全 1 的数加一后进位，与自身按位与必为 0。
4. 返回该布尔值。

以 `n = 5`（`101`）为例：`n >> 1 = 2`（`010`），`x = 5 ^ 2 = 7`（`111`）。`x + 1 = 8`，`7 & 8 = 0`，返回 `True`。

再看 `n = 11`（`1011`）：`n >> 1 = 5`（`0101`），`x = 11 ^ 5 = 14`（`1110`）。`x + 1 = 15`，`14 & 15 = 14 ≠ 0`，返回 `False`。注意 `x` 里出现了 0，说明原数第 2、3 位（从低位数）都是 1，不交替。

```python
x = n ^ (n >> 1)
return x & (x + 1) == 0
```

关键点：`n >> 1` 让第 `i` 位与第 `i+1` 位对齐，异或结果第 `i` 位为 1 当且仅当这两位不同。最高位与 0 异或后仍为 1，所以 `x` 的最高位一定是 1，全 1 判定不会误判前导零。

## 复杂度
时间：O(1)，`n` 最多 31 位，移位、异或、与都是常数次机器字操作。
空间：O(1)，只开了 `x` 一个临时整数，没有额外数组。

## 易错点
- 输入 `n = 1`（二进制 `1`）→ 若先写循环从最低两位开始比较，可能因只有一位而越界或返回 `False` → 正确做法是走异或公式，`x = 1 ^ 0 = 1`，`1 & 2 == 0` 返回 `True`。
- 输入 `n = 2**31 - 1`（31 个 1）→ 若用 `x & (x + 1)` 前先把 `x` 当有符号数处理，可能误判符号位 → Python 整数无溢出，直接算即可；题目保证 `n` 在 `1` 到 `2**31 - 1` 之间，`x` 最大 31 位全 1，`x + 1` 是 `2**31`，按位与仍为 0，结果正确。

## 如果面试官追问
问：如果要求返回最长的交替前缀长度怎么办？
答：从高位往低位扫，遇到第一对相同相邻位就停，返回已扫位数。
