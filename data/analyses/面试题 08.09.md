## 一句话思路
用回溯按位填 `(` 或 `)`，靠 `open < n` 和 `close < open` 两个约束剪枝，保证每个前缀合法且不重复。

## 怎么做
1. 维护 `path`（当前串）、`open`（已用左括号数）、`close`（已用右括号数），长度到 `2*n` 就收进结果。
2. 左括号只要 `open < n` 就能加，右括号只有 `close < open` 才能加。
3. 每次递归后 `path.pop()` 回退，两个计数靠传参自然恢复。

以 `n = 3` 为例，走到 `path = "(()"`、`open = 2`、`close = 1` 时：还能加 `(`（`2 < 3`），也能加 `)`（`1 < 2`），两条分支都展开；而 `path = "())"` 这种状态根本到不了，因为加第二个 `)` 时 `close = 2` 不满足 `close < open = 1`。

```python
def dfs(path, open, close):
    if len(path) == 2 * n:
        res.append("".join(path))
        return
    if open < n:
        path.append("(")
        dfs(path, open + 1, close)
        path.pop()
    if close < open:
        path.append(")")
        dfs(path, open, close + 1)
        path.pop()
```

关键点：`close < open` 而不是 `close < n`，前者保证任意前缀里右括号不超左括号，后者会生成 `")("` 这类非法串。

## 复杂度
时间：第 n 个卡特兰数 `C_n` 个答案，每个串长 `2n`，故 `O(n * C_n)`。
空间：递归栈深 `2n`，加 `path` 的 `2n`，不计结果集为 `O(n)`。

## 易错点
- 把右括号条件写成 `close < n` → `n = 2` 会输出 `")()("`、`")(()"` 等非法串 → 必须写 `close < open`，用左括号数当上界。
- 用 `set` 去重代替剪枝 → `n = 3` 会先枚举全部 `C(6,3) = 20` 个串再筛掉 15 个 → 直接靠两个 if 只走 5 条合法路径，别做无效枚举。

## 如果面试官追问
问：不用回溯，改成按 `n-1` 的结果拼 `n` 行不行？
答：可以，但要去重且不好写；DP 拼接的重复项比回溯剪枝更难控，面试优先写回溯。
