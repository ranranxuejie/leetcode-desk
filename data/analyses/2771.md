## 一句话思路
对每个下标维护「以 nums1[i] 结尾」和「以 nums2[i] 结尾」的最长非递减长度，逐位递推取最大。

## 怎么做
1. 定义 `a` = 以 `nums1[i]` 结尾的最长长度，`b` = 以 `nums2[i]` 结尾的最长长度，初始 `a = b = 1`。
2. 对每个 `i ≥ 1`，分别看 `nums1[i]` 能接在上一轮的 `nums1[i-1]`、`nums2[i-1]` 后面哪个更长，取最大再加 1；`nums2[i]` 同理。
3. 每轮更新答案 `ans = max(ans, a, b)`。
4. 用示例 2 走一步：`i=1` 时 `nums1[1]=3`，`nums1[0]=1 ≤ 3` 且 `nums2[0]=2 ≤ 3`，故 `a = max(1,1)+1 = 2`；`nums2[1]=2`，只有 `nums1[0]=1 ≤ 2`，`b = 2`。到 `i=3` 时 `nums2[3]=4` 能接住 `nums2[2]=3`，`b` 涨到 4。

```python
a = b = 1
ans = 1
for i in range(1, len(nums1)):
    na = 1 + max(a if nums1[i-1] <= nums1[i] else 0,
                 b if nums2[i-1] <= nums1[i] else 0)
    nb = 1 + max(a if nums1[i-1] <= nums2[i] else 0,
                 b if nums2[i-1] <= nums2[i] else 0)
    a, b = na, nb
    ans = max(ans, a, b)
return ans
```

## 复杂度
时间：O(n)，每个下标做常数次比较。
空间：O(1)，只存 `a`、`b`、`ans` 三个变量。

## 易错点
1. 输入 `nums1=[2,3,1], nums2=[1,2,1]` 时，若只用一个 `dp` 值记录「上一轮最优结尾」，会在 `i=1` 选 `nums1[1]=3`（长度 2），到 `i=2` 时 `3 > 1` 断掉，误得 2 但路径错；正确做法是同时保留 `a`、`b` 两条链，`i=2` 时从 `b=2`（结尾 2）出发也接不上 1，答案仍是 2，但换别的输入单链会低估。
2. 输入 `nums1=[1,1], nums2=[2,2]` 时，若把 `nums1[i-1] <= nums1[i]` 写成 `<`，`a` 停在 1，答案错成 1；非递减允许相等，必须用 `<=`。

## 如果面试官追问
要求输出具体构造方案怎么办？答：递推时额外存 `pre[i][0/1]` 记录从上一轮哪个数组转移来，最后从 `ans` 所在位置回溯即可。
