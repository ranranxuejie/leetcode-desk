## 一句话思路
用正则匹配 `conditions` 中「以空格或字符串开头、紧跟 DIAB1」的疾病码，因为 DIAB1 必须出现在词首而非词中。

## 怎么做
1. 关键约束：DIAB1 只能出现在空格后或字符串开头，不能出现在词中间。
2. 用正则 `(^| )DIAB1` 匹配，`^` 处理开头，` ` 处理后续疾病码。
3. 对官方示例逐行验证：Bob 的 `DIAB100 MYOP` 中 DIAB1 在开头，`^` 命中；George 的 `ACNE DIAB100` 中 DIAB1 前有空格，` ` 命中；Alain 的 `DIAB201` 虽以 DIAB 开头但后面是 2 不是 1，不匹配。
4. 空字符串 `conditions` 不匹配任何模式，自动排除。

```python
import re

def find_patients(patients):
    pattern = re.compile(r'(^| )DIAB1')
    return [
        (pid, name, cond)
        for pid, name, cond in patients
        if pattern.search(cond)
    ]
```

对示例 1 的中间值：`pattern.search("DIAB100 MYOP")` 返回匹配对象（位置 0），`pattern.search("ACNE DIAB100")` 返回匹配对象（位置 5），`pattern.search("DIAB201")` 返回 `None`，`pattern.search("")` 返回 `None`。

## 复杂度
时间：O(n·m)，n 为行数，m 为 conditions 平均长度，正则扫描每行。
空间：O(k)，k 为结果行数，额外只开了正则对象。

## 易错点
- 用 `LIKE '%DIAB1%'` → 会把 `XDIAB100` 这种词中出现的也匹配进来 → 必须用 `(^| )DIAB1` 锚定词首。
- 用 `LIKE 'DIAB1%'` → 只匹配开头，漏掉 George 的 `ACNE DIAB100` → 要同时覆盖开头和空格后两种情况。

## 如果面试官追问
问：conditions 字段很大且要频繁查询怎么办？
答：建全文索引或在写入时预计算布尔标记列，查询时直接过滤标记列。
