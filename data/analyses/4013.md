## 一句话思路
把每个数映射成 `+1`（奇数）/`-1`（偶数），用前缀和 + 树状数组统计满足 `2*(S_j-S_i) <= (a-b)*(j-i)` 的下标对。

## 怎么做
1. 令 `w[i] = 1 if nums[i]%2 else -1`，前缀和 `S[0]=0, S[k]=S[k-1]+w[k-1]`。
2. 子数组 `(i,j]` 中 `y-x = S[j]-S[i]`，`y+x = j-i`，条件 `x/y <= a/b` 且 `y>0` 等价于 `b*(y-x) <= (a-b)*(y+x)`，即 `b*(S[j]-S[i]) <= (a-b)*(j-i)`。
3. 移项成 `b*S[j] - (a-b)*j <= b*S[i] - (a-b)*i`，记 `T[k] = b*S[k] - (a-b)*k`，问题变成数下标对 `i<j` 且 `T[i] >= T[j]`，同时要保证 `y>0`（即 `S[j]>S[i]`）。
4. 用树状数组按 `T` 值离散化后从右往左扫，对每个 `j` 查询已插入的 `i>j` 中 `T[i] >= T[j]` 且 `S[i] < S[j]` 的个数——但 `S` 是二维条件，需按 `S` 分层或改用 CDQ 分治。

示例 `nums=[1,2,1,2], a=3, b=2`：`w=[1,-1,1,-1]`，`S=[0,1,0,1,0]`，`T[k]=2*S[k]-1*k=[0,1,-2,-1,-4]`。对 `j=4`（`T=-4`），需数 `i<4` 且 `T[i]>=-4` 且 `S[i]<S[4]=0`，即 `S[i]=-1` 不存在，故无贡献；实际有效对是 `(0,1),(0,2),(0,3),(0,4),(1,3),(2,3),(2,4)` 共 7 对。

```python
# 离散化 T 后，按 S 分桶 + 树状数组
vals = sorted(set(T))
bit = [0]*(len(vals)+1)
def add(x): 
    while x <= len(vals): bit[x] += 1; x += x & -x
def qry(x):
    s = 0
    while x: s += bit[x]; x -= x & -x
    return s
# 从右往左扫，按 S 值分组插入，查询 T[i] >= T[j]
```

## 复杂度
时间 `O(n log n)`：排序离散化 + 每个下标一次树状数组查询/更新。
空间 `O(n)`：`S`、`T`、离散化数组、树状数组各开 `n` 级。

## 易错点
- `nums=[2,2,2], a=1, b=1`：若只判 `T[i]>=T[j]` 会漏掉 `y>0` 约束，把全偶数子数组算进去得 6；正确做法是查询时额外要求 `S[i] < S[j]`，答案应为 0。
- `a < b` 时 `(a-b)` 为负，移项方向不变但 `T` 值可能很大（`b*S` 到 `1e5*1e9`），Python 无溢出但离散化必须用 `set(T)` 而非假设范围；若用 C++ 需 `long long`，Python 直接算即可。

## 如果面试官追问
若 `n` 到 `1e6` 且内存受限？答：改用归并排序统计逆序对变体，把 `S` 作为第二关键字，空间降到 `O(n)` 且常数更小。
