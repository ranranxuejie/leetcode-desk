## 一句话思路
从左往右扫，遇到第一个没被照到的位置 `i`，就在 `i+1` 装灯泡，这是覆盖 `i` 的最右选择。

## 怎么做
1. 用差分数组 `diff` 把每个已有灯泡的照亮区间 `[max(0,i-v), min(n-1,i+v)]` 打上标记，前缀和还原出每个位置的初始光照数。
2. 维护 `reach` 表示当前已保证可见的最右位置（初值 -1），从左到右找第一个 `i > reach` 且光照数为 0 的位置。
3. 在 `i+1` 装灯泡，答案 +1，它覆盖 `[i, i+2]`，于是 `reach = i+2`；若 `i+1` 越界则 `reach = n-1`。
4. 继续扫描，直到 `i` 走完。

以 `lights = [0,0,0,2,0]` 为例：`diff` 还原后光照数为 `[0,0,1,1,1]`。`i=0` 光照 0，装灯于位置 1，`reach=2`；`i=1` 光照 0 但 `1<=reach` 跳过；`i=2..4` 光照均 ≥1，答案 1。

```python
n = len(lights)
diff = [0] * (n + 1)
for i, v in enumerate(lights):
    if v > 0:
        diff[max(0, i - v)] += 1
        diff[min(n - 1, i + v) + 1] -= 1
cur = 0
lit = []
for i in range(n):
    cur += diff[i]
    lit.append(cur)
ans, reach = 0, -1
for i in range(n):
    if i > reach and lit[i] == 0:
        ans += 1
        reach = min(n - 1, i + 2)
```

## 复杂度
时间：O(n)，建差分、还原、贪心扫描各一遍，都是线性。
空间：O(n)，`diff` 和 `lit` 两个长度 n 的数组。

## 易错点
- `lights = [0,0,0,0]`：若在位置 0 装灯只覆盖 `[0,1]`，会多花一个灯泡得 3；正确是在位置 1 装，覆盖 `[0,1,2]`，再在位置 3 装，共 2。
- `lights = [0,0,0,2,0]`：若把已有灯泡的区间右端写成 `i+v` 而不截断到 `n-1`，`diff` 下标 5 越界；正确是 `min(n-1, i+v)+1` 处减一。

## 如果面试官追问
问：要求输出具体安装位置怎么办？
答：贪心时把 `i+1` 记进列表即可，答案不变。
