## 一句话思路
用滚动哈希枚举每个起点和半长，把 `text[i:i+k]` 与 `text[i+k:i+2k]` 的哈希放进集合去重。

## 怎么做
1. 预处理前缀哈希 `h` 和幂 `p`，使任意子串哈希 O(1) 取得。
2. 外层枚举起点 `i`，内层枚举半长 `k`，要求 `i + 2*k <= n`。
3. 比较 `text[i:i+k]` 与 `text[i+k:i+2*k]` 的哈希，相等就把 `(i, k)` 对应的整段哈希塞进 `seen`。
4. 返回 `len(seen)`。

以 `text = "abcabcabc"` 为例：`i=0, k=3` 时两半都是 `"abc"`，哈希相等，`seen` 加入 `"abcabc"`；`i=1, k=3` 得 `"bcabca"`；`i=2, k=3` 得 `"cabcab"`。`k=1` 时 `i=0` 比 `"a"` 与 `"b"` 不等，全部落空，最终 `len(seen) == 3`。

```python
n = len(text)
h = [0] * (n + 1)
p = [1] * (n + 1)
for i, c in enumerate(text):
    h[i + 1] = h[i] * 131 + ord(c)
    p[i + 1] = p[i] * 131

def get(l, r):
    return h[r] - h[l] * p[r - l]

seen = set()
for i in range(n):
    for k in range(1, (n - i) // 2 + 1):
        if get(i, i + k) == get(i + k, i + 2 * k):
            seen.add(get(i, i + 2 * k))
```

## 复杂度
时间 O(n²)：枚举 `(i, k)` 共约 n²/4 对，每对 O(1) 哈希。
空间 O(n²)：`seen` 最多存 O(n²) 个不同哈希，`h`、`p` 各 O(n)。

## 易错点
- 用单模哈希（如只对 `2**61-1` 取模）时，`"leetcodeleetcode"` 这类长串在 n=2000 下碰撞概率虽低但非零，会被构造数据卡掉；正确做法是双哈希或改用后缀数组/字典树做精确比较。
- 内层 `k` 的上界写成 `n - i` 而非 `(n - i) // 2`，会让 `i + 2*k` 越界访问 `h`，`"abcabcabc"` 在 `i=8, k=1` 时直接抛 IndexError；正确做法是 `range(1, (n - i) // 2 + 1)`。

## 如果面试官追问
若 n 放大到 10⁵ 怎么办？答：改用后缀数组 + LCP，对每个 `i` 用 LCP 判定 `text[i:i+k] == text[i+k:i+2k]`，整体 O(n log n)。
