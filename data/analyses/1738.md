## 一句话思路
二维前缀异或 `pre[i][j] = pre[i-1][j] ^ pre[i][j-1] ^ pre[i-1][j-1] ^ matrix[i][j]`，把全部 `pre` 值收集后取第 k 大。

## 怎么做
1. 开 `(m+1) x (n+1)` 的 `pre`，多出的一行一列全 0，省掉边界判断。
2. 按行扫描，用上面那条容斥式算出每个 `pre[i][j]`，同时把值塞进列表 `vals`。
3. 对 `vals` 排序后取 `vals[-k]`（或 `heapq.nlargest(k, vals)[-1]`）。

以 `matrix = [[5,2],[1,6]]` 为例：`pre[1][1] = 0^0^0^5 = 5`，`pre[1][2] = pre[0][2]^pre[1][1]^pre[0][1]^2 = 0^5^0^2 = 7`，`pre[2][1] = 0^5^0^1 = 4`，`pre[2][2] = pre[1][2]^pre[2][1]^pre[1][1]^6 = 7^4^5^6 = 0`，得 `vals = [5,7,4,0]`，排序后 `[-1]=7`、`[-2]=5`、`[-3]=4`、`[-4]=0`，与四个示例一一对上。

```python
m, n = len(matrix), len(matrix[0])
pre = [[0] * (n + 1) for _ in range(m + 1)]
vals = []
for i in range(1, m + 1):
    for j in range(1, n + 1):
        pre[i][j] = pre[i-1][j] ^ pre[i][j-1] ^ pre[i-1][j-1] ^ matrix[i-1][j-1]
        vals.append(pre[i][j])
vals.sort()
return vals[-k]
```

注意 `pre[i][j]` 里 `i`、`j` 是 1 基，取原矩阵元素要写 `matrix[i-1][j-1]`，这是最容易写错下标的一行。

## 复杂度
时间：O(m·n log(m·n))，排序贡献 log，前缀和本身 O(m·n)。
空间：O(m·n)，`pre` 表和 `vals` 各占一份，可只留一行滚动但没必要。

## 易错点
- 把容斥式写成 `pre[i-1][j] ^ pre[i][j-1] ^ matrix[i-1][j-1]` 漏掉 `pre[i-1][j-1]`：对 `[[5,2],[1,6]]` 算 `pre[2][2]` 会得 `7^4^6 = 5` 而不是 0，第 4 大直接错。异或里被重复覆盖的左上块要再异或一次消掉。
- 用 `heapq.nlargest(k, vals)` 后误取 `[0]`：`k=2` 时 `nlargest` 返回 `[7,5]`，`[0]` 是 7 而非 5。要么取 `[-1]`，要么直接 `sorted(vals)[-k]`。

## 如果面试官追问
问：m、n 到 1000 但 k 很小，能省掉全排序吗？
答：用大小为 k 的小顶堆扫一遍 `vals`，堆顶即答案，时间降到 O(m·n log k)。
