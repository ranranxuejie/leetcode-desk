## 一句话思路
排序后把数组劈成两半，用双指针让左半最小去配右半最小，能配就配，贪心成立因为小值当 i 最省。

## 怎么做
1. 排序 `nums`，取 `m = len(nums) // 2`，左半 `nums[:m]` 当候选 i，右半 `nums[m:]` 当候选 j。
2. 双指针 `i = 0`、`j = m`，`j` 扫右半，`i` 只在配对成功时前进。
3. 若 `2 * nums[i] <= nums[j]` 则 `i += 1`，答案加 2；无论成败 `j += 1`。
4. 返回 `i * 2`。

以 `nums = [3,5,2,4]` 为例：排序得 `[2,3,4,5]`，`m = 2`，左半 `[2,3]`，右半 `[4,5]`。`i=0,j=2`：`2*2=4 <= 4` 成立，`i` 变 1；`j=3`：`2*3=6 <= 5` 不成立，`j` 越界结束，答案 `1*2 = 2`。注意 `nums[1]=3` 配不上 `5`，但 `2` 配 `4` 已经吃掉一对，这正是「左半最小优先」的体现。

```python
nums.sort()
m = len(nums) // 2
i = 0
for j in range(m, len(nums)):
    if 2 * nums[i] <= nums[j]:
        i += 1
return i * 2
```

关键点：`i` 最多走到 `m-1`，因为左半只有 `m` 个元素；`j` 从 `m` 起保证 i、j 不重叠，天然满足「互不相同」。

## 复杂度
时间 O(n log n)：排序主导，双指针扫一遍 O(n)。
空间 O(1)：除排序自身开销外只用了 `i`、`j`、`m` 三个变量。

## 易错点
- 输入 `[9,2,5,4]` 若只拿 `nums[0]` 当 i 去配，会漏掉 `2*2<=9` 这种小值配大值 → 错成 2 而非 4 → 必须排序后从最小端开始贪心。
- 输入 `[1,2,3,4,5,6]` 若让 `i` 和 `j` 都从 0 起、不设 `j >= m` 的下界 → 会把同一个下标配两次或左右交叉 → 正确做法是 `j` 严格从 `m` 开始，保证右半元素都大于等于左半。

## 如果面试官追问
问：要求输出具体配对方案怎么办？
答：双指针里把每次成功的 `(i, j)` 存进列表即可，贪心顺序不变，答案对数仍是 `i` 的最终值。
