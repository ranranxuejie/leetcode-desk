## 一句话思路
两人速度相同，比较各自到 z 的距离 `abs(x-z)` 与 `abs(y-z)` 即可，距离小者先到。

## 怎么做
1. 算第 1 个人到 z 的步数 `d1 = abs(x - z)`。
2. 算第 2 个人到 z 的步数 `d2 = abs(y - z)`。
3. 比较 `d1` 与 `d2`：小者返回对应编号，相等返回 0。

拿示例 1 走一遍：`x=2, y=7, z=4`，则 `d1 = abs(2-4) = 2`，`d2 = abs(7-4) = 3`。`d1 < d2`，返回 1。关键中间值就是这两个距离，别去算「谁先动、动了几轮」，速度相同意味着步数就是距离。

```python
d1 = abs(x - z)
d2 = abs(y - z)
if d1 < d2:
    return 1
if d2 < d1:
    return 2
return 0
```

注意 `abs` 不能省：示例 3 里 `x=1, z=3`，若写成 `x - z` 得 `-2`，`y - z` 得 `2`，直接比大小会误判成第 2 个人更近（`-2 < 2`），实际两人都是 2 步。

## 复杂度
时间：O(1)，只做两次减法、两次取绝对值、两次比较，与输入规模无关。
空间：O(1)，只用了 `d1`、`d2` 两个整型变量。

## 易错点
- 输入 `x=1, y=5, z=3` → 若漏写 `abs`，`d1=-2`、`d2=2`，`d1 < d2` 成立会错返 1，正确应返 0 → 两边都必须取绝对值再比。
- 输入 `x=2, y=5, z=6` → 若把「距离」写成「位置大小」直接比 `x < y` 就返 1，实际 `d1=4 > d2=1` 应返 2 → 比较对象必须是到 z 的距离，不是 x、y 本身的大小。

## 如果面试官追问
问：如果第 1、2 个人速度不同（分别为 v1、v2），怎么改？
答：改比 `abs(x-z)/v1` 与 `abs(y-z)/v2`，用交叉相乘 `abs(x-z)*v2` 对比 `abs(y-z)*v1` 避免浮点误差。
