## 一句话思路
排序后首尾配对，和必须恒等于 `skill[0]+skill[-1]`，用哈希表计数可免排序验证并直接算乘积。

## 怎么做
1. 先算目标和 `target = skill[0] + skill[-1]`（排序后），或更稳妥地取 `target = 2 * sum(skill) // n`，因为每对和相等则总和必为 `target * n/2`。
2. 用 `Counter` 统计每个技能值出现次数，遍历 `skill` 中每个 `x`，找 `y = target - x`。
3. 若 `y` 不在计数中或 `x == y` 时计数不足 2，返回 `-1`；否则配对并扣减计数。
4. 每成功配一对就累加 `x * y`，遍历完返回总和。

以 `skill = [3,2,5,1,3,4]` 为例：`sum = 18`，`n = 6`，`target = 2*18//6 = 6`。遍历到 `x=3` 时 `y=3`，计数 `cnt[3]=2` 够用，扣成 0，累加 `3*3=9`；`x=2` 时 `y=4`，累加 `8`；`x=1` 时 `y=5`，累加 `5`，总计 `22`。

```python
from collections import Counter
cnt = Counter(skill)
target = 2 * sum(skill) // len(skill)
ans = 0
for x in skill:
    y = target - x
    if cnt[x] == 0 or cnt[y] == 0:
        return -1
    if x == y and cnt[x] < 2:
        return -1
    ans += x * y
    cnt[x] -= 1
    cnt[y] -= 1
return ans
```

注意 `target` 必须是整数：若 `2*sum(skill) % n != 0` 直接返回 `-1`，否则整除会悄悄截断。

## 复杂度
时间 O(n)：一次计数加一次遍历，`Counter` 哈希操作均摊 O(1)。
空间 O(n)：`Counter` 最多存 n 个不同技能值。

## 易错点
- `skill = [1,1,2,3]`：`sum=7`，`2*7//4=3` 但 `2*7%4=2≠0`，若直接整除得 `target=3`，会把 `1+2` 配成一对、`1+3` 配成一对，误判可行；正确做法是先检查 `2*sum(skill) % n == 0`，不整除立即返回 `-1`。
- `skill = [1,2,3,4]`：`target=5`，遍历到 `x=1` 配 `y=4` 成功，但若先处理 `x=2` 配 `y=3` 也成功，看似没问题；真正的坑是 `x==y` 时（如 `[3,3]`）若只判断 `cnt[y]>0` 而不检查 `cnt[x]>=2`，会把同一个 3 用两次，累加出 `9` 而非 `-1`；正确做法是 `x==y` 时要求 `cnt[x]>=2`。

## 如果面试官追问
若要求输出具体分组方案而非只求和？答：在配对成功时把 `(x, y)` 追加到结果列表，遍历完返回列表即可，逻辑不变。
