## 一句话思路
按名字分组，组内两两比较时间差和城市，同时单独判金额超 1000。

## 怎么做
1. 把每笔交易拆成 `(name, time, amount, city)`，用字典 `groups[name]` 收集下标。
2. 遍历每个名字的列表，两两配对 `(i, j)`，若 `abs(t1 - t2) <= 60` 且 `city1 != city2`，把 `i`、`j` 都标记为无效。
3. 单独扫一遍金额，`amount > 1000` 的直接标记。
4. 按原顺序收集被标记的原始字符串。

以示例 1 为例：`groups["alice"] = [0, 1]`，配对后 `t` 差为 `|20-50| = 30 <= 60`，城市 `mtv != beijing`，于是 `bad = {0, 1}`，两笔都输出。

```python
groups = {}
for i, s in enumerate(transactions):
    name, t, amt, city = s.split(',')
    groups.setdefault(name, []).append((i, int(t), int(amt), city))

bad = set()
for lst in groups.values():
    for a in range(len(lst)):
        for b in range(a + 1, len(lst)):
            i, t1, _, c1 = lst[a]
            j, t2, _, c2 = lst[b]
            if abs(t1 - t2) <= 60 and c1 != c2:
                bad.update((i, j))
for i, s in enumerate(transactions):
    if int(s.split(',')[2]) > 1000:
        bad.add(i)
return [transactions[i] for i in sorted(bad)]
```

## 复杂度
时间：O(n²) 最坏，全部同名时配对次数是 n(n-1)/2；拆串是 O(n)。
空间：O(n)，`groups` 存全部下标，`bad` 最多 n 个。

## 易错点
- 输入 `["alice,20,800,mtv","alice,50,100,mtv"]` → 只判时间差会误标两笔无效 → 必须加 `c1 != c2`，同城不构成无效。
- 输入 `["alice,20,800,mtv","alice,80,100,mtv","alice,140,100,beijing"]` → 只看相邻会漏掉 20 与 140 差 120 不成立、但 80 与 140 差 60 成立 → 必须两两全配对，不能只比相邻。

## 如果面试官追问
若交易数涨到 10⁵ 怎么办？答：按名字分组后组内按时间排序，用双指针滑窗只比较时间差 ≤60 的相邻段，复杂度降到 O(n log n)。
