## 一句话思路
二分答案长度 L，用滚动哈希把每个长度 L 的子串压成整数查重，找到重复就加长、否则缩短。

## 怎么做
1. 二分子串长度 `L ∈ [1, n-1]`，对每个 L 判断是否存在重复子串。
2. 用前缀哈希 + 幂表，O(1) 取出任意 `s[i:i+L]` 的哈希值，塞进 `set`，撞到重复即返回起点 `i`。
3. 记录当前最优长度与起点，二分结束后切片返回。

以 `s = "banana"` 为例：二分到 `L = 3` 时，`i=1` 与 `i=3` 的哈希都对应 `"ana"`，`seen` 里第二次出现即命中，`best_start = 1`；再试 `L = 4` 无重复，最终返回 `s[1:4]`。

```python
n, base, mod = len(s), 131, 2**61 - 1
h = [0] * (n + 1); p = [1] * (n + 1)
for i, c in enumerate(s):
    h[i+1] = (h[i] * base + ord(c)) % mod
    p[i+1] = p[i] * base % mod

def find(L):
    seen = {}
    for i in range(n - L + 1):
        cur = (h[i+L] - h[i] * p[L]) % mod
        if cur in seen:
            return i
        seen[cur] = i
    return -1
```

二分主体：`lo, hi, best = 1, n-1, -1`，`while lo <= hi:` 取 `mid`，`find(mid) != -1` 则 `best = find(mid); lo = mid + 1`，否则 `hi = mid - 1`；最后 `return s[best:best+hi+1] if best != -1 else ""`（注意用命中的那个长度，别用 mid）。

## 复杂度
时间 O(n log n)：二分 log n 层，每层 O(n) 扫一遍算哈希。
空间 O(n)：前缀哈希 `h`、幂表 `p`、每层 `seen` 字典各 O(n)。

## 易错点
- `s = "aaaa"` 这类全同字符 → 若二分里 `find(mid)` 调两次、第二次结果被覆盖，或返回长度用错 `mid` 而非命中长度，会切出错误子串 → 把 `find(mid)` 结果存进变量再用。
- 单模哈希在 `n = 3*10^4` 下可能被构造碰撞（如 `"aa...a"` 与特定串）→ 用 `2**61 - 1` 大模数，或双哈希 `(mod1, mod2)` 元组入 `set`，别用 `2**31` 小模数。

## 如果面试官追问
问：不用哈希怎么做？
答：后缀数组排序后取相邻 LCP 最大值，O(n log n) 且无碰撞风险，但实现重得多。
