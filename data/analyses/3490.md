## 一句话思路
数位 DP 同时记录「数位和」与「数位积」，枚举所有可能的和 s，只统计积能被 s 整除的路径。

## 怎么做
1. 上界 `r < 10^9`，最多 9 位，数位和最大 `9*9=81`，数位积最大 `9^9`，但含 0 时积为 0，0 能被任何正数和整除，所以 0 单独算作合法。
2. 对每个目标和 `s ∈ [1,81]` 跑一次记忆化搜索，状态 `(pos, sum, prod, tight)`，其中 `prod` 只保留 `min(prod, s)` 的截断值——因为只需判断 `prod % s == 0`，超过 s 的积不可能再变回 s 的倍数，截断到 s 后若 `prod == s` 就等价于「已达标」。
3. 用 `count(r) - count(l-1)` 得区间答案。

以 `l=10, r=20` 为例：`count(20)` 中，数字 10 的数位和 `s=1`、积 `0`，`0 % 1 == 0` 成立；数字 20 同理 `s=2`、积 `0`，成立；而 11 的 `s=2`、积 `1`，`1 % 2 != 0` 被排除。最终 `count(20)-count(9)=2`。

```python
from functools import lru_cache

def count(n, s):
    if n <= 0: return 0
    d = list(map(int, str(n)))
    @lru_cache(None)
    def dfs(pos, sm, pr, tight):
        if pos == len(d):
            return 1 if sm == s and pr % s == 0 else 0
        hi = d[pos] if tight else 9
        res = 0
        for x in range(hi + 1):
            res += dfs(pos+1, sm+x, min(pr*x, s), tight and x == hi)
        return res
    return dfs(0, 0, 1, True)
```

注意 `pr` 初值取 1（空积），遇到 0 时 `min(0, s)=0`，后续保持 0，最终 `0 % s == 0` 恒成立。

## 复杂度
时间：`O(81 * 位数 * 82 * 82 * 10)`，位数贡献 log n，81 来自枚举目标和。
空间：记忆化表 `O(位数 * 82 * 82)`，每轮清空。

## 易错点
- 输入含 0 的数字（如 10、20）→ 若把积初值设为 0 或跳过 0 位，会把 10 判成非美丽 → 积初值必须为 1，遇 0 后 `min(0,s)=0`，`0 % s == 0` 自动成立。
- 积不截断直接算 `9^9` 会爆状态数 → 必须 `min(pr*x, s)` 截断，否则记忆化表规模爆炸且 `pr` 永远到不了 `s` 的倍数判断。

## 如果面试官追问
问：若 r 放大到 `10^18` 怎么办？
答：位数变 18、数位和上限 162，仍按和枚举，状态数约 `162*163*163`，可接受，只是常数翻倍。
