## 一句话思路
从左往右找第一个不是 `'a'` 的字符，从它开始连续把字符减一，遇到 `'a'` 就停；若全是 `'a'`，只把最后一个 `'a'` 变成 `'z'`。

## 怎么做
1. 从左扫描，定位第一个 `s[i] != 'a'` 的下标 `i`，它就是操作区间的左端点。
2. 从 `i` 开始逐位减一，直到遇到 `'a'` 或字符串结束，这些位置就是操作区间。
3. 若扫描到末尾都没找到非 `'a'` 字符（全 `'a'`），把最后一个字符改成 `'z'`，因为操作必须恰好执行一次。

以 `s = "cbabc"` 为例：`i = 0`（`'c' != 'a'`），从下标 0 开始减一，`'c'→'b'`、`'b'→'a'`，到下标 2 的 `'a'` 停止，得到 `"baabc"`。中间变量就是区间 `[0, 1]`，下标 2 的 `'a'` 保持不动。

```python
def smallestString(s: str) -> str:
    a = list(s)
    i, n = 0, len(a)
    while i < n and a[i] == 'a':
        i += 1
    if i == n:
        a[-1] = 'z'
        return ''.join(a)
    while i < n and a[i] != 'a':
        a[i] = chr(ord(a[i]) - 1)
        i += 1
    return ''.join(a)
```

关键点：区间右端由「第一个 `'a'`」决定，而不是由「减到 `'a'` 为止」决定——`'b'` 减成 `'a'` 后仍要继续，只有原本就是 `'a'` 的字符才截断区间。

## 复杂度
时间 O(n)：`i` 只前进不回退，每个字符最多被访问两次。
空间 O(n)：`list(s)` 开了长度 n 的字符数组，返回值另算。

## 易错点
- 输入 `s = "aaab"` → 若从下标 0 就开始减，会把 `'a'` 变成 `'z'`，结果 `"zzza"` 比正确解 `"aaaa"` 大得多 → 必须跳过前缀所有 `'a'`，从第一个非 `'a'` 处开始。
- 输入 `s = "a"` 或 `"aaa"` → 若直接返回原串，等于没执行操作，违反「恰好一次」→ 全 `'a'` 时只能改最后一个字符为 `'z'`，`"a"` 的答案是 `"z"`。

## 如果面试官追问
问：如果允许操作零次或多次，答案会变吗？
答：会，零次时全 `'a'` 直接返回原串；多次时每段非 `'a'` 区间都能各减一次，需重新贪心。
