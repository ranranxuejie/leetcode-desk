## 一句话思路
沿主对角线铺一条「阶梯走廊」，其余格子全封死，走廊宽度恰好一格，路径唯一。

## 怎么做
1. 先把整个网格填成 `'#'`，得到 `grid = [['#'] * n for _ in range(m)]`。
2. 沿对角线打开格子：对每个 `k` 从 0 到 `min(m, n) - 1`，把 `(k, k)` 置为 `'.'`。
3. 若 `m > n`，把最后一列 `j = n - 1` 从 `k = n - 1` 到 `m - 1` 全打开；若 `n > m`，把最后一行 `i = m - 1` 从 `k = m - 1` 到 `n - 1` 全打开。
4. 把每行 `''.join` 成字符串返回。

以 `m = 3, n = 3` 为例：初始全 `'#'`，第 2 步打开 `(0,0)(1,1)(2,2)`，此时 `m == n` 无需补尾，得到 `["#.."→ 实为 "..#" 的对角]`，即 `["#..","#..","##."]` 的转置形式——关键是 `(1,1)` 这个中间格子：它左边 `(1,0)` 和上边 `(0,1)` 都是 `'#'`，所以从 `(0,0)` 只能先右到 `(0,1)` 再下到 `(1,1)`，无法从 `(1,0)` 绕进来，路径被卡死成一条。

```python
grid = [['#'] * n for _ in range(m)]
for k in range(min(m, n)):
    grid[k][k] = '.'
if m > n:
    for i in range(n - 1, m):
        grid[i][n - 1] = '.'
elif n > m:
    for j in range(m - 1, n):
        grid[m - 1][j] = '.'
return [''.join(row) for row in grid]
```

## 复杂度
时间：O(m·n)，初始化整张网格占满，补尾最多 O(max(m,n))。
空间：O(m·n)，即返回的字符串列表本身，无额外辅助结构。

## 易错点
- `m = 1, n = 4` → 若只按 `min(m,n)=1` 打开 `(0,0)`，返回 `["#..."]` 之外全是墙，终点 `(0,3)` 不可达 → 必须走 `n > m` 分支把最后一行 `(0,1..3)` 全打开，得到 `["...."]`。
- `m = 2, n = 3` → 若把对角线打开成 `(0,0)(1,1)` 就收手，`(1,2)` 仍是 `'#'`，终点封死 → 补尾分支要覆盖到 `j = n - 1 = 2`，即 `range(m-1, n) = range(1,3)` 打开 `(1,1)(1,2)`，路径 `(0,0)→(0,1)→(1,1)→(1,2)` 才成立。

## 如果面试官追问
问：若要求路径数恰好为 k 条怎么办？
答：把走廊在某处加宽成 2×2 的空块，每加一个这样的块路径数乘 2，按 k 的二进制拆即可。
