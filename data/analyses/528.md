## 一句话思路
把权重数组 `w` 累加成前缀和 `pre`，在 `[0, pre[-1])` 上取随机整数 `t`，二分找第一个 `pre[i] > t` 的下标。

## 怎么做
1. 构造时把 `w` 变成前缀和数组 `pre`，`pre[i] = w[0] + ... + w[i]`，总权重是 `pre[-1]`。
2. 每次 `pickIndex` 取 `t = random.randrange(pre[-1])`，即 `0 <= t < pre[-1]` 的整数。
3. 用 `bisect_right(pre, t)` 得到第一个满足 `pre[i] > t` 的下标，直接返回。

以官方示例 `w = [1, 3]` 为例：`pre = [1, 4]`，总权重 4。若 `t = 0`，`bisect_right([1,4], 0) = 0`，返回下标 0；若 `t = 1`，`bisect_right([1,4], 1) = 1`，返回下标 1。区间 `[0,1)` 长度 1 对应下标 0，`[1,4)` 长度 3 对应下标 1，概率正好 1/4 和 3/4。

```python
import random, bisect

def build(w):
    pre = []
    s = 0
    for x in w:
        s += x
        pre.append(s)
    return pre

def pick(pre):
    t = random.randrange(pre[-1])
    return bisect.bisect_right(pre, t)
```

关键点：`randrange` 上界是开区间，所以 `t` 最大取到 `pre[-1] - 1`，不会越界；`bisect_right` 而非 `bisect_left`，因为要的是第一个严格大于 `t` 的位置。

## 复杂度
时间：构造 O(n)，每次 pick 是 O(log n)，n 为 `w` 长度。
空间：额外 O(n) 存前缀和数组 `pre`。

## 易错点
- 用 `random.randint(0, pre[-1])` → 上界闭区间会取到 `pre[-1]`，此时 `bisect_right` 返回 `len(pre)` 越界 → 必须用 `randrange(pre[-1])` 或 `randint(0, pre[-1]-1)`。
- 用 `bisect_left(pre, t)` → 当 `t` 恰好等于某个 `pre[i]` 时返回 `i`，把本该归给 `i+1` 的边界点算给了 `i`，权重分布偏移 → 用 `bisect_right`，保证 `pre[i] <= t` 的下标被跳过。

## 如果面试官追问
问：`w` 长度到 10^6 且要频繁更新权重怎么办？
答：前缀和 + 二分不支持单点更新，改用 Fenwick 树，`pickIndex` 变成 O(log n) 的树上二分。
