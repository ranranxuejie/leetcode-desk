## 一句话思路
用四条边界 `top/bottom/left/right` 收缩模拟，每走完一条边就内缩一格，直到边界交叉。

## 怎么做
1. 初始化 `top=0, bottom=len(array)-1, left=0, right=len(array[0])-1`，结果列表 `res=[]`。
2. 循环条件 `top<=bottom and left<=right`，依次走：右（`left→right` 取 `array[top]`）、下（`top→bottom` 取 `array[i][right]`）、左（`right→left` 取 `array[bottom]`）、上（`bottom→top` 取 `array[i][left]`）。
3. 每走完一条边立刻收缩对应边界，且**走左和上之前要重新检查** `top<=bottom` / `left<=right`，否则单行/单列会重复。
4. 以示例 1 `[[1,2,3],[8,9,4],[7,6,5]]` 为例：第一轮右取 `1,2,3` 后 `top=1`；下取 `4,5` 后 `right=1`；此时 `top=1<=bottom=2` 成立，左取 `array[2][1..1]` 即 `6`，`bottom=1`；上取 `array[1][0]` 即 `8`，`left=1`。第二轮只剩中心 `9`。

```python
res = []
top, bottom, left, right = 0, len(array) - 1, 0, len(array[0]) - 1
while top <= bottom and left <= right:
    for j in range(left, right + 1): res.append(array[top][j])
    top += 1
    for i in range(top, bottom + 1): res.append(array[i][right])
    right -= 1
    if top <= bottom:
        for j in range(right, left - 1, -1): res.append(array[bottom][j])
        bottom -= 1
    if left <= right:
        for i in range(bottom, top - 1, -1): res.append(array[i][left])
        left += 1
```

## 复杂度
时间 O(m·n)：每个元素恰好被 `res.append` 一次，m、n 为行列数。
空间 O(1) 额外：除输出 `res` 外只用四个边界变量。

## 易错点
- 输入 `[[1,2,3]]`（单行）→ 若不检查 `top<=bottom` 就走「左」和「上」，会把 `3,2,1` 再取一遍 → 走左、上前必须加 `if top<=bottom` / `if left<=right` 守卫。
- 输入 `[[1],[2],[3]]`（单列）→ 同理「下」之后 `right` 已小于 `left`，再走「左」会重复取 `3` → 靠 `while` 条件与守卫拦住，别把守卫写成 `top<bottom`（会漏掉中心单元素）。

## 如果面试官追问
问：若要求逆时针（先向下）怎么办？答：把四条边的顺序换成下、右、上、左，边界收缩顺序同步调整，守卫逻辑不变。
