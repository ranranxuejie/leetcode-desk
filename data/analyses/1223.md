## 一句话思路
用 `dp[i][j][k]` 记第 i 次掷出点数 j、且 j 已连续出现 k 次（k 从 1 起）的序列数，按「换不换点数」转移。

## 怎么做
1. 初始化：`dp[1][j][1] = 1`，j 取 0..5，其余为 0。
2. 转移分两类：第 i 次掷出 j 且 k=1，说明第 i-1 次掷的不是 j，来源是 `sum(dp[i-1][x][*]) - sum(dp[i-1][j][*])`；k≥2 时只能由 `dp[i-1][j][k-1]` 接上。
3. 剪枝：k 只枚举到 `rollMax[j]`，k=1 的转移里减掉的那项就是「上一步也是 j」的全部情况。
4. 答案是 `sum(dp[n][j][k])` 对 `10**9+7` 取模。

拿示例 1 的 `n=2, rollMax=[1,1,2,2,2,3]` 走一遍：第 1 层每个 j 的 `dp[1][j][1]=1`，共 6 条。第 2 层算 j=0（rollMax=1，只能 k=1）：`sum(dp[1][x][*])=6`，减去 `sum(dp[1][0][*])=1`，得 5，即 (2,1)(3,1)(4,1)(5,1)(6,1)。j=1 同理得 5。j=2 的 k=1 得 5，k=2 由 `dp[1][2][1]=1` 接上得 1，共 6。四个 j 各 6，合计 5+5+6+6+6+6=34。

```python
MOD = 10**9 + 7
dp = [[[0] * 16 for _ in range(6)] for _ in range(n + 1)]
for j in range(6):
    dp[1][j][1] = 1
for i in range(2, n + 1):
    for j in range(6):
        total = sum(dp[i-1][x][k] for x in range(6) for k in range(1, 16)) % MOD
        same = sum(dp[i-1][j][k] for k in range(1, 16)) % MOD
        dp[i][j][1] = (total - same) % MOD
        for k in range(2, rollMax[j] + 1):
            dp[i][j][k] = dp[i-1][j][k-1]
return sum(dp[n][j][k] for j in range(6) for k in range(1, 16)) % MOD
```

## 复杂度
时间 O(n · 6 · 15)，n 来自掷骰次数，6 和 15 是点数与 `rollMax` 上限。
空间 O(n · 6 · 15)，可滚动成 O(6 · 15)，只留上一层。

## 易错点
- `rollMax[j]=1` 时若仍写 `for k in range(2, rollMax[j]+1)` 之外还去读 `dp[i-1][j][k-1]`，会把 k=2 的非法状态算进去；正确做法是循环上界严格取 `rollMax[j]`，k=1 单独走减法分支。
- 减法 `total - same` 在 Python 里可能为负，`% MOD` 能修正，但若先存进别处再取模、或漏掉 `% MOD`，示例 2 的 `n=2` 会得到 -6 而不是 30；正确做法是每步转移后立刻 `% MOD`。

## 如果面试官追问
若 n 放大到 10^9 怎么办？答：把 (j,k) 压成 6×15 的状态向量，用矩阵快速幂，O((90)^3 log n)。
