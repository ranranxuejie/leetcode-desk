## 一句话思路
把每栋楼拆成「左端点入堆、右端点出堆」两个事件，按 x 扫描，堆顶（最大高度）变化处就是关键点。

## 怎么做
1. 每个 `[l, r, h]` 生成两个事件：`(l, -h)` 表示进入，`(r, h)` 表示离开；用负号让同一 x 上「先入后出」。
2. 事件按 `(x, h)` 升序排序，`h` 为负（进入）排前面，保证同 x 处先加后删。
3. 维护一个懒删除最大堆：进入就 `heappush(-h)`，离开就记入 `removed` 计数；取堆顶前把 `removed` 里存在的值弹掉。
4. 每次事件后取当前最大高度 `cur`，若与上一个关键点高度不同，就追加 `[x, cur]`。

以示例 1 为例：事件到 `x=7` 时，楼 `[3,7,15]` 离开，堆顶从 15 掉到 12，于是产出 `[7,12]`；到 `x=12` 时 `[5,12,12]` 离开，堆空，产出 `[12,0]`。

```python
import heapq
events = []
for l, r, h in buildings:
    events.append((l, -h))
    events.append((r, h))
events.sort()
heap, removed, res, prev = [], {}, [], 0
for x, h in events:
    if h < 0:
        heapq.heappush(heap, h)
    else:
        removed[-h] = removed.get(-h, 0) + 1
    while heap and removed.get(-heap[0], 0) > 0:
        removed[-heap[0]] -= 1
        heapq.heappop(heap)
    cur = -heap[0] if heap else 0
    if cur != prev:
        res.append([x, cur])
        prev = cur
```

## 复杂度
时间：事件数 2n，排序 O(n log n)，每次堆操作 O(log n)，共 O(n log n)。
空间：堆与 `removed` 各 O(n)，事件表 O(n)，合计 O(n)。

## 易错点
- 输入 `[[0,2,3],[2,5,3]]`：若在 `x=2` 先处理离开再处理进入，堆会短暂为空，多输出 `[2,0]`；正确做法是排序键用 `(x, h)` 且进入记 `-h`，让 `-3 < 3` 使进入排在离开前，直接得到 `[[0,3],[5,0]]`。
- 输入 `[[1,2,1],[1,2,2]]`：若离开时直接从堆里删值而不做懒删除，会把同高度的另一栋楼一起删掉，导致 `x=2` 前高度错误地掉到 0；正确做法是用 `removed` 计数，只在堆顶命中时才弹。

## 如果面试官追问
若 buildings 未按 left 排序怎么办？答：事件表本身已按 `(x, h)` 全排序，与输入顺序无关，无需预处理。
