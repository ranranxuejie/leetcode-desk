## 一句话思路
把 1..N 与 nums 全部异或，结果 `x = a ^ b`，再取 `x` 最低位的 1 把数分成两组分别异或，即得 a、b。

## 怎么做
1. 令 `n = len(nums) + 2`，先算 `x = 1 ^ 2 ^ ... ^ n ^ nums[0] ^ ... ^ nums[-1]`，缺的两个数 `a ^ b` 就留在 `x` 里。
2. 取 `low = x & -x`，这是 `a` 与 `b` 第一个不同的二进制位，`a`、`b` 中恰有一个带这一位。
3. 再扫一遍 1..n 和 nums，按 `v & low` 是否为 0 分两组异或，两组结果就是 `a` 和 `b`。
4. 返回 `[a, b]`，顺序任意。

以 `nums = [2,3]` 为例：`n = 4`，`x = 1^2^3^4^2^3 = 1^4 = 5`（二进制 101），`low = 5 & -5 = 1`。按最低位分组：`1,3,3` 一组异或得 `1`，`2,4,2` 一组异或得 `4`，答案 `[1,4]`。

```python
n = len(nums) + 2
x = 0
for v in range(1, n + 1):
    x ^= v
for v in nums:
    x ^= v
low = x & -x
a = b = 0
for v in range(1, n + 1):
    if v & low:
        a ^= v
    else:
        b ^= v
for v in nums:
    if v & low:
        a ^= v
    else:
        b ^= v
return [a, b]
```

## 复杂度
时间 O(n)：两趟扫描，`n = len(nums) + 2`，每趟常数次异或。
空间 O(1)：只开 `x`、`low`、`a`、`b` 四个整数，没有额外数组。

## 易错点
- `nums = [1]` 时若把 `n` 写成 `len(nums)`，只扫 1..1，`x` 会算成 `1^1 = 0`，`low = 0` 分组全落一边，返回 `[0,0]`；正确是 `n = len(nums) + 2 = 3`，`x = 1^2^3^1 = 2^3 = 1`，`low = 1`，得 `[2,3]`。
- 分组时只扫 `nums` 忘了扫 1..n，`nums = [2,3]` 会得到 `a = 2^3 = 1`、`b = 0`；必须两批数都按 `v & low` 分进同一组异或，才能让成对出现的数互相抵消。

## 如果面试官追问
问：若缺的是 k 个数字怎么办？答：异或法只能拆两组，k > 2 时改用求和/平方和或原地哈希标记，O(n) 时间 O(1) 空间仍可做到。
