## 一句话思路
把每个 `1` 尽量往左挪到更大的 `nums` 上，用最小堆维护「当前可用的空位候选值」，贪心取最大。

## 怎么做
1. 从左往右扫，遇到 `s[i]=='1'` 就把它当作一个「可左移的 1」，压入候选。
2. 关键观察：交换只允许 `0` 与右侧 `1` 互换，等价于每个 `1` 只能往左走，且不能越过别的 `1`。所以从左到右处理时，遇到 `1` 就把它加入堆，遇到 `0` 时堆里所有 1 都能挪到这个位置。
3. 用最小堆存 `nums[i]`，遇到 `0` 时若堆非空，弹出最小值换成当前 `nums[i]`（因为当前位更靠左、值可能更大，用堆保证换掉的是最不划算的那个）。
4. 最终答案 = 初始所有 `1` 位置的 `nums` 之和 + 每次替换的增量。

以 `nums=[2,1,5,2,3], s="01010"` 为例：初始 `1` 在 i=1,3，和 `1+2=3`。扫到 i=0 是 `0`，堆空跳过；i=1 是 `1`，压入 1；i=2 是 `0`，堆顶 1 < 5，替换，增量 `5-1=4`，答案变 7；i=3 是 `1`，压入 2；i=4 是 `0`，堆顶 2 < 3，替换，增量 `3-2=1`，答案变 8？——注意 i=4 的 `1` 原本在 i=3，左移到 i=4 是**右移**，不合法。正确做法是只在 `0` 位置尝试「拉一个左边的 1 过来」，且该 1 必须原本在更左……实际合法方向是 `1` 左移，所以应反向扫描或按「每个 1 能到达的最左空位」处理。

修正：从右往左扫，遇到 `1` 压堆，遇到 `0` 时用堆顶替换（此时堆里的 1 都在右侧，可左移到当前 `0`）。示例中 i=4 是 `0` 堆空；i=3 是 `1` 压 2；i=2 是 `0`，堆顶 2 < 5，替换增量 3，答案 6；i=1 是 `1` 压 1；i=0 是 `0`，堆顶 1 < 2，替换增量 1，答案 7。✓

```python
import heapq
h = []
ans = sum(nums[i] for i in range(n) if s[i] == '1')
for i in range(n - 1, -1, -1):
    if s[i] == '1':
        heapq.heappush(h, nums[i])
    elif h and h[0] < nums[i]:
        ans += nums[i] - heapq.heappop(h)
        heapq.heappush(h, nums[i])
```

## 复杂度
时间 O(n log n)：每个下标至多入堆出堆一次，堆操作 log n。
空间 O(n)：堆最多存 n 个元素。

## 易错点
- 方向搞反：若从左往右扫、遇 `0` 就用堆顶替换，会把右侧的 `1` 往右挪（如示例 i=4 的 `1` 从 3 挪到 4），得到 8 的错误答案。必须从右往左扫，保证堆里的 `1` 都在当前 `0` 右侧、可合法左移。
- 替换后忘记把 `nums[i]` 重新压回堆：该位置变成 `1` 后仍可继续左移，漏压会导致后续更左的 `0` 无法复用这个值，示例中会少算增量。

## 如果面试官追问
问：若要求输出最终字符串 s？答：替换时记录被换下的原下标，最后按堆中保留的 `nums` 对应位置置 `1` 即可。
