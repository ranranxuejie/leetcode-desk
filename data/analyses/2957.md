## 一句话思路
从左往右扫，遇到 `word[i]` 与 `word[i-1]` 近似相等就改 `word[i]`，答案加一，因为改右边那个字符能同时断开与左右两侧的冲突。

## 怎么做
1. 用 `ans` 记操作次数，从下标 1 开始遍历 `word`。
2. 判断 `abs(ord(word[i]) - ord(word[i-1])) <= 1`，成立则 `ans += 1`。
3. 关键：把 `word[i]` 改成一个与 `word[i-1]` 和 `word[i+1]` 都不近似相等的字符，这样一次修改同时解决两处冲突。

以 `word = "aaaaa"` 为例：i=1 时 `'a'` 与 `'a'` 差 0，`ans=1`，把 `word[1]` 改成 `'c'`，此时 `word` 变成 `"acaaa"`；i=2 时 `'a'` 与 `'c'` 差 2，不冲突；i=3 时 `'a'` 与 `'a'` 差 0，`ans=2`，改成 `'c'`；i=4 时 `'a'` 与 `'c'` 差 2，不冲突。最终 `ans=2`。

```python
ans = 0
for i in range(1, len(word)):
    if abs(ord(word[i]) - ord(word[i-1])) <= 1:
        ans += 1
        # 改成与左右都不近似相等的字符，这里用 '#' 占位
        word = word[:i] + '#' + word[i+1:]
return ans
```

注意：实际实现中 `'#'` 不是小写字母，但仅用于断开比较；若要求严格小写字母，可改成 `'z'` 并确保与 `word[i-1]` 和 `word[i+1]` 都不相邻。更稳妥的做法是直接跳过下一个字符：`i += 2`，因为改完 `word[i]` 后 `word[i]` 与 `word[i+1]` 的冲突已被断开，无需再检查 `i+1`。

## 复杂度
时间：O(n)，n 为 `word` 长度，每个字符最多访问一次。
空间：O(1)，只用了 `ans` 和循环变量，未开额外数组。

## 易错点
- 输入 `"aaaaa"` → 若只改 `word[i]` 为任意字符但不检查与 `word[i+1]` 的关系，可能漏掉后续冲突 → 正确做法是改完后跳过下一个字符（`i += 2`），因为 `word[i]` 已与 `word[i+1]` 断开。
- 输入 `"abddez"` → 若只判断相等（`word[i] == word[i-1]`）而忽略相邻字母，会漏掉 `'d'` 与 `'e'` 的冲突 → 必须用 `abs(ord(...) - ord(...)) <= 1` 判断近似相等。

## 如果面试官追问
问：如果要求输出修改后的字符串而非次数？答：在 `ans += 1` 处记录修改位置和替换字符，最后按位置重建字符串即可。
