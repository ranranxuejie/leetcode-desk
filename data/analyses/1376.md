## 一句话思路
自底向上把每个员工到叶子的最长耗时累加，取根节点的值，因为通知是并行传播的。

## 怎么做
1. 建 `children` 邻接表：遍历 `manager`，把 `i` 挂到 `manager[i]` 下，跳过 `manager[headID] == -1`。
2. 从 `headID` 做 DFS，返回 `informTime[u] + max(子树返回值)`，叶子返回 0。
3. 用官方示例 2 走一遍：`children[2] = [0,1,3,4,5]`，五个孩子都是叶子返回 0，所以 `dfs(2) = informTime[2] + max(0) = 1 + 0 = 1`。
4. 答案就是 `dfs(headID)`，示例 2 输出 1。

```python
def dfs(u):
    if not children[u]:
        return 0
    return informTime[u] + max(dfs(v) for v in children[u])

children = [[] for _ in range(n)]
for i, m in enumerate(manager):
    if m != -1:
        children[m].append(i)
return dfs(headID)
```

关键中间值：`dfs(2)` 里 `max(...)` 的五个孩子全是 0，`informTime[2] = 1`，所以返回 1。

## 复杂度
时间 O(n)：每个员工在 `children` 里被访问一次，DFS 每条边走一次。
空间 O(n)：`children` 存 n-1 条边，递归栈最深 O(n)。

## 易错点
- `n = 1, headID = 0, manager = [-1]` → 若忘了 `if not children[u]: return 0`，`max()` 对空序列会抛 `ValueError` → 叶子必须先返回 0。
- 链状树如 `manager = [-1,0,1,2]`、`informTime = [1,1,1,0]` → 若写成「累加所有 `informTime`」会得 3，但正确是沿单链累加 1+1+1=3 恰好对；换成 `manager = [-1,0,0,1]` 这种分叉，累加会得 3，正确是 `dfs(0)=1+max(dfs(1),dfs(2))=1+max(1+0,0)=2` → 必须取 `max` 而非求和。

## 如果面试官追问
若要求输出「最晚收到消息的员工 ID」而非时间？答：DFS 返回 `(时间, 员工ID)`，比较时按时间取大，平局取任意一个即可。
