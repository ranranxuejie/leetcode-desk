## 一句话思路
染色区域是中心加四个方向上的菱形臂，第 k 圈每臂新增 k 格，总数 = 1 + 4·(1+2+…+(n-1))。

## 怎么做
1. 把 n 分钟后的图形看成中心格加上下左右四条「臂」，第 k 分钟每条臂恰好延长 k 格。
2. 于是总格子数 = 1 + 4·(1+2+…+(n-1))，用等差数列求和化简。
3. 代入 n=2：臂长和 = 1，总数 = 1 + 4·1 = 5，与示例一致。
4. 直接返回闭式，避免逐分钟模拟。

```python
def coloredCells(n):
    m = n - 1
    return 1 + 4 * m * (m + 1) // 2
```

n=3 时 m=2，1 + 4·(2·3//2) = 1 + 12 = 13，与图形吻合。

## 复杂度
时间：O(1)，只做常数次乘加，与 n 无关。
空间：O(1)，没有开数组或递归栈。

## 易错点
- 用 n 而不是 n-1 代入臂长：n=2 会算成 1+4·(2·3//2)=13，正确是 5；第一分钟只染中心，臂长从第 2 分钟才开始累加，所以 m = n - 1。
- 先乘后除的顺序写反：写成 `4 * m * (m+1) / 2` 得到浮点 4.0 之类，n=10^5 时 m(m+1) 约 10^10，浮点虽能表示但返回类型是 float 而非 int；必须用 `// 2` 且保证乘法在整除之前完成。

## 如果面试官追问
问：n 上限改成 10^18 还成立吗？
答：成立，闭式只做一次乘法，Python 大整数直接算，无需改逻辑。
