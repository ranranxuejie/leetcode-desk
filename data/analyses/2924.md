## 一句话思路
统计每个节点的入度，入度为 0 的节点就是没有队伍比它强的候选冠军，恰好一个才返回它。

## 怎么做
1. 开一个长度 n 的 `indeg` 数组，初始全 0。
2. 遍历 `edges`，对每条 `[u, v]` 执行 `indeg[v] += 1`——v 被 u 打败，v 不可能是冠军。
3. 扫一遍 `indeg`，收集所有 `indeg[i] == 0` 的下标。
4. 候选恰好 1 个就返回它，否则返回 -1。

以示例 2 `n = 4, edges = [[0,2],[1,3],[1,2]]` 为例，处理完三条边后 `indeg = [0, 0, 2, 1]`：节点 2 被 0 和 1 各打败一次，节点 3 被 1 打败一次。入度为 0 的是 `[0, 1]`，两个候选，返回 -1——正好对应题面说的「1 队和 0 队之间不存在强弱对比」。

```python
indeg = [0] * n
for u, v in edges:
    indeg[v] += 1
champ = -1
for i in range(n):
    if indeg[i] == 0:
        if champ != -1:
            return -1
        champ = i
return champ
```

关键点：DAG 保证至少有一个入度为 0 的节点，所以 `champ` 不会停在 -1；题目又保证强弱关系传递，因此「入度为 0」等价于「不存在比它强的队伍」，不需要真的做拓扑排序或比较传递闭包。

## 复杂度
时间：O(n + m)，遍历 edges 一次、扫 indeg 一次。
空间：O(n)，只开了 indeg 数组，没有建邻接表。

## 易错点
- 输入 `n = 1, edges = []` → 若把 `champ` 初值设成 0 再判断「`champ != -1` 就返回 -1」，会把唯一冠军 0 误判成 -1 → 初值必须用 -1 这种哨兵，且哨兵不能是合法队伍编号。
- 输入 `n = 4, edges = [[0,2],[1,3],[1,2]]` → 若只取第一个入度为 0 的节点直接返回，会错答 0 → 必须扫完全部 n 个节点确认候选唯一，中途发现第二个就立刻返回 -1。

## 如果面试官追问
问：如果要求返回所有可能的冠军（不要求唯一）怎么办？
答：把「发现第二个就返回 -1」改成收集进列表，最后返回整个列表即可，复杂度不变。
