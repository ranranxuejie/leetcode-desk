## 一句话思路
枚举 4 个 2×2 子方块，只要某个方块里 'B' 或 'W' 的个数 ≥ 3，改至多一格就能凑成全同色。

## 怎么做
1. 3×3 矩阵只有 4 个 2×2 子方块，左上角分别是 (0,0)、(0,1)、(1,0)、(1,1)，直接双重循环枚举。
2. 对每个子方块统计四个格子里 'B' 的数量 `cnt`，'W' 的数量就是 `4 - cnt`。
3. 判断 `cnt >= 3 or 4 - cnt >= 3`，成立立刻返回 `True`；四个都试完返回 `False`。

以示例 1 的 `grid = [["B","W","B"],["B","W","W"],["B","W","B"]]` 为例，取左上角 (0,1) 的方块，四格是 `grid[0][1]='W'`、`grid[0][2]='B'`、`grid[1][1]='W'`、`grid[1][2]='W'`，`cnt=1`，`4-cnt=3 ≥ 3`，说明只需把 `grid[0][2]` 从 'B' 改成 'W'，返回 `True`，与官方解释一致。

```python
for i in range(2):
    for j in range(2):
        cells = [grid[i][j], grid[i][j+1], grid[i+1][j], grid[i+1][j+1]]
        cnt = cells.count('B')
        if cnt >= 3 or 4 - cnt >= 3:
            return True
return False
```

关键点：`cnt >= 3` 覆盖「3 个 B + 1 个 W」和「4 个 B」两种情况，`4 - cnt >= 3` 覆盖对称的白色情况，两个条件合起来正好是「至多改一格」。示例 2 里每个 2×2 方块都是 2B2W（如 (0,0) 方块为 B,W,W,B），`cnt=2`，两个条件都不成立，四个方块全试完返回 `False`。

## 复杂度
时间：O(1)，固定 4 个方块 × 4 格，与输入规模无关。
空间：O(1)，只用了 `cnt` 和长度 4 的临时列表 `cells`。

## 易错点
- 只统计 'B' 就写 `cnt >= 3`，漏掉 `4 - cnt >= 3`：示例 1 的 (0,1) 方块 `cnt=1`，会误判为 `False`；必须两个条件都写，或改写成 `cnt != 2`（因为 4 格里非 2 即 ≥3 或 ≤1）。
- 把「至多改一格」理解成「必须改一格」：示例 3 的 (1,1) 方块四格全是 'W'，`cnt=0`，`4-cnt=4 ≥ 3` 直接成立，若要求必须改动反而会绕远；判断条件用 `>=` 而非 `==` 即可覆盖已满足的情况。

## 如果面试官追问
若矩阵放大到 n×n，怎么做？答：仍枚举所有 (n-1)² 个 2×2 方块，每个 O(1) 统计，总时间 O(n²)，无需额外空间。
