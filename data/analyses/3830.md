## 一句话思路
用 `up[i]`/`down[i]` 记录以 `i` 结尾、末段比较为升/降的最长交替长度，再用「删一个」的转移把断点两侧拼起来。

## 怎么做
1. 定义 `up[i]`：以 `i` 结尾且 `nums[i-1] < nums[i]` 的最长交替长度；`down[i]` 对称，初值都为 1。
2. 正序转移：`nums[i-1] < nums[i]` 时 `up[i] = down[i-1] + 1`，否则 `down[i] = up[i-1] + 1`。
3. 再扫一遍枚举被删的 `i`，用 `nums[i-1]` 与 `nums[i+1]` 的比较判断能否把 `i-1` 结尾的段和 `i+1` 开头的段接上。
4. 答案取所有 `up[i]`、`down[i]` 和拼接结果的最大值。

以 `nums = [3,2,1,2,3,2,1]` 为例，删 `nums[3]=2` 后看 `nums[2]=1` 与 `nums[4]=3`：`1 < 3`，所以左侧必须以「降」结尾（`down[2]=3`，即 `3>2>1`），右侧必须以「升」开头（`up[4]` 从 `3` 起算），拼出 `3,2,1,3,2,1` 长度 4。

```python
n = len(nums)
up = [1] * n
down = [1] * n
for i in range(1, n):
    if nums[i-1] < nums[i]:
        up[i] = down[i-1] + 1
    elif nums[i-1] > nums[i]:
        down[i] = up[i-1] + 1
ans = max(max(up), max(down))
for i in range(1, n-1):
    if nums[i-1] < nums[i+1]:
        ans = max(ans, down[i-1] + up[i+1])
    elif nums[i-1] > nums[i+1]:
        ans = max(ans, up[i-1] + down[i+1])
```

## 复杂度
时间 O(n)：两趟线性扫描，`up`/`down` 各算一次。
空间 O(n)：只开了 `up`、`down` 两个长度 n 的数组。

## 易错点
- `nums = [100000,100000]` 这类相等相邻：若把 `>=` 也当升、`<=` 也当降，`up[1]` 会错成 2；必须严格 `>`/`<`，相等时 `up[i]=down[i]=1`，答案才是 1。
- 拼接时只看 `nums[i-1]` 与 `nums[i+1]` 的大小，忘了左侧段末段方向：`nums=[1,3,2,4]` 删 `3` 得 `1,2,4`，`1<2<4` 不交替，正确做法是要求 `nums[i-1] < nums[i+1]` 时左侧取 `down[i-1]`（末段为降），取 `up[i-1]` 会拼出非法长度。

## 如果面试官追问
问：若允许删至多 k 个元素？答：把 `up`/`down` 扩成 `up[i][j]` 表示删 j 个，转移枚举断点，复杂度 O(nk)。
