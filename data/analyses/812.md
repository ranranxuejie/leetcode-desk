## 一句话思路
枚举所有三点组合，用叉积绝对值算面积取最大；n≤50 时 C(50,3)=19600 次枚举完全够用。

## 怎么做
1. 三重循环取下标 `i < j < k`，保证每个三角形只算一次。
2. 取 `a = points[i]`、`b = points[j]`、`c = points[k]`，算叉积 `cross = (b[0]-a[0])*(c[1]-a[1]) - (b[1]-a[1])*(c[0]-a[0])`。
3. 面积是 `abs(cross) / 2`，用 `max` 更新答案。
4. 返回浮点结果。

以示例 1 的 `points = [[0,0],[0,1],[1,0],[0,2],[2,0]]` 为例，取 `a=[0,0]`、`b=[0,2]`、`c=[2,0]`：`cross = (0-0)*(0-0) - (2-0)*(2-0) = -4`，`abs(cross)/2 = 2.0`，正好是最大面积。

```python
best = 0.0
n = len(points)
for i in range(n):
    for j in range(i + 1, n):
        for k in range(j + 1, n):
            ax, ay = points[i]
            bx, by = points[j]
            cx, cy = points[k]
            cross = (bx - ax) * (cy - ay) - (by - ay) * (cx - ax)
            best = max(best, abs(cross) / 2.0)
return best
```

注意 `abs(cross)` 里的 `cross` 是整数，`/ 2.0` 才转成浮点，别写成 `// 2`。

## 复杂度
时间：O(n³)，三重循环各贡献一个 n，n≤50 时约 2 万次。
空间：O(1)，只开了 `best`、`cross` 等几个标量。

## 易错点
- 三点共线时 `cross = 0`，面积 0。若用「先算三边长再海伦公式」，共线点会因浮点误差算出极小正数甚至负数开根报错；本题用叉积天然得 0，正确做法就是叉积。
- 用 `// 2` 或先除后取绝对值：`cross` 为奇数时 `// 2` 会截断，如 `cross = 3` 得 1 而非 1.5。必须 `abs(cross) / 2.0`，先取绝对值再除。

## 如果面试官追问
问：n 放大到 10⁵ 怎么办？
答：凸包 + 旋转卡壳，最大面积三角形顶点必在凸包上，O(n log n) 求凸包后 O(h²) 或旋转卡壳降维。
