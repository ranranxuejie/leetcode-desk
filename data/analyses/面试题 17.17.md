## 一句话思路
把 smalls 建成字典树，让 big 的每个起点沿树往下走，走到终止节点就记一次位置。

## 怎么做
1. 把 smalls 逐条插入字典树，终止节点存下该串在 smalls 中的下标。
2. 对 big 的每个起点 i，从根沿 big[i:] 往下走，每到一个终止节点就把 i 追加进对应答案。
3. 走不下去（字符不在子节点）或越界就停，换下一个起点。

以 `big = "mississippi"`、`smalls[0] = "is"` 为例：i=1 时路径 m→i→s，走到 `s` 节点是终止节点，`ans[0]` 记入 1；i=4 同理记入 4，得到 `[1,4]`。而 `smalls[2] = "hi"` 在树里以 `h` 开头，big 中无 `h`，i 从 0 到 10 第一步就失败，`ans[2]` 保持空。

```python
root = {}
for idx, w in enumerate(smalls):
    if not w:
        continue
    node = root
    for ch in w:
        node = node.setdefault(ch, {})
    node['#'] = idx          # 终止标记，存下标

ans = [[] for _ in smalls]
for i in range(len(big)):
    node = root
    for j in range(i, len(big)):
        if big[j] not in node:
            break
        node = node[big[j]]
        if '#' in node:
            ans[node['#']].append(i)
```

空串 `""` 按题意不参与匹配（示例中无空串，若出现则约定返回空列表），代码里 `continue` 跳过即可。

## 复杂度
时间 O(Σ|smalls[i]| + |big|²)，建树是前者，最坏每个起点走满 |big|。
空间 O(Σ|smalls[i]|)，字典树节点数，答案数组另算。

## 易错点
- `smalls` 含空串 `""` → 若把空串也插进树，根节点被标终止，big 每个起点都会命中，输出全位置列表 → 建树前 `if not w: continue` 跳过，答案留空。
- `big` 为空串 `""` → 若外层写成 `for i in range(len(big))` 没问题，但若先判断 `if not big: return []` 会漏掉 smalls 长度，返回长度对不上 → 直接返回 `[[] for _ in smalls]`，保证与 smalls 等长。

## 如果面试官追问
若 smalls 总字符数涨到 10^7 而 big 仍 1000，还建树吗？
答：改用哈希表存 smalls 按长度分组，对 big 每个起点枚举长度集合，总代价 O(|big|·不同长度数)，避免树节点内存爆炸。
