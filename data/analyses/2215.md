## 一句话思路
两个数组各转成 set，再用集合差集 `s1 - s2` 和 `s2 - s1` 直接得到去重后的差集。

## 怎么做
1. 把 `nums1`、`nums2` 分别转成 `set`，重复元素自动消掉。
2. 用 `s1 - s2` 得到只在 `nums1` 里出现的值，`s2 - s1` 得到只在 `nums2` 里出现的值。
3. 两个差集转成 `list` 后放进同一个列表返回。

以示例 2 为例：`nums1 = [1,2,3,3]` 转成 `s1 = {1,2,3}`，`nums2 = [1,1,2,2]` 转成 `s2 = {1,2}`。此时 `s1 - s2 = {3}`，`s2 - s1 = set()`，所以 `answer[0] = [3]`、`answer[1] = []`。注意 `nums1` 里两个 `3` 在 set 里只剩一个，这正是题目要的「不同整数」。

```python
s1, s2 = set(nums1), set(nums2)
return [list(s1 - s2), list(s2 - s1)]
```

关键点：差集运算本身已经保证结果去重，不需要再手动 `if x not in seen`。

## 复杂度
时间：O(n + m)，n、m 分别是两数组长度，建 set 和差集各扫一遍。
空间：O(n + m)，两个 set 各存一份去重后的元素。

## 易错点
- 输入 `nums1 = [1,2,3,3]` → 若用 `[x for x in nums1 if x not in s2]` 会得到 `[3,3]`，重复了 → 正确做法是先 `set(nums1)` 再去差，或对结果再 `set()`。
- 输入 `nums1 = [1,2,3], nums2 = [2,4,6]` → 若把 `s1 - s2` 和 `s2 - s1` 写反，会得到 `[[4,6],[1,3]]`，顺序颠倒 → 记住 `answer[0]` 永远来自 `nums1` 的差集。

## 如果面试官追问
问：如果要求结果按升序返回怎么办？
答：把 `list(s1 - s2)` 换成 `sorted(s1 - s2)`，复杂度多一个 O(k log k)，k 是差集大小。
