## 一句话思路
二分答案 `x`，用差分+贪心从左往右补电，判断能否让每座城市电量都 ≥ `x`。

## 怎么做
1. 先用差分算出原始电量 `power[i]`（每个站覆盖 `[i-r, i+r]`）。
2. 二分 `x` 在 `[0, sum(stations)+k]` 内，`check(x)` 判断能否达成。
3. `check` 里从左扫到右，维护滑动窗口内已加建站数 `added`；若 `power[i]+added < x`，缺口 `need = x-power[i]-added` 全建在 `i+r`（最右能覆盖 `i` 的位置），并让 `added += need`、`k -= need`。
4. 任一时刻 `k < 0` 返回 `False`。

以示例 1 `stations=[1,2,4,5,0], r=1, k=2` 为例，原始电量 `power=[3,7,11,9,5]`。`check(5)`：`i=0` 时 `3 < 5`，缺口 2 全建在位置 1，`k` 变 0，`added` 在 `i=2` 时滑出窗口归零；后续 `power[1..4]=[7,11,9,5]` 均 ≥5，返回 `True`，故答案 5。

```python
def check(x):
    added = 0
    diff = [0] * (n + 1)   # 记录加建站的影响
    rem = k
    for i in range(n):
        added += diff[i]
        if power[i] + added < x:
            need = x - power[i] - added
            rem -= need
            if rem < 0:
                return False
            added += need
            if i + 2 * r + 1 <= n:
                diff[i + 2 * r + 1] -= need
    return True
```

## 复杂度
时间：二分 `log(sum+k)` 次，每次 `check` 扫 `n`，共 `O(n log(sum+k))`。
空间：`power` 与 `diff` 各 `O(n)`，无其他额外结构。

## 易错点
- `r` 很大（如 `r = n-1`）时，加建站覆盖到数组末尾之外 → 若直接写 `diff[i+2*r+1]` 会越界 → 必须判断 `i+2*r+1 <= n` 再写差分。
- `k` 可达 `10^9`、`stations[i]` 达 `10^5`，累加电量远超 `2**31-1` → 用 Python 原生 int 即可，但若移植到定长语言需按 64 位处理，题目答案本身不截断。

## 如果面试官追问
问：要输出具体建站方案怎么办？
答：`check` 里把每次 `need` 和落点 `min(i+r, n-1)` 记进列表，二分确定 `x` 后重跑一次 `check(x)` 收集即可。
