## 一句话思路
先 BFS 求出 Bob 到 0 的到达时刻，再 DFS 枚举 Alice 到每个叶子的路径，按时刻比较决定该节点计 amount 全值、一半还是 0。

## 怎么做
1. 从 `bob` 出发 BFS 建 `parent`，回溯出 Bob 到 0 的路径，记 `bt[node] = 到达时刻`（`bt[bob]=0`）。
2. 从 0 出发 DFS，参数带 `t`（Alice 到达当前节点的时刻）和 `cur`（到当前节点为止的得分）。
3. 对节点 `u`：若 `t < bt[u]` 加 `amount[u]`，`t == bt[u]` 加 `amount[u] // 2`，`t > bt[u]` 加 0。
4. 若 `u` 是叶子（非根且度为 1）就用 `cur` 更新答案，否则递归子节点。

以示例 1 为例：`bt = {3:0, 1:1, 0:2}`。Alice 在 `t=1` 到节点 1，`1 == bt[1]`，加 `4 // 2 = 2`；`t=2` 到节点 3，`2 > bt[3]=0`，加 0；`t=3` 到叶子 4，加 6，总分 `-2+2+0+6 = 6`。

```python
def dfs(u, p, t, cur):
    if t < bt.get(u, INF): cur += amount[u]
    elif t == bt.get(u, INF): cur += amount[u] // 2
    if u != 0 and len(g[u]) == 1:
        ans = max(ans, cur); return
    for v in g[u]:
        if v != p: dfs(v, u, t + 1, cur)
```

## 复杂度
时间 O(n)：BFS 一次、DFS 一次，每条边各走常数次。
空间 O(n)：邻接表 `g`、`bt` 字典、递归栈深度最坏 n。

## 易错点
- Bob 到不了的节点：`bt` 里没有键，若直接 `bt[u]` 会 KeyError。正确做法是用 `bt.get(u, INF)`，让 `t < INF` 恒成立，按全值计。
- 根节点 0 的叶子判定：`n=2` 时 `edges=[[0,1]]`，节点 0 度为 1，若不加 `u != 0` 会在根就返回，漏掉节点 1。正确做法是叶子条件写成 `u != 0 and len(g[u]) == 1`。

## 如果面试官追问
问：若要求输出 Alice 走的具体叶子路径？
答：DFS 时多传一个 `path` 列表，更新答案时把当前 `path` 拷贝存下来即可，复杂度不变。
