## 一句话思路
从右往左找第一个非元音字符的位置，切片返回它左边的全部内容。

## 怎么做
1. 把五个元音放进集合 `vowels = set("aeiou")`，判断单字符是否元音是 O(1)。
2. 令 `i = len(s) - 1`，从末尾开始向左扫描。
3. 只要 `i >= 0 and s[i] in vowels` 就 `i -= 1`，跳过尾部连续的元音。
4. 循环结束时 `i` 指向最后一个保留字符，返回 `s[:i + 1]`；若全是元音则 `i == -1`，切片得空串。

以 `s = "idea"` 为例：`i = 3`，`s[3] = 'a'` 是元音，`i` 变 2；`s[2] = 'e'` 是元音，`i` 变 1；`s[1] = 'd'` 不在集合里，循环停。此时 `i = 1`，返回 `s[:2]` 即 `"id"`。关键中间值是停下时的 `i = 1`，切片上界必须写 `i + 1`，写成 `s[:i]` 会丢掉 `'d'`。

```python
vowels = set("aeiou")
i = len(s) - 1
while i >= 0 and s[i] in vowels:
    i -= 1
return s[:i + 1]
```

注意 `s = "day"` 时 `i = 2`，`s[2] = 'y'` 不是元音，循环一次都不进，直接返回 `s[:3]` 即原串，符合示例 2。`s = "aeiou"` 时 `i` 一路减到 `-1`，`s[:0]` 是 `""`，符合示例 3。三个官方示例都落在同一条路径上，没有分支特判。

## 复杂度
时间 O(n)：最坏全串是元音，`i` 从 `n-1` 走到 `-1`，每个字符查一次集合。
空间 O(n)：切片 `s[:i + 1]` 新建了一个长度至多 n 的字符串；`vowels` 固定 5 个元素。

## 易错点
- 输入 `s = "day"` → 若把 `'y'` 也当元音（英语里 y 有时算半元音）→ 会错成 `"da"`；本题元音集合严格只有 `a e i o u` 五个，`'y'` 必须保留。
- 输入 `s = "idea"` → 若循环条件写成 `s[i] in vowels` 却漏了 `i >= 0` → 全元音串如 `"aeiou"` 会索引到 `s[-1]` 绕回末尾，死循环或错删；正确做法是 `while i >= 0 and s[i] in vowels`，先判边界再取字符。

## 如果面试官追问
问：如果要求移除的是「尾部所有非字母字符」呢？
答：同一套从右扫描的骨架不变，只把 `s[i] in vowels` 换成 `not s[i].isalpha()`，切片逻辑一字不改。
