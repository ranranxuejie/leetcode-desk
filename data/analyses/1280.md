## 一句话思路
用 `Students × Subjects` 笛卡尔积做左连接骨架，再左连接 `Examinations` 后按学生科目分组计数，保证零次考试也出现在结果里。

## 怎么做
1. 先对 `Students` 和 `Subjects` 做无条件的 `CROSS JOIN`，得到 4×3=12 行完整组合，这是"每个学生每门科目"的全集。
2. 用 `LEFT JOIN Examinations` 把考试记录挂到这 12 行上，匹配不上的行 `Examinations.student_id` 为 `NULL`。
3. 按 `student_id, subject_name` 分组，用 `COUNT(Examinations.student_id)` 计数——注意数的是考试表那一侧，`NULL` 不计入，所以 Alex 的三行都是 0。
4. 最后 `ORDER BY student_id, subject_name`。

关键中间值：以 Bob（`student_id=2`）为例，笛卡尔积后他有 `(2,Math)`、`(2,Physics)`、`(2,Programming)` 三行；左连接后 `(2,Physics)` 的考试侧全为 `NULL`，`COUNT` 得 0，而 `(2,Math)` 匹配到 1 行、`(2,Programming)` 匹配到 1 行。

若用 pandas 表达同一逻辑：

```python
import pandas as pd
def students_and_examinations(students, subjects, examinations):
    grid = students.merge(subjects, how="cross")
    cnt = (examinations.groupby(["student_id", "subject_name"])
           .size().reset_index(name="attended_exams"))
    res = grid.merge(cnt, how="left",
                     on=["student_id", "subject_name"])
    res["attended_exams"] = res["attended_exams"].fillna(0).astype(int)
    return res.sort_values(["student_id", "subject_name"])
```

## 复杂度
时间：`O(S·U + E)`，S 学生数、U 科目数、E 考试行数，分组排序再乘 log。
空间：额外开 S·U 行的笛卡尔积结果，即 `O(S·U)`。

## 易错点
- 用 `INNER JOIN Examinations` → Alex（`student_id=6`）整行消失、Bob 的 Physics 也消失，结果只剩 9 行；必须 `LEFT JOIN` 且连接条件同时带 `student_id` 和 `subject_name`。
- 计数写成 `COUNT(*)` → 左连接产生的 `NULL` 行被算成 1，Alex 三门全变 1、Bob 的 Physics 变 1；要写 `COUNT(e.student_id)` 或 `COUNT(e.subject_name)`，只数考试表非空列。
