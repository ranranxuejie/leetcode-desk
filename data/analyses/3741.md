## 一句话思路
按值分组记录下标，每组内取连续三个下标，距离即 2×(最大−最小)，扫一遍取最小。

## 怎么做
1. 用字典 `pos` 把每个值出现的下标按顺序存成列表，一次遍历 `enumerate(nums)` 即可。
2. 对每个列表，只需检查**连续三个**下标 `a, b, c`：同值三元组的距离化简为 `2*(c - a)`，中间项 `b` 被消掉。
3. 所以组内最优一定是相邻三个，滑动窗口扫完取全局最小，没有长度 ≥3 的组就返回 -1。

以 `nums = [1,2,1,1,3]` 为例：`pos[1] = [0,2,3]`，取 `a=0,b=2,c=3`，距离 `2*(3-0)=6`；`pos[2]=[1]`、`pos[3]=[4]` 长度不足 3 跳过，答案 6。

```python
pos = {}
for i, x in enumerate(nums):
    pos.setdefault(x, []).append(i)

ans = float('inf')
for idx in pos.values():
    for t in range(len(idx) - 2):
        a, c = idx[t], idx[t + 2]
        ans = min(ans, 2 * (c - a))
return -1 if ans == float('inf') else ans
```

关键化简：`abs(i-j)+abs(j-k)+abs(k-i)` 在 `i<j<k` 时等于 `(j-i)+(k-j)+(k-i) = 2*(k-i)`，与 `j` 无关——这就是只看首尾两个下标的依据。

## 复杂度
时间 O(n)：建表 O(n)，每组滑窗总长不超过 n。
空间 O(n)：`pos` 存下所有下标，最坏全同值。

## 易错点
- 输入 `[1,1,1,1]` → 若只取每组前三个 `(0,1,2)` 得 4，但 `(1,2,3)` 也是 4、`(0,1,3)` 是 6，容易漏掉「窗口要滑动」而非固定取前三个 → 必须用 `range(len(idx)-2)` 全滑一遍。
- 输入 `[1,2,1,1,3]` → 若把 `pos` 建成 `set` 或只存首次出现位置，`pos[1]` 只剩 `{0}`，长度不足 3 直接返回 -1 → 必须用 `list` 按出现顺序 append，保留重复下标。

## 如果面试官追问
问：若要求返回具体三元组下标而非距离？
答：滑窗时同步记录 `(a, idx[t+1], c)` 与当前最小距离一起更新即可，逻辑不变。
