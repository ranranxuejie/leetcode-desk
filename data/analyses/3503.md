## 一句话思路
枚举 s 的每个子串作为回文左半，用双指针向 t 的两端扩展匹配，取最大长度。

## 怎么做
1. 枚举 s 的所有子串 `s[i:j]`，判断它本身是否回文，是则作为候选回文的核心或左半部分。
2. 对每个回文子串，用双指针 `l` 指向 t 开头、`r` 指向 t 结尾，尝试从两端各取字符与 s 子串两侧匹配扩展。
3. 若 s 子串非回文，则只能作为回文的一侧，需在 t 中找对应镜像，用双指针从 t 两端向中间夹。
4. 记录所有情况下的最大长度。

以示例 4 `s="abcde", t="ecdba"` 为例：取 s 子串 `"abc"`，它不是回文，但 `"abc"` 与 t 末尾 `"ba"` 拼接成 `"abcba"`。具体做法是枚举 s 子串 `s[i:j]`，再枚举 t 子串 `t[p:q]`，检查 `s[i:j]+t[p:q]` 是否回文。n,m≤30，四重枚举约 30^4≈81 万次，每次回文检查 O(60)，可接受。

```python
def longestPalindrome(s, t):
    best = 0
    for i in range(len(s)):
        for j in range(i, len(s) + 1):
            for p in range(len(t)):
                for q in range(p, len(t) + 1):
                    u = s[i:j] + t[p:q]
                    if u == u[::-1]:
                        best = max(best, len(u))
    return best
```

关键中间值：示例 4 中 `i=0,j=3` 得 `"abc"`，`p=3,q=5` 得 `"ba"`，拼接 `"abcba"` 回文，长度 5。

## 复杂度
时间：O(n²m²·(n+m))，四重枚举子串对，每次回文比较 O(n+m)。
空间：O(n+m)，仅拼接临时字符串。

## 易错点
- 输入 `s="b", t="aaaa"` → 若只枚举 s 非空子串会漏掉纯 t 回文 `"aaaa"` → 正确做法是允许 s 子串为空（`i==j`），此时退化为在 t 内找最长回文。
- 输入 `s="abc", t="def"` → 若只检查拼接后整体回文而忽略单字符 → 会错成 0 → 正确做法是空串+单字符组合也纳入枚举，保证至少返回 1。

## 如果面试官追问
问：n,m 放大到 2000 怎么办？答：四重枚举不可行，需改为枚举回文中心，用双指针在 s、t 上同步扩展，O(n²) 预处理后 O(n+m) 合并。
