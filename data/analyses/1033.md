## 一句话思路
先排序得 x<y<z，最小步数由「两端空隙是否 ≤1」分三档，最大步数就是两端空隙之和。

## 怎么做
1. 排序：`x, y, z = sorted([a, b, c])`，之后所有判断都基于有序三元组。
2. 最小步数分三档：已连续（`z - x == 2`）返回 0；某端空隙为 1（`y - x == 1 or z - y == 1`）返回 1；否则返回 2。
3. 最大步数：每回合只能把端点石子挪进中间，且必须留出空位，所以总消耗是 `(y - x - 1) + (z - y - 1) = z - x - 2`。
4. 返回 `[min_moves, z - x - 2]`。

以 `a=1, b=2, c=5` 为例：排序后 `x=1, y=2, z=5`，`z - x = 4 != 2`，但 `y - x == 1`，所以 `min_moves = 1`；最大步数 `5 - 1 - 2 = 2`，输出 `[1, 2]`。

```python
x, y, z = sorted([a, b, c])
if z - x == 2:
    min_moves = 0
elif y - x == 1 or z - y == 1:
    min_moves = 1
else:
    min_moves = 2
return [min_moves, z - x - 2]
```

关键在第二档：`y - x == 1` 时，把 `z` 直接放到 `y + 1` 就连续了，一步到位；若两端空隙都 ≥2（如 `1, 4, 7`），一步只能消掉一端，另一端还得再走一步，所以是 2。

## 复杂度
时间：O(1)，只有三次比较和一次排序，与输入数值大小无关。
空间：O(1)，排序三个元素，无额外数组。

## 易错点
- 输入 `a=1, b=3, c=5`（两端空隙都是 1）→ 若只判 `z - x == 2` 会错成 2 → 正确做法是先判连续，再判「任一端空隙为 1」返回 1，因为把 5 挪到 2 就得到 `1,2,3`。
- 输入 `a=1, b=2, c=3`（已连续）→ 若直接套 `z - x - 2` 会得到 0 但 min 也需单独判 → 正确做法是 `z - x == 2` 时直接返回 `[0, 0]`，避免 `y - x == 1` 分支误判成 1。

## 如果面试官追问
问：如果石子数变成 n 枚，最小步数怎么求？
答：先排序，统计相邻空隙为 1 的连续段长度，最小步数等于把两端石子填进最大空隙所需的次数，本质是「用最少移动消除所有空隙」。
