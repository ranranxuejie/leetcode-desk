## 一句话思路
枚举分母 d 与分子 a，用 `gcd(a, d) == 1` 判最简，成立因为最简分数定义就是分子分母互质。

## 怎么做
1. 外层 `for d in range(2, n + 1)`，分母从 2 起，因为分母 1 只能配 0 或 1，都被排除。
2. 内层 `for a in range(1, d)`，分子严格小于分母，保证值落在 (0, 1)。
3. 用 `math.gcd(a, d) == 1` 过滤，通过则拼 `f"{a}/{d}"` 追加到结果。
4. 直接返回列表，顺序不限，无需排序。

以 n = 4 为例：d = 2 时 a = 1，`gcd(1, 2) = 1`，收下 `"1/2"`；d = 4 时 a = 2，`gcd(2, 4) = 2`，跳过 `"2/4"`，a = 3 时 `gcd(3, 4) = 1`，收下 `"3/4"`。最终 5 个元素，与示例 3 一致。

```python
from math import gcd

res = []
for d in range(2, n + 1):
    for a in range(1, d):
        if gcd(a, d) == 1:
            res.append(f"{a}/{d}")
return res
```

n = 1 时外层 `range(2, 2)` 为空，直接返回 `[]`，与示例 4 吻合，不需要额外特判。

## 复杂度
时间 O(n² log n)：约 n²/2 对 (a, d)，每对一次 gcd 花 O(log n)。
空间 O(n²)：结果列表最多存约 3n²/π² 个字符串，其余只有循环变量。

## 易错点
- 内层写成 `range(1, d + 1)` → 会产出 `"1/1"`、`"2/2"` 这类等于 1 的分数 → 上界必须是 `d`，开区间。
- 用 `a % d != 0` 或 `d % a != 0` 代替 gcd 判互质 → n = 4 时 `"2/4"` 的 `4 % 2 == 0` 恰好能过滤，但 n = 6 的 `"2/6"`、`"3/6"` 也过，而 `"4/6"` 的 `6 % 4 != 0` 会被误收 → 只有 `gcd(a, d) == 1` 才是充要条件。

## 如果面试官追问
问：n 放大到 10⁵ 怎么改？答：枚举法 O(n²) 不可行，改用 Farey 序列递推，从 0/1 和 1/n 出发按 `k = (n + b) // d` 生成相邻项，O(答案个数) 时间。
