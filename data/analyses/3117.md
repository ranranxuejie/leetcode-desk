## 一句话思路
用 DP 按 andValues 逐段推进，每段只保留「AND 值恰好等于 andValues[i]」的极短后缀候选，靠 AND 单调不增把候选压到 O(log V) 个。

## 怎么做
1. 预处理 `pre[i][b]`：nums 前 i 个元素中第 b 位为 1 的个数，用于 O(1) 判断任意区间 AND 是否等于目标值。
2. 定义 `dp[i]` = 把 nums 前 i 个元素划分成前 j 段、且第 j 段 AND 恰为 andValues[j-1] 时的最小值和；初始 `dp[0]=0`，其余 `inf`。
3. 对第 j 段（j 从 1 到 m），枚举右端点 r，用双指针/二分找满足 `AND(nums[l..r]) == andValues[j-1]` 的 l 区间，取其中 `dp[l]` 最小者更新 `dp[r+1]`。
4. 答案取 `dp[n]`，若为 `inf` 返回 -1。

以示例 1 为例：`nums=[1,4,3,3,2]`，`andValues=[0,3,3,2]`。第 1 段目标 0，r=2 时 `1&4=0`，`dp[2]=4`；第 2 段目标 3，r=3 时 `3=3`，`dp[3]=4+3=7`；依次得 `dp[5]=12`。

```python
# 关键：区间 AND 用前缀位计数判断
def and_ok(l, r, target):          # nums[l..r] 的 AND 是否 == target
    for b in range(17):
        cnt = pre[r+1][b] - pre[l][b]
        if (cnt == r - l + 1) != bool(target >> b & 1):
            return False
    return True
# dp 推进（示意）
for j in range(1, m+1):
    ndp = [inf] * (n+1)
    for r in range(j-1, n):
        for l in range(j-1, r+1):
            if dp[l] < inf and and_ok(l, r, andValues[j-1]):
                ndp[r+1] = min(ndp[r+1], dp[l] + nums[r])
    dp = ndp
```

## 复杂度
时间：O(m·n·log V·17)，m≤10、n≤10⁴，log V 来自 AND 候选压缩。
空间：O(n·17) 存前缀位计数，DP 数组 O(n)。

## 易错点
1. 示例 3 `nums=[1,2,3,4]`、`andValues=[2]`：若只判断「存在某区间 AND 含 2 的位」会误判可行，实际整段 AND 为 0，必须逐位精确比对 `and_ok`，返回 -1。
2. 示例 2 中 `[2,3,5,7]` 段 AND 为 0 而非 7：若用「AND 单调不增」直接取最长后缀会漏掉 `[7,7,7]` 这种短段，必须枚举所有满足等值的 l 区间取 `dp[l]` 最小。

## 如果面试官追问
若 n 放大到 10⁵ 怎么办？答：用线段树维护区间 AND 并二分找等值边界，把每段枚举从 O(n) 降到 O(log n)，总 O(m·n·log n)。
