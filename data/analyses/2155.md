## 一句话思路
把得分拆成「左侧 0 的个数 + 右侧 1 的个数」，从 i=0 起逐个右移，用增量更新得分，一次遍历取最大。

## 怎么做
1. 先算 i=0 的得分：`score = nums.count(1)`，此时 left 为空、right 是整个数组。
2. 从 i=1 扫到 n，每移动一位只更新一个数：`nums[i-1] == 0` 时 `score += 1`，否则 `score -= 1`。
3. 每步把 `score` 与当前最大值比较，大于则清空答案列表并记下 i，等于则追加 i。
4. 返回答案列表。

以 `nums = [0,0,1,0]` 为例：初始 `score = 1`（右侧 1 个 1），答案 `[0]`。i=1 时 `nums[0]=0`，`score` 变 2，超过 1，答案重置为 `[1]`；i=2 时 `nums[1]=0`，`score` 变 3，答案重置为 `[2]`；i=3 时 `nums[2]=1`，`score` 回落到 2，不追加；i=4 时 `nums[3]=0`，`score` 回到 3，等于最大值，追加得 `[2,4]`。

```python
score = nums.count(1)
best, ans = score, [0]
for i in range(1, len(nums) + 1):
    if nums[i - 1] == 0:
        score += 1
    else:
        score -= 1
    if score > best:
        best, ans = score, [i]
    elif score == best:
        ans.append(i)
return ans
```

关键在增量：把 0 划进 left 让 left 的 0 计数 +1，把 1 划出 right 让 right 的 1 计数 -1，所以 `nums[i-1]=0` 时得分净增 1，`=1` 时净减 1。

## 复杂度
时间：O(n)，一次 `count` 加一次遍历，每个元素常数次操作。
空间：O(1) 额外空间（不计答案列表本身）。

## 易错点
- 忘记 i=n 这个切分点：`nums=[0,0,0]` 若循环写成 `range(1, n)` 就漏掉 i=3，答案错成 `[2]`；正确做法是循环上界取 `len(nums)+1`，让 left 能吞下整个数组。
- 最大值更新时只改 `best` 不清空 `ans`：`nums=[1,1]` 中 i=0 得分 2 是最大值，后续得分只降不升，若写成「大于等于都 append」会把 i=1、i=2 也塞进去；正确做法是严格大于时重置列表、等于时追加。

## 如果面试官追问
问：如果 nums 长度到 10^7，内存吃紧怎么办？
答：本解法已是 O(1) 额外空间、单遍扫描，只需把 `count(1)` 合并进同一次遍历（先累加总数再回扫），避免两次读数组。
