## 一句话思路
把 `runes` 排序后，答案就是最长的一段「相邻差值 ≤ 1」的连续区间长度。

## 怎么做
1. 先对 `runes` 排序，让魔力值相近的符文挨在一起。
2. 用双指针 `left`、`right` 扫排序后的数组，维护窗口内 `a[right] - a[left] <= 1`。
3. 若差值超过 1，就右移 `left` 直到重新满足条件。
4. 每次更新 `right - left + 1` 的最大值。

以 `runes = [1,3,5,4,1,7]` 为例，排序后是 `[1,1,3,4,5,7]`。当 `right` 指到 5（值 5）、`left` 指到 2（值 3）时，窗口 `[3,4,5]` 差值为 2，长度 3；再往右到 7 时差值 4，`left` 被推到 6，窗口只剩 `[7]`，最终最大值仍是 3。

```python
a = sorted(runes)
left = 0
best = 0
for right in range(len(a)):
    while a[right] - a[left] > 1:
        left += 1
    best = max(best, right - left + 1)
return best
```

关键点：排序后，任何合法排列所选的符文集合，在排序数组里必然落在一段差值 ≤ 1 的连续区间内；反过来这段区间按升序排列就满足相邻差 ≤ 1。所以问题等价于求最长这样的窗口。

## 复杂度
时间：排序 `O(n log n)` 主导，双指针扫描 `O(n)`，共 `O(n log n)`。
空间：排序额外 `O(n)`（Python `sorted` 返回新列表），双指针只用常数变量。

## 易错点
- 输入 `[1,1,3,3,2,4]` → 若只统计「相邻两数差 ≤ 1 的连续段」而不排序，会漏掉 `2` 把 `1` 和 `3` 连起来，错成 2；必须先排序再滑窗。
- 输入 `[1,3,5,4,1,7]` → 若把窗口条件写成 `a[right] - a[left] < 1`（严格小于），`[3,4,5]` 会被判不合法，错成 2；条件是 `<= 1`，允许差 1。

## 如果面试官追问
问：如果要求输出具体选了哪些符文怎么办？
答：滑窗记录最优时的 `left`、`right`，返回 `a[left:right+1]` 即可，复杂度不变。
