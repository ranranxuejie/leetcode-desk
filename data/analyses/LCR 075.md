## 一句话思路
用长度 1001 的计数数组统计 arr1 各值出现次数，先按 arr2 顺序输出，再升序输出剩余值。

## 怎么做
1. 建 `cnt = [0] * 1001`，遍历 arr1 把 `cnt[x]` 加一。
2. 按 arr2 顺序，对每个 `v` 把 `v` 重复 `cnt[v]` 次追加进结果，并清零 `cnt[v]`。
3. 从 0 到 1000 扫一遍 cnt，把 `i` 重复 `cnt[i]` 次追加到末尾。

以官方示例为例，统计后 `cnt[2]=3, cnt[3]=2, cnt[1]=1, cnt[4]=1, cnt[6]=1, cnt[7]=1, cnt[9]=1, cnt[19]=1`。按 arr2 输出得到 `[2,2,2,1,4,3,3,9,6]`，此时这些位置已清零；剩余扫描只命中 7 和 19，补成 `[...,7,19]`。

```python
cnt = [0] * 1001
for x in arr1:
    cnt[x] += 1
res = []
for v in arr2:
    res.extend([v] * cnt[v])
    cnt[v] = 0
for i in range(1001):
    if cnt[i]:
        res.extend([i] * cnt[i])
return res
```

关键点是 `cnt[v] = 0` 必须在按 arr2 输出后立刻执行，否则第 3 步会把 arr2 里的值再输出一遍，示例中 2 会多出 3 个。

## 复杂度
时间 O(n + m + 1001)：n 是 arr1 长度，m 是 arr2 长度，最后定长扫描 1001。
空间 O(1001 + n)：cnt 数组固定 1001，结果列表占 n。

## 易错点
- arr1 含大量重复值（示例中 2 出现 3 次）→ 若用 `set(arr1)` 或字典只记存在性，输出只剩一个 2 → 必须用计数，`res.extend([v] * cnt[v])`。
- 忘记清零已输出元素 → 示例中 2、1、4、3、9、6 会在末尾升序段再出现一次，结果长度变成 17 → 输出后立即 `cnt[v] = 0`。

## 如果面试官追问
若 arr1[i] 上限从 1000 放大到 10**9 怎么办？答：计数数组不可行，改用 `Counter` 统计 arr1，按 arr2 输出后对剩余键 `sorted()` 升序拼接。
