## 一句话思路
对除数 d 二分：`sum(ceil(x/d))` 随 d 单调不增，找满足 `<= threshold` 的最小 d。

## 怎么做
1. 二分区间取 `lo, hi = 1, max(nums)`，因为 d 超过最大值后和恒为 `len(nums)`，再大无意义。
2. 每轮算 `mid = (lo + hi) // 2`，用 `(x + mid - 1) // mid` 累加向上取整和。
3. 和 `<= threshold` 就 `hi = mid`，否则 `lo = mid + 1`，收敛到最小可行 d。

以 `nums = [1,2,5,9], threshold = 6` 为例：`hi = 9`，`mid = 5` 时和为 `1+1+1+2 = 5 <= 6`，收 `hi = 5`；接着 `mid = 3` 和为 `1+1+2+3 = 7 > 6`，`lo = 4`；`mid = 4` 和为 `1+1+2+3 = 7 > 6`，`lo = 5`，返回 5。

```python
lo, hi = 1, max(nums)
while lo < hi:
    mid = (lo + hi) // 2
    s = 0
    for x in nums:
        s += (x + mid - 1) // mid
        if s > threshold:      # 提前剪枝，避免大数组白算
            break
    if s <= threshold:
        hi = mid
    else:
        lo = mid + 1
return lo
```

注意剪枝那行的 `s` 已被截断，判断仍用 `s <= threshold` 是安全的：一旦 `s > threshold` 就 break，此时 `s` 必然大于阈值，走 `lo = mid + 1` 分支正确。

## 复杂度
时间 O(n log max(nums))：n 来自每轮遍历 nums，log 来自二分除数。
空间 O(1)：只开了 lo、hi、mid、s 几个标量。

## 易错点
- 用 `x // mid` 当向上取整 → 示例 1 中 `9 // 5 = 1`，和算成 4 而非 5，会误判 d=5 可行甚至返回更小的错值；必须写 `(x + mid - 1) // mid`。
- 上界写成 `sum(nums)` 或 `10**6` → 二分多跑十几轮但结果仍对，真正翻车是把上界写成 `threshold`：示例 3 中 `nums=[19], threshold=5`，若 `hi=5` 尚可，但若 `hi=threshold` 且 threshold 小于答案（如 `nums=[100], threshold=1` 时答案 100）会直接返回错误值；上界必须是 `max(nums)`。

## 如果面试官追问
问：若要求输出所有可行的最小除数（并列）怎么办？
答：本题答案唯一，因为 d 增大和严格不增；若改成「和恰好等于 threshold 的所有 d」，二分只能定位左端点，需在 `[lo, max(nums)]` 上再扫或再二分找右端点。
