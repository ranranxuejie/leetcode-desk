## 一句话思路
枚举 k 在两个数组的分配数 i，各自用单调栈取长度为 i 的最大子序列，再贪心归并取字典序最大者。

## 怎么做
1. 对每个 `i ∈ [max(0, k-n), min(k, m)]`，从 `nums1` 取 `i` 个、`nums2` 取 `k-i` 个。
2. 取子序列用单调栈：栈内元素递减，当 `len(stack) + (m - idx) > need` 且 `stack[-1] < nums[idx]` 时弹栈，保证剩余元素够填满 `need`。
3. 归并时逐位比较两个剩余后缀的字典序，谁大先取谁（不能只比当前位）。
4. 所有 `i` 的结果取字典序最大。

以示例 1 为例，`i=2` 时 `nums1` 得 `[6,5]`，`nums2` 取 3 个得 `[9,8,3]`；归并时 `9>6` 先取 9，`8>6` 取 8，再取 6、5，最后 3，得 `[9,8,6,5,3]`，即答案。

```python
def pick(nums, need):
    drop = len(nums) - need
    st = []
    for x in nums:
        while drop and st and st[-1] < x:
            st.pop(); drop -= 1
        st.append(x)
    return st[:need]

def merge(a, b):
    res = []
    while a or b:
        if a > b: res.append(a.pop(0))
        else: res.append(b.pop(0))
    return res
```

外层对每个 `i` 调 `pick` 两次再 `merge`，取最大。

## 复杂度
时间 O(k·(m+n)·k)：枚举 i 共 O(k) 种，每次 pick 与 merge 各 O(m+n)，比较后缀最坏 O(k)。
空间 O(m+n)：pick 的栈与 merge 的结果数组，均为线性。

## 易错点
- 归并只比 `a[0]` 和 `b[0]`：输入 `a=[6,7]`、`b=[6,0,4]` 时，首位都是 6，若随便取 `b` 得 `[6,0,4,6,7]`，正确应取 `a` 得 `[6,7,6,0,4]`。必须比较整个剩余后缀。
- `pick` 的弹栈条件漏掉 `drop` 计数：`nums=[9,1,2,5,8,3]` 取 3 个时，若不限弹栈次数会把 9 也弹掉，得到 `[8,3]` 长度不足。必须用 `drop = len(nums) - need` 封顶。

## 如果面试官追问
若 k 固定但要求返回所有能达到最大值的拼接方案数？答：归并时后缀相等处会产生分支，需在比较相等时同时探索两条路径并去重，复杂度升到指数级，改用 DP 记忆化。
