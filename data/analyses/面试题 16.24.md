## 一句话思路
用哈希表记录每个数已出现的次数，遍历时先查 `target - x` 的剩余计数，配对成功就消耗一次。

## 怎么做
1. 建空字典 `cnt`，遍历 `nums` 的每个 `x`，先算 `need = target - x`。
2. 若 `cnt.get(need, 0) > 0`，说明前面有可配对的数，把 `[need, x]` 加入答案，并把 `cnt[need]` 减 1。
3. 否则把 `x` 计入 `cnt[x] += 1`，留给后面的数来配。
4. 关键点：先查后记，保证同一个下标不会被自己配对（`x + x == target` 时尤其重要）。

以示例 2 `nums = [5,6,5,6], target = 11` 走一遍：`x=5` 时 `need=6`，`cnt` 为空，记 `cnt[5]=1`；`x=6` 时 `need=5`，`cnt[5]=1>0`，输出 `[5,6]`，`cnt[5]` 变 0，`cnt[6]` 不记；`x=5` 时 `need=6`，`cnt[6]=0`，记 `cnt[5]=1`；`x=6` 时 `need=5`，命中，输出第二个 `[5,6]`。最终 `[[5,6],[5,6]]`。

```python
cnt = {}
res = []
for x in nums:
    need = target - x
    if cnt.get(need, 0) > 0:
        res.append([need, x])
        cnt[need] -= 1
    else:
        cnt[x] = cnt.get(x, 0) + 1
return res
```

注意 `cnt[need] -= 1` 后不删键，`get` 默认 0 已能处理计数归零，省一次 `del`。

## 复杂度
时间 O(n)：一次遍历，字典查询均摊 O(1)。
空间 O(n)：`cnt` 最坏存 n 个不同值，答案列表另算。

## 易错点
- 输入 `nums = [5,5,5], target = 10` → 若先记后查，第一个 5 会和自己配上，输出 1 对甚至 2 对 → 正确做法是先查 `cnt[need]` 再记 `cnt[x]`，且配对后只减 `cnt[need]`，不记当前 `x`。
- 输入 `nums = [5,6,5], target = 11` → 若用 `set` 存已见数，第二个 5 会重复输出 `[5,6]` → 必须用计数而非集合，配对成功消耗一次 `cnt[need]`，示例 1 只应输出 1 对。

## 如果面试官追问
问：若要求输出所有下标对而非数值对，怎么改？
答：`cnt` 存 `值 -> 下标列表`，配对时 `pop()` 一个下标，答案存 `[i, j]`，同样先查后记。
