## 一句话思路
完全图有 n(n-1)/2 条曼哈顿边，用 Kruskal 排序取边、并查集判环，选够 n-1 条即最小生成树。

## 怎么做
1. 枚举所有 `i < j`，把 `(dist, i, j)` 塞进 `edges`，`dist = abs(xi-xj) + abs(yi-yj)`。
2. 按 `dist` 升序排序 `edges`。
3. 并查集逐个 union，成功则累加 `dist` 并 `cnt += 1`，`cnt == n-1` 立即 break。

以示例 1 的 `points = [[0,0],[2,2],[3,10],[5,2],[7,0]]` 为例：点 0 到点 1 的边是 `|0-2|+|0-2| = 4`，点 1 到点 3 是 `|2-5|+|2-2| = 3`，这两条最先被接受；接着点 0 到点 4 是 `7`，点 3 到点 4 是 `|5-7|+|2-0| = 4`，点 2 到点 3 是 `|3-5|+|10-2| = 10`，累计 `4+3+7+4+10` 中实际选中 `4+3+4+...`，最终 `ans = 20`，`cnt` 到 4 时停。

```python
n = len(points)
edges = []
for i in range(n):
    for j in range(i + 1, n):
        d = abs(points[i][0] - points[j][0]) + abs(points[i][1] - points[j][1])
        edges.append((d, i, j))
edges.sort()
parent = list(range(n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
ans = cnt = 0
for d, i, j in edges:
    ri, rj = find(i), find(j)
    if ri != rj:
        parent[ri] = rj
        ans += d
        cnt += 1
        if cnt == n - 1:
            break
```

## 复杂度
时间：O(n² log n)，边数 n(n-1)/2 主导排序。
空间：O(n²) 存 `edges`，并查集 `parent` 只占 O(n)。

## 易错点
- `n == 1`（示例 5）时 `edges` 为空、循环不进入，`ans` 保持 0 正确；若写成先 `cnt = 1` 再判 `cnt == n` 会漏掉这个边界，直接返回 0 即可。
- 坐标到 ±10⁶，单边最大 4×10⁶，1000 点最坏总费用约 4×10⁹，超过 `2**31 - 1`；Python 整数不溢出，但若按 32 位截断的题面要求输出，需注意别用 `int32` 语义的中间变量。

## 如果面试官追问
问：n 涨到 10⁵ 怎么办？答：完全图边数爆炸，改用 Prim + 每轮 O(n) 找最近点，O(n²) 时间、O(n) 空间，不再存边。
