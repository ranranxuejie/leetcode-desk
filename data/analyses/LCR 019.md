## 一句话思路
双指针从两端向中间夹，首次失配时分别尝试跳过左字符或右字符，看剩下子串是否回文。

## 怎么做
1. 设 `i = 0`、`j = len(s) - 1`，当 `s[i] == s[j]` 时同步内移，直到失配或 `i >= j`。
2. 失配点 `(i, j)` 是唯一可能删字符的位置：要么删 `s[i]`，要么删 `s[j]`，其余前缀已确认对称。
3. 写辅助函数 `is_pal(l, r)` 判断 `s[l:r+1]` 是否回文，返回 `is_pal(i+1, j) or is_pal(i, j-1)`。
4. 全程无失配（`i >= j`）直接返回 `True`。

以 `s = "abca"` 为例：`i=0, j=3`，`s[0]='a' == s[3]='a'`，内移到 `i=1, j=2`；此时 `s[1]='b' != s[2]='c'` 失配。试 `is_pal(2, 2)`（删 `b`）→ 单字符为真，返回 `True`。若换成 `"abc"`，`i=0, j=2` 时 `'a' != 'c'`，`is_pal(1,2)` 判 `"bc"` 假、`is_pal(0,1)` 判 `"ab"` 假，返回 `False`。

```python
def is_pal(l, r):
    while l < r:
        if s[l] != s[r]:
            return False
        l += 1
        r -= 1
    return True

i, j = 0, len(s) - 1
while i < j and s[i] == s[j]:
    i += 1
    j -= 1
if i >= j:
    return True
return is_pal(i + 1, j) or is_pal(i, j - 1)
```

## 复杂度
时间 O(n)：主循环加至多两次 `is_pal` 扫描，总比较次数不超过 2n。
空间 O(1)：只用 `i`、`j`、`l`、`r` 四个下标，无额外字符串切片。

## 易错点
- 输入 `"abca"` 时若只写 `is_pal(i+1, j)` 不写 `or is_pal(i, j-1)`，删 `b` 那条路走不通就误判 `False`；必须两条分支都试，因为失配时无法预知删哪边才对。
- 输入 `"deeee"` 时若在失配后直接 `return is_pal(i+1, j)`，删 `d` 得 `"eeee"` 为真没问题，但换成 `"eedede"` 这类删左不行删右才行的串就会错；正确做法是 `or` 短路，左分支假再算右分支，别提前 `return`。

## 如果面试官追问
问：若允许删 k 个字符呢？答：双指针失配时递归两支、深度计数减一，复杂度升到 O(n·2^k)，k 大时改用区间 DP `dp[i][j]` 存最少删除数。
