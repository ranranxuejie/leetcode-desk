## 一句话思路
用 `dp[i][j]` 表示以 `(i,j)` 为右下角的最大全 1 正方形边长，它同时等于该位置贡献的正方形个数，累加即答案。

## 怎么做
1. 状态转移：`matrix[i][j]==1` 时 `dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])`，取左、上、左上三者的最小值再 +1。
2. 边界处理：第一行、第一列没有完整的三邻居，`dp` 直接等于 `matrix` 本身的值（0 或 1）。
3. 边算边累加：每算出一个 `dp[i][j]` 就加进 `ans`，不需要最后再遍历一遍。

拿示例 1 走一遍关键格：`matrix[2][3]=1`，它的左 `dp[2][2]=2`、上 `dp[1][3]=2`、左上 `dp[1][2]=2`，`min=2`，所以 `dp[2][3]=3`。这个 3 表示以 `(2,3)` 为右下角，边长 1、2、3 的正方形各有一个，一次贡献 3 个，这正是「dp 值 = 贡献个数」的含义。全表累加得 15。

```python
m, n = len(matrix), len(matrix[0])
dp = [[0] * n for _ in range(m)]
ans = 0
for i in range(m):
    for j in range(n):
        if matrix[i][j] == 1:
            if i == 0 or j == 0:
                dp[i][j] = 1
            else:
                dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
            ans += dp[i][j]
return ans
```

## 复杂度
时间 O(m·n)：每个格子常数次比较，m、n 分别是行数、列数。
空间 O(m·n)：开了 m×n 的 `dp` 表；可压成一维 O(n)。

## 易错点
- 输入 `[[1]]` 这种单行单列 → 若漏掉 `i==0 or j==0` 的边界分支，会去访问 `dp[-1][j]`，Python 负索引不报错但取到的是最后一行，结果错成 0 或乱值 → 边界必须先判，直接置 1。
- 输入示例 2 的 `matrix[1][1]=1` → 若把转移写成 `1 + max(...)` 而不是 `min(...)`，会得到 2 而非 1，因为左 `dp[1][0]=1`、上 `dp[0][1]=0`、左上 `dp[0][0]=1`，`max` 取 1 加 1 得 2，但上方缺 1 撑不起边长 2 → 必须取三者最小值，短板决定边长。

## 如果面试官追问
问：空间能否降到 O(n)？
答：能，`dp[j]` 只依赖本行左侧 `dp[j-1]` 和上一行 `dp[j]`、`dp[j-1]`，用两个变量暂存左上角旧值即可滚动。
