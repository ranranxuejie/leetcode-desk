## 一句话思路
用集合记录已见过的数，第二次遇到就 XOR 进答案；每个数最多出现两次，所以「第二次遇到」恰好筛出重复数。

## 怎么做
1. 初始化 `seen = set()` 和 `ans = 0`。
2. 遍历 `nums` 中的每个 `x`：若 `x in seen`，说明这是第二次遇到，执行 `ans ^= x`；否则把 `x` 加入 `seen`。
3. 遍历结束返回 `ans`。

以 `nums = [1,2,2,1]` 为例：处理第一个 `2` 时 `seen = {1,2}`，`ans` 仍为 0；处理第二个 `2` 时命中 `seen`，`ans = 0 ^ 2 = 2`；处理第二个 `1` 时 `ans = 2 ^ 1 = 3`，与示例输出一致。

```python
seen = set()
ans = 0
for x in nums:
    if x in seen:
        ans ^= x
    else:
        seen.add(x)
return ans
```

关键点：`ans ^= x` 只在第二次遇到 `x` 时执行，所以每个重复数恰好被异或一次，不会因为出现两次而被异或两次抵消。示例 1 中 `nums = [1,2,1,3]`，第二个 `1` 触发 `ans = 0 ^ 1 = 1`，`2` 和 `3` 只进 `seen` 不参与异或，返回 1。

## 复杂度
时间 O(n)：遍历 `nums` 一次，集合查找均摊 O(1)。
空间 O(n)：`seen` 最多存 n 个不同值（本题值域 ≤50，实际 ≤50）。

## 易错点
- 输入 `nums = [1,1,1]` 这类（题面保证不会出现，但若放宽）→ 若写成「每次 `x in seen` 都 `ans ^= x`」，第三次遇到 `1` 会把已异或的 `1` 又异或掉，答案错成 0 → 正确做法是命中后仍要保证只异或一次，或用计数判断 `count == 2` 才异或。
- 输入 `nums = [1,2,3]`（无重复）→ 若把 `ans` 初始化为 `nums[0]` 或误在 `else` 分支里也异或，会返回非 0 → 正确做法是 `ans = 0` 起手，只在命中 `seen` 时异或，无命中自然返回 0。

## 如果面试官追问
问：若数字可出现任意次，要求返回所有出现次数为奇数的数的 XOR？
答：直接对全部元素异或即可，出现偶数次的会两两抵消，无需集合。
