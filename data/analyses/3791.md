## 一句话思路
数位 DP 按位填数，用「奇位和减偶位和」的差值做状态，最后差值 0 且位数 ≥2 即平衡。

## 怎么做
1. 写 `solve(x)` 统计 `[1, x]` 的平衡数，答案 `solve(high) - solve(low - 1)`。
2. 状态 `(pos, diff, started, tight)`：`diff` 是已填高位中奇位和减偶位和，`started` 标记是否已出现首位（前导零不算位数）。
3. 位置编号按「从最高位起第 1 位」算，所以填第 `pos` 位时若 `pos` 为奇数就 `diff + d`，偶数就 `diff - d`。
4. 递归到底返回 `started and diff == 0`；`started` 为假说明整个数没填过非零位，不算数。

以 `low=120, high=129` 为例，`solve(129)` 里走到 `pos=1` 填 `1` 后 `diff=1`，`pos=2` 填 `2` 后 `diff=-1`，`pos=3` 填 `1` 后 `diff=0` 且 `started=True`，计入；填 `129` 时 `diff=1-2+9=8` 不计入。区间内只有 `121` 命中。

```python
from functools import lru_cache

def solve(x):
    if x <= 0:
        return 0
    s = str(x)
    n = len(s)
    @lru_cache(None)
    def dfs(pos, diff, started, tight):
        if pos == n:
            return 1 if started and diff == 0 else 0
        up = int(s[pos]) if tight else 9
        res = 0
        for d in range(up + 1):
            ns = started or d != 0
            nd = diff + (d if (pos + 1) % 2 == 1 else -d) if ns else 0
            res += dfs(pos + 1, nd, ns, tight and d == up)
        return res
    return dfs(0, 0, False, True)
```

## 复杂度
时间：`O(len * 差值范围 * 10)`，`len ≤ 16`，差值范围 `[-144, 144]`，即 `O(log(high) * 289 * 10)`。
空间：记忆化表同量级，额外只存 `lru_cache` 的元组，无大数组。

## 易错点
- 输入 `low=1, high=9` → 若漏掉 `started` 判断，一位数 `diff` 恒为 0 会被误计成 9 个平衡数 → 必须要求 `started=True` 且位数 ≥2，一位数一律返回 0。
- 输入 `low=10, high=10` → 若把前导零也当偶数位参与 `diff`，`10` 的 `diff` 会算成 `1-0=1` 或错位成 `0-1`，与真实奇偶位错开 → 前导零不占位，`started` 为假时 `diff` 保持 0，首位一旦出现才按 `pos+1` 的奇偶加减。

## 如果面试官追问
问：`high` 放大到 `10^100` 怎么办？
答：`diff` 范围随位数线性增长到 `±9*len`，状态数 `O(len^2)`，仍可 DP，只是要换成字典或滚动数组存 `diff`。
