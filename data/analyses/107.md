## 一句话思路
BFS 逐层收集后整体反转，或每层插到结果头部；前者更省事。

## 怎么做
1. 空树直接返回 `[]`，否则 `queue = [root]`、`res = []`。
2. 每轮先记 `size = len(queue)`，只弹出这 `size` 个节点，保证一层一层走。
3. 把本层值收进 `level`，子节点入队；`res.append(level)`。
4. 最后 `return res[::-1]`。

以 `root = [3,9,20,null,null,15,7]` 为例：第一轮 `size=1`，弹出 3，`level=[3]`，队列变 `[9,20]`；第二轮 `size=2`，弹出 9、20，`level=[9,20]`，队列变 `[15,7]`；第三轮 `level=[15,7]`。此时 `res = [[3],[9,20],[15,7]]`，反转得 `[[15,7],[9,20],[3]]`。

```python
if not root:
    return []
queue, res = [root], []
while queue:
    size, level = len(queue), []
    for _ in range(size):
        node = queue.pop(0)
        level.append(node.val)
        if node.left:
            queue.append(node.left)
        if node.right:
            queue.append(node.right)
    res.append(level)
return res[::-1]
```

关键在 `size` 必须在 `for` 之前取：循环中 `queue` 会变长，用 `len(queue)` 当条件会把下一层混进来。

## 复杂度
时间 O(n)：每个节点入队出队各一次，`res[::-1]` 只反转层数（≤n）。
空间 O(n)：`queue` 最宽一层最多 n/2 个节点，`res` 存全部 n 个值。

## 易错点
- 输入 `[3,9,20,null,null,15,7]` → 若 `for` 里写 `while queue:` 而不是固定 `size`，第三层 15、7 会和第二层挤进同一个 `level`，输出变成 `[[3],[9,20,15,7]]` → 正确做法是先存 `size = len(queue)` 再循环。
- 输入 `[]` → 若直接 `queue = [root]` 不判空，`root.val` 抛 `AttributeError` → 正确做法是开头 `if not root: return []`，返回空列表而非 `[[]]`。

## 如果面试官追问
追问：不用反转，能否一次到位？
答：每层用 `res.insert(0, level)`，但 list 头部插入是 O(层数) 搬移，层数多时不如末尾追加再 `[::-1]`。
