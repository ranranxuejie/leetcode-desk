## 一句话思路
把 s 折成左半字符计数，用「剩余字符能拼出多少种排列」做逐位试填，按字典序从 'a' 到 'z' 试，用 k 减去整块计数定位。

## 怎么做
1. 统计 `cnt[26]`，取每个字符的一半得 `half[i] = cnt[i] // 2`，奇数个的那个字符留作中位 `mid`（s 是回文，至多一个）。
2. 左半长度 `m = sum(half)`，总排列数 = `m! / prod(half[i]!)`，用组合数逐位累乘算，超过 `k` 就截断到 `k`（防大数）。
3. 从左到右填 `m` 个位置：对每个候选字符 c（'a'→'z' 且 `half[c] > 0`），令 `half[c] -= 1`，算出剩余 `m-1` 个位置的排列数 `ways`；若 `k > ways` 则 `k -= ways`、`half[c] += 1` 继续试下一个，否则选定 c 并保留 `half[c] -= 1`。
4. 左半拼好后，答案 = 左半 + mid + 左半逆序。

以 `s = "abba", k = 2` 为例：`half = {a:1, b:1}`，`m = 2`，总排列数 `2!/(1!1!) = 2`。填第 0 位试 'a'：`half[a]` 变 0，剩余 1 位只有 'b'，`ways = 1`；`k = 2 > 1`，故 `k = 1`、回退 'a'。试 'b'：`ways = 1`，`k = 1 <= 1`，选定 'b'。左半 = "ba"，答案 "ba" + "" + "ab" = "baab"。

```python
from math import comb
def count(half, m):          # 剩余 m 位的排列数，截断到 k
    res, rem = 1, m
    for v in half:
        res *= comb(rem, v)
        rem -= v
        if res >= k: return k
    return res
```

## 复杂度
时间 O(26 · m · 26)，m = n/2，每步试 26 个字符、每次算 26 项组合数。
空间 O(26) 存计数，输出串 O(n)。

## 易错点
- `s = "aa", k = 2`：总排列数只有 1，若不先判 `k > 总数` 就进入试填，会在第 0 位找不到任何 `ways >= k` 的字符而返回错误串；正确做法是先算总数，`k > total` 直接返回 `""`。
- `s = "aabbcc...", k = 10**6`：组合数 `m! / prod` 会极大，Python 虽不溢出但算得慢且无意义；正确做法是 `count` 里一旦 `res >= k` 就 `return k` 截断，因为后续只需比较大小。

## 如果面试官追问
问：若 k 上限提到 10^18 怎么办？
答：截断阈值改成 `k` 本身即可，组合数仍用 `comb` 逐项乘并在 `>= k` 时提前返回，逻辑不变。
