## 一句话思路
按 arr 值从大到小排序后做记忆化 DP：值大的点先算，跳向值小的点必然已算好，dp[i] = 1 + max(dp[j])。

## 怎么做
1. 把下标按 `arr[i]` 降序排序，得到计算顺序。
2. 对每个下标 i，向左右各扫最多 d 步，遇到 `arr[j] >= arr[i]` 立即停（这是"中间不能有更高"的判定）。
3. 对每个合法 j 取 `dp[j]` 最大值，`dp[i] = 1 + best`。
4. 答案取所有 dp 的最大值。

以示例 1 的 `arr = [6,4,14,6,8,13,9,7,10,6,12], d = 2` 为例：排序后先算下标 2（值 14），左右邻居 4、6 都小于 14，`dp[2] = 1 + max(dp[1], dp[3])`；再算下标 5（值 13），左邻 8、右邻 9 都合法，但下标 4 的 8 与下标 6 的 9 之间隔着 13，从 5 出发只能跳到 4 或 6 中较小的那个方向——实际 `dp[5] = 1 + max(dp[4], dp[6])`，而 `dp[6]` 依赖 `dp[7]`（值 7），`dp[7]` 又依赖 `dp[8]`（值 10），链条 10→8→6→7 给出 4。

```python
order = sorted(range(n), key=lambda i: -arr[i])
dp = [1] * n
for i in order:
    for step in (-1, 1):
        for k in range(1, d + 1):
            j = i + step * k
            if j < 0 or j >= n or arr[j] >= arr[i]:
                break
            dp[i] = max(dp[i], 1 + dp[j])
return max(dp)
```

## 复杂度
时间：排序 O(n log n)，每个点最多扫 2d 步，共 O(n·d)，合计 O(n log n + n·d)。
空间：dp 数组 O(n)，排序下标 O(n)，无递归栈。

## 易错点
- `arr = [3,3,3,3,3], d = 3`：若用 `arr[j] > arr[i]` 才 break，会误判相等元素可跳，答案错成 5；正确是 `arr[j] >= arr[i]` 就停，输出 1。
- `arr = [7,1,7,1,7,1], d = 2`：若只检查 j 本身而不在遇到 `arr[j] >= arr[i]` 时 break，会从下标 0 越过下标 2 的 7 跳到下标 3，答案错成 3；正确是遇到 7 立即停，输出 2。

## 如果面试官追问
若 d 增大到 n 且要求输出具体路径？答：DP 时记录每个 i 的最优后继 `nxt[i]`，从 `max(dp)` 的下标沿 nxt 回溯即可，时间不变。
