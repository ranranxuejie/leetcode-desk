## 一句话思路
二分答案 `X`，用 DP 判断能否切成 k 段且每段 XOR 都 ≤ X，可行性对 X 单调。

## 怎么做
1. 预处理前缀 XOR `pre[i] = nums[0]^...^nums[i-1]`，子数组 `[l,r)` 的 XOR 为 `pre[r]^pre[l]`。
2. 二分 `X` 的取值区间 `[0, 2**31 - 1]`（答案必在此范围，因为元素 ≤ 1e9）。
3. 对给定 `X` 做 DP：`f[i][j]` 表示前 `i` 个元素切成 `j` 段是否可行，转移枚举上一刀位置 `p`，要求 `f[p][j-1]` 为真且 `pre[i]^pre[p] <= X`。
4. `f[n][k]` 为真则 `X` 可行，收缩右界。

以示例 1 `nums=[1,2,3], k=2` 为例，`pre=[0,1,3,0]`。试 `X=0`：切 `[1]` 得 XOR 1 > 0，不可行；试 `X=1`：`p=1` 时 `pre[3]^pre[1]=0^1=1 ≤ 1` 且 `f[1][1]` 真，可行，答案 1。

```python
pre = [0]
for v in nums:
    pre.append(pre[-1] ^ v)
n = len(nums)
def ok(X):
    f = [[False] * (k + 1) for _ in range(n + 1)]
    f[0][0] = True
    for i in range(1, n + 1):
        for j in range(1, min(i, k) + 1):
            for p in range(j - 1, i):
                if f[p][j - 1] and (pre[i] ^ pre[p]) <= X:
                    f[i][j] = True
                    break
    return f[n][k]
```

## 复杂度
时间：`O(log(2**31) * k * n^2)`，二分 31 次，每次 DP 是 `k*n^2`。
空间：`O(n*k)` 的 `f` 表，`pre` 占 `O(n)`。

## 易错点
- `k > n` 或某段必须非空：转移里 `p` 从 `j-1` 起、`i` 至少 `j`，否则会把空段算进去，`nums=[1], k=2` 会误判可行。
- 二分上界写成 `max(nums)` 而非 `2**31-1`：`nums=[1,1,2,3,1], k=2` 答案是 0，若下界从 1 起会漏掉 0，必须从 0 开始二分。

## 如果面试官追问
问：n 放大到 1e5 怎么办？答：这题 DP 是 `n^2`，规模一大就得换思路，通常靠贪心或按位贪心逐位确定答案。
