## 一句话思路
逐串判断是否全数字：是就转 int 取值，否则取长度，全程维护最大值。

## 怎么做
1. 初始化 `best = 0`，遍历 `strs` 中每个 `s`。
2. 用 `s.isdigit()` 判定是否只含数字，这一步同时排除了 `"alic3"` 这种混串。
3. 全数字时 `v = int(s)`，否则 `v = len(s)`，再 `best = max(best, v)`。

以示例 1 的 `strs = ["alic3","bob","3","4","00000"]` 为例：`"alic3"` 的 `isdigit()` 为 `False`，取 `len = 5`，`best` 从 0 升到 5；`"00000"` 全数字，`int("00000")` 得 `0`，不会因为长度 5 被误算成 5。

```python
best = 0
for s in strs:
    if s.isdigit():
        v = int(s)
    else:
        v = len(s)
    if v > best:
        best = v
return best
```

关键点：`isdigit()` 对空串返回 `False`，但题目保证 `len >= 1`，无需特判；`int()` 自动吃掉前导零，`"0001"` 得 1，正好对上示例 2 的四个串全为 1。

## 复杂度
时间 O(n·L)：n 为 `strs` 长度，L 为单串最大长度 9，`isdigit` 和 `int` 都扫一遍。
空间 O(1)：只开 `best`、`v` 两个标量，`int(s)` 的临时对象不计入。

## 易错点
- 输入 `["00000"]` → 若用 `len(s)` 当值会得 5，正确是 `int("00000") = 0`；全数字串必须走转换分支，长度只在含字母时才有意义。
- 输入 `["alic3"]` → 若用 `s.isalpha()` 判断字母串会漏掉混串，`"alic3"` 既非纯字母也非纯数字，值应为长度 5；判定条件必须是「全数字」而非「含字母」。

## 如果面试官追问
问：若字符串长度放宽到 10^5，`int(s)` 会不会出问题？
答：Python 大整数无溢出，但转换是 O(L) 且结果可能超 32 位，需按题意决定是否截断或改用长度比较。
