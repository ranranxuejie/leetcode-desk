## 一句话思路
把值域按 `(max-min)//(n-1)` 分桶，最大间距必出现在相邻非空桶之间，桶内差值不会超过桶宽。

## 怎么做
1. 先扫一遍求 `lo=min(nums)`、`hi=max(nums)`，`n<2` 或 `hi==lo` 直接返回 0。
2. 取桶宽 `w = max(1, (hi-lo)//(n-1))`，桶数 `k = (hi-lo)//w + 1`，每桶只存 `(桶内最小, 桶内最大)`。
3. 再扫一遍把每个 `x` 放进 `idx=(x-lo)//w` 号桶，更新该桶的 `mn`/`mx`。
4. 从左到右遍历非空桶，用「当前桶最小 − 上一个非空桶最大」更新答案。

以 `nums=[3,6,9,1]` 为例：`lo=1, hi=9, n=4`，`w=(9-1)//3=2`，`k=5`。分桶后 1→桶0、3→桶1、6→桶2、9→桶4，桶3 为空。相邻非空桶差为 `3-1=2`、`6-3=3`、`9-6=3`，答案 3。

```python
lo, hi = min(nums), max(nums)
if len(nums) < 2 or lo == hi:
    return 0
w = max(1, (hi - lo) // (len(nums) - 1))
k = (hi - lo) // w + 1
mn, mx = [None] * k, [None] * k
for x in nums:
    i = (x - lo) // w
    mn[i] = x if mn[i] is None else min(mn[i], x)
    mx[i] = x if mx[i] is None else max(mx[i], x)
ans, prev = 0, None
for i in range(k):
    if mn[i] is None:
        continue
    if prev is not None:
        ans = max(ans, mn[i] - prev)
    prev = mx[i]
return ans
```

## 复杂度
时间 O(n)：两次扫描数组，桶数 `k ≤ n`，遍历桶也是 O(n)。
空间 O(n)：`mn`/`mx` 两个长度 `k ≤ n` 的数组。

## 易错点
- `nums=[1,1,1,1]` → `hi-lo=0` 时 `(hi-lo)//(n-1)=0`，桶宽为 0 会除零；必须先判 `lo==hi` 返回 0，或写 `max(1, ...)`。
- `nums=[1,2,3,4]` → 桶宽 `(4-1)//3=1`，每个值独占一桶，看似没问题；但若写成 `(hi-lo)//n` 得 0，同样除零，桶宽分母必须是 `n-1`。

## 如果面试官追问
问：为什么最大间距不会落在同一个桶内？
答：桶宽 `w ≤ (hi-lo)/(n-1)`，桶内任意两数差 `< w`，而跨桶至少有一个空桶间隔，鸽巢保证存在跨桶差 `≥ w`。
