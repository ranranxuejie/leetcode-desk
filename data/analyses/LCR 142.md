## 一句话思路
用哑结点加尾指针迭代合并，每次把 `l1`、`l2` 当前较小节点接到尾部，O(m+n) 一次扫完。

## 怎么做
1. 建哑结点 `dummy = ListNode(0)`，`tail = dummy`，避免对头节点单独判空。
2. 循环条件写 `while l1 and l2`，比较 `l1.val` 与 `l2.val`，把小的那个节点整体接到 `tail.next`。
3. 接完把 `tail` 前移到刚接的节点，并把该链表指针后移一格。
4. 循环结束后把非空的那条链整段挂到 `tail.next`，返回 `dummy.next`。

以示例 1 的 `l1=[1,2,4]`、`l2=[1,3,4]` 为例：第一轮 `l1.val=1`、`l2.val=1`，走 `else` 分支接 `l2` 的头节点，此时 `tail` 指向值为 1 的节点、`l2` 前移到值为 3 的节点；下一轮 `1 < 3`，接 `l1` 的头节点，`l1` 前移到值为 2 的节点。注意相等时选哪边都不影响结果，但必须只前移被选中的那一边。

```python
dummy = ListNode(0)
tail = dummy
while l1 and l2:
    if l1.val <= l2.val:
        tail.next = l1
        l1 = l1.next
    else:
        tail.next = l2
        l2 = l2.next
    tail = tail.next
tail.next = l1 if l1 else l2
return dummy.next
```

## 复杂度
时间 O(m+n)：`l1`、`l2` 每个节点恰好被访问一次。
空间 O(1)：只开了 `dummy` 和 `tail` 两个指针，没有新建节点。

## 易错点
1. 输入 `l1=[]`、`l2=[0]` → 若循环写成 `while l1 or l2` 再在循环体内判空，容易在 `l1.val` 上抛 `AttributeError` → 正确做法是用 `while l1 and l2`，循环后一句 `tail.next = l1 if l1 else l2` 收尾。
2. 输入 `l1=[1,2,4]`、`l2=[1,3,4]` → 若写成 `tail = tail.next` 但忘了先 `tail.next = l1`，或接完节点后又 `tail.next = None`，会把后续链截断成 `[1]` → 正确做法是接节点和移 `tail` 成对出现，且全程不碰 `tail.next` 以外的指针。

## 如果面试官追问
问：若要求合并后去重（相同编号只留一个）怎么改？
答：把 `<=` 改成 `<`，相等时同时 `l1 = l1.next; l2 = l2.next`，其余不变。
