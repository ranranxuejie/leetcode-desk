## 一句话思路
把「第 j 小时关门」的代价拆成前缀里 'N' 的个数加后缀里 'Y' 的个数，扫一遍 j 取最小、并列取最早。

## 怎么做
1. 先数出 `totalY = customers.count('Y')`，它等于 j=0 时的后缀 'Y' 数。
2. 令 `leftN = 0`、`rightY = totalY`，从 j=0 开始逐个尝试，`cost = leftN + rightY`。
3. 每次把 j 推进到 j+1 前，用 `customers[j]` 更新两个计数器：是 'N' 则 `leftN += 1`，是 'Y' 则 `rightY -= 1`。
4. 只在 `cost < best` 时更新答案，用严格小于保证并列时保留更早的 j。

以 `customers = "YYNY"` 为例，`totalY = 3`。j=0 时 `leftN=0, rightY=3`，cost=3；处理 `customers[0]='Y'` 后 `rightY=2`；j=1 时 cost=2；处理 `customers[1]='Y'` 后 `rightY=1`；j=2 时 `leftN=0, rightY=1`，cost=1，刷新 best=2。j=3 时 `leftN=1, rightY=1`，cost=2 不刷新，最终返回 2。

```python
totalY = customers.count('Y')
leftN, rightY = 0, totalY
best, ans = totalY, 0          # j = 0 的代价
for j, ch in enumerate(customers):
    if ch == 'N':
        leftN += 1
    else:
        rightY -= 1
    cost = leftN + rightY      # 这是 j+1 时刻关门的代价
    if cost < best:
        best, ans = cost, j + 1
return ans
```

注意循环里 `cost` 对应的是 j+1，不是 j；j=0 的代价在循环外先算好。

## 复杂度
时间 O(n)：`count` 一次加循环一次，各扫 n 个字符。
空间 O(1)：只开了 `totalY`、`leftN`、`rightY`、`best`、`ans` 五个整数。

## 易错点
- 输入 `"NNNNN"` → 若把 j=0 的代价漏算、直接从 j=1 开始比较，会返回 1 而不是 0 → 必须先把 `best = totalY, ans = 0` 作为 j=0 的候选，再进循环。
- 输入 `"YYNY"` → 若用 `cost <= best` 更新，j=4 的 cost=1 会覆盖 j=2 的 1，返回 4 → 必须用严格小于，让并列时保留更早的关门时间。

## 如果面试官追问
问：如果要求返回所有达到最小代价的关门时间？
答：把 `cost < best` 改成 `cost == best` 时 append 到列表、`cost < best` 时清空列表再 append，最后返回整个列表。
