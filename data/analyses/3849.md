## 一句话思路
逐位贪心：s[i]='1' 时优先配 t 中的 '0' 得 1，s[i]='0' 时优先配 '1'，配不到才退而求其次。

## 怎么做
1. 统计 t 中 '0' 和 '1' 的个数，记为 `cnt0`、`cnt1`。
2. 从左到右扫 s，每一位按 s[i] 决定优先消耗哪种字符。
3. 优先字符够用就取它（异或得 '1'），否则取另一种（异或得 '0'），并扣减计数。
4. 把每位的异或结果拼成字符串返回。

以示例 2 `s="0110", t="1110"` 为例：初始 `cnt0=1, cnt1=3`。i=0 时 s[0]='0'，优先要 '1'，`cnt1` 从 3 减到 2，得 '1'；i=1 时 s[1]='1'，优先要 '0'，`cnt0` 从 1 减到 0，得 '1'；i=2 时 s[2]='1'，'0' 已耗尽，只能取 '1'，`cnt1` 减到 1，得 '0'；i=3 时 s[3]='0'，取 '1'，`cnt1` 减到 0，得 '1'。结果 `"1101"`。

```python
cnt0 = t.count('0')
cnt1 = len(t) - cnt0
res = []
for ch in s:
    if ch == '1':
        if cnt0 > 0:
            cnt0 -= 1
            res.append('1')
        else:
            cnt1 -= 1
            res.append('0')
    else:
        if cnt1 > 0:
            cnt1 -= 1
            res.append('1')
        else:
            cnt0 -= 1
            res.append('0')
return ''.join(res)
```

关键点：s[i]='1' 时只有配 '0' 才得 1，所以 `cnt0` 是这一支的稀缺资源；s[i]='0' 时稀缺资源换成 `cnt1`。两个分支的优先对象互为镜像，别写反。

## 复杂度
时间 O(n)：扫一遍 s，`t.count` 也是 O(n)。
空间 O(n)：`res` 存 n 个字符，`cnt0/cnt1` 是 O(1)。

## 易错点
- 输入 `s="11", t="11"` → 若在 s[i]='1' 时误判「没有 '0' 就跳过扣减」，`cnt1` 不减，后面计数错乱 → 正确做法是取不到优先字符时必须扣减另一种字符的计数，本例两位都得 '0'，输出 `"00"`。
- 输入 `s="0", t="0"` → 若把「优先 '1'」写成「有 '1' 才输出 '1'，否则输出空」会漏位 → 正确做法是每个 s 位必定消耗一个 t 字符，`cnt0+cnt1` 恒等于剩余长度，输出长度必须等于 n。

## 如果面试官追问
问：如果要求返回具体的 t 重排方案而不只是异或结果？
答：在贪心时同步记录每位选中的字符，按序拼起来就是重排后的 t，正确性由同一贪心保证。
