## 一句话思路
把 x 的二进制 0 位当作「可填位」，用 n-1 的二进制从低到高填进去，答案就是 x 或上这些位。

## 怎么做
1. 所有 nums[i] 都必须包含 x 的全部 1 位（否则 AND 结果会丢位），所以每个数形如 `x | 自由位`。
2. 要让 AND 恰好等于 x，只需保证每个 x 的 0 位在某个数里是 0；取最小方案时，让 nums[0]=x，其余数只在 x 的 0 位上做文章。
3. 于是问题变成：在 x 的 0 位位置上，按从小到大生成 n-1 个不同的「自由位组合」，第 n-1 个组合就是 n-1 的二进制展开。
4. 具体做法：遍历 x 的每个 0 位（从低位到高位），若 n-1 的当前位是 1，就把答案的这一位置 1。

以 n=3, x=4（二进制 100）为例：n-1=2（二进制 10）。x 的 0 位依次是 bit0、bit1、bit2…；n-1 的 bit0=0 跳过，bit1=1 则把答案 bit1 置 1，得 `100 | 010 = 110 = 6`。

```python
def minEnd(n, x):
    n -= 1
    ans = x
    bit = 0
    while n:
        if not (x >> bit) & 1:      # x 的这一位是 0，可以填
            ans |= (n & 1) << bit
            n >>= 1
        bit += 1
    return ans
```

关键中间值：循环中 `bit` 扫过 x 的 0 位，`n & 1` 决定该位填 0 还是 1，`ans` 逐步累积。

## 复杂度
时间：O(log x + log n)，循环次数约为 x 的位数加 n 的位数。
空间：O(1)，只用了 ans、bit、n 三个整型变量。

## 易错点
- n=1 时：若直接进入循环，n-1=0 使 while 不执行，返回 x 正确；但若写成先置位再判断，会多填一位得到错误值。正确做法是先 `n -= 1` 再进循环。
- x 高位全 1 时（如 x=7=111）：0 位从 bit3 才开始，若循环条件写成 `bit < 32` 固定上界，n 较大时会漏填高位。正确做法是用 `while n` 驱动，n 归零即停，不设固定位宽。

## 如果面试官追问
问：若要求输出整个数组而非仅最后一个元素？
答：对 k=0..n-1 各做一次「把 k 的二进制填进 x 的 0 位」，得到 n 个递增数，AND 仍为 x。
