## 一句话思路
双指针维护剩余最小/最大值，遇 `I` 取小端、遇 `D` 取大端，最后补上剩下的那个数。

## 怎么做
1. 设 `lo=0`、`hi=n`（`n=len(s)`），结果数组 `res` 长度 `n+1`。
2. 遍历 `s` 的每个字符 `c`：`c=='I'` 时把 `lo` 追加进 `res` 并 `lo+=1`，否则把 `hi` 追加进 `res` 并 `hi-=1`。
3. 循环结束后 `lo==hi`，把 `lo` 追加为最后一个元素。

以 `s="IDID"`（n=4）为例，初始 `lo=0, hi=4`：
- `'I'` → 取 0，`lo=1`，res=[0]
- `'D'` → 取 4，`hi=3`，res=[0,4]
- `'I'` → 取 1，`lo=2`，res=[0,4,1]
- `'D'` → 取 3，`hi=2`，res=[0,4,1,3]
- 收尾补 `lo=2`，得 `[0,4,1,3,2]`，与示例一致。

关键中间值：第 2 步结束时 `lo=1, hi=3`，剩余可用数字是 `{1,2,3}`，两端都还在，所以后面无论来 `I` 还是 `D` 都有数可取。

```python
lo, hi = 0, len(s)
res = []
for c in s:
    if c == 'I':
        res.append(lo)
        lo += 1
    else:
        res.append(hi)
        hi -= 1
res.append(lo)
return res
```

为什么成立：当前剩余区间 `[lo, hi]` 里，取 `lo` 一定小于后面任何还没用的数，满足 `I`；取 `hi` 一定大于后面任何还没用的数，满足 `D`。每一步都只消耗一个端点，区间始终连续，所以不会出现「取了 lo 之后下一步要 D 却无大数可用」的情况。

## 复杂度
时间 O(n)：遍历 `s` 一次，n 为 `len(s)`。
空间 O(n)：`res` 存 n+1 个整数，双指针是 O(1)。

## 易错点
- 输入 `s="III"` 时若先处理 `D` 分支或把 `lo/hi` 初值写成 `0, n-1`，最后一位会重复或越界；正确做法是 `hi` 初值取 `len(s)`，循环后单独补 `lo`，得到 `[0,1,2,3]`。
- 输入 `s="DDI"` 时若把 `'D'` 也取 `lo`，会得到递增序列，与 `perm[0]>perm[1]` 矛盾；正确做法是 `'D'` 必须取当前 `hi`，示例输出 `[3,2,0,1]` 正是先连取 3、2 再取 0。

## 如果面试官追问
问：若要求返回字典序最小的合法排列怎么办？
答：贪心取端点已保证每步选当前可选的最小值，`I` 取 `lo` 就是最小可行，`D` 取 `hi` 是被迫的，结果即字典序最小。
