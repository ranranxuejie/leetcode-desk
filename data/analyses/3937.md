## 一句话思路
对偶数位、奇数位分别统计余数频率，枚举 x、y 取总代价最小，且 x≠y。

## 怎么做
1. 把 nums 按奇偶下标拆成两组，各自对 k 取余得到余数列表。
2. 对每组统计每个余数 r 的出现次数 cnt，并算出该组全部改成 r 的代价 cost[r] = Σ min((a-r)%k, (r-a)%k)。
3. 取每组代价最小的两个余数（因为 x≠y，只留一个可能被另一组抢走）。
4. 枚举两组各自的前二候选，跳过 x==y 的组合，取 costE[x]+costO[y] 最小。

以示例 1 `nums=[1,4,2,8], k=3` 为例：偶数位是 `[1,2]`，余数 `[1,2]`，cost[1]=0+1=1，cost[2]=1+0=1；奇数位是 `[4,8]`，余数 `[1,2]`，cost[1]=0+1=1，cost[2]=1+0=1。两组最小都是 1，但 x≠y，只能取 (1,2) 或 (2,1)，总代价 1+1=2。

```python
def cost_of(arr, k):
    cnt = [0] * k
    for a in arr:
        cnt[a % k] += 1
    cost = [0] * k
    for r in range(k):
        cost[r] = sum(c * min((v - r) % k, (r - v) % k)
                      for v, c in enumerate(cnt) if c)
    return sorted(range(k), key=lambda r: cost[r])[:2], cost

even = nums[0::2]
odd = nums[1::2]
ce, costE = cost_of(even, k)
co, costO = cost_of(odd, k)
ans = min(costE[x] + costO[y]
          for x in ce for y in co if x != y)
```

## 复杂度
时间：O(n + k²)，n 是遍历 nums 统计余数，k² 是每组算 k 个余数的代价。
空间：O(k)，两个长度 k 的 cnt 与 cost 数组。

## 易错点
- 只取每组最小余数：示例 1 两组最小都是余数 1，若直接相加得 2 却违反 x≠y，实际要退到次小。必须保留前二候选再枚举。
- 代价算成 `abs(a-r)`：k=3、a=8、r=1 时 abs 得 7，正确是 `min((8-1)%3,(1-8)%3)=1`，因为可以跨过 k 的倍数往回走。

## 如果面试官追问
若 k 很大（如 10^9）怎么办？答：只对出现过的余数建哈希表，候选集缩到不同余数个数，复杂度降为 O(n + m²)。
