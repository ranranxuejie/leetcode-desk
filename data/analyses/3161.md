## 一句话思路
用树状数组维护「每个位置到其左侧最近障碍的距离」，查询时二分找 `[0,x]` 内最大空隙并与 `sz` 比较。

## 怎么做
1. 障碍集合初始含 `0`，用有序结构（这里用树状数组做前缀最大值）记录每个位置左侧最近障碍的距离。
2. 插入障碍 `x` 时，找到 `x` 右侧第一个障碍 `r`，把 `(x, r]` 区间的「左邻障碍距离」更新为 `pos - x`。
3. 查询 `[0,x]` 时，取 `x` 左侧最近障碍 `l`，候选空隙为 `x - l` 与 `[0,l]` 内已有最大空隙的较大者。
4. 判断该最大空隙是否 `>= sz`。

以示例 1 `[[1,2],[2,3,3],[2,3,1],[2,2,2]]` 为例：插入 `2` 后，`[0,2]` 空隙为 2，`(2,∞)` 空隙待定；查询 `[2,3,3]` 时 `x=3`，左邻障碍 `l=2`，候选 `3-2=1` 与 `[0,2]` 最大空隙 `2`，取 `2 < 3` 返回 `False`。

```python
# 树状数组维护前缀最大「左邻障碍距离」
def update(i, v):
    while i <= n:
        bit[i] = max(bit[i], v)
        i += i & -i

def query(i):
    res = 0
    while i > 0:
        res = max(res, bit[i])
        i -= i & -i
    return res
```

## 复杂度
时间：每次插入/查询 `O(log n)`，共 `O(q log n)`，`n` 为坐标上界。
空间：树状数组 `O(n)`，障碍集合 `O(q)`。

## 易错点
- 查询 `[2,3,3]` 时若只算 `x - l = 1` 而忽略 `[0,l]` 内已有空隙 `2`，会误判 `False`；正确做法是取两者最大值 `2` 再与 `sz=3` 比较。
- 插入 `x=2` 后若忘记把 `(2, r]` 区间更新，后续查询 `[2,7,5]` 时 `x=7` 的左邻障碍仍是 `0`，会算出空隙 `7` 误判 `True`；正确做法是插入时同步更新右侧区间。

## 如果面试官追问
若坐标范围扩大到 `10^9`，树状数组开不下怎么办？答：改用有序集合 + 线段树动态开点，或离线离散化所有 `x` 后建树。
