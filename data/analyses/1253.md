## 一句话思路
colsum 为 2 的列两行都必须放 1，先扣掉；剩下的 1 全塞给 upper，不够再给 lower，贪心即可。

## 怎么做
1. 先扫一遍 `colsum`：遇到 2 就两行都置 1，同时 `upper -= 1`、`lower -= 1`；遇到 0 两行都置 0。
2. 扫完后若 `upper < 0 or lower < 0`，说明 2 太多，直接返回 `[]`。
3. 再扫一遍，只处理 `colsum[i] == 1` 的列：`upper > 0` 就给第 0 行，否则给第 1 行，并相应减一。
4. 最后若 `upper != 0 or lower != 0`，说明 1 的个数和 upper+lower 对不上，返回 `[]`。

以示例 1 为例：`upper=2, lower=1, colsum=[1,1,1]`。第一遍没有 2，`upper/lower` 不变。第二遍三个 1：第 0 列 `upper=2>0` 给上行，`upper` 变 1；第 1 列 `upper=1>0` 给上行，`upper` 变 0；第 2 列 `upper=0` 给下行，`lower` 变 0。结果 `[[1,1,0],[0,0,1]]`。

```python
n = len(colsum)
ans = [[0] * n for _ in range(2)]
for i, c in enumerate(colsum):
    if c == 2:
        ans[0][i] = ans[1][i] = 1
        upper -= 1
        lower -= 1
if upper < 0 or lower < 0:
    return []
for i, c in enumerate(colsum):
    if c == 1:
        if upper > 0:
            ans[0][i] = 1
            upper -= 1
        else:
            ans[1][i] = 1
            lower -= 1
return ans if upper == 0 and lower == 0 else []
```

## 复杂度
时间：O(n)，两遍扫描 colsum，n 为列数。
空间：O(n)，除返回的 2×n 矩阵外只用了常数个变量。

## 易错点
- 输入 `upper=2, lower=3, colsum=[2,2,1,1]` → 若先处理 1 再处理 2，会把 upper 提前耗光，导致 2 的列无法两行都置 1 → 正确做法是先扣掉所有 2 的列，再分配 1。
- 输入 `upper=1, lower=1, colsum=[2]` → 只检查 `upper<0` 会漏掉 lower 变负 → 必须同时判断 `upper < 0 or lower < 0`，且最后校验两者都归零。

## 如果面试官追问
问：如果要求返回列字典序最小的方案？
答：把 colsum 为 1 的列尽量往后排给 upper，即从右往左分配 1，其余逻辑不变。
