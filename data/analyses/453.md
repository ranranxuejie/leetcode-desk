## 一句话思路
把「n-1 个元素 +1」等价看成「1 个元素 -1」，答案就是每个元素降到最小值所需的差值总和。

## 怎么做
1. 取 `m = min(nums)`，它是唯一不用动的目标值。
2. 对每个 `x` 累加 `x - m`，这就是总操作次数。
3. 用 `sum(nums) - m * len(nums)` 一步算完，避免显式循环。

以 `nums = [1,2,3]` 为例：`m = 1`，`sum = 6`，`len = 3`，答案 `6 - 1*3 = 3`。中间值 `x - m` 分别是 `0,1,2`，和正好 3，与示例输出一致。

```python
def minMoves(nums):
    m = min(nums)
    return sum(nums) - m * len(nums)
```

关键在等价变换：每次让 n-1 个元素 +1，相对差距不变，等价于让剩下那 1 个元素 -1。所以把最大值一路减到最小值，操作数就是所有元素与最小值的差之和。这个变换把「同时改 n-1 个」变成「只改 1 个」，才让求和公式成立。

## 复杂度
时间：O(n)，`min` 和 `sum` 各扫一遍数组。
空间：O(1)，只存 `m` 和累加结果，没有额外数组。

## 易错点
- 输入含负数如 `nums = [-1, 0, 1]` → 若误用「最大值减各元素」会得 3，方向反了 → 正确是降到最小值 `-1`，答案 `0+1+2 = 3`，公式 `sum - m*len` 自动处理负数。
- 输入 `nums = [1,1,1]` → 若先判断「是否已相等」再走循环，容易漏掉返回 0 → 公式直接得 `3 - 1*3 = 0`，无需特判。

## 如果面试官追问
问：若要求输出具体操作序列怎么办？
答：每轮把除当前最小值外的元素各 +1，重复 `sum - m*len` 次，记录每轮被加的下标即可。
