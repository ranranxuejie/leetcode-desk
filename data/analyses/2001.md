## 一句话思路
把每个矩形的宽高比约分成最简分数 `(w//g, h//g)` 当哈希键，同键的矩形两两可互换，边遍历边累加已见同键个数。

## 怎么做
1. 对每个 `[w, h]` 求 `g = gcd(w, h)`，键取 `(w // g, h // g)`。
2. 用字典 `cnt` 记录每个最简比值已出现的次数。
3. 遍历到当前矩形时，先 `ans += cnt.get(key, 0)`，再把 `cnt[key]` 加一——这样每对只算一次。
4. 返回 `ans`。

以示例 1 为例：`[4,8]` 约成 `(1,2)`，`cnt` 空，`ans += 0`；`[3,6]` 也是 `(1,2)`，`ans += 1`；`[10,20]` 键 `(1,2)`，`ans += 2`；`[15,30]` 键 `(1,2)`，`ans += 3`。最终 `ans = 0+1+2+3 = 6`，与输出一致。关键中间值是 `cnt[(1,2)]` 依次变成 1、2、3、4。

```python
from math import gcd
from collections import defaultdict

cnt = defaultdict(int)
ans = 0
for w, h in rectangles:
    g = gcd(w, h)
    key = (w // g, h // g)
    ans += cnt[key]
    cnt[key] += 1
return ans
```

注意不要用 `w / h` 浮点做键：`4/8`、`3/6`、`10/20` 在二进制浮点下未必严格相等，且 `10^5` 量级的比值精度不可靠。

## 复杂度
时间：O(n log C)，n 个矩形各做一次 gcd，C 为宽高上限 10^5。
空间：O(n)，`cnt` 最多存 n 个不同的最简比值键。

## 易错点
- 输入 `[[2,4],[1,2]]` 若直接用 `(w, h)` 原值做键，会得到 `(2,4)` 和 `(1,2)` 两个键，答案错成 0；必须先除以 `gcd` 约分，两者都归到 `(1,2)`，答案才是 1。
- 输入 `[[4,8],[3,6],[10,20],[15,30]]` 若写成「先统计完所有键的次数、最后对每个次数算 `c*(c-1)//2`」，逻辑也对，但若误用 `c*c` 或漏掉 `//2`，会得到 16 或 12 而非 6；正确是组合数 `c*(c-1)//2`，或按上面边遍历边加 `cnt[key]`。

## 如果面试官追问
若要求返回所有可互换矩形对的下标而非计数，怎么改？答：把 `cnt` 的值从计数改成「该键已出现下标列表」，遍历时对列表里每个下标产出一对，空间从 O(n) 升到 O(答案数)。
