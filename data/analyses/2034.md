## 一句话思路
用哈希表存 timestamp→price 支持更正，再用两个堆（带惰性删除）分别维护最高价和最低价。

## 怎么做
1. 维护 `prices` 字典记录每个时间戳的当前价格，`latest` 记录最大时间戳。
2. `update` 时写入 `prices[timestamp] = price`，并更新 `latest = max(latest, timestamp)`。
3. 维护大顶堆 `max_heap` 和小顶堆 `min_heap`，每次 update 都 push `(-price, timestamp)` 和 `(price, timestamp)`。
4. 查询 maximum/minimum 时，弹出堆顶中 `prices[timestamp] != 堆中价格` 的过期项，剩下的堆顶即答案。

以官方示例为例：`update(1,10)`、`update(2,5)` 后 `max_heap` 堆顶是 `(-10,1)`，`maximum()` 返回 10；接着 `update(1,3)` 把 `prices[1]` 改成 3，此时堆顶 `(-10,1)` 已过期（`prices[1]=3≠10`），弹出后堆顶变 `(-5,2)`，`maximum()` 返回 5。

```python
import heapq

def update(self, timestamp, price):
    self.prices[timestamp] = price
    self.latest = max(self.latest, timestamp)
    heapq.heappush(self.max_heap, (-price, timestamp))
    heapq.heappush(self.min_heap, (price, timestamp))

def maximum(self):
    while -self.max_heap[0][0] != self.prices[self.max_heap[0][1]]:
        heapq.heappop(self.max_heap)
    return -self.max_heap[0][0]
```

## 复杂度
时间：update 为 O(log n)，maximum/minimum 均摊 O(log n)，current 为 O(1)。
空间：O(n)，`prices` 存 n 条记录，两个堆各最多 n 项。

## 易错点
- 同一时间戳被多次更正 → 堆里残留旧价格的条目，若直接取堆顶会返回已失效的高价（如示例中 10 已被改成 3）→ 必须用 `prices[timestamp]` 校验堆顶，不等就 pop。
- `current()` 依赖最大时间戳而非最后插入的 → 若用「最后一次 update 的 timestamp」当最新，遇到乱序输入（先 update(5,..) 再 update(2,..)）会返回 2 的价格 → 必须用 `latest = max(latest, timestamp)` 维护。

## 如果面试官追问
问：若要求 O(1) 查询 maximum/minimum 怎么办？
答：改用有序结构（如平衡树/SortedList）维护价格多重集，update 时删旧插新，查询取首尾即 O(1)，代价是 update 变 O(log n)。
