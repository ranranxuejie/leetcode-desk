## 一句话思路
逐位取模拆出每位数字，边拆边累加数字和与数字积，最后判断 `n % (s + p) == 0`。

## 怎么做
1. 用 `m = n` 做副本，避免破坏原值，同时初始化 `s = 0`、`p = 1`。
2. 循环 `while m:`，每轮 `d = m % 10` 取出最低位，`s += d`、`p *= d`，再 `m //= 10`。
3. 循环结束后 `total = s + p`，返回 `n % total == 0`。

以 `n = 99` 为例：第一轮 `d = 9`，`s = 9`、`p = 9`、`m = 9`；第二轮 `d = 9`，`s = 18`、`p = 81`、`m = 0`；`total = 99`，`99 % 99 == 0` 返回 `True`。换成 `n = 23`：`s = 5`、`p = 6`、`total = 11`，`23 % 11 == 1` 返回 `False`。

```python
m, s, p = n, 0, 1
while m:
    d = m % 10
    s += d
    p *= d
    m //= 10
return n % (s + p) == 0
```

注意 `p` 初值必须是 `1` 而不是 `0`，否则乘积恒为 0，`total` 退化成数字和，`n = 99` 会算成 `99 % 18`。

## 复杂度
时间：O(log n)，循环次数是 n 的十进制位数，`n <= 10**6` 最多 7 轮。
空间：O(1)，只开了 `m`、`s`、`p`、`d` 四个整数。

## 易错点
- 输入含 0 的数如 `n = 10` → 若把 `p` 初始化为 `0`，`p` 永远是 0，`total = 1 + 0 = 1`，任何数都能整除，全部误判为 `True` → `p` 必须初始化为 `1`，`10` 的正确结果是 `s = 1`、`p = 0`、`total = 1`、`10 % 1 == 0` 返回 `True`，但 `n = 23` 这类无 0 的数会暴露错误。
- 直接用 `n` 做循环变量 → 循环结束时 `n` 已被除到 0，`n % total` 变成 `0 % total == 0`，恒返回 `True` → 必须用副本 `m = n` 拆位，原 `n` 保留到最后的取模判断。

## 如果面试官追问
若 n 放大到 `10**18` 超出 64 位范围怎么办？答：Python 整数无溢出，直接沿用同一份代码；若换 C++ 则需用 `long long` 或按字符串逐位处理。
