## 一句话思路
只有超过 k 的那根木材需要切，且最优切法必是切出一段长度 k，成本 = (x-k)*k。

## 怎么做
1. 分别判断 n、m 是否大于 k，只有大于 k 的那根才产生成本。
2. 对超长木材 x，切法固定为 k 和 x-k：因为 x ≤ 2k，切两刀以上只会更贵，而让某段尽量接近 k 能最小化乘积。
3. 累加两根木材的成本返回。

以 n=6, m=5, k=5 为例：n=6>5，切出 len1=1、len2=5，成本 1*5=5；m=5 不切，成本 0；总成本 5。中间值就是 `(6-5)*5 = 5`。

```python
def minCuttingCost(n, m, k):
    ans = 0
    if n > k:
        ans += (n - k) * k
    if m > k:
        ans += (m - k) * k
    return ans
```

关键点：不要写成 `min(len1*len2)` 去枚举切点，x ≤ 2k 保证只有一种切法有意义——切出 k 后剩下的 x-k 必然 ≤ k，两段都能上车，无需再切。

## 复杂度
时间：O(1)，只做两次比较和一次乘法。
空间：O(1)，没有开任何额外数组或容器。

## 易错点
- 输入 n=4, m=4, k=6 → 若误以为「总要切一刀凑三辆车」而返回非 0 → 正确做法是两根都 ≤ k 时直接返回 0，题目允许空车。
- 输入 n=10, m=10, k=6（n、m 都超 k）→ 若只处理一根或写成 `max(n,m)` 的差 → 正确做法是两根各自独立判断、各自累加 `(x-k)*k`，得到 24+24=48。

## 如果面试官追问
问：若 n、m 可到 3k 甚至更大，切法怎么变？
答：单根 x 需切成 ⌈x/k⌉ 段，最优是尽量均分，成本用「总和平方减平方和」除以 2 的公式算，不能再固定切 k。
