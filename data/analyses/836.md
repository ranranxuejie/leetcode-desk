## 一句话思路
把「重叠」转成「两个方向上的开区间都相交」，用 `max(左) < min(右)` 判定，严格小于正好排除边/角接触。

## 怎么做
1. 记 `rec1 = [x1,y1,x2,y2]`、`rec2 = [x3,y3,x4,y4]`，只比较 x 区间和 y 区间。
2. x 方向相交条件：`max(x1, x3) < min(x2, x4)`。
3. y 方向相交条件：`max(y1, y3) < min(y2, y4)`。
4. 两者同时成立才返回 `True`。

拿示例 1 走一遍：`rec1=[0,0,2,2]`，`rec2=[1,1,3,3]`。x 方向 `max(0,1)=1`，`min(2,3)=2`，`1 < 2` 成立；y 方向 `max(0,1)=1`，`min(2,3)=2`，同样成立，返回 `True`。再看示例 2：`rec1=[0,0,1,1]`，`rec2=[1,0,2,1]`，x 方向 `max(0,1)=1`，`min(1,2)=1`，`1 < 1` 为假，直接返回 `False`——这正是「共边不算重叠」被严格小于挡掉的地方。

```python
def isRectangleOverlap(rec1, rec2):
    x1, y1, x2, y2 = rec1
    x3, y3, x4, y4 = rec2
    overlap_x = max(x1, x3) < min(x2, x4)
    overlap_y = max(y1, y3) < min(y2, y4)
    return overlap_x and overlap_y
```

关键就一行：`max(左端点) < min(右端点)`。左端点取大、右端点取小，得到的是交集区间；区间长度为正才算真重叠。两个方向都满足，交集才是一个正面积矩形。

## 复杂度
时间：O(1)，只做 4 次比较和 4 次 max/min，与坐标值无关。
空间：O(1)，只用了 `overlap_x`、`overlap_y` 两个布尔量。

## 易错点
1. 把 `<` 写成 `<=`：输入 `rec1=[0,0,1,1]`、`rec2=[1,0,2,1]` 时，x 方向 `max=1`、`min=1`，用 `<=` 会判成重叠，返回 `True`，但正确答案是 `False`（共边、面积为 0）。必须用严格小于。
2. 只判一个方向就返回：输入 `rec1=[0,0,2,2]`、`rec2=[1,3,3,5]`，x 方向 `1 < 2` 成立，若此时直接 `return True` 就错了；y 方向 `max(0,3)=3`、`min(2,5)=2`，`3 < 2` 为假，两矩形上下分离。必须 `overlap_x and overlap_y` 同时成立。

## 如果面试官追问
问：如果矩形可能是旋转的（任意四边形）怎么办？
答：轴对齐的区间比较失效，改用分离轴定理，对两个矩形的每条边法线做投影判交。
