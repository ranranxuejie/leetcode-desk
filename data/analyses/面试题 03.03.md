## 一句话思路
用 `stacks` 列表存多个子栈，每个子栈是 Python list，`cap` 固定容量；push 满了就新开，pop/popAt 空了就删栈。

## 怎么做
1. 初始化 `self.cap = cap`、`self.stacks = []`；`cap == 0` 时所有 push 直接丢弃。
2. push：若 `stacks` 为空或 `len(stacks[-1]) == cap`，先 `stacks.append([])`，再 `stacks[-1].append(v)`。
3. pop：若 `stacks` 为空返回 `-1`；否则从 `stacks[-1]` 弹出，弹完若该栈空则 `stacks.pop()`。
4. popAt(i)：若 `i >= len(stacks)` 返回 `-1`；否则从 `stacks[i]` 弹出，弹空则 `del stacks[i]`。

以示例 2 为例，`cap = 2`，push 1、2、3 后 `stacks = [[1,2],[3]]`。第一次 `popAt(0)` 从 `[1,2]` 弹出 `2`，栈变为 `[[1],[3]]`（不删，因为非空）；第二次 `popAt(0)` 弹出 `1`，`[1]` 变空被 `del`，`stacks = [[3]]`；第三次 `popAt(0)` 弹出 `3`，返回 `3`，`stacks = []`。注意这里**不要求**把后面的栈往前补位，题目只要求「按指定子栈 pop」。

```python
def push(self, v):
    if self.cap == 0:
        return
    if not self.stacks or len(self.stacks[-1]) == self.cap:
        self.stacks.append([])
    self.stacks[-1].append(v)

def popAt(self, i):
    if i >= len(self.stacks):
        return -1
    v = self.stacks[i].pop()
    if not self.stacks[i]:
        del self.stacks[i]
    return v
```

## 复杂度
时间：push/pop 均摊 O(1)，popAt 的 `del` 需移动后续栈引用，O(栈个数)。
空间：O(n) 存全部元素，额外只有 `stacks` 列表的栈引用开销。

## 易错点
- `cap == 0` 时 push 1、2 再 pop → 若没特判会 `stacks.append([])` 后 `append` 成功，pop 返回 `2` 而非 `-1`；正确做法是 push 开头直接 `return`，让 `stacks` 始终为空。
- `popAt(0)` 弹空后不删栈 → 示例 2 中 `[1]` 弹空后若保留空 list，下次 `popAt(0)` 会对空栈 `pop()` 抛异常；正确做法是弹完立即 `if not self.stacks[i]: del self.stacks[i]`。

## 如果面试官追问
若要求 popAt 后把后续栈元素前移补满（像「盘子堆」进阶版）？答：需从 `i` 往后逐栈搬一个元素，popAt 变 O(n)，用 `collections.deque` 存子栈可优化头部删除。
