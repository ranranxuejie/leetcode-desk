## 一句话思路
k≥2 时前 k 个字符可任意置换，答案就是全串排序；k=1 时只能整体循环左移，取所有 n 个旋转里最小的。

## 怎么做
1. 先判 `k >= 2`，直接 `return ''.join(sorted(s))`。
2. 否则枚举 `s` 的每个循环左移 `s[i:] + s[:i]`，取字典序最小者。
3. 用 `min` 一次扫完，避免手写比较。

以 `s = "cba", k = 1` 为例：三个旋转是 `"cba"`、`"bac"`、`"acb"`，`min` 返回 `"acb"`，与示例一致。

```python
def orderlyQueue(s, k):
    if k >= 2:
        return ''.join(sorted(s))
    n = len(s)
    best = s
    for i in range(1, n):
        cur = s[i:] + s[:i]
        if cur < best:
            best = cur
    return best
```

k≥2 的成立理由：前 k 个位置里能把任意字符挪到队尾，等价于对前 k 个做任意排列，配合反复搬运可把整串排成升序。

## 复杂度
时间：k≥2 时排序 O(n log n)；k=1 时 O(n²)，n 个旋转各比较 O(n)。
空间：k=1 每轮新建长度 n 的字符串，额外 O(n)（不计输入输出）。

## 易错点
- `s = "baaca", k = 3` 若误按 k=1 处理，会返回某个旋转如 `"aacab"`，而正确答案是排序后的 `"aaabc"`；必须先判 `k >= 2` 走排序分支。
- `s = "aaab", k = 1` 若用「找最小字符再取其后缀」的贪心，会漏掉并列最小字符的不同起点；必须枚举全部 n 个旋转再取 `min`。

## 如果面试官追问
问：若 k=1 但 n 到 10⁵ 怎么办？答：用最小表示法（Booth 算法）O(n) 求最小旋转，不必枚举 n 个串。
