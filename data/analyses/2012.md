## 一句话思路
预处理前缀最大值 `pre[i]` 和后缀最小值 `suf[i]`，对每个中间下标 O(1) 判定 2/1/0 三档。

## 怎么做
1. 从左往右扫，`pre[i] = max(pre[i-1], nums[i])`，`pre[0] = nums[0]`。
2. 从右往左扫，`suf[i] = min(suf[i+1], nums[i])`，`suf[n-1] = nums[n-1]`。
3. 对 `i in range(1, n-1)`：若 `pre[i-1] < nums[i] < suf[i+1]` 记 2；否则若 `nums[i-1] < nums[i] < nums[i+1]` 记 1；否则 0。
4. 累加返回。

以 `nums = [2,4,6,4]` 为例：`pre = [2,4,6,6]`，`suf = [2,4,4,4]`。`i=1`：`pre[0]=2 < 4 < suf[2]=4` 不成立（4<4 假），退到 1 档，`2<4<6` 成立，记 1。`i=2`：`pre[1]=4 < 6 < suf[3]=4` 假，且 `4<6<4` 假，记 0。总和 1。

```python
n = len(nums)
pre = [0] * n
suf = [0] * n
pre[0], suf[-1] = nums[0], nums[-1]
for i in range(1, n):
    pre[i] = max(pre[i - 1], nums[i])
for i in range(n - 2, -1, -1):
    suf[i] = min(suf[i + 1], nums[i])
ans = 0
for i in range(1, n - 1):
    if pre[i - 1] < nums[i] < suf[i + 1]:
        ans += 2
    elif nums[i - 1] < nums[i] < nums[i + 1]:
        ans += 1
return ans
```

## 复杂度
时间 O(n)：三次线性扫描，每次 n 个元素。
空间 O(n)：额外开了 `pre`、`suf` 两个长度 n 的数组。

## 易错点
1. 用 `pre[i]` 而不是 `pre[i-1]` 判 2 档 → 对 `[1,2,3]` 的 `i=1`，`pre[1]=2 < 2` 为假，把本该得 2 的判成 1。必须取 `i` 左侧的 `pre[i-1]` 和右侧的 `suf[i+1]`，因为条件要求严格小于/大于所有其他元素，不含自身。
2. 把 1 档写成「不满足 2 档就加 1」→ 对 `[3,2,1]` 的 `i=1` 会错加 1，实际 `2<1` 不成立应为 0。1 档必须独立检查相邻的 `nums[i-1] < nums[i] < nums[i+1]`，两档是并列判定不是兜底。

## 如果面试官追问
问：能否把空间压到 O(1)？
答：可以，先正向算一遍 `pre` 存进结果数组，再反向滚动维护 `suf` 边算边累加，只留一个变量。
