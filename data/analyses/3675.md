## 一句话思路
按字母从 'b' 到 'z' 逐级推进，每级只对当前存在的字母做一次替换，答案就是非 'a' 字母的种类数。

## 怎么做
1. 统计 s 中出现过的字母集合，'a' 不计入。
2. 关键观察：一次操作只能把某个字母整体推进一格，而推进后它可能与已有字母合并，所以不能简单数种类。
3. 但合并只会减少后续工作量，不会增加，因此从 'b' 开始逐级推进到 'z'，每级若该字母存在就计一次操作。
4. 用 `s = "yz"` 走一遍：集合 {y, z}。推进到 y 时存在，计数 1，y→z 与已有 z 合并；推进到 z 时存在，计数 2，z→a。答案 2。

```python
seen = set(s)
ans = 0
for ch in "bcdefghijklmnopqrstuvwxyz":
    if ch in seen:
        ans += 1
        # 推进后 ch 变成下一个字母，可能已存在，无需额外处理
return ans
```

注意上面代码里 `ch` 推进后的新字母若原本不在 `seen` 中，理论上应加入，但由于我们按字母序从小到大遍历，新字母一定大于 `ch`，会在后续循环中被检查到——所以只需判断原始集合即可。这是本题最省事的地方。

## 复杂度
时间：O(n + 26)，n 为 s 长度，用于建集合，26 为固定字母表扫描。
空间：O(26) = O(1)，集合最多存 26 个字符。

## 易错点
- 输入 `s = "az"` → 若把 'a' 也计入种类会错成 2，正确做法是跳过 'a'，答案 1（z→a）。
- 输入 `s = "ba"` → 若认为 b 推进到 a 后与已有 a 合并就少算，会错成 0，正确做法是 b 本身仍需一次操作，答案 1。

## 如果面试官追问
问：如果要求输出具体操作序列怎么办？
答：按同样顺序记录每级推进的字母，遇到合并时跳过已不存在的字母即可。
