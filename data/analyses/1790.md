## 一句话思路
逐位比对，把不相等的位置收集起来，只有「0 个」或「恰好 2 个且交叉相等」才可能一次交换成功。

## 怎么做
1. 遍历下标 `i`，把 `s1[i] != s2[i]` 的位置记进列表 `diff`。
2. 若 `len(diff) == 0`，两串已相等，返回 `True`。
3. 若 `len(diff) != 2`，一次交换最多修好两个位置，直接返回 `False`。
4. 设 `i, j = diff`，检查 `s1[i] == s2[j] and s1[j] == s2[i]`，成立才返回 `True`。

以 `s1 = "bank", s2 = "kanb"` 为例：`i=0` 时 `'b' != 'k'`、`i=3` 时 `'k' != 'b'`，`diff = [0, 3]`；再验 `s1[0]=='b' == s2[3]=='b'` 且 `s1[3]=='k' == s2[0]=='k'`，返回 `True`。

```python
diff = [i for i in range(len(s1)) if s1[i] != s2[i]]
if len(diff) == 0:
    return True
if len(diff) != 2:
    return False
i, j = diff
return s1[i] == s2[j] and s1[j] == s2[i]
```

关键在第三步：`diff` 长度是 1、3、4 时都无解，别只判 `> 2`。

## 复杂度
时间 O(n)：`n = len(s1)`，一次扫描加常数次比较。
空间 O(1)：`diff` 最多存 2 个有用下标，可视为常数（写成列表推导则最坏 O(n)）。

## 易错点
- 输入 `s1 = "abcd", s2 = "dcba"` → 若只判 `len(diff) == 2` 就返回 `True`，会错成 `True`；实际 `diff = [0,1,2,3]` 长度 4，必须先卡长度等于 2。
- 输入 `s1 = "a", s2 = "b"` → 若漏掉「长度必须为 2」而只写 `len(diff) <= 2`，会把长度 1 当成功；正确做法是长度 0 或 2 之外一律 `False`，长度 1 永远修不好。

## 如果面试官追问
问：允许交换 k 次呢？答：统计每个字符在两串中的频次差，`diff` 长度必须为偶数且 ≤ 2k，再按字符配对校验。
