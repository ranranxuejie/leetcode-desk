## 一句话思路
用 `WHERE author_id = viewer_id` 筛出自己看自己的行，再 `DISTINCT` 去重、`ORDER BY` 排序。

## 怎么做
1. 过滤条件写成 `author_id = viewer_id`，因为题面明确同一人的两个 id 相同。
2. 用 `DISTINCT author_id` 去重，示例里 `article_id=3` 那两行都是 `author_id=4, viewer_id=4`，不去重会输出两个 4。
3. 结果列别名成 `id`，按 `author_id` 升序排。
4. 关键中间值：过滤后剩 `(2,7,7)`、`(3,4,4)`、`(3,4,4)` 三行，去重后作者集合是 `{7, 4}`，排序输出 `4, 7`。

```python
# 假设用 pandas 模拟 SQL 语义
df = views[views["author_id"] == views["viewer_id"]]
ids = sorted(df["author_id"].unique())
# ids == [4, 7]
```

对应 SQL：

```sql
SELECT DISTINCT author_id AS id
FROM Views
WHERE author_id = viewer_id
ORDER BY author_id;
```

注意 `ORDER BY` 里写 `author_id` 而不是别名 `id`，虽然多数引擎两者都认，但写原列名更稳。

## 复杂度
时间 O(n log n)：n 是 Views 行数，排序贡献 log n。
空间 O(k)：k 是去重后作者数，用于存结果集。

## 易错点
- 输入含 `(3,4,4)` 重复两行 → 直接 `SELECT author_id` 会输出两个 4 → 必须加 `DISTINCT`。
- 输入里 `(1,3,5)` 这种 `author_id != viewer_id` 的行 → 若漏写 `WHERE` 会把作者 3、5、6、1 全带出来 → 过滤条件必须是 `author_id = viewer_id`，不是 `article_id = viewer_id`。

## 如果面试官追问
追问：如果还要输出该作者浏览自己文章的次数怎么办？
答：去掉 `DISTINCT`，改成 `GROUP BY author_id` 加 `COUNT(*)`，排序不变。
