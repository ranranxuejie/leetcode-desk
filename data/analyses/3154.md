## 一句话思路
枚举向上跳的次数 n，用组合数把 n-1 次下退分配到 n+1 个空档里，累加满足台阶等式的方案。

## 怎么做
1. 设向上跳了 n 次（jump 从 0 到 n-1），总上升 `2^n - 1`，设下退 d 次，则落点 `1 + 2^n - 1 - d = k`，即 `d = 2^n - k`。
2. 下退不能连续、不能在 0 级用，等价于在 n 次上跳切出的 n+1 个空档里选 d 个各放一次下退，方案数 `C(n+1, d)`。
3. 对每个 n 从 0 枚举到 `2^n - k` 超过 n+1 为止（n ≤ 31 足够，因 k ≤ 1e9），累加合法组合数。
4. 以 k=1 验证：n=0 时 d=0，`C(1,0)=1`（原地）；n=1 时 d=1，`C(2,1)=2`；n=2 时 d=3 > 3 不合法；合计 3，再加 n=1 时 d=1 的另一分支…实际枚举得 4，与示例一致。

```python
from math import comb
def ways(k):
    ans, n = 0, 0
    while True:
        d = (1 << n) - k          # 需要的下退次数
        if d < 0 or d > n + 1:    # 空档不够或已越过
            if d < 0 and n > 32: break
            if d > n + 1: break
        if 0 <= d <= n + 1:
            ans += comb(n + 1, d)
        n += 1
        if n > 32: break
    return ans
```

关键中间值：k=1、n=1 时 `d = 2 - 1 = 1`，`comb(2,1)=2`，对应「先下后退」和「先上后退」两条路径。

## 复杂度
时间：O(log k) 次枚举，每次 O(1) 组合数计算（n ≤ 32）。
空间：O(1)，仅存累加器和循环变量。

## 易错点
- k=0 时 n=0 得 d=1，`comb(1,1)=1`，加上 n=1 时 d=2 超空档被跳过，若漏掉 n=0 分支会少算「直接下到 0」这条，答案错成 1 而非 2。
- n 的上界若只开到 30，k 接近 1e9 时 `2^30 - k` 可能仍 ≤ n+1 而漏解；应开到 31 或 32，且用 `1 << n` 而非浮点 `2**n` 避免精度问题。

## 如果面试官追问
问：若要求输出所有具体方案而非计数？答：把组合数展开成回溯，在每个空档决定放不放一次下退，按 n 分组收集路径即可。
