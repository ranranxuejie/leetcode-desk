## 一句话思路
用差分数组在年份轴上做「出生 +1、死亡 −1」，再从左到右累加求前缀和，第一个达到最大值的年份就是答案。

## 怎么做
1. 开一个长度 102 的差分数组 `diff`，下标 `y - 1950` 对应年份 `y`（年份范围 1950~2050）。
2. 对每个人 `[b, d]`：`diff[b-1950] += 1`，`diff[d-1950] -= 1`——死亡当年不计入，所以减在 `d` 而不是 `d+1`。
3. 从 1950 扫到 2050，累加 `cur += diff[i]`，用 `best` 记最大人口、`ans` 记对应年份；只在 `cur > best` 时更新，保证取最早年份。
4. 返回 `ans`。

拿示例 2 `[[1950,1961],[1960,1971],[1970,1981]]` 走一遍关键一步：`diff[0]=1, diff[11]=-1, diff[10]=1, diff[21]=-1, diff[20]=1, diff[31]=-1`。扫描到 1960（`i=10`）时 `cur` 从 1 变 2，`best` 更新为 2、`ans=1960`；到 1970（`i=20`）时 `cur` 先减 1 再加 1 仍是 2，因 `cur > best` 不成立，`ans` 保持 1960。

```python
diff = [0] * 102
for b, d in logs:
    diff[b - 1950] += 1
    diff[d - 1950] -= 1
cur = best = 0
ans = 1950
for i in range(101):
    cur += diff[i]
    if cur > best:
        best = cur
        ans = i + 1950
return ans
```

## 复杂度
时间：O(n + 101)，n 为 `logs` 长度，扫描年份是常数 101。
空间：O(101) 的 `diff` 数组，与 n 无关。

## 易错点
- 把死亡年也计入 → 写成 `diff[d-1950+1] -= 1`，示例 2 中 1960 会算成 3 人、答案错成 1960 之外的年份；正确是减在 `d` 上，因为区间是 `[birth, death-1]`。
- 用 `cur >= best` 更新 → 示例 2 在 1970 也会覆盖 `ans`，输出 1970 而非最早的 1960；必须严格 `cur > best` 才更新。

## 如果面试官追问
若 `logs` 涨到 10^5 且年份跨度到 10^9 怎么办？答：只对出生、死亡年份做离散化排序，在事件点上累加，O(n log n)。
