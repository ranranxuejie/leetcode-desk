## 一句话思路
先 BFS 求每个服务器到 0 的最短距离 d，再对每个数据服务器算它最后一次重发后回复到达的时刻，取全局最大值加 1。

## 怎么做
1. 从 0 出发 BFS，得到 `dist[i]`，即服务器 i 到主服务器单程耗时。
2. 对服务器 i，首个回复在 `2*dist[i]` 秒到达；在此之前它每隔 `patience[i]` 秒重发一次。
3. 最后一次重发的发送时刻是 `((2*dist[i]-1)//patience[i])*patience[i]`，其回复到达时刻为发送时刻 + `2*dist[i]`。
4. 答案取所有数据服务器该值的最大值再加 1。

以示例 1 为例：`dist = [0,1,2]`。服务器 2 的 `2*dist[2]=4`，`patience[2]=1`，最后一次重发时刻 `((4-1)//1)*1=3`，回复到达 `3+4=7`；服务器 1 的 `2*dist[1]=2`，`patience[1]=2`，最后一次重发时刻 `((2-1)//2)*2=0`，到达 `0+2=2`。全局最大 7，答案 8。

```python
from collections import deque
n = len(patience)
g = [[] for _ in range(n)]
for u, v in edges:
    g[u].append(v); g[v].append(u)
dist = [-1] * n
dist[0] = 0
q = deque([0])
while q:
    u = q.popleft()
    for v in g[u]:
        if dist[v] == -1:
            dist[v] = dist[u] + 1
            q.append(v)
ans = 0
for i in range(1, n):
    t = 2 * dist[i]
    last = (t - 1) // patience[i] * patience[i]
    ans = max(ans, last + t)
return ans + 1
```

## 复杂度
时间：BFS 遍历 O(n + m)，m 为边数；逐点计算 O(n)。
空间：邻接表 O(n + m)，`dist` 与队列 O(n)。

## 易错点
- 服务器 1 的 `patience[1]=2`、`2*dist[1]=2`：若用 `t // patience[i]` 算重发次数会多算一次（得 1 次），把最后一次重发时刻错成 2，答案变 9；正确用 `(t-1)//patience[i]`，得 0 次重发。
- 服务器 2 的 `patience[2]=1`：若把答案写成全局最大到达时刻 7 而不加 1，会输出 7；题目问的是「变为空闲的最早秒数」，第 7 秒仍有信息到达，须返回 8。

## 如果面试官追问
若 patience 全为 1 且图是链 0-1-…-(n-1)，答案量级如何？答：最远点 dist=n-1，最后一次重发约 2(n-1)-1，到达约 4(n-1)-1，答案 O(n)，仍在线性范围内。
