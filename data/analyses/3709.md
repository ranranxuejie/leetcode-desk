## 一句话思路
record 时间严格递增，所以维护两个平行数组 `times` 和 `prefix`（前缀和），查询时二分出区间端点相减。

## 怎么做
1. 初始化 `times = []`、`prefix = [0]`，`prefix[i]` 表示前 i 次考试的总分。
2. `record(time, score)` 直接 `times.append(time)`、`prefix.append(prefix[-1] + score)`，因为时间递增，天然有序。
3. `totalScore(startTime, endTime)` 用 `bisect_left(times, startTime)` 得左端点 `l`，用 `bisect_right(times, endTime)` 得右端点 `r`。
4. 返回 `prefix[r] - prefix[l]`，`prefix` 比 `times` 多一个前导 0，下标正好对齐。

以官方示例为例：record(1,98) 后 `times=[1]`、`prefix=[0,98]`；record(5,99) 后 `times=[1,5]`、`prefix=[0,98,197]`。查询 `totalScore(1,3)`：`l = bisect_left([1,5],1) = 0`，`r = bisect_right([1,5],3) = 1`，返回 `prefix[1]-prefix[0] = 98`。查询 `totalScore(3,4)`：`l = 1`、`r = 1`，返回 `prefix[1]-prefix[1] = 0`，正好覆盖「区间内无考试」。

```python
from bisect import bisect_left, bisect_right

class ExamTracker:
    def __init__(self):
        self.times = []
        self.prefix = [0]

    def record(self, time, score):
        self.times.append(time)
        self.prefix.append(self.prefix[-1] + score)

    def totalScore(self, startTime, endTime):
        l = bisect_left(self.times, startTime)
        r = bisect_right(self.times, endTime)
        return self.prefix[r] - self.prefix[l]
```

## 复杂度
时间：record 均摊 O(1)，totalScore 两次二分 O(log n)，n 为已记录考试数。
空间：`times` 与 `prefix` 各存 n 个元素，额外 O(n)。

## 易错点
1. 用 `bisect_left` 求右端点 → 对 `totalScore(1,5)` 会得 `r = bisect_left([1,5],5) = 1`，返回 `prefix[1]-prefix[0] = 98`，漏掉时间 5 的 99 分；右端点必须用 `bisect_right` 才能把等于 endTime 的考试算进去。
2. `prefix` 忘记加前导 0，直接 `prefix[i]` 存第 i 次考试分数 → 对 `totalScore(1,1)` 会算成 `prefix[1]-prefix[0]` 越界或错位；正确做法是 `prefix = [0]` 起手，`prefix[r]-prefix[l]` 天然表示 `times[l:r]` 的和。

## 如果面试官追问
若 record 的 time 不再递增、可乱序插入怎么办？答：改用有序容器（如平衡树/`SortedList`）按 time 插入并维护前缀和，查询仍是二分 O(log n)，插入变 O(log n) 而非 O(1)。
