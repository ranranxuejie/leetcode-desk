## 一句话思路
排序后平衡子数组必是连续一段，用双指针滑窗找最长满足 `nums[r] <= nums[l]*k` 的窗口，答案即 `n - 最长窗口长`。

## 怎么做
1. 先 `nums.sort()`，因为任意平衡集合排序后取最大最小，中间元素全保留不会破坏条件，故最优解对应排序后的连续区间。
2. 左指针 `l` 从 0 起，右指针 `r` 逐个右移，窗口 `[l, r]` 内 `nums[l]` 是最小、`nums[r]` 是最大。
3. 若 `nums[r] > nums[l] * k`，说明 `l` 太小，`l += 1` 直到条件重新成立（`r` 不动，因为缩小左端只会让 `nums[l]*k` 变大）。
4. 每步用 `r - l + 1` 更新最长窗口，最后返回 `len(nums) - best`。

以示例 2 `nums = [1,6,2,9], k = 3` 为例：排序得 `[1,2,6,9]`。`r=2` 时窗口 `[1,2,6]`，`6 > 1*3`，`l` 移到 1，此时 `6 <= 2*3` 成立，窗口长 2；`r=3` 时 `9 > 2*3`，`l` 移到 2，`9 > 6*3` 不成立？实际 `9 <= 6*3=18` 成立，窗口 `[6,9]` 长 2。最长 2，答案 `4-2=2`。

```python
nums.sort()
n = len(nums)
l = best = 0
for r in range(n):
    while nums[r] > nums[l] * k:
        l += 1
    best = max(best, r - l + 1)
return n - best
```

注意 `nums[l] * k` 最大到 `10^9 * 10^5 = 10^14`，Python 整数无溢出问题；若换语言需用 64 位。

## 复杂度
时间 O(n log n)：排序主导，滑窗 O(n) 中 `l`、`r` 各最多走 n 步。
空间 O(1) 额外（不计排序栈），只开了 `l`、`best` 两个变量。

## 易错点
- 输入 `nums = [1,1,1], k = 1`：若把窗口条件写成 `nums[r] < nums[l]*k`（漏等号），会把全相等数组判为不平衡，错答 1；正确是 `<=`，答案 0。
- 输入 `nums = [4,6], k = 2`：若排序后只比较相邻元素或固定窗口长，会漏掉 `6 <= 4*2` 已平衡的事实；必须用双指针动态扩缩，答案 0 而非 1。

## 如果面试官追问
要求输出具体移除哪些元素怎么办？答：记录最长窗口的 `[l, r]`，移除下标不在该区间的元素即可，重复值按排序后位置对应回原下标。
