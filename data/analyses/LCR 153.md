## 一句话思路
DFS 从根往下走，用 path 记录当前路径、remain 记录还差多少，到叶子且 remain 归零时把 path 的副本收进答案。

## 怎么做
1. 空树直接返回 `[]`，否则从 `(root, targetSum)` 开始递归。
2. 进入节点先 `path.append(node.val)`，同时把剩余目标改成 `remain - node.val`。
3. 判断叶子：`node.left is None and node.right is None`，此时若 `remain == 0` 就 `res.append(path[:])`。
4. 递归左右子树后必须 `path.pop()`，把当前节点从路径里撤掉再返回上一层。

拿示例 1 走一遍关键分支：根 5 入 path，remain 变 17；走左子 4，path=[5,4]，remain=13；再走 11，path=[5,4,11]，remain=2；到叶子 2 时 remain 恰好为 0，收下 `[5,4,11,2]`。回溯到 11 后 pop 掉 2，换走右子 7 时 remain 变成 -5，到叶子不为 0，丢弃。

```python
def dfs(node, remain):
    if node is None:
        return
    path.append(node.val)
    remain -= node.val
    if node.left is None and node.right is None and remain == 0:
        res.append(path[:])
    dfs(node.left, remain)
    dfs(node.right, remain)
    path.pop()
```

注意 `path[:]` 是拷贝，直接 append `path` 会让所有结果指向同一个列表，最后全变成空。

## 复杂度
时间 O(n)：每个节点进出各一次，n 为节点总数。
空间 O(h)：递归栈深 h，path 最长 h；答案列表不计入。

## 易错点
- 输入 `root = [1,2]`、`targetSum = 0` → 若在节点 1 处就判断 `remain == 0` 收答案，会错收 `[1]`；必须同时满足「是叶子」才收，节点 1 有左子 2，不是叶子。
- 输入示例 1 这种多分支树 → 若忘了 `path.pop()`，走完 `[5,4,11,2]` 后 path 残留 2，接着访问 7 会得到 `[5,4,11,2,7]` 这种非法路径；每次递归返回前都要 pop 掉本层节点。

## 如果面试官追问
问：节点值有负数，能不能用「remain < 0 就剪枝」？
答：不能，负值会让 remain 先降后升，剪枝会漏掉合法路径，只能靠叶子判断。
