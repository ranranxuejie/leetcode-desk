## 一句话思路
从右往左扫链表，用单调递减栈存「还没找到更大值的候选」，栈顶就是当前节点的答案。

## 怎么做
1. 先把链表值搬进数组 `a`，因为要倒着扫，链表没法反向遍历。
2. 建空栈 `st`（存下标）和 `ans = [0]*n`，从 `i = n-1` 往 0 走。
3. 每个 `a[i]` 先弹栈：`while st and a[st[-1]] <= a[i]: st.pop()`，把不可能再当答案的挤掉。
4. 弹完后栈非空则 `ans[i] = a[st[-1]]`，再把 `i` 压栈。

拿示例 2 `[2,7,4,3,5]` 走一遍：`i=4` 栈空，`ans[4]=0`，压 4；`i=3` 时 `a[4]=5 > 3` 不弹，`ans[3]=5`，压 3；`i=2` 时 `a[3]=3 <= 4` 弹出，`a[4]=5 > 4` 停，`ans[2]=5`；`i=1` 时 `a[2]=4 <= 7` 弹、`a[4]=5 <= 7` 弹，栈空，`ans[1]=0`；`i=0` 时 `a[1]=7 > 2`，`ans[0]=7`。结果 `[7,0,5,5,0]`。

```python
a = []
while head:
    a.append(head.val)
    head = head.next
n = len(a)
ans, st = [0] * n, []
for i in range(n - 1, -1, -1):
    while st and a[st[-1]] <= a[i]:
        st.pop()
    if st:
        ans[i] = a[st[-1]]
    st.append(i)
return ans
```

关键在 `<=`：相等也要弹，因为题目要**严格**大于，`[2,2]` 的答案必须是 `[0,0]` 而不是 `[2,0]`。

## 复杂度
时间 O(n)：每个下标最多进栈一次、出栈一次，共 2n 次操作。
空间 O(n)：数组 `a` 和 `ans` 各 n，栈最坏 n（如严格递减序列）。

## 易错点
- 输入 `[2,2]` → 若写成 `a[st[-1]] < a[i]` 才弹，栈顶的 2 会被当成答案，输出 `[2,0]` → 正确是 `[0,0]`，弹栈条件必须带等号。
- 输入 `[5,4,3]` 这种严格递减 → 若从左往右扫并只维护一个 `max`，会把 5 当成 4 和 3 的答案 → 必须用栈保留「每个位置各自的候选」，倒序扫时栈里始终是右侧递增序列。

## 如果面试官追问
问：链表长度到 10^6、内存紧张怎么办？
答：省掉 `a`，先反转链表再正序扫，栈存节点值而非下标，空间降到 O(栈深)。
