## 一句话思路
把「最多评论数」和「2 月最高均分」拆成两条独立查询，各自用 `ORDER BY 指标 DESC, 名称 ASC LIMIT 1` 取一条，再 `UNION ALL` 拼成单列。

## 怎么做
1. 第一条查询：`MovieRating JOIN Users` 后按 `user_id` 分组，`COUNT(*)` 得评论数，排序键 `(count DESC, name ASC)`。
2. 第二条查询：先 `WHERE created_at BETWEEN '2020-02-01' AND '2020-02-29'` 过滤，再按 `movie_id` 分组算 `AVG(rating)`，排序键 `(avg DESC, title ASC)`。
3. 两条各 `LIMIT 1`，用 `UNION ALL` 合并，列别名统一为 `results`。

以官方示例第一条为例：Daniel 和 Monica 的 `COUNT(*)` 都是 3，`ORDER BY cnt DESC, name ASC` 让 `'Daniel' < 'Monica'` 胜出。第二条中 Frozen 2 与 Joker 的 `AVG(rating)` 都是 `(5+2)/2=3.5` 和 `(3+4)/2=3.5`，靠 `title ASC` 取 Frozen 2。

```python
# 思路示意（SQL 逻辑，非可提交代码）
q1 = """
SELECT u.name AS results
FROM MovieRating m JOIN Users u ON m.user_id = u.user_id
GROUP BY m.user_id
ORDER BY COUNT(*) DESC, u.name ASC
LIMIT 1"""
q2 = """
SELECT mo.title AS results
FROM MovieRating m JOIN Movies mo ON m.movie_id = mo.movie_id
WHERE m.created_at >= '2020-02-01' AND m.created_at < '2020-03-01'
GROUP BY m.movie_id
ORDER BY AVG(m.rating) DESC, mo.title ASC
LIMIT 1"""
final = q1 + " UNION ALL " + q2
```

## 复杂度
时间：两次分组各扫一遍 MovieRating，O(n log n)，n 为评分行数，log n 来自排序。
空间：分组哈希表 O(u + m)，u 为用户数、m 为电影数。

## 易错点
1. 用 `created_at LIKE '2020-02%'` 或 `MONTH(created_at)=2` 过滤 → 前者依赖日期字符串格式，后者丢掉年份，会把 2021 年 2 月的数据算进来；正确写法是 `>= '2020-02-01' AND < '2020-03-01'`，左闭右开避开闰年 29 号边界。
2. 排序只写 `ORDER BY COUNT(*) DESC` 漏掉 `name ASC` → 平局时返回哪一行由引擎决定，示例里可能返回 Monica；必须显式补第二排序键，且 `AVG` 那条要用 `title` 而非 `movie_id`。

## 如果面试官追问
问：如果要求返回所有并列第一而非只取一条？
答：去掉 `LIMIT 1`，改用窗口函数 `RANK() OVER (ORDER BY 指标 DESC)` 再筛 `rn = 1`，两条查询各自包一层子查询后 `UNION ALL`。
