## 一句话思路
把「2 的幂之和的置位数」转成「下标多重集的去重后大小」，再对每个下标计数做组合 DP。

## 怎么做
1. 关键转化：`2^seq[0]+...+2^seq[m-1]` 的置位数 = 序列中**不同下标**的个数（同一幂相加会进位，但这里每个 seq[i] 只贡献一个 2 的幂，重复下标会合并成系数，置位数等于出现过的不同下标数）。所以条件等价于「序列里恰好有 k 个不同的下标」。
2. 于是按「选了哪些下标」分组：若选中的下标集合为 S，|S|=k，则每个 S 内的下标至少出现一次，共 m 个位置，方案数是 `k! * S(m,k)`（第二类斯特林数），且每个方案的乘积都是 `prod(nums[i] for i in S)`。
3. 答案 = `k! * S(m,k) * sum over |S|=k of prod(nums[i])`。后半部分用 DP 求：`f[j]` = 已选 j 个下标的乘积和，遍历 nums 做 0/1 背包式更新 `f[j] += f[j-1]*x`。
4. 以示例 2（m=2,k=2,nums=[5,4,3,2,1]）验证：`S(2,2)=1`，`k!=2`，`sum over |S|=2 of prod = 5*4+5*3+...+2*1 = 85`，`2*85=170`，与输出一致。

```python
MOD = 10**9 + 7
f = [0] * (k + 1)
f[0] = 1
for x in nums:
    for j in range(k, 0, -1):
        f[j] = (f[j] + f[j-1] * x) % MOD
# 第二类斯特林数 S(m,k)
s = [[0]*(k+1) for _ in range(m+1)]
s[0][0] = 1
for i in range(1, m+1):
    for j in range(1, k+1):
        s[i][j] = (s[i-1][j-1] + j * s[i-1][j]) % MOD
fact = 1
for i in range(2, k+1):
    fact = fact * i % MOD
return fact * s[m][k] % MOD * f[k] % MOD
```

## 复杂度
时间：O(n·k + m·k)，n = len(nums)，k ≤ 30。
空间：O(k + m·k)，即 f 数组和斯特林表。

## 易错点
- 把条件当成「二进制恰好 k 位为 1 且互不相同」→ 示例 2 中 [0,0] 这类重复下标序列会被误判为不合法，实际重复下标只算 1 个置位，必须用「不同下标数 = k」判定。
- 忘记乘 `k! * S(m,k)` 只算集合乘积 → 示例 2 会输出 85 而非 170，因为 [0,1] 和 [1,0] 是两个不同序列但同一集合。

## 如果面试官追问
若 m 增大到 10^9 而 k 仍 ≤ 30，怎么办？答：斯特林数改用容斥 `S(m,k)=1/k! * Σ(-1)^i C(k,i)(k-i)^m`，配合快速幂，O(k log m)。
