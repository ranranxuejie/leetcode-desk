## 一句话思路
用四个状态滚动 DP，分别记录「未删、已删」与「当前位取正、取负」的最大交替和，逐元素转移。

## 怎么做
1. 定义 `p0/n0` 为未删除时当前元素取正/取负结尾的最大和，`p1/n1` 为已删除一个元素后的对应值。
2. 每读入 `x`，新取正只能接在取负之后（或单独起头），新取负只能接在取正之后。
3. 删除转移：`p1` 可由「上一轮 `n0` 直接跳过当前元素」得来，即删掉 `x` 后正负号不变。
4. 全程取最大值，答案在四个状态里。

以 `nums = [10,-5,-100]` 为例：处理 `-5` 时 `n0 = 10-(-5) = 15`；处理 `-100` 时 `p1 = max(旧 n0=15, 旧 n1) - (-100)`，其中旧 `n1` 来自删掉 `-5` 后 `10-(-100)=110`，最终 `110`。

```python
NEG = -10**18
p0 = n0 = NEG          # 未删，当前取正 / 取负
p1 = n1 = NEG          # 已删，当前取正 / 取负
ans = NEG
for x in nums:
    np0 = max(p0, n0 + x, x)      # 取正：接负或新起
    nn0 = max(n0, p0 - x, -x)     # 取负：接正或新起
    np1 = max(p1, n1 + x, n0 + x, x)   # 已删后取正，可跳过 x
    nn1 = max(n1, p1 - x, p0 - x, -x)  # 已删后取负，可跳过 x
    p0, n0, p1, n1 = np0, nn0, np1, nn1
    ans = max(ans, p0, n0, p1, n1)
```

## 复杂度
时间：O(n)，一次遍历，n 为 `nums` 长度。
空间：O(1)，只维护四个滚动变量。

## 易错点
- 输入 `[4,7]` → 若只允许「取正接取负」而不允许单元素起头，会漏掉 `[7]` 得 7，错成 4 或负值；正确做法是转移里保留 `x` 和 `-x` 作为新起点。
- 输入 `[10,-5,-100]` → 若删除转移写成「删当前元素后正负翻转」，会把 `110` 算成 `10+(-100)` 之类的错值；正确做法是删元素不改变后续下标奇偶，`p1` 直接继承 `n0`。

## 如果面试官追问
问：若要求输出具体子数组和删除位置？答：在四个状态里各存一个 `(起点, 删除点)` 元组，转移时随最大值一起更新即可。
