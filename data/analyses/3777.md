## 一句话思路
把「相邻相等」记成 1，答案就是区间内相邻相等对数，用线段树维护单点反转带来的差分变化。

## 怎么做
1. 定义 `d[i] = 1 if s[i]==s[i-1] else 0`（`i>=1`），`d[0]=0`；则 `s[l..r]` 的最小删除数 = `sum(d[l+1..r])`，因为每对相邻相等必须删掉其中一个字符。
2. 线段树维护 `d` 的区间和，叶子是 `d[i]`。
3. 类型 1 反转 `s[j]`：只影响 `d[j]` 和 `d[j+1]`（若存在），各重算后单点更新。
4. 类型 2 查询：返回 `query(l+1, r)`，`l==r` 时返回 0。

以示例 2 `s="ABB"` 为例：`d=[0,0,1]`。查询 `[2,0,2]` 取 `sum(d[1..2])=0+1=1`，输出 1。反转 `s[2]` 后 `s="ABA"`，`d[2]` 由 1 变 0，再查得 0。

```python
# 线段树数组 tree，n 为 s 长度
def update(pos):
    i = pos + size
    tree[i] = d[pos]
    i //= 2
    while i:
        tree[i] = tree[2*i] + tree[2*i+1]
        i //= 2

def query(l, r):          # 闭区间
    res, l, r = 0, l + size, r + size
    while l <= r:
        if l & 1: res += tree[l]; l += 1
        if not (r & 1): res += tree[r]; r -= 1
        l //= 2; r //= 2
    return res

# 类型1：s[j] ^= 1，重算 d[j]、d[j+1] 后 update
# 类型2：ans.append(query(l+1, r) if l < r else 0)
```

## 复杂度
时间：每次查询/更新 O(log n)，共 O((n+q) log n)，n 来自建树。
空间：线段树 O(n)，另存 `d` 数组 O(n)。

## 易错点
- 查询 `[2,l,r]` 时误取 `sum(d[l..r])`：`d[l]` 描述的是 `s[l]` 与 `s[l-1]` 的关系，落在区间外，`l=1,r=2` 的 `"BA"` 会被算成 1 而非 0；正确是 `query(l+1, r)`，`l==r` 直接返回 0。
- 反转 `s[j]` 只更新 `d[j]`：漏掉 `d[j+1]`（`j+1<n` 时），如 `"ABB"` 反转 `s[1]` 后 `d[2]` 应从 1 变 0，漏更新会让后续查询多算 1；正确做法是 `j` 与 `j+1` 都重算并 update。

## 如果面试官追问
若要求输出删除后的具体交替串而非次数？答：在区间内贪心保留，遇到 `d[i]==1` 就删 `s[i]`，一次线性扫描即可还原方案。
