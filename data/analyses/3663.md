## 一句话思路
用长度 10 的计数数组统计每个数字出现次数，只在出现过的数字里取「次数最小、数字最小」的那个。

## 怎么做
1. 把 `n` 反复 `% 10` 取末位、`// 10` 去掉末位，累加到 `cnt[10]`。
2. 遍历 `d` 从 0 到 9，跳过 `cnt[d] == 0` 的数字（没出现过不算候选）。
3. 在候选里维护 `best_d` 和 `best_c`，`cnt[d] < best_c` 时更新；因为 `d` 升序遍历，相等时天然保留更小的数字，不需要额外比较。

以 `n = 723344511` 为例，统计后 `cnt = [0,2,1,2,2,1,0,1,0,0]`（下标即数字）。遍历到 `d=1` 时 `best_c=2`；`d=2` 时 `cnt[2]=1 < 2`，更新 `best_d=2, best_c=1`；`d=5` 时 `1 < 1` 不成立，保留 2；`d=7` 同理不更新。返回 2，与示例一致。

```python
cnt = [0] * 10
while n:
    cnt[n % 10] += 1
    n //= 10

best_d, best_c = -1, 10**9
for d in range(10):
    if cnt[d] and cnt[d] < best_c:
        best_d, best_c = d, cnt[d]
return best_d
```

注意 `n` 在 while 里被消耗掉了，如果后面还要用原值，先存一份 `m = n`。

## 复杂度
时间：O(log n)，循环次数等于 `n` 的十进制位数，最多 10 位（`2**31 - 1`）。
空间：O(1)，固定开 10 个计数槽，与 `n` 大小无关。

## 易错点
- 输入 `n = 1000` → 若把 `cnt[d] == 0` 的数字也当候选，会错答 2（或 0 以外的某个没出现的数字）→ 正确做法是 `if cnt[d]` 先过滤，只在出现过的数字里比。
- 输入 `n = 723344511` → 若用 `<=` 更新 `best_c`，`d=5`、`d=7` 会覆盖掉 `d=2`，错答 7 → 正确做法是用严格 `<`，配合 `d` 升序遍历，相等时自动保留最小数字。

## 如果面试官追问
问：如果要求返回所有频率最低的数字（列表）？
答：先扫一遍求出最小频率 `min_c`，再升序收集 `cnt[d] == min_c` 的 `d`，仍是 O(log n)。
