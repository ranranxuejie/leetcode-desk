## 一句话思路
状压 DP 从后往前填：`f[mask][r]` 表示用掉 `mask` 后剩余数能拼出余数 `r` 的方案是否存在，再贪心取最小字典序。

## 怎么做
1. 预处理每个 `nums[i]` 的 `len10[i]`（十进制位数）和 `mod10[i] = 10**len10[i] % k`，以及 `nums[i] % k`。
2. 倒推 DP：`f[mask][r]` 为 `True` 表示「已用集合 `mask`，当前前缀余数 `r`，剩余元素能补成整除」。转移是选一个未用的 `i`，新余数 `(r * mod10[i] + nums[i]) % k`，要求 `f[mask|1<<i][新余数]` 为真。
3. 从 `mask=0, r=0` 出发，每步按 `nums` 值从小到大（同值按下标）试第一个使 `f` 为真的 `i`，追加进答案并更新 `r`，直到 `mask` 满。
4. 若 `f[0][0]` 为假直接返回 `[]`。

以 `nums=[3,12,45], k=5` 为例：`len10=[1,2,2]`，`mod10=[10%5,100%5,100%5]=[0,0,0]`。于是任何转移后余数都等于 `nums[i]%5`，只有 `45%5==0` 能收尾；`f[0][0]` 为真，贪心先试 `3`：`(0*0+3)%5=3`，`f[{3}][3]` 为真，取 3，再取 12，最后 45，得 `[3,12,45]`。

```python
n = len(nums)
mod10 = [pow(10, len(str(x)), k) for x in nums]
f = [[False] * k for _ in range(1 << n)]
f[(1 << n) - 1][0] = True
for mask in range((1 << n) - 2, -1, -1):
    for r in range(k):
        for i in range(n):
            if not mask >> i & 1:
                nr = (r * mod10[i] + nums[i]) % k
                if f[mask | 1 << i][nr]:
                    f[mask][r] = True
                    break
```

## 复杂度
时间 `O(2^n * k * n)`，`n` 来自子集数、`k` 来自余数维、`n` 来自选元素。
空间 `O(2^n * k)` 的布尔表，另存 `mod10` 长度 `n`。

## 易错点
- `nums=[10,5], k=10`：若按原数组顺序贪心先试 10，得 `105` 不整除；必须按数值排序后试，`5` 在前才得 `[5,10]`。排序键用 `(nums[i], i)`，同值保持稳定。
- `nums=[3,12,45], k=5`：若把 `mod10` 写成 `10**len10[i]` 不取模，`n=13` 时数值巨大；虽 Python 不溢出，但 `r * mod10[i]` 会拖慢且无意义，必须先 `% k`。

## 如果面试官追问
问：`n` 放大到 20 还能做吗？
答：状压 `2^20 * k` 已到 10^8 量级，需换 meet-in-the-middle 或放弃精确字典序，先判可行性。
