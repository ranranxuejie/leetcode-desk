## 一句话思路
先算总异或 `x`：`x == 0` 或 `len(nums)` 为偶数时 Alice 必胜，否则必败。

## 怎么做
1. 用 `reduce(xor, nums)` 求全体异或值 `x`，这一步是唯一的计算量。
2. 若 `x == 0`，Alice 轮到时黑板异或已为 0，直接获胜，返回 `True`。
3. 否则看长度奇偶：`len(nums) % 2 == 0` 返回 `True`，奇数返回 `False`。
4. 关键中间值：`nums = [1,1,2]`，`x = 1^1^2 = 2 ≠ 0`，长度 3 为奇数 → `False`，与示例一致；`nums = [1,2,3]`，`x = 0` → 直接 `True`。

```python
from functools import reduce
from operator import xor

def xor_game(nums):
    x = reduce(xor, nums, 0)
    if x == 0:
        return True
    return len(nums) % 2 == 0
```

为什么奇偶能定胜负：设当前黑板异或为 `x ≠ 0`，擦掉 `a` 后剩 `x ^ a`。若 `x ^ a == 0` 即 `a == x`，该玩家立刻输，所以只要 `x` 在黑板里就没人敢擦它。可以证明 `x ≠ 0` 时，`x` 必在剩余数字中（否则全体异或为 0），于是每步都只能擦非 `x` 的数，局面等价于「谁被迫擦到 `x` 谁输」，胜负只由剩余个数奇偶决定，与具体数值无关。

## 复杂度
时间 O(n)：`reduce` 遍历一遍 `nums`，n 为数组长度。
空间 O(1)：只存一个异或累加值 `x`，无额外数组。

## 易错点
- 只判奇偶忘了 `x == 0`：`nums = [1,2,3]` 长度 3 为奇数，若直接返回 `False` 就错，正确是先判 `x == 0` 返回 `True`。
- 把「擦除后异或为 0 则当前玩家失败」理解成「擦除前为 0 就输」：`nums = [0,1]`，`x = 1 ≠ 0`，长度 2 偶数 → `True`；若误判成先手擦 0 后剩 `[1]` 异或为 1 不算输，逻辑就反了，正确是按剩余异或是否为 0 判负。

## 如果面试官追问
问：若要求输出 Alice 的第一步该怎么擦？答：`x == 0` 时任意擦都赢；否则擦任意 `a != x` 的数，把奇偶劣势留给 Bob。
