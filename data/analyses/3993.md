## 一句话思路
贪心：每两步（一上一下）净增 `m-1`，先判断能否先上，再按剩余步数算峰值。

## 怎么做
1. 若 `n == 1`，序列只有 `s`，直接返回 `s`。
2. 判断第一步能否向上：`s + m` 必须能作为 `seq[1]`，且之后要能下降，故需 `m >= 1`（恒成立），但若 `n >= 2` 且想走「先上」路线，`seq[1] = s + m`，`seq[2] = s + m - m = s`，形成 `s, s+m, s` 循环，每 2 步回到 `s`，净增 0。所以真正能累积的是「上-下」对中第二个上峰比前一个上峰高 `m-1`。
3. 设 `k = (n - 1) // 2` 为完整「上-下」对数。若 `n` 为奇数，最后一个元素是上峰；若偶数，最后是下谷。峰值出现在最后一个上峰位置。
4. 用官方示例 `n=4, s=3, m=5`：`k = 3//2 = 1`，完整对 1 组，剩余 1 步是上。第一对：`3 → 8 → 3`（下到 3），第二对起点 3 再上到 `3+5=8`？不对——实际最优是 `3,8,7,12`：`8→7` 只降 1，`7→12` 升 5。关键：下谷不必降到 `s`，只需比上峰低即可，故每次上峰可多爬 `m-1`。峰值 = `s + m + (k-1)*(m-1)` 当最后是上峰；若最后是下谷，峰值是前一个上峰。

```python
def maximumValue(n, s, m):
    if n == 1:
        return s
    # 上峰个数：位置 1,3,5,... 中 <= n-1 的个数
    peaks = (n) // 2          # n=4 -> 2 个上峰(位置1,3)
    # 第一个上峰 = s+m，之后每个上峰比前一个高 m-1
    return s + m + (peaks - 1) * (m - 1)
```

验证 `n=4,s=3,m=5`：`peaks=2`，返回 `3+5+1*4=12` ✓。`n=2,s=4,m=3`：`peaks=1`，返回 `4+3=7` ✓。

## 复杂度
时间：O(1)，只做常数次算术。
空间：O(1)，无额外数组。

## 易错点
- `n=1` 时若仍套公式 `s+m+...` 会返回 `s+m`，错成比 `s` 大的值；正确做法是先特判 `n==1` 返回 `s`。
- 误以为下谷必须回到 `s`，从而算出峰值 `s + m`（不随 `n` 增长）；实际下谷只需低于上峰，每对净增 `m-1`，`n=4,s=3,m=5` 应得 12 而非 8。

## 如果面试官追问
若要求输出具体序列而非最大值？答：按 `s, s+m, s+m-1, s+2m-1, ...` 构造，每步上 `m`、下 `1`，最后一步按奇偶截断即可。
