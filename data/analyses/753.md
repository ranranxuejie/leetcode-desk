## 一句话思路
把 n-1 位前缀当节点、追加一位当有向边，求一条欧拉回路，走遍 k^(n-1) 个节点即覆盖全部 k^n 个密码。

## 怎么做
1. 节点是长度 n-1 的字符串，边是「前缀 + 一位数字」，共 k^n 条边，每个节点出度入度都是 k，图必然存在欧拉回路。
2. 从 `"0"*(n-1)` 出发做 Hierholzer：对每个节点按 0..k-1 顺序递归访问未走过的边，回溯时把这位数字压栈。
3. 递归结束后把栈逆序拼成串，再在最前面补上 n-1 个 `'0'`。

以 n=2,k=2 为例：起点 `"0"`，先走边 `'0'` 到 `"0"`（自环），再走 `'1'` 到 `"1"`，从 `"1"` 走 `'1'` 回 `"1"`、走 `'0'` 回 `"0"`；回溯压栈顺序得到 `"0110"`，补前缀 `'0'` 得 `"00110"`，长度 5 = k^n + n - 1，覆盖 00/01/11/10 四个密码。

```python
def crackSafe(n, k):
    seen = set()
    res = []
    def dfs(node):
        for d in range(k):
            edge = node + str(d)
            if edge not in seen:
                seen.add(edge)
                dfs(edge[1:])
                res.append(str(d))
    dfs("0" * (n - 1))
    return "0" * (n - 1) + "".join(reversed(res))
```

关键点：`seen` 存的是**边**（长度 n 的串）而不是节点，节点会被重复访问，边只走一次。

## 复杂度
时间 O(k^n)：每条边恰好访问一次，递归深度也是 k^n。
空间 O(k^n)：`seen` 存 k^n 条边，`res` 与递归栈同阶；n 只影响单条串长度，不改变量级。

## 易错点
- n=1 时 `"0"*(n-1)` 是空串，节点为空、边就是单个数字，若把 `seen` 建成节点集合会立刻死循环或漏解；正确做法是始终以「边」为去重单位，n=1 时输出长度 k 的串（如 k=2 得 `"01"`）。
- 忘记补前缀：直接返回 `"".join(reversed(res))` 只有 k^n 位，n=2,k=2 时得 `"0110"`，虽然也覆盖全部密码但少了首位，若题目要求最短长度 k^n+n-1 就短了一位；正确做法是返回前拼上 `"0"*(n-1)`。

## 如果面试官追问
若 k^n 大到 10^6 级别怎么办？答：仍用 Hierholzer 但改成显式栈迭代，避免递归深度爆栈，时间空间不变。
