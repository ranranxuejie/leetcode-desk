## 一句话思路
把字母记 +1、数字记 −1 求前缀和，两个相等前缀和之间的区间字母数字数量相等，用哈希表存最早下标。

## 怎么做
1. 遍历 `array`，字母 `+1`、数字 `−1` 累加成 `pre`，`pre == 0` 表示从下标 0 到当前位置平衡。
2. 哈希表 `first` 记录每个 `pre` **第一次**出现的下标（`first[0] = -1` 作为哨兵，代表空前缀）。
3. 若当前 `pre` 已在 `first` 中，区间 `first[pre]+1 .. i` 平衡，长度 `i - first[pre]`，比当前最优长就更新；否则记下 `first[pre] = i`。
4. 只在新长度**严格大于**最优时更新，天然保证并列时保留左端点更小的那个。

以示例 1 为例：`["A","1","B","C","D","2","3","4","E","5",...]`，前 14 个元素字母 7 个、数字 7 个，`pre` 从 0 出发一路变化，到下标 13 时 `pre` 回到 0，长度 `13 - (-1) = 14`，正是输出子数组。而 `first[0] = -1` 这个哨兵是关键：没有它，`pre` 首次归零的区间会被漏掉。

```python
first = {0: -1}
pre = 0
best_l, best_len = 0, 0
for i, x in enumerate(array):
    pre += 1 if x.isalpha() else -1
    if pre in first:
        if i - first[pre] > best_len:
            best_l, best_len = first[pre] + 1, i - first[pre]
    else:
        first[pre] = i
return array[best_l:best_l + best_len]
```

## 复杂度
时间 O(n)：一次遍历，`array` 长度 n 决定。
空间 O(n)：`first` 最多存 n+1 个不同前缀和。

## 易错点
- 输入 `["A","A"]`：`pre` 依次为 1、2，从不重复也不为 0，若忘了 `best_len` 初值 0 直接切片会返回 `["A"]`；正确做法是初值设 0，最后返回空切片。
- 输入 `["A","1"]` 这类首次归零的：若 `first` 不预置 `{0: -1}`，`pre == 0` 时查不到历史下标，会漏掉从下标 0 开始的平衡区间，输出 `[]`；正确做法是初始化 `first = {0: -1}`。

## 如果面试官追问
问：若要求返回所有最长子数组？
答：把「只留一个最优」改成收集所有 `i - first[pre] == best_len` 的区间，最后统一切片返回列表。
