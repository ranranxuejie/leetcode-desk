## 一句话思路
把每头猪的生死序列看成 base-(测试轮数+1) 的一位，猪数就是能编码 buckets 所需的最小位数。

## 怎么做
1. 算轮数 `rounds = minutesToTest // minutesToDie`，每头猪有 `rounds + 1` 种结局（第 1..rounds 轮死，或活到最后）。
2. 答案是最小 `p` 使 `(rounds + 1) ** p >= buckets`，用循环乘到够为止。
3. 以示例 1 为例：`rounds = 60 // 15 = 4`，base = 5；`5**1=5 < 1000`，`5**2=25`，`5**3=125`，`5**4=625`，`5**5=3125 >= 1000`，返回 5。
4. 示例 2：`rounds = 15 // 15 = 1`，base = 2；`2**1=2 < 4`，`2**2=4 >= 4`，返回 2。

```python
rounds = minutesToTest // minutesToDie
base = rounds + 1
pigs = 0
covered = 1
while covered < buckets:
    covered *= base
    pigs += 1
return pigs
```

关键中间值：示例 1 里 `covered` 依次是 5、25、125、625、3125，循环在 `pigs=5` 时退出。

## 复杂度
时间：O(log_base(buckets))，每次乘 base，最多约 10 次。
空间：O(1)，只开 `covered`、`pigs`、`base` 三个整数。

## 易错点
- `minutesToTest = minutesToDie`（示例 2）→ 误以为只能测 0 轮、base 取 1，答案永远凑不够 → 正确是 `rounds = 1`、base = 2，因为第 1 轮喝完还能观察到死。
- `buckets = 1` → 循环条件写成 `covered <= buckets` 会返回 1，实际 0 头猪就够（无需区分）→ 用 `covered < buckets` 起始 `covered = 1`，直接返回 0。
- 用 `math.log(buckets, base)` 再向上取整 → 浮点误差在 `buckets = 125, base = 5` 这类完全幂上可能算出 3.0000000001 取整成 4 → 用整数乘法循环，别碰 log。

## 如果面试官追问
问：要输出具体喂法怎么办？
答：把每桶编号写成 base 进制，第 i 位是第 i 头猪在第几轮喝，位值为 0 表示不喝。
