## 一句话思路
把 wordsContainer 每个串**反转**建字典树，每个节点存「子树里最优下标」，查询时反转 wordsQuery 沿树走到底即可。

## 怎么做
1. 预处理：对每个 `wordsContainer[i]` 反转后插入字典树，节点上记录 `best`。
2. `best` 的比较键是 `(len(wordsContainer[i]), i)` 取最小，即长度短优先、同长取下标小。
3. 插入时**沿途每个节点**都更新 `best`，因为任何前缀（原串的后缀）都可能被查询命中。
4. 查询：反转 `wordsQuery[i]` 从根往下走，能走多远走多远，返回停住处节点的 `best`；根节点 `best` 天然覆盖「公共后缀为空」的情况。

以示例 1 为例：插入 `"abcd"` 反转 `"dcba"`，路径 d→c→b→a 上四个节点 `best` 都是 0；再插 `"bcd"` 反转 `"dcb"`，d、c、b 三节点 `best` 被改成 1（长度 3 < 4）。查询 `"cd"` 反转 `"dc"`，走到 d→c 后下一字符 `'d'` 不存在，停在 c 节点，`best = 1`，输出 1。

```python
def build(words):
    trie = [{}]
    best = [0]
    for i, w in enumerate(words):
        node = 0
        for ch in reversed(w):
            if ch not in trie[node]:
                trie[node][ch] = len(trie)
                trie.append({})
                best.append(i)
            node = trie[node][ch]
            if (len(words[i]), i) < (len(words[best[node]]), best[node]):
                best[node] = i
    return trie, best

def query(trie, best, q):
    node = 0
    for ch in reversed(q):
        if ch not in trie[node]:
            break
        node = trie[node][ch]
    return best[node]
```

## 复杂度
时间：建树 O(Σ|wordsContainer[i]|)，查询 O(Σ|wordsQuery[i]|)，字符集 26 不乘 log。
空间：字典树节点数 = 容器字符总数，额外存 `best` 数组与每节点 dict。

## 易错点
- 只在**串尾节点**更新 `best`：示例 1 查询 `"cd"` 反转 `"dc"` 停在中间节点 c，若 c 节点没存 `best` 就取不到 1，会退化成根节点的答案。必须沿途每个节点都更新。
- 比较键写成 `(len, i)` 但用 `<=` 覆盖：`"abcd"`(0) 与 `"bcd"`(1) 长度不同没问题，但若两个等长串先后插入，用 `<=` 会让**后插入**的下标覆盖前面的，违反「更早出现优先」。必须严格 `<` 才更新。

## 如果面试官追问
若 wordsContainer 长度总和涨到 10^7 且内存吃紧？答：把每节点 dict 换成 26 槽数组会爆内存，改用「按反转串排序 + 二分找最长公共前缀」的离线做法，空间降到 O(n)。
