## 一句话思路
按首字母分组，用「后缀集合」判断两个不同首字母组之间有多少对后缀互换后仍不冲突，累加后乘 2。

## 怎么做
1. 把每个 idea 拆成首字母 `c` 和后缀 `s = idea[1:]`，存进 `groups[c]` 这个 set。
2. 对每对首字母 `c1 < c2`，统计 `groups[c1]` 与 `groups[c2]` 中「后缀相同」的个数 `same`，则这两组能贡献 `(len(g1) - same) * (len(g2) - same)` 对。
3. 因为 A、B 有序（`("coffee","donuts")` 和 `("donuts","coffee")` 算两个），最后答案乘 2。

以 `["coffee","donuts","time","toffee"]` 为例：`groups['c']={'offee'}`，`groups['t']={'ime','offee'}`，`groups['d']={'onuts'}`。`c` 与 `t` 的公共后缀是 `'offee'`，`same=1`，贡献 `(1-1)*(2-1)=0`；`d` 与 `t` 的 `same=0`，贡献 `1*2=2`；`d` 与 `c` 贡献 `1*1=1`。合计 `3`，乘 2 得 `6`。

```python
from collections import defaultdict

groups = defaultdict(set)
for w in ideas:
    groups[w[0]].add(w[1:])

ans = 0
keys = list(groups)
for i in range(len(keys)):
    for j in range(i + 1, len(keys)):
        g1, g2 = groups[keys[i]], groups[keys[j]]
        same = len(g1 & g2)
        ans += (len(g1) - same) * (len(g2) - same)
return ans * 2
```

关键点：`same` 必须用集合交集算，不能只比长度；交集大小就是「交换后仍落在 ideas 里」的冲突对数。

## 复杂度
时间：O(26² × 平均组大小)，即 O(n) 量级，n 为 ideas 长度。
空间：O(n × 后缀长度)，存所有后缀集合。

## 易错点
- 输入 `["lack","back"]`：两组后缀都是 `'ack'`，`same=1`，贡献 `(1-1)*(1-1)=0`，正确输出 0；若漏算 `same` 会错成 `1*1*2=2`。
- 输入含同首字母的多个名字（如 `["aa","ab"]`）：它们同属一组，组内不能配对，因为交换首字母后名字不变、仍在 ideas 中；若把同组也枚举会多算。

## 如果面试官追问
问：若要求输出所有有效公司名字而非计数？答：把 `(len(g1)-same)*(len(g2)-same)` 展开成双重循环，枚举 `g1` 中不在交集的后缀与 `g2` 中不在交集的后缀配对，再补上反向即可。
