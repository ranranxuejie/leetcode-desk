## 一句话思路
按 `teacher_id` 分组后对 `subject_id` 去重计数，因为同一科目可在多个系重复出现。

## 怎么做
1. 先想清楚「科目种类」的粒度是 `subject_id`，不是 `(subject_id, dept_id)` 组合。
2. 用 `GROUP BY teacher_id` 把同一教师的行聚到一起。
3. 在聚合里写 `COUNT(DISTINCT subject_id)`，让重复科目只算一次。
4. 把结果列起别名 `cnt`，与示例输出对齐。

拿官方示例的教师 1 走一遍：他的三行是 `(2,3)`、`(2,4)`、`(3,3)`。若直接 `COUNT(subject_id)` 得 3，因为科目 2 在 3 系和 4 系各出现一次；加上 `DISTINCT` 后中间集合是 `{2, 3}`，计数得 2，正好对上输出里的 `cnt=2`。教师 2 的四行科目是 1、2、3、4，无重复，`DISTINCT` 前后都是 4。

```python
import pandas as pd

def count_unique_subjects(teacher: pd.DataFrame) -> pd.DataFrame:
    res = (
        teacher.groupby("teacher_id")["subject_id"]
        .nunique()
        .reset_index(name="cnt")
    )
    return res
```

`nunique()` 就是 pandas 版的 `COUNT(DISTINCT)`，默认不计 `NaN`；本题 `subject_id` 是主键的一部分，不会有空值，所以无需额外处理。若用 SQL 写，核心一行是 `SELECT teacher_id, COUNT(DISTINCT subject_id) AS cnt FROM Teacher GROUP BY teacher_id`。

## 复杂度
时间：O(n)，n 为 Teacher 行数，分组与去重各扫一遍。
空间：O(k)，k 为不同 `teacher_id` 数，即分组哈希表大小。

## 易错点
- 写成 `COUNT(subject_id)` 而非 `COUNT(DISTINCT subject_id)`：教师 1 的 `(2,3)`、`(2,4)` 两行会让科目 2 被数两次，输出 3 而非 2。必须去重。
- 误按 `(subject_id, dept_id)` 去重或先 `GROUP BY teacher_id, dept_id` 再计数：教师 1 会被拆成 3 系、4 系两组，得到两行而不是一行 `cnt=2`。分组键只能是 `teacher_id`。

## 如果面试官追问
问：若还要输出每位教师教的科目列表而非数量？
答：把 `nunique()` 换成 `lambda s: sorted(s.unique().tolist())`，聚合列变成列表，其余分组逻辑不变。
