## 一句话思路
从高位到低位贪心试填答案 `ans`，用「把每个数补到含 `ans` 的最小值」的代价排序取前 m 小，总代价 ≤ k 就保留该位。

## 怎么做
1. 从第 30 位枚举到第 0 位（`nums[i] ≤ 10^9 < 2^30`），设候选 `cand = ans | (1 << b)`。
2. 对每个 `nums[i]` 算补到「包含 cand 所有位」的最小值 `t`：若 `nums[i] & cand == cand` 则 `t = nums[i]`，否则 `t = (nums[i] | cand) & ~((1 << b) - 1)`，代价 `t - nums[i]`。
3. 把 n 个代价升序排序，取前 m 个求和，≤ k 则 `ans = cand`。
4. 返回 `ans`。

以示例 1 `nums = [3,1,2], k = 8, m = 2` 试第 2 位（值 4）：`cand = 4`，三个数代价分别 1、3、2，排序后前 2 小是 1+2=3 ≤ 8，保留；再试第 1 位得 `cand = 6`，代价 3、5、4，前 2 小 3+4=7 ≤ 8，保留，最终 6。

```python
ans = 0
for b in range(30, -1, -1):
    cand = ans | (1 << b)
    low = (1 << b) - 1
    costs = []
    for x in nums:
        if x & cand == cand:
            costs.append(0)
        else:
            t = (x | cand) & ~low
            costs.append(t - x)
    costs.sort()
    if sum(costs[:m]) <= k:
        ans = cand
return ans
```

## 复杂度
时间：31 轮 × 每轮 O(n log n) 排序，共 O(31 · n log n)。
空间：每轮一个长度 n 的 `costs` 列表，O(n)。

## 易错点
- 用 `x | cand` 直接当目标值：`nums = [3,1,2]`、`cand = 6` 时 `3|6 = 7`，多花 1 次操作，且 7 的按位与不是 6；必须用 `& ~((1<<b)-1)` 把低于 b 的位清零。
- 只对「已含 cand」的数记 0 代价、其余直接跳过：`nums = [1,2,8,4], k = 7, m = 3` 试 `cand = 4` 时若只数 8 和 4，会误判 m 个都凑不齐而放弃 4；正确做法是每个数都算代价，排序后取前 m 个。

## 如果面试官追问
若 k 极大、答案可超过 2^30 怎么办？答：上界取 `max(nums) + k` 的最高位，从该位往下枚举即可。
