## 一句话思路
用一把 `Condition` 配一个 `state` 变量轮转放行，三个线程各自等自己的 `state` 值，输出后把 `state` 交给下一个。

## 怎么做
1. 设 `self.state = 0`，含义是「下一个该谁输出」：0 归 zero，1 归 odd，2 归 even。
2. `zero()` 循环 n 次，每次等 `state == 0`，输出 0 后把 `state` 改成 1 或 2（看下一个数 `i+1` 的奇偶）。
3. `odd()` / `even()` 各自从 `i = 1` / `i = 2` 起，步长 2，每次等 `state` 等于自己的编号，输出 `i` 后把 `state` 置回 0。
4. 每次改完 `state` 都 `notify_all()`，让三个线程重新检查条件。

以 `n = 2` 为例：`state=0` 时 zero 输出 0，`i+1=1` 是奇数，置 `state=1`；odd 醒来输出 1，置 `state=0`；zero 输出 0，`i+1=2` 是偶数，置 `state=2`；even 输出 2，置 `state=0`。得到 `0102`。

```python
import threading

class ZeroEvenOdd:
    def __init__(self, n):
        self.n = n
        self.state = 0
        self.cv = threading.Condition()

    def _wait_turn(self, target):
        with self.cv:
            while self.state != target:
                self.cv.wait()

    def _release(self, nxt):
        with self.cv:
            self.state = nxt
            self.cv.notify_all()
```

`zero` 里就是 `self._wait_turn(0)` → `printNumber(0)` → `self._release(1 if i % 2 == 0 else 2)`，`i` 从 0 到 `n-1`。

## 复杂度
时间：O(n)，共 2n 次输出，每次 O(1) 加一次条件变量唤醒。
空间：O(1)，只开一个 `Condition` 和一个 `state`，与 n 无关。

## 易错点
- `n = 1` 时：若 `zero()` 里写成 `self._release(2 if i % 2 == 0 else 1)` 把奇偶判反，`state` 会置成 2，而 `even()` 从 2 起、`range(2, 2, 2)` 为空直接返回，`odd()` 永远等不到 `state == 1`，程序挂死。正确做法是「下一个数是 `i+1`，奇数放行 odd（1），偶数放行 even（2）」。
- 用 `if self.state != target: wait()` 而不是 `while`：`notify_all()` 会唤醒全部三个线程，被唤醒的线程若不再检查条件就直接往下走，`n = 5` 时可能出现两个线程同时输出、序列变成 `0102030405` 之外的乱序。必须用 `while` 重查 `state`。

## 如果面试官追问
问：不用 `Condition`，只用两个 `Semaphore` 行不行？
答：行，`zero` 持 `zero_sem`、`odd`/`even` 各持一个，输出后 `release` 对方那个，信号量初值 0/1 即可，逻辑等价但少一次广播。
