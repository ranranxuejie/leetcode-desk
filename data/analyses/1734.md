## 一句话思路
先由 1..n 全异或值异或掉 encoded 的奇数下标项，得到 perm[0]，再顺着 encoded 逐项异或还原。

## 怎么做
1. 算出 `total = 1 ^ 2 ^ ... ^ n`，n = len(encoded) + 1。
2. 算出 `odd = encoded[1] ^ encoded[3] ^ ...`（所有奇数下标项），它等于 perm[1]^perm[2]^...^perm[n-1]。
3. `perm[0] = total ^ odd`，因为 total 里 perm[0] 只出现一次、其余项被 odd 抵消。
4. 递推 `perm[i+1] = perm[i] ^ encoded[i]`。

以 `encoded = [3,1]` 为例，n = 3，`total = 1^2^3 = 0`，`odd = encoded[1] = 1`，于是 `perm[0] = 0 ^ 1 = 1`；接着 `perm[1] = 1 ^ 3 = 2`，`perm[2] = 2 ^ 1 = 3`。

```python
n = len(encoded) + 1
total = 0
for v in range(1, n + 1):
    total ^= v
odd = 0
for i in range(1, len(encoded), 2):
    odd ^= encoded[i]
perm = [total ^ odd]
for e in encoded:
    perm.append(perm[-1] ^ e)
```

关键点：`odd` 必须从下标 1 开始隔一个取，取成下标 0 起就变成 perm[0]^perm[1]^...，`total ^ odd` 会直接得到 perm[n-1] 而不是 perm[0]，整条链就反了。

## 复杂度
时间 O(n)：两次线性扫描，n 由 `range(1, n+1)` 和 `encoded` 长度贡献。
空间 O(n)：除返回的 `perm` 外只用了 `total`、`odd` 两个变量。

## 易错点
- `encoded = [6,5,4,6]` 时若把 `odd` 写成从下标 0 起累加，得到 `6^4 = 2`，`total = 1^2^3^4^5 = 1`，`perm[0] = 3`，还原出 `[3,5,1,4,2]`，与答案 `[2,4,1,5,3]` 完全错位——正确做法是 `range(1, len(encoded), 2)` 只取奇数下标。
- n 是奇数这个条件不能省：若 n 为偶数，`total` 里 perm[0] 与其余项无法用「奇数下标异或」干净剥离，`total ^ odd` 不再是单个元素；本题靠 n 为奇数保证 `odd` 恰好覆盖 perm[1..n-1] 共 n-1 项（偶数个），写法上不要改成取偶数下标。

## 如果面试官追问
若 n 可达 10^9 无法枚举 1..n 求 total 怎么办？答：用 `1..n` 异或的周期规律 `n % 4` 分四种情况 O(1) 算出 total，其余步骤不变。
