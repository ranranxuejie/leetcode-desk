## 一句话思路
按行统计 `'1'` 的个数，把非空行串起来，相邻两个非空行的设备数相乘再累加。

## 怎么做
1. 遍历 `bank`，对每行用 `row.count('1')` 得到该行设备数 `cnt`。
2. 跳过 `cnt == 0` 的空行，因为它们不打断激光束，只是被忽略。
3. 维护 `prev` 表示上一个非空行的设备数，遇到新的非空行就累加 `prev * cnt`，再令 `prev = cnt`。

以 `bank = ["011001","000000","010100","001000"]` 为例：第 0 行 `cnt=3`，`prev` 从 0 变 3；第 1 行 `cnt=0` 跳过；第 2 行 `cnt=2`，累加 `3*2=6`，`prev=2`；第 3 行 `cnt=1`，累加 `2*1=2`，总计 8。中间那行全 0 没有切断第 0 行和第 2 行的配对，这正是「跳过空行」而非「遇空行清零」的关键。

```python
prev = ans = 0
for row in bank:
    cnt = row.count('1')
    if cnt == 0:
        continue
    ans += prev * cnt
    prev = cnt
return ans
```

第 0 行时 `prev=0`，`0*3=0`，不会凭空产生光束；这一步保证只有「两个非空行」才配对。

## 复杂度
时间 O(m·n)：每行 `count` 扫一遍 n 个字符，共 m 行。
空间 O(1)：只开了 `prev`、`ans`、`cnt` 三个标量。

## 易错点
- 输入 `["000","111","000"]` → 若把首尾空行也当非空行处理，会算出 `0*3` 或 `3*0` 之外的错误配对；正确做法是 `cnt == 0` 直接 `continue`，`prev` 保持 0，答案 0。
- 输入 `["011001","000000","010100","001000"]` → 若遇空行把 `prev` 清零，第 0 行与第 2 行就配不上，答案会从 8 掉到 2；正确做法是空行只跳过、不清零 `prev`。

## 如果面试官追问
问：若要求输出每条激光束的两端坐标而非数量？答：在累加 `prev * cnt` 时枚举上一非空行的每个 `'1'` 下标与当前行每个 `'1'` 下标配对，复杂度升到 O(答案规模)。
