## 一句话思路
枚举子数组右端点，维护以它为右端点的所有 GCD 值（去重后只有 O(log V) 个），对每个 GCD 贪心翻倍。

## 怎么做
1. 对每个右端点 r，用「以 r-1 结尾的 GCD 集合」与 nums[r] 求 gcd 得到新集合，去重后规模是 O(log V)。
2. 对每个候选 GCD 值 g，统计子数组内有多少个元素满足 `nums[i] % g == 0` 但 `nums[i] % (2g) != 0`（即翻倍后能让 GCD 变成 2g 的「关键元素」）。
3. 若关键元素个数 ≤ k，则该子数组可把 GCD 提到 2g，分数为 `2g * len`；否则 GCD 保持 g，分数为 `g * len`。
4. 对所有 (g, len) 取最大值。

以示例 1 `nums=[2,4], k=1` 为例：r=1 时 GCD 集合含 g=2，子数组 [2,4] 中 `2%2==0 且 2%4!=0`，关键元素是 nums[0]，个数 1 ≤ k=1，故 GCD 可提到 4，分数 `4*2=8`。

```python
from math import gcd
ans = 0
prev = []  # (gcd值, 起始左端点)
for r, x in enumerate(nums):
    cur = [(x, r)]
    for g, l in prev:
        ng = gcd(g, x)
        if cur[-1][0] == ng:
            cur[-1] = (ng, l)
        else:
            cur.append((ng, l))
    for g, l in cur:
        cnt = sum(1 for i in range(l, r + 1)
                  if nums[i] % g == 0 and nums[i] % (2 * g) != 0)
        gg = 2 * g if cnt <= k else g
        ans = max(ans, gg * (r - l + 1))
    prev = cur
```

## 复杂度
时间：O(n · log V · n)，每个右端点 O(log V) 个 GCD，每个 GCD 扫一遍子数组；V 为值域。
空间：O(log V)，只存当前右端点的 GCD 去重列表。

## 易错点
- 输入 `nums=[5,5,5], k=1`：误以为翻倍总能提升 GCD，实际 `5%5==0 且 5%10!=0` 关键元素有 3 个 > k=1，GCD 提不到 10，正确分数是 `5*3=15` 而非 `10*3`。
- 输入 `nums=[3,5,7], k=2`：只枚举整段子数组会漏掉单元素 [7]，翻倍后 `7*2=14` 才是答案；必须枚举所有 (g, len) 组合，不能只取最长子数组。

## 如果面试官追问
若 k 很大（k ≥ n）？答：所有元素都能翻倍，直接对每个子数组算 `2*gcd * len` 取最大，无需统计关键元素。
