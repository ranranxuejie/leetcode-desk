## 一句话思路
一次遍历下标 1 到 n-2，用相邻比较同时判定峰谷，把峰值累加进 `peak`、谷值累加进 `valley`，最后相减。

## 怎么做
1. 初始化 `peak = valley = 0`，循环 `i` 从 `1` 到 `n - 2`。
2. 若 `nums[i] > nums[i-1] and nums[i] > nums[i+1]`，则 `peak += nums[i]`。
3. 若 `nums[i] < nums[i-1] and nums[i] < nums[i+1]`，则 `valley += nums[i]`。
4. 返回 `peak - valley`。

以示例 1 `nums = [1,5,2,4,1,3,0]` 为例：`i=1` 时 `5 > 1 and 5 > 2` 成立，`peak` 变 5；`i=2` 时 `2 < 5 and 2 < 4` 成立，`valley` 变 2；继续扫到 `i=5`，`peak = 5+4+3 = 12`，`valley = 2+1 = 3`，返回 9。

```python
peak = valley = 0
for i in range(1, len(nums) - 1):
    if nums[i] > nums[i - 1] and nums[i] > nums[i + 1]:
        peak += nums[i]
    elif nums[i] < nums[i - 1] and nums[i] < nums[i + 1]:
        valley += nums[i]
return peak - valley
```

注意用 `elif` 而非两个独立 `if`：同一位置不可能既严格大于两侧又严格小于两侧，但写成两个 `if` 会让读者误以为存在这种可能，逻辑上虽不出错，可读性差。

## 复杂度
时间：O(n)，一次遍历，每个下标做两次常数比较。
空间：O(1)，只开了 `peak`、`valley`、`i` 三个变量。

## 易错点
1. 输入含平台如 `[6,5,2,5,5,3,6]` → 若把 `nums[i] >= nums[i+1]` 写成非严格比较，`i=3` 的 `5` 会被误判为峰值（5 ≥ 5 且 5 > 2）→ 必须用严格 `>` 和 `<`，题面要求「大于/小于两侧」。
2. 输入 `[-5,-6,-1,-2,5,3,2]` → 若把初值写成 `peak = valley = 0` 后又用 `max/min` 聚合，负峰值会被 0 吞掉 → 本题是求和不是求极值，直接累加即可，`valley` 为负时相减自然变加。

## 如果面试官追问
若要求返回所有峰谷下标而非差值？答：把 `peak += nums[i]` 换成 `res.append(i)`，两个分支各 append 一次，顺序即下标升序。
