## 一句话思路
按 x 升序、x 相同按 y 降序排序后，对每个 Alice 只统计 y 严格递减的 Bob 序列，用单调栈式扫描避免 O(n³)。

## 怎么做
1. 排序：`points.sort(key=lambda p: (p[0], -p[1]))`，保证 Alice 在 Bob 左边（x 更小或 x 相同但 y 更高）。
2. 枚举 Alice 下标 `i`，向右扫描 `j > i`，维护 `max_y`（已扫过点中 y 的最大值，初始为 Alice 的 y）。
3. 若 `points[j][1] < max_y`，则 Bob 合法（矩形内无其他人），计数加一，并更新 `max_y = points[j][1]`。
4. 若 `points[j][1] >= max_y`，说明该点在当前矩形内或上方，跳过且不更新 `max_y`。

以示例 2 `[[6,2],[4,4],[2,6]]` 排序后为 `[[2,6],[4,4],[6,2]]`。Alice 取 `(2,6)` 时 `max_y=6`，扫到 `(4,4)` 满足 `4<6` 计数 1、`max_y=4`；再扫到 `(6,2)` 满足 `2<4` 计数 2。Alice 取 `(4,4)` 时 `max_y=4`，扫到 `(6,2)` 满足 `2<4` 计数 3？不对——`(2,6)` 在 Alice 左边不参与，实际只计 1 次，总数为 2，与示例一致。

```python
points.sort(key=lambda p: (p[0], -p[1]))
ans = 0
n = len(points)
for i in range(n):
    max_y = points[i][1]
    for j in range(i + 1, n):
        if points[j][1] < max_y:
            ans += 1
            max_y = points[j][1]
return ans
```

## 复杂度
时间：O(n²)，排序 O(n log n) 被 n² 枚举主导，n=1000 时约 10⁶ 次。
空间：O(1) 额外空间（排序原地，仅用 `max_y`、`ans` 等常数变量）。

## 易错点
1. 输入 `[[1,1],[1,3]]`（x 相同）→ 若按 x 升序、y 也升序排，会认为 `(1,1)` 在 `(1,3)` 左边合法，但 Alice 必须在左上角，`(1,1)` 的 y 更小不能当左上角 → 必须 x 相同按 y **降序**，让 y 大的排前面。
2. 输入 `[[1,1],[2,2],[3,3]]` → 若只判断 `points[j][1] < points[i][1]` 而不维护 `max_y`，会把 `(3,3)` 也计入（3 不小于 1 但中间 `(2,2)` 已挡住）→ 必须用 `max_y` 动态收缩，`(2,2)` 更新后 `max_y=2`，`(3,3)` 的 3 不满足 `<2` 被正确排除。

## 如果面试官追问
若 n 扩大到 10⁵ 怎么办？答：按 x 分组后对每组 y 做单调栈统计逆序对，可降到 O(n log n)，但需处理 x 相同的边界。
