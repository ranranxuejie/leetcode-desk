## 一句话思路
枚举左端点、右端点右移时增量维护 26 个字母的频次，每步扫一遍频次数组取最大最小非零值求和。

## 怎么做
1. 外层固定 `i`，内层 `j` 从 `i` 到 `n-1`，用长度 26 的 `cnt` 记录 `s[i..j]` 的字符频次。
2. 每加入 `s[j]` 只做 `cnt[ord(s[j]) - 97] += 1`，不重建数组。
3. 每次更新后遍历 `cnt`，跳过 0，取 `mx - mn` 累加到 `ans`。
4. 以 `s = "aabcb"` 为例：`i=0, j=2` 时 `cnt` 中 a=2、b=1，`mx=2, mn=1`，贡献 1；`i=0, j=4` 时 a=2、b=2、c=1，`mx=2, mn=1`，仍贡献 1，五个非零子串各贡献 1，合计 5。

```python
n = len(s)
ans = 0
for i in range(n):
    cnt = [0] * 26
    for j in range(i, n):
        cnt[ord(s[j]) - 97] += 1
        mx = 0
        mn = n
        for v in cnt:
            if v:
                mx = max(mx, v)
                mn = min(mn, v)
        ans += mx - mn
return ans
```

关键点：`mn` 初值取 `n` 而不是 0，因为 0 表示「该字母未出现」，不能参与最小值比较；`mx` 初值取 0 无妨，因为至少有一个非零频次。

## 复杂度
时间 O(n²·26)：外层 i 与内层 j 共 O(n²) 次，每次扫 26 个频次。
空间 O(26)：只开一个固定长度的 `cnt` 数组，与 n 无关。

## 易错点
- 输入 `s = "aaaa"` → 若把 `cnt` 里的 0 也算进最小值，`mn` 恒为 0，每个子串都算成 `4-0` 之类，答案偏大 → 必须 `if v:` 跳过 0，只统计出现过的字母。
- 输入 `s = "aabcb"` → 若在外层循环外只建一次 `cnt` 而不在 `i` 变化时重置，`i=1` 时还残留 `i=0` 的 a 计数，`mx` 偏大 → 每个新 `i` 都要 `cnt = [0] * 26` 重新开始。

## 如果面试官追问
问：n 放大到 10⁵ 怎么办？
答：O(n²) 不可行，需按「最大频次 f 与最小频次 g」分类，用前缀和/位置表统计每个 (f, g) 对应的子串数，把 26 的因子摊到枚举频次对上。
