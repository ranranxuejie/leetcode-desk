## 一句话思路
从最大数 n 开始逐个归位：先翻到队首，再翻到它该在的位置，每次最多两次翻转。

## 怎么做
1. 令 `size` 从 `len(arr)` 递减到 2，每轮负责把值 `size` 放到下标 `size-1`。
2. 用 `arr.index(size)` 找到它的当前位置 `i`；若 `i == size-1` 已就位，跳过。
3. 若 `i != 0`，翻转 `k = i+1` 把它送到队首；再翻转 `k = size` 把它压到末尾。
4. 记录每次的 `k`，返回列表。

以 `[3,2,4,1]` 为例：`size=4`，`4` 在下标 2，先翻 `k=3` 得 `[4,2,3,1]`，再翻 `k=4` 得 `[1,3,2,4]`，`4` 归位。接着 `size=3`，`3` 在下标 1，翻 `k=2` 得 `[3,1,2,4]`，再翻 `k=3` 得 `[2,1,3,4]`。注意官方示例的翻转序列不同但同样合法，判题接受任意有效方案。

```python
res = []
for size in range(len(arr), 1, -1):
    i = arr.index(size)
    if i == size - 1:
        continue
    if i != 0:
        arr[:i+1] = arr[:i+1][::-1]
        res.append(i + 1)
    arr[:size] = arr[:size][::-1]
    res.append(size)
return res
```

关键点：`arr.index(size)` 必须在每次翻转后重新查，因为翻转会改变下标；`size` 递减保证已归位的尾部不再被碰。

## 复杂度
时间：O(n²)，每轮 `index` 查找 O(n)，共 n 轮。
空间：O(n)，仅结果列表 `res` 最多 2n 个元素，原地翻转不额外开数组。

## 易错点
- 输入 `[1,2,3]` 已有序 → 若不加 `i == size-1` 判断，会对每个已就位元素白翻两次，输出 `[3,3,2,2,1,1]` 之类冗余序列 → 正确做法是先判 `i == size-1` 直接 `continue`。
- 输入 `[2,1]` 这类最大值已在队首的情况 → 若仍先翻 `k=i+1=1`，会做一次无意义的自翻转并把 `k=1` 记进结果 → 正确做法是 `i == 0` 时跳过第一次翻转，只翻 `k=size`。

## 如果面试官追问
问：能否保证翻转次数不超过 2n-3？
答：能，每轮最多 2 次、共 n-1 轮，且最大值归位那轮常只需 1 次，上界 2n-3 成立。
