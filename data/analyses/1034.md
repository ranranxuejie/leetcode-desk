## 一句话思路
从 `(row, col)` 出发 DFS 标记整个同色连通分量，再判断每个标记格是否为边界并改色，用「先标记后改色」避免新颜色污染搜索。

## 怎么做
1. 记 `old = grid[row][col]`，若 `old == color` 直接返回 `grid`（否则会把内部格也误染）。
2. DFS 从 `(row, col)` 出发，只走 `grid[r][c] == old` 的四邻格，把访问到的坐标存进 `comp` 集合。
3. 遍历 `comp`，对每个 `(r, c)` 检查四邻：越界或 `grid[nr][nc] != old` 即为边界。
4. 边界格写入 `color`，非边界保持 `old`。

以示例 3 为例：`grid` 全 1，`old = 1`，`comp` 含全部 9 格；中心 `(1,1)` 四邻都是 1 且不越界 → 非边界，保持 1；其余 8 格至少一邻越界 → 染成 2，得到 `[[2,2,2],[2,1,2],[2,2,2]]`。

```python
old = grid[row][col]
if old == color:
    return grid
comp, stack = set(), [(row, col)]
while stack:
    r, c = stack.pop()
    if (r, c) in comp:
        continue
    comp.add((r, c))
    for nr, nc in ((r+1,c),(r-1,c),(r,c+1),(r,c-1)):
        if 0 <= nr < len(grid) and 0 <= nc < len(grid[0]) and grid[nr][nc] == old:
            stack.append((nr, nc))
for r, c in comp:
    for nr, nc in ((r+1,c),(r-1,c),(r,c+1),(r,c-1)):
        if not (0 <= nr < len(grid) and 0 <= nc < len(grid[0])) or grid[nr][nc] != old:
            grid[r][c] = color
            break
```

## 复杂度
时间 O(m·n)：每个格最多入栈一次，边界判定每格看 4 个邻居。
空间 O(m·n)：`comp` 集合与 `stack` 最坏存下整个连通分量。

## 易错点
- `grid = [[1,1],[1,2]], row=0, col=0, color=1`：`old == color`，若不提前返回，DFS 后改色仍是 1 看似没事，但若在 DFS 中边搜边改色，会把 `(0,1)` 的新值 1 当成旧色继续扩散，误染 `(1,1)` 的 2 邻域。正确做法是先收集 `comp` 再统一改色，或开头判 `old == color` 直接返回。
- 示例 1 中 `(1,1)` 值为 2，与 `old=1` 不同：若把「邻居颜色不同」误写成「邻居未被访问」，会把 `(1,1)` 也算进分量。正确做法是 DFS 只按 `grid[nr][nc] == old` 扩展，边界判定才用 `!= old`。

## 如果面试官追问
问：若要求返回新矩阵而不修改 `grid`？答：DFS 时把 `comp` 坐标记下，复制一份 `res = [r[:] for r in grid]`，只在 `res` 上写 `color`，原矩阵不动。
