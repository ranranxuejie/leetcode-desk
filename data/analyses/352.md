## 一句话思路
用有序结构维护区间列表，`addNum` 时二分找到插入位置，按 `value` 与左右区间是否相邻分四种情况合并。

## 怎么做
1. 用 `starts` 列表存每个区间的起点，`intervals` 存 `[start, end]`，两者下标一一对应，`starts` 天然升序。
2. `addNum(value)` 用 `bisect_right(starts, value) - 1` 得到 `i`，即最后一个 `start <= value` 的区间下标。
3. 判断 `value` 落在区间内（`i >= 0 and intervals[i][1] >= value`）则直接返回，否则看它能否接上 `intervals[i]` 的右端或 `intervals[i+1]` 的左端。
4. 四种情况：只接左、只接右、两边都接（合并 `i` 和 `i+1`）、都不接（在 `i+1` 处插入 `[value, value]`）。

以示例 `addNum(2)` 为例：此时 `intervals = [[1,1],[3,3],[7,7]]`，`starts = [1,3,7]`，`bisect_right(starts, 2) - 1 = 0`，`i = 0`。`intervals[0][1] = 1` 不等于 `2-1`？等于，接左；`intervals[1][0] = 3` 等于 `2+1`，接右，于是合并成 `[1,3]`，`intervals` 变为 `[[1,3],[7,7]]`。

```python
from bisect import bisect_right

def addNum(self, value):
    i = bisect_right(self.starts, value) - 1
    if i >= 0 and self.intervals[i][1] >= value:
        return
    left = i >= 0 and self.intervals[i][1] + 1 == value
    right = i + 1 < len(self.intervals) and self.intervals[i + 1][0] - 1 == value
    if left and right:
        self.intervals[i][1] = self.intervals[i + 1][1]
        del self.intervals[i + 1]; del self.starts[i + 1]
    elif left:
        self.intervals[i][1] = value
    elif right:
        self.intervals[i + 1][0] = value
        self.starts[i + 1] = value
    else:
        self.intervals.insert(i + 1, [value, value])
        self.starts.insert(i + 1, value)
```

## 复杂度
时间：`addNum` 二分 O(log k) 加列表插入 O(k)，k 为当前区间数；`getIntervals` O(k)。
空间：`intervals` 与 `starts` 各存 k 个元素，O(k)，k ≤ 不同数字个数。

## 易错点
1. 输入 `addNum(2)` 在 `[[1,1],[3,3]]` 上：若只判断接左就改 `intervals[i][1] = 2`，会漏掉与 `[3,3]` 的合并，得到 `[[1,2],[3,3]]` 而非 `[[1,3]]`。必须先算 `left` 和 `right` 两个布尔值再分支。
2. 输入重复值如连续两次 `addNum(1)`：若不做 `intervals[i][1] >= value` 的提前返回，会走到 `else` 分支插入 `[1,1]`，产生重复区间。正确做法是命中已有区间立即 `return`。

## 如果面试官追问
问：若 `addNum` 调用 10^6 次、`getIntervals` 很少，怎么优化？
答：改用并查集或 `SortedDict` 维护端点，`addNum` 均摊 O(α(n))，`getIntervals` 时再线性扫描输出。
