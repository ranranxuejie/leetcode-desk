## 一句话思路
枚举 img1 相对 img2 的所有平移量 (dr, dc)，逐格统计两图同为 1 的个数取最大；n≤30 时 61×61 种平移完全可枚举。

## 怎么做
1. 平移量 dr、dc 各取 `-(n-1)..(n-1)`，共 (2n-1)² 种，覆盖所有可能重叠。
2. 对每种平移，只遍历 img1 中为 1 的格子 (i,j)，映射到 img2 的 (i+dr, j+dc)，越界即被清除、跳过。
3. 若 img2 该位置也为 1 则计数加一，用 `max` 更新答案。

以示例 1 为例，n=3，取 dr=1、dc=1：img1 的 (0,0)、(0,1)、(1,1)、(2,1) 四个 1 映射到 img2 的 (1,1)、(1,2)、(2,2)、(3,2)，最后一个越界丢弃，前三个在 img2 中都是 1，计数得 3，即答案。

```python
n = len(img1)
best = 0
for dr in range(-(n - 1), n):
    for dc in range(-(n - 1), n):
        cnt = 0
        for i in range(n):
            for j in range(n):
                if img1[i][j]:
                    r, c = i + dr, j + dc
                    if 0 <= r < n and 0 <= c < n and img2[r][c]:
                        cnt += 1
        best = max(best, cnt)
```

## 复杂度
时间：O(n⁴)，(2n-1)² 种平移 × n² 格，n=30 时约 3.2×10⁶ 次判断。
空间：O(1)，只用了 best、cnt、dr、dc 几个标量，未开额外矩阵。

## 易错点
- 平移范围写成 `range(n)` 或 `range(-n, n)` → 漏掉 dr=-(n-1) 这类极端平移，示例 1 中若只取非负平移就得不到 3；正确是 `-(n-1)` 到 `n-1` 闭区间，即 `range(-(n-1), n)`。
- 先判断 `img2[r][c]` 再判越界，或直接用负下标 `img2[i+dr][j+dc]` → Python 负索引会绕回最后一行/列，把越界的 1 误算成重叠；必须先 `0 <= r < n and 0 <= c < n` 再取 `img2[r][c]`。

## 如果面试官追问
若 n 放大到 1000 怎么办？答：把两图所有 1 的坐标取出，枚举坐标对差值作为平移量，用哈希表按差值累加计数，复杂度降到 O(k1·k2)，k 为 1 的个数。
