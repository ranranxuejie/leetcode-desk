## 一句话思路
按「前 i 个房子、第 i 个涂颜色 c、已形成 k 个街区」做三维 DP，因为街区数只由相邻颜色是否相同决定。

## 怎么做
1. 定义 `dp[c][k]` 为处理到当前房子、该房子颜色为 c、累计 k 个街区的最小花费，初始 `dp[houses[0]][1] = 0`（若 houses[0] 为 0 则对所有 c 取 `cost[0][c-1]`）。
2. 逐房转移：新颜色 c 与旧颜色 p 相同则街区数不变，不同则 k+1。
3. 若 `houses[i] != 0`，只保留 c = houses[i] 这一支，其余置无穷。
4. 答案取 `min(dp[c][target])`，全为无穷则返回 -1。

以示例 1 为例，`houses=[0,0,0,0,0]`，n=2。处理到第 2 个房子（下标 1）时，`dp[1][1]=1+10=11`（颜色 1→1，街区仍 1 个），`dp[2][2]=1+1=2`（颜色 1→2，街区变 2 个）。最终 `dp[1][3]=9` 对应方案 `[1,2,2,1,1]`。

```python
INF = float('inf')
dp = [[INF] * (target + 2) for _ in range(n + 1)]
for c in range(1, n + 1):
    if houses[0] in (0, c):
        dp[c][1] = 0 if houses[0] else cost[0][c - 1]
for i in range(1, m):
    ndp = [[INF] * (target + 2) for _ in range(n + 1)]
    for c in range(1, n + 1):
        if houses[i] not in (0, c):
            continue
        add = 0 if houses[i] else cost[i][c - 1]
        for k in range(1, target + 1):
            for p in range(1, n + 1):
                nk = k if p == c else k + 1
                if nk <= target and dp[p][k] + add < ndp[c][nk]:
                    ndp[c][nk] = dp[p][k] + add
    dp = ndp
ans = min(dp[c][target] for c in range(1, n + 1))
return -1 if ans == INF else ans
```

## 复杂度
时间：O(m · target · n²)，两层颜色枚举贡献 n²。
空间：O(target · n)，只保留上一层 dp 表。

## 易错点
- `houses[i] != 0` 时若仍对所有 c 转移，会把已涂色房子改色，示例 2 中 houses[1]=2 会被错误涂成 1，得到比 11 更小的非法值；正确做法是 `if houses[i] not in (0, c): continue`。
- 初始 `dp[c][1]` 对 houses[0]=0 要加 `cost[0][c-1]`，漏加会让示例 1 输出 8 而非 9；houses[0]!=0 时只初始化该颜色且花费为 0。

## 如果面试官追问
问：要求输出具体涂色方案怎么办？
答：转移时额外记录 `pre[i][c][k]` 的前一颜色，从 `dp[c][target]` 回溯即可。
