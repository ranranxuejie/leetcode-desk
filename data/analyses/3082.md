## 一句话思路
把「每个子序列的能量」交换求和顺序：对每个和为 k 的子序列 S，统计有多少个外层子序列包含它，即 2^(n-|S|)，用 dp[j] 累计。

## 怎么做
1. 定义 dp[j] = 当前已处理元素中，所有和为 j 的子序列的 2^(已选个数) 权重之和，初始 dp[0]=1。
2. 逆序遍历 j 从 k 到 nums[i]，用 dp[j] += dp[j-nums[i]] 更新，逆序保证每个 nums[i] 只用一次。
3. 关键：每选一个元素进内层子序列，外层可选元素少一个，权重从 2^(n-|S|) 变为 2^(n-|S|-1)，所以转移时把 dp[j-nums[i]] 除以 2 的逆元（mod 意义下乘 inv2）。
4. 答案就是 dp[k]。

以 nums=[1,2,3], k=3 为例：处理 1 后 dp[1]=inv2；处理 2 后 dp[3]=dp[1]*inv2=inv2²；处理 3 后 dp[3] 再累加 dp[0]*inv2=inv2，最终 dp[3]=inv2²+inv2，乘回 2³=8 得 2+4=6。

```python
MOD = 10**9 + 7
inv2 = (MOD + 1) // 2
dp = [0] * (k + 1)
dp[0] = 1
for x in nums:
    for j in range(k, x - 1, -1):
        dp[j] = (dp[j] + dp[j - x] * inv2) % MOD
return dp[k] * pow(2, len(nums), MOD) % MOD
```

## 复杂度
时间：O(n·k)，n 个元素各扫一遍 0..k 的背包。
空间：O(k)，只开一个长度 k+1 的 dp 数组。

## 易错点
- 内层循环写成正序 `for j in range(x, k+1)`：nums=[1,2,3], k=3 时 1 会被重复计入 dp[2]、dp[3]，答案偏大；必须逆序保证 0-1 背包语义。
- 忘记最后乘 `pow(2, n, MOD)`：dp 里存的是除以 2^|S| 后的权重，不乘回 2^n 会得到 6/8 这类小数取模的错误值；正确做法是 dp[k] 乘 2^n 再取模。

## 如果面试官追问
问：若 k 增大到 10^5、n 仍 100，怎么做？答：dp 维度仍是 k+1，O(n·k)=10^7 可接受，无需换算法。
