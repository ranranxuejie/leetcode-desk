## 一句话思路
取第 i 个字符串的第 i 位并翻转，拼成的串必不在 nums 中（对角线反证法）。

## 怎么做
1. 设 n = len(nums)，构造答案 ans 的第 i 位 = nums[i][i] 取反。
2. 关键中间值：以 nums = ["111","011","001"] 为例，取 nums[0][0]='1'→'0'，nums[1][1]='1'→'0'，nums[2][2]='1'→'0'，得 "000"。
3. 为什么必不同：若 ans 等于某个 nums[k]，则第 k 位应相同，但 ans[k] 恰是 nums[k][k] 的取反，矛盾。
4. 直接返回拼接结果，无需哈希或回溯。

```python
n = len(nums)
ans = []
for i in range(n):
    ans.append('1' if nums[i][i] == '0' else '0')
return ''.join(ans)
```

## 复杂度
时间 O(n)：只扫 n 个对角线字符，拼接也是 n 次。
空间 O(n)：ans 列表与结果串各占 n，无额外哈希表。

## 易错点
- 误用 `nums[i][i]` 的下标含义：若写成 `nums[i][0]`（固定取第 0 位），对 ["01","10"] 会得 "11" 看似对，但换 ["00","01"] 得 "11" 也对、换 ["111","011","001"] 取第 0 位得 "100" 恰好也对——这是巧合，遇到 ["010","001","111"] 取第 0 位得 "100"，而 "100" 不在集合里仍对，但构造逻辑已错，必须严格用对角线 `[i][i]`。
- 忘记取反方向：写成 `ans.append(nums[i][i])` 直接复制对角线，对 ["01","10"] 得 "01"，正好在 nums 里，返回了非法答案；必须翻转。

## 如果面试官追问
若要求返回字典序最小的合法串怎么办？答：对角线法只保证合法，需枚举 2^n 或用哈希集合补集，n≤16 时枚举可接受。
