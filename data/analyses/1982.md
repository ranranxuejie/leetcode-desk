## 一句话思路
把 sums 排序后，用「最小非零和必是某个元素」逐层剥离子集和，配合 Counter 做多重集减法。

## 怎么做
1. 排序 sums，用 Counter 记录每个和的剩余次数；`ans = []`。
2. 反复取当前 Counter 中最小的非零和 `x`，它就是下一个元素（因为剩余子集和里最小的正/负值只能由单个元素贡献）。
3. 从 Counter 中删掉「已有 ans 的所有子集和 + x」这一批值，把 x 加入 ans。
4. 重复 n 次，返回 ans。

以示例 1 为例：`sums = [-3,-2,-1,0,0,1,2,3]`，排序后 Counter 里最小非零是 `-3`，取 `x = -3`；此时 ans 为空，只需删掉 `-3` 本身，ans 变成 `[-3]`。下一轮最小非零是 `-2`，但 `-2 = -3 + 1`，说明 `1` 才是新元素——所以正确做法是：每轮取最小非零 `x` 后，先检查 `x` 是否已能由 ans 的子集和表示；不能表示才作为新元素。更稳的写法是：取最小非零 `x` 作为新元素，然后从 Counter 中删掉 `{s + x : s 是 ans 旧子集和}` 这一整批。

```python
from collections import Counter
cnt = Counter(sums)
ans = []
for _ in range(n):
    x = min(v for v in cnt if v != 0 and cnt[v] > 0)
    ans.append(x)
    # 删掉 ans 全部子集和 + x
    sub = [0]
    for a in ans[:-1]:
        sub += [s + a for s in sub]
    for s in sub:
        cnt[s + x] -= 1
```

关键中间值：处理示例 1 时，第一轮 `x = -3`，`sub = [0]`，删 `cnt[-3]`；第二轮 `x = 1`（此时最小非零是 1，因为 -2 已被 -3+1 覆盖），`sub = [0, -3]`，删 `cnt[1]` 和 `cnt[-2]`。

## 复杂度
时间 O(n · 2^n)：每轮枚举 ans 子集和共 2^k，累计约 2^n，n 轮外层。
空间 O(2^n)：Counter 存 2^n 个键值，sub 列表峰值 2^(n-1)。

## 易错点
- 输入含 0 元素（如示例 2 全 0）：若用「最小非零」逻辑会死循环取不到 0 → 正确做法是先统计 `sums` 中 0 的个数，`cnt[0]` 超过 1 的部分对应 0 元素，先剥离再处理非零。
- 有负数时最小非零可能是负的（示例 1 的 -3）：若只取最小正值会漏掉负元素 → 必须取「绝对值意义下最小」或直接取排序后第一个非零，且删子集和时用 `s + x` 而非 `s - x`。

## 如果面试官追问
若 n 扩大到 20 且 sums 只给部分子集和，怎么办？
答：无法唯一还原，需转为搜索/回溯验证候选元素，复杂度指数级上升。
