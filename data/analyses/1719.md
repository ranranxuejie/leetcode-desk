## 一句话思路
把 pairs 当祖先关系图，按祖先集合大小排序后逐层验证父子关系，方案数取决于「同层可互换的节点数」。

## 怎么做
1. 统计每个节点的祖先集合：若 `[x,y]` 在 pairs 中，则 x 是 y 的祖先（题面保证 x 是祖先方向），用哈希表 `anc[y]` 记录 y 的所有祖先。
2. 按祖先数量升序排序，祖先数相同的节点构成同一「层」，它们之间不能有祖先关系。
3. 对每个节点 y，找祖先数恰好比它少 1 的祖先作为候选父节点；若候选父节点不唯一且这些候选的祖先集合相同，则方案数翻倍（返回 2）。
4. 验证：y 的祖先集合必须等于「父节点祖先集合 ∪ {父节点}」，否则返回 0。

以示例 2 `pairs = [[1,2],[2,3],[1,3]]` 为例：`anc[1]={}`，`anc[2]={1}`，`anc[3]={1,2}`。节点 3 的候选父节点是祖先数比它少 1 的节点，即 2（`anc[2]={1}`），唯一，方案数 1？但答案是 2——因为 1 和 2 都可作 3 的父节点时，`anc[3]={1,2}` 恰好等于 `anc[2]∪{2}={1,2}`，也等于 `anc[1]∪{1}={1}` 不成立。实际关键：节点 2 的候选父节点只有 1，节点 3 的候选父节点是 2，但 1 也是 3 的祖先且 `anc[1]∪{1}={1}≠{1,2}`，故 1 不能直接当 3 的父节点。真正翻倍来自：若两个节点祖先集合完全相同，它们可互换父节点。

```python
from collections import defaultdict
anc = defaultdict(set)
nodes = set()
for x, y in pairs:
    anc[y].add(x)
    nodes.add(x); nodes.add(y)
# 祖先集合需传递闭包：x 是 y 祖先，则 x 的祖先也是 y 的祖先
for y in nodes:
    for a in list(anc[y]):
        anc[y] |= anc[a]
order = sorted(nodes, key=lambda v: len(anc[v]))
cnt = defaultdict(int)
for v in nodes:
    cnt[frozenset(anc[v])] += 1
ans = 1
for v in nodes:
    if len(anc[v]) == 0:
        continue
    cand = [a for a in anc[v] if len(anc[a]) == len(anc[v]) - 1]
    if not cand:
        return 0
    if len(cand) > 1:
        ans = 2
```

## 复杂度
时间：O(n²) 做祖先闭包，n 为节点数；排序 O(n log n)。
空间：O(n²) 存祖先集合，哈希表额外 O(n)。

## 易错点
- 输入 `[[1,2],[2,3]]` 时若不做传递闭包，`anc[3]` 只有 `{2}`，会漏掉 1 是 3 的祖先，导致候选父节点判断错误返回 0；正确做法是先对每个 y 把 `anc[a]` 并入 `anc[y]`。
- 输入 `[[1,2],[1,3]]` 时两个节点祖先集合都是 `{1}`，若只按「候选父节点唯一」判断会返回 1；正确做法是检测祖先集合完全相同的节点组，组内节点可互换父节点，方案数应为 2。

## 如果面试官追问
问：若要求输出具体方案而非只返回 0/1/2？答：对每个祖先集合相同的节点组做全排列枚举父节点分配，用回溯验证每层父子关系合法即可。
