## 一句话思路
用线段树维护每排剩余座位数，`gather` 找区间内首个剩余 ≥k 的排，`scatter` 用区间和判断并逐排扣减。

## 怎么做
1. 线段树每个节点存 `sum`（区间剩余总数）和 `max`（区间单排最大剩余），叶子是 `m`。
2. `gather(k, maxRow)`：在 `[0, maxRow]` 上二分找最左的 `max >= k` 的排 `r`，答案 `c = m - 剩余[r]`，然后该排减 `k`。
3. `scatter(k, maxRow)`：先查 `[0, maxRow]` 的 `sum`，小于 `k` 直接 `False`；否则从第 0 排起逐排取 `min(剩余, k)` 扣减，`k` 归零即停。
4. 以官方示例 `gather(4,0)` 为例：初始每排剩余 5，`[0,0]` 的 `max=5>=4`，命中 `r=0`，`c=5-5=0`，第 0 排剩余变 1；随后 `gather(2,0)` 查 `[0,0]` 的 `max=1<2`，返回 `[]`。

```python
def gather(self, k, maxRow):
    r = self.find_first(1, 0, self.n - 1, 0, maxRow, k)
    if r == -1:
        return []
    c = self.m - self.rem[r]
    self.update(1, 0, self.n - 1, r, self.rem[r] - k)
    self.rem[r] -= k
    return [r, c]

def scatter(self, k, maxRow):
    if self.query_sum(1, 0, self.n - 1, 0, maxRow) < k:
        return False
    r = 0
    while k > 0:
        take = min(self.rem[r], k)
        if take:
            self.update(1, 0, self.n - 1, r, self.rem[r] - take)
            self.rem[r] -= take
            k -= take
        r += 1
    return True
```

## 复杂度
时间：每次 `gather`/`scatter` 的线段树操作 O(log n)，`scatter` 逐排扫描累计 O(n log n)。
空间：线段树 4n 个节点，额外开 `rem` 数组存每排剩余，O(n)。

## 易错点
- `gather` 只查 `[0, maxRow]` 的 `max`，若写成全局 `max`，`maxRow=0` 时会把第 1 排的 5 个空位误判为可坐，返回 `[1,0]` 而非 `[]`。
- `scatter` 先判 `sum < k` 再扣减，若边扣边判，`k=5, maxRow=1` 时扣完第 0 排剩 1 个才发现不够，已破坏状态且返回 `False` 前未回滚。

## 如果面试官追问
若 `n` 升到 10^6 且 `scatter` 频繁，逐排扫描会退化怎么办？答：线段树上二分定位第一个「前缀和 ≥k」的排，一次 O(log n) 完成扣减。
