## 一句话思路
按 `@` 切分后只对本地名做 `+` 截断和去 `.`，域名原样保留，拼回后丢进 set 计数。

## 怎么做
1. 对每个 `email` 用 `local, domain = email.split('@')` 拆开，注意只拆一次。
2. 本地名先 `local.split('+', 1)[0]` 砍掉第一个 `+` 之后的内容，再 `replace('.', '')`。
3. 拼成 `local + '@' + domain` 加入 `seen` 集合，最后返回 `len(seen)`。

拿示例 1 第一个 `"test.email+alex@leetcode.com"` 走一遍：`local = "test.email"`，`split('+',1)[0]` 得 `"test.email"`，去点后是 `"testemail"`，域名 `"leetcode.com"` 不动，得到 `"testemail@leetcode.com"`。第二个 `"test.e.mail+bob.cathy@leetcode.com"` 同样归一成 `"testemail@leetcode.com"`，与第一个撞车；第三个域名是 `lee.tcode.com`，域名里的点必须保留，所以是 `"testemail@lee.tcode.com"`，最终 `len(seen) == 2`。

```python
seen = set()
for email in emails:
    local, domain = email.split('@')
    local = local.split('+', 1)[0].replace('.', '')
    seen.add(local + '@' + domain)
return len(seen)
```

关键顺序：先切 `+` 再去 `.`。反过来也能对，但先切 `+` 少处理一段字符，且语义上「加号后全忽略」优先。

## 复杂度
时间 O(n·L)：n 是 `emails` 长度，L 是单串长度，每个字符最多扫一遍。
空间 O(n·L)：`seen` 最多存 n 个归一化地址，每个长度 ≤ L。

## 易错点
- 对整串 `email.replace('.', '')` → 域名 `lee.tcode.com` 被改成 `leetcode.com`，示例 1 的第三个地址就和第一个撞成同一个，答案错成 1。正确做法是只在 `local` 上 `replace`，`domain` 原样拼回。
- 用 `local.split('+')[0]` 之外的写法如 `local[:local.index('+')]` → 本地名没有 `+` 时（如 `"a@leetcode.com"`）`index` 抛 `ValueError`。正确做法是用 `split('+', 1)[0]`，无 `+` 时原样返回。

## 如果面试官追问
问：如果要求输出所有归一化后的地址而不只是数目？
答：把 `seen` 换成 `dict` 或有序 `list` 加 `set` 去重，遍历时保留首次出现的原始串即可。
