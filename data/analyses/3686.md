## 一句话思路
按「子序列末尾奇偶性 + 末尾已连续同奇偶个数」做状态 DP，逐元素累加，滚动数组。

## 怎么做
1. 状态定义：`odd1/odd2` 表示末尾为奇数、且末尾连续奇数个数为 1/2 的稳定子序列数；`even1/even2` 同理。
2. 对每个 `x`，先按 `x` 的奇偶算出新加入的贡献，再更新对应状态，注意用旧值。
3. 若 `x` 为奇数：新增 `odd1 += 1 + even1 + even2`（单独成序列 + 接在所有偶数结尾后），`odd2 += odd1_old`。
4. 若 `x` 为偶数：对称处理，`even1 += 1 + odd1 + odd2`，`even2 += even1_old`。

以 `nums = [2,3,4,2]` 为例，处理到第 3 个元素 `4` 时，旧值 `even1=2`（`[2]`、`[2,3,4]` 中末尾偶数的…实际为 `[2]`、`[4]` 前的状态），`even2` 增加 `even1_old`，最终四状态和为 14。

```python
MOD = 10**9 + 7
odd1 = odd2 = even1 = even2 = 0
for x in nums:
    if x & 1:
        odd2 = (odd2 + odd1) % MOD
        odd1 = (odd1 + 1 + even1 + even2) % MOD
    else:
        even2 = (even2 + even1) % MOD
        even1 = (even1 + 1 + odd1 + odd2) % MOD
return (odd1 + odd2 + even1 + even2) % MOD
```

关键：`odd2` 必须先于 `odd1` 更新，否则会把本元素重复计入连续段。

## 复杂度
时间：O(n)，每个元素常数次取模加法。
空间：O(1)，只开四个滚动变量，无额外数组。

## 易错点
- 输入 `[1,3,5]` → 若先更新 `odd1` 再更新 `odd2`，`odd2` 会多算本元素，得到 7 而非 6 → 必须先 `odd2 += odd1_old` 再改 `odd1`。
- 输入 `[2,2,2]` → 若忘记 `+1` 单独成序列项，会漏掉长度 1 的子序列，答案偏小 → `even1` 更新里必须含 `1 + odd1 + odd2`。

## 如果面试官追问
问：若要求输出所有稳定子序列本身而非计数？
答：DP 状态改为存列表或回溯指针，空间升到 O(答案规模)，计数版无法避免枚举。
