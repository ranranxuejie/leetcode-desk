## 一句话思路
BFS 逐层收集节点值，奇数层（0-indexed）反转后再加入结果，因为层序天然给出从左到右的顺序。

## 怎么做
1. 用队列 `q = deque([root])` 做标准 BFS，每轮先取 `size = len(q)` 固定本层节点数。
2. 循环 `size` 次弹出节点，把 `node.val` 追加到本层列表 `level`，同时把非空左右孩子入队。
3. 用层号 `depth`（从 0 开始）判断：`depth % 2 == 1` 时执行 `level.reverse()`。
4. 把 `level` 加入 `res`，`depth += 1`，队列空时返回 `res`。

以官方示例 `root = [8,17,21,18,null,null,6]` 为例：第 0 层 `level = [8]`，不反转；第 1 层弹出 17、21，`level = [17,21]`，`depth=1` 反转成 `[21,17]`；第 2 层弹出 18、6，`level = [18,6]`，`depth=2` 不反转。最终 `[[8],[21,17],[18,6]]`。

```python
from collections import deque

q = deque([root]) if root else deque()
res, depth = [], 0
while q:
    level = []
    for _ in range(len(q)):
        node = q.popleft()
        level.append(node.val)
        if node.left: q.append(node.left)
        if node.right: q.append(node.right)
    if depth % 2 == 1:
        level.reverse()
    res.append(level)
    depth += 1
```

关键点是 `range(len(q))` 必须在循环前求值，这样内层循环只处理当前层，新入队的孩子留到下一轮。

## 复杂度
时间：O(n)，每个节点入队出队各一次，反转每层合计 O(n)。
空间：O(n)，队列最坏存一层节点（满二叉树约 n/2），结果列表存 n 个值。

## 易错点
- 空树 `root = None` → 若直接 `deque([root])` 会把 `None` 当节点，`node.val` 报 AttributeError → 正确做法是 `deque([root]) if root else deque()`，或进循环前判空返回 `[]`。
- 层号从 1 开始数 → 第 2 层（`depth=1`）本该反转却漏掉，示例会输出 `[[8],[17,21],[18,6]]` → 正确做法是 `depth` 从 0 起，判 `depth % 2 == 1` 才反转。

## 如果面试官追问
若要求第 1 层从左到右、第 2 层从右到左、第 3 层又从左到右交替（而非"除第一层外都与上一层相反"）？答：仍是 `depth % 2` 判奇偶反转，规则等价。
