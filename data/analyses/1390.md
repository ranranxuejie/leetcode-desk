## 一句话思路
对每个数只枚举到 √n 找因数对，凑满 4 个就累加，超过 4 个立即放弃。

## 怎么做
1. 对 `nums` 里每个 `x`，从 `d = 1` 枚举到 `isqrt(x)`，把能整除 `x` 的 `d` 和 `x // d` 都收进计数。
2. 计数一旦超过 4 就 `break`，因为再多也不可能回到 4。
3. 枚举结束后计数恰好为 4，就把这 4 个因数加进答案。

以 `nums = [21,4,7]` 为例，处理 `x = 21`：`d = 1` 得 `1` 和 `21`，`d = 2` 不整除，`d = 3` 得 `3` 和 `7`，`d = 4` 超过 `isqrt(21) = 4` 后循环结束，计数 4，和 `1+21+3+7 = 32`。处理 `x = 4`：`d = 1` 得 `1,4`，`d = 2` 时 `d == x // d`，只算一次 `2`，计数 3，跳过。`x = 7` 计数 2，跳过。最终 `32`。

```python
from math import isqrt

total = 0
for x in nums:
    cnt, s = 0, 0
    for d in range(1, isqrt(x) + 1):
        if x % d == 0:
            cnt += 1
            s += d
            if d != x // d:
                cnt += 1
                s += x // d
        if cnt > 4:
            break
    if cnt == 4:
        total += s
```

关键在 `d != x // d` 这个判断：完全平方数只算一个因数，否则 `4` 会被算成 4 个因数。

## 复杂度
时间：O(len(nums) · √max(nums))，每个数枚举到 `isqrt(x)`。
空间：O(1)，只用了 `cnt`、`s`、`total` 几个标量。

## 易错点
- 输入 `nums = [4]` → 若不加 `d != x // d` 判断，`d = 2` 会把 `2` 数两次，`4` 被误判成 4 个因数、答案错成 `1+4+2+2 = 9` → 正确做法是完全平方数只计一次，返回 `0`。
- 输入 `nums = [21,21]` → 若用 `set(nums)` 去重再求和，答案错成 `32` → 题目要求按数组元素逐个累加，重复的 `21` 要算两次，正确输出 `64`。

## 如果面试官追问
问：`nums[i]` 上限提到 `10^9`、`len(nums)` 到 `10^5` 怎么办？
答：先筛出 `10^9` 内的素数表，四因数只可能是 `p*q`（两不同素数）或 `p^3`，用试除到 `isqrt` 仍可，但可加记忆化缓存重复值。
