## 一句话思路
用线段树维护每个区间的 2×2 状态矩阵（左右端点选/不选），单点修改后合并矩阵，根节点给出全局最大和。

## 怎么做
1. 每个叶子节点 `i` 维护矩阵 `m[2][2]`，`m[a][b]` 表示该区间左端状态 a、右端状态 b 时的最大和。
2. 合并两子区间时，枚举中间相邻的两个状态，若同时为 1 则跳过（相邻不能都选）。
3. 每次查询先更新 `nums[pos]` 对应叶子，再沿路径向上合并，取根矩阵最大值累加。
4. 以 `nums=[3,5,9]` 为例，查询 `[1,-2]` 后 `nums=[3,-2,9]`，根矩阵最大值对应选下标 0 和 2，得 12。

```python
def merge(L, R):
    res = [[-inf]*2 for _ in range(2)]
    for a in range(2):
        for b in range(2):
            for c in range(2):
                for d in range(2):
                    if b == 1 and c == 1:
                        continue
                    res[a][d] = max(res[a][d], L[a][b] + R[c][d])
    return res

def leaf(v):
    return [[0, -inf], [-inf, v]]
```

## 复杂度
时间：每次查询 O(log n)，共 q 次，合并常数 16，总 O((n+q) log n)。
空间：线段树 4n 个 2×2 矩阵，O(n)。

## 易错点
- `nums` 全为负数如 `[-5,-1]` → 若初始化 `m[0][0]=0` 但其他设 0 会误选空集外的值 → 必须用 `-inf` 表示不可达状态，保证空子序列得 0。
- 合并时 `b==1 and c==1` 的相邻约束 → 若漏判会选出相邻元素 → 必须显式跳过该组合，这是本题唯一的状态转移限制。

## 如果面试官追问
若要求输出具体选了哪些下标？答：在矩阵中额外存选择路径或回溯时按状态转移反推，O(n) 恢复方案。
