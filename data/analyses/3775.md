## 一句话思路
按空格切词，先数首词元音数当基准，后续词元音数相等就切片反转，最后拼回。

## 怎么做
1. 用 `s.split(' ')` 切词，得到 `words`，首词 `words[0]` 的元音数记为 `target`。
2. 遍历 `words[1:]`，对每个词 `w` 用 `sum(c in 'aeiou' for c in w)` 数元音，等于 `target` 就换成 `w[::-1]`。
3. 用 `' '.join(words)` 拼回，单词间单空格由 join 保证。

以 `s = "cat and mice"` 为例：`words = ['cat','and','mice']`，`target = 1`（`cat` 里只有 `a`）。`and` 数出 1，命中，变成 `'dna'`；`mice` 数出 2（`i`、`e`），不等于 1，保持 `'mice'`。拼回得 `"cat dna mice"`。

```python
words = s.split(' ')
vowels = set('aeiou')
target = sum(c in vowels for c in words[0])
for i in range(1, len(words)):
    if sum(c in vowels for c in words[i]) == target:
        words[i] = words[i][::-1]
return ' '.join(words)
```

关键点：`target` 只由首词决定，后续词反转后**不能**再参与基准计算，所以循环里只读不改 `target`。

## 复杂度
时间 O(n)：每个字符被数元音和反转各扫常数次，n 为 `s` 长度。
空间 O(n)：`words` 列表和 `join` 结果各占 O(n)，无额外大结构。

## 易错点
- 输入 `"a b"`：首词 `a` 元音数 1，`b` 元音数 0 不反转，输出 `"a b"`；若误把 `b` 当首词或漏掉首词本身不反转的规则，会错成 `"a b"` 之外的乱序。正确做法是循环从 `i=1` 起，首词永远不动。
- 输入 `"book is nice"`：`nice` 元音数 2 等于 `book` 的 2，应反转为 `ecin`；若用 `set(w) & vowels` 去重计数，`nice` 会被算成 2 但 `book` 的 `oo` 只算 1，导致 `target` 错成 1、`nice` 不反转。正确做法是逐字符 `sum(c in vowels for c in w)`，重复元音要重复计。

## 如果面试官追问
若单词间允许多个空格、需保留原空格？答：改用 `re.split(r'( +)', s)` 保留分隔符，只对非空格片段判断反转，join 时原样拼回。
