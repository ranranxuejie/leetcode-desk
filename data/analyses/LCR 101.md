## 一句话思路
把问题转成 0/1 背包：能否从 nums 中选若干数凑出总和的一半 target。

## 怎么做
1. 先算 `total = sum(nums)`，若 `total % 2 == 1` 直接返回 `False`，否则 `target = total // 2`。
2. 若 `max(nums) > target`，该数无法放进任何一半，返回 `False`（可选剪枝）。
3. 用一维布尔数组 `dp`，`dp[j]` 表示能否凑出和 `j`，初始 `dp[0] = True`。
4. 对每个 `x` 逆序遍历 `j` 从 `target` 到 `x`，执行 `dp[j] = dp[j] or dp[j - x]`。

以 `nums = [1,5,11,5]` 为例：`total = 22`，`target = 11`。处理完前两个数 `1,5` 后，`dp[1]=dp[5]=dp[6]=True`；处理 `11` 时 `dp[11] = dp[11] or dp[0] = True`，最终返回 `True`。

```python
total = sum(nums)
if total % 2:
    return False
target = total // 2
dp = [False] * (target + 1)
dp[0] = True
for x in nums:
    for j in range(target, x - 1, -1):
        dp[j] = dp[j] or dp[j - x]
return dp[target]
```

关键在逆序：若正序遍历 `j`，`dp[j - x]` 可能已被当前 `x` 更新过，等于同一个数用了两次。逆序保证 `dp[j - x]` 还是上一轮的值，符合 0/1 背包语义。

## 复杂度
时间：O(n × target)，n 为 nums 长度，target 为总和一半。
空间：O(target)，只开一个长度 target+1 的 dp 数组。

## 易错点
- 输入 `nums = [1,2,5]`，`total = 8`、`target = 4`，但没有任何子集和为 4 → 若只判断 `total` 偶数就返回 `True` 会错，必须真正跑 dp 到 `dp[target]`。
- 输入 `nums = [2,2,3,5]`，`total = 12`、`target = 6`，正序遍历时处理第二个 `2` 会让 `dp[4]` 由 `dp[2]` 推出、`dp[2]` 又刚被本轮更新，等于用了两个以上 `2` → 必须 `range(target, x - 1, -1)` 逆序。

## 如果面试官追问
问：若要求输出具体两个子集而非布尔值？
答：dp 存布尔的同时记录每个 `j` 由哪个 `x` 转移而来，最后从 `target` 回溯收集元素，剩余即另一半。
