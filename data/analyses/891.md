## 一句话思路
排序后每个 nums[i] 作为最大值贡献 `nums[i]*(2^i-1)`、作为最小值贡献 `-nums[i]*(2^(n-1-i)-1)`，两者合并求和。

## 怎么做
1. 先排序：子序列的宽度只由最大最小元素决定，顺序无关，排序后下标即大小次序。
2. 对排序后下标 i，它作为最大值的子序列有 `2^i` 个（从左侧 i 个元素任选），去掉空集后是 `2^i - 1` 个。
3. 同理它作为最小值的子序列有 `2^(n-1-i) - 1` 个，符号为负。
4. 合并：`nums[i] * (2^i - 2^(n-1-i))`，累加取模。

以 `nums = [2,1,3]` 为例，排序后 `[1,2,3]`，n=3。i=0：`1*(2^0-2^2)=1*(1-4)=-3`；i=1：`2*(2-2)=0`；i=2：`3*(4-1)=9`；合计 6，与示例一致。关键中间值就是 i=0 的 `-3` 和 i=2 的 `9`，中间项因对称抵消为 0。

```python
MOD = 10**9 + 7
nums.sort()
n = len(nums)
pow2 = [1] * n
for i in range(1, n):
    pow2[i] = pow2[i-1] * 2 % MOD
ans = 0
for i, x in enumerate(nums):
    ans = (ans + x * (pow2[i] - pow2[n-1-i])) % MOD
return ans
```

注意 `pow2[i] - pow2[n-1-i]` 可能为负，Python 的 `%` 会自动归正，无需额外处理。

## 复杂度
时间：排序 O(n log n)，两次线性扫描 O(n)，n 为数组长度。
空间：pow2 数组 O(n)，排序本身 O(log n) 栈空间。

## 易错点
- 输入 `nums = [2]`（n=1）→ 若写成 `pow2[i] - pow2[n-1-i]` 但没初始化 `pow2[0]=1`，会得到 0 或报错 → 正确做法是 `pow2` 初值全 1，i=0 时 `1-1=0`，答案 0。
- 输入含重复值如 `[1,1,1]` → 若误以为重复元素要去重，会漏算子序列个数 → 排序后按下标逐个算，重复值各自贡献，结果仍为 0（因每项系数对称抵消），但计数逻辑不能去重。
