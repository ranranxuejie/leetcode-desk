## 一句话思路
把 s1 与 s2 逐位异或得到差异位，贪心地把相邻差异位配对成一次操作，落单的差异位用 3 次操作补齐。

## 怎么做
1. 构造差异数组 `diff = [i for i in range(n) if s1[i] != s2[i]]`，只有这些位置需要变动。
2. 若 `len(diff)` 为奇数，直接返回 -1：每次操作改变 1 或 2 个位置的状态，但单点 0→1 只增不减，奇数个差异无法配对消掉。
3. 相邻配对：遍历 `diff`，若 `diff[j+1] - diff[j] == 1` 则一次操作消掉两个，`ans += 1`，`j += 2`；否则 `ans += 2`，`j += 1`（把当前位与下一个差异位各用一次单点操作，再靠一次相邻清零，共 2 次）。
4. 末尾若剩一个差异位（只可能出现在奇数长度场景，已被步骤 2 拦截），无需处理。

以 `s1="01", s2="10"` 为例：`diff=[0,1]`，`diff[1]-diff[0]==1`，一次操作消掉，但实际答案是 3——因为 s1[0]='0' 要先变 '1' 才能和 s1[1]='1' 配对清零，所以相邻配对的实际代价是 1 次操作（当两位都是 1 时）或 3 次（当需要先补 1 时）。正确判据是看 `s1` 在 `diff` 位置上的原始值。

```python
diff = [i for i in range(n) if s1[i] != s2[i]]
if len(diff) % 2:
    return -1
ans, j = 0, 0
while j < len(diff):
    if j + 1 < len(diff) and diff[j+1] - diff[j] == 1:
        ans += 1 if s1[diff[j]] == '1' else 3
        j += 2
    else:
        ans += 2
        j += 1
return ans
```

## 复杂度
时间 O(n)：一次扫描构造 diff，再一次线性遍历配对。
空间 O(n)：diff 最坏存 n 个下标，无其他额外结构。

## 易错点
- `s1="01", s2="10"` → 若只按「相邻差异位配对算 1 次」会得 1，实际是 3：因为 s1[0]='0' 需先单点变 '1' 才能与 s1[1]='1' 一起清零，配对代价取决于 `s1[diff[j]]` 是否为 '1'。
- `s1="1", s2="0"` → 若只判 `len(diff)%2` 就返回 -1 会漏掉 n=1 时无法配对的边界，实际这里 diff 长度为 1 为奇数，返回 -1 正确；但若 `s1="10", s2="01"`，diff=[0,1] 相邻且 s1[0]='1'，代价 1，别误判成 3。

## 如果面试官追问
若要求输出具体操作序列而非次数，怎么办？答：在配对时记录每步操作的下标与类型（单点置 1 / 相邻清零），按贪心顺序输出即可，复杂度不变。
