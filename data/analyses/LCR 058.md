## 一句话思路
用有序列表维护已预订区间，每次二分找第一个 `start` 大于等于新 `start` 的区间，只查它和它前一个是否重叠。

## 怎么做
1. 维护 `starts` 和 `ends` 两个平行有序列表，`bisect_left(starts, start)` 得到插入点 `i`。
2. 检查右邻居：若 `i < len(starts)` 且 `start < ends[i]`，说明新区间起点落在第 `i` 个区间内部，冲突。
3. 检查左邻居：若 `i > 0` 且 `starts[i-1] < end`，说明第 `i-1` 个区间尾部越过了新起点，冲突。
4. 都不冲突才 `insert(i, start)` / `insert(i, end)` 并返回 `True`。

以官方示例为例：已存 `[10,20)`，`starts=[10]`、`ends=[20]`。`book(15,25)` 时 `bisect_left([10],15)=1`，右邻居不存在，左邻居 `starts[0]=10 < 25` 成立 → 返回 `False`。接着 `book(20,30)`：`bisect_left([10],20)=1`，左邻居 `starts[0]=10 < 30` 成立，但注意这里比较的是 `starts[i-1] < end`，`10 < 30` 为真会误判——所以左邻居必须用 `ends[i-1] > start`，即 `20 > 20` 为假，才正确返回 `True`。

```python
from bisect import bisect_left

class MyCalendar:
    def __init__(self):
        self.starts, self.ends = [], []

    def book(self, start, end):
        i = bisect_left(self.starts, start)
        if i < len(self.starts) and start < self.ends[i]:
            return False
        if i > 0 and self.ends[i - 1] > start:
            return False
        self.starts.insert(i, start)
        self.ends.insert(i, end)
        return True
```

## 复杂度
时间：每次 `book` 二分 O(log n)，但 `list.insert` 是 O(n)，n 为已存区间数，故单次 O(n)。
空间：两个列表共存 2n 个整数，O(n)。

## 易错点
- 左邻居判据写成 `starts[i-1] < end` → 对 `book(20,30)` 会因 `10 < 30` 误判冲突返回 `False`，正确应比 `ends[i-1] > start`，半开区间下 `20 > 20` 为假才放行。
- 只查右邻居不查左邻居 → 对 `book(5,15)`（已存 `[10,20)`）时 `bisect_left([10],5)=0`，右邻居 `5 < 20` 能拦住；但 `book(5,10)` 右邻居 `5 < 20` 也拦，看似够用，实际漏掉的是新区间完全包住旧区间的情形，如已存 `[10,20)` 再 `book(5,25)`，必须靠左邻居 `ends[0]=20 > 5` 才能判冲突。

## 如果面试官追问
若 `book` 调用到 10^5 次怎么办？答：换成 `SortedList` 或手写平衡树/线段树，把 `insert` 的 O(n) 降到 O(log n)。
