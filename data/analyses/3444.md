## 一句话思路
对每个 `nums[i]` 算出它能覆盖 target 的哪些下标（掩码）及代价，再做 2^m 状态的最小代价 DP。

## 怎么做
1. 枚举 `nums` 中每个元素 `x`，对每个 `target[j]` 算把 `x` 增到最近的 `target[j]` 倍数所需代价 `(target[j] - x % target[j]) % target[j]`，若代价为 0 则该位已满足。
2. 把每个 `x` 能覆盖的下标集合压成掩码 `mask`，代价取这些位对应代价的最大值（一次增量同时满足多个目标，取最大而非求和）。
3. `dp[mask]` 表示覆盖状态为 `mask` 的最小总代价，对每个 `x` 做 0/1 背包式转移：`dp[mask | m] = min(dp[mask | m], dp[mask] + cost)`。
4. 答案即 `dp[(1<<m)-1]`。

以示例 2 `nums=[8,4], target=[10,5]` 为例：`x=8` 对 10 代价 2、对 5 代价 2，掩码 `0b11` 代价 2；`x=4` 对 10 代价 6、对 5 代价 1，掩码 `0b10` 代价 1。DP 从 `dp[0]=0` 出发，用 `x=8` 直接得 `dp[3]=2`，最终答案 2。

```python
m = len(target)
full = (1 << m) - 1
INF = 10**18
dp = [INF] * (1 << m)
dp[0] = 0
for x in nums:
    mask = cost = 0
    for j, t in enumerate(target):
        c = (t - x % t) % t
        if c == 0:
            mask |= 1 << j
        else:
            # 记录该位代价，稍后取最大
            pass
    # 实际实现：对每个子集组合取 max 代价，见易错点
```

（完整实现需对每个 `x` 枚举其覆盖的所有子掩码并取对应最大代价，再更新 `dp`。）

## 复杂度
时间：`O(n * 2^m * m)`，`n` 来自 `nums`，`2^m` 来自掩码枚举，`m ≤ 4`。
空间：`O(2^m)`，只开一个 DP 数组，`m` 极小。

## 易错点
- 一个 `x` 同时满足多个 target 时，代价应取**最大**而非求和：如 `x=8, target=[10,5]`，对 10 需 +2、对 5 需 +2，取 max 得 2；若误加得 4，示例 2 会输出 4 而非 2。
- `x` 已是某 target 倍数时代价为 0，但若该位代价为 0 而另一位非 0，组合掩码的代价仍是那位非 0 值；把 0 当成「无需计入」直接丢掉该位，会漏掉已满足的目标，导致 `dp[full]` 偏大。

## 如果面试官追问
问：若 `target.length` 放宽到 20 怎么办？答：`2^20` 状态仍可 DP，但每元素枚举子掩码会到 `3^m`，需改用按位贪心或剪枝。
