## 一句话思路
按位数分段累减 k，定位到具体那个整数，再取它的第几位。

## 怎么做
1. 从 `digit = 1`、`start = 1`、`count = 9` 开始，每段是 `digit` 位数共 `count` 个，占 `digit * count` 位。
2. 若 `k > digit * count`，就 `k -= digit * count`，然后 `digit += 1`、`start *= 10`、`count *= 10`，继续下一段。
3. 落在本段后，第 k 位（1-based）对应整数 `num = start + (k - 1) // digit`，位偏移 `idx = (k - 1) % digit`。
4. 返回 `str(num)[idx]` 转成整数。

以 `k = 12` 为例：第 1 段 9 位，`12 > 9`，减完 `k = 3`，进入 `digit = 2, start = 10`；`num = 10 + (3-1)//2 = 11`，`idx = (3-1)%2 = 0`，取 `"11"[0]` 得 `1`。

```python
digit, start, count = 1, 1, 9
while k > digit * count:
    k -= digit * count
    digit += 1
    start *= 10
    count *= 10
num = start + (k - 1) // digit
idx = (k - 1) % digit
return int(str(num)[idx])
```

注意 `k` 是 1-based 的位序，所以减 1 再取模；`start` 是本段最小数（1、10、100…），不是 0。

## 复杂度
时间 O(log k)：循环次数等于 k 的十进制位数，最多约 10 次。
空间 O(1)：只用了 `digit/start/count/num/idx` 几个整数，`str(num)` 长度 ≤ 10。

## 易错点
- `k = 0`（提示允许 0）→ 若直接进循环会算出 `num = 0`、`idx = -1`，取到末位字符 → 按题意第 0 位无定义，需先判 `k <= 0` 返回 0 或按题目约定处理，别让负数下标溜进去。
- `k = 10**9` 附近 → 若用 `count = 9 * 10**(digit-1)` 现算而 `digit` 已到 9，`9 * 10**8 * 9` 仍在 Python 内安全，但若把 `digit * count` 写成 `count * 10` 会提前跳段，导致 `num` 偏大一位 → 严格用 `digit * count` 做减法。

## 如果面试官追问
问：k 上限改成 10^18 怎么办？
答：循环只多几次（位数到 18），逻辑不变，Python 整数天然支持，无需改结构。
