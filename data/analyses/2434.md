## 一句话思路
维护 `s` 的后缀最小字符，只要 `t` 顶字符不大于它，就弹出写纸；否则继续从 `s` 压栈。

## 怎么做
1. 预处理 `min_suf[i]`：`s[i:]` 中的最小字符，末尾补 `'{'`（比 `'z'` 大）当哨兵。
2. 遍历 `s`，把字符压入栈 `t`，同时用指针 `i` 推进。
3. 每压一个字符后，只要 `t` 非空且 `t[-1] <= min_suf[i]`，就弹出到结果 `res`。
4. 遍历结束后把 `t` 剩余字符全部弹出。

以 `s = "bac"` 为例：`min_suf = ['a','a','c','{']`。压入 `'b'`，`'b' > 'a'` 不弹；压入 `'a'`，`'a' <= 'a'` 弹出 `'a'`，此时 `t=['b']`，`'b' > 'a'` 停；压入 `'c'`，`'c' <= 'c'` 弹出 `'c'`，`'b' > '{'` 不成立，继续；最后弹出 `'b'`，得 `"abc"`。

```python
n = len(s)
min_suf = ['{'] * (n + 1)
for i in range(n - 1, -1, -1):
    min_suf[i] = min(s[i], min_suf[i + 1])

t, res = [], []
for i, ch in enumerate(s):
    t.append(ch)
    while t and t[-1] <= min_suf[i + 1]:
        res.append(t.pop())
while t:
    res.append(t.pop())
return ''.join(res)
```

关键在 `min_suf[i + 1]`：压入 `s[i]` 后，`s` 剩余部分是 `s[i+1:]`，只有 `t` 顶不大于它才值得立刻写纸，否则留着等更小的字符先出来。

## 复杂度
时间 O(n)：预处理后缀最小值和主循环各扫一遍，每个字符进出栈一次。
空间 O(n)：`min_suf` 数组和栈 `t` 各占 O(n)，结果 `res` 也是 O(n)。

## 易错点
- 输入 `s = "bdda"` → 若在压入 `'b'` 后立刻弹出（没比较后缀最小值），会得到 `"b..."` 开头；正确做法是 `'b' > min_suf[1] = 'a'`，必须等 `'a'` 先出来，最终 `"addb"`。
- 输入 `s = "zza"` → 若把哨兵写成 `'z'` 而非 `'{'`，末尾 `'z' <= 'z'` 会提前弹出，打乱顺序；正确做法是哨兵取比 `'z'` 大的 `'{'`，保证最后一段全部弹出。

## 如果面试官追问
若 `s` 长度升到 10^7、内存吃紧怎么办？答：`min_suf` 可换成 26 个桶记录每个字母最后出现位置，边扫边更新，空间降到 O(1)。
