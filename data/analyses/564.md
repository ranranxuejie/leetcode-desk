## 一句话思路
把 n 的前半段镜像成回文，再在「前缀 ±1」和边界 10^k±1 这几个候选里取差值最小者。

## 怎么做
1. 取 `half = int(n[:(len(n)+1)//2])`，用 `str(half)` 镜像拼出回文（偶数长度不重复末位）。
2. 对 `half-1`、`half`、`half+1` 各生成一个候选，再加 `10**(len(n)-1)-1` 和 `10**len(n)+1` 两个边界候选。
3. 以 `n = "123"` 为例：`half = 12`，镜像得 `"121"`；`half-1=11` 得 `"111"`，`half+1=13` 得 `"131"`；边界候选 `99` 和 `1001`。
4. 在候选里排除等于 `n` 的，按 `(abs(cand-int(n)), cand)` 排序取第一个，`"123"` 得 `121`。

```python
def make(h, odd):
    s = str(h)
    return int(s + s[-2::-1] if odd else s + s[::-1])

L = len(n)
odd = L % 2 == 1
half = int(n[:(L + 1) // 2])
cands = {make(half + d, odd) for d in (-1, 0, 1)}
cands.add(10 ** (L - 1) - 1)
cands.add(10 ** L + 1)
cands.discard(int(n))
return str(min(cands, key=lambda x: (abs(x - int(n)), x)))
```

## 复杂度
时间：O(L)，镜像和比较都只碰 O(L) 位，候选常数个。
空间：O(L)，存 5 个候选字符串，无额外结构。

## 易错点
- `n = "1"` → 只镜像 `half=1` 得 `"1"` 被排除，若不加边界候选 `10**0-1=0` 就无解；必须显式加入 `10**(L-1)-1` 和 `10**L+1`。
- `n = "10"` → `half=1`，`half-1=0` 镜像成 `"00"` 即 `0`，看似合法但 `9` 更近；正确做法是保留 `0` 候选同时靠 `(差值, 值)` 排序，`9` 差值 1 胜出，别手工丢掉前导零候选。

## 如果面试官追问
问：n 长度到 10^5 怎么办？答：思路不变，仍只构造常数个候选，比较改成字符串逐位比差值，避免转 int。
