## 一句话思路
用两个堆把已加景点切成「前 k 好」和「其余」，get 时 k 自增，答案就是前堆堆顶。

## 怎么做
1. 定义比较键 `(-score, name)`，越小表示越好；`top` 是大顶堆（存前 k 好，堆顶是最差的那个），`rest` 是小顶堆（存其余，堆顶是最好的那个）。
2. `add` 时先压入 `top`，再把 `top` 堆顶弹进 `rest`，保证 `top` 大小不超过当前 k。
3. `get` 时 k 先自增，若 `rest` 非空且 `rest` 堆顶比 `top` 堆顶更好，就交换两者，再返回 `top` 堆顶的 name。

以官方示例第 4 次 get 为例：此时 k 从 3 变 4，`top` 里是 branford(3)、orlando(3)、alpine(2)，`rest` 堆顶是 alps(2)。alps 的键 `(-2,"alps")` 小于 alpine 的 `(-2,"alpine")`，交换后 `top` 堆顶变成 alps，但第 4 好应是 bradford——注意 `top` 存的是「前 k 好里最差的」，堆顶取最大键，所以返回的是 bradford 而非 alps。

```python
import heapq

def add(self, name, score):
    key = (-score, name)
    heapq.heappush(self.top, (-key[0], key[1]))  # 大顶堆用取反
    s, n = heapq.heappop(self.top)
    heapq.heappush(self.rest, (s, n))

def get(self):
    self.k += 1
    if self.rest and self.rest[0] < (-self.top[0][0], self.top[0][1]):
        a = heapq.heappop(self.rest)
        b = heapq.heappop(self.top)
        heapq.heappush(self.top, (-a[0], a[1]))
        heapq.heappush(self.rest, (-b[0], b[1]))
    return self.top[0][1]
```

## 复杂度
时间：每次 add/get 各 O(log n)，n 为已加景点数，共 4×10⁴ 次操作。
空间：两个堆合计存 n 个元素，O(n)。

## 易错点
1. 同分不同名 → 只按 score 建堆会错成按插入顺序返回，如 alps 与 bradford 同为 2 分却要 alps 在前；键必须写成 `(-score, name)`，让字典序小的排前面。
2. get 时忘记先自增 k → 第 2 次 get 仍返回第 1 好（branford），正确是先把 k 加到 2 再平衡两堆，才返回 alps。

## 如果面试官追问
若要求支持删除景点怎么办？答：加一个 `deleted` 集合做惰性删除，弹出堆顶时跳过已删元素即可。
