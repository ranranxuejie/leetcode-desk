## 一句话思路
只用加法实现取负、倍增和二分累加，把减法、乘法、除法都归约成「加若干次」。

## 怎么做
1. 减法：`minus(a, b)` 就是 `a + neg(b)`，`neg(x)` 用循环把 `x` 逐次加 `-1` 或 `1` 得到相反数。
2. 乘法：对 `b` 做二进制式倍增，`a` 每轮翻倍（`a + a`），`b` 每轮减半用「反复减 2 直到不够」实现，累加对应项。
3. 除法：把 `b` 不断翻倍成不超过 `a` 的最大倍数，再逐层减去，商累加。

以 `multiply(3, 4)` 为例：`a=3, b=4`，第一轮 `b` 偶，`a` 变 `6`、`b` 变 `2`；第二轮 `a=12, b=1`；第三轮 `b` 奇，`res` 从 `0` 加到 `12`，返回 `12`。关键中间值就是 `a` 的翻倍序列 `3→6→12`。

```python
def neg(x):
    r, step = 0, -1 if x > 0 else 1
    for _ in range(abs(x)):
        r = r + step
    return r

def multiply(a, b):
    res, sign = 0, 1
    if b < 0:
        b, sign = neg(b), -1
    while b > 0:
        if b - (b // 2) * 2 == 1:   # 用减法判奇偶
            res = res + a
        a, b = a + a, b // 2
    return res if sign == 1 else neg(res)
```

`divide(5, -2)`：先取绝对值 `5, 2`，`2` 翻倍到 `4` 仍 ≤ `5`，商加 `2`，余 `1` 不够再减，得 `2`，符号异或为负，返回 `-2`。

## 复杂度
时间：乘法/除法 O(log |b|) 轮，每轮判奇偶用减法，整体 O(log n)。
空间：只开 `res/a/b/sign` 几个整数，O(1) 额外空间。

## 易错点
- `divide(5, -2)` 若直接对负数循环减，`b` 永远到不了 0 → 死循环；正确做法是先取绝对值算商，最后按 `a`、`b` 符号异或补负号。
- `multiply(3, 4)` 若用 `b // 2` 判奇偶，Python 里 `//` 对负数向下取整，`-3 // 2 = -2`，奇偶判断会错；正确做法是先把 `b` 转正再倍增，或统一用 `b - (b//2)*2` 在非负域判断。

## 如果面试官追问
问：不允许用 `//` 和 `%` 怎么办？
答：用循环减 2 求余数、减到不够为止求商，仍是 O(log n) 轮内的常数操作。
