## 一句话思路
把玩家 2 的路径上下翻转，两条路径都变成从同一行出发向右走，按列做双指针 DP 求共享格最大和。

## 怎么做
1. 玩家 2 的路径镜像成从 (0,0) 出发向右下走，与玩家 1 同向，共享格即两路径在同一列相交的格。
2. 按列推进，状态 `dp[i][j]` 表示玩家 1 在第 i 行、玩家 2 在第 j 行时的最大共享和，只保留上一列。
3. 转移时枚举两玩家本列的行 i、j，取上一列 i-1/i 与 j-1/j 四种组合的最大值，若 i==j 加上 `grid[i][c]`。
4. 最终答案是最后一列 `dp[m-1][m-1]`。

以示例 2 的 `grid = [[4,-2,-3],[-1,-3,-1],[-4,2,-1]]` 为例，第 0 列两玩家都在第 0 行，`dp[0][0]=4`；第 1 列玩家 1 下到第 1 行、玩家 2 仍在第 0 行，`dp[1][0]=4+(-1)=3`，正是最终共享和。

```python
m, n = len(grid), len(grid[0])
neg = -10**18
dp = [[neg]*m for _ in range(m)]
dp[0][0] = grid[0][0]
for c in range(1, n):
    ndp = [[neg]*m for _ in range(m)]
    for i in range(m):
        for j in range(m):
            best = neg
            for pi in (i-1, i):
                for pj in (j-1, j):
                    if 0 <= pi < m and 0 <= pj < m:
                        best = max(best, dp[pi][pj])
            if best > neg:
                ndp[i][j] = best + (grid[i][c] if i == j else 0)
    dp = ndp
return dp[m-1][m-1]
```

## 复杂度
时间 O(n·m²)，n 为列数、m 为行数，每列枚举 m² 个行对。
空间 O(m²)，只保留上一列和当前列的 dp 表。

## 易错点
- 玩家 2 原方向是向上，若直接按原坐标做 DP，行索引递减会让转移方向反掉，得到错误路径；必须先镜像成向下走再统一处理。
- 共享格只在同一列同一行才算，若写成 `i == j` 但漏判列相同，或把不同列的相同行号也计入，示例 1 会把 (2,1) 和 (3,1) 误加两次；正确做法是每列内仅当 `i == j` 时加 `grid[i][c]`。

## 如果面试官追问
问：m、n 都到 1000 时 O(n·m²) 会超时吗？答：m·n ≤ 5×10⁵ 限制了规模，最坏 m=1000、n=500 时约 5×10⁸ 次转移，需按列滚动并剪枝无效行对。
