## 一句话思路
中心扩展：以每个字符和每对相邻字符为回文中心向两边扩，每个中心扩出的每一步都对应一个回文子串。

## 怎么做
1. 枚举 2n-1 个中心：n 个单字符中心（奇数长度）和 n-1 个字符间隙中心（偶数长度）。
2. 对每个中心用左右指针 `l, r` 向两侧扩展，`s[l] == s[r]` 就计数加一并继续。
3. 一旦不等立即停，因为更长的子串必然也不回文。

以 `s = "aaa"` 为例：中心 `(1,1)` 处 `l=r=1` 先计 1（子串 `"a"`），扩到 `(0,2)` 时 `s[0]==s[2]=='a'` 再计 1（`"aaa"`），再扩越界停止；中心 `(0,1)` 计 `"a"` 后扩到 `(-1,2)` 越界。全部中心累加得 6。

```python
def countSubstrings(s):
    n, ans = len(s), 0
    for c in range(2 * n - 1):
        l, r = c // 2, c // 2 + c % 2
        while l >= 0 and r < n and s[l] == s[r]:
            ans += 1
            l -= 1
            r += 1
    return ans
```

`c // 2` 和 `c % 2` 把 2n-1 个中心映射成 `(l, r)`：偶数 `c` 得 `l == r`（奇数长度），奇数 `c` 得 `r == l + 1`（偶数长度）。这样不用写两套循环。

## 复杂度
时间 O(n²)：n 个中心，每个最多扩 n/2 步，最坏如 `"aaaa"` 全等。
空间 O(1)：只用了 `l, r, ans, c` 四个标量，没有开 DP 表。

## 易错点
- 输入 `"aaa"` 时若只枚举单字符中心，会漏掉 `"aa"` 和 `"aa"` 两个偶数长度回文，答案错成 4。必须枚举 2n-1 个中心，或对每个位置分别跑奇偶两次扩展。
- 输入 `"abc"` 时若在 `s[l] != s[r]` 后仍继续扩（比如想找更长的），会把 `"abc"` 之类非回文计入。正确做法是 `while` 条件里直接带 `s[l] == s[r]`，不等就退出，不再回退重试。

## 如果面试官追问
问：n 放大到 10⁵ 怎么办？答：中心扩展是 O(n²) 会超时，改用 Manacher 预处理回文半径，O(n) 累加各中心半径即得答案。
