## 一句话思路
用「动态数组存值 + 哈希表存值到下标」：数组保证 `getRandom` 等概率 O(1)，哈希表保证增删 O(1)。

## 怎么做
1. 维护 `nums`（列表）和 `pos`（字典，值→下标），`insert` 时若 `val in pos` 返回 `False`，否则追加到 `nums` 末尾并记下新下标。
2. `remove` 时若 `val not in pos` 返回 `False`；否则取出待删下标 `i = pos[val]`，把 `nums` 末尾元素搬到 `i` 位置，同步更新 `pos`，再 `pop()` 掉末尾。
3. `getRandom` 用 `random.choice(nums)` 或 `nums[random.randrange(len(nums))]`，每个下标等概率即每个元素等概率。

关键中间值：官方示例执行到 `remove(1)` 时，`nums = [1, 2]`、`pos = {1: 0, 2: 1}`。`i = pos[1] = 0`，末尾元素 `last = nums[-1] = 2`，执行 `nums[0] = 2`、`pos[2] = 0`、`nums.pop()` 后 `nums = [2]`、`pos = {2: 0}`，删掉 `pos[1]`。注意 `i` 恰好是末尾下标时不能自己覆盖自己再 pop 两次。

```python
def insert(self, val):
    if val in self.pos:
        return False
    self.pos[val] = len(self.nums)
    self.nums.append(val)
    return True

def remove(self, val):
    if val not in self.pos:
        return False
    i, last = self.pos[val], self.nums[-1]
    self.nums[i] = last
    self.pos[last] = i
    self.nums.pop()
    del self.pos[val]
    return True

def getRandom(self):
    return self.nums[random.randrange(len(self.nums))]
```

## 复杂度
时间：`insert`/`remove`/`getRandom` 均摊 O(1)，字典查找与数组尾部操作为常数。
空间：O(n)，`nums` 与 `pos` 各存 n 个元素，n 为当前集合大小。

## 易错点
1. 删除的正好是末尾元素（如 `nums = [2]` 时 `remove(2)`）→ 若先 `nums[i] = last` 再无条件 `pos[last] = i`，会把刚删的值又写回 `pos`，导致 `2 in pos` 仍为 `True` → 正确做法是先 `pop` 再 `del pos[val]`，且 `i == len(nums)-1` 时跳过搬移。
2. 搬移末尾元素后忘记更新 `pos[last]`（如上面 `pos[2]` 仍是 1 而非 0）→ 后续 `remove(2)` 会去删 `nums[1]`，越界或删错元素 → 必须同步 `self.pos[last] = i`。

## 如果面试官追问
问：若允许重复元素、`insert` 恒返回 `True` 怎么办？
答：`pos` 改成值→下标集合，删除时从集合任取一个下标与末尾交换，均摊仍 O(1)。
