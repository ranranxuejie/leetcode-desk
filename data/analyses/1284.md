## 一句话思路
把矩阵压成整数当状态做 BFS，因为翻转可交换、每格最多翻一次，最短路即最少次数。

## 怎么做
1. 用 `state = sum(mat[i][j] << (i*n+j))` 把矩阵编码成一个整数，BFS 从 `state` 出发、目标是 `0`。
2. 预处理每个位置 `p` 的翻转掩码 `mask[p]`：自身加四邻，共 1~5 个 bit。
3. 每层把 `state ^ mask[p]` 入队，用 `set` 去重，第一次遇到 `0` 就返回层数。
4. 队列空还没到 `0`，返回 `-1`。

以 `mat = [[0,0],[0,1]]` 为例，`n=2`，编码 `state = 1<<3 = 8`。位置 3（右下）的掩码是 bit1|bit3 = `0b1010 = 10`，`8 ^ 10 = 2`，即翻完变 `[[0,0],[1,0]]`，这是 BFS 第 1 层的一个状态；继续搜到第 3 层才出现 `0`。

```python
from collections import deque
m, n = len(mat), len(mat[0])
start = sum(mat[i][j] << (i*n+j) for i in range(m) for j in range(n))
mask = []
for i in range(m):
    for j in range(n):
        v = 1 << (i*n+j)
        for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
            x, y = i+di, j+dj
            if 0 <= x < m and 0 <= y < n:
                v |= 1 << (x*n+y)
        mask.append(v)
seen, q, step = {start}, deque([start]), 0
while q:
    for _ in range(len(q)):
        s = q.popleft()
        if s == 0:
            return step
        for v in mask:
            t = s ^ v
            if t not in seen:
                seen.add(t); q.append(t)
    step += 1
return -1
```

## 复杂度
时间：状态数 `2^(m*n)`，每个状态试 `m*n` 个掩码，即 `O(2^(mn) * mn)`。
空间：`seen` 存最多 `2^(mn)` 个整数，队列同量级，`O(2^(mn))`。

## 易错点
- 输入 `[[1,0,0],[1,0,0]]`（2×3）→ 若把 `mask` 只算自身和右邻、漏掉上下邻，会误判成有解 → 掩码必须按 `(1,0),(-1,0),(0,1),(0,-1)` 四方向加边界判断生成。
- 输入 `[[0]]` → 若先入队再判 `0` 或把 `step` 初值设成 1，会返回 1 而非 0 → 在出队时判 `s == 0` 并让 `step` 从 0 起，保证全零矩阵直接返回 0。

## 如果面试官追问
若 m、n 放大到 4×4 以上，BFS 状态数 `2^16` 起会吃紧，怎么办？
答：按行枚举第一行翻转方案（`2^n` 种），逐行贪心确定后续行，取最小翻转数，复杂度降到 `O(2^n * mn)`。
