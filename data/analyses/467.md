## 一句话思路
用 `dp[c]` 记录以字符 c 结尾的最长连续环绕串长度，答案就是所有 `dp` 值之和，因为每个字符结尾的合法子串恰好是长度 1 到 `dp[c]`。

## 怎么做
1. 维护 `dp = [0]*26`，`dp[i]` 表示以字母 `chr(97+i)` 结尾、在 s 中出现过的最长环绕子串长度。
2. 遍历 s，用 `cur` 记录当前连续环绕段的长度：若 `(ord(s[i]) - ord(s[i-1])) % 26 == 1` 则 `cur += 1`，否则 `cur = 1`。
3. 对每个位置更新 `dp[ord(s[i])-97] = max(dp[...], cur)`，只保留最长的那次。
4. 返回 `sum(dp)`。

以 `s = "zab"` 为例：i=0 时 `cur=1`，`dp['z'-97]=1`；i=1 时 `(ord('a')-ord('z'))%26 = 1`，`cur=2`，`dp['a'-97]=2`；i=2 时 `cur=3`，`dp['b'-97]=3`。最终 `sum = 1+2+3 = 6`，与示例一致。

```python
dp = [0] * 26
cur = 0
for i, ch in enumerate(s):
    if i > 0 and (ord(ch) - ord(s[i-1])) % 26 == 1:
        cur += 1
    else:
        cur = 1
    idx = ord(ch) - 97
    if cur > dp[idx]:
        dp[idx] = cur
return sum(dp)
```

关键点：同一个字符可能多次出现，比如 `"cac"` 中 `'c'` 出现两次，第一次 `cur=1`，第二次 `cur=1`（因为 `'a'→'c'` 不连续），`dp['c'-97]` 始终为 1，`dp['a'-97]=1`，答案 2，正确。

## 复杂度
时间 O(n)：一次遍历 s，n 为 s 长度。
空间 O(1)：只开长度 26 的 `dp` 数组和常数个变量。

## 易错点
- 输入 `"cac"` → 若把每个连续段的所有子串都累加，会得到 `'c'`、`'a'`、`'c'` 共 3 个，重复计算了 `'c'` → 正确做法是用 `dp` 按结尾字符去重，只保留最长长度。
- 输入 `"zab"` → 若判断连续性时写成 `ord(ch) - ord(s[i-1]) == 1`，`'z'→'a'` 差值为 -25 会被判为断开，`cur` 重置为 1，答案错成 3 → 正确做法是取模 26：`(ord(ch) - ord(s[i-1])) % 26 == 1`。

## 如果面试官追问
问：如果要求输出所有不同的合法子串而非计数？
答：对每个字符 c，枚举长度 1 到 `dp[c]`，从 s 中该字符最后一次作为最长段结尾的位置向前截取即可。
