## 一句话思路
先对每个字母求「必须整段包含」的闭包区间，再按右端点贪心选区间，得到最多且总长最短。

## 怎么做
1. 扫一遍 `s` 记录每个字母的 `first[c]`、`last[c]`。
2. 对每个字母 `c`，从 `first[c]` 向右扩到 `last[c]`，途中遇到字母 `d` 就把右端推到 `last[d]`，直到不再变化，得到闭包区间 `[l, r]`。
3. 以 `s = "adefaddaccc"` 为例：`a` 的闭包是 `[0,7]`（含 `d`、`e`、`f` 的尾巴），`e` 是 `[2,2]`，`f` 是 `[3,3]`，`c` 是 `[8,10]`；`d` 的闭包也被 `a` 拉成 `[0,7]`。
4. 把所有闭包按右端点升序排，依次取「左端点大于上一个已选右端点」的区间，即得 `["e","f","ccc"]`。

```python
first = [n] * 26
last = [-1] * 26
for i, ch in enumerate(s):
    c = ord(ch) - 97
    first[c] = min(first[c], i)
    last[c] = i

intervals = []
for c in range(26):
    if last[c] == -1:
        continue
    l, r = first[c], last[c]
    j = l
    while j <= r:
        r = max(r, last[ord(s[j]) - 97])
        j += 1
    intervals.append((r, l))

intervals.sort()
res, end = [], -1
for r, l in intervals:
    if l > end:
        res.append(s[l:r + 1])
        end = r
```

## 复杂度
时间：O(26n + 26·26)，扫描与闭包扩展各贡献 n，排序只有 26 个元素。
空间：O(26) 存 first/last，结果列表最多 26 段。

## 易错点
- 闭包只扩一次就停：`s = "abacb"` 中 `a` 的 `last` 是 2，扩到 2 时遇到 `b` 要把右端推到 4，若不再回扫就会漏掉 `c`，得到错误区间 `[0,2]`。正确做法是 `while j <= r` 动态推进 `r`。
- 按左端点排序贪心：`s = "abbaccd"` 中 `a` 的闭包 `[0,3]` 左端最小，先选它会挤掉 `bb`、`cc`，只剩 2 段。必须按右端点升序，才能让 `bb`、`cc`、`d` 都入选。

## 如果面试官追问
若要求返回字典序最小的最优解？答：段数由右端点贪心唯一确定，同段数下总长最短也唯一，字典序需在等长候选间再比较，本题不涉及。
