## 一句话思路
按空格切词，逐词判断首字母是否在元音集合里，再按索引 1 起拼 `"ma" + "a"*i`。

## 怎么做
1. 用 `sentence.split(" ")` 切出单词列表，因为题面保证单个空格分隔、无首尾空格，直接切不会产生空串。
2. 对第 `i` 个单词（`i` 从 1 开始），取 `w[0].lower()` 判断是否在 `set("aeiou")` 中；注意必须 `lower()`，否则 `"I"`、`"Apple"` 会被当辅音。
3. 元音开头保留原词，辅音开头做 `w[1:] + w[0]`，然后统一追加 `"ma" + "a" * i`。
4. 用 `" ".join(...)` 拼回，空格数量与原文一致。

以示例 1 的 `"I speak Goat Latin"` 为例：第 1 词 `"I"`，`w[0].lower() == "i"` 命中元音，得 `"I" + "ma" + "a"*1 = "Imaa"`；第 3 词 `"Goat"`，`"g"` 不在元音集，先变 `"oatG"`，再拼 `"ma" + "aaa"` 得 `"oatGmaaaa"`。

```python
vowels = set("aeiou")
words = sentence.split(" ")
res = []
for i, w in enumerate(words, 1):
    if w[0].lower() in vowels:
        cur = w
    else:
        cur = w[1:] + w[0]
    res.append(cur + "ma" + "a" * i)
return " ".join(res)
```

关键就三行：`w[0].lower() in vowels`、`w[1:] + w[0]`、`"a" * i`。

## 复杂度
时间 O(n)：n 为 `sentence` 总长，每个字符被扫常数次，`"a"*i` 的总量也是 O(n)。
空间 O(n)：`res` 列表和最终字符串各存一份结果，`split` 另开一份词表。

## 易错点
- 输入 `"I speak Goat Latin"` → 若直接写 `w[0] in vowels` 而不 `lower()`，`"I"` 被判为辅音，输出 `"maI..."` 而非 `"Imaa"`；正确做法是先 `w[0].lower()` 再查集合，且集合里只放小写 `"aeiou"`。
- 输入 `"The quick brown fox"` → 若把索引写成从 0 开始，第 1 词 `"The"` 会得到 `"heTma"` 而非 `"heTmaa"`，整句每个词的 `a` 数量都少一个；正确做法是 `enumerate(words, 1)` 或 `i+1`，让第 1 词追加 1 个 `a`。

## 如果面试官追问
追问：如果单词间可能有多个空格、需要保留原空格怎么办？
答：改用 `re.split(r"(\s+)", sentence)` 保留分隔符，只对非空白片段做变换，索引只对单词递增。
