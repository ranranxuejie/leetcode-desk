## 一句话思路
从左到右扫，每个 `?` 只需避开左右两个邻居，26 个字母里最多排除 2 个，必能选到。

## 怎么做
1. 把 `s` 转成列表 `a`，因为字符串不可变，要按下标改。
2. 从左到右遍历 `i`，只处理 `a[i] == '?'`。
3. 对每个 `?`，从 `'a'` 起试，跳过 `a[i-1]`（`i>0` 时）和 `a[i+1]`（`i<n-1` 时）。
4. 找到第一个合法的就写回 `a[i]`，继续往右。

以 `s = "ubv?w"` 为例：`i=3` 时 `a[2]='v'`、`a[4]='w'`，从 `'a'` 试起，`'a'` 既不等于 `'v'` 也不等于 `'w'`，直接写入，得 `"ubvaw"`。

关键点：**只看左右邻居**。因为题目保证非 `?` 部分本身无连续重复，且左边已填好的位置不会再被改动，所以填 `i` 时只需保证与 `i-1`、`i+1` 不同，全局就无连续重复。

```python
a = list(s)
n = len(a)
for i in range(n):
    if a[i] != '?':
        continue
    for c in 'abcdefghijklmnopqrstuvwxyz':
        if i > 0 and a[i-1] == c:
            continue
        if i + 1 < n and a[i+1] == c:
            continue
        a[i] = c
        break
return ''.join(a)
```

注意 `a[i+1]` 此时可能还是 `'?'`，那它不等于任何小写字母，条件自然不触发，不用特判。

## 复杂度
时间 O(n)：每个 `?` 最多试 3 个字母就命中，扫描一趟。
空间 O(n)：`list(s)` 开了长度 n 的列表，返回值另算。

## 易错点
- 输入 `"???"` → 若只比较左邻居，会填成 `"aaa"` 连续重复 → 必须同时检查 `a[i+1]`，虽然它还是 `?`，但填完后相邻两个 `?` 会互相影响，正确结果是 `"aba"` 这类。
- 输入 `"?zs"` → 若从 `'z'` 开始试或忘了跳过右邻居 `'z'`，会得到 `"zzs"` → 必须跳过 `a[i+1]='z'`，从 `'a'` 起试得 `"azs"`。

## 如果面试官追问
问：如果要求返回字典序最小的方案？答：每个 `?` 仍从 `'a'` 起取第一个合法字母即可，因为各位置独立、互不影响，贪心就是最优。
