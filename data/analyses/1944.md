## 一句话思路
从右往左维护一个单调递减栈，栈里是当前人右侧所有「可能被看到」的候选，弹栈计数、遇高即停。

## 怎么做
1. 从 `n-1` 往 `0` 遍历 `heights`，栈 `st` 存右侧尚未被遮挡的候选高度（从栈底到栈顶递减）。
2. 对当前 `heights[i]`，循环弹出所有 `< heights[i]` 的栈顶，每弹一个 `answer[i] += 1`。
3. 弹完后若栈非空，说明还剩一个比 `heights[i]` 高的人挡在最前面，`answer[i] += 1`，然后 `st.append(heights[i])`。
4. 关键中间值：以 `heights = [10,6,8,5,11,9]` 为例，处理 `i=2`（高度 8）时栈为 `[9,11]`，弹出 9 使 `answer[2]=1`，栈顶 11 比 8 高，再 `+1` 得 `answer[2]=2`，与输出一致。

```python
n = len(heights)
answer = [0] * n
st = []
for i in range(n - 1, -1, -1):
    while st and st[-1] < heights[i]:
        st.pop()
        answer[i] += 1
    if st:
        answer[i] += 1
    st.append(heights[i])
```

被弹出的每个人都必然被 `i` 看到（中间无人更高），而栈里剩下的第一个更高者恰好是「挡住后面所有人」的那位，只贡献 1 次。

## 复杂度
时间：O(n)，每个下标入栈出栈各一次，循环总次数 2n。
空间：O(n)，`st` 最坏存 n 个高度，`answer` 另占 n。

## 易错点
- 输入 `[5,1,2,3,10]` → 若只弹 `<=` 或漏掉「弹完后栈非空再 +1」，`answer[0]` 会算成 3 而非 4 → 正确做法是弹严格小于者，弹完若栈非空补 1。
- 输入 `[10,6,8,5,11,9]` 处理 `i=0` → 若把栈里所有元素都算作可见，会得到 5 而非 3 → 只有被弹出的（6、8）和第一个更高的（11）可见，9 被 11 挡住不计。

## 如果面试官追问
问：若要求输出每个人具体看到的是哪些下标，怎么改？
答：栈里存下标而非高度，弹栈时把该下标记入 `answer[i]` 的列表，栈非空时再补栈顶下标。
