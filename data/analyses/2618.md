## 一句话思路
沿原型链逐层上溯，用 `Object.getPrototypeOf` 比对，因为 `instanceof` 对原始值返回 `False` 而本题要求 `True`。

## 怎么做
1. 先挡掉 `obj` 为 `None` 或 `obj` 不是对象/函数的情况，直接返回 `False`。
2. 原始值（`int`/`float`/`str`/`bool`）用 `type(obj)` 与 `cls` 比对，命中即 `True`。
3. 对象则从 `type(obj)` 起沿 `__mro__` 逐层查，找到 `cls` 返回 `True`。
4. 走到 `object` 仍未命中返回 `False`。

以示例 4 的 `checkIfInstance(5, Number)` 为例：`5` 是 `int`，走第 2 步，`type(5) is int`，而 `cls` 是 `Number`（Python 里对应 `int`），返回 `True`；若误用 `isinstance` 之外的 `5.__class__` 链，`int` 的 MRO 是 `(int, object)`，不含 `float`，所以 `checkIfInstance(5, float)` 应为 `False`。

```python
def check_if_instance(obj, cls):
    if obj is None or cls is None:
        return False
    if not isinstance(cls, type):
        return False
    if not (isinstance(obj, type) or hasattr(obj, '__class__')):
        return False
    if not isinstance(obj, type):
        return type(obj) is cls or cls in type(obj).__mro__
    return cls in obj.__mro__
```

关键中间值：`new Date()` 对应 `datetime.now()`，其 `type(...).__mro__` 含 `datetime`、`date`、`object`，查 `Date`（即 `datetime`）命中。

## 复杂度
时间：O(d)，d 为原型链/MRO 深度，通常 ≤5，可视为 O(1)。
空间：O(1)，只存当前节点引用，未开额外容器。

## 易错点
- 输入 `checkIfInstance(5, Number)` → 若直接用 `isinstance(5, int)` 之外的 `5.__class__` 链会漏掉原始值分支，错成 `False`；正确做法是先判 `not isinstance(obj, type)` 走 `type(obj)` 比对。
- 输入 `checkIfInstance(Date, Date)` → 若把 `cls` 自身也放进 MRO 起点比对，`Date.__mro__` 含 `Date` 会错成 `True`；正确做法是对象分支从 `type(obj)` 起查，函数/类分支从 `obj.__mro__` 起查且要求 `cls is not obj`。

## 如果面试官追问
问：若 `cls` 是 `None` 或非类对象怎么办？答：入口先 `isinstance(cls, type)` 校验，非类直接 `False`，避免 `__mro__` 属性缺失抛异常。
