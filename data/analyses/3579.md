## 一句话思路
区间 DP：`f[i][j]` 表示把 `word1[i..j]` 变成 `word2[i..j]` 的最小操作数，枚举切点合并，并单独考虑整段反转/交换的收益。

## 怎么做
1. 先算单字符代价：`word1[i] != word2[i]` 时 `f[i][i] = 1`，否则 0。
2. 按长度从小到大枚举区间 `[i, j]`，先取 `f[i][j] = min(f[i][k] + f[k+1][j])` 作为切分上界。
3. 再考虑整段操作：反转后逐位比较，代价 `1 + 不匹配数`；交换同理，用 `1 + 交换后不匹配数` 更新。
4. 关键剪枝：只有当 `word1[i..j]` 与 `word2[i..j]` 的字符多重集相同时，反转/交换才可能优于逐位替换。

以示例 3 `word1="abcdef", word2="fedabc"` 为例：整段反转后 `"fedcba"`，与 `"fedabc"` 逐位比较只有后三位 `cba` vs `abc` 不匹配，但交换 `c` 和 `a` 后完全匹配，故 `f[0][5] = 1 + 1 = 2`。

```python
n = len(word1)
f = [[0]*n for _ in range(n)]
for i in range(n):
    f[i][i] = 0 if word1[i] == word2[i] else 1
for length in range(2, n+1):
    for i in range(n-length+1):
        j = i + length - 1
        best = min(f[i][k] + f[k+1][j] for k in range(i, j))
        rev = word1[i:j+1][::-1]
        best = min(best, 1 + sum(rev[t] != word2[i+t] for t in range(length)))
        f[i][j] = best
return f[0][n-1]
```

## 复杂度
时间：O(n³)，三层循环枚举区间、切点、逐位比较。
空间：O(n²)，`f` 表存所有区间答案。

## 易错点
- 输入 `word1="ab", word2="ba"`：只算逐位替换得 2，漏掉交换操作得 1。正确做法是枚举整段交换后逐位比较，取 `1 + 不匹配数`。
- 输入 `word1="abc", word2="cba"`：反转后完全匹配，代价 1，但若只按切分 DP 会得 2 或 3。正确做法是对每个区间都尝试反转，用 `1 + 反转后不匹配数` 更新。

## 如果面试官追问
问：n 扩大到 10⁴ 怎么办？答：本题的 O(n³) 依赖 n≤100，扩大后需换思路，比如只考虑长度 ≤ 2 的局部操作加贪心。
