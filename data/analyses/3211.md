## 一句话思路
回溯逐位填 0/1，只禁止「上一位是 0 时再填 0」，因为长度 2 子串含 1 等价于没有连续两个 0。

## 怎么做
1. 用 `path` 存当前已填的字符，`dfs` 只关心 `path[-1]` 是不是 `'0'`。
2. 填 `'1'` 永远合法；填 `'0'` 仅当 `path` 为空或 `path[-1] == '1'`。
3. 长度到 `n` 时把 `''.join(path)` 收进答案。

以 `n = 3` 为例，走到 `path = ['0']` 时，下一位只能填 `'1'`，得到 `"01"`；再填 `'0'` 得 `"010"`，填 `'1'` 得 `"011"`。而 `path = ['0','0']` 这条分支在第二步就被剪掉，所以最终 5 个结果里没有 `"000"`、`"001"`、`"100"`。

```python
def dfs(path):
    if len(path) == n:
        ans.append(''.join(path))
        return
    path.append('1')
    dfs(path)
    path.pop()
    if not path or path[-1] == '1':
        path.append('0')
        dfs(path)
        path.pop()
```

关键剪枝就一行：`if not path or path[-1] == '1'`。注意 `path.pop()` 之后再判断 `path[-1]`，此时它才是「上一位」。

## 复杂度
时间 O(答案个数 × n)，每个叶子拷贝长度 n 的字符串；答案数即斐波那契数 F(n+2)。
空间 O(n) 递归栈 + O(答案总长) 输出，未计输出则额外 O(n)。

## 易错点
- `n = 1` → 若把「禁止连续 0」写成「首位不能是 0」，会漏掉 `"0"`，只剩 `["1"]`；正确做法是首位填 `'0'` 也放行，因为 `path` 为空时没有左邻。
- `n = 2` → 若在 `path.pop()` 之前读 `path[-1]`，读到的是刚弹出的 `'1'`，条件恒真，会错误产出 `"00"`；正确做法是先 `pop` 再判 `path[-1] == '1'`，或改用参数 `last` 传递上一位。

## 如果面试官追问
问：n 放大到 10^5、只要方案数不要具体串怎么办？
答：`f[i] = f[i-1] + f[i-2]`，`f[1]=2, f[2]=3`，滚动两变量 O(n) 时间 O(1) 空间。
