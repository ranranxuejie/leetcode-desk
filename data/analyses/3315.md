## 一句话思路
质数只有 2 是偶数，其余为奇；奇数 x 的最小解是把最低位的 0 置 1 后减一，即 `x - (lowbit(x) + 1) // 2`。

## 怎么做
1. 若 `x == 2` 直接返回 -1，因为 `a | (a+1)` 恒为奇数。
2. 对奇数 x，设最低位的 0 在权值 `p = lowbit(~x)` 处，则 `a = x - p // 2` 是最小解。
3. 用 `p = (x + 1) & ~x` 取这个权值，避免对负数取 lowbit。
4. 验证 `a | (a+1) == x` 后写入答案。

以 `nums = [11,13,31]` 为例：x=11 二进制 1011，最低位 0 在权值 4，`a = 11 - 2 = 9`，`9 | 10 = 1011 = 11`；x=13 是 1101，最低位 0 在权值 2，`a = 13 - 1 = 12`，`12 | 13 = 13`；x=31 是 11111，最低位 0 在权值 32，`a = 31 - 16 = 15`，`15 | 16 = 31`。三个值都与示例输出一致。

```python
def solve(nums):
    ans = []
    for x in nums:
        if x == 2:
            ans.append(-1)
            continue
        p = (x + 1) & ~x      # 最低位 0 的权值
        a = x - p // 2
        ans.append(a if (a | (a + 1)) == x else -1)
    return ans
```

关键点：`a` 与 `a+1` 只在最低位 0 处发生进位，该位以下全 1、以上与 x 相同，所以 OR 结果恰好把这一位补成 1，得到 x。取 `p//2` 而非 `p` 是因为 a 在该位必须是 0，进位后变 1。

## 复杂度
时间 O(n log max(nums))，每个数做常数次位运算，log 来自整数位宽。
空间 O(n)，仅答案数组，无额外结构。

## 易错点
- 输入含 2 → 若套用奇数公式会算出 `p = 3 & ~2 = 1`、`a = 2 - 0 = 2`，但 `2 | 3 = 3 ≠ 2`，错答 2；正确做法是先判 `x == 2` 返回 -1。
- 用 `x & -x` 取 lowbit → 那是最低位 1 的权值，对 11 得 1，算出 `a = 10`，`10 | 11 = 11` 虽成立但不是最小；正确做法是取最低位 0 的权值 `(x+1) & ~x`。

## 如果面试官追问
若 nums 不再限定质数、允许偶数怎么办？答：偶数 x 的 `a | (a+1)` 必为奇数，直接返回 -1，其余逻辑不变。
