## 一句话思路
直接套两条线性公式，一次算出 `kelvin` 和 `fahrenheit` 放进列表返回。

## 怎么做
1. 开氏度用 `celsius + 273.15`，华氏度用 `celsius * 1.80 + 32.00`，两个公式互不依赖，顺序随意。
2. 把两个结果按 `[kelvin, fahrenheit]` 的顺序放进列表，顺序反了示例 1 就对不上。
3. 不要对结果做 `round`，题目只要求误差 ≤ 1e-5，多保留小数无害，反而 `round(x, 2)` 会把 251.798 砍成 251.8。

以 `celsius = 122.11` 为例，关键中间值：`kelvin = 122.11 + 273.15 = 395.26`，`fahrenheit = 122.11 * 1.80 + 32.00 = 219.798 + 32.00 = 251.798`，正好对上示例 2 的 `[395.26000, 251.79800]`。

```python
def convert(celsius):
    kelvin = celsius + 273.15
    fahrenheit = celsius * 1.80 + 32.00
    return [kelvin, fahrenheit]
```

注意 `1.80` 写成 `1.8` 结果一样，但别写成 `9/5` 的整数除法 `9 // 5`，那会得到 1，`122.11` 的华氏度就变成 154.11，直接错。

## 复杂度
时间：O(1)，两次浮点运算，与 `celsius` 大小无关。
空间：O(1)，只开了 `kelvin`、`fahrenheit` 两个标量和长度 2 的返回列表。

## 易错点
- 输入 `celsius = 0` → 若把华氏度写成 `celsius * 1.8` 漏掉 `+ 32.00`，会返回 `[273.15, 0.0]`，正确应是 `[273.15, 32.0]`；常数项必须显式加上。
- 输入 `celsius = 122.11` → 若对结果调 `round(fahrenheit, 2)`，得到 `251.8`，虽然误差判定可能仍过，但一旦题目收紧到精确匹配就挂；正确做法是原样返回浮点值，不做任何舍入。

## 如果面试官追问
问：如果要求返回结果四舍五入到 5 位小数怎么办？
答：对两个值各调 `round(x, 5)` 再入列表，注意 `round` 是银行家舍入，边界值需用 `Decimal` 兜底。
