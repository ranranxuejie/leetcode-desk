## 一句话思路
先 DFS 求每个节点的子树大小，再用 `n - size[u]` 补出「父方向」那块，三块相乘取最大。

## 怎么做
1. 由 `parents` 建 `children` 邻接表，跳过 `parents[0] == -1`。
2. 后序 DFS 求 `size[u] = 1 + sum(size[c])`，同时算分数：把每个孩子子树大小、以及 `n - size[u]`（非零时）都乘进 `score`。
3. 用 `best` 和 `cnt` 边算边更新，最后返回 `cnt`。

以 `parents = [-1,2,0,2,0]` 为例：`children[2] = [1,3]`，`children[0] = [2,4]`。DFS 到节点 1 得 `size[1] = 1`，分数只有父方向 `5 - 1 = 4`；节点 2 得 `size[2] = 3`，分数 `size[1] * size[3] * (5-3) = 1*1*2 = 2`；节点 0 得 `size[0] = 5`，分数 `size[2] * size[4] = 3*1 = 3`。最大值 4 出现 3 次。

```python
def dfs(u):
    nonlocal best, cnt
    s, score = 1, 1
    for c in children[u]:
        cs = dfs(c)
        s += cs
        score *= cs
    if n - s:
        score *= n - s
    if score > best:
        best, cnt = score, 1
    elif score == best:
        cnt += 1
    size[u] = s
    return s
```

注意 `n - s` 为 0 时（根节点）不能乘，否则分数变 0。

## 复杂度
时间 O(n)：每个节点进 DFS 一次，邻接表遍历每条边一次。
空间 O(n)：`children` 存 n-1 条边，递归栈最坏 O(n)。

## 易错点
- 输入 `parents = [-1,2,0]`（链状）→ 若把 `n - size[u]` 无条件乘进去，根节点 0 的分数变成 `2 * 0 = 0`，正确答案应是 2 → 必须判断 `n - s != 0` 才乘。
- 输入 `parents = [-1,2,0,2,0]` → 若只乘孩子子树、漏掉父方向，节点 1 分数算成 1（无孩子时乘积为 1），实际应为 4 → 叶子节点分数就是 `n - 1`，必须补上父方向那块。

## 如果面试官追问
问：n 扩大到 10^6、递归会爆栈怎么办？
答：改成迭代后序（显式栈存 `(u, 状态)`），或先按 `parents` 逆序处理——父节点编号不一定小于子节点，需先拓扑排序出后序。
