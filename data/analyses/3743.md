## 一句话思路
把环在某处剪开成链，用 DP 枚举「第一段从哪开始」并记录首段极值，避免重复枚举起点。

## 怎么做
1. 环划分等价于选一个切点把数组拉成链，链上做「至多 k 段」的区间划分 DP。
2. 固定起点 s，令 `dp[j][t]` 为前 j 个元素分成 t 段的最大得分，转移枚举最后一段起点 i，加上 `max(nums[i:j]) - min(nums[i:j])`。
3. 对每个 s 跑一次，取所有 s、所有 t≤k 的最大值；n≤1000 时 O(n³k) 会超，需用单调栈/预处理区间极值把转移降到 O(1) 查询。
4. 以 `nums=[1,2,3,3], k=2` 为例，取 s=1（即链 `[2,3,3,1]`），切 `[2,3]` 与 `[3,1]`，两段范围 1 和 2，得分 3，与示例一致。

```python
# 预处理区间极值后，链上 DP 的核心转移
for t in range(1, k + 1):
    for j in range(1, n + 1):
        best = 0
        for i in range(t - 1, j):
            rng = mx[i][j] - mn[i][j]
            best = max(best, dp[t - 1][i] + rng)
        dp[t][j] = best
```

## 复杂度
时间 O(n³k)（枚举起点 s、段数 t、终点 j、切点 i），预处理极值后转移可降到 O(n²k)。
空间 O(n²) 存区间极值表，DP 表 O(nk)。

## 易错点
- 只从下标 0 切链 → 漏掉环绕方案，如示例 1 的 `[3,1]` 跨尾首，必须枚举所有起点 s。
- 把「最多 k 段」当成「恰好 k 段」→ 示例 3 中 k=4 但最优只用 2 段，需在所有 t≤k 上取 max，不能只取 t=k。

## 如果面试官追问
问：n 放大到 1e5 怎么办？
答：区间极值用单调栈 + 分治或线段树维护，DP 转移用斜率/单调队列优化，目标 O(nk log n)。
