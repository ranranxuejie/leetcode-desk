## 一句话思路
用 Floyd 求全源最短路，再逐城数 `dist[i][j] <= distanceThreshold` 的邻居，取最少且编号最大者。

## 怎么做
1. 建 `dist = [[inf]*n for _ in range(n)]`，对角线置 0，每条边双向填权重。
2. 三重循环 Floyd：`dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`。
3. 对每个 i 数 `sum(1 for j in range(n) if j != i and dist[i][j] <= distanceThreshold)`。
4. 用 `(cnt, -i)` 取最小，最后返回 `-i`，即编号最大者胜出。

以示例 1 为例，`n=4, distanceThreshold=4`。Floyd 跑完后 `dist[0][2]` 不是直连的 inf，而是 `0→1→2 = 3+1 = 4`，恰好 `<= 4`，所以城市 0 的邻居数是 2；`dist[0][3] = 0→1→3 = 3+4 = 7 > 4`，不计入。城市 3 同样得 2，比较时 `(2,-0)` 与 `(2,-3)`，后者更小，返回 3。

```python
inf = float('inf')
dist = [[inf] * n for _ in range(n)]
for i in range(n):
    dist[i][i] = 0
for u, v, w in edges:
    dist[u][v] = dist[v][u] = w
for k in range(n):
    for i in range(n):
        dik = dist[i][k]
        for j in range(n):
            if dik + dist[k][j] < dist[i][j]:
                dist[i][j] = dik + dist[k][j]
best, best_cnt = -1, n
for i in range(n):
    cnt = sum(1 for j in range(n) if j != i and dist[i][j] <= distanceThreshold)
    if cnt <= best_cnt:
        best, best_cnt = i, cnt
return best
```

## 复杂度
时间 O(n³)：Floyd 三重循环，n ≤ 100 时约 10⁶ 次。
空间 O(n²)：`dist` 二维表，未额外开堆或队列。

## 易错点
- 示例 1 中 `dist[0][2]` 若只填直连边就是 inf，会漏掉经城市 1 中转的路径 4，导致城市 0 邻居数算成 1 而非 2；必须跑完 Floyd 再统计。
- 平局时若用 `cnt < best_cnt` 严格小于，示例 1 会停在城市 0 返回 0；正确写法是 `cnt <= best_cnt` 且按 i 升序遍历，让后面的更大编号覆盖，或直接比较 `(cnt, -i)`。

## 如果面试官追问
若 n 涨到 10⁴ 而边稀疏，Floyd 的 O(n³) 不可行，怎么办？
答：对每个点跑一次 Dijkstra（堆优化），只统计距离 ≤ 阈值的点，复杂度降到 O(n·(m log n))。
