## 一句话思路
把「每个篮子两个槽」摊平成 2*numSlots 个槽，用位掩码 DP 按槽位从低到高填数，每步挑一个未用的 nums 元素。

## 怎么做
1. 槽位编号 `slot = i // 2 + 1`（i 从 0 起），篮子编号就是槽位号，两个槽共享同一个篮子编号。
2. `dp[mask]` 表示已用掉 mask 中这些 nums 元素时的最大与和；mask 的 popcount 就是已填的槽数，决定当前填第几个槽。
3. 转移：`dp[mask | (1<<j)] = max(..., dp[mask] + (nums[j] & slot))`，j 取所有未用元素。
4. 答案取 `dp[(1<<n)-1]`。

以示例 1 `nums=[1,2,3,4,5,6], numSlots=3` 为例：槽 0、1 都属于篮子 1，槽 2、3 属于篮子 2。填到 `mask` 有 2 个 1 时，`slot = 2//2+1 = 2`，此时把 `nums[5]=6` 放进去得 `6 & 2 = 2`，与示例里 `6 AND 2 = 2` 对上。

```python
n = len(nums)
full = 1 << n
dp = [-1] * full
dp[0] = 0
for mask in range(full):
    if dp[mask] < 0:
        continue
    slot = mask.bit_count() // 2 + 1   # 下一个要填的槽所属篮子
    for j in range(n):
        if not (mask >> j) & 1:
            nm = mask | (1 << j)
            v = dp[mask] + (nums[j] & slot)
            if v > dp[nm]:
                dp[nm] = v
return dp[full - 1]
```

注意 `slot` 只由 `mask.bit_count()` 决定，与具体用了哪些元素无关——这是把「篮子」压成「槽」的关键。

## 复杂度
时间：`O(2^n * n)`，n 是 nums 长度，枚举 mask 与未用元素。
空间：`O(2^n)`，dp 数组，无其他额外结构。

## 易错点
- 把槽位写成 `mask.bit_count() + 1` 而不是 `// 2 + 1`：示例 1 中填第 2 个槽时篮子编号会算成 3 而非 2，`6 & 3 = 2` 恰好相同但 `4 & 3 = 0` 与正确值 `4 & 1 = 0` 也巧合，换 `nums=[2,2,...]` 就会偏大。正确做法是 `bit_count() // 2 + 1`。
- 只对 `mask` 中 popcount 为偶数的状态转移，或漏掉 `dp[mask] < 0` 的跳过：前者会让第二个槽永远填不上，后者会让 `-1` 参与加法把答案拉低。正确做法是遍历全部 mask，用 `dp[mask] < 0` 剪掉不可达状态。

## 如果面试官追问
问：numSlots 放大到 20 怎么办？
答：`2^n` 已不可行，需换思路；本题 n ≤ 18 才使位掩码 DP 成立。
