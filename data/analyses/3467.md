## 一句话思路
数出偶数个数 `z`，答案就是 `z` 个 0 接上 `n - z` 个 1，无需真的替换再排序。

## 怎么做
1. 用 `sum(1 for x in nums if x % 2 == 0)` 统计偶数个数，记为 `z`。
2. 结果数组前 `z` 位全是 0，后 `n - z` 位全是 1，直接拼接返回。
3. 以 `nums = [1,5,1,4,2]` 为例：偶数只有 4 和 2，`z = 2`，`n = 5`，于是前 2 位是 0、后 3 位是 1，得 `[0,0,1,1,1]`，与官方输出一致。
4. 关键中间值就是 `z`：它同时决定了 0 的个数和 1 的起始下标，替换与排序两步都被它吸收掉了。

```python
z = sum(1 for x in nums if x % 2 == 0)
n = len(nums)
return [0] * z + [1] * (n - z)
```

也可以写成 `[0] * z + [1] * (len(nums) - z)`，省掉 `n` 这个中间变量。

## 复杂度
时间 O(n)：一次遍历统计偶数，拼接本身也是 O(n)。
空间 O(n)：结果数组占 n 个位置，`z` 和 `n` 是常数级。

## 易错点
- 输入 `nums = [2,4,6]` → 若把「偶数替换为 0」理解成保留原值再排序，会返回 `[2,4,6]` → 正确做法是先做奇偶映射，全偶时答案必须是 `[0,0,0]`。
- 输入 `nums = [1,5,1,4,2]` → 若先原地替换成 `[1,1,1,0,0]` 再调 `sort()`，虽然结果对，但多了一次 O(n log n) 排序 → 正确做法是只数 `z`，用 `[0]*z + [1]*(n-z)` 一次成型，避免无谓的排序开销。

## 如果面试官追问
问：如果要求返回「原数组每个元素被替换后的值」而不是排序后的数组呢？
答：那就不能只数 `z`，要逐位输出 `x % 2 == 0` 对应的 0 或 1，仍是 O(n) 一次遍历。
