## 一句话思路
对 `[lo, hi]` 每个数用记忆化求权重，再按 `(权重, 数值)` 双关键字排序取第 `k-1` 个。

## 怎么做
1. 建字典 `memo`，先存 `{1: 0}`，把「到 1 的步数」作为递归基准。
2. 写 `weight(x)`：命中 `memo` 直接返回；否则按奇偶走一步，`memo[x] = 1 + weight(下一步)`。
3. 对 `range(lo, hi+1)` 每个 `x` 算出 `(weight(x), x)`，装进列表。
4. 列表排序（元组天然先比权重再比数值），返回下标 `k-1` 的元素。

以示例 1 的 `lo=12, hi=15, k=2` 为例，关键中间值是 `weight(12)`：12→6→3→10→5→16→8→4→2→1 共 9 步，而 `weight(3)` 在算 12 时已被写入 `memo`，后面算 13 时 13→40→20→10 直接命中 `memo[10]`，省掉后半段。最终四个元组是 `(9,12),(9,13),(17,14),(17,15)`，排序后第 2 个（下标 1）是 13。

```python
memo = {1: 0}
def weight(x):
    if x in memo:
        return memo[x]
    nxt = x // 2 if x % 2 == 0 else 3 * x + 1
    memo[x] = 1 + weight(nxt)
    return memo[x]

items = [(weight(x), x) for x in range(lo, hi + 1)]
items.sort()
return items[k - 1][1]
```

注意 `x % 2 == 0` 判断偶数、`x // 2` 用整除；奇数分支 `3 * x + 1` 在 Python 里不会溢出，无需截断。

## 复杂度
时间：`hi-lo+1` 个数各算一次权重，每个数的链长约 `log` 级，排序 `O(n log n)`。
空间：`memo` 存链上所有中间值，规模与最大链长同阶，外加 `n` 个元组的列表。

## 易错点
- 只对 `[lo, hi]` 内的数做记忆化、不缓存链上跑出去的中间值（如 12 链上的 40、20）→ 13、14 重复走长链，`hi=1000` 时白白多算几百步 → 正确做法是 `memo` 全局共享，任何算过的 `x` 都写进去。
- 排序只按权重、忽略并列时的数值升序 → 示例 1 中 12 和 13 权重都是 9，若排序不稳定或只比权重，可能返回 12 而非 13 → 正确做法是直接排 `(weight, x)` 元组，让 Python 的字典序兜住第二关键字。

## 如果面试官追问
问：若 `hi` 放大到 `10**6`，还这么写行吗？
答：行，记忆化后每个数均摊接近 O(1)，瓶颈变成排序的 `O(n log n)`；要更快可用桶按权重分桶。
