## 一句话思路
统计负数个数与最小绝对值：偶数个负数全翻正，奇数个则牺牲绝对值最小的那个。

## 怎么做
1. 遍历 `matrix` 全部元素，累加 `abs(x)` 到 `total`，同时记录负数个数 `neg` 和最小绝对值 `min_abs`。
2. 若 `neg` 为偶数，答案就是 `total`；否则答案是 `total - 2 * min_abs`。
3. 关键中间值：示例 2 中 `total = 1+2+3+1+2+3+1+2+3 = 18`，`neg = 3`（奇数），`min_abs = 1`，答案 `18 - 2 = 16`。

```python
total = 0
neg = 0
min_abs = 10**5 + 1
for row in matrix:
    for x in row:
        total += abs(x)
        if x < 0:
            neg += 1
        min_abs = min(min_abs, abs(x))
return total if neg % 2 == 0 else total - 2 * min_abs
```

为什么成立：一次操作翻转两个相邻格，等价于同时改变两个格符号，因此负数个数的奇偶性只在「翻两个」时不变——实际上每次操作改变负数个数为偶数（0 或 ±2），所以 `neg` 的奇偶性是不变量。方阵 n≥2 连通，任意两个格都能通过相邻翻转配对，所以只要 `neg` 是偶数就能全翻正；是奇数则必剩一个负数，选绝对值最小的那个损失最小。

## 复杂度
时间 O(n²)：每个元素访问一次，n 是边长。
空间 O(1)：只用了 `total`、`neg`、`min_abs` 三个变量。

## 易错点
- 输入含 0 且负数个数为奇数，如 `[[0,-1],[-1,-1]]`：若只按「奇数就减 2*min_abs」且 `min_abs` 取到 1，会得 `total-2`；但 0 可以当「免费翻转点」，正确做法是 `min_abs` 取到 0 时答案就是 `total`，因为 0 翻符号不变，等价于把奇数个负数配成偶数。
- 全负数且 n 为奇数，如 3×3 全 -1：`neg=9` 奇数，`total=9`，`min_abs=1`，答案 `9-2=7`；若误以为「负数多就保留大的」去减最大绝对值会得 3，错在应牺牲绝对值最小的。

## 如果面试官追问
问：若要求输出具体翻转方案而非只求和？
答：先按上述定符号，再对每对「需翻正的负号格」沿相邻路径逐格翻转，路径上中间格被翻两次抵消，只改两端。
