## 一句话思路
用哈希集合边遍历边查，`nums[i]` 已在集合里就说明重复，直接返回 `True`。

## 怎么做
1. 建一个空集合 `seen`，用来存已经扫过的值。
2. 从左到右遍历 `nums`，每个元素先判断 `if x in seen`。
3. 命中就立即 `return True`，没命中就 `seen.add(x)` 继续。
4. 循环走完没命中，说明所有值互不相同，`return False`。

以示例 1 `nums = [1,2,3,1]` 为例：扫到下标 0 时 `seen = {1}`，下标 1 后 `seen = {1,2}`，下标 2 后 `seen = {1,2,3}`；到下标 3 的 `x = 1`，`1 in seen` 为 `True`，此时函数返回 `True`，后面的元素不再看。关键中间值就是这一步的 `seen` 已经含 `1`。

```python
seen = set()
for x in nums:
    if x in seen:
        return True
    seen.add(x)
return False
```

排序法作为对照：`nums.sort()` 后比较相邻元素 `nums[i] == nums[i-1]`，示例 1 排序成 `[1,1,2,3]`，下标 1 处就命中。它省掉集合但改了原数组，且要多花排序时间，面试默认写哈希版。

## 复杂度
时间 O(n)：遍历 n 个元素，集合查找和插入均摊 O(1)。
空间 O(n)：`seen` 最坏存下全部 n 个不同值。

## 易错点
- 输入 `nums = [1,2,3,4]` 时若把 `return False` 写在循环体内（每轮没命中就返回），下标 0 的 `1` 没命中就立刻返回 `False`，答案碰巧对但逻辑错；正确做法是 `return False` 放在 for 循环之外，只有全部扫完才执行。
- 输入 `nums = [1,1,1,3,3,4,3,2,4,2]` 时若用 `len(set(nums)) == len(nums)` 一行判断，虽然结果对，但会先把整个数组转成集合、丢掉「提前返回」的机会；正确做法是边遍历边查，示例 3 在下标 1 的第二个 `1` 就返回 `True`，不必扫完 10 个元素。

## 如果面试官追问
问：不允许额外空间怎么办？
答：先 `nums.sort()` 再比较相邻元素，时间升到 O(n log n)，空间降到 O(1)（不计排序栈），代价是修改了入参。
