## 一句话思路
枚举 1 到 min(a,b) 的每个 x，用 `a % x == 0 and b % x == 0` 判断，计数即可。

## 怎么做
1. 取上界 `m = min(a, b)`，公因子不可能超过较小者。
2. 从 1 遍历到 m，逐个判断能否同时整除 a 和 b。
3. 满足条件就 `count += 1`，最后返回 count。

以 a = 12, b = 6 为例，m = 6。遍历到 x = 3 时，`12 % 3 == 0` 且 `6 % 3 == 0` 成立，count 从 2（x=1,2）变成 3；x = 6 时再 +1，最终 count = 4，与示例一致。

```python
m = min(a, b)
count = 0
for x in range(1, m + 1):
    if a % x == 0 and b % x == 0:
        count += 1
return count
```

更省事的写法是先求 `g = math.gcd(a, b)`，再枚举 g 的因子：公因子集合恰好等于 gcd 的因子集合。对 a=12,b=6，g=6，枚举 1..6 中整除 6 的数得 1,2,3,6 共 4 个。两种写法在 a,b ≤ 1000 时都能过，前者更直白，后者是数论正解。

## 复杂度
时间：O(min(a,b))，循环上界由较小者贡献，每次取模 O(1)。
空间：O(1)，只用了 count、m 两个变量。

## 易错点
- 循环写成 `range(1, m)` 漏掉 m 本身 → 对 a=12,b=6 会输出 3 而不是 4，因为 6 是公因子却被排除；正确写法是 `range(1, m + 1)`。
- 用 `a % x == 0 or b % x == 0` 代替 and → 对 a=25,b=30 会把只整除其一的 2、3、10 等也算进去，输出远大于 2；必须两个条件同时成立。

## 如果面试官追问
若 a、b 放大到 10^9 怎么办？答：先 `g = math.gcd(a, b)`，再枚举 1..isqrt(g) 成对计数，复杂度降到 O(√g)。
