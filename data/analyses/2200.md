## 一句话思路
从左到右扫一遍，维护「最近一个 key 的下标」，用它判断当前下标是否落在 k 范围内。

## 怎么做
1. 先正向扫，记录每个位置左侧（含自身）最近的 key 下标 `last`，若 `i - last <= k` 则标记。
2. 再反向扫一遍，记录右侧最近的 key 下标，补上正向漏掉的。
3. 两遍标记都为真的下标按序收集。

以 `nums = [3,4,9,1,3,9,5], key = 9, k = 1` 为例：正向扫到 `i=2` 时 `last=2`，标记 2；`i=3` 时 `last=2`，`3-2=1<=1` 标记 3；`i=4` 时 `last=2`，`4-2=2>1` 不标记，但反向扫时右侧 `last=5`，`5-4=1<=1` 补标 4。

```python
n = len(nums)
ok = [False] * n
last = -10**9
for i in range(n):
    if nums[i] == key:
        last = i
    if i - last <= k:
        ok[i] = True
last = 10**9
for i in range(n - 1, -1, -1):
    if nums[i] == key:
        last = i
    if last - i <= k:
        ok[i] = True
return [i for i in range(n) if ok[i]]
```

## 复杂度
时间 O(n)：正向、反向各扫一遍，收集再扫一遍。
空间 O(n)：`ok` 布尔数组占 n 个位置，返回值另算。

## 易错点
- `nums = [9,1,1,1,9], k = 1` 只正向扫会漏掉下标 3（左侧 key 在 0，距离 3>1），必须反向补扫，否则输出缺 3。
- `last` 初值若用 `0` 而非足够小的负数，`nums = [1,1,9], key = 9, k = 1` 中 `i=0` 会误判 `0-0<=1` 把 0 标进去；初值要取 `-10**9`（或先判断 `last != -1`）。

## 如果面试官追问
若 k 很大、key 出现很多次，能否 O(1) 额外空间？可以：用双指针维护当前覆盖区间 `[last-k, last+k]`，边扫边输出，但要注意去重相邻区间。
