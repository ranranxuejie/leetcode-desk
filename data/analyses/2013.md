## 一句话思路
用哈希表按 x 分组存 y 的计数，查询时枚举同列的点确定边长，再查另外两个角是否存在。

## 怎么做
1. 用 `cols: dict[int, Counter]` 存每个 x 上各 y 出现次数，`add` 时 `cols[x][y] += 1`。
2. 查询 `(px, py)` 时，遍历 `cols[px]` 中所有 `y != py` 的点，边长 `d = abs(y - py)`。
3. 对每个 `y`，两个候选 x 是 `px - d` 和 `px + d`，分别查 `cols[x][y]` 和 `cols[x][py]` 的计数。
4. 累加 `cnt(y) * cnt(x, y) * cnt(x, py)`，即三个角的组合数。

以示例查询 `count([11, 10])` 为例：`cols[11]` 里有 `y=2`（计数 2）和 `y=10`。取 `y=2`，`d=8`，候选 `x=3`；`cols[3][2]=1`，`cols[3][10]=1`，贡献 `2*1*1=2`。取 `y=10` 时 `d=0` 跳过。结果 2，与输出一致。

```python
def count(self, point):
    px, py = point
    ans = 0
    for y, cy in self.cols.get(px, {}).items():
        d = abs(y - py)
        if d == 0:
            continue
        for x in (px - d, px + d):
            col = self.cols.get(x)
            if not col:
                continue
            ans += cy * col.get(y, 0) * col.get(py, 0)
    return ans
```

## 复杂度
时间：`add` O(1)；`count` O(同列不同 y 的个数)，最坏 O(n)，n 为总点数。
空间：O(n)，哈希表存每个不同 (x, y) 的计数。

## 易错点
1. 查询点自身同列有重复点，如 `add([11,10])` 两次后 `count([11,10])`：若把 `y == py` 也当边长 `d=0` 处理，会算出退化正方形并多计。正确做法是 `d == 0` 直接 `continue`，因为题目要求面积为正。
2. 重复点被当作不同点：示例中 `[11,2]` 加了两次，`count([11,10])` 从 1 变 2。若用 `set` 存点会丢掉重复，答案恒为 1。正确做法是用 `Counter` 存计数，三个角相乘 `cy * col[y] * col[py]` 而不是布尔判断。

## 如果面试官追问
问：坐标范围扩大到 10^9 怎么办？答：哈希表本来就按实际出现的坐标存，与坐标范围无关，复杂度只取决于点数 n。
