## 一句话思路
在有序数组上二分，遇到 `words[mid] == ""` 就把 `mid` 往左挪到非空再比较，因为空串不携带大小信息。

## 怎么做
1. 设 `lo, hi = 0, len(words) - 1`，循环条件 `lo <= hi`。
2. 每轮先算 `mid = (lo + hi) // 2`，然后 `while mid > lo and words[mid] == "": mid -= 1`，把空串跳过。
3. 若 `words[mid] == s` 返回 `mid`；若 `words[mid] < s` 则 `lo = mid + 1`，否则 `hi = mid - 1`。
4. 循环结束返回 `-1`。

关键中间值：以示例 2 为例，`words` 长度 13，`s = "ball"`。第一轮 `lo=0, hi=12, mid=6`，`words[6] == ""`，左移到 `mid=5` 仍是 `""`，再左移到 `mid=4` 得 `"ball"`，与 `s` 相等，直接返回 `4`。注意这里 `mid` 从 6 一路退到 4，比较用的不是原来的 6。

```python
lo, hi = 0, len(words) - 1
while lo <= hi:
    mid = (lo + hi) // 2
    while mid > lo and words[mid] == "":
        mid -= 1
    if words[mid] == s:
        return mid
    if words[mid] < s:
        lo = mid + 1
    else:
        hi = mid - 1
return -1
```

`mid > lo` 这个下界不能写成 `mid > 0`：若 `lo` 已经右移，退到 `lo` 之前会把区间外的元素拿来比较。

## 复杂度
时间：最坏 O(n)，空串连续时每轮左移可能扫过整段，非空时才是 O(log n)。
空间：O(1)，只用了 `lo, hi, mid` 三个变量。

## 易错点
1. 输入 `words = ["", "", "a"]`、`s = "a"` → 若左移写成 `while mid > 0`，`mid` 会退到 0 拿到 `""` 与 `"a"` 比较，判成 `"" < "a"` 后 `lo = 1`，丢掉答案 → 正确做法是下界用 `mid > lo`，保证退到的位置仍在 `[lo, hi]` 内。
2. 输入 `words = ["a", "", "", ""]`、`s = "b"` → 若左移后忘记用新的 `mid` 更新 `hi`，仍按原 `mid=1` 收缩，`hi` 停在 1，`lo=0` 时反复比较 `"a"` 死循环或漏判 → 正确做法是左移后所有比较和 `lo/hi` 更新都用左移后的 `mid`。

## 如果面试官追问
问：若空串极多、要求严格 O(log n) 怎么办？
答：预处理每个位置左侧最近的非空下标数组，二分时 O(1) 跳到非空位，代价是 O(n) 额外空间。
