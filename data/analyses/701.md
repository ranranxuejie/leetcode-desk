## 一句话思路
沿 BST 比较大小一路向下，走到空位挂上新节点即可，因为插入点唯一且必是叶子位置。

## 怎么做
1. 若 `root` 为 `None`，直接返回 `TreeNode(val)`，覆盖空树和递归到底两种情况。
2. 比较 `val` 与 `root.val`：小就往 `root.left` 递归，大就往 `root.right` 递归。
3. 把递归返回值接回 `root.left` 或 `root.right`，最后返回 `root`。

以示例 1 的 `root = [4,2,7,1,3], val = 5` 为例：`5 > 4` 走右子树到 `7`；`5 < 7` 走左子树，`7.left` 是 `None`，于是新建节点 `5` 挂在 `7` 的左边。中间关键值是第二次比较后 `root` 变成 `7`、`root.left` 为 `None`。

```python
def insertIntoBST(self, root, val):
    if root is None:
        return TreeNode(val)
    if val < root.val:
        root.left = self.insertIntoBST(root.left, val)
    else:
        root.right = self.insertIntoBST(root.right, val)
    return root
```

迭代写法同理：用 `cur` 走到 `None` 前一步，再按最后一次比较结果挂到 `cur.left` 或 `cur.right`，省掉递归栈。

## 复杂度
时间：O(h)，h 为树高，最坏链状 O(n)，与节点总数 n 无关的平均情况是 O(log n)。
空间：递归栈 O(h)；迭代写法额外 O(1)，只开了 `cur` 指针。

## 易错点
- 空树 `root = []`、`val = 5` → 若只写递归分支不判 `root is None`，会对 `None.val` 报错 → 第一行必须返回 `TreeNode(val)`，它同时是空树答案和叶子挂载点。
- 示例 2 的 `val = 25` → 若写成 `val <= root.val` 走左边，虽然本题保证不重复不会立刻错，但把等值情况塞进左子树会破坏「左 < 根 < 右」的严格性 → 用 `val < root.val` 走左、`else` 走右，等值不可能出现。

## 如果面试官追问
问：要求插入后树高最小（尽量平衡）怎么办？
答：普通 BST 插入点由大小关系唯一确定，无法选位置；要平衡得换 AVL/红黑树的旋转逻辑，或先收集中序再重建。
