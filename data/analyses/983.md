## 一句话思路
按 `days` 的下标做 DP，`dp[i]` 表示覆盖前 i 个旅行日的最低花费，每次枚举三种票从哪个位置接上。

## 怎么做
1. 令 `dp[0] = 0`，`dp[i]` 表示覆盖 `days[0..i-1]` 这 i 天的最低消费。
2. 对每个 i，三种票分别回退：1 天票从 `dp[i-1]` 接，7 天票找第一个满足 `days[j] > days[i-1] - 7` 的 j，从 `dp[j]` 接，30 天票同理。
3. 取三者最小值赋给 `dp[i]`。
4. 答案是 `dp[n]`。

以示例 1 `days = [1,4,6,7,8,20]`、`costs = [2,7,15]` 为例，算到 i=5（`days[4]=8`）时：1 天票 = `dp[4]+2`；7 天票回退到 `days[j] > 1`，j=1，得 `dp[1]+7 = 2+7 = 9`；30 天票回退到 j=0，得 `dp[0]+15 = 15`。取 min 得 `dp[5] = 9`。最后 i=6（`days[5]=20`）时 7 天票回退到 j=5，得 `dp[5]+7 = 16`，1 天票得 `dp[5]+2 = 11`，答案 11。

```python
n = len(days)
dp = [0] * (n + 1)
for i in range(1, n + 1):
    dp[i] = dp[i - 1] + costs[0]
    for k, dur in ((1, 7), (2, 30)):
        j = i - 1
        while j > 0 and days[j - 1] > days[i - 1] - dur:
            j -= 1
        dp[i] = min(dp[i], dp[j] + costs[k])
return dp[n]
```

## 复杂度
时间：O(n²)，n 为 `days` 长度，每个 i 最多回退 n 步。
空间：O(n)，`dp` 数组长度 n+1，无其他额外结构。

## 易错点
- 7 天票的边界写成 `days[j] >= days[i-1] - 7` → 会把第 `days[i-1]-7` 天也当成被覆盖，示例 1 中 i=5 时错误回退到 j=0，得 `dp[5]=15` 而非 9 → 正确条件是严格大于 `days[i-1] - 7`，即票从 `days[i-1]-6` 起生效。
- 把 DP 下标当成「天数」而不是「`days` 的下标」→ 在 `days = [1,4,6,7,8,20]` 上按天遍历会多算 20 个空状态，且回退时找不到对应 `days` 元素 → 必须用 `days` 的下标 i 做状态，回退时比较的是 `days[j-1]` 与 `days[i-1] - dur`。

## 如果面试官追问
问：如果 `days` 长度放大到 10^5 怎么办？
答：把内层 while 换成 `bisect_right(days, days[i-1] - dur)` 二分找 j，时间降到 O(n log n)。
