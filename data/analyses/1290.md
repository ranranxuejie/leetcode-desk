## 一句话思路
边遍历边用 `ans = ans * 2 + node.val` 累积，因为每读一位相当于把已有结果左移一位再补上这一位。

## 怎么做
1. 初始化 `ans = 0`，指针 `cur = head`。
2. 循环 `while cur:`，每轮执行 `ans = ans * 2 + cur.val`，然后 `cur = cur.next`。
3. 循环结束返回 `ans`。

以 `head = [1,0,1]` 为例，关键中间值：读到第 2 个结点 `0` 时，`ans` 从 `1` 变成 `1*2+0 = 2`；读到第 3 个结点 `1` 时，`ans = 2*2+1 = 5`，正好是 `(101)₂`。

```python
ans = 0
cur = head
while cur:
    ans = ans * 2 + cur.val
    cur = cur.next
return ans
```

`ans * 2` 就是二进制左移一位，`+ cur.val` 就是补上最低位，所以遍历到链表尾部时 `ans` 就是完整十进制值。头结点是最高位，天然对应「先读到的位权重最高」，不需要反转链表或先求长度。

## 复杂度
时间 O(n)：n 是结点数，每个结点做一次乘 2 加一次加法。
空间 O(1)：只开了 `ans` 和 `cur` 两个变量，没开额外数组或栈。

## 易错点
- 输入 `head = [1,0,1]` 若写成 `ans = ans + cur.val * 2**i` 且 `i` 从 0 递增，会错成 `1*1+0*2+1*4 = 5` 碰巧对，但换成 `[1,1]` 会错成 `1+2 = 3`（正确是 3 也碰巧对），真正翻车在 `[1,0]`：错成 `1+0 = 1`，正确是 2。正确做法是用 `ans * 2 + val` 让旧结果整体左移。
- 输入 `head = [0]` 或前导零如 `[0,1,1]`，若先算长度再按 `2**(n-1-i)` 加权，`[0,1,1]` 会算成 `0*4+1*2+1 = 3` 正确，但若把前导零当有效位处理长度就会多算一位权重，错成 6。正确做法是统一用累乘法，前导零自然贡献 `0*2 = 0`，不影响结果。

## 如果面试官追问
追问：链表结点数放宽到 10^5 怎么办？
答：累乘法仍是 O(n) 时间 O(1) 空间，只是 Python 大整数会变长，实际复杂度按位数算，逻辑不用改。
