## 一句话思路
先枚举分界点，用前缀和 O(1) 取两侧窗口和，再用两个方向的「左侧最大窗口和」数组把 O(n²) 压到 O(n)。

## 怎么做
1. 用 `pre[i]` 表示 `nums[:i]` 的和，则长度 `L` 起点 `i` 的窗口和是 `pre[i+L]-pre[i]`。
2. 正序扫一遍，`leftA[i]` = 起点 ≤ i 的长度 `firstLen` 窗口最大和；同理 `leftB` 用 `secondLen`。
3. 倒序扫一遍得 `rightA[i]`、`rightB[i]`，表示起点 ≥ i 的最大窗口和。
4. 枚举分界 `k`（`firstLen+secondLen ≤ k ≤ n`），取 `max(leftA[k-firstLen] + rightB[k], leftB[k-secondLen] + rightA[k])`。

以示例 1 为例，`nums=[0,6,5,2,2,5,1,9,4]`，`firstLen=1`，`secondLen=2`。分界 `k=8` 时，`leftA[7]` 是 `nums[:8]` 中长度 1 的最大窗口和 = 9（取 `nums[7]`），`rightB[8]` 是 `nums[8:]` 中长度 2 的窗口和，只有起点 8 越界，故该侧为负无穷；换 `k=7`，`leftA[6]=6`，`rightB[7]` 取 `nums[7:9]=[9,4]` 和 13，合计 19；真正命中 20 的是 `k=6`：`leftA[5]=6`（`nums[1]`），`rightB[6]` 取 `nums[6:8]=[1,9]` 和 10，不对——实际 20 来自 `leftB` 侧：`leftB[6]` 中长度 2 最大是 `[6,5]=11`，`rightA[6]` 中长度 1 最大是 `nums[7]=9`，11+9=20。

```python
n = len(nums)
pre = [0] * (n + 1)
for i, x in enumerate(nums):
    pre[i + 1] = pre[i] + x
def win(L):
    return [pre[i + L] - pre[i] for i in range(n - L + 1)]
wa, wb = win(firstLen), win(secondLen)
NEG = -10**18
la = [NEG] * (n + 1); lb = [NEG] * (n + 1)
for i in range(len(wa)):
    la[i + 1] = max(la[i], wa[i])
for i in range(len(wb)):
    lb[i + 1] = max(lb[i], wb[i])
ra = [NEG] * (n + 1); rb = [NEG] * (n + 1)
for i in range(len(wa) - 1, -1, -1):
    ra[i] = max(ra[i + 1], wa[i])
for i in range(len(wb) - 1, -1, -1):
    rb[i] = max(rb[i + 1], wb[i])
ans = 0
for k in range(firstLen + secondLen, n + 1):
    ans = max(ans, la[k - firstLen] + rb[k], lb[k - secondLen] + ra[k])
```

## 复杂度
时间 O(n)：前缀和、四次扫描、一次枚举分界各 O(n)。
空间 O(n)：`pre`、`la/lb/ra/rb` 共 5 个长度 n+1 的数组。

## 易错点
- `nums` 全为 0 或窗口和可能为 0 时，若把 `NEG` 初始化成 0，`la[k-firstLen]` 在无合法窗口时会假性参与比较，把答案算成偏大值；必须用 `-10**18` 这类真负无穷，且 `ans` 从 0 起（本题 `nums[i]≥0`）。
- 分界 `k` 的下界写成 `firstLen+secondLen` 而不是 `max(firstLen, secondLen)`：`k` 表示「前段至少容纳一个完整窗口」，若取小了，`la[k-firstLen]` 索引为负会静默取到数组尾部，示例 2 中 `firstLen=3, secondLen=2` 会因此把 `[8,9]` 和 `[3,8,1]` 重叠计算。
