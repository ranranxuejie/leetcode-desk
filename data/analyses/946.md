## 一句话思路
用一个栈模拟 push，每压入一个就尽量按 popped 顺序弹出，最后栈空即合法。

## 怎么做
1. 维护栈 `st` 和指向 `popped` 的指针 `j = 0`。
2. 遍历 `pushed`，每个元素 `x` 先 `st.append(x)`。
3. 压入后立刻用 `while st and st[-1] == popped[j]` 连续弹出并 `j += 1`。
4. 遍历结束返回 `not st`（等价 `j == len(popped)`）。

以示例 1 为例，压到 `4` 时 `st = [1,2,3,4]`，`st[-1] == popped[0] == 4`，弹出后 `st = [1,2,3]`、`j = 1`；接着压 `5`，`st[-1] == popped[1] == 5`，弹出后 `j = 2`，此时 `st[-1] == 3 == popped[2]`，继续弹到 `j = 5`、`st` 空，返回 `True`。

示例 2 里压到 `4` 弹出后 `j = 1`，`st[-1] == 3 == popped[1]`，弹出 `j = 2`；再压 `5` 弹出 `j = 3`，此时 `st = [1,2]`，`st[-1] == 2` 但 `popped[3] == 1`，while 不成立；遍历结束 `st` 非空，返回 `False`。

```python
st, j = [], 0
for x in pushed:
    st.append(x)
    while st and st[-1] == popped[j]:
        st.pop()
        j += 1
return not st
```

关键点：`while` 必须循环而不是 `if`，因为一次压入可能触发连续多次弹出（示例 1 压 `5` 后连弹三次）。

## 复杂度
时间 O(n)：每个元素最多进栈一次、出栈一次，`while` 总次数不超过 n。
空间 O(n)：`st` 最坏存下全部 `pushed` 元素。

## 易错点
- 把 `while` 写成 `if`：输入 `pushed=[1,2,3]`、`popped=[3,2,1]`，压 `3` 后只弹一次得 `st=[1,2]`、`j=1`，遍历结束栈非空误判 `False`；正确做法是循环弹到栈顶不等于 `popped[j]` 为止。
- 在 `while` 条件里漏掉 `st` 非空判断：输入 `pushed=[1]`、`popped=[1]`，弹出后 `st` 为空，若继续访问 `st[-1]` 会抛 `IndexError`；正确写法是 `while st and st[-1] == popped[j]`，短路求值先挡住空栈。

## 如果面试官追问
问：若 `popped` 不是 `pushed` 的排列（长度或元素可能不匹配）怎么办？
答：先判 `len(pushed) == len(popped)` 且元素集合相等，再跑同一模拟，否则直接 `False`。
