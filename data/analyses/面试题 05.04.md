## 一句话思路
用位运算直接构造：把最低位的 `01` 翻成 `10` 并把低位 1 全挤到最低处得后继，反向操作得前驱。

## 怎么做
1. 后继：找最靠右的 `01`（即 `num` 中最低的 `0` 且其右侧有 `1`），把它翻成 `10`，再把右侧所有 `1` 压到最低位。
2. 前驱：找最靠右的 `10`（最低的 `1` 且其左侧有 `0`），翻成 `01`，再把右侧所有 `1` 顶到最高位。
3. 两个方向都找不到时返回 `-1`。

以 `num = 2`（`0b10`）为例：后继找 `01` 失败（只有 `10`），改用「最低的 0 在 bit0，右侧无 1」——实际是 `0b10` 的 `01` 不存在，走通用式 `c = num & -num` 得 `2`，`r = num + c = 4`，`ones = ((r ^ num) // c) >> 2 = 0`，答案 `4`。前驱：`c = 2`，`r = num - c = 0`，`ones = ((num ^ r) // c) >> 2 = 0`，答案 `0` 但需为正数，故 `1`。

```python
def findClosedNumbers(num):
    big = -1
    c = num & -num
    r = num + c
    if r <= 2**31 - 1:
        ones = ((r ^ num) // c) >> 2
        big = r | (ones - 1) if ones else r
    small = -1
    c = num & -num
    r = num - c
    if r > 0:
        ones = ((num ^ r) // c) >> 2
        small = r | ((1 << ones) - 1) if ones else r
    return [big, small]
```

关键中间值：`num = 2` 时后继 `c = 2, r = 4, ones = 0`，得 `4`；前驱 `r = 0` 不满足 `> 0`，落到 `-1` 分支前先判正数。

## 复杂度
时间 O(log num)：位运算常数次，`ones` 移位次数与 1 的个数成正比。
空间 O(1)：只开了 `c, r, ones` 几个整数。

## 易错点
- `num = 1`（`0b1`）→ 前驱 `r = 0`，若直接返回 `0` 就错，题目要求正数，应返回 `-1`；正确做法是 `r > 0` 才计算 `small`。
- `num = 2**31 - 1`（31 个 1）→ 后继 `r = 2**31` 超出 32 位上限，若直接返回会得到非法值；正确做法是 `r <= 2**31 - 1` 才赋值 `big`，否则 `-1`。

## 如果面试官追问
问：若 `num` 可达 64 位怎么办？答：把 `2**31 - 1` 换成 `2**63 - 1`，其余位运算逻辑不变。
