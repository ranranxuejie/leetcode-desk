## 一句话思路
双指针从两端向中间扫，每对 `s[i]` 与 `s[j]` 取较小者同时赋给两端，既保证回文又字典序最小。

## 怎么做
1. 把 `s` 转成可变列表 `a`，左右指针 `i=0`、`j=len(s)-1`。
2. 当 `i < j` 时，取 `c = min(a[i], a[j])`，把 `a[i]` 和 `a[j]` 都改成 `c`。
3. 指针内移 `i += 1`、`j -= 1`，循环结束返回 `''.join(a)`。

以 `s = "egcfe"` 为例：`i=0,j=4` 时 `a[0]='e'`、`a[4]='e'`，`c='e'` 不变；`i=1,j=3` 时 `a[1]='g'`、`a[3]='f'`，`c='f'`，于是 `a[1]` 从 `'g'` 改成 `'f'`，得到 `"efcfe"`。中间 `i=j=2` 的 `'c'` 不动。

```python
a = list(s)
i, j = 0, len(a) - 1
while i < j:
    c = min(a[i], a[j])
    a[i] = a[j] = c
    i += 1
    j -= 1
return ''.join(a)
```

关键点：每对字符若不同，必须改一个才能成回文，改小的那个是唯一能同时满足「操作数最少」和「字典序最小」的选择——改大的那个会让这一位变大，字典序反而更差。

## 复杂度
时间 O(n)：`i` 和 `j` 各走 n/2 步，每步 O(1)。
空间 O(n)：`list(s)` 开了长度 n 的列表，返回值另算。

## 易错点
- 输入 `s = "abcd"`：若只把 `a[j]` 改成 `a[i]`（单向复制），得到 `"abca"` 不是回文；正确做法是 `a[i] = a[j] = min(a[i], a[j])`，两端同时赋值，得到 `"abba"`。
- 输入 `s = "seven"`：若写成 `max(a[i], a[j])`，`i=0,j=4` 时 `'s'` 与 `'n'` 取 `'s'`，输出 `"seves"`，字典序比正确答案 `"neven"` 大；必须取 `min`，让靠前的位置尽量小。

## 如果面试官追问
问：若允许删除字符而非替换，怎么求最少删除次数使其成回文？
答：转成 `s` 与 `s[::-1]` 的最长公共子序列，答案 `n - LCS`，O(n²) DP。
