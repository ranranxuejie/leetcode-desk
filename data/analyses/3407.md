## 一句话思路
把 p 按 `*` 切成前缀 a 和后缀 b，在 s 里找一个 a 的起点，使 b 紧接其后出现。

## 怎么做
1. 用 `p.split('*')` 得到 `a, b`，`*` 可吞任意长，所以只需 a 的结尾位置 ≤ b 的起始位置。
2. 枚举 a 在 s 中的每个出现位置 `i`（`s.find(a, start)` 循环推进），得到 a 的结束位置 `i + len(a)`。
3. 从 `i + len(a)` 起找 b，若 `s.find(b, i + len(a)) != -1` 就返回 `True`。
4. 全部起点试完返回 `False`；a 为空时 `find` 返回 0，天然覆盖「`*` 在开头」的情形。

以 `s = "leetcode", p = "ee*e"` 为例：`a = "ee"`，`b = "e"`。`s.find("ee")` 得 `i = 1`，a 结束于 3；`s.find("e", 3)` 得 3，返回 `True`（对应子串 `"eetcode"`，`*` 吞掉 `"tcod"`）。

```python
def hasMatch(s, p):
    a, b = p.split('*')
    start = 0
    while True:
        i = s.find(a, start)
        if i == -1:
            return False
        if s.find(b, i + len(a)) != -1:
            return True
        start = i + 1
```

关键点：`start = i + 1` 而不是 `i + len(a)`，因为 a 的出现位置可能重叠（如 `a = "aa"`、`s = "aaa"`），跳过会漏解。

## 复杂度
时间 O(|s|·|p|)：最坏每个起点做一次 `find`，Python 的 `find` 是线性扫描。
空间 O(|p|)：只存切出来的 a、b 两个串，无额外数组。

## 易错点
- 输入 `s = "aaa", p = "aa*aa"` → 若把 `start` 推进到 `i + len(a)`，会跳过 `i = 1` 这个起点而错判 `False`；正确做法是每次只 `+1`，让重叠出现也被枚举。
- 输入 `s = "car", p = "c*v"` → 若只检查 a 和 b 是否各自出现在 s 中（`"c"` 在、`"v"` 不在）就下结论，逻辑上碰巧对，但换成 `p = "c*r"` 会错判 `True`；正确做法是必须验证 b 出现在 a 结束位置**之后**，即 `s.find(b, i + len(a))`。

## 如果面试官追问
若 `*` 可以出现多个，怎么改？答：切成 k+1 段，从第一段末尾开始依次贪心 `find` 每段，任一段找不到即 `False`。
