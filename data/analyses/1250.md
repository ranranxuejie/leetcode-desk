## 一句话思路
裴蜀定理：子集能凑出 1 当且仅当这些数的 gcd 为 1，所以只需对全数组求 gcd。

## 怎么做
1. 从 `nums[0]` 起，用 `math.gcd` 逐个累除，得到全数组的 gcd。
2. 中途若 gcd 已变成 1，可提前返回 `True`（后面再 gcd 也还是 1）。
3. 循环结束返回 `g == 1`。

以 `nums = [12,5,7,23]` 为例：`g` 依次为 12 → gcd(12,5)=1，此时已可返回 `True`；对应解释里挑的 5、7 满足 5*3+7*(-2)=1，正是 gcd(5,7)=1 的体现。再看 `[3,6]`：gcd(3,6)=3≠1，返回 `False`。

```python
from math import gcd

def isGoodArray(nums):
    g = 0
    for x in nums:
        g = gcd(g, x)
        if g == 1:
            return True
    return g == 1
```

关键点：`g` 初值取 0，`gcd(0, x) = x`，省去对 `nums[0]` 的特判；`nums` 长度至少 1，不会出现空数组返回 `g == 1` 为 `False` 的歧义。

## 复杂度
时间：O(n log M)，n 为 `nums` 长度，log M 来自每次 gcd 的欧几里得除法，M 为元素上界 1e9。
空间：O(1)，只开了一个累除变量 `g`。

## 易错点
- 误以为要枚举子集：`nums = [12,5,7,23]` 有 15 个非空子集，n 到 1e5 时组合爆炸；正确做法是只算全数组 gcd，因为 gcd 为 1 时必存在某个子集（由裴蜀定理保证），无需真的找出来。
- 把「子集 gcd 为 1」写成「存在两数互质」：`nums = [6,10,15]` 两两 gcd 分别是 2、3、5 都不为 1，但 gcd(6,10,15)=1，返回 `True`；必须累除全部元素，不能只查相邻或两两。

## 如果面试官追问
问：要求输出一组系数怎么办？答：对全数组做扩展欧几里得，把每步的系数按 gcd 合并回代，得到满足 Σ nums[i]*c[i] = 1 的整数系数。
