## 一句话思路
奇偶下标各自独立，只需分别保留出现次数最多的值，冲突时退而求其次选次大值。

## 怎么做
1. 用两个 Counter 分别统计偶数下标和奇数下标的元素频次，记 `even`、`odd`。
2. 取各自频次最高的两个值（含次数），不足两个时用 `(0, 0)` 占位。
3. 若两边的第一名值不同，直接都保留第一名；若相同，则比较「even 第一名 + odd 第二名」与「even 第二名 + odd 第一名」，取较大者。
4. 答案 = `n - 保留的总数`。

以 `nums = [3,1,3,2,4,3]` 为例：偶数下标元素是 `[3,3,4]`，`even` 第一名 `(3,2)`、第二名 `(4,1)`；奇数下标是 `[1,2,3]`，`odd` 第一名 `(1,1)`、第二名 `(2,1)`。两边第一名值 `3 != 1`，保留 `2 + 1 = 3` 个，答案 `6 - 3 = 3`。

```python
from collections import Counter

even = Counter(nums[0::2])
odd = Counter(nums[1::2])
e = even.most_common(2) + [(0, 0)] * 2
o = odd.most_common(2) + [(0, 0)] * 2
if e[0][0] != o[0][0]:
    keep = e[0][1] + o[0][1]
else:
    keep = max(e[0][1] + o[1][1], e[1][1] + o[0][1])
return len(nums) - keep
```

## 复杂度
时间：O(n)，遍历 nums 建两个 Counter，`most_common(2)` 只多 O(不同值个数)。
空间：O(n)，两个 Counter 最多各存 n/2 个不同值。

## 易错点
- 输入 `[1,2,2,2,2]`：偶数下标 `[1,2,2]` 第一名是 `2`（2 次），奇数下标 `[2,2]` 第一名也是 `2`，若直接相加会得到 `2+2=4` 保留数，答案错成 1；正确做法是走冲突分支，`max(2+0, 1+2)=3`，答案 `5-3=2`。
- 输入 `[1]` 或 `[1,1]`：`odd` 可能为空 Counter，`most_common(2)` 返回不足两项，直接取 `o[1]` 会 IndexError；正确做法是补 `[(0,0)]*2` 占位，让空侧贡献 0。

## 如果面试官追问
要求输出具体方案怎么办？答：在保留第一/第二名时同时记下对应值，把偶数位全填该值、奇数位全填另一值，逐位比对原数组统计改动下标即可。
