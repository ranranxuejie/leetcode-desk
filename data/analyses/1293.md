## 一句话思路
把状态从 `(r,c)` 扩成 `(r,c,used)`，用 BFS 按步数分层搜索，第一次弹出终点即为最短步数。

## 怎么做
1. 状态是 `(r, c, used)`，`used` 为已消除障碍数；起点 `(0,0,0)` 入队，`dist` 用三维数组或字典记录。
2. 每步向四邻扩展，若 `grid[nr][nc]==1` 则 `used+1`，超过 `k` 就丢弃。
3. 出队时若 `(r,c)==(m-1,n-1)` 直接返回当前步数，BFS 保证最短。
4. 队列空仍未到终点返回 `-1`。

以示例 1 为例，`grid` 5×3、`k=1`。BFS 第 3 层到达 `(1,2)` 时 `used=0`；第 4 层从 `(1,2)` 下探 `(2,2)`（`grid=0`，`used=0`）；第 5 层到 `(3,2)` 时 `grid[3][2]=1`，`used` 变 1，仍 ≤ k；第 6 层到 `(4,2)` 出队返回 6。关键中间值：`(3,2)` 处 `used=1`，若 `k=0` 这条分支会被剪掉。

```python
from collections import deque
q = deque([(0, 0, 0)])
seen = {(0, 0, 0)}
step = 0
while q:
    for _ in range(len(q)):
        r, c, used = q.popleft()
        if (r, c) == (m - 1, n - 1):
            return step
        for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < m and 0 <= nc < n:
                nu = used + grid[nr][nc]
                if nu <= k and (nr, nc, nu) not in seen:
                    seen.add((nr, nc, nu))
                    q.append((nr, nc, nu))
    step += 1
return -1
```

## 复杂度
时间 O(m·n·k)：每个 `(r,c,used)` 状态最多入队一次，四邻扩展常数。
空间 O(m·n·k)：`seen` 集合与队列各存至多这么多状态。

## 易错点
- 只按 `(r,c)` 去重 → 示例 1 中先以 `used=1` 到达 `(3,2)` 会挡住后来 `used=0` 的更优路径，导致误判 -1；必须把 `used` 放进状态键。
- `k` 很大时（如 `k >= m+n-2`）不剪枝 → 状态数膨胀到 40×40×1600；正确做法是先把 `k` 截到 `m+n-2`，因为最短路径最多经过这么多格。

## 如果面试官追问
问：要求输出具体路径怎么办？
答：`seen` 改存前驱 `(pr,pc,pu)`，终点出队后沿前驱回溯，再反转。
