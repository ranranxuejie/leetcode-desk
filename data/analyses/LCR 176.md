## 一句话思路
后序 DFS 让每个节点返回自身高度，同时用 -1 表示「子树已失衡」，一次遍历即可判定。

## 怎么做
1. 定义 `dfs(node)`：空节点返回 0，否则递归取左右子树高度 `lh`、`rh`。
2. 若 `lh == -1 or rh == -1 or abs(lh - rh) > 1`，直接返回 -1 向上短路。
3. 否则返回 `max(lh, rh) + 1`，最后判断 `dfs(root) != -1`。

以示例 2 的 `[1,2,2,3,3,null,null,4,4]` 为例：到节点 `3`（值为 3 的左孩子）时，它的左孩子是 `4`、右孩子是 `4`，`lh = rh = 1`，返回 2；回到值为 2 的节点，其左子树高 2、右子树高 0，`abs(2 - 0) = 2 > 1`，返回 -1，一路冒泡到根，结果为 `False`。

```python
def dfs(node):
    if not node:
        return 0
    lh = dfs(node.left)
    if lh == -1:
        return -1
    rh = dfs(node.right)
    if rh == -1 or abs(lh - rh) > 1:
        return -1
    return max(lh, rh) + 1

return dfs(root) != -1
```

关键在 `-1` 这个哨兵：它既表示「不平衡」，又不会和合法高度（≥0）混淆，所以父节点只需一次 `== -1` 判断就能剪枝，不必再往下算。

## 复杂度
时间 O(n)：每个节点被访问一次，失衡后靠 -1 提前返回，不会重复计算子树高度。
空间 O(h)：递归栈深度等于树高 h，最坏链状树 h = n，未额外开数组。

## 易错点
- 输入 `[1,2,2,3,3,null,null,4,4]` → 若只比较根节点左右子树高度（都是 3）就返回 `True`，错成 `True`；正确做法是每个节点都检查 `abs(lh - rh) > 1`，失衡点在值为 2 的节点处。
- 输入 `[1,null,2,null,3]`（长链） → 若用「自顶向下对每个节点重算高度」的写法，会退化成 O(n²) 且递归深度达 10000 触发栈溢出；正确做法是后序一次遍历，用 -1 短路，深度只走一遍。

## 如果面试官追问
问：节点数涨到 10^6、递归会爆栈怎么办？
答：改成显式栈做后序，用字典存每个节点的高度，逻辑不变，空间仍是 O(n)。
