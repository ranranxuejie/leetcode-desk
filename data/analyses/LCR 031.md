## 一句话思路
哈希表存 key→节点，双向链表按访问顺序串节点，头新尾旧，get/put 都 O(1)。

## 怎么做
1. 建 `self.map = {}` 和带 `prev/next` 的哨兵 `head/tail`，`head.next` 是最新、`tail.prev` 是最旧。
2. `get(key)`：不在 `map` 返回 -1；在则把该节点摘出、插到 `head` 后，返回 `node.val`。
3. `put(key, value)`：已存在则改 `val` 并移到头部；不存在则新建节点插头部、写入 `map`，若 `len(map) > capacity` 就删 `tail.prev` 并从 `map` 里 pop 它的 key。
4. 摘除和插入各写成一个 4 行小函数，避免在 get/put 里重复改 6 个指针。

以官方示例 `capacity=2` 走到 `put(3,3)` 时：此时链表头到尾是 `1,2`，`len(map)=2` 已满，先删 `tail.prev` 即 key=2，`map` 变成 `{1:node1}`，再插入 3，链表为 `3,1`，所以随后 `get(2)` 返回 -1。

```python
def _remove(self, node):
    node.prev.next, node.next.prev = node.next, node.prev

def _add_front(self, node):
    node.next, node.prev = self.head.next, self.head
    self.head.next.prev = node
    self.head.next = node

def get(self, key):
    if key not in self.map:
        return -1
    node = self.map[key]
    self._remove(node)
    self._add_front(node)
    return node.val
```

## 复杂度
时间：每次 get/put 只做常数次指针改动和一次字典查找，O(1)。
空间：`map` 与链表各存至多 capacity 个节点，O(capacity)。

## 易错点
- `put` 一个已存在的 key（如示例里若再 `put(1,10)`）→ 只改值不移位，会让 1 仍被当成最旧而先被淘汰 → 必须先 `_remove` 再 `_add_front`，顺序不能省。
- `capacity=1` 时 `put` 新 key → 先插后删会把刚插入的节点自己删掉（`tail.prev` 就是新节点）→ 正确做法是先判断 `len(map) > capacity` 再删，且删除发生在插入之后、用被删节点的 key 去 `map.pop`，不要用当前 key。

## 如果面试官追问
问：要支持按过期时间淘汰怎么办？答：链表按过期时间排序或用最小堆存 (expire, key)，get 时惰性删除堆顶过期项。
