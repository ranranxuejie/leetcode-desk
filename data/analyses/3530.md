## 一句话思路
用位掩码 `mask` 表示已处理节点集合，`dp[mask]` 存该集合的最大利润，按 `popcount(mask)+1` 作为下一个节点的位置乘数转移。

## 怎么做
1. 预处理 `pre[v]`：节点 v 的所有前驱位掩码，`pre[v] |= 1 << u`。
2. `dp` 数组长 `1<<n`，`dp[0]=0`，其余 `-1`；`dp[mask]` 表示处理完 `mask` 中节点后的最大利润。
3. 枚举 `mask`，对每个不在 `mask` 里的 v，若 `pre[v] & mask == pre[v]` 则可加入，位置为 `k = popcount(mask)+1`，转移 `dp[mask|1<<v] = max(..., dp[mask] + score[v]*k)`。
4. 答案是 `dp[(1<<n)-1]`。

以示例 2 为例：`pre[1]=pre[2]=0b001`，`pre[0]=0`。`mask=0b001`（已放节点 0）时 `k=2`，节点 1、2 都可入：放 2 得 `1+3*2=7`，放 1 得 `1+6*2=13`；再从 `mask=0b101` 放 1，`k=3`，得 `7+18=25`，即最优。

```python
pre = [0] * n
for u, v in edges:
    pre[v] |= 1 << u
full = (1 << n) - 1
dp = [-1] * (1 << n)
dp[0] = 0
for mask in range(1 << n):
    if dp[mask] < 0:
        continue
    k = bin(mask).count("1") + 1
    for v in range(n):
        if not (mask >> v) & 1 and pre[v] & mask == pre[v]:
            nm = mask | (1 << v)
            dp[nm] = max(dp[nm], dp[mask] + score[v] * k)
return dp[full]
```

## 复杂度
时间：`O(2^n * n)`，`2^n` 个状态各扫 n 个候选节点。
空间：`O(2^n)`，`dp` 数组加 `pre` 的 n 个整数。

## 易错点
- 用 `pre[v] & mask == pre[v]` 判前驱，若写成 `pre[v] & mask` 非零就跳过，会把「前驱已全在 mask 里」误判为不可入，示例 2 中 `mask=0b001` 时节点 1 被错误排除，答案退化成 13。
- 乘数 `k` 必须用 `popcount(mask)+1` 而不是 `popcount(mask)`，示例 1 中 `mask=0` 放节点 0 时 `k=1`，写成 0 会让 `score[0]*0=0`，最终得 6 而非 8。

## 如果面试官追问
问：n 放宽到 30 怎么办？答：位掩码 DP 的 `2^n` 状态爆炸，需换思路（如按 score 排序的贪心在一般 DAG 上不成立，只能说明该规模下本题无多项式解法）。
