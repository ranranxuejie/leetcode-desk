## 一句话思路
n≤12，枚举所有子集掩码，用 `dp[mask]` 记录该子集能否构成回文，再枚举两个不相交掩码取长度乘积最大值。

## 怎么做
1. 预处理每个掩码对应子序列是否为回文：`dp[mask]` 为 `True` 当且仅当按位取出的字符正反相同。
2. 枚举 `mask` 从 1 到 `(1<<n)-1`，用双指针从两端向中间比对字符，判断回文。
3. 双重枚举 `a`、`b`，若 `a & b == 0` 且两者都是回文，更新 `ans = max(ans, popcount(a) * popcount(b))`。
4. 返回 `ans`。

以 `s = "leetcodecom"`（n=11）为例，取 `a` 对应下标 `{1,3,5}` 得 `"ete"`，`b` 对应 `{6,8,10}` 得 `"cdc"`，`a & b == 0`，乘积 `3*3=9`。

```python
n = len(s)
full = 1 << n
ok = [False] * full
for mask in range(1, full):
    idx = [i for i in range(n) if mask >> i & 1]
    chars = [s[i] for i in idx]
    ok[mask] = chars == chars[::-1]
ans = 0
for a in range(1, full):
    if not ok[a]:
        continue
    for b in range(1, full):
        if a & b == 0 and ok[b]:
            ans = max(ans, bin(a).count('1') * bin(b).count('1'))
```

## 复杂度
时间：`O(2^n * n + 4^n)`，双重枚举掩码对是 `4^n`，n=12 时约 1677 万次。
空间：`O(2^n)`，`ok` 数组存 4096 个布尔值。

## 易错点
- 输入 `s = "bb"`：若只枚举 `a` 后直接取 `b = full ^ a`，会漏掉 `a={0}, b={1}` 这种非补集组合，错成 0；必须双重枚举所有 `b` 并检查 `a & b == 0`。
- 输入 `s = "accbcaxxcxx"`：若把 `ok[mask]` 判断写成「字符集合对称」而非「按原顺序正反相同」，会把 `"acbca"` 之类误判为回文；必须用 `chars == chars[::-1]` 严格比对顺序。

## 如果面试官追问
问：n 放大到 20 怎么办？答：`4^n` 枚举不可行，改为对每个回文掩码按长度降序，用子集卷积或 SOS DP 求「与 mask 不相交的最大回文长度」。
