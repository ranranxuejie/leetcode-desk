## 一句话思路
列字母和行数字各自是连续区间，双重循环按「列在外、行在内」枚举即可，顺序天然非递减。

## 怎么做
1. 从 `s` 里切出四个端点：`c1, r1 = s[0], int(s[1])`，`c2, r2 = s[3], int(s[4])`。
2. 外层用 `for col in range(ord(c1), ord(c2)+1)` 遍历列，内层用 `for row in range(r1, r2+1)` 遍历行。
3. 每个组合拼成 `chr(col) + str(row)` 追加到结果列表。

以 `s = "K1:L2"` 为例，`c1='K'`（ord 75）、`c2='L'`（ord 76）、`r1=1`、`r2=2`。外层第一轮 `col=75`，内层产出 `"K1"`、`"K2"`；第二轮 `col=76` 产出 `"L1"`、`"L2"`，正好是 `["K1","K2","L1","L2"]`。若把两层循环写反，先出 `"K1","L1","K2","L2"`，就错了。

```python
c1, r1 = s[0], int(s[1])
c2, r2 = s[3], int(s[4])
res = []
for col in range(ord(c1), ord(c2) + 1):
    for row in range(r1, r2 + 1):
        res.append(chr(col) + str(row))
return res
```

注意 `range` 上界要 `+1`，`ord(c2)+1` 和 `r2+1` 两处都不能漏，否则 `"L2"` 和 `"K2"` 会丢。

## 复杂度
时间：O((c2-c1+1)×(r2-r1+1))，即输出单元格总数，每个格子拼一次字符串。
空间：O(输出总数) 存结果列表，除此外只有四个标量。

## 易错点
1. 输入 `"A1:F1"` 时若把内层写成 `range(r1, r2)` 漏掉 `+1`，`r1==r2==1` 会得到空列表；正确做法是两处 `range` 上界都写 `+1`，让单行区间也能产出 `"A1"` 到 `"F1"` 共 6 个。
2. 输入 `"K1:L2"` 时若外层行、内层列，输出变成 `["K1","L1","K2","L2"]`，与要求的「先按列排再按行排」不符；正确做法是列作外层循环、行作内层循环。

## 如果面试官追问
若列号扩展到 `"AA"` 这类多字母（如 `"A1:AB3"`），怎么改？答：先把列名按 26 进制转成整数，枚举后再转回列名，循环结构不变。
