## 一句话思路
先按起点排序合并相接区间，再用空闲区间把每个合并段切成左右两截。

## 怎么做
1. 对 `occupiedIntervals` 按 `start` 升序排序。
2. 线性扫描合并：若 `cur[1] + 1 >= nxt[0]` 就并入，否则收尾。
3. 对每个合并段 `[s, e]` 与 `[freeStart, freeEnd]` 求差：无交集整段保留；完全覆盖丢弃；否则保留 `[s, freeStart-1]` 和/或 `[freeEnd+1, e]` 中非空的部分。

以示例 1 为例，排序后合并得到 `[2,8]`、`[10,12]`、`[14,16]`（`[10,10]` 与 `[10,12]` 因 `10+1>=10` 合并）。对 `[10,12]` 与 `[7,11]`：`s=10 <= freeEnd=11` 且 `e=12 > freeEnd`，只保留 `[12,12]`。

```python
merged = []
for s, e in sorted(occupiedIntervals):
    if merged and merged[-1][1] + 1 >= s:
        merged[-1][1] = max(merged[-1][1], e)
    else:
        merged.append([s, e])

res = []
for s, e in merged:
    if e < freeStart or s > freeEnd:
        res.append([s, e])
        continue
    if s < freeStart:
        res.append([s, freeStart - 1])
    if e > freeEnd:
        res.append([freeEnd + 1, e])
```

## 复杂度
时间：排序 O(n log n)，合并与切分各 O(n)，n 为区间数。
空间：合并结果与答案列表 O(n)，排序栈开销 O(log n)。

## 易错点
- 输入 `[[1,1],[2,2]]`：只判 `merged[-1][1] >= s` 会漏合并成两段，答案多一个区间；必须用 `+1 >= s` 处理相接。
- 输入 `[1,5]` 配 `freeStart=3, freeEnd=8`：若先切分再合并，或对 `e > freeEnd` 不加判断就追加 `[9,5]`，会产出非法区间；正确做法是只在 `e > freeEnd` 时追加 `[freeEnd+1, e]`，且切分在合并之后做。

## 如果面试官追问
问：区间端点改成左闭右开怎么办？答：合并条件改为 `merged[-1][1] >= s`，切分时左段到 `freeStart`、右段从 `freeEnd` 起，不再有 `+1`/`-1`。
