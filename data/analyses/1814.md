## 一句话思路
把等式移项成 `nums[i]-rev(nums[i]) == nums[j]-rev(nums[j])`，用哈希表统计每个差值已出现次数，边扫边累加。

## 怎么做
1. 对每个 `nums[i]` 算 `key = nums[i] - rev(nums[i])`，把「好对子」条件转成「key 相等」。
2. 用字典 `cnt` 记录每个 key 之前出现过几次；扫到当前元素时，`ans += cnt.get(key, 0)`，因为前面每个同 key 的下标都能和它配成一对。
3. 再把当前 key 的计数加一，继续下一个。
4. 全程对 `10**9 + 7` 取余。

以 `nums = [42,11,1,97]` 为例：`rev(42)=24`，key 为 `42-24=18`；`rev(11)=11`，key 为 `0`；`rev(1)=1`，key 为 `0`；`rev(97)=79`，key 为 `97-79=18`。扫到 `1` 时 `cnt[0]` 已是 1，`ans` 加 1；扫到 `97` 时 `cnt[18]` 已是 1，`ans` 再加 1，最终 `ans = 2`。

```python
MOD = 10**9 + 7
cnt = {}
ans = 0
for x in nums:
    r, t = 0, x
    while t:
        r = r * 10 + t % 10
        t //= 10
    key = x - r
    ans = (ans + cnt.get(key, 0)) % MOD
    cnt[key] = cnt.get(key, 0) + 1
return ans
```

注意 `rev` 用 `while t` 循环，`t` 为 0 时直接得 `r = 0`，所以 `nums[i] = 0` 的 key 是 `0`，不会死循环。

## 复杂度
时间：O(n · log₁₀ max(nums))，n 来自遍历数组，log 来自每个数的数位反转。
空间：O(n)，哈希表最多存 n 个不同 key。

## 易错点
- 输入含 `0` 或末尾带零的数（如 `nums = [0, 10]`）→ 若 `rev` 写成字符串反转再 `int()`，`rev(10)` 得 `1` 没问题，但若手写循环写成 `while t > 0` 之外的变体容易把 `0` 漏掉 → 正确做法是用 `while t:` 且初值 `r = 0`，`rev(0) = 0`。
- 直接把 `nums[i] + rev(nums[j])` 和 `nums[j] + rev(nums[i])` 两两比较 → O(n²) 在 n=10^5 时超时 → 必须先移项成 `nums[i]-rev(nums[i])` 再哈希，不能保留原式。

## 如果面试官追问
问：如果要求返回所有好对子的下标而不是个数？
答：哈希表 value 从计数改成下标列表，扫到当前 key 时把列表里每个下标与当前下标配对输出，空间仍是 O(n)。
