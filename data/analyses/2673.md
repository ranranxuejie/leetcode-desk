## 一句话思路
自底向上，每个节点把左右子树的路径和补齐到较大者，差值累加即答案。

## 怎么做
1. 从最后一个非叶子节点 `n // 2` 开始倒序处理到根节点 1，因为满二叉树的叶子全在数组后半段，倒序保证处理父节点时孩子的路径和已就绪。
2. 对节点 `i`，取 `left = cost[2*i - 1]`、`right = cost[2*i]`（`cost` 下标是节点号减 1），把较小的那个补到 `max(left, right)`，差值 `abs(left - right)` 计入答案。
3. 把补齐后的路径和写回 `cost[i - 1] += max(left, right)`，让父节点看到的是「以 i 为根的子树已经内部拉平后的路径和」。

以 `n = 7, cost = [1,5,2,2,3,3,1]` 为例：处理节点 3 时 `left = cost[5] = 3`、`right = cost[6] = 1`，补 2，`cost[2]` 变成 `2 + 3 = 5`；处理节点 2 时 `left = 2`、`right = 3`，补 1，`cost[1]` 变成 `5 + 3 = 8`；最后根节点 `left = 8`、`right = 5`，补 3，累计 `2 + 1 + 3 = 6`。

```python
ans = 0
for i in range(n // 2, 0, -1):
    l, r = cost[2 * i - 1], cost[2 * i]
    ans += abs(l - r)
    cost[i - 1] += max(l, r)
return ans
```

关键点：`cost[i-1] += max(l, r)` 而不是 `= max(l, r)`，节点自身的值必须保留在路径和里。

## 复杂度
时间 O(n)：倒序遍历 `n // 2` 个非叶子节点，每个 O(1)。
空间 O(1)：原地修改 `cost`，只多了 `ans`、`l`、`r` 几个变量。

## 易错点
- 写成 `cost[i-1] = max(l, r)` → 丢掉了节点 i 自身的值，示例 1 中节点 3 会变成 3 而非 5，根节点处差值算成 5，答案错成 8。正确做法是 `+=`，因为路径和包含路径上每个节点。
- 从 1 正序处理到 `n // 2` → 父节点读到的还是孩子的原始值而非拉平后的值，示例 1 中根节点读到 `cost[1] = 5`、`cost[2] = 2`，补 3 后答案错成 3。必须倒序，保证子树的路径和先被统一。

## 如果面试官追问
问：如果允许减少节点值，答案会变吗？
答：不会，减少只会让某条路径变短再被迫补回来，等价于只增不减，贪心结论不变。
