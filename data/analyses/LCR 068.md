## 一句话思路
在升序数组上二分，循环结束时 `lo` 恰好是第一个 ≥ target 的位置，即答案。

## 怎么做
1. 取 `lo, hi = 0, len(nums)`，右边界取开区间，这样 target 比所有元素大时答案自然落在 `len(nums)`。
2. 循环条件写 `while lo < hi`，保证区间非空才继续。
3. 取 `mid = (lo + hi) // 2`，比较 `nums[mid]` 与 target：`nums[mid] < target` 则 `lo = mid + 1`，否则 `hi = mid`。
4. 循环退出时返回 `lo`。

以 `nums = [1,3,5,6], target = 2` 为例：初始 `lo=0, hi=4`；`mid=2`，`nums[2]=5 >= 2`，`hi=2`；`mid=1`，`nums[1]=3 >= 2`，`hi=1`；此时 `lo=1, hi=1` 退出，返回 1，正是 2 该插入的位置。

```python
lo, hi = 0, len(nums)
while lo < hi:
    mid = (lo + hi) // 2
    if nums[mid] < target:
        lo = mid + 1
    else:
        hi = mid
return lo
```

关键在 `else` 分支写 `hi = mid` 而不是 `mid - 1`：`nums[mid] == target` 时 mid 本身就是候选答案，不能跳过。

## 复杂度
时间 O(log n)：每次把 `[lo, hi)` 长度减半，n 是 `len(nums)`。
空间 O(1)：只开了 `lo, hi, mid` 三个整数。

## 易错点
- `nums = [1,3,5,6], target = 7` → 若把 `hi` 初始化为 `len(nums) - 1`，循环结束时 `lo` 最多到 3，返回 3 而不是 4 → 右边界必须取 `len(nums)` 的开区间。
- `nums = [1,3,5,6], target = 5` → 若 `else` 分支写成 `hi = mid - 1`，命中 5 时会把 mid 排除掉，最终返回 1 而不是 2 → 相等时保留 `hi = mid`，让 `lo` 收敛到第一个 ≥ target 的位置。

## 如果面试官追问
问：数组有重复元素、要求返回第一个 target 的下标怎么办？
答：这段代码原样可用，`lo` 收敛到的就是第一个 ≥ target 的位置，只需在返回前判断 `lo < len(nums) and nums[lo] == target`。
