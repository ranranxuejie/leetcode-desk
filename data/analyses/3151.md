## 一句话思路
逐对比较 `nums[i]` 与 `nums[i-1]` 的奇偶性，用 `% 2` 是否相等判断，一旦相等立即返回 `False`。

## 怎么做
1. 从下标 `1` 开始遍历到 `len(nums)-1`，每次只看当前元素和前一个元素。
2. 用 `nums[i] % 2 == nums[i-1] % 2` 判断这一对是否奇偶性相同。
3. 相同就 `return False`，循环走完没触发就 `return True`。

以 `nums = [4,3,1,6]` 为例：`i=1` 时 `3 % 2 = 1`、`4 % 2 = 0`，不等，继续；`i=2` 时 `1 % 2 = 1`、`3 % 2 = 1`，相等，立刻返回 `False`——这正是示例 3 的答案。关键中间值就是 `i=2` 这一对的两个余数都是 `1`。

```python
n = len(nums)
for i in range(1, n):
    if nums[i] % 2 == nums[i - 1] % 2:
        return False
return True
```

注意 `range(1, n)` 在 `n == 1` 时是空循环，直接落到 `return True`，正好覆盖示例 1 的单元素情形，不需要额外写 `if n == 1` 的特判。

## 复杂度
时间 O(n)：`n = len(nums)`，每对相邻元素比较一次，最坏扫完整个数组。
空间 O(1)：只用了循环变量 `i`，没有额外开数组。

## 易错点
- 输入 `nums = [1]` → 若写成 `for i in range(1, n-1)` 或先取 `nums[0]` 与 `nums[1]` 比较，会越界或漏判 → 正确做法是 `range(1, n)`，空循环自然返回 `True`。
- 输入 `nums = [2,1,4]` → 若用 `nums[i] + nums[i-1]` 的奇偶性判断（和为奇数才不同），逻辑上碰巧等价但容易在负数上想歪；本题 `nums[i] >= 1` 无负数，仍应直接用 `% 2` 相等判断，语义最直白。

## 如果面试官追问
问：如果要求返回第一个违反位置的下标而不是布尔值？
答：把 `return False` 改成 `return i`，循环结束返回 `-1`，其余不变。
