## 一句话思路
用栈存连续 `'D'` 段的下标，遇 `'I'` 或末尾时把栈内下标按后进先出填上递增数字，保证每段 `'D'` 被反转成降序。

## 怎么做
1. 维护 `stack` 存待填下标，`num` 初始化为长度 `n+1` 的空列表，`cur = 1` 为下一个要用的最小数字。
2. 从左到右扫 `i` 从 0 到 n：先 `stack.append(i)`，若 `i == n` 或 `pattern[i] == 'I'`，就 `while stack: num[stack.pop()] = str(cur); cur += 1`。
3. 以 `pattern = "IIIDIDDD"`（n=8）为例，扫到 `i=3` 时 `pattern[3]=='D'` 不入栈弹出，栈里是 `[0,1,2,3]`？不对——`i=0,1,2` 处 `pattern` 为 `'I'`，每次 append 后立刻弹出，`num[0..2]` 依次得 `'1','2','3'`；`i=3` 时 `pattern[3]=='D'`，只 append 不弹，栈为 `[3]`；`i=4` 时 `pattern[4]=='I'`，append 4 后弹出得 `num[4]='4'`、`num[3]='5'`，此时 `num` 前五位是 `"12354"`。
4. 继续扫到 `i=8`（末尾）时栈里是 `[5,6,7,8]`，依次弹出填 `'6','7','8','9'`，最终 `num = "123549876"`。

```python
n = len(pattern)
num = [''] * (n + 1)
stack, cur = [], 1
for i in range(n + 1):
    stack.append(i)
    if i == n or pattern[i] == 'I':
        while stack:
            num[stack.pop()] = str(cur)
            cur += 1
return ''.join(num)
```

## 复杂度
时间 O(n)：每个下标入栈出栈各一次，`cur` 递增 n+1 次。
空间 O(n)：`stack` 最坏存 n+1 个下标，`num` 存 n+1 个字符。

## 易错点
- `pattern = "DDD"` 时若在 `i=0` 就因「不是 I」跳过入栈，会漏掉下标 0，输出错成 `"321"` 少一位；正确做法是**每个 i 都先 append**，只在 `i==n` 或 `pattern[i]=='I'` 时才弹出。
- 末尾 `i == n` 必须触发弹出，否则 `pattern = "IIIDIDDD"` 的最后一段 `[5,6,7,8]` 留在栈里，`num` 后四位是空串；正确做法是把 `i == n` 和 `pattern[i] == 'I'` 用 `or` 并列判断。

## 如果面试官追问
问：若 pattern 长度扩到 10^5 且数字允许 1 到 10^5+1 呢？
答：同一贪心直接套，`cur` 上限改成 `n+1`，时间空间仍是 O(n)，无需回溯。
