## 一句话思路
用归并排序在合并时统计「左半大于右半」的配对，排序与计数一次完成。

## 怎么做
1. 对 `record` 做自顶向下归并，递归返回该段排好序的列表和逆序对数。
2. 合并两个有序段 `L`、`R` 时，若 `L[i] > R[j]`，则 `L[i:]` 全部大于 `R[j]`，一次加 `len(L) - i`。
3. 用双指针把较小者依次写入结果，保证合并后有序。
4. 累加左右递归的计数与本次合并计数。

以 `record = [9, 7, 5, 4, 6]` 为例，左段 `[9,7,5]` 内部得 3，右段 `[4,6]` 得 0；合并 `L=[5,7,9]`、`R=[4,6]` 时，`j=0` 处 `5 > 4`，一次加 `len(L)-0 = 3`，最终 3+0+3+2=8。

```python
def merge_sort(a):
    if len(a) <= 1:
        return a, 0
    mid = len(a) // 2
    L, cl = merge_sort(a[:mid])
    R, cr = merge_sort(a[mid:])
    i = j = cnt = 0
    merged = []
    while i < len(L) and j < len(R):
        if L[i] <= R[j]:
            merged.append(L[i]); i += 1
        else:
            merged.append(R[j]); j += 1
            cnt += len(L) - i
    merged += L[i:] + R[j:]
    return merged, cl + cr + cnt
```

## 复杂度
时间：归并每层合并 O(n)，共 O(log n) 层，总计 O(n log n)。
空间：递归栈与临时列表共 O(n) 额外空间。

## 易错点
- 输入 `[9,7,5,4,6]` 中 `L[i] == R[j]` 时若写成 `>=` 提前计数，会把相等对算成逆序，答案偏大；正确用 `L[i] <= R[j]` 走左指针，相等不计。
- 空数组 `record = []` 或单元素时，若递归基线写成 `len(a) == 0` 之外还访问 `a[0]`，会索引越界；基线应为 `len(a) <= 1` 直接返回 `(a, 0)`。

## 如果面试官追问
问：数据规模升到 10^6 且内存紧张怎么办？
答：改用树状数组对离散化后的值域计数，边扫边查已出现的大于当前值的个数，空间 O(n) 但常数更小。
