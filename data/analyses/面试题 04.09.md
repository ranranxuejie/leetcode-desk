## 一句话思路
用回溯维护「当前可插入的候选节点集合」，每步任选一个插入，选完把它的左右孩子加入候选。

## 怎么做
1. 关键观察：一个节点能被插入，当且仅当它的父节点已经插入过；所以候选集初始只有 `root`。
2. 每步从候选集里挑一个节点 `x` 追加到路径，把 `x.left`、`x.right`（非空）加入候选，递归后撤销。
3. 候选集为空时路径长度等于节点数，把路径副本存进答案。

以 `root = [2,1,3]` 为例：初始候选 `[2]`，只能先取 2，路径 `[2]`，候选变成 `[1,3]`；接着取 1 得 `[2,1,3]`，或取 3 得 `[2,3,1]`，两种都合法。

```python
def dfs(path, cand):
    if not cand:
        res.append(path[:])
        return
    for i, x in enumerate(cand):
        rest = cand[:i] + cand[i+1:]
        if x.left: rest.append(x.left)
        if x.right: rest.append(x.right)
        path.append(x.val)
        dfs(path, rest)
        path.pop()
```

注意 `rest` 是新建列表，不能原地改 `cand` 再撤销——`cand[:i] + cand[i+1:]` 保证每层互不污染。

## 复杂度
时间：O(方案数 × n)，每个方案复制长度 n 的路径，方案数 ≤ 5000。
空间：O(n) 递归栈 + O(n) 候选集与路径，答案本身占 O(方案数 × n)。

## 易错点
- 输入 `root = []`（节点数可为 0）→ 若直接对 `root.val` 取值会抛异常 → 先判空返回 `[]`，注意是空列表而非 `[[]]`。
- 输入 `[4,1,null,null,3,2]` → 若把候选集写成「所有已插入节点的孩子」而不去重，或误以为左右子树可任意交错 → 实际 3 的父节点 1 必须先于 3，2 又必须晚于 3，唯一解 `[4,1,3,2]`；正确做法是候选只来自「已插入节点的未插入孩子」，天然满足父子先后。

## 如果面试官追问
问：节点数涨到 10^5 但只要求输出任意一种序列怎么办？
答：退化成先序遍历，父子约束自动满足，O(n) 直接输出。
