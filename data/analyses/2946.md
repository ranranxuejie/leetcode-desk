## 一句话思路
每行独立循环移位，k 步后等价于左移 `k % n`（偶数行）或右移 `k % n`（奇数行），逐行比对即可。

## 怎么做
1. 取 `n = len(mat[0])`，`shift = k % n`，因为移位 n 次回到原样。
2. 偶数行 `i % 2 == 0`：要求 `mat[i][j] == mat[i][(j + shift) % n]`，即原矩阵左移 shift 后第 j 位来自原第 j+shift 位。
3. 奇数行：要求 `mat[i][j] == mat[i][(j - shift) % n]`，方向相反。
4. 任一位不等立即返回 `False`，全部通过返回 `True`。

用示例 1：`mat = [[1,2,3],[4,5,6],[7,8,9]]`，`k = 4`，`n = 3`，`shift = 4 % 3 = 1`。行 0 是偶数行，检查 `mat[0][0] == mat[0][1]`，即 `1 == 2`，不成立，直接返回 `False`。

```python
n = len(mat[0])
s = k % n
for i, row in enumerate(mat):
    for j in range(n):
        if i % 2 == 0:
            if row[j] != row[(j + s) % n]:
                return False
        else:
            if row[j] != row[(j - s) % n]:
                return False
return True
```

注意 `(j - s) % n` 在 Python 里天然非负，不用额外加 n。

## 复杂度
时间 O(m·n)：每个元素比对一次，m 行 n 列各贡献一层循环。
空间 O(1)：只用了 `n`、`s`、`i`、`j` 几个标量，没开新矩阵。

## 易错点
- `k` 直接当移位量用 → 示例 1 中 `k = 4`、`n = 3`，若不移模会越界或算错方向；正确做法是先算 `s = k % n`，`s = 1` 时行 0 才判出 `1 != 2`。
- 奇数行方向写反 → 示例 2 中 `mat[1] = [5,5,5,5]` 全相等看不出错，但换成 `mat[1] = [4,5,6]`、`s = 1` 时，右移应满足 `row[0] == row[2]`（即 `4 == 6` 为假），若误写成 `(j + s) % n` 会拿 `row[0]` 比 `row[1]`，把 `4 != 5` 也判成假，方向错时结论可能碰巧一致，必须按 `i % 2` 分支写对符号。

## 如果面试官追问
若 k 大到 10^18 怎么办？答：`k % n` 已经把 k 压到 n 以内，k 再大也只做一次取模，复杂度不变。
