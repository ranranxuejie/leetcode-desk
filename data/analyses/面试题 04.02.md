## 一句话思路
取有序数组中点作根，左右两半递归建树，每层高度差不超过 1，故树高最小。

## 怎么做
1. 用 `lo`、`hi` 两个下标框定当前子数组 `nums[lo:hi+1]`，空区间返回 `None`。
2. 取 `mid = (lo + hi) // 2` 作为根，保证左右元素个数差 ≤1。
3. 递归 `build(lo, mid - 1)` 和 `build(mid + 1, hi)` 分别挂到 `root.left`、`root.right`。
4. 以示例 `[-10,-3,0,5,9]` 为例：`lo=0, hi=4`，`mid=2`，根取 `nums[2]=0`；左区间 `[0,1]` 的 `mid=0` 得 `-10`，其右子 `mid=1` 得 `-3`；右区间 `[3,4]` 的 `mid=3` 得 `5`，其右子得 `9`。

```python
def build(lo, hi):
    if lo > hi:
        return None
    mid = (lo + hi) // 2
    node = TreeNode(nums[mid])
    node.left = build(lo, mid - 1)
    node.right = build(mid + 1, hi)
    return node

return build(0, len(nums) - 1)
```

关键中间值：`mid=2` 时左半长度 2、右半长度 2，两边平衡；若取 `mid=1`（`-3` 作根），左 1 右 3，高度立刻多一层。

## 复杂度
时间 O(n)：每个元素恰好被访问一次建一个节点。
空间 O(log n)：递归栈深度等于树高，输出树本身占 O(n) 不计入额外空间。

## 易错点
- 空数组 `nums=[]` → 若直接写 `mid = len(nums)//2` 再取 `nums[mid]` 会 `IndexError` → 必须先判 `lo > hi` 返回 `None`，让 `build(0, -1)` 走空分支。
- 取中点写成 `mid = (lo + hi + 1) // 2` → 对 `[-10,-3,0,5,9]` 得 `mid=2` 尚可，但对偶数长度如 `[1,2]` 得 `mid=1`，左空右 1，虽仍平衡但和「取左中点」的预期不一致，递归边界 `mid-1` 容易写错成 `mid` 导致死循环 → 统一用向下取整 `(lo + hi) // 2`，左区间写 `mid - 1`。

## 如果面试官追问
问：若数组含重复元素、要求相同值只保留一个节点怎么办？
答：先双指针去重成新数组再套同一分治，或递归时跳过与父节点相等的值。
