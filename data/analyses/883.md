## 一句话思路
三个投影面积分别等于非零格子数、每行最大值之和、每列最大值之和，逐格累加即可。

## 怎么做
1. 遍历 `grid` 每个格子 `grid[i][j]`，`v > 0` 时给俯视图面积 `top` 加 1。
2. 同一行内维护 `row_max`，行结束后累加到 `front`。
3. 同一列内维护 `col_max[j]`，全部遍历完后把 `col_max` 求和得到 `side`。
4. 返回 `top + front + side`。

以 `[[1,2],[3,4]]` 为例：俯视图 4 个格子都非零，`top = 4`；第 0 行 `row_max = 2`、第 1 行 `row_max = 4`，`front = 6`；列最大值 `col_max = [3, 4]`，`side = 7`；合计 `4 + 6 + 7 = 17`。

```python
top = front = 0
col_max = [0] * len(grid)
for i, row in enumerate(grid):
    row_max = 0
    for j, v in enumerate(row):
        if v > 0:
            top += 1
        row_max = max(row_max, v)
        col_max[j] = max(col_max[j], v)
    front += row_max
side = sum(col_max)
return top + front + side
```

关键点：`col_max[j]` 必须在遍历过程中就地更新，不能等整行结束再处理，否则列信息会丢。

## 复杂度
时间：O(n²)，每个格子访问一次，`max` 是 O(1)。
空间：O(n)，只开了长度为 n 的 `col_max` 数组。

## 易错点
- 输入 `[[0]]` → 若把俯视图面积写成 `n * n` 会得 1，正确应为 0，因为 `v = 0` 表示该格没有立方体，俯视图不贡献面积。
- 输入 `[[1,0],[0,2]]` → 若把 `front` 写成所有行最大值再乘 n，或把 `side` 写成 `sum(row_max)`，会得 8 之外的错误值；正确是 `front = 1 + 2 = 3`、`side = 1 + 2 = 3`、`top = 2`，合计 8，行列最大值必须分开统计。

## 如果面试官追问
问：如果 grid 不是方阵（m × n）怎么办？
答：思路不变，`col_max` 开长度为 n，`front` 按 m 行累加，俯视图仍数非零格子，复杂度 O(mn)。
