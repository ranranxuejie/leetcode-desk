## 一句话思路
把元音字母抽出来排序后按原顺序填回元音位置，辅音不动，一次遍历即可。

## 怎么做
1. 定义元音集合 `vowels = set("aeiouAEIOU")`，遍历 `s` 收集所有元音字符到列表 `vs`。
2. 对 `vs` 排序，得到非递减的 ASCII 序。
3. 再遍历一次 `s`，遇到元音位置就依次取 `vs` 中的下一个字符替换，辅音原样保留。

以 `s = "lEetcOde"` 为例：第一遍收集得到 `vs = ['E','e','O','e']`，排序后 `vs = ['E','O','e','e']`。第二遍扫描时下标 1 是 `'E'`（元音），替换为 `vs[0]='E'`；下标 3 是 `'e'`，替换为 `vs[1]='O'`；下标 4 是 `'c'`（辅音）跳过；下标 5 是 `'O'`，替换为 `vs[2]='e'`；下标 7 是 `'e'`，替换为 `vs[3]='e'`，最终 `"lEOtcede"`。

```python
vowels = set("aeiouAEIOU")
vs = [c for c in s if c in vowels]
vs.sort()
res = list(s)
k = 0
for i, c in enumerate(res):
    if c in vowels:
        res[i] = vs[k]
        k += 1
return "".join(res)
```

关键点：`vs.sort()` 用的是字符的 ASCII 值，所以大写元音（如 `'E'=69`）会排在小写元音（如 `'e'=101`）前面，这正是示例 1 中 `'E'` 和 `'O'` 出现在 `'e'` 之前的原因。

## 复杂度
时间 O(n + m log m)，n 为字符串长度（两遍扫描），m 为元音个数（排序）。
空间 O(n)，`res` 列表和 `vs` 列表各占一份，`vs` 最多 n 个。

## 易错点
1. 输入 `s = "lEetcOde"` 时若只把小写元音 `"aeiou"` 当元音，`'E'` 和 `'O'` 会被当辅音留在原位，输出变成 `"lEetcOde"` 的错排版本而非 `"lEOtcede"`。正确做法是元音集合必须包含大写 `"AEIOU"`。
2. 输入 `s = "lYmpH"` 时若在收集 `vs` 后不判空就直接 `vs.sort()` 再回填，逻辑上没问题但若代码写成 `vs[0]` 之类会越界；更隐蔽的坑是排序后回填时用 `s.index(c)` 找位置，遇到重复元音（如示例中两个 `'e'`）会全部填到第一个 `'e'` 的位置。正确做法是用独立指针 `k` 顺序消费 `vs`。

## 如果面试官追问
若要求辅音也按某种规则重排而非原地保留，答：那就退化成对全串按自定义 key 排序，元音和辅音各用各的排序键，一次 `sorted` 即可。
