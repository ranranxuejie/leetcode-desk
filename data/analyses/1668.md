## 一句话思路
枚举重复次数 k，检查 `word * k` 是否为 `sequence` 的子串，取最大可行 k。

## 怎么做
1. 上界取 `len(sequence) // len(word)`，因为 `word * k` 长度不能超过 `sequence`。
2. 从 1 到上界逐个试，用 `in` 判断子串，记录最后一个成功的 k。
3. 以 `sequence = "ababc", word = "ab"` 为例：上界 `5 // 2 = 2`；k=1 时 `"ab" in "ababc"` 为 True，k=2 时 `"abab" in "ababc"` 也为 True，k=3 已超上界，答案 2。
4. 若 k=1 就失败，直接返回 0。

```python
n, m = len(sequence), len(word)
ans = 0
for k in range(1, n // m + 1):
    if word * k in sequence:
        ans = k
    else:
        break
return ans
```

注意 `break` 的合法性：若 `word * (k+1)` 是子串，则 `word * k` 必是其前缀、也必是子串，所以一旦失败后面全失败，可以提前退出。示例 2 中 `word = "ba"`：k=1 时 `"ba" in "ababc"` 为 True，k=2 时 `"baba" in "ababc"` 为 False，break，返回 1。

## 复杂度
时间 O(n²/m)：最多 n/m 次子串检查，每次最坏 O(n)。
空间 O(n)：`word * k` 最长 n 个字符的临时串。

## 易错点
- `sequence = "ababc", word = "ab"` 若上界写成 `len(sequence)` 而非 `n // m`，会白跑 k=3、4、5 三次必然失败的检查，虽不改变答案但多花时间；正确做法是上界 `n // m`。
- `sequence = "aaaa", word = "aa"` 若用 `sequence.count(word)` 或 `find` 只查一次就返回，会错成 1 或 2 的偶然值；正确做法是必须按 k 递增构造 `word * k` 再判断，才能得到 2。

## 如果面试官追问
问：sequence 长度到 10⁵ 怎么办？答：改用 KMP 在 `sequence` 上匹配 `word`，统计连续匹配段长度除以 m 取最大，O(n+m)。
