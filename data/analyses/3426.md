## 一句话思路
按行、列拆开算：每对格子贡献的期望距离乘以方案总数，用组合数把「选中这对格子」的方案数算出来。

## 怎么做
1. 总方案数 `C(m*n, k)`，一对格子被同时选中的方案数是 `C(m*n-2, k-2)`，所以每对格子的贡献权重 `w = C(m*n-2, k-2)`。
2. 行方向：所有格子对的行距离之和 `rowSum = n*n * Σ_{d=1}^{m-1} d*(m-d)`，因为每一对行 `(i,j)` 对应 `n*n` 个格子对。
3. 列方向同理 `colSum = m*m * Σ_{d=1}^{n-1} d*(n-d)`。
4. 答案 `= w * (rowSum + colSum) mod 1e9+7`。

以 `m=2, n=2, k=2` 验证：`w = C(2,0) = 1`；`rowSum = 2*2 * (1*1) = 4`；`colSum = 4`；答案 `1*(4+4)=8`，与示例一致。

```python
MOD = 10**9 + 7
N = m * n
# 预处理阶乘求组合数
fact = [1] * (N + 1)
for i in range(1, N + 1):
    fact[i] = fact[i-1] * i % MOD
inv = [1] * (N + 1)
inv[N] = pow(fact[N], MOD-2, MOD)
for i in range(N, 0, -1):
    inv[i-1] = inv[i] * i % MOD
def C(a, b):
    if b < 0 or b > a: return 0
    return fact[a] * inv[b] % MOD * inv[a-b] % MOD
w = C(N-2, k-2)
rowSum = n*n % MOD * sum(d*(m-d) for d in range(1, m)) % MOD
colSum = m*m % MOD * sum(d*(n-d) for d in range(1, n)) % MOD
return w * (rowSum + colSum) % MOD
```

## 复杂度
时间：O(m*n) 预处理阶乘，求和 O(m+n)。
空间：O(m*n) 存 fact 和 inv 两个数组。

## 易错点
- `k=2` 时 `C(N-2, 0)=1`，若把 `w` 写成 `C(N, k)` 会放大 `N*(N-1)/2` 倍，示例 1 会得 48 而非 8。
- `m=1` 时行方向 `range(1,1)` 为空、`rowSum=0`，若漏掉这个边界直接算 `m*m` 会多算；示例 2 中 `colSum = 1*1*(1*3+2*2+3*1)=10`，`w=C(2,1)=2`，答案 20。

## 如果面试官追问
问：若要求输出每个方案的距离总和而非取模？答：中间量 `w` 会超 64 位，需用 Python 大整数或分段取模再合并。
