## 一句话思路
先找最长递增前缀 `i` 和最长递增后缀 `j`，再对每个前缀端点用二分找后缀起点，累加可删区间数。

## 怎么做
1. 从右往左扫，找到最长严格递增后缀的起点 `j`（即 `nums[j] < nums[j+1] < ...` 的最左位置）。
2. 若 `j == 0`，整个数组已递增，答案就是 `n*(n+1)//2`，直接返回。
3. 枚举前缀保留到 `i`（`i` 从 `-1` 到 `j-1`，`-1` 表示前缀全删），对每个 `i` 在 `[j, n]` 中二分找最小的 `k`，使 `nums[k] > nums[i]`（`i == -1` 时 `k = j`）。
4. 对每个 `i`，可删子数组右端点从 `k-1` 到 `n-1` 都合法，累加 `n - k + 1`。

以 `nums = [6,5,7,8]` 为例：后缀起点 `j = 2`（`7,8` 递增）。`i = -1` 时 `k = 2`，贡献 `4-2+1 = 3`；`i = 0`（`nums[0]=6`）二分得 `k = 2`（`7 > 6`），贡献 3；`i = 1`（`nums[1]=5`）得 `k = 2`，贡献 3。但 `i=0` 时前缀 `[6]` 本身合法，`i=1` 时前缀 `[6,5]` 不递增，需跳过。修正后总数为 7。

```python
n = len(nums)
j = n - 1
while j > 0 and nums[j-1] < nums[j]:
    j -= 1
if j == 0:
    return n * (n + 1) // 2
ans = n - j + 1  # i = -1
for i in range(j):
    if i > 0 and nums[i-1] >= nums[i]:
        break
    k = bisect_right(nums, nums[i], j)  # 在 [j,n) 找第一个 > nums[i]
    ans += n - k + 1
return ans
```

## 复杂度
时间：O(n log n)，外层枚举前缀 O(n)，每次二分 O(log n)。
空间：O(1)，只用了 `i`、`j`、`k` 几个变量。

## 易错点
- `nums = [8,7,6,6]`：后缀起点 `j = 3`（只有最后一个 `6`），但 `nums[2]=6` 与 `nums[3]=6` 相等不递增。若误把 `j` 算成 2，会多算 `[8,7]` 这类非法子数组。正确做法是循环条件用严格小于 `<`。
- `nums = [1,2,3,4]`：`j = 0` 时若仍走枚举循环，`bisect_right` 在空区间 `[0,4)` 上会返回 4，导致 `ans` 多加。正确做法是先判 `j == 0` 直接返回 `n*(n+1)//2 = 10`。

## 如果面试官追问
若要求输出所有移除递增子数组的具体下标方案，怎么改？
答：把累加 `n-k+1` 换成对每个 `i` 枚举右端点 `r` 从 `k-1` 到 `n-1`，收集 `(i+1, r)` 即可，复杂度升到 O(n²)。
