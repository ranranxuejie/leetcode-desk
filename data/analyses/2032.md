## 一句话思路
对每个数组先去重，再用一个计数数组统计每个值出现在几个数组里，计数 ≥2 的即为答案。

## 怎么做
1. 用 `set(nums1)`、`set(nums2)`、`set(nums3)` 去重，避免同一数组内重复值被重复计数。
2. 开一个长度 101 的 `cnt`（值域 1~100），对三个集合里出现的每个值 `cnt[v] += 1`。
3. 遍历 `v in range(1, 101)`，把 `cnt[v] >= 2` 的 `v` 收进结果。

以示例 1 为例：三个集合分别是 `{1,3,2}`、`{2,3}`、`{3}`，累加后 `cnt[3] = 3`、`cnt[2] = 2`、`cnt[1] = 1`，只有 3 和 2 满足 `>= 2`，输出 `[3,2]`。关键中间值就是 `cnt[2]`：`nums2` 里的 2 让它从 1 变成 2，这一步决定了它入选。

```python
cnt = [0] * 101
for s in (set(nums1), set(nums2), set(nums3)):
    for v in s:
        cnt[v] += 1
return [v for v in range(1, 101) if cnt[v] >= 2]
```

若不想依赖值域，可换成 `defaultdict(int)` 或 `Counter`，逻辑不变。

## 复杂度
时间：O(n1+n2+n3+100)，三个数组各扫一遍建集合，最后固定扫 101 个值。
空间：O(n1+n2+n3) 存三个集合，外加固定 101 的 `cnt`。

## 易错点
- 输入 `nums1 = [1,1,3,2]` 这种带重复的数组 → 若直接对原数组累加 `cnt`，`cnt[1]` 会变成 2，把只在 `nums1` 出现过的 1 误判为答案 → 必须先 `set()` 去重再计数。
- 输入 `nums3 = [5]`、`nums1`/`nums2` 里都没有 5 → 若把阈值写成 `cnt[v] > 2` 或误用「三个数组都出现」，会漏掉只在两个数组出现的值（如示例 1 的 2）→ 阈值严格是 `>= 2`，且要覆盖「恰好两个」的情况。

## 如果面试官追问
问：值域不再是 1~100 而是任意大整数怎么办？
答：把 `cnt` 换成 `defaultdict(int)`，最后遍历它的键取计数 ≥2 的，时间空间都只与去重后元素总数有关。
