## 一句话思路
对 threshold 二分，判定时把 ≤threshold 的边记 0 代价、其余记 1 代价，跑 0-1 BFS 看最短路是否 ≤k。

## 怎么做
1. 候选 threshold 只可能是 0 或某条边的权重，故对 `sorted({0} | {w for _,_,w in edges})` 二分。
2. 判定函数：`dist` 数组初值 `2**31-1`，`dist[source]=0`，用 deque 做 0-1 BFS，边权 `w<=threshold` 时 `cost=0` 走 `appendleft`，否则 `cost=1` 走 `append`。
3. 若 `dist[target] <= k` 则收缩右界，否则左界右移；循环结束返回左界，若连最大权重都不可达则 -1。

以示例 1 为例，取 `threshold=4`：边 `[0,1,5]` 是重边（cost 1），其余轻边 cost 0。BFS 中 `dist[1]=1`（经 0→1），`dist[4]=1`（1→4 轻边），`dist[3]=1`（4→3 轻边），`dist[3]=1 <= k=1` 成立；而 `threshold=3` 时 `[3,4,4]` 也变重，到 3 至少要 2 条重边，失败。

```python
from collections import deque
def ok(t):
    dist = [2**31 - 1] * n
    dist[source] = 0
    dq = deque([source])
    while dq:
        u = dq.popleft()
        for v, w in g[u]:
            c = 0 if w <= t else 1
            if dist[u] + c < dist[v]:
                dist[v] = dist[u] + c
                dq.appendleft(v) if c == 0 else dq.append(v)
    return dist[target] <= k
```

## 复杂度
时间：二分 O(log E) 次，每次 0-1 BFS 是 O(n+E)，共 O((n+E) log E)。
空间：`dist` 数组 O(n)，deque 与邻接表 O(n+E)。

## 易错点
- `source == target`（示例 3）→ 若直接对边权二分会返回最小边权 2，错成 2 → 正确做法是判定函数里 `dist[source]=0` 天然满足 `0<=k`，二分下界取 0 即可返回 0。
- 图不连通（示例 2）→ 若二分后直接返回左界会返回某个边权而非 -1 → 正确做法是先用最大权重跑一次判定，`dist[target]` 仍为 `2**31-1` 时返回 -1。

## 如果面试官追问
若要求输出具体路径而非阈值？答：在 0-1 BFS 里记 `parent` 数组，判定成功后从 target 回溯，重边数即路径代价。
