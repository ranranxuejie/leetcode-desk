## 一句话思路
用 `pivot` 把 `month` 作索引、`city` 作列、`temperature` 作值，再 `reset_index()` 把 month 还原成普通列。

## 怎么做
1. 直接调 `weather.pivot(index="month", columns="city", values="temperature")`，一步完成行列重排。
2. 中间结果是一个以 `month` 为行标签、`ElPaso`/`Jacksonville` 为列名的 DataFrame，单元格里是温度。
3. 用 `reset_index()` 把行索引 `month` 变回列，得到题目要求的平表。
4. 若列顺序有要求，最后加 `sort_index(axis=1)` 或按需重排列名。

以官方示例为例：`pivot` 后行标签是 `April/February/January/March/May`，列是 `ElPaso`、`Jacksonville`；`April` 行取到 `2` 和 `5`，`January` 行取到 `20` 和 `13`。`reset_index()` 后 `month` 成为第一列，正好对上输出表头。

```python
def pivot_table(weather):
    out = weather.pivot(
        index="month",
        columns="city",
        values="temperature",
    ).reset_index()
    out.columns.name = None
    return out
```

关键点：`pivot` 要求 `(month, city)` 组合唯一，本题每个城市每月只有一条记录，所以成立；若同一组合出现两次，`pivot` 会抛 `ValueError`，此时才需要 `pivot_table` 加 `aggfunc`。

## 复杂度
时间：O(n)，n 为 `weather` 行数，需扫一遍建索引。
空间：O(n)，额外存一份透视后的 DataFrame。

## 易错点
- 同一 `(month, city)` 出现重复行 → `pivot` 直接抛 `ValueError: Index contains duplicate entries`，不是静默取最后一个 → 改用 `pivot_table(..., aggfunc="first")` 或先去重。
- 忘记 `reset_index()` → 返回的 `month` 还挂在索引上，输出表缺 `month` 列，与期望表头对不上 → 必须显式 `reset_index()`，并顺手把 `columns.name` 置 `None` 去掉 `city` 这个多余列名。

## 如果面试官追问
问：若某城市缺某月数据怎么办？
答：`pivot` 会填 `NaN`，需要补 `0` 就加 `.fillna(0)`，或改用 `pivot_table` 的 `fill_value` 参数。
