## 一句话思路
以 0 为根做一次 DFS 求出每棵子树的异或值，任删两条边得到的三个组件异或值都能由这些子树异或值两两组合算出。

## 怎么做
1. 把无向边建成邻接表，从 0 开始 DFS，`sub[u]` 记录以 u 为根的子树的异或和，同时记下每个节点的父边（即删这条边会切出 `sub[u]` 这块）。
2. 枚举两条被删的边，它们对应两个非根节点 a、b，先判断祖先关系：若 a 是 b 的祖先，则三块是 `sub[b]`、`sub[a]^sub[b]`、`total^sub[a]`；否则三块是 `sub[a]`、`sub[b]`、`total^sub[a]^sub[b]`。
3. 对每组三值取 `max-min`，更新答案。

以示例 1 为例：`nums=[1,5,5,4,11]`，根 0，DFS 得 `sub[4]=11, sub[3]=4^11=15, sub[2]=5, sub[1]=5^5^15=15, sub[0]=1^15=16`（total=16）。删边 (1,3) 与 (3,4)：3 是 4 的祖先，三块为 `sub[4]=11`、`sub[3]^sub[4]=15^11=4`、`total^sub[3]=16^15=1`，分数 `11-1=10`。真正最优是删 (0,1)、(1,2)：1 是 2 的祖先，三块 `sub[2]=5`、`sub[1]^sub[2]=15^5=10`、`total^sub[1]=16^15=1`，分数 `10-1=9`。

```python
def dfs(u, p):
    sub[u] = nums[u]
    for v in g[u]:
        if v != p:
            par[v] = u
            dfs(v, u)
            sub[u] ^= sub[v]

# 判断 a 是否为 b 的祖先：沿 par 从 b 往上爬
def is_anc(a, b):
    while b != -1:
        if b == a: return True
        b = par[b]
    return False
```

枚举时对每对 `(a,b)`（a、b 均非根）按上面两种情形取三值即可。

## 复杂度
时间：O(n²)，枚举 O(n²) 对边，每对判祖先最坏 O(n)，n≤1000 可过。
空间：O(n)，邻接表、`sub`、`par` 各 O(n)。

## 易错点
- 忘记判祖先关系：直接把三块写成 `sub[a]`、`sub[b]`、`total^sub[a]^sub[b]`，当 a 是 b 的祖先时 `sub[a]` 已包含 `sub[b]`，会算出错误的三值（如示例 1 删 (1,3)、(3,4) 会得 11、15、1，分数 14 而非 10）。必须先判祖先再分支。
- 把根节点 0 也当可删边对象：`par[0]=-1`，若枚举到 0 会访问 `sub[-1]` 或死循环。枚举范围限定为 `1..n-1` 的非根节点。

## 如果面试官追问
问：n 放大到 1e5 怎么办？答：枚举 O(n²) 不可行，需按 `sub` 值排序后二分/双指针逼近，或利用异或值域做 trie 查询最接近的三元组。
