## 一句话思路
按列填充结果矩阵，用 `col % 2` 决定这一列从上往下还是从下往上，`nums` 顺序消费即可。

## 怎么做
1. 先判 `rowsCount * colsCount != len(nums)`，直接返回 `[]`。
2. 建 `rowsCount × colsCount` 的空矩阵 `res`，用指针 `k` 从 0 扫 `nums`。
3. 对每列 `c`：若 `c % 2 == 0` 则行号 `0→rowsCount-1`，否则 `rowsCount-1→0`，逐格写 `nums[k]` 并 `k += 1`。

以示例 1 为例，`rowsCount=5, colsCount=4`。第 0 列（偶）从上往下填 `19,10,3,7,9`，`k` 到 5；第 1 列（奇）从下往上填 `8,5,2,1,17`，`k` 到 10；第 2 列（偶）填 `16,14,12,18,6`，`k` 到 15；第 3 列（奇）填 `13,11,20,4,15`，`k` 到 20。最终 `res[0] = [19,17,16,15]`，与输出一致。

```python
if rowsCount * colsCount != len(nums):
    return []
res = [[0] * colsCount for _ in range(rowsCount)]
k = 0
for c in range(colsCount):
    rng = range(rowsCount) if c % 2 == 0 else range(rowsCount - 1, -1, -1)
    for r in rng:
        res[r][c] = nums[k]
        k += 1
return res
```

关键点：`res[r][c]` 是「行 r、列 c」，不是 `res[c][r]`；`rng` 的方向只由列号奇偶决定，与 `k` 无关。

## 复杂度
时间 O(rowsCount × colsCount)，即 O(len(nums))，每个元素写一次。
空间 O(rowsCount × colsCount)，即输出矩阵本身，无额外辅助结构。

## 易错点
1. 输入 `nums=[1,3], rowsCount=2, colsCount=2` → 若忘记长度校验，`k` 会在第 3 格越界或读到 `None` → 必须先判 `rowsCount * colsCount != len(nums)` 返回 `[]`，注意是乘积比较而非任一维度比较。
2. 输入 `rowsCount=1, colsCount=4`（示例 2）→ 若把方向写成按行交替，会得到错位结果 → 方向只由列号 `c` 的奇偶决定，`rowsCount=1` 时两种方向等价，结果仍是 `[[1,2,3,4]]`，不要额外特判。

## 如果面试官追问
若要求原地转换、不许开新矩阵？答：一维数组按列优先的索引映射 `idx = c * rowsCount + (r if c%2==0 else rowsCount-1-r)` 直接读写，空间降到 O(1) 辅助。
