## 一句话思路
一次遍历，用 `abs(x)` 与当前最优比较，距离相等时取较大值，因为「更接近 0」等价于绝对值更小。

## 怎么做
1. 把答案初值设为 `nums[0]`，避免用 `2**31 - 1` 这类哨兵值再额外判断。
2. 遍历 `nums` 中每个 `x`，计算 `d = abs(x)` 和当前最优的 `abs(ans)`。
3. 若 `d < abs(ans)`，或 `d == abs(ans) and x > ans`，就更新 `ans = x`。
4. 遍历结束返回 `ans`。

用示例 2 `nums = [2,-1,1]` 走一遍：初值 `ans = 2`；遇到 `-1`，`d = 1 < abs(2) = 2`，更新 `ans = -1`；遇到 `1`，`d = 1 == abs(-1) = 1` 且 `1 > -1`，更新 `ans = 1`。最终返回 `1`，正是「距离相等取最大值」生效的那一步。

```python
ans = nums[0]
for x in nums:
    d, best = abs(x), abs(ans)
    if d < best or (d == best and x > ans):
        ans = x
return ans
```

关键在第二个条件：只写 `d < best` 会在 `[2,-1,1]` 上返回 `-1`，因为 `-1` 先出现且距离不比 `2` 大，`1` 因距离相等被跳过。

## 复杂度
时间 O(n)：一次遍历，每个元素做两次 `abs` 和一次比较。
空间 O(1)：只开了 `ans`、`x`、`d`、`best` 四个标量。

## 易错点
- 输入 `[2,-1,1]` → 只写 `if abs(x) < abs(ans)` 会返回 `-1`，因为 `1` 与 `-1` 距离相等时被跳过 → 必须补 `d == best and x > ans` 这一支。
- 输入 `[-1]` 或全负数如 `[-5,-3,-1]` → 若把 `ans` 初始化成 `0`，`abs(0) = 0` 永远最小，直接返回 `0`（不在数组里）→ 初值必须取 `nums[0]`，不能取 `0`。

## 如果面试官追问
问：如果要求返回所有最接近 0 的数字（去重后升序）？
答：先求最小距离 `best`，再扫一遍收集 `abs(x) == best` 的值放进 `set`，最后 `sorted` 返回。
