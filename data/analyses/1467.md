## 一句话思路
按颜色逐个决定「放几个进盒子一」，用 DP 记录已放球数和两边颜色数之差，最后取差为 0 的概率。

## 怎么做
1. 总球数 `total = sum(balls)`，`n = total // 2`；分母是所有长度为 total 的排列数 `total!`，等价于按颜色分配后乘各颜色内部排列数。
2. 状态 `dp[i][j][d]`：处理完前 i 种颜色、盒子一已放 j 个球、两边颜色数差为 d 的方案数（d 可负，用偏移量 `k` 平移）。
3. 对颜色 i 枚举放 `x` 个进盒子一（0..balls[i]），盒子二得 `balls[i]-x`；只有 x>0 时盒子一多一种颜色，只有 x<balls[i] 时盒子二多一种颜色，据此更新 d。
4. 转移权重乘 `C(balls[i], x)`，因为同色球选哪几个进盒子一是不同的；答案 = `dp[k][n][0] / C(total, n)`。

以 `balls=[2,1,1]` 为例，total=4、n=2。处理颜色 0（2 个球）时 x 可取 0/1/2，权重 1/2/1；处理完颜色 1 后，j=2 且 d=0 的路径已累计到 4 条，最终 `dp[3][2][0]=8`，分母 `C(4,2)=6`… 注意这里分母要用排列数 12，故权重应写成 `C(balls[i],x)` 后整体除以 `C(total,n)` 会差一个因子，正确做法是分母取 `total!/(n!n!)` 的等价形式——直接用 `math.comb(total,n)` 作分母、转移权重用 `comb(balls[i],x)` 即可，示例 2 得 8/12=0.66667。

```python
from math import comb
k = len(balls); total = sum(balls); n = total // 2
off = k
dp = [[[0]*(2*k+1) for _ in range(n+1)] for _ in range(k+1)]
dp[0][0][off] = 1
for i in range(k):
    b = balls[i]
    for j in range(n+1):
        for d in range(2*k+1):
            v = dp[i][j][d]
            if not v: continue
            for x in range(b+1):
                if j+x > n: break
                nd = d + (1 if x > 0 else 0) - (1 if x < b else 0)
                dp[i+1][j+x][nd] += v * comb(b, x)
return dp[k][n][off] / comb(total, n)
```

## 复杂度
时间：O(k · n · k · max(balls))，k≤8、n≤24，实际几千次转移。
空间：O(k · n · k)，即三维 dp 表，约 8×25×17。

## 易错点
- `balls=[1,1]`：若把两个盒子视为相同，会算成 1 种分配而非 2 种，概率仍对但推广到 `[2,1,1]` 会漏掉一半排列；盒子有标号，分母必须用 `comb(total,n)` 而非除以 2。
- `balls=[2,1,1]`：颜色 0 的 2 个球若当成「不可区分」只记 x=0/1/2 各 1 种，会得 4/6 而非 8/12；必须乘 `comb(balls[i],x)`，因为具体哪几个球进盒子一是不同的。

## 如果面试官追问
问：若 balls 长度增到 50、每色球数仍 ≤6 怎么办？
答：k 变大后 d 的范围和状态数涨到 O(k²n)，需把 d 改成「盒子一颜色数」单维并最后比较，或改用生成函数/卷积加速。
