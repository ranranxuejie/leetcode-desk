## 一句话思路
每轮用 DFS 把病毒分成连通块，统计每块能新感染的格子集合与所需墙数，隔离威胁最大（新感染格最多）的那块，其余块扩散，重复到无新感染。

## 怎么做
1. 对每个未访问的 `1` 做 DFS，收集该连通块的病毒格、它邻接的未感染格集合 `frontier`、以及边界墙数 `walls`（每个病毒格的四邻中为 `0` 或越界的边各算一堵）。
2. 选 `len(frontier)` 最大的块，把 `walls` 累加进答案，并把该块所有格子标记为已隔离（改成 `2`，之后不再扩散也不再参与 DFS）。
3. 其余块按 `frontier` 扩散：把这些 `0` 置为 `1`。
4. 若某轮所有块 `frontier` 都为空则停止，返回累计墙数。

以示例 1 第一天为例：左侧块 `frontier` 有 5 个格子（第 0 列 3 个 + 第 1 行第 2 列等），右侧块 `frontier` 也是 5 个，但左侧块 `walls` 为 5，隔离它后答案累加 5；右侧块扩散后第 3 列变 `1`，第二天右侧块 `frontier` 仍非空，再累加 5，共 10。

```python
def dfs(i, j):
    if (i, j) in seen: return
    seen.add((i, j)); cells.append((i, j))
    for di, dj in dirs:
        x, y = i + di, j + dj
        if 0 <= x < m and 0 <= y < n:
            if g[x][y] == 1: dfs(x, y)
            elif g[x][y] == 0:
                frontier.add((x, y)); walls[0] += 1
        else:
            walls[0] += 1
```

## 复杂度
时间：每轮 DFS 遍历全图 O(mn)，最多 O(mn) 轮，共 O((mn)^2)。
空间：`seen`、`frontier`、`cells` 各 O(mn)，递归栈 O(mn)。

## 易错点
- 输入 `[[1,1,1],[1,0,1],[1,1,1]]`：若把中心 `0` 的四面墙都算给同一块，会得 8；正确是中心 `0` 被同一块包围，四面墙都算，但答案 4 是因为该块 `frontier` 只有中心 1 格、`walls` 为 4，隔离它即得 4——关键是墙按「病毒格到 `0` 的边」计数，不是按 `0` 的邻接数。
- 隔离后把格子改成 `2` 而非 `1`：若仍留 `1`，下一轮 DFS 会把它当活跃病毒继续扩散，示例 1 会多算墙；正确是 `2` 表示已隔离，DFS 和扩散都跳过。

## 如果面试官追问
问：若要求输出每轮隔离的是哪一块（坐标）？
答：在选最大 `frontier` 时记录该块任一代表格坐标，按轮次追加到结果列表即可。
