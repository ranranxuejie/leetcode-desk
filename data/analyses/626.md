## 一句话思路
用 `CASE` 把奇数 id 映射到 `id+1`、偶数 id 映射到 `id-1`，再按新 id 排序；奇数行数时最大 id 落回自身。

## 怎么做
1. 先判断每个 id 的奇偶：`id % 2 = 1` 为奇，`= 0` 为偶。
2. 奇数 id 若还有下一行（`id < 总行数`）就换成 `id+1`，否则保持 `id`。
3. 偶数 id 一律换成 `id-1`。
4. 用换好的新 id 排序输出，`student` 不动。

拿官方示例走一遍：总行数 5，id=5 是奇数且 `5 < 5` 为假，所以 5 保持不动；id=1→2、2→1、3→4、4→3。排序后 id=1 拿到原 id=2 的 Doris，id=2 拿到 Abbot，id=3 拿到 Green，id=4 拿到 Emerson，id=5 仍是 Jeames。

```python
n = len(seats)  # 行数，奇数时最后一行不换
def new_id(i):
    if i % 2 == 1:
        return i + 1 if i < n else i
    return i - 1

rows = sorted(((new_id(i), s) for i, s in seats), key=lambda x: x[0])
```

关键中间值：`n=5`，`new_id(5)` 走 `5 < 5` 为假的分支返回 5；`new_id(4)` 返回 3。

## 复杂度
时间：排序贡献 O(n log n)，n 为 Seat 行数。
空间：结果列表 O(n)，映射本身 O(1)。

## 易错点
- 输入 5 行（奇数）时，若把奇数 id 无条件写成 `id+1`，id=5 会变成 6，输出多出一行且 id 不连续；正确做法是加 `id < n` 判断，让最后一行原地不动。
- 输入 2 行时，若先按 student 交换再排序，容易把 id 也一起换掉导致顺序错乱；正确做法是只改 id、`student` 原样跟随，最后按新 id 升序排。

## 如果面试官追问
问：如果 id 不连续（有删除空洞）怎么办？
答：先按 id 排序取行号 `row_number()`，用行号判奇偶，再按行号回填 id。
