## 一句话思路
正着模拟会爆内存，改为倒推：从最终长度出发，按操作逆序把下标 k 映射回原始字符。

## 怎么做
1. 正向扫一遍 s，只维护长度 `L`：字母 `L += 1`，`*` 则 `L = max(L-1, 0)`，`#` 则 `L *= 2`，`%` 不变；`L` 超过 `k` 后可以截断为 `k+1`（因为只需判断 k 是否越界）。
2. 若最终 `L <= k`，直接返回 `'.'`。
3. 倒序扫 s，用 `k` 表示「当前 result 中目标字符的下标」，按操作反向映射，遇到字母就返回它。
4. 反向规则：`#` 时若 `k >= L//2` 则 `k -= L//2`，再 `L //= 2`；`%` 时 `k = L-1-k`；`*` 时 `L += 1`（被删的是末尾，k 不变）；字母时若 `k == L-1` 返回该字母，否则 `L -= 1`。

以 `s = "cd%#*#"`, `k = 3` 为例：正向长度依次 1,2,2,4,3,6。倒推：`#` 时 `L=6, k=3 >= 3` 得 `k=0, L=3`；`*` 得 `L=4`；`#` 时 `k=0 < 2`，`L=2`；`%` 得 `k=1`；`d` 时 `k != L-1=1`？等于，返回 `'d'`。

```python
L = 0
for c in s:
    if c == '*': L = max(L - 1, 0)
    elif c == '#': L = min(L * 2, k + 1)
    elif c == '%': pass
    else: L = min(L + 1, k + 1)
if L <= k: return '.'
for c in reversed(s):
    if c == '#':
        half = L // 2
        if k >= half: k -= half
        L = half
    elif c == '%': k = L - 1 - k
    elif c == '*': L += 1
    else:
        if k == L - 1: return c
        L -= 1
```

## 复杂度
时间 O(n)，n 为 s 长度，正反各扫一遍。
空间 O(1)，只存长度 L 和下标 k。

## 易错点
- 正向算长度不截断：`s` 含大量 `#` 时 `L` 会指数膨胀到天文数字，Python 大整数乘法虽不溢出但会拖慢；应在 `#` 和字母分支用 `min(..., k+1)` 截断，因为只需知道 k 是否越界。
- `*` 反向时误把 `L` 减一：`*` 删的是末尾字符，目标下标 k 不受影响，正确做法是 `L += 1` 后再判断；若写成 `L -= 1`，示例 2 中 `k=3` 会错位到 `'c'`。

## 如果面试官追问
若要求返回整个最终字符串而非第 k 个字符？答：长度可达 10^15，无法构造，只能按需定位或流式输出，思路仍是倒推定位每个下标。
