## 一句话思路
用栈存每层 `NestedInteger` 列表，遇 `[` 压栈、遇 `]` 弹栈并挂到父层，遇数字就解析成整数塞进栈顶。

## 怎么做
1. 栈 `stack` 初始为空，`num` 记当前数字、`sign` 记符号，遍历 `s` 的每个字符。
2. 遇 `[`：新建空 `NestedInteger` 压栈；遇 `]`：先把残留的 `num` 收尾，再弹出栈顶 `top`，若栈非空就 `stack[-1].add(top)`，否则 `top` 就是答案。
3. 遇 `,`：把 `num` 收尾塞进 `stack[-1]`，`num` 清零、`sign` 复位。
4. 遇数字或 `-`：累积到 `num`，`-` 只改 `sign`。

以 `s = "[123,[456,[789]]]"` 为例：读到 `123` 后遇 `,`，`stack[-1]`（外层列表）里加入 `123`；读到第二个 `[` 时栈深变为 2，`456` 加入内层；`789` 加入最内层后，`]` 触发弹出，`[789]` 被 `add` 进 `[456,...]`，再弹一次 `[456,[789]]` 挂到外层，最终栈只剩一个元素即答案。

```python
stack, num, sign = [], 0, 1
for ch in s:
    if ch == '[':
        stack.append(NestedInteger())
    elif ch == ']':
        if s[i-1] != ']' and s[i-1] != '[':   # 有残留数字才收尾
            stack[-1].add(NestedInteger(sign * num)); num, sign = 0, 1
        top = stack.pop()
        if stack: stack[-1].add(top)
        else: return top
    elif ch == ',':
        stack[-1].add(NestedInteger(sign * num)); num, sign = 0, 1
    elif ch == '-':
        sign = -1
    else:
        num = num * 10 + int(ch)
return NestedInteger(sign * num)   # 纯数字如 "324"
```

## 复杂度
时间 O(n)：`s` 每个字符恰好扫一次，`n = len(s)`。
空间 O(d)：栈深等于嵌套层数 `d`，最坏 `d = n/2`，无额外大数组。

## 易错点
- 输入 `"324"`（无括号）→ 循环结束没走 `]` 分支，`num` 没被收尾，返回空对象 → 循环后必须补一句 `return NestedInteger(sign * num)`。
- 输入 `"[[]]"` 或 `"[1,]"` 类边界 → 在 `]` 前无条件 `add(num)` 会把 `0` 塞进空列表 → 收尾前判断前一字符是否为数字（`s[i-1].isdigit()`），否则跳过。

## 如果面试官追问
问：若 `s` 长度到 10^7、递归写法会爆栈怎么办？
答：本解已是迭代栈，深度只受内存限制，无需改；只需把 `num` 累积改成流式读入即可。
