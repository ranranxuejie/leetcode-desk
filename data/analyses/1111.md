## 一句话思路
按当前左括号的栈深度 `d` 的奇偶分给 A/B，使同一层相邻括号分属不同组，深度被对半砍。

## 怎么做
1. 用 `d` 记录当前未匹配左括号数，遇 `(` 先 `d += 1`，遇 `)` 先取 `d` 再 `d -= 1`。
2. 分配规则统一为 `d % 2`：左括号用自增后的 `d`，右括号用自减前的 `d`，保证配对括号同组。
3. 以 `seq = "(()())"` 为例：`(` 后 `d=1` 给 0，第二个 `(` 后 `d=2` 给 1，第一个 `)` 前 `d=2` 给 1，第二个 `)` 前 `d=1` 给 0，得 `[0,1,1,1,1,0]`。
4. 因为深度为 `d` 的括号只可能落在 `d%2` 两组之一，每组最大深度不超过 `ceil(D/2)`，已是最优下界。

```python
ans = []
d = 0
for ch in seq:
    if ch == '(':
        d += 1
        ans.append(d % 2)
    else:
        ans.append(d % 2)
        d -= 1
```

## 复杂度
时间 O(n)：一次遍历 `seq`，每个字符常数操作。
空间 O(n)：只额外开 `ans` 长度 n，`d` 是 O(1)。

## 易错点
- 右括号写成先 `d -= 1` 再取 `d % 2` → 对 `"()"` 会输出 `[0,0]`，配对括号被拆到同组，A 变成 `"("`、B 变成 `")"`，都不是 VPS；正确是先取 `d % 2` 再减。
- 用 `d % 2` 时把左括号的 `d` 取成自增前的值 → 对 `"(()())"` 得 `[0,1,1,0,0,1]`，第一个 `(` 和最后一个 `)` 同组但中间配对错位，A 成 `"()("` 非法；左右括号必须用同一套「配对括号同深度」的取值。

## 如果面试官追问
问：若要求输出字典序最小的 answer？答：奇偶分配已唯一确定每对括号的组别，交换 0/1 只影响首位，取首位为 0 即可。
