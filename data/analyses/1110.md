## 一句话思路
后序 DFS 返回「本子树处理完后挂到父节点上的那棵根」，用 `set(to_delete)` 做 O(1) 判定，删点即断链。

## 怎么做
1. 把 `to_delete` 转成 `dele = set(to_delete)`，避免每次线性查找。
2. 递归函数 `dfs(node)` 返回该子树修剪后应交给父节点的根（`None` 表示整棵被删空）。
3. 先递归左右子，再判断自己：若 `node.val in dele`，把非空的左右子加入 `forest`，返回 `None`；否则返回 `node`。
4. 主函数里若 `dfs(root)` 非空，把它也加入 `forest`。

以示例 1 为例，`dele = {3, 5}`。走到节点 5 时，左右子皆 `None`，`5 in dele` 成立，返回 `None`，节点 2 的右子被置空；走到节点 3 时，左子 6、右子 7 都非空，两者被 append 进 `forest`，返回 `None`，于是根 1 的右子变 `None`。最终 `forest = [6, 7]`，加上根返回的 1，得到 `[[1,2,null,4],[6],[7]]`。

```python
def dfs(node):
    if not node:
        return None
    node.left = dfs(node.left)
    node.right = dfs(node.right)
    if node.val in dele:
        if node.left: forest.append(node.left)
        if node.right: forest.append(node.right)
        return None
    return node

r = dfs(root)
if r: forest.append(r)
```

关键点：子节点是在**父节点被删的那一刻**才被收进 `forest` 的，所以不会重复收集——节点 6 只会在处理 3 时被 append 一次。

## 复杂度
时间 O(n)：每个节点访问一次，`set` 查询 O(1)。
空间 O(n)：`dele` 占 O(m)，递归栈最坏 O(n)（链状树）。

## 易错点
- 根节点被删时忘记收子：输入 `root=[1,2], to_delete=[1]`，若只写 `dfs(root)` 不处理返回值，`forest` 里只剩 `[2]` 却漏了「根返回 `None` 时不该再 append」的判断，或反过来把 `None` 塞进结果。正确做法是 `r = dfs(root); if r: forest.append(r)`。
- 在递归**前**判断删除并直接返回：输入 `root=[1,2,3,4,5,6,7], to_delete=[3]`，若先判 `3 in dele` 就 `return None`，节点 6、7 从未被访问，森林里丢掉 `[6]`、`[7]`。必须先递归左右子再判自己。

## 如果面试官追问
问：若 `to_delete` 很大、节点值不再互异怎么办？
答：值重复时 `set` 判定会误删同名节点，需改成按节点对象（`id`）标记，先遍历一次建 `id -> 是否删除` 的映射。
