## 一句话思路
按成本排序后，枚举第二台机器，用双指针在它左边找成本严格小于 `budget - costs[j]` 的最大容量。

## 怎么做
1. 把 `(costs[i], capacity[i])` 打包成列表，按成本升序排序。
2. 预处理前缀最大容量 `pref[i] = max(capacity[0..i])`，这样左边任意一段的最优容量能 O(1) 取到。
3. 枚举右机器 `j`，用双指针 `i` 从 `j-1` 往左收缩，直到 `costs[i] + costs[j] < budget`；此时 `pref[i]` 就是左机器的最优容量。
4. 答案同时考虑单台机器（`capacity[j] < budget` 时）和双台组合。

以示例 1 为例：排序后 `costs=[3,4,5,8]`、`capacity=[7,1,2,5]`，`pref=[7,7,7,7]`。枚举 `j=1`（cost=4）时，`budget-costs[j]=4`，`i=0` 满足 `3+4=7<8`，候选 `pref[0]+capacity[1]=7+1=8`，即答案。

```python
items = sorted(zip(costs, capacity))
pref = []
best = 0
for c, v in items:
    best = max(best, v)
    pref.append(best)
ans = 0
i = -1
for j in range(len(items)):
    if items[j][0] < budget:
        ans = max(ans, items[j][1])
    while i + 1 < j and items[i + 1][0] + items[j][0] < budget:
        i += 1
    if i >= 0:
        ans = max(ans, pref[i] + items[j][1])
```

## 复杂度
时间 O(n log n)：排序贡献 log n，双指针 `i` 单调右移，总扫描 O(n)。
空间 O(n)：`items` 和 `pref` 各开一个长度 n 的列表。

## 易错点
- 条件是**严格小于** `budget`，不是 `<=`。示例 1 中若写成 `<=`，`costs[1]+costs[2]=4+5=9` 仍不满足，但 `3+5=8` 会被误判合法，容量变成 `7+2=9`，输出 9 而非 8。
- 只选一台机器的情况容易漏。示例 2 中 `costs=[3,5,7,4]`，任意两台最小和 `3+4=7` 不严格小于 7，双台全废；只有单台 `costs[3]=4<7` 给出容量 6，漏掉单台会返回 0。
- 双指针 `i` 必须全局单调，不能每轮重置为 `j-1`，否则退化成 O(n²)，n=10^5 时超时。

## 如果面试官追问
若要求输出具体选中的两台机器下标？答：排序时保留原始下标，`pref` 存「前缀最大容量对应的下标」，命中时同时取出 `pref_idx[i]` 和 `j` 的原始下标即可。
