## 一句话思路
自底向上 DFS 返回子树高度（非完美返回 -1），完美就把 `2**h - 1` 收进列表，降序取第 k 个。

## 怎么做
1. 递归函数返回该子树的高度：空树返回 0，任一孩子返回 -1 就返回 -1，两孩子高度不等也返回 -1，否则返回 `h+1`。
2. 每次拿到非 -1 的高度 h，说明当前子树完美，把大小 `2**h - 1` 追加到 `sizes`。
3. 遍历完对 `sizes` 降序排序，`k > len(sizes)` 返回 -1，否则返回 `sizes[k-1]`。

以示例 1 的 `root = [5,3,6,5,2,5,7,1,8,null,null,6,8]` 为例：叶子 1、8、6、8 各返回高度 1，贡献大小 1；节点 5（左孩子 1、右孩子 8）两孩子高度都是 1，返回 2，贡献 `2**2-1 = 3`；节点 3 的左孩子 5 返回 2、右孩子 2 返回 1，高度不等返回 -1，所以以 3 为根的子树不完美、不入表。最终 `sizes` 降序为 `[3,3,1,1,1,1,1,1]`，`k=2` 取 `sizes[1] = 3`。

```python
def dfs(node):
    if not node:
        return 0
    lh, rh = dfs(node.left), dfs(node.right)
    if lh == -1 or rh == -1 or lh != rh:
        return -1
    sizes.append(2 ** (lh + 1) - 1)
    return lh + 1

sizes = []
dfs(root)
sizes.sort(reverse=True)
return sizes[k - 1] if k <= len(sizes) else -1
```

关键点：高度用「层数」而非「边数」，空树 0、叶子 1，这样 `2**h - 1` 直接就是节点数，不用额外记 size。

## 复杂度
时间 O(n + m log m)：DFS 访问 n 个节点，m 个完美子树排序，m ≤ n。
空间 O(n)：递归栈最坏 n 层，`sizes` 最多 n 个元素。

## 易错点
- 输入 `[1,2,3,null,4]`：节点 2 只有右孩子 4，若只比较左右高度会得到 `lh=0, rh=1` 不等返回 -1，看似没问题；但若写成「空孩子高度记 0 且跳过比较」，就会把节点 2 误判为完美并贡献大小 3，正确做法是空树返回 0 且必须参与 `lh != rh` 判断。
- 输入 `[1,2,3,4,5,6,7]` 且 `k=1`：若把高度定义成边数（叶子返回 0），根返回 2，算出 `2**2-1 = 3` 而不是 7，正确做法是叶子返回 1、根返回 3，`2**3-1 = 7`。

## 如果面试官追问
问：不排序能否 O(n) 拿到第 k 大？
答：可以，用一个大小为 k 的小顶堆维护当前最大的 k 个大小，插入 O(log k)，总 O(n log k)，k 小时更快。
