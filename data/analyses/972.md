## 一句话思路
把两个字符串都精确转成分数 `分子/分母`，再交叉相乘比较，避免浮点误差和无限小数展开。

## 怎么做
1. 用 `find('(')` 判断有无循环节，拆出整数部分、非循环部分 `non`、循环部分 `rep`。
2. 无循环节时，值 = `int(整数 + non) / 10**len(non)`。
3. 有循环节时，值 = `(int(整数+non+rep) - int(整数+non)) / (10**len(non) * (10**len(rep)-1))`。
4. 两个分数交叉相乘 `a*d == c*b` 返回布尔。

以 `s = "0.9(9)"` 为例：整数 `"0"`，`non = "9"`，`rep = "9"`。分子 = `int("099") - int("09") = 99 - 9 = 90`，分母 = `10**1 * (10**1 - 1) = 10 * 9 = 90`，得 `90/90 = 1`；`t = "1."` 得 `1/1`，交叉相乘 `90*1 == 1*90`，返回 `True`。

```python
def parse(x):
    i = x.find('(')
    if i == -1:
        ip, _, non = x.partition('.')
        return int(ip + non), 10 ** len(non)
    ip, _, rest = x[:i].partition('.')
    rep = x[i + 1:-1]
    a = int(ip + rest + rep) - int(ip + rest)
    b = 10 ** len(rest) * (10 ** len(rep) - 1)
    return a, b

a, b = parse(s)
c, d = parse(t)
return a * d == c * b
```

## 复杂度
时间：O(n)，n 为两串总长，`int()` 转换与长度成正比。
空间：O(n)，存拼接后的数字串，Python 大整数本身也占 O(n) 位。

## 易错点
- `"1."` 这类无小数位的输入 → `partition('.')` 后 `non` 为空串，若直接 `int(non)` 会抛异常 → 正确做法是拼成 `ip + non` 再 `int`，空串拼进去不影响。
- `"0.(52)"` 的 `non` 为空 → 若分母写成 `10**len(non)` 得 1，但循环节公式里 `int(ip+non+rep) - int(ip+non)` 仍成立；关键是 `non` 为空时 `int("0") - int("0")` 不能漏掉 `rep` 的拼接，否则分子恒为 0。

## 如果面试官追问
若要求支持负号或科学计数法？答：解析时先剥离符号位，指数部分折算成 `10**k` 乘到分母上，交叉相乘逻辑不变。
