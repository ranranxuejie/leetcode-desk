## 一句话思路
从下标 1 扫到 n-2，逐个检查 `mountain[i]` 是否严格大于左右邻居，满足就收集下标。

## 怎么做
1. 答案列表 `res = []`，循环范围取 `range(1, len(mountain) - 1)`，天然排除首尾。
2. 每个 `i` 判断 `mountain[i] > mountain[i-1] and mountain[i] > mountain[i+1]`，两个条件必须同时成立。
3. 成立就 `res.append(i)`，不成立直接跳过，无需提前退出。
4. 扫完返回 `res`，题目允许顺序不限，所以不用排序。

以 `mountain = [1,4,3,8,5]` 为例：`i=1` 时 `4 > 1` 且 `4 > 3`，收下标 1；`i=2` 时 `3 > 4` 为假，跳过；`i=3` 时 `8 > 3` 且 `8 > 5`，收下标 3，最终 `res = [1,3]`。

```python
res = []
for i in range(1, len(mountain) - 1):
    if mountain[i] > mountain[i - 1] and mountain[i] > mountain[i + 1]:
        res.append(i)
return res
```

关键点：循环上界是 `len(mountain) - 1`，`range` 右开，最后一个被检查的下标是 `n-2`，正好避开 `n-1`。

## 复杂度
时间 O(n)：每个中间元素只被比较一次，n 是数组长度。
空间 O(1)：除答案列表外没有额外数组，答案本身最多 n-2 个下标。

## 易错点
- 输入 `[2,4,4]` → 若把条件写成 `>=`，`i=1` 时 `4 >= 4` 成立，会错答 `[1]`；正确做法是两处都用严格 `>`，返回 `[]`。
- 输入 `[1,2,3]` → 若循环写成 `range(1, len(mountain))`，`i=2` 会去取 `mountain[3]` 越界报错；正确做法是上界写 `len(mountain) - 1`，只扫到 `n-2`。

## 如果面试官追问
问：数组长度放大到 10^7 且内存受限怎么办？
答：仍是单次 O(n) 扫描、O(1) 额外空间，只需把答案下标流式输出，不必整体存 `res`。
