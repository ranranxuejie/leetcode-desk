## 一句话思路
按数位逐位统计 0–9 各出现几次，用「该位总对数 − 相同数字对数」累加，避免枚举 O(n²) 对。

## 怎么做
1. 取 `L = len(str(nums[0]))`，因为所有数等长，逐位处理 `p = 0..L-1`。
2. 对第 `p` 位（从低位起，用 `(x // 10**p) % 10` 取），开长度 10 的计数数组 `cnt`，遍历 `nums` 累加。
3. 该位贡献 = `n*(n-1)//2 - sum(c*(c-1)//2 for c in cnt)`，即总对数减去同数字对数。
4. 所有位贡献相加返回。

以 `nums = [13,23,12]` 为例，个位数字是 `3,3,2`，`cnt[3]=2, cnt[2]=1`，总对数 `3*2//2=3`，相同对数 `1+0=1`，个位贡献 `2`；十位是 `1,2,1`，`cnt[1]=2, cnt[2]=1`，贡献也是 `2`；合计 `4`，与示例一致。

```python
n = len(nums)
L = len(str(nums[0]))
ans = 0
total = n * (n - 1) // 2
for p in range(L):
    cnt = [0] * 10
    for x in nums:
        cnt[(x // 10**p) % 10] += 1
    same = sum(c * (c - 1) // 2 for c in cnt)
    ans += total - same
return ans
```

关键点：`total` 只算一次，别放进循环里重复乘；`same` 必须对 10 个桶全求和，漏掉 `cnt[0]` 在含 0 的数位上会少减。

## 复杂度
时间：O(n·L)，`n` 来自遍历 `nums`，`L ≤ 9` 来自数位长度。
空间：O(1)，只开了长度 10 的 `cnt`，与 `n` 无关。

## 易错点
- 输入 `nums = [10,10,10,10]` → 若只统计出现过的数字、跳过 `cnt[0]`，个位 4 个 0 的相同对数 `6` 被漏减，答案错成 `6` 而非 `0` → 必须对 `cnt` 全部 10 个桶求和。
- 输入 `nums = [13,23,12]` → 若用 `str(x)[p]` 从左往右取位，个位和十位顺序颠倒，本例恰好对称看不出错，换成 `[12,13,23]` 或 `[19,91]` 就会算错 → 统一用 `(x // 10**p) % 10` 从低位起，或统一用字符串但保证所有数同向。

## 如果面试官追问
若 `nums[i]` 数位长度不再相同，怎么改？
答：按最长位数对齐，短数高位补 0 再统计，补出的 0 参与计数即可，复杂度不变。
