## 一句话思路
分别用 Counter 统计两个数组的词频，再取交集，只保留两边计数都恰为 1 的键。

## 怎么做
1. 用 `Counter(words1)` 和 `Counter(words2)` 各建一张词频表。
2. 遍历 `c1` 的键，只检查同时出现在 `c2` 里的词。
3. 对每个候选词，判断 `c1[w] == 1 and c2[w] == 1`，成立就累加。
4. 返回累加值。

以示例 1 为例：`c1 = {"leetcode":1, "is":2, "amazing":1, "as":1}`，`c2 = {"amazing":1, "leetcode":1, "is":1}`。遍历 `c1` 时，`"is"` 的 `c1["is"] == 2`，被排除；`"as"` 不在 `c2` 里，也被排除；剩下 `"leetcode"` 和 `"amazing"` 两边计数都是 1，答案 2。

```python
from collections import Counter

c1 = Counter(words1)
c2 = Counter(words2)
ans = 0
for w, cnt in c1.items():
    if cnt == 1 and c2.get(w, 0) == 1:
        ans += 1
return ans
```

关键在 `c2.get(w, 0) == 1`：用 `get` 的默认值 0 把「不在 words2 中」和「在 words2 中出现多次」统一成不满足条件，省掉一次 `in` 判断。

## 复杂度
时间 O(n + m)：n、m 分别是 words1、words2 的长度，建两张表加一次遍历。
空间 O(n + m)：两张 Counter 各存去重后的词，最坏无重复时是 n + m 个键。

## 易错点
- 只统计 `c1[w] == 1` 就累加 → 示例 1 里 `"as"` 会被错算进去，答案变成 3。必须同时要求 `c2.get(w, 0) == 1`，两个数组都恰好一次才算。
- 用 `set(words1) & set(words2)` 求交集 → 示例 1 里 `"is"` 会留在交集中，答案错成 3。集合丢掉了频次信息，`"is"` 在 words1 出现 2 次必须被剔除，所以要用 Counter 而不是 set。

## 如果面试官追问
若 words1 长度到 10^6 而 words2 很小，怎么优化？
答：只对 words2 建 Counter，再单遍扫 words1 计数，命中且计数为 1 时累加，空间降到 O(m)。
