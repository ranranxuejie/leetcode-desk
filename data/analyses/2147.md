## 一句话思路
按座位分组，每两个座位成一段，相邻两段之间的植物数 +1 就是可插入屏风的位置数，全部相乘。

## 怎么做
1. 先数总座位数 `total`，若 `total == 0` 或 `total % 2 == 1`，直接返回 0。
2. 扫描字符串，记录每个座位的位置，把第 2k 个和第 2k+1 个座位配对成一段。
3. 相邻两段之间，屏风可放在「上一段最后一个座位」到「下一段第一个座位」之间的任意空隙，方案数为 `gap = pos[next_first] - pos[prev_last]`。
4. 把所有 `gap` 相乘，对 `10**9 + 7` 取余。

以 `corridor = "SSPPSPS"` 为例，座位下标是 `[0,1,4,6]`。第一段是 `(0,1)`，第二段是 `(4,6)`。两段之间的空隙是下标 1 到 4 之间，`gap = 4 - 1 = 3`，正好对应示例输出的 3。

```python
MOD = 10**9 + 7
pos = [i for i, c in enumerate(corridor) if c == 'S']
if not pos or len(pos) % 2:
    return 0
ans = 1
for k in range(2, len(pos), 2):
    ans = ans * (pos[k] - pos[k - 1]) % MOD
return ans
```

关键点：`pos[k]` 是下一段的第一个座位，`pos[k-1]` 是上一段的最后一个座位，两者之差就是这段植物区间的长度加 1，也就是屏风可放的位置数。

## 复杂度
时间：O(n)，一次遍历收集座位位置，n 是走廊长度。
空间：O(n)，`pos` 数组最多存 n 个下标。

## 易错点
- 输入 `corridor = "PPSPSP"` 时，座位下标是 `[2,4]`，只有一段，循环 `range(2, 2, 2)` 不执行，`ans` 保持 1，正确。若误写成从 `range(0, ...)` 开始配对，会把 `pos[0]` 和 `pos[-1]` 错配，得到错误结果。
- 输入 `corridor = "SS"` 时，`pos = [0,1]`，循环不执行返回 1，表示不放置任何屏风也是一种方案。若把「不放置屏风」当成非法情况返回 0，就会漏掉这个合法解。

## 如果面试官追问
问：如果要求每段植物数不超过 k，怎么改？
答：把 `gap` 从「全部空隙数」改成 `min(gap, k+1)`，再连乘即可。
