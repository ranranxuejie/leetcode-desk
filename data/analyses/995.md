## 一句话思路
从左到右扫，遇到 0 就必须以它为左端点翻一次，用队列维护当前生效的翻转次数。

## 怎么做
1. 维护 `q` 存所有「已执行翻转的左端点」，`i` 处实际生效的翻转次数就是 `len(q)`。
2. 扫到 `i` 时先弹出 `q[0] + k <= i` 的过期翻转，再判断 `(nums[i] + len(q)) % 2`。
3. 若结果为 0 说明 `i` 是 0，必须以 `i` 为左端点翻一次；若 `i + k > n` 则返回 -1。
4. 否则 `q.append(i)`，答案加一。

以示例 3 `nums = [0,0,0,1,0,1,1,0], k = 3` 为例：`i=0` 时 `q` 空，`nums[0]=0` 需翻，`q=[0]`；`i=3` 时 `q[0]+3=3<=3` 弹出，`q` 空，`nums[3]=1` 不翻；`i=4` 时 `nums[4]=0` 需翻，`q=[4]`；`i=5` 时 `len(q)=1`，`nums[5]+1=2` 为偶，需翻，`q=[4,5]`；`i=6` 时 `len(q)=2`，`nums[6]+2=3` 为奇，不翻；`i=7` 时 `q[0]+3=7<=7` 弹出，`q=[5]`，`nums[7]+1=1` 为奇，不翻。共 3 次。

```python
from collections import deque

def minKBitFlips(nums, k):
    n = len(nums)
    q = deque()
    ans = 0
    for i in range(n):
        if q and q[0] + k <= i:
            q.popleft()
        if (nums[i] + len(q)) % 2 == 0:
            if i + k > n:
                return -1
            q.append(i)
            ans += 1
    return ans
```

关键点：`len(q)` 就是 `i` 处被翻转的奇偶性来源，不需要真的改 `nums`。

## 复杂度
时间 O(n)：每个下标最多入队、出队各一次。
空间 O(k)：`q` 中最多同时存 k 个左端点。

## 易错点
- 输入 `nums = [1,1,0], k = 2`：扫到 `i=2` 时 `nums[2]=0` 需翻，但 `2+2>3`，若忘记判 `i+k>n` 会越界或错误返回 0，正确做法是立即返回 -1。
- 输入 `nums = [0,1,0], k = 1`：若用 `q[0]+k < i` 而非 `<= i` 判过期，`i=1` 时 `q=[0]` 未弹出，`nums[1]+1=2` 为偶会误翻，正确条件是 `q[0]+k <= i`。

## 如果面试官追问
问：要求输出具体翻转方案怎么办？
答：把每次 `q.append(i)` 的 `i` 记进结果列表，最后返回该列表即可，逻辑不变。
