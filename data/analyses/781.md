## 一句话思路
按回答值 k 分组，每组每 k+1 只兔子共用一种颜色，向上取整即得该组最少兔子数。

## 怎么做
1. 用哈希表 `cnt` 统计每个回答值出现的次数，键是 `answers[i]`，值是出现次数。
2. 对每个键 `k`，同色兔子总数固定为 `k+1`（回答 k 意味着包括自己在内共 k+1 只同色）。
3. 该组需要的颜色批次数是 `ceil(cnt[k] / (k+1))`，用 `(cnt[k] + k) // (k + 1)` 实现。
4. 每批贡献 `k+1` 只兔子，累加 `批次 * (k+1)` 即为答案。

以 `answers = [1,1,2]` 为例：`cnt = {1: 2, 2: 1}`。对 `k=1`，批次 `(2+1)//2 = 1`，贡献 `1*2 = 2`；对 `k=2`，批次 `(1+2)//3 = 1`，贡献 `1*3 = 3`；合计 `2+3 = 5`。

```python
from collections import Counter

cnt = Counter(answers)
total = 0
for k, c in cnt.items():
    group = k + 1
    batches = (c + group - 1) // group
    total += batches * group
return total
```

关键中间值：`k=2` 时 `group=3`，虽然只有 1 只兔子回答 2，但必须补足 3 只同色兔子，所以贡献 3 而非 1。

## 复杂度
时间 O(n)：遍历 `answers` 建表一次，再遍历不同回答值（≤ n 个）。
空间 O(n)：`Counter` 最多存 n 个不同键，无其他额外结构。

## 易错点
- 输入 `answers = [10,10,10]` → 若误以为 3 只回答 10 的兔子同色、总数就是 3 → 实际同色组固定 11 只，批次 `(3+10)//11 = 1`，答案应为 11。必须按 `k+1` 补足整组。
- 输入 `answers = [0,0,0]` → 若用 `c // (k+1)` 向下取整 → 得 0 批、答案 0，错误。`k=0` 时每组只有 1 只，3 只互不同色，答案应为 3；必须用向上取整 `(c + k) // (k + 1)`。

## 如果面试官追问
问：若要求输出每种颜色各多少只兔子，怎么改？
答：在累加时记录每个 `k` 的 `batches`，输出 `batches` 个大小为 `k+1` 的组即可。
