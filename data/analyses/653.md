## 一句话思路
中序遍历得到升序数组，再在数组上左右双指针逼近 k，因为 BST 中序有序。

## 怎么做
1. 中序遍历 `root`，把节点值按序追加到 `vals`。
2. 对示例 1 得到 `vals = [2,3,4,5,6,7]`，`k = 9`。
3. 设 `i = 0`、`j = len(vals)-1`，循环比较 `vals[i] + vals[j]` 与 `k`。
4. 和小于 `k` 就 `i += 1`，大于就 `j -= 1`，相等返回 `True`；循环结束返回 `False`。

关键中间值：示例 1 首轮 `vals[0]+vals[5] = 2+7 = 9`，直接命中返回 `True`；示例 2 中 `k = 28`，首轮 `2+7 = 9 < 28` 故 `i` 右移，最终 `6+7 = 13 < 28` 后 `i` 越过 `j`，返回 `False`。

```python
def inorder(node, vals):
    if not node:
        return
    inorder(node.left, vals)
    vals.append(node.val)
    inorder(node.right, vals)

vals = []
inorder(root, vals)
i, j = 0, len(vals) - 1
while i < j:
    s = vals[i] + vals[j]
    if s == k:
        return True
    if s < k:
        i += 1
    else:
        j -= 1
return False
```

## 复杂度
时间：中序 O(n)，双指针 O(n)，合计 O(n)，n 为节点数。
空间：`vals` 存 n 个值 O(n)，递归栈最坏 O(n)（链状 BST）。

## 易错点
- 输入 `root = [2,1,3]`、`k = 4` → 若用哈希边遍历边查，先插入 2 再查 `4-2=2` 会命中自己，错返回 `True`；正确做法是查完再插入，或先中序收集再双指针，天然不会取同一节点两次。
- 输入 `root = [1]`、`k = 2` → 若双指针写成 `while i <= j`，`i == j` 时会拿同一个节点自加，错返回 `True`；正确写法是 `while i < j`，单节点必返回 `False`。

## 如果面试官追问
问：要求 O(h) 空间、不存整个数组怎么办？
答：用两个迭代器中序/逆序各走一步，模拟双指针，栈深度即树高 h。
