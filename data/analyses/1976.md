## 一句话思路
先 Dijkstra 求 0 到各点的最短路，再按距离升序 DP 累加「只走最短路上的边」的路径数。

## 怎么做
1. 用堆优化 Dijkstra 从 0 出发，得到 `dist[i]`，示例 1 中 `dist = [0,2,5,5,5,6,7]`。
2. 把 roads 建成邻接表，每条边双向存 `(v, w)`。
3. 按 `dist` 升序处理节点（Dijkstra 出堆顺序天然满足），对每个 `u` 遍历邻居 `v`：若 `dist[u] + w == dist[v]`，则 `ways[v] = (ways[v] + ways[u]) % MOD`。
4. 返回 `ways[n-1]`，示例 1 中 6 号点被 0、4、5 三条最短路前驱累加，得 4。

关键中间值：处理 `u=5`（dist=6）时，邻居 6 满足 `6+1==7`，`ways[6]` 从 3 变 4；而 `u=3` 到 6 的边权 3 使 `5+3=8≠7`，被跳过。

```python
import heapq
MOD = 10**9 + 7
dist = [float('inf')] * n
dist[0] = 0
pq = [(0, 0)]
while pq:
    d, u = heapq.heappop(pq)
    if d > dist[u]:
        continue
    for v, w in adj[u]:
        if d + w < dist[v]:
            dist[v] = d + w
            heapq.heappush(pq, (dist[v], v))
ways = [0] * n
ways[0] = 1
for u in sorted(range(n), key=lambda x: dist[x]):
    for v, w in adj[u]:
        if dist[u] + w == dist[v]:
            ways[v] = (ways[v] + ways[u]) % MOD
```

## 复杂度
时间：Dijkstra 的 `O(m log n)` 主导，排序 `O(n log n)`，`m` 为边数。
空间：邻接表 `O(n+m)`，`dist`/`ways` 各 `O(n)`，堆 `O(m)`。

## 易错点
1. 边权最大 10^9、n=200，最短路可达 2*10^11，用 `2**31 - 1` 当无穷大会把 `dist` 截断成错误值 → 必须用 `float('inf')` 或 `10**18`。
2. 用「先求 dist 再对每条边判断」时，若按节点编号而非 `dist` 升序累加，`ways[u]` 可能尚未定型就被用来更新 `ways[v]` → 必须 `sorted(range(n), key=lambda x: dist[x])`，示例 1 中 6 号点编号最大但 dist 最大，恰好安全，换成编号乱序的图就翻车。

## 如果面试官追问
问：要求输出所有最短路的具体路径怎么办？
答：在 DP 时给每个点存前驱列表，最后从 `n-1` 沿 `dist[u]+w==dist[v]` 反向 DFS 回溯即可。
