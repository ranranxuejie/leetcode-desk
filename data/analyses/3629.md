## 一句话思路
对下标做 BFS，把每个质数值的传送目标一次性用完即删，避免重复枚举。

## 怎么做
1. 先用埃氏筛预处理到 `max(nums)` 的质数表，`is_prime` 用于判断 `nums[i]`。
2. 建 `pos = defaultdict(list)`，把每个值对应的下标都存进去；BFS 队列从 `0` 开始，`dist[0]=0`。
3. 出队下标 `i` 时，先试 `i-1`、`i+1`；若 `nums[i]` 是质数 `p`，再遍历 `pos[p]` 的倍数键 `2p,3p,...`，把 `pos[k]` 里所有下标入队后**清空该列表**。
4. 一旦弹出 `n-1` 就返回 `dist`。

以 `nums=[1,2,4,6]` 为例：`dist[0]=0`，先入队 `1`（`dist=1`）；弹出 `1` 时 `nums[1]=2` 是质数，遍历 `pos[2]`、`pos[4]`、`pos[6]`，其中 `pos[6]=[3]` 入队得 `dist[3]=2`，弹出 `3` 即返回 `2`。

```python
from collections import defaultdict, deque
# 筛法略，is_prime 已就绪
pos = defaultdict(list)
for i, v in enumerate(nums):
    pos[v].append(i)
dist = [-1] * n
dist[0] = 0
q = deque([0])
while q:
    i = q.popleft()
    if i == n - 1:
        return dist[i]
    for j in (i - 1, i + 1):
        if 0 <= j < n and dist[j] < 0:
            dist[j] = dist[i] + 1
            q.append(j)
    p = nums[i]
    if is_prime[p]:
        for k in range(p, max_v + 1, p):
            for j in pos[k]:
                if dist[j] < 0:
                    dist[j] = dist[i] + 1
                    q.append(j)
            pos[k].clear()
```

## 复杂度
时间：筛法 `O(M log log M)`，`M=max(nums)`；BFS 中每个下标入队一次、每个值列表被清空一次，`O(n + M log log M)`。
空间：`pos` 存 `n` 个下标，`dist` 与队列各 `O(n)`，筛表 `O(M)`。

## 易错点
- 传送后不清空 `pos[k]`：`nums` 里有很多相同倍数（如全为 `6`）时，每个质数都会重扫整张表，退化成 `O(n²)`；正确做法是入队后立刻 `pos[k].clear()`，因为同一列表第二次被访问时所有下标必然已有 `dist`。
- 把 `nums[i]` 本身当传送目标：题面要求 `j != i`，但 `pos[p]` 里含 `i` 自己；靠 `dist[j] < 0` 挡掉即可，若改成无条件入队会把 `i` 重新压回队列造成死循环。

## 如果面试官追问
问：`nums[i]` 上限提到 `10^9` 怎么办？
答：筛法不可行，改用试除到 `sqrt(nums[i])` 判质数，传送仍靠 `pos` 按值分组，复杂度不变。
