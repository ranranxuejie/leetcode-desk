## 一句话思路
两次 DFS：先自底向上求子树大小与根的距离和，再自顶向下用换根公式一次推出所有答案。

## 怎么做
1. 建邻接表 `g`，任选 0 为根，DFS 后序算出 `size[u]`（含 u 的子树节点数）和 `ans[0] = sum(depth)`。
2. 换根递推：对边 `u -> v`（v 是 u 的儿子），把根从 u 挪到 v 时，v 子树内 `size[v]` 个点各近 1，其余 `n - size[v]` 个点各远 1。
3. 所以 `ans[v] = ans[u] - size[v] + (n - size[v])`，按前序再 DFS 一遍填满数组。

以示例 1 为例：以 0 为根，`size = [6,1,4,1,1,1]`，`ans[0] = 1+1+2+2+2 = 8`。换到节点 2：`ans[2] = 8 - 4 + (6-4) = 6`，与输出一致；再由 2 推到 3：`6 - 1 + 5 = 10`。

```python
def dfs1(u, p):
    size[u] = 1
    for v in g[u]:
        if v != p:
            dfs1(v, u)
            size[u] += size[v]
            ans[u] += ans[v] + size[v]

def dfs2(u, p):
    for v in g[u]:
        if v != p:
            ans[v] = ans[u] - size[v] + (n - size[v])
            dfs2(v, u)
```

`ans[u] += ans[v] + size[v]` 是关键：v 子树每个点到 u 的距离 = 到 v 的距离 + 1，共 `size[v]` 个点。

## 复杂度
时间 O(n)：两次 DFS 各遍历每条边一次，n 来自节点数。
空间 O(n)：邻接表 `g` 占 2(n-1) 项，`size`、`ans` 各 n 项，递归栈最坏 n 层。

## 易错点
- 链状输入（如 `edges = [[0,1],[1,2],...,[n-2,n-1]]`，n = 3*10^4）→ Python 默认递归深度约 1000，`dfs1` 直接 `RecursionError` → 要么 `sys.setrecursionlimit(10**5)`，要么改写成显式栈的迭代后序。
- 换根公式写成 `ans[v] = ans[u] - size[v] + n - size[v]` 时漏括号或符号搞反 → 示例 1 中 `ans[2]` 会算成 `8 - 4 + 4 = 8` 而非 6 → 记住「子树内减、子树外加」，即 `-size[v] + (n - size[v])`。
- 忘记 `v != p` 判父 → 在无向树上会立刻回访父节点死循环，`size` 被反复累加。

## 如果面试官追问
问：n 放大到 10^6 且要求不递归怎么办？
答：用栈做显式后序求 `size` 和 `ans[0]`，再用栈做前序跑换根，逻辑不变，只是把调用栈搬到数组里。
