## 一句话思路
自底向上 DFS，每个节点返回「以它为顶端向下延伸的最长合法链长」，在节点处把两个不同字符子树的最长链拼成过该点的路径。

## 怎么做
1. 用 `parent` 建子节点表 `children`，从 0 号节点开始 DFS。
2. 对节点 `u`，递归拿到每个子节点 `v` 的返回值 `down[v]`，只有当 `s[u] != s[v]` 时这条边才可用。
3. 在 `u` 处维护最大的两个可用 `down[v]`（记为 `best1`、`best2`），用 `best1 + best2 + 1` 更新全局答案，返回 `best1 + 1`。
4. 以示例 1 为例：`parent = [-1,0,0,1,1,2]`、`s = "abacbe"`，节点 1 的子节点 3、4 字符分别是 `b`、`c`，都与 `s[1]='b'` 不同，`down[3]=down[4]=1`，于是 `best1=best2=1`，在节点 1 处得到 `1+1+1=3`，即路径 3→1→0 之外的 3→1→4 长度 3。

```python
def dfs(u):
    best1 = best2 = 0
    for v in children[u]:
        d = dfs(v)
        if s[u] != s[v]:
            if d > best1:
                best1, best2 = d, best1
            elif d > best2:
                best2 = d
    ans[0] = max(ans[0], best1 + best2 + 1)
    return best1 + 1
```

注意 `best1`、`best2` 只在字符不同时才参与比较，字符相同的子节点 `d` 直接丢弃，不能退回成 0 参与拼接。

## 复杂度
时间：O(n)，每个节点只被 DFS 访问一次，子节点遍历总次数为边数 n-1。
空间：O(n)，`children` 存 n-1 条边，递归栈最坏 O(n)（链状树）。

## 易错点
- 输入 `parent = [-1,0,0,0]`、`s = "aabc"`：节点 0 与节点 1 字符都是 `a`，若把 `down[1]` 也计入 `best1`，会在节点 0 拼出非法路径 1→0→2，错答 3 但路径含相同字符边；正确做法是 `s[u] != s[v]` 不成立时跳过该子节点，答案 3 来自 2→0→3。
- 输入是单链 `parent = [-1,0,1]`、`s = "abc"`：若只更新全局答案而不返回 `best1 + 1`，上层节点拿不到下层链长，节点 0 处只能拼出 1，错答 2；正确做法是返回值必须是「向下延伸的最长链」，让父节点能继续拼接。

## 如果面试官追问
问：若要求输出这条最长路径的具体节点序列？
答：DFS 时额外记录每个节点 `best1` 对应的子节点编号，更新答案时存下 `u` 和两个子节点，最后从两端沿记录回溯拼出路径。
