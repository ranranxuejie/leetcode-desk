## 一句话思路
用切片 `password[target:] + password[:target]` 直接拼接，因为左移 target 位等价于把前 target 个字符整段搬到末尾。

## 怎么做
1. 取 `password[target:]`，即从下标 `target` 到末尾的后半段。
2. 取 `password[:target]`，即前 `target` 个字符。
3. 两段按「后半段 + 前半段」顺序拼接返回。

以示例 1 的 `password = "s3cur1tyC0d3"`、`target = 4` 为例：`password[4:]` 得到 `"r1tyC0d3"`（下标 4 起的 8 个字符），`password[:4]` 得到 `"s3cu"`，拼接后是 `"r1tyC0d3s3cu"`，与输出一致。关键中间值就是切点下标 4——它同时是后半段的起点和前半段的终点，两个切片长度之和必须等于 `len(password)`。

```python
def dynamicPassword(password, target):
    return password[target:] + password[:target]
```

若面试官要求原地修改（不允许新建字符串），用三次反转：反转 `[0, target)`、反转 `[target, n)`、反转整体，得到同样结果。以 `"lrloseumgh"`、`target = 6` 走一遍：先反转前 6 位得 `"esolrl"`，反转后 5 位得 `"hgmue"`，整体反转 `"esolrlhgmue"` 得 `"umghlrlose"`。注意原地版在 Python 里字符串不可变，需先转 `list`，最后 `"".join` 回来。

## 复杂度
时间 O(n)：切片和拼接各扫一遍全部 n 个字符。
空间 O(n)：`password[target:]` 和 `password[:target]` 各开一段新字符串，合计 n 个字符。

## 易错点
- `target` 等于 `len(password)` 时 → 若按「前 target 个移到末尾」硬算，会得到原串但切片 `password[target:]` 是空串，拼接结果恰好正确；真正翻车的是把 `target` 当成「保留前 target 个不动」，写成 `password[:target] + password[target:]`，输出原串而非左移结果。正确做法是后半段在前。
- `target` 为 0 或负数时 → 题面保证 `1 <= target < len`，但若测试放宽到 0，`password[0:] + password[:0]` 仍返回原串，逻辑自洽；若传负数如 `-1`，`password[-1:]` 会取最后一个字符，结果错乱。正确做法是先 `target %= len(password)` 归一化再切。

## 如果面试官追问
追问：若 password 长达 10^7 且内存受限，怎么改？
答：用三次反转的原地版，只开一个 `list` 副本，空间从两段切片降为一份，仍是 O(n) 但常数更小。
