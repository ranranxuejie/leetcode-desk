## 一句话思路
把「平均值相等」化成「子集和为总和的一半」，用集合 DP 枚举可达的 (元素个数, 子集和)。

## 怎么做
1. 设总和 `S = sum(nums)`、长度 `n`，若 A 有 `k` 个元素，则 `sum(A) = S*k/n`，故只需找 `k` 使 `S*k % n == 0` 且存在大小为 `k`、和为 `S*k//n` 的子集。
2. 用 `dp[k]` 存「恰好 k 个元素能凑出的所有和」的集合，从 `dp[0]={0}` 起按元素逐个更新。
3. 只枚举 `1 <= k <= n//2`（A、B 对称），命中即返回 `True`。
4. 剪枝：`k` 的和上界是 `S*k//n`，超过它的和不必存。

以 `nums = [1,2,3,4,5,6,7,8]` 为例，`S=36, n=8`。`k=4` 时目标和 `36*4//8=18`，`dp[4]` 里确实有 `18`（来自 `1+4+5+8`），返回 `True`。

```python
S, n = sum(nums), len(nums)
dp = [set() for _ in range(n // 2 + 1)]
dp[0].add(0)
for x in nums:
    for k in range(n // 2, 0, -1):
        for s in dp[k - 1]:
            if s + x <= S * k // n:
                dp[k].add(s + x)
for k in range(1, n // 2 + 1):
    if S * k % n == 0 and S * k // n in dp[k]:
        return True
return False
```

## 复杂度
时间：`O(n^2 * S)`，`n` 是元素个数，`S` 是总和，内层集合大小受 `S*k//n` 约束。
空间：`O(n * S)`，`dp` 存 `n//2+1` 个和集合，无额外大数组。

## 易错点
- `nums = [3,1]`：`S=4, n=2`，`k=1` 时目标和 `2`，但 `dp[1]` 只有 `{3,1}`，不含 `2`，须返回 `False`；若漏掉 `S*k % n == 0` 判断，会把 `4*1//2=2` 当成合法目标而误判。
- `nums = [0,0]`：`S=0`，目标和恒为 `0`，`dp[1]` 含 `0`，应返回 `True`；若把 `S*k//n` 当上界写成 `s + x < S*k//n`（严格小于），`0+0` 被剪掉，会错成 `False`。

## 如果面试官追问
问：`n` 放大到 100 怎么办？答：集合 DP 的 `O(n^2*S)` 会爆，改用 meet-in-the-middle 折半枚举子集和再哈希匹配。
