## 一句话思路
按 nums2 从大到小排序，枚举每个元素作为最小值，用大小为 k 的小顶堆维护 nums1 中最大的 k 个和。

## 怎么做
1. 把 (nums2[i], nums1[i]) 配对后按 nums2 降序排序，这样遍历到下标 i 时，nums2[i] 就是当前已选集合的最小值。
2. 遍历排序后的数组，把 nums1 值压入小顶堆并累加到 sum，堆超过 k 就弹出堆顶并从 sum 减去。
3. 当堆大小恰好为 k 时，用 `sum * nums2[i]` 更新答案。

以示例 1 为例：配对排序后为 `[(4,2),(3,3),(2,1),(1,3)]`（nums2, nums1）。遍历到第 3 个元素 `(2,1)` 时，堆内是 `[2,3,3]`，sum=8，但此时堆大小 3=k，计算 `8*2=16`？不对——注意排序后第 3 个是 `(2,1)`，堆里应是前三个 nums1 值 `{2,3,3}`，sum=8，`8*2=16` 与答案 12 不符。正确遍历：`(4,2)` 入堆 sum=2；`(3,3)` 入堆 sum=5；`(2,1)` 入堆 sum=6，堆大小 3=k，`6*2=12`；`(1,3)` 入堆 sum=9 超 k 弹出最小值 1，sum=8，`8*1=8`。答案 12。

```python
import heapq
pairs = sorted(zip(nums2, nums1), reverse=True)
heap, total, ans = [], 0, 0
for b, a in pairs:
    heapq.heappush(heap, a)
    total += a
    if len(heap) > k:
        total -= heapq.heappop(heap)
    if len(heap) == k:
        ans = max(ans, total * b)
return ans
```

## 复杂度
时间 O(n log n)：排序 O(n log n)，每个元素进出堆各 O(log k)，共 O(n log k)。
空间 O(n)：pairs 列表 O(n)，堆 O(k)。

## 易错点
- 排序方向搞反：若按 nums2 升序排，遍历到 i 时 nums2[i] 不是已选集合最小值，示例 1 会算出 `(1+3+3)*4=28` 这类错误值。必须降序，保证当前 b 是候选最小值。
- 堆未满 k 就更新答案：示例 2 中 k=1，若在堆大小 <k 时也算，会得到 `4*7=28` 而非正确 30。必须 `len(heap)==k` 才更新，且弹出要在更新前完成。

## 如果面试官追问
要求输出具体下标方案而非分数？答：堆里存 `(nums1[i], i)` 元组，更新答案时记录当前 b 对应的下标和堆内全部下标即可。
