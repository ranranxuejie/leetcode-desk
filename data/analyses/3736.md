## 一句话思路
只能加不能减，所以目标值只能是 `max(nums)`，答案就是每个元素补到最大值的缺口之和。

## 怎么做
1. 先取 `m = max(nums)`，这是唯一可能的目标值——任何小于它的目标都要求把最大值往下调，而操作只允许加。
2. 遍历 `nums`，对每个 `x` 累加 `m - x`，这就是它需要的加一次数。
3. 返回累加和。

以 `nums = [2,1,3]` 为例：`m = 3`。三个缺口分别是 `3-2=1`、`3-1=2`、`3-3=0`，累加得 `1+2+0 = 3`，与示例一致。注意中间值 `3-1=2` 是最大的一笔，别漏掉。

```python
m = max(nums)
ans = 0
for x in nums:
    ans += m - x
return ans
```

等价的一行写法是 `sum(max(nums) - x for x in nums)`，但面试时先写循环版更好讲清「缺口」这个语义。

为什么不能选比 `max` 更大的目标？设目标为 `m + k`（`k > 0`），每个元素都得多加 `k`，总次数变成 `sum(m - x) + n*k`，严格变大。所以 `max(nums)` 就是最优解，不需要枚举。

## 复杂度
时间 O(n)：一次 `max` 加一次遍历，n 是 `nums` 长度。
空间 O(1)：只用了 `m` 和 `ans` 两个标量，没有额外数组。

## 易错点
- 输入 `nums = [4,4,5]` → 若误以为目标是平均值 `13//3 = 4`，会算出把 `5` 减 1 的负数操作，或强行算成 1；正确做法是目标取 `max = 5`，缺口 `1+1+0 = 2`。
- 输入 `nums = [1]` 或全相等如 `[7,7,7]` → 若在循环里用 `if x != m` 之外还额外做「至少操作一次」的补偿，会返回 1 而非 0；正确做法是缺口为 0 时直接累加 0，单元素数组答案恒为 0。

## 如果面试官追问
问：如果操作改成「每次可把任一元素加 1 或减 1」，答案怎么变？
答：目标变成中位数，答案是 `sum(abs(x - median))`，排序后取 `nums[n//2]` 即可。
