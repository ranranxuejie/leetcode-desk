## 一句话思路
把边和查询都按长度升序排，用双指针只把 `< limit` 的边并进并查集，再查 p、q 是否同根。

## 怎么做
1. 给 `edgeList` 按 `dis` 升序排，给 `queries` 按 `limit` 升序排，但保留原下标 `i`。
2. 指针 `k` 从 0 开始；对每个查询，把 `edgeList[k][2] < limit` 的边逐条 `union(u, v)` 后 `k += 1`。
3. 此时并查集里恰好是所有长度严格小于 `limit` 的边，`find(p) == find(q)` 即答案。
4. 结果写回 `answer[i]`，最后按原顺序返回。

以示例 1 为例：边排序后为 `[0,1,2],[1,2,4],[2,0,8],[1,0,16]`。查询 `[0,1,2]` 的 `limit=2`，`edgeList[0][2]=2` 不满足 `< 2`，一条边都不并，`find(0) != find(1)`，得 `False`；查询 `[0,2,5]` 时并入了前两条边，`0-1-2` 连通，得 `True`。

```python
edges = sorted(edgeList, key=lambda e: e[2])
order = sorted(range(len(queries)), key=lambda i: queries[i][2])
ans = [False] * len(queries)
k = 0
for i in order:
    p, q, lim = queries[i]
    while k < len(edges) and edges[k][2] < lim:
        union(edges[k][0], edges[k][1])
        k += 1
    ans[i] = find(p) == find(q)
```

## 复杂度
时间：排序 `O(E log E + Q log Q)`，双指针加并查集近似 `O((E+Q) α(n))`。
空间：并查集 `parent`、`rank` 共 `O(n)`，排序下标数组 `O(Q)`。

## 易错点
- 边权恰好等于 `limit` 时：若写成 `edges[k][2] <= lim`，示例 1 第一个查询会把长度 2 的边并进去，`0` 与 `1` 连通，错答 `True`；题目要求严格小于，必须用 `<`。
- 查询乱序处理却按排序后顺序填 `answer`：示例 2 中 `limit=14` 的查询排在 `limit=13` 之后，若直接 `answer.append(...)`，输出变成 `[False, True]`；必须用 `order` 记原下标写回 `ans[i]`。

## 如果面试官追问
问：若要求输出具体路径而非布尔值？
答：并查集只给连通性，需改在排序后的图上对每个查询做 BFS/DFS 限边权搜索，或建 Kruskal 重构树后倍增求路径最大边。
