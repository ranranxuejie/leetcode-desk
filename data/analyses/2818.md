## 一句话思路
每个下标 i 能被选中 `left[i]*right[i]` 次（以 i 为质数分数严格最大/左侧相等取左的区间数），按 nums 值从大到小贪心取次数，快速幂累乘。

## 怎么做
1. 线性筛出 1..10^5 的质数，对每个 nums[i] 算不同质因子个数 `score[i]`。
2. 单调栈求 `left[i]`：左边第一个 `score >= score[i]` 的位置；`right[i]`：右边第一个 `score > score[i]` 的位置。这样相等时归左边，符合「下标最小」。
3. `cnt[i] = (i-left[i])*(right[i]-i)`，把 `(nums[i], cnt[i])` 按 nums 降序。
4. 依次取 `t = min(k, cnt)`，`ans = ans * pow(nums[i], t, MOD) % MOD`，`k -= t`，k 为 0 停。

以示例 1 `nums=[8,3,9,3,8]` 为例：score 全为 1（8=2^3, 3, 9=3^2, 3, 8）。对 i=2（值 9），left 因 `score>=1` 一路到 -1，`left[2]=-1`；right 因 `score>1` 不存在，`right[2]=5`；`cnt[2]=3*3=9`。i=0 值 8：`left=-1`，右边第一个 `score>1` 也没有，但相等归左，`right[0]=5`，`cnt[0]=1*5=5`。降序先取 9 两次（k=2），得 81。

```python
MOD = 10**9 + 7
# score 已算好，left/right 已用单调栈求出
items = sorted(((nums[i], (i-left[i])*(right[i]-i)) for i in range(n)), reverse=True)
ans = 1
for v, c in items:
    if k == 0: break
    t = min(k, c)
    ans = ans * pow(v, t, MOD) % MOD
    k -= t
return ans
```

## 复杂度
时间 O(n log n + M)：排序 O(n log n)，筛法 O(M)，M=10^5。
空间 O(n + M)：left/right/cnt 三个数组加质数表。

## 易错点
- 相等 score 时若两边都用 `>=` 或都用 `>`，`cnt` 会重复计数。示例 1 中 score 全相等，若右侧也用 `>=`，`right[0]` 变成 1，`cnt[0]=1`，8 只能取 1 次，k=2 时凑不出 81。正确：左 `>=`、右 `>`。
- `k` 可达 10^9 而 `cnt` 之和是 n(n+1)/2，直接循环 `k` 次会超时。示例 1 里 `cnt[2]=9` 一次就吃掉 2 次操作，必须整块 `pow` 而不是逐次乘。

## 如果面试官追问
若要求输出每次选中的下标序列？答：按同样降序展开 `cnt[i]` 个 i，前 k 个即答案，但需保证同值内下标递增以匹配「最小下标」规则。
