## 一句话思路
从右下角 S 反向 DP 到左上角 E，每个格子同时记录「到 E 的最大得分」和「取到该得分的路径数」。

## 怎么做
1. 把 `board` 转成二维，`dp[i][j] = (score, ways)`，`dp[0][0] = (0, 1)`（E 本身不加分），其余初始 `(-1, 0)` 表示不可达。
2. 按行优先从 `(0,0)` 向右下推：每个格子只从 `(i-1,j)`、`(i,j-1)`、`(i-1,j-1)` 三个前驱转移，取三者中 `score` 最大者，`ways` 为所有达到该最大值的方案数之和。
3. 若当前格是 `'X'` 直接跳过；若是数字字符，把 `int(board[i][j])` 加到 `score` 上。
4. 答案取 `dp[n-1][n-1]`，`ways` 对 `10**9 + 7` 取模；若 `score < 0` 返回 `[0, 0]`。

以示例 2 `["E12","1X1","21S"]` 为例，推到 `(2,2)` 时三个前驱是 `(1,2)`、`(2,1)`、`(1,1)`：`(1,1)` 是 `'X'` 不可达，`(1,2)` 的 score 为 1+1=2，`(2,1)` 的 score 为 2+1=3，两者加上 S 的 0 后分别是 2 和 3，最大值 4 由两条路径共同达到，故 `ways = 2`，输出 `[4, 2]`。

```python
MOD = 10**9 + 7
n = len(board)
dp = [[(-1, 0)] * n for _ in range(n)]
dp[0][0] = (0, 1)
for i in range(n):
    for j in range(n):
        if (i, j) == (0, 0) or board[i][j] == 'X':
            continue
        best, cnt = -1, 0
        for pi, pj in ((i-1, j), (i, j-1), (i-1, j-1)):
            if pi >= 0 and pj >= 0 and dp[pi][pj][0] > best:
                best, cnt = dp[pi][pj][0], dp[pi][pj][1]
            elif pi >= 0 and pj >= 0 and dp[pi][pj][0] == best and best >= 0:
                cnt = (cnt + dp[pi][pj][1]) % MOD
        if best >= 0:
            add = 0 if board[i][j] == 'E' else int(board[i][j])
            dp[i][j] = (best + add, cnt)
```

## 复杂度
时间 O(n²)：每个格子常数次前驱比较，n 为边长。
空间 O(n²)：`dp` 二维表存 `(score, ways)`，可滚动到 O(n)。

## 易错点
- 输入 `["E11","XXX","11S"]` → 若把 `'X'` 当成 score 0 参与比较，会把不可达格误判为可达并累加 `ways` → 必须显式跳过 `'X'`，且用 `-1` 而非 `0` 表示不可达，否则 `(0,0)` 的 score 0 会和「不可达」混淆。
- 输入 `["E23","2X2","12S"]` → 若在 `best` 更新时先加 `add` 再比较，或对 `ways` 只在严格大于时重置、等于时忘记累加，会漏掉并列最优路径 → 先比较前驱的原始 score 选出 `best`，再统一加当前格数字，`==` 分支必须 `cnt = (cnt + ...) % MOD`。

## 如果面试官追问
问：能否只开 O(n) 空间？答：可以，按行滚动，`dp[j]` 只依赖上一行同列、本行前一列、上一行前一列，用两个一维数组交替即可。
