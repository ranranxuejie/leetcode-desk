## 一句话思路
按斜率分组枚举所有点对，用「同斜率线段数组合」减去共线重复，得到至少一对平行边的凸四边形数。

## 怎么做
1. 枚举所有点对 `(i,j)`，把方向向量约分成最简形式 `(dx,dy)`（`dx>0`，或 `dx==0` 时 `dy>0`），作为斜率键。
2. 对每个斜率键，记录该斜率下所有线段；同时记录每条线段所在直线的截距键 `(dx,dy,c)`，用于后面去重。
3. 对每个斜率组，若组内有 `k` 条线段，则 `C(k,2)` 就是「选两条平行线段」的方案数，对应一个四边形（可能退化）。
4. 减去共线情形：同一斜率下，若某条直线上有 `m` 个点，则它贡献 `C(m,2)` 条线段，这些线段两两组合会形成退化四边形（四点共线或三点共线），需从总数中扣除。

以示例 2 `points=[[0,0],[1,0],[0,1],[2,1]]` 为例：斜率 `(1,0)` 组有线段 `(0,0)-(1,0)` 和 `(0,1)-(2,1)` 两条，`C(2,2)=1`；斜率 `(1,1)` 组只有 `(0,0)-(0,1)` 一条，贡献 0；斜率 `(1,-1)` 组有 `(1,0)-(0,1)` 一条，贡献 0。总数为 1，与答案一致。

```python
from collections import defaultdict
from math import gcd

def count(points):
    groups = defaultdict(list)          # 斜率 -> 线段列表
    for i in range(len(points)):
        for j in range(i + 1, len(points)):
            dx = points[j][0] - points[i][0]
            dy = points[j][1] - points[i][1]
            g = gcd(abs(dx), abs(dy))
            dx //= g; dy //= g
            if dx < 0 or (dx == 0 and dy < 0):
                dx, dy = -dx, -dy
            groups[(dx, dy)].append((i, j))
    ans = 0
    for segs in groups.values():
        k = len(segs)
        ans += k * (k - 1) // 2
    return ans
```

注意上面只是骨架，还需按直线截距扣除共线退化：对每个斜率组，用 `defaultdict(set)` 把点按截距 `c = dx*y - dy*x` 分组，若某截距下有 `m` 个点，则扣 `m*(m-1)//2` 条线段对应的组合数。

## 复杂度
时间：`O(n^2 log C)`，`n` 为点数，`log C` 来自 gcd 约分，`n^2` 来自点对枚举。
空间：`O(n^2)`，存所有点对的斜率键与截距键。

## 易错点
- 输入含共线三点如 `[[0,0],[1,1],[2,2],[3,0]]` → 若只按斜率累加 `C(k,2)`，会把三点共线产生的退化四边形算进去 → 必须按截距分组，扣除同一直线上 `m` 个点贡献的 `C(m,2)` 条线段组合。
- 方向向量未约分或符号不统一，如 `(2,4)` 与 `(1,2)`、`(-1,-2)` 被当成不同斜率 → 平行边漏算 → 用 `gcd` 约分并强制 `dx>0`（`dx==0` 时 `dy>0`）。

## 如果面试官追问
若要求输出所有梯形方案而非计数，怎么做？答：在每个斜率组内枚举两条线段，再用截距键过滤共线，直接收集四元组，复杂度升到 `O(n^4)` 量级。
