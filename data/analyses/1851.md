## 一句话思路
按左端点排序区间、按值排序查询，用最小堆维护右端点 ≥ 当前查询的区间长度，堆顶即答案。

## 怎么做
1. 把 `intervals` 按 `left` 升序排序，把 `queries` 转成 `(值, 原下标)` 后按值升序排序。
2. 指针 `i` 扫 `intervals`，对每个查询 `q`，把所有 `left <= q` 的区间压入堆，堆元素为 `(长度, right)`。
3. 弹出堆顶中 `right < q` 的区间（已不覆盖 `q`），此时堆顶长度就是该查询答案，写回 `ans[原下标]`。
4. 堆空则填 `-1`。

以示例 1 为例：排序后 `intervals = [[1,4],[2,4],[3,6],[4,4]]`，查询排序为 `(2,0),(3,1),(4,2),(5,3)`。处理 `q=2` 时压入 `[1,4]`（长度 4）和 `[2,4]`（长度 3），堆顶为 `(3,4)`，`right=4 >= 2`，答案 3。处理 `q=5` 时压入 `[3,6]`（长度 4）和 `[4,4]`（长度 1），弹出 `right<5` 的 `(1,4)`，堆顶变 `(4,6)`，答案 4。

```python
intervals.sort()
order = sorted(range(len(queries)), key=lambda k: queries[k])
ans = [-1] * len(queries)
heap, i = [], 0
for k in order:
    q = queries[k]
    while i < len(intervals) and intervals[i][0] <= q:
        l, r = intervals[i]
        heapq.heappush(heap, (r - l + 1, r))
        i += 1
    while heap and heap[0][1] < q:
        heapq.heappop(heap)
    if heap:
        ans[k] = heap[0][0]
```

## 复杂度
时间：排序 `intervals` 与 `queries` 各 O(n log n)、O(m log m)，每个区间进出堆一次 O(n log n)。
空间：堆最多存 n 个区间，`order` 与 `ans` 各 O(m)。

## 易错点
- 查询值相同但原下标不同：若直接对 `queries` 排序后按下标写回，重复值会错位。示例 2 中 `queries=[2,19,5,22]` 排序后位置全变，必须用 `(值, 原下标)` 或 `order` 数组回填，否则 `ans` 顺序错乱。
- 只弹出 `right < q` 而非 `right <= q`：区间是闭区间，`q=4` 时 `[4,4]` 的 `right=4` 仍覆盖，若写成 `<=` 会把它误删，示例 1 的 `q=4` 会错答 3 而非 1。

## 如果面试官追问
问：若要求返回最小区间的下标而非长度？答：堆元素改为 `(长度, right, 原下标)`，排序前先给每个区间记下原始索引即可。
