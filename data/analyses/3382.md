## 一句话思路
按 x 分组、组内按 y 排序，用树状数组维护「相邻 y 之间是否已被占位」，从右往左扫左边界，找最近的可配对右边界。

## 怎么做
1. 把点按 x 分组，每组内 y 升序；对 y 做离散化，得到全局排名 `rank`。
2. 从最大的 x 组往左扫，维护树状数组 `bit`：`bit` 上位置 `r` 记录「y 排名 r 与 r+1 之间这段是否已被某条竖边占用」。
3. 对当前组（作为左边界），枚举组内相邻的两点 `(x, y1)`、`(x, y2)`，查询 `bit` 中 `[rank(y1), rank(y2)-1]` 是否全空；全空说明存在一条右竖边同时覆盖这两点，面积 `(xr - x) * (y2 - y1)`。
4. 查询完再把当前组所有 y 的相邻段插入 `bit`，作为后续更左组的候选右边界。

以示例 3 为例：x=3 组 y={1,2,3}，插入段 [1,2]、[2,3]；扫到 x=1 组 y={1,2,3}，查 [1,2] 命中，得面积 `(3-1)*(2-1)=2`。

```python
# 组内相邻 y 段：用 bit 记录「该段是否已被占用」
def query(l, r):          # 区间 [l, r] 是否全空
    return prefix(r) - prefix(l - 1) == 0
def insert(l, r):
    add(l, 1)             # 段 [l, r] 用左端点 l 标记
# 从右往左扫 x 组
for x in sorted(groups, reverse=True):
    ys = groups[x]
    for i in range(len(ys) - 1):
        if query(rank[ys[i]], rank[ys[i+1]] - 1):
            ans = max(ans, (xr - x) * (ys[i+1] - ys[i]))
    for i in range(len(ys) - 1):
        insert(rank[ys[i]], rank[ys[i+1]] - 1)
```

## 复杂度
时间：排序 O(n log n)，每个相邻 y 段各查询、插入一次，树状数组 O(log n)，共 O(n log n)。
空间：`groups` 存 n 个点，`bit` 与 `rank` 各 O(n)。

## 易错点
- 示例 2 的 `[2,2]` 落在矩形内部：若只检查四条边上的点、不检查内部，会错判为面积 4；正确做法是「段被占用」即代表有更右的竖边穿过，内部点必然使某段非空，从而被排除。
- 同一 x 组内多点（示例 3 的 x=1 有 y=1,2,3）：若只取组内最小最大 y 配对，会漏掉 `(1,2)-(3,2)` 这类窄矩形；必须枚举组内所有相邻 y 对。

## 如果面试官追问
问：若要求输出具体矩形而非面积？答：查询命中时记录当前 `(x, ys[i], ys[i+1])` 和产生该空段的右竖边 x，回溯即得四顶点。
