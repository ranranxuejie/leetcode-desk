## 一句话思路
维护一个带哑结点 `dummy` 的有序子链表，逐个摘下原链表节点，从 `dummy` 往后扫到第一个比它大的位置插入。

## 怎么做
1. 建 `dummy = ListNode(0)`，`dummy.next = head`，`cur = head.next`，并把 `head.next = None` 断开——有序部分初始只有第一个节点。
2. 每轮先存 `nxt = cur.next`，再从 `pre = dummy` 开始扫，条件是 `pre.next and pre.next.val <= cur.val`。
3. 扫停后把 `cur` 插到 `pre` 和 `pre.next` 之间，然后 `cur = nxt` 继续下一轮。
4. 返回 `dummy.next`。

以 `[4,2,1,3]` 为例，有序部分 `[4]`，`cur=2`：`pre=dummy`，`dummy.next.val=4 > 2` 立即停，插入后 `dummy.next` 变 `2`，链为 `2->4`。接着 `cur=1` 插到最前，`cur=3` 扫过 `2`、停在 `4` 前，得 `1->2->3->4`。

```python
dummy = ListNode(0)
dummy.next = head
cur = head.next
head.next = None
while cur:
    nxt = cur.next
    pre = dummy
    while pre.next and pre.next.val <= cur.val:
        pre = pre.next
    cur.next = pre.next
    pre.next = cur
    cur = nxt
return dummy.next
```

关键在 `pre.next.val <= cur.val` 用 `<=` 而非 `<`：相等时继续往后走，保证相等元素保持原相对顺序（稳定），本题不要求但不会错。

## 复杂度
时间 O(n²)：每个 `cur` 最多扫过整个有序部分，最坏逆序时约 n²/2 次比较。
空间 O(1)：只开了 `dummy` 一个额外节点和 `cur/nxt/pre` 三个指针。

## 易错点
- 输入 `[1]` 或空链表：直接写 `cur = head.next` 会在 `head` 为 `None` 时抛 `AttributeError`，或漏掉单节点情况。正确做法是先判 `if not head or not head.next: return head`，再进主循环。
- 输入 `[4,2,1,3]` 这类需要插到最前的：若从 `cur` 的前驱开始扫而不是从 `dummy` 开始，`2` 和 `1` 找不到「比它小的前驱」，会错插到 `4` 后面。正确做法是每轮 `pre` 都重置为 `dummy`，靠哑结点兜住「插到头」的情况。

## 如果面试官追问
问：n 到 5×10⁴ 还这么写吗？答：链表插入排序仍是 O(n²)，可先转数组 `sorted()` 再重建链表，O(n log n)，代价是 O(n) 空间。
