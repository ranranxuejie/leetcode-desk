## 一句话思路
用 pandas 的列向量化赋值 `employees["bonus"] = employees["salary"] * 2`，逐行对齐天然成立。

## 怎么做
1. 直接对整列做乘法，pandas 会把标量 2 广播到每一行。
2. 把结果赋给新列名 `"bonus"`，原表就地多一列。
3. 返回同一个 DataFrame（题目要求返回结果表，不要求保留原对象）。

拿官方示例第一行验证：`salary = 4548`，`4548 * 2 = 9096`，写入 `bonus` 列首行；`Finn` 行 `74576 * 2 = 149152`，与输出一致。

```python
import pandas as pd

def createBonusColumn(employees: pd.DataFrame) -> pd.DataFrame:
    employees["bonus"] = employees["salary"] * 2
    return employees
```

关键点：`employees["salary"]` 是 Series，`* 2` 是逐元素运算，索引自动对齐，不需要 `apply` 或循环。

## 复杂度
时间：O(n)，n 为行数，一次整列乘法遍历所有 salary。
空间：O(n)，新增 bonus 列占 n 个整数位，无其他额外结构。

## 易错点
- 写成 `employees["bonus"] = employees["salary"].apply(lambda x: x * 2)` → 结果数值正确但慢一个量级，且在大表上触发逐行 Python 调用；正确做法是直接整列 `* 2` 走向量化。
- 用 `employees.bonus = ...` 属性赋值 → 在列名与 DataFrame 内置属性冲突或列不存在时行为不可靠；正确做法是始终用 `employees["bonus"]` 方括号写法。

## 如果面试官追问
问：salary 含缺失值怎么办？答：`NaN * 2` 仍是 `NaN`，bonus 列对应位置保持缺失，无需额外处理。
