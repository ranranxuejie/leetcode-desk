## 一句话思路
用二分查找定位「配对断裂点」：单一元素左侧所有配对都从偶数下标开始，右侧从奇数下标开始。

## 怎么做
1. 取 `lo = 0`、`hi = len(nums) - 1`，在闭区间上二分。
2. 每轮取 `mid = (lo + hi) // 2`，把 `mid` 强制成偶数（`mid -= 1` 若为奇数），保证比较的是同一对的两个位置。
3. 若 `nums[mid] == nums[mid + 1]`，说明断裂点在 `mid` 右侧，令 `lo = mid + 2`；否则令 `hi = mid`。
4. 循环到 `lo == hi` 时返回 `nums[lo]`。

以 `nums = [1,1,2,3,3,4,4,8,8]` 为例：`lo=0, hi=8`，`mid=4` 为偶数，`nums[4]=3`、`nums[5]=4` 不等，说明断裂点在 `mid` 左侧或就是 `mid`，令 `hi=4`；下一轮 `mid=2`，`nums[2]=2`、`nums[3]=3` 不等，`hi=2`；再一轮 `mid=1` 为奇数，调成 `0`，`nums[0]=nums[1]=1` 相等，`lo=2`，此时 `lo==hi==2`，返回 `nums[2]=2`。

```python
lo, hi = 0, len(nums) - 1
while lo < hi:
    mid = (lo + hi) // 2
    if mid % 2 == 1:
        mid -= 1
    if nums[mid] == nums[mid + 1]:
        lo = mid + 2
    else:
        hi = mid
return nums[lo]
```

关键点：`mid` 调成偶数后，`nums[mid]` 与 `nums[mid + 1]` 恰好是「本应成对」的两个位置；相等就说明这对没被破坏，断裂点必在右侧。

## 复杂度
时间：二分每轮砍半，共 `O(log n)` 轮，每轮 `O(1)` 比较。
空间：只开 `lo`、`hi`、`mid` 三个整数，`O(1)`。

## 易错点
- 输入 `nums = [3,3,7,7,10,11,11]`（长度 7，单一元素在下标 4）→ 若忘记把 `mid` 调成偶数，`mid=3` 时比较 `nums[3]=7` 与 `nums[4]=10` 不等会误判断裂点在左，把 `hi` 压到 3，漏掉答案 → 必须先 `mid -= 1` 再比较。
- 输入 `nums = [1]`（长度 1）→ 若写成 `while lo <= hi` 并在循环内访问 `nums[mid + 1]`，`mid=0` 时 `nums[1]` 越界 → 用 `while lo < hi`，单元素直接跳过循环返回 `nums[0]`。

## 如果面试官追问
问：数组无序但只有一个数出现一次，其余成对，怎么办？
答：丢掉二分，用异或一遍扫，`O(n)` 时间 `O(1)` 空间，`reduce(xor, nums)` 即可。
