## 一句话思路
把毯子左端对齐到某个白砖起点，用滑动窗口 + 前缀和求窗口内白砖总数，取最大。

## 怎么做
1. 按 `l` 排序 `tiles`，并预处理每段的长度 `len_i = r_i - l_i + 1` 及其前缀和 `pre`。
2. 枚举毯子左端 `tiles[i][0]`（最优解一定能让毯子左端贴住某段白砖起点，否则左移不亏）。
3. 毯子右端为 `tiles[i][0] + carpetLen - 1`，二分找到最后一个满足 `tiles[j][0] <= 右端` 的段 `j`。
4. 答案 = `pre[j] - pre[i]`（完整覆盖的段）减去 `max(0, tiles[j][1] - 右端)`（最后一段被截掉的部分）。

以示例 1 为例，`i=1`（段 `[10,11]`），右端 `= 10+10-1 = 19`，二分得 `j=2`（段 `[12,18]`，因 `20 > 19`）。`pre[3]-pre[1] = (5+2+7) - 5 = 9`，末段 `18 <= 19` 无需截断，得 9。

```python
tiles.sort()
pre = [0]
for l, r in tiles:
    pre.append(pre[-1] + r - l + 1)
ans = 0
for i, (l, _) in enumerate(tiles):
    end = l + carpetLen - 1
    j = bisect_right([t[0] for t in tiles], end) - 1
    cover = pre[j + 1] - pre[i]
    if tiles[j][1] > end:
        cover -= tiles[j][1] - end
    ans = max(ans, cover)
```

## 复杂度
时间：排序 `O(n log n)`，每个起点二分 `O(n log n)`，共 `O(n log n)`。
空间：`pre` 数组和起点列表各 `O(n)`，无其他额外结构。

## 易错点
- 毯子右端算成 `l + carpetLen` → 多算一格，示例 1 中 `i=1` 会得 10 而非 9 → 正确是 `l + carpetLen - 1`。
- 末段截断漏判：当 `tiles[j][1] > end` 时必须减去 `tiles[j][1] - end`，否则把整段 `[12,18]` 全算进去；示例 1 若 `carpetLen=8`，`end=17`，需减 `18-17=1`。

## 如果面试官追问
若要求输出毯子放置位置而非数量？答：在更新 `ans` 时同步记录当前 `i` 对应的 `l`，即毯子左端坐标。
