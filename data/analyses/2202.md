## 一句话思路
分 k 与 n 的大小关系讨论：k 小时答案来自前 k+1 个元素或 nums[k-1]，k 大时直接取整个数组最大值。

## 怎么做
1. 若 `k == 0`，一次操作都不做，堆顶就是 `nums[0]`，直接返回。
2. 若 `k > len(nums)`，删除次数足够把整个堆清空，被删元素全部可回填，答案就是 `max(nums)`。
3. 若 `k == len(nums)`，恰好删完所有元素，堆必空，返回 `-1`。
4. 否则 `1 <= k < n`：答案取 `max(nums[:k+1])` 与 `nums[k-1]` 的较大者——前者是「删 k 次前先把最大值留在手里再回填」，后者是「删 k-1 次后堆顶正好是 nums[k-1]」。

以 `nums = [5,2,2,4,0,6], k = 4` 为例：`n = 6`，`1 <= 4 < 6` 走第 4 步。`nums[:5] = [5,2,2,4,0]`，`max` 为 `5`；`nums[k-1] = nums[3] = 4`；两者取大得 `5`，与官方输出一致。注意 `nums[4] = 0` 和 `nums[5] = 6` 都不在候选内，因为 4 次操作最多只能把前 5 个元素之一搬到堆顶。

```python
n = len(nums)
if k == 0:
    return nums[0]
if k > n:
    return max(nums)
if k == n:
    return -1
return max(max(nums[:k + 1]), nums[k - 1])
```

第 4 步的两个候选缺一不可：`k = 1, nums = [3, 9]` 时 `max(nums[:2]) = 9`，但 1 次操作只能删掉 3 或把 3 放回，堆顶最大是 3，靠 `nums[k-1] = nums[0] = 3` 兜住。

## 复杂度
时间 O(min(k, n))，切片 `nums[:k+1]` 的长度由 k 和 n 共同决定。
空间 O(min(k, n))，切片额外开了一个列表；可改成循环取 max 降到 O(1)。

## 易错点
- `k == len(nums)` 时误用 `k > n` 分支返回 `max(nums)`：如 `nums = [2], k = 1`，会错答 2，实际删完堆空，正确返回 `-1`。
- 只取 `max(nums[:k+1])` 漏掉 `nums[k-1]`：如 `nums = [3,9], k = 1`，会错答 9，但 1 次操作后堆顶只能是 3，正确做法是两者取大。

## 如果面试官追问
要求输出具体操作序列怎么办？答：先删 k-1 次，若目标值在已删集合里就回填它，否则第 k 次删掉 `nums[k-1]` 后回填目标值。
