## 一句话思路
按 target 逐位推进，用「word1 用到下标 i、word2 用到下标 j」的二维 DP 加前缀和优化，因为每个字符只能接在更小下标之后。

## 怎么做
1. 定义 `dp[i][j]` 为 target 前 `i+j` 位已匹配、word1 恰好用到下标 `i-1`、word2 恰好用到下标 `j-1` 的方案数（`i`、`j` 是已用字符数，不是下标）。
2. 转移时，target 第 `i+j` 位若取 word1 的 `word1[i]`，则前驱是所有 `dp[i][j']`（`j' < j`），用前缀和 `pre[i][j] = sum(dp[i][0..j])` 一次拿到。
3. 同理取 word2 时用 `pre[j][i]` 方向的前缀和，避免 O(n²m²)。
4. 最后减去「全来自 word1」和「全来自 word2」两种退化方案，因为题目要求两边至少各选一个。

以示例 1 `word1="abc", word2="bac", target="abc"` 为例：`dp[1][0]`（用 word1[0]='a'）为 1，`dp[0][1]`（用 word2[1]='a'）为 1；到 target 第 2 位 'b' 时，`dp[2][0]` 由 `dp[1][0]` 接 word1[1]='b' 得 1，`dp[1][1]` 由 `dp[1][0]` 接 word2[0]='b' 得 1，前缀和把这两条路径都累进后续状态，最终 5 种方案全部被计入。

```python
MOD = 10**9 + 7
n, m, L = len(word1), len(word2), len(target)
dp = [[0] * (m + 1) for _ in range(n + 1)]
dp[0][0] = 1
for i in range(n + 1):
    for j in range(m + 1):
        if i + j == 0:
            continue
        c = target[i + j - 1]
        if i > 0 and word1[i - 1] == c:
            dp[i][j] = (dp[i][j] + dp[i - 1][j]) % MOD
        if j > 0 and word2[j - 1] == c:
            dp[i][j] = (dp[i][j] + dp[i][j - 1]) % MOD
```

## 复杂度
时间 O(n·m)，n、m 为 word1、word2 长度，前缀和把内层枚举压成 O(1)。
空间 O(n·m)，开了二维 dp 表，可滚动到 O(m)。

## 易错点
- 输入 `word1="xy", word2="xy", target="xyxy"` → 若忘记「两边至少各选一个」的约束，会把「全用 word1」和「全用 word2」两条路径也算进去，得到 4 而非 2 → 正确做法是最后单独减去 `dp[n][0]` 和 `dp[0][m]` 两条退化路径。
- 输入 `word1="cd", word2="cd", target="ccd"` → 若把 `dp[i][j]` 的下标当成「word1 当前指向 i」而非「已用 i 个字符」，转移时 `word1[i-1]` 会越界或错位，把两个 'c' 都算到同一个字符串上 → 正确做法是明确 `i`、`j` 是已用字符数，取字符用 `word1[i-1]`。

## 如果面试官追问
问：若要求输出所有具体方案而非计数？答：把 dp 换成存路径列表，回溯时按前缀和区间枚举前驱，复杂度升到方案数级别。
