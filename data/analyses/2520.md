## 一句话思路
逐位取模统计：用 `num % 10` 取末位、`num //= 10` 推进，对每个非零位判断 `num % d == 0`。

## 怎么做
1. 先把原数存进 `x = num`，因为后面要反复对 `num` 做整除，原值必须留一份。
2. 循环条件写 `while num:`，每轮 `d = num % 10` 取当前末位。
3. 判断 `x % d == 0`，成立则 `ans += 1`。
4. 收尾 `num //= 10`，直到 `num` 变成 0。

以 `num = 121` 为例：`x = 121`。第一轮 `d = 1`，`121 % 1 == 0`，`ans = 1`，`num` 变 12；第二轮 `d = 2`，`121 % 2 == 1`，跳过，`num` 变 1；第三轮 `d = 1`，`121 % 1 == 0`，`ans = 2`，`num` 变 0 退出。两个 1 各计一次，正是题目要的「按出现次数算」。

```python
x = num
ans = 0
while num:
    d = num % 10
    if x % d == 0:
        ans += 1
    num //= 10
return ans
```

关键点：取模的对象始终是 `x`（原数），不是被不断缩小的 `num`。若误写成 `num % d`，`121` 第二轮会变成 `12 % 2 == 0` 而多计一次，答案错成 3。

## 复杂度
时间：O(log num)，循环次数等于十进制位数，`num ≤ 10^9` 最多 10 轮。
空间：O(1)，只开了 `x`、`ans`、`d` 三个变量。

## 易错点
- 输入 `num = 121` → 若用 `num % d` 而不是 `x % d` 判断，第二轮 `12 % 2 == 0` 会误判为整除，输出 3 而非 2 → 必须先把原值存进 `x`，全程用 `x` 取模。
- 输入含 0 的位（如 `num = 10`）→ 若直接 `x % d` 会触发 `ZeroDivisionError` → 本题提示保证「数位中不含 0」，但若换约束去掉该保证，需在取模前加 `if d != 0` 守卫，否则程序直接崩。

## 如果面试官追问
问：若允许数位含 0，怎么改？
答：取模前加 `if d and x % d == 0`，0 位直接跳过不计入答案。
