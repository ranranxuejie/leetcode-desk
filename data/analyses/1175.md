## 一句话思路
质数只能放质数索引、非质数只能放非质数索引，两类各自全排列后相乘，即 `p! * (n-p)!`，其中 `p` 是 1..n 中质数个数。

## 怎么做
1. 先数出 1..n 里质数的个数 `p`，用试除到 `isqrt(i)` 即可，n ≤ 100 完全够。
2. 质数索引的个数恰好也是 `p`（索引 1..n 与数值 1..n 同范围），所以质数有 `p!` 种摆法。
3. 剩下 `n - p` 个非质数放进 `n - p` 个非质数索引，有 `(n-p)!` 种摆法。
4. 两者独立相乘，每步对 `10**9 + 7` 取模。

以 `n = 5` 为例：1..5 中质数是 2、3、5，得 `p = 3`；质数索引是 2、3、5 共 3 个，摆法 `3! = 6`；非质数 1、4 放进索引 1、4，摆法 `2! = 2`；答案 `6 * 2 = 12`，与示例一致。

```python
from math import isqrt

MOD = 10**9 + 7

def count_primes(n):
    cnt = 0
    for x in range(2, n + 1):
        if all(x % d for d in range(2, isqrt(x) + 1)):
            cnt += 1
    return cnt

p = count_primes(n)
ans = 1
for k in range(2, p + 1):
    ans = ans * k % MOD
for k in range(2, n - p + 1):
    ans = ans * k % MOD
```

关键中间值：`n = 5` 时 `p = 3`，第一个循环乘到 `6`，第二个循环乘到 `12`。

## 复杂度
时间：`O(n * sqrt(n))`，质数判定贡献 `sqrt(n)`，外层扫 `n` 个数。
空间：`O(1)`，只用了 `cnt`、`ans` 几个标量。

## 易错点
- `n = 1` 时 `p = 0`，两个阶乘循环都从 2 开始、一次不执行，答案应为 `1`（空排列算一种）。若把循环写成 `range(1, p+1)` 再乘 `0!` 之外的项，或误以为无解返回 `0`，就会错成 `0`。
- `n = 100` 时 `p = 25`，`25!` 和 `75!` 都远超 32 位，必须在每次乘法后 `% MOD`。若先算完两个阶乘再相乘取模，Python 虽不溢出但中间数巨大、且与「按 32 位截断」的题意不符，容易在别的语言里翻车。

## 如果面试官追问
问：n 放大到 `10**7` 怎么办？
答：质数个数改用线性筛 `O(n)` 预处理，阶乘边乘边取模，总时间 `O(n)`、空间 `O(n)`。
