## 一句话思路
把每个值 v 当作下标 v-1 打负号标记，最后仍为正的位置 i 对应缺失值 i+1。

## 怎么做
1. 遍历 nums，对每个值 v 取 `idx = abs(v) - 1`，把 `nums[idx]` 置为负数，表示 idx+1 出现过。
2. 用 `abs(v)` 而不是 v，是因为前面的标记可能已把当前元素改成负数。
3. 再遍历一遍，`nums[i] > 0` 的位置说明 i+1 从未被标记，收进结果。

以 `nums = [4,3,2,7,8,2,3,1]` 为例：处理到 v=4 时 `idx=3`，`nums[3]` 从 7 变 -7；处理到 v=7 时取 `abs(-7)-1=6`，`nums[6]` 从 3 变 -3。全部标记后数组为 `[-4,-3,-2,-7,8,2,-3,-1]`，下标 4、5 处仍是正数 8 和 2，输出 `[5,6]`。

```python
n = len(nums)
for v in nums:
    idx = abs(v) - 1
    if nums[idx] > 0:
        nums[idx] = -nums[idx]
res = []
for i in range(n):
    if nums[i] > 0:
        res.append(i + 1)
```

`if nums[idx] > 0` 这个判断不能省：示例里 2 和 3 各出现两次，第二次访问同一 idx 时若再取负会翻回正数，把出现过的数误判成缺失。

## 复杂度
时间 O(n)：两趟遍历，每趟 n 次。
空间 O(1)：只在原数组上打标记，返回的 res 不计入。

## 易错点
- 输入 `[1,1]` → 若不加 `nums[idx] > 0` 判断，v=1 两次都把 `nums[0]` 取负，-1 翻回 1，结果误报 `[1]` → 正确做法是只在 `nums[idx] > 0` 时才取负。
- 输入 `[4,3,2,7,8,2,3,1]` → 若用 `idx = v - 1` 而非 `abs(v) - 1`，读到已被标记的 -7 会算出 idx=-8，越界或错标 → 正确做法是每步都先 `abs(v)`。

## 如果面试官追问
追问：不允许修改原数组怎么办？
答：用 `set(nums)` 记出现过的值，再扫 1..n 找不在集合里的，空间 O(n) 换不改原数组。
