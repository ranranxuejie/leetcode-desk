## 一句话思路
把每个串排序后的结果当哈希键，异位词排序后必然相同，同键的串归到一组。

## 怎么做
1. 建一个 `dict`，键是排序后的字符串，值是原串列表。
2. 遍历 `strs`，对每个 `s` 算 `key = ''.join(sorted(s))`。
3. 用 `groups.setdefault(key, []).append(s)` 一次完成「取桶 + 塞入」。
4. 返回 `list(groups.values())`。

拿示例 1 走一遍：`"eat"` 排序得 `"aet"`，`"tea"` 排序也是 `"aet"`，`"ate"` 同样是 `"aet"`，三者落进同一个桶 `groups["aet"] = ["eat","tea","ate"]`；`"tan"` 和 `"nat"` 都排成 `"ant"`，进另一桶；`"bat"` 排成 `"abt"` 单独一桶。最终三个桶正好对应输出。

```python
groups = {}
for s in strs:
    key = ''.join(sorted(s))
    groups.setdefault(key, []).append(s)
return list(groups.values())
```

关键点：`sorted(s)` 返回字符列表，必须 `join` 回字符串才能当键；列表不可哈希，直接拿 `sorted(s)` 当键会抛 `TypeError`。

## 复杂度
时间 O(n·k log k)，n 是串个数，k 是串长，每个串排序花 k log k。
空间 O(n·k)，哈希表存下所有原串，键额外占 O(n·k)。

## 易错点
- 输入 `[""]` → 若用 `sorted(s)` 直接当键会因列表不可哈希报错，或误以为空串要跳过；正确做法是 `''.join(sorted(''))` 得 `""`，空串自成一桶返回 `[[""]]`。
- 输入含大量同长串如 `["abc","bca","cab"]` → 若用字符计数元组当键但写成 `tuple(sorted(s))` 与字符串键混用，会分裂成两类；正确做法是全题统一一种键形式，要么都用 `''.join(sorted(s))`，要么都用 26 长度计数元组。

## 如果面试官追问
问：串长到 10^5、字符集扩到全部 ASCII 怎么办？
答：排序键退化成 O(k log k)，改用 26（或 128）长度计数元组当键，降到 O(k)。
