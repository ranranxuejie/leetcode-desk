## 一句话思路
把每个未感染段独立计数，再用组合数把各段的传染顺序交错合并。

## 怎么做
1. 设 `m = len(sick)`，把队列切成 `m+1` 段：左端 `[0, sick[0])`、中间 `(sick[i], sick[i+1])`、右端 `(sick[-1], n-1]`。
2. 左端长度 `L = sick[0]`、右端长度 `R = n-1-sick[-1]`，这两段只有一侧有传染源，段内顺序被唯一确定，贡献因子恒为 1。
3. 中间段长度 `k = sick[i+1]-sick[i]-1`，两端都有源，段内顺序有 `2**(k-1)` 种（最后一个被传染的人必在中间，前面每个位置可选左或右）。
4. 所有段的总长度 `total = n - m`，按段长用组合数交错合并：`ans *= C(已放置数 + k, k)`。

以 `n=5, sick=[0,4]` 为例：中间段 `k = 4-0-1 = 3`，因子 `2**(3-1) = 4`；`total = 3`，只有一段，组合数 `C(3,3)=1`，答案 4。

```python
MOD = 10**9 + 7
total = n - len(sick)
ans, placed = 1, 0
for i in range(len(sick) - 1):
    k = sick[i+1] - sick[i] - 1
    if k:
        ans = ans * pow(2, k-1, MOD) % MOD
        placed += k
        ans = ans * comb(placed, k) % MOD   # comb 取模需自写或用阶乘表
```

## 复杂度
时间：O(n) 预处理阶乘与逆元，之后每段 O(1)，共 O(n)。
空间：O(n) 存阶乘表和逆元表，无其他额外结构。

## 易错点
- `sick = [1], n = 4`：若把左端 `[0]` 也乘 `2**(L-1)`，会得到 `2**-1` 或错误因子 2，答案错成 6。正确做法是左右两端因子恒为 1，只有中间段乘 `2**(k-1)`。
- `sick = [0,1,2], n = 5`：若对 `k=0` 的相邻对仍执行 `pow(2,-1)`，Python 会返回浮点或报错。正确做法是 `if k:` 跳过空段，且 `placed` 不增加。

## 如果面试官追问
要求输出所有感冒序列而非计数？答：把每段的 `2**(k-1)` 展开成枚举左右选择，再对段间做多重集排列回溯，规模指数级。
