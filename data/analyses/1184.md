## 一句话思路
顺时针走一段、逆时针走另一段，两段之和是整圈总长，取较小值即可。

## 怎么做
1. 先把 `start` 和 `destination` 排序，让 `lo = min(start, destination)`、`hi = max(...)`，这样顺时针段就是下标 `lo` 到 `hi-1` 的连续区间。
2. 累加 `distance[lo:hi]` 得到顺时针距离 `clockwise`。
3. 逆时针距离 = `sum(distance) - clockwise`，返回两者较小值。

以示例 3 为例：`distance = [1,2,3,4]`，`start=0`、`destination=3`，排序后 `lo=0, hi=3`，顺时针累加 `distance[0]+distance[1]+distance[2] = 1+2+3 = 6`，总长 `10`，逆时针 `10-6 = 4`，返回 `min(6,4) = 4`。

```python
total = sum(distance)
lo, hi = min(start, destination), max(start, destination)
clockwise = sum(distance[lo:hi])
return min(clockwise, total - clockwise)
```

关键点：`distance[i]` 是站 `i` 到站 `i+1` 的边，所以从 `lo` 走到 `hi` 恰好用掉下标 `lo..hi-1` 这 `hi-lo` 条边，切片右端 `hi` 不含正好对上。`start == destination` 时切片为空，`clockwise = 0`，返回 `0`，无需特判。

## 复杂度
时间：O(n)，`sum(distance)` 和切片各扫一遍，n 为站数。
空间：O(n)，切片 `distance[lo:hi]` 复制了一份；改成循环累加可降到 O(1)。

## 易错点
- 输入 `start=3, destination=0`（逆序）→ 若直接写 `sum(distance[start:destination])` 会得到空切片 `0`，错答成 0 → 必须先 `min/max` 排序再切片。
- 输入 `distance=[1,2,3,4], start=0, destination=3` → 若忘记用总长减、只算顺时针得 6，错答成 6 → 必须 `min(clockwise, total - clockwise)`，本题答案是 4。

## 如果面试官追问
问：如果要求返回具体走法（经过哪些站）？
答：顺时针段就是 `range(lo, hi)`，逆时针段是 `range(hi, n) + range(0, lo)`，比较两段和后输出对应序列即可。
