## 一句话思路
每个下标只记录「值变化的历史」，按 snap_id 二分找最后一次修改，避免每次 snap 复制整个数组。

## 怎么做
1. 初始化 `history = [[] for _ in range(length)]`，每个下标存 `(snap_id, val)` 列表，`snap_id = 0` 表示初始值 0。
2. `set(index, val)` 时把 `(当前snap_id, val)` 追加到 `history[index]`，同一 snap 内多次 set 只保留最后一次即可（追加也行，二分取最后一个 ≤ snap_id 的）。
3. `snap()` 返回当前 `snap_id` 后自增。
4. `get(index, snap_id)` 在 `history[index]` 上二分，找最后一个 `sid <= snap_id` 的条目，返回其 val；找不到返回 0。

用官方示例走一遍：`set(0,5)` 后 `history[0]=[(0,5)]`；`snap()` 返回 0，`snap_id` 变 1；`set(0,6)` 后 `history[0]=[(0,5),(1,6)]`；`get(0,0)` 二分找 `sid<=0`，命中 `(0,5)`，返回 5。

```python
def set(self, index, val):
    self.history[index].append((self.snap_id, val))

def snap(self):
    sid = self.snap_id
    self.snap_id += 1
    return sid

def get(self, index, snap_id):
    h = self.history[index]
    i = bisect_right(h, (snap_id, 10**18)) - 1
    return h[i][1] if i >= 0 else 0
```

关键：`bisect_right` 用 `(snap_id, 10**18)` 作哨兵，保证同 snap_id 的条目也被算进去。

## 复杂度
时间：set/snap 均摊 O(1)，get 为 O(log k)，k 是该下标的历史修改次数。
空间：O(length + 总 set 次数)，history 里每条修改占一个元组。

## 易错点
1. `get(index, snap_id)` 里若用 `bisect_left(h, (snap_id,))` 会漏掉同 snap 的条目 → 返回旧值。正确做法是用 `bisect_right` 配大哨兵 `(snap_id, 10**18)`，或手写二分找最后一个 `sid <= snap_id`。
2. 某下标从未被 set 过，`history[index]` 为空 → 直接 `h[i]` 会 IndexError。正确做法是 `i >= 0` 判断后返回 0，因为初始值就是 0。

## 如果面试官追问
问：若 snap 次数到 10^5 且要求 get 严格 O(1) 怎么办？
答：用「写时复制 + 版本号」或对每个下标预存全部 snap 的扁平数组，空间换时间。
