## 一句话思路
先以 0 为根算出正确猜测数，再用换根 DP 沿边 O(1) 修正，统计 ≥k 的根数。

## 怎么做
1. 把 guesses 存成集合 `g = {(u,v)}`，便于 O(1) 判断某条有向边是否被猜中。
2. 以 0 为根 DFS，对每条父子边 `(p,c)`，若 `(p,c) in g` 则计入 `cnt`，得到根为 0 时的正确数。
3. 换根：从 u 移到相邻子节点 v 时，只有边 `(u,v)` 的方向翻转，`cnt` 变化为 `-(u,v) in g + (v,u) in g`。
4. 再 DFS 一遍把修正值传下去，每个节点判断 `cnt >= k` 就累加答案。

以示例 1 为例，根为 0 时父子边是 `(0,1),(1,2),(1,3),(2,4)`，命中 `(0,1),(1,3),(2,4)`，`cnt=3`。换根到 1：边 `(0,1)` 翻成 `(1,0)`，`(1,0) in g` 为真、`(0,1) in g` 也为真，`cnt` 仍为 3。

```python
g = {(u, v) for u, v in guesses}
adj = [[] for _ in range(n)]
for a, b in edges:
    adj[a].append(b); adj[b].append(a)

def dfs(u, p):
    c = 0
    for v in adj[u]:
        if v != p:
            c += (u, v) in g
            c += dfs(v, u)
    return c

ans = 0
def reroot(u, p, cnt):
    nonlocal ans
    if cnt >= k: ans += 1
    for v in adj[u]:
        if v != p:
            reroot(v, u, cnt - ((u, v) in g) + ((v, u) in g))

reroot(0, -1, dfs(0, -1))
```

## 复杂度
时间 O(n + m)：建图与两次 DFS 各 O(n)，m 为 guesses 长度，集合查询 O(1)。
空间 O(n + m)：邻接表 O(n)、猜测集合 O(m)、递归栈 O(n)。

## 易错点
- 换根修正写成 `cnt + ((u,v) in g) - ((v,u) in g)` 符号反了 → 示例 1 从根 0 换到 1 会得 5 而非 3，答案偏大；正确是减去旧方向 `(u,v)`、加上新方向 `(v,u)`。
- 只对 `(u,v) in g` 判断而不查反向，或把 guesses 当无向边存 → 示例 2 中 `(1,0)` 与 `(0,1)` 会被混为一谈，根 0 的 `cnt` 从 1 错算成 2；必须按有向对存集合。

## 如果面试官追问
若 n 升到 10^6 递归会爆栈怎么办？答：把两次 DFS 改成显式栈迭代，先序记录父节点再逆序回传 cnt。
