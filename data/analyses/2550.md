## 一句话思路
总方案 2^n 减去不碰撞的 2 种（全顺时针、全逆时针），答案 = 2^n - 2。

## 怎么做
1. 每只猴子独立选顺/逆，总移动方式为 `2**n`。
2. 不碰撞当且仅当所有猴子同向：全顺时针或全逆时针，共 2 种。
3. 答案 = `(pow(2, n, MOD) - 2) % MOD`，用快速幂避免 n 到 1e9 时超时。

以 n = 3 为例：`pow(2, 3, MOD) = 8`，减 2 得 6，与示例一致。n = 4 时 `pow(2, 4, MOD) = 16`，减 2 得 14。

```python
MOD = 10**9 + 7

def monkeyMove(n):
    return (pow(2, n, MOD) - 2) % MOD
```

关键中间值：n = 3 时 `pow(2, 3, MOD)` 返回 8，`(8 - 2) % MOD = 6`。

## 复杂度
时间：O(log n)，快速幂按指数二进制位迭代。
空间：O(1)，只存底数、指数、模数和结果。

## 易错点
- n = 3 时若直接写 `2**n - 2` 得 6 没问题，但 n = 1e9 时 `2**n` 是十亿位大整数，内存和取模都爆；必须用 `pow(2, n, MOD)` 三参数形式，边乘边取模。
- 减法后忘记 `% MOD`：n 很大时 `pow(2, n, MOD)` 可能返回 0 或 1，`0 - 2 = -2`、`1 - 2 = -1` 是负数；Python 的 `%` 会修正为非负，但若写成 `pow(...) - 2` 直接返回就错了，必须套 `% MOD`。

## 如果面试官追问
问：若要求返回不碰撞的方案数而非碰撞数？答：直接返回 2（n ≥ 3 时全顺、全逆两种），与 n 无关。
