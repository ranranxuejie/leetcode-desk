## 一句话思路
n≤15，枚举每个非空点集当子树，用位掩码 DP 求该点集内最远点对距离，按距离计数。

## 怎么做
1. 预处理 `adj` 邻接表，把边转成 0-indexed。
2. 枚举 `mask` 从 1 到 `(1<<n)-1`，先判连通：从 `mask` 最低位出发 BFS/DFS，只走 `mask` 内的点，看能否覆盖 `mask` 全部位。
3. 对连通的 `mask`，用树形 DP 求直径：任取 `mask` 内一点 `r`，DFS 返回以 `r` 为根时每个子树向下的最大深度，直径 = 所有节点「最大两个子深度之和」的最大值。
4. 把直径 `d` 累加到 `ans[d-1]`。

以示例 1 `n=4, edges=[[1,2],[2,3],[2,4]]` 为例，0-indexed 后 `adj[1]=[0,2,3]`。取 `mask=0b1110`（城市 2,3,4），连通，以 1 为根：子 2、3 深度都是 1，直径 = 1+1 = 2，`ans[1] += 1`。取 `mask=0b0011`（城市 1,2），直径 = 1，`ans[0] += 1`。最终 `ans=[3,4,0]`。

```python
def dfs(u, p, mask):
    best = 0
    for v in adj[u]:
        if v != p and (mask >> v) & 1:
            d = dfs(v, u, mask) + 1
            nonlocal dia
            dia = max(dia, best + d)
            best = max(best, d)
    return best

for mask in range(1, 1 << n):
    # 连通性检查略，用 visited 覆盖 mask 全部位
    dia = 0
    dfs(root, -1, mask)
    if dia: ans[dia - 1] += 1
```

## 复杂度
时间：O(2^n · n)，枚举 2^n 个点集，每个点集 DFS 遍历 n 个点。
空间：O(n) 递归栈 + O(n) 邻接表，无额外大数组。

## 易错点
- 单点集 `mask` 只有 1 位时直径 `dia=0`，若直接 `ans[dia-1]` 会写成 `ans[-1]` 把单点集错记到最大距离上 → 必须 `if dia:` 跳过，因为题目只统计 d≥1。
- 连通性没判就 DFS：如示例 1 取 `mask=0b0101`（城市 1,3），从 0 出发只覆盖 0，`dia=0` 被跳过看似无害，但若点集是 `{1,3,4}` 这类不连通却含多条边的组合，DFS 只走一个连通块会算出偏小的直径并错误计数 → 必须先验证 `visited` 覆盖 `mask` 全部位。

## 如果面试官追问
若 n 放大到 10^5 怎么办？答：枚举点集不可行，需换「按直径中点/边分类 + 换根 DP 统计」的做法，复杂度降到 O(n)。
