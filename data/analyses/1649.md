## 一句话思路
用树状数组在线统计已插入元素中「严格小于 x」和「严格大于 x」的个数，取 min 累加。

## 怎么做
1. 值域上界 `M = max(instructions)`，开长度 `M+1` 的树状数组 `bit`，下标即数值。
2. 遍历 `x`，先查 `less = query(x-1)`（严格小于），再查 `le = query(x)`，则 `greater = i - le`（`i` 是已插入个数，含重复值不算大于）。
3. `ans = (ans + min(less, greater)) % (10**9+7)`，然后 `update(x, 1)`。

以示例 3 的 `instructions = [1,3,3,3,2,4,2,1,2]` 为例，处理到第 5 个元素 `x=2` 时，已插入 `[1,3,3,3]`，`i=4`：`less = query(1) = 1`，`le = query(2) = 1`，`greater = 4 - 1 = 3`，代价 `min(1,3) = 1`，与官方解释一致。

```python
M = max(instructions)
bit = [0] * (M + 1)
def update(i):
    while i <= M:
        bit[i] += 1
        i += i & -i
def query(i):
    s = 0
    while i > 0:
        s += bit[i]
        i -= i & -i
    return s
ans = 0
for i, x in enumerate(instructions):
    less = query(x - 1)
    greater = i - query(x)
    ans = (ans + min(less, greater)) % (10**9 + 7)
    update(x)
```

## 复杂度
时间：O(n log M)，n 为 instructions 长度，M 为最大值，每次查询/更新各 log M。
空间：O(M)，树状数组长度 M+1，无其他额外结构。

## 易错点
- 重复值处理：`instructions = [1,3,3,3]` 插入第二个 3 时，若用 `query(x)` 当「小于等于」再算 greater 会漏掉等值，正确是 `greater = i - query(x)`，等值既不算小也不算大，代价为 0。
- 取模时机：`ans` 累加后立即 `% (10**9+7)`，若只在最后取模，n=10^5 时累加值可达 10^10 量级，虽 Python 不溢出但会拖慢大数运算；且题目要求返回取模结果。

## 如果面试官追问
若 instructions 长度升到 10^7 且值域也到 10^7，怎么办？答：先离散化压缩值域到 n 个不同值，树状数组长度降为 n，时间 O(n log n)、空间 O(n)。
