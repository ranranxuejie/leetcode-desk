## 一句话思路
按 key 中字母首次出现顺序建 26 位映射表，再逐字符查表替换 message，空格原样保留。

## 怎么做
1. 遍历 key，用 `seen` 集合去重，把首次出现的字母依次追加到 `order` 列表，凑满 26 个即停。
2. 用 `order[i]` 对应明文字母 `chr(ord('a') + i)`，建字典 `table`。
3. 遍历 message，字母查 `table`，空格直接保留，拼成结果。

以示例 1 的 key 为例，前几个首次出现的字母是 `t,h,e,q,u,i,c,k,b,r,o,w,n,f,x,j,m,p,s,v,l,a,z,y,d,g`，于是 `table['v']='t'`、`table['k']='h'`、`table['b']='i'`、`table['s']='s'`，`"vkbs"` 解出 `"this"`。

```python
order, seen = [], set()
for ch in key:
    if ch != ' ' and ch not in seen:
        seen.add(ch)
        order.append(ch)
table = {order[i]: chr(ord('a') + i) for i in range(26)}
res = []
for ch in message:
    res.append(' ' if ch == ' ' else table[ch])
return ''.join(res)
```

关键中间值：`order[0]='t'` 对应 `'a'`，所以 message 里的 `'v'`（`order` 中下标 19）映射到 `chr(ord('a')+19)='t'`。

## 复杂度
时间 O(|key| + |message|)，key 最多扫 2000 字符，message 逐字符查表 O(1)。
空间 O(1)，`seen`/`order`/`table` 都只装 26 个字母，结果串 O(|message|)。

## 易错点
- key 里含空格：若把 `' '` 也塞进 `seen`/`order`，`order` 长度会错位，`table` 里 `' '` 占掉一个明文字母位，导致后续所有映射整体偏移。正确做法是 `if ch != ' '` 先过滤再判重。
- 直接对 key 去重后按 `set` 迭代顺序建表：`set` 无序，`order` 顺序会乱，`"vkbs"` 可能解成别的串。必须用列表按遍历顺序 append，`seen` 只负责判重。

## 如果面试官追问
问：若 message 含大写字母怎么办？答：建表时把 `chr(ord('a')+i)` 换成对应大小写规则，或在查表前统一 `lower()` 再按需还原大小写。
