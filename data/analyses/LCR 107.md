## 一句话思路
从所有 0 同时出发做多源 BFS，第一次到达某格时的层数就是它到最近 0 的距离。

## 怎么做
1. 建 `dist` 矩阵，0 处填 0 并入队，1 处先填 `-1` 表示未访问。
2. 队列里弹出 `(i, j)`，向上下左右四个邻居扩散。
3. 邻居越界或 `dist[ni][nj] != -1` 就跳过，否则 `dist[ni][nj] = dist[i][j] + 1` 并入队。

以示例 2 `mat = [[0,0,0],[0,1,0],[1,1,1]]` 为例：初始队列是 7 个 0 的坐标，`dist[1][1] = -1`。第一层扩散时 `(0,1)` 把 `(1,1)` 置为 `0+1=1`；第二层 `(1,1)` 把 `(2,1)` 置为 `1+1=2`，`(2,0)`、`(2,2)` 由 `(1,0)`、`(1,2)` 置为 1。最终 `dist[2] = [1,2,1]`。

```python
from collections import deque
m, n = len(mat), len(mat[0])
dist = [[0 if mat[i][j] == 0 else -1 for j in range(n)] for i in range(m)]
q = deque((i, j) for i in range(m) for j in range(n) if mat[i][j] == 0)
while q:
    i, j = q.popleft()
    for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
        ni, nj = i + di, j + dj
        if 0 <= ni < m and 0 <= nj < n and dist[ni][nj] == -1:
            dist[ni][nj] = dist[i][j] + 1
            q.append((ni, nj))
```

关键点：所有 0 一开始就全部入队，BFS 的层数天然等于到最近 0 的曼哈顿距离，不需要对每个 1 单独跑一次 BFS。

## 复杂度
时间 O(m·n)：每个格子最多入队、出队一次，四个方向各查一次。
空间 O(m·n)：`dist` 矩阵加队列，最坏情况全是 0 时队列装 m·n 个坐标。

## 易错点
- 用 `mat` 原地当访问标记（把 1 改成距离）→ 后续判断 `mat[ni][nj] == 1` 时会把已访问的格子误判成未访问，导致重复入队甚至死循环；正确做法是另开 `dist`，用 `-1` 标记未访问。
- 只把第一个 0 入队 → 示例 2 中 `(2,0)` 会得到 3（绕经 `(1,1)`）而不是 1；必须把所有 0 一次性全部入队，才能保证每个格子第一次被访问就是最短距离。

## 如果面试官追问
问：如果矩阵大到 10^9 格、但 0 很少，怎么优化？
答：从每个 1 出发找最近 0 不可行，仍用多源 BFS，但只存 0 的坐标做稀疏队列，距离按需计算，避免开满 `dist` 矩阵。
