## 一句话思路
把路径异或拆成根到点的前缀异或，平衡条件变成两个前缀异或的 popcount 奇偶相同，再在树上做「同色最近距离」的换根 DP。

## 怎么做
1. 任选 0 为根，DFS 求出 `px[v]`（根到 v 的路径异或，含两端点）和 `dist[v]`（根到 v 的边权和）。
2. 记 `par[v] = popcount(px[v]) & 1`，路径 u-v 的异或 = `px[u] ^ px[v] ^ values[lca]`，但更省事的等价写法是：路径异或的 popcount 奇偶 = `par[u] ^ par[v] ^ (popcount(values[lca]) & 1)`，据此判断平衡。
3. 对每个节点做换根：维护「子树内到当前点距离最小的、par 为 0/1 的节点距离」，合并两个不同子树（或子树与当前点）时若奇偶条件满足就更新答案。
4. 答案取所有候选的最小值，没有则 -1。

以示例 1 为例：根 0，`px = [3, 2, 5, 2, 1]`，`dist = [0, 4, 6, 3, 8]`。节点 1 的 `par=1`，节点 3 的 `par=1`，`values[lca=0]=3` 的 popcount 为 2（偶），故 1-0-3 平衡，开销 `dist[1]+dist[3]-2*dist[0] = 4+3 = 7`。

```python
def dfs(u, p):
    px[u] = px[p] ^ values[u]
    dist[u] = dist[p] + w
    for v, c in g[u]:
        if v != p:
            dfs(v, u)

# 换根合并：best[u][k] = 子树内 par==k 的节点到 u 的最小距离
for v, c in g[u]:
    if v == p: continue
    for k in (0, 1):
        if best[v][k] < INF:
            need = par[u] ^ k ^ (popcount(values[u]) & 1)
            if need == 0:
                ans = min(ans, best[v][k] + c + cur[u][k ^ ...])
```

## 复杂度
时间：每个节点合并两个子树的 0/1 状态，O(n)。
空间：邻接表、`px`、`dist`、`best[n][2]`，O(n)。

## 易错点
- 把路径异或直接写成 `px[u] ^ px[v]`，漏掉 `values[lca]` 被异或两次抵消的问题 → 示例 1 中 1-0-3 会算成 `2^2=0`（popcount 0，偶，碰巧对），但 0-1 会算成 `3^2=1`（奇，错判不平衡）→ 必须显式处理 lca 项或改用 `par` 递推。
- 换根时只合并「子树内」而不把当前点自身作为候选 → 单边路径（如示例 2 的 0-1）永远进不了答案 → 初始化 `best[u][par[u]] = 0` 再合并。

## 如果面试官追问
若要求输出具体路径而非开销？答：在 DP 里同时记录取得最小值的两个端点编号，回溯父指针即可还原路径。
