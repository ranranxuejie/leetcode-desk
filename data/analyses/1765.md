## 一句话思路
多源 BFS：所有水域同时入队当第 0 层，逐层向外扩散，每个陆地格第一次被访问到的层数就是它的最大可行高度。

## 怎么做
1. 建 `height` 矩阵，水域格填 0 并入队，陆地格先填 -1 表示未访问。
2. 队列里同时装着所有水域，BFS 的层数天然等于「到最近水域的曼哈顿距离」。
3. 出队 `(i,j)` 时向四邻扩散，若邻居 `height == -1` 就置为 `height[i][j] + 1` 并入队。
4. 队列空时返回 `height`。

拿示例 1 `isWater = [[0,1],[0,0]]` 走一遍：初始队列 `[(0,1)]`，`height = [[-1,0],[-1,-1]]`。弹出 `(0,1)`，邻居 `(0,0)` 和 `(1,1)` 都置 1 入队；再弹出 `(0,0)`，邻居 `(1,0)` 置 2。最终 `[[1,0],[2,1]]`，最高值 2 出现在 `(1,0)`。

```python
from collections import deque
m, n = len(isWater), len(isWater[0])
height = [[0 if isWater[i][j] else -1 for j in range(n)] for i in range(m)]
q = deque((i, j) for i in range(m) for j in range(n) if isWater[i][j])
while q:
    i, j = q.popleft()
    for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
        x, y = i + di, j + dj
        if 0 <= x < m and 0 <= y < n and height[x][y] == -1:
            height[x][y] = height[i][j] + 1
            q.append((x, y))
```

关键在 `height[x][y] == -1` 这个判断：它同时承担「未访问」和「不覆盖水域的 0」两个职责，所以不需要额外开 `visited` 数组。

## 复杂度
时间 O(m·n)：每个格子最多入队出队一次，四邻检查是常数。
空间 O(m·n)：`height` 矩阵加队列，最坏情况所有格子同时入队。

## 易错点
- 从每个陆地格单独 BFS 找最近水域 → m·n 个格子各跑一次，1000×1000 直接超时 → 必须把所有水域一次性入队做多源 BFS，层数才等于最近距离。
- 用 `height[x][y] == 0` 判断未访问 → 水域格本身就是 0，会被反复入队甚至覆盖成非 0 → 初始化时陆地填 -1、水域填 0，判断条件写 `== -1`。

## 如果面试官追问
问：如果要求返回所有最高高度方案中字典序最小的那个怎么办？
答：BFS 只保证高度值唯一（等于最近水域距离），方案本身唯一，无需额外处理。
