## 一句话思路
答案对速度单调（速度越快总耗时越短），在 `[1, 10^7]` 上二分最小可行速度。

## 怎么做
1. 先判不可行：前 `n-1` 趟每趟至少耗 1 小时（向上取整），末趟至少 `dist[-1]/10^7`，若这个下界都超过 `hour` 就返回 `-1`。
2. 二分 `lo=1, hi=10^7`，对每个 `mid` 算总耗时 `t`。
3. 累加时前 `n-1` 趟用 `math.ceil(d / mid)`，最后一趟用 `d / mid` 不取整。
4. `t <= hour` 则 `hi = mid`，否则 `lo = mid + 1`，返回 `lo`。

以 `dist=[1,3,2], hour=2.7` 为例，`mid=3` 时：`ceil(1/3)=1`，`ceil(3/3)=1`，累计到 2，末趟 `2/3≈0.6667`，`t≈2.6667 ≤ 2.7`，可行，`hi` 收缩到 3。

```python
import math
lo, hi = 1, 10**7
while lo < hi:
    mid = (lo + hi) // 2
    t = 0.0
    for d in dist[:-1]:
        t += math.ceil(d / mid)
    t += dist[-1] / mid
    if t <= hour:
        hi = mid
    else:
        lo = mid + 1
return lo
```

注意 `math.ceil(d / mid)` 里 `d / mid` 是浮点，`d=3, mid=3` 得 `1.0`，`ceil` 得 1，没问题；但若写成 `(d + mid - 1) // mid` 纯整数更稳。

## 复杂度
时间：二分 `log(10^7)≈24` 轮，每轮扫 `n` 个 `dist`，共 `O(n log 10^7)`。
空间：只开 `lo/hi/mid/t` 几个标量，`O(1)` 额外空间。

## 易错点
- 末趟也取整 → `dist=[1,3,2], hour=2.7` 时把末趟 `2/3` 算成 1，总耗时 3 > 2.7，误判速度 3 不可行、返回 4。正确做法是 `dist[:-1]` 取整、`dist[-1]` 保留小数。
- 用 `d // mid` 代替 `ceil` → `dist=[1,3,2], hour=6, mid=1` 时 `1//1=1` 碰巧对，但 `mid=2, d=3` 时 `3//2=1` 而实际需 2 小时，总耗时算小、误判可行。正确做法是 `math.ceil(d / mid)` 或 `(d + mid - 1) // mid`。

## 如果面试官追问
问：若 `hour` 精度只到小数点后两位，能否避免浮点比较？
答：把 `hour` 乘 100 转整数，耗时也乘 100 用整数比，`t*100 <= round(hour*100)` 即可消除误差。
