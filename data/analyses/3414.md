## 一句话思路
按右端点排序后做「前 i 个区间选至多 k 个」的 DP，同时用字典序比较记录方案，二分找最后一个不重叠区间。

## 怎么做
1. 把 `intervals` 按下标打包成 `(r, l, w, idx)` 并按 `r` 升序排序，得到 `a`；排序后位置 `i` 对应原下标 `a[i][3]`。
2. 对每个位置 `i`，用 `bisect_right` 在 `a` 的右端点列上找第一个 `r >= a[i][1]` 的位置 `p`，则 `p-1` 是最后一个满足 `r < l_i` 的区间（共享边界算重叠，所以必须严格小于）。
3. 设 `dp[k][i]` 为前 `i` 个区间选至多 `k` 个的最优 `(得分, 下标元组)`，转移取「不选 `i`」与「选 `i` 加上 `dp[k-1][p]`」的较大者；比较时先比得分，得分相同比下标元组字典序（元组升序即字典序最小）。
4. 答案取 `dp[4][n]` 的下标元组，转成列表返回。

以示例 1 为例：排序后 `a = [(3,1,2,0),(5,1,5,2),(5,4,2,1),(7,6,1,4),(9,6,3,3),(9,8,1,5)]`。处理到 `(9,6,3,3)` 时 `p = bisect_right([3,5,5,7,9,9], 6) = 4`，即 `dp[1][4]` 覆盖前 4 个区间，最优是下标 `(2,)` 得分 5，加上 3 得 8，与不选时的 5 比较后胜出，最终 `dp[4][6]` 得 `(8, (2,3))`。

```python
from bisect import bisect_right
a = sorted((r, l, w, i) for i, (l, r, w) in enumerate(intervals))
n = len(a); rs = [x[0] for x in a]
dp = [[(0, ())] * (n + 1) for _ in range(5)]
for k in range(1, 5):
    for i in range(1, n + 1):
        r, l, w, idx = a[i - 1]
        p = bisect_right(rs, l - 1)
        cand = (dp[k - 1][p][0] + w, tuple(sorted(dp[k - 1][p][1] + (idx,))))
        dp[k][i] = max(dp[k][i - 1], cand)
return list(dp[4][n][1])
```

## 复杂度
时间：排序 `O(n log n)`，DP 是 `4n` 次转移、每次二分 `O(log n)`，合计 `O(n log n)`。
空间：`dp` 表 `5×(n+1)` 个元组，元组最长 4 个下标，`O(n)`。

## 易错点
1. 用 `bisect_right(rs, l)` 而不是 `l - 1`：示例 1 中区间 `(5,4,2,1)` 的 `l=4`，若查 `4` 会返回 2，把右端点 5 的 `(5,1,5,2)` 当成不重叠，得分虚高成 7；共享边界算重叠，必须查 `l-1`。
2. 得分相同时直接返回先算出的方案：示例 1 里 `(2,3)` 与 `(3,5)` 得分都是 8，若只保留第一个遇到的而不比较下标元组，可能返回 `(3,5)`；必须用元组比较取字典序最小。

## 如果面试官追问
问：若允许选至多 `m` 个（`m` 可达 `n`）怎么办？
答：DP 维度变成 `m×n` 会爆，改成按得分排序后贪心不可行，需用 `O(nm)` 但 `m` 小时仍可，或换 wqs 二分。
