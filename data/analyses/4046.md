## 一句话思路
把状态扩成 `(i, j, 方向, 已用转向数)` 跑 Dijkstra，因为边权非负且转向数单调不减，堆首弹出终点即最优。

## 怎么做
1. 状态定为 `(cost, i, j, d, t)`，`d∈{0,1,2,3}` 表示上一步方向，`t` 是已用转向数，起点特殊处理为 `d=-1, t=0`。
2. 从 `(i,j,d,t)` 向四邻 `(ni,nj)` 扩展，`nd != d` 且 `d != -1` 时 `nt = t+1`，否则 `nt = t`；`nt > k` 直接剪掉。
3. 用 `dist[i][j][d][t]` 存最小代价，弹出时若已大于记录值就跳过。
4. 堆里第一次弹出 `(m-1, n-1)` 任意方向任意 `t` 的代价就是答案；堆空返回 `-1`。

以示例 1 `grid=[[2,7,3],[1,4,5]], k=1` 为例：起点 `(0,0)` 代价 2；先向下到 `(1,0)` 得 `(3,1,0,0)`，再向右到 `(1,1)` 时方向由 0 变 1，`nt=1`，代价 `3+4=7`；继续向右到 `(1,2)` 方向不变，`nt` 仍为 1，代价 `7+5=12`，弹出终点得 12。

```python
import heapq
# dist 用字典或四维数组，这里示意核心松弛
pq = [(grid[0][0], 0, 0, -1, 0)]
while pq:
    c, i, j, d, t = heapq.heappop(pq)
    if (i, j) == (m - 1, n - 1):
        return c
    for nd, (di, dj) in enumerate(((1,0),(-1,0),(0,1),(0,-1))):
        ni, nj = i + di, j + dj
        if not (0 <= ni < m and 0 <= nj < n):
            continue
        nt = t + (d != -1 and nd != d)
        if nt > k:
            continue
        nc = c + grid[ni][nj]
        if nc < dist[ni][nj][nd][nt]:
            dist[ni][nj][nd][nt] = nc
            heapq.heappush(pq, (nc, ni, nj, nd, nt))
return -1
```

## 复杂度
时间 `O(m*n*k*4 * log(m*n*k*4))`，堆操作贡献 log。
空间 `O(m*n*k*4)`，即四维 dist 表加堆。

## 易错点
- 起点方向设成 `-1` 而不是 0：若设 0，第一步向右会被误判成一次转向，示例 3 `k=0` 会错答成有解；正确做法是首步不计转向。
- `k` 上界是 `min(m,n)-1`，但路径可能绕行消耗更多转向；若把 `nt` 上限写成 `k` 之外还额外限制步数会漏解，正确做法是只按 `nt > k` 剪枝，不限制访问次数。

## 如果面试官追问
问：若要求输出具体路径怎么办？
答：在松弛时记录每个状态的 `pre` 指针，终点弹出后沿 `pre` 回溯即可，空间多一维。
