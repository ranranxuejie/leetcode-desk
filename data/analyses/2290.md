## 一句话思路
把每格权重视为 `grid[i][j]`（0 或 1），求 (0,0) 到 (m-1,n-1) 的 0-1 最短路，用双端队列 BFS。

## 怎么做
1. 建 `dist` 二维数组，全部初始化为 `2**31 - 1`，`dist[0][0] = 0`，双端队列放入 `(0, 0)`。
2. 每次弹出队首 `(r, c)`，向四邻 `(nr, nc)` 扩展，代价 `w = grid[nr][nc]`。
3. 若 `dist[r][c] + w < dist[nr][nc]`，更新它；`w == 0` 时 `appendleft`，`w == 1` 时 `append`。
4. 队列空时返回 `dist[m-1][n-1]`。

以示例 1 的 `grid = [[0,1,1],[1,1,0],[1,1,0]]` 为例：从 (0,0) 出发，(0,1) 是障碍，`dist[0][1] = 1` 入队尾；而 (1,0) 也是障碍，`dist[1][0] = 1`。继续扩展时 (0,2) 得 2、(1,1) 得 2，最终 `dist[2][2] = 2`——注意 (2,2) 本身是 0，代价来自路径上被移除的两个 1。

```python
from collections import deque

m, n = len(grid), len(grid[0])
INF = 2**31 - 1
dist = [[INF] * n for _ in range(m)]
dist[0][0] = 0
dq = deque([(0, 0)])
while dq:
    r, c = dq.popleft()
    for nr, nc in ((r+1,c),(r-1,c),(r,c+1),(r,c-1)):
        if 0 <= nr < m and 0 <= nc < n:
            w = grid[nr][nc]
            if dist[r][c] + w < dist[nr][nc]:
                dist[nr][nc] = dist[r][c] + w
                (dq.appendleft if w == 0 else dq.append)((nr, nc))
return dist[m-1][n-1]
```

## 复杂度
时间：O(m·n)，每个格子最多被松弛常数次，边权只有 0/1。
空间：O(m·n)，`dist` 二维表加双端队列，队列最多存 m·n 个坐标。

## 易错点
- 用普通 BFS 按层数当距离：示例 1 里 (0,1) 和 (1,0) 都在第 1 层，但 (2,2) 的真实答案是 2 而非层数 4，会错成 4 或更大；必须按 `dist` 值松弛，而不是按入队层数。
- 把起点或终点当障碍计数：题面保证 `grid[0][0] == grid[m-1][n-1] == 0`，但若写成 `dist[0][0] = grid[0][0]` 再在别处误加终点代价，示例 2 会从 0 变成 1；正确做法是起点固定 0，终点代价只由路径上的 1 累加。

## 如果面试官追问
问：若要求输出具体移除哪些障碍物？
答：在 `dist` 更新时记录 `parent[nr][nc] = (r, c)`，最后从终点回溯，收集 `grid == 1` 的格子即可。
