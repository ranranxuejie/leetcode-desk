## 一句话思路
后序 DFS 返回「以该节点为根的子树是否含 1」，返回 False 时把父节点对应指针置 None。

## 怎么做
1. 递归函数 `dfs(node)` 返回布尔值：该子树剪枝后是否还含 1。
2. 空节点返回 `False`；否则先递归左右，再按返回值把 `node.left` / `node.right` 置 `None`。
3. 最后返回 `node.val == 1 or left_has or right_has`，根节点若返回 `False` 则整棵树为空。

以示例 1 `[1,null,0,0,1]` 为例：走到最右的叶子 `1`，`dfs` 返回 `True`；它的父节点 `0` 左孩子为空、右孩子是 `1`，`left_has=False, right_has=True`，返回 `True`，所以这个 `0` 被保留。而它上面那个 `0` 的左右都是空，返回 `False`，被剪掉。

```python
def dfs(node):
    if not node:
        return False
    left_has = dfs(node.left)
    right_has = dfs(node.right)
    if not left_has:
        node.left = None
    if not right_has:
        node.right = None
    return node.val == 1 or left_has or right_has

return root if dfs(root) else None
```

关键在「先递归、后判断」：只有知道孩子子树剪完还剩什么，才能决定当前指针要不要断。顺序反了就拿不到孩子的结果。

## 复杂度
时间 O(n)：每个节点被 `dfs` 访问一次，n 是节点总数。
空间 O(h)：递归栈深度等于树高 h，最坏链状 O(n)，未额外开数组。

## 易错点
- 输入 `[0]`（根就是 0）→ 若只写 `dfs(root); return root`，会返回值为 0 的单节点而非空树 → 必须用 `return root if dfs(root) else None` 处理根被剪空的情况。
- 输入 `[1,0,1,0,0,0,1]` → 若在递归前就判断 `node.val == 0` 直接返回 False，会把「自己是 0 但右孩子是 1」的节点误剪 → 必须先拿到 `left_has/right_has` 再决定返回值，`node.val` 只参与最后那行 or。

## 如果面试官追问
问：改成「删除所有值等于 0 的叶子，反复直到没有」怎么变？
答：同一份后序 DFS，只是返回条件换成「子树剪完后是否非空」，逻辑不变。
