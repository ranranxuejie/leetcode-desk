## 一句话思路
回文数由前 `half = (n+1)//2` 位唯一决定，从全 9 开始按字典序降序枚举，用余数 DP 判可达，第一个可行即最大。

## 怎么做
1. 只枚举左半 `half` 位，右半由镜像唯一确定；`n` 为奇数时中间位只出现一次。
2. 从 `half` 位全 9 开始逐位贪心降序，每定一位就用 DP 判断「剩余位能否补成余数 0」。
3. DP 状态是 `(位置, 当前余数)`，转移时把该位对 `k` 的贡献按它出现 1 次还是 2 次累加。

以 `n=3, k=5` 为例：`half=2`，先试 `99`，镜像得 `999`，`999 % 5 = 4` 不可行；降到 `98` 得 `989`，`989 % 5 = 4`；再到 `95` 得 `959`，`959 % 5 = 4`；`59` 得 `595`，`595 % 5 = 0`，输出 `"595"`。注意首位从 9 降到 1，不能取 0。

```python
def largestPalindrome(n, k):
    half = (n + 1) // 2
    # 第 i 位（0 起）在完整数中的权重：10^(n-1-i) + 10^i，中间位只算一次
    w = []
    for i in range(half):
        j = n - 1 - i
        w.append((pow(10, j, k) + (pow(10, i, k) if i != j else 0)) % k)
    # can[i][r]: 从第 i 位起能否凑出余数 r
    can = [[False] * k for _ in range(half + 1)]
    can[half][0] = True
    for i in range(half - 1, -1, -1):
        for r in range(k):
            for d in range(10):
                if can[i + 1][(r - d * w[i]) % k]:
                    can[i][r] = True
                    break
    if not can[0][0]:
        return ""
    res, rem = [], 0
    for i in range(half):
        lo = 1 if i == 0 else 0
        for d in range(9, lo - 1, -1):
            nr = (rem + d * w[i]) % k
            if can[i + 1][(k - nr) % k]:
                res.append(str(d))
                rem = nr
                break
    s = "".join(res)
    return s + s[-1 - (n % 2)::-1]
```

## 复杂度
时间：`O(half * k * 10)`，`half = (n+1)//2`，与 `n` 线性、与 `k ≤ 9` 常数。
空间：`O(half * k)` 的 `can` 表，外加长度 `n` 的结果串。

## 易错点
- `n=1, k=4`：若把首位下限写成 0，会试出 `"0"` 或空串；正确做法是首位 `lo=1`，从 9 降到 1，得 `"8"`。
- `n` 为奇数时中间位权重算两次：如 `n=3` 的 `w[1]` 若写成 `10^1+10^1`，`595` 的余数会算成 `(5*1+9*10+5*1)%5=0` 碰巧对，但 `n=5,k=6` 的 `89898` 会判错；正确做法是 `i == j` 时只加一次。

## 如果面试官追问
问：`n` 放大到 `10^6` 且 `k` 到 `10^3` 怎么办？
答：DP 表 `half*k` 会到 `5*10^8`，改用滚动数组只留下一层，并预计算 `10^p mod k`。
