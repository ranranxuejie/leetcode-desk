## 一句话思路
三指针遍历一遍，用 `prev` 记录上一个临界点的下标，边扫边更新最小和最大距离。

## 怎么做
1. 用 `prev`、`cur`、`nxt` 三个指针同步后移，`i` 记录 `cur` 的下标（从 0 起）。
2. 判断 `cur` 是否为临界点：`(cur.val > prev.val and cur.val > nxt.val) or (cur.val < prev.val and cur.val < nxt.val)`。
3. 若是临界点：`first` 为空则记 `first = i`；否则 `minD = min(minD, i - last)`，`maxD = i - first`；最后 `last = i`。
4. 循环结束若 `first` 仍为空或 `last == first`，返回 `[-1, -1]`。

以示例 2 `[5,3,1,2,5,1,2]` 为例：`i=2` 时 `1 < 3 and 1 < 2`，`first = last = 2`；`i=4` 时 `5 > 2 and 5 > 1`，`minD = 4-2 = 2`，`maxD = 4-2 = 2`，`last = 4`；`i=5` 时 `1 < 5 and 1 < 2`，`minD = min(2, 5-4) = 1`，`maxD = 5-2 = 3`。结果 `[1,3]`。

```python
i, first, last = 1, -1, -1
minD, maxD = 10**9, -1
while nxt:
    if (cur.val > prev.val and cur.val > nxt.val) or \
       (cur.val < prev.val and cur.val < nxt.val):
        if first == -1:
            first = i
        else:
            minD = min(minD, i - last)
            maxD = i - first
        last = i
    prev, cur, nxt = cur, nxt, nxt.next
    i += 1
return [minD, maxD] if maxD != -1 else [-1, -1]
```

## 复杂度
时间 O(n)：三个指针各走一遍链表，n 是节点数。
空间 O(1)：只开了 `prev/cur/nxt/i/first/last/minD/maxD` 几个变量。

## 易错点
- 输入 `[2,3,3,2]` → 若把「严格大于」写成 `>=`，会把下标 1 的 3 误判为极大值点，输出 `[1,1]`；正确做法是两处比较都用 `>` 和 `<`，相等不算临界点。
- 输入 `[3,1]` 或 `[1,3,2,2,3,2,2,2,7]` 的末尾 → 若循环条件写成 `while cur`，会把最后一个节点当候选，但它没有后继；正确做法是 `while nxt`，保证 `cur` 前后都有节点。

## 如果面试官追问
问：链表长度到 10^7 且内存受限怎么办？
答：本解已是 O(1) 空间单遍扫描，无需改；只需把 `i` 换成 Python 整数即可，不会溢出。
