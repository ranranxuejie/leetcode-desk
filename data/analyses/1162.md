## 一句话思路
多源 BFS：把所有陆地同时入队向外扩散，最后一个被访问的海洋格子的层数就是答案。

## 怎么做
1. 先扫一遍 `grid`，把所有 `grid[i][j] == 1` 的坐标压进 `deque`，同时统计陆地数 `land`。
2. 若 `land == 0 or land == n*n`，直接返回 `-1`（全海或全陆）。
3. 以队列初始层为第 0 层做 BFS，每弹一层 `dist += 1`，把未访问的 0 邻居标记为已访问并入队。
4. BFS 结束时 `dist - 1` 即最大距离（因为最后一层是空转）。

以示例 2 `grid = [[1,0,0],[0,0,0],[0,0,0]]` 为例：初始队列 `[(0,0)]`，第 1 层扩散到 `(0,1),(1,0)`，第 2 层到 `(0,2),(1,1),(2,0)`，第 3 层到 `(1,2),(2,1)`，第 4 层到 `(2,2)`，队列空时 `dist = 5`，返回 `4`。

```python
from collections import deque
n = len(grid)
q = deque((i, j) for i in range(n) for j in range(n) if grid[i][j] == 1)
land = len(q)
if land == 0 or land == n * n:
    return -1
dist = -1
while q:
    dist += 1
    for _ in range(len(q)):
        x, y = q.popleft()
        for dx, dy in ((1,0),(-1,0),(0,1),(0,-1)):
            nx, ny = x + dx, y + dy
            if 0 <= nx < n and 0 <= ny < n and grid[nx][ny] == 0:
                grid[nx][ny] = 1
                q.append((nx, ny))
return dist
```

## 复杂度
时间：O(n²)，每个格子最多入队一次，4 个方向常数。
空间：O(n²)，队列最坏存全部格子，原地改 `grid` 不额外开 visited。

## 易错点
- 全陆地 `grid = [[1,1],[1,1]]` → 若只判 `land == 0` 会返回 0 而非 -1 → 必须同时判 `land == n*n`。
- 层数计数写成 `dist` 初值 0 且每层 `+1` 后直接返回 → 示例 1 会得 3 而非 2 → 初值设 `-1` 或最后返回 `dist - 1`，因为最后一层是空转。

## 如果面试官追问
若要求输出那个最远海洋格坐标？答：BFS 时记录最后出队的坐标，返回 `(x, y)` 和 `dist` 即可。
