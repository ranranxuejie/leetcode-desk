## 一句话思路
后序 DFS 给每个节点返回三态（0 未覆盖 / 1 有摄像头 / 2 已覆盖），由子节点状态反推父节点是否必须装摄像头，贪心自底向上。

## 怎么做
1. 定义状态：`0` 表示该节点未被覆盖，`1` 表示该节点装了摄像头，`2` 表示该节点已被覆盖但没装。
2. 空节点返回 `2`（视为已覆盖，不逼父节点装摄像头）。
3. 后序拿到左右子状态：只要有子返回 `0`，当前节点必须装摄像头，`ans += 1`，返回 `1`；否则若任一子返回 `1`，当前已被覆盖，返回 `2`；否则两子都是 `2`，当前未被覆盖，返回 `0`。
4. 根节点若最终返回 `0`，说明根没被覆盖，再补一个摄像头。

以示例 1 `[0,0,null,0,0]` 为例：根 `0`，左子 `0`，左子的左右子都是 `0`。两个叶子返回 `0`，左子因此必须装摄像头，`ans` 变 `1`，返回 `1`；根收到左子 `1`，返回 `2`；根最终是 `2`，不再补，答案 `1`。

```python
def dfs(node):
    if not node:
        return 2
    l, r = dfs(node.left), dfs(node.right)
    if l == 0 or r == 0:
        nonlocal ans
        ans += 1
        return 1
    if l == 1 or r == 1:
        return 2
    return 0

ans = 0
if dfs(root) == 0:
    ans += 1
return ans
```

关键：`l == 0 or r == 0` 优先于 `l == 1 or r == 1`，因为子节点没被覆盖时父节点必须兜底，哪怕另一个子已装摄像头。

## 复杂度
时间 O(n)：每个节点后序访问一次，`dfs` 调用 n 次。
空间 O(h)：递归栈深度为树高 h，最坏链状 O(n)，未开额外数组。

## 易错点
- 输入是单节点 `[0]`：`dfs` 返回 `0`，若忘了根节点补摄像头那一步，会输出 `0`，正确是 `1`。根没有父节点兜底，必须单独判断返回值是否为 `0`。
- 输入是链 `[0,0,null,0,null,0]`：若把「子返回 `1` 就返回 `2`」写在「子返回 `0` 就装摄像头」之前，会漏装摄像头导致上层误判已覆盖，答案偏小。判断顺序必须是先查 `0` 再查 `1`。

## 如果面试官追问
问：要输出具体摄像头位置怎么办？
答：`dfs` 返回状态的同时把装摄像头的节点收集进列表，最后根补装时也加入，返回列表即可。
