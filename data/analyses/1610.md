## 一句话思路
把每个点转成相对 location 的极角，排序后复制一份加 2π，用滑动窗口找角度跨度 ≤ angle 的最多点数。

## 怎么做
1. 遍历 points，跳过与 location 重合的点，用 `atan2(dy, dx)` 求极角存入 `angles`，重合点计数 `same`。
2. 对 `angles` 排序，再拼接 `angles + [a + 2*pi for a in angles]` 处理跨 0 度的环形区间。
3. 双指针滑动窗口：右指针 `r` 前进，当 `angles2[r] - angles2[l] > angle*pi/180` 时左指针 `l` 右移，窗口长度即当前可见点数。
4. 答案取 `max(窗口长度) + same`。

以示例 1 为例：location=[1,1]，三个点相对坐标 (1,0)、(1,1)、(2,2)，极角约 0、0.785、0.785 弧度。angle=90 即 π/2≈1.571，窗口能覆盖全部三个，`same=0`，答案 3。

```python
from math import atan2, pi
angles, same = [], 0
for x, y in points:
    dx, dy = x - location[0], y - location[1]
    if dx == 0 and dy == 0:
        same += 1
    else:
        angles.append(atan2(dy, dx))
angles.sort()
angles2 = angles + [a + 2 * pi for a in angles]
limit = angle * pi / 180
l = best = 0
for r in range(len(angles2)):
    while angles2[r] - angles2[l] > limit:
        l += 1
    best = max(best, r - l + 1)
return best + same
```

## 复杂度
时间：O(n log n)，n 为 points 长度，排序贡献 log n，滑动窗口 O(n)。
空间：O(n)，angles 与复制后的 angles2 各占 O(n)。

## 易错点
- 输入含与 location 重合的点（如示例 2 的 [1,1]）→ 若直接算 atan2(0,0) 会得到 0 混入角度数组，且该点永远可见 → 必须单独用 `same` 计数，最后加回答案。
- 视野跨越 0 度边界（如角度接近 ±π 的点同时可见）→ 只对原数组滑窗会漏掉环形区间 → 必须拼接 `a + 2*pi` 的副本再滑窗。

## 如果面试官追问
问：若 angle ≥ 360 怎么处理？答：此时所有非重合点都可见，直接返回 `len(points)`，滑窗逻辑无需特判也能过，但提前返回更清晰。
