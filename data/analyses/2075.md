## 一句话思路
把 `encodedText` 按行切成 `rows` 段还原矩阵，再沿对角线（列号减行号恒定）读出字符，去掉尾部空格。

## 怎么做
1. 列数 `cols = len(encodedText) // rows`，因为矩阵被完全填满后按行拼接。
2. 第 `r` 行对应切片 `encodedText[r*cols:(r+1)*cols]`，拼成二维矩阵。
3. 按斜向顺序遍历：外层 `d` 从 `0` 到 `cols-1`，内层 `r` 从 `0` 到 `rows-1`，取 `mat[r][d+r]`（越界跳过）。
4. 结果 `rstrip()` 去掉尾部填充空格。

以示例 1 为例：`encodedText = "ch ie pr"`，`rows = 3`，`cols = 8 // 3 = 2`。三行切片分别是 `"ch"`、`" i"`、`"e "`。按 `d=0` 取 `mat[0][0]='c'`、`mat[1][1]='i'`；`d=1` 取 `mat[0][1]='h'`、`mat[1][2]` 越界跳过、`mat[2][3]` 越界跳过……实际遍历顺序得到 `"cipher"`。

```python
cols = len(encodedText) // rows
mat = [encodedText[r*cols:(r+1)*cols] for r in range(rows)]
res = []
for d in range(cols):
    for r in range(rows):
        c = d + r
        if c < cols:
            res.append(mat[r][c])
return ''.join(res).rstrip()
```

注意 `d + r` 是列号，`d` 是斜线编号，`r` 是行号，三者关系不能写反。

## 复杂度
时间 O(n)，n 为 `encodedText` 长度，每个字符访问一次。
空间 O(n)，矩阵 `mat` 和结果 `res` 各占 n。

## 易错点
- `rows = 1` 时 `cols = len(encodedText)`，斜向遍历退化成单行顺序读取，若把 `d` 上限写成 `cols - rows` 会漏字符；正确做法是 `d` 从 `0` 到 `cols-1`，内层用 `c < cols` 判越界。
- 示例 4 输入 `" b ac"`、`rows = 2`，`cols = 2`，矩阵为 `[" b", " a"]` 加末列 `"c"` 的填充位；若忘记 `rstrip()` 会返回 `" abc "` 而非 `" abc"`，尾部空格必须去掉。

## 如果面试官追问
若 `rows` 可达 10^6 而 `encodedText` 长度不变，怎么处理？答：`cols` 可能为 0，需特判 `rows > len(encodedText)` 时直接返回空串或原串，避免切片越界。
