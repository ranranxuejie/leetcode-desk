## 一句话思路
把每个 nums[i] 与它的质因子并到同一集合，最后统计每个根下挂了多少个 nums 元素。

## 怎么做
1. 并查集开 `10**5 + 1` 个槽，下标既表示 nums 的值也表示质因子。
2. 对每个 `x` 试除出质因子 `p`，执行 `union(x, p)`。
3. 用 `size` 数组按根累计：`size[find(x)] += 1`，只对 nums 里的值累加。
4. 答案取 `max(size)`。

以 `nums = [4,6,15,35]` 为例：4 并到 2，6 并到 2 和 3，15 并到 3 和 5，35 并到 5 和 7。此时 4、6、15、35 的根全落在 2 上，`size[find(2)] == 4`。

```python
parent = list(range(M + 1))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
def union(a, b):
    ra, rb = find(a), find(b)
    if ra != rb:
        parent[ra] = rb

for x in nums:
    t, p = x, 2
    while p * p <= t:
        if t % p == 0:
            union(x, p)
            while t % p == 0:
                t //= p
        p += 1
    if t > 1:
        union(x, t)

size = [0] * (M + 1)
for x in nums:
    size[find(x)] += 1
return max(size)
```

## 复杂度
时间：O(n·√max(nums)·α)，试除是 √max 的主项，并查集近似常数。
空间：O(max(nums))，parent 与 size 各开 10**5+1。

## 易错点
- `nums = [1]` → 1 没有大于 1 的质因子，若漏掉「t > 1 才 union」之外的兜底，`size[find(1)]` 仍是 1，答案应为 1；正确做法是 1 单独成组件，不参与任何 union。
- `nums = [2,4,8]` → 若只对 x 试除到 `p*p <= x` 却不把剩余 `t` 并进去，8 只并到 2 没问题，但 `nums = [6,10,15]` 中 10 的剩余因子 5 漏并，10 与 15 就断开了；正确做法是循环结束后 `if t > 1: union(x, t)`。

## 如果面试官追问
若 nums 值域放大到 10**9 怎么办？答：先筛出 √10**9 内的质数做试除，剩余大因子直接当独立节点 union，复杂度仍可控。
