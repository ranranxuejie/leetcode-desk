## 一句话思路
这是「下一个排列」的逆运算：把 s 当作多重集排列的字典序排名，答案就是它前面有多少个排列。

## 怎么做
1. 从右往左扫，对每个位置 i 统计「右侧比 s[i] 小的字符个数」，记为 `less`。
2. 位置 i 的贡献是 `less * (n-1-i)! / (各字符剩余计数的阶乘之积)`，即把 s[i] 换成更小字符后，后缀任意排列的方案数。
3. 用后缀字符计数维护分母，边扫边更新，累加取模。

以 `s = "cba"` 为例：i=2 时右侧无字符，`less=0`；i=1 时右侧 `{'a':1}`，`less=1`，后缀长度 1，贡献 `1*1!/1! = 1`；i=0 时右侧 `{'b':1,'a':1}`，`less=2`，后缀长度 2，`2*2!/(1!*1!) = 4`。合计 `0+1+4 = 5`，与示例一致。

```python
MOD = 10**9 + 7
n = len(s)
fact = [1] * (n + 1)
for i in range(1, n + 1):
    fact[i] = fact[i - 1] * i % MOD
inv_fact = [1] * (n + 1)
inv_fact[n] = pow(fact[n], MOD - 2, MOD)
for i in range(n, 0, -1):
    inv_fact[i - 1] = inv_fact[i] * i % MOD

cnt = [0] * 26
ans = 0
for i in range(n - 1, -1, -1):
    c = ord(s[i]) - 97
    less = sum(cnt[:c])
    ways = fact[n - 1 - i]
    for k in range(26):
        ways = ways * inv_fact[cnt[k]] % MOD
    ans = (ans + less * ways) % MOD
    cnt[c] += 1
```

## 复杂度
时间 O(26n)：每个位置扫一遍 26 个字母统计 `less` 和分母。
空间 O(n)：`fact`、`inv_fact` 两个长度 n+1 的数组，`cnt` 固定 26。

## 易错点
- `s = "aabaa"` 这类有重复字符的输入 → 若按普通「下一个排列」排名算，会把相同字符的交换重复计数，得到 4 而非 2 → 必须除以 `inv_fact[cnt[k]]` 消掉重复排列。
- `s = "cba"` 中 i=0 的 `less=2` → 若只统计「右侧严格小于 s[i] 的不同字符种类数」会得 1，贡献变 2，答案错成 3 → `less` 要按字符出现次数累加，不是种类数。

## 如果面试官追问
问：n 放大到 10^5 怎么办？答：26 的常数可接受，瓶颈是阶乘预处理 O(n)，仍成立；若字符集变大则改用树状数组统计 `less`。
