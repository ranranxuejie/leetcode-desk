## 一句话思路
把 `special` 排序后，相邻特殊楼层之间的空隙就是候选连续段，取最大空隙即可。

## 怎么做
1. 对 `special` 升序排序，使空隙可以线性扫描。
2. 先处理左边界：`special[0] - bottom` 是 `bottom` 到第一个特殊楼层前的连续段长度。
3. 再扫描相邻元素：`special[i] - special[i-1] - 1` 是两特殊楼层之间的连续段长度。
4. 最后处理右边界：`top - special[-1]`，与前面所有候选取最大值。

以示例 1 为例：`bottom=2, top=9, special=[4,6]`，排序后仍是 `[4,6]`。左边界 `4-2=2`，中间 `6-4-1=1`，右边界 `9-6=3`，最大值为 3。

```python
special.sort()
ans = special[0] - bottom
for i in range(1, len(special)):
    ans = max(ans, special[i] - special[i-1] - 1)
ans = max(ans, top - special[-1])
return ans
```

注意中间空隙要减 1，因为两端都是特殊楼层，不能计入连续段；而左右边界只减 `bottom`/`top`，因为边界本身不是特殊楼层。

## 复杂度
时间：排序 `O(m log m)`，扫描 `O(m)`，`m = len(special)`。
空间：排序额外空间 `O(log m)`（TimSort 栈），其余 `O(1)`。

## 易错点
- `special` 覆盖了 `[bottom, top]` 全部楼层（如示例 2：`bottom=6, top=8, special=[6,7,8]`）→ 若忘记中间空隙减 1，会算出 `7-6-1=0` 正确，但左边界 `6-6=0`、右边界 `8-8=0`，结果仍为 0；真正翻车的是把中间公式写成 `special[i]-special[i-1]`，会得到 1 → 正确做法是中间空隙必须 `-1`。
- `special` 只有一个元素时 → 若只写循环体而漏掉左右边界单独计算，会返回 0 或漏掉一侧 → 正确做法是初始化 `ans = special[0] - bottom`，循环后再 `max(ans, top - special[-1])`，保证单元素时两侧都参与比较。

## 如果面试官追问
若要求返回具体的连续楼层区间而非长度？答：在更新 `ans` 时同步记录区间端点 `(start, end)`，左边界为 `(bottom, special[0]-1)`，中间为 `(special[i-1]+1, special[i]-1)`，右边界为 `(special[-1]+1, top)`。
