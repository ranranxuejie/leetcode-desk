## 一句话思路
用哈希表统计每个 `hours[i] % 24` 的余数出现次数，边扫边查补数 `(24 - r) % 24` 的已有计数并累加。

## 怎么做
1. 建 `cnt` 记录余数出现次数，`ans = 0`。
2. 对每个 `h` 取 `r = h % 24`，先查 `cnt[(24 - r) % 24]` 累加到 `ans`（保证 `i < j`）。
3. 再把 `cnt[r] += 1`。
4. 返回 `ans`。

以 `hours = [12,12,30,24,24]` 为例：`h=12` 时 `r=12`，补数 `(24-12)%24=12`，`cnt[12]=0`，`ans=0`，随后 `cnt[12]=1`；第二个 `12` 查得 `cnt[12]=1`，`ans=1`；`30` 的 `r=6`，补数 `18`，`cnt[18]=0`；`24` 的 `r=0`，补数 `0`，`cnt[0]=0`，随后 `cnt[0]=1`；第二个 `24` 查得 `cnt[0]=1`，`ans=2`。

```python
cnt = {}
ans = 0
for h in hours:
    r = h % 24
    ans += cnt.get((24 - r) % 24, 0)
    cnt[r] = cnt.get(r, 0) + 1
return ans
```

关键点：`(24 - r) % 24` 在 `r == 0` 时得 `0`，正好让两个 24 的倍数配对；若写成 `24 - r` 则 `r=0` 时查 `24`，永远查不到。

## 复杂度
时间：O(n)，n 为 `hours` 长度，每个元素 O(1) 哈希操作。
空间：O(1)，`cnt` 最多 24 个键。

## 易错点
- 输入 `hours = [24,24]` → 若补数写成 `24 - r`，`r=0` 时查 `cnt[24]` 得 0，答案错成 0 → 必须写 `(24 - r) % 24`。
- 输入 `hours = [72,48,24,3]` → 若先 `cnt[r] += 1` 再查补数，会把自身算进去（`r=0` 时自己配自己），答案错成 6 → 必须先查后加，保证只统计 `i < j`。

## 如果面试官追问
问：若要求输出所有下标对而非计数？答：仍需先查后加，把 `cnt` 存成余数到下标列表的映射，查补数时遍历列表拼对，最坏 O(n²) 输出。
