## 一句话思路
用状态 `(当前节点, 已访问节点掩码)` 做 BFS，第一次出现掩码为 `(1<<n)-1` 时层数即最短路径。

## 怎么做
1. 起点不唯一，把所有 `(i, 1<<i)` 一次性入队，`dist` 初始为 0。
2. 队列里弹出 `(u, mask)`，若 `mask == (1<<n)-1` 直接返回 `dist[(u,mask)]`。
3. 否则枚举 `graph[u]` 的邻居 `v`，新掩码 `mask | (1<<v)`，未访问过就入队并 `dist+1`。
4. BFS 按层扩展，保证首次到达全掩码时步数最少。

以示例 1 `graph = [[1,2,3],[0],[0],[0]]` 为例：初始入队 `(0,1),(1,2),(2,4),(3,8)`。从 `(1,2)` 扩展到 `(0,3)`，再到 `(2,7)`，再到 `(0,7)`，再到 `(3,15)`，此时 `mask=15=(1<<4)-1`，`dist=4`，返回 4。

```python
from collections import deque
n = len(graph)
full = (1 << n) - 1
q = deque()
dist = {}
for i in range(n):
    q.append((i, 1 << i))
    dist[(i, 1 << i)] = 0
while q:
    u, mask = q.popleft()
    if mask == full:
        return dist[(u, mask)]
    for v in graph[u]:
        nm = mask | (1 << v)
        if (v, nm) not in dist:
            dist[(v, nm)] = dist[(u, mask)] + 1
            q.append((v, nm))
```

## 复杂度
时间：`O(n * 2^n)`，每个 `(节点, 掩码)` 状态最多扩展一次，每次枚举度数。
空间：`O(n * 2^n)`，`dist` 字典存全部状态，队列同阶。

## 易错点
- 只从节点 0 出发 → 示例 1 会得到 3 或错误值，因为最优路径起点是 1（`[1,0,2,0,3]`）→ 必须把所有 `(i, 1<<i)` 都入队，`dist` 初始为 0。
- 用 `visited` 集合判重但忘记把起点掩码写对 → 例如 `1<<i` 写成 `i`，导致 `mask` 永远到不了 `full`，死循环或返回 `None` → 掩码必须是 `1 << i`，全掩码是 `(1 << n) - 1`。

## 如果面试官追问
问：如果要求输出具体路径而不只是长度？
答：在 `dist` 之外再存 `parent[(v,nm)] = (u,mask)`，到达 `full` 后沿父指针回溯即可。
