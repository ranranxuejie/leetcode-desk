## 一句话思路
逐位 DP：每个位置只有「换」与「不换」两态，用前一位的两态最小值推当前位。

## 怎么做
1. 定义 `keep` = 到 i 位为止、第 i 位不交换的最小次数；`swap` = 第 i 位交换的最小次数。初始 `keep, swap = 0, 1`。
2. 对每个 i≥1，先算两个布尔量：`can_keep = nums1[i-1] < nums1[i] and nums2[i-1] < nums2[i]`（前后都不换也递增），`can_swap = nums2[i-1] < nums1[i] and nums1[i-1] < nums2[i]`（前不换后换，交叉比较）。
3. 新 `keep` 只能来自「前不换且 can_keep」或「前换且 can_swap」；新 `swap` 同理但代价 +1，取两者较小。
4. 用临时变量先存旧值再更新，避免 `keep` 被覆盖后 `swap` 用到新值。

以示例 1 `nums1=[1,3,5,4], nums2=[1,2,3,7]` 为例，走到 i=3 时旧值 `keep=0, swap=1`：`can_keep = 5<4` 为 False，`can_swap = 3<4 and 5<7` 为 True，故新 `keep = swap = 1`，新 `swap = keep+1 = 1`，答案 `min(1,1)=1`。

```python
keep, swap = 0, 1
for i in range(1, len(nums1)):
    ck = nums1[i-1] < nums1[i] and nums2[i-1] < nums2[i]
    cs = nums2[i-1] < nums1[i] and nums1[i-1] < nums2[i]
    nk = min(keep if ck else INF, swap if cs else INF)
    ns = min(swap + 1 if ck else INF, keep + 1 if cs else INF)
    keep, swap = nk, ns
return min(keep, swap)
```

## 复杂度
时间 O(n)：一次遍历，n 为数组长度。
空间 O(1)：只维护 `keep`、`swap` 两个标量。

## 易错点
- 只判 `can_keep` 不判 `can_swap`：如 `nums1=[0,3,5,8,9], nums2=[2,1,4,6,9]`，i=1 时 `3<1` 假但 `1<3 and 0<4` 真，漏掉交叉分支会误判无解或次数偏大，必须两条件都算。
- 更新顺序写反：先改 `keep` 再算 `swap`，`swap` 会读到新 `keep` 而非旧值，示例 1 的 i=3 会算出 `swap=2` 而非 1，正确做法是先用 `nk/ns` 暂存再同时赋值。

## 如果面试官追问
要求输出具体交换了哪些下标怎么办？答：DP 时额外存每步选了哪个分支（keep 来自 keep 还是 swap），回溯即可还原下标集合。
