## 一句话思路
从左到右贪心：每位尽量压到 `'a'`，代价是 `min(ord(c)-97, 123-ord(c))`，代价不够就只降剩余 k。

## 怎么做
1. 逐位扫描 `s`，对每个字符 `c` 算把它变成 `'a'` 的最小距离 `d = min(ord(c) - 97, 123 - ord(c))`。
2. 若 `d <= k`，直接置 `'a'` 并 `k -= d`；否则这一位只能降 `k`，变成 `chr(ord(c) - k)`，然后 `k = 0`。
3. `k` 归零后，剩余字符原样保留（再改只会让字典序变大或超预算）。

以 `s = "xaxcd", k = 4` 为例：`'x'` 的 `d = min(23, 3) = 3`（绕回 `'a'` 更近），`3 <= 4`，置 `'a'`，`k = 1`；`'a'` 的 `d = 0`，置 `'a'`，`k` 仍为 1；`'x'` 的 `d = 3 > 1`，只能降 1 位得 `'w'`，`k = 0`；后面 `"cd"` 原样。结果 `"aawcd"`。

```python
res = []
for c in s:
    if k == 0:
        res.append(c)
        continue
    d = min(ord(c) - 97, 123 - ord(c))
    if d <= k:
        res.append('a')
        k -= d
    else:
        res.append(chr(ord(c) - k))
        k = 0
return ''.join(res)
```

关键在 `d` 的绕回项 `123 - ord(c)`：`'z'` 变 `'a'` 只需 1 步，不是 25 步。示例 1 中 `"zbbz", k = 3`：`'z'` 的 `d = 1`，置 `'a'`，`k = 2`；两个 `'b'` 各花 1，`k = 0`；末位 `'z'` 保留，得 `"aaaz"`。

## 复杂度
时间 O(n)：`n = len(s)`，每位常数次运算。
空间 O(n)：结果列表 `res` 存 n 个字符。

## 易错点
- `s = "z", k = 0` 或 `k` 在中间耗尽 → 若仍对后续字符做 `chr(ord(c) - k)` 会得到 `'z'` 本身以外的乱码（`k = 0` 时恰好不变，但若漏判 `k == 0` 又用了别的分支就会错）→ 必须先判 `k == 0` 直接原样追加。
- `s = "z", k = 1` → 若用 `ord(c) - 97` 当距离，会认为要 25 步、放弃改 `'z'`，输出 `"z"` → 正确距离是 `min(25, 1) = 1`，应输出 `"a"`；绕回项不能漏。

## 如果面试官追问
问：若要求输出所有距离 ≤ k 的字典序最小串的数量？答：每位独立，把每位的可选字符数相乘，`'a'` 位贡献 1，其余位贡献 `2*min(...)+1` 类计数。
