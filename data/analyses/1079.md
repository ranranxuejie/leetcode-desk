## 一句话思路
用 Counter 统计每个字母的剩余次数，回溯时每层挑一个剩余次数 >0 的字母接上，每接一个就计一次数。

## 怎么做
1. 先 `cnt = Counter(tiles)`，把 "AAB" 变成 `{'A': 2, 'B': 1}`，后续只看计数不看原串。
2. 回溯函数返回「在当前剩余计数下还能印出多少非空序列」，每层遍历 `cnt` 里所有 `cnt[ch] > 0` 的字母。
3. 选中 `ch` 时先 `cnt[ch] -= 1`，这一支贡献 `1 + dfs()`（1 是「以 ch 结尾的当前前缀」本身，dfs 是往后接的），再 `cnt[ch] += 1` 还原。
4. 累加所有分支即为答案。

以 "AAB" 为例，第一层选 A 后 `cnt` 变成 `{'A': 1, 'B': 1}`，这一支返回 `1 + 3 = 4`（对应 A、AA、AB、ABA 等以 A 开头的 4 个）；选 B 后 `cnt` 变成 `{'A': 2, 'B': 0}`，返回 `1 + 3 = 4`；总答案 8。

```python
from collections import Counter

def dfs():
    total = 0
    for ch in cnt:
        if cnt[ch] > 0:
            cnt[ch] -= 1
            total += 1 + dfs()
            cnt[ch] += 1
    return total

cnt = Counter(tiles)
return dfs()
```

关键点：`for ch in cnt` 遍历的是**去重后的字母种类**，不是原串下标，所以 "AAB" 里两个 A 不会被当成两条不同分支，天然避免了重复序列。

## 复杂度
时间：O(答案规模)，即所有合法序列数，最坏约 7! 量级，每个节点做 O(不同字母数) 的循环。
空间：O(不同字母数) 的递归栈与 Counter，最多 7 层。

## 易错点
- 输入 "AAB" → 若按原串下标回溯并去重，会把 "A₁A₂B" 和 "A₂A₁B" 算成两条不同路径再靠 set 去重，白白多跑一倍分支；正确做法是直接对 Counter 的字母种类分支，重复字母从一开始就不产生重复路径。
- 输入 "V" → 若把 `total += 1 + dfs()` 写成 `total += dfs()`，会漏掉「单个字母本身」这一层，输出 0 而不是 1；正确做法是每选一个字母就先记 1，再叠加它后面的延伸。

## 如果面试官追问
问：如果 tiles 长度放宽到 15，还这么写吗？
答：不行，序列数会爆炸；改用「按字母种类分配长度 + 组合数」的公式法，或直接对答案取模。
