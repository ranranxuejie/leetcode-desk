## 一句话思路
用 `Person` 左连接 `Address`，因为要保留 Person 全部行、地址缺失补 `None`。

## 怎么做
1. 以 `Person` 为左表，`LEFT JOIN Address`，连接键是两表的 `personId`。
2. 选列顺序按输出要求：`firstName, lastName, city, state`，注意题面表结构里 `lastName` 在前但输出 `firstName` 在前。
3. 用官方示例走一遍：`Person` 的 `personId=1`（Allen Wang）在 `Address` 里没有匹配行，左连接后该行 `city`、`state` 两列取到 `None`；`personId=2` 匹配到 `addressId=1`，取到 `New York City`/`New York`。
4. `Address` 里 `personId=3`（Leetcode/California）因左表无对应人，被丢弃，不出现在结果里。

```python
# 用 pandas 表达同一逻辑
merged = person.merge(address, on="personId", how="left")
result = merged[["firstName", "lastName", "city", "state"]]
```

SQL 版关键一行：

```sql
SELECT p.firstName, p.lastName, a.city, a.state
FROM Person p LEFT JOIN Address a ON p.personId = a.personId;
```

中间值核对：连接后 `personId=1` 那行的 `a.city` 是 `None`，不是空字符串，也不是被过滤掉——这正是 `LEFT JOIN` 与 `INNER JOIN` 的分水岭。

## 复杂度
时间 O(n+m)：n 为 Person 行数、m 为 Address 行数，各扫一遍做哈希连接。
空间 O(n+m)：连接结果保留 Person 全部 n 行，另需 Address 的哈希表。

## 易错点
- 写成 `INNER JOIN`：`personId=1`（Allen Wang）会被直接丢掉，结果只剩 Bob 一行，而正确输出必须有两行、第一行 city/state 为 `None`。判断依据是题面「报告 Person 表中每个人」，主语是 Person。
- 把连接键写成 `addressId = personId`：示例里 `personId=2` 会去匹配 `addressId=2`（Leetcode/California），输出成 Bob 住 California，而正确答案是 `addressId=1` 的 New York City。键必须是两表的 `personId`。

## 如果面试官追问
问：如果 Address 里同一 personId 有多条地址怎么办？
答：左连接会让人物行数翻倍，需先用 `ROW_NUMBER()` 按 `addressId` 取一条，或明确业务上取哪个地址再连接。
