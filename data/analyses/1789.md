## 一句话思路
用 `GROUP BY employee_id` 聚合，取 `MAX(primary_flag)` 对应的行；因为 `'Y' > 'N'`，单部门员工只有 `'N'` 也会被选中。

## 怎么做
1. 先按 `employee_id` 分组，统计每个员工的行数，得到「单部门」与「多部门」两类。
2. 对多部门员工，只保留 `primary_flag = 'Y'` 的那一行；对单部门员工，保留唯一那一行。
3. 用 `UNION` 合并两类结果，或直接用 `WHERE primary_flag = 'Y' OR employee_id IN (单部门子查询)`。

以官方示例员工 4 为例：三行 `(4,2,'N')`、`(4,3,'Y')`、`(4,4,'N')`，分组计数为 3，走多部门分支，只留 `department_id = 3`。员工 3 只有一行 `(3,3,'N')`，计数为 1，走单部门分支，输出 `(3,3)`。

```python
# 假设 df 是 Employee 的 DataFrame
cnt = df.groupby('employee_id')['department_id'].transform('count')
single = df[cnt == 1][['employee_id', 'department_id']]
multi = df[(cnt > 1) & (df['primary_flag'] == 'Y')][['employee_id', 'department_id']]
result = pd.concat([single, multi]).sort_values('employee_id')
```

SQL 等价写法：

```sql
SELECT employee_id, department_id FROM Employee WHERE primary_flag = 'Y'
UNION
SELECT employee_id, department_id FROM Employee
GROUP BY employee_id HAVING COUNT(*) = 1;
```

## 复杂度
时间：O(n)，n 为 Employee 行数，分组与两次扫描各一遍。
空间：O(k)，k 为员工数，用于存分组计数与结果集。

## 易错点
1. 只写 `WHERE primary_flag = 'Y'` → 员工 1、3 这种单部门且标记为 `'N'` 的行会被漏掉，输出少两行；必须补上 `COUNT(*) = 1` 的分支。
2. 用 `UNION ALL` 而非 `UNION` → 若某员工既满足 `'Y'` 又恰好只有一行（数据异常时），会重复输出同一 `(employee_id, department_id)`；本题主键保证不会，但换约束后要改用 `UNION` 去重。

## 如果面试官追问
问：如果允许一个员工有多个 `'Y'` 怎么办？答：题面保证唯一，若放开则需按业务规则（如取最小 `department_id`）再聚合一次，用 `MIN(department_id)` 配合 `GROUP BY employee_id`。
