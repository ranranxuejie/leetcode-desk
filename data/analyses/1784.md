## 一句话思路
数 `'1'` 段的数量，用 `s[i]=='1' and s[i-1]=='0'` 判断新段起点，段数 ≤1 即真。

## 怎么做
1. 因为 `s[0]=='1'`，段数初值设为 1，从下标 1 开始扫。
2. 遇到 `s[i]=='1'` 且 `s[i-1]=='0'`，说明新开了一段，计数加一。
3. 计数一旦到 2 就可以直接返回 `False`，不用扫完。
4. 扫完返回 `True`。

以 `s = "1001"` 为例：初值 `cnt = 1`。`i=1` 时 `s[1]=='0'` 跳过；`i=2` 也是 `'0'`；`i=3` 时 `s[3]=='1'` 且 `s[2]=='0'`，`cnt` 变成 2，立刻返回 `False`。而 `s = "110"` 全程没有出现 `'1'` 紧跟 `'0'` 的位置，`cnt` 停在 1，返回 `True`。

```python
cnt = 1
for i in range(1, len(s)):
    if s[i] == '1' and s[i - 1] == '0':
        cnt += 1
        if cnt == 2:
            return False
return True
```

关键点在于「新段起点」的判定条件必须同时看 `s[i]` 和 `s[i-1]`：只看 `s[i]=='1'` 会把 `"110"` 里的第二个 `'1'` 也当成新段，直接误判为 `False`。

## 复杂度
时间 O(n)：`i` 从 1 扫到 `len(s)-1`，最坏扫满整个字符串。
空间 O(1)：只开了 `cnt` 和 `i` 两个整型变量，没有额外数组。

## 易错点
- 输入 `s = "1"` → 若把 `cnt` 初值写成 0 再靠循环累加，循环体一次都不执行，会错成 `False` → 正确做法是利用题面保证 `s[0]=='1'`，初值直接给 1。
- 输入 `s = "101"` → 若判定条件写成 `s[i]=='1'` 单独判断，`i=2` 的 `'1'` 会被当成第二段，错成 `False` → 正确做法是加上 `s[i-1]=='0'` 这个与条件，只有前一位是 `'0'` 才算新段。

## 如果面试官追问
问：如果去掉「不含前导零」这个保证，`s` 可能以 `'0'` 开头怎么办？
答：初值改成 0，循环从 `i=0` 开始，把 `i==0` 视作前一位为 `'0'` 即可。
