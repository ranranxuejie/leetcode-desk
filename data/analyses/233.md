## 一句话思路
按位统计：对每一位 `factor`，用高位 `high`、当前位 `cur`、低位 `low` 算出该位出现 1 的次数，累加。

## 怎么做
1. 从个位起令 `factor = 1`，每轮 `high = n // (factor * 10)`、`cur = n // factor % 10`、`low = n % factor`。
2. `cur == 0` 时该位贡献 `high * factor`；`cur == 1` 时贡献 `high * factor + low + 1`；`cur >= 2` 时贡献 `(high + 1) * factor`。
3. `factor *= 10` 直到 `factor > n`，累加结果返回。

以 `n = 13` 为例：`factor = 1` 时 `high = 1, cur = 3, low = 0`，`cur >= 2` 贡献 `(1+1)*1 = 2`（即 1、11 的个位）；`factor = 10` 时 `high = 0, cur = 1, low = 3`，贡献 `0*10 + 3 + 1 = 4`（10、11、12、13 的十位），合计 6。

```python
ans, factor = 0, 1
while factor <= n:
    high = n // (factor * 10)
    cur = n // factor % 10
    low = n % factor
    if cur == 0:
        ans += high * factor
    elif cur == 1:
        ans += high * factor + low + 1
    else:
        ans += (high + 1) * factor
    factor *= 10
return ans
```

## 复杂度
时间：O(log n)，`factor` 每次乘 10，循环约 10 次（n ≤ 10^9）。
空间：O(1)，只开 `ans/high/cur/low/factor` 五个整型变量。

## 易错点
- `n = 0` → 若循环写成 `while factor < n` 或先算再判，会漏掉直接返回 0 的分支或死循环；正确做法是 `while factor <= n`，此时 `high=0, cur=0, low=0`，贡献 0，自然返回 0。
- `n = 13` 的十位 → 若把 `cur == 1` 也按 `(high+1)*factor` 算，会得 `1*10 = 10`，比正确的 4 多算 6；必须单独加 `low + 1`，因为 10~13 这 4 个数才真正带十位的 1。
