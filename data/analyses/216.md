## 一句话思路
用回溯在 1..9 上按升序选数，靠「剩余个数」和「剩余和」两个约束剪枝，天然去重。

## 怎么做
1. 递归参数定为 `(start, left_k, left_n)`，`start` 是下一个可选的最小数字，保证组合内严格递增、不重复。
2. 终止条件：`left_k == 0` 时若 `left_n == 0` 就收集当前 `path`，否则直接返回。
3. 循环 `i` 从 `start` 到 `9`，先剪枝再递归：`i > left_n` 时 break（后面更大更不可能），`left_k > 9 - i + 1` 时也 break（剩下的数不够凑个数）。
4. 递归前 `path.append(i)`，递归 `(i + 1, left_k - 1, left_n - i)`，回来后 `path.pop()`。

以 `k = 3, n = 9` 为例，走到 `path = [1, 2]` 时 `left_k = 1, left_n = 6`，循环从 `i = 3` 起，`i = 6` 时 `left_n - i = 0` 且 `left_k - 1 = 0`，收集 `[1, 2, 6]`；`i = 7` 时 `7 > 6` 触发 break，不再试 7、8、9。

```python
def dfs(start, left_k, left_n):
    if left_k == 0:
        if left_n == 0:
            res.append(path[:])
        return
    for i in range(start, 10):
        if i > left_n or left_k > 10 - i:
            break
        path.append(i)
        dfs(i + 1, left_k - 1, left_n - i)
        path.pop()
dfs(1, k, n)
```

## 复杂度
时间：O(C(9,k)) 个节点，每个节点拷贝长度 k 的路径，上界 O(k·C(9,k))。
空间：递归深度最多 k，`path` 长 k，不计结果集为 O(k)。

## 易错点
- `k = 4, n = 1` 这类「最小和都超了」的输入 → 若不剪枝会白跑整棵搜索树 → 在入口先判 `n < k*(k+1)//2` 或 `n > (19-k)*k//2` 直接返回 `[]`。
- 递归传 `start = i` 而不是 `i + 1` → 数字会被重复使用，`k = 3, n = 9` 会多出 `[1, 1, 7]` 这类非法组合 → 必须传 `i + 1`，因为每个数字最多用一次。

## 如果面试官追问
问：数字范围从 1..9 扩到 1..m，怎么改？
答：把循环上界 `10` 换成 `m + 1`，剪枝条件同步改成 `left_k > m - i + 1`，其余不变。
