## 一句话思路
二分答案 k，用「以 i 结尾的递增段长度」数组在 O(n) 内判定是否存在相邻两段长度都 ≥ k。

## 怎么做
1. 预处理 `inc[i]`：以 `i` 结尾的最长严格递增子数组长度，`inc[0]=1`，`nums[i]>nums[i-1]` 时 `inc[i]=inc[i-1]+1`，否则为 1。
2. 判定 `check(k)`：枚举分界点 `i`（左段结尾），要求 `inc[i]>=k` 且 `inc[i+k]>=k`，任一成立即真。
3. 答案在 `[1, n//2]` 上二分，`check(mid)` 为真则 `lo=mid`，否则 `hi=mid-1`。

以示例 1 `nums=[2,5,7,8,9,2,3,4,3,1]` 为例，`inc=[1,2,3,4,5,1,2,3,1,1]`。`check(3)` 时 `i=2`：`inc[2]=3>=3`，`inc[5]=1<3` 失败；`i=4`：`inc[4]=5>=3`，`inc[7]=3>=3` 成立，故 k=3 可行。

```python
n = len(nums)
inc = [1] * n
for i in range(1, n):
    if nums[i] > nums[i - 1]:
        inc[i] = inc[i - 1] + 1

def check(k):
    for i in range(k - 1, n - k):
        if inc[i] >= k and inc[i + k] >= k:
            return True
    return False

lo, hi = 1, n // 2
while lo < hi:
    mid = (lo + hi + 1) // 2
    if check(mid):
        lo = mid
    else:
        hi = mid - 1
return lo
```

## 复杂度
时间 O(n log n)：预处理 O(n)，二分 log(n/2) 次、每次 check 扫 O(n)。
空间 O(n)：额外开了长度 n 的 `inc` 数组。

## 易错点
- `nums=[1,2,3,4,4,4,4,5,6,7]`：若把 `inc` 写成「以 i 开头」的递增长度，`i+k` 的边界会算错，`check(2)` 在 `i=2` 处误判。正确做法是统一用「以 i 结尾」，分界点 `i` 是左段末尾，右段末尾是 `i+k`。
- 二分上界写成 `n` 而非 `n//2`：两段相邻共占 `2k` 个元素，`k>n//2` 时 `i+k` 必越界，`check` 里 `range(k-1, n-k)` 为空会返回 False，但若循环写成 `range(n)` 就会 IndexError。正确做法是 `hi=n//2` 且循环上界 `n-k`。

## 如果面试官追问
问：不二分，能 O(n) 吗？答：可以，对每个分界点 `i` 取 `min(inc[i], inc[i+1])` 的候选（左段以 i 结尾、右段从 i+1 起），再结合跨段延伸，扫一遍取最大即可。
