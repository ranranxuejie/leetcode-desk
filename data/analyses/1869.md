## 一句话思路
一次遍历同时维护当前连续段长度和两类历史最大值，最后比较 `max1 > max0`。

## 怎么做
1. 初始化 `max1 = max0 = cur = 0`，`prev = ''` 记录上一个字符。
2. 遍历 `s`，若 `ch == prev` 则 `cur += 1`，否则 `cur = 1` 并更新 `prev = ch`。
3. 每步按 `ch` 把 `cur` 归入 `max1` 或 `max0`（取较大值）。
4. 返回 `max1 > max0`。

以 `s = "1101"` 为例：走到第 3 个字符 `'0'` 时，`prev` 从 `'1'` 变成 `'0'`，`cur` 由 2 重置为 1，此时 `max1` 已定格为 2；继续走到末尾 `'1'`，`cur = 1`，`max0` 保持 1。最终 `2 > 1` 返回 `True`。

```python
max1 = max0 = cur = 0
prev = ''
for ch in s:
    if ch == prev:
        cur += 1
    else:
        cur = 1
        prev = ch
    if ch == '1':
        max1 = max(max1, cur)
    else:
        max0 = max(max0, cur)
return max1 > max0
```

关键点：重置 `cur` 和更新 `max` 必须在同一轮完成，否则像 `"111000"` 这种末尾段会被漏记——该例中 `max1` 和 `max0` 都应为 3，返回 `False`。

## 复杂度
时间 O(n)：`n = len(s)`，每个字符只被访问一次。
空间 O(1)：只开了 `max1`、`max0`、`cur`、`prev` 四个变量。

## 易错点
- 输入 `"111000"` → 若只在字符切换时才更新 `max`，末尾的 `"000"` 段不会被计入，`max0` 停在 0，误返回 `True`；正确做法是每轮无条件用 `cur` 更新对应 `max`。
- 输入 `"0"` 或 `"1"` → 若把 `max0`、`max1` 初值都设成 0 却忘了首字符 `cur` 从 1 起算，会得到 `0 > 0` 的 `False`；正确做法是首字符走 `else` 分支置 `cur = 1`，保证单字符串也能得到 `1 > 0` 或 `0 > 1` 的正确结果。

## 如果面试官追问
问：若要求返回最长 1 段和最长 0 段的具体起止下标？
答：在更新 `max1`/`max0` 时同步记录 `i - cur + 1` 和 `i` 即可，空间仍是 O(1)。
