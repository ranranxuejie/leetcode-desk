## 一句话思路
逐格累加 `2 + 4*grid[i][j]`，再减去每对相邻格子重叠的 `2*min(两者高度)`，重叠面被两侧各算一次。

## 怎么做
1. 遍历每个格子，先加上该柱子的独立表面积 `2 + 4*v`（上下底面各 1，四个侧面各 v）。
2. 只向右、向下两个方向检查邻居，避免同一对相邻格子被减两次。
3. 对每个存在的邻居，减去 `2 * min(v, w)`，因为两柱贴合处被遮住的面在两侧各算了一次。

以 `grid = [[1,2],[3,4]]` 为例：独立表面积 = (2+4)+(2+8)+(2+12)+(2+16) = 6+10+14+18 = 48。右邻居：(0,0)-(0,1) 减 `2*min(1,2)=2`，(1,0)-(1,1) 减 `2*min(3,4)=6`；下邻居：(0,0)-(1,0) 减 `2*min(1,3)=2`，(0,1)-(1,1) 减 `2*min(2,4)=4`。48-2-6-2-4 = 34，与示例一致。

```python
n = len(grid)
area = 0
for i in range(n):
    for j in range(n):
        v = grid[i][j]
        if v:
            area += 2 + 4 * v
        if j + 1 < n:
            area -= 2 * min(v, grid[i][j+1])
        if i + 1 < n:
            area -= 2 * min(v, grid[i+1][j])
return area
```

注意 `v == 0` 时不能加 `2`（没有底面也没有顶面），但减重叠时 `min` 自然为 0，无需特判。

## 复杂度
时间：O(n²)，每个格子常数次操作，n 为网格边长。
空间：O(1)，只用了 `area` 等几个标量，未开额外数组。

## 易错点
- 输入 `[[0]]` 或含 0 的格子 → 若写成 `area += 2 + 4*v` 不加 `if v` 判断，空柱子会凭空多出 2 的上下底面积，示例 2 中心为 0 会算成 34 而非 32 → 正确做法是 `v` 为 0 时跳过加 `2+4v`。
- 输入 `[[1,2],[3,4]]` → 若四个方向都检查邻居，每对相邻格子被减两次 `2*min`，结果变成 48-2*(2+6+2+4)=20 → 正确做法是只查右、下两个方向，保证每对邻居恰好减一次。

## 如果面试官追问
若 grid 不是方阵（m×n）怎么改？答：把 `n = len(grid)` 拆成 `rows, cols`，内层循环用 `cols`，右邻居判 `j+1 < cols`、下邻居判 `i+1 < rows`，其余逻辑不变。
