## 一句话思路
用循环模拟「空瓶换水、喝完又得空瓶」的过程，因为每轮空瓶数严格减少，循环必然终止。

## 怎么做
1. 用 `total` 记已喝瓶数，初值 `numBottles`；用 `empty` 记当前空瓶数，初值也是 `numBottles`。
2. 当 `empty >= numExchange` 时，用整除算出这轮能换几瓶：`new = empty // numExchange`。
3. 换来的 `new` 瓶喝掉，`total += new`；空瓶数变成「没换掉的余数 + 新喝出的空瓶」：`empty = empty % numExchange + new`。
4. 循环结束返回 `total`。

拿示例 2（`numBottles = 15, numExchange = 4`）走一遍：初始 `total = 15, empty = 15`。第一轮 `new = 15 // 4 = 3`，`total = 18`，`empty = 15 % 4 + 3 = 3 + 3 = 6`；第二轮 `new = 6 // 4 = 1`，`total = 19`，`empty = 6 % 4 + 1 = 2 + 1 = 3`；此时 `3 < 4` 退出，返回 19。关键中间值是第二轮后的 `empty = 3`——余数 2 必须留着，不能丢。

```python
total = numBottles
empty = numBottles
while empty >= numExchange:
    new = empty // numExchange
    total += new
    empty = empty % numExchange + new
return total
```

第 3 步的 `empty % numExchange` 是本题唯一容易写错的地方：换出去的瓶子没了，但不够换的零头还在手里，下一轮还能凑。

## 复杂度
时间：O(log n)，`empty` 每轮约缩为原来的 `1/numExchange`，轮数是 log 级。
空间：O(1)，只开了 `total`、`empty`、`new` 三个整数。

## 易错点
- 输入 `numBottles = 15, numExchange = 4` → 若写成 `empty = new` 丢掉余数，第二轮从 `empty = 3` 变成 `empty = 1`，直接少喝 1 瓶得 18 → 正确写法是 `empty = empty % numExchange + new`，保留零头。
- 输入 `numBottles = 9, numExchange = 3` → 若用 `while empty > numExchange` 而非 `>=`，第一轮就进不去，返回 9 而不是 13 → 边界必须是 `empty >= numExchange`，恰好够换时也要换。

## 如果面试官追问
问：`numBottles` 放大到 `10**9`、`numExchange = 2` 还能循环吗？
答：能，但轮数约 30 轮；也可直接推公式 `numBottles + (numBottles - 1) // (numExchange - 1)`，O(1) 出解。
