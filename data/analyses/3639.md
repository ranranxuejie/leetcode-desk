## 一句话思路
对时间 t 二分，用「总子串数 − 全不含 `*` 的连续段子串数」在 O(n) 内算出有效子串数，单调性保证二分成立。

## 怎么做
1. 把 `order[0..t]` 这些下标标成 `*`，扫描 `s` 得到所有非 `*` 的连续段长度。
2. 有效子串数 = `n*(n+1)//2 − Σ L*(L+1)//2`，因为无效子串恰好是完全落在某个非 `*` 段内的子串。
3. 该值随 t 单调不减，二分 `[0, n-1]`；先判 `t = n-1` 时是否 `>= k`，否则返回 -1。

以示例 2 `s = "cat", order = [0,2,1], k = 6` 为例，`t = 1` 时被标记的是下标 0 和 2，`s` 变成 `*a*`，非 `*` 段只有 `[1,1]`，`L = 1`，有效数 = `3*4//2 − 1*2//2 = 6 − 1 = 5 < 6`，所以继续往右二分到 `t = 2`。

```python
def count_valid(t):
    marked = [False] * n
    for i in range(t + 1):
        marked[order[i]] = True
    total, run = n * (n + 1) // 2, 0
    for i in range(n):
        if marked[i]:
            total -= run * (run + 1) // 2
            run = 0
        else:
            run += 1
    total -= run * (run + 1) // 2
    return total

lo, hi = 0, n - 1
if count_valid(hi) < k:
    return -1
while lo < hi:
    mid = (lo + hi) // 2
    if count_valid(mid) >= k:
        hi = mid
    else:
        lo = mid + 1
return lo
```

## 复杂度
时间：二分 `log n` 轮，每轮重建 `marked` 并扫描 O(n)，共 O(n log n)。
空间：`marked` 数组 O(n)，无其他额外结构。

## 易错点
- `k` 可达 `10^9`，而 `n = 10^5` 时总子串数约 `5*10^9`，用 Python 的 int 没问题，但若在别的语言里用 32 位整型累加 `n*(n+1)//2` 会溢出，必须用 64 位。
- 忘记先判 `t = n-1` 是否达标：示例 3 `s = "xy", k = 4`，全标记后总子串数只有 `3 < 4`，若直接二分会在 `lo == hi` 时返回 1，错成有解，正确做法是先返回 -1。

## 如果面试官追问
问：如果要求返回具体的标记方案而不只是时间？答：二分出最小 t 后，`order[0..t]` 就是方案，直接切片返回即可。
