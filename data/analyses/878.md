## 一句话思路
二分答案 x，用容斥数出 ≤x 的神奇数，找第一个 count ≥ n 的 x。

## 怎么做
1. 数数公式：`cnt(x) = x//a + x//b - x//lcm`，其中 `lcm = a*b//gcd(a,b)`，减掉被重复算的公共倍数。
2. 二分下界 `lo = min(a,b)`（第 1 个神奇数至少是它），上界 `hi = n * min(a,b)`（最坏情况全是小的那个的倍数）。
3. 循环 `while lo < hi`，取 `mid = (lo+hi)//2`，`cnt(mid) >= n` 就 `hi = mid`，否则 `lo = mid+1`。
4. 返回 `lo % (10**9+7)`。

拿示例 2（n=4, a=2, b=3）走一遍：`lcm=6`，`lo=2`，`hi=8`。`mid=5` 时 `cnt = 5//2 + 5//3 - 5//6 = 2+1-0 = 3 < 4`，所以 `lo=6`；`mid=7` 时 `cnt = 3+2-1 = 4 >= 4`，`hi=7`；`mid=6` 时 `cnt = 3+2-1 = 4 >= 4`，`hi=6`，收敛到 6，正是答案。

```python
from math import gcd
lcm = a * b // gcd(a, b)
lo, hi = min(a, b), n * min(a, b)
while lo < hi:
    mid = (lo + hi) // 2
    if mid // a + mid // b - mid // lcm >= n:
        hi = mid
    else:
        lo = mid + 1
return lo % (10**9 + 7)
```

关键点：`cnt` 单调不减，所以「第一个满足 cnt ≥ n 的位置」就是第 n 个神奇数本身——因为神奇数恰好是 cnt 跳变的位置，cnt(x) ≥ n 的最小 x 必是 a 或 b 的倍数。

## 复杂度
时间 O(log(n·min(a,b)))，二分次数由 n 和 min(a,b) 的乘积决定，每次 O(1) 算 cnt。
空间 O(1)，只开了 lo/hi/mid/lcm 几个整数。

## 易错点
- 上界写成 `n*a` 而 a 不是较小值时 → hi 偏大仍正确但多跑几轮；若误写成 `n*max(a,b)` 之外的更小值（如 `n`）→ 会漏掉答案区间，二分解落在错误位置。正确用 `n * min(a, b)`。
- 忘记减 `x//lcm` → 示例 2 中 `mid=6` 会算成 `3+2=5 ≥ 4`，二分会提前收敛到 5 附近而非 6，答案错。必须用 `a*b//gcd(a,b)` 去重。
- 返回时对 `10**9+7` 取模要在二分结束后做，不能对 mid 取模，否则单调性被破坏。

## 如果面试官追问
问：若要求返回第 n 个神奇数本身而非取模值？答：直接返回 `lo`，二分过程中不取模，Python 大整数天然支持，无需改结构。
