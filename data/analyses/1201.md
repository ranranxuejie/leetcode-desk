## 一句话思路
用二分答案：对候选值 x 数出 ≤x 的丑数个数，找第一个计数 ≥ n 的 x。

## 怎么做
1. 计数公式：`cnt(x) = x//a + x//b + x//c - x//lcm(a,b) - x//lcm(a,c) - x//lcm(b,c) + x//lcm(a,b,c)`，容斥去重。
2. 二分区间 `lo, hi = 1, 2*10**9`，`cnt(mid) < n` 则 `lo = mid+1`，否则 `hi = mid`。
3. 返回 `lo`。

拿示例 1（n=3, a=2, b=3, c=5）走一步：`lcm(2,3)=6, lcm(2,5)=10, lcm(3,5)=15, lcm(2,3,5)=30`。取 `mid=4`，`cnt = 4//2+4//3+4//5 - 4//6-4//10-4//15 + 4//30 = 2+1+0-0-0-0+0 = 3`，`3 >= n`，所以 `hi=4`；最终 `lo=4`，与输出一致。

```python
from math import gcd

def lcm(x, y):
    return x // gcd(x, y) * y

def cnt(x, a, b, c):
    ab, ac, bc = lcm(a, b), lcm(a, c), lcm(b, c)
    abc = lcm(ab, c)
    return x//a + x//b + x//c - x//ab - x//ac - x//bc + x//abc

lo, hi = 1, 2 * 10**9
while lo < hi:
    mid = (lo + hi) // 2
    if cnt(mid, a, b, c) < n:
        lo = mid + 1
    else:
        hi = mid
return lo
```

## 复杂度
时间：二分 log(2*10^9) ≈ 31 轮，每轮 7 次整除，与 n 无关。
空间：只存几个 lcm 和边界，O(1)。

## 易错点
- 直接用 `a*b` 当 lcm → 如 a=b=2 时 `lcm` 应为 2 却算成 4，`x//4` 把重复项多减一次，计数偏小。必须先 `x//gcd(x,y)*y`，且先除后乘避免中间值过大。
- 三个数两两相同（如 a=b=c=2）→ 容斥里 `x//ab` 等三项和 `x//abc` 会重复扣加，若 lcm 算错就整体错位。正确做法是让 lcm 函数对相同输入返回自身，公式自然成立。

## 如果面试官追问
问：若 a、b、c 可含 1 怎么办？
答：公式不变，`x//1 = x`，计数直接等于 x，二分照样返回 n，无需特判。
