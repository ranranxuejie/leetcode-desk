## 一句话思路
区间 DP：`dp[i][j]` 记当前玩家在 `stones[i..j]` 上能取得的最大净胜分，靠「拿左/拿右」两种转移取 max。

## 怎么做
1. 先算前缀和 `pre`，使 `sum(i,j) = pre[j+1]-pre[i]` 为 O(1)。
2. 定义 `dp[i][j]` = 轮到某人面对 `stones[i..j]` 时，他相对对手能多拿的分。
3. 转移：拿左得 `sum(i+1,j) - dp[i+1][j]`，拿右得 `sum(i,j-1) - dp[i][j-1]`，取较大者；减号是因为之后轮到对手。
4. 按区间长度从 2 递增填表，答案 `dp[0][n-1]`。

以 `stones=[5,3,1,4,2]` 为例，`pre=[0,5,8,9,13,15]`。长度 2 时 `dp[3][4]=max(sum(4,4)-dp[4][4], sum(3,3)-dp[3][3])=max(2-0,4-0)=4`；长度 5 时 `dp[0][4]=max(sum(1,4)-dp[1][4], sum(0,3)-dp[0][3])=max(10-4,13-7)=6`，与输出一致。

```python
n = len(stones)
pre = [0] * (n + 1)
for i, v in enumerate(stones):
    pre[i + 1] = pre[i] + v
dp = [[0] * n for _ in range(n)]
for length in range(2, n + 1):
    for i in range(n - length + 1):
        j = i + length - 1
        take_left = pre[j + 1] - pre[i + 1] - dp[i + 1][j]
        take_right = pre[j] - pre[i] - dp[i][j - 1]
        dp[i][j] = max(take_left, take_right)
return dp[0][n - 1]
```

## 复杂度
时间：O(n²)，两层区间枚举，每次转移 O(1)。
空间：O(n²) 存 `dp` 表，`pre` 额外 O(n)。

## 易错点
1. `stones=[5,3,1,4,2]` 若把得分写成「被移除石子的值」而非「剩余石子之和」，`dp[3][4]` 会算成 `max(4,2)=4` 但方向反了，长度 5 时得 4 而非 6；正确是 `sum(i+1,j)` 这种「剩余区间和」，用前缀和取 `pre[j+1]-pre[i+1]`。
2. 转移漏掉减 `dp` 或写成加 `dp`：`stones=[7,90,...]` 会把双方都当最大化，答案偏大；正确是 `sum - dp[...]`，因为对手的净胜分就是你的负收益。

## 如果面试官追问
问：n 到 10⁵ 怎么办？答：这题区间 DP 无法降维，只能换题；若只求单点可用记忆化搜索，规模仍 O(n²)。
