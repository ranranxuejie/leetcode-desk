## 一句话思路
利用 BST 左小右大的有序性，从根开始按 `val` 与当前节点值比较，每次只走一个分支，走到即返回。

## 怎么做
1. 令 `cur = root`，进入循环，条件是 `cur` 不为 `None`。
2. 比较 `val` 与 `cur.val`：相等就返回 `cur`；`val < cur.val` 就 `cur = cur.left`；否则 `cur = cur.right`。
3. 循环结束仍未命中，返回 `None`。

以示例 1 的 `root = [4,2,7,1,3], val = 2` 为例：第一轮 `cur.val = 4`，`2 < 4` 走左子树，`cur` 变成 `2`；第二轮 `2 == 2`，直接返回以 `2` 为根的子树 `[2,1,3]`，右子树 `7` 根本没被访问。

```python
cur = root
while cur:
    if val == cur.val:
        return cur
    cur = cur.left if val < cur.val else cur.right
return None
```

关键点：每轮只做一次比较、只移动一次指针，不需要递归也不需要栈。示例 2 中 `val = 5`：`5 > 4` 走右到 `7`，`5 < 7` 走左到 `None`，循环退出返回 `None`，对应输出 `[]`。

## 复杂度
时间：O(h)，h 为树高，每层只走一个分支，最坏链状 O(n)。
空间：O(1)，只用了 `cur` 一个指针，无递归栈。

## 易错点
- 输入 `root = [4,2,7,1,3], val = 5` → 若写成「先递归左子树再递归右子树」的普通查找，会遍历整棵树才返回 `None`，复杂度退化成 O(n)；正确做法是每层只根据 `val` 与 `cur.val` 的大小关系选一边，`5 > 4` 后不再碰左子树。
- 输入 `root = [4,2,7,1,3], val = 2` → 若返回 `cur.val` 或 `True` 而不是节点本身，输出就不是 `[2,1,3]`；题目要的是「以该节点为根的子树」，必须 `return cur`，让调用方从该节点继续读 `left`/`right`。

## 如果面试官追问
问：如果这棵树不是 BST 而是普通二叉树怎么办？
答：有序性失效，只能 DFS/BFS 全树找 `val`，时间从 O(h) 退化到 O(n)，需额外 O(h) 栈或 O(n) 队列。
