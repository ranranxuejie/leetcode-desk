## 一句话思路
按长度排序后做 DP：`dp[w]` 表示以 `w` 结尾的最长链长，枚举删掉 `w` 的每个字符得到前身去查表。

## 怎么做
1. 把 `words` 按长度升序排序，保证算 `dp[w]` 时所有更短的前身都已算过。
2. 对每个 `w`，枚举删除下标 `i`（`0..len(w)-1`）得到候选前身 `pre = w[:i] + w[i+1:]`。
3. 若 `pre` 在 `dp` 中，则 `dp[w] = max(dp[w], dp[pre] + 1)`，否则至少为 1。
4. 用哈希表存 `dp`，边算边更新答案。

以示例 1 为例，排序后为 `["a","b","ba","bca","bda","bdca"]`。算到 `"bda"` 时，删下标 1 得 `"ba"`，`dp["ba"]=2`，故 `dp["bda"]=3`；算到 `"bdca"` 时删下标 2 得 `"bda"`，得 `dp["bdca"]=4`。

```python
words.sort(key=len)
dp = {}
ans = 1
for w in words:
    best = 1
    for i in range(len(w)):
        pre = w[:i] + w[i+1:]
        if pre in dp:
            best = max(best, dp[pre] + 1)
    dp[w] = best
    ans = max(ans, best)
```

注意 `pre` 用切片拼接，长度 16 时开销可忽略；不要用 `set` 存 `dp`，否则拿不到 `dp[pre]` 的值。

## 复杂度
时间：O(n · L²)，n 为单词数，每个词枚举 L 个删除位、每次切片 O(L)。
空间：O(n · L)，`dp` 存下全部单词及其长度。

## 易错点
- 输入含重复单词如 `["a","a"]` → 若用 `dp[w] = best` 覆盖，重复词会互相干扰；正确做法是重复词结果相同，覆盖无害，但别在 `pre == w` 时误判自环（删一个字符长度必减 1，不会自环）。
- 输入 `["abcd","dbqca"]` → 若只比较长度差 1 就认为成链，会错答 2；正确做法是必须真正删字符后与 `pre` 精确相等，`"dbqca"` 删任何一位都得不到 `"abcd"`，答案应为 1。

## 如果面试官追问
问：若要求输出具体链而非长度？答：`dp` 里额外存前驱单词，最后从最长链末端回溯即可。
