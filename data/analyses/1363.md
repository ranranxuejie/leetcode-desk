## 一句话思路
按位从大到小拼接必然最大，只需用数字和模 3 的余数决定删哪 1 或 2 个最小的数。

## 怎么做
1. 统计每个数字出现次数 `cnt[0..9]`，求和 `s = sum(digits)`。
2. `s % 3 == 0` 时全部保留；余 1 时删一个模 3 余 1 的最小数字，没有就删两个模 3 余 2 的最小数字；余 2 对称处理。
3. 从 9 到 0 按 `cnt` 重复输出，最后处理全零与前导零。

以 `digits = [8,6,7,1,0]` 为例：`s = 22`，`22 % 3 == 1`。模 3 余 1 的数字有 7、1，删最小的 1，`cnt[1]` 从 1 变 0，剩下 8、6、7、0，拼成 `"8760"`。

```python
s = sum(digits)
cnt = [0] * 10
for d in digits:
    cnt[d] += 1
r = s % 3
if r:
    for m in ([1, 2] if r == 1 else [2, 1]):
        for d in range(1, 10):
            if cnt[d] and d % 3 == m:
                cnt[d] -= 1
                r = 0
                break
        if r == 0:
            break
        # 删两个：同一余数类里取两个最小的
        need = 2
        for d in range(1, 10):
            while cnt[d] and d % 3 == m and need:
                cnt[d] -= 1
                need -= 1
        if need == 0:
            break
res = ''.join(str(d) * cnt[d] for d in range(9, -1, -1))
return res.lstrip('0') or ('0' if cnt[0] else '')
```

## 复杂度
时间 O(n + 10)，n 是 `digits` 长度，计数与拼接各扫一遍。
空间 O(1)，只开了长度 10 的 `cnt` 和结果字符串。

## 易错点
- 输入 `[1]`：`s % 3 == 1`，删掉唯一的 1 后 `cnt` 全零，若直接 `''.join(...)` 返回 `""` 正确；但输入 `[0]` 时 `s % 3 == 0` 不删，拼接得 `"0"`，`lstrip('0')` 会变空串，必须回退成 `"0"`。
- 输入 `[1,1,1,2]`：`s = 5`，余 2，模 3 余 2 的数字只有 2，删它得 `"111"`；若先按余 1 删两个 1 会得到 `"112"`，比 `"111"` 小，必须严格按「先删 1 个、删不掉再删 2 个」的顺序。

## 如果面试官追问
问：若要求返回所有不同的最大倍数方案？
答：在删数那步枚举同余类中所有等价的删除组合，用集合去重后逐个拼接。
