## 一句话思路
前缀和相同则中间那段和为 0，用哈希表记录每个前缀和**最后**出现的位置，一次遍历直接跳过整段。

## 怎么做
1. 建哑节点 `dummy` 指向 `head`，从 `dummy` 开始算前缀和 `s`，用字典 `last[s] = 节点` 记录每个和**最后**出现的位置。
2. 第二次从 `dummy` 遍历，重算 `s`，令 `cur.next = last[s].next`，一步跨过 `(last[s], cur]` 这段和为 0 的区间。
3. 返回 `dummy.next`。

以 `[1,2,-3,3,1]` 为例：第一遍得到 `last = {0: dummy, 1: 节点1, 3: 节点2, 0: 节点3, 3: 节点4, 4: 节点5}`——注意 `0` 和 `3` 都被覆盖成靠后的节点。第二遍从 `dummy` 出发，`s=0` 时 `last[0]` 是节点 3（值为 -3 那个），于是 `dummy.next` 直接指向节点 3 的 `next`，即值为 3 的节点，前三个节点 `1,2,-3` 整段被摘掉；接着 `s=3` 时 `last[3]` 是节点 4，`cur` 停在节点 3 上，`cur.next` 指向节点 4 的 `next`，值为 1 的节点保留。结果 `[3,1]`。

```python
dummy = ListNode(0, head)
last, s, cur = {}, 0, dummy
while cur:
    s += cur.val
    last[s] = cur
    cur = cur.next
s, cur = 0, dummy
while cur:
    s += cur.val
    cur.next = last[s].next
    cur = cur.next
return dummy.next
```

关键点：第一遍必须**覆盖**写 `last[s]`，保留最靠后的位置；第二遍每步都跳，跳完 `cur` 直接落到被保留的节点上，不会重复处理已删区间。

## 复杂度
时间 O(n)：两遍遍历，n 为节点数。
空间 O(n)：`last` 字典最多存 n+1 个不同前缀和。

## 易错点
- 输入 `[0]` 或 `[1,-1]` → 若 `last` 用 `setdefault` 只记第一次出现，`s=0` 会指回 `dummy` 自己，`dummy.next` 变成 `dummy.next` 原地打转或漏删 → 必须用覆盖赋值 `last[s] = cur`，让 `0` 指向最后一个前缀和为 0 的节点。
- 输入 `[1,2,-3,3,1]` → 若第二遍不重算 `s` 而是复用第一遍的字典键顺序，或跳过后忘记把 `cur` 移到 `last[s].next`，会漏掉 `3,1` 中 `s=3` 的第二次匹配 → 第二遍必须从 `dummy` 重新累加 `s`，且 `cur = cur.next` 放在赋值之后。

## 如果面试官追问
要求输出所有可能的删除方案而非任一方案，怎么办？
答：前缀和相同的区间互相嵌套，用 DFS 枚举每对相同前缀和的切分点，指数级但 n≤1000 时需剪枝。
