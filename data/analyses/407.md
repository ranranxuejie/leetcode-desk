## 一句话思路
从边界向内做小顶堆 BFS，每个格子能存的水由「到边界路径上的最低高度」决定。

## 怎么做
1. 把所有边界格子 `(heightMap[i][j], i, j)` 压入小顶堆，并标记 `visited`。
2. 每次弹出堆顶最小高度 `h`，向四邻扩展；邻格 `nh` 若未访问，则 `ans += max(0, h - nh)`，并把 `max(h, nh)` 入堆。
3. 重复直到堆空，返回 `ans`。

以示例 2 的 5×5 为例：边界全是 3，先入堆。弹出 3 扩展到内圈 `(1,1)=2`，`ans += 3-2 = 1`，入堆 `max(3,2)=3`；继续向内到中心 `(2,2)=1`，此时堆顶仍是 3，`ans += 3-1 = 2`。四圈累加得 10。

```python
import heapq
m, n = len(heightMap), len(heightMap[0])
heap, visited, ans = [], set(), 0
for i in range(m):
    for j in range(n):
        if i in (0, m-1) or j in (0, n-1):
            heapq.heappush(heap, (heightMap[i][j], i, j))
            visited.add((i, j))
while heap:
    h, i, j = heapq.heappop(heap)
    for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
        ni, nj = i+di, j+dj
        if 0 <= ni < m and 0 <= nj < n and (ni, nj) not in visited:
            visited.add((ni, nj))
            ans += max(0, h - heightMap[ni][nj])
            heapq.heappush(heap, (max(h, heightMap[ni][nj]), ni, nj))
```

## 复杂度
时间：O(mn log(mn))，每个格子入堆一次，堆操作 log(mn)。
空间：O(mn)，`visited` 集合加堆最多存 mn 个元素。

## 易错点
- 输入 `[[1,4,3,1,3,2],[3,2,1,3,2,4],[2,3,3,2,3,1]]` 中 `(1,2)=1` 被四邻 3、2、3、3 围住，若只按「四邻最小值减自身」算会得 1，但正确水位是 2（`ans` 里它贡献 1）。必须用堆里传播的 `max(h, nh)` 而非局部最小值。
- 边界格子本身不能存水，若忘记先把边界全部入堆并标记 `visited`，内圈格子会被当作可存水，示例 2 会多算边界一圈的 0 或错算成 3。

## 如果面试官追问
问：若要求输出每个格子的水位矩阵而非总量？答：把 `ans += ...` 换成 `water[i][j] = max(0, h - heightMap[i][j])`，最后返回该矩阵即可。
