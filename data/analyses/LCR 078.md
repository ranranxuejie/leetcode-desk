## 一句话思路
用最小堆维护 k 个链表当前头节点，每次弹出全局最小并推进该链表，堆空即合并完成。

## 怎么做
1. 把每个非空 `lists[i]` 的头节点连同 `i` 一起压入堆，堆按节点值排序。
2. 建 `dummy` 哨兵和 `tail` 指针，循环直到堆空。
3. 每轮 `val, i = heappop(heap)`，把该节点接到 `tail.next`，`tail` 后移。
4. 若 `lists[i]` 还有后继，把后继压堆；否则该链表耗尽。

以示例 1 为例，初始堆为 `[(1,0),(1,1),(2,2)]`。第一次弹出 `(1,0)`，接上后把 `lists[0]` 的 `4` 压入，堆变成 `[(1,1),(2,2),(4,0)]`；第二次弹出 `(1,1)`，接上后压入 `3`，堆为 `[(2,2),(3,1),(4,0)]`。可见两个 `1` 都先出堆，顺序正确。

```python
import heapq
heap = []
for i, node in enumerate(lists):
    if node:
        heapq.heappush(heap, (node.val, i, node))
dummy = tail = ListNode(0)
while heap:
    val, i, node = heapq.heappop(heap)
    tail.next = node
    tail = node
    if node.next:
        heapq.heappush(heap, (node.next.val, i, node.next))
return dummy.next
```

关键点：堆里存 `(val, i, node)` 三元组，`i` 是必需的——两个节点值相同时 Python 会去比较第三个元素 `ListNode`，而链表节点没有定义 `<`，会直接抛 `TypeError`。

## 复杂度
时间 O(N log k)：N 为所有节点总数，每个节点进出堆各一次，堆大小不超过 k。
空间 O(k)：堆最多存 k 个节点，另加 dummy 一个哨兵。

## 易错点
- `lists = []` 或 `lists = [[]]` → 若直接 `heappush(heap, (lists[0].val, 0, lists[0]))` 会 `AttributeError` 或 `IndexError` → 压堆前必须判 `if node:`，空数组时堆为空、循环不执行，返回 `dummy.next` 即 `None`。
- 堆元素只存 `(val, node)` → 遇到示例 1 中两个值都为 `1` 的节点时，Python 比较到第二个元素 `ListNode` 抛 `TypeError` → 必须加 `i` 作为第二关键字，把节点挤到第三位，保证比较永远停在整数上。

## 如果面试官追问
若 k 远大于 N（大量空链表），堆方案还划算吗？答：先过滤掉空链表再建堆，堆大小从 k 降到实际非空链表数，初始化开销随之下降。
