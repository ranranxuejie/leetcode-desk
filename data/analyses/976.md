## 一句话思路
排序后从大到小取连续三元组，第一个满足 `a+b>c` 的就是最大周长，因为更大的组合已被跳过。

## 怎么做
1. 对 `nums` 升序排序，让候选三元组按边长从大到小自然排列。
2. 从 `i = len(nums)-1` 往下扫，每次看 `nums[i-2], nums[i-1], nums[i]` 这三个相邻元素。
3. 只要 `nums[i-2] + nums[i-1] > nums[i]` 成立就立刻返回三者之和，扫完返回 0。

以 `nums = [2,1,2]` 为例：排序得 `[1,2,2]`，`i=2` 时取 `1,2,2`，`1+2=3 > 2` 成立，返回 `1+2+2=5`。

关键点在于「相邻」：若 `nums[i-2]+nums[i-1] <= nums[i]`，那么任何用 `nums[i]` 当最大边的组合（前两条边只会更小）都不成立，所以直接跳到 `i-1` 不丢解。

```python
nums.sort()
for i in range(len(nums) - 1, 1, -1):
    a, b, c = nums[i - 2], nums[i - 1], nums[i]
    if a + b > c:
        return a + b + c
return 0
```

注意 `range` 的终点是 `1`，保证 `i-2 >= 0`，不会越界。

## 复杂度
时间 O(n log n)：排序贡献 log n，单次倒序扫描 O(n)。
空间 O(1)：除排序内部开销外只用了 `a,b,c` 三个变量。

## 易错点
- 输入 `[1,2,1,10]` → 若只检查全局最大的三个 `2,1,10` 就判失败返回 0，但正确做法是继续往下扫，本题确实无解才返回 0；换成 `[3,4,5,100]` 时最大三个失败但 `3,4,5` 成立，答案是 12，漏扫就错。
- 输入 `[2,2,1,2]` → 若用 `a+b>=c` 判退化三角形，会把 `1,2,2` 之外的退化组合也算进去；本题要求面积非零，必须严格 `>`，等号情况（如 `[1,1,2]`）要跳过。

## 如果面试官追问
要求输出具体三条边而非周长？答：返回 `(a,b,c)` 即可，扫描逻辑不变，仍是第一个满足严格不等式的相邻三元组。
