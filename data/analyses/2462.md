## 一句话思路
用两个最小堆分别维护前 `candidates` 个和后 `candidates` 个候选工人，每轮取两堆顶较小者（相等取下标小），再从对应侧补入新工人。

## 怎么做
1. 初始化：左堆装 `costs[0..candidates-1]`，右堆装 `costs[n-candidates..n-1]`，用 `(cost, index)` 元组保证同代价比下标；左右指针 `l = candidates`、`r = n - candidates - 1`。
2. 每轮比较 `left[0]` 与 `right[0]`：若左堆顶 `(cost, i)` 的 cost 更小，或相等但 i 更小，就弹出左堆，累加 cost，若 `l <= r` 则把 `costs[l]` 压入左堆并 `l += 1`；否则对称操作右堆。
3. 重复 k 轮，返回累加和。

以示例 1 `costs = [17,12,10,2,7,2,11,20,8], k=3, candidates=4` 为例：初始左堆含下标 0-3 的 `(17,0)(12,1)(10,2)(2,3)`，右堆含下标 5-8 的 `(2,5)(11,6)(20,7)(8,8)`。第一轮两堆顶都是 cost=2，取下标小的 3，弹出后 `l=4`，把 `costs[4]=7` 压入左堆。第二轮左堆顶变 `(7,4)`，右堆顶仍 `(2,5)`，取 5，`r=4`，此时 `l=4 > r=4` 不再补入。第三轮左堆顶 `(7,4)` 对右堆顶 `(8,8)`，取 4，总代价 `2+2+7=11`。

```python
import heapq
left = [(costs[i], i) for i in range(candidates)]
right = [(costs[i], i) for i in range(n - candidates, n)]
heapq.heapify(left); heapq.heapify(right)
l, r, total = candidates, n - candidates - 1, 0
for _ in range(k):
    if left and (not right or left[0] <= right[0]):
        c, _ = heapq.heappop(left)
        if l <= r: heapq.heappush(left, (costs[l], l)); l += 1
    else:
        c, _ = heapq.heappop(right)
        if l <= r: heapq.heappush(right, (costs[r], r)); r -= 1
    total += c
```

## 复杂度
时间：O((n + k) log candidates)，建堆 O(n)，每轮弹出压入各 O(log candidates)。
空间：O(candidates)，两个堆合计最多 2·candidates 个元组。

## 易错点
1. `n < 2*candidates` 时左右区间重叠（示例 2 中 `n=4, candidates=3`，下标 1、2 同时在两堆里）→ 若照常建两堆会把同一工人算两次 → 正确做法是建堆前判断 `if n <= 2*candidates`，直接把全部 `costs` 放进一个堆取 k 次。
2. 补入时用 `l <= r` 判断而非 `l < n` → 示例 1 第二轮后 `l=4, r=4`，若写成 `l < n` 会把已属于右堆范围的 `costs[4]` 再压进左堆造成重复 → 必须用 `l <= r` 保证左右指针不交叉。

## 如果面试官追问
问：若要求输出被雇佣工人的下标序列而非总代价？答：堆里存 `(cost, index)` 已带下标，每轮弹出时把 index 追加到结果列表即可，逻辑不变。
