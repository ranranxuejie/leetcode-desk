## 一句话思路
枚举黑棋第一步的每个候选落点，对每个落点判断「黑一步胜 / 白能否一步胜 / 黑能否两步胜」，因为三步内只有黑、白、黑三次落子。

## 怎么做
1. 候选落点只取已有棋子周围 4 格内的空点（五子棋连五必须紧贴已有棋子），用 `set` 去重，坐标范围 `-1e9` 到 `1e9` 不影响。
2. 对每个黑候选点 `p`，先看黑落 `p` 后是否已成五连，是则直接返回 `"Black"`。
3. 否则枚举白棋所有候选点 `q`，若白落 `q` 后成五连，说明黑这步 `p` 不行（白会赢），跳过 `p`。
4. 若白无论如何都不能一步胜，再看黑是否有第二个点 `r` 使黑落 `p`、`r` 后成五连，有则 `"Black"`；全部 `p` 失败返回 `"None"`。

以示例 2 为例：黑先落 `(2,2)` 后，白棋候选点里没有任何一点能让白成五连（白只有 `(1,2),(1,4),(1,5),(3,2),(4,2),(5,2)` 六子，缺 `(2,2)` 已被黑占），于是黑第二步补 `(2,2)` 附近即可连成 `(1,2)~(5,2)` 竖线，返回 `"Black"`。

```python
def win(board, x, y, c):
    for dx, dy in ((1,0),(0,1),(1,1),(1,-1)):
        cnt = 1
        for s in (1, -1):
            nx, ny = x + s*dx, y + s*dy
            while board.get((nx, ny)) == c:
                cnt += 1
                nx, ny = nx + s*dx, ny + s*dy
        if cnt >= 5:
            return True
    return False
```

关键中间值：`board` 用 `dict` 存 `(x,y)->color`，`win` 对四个方向双向延伸计数，`cnt >= 5` 即胜。

## 复杂度
时间：候选点 O(n) 个，每个黑点枚举白点 O(n)，再枚举黑第二点 O(n)，共 O(n^3)，n 为棋子数。
空间：`board` 字典与候选点集合各 O(n)。

## 易错点
1. 候选点只取棋子周围 4 格 → 若取更大范围（如 5 格）会漏判「黑两步胜」中第二步落在远端的情况，正确做法是候选集必须包含所有可能成五连的空位，即已有棋子同一直线上两端延伸 4 格内的点。
2. 白棋一步胜的判断顺序 → 若先判黑两步胜再判白一步胜，会把「黑落 p 后白立即五连」误判为黑胜，正确做法是每个黑候选点 p 先排除白一步胜，再判黑两步胜。

## 如果面试官追问
若要求输出具体落子方案而非仅胜负？答：在返回 `"Black"` 时同时记录使黑成五连的 `p` 和 `r`，白一步胜时记录 `q`，按落子顺序输出即可。
