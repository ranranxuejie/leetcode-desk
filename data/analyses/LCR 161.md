## 一句话思路
用 Kadane 动态规划：以每天结尾的最大子段和，要么接上前一天，要么从今天重新开始。

## 怎么做
1. 定义 `cur` 为「必须以当前元素结尾」的最大和，`best` 为全局答案，二者都初始化为 `sales[0]`。
2. 从左到右遍历 `sales[1:]`，每步执行 `cur = max(sales[i], cur + sales[i])`。
3. 每步用 `best = max(best, cur)` 更新全局答案。
4. 返回 `best`。

拿示例 1 的 `sales = [-2,1,-3,4,-1,2,1,-5,4]` 走关键几步：到 `4` 时 `cur = max(4, -2+4) = 4`；接着 `-1` 得 `3`，`2` 得 `5`，`1` 得 `6`，此时 `best = 6`；再遇 `-5` 得 `1`，遇 `4` 得 `5`，`best` 保持 6。

```python
cur = best = sales[0]
for x in sales[1:]:
    cur = max(x, cur + x)
    best = max(best, cur)
return best
```

核心是 `cur + x` 与 `x` 的比较：`cur` 为负时，接上它只会拖累，直接丢弃、从 `x` 重新起头。示例 1 中 `cur` 在 `-2` 后变 `-1`，到 `1` 时 `max(1, -1+1)=1`，正是「重新开始」生效的位置。

## 复杂度
时间 O(n)：一次遍历 `sales`，每个元素做两次 `max`。
空间 O(1)：只开 `cur`、`best` 两个变量，不复制数组。

## 易错点
- 全负数输入如 `sales = [-3,-1,-2]` → 若把 `best` 初始化为 0，会错答 0 → 必须初始化为 `sales[0]`，正确答案是 `-1`（单天 `-1`）。
- 忘记「必须连续」而把正数全加起来 → 示例 1 会错答 `1+4+2+1+4=12` → 正确做法是每步只允许接上前一天的 `cur`，遇到 `-5` 这类断点后 `cur` 从 `1` 重新累积，最终得 6。

## 如果面试官追问
要求返回子数组起止下标怎么办？答：在 `cur` 被 `x` 重置时记 `start = i`，在 `best` 被刷新时记 `best_start, best_end = start, i`，多两个变量仍是 O(1) 空间。
