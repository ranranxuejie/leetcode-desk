## 一句话思路
用 26 位掩码记录出现过的字母，遍历时若 `mask & bit` 非零说明重复，否则把该位并入 `mask`。

## 怎么做
1. 初始化 `mask = 0`，它表示"已出现字母集合"。
2. 对 `astr` 中每个字符 `ch`，算出 `bit = 1 << (ord(ch) - ord('a'))`。
3. 若 `mask & bit` 非零，立即返回 `False`；否则 `mask |= bit`。
4. 遍历结束返回 `True`。

以 `astr = "leetcode"` 为例：前 4 个字符 `l,e,e` 中，处理到第二个 `e` 时 `mask` 已含 `e` 对应的位（`ord('e')-ord('a') = 4`，即 `1 << 4 = 16`），`mask & 16` 得 16 非零，直接返回 `False`，不必扫完剩下的 `tcode`。

```python
mask = 0
for ch in astr:
    bit = 1 << (ord(ch) - ord('a'))
    if mask & bit:
        return False
    mask |= bit
return True
```

关键点：`bit` 只由 `ch` 决定，`mask` 只增不减，所以"某位已置 1"等价于"该字母此前出现过"。`len(astr) > 26` 时可直接返回 `False`，因为小写字母只有 26 个，这是可选的提前剪枝。

## 复杂度
时间 O(n)：`n = len(astr)`，每个字符做一次移位和两次位运算，常数时间。
空间 O(1)：只开一个 `mask` 整数，26 位远小于机器字长。

## 易错点
- 输入 `astr = ""` → 若先写 `if len(astr) > 26: return False` 之外的判断顺序搞反，或误以为空串非法 → 空串应返回 `True`，循环零次直接落到 `return True`，别在开头加 `if not astr: return False`。
- 输入含大写或非字母（题面保证不会，但若放宽约束）→ 仍用 `ord(ch) - ord('a')` 会得到负数，`1 << 负数` 在 Python 抛 `ValueError` → 应先判断 `'a' <= ch <= 'z'`，或改用 `set` 兜底。

## 如果面试官追问
问：若字符集扩到全部 ASCII（128 个）怎么办？
答：掩码换成 128 位整数照样 O(1)，或直接用 `set`，空间仍是常数级。
