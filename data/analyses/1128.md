## 一句话思路
把每张骨牌归一化成 `(min, max)` 做键，用哈希表边计数边累加已出现的同键数量。

## 怎么做
1. 遍历 `dominoes`，对每张 `[a, b]` 取 `key = (a, b) if a <= b else (b, a)`，让 `[1,2]` 和 `[2,1]` 落到同一个键。
2. 用字典 `cnt` 记录每个键已出现的次数，当前这张能配成的对数就是 `cnt.get(key, 0)`，直接累加进答案。
3. 累加后再把 `cnt[key]` 加一，保证不会把自己和自己配对（题目要求 `i < j`）。

以示例 1 的 `[[1,2],[2,1],[3,4],[5,6]]` 为例：第一张键是 `(1,2)`，`cnt` 为空，答案加 0，`cnt` 变成 `{(1,2): 1}`；第二张 `[2,1]` 归一化后仍是 `(1,2)`，`cnt.get((1,2), 0)` 返回 1，答案变成 1，`cnt` 变成 `{(1,2): 2}`；后两张键 `(3,4)`、`(5,6)` 都是首次出现，各加 0。最终返回 1。

```python
cnt = {}
ans = 0
for a, b in dominoes:
    key = (a, b) if a <= b else (b, a)
    ans += cnt.get(key, 0)
    cnt[key] = cnt.get(key, 0) + 1
return ans
```

示例 2 里 `[1,2]` 出现三次，键 `(1,2)` 依次贡献 0、1、2，合计 3，正好是输出。

## 复杂度
时间 O(n)：遍历 `dominoes` 一次，每张骨牌做常数次字典操作。
空间 O(n)：`cnt` 最多存 n 个不同的键，键是二元组。

## 易错点
- 忘记归一化：输入 `[[1,2],[2,1]]` 时若直接用 `(a, b)` 当键，两张骨牌落到 `(1,2)` 和 `(2,1)` 两个桶，答案错成 0；必须先取 `min/max` 再入表。
- 先加计数后累加答案：同一张骨牌会和自己配对，`[[1,2]]` 这种单元素输入会错成 1；正确顺序是先 `ans += cnt.get(key, 0)`，再 `cnt[key] += 1`。

## 如果面试官追问
追问：骨牌值域从 1..9 放大到 1..10^9 怎么办？
答：键换成 `min * base + max`（`base` 取 10^9+1）做整数编码，哈希表方案和 O(n) 复杂度不变。
