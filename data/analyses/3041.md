## 一句话思路
排序后按值域做 DP，`dp[x]` 表示以 x 结尾的最长连续段长度，每个值最多被 +1 一次。

## 怎么做
1. 排序 `nums`，用哈希表 `dp` 记录「以值 v 结尾的最长连续段长度」。
2. 对每个 `x`，先算「不把 x 加 1」的贡献：`dp[x] = dp.get(x-1, 0) + 1`。
3. 再算「把 x 加 1」的贡献：`dp[x+1] = max(dp[x+1], dp.get(x, 0) + 1)`，注意此时 `dp[x]` 已含 x 本身，所以是 `dp[x] + 1` 而非 `dp[x-1]+2`。
4. 答案取所有 `dp` 值的最大值。

以 `nums = [2,1,5,1,1]` 排序后为 `[1,1,1,2,5]`。处理到第二个 `1` 时，`dp[1]` 从 1 变 2；处理 `2` 时 `dp[2] = dp[1]+1 = 3`，这就是答案 3。关键中间值：`dp = {1:3, 2:3, 5:1, 6:1}`，最大值 3。

```python
nums.sort()
dp = {}
for x in nums:
    dp[x] = dp.get(x - 1, 0) + 1
    dp[x + 1] = max(dp.get(x + 1, 0), dp[x] + 1)
return max(dp.values())
```

注意第 3 行必须在第 2 行之后：`dp[x]` 已把当前 x 计入，`dp[x+1]` 才能接上「x 加 1」这条链。若先写 `dp[x+1]` 再写 `dp[x]`，`dp[x]` 还是旧值，会少算一个。

## 复杂度
时间 O(n log n)：排序贡献 log n，单次遍历 O(n)。
空间 O(n)：`dp` 哈希表最多存 2n 个键。

## 易错点
- 输入 `[1,1,2]` → 若把两个 1 都 +1 得 `[2,2,2]`，误以为能凑 3 个连续 → 正确做法是只把其中一个 1 变 2，得 `[1,2,2]` 选 `[1,2]` 长度 2；DP 里 `dp[2]` 只从 `dp[1]` 继承一次，不会重复加。
- 输入 `[1,2,3]` → 若对每个 x 都无条件写 `dp[x+1] = dp[x]+1`，会把 3 推到 4，误得 4 → 正确做法是 `dp[x+1]` 取 `max`，且答案只取真实出现过的值域，`max(dp.values())` 里 4 的候选值来自 `dp[3]+1=4`，但 `dp[3]` 本身是 3，不会凭空多出元素。

## 如果面试官追问
若要求输出具体选了哪些元素？答：在 `dp` 更新时额外记录前驱值，最后从最大值回溯，沿 `x-1` 或 `x` 链还原即可。
