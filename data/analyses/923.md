## 一句话思路
先统计每个值的出现次数，再按值枚举三元组并用组合数计数，避免下标重复。

## 怎么做
1. 用 `Counter(arr)` 得到 `cnt`，键是值，值是出现次数。
2. 枚举 `x <= y <= z` 且 `x + y + z == target` 的所有值组合，只枚举 `cnt` 中存在的值。
3. 按三者是否相等分三种情况算组合数：全等 `C(c,3)`、两等 `C(c,2)*c3`、全异 `c1*c2*c3`。
4. 累加后对 `10**9 + 7` 取模。

以示例 1 为例，`cnt = {1:2, 2:2, 3:2, 4:2, 5:2}`，`target = 8`。枚举到 `(1,2,5)` 时三者全异，贡献 `2*2*2 = 8`；枚举到 `(2,2,4)` 时 `x == y != z`，贡献 `C(2,2)*2 = 1*2 = 2`。四组分别得 8、8、2、2，合计 20。

```python
from collections import Counter
from math import comb

def three_sum_multi(arr, target):
    MOD = 10**9 + 7
    cnt = Counter(arr)
    vals = sorted(cnt)
    ans = 0
    for i, x in enumerate(vals):
        for j in range(i, len(vals)):
            y = vals[j]
            z = target - x - y
            if z < y or z not in cnt:
                continue
            if x == y == z:
                ans += comb(cnt[x], 3)
            elif x == y:
                ans += comb(cnt[x], 2) * cnt[z]
            elif y == z:
                ans += comb(cnt[y], 2) * cnt[x]
            else:
                ans += cnt[x] * cnt[y] * cnt[z]
    return ans % MOD
```

## 复杂度
时间：O(n + V²)，n 是数组长度，V 是不同值个数（≤101），排序贡献 O(V log V)。
空间：O(V)，`cnt` 字典存每个不同值的计数。

## 易错点
- `arr = [1,1,2,2,2,2], target = 5` → 若用双指针按下标枚举，会把同一个 `(1,2,2)` 值组合重复计入多次，得到远大于 12 的结果 → 必须按值枚举，用 `comb(cnt[2], 2) = 6` 一次算清。
- `arr = [0,0,0,0], target = 0` → 若在 `x == y == z` 时写成 `cnt[x]**3`，会得 64，正确是 `C(4,3) = 4` → 三值相等必须用组合数而非幂。

## 如果面试官追问
问：若 `arr[i]` 范围放大到 10^9 怎么办？
答：值域变大后 V 可能接近 n，O(V²) 退化为 O(n²)，此时改用排序加双指针枚举前两个值、第三值二分查找，仍是 O(n²) 但常数更小。
