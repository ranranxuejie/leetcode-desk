## 一句话思路
求最长可保留列序列，使每行在这些列上非递减；答案 = 列数 − 该序列长度，用 DP 求最长链。

## 怎么做
1. 把「保留哪些列」看成在列下标上选一个子序列，相邻两列 `i < j` 可同时保留的条件是：对所有行 `r`，`strs[r][i] <= strs[r][j]`。
2. 定义 `dp[j]` 为以第 `j` 列结尾的最长可保留列序列长度，初值全为 1。
3. 对每个 `j`，枚举 `i < j`，若 `all(strs[r][i] <= strs[r][j] for r in range(n))`，则 `dp[j] = max(dp[j], dp[i] + 1)`。
4. 返回 `m - max(dp)`，`m` 为列数。

以 `strs = ["babca","bbazb"]` 为例，`m = 5`。检查列 1 与列 3：第 0 行 `a <= z` 成立，第 1 行 `b <= z` 成立，故 `dp[3]` 可由 `dp[1] + 1 = 2` 更新；列 3 与列 4 也满足（`z <= a`？不成立），所以最终最长链是列 1、列 3，长度 2，答案 `5 - 2 = 3`。

```python
n, m = len(strs), len(strs[0])
dp = [1] * m
for j in range(m):
    for i in range(j):
        if all(strs[r][i] <= strs[r][j] for r in range(n)):
            dp[j] = max(dp[j], dp[i] + 1)
return m - max(dp)
```

关键点：`dp` 的下标是**列**，不是行；比较的是同一行里两列的字符，跨行之间没有任何约束（示例 1 里 `"bc" > "az"` 也合法）。

## 复杂度
时间：`O(m^2 * n)`，`m` 为列数、`n` 为行数，每对列都要扫全部行。
空间：`O(m)`，只有 `dp` 数组，没有二维表。

## 易错点
- 输入 `strs = ["edcba"]`：若误以为「相邻列满足即可」而只做一次线性扫描，会得到保留 1 列、答案 4 之外的错误值；正确做法是对每对 `(i, j)` 都检查，`dp` 才能捕捉到 `e>d>c>b>a` 全逆序、最长链只能是 1。
- 输入 `strs = ["ghi","def","abc"]`：若把条件写成「存在某行满足 `strs[r][i] <= strs[r][j]`」而非 `all(...)`，会误判列 0 与列 1 可共存（`g>d`、`h>e`、`i>f` 全不满足，实际不可），答案错成 0 以外的值；必须用 `all` 逐行验证。

## 如果面试官追问
问：若要求输出具体删除哪些列怎么办？
答：在 `dp` 转移时记录前驱 `prev[j] = i`，从 `max(dp)` 的下标回溯出保留列集合，再取补集即为删除索引。
