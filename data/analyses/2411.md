## 一句话思路
从右往左维护「以 i+1 开头各后缀的或值集合」，去重后最多 30 个，再与 nums[i] 或一次取最短。

## 怎么做
1. 倒序遍历 i，把 nums[i] 与上一轮集合里每个或值再或一次，得到以 i 开头的候选或值。
2. 集合按或值去重（或值相同只留最短长度），因为或值单调不减且位数有限，规模 ≤ 30。
3. 取候选里最大的或值，其对应最短长度即 answer[i]。
4. 用示例 1 走 i=2：上一轮（i=3）集合为 {1:1, 3:2}，与 nums[2]=2 或得 {3:1, 3:2}，去重后 {3:1}，answer[2]=1？实际应为 2——注意 nums[2]=2 单独或值为 2，需保留 {2:1, 3:2}，最大 3 对应长度 2。

```python
n = len(nums)
ans = [0] * n
cur = {}  # 或值 -> 最短长度
for i in range(n - 1, -1, -1):
    nxt = {nums[i]: 1}
    for v, l in cur.items():
        nv = v | nums[i]
        if nv not in nxt or nxt[nv] > l + 1:
            nxt[nv] = l + 1
    best = max(nxt)
    ans[i] = nxt[best]
    cur = nxt
```

## 复杂度
时间 O(n·30)：每个 i 只遍历 ≤30 个不同或值。
空间 O(30)：cur/nxt 字典各存 ≤30 项，ans 占 O(n)。

## 易错点
- 输入 `[1,2]`：若只保留最大或值而丢掉较小或值，i=0 时 cur 只有 {2:1}，与 1 或得 3，长度 2 正确；但若在 i=1 时把 {2:1} 误当唯一候选，会漏掉 nums[1]=2 本身，导致 answer[1] 错。正确做法是每轮先把 nums[i] 单独放入 nxt。
- 输入 `[1,0,2,1,3]`：若不去重，cur 会随 i 增长到 O(n)，超时；必须用字典按或值合并，同或值只留最短长度。

## 如果面试官追问
若要求输出具体子数组而非长度？答：在字典里同时存结束下标，取最大或值对应最短长度的那个下标即可。
