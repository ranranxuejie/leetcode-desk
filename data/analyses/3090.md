## 一句话思路
用滑动窗口维护 `[left, right]`，窗口内每个字符计数不超过 2 就右扩，超了就左缩。

## 怎么做
1. 初始化 `cnt = [0]*26`、`left = 0`、`ans = 0`，`right` 从 0 遍历到 `len(s)-1`。
2. 把 `s[right]` 计入 `cnt`，若该字符计数变成 3，则循环右移 `left` 并递减 `cnt[s[left]]`，直到它回到 2。
3. 每轮用 `right - left + 1` 更新 `ans`。

以 `s = "bcbbbcba"` 为例：`right` 走到 3（字符 `b`）时，窗口 `[0,3]` 里 `b` 出现 3 次，`left` 从 0 移到 1，`cnt['b']` 由 3 降回 2，此时窗口 `"cbbb"` 长度 4 被记入 `ans`；后续 `right` 到 7 时窗口收缩为 `"bcba"`，长度仍是 4。

```python
cnt = [0] * 26
left = ans = 0
for right, ch in enumerate(s):
    i = ord(ch) - 97
    cnt[i] += 1
    while cnt[i] > 2:
        cnt[ord(s[left]) - 97] -= 1
        left += 1
    ans = max(ans, right - left + 1)
```

关键点：`while` 条件只看**当前新进窗口的那个字符** `i`，因为收缩前其他字符都合法，只有它可能被撑到 3。

## 复杂度
时间 O(n)：`right` 和 `left` 各单向走一遍，每个字符最多进出窗口一次。
空间 O(1)：`cnt` 固定 26 个槽，与 `n` 无关。

## 易错点
- 输入 `"aaaa"`：若把 `while cnt[i] > 2` 写成 `if`，`left` 只移一格，`cnt['a']` 停在 3，窗口 `[1,3]` 仍非法，答案会错成 3；必须用 `while` 收缩到计数回到 2。
- 输入 `"bcbbbcba"`：若收缩时忘了同步 `cnt[ord(s[left]) - 97] -= 1`，只挪 `left` 不减计数，`cnt['b']` 永远降不下来，`while` 死循环或窗口被压成 1；挪指针和减计数必须成对出现。

## 如果面试官追问
若把「最多两次」改成「最多 k 次」怎么办？答：把 `while cnt[i] > 2` 换成 `> k`，其余不变，复杂度仍是 O(n)。
