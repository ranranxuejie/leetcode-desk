## 一句话思路
对每个连通块做二分图染色，块内最大组数等于「以每个点为起点的染色深度」的最大值，各块相加。

## 怎么做
1. 建邻接表，遍历 1..n，对未染色的点启动 BFS，同时记录它属于哪个连通块。
2. 染色时若发现 `color[v] == color[u]`，说明块内有奇环，直接返回 -1。
3. 对每个连通块，从块内每个点各做一次 BFS，取 `max(dist)` 作为该块的贡献。
4. 所有块贡献求和即为答案。

以示例 1 为例，块 {1,2,3,4,5,6} 从节点 5 出发 BFS 得 dist: 5→0, 1→1, 2→2, 4→2, 3→3, 6→3，最大深度 3，加 1 得 4，与输出一致。

```python
from collections import deque

def bfs(start, adj, color, cid, c):
    q = deque([start])
    color[start] = 0
    comp[start] = cid
    far = 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                comp[v] = cid
                dist[v] = dist[u] + 1
                far = max(far, dist[v])
                q.append(v)
            elif color[v] == color[u]:
                return -1
    return far + 1
```

关键点：块内最大组数不是「一次 BFS 的深度」，而是「所有起点里最深的那个」。示例 1 从节点 5 出发恰好最深，但从节点 3 出发只有 3 层，所以必须枚举块内每个点。

## 复杂度
时间：每个连通块做 k 次 BFS，k 为该块点数，总计 O(n·(n+m))，n≤500 可接受。
空间：邻接表 O(n+m)，color/dist/comp 三个数组各 O(n)。

## 易错点
- 只从一个点 BFS 一次就取深度 → 示例 1 若从节点 3 出发得 3 而非 4 → 必须对块内每个点各跑一次 BFS 取最大值。
- 把奇环判断写成「边数 ≥ 点数」→ 示例 2 三角形边数 3 点数 3 会漏判 → 正确做法是染色时检查 `color[v] == color[u]`，同色即冲突。

## 如果面试官追问
问：n 放大到 10^5 怎么办？
答：块内最大深度等于该块直径相关量，可用两次 BFS 求直径端点再取距离，降到 O(n+m)。
