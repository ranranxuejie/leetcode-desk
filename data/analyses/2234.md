## 一句话思路
排序后枚举「完善花园个数 k」，用前缀和 O(1) 算出把最小的 n-k 个抬到同一水位能到多高，取 `k*full + 水位*partial` 的最大值。

## 怎么做
1. 先给已经 ≥ target 的花园直接记入 `full` 收益，把它们从数组里剔除（再种花是浪费），剩下的升序排序。
2. 枚举 k = 剩余花园中要补成完善的花园个数，从最大的开始补，用 `need` 累加补满它们的代价。
3. 剩余 `newFlowers - need` 全部用来抬升最小的 `m = len - k` 个花园的水位，二分找最大可行水位 `level`（受 `target - 1` 封顶）。
4. 答案取 `(base + k) * full + level * partial` 的最大值。

以示例 1 为例：`flowers=[1,3,1,1]`，无花园达标，排序后 `[1,1,1,3]`，`newFlowers=7`。枚举 k=1 时补满 3 需 3 朵，剩 4 朵抬升前三个 `[1,1,1]`，水位到 2（花 3 朵），得 `1*12 + 2*1 = 14`。

```python
s = [0]
for x in a: s.append(s[-1] + x)
ans = 0
for k in range(len(a) + 1):
    m = len(a) - k
    if m == 0:
        ans = max(ans, (base + k) * full); break
    rem = newFlowers - need
    if rem < 0: break
    # 二分最大水位 level，使 m*level - s[m] <= rem
    lo, hi = a[0], target - 1
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if m * mid - s[m] <= rem: lo = mid
        else: hi = mid - 1
    ans = max(ans, (base + k) * full + lo * partial)
    need += target - a[m - 1]   # 下一轮把 a[m-1] 也补满
```

## 复杂度
时间：排序 O(n log n)，枚举 k 各做一次 O(log target) 二分，共 O(n log target)。
空间：前缀和数组 O(n)，其余 O(1)。

## 易错点
- `newFlowers` 可达 1e10，`need` 累加和 `m*mid - s[m]` 都会超 32 位；Python 整数无溢出，但若照抄 C++ 写法用 int 会错，答案本身也要用 long 承接。
- 水位二分上界必须取 `target - 1`：若允许抬到 `target`，这些花园其实已完善，应计入 `full` 而非 `partial`，否则示例 2 会算出 `3*2+5*6=36` 这种非法值（正确 30）。
- 枚举 k 时 `need` 要按「从大到小补」的顺序累加，且当 `rem < 0` 应立即 break，否则后续 k 更大只会更缺花。

## 如果面试官追问
问：若要求输出具体种花方案？答：记录每个 k 下的 `level` 和补满的花园下标，取最优 k 后回填，把前 m 个抬到 `level`、后 k 个补到 `target` 即可。
