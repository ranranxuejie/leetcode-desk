## 一句话思路
初始化时把每个值映射到它的坐标，查询时按坐标取四邻或四对角求和，避免每次扫描整个矩阵。

## 怎么做
1. 构造时遍历 `grid`，建 `pos[value] = (i, j)`，因为值域是 `[0, n^2-1]` 且不重复，可直接用列表当哈希表。
2. 两个查询共用一份方向偏移表：相邻 `[(-1,0),(1,0),(0,-1),(0,1)]`，对角 `[(-1,-1),(-1,1),(1,-1),(1,1)]`。
3. 查询时取 `i, j = pos[value]`，遍历偏移，越界的跳过，累加 `grid[i+di][j+dj]`。
4. 以示例 1 的 `adjacentSum(4)` 为例：`pos[4]=(1,1)`，四个方向得到 `(0,1)=1`、`(2,1)=7`、`(1,0)=3`、`(1,2)=5`，和为 16；`diagonalSum(8)` 时 `pos[8]=(2,2)`，只有 `(1,1)=4` 在界内，返回 4。

```python
n = len(grid)
pos = [None] * (n * n)
for i in range(n):
    for j in range(n):
        pos[grid[i][j]] = (i, j)

ADJ = ((-1, 0), (1, 0), (0, -1), (0, 1))
DIA = ((-1, -1), (-1, 1), (1, -1), (1, 1))

def query(value, dirs):
    i, j = pos[value]
    s = 0
    for di, dj in dirs:
        r, c = i + di, j + dj
        if 0 <= r < n and 0 <= c < n:
            s += grid[r][c]
    return s
```

## 复杂度
时间：构造 O(n²)，每次查询 O(1)（固定 4 个方向），总调用 2n² 次仍是 O(n²)。
空间：`pos` 长度 n² 存坐标，额外 O(n²)，未复制 grid。

## 易错点
- 边界值如示例 1 的 `diagonalSum(8)`（右下角）→ 若不加 `0 <= r < n` 判断会越界或读到上一行末尾的错值 → 必须对每个方向单独判界，不能只判 `i+di`。
- 示例 2 的 `adjacentSum(15)`，15 在 `(1,2)`，左邻是 7、右邻是 6 → 若把方向表写成行列颠倒（`(0,1)` 当上下）会得到 0、10、2、9 之类的错和 → 偏移统一按 `(di, dj)` 对应 `(行, 列)`，与 `grid[i][j]` 下标顺序一致。

## 如果面试官追问
若 grid 值域不再是 `[0, n^2-1]`（比如任意整数），怎么做？答：把 `pos` 换成 `dict`，构造仍 O(n²)，查询不变。
