## 一句话思路
用前缀异或哈希把「每个数出现偶数次」变成两个前缀哈希相等，再按左端点离线扫描 + 树状数组统计恰好 k 个不同值。

## 怎么做
1. 对 `nums` 做随机哈希 `h[x]`，令 `pre[i+1] = pre[i] ^ h[nums[i]]`，则子数组 `[l,r]` 全偶数次 ⟺ `pre[l] == pre[r+1]`。
2. 固定右端点 `r`，用 `last[x]` 记录每个值最近一次出现位置，维护「以 `r` 结尾、恰好 k 个不同值」的左端点区间 `[lo, hi]`：`hi` 是第 k 个不同值的最右出现位置，`lo` 是第 k+1 个不同值的最右出现位置 +1。
3. 把查询按 `r` 分组，扫描到 `r` 时对区间 `[lo, hi]` 内的左端点做「前缀哈希值 = pre[r+1]」的计数，用「哈希值 → 树状数组」按左端点下标存 1。
4. 查询 `[l,r]` 答案 = 该哈希值树状数组在 `[l, hi]` 的区间和 > 0。

以 `nums=[1,2,2,1], k=2` 为例，`r=3` 时 `pre[4]=0`，`lo=0, hi=0`（第 2 个不同值 1 的最右出现是 0，第 3 个不存在），只有 `l=0` 被计入，故 `[0,3]` 为 `True`。

```python
import random
h = {x: random.getrandbits(64) for x in set(nums)}
pre = [0]
for x in nums: pre.append(pre[-1] ^ h[x])
# 按 r 扫描，pos[hash] 是树状数组，add(l) / query(l..hi)
for r in range(n):
    # 更新 last[nums[r]]，重算 lo/hi
    for l, idx in bucket[r]:
        ans[idx] = bit_sum(pre[r+1], l, hi) > 0
```

## 复杂度
时间：`O((n + q) log n)`，每个元素和查询各一次树状数组操作。
空间：`O(n + q)`，存 `pre`、`last`、按哈希分桶的树状数组和查询分组。

## 易错点
- `k` 大于当前窗口不同值个数时，`hi` 无定义 → 若直接取 `last` 会越界或算错区间，正确做法是 `hi = -1` 使区间为空，查询直接 `False`（如示例 1 的 `[1,2]`，只有 1 个不同值）。
- 哈希碰撞：`pre[l] == pre[r+1]` 可能因随机哈希碰撞误判 → 用 64 位随机数，碰撞概率约 `q/2^64`，不要用 `nums[i]` 本身当哈希（如 `[1,2,2,1]` 会因 `1^2^2^1=0` 与空前缀混淆）。

## 如果面试官追问
若 `nums[i]` 范围扩大到 `10^9` 且要求确定性？答：改用「每个值映射到随机 64 位 + 双哈希」或对每个值维护出现次数的奇偶集合，用可持久化线段树比较两前缀的奇偶向量。
