## 一句话思路
只统计每行、每列被加的次数，单元格 (i,j) 的值是 `row[i]+col[j]`，判奇偶即可。

## 怎么做
1. 开两个数组 `row = [0]*m`、`col = [0]*n`，遍历 `indices` 累加对应行、列。
2. 单元格 (i,j) 的最终值等于 `row[i] + col[j]`，因为行加和列加互不干扰。
3. 双重循环数 `(row[i]+col[j]) % 2 == 1` 的格子数。

以示例 1 为例：`indices=[[0,1],[1,1]]` 处理后 `row=[1,1]`、`col=[0,2,0]`。看 (0,0)：`1+0=1` 奇数；(0,1)：`1+2=3` 奇数；(1,0)：`1+0=1` 奇数。逐格判完共 6 个。

```python
row = [0] * m
col = [0] * n
for r, c in indices:
    row[r] += 1
    col[c] += 1
ans = 0
for i in range(m):
    for j in range(n):
        if (row[i] + col[j]) % 2 == 1:
            ans += 1
```

进阶做法：设 `row` 中奇数个数 `ro`、偶数个数 `re`，`col` 中奇数 `co`、偶数 `ce`。和为奇数只有「一奇一偶」两种组合，答案 `ro*ce + re*co`，省掉双重循环。

## 复杂度
时间：O(len(indices) + m*n)，双重循环贡献 m*n，累加贡献 indices 长度。
空间：O(m + n)，只开了 row、col 两个计数数组。

## 易错点
- 把 `indices` 里的 `[ri, ci]` 当成只给单个格子加 1 → 示例 1 会算成 2 个奇数 → 正确是整行整列各加 1，用 row/col 分别累加。
- 用 `row[i] + col[j]` 时误以为交叉点被加了两次要减 1 → 示例 1 的 (1,1) 会算成 `1+2-1=2` 判偶 → 实际行加和列加是两次独立操作，交叉点本来就该加 2，不减。

## 如果面试官追问
问：m、n 到 10^9 但 indices 很小怎么办？
答：只对出现过的行、列建字典计数，答案用 `ro*ce + re*co` 公式算，不展开矩阵。
