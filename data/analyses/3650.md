## 一句话思路
把每条边拆成正向 `w`、反向 `2w` 两条弧建图，跑 Dijkstra；反向弧即「在终点用开关反转」。

## 怎么做
1. 对 `edges[i] = [u, v, w]`，向邻接表同时插入 `(v, w)` 到 `adj[u]` 和 `(u, 2*w)` 到 `adj[v]`。
2. 反向弧的代价是 `2*w`，正好对应「到达 v 后反转 u→v 并穿过」，无需额外状态。
3. 从 0 跑堆优化 Dijkstra，`dist[n-1]` 即答案，不可达返回 -1。

以示例 1 为例：`edges = [[0,1,3],[3,1,1],[2,3,4],[0,2,2]]`。建图后 `adj[1]` 含 `(0, 6)`（反转 0→1 的代价 2*3）和 `(3, 2)`（反转 3→1 的代价 2*1）。从 0 出发：`dist[1]=3`（走 0→1），弹出 1 后松弛 `adj[1]` 得 `dist[3]=3+2=5`，与 `dist[2]=2` 松弛出的 `dist[3]=2+4=6` 比较取 5，最终 `dist[3]=5`。

```python
import heapq
adj = [[] for _ in range(n)]
for u, v, w in edges:
    adj[u].append((v, w))
    adj[v].append((u, 2 * w))
dist = [float('inf')] * n
dist[0] = 0
pq = [(0, 0)]
while pq:
    d, u = heapq.heappop(pq)
    if d > dist[u]:
        continue
    for v, w in adj[u]:
        if d + w < dist[v]:
            dist[v] = d + w
            heapq.heappush(pq, (dist[v], v))
return -1 if dist[n - 1] == float('inf') else dist[n - 1]
```

## 复杂度
时间：O((n + m) log n)，m = len(edges)，堆操作贡献 log n。
空间：O(n + m)，邻接表存 2m 条弧，dist 与堆各 O(n)。

## 易错点
- 反向弧代价写成 `w` 而非 `2*w`：示例 1 会得 4（0→1→3 用 3+1），正确是 5。建图时反向必须 `2 * w`。
- 只建正向边、指望「到点后再查入边」：示例 1 中 1 的入边 3→1 在正向图里不可达，会返回 -1。必须预先插入反向弧，让 Dijkstra 自然发现。
- 用 `dist[n-1] == float('inf')` 判不可达时写成 `>=` 或漏判：n=2 且无边时 `dist[1]` 仍是 inf，须显式返回 -1。

## 如果面试官追问
问：若要求输出具体路径怎么办？答：Dijkstra 里加 `parent[v] = u`，终点回溯；反向弧回溯时标记该步为反转即可。
