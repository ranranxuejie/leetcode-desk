## 一句话思路
按数组顺序逐个用双指针判回文，第一个判真即返回，全假返回 `""`。

## 怎么做
1. 用 `for w in words` 顺序遍历，顺序本身就是「第一个」的保证。
2. 对每个 `w` 用 `w == w[::-1]` 或双指针判回文，命中就 `return w`。
3. 循环结束仍无命中，`return ""`。

以 `words = ["abc","car","ada","racecar","cool"]` 为例：`"abc"` 反转 `"cba"` 不等，跳过；`"car"` 反转 `"rac"` 不等，跳过；`"ada"` 反转仍是 `"ada"`，相等，立即返回 `"ada"`，后面的 `"racecar"` 根本不会被检查——这正是「第一个」的含义。

```python
for w in words:
    i, j = 0, len(w) - 1
    while i < j and w[i] == w[j]:
        i += 1
        j -= 1
    if i >= j:
        return w
return ""
```

双指针版里，`"ada"` 走到 `i=1, j=1` 时 `i < j` 为假退出，`i >= j` 成立判为回文；而 `"abc"` 在 `i=0, j=2` 时 `w[0] != w[2]` 直接退出，`i=0 < j=2` 判为假。切片版 `w[::-1]` 更短，但每次多开一个长度 `len(w)` 的新串。

## 复杂度
时间 O(n·m)：n 为 `words` 长度，m 为单词长度，最坏每个词扫一半。
空间 O(1)：双指针只开 `i, j`；若用切片则每次额外 O(m)。

## 易错点
- 输入 `["racecar","ada"]` → 若先收集所有回文再取「最短」或「字典序最小」，会错成 `"ada"` → 正确做法是遍历中一命中就 `return`，`"racecar"` 在索引 0 就该返回。
- 输入 `["def","ghi"]` → 若把 `return ""` 写在循环体内（如 `else` 分支里）会错成提前返回空串 → 正确做法是 `return ""` 放在 `for` 循环之外，只有全部判假才执行。

## 如果面试官追问
若 `words` 长度到 10^5、单词长度到 10^5，总字符数很大怎么办？答：仍逐个判、命中即返回，最坏 O(总字符数)，不必预处理或排序。
