## 一句话思路
把 nums 排序后取最短的前 k 个元素，其和一定最小，因此答案就是前缀和数组里不超过 queries[i] 的最大下标加一。

## 怎么做
1. 对 nums 升序排序，因为选最小的 k 个元素能得到长度为 k 的子序列中的最小和。
2. 原地构造前缀和：`nums[i] += nums[i-1]`，此时 `nums[i]` 表示前 i+1 个最小元素之和。
3. 对每个 q，用 `bisect_right(nums, q)` 得到第一个大于 q 的位置，该位置就是能取的元素个数。
4. 把结果收集成列表返回。

以 `nums = [4,5,2,1]` 为例：排序后为 `[1,2,4,5]`，前缀和为 `[1,3,7,12]`。对 `queries[0]=3`，`bisect_right([1,3,7,12], 3)` 返回 2，即取 `[1,2]` 和为 3，答案 2；对 `queries[1]=10` 返回 3，对 `queries[2]=21` 返回 4。

```python
from bisect import bisect_right

nums.sort()
for i in range(1, len(nums)):
    nums[i] += nums[i - 1]

ans = []
for q in queries:
    ans.append(bisect_right(nums, q))
return ans
```

注意 `bisect_right` 而非 `bisect_left`：当 q 恰好等于某个前缀和时，该长度是合法的，必须算进去。

## 复杂度
时间：排序 O(n log n)，每个 query 二分 O(log n)，共 O(n log n + m log n)。
空间：除返回的 answer 外只用了常数级额外空间，前缀和原地写在 nums 里。

## 易错点
- 用 `bisect_left` 代替 `bisect_right`：输入 `nums=[1,2,4,5], queries=[3]` 时，`bisect_left([1,3,7,12], 3)` 返回 1，错答 1；正确应返回 2，因为 `[1,2]` 的和正好等于 3，长度 2 合法。
- 误以为子序列要保持原顺序而不能排序：题面说「删除某些元素不改变剩余顺序」，但选哪几个元素是自由的，排序只是换一种选法，不改变「存在某个子序列」这一事实；若坚持在原数组上滑窗，`[4,5,2,1]` 对 q=3 会找不到连续段而错答 0。

## 如果面试官追问
问：如果 queries 很大且要求在线逐个回答怎么办？
答：预处理排序加前缀和后，每个 query 独立二分 O(log n)，无需重算，天然支持在线。
