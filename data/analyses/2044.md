## 一句话思路
n ≤ 16，直接枚举 2^n 个下标子集，边枚举边算按位或，同时维护最大值和计数。

## 怎么做
1. 先求全数组的按位或 `full = reduce(or, nums)`，它就是理论最大值——任何子集的或都是 `full` 的子集位。
2. 枚举 `mask` 从 1 到 `2**n - 1`，对每个 `mask` 累加 `cur = nums[i]` 当 `mask >> i & 1`。
3. `cur == full` 时 `ans += 1`。
4. 返回 `ans`。

以 `nums = [3,2,1,5]` 为例：`full = 3|2|1|5 = 7`。`mask = 0b1001`（选下标 0、3）得 `cur = 3|5 = 7`，计数 +1；`mask = 0b0110`（选 2、1）得 `2|1 = 3 ≠ 7`，跳过。最终 6 个 mask 命中。

```python
n = len(nums)
full = 0
for x in nums:
    full |= x
ans = 0
for mask in range(1, 1 << n):
    cur = 0
    for i in range(n):
        if mask >> i & 1:
            cur |= nums[i]
    if cur == full:
        ans += 1
return ans
```

关键点：最大值不用搜索，`full` 一步到位；枚举只需数「或等于 full」的 mask。

## 复杂度
时间：O(2^n · n)，外层 2^n 个 mask，内层扫 n 位。
空间：O(1)，只用了 `full`、`ans`、`cur` 三个标量。

## 易错点
- `nums = [2,2,2]` → 若用「去重后的元素集合」枚举会漏掉重复下标，错成 3 而非 7 → 必须按**下标**枚举 mask，重复值算不同子集。
- `nums = [3,1]` → 若把空集也算进去或漏掉单元素 `[3]`，会错成 1 或 3 → 循环从 `mask = 1` 起，且 `[3]` 的 `cur = 3 = full` 必须计入，答案 2。

## 如果面试官追问
若 n 放大到 10^5 怎么办？答：按位拆解，对 `full` 的每个为 1 的位统计「至少选一个含该位的元素」的容斥，或直接说明该规模下需换思路、原枚举不可行。
