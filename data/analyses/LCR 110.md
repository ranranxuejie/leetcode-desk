## 一句话思路
用 DFS 回溯从 0 号节点往下走，走到 n-1 就存一份路径副本，因为图是 DAG 所以不需要 visited 数组。

## 怎么做
1. 维护一个 `path` 列表，初始为 `[0]`，从节点 0 开始递归。
2. 每进入一个节点 `u`，先判断 `u == n - 1`，是就 `res.append(path[:])` 并返回。
3. 否则遍历 `graph[u]` 里的每个后继 `v`，`path.append(v)` 后递归 `v`，返回后 `path.pop()` 撤销。
4. 递归结束返回 `res`。

以示例 1 `graph = [[1,2],[3],[3],[]]` 为例，n=4。从 0 出发，`path=[0]`，先走 `v=1`，`path=[0,1]`；1 的后继是 3，`path=[0,1,3]`，此时 `u==3==n-1`，存入 `[0,1,3]`；回溯 `pop` 掉 3 和 1，`path` 回到 `[0]`，再走 `v=2`，得到 `[0,2,3]`。关键中间值是回溯后 `path` 必须精确回到 `[0]`，否则第二条路径会变成 `[0,1,2,3]`。

```python
def dfs(u):
    if u == n - 1:
        res.append(path[:])
        return
    for v in graph[u]:
        path.append(v)
        dfs(v)
        path.pop()

n = len(graph)
res, path = [], [0]
dfs(0)
return res
```

注意 `path[:]` 是拷贝，直接 `res.append(path)` 会让所有结果指向同一个列表，最后全变成空或同一条。

## 复杂度
时间：O(所有路径的节点总数)，最坏每条路径长度 n，路径数指数级。
空间：O(n) 递归栈加 `path`，结果集本身占输出规模。

## 易错点
- 输入 `graph = [[1,2],[3],[3],[]]`：若 `res.append(path)` 不拷贝，最终 `res` 里两个元素都是同一个列表对象，输出变成 `[[],[]]` 或全一样 → 必须写 `path[:]`。
- 输入 `graph = [[1],[]]`（n=2）：若把终止判断写成 `u == n` 或漏掉起点 0 已在 `path` 里，会返回空或 `[[0]]` → 起点先放进 `path`，终止条件严格用 `u == n - 1`。

## 如果面试官追问
问：如果图里有环怎么办？答：加一个 `visited` 集合，进入节点时标记、回溯时清除，避免同一路径重复访问节点导致死循环。
