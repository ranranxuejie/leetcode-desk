## 一句话思路
按规则模拟：维护 arr1、arr2 的尾元素，每次比较后追加，最后拼接。

## 怎么做
1. 初始化 `arr1 = [nums[0]]`、`arr2 = [nums[1]]`，对应第 1、2 次操作。
2. 从 `i = 2` 遍历到 `n-1`，每次比较 `arr1[-1]` 与 `arr2[-1]`。
3. 若 `arr1[-1] > arr2[-1]` 则 `arr1.append(nums[i])`，否则 `arr2.append(nums[i])`。
4. 返回 `arr1 + arr2`。

以 `nums = [5,4,3,8]` 为例：初始 `arr1=[5]`、`arr2=[4]`。`i=2` 时 `5 > 4`，`nums[2]=3` 进 arr1，得 `arr1=[5,3]`；`i=3` 时比较 `arr1[-1]=3` 与 `arr2[-1]=4`，`3 > 4` 为假，`nums[3]=8` 进 arr2，得 `arr2=[4,8]`。拼接 `[5,3]+[4,8]=[5,3,4,8]`。

```python
arr1, arr2 = [nums[0]], [nums[1]]
for x in nums[2:]:
    if arr1[-1] > arr2[-1]:
        arr1.append(x)
    else:
        arr2.append(x)
return arr1 + arr2
```

注意比较的是**当前**尾元素，不是初始的 `nums[0]`、`nums[1]`——上面 `i=3` 那步比的是 3 和 4，若误用 5 和 4 就会把 8 错放进 arr1。

## 复杂度
时间 O(n)：一次遍历，每个元素只被比较和追加一次。
空间 O(n)：arr1、arr2 合计存 n 个元素，返回值另占 n。

## 易错点
- 输入 `nums = [5,4,3,8]` → 若把比较写成固定的 `nums[0] > nums[1]`，`i=3` 时仍判 `5 > 4` 为真，8 会错进 arr1 得 `[5,3,8,4]` → 必须每次取 `arr1[-1]`、`arr2[-1]` 现算。
- 输入 `nums = [2,1,3]` → 若循环从 `i=0` 或 `i=1` 开始，会把 `nums[0]=2`、`nums[1]=1` 重复追加，得到长度 5 的数组 → 循环必须从下标 2 起，前两个元素只做初始化。

## 如果面试官追问
问：若要求 arr1、arr2 内部保持原相对顺序且输出各元素所属数组编号，怎么改？
答：追加逻辑不变，只需在 append 时同步记录 `1` 或 `2` 到标记数组，最后按标记输出即可。
