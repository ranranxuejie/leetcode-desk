## 一句话思路
全局倒置数等于局部倒置数，当且仅当每个元素离它排序后的位置不超过 1，即 `abs(nums[i] - i) <= 1`。

## 怎么做
1. 关键观察：局部倒置是全局倒置的子集（相邻对必是下标对），所以全局数 ≥ 局部数，只需判断有没有「非相邻的逆序对」。
2. 若存在 `j >= i + 2` 且 `nums[i] > nums[j]`，全局数就比局部数多，直接返回 `False`。
3. 对排列而言，这个条件等价于每个元素最多偏移一位：`abs(nums[i] - i) <= 1`，一次遍历即可判定。
4. 用示例 2 `nums = [1,2,0]` 走一遍：`i=0` 时 `abs(1-0)=1` 通过；`i=1` 时 `abs(2-1)=1` 通过；`i=2` 时 `abs(0-2)=2 > 1`，返回 `False`，与官方输出一致。

```python
for i, x in enumerate(nums):
    if abs(x - i) > 1:
        return False
return True
```

对照示例 1 `[1,0,2]`：三个位置偏移量分别是 1、1、0，全部 ≤ 1，返回 `True`。

## 复杂度
时间：O(n)，一次遍历，每个元素只做一次减法与取绝对值。
空间：O(1)，只用了循环变量 `i`、`x`，没有额外数组。

## 易错点
- 输入 `[2,0,1]` → 若只检查相邻逆序（`2>0` 一处）就判 `True`，但 `i=0,j=2` 有 `2>1` 的全局倒置，全局 2 个、局部 1 个 → 正确做法是检查 `abs(nums[i]-i) > 1`，此处 `i=0` 时 `abs(2-0)=2` 直接返回 `False`。
- 输入 `[0]` 或 `[0,1]` → 若循环写成 `range(n-1)` 再比较 `nums[i]` 与 `nums[i+1]`，会漏掉最后一个位置的偏移检查，`[0,1]` 恰好通过但 `[1,0]` 的 `i=1` 未被验证 → 正确做法是遍历全部 `n` 个下标，边界由 `abs` 条件自然覆盖。

## 如果面试官追问
问：如果数组不是 `[0, n-1]` 的排列，而是任意互不相同的整数，结论还成立吗？
答：不成立，偏移量判据依赖「值域等于下标域」，此时要回到「是否存在 `j >= i+2` 且 `nums[i] > nums[j]`」，用后缀最小值 O(n) 判定。
