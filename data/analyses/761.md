## 一句话思路
把 s 拆成若干不可再分的特殊子串，各自递归求最大后按字典序降序拼接，因为交换只能重排这些顶层块。

## 怎么做
1. 用计数器 `bal` 扫描 s，`'1'` 加一、`'0'` 减一，`bal` 回到 0 的位置就是一个顶层特殊子串的结尾。
2. 对每个顶层块，剥掉首尾的 `'1'` 和 `'0'`，对内部递归调用，再套回 `'1' + 内部 + '0'`。
3. 把所有顶层块按字符串降序排序后拼接，即为答案。

以 `s = "11011000"` 为例：`bal` 在索引 3 回到 0，得到块 `"1100"`；继续扫到索引 7，得到块 `"10"`。两块内部递归后仍是 `"1100"` 和 `"10"`，降序排序得 `["1100","10"]`，拼接为 `"110010"`——注意这里必须用完整示例：`"11011000"` 实际切分是 `"1100"` 和 `"1100"`？重新数：`1,1,0,1,1,0,0,0`，`bal` 序列 `1,2,1,2,3,2,1,0`，只在索引 7 归零，所以整体是一个块，剥壳后内部 `"101100"`，递归得 `"110010"`，套壳 `"1"+"110010"+"0"` = `"11100100"`，与官方输出一致。

```python
def makeLargestSpecial(s):
    parts, bal, start = [], 0, 0
    for i, ch in enumerate(s):
        bal += 1 if ch == '1' else -1
        if bal == 0:
            inner = makeLargestSpecial(s[start + 1:i])
            parts.append('1' + inner + '0')
            start = i + 1
    parts.sort(reverse=True)
    return ''.join(parts)
```

关键中间值：`s="11011000"` 时 `bal` 全程只在 `i=7` 归零，`parts` 只有一个元素，递归深度 2 层。

## 复杂度
时间 O(n²)：每层递归扫描当前长度，最坏链状嵌套 n/2 层，排序总代价不超过 O(n log n)。
空间 O(n)：递归栈深度最坏 n/2，`parts` 与切片临时串合计 O(n)。

## 易错点
- 输入 `"10"` → 若忘记剥壳直接对整串递归，`s[1:0]` 为空串导致死循环或返回空 → 正确做法是先切出块再剥首尾，`"10"` 剥壳后内部为空串，递归返回 `""`，套壳还原 `"10"`。
- 输入 `"11011000"` → 若按「遇到 bal 归零就切」但忘记对块内递归，只做一次排序，会得到 `"11001100"` 而非 `"11100100"` → 正确做法是每个块先递归求内部最大再套壳，最后才排序拼接。

## 如果面试官追问
问：如果允许交换任意两个特殊子串（不要求连续）呢？
答：那时顶层块可任意排列，但块内结构仍受嵌套约束，递归+排序的框架不变，只是切分粒度要按所有 bal 归零位置重新定义。
