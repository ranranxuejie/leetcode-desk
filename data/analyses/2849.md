## 一句话思路
切比雪夫距离 `d = max(|sx-fx|, |sy-fy|)` 是理论最少步数，8 邻域每步最多缩短 1，所以 `t >= d` 且排除「原地打转」的死角即可。

## 怎么做
1. 先算最少步数 `d = max(abs(sx - fx), abs(sy - fy))`，这是 8 方向移动的下界。
2. 若 `t < d`，直接 `False`（示例 2：`d = max(4, 2) = 4 > t = 3`）。
3. 若 `t >= d`，一般能靠「走一步退一步」凑出多余秒数，唯一例外是起点终点重合且 `t == 1`。
4. 起点终点重合时 `d = 0`：`t == 0` 返回 `True`，`t == 1` 返回 `False`（必须移动，1 秒回不到原格），`t >= 2` 返回 `True`（来回一趟）。

示例 1 中间值：`d = max(|2-7|, |4-7|) = max(5, 3) = 5`，`t = 6 >= 5` 且非重合，返回 `True`。

```python
def isReachableAtTime(sx, sy, fx, fy, t):
    d = max(abs(sx - fx), abs(sy - fy))
    if d == 0:
        return t != 1
    return t >= d
```

关键在 `d == 0` 分支：`t != 1` 一行覆盖 `t=0`（True）和 `t>=2`（True），只有 `t=1` 落 False。

## 复杂度
时间 O(1)：只做 4 次减法、2 次 abs、1 次 max。
空间 O(1)：无额外容器，仅几个整型临时变量。

## 易错点
- 输入 `sx=fx, sy=fy, t=1` → 若只写 `return t >= d` 会错成 `True` → 必须单独判 `d == 0 and t == 1` 返回 `False`，因为每秒必须移动，1 秒无法回到原格。
- 输入 `sx=fx, sy=fy, t=0` → 若把重合情形一律返回 `False` 会错成 `False` → 正确是 `t == 0` 时已在终点，返回 `True`；用 `t != 1` 一并处理。

## 如果面试官追问
问：若允许每步只能走 4 邻域（上下左右）呢？
答：最少步数变成曼哈顿距离 `|sx-fx| + |sy-fy|`，且多余步数必须为偶数才能凑，判据改为 `t >= d and (t - d) % 2 == 0`。
