## 一句话思路
按第一组点逐个处理，用位掩码记录第二组哪些点已被覆盖，DP 求最小成本。

## 怎么做
1. 设 `m = len(cost[0])`，状态 `dp[mask]` 表示处理完前 `i` 个第一组点后，第二组被覆盖情况为 `mask` 的最小成本，初始 `dp[0] = 0`。
2. 对每个第一组点 `i`，枚举新状态：先让 `i` 至少连一个第二组点，用 `cost[i][j]` 更新；再允许 `i` 额外连多个点（因为多连不增加约束，只可能更便宜）。
3. 转移时对每个 `mask`，枚举 `i` 连的子集 `sub`（非空），`new = mask | sub`，`dp2[new] = min(dp2[new], dp[mask] + sum(cost[i][j] for j in sub))`。
4. 答案取 `dp[(1<<m)-1]`。

以示例 2 `cost = [[1,3,5],[4,1,1],[1,5,3]]` 为例，`m=3`。处理 `i=0` 时，`sub={0}` 得 `dp[001]=1`，`sub={0,1}` 得 `dp[011]=4`；处理 `i=1` 时从 `mask=001` 连 `{1,2}` 成本 `1+1=2`，得 `dp[111]=3`；最终答案 4 来自 `i=0` 连 A、`i=1` 连 B,C、`i=2` 连 A 的组合。

```python
m = len(cost[0])
full = (1 << m) - 1
INF = 10**9
dp = [INF] * (1 << m)
dp[0] = 0
for i in range(len(cost)):
    ndp = [INF] * (1 << m)
    for mask in range(1 << m):
        if dp[mask] == INF:
            continue
        for sub in range(1, 1 << m):
            add = sum(cost[i][j] for j in range(m) if sub >> j & 1)
            nm = mask | sub
            if dp[mask] + add < ndp[nm]:
                ndp[nm] = dp[mask] + add
    dp = ndp
return dp[full]
```

## 复杂度
时间：`O(size1 * 3^size2)`，枚举 `mask` 与 `sub` 的子集关系。
空间：`O(2^size2)`，两个 DP 数组。

## 易错点
- 输入 `cost = [[1,3,5],[4,1,1],[1,5,3]]` 时若只允许每个第一组点连一个第二组点，会漏掉 `i=1` 同时连 B、C 的方案，答案错成 5 而非 4；正确做法是枚举 `sub` 的所有非空子集。
- 输入 `cost = [[15,96],[36,2]]` 时若忘记第二组每个点也必须被覆盖，可能只取 `cost[0][0]+cost[1][1]=17` 看似对，但若某列从未被任何 `sub` 选中，`mask` 到不了 `full`；必须保证最终 `mask == (1<<m)-1`。

## 如果面试官追问
问：若要求输出具体连接方案而非仅成本？答：在 DP 转移时额外记录每个状态选用的 `(i, sub)` 前驱，最后从 `full` 回溯即可。
