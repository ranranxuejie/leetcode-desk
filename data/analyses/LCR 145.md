## 一句话思路
用双指针镜像递归：`left.left` 对 `right.right`、`left.right` 对 `right.left`，逐层比对。

## 怎么做
1. 空树直接返回 `True`；否则把 `root.left` 和 `root.right` 交给辅助函数 `mirror(a, b)`。
2. `mirror` 的终止条件：`a is None and b is None` 返回 `True`；只有一方为 `None` 返回 `False`。
3. 值不等返回 `False`，否则递归 `mirror(a.left, b.right) and mirror(a.right, b.left)`。
4. 用示例 2 走一遍：`root = [1,2,2,null,3,null,3]`，第一层 `mirror(2, 2)` 值相等；进入 `mirror(None, 3)`（左子树的左 vs 右子树的右），一方为 `None` 立刻返回 `False`，整棵树判 `False`。

```python
def mirror(a, b):
    if a is None and b is None:
        return True
    if a is None or b is None:
        return False
    if a.val != b.val:
        return False
    return mirror(a.left, b.right) and mirror(a.right, b.left)

return root is None or mirror(root.left, root.right)
```

关键在参数顺序：`a.left` 必须配 `b.right`。写成 `mirror(a.left, b.left)` 就退化成「左右子树各自相同」，示例 1 的 `[6,7,7,8,9,9,8]` 仍会返回 `True`，但示例 2 的 `null,3` 与 `null,3` 也会被判相等，答案错成 `True`。

## 复杂度
时间 O(n)：每个节点最多被 `mirror` 访问一次，n 为节点数。
空间 O(h)：递归栈深度等于树高 h，最坏链状树 O(n)，平衡树 O(log n)。

## 易错点
- 输入 `[1,2,2,null,3,null,3]` → 若只比较「左子树 == 右子树」而不做镜像配对，会把两个 `null,3` 判成相同，错答 `True`；正确做法是 `a.left` 对 `b.right`、`a.right` 对 `b.left` 交叉递归。
- 输入 `[1,2,2,2,null,2]` 这类一方缺孩子的结构 → 若漏写 `a is None or b is None` 的单边判断，直接访问 `a.val` 会抛 `AttributeError`；正确做法是先判 `None` 再比值，两个 `None` 才算对称。

## 如果面试官追问
追问：节点数涨到 10^6、递归会爆栈怎么办？
答：改成队列存 `(a, b)` 对做 BFS，每轮弹出后按镜像顺序压入子节点，空间 O(宽度)。
