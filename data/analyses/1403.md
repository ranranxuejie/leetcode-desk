## 一句话思路
降序排序后从大到小累加，累加和首次严格大于剩余和时停止，取到的前缀就是答案。

## 怎么做
1. 先求总和 `total`，把 `nums` 降序排序。
2. 从前往后累加 `cur`，每加一个就判断 `cur > total - cur`。
3. 一旦成立立即返回已取的元素（天然非递增）。

以 `nums = [4,3,10,9,8]` 为例：`total = 34`，降序后 `[10,9,8,4,3]`。加 `10` 得 `cur = 10`，`10 > 24` 不成立；再加 `9` 得 `cur = 19`，`19 > 15` 成立，返回 `[10,9]`。

```python
nums.sort(reverse=True)
total = sum(nums)
cur = 0
for i, x in enumerate(nums):
    cur += x
    if cur > total - cur:
        return nums[:i + 1]
```

关键点：`total - cur` 是剩余元素之和，不用单独维护。排序保证「长度最小」和「和最大」同时满足——同样长度下，取最大的几个数，和必然最大。

## 复杂度
时间 O(n log n)：排序主导，遍历是 O(n)。
空间 O(1)：除排序栈外只用了 `total`、`cur` 两个变量（返回值不计）。

## 易错点
- 写成 `cur >= total - cur`：输入 `[4,4,7,6,7]` 时，取到 `[7,7]` 得 `cur = 14`，剩余也是 `14`，用 `>=` 会提前返回 `[7,7]`，但题目要求**严格**大于，正确答案是 `[7,7,6]`。
- 升序排序后从尾部取：`[4,3,10,9,8]` 升序是 `[3,4,8,9,10]`，从尾部累加逻辑上等价，但若写成从头部累加会得到 `[3,4,8]`，和只有 15，不满足 `15 > 19`，直接错。必须确认累加方向是从最大值开始。

## 如果面试官追问
问：如果要求返回所有满足条件的子序列中字典序最小的？
答：先按上述方法定出长度 k 和目标和，再在候选里做一次贪心选取即可。
