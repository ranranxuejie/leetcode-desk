## 一句话思路
稳定子数组即非递减子数组；预处理每个右端点向左的最长非递减段，再用前缀和加二分回答区间查询。

## 怎么做
1. 令 `left[i]` 表示以 `i` 结尾的最长非递减子数组的起点：`nums[i-1] <= nums[i]` 时 `left[i]=left[i-1]`，否则 `left[i]=i`。
2. 以 `nums=[3,1,2]` 为例，`left=[0,1,2]`；`i=1` 时 `3>1` 断链，`left[1]=1`，`i=2` 时 `1<=2` 续上，`left[2]=left[1]=1`。
3. 对每个查询 `[l,r]`，答案 = 所有右端点 `j∈[l,r]` 的贡献之和，贡献为 `j - max(left[j], l) + 1`。
4. 把 `max` 拆开：`left[j] >= l` 的部分贡献 `j-left[j]+1`，用前缀和 `pre[j]` 一次取到；`left[j] < l` 的部分贡献恒为 `j-l+1`，用等差数列求和。分界点 `p` 是第一个满足 `left[p] >= l` 的下标，二分得到。

```python
n = len(nums)
left = [0] * n
for i in range(1, n):
    left[i] = left[i-1] if nums[i-1] <= nums[i] else i
pre = [0] * (n + 1)          # pre[j] = sum_{t<j} (t - left[t] + 1)
for j in range(n):
    pre[j+1] = pre[j] + (j - left[j] + 1)

def solve(l, r):
    p = bisect_left(left, l, l, r + 1)   # 第一个 left[p] >= l
    # [l, p-1] 贡献 j-l+1；[p, r] 贡献 j-left[j]+1
    m = p - l
    ans = m * (m + 1) // 2
    return ans + pre[r+1] - pre[p]
```

## 复杂度
时间：预处理 O(n)，每个查询二分 O(log n)，共 O(n + q log n)。
空间：`left` 与 `pre` 各 O(n)，无其他额外结构。

## 易错点
- 把稳定判成「严格递增」：`nums=[2,2]` 时 `2<=2` 应续链，`left=[0,0]`，查询 `[0,1]` 得 3；若写成 `<` 会断成 `left=[0,1]`，答案错成 2。
- 二分区间写成 `[0, n)` 而非 `[l, r+1]`：`left` 在 `[0,l)` 上必然 `< l`，从 0 搜会取到错误分界点，导致 `pre[r+1]-pre[p]` 把不该算的 `j-left[j]+1` 计进去，`[0,2]` 会算成 5 而非 4。

## 如果面试官追问
若 `nums` 允许单点修改，怎么答？用线段树维护 `left` 的断点集合，查询时按断点分段求和，单次 O(log² n)。
