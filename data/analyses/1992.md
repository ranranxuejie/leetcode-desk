## 一句话思路
从左到右、从上到下扫描，遇到未访问的 `1` 就向右、向下扩展出矩形边界，标记已访问。

## 怎么做
1. 双重循环扫描 `land`，遇到 `1` 且未访问时，以 `(r, c)` 为左上角开始扩展。
2. 先向右扩展确定右边界 `c2`，再向下扩展确定下边界 `r2`，因为矩形保证完整。
3. 将 `[r, c, r2, c2]` 加入结果，并把该矩形内所有格子标记为已访问（置 0 或另开 visited）。
4. 继续扫描，跳过已访问格子。

以示例 1 `land = [[1,0,0],[0,1,1],[0,1,1]]` 为例：扫描到 `(0,0)` 时，向右扩展 `c2=0`，向下扩展 `r2=0`，得到 `[0,0,0,0]`；继续扫描到 `(1,1)` 时，向右扩展 `c2=2`，向下扩展 `r2=2`，得到 `[1,1,2,2]`。

```python
for r in range(m):
    for c in range(n):
        if land[r][c] == 1:
            c2 = c
            while c2 + 1 < n and land[r][c2 + 1] == 1:
                c2 += 1
            r2 = r
            while r2 + 1 < m and land[r2 + 1][c] == 1:
                r2 += 1
            res.append([r, c, r2, c2])
            for i in range(r, r2 + 1):
                for j in range(c, c2 + 1):
                    land[i][j] = 0
```

## 复杂度
时间：O(m×n)，每个格子最多被扫描和标记各一次。
空间：O(1) 额外空间（原地修改 `land`），结果数组不计入。

## 易错点
1. 输入 `land = [[1,1],[1,1]]` → 若只向右扩展不向下扩展，会漏掉下边界，错成 `[0,0,0,1]` → 正确做法是同时扩展 `c2` 和 `r2`，得到 `[0,0,1,1]`。
2. 输入 `land = [[1,0,0],[0,1,1],[0,1,1]]` → 若扩展后不标记已访问，扫描到 `(1,2)` 时会重复识别同一矩形 → 正确做法是将矩形内所有格子置 0 或使用 visited 数组。

## 如果面试官追问
若农场组不保证矩形，如何修改？答：改用 DFS/BFS 遍历连通块，记录连通块内最小/最大行列坐标作为边界。
