## 一句话思路
按二进制长度分块，枚举回文左半段生成回文数，再与 n 逐位比较计数。

## 怎么做
1. 长度 L < n 的二进制位数时，回文数个数为 `2**((L-1)//2)`（首位固定 1，左半段自由）。
2. 长度等于 n 的位数时，枚举左半段 `half`，拼出回文 `p`，统计 `p <= n` 的个数。
3. 拼接规则：`s = bin(half)[2:]`，若 L 为奇数则 `s + s[-2::-1]`，偶数则 `s + s[::-1]`。
4. 加上 0 这一个特例。

以 n=9（`1001`，L=4）为例：L=1 有 1 个（1），L=2 有 1 个（3），L=3 有 2 个（5,7），共 4 个；L=4 时 half 从 `100` 到 `111`，拼出 `1001`(9)、`1111`(15)，只有 9 ≤ 9，计 1 个；再加 0，总数 4+1+1=6。

```python
def count(n):
    if n == 0:
        return 1
    L = n.bit_length()
    ans = 1  # 0
    for l in range(1, L):
        ans += 1 << ((l - 1) // 2)
    half = 1 << ((L - 1) // 2)
    while True:
        s = bin(half)[2:]
        p = int(s + (s[-2::-1] if L % 2 else s[::-1]), 2)
        if p > n:
            break
        ans += 1
        half += 1
    return ans
```

关键中间值：n=9 时 L=4，`half` 初值 `1 << 1 = 2`（二进制 `10`），但需保证左半段长度为 `(L+1)//2 = 2`，故实际从 `2` 开始拼 `10` + `01` = `1001` = 9，命中；`half=3` 拼 `1111`=15 > 9，退出。

## 复杂度
时间：O(2^(L/2))，L = log n，即 O(√n) 量级枚举。
空间：O(L) 存字符串，无额外数组。

## 易错点
- n=0 → 若直接走分块逻辑会返回 0，漏掉 0 本身；正确做法是开头特判 `return 1`。
- 长度等于 L 时 half 的起始值算错 → 例如 L=4 时若从 `half=1` 开始会拼出 `1001`? 不，`1` 拼成 `11` 长度只有 2，导致漏计或重复；正确做法是 `half = 1 << ((L-1)//2)`，保证左半段恰好 `(L+1)//2` 位。

## 如果面试官追问
问：n 扩大到 10^18 怎么办？答：思路不变，枚举量约 2^30 仍可接受；若再大需数位 DP 按位统计。
