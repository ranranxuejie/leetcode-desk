## 一句话思路
按 store_id 分组后，用 `ROW_NUMBER` 按价格降序/升序各取一行（同价取 quantity 最大），再自连接比较数量。

## 怎么做
1. 对 inventory 按 `store_id` 分组，用 `ROW_NUMBER() OVER (PARTITION BY store_id ORDER BY price DESC, quantity DESC)` 标记最贵商品，同理 `price ASC, quantity DESC` 标记最便宜商品。
2. 各取 `rn = 1` 的行，得到每店的 `most_exp_product/quantity` 与 `cheapest_product/quantity`，同时 `COUNT(*)` 得到商品数。
3. 用 `HAVING COUNT(DISTINCT product_name) >= 3` 过滤，再筛 `most_qty < cheap_qty`。
4. 计算 `ROUND(cheap_qty / most_qty, 2)`，按比率降序、`store_name` 升序输出。

以 store_id=1 为例：最贵 Laptop 的 quantity=5，最便宜 Mouse 的 quantity=50，5 < 50 成立，比率 `50/5 = 10.00`；store_id=4 只有 Watch、Band 两件，`COUNT=2` 被过滤掉。

若用 Python 实现，核心是两次 `sorted` 取首元素：

```python
from collections import defaultdict
g = defaultdict(list)
for r in inventory:
    g[r.store_id].append(r)
for sid, rows in g.items():
    if len({r.product_name for r in rows}) < 3:
        continue
    hi = max(rows, key=lambda r: (r.price, r.quantity))
    lo = min(rows, key=lambda r: (r.price, -r.quantity))
    if hi.quantity < lo.quantity:
        ratio = round(lo.quantity / hi.quantity, 2)
```

## 复杂度
时间：O(n log n)，n 为 inventory 行数，排序/窗口按店分组内排序贡献 log n。
空间：O(n)，分组字典或窗口中间表存每行一份。

## 易错点
- 同价多商品时：若只按 `price DESC` 排序，store 内出现两个同价最高价商品会随机取一个，quantity 可能取到小的那个 → 必须加 `quantity DESC` 作第二排序键，最便宜侧则是 `quantity DESC`（取数量最多），别写成 `quantity ASC`。
- 过滤顺序：先按 `store_id` 分组算 `COUNT(DISTINCT product_name)`，若用 `COUNT(*)` 而某店同一 product_name 有多条记录（题面未保证唯一），会把 2 件商品误判成 ≥3 件 → 用 `COUNT(DISTINCT product_name)` 更稳。

## 如果面试官追问
问：如果要求返回所有店铺（含不平衡的）并标记是否不平衡？
答：去掉 `most_qty < cheap_qty` 的 WHERE 条件，改成 `CASE WHEN ... THEN 'imbalanced' ELSE 'balanced' END` 输出列即可。
