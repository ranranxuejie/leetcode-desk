## 一句话思路
先算 `diff = goal - sum(nums)`，再用尽量少的 ±limit 内整数凑出 diff，即 `ceil(|diff| / limit)`。

## 怎么做
1. 求当前和 `s = sum(nums)`，缺口 `diff = goal - s`。
2. 若 `diff == 0` 直接返回 0，否则答案只取决于 `|diff|` 和 `limit`。
3. 每个新元素绝对值不超过 `limit`，所以一次最多补 `limit`，最少个数是 `(|diff| + limit - 1) // limit`。
4. 符号取 `diff` 的符号即可，题目允许添加负数。

以示例 1 为例：`nums = [1,-1,1]`，`s = 1`，`goal = -4`，所以 `diff = -5`。`|diff| = 5`，`limit = 3`，`(5 + 3 - 1) // 3 = 7 // 3 = 2`，返回 2，对应添加 `-2` 和 `-3`。

```python
s = sum(nums)
diff = goal - s
if diff == 0:
    return 0
return (abs(diff) + limit - 1) // limit
```

关键点：不要模拟逐个添加元素，`diff` 的绝对值除以 `limit` 向上取整就是最少个数；因为每个元素最大贡献是 `limit`，且任意不超过 `limit` 的整数都能取到。

## 复杂度
时间：O(n)，`sum(nums)` 扫一遍数组，其余是常数运算。
空间：O(1)，只用了 `s`、`diff` 两个变量。

## 易错点
- `nums = [1,-1,1], limit = 3, goal = -4` → 若写成 `abs(goal) // limit` 会得 `4 // 3 = 1`，错在没减当前和 `s = 1`；正确是先算 `diff = goal - s = -5` 再向上取整得 2。
- `nums = [1,-10,9,1], limit = 100, goal = 0` → 若用 `diff // limit` 向下取整，`diff = 0 - 1 = -1`，`-1 // 100 = -1`，返回负数；正确做法是对 `abs(diff)` 做 `(abs(diff) + limit - 1) // limit`，得 1。

## 如果面试官追问
要求输出具体添加了哪些元素怎么办？
答：取 `k = ceil(|diff| / limit)`，先放 `k-1` 个 `sign*limit`，最后一个放 `diff - sign*limit*(k-1)`，其绝对值必不超过 `limit`。
