## 一句话思路
用栈存每层括号的原子计数，遇 `)` 把栈顶弹出乘系数后并入上一层，最后排序拼接。

## 怎么做
1. 遍历 `formula`，用 `i` 指针；栈 `stack = [defaultdict(int)]`，栈顶是当前层的计数。
2. 遇 `(` 压入新的 `defaultdict(int)`；遇 `)` 先读出后面的数字 `mul`（无数字则 1），把弹出的层乘 `mul` 累加进新栈顶。
3. 遇大写字母，向后吞小写字母得到原子名 `name`，再读数字 `cnt`（无则 1），`stack[-1][name] += cnt`。
4. 最后 `sorted(stack[0].items())`，数量为 1 只写名字，否则名字加数字。

以 `"K4(ON(SO3)2)2"` 为例：读到 `(SO3)` 后遇 `)2`，弹出层 `{S:1, O:3}` 乘 2 得 `{S:2, O:6}` 并入外层，此时外层是 `{O:1, N:1, S:2, O:6}` 合并为 `{O:7, N:1, S:2}`；再遇最外 `)2`，整层乘 2 得 `{O:14, N:2, S:4}`，加上 `K:4`。

```python
stack = [defaultdict(int)]
i, n = 0, len(formula)
while i < n:
    c = formula[i]
    if c == '(':
        stack.append(defaultdict(int)); i += 1
    elif c == ')':
        i += 1; j = i
        while j < n and formula[j].isdigit(): j += 1
        mul = int(formula[i:j]) if j > i else 1
        top = stack.pop()
        for k, v in top.items(): stack[-1][k] += v * mul
        i = j
    else:
        j = i + 1
        while j < n and formula[j].islower(): j += 1
        name = formula[i:j]; i = j; k = i
        while k < n and formula[k].isdigit(): k += 1
        cnt = int(formula[i:k]) if k > i else 1
        stack[-1][name] += cnt; i = k
```

## 复杂度
时间 O(n + m log m)：n 为 formula 长度，m 为不同原子数，排序贡献 log。
空间 O(m + 括号深度)：栈每层一个 dict，总计不超过原子种类数。

## 易错点
- 输入 `"Mg(OH)2"`：若把 `)` 后无数字当 0 处理，`mul` 会变 0，整层清零。正确做法是 `j > i` 才取 `int`，否则 `mul = 1`。
- 输入 `"H2O"` 里 `O` 后面没有数字：若读数字时没判 `k > i` 就 `int("")` 会抛异常；且输出时数量为 1 必须省略数字，写成 `"H2O1"` 就错。

## 如果面试官追问
问：若 formula 长度到 10^5 且括号嵌套很深，递归解析会怎样？
答：递归深度可能爆栈，改用显式栈迭代即可，复杂度不变。
