## 一句话思路
对每个 query 逐字符比对 dictionary 中每个词，统计不同位置数，≤2 即命中。

## 怎么做
1. 外层遍历 `queries`，内层遍历 `dictionary`，保持 queries 原顺序。
2. 对每一对 `(q, d)` 用 `zip` 逐位比较，累计 `diff`，一旦 `diff > 2` 立即 `break`。
3. 命中则把 `q` 加入结果并 `break` 跳出内层，避免重复加入。
4. 关键中间值：`q="note"`、`d="joke"` 时，逐位 `n≠j`、`o=o`、`t≠k`、`e=e`，`diff=2`，命中；而 `q="ants"` 对 `"wood"` 逐位全不同，`diff` 在第 3 位就超 2 被剪掉。

```python
res = []
for q in queries:
    for d in dictionary:
        diff = 0
        for a, b in zip(q, d):
            if a != b:
                diff += 1
                if diff > 2:
                    break
        if diff <= 2:
            res.append(q)
            break
return res
```

注意 `diff <= 2` 判断放在内层 for 之后，此时 `diff` 要么是真实差异数，要么是 3（被 break 截断），两种情况都正确。

## 复杂度
时间：O(len(queries) × len(dictionary) × n)，n 为单词长度，最坏全比完。
空间：O(1) 额外，除返回值外只用了 `diff` 等常数变量。

## 易错点
- `queries=["wood"]`、`dictionary=["wood","wood"]` → 若不加 `break` 会把 `"wood"` 加入两次 → 命中后必须 `break` 跳出内层，保证每个 query 最多进结果一次。
- `q="ants"`、`d="wood"` → 若把 `diff > 2` 的剪枝写成 `diff >= 2` 会漏掉恰好 2 次编辑的合法词（如 `"note"`→`"joke"`）→ 剪枝条件必须是严格大于 2。

## 如果面试官追问
若 n 放大到 10^4、dictionary 到 10^5，怎么做？答：把 dictionary 建字典树，对每个 query 做带剩余编辑次数的 DFS，剪掉超 2 的分支。
