## 一句话思路
用滑动窗口维护一段「元音按 a→e→i→o→u 单调不减」的连续区间，窗口内凑齐 5 个元音时更新答案。

## 怎么做
1. 把 `word` 逐字符扫，用 `left` 记当前合法窗口左端，`cnt` 记窗口内已出现的不同元音数。
2. 遇到 `word[i] < word[i-1]`（字典序下降，如 `i` 后接 `a`）就说明窗口必须断开，令 `left = i`、`cnt = 1`。
3. 否则若 `word[i] != word[i-1]`，说明进入新元音，`cnt += 1`；当 `cnt == 5` 时用 `i - left + 1` 更新 `ans`。

以示例 1 的 `"aeiaaioaaaaeiiiiouuuooaauuaeiu"` 为例：扫到下标 2 的 `i` 后接下标 3 的 `a`，`'a' < 'i'`，窗口重置 `left = 3`；继续扫到 `"aaaaeiiiiouuu"` 末尾时 `cnt` 恰好到 5，长度 `i - left + 1 = 13`。

```python
vowels = "aeiou"
ans = left = cnt = 0
for i, ch in enumerate(word):
    if i > 0 and ch < word[i - 1]:
        left, cnt = i, 1
    elif i > 0 and ch != word[i - 1]:
        cnt += 1
    elif i == 0:
        cnt = 1
    if cnt == 5:
        ans = max(ans, i - left + 1)
return ans
```

注意 `cnt` 只在「字符变化」时加一，连续相同元音（`aaaa`）不重复计数，这正是美丽串允许重复字母的关键。

## 复杂度
时间 O(n)：`word` 每个字符只被扫一次，`n = len(word)`。
空间 O(1)：只开了 `left`、`cnt`、`ans` 三个标量。

## 易错点
- 输入 `"aeiouu"` → 若在 `cnt == 5` 后不再更新，会漏掉尾部 `u` 使长度停在 5；正确做法是每次循环都判断 `cnt == 5` 并取 `i - left + 1`，得到 6。
- 输入 `"aaeiaaioooaauuaeiu"` → 若把 `ch < word[i-1]` 写成 `<=`，遇到连续相同元音就误重置窗口，`"aaaaeiiiiouuu"` 会被切碎；正确做法是严格小于才重置，相等时保持窗口。

## 如果面试官追问
要求返回最长美丽子串本身而非长度？答：在 `cnt == 5` 更新 `ans` 时同步记录 `best = (left, i)`，最后切片 `word[best[0]:best[1]+1]` 即可，复杂度不变。
