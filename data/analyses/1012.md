## 一句话思路
正难则反：用数位 DP 统计 `[1,n]` 中「各位数字互不相同」的个数，再用 `n` 减掉。

## 怎么做
1. 把 `n` 转成字符串 `s`，长度 `L`，逐位枚举「互不相同」的数。
2. 先算位数 `< L` 的：首位 1..9 有 9 种，后面每位从剩余 9、8… 里选，累加 `9 * P(9, k-1)`。
3. 再算位数 `= L` 且严格小于 `n` 的：从左往右，对第 `i` 位枚举比 `s[i]` 小的可用数字，后面 `L-i-1` 位从剩余数字里排列。
4. 若 `s` 本身各位互不相同，还要把 `n` 自己算进去。

以 `n = 1000` 为例：`L=4`。位数 1..3 的互异数共 `9 + 81 + 648 = 738`。第 4 位前缀 `1`，第 2 位 `s[1]='0'`，比 0 小的没有，跳过；第 3 位同理；第 4 位同理。`s="1000"` 有重复，不加。互异数 `738`，答案 `1000 - 738 = 262`，与示例 3 一致。

```python
def count_unique(n):
    s = str(n); L = len(s); total = 0
    # 位数更少的
    for k in range(1, L):
        total += 9 * perm(9, k - 1)
    # 同位数、前缀相同、当前位更小
    used = set()
    for i, ch in enumerate(s):
        d = int(ch)
        for x in range(0 if i else 1, d):
            if x not in used:
                total += perm(9 - i, L - i - 1)
        if d in used:
            return total          # n 自身有重复，不再往下
        used.add(d)
    return total + 1              # n 自身互异
```

`perm(a,b)` 即 `a!/(a-b)!`，`b<0` 时返回 0。

## 复杂度
时间：`O(L^2)`，`L = len(str(n)) ≤ 10`，每位内层最多 10 次枚举。
空间：`O(L)`，`used` 集合与 `s` 各占 `L`，无额外 DP 表。

## 易错点
- `n = 100`：若把「位数更少」的循环写成 `range(1, L+1)`，会把 3 位数也算进去，互异数偏大，答案偏小；正确是 `range(1, L)`，只算 1、2 位。
- `n = 20`：第 2 位 `s[1]='0'`，若内层起点写成 `range(1, d)` 而非 `range(0, d)`，会漏掉 `10`、`12`…`19` 这些互异数，答案从 1 变成 2；首位才用 `range(1, d)`，非首位从 0 起。

## 如果面试官追问
问：`n` 放大到 `10^18` 还成立吗？答：成立，`L` 变 19，`O(L^2)` 仍秒过；只是 `perm` 结果超过 32 位，Python 整数天然支持，无需截断。
