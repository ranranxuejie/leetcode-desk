## 一句话思路
从目标倒推回起点：每步只能把较大的坐标减去较小的坐标，用整除一次跳多步。

## 怎么做
1. 若 `sx > tx or sy > ty`，坐标只增不减，直接返回 `-1`。
2. 循环中若 `tx == sx and ty == sy` 则返回 `ans`；若 `tx == ty` 且不等于起点，则无法再倒推，返回 `-1`。
3. 保证 `tx >= ty`（否则交换 `tx, ty` 与 `sx, sy`），此时最后一步必是 `tx -= ty`，可一次减 `k = (tx - sx) // ty` 步，但 `k` 至少为 1，且减完后 `tx` 不能小于 `sx`。
4. 累加 `ans += k`，`tx -= k * ty`，继续循环。

以示例 1 `sx=1, sy=2, tx=5, ty=4` 为例：`tx>ty`，`k = (5-1)//4 = 1`，`tx` 变为 `5-4=1`，`ans=1`；下一轮 `tx<ty` 交换后 `tx=4, ty=1`，`k=(4-2)//1=2`，但 `tx` 只能减到 `sy=2`，实际 `k=2`，`tx` 变为 `2`，`ans=3`？注意交换后起点也交换为 `sx=2, sy=1`，此时 `tx=2, ty=1` 已等于起点，返回 `ans=2`。

```python
ans = 0
while True:
    if tx == sx and ty == sy:
        return ans
    if tx == ty:
        return -1
    if tx < ty:
        tx, ty = ty, tx
        sx, sy = sy, sx
    k = (tx - sx) // ty
    if k == 0:
        return -1
    ans += k
    tx -= k * ty
```

## 复杂度
时间：每轮至少让 `tx` 减半或交换，`O(log(max(tx, ty)))`。
空间：只用了 `ans, k` 等常数变量，`O(1)`。

## 易错点
- 输入 `sx=1, sy=1, tx=2, ty=2` → 若直接 `k=(2-1)//2=0` 却不判 `k==0`，会死循环或错算 → 正确做法是 `k==0` 时返回 `-1`，因为 `tx` 无法再减到 `sx`。
- 输入 `sx=0, sy=1, tx=2, ty=3` → 若 `k=(tx-sx)//ty` 不限制下界，可能把 `tx` 减到小于 `sx` → 正确做法是 `k` 取 `(tx-sx)//ty` 且至少为 1，保证 `tx` 不低于 `sx`。

## 如果面试官追问
问：若要求输出具体移动序列而非次数？答：倒推时记录每步减的是哪个坐标和步数 `k`，再反转顺序即可。
