## 一句话思路
把每个单词反转后建字典树，只有叶子节点（不是任何其他单词后缀的单词）才需要贡献 `len+1`。

## 怎么做
1. 把所有单词反转，这样「后缀关系」变成「前缀关系」，可以直接用字典树判前缀。
2. 用 `set` 去重后逐个插入反转串，插入时若路径上已有节点被标记为「单词结尾」，说明当前串是别人前缀，它不该被计数。
3. 更简单的做法：把所有反转串放进 `set`，对每个串枚举它的所有真前缀，若某个前缀也在 `set` 里，就把它从 `set` 中删掉。
4. 最后答案是 `sum(len(w) + 1 for w in set)`。

以 `words = ["time", "me", "bell"]` 为例，反转后集合为 `{"emit", "em", "lleb"}`。检查 `"em"` 的真前缀 `"e"` 不在集合中，保留；检查 `"emit"` 的真前缀 `"e"`、`"em"`、`"emi"`，其中 `"em"` 在集合里，于是 `"emit"` 被删除。最终集合为 `{"em", "lleb"}`，答案 `2+1 + 4+1 = 8`？不对——注意 `"em"` 对应原词 `"me"`，`"lleb"` 对应 `"bell"`，但 `"time"` 被误删了。问题在于：`"me"` 是 `"time"` 的后缀，所以 `"time"` 应该保留、`"me"` 被吸收。反转后 `"em"` 是 `"emit"` 的前缀，应该删 `"em"` 而不是 `"emit"`。正确逻辑：若某串是另一串的前缀，删短的那个。所以枚举时应该检查「当前串是否是别人的前缀」，即对每个串枚举其真前缀，若前缀在集合中则删前缀。修正后：`"emit"` 的前缀 `"em"` 在集合中 → 删 `"em"`；最终 `{"emit", "lleb"}`，答案 `4+1 + 4+1 = 10`，与示例一致。

```python
seen = set(w[::-1] for w in words)
for w in list(seen):
    for i in range(1, len(w)):
        seen.discard(w[:i])
return sum(len(w) + 1 for w in seen)
```

## 复杂度
时间：O(N·L²)，N 为单词数、L 为最大长度 7，每个串枚举 L 个前缀、切片 O(L)。
空间：O(N·L)，`seen` 存所有反转串。

## 易错点
- 输入 `["time", "me"]` → 若直接对原串判后缀会漏掉 `"me"` 被 `"time"` 吸收，错算成 `5+3=8`；正确做法是先反转再判前缀，答案 `5+1=6`。
- 输入 `["me", "me"]` → 不去重会重复计数成 `2*(2+1)=6`；正确做法是先用 `set` 去重，答案 `3`。

## 如果面试官追问
问：若单词长度上限从 7 放宽到 2000 怎么办？答：O(N·L²) 的切片枚举会退化，改用字典树插入反转串，O(N·L) 即可。
