## 一句话思路
枚举 2^n 个「谁是好人」的集合，逐个校验集合内每个人的陈述是否与集合一致，取合法集合的最大大小。

## 怎么做
1. 用整数 `mask` 的二进制位表示假设的好人集合，`mask` 从 0 枚举到 `(1<<n)-1`。
2. 对 `mask` 中每个为 1 的位 `i`（即假设 i 是好人），检查 `statements[i][j]`：若为 1 则 `j` 必须在 `mask` 里，若为 0 则 `j` 必须不在 `mask` 里，为 2 跳过。
3. 任一冲突则 `mask` 非法；全部通过则用 `mask.bit_count()` 更新答案。
4. 坏人不需要校验——坏人可以说真也可以说假，任何陈述都不构成矛盾。

以示例 1 `[[2,1,2],[1,2,2],[2,0,2]]` 为例，`mask=0b011`（0、1 是好人）：检查 0 号，`statements[0][1]=1` 且 1 在 mask 中，通过；检查 1 号，`statements[1][0]=1` 且 0 在 mask 中，通过；合法，答案 2。而 `mask=0b100`（只有 2 是好人）时，`statements[2][1]=0` 要求 1 不在 mask 中，成立，但 2 号说 1 是坏人——1 确实不在，通过，大小 1，不敌 2。

```python
n = len(statements)
ans = 0
for mask in range(1 << n):
    ok = True
    for i in range(n):
        if not (mask >> i) & 1:
            continue
        for j in range(n):
            s = statements[i][j]
            if s == 2:
                continue
            if s != ((mask >> j) & 1):
                ok = False
                break
        if not ok:
            break
    if ok:
        ans = max(ans, mask.bit_count())
```

## 复杂度
时间：O(2^n · n^2)，枚举 2^n 个 mask，每个最多查 n^2 条陈述。
空间：O(1)，只用 `mask`、`ans` 等几个整数，无额外数组。

## 易错点
- 只校验好人、忘了坏人不用管：若对 mask 外的 i 也去比对 `statements[i][j]`，示例 1 的 `mask=0b011` 会被 2 号的 `statements[2][1]=0` 误判冲突（2 是坏人，说假话合法），答案错成 1。正确做法是 `if not (mask >> i) & 1: continue` 直接跳过。
- 把 `statements[i][j]=2` 当成「必须一致」：示例 1 的 `statements[0][2]=2`，若拿 2 去和 `(mask>>2)&1` 比较必然不等，所有 mask 全废，答案错成 0。正确做法是 `s == 2` 时 `continue`。

## 如果面试官追问
若 n 放大到 30 怎么办？答：2^30 枚举不可行，需按陈述建 2-SAT 或利用「好人集合必须对每条 1/0 陈述闭合」做剪枝搜索，本题 n≤15 才保证枚举可行。
