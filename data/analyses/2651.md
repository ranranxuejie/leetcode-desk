## 一句话思路
把 `arrivalTime + delayedTime` 对 24 取模，因为 24 小时制下 24 点即 0 点。

## 怎么做
1. 先算总小时数 `total = arrivalTime + delayedTime`。
2. 再取模 `total % 24` 得到 0~23 的实际时刻。
3. 直接返回该值，无需额外分支。

以示例 2 为例：`arrivalTime = 13`、`delayedTime = 11`，中间变量 `total = 24`，`24 % 24 = 0`，正好对应 24 小时制的 00:00，返回 0。示例 1 中 `total = 20`，`20 % 24 = 20`，取模不改变结果。

```python
def findDelayedArrivalTime(arrivalTime, delayedTime):
    total = arrivalTime + delayedTime
    return total % 24
```

关键点在于 `total` 的取值范围：`arrivalTime` 最大 23、`delayedTime` 最大 24，所以 `total` 最大 47，最多跨一次 24 点，一次取模足够，不需要 `while total >= 24` 循环。

## 复杂度
时间：O(1)，只做一次加法和一次取模。
空间：O(1)，没有开任何额外容器。

## 易错点
- 输入 `arrivalTime = 13, delayedTime = 11` → 若写成 `if total > 24: total -= 24` 会漏掉 `total == 24` 的情况，返回 24 而非 0 → 正确做法是用 `total % 24`，或判断写成 `total >= 24`。
- 输入 `arrivalTime = 15, delayedTime = 5` → 若误以为要返回字符串 `"20:00"` 或补零成 `"20"`，会与返回类型 `integer` 不符 → 题目要的是整数小时，直接返回 `20`。

## 如果面试官追问
问：若 `delayedTime` 可达 10^9 怎么办？答：取模一次仍成立，`(arrivalTime + delayedTime) % 24` 直接算，O(1) 不变。
