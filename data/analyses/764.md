## 一句话思路
对每个格子分别求上、下、左、右四个方向的连续 1 长度，取四者最小值即该格加号阶数，全局取最大。

## 怎么做
1. 建 `n x n` 的 `grid` 全填 1，把 `mines` 里每个 `[x, y]` 置 0。
2. 从左到右、从上到下各扫一遍，得到每格向左、向上的连续 1 长度，存进 `left`、`up`。
3. 从右到左、从下到上再扫一遍，得到向右、向下的长度 `right`、`down`。
4. 遍历每格，`min(left, up, right, down)` 取最大。

以 `n = 5, mines = [[4, 2]]` 为例，只有 `grid[4][2] = 0`。中心 `(2, 2)` 的四个方向长度都是 3（到边界），但向下走到 `(4, 2)` 被 0 挡住，所以 `down[2][2] = 2`，`min = 2`，答案 2。而 `(2, 3)` 向左到 `(2, 2)` 是 1，`left = 3`，但向上只有 3、向下 3、向右 2，`min = 2`，不会超过 2。

```python
grid = [[1] * n for _ in range(n)]
for x, y in mines:
    grid[x][y] = 0
left = [[0] * n for _ in range(n)]
for i in range(n):
    for j in range(n):
        if grid[i][j]:
            left[i][j] = (left[i][j - 1] if j else 0) + 1
# up / right / down 同理，方向反过来扫
ans = 0
for i in range(n):
    for j in range(n):
        if grid[i][j]:
            ans = max(ans, min(left[i][j], up[i][j], right[i][j], down[i][j]))
```

## 复杂度
时间：O(n²)，四次扫描各 O(n²)，mines 建表 O(m)。
空间：O(n²)，四个方向各开一个 n×n 数组。

## 易错点
- `mines` 为空或全 1 网格 → 若把 `left[i][j-1]` 的边界判断写成 `left[i][j-1] + 1` 而不判 `j == 0`，会取到 `left[i][-1]`（Python 负索引回绕到行尾），结果偏大。正确做法是 `j == 0` 时直接置 1。
- `n = 1, mines = [[0, 0]]` → 若在 `grid[i][j]` 为 0 时仍参与 `min` 计算，会把 0 当成合法阶数返回 0 之外的值；正确做法是只在 `grid[i][j] == 1` 时更新 `ans`，否则该格跳过。

## 如果面试官追问
若 n 扩大到 5000 且 mines 稀疏，怎么省空间？答：只存 `left` 和 `up` 两个数组，右、下方向边扫边用一维滚动数组更新 `ans`，空间降到 O(n²) 但常数减半。
