## 一句话思路
一次遍历统计元音数 v 和辅音数 c，最后按 c 是否为 0 决定返回 0 还是 `v // c`。

## 怎么做
1. 初始化 `v = 0`、`c = 0`，元音集合写成 `set("aeiou")`。
2. 遍历 `s` 的每个字符 `ch`：在元音集合里就 `v += 1`，否则若 `ch.isalpha()` 就 `c += 1`。
3. 空格和数字既不是元音也不是辅音，靠 `isalpha()` 挡掉，不参与任何计数。
4. 收尾：`return v // c if c else 0`。

以示例 2 `s = "axeyizou"` 为例，走完一遍后 `v = 5`（a、e、i、o、u）、`c = 3`（x、y、z），`5 // 3 = 1`，与输出一致。关键中间值是 `c` 从 0 涨到 3 的过程——若漏掉 `isalpha()` 判断，`c` 不会变，但这里没有空格数字，所以真正暴露问题的是示例 3。

```python
vowels = set("aeiou")
v = c = 0
for ch in s:
    if ch in vowels:
        v += 1
    elif ch.isalpha():
        c += 1
return v // c if c else 0
```

注意 `elif` 不能写成 `else`：`else` 会把空格和数字也算进 `c`，示例 3 的 `"au 123"` 就会得到 `c = 4`，输出 `2 // 4 = 0` 碰巧对，但换成 `"au1"` 就错成 `c = 1`、返回 2。

## 复杂度
时间 O(n)：n 是 `len(s)`，每个字符做一次集合查找和一次 `isalpha()`。
空间 O(1)：只开了 `v`、`c` 两个整数和固定 5 元素的元音集合。

## 易错点
- 输入 `"au 123"` → 若用 `else` 而非 `elif ch.isalpha()`，空格和 `1`、`2`、`3` 全被算成辅音，`c` 变成 4，虽然本题输出仍是 0，但换成 `"au1"` 就会返回 2 而非 0 → 正确做法是辅音分支必须加 `isalpha()` 过滤。
- 输入 `"bcdfg"`（v = 0）→ 若先算 `v // c` 再判 c，得到 0 没问题；但输入 `"aeiou"`（c = 0）→ 直接 `v // c` 会抛 `ZeroDivisionError` → 正确做法是先判 `if c` 再除，c 为 0 时直接返回 0。

## 如果面试官追问
问：若 s 长度放大到 10^7 且要求流式读入怎么办？
答：逻辑不变，仍是单次扫描 O(1) 空间，只是把 `for ch in s` 换成逐块读取、跨块保留 `v`、`c` 两个累加器即可。
