## 一句话思路
枚举 s 与 t 的起点对 (i,j)，沿对角线同步延伸，用「已失配次数」控制长度，失配恰为 1 时计数。

## 怎么做
1. 外层双重循环枚举起点对 `(i, j)`，`i` 遍历 `s`，`j` 遍历 `t`。
2. 内层用 `k` 同步推进，`diff` 记录当前这对子串的失配字符数，一旦 `diff > 1` 立即 `break`。
3. 每步若 `diff == 1`，说明长度 `k+1` 的这对子串合法，`ans += 1`。
4. 返回 `ans`。

以 `s = "ab", t = "bb"` 为例：起点 `(0,0)` 时 `k=0` 比较 `'a'`/`'b'`，`diff=1`，`ans=1`；`k=1` 比较 `'b'`/`'b'`，`diff` 仍为 1，`ans=2`。起点 `(0,1)` 时 `k=0` 比较 `'a'`/`'b'`，`diff=1`，`ans=3`；`k=1` 越界停止。起点 `(1,0)` 时 `k=0` 比较 `'b'`/`'b'`，`diff=0` 不计数，`k=1` 比较 `'b'`/`'b'`，`diff=0` 不计数。最终 `ans=3`，与示例一致。

```python
ans = 0
for i in range(len(s)):
    for j in range(len(t)):
        diff = 0
        k = 0
        while i + k < len(s) and j + k < len(t):
            if s[i + k] != t[j + k]:
                diff += 1
                if diff > 1:
                    break
            if diff == 1:
                ans += 1
            k += 1
return ans
```

关键点：`diff == 1` 的判断放在 `break` 之后、`k += 1` 之前，保证「刚失配的那一步」也被计入；`diff == 0` 的公共前缀段不计数，因为题目要求恰好一个字符不同。

## 复杂度
时间 O(|s|·|t|·min(|s|,|t|))，三重循环由起点对和延伸长度贡献。
空间 O(1)，只用了 `ans`、`diff`、`k` 三个标量。

## 易错点
- 输入 `s = "a", t = "a"` → 若把 `diff == 0` 也计入会错成 1 → 必须严格 `diff == 1` 才 `ans += 1`，完全相同的前缀不算。
- 输入 `s = "ab", t = "bb"` 起点 `(0,0)` → 若在 `diff > 1` 时先 `break` 再判断计数，会漏掉 `k=0` 这一步 → 计数判断要放在 `break` 之前或紧跟失配赋值之后，保证失配那一步被统计。

## 如果面试官追问
若 |s|、|t| 放大到 10^5，O(n^3) 会超时，怎么办？
答：按「失配位置」分组，用后缀数组或 Z 函数求每个起点对的最长公共前缀，把每对起点的贡献压缩成 O(1) 计算。
