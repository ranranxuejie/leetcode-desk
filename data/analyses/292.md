## 一句话思路
用模 4 判定：`n % 4 == 0` 时先手必败，否则必胜，因为每轮双方合计可凑出 4。

## 怎么做
1. 把局面按 `n % 4` 分类，只有余 0 是必败态。
2. 归纳：`n = 4` 时你拿 1/2/3，对手拿 3/2/1 收尾，你必输。
3. 若 `n % 4 != 0`，你拿 `n % 4` 块，把剩余石头数压成 4 的倍数交给对手。
4. 之后对手拿 `k` 块，你就拿 `4 - k` 块，每轮合计消耗 4，最后一块必然落在你手上。

以 `n = 4` 为例：`4 % 4 == 0`，返回 `False`；你拿 1 块后剩 3，对手一次拿 3 收尾。以 `n = 5` 为例：`5 % 4 == 1`，你先拿 1 块，剩 4 交给对手，此时对手面对的是必败态。

```python
def canWinNim(n: int) -> bool:
    return n % 4 != 0
```

关键中间值就是 `n % 4`：`n = 4` 得 0 → `False`；`n = 5` 得 1 → `True`；`n = 8` 得 0 → `False`。注意 `n` 最大到 `2**31 - 1`，Python 取模没有溢出问题，直接算即可。

## 复杂度
时间：O(1)，只做一次取模，与 n 的大小无关。
空间：O(1)，没有开任何额外容器。

## 易错点
- 输入 `n = 4` → 若按「能拿 1-3 块就先拿」的贪心写成 `n > 3` 返回 `True`，会错成 `True`；正确做法是只判 `n % 4 == 0`，4 是必败态而不是「石头多就能赢」。
- 输入 `n = 8` → 若只特判 `n == 4` 而漏掉其他 4 的倍数，会错成 `True`；正确做法是把整个 `n % 4 == 0` 集合都判为 `False`，8、12、`2**31 - 4` 同理。

## 如果面试官追问
问：如果每次可以拿 1 到 k 块呢？
答：必败态变成 `n % (k + 1) == 0`，其余全胜，因为双方每轮可凑出 `k + 1`。
