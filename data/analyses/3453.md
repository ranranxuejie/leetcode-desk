## 一句话思路
对水平线高度 y 二分，用「线下面积 ≤ 总面积一半」作单调判据，收敛到最小可行 y。

## 怎么做
1. 先算 `total = sum(l*l for _,_,l in squares)`，目标半面积 `half = total/2`。
2. 二分区间取 `lo = min(y_i)`、`hi = max(y_i + l_i)`，因为线下面积在这段外不再变化。
3. 每次取 `mid`，遍历所有正方形累加线下面积：只有 `y_i < mid` 时贡献 `l * min(l, mid - y_i)`。
4. 若 `area < half` 则 `lo = mid`，否则 `hi = mid`；迭代 100 次左右即可到 1e-5。

以示例 2 `[[0,0,2],[1,1,1]]` 为例，`total = 4+1 = 5`，`half = 2.5`。取 `mid = 1.16667`：红方块 `min(2, 1.16667)*2 = 2.33334`，蓝方块 `min(1, 0.16667)*1 = 0.16667`，合计 `2.5`，正好等于 `half`，故 `hi` 不再下压，答案收敛到 `7/6 ≈ 1.16667`。

```python
total = sum(l * l for _, _, l in squares)
half = total / 2.0
lo = min(y for _, y, _ in squares)
hi = max(y + l for _, y, l in squares)
for _ in range(100):
    mid = (lo + hi) / 2
    area = 0.0
    for _, y, l in squares:
        if y < mid:
            area += l * min(l, mid - y)
    if area < half:
        lo = mid
    else:
        hi = mid
return lo
```

## 复杂度
时间：二分 100 次 × 每次扫 n 个正方形，O(n log(范围/精度))，n 是 squares 长度。
空间：只存 `total/half/lo/hi/mid/area` 几个标量，O(1) 额外空间。

## 易错点
- 用 `mid - y` 直接乘 `l` 而不截断：当 `mid` 高于方块顶部时，`mid - y > l`，会多算面积，导致 `area` 虚高、二分把 `hi` 压得过低。必须写 `min(l, mid - y)`。
- 判据方向写反：若用 `area <= half` 就更新 `hi`，会收敛到最大可行 y 而非最小。本题要最小 y，必须 `area < half → lo = mid`，等号归到 `hi` 一侧。

## 如果面试官追问
问：正方形数到 5e4、坐标到 1e9，二分次数能减吗？
答：可以，把 100 次换成固定 60 次（2^-60 远小于 1e-5 相对精度），或按 `hi-lo > 1e-6` 循环，复杂度不变但常数更小。
