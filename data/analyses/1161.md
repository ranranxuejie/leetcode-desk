## 一句话思路
BFS 逐层累加，边扫边比较，因为层和只依赖同层节点，队列天然按层分组。

## 怎么做
1. 队列初始化 `q = [root]`，`best = -2**31`、`ans = 1`、`level = 1`。
2. 每轮先记 `size = len(q)`，只弹出这 `size` 个节点，保证不串层。
3. 累加 `s`，同时把非空左右孩子压入队尾。
4. 用 `s > best` 严格大于才更新，这样并列时保留更小的层号。

以示例 1 为例：第 2 轮 `size = 2`，弹出 `7` 和 `0`，`s = 7`，压入 `7`、`-8`；此时 `best = 1`，`7 > 1` 成立，`ans = 2`。第 3 轮 `s = 7 + (-8) = -1`，不更新。

```python
q, best, ans, level = [root], -2**31, 1, 1
while q:
    size, s = len(q), 0
    for _ in range(size):
        node = q.pop(0)
        s += node.val
        if node.left: q.append(node.left)
        if node.right: q.append(node.right)
    if s > best:
        best, ans = s, level
    level += 1
```

## 复杂度
时间 O(n)：每个节点入队出队各一次。
空间 O(w)：队列最多存一层，w 为最大层宽，最坏 O(n)。

## 易错点
- 输入 `[1,7,0,7,-8]` 这类含负值层：若把 `best` 初始化成 `0`，第 3 层 `-1` 不更新、第 1 层 `1` 也不更新，会错答 1；正确做法是 `best = -2**31`（节点值下限 `-10^5`、节点数 `10^4`，层和最小约 `-10^9`，仍在 32 位内）。
- 并列层：若写成 `s >= best`，示例 1 中若两层同为 7 会返回较大层号；必须用严格 `>`，因为遍历是从第 1 层往上递增的。

## 如果面试官追问
若节点数涨到 `10^6` 且树退化成链：BFS 队列只存 1 个节点，空间仍是 O(1) 级别，但 `pop(0)` 是 O(n) 搬移，应改用 `collections.deque` 的 `popleft()`。
