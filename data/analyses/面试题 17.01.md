## 一句话思路
用异或算无进位和、与运算左移算进位，循环到进位为 0。

## 怎么做
1. 令 `carry = (a & b) << 1`，`a = a ^ b`，前者是进位，后者是不带进位的和。
2. 令 `b = carry`，把进位加回 `a`，重复第 1 步。
3. 当 `b == 0` 时 `a` 就是结果。

以 `a = 1, b = 1` 为例：第一轮 `a ^ b = 0`，`(a & b) << 1 = 2`，于是 `a = 0, b = 2`；第二轮 `a ^ b = 2`，`(a & b) << 1 = 0`，`b` 归零，返回 `2`。关键中间值是第一轮的 `carry = 2`——它把「1+1 的进位」显式搬到了下一位。

```python
a, b = 1, 1
while b:
    carry = (a & b) << 1
    a = a ^ b
    b = carry
# a == 2
```

负数在 Python 里靠无限符号位表示，`<< 1` 不会截断，所以循环可能不终止。做法是先 `a &= 0xFFFFFFFF`、`b &= 0xFFFFFFFF` 把两者转成 32 位无符号，循环结束后若 `a >= 2**31` 再 `a -= 2**32` 还原成负数。例如 `a = -1, b = 1`：掩码后 `a = 0xFFFFFFFF`，一轮后 `a = 0xFFFFFFFE, b = 0`，再减 `2**32` 得 `-2`，与 `-1 + 1` 一致。

## 复杂度
时间：O(log n)，n 取 `abs(a)+abs(b)` 的量级，进位每轮至少左移一位。
空间：O(1)，只开了 `carry` 一个临时变量。

## 易错点
- 输入含负数（如 `a = -1, b = 1`）→ 直接循环会因 Python 无限符号位使 `b` 永不归零、死循环 → 先 `& 0xFFFFFFFF` 转无符号，出循环再按 `2**31` 判负还原。
- 结果落在负数区间（如 `a = -2, b = 0`）→ 掩码后得到 `0xFFFFFFFE` 直接返回，输出 4294967294 而非 -2 → 循环后加一步 `if a >= 2**31: a -= 2**32`。

## 如果面试官追问
问：不用循环能写吗？
答：不能，进位链长度取决于数据，最坏要 O(log n) 轮，递归只是把循环换成栈。
