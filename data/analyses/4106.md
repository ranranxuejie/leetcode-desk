## 一句话思路
一次线性扫描，用 `start` 记录不匹配段起点，遇到相等字符就结算上一段，天然保证「极大连续」。

## 怎么做
1. 初始化 `start = -1`，`res = []`，`start` 为 -1 表示当前不在不匹配段内。
2. 从左到右遍历下标 `i`，比较 `s1[i]` 与 `s2[i]`。
3. 若不等且 `start == -1`，把 `start = i`，标记进入一段。
4. 若相等且 `start != -1`，说明上一段在 `i-1` 结束，追加 `[s1[start:i], s2[start:i]]`，再把 `start` 复位为 -1。
5. 循环结束后若 `start != -1`，补追加 `[s1[start:], s2[start:]]`。

拿示例 1 `s1 = "earth"`、`s2 = "empty"` 走一遍关键中间值：`i=0` 时 `'e'=='e'`，`start` 仍为 -1；`i=1` 时 `'a'!='m'`，`start` 置为 1；`i=2` 时 `'r'!='p'`，`start` 保持 1；`i=3` 时 `'t'=='t'`，结算 `s1[1:3]="ar"`、`s2[1:3]="mp"`，`start` 复位 -1；`i=4` 时 `'h'!='y'`，`start=4`；循环结束补结算 `s1[4:]="h"`、`s2[4:]="y"`。

```python
start = -1
res = []
for i in range(len(s1)):
    if s1[i] != s2[i]:
        if start == -1:
            start = i
    elif start != -1:
        res.append([s1[start:i], s2[start:i]])
        start = -1
if start != -1:
    res.append([s1[start:], s2[start:]])
```

## 复杂度
时间 O(n)：`n = len(s1)`，每个下标只比较一次，切片总长也不超过 n。
空间 O(n)：除输出外只开了 `start`、`res`，切片字符串累计长度 O(n)。

## 易错点
- 输入 `s1 = "hot"`、`s2 = "hot"` → 若在循环里无条件 `res.append` 会把空段塞进去 → 必须靠 `start == -1` 判断，只有真正进入过不匹配段才结算。
- 输入 `s1 = "earth"`、`s2 = "empty"` → 若只在「遇到相等」时结算，末尾 `i=4` 的 `"h"/"y"` 会漏掉 → 循环结束后必须再补一次 `if start != -1` 的结算。

## 如果面试官追问
问：若要求返回每段的下标区间而非子串？答：把 `res.append([s1[start:i], s2[start:i]])` 换成 `res.append([start, i-1])`，末尾补 `[start, len(s1)-1]`，逻辑不变。
