## 一句话思路
一次遍历，用 `cur` 记录以当前字符结尾的连续段长度，相邻字符差为 1 就加一，否则重置为 1。

## 怎么做
1. 初始化 `cur = 1`、`best = 1`，因为单字符本身就是连续串。
2. 从下标 1 开始遍历，比较 `ord(s[i]) - ord(s[i-1]) == 1`。
3. 成立则 `cur += 1`，否则 `cur = 1`，每步用 `best = max(best, cur)` 更新答案。
4. 返回 `best`。

以 `s = "abacaba"` 为例：i=1 时 `'b'-'a'==1`，`cur` 从 1 变 2，`best=2`；i=2 时 `'a'-'b'==-1`，`cur` 重置为 1；i=3 时 `'c'-'a'==2`，仍重置为 1。之后 `"ab"` 再出现也只到 2，最终 `best=2`。

```python
cur = best = 1
for i in range(1, len(s)):
    if ord(s[i]) - ord(s[i - 1]) == 1:
        cur += 1
    else:
        cur = 1
    if cur > best:
        best = cur
return best
```

关键点：判断的是**相邻两字符**的差，不是与段首字符的差。`"abacaba"` 中 `s[3]='c'` 与 `s[2]='a'` 差 2，虽然 `'c'` 和段首 `'a'` 差也是 2，但这里必须断开，因为 `"ac"` 不是连续串。

## 复杂度
时间：O(n)，`for` 循环扫一遍 `s`，每次 O(1) 比较。
空间：O(1)，只开了 `cur`、`best`、`i` 三个整型变量。

## 易错点
- 输入 `"za"` → 若用 `ord(s[i]) - ord(s[i-1]) == 1` 判断会得 1（正确），但若误写成 `abs(...) == 1` 会得 2，把 `"za"` 当成连续串。正确做法是不加 `abs`，只认正向差 1。
- 输入 `"abcde"` → 若循环从 i=0 开始并访问 `s[i-1]`，会取到 `s[-1]='e'`，`'a'-'e'` 不为 1，`cur` 被错误重置，答案变成 1。正确做法是 i 从 1 起，或单独处理首字符。
- 输入长度为 1 的 `"a"` → 若 `best` 初始化为 0 且循环不执行，会返回 0。正确做法是 `best` 初始化为 1。

## 如果面试官追问
问：若要求返回最长连续子串本身而非长度？
答：在 `cur > best` 时同步记录 `start = i - cur + 1`，最后返回 `s[start:start+best]`，仍 O(n)。
