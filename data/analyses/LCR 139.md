## 一句话思路
用左右双指针从两端向中间扫，左指针遇偶数、右指针遇奇数就交换，一趟原地完成奇偶分区。

## 怎么做
1. 初始化 `left = 0`、`right = len(actions) - 1`。
2. `left` 右移跳过奇数，停在第一个偶数上。
3. `right` 左移跳过偶数，停在第一个奇数上。
4. 若 `left < right` 就交换 `actions[left]` 与 `actions[right]`，然后两指针各走一步，回到步骤 2。

以 `actions = [1,2,3,4,5]` 为例：`left` 停在 1（值 2），`right` 停在 3（值 4），交换后数组变成 `[1,4,3,2,5]`；下一轮 `left` 走到 2（值 3 是奇数，继续右移）越过，`right` 走到 3 后与 `left` 交错，循环结束，得到 `[1,4,3,2,5]`——奇数 1、3、5 全在偶数 4、2 之前，是合法答案（不要求与示例输出完全一致）。

```python
left, right = 0, len(actions) - 1
while left < right:
    while left < right and actions[left] % 2 == 1:
        left += 1
    while left < right and actions[right] % 2 == 0:
        right -= 1
    if left < right:
        actions[left], actions[right] = actions[right], actions[left]
        left += 1
        right -= 1
return actions
```

内层两个 `while` 都必须带 `left < right` 条件，否则全奇数或全偶数的输入会让指针越界。

## 复杂度
时间 O(n)：`left` 与 `right` 合计最多走 n 步，每个元素只被访问常数次。
空间 O(1)：只在原数组上交换，除两个下标外没开额外结构。

## 易错点
- 输入 `actions = [1,3,5]`（全奇数）→ 若内层写 `while actions[left] % 2 == 1: left += 1` 而不加 `left < right`，`left` 会一路加到 3 越界抛 IndexError → 正确做法是两个内层循环都写成 `while left < right and ...`。
- 输入 `actions = []` 或 `[2]` → 若先做交换再判断边界，或把外层写成 `while left <= right`，单元素时会自己和自己交换、空数组时下标 `-1` 被误用 → 正确做法是外层用 `while left < right`，空数组和单元素直接跳过循环返回原数组。

## 如果面试官追问
问：要求保持奇数之间、偶数之间的相对顺序怎么办？
答：双指针交换会打乱相对顺序，改用稳定划分：新建结果数组，先追加所有奇数再追加所有偶数，空间换 O(n)。
