## 一句话思路
排序后，最小次数用长度为 n 的滑动窗口求最多能框住多少石子，最大次数等于「空位数减去首尾两端中较小的一段空隙」。

## 怎么做
1. 排序 `stones`，记 `n = len(stones)`，总跨度 `span = stones[-1] - stones[0] + 1`，空位数 `empty = span - n`。
2. 最大次数：每轮只能从某一端「消耗」一个端点石子，所以最多能走的步数是 `empty - min(stones[1]-stones[0]-1, stones[-1]-stones[-2]-1)`，即先保留较短的那段空隙不动。
3. 最小次数：用双指针维护窗口 `[i, j]`，使 `stones[j] - stones[i] + 1 <= n`，窗口内石子数 `cnt = j - i + 1`，答案取 `n - max(cnt)`。
4. 特判「窗口内已有 n-1 个连续石子」：此时 `stones[j]-stones[i]+1 == n-1` 且 `cnt == n-1`，需要 2 步而不是 1 步。

以 `stones = [6,5,4,3,10]` 排序得 `[3,4,5,6,10]`，`n=5`，`span=8`，`empty=3`。两端空隙：`stones[1]-stones[0]-1 = 0`，`stones[-1]-stones[-2]-1 = 3`，取 `min=0`，最大次数 `3-0=3`。最小次数：窗口 `[3,4,5,6]` 长度 4 覆盖 4 个石子，`n-4=1`，但 `stones[3]-stones[0]+1 = 4 == n-1` 且 `cnt=4==n-1`，触发特判得 2。

```python
stones.sort()
n = len(stones)
empty = stones[-1] - stones[0] + 1 - n
mx = empty - min(stones[1] - stones[0] - 1, stones[-1] - stones[-2] - 1)
mn, i = n, 0
for j in range(n):
    while stones[j] - stones[i] + 1 > n:
        i += 1
    cnt = j - i + 1
    if cnt == n - 1 and stones[j] - stones[i] + 1 == n - 1:
        mn = min(mn, 2)
    else:
        mn = min(mn, n - cnt)
```

## 复杂度
时间 O(n log n)：排序主导，双指针扫描 O(n)。
空间 O(1)：除排序外只用了 `i, j, cnt` 几个变量。

## 易错点
- 输入 `[1,2,3,4,6]`（n-1 个已连续）→ 若直接取 `n - cnt = 1` 会错成 1 → 必须特判 `cnt == n-1 and 跨度 == n-1` 时答案为 2，因为那个孤立石子无法一步塞进连续段。
- 输入 `[1,2,5]` → 若最大次数直接写 `empty` 会错成 2 → 正确是 `empty - min(0, 2) = 2 - 0 = 2`，但当两端空隙都非零时（如 `[1,5,9]`，`empty=6`，`min(3,3)=3`）必须减掉较短那段，否则会多算。

## 如果面试官追问
问：若要求输出具体移动方案而非次数？
答：最小方案按最优窗口把窗口外的石子逐个填进窗口内空洞，最大方案固定保留较短空隙、从另一端逐个外移。
