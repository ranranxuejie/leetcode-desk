## 一句话思路
递归交换每个节点的左右孩子，因为翻转整棵树等价于先翻转左右子树、再交换这两个孩子。

## 怎么做
1. 空节点直接返回 `None`，这是递归出口。
2. 递归翻转 `root.left` 和 `root.right`，拿到两棵已翻转的子树。
3. 把翻转后的右子树挂到 `root.left`，左子树挂到 `root.right`。
4. 返回 `root`。

以 `root = [5,7,9,8,3,2,4]` 为例：先处理 7 这棵子树，它的孩子 8、3 互换后变成 `[7,3,8]`；再处理 9 这棵子树，孩子 2、4 互换后变成 `[9,4,2]`；最后在根 5 处交换，`root.left` 指向 `[9,4,2]`、`root.right` 指向 `[7,3,8]`，得到 `[5,9,7,4,2,3,8]`。关键中间值就是根节点交换后 `root.left.val == 9`、`root.right.val == 7`。

```python
def flip(node):
    if node is None:
        return None
    left = flip(node.left)
    right = flip(node.right)
    node.left, node.right = right, left
    return node
```

注意 `left`/`right` 必须在交换前存好，否则先改 `node.left` 会丢掉原左子树。

## 复杂度
时间 O(n)：每个节点访问一次，n 为节点数。
空间 O(h)：递归栈深度等于树高 h，最坏链状树 O(n)，额外只开了常数个变量。

## 易错点
- 输入 `root = []`（空树）→ 若没写 `if node is None: return None` 会直接 `AttributeError` → 空节点必须先返回 `None`，主函数也直接返回 `root` 即可。
- 输入 `[5,7,9,8,3,2,4]` → 若写成 `node.left = flip(node.left); node.right = flip(node.right)` 之后再交换，看似也对，但若先 `node.left = node.right` 再递归，原左子树已丢失，结果只剩半边 → 必须先递归取回 `left`、`right` 两个变量，再一次性 `node.left, node.right = right, left`。

## 如果面试官追问
追问：不能用递归怎么办？
答：用栈或队列做迭代，弹出节点时交换其左右孩子，再把非空孩子压入，逻辑与递归一致，空间仍是 O(n)。
