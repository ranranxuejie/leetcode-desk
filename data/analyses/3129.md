## 一句话思路
按「末尾是 0 还是 1」做二维 DP，再用前缀和把「连续段长度 ≤ limit」的转移压成 O(1)。

## 怎么做
1. 定义 `f0[i][j]` = 用 i 个 0、j 个 1 且以 0 结尾的稳定数组数，`f1` 对称；稳定等价于任何连续同色段长度 ≤ limit。
2. 末尾接一个 0：前一段可以是 1 结尾（任意长度），或 0 结尾但 0 的连续段还没到 limit，故 `f0[i][j] = f1[i-1][j] + f0[i-1][j] - f0[i-limit-1][j]`（越界项按 0 处理）。
3. 用 `zero=3, one=3, limit=2` 验证一步：`f0[1][1] = f1[0][1] + f0[0][1] - f0[-1][1] = 1 + 0 = 1`（对应 `[1,0]`），`f1[1][1] = 1`（对应 `[0,1]`），与示例 1 的 2 一致。
4. 答案取 `f0[zero][one] + f1[zero][one]`，全程对 `10**9 + 7` 取模。

```python
MOD = 10**9 + 7
f0 = [[0] * (one + 1) for _ in range(zero + 1)]
f1 = [[0] * (one + 1) for _ in range(zero + 1)]
f0[0][0] = f1[0][0] = 1          # 空数组视作两种结尾的起点
for i in range(zero + 1):
    for j in range(one + 1):
        if i:
            f0[i][j] = (f1[i-1][j] + f0[i-1][j]) % MOD
            if i > limit:
                f0[i][j] = (f0[i][j] - f0[i-limit-1][j]) % MOD
        if j:
            f1[i][j] = (f0[i][j-1] + f1[i][j-1]) % MOD
            if j > limit:
                f1[i][j] = (f1[i][j] - f1[i][j-limit-1]) % MOD
return (f0[zero][one] + f1[zero][one]) % MOD
```

## 复杂度
时间 O(zero × one)：两层循环各走 zero+1、one+1 次，每次 O(1)。
空间 O(zero × one)：开了 f0、f1 两张表，无其他额外结构。

## 易错点
- `limit >= zero` 且 `limit >= one` 时，减法项 `f0[i-limit-1][j]` 的下标恒为负，若直接索引会取到表尾元素（Python 负索引）→ 答案偏小 → 必须先判 `i > limit` 再减。
- `zero=1, one=2, limit=1` 时，若把「连续段 ≤ limit」写成「< limit」，`[1,0,1]` 会被误杀 → 输出 0 而非 1 → 边界是 `i > limit` 才减，不是 `i >= limit`。

## 如果面试官追问
问：zero、one 放大到 10^5 怎么办？答：limit 固定时转移只依赖前 limit+1 行，用滚动数组把空间压到 O(one × limit)，时间不变。
