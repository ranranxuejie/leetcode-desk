## 一句话思路
所有 1 的最小包围矩形由最上/下/左/右的 1 决定，扫一遍记录四个边界即可。

## 怎么做
1. 初始化 `top, bottom = m, -1`，`left, right = n, -1`（m、n 为行列数）。
2. 双重循环遍历每个格子，遇到 `grid[i][j] == 1` 就更新四个边界。
3. 返回 `(bottom - top + 1) * (right - left + 1)`。

以示例 1 `grid = [[0,1,0],[1,0,1]]` 为例：扫到 `(0,1)` 时 `top=0, bottom=0, left=1, right=1`；扫到 `(1,0)` 时 `left` 变 0、`bottom` 变 1；扫到 `(1,2)` 时 `right` 变 2。最终 `top=0, bottom=1, left=0, right=2`，面积 `2 * 3 = 6`。

```python
m, n = len(grid), len(grid[0])
top, bottom = m, -1
left, right = n, -1
for i in range(m):
    for j in range(n):
        if grid[i][j] == 1:
            top = min(top, i)
            bottom = max(bottom, i)
            left = min(left, j)
            right = max(right, j)
return (bottom - top + 1) * (right - left + 1)
```

关键点：矩形必须水平竖直，所以面积只由四个极值决定，中间的 0 不影响结果。

## 复杂度
时间：O(m·n)，每个格子访问一次，m、n 为行列数。
空间：O(1)，只开了 top/bottom/left/right 四个变量。

## 易错点
- 全 1 只有一行时（如 `[[1,1,1]]`），若把 `bottom` 初始化为 0 而非 -1，`max` 逻辑会掩盖真实下界；正确做法是 `bottom = -1`、`top = m`，让第一次命中必然覆盖。
- 边界初始值写反（`top = -1, bottom = m`）→ 面积算成负数或 0；正确做法是 `top` 取大、`bottom` 取小，配合 `min`/`max` 收敛。

## 如果面试官追问
若要求返回矩形坐标而非面积？答：同样四个边界变量，直接返回 `(top, left, bottom, right)`，逻辑不变。
