## 一句话思路
用余弦定理 `cos C = (a²+b²-c²)/(2ab)` 反推每个角，先判三角不等式排除退化三角形。

## 怎么做
1. 排序 `sides`，检查 `sides[0] + sides[1] > sides[2]`，不满足直接返回 `[]`。
2. 对每条边作为对角边，用余弦定理算出对应角的余弦值。
3. 用 `math.degrees(math.acos(cos))` 转成度数。
4. 结果排序后返回。

以 `sides = [3,4,5]` 为例：排序后仍是 `[3,4,5]`，`3+4>5` 成立。对边 3，`cos = (4²+5²-3²)/(2*4*5) = 32/40 = 0.8`，`acos(0.8) ≈ 36.87°`；对边 5，`cos = (3²+4²-5²)/(2*3*4) = 0/24 = 0`，`acos(0) = 90°`。

```python
import math

def internal_angles(sides):
    a, b, c = sorted(sides)
    if a + b <= c:
        return []
    res = []
    for i in range(3):
        x, y, z = sides[i], sides[(i+1) % 3], sides[(i+2) % 3]
        cos_val = (y*y + z*z - x*x) / (2.0 * y * z)
        cos_val = max(-1.0, min(1.0, cos_val))
        res.append(math.degrees(math.acos(cos_val)))
    return sorted(res)
```

## 复杂度
时间：O(1)，只有 3 条边，排序和三次 acos 都是常数。
空间：O(1)，只开了长度为 3 的结果数组。

## 易错点
- 输入 `[2,4,2]` → 若只判 `a+b>=c` 会误判为合法，`2+2=4` 面积为 0 → 必须用严格大于 `a+b>c`。
- 输入 `[1,1,1]` 这类等边三角形 → 浮点误差可能让 `cos_val` 略超 `[-1,1]` 导致 `acos` 抛 `ValueError` → 用 `max(-1.0, min(1.0, cos_val))` 夹紧。

## 如果面试官追问
问：如果边长是浮点数怎么办？答：判三角不等式时加 `1e-9` 容差，`acos` 前同样夹紧 `[-1,1]`，其余逻辑不变。
