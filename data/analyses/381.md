## 一句话思路
数组存值、哈希表存「值 → 下标集合」，删除时用尾元素填洞，保证 O(1)。

## 怎么做
1. `nums` 存所有元素（含重复），`pos` 是 `val -> set(下标)`，插入时把新下标加进 `pos[val]`，返回 `len(pos[val]) == 1`。
2. 删除时从 `pos[val]` 任取一个下标 `i`，把 `nums` 末尾元素 `last` 挪到 `i`，同步改 `pos[last]` 的下标记录。
3. 若 `i` 恰好是末尾下标，跳过第 2 步的搬移，只从 `pos[val]` 删 `i` 并 `pop` 掉 `nums` 末尾。
4. `getRandom` 用 `random.choice(nums)`，每个下标等概率，重复值自然按数量加权。

用示例 `[1,1,2]` 走一遍删除 `1`：`pos[1] = {0,1}`，取 `i = 0`，`last = nums[2] = 2`。把 `nums[0]` 改成 `2`，`pos[2]` 从 `{2}` 变成 `{0,2}`，`pos[1]` 删掉 `0` 后剩 `{1}`，`nums` 变 `[2,1]`。注意此时 `pos[2]` 里还留着旧下标 `2`，必须 `discard(2)` 再 `add(0)`，否则下次删 `2` 会取到越界下标。

```python
def remove(self, val):
    if val not in self.pos:
        return False
    i = self.pos[val].pop()
    last = self.nums[-1]
    if i != len(self.nums) - 1:
        self.nums[i] = last
        self.pos[last].discard(len(self.nums) - 1)
        self.pos[last].add(i)
    self.nums.pop()
    if not self.pos[val]:
        del self.pos[val]
    return True
```

## 复杂度
时间：insert/remove/getRandom 均摊 O(1)，集合增删下标是常数次。
空间：O(n)，`nums` 存 n 个元素，`pos` 存 n 个下标。

## 易错点
- 删除时 `i` 就是末尾下标（如 `[1,2]` 删 `2`，`i = 1 = len-1`）→ 若仍执行搬移，会把 `last` 写回自己并污染 `pos[2]`，导致集合里残留已删下标 → 必须先判 `i != len(nums)-1` 再搬。
- 搬移后忘了从 `pos[last]` 里删旧末尾下标（示例中 `pos[2]` 的 `2`）→ 下次删 `2` 取到越界下标抛异常 → 先 `discard(len-1)` 再 `add(i)`，顺序不能反，否则 `i` 可能被误删。

## 如果面试官追问
问：若要求 remove 删除「最先插入」的那个 val 呢？
答：把 `pos[val]` 从 set 换成有序结构或队列，取队首下标，其余搬移逻辑不变。
