## 一句话思路
逐人累加：k 之前的人最多买 `tickets[k]` 张，k 之后的人最多买 `tickets[k]-1` 张，取 `min` 求和。

## 怎么做
1. 记 `t = tickets[k]`，这是 k 完成买票时的秒数上界。
2. 对 `i < k`，k 完成前第 i 人最多轮到他 `t` 次，贡献 `min(tickets[i], t)`。
3. 对 `i > k`，k 买最后一张时第 i 人还没轮到，贡献 `min(tickets[i], t - 1)`。
4. 加上 k 自己的 `t`，全部相加即答案。

以 `tickets = [2,3,2], k = 2` 为例，`t = 2`：i=0 贡献 `min(2,2)=2`，i=1 贡献 `min(3,2)=2`，k 自己贡献 2，合计 6。注意 i=1 的 `tickets[1]=3` 被截到 2，因为第 3 张票轮不到他买。

```python
def timeRequiredToBuy(tickets, k):
    t = tickets[k]
    total = t
    for i in range(k):
        total += min(tickets[i], t)
    for i in range(k + 1, len(tickets)):
        total += min(tickets[i], t - 1)
    return total
```

关键在 `t - 1`：k 之后的人少买一轮，因为 k 买完最后一张就返回，后面的人不再被服务。

## 复杂度
时间：O(n)，一次遍历数组，n 为 `tickets` 长度。
空间：O(1)，只用了 `t` 和 `total` 两个变量。

## 易错点
- `tickets = [5,1,1,1], k = 0` → 若对 i>k 也用 `min(tickets[i], t)`，会多算 3 秒得 11，正确是 8。k 之后必须用 `t - 1`。
- `tickets = [1,1,1], k = 1` → 若漏掉 k 自己那 1 秒，得 1，正确是 2。`total` 初值必须是 `tickets[k]` 而非 0。

## 如果面试官追问
若 n 扩大到 10^5 且 tickets 值到 10^9，还能 O(n) 吗？答：能，公式只依赖 `min` 截断，与票数大小无关，仍是 O(n)。
