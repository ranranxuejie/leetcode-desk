## 一句话思路
每个 `1` 右侧的 `0` 都能被它跨过一次，答案就是所有 `1` 后面 `0` 的个数之和，从左往右扫一遍累加即可。

## 怎么做
1. 设 `ones = 0`、`ans = 0`，从左到右遍历 `s` 的每个字符 `c`。
2. 遇到 `'1'` 就 `ones += 1`，表示当前有这么多 `1` 可以向右推。
3. 遇到 `'0'` 就 `ans += ones`，因为每个在它左边的 `1` 都能跨过这个 `0` 一次。
4. 遍历结束返回 `ans`。

以 `s = "1001101"` 为例：扫到下标 1 的 `'0'` 时 `ones = 1`，`ans` 变 1；下标 2 的 `'0'` 时 `ans` 变 2；下标 4 的 `'0'` 时 `ones = 2`，`ans` 变 4；下标 6 的 `'0'` 时 `ones = 3`，`ans` 变 7？——注意下标 6 是 `'1'`，所以最终 `ans = 4`，与示例一致。关键中间值：`ones` 在扫到第二个 `1` 后为 2，此时 `ans` 已累计 2。

```python
ones = ans = 0
for c in s:
    if c == '1':
        ones += 1
    else:
        ans += ones
return ans
```

等价写法：先数总 `1` 数 `total`，再扫一遍，遇 `'1'` 减一，遇 `'0'` 加剩余 `ones`。两种写法结果相同，第一种更省一次遍历。

## 复杂度
时间 O(n)：`n = len(s)`，每个字符访问一次。
空间 O(1)：只开了 `ones`、`ans` 两个整数。

## 易错点
- 输入 `s = "00111"` → 若从右往左扫并累加左侧 `1` 数，会得到 0 但逻辑写反成累加右侧 `0` 数仍为 0，看似对；换成 `s = "11100"` 就会错成 0，正确做法是遇 `'0'` 加**它左边**的 `1` 数，即 `"11100"` 应得 6。
- 输入 `s = "10"` → 若把 `ans` 写成 `ones * 0 的个数` 全局相乘，会得 1 正确；但 `s = "1010"` 全局相乘得 2×2=4，实际是 1+2=3，正确做法是逐字符累加而非总数相乘。

## 如果面试官追问
问：要求输出具体操作序列怎么办？
答：从右往左处理每个 `0`，把它左边最近的 `1` 依次右移，记录每次移动的下标即可，操作数不变。
