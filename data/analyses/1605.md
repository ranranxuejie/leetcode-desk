## 一句话思路
贪心：每个格子取 `min(rowSum[i], colSum[j])`，填完立刻从行和列里扣掉，保证剩余和始终非负。

## 怎么做
1. 建 `n × m` 全零矩阵 `ans`，`n = len(rowSum)`，`m = len(colSum)`。
2. 双重循环按行优先遍历，每格填 `v = min(rowSum[i], colSum[j])`。
3. 填完立即执行 `rowSum[i] -= v`、`colSum[j] -= v`，让行、列剩余需求同步收缩。
4. 遍历结束返回 `ans`；每行每列剩余需求必为 0。

以 `rowSum = [3,8], colSum = [4,7]` 为例：`(0,0)` 填 `min(3,4)=3`，扣完后 `rowSum=[0,8]`、`colSum=[1,7]`；`(0,1)` 填 `min(0,7)=0`；`(1,0)` 填 `min(8,1)=1`，`colSum[0]` 归零；`(1,1)` 填 `min(7,7)=7`，全部归零。

```python
n, m = len(rowSum), len(colSum)
ans = [[0] * m for _ in range(n)]
for i in range(n):
    for j in range(m):
        v = min(rowSum[i], colSum[j])
        ans[i][j] = v
        rowSum[i] -= v
        colSum[j] -= v
return ans
```

关键点：`v` 取两者较小值，所以扣减后两个剩余量都不会变负；行优先遍历时，走到第 `i` 行第 `j` 列，前 `j` 列已把 `rowSum[i]` 消耗到只剩「本行还没分配的量」，而 `colSum[j]` 是「本列还没被上面各行填满的量」，两者取小正好把其中一个清零。

## 复杂度
时间：O(n·m)，`n = len(rowSum)`、`m = len(colSum)`，每个格子常数次操作。
空间：O(n·m) 存返回矩阵 `ans`，除此外只用了 `v` 一个临时变量。

## 易错点
- 写成 `ans[i][j] = rowSum[i]` 或直接填 `colSum[j]` → 遇到 `rowSum=[14,9], colSum=[6,9,8]` 时第一格填 14 就超过 `colSum[0]=6`，列和永远补不回来 → 必须取 `min(rowSum[i], colSum[j])`。
- 填完忘了同步扣减 `colSum[j]`（只扣行）→ 示例 1 中 `(1,1)` 会填 `min(8,7)=7` 看似对，但换 `rowSum=[5,7,10], colSum=[8,6,8]` 时第 0 行填完 `colSum` 没变，第 1 行 `(1,0)` 又填 6，`colSum[0]` 被重复消耗成负数 → 行列两个剩余量必须一起扣。

## 如果面试官追问
问：如果要求矩阵元素只能是 0 或 1（即判断是否存在 0-1 矩阵）？
答：贪心不再成立，这是二分图度序列问题，需用 Gale-Ryser 定理或最大流判定。
