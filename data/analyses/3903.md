## 一句话思路
预处理后缀最小值数组，再从左往右滚动维护前缀最大值，第一个满足 `preMax - sufMin[i] <= k` 的下标即为答案。

## 怎么做
1. 先建 `sufMin`，`sufMin[i] = min(nums[i..n-1])`，从右往左一遍填完。
2. 从左往右扫，用变量 `preMax` 滚动记录 `nums[0..i]` 的最大值。
3. 每个 `i` 判断 `preMax - sufMin[i] <= k`，成立就立即返回 `i`。
4. 扫完没命中返回 `-1`。

拿示例 1 `nums = [5,0,1,4]` 说中间值：`sufMin = [0,0,1,4]`。扫到 `i=2` 时 `preMax = 5`，`5 - sufMin[2] = 5 - 1 = 4 > 3`，不成立；到 `i=3` 时 `preMax` 仍是 5，`5 - 4 = 1 <= 3`，返回 3。

```python
n = len(nums)
sufMin = [0] * n
sufMin[-1] = nums[-1]
for i in range(n - 2, -1, -1):
    sufMin[i] = min(nums[i], sufMin[i + 1])

preMax = nums[0]
for i in range(n):
    preMax = max(preMax, nums[i])
    if preMax - sufMin[i] <= k:
        return i
return -1
```

注意 `preMax` 的更新要放在判断之前，否则 `i=0` 时用的是未定义值。

## 复杂度
时间：O(n)，建 `sufMin` 一遍加扫描一遍，各 n 次。
空间：O(n)，额外开了一个长度 n 的 `sufMin` 数组。

## 易错点
- `nums = [0]`、`k = 0` → 若把 `sufMin[-1]` 的初始化漏掉或循环写成 `range(n-2, -1, -1)` 却先访问 `sufMin[i+1]` 越界 → 正确做法是先单独赋 `sufMin[n-1] = nums[n-1]`，再从 `n-2` 倒推。
- `nums = [3,2,1]`、`k = 1` → 若把判断写成 `preMax - sufMin[i] < k`（漏等号）或把 `preMax` 更新放到判断之后 → 会错成 -1 或漏掉合法下标；本题要求「小于等于」，且 `i=0` 的 `preMax` 必须等于 `nums[0]`。

## 如果面试官追问
问：n 放大到 10^7、内存吃紧怎么办？
答：不存 `sufMin` 数组，改为先算全局最小值位置，或直接接受 O(n) 空间；也可用两遍扫描换 O(1) 空间但常数更大。
