## 一句话思路
按模 3 余数计数，0 是「跳过牌」可成对抵消，胜负只由余 1 与余 2 的数量差和 0 的奇偶决定。

## 怎么做
1. 统计 `c0, c1, c2` 分别为模 3 余 0/1/2 的个数，余 0 的石子不改变总和模 3，等价于「跳过一手」。
2. 若 `c0` 为偶数，跳过牌成对抵消，先手只需在余 1 与余 2 之间周旋：`c1 > 0 and c2 > 0` 或某一方数量 ≥ 2 时先手可逼对方踩雷。
3. 若 `c0` 为奇数，跳过牌改变先后手节奏，判据变为 `c1 - c2 > 2 or c2 - c1 > 2`。
4. 用示例 3 `[5,1,2,4,3]` 验证：`c0=1, c1=2, c2=2`，`c0` 奇，`|c1-c2|=0 ≤ 2`，返回 `False`，与官方一致。

```python
c0 = sum(1 for x in stones if x % 3 == 0)
c1 = sum(1 for x in stones if x % 3 == 1)
c2 = sum(1 for x in stones if x % 3 == 2)
if c0 % 2 == 0:
    return c1 > 0 and c2 > 0 or c1 >= 2 or c2 >= 2
else:
    return abs(c1 - c2) > 2
```

## 复杂度
时间 O(n)：一次遍历统计三类余数。
空间 O(1)：只开三个计数器。

## 易错点
- 输入 `[1]`（`c0=0,c1=1,c2=0`）→ 若误判「有石子就能赢」会返回 `True`，实际 Alice 取完总和 1 不可整除但无剩余，Bob 直接获胜 → 必须走 `c1>=2 or c2>=2` 分支返回 `False`。
- 输入 `[3,3,1,1,1]`（`c0=2,c1=3`）→ 若忽略 `c0` 奇偶直接比 `c1` 与 `c2` 会误判 → 偶数个 0 时判据是「两类都非空或某类 ≥2」，奇数个 0 时才用差值 >2。

## 如果面试官追问
问：若要求输出 Alice 的必胜首步？答：偶数 `c0` 时优先取数量多的那类余数，奇数 `c0` 时取差值大的一侧，具体下标扫一遍即可。
