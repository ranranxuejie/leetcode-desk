## 一句话思路
先用哈希表数每个字符串出现次数，再按原数组顺序扫一遍，数到第 k 个计数为 1 的就返回。

## 怎么做
1. 用 `Counter(arr)` 建频次表 `cnt`。
2. 顺序遍历 `arr`，遇到 `cnt[s] == 1` 就把计数器 `seen` 加一。
3. `seen == k` 时立刻返回当前 `s`，遍历结束没凑够就返回 `""`。

以示例 1 的 `arr = ["d","b","c","b","c","a"]` 为例，`cnt` 为 `{"d":1,"b":2,"c":2,"a":1}`。顺序扫到 `"d"` 时 `seen` 变 1，扫到 `"a"` 时 `seen` 变 2，等于 `k=2`，返回 `"a"`。注意 `"b"`、`"c"` 虽然排在 `"a"` 前面，但 `cnt` 为 2，直接跳过，不占 `seen` 的名额。

```python
from collections import Counter

cnt = Counter(arr)
seen = 0
for s in arr:
    if cnt[s] == 1:
        seen += 1
        if seen == k:
            return s
return ""
```

关键点：**必须按 `arr` 原顺序扫**，不能遍历 `cnt` 的键。字典键的顺序是首次插入顺序，本题恰好一致，但依赖它属于隐性假设，直接扫 `arr` 更稳。

## 复杂度
时间 O(n)：建 `cnt` 扫一遍，再扫一遍 `arr`，n 为 `arr` 长度。
空间 O(m)：`cnt` 存 m 个不同字符串，m ≤ n。

## 易错点
- 输入 `arr = ["a","b","a"]`、`k = 3`：若把 `"a"` 也算进唯一字符串（漏判 `cnt["a"] == 2`），会误以为有 2 个候选、`seen` 计数错位；正确做法是只对 `cnt[s] == 1` 的 `s` 递增 `seen`，最终 `seen` 只有 1，返回 `""`。
- 输入 `arr = ["aaa","aa","a"]`、`k = 1`：若先对 `arr` 排序或按长度处理，会打乱原顺序，可能返回 `"a"`；正确做法是全程保持 `arr` 的原始下标顺序，第一个满足 `cnt[s] == 1` 的 `"aaa"` 就是答案。

## 如果面试官追问
若 `arr` 长度涨到 10^7、内存吃紧怎么办？答：仍用 `Counter` 但只存计数，第二遍流式扫 `arr`，不额外建唯一字符串列表，空间 O(不同串数)。
