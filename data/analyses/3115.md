## 一句话思路
只需找到最左和最右的质数下标，答案就是两者之差，因为距离最大的两个质数必然取在两端。

## 怎么做
1. 预处理 100 以内的质数表（`nums[i] <= 100`），用埃氏筛或直接硬编码集合。
2. 从左往右扫，第一个命中的下标记为 `left`。
3. 从右往左扫，第一个命中的下标记为 `right`。
4. 返回 `right - left`；若只有一个质数，`left == right`，自然得 0。

以 `nums = [4,2,9,5,3]` 为例：左扫时 `i=0` 是 4 跳过，`i=1` 是 2 命中，`left = 1`；右扫时 `i=4` 是 3 命中，`right = 4`；返回 `4 - 1 = 3`。

```python
def is_prime(x):
    if x < 2:
        return False
    for d in range(2, int(x ** 0.5) + 1):
        if x % d == 0:
            return False
    return True

n = len(nums)
left = next(i for i in range(n) if is_prime(nums[i]))
right = next(i for i in range(n - 1, -1, -1) if is_prime(nums[i]))
return right - left
```

注意 `next(...)` 依赖题目保证「至少有一个质数」，否则会抛 `StopIteration`。若想更稳，可写成显式循环并初始化 `left = -1`。

## 复杂度
时间：O(n·√100)，每个元素试除到 10，n 来自数组长度。
空间：O(1)，只用了 `left`、`right` 两个下标变量。

## 易错点
- `nums = [1,2]` → 把 1 当质数，`left` 错成 0，答案变 2 → 质数判定必须先判 `x < 2` 返回 `False`。
- `nums = [4,8,2,8]` → 只找到一个质数时若用「两个不同下标」的写法会越界或返回错误值 → 允许 `left == right`，直接返回 0 即可。

## 如果面试官追问
问：若 `nums[i]` 上限改成 `10**9` 怎么办？
答：不能预筛到 1e9，改为对每个数做 O(√x) 试除，或只对出现的值做 Miller-Rabin。
