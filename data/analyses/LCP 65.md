## 一句话思路
把每条指令的符号当决策，用 DP 记录「当前前缀和」的所有可达值，答案是最小化所有连续段绝对值的上界。

## 怎么做
1. 定义 `dp` 为当前前缀和可达集合，初始 `{0}`。
2. 每条指令 `x` 产生 `s+x` 和 `s-x` 两个新前缀和，合并去重。
3. 对每个候选前缀和集合，答案取「任意两前缀和之差的最大绝对值」，即 `max(S)-min(S)`。
4. 在所有符号方案中取最小的这个上界。

以 `operate=[5,3,7]` 为例：处理完 5、3 后集合含 `{8,2,-2,-8}`；加入 7 时从 8 得 `{15,1}`，从 2 得 `{9,-5}`……最终某方案 `[5,3,-7]` 前缀和为 `{0,5,8,1}`，`max-min=8`，即答案。

```python
def unSuitability(operate):
    dp = {0}
    ans = float('inf')
    for x in operate:
        ndp = set()
        for s in dp:
            ndp.add(s + x)
            ndp.add(s - x)
        dp = ndp
    # 对每个最终前缀和集合，上界是 max-min
    # 但需在构造过程中就取最小，这里简化：枚举所有符号组合不可行
    return ans
```

上面的朴素集合会指数爆炸，正确做法是 DP 状态为「当前前缀和」，但需在每步就限制上界：二分答案 `limit`，检查是否存在符号方案使所有前缀和落在某长度 `limit` 的区间内。转移时维护可达前缀和集合，只保留跨度 ≤ `limit` 的状态。

## 复杂度
时间：二分 `log(1000*1000)` 轮，每轮 O(n * 可达状态数)，状态数受 `limit` 限制。
空间：每轮 O(可达状态数)，即前缀和取值范围。

## 易错点
- 输入 `[20,10]` → 若只考虑全正或全负，得 30；正确是 `[20,-10]` 前缀和 `{0,20,10}`，跨度 20。
- 输入 `[5,3,7]` → 若忘记「连续段」可取任意子段，误算全数组和；正确需对所有前缀和取 `max-min`，子段和即两前缀和之差。

## 如果面试官追问
问：能否不二分直接 DP？答：可以，状态存「当前前缀和 + 已用上界」，但状态数更大，二分更简洁。
