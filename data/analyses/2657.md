## 一句话思路
用计数数组 `cnt` 记录每个值在 A、B 前缀中出现的次数，扫到某值计数变 2 时公共数 +1。

## 怎么做
1. 开 `cnt = [0]*(n+1)` 和 `ans = []`，`common = 0`。
2. 对每个下标 `i`，把 `A[i]` 的计数 +1，若变成 2 则 `common += 1`。
3. 同样处理 `B[i]`，若 `cnt[B[i]]` 变成 2 则 `common += 1`。
4. 把 `common` 追加进 `ans`，循环结束返回。

以 `A = [1,3,2,4], B = [3,1,2,4]` 为例：`i=0` 时 `cnt[1]=1`、`cnt[3]=1`，`common=0`；`i=1` 时 `cnt[3]` 变 2（`common=1`），`cnt[1]` 变 2（`common=2`），`ans[1]=2`。

```python
n = len(A)
cnt = [0] * (n + 1)
ans, common = [], 0
for i in range(n):
    cnt[A[i]] += 1
    if cnt[A[i]] == 2:
        common += 1
    cnt[B[i]] += 1
    if cnt[B[i]] == 2:
        common += 1
    ans.append(common)
return ans
```

关键点：一个值在 A 前缀出现一次、B 前缀出现一次，计数恰好到 2，此时它才成为公共元素；排列保证每个值最多出现两次，所以 `== 2` 不会重复触发。

## 复杂度
时间 O(n)：单次遍历，每个元素常数次操作。
空间 O(n)：`cnt` 长度 n+1，`ans` 长度 n。

## 易错点
- 输入 `A=[2,3,1], B=[3,1,2]` 时，若在 `i=0` 就同时把 `A[0]`、`B[0]` 都加完再判断，容易漏掉「同一轮里 A 和 B 各贡献一次」的叠加；正确做法是分开两次判断，各自 `== 2` 时 `common += 1`，`i=0` 得 0、`i=1` 得 1。
- 若用集合 `set(A[:i+1]) & set(B[:i+1])` 求交集，`i=0` 时 `A[:1]={2}`、`B[:1]={3}` 交集为空得 0 没错，但每轮重建切片是 O(n²)；正确做法是维护 `cnt` 增量更新，避免切片。

## 如果面试官追问
问：若 A、B 不是排列、元素可重复怎么办？
答：`cnt` 改成记录「A 前缀出现次数」与「B 前缀出现次数」两个数组，公共数按 `min` 累加，不能再用 `== 2` 判断。
