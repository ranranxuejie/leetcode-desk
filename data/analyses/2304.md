## 一句话思路
逐行 DP：`dp[j]` 表示到达当前行第 j 列的最小代价，转移时枚举上一行所有列取最小。

## 怎么做
1. 初始化 `dp = grid[0][:]`，第一行没有移动代价，直接就是单元格值。
2. 对第 `i` 行（`i` 从 1 到 m-1），新建 `ndp[j] = grid[i][j] + min(dp[k] + moveCost[grid[i-1][k]][j] for k in range(n))`。
3. 用 `ndp` 覆盖 `dp`，最后返回 `min(dp)`。

以示例 1 为例，`grid = [[5,3],[4,0],[2,1]]`。第一行 `dp = [5,3]`。处理第二行时，对 `j=1`（值为 0 的格子）：从 `k=0`（值 5）来是 `5 + moveCost[5][1] = 5 + 3 = 8`，从 `k=1`（值 3）来是 `3 + moveCost[3][1] = 3 + 6 = 9`，取 8，加 `grid[1][1]=0` 得 `ndp[1]=8`。同理 `ndp[0] = min(5+moveCost[5][0], 3+moveCost[3][0]) + 4 = min(14,21)+4 = 18`。第二行 `dp = [18,8]`。第三行对 `j=1`：从 `k=0`（值 4）来 `18 + moveCost[4][1] = 18+4 = 22`，从 `k=1`（值 0）来 `8 + moveCost[0][1] = 8+8 = 16`，取 16，加 `grid[2][1]=1` 得 17。答案 `min(dp) = 17`。

```python
m, n = len(grid), len(grid[0])
dp = grid[0][:]
for i in range(1, m):
    ndp = [0] * n
    for j in range(n):
        best = min(dp[k] + moveCost[grid[i-1][k]][j] for k in range(n))
        ndp[j] = best + grid[i][j]
    dp = ndp
return min(dp)
```

## 复杂度
时间：O(m·n²)，每行 n 个目标列各枚举 n 个来源列。
空间：O(n)，只保留两行 dp，`ndp` 每轮新建。

## 易错点
- 把 `moveCost` 的第一维下标写成列号 `j` 而非**上一行单元格的值** `grid[i-1][k]`：示例 1 中从值 5 出发应查 `moveCost[5]`，写成 `moveCost[0]` 会得到 9 而非 3，答案偏大。
- 忘记加当前格子的值 `grid[i][j]`：示例 1 第二行 `ndp[1]` 会算成 8 而非 8+0=8（此处恰好为 0 不暴露），但第三行 `j=1` 会算成 16 而非 17，答案错成 16。

## 如果面试官追问
问：n 放大到 10⁵ 怎么办？答：把 `dp[k] + moveCost[grid[i-1][k]][j]` 拆成按来源值分组，对每个 j 维护前缀最小值，或用线段树按列建，降到 O(m·n·log n)。
