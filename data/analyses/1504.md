## 一句话思路
按行累加每列向上的连续 1 高度 `h[j]`，对每行用单调栈统计以该行为底的全 1 子矩形数，逐行求和。

## 怎么做
1. 维护 `h`，长度 n，`mat[i][j]==1` 时 `h[j] += 1`，否则 `h[j] = 0`。
2. 对每行的 `h` 求「以每个 j 为右边界、高度为 h[j] 的矩形个数」之和，用单调栈一次扫完。
3. 栈存下标，保持 `h` 递增；弹出时用 `left`（弹出后栈顶下标）和 `width = j - left` 算贡献。

以示例 1 第 3 行（i=2）为例，此时 `h = [3,2,0]`。扫到 j=2 时 h[2]=0，把栈里 (0,3)、(1,2) 全弹出：弹 (1,2) 时 left=0，`width=2-0=2`，贡献 `2*2=4`；弹 (0,3) 时 left=-1，`width=2-(-1)=3`，贡献 `3*3=9`。这一行合计 13 中的 4+9=13，加上前两行的 0 和 0，正好 13。

```python
h = [0] * n
ans = 0
for row in mat:
    for j in range(n):
        h[j] = h[j] + 1 if row[j] else 0
    stack = []
    for j in range(n + 1):
        cur = h[j] if j < n else 0
        while stack and h[stack[-1]] >= cur:
            k = stack.pop()
            left = stack[-1] if stack else -1
            ans += h[k] * (j - left)
        stack.append(j)
```

注意 `j == n` 时补一个 `cur = 0` 把栈清空，否则最后一段递增高度不会被结算。

## 复杂度
时间 O(m·n)：每行每列各入栈出栈一次，n 是列数。
空间 O(n)：`h` 和 `stack` 各开 n，m 行不额外存。

## 易错点
- 忘记在 `j == n` 补哨兵 0：示例 1 第 3 行 `h=[3,2,0]` 恰好末尾是 0 能清空，但若某行 `h=[1,2,3]`（如 mat 全 1 的 3 列），栈里三个元素永不弹出，这一行贡献算成 0，答案偏小。正确做法是循环到 `n+1`，越界时 `cur=0`。
- 弹出条件写成 `>` 而非 `>=`：示例 1 第 3 行 `h=[3,2,0]` 无相等值看不出差别，但遇到 `h=[2,2]` 时用 `>` 会让两个 2 都留在栈里，宽度算错，贡献变成 2+4=6 而非正确的 2+4=6 之外的重复计数。正确做法是 `>=`，保证相等高度也弹出并按 `left` 重算宽度。

## 如果面试官追问
问：如果要求返回所有全 1 子矩形的坐标列表而不是计数？
答：计数改成在弹出时枚举 `left+1..j-1` 为右边界、`h[k]` 个高度起点，输出量本身是答案规模，复杂度变为 O(答案数)。
