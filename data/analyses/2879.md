## 一句话思路
用 pandas 的 `head(3)` 直接切片前 3 行，因为 DataFrame 行序即输入顺序，取头部无需排序。

## 怎么做
1. 确认输入 `employees` 是 pandas DataFrame，行序就是示例中 Bob、Alice、Tatiana 的排列顺序。
2. 调用 `employees.head(3)`，它等价于 `employees.iloc[:3]`，保留原列名与索引。
3. 返回结果直接作为答案，不要 `reset_index`，因为示例输出索引仍是 0、1、2。

关键中间值：对示例输入调用 `head(3)` 后，结果 `shape` 从 `(6, 4)` 变为 `(3, 4)`，第 4 行 Annabelle 被截掉，前三行 `employee_id` 依次为 `3, 90, 9`。

```python
import pandas as pd

def selectFirstRows(employees: pd.DataFrame) -> pd.DataFrame:
    return employees.head(3)
```

若环境要求写成类方法，只需把函数体换成 `return employees.head(3)`，不要额外做 `sort_values` 或 `drop_duplicates`。

## 复杂度
时间：O(k)，k=3，只复制前 3 行，与总行数 n 无关。
空间：O(k)，额外存 3 行 4 列，不复制整个 DataFrame。

## 易错点
- 输入行数少于 3（如只有 2 行）→ 若用 `employees.iloc[0:3]` 其实也安全，但若手写 `employees.iloc[[0,1,2]]` 会抛 IndexError → 正确做法是用 `head(3)` 或 `iloc[:3]`，越界自动截断。
- 误以为要按 `salary` 或 `employee_id` 排序后取前三 → 示例输出顺序是 Bob、Alice、Tatiana，并非按 id 或薪资排序 → 正确做法是保持原行序，不做任何 `sort_values`。

## 如果面试官追问
问：如果要求「按 salary 降序取前三」怎么改？
答：`employees.sort_values('salary', ascending=False).head(3)`，注意并列薪资时需再指定 `kind='stable'` 或加次级排序键。
