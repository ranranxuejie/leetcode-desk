## 一句话思路
按河道顺序做 DP，状态是「当前浮木被推到哪」，用前缀最小值把 O(num) 的转移压成 O(1)。

## 怎么做
1. 把 `wood` 按左端点排序，记第 i 块为 `[l, r]`，`len = r - l`。
2. 定义 `dp[i][x]`：第 i 块浮木左端点落在 x 时，前 i 块全部连通的最小花费。初始 `dp[0][x] = abs(x - l0)`。
3. 转移：第 i 块要能和上一块重叠，需 `x <= prev_x + len_{i-1}` 且 `x + len_i >= prev_x`，即 `prev_x ∈ [x - len_i, x + len_{i-1}]`。所以 `dp[i][x] = abs(x - l_i) + min(dp[i-1][prev_x])`，区间取最小。
4. 用前缀/后缀最小值维护上一行，x 只需枚举到 `num` 范围内的有效区间。

以示例 1 `[[1,2],[4,7],[8,9]]` 为例：第 0 块 `[1,2]`，第 1 块 `[4,7]` 长度 3。当第 1 块左端 `x=4` 时，`prev_x ∈ [4-3, 4+1] = [1,5]`，取 `dp[0]` 在 `[1,5]` 的最小值即 `dp[0][2]=1`（把 `[1,2]` 推到 `[2,3]`），故 `dp[1][4]=1+0=1`。

```python
# 上一行用数组 pre 表示，区间最小值用滑窗/前缀预处理
for i in range(1, n):
    l, r = wood[i]
    length = r - l
    # 对每个 x，取 pre 在 [x-length, x+prev_len] 的最小值
    # 用单调队列或前后缀 min 实现 O(1) 查询
    cur = [abs(x - l) + query_min(pre, x - length, x + prev_len)
           for x in range(lo, hi + 1)]
    pre, prev_len = cur, length
```

## 复杂度
时间：O(n · num) 枚举 x，n 为浮木数，num 为河道长度。
空间：O(num) 存上一行 DP 数组。

## 易错点
- 输入 `[[1,5],[1,1],[10,10],[6,7],[7,8]]`：若只按原顺序 DP，`[10,10]` 和 `[1,1]` 距离远，会漏掉「都推到 6」的方案 → 必须先按左端点排序再 DP。
- 区间边界 `prev_x ∈ [x - len_i, x + len_{i-1}]`：若写成 `[x - len_i, x + len_i]`，示例 1 中 `x=4` 会取到 `prev_x=7` 之外的非法值 → 上界必须是 `x + len_{i-1}`，即上一块自己的长度。

## 如果面试官追问
问：num 到 1e9 怎么办？答：DP 的 x 只需在每块浮木原始区间附近取值，离散化到 O(n) 个候选点即可。
