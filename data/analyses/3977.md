## 一句话思路
在「节点 × 剩余电量」的状态图上跑 Dijkstra，按时间最小、同时间电量最大做双关键字松弛。

## 怎么做
1. 状态定为 `(u, p)`：在节点 `u` 且剩余电量 `p`，`dist[u][p]` 存最小时间，`best[u][p]` 存该时间下最大电量（其实 `p` 就是电量，只需 `dist`）。
2. 从 `(source, power)` 出发，堆里放 `(time, -power, u)`，弹出时若 `time` 大于 `dist[u][p]` 就跳过。
3. 松弛条件：`p >= cost[u]` 才能走边，新电量 `np = p - cost[u]`，新时间 `nt = time + t`。
4. 到达 `target` 时不能立刻返回，因为可能还有更小时间的路径没弹出；用 `ans_time`、`ans_power` 记录最优，堆空后输出。

以示例 1 为例：`power = 4`，从 `(0,4)` 弹出，走 `0->2` 后 `np = 4 - cost[0] = 2`，`nt = 1`；再走 `2->3` 时 `np = 2 - cost[2] = 1`，`nt = 2`；`3->4` 时 `np = 1 - cost[3] = 0`，`nt = 3`，得到 `[3,0]`。而 `0->1` 分支 `np = 2 < cost[1] = 3`，直接剪掉。

```python
import heapq
INF = float('inf')
dist = [[INF] * (power + 1) for _ in range(n)]
dist[source][power] = 0
pq = [(0, -power, source)]
ans_t, ans_p = INF, -1
while pq:
    t, negp, u = heapq.heappop(pq)
    p = -negp
    if t > dist[u][p]:
        continue
    if u == target and (t < ans_t or (t == ans_t and p > ans_p)):
        ans_t, ans_p = t, p
    if p < cost[u]:
        continue
    for v, w in adj[u]:
        np, nt = p - cost[u], t + w
        if nt < dist[v][np]:
            dist[v][np] = nt
            heapq.heappush(pq, (nt, -np, v))
```

## 复杂度
时间：`O((n·power + m·power) log(n·power))`，堆里最多 `n·power` 个状态。
空间：`dist` 表 `O(n·power)`，堆同阶，`adj` 占 `O(m)`。

## 易错点
- `source == target` 时（示例 2）：若先判断「必须走一条边才算到达」，会输出 `[-1,-1]` 或错误时间；正确做法是初始就把 `(source, power)` 当作候选答案，时间 0、电量 `power`。
- 电量恰好等于 `cost[u]` 时：若写成 `p > cost[u]` 才放行，示例 1 的 `3->4` 会被误判不可走（`p = 1 = cost[3]`），答案变成 `[-1,-1]`；正确条件是 `p >= cost[u]`，走完 `np` 可以为 0。
- 到达 `target` 就 `return`：会漏掉同时间但电量更大的路径，`answer[1]` 偏小；必须等堆空或确认无更优时间。

## 如果面试官追问
问：`power` 放大到 `10^9` 怎么办？
答：状态数爆炸，需换思路——按时间做 Dijkstra，每个节点只保留「到达时间相同下最大电量」的 Pareto 前沿，用有序结构剪枝。
