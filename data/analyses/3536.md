## 一句话思路
把 n 的每一位拆出来，最大乘积必然来自最大的两个数字，所以只需找最大的两位。

## 怎么做
1. 用 `while n > 0` 循环，每次取 `d = n % 10`，再 `n //= 10`，逐个拿到数字。
2. 维护两个变量 `first`（最大）和 `second`（次大），每来一个 `d` 先和 `first` 比，再和 `second` 比。
3. 循环结束后返回 `first * second`。

以 `n = 124` 为例：初始 `first = second = 0`。取到 `d = 4`，`first` 变 4、`second` 变 0；取到 `d = 2`，2 不大于 4，但大于 0，`second` 变 2；取到 `d = 1`，1 不大于 2，`second` 保持 2。最终 `4 * 2 = 8`，与示例一致。注意 `n = 22` 时两个 2 都要算进去：第一个 2 进 `first`，第二个 2 不大于 `first` 但大于 `second`，于是 `second = 2`，得到 `2 * 2 = 4`，这正是题面允许重复使用同一数字的含义。

```python
first = second = 0
while n > 0:
    d = n % 10
    if d > first:
        first, second = d, first
    elif d > second:
        second = d
    n //= 10
return first * second
```

关键在 `elif`：如果写成两个独立 `if`，`d = 4` 时会先让 `first = 4`，紧接着又拿 4 和 `second` 比，把 `second` 也刷成 4，`124` 就会错算成 16。

## 复杂度
时间：O(log n)，循环次数等于 n 的十进制位数，n 每轮 `// 10` 缩小十倍。
空间：O(1)，只开了 `first`、`second`、`d` 三个整数变量。

## 易错点
- 输入 `n = 22` → 若只记录一个最大值 `first`，会返回 `2 * 0 = 0` 或漏掉重复数字 → 必须同时维护 `second`，让第二个 2 落进次大值。
- 输入 `n = 124` → 若把更新写成两个并列 `if`，`second` 会被同一个 4 覆盖，返回 16 → 用 `elif` 保证一个数字只占一个坑位。

## 如果面试官追问
问：如果要求返回乘积最大的那两个数字本身（输出方案）？
答：在更新 `first`/`second` 时同步记录它们来自哪一位，返回 `(first, second)` 即可，逻辑不变。
