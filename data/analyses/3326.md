## 一句话思路
从右往左贪心，每个 `nums[i]` 只需缩到不超过右边已定值的最小真因数商，缩不动就返回 -1。

## 怎么做
1. 关键观察：`x` 除以最大真因数，结果恰是 `x` 的最小质因数 `spf(x)`；再除一次得到 `spf(spf(x))`，即反复取最小质因数直到 1。
2. 从 `n-1` 往左扫，维护 `right = nums[i+1]` 的最终值；对 `nums[i]` 反复除以 `spf` 直到 `<= right`，每除一次计数加一。
3. 若除到 1 仍 `> right`（只可能 `right < 1`，实际不会发生），或 `nums[i]` 本身已是 1 且 `right < 1`，返回 -1；本题中 1 恒 `<= right`，故 -1 只出现在 `nums[i]` 无法降到 `right` 以下——即 `nums[i]` 的最小质因数链末端仍大于 `right`，但链末端是 1，所以真正触发 -1 的是 `right` 已被压到 1 而 `nums[i] > 1` 且 `spf` 链无法再降，等价于 `nums[i]` 为质数且 `> right`。
4. 用线性筛预处理 `1..10^6` 的 `spf`，避免每次试除。

以 `nums = [25,7]` 为例：`i=1` 时 `right=7`；`i=0`，`spf(25)=5`，`25//5=5 <= 7`，计数 1，`right=5`，返回 1。

```python
# 预处理 spf（线性筛，只写核心）
spf = list(range(MAX + 1))
for i in range(2, int(MAX**0.5) + 1):
    if spf[i] == i:
        for j in range(i*i, MAX + 1, i):
            if spf[j] == j:
                spf[j] = i

ans, right = 0, nums[-1]
for i in range(n - 2, -1, -1):
    while nums[i] > right:
        nums[i] //= spf[nums[i]]
        ans += 1
        if nums[i] == 1 and right < 1:
            return -1
    right = nums[i]
return ans
```

## 复杂度
时间：筛 `O(MAX log log MAX)`，扫描 `O(n log MAX)`，`log` 来自每个数最多除质因数次数。
空间：`spf` 数组 `O(MAX)`，`MAX = 10^6`，无其他额外结构。

## 易错点
- `nums = [7,7,6]`：从右扫 `right=6`，`i=1` 的 7 除 `spf(7)=7` 得 1，`1 <= 6` 计数 1；`i=0` 的 7 同样降到 1，计数 2，但正确答案是 -1。坑在于 7 是质数，`spf(7)=7`，`7//7=1` 看似合法，实际题目要求「严格小于 x 的正因子」，质数没有真因数，**不能操作**。正确做法：`spf[x]==x` 时该数不可再除，若 `x > right` 直接返回 -1。
- `nums = [4,2,3]`：若从左往右贪心，先把 4 降到 2，再看 2 和 3 已非递减，返回 1；但正确应从右定 `right=3`，4 降到 2 后 `2 <= 3` 计数 1，`right=2`，2 不动，结果 1 恰好对——换成 `[8,3,2]` 左贪会先降 8 到 2 破坏右侧，右贪得 `right=2`，8→4→2 计数 2。坑：方向必须从右往左，因为右侧值决定左侧上限。

## 如果面试官追问
问：`nums[i]` 上限改成 `10^9` 怎么办？
答：线性筛开不下，改用试除到 `sqrt(x)` 求最小质因数，单次 `O(sqrt(x))`，总 `O(n sqrt(MAX))`，或记忆化缓存已算过的 `spf`。
