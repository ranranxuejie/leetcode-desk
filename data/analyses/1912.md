## 一句话思路
用「按电影分组的未借出最小堆」+「全局已借出最小堆」，配合 `(shop, movie) -> price` 哈希表做懒删除。

## 怎么做
1. 建 `price[(shop, movie)]` 存价格；`avail[movie]` 是堆，元素 `(price, shop)`，初始把每条 entries 压进去。
2. `search(movie)`：从 `avail[movie]` 弹堆顶，跳过 `(shop, movie)` 已在借出集合里的条目，收集最多 5 个 shop，再把弹出的全部压回。
3. `rent(shop, movie)`：把 `(shop, movie)` 加入 `rented` 集合，并向 `borrowed` 堆压 `(price, shop, movie)`。
4. `drop(shop, movie)`：从 `rented` 移除，并把 `(price, shop)` 压回 `avail[movie]`；`report()` 同样弹 `borrowed` 堆顶、跳过不在 `rented` 里的条目，取 5 个后压回。

以示例为例：`search(1)` 时 `avail[1]` 堆顶依次弹出 `(4,1)`、`(5,0)`、`(5,2)`，得到 `[1,0,2]`；随后 `rent(0,1)` 使 `rented={(0,1)}`，`report()` 弹 `borrowed` 得 `(5,0,1)` 与 `(7,1,2)`，输出 `[[0,1],[1,2]]`。

```python
import heapq

def search(self, movie):
    h, res = self.avail[movie], []
    tmp = []
    while h and len(res) < 5:
        p, s = heapq.heappop(h)
        tmp.append((p, s))
        if (s, movie) not in self.rented:
            res.append(s)
    for x in tmp:
        heapq.heappush(h, x)
    return res

def rent(self, shop, movie):
    self.rented.add((shop, movie))
    heapq.heappush(self.borrowed, (self.price[(shop, movie)], shop, movie))
```

## 复杂度
时间：每次 search/report 弹压 O(k log m)，k≤5 加上被跳过的脏条目，摊还 O(log m)；rent/drop O(log m)。
空间：`price` 与两个堆共 O(E)，E 为 entries 数，脏条目最多累积到操作总数。

## 易错点
- `search` 弹出的脏条目（已借出的 `(shop, movie)`）必须压回堆，否则 `drop` 后这部电影就再也搜不到；示例中 `rent(0,1)` 后若丢弃 `(5,0)`，`drop` 再 `search(1)` 会漏掉商店 0。
- `report` 的排序键是 `(price, shop, movie)` 三元组，而 `search` 只需 `(price, shop)`；若 `borrowed` 堆只存 `(price, shop)`，同价同店不同电影时顺序会错，必须把 movie 也入堆。

## 如果面试官追问
问：若 search 要返回前 k 个而非固定 5 个？答：堆不变，把 `len(res) < 5` 改成 `< k`，复杂度变为 O(k log m)。
