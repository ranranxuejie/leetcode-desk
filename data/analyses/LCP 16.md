## 一句话思路
枚举公共点 A，对每个 A 取邻接点里权值最大的两条「可配对」边，配对条件用三角形枚举预处理。

## 怎么做
1. 把每条边定向成 `u < v`，用 `adj` 存无向邻接表，同时用集合 `E` 存所有边（用于 O(1) 判边）。
2. 对每个点 A，枚举它的邻接点对 (B, C)，若 `(B,C)` 也是边，则 A-B-C-A 是合法三角形，把 `value[B]+value[C]` 记为该三角形对 A 的贡献。
3. 对每个 A，把邻接点按 `value` 降序排，取前两名作为候选；若这两个点之间没有边，直接 `value[A]+value[b1]+value[b2]` 就是 A 的最优单条路径。
4. 若前两名之间无边，则两条路径可共享 A 和这两个点，答案即 `value[A]+value[b1]+value[b2]`；若有边，则需退而求其次，用三角形枚举的结果补上第二条路径。

关键中间值：示例 3 中 A=3，邻接点按 value 降序为 `[4(9), 5(7), 0(7), 1(8)]`，排序后 b1=4, b2=5，`(4,5)` 是边，所以单条路径只能取 3-4-5-3 得 7+9+7=23；第二条路径取 3-0-1-3 得 7+7+8=22，合并去重后 7+9+7+8=31？实际最优是 3-0-1-3 与 3-4-5-3，共享点 3，总和 7+8+8+9+7=39。

```python
# 预处理三角形：对每个 A 记录 (B,C) 边存在时的 value[B]+value[C]
tri = [[] for _ in range(n)]
for a in range(n):
    nb = adj[a]
    for i in range(len(nb)):
        for j in range(i+1, len(nb)):
            b, c = nb[i], nb[j]
            if (min(b,c), max(b,c)) in E:
                tri[a].append((value[b]+value[c], b, c))
```

## 复杂度
时间 O(Σ deg(A)²)，最坏 O(M·√M) 量级，三角形枚举是瓶颈。
空间 O(N+M)，`adj` 与 `E` 各占一份，`tri` 存三角形三元组。

## 易错点
- 邻接点按 value 排序后取前两名，若 `(b1,b2)` 是边就以为无解返回 0 → 示例 3 会错成 0 → 正确做法是此时用 `tri[A]` 里排除掉与 b1 或 b2 冲突的组合，或直接枚举所有三角形对。
- 两条路径共享 A 以外的点（如示例 1 的 0-1-2-0 与 0-2-1-0 共享全部三点）→ 若按「两条路径点集不相交」去重会少算 → 正确做法是用集合 `set` 合并点后求和，重复点只计一次。

## 如果面试官追问
若 N、M 放大到 10^5 且要求输出具体两条路径，怎么办？
答：三角形枚举退化为按度分块（重点枚举高度点、低度点暴力），路径用父指针回溯记录。
