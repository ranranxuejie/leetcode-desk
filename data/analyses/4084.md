## 一句话思路
沿指针走，用 `visited` 集合记录走过的坐标，下一步越界或已在集合中就停，返回当前坐标。

## 怎么做
1. 初始化 `r, c = 0, 0`，`visited = {(0, 0)}`，方向映射 `d = {'L':(0,-1),'R':(0,1),'U':(-1,0),'D':(1,0)}`。
2. 循环：按 `grid[r][c]` 取 `dr, dc`，算出 `nr, nc = r+dr, c+dc`。
3. 若 `nr` 不在 `[0, m)` 或 `nc` 不在 `[0, n)`，或 `(nr, nc) in visited`，直接 `return [r, c]`。
4. 否则 `r, c = nr, nc`，把 `(r, c)` 加入 `visited`，继续。

拿示例 1 走一遍关键一步：走到 `(1, 0)` 时 `grid[1][0] == 'U'`，算出 `nr, nc = 0, 0`，而 `(0, 0)` 已在 `visited` 里，于是返回 `[1, 0]`——注意返回的是**当前**的 `r, c`，不是算出来的 `nr, nc`。

```python
m, n = len(grid), len(grid[0])
d = {'L': (0, -1), 'R': (0, 1), 'U': (-1, 0), 'D': (1, 0)}
r = c = 0
visited = {(0, 0)}
while True:
    dr, dc = d[grid[r][c]]
    nr, nc = r + dr, c + dc
    if not (0 <= nr < m and 0 <= nc < n) or (nr, nc) in visited:
        return [r, c]
    r, c = nr, nc
    visited.add((r, c))
```

## 复杂度
时间 O(m·n)：每个单元格最多访问一次，`m*n <= 10^5`。
空间 O(m·n)：`visited` 集合最多存 `m*n` 个坐标元组。

## 易错点
- 输入 `grid = [["R"]]`（1x1）→ 若先移动再判断，会去读 `grid[0][1]` 越界报错 → 正确做法是每轮先算 `nr, nc` 并做边界检查，越界就返回 `[0, 0]`，一次都不移动。
- 输入 `grid = [["R","L"]]` → 若把「进入已访问单元格」当成可以走进去再停，会返回 `[0, 0]` 而不是 `[0, 1]` → 正确做法是移动前用 `(nr, nc) in visited` 拦截，返回拦截前的 `r, c`。

## 如果面试官追问
问：如果要求返回整条访问路径而不是终点？答：把 `visited` 换成 `path` 列表，每次移动 `append((r, c))`，终止时直接返回 `path`，时间空间不变。
