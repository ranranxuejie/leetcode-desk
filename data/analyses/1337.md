## 一句话思路
每行 1 都在前面，用二分找第一个 0 的位置得到军人数，再按 (军人数, 行号) 升序取前 k 个行号。

## 怎么做
1. 对第 i 行用 `bisect_left(mat[i], 0)` 求第一个 0 的下标，即该行军人数 `cnt`。
2. 把 `(cnt, i)` 放进列表 `rows`，元组比较天然满足「军人数少者弱、同数行号小者弱」。
3. 对 `rows` 排序后取前 k 个元组的第二个元素。
4. 以示例 1 为例：行 0 得 `(2,0)`、行 2 得 `(1,2)`、行 4 得 `(5,4)`；排序后前 3 个是 `(1,2),(2,0),(2,3)`，取行号得 `[2,0,3]`。

```python
from bisect import bisect_left

rows = []
for i, row in enumerate(mat):
    cnt = bisect_left(row, 0)   # 全 1 时返回 n
    rows.append((cnt, i))
rows.sort()
return [i for _, i in rows[:k]]
```

注意 `bisect_left(row, 0)` 在整行都是 1 时返回 `n`，正好等于军人数，不需要特判。

## 复杂度
时间：O(m log n + m log m)，二分每行 log n，排序 m 个元组。
空间：O(m)，`rows` 存 m 个 `(cnt, i)` 元组。

## 易错点
- 整行全为 1（如示例 1 的行 4）→ 若用 `row.index(0)` 会抛 `ValueError` → 用 `bisect_left` 返回 `n`，或先判 `0 in row`。
- 军人数相同（示例 1 行 0 和行 3 都是 2）→ 只按 `cnt` 排序时行号顺序不确定，可能输出 `[2,3,0]` → 必须排 `(cnt, i)` 二元组，靠元组第二项保证行号升序。

## 如果面试官追问
问：n 很大、m 也很大，能否不排序？
答：用大小为 k 的最大堆存 `(cnt, i)`，O(m log n + m log k)，k 远小于 m 时更优。
