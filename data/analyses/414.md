## 一句话思路
用三个变量维护当前见过的最大、次大、第三大**不同**值，扫一遍即可，因为只需保留前三名。

## 怎么做
1. 初始化 `first = second = third = None`，表示尚未出现。
2. 遍历 `nums`，对每个 `x` 先跳过与 `first`/`second`/`third` 相等的重复值。
3. 若 `x > first`，则整体下移：`third, second, first = second, first, x`；否则若 `x > second`，则 `third, second = second, x`；否则若 `x > third`，则 `third = x`。
4. 遍历结束，`third` 为 `None` 说明不同值不足 3 个，返回 `first`，否则返回 `third`。

以 `[2, 2, 3, 1]` 为例：处理第一个 `2` 后 `first=2`；第二个 `2` 与 `first` 相等被跳过（这是关键，否则会把 `2` 挤到 `second`）；处理 `3` 后 `first=3, second=2`；处理 `1` 后 `third=1`，返回 `1`。

```python
first = second = third = None
for x in nums:
    if x == first or x == second or x == third:
        continue
    if first is None or x > first:
        third, second, first = second, first, x
    elif second is None or x > second:
        third, second = second, x
    elif third is None or x > third:
        third = x
return first if third is None else third
```

## 复杂度
时间 O(n)：`nums` 每个元素只比较常数次。
空间 O(1)：只开了 `first`/`second`/`third` 三个变量。

## 易错点
- 输入 `[2, 2, 3, 1]` → 若不去重，两个 `2` 会占掉第一、第二，`third` 变成 `2`，错答 `2` → 必须先判断 `x == first or x == second or x == third` 再跳过。
- 输入 `[1, 2]` 或 `[1, 1, 1]` → 若用 `-2**31` 当哨兵，`third` 仍是哨兵值却被当成有效答案返回 → 用 `None` 标记未填满，最后判 `third is None` 返回 `first`。

## 如果面试官追问
问：若要求返回第 k 大的不同值，怎么做？
答：把三个变量换成大小为 k 的小顶堆，堆内去重，时间 O(n log k)。
