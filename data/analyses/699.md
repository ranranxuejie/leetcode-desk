## 一句话思路
把每个方块的 x 区间离散化后建线段树维护区间最大高度，落块时查询区间最大值再加边长。

## 怎么做
1. 收集所有 `left` 和 `left + sideLength` 作为端点，排序去重得到坐标轴，把每个方块映射成左闭右开的离散下标区间 `[l, r)`。
2. 线段树每个节点存该区间的最大高度，初始全 0。
3. 对每个方块，先查询 `[l, r)` 的最大值 `base`，新高度 `h = base + sideLength`，再把 `[l, r)` 区间整体赋值为 `h`。
4. 用全局变量 `ans_max` 记录历史最大高度，每步追加。

以示例 1 为例：`positions = [[1,2],[2,3],[6,1]]`，端点集合 `{1,3,2,5,6,7}`，排序后 `[1,2,3,5,6,7]`。第 2 块 `left=2, side=3`，区间 `[2,5)` 对应下标 `[1,3)`，查询得 `base=2`（来自第 1 块覆盖的 `[1,3)`），`h=2+3=5`，更新后 `ans_max=5`。

```python
coords = sorted({x for l, s in positions for x in (l, l + s)})
idx = {v: i for i, v in enumerate(coords)}
size = len(coords) - 1
tree = [0] * (4 * size)  # 区间最大值 + 懒标记赋值
def query(node, lo, hi, ql, qr): ...
def update(node, lo, hi, ql, qr, val): ...
res, ans_max = [], 0
for l, s in positions:
    ql, qr = idx[l], idx[l + s]
    base = query(1, 0, size, ql, qr)
    h = base + s
    update(1, 0, size, ql, qr, h)
    ans_max = max(ans_max, h)
    res.append(ans_max)
```

## 复杂度
时间：`n` 个方块，每次查询/更新 `O(log n)`，离散化排序 `O(n log n)`，共 `O(n log n)`。
空间：线段树 `O(n)`，坐标映射 `O(n)`。

## 易错点
- 区间端点处理：`[1,2]` 和 `[2,3]` 这种擦边不算着陆，若把区间写成闭区间 `[l, r]` 会导致第 2 块错误地叠在第 1 块上，高度算成 5 而非 3。正确做法是用左闭右开 `[l, l+s)`，离散化后 `qr = idx[l+s]` 不含右端点。
- 懒标记下推：区间赋值时若只更新父节点不推标记，后续查询子区间会拿到旧值。例如先覆盖 `[1,5)` 为 5，再查 `[2,3)` 应得 5，漏推标记会返回 0，导致 `base` 偏小、高度算错。

## 如果面试官追问
若 `positions.length` 升到 `10^5` 且 `left` 到 `10^9`，离散化线段树仍是 `O(n log n)`，无需改结构，只需把递归改成迭代或加 `sys.setrecursionlimit`。
