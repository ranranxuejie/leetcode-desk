## 一句话思路
用长度 26 的布尔数组记录已见字母，从左到右扫，遇到已标记的立刻返回——它正是第二次出现下标最小的那个。

## 怎么做
1. 建 `seen = [False] * 26`，下标 `ord(ch) - ord('a')` 对应字母。
2. 遍历 `s` 的每个字符 `ch`，算 `i = ord(ch) - 97`。
3. 若 `seen[i]` 为 `True`，直接 `return ch`；否则置 `seen[i] = True`。
4. 循环内返回保证第一次命中就是答案，无需比较下标。

以 `s = "abccbaacz"` 为例：扫到下标 2 的 `'c'` 时 `seen[2]` 刚被置 `True`；扫到下标 3 的 `'c'`，`i = 2`、`seen[2] == True`，立即返回 `'c'`。此时 `'a'` 的第二次出现在下标 5、`'b'` 在下标 4，都比 3 靠后，所以先返回是对的。

```python
seen = [False] * 26
for ch in s:
    i = ord(ch) - 97
    if seen[i]:
        return ch
    seen[i] = True
```

关键点：判断和置位必须"先查后置"，顺序反了就永远查不到重复。用 `set` 也行，`if ch in seen: return ch` 然后 `seen.add(ch)`，但 26 个字母用定长数组更省，且 `ord` 减法比哈希快。

## 复杂度
时间 O(n)：n 为 `s` 长度，每个字符做一次 O(1) 的数组下标访问。
空间 O(1)：额外只开 26 个布尔位，与 n 无关。

## 易错点
- 输入 `"abccbaacz"` 若先置位再判断，`seen[2]` 在第一次遇到 `'c'` 时就被自己覆盖，之后永远返回不了 `'c'`，会错成 `'a'`（下标 5 才命中）→ 正确做法是先 `if seen[i]` 再 `seen[i] = True`。
- 输入 `"abcdd"` 若用 `s.count(ch) == 2` 逐字符判断，`'d'` 确实返回对，但换成 `"aabc"` 会先看 `'a'` 的 count 为 2 就返回 `'a'`——本例碰巧对，可一旦有字母出现三次（如 `"aaab"` 中 `'a'` count 为 3）就漏判 → 正确做法是扫到第二次出现就返回，不依赖总次数。

## 如果面试官追问
若要求返回所有出现两次的字母并按第二次出现位置排序？答：扫一遍用 `seen` 记录首次位置，命中时把 `(当前下标, ch)` 追加进列表，最后按下标排序输出。
