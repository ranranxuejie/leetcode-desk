## 一句话思路
去掉所有 X 后两串必须相同，且每个 L 只能左移、每个 R 只能右移，用双指针逐字符校验位置约束。

## 怎么做
1. 先比较 `start.replace('X','')` 与 `result.replace('X','')`，不等直接返回 `False`。
2. 用两个指针 `i`、`j` 分别扫 `start`、`result`，跳过所有 `'X'`。
3. 若 `start[i] != result[j]` 返回 `False`；若是 `'L'` 要求 `i >= j`，若是 `'R'` 要求 `i <= j`。
4. 两指针都走到末尾则返回 `True`。

以示例 1 为例，`start = "RXXLRXRXL"`、`result = "XRLXXRRLX"`。第一次对齐时 `i=0`（`'R'`）、`j=1`（`'R'`），`i <= j` 成立；继续推进到 `start` 的 `'L'` 在 `i=3`、`result` 的 `'L'` 在 `j=2`，`i >= j` 成立，全部通过返回 `True`。

```python
def canTransform(start, result):
    if start.replace('X', '') != result.replace('X', ''):
        return False
    i = j = 0
    n = len(start)
    while i < n and j < n:
        while i < n and start[i] == 'X':
            i += 1
        while j < n and result[j] == 'X':
            j += 1
        if i == n or j == n:
            break
        if start[i] != result[j]:
            return False
        if start[i] == 'L' and i < j:
            return False
        if start[i] == 'R' and i > j:
            return False
        i += 1
        j += 1
    return True
```

## 复杂度
时间：O(n)，两个指针各扫一遍字符串，`replace` 也是 O(n)。
空间：O(n)，`replace` 生成两个新串；若改用计数器可降到 O(1)。

## 易错点
- 只比较去 X 后的字符串就返回 `True`，如 `start="L"`、`result="XL"` 会错判为真；必须再校验 L 只能左移（`i >= j`）、R 只能右移（`i <= j`）。
- 跳过 X 后某一指针先到末尾却未检查另一指针，如 `start="RXX"`、`result="XXR"` 会漏判；循环结束要确认两指针都耗尽。

## 如果面试官追问
问：若要求输出具体移动序列而非布尔值？
答：按双指针找到每个错位字符，贪心地把 L 向左、R 向右逐次与相邻 X 交换，记录每步即可，步数上界 O(n²)。
