## 一句话思路
逐位取模弹出 `x` 的末位、压入 `rev`，每步前用 `rev` 与 `2**31-1 // 10` 比较来提前判溢出。

## 怎么做
1. 记录符号 `sign`，把 `x` 取绝对值，统一按正数处理。
2. 循环：`digit = x % 10`，`x //= 10`，先判溢出再 `rev = rev * 10 + digit`。
3. 溢出判据：`rev > (2**31 - 1) // 10` 直接返回 0；`rev == (2**31 - 1) // 10` 时再看 `digit > 7`。
4. 循环结束返回 `sign * rev`。

以 `x = 123` 为例：第一轮 `digit = 3`、`x = 12`、`rev = 3`；第二轮 `digit = 2`、`x = 1`、`rev = 32`；第三轮 `digit = 1`、`x = 0`、`rev = 321`，返回 321。关键中间值是第二轮结束时的 `rev = 32`——它已经决定了最终量级，溢出判断必须在 `rev * 10 + digit` 之前做，而不是之后。

```python
sign = -1 if x < 0 else 1
x = abs(x)
rev = 0
LIMIT = (2**31 - 1) // 10   # 214748364
while x:
    digit = x % 10
    if rev > LIMIT or (rev == LIMIT and digit > 7):
        return 0
    rev = rev * 10 + digit
    x //= 10
return sign * rev
```

注意 `digit > 7` 只对正数分支成立；负数侧下界是 `-2**31`，末位允许到 8，所以更稳的写法是全程按正数算、最后乘 `sign`，再单独检查 `sign * rev` 是否落在 `[-2**31, 2**31 - 1]`。

## 复杂度
时间：O(log₁₀|x|)，循环次数等于十进制位数，`123` 走 3 轮。
空间：O(1)，只开了 `rev`、`digit`、`sign` 三个标量。

## 易错点
- 输入 `x = 1534236469` → 反转得 `9646324351`，超出 `2**31 - 1`；若先算 `rev = rev * 10 + digit` 再判断，Python 不会报错但会返回错误的大数，必须按题目规定在乘之前用 `rev > 214748364` 拦截并返回 0。
- 输入 `x = -2147483648` → 直接 `abs(x)` 后反转得 `8463847412`，若只判正向上界会漏掉负数下界 `-2**31`；正确做法是算出 `sign * rev` 后再统一检查是否落在 `[-2**31, 2**31 - 1]`，越界返回 0。

## 如果面试官追问
问：不允许用 `abs` 和额外符号变量怎么办？
答：在循环里用 `x % 10` 配合 Python 的向下取整语义（`-123 % 10 == 7`）会出错，改用 `int(x / 10)` 截断或先转成字符串处理末位。
