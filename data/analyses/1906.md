## 一句话思路
值域只有 1~100，对每个值建前缀出现次数，查询时按值升序扫一遍取相邻出现值的最小差。

## 怎么做
1. 建 `pre[v][i]` = 值 v 在 `nums[0..i-1]` 中出现次数，即长度 `101 × (n+1)` 的前缀和表。
2. 对查询 `[l, r]`，值 v 在区间内出现当且仅当 `pre[v][r+1] - pre[v][l] > 0`。
3. 从 1 到 100 扫 v，记录上一个出现的值 `prev`，遇到新出现的 v 就更新 `ans = min(ans, v - prev)`。
4. 若扫完 `ans` 仍是初值（区间内只有一个不同值），返回 -1。

以 `nums = [1,3,4,8]`、查询 `[0,3]` 为例：扫到 v=1 时 `prev=1`，v=3 时 `ans=3-1=2`、`prev=3`，v=4 时 `ans=min(2,1)=1`、`prev=4`，v=8 时 `ans=min(1,4)=1`，最终 1。

```python
n = len(nums)
pre = [[0] * (n + 1) for _ in range(101)]
for v in range(1, 101):
    row, src = pre[v], pre[v]
    for i in range(n):
        row[i + 1] = row[i] + (1 if nums[i] == v else 0)

res = []
for l, r in queries:
    ans, prev = 101, -1
    for v in range(1, 101):
        if pre[v][r + 1] - pre[v][l] > 0:
            if prev != -1:
                ans = min(ans, v - prev)
            prev = v
    res.append(-1 if ans == 101 else ans)
```

## 复杂度
时间：建表 O(100·n)，每个查询 O(100)，总 O(100·(n+q))。
空间：`pre` 表 O(100·n)，即 101 行各 n+1 个整数。

## 易错点
- 查询 `[2,3]` 在 `nums=[4,5,2,2,7,10]` 上子数组是 `[2,2]`：若把「相邻出现值之差」写成「相邻下标之差」或忘记 `nums[i] != nums[j]` 的约束，会返回 0；正确做法是只在**不同值**之间算差，同值重复出现不产生候选，答案为 -1。
- 区间内只有一个不同值时 `ans` 保持初值 101：若直接返回 101 或 0 就错了，必须显式判 `ans == 101` 返回 -1；初值取 101 而非 `2**31 - 1` 是为了让「未更新」可判定。

## 如果面试官追问
若 nums 值域放大到 10^9 怎么办？答：改为对每个值存出现下标列表，查询时二分定位区间内出现的值，再在有序值集合上求相邻差最小值。
