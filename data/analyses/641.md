## 一句话思路
用长度 k+1 的数组加 head、size 两个指针做环形缓冲，留一个空位区分队满与队空。

## 怎么做
1. 开 `self.buf = [0] * (k + 1)`，`self.head = 0`，`self.size = 0`，容量取 k+1 让 `size == k` 即满、`size == 0` 即空。
2. `insertLast` 先判满，写入位置 `(head + size) % (k+1)`，再 `size += 1`。
3. `insertFront` 先判满，`head = (head - 1) % (k+1)` 后写入 `buf[head]`，再 `size += 1`。
4. 删除与读取：`getFront` 取 `buf[head]`，`getRear` 取 `buf[(head + size - 1) % (k+1)]`；`deleteFront` 只 `head = (head + 1) % (k+1)` 并 `size -= 1`，`deleteLast` 只 `size -= 1`。

以示例 k=3 走一遍：`insertLast(1)` 写 `buf[0]`，`insertLast(2)` 写 `buf[1]`，此时 `head=0, size=2`；`insertFront(3)` 先 `head=(0-1)%4=3`，写 `buf[3]=3`，`size=3`；再 `insertFront(4)` 时 `size==3==k` 直接返回 `False`。随后 `getRear` 算 `(0+3-1)%4=2`，得 `buf[2]=2`。

```python
def insertFront(self, value):
    if self.size == self.k:
        return False
    self.head = (self.head - 1) % (self.k + 1)
    self.buf[self.head] = value
    self.size += 1
    return True

def getRear(self):
    if self.size == 0:
        return -1
    return self.buf[(self.head + self.size - 1) % (self.k + 1)]
```

## 复杂度
时间：每个操作 O(1)，只有取模和数组下标。
空间：O(k)，额外开了长度 k+1 的 `buf` 数组。

## 易错点
1. 数组只开 k 个 → `head` 和 `size` 无法区分「满」和「空」，示例中 `insertFront(4)` 会误判成功并覆盖 `buf[0]=1`。正确做法是开 k+1 个槽，用 `size == k` 判满、`size == 0` 判空。
2. `insertFront` 先写 `buf[head]` 再移动 `head` → 示例中 3 会写到 `buf[0]` 覆盖 1，`getFront` 返回 1 而非 4。正确顺序是先 `head = (head - 1) % (k+1)` 再写入。

## 如果面试官追问
问：k 放大到 10^9 还能用数组吗？
答：改用双向链表加节点计数，每个操作仍是 O(1)，空间只随实际元素数增长。
