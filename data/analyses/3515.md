## 一句话思路
用 DFS 序把子树拍成连续区间，边权变化等价于对子树区间整体加减，树状数组做区间加、单点查。

## 怎么做
1. 以 1 为根 DFS，记录 `tin[u]`、`tout[u]`（子树区间）和 `dist[u]`（初始根到 u 的距离），并把每条边挂到它的**子节点**上。
2. 建差分树状数组 `bit`，初始把 `dist` 的差值写进去（或直接对每个点做一次区间加）。
3. 更新 `[1,u,v,w']`：先判断谁是子节点（`tin` 大的那个），设旧权为 `old`，则对子节点 `c` 的子树区间加 `w' - old`。
4. 查询 `[2,x]`：返回 `bit` 在 `tin[x]` 的前缀和。

以示例 3 为例：`edges=[[1,2,2],[2,3,1],[3,4,5]]`，DFS 后 `tin` 为 1→1, 2→2, 3→3, 4→4，`dist=[0,2,3,8]`。执行 `[1,2,3,3]` 时子节点是 3，`old=1`，对区间 `[tin[3], tout[3]] = [3,4]` 加 `3-1=2`；随后 `[2,3]` 前缀和得 `3+2=5`，与输出一致。

```python
# 更新：c 是 u,v 中的子节点
delta = w2 - weight[edge_id]
i = tin[c]
while i <= n:
    bit[i] += delta
    i += i & -i
j = tout[c] + 1
while j <= n:
    bit[j] -= delta
    j += j & -j
# 查询
s, i = 0, tin[x]
while i > 0:
    s += bit[i]
    i -= i & -i
```

## 复杂度
时间：DFS 建树 O(n)，每次更新/查询 O(log n)，共 O(n + q log n)。
空间：邻接表与 `tin/tout/dist` 各 O(n)，树状数组 O(n)。

## 易错点
- 更新时把 `u` 当子节点 → 若 `u` 是父节点（如示例 2 的 `[1,1,3,7]`，1 是根），区间加会加到整棵树，`[2,2]` 错成 4 而非 2 → 必须用 `tin[u] > tin[v]` 选出子节点。
- 区间加只加了左端点忘了 `tout[c]+1` 处减回 → 后续查询兄弟子树（如示例 3 中节点 2）会被污染 → 差分必须成对写入 `tin[c]` 与 `tout[c]+1`。

## 如果面试官追问
若要求同时支持「任意两点距离」而非仅根到点，怎么办？
答：距离 = `dist[u]+dist[v]-2*dist[lca]`，LCA 用倍增预处理，边权更新仍走子树区间加。
