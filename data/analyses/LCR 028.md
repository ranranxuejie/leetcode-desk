## 一句话思路
DFS 先展平 `child` 再展平 `next`，把子链表整段插到当前节点与 `next` 之间，天然满足「子项优先」的顺序。

## 怎么做
1. 写 `dfs(node)`，返回以 `node` 为头的这一段展平后的**尾节点**。
2. 遍历当前层，遇到 `node.child` 就先递归拿到子链尾 `childTail`，做四针缝合：`node.next ↔ child`、`childTail ↔ 原 next`，并把 `node.child = None`。
3. 缝合后从 `childTail` 继续往后走（它才是新的前驱），直到 `next` 为空，返回当前尾。
4. 主函数只调 `dfs(head)`，返回值丢弃。

以示例 1 走到 `node = 3` 时：`node.child = 7`，递归得 `childTail = 12`，原 `node.next = 4`。缝合后 `3.next = 7`、`7.prev = 3`、`12.next = 4`、`4.prev = 12`，`3.child = None`；接着从 `12` 往后走，最终整条链尾是 `6`。

```python
def dfs(node):
    cur, tail = node, None
    while cur:
        nxt = cur.next
        if cur.child:
            childTail = dfs(cur.child)
            cur.next, cur.child.prev = cur.child, cur
            childTail.next, cur.child = nxt, None
            if nxt:
                nxt.prev = childTail
            cur = childTail
        tail = cur
        cur = cur.next
    return tail
```

关键在 `cur = childTail` 这一句：不跳过去，就会把子链尾当成普通节点再走一遍 `next`，缝合处被重复处理。

## 复杂度
时间 O(n)：每个节点被 `dfs` 访问一次，缝合是 O(1)。
空间 O(d)：递归栈深度等于最大嵌套层数 d，最坏 O(n)，无额外容器。

## 易错点
- 子链尾后面没有节点（如示例 2 的 `3`，`nxt = None`）→ 直接写 `nxt.prev = childTail` 会 `AttributeError` → 必须先 `if nxt:` 再改 `prev`。
- 缝合后忘记 `cur.child = None` → 输出序列化时该节点仍带子指针，判题按多级结构比对会判错 → 缝合完立刻置 `None`，别留到循环末尾。

## 如果面试官追问
问：不许递归，栈深度 O(1) 怎么做？
答：先沿 `next` 走一遍，把带 `child` 的节点压栈；再逐个弹出，把子链整段摘下接到该节点后，边接边把子链里的带 child 节点继续压栈。
