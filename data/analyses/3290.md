## 一句话思路
按 a 的四个位置分阶段做 DP，`dp[j]` 表示已选 j 个下标的最大得分，逐元素更新。

## 怎么做
1. 初始化 `dp = [0, -inf, -inf, -inf]`，`dp[0]=0` 表示一个都没选。
2. 对 b 中每个 `x`，从 j=3 倒序到 0 更新 `dp[j+1] = max(dp[j+1], dp[j] + a[j]*x)`。
3. 倒序是为了让本轮刚更新的 `dp[j]` 不被同一元素重复使用。
4. 答案即 `dp[4]`。

以示例 1 的 `a=[3,2,5,6]`、`b=[2,-6,4,-5,-3,2,-7]` 为例：处理到 `x=4`（下标 2）时，`dp[2]` 从 `3*2+2*(-6)=-6` 更新为 `max(-6, dp[1]+5*4)=max(-6, 6+20)=26` 的前身 `dp[1]=6`；最终 `dp[4]=26`。

```python
NEG = -10**30
dp = [0, NEG, NEG, NEG]
for x in b:
    for j in range(3, -1, -1):
        if dp[j] != NEG:
            cand = dp[j] + a[j] * x
            if cand > dp[j + 1]:
                dp[j + 1] = cand
return dp[4]
```

关键点：`dp[j]` 只依赖上一轮的值，倒序保证 `b` 的每个下标最多用一次；`NEG` 要足够小，因为 `a[i]*b[i]` 最小约 `-10^10`，四个相加约 `-4*10^10`。

## 复杂度
时间：O(4n)，n 为 b 长度，每个元素做 4 次转移。
空间：O(1)，只开长度 5 的 dp 数组。

## 易错点
- 正序更新 `dp[j+1]`：同一 `x` 会被连续用于多个位置，示例 1 中 `x=2` 可能被当成 i0 和 i1 两次使用，得分虚高；必须 `range(3,-1,-1)` 倒序。
- 用 `0` 初始化 `dp[1..3]`：当 `a` 含负数（如示例 2 的 `a[0]=-1`）时，未选状态被当成得分 0，会漏掉必须选满 4 个的约束，得到错误的正值；应初始化为足够小的 `NEG`。

## 如果面试官追问
若要求输出具体下标方案？答：额外开 `pre[j]` 记录 `dp[j]` 更新时的 b 下标，最后从 `dp[4]` 回溯四个位置即可。
