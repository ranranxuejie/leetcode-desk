## 一句话思路
先分别预处理「前缀严格递增」和「后缀严格递减」的合法边界，再枚举分割点用前缀和算差值取最小。

## 怎么做
1. 从左往右扫，用 `inc[i]` 记录 `nums[0..i]` 是否严格递增：`inc[i] = inc[i-1] and nums[i] > nums[i-1]`。
2. 从右往左扫，用 `dec[i]` 记录 `nums[i..n-1]` 是否严格递减：`dec[i] = dec[i+1] and nums[i] > nums[i+1]`。
3. 枚举分割点 `i`（left 取 `0..i`，right 取 `i+1..n-1`），合法条件是 `inc[i] and dec[i+1]`。
4. 用前缀和 `pre[i+1]` 得 `left = pre[i+1]`、`right = pre[n] - pre[i+1]`，取 `abs(left-right)` 最小值。

以 `nums = [1,2,4,3]` 为例：`inc = [T,T,T,F]`，`dec = [F,F,T,T]`。`i=1` 时 `inc[1]=T` 且 `dec[2]=T`，合法，`left=3`、`right=7`，差 4；`i=2` 时 `inc[2]=T` 且 `dec[3]=T`，`left=7`、`right=3`，差 4。答案 4。

```python
n = len(nums)
pre = [0] * (n + 1)
for i in range(n):
    pre[i + 1] = pre[i] + nums[i]
inc = [True] * n
for i in range(1, n):
    inc[i] = inc[i - 1] and nums[i] > nums[i - 1]
dec = [True] * n
for i in range(n - 2, -1, -1):
    dec[i] = dec[i + 1] and nums[i] > nums[i + 1]
ans = -1
for i in range(n - 1):
    if inc[i] and dec[i + 1]:
        left = pre[i + 1]
        right = pre[n] - left
        d = abs(left - right)
        if ans == -1 or d < ans:
            ans = d
```

## 复杂度
时间：O(n)，三次线性扫描，枚举分割点也是 O(n)。
空间：O(n)，`pre`、`inc`、`dec` 三个长度 n 的数组。

## 易错点
- `nums = [3,1,2]`：`inc = [T,F,F]`、`dec = [F,F,T]`，没有任何 `i` 同时满足 `inc[i]` 和 `dec[i+1]`，若忘记判空直接返回初始 `ans=0` 会错成 0，正确做法是 `ans` 初始化为 -1 且只在合法时更新。
- `nums = [1,2,4,3]` 的 `i=0`：`inc[0]=True` 但 `dec[1]=False`（`2<4` 不递减），若只检查 `inc[i]` 不检查 `dec[i+1]` 会把 `[1]` 与 `[2,4,3]` 判为合法，正确做法是两个条件用 `and` 同时成立。

## 如果面试官追问
问：若要求输出所有最优分割点？
答：把 `ans` 更新处改成收集列表，遇到更小差值清空重收、相等则追加 `i`，仍是 O(n)。
