## 一句话思路
逐位比较 a、b、c 的同一二进制位，按真值表累加最少翻转数。

## 怎么做
1. 从第 0 位开始，循环到 a、b、c 的最高位（取三者最大值 `max(a,b,c).bit_length()`）。
2. 用 `(a>>i)&1`、`(b>>i)&1`、`(c>>i)&1` 取出第 i 位的三个比特。
3. 按位判断：若 c 位为 1 而 a、b 该位都为 0，则必须翻一个（+1）；若 c 位为 0 而 a、b 该位有 1，则每个 1 都要翻成 0（有几个加几个）。
4. 累加所有位的翻转数返回。

以 a=2, b=6, c=5 为例，二进制 a=010, b=110, c=101：
- 第 0 位：a=0, b=0, c=1 → c 要 1 但两者都 0，翻 1 次（把 a 或 b 该位变 1）。
- 第 1 位：a=1, b=1, c=0 → c 要 0 但两者都 1，翻 2 次（两个都变 0）。
- 第 2 位：a=0, b=1, c=1 → 已满足，翻 0 次。
合计 1+2+0=3，与输出一致。

```python
ans = 0
for i in range(max(a, b, c).bit_length()):
    x, y, z = (a >> i) & 1, (b >> i) & 1, (c >> i) & 1
    if z == 1 and x == 0 and y == 0:
        ans += 1
    elif z == 0:
        ans += x + y
return ans
```

关键中间值：第 1 位 x=1, y=1, z=0，走 `elif z==0` 分支，`ans += 1+1` 得 2。

## 复杂度
时间 O(log max(a,b,c))，即遍历最高位的位数。
空间 O(1)，只用了 ans、x、y、z 几个变量。

## 易错点
- 循环上界只取 `a.bit_length()`：当 b 或 c 比 a 高位更多时（如 a=1, b=8, c=8），会漏掉高位，b 的第 3 位 1 没被处理，答案偏小；应取 `max(a,b,c).bit_length()`。
- 把 c 位为 0 且 a、b 都为 1 的情况只加 1：如 a=3, b=3, c=0，第 0、1 位各有两个 1，正确是 4 次，只加 1 会得 2；应 `ans += x + y` 逐个数。

## 如果面试官追问
若要求输出翻转后的 a、b 具体值而非次数？答：在累加时记录每位翻哪个数（c 位为 1 且两者为 0 时翻 a 该位；c 位为 0 时把 a、b 该位的 1 清零），最后拼回整数即可。
