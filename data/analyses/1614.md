## 一句话思路
遍历字符串维护当前深度 `cur`，遇 `(` 加一、遇 `)` 减一，全程记录 `cur` 的最大值。

## 怎么做
1. 初始化 `cur = 0`、`best = 0`。
2. 逐字符扫描 `s`，只对 `(` 和 `)` 反应，数字和运算符直接跳过。
3. 遇 `(` 时 `cur += 1` 并立刻用 `best = max(best, cur)` 更新答案。
4. 遇 `)` 时 `cur -= 1`。

以示例 3 `s = "()(())((()()))"` 为例，扫到下标 8 的那个 `(` 时，前面已经开了 `((`，`cur` 从 2 变成 3，`best` 同步更新为 3；后面再没有超过 3 的层数，最终返回 3。关键点在于 `best` 必须在 `cur += 1` 之后取，而不是在 `)` 处取。

```python
cur = best = 0
for ch in s:
    if ch == '(':
        cur += 1
        if cur > best:
            best = cur
    elif ch == ')':
        cur -= 1
return best
```

因为题目保证括号串有效，`cur` 永远不会变成负数，`)` 处不需要额外判断。整个循环只关心括号字符，`+`、`-`、`*`、`/` 和数字 0-9 全部走空分支。

## 复杂度
时间 O(n)：n 是 `len(s)`，每个字符访问一次，比较和加减都是 O(1)。
空间 O(1)：只开了 `cur` 和 `best` 两个整数，没有栈、没有数组。

## 易错点
- 输入 `"()"` → 若在 `)` 处才更新 `best`，`cur` 已减回 0，会错成 0 → 正确做法是在 `(` 分支里先 `cur += 1` 再更新 `best`，这样 `"()"` 得到 1。
- 输入 `"()(())((()()))"` → 若把 `best` 写成「最后一次赋值的 `cur`」而非取最大值，会错成 1（最后一个 `)` 后 `cur` 归零）→ 正确做法是每次 `cur` 增长都和 `best` 比较取大，保留历史峰值 3。

## 如果面试官追问
问：如果字符串不保证有效，比如 `")("` 怎么办？
答：遇 `)` 时先判 `cur > 0` 再减，否则说明出现非法闭合，可直接返回 -1 或抛异常。
