## 一句话思路
完全背包求方案数：外层遍历 4 种币值、内层正序累加 `dp[j] += dp[j-coin]`，保证每种组合只按币值递增顺序被数一次。

## 怎么做
1. 定义 `dp[j]` 为凑出金额 `j` 的方案数，初始化 `dp[0] = 1`，其余为 0。
2. 外层按 `coins = [1, 5, 10, 25]` 顺序遍历币值，内层 `j` 从 `coin` 到 `n` 正序遍历。
3. 转移 `dp[j] = (dp[j] + dp[j-coin]) % 1000000007`，最后返回 `dp[n]`。

以 `n = 10` 为例，走完 `coin = 1` 后 `dp[0..10]` 全为 1；走完 `coin = 5` 后 `dp[5] = 2`、`dp[10] = 3`（`10`、`5+5`、`5+1×5`）；走完 `coin = 10` 时 `dp[10] += dp[0]` 得 4，与示例一致。关键中间值就是 `dp[10]` 从 3 变 4 的那一步。

```python
MOD = 1000000007
dp = [0] * (n + 1)
dp[0] = 1
for coin in (1, 5, 10, 25):
    for j in range(coin, n + 1):
        dp[j] = (dp[j] + dp[j - coin]) % MOD
return dp[n]
```

币值顺序不能换到内层：若写成外层 `j`、内层 `coin`，`5+5` 与 `5+5` 会被按不同排列重复计数，`n = 10` 会得到 11 而不是 4。

## 复杂度
时间：O(4n)，4 是币值个数，n 是金额，与 log n 无关。
空间：O(n)，只开一个长度 n+1 的 `dp` 数组。

## 易错点
- 内外层写反（外层金额、内层币值）→ `n = 10` 输出 11，把 `1+5+...` 和 `5+1+...` 当成不同方案 → 必须外层币值、内层金额正序，让组合按币值非降序唯一生成。
- 忘记取模或只在最后取模 → `n = 1000000` 时 `dp` 值指数级膨胀，Python 大整数运算拖慢到超时 → 每次 `dp[j]` 更新后立即 `% 1000000007`，别攒到最后。

## 如果面试官追问
问：要求输出所有具体方案而非方案数？
答：把 `dp` 换成 `dp[j]` 存方案列表，转移时把 `dp[j-coin]` 每个列表追加 `coin` 后并入，空间升到方案总数级别。
