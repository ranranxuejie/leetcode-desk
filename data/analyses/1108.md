## 一句话思路
用 `str.replace(".", "[.]")` 一次性替换所有点，因为 IPv4 里点只作分隔符，不存在需要保留的 `.`。

## 怎么做
1. 直接对 `address` 调用 `replace`，把每个 `.` 换成三字符的 `"[.]"`。
2. 以 `address = "1.1.1.1"` 为例：扫描到第 2 个字符 `.` 时，输出已累积 `"1"`，替换后追加 `"[.]"`，继续读下一个 `1`。
3. 重复到串尾，得到 `"1[.]1[.]1[.]1"`，长度从 7 变 11（3 个点各多 2 字符）。

```python
def defangIPaddr(address):
    return address.replace(".", "[.]")
```

手写循环版（面试要求不用内置函数时）：

```python
def defangIPaddr(address):
    res = []
    for ch in address:
        if ch == ".":
            res.append("[.]")
        else:
            res.append(ch)
    return "".join(res)
```

关键中间值：`address = "255.100.50.0"` 遍历到第一个 `.` 时 `res == ['2','5','5']`，追加后变 `['2','5','5','[.]']`。

## 复杂度
时间 O(n)：n 是 `address` 长度，每个字符看一次，替换后总长最多 3n。
空间 O(n)：`res` 列表或返回串本身占 O(n)，`replace` 内部同样要开新串。

## 易错点
- 输入 `"1.1.1.1"` 若写成 `address.replace(".", "[.]", 1)` 只换第一个点 → 输出 `"1[.]1.1.1"`，漏了后两个；本题必须替换全部，不能带 count 参数。
- 输入 `"255.100.50.0"` 若先 `split(".")` 再 `"[.]".join(...)` → 得到 `"255[.]100[.]50[.]0"` 看似对，但若地址里出现连续点（本题保证不会）会多出空段；本题安全，但别把这个写法当通用模板。

## 如果面试官追问
问：如果输入不是合法 IPv4，可能含 `[` `]` 等字符怎么办？
答：替换逻辑不变，`replace` 只认 `.`，其他字符原样保留，无需额外转义。
