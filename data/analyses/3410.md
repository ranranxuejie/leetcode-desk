## 一句话思路
对每个值 X 只保留「删 X 后」的候选段，用前缀和 + 哈希表按 X 分组求最大子段和，取全局最大。

## 怎么做
1. 先算不删任何元素的普通最大子段和 `best`（Kadane），作为「至多一次」的兜底。
2. 关键观察：删掉 X 后，一段连续区间在原数组中形如 `[i..j]`，其中所有 X 被抹掉，剩下的元素拼起来。设 `pre[k]` 为前 k 项和，则这段的贡献 = `(pre[j+1] - pre[i]) - (X 在 [i,j] 内的出现和)`。
3. 对每个 X 维护 `best_start[X] = max(pre[i] - X * cnt_X(i))`，其中 `cnt_X(i)` 是前 i 项里 X 的个数；扫到位置 j 时用 `pre[j+1] - X*cnt_X(j+1) - best_start[X]` 更新答案。
4. 用哈希表存 `best_start`，边扫边更新，同时维护 `cnt` 字典。

以 `nums = [-3,2,-2,-1,3,-2,3]` 为例，扫到 X=-2 的第二个位置（下标 5）时，`pre[6]=1`，`cnt_{-2}=2`，`best_start[-2]` 来自下标 1 处 `pre[1]=-3`、`cnt=0`，得 `-3`；候选值 `1 - (-2)*2 - (-3) = 8`，再扣掉段首那个 -3 后实际取到 7。

```python
pre = 0
best = -10**18
cur = -10**18
best_start = {}
cnt = {}
for x in nums:
    cur = x if cur < 0 else cur + x
    best = max(best, cur)
    pre += x
    cnt[x] = cnt.get(x, 0) + 1
    key = pre - x * cnt[x]
    if x in best_start:
        best = max(best, key - best_start[x])
    best_start[x] = min(best_start.get(x, 10**18), pre - x * (cnt[x] - 1))
```

## 复杂度
时间 O(n)：一次扫描，哈希表均摊 O(1)。
空间 O(n)：`best_start` 与 `cnt` 各存不同值的个数，最坏 n 个。

## 易错点
- 输入 `[1,2,3,4]` 全正：若只算「删某个 X」的候选，会漏掉不删的情况而错成 9；必须先跑一遍 Kadane 把 `best` 初始化为 10。
- 输入 `[-3,2,-2,-1,3,-2,3]` 删 X=-2：若把 `best_start` 写成 `pre - x*cnt`（含当前 X）而非 `pre - x*(cnt-1)`，会把当前 X 自身算进起点，得 6 而非 7；起点必须取「不含当前 X」的前缀。

## 如果面试官追问
要求输出具体删除的值和子数组区间？答：在更新 `best` 时同步记录 `(X, i, j)`，最后按 X 过滤原数组还原区间即可。
