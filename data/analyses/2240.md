## 一句话思路
枚举钢笔支数 `pens`，每支剩余钱 `total - pens*cost1` 能买 `//cost2 + 1` 种铅笔数，累加即可。

## 怎么做
1. 确定枚举上界：`pens` 从 0 到 `total // cost1`，因为再多一支钢笔就超预算。
2. 对每个 `pens`，剩余钱 `rest = total - pens * cost1`，铅笔可选 0 到 `rest // cost2`，共 `rest // cost2 + 1` 种。
3. 把每轮的这个值累加到答案，返回。

以 `total=20, cost1=10, cost2=5` 为例：`pens=0` 时 `rest=20`，`20//5+1=5`；`pens=1` 时 `rest=10`，`10//5+1=3`；`pens=2` 时 `rest=0`，`0//5+1=1`；合计 `5+3+1=9`。

```python
ans = 0
for pens in range(total // cost1 + 1):
    rest = total - pens * cost1
    ans += rest // cost2 + 1
return ans
```

关键点：`+1` 是算上「铅笔买 0 支」这一种，漏掉它示例 1 会得 6 而不是 9。

## 复杂度
时间：O(total / cost1)，枚举钢笔支数，最坏 total=10^6、cost1=1 时约 10^6 次。
空间：O(1)，只用了 `ans`、`pens`、`rest` 三个变量。

## 易错点
- `cost1 > total`（如示例 2 的 `cost1=10, total=5`）→ 若循环写成 `range(total // cost1)` 会一次都不进，返回 0 → 正确是 `range(total // cost1 + 1)`，至少枚举 `pens=0`，返回 1。
- 答案规模 → `total=10^6, cost1=cost2=1` 时方案数约 5×10^11，超出 32 位 → 返回类型是 `long`，Python 整数天然不溢出，但若在别的语言里用 `int` 累加会截断，需用 64 位。

## 如果面试官追问
问：若要求输出所有具体方案而非计数？
答：把累加换成内层 `for pencils in range(rest // cost2 + 1)` 收集 `(pens, pencils)`，复杂度升到 O(方案数)。
