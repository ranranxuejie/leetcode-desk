## 一句话思路
用位掩码 `mask` 表示已修课程集合，DP 求每个状态到全修完的最少学期数，转移时枚举本学期可修的课。

## 怎么做
1. 预处理每门课的先修掩码 `pre[i]`，`pre[i]` 的第 j 位为 1 表示 j 是 i 的先修课。
2. 状态 `mask` 表示已修集合，`dp[mask]` = 修完 `mask` 后还需的最少学期数，从全 1 往前推或记忆化搜索。
3. 从 `mask` 出发，先算出所有「先修已满足」的候选课 `avail`，再从中枚举大小 ≤ k 的子集作为本学期修的课。
4. 关键剪枝：若 `avail` 中课程数 > k，优先修「后继课多」的课，避免枚举所有子集爆炸。

以示例 1 为例：`n=4, relations=[[2,1],[3,1],[1,4]], k=2`。初始 `mask=0`，`avail` 为课程 2、3（二进制 `0b0110`），枚举子集 `{2,3}` 后 `mask=0b0110`，下一学期 `avail` 只有课程 1。

```python
from functools import lru_cache

pre = [0] * n
for x, y in relations:
    pre[y-1] |= 1 << (x-1)

@lru_cache(None)
def dp(mask):
    if mask == (1 << n) - 1:
        return 0
    avail = 0
    for i in range(n):
        if not (mask >> i) & 1 and (pre[i] & mask) == pre[i]:
            avail |= 1 << i
    # 枚举 avail 的大小 <= k 的子集
    best = n
    sub = avail
    while sub:
        if sub.bit_count() <= k:
            best = min(best, 1 + dp(mask | sub))
        sub = (sub - 1) & avail
    return best
```

## 复杂度
时间：`O(2^n * 2^n)` 最坏，实际因 `avail` 子集枚举远小于此，`n≤15` 可过。
空间：`O(2^n)` 存 `dp` 缓存，`pre` 数组 `O(n)`。

## 易错点
- 输入 `relations=[]`（示例 3）→ 若忘记处理空图，`avail` 计算可能漏掉所有课 → 正确做法是 `pre[i]=0` 时所有课都可直接修，`dp` 应返回 `ceil(n/k)`。
- `avail` 课程数 > k 时 → 若暴力枚举所有子集会超时（`n=15, k=7` 时子集数巨大）→ 正确做法是只枚举 `bit_count() <= k` 的子集，或按后继数排序贪心选前 k 个。

## 如果面试官追问
问：若要求输出具体每学期修哪些课？答：在 `dp` 转移时记录选择的子集 `sub`，回溯即可还原方案。
