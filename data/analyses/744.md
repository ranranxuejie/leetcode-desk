## 一句话思路
在有序数组上找第一个严格大于 target 的位置，用二分；越界就回到 `letters[0]`。

## 怎么做
1. 把 `lo=0, hi=len(letters)`，区间取左闭右开，答案位置落在 `[lo, hi]`。
2. 循环条件 `lo < hi`，取 `mid=(lo+hi)//2`，比较 `letters[mid] <= target`。
3. 若 `letters[mid] <= target` 则 `lo=mid+1`，否则 `hi=mid`，循环结束时 `lo` 就是第一个大于 target 的下标。
4. 返回 `letters[lo]`，但 `lo == len(letters)` 时返回 `letters[0]`。

拿示例 2 走一遍：`letters=['c','f','j'], target='c'`。初始 `lo=0, hi=3`；`mid=1`，`letters[1]='f' > 'c'`，所以 `hi=1`；`mid=0`，`letters[0]='c' <= 'c'`，所以 `lo=1`；此时 `lo==hi==1` 退出，`letters[1]='f'`。注意这里用的是 `<=` 而不是 `<`，因为题目要的是**严格大于**，等于 target 的 'c' 必须被跳过。

```python
lo, hi = 0, len(letters)
while lo < hi:
    mid = (lo + hi) // 2
    if letters[mid] <= target:
        lo = mid + 1
    else:
        hi = mid
return letters[lo] if lo < len(letters) else letters[0]
```

示例 3 验证边界：`letters=['x','x','y','y'], target='z'`，所有元素都 `<= 'z'`，`lo` 一路推到 4，等于 `len(letters)`，走 `letters[0]='x'`。

## 复杂度
时间 O(log n)：n 是 `letters` 长度，二分每轮砍半。
空间 O(1)：只开了 `lo/hi/mid` 三个整数。

## 易错点
- 输入 `letters=['c','f','j'], target='c'` → 若写成 `letters[mid] < target` 才右移，`mid=0` 时 'c' 不小于 'c' 会把 `hi` 压到 0，返回 'c' 本身 → 必须用 `<=` 跳过所有等于 target 的元素。
- 输入 `letters=['x','x','y','y'], target='z'` → 若直接 `return letters[lo]` 会下标越界（`lo=4`）→ 返回前先判 `lo == len(letters)` 再取 `letters[0]`。

## 如果面试官追问
问：若 letters 不保证有序怎么办？
答：先排序 O(n log n) 再二分，或直接线性扫一遍取最小的大于 target 的字符，O(n)。
