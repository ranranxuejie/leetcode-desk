## 一句话思路
对每个节点做后序 DFS，用 1024 大小的位掩码 DP 合并子树，掩码记录已用数字，取最大和。

## 怎么做
1. 把 `par` 转成子节点列表 `children`，从 0 开始后序 DFS。
2. 每个节点维护 `dp[mask]` = 该子树内用掉数字集合 `mask` 时的最大和，初始只有 `dp[0]=0`。
3. 合并子节点时，对每个 `mask` 尝试与子节点的 `dp` 做不相交并（`mask & sub == 0`），更新 `new[mask|sub] = max(..., dp[mask]+sub_dp[sub])`。
4. 处理完所有子节点后，再尝试把当前节点 `vals[u]` 加入：先算 `vals[u]` 的数字掩码 `vm`，若 `mask & vm == 0` 则 `dp[mask|vm] = max(dp[mask|vm], dp[mask]+vals[u])`；最后 `maxScore[u] = max(dp)`，累加到答案。

以示例 3 `vals=[34,1,2], par=[-1,0,1]` 为例：节点 2 的 `dp` 为 `{0:0, 4:2}`（数字 2 对应 bit 2）；节点 1 合并后得 `{0:0, 2:1, 4:2, 6:3}`，加入自身 `1` 后 `dp[6]=3`；节点 0 合并子树得 `{0:0,2:1,4:2,6:3}`，加入 `34`（掩码 bit3|bit4=24）后 `dp[30]=37`，`maxScore[0]=37`。

```python
def dfs(u):
    dp = {0: 0}
    for v in children[u]:
        sub = dfs(v)
        nd = dict(dp)
        for m1, s1 in dp.items():
            for m2, s2 in sub.items():
                if m1 & m2 == 0:
                    nm = m1 | m2
                    if s1 + s2 > nd.get(nm, -1):
                        nd[nm] = s1 + s2
        dp = nd
    vm = 0
    x = vals[u]
    while x:
        vm |= 1 << (x % 10)
        x //= 10
    nd = dict(dp)
    for m, s in dp.items():
        if m & vm == 0:
            nm = m | vm
            if s + vals[u] > nd.get(nm, -1):
                nd[nm] = s + vals[u]
    dp = nd
    best = max(dp.values())
    ans[0] = (ans[0] + best) % (10**9 + 7)
    return dp
```

## 复杂度
时间：每个节点合并子节点时枚举 1024×1024 掩码对，总 O(n·2^20) 最坏，实际远小。
空间：每个节点存 1024 大小的 `dp`，递归栈 O(n)，合计 O(n·2^10)。

## 易错点
- `vals[u]` 含重复数字（如 `22`）→ 若直接 `vm |= 1<<(x%10)` 不检查，会把 `22` 当成合法单节点加入，实际它自身就不合法，正确做法是先算 `vm` 时检测 `vm & (1<<d)` 非零则整个节点不可选（`vm` 设为无效标记）。
- 合并顺序：先合并所有子节点再处理当前节点 → 若先处理当前节点再合并子节点，会漏掉「当前节点与某子节点同时选」的组合，正确做法是子节点全部合并完后再尝试加入 `vals[u]`。

## 如果面试官追问
若 `vals[i]` 可达 `10^9` 且数字更多，掩码仍只需 10 位，但需先过滤掉自身含重复数字的节点，答案不变。
