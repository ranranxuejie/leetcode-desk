## 一句话思路
二分答案 x，判定「只保留强度 ≥ x 的边（可选边可升级一次）能否构成含全部必选边的生成树」，用并查集。

## 怎么做
1. 先判必选边自身是否成环：把 must=1 的边全部 union，若某条必选边两端已连通，直接返回 -1。
2. 二分稳定性 x，范围 `[1, 2*max(s)]`（升级后最大强度是 2×10^5）。
3. 判定 check(x)：先 union 所有 must=1 且 s≥x 的边，若存在 must=1 且 s<x 则失败；再对 must=0 的边按「s≥x 免费、s<x 但 2s≥x 花 1 次升级」贪心 union，统计升级次数 ≤ k 且最终连通。
4. 二分取最大可行 x。

以示例 2 为例：n=3，三条可选边 s=4,3,1，k=2。check(6) 时：边 4 需升级（4<6≤8），边 3 需升级（3<6≤6），边 1 不可用（2<6）。两次升级后 union 出 {0-1,1-2}，连通且花费 2≤k，可行；check(7) 时边 3 升级后 6<7 不可用，只剩一条边，不连通，失败。故答案 6。

```python
def check(x):
    p = list(range(n)); cnt = 0
    def find(a):
        while p[a] != a:
            p[a] = p[p[a]]; a = p[a]
        return a
    for u, v, s, m in edges:
        if m == 1:
            if s < x: return False
            p[find(u)] = find(v)
    for u, v, s, m in edges:
        if m == 0:
            if s >= x: p[find(u)] = find(v)
            elif 2 * s >= x and cnt < k:
                p[find(u)] = find(v); cnt += 1
    return len({find(i) for i in range(n)}) == 1
```

## 复杂度
时间：二分 O(log(2·10^5)) 轮，每轮并查集 O((n+m)α)，共 O((n+m) log S · α)。
空间：并查集数组 O(n)，无额外大结构。

## 易错点
- 必选边成环（示例 3 三条 must=1 边构成三角形）→ 若只在 check 里 union 而不预先判环，会误判为可行 → 必须一开始单独 union 必选边并检测冲突，冲突即返回 -1。
- 可选边 s<x 但 2s≥x 时，若先处理 s≥x 的边再处理升级边，可能升级次数被浪费在已连通的分量上 → 正确做法是升级前先 find 判断两端是否已连通，已连通则跳过不消耗 k。

## 如果面试官追问
问：若要求输出具体生成树方案怎么办？
答：二分确定 x 后，在 check(x) 中记录每条被选中的边（含是否升级），直接返回该边集即可。
