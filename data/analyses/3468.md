## 一句话思路
所有 copy 都由 `copy[0]` 唯一决定，把每个位置的下界约束反解成对 `copy[0]` 的区间，取交集数个数。

## 怎么做
1. 令 `d[i] = original[i] - original[0]`，则 `copy[i] = copy[0] + d[i]`，只需确定 `copy[0]`。
2. 对每个 i，由 `u_i <= copy[0] + d[i] <= v_i` 得区间 `[u_i - d[i], v_i - d[i]]`。
3. 所有区间取交集 `[lo, hi]`，答案 `max(0, hi - lo + 1)`。

以示例 2 为例：`d = [0,1,2,3]`，第 0 个区间 `[1,10]`，第 1 个 `[1,8]`，第 2 个 `[1,6]`，第 3 个 `[1,4]`，交集 `[1,4]`，答案 4。

```python
lo, hi = -2**31, 2**31 - 1
d = 0
for i in range(len(original)):
    if i > 0:
        d += original[i] - original[i-1]
    lo = max(lo, bounds[i][0] - d)
    hi = min(hi, bounds[i][1] - d)
return max(0, hi - lo + 1)
```

注意 `d` 用增量累加，避免每次减 `original[0]` 时重复访问；`lo/hi` 初值取题目值域外即可，Python 整数不会溢出。

## 复杂度
时间 O(n)：一次遍历，每个位置做两次 max/min。
空间 O(1)：只维护 `lo`、`hi`、`d` 三个变量。

## 易错点
- 示例 3 这类 `original` 非单调（`[1,2,1,2]`）的输入 → 若误以为 `d` 单调递增、只检查端点会漏掉中间冲突 → 必须对每个 i 都更新交集，`d` 可正可负。
- 交集为空时（如 `lo > hi`）→ 若直接返回 `hi - lo + 1` 会得到负数 → 必须 `max(0, ...)`，示例 3 交集为空返回 0。

## 如果面试官追问
要求输出所有可行数组？答：交集大小即答案，枚举 `copy[0]` 从 `lo` 到 `hi`，每个加 `d[i]` 即得一组解，输出规模 O(答案 × n)。
