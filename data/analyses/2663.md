## 一句话思路
从右往左找第一个能增大的位置，改大后把后缀全部填成最小可行字符，贪心即最优。

## 怎么做
1. 关键观察：无长度 ≥2 的回文，等价于对每个 i，`s[i] != s[i-1]` 且 `s[i] != s[i-2]`（只需检查前两位）。
2. 从 `i = n-1` 往左扫，对每个 i 尝试把 `s[i]` 增大到 `c`（`s[i] < c < 'a'+k`），且 `c != s[i-1]`、`c != s[i-2]`；第一个成功的 i 就是改动点。
3. 改动点之后的位置 `j = i+1..n-1` 全部贪心取最小合法字符：从 `'a'` 起找第一个不等于 `res[j-1]`、`res[j-2]` 的字符。
4. 若整个扫描都没找到改动点，返回 `""`。

以 `s = "abcz", k = 26` 为例：i=3 时 `s[3]='z'` 已无更大字母，失败；i=2 时 `s[2]='c'`，试 `'d'`，检查 `s[1]='b'`、`s[0]='a'` 均不等，成功。于是 `res = "abd"`，再补 j=3：`'a'` 与 `res[2]='d'`、`res[1]='b'` 都不等，取 `'a'`，得 `"abda"`。

```python
res = list(s)
n = len(s)
for i in range(n - 1, -1, -1):
    for c in range(ord(s[i]) + 1, ord('a') + k):
        ch = chr(c)
        if i >= 1 and ch == res[i-1]: continue
        if i >= 2 and ch == res[i-2]: continue
        res[i] = ch
        for j in range(i + 1, n):
            for d in range(ord('a'), ord('a') + k):
                cd = chr(d)
                if j >= 1 and cd == res[j-1]: continue
                if j >= 2 and cd == res[j-2]: continue
                res[j] = cd
                break
        return ''.join(res)
return ""
```

## 复杂度
时间 O(n·k)：外层 n 个位置，每个最多试 k 个字母，后缀填充每格最多试 3 个字母。
空间 O(n)：`res` 列表存结果，无其他额外结构。

## 易错点
- 输入 `s = "abcz", k = 26`：若只检查 `s[i] != s[i-1]` 而漏掉 `s[i-2]`，会把 `"abda"` 错填成 `"abca"`（`'a'` 与 `res[1]='b'` 不等但与 `res[0]='a'` 相等，形成 `"aba"` 回文）。必须同时比较前两位。
- 输入 `s = "dc", k = 4`：若在 i=1 时只判断 `'d'` 有无更大字母就返回，会漏掉 i=0 也失败的情况。正确做法是两层循环都跑完仍无改动点才返回 `""`，不能提前退出。

## 如果面试官追问
问：若要求返回所有字典序大于 s 的美丽字符串中第 m 小的？答：把「找第一个可增大位」改成按位计数，用组合数累加后缀方案数定位第 m 个。
