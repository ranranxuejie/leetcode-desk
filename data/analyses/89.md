## 一句话思路
用公式 `g(i) = i ^ (i >> 1)` 直接生成第 i 个码，天然满足相邻只差一位。

## 怎么做
1. 循环 `i` 从 0 到 `2**n - 1`，每个 `i` 映射成一个格雷码。
2. 映射公式：`i ^ (i >> 1)`，右移一位后异或，把二进制「折叠」成反射码。
3. 按顺序收集即得序列，首项 `i=0` 得 0，末项与首项也只差一位。

以 `n = 2` 为例，`i` 取 0..3：
- `i=0`：`0 ^ 0 = 0` → `00`
- `i=1`：`1 ^ 0 = 1` → `01`
- `i=2`：`2 ^ 1 = 3` → `11`
- `i=3`：`3 ^ 1 = 2` → `10`

得到 `[0,1,3,2]`，与示例一致。关键中间值：`i=2` 时 `i>>1 = 1`，`2 ^ 1 = 3`，正是从 `01` 跳到 `11` 的那一位翻转。

```python
def grayCode(n):
    res = []
    for i in range(1 << n):
        res.append(i ^ (i >> 1))
    return res
```

`1 << n` 就是 `2**n`，`i >> 1` 是 `i // 2`。整个循环无分支、无回溯。

## 复杂度
时间 O(2^n)：循环 2^n 次，每次异或 O(1)。
空间 O(2^n)：结果列表存 2^n 个整数，无额外辅助结构。

## 易错点
- `n = 16` → 若用回溯逐位试错会超时或栈深爆炸 → 直接用公式，`2**16 = 65536` 次循环瞬间完成。
- 写成 `i ^ (i << 1)` → `n = 2` 得 `[0,3,2,1]`，相邻差两位，不合法 → 必须右移 `i >> 1`，方向不能反。

## 如果面试官追问
问：不用公式，怎么构造？
答：从 `[0]` 起，每轮把已有序列倒序、每个数加 `1 << (k-1)` 再拼接，反射构造同样 O(2^n)。
