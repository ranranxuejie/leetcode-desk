## 一句话思路
枚举所有满足 a³+b³≤n 的 (a,b)，用哈希表统计每个和出现次数，出现 ≥2 次即为好整数。

## 怎么做
1. 确定上界：a 最大到 `int(n ** (1/3)) + 1`，因为 a≤b 且 a³≤n/2 时才有解，实际取 `limit = int(n ** (1/3)) + 2` 足够。
2. 双重循环枚举 `a in range(1, limit)`、`b in range(a, limit)`，计算 `s = a**3 + b**3`，若 `s > n` 就 `break`（b 递增，后面只会更大）。
3. 用字典 `cnt[s] += 1` 计数，最后收集 `cnt[s] >= 2` 的键并排序。

以 n=4104 为例：`limit = 16+2 = 18`。枚举到 `(1,12)` 得 1729，`(9,10)` 也得 1729，`cnt[1729]` 变成 2；`(2,16)` 和 `(9,15)` 都得 4104，`cnt[4104]` 变成 2。其余和只出现一次，最终答案 `[1729, 4104]`。

```python
limit = int(n ** (1/3)) + 2
cnt = {}
for a in range(1, limit):
    for b in range(a, limit):
        s = a**3 + b**3
        if s > n:
            break
        cnt[s] = cnt.get(s, 0) + 1
return sorted(k for k, v in cnt.items() if v >= 2)
```

关键点：`b` 从 `a` 开始保证 `a<=b`，避免 (1,12) 和 (12,1) 被算成两组不同解——题目要求的是不同整数对，`(a,b)` 与 `(b,a)` 视为同一组。

## 复杂度
时间：O(limit²) ≈ O(n^(2/3))，limit 由 n 的立方根决定，内层 break 后实际更少。
空间：O(n^(2/3)) 个不同和存入字典 cnt，最坏约 limit²/2 个键。

## 易错点
- n=1 或 n=578 这类小输入 → 若 `limit` 只取 `int(n**(1/3))`，n=1 时 limit=1，range(1,1) 为空，漏掉边界；正确做法是 `+2` 兜底，保证 a=1,b=1 的 2 也被枚举到（虽然 2 不是好整数，但边界不能漏）。
- 内层不写 `if s > n: break` → 对 n=10^9，limit≈1002，双重循环约 50 万次全跑完，虽然能过但慢；正确做法是 b 递增时一旦超 n 立即 break，因为 b³ 单调增。

## 如果面试官追问
问：n 放大到 10^12 怎么办？
答：limit 变成 10^4，枚举量 5×10^7 偏大，可改用双指针：a 从 1 增、b 从 limit 减，O(limit) 找所有和，再哈希计数。
