## 一句话思路
按每个点到原点的切比雪夫距离 `d = max(|x|,|y|)` 排序，答案就是「第一个出现重复标签的距离」之前能放下的点数。

## 怎么做
1. 对每个点算 `d = max(abs(x), abs(y))`，边长 `2r` 的正方形恰好包含所有 `d <= r` 的点。
2. 把 `(d, s[i])` 按 `d` 升序排序，同距离的点必须整批一起纳入。
3. 逐批扫描：若某批加入后出现重复标签，则该批及之后全部不能要，答案 = 此前已纳入的点数。
4. 用 `seen` 集合记录已纳入标签，批内先查重再统一写入。

以示例 1 为例：`points[0]=(2,2)` 得 `d=2`，`points[1]=(-1,-2)` 得 `d=2`，`points[4]=(3,-3)` 得 `d=3`，`points[3]=(-3,1)` 得 `d=3`，`points[2]=(-4,4)` 得 `d=4`。排序后第一批 `d=2` 是标签 `a`、`b`，无冲突，`seen={a,b}`，计数 2；第二批 `d=3` 是 `c`、`a`，`a` 已在 `seen` 中，冲突，停止，返回 2。

```python
items = sorted((max(abs(x), abs(y)), ch) for (x, y), ch in zip(points, s))
seen, ans, i = set(), 0, 0
while i < len(items):
    j = i
    batch = set()
    while j < len(items) and items[j][0] == items[i][0]:
        if items[j][1] in seen or items[j][1] in batch:
            return ans
        batch.add(items[j][1])
        j += 1
    seen |= batch
    ans += j - i
    i = j
return ans
```

## 复杂度
时间 O(n log n)：排序主导，扫描 O(n)。
空间 O(n)：`items` 列表与 `seen` 集合各存 n 个元素。

## 易错点
- 同距离的点必须整批处理：示例 3 中 `(1,1)` 和 `(-1,-1)` 的 `d` 都是 1、标签都是 `c`，若逐个加入会在第二个 `c` 处返回 1，但正确结果是 0——因为边长 2 的正方形无法只装其中一个，所以整批冲突时答案应保持为 0。
- 冲突判定要同时查 `seen` 和批内 `batch`：示例 2 中 `(-2,-2)` 与 `(-2,2)` 的 `d` 都是 2、标签都是 `b`，只查 `seen` 会漏掉批内重复，误返回 2 而非 1。

## 如果面试官追问
若要求输出具体正方形边长？答：返回冲突批的前一个距离 `r`，边长取 `2r`，注意 `r` 可能为 0。
