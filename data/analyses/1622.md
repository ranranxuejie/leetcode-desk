## 一句话思路
用全局仿射变换 `(mul, add)` 懒标记，每个元素只存「入队时的原始值」，查询时再套当前变换。

## 怎么做
1. 维护全局 `mul`、`add`，初始 `mul=1, add=0`，表示所有元素当前值 = 原始值 × mul + add。
2. `append(val)` 时不能直接存 `val`，要存反解出的原始值 `(val - add) * inv(mul) % MOD`，这样它套上当前变换恰好等于 `val`。
3. `addAll(inc)` 直接 `add += inc`；`multAll(m)` 则 `mul *= m`、`add *= m`（先乘后加的顺序不能反）。
4. `getIndex(idx)` 返回 `(raw[idx] * mul + add) % MOD`，越界返回 -1。

以官方示例走一遍关键一步：执行到 `multAll(2)` 前，`mul=1, add=3`，`raw=[2, 4]`（`append(7)` 时反解 `(7-3)*1=4`）。`multAll(2)` 后 `mul=2, add=6`，`getIndex(0)` 得 `2*2+6=10`，与示例一致。

```python
MOD = 10**9 + 7

def append(self, val):
    raw = (val - self.add) * pow(self.mul, MOD - 2, MOD) % MOD
    self.raw.append(raw)

def multAll(self, m):
    self.mul = self.mul * m % MOD
    self.add = self.add * m % MOD

def getIndex(self, idx):
    if idx >= len(self.raw):
        return -1
    return (self.raw[idx] * self.mul + self.add) % MOD
```

## 复杂度
时间：每次操作 O(log MOD)（`append` 求逆元），其余 O(1)。
空间：`raw` 存 n 个原始值，O(n)。

## 易错点
- `multAll` 时只更新 `mul` 忘了 `add *= m` → 示例中 `multAll(2)` 后 `add` 仍是 3，`getIndex(0)` 得 `2*2+3=7` 而非 10。正确做法是两个都乘 m。
- `append` 直接存 `val` → 示例中 `append(7)` 存 7，之后 `multAll(2)` 得 14，但期望 10。必须先反解成原始值再存。

## 如果面试官追问
问：若 `mul` 可能为 0 怎么办？答：`pow(0, MOD-2)` 无解，需在 `mul==0` 时把已有 `raw` 全部重置为当前值并把 `mul` 复位为 1。
