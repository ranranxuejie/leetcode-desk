## 一句话思路
目标函数是凸的，用 Weiszfeld 迭代（加权平均）逼近几何中位数，比三分/梯度下降更稳。

## 怎么做
1. 取所有点的算术平均作初值 `cx, cy`，它是凸函数的合理起点。
2. 每轮按 `w_i = 1 / dist((cx,cy), p_i)` 加权，更新 `cx = Σ w_i·x_i / Σ w_i`，`cy` 同理。
3. 若某点距离 `< 1e-12`，跳过它（否则除零），或直接返回当前和。
4. 迭代到 `(cx,cy)` 位移小于 `1e-7` 或跑满 1000 轮，再算一次总距离。

以示例 1 `[[0,1],[1,0],[1,2],[2,1]]` 为例：初值 `cx=cy=1.0`，四个距离都是 1，权重全为 1，加权平均仍是 `(1,1)`，一步就收敛，返回 `4.0`。

```python
import math
cx = sum(p[0] for p in positions) / len(positions)
cy = sum(p[1] for p in positions) / len(positions)
for _ in range(1000):
    sw = sx = sy = 0.0
    for x, y in positions:
        d = math.hypot(x - cx, y - cy)
        if d < 1e-12:
            continue
        w = 1.0 / d
        sw += w; sx += w * x; sy += w * y
    if sw == 0:
        break
    nx, ny = sx / sw, sy / sw
    if math.hypot(nx - cx, ny - cy) < 1e-7:
        cx, cy = nx, ny
        break
    cx, cy = nx, ny
return sum(math.hypot(x - cx, y - cy) for x, y in positions)
```

## 复杂度
时间：O(n·K)，n 为点数，K 为迭代轮数（≤1000），每轮扫一遍数组。
空间：O(1)，只存 `cx, cy, sw, sx, sy` 几个标量。

## 易错点
- 所有点重合（如 `[[5,5],[5,5]]`）→ 每轮 `d<1e-12` 全被跳过，`sw=0` 导致除零 → 必须加 `if sw == 0: break` 保护，直接返回 0。
- 初值取 `(0,0)` 而非均值 → 当点全在 `x,y≥50` 区域时，首轮权重被远端主导，收敛慢甚至震荡 → 用算术平均起步，示例 1 一步即中。

## 如果面试官追问
问：点坐标范围放大到 1e9 会怎样？答：Weiszfeld 仍收敛，但 `1e-7` 的位移阈值要按坐标量级放大，否则提前停。
