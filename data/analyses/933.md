## 一句话思路
用一个队列按时间顺序存请求，每次 ping 把队头早于 `t - 3000` 的弹出，剩下的长度就是答案。

## 怎么做
1. 初始化一个空的双端队列 `q`（`collections.deque`），只存时间戳。
2. 每次 `ping(t)` 先把 `t` 追加到队尾。
3. 循环检查队头：只要 `q[0] < t - 3000` 就 `popleft()`，因为时间严格递增，队头一定是最早的请求。
4. 返回 `len(q)`。

以官方示例走一遍关键一步：`ping(3001)` 时先入队，`q = [1, 100, 3001]`；阈值是 `3001 - 3000 = 1`，队头 `1 < 1` 为假，不弹出，返回 `3`。接着 `ping(3002)`，`q = [1, 100, 3001, 3002]`，阈值 `2`，队头 `1 < 2` 为真，弹出 `1`，`q = [100, 3001, 3002]`，返回 `3`——注意 `100` 没被弹，因为 `100 >= 2`。

```python
from collections import deque

class RecentCounter:
    def __init__(self):
        self.q = deque()

    def ping(self, t: int) -> int:
        self.q.append(t)
        while self.q[0] < t - 3000:
            self.q.popleft()
        return len(self.q)
```

边界用 `<` 而不是 `<=`：`t - 3000` 本身算在窗口内。示例里 `ping(3001)` 的窗口是 `[1, 3001]`，`1` 必须保留，若写成 `<=` 会把 `1` 弹掉，返回 `2` 就错了。

## 复杂度
时间：每次 ping 均摊 O(1)，每个时间戳最多入队一次、出队一次，总计 O(n)。
空间：O(n)，`q` 最多同时存 n 个时间戳，n 为 ping 调用次数。

## 易错点
- 把弹出条件写成 `q[0] <= t - 3000` → 示例 `ping(3001)` 会弹掉 `1` 返回 `2`，正确答案是 `3` → 必须用严格小于 `<`，因为 `t - 3000` 在闭区间内。
- 用 `list` 加 `pop(0)` 实现 → 每次弹出是 O(n) 搬移，10^4 次调用虽能过但退化 → 用 `deque.popleft()`，或改用 `list` 配一个 `head` 下标指针只增不减。

## 如果面试官追问
追问：如果 t 不保证递增怎么办？
答：队列失效，改用有序结构（如按时间排序的平衡树或对时间戳二分），每次统计 `[t-3000, t]` 区间内的个数。
