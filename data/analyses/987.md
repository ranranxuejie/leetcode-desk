## 一句话思路
DFS 给每个结点打上 (col, row, val) 三元组，按 col 升序、row 升序、val 升序排序后按 col 分组即可。

## 怎么做
1. 从根 `(0, 0)` 出发 DFS，左孩子 `col-1`、右孩子 `col+1`，把 `(col, row, node.val)` 塞进列表 `nodes`。
2. 对 `nodes` 按 `(col, row, val)` 三元组排序——Python 元组默认字典序，一行 `nodes.sort()` 就够。
3. 顺序扫一遍，`col` 变化时开新组，把 `val` 追加进当前组。

以示例 2 `root = [1,2,3,4,5,6,7]` 为例：DFS 后 `nodes` 含 `(0,0,1)`、`(-1,1,2)`、`(1,1,3)`、`(-2,2,4)`、`(0,2,5)`、`(0,2,6)`、`(2,2,7)`。排序后 `(0,2,5)` 排在 `(0,2,6)` 前，因为 row 相同、val 5<6；而 `(0,0,1)` 因 row=0 排在这两个之前，所以列 0 得到 `[1,5,6]`。

```python
nodes = []
def dfs(node, row, col):
    if not node:
        return
    nodes.append((col, row, node.val))
    dfs(node.left, row + 1, col - 1)
    dfs(node.right, row + 1, col + 1)
dfs(root, 0, 0)
nodes.sort()
res = []
for col, row, val in nodes:
    if not res or col != last_col:
        res.append([])
        last_col = col
    res[-1].append(val)
```

## 复杂度
时间 O(n log n)：n 个结点排序，比较键是三元组常数长度。
空间 O(n)：`nodes` 存 n 个三元组，递归栈最坏 O(n)。

## 易错点
- 输入 `[1,2,3,4,5,6,7]` 中 5 和 6 同处 `(2, 0)`：只按 `(col, row)` 排序会保留 DFS 访问顺序，示例 3 交换 5、6 位置后输出就变了；必须把 `val` 作为第三排序键。
- 输入 `[3,9,20,null,null,15,7]` 的列号含负数 `-1`：若用 `col` 直接当下标存进数组会越界或错位；正确做法是排序后按 `col` 值分组，或先求 `min_col` 再整体平移。

## 如果面试官追问
问：结点数涨到 10^6 还要求 O(n)？
答：用 BFS 按 row 逐层处理，同层内按 col 归并，避免全局排序的 log n。
