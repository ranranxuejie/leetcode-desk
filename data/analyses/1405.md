## 一句话思路
每步取剩余最多的字母追加，若它已连续两次则改取次多的，贪心保证最长。

## 怎么做
1. 用三个变量 `cnt = [a, b, c]` 记录剩余数量，循环直到无法再追加。
2. 每轮按数量降序挑候选字母，优先选最多的那个。
3. 若最多的字母恰好等于结果串末尾两个字符，则跳过它，改选次多的。
4. 追加后对应计数减一，若所有候选都被跳过则结束。

以 `a=1, b=1, c=7` 为例：第一轮 `cnt=[1,1,7]`，最多是 `c`，末尾无冲突，追加 `c`，`cnt=[1,1,6]`；第二轮仍选 `c`，追加后 `cnt=[1,1,5]`；第三轮 `c` 已连续两次，跳过，选次多的 `a`，追加 `a`，`cnt=[0,1,5]`。如此交替，最终得到 `"ccaccbcc"` 这类合法串。

```python
cnt = [a, b, c]
res = []
while True:
    picked = -1
    for i in sorted(range(3), key=lambda x: -cnt[x]):
        if cnt[i] == 0:
            continue
        if len(res) >= 2 and res[-1] == res[-2] == chr(ord('a') + i):
            continue
        picked = i
        break
    if picked == -1:
        break
    res.append(chr(ord('a') + picked))
    cnt[picked] -= 1
return ''.join(res)
```

关键点：`sorted(range(3), key=lambda x: -cnt[x])` 每轮重新排序，保证总是先试最多的字母；`res[-1] == res[-2] == chr(...)` 判断是否会造成三连。

## 复杂度
时间：每轮排序 3 个元素是 O(1)，共 O(a+b+c) 轮，总 O(n)，n = a+b+c。
空间：结果串 O(n)，计数数组和排序临时量 O(1)。

## 易错点
- 输入 `a=7, b=1, c=0` → 若只按数量贪心不检查末尾，会生成 `"aaaa..."` 出现 `"aaa"`；正确做法是当 `a` 已连续两次时强制插入 `b`，得到 `"aabaa"`。
- 输入 `a=0, b=0, c=1` → 若循环条件写成「三个计数都大于 0 才继续」会直接返回空串；正确做法是只要存在任一 `cnt[i] > 0` 且不违反三连就继续，返回 `"c"`。

## 如果面试官追问
问：若字母种类扩展到 k 种怎么做？
答：把排序换成大小为 k 的最大堆，每轮弹出堆顶，若与末尾两次相同则弹次顶，操作后重新入堆，复杂度 O(n log k)。
