## 一句话思路
每次操作让 x 减 1、num 加 1，两者差距缩小 2，t 次后最大 x 就是 num + 2*t。

## 怎么做
1. 把「x 变到 num」改写成「x 与 num 的差」：初始差 d = x - num，目标是 d 降到 0。
2. 每次操作 x 减 1、num 加 1，d 减少 2，所以 t 次最多消掉 2*t 的差。
3. 要让 x 最大，就让 d 恰好等于 2*t，即 x = num + 2*t。

以官方示例 num = 4, t = 1 为例：d 初始为 x - 4，一次操作后 d 减 2，要归零需 d = 2，于是 x = 4 + 2 = 6，与输出一致。示例 2 中 num = 3, t = 2，d = 4，x = 3 + 4 = 7。

```python
def theMaximumAchievableX(num: int, t: int) -> int:
    return num + 2 * t
```

关键就一行：`num + 2 * t`。不需要循环，也不需要模拟操作过程。

## 复杂度
时间：O(1)，只有一次加法和一次乘法。
空间：O(1)，没有开任何额外数组或哈希表。

## 易错点
- 把每次操作理解成「x 和 num 各动 1，所以差距只缩小 1」→ 对 num = 4, t = 1 会算成 5 → 正确是差距缩小 2，答案 6。
- 以为 x 只能减小、不能增大，于是返回 num 本身 → 对 num = 3, t = 2 会错成 3 → 题目问的是「可达成数字的最大值」，x 可以比 num 大，答案 7。

## 如果面试官追问
问：如果要求返回所有可达成数字而非最大值？答：可达范围是 [num - 2*t, num + 2*t] 内与 num 同奇偶的所有整数，最大值仍是 num + 2*t。
