## 一句话思路
异或分数等于子数组所有元素的异或（反复相邻异或等价于全体异或），于是问题变成「区间内任意子数组的最大异或和」，用前缀异或 + 按右端点递推的 DP 表。

## 怎么做
1. 先证：长度 m 的数组反复操作后剩下的是全部元素异或，所以分数 = 子数组异或和。
2. 令 `pre[i] = nums[0]^...^nums[i-1]`，子数组 `[a,b]` 的分数 = `pre[b+1]^pre[a]`。
3. 对每个右端点 `r`，维护 `best[l]` = 在 `nums[l..r]` 内任选子数组的最大异或，`r` 增大时用 `pre[r+1]` 与 `pre[l..r]` 逐个异或更新。
4. 查询 `[l,r]` 直接读 `best` 表在 `r` 行、`l` 列的值。

以示例 1 的 `nums=[2,8,4,32,16,1]` 为例，`pre=[0,2,10,14,46,62,63]`。处理到 `r=2`（即 `pre[3]=14`）时，与 `pre[0..2]=[0,2,10]` 异或得 `14,12,4`，其中 `12 = pre[3]^pre[1]` 对应子数组 `[8,4]`，正是查询 `[0,2]` 的答案。

```python
n = len(nums)
pre = [0] * (n + 1)
for i, x in enumerate(nums):
    pre[i + 1] = pre[i] ^ x
best = [[0] * n for _ in range(n)]
for r in range(n):
    cur = 0
    for l in range(r, -1, -1):
        cur = max(cur, pre[r + 1] ^ pre[l])
        best[l][r] = cur
return [best[l][r] for l, r in queries]
```

## 复杂度
时间：`O(n^2)` 建表（每个 `(l,r)` 一次异或比较），`O(q)` 回答，`n=2000` 时约 4×10^6。
空间：`O(n^2)` 的 `best` 表，约 4×10^6 个整数，`pre` 只占 `O(n)`。

## 易错点
- 把「异或分数」当成某种特殊运算去模拟 → 对 `[2,8,4]` 会算出 6 而不是 12 → 必须先化简为全体异或，再用 `pre[r+1]^pre[l]`。
- 建表时 `cur` 只与 `pre[r+1]^pre[r]`（单元素）比较，漏掉更长子数组 → 示例 1 查询 `[0,2]` 会得 4 而非 12 → 内层 `l` 必须从 `r` 递减到 0，让 `cur` 累积覆盖所有左端点。

## 如果面试官追问
问：n 放大到 10^5 怎么办？答：`O(n^2)` 表存不下，需按查询离线排序 + 可持久化 01 字典树，把「区间内最大子数组异或」转成前缀异或集合上的最大异或查询。
