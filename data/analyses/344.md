## 一句话思路
用左右双指针 `i`、`j` 从两端向中间靠拢，逐对交换 `s[i]` 与 `s[j]`，走到相遇即完成原地反转。

## 怎么做
1. 初始化 `i = 0`、`j = len(s) - 1`，两个指针分别指向首尾。
2. 循环条件写 `while i < j`，保证中间那个元素（奇数长度时）不被自己和自己交换。
3. 每轮执行 `s[i], s[j] = s[j], s[i]`，然后 `i += 1`、`j -= 1`。
4. 循环结束时数组已原地反转，函数返回 `None` 即可（题目要求 `-> void`）。

以示例 1 `s = ["h","e","l","l","o"]` 为例，长度 5，`i=0, j=4`：
- 第 1 轮交换后 `s = ["o","e","l","l","h"]`，`i=1, j=3`；
- 第 2 轮交换后 `s = ["o","l","l","e","h"]`，`i=2, j=2`；
- 此时 `i < j` 为 `False`，退出，中间的 `"l"` 原地不动，结果正确。

```python
i, j = 0, len(s) - 1
while i < j:
    s[i], s[j] = s[j], s[i]
    i += 1
    j -= 1
```

关键点：交换用 Python 的元组解包一行完成，不需要 `tmp`；`while i < j` 而不是 `i <= j`，否则奇数长度时 `i == j` 会多做一次无意义的自交换（结果不变但多一次赋值）。

## 复杂度
时间 O(n)：`n = len(s)`，共交换 `n // 2` 次，每次 O(1)。
空间 O(1)：只用了 `i`、`j` 两个整数下标，没有新建数组。

## 易错点
- 输入 `s = ["a"]`（长度 1）→ 若写成 `while i <= j` 会执行一次 `s[0], s[0] = s[0], s[0]`，虽结果对但逻辑冗余；若误写成先 `i += 1` 再判断，还可能越界。正确做法是条件用 `i < j`，单元素直接跳过循环。
- 输入 `s = ["h","e","l","l","o"]` → 若用 `s = s[::-1]` 或 `s.reverse()` 之外的「新建列表再赋值」写法（如 `s = list(reversed(s))`），只是让局部名 `s` 指向新对象，调用方持有的原数组没变，判题会读到旧值。正确做法是只做下标赋值 `s[i], s[j] = s[j], s[i]`，绝不重新绑定 `s`。

## 如果面试官追问
问：如果输入是字符串而不是字符数组，还能 O(1) 空间吗？
答：不能，Python 字符串不可变，反转必然新建对象，空间 O(n)；只有字符数组（list）才能原地交换。
