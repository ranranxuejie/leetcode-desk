## 一句话思路
把「已分配导师集合」压成位掩码做状压 DP，`dp[mask]` 表示前 `popcount(mask)` 个学生配完这些导师的最大得分。

## 怎么做
1. 先算 `score[i][j]`：学生 `i` 与导师 `j` 逐位相同个数，`m,n ≤ 8` 直接双重循环。
2. 状态 `mask` 的二进制第 `j` 位为 1 表示导师 `j` 已被占用；`mask` 里 1 的个数就是已配好的学生数 `i`。
3. 转移：枚举未占用的导师 `j`，`dp[mask | 1<<j] = max(..., dp[mask] + score[i][j])`。
4. 答案 `dp[(1<<m)-1]`。

以示例 1 为例，`score[0] = [2,1,3]`。当 `mask=0b101`（导师 0、2 已用，`i=2`）时，只剩导师 1，`dp[0b111] = dp[0b101] + score[2][1] = 5 + 3 = 8`，这就是最终答案。

```python
m = len(students)
score = [[sum(a == b for a, b in zip(s, t)) for t in mentors] for s in students]
full = (1 << m) - 1
dp = [-1] * (1 << m)
dp[0] = 0
for mask in range(1 << m):
    if dp[mask] < 0:
        continue
    i = bin(mask).count("1")
    for j in range(m):
        if not (mask >> j) & 1:
            nm = mask | (1 << j)
            dp[nm] = max(dp[nm], dp[mask] + score[i][j])
return dp[full]
```

## 复杂度
时间：`O(2^m · m)`，`m` 是导师数，`score` 预处理另花 `O(m^2 n)`。
空间：`O(2^m)` 的 `dp` 数组，`score` 占 `O(m^2)`。

## 易错点
- 忘记 `mask` 的 1 的个数就是学生下标 `i`：若把 `i` 写成循环变量或 `mask` 本身，示例 1 中 `mask=0b101` 会取到 `score[5]` 越界。正确做法是 `i = bin(mask).count("1")`。
- 用 `dp` 初值 `0` 而非 `-1`：示例 2 全 0 分时看不出错，但示例 1 中未到达的状态会被当成合法 0 分参与转移，可能把 `dp[0b111]` 压成 5。正确做法是初值 `-1` 并跳过 `dp[mask] < 0`。

## 如果面试官追问
若 `m` 放大到 20 要求输出具体配对方案？状压 DP 存不下 `2^20` 的转移来源，改用匈牙利算法求二分图最大权匹配，`O(m^3)` 并回溯匹配边。
