## 一句话思路
先数每行每列的 1 的个数，只有行和为 1 且列和为 1 的 `mat[i][j]==1` 才是特殊位置。

## 怎么做
1. 遍历 `mat`，累加出 `row[i]`（第 i 行 1 的个数）和 `col[j]`（第 j 列 1 的个数）。
2. 再遍历一次，对每个 `mat[i][j]==1` 检查 `row[i]==1 and col[j]==1`，成立则计数加一。
3. 用示例 1 走一遍：`mat = [[1,0,0],[0,0,1],[1,0,0]]`，得到 `row = [1,1,1]`、`col = [2,0,1]`。
4. 检查 (1,2)：`mat[1][2]==1`、`row[1]==1`、`col[2]==1`，计数 1；而 (0,0) 因 `col[0]==2` 被排除，(2,0) 同理。

```python
m, n = len(mat), len(mat[0])
row = [0] * m
col = [0] * n
for i in range(m):
    for j in range(n):
        if mat[i][j] == 1:
            row[i] += 1
            col[j] += 1
ans = 0
for i in range(m):
    for j in range(n):
        if mat[i][j] == 1 and row[i] == 1 and col[j] == 1:
            ans += 1
```

关键点：`row[i]==1` 已经保证该行其余元素全为 0，`col[j]==1` 保证该列其余元素全为 0，所以不必再逐行逐列扫一遍验证。

## 复杂度
时间：O(m·n)，两趟完整遍历，每格常数次操作。
空间：O(m+n)，只开了 `row` 和 `col` 两个计数数组。

## 易错点
- 输入 `[[1,0],[0,1]]` 时若只判 `row[i]==1` 就计数，会把 (0,0) 和 (1,1) 都算对，但换成 `[[1,1],[0,0]]` 就会把 (0,0)、(0,1) 误判为特殊位置 → 必须同时要求 `col[j]==1`，两个条件缺一不可。
- 输入 `[[0,0],[0,0]]` 时若把「行和列全 0」也当成候选，会返回 4 → 计数前必须先确认 `mat[i][j]==1`，全 0 矩阵答案应为 0。

## 如果面试官追问
问：若矩阵是稀疏的、1 很少，怎么优化？
答：只存 1 的坐标列表，按行分组，行内只有一个 1 时再查该列 1 的个数是否为 1，复杂度降到 O(k)。
