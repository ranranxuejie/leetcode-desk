## 一句话思路
删掉一段长度 k 的窗口后，终点 = 总位移 − 该窗口位移，故只需对 n−k+1 个窗口位移去重。

## 怎么做
1. 先算整串总位移 `(tx, ty)`，再算前缀位移数组 `px[i], py[i]`（走完前 i 个字符后的坐标）。
2. 对起点 `i` 从 0 到 n−k，窗口 `s[i:i+k]` 的位移是 `(px[i+k]-px[i], py[i+k]-py[i])`，终点是 `(tx - 该dx, ty - 该dy)`。
3. 把这些终点塞进 `set`，返回 `len(set)`。

以 `s = "LUL", k = 1` 为例：总位移 `tx = -1, ty = 1`；前缀为 `(0,0), (-1,0), (-1,1), (-2,1)`。i=0 窗口 `"L"` 位移 `(-1,0)`，终点 `(0,1)`；i=1 窗口 `"U"` 位移 `(0,1)`，终点 `(-1,0)`；i=2 窗口 `"L"` 位移 `(-1,0)`，终点 `(0,1)`。集合为 `{(0,1), (-1,0)}`，大小 2。

```python
n = len(s)
px, py = [0]*(n+1), [0]*(n+1)
for i, c in enumerate(s):
    dx, dy = {'U':(0,1),'D':(0,-1),'L':(-1,0),'R':(1,0)}[c]
    px[i+1], py[i+1] = px[i]+dx, py[i]+dy
tx, ty = px[n], py[n]
seen = set()
for i in range(n-k+1):
    seen.add((tx-(px[i+k]-px[i]), ty-(py[i+k]-py[i])))
return len(seen)
```

注意 `range(n-k+1)` 恰好覆盖所有合法起点，`k == n` 时只有 i=0，终点为 `(0,0)`。

## 复杂度
时间 O(n)：一次前缀和 + n−k+1 次窗口查询，每次 O(1)。
空间 O(n)：前缀数组 2(n+1) 个整数，外加最多 n−k+1 个终点的 set。

## 易错点
- `k == n` 时若写成 `range(n-k)` 会得到空循环、返回 0；正确是 `range(n-k+1)`，此时唯一终点 `(tx-tx, ty-ty) = (0,0)`，答案 1。
- 用「窗口位移」而非「窗口内坐标」去重：如 `s = "UU", k = 1`，两个窗口位移都是 `(0,1)`，终点都是 `(0,1)`，若误按窗口起点去重会得 2；正确做法是对终点元组去重，答案 1。

## 如果面试官追问
若要求输出所有不同终点而非计数？答：把 set 换成按插入序去重的 list（配一个 seen set），返回坐标列表即可，复杂度不变。
