## 一句话思路
用 `n & (n - 1)` 每次消掉最低位的 1，循环次数等于 1 的个数，比逐位检查 32 次更省。

## 怎么做
1. 计数器 `count = 0`，循环条件 `while n:`。
2. 每轮执行 `n &= n - 1`，把最低位的 1 清零，`count += 1`。
3. 循环结束时 `n == 0`，返回 `count`。

以示例 1 的 `n = 11`（二进制 `1011`）为例：第一轮 `n & (n-1)` 即 `1011 & 1010 = 1010`，`count = 1`；第二轮 `1010 & 1001 = 1000`，`count = 2`；第三轮 `1000 & 0111 = 0000`，`count = 3`，`n` 归零退出，返回 3。三次循环正好对应三个 1。

```python
count = 0
while n:
    n &= n - 1
    count += 1
return count
```

关键点：`n - 1` 会把最低位的 1 变成 0、把它右边的所有 0 变成 1，再与 `n` 相与，恰好只抹掉那一个 1，其余位不变。所以循环次数严格等于 1 的个数，而不是固定 32 次。

## 复杂度
时间：O(k)，k 为 1 的个数，最坏 32 次，与 n 的位宽相关。
空间：O(1)，只用了 `count` 和循环变量 `n`，无额外数组。

## 易错点
- 输入 `n = 4294967293`（即 `-3`，二进制 31 个 1）→ 若用 `while n > 0` 判断，负数直接不进循环返回 0 → 正确写法是 `while n:`，靠 `n &= n - 1` 把高位 1 逐个消掉直到 0，不依赖符号。
- 输入 `n = 0` → 若先写 `count = 1` 或漏掉循环边界，会返回 1 → 正确做法是 `count` 初始为 0，`while n:` 对 0 直接跳过，返回 0。

## 如果面试官追问
问：如果要求统计任意长度大整数（比如 1024 位）的 1 个数怎么办？
答：同样用 `n &= n - 1`，Python 大整数天然支持，循环次数仍是 1 的个数，只是单次位运算代价随位数增长。
