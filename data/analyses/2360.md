## 一句话思路
每个点出度至多 1，用带时间戳的 DFS 走链，遇到本次访问过的点就得到环长。

## 怎么做
1. 开 `vis` 数组记录每个节点被访问时的「轮次时间戳」，初值 0，全局计数器 `t` 从 1 递增。
2. 对每个未访问节点启动一次遍历：沿 `edges` 一路走，边走边把 `vis[cur] = t`，`t += 1`。
3. 走到 `-1` 或走到 `vis[cur] != 0` 就停；若停下的点 `vis[cur] >= start_t`，说明是本轮踩到的，环长 = `t - vis[cur]`。
4. 取所有环长的最大值，没有环返回 -1。

以 `edges = [3,3,4,2,3]` 为例，从 0 出发：`vis[0]=1`，走到 3 记 `vis[3]=2`，走到 2 记 `vis[2]=3`，走到 4 记 `vis[4]=4`，再走回 3 时 `vis[3]=2 >= start_t=1`，环长 `t - vis[3] = 5 - 2 = 3`，正是 2→4→3→2。

```python
n = len(edges)
vis = [0] * n
t = 1
ans = -1
for i in range(n):
    if vis[i]:
        continue
    start = t
    cur = i
    while cur != -1 and vis[cur] == 0:
        vis[cur] = t
        t += 1
        cur = edges[cur]
    if cur != -1 and vis[cur] >= start:
        ans = max(ans, t - vis[cur])
return ans
```

关键在 `vis[cur] >= start`：只有本轮（时间戳不小于本轮起点）访问过的点才构成新环，否则是撞上了前面某轮走过的链，直接跳过。

## 复杂度
时间 O(n)：每个节点最多被写入 `vis` 一次，指针沿边只前进不回退。
空间 O(n)：`vis` 数组存 n 个时间戳，无递归栈。

## 易错点
- 输入 `edges = [1,2,0]` 这种纯环：若用「访问过就跳过」的布尔标记而不带轮次，从 0 走完环后从 1 出发会误判为已访问而漏算，正确做法是记录时间戳并比较 `vis[cur] >= start`。
- 输入 `edges = [2,-1,3,1]`（示例 2）：从 0 走到 2 再走到 3 再走到 1 停在 -1，`cur == -1` 时若仍去读 `vis[cur]` 会下标越界，必须先判 `cur != -1` 再比较时间戳。

## 如果面试官追问
若要求输出最长环的具体节点序列而非长度？答：在 DFS 中额外记录路径栈，命中环时从栈中截取 `vis[cur]` 对应位置到栈顶的片段即可。
