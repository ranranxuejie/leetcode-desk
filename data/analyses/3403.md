## 一句话思路
枚举每个起点 i，取 `word[i:i+L]`（L 由 numFriends 决定），取字典序最大者；因为最优段必是某后缀的前缀。

## 怎么做
1. 若 `numFriends == 1`，唯一分割就是整串，直接返回 `word`。
2. 记 `n = len(word)`，单个朋友最多能拿 `L = n - numFriends + 1` 个字符（其余 numFriends-1 人至少各占 1 个）。
3. 枚举起点 `i` 从 0 到 n-1，候选为 `word[i:i+L]`（不足 L 就截到末尾），保留字典序最大者。
4. 用 `max` 直接比较字符串即可，Python 字符串比较就是字典序。

以 `word = "dbca", numFriends = 2` 为例：`n=4`，`L = 4-2+1 = 3`。候选依次为 `"dbc"`（i=0）、`"bca"`（i=1）、`"ca"`（i=2）、`"a"`（i=3），最大是 `"dbc"`。

```python
n = len(word)
if numFriends == 1:
    return word
L = n - numFriends + 1
best = ""
for i in range(n):
    cand = word[i:i + L]
    if cand > best:
        best = cand
return best
```

关键点：为什么不用考虑「段必须非空且拼满整串」？因为任何长度 ≤ L 的段都能作为某个分割中的一块出现——把剩下的字符切成 numFriends-1 个非空块即可（剩余长度 n-len ≥ numFriends-1 恰好由 L 的定义保证）。所以候选集合就是所有 `word[i:i+L]` 截断形式。

## 复杂度
时间：O(n·L)，n 个起点各比较至多 L 个字符，L ≤ n。
空间：O(L)，只存 best 和 cand 两个切片。

## 易错点
- `numFriends == 1` 时若仍按 `L = n` 枚举，`word[i:i+n]` 会得到 `"dbca"`、`"bca"`、`"ca"`、`"a"`，最大是 `"dbca"` 恰好也对；但若漏掉这个分支又误把 L 算成 `n - numFriends + 1 = n`，逻辑上没错却容易在别的题面变体里翻车——本题必须显式处理，因为 numFriends=1 时"分割成 1 个非空串"只有一种方式，答案就是原串。
- 输入 `word = "gggg", numFriends = 4`：`L = 4-4+1 = 1`，候选全是 `"g"`，答案 `"g"`。若把 L 误写成 `n // numFriends = 1` 碰巧对，但换成 `"abcdef", numFriends = 3` 时 `n//3 = 2` 而正确 `L = 4`，会漏掉 `"abcd"` 这类长候选，错答成 `"cd"` 或 `"ef"`。

## 如果面试官追问
问：n 放大到 5×10^5 怎么办？答：O(n·L) 会退化，改用后缀数组或双指针比较后缀排名，O(n log n) 预处理后 O(n) 取最大。
