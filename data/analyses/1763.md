## 一句话思路
分治：在区间里找「只出现大写或只出现小写」的字符当分割点，两侧递归取更长者。

## 怎么做
1. 对区间 `s[lo:hi]` 扫一遍，用 26 位掩码 `lower`、`upper` 记录出现过的小写/大写字母。
2. 若 `lower == upper`，整个区间就是美好串，直接返回。
3. 否则取 `bad = lower ^ upper`（只出现单侧的字母），把区间按这些字符切成若干段，逐段递归。
4. 用 `(长度, -起点)` 比较，长度相同取起点更小的，保证「最早出现」。

以 `s = "YazaAay"` 为例，第一层 `lower` 含 a、z、y，`upper` 含 Y、A，`bad` 里 y 和 Y 都在但 z 只有小写，于是 `z` 成为分割点，切成 `"Ya"` 和 `"aAay"`；右段再切掉 `y`，得 `"aAa"`，`lower == upper`，返回它。

```python
def solve(lo, hi):
    lower = upper = 0
    for ch in s[lo:hi]:
        if ch.islower(): lower |= 1 << (ord(ch) - 97)
        else: upper |= 1 << (ord(ch) - 65)
    if lower == upper: return s[lo:hi]
    bad = lower ^ upper
    best, i = "", lo
    for j in range(lo, hi + 1):
        if j == hi or (bad >> (ord(s[j].lower()) - 97)) & 1:
            cand = solve(i, j)
            if len(cand) > len(best): best = cand
            i = j + 1
    return best
```

## 复杂度
时间：每层扫描 O(n)，递归深度最多 26（每层至少消掉一种字母），O(26n)。
空间：递归栈 O(26)，无额外数组。

## 易错点
- 输入 `"c"`：`lower = 1, upper = 0`，`bad = 1`，若忘记在 `j == hi` 处收尾，最后一段永远不递归，返回 `""` 恰好对但 `"Bb"` 这类会漏；必须显式处理右边界。
- 输入 `"dDzeE"`：`dD` 与 `eE` 等长，若用 `>=` 更新 `best` 会返回 `"eE"`；必须严格 `>` 才保留最早出现的 `"dD"`。

## 如果面试官追问
问：n 到 10^5 还能分治吗？
答：不能，退化成 O(n²)；改用固定左端点枚举 26 种「允许字母集合」的滑窗，O(26n)。
