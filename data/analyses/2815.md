## 一句话思路
用长度 10 的数组 `best[d]` 记录「数位最大数字为 d」的已出现最大值，边扫边配对求和。

## 怎么做
1. 开 `best = [-1] * 10`，下标就是数位最大数字 d（0~9）。
2. 对每个 `x` 求 d：`d = max(int(c) for c in str(x))`。
3. 若 `best[d] != -1`，用 `best[d] + x` 更新答案；再用 `x` 更新 `best[d]`。
4. 扫完返回答案，没配成对就是 -1。

以 `nums = [51,71,17,24,42]` 为例：51 的 d=5，`best[5]=51`；71 的 d=7，`best[7]=71`；17 的 d=7，此时 `best[7]=71` 已存在，候选和 `71+17=88`，答案变 88，`best[7]` 更新为 71（17 更小不替换）；24 的 d=4，`best[4]=24`；42 的 d=4，候选 `24+42=66`，小于 88 不更新。最终 88。

关键点：同一 d 下只需保留最大值，因为和要最大，配对时对方固定，自己越大越好。

```python
best = [-1] * 10
ans = -1
for x in nums:
    d = max(int(c) for c in str(x))
    if best[d] != -1:
        ans = max(ans, best[d] + x)
    best[d] = max(best[d], x)
return ans
```

注意 `best[d] = max(best[d], x)` 必须在配对之后，否则同一个 x 会和自己配对（虽然本题要求 i≠j，但先配对后更新天然避免）。

## 复杂度
时间 O(n·k)，k 是数字位数（≤5），即 O(n)。
空间 O(1)，只开了长度 10 的 `best` 数组。

## 易错点
- 输入 `[1,2,3,4]` → 若把 `ans` 初始化为 0，会返回 0 而非 -1 → 初始值必须是 -1，且只有真正配成对才更新。
- 输入 `[10,10]` → 若先更新 `best[d]` 再配对，会让同一个 10 和自己相加得 20 → 必须先查 `best[d]` 配对、再更新 `best[d]`，正确结果是 20（两个不同的 10）。

## 如果面试官追问
问：要求返回具体下标对而不只是和？
答：`best` 存 `(最大值, 下标)` 二元组，配对时同时记下两个下标即可。
