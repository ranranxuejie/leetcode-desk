## 一句话思路
对每个连通分量数顶点数 `k` 和内部边数 `e`，判 `e == k*(k-1)//2` 即完全。

## 怎么做
1. 用并查集把 `edges` 里的点合并，得到每个分量的根。
2. 遍历 `0..n-1`，统计每个根的顶点数 `size[root]`。
3. 遍历 `edges`，把每条边记到它端点所属根的 `edge_cnt[root]` 上。
4. 对每个根 `r`，若 `edge_cnt[r] == size[r]*(size[r]-1)//2` 则答案加一。

以示例 2 为例：`n=6, edges=[[0,1],[0,2],[1,2],[3,4],[3,5]]`。合并后根为 0 的分量 `size[0]=3`、`edge_cnt[0]=3`，`3 == 3*2//2` 成立；根为 3 的分量 `size[3]=3`、`edge_cnt[3]=2`，`2 != 3` 不成立。孤立点 5 之外没有别的点，答案 1。

```python
parent = list(range(n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
for a, b in edges:
    parent[find(a)] = find(b)
size = [0] * n
edge_cnt = [0] * n
for v in range(n):
    size[find(v)] += 1
for a, b in edges:
    edge_cnt[find(a)] += 1
ans = sum(1 for r in range(n) if find(r) == r and edge_cnt[r] == size[r] * (size[r] - 1) // 2)
```

## 复杂度
时间：`O((n + m) α(n))`，`m = len(edges)`，并查集近似常数。
空间：`O(n)`，`parent`、`size`、`edge_cnt` 三个长度 n 的数组。

## 易错点
- 统计 `edge_cnt` 时用 `find(a)` 而非 `a`：若写成 `edge_cnt[a] += 1`，示例 2 中边 `[1,2]` 会记到节点 1 上，根 0 只拿到 2 条边，`2 != 3`，把完全分量误判成非完全，答案错成 0。
- 孤立点（`edges` 中不出现的顶点）必须计入：`size[r]=1, edge_cnt[r]=0`，`0 == 1*0//2` 成立，应算一个完全分量。若只遍历 `edges` 里的点，示例 1 中 `n=6` 但只出现 0..4，会漏掉顶点 5，答案从 3 错成 2。

## 如果面试官追问
若 `n` 放大到 `10^5` 且要求输出每个完全分量的顶点列表，怎么改？答：并查集不变，额外用字典把根映射到顶点列表，判完全后直接输出该列表。
