## 一句话思路
用最大堆每次取两块最重的相减，差值非零就塞回堆，堆空或剩一块即为答案。

## 怎么做
1. 把 `stones` 全部取负压入 `heapq`，Python 只有最小堆，取负即得最大堆。
2. 循环条件 `while len(heap) > 1`，每次 `heappop` 两次得到 `a`、`b`（都是负数）。
3. 若 `a != b`，把 `a - b`（负数差，等价于 `-(|a|-|b|)`）`heappush` 回去。
4. 循环结束返回 `-heap[0]`，堆空则返回 0。

以 `[2,7,4,1,8,1]` 为例：堆顶弹出 `-8`、`-7`，`a - b = -8 - (-7) = -1`，压回 `-1`，此时堆内是 `[-4,-2,-1,-1,-1]`。下一轮弹出 `-4`、`-2`，差 `-2` 压回，堆变 `[-2,-1,-1,-1]`。继续到弹出 `-1`、`-1` 时 `a == b`，不压回，堆剩 `[-1]`，返回 `-(-1) = 1`。

```python
import heapq

def lastStoneWeight(stones):
    heap = [-s for s in stones]
    heapq.heapify(heap)
    while len(heap) > 1:
        a = heapq.heappop(heap)
        b = heapq.heappop(heap)
        if a != b:
            heapq.heappush(heap, a - b)
    return -heap[0] if heap else 0
```

关键点：`a - b` 直接就是负数，不用再取负；`a == b` 时两块都消失，绝不能 push 0，否则堆里多出一个假石头，最后返回 0 却让循环多跑一轮。

## 复杂度
时间 O(n log n)：n 块石头建堆 O(n)，每轮两次 pop 一次 push 各 O(log n)，最多 n 轮。
空间 O(n)：额外开了一个长度 n 的 `heap` 列表。

## 易错点
- 输入 `[1,1]` → 若写成 `heappush(heap, a - b)` 不判等，会压入 `0`，堆变 `[0]`，返回 `-0 = 0` 结果碰巧对，但输入 `[1,1,1]` 时先消掉两个 1 压入 0，再拿 0 和 1 比，返回 1 而正确答案是 1——看似对，实际多了一次无意义粉碎；正确做法是 `a != b` 才 push。
- 输入 `[2,2]` → 若用 `max(stones)` 加 `list.remove` 模拟，每次 remove 是 O(n) 且要删两次，容易删错下标；正确做法是用堆，pop 天然取走堆顶。

## 如果面试官追问
问：石头数量到 10^5、重量到 10^9 还成立吗？
答：成立，堆操作 O(log n)，重量只参与减法，Python 整数无溢出，总时间仍是 O(n log n)。
