## 一句话思路
枚举两条对角线，用「中点相同 + 长度相同」判定矩形，面积由两条对角线叉积的一半给出。

## 怎么做
1. 把 `points` 转成集合 `S`，便于 O(1) 判断某个坐标是否存在。
2. 双重循环枚举所有点对 `(i, j)`，把 `i, j` 当作矩形的一条对角线，算出中点 `(x1+x2, y1+y2)`（用两倍坐标避免浮点）和长度平方 `d = (x1-x2)**2 + (y1-y2)**2`。
3. 用 `(中点, d)` 作哈希键，把同键的对角线分组；同组内任意两条对角线共享中点且等长，即构成矩形。
4. 对组内两条对角线 `(a,b)` 与 `(c,d)`，面积 = `|ac × ad|`，即 `abs((cx-ax)*(dy-ay) - (cy-ay)*(dx-ax))`，取全局最小。

以示例 1 的 `[[1,2],[2,1],[1,0],[0,1]]` 为例：对角线 `(1,2)-(1,0)` 中点两倍为 `(2,2)`、`d=4`；对角线 `(2,1)-(0,1)` 中点两倍也是 `(2,2)`、`d=4`，同键命中。取 `a=(1,2), c=(2,1), d=(0,1)`，叉积 `(1)*(-1) - (-1)*(-2) = -1-2 = -3`，绝对值 3？注意这里应取相邻顶点，实际用 `a=(1,2)` 与 `c=(2,1)`、`d=(0,1)` 算得面积 2（`|1*(-1)-(-1)*(-2)|` 需按相邻边向量重算，代码里用 `a` 到 `c`、`a` 到 `d` 的叉积，示例结果为 2）。

```python
S = set(map(tuple, points))
groups = {}
for i in range(len(points)):
    for j in range(i+1, len(points)):
        x1,y1 = points[i]; x2,y2 = points[j]
        key = (x1+x2, y1+y2, (x1-x2)**2+(y1-y2)**2)
        groups.setdefault(key, []).append((points[i], points[j]))
ans = float('inf')
for diags in groups.values():
    for p in range(len(diags)):
        for q in range(p+1, len(diags)):
            a = diags[p][0]; c = diags[q][0]; d = diags[q][1]
            area = abs((c[0]-a[0])*(d[1]-a[1]) - (c[1]-a[1])*(d[0]-a[0]))
            if area: ans = min(ans, area)
return 0.0 if ans == float('inf') else ans
```

## 复杂度
时间：O(n²) 枚举点对建组，组内配对最坏 O(n⁴)，n≤50 可过。
空间：O(n²) 存哈希表，键为 `(中点, 长度平方)`。

## 易错点
- 用浮点中点做键：`(x1+x2)/2` 在坐标 4e4 下可能因精度把不同中点判等，导致把非矩形当矩形；正确做法是用两倍坐标 `x1+x2` 作整数键。
- 组内配对时把同一条对角线的两个端点顺序搞混：`diags[q]` 存的是 `(c,d)`，若误用 `diags[p][1]` 当 `a`，叉积算出的不是相邻边而是同一条线，面积恒为 0 被跳过，漏掉真实矩形；正确做法固定取 `diags[p][0]` 作公共顶点。

## 如果面试官追问
问：若 points 规模升到 2000 怎么办？答：O(n²) 建组后组内配对会爆，改用「枚举一条边 + 查另外两点是否存在」的 O(n²·n) 或按斜率分组剪枝。
