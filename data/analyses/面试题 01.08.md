## 一句话思路
用第一行和第一列当标记位，先记录首行首列自身是否含零，再原地标记、最后统一清零。

## 怎么做
1. 先扫第一行和第一列，用 `row0`、`col0` 两个布尔量记住它们本身有没有 0。
2. 从 `matrix[1][1]` 开始扫，遇到 `matrix[i][j] == 0` 就把 `matrix[i][0]` 和 `matrix[0][j]` 置 0，作为标记。
3. 再扫一遍 `i,j >= 1`，若 `matrix[i][0] == 0 or matrix[0][j] == 0` 就把 `matrix[i][j]` 置 0。
4. 最后按 `row0`、`col0` 决定是否清空第一行、第一列。

以示例 2 为例，`matrix[0][0]` 和 `matrix[0][3]` 是 0，所以 `row0 = True`；第一列 `matrix[0][0]` 为 0，`col0 = True`。内层扫描时 `matrix[1][0]`、`matrix[1][3]` 被置 0，第二遍据此把第 1 行第 0、3 列清零，最终得到 `[0,4,5,0]`。

```python
row0 = any(matrix[0][j] == 0 for j in range(n))
col0 = any(matrix[i][0] == 0 for i in range(m))
for i in range(1, m):
    for j in range(1, n):
        if matrix[i][j] == 0:
            matrix[i][0] = matrix[0][j] = 0
for i in range(1, m):
    for j in range(1, n):
        if matrix[i][0] == 0 or matrix[0][j] == 0:
            matrix[i][j] = 0
if row0:
    for j in range(n): matrix[0][j] = 0
if col0:
    for i in range(m): matrix[i][0] = 0
```

## 复杂度
时间 O(m·n)：两遍全矩阵扫描，`m` 行 `n` 列各贡献一次。
空间 O(1)：只多了 `row0`、`col0` 两个布尔量，没有额外数组。

## 易错点
- 输入 `[[1,0],[0,1]]` → 若先清第一行再扫内层，`matrix[0][1]` 的标记已被抹掉，导致第 1 列漏清 → 正确做法是先完成全部标记再统一清零，或像上面代码先记 `row0/col0` 再动首行首列。
- 输入 `[[0]]`（单元素）→ 若循环从 `range(1, m)` 开始且忘了 `row0/col0`，矩阵不变 → 正确做法是首行首列单独判断，`row0` 为 `True` 时清空第一行。

## 如果面试官追问
问：不允许修改原矩阵标记位怎么办？
答：用两个长度 `m`、`n` 的布尔数组记录哪行哪列有 0，空间 O(m+n)，逻辑不变。
