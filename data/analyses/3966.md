## 一句话思路
数位 DP 逐位填数并记录上一位，用 `f(r) - f(l-1)` 求区间答案。

## 怎么做
1. 把上界 `x` 转成字符串 `s`，定义 `dfs(pos, prev, tight, started)`，`prev` 是上一位数字（未开始时记 `-1`）。
2. `started=False` 时跳过前导零，不校验差值；一旦开始，每位 `d` 需满足 `abs(d - prev) <= k`。
3. `tight` 为真时当前位只能到 `int(s[pos])`，否则到 9；`pos == len(s)` 且 `started` 返回 1。
4. 用 `(pos, prev, tight, started)` 做记忆化，`prev` 取 `-1..9` 共 11 种。

以 `l=10, r=15, k=1` 算 `f(15)`：首位 `d=1` 开始，`prev=1`；第二位 `tight` 下试 `d=0..5`，`abs(d-1)<=1` 只放行 `0,1,2`，得 10、11、12 三个，`f(15)=3`；`f(9)=0`（一位数无相邻对，但 `10..15` 之外不计），答案 `3-0=3`。

```python
from functools import lru_cache

def count(x):
    if x < 0:
        return 0
    s = str(x)
    @lru_cache(maxsize=None)
    def dfs(pos, prev, tight, started):
        if pos == len(s):
            return 1 if started else 0
        hi = int(s[pos]) if tight else 9
        total = 0
        for d in range(hi + 1):
            nt = tight and d == hi
            if not started and d == 0:
                total += dfs(pos + 1, -1, nt, False)
            elif not started or abs(d - prev) <= k:
                total += dfs(pos + 1, d, nt, True)
        return total
    return dfs(0, -1, True, False)

return count(r) - count(l - 1)
```

## 复杂度
时间：`O(位数 × 11 × 2 × 2 × 10)`，位数即 `log10(r) ≤ 16`。
空间：记忆化表同规模，约 `16 × 11 × 4` 个状态。

## 易错点
- `k=0` 且区间含 `10`：若漏掉 `started` 判断，前导零会被当成真实数位，`abs(1-0)=1>0` 把 10 误判为坏数；正确做法是未开始时直接下传 `prev=-1` 不校验。
- `l=10` 时算 `f(l-1)=f(9)`：若把一位数也当「无相邻对即好数」返回 9，`f(9)` 应为 9 而非 0，但 `f(15)-f(9)` 仍得 3；真正翻车点是 `l=1` 时 `f(0)` 必须返回 0，否则多算。

## 如果面试官追问
问：`r` 放大到 `10^100` 怎么办？
答：字符串长度变 100，状态数线性增长，记忆化 DP 仍 `O(100×11×4×10)`，无需改结构。
