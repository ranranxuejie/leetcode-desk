## 一句话思路
从右上角出发，利用「左小下大」的单调性，每步排除一行或一列，最多 m+n 步。

## 怎么做
1. 设 `i = 0`（行）、`j = n - 1`（列），从右上角 `plants[0][n-1]` 起步。
2. 若 `plants[i][j] == target` 直接返回 `True`。
3. 若 `plants[i][j] > target`，说明这一列下方都不小于它，整列排除，`j -= 1`。
4. 若 `plants[i][j] < target`，说明这一行左侧都不大于它，整行排除，`i += 1`。
5. 越界（`i == m` 或 `j < 0`）则返回 `False`。

用示例 1：`plants = [[2,3,6,8],[4,5,8,9],[5,9,10,12]]`，`target = 8`。起点 `plants[0][3] = 8`，第一步就命中，返回 `True`。若 `target = 7`：起点 8 > 7，`j` 变 2，`plants[0][2] = 6 < 7`，`i` 变 1；`plants[1][2] = 8 > 7`，`j` 变 1；`plants[1][1] = 5 < 7`，`i` 变 2；`plants[2][1] = 9 > 7`，`j` 变 0；`plants[2][0] = 5 < 7`，`i` 变 3 越界，返回 `False`。

```python
m, n = len(plants), len(plants[0]) if plants else 0
i, j = 0, n - 1
while i < m and j >= 0:
    cur = plants[i][j]
    if cur == target:
        return True
    if cur > target:
        j -= 1
    else:
        i += 1
return False
```

关键点：起点必须选**右上角**或**左下角**。左上角 `plants[0][0]` 的右和下都更大，`target` 比它大时无法判断该往哪走；右上角则「左小下大」，两个方向含义相反，才能二选一。

## 复杂度
时间：O(m + n)，`i` 只增、`j` 只减，合计最多 m+n 步。
空间：O(1)，只用了 `i`、`j`、`cur` 三个变量。

## 易错点
- 输入 `plants = []` 或 `plants = [[]]` → 直接写 `n = len(plants[0])` 会抛 `IndexError` → 先判空，用 `n = len(plants[0]) if plants else 0`，此时 `j = -1` 循环不进入，返回 `False`。
- 从左上角 `plants[0][0]` 起步 → 遇到 `target = 7`、`plants[0][0] = 2` 时，右和下都可能是 7，无法决定方向，会漏解 → 必须从右上角或左下角起步，本题代码固定用右上角。

## 如果面试官追问
问：如果矩阵只保证每行有序、列无序，还能 O(m+n) 吗？
答：不能，退化成对每行二分，O(m log n)。
