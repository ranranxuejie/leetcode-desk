## 一句话思路
一次遍历，用 `cur` 记录以当前元素结尾的连续递增段长度，遇到 `nums[i] <= nums[i-1]` 就重置为 1，全程维护最大值。

## 怎么做
1. 初始化 `cur = 1`、`best = 1`，从下标 1 开始扫描。
2. 若 `nums[i] > nums[i-1]`，则 `cur += 1`；否则 `cur = 1`。
3. 每步用 `best = max(best, cur)` 更新答案，最后返回 `best`。

以 `nums = [1,3,5,4,7]` 为例：i=1 时 3>1，`cur` 从 1 变 2；i=2 时 5>3，`cur` 变 3，`best` 变 3；i=3 时 4<5，`cur` 重置为 1；i=4 时 7>4，`cur` 变 2，`best` 仍为 3。

```python
cur = best = 1
for i in range(1, len(nums)):
    if nums[i] > nums[i - 1]:
        cur += 1
    else:
        cur = 1
    best = max(best, cur)
return best
```

关键点：`cur` 的含义是「以 i 结尾」的段长，所以断点处必须重置为 1 而不是 0——`[2,2,2,2,2]` 里每个 2 自身就是长度 1 的序列。

## 复杂度
时间：O(n)，一次遍历，每个元素比较一次。
空间：O(1)，只开了 `cur`、`best`、`i` 三个变量。

## 易错点
- 输入 `[2,2,2,2,2]` → 若把重置写成 `cur = 0`，返回 0；正确是 `cur = 1`，因为单个元素也算长度 1 的递增序列，答案应为 1。
- 输入 `[1,3,5,4,7]` → 若只更新 `cur` 忘了 `best = max(best, cur)`，会返回最后一段的长度 2；正确是在每步都取最大值，得到 3。

## 如果面试官追问
要求返回该序列本身而非长度？答：额外记 `start`，在 `cur` 刷新 `best` 时同步记下 `i - cur + 1`，最后切片 `nums[start:start+best]`。
