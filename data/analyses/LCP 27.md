## 一句话思路
把 2(m+n) 个孔按「斜率为 ±1 的光线」分成两组编号，反射等价于在这组编号上循环走，用有序集合找下一个开着的孔。

## 怎么做
1. 给每个孔算两个「对角线编号」：沿 y=x 走时孔所在的斜线号 `a = (x+y) mod 2` 之类不成立，正确做法是把孔映射到两条反射轨道上，轨道长度分别是 `2*(m+n)` 的约数；本题标准做法是直接模拟「展开」：把矩形按镜面不断翻折，光线变成直线，孔变成周期点。
2. 关键化简：光线在盒内永远沿 ±45°，碰到边界只改变一个分量符号，所以孔序列是确定的环。对每个孔预计算它在 `dir=1` 和 `dir=-1` 两条环上的后继，环长 ≤ `2*(m+n)`。
3. 用两个有序集合（`sortedcontainers` 或手写并查集「下一个开着的孔」）维护每条环上开着的孔，`open` 时插入，`close` 时删除。
4. 查询时在环上从起点往后找第一个开着的孔即为出口；若起点自己就是唯一开着的孔，则原路返回自身。

以示例 1 的 `open(4,-1)`（n=2,m=3）为例：4 号孔在 `dir=-1` 环上的序列是 `4→2→8→2→4`，环上开着的孔只有 4，所以后继绕一圈回到 4，输出 4。

```python
# 环上「下一个开着的孔」用并查集维护，删除即 union 到后继
def find(nxt, i):
    while nxt[i] != i:
        nxt[i] = nxt[nxt[i]]
        i = nxt[i]
    return i

# open 时把 i 从环上摘掉：nxt[i] = find(nxt, (i+1) % L)
# 查询：j = find(nxt, start)；若 j == start 说明绕回自身
```

## 复杂度
时间：每次操作 O(α(L))，L = 2(m+n)，并查集近似常数；预处理 O(L)。
空间：两个环各开 O(L) 的 `nxt` 数组，共 O(m+n)。

## 易错点
- 拐角孔（如 0 号）只允许一种入射方向，若按普通孔处理 `dir` 会算出环外下标 → 越界或错环 → 正确做法是拐角处强制把 `direction` 归一到题面允许的那个值再查。
- 起点孔自己开着且是环上唯一开着的孔时，光线原路反射回自身 → 若直接取「严格后继」会返回别的孔或死循环 → 正确做法是先 `find(start)`，等于 `start` 就输出 `start`。

## 如果面试官追问
若 n,m 放大到 1e9 但操作仍 1e4，怎么办？
答：不预建整环，只对出现过的孔按模 L 排序，用平衡树存这些稀疏点，查询时在模 L 意义下找后继。
