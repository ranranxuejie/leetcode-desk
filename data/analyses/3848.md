## 一句话思路
枚举 n 的每个排列不现实，改为枚举 0-9 各数字出现次数，用阶乘和反推数字本身再比对位数。

## 怎么做
1. 预处理 `fact[0..9]`，`fact[0]=1`，其余 `fact[i]=fact[i-1]*i`。
2. 统计 n 的位数 `L` 和每个数字 `d` 的出现次数 `cnt[d]`。
3. 枚举所有长度为 L 的数字多重集（即 `cnt` 的排列），对每个多重集算 `S = sum(fact[d]*c[d])`。
4. 若 `S` 的位数恰为 L、其数字计数与 `c` 完全一致、且首位非 0，则返回 `True`。

关键中间值：以 `n=145` 为例，`L=3`，`cnt={1:1,4:1,5:1}`。取 `c={1:1,4:1,5:1}` 时 `S=1!+4!+5!=1+24+120=145`，`S` 的计数也是 `{1:1,4:1,5:1}`，匹配成功。

```python
fact = [1]*10
for i in range(1,10): fact[i] = fact[i-1]*i

def check(c, L):
    S = sum(fact[d]*c[d] for d in range(10))
    if S < 10**(L-1) or S >= 10**L: return False
    t = [0]*10
    for ch in str(S): t[int(ch)] += 1
    return t == c

# 枚举 c 的递归骨架
def dfs(d, rem, c):
    if d == 10:
        if rem == 0 and check(c, L): return True
        return False
    for k in range(rem+1):
        c[d] = k
        if dfs(d+1, rem-k, c): return True
    c[d] = 0
    return False
```

## 复杂度
时间：枚举多重集约 `C(L+9,9)` 种，每种 O(10)，L≤10 时约几万次。
空间：`fact`、`cnt`、`c` 各长 10，递归深度 10，O(1)。

## 易错点
- 输入 `n=10`：若只算 `1!+0!=2` 就判 `2` 是否等于 `10`，会漏掉「排列」语义而错判；正确做法是枚举多重集后检查 `S` 的数字计数是否与 `c` 一致，`10` 的计数 `{1:1,0:1}` 反推 `S=2` 位数不符，返回 `False`。
- 输入含 0 的多重集如 `n=100`：若允许 `S` 首位为 0 的排列参与匹配，会把 `001` 之类当合法；正确做法是 `check` 里用 `S >= 10**(L-1)` 强制首位非 0，`100` 的 `S=1!+0!+0!=3` 位数不足直接排除。

## 如果面试官追问
问：若 n 上限提到 10^18 怎么办？
答：位数 L 变大，多重集枚举 `C(L+9,9)` 爆炸，需改为按阶乘和的值域剪枝或直接枚举 0-9 计数组合并验证，不能全枚举。
