## 一句话思路
用区间 DP：第 i 步后已取走 i 个元素，只需记录「从左边取了多少个」，右端位置由 i 推出。

## 怎么做
1. 定义 `dp[j]` = 执行完前 i 步、其中 j 步取左端时的最大分数，则右端已取 `i - j` 个。
2. 第 i+1 步（下标 i）取左端：`nums[j] * multipliers[i]`；取右端：`nums[n - 1 - (i - j)] * multipliers[i]`。
3. 用滚动数组从后往前更新 j，避免覆盖本层还要用的值。
4. 答案取 `max(dp)`。

以示例 2 为例，`n=6, m=5`。i=0 时 `dp[0]=0`，取左得 `-5*-10=50`，取右得 `1*-10=-10`，故 `dp[1]=50, dp[0]=-10`。i=1 时从 `dp[1]=50` 取左 `-3*-5=15` 得 `dp[2]=65`，从 `dp[0]=-10` 取右 `7*-5=-35` 得 `dp[0]=-45`。最终最优路径在 i=4 时落在 `dp[2]=102`。

```python
n, m = len(nums), len(multipliers)
NEG = -10**18
dp = [NEG] * (m + 1)
dp[0] = 0
for i in range(m):
    for j in range(i, -1, -1):
        if dp[j] == NEG:
            continue
        # 取左端
        dp[j + 1] = max(dp[j + 1], dp[j] + nums[j] * multipliers[i])
        # 取右端
        dp[j] = max(dp[j], dp[j] + nums[n - 1 - (i - j)] * multipliers[i])
return max(dp)
```

## 复杂度
时间：O(m²)，两层循环各 m 次，与 n 无关。
空间：O(m)，只开一个长度 m+1 的滚动数组 dp。

## 易错点
- `nums` 有 10^5 个但只用 m 步 → 若按 n 开二维 `dp[n][m]` 会 MLE；正确做法是只按已取步数 i 和左取数 j 建 O(m²) 状态，右端下标用 `n-1-(i-j)` 现算。
- 滚动数组若 j 从 0 正向遍历 → `dp[j+1]` 被本层刚更新的值污染，等价于同一元素取两次；必须 `range(i, -1, -1)` 倒序，且 `dp[j]` 的右端转移要用更新前的旧值（先算 `dp[j+1]` 再算 `dp[j]`）。

## 如果面试官追问
问：要求输出具体取数方案怎么办？
答：额外开 `choice[i][j]` 记录每步取左还是取右，最后从 `max(dp)` 的终点回溯。
