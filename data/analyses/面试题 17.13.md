## 一句话思路
用 `dp[i]` 表示 `sentence` 前 i 个字符的最少未识别数，从每个 i 向后枚举所有词典词，能匹配就转移。

## 怎么做
1. 建字典树：把 `dictionary` 全部插入 trie，节点用 `dict` 存子节点，词尾打 `end` 标记。
2. 定义 `dp[i]` 为前 i 个字符的最少未识别字符数，`dp[0] = 0`，其余初始化为 `i`（全当未识别）。
3. 对每个 i，先令 `dp[i+1] = min(dp[i+1], dp[i] + 1)`（第 i 个字符未识别），再从 i 出发沿 trie 走 `sentence[i:]`，每走到一个 `end` 节点就更新 `dp[j] = min(dp[j], dp[i])`。
4. 返回 `dp[n]`。

用官方示例：`sentence = "jesslookedjustliketimherbrother"`，走到 i=4 时 trie 能匹配 `"looked"`（j=10），于是 `dp[10] = min(dp[10], dp[4]) = 4`；而 `dp[4]` 来自前 4 个字符 `"jess"` 全未识别，即 4。最终 `dp[30] = 7`。

```python
n = len(sentence)
dp = list(range(n + 1))
for i in range(n):
    dp[i + 1] = min(dp[i + 1], dp[i] + 1)
    node = root
    j = i
    while j < n and sentence[j] in node:
        node = node[sentence[j]]
        j += 1
        if node.get('end'):
            dp[j] = min(dp[j], dp[i])
return dp[n]
```

关键点：`dp[i+1]` 的「+1 未识别」必须在枚举匹配之前或之后都行，但 `dp[i]` 必须是已定稿的最小值，所以外层按 i 递增即可。

## 复杂度
时间 O(n·L + 词典总字符)，L 为最长词长，n = len(sentence)。
空间 O(词典总字符 + n)，trie 节点数加 dp 数组。

## 易错点
- `sentence` 为空串（n=0）→ 若循环写成 `for i in range(1, n+1)` 且没处理 `dp[0]`，会返回错误值或越界 → 直接返回 `dp[0]` 即 0，初始化 `dp = list(range(n+1))` 天然覆盖。
- 词典里有词是另一个词的前缀（如 `["her","herbrother"]`）→ 若匹配到第一个 `end` 就 break，会漏掉更长的 `"herbrother"` 带来的更优 `dp[j]` → 必须继续沿 trie 往下走，每个 `end` 都更新一次 `dp[j]`。

## 如果面试官追问
要求输出具体断句方案而非只返回数字？答：在 `dp` 转移时额外记录 `pre[j] = i` 和是否走了词，最后从 n 回溯即可。
