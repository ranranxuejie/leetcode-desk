## 一句话思路
把 word1+word2 拼成 s，求 s 上「跨越拼接点」的最长回文子序列，用区间 DP。

## 怎么做
1. 令 s = word1 + word2，n1 = len(word1)，在 s 上做区间 DP：`dp[i][j]` 表示 s[i..j] 的最长回文子序列长度。
2. 转移：`s[i]==s[j]` 时 `dp[i][j] = dp[i+1][j-1] + 2`，否则 `max(dp[i+1][j], dp[i][j-1])`。
3. 关键约束：回文必须同时用到 word1 和 word2 的字符，即左端点 i < n1 且右端点 j >= n1 时才更新答案。
4. 按区间长度从 2 到 n 递推，`dp[i][i] = 1`。

以示例 1 为例：s = "cacbcbba"，n1 = 4。当 i=0（'c'）、j=7（'a'）不匹配，取 `max(dp[1][7], dp[0][6])`；真正贡献答案的是 i=1（'a'）、j=6（'b'）不匹配后落到 i=1、j=5 的 'a'…'a' 匹配，`dp[1][5] = dp[2][4] + 2`，最终 dp[1][5] = 5，且 1 < 4 <= 5，答案取 5。

```python
s = word1 + word2
n, n1 = len(s), len(word1)
dp = [[0] * n for _ in range(n)]
ans = 0
for i in range(n):
    dp[i][i] = 1
for length in range(2, n + 1):
    for i in range(n - length + 1):
        j = i + length - 1
        if s[i] == s[j]:
            dp[i][j] = dp[i + 1][j - 1] + 2 if length > 2 else 2
        else:
            dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
        if i < n1 <= j:
            ans = max(ans, dp[i][j])
return ans
```

## 复杂度
时间 O(n²)，n = len(word1)+len(word2)，两层区间枚举。
空间 O(n²)，开了 n×n 的 dp 表。

## 易错点
- 输入 word1="aa"、word2="bb" → 若不加 `i < n1 <= j` 判断，会把 word1 内部的 "aa" 当成答案返回 2 → 必须只在区间跨越拼接点时更新 ans，正确返回 0。
- 输入 word1="a"、word2="a" → 若把 `dp[i][i]=1` 的单字符区间也算进答案，会漏掉跨界的 "aa"=2，或反过来把单侧字符算成答案 → 单字符区间不满足 i<n1<=j，答案只能来自长度 ≥2 的跨界区间，正确返回 2。

## 如果面试官追问
要求输出具体回文串而非长度？答：在 dp 表上从 (0, n-1) 回溯，匹配时两端各取一字符，不匹配时走向较大的子区间，拼接后即得。
