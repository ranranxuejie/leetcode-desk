## 一句话思路
先算总分 `total`，再从左往右累加 `left`，只要某个 `i` 满足 `left == total - left` 就返回 `True`。

## 怎么做
1. 用 `sum(ord(c) - 96 for c in s)` 求出整串得分 `total`。
2. 令 `left = 0`，从 `i = 0` 遍历到 `n - 2`（右段必须非空，所以不能走到最后一个字符）。
3. 每步把 `ord(s[i]) - 96` 累加进 `left`，然后判断 `left * 2 == total`。
4. 命中就返回 `True`，循环结束返回 `False`。

以 `s = "adcb"` 为例：`total = 1 + 4 + 3 + 2 = 10`。`i = 0` 时 `left = 1`，`1 * 2 != 10`；`i = 1` 时 `left = 1 + 4 = 5`，`5 * 2 == 10`，返回 `True`，此时右段 `"cb"` 得分正好也是 5。

```python
total = sum(ord(c) - 96 for c in s)
left = 0
for i in range(len(s) - 1):
    left += ord(s[i]) - 96
    if left * 2 == total:
        return True
return False
```

关键点：用 `left * 2 == total` 而不是 `left == total - left`，省一次减法，也避免把 `total` 写错成右段得分。

## 复杂度
时间：O(n)，一次求 `total` 加一次遍历，`n = len(s)`。
空间：O(1)，只开了 `total`、`left`、`i` 三个标量。

## 易错点
- 输入 `s = "aa"` → 若循环写成 `range(len(s))`，`i = 1` 时 `left = 2`，右段为空却可能被误判 → 正确做法是循环上界取 `len(s) - 1`，保证右段非空。
- 输入 `s = "ab"` → 若把 `ord(c) - 96` 写成 `ord(c) - ord('a')`，`"ab"` 会算成 `0 + 1 = 1`，`left` 永远对不上 `total` → 正确做法是减 96（即 `'a'` 的 ASCII 值），让 `'a'` 得 1。

## 如果面试官追问
问：如果要求返回所有可行的拆分下标？
答：把 `return True` 换成 `res.append(i)`，循环结束后返回 `res`，时间仍是 O(n)。
