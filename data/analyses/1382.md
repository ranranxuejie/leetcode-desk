## 一句话思路
中序遍历拿到升序数组，再每次取中点递归建树，天然保证左右子树高度差不超过 1。

## 怎么做
1. 中序遍历原 BST，把节点值按升序存进 `vals`。
2. 写 `build(lo, hi)`：`lo > hi` 返回 `None`，否则取 `mid = (lo + hi) // 2` 建根。
3. 递归 `build(lo, mid - 1)` 和 `build(mid + 1, hi)` 挂到左右。
4. 返回 `build(0, len(vals) - 1)`。

以示例 1 的链 `1→2→3→4` 为例，中序得 `vals = [1,2,3,4]`，`lo=0, hi=3`，`mid=1`，根取 `vals[1]=2`；左区间 `[0,0]` 得 `1`，右区间 `[2,3]` 的 `mid=2` 得 `3`，其右子 `4`。结果 `[2,1,3,null,null,null,4]`，与官方输出一致。

```python
def inorder(node):
    if not node:
        return
    inorder(node.left)
    vals.append(node.val)
    inorder(node.right)

def build(lo, hi):
    if lo > hi:
        return None
    mid = (lo + hi) // 2
    node = TreeNode(vals[mid])
    node.left = build(lo, mid - 1)
    node.right = build(mid + 1, hi)
    return node
```

关键点：`mid` 用下取整，偶数长度时根偏左，这仍满足平衡，不必纠结取哪个中点。

## 复杂度
时间 O(n)：中序遍历访问每个节点一次，建树每个 `vals` 元素建一个节点。
空间 O(n)：`vals` 存 n 个值，递归栈 O(log n)，合计 O(n)。

## 易错点
- 输入是示例 1 那种右斜链 `[1,null,2,null,3,null,4]` → 若直接在原树上做旋转或试图原地调整，容易漏掉深层节点或破坏 BST 性质 → 正确做法是先中序拍平成 `vals`，再从中点重建，完全绕开旋转。
- 节点数到 10^4 的链 → 若用递归中序遍历，Python 默认递归深度约 1000，会 `RecursionError` → 正确做法是把中序改成显式栈迭代，或 `sys.setrecursionlimit(20000)`；建树递归深度只有 O(log n)，不受影响。

## 如果面试官追问
问：不额外开 `vals` 数组，能否 O(1) 额外空间完成？
答：可以，先用 Day-Stout-Warren 把树原地转成 vine，再按中点数自底向上重建，时间仍 O(n)。
