## 一句话思路
前 n 位逐位对齐的代价固定，只需在 nums2 末尾那个多出的元素上选一个 nums1 原值追加，取最小。

## 怎么做
1. 先算 `base = sum(abs(nums1[i] - nums2[i]) for i in range(n))`，这是前 n 位必须付的代价。
2. 多出的 `nums2[n]` 只能靠「追加某个 nums1[i] 再改成它」得到，代价是 `1 + abs(nums1[i] - nums2[n])`。
3. 取所有 i 里最小的那个，加到 base 上返回。

以示例 1 为例：`nums1 = [2,8]`，`nums2 = [1,7,3]`，`base = |2-1| + |8-7| = 1 + 1 = 2`。追加项 `nums2[2] = 3`，对 i=0 代价 `1 + |2-3| = 2`，对 i=1 代价 `1 + |8-3| = 6`，取 2，答案 `2 + 2 = 4`。

```python
n = len(nums1)
base = 0
for i in range(n):
    base += abs(nums1[i] - nums2[i])
extra = min(1 + abs(nums1[i] - nums2[n]) for i in range(n))
return base + extra
```

注意 `extra` 里的 `1` 是追加操作本身，不能漏；`abs` 部分是把被追加的那个副本改成目标值。

## 复杂度
时间 O(n)：一次遍历算 base，一次遍历求 extra 最小值。
空间 O(1)：只用了 base、extra 两个标量。

## 易错点
- 误以为要追加 `nums2[n]` 本身：追加的是 `nums1[i]` 的副本，所以代价是 `1 + abs(nums1[i] - nums2[n])`，不是 `1`。示例 3 中 `nums1=[2]`、`nums2=[3,4]`，若漏掉 abs 会得 `1+1=2`，正确是 `1+|2-4|=3`。
- 只拿 `nums1[n-1]` 或某个固定位置去追加：示例 1 里若固定用 i=1，代价 `1+|8-3|=6`，答案变 8 而非 4。必须对全部 n 个下标取 min。

## 如果面试官追问
若要求输出具体操作方案？答：记录取到 min 的那个下标 i，先对前 n 位逐位加减，再追加 `nums1[i]` 并把它改成 `nums2[n]`。
