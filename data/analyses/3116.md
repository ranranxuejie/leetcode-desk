## 一句话思路
答案具有单调性，二分金额 x，用容斥统计 ≤x 的「某面额倍数」个数，凑够 k 即最小可行 x。

## 怎么做
1. 先对 coins 去重、去掉被其他面额整除的冗余项（如 [3,6,9] 中 6、9 都是 3 的倍数，只留 3）。
2. 对剩余 m 个面额枚举全部 2^m 个非空子集，预处理每个子集的 lcm 与符号 (-1)^(size+1)。
3. 二分 x ∈ [1, min(coins)*k]，用 count(x)=Σ sign*lcm 的 floor(x/lcm) 判断是否 ≥ k。
4. 取最小满足 count(x) ≥ k 的 x。

以 coins=[5,2], k=7 为例：无冗余，子集 lcm 为 5(+)、2(+)、10(-)。x=10 时 count=2+5-1=6<7；x=12 时 count=2+6-1=7≥7，故答案 12。

```python
from math import gcd
def count(x):
    s = 0
    for l, sg in subs:
        s += sg * (x // l)
    return s
lo, hi = 1, min(coins) * k
while lo < hi:
    mid = (lo + hi) // 2
    if count(mid) >= k: hi = mid
    else: lo = mid + 1
return lo
```

## 复杂度
时间：O(2^m · log(min(coins)·k))，m 为去冗余后面额数，二分 log 项。
空间：O(2^m) 存子集 lcm 与符号。

## 易错点
- 不去冗余直接枚举 15 个面额 → 2^15 子集里大量 lcm 重复且超界，count 变慢甚至 lcm 爆大；正确做法是先剔除被其他面额整除的项，[3,6,9] 只留 3。
- 二分上界取 k*max(coins) 或 2^31 → 可能漏解或越界；正确上界是 min(coins)*k，因为最小面额的倍数已能提供 k 个金额。

## 如果面试官追问
问：若 k 更大、coins 更多怎么办？答：仍用容斥二分，但需对 lcm 去重合并同值符号，控制子集规模。
