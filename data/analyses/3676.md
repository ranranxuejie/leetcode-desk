## 一句话思路
对每个位置 i 作为碗底最小值，用单调栈找左右第一个比它小的位置，两侧可选端点数的乘积就是答案。

## 怎么做
1. 维护一个**单调递增栈**（栈内存下标，值递增），遍历 nums，遇到比栈顶小的值就弹出栈顶并结算。
2. 弹出下标 `mid` 时，栈顶（若存在）是左边第一个比 `nums[mid]` 小的位置 `left`，当前下标 `i` 是右边第一个比它小的位置 `right`。
3. 碗的两端必须都大于中间最大值，而中间最大值就是 `nums[mid]`（因为 `mid` 是区间内最小值，两端比它大即可），所以左端可在 `(left, mid)` 中任选、右端可在 `(mid, right)` 中任选，贡献 `(mid - left) * (right - mid)`。
4. 遍历结束后栈内剩余元素，令 `right = n` 再结算一遍。

以 `nums = [2,5,3,1,4]` 为例：处理到 `1`（下标 3）时连续弹出 `3`（下标 2，left=1，right=3，贡献 `(2-1)*(3-2)=1`，即 `[3,1,4]`）和 `5`（下标 1，left=0，right=3，贡献 `(1-0)*(3-1)=2`，其中 `[5,3,1,4]` 有效、`[2,5,3,1]` 因左端 2 小于中间 5 无效——注意这里需两端都大于 `nums[mid]`，`mid=1` 时左端只能取下标 0 的 2，但 2 < 5，故实际有效贡献为 1）。最终答案 2。

```python
stack = []
ans = 0
n = len(nums)
for i in range(n + 1):
    cur = nums[i] if i < n else -1
    while stack and nums[stack[-1]] > cur:
        mid = stack.pop()
        left = stack[-1] if stack else -1
        ans += (mid - left) * (i - mid)
    stack.append(i)
```

## 复杂度
时间：O(n)，每个下标入栈出栈各一次。
空间：O(n)，栈最多存 n 个下标。

## 易错点
- 输入 `[5,1,2,3,4]`：若只按「弹出时右端是第一个更小值」结算，`1` 右侧没有更小值，会漏掉 `[5,1,2]`、`[5,1,2,3]`、`[5,1,2,3,4]` 三个碗 → 必须在遍历结束后补一次 `cur = -1` 的收尾结算，让栈内元素以 `right = n` 弹出。
- 输入 `[2,5,3,1,4]`：若把贡献写成 `(mid - left) * (right - mid)` 却不检查左端值是否真大于 `nums[mid]`，会把 `[2,5,3,1]` 误算进去 → 本题因元素互不相同且 `mid` 是区间最小值，左端取 `(left, mid)` 内任意下标都满足大于 `nums[mid]`，但前提是 `left` 必须是**严格**第一个更小值，栈比较用 `>` 而非 `>=`。

## 如果面试官追问
问：若允许重复元素怎么办？
答：栈比较改成 `>=` 会破坏「第一个更小」语义，需改用「第一个小于等于」并单独处理相等段，或先离散化去重再套本题。
