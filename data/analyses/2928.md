## 一句话思路
枚举第一个小朋友的糖果数 `a`，第二个 `b` 的范围由 `n - a - b <= limit` 直接夹出来，O(limit²) 枚举。

## 怎么做
1. 枚举 `a` 从 `0` 到 `min(limit, n)`，`b` 从 `0` 到 `min(limit, n - a)`。
2. 令 `c = n - a - b`，若 `0 <= c <= limit` 则计数加一。
3. 用 `n=5, limit=2` 走一遍：`a=1, b=2` 时 `c=2`，命中；`a=0, b=2` 时 `c=3 > limit`，跳过。

```python
ans = 0
for a in range(min(limit, n) + 1):
    for b in range(min(limit, n - a) + 1):
        c = n - a - b
        if 0 <= c <= limit:
            ans += 1
return ans
```

关键中间值：`a=1, b=2` 时 `c = 5 - 1 - 2 = 2`，落在 `[0, 2]` 内，计入；`a=0, b=2` 时 `c=3`，超出 `limit=2` 被丢弃。三个合法解 `(1,2,2)`、`(2,1,2)`、`(2,2,1)` 分别对应 `(a,b)=(1,2)`、`(2,1)`、`(2,2)`。

## 复杂度
时间：O(min(limit,n)²)，两层循环各贡献一个 `limit`。
空间：O(1)，只开了 `ans`、`a`、`b`、`c` 四个标量。

## 易错点
- `n=3, limit=3` 时若把 `b` 的上界写成 `limit` 而不是 `min(limit, n-a)`，会枚举出 `a=0,b=3,c=0` 之外的 `a=0,b=3` 已合法但 `a=3,b=3` 时 `c=-3`，必须靠 `c >= 0` 兜住，否则多算。
- `n=5, limit=2` 时若只判 `c <= limit` 忘了 `c >= 0`，`a=2,b=2` 会算出 `c=1` 合法，但 `a=2,b=3` 这类越界组合在 `b` 上界没夹紧时会算出 `c=0` 被误计，正确做法是 `b` 上界取 `min(limit, n-a)` 且 `c` 双端检查。

## 如果面试官追问
问：`n` 放大到 `10^9`、`limit` 也很大怎么办？
答：改用容斥，`C(n+2,2) - 3*C(n-limit+1,2) + 3*C(n-2limit,2) - C(n-3limit-1,2)`，各项为负时取 0。
