## 一句话思路
用回溯按位填 `(` 或 `)`，靠 `open < n` 和 `close < open` 两个约束保证前缀始终合法，走到 `2n` 长度即得一个解。

## 怎么做
1. 维护 `path`（当前串）、`open`（已用左括号数）、`close`（已用右括号数），长度到 `2*n` 时把 `"".join(path)` 收进结果。
2. 只有 `open < n` 才能追加 `(`，否则左括号会超配额。
3. 只有 `close < open` 才能追加 `)`，否则前缀里右括号多于左括号，必然非法。
4. 两处都 `append` → 递归 → `pop` 回溯，恢复现场。

以 `n = 3` 为例，走到 `path = "(()"`、`open = 2`、`close = 1` 时：`open < 3` 成立可继续加 `(`；`close < open` 即 `1 < 2` 成立可加 `)`，于是分叉出 `"(())"` 和 `"(()("` 两条路。若某刻 `close == open == 2`，则只能加 `(`，加 `)` 会被 `close < open` 挡掉。

```python
def dfs(path, open, close):
    if len(path) == 2 * n:
        res.append("".join(path))
        return
    if open < n:
        path.append("(")
        dfs(path, open + 1, close)
        path.pop()
    if close < open:
        path.append(")")
        dfs(path, open, close + 1)
        path.pop()
```

关键点：`close < open` 用的是**当前**已放置数量，不是 `n`；写成 `close < n` 就会生成 `"())("` 这类非法串。

## 复杂度
时间：O(4^n / sqrt(n))，即第 n 个卡特兰数，每个合法串长度 2n 的拷贝成本已含在内。
空间：O(n)，递归栈深最多 2n，`path` 长度 2n，结果集不计入。

## 易错点
- `n = 2` 时若把剪枝写成 `close < n`，会产出 `"())("`、`")()("` 这类前缀非法的串，答案从 2 个变 6 个；必须用 `close < open` 卡住右括号。
- `n = 1` 时若在 `len(path) == 2*n` 判断前就先 `append` 再判，容易把 `"("` 单独收进结果；正确做法是先判长度再决定是否收集，且收集时用 `"".join(path)` 而非直接存 `path` 引用（否则后续 `pop` 会把已存结果改空）。

## 如果面试官追问
问：n 放大到 15 还这么写吗？答：思路不变，但结果数是卡特兰数增长，内存先炸，需改成生成器逐个 `yield`，别一次性存 `res`。
