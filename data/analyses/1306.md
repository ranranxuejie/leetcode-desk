## 一句话思路
从 start 做 BFS/DFS，只走 `i±arr[i]` 且不越界，访问过的下标不再入队，遇到 `arr[i]==0` 立即返回 True。

## 怎么做
1. 用 `visited` 集合记录已到达下标，队列初始为 `[start]`。
2. 每次弹出 `i`，先判 `arr[i] == 0`，是则直接返回 `True`。
3. 对 `i + arr[i]` 和 `i - arr[i]` 分别检查 `0 <= j < len(arr)` 且 `j not in visited`，满足才入队。
4. 队列空仍未命中 0，返回 `False`。

以示例 1 `arr = [4,2,3,0,3,1,2], start = 5` 为例：弹出 5，`arr[5]=1`，邻居是 6 和 4，都入队；弹出 6，`arr[6]=2`，邻居 8（越界丢弃）和 4（已在 visited 跳过）；弹出 4，`arr[4]=3`，邻居 7（越界）和 1；弹出 1，`arr[1]=2`，邻居 3 入队；弹出 3 时 `arr[3]==0`，返回 `True`。关键中间值是 visited 依次为 `{5,6,4,1,3}`，下标 4 被 5 和 6 各指向一次，靠 visited 只处理一次。

```python
from collections import deque

def canReach(arr, start):
    n = len(arr)
    visited = {start}
    q = deque([start])
    while q:
        i = q.popleft()
        if arr[i] == 0:
            return True
        for j in (i + arr[i], i - arr[i]):
            if 0 <= j < n and j not in visited:
                visited.add(j)
                q.append(j)
    return False
```

## 复杂度
时间 O(n)：每个下标最多入队一次，每次只做两次邻居检查。
空间 O(n)：`visited` 集合和队列最坏各存 n 个下标。

## 易错点
- `arr = [0], start = 0` → 若先扩展邻居再判 0，会因 `i±arr[i]` 都是 0 而把 0 反复入队死循环 → 必须在弹出时先判 `arr[i] == 0` 再扩展。
- `arr = [3,0,2,1,2], start = 2` → 若不加 visited，2→0→3→0→… 在 0 和 3 之间来回跳，队列永不空 → 入队前用 `j not in visited` 拦截，示例 3 的 visited 最终为 `{2,0,4,3}`，不含 1，正确返回 `False`。

## 如果面试官追问
要求输出一条到达 0 的路径怎么办？答：BFS 时用 `parent[j] = i` 记录前驱，命中 0 后从该下标沿 parent 回溯到 start 再反转。
