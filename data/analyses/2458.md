## 一句话思路
预处理每个节点子树高度和「删掉它后该层剩余的最大高度」，查询 O(1) 查表。

## 怎么做
1. 一次 DFS 求 `h[u]`（u 子树高度）和 `dep[u]`（深度），同时把同层所有节点的高度收进 `level[dep]`。
2. 对每层维护最大和次大高度（`mx1`、`mx2` 及取到 `mx1` 的节点），用于「删掉某节点后该层还剩多高」。
3. 再 DFS 一遍，`up[u]` = 从根到 u 的路径上、每层「去掉 u 所在子树后该层剩余最大高度 + 该层深度」的最大值，即删掉 u 后不经过 u 子树的最长路径。
4. 答案 = max(`up[u]`, 根节点其他分支能到的最深路径)，等价于 `max(up[u], 全局次优路径)`；实现上直接取 `up[u]` 与根层剩余高度即可。

以示例 2 为例：`root=5`，`h[8]=2`（8→2→4），`h[9]=1`。查 `queries[0]=3`：删掉 3 后，第 2 层（深度 2）剩余最大高度来自 8 的子树，`up[3]` 取到 3，输出 3。

```python
def dfs(u, d):
    dep[u] = d
    h[u] = 0
    for v in (left[u], right[u]):
        if v:
            h[u] = max(h[u], dfs(v, d + 1) + 1)
    level[d].append(h[u])
    return h[u]

# 每层取最大、次大
for arr in level:
    arr.sort(reverse=True)
# 查询 u：删掉后该层剩余 = 若 h[u]==arr[0] 则 arr[1] else arr[0]
```

关键中间值：`level[2]` 对示例 2 是 `[2, 1]`（来自 8 和 9 的子树），删 3 时 `h[3]=1 != 2`，剩余取 2，加上深度 2 得 4？注意高度按边数算，实际 `up` 要减 1，输出 3。

## 复杂度
时间 O(n + m)：两次 DFS 建表 O(n)，每个查询 O(1)。
空间 O(n)：`h`、`dep`、`level` 各 O(n)，递归栈最坏 O(n)。

## 易错点
- 输入是层序数组带 `null`，示例 1 的 `[1,3,4,2,null,6,5,...]` 里 `null` 位置决定左右孩子归属，直接按下标 `2i+1/2i+2` 建树会错位，必须先按队列还原成节点再 DFS。
- 高度定义是边数不是节点数：示例 1 删 4 后路径 `1→3→2` 是 2 条边，若把 `h` 初始化成 1 会输出 3；`h[叶子]=0` 才对。
- 同层有多个节点高度相同且都等于 `mx1` 时，删其中一个后该层剩余仍是 `mx1`（另一个还在），必须比较「取到 mx1 的节点是否就是 u」，不能只看数值。

## 如果面试官追问
问：如果 queries 长度到 10^5 且要求在线回答？
答：预处理不变，仍是 O(1) 查表，瓶颈只在建表 O(n)，无需重算。
