## 一句话思路
用「阶梯式障碍」把路径数按二进制位拆开：第 i 级贡献 2^i 条路径，按 k 的二进制位决定是否开启该级。

## 怎么做
1. 特判 `m == 1 or n == 1`：此时路径数只能是 1（全空）或 0（有障碍），故 `k == 1` 返回全 `'.'`，否则返回 `[]`。
2. 把 k 写成二进制，第 i 位为 1 表示需要 2^i 条路径；由于 `k <= 4`，最多用到 2^2 = 4，只需 3 级阶梯。
3. 在网格里沿对角线放障碍：第 i 级阶梯用一行 `'#'` 堵住「直走」通道，只留一个缺口，使该级恰好把路径数乘以 2。
4. 以 `m=3, n=3, k=4` 为例：k 的二进制是 `100`，只有第 2 位为 1，于是只开启第 2 级阶梯，得到 `["..#","...","#.."]`，路径数 = 2^2 = 4。

```python
def createGrid(m, n, k):
    if m == 1 or n == 1:
        return ['.' * n for _ in range(m)] if k == 1 else []
    grid = [['.'] * n for _ in range(m)]
    # 第 i 级阶梯：在第 i 行第 n-1-i 列放障碍，堵住一条通道
    for i in range(min(m, n) - 1):
        if (k >> i) & 1:
            grid[i][n - 1 - i] = '#'
    return [''.join(row) for row in grid]
```

关键中间值：`k=4` 时 `(k>>0)&1=0`、`(k>>1)&1=0`、`(k>>2)&1=1`，只有 `i=2` 触发，`grid[2][0]='#'`。

## 复杂度
时间：O(m·n)，构造网格并逐格写入，`min(m,n)` 次阶梯判断可忽略。
空间：O(m·n)，即返回的字符网格本身，无额外辅助结构。

## 易错点
- 输入 `m=1, n=4, k=2` → 若直接套阶梯逻辑会返回非空网格，但单行网格路径数只能是 0 或 1 → 必须先特判 `m==1 or n==1`，`k!=1` 时返回 `[]`。
- 输入 `m=2, n=3, k=2` → 若把阶梯放在第 0 行第 `n-1` 列（即 `grid[0][2]`），会堵死终点上方通道导致路径数为 0 → 障碍应放在 `grid[i][n-1-i]`，即从右上往左下错开，保证每级只砍掉一条分支。

## 如果面试官追问
若 k 放大到 10^9 怎么办？答：阶梯级数需扩到 `log2(k)`，要求 `min(m,n) > log2(k)`，否则返回 `[]`，其余逻辑不变。
