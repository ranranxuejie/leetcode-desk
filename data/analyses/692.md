## 一句话思路
先用哈希表统计词频，再用排序键 `(-count[w], w)` 一次排序取前 k，频率降序与字典序升序同时满足。

## 怎么做
1. 用 `Counter(words)` 统计每个单词出现次数，得到 `cnt`。
2. 对 `cnt` 的键排序，键为 `(-cnt[w], w)`：负号把频率翻成升序，等价于频率降序；同频时 `w` 升序即字典序。
3. 取排序结果前 `k` 个返回。

以示例 1 为例，`cnt = {"i":2, "love":2, "leetcode":1, "coding":1}`。排序键分别是 `(-2,"i")`、`(-2,"love")`、`(-1,"coding")`、`(-1,"leetcode")`，排完是 `["i","love","coding","leetcode"]`，取前 2 得 `["i","love"]`——注意 `"i"` 和 `"love"` 同为 2 次，靠字典序 `"i" < "love"` 定先后。

```python
from collections import Counter

cnt = Counter(words)
order = sorted(cnt, key=lambda w: (-cnt[w], w))
return order[:k]
```

若面试官要 O(n log k)，把第 2 步换成大小为 k 的堆：堆里存 `(cnt[w], 逆字典序)` 的相反数组合，或直接对 `(-cnt[w], w)` 维护最大堆取前 k。本题 `words.length ≤ 500`，全排序足够。

## 复杂度
时间：O(m log m)，m 为不同单词数，排序主导；计数 O(n)。
空间：O(m)，`cnt` 哈希表与排序结果各占一份。

## 易错点
- 只按频率排序、忘了同频字典序：示例 1 中 `"i"` 与 `"love"` 都是 2 次，若键写成 `-cnt[w]` 单键，Python 稳定排序会保留 `words` 里首次出现顺序，恰好也是 `"i"` 在前，看似对；但示例 2 里 `"is"` 与 `"sunny"` 都是 3 次，首次出现顺序是 `"sunny"` 先（第 4 个词）而 `"is"` 后（第 3 个词）——实际 `"is"` 先出现，仍可能蒙对。真正翻车在 `"day"` 与其它 1 次词：必须显式加 `w` 作第二键，别赌稳定排序。
- 用堆时把比较方向搞反：要保留「频率高、字典序小」的 k 个，堆顶应是「频率低、字典序大」的最差元素，即 `(cnt[w], 逆序字符串)` 或 `(-cnt[w], w)` 取反。若直接对 `(cnt[w], w)` 建最小堆，弹出的是低频词，结果会变成频率最低的 k 个。

## 如果面试官追问
问：若 `words` 是流式输入、内存放不下全部单词怎么办？
答：维护大小为 k 的最小堆，每来一个词更新计数后与堆顶比较，堆顶是当前第 k 名，O(n log k) 时间、O(k + 不同词数) 空间。
