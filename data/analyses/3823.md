## 一句话思路
两次双指针原地交换：一次只换字母，一次只换特殊字符，各自从两端向中间收拢。

## 怎么做
1. 把 `s` 转成列表 `a`，因为 Python 字符串不可变，交换必须落在列表上。
2. 第一趟：`i=0, j=n-1`，`i` 跳过特殊字符、`j` 跳过特殊字符，两边都是字母时交换并同时内移。
3. 第二趟：同样的双指针，但跳过条件反过来——跳过字母，两边都是特殊字符时交换。
4. `''.join(a)` 返回。

拿示例 1 `s = ")ebc#da@f("`（长度 11）走第一趟：`i=0` 是 `')'` 跳过，`i=1` 是 `'e'`；`j=10` 是 `'('` 跳过，`j=9` 是 `'f'`，交换得 `a[1]='f', a[9]='e'`。继续收拢，最终字母段变成 `fad` + `cb` + `e`，即 `")fad#cb@e("`。第二趟在 `i=0` 与 `j=10` 处交换 `')'` 和 `'('`，再在 `i=4` 与 `j=7` 处交换 `'#'` 和 `'@'`，得到 `"(fad@cb#e)"`。

```python
a = list(s)
n = len(a)
i, j = 0, n - 1
while i < j:
    while i < j and not a[i].islower(): i += 1
    while i < j and not a[j].islower(): j -= 1
    a[i], a[j] = a[j], a[i]
    i += 1; j -= 1
i, j = 0, n - 1
while i < j:
    while i < j and a[i].islower(): i += 1
    while i < j and a[j].islower(): j += 1
    a[i], a[j] = a[j], a[i]
    i += 1; j -= 1
return ''.join(a)
```

关键点：内层 `while` 必须带 `i < j` 守卫，否则全字母或全特殊字符时指针会越界。

## 复杂度
时间 O(n)：两趟各扫一遍，每趟指针总移动量不超过 n。
空间 O(n)：`list(s)` 和 `''.join` 各开一份，均为 n 量级。

## 易错点
- 输入 `"!@#$%^&*()"`（全特殊字符）→ 第一趟内层 `while` 若漏写 `i < j`，`i` 会一路加到 10 越界报 IndexError → 两个内层循环都要写 `while i < j and ...`。
- 输入 `"z"` 或 `"ab"` 这类字母数 ≤1 的情况 → 若先做第二趟再做第一趟、或交换后忘记 `i += 1; j -= 1`，会死循环或把同一对换两次 → 交换后必须无条件双指针内移，且两趟互不干扰。

## 如果面试官追问
问：如果要求一次遍历完成？
答：可以预先把字母位置和特殊字符位置各存一个下标列表，再按下标列表首尾配对交换，仍 O(n) 但多开两个下标数组。
