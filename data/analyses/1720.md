## 一句话思路
用 `arr[i+1] = arr[i] XOR encoded[i]` 从 `first` 顺推，因为异或自带逆运算：`a XOR b = c` 两边同异或 `a` 就还原出 `b`。

## 怎么做
1. 建结果数组 `arr`，长度是 `len(encoded) + 1`，把 `arr[0] = first` 放进去。
2. 从 `i = 0` 到 `len(encoded) - 1` 逐位推：`arr[i+1] = arr[i] ^ encoded[i]`。
3. 返回 `arr`。

拿示例 2 走一遍关键一步：`encoded = [6,2,7,3]`，`first = 4`，所以 `arr[0] = 4`。第一步 `arr[1] = 4 ^ 6 = 2`；接着 `arr[2] = 2 ^ 2 = 0`，`arr[3] = 0 ^ 7 = 7`，`arr[4] = 7 ^ 3 = 4`，得到 `[4,2,0,7,4]`。注意 `arr[2]` 是 0 而不是 2——`2 ^ 2` 抵消成 0，这一步最容易手算错。

```python
def decode(encoded, first):
    arr = [first] * (len(encoded) + 1)
    for i, e in enumerate(encoded):
        arr[i + 1] = arr[i] ^ e
    return arr
```

也可以不预分配，用 `arr = [first]` 然后 `arr.append(arr[-1] ^ e)`，效果一样，`arr[-1]` 就是刚推出来的前一项。

## 复杂度
时间 O(n)：`n = len(encoded) + 1`，循环跑 `len(encoded)` 次，每次一次异或。
空间 O(n)：除返回的 `arr` 外没有额外结构，`arr` 本身占 n 个元素。

## 易错点
- `encoded = [0]`、`first = 5` → 若把循环写成 `range(len(encoded) - 1)` 会漏掉最后一位，返回 `[5]` 而不是 `[5,5]`；正确做法是循环上界取 `len(encoded)`，因为 `encoded` 比 `arr` 少一个元素，要推 `len(encoded)` 次。
- `encoded = [1,2,3]`、`first = 1` → 若误用 `arr[i+1] = arr[i] ^ encoded[i+1]`（下标错位）会得到 `[1,3,1,2]`；正确做法是第 i 步固定用 `encoded[i]` 配 `arr[i]`，两者下标相同。

## 如果面试官追问
问：如果只给 `encoded` 不给 `first`，还能唯一解码吗？
答：不能，`arr` 整体异或同一个常数 `k` 后 `encoded` 不变，有 2**31 组解，必须额外给 `first` 或 `arr` 的异或和。
