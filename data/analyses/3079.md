## 一句话思路
逐位取最大值 `m`，再用 `m` 重复原数位数拼成新数，累加即可。

## 怎么做
1. 对每个 `x`，用 `while` 循环取余 `x % 10` 扫出最大数位 `m`，同时数出位数 `k`。
2. 用 `m` 拼出 `k` 位全 `m` 的数：循环 `k` 次 `enc = enc * 10 + m`。
3. 把 `enc` 累加进 `total`，返回 `total`。

以 `nums = [10, 21, 31]` 为例，`x = 10`：扫位得 `m = 1`、`k = 2`，拼出 `enc = 11`；`x = 21` 得 `m = 2`、`k = 2`，`enc = 22`；`x = 31` 得 `enc = 33`，累加 `11 + 22 + 33 = 66`。

```python
total = 0
for x in nums:
    t, m, k = x, 0, 0
    while t:
        m = max(m, t % 10)
        t //= 10
        k += 1
    enc = 0
    for _ in range(k):
        enc = enc * 10 + m
    total += enc
return total
```

关键点：`m` 和 `k` 必须在同一次扫位里一起得到，否则要扫两遍。`x = 1000` 时 `m = 1`、`k = 4`，`enc = 1111`，注意 `k` 数的是原数位数而不是最大数位本身。

## 复杂度
时间：O(n · log₁₀ max(nums))，`n` 是数组长度，`log` 来自每个数的位数（≤4）。
空间：O(1)，只用了 `t`、`m`、`k`、`enc`、`total` 几个标量。

## 易错点
- 输入 `nums = [1000]` → 若把 `m` 直接当结果或只拼一次，会错成 `1` → 正确是 `m = 1`、`k = 4`、`enc = 1111`，位数必须单独计数。
- 输入 `nums = [10]` → 若用 `str(x)` 取 `max` 后忘记 `int` 拼回，会错成字符串 `"11"` 参与加法 → 正确做法是全程整数运算，`enc = enc * 10 + m`。

## 如果面试官追问
问：`nums[i]` 上限改成 `10**18` 怎么办？
答：思路不变，扫位循环次数变成 ≤19，仍是 O(n · 位数)，Python 大整数直接算。
