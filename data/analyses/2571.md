## 一句话思路
从低位向高位扫二进制，遇到连续 1 段就整段消掉：段长 1 减一次，段长 ≥2 加一次进位再减一次，段数即答案。

## 怎么做
1. 把 n 看成二进制串，答案等于「把串变成全 0 需要处理的 1 段数」，每段贡献 1 次操作。
2. 段长 ≥2 时，先加 1 让整段进位成一个更高的 1，再一次性减掉，所以段长 ≥2 也只算 1 次。
3. 用 `while n:` 循环，每轮先 `n >>= 1` 跳过末尾的 0，再数连续 1 的个数 `cnt`，`ans += 1`。
4. 若 `cnt > 1`，说明这段要进位，`n += 1` 把进位补上，继续下一轮。

以 n = 39（二进制 `100111`）为例：第一轮跳过末尾 0 后数到 `111` 共 3 个 1，`ans = 1`，`cnt > 1` 所以 `n += 1` 变成 40（`101000`）；第二轮数到单个 1，`ans = 2`；第三轮再数到单个 1，`ans = 3`，与示例一致。

```python
ans = 0
while n:
    n >>= 1
    cnt = 0
    while n & 1:
        n >>= 1
        cnt += 1
    if cnt:
        ans += 1
    if cnt > 1:
        n += 1
return ans
```

## 复杂度
时间：O(log n)，每轮至少右移一位，n 的二进制位数决定轮数。
空间：O(1)，只用了 `ans`、`cnt` 两个整数，没有额外数组。

## 易错点
- n = 3（`11`）→ 若按「每个 1 减一次」会得 2，实际加 1 到 4 再减 4 只需 2 次也等于 2，但 n = 7（`111`）按位算得 3，正确是 2（加 1 到 8 再减 8）→ 必须对段长 ≥2 做进位 `n += 1`。
- n = 2**k - 1 这类全 1 数 → 若在 `cnt > 1` 时忘记 `n += 1`，进位丢失会让后续轮次多数出一段，答案偏大 → 进位后要重新进入 `while n:` 判断，不能直接跳出。

## 如果面试官追问
若 n 上限提到 10^18 怎么办？答：算法只依赖二进制位数，O(log n) 轮循环照样跑，Python 大整数无需改代码。
