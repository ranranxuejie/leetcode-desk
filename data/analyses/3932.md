## 一句话思路
用二分求 `r` 和 `l-1` 各自的「最大底数」，两者相减即答案；因为 `x^k` 随 `x` 单调递增。

## 怎么做
1. 定义 `cnt(n)`：返回 `[0, n]` 内完全 k 次幂的个数，即满足 `x^k <= n` 的非负整数 `x` 的个数。
2. 在 `[0, n]` 上二分底数 `x`，找最大的满足 `x**k <= n` 的 `x`，答案就是 `x + 1`（含 `x=0`）。
3. 结果 = `cnt(r) - cnt(l-1)`，`l=0` 时 `cnt(-1)` 直接返回 0。

以 `l=1, r=9, k=3` 为例：`cnt(9)` 二分到 `hi=2`（`2**3=8<=9`，`3**3=27>9`），返回 `3`（底数 0,1,2）；`cnt(0)` 返回 `1`（只有 `0^3=0`）；答案 `3-1=2`。

```python
def cnt(n):
    if n < 0:
        return 0
    lo, hi = 0, int(n ** (1.0 / k)) + 2  # 浮点估个上界，再修正
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if mid ** k <= n:
            lo = mid
        else:
            hi = mid - 1
    return lo + 1  # 底数 0..lo 共 lo+1 个
```

注意 `int(n ** (1.0/k))` 只是加速上界，浮点会偏小，所以 `+2` 兜底，真正的判定仍靠 `mid ** k <= n` 的整数比较。

## 复杂度
时间：每次二分 `O(log n)`，两次共 `O(log r)`，`k` 只影响单次幂运算。
空间：`O(1)`，只开了 `lo/hi/mid` 几个整数。

## 易错点
- `l=0` 时 → 若直接算 `cnt(l-1)=cnt(-1)` 会进入二分死循环或返回负数 → 正确做法是在 `cnt` 开头对 `n < 0` 直接 `return 0`。
- `k=1` 且区间很大 → 若用 `int(n ** (1.0/k))` 当最终答案，浮点误差会让 `10^9` 附近少算 1 → 正确做法是浮点只当上界，最终用 `mid ** k <= n` 整数比较收敛。

## 如果面试官追问
问：若 `r` 扩大到 `10^18`、`k` 到 `60` 呢？
答：思路不变，二分上界改成 `int(n ** (1.0/k)) + 2` 仍成立，Python 大整数保证 `mid ** k` 精确，只是幂运算位数变多。
