## 一句话思路
一次线性扫描：先跳过空格，再取一个符号，然后逐位累加数字，每步用 `2**31-1` 和 `-2**31` 判断截断。

## 怎么做
1. 用指针 `i` 跳过所有 `' '`，越界就直接返回 0。
2. 在 `i` 处读一个 `'+'` 或 `'-'` 定 `sign`，读到就 `i += 1`。
3. 循环 `while i < len(s) and s[i].isdigit()`，把 `res = res * 10 + int(s[i])` 累加，`i += 1`。
4. 每步累加后立刻按 `sign` 检查是否越界并返回边界值。

以 `s = " -42"` 为例：跳过 1 个空格后 `i=1`，读到 `'-'` 使 `sign=-1`、`i=2`；循环里 `res` 依次变成 `4`、`42`，最终返回 `-1 * 42 = -42`。

```python
i, n = 0, len(s)
while i < n and s[i] == ' ':
    i += 1
sign = 1
if i < n and s[i] in '+-':
    sign = -1 if s[i] == '-' else 1
    i += 1
res = 0
while i < n and s[i].isdigit():
    res = res * 10 + int(s[i])
    if sign == 1 and res > 2**31 - 1:
        return 2**31 - 1
    if sign == -1 and res > 2**31:
        return -2**31
    i += 1
return sign * res
```

关键点：负号侧比较的是 `res > 2**31`（即 `abs` 与 `2**31` 比），因为 `-2**31` 本身合法，只有超过才截断。

## 复杂度
时间 O(n)：`i` 从 0 走到 `len(s)`，每个字符最多看一次。
空间 O(1)：只开了 `i`、`sign`、`res` 三个标量。

## 易错点
- 输入 `"words and 987"` → 若先找数字再判断符号，会错成 `987`；正确做法是跳过空格后**必须**先看 `s[i]` 是不是 `+`/`-`，不是数字就立刻返回 0，因为首字符是 `'w'`。
- 输入 `"-91283472332"` → 若最后才统一截断，中间 `res` 会累到 `91283472332`；题目规定答案按 32 位截断，正确做法是循环内每步用 `res > 2**31` 提前返回 `-2**31`，别等循环结束。

## 如果面试官追问
问：如果要求返回截断前的原始大整数怎么办？
答：把循环内的越界 return 去掉，Python 整数天然不溢出，最后再统一 `min(max(res*sign, -2**31), 2**31-1)`。
