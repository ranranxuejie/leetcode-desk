## 一句话思路
每个 x 值只保留最大 y，再取前三大的 y 求和；不同 x 值不足 3 个返回 -1。

## 怎么做
1. 用哈希表 `best` 记录每个 x 值对应的最大 y：遍历 `zip(x, y)`，`best[xi] = max(best.get(xi, 0), yi)`。
2. 若 `len(best) < 3`，直接返回 -1。
3. 取 `best.values()` 中最大的三个数求和。

以示例 1 为例：`best` 最终为 `{1: 5, 2: 3, 3: 6}`（x=1 时 y=5 与 4 取 5，x=2 时 y=3 与 2 取 3），三个值 5、3、6 求和得 14。

```python
best = {}
for xi, yi in zip(x, y):
    if yi > best.get(xi, 0):
        best[xi] = yi
if len(best) < 3:
    return -1
top3 = sorted(best.values(), reverse=True)[:3]
return sum(top3)
```

关键点：同一个 x 值出现多次时，只有最大的那个 y 可能被选中，其余全被淘汰，所以先压缩再排序，规模从 n 降到不同 x 的个数。

## 复杂度
时间：O(n) 建哈希表，O(d log d) 排序，d 为不同 x 值个数，d ≤ n。
空间：O(d) 存哈希表，排序额外 O(d)。

## 易错点
- 输入 `x = [1,2,1,2], y = [4,5,6,7]`：若直接对 y 排序取前三（7+6+5=18）会错，因为 7 和 5 的 x 都是 2、6 和 4 的 x 都是 1，凑不出三个不同 x；必须先按 x 去重取最大，`best` 只有 `{1: 6, 2: 7}` 两个键，正确返回 -1。
- 输入 `x = [1,1,1,2,3], y = [1,9,2,5,4]`：若用 `best[xi] = yi` 直接覆盖而不比较大小，x=1 会留下最后的 2 而非 9，答案从 9+5+4=18 错成 2+5+4=11；正确写法是只在 `yi > best.get(xi, 0)` 时更新。

## 如果面试官追问
要求输出具体下标而非和？答：哈希表存 `(最大 y, 对应下标)`，取前三后返回这三个下标即可，逻辑不变。
