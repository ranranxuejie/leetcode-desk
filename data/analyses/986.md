## 一句话思路
两个已排序且各自不相交的区间列表，用双指针 i、j 同步扫描，每次取 `max(start)` 到 `min(end)`，再推进右端点更小的那个。

## 怎么做
1. 初始化 `i = j = 0`，结果列表 `res = []`。
2. 每轮取 `lo = max(firstList[i][0], secondList[j][0])`、`hi = min(firstList[i][1], secondList[j][1])`。
3. 若 `lo <= hi` 则把 `[lo, hi]` 加入 `res`（闭区间，相等也算交集）。
4. 比较两个区间的右端点，谁小谁前进一格；相等时两个都进（或只进一个也不会漏，但会多一轮空比较）。

用示例 1 走关键一步：`i=0` 时 `firstList[0]=[0,2]`、`j=0` 时 `secondList[0]=[1,5]`，`lo=max(0,1)=1`、`hi=min(2,5)=2`，得 `[1,2]`；因 `2 < 5`，只推进 `i` 到 1。下一轮 `[5,10]` 对 `[1,5]`，`lo=5, hi=5`，产出 `[5,5]`——这就是闭区间必须用 `<=` 而非 `<` 的地方。

```python
i = j = 0
res = []
while i < len(firstList) and j < len(secondList):
    lo = max(firstList[i][0], secondList[j][0])
    hi = min(firstList[i][1], secondList[j][1])
    if lo <= hi:
        res.append([lo, hi])
    if firstList[i][1] < secondList[j][1]:
        i += 1
    else:
        j += 1
```

## 复杂度
时间 O(m + n)：i、j 各自单调前进，每轮至少推进一个指针。
空间 O(1) 额外（不计输出 res 本身）。

## 易错点
- 输入 `firstList=[[1,7]]`、`secondList=[[3,10]]` → 若把 `lo <= hi` 写成 `lo < hi`，单点交集 `[5,5]`、`[25,25]` 这类会被丢掉，示例 1 直接少两个结果 → 闭区间一律用 `<=`。
- 输入 `firstList=[[0,2],[5,10]]`、`secondList=[[1,5],[8,12]]` → 若按「两个都推进」处理，`[5,10]` 与 `[1,5]` 的 `[5,5]` 之后会跳过 `[8,10]` 的配对 → 必须只推进右端点更小的那个，相等时才可同时推进。

## 如果面试官追问
问：若区间列表未排序怎么办？答：先按起点排序再双指针，复杂度变 O(m log m + n log n)；或直接扫描线合并后求交。
