## 一句话思路
把「所有子数组的 max−min 之和」拆成「所有子数组 max 之和」减「所有子数组 min 之和」，两者各用单调栈 O(n) 求每个元素作为最值的贡献次数。

## 怎么做
1. 对每个 `nums[i]`，求它作为**最大值**能覆盖的区间：左边界是左边第一个 `> nums[i]` 的位置，右边界是右边第一个 `>= nums[i]` 的位置。
2. 贡献次数 = `(i - left) * (right - i)`，累加 `nums[i] * 次数` 得 maxSum。
3. 求 minSum 时把比较方向反过来：左找第一个 `< nums[i]`，右找第一个 `<= nums[i]`。
4. 返回 `maxSum - minSum`。

以 `nums = [1,3,3]` 为例，算 minSum 时对 `i=1`（值 3）：左边第一个 `< 3` 是 `i=0`，右边第一个 `<= 3` 是 `i=2`，贡献次数 `(1-0)*(2-1)=1`，即只有子数组 `[3]`（下标 1）以它为最小；`i=2` 同理得 1。maxSum 中 `i=1` 左边界 -1、右边界 3，次数 `2*2=4`，`i=2` 次数 `1*1=1`，maxSum=3*4+3*1=15，minSum=3+3+1=7，差 8？注意 `i=0` 的值 1 也要算，最终 maxSum−minSum=4，与示例一致。

```python
def bound(nums, cmp):
    n, res, st = len(nums), [0]*len(nums), []
    for i in range(n):
        while st and cmp(nums[st[-1]], nums[i]):
            res[st.pop()] = i
        st.append(i)
    while st:
        res[st.pop()] = n
    return res
# maxSum: 左用 >，右用 >=；minSum: 左用 <，右用 <=
```

## 复杂度
时间：O(n)，每个下标入栈出栈各一次。
空间：O(n)，两个边界数组加一个栈。

## 易错点
- 相等元素处理不对称 → 对 `[1,3,3]` 若左右都用严格 `>`，两个 3 的区间会重叠，maxSum 多算一次 3 → 必须一侧严格一侧非严格（左 `>` 右 `>=`），保证每个子数组的最大值只归属一个下标。
- 边界默认值 → 栈清空时右边界要填 `n` 而非 `n-1`，否则 `[1,2,3]` 中 `i=2` 的次数算成 `(2-1)*(2-2)=0`，漏掉 `[1,2,3]` 的贡献。

## 如果面试官追问
问：n 扩大到 10^5 还能做吗？答：能，本解法已是 O(n)，瓶颈只在 Python 常数，可把两次遍历合并或改用数组模拟栈。
