## 一句话思路
按值域分桶（桶宽 t+1），只需检查同桶和相邻两桶，桶内值差必 ≤ t。

## 怎么做
1. 桶宽 `w = t + 1`，用 `id = x // w` 把值映射到桶号，`dict` 存桶号到值的映射。
2. 遍历 `nums`，先删掉下标 `i - k - 1` 对应的旧桶，保证窗口内下标差 ≤ k。
3. 对当前 `x` 查 `id`、`id-1`、`id+1` 三个桶，任一桶内值与 `x` 差 ≤ t 就返回 `True`。
4. 否则写入 `buckets[id] = x`，继续。

以示例 2 `nums = [1,0,1,1], k = 1, t = 2` 为例，`w = 3`。`i=0` 时 `1//3=0`，桶 `{0:1}`；`i=1` 时 `0//3=0`，同桶已有 `1`，`abs(0-1)=1 ≤ 2`，直接返回 `True`。注意 `i=1` 时窗口只保留 `i=0`，删桶条件是 `i-k-1 = -1`，不触发删除。

```python
w = t + 1
buckets = {}
for i, x in enumerate(nums):
    if i - k - 1 >= 0:
        del buckets[nums[i - k - 1] // w]
    bid = x // w
    for b in (bid - 1, bid, bid + 1):
        if b in buckets and abs(x - buckets[b]) <= t:
            return True
    buckets[bid] = x
return False
```

关键点：桶宽取 `t+1` 而非 `t`，这样同桶两值差最大为 `t`，必然满足条件；相邻桶才需要显式比较 `abs`。

## 复杂度
时间：O(n)，每个元素只查 3 个桶，删除也是 O(1)。
空间：O(min(n, k+1))，`buckets` 最多存窗口内 k+1 个元素。

## 易错点
1. 输入含负数如 `nums = [-1, -2], k = 1, t = 1` → Python 的 `//` 对负数向下取整，`-1 // 2 = -1`、`-2 // 2 = -1`，同桶命中正确；若用 `int(x / w)` 截断会得到 `0` 和 `-1`，分到不同桶漏判。统一用 `x // w`。
2. `t = 0` 时桶宽 `w = 1`，每个整数独占一桶，此时只能靠同桶命中（相等值），相邻桶差至少 1 > 0 不会误判；但若把桶宽写成 `t`（即 0），会除零崩溃。桶宽必须是 `t + 1`。

## 如果面试官追问
问：若要求返回具体下标对而非布尔值？
答：桶里存 `(值, 下标)`，命中时连同当前 `i` 一起返回即可，逻辑不变。
