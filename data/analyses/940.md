## 一句话思路
按字符末位去重：维护以每个字母结尾的不同子序列数，新字符 c 的贡献是「当前总数 + 1」减去旧的以 c 结尾的计数。

## 怎么做
1. 设 `end[c]` 为以字母 c 结尾的不同非空子序列个数，`total` 为全部不同非空子序列数。
2. 扫到字符 c 时，新产生的子序列 = 所有已有子序列末尾接 c（共 `total` 个）加上单独的 `"c"`，即 `total + 1`。
3. 但其中以 c 结尾的部分会与旧的 `end[c]` 重复，所以增量是 `total + 1 - end[c]`，更新 `end[c] = total + 1`，`total += 增量`。
4. 全程对 `10**9 + 7` 取余。

以 `s = "aba"` 为例：初始 `total = 0`，`end` 全 0。
- 读到 `'a'`：`end['a'] = 0 + 1 = 1`，`total = 1`。
- 读到 `'b'`：`end['b'] = 1 + 1 = 2`，`total = 1 + 2 = 3`。
- 读到第二个 `'a'`：`end['a'] = 3 + 1 = 4`，`total = 3 + (4 - 1) = 6`。

关键中间值就是第二次读 `'a'` 时的 `end['a']` 旧值 1——它正是被减掉的重复量。

```python
MOD = 10**9 + 7
end = [0] * 26
total = 0
for ch in s:
    i = ord(ch) - ord('a')
    new_end = (total + 1) % MOD
    total = (total + new_end - end[i]) % MOD
    end[i] = new_end
return total % MOD
```

注意 `new_end` 必须先算出来再更新 `total`，否则 `total` 已被改动，`end[i]` 的语义就乱了。

## 复杂度
时间 O(n)：n 为 `len(s)`，每个字符 O(1) 更新。
空间 O(1)：只开长度 26 的 `end` 数组，与 n 无关。

## 易错点
- 输入 `"aaa"` → 若写成 `total += total + 1` 不去重，会得到 7 而非 3 → 必须减去旧的 `end['a']`，第二次读 `'a'` 时减 1、第三次减 3。
- 输入 `"aba"` → 若把 `end[i] = total + 1` 写在 `total` 更新之后，`end['a']` 会存成 6 而非 4，下次再遇 `'a'` 减多了 → 先存 `new_end`，再改 `total`，最后赋 `end[i]`。

## 如果面试官追问
问：要求输出所有不同子序列本身而非个数？
答：同样按末位去重，但 `end[c]` 要存字符串集合，空间退化为 O(答案总长)，n=2000 时不可行。
