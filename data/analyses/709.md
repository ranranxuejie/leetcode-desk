## 一句话思路
逐字符判断是否落在 `'A'`–`'Z'`，是就加 32 转小写，其余原样保留。

## 怎么做
1. 把 `s` 转成列表 `res`，方便按下标原地改写。
2. 遍历每个下标 `i`，取 `c = s[i]`。
3. 若 `'A' <= c <= 'Z'`，令 `res[i] = chr(ord(c) + 32)`；否则不动。
4. 用 `''.join(res)` 返回。

以 `s = "Hello"` 为例：`i=0` 时 `c='H'`，满足 `'A' <= 'H' <= 'Z'`，`ord('H')=72`，`72+32=104`，`chr(104)='h'`，`res[0]` 从 `'H'` 变成 `'h'`；`i=1` 时 `c='e'` 不满足区间，`res[1]` 保持 `'e'`。最终 `res` 为 `['h','e','l','l','o']`。

```python
res = list(s)
for i, c in enumerate(s):
    if 'A' <= c <= 'Z':
        res[i] = chr(ord(c) + 32)
return ''.join(res)
```

关键点：ASCII 里大写 `'A'`=65 到 `'Z'`=90，小写 `'a'`=97 到 `'z'`=122，同一字母大小写差恰好 32，所以 `+32` 一步到位。用 `'A' <= c <= 'Z'` 而不是 `c.isupper()`，因为 `isupper()` 对非 ASCII 大写字母也返回 `True`，而本题只保证 ASCII 可打印字符，用区间判断语义更贴题。

## 复杂度
时间 O(n)：`n` 是 `len(s)`，每个字符判一次区间。
空间 O(n)：`res` 列表和 `join` 结果各占 n，非原地。

## 易错点
- 输入 `s = "here"` 或含数字、空格如 `"a1 B"` → 若写成「无脑 `chr(ord(c)+32)`」会把 `'e'` 变成 `'E'` 之外的乱码、把 `'1'` 变成 `'Q'` → 必须先判 `'A' <= c <= 'Z'` 再改。
- 输入 `s = "LOVELY"` → 若用 `s.replace(c, chr(ord(c)+32))` 逐个替换，会重复扫描且对已改写的字符再处理，逻辑易乱 → 按下标写 `res[i]`，每个位置只处理一次。

## 如果面试官追问
问：若字符集扩到 Unicode 大写字母怎么办？
答：改用 `c.isupper()` 配合 `c.lower()`，但需注意 `lower()` 可能返回多字符（如 `'İ'`），要按题面约束确认。
