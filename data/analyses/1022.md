## 一句话思路
DFS 向下传当前路径值 `cur = cur * 2 + node.val`，到叶子就把 `cur` 累加进总和。

## 怎么做
1. 递归函数带两个参数：节点 `node` 和到达它之前已构成的数值 `cur`。
2. 进入节点先更新 `cur = cur * 2 + node.val`，这一步等价于二进制左移一位再补当前位。
3. 若 `node` 左右子都为空（叶子），把 `cur` 加到 `total`；否则分别递归左右子。
4. 用 `nonlocal total` 或返回子树和累加，避免全局变量。

以示例 1 `root = [1,0,1,0,1,0,1]` 为例，走到最左叶子路径 `1→0→0`：根处 `cur=1`，左子 `cur=1*2+0=2`，再左子 `cur=2*2+0=4`，叶子累加 4。四条叶子路径分别得 4、5、6、7，`total=22`。

```python
def dfs(node, cur):
    if not node:
        return 0
    cur = cur * 2 + node.val
    if not node.left and not node.right:
        return cur
    return dfs(node.left, cur) + dfs(node.right, cur)

return dfs(root, 0)
```

关键点：`cur` 是**向下传参**而非全局累加，保证每个分支独立；叶子判断必须 `not left and not right`，不能只判 `not node`。

## 复杂度
时间 O(n)：每个节点访问一次，n 为节点数。
空间 O(h)：递归栈深度为树高 h，最坏链状 O(n)，未额外开数组。

## 易错点
- 输入 `root = [0]`（单节点即叶子）→ 若把叶子判断写成「有子才累加」会漏掉，返回 0 虽巧合正确，但换成 `[1]` 就错成 0 而非 1 → 正确做法是进节点先算 `cur`，再判叶子直接返回 `cur`。
- 输入 `[1,0,1,0,1,0,1]` → 若把 `cur` 写成全局变量在回溯时不还原，右子树会带着左子树的值继续左移，得到远大于 22 的结果 → 正确做法是 `cur` 作为参数按值传递，每个分支各算各的。

## 如果面试官追问
问：节点值不止 0/1 怎么办？
答：把 `cur * 2` 改成 `cur * 10`（十进制）或按进制基数 `cur * base + val`，框架不变。
