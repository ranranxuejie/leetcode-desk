## 一句话思路
按切割开销从大到小贪心：贵的线先切，此时它穿过的蛋糕块最少，乘数最小。

## 怎么做
1. 把 `horizontalCut` 和 `verticalCut` 合并成 `(cost, 方向)` 列表，按 `cost` 降序排序。
2. 维护两个计数器 `h_seg = 1`（当前水平方向的段数）、`v_seg = 1`（垂直方向的段数）。
3. 遇到水平线，答案加 `cost * v_seg`，然后 `h_seg += 1`；遇到垂直线，答案加 `cost * h_seg`，然后 `v_seg += 1`。

以示例 1 为例：`m=3, n=2, horizontalCut=[1,3], verticalCut=[5]`，排序后为 `[(5,'v'),(3,'h'),(1,'h')]`。先切 5：`h_seg=1`，加 `5*1=5`，`v_seg` 变 2；再切 3：`v_seg=2`，加 `3*2=6`，`h_seg` 变 2；最后切 1：加 `1*2=2`。总计 `5+6+2=13`。

```python
cuts = [(c, 0) for c in horizontalCut] + [(c, 1) for c in verticalCut]
cuts.sort(reverse=True)
ans, h_seg, v_seg = 0, 1, 1
for cost, d in cuts:
    if d == 0:          # 水平线
        ans += cost * v_seg
        h_seg += 1
    else:               # 垂直线
        ans += cost * h_seg
        v_seg += 1
return ans
```

关键点：切一条水平线时，它要横穿当前所有 `v_seg` 个竖直分段，所以乘数是 `v_seg` 而不是 `h_seg`——这两个计数器别写反。

## 复杂度
时间：排序 `O((m+n) log(m+n))`，遍历 `O(m+n)`。
空间：`cuts` 列表 `O(m+n)`，其余常数。

## 易错点
- 乘数写反：示例 1 中切水平线 3 时若乘 `h_seg=1` 得 3，正确应乘 `v_seg=2` 得 6，总和会错成 10 而非 13。水平线乘垂直段数，垂直线乘水平段数。
- 贪心方向搞反：若按开销从小到大切，示例 2 中先切 4 得 `4*1=4`、再切 7 得 `7*2=14`，总 18；正确是先切 7 得 7、再切 4 两次得 8，总 15。必须降序。

## 如果面试官追问
若 `m, n` 放大到 1e5 且切割线开销有重复，贪心还成立吗？答：成立，相等开销任意顺序结果相同，排序仍是瓶颈。
