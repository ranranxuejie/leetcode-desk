## 一句话思路
按数值排序后从小到大扫，用 DP 记录「以当前数值结尾、被顺子借走多少张」的最优牌组数，因为顺子只跨三个连续值，状态只需三维。

## 怎么做
1. 统计每个数值的出现次数，排序去重后得到 `(value, cnt)` 序列。
2. 设 `dp[i][j]` 表示处理到当前数值时，留下 `i` 张给下一个数值的顺子、`j` 张给下下个数值的顺子时的最大牌组数；转移时枚举当前数值分给刻子、顺子、以及向后借出的张数。
3. 关键中间值：以 `tiles=[2,2,2,3,4,1,3]` 为例，计数为 `1:1, 2:3, 3:2, 4:1`。处理到 `2` 时，若把 2 张 2 借给 `[2,3,4]` 顺子，则 `dp` 中「借出 2 张」状态记录牌组数 0，剩余 1 张 2 留给刻子；处理到 `3` 时，`3` 有 2 张，其中 1 张接上从 `2` 借来的顺子，另 1 张再借给 `[3,4,5]`，最终凑出 2 组。
4. 答案取处理完所有数值后 `dp[0][0]` 的最大值。

```python
from collections import Counter
cnt = Counter(tiles)
vals = sorted(cnt)
# dp[a][b]: 当前值向后借出 a 张给下一值、b 张给下下值时的最大组数
dp = {(0, 0): 0}
for v in vals:
    ndp = {}
    c = cnt[v]
    for (a, b), g in dp.items():
        for use in range(min(c, 3) + 1):  # 当前值实际可用的张数
            pass
    dp = ndp
```

（完整转移需枚举 `use` 拆成刻子、顺子、借出三部分，代码片段只示意状态结构。）

## 复杂度
时间：O(n log n)，排序去重贡献 log n，DP 状态数常数级（每值最多 3×3 种借出组合）。
空间：O(n) 存计数，DP 表为常数大小。

## 易错点
- 输入 `[2,2,2,3,4]`：若贪心先凑刻子 `[2,2,2]`，剩 `3,4` 凑不成，错成 1 组但漏掉 `[2,3,4]` 也是 1 组——本题两种都 1 组，真正翻车在 `[1,2,2,2,3,4]`：先凑刻子得 1 组，正确应先借 2 张 2 给 `[1,2,3]` 和 `[2,3,4]` 得 2 组，必须 DP 枚举借出量。
- 数值不连续时（如 `[1,1,1,5,5,5]`）：若按「相邻值差 1 才转移」写死，会把 `1` 和 `5` 之间的空档误判为可接顺子，正确做法是遇到 `vals` 中不连续就清空借出状态（`a=b=0` 之外的状态作废）。

## 如果面试官追问
问：若要求输出具体牌组方案而非只给数量？
答：在 DP 转移时额外记录每步选择的 `(刻子数, 顺子数, 借出数)`，回溯即可还原每组牌。
