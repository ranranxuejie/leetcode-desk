## 一句话思路
统计 s 与 t 的字符频次差，把 t 中「多出来的」字符逐个改成「缺的」字符，答案就是所有正差之和。

## 怎么做
1. 用长度 26 的数组 `diff` 记录 s 的频次减去 t 的频次，`diff[c] > 0` 表示字符 c 在 s 里多、t 里缺。
2. 遍历 s 做 `diff[ord(ch)-97] += 1`，遍历 t 做 `-= 1`。
3. 把所有正的 `diff` 值累加，即为最小步骤数。

以 `s = "leetcode", t = "practice"` 为例：s 中 `e` 出现 3 次、t 中 1 次，`diff['e'] = 2`；`l` 在 s 有 1 次、t 有 0 次，`diff['l'] = 1`；而 `p`、`r`、`a`、`i`、`c` 在 t 里多出来，对应 `diff` 为负。正差之和 = 2 + 1 + 1 + 1 = 5，正好等于示例答案。

为什么正差之和就是答案：每次替换只能消掉 t 的一个多余字符、补上一个缺失字符，一次操作最多让一个正差减少 1；而正差总和恰好等于 t 中需要被替换的字符个数，所以下界可达。

```python
diff = [0] * 26
for ch in s:
    diff[ord(ch) - 97] += 1
for ch in t:
    diff[ord(ch) - 97] -= 1
ans = 0
for d in diff:
    if d > 0:
        ans += d
```

注意只累加正值，负值代表 t 多出来的字符，它们会被替换掉，不额外计数。

## 复杂度
时间：O(n + 26)，n 为字符串长度，两趟遍历加一次常数扫描。
空间：O(26) = O(1)，只开了固定大小的 `diff` 数组。

## 易错点
- 输入 `s = "bab", t = "aba"`：若对 `diff` 取绝对值再求和，会得到 2，但正确答案是 1。因为 `diff['a'] = -1`、`diff['b'] = 1` 是同一对字符的进出，只算一次即可。正确做法是只累加 `d > 0` 的部分。
- 输入 `s = "anagram", t = "mangaar"`：若先排序再逐位比较，虽然结果对，但会引入 O(n log n)；更隐蔽的坑是误以为「位置不同的字符都要换」，从而数出非零位置个数。实际两串频次完全一致，`diff` 全为 0，答案应为 0。

## 如果面试官追问
问：若字符集扩展到全部 Unicode，怎么做？
答：把 26 数组换成 `collections.Counter`，仍只累加 `(cnt_s - cnt_t).values()` 中的正值。
