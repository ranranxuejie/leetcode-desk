## 一句话思路
用有序集合维护「当前最短路径必须经过的节点」，每条新边 `(u,v)` 删掉区间 `(u,v)` 内的所有中间节点，答案就是集合大小减一。

## 怎么做
1. 初始把 `0..n-1` 全部放进有序集合 `s`，此时路径 0→1→…→n-1 长度 `n-1`。
2. 对每条 `(u,v)`，用 `bisect_right(s, u)` 找到第一个大于 `u` 的位置，循环删除所有 `< v` 的节点。
3. 每删一个节点，路径长度减一；把结果追加到 `answer`。
4. 关键中间值：示例 1 处理 `(2,4)` 时 `s` 从 `{0,1,2,3,4}` 删掉 `3` 得 `{0,1,2,4}`，长度 `4-1=3`；再处理 `(0,2)` 删掉 `1`，长度 2。

```python
from sortedcontainers import SortedList
from bisect import bisect_right

s = SortedList(range(n))
ans = []
for u, v in queries:
    i = bisect_right(s, u)
    while i < len(s) and s[i] < v:
        s.pop(i)
    ans.append(len(s) - 1)
```

（`SortedList` 不可用时，用 `list` + `bisect` 也行，但删除是 O(n)；面试中说明用平衡树即可。）

## 复杂度
时间：每条查询 O(log n + 删除数)，总删除数 ≤ n，故 O((n+q) log n)。
空间：`SortedList` 存最多 n 个节点，O(n)。

## 易错点
- 输入 `n=4, queries=[[0,3],[0,2]]`：若对 `(0,2)` 也盲目删 `(0,2)` 内节点，会误删已不在集合里的节点或重复计数 → 必须用 `bisect_right(s,u)` 定位后只删集合中实际存在的、`< v` 的节点，第二条查询删不到东西，答案保持 1。
- 输入 `n=5, queries=[[2,4],[0,2],[0,4]]`：若把 `(0,4)` 当成「删 1,2,3」而不检查 `2` 已被删，会多减一次得到 0 → 正确做法是循环里每次重新看 `s[i]`，`2` 已不在集合中，只删 `1` 和 `3`，长度从 2 变 1。

## 如果面试官追问
问：如果查询不满足「无交叉」约束怎么办？
答：那删除逻辑仍成立，但需证明删掉的节点确实不在任何更短路径上——交叉时可能删错，得改用 BFS 或线段树维护区间最短路。
