## 一句话思路
先统计每个节点被多少条 trip 路径覆盖，再在树上做「选/不选减半」的树形 DP。

## 怎么做
1. 对每条 `trips[i]` 用 BFS/DFS 找路径，把路径上每个节点的 `cnt[v]` 加一；`cnt[v]` 就是节点 v 的原始贡献系数。
2. 以 0 为根建树，`dfs(u, parent)` 返回 `(不选u减半, 选u减半)` 两个值。
3. 不选 u 时，子节点可自由选：`no = cnt[u]*price[u] + sum(max(child))`；选 u 时子节点都不能选：`yes = cnt[u]*price[u]//2 + sum(child_no)`。
4. 答案取根节点两值较小者。

以示例 1 为例：三条 trip 覆盖后 `cnt = [1,3,2,2]`（节点 0 只在 trip1，节点 1 在三条里，节点 2 在 trip2、3，节点 3 在 trip1、3）。叶子 3：`no=2*6=12, yes=6`；节点 2：`no=2*10+6=26, yes=10+6=16`；节点 1 汇总后根节点 0 得 `no=2+min(...)`，最终 `min=23`。

```python
def dfs(u, p):
    no = cnt[u] * price[u]
    yes = no // 2
    for v in adj[u]:
        if v == p: continue
        c_no, c_yes = dfs(v, u)
        no += min(c_no, c_yes)
        yes += c_no
    return no, yes
```

路径统计用 `parent` 数组从 start 回溯到 end 即可，n≤50 直接暴力。

## 复杂度
时间：每条 trip 找路径 O(n)，共 O(len(trips)·n)，树形 DP O(n)。
空间：`cnt`、`adj`、递归栈各 O(n)，路径 BFS 队列 O(n)。

## 易错点
- 节点 0 只在 trip1 出现，若把 `cnt` 初始化成全 1 或漏统计某条 trip，示例 1 会算成 `cnt[0]=3`，根节点贡献从 2 变 6，答案偏大。必须对每条 trip 单独回溯路径累加。
- 选 u 减半时子节点强制不能选，写成 `yes += min(c_no, c_yes)` 会让示例 1 节点 2 的 `yes` 从 16 变 22，因为错误地允许了子节点 3 也减半（相邻冲突）。正确是 `yes += c_no`。

## 如果面试官追问
若 trips 规模涨到 1e5 且 n 也到 1e5，怎么做？答：用树上差分，每条 trip 在 `start`、`end` 处 +1、`lca` 处 -1、`parent(lca)` 处 -1，一次 DFS 前缀和得到 `cnt`，总复杂度 O((n+m)log n)。
