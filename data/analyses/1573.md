## 一句话思路
数 1 的总数，若不能被 3 整除直接返回 0；否则用「第二段起点可选数 × 第三段起点可选数」计数。

## 怎么做
1. 统计 `s.count('1')` 记为 `total`；`total % 3 != 0` 时返回 0（如 `"1001"`，`total=2`）。
2. `total == 0` 时全是 0，答案是 `(n-1)*(n-2)//2`（`"0000"` 得 3）。
3. 否则每段需 `k = total // 3` 个 1。找到第 `k` 个 1 的位置 `p1`、第 `k+1` 个 1 的位置 `p2`、第 `2k` 个 1 的位置 `p3`、第 `2k+1` 个 1 的位置 `p4`。
4. 第一刀可在 `p1..p2-1` 之间任意位置切（共 `p2-p1` 种），第二刀在 `p3..p4-1` 之间（共 `p4-p3` 种），两刀独立，乘积即答案。

以 `"10101"` 为例：`total=3`，`k=1`。1 的下标是 `[0,2,4]`，所以 `p1=0, p2=2, p3=2, p4=4`。第一刀可选 `{0,1}` 共 2 种，第二刀可选 `{2,3}` 共 2 种，`2*2=4`，与示例一致。

```python
MOD = 10**9 + 7
n = len(s)
total = s.count('1')
if total % 3:
    return 0
if total == 0:
    return (n - 1) * (n - 2) // 2 % MOD
k = total // 3
pos = [i for i, c in enumerate(s) if c == '1']
p1, p2 = pos[k - 1], pos[k]
p3, p4 = pos[2 * k - 1], pos[2 * k]
return (p2 - p1) * (p4 - p3) % MOD
```

## 复杂度
时间 O(n)：`count` 和一次扫描建 `pos` 各扫一遍，n 是串长。
空间 O(n)：`pos` 存了全部 1 的下标；只存 4 个位置可降到 O(1)。

## 易错点
- 输入 `"0000"` → 若走通用分支，`pos` 为空、`pos[k-1]` 直接越界 → 必须先单独处理 `total == 0`，返回 `(n-1)*(n-2)//2`，这里 n=4 得 3。
- 输入 `"10101"` → 若把第一刀范围写成 `p1..p2`（含 `p2`），会把 `"101|0|1"` 这种第二段 0 个 1 的切法算进去，得 6 而非 4 → 右端必须开区间，用 `p2 - p1` 而不是 `p2 - p1 + 1`。

## 如果面试官追问
问：要求输出所有具体分割方案怎么办？
答：两刀位置各是一段连续区间，双重循环枚举 `i in [p1,p2)`、`j in [p3,p4)` 即可，方案数本身可能到 O(n²)。
