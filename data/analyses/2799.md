## 一句话思路
用滑动窗口维护「窗口内不同元素数 == 全数组不同元素数」的右端点集合，对每个左端点累加合法右端点个数。

## 怎么做
1. 先求全数组不同元素个数 `need = len(set(nums))`。
2. 右指针 `r` 从 0 扫到 n-1，把 `nums[r]` 计入窗口计数 `cnt`。
3. 当 `len(cnt) == need` 时，说明从当前 `l` 到 `r` 已完全，且 `r` 到末尾都合法，答案加 `n - r`；随后收缩左端 `nums[l]`，`l += 1`，直到窗口不再完全。
4. 重复直到 `r` 到末尾。

以 `nums = [1,3,1,2,2]` 为例，`need = 3`。`r=3` 时窗口 `[1,3,1,2]` 的 `cnt` 有 3 个键，`len(cnt)==3`，答案加 `5-3=2`（对应 `[1,3,1,2]`、`[1,3,1,2,2]`）；收缩 `l=0` 后窗口 `[3,1,2]` 仍完全，答案再加 `5-3=2`（对应 `[3,1,2]`、`[3,1,2,2]`）；再收缩 `l=1` 后窗口 `[1,2]` 只有 2 个键，停止。总计 4。

```python
need = len(set(nums))
cnt, l, ans = {}, 0, 0
for r, x in enumerate(nums):
    cnt[x] = cnt.get(x, 0) + 1
    while len(cnt) == need:
        ans += len(nums) - r
        y = nums[l]
        cnt[y] -= 1
        if cnt[y] == 0:
            del cnt[y]
        l += 1
```

## 复杂度
时间 O(n)：`r` 和 `l` 各前进至多 n 次，哈希表操作均摊 O(1)。
空间 O(k)：`cnt` 最多存 `need` 个键，k 为不同元素个数，≤ n。

## 易错点
- 收缩时只做 `cnt[y] -= 1` 而不删零值键：`nums = [5,5,5,5]` 中 `cnt[5]` 减到 0 后 `len(cnt)` 仍为 1，`while` 永不退出，死循环。必须在计数归零时 `del cnt[y]`。
- 把 `ans += 1` 而不是 `ans += n - r`：`nums = [1,3,1,2,2]` 在 `r=3` 只记 1 个，漏掉 `[1,3,1,2,2]` 这类右端延长的子数组，正确答案 4 会算成 2。固定左端点时，所有 `r' >= r` 都合法，一次加 `n - r`。

## 如果面试官追问
若 `nums[i]` 范围放大到 10^9 且 n 到 10^5，做法变吗？不变，哈希表按值存键，与值域无关，仍是 O(n) 时间、O(k) 空间。
