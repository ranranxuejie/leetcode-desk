## 一句话思路
用哈希表统计较短数组的元素频次，再遍历另一个数组逐个消耗计数，命中即收集。

## 怎么做
1. 若 `len(nums1) > len(nums2)`，交换两者，保证 `nums1` 是较短的那个。
2. 用 `Counter(nums1)` 建频次表 `cnt`。
3. 遍历 `nums2`，若 `cnt[x] > 0` 则把 `x` 加入结果并把 `cnt[x]` 减一。
4. 返回结果列表。

以示例 2 为例：`nums1 = [4,9,5]` 较短，`cnt = {4:1, 9:1, 5:1}`。遍历 `nums2 = [9,4,9,8,4]`：`9` 命中，`cnt[9]` 变 0；`4` 命中，`cnt[4]` 变 0；第二个 `9` 时 `cnt[9] == 0` 被跳过；`8` 不在表中跳过；第二个 `4` 时 `cnt[4] == 0` 被跳过。结果 `[9,4]`。

```python
from collections import Counter

def intersect(nums1, nums2):
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1
    cnt = Counter(nums1)
    res = []
    for x in nums2:
        if cnt[x] > 0:
            res.append(x)
            cnt[x] -= 1
    return res
```

关键在 `cnt[x] -= 1`：它让 `[2,2]` 这种重复元素被消耗两次，而 `[4,9,5]` 里每个只出现一次的元素最多贡献一次。

## 复杂度
时间：O(m + n)，m、n 分别是两数组长度，建表与遍历各扫一遍。
空间：O(min(m, n))，`cnt` 只装较短数组的去重元素。

## 易错点
- 输入 `nums1 = [1,2,2,1], nums2 = [2,2]` → 若用 `set` 求交集会得到 `[2]`，丢掉重复次数 → 必须用 `Counter` 计数并在命中后 `cnt[x] -= 1`。
- 输入 `nums1 = [3,1,2], nums2 = [1,1]` → 若忘记判断 `cnt[x] > 0` 而直接 `if x in cnt`，会把第二个 `1` 也收进去得到 `[1,1]`，但 `nums1` 里 `1` 只出现一次 → 正确结果是 `[1]`，靠 `cnt[x] > 0` 拦住。

## 如果面试官追问
问：数组已排序怎么优化？
答：双指针 `i`、`j` 同步后移，相等就收集并同时前进，否则移动较小者，时间 O(m+n)、额外空间 O(1)。
