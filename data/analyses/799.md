## 一句话思路
逐行滚动数组模拟溢出：每杯先扣满 1，剩余量对半分给下一行左右两杯。

## 怎么做
1. 用长度 `query_row+1` 的数组 `dp` 表示当前行各杯的**总量**（含已满的 1），初始 `dp[0] = poured`。
2. 对第 `r` 行（`r` 从 0 到 `query_row-1`），把每杯超出 1 的部分 `(dp[j]-1)/2` 加到下一行 `j` 和 `j+1`。
3. 只算到 `query_row` 就停，最后返回 `min(dp[query_glass], 1.0)`。

以 `poured=2, query_row=1, query_glass=1` 为例：`dp=[2]`；第 0 行溢出 `(2-1)/2=0.5`，下一行 `dp=[0.5, 0.5]`；返回 `min(0.5,1.0)=0.5`。

```python
dp = [0.0] * (query_row + 1)
dp[0] = poured
for r in range(query_row):
    for j in range(r, -1, -1):          # 倒序，避免覆盖本行未处理值
        over = (dp[j] - 1) / 2
        if over > 0:
            dp[j + 1] += over
            dp[j] = over
        else:
            dp[j] = 0.0
return min(dp[query_glass], 1.0)
```

注意倒序遍历：`dp[j+1]` 是本行还没处理的位置，正序会把刚加进去的溢出量再算一遍。

## 复杂度
时间：`O(query_row^2)`，两层循环共约 `query_row*(query_row+1)/2` 次，`query_row<100`。
空间：`O(query_row)`，只开一个长度 `query_row+1` 的 `dp`，无二维表。

## 易错点
- `poured=0` 或 `poured=1, query_row=1` → 若直接返回 `dp[query_glass]` 而不截断，可能拿到 0 或负数；正确做法是 `min(dp[query_glass], 1.0)`，且溢出量 `over<=0` 时置 0，别把负值往下传。
- `poured=100000009, query_row=33` → 若用二维数组存全部 100 行会白算 67 行；正确做法是只迭代到 `query_row`，且 `poured` 是 `10^9` 量级，Python 浮点足够，但别用整数除法 `//` 把 0.5 截成 0。

## 如果面试官追问
问：如果 `query_row` 放大到 `10^4` 怎么办？
答：`O(n^2)` 会超时，可只保留目标杯所在路径上的贡献，或用前缀和/闭式递推降维。
