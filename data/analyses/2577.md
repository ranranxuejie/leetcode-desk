## 一句话思路
用 Dijkstra（堆）按到达时间从小到大扩展，因为「等待」让边权不再是 1，普通 BFS 的层序不再等于时间序。

## 怎么做
1. 起点 `(0,0)` 时间 0 入堆，`dist` 用二维数组初始化为 `2**31 - 1`。
2. 弹出 `(t, r, c)`，若 `t > dist[r][c]` 跳过；到 `(m-1,n-1)` 直接返回 `t`。
3. 对每个邻居 `(nr,nc)`，算到达时间：`nt = t + 1`，若 `nt < grid[nr][nc]` 则要等，且因为不能停留，等待必须凑成与 `nt` 同奇偶的最近值。
4. 松弛成功就更新 `dist` 并入堆。

关键中间值：示例 1 从 `(1,1)` 时间 2 走向 `(1,2)`，`nt = 3`，`grid[1][2] = 2 <= 3`，不等待，直接 `dist[1][2] = 3`；而若目标是 `grid = 8` 的 `(2,2)`，从时间 3 出发 `nt = 4 < 8`，需等到 `8`（4 与 8 同偶），得 `nt = 8` 而非 9。

```python
import heapq
INF = 2**31 - 1
dist = [[INF] * n for _ in range(m)]
dist[0][0] = 0
pq = [(0, 0, 0)]
while pq:
    t, r, c = heapq.heappop(pq)
    if t > dist[r][c]:
        continue
    if r == m - 1 and c == n - 1:
        return t
    for nr, nc in ((r+1,c),(r-1,c),(r,c+1),(r,c-1)):
        if 0 <= nr < m and 0 <= nc < n:
            nt = t + 1
            if nt < grid[nr][nc]:
                nt = grid[nr][nc] + (grid[nr][nc] - nt) % 2
            if nt < dist[nr][nc]:
                dist[nr][nc] = nt
                heapq.heappush(pq, (nt, nr, nc))
return -1
```

## 复杂度
时间：O(m·n·log(m·n))，堆里最多 O(m·n) 条记录，每次 push/pop 是 log。
空间：O(m·n)，`dist` 二维表加堆，堆最坏存 O(m·n) 个三元组。

## 易错点
- 等待公式写成 `nt = grid[nr][nc]` 直接赋值 → 对 `grid=8`、`nt=3` 会得到 8，但 3 与 8 奇偶不同，实际走不到（每步必花 1 时间，奇偶性固定），正确是 `grid + (grid - nt) % 2`，得 9。
- 用普通 BFS 按步数分层 → 示例 1 中 `(1,1)` 会被 2 步到达，但绕行 `(1,1)→(1,2)→(1,1)` 让时间涨到 4 仍是合法路径，BFS 只记最短步数会漏掉「等待后更优」的到达时刻，必须用 Dijkstra 按时间排序。

## 如果面试官追问
问：若要求输出具体路径怎么办？
答：在松弛时额外记 `parent[nr][nc] = (r,c)`，到达终点后从 `(m-1,n-1)` 回溯即可，等待步数按奇偶补成往返。
