## 一句话思路
把 s 按中点切成 a、b 两段，各自数元音个数再比较是否相等。

## 怎么做
1. 取 `mid = len(s) // 2`，得到 `a = s[:mid]`、`b = s[mid:]`。
2. 用一个集合 `vowels = set("aeiouAEIOU")` 做 O(1) 判定，避免写 10 个 `or`。
3. 分别对 a、b 求和 `sum(c in vowels for c in ...)`，直接比较两个整数。
4. 相等返回 `True`，否则 `False`。

以 `s = "textbook"` 为例：`len(s) = 8`，`mid = 4`，所以 `a = "text"`、`b = "book"`。对 a 求和时只有 `'e'` 命中，得 1；对 b 求和时 `'o'` 出现两次都命中，得 2。`1 != 2`，返回 `False`——注意 `'o'` 是计次不是计种类，这正是示例 2 与示例 1 的分水岭。

```python
vowels = set("aeiouAEIOU")
mid = len(s) // 2
a, b = s[:mid], s[mid:]
ca = sum(c in vowels for c in a)
cb = sum(c in vowels for c in b)
return ca == cb
```

`c in vowels` 返回布尔值，Python 里 `True == 1`，所以 `sum` 直接累加计数，不需要 `if` 分支。切片 `s[:mid]` 和 `s[mid:]` 各占一半，长度都是 `mid`，因为题目保证 `len(s)` 是偶数，不会出现中点落在字符中间的问题。

## 复杂度
时间 O(n)：n 是 `len(s)`，两半各扫一遍，总共每个字符访问一次。
空间 O(1)：`vowels` 固定 10 个元素，切片 a、b 合计 O(n) 但可省去，用下标遍历则无额外空间。

## 易错点
- 输入 `s = "book"` 时若只判断「两半是否含相同元音种类」，会错成比较集合 `{'o'} == {'o'}` 而漏掉计数语义；正确做法是累加次数，`"textbook"` 的 b 段 `'o'` 计 2 次才能暴露差异。
- 输入含大写如 `s = "AbCd"` 时若只写 `set("aeiou")`，`'A'` 会被漏数，导致 `ca` 偏小、误判为不相似；正确做法是集合里同时放 `"aeiouAEIOU"` 十个字符，或先 `s.lower()` 再数。

## 如果面试官追问
问：若要求返回两半元音的具体位置而非布尔值？
答：遍历时记录 `(index, char)` 到两个列表，最后比较长度并返回列表，时间仍是 O(n)。
