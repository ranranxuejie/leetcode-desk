## 一句话思路
用 26 位掩码表示路径字符奇偶性，树剖 + 线段树维护区间异或，路径查询看 popcount 是否 ≤1。

## 怎么做
1. 每个节点字符 `s[u]` 映射成 `1 << (ord(s[u]) - 97)`，路径可重排成回文 ⟺ 路径上所有掩码异或后 popcount ≤ 1（至多一个字符出现奇数次）。
2. 树剖把路径拆成 O(log n) 段连续区间，线段树每个节点存区间异或和，`update` 是单点改，`query` 是区间异或。
3. 路径 u→v 的异或值 = 根到 u 的异或 ⊕ 根到 v 的异或 ⊕ 掩码(lca)，但树剖下直接沿链累加更省事：`res ^= seg.query(...)` 逐段合并。

以示例 1 为例：`s = "aac"`，掩码为 `a=1, a=1, c=4`。查询 `0→2` 路径异或 `1^1^4 = 4`，popcount=1，返回 `True`。`update 1 b` 后节点 1 掩码变 `2`，路径异或 `1^2^4 = 7`，popcount=3，返回 `False`。

```python
def path_xor(u, v):
    res = 0
    while top[u] != top[v]:
        if dep[top[u]] < dep[top[v]]:
            u, v = v, u
        res ^= seg_query(pos[top[u]], pos[u])
        u = fa[top[u]]
    if dep[u] > dep[v]:
        u, v = v, u
    res ^= seg_query(pos[u], pos[v])
    return res

# 查询判定
ans.append(path_xor(u, v).bit_count() <= 1)
```

## 复杂度
时间：预处理 O(n)，每次 update/query 树剖 O(log n) 段 × 线段树 O(log n) = O(log² n)。
空间：邻接表 + 树剖数组 + 线段树 4n，共 O(n)。

## 易错点
- 路径异或写成「根到 u ⊕ 根到 v」会漏掉 LCA 节点本身（被异或两次抵消），示例 1 中 `0→2` 会得 `1^1^4^1 = 5` 而非 `4`，popcount 仍为 2 判错；正确做法是树剖逐段累加，或额外 `^ mask[lca]`。
- `update` 时只改 `s[u]` 忘了同步线段树叶子，后续查询仍用旧掩码；正确做法是 `seg_update(pos[u], 1 << (ord(c)-97))` 并更新 `s[u] = c`。

## 如果面试官追问
若 n、queries 都到 2×10^5 且要求 O(log n) 单次查询？答：改用欧拉序 + 前缀异或 + LCA，配合树状数组做单点更新区间查询，把 log² 降到 log。
