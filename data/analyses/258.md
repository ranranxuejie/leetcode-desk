## 一句话思路
用同余性质：十进制数与其各位数字和对 9 同余，答案就是 `num % 9`（0 映射为 9，num=0 除外）。

## 怎么做
1. 先处理边界：`num == 0` 直接返回 0。
2. 取 `r = num % 9`，这是数根在 1..8 或 0 上的落点。
3. 若 `r == 0` 说明数根是 9（因为 num>0 且被 9 整除），返回 9；否则返回 `r`。

以 `num = 38` 为例：`38 % 9 = 2`，非 0，直接返回 2，与逐步相加 `38→11→2` 一致。再以 `num = 18` 为例：`18 % 9 = 0`，返回 9，验证 `18→9` 正确。

```python
def add_digits(num: int) -> int:
    if num == 0:
        return 0
    r = num % 9
    return 9 if r == 0 else r
```

等价写法 `1 + (num - 1) % 9` 对 `num=0` 会返回 0，也可一行搞定，但可读性差些。

## 复杂度
时间：O(1)，只做一次取模和一次比较，与 num 的位数无关。
空间：O(1)，没有开任何额外容器。

## 易错点
- 输入 `num = 0` → 若直接写 `num % 9` 会返回 0，看似对，但若写成 `1 + (num-1) % 9` 会得到 0 之外的错误值（Python 中 `(0-1)%9 = 8`，结果 9）→ 正确做法是先判 `num == 0` 返回 0。
- 输入 `num = 9` 或 `num = 18` → 若只写 `num % 9` 会返回 0，而正确答案是 9 → 正确做法是 `r == 0` 时返回 9（num>0 前提下）。

## 如果面试官追问
问：不用取模，怎么 O(1) 做？答：用 `num - 9 * ((num - 1) // 9)`（num>0），本质还是同余，只是把 `%` 展开成整除。
