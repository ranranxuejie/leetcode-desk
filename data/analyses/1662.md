## 一句话思路
把两个数组各自 `"".join()` 成完整字符串再比较，长度不等直接 False。

## 怎么做
1. 用 `"".join(word1)` 和 `"".join(word2)` 拼出两个完整串。
2. 先比长度，不等立刻返回 `False`，省掉逐字符比较。
3. 长度相等时直接 `==` 比较，Python 内部逐字符短路。

以示例 1 为例：`"".join(["ab","c"])` 得到 `"abc"`，`"".join(["a","bc"])` 也得到 `"abc"`，两者长度都是 3 且逐位相等，返回 `True`。示例 2 拼出 `"acb"` 和 `"abc"`，长度同为 3，但第 2 位 `'c' != 'b'`，返回 `False`。

```python
s1 = "".join(word1)
s2 = "".join(word2)
if len(s1) != len(s2):
    return False
return s1 == s2
```

关键中间值就是 `s1`、`s2` 这两个拼接结果：示例 1 里它们都是 `"abc"`；示例 3 里 `s1 = "abc" + "d" + "defg" = "abcddefg"`，`s2 = "abcddefg"`，相等返回 `True`。

## 复杂度
时间 O(n)，n 为两数组字符总数，拼接和比较各扫一遍。
空间 O(n)，额外开了 `s1`、`s2` 两个拼接串。

## 易错点
- 只比 `word1 == word2`（数组逐元素比较）→ 示例 1 会错成 `False`，因为 `["ab","c"] != ["a","bc"]`；必须先 join 成字符串再比。
- 用 `" ".join` 或带分隔符拼接 → 示例 1 得到 `"ab c"` 与 `"a bc"`，长度都变 5 却仍不等，示例 3 也会被分隔符污染；必须用空串 `""` 作分隔符。

## 如果面试官追问
追问：不允许额外 O(n) 空间怎么办？
答：用双指针分别遍历两个数组的当前词和词内下标，逐字符比对，空间降到 O(1)。
