## 一句话思路
先求 numsDivide 全体元素的最大公约数 g，再在 nums 中找最小的能整除 g 的元素，删掉所有比它小的数。

## 怎么做
1. 用 `math.gcd` 对 numsDivide 做一次折叠，得到 `g`；因为 x 整除所有元素 ⟺ x 整除它们的 gcd。
2. 对 nums 升序排序，从左往右找第一个满足 `g % x == 0` 的元素。
3. 找到就返回它的下标（下标即「比它小的元素个数」，也就是删除次数）；扫完没找到返回 -1。

以示例 1 为例：`numsDivide = [9,6,9,3,15]`，折叠得 `g = gcd(9,6)=3, gcd(3,9)=3, gcd(3,3)=3, gcd(3,15)=3`，即 `g = 3`。排序后 `nums = [2,2,3,3,4]`，`3 % 2 != 0` 跳过，`3 % 3 == 0` 命中，下标 2，返回 2。

```python
from math import gcd
from functools import reduce

g = reduce(gcd, numsDivide)
nums.sort()
for i, x in enumerate(nums):
    if g % x == 0:
        return i
return -1
```

注意判断方向是 `g % x`，不是 `x % g`：要的是「nums 的最小元素整除 numsDivide 的所有元素」，即 x 是 g 的约数。

## 复杂度
时间 O(m + n log n)：m 为 numsDivide 长度（求 gcd），n log n 来自 nums 排序。
空间 O(1) 额外（排序原地，不计输入）。

## 易错点
- 把判断写成 `x % g == 0`：示例 1 中 `g = 3`，`3 % 3 == 0` 恰好也对，但示例 2 里 `g = gcd(8,2,6,10) = 2`，`nums = [4,3,6]` 排序后 `4 % 2 == 0` 会误判返回 0，正确答案是 -1。正确写法是 `g % x == 0`。
- 只拿 `numsDivide[0]` 当除数：`numsDivide = [9,6,9,3,15]` 时用 9 会漏掉 3 这个合法答案，返回 -1。必须先折叠成全体 gcd。

## 如果面试官追问
问：如果要求输出删除后剩下的数组，怎么做？
答：命中下标 i 后返回 `nums[i:]` 即可，因为排序后所有 ≥ nums[i] 的元素都保留，最小元素仍是 nums[i]。
