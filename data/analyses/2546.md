## 一句话思路
操作本质是「把 1 搬到别处」，所以只需比较 s 与 target 中 1 的个数是否同为零或同为正。

## 怎么做
1. 先看 s 和 target 是否完全相等，相等直接返回 `True`（此时无需任何操作）。
2. 统计 s 中 `'1'` 的个数 `cs`，target 中 `'1'` 的个数 `ct`。
3. 若 `cs == 0 or ct == 0`，说明有一方全是 0，而操作无法凭空造出 1，返回 `cs == ct`。
4. 否则两边都至少有一个 1，返回 `True`。

以 `s = "1010", target = "0110"` 为例：`cs = 2`，`ct = 2`，两者都非零，直接返回 `True`。中间关键值是 `cs` 与 `ct` 都等于 2——只要都 ≥1，1 就能在任意位置间搬运，具体位置无关。

```python
def makeStringsEqual(s: str, target: str) -> bool:
    if s == target:
        return True
    cs = s.count('1')
    ct = target.count('1')
    if cs == 0 or ct == 0:
        return cs == ct
    return True
```

为什么「都 ≥1 就够」：对 `(i, j)` 操作，`(0,1) → (1,1)`、`(1,0) → (1,1)`、`(1,1) → (1,0)`，即一个 1 可以复制到 0 位，也可以把两个 1 消成一个。只要存在一个 1，就能把它复制到任意 0 位，再消掉多余的 1，从而凑出 target 的任意 1 分布。

## 复杂度
时间 O(n)：`count` 与字符串比较各扫一遍，n 为串长。
空间 O(1)：只用了 `cs`、`ct` 两个整数。

## 易错点
- 输入 `s = "11", target = "00"` → 若只判断「两边 1 的个数都 ≥1 就 True」会漏掉 target 全 0 的情况，错答 `True`；正确做法是先判 `ct == 0`，此时只有 `cs == 0` 才成立，返回 `False`。
- 输入 `s = "00", target = "11"` → 若只看 `cs > 0 and ct > 0` 会因 `cs == 0` 短路，但若写成 `cs != 0 or ct != 0` 就错答 `True`；正确做法是「任一方为 0 时要求 `cs == ct`」，即两边必须同为 0。

## 如果面试官追问
问：若要求输出具体操作序列怎么办？
答：先找一个 1 作「源」，用它把 target 需要 1 的位置逐个 OR 成 1，再把 target 为 0 的多余 1 与源 XOR 消掉，每步 O(1) 记录即可。
