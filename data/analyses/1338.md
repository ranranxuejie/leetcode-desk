## 一句话思路
统计每个数的出现次数，按频次从大到小贪心累加，累加到 ≥ n/2 时的个数就是答案。

## 怎么做
1. 用 `Counter(arr)` 得到每个值的频次，记 `need = len(arr) // 2`。
2. 把频次降序排序，因为删一个数能删掉的就是它的全部频次，先挑大的必然不劣。
3. 从大到小累加，累加值首次 ≥ `need` 时返回已选的个数。

以 `arr = [3,3,3,3,5,5,5,2,2,7]` 为例：频次为 `{3:4, 5:3, 2:2, 7:1}`，`need = 5`；降序 `[4,3,2,1]`，累加 `4` 不够，`4+3=7 ≥ 5`，返回 `2`。

```python
from collections import Counter

def minSetSize(arr):
    need = len(arr) // 2
    freq = sorted(Counter(arr).values(), reverse=True)
    total = 0
    for i, f in enumerate(freq, 1):
        total += f
        if total >= need:
            return i
    return len(freq)
```

关键点：`total >= need` 用 `>=` 而不是 `>`，因为恰好删掉一半也满足「至少一半」。

## 复杂度
时间 O(n + k log k)，n 是数组长度用于计数，k 是不同值个数用于排序。
空间 O(k)，Counter 和排序后的频次列表各占 k。

## 易错点
- 输入 `arr = [7,7,7,7,7,7]`：若把 `need` 写成 `len(arr) / 2` 得到浮点 `3.0`，比较虽仍成立，但若误写成 `len(arr) // 2 + 1` 就会多算一个数返回 2；正确是 `need = 3`，第一个频次 6 ≥ 3 直接返回 1。
- 输入 `arr = [1,1,2,2,3,3]`：频次 `[2,2,2]`，`need = 3`；若循环里用 `total > need` 判断，累加到 4 才停，返回 2，而正确答案是 2 恰好对——但换成 `arr = [1,1,1,2,2,3]`（频次 `[3,2,1]`，need=3）用 `>` 会返回 2，正确是 1。必须用 `>=`。

## 如果面试官追问
要求输出具体选了哪些数怎么办？
答：排序时保留 `(频次, 值)` 对，累加时把对应的值收集进结果列表即可，复杂度不变。
