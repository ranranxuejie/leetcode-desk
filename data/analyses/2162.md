## 一句话思路
枚举分钟数 m（0..99），秒数 s = targetSeconds - 60m 必须落在 0..99，对每个合法 (m,s) 算代价取最小。

## 怎么做
1. 枚举 m 从 0 到 99，令 s = targetSeconds - 60*m，只保留 0 ≤ s ≤ 99 的组合。
2. 把 m、s 拼成字符串：m 非 0 时是 `str(m)+str(s).zfill(2)`，m 为 0 时是 `str(s)`，再 `lstrip('0')` 去掉前导零（全零则保留一个 `'0'`）。
3. 对每个数字串逐位累加：第一位若等于 startAt 只付 pushCost，否则付 moveCost + pushCost；后续位与上一位比较。
4. 取所有合法组合的最小值。

以 `startAt=1, moveCost=2, pushCost=1, targetSeconds=600` 为例：m=10,s=0 得串 `"1000"`，首位 `'1'` 等于 startAt，代价 1；后三位都是 `'0'`，每位 2+1=3，合计 1+3*3=10？不对——首位后移到 0 只算一次移动：`'1'→'0'` 付 2+1，后两个 `'0'` 各付 1，总 1+3+1+1=6。m=9,s=60 得串 `"960"`，首位 `'9'`≠1 付 3，`'9'→'6'` 付 3，`'6'→'0'` 付 3，共 9。

```python
best = float('inf')
for m in range(100):
    s = targetSeconds - 60 * m
    if not (0 <= s <= 99):
        continue
    t = (str(m) + str(s).zfill(2)) if m else str(s)
    t = t.lstrip('0') or '0'
    cost, prev = 0, str(startAt)
    for ch in t:
        if ch != prev:
            cost += moveCost
        cost += pushCost
        prev = ch
    best = min(best, cost)
```

## 复杂度
时间：O(100 × 4)，枚举 100 个 m，每个串最多 4 位。
空间：O(1)，只存当前串和 best。

## 易错点
- `targetSeconds=600` 时只想到 m=10,s=0，漏掉 m=9,s=60 这个同样合法的写法（s=60 未超 99），会错成 10 而非 6；必须让 s 独立校验 0..99，不能假设 s<60。
- `targetSeconds=76` 时若把 m=0 的串写成 `"0076"` 而不 `lstrip('0')`，会多算两个前导 0 的 pushCost（多 4），错成 10 而非 6；m=0 分支必须走 `str(s)` 并去前导零。

## 如果面试官追问
问：若允许秒数上限改成 999 怎么办？答：枚举 m 的上界改为 `targetSeconds//60`，s 校验区间改 0..999，其余逻辑不变。
