## 一句话思路
把每个单词的所有「后缀 + 分隔符 + 前缀」拼成键存进哈希表，值取最大下标，查询时 O(1) 拼键直接查。

## 怎么做
1. 预处理：对每个 `words[i]`，枚举所有后缀起点 `j` 和前缀终点 `k`，拼出键 `words[i][j:] + '#' + words[i][:k]`。
2. 键写入字典 `d`，值直接覆盖为 `i`，因为 `i` 递增，最后留下的就是最大下标。
3. 查询 `f(pref, suff)` 时拼 `suff + '#' + pref`，`d.get(key, -1)` 返回。
4. 用 `'#'` 做分隔符，因为输入只有小写字母，不会与单词内容冲突。

以 `words = ["apple"]`、`f("a", "e")` 为例：预处理时 `i=0`，`j=4` 得后缀 `"e"`，`k=1` 得前缀 `"a"`，键为 `"e#a"`，`d["e#a"] = 0`；查询拼出 `"e#a"`，命中返回 `0`。

```python
d = {}
for i, w in enumerate(words):
    n = len(w)
    for j in range(n):
        for k in range(1, n + 1):
            d[w[j:] + '#' + w[:k]] = i

def f(pref, suff):
    return d.get(suff + '#' + pref, -1)
```

注意 `k` 从 1 开始，因为 `pref.length >= 1`，空前缀不会出现在查询里；`j` 从 0 开始，因为后缀可以等于整个单词（`suff` 长度可达 7，可能等于 `words[i]`）。

## 复杂度
时间：预处理 O(Σ|w|²) 即每个词最多 7×7=49 次拼接，查询 O(|pref|+|suff|) 拼键加哈希。
空间：字典存 Σ|w|² 个键，每个键长 ≤ 15，即 O(Σ|w|²·|w|) 字符。

## 易错点
- `words = ["apple","apple"]` 时若写成 `if key not in d` 才写入，`"e#a"` 会停在 `0`，`f("a","e")` 错答 `0`；正确做法是无条件 `d[key] = i`，让后出现的下标覆盖。
- `words = ["a"]`、`f("a","a")` 时若 `k` 从 0 开始，会多存 `"a#"` 这类空前缀键，浪费空间且与 `pref` 最短为 1 的约束不符；正确做法是 `range(1, n+1)`，同时 `j` 必须从 0 开始才能覆盖 `suff` 等于整词的情况。

## 如果面试官追问
若 `words[i].length` 放宽到 10³，这套 O(|w|²) 预处理会爆，怎么办？答：改用前缀树存前缀、反向前缀树存后缀，查询时取两个下标集合的交集最大值。
