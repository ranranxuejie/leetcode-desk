## 一句话思路
用 `dp[i] = dp[i >> 1] + (i & 1)` 递推：右移一位去掉最低位，1 的个数只差最低位本身。

## 怎么做
1. 开长度 `n + 1` 的数组 `dp`，`dp[0] = 0`。
2. 从 `i = 1` 遍历到 `n`，每个 `i` 用 `dp[i >> 1]` 加 `i & 1`。
3. 返回 `dp`。

以 `n = 5` 为例，关键中间值：`i = 4` 时 `i >> 1 = 2`，`dp[2] = 1`，`i & 1 = 0`，得 `dp[4] = 1`；`i = 5` 时 `i >> 1 = 2`，`dp[2] = 1`，`i & 1 = 1`，得 `dp[5] = 2`。最终 `[0,1,1,2,1,2]`。

```python
dp = [0] * (n + 1)
for i in range(1, n + 1):
    dp[i] = dp[i >> 1] + (i & 1)
return dp
```

`i >> 1` 一定小于 `i`，所以递推时 `dp[i >> 1]` 已经算好，一趟扫描即可。

## 复杂度
时间 O(n)：`i` 从 1 到 `n` 各做一次移位和与运算，常数时间。
空间 O(n)：`dp` 数组长度 `n + 1`，除此之外只用了 `i` 一个临时变量。

## 易错点
- `n = 0` → 若循环写成 `range(1, n)` 或忘记 `dp[0]`，会返回空数组或越界；正确做法是数组长度取 `n + 1`，`dp[0]` 天然为 0，循环从 1 到 `n` 闭区间。
- 用 `dp[i] = dp[i - 1] + 1` 这类错误递推 → 在 `i = 2`（二进制 `10`）会得 2，实际应为 1；正确做法是必须按 `i >> 1` 去掉最低位，只有 `i & 1` 为 1 时才加 1。

## 如果面试官追问
追问：不用 `dp` 数组、只允许 O(1) 额外空间怎么做？
答：做不到，输出本身就要 O(n) 空间；能省的只是除返回数组外的辅助空间，本解法已经只用了返回数组。
