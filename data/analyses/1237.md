## 一句话思路
固定 x 从 1 递增，y 从 z 递减，利用 f 对 y 单调递增做双指针夹逼，一次扫描出全部解。

## 怎么做
1. 令 `x = 1`、`y = z`，因为正整数解里 `f(1, y) ≤ z` 时 `y` 最大不超过 `z`（`f` 至少随 y 增长，取 `f(x,y) ≥ y` 的常见实现，保守取 `y = z` 起步）。
2. 循环条件 `x <= z and y >= 1`，每轮算 `v = customfunction.f(x, y)`。
3. `v == z` 时记录 `[x, y]`，同时 `x += 1`、`y -= 1`；`v < z` 说明 x 太小，`x += 1`；`v > z` 说明 y 太大，`y -= 1`。
4. 循环结束返回结果列表。

以示例 1（`f = x + y`，`z = 5`）走一遍关键几步：初始 `(1,5)` 得 `v=6 > 5`，`y` 减到 4；`(1,4)` 得 `v=5`，记录 `[1,4]` 后变 `(2,3)`；`v=5` 记录 `[2,3]` 后变 `(3,2)`；继续得 `[3,2]`、`[4,1]`，到 `(5,0)` 时 `y < 1` 退出。中间变量 `v` 每次只跟 `z=5` 比大小，方向唯一。

```python
res = []
x, y = 1, z
while x <= z and y >= 1:
    v = customfunction.f(x, y)
    if v == z:
        res.append([x, y])
        x += 1
        y -= 1
    elif v < z:
        x += 1
    else:
        y -= 1
return res
```

## 复杂度
时间：O(z)，x 与 y 各自单调移动，总步数不超过 2z。
空间：O(1) 额外，除结果列表外只存 x、y、v。

## 易错点
- 起始 `y` 取成 `z` 而非更大：若某实现 `f(1, y)` 在 `y = z` 时已大于 `z`，第一轮就 `y -= 1` 是正确收缩，不会漏解；但若把 `y` 初值写成 `1`，则 `f(1,1) < z` 会一路 `x += 1`，永远碰不到 `y` 大的解，示例 1 会漏掉 `[1,4]`。
- `v == z` 时只 `x += 1` 不 `y -= 1`：示例 1 中 `(1,4)` 命中后若只加 x，下一轮 `(2,4)` 得 `v=6 > 5` 再减 y 到 3，虽仍能凑出 `[2,3]`，但多走一步且逻辑依赖巧合；正确做法是命中后两个指针同时动，因为同一 x 下 f 对 y 严格增，同一 y 下对 x 严格增，不会再有第二个解。

## 如果面试官追问
问：若 z 大到 10^9 还能双指针吗？
答：不能线性扫，改为对每个 x 二分查 y，O(z log z) 仍太大，需利用具体 f 形式或解方程。
