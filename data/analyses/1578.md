## 一句话思路
按颜色连续段分组，每段保留 `neededTime` 最大的那个气球，删掉其余，累加删除代价。

## 怎么做
1. 用单指针 `i` 从左扫到右，遇到 `colors[i] == colors[i-1]` 就说明进了同一段。
2. 段内维护 `seg_sum`（该段所有 `neededTime` 之和）和 `seg_max`（该段最大值）。
3. 段结束时把 `seg_sum - seg_max` 累加进答案，因为保留最大值最省。
4. 最后一段在循环外补一次结算。

拿示例 3 `colors = "aabaa"`、`neededTime = [1,2,3,4,1]` 走一遍：第一段是下标 0、1 的 `"aa"`，`seg_sum = 1+2 = 3`，`seg_max = 2`，贡献 `3-2 = 1`；中间 `"b"` 单独成段，贡献 0；最后一段下标 3、4 的 `"aa"`，`seg_sum = 4+1 = 5`，`seg_max = 4`，贡献 `5-4 = 1`。总答案 `1+1 = 2`，与官方一致。

```python
ans = 0
seg_sum = seg_max = neededTime[0]
for i in range(1, len(colors)):
    if colors[i] == colors[i - 1]:
        seg_sum += neededTime[i]
        seg_max = max(seg_max, neededTime[i])
    else:
        ans += seg_sum - seg_max
        seg_sum = seg_max = neededTime[i]
ans += seg_sum - seg_max
```

关键点：`seg_sum - seg_max` 就是「这一段除最大者外全部删掉」的代价，段长 1 时它恒为 0，所以不用特判。

## 复杂度
时间 O(n)：`i` 从 1 扫到 n-1，每步 O(1)。
空间 O(1)：只开了 `ans`、`seg_sum`、`seg_max` 三个变量。

## 易错点
- 输入 `colors = "aaaa"`、`neededTime = [1,2,3,4]` → 若写成「每遇到相同就删前一个」，会删掉 1、2、3 得 6，而正确是删 1、2、3 保留 4 得 6 恰好对，但换成 `[4,3,2,1]` 就会删 4、3、2 得 9，正确是删 3、2、1 得 6。必须段内先比出 `seg_max` 再算差。
- 输入 `colors = "ab"`、`neededTime = [5,7]` → 若在循环里只在「颜色相同」分支累加、忘了段切换时结算，会漏掉第一段；正确做法是每次 `colors[i] != colors[i-1]` 都先 `ans += seg_sum - seg_max` 再重置，循环结束后再补最后一段。

## 如果面试官追问
要求输出具体删除哪些下标怎么办？答：段内记录 `seg_max` 的下标，把该段其余下标全部收集进结果列表，时间仍是 O(n)。
