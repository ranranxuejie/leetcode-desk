## 一句话思路
用一个临时栈把主栈里比待插入元素小的元素倒出来，插完再倒回去，主栈始终从栈顶到栈底递增。

## 怎么做
1. 维护主栈 `st`（栈顶最小）和辅助栈 `tmp`，`push(val)` 时先把 `st` 中所有 `< val` 的元素弹出压入 `tmp`。
2. 把 `val` 压入 `st`，此时 `st` 栈顶是 `val`，下面全是 `>= val` 的元素。
3. 把 `tmp` 里的元素逐个弹回 `st`，恢复栈顶最小的性质。
4. `pop`/`peek`/`isEmpty` 直接操作 `st`，`peek` 空栈返回 `-1`。

以示例 1 为例：先 `push(1)`，`st=[1]`；再 `push(2)`，`st` 中 `1 < 2`，弹出 `1` 到 `tmp`，`st=[2]`，压入 `2` 后 `st=[2,2]`？不对——正确过程是 `st` 弹出 `1` 后为空，压 `2` 得 `st=[2]`，再把 `tmp` 的 `1` 弹回得 `st=[2,1]`（栈顶 `1`）。此时 `peek` 返回 `1`，`pop` 后 `peek` 返回 `2`，与输出一致。

```python
def push(self, val):
    while self.st and self.st[-1] < val:
        self.tmp.append(self.st.pop())
    self.st.append(val)
    while self.tmp:
        self.st.append(self.tmp.pop())

def peek(self):
    return self.st[-1] if self.st else -1
```

关键中间值：`push(2)` 时 `while` 条件 `st[-1]=1 < 2` 成立，`1` 进 `tmp`，插入后 `st=[2]`，回填得 `st=[2,1]`。

## 复杂度
时间：单次 `push` 最坏 O(n)，n 为当前栈内元素数，`pop`/`peek` 为 O(1)。
空间：额外一个 `tmp` 栈，最坏 O(n)。

## 易错点
- 输入 `push(2)` 在已有 `[1]` 的栈上 → 若用 `<=` 而非 `<` 比较，`1` 不会被弹出，`st` 变成 `[1,2]`，`peek` 返回 `2` 而非 `1` → 必须用严格 `<`，相等元素留在下面。
- 输入 `pop`/`peek` 在空栈上 → 直接 `st[-1]` 会抛 `IndexError`，`peek` 应返回 `-1`，`pop` 需先判空 → 所有读操作前加 `if not self.st` 分支。

## 如果面试官追问
追问：元素规模到 10^5 且要求 `push` 均摊 O(1) 怎么办？
答：改用两个栈模拟单调队列思路或换用有序结构，但本题限制只能用栈，故维持 O(n) 最坏、均摊仍可接受。
