## 一句话思路
枚举 a、b 两重循环，用 `isqrt(a*a+b*b)` 反查 c 是否为整数且不超过 n，避免三重循环。

## 怎么做
1. 外层 `a` 从 1 到 n，内层 `b` 从 1 到 n，只枚举前两个数。
2. 对每组 `(a,b)` 算 `s = a*a + b*b`，取 `c = isqrt(s)`。
3. 判定 `c <= n and c*c == s`，成立就 `ans += 1`。

以 n = 5 为例：`a=3, b=4` 时 `s = 9+16 = 25`，`isqrt(25) = 5`，`5*5 == 25` 且 `5 <= 5`，计数加一；`a=4, b=3` 同样命中，得到 2。而 `a=1, b=1` 时 `s=2`，`isqrt(2)=1`，`1*1 != 2`，不计数。

```python
from math import isqrt

ans = 0
for a in range(1, n + 1):
    for b in range(1, n + 1):
        s = a * a + b * b
        c = isqrt(s)
        if c <= n and c * c == s:
            ans += 1
return ans
```

关键点：`isqrt` 返回下取整，必须再用 `c*c == s` 复核，否则 `s=2` 这类非完全平方数会被 `c=1` 误判。`c <= n` 不能省，因为 `a=b=n` 时 `c` 可能超过 n。

## 复杂度
时间：O(n²) 组枚举，每组 O(1) 次 isqrt，n 来自两重循环。
空间：O(1)，只开了 `ans`、`s`、`c` 几个标量。

## 易错点
- 输入 n = 5 → 若只写 `c = isqrt(s)` 不校验 `c*c == s`，`(1,1)` 的 `s=2` 会被当成 `c=1` 计入，答案偏大 → 必须加 `c*c == s`。
- 输入 n = 250 → 若漏掉 `c <= n`，`a=b=250` 时 `s=125000`、`c≈353` 超出范围仍可能被算进 → 判定条件写成 `c <= n and c*c == s`。

## 如果面试官追问
若 n 放大到 10^5，O(n²) 不可行怎么办？答：改用枚举 c 与 a，用 `b² = c² - a²` 反查 b 是否为整数，仍是 O(n²) 但常数更小，或直接生成毕达哥拉斯三元组。
