## 一句话思路
用栈从左到右扫描，新元素与栈顶反复合并（GCD>1 就换成 LCM），因为合并只会让栈顶变大、不会与更早元素产生新冲突。

## 怎么做
1. 建空栈 `st`，遍历 `nums` 中每个 `x`。
2. 若 `st` 非空且 `gcd(st[-1], x) > 1`，弹出栈顶 `y`，令 `x = y // gcd(y, x) * x`（先除后乘，避免中间值无谓变大），回到步骤 2 继续比。
3. 否则把 `x` 压栈。
4. 遍历结束返回 `st`。

以 `nums = [6,4,3,2,7,6,2]` 为例：压 6、压 4 时 `gcd(6,4)=2`，弹出 6 得 `x = 6//2*4 = 12`，栈变 `[12]`；接着 3 与 12 的 `gcd=3`，`x = 12//3*3 = 12`，栈仍 `[12]`；2 与 12 的 `gcd=2`，`x = 12`；7 互质压栈得 `[12,7]`；6 与 7 互质压栈；最后的 2 与 6 的 `gcd=2`，`x = 6//2*2 = 6`，栈顶 6 与 6 的 `gcd=6`，`x = 6//6*6 = 6`，最终 `[12,7,6]`。

```python
from math import gcd
st = []
for x in nums:
    while st and gcd(st[-1], x) > 1:
        y = st.pop()
        x = y // gcd(y, x) * x
    st.append(x)
return st
```

关键点：合并后必须**继续**和新的栈顶比，不能只比一次——示例 1 里 12 连续吞掉 3 和 2 就是靠 while 循环。

## 复杂度
时间 O(n log M)：每个元素最多入栈出栈各一次，每次 GCD 是 O(log M)，M 为元素值。
空间 O(n)：栈最多存 n 个元素，无其他辅助结构。

## 易错点
- 输入 `[2,2,1,1,3,3,3]` → 若用 `if` 只合并一次，末尾三个 3 只并成两个 3，输出 `[2,1,1,3,3]` 而非 `[2,1,1,3]` → 必须用 `while` 让新栈顶继续与合并结果比较。
- 输入 `[6,4,3,2,...]` → 若写成 `x = y * x // gcd(y, x)`，中间乘积可能远超 10^8（虽 Python 不溢出，但语义上应先除后乘保持值域可控）→ 用 `y // gcd(y, x) * x`，保证中间值不超过最终 LCM。

## 如果面试官追问
问：如果要求返回合并的完整操作序列（每步合并了哪两个下标）怎么办？
答：栈里同时存值和原始下标区间，每次弹出时记录 `(左区间, 右区间, 新值)`，按弹出顺序输出即可。
