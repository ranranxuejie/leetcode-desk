## 一句话思路
统计每个数字出现次数，用 `cnt[d] // 2` 从 9 到 0 拼出最大左半，再补一个最大的奇数次数字作中心。

## 怎么做
1. 用长度 10 的数组 `cnt` 统计 `num` 中每个数字出现次数。
2. 从 9 到 0 遍历，每个数字取 `cnt[d] // 2` 个追加到 `half`，得到字典序最大的左半。
3. 从 9 到 0 找第一个 `cnt[d] % 2 == 1` 的数字作中心 `mid`。
4. 若 `half` 非空，答案是 `half + mid + half[::-1]`；若 `half` 为空（只剩单个数字），返回 `mid`。

以 `num = "444947137"` 为例：`cnt` 中 4 出现 3 次、7 出现 2 次、9 出现 1 次、1 和 3 各 1 次。从 9 到 0 取半数：9 取 0 个，7 取 1 个，4 取 1 个，得到 `half = "74"`；再找最大奇数次数字，9 的 `cnt[9] % 2 == 1`，所以 `mid = "9"`，拼接得 `"74" + "9" + "47" = "7449447"`。

```python
cnt = [0] * 10
for ch in num:
    cnt[int(ch)] += 1

half = ""
for d in range(9, -1, -1):
    half += str(d) * (cnt[d] // 2)

mid = ""
for d in range(9, -1, -1):
    if cnt[d] % 2 == 1:
        mid = str(d)
        break

if half:
    return half + mid + half[::-1]
return mid
```

关键点：`half` 从 9 到 0 构造，保证高位尽量大；中心只取一个数字，因为回文最多一个奇数次字符。

## 复杂度
时间：O(n + 10)，n 是 `num` 长度，统计计数和拼接各扫一遍。
空间：O(n)，`half` 和结果字符串占用与输入同阶的空间，`cnt` 固定 10 个。

## 易错点
- 输入 `"00009"` → 若直接拼 `half + mid + half[::-1]`，`half` 会包含前导 0（如 `"0"`），得到 `"000"` 或 `"090"` 这类非法结果 → 正确做法是当 `half` 全为 0 时只返回 `mid`，即 `"9"`。
- 输入 `"00"` → 若 `half` 为空且没有奇数次数字，会返回空串 → 正确做法是至少返回一个数字，此时应返回 `"0"`（`mid` 为空时取 `half` 的第一个字符或 `"0"`）。

## 如果面试官追问
问：如果要求使用 num 中所有数字且必须构成回文，怎么办？
答：先检查奇数次数字个数是否 ≤1，不满足则返回空串；满足则按同样方式拼接，中心放那个奇数次数字。
