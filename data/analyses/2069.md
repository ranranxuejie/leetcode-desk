## 一句话思路
把整圈周长 `P = 2*(width+height) - 4` 取模，机器人位置只由累计步数 `pos` 决定，四段直线映射回坐标。

## 怎么做
1. 初始化 `self.pos = 0`，`self.P = 2*(width+height) - 4`，方向表按逆时针存 `["East","North","West","South"]`。
2. `step(num)` 只做 `self.pos = (self.pos + num) % self.P`，不逐格模拟。
3. `getPos()` 按 `pos` 落在哪一段反推坐标：`[0, width-1]` 在东边底边，`[width, width+height-2]` 在东边竖边，依此类推。
4. `getDir()` 由 `pos` 所在段决定方向，注意 `pos == 0` 时方向是 `"South"` 而非 `"East"`（走完一圈回到原点时朝向已转过）。

以示例 `width=6, height=3` 为例，`P = 2*9-4 = 14`。前两次 `step(2)` 后 `pos = 4`，落在 `[0,5]` 段，`getPos` 返回 `[4, 0]`，方向 `"East"`。再 `step(2)+step(1)+step(4)` 共 7 步，`pos = (4+7) % 14 = 11`，落在 `[6, 11]` 段（东边竖边），`x = 5`，`y = 11 - 6 + 1 = 6`？不对——竖边从 `(5,1)` 起，`pos=6` 对应 `(5,1)`，故 `y = pos - 6 + 1 = 6`，超出 `height-1=2`，说明段边界要按 `width+height-2 = 7` 收：`pos=11` 落在 `[8, 11]` 段（顶边向西），`x = 5 - (11-8) = 2`，`y = 2`。与示例 `[1,2]` 差 1，因顶边起点是 `pos=8` 对应 `(5,2)`，`pos=11` 走 3 步到 `x=2`；示例累计步数是 2+2+2+1+4=11，`pos=11`，输出 `[1,2]` 说明顶边每步 `x` 减 1 且 `pos=8` 对应 `(5,2)`，则 `pos=11` 是 `(2,2)`——示例给 `[1,2]`，故顶边起点应为 `pos=7` 对应 `(5,2)`，即竖边只占 `[6,6]` 一格（`height-2=1` 步）。段长按 `width-1`、`height-1` 计。

```python
P = 2*(w+h) - 4
self.pos = (self.pos + num) % P
# 段长: 东 width-1, 北 height-1, 西 width-1, 南 height-1
if p <= w-1:      x, y, d = p, 0, 0
elif p <= w+h-2:  x, y, d = w-1, p-(w-1), 1
elif p <= 2*w+h-3:x, y, d = w-1-(p-(w+h-2)), h-1, 2
else:             x, y, d = 0, h-1-(p-(2*w+h-3)), 3
```

## 复杂度
时间：每次 `step`/`getPos`/`getDir` 都是 O(1)，与 `num` 无关。
空间：O(1)，只存 `pos`、`P` 和方向表。

## 易错点
- `pos == 0` 时若直接返回 `"East"` 会错：走满一圈回到 `(0,0)` 时朝向已是 `"South"`（逆时针转满 360° 的最后一格），示例里 `step` 累计恰好整除 `P` 就会暴露。
- 段长写成 `width` 而非 `width-1`：`width=6` 时东边只有 5 步（`(0,0)` 到 `(5,0)`），多算一格会让 `pos=5` 映射到 `(6,0)` 越界，后续所有段整体偏移。

## 如果面试官追问
若 `num` 上限提到 `10**18` 且要求返回路径上经过的所有格子？答：仍需取模定位，但输出方案要按段展开，复杂度变为 O(输出长度)。
