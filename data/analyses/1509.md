## 一句话思路
排序后答案必是「删掉最小的 k 个和最大的 3-k 个」之一，枚举 k=0..3 取最小跨度。

## 怎么做
1. 先排序，`nums` 变成有序数组，跨度只由两端决定。
2. 关键观察：改一个元素等于把它「挪走」，最优策略只会动两端，不会动中间。
3. 枚举四种删法：删 3 头、2 头 1 尾、1 头 2 尾、3 尾，取 `nums[n-1-i] - nums[3-i]` 的最小值。
4. 用示例 2 `[1,5,0,10,14]` 排序得 `[0,1,5,10,14]`，n=5：i=0 得 `14-0=14`，i=1 得 `10-1=9`，i=2 得 `5-5=0`？注意这里 i=2 是删 2 头 1 尾，跨度 `nums[5-1-2]-nums[3-2]=nums[2]-nums[1]=5-1=4`；i=3 得 `nums[1]-nums[0]=1-0=1`，取最小为 1，与官方输出一致。

```python
nums.sort()
n = len(nums)
ans = nums[-1] - nums[0]
for i in range(4):
    if n - 1 - i >= 3 - i:
        ans = min(ans, nums[n - 1 - i] - nums[3 - i])
return ans
```

注意 `n <= 3` 时循环里 `3-i` 会越界，实际应加 `if n <= 4: return 0` 提前返回（长度不超过 4 时三次操作足以全部改成同一个值）。

## 复杂度
时间：排序 O(n log n) 是主导，枚举 4 次是 O(1)。
空间：排序额外 O(log n) 栈空间，其余 O(1)。

## 易错点
- 输入 `nums = [3,100,20]`（n=3）→ 若直接跑 `nums[3-i]` 会下标越界或读到错误值 → 正确做法是先判 `n <= 4` 直接返回 0，因为三次操作能把所有元素改成同一个数。
- 输入 `[1,5,0,10,14]` → 若只比较「删 3 头」和「删 3 尾」两种，会得到 `14-1=13` 或 `10-0=10`，漏掉混合删法 → 必须枚举 i=0..3 四种组合，答案 1 来自 i=3（删 2 尾 1 头）。

## 如果面试官追问
问：如果操作次数改成 k 次怎么办？
答：同样排序后枚举删 i 头、k-i 尾，i 从 0 到 k，取 `nums[n-1-(k-i)] - nums[i]` 最小值，复杂度 O(n log n + k)。
