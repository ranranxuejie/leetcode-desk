## 一句话思路
用双指针从两端向中间夹，只要 `s[l] == s[r]` 就把两端同字符的整段一起跳过，剩下的就是最短长度。

## 怎么做
1. 初始化 `l = 0`、`r = len(s) - 1`，循环条件为 `l <= r and s[l] == s[r]`。
2. 记下当前字符 `c = s[l]`，然后 `while l <= r and s[l] == c: l += 1`，把左侧整段同字符吃掉。
3. 同样 `while l <= r and s[r] == c: r -= 1`，吃掉右侧整段。
4. 循环结束后返回 `r - l + 1`（可能为 0）。

以 `s = "aabccabba"` 为例：首轮 `c = 'a'`，左指针从 0 推到 2（跳过 `"aa"`），右指针从 8 退到 7（只跳过末尾一个 `'a'`），此时 `l=2, r=7`，子串变成 `"bccabb"`；第二轮 `c = 'b'`，`l` 推到 3、`r` 退到 6，剩 `"cca"`；第三轮 `s[3]='c'` 但 `s[6]='a'`，不等，退出，返回 `6-3+1 = 3`。

```python
l, r = 0, len(s) - 1
while l <= r and s[l] == s[r]:
    c = s[l]
    while l <= r and s[l] == c:
        l += 1
    while l <= r and s[r] == c:
        r -= 1
return r - l + 1
```

关键点：内层两个 `while` 必须都带 `l <= r` 边界，否则 `"aa"` 这种会越界；`c` 要在移动 `l` 之前存下来。

## 复杂度
时间 O(n)：`l` 和 `r` 各自单调移动，每个字符最多被访问一次。
空间 O(1)：只用了 `l`、`r`、`c` 三个变量，没有额外数组。

## 易错点
- 输入 `"aa"`：若内层 `while` 不写 `l <= r`，`l` 会一路加到 2 越界，或 `r` 减到 -1；正确做法是两个内层循环都先判 `l <= r`，这样 `l=1, r=0` 退出，返回 0。
- 输入 `"ca"`：若把循环条件写成 `s[l] != s[r]` 就退出，会误以为能删；实际首字符 `'c'` 与末字符 `'a'` 不同，一次操作都不能做，必须返回原长 2，所以循环条件必须是 `s[l] == s[r]` 才进入。

## 如果面试官追问
问：如果要求输出删除后的字符串而不只是长度？答：把 `l`、`r` 的最终值记下来，返回 `s[l:r+1]` 即可，逻辑完全不变。
