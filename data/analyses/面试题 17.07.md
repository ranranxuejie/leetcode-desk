## 一句话思路
用并查集把同义名字合并成连通块，每块取字典序最小的名字作代表，把频率累加到代表上。

## 怎么做
1. 解析 `names`，用 `split("(")` 拆出名字和频率，存进 `freq` 字典；同时把所有名字放进并查集的 `parent`。
2. 解析 `synonyms`，去掉括号后按逗号拆成 `a`、`b`，对 `a`、`b` 做 `union`；`union` 时让字典序小的当根，这样根天然就是真实名字。
3. 遍历 `freq`，把每个名字的频率累加到 `find(name)` 上，得到 `total`。
4. 把 `total` 按 `名字(频率)` 格式化输出。

关键中间值：示例里 `Jon` 和 `John` 合并后根是 `John`（`"John" < "Jon"`）；`Johnny` 通过 `John` 也挂到 `John` 下，`total["John"] = 15 + 12 = 27`。`Chris` 块里 `"Chris"` 字典序最小，`total["Chris"] = 13 + 4 + 19 = 36`。

```python
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

def union(a, b):
    ra, rb = find(a), find(b)
    if ra != rb:
        if ra < rb:
            parent[rb] = ra
        else:
            parent[ra] = rb

for a, b in pairs:
    union(a, b)
total = {}
for name, f in freq.items():
    r = find(name)
    total[r] = total.get(r, 0) + f
```

注意 `union` 里比较的是根 `ra < rb`，不是原始名字，否则传递合并后根可能不是最小。

## 复杂度
时间：O((N + M) α(N))，N 为名字数、M 为同义对数，α 为反阿克曼函数。
空间：O(N)，`parent`、`freq`、`total` 各存 N 个键。

## 易错点
1. 只在 `synonyms` 里出现的名字（如示例的 `Johnny`）不在 `names` 中 → 若只对 `names` 建并查集，`find("Johnny")` 会 KeyError → 建 `parent` 时要把 `synonyms` 两端的名字也加进去，频率默认 0。
2. `union` 按原始名字而非根比较 → 链式合并 `A-B`、`B-C` 时根可能停在 `B`，输出真实名字错成 `B` → 必须 `find` 出根后再比 `ra < rb`。

## 如果面试官追问
若 `names` 规模到 10^6 且 `synonyms` 稀疏，怎么省内存？答：并查集用数组下标代替字符串键，先哈希映射名字到 id，再做 union。
