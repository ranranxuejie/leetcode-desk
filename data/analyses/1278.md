## 一句话思路
先预处理任意子串变成回文的最小代价 `cost[i][j]`，再用 `dp[t][i]` 表示前 i 个字符切成 t 段的最小总代价。

## 怎么做
1. 预处理 `cost[i][j]`：从短到长枚举区间，`cost[i][j] = cost[i+1][j-1] + (s[i] != s[j])`，长度 1 为 0、长度 2 只比一次。
2. 定义 `dp[t][i]`：把 `s[0:i]` 切成 t 段的最小修改数，`dp[1][i] = cost[0][i-1]`。
3. 转移 `dp[t][i] = min(dp[t-1][j] + cost[j][i-1])`，j 从 `t-1` 到 `i-1`（保证前 t-1 段每段非空）。
4. 答案 `dp[k][n]`。

以 `s = "abc", k = 2` 为例：`cost[0][1] = 1`（"ab" 改 1 个），`cost[2][2] = 0`。切在 j=2 时 `dp[1][2] + cost[2][2] = 1 + 0 = 1`，切在 j=1 时 `dp[1][1] + cost[1][2] = 0 + 1 = 1`，故 `dp[2][3] = 1`。

```python
n = len(s)
cost = [[0] * n for _ in range(n)]
for length in range(2, n + 1):
    for i in range(n - length + 1):
        j = i + length - 1
        cost[i][j] = cost[i + 1][j - 1] + (s[i] != s[j])
INF = 10**9
dp = [[INF] * (n + 1) for _ in range(k + 1)]
for i in range(1, n + 1):
    dp[1][i] = cost[0][i - 1]
for t in range(2, k + 1):
    for i in range(t, n + 1):
        for j in range(t - 1, i):
            dp[t][i] = min(dp[t][i], dp[t - 1][j] + cost[j][i - 1])
return dp[k][n]
```

## 复杂度
时间：O(n²) 预处理 + O(k·n²) 转移，n 为串长。
空间：O(n²) 存 `cost`，O(k·n) 存 `dp`。

## 易错点
- `s = "abc", k = 3` 时若允许空段，会算出 0；必须让内层 j 从 `t-1` 起、i 从 `t` 起，保证每段长度 ≥1。
- 预处理 `cost` 时若按 `i` 从 0 到 n-1 正序填，`cost[i+1][j-1]` 还没算出来；必须按区间长度从小到大枚举，长度 1、2 单独处理。

## 如果面试官追问
问：n 放大到 500、k 也到 500 怎么办？
答：转移是区间划分型，可用 Knuth 优化或四边形不等式把 O(k·n²) 降到 O(k·n)，但 `cost` 的 O(n²) 空间仍在。
