## 一句话思路
用 `ball` 记每个球当前颜色、`cnt` 记每种颜色被几个球占用，颜色数就是 `cnt` 的键数。

## 怎么做
1. 维护 `ball = {}`（球号→颜色）和 `cnt = {}`（颜色→球数），答案数组 `res`。
2. 每次取 `x, y`，若 `x` 已有旧色 `old`，把 `cnt[old]` 减 1，减到 0 就删键。
3. 再给 `x` 染 `y`：`ball[x] = y`，`cnt[y] = cnt.get(y, 0) + 1`。
4. 每步把 `len(cnt)` 追加进 `res`。

以示例 1 第 3 步 `[1,3]` 为例：此时 `ball = {1:4, 2:5}`、`cnt = {4:1, 5:1}`；旧色 `old = 4` 减到 0 被删，`cnt` 变成 `{5:1}`，再染 3 得 `{5:1, 3:1}`，`len(cnt) = 2`，与输出第 3 位一致。

```python
ball, cnt, res = {}, {}, []
for x, y in queries:
    old = ball.get(x)
    if old is not None:
        cnt[old] -= 1
        if cnt[old] == 0:
            del cnt[old]
    ball[x] = y
    cnt[y] = cnt.get(y, 0) + 1
    res.append(len(cnt))
```

关键点：`old` 用 `None` 判空而不是 `0`，因为颜色值从 1 起，`0` 不会出现但 `None` 语义更稳；`del` 必须在加新色之前，否则同色重染会多算。

## 复杂度
时间 O(n)：n 次操作，每次哈希增删查均摊 O(1)。
空间 O(n)：`ball` 最多 n 个球，`cnt` 最多 n 种颜色，`res` 长度 n。

## 易错点
1. 输入 `[[1,4],[1,4]]`（同球同色重染）→ 若先加新色再减旧色，`cnt[4]` 会先变 2 再变 1，中间 `len(cnt)` 不变但计数错；正确做法是先减旧色并判 0 删键，再加新色。
2. 输入 `[[1,4],[2,4]]`（两球同色）→ 若减旧色时不判 `cnt[old] == 0` 就删键，会把还有球占用的颜色 4 误删，`len(cnt)` 少 1；正确做法是只在计数归零时 `del`。

## 如果面试官追问
若 limit 缩小到 10^5 且要求输出每种颜色的球号列表？答：把 `cnt` 换成 `dict[int, set]`，增删球号，`len(cnt)` 仍为颜色数。
