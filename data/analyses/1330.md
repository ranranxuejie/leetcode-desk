## 一句话思路
翻转只改两个断点，枚举「翻转后新增收益」的最大值，加上原数组值即可。

## 怎么做
1. 先算原数组值 `base = sum(|nums[i]-nums[i+1]|)`，翻转内部相邻对的差不变，只有两个断点会变。
2. 翻转 `[i+1, j]` 时，断点从 `(a=nums[i], b=nums[i+1])` 和 `(c=nums[j], d=nums[j+1])` 变成 `|a-c|` 和 `|b-d|`，收益 `gain = |a-c|+|b-d|-|a-b|-|c-d|`。
3. 边界情况：翻转前缀或后缀只有一个断点，收益是 `|nums[0]-nums[j]|-|nums[j]-nums[j+1]|` 这类，单独扫一遍。
4. 内部情况用贪心：把每对相邻数看成区间 `[min, max]`，`gain` 最大就是 `2*(最大左端点 - 最小右端点)`，前提是两区间不相交。

以 `nums=[2,3,1,5,4]` 为例，`base=1+2+4+1=8`。区间为 `[2,3]`、`[1,3]`、`[1,5]`、`[4,5]`。最大左端点 `4`，最小右端点 `3`，`gain=2*(4-3)=2`，答案 `8+2=10`，对应翻转 `[3,1,5]`。

```python
base = sum(abs(nums[i] - nums[i+1]) for i in range(len(nums)-1))
best = 0
lo = min(nums[0], nums[1]); hi = max(nums[0], nums[1])
for i in range(1, len(nums)-1):
    a, b = nums[i], nums[i+1]
    best = max(best, abs(nums[0]-b) - abs(a-b))
    best = max(best, abs(nums[-1]-a) - abs(a-b))
    best = max(best, 2*(max(a,b) - lo), 2*(hi - min(a,b)))
    lo = min(lo, a, b); hi = max(hi, a, b)
return base + best
```

## 复杂度
时间 O(n)：一次线性扫描，`n = len(nums)`。
空间 O(1)：只维护 `base`、`best`、`lo`、`hi` 四个变量。

## 易错点
- 输入 `[2,3,1,5,4]` 只算内部区间收益会漏掉翻转前缀/后缀的情况，比如翻转 `[5,4]` 收益来自 `|nums[0]-nums[j]|`；必须单独用 `abs(nums[0]-b)` 和 `abs(nums[-1]-a)` 扫一遍。
- 输入 `[1,2,3,4]` 所有区间都相交，`2*(max(a,b)-lo)` 会算出负值；`best` 初值设 0 并取 `max`，保证不翻转时答案就是 `base`。

## 如果面试官追问
要求输出具体翻转区间怎么办？
答：记录取得 `best` 时的 `i, j`，内部情况对应翻转 `[i+1, j]`，边界情况对应前缀或后缀，回溯即可。
