## 一句话思路
把每个 nums[i] 按「能否整除 target」分成必选池和干扰池，再对必选池做子集枚举，看能否凑出两个乘积都等于 target 的组。

## 怎么做
1. 先筛：`nums[i]` 不整除 `target` 的直接判 `False`，因为任何一组含它乘积就不可能等于 target。
2. 再算总乘积 `P = prod(nums)`，若 `P != target * target` 直接 `False`——两组乘积都是 target，全体乘积必为 target²。
3. 枚举子集 `mask`（1 到 `2**n - 2`，排除全空和全集），累乘 `mask` 内元素，等于 target 就返回 `True`。
4. 用 `mask` 的补集乘积 = `P // 子集乘积` 判断，避免重复算两遍。

以示例 1 `nums = [3,1,6,8,4], target = 24` 为例：`P = 3*1*6*8*4 = 576 = 24*24` 通过；枚举到 `mask` 选中 `{3,8}` 时子集乘积 `24`，补集 `{1,6,4}` 乘积 `576//24 = 24`，返回 `True`。

```python
from math import prod
n = len(nums)
P = prod(nums)
if P != target * target:
    return False
for mask in range(1, (1 << n) - 1):
    cur = 1
    for i in range(n):
        if mask >> i & 1:
            cur *= nums[i]
            if cur > target:
                break
    if cur == target:
        return True
return False
```

## 复杂度
时间：O(2^n · n)，n = len(nums) ≤ 12，枚举子集乘内层扫描。
空间：O(1)，只用了 `P`、`cur`、`mask` 几个标量。

## 易错点
- 输入 `nums = [1,1,...]` 类含 1 的情况：1 乘进任何组不改变乘积，若只按「整除 target」筛会漏掉 1 必须被分到某一组。正确做法是让 1 参与枚举，靠 `P == target*target` 和子集枚举自然覆盖，别提前剔除。
- 输入 `nums = [2,5,3,7], target = 15`：`P = 210 ≠ 225`，若跳过总乘积校验直接枚举，会在 `{3,5}` 乘积 15 时误判 `True`，但补集 `{2,7}` 乘积 14 ≠ 15。必须先做 `P != target*target` 的全局校验。

## 如果面试官追问
问：若 nums 长度放宽到 20 怎么办？
答：2^20 枚举仍可接受（约百万级），但内层 O(n) 要改成递推 `sub[mask] = sub[mask & (mask-1)] * nums[lowbit]`，把单次枚举降到 O(1)。
