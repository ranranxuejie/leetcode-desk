## 一句话思路
从高位到低位逐位比较 n 的二进制，用 pre1 记录上一位是否为 1，遇到 n 的 1 位就累加「该位取 0、低位自由」的合法方案数。

## 怎么做
1. 预处理 dp[i]：长度为 i 的二进制串（允许前导 0）中不含连续 1 的个数，dp[0]=1、dp[1]=2，dp[i]=dp[i-1]+dp[i-2]。
2. 把 n 的二进制位从高到低扫，维护 pre1（上一位是否已放 1）。
3. 当前位为 1 时：先累加「本位放 0」的方案 dp[剩余位数]；若 pre1 已为 True，说明 n 自身前缀已出现 11，立即 break，不再累加。
4. 本位放 1 后置 pre1=True；若扫完所有位都没 break，说明 n 本身合法，答案再加 1。

以 n=5（二进制 `101`）为例：i=2 位为 1，pre1=False，累加 dp[2]=3（对应 000、001、010 即 0、1、2），pre1 置 True；i=1 位为 0，pre1 置 False；i=0 位为 1，pre1=False，累加 dp[0]=1（对应 100 即 4），pre1 置 True；循环结束未 break，再加 1（n=5 自身），得 3+1+1=5。

```python
dp = [1, 2]
for i in range(2, 32):
    dp.append(dp[i-1] + dp[i-2])
bits = bin(n)[2:]
ans, pre1 = 0, False
for i, ch in enumerate(bits):
    rest = len(bits) - i - 1
    if ch == '1':
        ans += dp[rest]
        if pre1:
            return ans
        pre1 = True
    else:
        pre1 = False
return ans + 1
```

## 复杂度
时间 O(log n)：只扫 n 的二进制位数，dp 预处理固定 32 次。
空间 O(log n)：dp 表固定 32 项，bits 列表长度等于 n 的位数。

## 易错点
- n=3（`11`）：若在 i=1 位为 1 时仍累加 dp[0] 再继续，会把 3 自身算进合法数，得 4；正确做法是 pre1 为 True 时累加完立即 return，输出 3。
- n=1（`1`）：若循环结束后忘记 `ans + 1`，只返回 dp[0]=1，漏掉 n 自身，输出 1 而非 2；正确做法是未 break 时补加 1。

## 如果面试官追问
若要求输出所有合法整数而非计数？答：把 dp 累加改成回溯枚举，每层按「放 0 或放 1（pre1 为 False 时）」分支，收集到列表即可。
