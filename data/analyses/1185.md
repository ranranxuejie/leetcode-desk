## 一句话思路
用蔡勒公式（Zeller）直接由 day/month/year 算出星期偏移，再对 7 取模映射到英文名。

## 怎么做
1. 把 1、2 月视为上一年的 13、14 月，即 `if month < 3: month += 12; year -= 1`。
2. 取 `K = year % 100`、`J = year // 100`，代入 `h = (day + 13*(month+1)//5 + K + K//4 + J//4 + 5*J) % 7`。
3. `h` 的 0 对应 Saturday，按 `["Saturday","Sunday","Monday","Tuesday","Wednesday","Thursday","Friday"]` 取下标。
4. 以示例 1（31, 8, 2019）验证：month=8 不改，K=19、J=20，`h = (31 + 13*9//5 + 19 + 4 + 5 + 100) % 7 = (31+23+19+4+5+100)%7 = 182%7 = 0`，取 `names[0]` 得 `"Saturday"`，与输出一致。

```python
def day_of_week(day, month, year):
    if month < 3:
        month += 12
        year -= 1
    K, J = year % 100, year // 100
    h = (day + 13 * (month + 1) // 5 + K + K // 4 + J // 4 + 5 * J) % 7
    names = ["Saturday", "Sunday", "Monday", "Tuesday",
             "Wednesday", "Thursday", "Friday"]
    return names[h]
```

注意 `13*(month+1)//5` 里 `//` 的优先级高于 `+`，但低于 `*`，写成 `13*(month+1)//5` 才不会被误读成 `13*((month+1)//5)`；Python 中 `//` 与 `*` 同级左结合，所以上式实际是 `(13*(month+1))//5`，正确。

## 复杂度
时间：O(1)，只做常数次整数运算，与 year 大小无关。
空间：O(1)，仅 names 列表 7 个字符串。

## 易错点
- 输入 month=1 或 2（如 1999-01-15）→ 忘记 `month += 12; year -= 1`，K/J 用错年份，结果整体偏移 → 必须先做 1、2 月的年份回退再取 K、J。
- 输入 2019-08-31 → 把 `h=0` 直接当成 Sunday，因为默认 0 是周日 → 本题公式 0 对应 Saturday，映射表首元素必须是 `"Saturday"`。

## 如果面试官追问
问：若要求支持 1582 年以前（儒略历）日期怎么办？
