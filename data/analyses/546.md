## 一句话思路
用 `dp(l, r, k)` 表示「区间 `[l,r]` 加上右端挂着 `k` 个与 `boxes[r]` 同色的盒子」的最大积分，靠记忆化避免重复子问题。

## 怎么做
1. 预处理：把连续同色盒子合并成 `(颜色, 个数)` 数组，长度记为 `m`，这样 `[1,1,1]` 直接变成 `[(1,3)]`。
2. 状态定义：`dp(l, r, k)` 中 `k` 是紧贴在 `boxes[r]` 右侧、与它同色且已被「预留」的盒子数。
3. 转移一：直接消掉右端这一坨，得分 `(cnt[r] + k) ** 2 + dp(l, r-1, 0)`。
4. 转移二：在 `[l, r-1]` 里找 `i` 使 `color[i] == color[r]`，把 `r` 这一坨并到 `i` 上，得分 `dp(i+1, r-1, 0) + dp(l, i, cnt[r] + k)`。

以示例 1 为例，合并后是 `[(1,1),(3,1),(2,3),(3,1),(4,1),(3,1),(1,1)]`。关键中间值：`dp(0, 6, 0)` 里 `color[6]=1`，向前找到 `i=0`，于是拆成 `dp(1, 5, 0) + dp(0, 0, 1)`，后者得 `(1+1)**2 = 4`，正是最终那步 `[1,1]` 拿的 4 分。

```python
from functools import lru_cache

@lru_cache(None)
def dp(l, r, k):
    if l > r:
        return 0
    best = (cnt[r] + k) ** 2 + dp(l, r - 1, 0)
    for i in range(l, r):
        if color[i] == color[r]:
            best = max(best, dp(i + 1, r - 1, 0) + dp(l, i, cnt[r] + k))
    return best
```

## 复杂度
时间：状态数 `O(m^2 * n)`，每个状态扫 `O(m)` 个 `i`，共 `O(m^3 * n)`，`m ≤ n`。
空间：记忆化表存 `O(m^2 * n)` 个整数，递归栈深 `O(m)`。

## 易错点
- 输入 `[1,3,2,2,2,3,4,3,1]` 若不先合并连续同色，`k` 的含义会退化成「单个盒子数」，`(cnt[r]+k)**2` 里的 `cnt[r]` 恒为 1，示例 1 会算成 19 而不是 23；正确做法是先压成 `(颜色, 个数)` 再跑 DP。
- 输入 `[1,1,1]` 若在转移二里允许 `i == r`，会得到 `dp(r+1, r-1, 0) + dp(l, r, cnt[r]+k)` 这种自己调自己的循环；正确做法是 `range(l, r)` 严格排除 `r`，只把 `r` 并到左侧同色块上。

## 如果面试官追问
问：`n` 放大到 1000 还这么做吗？
答：`O(m^3 * n)` 撑不住，得换「按颜色分组 + 区间 DP 只枚举同色位置」的写法，把第三维压掉。
