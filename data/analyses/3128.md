## 一句话思路
枚举每个为 1 的格子当直角顶点，用行、列 1 的计数相乘累加，因为同行任选一个、同列任选一个就唯一确定一个三角形。

## 怎么做
1. 预处理 `row[i]` = 第 i 行 1 的个数，`col[j]` = 第 j 列 1 的个数。
2. 遍历每个 `grid[i][j] == 1` 的格子，把它当直角顶点。
3. 该顶点贡献 `(row[i] - 1) * (col[j] - 1)` 个三角形，累加到答案。
4. 返回累加和。

以示例 1 `grid = [[0,1,0],[0,1,1],[0,1,0]]` 为例：`row = [1,2,1]`，`col = [0,3,1]`。直角顶点只有 `(1,1)` 和 `(1,2)` 两处为 1。`(1,1)` 贡献 `(2-1)*(3-1) = 2`；`(1,2)` 贡献 `(2-1)*(1-1) = 0`。合计 2，与输出一致。

```python
m, n = len(grid), len(grid[0])
row = [sum(r) for r in grid]
col = [sum(grid[i][j] for i in range(m)) for j in range(n)]
ans = 0
for i in range(m):
    for j in range(n):
        if grid[i][j] == 1:
            ans += (row[i] - 1) * (col[j] - 1)
return ans
```

关键点：`row[i] - 1` 和 `col[j] - 1` 都减掉了顶点自己，避免把顶点重复算进两条臂。

## 复杂度
时间：O(m·n)，预处理两遍加一次遍历，m、n 分别是行数、列数。
空间：O(m + n)，只开了 `row`、`col` 两个计数数组，没有额外矩阵。

## 易错点
- 输入 `[[1,1],[1,1]]` → 若忘记减 1，`(1,1)` 会算成 `2*2=4`，实际应为 `1*1=1`，答案从 4 个虚高到 16。正确做法是每条臂都先 `-1` 排除顶点自身。
- 输入示例 1 中 `(1,1)` 与 `(1,2)` 同行、`(1,1)` 与 `(0,1)` 同列 → 若把「同行两个 + 同列一个」按无序三元组去重，会漏算或重算。正确做法是固定直角顶点枚举，每个三角形恰好被它的直角顶点数一次，无需去重。

## 如果面试官追问
问：若 grid 是稀疏的（1 很少），怎么优化？
答：只把值为 1 的坐标存进列表，用字典统计每行每列计数，遍历 1 的坐标而非全矩阵，复杂度降到 O(k)，k 为 1 的个数。
