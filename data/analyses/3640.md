## 一句话思路
用四个状态 DP 从左到右扫，分别记录「处于第一段升」「处于第二段降」「处于第三段升」时的最大子数组和，转移只依赖相邻元素大小关系。

## 怎么做
1. 定义 `up1`、`down`、`up2` 三个量：分别表示以当前下标结尾、且当前处于第一段/第二段/第三段的最大和。
2. 从左到右遍历 `i`，按 `nums[i]` 与 `nums[i-1]` 的大小关系更新三个状态。
3. 每次更新 `up2` 后用它更新答案。

以 `nums = [1,4,2,7]` 为例：`i=1` 时 `1<4`，`up1=5`；`i=2` 时 `4>2`，`down=up1+2=7`；`i=3` 时 `2<7`，`up2=down+7=14`，答案即 14。

```python
up1 = down = up2 = -10**18
ans = -10**18
for i in range(1, len(nums)):
    a, b = nums[i-1], nums[i]
    new_up1 = max(up1 + b, a + b) if a < b else -10**18
    new_down = max(down + b, up1 + b) if a > b else -10**18
    new_up2 = max(up2 + b, down + b) if a < b else -10**18
    up1, down, up2 = new_up1, new_down, new_up2
    ans = max(ans, up2)
```

关键点：`new_down` 从 `up1 + b` 起跳，保证第二段至少接在第一段之后；`new_up2` 从 `down + b` 起跳，保证第三段接在第二段之后。

## 复杂度
时间：O(n)，一次遍历，每个下标常数次比较与加法。
空间：O(1)，只维护 `up1`、`down`、`up2`、`ans` 四个变量。

## 易错点
- 全负数组如 `[-1,-2,-3,-4]`：若把初值设成 0，`up1` 会被错误地"重置"为 0 再累加，得到偏大的和；正确做法是初值设 `-10**18`，且 `new_up1` 只在 `a < b` 时从 `a + b` 起跳，否则置负无穷。
- 相邻相等如 `[1,1,2,3]`：若用 `<=` 判断递增，会把相等元素算进严格递增段；正确做法是严格用 `a < b` 和 `a > b`，相等时三个状态全部置负无穷，强制断开。

## 如果面试官追问
问：如果要求输出具体的 l、p、q、r 而不是只返回和？
答：在每个状态里额外存起始下标，转移时继承或重置，最后回溯 `up2` 的来源即可。
