## 一句话思路
用倍增预处理 `up[j][i]` 和 `sum[j][i]`（走 2^j 步的落点与路径和），把 k 拆成二进制位累加。

## 怎么做
1. 初始化 `up[0][i] = receiver[i]`，`sum[0][i] = receiver[i]`（走 1 步的落点与和）。
2. 递推 `up[j][i] = up[j-1][up[j-1][i]]`，`sum[j][i] = sum[j-1][i] + sum[j-1][up[j-1][i]]`。
3. 对每个起点 x，从高位到低位扫 k 的二进制位，若该位为 1 则 `ans += sum[j][cur]; cur = up[j][cur]`。
4. 取所有起点结果的最大值。

以示例 1 `receiver = [2,0,1], k = 4` 为例，从 x=2 出发：k=4 二进制 `100`，只走 j=2 这一层。`up[2][2]` 表示走 4 步的落点，`sum[2][2]` 表示这 4 步的路径和 = 1+0+2+1 = 4，加上起点 2 得 f(2)=6。

```python
n = len(receiver)
LOG = k.bit_length()
up = [[0]*n for _ in range(LOG)]
sm = [[0]*n for _ in range(LOG)]
for i in range(n):
    up[0][i] = receiver[i]
    sm[0][i] = receiver[i]
for j in range(1, LOG):
    for i in range(n):
        mid = up[j-1][i]
        up[j][i] = up[j-1][mid]
        sm[j][i] = sm[j-1][i] + sm[j-1][mid]
best = 0
for x in range(n):
    cur, total = x, x
    for j in range(LOG):
        if (k >> j) & 1:
            total += sm[j][cur]
            cur = up[j][cur]
    best = max(best, total)
```

## 复杂度
时间：O(n log k)，n 个起点各扫 log k 位，预处理也是 n log k。
空间：O(n log k)，up 和 sm 两张表各 n×log k。

## 易错点
- `k` 可达 10^10，`LOG = k.bit_length()` 约 34 层，若只开 32 层会漏掉高位导致少走步数，答案偏小。
- 起点自身要计入总和：`total` 初始化为 `x` 而非 0，示例 1 中若漏掉起点 2 会得到 4 而非 6。

## 如果面试官追问
若要求输出最优起点编号而非最大值？答：在 `best = max(best, total)` 处同时记录对应 `x` 即可，逻辑不变。
