## 一句话思路
用线段树维护每个区间篮子的最大容量，每次查询最左侧容量 ≥ fruits[i] 的篮子并置为 0。

## 怎么做
1. 建线段树，叶子存 `baskets[j]`，内部节点存左右子树最大值。
2. 对每个 `fruits[i]`，从根递归：若左子树最大值 ≥ `fruits[i]` 就进左子树，否则进右子树；都进不去说明无篮可用。
3. 找到叶子下标 `j` 后把该位置更新为 0，表示篮子已占用。
4. 统计找不到篮子的水果个数即为答案。

以 `fruits = [4,2,5], baskets = [3,5,4]` 为例：`fruits[0]=4` 时根最大值 5 ≥ 4，左子树（叶子 3）最大值 3 < 4，转右子树，命中下标 1 的 5，置 0；此时树变为 `[3,0,4]`。`fruits[1]=2` 时左子树最大值 3 ≥ 2，直接命中下标 0。`fruits[2]=5` 时根最大值 4 < 5，未放置，答案 1。

```python
def find(node, l, r, need):
    if tree[node] < need:
        return -1
    if l == r:
        tree[node] = 0
        return l
    mid = (l + r) // 2
    if tree[node * 2] >= need:
        res = find(node * 2, l, mid, need)
    else:
        res = find(node * 2 + 1, mid + 1, r, need)
    tree[node] = max(tree[node * 2], tree[node * 2 + 1])
    return res
```

## 复杂度
时间：每个水果一次 O(log n) 查询加一次 O(log n) 更新，共 O(n log n)。
空间：线段树数组约 4n 个节点，O(n)。

## 易错点
- `baskets = [5,3,4]`、`fruits = [4,4]`：若只按容量排序贪心，会把 4 放进 5 再放进 4，看似可行；但本题要求「最左侧可用篮子」，第一个 4 必须放下标 0 的 5，第二个 4 放下标 2 的 4。排序贪心会打乱下标顺序，必须用线段树保序。
- `fruits = [5], baskets = [4]`：若查询时只判断根最大值 ≥ need 就返回根，会误判为可放置。必须递归到叶子，且叶子命中后立刻置 0，否则同一篮子会被重复使用。

## 如果面试官追问
若 n 扩大到 10^5 且要求输出每个水果放入的篮子下标，怎么做？答：线段树查询时返回叶子下标并记录到结果数组，复杂度不变。
