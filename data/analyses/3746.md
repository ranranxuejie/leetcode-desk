## 一句话思路
用栈抵消相邻的 `'a'`/`'b'` 对，剩下的全是同一种字符，长度即答案。

## 怎么做
1. 维护一个栈 `st`，遍历 `s` 的每个字符 `c`。
2. 若 `st` 非空且 `st[-1] != c`，说明栈顶与 `c` 构成一对可消的异字符，`pop` 掉栈顶；否则 `push(c)`。
3. 遍历结束后 `len(st)` 就是最小长度。

以 `s = "aaabb"` 为例：读 `a`→`['a']`；读 `a`→`['a','a']`；读 `a`→`['a','a','a']`；读 `b` 与栈顶 `a` 不同，弹出→`['a','a']`；再读 `b` 弹出→`['a']`，最终长度 1，与示例一致。

```python
st = []
for c in s:
    if st and st[-1] != c:
        st.pop()
    else:
        st.append(c)
return len(st)
```

关键点：栈里始终只含同一种字符（一旦出现异字符立刻被弹掉），所以「栈顶与 `c` 不同」等价于「存在可消的相邻异字符对」。消完后剩下的必然是纯 `a` 串或纯 `b` 串，无法再消，故为最小。

## 复杂度
时间 O(n)：每个字符最多入栈、出栈各一次。
空间 O(n)：栈最坏存下整个 `s`（如 `"aaaa"`）。

## 易错点
- 输入 `"abab"`：若只统计 `a`、`b` 总数取差值，得 0 看似对，但换成 `"aabb"` 也靠总数差得 0 而漏掉「必须连续子串」的约束；本题恰好总数差等于栈结果，但思路错在把「任意子串」当成「任意子序列」，正确做法是逐字符用栈消相邻异字符。
- 输入 `"aaaa"`：若写成「遇到异字符才 push、相同就跳过」，会把 4 个 `a` 压成 1 个，错答 1；正确做法是相同字符也要 `push`，栈长度才等于剩余长度。

## 如果面试官追问
问：若字符集扩到 `k` 种，还能用栈吗？
答：不能简单两两消，需按计数或贪心配对，复杂度与 `k` 相关。
