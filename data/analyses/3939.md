## 一句话思路
树上「选/不选」互斥，用树形 DP 按 `sum % k` 分桶，父节点选时子节点只能不选。

## 怎么做
1. 建 `children` 邻接表，`parent[i] < i` 保证从 0 到 n-1 顺序即拓扑序，可倒序迭代代替递归。
2. 每个节点维护两个长度 k 的数组：`dp0[r]` 表示不选该节点、子树和模 k 为 r 的方案数，`dp1[r]` 表示选该节点。
3. 初始 `dp0[0] = 1`（空集），`dp1[nums[u] % k] = 1`；把每个子节点 v 的 `dp0[v] + dp1[v]` 按模 k 卷积进 `dp0[u]`，把 `dp0[v]` 卷积进 `dp1[u]`。
4. 根节点答案为 `(dp0[0] + dp1[0] - 1) % MOD`，减 1 去掉空集。

以示例 2 为例：`parent = [-1,0,0,0]`，`nums = [2,1,2,1]`，`k = 3`。节点 1 的 `dp1[1] = 1`，节点 2 的 `dp1[2] = 1`，节点 3 的 `dp1[1] = 1`。节点 0 的 `dp0` 卷积三个子节点后，`dp0[0]` 包含 `{1,2}`（1+2=3）和 `{2,3}`（2+1=3），加上 `dp1[2] = 1` 对应 `{0}`（2），再减空集，得 2。

```python
MOD = 10**9 + 7
n = len(parent)
children = [[] for _ in range(n)]
for i in range(1, n):
    children[parent[i]].append(i)
dp0 = [[0] * k for _ in range(n)]
dp1 = [[0] * k for _ in range(n)]
for u in range(n - 1, -1, -1):
    dp0[u][0] = 1
    dp1[u][nums[u] % k] = 1
    for v in children[u]:
        nd0 = [0] * k
        nd1 = [0] * k
        for a in range(k):
            if dp0[u][a] == 0: continue
            for b in range(k):
                nd0[(a + b) % k] = (nd0[(a + b) % k] + dp0[u][a] * (dp0[v][b] + dp1[v][b])) % MOD
                nd1[(a + b) % k] = (nd1[(a + b) % k] + dp1[u][a] * dp0[v][b]) % MOD
        dp0[u], dp1[u] = nd0, nd1
return (dp0[0][0] + dp1[0][0] - 1) % MOD
```

## 复杂度
时间：O(n·k²)，每条父子边做一次 k×k 卷积。
空间：O(n·k)，存两个 DP 数组；`children` 另占 O(n)。

## 易错点
- 忘记减空集：示例 1 中 `dp0[0][0]` 初始为 1，若直接返回 `dp0[0][0] + dp1[0][0]` 会得到 2 而非 1，必须 `-1` 再取模。
- 卷积时 `dp1[u]` 只能乘子节点的 `dp0[v]`：若误乘 `dp0[v] + dp1[v]`，示例 2 中会允许 `{0,1}` 这类相邻组合，答案从 2 变成 3。

## 如果面试官追问
若 k 增大到 10^5 且 n 仍为 1000，怎么做？答：卷积退化为 O(n·k²) 不可行，需改用生成函数或 NTT 合并子树，或按模 k 的循环卷积优化。
