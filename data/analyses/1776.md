## 一句话思路
从右往左单调栈，栈里存「还没被追上、且追它更划算」的车，用相遇时间做单调性筛选。

## 怎么做
1. 从右往左遍历，栈中存下标，保证 `cars[栈顶].position` 递增（越靠右越靠前）。
2. 对当前车 `i`，先弹掉所有 `speed[i] <= speed[栈顶]` 的车——追不上，永远不算「下一辆」。
3. 剩下的栈顶 `j` 是候选，算 `t = (pos[j] - pos[i]) / (speed[i] - speed[j])`；若 `j` 自己也会在 `t` 之前被合并（`answer[j] != -1 and t >= answer[j]`），说明 `i` 实际先撞上的是 `j` 所在的那个车队，继续弹。
4. 弹到满足条件或栈空，`answer[i] = t` 或 `-1`，再把 `i` 入栈。

以示例 2 `[[3,4],[5,4],[6,3],[9,1]]` 为例：处理 `i=2`（pos 6, speed 3）时栈里是 `[3]`，`t = (9-6)/(3-1) = 1.5`，`answer[3] = -1` 不触发弹栈，得 `answer[2] = 1.5`。处理 `i=1`（pos 5, speed 4）时栈是 `[2,3]`，先算对 `2` 的 `t = (6-5)/(4-3) = 1.0`，而 `answer[2] = 1.5 > 1.0`，说明车 1 在车 2 合并前就追上了，直接取 1.0。

```python
n = len(cars)
ans = [-1.0] * n
st = []
for i in range(n - 1, -1, -1):
    pi, si = cars[i]
    while st:
        j = st[-1]
        pj, sj = cars[j]
        if si <= sj:
            st.pop()
            continue
        t = (pj - pi) / (si - sj)
        if ans[j] != -1.0 and t >= ans[j]:
            st.pop()
            continue
        break
    if st:
        j = st[-1]
        ans[i] = (cars[j][0] - pi) / (si - cars[j][1])
    st.append(i)
```

## 复杂度
时间 O(n)：每个下标最多入栈出栈各一次，`while` 总弹栈次数不超过 n。
空间 O(n)：`st` 最坏存 n 个下标，`ans` 另开 n 个 double。

## 易错点
- 输入 `[[1,2],[2,1],[4,3],[7,2]]`：若只弹 `si <= sj` 而不检查 `t >= ans[j]`，车 0 会算成追上被合并后的慢车队，得到错误时间。正确做法是保留 `t >= ans[j]` 的弹栈条件，让车 0 直接对上车 1 得 1.0。
- 输入 `[[3,4],[5,4],[6,3],[9,1]]`：若用 `si < sj` 而非 `si <= sj`，等速的车 0、1 会算出除零或无穷大。正确做法是等速也弹栈，因为后车永远追不上前车，`answer` 保持 `-1`。

## 如果面试官追问
问：如果要求输出每次合并的具体车辆集合而非时间？
答：在弹栈时记录被合并的下标链，用并查集或链表把 `i` 与栈顶合并，时间仍是 O(n)。
