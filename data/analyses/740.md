## 一句话思路
把相同数值合并成点数桶，问题变成「相邻桶不能同时取」的打家劫舍，用 DP 求最大和。

## 怎么做
1. 统计每个值 v 的总点数 `cnt[v] * v`，存进长度 `max(nums)+2` 的数组 `points`，下标即数值。
2. 定义 `dp[i]` 为只考虑数值 0..i 能拿到的最大点数，转移 `dp[i] = max(dp[i-1], dp[i-2] + points[i])`。
3. 取 `dp[max(nums)]` 返回。

用示例 2 `nums = [2,2,3,3,3,4]`：`points[2]=4`、`points[3]=9`、`points[4]=4`。算到 `dp[3]` 时，`dp[2]=4`（选 2 得 4），`dp[1]+points[3]=0+9=9`，取 9；再算 `dp[4]=max(9, dp[2]+4=8)=9`，最终 9，正好对应「全删 3」。

```python
m = max(nums)
points = [0] * (m + 2)
for v in nums:
    points[v] += v          # 同值累加，等价于 cnt[v]*v
prev2, prev1 = 0, 0         # dp[i-2], dp[i-1]
for i in range(1, m + 1):
    prev2, prev1 = prev1, max(prev1, prev2 + points[i])
return prev1
```

关键点：`points[v] += v` 循环一次就把重复值全加进去了，不需要额外 `Counter`；`prev2, prev1` 滚动时先存旧 `prev1` 再更新，顺序写反会用到已覆盖的值。

## 复杂度
时间 O(n + m)：n 是 `nums` 长度做一次累加，m 是 `max(nums)` 做一次 DP 扫描。
空间 O(m)：`points` 数组开 `max(nums)+2`，滚动变量只占常数。

## 易错点
- 输入 `nums = [2,2,3,3,3,4]` 若直接对原数组排序后做「相邻不能同取」，会把两个 2 当成互斥项，错成 6 或 7；正确做法是先按值聚合，`points[2]=4` 作为一个整体参与 DP。
- 输入 `nums = [1]` 或 `nums = [10000]` 时，若 `points` 只开到 `max(nums)` 而循环写成 `range(1, m+2)`，会越界；正确做法是数组开 `m+2`、循环到 `m`，或数组开 `m+1` 循环到 `m`，两者对齐。

## 如果面试官追问
问：要求输出具体选了哪些数值怎么办？
答：DP 时额外存 `choice[i]` 记录是否取 `points[i]`，从 `m` 往回走，取了就跳到 `i-2`，否则到 `i-1`。
