## 一句话思路
把 target 记 +1、其余记 -1，子数组和 > 0 即 target 过半，用前缀和 + 树状数组数逆序对。

## 怎么做
1. 令 `a[i] = 1 if nums[i] == target else -1`，前缀和 `pre[0]=0, pre[i]=pre[i-1]+a[i-1]`。
2. 子数组 `[l..r]` 满足 `pre[r+1] - pre[l] > 0`，即 `pre[l] < pre[r+1]`，对每个 `r+1` 数前面比它小的前缀和个数。
3. 前缀和取值在 `[-n, n]`，整体加 `n` 后落在 `[0, 2n]`，用树状数组按值域计数，边扫边查。

以 `nums=[1,2,2,3], target=2` 为例：`a=[-1,1,1,-1]`，`pre=[0,-1,0,1,0]`。扫到 `pre[4]=0` 时，前面比 0 小的只有 `pre[1]=-1`，贡献 1；累计得 5。

```python
n = len(nums)
size = 2 * n + 2
bit = [0] * (size + 1)
def add(i):
    i += 1
    while i <= size:
        bit[i] += 1
        i += i & -i
def query(i):          # 统计 <= i 的个数
    i += 1
    s = 0
    while i > 0:
        s += bit[i]
        i -= i & -i
    return s
ans = 0
add(n)                 # 放入 pre[0]=0（偏移 n）
cur = 0
for x in nums:
    cur += 1 if x == target else -1
    ans += query(cur + n - 1)   # 严格小于 cur 的前缀和
    add(cur + n)
```

## 复杂度
时间：O(n log n)，n 次树状数组查询与更新各 O(log n)。
空间：O(n)，bit 数组长度 2n+2，无其他额外结构。

## 易错点
- `nums=[2,2], target=2`：若用 `query(cur+n)` 统计「小于等于」，会把 `pre[l]==pre[r+1]` 的等值对算进去，答案从 3 变 4；必须查 `cur+n-1` 保证严格小于。
- `nums=[1,2,3], target=4`：target 不出现时 `a` 全为 -1，前缀和严格递减，任何子数组和都 ≤ -1；若忘记偏移 `+n` 直接用负下标访问 bit，会索引越界或静默错位，答案错成非 0。

## 如果面试官追问
若 n 放大到 10^5 且要求输出所有满足条件的子数组？答：枚举右端点时在树状数组上二分找第一个小于 `pre[r+1]` 的位置，逐个回溯输出，总代价 O(答案数 · log n)。
