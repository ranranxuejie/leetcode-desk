## 一句话思路
用 `dp[c]` 记以字母 c 结尾的最长理想子序列长度，每读一个字符只查它前后 k 个字母。

## 怎么做
1. 开长度 26 的数组 `dp`，`dp[c]` 表示以字母 c 结尾的最长理想子序列长度，初值全 0。
2. 遍历 `s` 中每个字符 `ch`，令 `x = ord(ch) - 97`，在 `[x-k, x+k]` 与 `[0,25]` 的交集里取 `dp` 最大值 `best`。
3. 更新 `dp[x] = max(dp[x], best + 1)`，同时维护全局答案。
4. 返回全局最大值。

以 `s = "acfgbd", k = 2` 为例：读到 `'f'`（x=5）时，窗口是字母 3..7，此时 `dp['c'=2] = 2`（"ac"）不在窗口内，`dp['a'=0] = 1` 也不在，窗口内最大是 `dp['d'?]` 尚未出现，实际 `best = 0`，于是 `dp[5] = 1`——这正是 "acfgbd" 里 f 不能接在 c 后面的体现。读到 `'b'`（x=1）时窗口 0..3，`dp['a'=0]=1`、`dp['c'=2]=2`，取 `best=2`，`dp[1]=3`（"acb"）；再读到 `'d'`（x=3）窗口 1..5，`dp['b'=1]=3`，`dp[3]=4`（"acbd"）。

```python
dp = [0] * 26
ans = 0
for ch in s:
    x = ord(ch) - 97
    lo, hi = max(0, x - k), min(25, x + k)
    best = max(dp[lo:hi + 1])
    dp[x] = max(dp[x], best + 1)
    ans = max(ans, dp[x])
return ans
```

关键点：`dp[x]` 用 `max` 而不是直接赋值，因为同一字母可能出现多次，后来的可能接上更长的前缀。

## 复杂度
时间 O(26n)：每个字符扫最多 26 个窗口位置，n 是 `len(s)`。
空间 O(1)：只开 26 个槽的 `dp`，与 n 无关。

## 易错点
- `k = 0` 且 `s = "aaaa"` → 若写成 `dp[x] = best + 1` 而不取 `max`，每次都被重置为 1，答案错成 1 → 正确是 `dp[x] = max(dp[x], best + 1)`，得 4。
- `s = "abcd", k = 3` → 若窗口写成 `[x-k, x]` 只往前看，`'a'` 之后 `'d'` 的窗口 0..3 仍能取到 `dp['c']=3`，这题碰巧对；但若写成只查 `x-1` 和 `x+1` 两个邻居，`k=3` 时 `'a'` 到 `'d'` 差 3 就漏了 → 必须扫满 `x-k` 到 `x+k` 整段。

## 如果面试官追问
要求输出这个最长理想子序列本身怎么办？
答：`dp` 改存 `(长度, 前驱字符, 前驱下标)`，最后从最大长度处沿前驱回溯即可。
