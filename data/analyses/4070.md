## 一句话思路
逐位累加环形距离 `min(|a-b|, 10-|a-b|)`，因为每步独立取最短方向即全局最优。

## 怎么做
1. 用 `prev = 0` 记录指针当前位置，初始指向 0。
2. 遍历 `s` 中每个字符，转成整数 `cur`。
3. 计算 `d = abs(cur - prev)`，取 `min(d, 10 - d)` 累加到答案。
4. 更新 `prev = cur`，继续下一位。

以 `s = "0192837465"` 为例，走到第 3 步时 `prev = 1`、`cur = 9`，`d = 8`，`10 - d = 2`，取 2（1→0→9 反向更近），累加后 `prev = 9`。第 4 步 `prev = 9`、`cur = 2`，`d = 7`，`10 - d = 3`，取 3，与示例表格一致。

```python
prev = 0
ans = 0
for ch in s:
    cur = int(ch)
    d = abs(cur - prev)
    ans += min(d, 10 - d)
    prev = cur
return ans
```

关键点：`10 - d` 是反向走的步数，因为 0 和 9 相邻，环上一共 10 个数字，两个方向步数之和恒为 10。所以每步只需比较 `d` 和 `10 - d`，不需要模拟旋转过程。

## 复杂度
时间：O(n)，n 为 `s` 长度，每个字符做一次常数运算。
空间：O(1)，只开 `prev`、`ans`、`cur`、`d` 四个变量。

## 易错点
- 输入 `s = "09"` → 若只写 `abs(cur - prev)` 会得 9 → 正确做法是取 `min(9, 10 - 9) = 1`，因为 0 和 9 在环上相邻，反向一步就到。
- 输入 `s = "55"` → 若忘记更新 `prev` 或把 `prev` 初始成 `s[0]` 而非 0 → 会少算或多算首步 → 正确做法是 `prev = 0` 起步，第一位也要算 `0` 到 `s[0]` 的距离（如 `s[0] = '0'` 时贡献 0，`s[0] = '5'` 时贡献 5）。

## 如果面试官追问
问：如果拨号盘不是 0-9 顺序排列，而是任意给定一个环，怎么做？
答：把每个数字映射到环上的下标，距离改成 `min(|i-j|, m-|i-j|)`，m 为环长，其余逻辑不变。
