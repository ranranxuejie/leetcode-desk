## 一句话思路
按字符逐个维护「以 0 结尾」和「以 1 结尾」的不同好子序列数，遇到重复字符时用减法去重。

## 怎么做
1. 设 `end0`、`end1` 分别表示以 0、1 结尾的不同好子序列个数，初值 0。
2. 遍历 `binary`，遇到 `'1'` 时 `end1 = end1 + end0 + 1`，遇到 `'0'` 时 `end0 = end0 + end1`。
3. 若字符串中出现过 `'0'`，答案额外加 1（单独的 `"0"`），最后对 `10**9 + 7` 取余。

以 `binary = "101"` 为例：初始 `end0=end1=0`。读到第一个 `'1'`：`end1 = 0+0+1 = 1`；读到 `'0'`：`end0 = 0+1 = 1`；读到第二个 `'1'`：`end1 = 1+1+1 = 3`。出现过 `'0'`，答案 `1+3+1 = 5`，与示例一致。

```python
MOD = 10**9 + 7
end0 = end1 = 0
has_zero = False
for ch in binary:
    if ch == '1':
        end1 = (end1 + end0 + 1) % MOD
    else:
        has_zero = True
        end0 = (end0 + end1) % MOD
ans = (end0 + end1 + (1 if has_zero else 0)) % MOD
```

关键点：`end1` 更新时加 `end0` 是因为任何以 0 结尾的好子序列后接 `'1'` 仍合法；加 1 是单独的 `"1"`。`end0` 不加 1，因为单独的 `"0"` 只算一次，统一在最后补。

## 复杂度
时间：O(n)，n 为 `binary` 长度，单次遍历。
空间：O(1)，只开 `end0`、`end1`、`has_zero` 三个变量。

## 易错点
- 输入 `"001"`：若对每个 `'0'` 都执行 `end0 += 1`，会把 `"0"` 重复计数成 2 次，得到 3 而非 2。正确做法是 `end0` 更新不加 1，单独的 `"0"` 只在最后按 `has_zero` 补一次。
- 输入 `"11"`：若 `end1` 更新写成 `end1 = end1 + 1`（漏加 `end0`），第二个 `'1'` 只得到 2，漏掉 `"11"`。正确做法是 `end1 = end1 + end0 + 1`，让已有以 0 结尾的子序列都能接上这个 `'1'`。

## 如果面试官追问
问：若要求输出所有不同好子序列本身而非计数？
答：同样用 `end0`/`end1` 存集合而非计数，每次把 `end0` 中每个串拼 `'1'` 并入 `end1`，复杂度升到 O(答案总长)。
