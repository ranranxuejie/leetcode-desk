## 一句话思路
先 BFS 建出「每个词到 endWord 的最短距离」层图，再在层图上 DFS 回溯，只走距离递减的边，保证每条路径都最短。

## 怎么做
1. 若 `endWord` 不在 `wordList`，直接返回 `[]`；把 `beginWord` 加入集合。
2. 从 `beginWord` 做 BFS，`dist[w]` 记录到 `beginWord` 的层数，同时记录每个词的邻居。
3. 用 `dist` 剪枝：DFS 时只从 `dist` 大的一层走向 `dist` 小一层的邻居。
4. 到达 `endWord` 时把当前路径 `path` 拷一份加入结果。

以示例 1 为例：BFS 后 `dist = {hit:0, hot:1, dot:2, lot:2, dog:3, log:3, cog:4}`。DFS 从 `hit` 出发，`hot` 的邻居里 `dot`、`lot` 的 `dist` 都是 2，都满足 `dist[dot] == dist[hot]+1`，两条分支都保留，最终得到两条长度 5 的路径。

```python
from collections import deque, defaultdict

def findLadders(beginWord, endWord, wordList):
    words = set(wordList)
    if endWord not in words:
        return []
    words.add(beginWord)
    dist = {beginWord: 0}
    q = deque([beginWord])
    while q:
        w = q.popleft()
        for i in range(len(w)):
            for c in 'abcdefghijklmnopqrstuvwxyz':
                nxt = w[:i] + c + w[i+1:]
                if nxt in words and nxt not in dist:
                    dist[nxt] = dist[w] + 1
                    q.append(nxt)
    res, path = [], [beginWord]
    def dfs(w):
        if w == endWord:
            res.append(path[:]); return
        for i in range(len(w)):
            for c in 'abcdefghijklmnopqrstuvwxyz':
                nxt = w[:i] + c + w[i+1:]
                if dist.get(nxt) == dist[w] + 1:
                    path.append(nxt); dfs(nxt); path.pop()
    dfs(beginWord)
    return res
```

## 复杂度
时间：BFS 与 DFS 各 O(N·L·26)，N 为词数、L 为词长，DFS 最坏枚举所有最短路径。
空间：`dist` 与队列 O(N)，递归栈与 `path` O(L)，结果集另计。

## 易错点
- `endWord` 不在 `wordList`（示例 2）→ 若先 BFS 再判空，会白跑一遍且 `dist` 里没有 `cog`，DFS 永远到不了终点却返回 `[]` 看似正确，但若 `beginWord` 恰能一步到 `cog` 就会误判 → 入口先 `if endWord not in words: return []`。
- 用 `dist[nxt] == dist[w] + 1` 判边时，若把 `beginWord` 漏加进 `words`，`hit` 的邻居 `hot` 能搜到但 `dist` 里没有 `hit` 的层信息 → BFS 起点必须显式 `words.add(beginWord)` 并 `dist[beginWord]=0`。

## 如果面试官追问
问：词表到 5000、词长到 10 怎么优化？答：预处理通配符桶 `h*t -> [hot, hit]` 建图，把每层 26·L 的枚举降到桶内邻居数。
