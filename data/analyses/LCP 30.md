## 一句话思路
从左到右累加血量，一旦跌破 0 就把此前扣血最多的怪物挪到末尾，用大顶堆维护已访问的负数。

## 怎么做
1. 用 `hp` 记录当前血量（初始 1），`heap` 存已访问房间里的负数（取相反数，即大顶堆），`ans` 记调整次数。
2. 遍历 `nums`：`hp += x`；若 `x < 0` 就 `heappush(heap, -x)`。
3. 若 `hp <= 0`，从堆顶弹出最大的扣血量 `d`，`hp += d`、`ans += 1`——把最伤的那个怪挪到最后，等价于此刻先不扣它。
4. 遍历结束后若 `hp + sum(所有被挪走的 d) <= 0`，说明总血量都不够，返回 -1；否则返回 `ans`。

以示例 1 的 `nums = [100,100,100,-250,-60,-140,-50,-50,100,150]` 为例：走到 `-250` 时 `hp = 1+300-250 = 51`，仍为正；继续到 `-140` 时 `hp = 51-60-140 = -149 <= 0`，堆顶是 250，弹出后 `hp = 101`、`ans = 1`，之后一路为正，返回 1。

```python
import heapq
hp, ans, heap = 1, 0, []
for x in nums:
    hp += x
    if x < 0:
        heapq.heappush(heap, -x)
    if hp <= 0 and heap:
        hp += -heapq.heappop(heap)
        ans += 1
if hp <= 0:
    return -1
return ans
```

注意第 4 步的判定：被挪走的怪最终仍要打，所以真正可用的总血量是 `hp`（已把挪走的补回来）加上后续所有房间之和，等价于 `1 + sum(nums) > 0`。代码里遍历完的 `hp` 已经加回了所有弹出的 `d`，因此直接判 `hp <= 0` 即可。

## 复杂度
时间 O(n log n)：n 个房间各入堆一次，每次弹出 O(log n)，最多弹 n 次。
空间 O(n)：`heap` 最坏存下全部负数房间。

## 易错点
- 输入 `nums = [-200,-300,400,0]`：若只判「遍历中 `hp <= 0` 就弹堆」，弹完 `-200` 后 `hp = 1`，再遇 `-300` 又弹，最终 `ans = 2` 却仍返回 2 而非 -1。正确做法是遍历结束后再判一次 `hp <= 0` 返回 -1，因为挪到末尾的怪照样要打。
- 输入 `nums = [0, -1]`：若把 `x <= 0` 都入堆，`0` 会被当成怪物弹出，`ans` 虚增。正确做法是只对 `x < 0` 入堆，`0` 房间既不加血也不扣血，不该被调整。

## 如果面试官追问
要求输出具体挪动了哪些房间怎么办？答：堆里存 `(扣血量, 下标)`，弹出时把下标记进结果列表，最后按原顺序输出即可。
