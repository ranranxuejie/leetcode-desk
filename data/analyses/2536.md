## 一句话思路
用二维差分矩阵记录每个查询的四个角，最后对差分矩阵做二维前缀和还原出答案。

## 怎么做
1. 开一个 `(n+1) x (n+1)` 的差分矩阵 `diff`，多出的一行一列用来免去边界判断。
2. 对每个 `[r1,c1,r2,c2]`，在 `diff[r1][c1] += 1`、`diff[r1][c2+1] -= 1`、`diff[r2+1][c1] -= 1`、`diff[r2+1][c2+1] += 1`。
3. 对 `diff` 做二维前缀和，`diff[i][j] += diff[i-1][j] + diff[i][j-1] - diff[i-1][j-1]`。
4. 取左上 `n x n` 部分作为结果返回。

以示例 1 的 `n=3, queries=[[1,1,2,2],[0,0,1,1]]` 为例，处理第一个查询后 `diff[1][1]=1, diff[1][3]=-1, diff[3][1]=-1, diff[3][3]=1`；处理第二个查询后 `diff[0][0]=1, diff[0][2]=-1, diff[2][0]=-1, diff[2][2]=1`。前缀和还原后 `diff[1][1]` 处累加得 2，正是答案矩阵中心元素。

```python
diff = [[0] * (n + 1) for _ in range(n + 1)]
for r1, c1, r2, c2 in queries:
    diff[r1][c1] += 1
    diff[r1][c2 + 1] -= 1
    diff[r2 + 1][c1] -= 1
    diff[r2 + 1][c2 + 1] += 1
for i in range(n):
    for j in range(n):
        diff[i][j] += (diff[i-1][j] if i else 0) + (diff[i][j-1] if j else 0) - (diff[i-1][j-1] if i and j else 0)
return [row[:n] for row in diff[:n]]
```

## 复杂度
时间：O(n² + q)，q 为查询数，每个查询 O(1)，前缀和扫 n² 格。
空间：O(n²)，额外开了 `(n+1)²` 的差分矩阵。

## 易错点
- `c2+1` 或 `r2+1` 等于 n 时，若差分矩阵只开 `n x n` 会越界 → 正确做法是开 `(n+1) x (n+1)`，让右下角的减操作落在第 n 行/列上，最后只取前 n 行 n 列。
- 前缀和循环里对 `i=0` 或 `j=0` 直接访问 `diff[i-1][j]` 会取到末行（Python 负索引）→ 必须显式判断 `if i` / `if j`，或把循环从 1 开始并保留第 0 行第 0 列为 0。

## 如果面试官追问
问：如果 n 大到 10^9 但查询很少怎么办？
答：改用坐标压缩，只对查询涉及的边界行列建差分，复杂度降到 O(q²)。
