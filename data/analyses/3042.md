## 一句话思路
n≤50、串长≤10，直接双重循环枚举 i<j，用 `startswith` 和 `endswith` 判断即可。

## 怎么做
1. 外层 `i` 从 0 到 n-1，内层 `j` 从 `i+1` 到 n-1，只统计 i<j 的对。
2. 对每对先比较长度：`len(words[i]) > len(words[j])` 直接跳过，短串不可能是长串的前后缀。
3. 长度过关后同时检查 `words[j].startswith(words[i])` 和 `words[j].endswith(words[i])`，两者都真才 `ans += 1`。

以示例 1 `words = ["a","aba","ababa","aa"]` 为例，`i=0, j=3` 时 `words[0]="a"`、`words[3]="aa"`，`"aa".startswith("a")` 为 `True`、`"aa".endswith("a")` 也为 `True`，计数加一；而 `i=1, j=3` 时 `len("aba")=3 > len("aa")=2`，长度检查直接跳过，不会误判。

```python
ans = 0
n = len(words)
for i in range(n):
    a = words[i]
    for j in range(i + 1, n):
        b = words[j]
        if len(a) <= len(b) and b.startswith(a) and b.endswith(a):
            ans += 1
return ans
```

注意 `startswith`/`endswith` 在 `a` 比 `b` 长时本身就返回 `False`，长度检查只是提前剪枝，去掉也不影响正确性，但保留能少做两次切片比较。

## 复杂度
时间 O(n² · L)，n 是 words 长度、L 是串长上限 10，每对做两次长度 L 的匹配。
空间 O(1)，只用了 `ans`、`i`、`j`、`a`、`b` 几个变量。

## 易错点
- 输入 `["abab","ab"]` → 若只查前缀不查后缀，会误判 `i=0,j=1` 成立得 1，实际 `"abab".endswith("ab")` 为 `True` 但 `"abab".startswith("ab")` 也为 `True`，这题真正翻车点是反过来：`["ab","abab"]` 顺序下 `i=0,j=1` 才成立，而示例 3 是长串在前，必须靠 `i<j` 的下标顺序而非长度顺序，别自作聪明按长度排序。
- 输入 `["a","a"]` → 若用 `set` 去重或按字符串值分组计数，会把两个相同串当成一个，漏掉 `(0,1)` 这一对；必须按下标枚举，相同字符串也要各算各的。

## 如果面试官追问
若 n 放大到 10^5、串长仍 ≤10，怎么做？答：把所有串按长度分桶，对每个 `words[j]` 枚举其所有前缀（≤10 个）作为候选 `str1`，在哈希表里查该前缀串在 j 之前出现几次，累加即可，O(n·L²)。
