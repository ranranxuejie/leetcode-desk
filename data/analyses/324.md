## 一句话思路
先排序，再把数组从中间劈成两半，倒序交错填入偶数位和奇数位，保证相邻不等。

## 怎么做
1. 排序 `nums`，得到非递减序列。
2. 取 `mid = (n - 1) // 2`，把 `[0..mid]` 视为小半区、`[mid+1..n-1]` 视为大半区。
3. 用两个指针 `i = mid`、`j = n - 1`，从各自末尾倒着取，交替写入结果数组的偶数下标 `0,2,4...` 和奇数下标 `1,3,5...`。
4. 把结果写回 `nums`。

以 `nums = [1,5,1,1,6,4]` 为例：排序后 `[1,1,1,4,5,6]`，`n=6`，`mid=2`，小半区 `[1,1,1]`、大半区 `[4,5,6]`。倒序取：`i=2` 取 1 放 `res[0]`，`j=5` 取 6 放 `res[1]`，`i=1` 取 1 放 `res[2]`，`j=4` 取 5 放 `res[3]`，`i=0` 取 1 放 `res[4]`，`j=3` 取 4 放 `res[5]`，得 `[1,6,1,5,1,4]`。

```python
nums.sort()
n = len(nums)
res = [0] * n
mid = (n - 1) // 2
i, j = mid, n - 1
for k in range(n):
    if k % 2 == 0:
        res[k] = nums[i]; i -= 1
    else:
        res[k] = nums[j]; j -= 1
nums[:] = res
```

关键在倒序：小半区从 `mid` 往前、大半区从 `n-1` 往前，这样重复元素（如三个 1）被推到偶数位最左端，不会和大半区的最小值撞在相邻位置。

## 复杂度
时间：排序 `O(n log n)`，交错填充 `O(n)`，总 `O(n log n)`。
空间：`res` 数组 `O(n)`；进阶的 `O(1)` 需快速选择 + 三路划分原地做。

## 易错点
- 输入 `[1,1,2,2]` 这类两两重复：若正序交错（小半区从头取、大半区从头取），会得到 `[1,2,1,2]` 看似对，但 `[1,1,1,2,2,2]` 正序会撞出相邻相等 → 必须两个半区都**倒序**取。
- 输入 `[4,5,5,6]`：`mid=(4-1)//2=1`，小半区 `[4,5]`、大半区 `[5,6]`。若把 `mid` 算成 `n//2=2`，小半区变 `[4,5,5]`，5 会同时出现在 `res[2]` 和 `res[3]` 相邻 → `mid` 必须取 `(n-1)//2`，让小半区长度 `⌈n/2⌉`。

## 如果面试官追问
问：要求 `O(n)` 时间且 `O(1)` 空间怎么办？
答：用快速选择找中位数，再按 `(2*i+1) % (n|1)` 映射做三路划分原地交错，把大于中位数的放奇数位、小于的放偶数位。
