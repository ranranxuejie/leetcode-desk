## 一句话思路
双指针贪心匹配，每个 str2[j] 只需 str1[i] 等于它或等于它的前一字符（循环意义），匹配上就同时前进。

## 怎么做
1. 设 i 扫 str1、j 扫 str2，初值都为 0。
2. 对每个 str1[i]，判断它能否变成 str2[j]：`str1[i] == str2[j]` 或 `(ord(str1[i]) - 96) % 26 + 97 == ord(str2[j])`，即循环加一后相等。
3. 能匹配就 `j += 1`；无论是否匹配，`i += 1` 继续往后扫。
4. 扫完若 `j == len(str2)` 返回 `True`，否则 `False`。

用示例 1 `str1 = "abc", str2 = "ad"`：i=0 时 `'a'` 匹配 `'a'`，j 变 1；i=1 时 `'b'` 既不等于 `'d'`，加一后是 `'c'` 也不等于 `'d'`，跳过；i=2 时 `'c'` 加一得 `'d'`，匹配成功，j 变 2，等于 `len(str2)`，返回 `True`。关键中间值就是 i=2 时 `(ord('c')-96)%26+97 == ord('d')` 成立。

```python
i = j = 0
while i < len(str1) and j < len(str2):
    if str1[i] == str2[j] or (ord(str1[i]) - 96) % 26 + 97 == ord(str2[j]):
        j += 1
    i += 1
return j == len(str2)
```

注意 `ord('z')-96 = 26`，`26 % 26 = 0`，`0 + 97 = 97` 即 `'a'`，循环递增正确闭合。

## 复杂度
时间 O(len(str1))，i 只前进不回头，str2 的扫描被 i 的推进吸收。
空间 O(1)，只开了 i、j 两个整数。

## 易错点
- 输入 `str1 = "z", str2 = "a"` → 若用 `chr(ord(str1[i])+1)` 直接加一会得到 `'{'`，判成不匹配而错答 `False` → 必须用 `(ord(c)-96) % 26 + 97` 处理 `'z'→'a'` 的回绕。
- 输入 `str1 = "ab", str2 = "d"` → 若把「至多一次操作」理解成「必须操作」或允许对同一字符多次加一，会误判 → 每个下标最多加一，`'a'` 只能变 `'b'`，不能变 `'d'`，所以返回 `False`。

## 如果面试官追问
问：若允许每个字符循环递增任意次（不限于一次）呢？
答：条件放宽为 `(ord(str2[j]) - ord(str1[i])) % 26 >= 0` 恒成立，即任意字符都能变成任意字符，只需 `len(str1) >= len(str2)` 即返回 `True`。
