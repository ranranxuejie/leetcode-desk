## 一句话思路
二分答案 x，只保留 cost≥x 的边做 DAG 最短路，判断 0→n-1 的最小总成本是否 ≤k。

## 怎么做
1. 二分答案 x 落在 `[0, max(cost)]`，判定函数 `feasible(x)` 只保留 `cost >= x` 的边。
2. 在过滤后的 DAG 上按拓扑序 DP 求 `dist[v]` = 从 0 到 v 的最小总成本，离线中间节点直接跳过。
3. 若 `dist[n-1] <= k` 则 x 可行，向右收缩；否则向左。

以示例 1 为例，`edges=[[0,1,5],[1,3,10],[0,2,3],[2,3,4]]`，`k=10`。取 x=3 时保留全部边，拓扑序 0,1,2,3：`dist[1]=5`，`dist[2]=3`，`dist[3]=min(5+10, 3+4)=7 ≤ 10`，可行；取 x=4 时边 `[0,2,3]` 被过滤，`dist[2]=inf`，`dist[3]=15 > 10`，不可行，故答案 3。

```python
def feasible(x):
    dist = [INF] * n
    dist[0] = 0
    for u in topo:
        if dist[u] == INF:
            continue
        for v, c in adj[u]:
            if c >= x and online[v] and dist[u] + c < dist[v]:
                dist[v] = dist[u] + c
    return dist[n - 1] <= k
```

`topo` 与 `adj` 预处理一次即可，二分内只做一遍 O(n+m) 的 DP。

## 复杂度
时间：二分 O(log(maxcost)) 轮，每轮 O(n+m)，共 O((n+m) log C)。
空间：`adj` 存 m 条边、`dist` 与 `topo` 各 n，共 O(n+m)。

## 易错点
- 中间节点离线时若只过滤边不过滤点，示例 2 中 `0→2→3→4` 会被当成候选路径（成本 14 恰好超 k 才侥幸不误判），换一组 cost 更小的数据就会把离线节点 3 算进路径 → 正确做法是在 DP 松弛时对 `v != n-1` 检查 `online[v]`，或预处理时直接删掉所有离线中间节点的入边。
- `dist` 初值用 `2**31 - 1` 或 `10**18` 都行，但 `k` 可达 `5*10**13`、单边 cost 可达 `10**9`，若用 `float('inf')` 与整数相加再比较虽不报错，但 `dist[u] + c` 在 `dist[u]` 为 inf 时会得到 inf 并参与 `min`，需先 `if dist[u] == INF: continue` 跳过，否则拓扑序靠后的节点可能被 inf 污染成「看似可达」。

## 如果面试官追问
问：要求输出具体路径而不只是分数？
答：二分确定 x 后，在可行图上再跑一次 DP 并记录 `pre[v]`，从 n-1 回溯即可，代价仍是 O(n+m)。
