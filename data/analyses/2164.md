## 一句话思路
把偶数下标和奇数下标的值分别抽出，一个升序一个降序，再按原下标交错写回。

## 怎么做
1. 用切片 `nums[0::2]` 和 `nums[1::2]` 分别取出偶数位、奇数位的值。
2. 偶数位列表升序排序，奇数位列表降序排序。
3. 用步长 2 的切片赋值把两个有序列表写回原数组对应位置。

以 `nums = [4,1,2,3]` 为例：`even = [4,2]` 排序后为 `[2,4]`，`odd = [1,3]` 降序后为 `[3,1]`；写回后 `nums[0::2] = [2,4]`、`nums[1::2] = [3,1]`，得到 `[2,3,4,1]`。

```python
even = nums[0::2]
odd = nums[1::2]
even.sort()
odd.sort(reverse=True)
nums[0::2] = even
nums[1::2] = odd
return nums
```

关键在切片赋值：`nums[0::2]` 的长度必须和 `even` 一致，否则 Python 会改变数组长度。本题两个列表长度天然匹配，所以安全。

## 复杂度
时间 O(n log n)：两个子序列各自排序，长度各约 n/2。
空间 O(n)：`even` 和 `odd` 两个列表合计存了 n 个元素。

## 易错点
- 输入 `nums = [4,1,2,3]` 时若把奇数位也升序排，会得到 `[2,1,4,3]`，与期望 `[2,3,4,1]` 不符；奇数位必须 `reverse=True`。
- 输入长度为奇数如 `nums = [5,3,1]` 时，若误以为 `even` 和 `odd` 等长而用同一个下标遍历写回，会越界或漏掉最后一个偶数位；正确做法是直接用切片赋值，让 Python 按各自长度对齐。

## 如果面试官追问
问：如果要求原地排序、不许开额外数组怎么办？
答：仍要先把两组值各拷到临时列表排序，再写回；纯原地交换无法保证两组独立有序。
