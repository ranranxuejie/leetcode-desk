## 一句话思路
按 n 的奇偶分两支：奇数返回 `2*n`，偶数返回 `n`，因为 2 与奇数互质、偶数本身已含因子 2。

## 怎么做
1. 判断 `n % 2` 是否为 1，是则 2 与 n 互质，最小公倍数就是乘积 `2*n`。
2. 否则 n 已被 2 整除，n 自身就是 2 和 n 的公倍数，且没有更小的正倍数，直接返回 `n`。
3. 用官方示例 n = 5 走一遍：`5 % 2 == 1` 成立，走第一支，返回 `2*5 = 10`，与输出一致。
4. 用 n = 6 走一遍：`6 % 2 == 1` 为 `False`，走第二支返回 `6`，注意 6 是它自身的倍数，不是 12。

```python
def smallestEvenMultiple(n: int) -> int:
    if n % 2 == 1:
        return 2 * n
    return n
```

也可以写成一行 `return n if n % 2 == 0 else 2 * n`，判断顺序反过来，逻辑等价。关键中间值只有 `n % 2` 这一个：n = 5 时它是 1，n = 6 时它是 0，分支完全由它决定，不需要真的去算 gcd 或枚举倍数。

如果坚持用通式 `n * 2 // gcd(n, 2)`，n = 5 时 `gcd(5,2)=1` 得 10，n = 6 时 `gcd(6,2)=2` 得 `12//2=6`，结果一样，但多一次 gcd 调用，对本题规模没必要。

## 复杂度
时间：O(1)，只做一次取模和一次乘法，与 n 的大小无关。
空间：O(1)，没有开任何额外容器，只用了常数个临时值。

## 易错点
- 输入 n = 6 → 若误以为「最小偶倍数」是「大于 n 的最小偶数」而返回 8 或 12 → 正确做法是返回 n 本身，因为 6 已经是 2 的倍数，题目要的是 2 和 n 的最小公倍数而非严格大于 n。
- 输入 n = 1 → 若写成 `n if n % 2 == 1 else 2*n` 把两支写反，会返回 1，但 1 不是偶数 → 正确做法是奇数支返回 `2*n`，n = 1 时得 2，这才是 2 和 1 的最小公倍数。

## 如果面试官追问
问：若把 2 换成任意正整数 k，求 k 和 n 的最小公倍数怎么写？
答：`n * k // gcd(n, k)`，用 `math.gcd`，k = 2 时退化成上面的分支写法。
