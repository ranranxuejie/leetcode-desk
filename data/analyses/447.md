## 一句话思路
固定回旋镖的拐点 i，用哈希表统计其余点到 i 的距离，同距离有 c 个点就贡献 c*(c-1) 个有序元组。

## 怎么做
1. 外层枚举拐点 `i`，内层枚举 `j != i`，算距离平方 `d = (xi-xj)**2 + (yi-yj)**2`，累加到 `cnt[d]`。
2. 用距离平方而非开根，避免浮点误差；坐标差最大 2*10^4，平方和最大 8*10^8，Python 整数无压力。
3. 内层结束后遍历 `cnt.values()`，对每个计数 `c` 累加 `c * (c - 1)`，因为 j、k 有序。
4. 换下一个拐点，清空哈希表重来。

以 `points = [[0,0],[1,0],[2,0]]` 为例，拐点取 `i=1`（点 `[1,0]`）时：到 `[0,0]` 的 `d=1`，到 `[2,0]` 的 `d=1`，`cnt = {1: 2}`，贡献 `2*1 = 2`；拐点取 `i=0` 时 `cnt = {1:1, 4:1}`，贡献 0；拐点取 `i=2` 同理贡献 0，总计 2。

```python
n = len(points)
ans = 0
for i in range(n):
    xi, yi = points[i]
    cnt = {}
    for j in range(n):
        if j == i:
            continue
        xj, yj = points[j]
        d = (xi - xj) ** 2 + (yi - yj) ** 2
        cnt[d] = cnt.get(d, 0) + 1
    for c in cnt.values():
        ans += c * (c - 1)
return ans
```

关键点：`c * (c - 1)` 而不是 `c * (c - 1) // 2`，因为 `(i, j, k)` 和 `(i, k, j)` 是两个不同回旋镖。

## 复杂度
时间：O(n^2)，外层 n 个拐点，内层扫 n 个点算距离。
空间：O(n)，每个拐点的哈希表最多存 n-1 个不同距离。

## 易错点
- 输入 `[[0,0],[1,0],[2,0]]` 若写成 `c * (c - 1) // 2`，会得 1 而非 2；题目要求元组有序，j 和 k 交换算两个，必须用 `c * (c - 1)`。
- 输入 `[[1,1],[2,2],[3,3]]` 若用 `math.sqrt` 开根比较距离，浮点误差可能让本相等的距离判不相等；应全程用距离平方 `(xi-xj)**2 + (yi-yj)**2` 作哈希键。

## 如果面试官追问
若 n 扩大到 10^5 怎么办？答：O(n^2) 不可行，需按距离分组后对每组用几何/哈希优化，或说明该规模下无已知亚二次解法。
