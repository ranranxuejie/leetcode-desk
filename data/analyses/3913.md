## 一句话思路
先统计元音频率和首次出现位置，按 `(-freq, first)` 排序元音字母，再按原顺序填回元音位置。

## 怎么做
1. 遍历 `s`，用 `cnt` 记元音频率、`first` 记首次出现下标，同时把元音位置存进 `pos`。
2. 对出现过的元音按 `(-cnt[c], first[c])` 排序，得到字母顺序 `order`。
3. 把 `order` 按频率展开成字符序列，依次写回 `pos` 中的位置。

以 `s = "leetcode"` 为例：`pos = [1,2,4,7]`，`cnt = {e:3, o:1}`，`first = {e:1, o:4}`；排序后 `order = ['e','o']`，展开得 `['e','e','e','o']`，写回后 `s[1]=e, s[2]=e, s[4]=e, s[7]=o`，即 `"leetcedo"`。

```python
vowels = set('aeiou')
cnt, first, pos = {}, {}, []
for i, ch in enumerate(s):
    if ch in vowels:
        if ch not in cnt:
            first[ch] = i
        cnt[ch] = cnt.get(ch, 0) + 1
        pos.append(i)
order = sorted(cnt, key=lambda c: (-cnt[c], first[c]))
chars = [c for c in order for _ in range(cnt[c])]
res = list(s)
for i, c in zip(pos, chars):
    res[i] = c
return ''.join(res)
```

## 复杂度
时间：O(n + 5log5)，n 为 `s` 长度，遍历与写回各一次，排序只涉及至多 5 个元音。
空间：O(n)，`pos` 与 `res` 各占 O(n)，`cnt`/`first` 至多 5 项。

## 易错点
- 输入 `"baeiou"` → 若只按频率排序、忽略首次位置，`sorted` 对同频字母按字典序给出 `a,e,i,o,u`，本例恰好对；但换成 `"uoiea"` 就会错排成 `aeiou` → 必须把 `first[c]` 作为第二关键字。
- 输入 `"leetcode"` → 若把非元音也纳入排序或直接对整串排序，`l`、`t`、`c`、`d` 会被移动，输出不再是 `"leetcedo"` → 只对 `pos` 记录的位置写回，非元音位置原样保留。

## 如果面试官追问
若要求同频时按字母表顺序而非首次出现位置？答：把排序键改成 `(-cnt[c], c)`，其余流程不变。
