## 一句话思路
双指针从两串末尾往前逐位相加，用 `carry` 记录进位，最后把剩余进位补到结果最前面。

## 怎么做
1. 令 `i = len(a) - 1`、`j = len(b) - 1`、`carry = 0`，结果用列表 `res` 从后往前收集。
2. 每轮取 `x = int(a[i]) if i >= 0 else 0`，`y` 同理，算 `total = x + y + carry`，把 `total % 2` 追加进 `res`，`carry = total // 2`。
3. 两个指针都走完后，若 `carry` 还是 1，再追加一个 `'1'`。
4. 把 `res` 反转拼成字符串返回。

以 `a = "1010", b = "1011"` 为例，走到 `i = 0, j = 0` 这一轮时，`x = 1, y = 1, carry = 1`，`total = 3`，写入 `'1'`、`carry` 变 1；循环结束后 `carry` 仍为 1，补上最高位，得到 `"10101"`。

```python
i, j, carry, res = len(a) - 1, len(b) - 1, 0, []
while i >= 0 or j >= 0 or carry:
    x = int(a[i]) if i >= 0 else 0
    y = int(b[j]) if j >= 0 else 0
    total = x + y + carry
    res.append(str(total % 2))
    carry = total // 2
    i -= 1
    j -= 1
return ''.join(reversed(res))
```

关键是循环条件写成 `or carry`，这样 `a = "1", b = "1"` 时不会漏掉最高位的 `'1'`。

## 复杂度
时间 O(max(len(a), len(b)))，逐位扫描一遍，n 取较长串长度。
空间 O(max(len(a), len(b)))，`res` 列表最多存 n+1 个字符。

## 易错点
- 输入 `a = "1", b = "1"` → 若循环只写 `while i >= 0 or j >= 0`，最后 `carry = 1` 被丢掉，输出 `"0"` → 循环条件必须带上 `or carry`，或在循环后单独补一位。
- 输入 `a = "0", b = "0"` → 若用 `int(a, 2) + int(b, 2)` 再 `bin()` 转换，会得到 `"0b0"` 而不是 `"0"`，需要 `[2:]` 切片 → 更稳的做法是坚持逐位模拟，天然输出 `"0"`。

## 如果面试官追问
问：如果要求结果按 32 位截断（超出部分丢弃）怎么办？
答：仍逐位模拟，但只保留低 32 位，最后对结果串取后 32 个字符即可。
