## 一句话思路
左侧 `pos` 人里选 `i` 个可见、右侧选 `k-i` 个可见，用组合数求和，`pos` 本人乘 2。

## 怎么做
1. 记 `left = pos`、`right = n - 1 - pos`，可见人数只由两侧选 `L`/`R` 的个数决定。
2. 枚举左侧可见人数 `i`，范围 `max(0, k - right) <= i <= min(k, left)`，右侧可见 `k - i` 人。
3. 每项贡献 `C(left, i) * C(right, k - i)`，累加后乘 2（`pos` 本人方向自由）。
4. 用阶乘 + 逆元预处理组合数，模 `10**9 + 7`。

以示例 2 `n=3, pos=2, k=1` 为例：`left=2, right=0`，`i` 只能取 1，`C(2,1)*C(0,0)=2`，乘 2 得 4。

```python
MOD = 10**9 + 7
fact = [1] * (n + 1)
for i in range(1, n + 1):
    fact[i] = fact[i-1] * i % MOD
inv = [1] * (n + 1)
inv[n] = pow(fact[n], MOD - 2, MOD)
for i in range(n, 0, -1):
    inv[i-1] = inv[i] * i % MOD

def C(a, b):
    if b < 0 or b > a:
        return 0
    return fact[a] * inv[b] % MOD * inv[a-b] % MOD

left, right = pos, n - 1 - pos
ans = 0
for i in range(max(0, k - right), min(k, left) + 1):
    ans = (ans + C(left, i) * C(right, k - i)) % MOD
return ans * 2 % MOD
```

## 复杂度
时间：预处理 O(n)，枚举 O(k)，合计 O(n)。
空间：`fact`、`inv` 两个长度 n+1 数组，O(n)。

## 易错点
- `k > left + right` 时（如 `n=3, pos=1, k=2`），循环区间为空，`ans=0`，正确返回 0；若忘记下界 `max(0, k-right)` 会让 `k-i` 越界，`C` 返回 0 但循环多跑，需靠 `C` 内 `b<0 or b>a` 兜住。
- `n=1, pos=0, k=0` 时 `left=right=0`，循环只跑 `i=0`，`C(0,0)*C(0,0)=1`，乘 2 得 2；若漏乘 2 会错成 1。

## 如果面试官追问
若 `n` 升到 `10**9` 但 `k` 很小，怎么办？答：改用 O(k) 递推组合数 `C(left,i)` 逐项乘除，避免 O(n) 预处理。
