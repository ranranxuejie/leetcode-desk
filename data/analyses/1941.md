## 一句话思路
用 `Counter` 统计每个字符频次，把所有频次塞进 `set`，看集合大小是否为 1。

## 怎么做
1. 用 `Counter(s)` 得到字符到频次的映射。
2. 取 `set(cnt.values())`，它把所有出现次数去重。
3. 判断该集合长度是否等于 1，是则返回 `True`。

以 `s = "abacbc"` 为例，`cnt = {'a':2,'b':2,'c':2}`，`cnt.values()` 是 `[2,2,2]`，`set` 后为 `{2}`，长度 1，返回 `True`。换成 `"aaabb"`，`cnt = {'a':3,'b':2}`，`set` 后为 `{3,2}`，长度 2，返回 `False`。

```python
from collections import Counter

def areOccurrencesEqual(s):
    cnt = Counter(s)
    return len(set(cnt.values())) == 1
```

关键点：`set` 只保留不同频次，所以只要出现两种不同次数，长度立刻变 2 以上。不需要手动记录第一个频次再逐个比对，`set` 一步到位。

## 复杂度
时间 O(n)：`Counter` 扫一遍 `s`，n 为字符串长度。
空间 O(k)：`cnt` 和 `set` 各存至多 26 个小写字母的频次。

## 易错点
- 输入 `s = "a"` → 若先取 `cnt.values()` 再手动比较「第一个和其余」，容易漏掉单字符情况；正确做法是 `set` 长度为 1 直接判 `True`，单字符天然满足。
- 输入 `s = "aabb"` → 若误用 `len(set(s))` 判断字符种类数而非频次，会得到 2 而错判；正确做法是对 `cnt.values()` 去重，不是对 `s` 去重。

## 如果面试官追问
若字符集扩展到全部 Unicode，怎么做？答：`Counter` 和 `set` 逻辑不变，只是空间从 O(26) 变成 O(不同字符数)，无需改代码。
