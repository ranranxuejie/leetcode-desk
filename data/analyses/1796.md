## 一句话思路
用两个变量 `first`、`second` 边扫边维护最大与次大数字，遇到比 `first` 小但比 `second` 大的就更新。

## 怎么做
1. 初始化 `first = -1`、`second = -1`，表示还没见过任何数字。
2. 遍历 `s` 的每个字符 `ch`，用 `ch.isdigit()` 过滤掉字母。
3. 把字符转成整数 `d = ord(ch) - ord('0')`，再分三种情况更新。
4. 返回 `second`，若从未更新过它自然还是 `-1`。

以 `s = "dfa12321afd"` 为例，扫到 `'3'` 时 `first` 从 2 变 3、`second` 变 2；后面再出现的 `'2'`、`'1'` 都因 `d <= second` 被跳过，最终 `second = 2`。

```python
first = second = -1
for ch in s:
    if not ch.isdigit():
        continue
    d = ord(ch) - ord('0')
    if d > first:
        first, second = d, first
    elif second < d < first:
        second = d
return second
```

关键在 `elif` 的条件必须写成 `second < d < first` 而不是 `d > second`：后者会把重复的最大值也算进去。比如 `s = "abc1111"`，第一个 `'1'` 让 `first = 1`，若条件写成 `d > second`，第二个 `'1'` 就会把 `second` 也置成 1，错误返回 1 而不是 -1。

## 复杂度
时间 O(n)，n 为 `s` 长度，每个字符只做一次 `isdigit` 和常数次比较。
空间 O(1)，只开了 `first`、`second`、`d` 三个整型变量。

## 易错点
- 输入 `"abc1111"` → 若用 `d > second` 判次大，重复的 `'1'` 会把 `second` 填成 1，错答 1 → 正确做法是严格用 `second < d < first`，保证次大值严格小于最大值。
- 输入 `"abc"`（无数字）或 `"a1b"`（只有一个数字）→ 若把 `second` 初始化为 0，会错答 0 → 必须初始化为 `-1`，这样无第二大的数字时直接返回 -1，与题目要求一致。

## 如果面试官追问
问：如果要求返回第二大的数字及其首次出现下标怎么办？
答：更新 `second` 时同步记录当前下标 `i`，注意 `first` 被顶替时 `second` 要继承旧 `first` 的值和下标。
