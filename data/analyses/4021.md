## 一句话思路
枚举 n 种左旋偏移，每种偏移下把每对失配字符单向递增到相同，取总代价最小。

## 怎么做
1. 左旋 k 次等价于把 s 看成环、从下标 k 开始读，所以只需枚举 k ∈ [0, n)。
2. 固定 k 后，回文约束是 s[(k+i) % n] 与 s[(k+n-1-i) % n] 相等，i 取 0..n//2-1。
3. 一对字符 a、b 的最小递增代价是 min(|a-b|, 26-|a-b|)，因为只能单向递增但可以绕一圈。
4. 各对代价求和即该 k 的答案，对所有 k 取最小值。

以 s = "abc" 为例，k=1 时读作 "bca"：配对 (b,a) 代价 min(1,25)=1，(c,c) 代价 0，合计 1；再加左旋本身 1 次操作，得 2，与示例一致。注意左旋次数 k 也要计入总操作数。

```python
n = len(s)
best = float('inf')
for k in range(n):
    cost = k
    for i in range(n // 2):
        a = ord(s[(k + i) % n]) - 97
        b = ord(s[(k + n - 1 - i) % n]) - 97
        d = abs(a - b)
        cost += min(d, 26 - d)
    best = min(best, cost)
return best
```

关键中间值：k=1 时 `(k+i)%n` 依次取 1,2，`(k+n-1-i)%n` 依次取 0,1，配对为 (s[1],s[0]) 和 (s[2],s[1])，即 (b,a) 与 (c,b)——等等，这里第二对是 (c,b) 代价 1，合计 2，再加 k=1 得 3。重新核对：n=3 时 n//2=1，只配一对 (b,a)，代价 1，总 2。n 为奇数时中间字符自配对，不产生代价。

## 复杂度
时间：O(n²)，外层 n 个偏移、内层 n/2 对字符。
空间：O(1)，只用了 cost、best 等常数个变量。

## 易错点
- s = "yb"：只算字符代价得 min(23,3)=3，忘了加左旋次数；k=0 时配对 (y,b) 代价 3 已是最优，但若写成「先旋再算」而漏加 k，遇到 s = "ab" 会错答 1（正确是 0，k=0 时 a、b 代价 1？）——实际 s="ab" 应输出 1，k=0 配对 (a,b) 代价 1。正确做法是每个 k 的 cost 初值设为 k 本身。
- 奇数长度：n=3 时若内层写成 range(n//2 + 1)，会把中间字符和自己配一次，代价恒 0 不影响结果，但 n 为偶数时会越界取到重复下标；正确做法是内层严格用 n//2。

## 如果面试官追问
若 n 扩大到 10⁵ 怎么办？答：代价函数对每对字符独立，可预处理前缀和或利用旋转后配对集合的滑动关系，把 O(n²) 降到 O(n·26) 级别。
