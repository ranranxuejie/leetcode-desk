## 一句话思路
用哨兵节点 `dummy` 指向 `head`，再用 `prev` 指针跳过所有 `val` 节点，避免单独处理头节点。

## 怎么做
1. 建 `dummy = ListNode(0)`，`dummy.next = head`，令 `prev = dummy`。
2. 循环 `while prev.next`：若 `prev.next.val == val` 则 `prev.next = prev.next.next`，否则 `prev = prev.next`。
3. 返回 `dummy.next`。

以 `head = [1,2,6,3,4,5,6], val = 6` 为例：`prev` 停在 `2` 时，`prev.next` 是第一个 `6`，执行 `prev.next = prev.next.next` 后 `prev` 仍指向 `2`、`prev.next` 变成 `3`——关键点是**删完不移动 `prev`**，才能连续删掉末尾的第二个 `6`。

```python
dummy = ListNode(0)
dummy.next = head
prev = dummy
while prev.next:
    if prev.next.val == val:
        prev.next = prev.next.next
    else:
        prev = prev.next
return dummy.next
```

哨兵的价值在示例 3：`head = [7,7,7,7], val = 7`，若没有 `dummy`，就得写一段专门改 `head` 的分支；有了它，四个 `7` 全由同一行 `prev.next = prev.next.next` 删掉，最后 `dummy.next` 是 `None`，直接返回即空链表。

## 复杂度
时间 O(n)：`prev` 沿链表走一遍，每个节点最多被 `prev.next` 看两次。
空间 O(1)：只多开一个 `dummy` 节点和 `prev` 指针，递归写法才会是 O(n) 栈。

## 易错点
- 输入 `[7,7,7,7], val = 7` → 若直接 `while head and head.val == val: head = head.next` 却漏写循环（写成 `if`），只删掉第一个 `7`，返回 `[7,7,7]` → 删头必须用 `while` 而不是 `if`，或干脆用 `dummy` 统一处理。
- 输入 `[1,2,6,3,4,5,6], val = 6` → 若写成 `prev = prev.next` 无条件前移，删掉第一个 `6` 后 `prev` 跳到 `3`，末尾的 `6` 被跳过，输出 `[1,2,3,4,5,6]` → 只有 `else` 分支才移动 `prev`。

## 如果面试官追问
追问：改成「删除所有重复出现的值，只保留出现一次的节点」怎么办？
答：先哈希统计每个值出现次数，再用同样的 `dummy + prev` 骨架按计数删，仍是 O(n) 时间。
