## 一句话思路
把每个数压成二进制掩码，用 DP 求「掩码子集内的最大数」，再对每个数查它补集的子集最大值配对。

## 怎么做
1. 建数组 `best`，长度 `1 << 20`（`nums[i] ≤ 10^6 < 2^20`），`best[mask]` 先填该掩码上出现的最大原值。
2. 对每个掩码做子集 DP：`best[mask] = max(best[mask], best[mask ^ (1<<b)])`，把最大值向所有超集传播。
3. 对每个 `x`，取 `comp = full ^ x`（`full = (1<<20)-1`），候选为 `x * best[comp]`，取全局最大。
4. 若 `best[comp] == 0` 说明没有合法搭档，跳过；全程无合法对则返回 0。

以示例 1 的 `nums = [1,2,3,4,5,6,7]` 为例：`x = 3`（`011`），`comp` 的低位是 `...100`，`best[comp]` 在 DP 传播后等于 4，得 `3*4 = 12`；而 `x = 7`（`111`）的 `comp` 低位全 0，`best[comp]` 只能取到 0，被跳过。

```python
B = 20
full = (1 << B) - 1
best = [0] * (1 << B)
for x in nums:
    best[x] = max(best[x], x)
for b in range(B):
    bit = 1 << b
    for m in range(1 << B):
        if m & bit:
            best[m] = max(best[m], best[m ^ bit])
ans = 0
for x in nums:
    y = best[full ^ x]
    if y:
        ans = max(ans, x * y)
```

## 复杂度
时间：`O(2^20 * 20 + n)`，`n` 来自建表和枚举，`2^20 * 20` 来自子集 DP。
空间：`O(2^20)`，即 `best` 数组，与 `n` 无关。

## 易错点
- `nums = [5,6,4]` → 若把 `best[comp]` 的 0 当成合法值直接乘，会得到 `x*0 = 0` 混进答案，甚至掩盖真正的 0 与「无解」的区别 → 必须先判 `if y:` 再更新 `ans`。
- `nums = [64,8,32]` → 若只对出现过的掩码做 DP、不向超集传播，`x=64` 查 `comp` 时拿不到 32 → 必须让 `best` 覆盖全部 `2^20` 个掩码并做超集传播，而不是只遍历 `nums` 里的值。

## 如果面试官追问
问：`nums[i]` 上限提到 `10^9` 怎么办？
答：位数涨到 30，`2^30` 的 DP 不可行，改用按位枚举候选或哈希剪枝。
