## 一句话思路
路径边数 k 决定答案：奇数代价方案数 = 2^(k-1)（k≥1），k=0 时为 0，用 LCA 求 k。

## 怎么做
1. 从根 1 做一次 DFS，记录每个节点的 `depth`（边数深度）和倍增表 `up[j][v]`。
2. 对查询 `[u,v]`，用 LCA 求路径边数 `k = depth[u] + depth[v] - 2*depth[lca]`。
3. 若 `k == 0` 输出 0，否则输出 `pow(2, k-1, MOD)`。

以示例 2 的查询 `[2,5]` 为例：`depth[2]=1, depth[5]=2, lca=1, depth[1]=0`，得 `k = 1+2-0 = 3`，答案 `pow(2,2)=4`，与输出一致。

```python
MOD = 10**9 + 7
LOG = 17  # n <= 1e5
# depth、up 已由 DFS 填好
def lca(u, v):
    if depth[u] < depth[v]:
        u, v = v, u
    for j in range(LOG - 1, -1, -1):
        if depth[u] - (1 << j) >= depth[v]:
            u = up[j][u]
    if u == v:
        return u
    for j in range(LOG - 1, -1, -1):
        if up[j][u] != up[j][v]:
            u, v = up[j][u], up[j][v]
    return up[0][u]

k = depth[u] + depth[v] - 2 * depth[lca(u, v)]
ans = 0 if k == 0 else pow(2, k - 1, MOD)
```

## 复杂度
时间：DFS 建表 O(n log n)，每个查询 LCA O(log n)，共 O((n+q) log n)。
空间：`up` 表 O(n log n)，`depth` 与邻接表 O(n)。

## 易错点
- 查询 `[u,u]`（如示例 1 的 `[1,1]`）→ 若直接套 `pow(2, k-1)` 会得到 `pow(2,-1)` 报错或算成 1 → 必须先判 `k == 0` 返回 0。
- 用节点编号差或 `depth` 直接当边数 → 路径边数是 `depth[u]+depth[v]-2*depth[lca]`，漏减 `2*depth[lca]` 会把示例 2 的 `[1,4]` 算成 k=3 得 4，正确是 k=2 得 2。

## 如果面试官追问
若 n 升到 10^6 且查询更多？答：改用欧拉序 + 稀疏表 O(1) 查询 LCA，预处理 O(n log n) 不变但常数更小。
