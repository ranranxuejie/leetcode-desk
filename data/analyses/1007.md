## 一句话思路
目标值只能是 `tops[0]` 或 `bottoms[0]`，对这两个候选各扫一遍，统计把某一行全变成它所需的最少翻转数。

## 怎么做
1. 候选值只取 `tops[0]` 和 `bottoms[0]`：任何合法方案里第 0 张牌必有一面等于目标值。
2. 对候选 `x`，逐列检查：若 `tops[i] != x and bottoms[i] != x`，该候选直接判死。
3. 否则累加 `tops[i] != x` 的列数（把上面变成 x 要翻的次数）和 `bottoms[i] != x` 的列数，取较小者。
4. 两个候选的结果取最小，全死则返回 -1。

以示例 1 的 `x = 2` 为例：第 1 列 `tops[1]=1, bottoms[1]=2`，上面不是 2 要翻，`top_rot` 累加到 1；第 3 列 `tops[3]=4, bottoms[3]=2` 同理累加到 2。最终 `top_rot = 2`、`bot_rot = 4`（下面为 2 的列只有 1、3、5 三列，其余四列要翻），取 2。

```python
def rotations(x, tops, bottoms):
    top_rot = bot_rot = 0
    for t, b in zip(tops, bottoms):
        if t != x and b != x:
            return float('inf')
        if t != x:
            top_rot += 1
        if b != x:
            bot_rot += 1
    return min(top_rot, bot_rot)

ans = min(rotations(tops[0], tops, bottoms),
          rotations(bottoms[0], tops, bottoms))
return -1 if ans == float('inf') else ans
```

关键点：`top_rot` 和 `bot_rot` 是同一列的两个独立计数，不能合并——翻一次只能让一面变成 x，所以两者互斥地各自累加。

## 复杂度
时间 O(n)：两个候选各扫一遍数组，n 为骨牌数。
空间 O(1)：只开了 `top_rot`、`bot_rot` 两个计数器。

## 易错点
- 候选值取成「出现次数最多的数字」→ 示例 2 里 3 出现 5 次看似最优，但第 1 列 `tops[1]=5, bottoms[1]=6` 两面都不是 3，直接判死；正确做法是只试 `tops[0]` 和 `bottoms[0]`，因为第 0 列无法回避。
- 把 `top_rot` 和 `bot_rot` 写成同一个计数器或取 `max` → 示例 1 会得到 4 而非 2；正确做法是分别统计「上面不等于 x 的列数」和「下面不等于 x 的列数」，最后取 `min`。

## 如果面试官追问
问：如果要求输出具体翻转了哪些下标？
答：在 `rotations` 里额外收集 `t != x` 的下标列表，选 `top_rot` 更小的那组返回即可，逻辑不变。
