## 一句话思路
把 arr2 消掉，只对 arr1[i] 做 DP，用前缀和把「上一项 ≤ 当前项」的转移压成 O(1)。

## 怎么做
1. 由 arr1[i]+arr2[i]=nums[i] 且 arr2 非增，得 arr1[i]-arr1[i-1] ≥ nums[i]-nums[i-1]，即 arr1[i] ≥ arr1[i-1] 且 arr1[i] ≥ nums[i]-nums[i-1]+arr1[i-1]；同时 arr1[i] ≤ nums[i]。
2. 设 dp[v] = 以 arr1[i]=v 结尾的方案数，转移 dp_new[v] = sum(dp[u] for u ≤ min(v, v-(nums[i]-nums[i-1])))，用前缀和一次扫完。
3. 以 nums=[2,3,2] 为例：i=0 时 dp=[1,1,1]（v=0,1,2）；i=1 时 nums 差为 1，v=1 只能接 u≤0，v=2 接 u≤1，得 dp=[0,1,2]；i=2 差为 -1，条件退化为 u≤v，前缀和得 4。

```python
MOD = 10**9 + 7
m = max(nums)
dp = [1] * (nums[0] + 1)          # i=0：arr1[0] 可取 0..nums[0]
for i in range(1, len(nums)):
    d = nums[i] - nums[i - 1]
    pre = [0] * (len(dp) + 1)
    for j, x in enumerate(dp):
        pre[j + 1] = (pre[j] + x) % MOD
    ndp = [0] * (nums[i] + 1)
    for v in range(nums[i] + 1):
        hi = min(v, v - d, len(dp) - 1)   # u 的上界
        if hi >= 0:
            ndp[v] = pre[hi + 1]
    dp = ndp
return sum(dp) % MOD
```

## 复杂度
时间：O(n · max(nums))，n 来自数组长度，max(nums) ≤ 50 来自值域。
空间：O(max(nums))，只存当前层 dp 和前缀和数组。

## 易错点
- nums 出现下降（如 [2,3,2] 的 3→2）时，若仍按 u ≤ v 转移会漏掉 arr1 必须「多降」的约束；正确做法是上界取 min(v, v-d)，d 为负时该式自动放宽为 v。
- 忘记 arr1[i] 上界是 nums[i] 而非全局 max(nums)：dp 数组长度必须按 nums[i]+1 重建，否则会把 arr1[i] > nums[i] 的非法状态算进去。

## 如果面试官追问
若 nums[i] 放大到 10^9 怎么办？答：值域 DP 失效，改用分段线性的前缀和函数或组合计数闭式，按 nums 的拐点分段维护。
