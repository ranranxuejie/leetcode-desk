## 一句话思路
自顶向下 DFS，把「我是父节点的左孩子」这个身份作为参数传下去，遇到叶子且身份为左就累加。

## 怎么做
1. 递归函数带两个参数：当前节点 `node` 和布尔 `is_left`，表示它是不是父节点的左孩子。
2. 空节点直接返回 0。
3. 若 `node` 无左右孩子且 `is_left` 为真，返回 `node.val`；否则返回左右子树递归结果之和，左孩子传 `True`、右孩子传 `False`。
4. 根节点传 `False`，因为根没有父节点，不可能是左叶子。

以 `root = [3,9,20,null,null,15,7]` 为例：走到 `9` 时 `is_left=True` 且它是叶子，返回 9；走到 `15` 时它是 `20` 的左孩子、也是叶子，返回 15；`7` 虽是叶子但 `is_left=False`，返回 0。三处相加 9+15+0=24。

```python
def dfs(node, is_left):
    if node is None:
        return 0
    if node.left is None and node.right is None:
        return node.val if is_left else 0
    return dfs(node.left, True) + dfs(node.right, False)

return dfs(root, False)
```

关键点：判断「左叶子」不能只看叶子，必须同时看它是谁的左孩子。把身份当参数传，比在父节点里判断 `node.left` 是否为叶子更省事，也避免了对根节点做特判。

## 复杂度
时间 O(n)：每个节点访问一次，n 为节点数。
空间 O(h)：递归栈深度等于树高 h，最坏链状树 O(n)，无额外数组。

## 易错点
- 输入 `root = [1]`（单节点）→ 若把根当左孩子处理会返回 1 → 根必须传 `is_left=False`，正确答案是 0。
- 输入 `[3,9,20,null,null,15,7]` 中的 `7` → 若只判断「是叶子」就累加会得到 31 → 必须用 `is_left` 过滤，只有 `9` 和 `15` 计入，得 24。

## 如果面试官追问
要求返回所有左叶子的列表而非和？答：把返回值从整数改成列表，叶子处返回 `[node.val]` 或 `[]`，递归处做列表拼接，复杂度不变。
