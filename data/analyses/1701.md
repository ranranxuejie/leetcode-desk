## 一句话思路
维护厨师空闲时刻 `free`，逐个顾客取 `max(free, arrival) + time` 作为完成时刻，累加等待时间。

## 怎么做
1. 初始化 `free = 0`、`total = 0`。
2. 遍历每个 `[arrival, time]`：厨师开始时刻是 `max(free, arrival)`，完成时刻 `free = max(free, arrival) + time`。
3. 该顾客等待时间 = `free - arrival`，累加进 `total`。
4. 返回 `total / len(customers)`。

以示例 1 `[[1,2],[2,5],[4,3]]` 为例，关键中间值：
- 第 1 位：`free = max(0,1)+2 = 3`，等待 `3-1=2`。
- 第 2 位：`free = max(3,2)+5 = 8`，等待 `8-2=6`（注意 `max` 取到 3 而非 2，厨师没空闲）。
- 第 3 位：`free = max(8,4)+3 = 11`，等待 `11-4=7`。
- `total = 15`，`15/3 = 5.0`。

```python
free = 0
total = 0
for arrival, time in customers:
    start = max(free, arrival)
    free = start + time
    total += free - arrival
return total / len(customers)
```

`max(free, arrival)` 是核心：`free > arrival` 说明厨师还在忙，顾客要等；`free <= arrival` 说明厨师已空闲，顾客到达即开工。两种情形统一成一个表达式，不用写 if。

## 复杂度
时间：O(n)，n 为顾客数，每个顾客常数次运算。
空间：O(1)，只开 `free`、`total` 两个变量。

## 易错点
- 输入 `[[5,2],[5,4]]` 这类到达时间相同的 → 若用 `free = arrival + time` 覆盖而不取 `max`，第二位会算成 `5+4=9`、等待 4，正确是 `max(7,5)+4=11`、等待 6 → 必须 `max(free, arrival)`。
- 输入 `[[1,100],[200,1]]` 这类后到顾客到达时厨师早已空闲 → 若漏掉 `max` 直接用 `free + time`，第二位完成时刻算成 `101+1=102`、等待 -98 → 正确是 `max(101,200)+1=201`、等待 1，等待时间不可能为负。

## 如果面试官追问
问：若顾客不按到达顺序给出，怎么改？
答：先按 `arrival` 排序再跑同一循环，时间变 O(n log n)，`free` 逻辑不变。
