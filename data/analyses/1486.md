## 一句话思路
逐项异或 `start + 2*i` 即可，n ≤ 1000 时 O(n) 直接扫，不必推数学公式。

## 怎么做
1. 令 `ans = 0`，循环 `i` 从 0 到 `n-1`。
2. 每轮把 `start + 2*i` 异或进 `ans`。
3. 循环结束返回 `ans`。

以示例 2（`n = 4, start = 3`）为例，`i` 依次取 0、1、2、3，对应元素是 3、5、7、9；`ans` 的变化是 `0^3=3`、`3^5=6`、`6^7=1`、`1^9=8`，返回 8。

```python
ans = 0
for i in range(n):
    ans ^= start + 2 * i
return ans
```

关键点：`start + 2*i` 里的 `2*i` 是下标乘 2，不是 `start` 乘 2；示例 1 中 `start = 0` 时序列是 0、2、4、6、8，若误写成 `start + i` 会得到 0、1、2、3、4，异或结果是 4 而不是 8。

## 复杂度
时间：O(n)，循环 n 次，每次一次加法一次异或。
空间：O(1)，只用了 `ans` 和 `i` 两个变量。

## 易错点
- `n = 1, start = 7` → 若把 `ans` 初值设成 `start` 又循环加一次，会得到 `7^7=0` → 正确做法是 `ans` 从 0 开始，循环里统一处理第 0 项。
- `n = 10, start = 5` → 若把 `2*i` 写成 `i`，序列变成 5、6、…、14，异或结果不是 2 → 必须严格用 `start + 2*i`，可拿示例 4 的答案 2 自测。

## 如果面试官追问
问：n 放大到 10^9 怎么办？
答：按 `start` 的奇偶拆成两段连续整数异或，用 `1..k` 前缀异或公式 O(1) 算。
