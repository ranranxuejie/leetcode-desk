## 一句话思路
把 `nums` 按 `(数位和, 值)` 排序得到目标排列，再对「原位置→目标位置」的置换环计数，答案 = n − 环数。

## 怎么做
1. 用 `sorted(nums, key=lambda x: (sum(map(int, str(x))), x))` 得到目标数组 `target`。
2. 建 `pos = {值: 下标}`，记录每个值在 `target` 里的位置。
3. 遍历 `nums` 的每个下标 `i`，若 `nums[i]` 不在它的目标位置，就沿置换环一路换回去，每换一次 `ans += 1`。
4. 每个长度 `L` 的环恰好需要 `L-1` 次交换，累加即最小交换数。

以 `nums = [18,43,34,16]` 为例：数位和为 `[9,7,7,7]`，排序后 `target = [16,34,43,18]`，`pos = {16:0, 34:1, 43:2, 18:3}`。下标 0 上是 18，它该去 3，于是 `18↔16`；下标 1 上是 43，它该去 2，于是 `43↔34`。两个长度 2 的环，各 1 次，共 2。

```python
target = sorted(nums, key=lambda x: (sum(map(int, str(x))), x))
pos = {v: i for i, v in enumerate(target)}
ans = 0
for i in range(len(nums)):
    while nums[i] != target[i]:
        j = pos[nums[i]]          # nums[i] 该去的位置
        nums[i], nums[j] = nums[j], nums[i]
        ans += 1
return ans
```

关键点：`pos` 的键是**值**不是下标，因为题目保证互不相同，值才能唯一定位目标位置；`while` 而不是 `if`，因为一次交换后 `nums[i]` 可能仍不对。

## 复杂度
时间：排序 O(n log n) 主导，数位和计算 O(n log V)，置换环 O(n)。
空间：`target`、`pos` 各 O(n)，无递归栈。

## 易错点
- 只按数位和排序、漏掉「数位和相等时较小值在前」：`[18,43,34,16]` 中 43、34、16 数位和都是 7，若稳定排序保留原序得 `[16,43,34,18]`，环变成 3 次，错答 3；正确 key 必须是 `(数位和, 值)` 二元组。
- 用 `if` 代替 `while` 做单次交换：`[37,100]` 交换后恰好归位看不出问题，但长环如 `[3,1,2]`（假设目标 `[1,2,3]`）下标 0 换一次后 `nums[0]=1` 已对，`nums[1]=3` 仍错，`if` 会漏计；必须循环到 `nums[i] == target[i]`。

## 如果面试官追问
问：若 `nums` 允许重复值，置换环法还成立吗？
答：不成立，重复值使「哪个副本去哪个位置」不唯一，需改成对每个值统计错位计数再配对，答案不再是 n − 环数。
