## 一句话思路
完全背包型 DP：`dp[x]` 表示凑出金额 x 的最少硬币数，用每个硬币去松弛所有可达金额。

## 怎么做
1. 开长度 `amount + 1` 的数组 `dp`，全部初始化为 `amount + 1`（一个凑不出来的哨兵值，比任何合法答案都大），并令 `dp[0] = 0`。
2. 外层遍历金额 `x` 从 1 到 `amount`，内层遍历每个 `c in coins`，若 `x >= c` 则 `dp[x] = min(dp[x], dp[x - c] + 1)`。
3. 结束后若 `dp[amount] > amount` 说明不可达，返回 `-1`，否则返回 `dp[amount]`。

以 `coins = [1, 2, 5], amount = 11` 为例，关键中间值是 `dp[10] = 2`（5+5）：当 `x = 11` 且 `c = 1` 时，`dp[11] = min(inf, dp[10] + 1) = 3`，这就是最终答案；`c = 5` 时 `dp[6] + 1` 更大，不会更优。

```python
dp = [amount + 1] * (amount + 1)
dp[0] = 0
for x in range(1, amount + 1):
    for c in coins:
        if x >= c and dp[x - c] + 1 < dp[x]:
            dp[x] = dp[x - c] + 1
return dp[amount] if dp[amount] <= amount else -1
```

注意内层循环顺序无所谓（完全背包，同一硬币可重复用），但 `dp[x - c]` 必须是本层已更新的值，所以金额必须从小到大遍历。

## 复杂度
时间 O(amount × len(coins))，两层循环各贡献一个因子。
空间 O(amount)，只开了 `dp` 这一张表，无其他辅助结构。

## 易错点
- `amount = 0` 且 `coins = [1]` → 若把哨兵设成 0 或忘记 `dp[0] = 0`，会返回 -1 或 1 → 正确做法是显式 `dp[0] = 0`，循环从 1 开始，直接返回 0。
- `coins = [2], amount = 3` → 若用 `dp[amount] == amount + 1` 判不可达但中途某步写了 `dp[x] = dp[x-c] + 1` 而不取 min，会把不可达的 `dp[1]` 污染成 2 → 正确做法是每次松弛都取 min，最后用 `dp[amount] > amount` 判 -1。

## 如果面试官追问
要求输出具体硬币组合怎么办？答：再开一个 `choice[x]` 记录让 `dp[x]` 取到最小值的那个 `c`，从 `amount` 倒推 `x -= choice[x]` 即可还原方案。
