## 一句话思路
用染色 DFS 给每个点标 0/1，相邻点必须异色，冲突即非二分图；图不连通所以要遍历所有起点。

## 怎么做
1. 开 `color = [-1] * n`，-1 表示未染色。
2. 外层 `for i in range(n)`：若 `color[i] == -1`，以 i 为起点染 0 并 DFS，这一步专门处理不连通分量。
3. DFS 中遍历 `graph[u]` 的每个 v：若 `color[v] == -1` 就染成 `1 - color[u]` 递归；否则若 `color[v] == color[u]` 立即返回 `False`。
4. 所有分量都无冲突则返回 `True`。

以示例 1 `graph = [[1,2,3],[0,2],[0,1,3],[0,2]]` 为例：从 0 染 0，邻居 1、2、3 全染 1；递归到 1 时看邻居 2，`color[2] == 1 == color[1]`，冲突，返回 `False`。关键中间值就是 `color = [0,1,1,1]` 时撞上边 (1,2)。

```python
def dfs(u, c):
    color[u] = c
    for v in graph[u]:
        if color[v] == -1:
            if not dfs(v, 1 - c):
                return False
        elif color[v] == c:
            return False
    return True

for i in range(n):
    if color[i] == -1 and not dfs(i, 0):
        return False
return True
```

注意 `1 - c` 而不是 `c + 1`，否则第二层就变成 2，后面 `color[v] == c` 的比较全失效。

## 复杂度
时间 O(n + E)：每个点染一次色，每条无向边在两端各被看一次。
空间 O(n)：`color` 数组 n 个槽，DFS 递归栈最坏 n 层（链状图）。

## 易错点
- 输入 `graph = [[1,3],[0,2],[1,3],[0,2]]` 这类不连通图（比如加一个孤立点 `[]`）→ 只从 0 出发 DFS 会漏掉后面分量，把非二分图误判成 `True` → 必须外层 `for i in range(n)` 补起点。
- 输入 `graph = [[1,2,3],[0,2],[0,1,3],[0,2]]` → 若写成「染完色再统一检查所有边」而 DFS 里不提前返回，遇到冲突点仍继续递归，可能把已染色的点覆盖成新颜色，最终检查反而通过 → 冲突必须当场 `return False`，不能靠事后扫描。

## 如果面试官追问
问：要求输出具体分组方案怎么办？
答：染色时把 `color[u] == 0` 的点收进 A、`== 1` 的收进 B，冲突返回空列表即可。
