## 一句话思路
用前缀和一次遍历：维护左侧和 `left`，右侧和 = `total - left`，逐下标算 `|left//(i+1) - right//(n-i-1)|` 取最小。

## 怎么做
1. 先求 `total = sum(nums)`，令 `left = 0`，`best = 2**31 - 1`，`ans = 0`。
2. 遍历 `i` 从 0 到 n-1：先把 `nums[i]` 累进 `left`，此时左段是 `nums[0..i]`，右段是 `nums[i+1..]`。
3. 右段长度 `rlen = n - i - 1`，右段和 `right = total - left`；若 `rlen == 0` 则右平均为 0，否则 `right // rlen`。
4. 算 `diff = abs(left // (i+1) - right_avg)`，只有 `diff < best` 才更新（严格小于，保证并列时留小下标）。

以 `nums = [2,5,3,9,5,3]` 为例，`total = 27`。走到 `i = 3` 时 `left = 2+5+3+9 = 19`，`right = 27-19 = 8`，`rlen = 2`，于是 `19//4 = 4`、`8//2 = 4`，`diff = 0`，刷新 `best` 和 `ans = 3`。后面 `i = 4` 得 `diff = |24//5 - 3//1| = |4-3| = 1`，不更新。

```python
total = sum(nums)
left, best, ans = 0, 2**31 - 1, 0
n = len(nums)
for i, x in enumerate(nums):
    left += x
    rlen = n - i - 1
    right_avg = (total - left) // rlen if rlen else 0
    diff = abs(left // (i + 1) - right_avg)
    if diff < best:
        best, ans = diff, i
return ans
```

## 复杂度
时间 O(n)：一次遍历，每步 O(1) 运算。
空间 O(1)：只开 `left`、`best`、`ans`、`total` 几个标量。

## 易错点
- `i = n-1` 时右段为空，`rlen = 0` 直接除会 ZeroDivisionError；必须特判成右平均 0，示例 1 的 `i = 5` 就是这种情况（`|27//6 - 0| = 4`）。
- 并列时若写成 `diff <= best`，示例 1 中 `i = 1` 和 `i = 2` 的 `diff` 都是 2，会把答案推成 2 而不是 3；必须用严格 `<`，只在更小时覆盖。

## 如果面试官追问
若要求返回所有达到最小平均差的下标？把 `if diff < best` 改成「小于则清空列表并重置，等于则追加」，最后返回列表。
