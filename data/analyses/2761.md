## 一句话思路
先用埃氏筛把 `1..n` 的质数标记出来，再枚举 `x` 从 2 到 `n//2`，检查 `x` 和 `n-x` 是否同时为质数。

## 怎么做
1. 建布尔数组 `is_prime = [True] * (n + 1)`，把 0、1 置 `False`。
2. 从 2 开始筛：若 `is_prime[i]` 为真，就把 `i*i, i*i+i, ...` 全部置 `False`，上界是 `n`。
3. 枚举 `x` 从 2 到 `n // 2`，若 `is_prime[x] and is_prime[n - x]` 就收集 `[x, n - x]`。
4. 因为 `x` 递增枚举，结果天然按 `x` 非递减，直接返回。

以 `n = 10` 为例：筛完后 `is_prime` 中 2、3、5、7 为 `True`。枚举 `x = 2` 时 `n - x = 8` 非质数，跳过；`x = 3` 时 `n - x = 7` 为质数，收 `[3,7]`；`x = 4` 跳过；`x = 5` 时 `n - x = 5` 为质数，收 `[5,5]`。循环上界 `n // 2 = 5`，正好覆盖 `x == y` 的情况。

```python
is_prime = [True] * (n + 1)
if n >= 0: is_prime[0] = False
if n >= 1: is_prime[1] = False
for i in range(2, int(n ** 0.5) + 1):
    if is_prime[i]:
        for j in range(i * i, n + 1, i):
            is_prime[j] = False
res = []
for x in range(2, n // 2 + 1):
    if is_prime[x] and is_prime[n - x]:
        res.append([x, n - x])
return res
```

## 复杂度
时间：O(n log log n) 由筛法贡献，枚举 O(n)，筛法主导。
空间：O(n)，`is_prime` 数组占 n+1 个布尔位，结果列表最多 O(n) 个对。

## 易错点
- `n = 2` 或 `n = 3`：若循环写成 `range(2, n // 2)` 会漏掉 `x == y` 的边界，`n = 4` 时 `[2,2]` 也取不到；正确上界是 `n // 2 + 1`，让 `x` 能取到 `n // 2`。
- `n = 4`：`is_prime[0]`、`is_prime[1]` 若没手动置 `False`，`x = 2` 时 `n - x = 2` 没问题，但 `n = 2` 时 `x` 从 2 开始、`n - x = 0` 会被误判为质数；必须先置 `is_prime[0] = is_prime[1] = False`。

## 如果面试官追问
问：n 放大到 10^8 怎么办？答：筛法内存吃紧，改用分段筛只保留 `[n//2, n]` 段，或对每个候选 `x` 用 Miller-Rabin 单点判素。
