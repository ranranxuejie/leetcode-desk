## 一句话思路
统计奇数频次字符个数 odd，答案就是 `odd <= k <= len(s)`：每个奇数频次字符必须独占一个回文串的中心。

## 怎么做
1. 用 `Counter(s)` 数频次，`odd = sum(v % 2 for v in cnt.values())`。
2. 下界：每个奇数频次字符至少贡献一个中心，所以 `k >= odd`，否则凑不出 k 个回文串。
3. 上界：每个字符单独成串最多 `len(s)` 个，所以 `k <= len(s)`，否则串数不够。
4. 两条件同时成立即返回 `True`。

以 `s = "annabelle"` 为例：频次 a:2, n:2, b:1, e:2, l:2，`odd = 1`（只有 b），`len(s) = 9`，`k = 2` 落在 `[1, 9]` 内，返回 `True`。再看 `s = "leetcode", k = 3`：频次 l:1, e:3, t:1, c:1, o:1, d:1，`odd = 6`，`k = 3 < 6`，返回 `False`。

```python
from collections import Counter

cnt = Counter(s)
odd = sum(v % 2 for v in cnt.values())
return odd <= k <= len(s)
```

关键点：`odd` 是下界而非精确值——多出来的偶数对可以拆开塞进任意回文串两侧，所以只要 `k >= odd` 就一定能凑够，不需要真的去构造。

## 复杂度
时间 O(n)：遍历 s 计数一次，再遍历至多 26 个键。
空间 O(1)：哈希表最多存 26 个小写字母的计数。

## 易错点
- 只判 `odd <= k` 忘了上界：`s = "a", k = 2` 时 `odd = 1 <= 2` 会错判 `True`，但 1 个字符造不出 2 个非空串，必须加 `k <= len(s)`。
- 把 `odd` 当成「必须恰好等于 k」：`s = "annabelle", k = 2` 时 `odd = 1 != 2`，若写成 `odd == k` 会错判 `False`，正确是 `odd <= k`，因为偶数对可以拆开填充。

## 如果面试官追问
问：要求返回具体构造方案怎么办？
答：先给 `odd` 个串各放一个奇数字符作中心，剩余偶数对逐个拆成两半，依次塞进前 k 个串两侧即可。
