## 一句话思路
在 grid2 上做 DFS 遍历每个岛屿，遍历时同步检查该岛屿每个格子在 grid1 中是否也为 1，全部为 1 才计数。

## 怎么做
1. 双重循环扫描 grid2，遇到 `grid2[i][j] == 1` 就启动一次 DFS，用变量 `ok` 记录该岛屿是否合格。
2. DFS 中每访问一个格子 `(i, j)`，若 `grid1[i][j] == 0` 则把 `ok` 置为 `False`，继续遍历（不能提前返回，否则岛屿剩余部分未标记，会被重复计数）。
3. DFS 把访问过的 `grid2[i][j]` 置 0 作为访问标记，遍历完整个岛屿后若 `ok` 仍为 `True`，答案加 1。

以示例 1 为例：扫描到 `grid2[0][0]=1`，DFS 覆盖 `(0,0),(0,1),(0,2),(1,2)`，其中 `grid1[1][2]=1`、`grid1[0][0..2]=1`，全部匹配，`ok=True`，计数 +1。继续扫描到 `grid2[1][3]=1`，该岛屿含 `(1,3),(1,4)`，但 `grid1[1][3]=1`、`grid1[1][4]=1` 也匹配，计数 +1。最终得到 3。

```python
def dfs(i, j):
    nonlocal ok
    if i < 0 or i >= m or j < 0 or j >= n or grid2[i][j] == 0:
        return
    grid2[i][j] = 0
    if grid1[i][j] == 0:
        ok = False
    dfs(i+1, j); dfs(i-1, j); dfs(i, j+1); dfs(i, j-1)

ans = 0
for i in range(m):
    for j in range(n):
        if grid2[i][j] == 1:
            ok = True
            dfs(i, j)
            if ok:
                ans += 1
```

## 复杂度
时间：O(m·n)，每个格子最多被 DFS 访问一次。
空间：O(m·n)，递归栈最深可达岛屿大小，最坏全 1 矩阵。

## 易错点
- 发现 `grid1[i][j]==0` 就 `return` 提前结束 DFS → 岛屿剩余格子没被置 0，外层循环再次扫到会重复计数 → 必须继续遍历完整个岛屿，只用 `ok` 标记不合格。
- 忘记把 `grid2[i][j]` 置 0 做访问标记 → 同一岛屿被反复 DFS，答案虚高甚至死循环 → 进入 DFS 第一件事就是置 0。

## 如果面试官追问
若 m、n 到 5000 导致递归爆栈怎么办？答：改用显式栈的迭代 DFS，或 BFS 队列，空间仍是 O(m·n) 但不受 Python 递归深度限制。
