## 一句话思路
按左端点排序后，用「总对数 − 不相交对数」计数，不相交等价于前一个区间的右端点严格小于后一个区间的左端点。

## 怎么做
1. 把 `intervals` 按 `start` 升序排序，`n = len(intervals)`，答案初值取 `n*(n-1)//2`。
2. 排序后对每个 `j`，所有 `i < j` 满足 `intervals[i][1] < intervals[j][0]` 的都不相交，用二分在已排序的右端点前缀里数出个数。
3. 维护一个 `ends` 列表存已处理区间的右端点并保持有序，用 `bisect_left(ends, intervals[j][0])` 得到严格小于 `start_j` 的个数，从答案里减掉。
4. 把 `intervals[j][1]` 插入 `ends` 继续。

以示例 1 `[[1,2],[2,3],[3,4]]` 为例：总对数 `3*2//2 = 3`。处理 `[2,3]` 时 `ends=[2]`，`bisect_left([2], 2) = 0`，不减；处理 `[3,4]` 时 `ends=[2,3]`，`bisect_left([2,3], 3) = 1`，减 1，答案 `3-1 = 2`。注意 `[1,2]` 与 `[2,3]` 共享端点 2，`2 < 2` 为假，所以不算不相交，正确。

```python
from bisect import bisect_left, insort
n = len(intervals)
intervals.sort()
ans = n * (n - 1) // 2
ends = []
for s, e in intervals:
    ans -= bisect_left(ends, s)
    insort(ends, e)
return ans
```

## 复杂度
时间：排序 `O(n log n)`，每个区间一次二分加一次插入，共 `O(n log n)`。
空间：`ends` 存 n 个右端点，`O(n)`。

## 易错点
- 把不相交判成 `end_i <= start_j`：示例 1 中 `[1,2]` 与 `[2,3]` 会被误判为不相交，答案从 2 变成 1。闭区间共享端点算相交，必须用严格小于 `end_i < start_j`，即 `bisect_left` 而不是 `bisect_right`。
- 只按左端点排序后直接线性扫右端点最小值：`[[1,5],[2,4],[3,6]]` 中 `[1,5]` 的右端点 5 会挡住后面所有判断，漏掉 `[2,4]` 与 `[3,6]` 这对。必须用有序的 `ends` 做二分，不能只维护单个最小右端点。

## 如果面试官追问
若要求输出所有相交对而非计数？答：计数可二分，输出方案最坏是 `O(n^2)` 对，只能枚举，规模必须降到千级。
