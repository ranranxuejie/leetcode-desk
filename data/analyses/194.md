## 一句话思路
按行读入后切成二维列表，再按列下标外层循环、行下标内层循环重新拼行，因为转置就是把 `grid[i][j]` 搬到 `grid[j][i]`。

## 怎么做
1. 逐行读文件，`line.split()` 得到每行的字段列表，存进 `grid`。
2. 取 `cols = len(grid[0])`，外层枚举列下标 `j`，内层枚举行下标 `i`。
3. 把 `grid[i][j]` 收集成一行，用 `' '.join` 拼好写入结果。
4. 按行输出，行间用 `\n` 连接。

以官方示例为例，`grid = [['name','age'], ['alice','21'], ['ryan','30']]`，`cols = 2`。当 `j = 0` 时内层依次取到 `grid[0][0]='name'`、`grid[1][0]='alice'`、`grid[2][0]='ryan'`，拼成 `'name alice ryan'`；`j = 1` 时得到 `'age 21 30'`。

```python
lines = open('file.txt').read().splitlines()
grid = [ln.split() for ln in lines if ln.strip()]
cols = len(grid[0])
out = []
for j in range(cols):
    out.append(' '.join(grid[i][j] for i in range(len(grid))))
print('\n'.join(out))
```

关键中间值：`cols` 必须从 `grid[0]` 取，不能从 `len(grid)` 取——示例里行数是 3、列数是 2，两者不等，取错就直接越界或漏列。

## 复杂度
时间 O(R·C)，R 行 C 列，每个字段恰好访问一次。
空间 O(R·C)，`grid` 和 `out` 各存一份全部字段。

## 易错点
- 输入末尾有空行（很多文件以 `\n` 结尾）→ `splitlines()` 会多出一个 `''`，`''.split()` 得到 `[]`，`grid` 里混进空列表，`grid[i][j]` 抛 IndexError → 用 `if ln.strip()` 过滤掉空行再建 `grid`。
- 只有一行（如 `name age`）→ 若外层写成枚举行、内层枚举列，输出会变成 `name` 和 `age` 两行，正好是原样而非转置 → 外层必须是列下标 `j`、内层是行下标 `i`，示例中 `cols=2`、行数 3 时才能得到 2 行输出。

## 如果面试官追问
如果文件大到不能一次读进内存怎么办？
答：先扫一遍只记下列数 C，再对每个列下标 j 重新流式读文件、取每行第 j 个字段，时间 O(R·C)、额外空间 O(R)。
