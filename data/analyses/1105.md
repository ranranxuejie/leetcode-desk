## 一句话思路
用 `dp[i]` 表示前 i 本书的最小总高度，枚举最后一层的起点 j，取 `dp[j] + 该层最大高度` 的最小值。

## 怎么做
1. 定义 `dp[0] = 0`，`dp[i]` 为前 i 本书摆完的最小总高度。
2. 从 i 往前倒推最后一层的起点 j，累加厚度 `w`、维护层高 `h = max(h, books[k][1])`，一旦 `w > shelfWidth` 就 break。
3. 对每个合法 j 更新 `dp[i] = min(dp[i], dp[j] + h)`。
4. 返回 `dp[n]`。

以示例 1 的 `books = [[1,1],[2,3],[2,3],[1,1],[1,1],[1,1],[1,2]]`、`shelfWidth = 4` 为例：算 `dp[2]` 时，最后一层若只放第 2 本（下标 1），`dp[1] + 3 = 1 + 3 = 4`；若把第 1、2 本放同一层，厚度 `1 + 2 = 3 ≤ 4`，层高 `max(1,3) = 3`，得 `dp[0] + 3 = 3`，取小为 3。最终 `dp[7] = 6`。

```python
n = len(books)
dp = [0] + [2**31 - 1] * n
for i in range(1, n + 1):
    w = 0
    h = 0
    j = i - 1
    while j >= 0:
        w += books[j][0]
        if w > shelfWidth:
            break
        h = max(h, books[j][1])
        dp[i] = min(dp[i], dp[j] + h)
        j -= 1
return dp[n]
```

## 复杂度
时间：O(n²)，每个 i 向前最多扫 n 本，n 为书数。
空间：O(n)，只开了长度 n+1 的 `dp` 数组。

## 易错点
- 把 `dp` 初值设成 0 或很小的数 → 未计算的状态被当成合法答案参与 `min`，结果偏小 → 必须用 `2**31 - 1` 初始化 `dp[1..n]`，只让 `dp[0] = 0`。
- 先判断 `w > shelfWidth` 再更新 `h` 和 `dp`，顺序写反 → 厚度已超宽的那本书仍被算进层高，答案偏大 → 必须累加厚度后立刻 break，再更新 `h` 与 `dp[i]`。

## 如果面试官追问
问：n 放大到 10⁵ 还能这么做吗？
答：不能，O(n²) 会超时；需用单调栈维护「层高最大值」的分段，配合前缀和把转移压到 O(n log n) 或 O(n)。
