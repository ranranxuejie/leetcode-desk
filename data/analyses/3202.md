## 一句话思路
把相邻两项之和的模固定为 `t`，用 `dp[t][r]` 记录以余数 `r` 结尾的最长链，边扫边更新。

## 怎么做
1. 关键观察：条件等价于存在 `t`，使链中每对相邻项满足 `(前 + 后) % k == t`；给定 `t` 和当前项余数 `r`，前一项余数被唯一确定为 `(t - r) % k`。
2. 因此对每个 `t ∈ [0, k)` 维护一维数组 `dp[r]`，表示以余数 `r` 结尾的最长有效子序列长度。
3. 扫 `nums`，对每个 `t` 用 `dp[(t - r) % k] + 1` 更新 `dp[r]`，注意必须用**更新前**的旧值，否则同一元素会被重复使用。
4. 答案取所有 `dp[r]` 的最大值。

以 `nums = [1,4,2,3,1,4], k = 3` 为例：取 `t = 2`，扫到第二个 `1`（余数 1）时，`dp[(2-1)%3] = dp[1]` 此时为 2（链 `[1,4]`），更新后 `dp[1] = 3`；再扫到 `4`（余数 1），`dp[1]` 变 4，得到 `[1,4,1,4]`。

```python
n, k = len(nums), k
ans = 1
for t in range(k):
    dp = [0] * k
    for x in nums:
        r = x % k
        prev = (t - r) % k
        dp[r] = max(dp[r], dp[prev] + 1)
        ans = max(ans, dp[r])
```

注意 `dp[r]` 与 `dp[prev]` 可能是同一个下标（当 `r == prev`，即 `2r % k == t`），此时 `dp[r] = dp[r] + 1` 自增，正是「同一余数反复接龙」的正确行为，无需特判。

## 复杂度
时间：`O(k * n)`，外层 `k` 次、内层扫 `n` 个元素。
空间：`O(k)`，每个 `t` 只开一个长度 `k` 的 `dp` 数组，循环间复用。

## 易错点
- 输入 `nums = [1,2,3,4,5], k = 2`：若把 `dp` 写在 `t` 循环外只初始化一次，不同 `t` 的结果会互相污染，答案偏大；正确做法是每个 `t` 重新开 `dp = [0] * k`。
- 输入 `nums = [1,1,1], k = 2`：若先算 `dp[r]` 再读 `dp[prev]`，当 `r == prev` 时会读到刚更新的值，长度被虚增；正确做法是先把 `dp[prev] + 1` 算出来再赋给 `dp[r]`（或按上面代码用 `max` 一次性写回）。
- 单元素子序列恒有效，`ans` 初值必须是 1 而不是 0。

## 如果面试官追问
问：若 `k` 增大到 `10^9` 怎么办？
答：`k` 大时不能枚举 `t`，改为枚举「前一项余数」对，用哈希表存 `(t, r)` 状态，复杂度退化为 `O(n^2)`。
