## 一句话思路
按奇偶分治：奇数放左、偶数放右，递归构造，因为 2·nums[k]=nums[i]+nums[j] 在奇偶同侧时不可能成立。

## 怎么做
1. 递归基：`n == 1` 直接返回 `[1]`。
2. 把 `1..n` 拆成奇数序列 `1,3,5,...` 和偶数序列 `2,4,6,...`，长度分别是 `(n+1)//2` 和 `n//2`。
3. 对奇数长度递归得到 `left`，对偶数长度递归得到 `right`，把 `left` 映射成 `2*x-1`、`right` 映射成 `2*x`，拼接返回。
4. 以 `n = 5` 为例：奇数长度 3、偶数长度 2；递归 `beautifulArray(3)` 得 `[2,1,3]`，映射后为 `[3,1,5]`；`beautifulArray(2)` 得 `[1,2]`，映射后为 `[2,4]`；拼接得 `[3,1,5,2,4]`，与示例 `[3,1,2,5,4]` 同为合法答案。

```python
def beautifulArray(n):
    if n == 1:
        return [1]
    left = beautifulArray((n + 1) // 2)
    right = beautifulArray(n // 2)
    return [2 * x - 1 for x in left] + [2 * x for x in right]
```

关键点：映射 `2*x-1` 把 `left` 里的相对顺序原样搬到奇数位上，`2*x` 搬到偶数位上，所以子问题的「漂亮」性质被保留；而跨左右取 `i` 在左、`j` 在右时，`nums[i]+nums[j]` 是奇数，`2*nums[k]` 是偶数，等式不可能成立。

## 复杂度
时间：`O(n log n)`，每层总长度是 `n`，递归深度 `log n`。
空间：`O(n log n)` 的列表开销（每层都新建列表），递归栈 `O(log n)`。

## 易错点
- `n = 1` 时若直接走拆分逻辑，`n // 2 = 0` 会递归出空列表，返回 `[]` 而不是 `[1]`；必须先写 `if n == 1: return [1]` 兜底。
- 用 `2*x` 映射偶数时若写成 `2*x-1`，`n = 4` 会得到 `[1,3,1,3]` 这种重复元素，不再是 `1..n` 的排列；奇偶两段的映射公式必须不同，且 `left` 用 `2*x-1`、`right` 用 `2*x`。

## 如果面试官追问
问：要求返回字典序最小的漂亮数组怎么办？
答：分治只保证合法不保证最小，需换构造或对候选做验证，`n ≤ 1000` 时可枚举小规模找规律。
