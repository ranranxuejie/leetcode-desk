## 一句话思路
按右端点升序排序后贪心，每次只在区间最右端补数，让新加的数尽可能被后面的区间复用。

## 怎么做
1. 把 `intervals` 按 `end` 升序排序，右端点相同的顺序无所谓。
2. 维护已选集合里最大的两个数 `a < b`（初始为 `-1, -1`，因为 `start >= 0`）。
3. 对每个 `[s, e]`：若 `s <= a` 则已含两个数，跳过；若 `s <= b` 则只缺一个，补 `e`，更新 `a, b = b, e`；否则两个都缺，补 `e-1, e`，更新 `a, b = e-1, e`。
4. 每补一个数答案 `+1`。

以示例 1 `[[1,3],[3,7],[8,9]]` 排序后不变。处理 `[1,3]`：`s=1 > b=-1`，补 `2,3`，`a=2,b=3`。处理 `[3,7]`：`s=3 <= b=3` 但 `s > a=2`，只缺一个，补 `7`，`a=3,b=7`。处理 `[8,9]`：`s=8 > b=7`，补 `8,9`。答案 5。

```python
intervals.sort(key=lambda x: x[1])
a = b = -1
ans = 0
for s, e in intervals:
    if s <= a:
        continue
    if s <= b:
        a, b = b, e
        ans += 1
    else:
        a, b = e - 1, e
        ans += 2
return ans
```

关键在 `s <= a` 这个判断：`a, b` 是当前选中的最大两个数，只要区间左端点不超过 `a`，这两个数就都落在区间内。

## 复杂度
时间：排序 `O(n log n)`，扫描 `O(n)`，n 为区间数。
空间：排序栈空间 `O(log n)`，其余只用了 `a, b, ans` 三个变量。

## 易错点
- 输入 `[[1,2],[2,3],[2,4],[4,5]]`：若按左端点排序，会先处理 `[1,2]` 补 `1,2`，再处理 `[4,5]` 补 `4,5`，中间 `[2,4]` 只含 `2` 一个数，答案错成 4；必须按右端点排序，让 `[2,4]` 先于 `[4,5]` 被满足。
- 输入 `[[1,3],[3,7]]`：若判断写成 `s < b` 而非 `s <= b`，`s=3, b=3` 会被误判为缺两个数，补 `6,7`，答案多 1；端点闭区间，等号必须取到。

## 如果面试官追问
要求输出具体的 `nums` 而不只是大小？答：把 `ans += 1/2` 换成 `append(e)` 或 `append(e-1); append(e)`，最后返回列表即可，贪心结构不变。
