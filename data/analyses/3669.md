## 一句话思路
枚举 n 的每个因数 d 作为当前因子，回溯填满 k 个位置，用「当前最大值 - 最小值」剪枝，取差值最小的方案。

## 怎么做
1. 预处理 n 的所有因数（升序），回溯时只从 `>= 上一个因子` 的因数里选，保证方案不重复。
2. 每层把 `n // d` 继续分解，剩余位置为 `k - len(path)`，当只剩 1 个位置时直接放剩余商。
3. 用当前 `max(path)` 与 `min(path)` 的差和已知最优 `best` 比较剪枝。

以 `n = 44, k = 3` 为例：第一层选 `d = 2`，剩余 `22`、还需 2 个数；第二层从 `>= 2` 的因数里选 `2`，剩余 `11`、还需 1 个数，直接放 `11`，得到 `[2,2,11]`，差值 `11-2 = 9`，刷新 `best = 9`。之后枚举 `[1,4,11]` 差值 10、`[1,2,22]` 差值 21 都被剪掉。

```python
def dfs(rem, start, path):
    nonlocal best, ans
    if len(path) == k - 1:
        cand = path + [rem]
        diff = max(cand) - min(cand)
        if diff < best:
            best, ans = diff, cand
        return
    for d in divs:
        if d < start or d * d > rem:
            break
        if rem % d == 0:
            dfs(rem // d, d, path + [d])
```

`divs` 是 n 的因数升序列表，`start` 保证非降序，`d * d > rem` 提前截断。

## 复杂度
时间：因数个数约 `O(sqrt(n))`，回溯受 k ≤ 5 与剪枝约束，实际远小于 `O(sqrt(n)^k)`。
空间：递归深度 k ≤ 5，`path` 与 `divs` 各 `O(sqrt(n))`。

## 易错点
1. 输入 `n = 44, k = 3` 时若允许因子乱序（如先选 11 再选 2），会重复枚举 `[2,2,11]` 与 `[11,2,2]`，且 `start` 失效导致剪枝错误；正确做法是回溯时强制 `d >= start`，保持非降序。
2. 输入 `n = 100, k = 2` 时若在 `len(path) == k` 才判断，会漏掉「最后一个位置直接放 `rem`」的分支，导致 `[10,10]` 枚举不到；正确做法是在 `len(path) == k - 1` 时把 `rem` 作为最后一个因子收尾。

## 如果面试官追问
问：若 k 增大到 10 怎么办？答：因数分解回溯仍可行，但需加「剩余商 >= 当前因子^(剩余位置)」的下界剪枝，否则分支爆炸。
