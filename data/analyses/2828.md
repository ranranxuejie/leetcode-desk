## 一句话思路
先比长度，再逐位比 `words[i][0]` 与 `s[i]`，长度不等直接 False。

## 怎么做
1. 若 `len(words) != len(s)`，直接返回 `False`——缩略词长度必然等于单词个数。
2. 否则用 `zip(words, s)` 同时遍历，逐对比较首字符。
3. 任一对不等即返回 `False`，全部通过返回 `True`。

以示例 2 为例：`words = ["an","apple"]`，`s = "a"`。第 1 步 `len(words)=2`、`len(s)=1`，不等，立刻返回 `False`，根本不用看首字母——这正是示例 2 的坑：两个单词首字母都是 `'a'`，串联是 `"aa"` 而非 `"a"`，长度检查一步拦下。

再看示例 1：`words = ["alice","bob","charlie"]`，`s = "abc"`。长度都是 3，进入 `zip`：`('alice','a')` 比 `'a'=='a'` 通过，`('bob','b')` 通过，`('charlie','c')` 通过，返回 `True`。

```python
if len(words) != len(s):
    return False
for w, c in zip(words, s):
    if w[0] != c:
        return False
return True
```

等价的一行写法是 `return len(words) == len(s) and all(w[0] == c for w, c in zip(words, s))`，但显式循环在面试时更好讲。注意 `w[0]` 安全：提示保证 `words[i].length >= 1`，不会空串越界。

## 复杂度
时间 O(n)：n 为 `len(words)`，最坏比完所有对，每对只取一个字符。
空间 O(1)：`zip` 是惰性迭代器，不额外开数组。

## 易错点
- `words = ["an","apple"], s = "a"` → 只比首字符会误判为 `True`（两个 `'a'` 里第一个就匹配上了）→ 必须先做 `len(words) != len(s)` 的长度闸门，长度不等直接 `False`。
- `words = ["ab","c"], s = "ac"` → 若写成 `s in "".join(w[0] for w in words)` 之类的子串/集合判断，会漏掉顺序和重复 → 必须按 `zip` 的下标一一对应比较，`words[0][0]` 只对 `s[0]`，不能对任意位置。

## 如果面试官追问
问：若 `words` 里允许空串怎么办？答：空串没有首字符，约定视为不匹配，比较前加 `if not w: return False`。
