## 一句话思路
把 nums 里所有大于 k 的不同值从大到小各操作一次，答案就是这些不同值的个数。

## 怎么做
1. 先扫一遍：只要出现 `nums[i] < k`，立刻返回 `-1`，因为操作只能把值变小，永远升不回 k。
2. 把所有 `nums[i] > k` 的值丢进集合 `s`，重复值只算一次。
3. 返回 `len(s)`。

以示例 1 `nums = [5,2,5,4,5], k = 2` 为例：没有元素小于 2，`s = {5,4}`，`len(s) = 2`，与输出一致。为什么成立：当前最大值集合里最大的那个值，一定可以选 `h` 为「第二大的值」，把最大值整体压下来；每压一次恰好消掉一个不同值，所以不同值个数就是最少次数。

```python
s = set()
for x in nums:
    if x < k:
        return -1
    if x > k:
        s.add(x)
return len(s)
```

示例 3 `nums = [9,7,5,3], k = 1`：`s = {9,7,5,3}`，返回 4，对应依次选 h = 7、5、3、1 四次操作。

## 复杂度
时间 O(n)：一次遍历，集合插入均摊 O(1)。
空间 O(n)：最坏情况下 `s` 存 n 个不同值。

## 易错点
- `nums = [2,1,2], k = 2` → 若只统计大于 k 的不同值，会得到 0 并返回 0，但 1 永远变不成 2 → 必须先检查 `x < k` 直接返回 -1。
- `nums = [3,3,3], k = 3` → 若把等于 k 的值也塞进集合，会返回 1，实际不需要任何操作 → 只对 `x > k` 做 `s.add(x)`，返回 0。

## 如果面试官追问
要求输出具体操作序列怎么办？答：把 `s` 降序排序，第 i 次操作取 `h = sorted_s[i+1]`（最后一个取 k），逐个输出即可。
