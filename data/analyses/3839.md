## 一句话思路
按前 k 个字符分桶计数，桶大小 ≥2 的桶数就是答案。

## 怎么做
1. 遍历 `words`，跳过 `len(w) < k` 的单词（它们无法贡献前缀）。
2. 用 `w[:k]` 作哈希键，统计每个前缀出现的次数。
3. 统计计数 ≥2 的键个数。

以示例 3 `words = ["bat","dog","dog","doggy","bat"], k = 3` 为例：`"bat"` 出现 2 次、`"dog"` 出现 2 次、`"doggy"` 的前缀 `"dog"` 也归入同一桶，所以 `"dog"` 桶计数为 3。最终两个桶（`"bat"`、`"dog"`）计数都 ≥2，返回 2。

```python
from collections import Counter

cnt = Counter()
for w in words:
    if len(w) >= k:
        cnt[w[:k]] += 1

ans = sum(1 for v in cnt.values() if v >= 2)
```

关键点：`"doggy"` 长度 5 ≥ 3，取 `w[:3]` 得 `"dog"`，与两个 `"dog"` 合并，桶值从 2 变 3——这正是示例 3 输出 2 而非 3 的原因。

## 复杂度
时间：O(n·k)，n 为单词数，每个单词切片最多 k 个字符。
空间：O(n·k)，哈希表最多存 n 个长度为 k 的前缀。

## 易错点
- 输入 `words = ["car","cat","cartoon"], k = 3` → 若用 `startswith` 两两比较会漏掉 `"car"` 与 `"cartoon"` 的配对（长度不同但前缀相同）→ 正确做法是统一取 `w[:k]` 作键，长度不足 k 的直接跳过。
- 输入 `words = ["bat","dog","dog","doggy","bat"], k = 3` → 若把 `"doggy"` 当成独立单词或按完整字符串去重，会得到 1 或 3 → 正确做法是重复字符串视为不同单词（计数累加），且 `"doggy"` 的前缀 `"dog"` 必须并入 `"dog"` 桶。

## 如果面试官追问
若要求返回每个连接组的具体单词列表而非组数，怎么改？
答：把 `Counter` 换成 `defaultdict(list)`，键为 `w[:k]`、值为单词列表，最后筛出长度 ≥2 的列表即可。
