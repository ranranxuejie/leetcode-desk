## 一句话思路
从 start 出发做 BFS/DFS，用 visited 数组去重，能碰到 target 就返回 True。

## 怎么做
1. 先把 graph 的边表转成邻接表 `adj`，节点数 n 可达 1e5，边表里平行边很多（示例 2 里 `[0,4]` 出现两次）。
2. 特判 `start == target` 直接返回 True，否则自环 `[0,0]` 会让 visited 逻辑绕圈。
3. 用栈做 DFS，从 start 弹出节点，遍历 `adj[u]`，遇到 target 立即 True，未访问的邻居压栈并标记。
4. 栈空仍未命中返回 False。

以示例 2 为例：`adj[0] = [1,2,4,4,1]`，第一轮弹出 0，邻居 1 未访问压栈并标记，邻居 2、4 同理；弹出 4 时 `u == target`，直接返回 True，此时 visited 里只有 `{0,1,2,4}`，节点 3 根本没被展开。

```python
adj = [[] for _ in range(n)]
for a, b in graph:
    adj[a].append(b)
if start == target:
    return True
visited = [False] * n
visited[start] = True
stack = [start]
while stack:
    u = stack.pop()
    for v in adj[u]:
        if v == target:
            return True
        if not visited[v]:
            visited[v] = True
            stack.append(v)
return False
```

## 复杂度
时间 O(n + E)，E 是 graph 长度（含平行边），每个节点入栈一次、每条边扫一次。
空间 O(n + E)，邻接表存了全部边，visited 和 stack 各 O(n)。

## 易错点
- 输入 `n = 0` 或 `start`/`target` 越界（题面说编号在 [0,n) 内，但 n=0 时 start 无意义）→ 直接建 `adj = [[] for _ in range(n)]` 后访问 `adj[start]` 会 IndexError → 先判 `start == target` 再判 `n == 0` 返回 False。
- 示例 1 里 `[1,2]` 出现两次、示例 2 里 `[0,4]` 出现两次 → 若用「边数」当终止条件或不去重 visited，会在平行边上重复压栈导致栈膨胀甚至死循环 → 必须用 visited 标记节点而非边，压栈前检查 `not visited[v]`。

## 如果面试官追问
要求输出具体路径而非布尔值怎么办？答：把 stack 换成存 `(node, path)` 或额外维护 parent 数组，命中 target 后从 parent 回溯即可，空间仍是 O(n)。
