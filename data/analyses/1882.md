## 一句话思路
用「空闲堆（权重,下标）」+「忙碌堆（结束时间,权重,下标）」模拟时间推进，每次取权重最小的空闲服务器。

## 怎么做
1. 把全部服务器 `(servers[i], i)` 压入空闲堆 `free`，忙碌堆 `busy` 存 `(结束时间, 权重, 下标)`。
2. 按 `j` 从 0 到 m-1 遍历任务，当前时刻 `t = max(t, j)`（任务 j 最早第 j 秒可开始）。
3. 先把 `busy` 中结束时间 `<= t` 的服务器弹出，压回 `free`；若 `free` 为空，则令 `t = busy[0][0]` 并重复弹出。
4. 从 `free` 弹出堆顶分配任务，记录下标，把 `(t + tasks[j], 权重, 下标)` 压入 `busy`。

以示例 1 的 `servers=[3,3,2], tasks=[1,2,3,2,1,2]` 为例：j=0 时 t=0，free 堆顶是 `(2,2)`，分配服务器 2，busy 压入 `(1,2,2)`；j=1 时 t=1，弹出 `(1,2,2)` 回 free，堆顶仍是 `(2,2)`，ans[1]=2，busy 压入 `(3,2,2)`。

```python
import heapq
free = [(w, i) for i, w in enumerate(servers)]
heapq.heapify(free)
busy, ans, t = [], [], 0
for j, dur in enumerate(tasks):
    t = max(t, j)
    while busy and busy[0][0] <= t:
        end, w, i = heapq.heappop(busy)
        heapq.heappush(free, (w, i))
    if not free:
        t = busy[0][0]
        while busy and busy[0][0] <= t:
            end, w, i = heapq.heappop(busy)
            heapq.heappush(free, (w, i))
    w, i = heapq.heappop(free)
    ans.append(i)
    heapq.heappush(busy, (t + dur, w, i))
```

## 复杂度
时间：O((n+m) log n)，每次堆操作 log n，共约 n+m 次。
空间：O(n)，两个堆各存 n 个元素，ans 存 m 个。

## 易错点
- 输入 `servers=[1], tasks=[1,1,1]`：若只在 `free` 非空时才推进时间，j=1 时 free 为空会直接崩或错配。正确做法是 free 为空时把 `t` 跳到 `busy[0][0]` 再重试弹出。
- 输入 `servers=[3,3,2]`：若堆里只存权重不存下标，两台权重 3 的服务器顺序不确定，ans 会错成 `[2,2,1,...]`。正确做法是元组写成 `(权重, 下标)`，靠下标天然升序打破平局。

## 如果面试官追问
问：如果任务不是第 j 秒到达而是给定到达时间数组？答：把 `t = max(t, j)` 换成 `t = max(t, arrive[j])`，其余堆逻辑不变。
