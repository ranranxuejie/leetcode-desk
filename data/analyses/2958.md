## 一句话思路
右指针扩张、左指针收缩的滑动窗口，窗口内用哈希表记频率，一旦某值频率超过 k 就左移直到它降回 k。

## 怎么做
1. 用 `left`、`cnt`（字典）维护当前窗口 `nums[left..right]` 内每个值的出现次数。
2. `right` 从 0 遍历到 `n-1`，先把 `nums[right]` 计入 `cnt`。
3. 若 `cnt[nums[right]] > k`，说明只有这个值越界，循环 `cnt[nums[left]] -= 1; left += 1` 直到它回到 k。
4. 每轮用 `right - left + 1` 更新 `ans`。

以示例 1 `nums = [1,2,3,1,2,3,1,2], k = 2` 为例：`right` 走到 5 时窗口是 `[1,2,3,1,2,3]`，`cnt = {1:2, 2:2, 3:2}`，全部 ≤ 2，`ans = 6`；`right = 6` 时 `cnt[1]` 变成 3，左指针从 0 移到 1，`cnt[1]` 回到 2，窗口变 `[2,3,1,2,3,1]`，长度仍是 6。

```python
cnt = {}
left = ans = 0
for right, x in enumerate(nums):
    cnt[x] = cnt.get(x, 0) + 1
    while cnt[x] > k:
        cnt[nums[left]] -= 1
        left += 1
    ans = max(ans, right - left + 1)
return ans
```

关键点：`while` 的条件只看 `cnt[x]`，因为每轮只新增一个元素，越界的只可能是它。

## 复杂度
时间 O(n)：`right` 走 n 步，`left` 总共也只走 n 步，均摊线性。
空间 O(m)：`cnt` 存窗口内不同值，m ≤ min(n, 不同值个数)，最坏 O(n)。

## 易错点
- 输入 `nums = [5,5,5,5,5,5,5], k = 4` → 若把 `while` 写成 `if`，`cnt[5]` 会停在 5 以上，窗口长度算成 7 → 必须用 `while` 一直收缩到 `cnt[5] == 4`，答案才是 4。
- 输入 `nums = [1,2,1,2,1,2,1,2], k = 1` → 若收缩时忘了 `cnt[nums[left]] -= 1` 只移 `left`，字典频率不降，`while` 死循环或窗口被无限压缩 → 移指针和减计数必须成对出现。

## 如果面试官追问
问：要求返回最长好子数组本身而非长度？答：在更新 `ans` 时同步记录 `best_left = left`、`best_right = right`，最后切片 `nums[best_left:best_right+1]` 即可，复杂度不变。
