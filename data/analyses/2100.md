## 一句话思路
用两个 DP 数组分别记录「以 i 结尾的连续非递增长度」和「以 i 开头的连续非递减长度」，再扫一遍取交集。

## 怎么做
1. 定义 `left[i]`：满足 `security[i-k] >= ... >= security[i]` 的最大 k（即 i 左侧连续非递增天数，不含 i 本身）。`left[0]=0`，若 `security[i-1] >= security[i]` 则 `left[i]=left[i-1]+1`，否则 0。
2. 定义 `right[i]`：i 右侧连续非递减天数。`right[n-1]=0`，若 `security[i] <= security[i+1]` 则 `right[i]=right[i+1]+1`，否则 0。
3. 遍历 i，`left[i] >= time and right[i] >= time` 就收进答案。

以 `security=[5,3,3,3,5,6,2], time=2` 为例，关键中间值：`left=[0,1,2,3,0,0,0]`（第 3 天前有 3 天非递增），`right=[0,0,0,1,2,1,0]`（第 2 天起 3,5,6 非递减）。i=2 时 `left[2]=2>=2`、`right[2]=2>=2`，命中；i=3 时 `left[3]=3`、`right[3]=1<2`，不命中——注意 `right[3]` 只数到 5,6 两天，第 6 天是 2 断了。

```python
n = len(security)
left = [0] * n
right = [0] * n
for i in range(1, n):
    if security[i - 1] >= security[i]:
        left[i] = left[i - 1] + 1
for i in range(n - 2, -1, -1):
    if security[i] <= security[i + 1]:
        right[i] = right[i + 1] + 1
return [i for i in range(n) if left[i] >= time and right[i] >= time]
```

## 复杂度
时间 O(n)：两趟 DP 加一趟扫描，各线性。
空间 O(n)：`left`、`right` 两个长度 n 的数组，答案列表最坏也是 n。

## 易错点
- `time=0` 时：若把条件写成 `left[i] > time` 或额外判断 `i-time>=0`，会漏掉全部或部分下标。正确做法是 `>= time`，此时 `left[i]>=0` 恒真，直接返回所有下标。
- 相等元素：`security=[3,3,3]` 时若把非递增写成严格 `>`，`left[2]` 会算成 0 而非 2。题目要求「非递增/非递减」，比较必须用 `>=` 和 `<=`，等号算合法。

## 如果面试官追问
问：能否把空间压到 O(1)？
答：可以，先正序算出 `left` 存进答案候选，再逆序滚动一个变量算 `right` 并当场判定，但代码可读性下降，n=1e5 时没必要。
