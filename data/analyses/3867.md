## 一句话思路
先扫一遍维护 `mx` 并算出 `prefixGcd`，排序后首尾配对累加 `gcd`，中间元素自然被跳过。

## 怎么做
1. 单次遍历：`mx = max(mx, x)`，把 `gcd(x, mx)` 追加进 `prefixGcd`。
2. 对 `prefixGcd` 排序，得到非递减序列。
3. 双指针 `i = 0`、`j = n - 1`，当 `i < j` 时累加 `gcd(prefixGcd[i], prefixGcd[j])` 并 `i += 1; j -= 1`。
4. 循环结束时若 `n` 为奇数，`i == j` 指向中间元素，不进入循环，自动忽略。

以 `nums = [3,6,2,8]` 为例：遍历后 `mx` 依次为 3、6、6、8，`prefixGcd = [3, 6, 2, 8]`；排序得 `[2, 3, 6, 8]`；第一对 `gcd(2, 8) = 2`，第二对 `gcd(3, 6) = 3`，`i` 与 `j` 交错退出，答案 5。

```python
from math import gcd

mx = 0
prefix_gcd = []
for x in nums:
    mx = max(mx, x)
    prefix_gcd.append(gcd(x, mx))

prefix_gcd.sort()
ans = 0
i, j = 0, len(prefix_gcd) - 1
while i < j:
    ans += gcd(prefix_gcd[i], prefix_gcd[j])
    i += 1
    j -= 1
```

注意 `mx` 初值取 0 即可，因为 `nums[i] >= 1`，第一次 `max(0, x) = x`，`gcd(x, x) = x` 与题面 `mx_0 = nums[0]` 一致。

## 复杂度
时间：O(n log n)，排序主导，遍历与配对各 O(n)，每次 `gcd` 为 O(log V)。
空间：O(n)，`prefixGcd` 存 n 个值，排序原地进行。

## 易错点
1. 把 `mx_i` 误当成 `nums[i]` 或整个数组的最大值 → 对 `[3,6,2,8]` 会算出 `[3,6,2,8]` 之外的错误序列（如全用全局 max 8 得 `[1,2,2,8]`）→ 正确做法是边遍历边更新 `mx`，`mx` 只增不减。
2. 奇数长度时把中间元素也拿去配对 → 对 `[2,6,4]` 排序后 `[2,2,6]`，若写成 `i <= j` 会多算一次 `gcd(2,2) = 2`，答案错成 4 → 循环条件必须是 `i < j`，让 `i == j` 自然退出。

## 如果面试官追问
问：若要求返回所有配对方案而不只是和？答：双指针时把 `(prefixGcd[i], prefixGcd[j])` 存进列表返回即可，复杂度不变。
