## 一句话思路
按列独立：每列内部必须全相等，相邻列取值必须不同，于是对列做「选值」DP，值域只需 0..9。

## 怎么做
1. 先算每列代价：`cost[j][v]` = 第 j 列改成全 v 要改几个格子，即 `n - cnt[j][v]`。
2. 关键观察：值域 0..9 共 10 个，最优解里每列的值一定落在 0..9 内（改成 ≥10 只会多花操作，且不帮助区分相邻列）。
3. DP：`dp[v]` = 前 j 列处理完、第 j 列取 v 的最小代价；转移 `dp2[v] = cost[j][v] + min(dp[u] for u != v)`。
4. 用「最小 + 次小」把 `min over u != v` 降到 O(1)，每列 O(10)。

以示例 2 `grid = [[1,1,1],[0,0,0]]` 为例：`cnt[0] = {1:1, 0:1}`，`cost[0][1] = 1`；第 1 列同理 `cost[1][0] = 1`；第 2 列 `cost[2][1] = 1`。取 1,0,1 总代价 3，与输出一致。

```python
INF = 10**9
dp = [0] * 10
for j in range(len(grid[0])):
    cost = [len(grid) - sum(row[j] == v for row in grid) for v in range(10)]
    m1 = min(dp); i1 = dp.index(m1)
    m2 = min(dp[v] for v in range(10) if v != i1)
    ndp = [0] * 10
    for v in range(10):
        ndp[v] = cost[v] + (m2 if v == i1 else m1)
    dp = ndp
return min(dp)
```

## 复杂度
时间 O(m·n + n·10)，m·n 来自统计每列频次，n·10 来自 DP。
空间 O(10)，只存 `dp`/`ndp` 两个长度 10 的数组。

## 易错点
- 把「下面相邻相等」误当成「行内相等」→ 会对 `[[1],[2],[3]]` 输出 0 而不是 2 → 记住约束是**列内全等、列间不等**，转置后 DP 才对。
- 只保留每列出现最多的值做候选 → 示例 2 中第 0 列众数 1 与第 1 列众数 0 恰好可行，但换成 `[[0,0],[0,1]]` 这类会漏掉「次优值」→ 必须对 10 个值全枚举，用最小/次小转移。

## 如果面试官追问
若值域放大到 10^9 怎么办？答：候选值只需取「各列出现过的值 ∪ 少量补位值」，用哈希 + 全局最小/次小转移，复杂度仍是 O(m·n + n·k)。
