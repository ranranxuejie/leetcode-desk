## 一句话思路
把每个元素取模 k 后，有韧性等价于「子数组内所有余数相同」，用前缀和加哈希找最长等余区间。

## 怎么做
1. 先证等价：设子数组和为 S，删掉元素 x 后剩 S−x，要求 S−x ≡ 0 (mod k) 对每个 x 成立，即所有 x ≡ S (mod k)，也就是子数组内每个元素模 k 的余数都相等。
2. 于是问题变成：找最长的连续段，段内 `nums[i] % k` 全部相同。
3. 用「分段」扫描：维护当前段的余数 `cur` 和起点 `start`，遇到 `nums[i] % k != cur` 就结算长度 `i - start`，再把 `start = i`、`cur` 换成新余数。
4. 扫完补一次结算 `n - start`。

以示例 3 `nums = [5,5,4,8], k = 4` 为例：余数为 `[1,1,0,0]`。i=0 起段 cur=1；i=1 余 1 不变；i=2 余 0 不等，结算长度 `2-0=2`，start 改 2、cur=0；i=3 余 0 不变；收尾结算 `4-2=2`。答案 2，与官方一致。

```python
n = len(nums)
best = 0
start = 0
cur = nums[0] % k
for i in range(1, n):
    r = nums[i] % k
    if r != cur:
        best = max(best, i - start)
        start, cur = i, r
best = max(best, n - start)
return best
```

注意 k=1 时所有余数都是 0，整段合法，直接返回 n，上面的循环也自然给出 n。

## 复杂度
时间 O(n)：一次线性扫描，每个元素只取一次模。
空间 O(1)：只存 start、cur、best 三个变量，不额外开数组。

## 易错点
- 输入 `nums = [5,5,4,8], k = 4`：若只比较相邻两元素是否同余，会把 `[5,5]` 判成合法段，但删掉一个 5 剩 5 不能被 4 整除；正确做法是整段余数必须全等，靠 `cur` 记录段首余数而非前一个元素。
- 输入 `nums = [2,4,6,3], k = 2`：若忘记收尾结算，最后一段 `[2,4,6]`（余数全 0）长度 3 会漏掉，只返回 0；循环结束后必须再算一次 `n - start`。

## 如果面试官追问
问：要求返回具体子数组下标而不只是长度？
答：结算时多存 `(start, i-1)`，取最大长度那一段的起止即可，逻辑不变。
