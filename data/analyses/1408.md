## 一句话思路
对每个 `words[i]`，只要存在另一个更长的 `words[j]` 使 `words[i] in words[j]`，就收进答案。

## 怎么做
1. 外层遍历每个候选短串 `w = words[i]`。
2. 内层遍历所有 `words[j]`，跳过 `i == j` 自身。
3. 用 `w in words[j]` 判断子串，命中一次就 `break`，避免重复加入。
4. 用 `len(w) < len(words[j])` 提前剪枝，长度不更长的必然不可能是真子串。

以示例 1 `["mass","as","hero","superhero"]` 为例：处理 `w = "as"` 时，`j` 走到 `"mass"`，`"as" in "mass"` 为 `True`，立即 `break` 并加入答案；处理 `"hero"` 时，`"hero" in "superhero"` 为 `True`，同样命中。而 `"mass"` 与 `"superhero"` 找不到更长的容器，被排除。

```python
res = []
for i, w in enumerate(words):
    for j, other in enumerate(words):
        if i != j and len(w) < len(other) and w in other:
            res.append(w)
            break
return res
```

关键点：`break` 放在 `append` 之后，保证每个单词最多进答案一次；`len(w) < len(other)` 让 `"as"` 不会去和 `"as"` 自己比，也省掉大量无意义的 `in` 检查。

## 复杂度
时间：O(n² · L)，n 为 `words` 长度，L 为最长串长，`in` 每次最多扫 L 个字符。
空间：O(1) 额外空间（不计返回的 `res`），没有开集合或哈希表。

## 易错点
- 输入 `["a","a"]` 这类（虽然题面保证唯一，但若允许重复）→ 用 `i != j` 只排下标，两个相同串会互相判定为子串 → 正确做法是加 `len(w) < len(other)`，长度相等直接跳过。
- 输入 `["blue","green","bu"]` → 若漏了 `break`，`"bu"` 在多个容器里命中会被重复 append → 正确做法是命中后立刻 `break`，保证每个 `w` 只进一次。

## 如果面试官追问
问：若 `words` 长度到 10⁴ 怎么办？
答：按长度排序后只和更长的串比，或用字典树/后缀自动机把子串查询降到近线性。
