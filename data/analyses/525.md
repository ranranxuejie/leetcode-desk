## 一句话思路
把 0 记作 -1，问题变成「前缀和相等的最远下标差」，用哈希表存每个前缀和首次出现的下标。

## 怎么做
1. 令 `pre = 0`，`first = {0: -1}`（空前缀和为 0，下标 -1），`ans = 0`。
2. 遍历 `i, x`，`pre += 1 if x == 1 else -1`。
3. 若 `pre in first`，则 `ans = max(ans, i - first[pre])`；否则 `first[pre] = i`。
4. 返回 `ans`。

以 `nums = [0,1,1,1,1,1,0,0,0]` 为例，前缀和依次为 `-1,0,1,2,3,4,3,2,1`。到 `i=8` 时 `pre=1`，而 `first[1]=2`（`i=2` 处首次出现），长度 `8-2=6`，正是答案；`i=5` 时 `pre=4` 首次出现，只记下标不更新答案。

```python
pre, ans = 0, 0
first = {0: -1}
for i, x in enumerate(nums):
    pre += 1 if x == 1 else -1
    if pre in first:
        ans = max(ans, i - first[pre])
    else:
        first[pre] = i
return ans
```

关键点：`first` 只存**首次**下标，因为要最长；`{0: -1}` 这个哨兵让「从下标 0 开始的合法子数组」也能被算出长度，例如 `[0,1]` 在 `i=1` 时 `pre=0`，`1-(-1)=2`。

## 复杂度
时间 O(n)：一次遍历，每个元素做一次哈希查找和一次加法。
空间 O(n)：`first` 最多存 n+1 个不同前缀和。

## 易错点
- 输入 `[0,1]` → 若 `first` 初始化为空字典，`i=1` 时 `pre=0` 不在表里，会错答 0 → 必须预置 `{0: -1}`，用 -1 而不是 0 作哨兵下标。
- 输入 `[0,0,1,1]` → 若每次遇到相同 `pre` 都覆盖 `first[pre] = i`，`pre=0` 的下标被推到 2，`i=3` 时算出 `3-2=1`，错答 1 → 只在 `pre not in first` 时写入，保留最早下标。

## 如果面试官追问
若要求输出该子数组本身而非长度？答：`first` 存下标即可，命中时记下 `(first[pre]+1, i)`，最后按区间切片返回。
