## 一句话思路
把分数拆成「首尾固定项 + 切点贡献」，切点贡献就是相邻两珠之和，选 k-1 个最大/最小的切点相减。

## 怎么做
1. 任何方案必含 `weights[0] + weights[-1]`，与切法无关，先把它从差值里消掉。
2. 在 `i` 和 `i+1` 之间切一刀，就多付 `weights[i] + weights[i+1]`；共切 k-1 刀。
3. 把 n-1 个相邻和排序，最大分数取最大的 k-1 个，最小分数取最小的 k-1 个。
4. 两者相减即答案；k == 1 时无刀可切，返回 0。

以 `weights = [1,3,5,1], k = 2` 为例，相邻和为 `[4,8,6]`，切 1 刀：最大取 8（切在 3|5 后），最小取 4（切在 1|3 后），差值 `8 - 4 = 4`，与官方一致。

```python
n = len(weights)
if k == 1:
    return 0
gaps = [weights[i] + weights[i + 1] for i in range(n - 1)]
gaps.sort()
m = k - 1
return sum(gaps[-m:]) - sum(gaps[:m])
```

注意 `gaps[-m:]` 在 m == n-1 时就是整个数组，不会越界；`sum` 结果最大约 `2 * 10^9 * 10^5`，Python 整数无溢出问题。

## 复杂度
时间 O(n log n)：n-1 个相邻和排序主导，n 来自 weights 长度。
空间 O(n)：额外开了一个长度 n-1 的 gaps 列表。

## 易错点
- `k == 1` 时若照常算 `gaps[:0]` 和 `gaps[-0:]`，`-0` 就是 `0`，`gaps[-0:]` 等于整个数组，会返回负数；必须先特判返回 0。
- 只算切点贡献而忘了首尾项：`weights = [1,3,5,1], k = 2` 时若直接返回 `8 - 4 = 4` 恰好对，但换成 k = 3 的方案对比时，漏掉 `weights[0] + weights[-1] = 2` 会让最大最小都少 2，差值虽不变、但若面试官要求输出具体分数就会错；正确做法是明确首尾项在差值中抵消，只对切点排序。

## 如果面试官追问
要求输出具体分配方案而非差值怎么办？答：排序后记录每个相邻和的原下标，取最大 k-1 个下标升序即为切点位置，据此切分数组。
