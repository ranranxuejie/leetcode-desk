## 一句话思路
用并查集把每对 `intersect >= k` 的节点合并，最后数根节点个数；n≤100 所以 O(n²m) 暴力两两比较完全够。

## 怎么做
1. 先把每个 `properties[i]` 转成 `set`，去重后交集大小就是 `len(si & sj)`，避免重复元素把计数虚高。
2. 双重循环枚举 `i < j`，若 `len(si & sj) >= k` 就 `union(i, j)`。
3. 最后统计 `find(i) == i` 的个数，即连通分量数。

以示例 1 为例：`properties[0]=[1,2]`、`properties[1]=[1,1]`，去重后 `s1={1}`，`s0 & s1 = {1}` 大小为 1 ≥ k=1，所以 0 和 1 合并；而 `s1` 与 `s2={3,4}` 交集为空，不合并。注意 `[1,1]` 若不去重会算成 2，直接把示例 3 的答案从 2 错成 1。

```python
n = len(properties)
parent = list(range(n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
sets = [set(p) for p in properties]
for i in range(n):
    for j in range(i + 1, n):
        if len(sets[i] & sets[j]) >= k:
            ri, rj = find(i), find(j)
            if ri != rj:
                parent[ri] = rj
return sum(find(i) == i for i in range(n))
```

## 复杂度
时间 O(n²·m)：n² 对节点，每对求交集最多扫 m 个元素。
空间 O(n·m)：存 n 个去重集合，外加 O(n) 的 parent 数组。

## 易错点
- 输入 `[[1,1],[1,1]], k=2` → 若直接用原数组求交集会得到 2，误判有边、输出 1 → 必须先 `set(p)` 去重，正确答案是 2。
- 输入 `k` 大于两集合交集但等于单集合大小，如 `[[1,2],[1,3]], k=2` → 若误用 `len(si) >= k` 或 `len(si | sj)` 判断 → 必须严格用 `len(si & sj) >= k`，此例交集只有 `{1}` 大小 1，应无边。

## 如果面试官追问
若 n 放大到 10⁵ 怎么办？答：不能两两枚举，改为按「值 → 节点列表」建倒排，只对共享同一值的节点对计数，累计到 k 才 union，复杂度降到 O(Σ 值出现次数的平方)。
