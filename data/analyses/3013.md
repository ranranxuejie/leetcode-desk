## 一句话思路
固定最后一个切点 j，用对顶堆在窗口 nums[j-dist..j-1] 里维护最小的 k-2 个值之和，滑窗取最小。

## 怎么做
1. 第一个子数组代价恒为 nums[0]，最后一个切点 j 的代价是 nums[j]，中间还需 k-2 个切点，全部落在 [j-dist, j-1] 内。
2. 枚举 j 从 k-1 到 n-1，窗口是 nums[j-dist .. j-1]，用两个堆（大顶堆存最小的 k-2 个、小顶堆存其余）维护窗口内最小 k-2 个值之和 `s`。
3. 答案 = nums[0] + min over j of (nums[j] + s)。
4. 窗口滑动时先删 nums[j-dist-1]（懒删除），再加 nums[j-1]，并调整两堆大小使大顶堆恰有 k-2 个元素。

以示例 1 为例：nums=[1,3,2,6,4,2], k=3, dist=3，k-2=1。j=5 时窗口为 nums[2..4]=[2,6,4]，最小 1 个是 2，`s=2`，总代价 1+2+2=5。

```python
import heapq
# lo: 大顶堆(-v) 存最小 k-2 个; hi: 小顶堆 存其余
# s = sum of -x for x in lo
for j in range(k-1, n):
    # 加入 nums[j-1]，删除 nums[j-dist-1]（若存在）
    # 调整 lo 大小 == k-2，s 随 push/pop 更新
    ans = min(ans, nums[0] + nums[j] + s)
```

## 复杂度
时间 O(n log dist)：每个元素进出堆各一次，堆大小不超过 dist。
空间 O(dist)：两个堆加懒删除计数。

## 易错点
1. 窗口下界算错：j=k-1 时窗口应为 nums[k-1-dist .. k-2]，若写成 nums[j-dist .. j-1] 会越界或漏元素；正确做法是窗口左端 `max(0, j-dist)`，且保证长度 ≥ k-2（题设 k-2 ≤ dist 已保证）。
2. 懒删除时堆顶元素已过期却没弹出：删除 nums[j-dist-1] 后若它恰在 lo 堆顶，必须先 pop 再补元素，否则 `s` 会包含已离开窗口的值，示例 1 中 j=5 删 nums[1]=3 时就会算错。

## 如果面试官追问
若 dist 缩小到 k-2 恰好相等？答：窗口固定长度 k-2，退化为对每个 j 求定长窗口最小值之和，仍用同一对顶堆，只是无需懒删除。
