## 一句话思路
答案对 k 单调（前 k 个查询够用则更多也够用），二分 k，每次用差分数组 O(n+m) 判断前 k 个查询能否覆盖 nums。

## 怎么做
1. 二分下界 `lo=0`、上界 `hi=len(queries)`，找最小的可行 k。
2. 判定函数 `check(k)`：开长度 `n+1` 的差分数组 `diff`，对前 k 个查询做 `diff[l]+=val`、`diff[r+1]-=val`。
3. 从左到右累加 `cur`，逐位比较 `cur >= nums[i]`，任一位不满足即返回 `False`。
4. 二分结束若 `lo == len(queries)` 且仍不可行，返回 -1。

以示例 1 的 `nums=[2,0,2]`、`queries=[[0,2,1],[0,2,1],[1,1,3]]` 为例，`check(2)` 时前两个查询都覆盖 `[0,2]`，`diff` 累加后每个下标 `cur=2`，`2>=2`、`2>=0`、`2>=2` 全过，返回 `True`；而 `check(1)` 时 `cur=[1,1,1]`，下标 0 处 `1<2` 失败。

```python
def check(k):
    diff = [0] * (n + 1)
    for l, r, v in queries[:k]:
        diff[l] += v
        diff[r + 1] -= v
    cur = 0
    for i in range(n):
        cur += diff[i]
        if cur < nums[i]:
            return False
    return True

lo, hi = 0, len(queries)
while lo < hi:
    mid = (lo + hi) // 2
    if check(mid):
        hi = mid
    else:
        lo = mid + 1
return lo if check(lo) else -1
```

## 复杂度
时间：二分 O(log m) 次，每次 O(n+m)，共 O((n+m) log m)，m 为 queries 长度。
空间：每次 check 新开长度 n+1 的 `diff`，O(n) 额外空间。

## 易错点
- `nums` 里含 0（如示例 1 下标 1）：若把判定写成「必须恰好减到 0」或漏掉 `cur >= nums[i]` 的等号方向，会把 `nums[i]=0` 误判为不可行；正确做法是只要求累计减少量 `cur` 不小于 `nums[i]`，因为每个下标可独立选择减多少。
- 全部查询用完仍不够（示例 2）：若二分只返回 `lo` 而不做最后一次 `check(lo)`，会返回 `2` 而不是 `-1`；正确做法是二分后显式验证 `check(lo)`，失败返回 -1。

## 如果面试官追问
若要求输出具体每个查询在每个下标减多少？答：在 `check` 通过后正序回放前 k 个查询，按 `min(val, 剩余需求)` 贪心分配即可。
