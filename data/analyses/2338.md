## 一句话思路
把每个理想数组按「相邻倍数链」拆成质因数指数向量，用 DP 统计长度 ≤n 的链数，再乘组合数把链铺进 n 个位置。

## 怎么做
1. 关键观察：arr 的整除链等价于每个质因子的指数单调不减，且不同质因子互相独立，所以只需统计「单条链」的形态数。
2. 设 `dp[k]` = 以某个数结尾、链长为 k 的链数（按质因子指数向量计），用筛法枚举倍数转移：`dp[k][j] += dp[k-1][i]`（i 整除 j）。
3. 把长度 k 的链铺进 n 个位置：链上 k 个值必须按序出现，等价于在 n 个位置里选 k 个「跳变点」，方案数 `C(n-1, k-1)`。
4. 答案 = Σ_k `dp[k] * C(n-1, k-1)`，k 最大到 `log2(maxValue)+1`（因为每步至少乘 2）。

以 `n=2, maxValue=5` 为例：`dp[1]=5`（每个数自成链），`dp[2]` 统计 i|j 且 i<j 的对：1→2,3,4,5；2→4，共 5 对。答案 = `5*C(1,0) + 5*C(1,1) = 5+5 = 10`。

```python
MOD = 10**9 + 7
# dp[k][v]: 以 v 结尾、链长 k 的链数
dp = [[0]*(maxValue+1) for _ in range(maxk+1)]
for v in range(1, maxValue+1):
    dp[1][v] = 1
for k in range(2, maxk+1):
    for i in range(1, maxValue+1):
        for j in range(i*2, maxValue+1, i):
            dp[k][j] = (dp[k][j] + dp[k-1][i]) % MOD
# 组合数 C(n-1, k-1) 用阶乘预处理
ans = 0
for k in range(1, maxk+1):
    ans = (ans + sum(dp[k]) * comb(n-1, k-1)) % MOD
```

## 复杂度
时间：O(maxValue · log(maxValue) · maxk)，maxk ≈ log2(maxValue)，筛倍数贡献 log。
空间：O(maxValue · maxk) 存 dp 表，组合数阶乘 O(n)。

## 易错点
- `n=10000, maxValue=10000` 时若把 maxk 设成 n，dp 表开成 10^4×10^4 直接 MLE；正确做法是 maxk 取 `maxValue.bit_length()`（约 14），因为链长受倍数增长限制。
- `maxValue=1` 时只有全 1 数组，若循环从 k=2 开始且没处理 `dp[1]` 的 `C(n-1,0)=1`，会漏掉这 1 个；正确做法是 k=1 项必须计入。

## 如果面试官追问
若要求输出所有理想数组而非计数，怎么办？
答：把 dp 的计数改成存前驱列表，回溯枚举每条链，再对每条链枚举跳变点位置组合，输出规模本身是指数级。
