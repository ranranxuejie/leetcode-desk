## 一句话思路
奇数时看二进制末两位：`n % 4 == 3` 且 `n != 3` 就 `n+1`，否则 `n-1`，偶数直接右移，贪心每步最优。

## 怎么做
1. 循环条件写 `while n > 1`，用 `count` 累计替换次数。
2. 偶数时 `n //= 2`，`count += 1`，没有选择余地。
3. 奇数时判断 `n % 4 == 3 and n != 3`，成立走 `n += 1`，否则走 `n -= 1`。
4. 每轮结束 `count += 1`，返回 `count`。

以 `n = 7` 为例：`7 % 4 == 3` 且 `7 != 3`，走 `n + 1 = 8`，`count = 1`；之后 `8 -> 4 -> 2 -> 1` 三步，总计 4。若在 7 处错走 `n - 1 = 6`，路径是 `6 -> 3 -> 2 -> 1`，也是 4 步，这个例子两条路打平，看不出差别——真正区分的是 `n = 15`：`15 % 4 == 3`，`+1` 得 16，`16 -> 8 -> 4 -> 2 -> 1` 共 5 步；若 `-1` 得 14，`14 -> 7 -> 8 -> 4 -> 2 -> 1` 共 6 步，差 1 步。

```python
count = 0
while n > 1:
    if n % 2 == 0:
        n //= 2
    elif n % 4 == 3 and n != 3:
        n += 1
    else:
        n -= 1
    count += 1
return count
```

`n = 3` 必须走 `-1`：`3 -> 2 -> 1` 两步，`+1` 得 4 再两步共 3 步，所以 `n != 3` 这个条件不能省。

## 复杂度
时间：O(log n)，每轮 n 至少减半，最多约 32 轮（n ≤ 2**31 - 1）。
空间：O(1)，只用了 `count` 和 `n` 两个变量，没有递归栈和数组。

## 易错点
- 输入 `n = 3` → 若只写 `n % 4 == 3` 就 `+1`，会走 `3 -> 4 -> 2 -> 1` 得 3 步，正确是 `3 -> 2 -> 1` 得 2 步；必须加 `n != 3` 这个例外。
- 输入 `n = 2**31 - 1`（即 2147483647）→ 若用 `n + 1` 后按 32 位有符号截断，会变成 `-2**31` 死循环；Python 整数不溢出，`n + 1` 得 2147483648 正常继续，别手动模拟截断。

## 如果面试官追问
问：要求输出具体替换序列而不只是次数？
答：把每轮选中的 `n` 追加进 `path` 列表，循环结束后 `path.append(1)` 返回即可，贪心选择不变。
