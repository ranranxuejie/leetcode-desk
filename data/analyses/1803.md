## 一句话思路
用二进制字典树边插边查，把「异或值 ≤ x 的对数」写成 f(x)，答案就是 f(high) - f(low-1)。

## 怎么做
1. 定义 `f(x)`：统计所有满足 `nums[i] XOR nums[j] <= x` 的 `i < j` 对数；答案 = `f(high) - f(low - 1)`。
2. 遍历 `nums`，对每个 `v` 先在当前树里查「与 `v` 异或 ≤ x」的已有元素个数并累加，再把 `v` 插入树。
3. 查询时从高位（第 14 位，因为 `nums[i] ≤ 2*10^4 < 2**15`）往下走：若 `x` 当前位为 1，则异或位取 `v` 的同位时结果该位为 0，整棵子树都合法，直接累加其 `cnt`，然后走「异或位为 1」的分支继续；若 `x` 该位为 0，只能走「异或位为 0」的分支。
4. 走到底（15 位全部匹配）时再累加一次当前节点 `cnt`，对应异或值恰好等于 `x` 的情况。

以 `nums = [1,4,2,7], low=2, high=6` 为例：插入 `1` 后查 `4`，`4 XOR 1 = 5 ≤ 6` 计入 `f(6)`；而 `5 ≤ 1` 不成立，故不计入 `f(1)`，最终 `f(6) - f(1) = 6 - 0 = 6`。

```python
def f(x):
    if x < 0:
        return 0
    root = {}
    ans = 0
    for v in nums:
        node, cur = root, 0
        for b in range(14, -1, -1):
            vb, xb = (v >> b) & 1, (x >> b) & 1
            if xb:
                ans += node.get((vb,), {}).get('cnt', 0)  # 异或位=0 的整棵子树
                node = node.get((vb ^ 1,))
            else:
                node = node.get((vb,))
            if node is None:
                break
        else:
            ans += node.get('cnt', 0)
        node = root
        for b in range(14, -1, -1):
            node = node.setdefault((v >> b) & 1, {})
            node['cnt'] = node.get('cnt', 0) + 1
    return ans
```

## 复杂度
时间：`O(n * 15)`，`n = len(nums)`，每位一次字典跳转，共 15 位。
空间：`O(n * 15)` 个字典节点，即插入全部元素后的字典树规模。

## 易错点
- `low = 1` 时若直接算 `f(low)` 而非 `f(low - 1)`，会把异或值恰为 0 的对（只有 `nums[i] == nums[j]`）漏掉或多算；必须用 `f(high) - f(low - 1)`，且 `f` 内对 `x < 0` 返回 0。
- 位宽取 14 不够：`nums[i]` 最大 `2*10^4`，`2**14 = 16384 < 20000`，最高位会丢；应从第 14 位（`2**14`）起算到第 0 位，共 15 位。

## 如果面试官追问
若 `nums` 长度涨到 `10^6`，还能这么做吗？答：仍是 `O(n * 15)`，瓶颈变成字典节点内存，可改用数组式 trie（`ch[2]` + `cnt`）压掉字典开销。
