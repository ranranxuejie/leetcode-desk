## 一句话思路
年龄固定在 `s[11:13]`，直接切片转 `int` 与 60 比较，遍历计数即可。

## 怎么做
1. 遍历 `details` 中每个字符串 `s`，长度恒为 15，无需校验。
2. 取 `s[11:13]` 得到两位年龄字符串，`int()` 转成整数。
3. 若该整数 `> 60` 则计数加一，注意是严格大于。
4. 返回计数。

以示例 1 第一个元素 `"7868190130M7522"` 为例：下标 10 是 `'M'`，`s[11:13]` 取到 `"75"`，`int("75") = 75 > 60`，计数从 0 变 1；第三个元素 `s[11:13]` 是 `"40"`，不计数，最终返回 2。

```python
def countSeniors(details):
    cnt = 0
    for s in details:
        age = int(s[11:13])
        if age > 60:
            cnt += 1
    return cnt
```

切片起点为什么是 11 而不是 10：前 10 个字符是手机号（下标 0–9），下标 10 是性别，年龄从下标 11 开始占两位（11、12），座位号是 13、14。写成 `s[10:12]` 会把性别字符混进去，`int("M7")` 直接抛 `ValueError`。

## 复杂度
时间：O(n)，n 为 `details` 长度，每个元素只做一次定长切片和一次 `int` 转换。
空间：O(1)，只开 `cnt` 和循环变量 `s`，切片产生的是长度 2 的临时字符串。

## 易错点
- 输入 `"1313579440F2036"`：若用 `s[10:12]` 取年龄，得到 `"F2"`，`int()` 抛 `ValueError`；正确起点是 11，取 `s[11:13]` 得 `"20"`，不计数。
- 输入年龄恰为 `"60"`（如 `s[11:13] == "60"`）：若写成 `>= 60` 会把它算进去，示例里没有这种数据但题目要求严格大于；正确写法是 `int(s[11:13]) > 60`。

## 如果面试官追问
问：若年龄字段变成不定长、由分隔符隔开怎么办？
答：改用 `s.split(sep)` 后按固定字段下标取年龄，切片方案失效，复杂度仍是 O(n)。
