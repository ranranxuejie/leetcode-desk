## 一句话思路
逐层做「相邻和模 10」的模拟，因为每轮长度减一，最多 100 轮，直接算即可。

## 怎么做
1. 把 `s` 转成整数列表 `a`，循环条件是 `len(a) > 2`。
2. 每轮用列表推导生成 `b = [(a[i] + a[i+1]) % 10 for i in range(len(a)-1)]`，再 `a = b`。
3. 循环结束后比较 `a[0] == a[1]`。

以 `s = "3902"` 为例：`a = [3,9,0,2]`，第一轮得 `[(3+9)%10, (9+0)%10, (0+2)%10] = [2,9,2]`；第二轮 `[(2+9)%10, (9+2)%10] = [1,1]`，`a[0] == a[1]` 返回 `True`。

```python
a = [int(c) for c in s]
while len(a) > 2:
    a = [(a[i] + a[i + 1]) % 10 for i in range(len(a) - 1)]
return a[0] == a[1]
```

关键点：`% 10` 必须每轮都做，不能只在最后做；`"3902"` 若漏掉模 10，第一轮会得到 `[12,9,2]`，后续全错。

## 复杂度
时间：O(n²)，第 k 轮处理 n-k 个元素，共约 n²/2 次加法。
空间：O(n)，每轮新建列表 `b`，最大长度 n-1。

## 易错点
- 输入 `"3902"` 时若把 `(3+9)%10` 写成 `3+9`，第一轮得到 `[12,9,2]`，第二轮 `[21,11]` 判成不等；正确做法是每次加法后立刻 `% 10`，保证每个元素始终是 0-9。
- 输入 `"999"` 时若循环条件写成 `len(a) >= 2`，会在 `[8,8]` 上再算一轮变成 `[6]`，随后 `a[1]` 越界；正确做法是 `while len(a) > 2`，恰好剩两个就停。

## 如果面试官追问
问：n 扩大到 10^5 怎么办？
答：不能逐层模拟 O(n²)，要利用二项式系数：最终两数等于 `sum(C(n-2,i)*d_i) % 10` 与 `sum(C(n-2,i)*d_{i+1}) % 10`，用 Lucas 定理算组合数模 2 和模 5。
