## 一句话思路
把每个数取模 k 后计数，余数 r 必须与余数 (k-r)%k 数量相等，用哈希表一次校验。

## 怎么做
1. 对 `arr` 每个元素算 `r = x % k`，Python 的 `%` 对负数返回非负余数，正好符合需要，直接累加到 `cnt[r]`。
2. 遍历 `cnt` 的每个键 `r`，检查 `cnt[r] == cnt[(k - r) % k]`。
3. 全部相等返回 `True`，任一不等返回 `False`。

以示例 1 为例，`arr = [1,2,3,4,5,10,6,7,8,9]`、`k = 5`，取模后计数为 `{1:2, 2:2, 3:2, 4:2, 0:2}`。检查 `r=1` 时 `cnt[1]=2`、`cnt[(5-1)%5]=cnt[4]=2`，相等；`r=0` 时 `(5-0)%5=0`，自己和自己比，`cnt[0]=2` 为偶数，通过。

```python
from collections import Counter

cnt = Counter(x % k for x in arr)
for r, c in cnt.items():
    if c != cnt.get((k - r) % k, 0):
        return False
return True
```

关键点：`(k - r) % k` 这个写法把 `r=0` 映射回 `0`，避免写成 `k - r` 时 `r=0` 得到 `k` 这个不存在的键。示例 3 中 `k=10`，`arr` 取模得 `{1:1,2:1,3:1,4:1,5:1,6:1}`，检查 `r=1` 需要 `cnt[9]=0`，实际 `cnt[1]=1`，立即返回 `False`。

## 复杂度
时间：O(n)，遍历 arr 取模计数一次，再遍历至多 k 个余数键。
空间：O(k)，Counter 最多存 k 个不同余数。

## 易错点
- 负数元素如 `arr=[-1,1]`、`k=2`：若用 C 风格取模会得 `-1`，与 `1` 分成两组导致误判 `False`；Python 的 `-1 % 2 == 1` 天然正确，别手动写 `x - (x//k)*k` 之外的修正逻辑。
- `r=0` 的配对：写成 `cnt[k - r]` 时 `r=0` 查的是 `cnt[k]`，恒为 0，示例 1 的 `{0:2}` 会被判 `False`；必须用 `(k - r) % k` 或单独处理 `r == 0` 时检查 `cnt[0]` 为偶数。

## 如果面试官追问
要求输出具体配对方案怎么办？答：对每个余数 r 维护一个下标列表，`r` 与 `(k-r)%k` 两列表按序配对，`r=0` 或 `r*2==k` 时列表内部两两配对即可。
