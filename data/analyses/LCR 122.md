## 一句话思路
用 `str.replace('.', ' ')` 一次替换全部分隔符，因为题目只要求把 `.` 换成空格，不涉及转义或连续分隔符合并。

## 怎么做
1. 直接对 `path` 调用 `replace('.', ' ')`，返回新字符串。
2. 以官方示例 `path = "a.aef.qerf.bb"` 走一遍：`replace` 从左扫描，遇到下标 1 的 `.` 换成空格，下标 5、10 同理，得到 `"a aef qerf bb"`。
3. 不需要 `split` 再 `join`，因为那样在 `path` 为空串或含连续 `..` 时还要额外处理空段，而 `replace` 天然逐字符映射，`".."` 会变成两个空格，符合「替换分隔符」的字面语义。

```python
def pathEncryption(path: str) -> str:
    return path.replace('.', ' ')
```

关键中间值：输入 `"a.aef.qerf.bb"` 长度 13，其中 `.` 出现在下标 1、5、10，替换后长度仍是 13，三个位置变为 `' '`，其余字符原样保留。

## 复杂度
时间 O(n)：`replace` 扫描 `path` 每个字符一次，n 为 `path.length`。
空间 O(n)：返回新字符串占 n 个字符，原串不被修改。

## 易错点
- 输入 `path = ""` → 若先写 `path[0]` 或假设非空会抛 `IndexError` → 正确做法是直接 `replace`，空串返回空串，无需特判。
- 输入 `path = "a..b"` → 若用 `split('.')` 再 `' '.join(...)` 会得到 `"a  b"`（两个空格，中间夹一个空段），看似对；但若题目要求「连续分隔符合并」就会错 → 本题按字面替换，`replace` 得 `"a  b"` 正确，别自作主张去重。

## 如果面试官追问
若要求原地修改且 `path` 是字符数组（长度不变）？答：遍历下标，`path[i] == '.'` 时置 `' '`，O(n) 时间 O(1) 额外空间。
