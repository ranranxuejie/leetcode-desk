## 一句话思路
对每个 `w` 用 `s.startswith(w)` 判断，成立就计数；前缀定义天然对应这个判断。

## 怎么做
1. 初始化 `ans = 0`，遍历 `words` 中每个 `w`。
2. 用 `s.startswith(w)` 判断 `w` 是否为 `s` 的前缀，成立则 `ans += 1`。
3. 遍历结束返回 `ans`。

以示例 1 为例：`words = ["a","b","c","ab","bc","abc"]`，`s = "abc"`。逐个判断：`"a"` → `s.startswith("a")` 为 `True`，`ans=1`；`"b"` → `False`；`"c"` → `False`；`"ab"` → `True`，`ans=2`；`"bc"` → `False`；`"abc"` → `True`，`ans=3`。返回 3。

关键中间值：`"bc"` 虽然是 `s` 的子串，但 `s.startswith("bc")` 为 `False`，因为 `s[0:2] == "ab" != "bc"`。这正是「前缀」与「子串」的分界，不能写成 `w in s`。

```python
ans = 0
for w in words:
    if s.startswith(w):
        ans += 1
return ans
```

也可以写成一行生成器：

```python
return sum(s.startswith(w) for w in words)
```

`startswith` 内部按 `w` 的长度逐字符比较，长度超过 `s` 时直接返回 `False`，不会越界，无需手动加 `len(w) <= len(s)` 判断。

## 复杂度
时间：O(Σ|words[i]|)，每个 `w` 最多比较 `len(w)` 个字符，`s` 长度不影响上界。
空间：O(1)，只开了 `ans` 一个计数器，没有额外数组或哈希表。

## 易错点
- 输入 `words = ["bc"]`，`s = "abc"` → 若写成 `w in s` 会错判为 `True` 计 1 → 正确用 `s.startswith(w)`，返回 0。子串和前缀只差「是否从下标 0 开始」。
- 输入 `words = ["a","a"]`，`s = "aa"` → 若先去重成 `set(words)` 会错成 1 → 题目明确相同字符串计多次，必须对原列表逐个遍历累加，返回 2。

## 如果面试官追问
追问：若 `words` 规模到 10^5、`s` 长度到 10^5，怎么优化？
答：把 `words` 建前缀树或按长度分桶，只与 `s` 的前 `len(w)` 个字符比较，避免重复扫描长 `s`。
