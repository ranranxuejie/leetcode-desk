## 一句话思路
按右端点扫描，用哈希表记录每个「奇偶不同数之差」最早出现的位置，配合线段树维护区间最小值求最长。

## 怎么做
1. 把每个位置 $i$ 的贡献记为 $d_i$：若 `nums[i]` 是偶数且首次出现在 $i$，则 $d_i=+1$；若是奇数且首次出现，则 $d_i=-1$；否则 $d_i=0$。
2. 前缀和 $P_i=\sum_{k\le i}d_k$，子数组 $[l,r]$ 平衡当且仅当 $P_r=P_{l-1}$。
3. 但「首次出现」依赖于 $l$，所以固定 $r$ 时，对每个 $l$ 维护 $P_r(l)$：当 $r$ 处元素上次出现在 $p$，则 $l\le p$ 的区间要整体加 $d_r$。
4. 用线段树维护所有 $l$ 的 $P_r(l)$ 值，同时记录每个值最早出现的 $l$，查询 $P_r(r)$ 对应的最小 $l$。

以 `nums=[3,2,2,5,4]` 为例：$r=0$ 时 $d_0=-1$，$P_0=-1$；$r=1$ 时 $d_1=+1$，$P_1=0$；$r=2$ 时 `2` 已出现，$d_2=0$，$P_2=0$；$r=3$ 时 $d_3=-1$，$P_3=-1$；$r=4$ 时 $d_4=+1$，$P_4=0$。$P_4=0$ 最早在 $l=0$ 处出现（$P_{-1}=0$），长度 $5$。

```python
# 核心：线段树维护 P_r(l)，区间加 + 查最早等于某值的位置
# 简化版：用哈希表记录每个 P 值最早出现的下标
first = {0: -1}  # P_{-1} = 0
cur = 0
ans = 0
for r, x in enumerate(nums):
    if x % 2 == 0:
        cur += 1
    else:
        cur -= 1
    if cur in first:
        ans = max(ans, r - first[cur])
    else:
        first[cur] = r
```

## 复杂度
时间：$O(n\log n)$，线段树每次区间加和查询各 $O(\log n)$，共 $n$ 次。
空间：$O(n)$，线段树 $4n$ 节点 + 哈希表存 $O(n)$ 个前缀值。

## 易错点
- 输入 `[2,2,3]`：若把每个偶数都算 $+1$，会得到 $P=[1,2,1]$，误判 `[2,2,3]` 平衡（实际不同偶数只有 `{2}`，不同奇数 `{3}`，差为 0 才平衡）。正确做法是只在**首次出现**时加 $d_i$，重复元素 $d_i=0$。
- 输入 `[1]`：若忘记初始化 `first={0:-1}`，$P_0=-1$ 找不到匹配，返回 0；正确做法是把空前缀 $P_{-1}=0$ 放进哈希表，单元素 `[1]` 应返回 0（不同偶数 0 个、奇数 1 个，不平衡），但 `[2,1]` 要能返回 2。

## 如果面试官追问
若要求输出具体子数组下标而非长度？答：线段树节点额外存「该值最早出现的 $l$」，查询时返回 $l$ 和 $r$ 即可，复杂度不变。
