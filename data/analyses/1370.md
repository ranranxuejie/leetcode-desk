## 一句话思路
用长度 26 的计数数组代替排序，每轮先升序扫一遍再降序扫一遍，扫到计数为 0 就跳过。

## 怎么做
1. 建 `cnt = [0]*26`，遍历 `s` 把每个字符的频次记进对应下标。
2. 外层循环条件是 `len(res) < len(s)`，保证所有字符都被取完。
3. 每轮先 `for i in range(26)` 升序扫，`cnt[i] > 0` 就 `res.append(chr(97+i))` 并 `cnt[i] -= 1`。
4. 再 `for i in range(25, -1, -1)` 降序扫，同样条件同样操作。

以 `s = "aaaabbbbcccc"` 为例：初始 `cnt[0]=4, cnt[1]=4, cnt[2]=4`。第一轮升序扫出 `a,b,c`，此时 `cnt` 变成 `[3,3,3]`；紧接着降序扫出 `c,b,a`，`cnt` 变成 `[2,2,2]`，`res = "abccba"`。第二轮重复得到 `"abccbaabccba"`，与示例一致。

```python
cnt = [0] * 26
for ch in s:
    cnt[ord(ch) - 97] += 1
res = []
while len(res) < len(s):
    for i in range(26):
        if cnt[i] > 0:
            res.append(chr(97 + i))
            cnt[i] -= 1
    for i in range(25, -1, -1):
        if cnt[i] > 0:
            res.append(chr(97 + i))
            cnt[i] -= 1
return "".join(res)
```

关键点：升序扫和降序扫共用同一个 `cnt`，不需要真的从 `s` 里删除字符，也不需要每轮重新排序。

## 复杂度
时间：O(n + 26·轮数)，轮数 ≤ 26，实际是 O(n)，n 为 `s` 长度。
空间：O(26) 计数数组 + O(n) 结果串，字母表固定所以额外空间是常数级。

## 易错点
- 输入 `"rat"` 这类各字符只出现一次的情况 → 若把外层循环写成 `while max(cnt) > 0` 且降序扫时忘了 `cnt[i] > 0` 判断，会往 `res` 里塞空字符或重复字符 → 两个方向的内层循环都必须先判 `cnt[i] > 0` 再 append。
- 输入 `"aaaabbbbcccc"` → 若每轮只做升序扫、忘了降序扫，输出会变成 `"abcabcabcabc"` 而不是 `"abccbaabccba"` → 一轮必须包含升序 + 降序两段，且降序从 `range(25, -1, -1)` 开始，不能从 24 开始漏掉 `z`。

## 如果面试官追问
问：如果字符集不是小写字母而是任意 Unicode 呢？
答：把 26 换成 `sorted(set(s))` 得到有序去重列表，再按索引正反扫，复杂度变成 O(n + k log k)，k 为不同字符数。
