## 一句话思路
用 `dp[diff]` 记录「两支架高度差为 diff 时，较高支架的最大高度」，逐根钢筋做三选一转移。

## 怎么做
1. 状态定义：`dp` 是字典，键为两支架高度差 `diff`（左减右，可负），值为该差下**较高支架**的高度；初始 `dp = {0: 0}`。
2. 对每根 `r`，从旧 `dp` 生成新字典，每根钢筋三种去向：放高的一侧（差变大、高者加 `r`）、放矮的一侧（差缩小，可能翻转）、丢弃。
3. 翻转时用绝对值统一：新差 `nd = abs(diff ± r)`，新高 `nh` 按「谁变高」算，取 `max` 合并。
4. 答案取 `dp[0]`（差为 0 时两支架等高，值即高度），无解返回 0。

以 `[1,2,3,6]` 为例，处理到 `6` 时旧 `dp` 含 `{0:0, 1:1, 2:2, 3:3, 6:6, ...}`（由 `1,2,3` 组合出），把 `6` 放到差为 0 的矮侧得 `nd=6, nh=6`，放到差为 6 的矮侧得 `nd=0, nh=6`，于是 `dp[0]=6`。

```python
dp = {0: 0}
for r in rods:
    nd = dict(dp)                      # 丢弃
    for diff, hi in dp.items():
        # 放高侧：差变大，高者加 r
        k = diff + r
        nd[k] = max(nd.get(k, -1), hi + r)
        # 放矮侧：差可能翻转
        k2 = abs(diff - r)
        nh = hi if diff >= r else hi + (r - diff)
        nd[k2] = max(nd.get(k2, -1), nh)
    dp = nd
return dp.get(0, 0)
```

关键在 `nh`：`diff >= r` 时矮侧加完仍不反超，高者不变；否则矮侧反超，新高为 `hi + (r - diff)`。

## 复杂度
时间：O(n · S)，S 为 `sum(rods)`，每根钢筋遍历至多 2S+1 个差。
空间：O(S)，`dp` 字典最多存 2S+1 个键，另开一份 `nd` 同阶。

## 易错点
- 输入 `[1,2]`：若只写 `diff + r` 不写 `abs(diff - r)`，两根钢筋永远凑不出差 0，错答 0 之外还可能漏掉「矮侧反超」的合法组合；必须两种放置都枚举，翻转用 `abs`。
- 输入 `[1,2,3,6]`：若在遍历 `dp` 时直接原地改 `dp`，同一根钢筋会被重复使用（`6` 被加两次），错答 12；正确做法是每轮先 `nd = dict(dp)` 再写 `nd`，循环结束才 `dp = nd`。

## 如果面试官追问
问：要求输出具体是哪几根钢筋组成两支架，怎么改？
答：`dp` 值改存 `(高度, 选择路径)`，每步记录钢筋下标与去向，最后从 `dp[0]` 回溯。
