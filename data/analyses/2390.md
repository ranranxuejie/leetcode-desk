## 一句话思路
用栈从左到右扫：字母入栈，遇 `*` 弹栈顶，因为每个星号只吃掉它左边最近的那个未匹配字母。

## 怎么做
1. 建空列表 `st`，遍历 `s` 的每个字符 `ch`。
2. `ch != '*'` 就 `st.append(ch)`。
3. `ch == '*'` 就 `st.pop()`，题面保证此时栈非空。
4. 返回 `''.join(st)`。

以 `s = "leet**cod*e"` 为例，扫到第二个 `*`（下标 5）时，栈内是 `['l','e','e']`，`pop()` 掉的是下标 4 的 `'e'`，不是 `'t'`——`'t'` 已被第一个 `*` 弹走。继续扫 `cod` 后栈为 `['l','e','e','c','o','d']`，遇 `*` 弹出 `'d'`，再入 `'e'`，最终 `['l','e','c','o','e']`。

```python
st = []
for ch in s:
    if ch == '*':
        st.pop()
    else:
        st.append(ch)
return ''.join(st)
```

关键点：星号弹的是「当前栈顶」，而栈顶天然就是「左侧最近且尚未被删的字母」，所以不需要回退下标或记录位置。

## 复杂度
时间 O(n)：`s` 的每个字符进栈或触发一次 `pop`，各一次。
空间 O(n)：`st` 最坏存下全部字母（如 `s` 无星号时）。

## 易错点
- 输入 `s = "erase*****"` → 若用 `st.pop()` 前不判空，或误以为星号可能多于字母而加 `if st` 保护，会掩盖逻辑；本题保证可执行，直接 `pop()` 即可，但若改成「星号可能多余」的变体，`pop()` 会抛 `IndexError`，那时才需要判空。
- 输入 `s = "abc*"` → 若从右往左扫或误删「星号右侧」字符，会得到 `"abc"` 或 `"ab"`；正确是删左侧最近的 `'c'`，得 `"ab"`。方向必须是从左到右，因为星号只作用于它左边。

## 如果面试官追问
问：若星号可出现在任意位置且可能多于字母（不保证可执行），怎么改？
答：`pop()` 前加 `if st:`，多余星号直接忽略，其余不变。
