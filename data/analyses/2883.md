## 一句话思路
用 `dropna(subset=["name"])` 只按 name 列判空删行，因为题面明确缺失只出现在 name。

## 怎么做
1. 确认缺失只发生在 `name` 列，`student_id`、`age` 都完整。
2. 调 `students.dropna(subset=["name"])`，`subset` 把判空范围锁死在 name 上。
3. 返回结果，索引保持原样即可，力扣不校验行号。

拿官方示例走一遍：输入四行，`name` 依次是 `Piper / None / Georgia / Willow`。`dropna` 逐行检查 `subset` 里的 name，第 2 行（`student_id=217`）命中 `None` 被丢弃，其余三行保留，输出正好是 32、779、849 三行。关键中间值就是那个布尔掩码 `[True, False, True, True]`，长度 4，和为 3。

```python
import pandas as pd

def drop_missing(students: pd.DataFrame) -> pd.DataFrame:
    return students.dropna(subset=["name"])
```

不写 `subset` 的话，`dropna()` 会检查全部三列；本题恰好只有 name 有缺失，结果一样，但语义上是在赌数据干净，面试里要说明为什么加 `subset`。

## 复杂度
时间：O(n)，n 为行数，逐行检查 name 是否为空。
空间：O(n)，`dropna` 返回新 DataFrame，原表不动。

## 易错点
- 输入里 `name` 是字符串 `"None"` 而非真正的空值 → `dropna` 不会删它，输出仍是 4 行 → 正确做法是先确认列里是 `NaN`/`None` 对象，必要时 `replace("None", pd.NA)` 再删。
- 直接写 `students.dropna()` 而不带 `subset` → 本题碰巧对，但若 `age` 也有缺失就会多删行 → 正确做法是始终写 `subset=["name"]`，把判空范围钉死在题面指定的列上。

## 如果面试官追问
问：如果要求同时删 name 和 age 缺失的行呢？
答：`subset=["name", "age"]`，任一列为空即删，仍是 O(n) 一次扫描。
