## 一句话思路
先全选求和，再按余数删掉最小的 1 个或 2 个数，使总和能被 3 整除。

## 怎么做
1. 把 `nums` 按 `x % 3` 分成三组，只保留余 1 和余 2 两组各自最小的两个值（`r1`、`r2` 升序）。
2. 令 `total = sum(nums)`，看 `total % 3`：为 0 直接返回；为 1 删一个余 1 的数，或删两个余 2 的数；为 2 反之。
3. 两种删法取「删得少」的那个，即 `total - min(删法A, 删法B)`，删不动就返回 0。

以 `nums = [3,6,5,1,8]` 为例：`total = 23`，`23 % 3 = 2`。余 2 组是 `[5,8]`，删最小一个 5 得 18；余 1 组是 `[1]`，不够两个，此路不通。答案 18。

```python
total = sum(nums)
if total % 3 == 0:
    return total
r1 = sorted(x for x in nums if x % 3 == 1)[:2]
r2 = sorted(x for x in nums if x % 3 == 2)[:2]
if total % 3 == 1:
    cand = [sum(r1[:1]), sum(r2[:2])]
else:
    cand = [sum(r2[:1]), sum(r1[:2])]
cand = [c for c in cand if c > 0]  # 空列表 sum 为 0，需排除
return total - min(cand) if cand else 0
```

注意 `sum(r1[:2])` 在 `r1` 只有一个元素时只删一个，会算错，所以用 `c > 0` 过滤前要保证长度够：更稳的写法是 `len(r1) >= 1` 才收 `r1[0]`，`len(r2) >= 2` 才收 `r2[0]+r2[1]`。

## 复杂度
时间 O(n)：一次求和加一次分组扫描，排序只排常数个元素。
空间 O(1)：只存 `r1`、`r2` 各至多两个数。

## 易错点
- `nums = [4]`：`total = 4`，`4 % 3 = 1`，`r1` 为空、`r2` 为空，两种删法都不可行 → 若直接 `total - min(cand)` 会崩或返回 4，正确做法是返回 0。
- `nums = [2,2,2]`：`total = 6` 已整除，别再多删；而 `nums = [1,1,1,1]` 时 `total = 4`，删两个余 1 得 2，若误删一个余 1 得 3 也整除但更小，必须按「余 1 删 1 个或删 2 个余 2」的配对规则，不能随手删。

## 如果面试官追问
要求输出具体选了哪些数怎么办？答：分组时同时记下标，删数时按记录的下标从全集里剔除，剩下的下标即方案。
