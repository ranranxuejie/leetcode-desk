## 一句话思路
自顶向下 DFS 带一个「路径最大值」参数，节点值 ≥ 该最大值即计数并更新。

## 怎么做
1. 递归函数传 `(node, path_max)`，`path_max` 是根到当前节点父节点路径上的最大值。
2. 进入节点先判 `node.val >= path_max`，成立则计数加一，并令 `path_max = node.val`。
3. 用更新后的 `path_max` 递归左右子树，空节点直接返回。

以示例 1 `[3,1,4,3,null,1,5]` 为例：根 3 传入 `path_max = -inf`，`3 >= -inf` 计数 1，`path_max` 变 3；走到左子 1，`1 >= 3` 不成立，`path_max` 仍为 3；再走到 1 的左子 3，`3 >= 3` 成立（注意是 `>=` 不是 `>`），计数加一。

```python
def dfs(node, path_max):
    if not node:
        return 0
    good = 1 if node.val >= path_max else 0
    path_max = max(path_max, node.val)
    return good + dfs(node.left, path_max) + dfs(node.right, path_max)

return dfs(root, -2**31)
```

初始值取 `-2**31` 而不是 0，因为节点权值范围是 `[-10^4, 10^4]`，根节点值可能为负，用 0 会把负值根节点误判成非好节点。

## 复杂度
时间 O(n)：每个节点访问一次，n 为节点数。
空间 O(h)：递归栈深度为树高 h，最坏链状树 O(n)，未额外开数组。

## 易错点
- 输入 `[3,3,null,4,2]` 中节点 3 的右子 2：若把判断写成 `node.val > path_max`，节点 3（值等于父节点 3）会被漏计，示例 2 应输出 3 却得 2；正确用 `>=`，因为「没有任何节点大于 X」允许相等。
- 输入 `[-1,-2,-3]` 这类全负树：若初始 `path_max` 写成 0，根节点 -1 判 `-1 >= 0` 失败，答案从 3 错成 0；正确初始值取 `-2**31` 或 `float('-inf')`。

## 如果面试官追问
若节点数涨到 10^7 递归会爆栈怎么办？改成显式栈迭代，栈里存 `(node, path_max)` 元组，逻辑不变。
