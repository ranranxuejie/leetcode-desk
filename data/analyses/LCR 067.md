## 一句话思路
按位从高到低贪心，用前缀集合判断当前候选答案能否由两个数异或得到。

## 怎么做
1. 从第 30 位枚举到第 0 位（`nums[i] <= 2**31 - 1`，最高有效位是 30），维护已确定的高位答案 `ans`。
2. 每轮先假设当前位能取 1，得到 `cand = ans | (1 << b)`，把所有数的「高 b 位前缀」放进集合 `pre`。
3. 检查是否存在 `p` 使 `p ^ cand` 也在 `pre` 中——存在就说明 `cand` 可达，`ans = cand`；否则该位只能为 0。
4. 返回 `ans`。

以 `nums = [3,10,5,25,2,8]` 为例，处理到第 4 位（值 16）时，前缀集合含 `{0, 0, 0, 1, 0, 0}`（即 25 的前缀为 1，其余为 0），`cand = 16`，检查 `1 ^ 16 = 17` 不在集合、`0 ^ 16 = 16` 不在集合，故第 4 位判 0；继续到低位最终拼出 28（5 与 25 的异或）。

```python
ans = 0
for b in range(30, -1, -1):
    ans <<= 1
    pre = {x >> b for x in nums}
    cand = ans | 1
    if any((p ^ cand) in pre for p in pre):
        ans = cand
```

注意 `ans <<= 1` 要在判位前做，这样 `ans` 始终是「已确定高位 + 当前位待定」的形态；`pre` 里存的是 `x >> b`，即包含当前位在内的前缀。

## 复杂度
时间 O(31n)：31 次位枚举，每次遍历 n 个数建集合。
空间 O(n)：每轮集合最多存 n 个前缀，与位宽无关。

## 易错点
- 输入 `nums = [0]` 或全相同元素 → 若把 `i < j` 当硬约束去重，会漏掉 `i == j` 的合法情况；题面允许 `i <= j`，`0 XOR 0 = 0` 应正常返回 0，不要特判跳过。
- 输入含 `2**31 - 1`（如 `[2**31 - 1, 0]`）→ 若位枚举从 31 开始，`x >> 31` 全为 0，会多算一位高位导致答案偏大；正确上界是 30，因为 `2**31 - 1` 的最高位就是第 30 位。

## 如果面试官追问
问：要求返回具体是哪两个下标怎么办？
答：判位时把前缀映射到任一原下标，命中 `p ^ cand` 时同时取出两个下标即可，空间多存一个 dict。
