## 一句话思路
按 x 扫描，用线段树维护当前被覆盖的 y 总长，逐段累加 `覆盖y长 × dx`。

## 怎么做
1. 把所有 `x1`、`x2` 收集成事件：`(x, y1, y2, +1/-1)`，按 x 排序。
2. 对 y 坐标离散化，线段树每个叶子代表一段 `ys[i]~ys[i+1]`，节点存 `cover`（被完整覆盖次数）和 `length`（有效覆盖长度）。
3. 相邻事件之间，若 `cover[1] > 0` 则整段有效，否则由子节点合并；面积累加 `length[1] * (x_next - x)`。

以示例 1 为例，事件排序后 x 依次为 0,1,2,3。x=1 时三个矩形都进入，`ys=[0,1,2,3]`，`length[1]=3`，这一段 `dx=1` 贡献 3；x=2 时绿色矩形退出，`length[1]=2`，`dx=1` 贡献 2；x=3 时只剩蓝色，贡献 1，合计 6。

```python
events = []
ys = []
for x1, y1, x2, y2 in rectangles:
    events.append((x1, y1, y2, 1))
    events.append((x2, y1, y2, -1))
    ys += [y1, y2]
ys = sorted(set(ys))
idx = {v: i for i, v in enumerate(ys)}
events.sort()
area = 0
for i in range(len(events) - 1):
    x, y1, y2, d = events[i]
    update(1, 0, len(ys) - 1, idx[y1], idx[y2] - 1, d)
    dx = events[i + 1][0] - x
    area += length[1] * dx
return area % (10**9 + 7)
```

## 复杂度
时间：O(n log n)，n 为矩形数，事件排序与每次线段树更新各贡献 log n。
空间：O(n)，存 2n 个事件和 2n 个 y 坐标。

## 易错点
- 输入 `[[0,0,2,2],[1,0,2,3],[1,0,3,1]]` 中 x=2 处两个矩形同时退出，若先算面积再更新会漏掉或重复一段；正确做法是先用 `events[i]` 更新再取 `events[i+1][0]-x` 作 dx。
- 单个矩形 `[[0,0,10**9,10**9]]` 面积 10^18，Python 不会溢出但必须最后 `% (10**9+7)`；若中途取模再比较 `cover` 会错，取模只放在返回处。

## 如果面试官追问
若矩形数涨到 10^5 怎么办？答：扫描线不变，线段树已是 O(n log n)，只需把事件数组换成流式读入避免存全量。
