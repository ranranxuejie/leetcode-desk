## 一句话思路
沿「更有钱 → 更穷」的边做记忆化 DFS，把每个人所有祖先里 quiet 最小的编号传下来。

## 怎么做
1. 建图：`richer[i] = [a, b]` 表示 a 比 b 有钱，边方向取 `a -> b`，`graph[a].append(b)`。
2. 对每个 `x` 做 DFS，返回「x 及其所有更有钱的人中 quiet 最小的编号」，用 `memo` 缓存。
3. 递归式：先令 `best = x`，再对每个祖先 `u` 取 `cand = dfs(u)`，若 `quiet[cand] < quiet[best]` 则更新 `best`。
4. 对 `range(n)` 逐个调用 `dfs`，结果填进 `answer`。

用示例 1 看关键中间值：`dfs(0)` 沿 `1->0` 进入 `dfs(1)`，再沿 `2->1`、`3->1` 进入 `dfs(3)`，`dfs(3)` 的祖先有 4、5、6，其中 `quiet[5]=1` 最小，故 `dfs(3)=5`；回到 `dfs(1)` 比较 `quiet[2]=5`、`quiet[5]=1`，得 `dfs(1)=5`；最终 `answer[0]=5`。

```python
def dfs(x):
    if memo[x] != -1:
        return memo[x]
    best = x
    for u in graph[x]:          # u 比 x 更有钱
        cand = dfs(u)
        if quiet[cand] < quiet[best]:
            best = cand
    memo[x] = best
    return best

memo = [-1] * n
answer = [dfs(x) for x in range(n)]
```

注意边方向别写反：`graph[x]` 里存的是「比 x 有钱的人」，DFS 才是往上游走。

## 复杂度
时间 O(n + m)，m 为 `richer` 长度，每条边只被 DFS 走一次。
空间 O(n + m)，`graph` 存 m 条边，`memo` 与递归栈各 O(n)。

## 易错点
1. 边方向写反成 `graph[b].append(a)` 后从 x 往下游搜，示例 1 中 `dfs(7)` 会返回 7 而 `dfs(0)` 搜不到 5，输出错成 `[0,1,2,3,4,5,6,7]` 一类结果；正确做法是 `graph[a].append(b)`，让 DFS 从穷往富走。
2. 不加 `memo` 直接递归，示例 1 里 `dfs(1)` 会被 0、2、3 三条路径重复展开，链长时退化成指数级；正确做法是 `memo[x]` 命中即返回，且只在 DFS 结束后写入。

## 如果面试官追问
若 n 放大到 10^5 且 richer 是 DAG，递归会爆栈怎么办？答：改成按入度做拓扑排序，从最有钱的人开始把 `best` 往下推。
