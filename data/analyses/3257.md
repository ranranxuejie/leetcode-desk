## 一句话思路
三车互不攻击等价于三行三列互不相同，枚举中间车所在行，用上下各取「不同列的最大值」拼出答案。

## 怎么做
1. 预处理 `top[i][j]`：第 `i` 行及以上、列不等于 `j` 的最大值；`bot[i][j]` 同理向下。
2. 枚举中间车位置 `(i, j)`，则第一车在 `top[i-1][j]`、第三车在 `bot[i+1][j]`，三者列都避开 `j`。
3. 但上下两车列可能相同，需再按列拆：对每行只保留前三大值，枚举上下列组合。
4. 取所有组合的最大和。

以示例 1 为例，`board = [[-3,1,1,1],[-3,1,-3,1],[-3,2,1,1]]`，中间行取 `i=1`、`j=3`（值 1），上方 `top[0][3]` 在列 0..2 中最大为 1（列 1 或 2），下方 `bot[2][3]` 在列 0..2 中最大为 2（列 1），但列 1 已被上方占用，改取列 2 的 1，总和 `1+1+1=3`；换 `j=1` 时上取列 2 的 1、下取列 2 冲突，实际最优是 `(0,2)+(1,3)+(2,1)=1+1+2=4`。

```python
# 每行取前三大值 (值, 列)，用于上下组合
def top3(row):
    return sorted(((v, c) for c, v in enumerate(row)), reverse=True)[:3]

# 枚举中间行 i、中间列 j，上下各取一个不同列
ans = -10**18
for i in range(1, m - 1):
    up, down = top3(board[i - 1]), top3(board[i + 1])
    for j in range(n):
        for vu, cu in up:
            for vd, cd in down:
                if cu != j and cd != j and cu != cd:
                    ans = max(ans, vu + board[i][j] + vd)
```

## 复杂度
时间：O(m·n·3·3)，即 O(mn)，每格只试 9 种上下组合。
空间：O(1) 额外，只存每行前三大值。

## 易错点
- 只取「全局上下最大值」而不按列去重：如示例 1 中 `i=1, j=1` 时上下最大值都在列 2，直接相加会重复用列 2，得到错误值；必须检查 `cu != cd`。
- 中间行取 `i=0` 或 `i=m-1`：此时没有上方或下方车，`top3` 越界或返回空，答案被算成两车之和；循环必须从 `1` 到 `m-2`。

## 如果面试官追问
问：若要求输出三车坐标而非和？答：在 `ans` 更新处同时记录 `(i, j, cu, cd)` 四个下标，最后按行还原坐标即可。
