## 一句话思路
用哈希表把「原节点 → 新节点」一一映射，两遍扫描分别接 `next` 和 `random`，因为 `random` 可能指向还没创建的节点。

## 怎么做
1. 第一遍遍历原链表，为每个节点 `cur` 新建 `Node(cur.val)`，存进 `mp[cur] = 新节点`。
2. 第二遍再遍历，用 `mp[cur].next = mp[cur.next]` 和 `mp[cur].random = mp[cur.random]` 接指针。
3. 空指针要单独处理：`mp.get(None)` 返回 `None`，正好让 `random` 为 `null` 的节点接上 `None`。

拿示例 1 的 `[[7,null],[13,0],[11,4],[10,2],[1,0]]` 说：第一遍建完后 `mp` 有 5 个键值对；第二遍处理到值为 `13` 的节点时，`cur.random` 是值为 `7` 的头节点，`mp[cur.random]` 直接取到新建的 `7` 节点，`random` 就接对了，而不是接到原链表的 `7` 上。

```python
mp = {}
cur = head
while cur:
    mp[cur] = Node(cur.val)
    cur = cur.next
cur = head
while cur:
    mp[cur].next = mp.get(cur.next)
    mp[cur].random = mp.get(cur.random)
    cur = cur.next
return mp.get(head)
```

关键在 `mp.get(cur.next)`：`cur.next` 为 `None` 时返回 `None`，省掉判空分支。

## 复杂度
时间：O(n)，两遍遍历各 O(n)，哈希表查询 O(1)。
空间：O(n)，`mp` 存 n 个原节点到新节点的映射，外加 n 个新节点本身。

## 易错点
- 输入 `head = []` → 若直接写 `mp[head]` 会 `KeyError`，或返回 `mp[head]` 而非 `None` → 正确做法是返回 `mp.get(head)`，空表自然得到 `None`。
- 示例 3 的 `[[3,null],[3,0],[3,null]]` 三个节点值都是 `3` → 若用 `val` 当哈希键，`mp[3]` 会被覆盖成同一个新节点，`random` 全指错 → 必须用节点对象本身（`cur`）当键，值相同也不冲突。

## 如果面试官追问
问：不额外开哈希表能做到 O(1) 空间吗？
答：可以，把新节点插到原节点后面（`A→A'→B→B'`），用 `cur.next.random = cur.random.next` 接 `random`，最后拆成两条链。
