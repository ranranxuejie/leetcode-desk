## 一句话思路
从右往左扫，维护「后缀已排序」的边界：只要 `nums[i]` 不小于后缀最大值，`i` 就可能是答案，再用前缀相等条件筛。

## 怎么做
1. 先判断 `i = n-1` 之外的前缀：排序只动 `nums[i..]`，所以 `nums[0..i-1]` 必须逐位等于 `target[0..i-1]`，用一次从左到右的比对记录第一个失配位置 `first_bad`。
2. 从右往左扫，维护 `suf_max = max(nums[i..n-1])`；后缀按非递增排序后，其首元素就是 `suf_max`，所以 `target[i]` 必须等于 `suf_max`。
3. 同时后缀排序结果必须等于 `target[i..]`，等价于 `nums[i..]` 与 `target[i..]` 的多重集合相同且 `target[i..]` 本身非递增——用「`target` 后缀非递增」+「`nums` 后缀计数等于 `target` 后缀计数」两个条件维护。
4. 对每个 `i`，若 `i <= first_bad`（前缀全等）且上述后缀条件成立，答案加一。

以示例 2 `nums = [1,5,6,4,6]`, `target = [1,5,6,6,4]` 为例：`first_bad = 3`（`nums[3]=4 != target[3]=6`）。从右扫：`i=4` 时 `suf_max=6`，但 `target[4]=4 != 6`，不成立；`i=3` 时 `suf_max=6`，`target[3]=6` 成立，且 `i=3 <= first_bad=3`，计数；`i=2` 时 `suf_max=6`，`target[2]=6` 成立且 `2 <= 3`，计数；`i=1` 时 `suf_max=6`，`target[1]=5 != 6`，停。答案 2。

```python
from collections import Counter
n = len(nums)
first_bad = n
for k in range(n):
    if nums[k] != target[k]:
        first_bad = k
        break
ans = 0
suf_max = -1
cnt_n, cnt_t = Counter(), Counter()
for i in range(n - 1, -1, -1):
    suf_max = max(suf_max, nums[i])
    cnt_n[nums[i]] += 1
    cnt_t[target[i]] += 1
    if i <= first_bad and target[i] == suf_max and cnt_n == cnt_t:
        ans += 1
```

## 复杂度
时间：O(n)，一次前缀比对加一次反向扫描，`Counter` 比较摊还 O(1)（值域 10^5）。
空间：O(n)，两个 `Counter` 存后缀频次，最坏各 10^5 个键。

## 易错点
- `nums = [1,2,3]`, `target = [3,2,1]`：若只查 `target[i] == suf_max` 就计数，`i=0` 时 `suf_max=3` 成立，但 `i=1` 时 `suf_max=3`、`target[1]=2` 不成立——正确做法是同时要求 `i <= first_bad`，本例 `first_bad=0`，只有 `i=0` 通过。
- `nums = [7,6,8]`, `target = [8,6,7]`：`i=0` 时 `suf_max=8 == target[0]`，但 `cnt_n` 是 `{7:1,6:1,8:1}`、`cnt_t` 是 `{8:1,6:1,7:1}` 相等，会误判；实际排序后是 `[8,7,6] != target`，正确做法是额外要求 `target[i..]` 非递增（本例 `target[1]=6 < target[2]=7` 破坏），或直接比较排序结果。

## 如果面试官追问
若 n 扩到 10^6 且值域更大？答：把 `Counter` 换成「失配计数」变量，只在 `nums[i] != target[i]` 时增减，避免哈希开销。
