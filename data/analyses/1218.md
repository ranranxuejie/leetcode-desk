## 一句话思路
用哈希表 `dp[x]` 记录以值 `x` 结尾的最长定差子序列长度，遍历时查 `dp[x - difference]` 转移。

## 怎么做
1. 建字典 `dp`，键是元素值，值是以该值结尾的最长长度。
2. 遍历 `arr` 的每个 `x`，先算 `dp[x] = dp.get(x - difference, 0) + 1`。
3. 用 `best` 记录遍历过程中的最大值，最后返回 `best`。

以示例 3 `arr = [1,5,7,8,5,3,4,2,1], difference = -2` 为例：处理到 `x = 3` 时，`dp[3 - (-2)] = dp[5]`，此时 `dp[5]` 已经是 2（来自 `[7,5]`），于是 `dp[3] = 3`；再处理第二个 `1` 时 `dp[1] = dp[3] + 1 = 4`，得到答案。

```python
dp = {}
best = 0
for x in arr:
    dp[x] = dp.get(x - difference, 0) + 1
    if dp[x] > best:
        best = dp[x]
return best
```

关键点：`dp` 的键是**值**不是下标，所以重复元素（示例 3 里的两个 `5`、两个 `1`）会自然覆盖成更长的链，不需要额外处理。

## 复杂度
时间 O(n)：遍历 `arr` 一次，每次字典查询均摊 O(1)。
空间 O(n)：`dp` 最多存 n 个不同值。

## 易错点
- 示例 3 中 `5` 出现两次：若用下标做 DP 状态（`dp[i]` 表示以 `i` 结尾），第二个 `5` 会漏掉「`7→5`」这条链，答案错成 3；正确做法是让 `dp` 以值为键，后出现的 `5` 直接覆盖为更长值。
- `difference` 为负（如 -2）时，若把转移写成 `dp.get(x + difference)` 而非 `x - difference`，示例 3 会退化成 1；统一写 `x - difference`，负差自动成立。

## 如果面试官追问
问：要求返回具体子序列而不只是长度？答：`dp` 值改存 `(长度, 前驱值)`，最后从 `best` 对应值沿前驱回溯即可。
