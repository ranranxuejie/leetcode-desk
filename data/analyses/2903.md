## 一句话思路
固定 j 往前看 i ≤ j - indexDifference，只需维护前缀最小值和最大值，差值够大就命中。

## 怎么做
1. 令 j 从 indexDifference 遍历到 n-1，此时 i = j - indexDifference 才刚满足下标差。
2. 维护 `min_i`、`max_i` 记录 [0, j - indexDifference] 内的最小值和最大值及其下标。
3. 若 `nums[j] - min_i >= valueDifference` 或 `max_i - nums[j] >= valueDifference`，返回对应下标对。
4. 遍历结束返回 `[-1, -1]`。

以示例 1 `nums = [5,1,4,1]`、`indexDifference = 2`、`valueDifference = 4` 为例：j=2 时把 i=0 纳入，`min_i = max_i = 5`；`nums[2]=4`，`5-4=1 < 4`，不命中。j=3 时纳入 i=1，`min_i = 1`（下标 1），`max_i = 5`（下标 0）；`nums[3]=1`，`5-1=4 >= 4`，返回 `[0,3]`。

```python
n = len(nums)
min_i = max_i = nums[0]
min_idx = max_idx = 0
for j in range(indexDifference, n):
    k = j - indexDifference
    if nums[k] < min_i:
        min_i, min_idx = nums[k], k
    if nums[k] > max_i:
        max_i, max_idx = nums[k], k
    if nums[j] - min_i >= valueDifference:
        return [min_idx, j]
    if max_i - nums[j] >= valueDifference:
        return [max_idx, j]
return [-1, -1]
```

关键点：纳入 i 的时机是 `k = j - indexDifference`，保证 `abs(i-j) >= indexDifference` 恒成立，无需再判下标。

## 复杂度
时间 O(n)：j 单趟扫描，每个下标只纳入一次。
空间 O(1)：只开 min_i/max_i/min_idx/max_idx 四个变量。

## 易错点
- `indexDifference = 0` 且 `valueDifference = 0`（示例 2）→ 若循环从 `j = indexDifference + 1` 起，会漏掉 `[0,0]` → 循环必须从 `j = indexDifference` 开始，此时 k=0 先纳入自身，`nums[0]-nums[0]=0 >= 0` 立即命中。
- `indexDifference > n-1`（如 n=3、indexDifference=5）→ 若先访问 `nums[k]` 再判边界会越界 → 循环条件 `range(indexDifference, n)` 为空，直接落到 `return [-1, -1]`，不要提前取 `nums[0]` 之外的 k。

## 如果面试官追问
若 n 放大到 10^5 并要求返回所有合法下标对，怎么办？
答：仍用前缀 min/max 单趟 O(n)，但只返回一组；要全部则需按值域 0..50 分桶记录最早下标，复杂度 O(n + 51)。
