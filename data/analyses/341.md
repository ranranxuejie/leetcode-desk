## 一句话思路
用栈存待处理的元素，`hasNext` 时把栈顶的列表就地展开压回栈，保证栈顶永远是整数。

## 怎么做
1. 初始化时把 `nestedList` 逆序压栈，使栈顶是第一个元素。
2. `hasNext` 循环：栈非空且栈顶是列表，就弹出它、逆序压入它的所有元素，直到栈顶是整数或栈空。
3. `next` 先调一次 `hasNext` 兜底，再 `pop` 栈顶整数返回。

以 `[1,[4,[6]]]` 为例：初始栈（栈顶在右）为 `[6的列表, 4的列表, 1]` 的逆序压法，实际栈顶是 `1`。第一次 `hasNext` 直接返回 `True`，`next` 弹出 `1`。第二次 `hasNext` 发现栈顶是 `[4,[6]]`，弹出后逆序压入 `[6]` 和 `4`，此时栈顶变 `4`，返回 `True`。第三次 `hasNext` 弹出 `[6]` 压入 `6`，栈顶为 `6`。最终输出 `[1,4,6]`。

```python
def __init__(self, nestedList):
    self.stack = nestedList[::-1]

def hasNext(self):
    while self.stack and not isinstance(self.stack[-1], int):
        top = self.stack.pop()
        self.stack.extend(top[::-1])
    return bool(self.stack)

def next(self):
    self.hasNext()
    return self.stack.pop()
```

关键点：`extend(top[::-1])` 而不是 `extend(top)`，否则 `[1,1]` 展开后栈顶变成第二个 `1`，输出顺序反了。

## 复杂度
时间：每个元素最多入栈出栈各一次，均摊 O(n)，n 为扁平化后整数总数。
空间：栈最多存 O(n) 个元素，嵌套深度 d 时额外递归栈为 O(d)。

## 易错点
- 输入 `[[1,1],2,[1,1]]` → 若用 `extend(top)` 正序压入，`[1,1]` 展开后栈顶是第二个 `1`，输出变成 `[1,1,2,1,1]` 中前两个 `1` 顺序颠倒 → 必须 `extend(top[::-1])`。
- 输入 `[[]]` 或 `[[],[1]]` → 若 `hasNext` 只判断 `stack` 非空而不循环展开，空列表 `[]` 会让 `hasNext` 返回 `True` 但 `next` 弹出列表而非整数 → 必须用 `while` 循环展开到栈顶为 `int` 或栈空。

## 如果面试官追问
如果要求 `next` 严格 O(1) 而 `hasNext` 可以慢，怎么改？
答：初始化时一次性 DFS 全展开成数组，`next` 用下标自增，`hasNext` 比较下标与长度。
