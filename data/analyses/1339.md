## 一句话思路
先求整棵树总和 S，再 DFS 求每个子树和 sub，取 sub×(S−sub) 的最大值。

## 怎么做
1. 一次后序 DFS 求出每个节点的子树和，同时把整棵树总和记为 `total`。
2. 遍历过程中把每个非根节点的子树和 `sub` 收集起来（根节点不能删，删了没有意义）。
3. 对每个 `sub` 算 `sub * (total - sub)`，取最大值，最后对 `10**9 + 7` 取模。

以示例 1 `root = [1,2,3,4,5,6]` 为例：`total = 21`。节点 2 的子树和是 `2+4+5 = 11`，节点 3 的子树和是 `3+6 = 9`。候选乘积有 `11*(21-11)=110`、`9*(21-9)=108`、`4*17=68`……最大值是 110，与输出一致。

```python
def dfs(node):
    if not node:
        return 0
    s = node.val + dfs(node.left) + dfs(node.right)
    if node is not root:
        subs.append(s)
    return s

total = dfs(root)
best = max(s * (total - s) for s in subs)
return best % (10**9 + 7)
```

关键点：`subs` 里存的是「删掉这条边后，下方那棵子树的节点和」，上方那棵的和永远是 `total - sub`，所以不用真的去删边。

## 复杂度
时间 O(n)：每个节点访问一次，`max` 再扫一遍 `subs`（最多 n−1 个）。
空间 O(n)：递归栈最坏 n 层，`subs` 存 n−1 个整数。

## 易错点
- 把根节点也放进 `subs`：示例 4 `root = [1,1]` 会算出 `2*(2-2)=0`，正确是删掉一条边得 `1*1=1`。必须用 `node is not root` 排除根。
- 先取模再比较大小：示例 3 的 `total = 65`，若某个 `sub*(total-sub)` 超过 `10**9+7`，先取模会让大小关系错乱，选出错误的边。正确做法是全程用原始整数比较，只在 `return` 时取模一次。

## 如果面试官追问
问：节点值允许为负怎么办？
答：`sub*(total-sub)` 不再单调，不能只靠遍历所有 sub 取 max 的直觉，但仍需枚举全部 n−1 种切法，O(n) 不变，只是不能提前剪枝。
