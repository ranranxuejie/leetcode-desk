## 一句话思路
按空格切词，对每个词先判首字符是否字母，再判是否含 `-` 分段，逐段做 `upper()+lower()` 拼接。

## 怎么做
1. 用 `content_text.split(' ')` 切词（不能用默认 `split()`，否则连续空格会被吞掉，空格格式必须原样保留）。
2. 对每个词 `w`：若 `not w[0].isalpha()`，原样返回。
3. 否则按 `-` 拆成 `parts`，若 `len(parts) >= 2` 且每段都非空，则每段 `p[0].upper() + p[1:].lower()` 再用 `-` 拼回。
4. 否则整词 `w[0].upper() + w[1:].lower()`，最后 `' '.join(...)`。

以 `"QUICK-brown"` 为例：`parts = ["QUICK", "brown"]`，两段都非空，得到 `"Quick"` 和 `"Brown"`，拼成 `"Quick-Brown"`。注意 `w[1:].lower()` 只降英文字母，`\ @ / ^ ,` 这些特殊字符 `lower()` 不动，正好符合「特殊字符保持不变」。

```python
def conv(w):
    if not w[0].isalpha():
        return w
    parts = w.split('-')
    if len(parts) >= 2 and all(parts):
        return '-'.join(p[0].upper() + p[1:].lower() for p in parts)
    return w[0].upper() + w[1:].lower()

converted = ' '.join(conv(w) for w in content_text.split(' '))
```

## 复杂度
时间 O(n)，n 为 `content_text` 总字符数，每个字符被 `lower()` 扫常数次。
空间 O(n)，`split` 出的词列表和结果串各占一份。

## 易错点
- 输入 `"a  b"`（两个空格）→ 用 `split()` 会得到 `["a","b"]`，输出变 `"A B"` 丢了一个空格 → 必须 `split(' ')` 再 `join(' ')`，空串词走 `w[0]` 会崩，需先判 `if not w: return w`。
- 输入 `"a-b-c"` 或 `"-abc"` → 前者三段合法应转 `"A-B-C"`，后者 `parts = ["", "abc"]` 有空段，按规则不算「两个非空部分」→ 必须加 `all(parts)` 守卫，否则 `p[0]` 对空串抛 `IndexError`。

## 如果面试官追问
问：若文本含连续多个连字符 `"a--b"` 怎么处理？答：`parts` 出现空段，`all(parts)` 为假，退回整词规则，只大写首字母得 `"A--b"`。
