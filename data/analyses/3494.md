## 一句话思路
按药水顺序递推每瓶的开工时间，用前缀和 O(1) 算出「巫师 i 空闲」这一约束，取所有约束的最大值。

## 怎么做
1. 记 `pre[i] = skill[0]+...+skill[i-1]`（`pre[0]=0`），则药水 j 在巫师 i 上处理完的绝对时刻是 `start[j] + pre[i+1]*mana[j]`。
2. 药水 j 的开工时间 `start[j]` 必须同时满足：巫师 i 处理完药水 j-1 之后才能接 j，即 `start[j] + pre[i]*mana[j] >= start[j-1] + pre[i+1]*mana[j-1]`。
3. 移项得 `start[j] >= start[j-1] + pre[i+1]*mana[j-1] - pre[i]*mana[j]`，对 i 取 max，再与 `start[j-1]` 取 max（同一巫师不能并行）。
4. 答案 = `start[m-1] + pre[n]*mana[m-1]`。

用示例 1 的 `skill=[1,5,2,4], mana=[5,1,4,2]`：`pre=[0,1,6,8,12]`，`start[0]=0`。算 `start[1]` 时 i=3 给出 `0 + 12*5 - 8*1 = 52`，是四个约束里最大的，所以 `start[1]=52`，与官方表格一致。

```python
pre = [0] * (n + 1)
for i in range(n):
    pre[i + 1] = pre[i] + skill[i]
start = 0
for j in range(1, m):
    best = start
    for i in range(n):
        cand = start + pre[i + 1] * mana[j - 1] - pre[i] * mana[j]
        best = max(best, cand)
    start = best
return start + pre[n] * mana[m - 1]
```

## 复杂度
时间 O(n·m)：外层 m 瓶药水，内层 n 个巫师各算一次约束。
空间 O(n)：只开了长度 n+1 的前缀和数组 `pre`。

## 易错点
- 只取 `i = n-1`（最后一个巫师）的约束 → 示例 1 会得 60 而非 52，因为瓶颈可能出现在中间巫师，必须对全部 i 取 max。
- 忘记 `best` 初值取 `start`（即 `start[j] >= start[j-1]`）→ 当 `mana` 递减时算出比上一瓶还早的开工时间，实际同一巫师无法并行处理两瓶。

## 如果面试官追问
若 n、m 都放大到 10^5 怎么办？答：约束式对 i 是线性的，可把 `pre[i+1]*mana[j-1] - pre[i]*mana[j]` 拆成 `mana[j-1]*pre[i+1] - mana[j]*pre[i]`，用凸包/斜率优化把每瓶的 max 降到 O(log n)。
