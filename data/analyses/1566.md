## 一句话思路
枚举每个起点 i，把 arr[i:i+m] 与 arr[i+m:i+2m]…逐段比对，连续相等段数达到 k 即返回 True。

## 怎么做
1. 起点 i 只需枚举到 `len(arr) - m*k`，再往后放不下 k 段。
2. 对每个 i，用 `cnt = 1` 记录当前已连续重复的段数，从 `j = i + m` 开始逐段比对。
3. 若 `arr[j:j+m] == arr[i:i+m]` 则 `cnt += 1`，否则立即 break；`cnt == k` 时返回 True。
4. 全部起点失败返回 False。

以示例 2 `arr = [1,2,1,2,1,1,1,3], m = 2, k = 2` 为例：`i = 0` 时模式是 `arr[0:2] = [1,2]`，`j = 2` 处 `arr[2:4] = [1,2]` 相等，`cnt` 从 1 变 2，命中返回 True。注意 `i = 4` 时模式 `[1,1]`，`j = 6` 处 `arr[6:8] = [1,3]` 不等，`cnt` 停在 1，break。

```python
n = len(arr)
for i in range(n - m * k + 1):
    cnt = 1
    j = i + m
    while j + m <= n and arr[j:j + m] == arr[i:i + m]:
        cnt += 1
        if cnt == k:
            return True
        j += m
return False
```

关键点：比对基准始终是 `arr[i:i+m]`，不是上一段，这样才保证「同一个模式」连续重复；`j` 每次跳 `m` 而不是 1，天然不重叠。

## 复杂度
时间 O(n·m·k)：n 个起点，每段切片比较 O(m)，最多比 k 段。
空间 O(m)：切片 `arr[i:i+m]` 与 `arr[j:j+m]` 各开一个长度 m 的临时列表。

## 易错点
- 输入 `arr = [2,2,2,2], m = 2, k = 3` → 若按「相邻两元素相等就计数」会误判 True → 正确做法是整段切片比对，此例只有 `[2,2]` 重复 2 次，返回 False。
- 输入 `arr = [1,2,1,2,1,3], m = 2, k = 3` → 若起点枚举到 `n-m` 且不检查剩余长度，会在 `i=4` 处越界或错配 → 正确做法是 `range(n - m*k + 1)`，此例上界为 1，只试 `i=0`，返回 False。

## 如果面试官追问
问：n 放大到 10^5 怎么办？答：用滚动哈希把每段 m 长窗口压成整数，O(n) 内比较相邻窗口是否相等，再数连续相等段数。
