## 一句话思路
快慢指针先判环并相遇，再让一个指针回到 head，两指针同速走，相遇点即环入口。

## 怎么做
1. 初始化 `slow = fast = head`，`fast` 每步走两格、`slow` 走一格，直到 `fast is None or fast.next is None`（无环）或 `slow is fast`（相遇）。
2. 相遇后令 `slow = head`，`fast` 留在相遇点，两指针都每次走一格。
3. 再次 `slow is fast` 时返回 `slow`，即环入口。

以 `head = [3,2,0,-4], pos = 1` 为例：节点依次为 3→2→0→-4→2。`slow` 走 3→2→0，`fast` 走 3→0→2→-4→0，第 3 步后两者在节点 `0` 相遇。此时把 `slow` 拉回 `3`，`fast` 停在 `0`；下一步 `slow` 到 `2`、`fast` 到 `-4`，再下一步两者都到 `2`，返回节点 `2`（索引 1），与输出一致。

```python
slow = fast = head
while fast and fast.next:
    slow, fast = slow.next, fast.next.next
    if slow is fast:
        slow = head
        while slow is not fast:
            slow, fast = slow.next, fast.next
        return slow
return None
```

关键中间值：相遇点是 `0`（不是入口 `2`），所以必须走第二段，不能直接返回相遇点。

## 复杂度
时间 O(n)：`fast` 最多走 2n 步，第二段最多再走 n 步。
空间 O(1)：只用了 `slow`、`fast` 两个指针，没开哈希表。

## 易错点
- 输入 `head = [1], pos = -1` → 若循环条件只写 `while fast:`，`fast.next.next` 会对 `None` 取属性抛 `AttributeError` → 必须写成 `while fast and fast.next:`，让单节点无环直接返回 `None`。
- 输入 `head = [3,2,0,-4], pos = 1` → 若在第一次相遇（节点 `0`）就 `return slow`，会错答索引 2 → 相遇点不等于入口，必须重置 `slow = head` 后再同步走一轮。

## 如果面试官追问
问：不允许改链表，但允许 O(n) 空间怎么做？
答：用 `set` 存已访问节点 id，第一个重复出现的节点就是入口，时间 O(n)、空间 O(n)。
