## 一句话思路
二维前缀和：先建 (m+1)×(n+1) 的 `pre`，再用四个角一次算出每个窗口的和。

## 怎么做
1. 建 `pre`，`pre[i+1][j+1] = mat[i][j] + pre[i][j+1] + pre[i+1][j] - pre[i][j]`。
2. 对每个 `(i,j)` 把窗口裁剪到矩阵内：`r1=max(0,i-k), r2=min(m-1,i+k)`，列同理。
3. 用 `pre[r2+1][c2+1] - pre[r1][c2+1] - pre[r2+1][c1] + pre[r1][c1]` 填 `answer[i][j]`。

以示例 1 的 `(0,0)`、`k=1` 为例：窗口裁剪后是 `r1=0,r2=1,c1=0,c2=1`，即左上 2×2 块，`pre` 四角算出 `1+2+4+5=12`，与输出首元素一致。

```python
m, n = len(mat), len(mat[0])
pre = [[0] * (n + 1) for _ in range(m + 1)]
for i in range(m):
    for j in range(n):
        pre[i+1][j+1] = mat[i][j] + pre[i][j+1] + pre[i+1][j] - pre[i][j]

ans = [[0] * n for _ in range(m)]
for i in range(m):
    for j in range(n):
        r1, r2 = max(0, i - k), min(m - 1, i + k)
        c1, c2 = max(0, j - k), min(n - 1, j + k)
        ans[i][j] = (pre[r2+1][c2+1] - pre[r1][c2+1]
                     - pre[r2+1][c1] + pre[r1][c1])
```

## 复杂度
时间 O(m·n)：建 `pre` 和填 `ans` 各扫一遍矩阵。
空间 O(m·n)：额外开了 (m+1)×(n+1) 的 `pre` 和同尺寸的 `ans`。

## 易错点
- 边界不裁剪：`k=2` 时 `(0,0)` 的 `i-k=-2`，直接当下标用会越界或取到错误区域；必须先 `max(0, i-k)`、`min(m-1, i+k)` 夹住。
- `pre` 与 `mat` 差一位：`pre` 是 (m+1)×(n+1)，窗口 `[r1,r2]` 对应 `pre` 的行 `r1..r2+1`；写成 `pre[r2][c2]` 会整体少算最后一行一列，示例 1 的 `(0,0)` 会得 8 而不是 12。

## 如果面试官追问
问：`k` 很大时能否不建 `pre`？答：不能省，`k≥max(m,n)` 时每个窗口都是全矩阵和，仍要靠 `pre[m][n]` 一次取出，否则退化成 O(m·n·k²)。
