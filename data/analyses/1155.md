## 一句话思路
用 `dp[s]` 记「已掷若干骰子、和为 s 的方案数」，每加一个骰子就做一次滑动窗口转移，答案取 `dp[target]`。

## 怎么做
1. 先剪枝：若 `target < n` 或 `target > n*k`，直接返回 0，因为 n 个骰子最小和 n、最大和 n*k。
2. 初始化 `dp = [0]*(target+1)`，`dp[0] = 1`，表示 0 个骰子和为 0 有 1 种。
3. 对每个骰子（共 n 轮），用前缀和把 `new[s] = sum(dp[s-k .. s-1])` 的 k 次加法压成 O(1)，即 `window` 滑窗。
4. 每轮只遍历 `s` 从 1 到 `min(target, i*k)`，超出当前 i 个骰子最大和的 s 必为 0，跳过省时间。

以示例 2（n=2, k=6, target=7）走一遍关键那步：第 1 轮后 `dp[1..6]` 全为 1；第 2 轮算 `s=7` 时窗口覆盖 `dp[1..6]`，累加得 6，正是 `1+6,2+5,...,6+1` 六种。

```python
MOD = 10**9 + 7
if target < n or target > n * k:
    return 0
dp = [0] * (target + 1)
dp[0] = 1
for i in range(1, n + 1):
    new = [0] * (target + 1)
    window = 0
    hi = min(target, i * k)
    for s in range(1, hi + 1):
        window += dp[s - 1]
        if s - k - 1 >= 0:
            window -= dp[s - k - 1]
        new[s] = window % MOD
    dp = new
return dp[target]
```

## 复杂度
时间：O(n·target)，n 轮各扫一遍 target，滑窗把内层 k 消掉。
空间：O(target)，只开 `dp` 和 `new` 两个长度 target+1 的数组。

## 易错点
1. 输入 `n=30, k=30, target=500` → 若每轮都遍历到 `target` 而不截到 `i*k`，会白算大量必为 0 的 s，虽不改变结果但常数翻倍；正确做法是 `hi = min(target, i*k)`，且 `s-k-1` 越界判断用 `>= 0` 而非 `> 0`。
2. 输入 `n=1, k=6, target=3` → 若忘记 `target > n*k` 的上界剪枝，`target=1000, n=1, k=6` 这类会白跑 1000 次循环；正确做法是开头两行剪枝直接返回 0，注意 `target < n` 也要判。

## 如果面试官追问
问：若 k 很大（如 10^9）怎么办？答：滑窗仍 O(n·target)，但 `i*k` 上界失去剪枝意义，需改用组合容斥或生成函数，复杂度与 k 无关。
