## 一句话思路
后序 DFS 让每个节点只返回一次高度，同时用 `-1` 当"不平衡"哨兵向上短路，避免 O(n²) 的重复求高。

## 怎么做
1. 定义 `height(node)`：空节点返回 0，否则递归取左右高度。
2. 任一子树返回 `-1` 就立刻返回 `-1`，不再算另一侧。
3. 左右高度差 `abs(l - r) > 1` 返回 `-1`，否则返回 `max(l, r) + 1`。
4. 主函数判断 `height(root) != -1`。

拿示例 2 的 `[1,2,2,3,3,null,null,4,4]` 走一遍：最底层节点 4 的左右都是 `None`，返回 `0+1=1`；它的父节点 3 左高 1、右高 0，差 1，返回 2；再上一层节点 2 左高 2、右高 0，`abs(2-0)=2 > 1`，返回 `-1`；这个 `-1` 一路传到根，`height(root) == -1`，输出 `False`。关键中间值是节点 2 处的 `l=2, r=0`。

```python
def height(node):
    if node is None:
        return 0
    l = height(node.left)
    if l == -1:
        return -1
    r = height(node.right)
    if r == -1:
        return -1
    if abs(l - r) > 1:
        return -1
    return max(l, r) + 1

return height(root) != -1
```

## 复杂度
时间 O(n)：每个节点进 `height` 一次，`-1` 短路只减少不增加。
空间 O(h)：递归栈深度等于树高，最坏链状树 O(n)，平衡时 O(log n)，无额外数组。

## 易错点
- 对每个节点单独调一次求高函数（`isBalanced(left) and isBalanced(right)` 再各算高度）→ 链状树上退化成 O(n²)，n=10⁴ 就超时 → 必须让同一次后序递归既返回高度又返回平衡标记，用 `-1` 合并两个信息。
- 只比较根节点左右子树高度 → 示例 2 的根 `1` 左高 3、右高 1，差 2 恰好能判出，但换成 `[1,2,2,3,null,null,3,4,null,null,4]` 这类根差 ≤1、深层才失衡的树会错判 `True` → 失衡判断必须下沉到每个节点，在 `height` 内部对每个 `node` 都做 `abs(l - r) > 1` 检查。

## 如果面试官追问
问：要求返回所有失衡节点而非布尔值？
答：`height` 改成返回 `(高度, 失衡列表)`，差 >1 时把当前 `node` 追加进去，最后返回列表。
