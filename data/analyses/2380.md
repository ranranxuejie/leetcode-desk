## 一句话思路
用 DP 扫一遍：每个 `1` 的完成时间 = max(前一个 `1` 的完成时间 + 1, 它前面 `0` 的个数)，取最大值。

## 怎么做
1. 设 `zeros` 为已扫过的 `0` 的个数，`dp` 为当前这个 `1` 归位所需的秒数，`ans` 记录最大值。
2. 遇到 `'0'` 就 `zeros += 1`，不更新 `dp`。
3. 遇到 `'1'`：若 `zeros > 0`，则 `dp = max(dp + 1, zeros)`；否则 `dp = 0`（左边没有 `0` 可换，它本来就在位）。
4. 每步 `ans = max(ans, dp)`，最后返回 `ans`。

拿 `s = "0110101"` 走一遍关键位置：扫到下标 1 的 `'1'` 时 `zeros = 1`，`dp = max(0+1, 1) = 1`；扫到下标 2 的 `'1'` 时 `zeros` 仍是 1，`dp = max(1+1, 1) = 2`；扫到下标 4 的 `'1'` 时 `zeros = 2`，`dp = max(2+1, 2) = 3`；扫到下标 6 的 `'1'` 时 `zeros = 3`，`dp = max(3+1, 3) = 4`，答案 4。

```python
zeros = dp = ans = 0
for ch in s:
    if ch == '0':
        zeros += 1
    elif zeros > 0:
        dp = max(dp + 1, zeros)
        ans = max(ans, dp)
return ans
```

`dp + 1` 的含义：这个 `1` 必须等它左边那个 `1` 先走一步，自己才能动，所以至少比前一个 `1` 晚一秒；`zeros` 的含义：它左边有这么多 `0` 要跨过去，每秒最多跨一个，所以至少 `zeros` 秒。两者取大即为它的完成时刻。

## 复杂度
时间 O(n)：一次遍历，n 为 `len(s)`。
空间 O(1)：只开 `zeros`、`dp`、`ans` 三个整数。

## 易错点
- 输入 `s = "10"` 或 `"11100"` → 若不加 `zeros > 0` 判断，`dp` 会被算成 `max(0+1, 0) = 1`，错答 1 → 正确做法是左边没有 `0` 时 `dp` 保持 0，答案 0。
- 输入 `s = "0011"` → 若写成 `dp = dp + 1` 而漏掉 `max(..., zeros)`，两个 `1` 各得 1、2，错答 2 → 实际第一个 `1` 要跨两个 `0`，正确是 `max(0+1, 2) = 2`、`max(2+1, 2) = 3`，答案 3。

## 如果面试官追问
问：如果每秒只允许替换**一个** `"01"`（而非全部同时），答案怎么变？
答：退化成冒泡，每个 `1` 跨过左边每个 `0` 各花一秒，答案就是所有 `1` 左侧 `0` 的个数之和，即逆序对数。
