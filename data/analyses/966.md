## 一句话思路
建三张哈希表：原词表、小写表、元音归一表，查询按「原词→小写→元音」三级降级查找，每张表只存首次出现的原词。

## 怎么做
1. 遍历 `wordlist`，把原词、`w.lower()`、`w.lower()` 中元音替换成 `'a'` 后的键分别塞进三张 dict，用 `setdefault` 保证只留第一个。
2. 对每个 `query`，先查原词表 `exact`，命中直接返回。
3. 未命中则查 `lower` 表，键为 `query.lower()`。
4. 仍未命中则查 `vowel` 表，键为 `query.lower()` 的元音归一形式。

以示例 1 为例，`wordlist` 建表后 `lower` 里 `"kite"` 对应 `"KiTe"`（先出现），`"hare"` 对应 `"hare"`；`vowel` 里 `"kite"` 和 `"keto"` 都归一成 `"kata"`，`setdefault` 让 `"kata"` 只保留 `"KiTe"`。查询 `"keto"` 原词表、小写表都落空，归一成 `"kata"` 命中 `"KiTe"`，输出正是示例里的 `"KiTe"`。

```python
def norm(w):
    return ''.join('a' if c in 'aeiou' else c for c in w.lower())

exact, lower, vowel = {}, {}, {}
for w in wordlist:
    exact.setdefault(w, w)
    lower.setdefault(w.lower(), w)
    vowel.setdefault(norm(w), w)

ans = []
for q in queries:
    if q in exact:
        ans.append(exact[q])
    elif q.lower() in lower:
        ans.append(lower[q.lower()])
    else:
        ans.append(vowel.get(norm(q), ""))
```

## 复杂度
时间：O((n+m)·L)，n、m 为两表长度，L≤7 是单词长度，建表加查询各扫一遍。
空间：O(n·L)，三张 dict 各存 n 个键值，键长最多 7。

## 易错点
- `wordlist = ["KiTe","kite"]`，`queries = ["kite"]` → 若用普通赋值 `lower[w.lower()] = w`，`"kite"` 会被后出现的 `"kite"` 覆盖，返回 `"kite"`；正确是 `setdefault` 保留首个 `"KiTe"`。
- `queries = ["Hear"]`，`wordlist` 含 `"hare"` → 若先做元音归一再查小写表，`"hear"` 归一成 `"haar"` 与 `"hare"` 的 `"hara"` 不等，看似安全；但若把元音表键写成未小写的原词，`"Hear"` 归一成 `"Haar"` 就漏配。正确做法是归一前先 `lower()`，且三级顺序不能颠倒。

## 如果面试官追问
问：若 `wordlist` 涨到 10^6、单词长 20，怎么优化？
答：三张表仍 O(n·L) 建表，查询 O(L)；瓶颈在内存，可只存 `lower` 和 `vowel` 两张表，原词命中用 `lower` 表加大小写比对代替。
