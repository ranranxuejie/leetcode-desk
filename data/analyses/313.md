## 一句话思路
用 dp 数组按序生成丑数，每个质数配一个指针指向它当前该乘的 dp 位置，取最小者推进。

## 怎么做
1. 建 `dp = [1] + [0]*(n-1)`，`dp[0] = 1`，再建 `idx = [0]*len(primes)`，每个质数对应一个指针。
2. 循环 `i` 从 1 到 `n-1`，每轮算 `cand = [primes[j] * dp[idx[j]] for j in range(m)]`，取 `dp[i] = min(cand)`。
3. 对每个 `j`，若 `primes[j] * dp[idx[j]] == dp[i]` 则 `idx[j] += 1`——必须用 `if` 而非 `elif`，让所有并列的质数一起前进。
4. 返回 `dp[n-1]`。

以 `n=12, primes=[2,7,13,19]` 为例，生成到 `dp[11]` 时，四个指针分别停在使乘积为 32 的位置：`2*dp[4]=2*8=16` 不对，实际是 `2*dp[5]=2*13=26`、`7*dp[3]=7*7=49`… 关键中间值：`dp[9]=26` 由 `2*dp[5]`（`dp[5]=13`）产生，`dp[10]=28` 由 `2*dp[6]`（`dp[6]=14`）与 `7*dp[2]`（`dp[2]=4`→28）并列产生，两个指针同时 `+1`，否则 28 会被重复写入。

```python
dp = [1] * n
idx = [0] * len(primes)
for i in range(1, n):
    cand = [p * dp[k] for p, k in zip(primes, idx)]
    dp[i] = min(cand)
    for j, p in enumerate(primes):
        if p * dp[idx[j]] == dp[i]:
            idx[j] += 1
return dp[n - 1]
```

## 复杂度
时间：`O(n * m)`，`n` 是生成个数，`m = len(primes) ≤ 100`，每轮扫一遍质数。
空间：`O(n + m)`，`dp` 存 `n` 个丑数，`idx` 存 `m` 个指针。

## 易错点
- `primes` 含 2 和 7 且 `dp` 中出现 14、28 这类被两个质数同时生成的数 → 若写成 `elif` 只推进一个指针，下一轮会再次算出同一个值，`dp` 里出现重复丑数，`n=12` 时输出会偏小 → 必须用独立 `if` 让所有命中的指针都 `+1`。
- `n=1` 时循环体一次都不执行 → 若把 `dp` 初始化成 `[0]*n` 再在循环里赋 `dp[0]`，会返回 0 而非 1 → 直接 `dp = [1]*n` 或特判返回 1。

## 如果面试官追问
问：`primes` 长度到 10^4 怎么办？
答：`O(n*m)` 会到 10^9，改用小顶堆存 `(值, 质数下标)`，每轮弹出最小值并只推进对应指针，`O(n log m)`。
