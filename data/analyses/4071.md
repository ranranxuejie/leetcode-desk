## 一句话思路
反转后缀 `s[k:]` 等价于把原串切成 `s[:k]` 和 `s[k:]` 两段，第二段倒序接上；枚举切点 k，用前缀和 O(1) 算出每段代价。

## 怎么做
1. 先算不反转的代价：`cost[i] = min(|a-b|, 10-|a-b|)`，起点是 0，累加得 `base`。
2. 反转后串为 `s[:k] + s[k:][::-1]`，代价 = 前段内部代价 + 跨接点代价 + 后段倒序内部代价。
3. 预处理 `pre[i]`（原串前 i 个字符的代价和）与 `suf[i]`（原串从 i 到末尾倒序拨的代价和），枚举 k 时 O(1) 拼出总代价。
4. 取所有 k（含 k=n 即不反转）的最小值。

以 `s="1502"` 为例，k=1 时串变 `"1" + "205"`：前段代价 `|0-1|=1`，跨接点 `1→2` 代价 1，后段倒序 `2→0→5` 代价 `2+5=7`，合计 9。注意后段倒序内部代价要按 `s[n-1], s[n-2], ..., s[k]` 的顺序算，不是原顺序。

```python
def d(a, b):
    x = abs(a - b)
    return min(x, 10 - x)

pre = [0] * (n + 1)
for i in range(n):
    pre[i + 1] = pre[i] + d(int(s[i - 1]) if i else 0, int(s[i]))

suf = [0] * (n + 1)
for i in range(n - 1, -1, -1):
    nxt = int(s[i + 1]) if i + 1 < n else 0
    suf[i] = suf[i + 1] + d(int(s[i]), nxt)

ans = pre[n]
for k in range(n):
    head = pre[k] + d(int(s[k - 1]) if k else 0, int(s[n - 1]))
    ans = min(ans, head + suf[k])
```

## 复杂度
时间：O(n)，枚举 k 与两次前缀和扫描各一遍，每次 O(1)。
空间：O(n)，`pre` 和 `suf` 两个长度 n+1 的数组。

## 易错点
- `s="4219"` 反转整个串得 `"9124"`：若把后段倒序代价按原顺序 `4→2→1→9` 算会得错值，正确是按 `9→1→2→4` 顺序累加，即 `suf` 要从右往左建。
- k=0 时前段为空，跨接点应是 `0→s[n-1]` 而非 `0→s[-1]` 的索引越界；k=n 时没有后段，跨接点不存在，必须单独用 `pre[n]` 作为候选，否则会漏掉不反转的情况。

## 如果面试官追问
若要求输出最优 k 而非仅最小次数？答：枚举时同步记录使 `ans` 最小的 k，注意 k=n 表示不反转，返回时特判。
