## 一句话思路
用异或：把 0..n 全部异或一遍再和 nums 每个元素异或，成对出现的数抵消，剩下的就是缺失值。

## 怎么做
1. 令 `n = len(nums)`，答案候选 `res = n`（因为 0..n 共 n+1 个数，nums 只有 n 个）。
2. 遍历 `i, v in enumerate(nums)`，同时异或 `i` 和 `v`。
3. 遍历结束后 `res` 就是缺失的那个数。

以示例 1 `nums = [3,0,1]` 为例，`n = 3`，`res` 初值 3。第 0 轮 `res = 3^0^3 = 0`；第 1 轮 `res = 0^1^0 = 1`；第 2 轮 `res = 1^2^1 = 2`。最终 `res = 2`，正好是缺的数。关键中间值：每轮 `res` 里保留的是「已处理下标集合」与「已处理元素集合」的对称差。

```python
def missing_number(nums):
    n = len(nums)
    res = n
    for i, v in enumerate(nums):
        res ^= i
        res ^= v
    return res
```

为什么成立：完整集合是 `{0,1,...,n}`，nums 是它去掉一个元素。把两组数全部异或，出现两次的抵消成 0，只出现一次的就是缺失值。异或满足交换律和结合律，顺序无关。

## 复杂度
时间 O(n)：一次遍历，每轮两次异或。
空间 O(1)：只用了 `res`、`i`、`v` 三个变量，没有额外数组。

## 易错点
- 输入 `[0]` → 若把 `res` 初值写成 0 而不是 `n`，会返回 0，但正确答案是 1（缺的是 n 本身）。正确做法：`res = n` 起手，把「多出来的那个上界」先放进异或池。
- 输入 `[1]` → 若只异或 nums 元素、忘了异或下标 `i`，得到 1，而正确答案是 0。正确做法：循环里 `res ^= i` 和 `res ^= v` 两行都不能省，下标集合恰好补齐 0..n-1。

## 如果面试官追问
问：如果数组里缺两个数，怎么找？
答：仍全异或得到 `a^b`，取最低位的 1 把数组分成两组分别异或，即得 `a` 和 `b`。
