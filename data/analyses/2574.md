## 一句话思路
用总和减去当前元素得到左右和之和，再用前缀和 left 直接算出 `|2*left + nums[i] - total|`。

## 怎么做
1. 先求 `total = sum(nums)`，它是不变的基准。
2. 维护 `left` 表示 `nums[i]` 左侧元素之和，初始为 0。
3. 对每个 `i`，`right = total - left - nums[i]`，答案取 `abs(left - right)`。
4. 更新 `left += nums[i]` 进入下一轮。

以 `nums = [10,4,8,3]` 为例，`total = 25`。`i=0` 时 `left=0`，`right=25-0-10=15`，答案 `|0-15|=15`；随后 `left` 变成 10。`i=1` 时 `right=25-10-4=11`，答案 `|10-11|=1`。关键中间值就是 `right` 由 `total - left - nums[i]` 一次算出，不用单独建 rightSum 数组。

```python
total = sum(nums)
left = 0
ans = []
for x in nums:
    right = total - left - x
    ans.append(abs(left - right))
    left += x
return ans
```

这样只扫一遍，`left` 和 `right` 都是即时值，空间只花在输出数组上。

## 复杂度
时间 O(n)：一次求和加一次遍历，各扫 n 个元素。
空间 O(1) 额外（不计输出数组 ans 的 n 个位置）。

## 易错点
- `nums = [1]` → 若把 `right` 写成 `total - left` 忘了减 `nums[i]`，会得到 `right=1`、答案 1，正确是 `right=0`、答案 0。必须减掉当前元素本身。
- `nums = [10,4,8,3]` → 若在算 `right` 前就执行 `left += x`，`i=0` 时 `left` 已是 10，`right=25-10-10=5`，答案错成 5 而非 15。更新 `left` 必须放在 append 之后。

## 如果面试官追问
问：如果 nums 长度到 10^5 且要求原地修改返回？答：仍是一遍扫描，把结果直接写回 `nums[i]`，`left` 用临时变量保存即可，空间降到 O(1)。
