## 一句话思路
从 target 倒推回 1：能除 2 就除 2（省一次加倍），除不尽先减 1，加倍次数用完就一路减到 1。

## 怎么做
1. 维护 `target` 和剩余加倍次数 `maxDoubles`，答案 `ans = 0`，倒着走。
2. 只要 `maxDoubles > 0 and target > 1`：若 `target` 是奇数，先 `target -= 1`、`ans += 1`（这一步对应正向的递增）；再 `target //= 2`、`ans += 1`、`maxDoubles -= 1`。
3. 加倍用完或 `target` 已到 1 时，剩下的差值只能靠递增补齐，`ans += target - 1`。
4. 返回 `ans`。

拿示例 2 走一遍：`target=19, maxDoubles=2`。19 是奇数 → 18，`ans=1`；除 2 → 9，`ans=2`，`maxDoubles=1`。9 是奇数 → 8，`ans=3`；除 2 → 4，`ans=4`，`maxDoubles=0`。循环停，补 `4-1=3`，`ans=7`。注意倒推时 19→18 这一步，正向看是 18 加倍后 +1，不是先 +1 再加倍，顺序别搞反。

```python
ans = 0
while maxDoubles > 0 and target > 1:
    if target % 2 == 1:
        target -= 1
        ans += 1
    target //= 2
    ans += 1
    maxDoubles -= 1
ans += target - 1
return ans
```

关键点：倒推时「奇数先减 1」是唯一选择，因为 `2x` 永远是偶数，奇数 target 不可能由加倍直接得到。

## 复杂度
时间：O(log target + maxDoubles)，循环次数由 target 每次折半决定，最多约 30 次（target ≤ 10^9）。
空间：O(1)，只用了 `ans`、`target`、`maxDoubles` 三个变量。

## 易错点
- `target=1, maxDoubles=100` → 若循环条件写成 `target >= 1`，会进循环把 1 除成 0，答案错成 1 或负数 → 正确做法是条件写 `target > 1`，直接返回 0。
- `target=10, maxDoubles=4` → 若正向贪心「先加倍到 8 再补 2」得 5 步，或倒推时对偶数也先减 1 再除，会多算 → 正确做法是偶数直接除 2，示例 3 的答案是 4（10→5→4→2→1 倒推）。

## 如果面试官追问
问：如果要求输出具体操作序列而不是次数？
答：倒推时把每步记成反向操作（除 2 记「加倍」、减 1 记「递增」），最后反转列表即可，复杂度不变。
