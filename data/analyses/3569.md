## 一句话思路
维护每个质数出现位置的集合，答案等于「全局不同质数数 + 存在质数同时出现在切点两侧的个数」，用线段树维护每个切点两侧的并集大小。

## 怎么做
1. 预处理 `MAXV=10**5` 的质数表，把 `nums` 中每个质数 `p` 的出现下标放进有序集合 `pos[p]`。
2. 对每个切点 `k`（1..n-1），记 `L(k)` = 前缀 `[0,k-1]` 的不同质数数，`R(k)` = 后缀 `[k,n-1]` 的不同质数数，`B(k)` = 同时出现在两侧的质数数，则 `L+R = 全局质数数 + B(k)`，答案取 `max_k`。
3. 只有 `p` 的最小下标 `< k <= 最大下标` 时 `p` 才贡献 `B(k)`，即 `p` 给区间 `[minpos+1, maxpos]` 整体加 1，用线段树做区间加、全局最大值。
4. 每次查询只影响旧值和新值两个质数的集合，各自删/插下标后重算该质数的贡献区间，做两次区间加即可。

以示例 1 第一次查询后 `nums=[2,2,3,1,2]` 为例：`pos[2]={0,1,4}`，`pos[3]={2}`，全局质数数 2；`2` 贡献区间 `[1,4]`，`3` 贡献区间 `[3,2]`（空），线段树最大值在 `k=1` 处为 1，答案 `2+1=3`。

```python
def update(p, delta):  # delta=+1 插入后重算, -1 删除前撤销
    s = pos[p]
    if not s: return
    lo, hi = min(s), max(s)
    if lo < hi:
        seg.add(lo + 1, hi, delta)

# 查询循环内
old = nums[idx]
if is_prime(old): update(old, -1); pos[old].discard(idx)
nums[idx] = val
if is_prime(val): pos[val].add(idx); update(val, +1)
ans.append(total_prime + max(0, seg.max_all()))
```

## 复杂度
时间：每次查询 O(log n)（线段树区间加 + 集合增删），预处理 O(n log n)。
空间：`pos` 存 n 个下标，线段树 4n，质数表 10^5。

## 易错点
- `nums=[2,1,4]` 查询 `[0,1]` 后无质数：若忘记 `total_prime` 会随删除减到 0，会输出线段树残留的旧值而非 0 → 删除时同步维护全局质数计数，答案取 `total_prime + max(0, seg.max)`。
- 某质数只出现一次（如 `pos[3]={2}`）：若写成 `lo <= hi` 会给自己加 1，答案虚高 → 必须 `lo < hi` 才加区间，单点质数对任何切点都不可能在两侧同时出现。

## 如果面试官追问
问：若要求返回最优切点 k 而非最大值？答：线段树节点额外存最大值对应的下标，`max_all` 时下推取 argmax 即可。
