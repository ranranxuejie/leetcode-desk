## 一句话思路
用 `dp[i]` 表示 `s[:i]` 的切分方案数，从每个 `i` 向后枚举长度 ≤ 10 的合法段（无前导 0 且值 ≤ k）转移。

## 怎么做
1. 定义 `dp[i]` 为前 `i` 个字符的方案数，`dp[0] = 1`，答案 `dp[n]`。
2. 对每个 `i`，若 `dp[i] == 0` 直接跳过（剪枝，避免无效枚举）。
3. 从 `i` 向后取 `j = i+1 ... min(n, i+10)`，遇到 `s[i] == '0'` 立即 break（前导 0 非法）。
4. 边取边累加数值 `val = val*10 + int(s[j-1])`，`val > k` 时 break（再长只会更大），否则 `dp[j] += dp[i]`。

以 `s = "1317", k = 2000` 为例：`i=0` 时 `val` 依次为 1、13、131、1317，全部 ≤ 2000，于是 `dp[1..4]` 各加 1；`i=1` 时 `dp[1]=1`，`val` 为 3、31、317 均合法，`dp[2]+=1, dp[3]+=1, dp[4]+=1`；最终 `dp[4] = 8`。

```python
MOD = 10**9 + 7
n = len(s)
dp = [0] * (n + 1)
dp[0] = 1
for i in range(n):
    if dp[i] == 0 or s[i] == '0':
        continue
    val = 0
    for j in range(i, min(n, i + 10)):
        val = val * 10 + int(s[j])
        if val > k:
            break
        dp[j + 1] = (dp[j + 1] + dp[i]) % MOD
return dp[n]
```

## 复杂度
时间：`O(n * log k)`，内层最多 10 次（`k ≤ 10^9`）。
空间：`O(n)`，仅 `dp` 数组。

## 易错点
- `s = "1000", k = 10`：若在 `i=0` 处不检查 `s[i]=='0'` 就继续枚举，会把 `"0"` 当合法段，错算成有方案；正确做法是 `s[i]=='0'` 时直接 `continue`，因为任何以 0 开头的段都含前导 0。
- `s = "2020", k = 30`：若只判 `val > k` 而不在 `i=1` 处因 `s[1]=='0'` 跳过，会把 `"020"` 拆成 `[2, 020]` 计入；正确做法是遇到 `s[i]=='0'` 就跳过该起点，`"020"` 永远不该被枚举。

## 如果面试官追问
问：若要求输出所有方案而非计数？答：把 `dp` 改成回溯 + 记忆化，`dfs(i)` 返回从 `i` 开始的所有切分列表，复杂度变为输出规模乘以 `n`。
