## 一句话思路
用二进制位掩码枚举 0 到 2^n-1，第 i 位为 1 就选 nums[i]，天然不重不漏。

## 怎么做
1. 令 n = len(nums)，外层循环 mask 从 0 到 2**n - 1。
2. 内层循环 i 从 0 到 n-1，判断 `mask >> i & 1`。
3. 为 1 就把 nums[i] 追加进当前子集 cur，循环结束后把 cur 收进结果。
4. 以 nums = [1,2,3] 为例，mask = 5 即二进制 101，i=0 和 i=2 命中，cur = [1,3]，正是输出里的 `[1,3]`。

```python
n = len(nums)
res = []
for mask in range(1 << n):
    cur = []
    for i in range(n):
        if mask >> i & 1:
            cur.append(nums[i])
    res.append(cur)
return res
```

关键中间值：n=3 时 mask 取遍 0..7，mask=0 得 `[]`，mask=7 得 `[1,2,3]`，共 8 个子集，与示例输出一一对应。

## 复杂度
时间 O(n · 2^n)：2^n 个 mask，每个扫 n 位。
空间 O(n · 2^n)：结果本身占这么多，递归栈不用开，cur 最多 n 个元素。

## 易错点
1. 写成 `mask >> i & 1 == 1` 时优先级出错 → 在 Python 里 `==` 比 `&` 优先级高，实际算成 `mask >> i & (1 == 1)`，条件恒为 `mask >> i & 1` 的真假值，结果错乱 → 写成 `(mask >> i) & 1` 或直接 `mask >> i & 1` 不加比较。
2. 用 `cur` 直接 append 进 res 后没新建列表 → 若改成回溯写法复用同一个 cur，最后 res 里全是同一个引用，输出变成 8 个 `[1,2,3]` → 每次 `res.append(cur[:])` 拷一份。

## 如果面试官追问
问：nums 有重复元素怎么办（对应主站 90 题）？
答：先排序，回溯时同一层跳过 `i > start and nums[i] == nums[i-1]`，位掩码法失效需换回溯。
