## 一句话思路
用大根堆反复把当前最大值还原成「它减去其余元素之和」，能一路还原到全 1 就成立。

## 怎么做
1. 把 `target` 全部入大根堆（Python 用负数），维护总和 `total`。
2. 每轮弹出最大值 `mx`，其余元素和是 `rest = total - mx`；若 `rest == 0` 说明只剩一个元素，直接看它是否为 1。
3. 关键剪枝：`mx` 可能远大于 `rest`，一次只减一轮会超时，应直接算 `k = (mx - 1) // rest`，把 `mx` 一次降到 `mx - k * rest`，同时 `total -= k * rest`。
4. 若 `mx - rest < 1`（即还原后小于 1）返回 `False`；否则把新值压回堆，继续。

以 `target = [9,3,5]` 为例：`total = 17`，弹出 `mx = 9`，`rest = 8`，`k = (9-1)//8 = 1`，新值 `9 - 8 = 1`，堆变 `[5,3,1]`，`total = 9`；再弹 `5`，`rest = 4`，新值 `1`；再弹 `3`，`rest = 2`，新值 `1`，堆全为 1，返回 `True`。

```python
import heapq
def isPossible(target):
    if len(target) == 1:
        return target[0] == 1
    total = sum(target)
    heap = [-x for x in target]
    heapq.heapify(heap)
    while True:
        mx = -heapq.heappop(heap)
        rest = total - mx
        if rest == 0:
            return mx == 1
        k = max(1, (mx - 1) // rest)
        new = mx - k * rest
        if new < 1:
            return False
        total -= k * rest
        heapq.heappush(heap, -new)
        if new == 1 and -heap[0] == 1:
            return True
```

## 复杂度
时间：每轮堆操作 O(log n)，`mx` 每次至少减半，共 O(log(max target)) 轮，总 O(n log n + log(max) · log n)。
空间：堆存 n 个元素，O(n)。

## 易错点
- 输入 `[1, 1000000000]`：若每轮只减一次 `rest`，要循环近 10^9 次直接超时 → 必须用 `k = (mx - 1) // rest` 批量还原，一步把 `mx` 压到 1。
- 输入 `[2]` 或 `[1,1,1,2]`：`[2]` 时 `rest = 0`，若直接返回 `True` 就错，应判断 `mx == 1`；`[1,1,1,2]` 弹出 `2` 后 `rest = 3`，`new = 2 - 3 < 1` 返回 `False`，别漏这个下界检查。

## 如果面试官追问
问：要求输出还原的操作序列怎么办？
答：在堆里同时记录下标，每次弹出 `mx` 时把 `(下标, k)` 压入栈，最后逆序输出即可。
