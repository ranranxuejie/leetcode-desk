## 一句话思路
按到达时间排序，用最小堆维护空闲椅子、用堆按离开时间回收椅子，模拟到 targetFriend 到达即停。

## 怎么做
1. 把 `(arrival, leaving, i)` 按 arrival 升序排序，得到处理顺序。
2. 维护两个堆：`free` 存空闲椅子编号（初始压入 0..n-1），`busy` 存 `(leaving, chair)`。
3. 每个朋友到达前，先 `while busy and busy[0][0] <= arrival` 弹出，把椅子 push 回 `free`——注意是 `<=`，同一时刻离开的椅子可被立即占用。
4. 从 `free` 弹出最小椅子给当前朋友；若 `i == targetFriend` 立即返回该椅子，否则把 `(leaving, chair)` 压入 `busy`。

以示例 1 `times = [[1,4],[2,3],[4,6]]`、`targetFriend = 1` 为例：排序后顺序是朋友 0(1,4)、1(2,3)、2(4,6)。朋友 0 拿椅子 0，`busy = [(4,0)]`；朋友 1 到达时刻 2，`busy[0][0]=4 > 2` 不回收，从 `free` 弹出 1，命中 targetFriend，返回 1。关键中间值就是这一步 `free` 弹出的是 1 而不是 0——因为 0 还压在 `busy` 里没到期。

```python
order = sorted((a, l, i) for i, (a, l) in enumerate(times))
free = list(range(len(times)))
heapq.heapify(free)
busy = []
for a, l, i in order:
    while busy and busy[0][0] <= a:
        _, c = heapq.heappop(busy)
        heapq.heappush(free, c)
    c = heapq.heappop(free)
    if i == targetFriend:
        return c
    heapq.heappush(busy, (l, c))
```

## 复杂度
时间 O(n log n)：排序一次，每个朋友进出 `free`/`busy` 各 O(log n)。
空间 O(n)：`order`、`free`、`busy` 各存 n 个元素。

## 易错点
- 回收条件写成 `busy[0][0] < a` → 示例 1 中朋友 0 在时刻 4 离开、朋友 2 在时刻 4 到达，会漏回收椅子 0，朋友 2 错拿椅子 2。必须用 `<=`。
- 先给椅子再判 targetFriend，或判完 targetFriend 就 `break` 而不返回 → 拿不到椅子编号。正确做法是弹出 `c` 后立刻 `if i == targetFriend: return c`，此时 `c` 就是答案。

## 如果面试官追问
若 arrival 不再互不相同、同一时刻多人到达怎么办？答：排序键加上朋友编号 `i` 作为次序，模拟顺序确定后答案仍唯一。
