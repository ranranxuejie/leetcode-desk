## 一句话思路
按列从左到右做 DP，状态是「当前列上下两格是否已被封锁」，用最小割的列间转移求最少放置数。

## 怎么做
1. 把每列压成 4 种状态：上下两格是否可通行（`#`/`S`/`C`/`P` 都算不可通行或特殊处理），先判断 `S` 与 `C` 是否已被 `#` 隔开。
2. 逐列枚举「本列上下格是否放障碍」，代价是本列新放的 `#` 数。
3. 列间转移要求：相邻两列之间不能存在一条从 `S` 侧到 `C` 侧的通路，即上下两行的横向连通必须被切断。
4. 用 `dp[col][mask]` 记录前 `col` 列、当前列封锁状态为 `mask` 的最小代价，`mask` 取 0..3。

以示例 1 `["S.C.P#P.", ".....#.S"]` 为例，第 0 列上格是 `S`、下格是 `.`，`mask` 只能取「下格放障碍」这一种才切断 `S` 向下绕行；此时 `dp[0][mask]=1`，后续列继续累加，最终 `dp[N-1][*]` 最小值为 3。

```python
# 列状态：bit0=上格可走, bit1=下格可走
INF = 2**31 - 1
dp = [INF] * 4
for mask in range(4):
    if ok_col(0, mask):
        dp[mask] = cost_col(0, mask)
for c in range(1, n):
    ndp = [INF] * 4
    for pm in range(4):
        for cm in range(4):
            if ok_col(c, cm) and ok_between(pm, cm):
                ndp[cm] = min(ndp[cm], dp[pm] + cost_col(c, cm))
    dp = ndp
ans = min(dp)
return -1 if ans >= INF else ans
```

## 复杂度
时间：`O(N * 4 * 4)`，`N` 为列数，常数 16 来自状态枚举。
空间：`O(4)`，只保留相邻两列的 `dp` 数组。

## 易错点
- 输入 `["SP#P..P#PC#.S", "..#P..P####.#"]`：若把 `P` 当平地处理，会误判 `S` 能经瞬移点绕过 `#` 到达 `C`，输出非 `-1`；正确做法是把 `P` 视作不可通行（或单独建瞬移连通分量），本列 `mask` 中 `P` 格必须记为封锁。
- 输入 `["CP.#.P.", "...S..S"]`：若只检查上下两行各自的横向连通、忽略上下格之间的竖直通路，会漏掉 `S` 从下格绕到上格再进 `C` 的路径，得到小于 4 的答案；正确做法是 `ok_between` 同时检查两行横向边和同列竖直边。

## 如果面试官追问
问：若 `N` 扩大到 10^6 且要求输出具体放置方案？
答：DP 时额外存每列 `mask` 的前驱，回溯即可还原，时间不变。
