## 一句话思路
把 `(鼠位置, 猫位置, 轮到谁)` 当状态做记忆化极小化极大，超过 1000 步判猫胜，靠「步数上界」保证搜索终止。

## 怎么做
1. 预处理每个格子在 `mouseJump`/`catJump` 内沿四方向能跳到的格子（遇 `#` 停），得到 `moves[cell]` 和 `cmoves[cell]`。
2. 状态 `(m, c, turn)`，`turn=0` 鼠走、`1` 猫走；鼠走时任一后继为胜即胜，猫走时任一后继为胜即猫胜。
3. 用 `step` 计数，`step >= 1000` 直接返回 `False`（鼠输），并把 `(m,c,turn)` 记入 memo 防重复。
4. 以示例 3 `["M.C...F"]`、`catJump=1, mouseJump=3` 为例：鼠在 0 号格，一步能跳到 3 号格（`M` 到 `F` 距离 6，`mouseJump=3` 跳不到），而猫在 2 号格，`catJump=1` 每步逼近，鼠的每个落点都在猫一步可达范围内，最终返回 `False`。

```python
def dfs(m, c, turn, step):
    if step >= 1000: return False
    if m == c: return False
    if m == food: return True
    if c == food: return False
    key = (m, c, turn)
    if key in memo: return memo[key]
    memo[key] = False  # 防环
    if turn == 0:
        res = any(dfs(nm, c, 1, step + 1) for nm in moves[m])
    else:
        res = all(dfs(m, nc, 0, step + 1) for nc in cmoves[c])
    memo[key] = res
    return res
```

## 复杂度
时间：状态数 `O(rows*cols)^2 * 2`，每状态枚举 `O(rows+cols)` 个落点，共 `O((RC)^2 * (R+C))`。
空间：memo 存 `O((RC)^2)` 个状态，另加递归栈深度 ≤1000。

## 易错点
- 忘记「猫先到食物也算猫胜」：示例 1 中猫在 `(1,1)`、食物在 `(0,4)`，若只判 `m==c` 会漏掉猫抢食路径，正确做法是 `c == food` 时直接返回 `False`。
- 状态里漏掉 `turn`：鼠和猫在同一 `(m,c)` 但轮到不同玩家时胜负相反，示例 2 中鼠一步到食物、猫一步到不了，若合并状态会把鼠的必胜误判成猫胜。

## 如果面试官追问
问：若把 1000 步上限去掉怎么办？答：状态图有环，需用拓扑排序从终局反推胜负，无法用纯 DFS 记忆化。
