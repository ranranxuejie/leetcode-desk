## 一句话思路
三条路径互不干扰，各自在「只能向右/下走」的约束下取最大路径和，答案就是三个独立 DP 之和。

## 怎么做
1. 观察：从 (0,0) 出发只能向右/下，从 (0,n-1) 出发只能向左下/下/右下，从 (n-1,0) 出发只能向上/右/右下——三者的可达区域互不重叠（除终点），所以可以拆成三个独立子问题。
2. 对每个起点做一次二维 DP：`dp[i][j] = fruits[i][j] + max(三个前驱)`，按行/列顺序递推。
3. 用官方示例验证：从 (0,0) 出发，`dp[1][1] = 6 + max(dp[0][0], dp[0][1], dp[1][0]) = 6 + 1 = 7`；从 (0,3) 出发，`dp[1][2] = 8 + max(dp[0][1], dp[0][2], dp[0][3]) = 8 + 4 = 12`；从 (3,0) 出发，`dp[3][1] = 14 + dp[3][0] = 14 + 13 = 27`。
4. 三个 DP 的终点值相加即答案（示例中为 1+6+11+16 + 4+8+12+16 + 13+14+15+16 的路径和，注意终点只算一次）。

```python
def maxCollectedFruits(fruits):
    n = len(fruits)
    def dp(sr, sc, dirs):
        d = [[-1] * n for _ in range(n)]
        d[sr][sc] = fruits[sr][sc]
        for i in range(n):
            for j in range(n):
                if d[i][j] < 0: continue
                for di, dj in dirs:
                    ni, nj = i + di, j + dj
                    if 0 <= ni < n and 0 <= nj < n:
                        d[ni][nj] = max(d[ni][nj], d[i][j] + fruits[ni][nj])
        return d[n-1][n-1]
    a = dp(0, 0, [(1,0),(0,1),(1,1)])
    b = dp(0, n-1, [(1,-1),(1,0),(1,1)])
    c = dp(n-1, 0, [(-1,1),(0,1),(1,1)])
    return a + b + c - 2 * fruits[n-1][n-1]
```

## 复杂度
时间：O(n²)，三个 DP 各扫一遍 n×n 网格。
空间：O(n²)，每个 DP 开一个 n×n 的 `d` 表（可滚动优化到 O(n)）。

## 易错点
- 终点 (n-1,n-1) 被三个 DP 各算了一次 → 直接相加会多算两份 `fruits[n-1][n-1]` → 最后要减去 `2 * fruits[n-1][n-1]`，示例 1 中就是多减了 32。
- 从 (0,n-1) 出发的路径列坐标可能越界（如 `(1, n)`）→ 不判 `0 <= nj < n` 会数组越界或读到错误值 → 每个方向都要检查边界，示例中 `dp[1][3]` 只能从 `dp[0][2]` 或 `dp[0][3]` 转移。

## 如果面试官追问
问：n 扩大到 10⁵ 怎么办？答：本题路径约束使三区域分离，但网格本身是 O(n²) 输入，无法再降；若只给稀疏水果点，可改成按行扫描的滚动 DP。
