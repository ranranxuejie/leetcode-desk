## 一句话思路
排序后枚举 nums1 中被删的两个元素之一，用 nums2[0] 反推 x 并双指针验证，取最小 x。

## 怎么做
1. 两个数组都排序，`nums1` 长度 n，`nums2` 长度 n-2。
2. 被删的两个元素中必有一个落在 `nums1` 的前 3 个位置（因为删 2 个，前 3 个里至少剩 1 个参与匹配），所以只需枚举 `i in 0..2` 作为「被删的下标」。
3. 对每个 i，令 `x = nums2[0] - nums1[i]`（假设 nums1[i] 被删，则 nums1 中第一个未被删的元素对应 nums2[0]），再用双指针扫一遍验证。
4. 验证通过就更新答案取 min。

以示例 1 为例：排序后 `nums1 = [4,8,12,16,20]`，`nums2 = [10,14,18]`。枚举 i=0 时 `x = 10-4 = 6`，验证失败；i=1 时 `x = 10-8 = 2`，失败；i=2 时 `x = 10-12 = -2`，双指针匹配成功，答案 -2。

```python
nums1.sort(); nums2.sort()
ans = 2**31 - 1
for i in range(3):
    x = nums2[0] - nums1[i]
    j = k = 0
    while j < len(nums1) and k < len(nums2):
        if j == i:
            j += 1
            continue
        if nums1[j] + x == nums2[k]:
            j += 1; k += 1
        else:
            j += 1
    if k == len(nums2):
        ans = min(ans, x)
return ans
```

## 复杂度
时间：排序 O(n log n)，枚举 3 次双指针 O(n)，共 O(n log n)，n 为 nums1 长度。
空间：排序栈开销 O(log n)，无额外数组。

## 易错点
- 枚举范围写成 `range(len(nums1))`：示例 1 中 i=3 时 `x = 10-16 = -6`，双指针可能误判通过，导致答案偏小。正确做法是只枚举前 3 个下标，因为删 2 个元素后前 3 个里必有一个保留。
- 验证时忘记跳过被删下标 i：`nums1 = [3,5,5,3]` 排序后 `[3,3,5,5]`，若 i=0 不跳过，`nums1[0]+x` 会重复参与匹配，k 提前到达 len(nums2) 误判成功。正确做法是 `if j == i: j += 1; continue`。

## 如果面试官追问
若要求输出被删的两个下标而非 x？答：验证通过时记录 i 和双指针中未匹配的 j，即为两个被删位置。
