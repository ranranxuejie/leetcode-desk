## 一句话思路
维护当前人数 `cur`，每遇 `E` 加一、遇 `L` 减一，答案就是 `cur` 的历史最大值。

## 怎么做
1. 初始化 `cur = 0`、`ans = 0`，`cur` 表示此刻室内人数。
2. 遍历 `s` 的每个字符，`E` 让 `cur += 1`，`L` 让 `cur -= 1`。
3. 每次更新后立刻 `ans = max(ans, cur)`，因为椅子数必须覆盖任意时刻的峰值。
4. 返回 `ans`。

以示例 3 `s = "ELEELEELLL"` 为例，逐字符走：`cur` 依次为 1,0,1,2,1,2,3,2,1,0，其中第 6 秒（下标 6，字符 `E`）达到峰值 3，所以 `ans = 3`。关键点是峰值出现在中途而非结尾——结尾 `cur` 回到 0，若只看最终值会错答 0。

```python
cur = 0
ans = 0
for ch in s:
    if ch == 'E':
        cur += 1
    else:
        cur -= 1
    ans = max(ans, cur)
return ans
```

注意 `ans` 的更新必须放在 `if/else` 之后、循环体内，不能挪到循环外只算一次。

## 复杂度
时间 O(n)：`n = len(s)`，每个字符常数次操作。
空间 O(1)：只开 `cur`、`ans` 两个整型变量，无额外容器。

## 易错点
- 输入 `"ELELEEL"` → 若把 `ans` 更新写在循环外、只取最终 `cur`，会得到 1 而非 2 → 正确做法是每步都 `max`，因为峰值出现在下标 5 的第二个连续 `E`。
- 输入 `"LE"` 这类以 `L` 开头的序列 → 若先判断 `cur > 0` 再减、或对 `cur` 做 `max(cur, 0)` 截断，会掩盖真实人数 → 题目保证序列有效，`L` 时直接 `cur -= 1` 即可，不要加保护性截断。

## 如果面试官追问
问：若要求输出「每个时刻需要的最少椅子数」序列怎么办？
答：把 `ans = max(ans, cur)` 换成 `res.append(cur)`，最后对 `res` 求前缀最大值即可。
