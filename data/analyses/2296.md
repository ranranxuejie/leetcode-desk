## 一句话思路
用两个栈 `left`/`right` 以光标为界分存文本，所有操作只动栈顶，天然 O(k)。

## 怎么做
1. `left` 存光标左边字符（栈顶是光标前一个字符），`right` 存光标右边字符（栈顶是光标后一个字符，故顺序反转）。
2. `addText`：把 `text` 逐字符压入 `left`，光标自动落在其右侧。
3. `deleteText`：从 `left` 弹 `min(k, len(left))` 个，返回实际弹出数。
4. `cursorLeft`/`cursorRight`：在 `left` 与 `right` 之间搬 `min(k, 源栈长度)` 个字符，再返回 `''.join(left[-10:])`。

以示例 `addText("leetcode")` 后 `deleteText(4)` 为例：`left` 从 `['l','e','e','t','c','o','d','e']` 弹出 4 个后变 `['l','e','e','t']`，`right` 仍为空，返回 4。随后 `addText("practice")` 使 `left` 变 `['l','e','e','t','p',...,'e']`，`cursorRight(3)` 时 `right` 为空，搬不动，直接返回 `left[-10:]` = `"etpractice"`。

```python
def cursorLeft(self, k):
    for _ in range(min(k, len(self.left))):
        self.right.append(self.left.pop())
    return ''.join(self.left[-10:])

def cursorRight(self, k):
    for _ in range(min(k, len(self.right))):
        self.left.append(self.right.pop())
    return ''.join(self.left[-10:])
```

## 复杂度
时间：每次调用 O(k + 10)，`k` 是移动/删除字符数，取末尾 10 个是常数。
空间：O(n)，`n` 为编辑器当前总字符数，两个栈合计存全部字符。

## 易错点
- `cursorRight` 时 `right` 为空（如示例 `cursorRight(3)`）→ 若直接 `pop` 会抛异常 → 必须先 `min(k, len(right))` 截断，搬不动就原样返回。
- `deleteText(10)` 而 `left` 只有 4 个字符（示例中 `"leet"`）→ 若循环 10 次会越界 → 用 `min(k, len(left))` 作循环上界，并把这个上界作为返回值，示例应返回 4 而非 10。

## 如果面试官追问
若要求单次 O(1) 而非 O(k)？答：改用双向链表加游标节点，移动时沿指针走 k 步仍是 O(k)，但增删是 O(1)；要真正 O(1) 移动需可持久化/块状结构，代价是常数变大。
