## 一句话思路
用 DP 维护「当前元素作为子数组首项」和「作为非首项」两种状态的最大总成本。

## 怎么做
1. 定义 `f0` = 以当前元素为某个子数组**首项**时的最大总成本，`f1` = 以当前元素为**非首项**（即前面已有元素、符号由位置奇偶决定）时的最大总成本。
2. 从左到右扫描，对 `nums[i]` 分奇偶讨论：偶数下标贡献 `+nums[i]`，奇数下标贡献 `-nums[i]`（因为子数组内符号是 `+ - + -`，与全局下标奇偶一致）。
3. 转移：`f0 = max(f0, f1) + nums[i]`（新开一段，符号必为 `+`）；`f1 = max(f0_old, f1) - nums[i]`（接在后面，符号为 `-`）。注意 `f1` 用的是更新前的 `f0`。
4. 答案取 `max(f0, f1)`。

以 `nums = [1,-2,3,4]` 为例：初始 `f0 = f1 = -inf`。`i=0`：`f0 = 1`，`f1 = -inf`。`i=1`：`f0 = max(1,-inf) + (-2) = -1`，`f1 = max(1,-inf) - (-2) = 3`。`i=2`：`f0 = max(-1,3)+3 = 6`，`f1 = max(-1,3)-3 = 0`。`i=3`：`f0 = max(6,0)+4 = 10`，`f1 = max(6,0)-4 = 2`。最终 `max(10,2)=10`，与示例一致。

```python
NEG = float('-inf')
f0 = f1 = NEG
for i, x in enumerate(nums):
    if i % 2 == 0:
        f0, f1 = max(f0, f1) + x, max(f0, f1) - x
    else:
        f0, f1 = max(f0, f1) - x, max(f0, f1) + x
return max(f0, f1)
```

（上面用 `max(f0,f1)` 同时算两个值会互相污染，实际写法应先存 `best = max(f0, f1)`，再分别更新 `f0 = best + sign*x`、`f1 = best - sign*x`，其中偶数位 `sign=1`、奇数位 `sign=-1`。）

## 复杂度
时间 O(n)：一次线性扫描，每个元素常数次比较。
空间 O(1)：只维护 `f0`、`f1` 两个变量，无额外数组。

## 易错点
- 输入 `nums = [1,-1]`：若把 `f1` 的转移写成用更新后的 `f0`，会得到错误值；正确做法是先存 `best = max(f0, f1)` 再同时更新两个状态，保证用的是上一轮的值。
- 输入含 `-10^9` 且长度 `10^5`：累加结果可达 `10^14`，若用 32 位整型会溢出；Python 整数天然安全，但若题目要求按 32 位截断则需显式处理，本题直接返回 Python int 即可。

## 如果面试官追问
