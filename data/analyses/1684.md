## 一句话思路
把 `allowed` 压成一个 26 位掩码，每个 `words[i]` 也压成掩码，用 `w & ~mask == 0` 判断是否被包含。

## 怎么做
1. 遍历 `allowed`，把 `ord(c) - ord('a')` 位设为 1，得到整数 `mask`。
2. 对每个 `w in words`，同样累出 `wm`，但一旦发现某位不在 `mask` 里就可以提前判否。
3. 计数满足条件的 `w` 并返回。

以示例 1 的 `allowed = "ab"` 为例，`mask = 0b11 = 3`。处理 `"ad"` 时，`'a'` 对应位 0、`'d'` 对应位 3，`wm` 含位 3，`wm & ~mask` 非 0，判否；处理 `"aaab"` 时 `wm = 0b11`，`wm & ~mask == 0`，计入，最终得 2。

```python
mask = 0
for c in allowed:
    mask |= 1 << (ord(c) - 97)

ans = 0
for w in words:
    wm = 0
    for c in w:
        wm |= 1 << (ord(c) - 97)
    if wm & ~mask == 0:
        ans += 1
```

注意 `~mask` 在 Python 里是负数（无限位补码），但 `wm` 只有低 26 位非零，`wm & ~mask` 仍然只保留 `wm` 中不在 `mask` 里的位，结果正确，不需要额外 `& 0x3FFFFFF`。

## 复杂度
时间：O(总字符数)，`allowed` 长度加所有 `words[i]` 长度之和，每个字符一次移位或运算。
空间：O(1)，只开了 `mask`、`wm`、`ans` 三个整数。

## 易错点
- `allowed = "ab"`、`words = ["ad"]`：若用 `set(allowed)` 后写 `all(c in s for c in w)` 是对的，但若误写成 `w in allowed` 或 `set(w) <= set(allowed)` 之外的子串判断，会把 `"ad"` 判成一致；正确做法是逐字符判断或位掩码包含。
- `allowed = "cad"`、`words = ["ac"]`：`allowed` 顺序是 `c,a,d`，若用 `allowed.find(c)` 之类依赖顺序的逻辑会出错；正确做法是只关心字符集合，与 `allowed` 中字符顺序无关。

## 如果面试官追问
追问：如果 `words` 很大、需要多次查询怎么办？
答：预处理 `allowed` 掩码一次，每个词 O(长度) 判断，已是线性下界；可把短词掩码缓存进字典复用。
