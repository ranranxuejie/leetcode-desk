## 一句话思路
统计每个值的出现次数，只要没有任何值出现超过 2 次，就能分成两半且各自无重复。

## 怎么做
1. 用 `Counter(nums)` 统计每个值的频次。
2. 遍历频次，若某个值出现次数 `> 2`，直接返回 `False`。
3. 全部 ≤ 2 则返回 `True`。

以 `nums = [1,1,2,2,3,4]` 为例：`Counter` 得到 `{1:2, 2:2, 3:1, 4:1}`，最大频次是 2，没有超过 2 的值，返回 `True`。若换成 `[1,1,1,1]`，`{1:4}` 中 `1` 的频次 4 > 2，返回 `False`。

```python
from collections import Counter

def isPossibleToSplit(nums):
    cnt = Counter(nums)
    for v in cnt.values():
        if v > 2:
            return False
    return True
```

为什么频次 ≤ 2 就够：每个值最多出现两次，把每个值的两次出现分别放进 nums1 和 nums2（只出现一次的值随便放一边），两边都不会有重复；而长度各为 `n/2` 由「每个值最多贡献 2 个、总数 n」自动满足——把每个值的第一份给 nums1、第二份给 nums2，若某边不足 `n/2`，说明另一边的值可以挪过来，因为每个值在两边各至多一个，挪动不会造成重复。更直接地看：频次 ≤ 2 时，出现两次的值有 `k` 个，它们各占两边一个位置，剩下 `n - 2k` 个单次值平分到两边，两边各得 `k + (n-2k)/2 = n/2`，恰好满足。

## 复杂度
时间 O(n)：`Counter` 遍历一次 nums，再遍历至多 n 个不同值。
空间 O(n)：哈希表存每个不同值的频次，最坏 n 个键。

## 易错点
- 输入 `[1,1,1,2,2,3]` → 若只检查「不同值个数 ≥ n/2」会误判为 `True`（不同值有 3 个，n/2=3）→ 正确做法是检查每个值的频次是否 ≤ 2，这里 `1` 出现 3 次应返回 `False`。
- 输入 `[1,1,2,2]` → 若误以为「有重复就失败」会返回 `False` → 正确做法是允许每个值出现两次（分居两边），此例应返回 `True`。

## 如果面试官追问
要求输出具体分割方案怎么办？答：第一份取每个值的首次出现，第二份取第二次出现，单次值交替分配，即可构造出等长的两组。
