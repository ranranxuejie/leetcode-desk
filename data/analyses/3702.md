## 一句话思路
先求全数组异或和 `total`：非零就取全部 n 个，为零就删掉一个非零元素取 n-1。

## 怎么做
1. 遍历 `nums` 累异或得到 `total`。
2. `total != 0` 时直接返回 `len(nums)`，因为整个数组本身就是合法子序列。
3. `total == 0` 时，只要存在任一 `x != 0`，删掉它后剩余异或为 `0 ^ x = x != 0`，返回 `n - 1`。
4. 否则（全为 0，或数组为空）返回 0。

以 `nums = [1,2,3]` 为例：`total = 1 ^ 2 ^ 3 = 0`，命中第 3 步；数组里有 `1 != 0`，删掉它后 `2 ^ 3 = 1 != 0`，返回 `3 - 1 = 2`，与示例一致。再看 `[2,3,4]`：`total = 2 ^ 3 ^ 4 = 5 != 0`，直接返回 3。

```python
total = 0
for x in nums:
    total ^= x
if total != 0:
    return len(nums)
for x in nums:
    if x != 0:
        return len(nums) - 1
return 0
```

关键点：删掉一个元素只影响异或和的那一位，`total ^ x` 就是删掉 `x` 后的异或和；`total == 0` 时它等于 `x`，所以只要 `x != 0` 就一定非零。这也说明答案只可能是 `n`、`n-1`、`0` 三种，不需要枚举子序列。

## 复杂度
时间 O(n)：一次求异或和，最坏再扫一遍找非零元素。
空间 O(1)：只存 `total` 一个整数，没有额外数组。

## 易错点
- 输入 `nums = [0,0]` → 若照搬「`total == 0` 就返回 `n-1`」会得到 1，但任何子序列异或都是 0 → 必须先确认存在 `x != 0` 才返回 `n-1`，否则返回 0。
- 输入 `nums = [0,0,5]` → `total = 5 != 0`，若误以为「含 0 要特殊处理」而返回 2 就错了 → 0 不影响异或和，直接返回 3。

## 如果面试官追问
问：要求输出具体子序列而非长度？
答：`total != 0` 输出全部；`total == 0` 输出除第一个非零元素外的所有元素，顺序保持原下标即可。
