## 一句话思路
按下标奇偶决定加减号，一次遍历累加即可，因为每一项的符号只由 `i % 2` 决定。

## 怎么做
1. 初始化 `ans = 0`，遍历 `i` 从 `0` 到 `len(nums) - 1`。
2. `i` 为偶数时执行 `ans += nums[i]`，为奇数时执行 `ans -= nums[i]`。
3. 遍历结束后返回 `ans`。

以 `nums = [1,3,5,7]` 为例，关键中间值：`i=0` 时 `ans = 0 + 1 = 1`；`i=1` 时 `ans = 1 - 3 = -2`；`i=2` 时 `ans = -2 + 5 = 3`；`i=3` 时 `ans = 3 - 7 = -4`，与输出一致。

```python
ans = 0
for i, x in enumerate(nums):
    if i % 2 == 0:
        ans += x
    else:
        ans -= x
return ans
```

也可以写成一行生成器：`return sum(x if i % 2 == 0 else -x for i, x in enumerate(nums))`。两种写法等价，前者更直白，后者更短；面试时选前者，便于口述每一步的 `ans` 变化。

注意 `i % 2 == 0` 判断的是**下标**的奇偶，不是 `nums[i]` 值的奇偶。示例 1 中 `nums[1] = 3` 是奇数、下标 1 也是奇数，纯属巧合；换成 `nums = [2,4,6]` 时，`nums[1] = 4` 是偶数但下标 1 是奇数，仍要减，结果 `2 - 4 + 6 = 4`。

## 复杂度
时间 O(n)：一次遍历，n 为 `len(nums)`。
空间 O(1)：只开 `ans` 一个累加变量，生成器写法也不额外存列表。

## 易错点
- 输入 `nums = [100]`（长度 1）→ 若循环写成 `for i in range(1, len(nums))` 会漏掉 `nums[0]`，返回 0 → 正确做法是从 `i = 0` 起遍历，或直接 `ans = nums[0]` 再从 `i = 1` 开始加减。
- 输入 `nums = [2,4,6]` → 若误判成「值为偶数就加、值为奇数就减」，会得到 `2 + 4 + 6 = 12` → 正确做法是只看 `i % 2`，得到 `2 - 4 + 6 = 4`。

## 如果面试官追问
追问：若要求返回交替和的绝对值，或数组长度到 10^7 怎么办？
答：绝对值只需在返回前套 `abs(ans)`；10^7 规模下 O(n) 单次遍历已是最优，无需额外空间，注意用 Python 内置 `sum` 加生成器比手写循环更快。
