## 一句话思路
用最大堆每轮弹出最大值 x，压回 `isqrt(x)`，重复 k 次后求和；因为每轮必须取当前最大，堆能 O(log n) 拿到它。

## 怎么做
1. 把 `gifts` 全部取负压入 `heapq`（Python 只有小顶堆），这样堆顶 `-heap[0]` 就是当前最大堆。
2. 循环 k 次：弹出堆顶 `x = -heappop(h)`，算出 `y = isqrt(x)`，把 `-y` 压回。
3. 循环结束后对 `-v` 求和返回。

以 `gifts = [25,64,9,4,100], k = 4` 为例：初始堆顶是 100，第一秒弹出 100 → `isqrt(100) = 10` 压回；第二秒堆顶变成 64 → `isqrt(64) = 8`；第三秒堆顶 25 → `isqrt(25) = 5`；第四秒堆顶是 10（刚压回的）→ `isqrt(10) = 3`。此时堆内为 `[5,8,9,4,3]`，和 29。

关键中间值：第四秒选中的是 10 而不是 9，说明压回的新值必须重新参与比较，不能只在原数组上排序。

```python
import heapq
from math import isqrt

h = [-g for g in gifts]
heapq.heapify(h)
for _ in range(k):
    x = -heapq.heappop(h)
    heapq.heappush(h, -isqrt(x))
return -sum(h)
```

注意 `isqrt` 是整数平方根，比 `int(x ** 0.5)` 安全：`10**9` 附近浮点开方可能差 1。

## 复杂度
时间 O((n + k) log n)：建堆 n，每轮弹压各 log n，共 k 轮。
空间 O(n)：堆里始终存 n 个元素。

## 易错点
- 输入 `gifts = [1,1,1,1], k = 4` → 若用 `while x > 1` 才压回，会漏掉 1 的堆，堆变空后 `heappop` 抛异常 → 正确做法是每轮无条件弹压，`isqrt(1) = 1` 原样压回。
- 输入 `gifts = [10**9], k = 1000` → 若用 `int(x ** 0.5)`，`10**9` 附近浮点误差可能得到 31622 而非 31622（差 1 时结果错）→ 用 `math.isqrt` 保证精确向下取整。

## 如果面试官追问
问：k 放大到 10^9 怎么办？答：k 超过约 6 轮后所有堆都收敛到 1，可提前判断堆顶为 1 就 break，剩余轮次不影响结果。
