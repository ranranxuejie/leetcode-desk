## 一句话思路
从左到右扫 `command`，遇到 `G` 直接收，遇到 `(` 看下一个字符是 `)` 还是 `a` 决定收 `o` 还是 `al`。

## 怎么做
1. 建 `res = []`，指针 `i = 0`，循环到 `i == len(command)`。
2. `command[i] == 'G'` 时追加 `'G'`，`i += 1`。
3. 否则 `command[i] == '('`，看 `command[i+1]`：是 `')'` 就追加 `'o'`、`i += 2`；是 `'a'` 就追加 `'al'`、`i += 4`。
4. 循环结束 `return ''.join(res)`。

以 `command = "G()(al)"` 为例：`i=0` 取 `'G'`，`i=1` 时 `command[2] == ')'` 追加 `'o'` 跳到 `i=3`，`i=3` 时 `command[4] == 'a'` 追加 `'al'` 跳到 `i=7`，`res` 为 `['G','o','al']`，拼接得 `"Goal"`。

```python
res, i = [], 0
while i < len(command):
    if command[i] == 'G':
        res.append('G'); i += 1
    elif command[i + 1] == ')':
        res.append('o'); i += 2
    else:
        res.append('al'); i += 4
return ''.join(res)
```

关键在 `i += 4`：`"(al)"` 长 4，跳少了会在 `'l'` 或 `')'` 上再判一次，跳多了会漏字符。

## 复杂度
时间 O(n)：`i` 每次至少前进 1，最多扫一遍 `command`。
空间 O(n)：`res` 存解释结果，最坏 `command` 全是 `"()"` 时长度约 n/2。

## 易错点
- 输入 `"(al)"` 时若只写 `i += 2`（把 `"(al)"` 当 `"()"` 处理），会在 `'l'` 处再进循环、`command[i]` 既不是 `'G'` 也不是 `'('`，落到 `elif` 分支误判成 `'o'`。正确做法是 `'a'` 分支必须 `i += 4`。
- 输入 `"G"` 这种单字符时，若先判 `command[i] == '('` 再判 `'G'`，`i+1` 会越界访问 `command[1]`。正确做法是把 `'G'` 放第一个分支，保证 `i+1` 只在确认 `command[i] == '('` 后才用。

## 如果面试官追问
问：若 `command` 里出现嵌套或非法片段怎么办？答：本题保证只含三种合法片段，无需校验；要校验就加一个 `else` 抛错，逻辑不变。
