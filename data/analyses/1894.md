## 一句话思路
先对 `sum(chalk)` 取模把 `k` 压到一轮以内，再从左往右累减，第一个减不动的下标就是答案。

## 怎么做
1. 求一轮总消耗 `total = sum(chalk)`，令 `k %= total`，把无意义的整轮循环全部跳过。
2. 从左到右遍历 `chalk`，对每个 `chalk[i]` 判断 `k < chalk[i]` 是否成立，成立就返回 `i`。
3. 否则执行 `k -= chalk[i]` 继续往后。

用示例 2 走一遍：`chalk = [3,4,1,2]`，`total = 10`，`k = 25 % 10 = 5`。此时 `i=0`，`5 >= 3`，`k` 变 `2`；`i=1`，`2 < 4` 成立，返回 `1`。注意取模后 `k=5` 而不是 25，这正是跳过两整轮（20 支）的结果。

```python
total = sum(chalk)
k %= total
for i, c in enumerate(chalk):
    if k < c:
        return i
    k -= c
```

关键点：取模后 `k` 的范围是 `[0, total-1]`，所以循环内一定会命中某个 `i`，不需要兜底返回值。

## 复杂度
时间：O(n)，`sum` 一遍加遍历一遍，各 O(n)。
空间：O(1)，只用了 `total` 和 `k` 两个变量。

## 易错点
- `k` 恰好是 `total` 的整数倍（如 `chalk=[5,1,5]`、`k=11`）→ 取模后 `k=0`，若写成 `k <= chalk[i]` 会错判学生 0 需要补充 → 必须用严格小于 `k < chalk[i]`，`k=0` 时学生 0 确实补不了，返回 0 才对。
- 直接模拟不取模（`k=10**9`、`chalk` 全为 1）→ 循环 10^9 次超时 → 先 `k %= total` 把轮数压掉，这是本题从「模拟」升级到「O(n)」的唯一关键。

## 如果面试官追问
问：如果 `chalk` 会动态修改（单点更新），怎么快速回答？
答：维护前缀和数组加树状数组，用 `k % total` 后在前缀和上二分找第一个 `> k` 的位置，单次 O(log n)。
