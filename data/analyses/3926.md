## 一句话思路
先按分隔符切出候选片段，再用「连字符两侧必须是字母」的规则把片段修成合法单词，最后用哈希表统计词频并回答 queries。

## 怎么做
1. 把 `chunks` 直接 `"".join(chunks)` 得到 `s`，不要逐块处理，因为单词可能跨块（示例 1 的 `"wor"+"ld"`）。
2. 用正则 `[^a-z-]+` 切分 `s`，得到只含小写字母和连字符的候选片段。
3. 对每个候选片段，按连字符再切一次，丢掉空串，剩下的每段就是合法单词——这等价于「连字符两侧必须都是字母」。
4. 用 `Counter` 统计所有合法单词，`queries` 逐个查表，缺失返回 0。

以示例 2 为例：`s = "a--b a--c"`，正则切分得到 `["a--b", "a--c"]`；再按 `-` 切，`"a--b"` 得到 `["a","","b"]`，丢掉空串后是 `["a","b"]`，`"a--c"` 同理得到 `["a","c"]`，最终计数 `{"a":2,"b":1,"c":1}`。

```python
import re
from collections import Counter

s = "".join(chunks)
cnt = Counter()
for seg in re.split(r"[^a-z-]+", s):
    for w in seg.split("-"):
        if w:
            cnt[w] += 1
ans = [cnt.get(q, 0) for q in queries]
```

关键点：`seg.split("-")` 后空串必须丢弃，否则 `"a--b"` 会把 `""` 当成单词。

## 复杂度
时间 O(N + M)，N 是 `s` 总长、M 是 queries 总长，正则扫描与建表各一遍。
空间 O(N)，`Counter` 最坏存下所有单词，`re.split` 的中间列表也是 O(N)。

## 易错点
- 输入 `chunks = ["a-","-b"]` → 若逐块切分，会把 `"a"` 和 `"b"` 当两个词，漏掉跨块的 `"a--b"` → 必须先 `"".join(chunks)` 再切。
- 输入 `s = "a--b"` → 若用 `seg.split("-")` 后不判空，`""` 会被计入 `cnt`，虽然不影响 query 结果但浪费空间；更危险的是若把 `"-"` 当合法字符保留，`"a-"` 会被误判为单词 `"a-"` → 正确做法是切分后 `if w` 过滤，且正则只保留 `a-z` 和 `-`。

## 如果面试官追问
问：如果 `chunks` 总长到 10^7 怎么办？
答：仍用 `"".join` + 正则，但改成流式扫描字符、边扫边切词，避免一次性建大字符串和中间列表。
