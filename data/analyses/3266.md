## 一句话思路
先用小根堆模拟到最小值超过 `max(nums)`，剩下的 k 次按「排序后轮流乘」的周期规律分配。

## 怎么做
1. 建 `(值, 下标)` 小根堆，模拟 `min(k, 若干次)` 次：弹出最小、乘 `multiplier`、压回，直到堆顶 ≥ 原数组最大值或 k 用完。
2. 以示例 1 为例：`nums=[2,1,3,5,6], k=5, multiplier=2`，堆顶依次弹出 1→2、2→4、2→4、3→6，此时堆顶 4 < 6 继续，第 5 次弹出 4→8，k 归零，得 `[8,4,6,5,6]`。
3. 若 k 还有剩（说明所有值已 ≥ 原最大值），把当前数组按值升序排，剩余 k 次就是「排序后第 i 个元素乘 `multiplier ** (k // n + (i < k % n))`」，用快速幂算。
4. 最后每个元素对 `10**9 + 7` 取余，按原下标写回。

```python
import heapq
MOD = 10**9 + 7
h = [(v, i) for i, v in enumerate(nums)]
heapq.heapify(h)
mx = max(nums)
while k and h[0][0] < mx:
    v, i = heapq.heappop(h)
    heapq.heappush(h, (v * multiplier, i))
    k -= 1
order = sorted(h)                      # 按值升序
n = len(order)
q, r = divmod(k, n)
for pos, (v, i) in enumerate(order):
    e = q + (1 if pos < r else 0)
    nums[i] = v % MOD * pow(multiplier, e, MOD) % MOD
```

## 复杂度
时间：模拟阶段 O(n log n + k' log n)，k' 是堆顶追上最大值前的次数，之后排序 O(n log n) 加 n 次快速幂 O(n log k)。
空间：堆和排序各 O(n)，无其他额外结构。

## 易错点
- `nums=[1,1], k=10**9, multiplier=1`：若只写「堆顶 ≥ max 就停」，`multiplier=1` 时堆顶永远等于 max，循环立刻退出，剩余 k 全走周期公式，结果仍对；但若把停止条件写成 `h[0][0] > mx`，会白跑 10^9 次模拟直接超时，必须用 `< mx` 作继续条件。
- `nums=[100000,2000], k=2, multiplier=1000000`：模拟中 `100000*1000000=10**11` 远超 32 位，若中途取余再比较大小，堆序会乱（`10**11 % MOD` 反而变小），正确做法是模拟阶段保留真实大整数，只在最后一步 `% MOD`。

## 如果面试官追问
问：k 更大到 10^18 怎么办？答：周期公式里 `pow(multiplier, e, MOD)` 已是 O(log e)，只需把 `divmod` 的 q 用大整数算，其余不变。
