## 一句话思路
用 `win[i]` 表示剩 i 个石子时先手是否必胜，只要存在平方数 k 使 `win[i-k]` 为假，`win[i]` 就为真。

## 怎么做
1. 建长度 `n+1` 的布尔数组 `win`，`win[0] = False`（无石子可拿即输）。
2. 从 `i = 1` 递推到 `n`，枚举所有 `k = j*j <= i`。
3. 若某个 `win[i-k]` 为 `False`，置 `win[i] = True` 并跳出内层循环。
4. 返回 `win[n]`。

以 `n = 7` 为例：`win[1]=True`（拿1）、`win[2]=False`（只能到 `win[1]`）、`win[3]=True`（拿1到 `win[2]`）、`win[4]=True`（拿4到 `win[0]`）、`win[5]=False`、`win[6]=True`、`win[7]`：k=1→`win[6]=True`，k=4→`win[3]=True`，两个后继全为真，故 `win[7]=False`，与示例一致。

```python
win = [False] * (n + 1)
for i in range(1, n + 1):
    j = 1
    while j * j <= i:
        if not win[i - j * j]:
            win[i] = True
            break
        j += 1
return win[n]
```

## 复杂度
时间：O(n·√n)，外层 n 个状态，每个状态最多试 √n 个平方数。
空间：O(n)，只开了 `win` 这一个长度 n+1 的布尔数组。

## 易错点
- `n = 1` 时若把 `win[0]` 初始化成 `True`，会得到 `win[1] = False`，与示例 1 的 `true` 相反；`win[0]` 必须为 `False`，因为「轮到谁无石子可拿谁输」。
- `n = 4` 时若内层循环写成 `j*j < i`（漏等号），就拿不到 k=4 这一步，`win[4]` 会由 k=1 推出 `win[3]=True` 而误判为 `False`；条件必须是 `j*j <= i`。

## 如果面试官追问
问：n 放大到 10^9 怎么办？
答：这题有数学结论——n 形如 `4^a(8b+7)` 时必败，其余必胜，O(log n) 判定。
