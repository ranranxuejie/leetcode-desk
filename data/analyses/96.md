## 一句话思路
按根节点枚举左右子树规模，用卡特兰数递推 `dp[i] = Σ dp[j]*dp[i-1-j]`，因为左右子树结构独立可乘。

## 怎么做
1. 定义 `dp[i]` 为 i 个连续节点能构成的 BST 种数，`dp[0] = dp[1] = 1`。
2. 对每个 `i` 从 2 到 n，枚举左子树节点数 `j` 从 0 到 `i-1`，右子树固定为 `i-1-j`。
3. 累加 `dp[j] * dp[i-1-j]`，因为根节点固定后左右子树组合数相乘。
4. 返回 `dp[n]`。

以 `n = 3` 为例，`dp[2] = dp[0]*dp[1] + dp[1]*dp[0] = 2`；`dp[3] = dp[0]*dp[2] + dp[1]*dp[1] + dp[2]*dp[0] = 2 + 1 + 2 = 5`，与示例一致。

```python
dp = [0] * (n + 1)
dp[0] = dp[1] = 1
for i in range(2, n + 1):
    for j in range(i):
        dp[i] += dp[j] * dp[i - 1 - j]
return dp[n]
```

## 复杂度
时间：O(n²)，双重循环枚举 i 和 j。
空间：O(n)，只开 dp 数组，无递归栈。

## 易错点
- `n = 1` 时若只初始化 `dp[0] = 1` 而漏掉 `dp[1]`，循环不执行直接返回 `dp[1] = 0`，正确做法是 `dp[0] = dp[1] = 1`。
- 内层写成 `range(1, i)` 会漏掉 `j = 0`（左空右满）和 `j = i-1`（左满右空）两种退化情况，`n = 3` 会算成 3 而非 5，正确做法是 `range(i)` 覆盖 0 到 i-1。

## 如果面试官追问
问：n 很大（如 10⁵）且要求答案对 10⁹+7 取模怎么办？
答：O(n²) 不可行，改用卡特兰数通项 `C(2n,n)/(n+1)`，配合阶乘预处理和模逆元，O(n) 时间。
