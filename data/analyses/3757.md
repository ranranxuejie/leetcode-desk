## 一句话思路
用「总子序列数 − 无效子序列数」计数，无效即剩余部分按位或仍等于全数组按位或，用按位或状态压缩 DP 统计。

## 怎么做
1. 先求全数组按位或 `total`，答案初值 `2**n - 1`（所有非空子序列）。
2. 反向理解：被移除的子序列有效 ⇔ 剩余元素按位或 < `total`；等价于统计「剩余部分按位或 = total」的子序列数，再减。
3. 用 DP 记录「剩余部分按位或」的分布：`dp[mask]` 表示当前已选剩余元素按位或为 `mask` 的方案数，对每个 `nums[i]` 做 `dp[mask | nums[i]] += dp[mask]`。
4. 最终无效数 = `dp[total]`（含空集，空集按位或为 0，若 `total != 0` 不影响），答案 = `(2**n - 1 - dp[total]) % MOD`。

以 `nums = [1,2,3]` 为例：`total = 3`。DP 结束后 `dp[3]` 统计剩余部分按位或为 3 的方案，即移除后剩余仍为 3 的子序列；`2**3 - 1 = 7`，减去 `dp[3] = 4`（剩余 `[1,2,3]`、`[1,2]`、`[1,3]`、`[2,3]` 中按位或为 3 的对应移除方案），得 3，与示例一致。

```python
MOD = 10**9 + 7
total = 0
for x in nums:
    total |= x
dp = {0: 1}
for x in nums:
    ndp = dict(dp)
    for mask, cnt in dp.items():
        nm = mask | x
        ndp[nm] = (ndp.get(nm, 0) + cnt) % MOD
    dp = ndp
invalid = dp.get(total, 0)
ans = (pow(2, len(nums), MOD) - 1 - invalid) % MOD
```

## 复杂度
时间：O(n · 2^B)，B 为按位或状态数（≤20 位，实际不同 mask 远少于 2^B）。
空间：O(2^B) 存 dp 字典，B 由 `nums[i] ≤ 10^6` 决定（约 20 位）。

## 易错点
- 输入 `[8,8]`：若把「剩余部分按位或 = total」直接当无效，会漏掉空集情形；空集按位或为 0，当 `total != 0` 时 `dp[0]` 不计入 `dp[total]`，但若 `total == 0`（全 0 数组）需特判，本题 `nums[i] ≥ 1` 规避了。
- 输入 `[7,4,6]`：若用「移除子序列本身的按位或」做状态会算错方向；必须对**剩余部分**做按位或 DP，`dp[total]` 才是无效数，`2**n - 1 - dp[total]` 才是答案。

## 如果面试官追问
问：若 `nums[i]` 上限提到 `10^9`，状态数爆炸怎么办？
答：改用「按位或只有 O(log max) 种不同值」的压缩 DP，只保留可达 mask 集合，规模 O(n log max)。
