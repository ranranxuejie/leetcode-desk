## 一句话思路
用两个状态滚动 DP：`hold` 表示当前持股的最大现金，`free` 表示空仓的最大现金，每天按「卖/不卖、买/不买」转移。

## 怎么做
1. 初始化 `hold = -prices[0]`（第 0 天买入，现金为负），`free = 0`（不交易）。
2. 每天先更新 `free = max(free, hold + prices[i] - fee)`，即今天卖出或不卖。
3. 再更新 `hold = max(hold, free - prices[i])`，即今天买入或不买。
4. 返回 `free`，因为最后空仓一定不劣于持股。

以 `prices = [1, 3, 2, 8, 4, 9], fee = 2` 为例，第 3 天（`prices[3] = 8`）时 `hold = -1`，`free = max(0, -1 + 8 - 2) = 5`；随后 `hold = max(-1, 5 - 8) = -1`，说明这天不重新买入。到第 5 天 `free = max(5, -1 + 9 - 2) = 6`，但注意第 4 天 `hold` 已被更新为 `5 - 4 = 1`，所以第 5 天实际是 `free = max(5, 1 + 9 - 2) = 8`，与示例答案一致。

```python
hold, free = -prices[0], 0
for p in prices[1:]:
    free = max(free, hold + p - fee)
    hold = max(hold, free - p)
return free
```

关键点：`free` 必须先于 `hold` 更新，否则同一天会「先买后卖」白赚差价。

## 复杂度
时间 O(n)：遍历 `prices` 一次，每天常数次比较。
空间 O(1)：只维护 `hold`、`free` 两个变量，没有额外数组。

## 易错点
- 输入 `prices = [1, 3], fee = 2` → 若写成 `hold + p` 忘记减 `fee`，会得 2，正确是 `max(0, -1 + 3 - 2) = 0`，即这笔交易不划算就不做。
- 输入 `prices = [1, 3, 7, 5, 10, 3], fee = 3` → 若先更新 `hold` 再更新 `free`，第 2 天会用当天买入价算卖出，得 7 而非 6；正确顺序是先 `free` 后 `hold`。

## 如果面试官追问
问：若要求输出具体买卖日期？答：在 `free` 更新变大时记录卖出日 `i`，并回溯 `hold` 最后一次变大的买入日 `j`，成对存入结果。
