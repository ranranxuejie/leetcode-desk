## 一句话思路
按空格切分句子后逐词用 `startswith` 判断，第一个命中的词下标加一即为答案。

## 怎么做
1. 用 `sentence.split()` 切出单词列表，空格是单个的，切完不会出现空串。
2. 按下标 `i` 从 0 遍历单词列表，对每个 `word` 判断 `word.startswith(searchWord)`。
3. 命中就立即返回 `i + 1`，因为是从左往右扫，天然满足「最小下标」。
4. 循环结束仍未命中，返回 `-1`。

以示例 1 为例：`sentence = "i love eating burger"`，`searchWord = "burg"`。`split()` 得到 `["i", "love", "eating", "burger"]`。`i=0` 时 `"i".startswith("burg")` 为 `False`，`i=1`、`i=2` 同样为 `False`；`i=3` 时 `"burger".startswith("burg")` 为 `True`，返回 `3 + 1 = 4`。

```python
words = sentence.split()
for i, word in enumerate(words):
    if word.startswith(searchWord):
        return i + 1
return -1
```

关键点：`startswith` 要求 `searchWord` 是 `word` 的**前导**子串，`"burger".startswith("urg")` 是 `False`，所以不需要额外判断位置。示例 2 中 `"problem"` 在 `i=1` 和 `i=5` 都命中，循环在 `i=1` 就返回 `2`，不会走到 `i=5`。

## 复杂度
时间 O(L)，L 是 `sentence` 总长度，每个字符最多被 `split` 和 `startswith` 各扫一次。
空间 O(L)，`split()` 额外存了所有单词，最坏情况每个字符一个单词。

## 易错点
- 输入 `sentence = "i love eating burger"`、`searchWord = "burger"` 时，若用 `searchWord in word` 判断会误判 `"burg"` 这类子串；必须用 `startswith`，`"burger".startswith("urger")` 才是 `False`。
- 输入 `sentence = "hello"`、`searchWord = "hello"` 时，若返回 `i` 而不是 `i + 1` 会得到 `0`；题目要求下标从 1 开始，命中时返回 `i + 1`，未命中返回 `-1`，两者不能混用同一个基准。

## 如果面试官追问
若 `sentence` 长度到 10^6 且要多次查询不同 `searchWord`，怎么办？答：预处理建前缀树（Trie），每次查询沿树走 `len(searchWord)` 步，把重复扫描降到 O(|searchWord|)。
