## 一句话思路
枚举分界点，左边全留 a、右边全留 b，用前缀 b 计数和后缀 a 计数取最小删除量。

## 怎么做
1. 平衡串必形如 `a...ab...b`，即存在一个切点，切点左侧的 `b` 和右侧的 `a` 都得删。
2. 先统计整串 `a` 的总数 `total_a`，它等于切点在 0 号位左侧时的「右侧 a 数」。
3. 从左往右扫，维护 `b_left`（已扫过的 b 数）和 `a_right`（还没扫的 a 数），每步 `ans = min(ans, b_left + a_right)`。
4. 扫到字符 `a` 时 `a_right -= 1`，扫到 `b` 时 `b_left += 1`，注意先算答案再更新，或更新顺序与切点定义对齐。

以 `s = "aababbab"` 为例：`total_a = 4`。切点在第 2 个字符后（即 `"aa" | "babbab"`）时，`b_left = 0`、`a_right = 2`（右侧 `babbab` 里有 2 个 a），代价 2；切点在第 6 位后 `"aababb" | "ab"` 时 `b_left = 3`、`a_right = 1`，代价 4。最小值 2，与答案一致。

```python
total_a = s.count('a')
b_left = 0
a_right = total_a
ans = total_a          # 切点在最左：删掉所有 a
for ch in s:
    if ch == 'a':
        a_right -= 1
    else:
        b_left += 1
    ans = min(ans, b_left + a_right)
```

循环里 `ans` 的候选值就是「以当前位置为切点」的删除数，最后取全局最小。

## 复杂度
时间 O(n)：一次 `count` 加一次遍历，n 为 `len(s)`。
空间 O(1)：只开了 `total_a`、`b_left`、`a_right`、`ans` 四个整数。

## 易错点
- 输入 `"bbaaaaabb"` → 若只从「删 b」角度想，会漏掉删前缀两个 `b` 后剩 `"aaaaabb"` 仍含 `ba` 对；正确做法是切点枚举，切点在第 2 位后 `b_left = 2`、`a_right = 0`，代价 2 才是最优。
- 输入 `"aababbab"` → 若把切点定义成「切点字符归左」并先更新再算答案，会在 `a` 上多减一次 `a_right`，得到 1 这种偏小值；正确做法是每步先按当前 `b_left + a_right` 更新 `ans`，再根据 `ch` 调整计数。

## 如果面试官追问
要求输出具体删除的下标集合怎么办？答：记录取到最小值的切点位置 `k`，删掉 `s[:k]` 中所有 `b` 和 `s[k:]` 中所有 `a` 的下标即可，仍是 O(n)。
