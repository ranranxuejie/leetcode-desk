## 一句话思路
用计数数组 + 前缀和，按「分母值 v」分组，把商为 k 的分子区间 [k·v, (k+1)·v−1] 一次性整段求和，避免 O(n²) 枚举。

## 怎么做
1. 统计每个值出现次数 `cnt[v]`，并对 `cnt` 做前缀和 `pre`，使 `pre[r]-pre[l-1]` 是值落在 [l,r] 的个数。
2. 枚举分母值 `v`（只枚举 `cnt[v]>0` 的），对每个 `v` 枚举商 `k=1,2,...` 直到 `k*v > maxV`。
3. 对每个 k，分子区间是 `[k*v, min((k+1)*v-1, maxV)]`，该区间内每个分子贡献商 k，累加 `k * cnt[v] * (pre[hi]-pre[lo-1])`。
4. 商为 0 的项（分子 < 分母）贡献 0，直接跳过；最后对 `10**9+7` 取余。

以 `nums=[2,5,9]` 为例：`cnt[2]=cnt[5]=cnt[9]=1`，`maxV=9`。分母 v=2 时 k=1 区间 [2,3] 含 2 一个数，贡献 1·1·1=1；k=2 区间 [4,5] 含 5，贡献 2·1·1=2；k=4 区间 [8,9] 含 9，贡献 4·1·1=4。分母 v=5 时 k=1 区间 [5,9] 含 5、9 两个数，贡献 1·1·2=2。分母 v=9 时 k=1 区间 [9,9] 含 9，贡献 1。合计 1+2+4+2+1=10。

```python
MOD = 10**9 + 7
maxV = max(nums)
cnt = [0] * (maxV + 1)
for x in nums:
    cnt[x] += 1
pre = [0] * (maxV + 1)
for v in range(1, maxV + 1):
    pre[v] = pre[v - 1] + cnt[v]

ans = 0
for v in range(1, maxV + 1):
    if cnt[v] == 0:
        continue
    k = 1
    while k * v <= maxV:
        lo = k * v
        hi = min((k + 1) * v - 1, maxV)
        ans += k * cnt[v] * (pre[hi] - pre[lo - 1])
        k += 1
ans %= MOD
```

## 复杂度
时间：O(maxV · log maxV)，即 Σ maxV/v 的调和级数，maxV ≤ 10^5。
空间：O(maxV)，开了 `cnt` 和 `pre` 两个长度 maxV+1 的数组。

## 易错点
- 输入 `[7,7,7,7,7,7,7]`：若按「每个 i 对每个 j」双重循环会得 49 但超时；正确做法是 `cnt[7]=7`，v=7 时 k=1 区间 [7,7] 含 7 个，贡献 1·7·7=49，一次算完。
- 区间上界忘记 `min((k+1)*v-1, maxV)`：如 `nums=[2,5,9]`、v=2、k=4 时若写成 `(k+1)*v-1=9` 恰好没越界，但 v=5、k=1 时上界 9 也刚好；换成 `nums=[2,3]`、v=2、k=1 上界 3 未越界，而 k=2 时 `k*v=4>maxV=3` 循环已停——真正翻车在 `nums=[1,100000]` 这类：不截断会让 `pre[hi]` 下标越界报 IndexError，必须先 `min`。

## 如果面试官追问
问：若 nums 长度到 10^6 但值域仍 10^5 怎么办？
答：复杂度只由 maxV 决定，与 n 无关，n 变大只是建 `cnt` 多扫一遍，仍是 O(n + maxV log maxV)。
