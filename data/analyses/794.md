## 一句话思路
数 X/O 个数定轮次，再判胜负是否与轮次自洽：X 赢则 X 比 O 多 1，O 赢则两者相等。

## 怎么做
1. 统计 `cx = sum(row.count('X') for row in board)`、`co` 同理，先卡 `cx - co` 只能是 0 或 1。
2. 写 `win(ch)`：8 条线（3 行 3 列 2 对角）任一条三格都是 `ch` 即返回 `True`。
3. 若 `win('X')` 为真，要求 `cx == co + 1`；若 `win('O')` 为真，要求 `cx == co`。
4. 两者同时为真直接 `False`（一局不可能两人都赢）。

以示例 2 `["XOX"," X "," "]` 为例：`cx = 3`（第 0 行两个 + 第 1 行中间一个），`co = 1`，`cx - co = 2`，第 1 步就返回 `False`，不必进胜负判断。

```python
def win(ch):
    lines = [board[i] for i in range(3)]
    lines += [''.join(board[i][j] for i in range(3)) for j in range(3)]
    lines += [''.join(board[i][i] for i in range(3)),
              ''.join(board[i][2 - i] for i in range(3))]
    return any(l == ch * 3 for l in lines)

if cx - co not in (0, 1):
    return False
wx, wo = win('X'), win('O')
if wx and wo:
    return False
if wx:
    return cx == co + 1
if wo:
    return cx == co
return True
```

关键中间值：示例 3 `["XOX","O O","XOX"]` 中 `cx = 5`、`co = 4`，`win('X')` 检查 8 条线全不满足（主对角是 `X,O,X`），`win('O')` 也全不满足，落到最后 `return True`。

## 复杂度
时间 O(1)：棋盘固定 9 格，8 条线各查 3 格，与输入规模无关。
空间 O(1)：`lines` 最多 8 个长度 3 的字符串，常数级。

## 易错点
- 输入 `["XXX","OOO","   "]` → 只查个数会得 `cx = co = 3` 判 `True`，但两人同时成三 → 必须先判 `wx and wo` 直接 `False`。
- 输入 `["XXX","XOO","OO "]` → `cx = 4`、`co = 4`，个数差为 0 看似合法，但 X 已赢却和 O 同数（X 赢必须多 1）→ 用 `wx` 分支要求 `cx == co + 1` 拦下。

## 如果面试官追问
问：若棋盘放大到 N×N、连成 k 子算赢，怎么改？
答：统计仍 O(N²)，胜负改成滑窗扫每行每列两对角，O(N²)，不再有常数优势。
