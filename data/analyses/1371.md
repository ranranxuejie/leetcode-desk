## 一句话思路
用 5 位掩码记录每个元音出现次数的奇偶性，前缀掩码相同则中间子串各元音为偶数次，取最远下标差。

## 怎么做
1. 把 `a,e,i,o,u` 映射到第 0..4 位，遍历时遇到元音就 `mask ^= 1 << idx`，非元音不动。
2. 用字典 `first` 记录每个 `mask` 第一次出现的下标，初始化 `first = {0: -1}`（空前缀）。
3. 每步先查 `mask` 是否在 `first` 里：在则 `i - first[mask]` 更新答案；不在则记 `first[mask] = i`。
4. 顺序不能反：先查后记，否则 `i - i = 0` 会污染。

以 `s = "eleetminicoworoep"` 为例，走到下标 12（字符 `r`）时，`e,i,o` 各出现 2 次，`mask` 回到 0；`first[0] = -1`，长度 `12 - (-1) = 13`，正是答案 `"leetminicowor"`。

```python
vowel = {'a': 0, 'e': 1, 'i': 2, 'o': 3, 'u': 4}
first = {0: -1}
mask = ans = 0
for i, ch in enumerate(s):
    if ch in vowel:
        mask ^= 1 << vowel[ch]
    if mask in first:
        ans = max(ans, i - first[mask])
    else:
        first[mask] = i
```

## 复杂度
时间 O(n)：`n = len(s)`，每个字符做一次字典查询和一次异或。
空间 O(1)：`first` 最多 2^5 = 32 个键，与 n 无关。

## 易错点
- 初始化写成 `first = {}` 而非 `{0: -1}`：输入 `"bcbcbc"` 时 `mask` 全程为 0，却查不到，答案错成 0；正确做法是预置空前缀 `-1`，让 `i - (-1) = i + 1` 覆盖从 0 开始的子串。
- 先记 `first[mask] = i` 再算长度：输入 `"a"` 时 `mask` 变 1，若先记再查，`first[1] = 0`，长度算成 `0 - 0 = 0`；正确做法是先查后记，保证 `first` 存的是最早下标。

## 如果面试官追问
问：若要求返回具体子串而非长度？答：`first` 存下标，更新答案时同步记 `(first[mask]+1, i)`，最后切片即可。
