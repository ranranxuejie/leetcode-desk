## 一句话思路
用一次遍历维护「以 i 结尾的严格递增段长度」`run`，当 `run >= 2*k` 时说明存在两段相邻的 k 长递增子数组。

## 怎么做
1. 令 `run = 1`，从 `i = 1` 扫到 `n-1`，比较 `nums[i]` 与 `nums[i-1]`。
2. 若 `nums[i] > nums[i-1]` 则 `run += 1`，否则重置 `run = 1`。
3. 每次更新后检查 `run >= 2*k`，成立立即返回 `True`。
4. 扫完未命中返回 `False`。

关键中间值：示例 1 中 `nums = [2,5,7,8,9,2,3,4,3,1]`，`k = 3`。扫到下标 4 时 `run = 5`（2,5,7,8,9 连续递增），`2*k = 6`，5 < 6 不成立；扫到下标 7 时 `run = 3`（2,3,4），仍不成立。但注意下标 4 的 `run=5` 已覆盖 `[7,8,9]` 与 `[8,9,?]`——真正命中的是下标 2 起 `[7,8,9]` 和下标 5 起 `[2,3,4]` 这两段，它们各自独立递增，中间 `9 > 2` 断开。所以单靠 `run >= 2*k` 会漏判！正确判据是：存在某个位置 `i`，使得以 `i` 结尾的递增段长度 `>= k` 且以 `i+k` 结尾的递增段长度 `>= k`，即 `run[i] >= k and run[i+k] >= k`。

```python
run = [1] * len(nums)
for i in range(1, len(nums)):
    if nums[i] > nums[i-1]:
        run[i] = run[i-1] + 1
for i in range(k, len(nums)):
    if run[i] >= k and run[i-k] >= k:
        return True
return False
```

## 复杂度
时间：O(n)，一次遍历算 `run`、一次遍历判相邻，n 为 `len(nums)`。
空间：O(n)，额外开 `run` 数组存每个位置结尾的递增段长度。

## 易错点
1. 输入 `nums = [2,5,7,8,9,2,3,4,3,1], k = 3` → 若只用「`run >= 2*k` 就返回」会漏判，因为最长递增段只有 5 < 6，但答案应为 `True` → 正确做法是分别检查 `run[i] >= k and run[i-k] >= k`，允许两段被下降点隔开。
2. 输入 `nums = [1,2,3,4,4,4,4,5,6,7], k = 5` → 若把 `>=` 写成 `>` 判断递增，会把 `4,4` 当成递增，`run` 虚高 → 严格递增必须用 `nums[i] > nums[i-1]`，等号即断开，重置 `run = 1`。

## 如果面试官追问
问：能否 O(1) 空间？答：可以，只保留最近 k 个位置的 `run` 值，用长度 k 的循环数组滚动覆盖即可。
