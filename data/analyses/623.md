## 一句话思路
用 BFS 逐层下探到 depth-1 层，对每个节点插入两个 val 节点，depth==1 时新建根。

## 怎么做
1. depth==1 时直接返回 `TreeNode(val, root, None)`，原树挂到新根左子树。
2. 否则用队列从 root（第 1 层）开始逐层 BFS，每轮把当前层节点全部出队、子节点入队。
3. 当 `level == depth - 1` 时停止下探，对队列中每个 cur 做插入。
4. 插入时先存 `cur.left`、`cur.right`，再建两个 val 节点分别接回原左右子树。

以示例 1（root=[4,2,6,3,1,5], val=1, depth=2）为例：depth-1=1，队列初始只有 `[4]`，level 就是 1，直接对 4 插入——`cur.left=2` 存下，新建 `TreeNode(1, 2, None)` 挂到 4 左边，`cur.right=6` 同理，结果根为 4、左右各一个 1。

```python
if depth == 1:
    return TreeNode(val, root, None)
q, level = [root], 1
while level < depth - 1:
    q = [c for cur in q for c in (cur.left, cur.right) if c]
    level += 1
for cur in q:
    cur.left = TreeNode(val, cur.left, None)
    cur.right = TreeNode(val, cur.right, None)
return root
```

关键在 `TreeNode(val, cur.left, None)`：第二个参数把原左子树变成新节点的左孩子，第三个参数 `None` 保证新节点右孩子为空，原右子树由下一行接回。

## 复杂度
时间 O(n)：最坏遍历到 depth-1 层，节点数不超过 n。
空间 O(w)：队列最多存一层宽度 w，depth==1 时额外只开 1 个节点。

## 易错点
- depth 恰好等于树深+1（如示例 2 的 depth=3 落在叶子 3、1 下面）→ 若在 depth-1 层只处理非空 cur 却漏掉「叶子也要插」，会少插一层；正确做法是 depth-1 层所有非空节点都插，叶子插完新节点左右孩子为 None。
- depth==1 时直接对 root 插入 → 会把原树拆散成 root 的左右子树，丢掉「原树整体作为新根左子树」的语义；正确做法是单独分支返回 `TreeNode(val, root, None)`，不进入 BFS。

## 如果面试官追问
若 depth 可能大于树深+1 怎么办？答：题面保证 depth ≤ 树深+1，若放开则 BFS 到空队列即停，不插入直接返回 root。
