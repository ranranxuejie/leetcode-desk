## 一句话思路
三指针 DP：每个丑数由更小的丑数乘 3/5/7 得到，用 i3/i5/i7 指向尚未被乘过的位置，每次取最小值。

## 怎么做
1. 初始化 `dp = [1]`，三个指针 `i3 = i5 = i7 = 0`。
2. 循环 k-1 次，计算 `n3, n5, n7 = dp[i3]*3, dp[i5]*5, dp[i7]*7`，取 `m = min(n3, n5, n7)` 追加到 `dp`。
3. 哪个指针的乘积等于 `m` 就前进一格（用三个独立 `if`，不是 `elif`，避免重复值漏推进）。

以 k=5 为例，中间过程：`dp=[1]` → m=3，i3=1 → `dp=[1,3]` → m=5，i5=1 → `dp=[1,3,5]` → m=7，i7=1 → `dp=[1,3,5,7]` → 此时 `n3=dp[1]*3=9, n5=dp[1]*5=15, n7=dp[1]*7=21`，m=9，返回 `dp[4]=9`。

```python
dp = [1]
i3 = i5 = i7 = 0
for _ in range(k - 1):
    n3, n5, n7 = dp[i3] * 3, dp[i5] * 5, dp[i7] * 7
    m = min(n3, n5, n7)
    dp.append(m)
    if m == n3: i3 += 1
    if m == n5: i5 += 1
    if m == n7: i7 += 1
return dp[k - 1]
```

关键在三个 `if` 并列：当 m 同时等于 n3 和 n5（如 15 = 3×5 = 5×3）时，两个指针都要前进，否则 15 会被重复生成。

## 复杂度
时间 O(k)：循环 k-1 次，每次常数次比较。
空间 O(k)：dp 数组存 k 个数，三指针额外 O(1)。

## 易错点
- 输入 k=1 → 若循环写成 `range(k)` 会多算一个数返回 `dp[1]=3` 而非 1 → 循环必须是 `range(k-1)`，或直接特判返回 1。
- 输入 k 较大时出现重复值（如 15、45、105 同时是 3 和 5 的倍数）→ 若用 `elif` 只推进一个指针，下一轮会再次生成同一个数，dp 里出现重复且长度错位 → 三个 `if` 独立判断，`m == n3`、`m == n5`、`m == n7` 各自推进。

## 如果面试官追问
问：如果素因子集合变成任意给定的质数列表 primes，怎么改？
答：把三个指针换成 `len(primes)` 个指针数组，`min` 对全部乘积取最小，仍是 O(k·len(primes))。
