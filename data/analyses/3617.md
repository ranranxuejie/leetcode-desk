## 一句话思路
按学生按日期排序后，用「相邻日期差 ≤2 天」切连续段，再在每段里找最短重复周期。

## 怎么做
1. 每个学生按 `session_date` 升序排列，`session_date` 与上一条差 >2 天就断开成新段。
2. 对每个连续段，从 `k=3` 起枚举周期长度，检查 `subjects[i] == subjects[i-k]` 对所有 `i>=k` 成立，第一个成立的 `k` 即循环长度。
3. 要求段长 `>= 2*k`（两个完整周期）且 `k>=3`，取该学生所有合法段中 `k` 最大的（同 `k` 取总时长最大）。
4. 汇总 `total_study_hours = sum(hours_studied)`，按 `cycle_length` 降序、`total_study_hours` 降序输出。

以 Alice 为例：排序后日期 10-01..10-06 差均为 1 天，成一段，`subjects = [Math, Physics, Chemistry, Math, Physics, Chemistry]`。`k=3` 时 `subjects[3]==subjects[0]`、`subjects[4]==subjects[1]`、`subjects[5]==subjects[2]` 全成立，段长 6 = 2*3，`cycle_length=3`，`total=15.0`。

```python
for sid, rows in sessions.items():
    rows.sort(key=lambda r: r[2])
    segs, cur = [], [rows[0]]
    for r in rows[1:]:
        if (r[2] - cur[-1][2]).days > 2:
            segs.append(cur); cur = [r]
        else:
            cur.append(r)
    segs.append(cur)
    for seg in segs:
        subs = [r[1] for r in seg]
        for k in range(3, len(seg) // 2 + 1):
            if all(subs[i] == subs[i - k] for i in range(k, len(subs))):
                best = max(best, (k, sum(r[3] for r in seg)))
                break
```

## 复杂度
时间：O(S log S + S·K)，S 为该生记录数，排序占 S log S，周期枚举最坏 O(S·K)。
空间：O(S)，存排序后的段与学科列表。

## 易错点
- 把「间隔不超过 2 天」当成「恰好 1 天」：David 的 10-01 与 10-05 差 4 天必须断开，但若写成 `!= 1` 会把合法的隔天记录也切断，正确是 `> 2` 才断。
- 只检查前 `k` 个学科互不相同就认定周期：Carol 的 `[Biology, Chemistry, Biology, Chemistry]` 在 `k=2` 时成立，但 `k<3` 必须排除；且 `k` 要满足 `len(seg) >= 2*k`，否则 Alice 的 6 条记录在 `k=4` 时会被误判。

## 如果面试官追问
问：若允许周期内学科顺序循环移位（如 A,B,C,B,C,A）怎么办？
答：把段复制一份接在尾部，用 KMP 求最小循环节，再验证长度整除。
