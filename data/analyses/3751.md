## 一句话思路
用数位 DP 求 `[1, x]` 的波动值总和，答案 = `f(num2) - f(num1-1)`，逐位累加峰谷贡献。

## 怎么做
1. 把上界 `x` 拆成数位列表 `digits`，从高位到低位枚举每一位填什么。
2. 状态记 `(pos, prev2, prev1, tight, started)`：`prev2/prev1` 是前两位数字，`started` 标记是否已出现非零位（前导零不算数位）。
3. 在 `pos` 处枚举 `d`，若 `started` 且 `prev2` 存在，判断 `prev1` 是否为峰/谷：`(prev1 > prev2 and prev1 > d) or (prev1 < prev2 and prev1 < d)`，是则贡献 +1。
4. 递归返回「当前位之后所有填法的波动值总和」，用记忆化缓存非 `tight` 状态。

以 `num1 = 120, num2 = 130` 为例，算 `f(130) - f(119)`。处理 130 时，`pos=2` 填 `d=0`，此时 `prev2=1, prev1=3`，`3 > 1 and 3 > 0` 成立，`prev1=3` 是峰，贡献 +1；而 121 中 `prev2=1, prev1=2, d=1`，`2 > 1 and 2 > 1` 也成立，同样 +1。

```python
from functools import lru_cache

def f(x):
    if x < 100:
        return 0
    ds = list(map(int, str(x)))
    @lru_cache(None)
    def dfs(pos, p2, p1, tight, started):
        if pos == len(ds):
            return 0
        hi = ds[pos] if tight else 9
        total = 0
        for d in range(hi + 1):
            nt = tight and d == hi
            if not started and d == 0:
                total += dfs(pos + 1, -1, -1, nt, False)
            else:
                add = 1 if (p2 != -1 and ((p1 > p2 and p1 > d) or (p1 < p2 and p1 < d))) else 0
                total += add + dfs(pos + 1, p1, d, nt, True)
        return total
    return dfs(0, -1, -1, True, False)
```

## 复杂度
时间：`O(位数 × 10 × 10 × 10 × 2)`，位数最多 6，常数级。
空间：记忆化表存 `pos × p2 × p1 × tight × started` 个状态，约几千项。

## 易错点
- 输入 `num1 = 1, num2 = 99` → 若忘记「少于 3 位波动值为 0」直接进 DFS，会把两位数当峰谷算 → 正确做法是 `f(x)` 开头 `if x < 100: return 0`。
- 输入 `num1 = 100, num2 = 100` → 若把前导零当真实数位，`100` 的 `0` 会被误判为谷 → 正确做法是用 `started` 标记，前导零只传递 `-1` 不参与比较。

## 如果面试官追问
若 `num2` 放大到 `10^18` 呢？答：数位 DP 状态不变，位数从 6 变 19，记忆化表仍只有 `19×10×10×2×2` 量级，照样秒过。
