## 一句话思路
用 10 位掩码记录前缀各数字出现次数的奇偶性，相同掩码（或差一位）的两个前缀之间就是超赞子串。

## 怎么做
1. 前缀掩码 `mask` 每遇到数字 `d` 就异或 `1 << d`，把「各数字奇偶性」压成一个整数。
2. 哈希表 `first` 记录每个掩码**最早**出现的下标，初始化 `first[0] = -1`（空前缀）。
3. 遍历到下标 `i` 时，先查 `first[mask]` 更新答案；再枚举翻转某一位 `mask ^ (1 << d)`，若在表里也更新答案。
4. 若当前 `mask` 不在表里才写入 `i`，保证存的是最早位置。

以 `s = "3242415"` 为例：走到下标 4（字符 `'4'`）时，前缀 `"32424"` 的掩码回到 `0`，而 `first[0] = -1`，长度 `4 - (-1) = 5`，正是答案 `"24241"`。

```python
first = {0: -1}
mask = ans = 0
for i, ch in enumerate(s):
    mask ^= 1 << int(ch)
    if mask in first:
        ans = max(ans, i - first[mask])
    for d in range(10):
        t = mask ^ (1 << d)
        if t in first:
            ans = max(ans, i - first[t])
    if mask not in first:
        first[mask] = i
```

## 复杂度
时间：O(10n)，n 为 `len(s)`，每步枚举 10 个数字位。
空间：O(min(2^10, n))，哈希表最多存 1024 个掩码。

## 易错点
- 输入 `"00"` → 若忘记 `first[0] = -1`，下标 1 时 `mask` 回到 0 却查不到，答案错成 1；正确做法是初始化空前缀位置为 -1，得 `1 - (-1) = 2`。
- 输入 `"12345678"` → 若把翻转位的候选也写进 `first`，会把错误下标当起点；正确做法是只对原始 `mask` 做 `if mask not in first` 写入，翻转位只查不存。

## 如果面试官追问
若字符集扩到小写字母 26 个怎么办？答：掩码改 26 位，翻转枚举从 10 次变 26 次，复杂度 O(26n)，其余不变。
