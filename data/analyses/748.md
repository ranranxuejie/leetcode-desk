## 一句话思路
把 licensePlate 的字母压成 26 位计数表，再按 words 顺序扫，用「长度更短才替换」保住首次出现的最短词。

## 怎么做
1. 遍历 licensePlate，`c.isalpha()` 为真时把 `c.lower()` 计入 `need`，得到需求表。
2. 对 words 里每个 `w`，用 `Counter(w)` 或长度 26 的数组统计，逐字母比对 `need[i] <= cnt[i]`。
3. 全部满足时，若 `best is None or len(w) < len(best)` 才更新 `best`，用严格小于保证并列取先出现的。

以示例 1 为例：`licensePlate = "1s3 PSt"` 过滤后是 `s P S t`，小写化得 `need = {s:2, p:1, t:1}`。扫到 `"step"` 时 `cnt[s] = 1 < need[s] = 2`，直接判不合格；扫到 `"steps"` 时 `cnt = {s:2, t:1, e:1, p:1}` 全部达标，`best = "steps"`，长度 5。后面 `"stripe"`、`"stepple"` 都缺一个 s，不更新。

```python
need = [0] * 26
for c in licensePlate:
    if c.isalpha():
        need[ord(c.lower()) - 97] += 1

best = None
for w in words:
    cnt = [0] * 26
    for c in w:
        cnt[ord(c) - 97] += 1
    if all(need[i] <= cnt[i] for i in range(26)):
        if best is None or len(w) < len(best):
            best = w
```

## 复杂度
时间：O(len(licensePlate) + 26 * len(words) + 所有 words 字符总数)，26 是常数。
空间：O(1)，只开了两个长度 26 的计数数组。

## 易错点
- `licensePlate = "aBc 12c"` 若忘了 `c.lower()`，`'B'` 的 `ord` 是 66，减 97 得 -31，直接索引越界或错位；必须先小写再减 97。
- 示例 2 中 `"pest"`、`"stew"`、`"show"` 都含 s 且长度都是 4，若写成 `len(w) <= len(best)` 就会返回 `"show"`；必须用严格小于，才能保住 words 中第一个出现的 `"pest"`。

## 如果面试官追问
问：若 words 长度到 10^6、单词长度到 10^3，怎么优化？
答：预处理每个词的 26 位签名并缓存，或先按长度升序稳定排序 words，命中第一个即返回，省掉全量比对。
