## 一句话思路
先统计冲突位置数 `bad`，再看能否用「冲突位置之间互换」或「与好位置互换」消掉，答案由冲突值的计数决定。

## 怎么做
1. 遍历一遍，把 `nums[i] == forbidden[i]` 的下标记为冲突，记冲突总数 `bad`，同时统计每个冲突值 `nums[i]` 的出现次数 `cnt`。
2. 若 `bad == 0` 直接返回 0。
3. 对每个冲突值 `v`，若 `cnt[v] > bad - cnt[v]`，说明该值在冲突位置里占多数，无法靠冲突位置内部互换消化，必须借助好位置，此时需要额外一次交换。
4. 若不存在好位置（`bad == n`）且存在多数冲突值，返回 -1；否则答案 = `(bad + 1) // 2` 加上额外次数。

以示例 2 `nums=[4,6,6,5], forbidden=[4,6,5,5]` 为例：冲突下标是 0、1、2（`bad=3`），冲突值计数 `cnt={4:1,6:1,5:1}`，无多数值，答案 `(3+1)//2 = 2`，与输出一致。

```python
from collections import Counter
bad = 0
cnt = Counter()
for x, f in zip(nums, forbidden):
    if x == f:
        bad += 1
        cnt[x] += 1
if bad == 0:
    return 0
extra = 0
for v, c in cnt.items():
    if c * 2 > bad:
        if bad == len(nums):
            return -1
        extra = 1
return (bad + 1) // 2 + extra
```

## 复杂度
时间：O(n)，一次遍历统计冲突与计数，Counter 的键数不超过 n。
空间：O(n)，最坏情况下 `cnt` 存 n 个不同冲突值。

## 易错点
- 输入 `nums=[7,7], forbidden=[8,7]`：冲突值 7 计数 1，`bad=1`，`1*2 > 1` 成立且 `bad == n`，必须返回 -1；若漏判 `bad == n` 会错答 1。
- 输入 `nums=[1,1,2], forbidden=[1,2,1]`：冲突下标 0、2，`bad=2`，冲突值 1 计数 1、2 计数 1，无多数，答案 `(2+1)//2=1`；若直接返回 `bad` 会错成 2。

## 如果面试官追问
问：若要求输出具体交换方案怎么办？
答：先按上述公式定次数，再把多数冲突值与好位置配对交换，其余冲突位置两两互换即可。
