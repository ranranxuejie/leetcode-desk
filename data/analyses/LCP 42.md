## 一句话思路
对每个玩具，只需在它附近半径 `r + ri` 的网格里找圈心，用哈希分桶把 10^8 次比较降到近线性。

## 怎么做
1. 把每个圈心按 `(x // s, y // s)` 分桶，`s = 2 * r + 2`（大于任何玩具的搜索半径 `r + ri`，`ri <= 10`）。
2. 对每个玩具 `(xi, yi, ri)`，只查它所在桶及周围 8 个桶里的圈心。
3. 判定条件用平方比较：`(xj - xi)**2 + (yj - yi)**2 <= (r - ri)**2`，注意是 `r - ri` 不是 `r + ri`。
4. 命中即 `ans += 1` 并跳出，避免重复计数。

以示例 1 为例：`toys[0] = [3,3,1]`，`r = 2`，`s = 6`，桶键 `(0,0)`；圈心 `(4,3)` 也在 `(0,0)`。距离平方 `1 + 0 = 1`，阈值 `(2-1)**2 = 1`，`1 <= 1` 成立，套中。玩具 `[3,2,1]` 距离平方 `1 + 1 = 2 > 1`，不中，答案 1。

```python
s = 2 * r + 2
buckets = {}
for x, y in circles:
    buckets.setdefault((x // s, y // s), []).append((x, y))
ans = 0
for xi, yi, ri in toys:
    bx, by = xi // s, yi // s
    lim = (r - ri) ** 2
    for dx in (-1, 0, 1):
        for dy in (-1, 0, 1):
            for xj, yj in buckets.get((bx + dx, by + dy), ()):
                if (xj - xi) ** 2 + (yj - yi) ** 2 <= lim:
                    ans += 1
                    break
            else:
                continue
            break
        else:
            continue
        break
```

## 复杂度
时间：O((n + m) + 命中检查)，桶大小均摊常数，最坏退化 O(nm)。
空间：O(m)，哈希表存 m 个圈心坐标。

## 易错点
- 判定写成 `(r + ri)**2`：示例 1 中玩具 `[3,2,1]` 会被误判套中，答案变 2。正确是圈半径减玩具半径 `r - ri`，因为玩具要整体落在圈内。
- 桶边长取 `r` 而非 `2r + 2`：`ri` 最大 10，玩具搜索半径 `r + ri` 可能跨两个桶，只查 3×3 邻域会漏掉对角桶外的圈心，导致漏判。

## 如果面试官追问
若 `r` 和 `ri` 都放大到 10^9，桶边长 `2r + 2` 仍成立，但坐标除法要用 Python 整除处理负数；答案不变，只是桶数变少、桶内链表变长，需换 KD 树或按 x 排序后二分。
