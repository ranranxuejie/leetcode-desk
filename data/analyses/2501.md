## 一句话思路
把 nums 去重后放进集合，对每个数 x 沿 x*x 链查集合，取最长链；排序保证只从链头起算。

## 怎么做
1. 用 `set(nums)` 去重，重复值对链长没有贡献，反而会让同一元素被算两次。
2. 对集合中每个 x，若 `x` 的平方根不在集合里，它就是某条链的起点，从它开始向上跳。
3. 跳法：`cur = x*x`，只要 `cur in s` 就 `cur *= cur`、长度加一，越界（`cur > 10**5`）即停。
4. 全程维护最大值，最后 `max_len >= 2` 返回它，否则返回 -1。

以 `nums = [4,3,6,16,8,2]` 为例，`s = {2,3,4,6,8,16}`。从 2 起跳：`cur = 4` 在集合里，长度 2；`cur = 16` 在集合里，长度 3；`cur = 256` 不在，停。从 4 起跳会被跳过，因为 `int(4**0.5) = 2` 在集合里，4 不是链头。最终 `max_len = 3`。

```python
s = set(nums)
best = 1
for x in s:
    r = int(x ** 0.5)
    if r * r == x and r in s:
        continue          # 不是链头
    cur, length = x * x, 1
    while cur in s:
        length += 1
        cur *= cur
    best = max(best, length)
return best if best >= 2 else -1
```

判断链头时用 `r * r == x` 而不是只比 `int(x**0.5)`，避免浮点误差把 4 误判成非完全平方。

## 复杂度
时间 O(n log log M)：n 是去重后元素数，每条链长度受 M=10^5 限制，最多约 4 跳。
空间 O(n)：集合 s 存去重后的元素，无其他额外结构。

## 易错点
- 输入 `[4,4,16]` → 不去重时 4 被访问两次，若用「从每个元素起跳」的写法会重复计数或逻辑混乱 → 先 `set(nums)`，重复值只保留一份。
- 输入 `[2,4,16,256]` → 从 4 起跳也能得到长度 3，但若同时从 2 起跳会重复走同一条链，最坏退化成 O(n·链长) → 用「平方根不在集合里」筛出链头，保证每条链只走一次。

## 如果面试官追问
问：若 nums[i] 上限改成 10^18 怎么办？
答：链长仍只有约 6 跳（2→4→16→256→65536→…），但 `x*x` 会超 64 位，Python 无溢出问题，只需把越界判断改成 `cur > max(nums)` 提前停。
