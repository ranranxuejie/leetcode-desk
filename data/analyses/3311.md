## 一句话思路
按度数找角点，沿边逐行蛇形铺格：矩阵相邻当且仅当有边，故只需保证每步走的是真实邻边。

## 怎么做
1. 统计每个节点的度数 `deg`，最小度数的点必是角点（度数 2，n=2 时度数 1）。
2. 从角点出发，选一个邻居作为第二格，再找同时邻接两者的点作为下一行起点，确定列数 `w`。
3. 逐行蛇形填充：每行内沿当前节点的未用邻居走，行末换到下一行起点。
4. 用 `used` 集合防止回头。

以示例 3 为例：`deg[0]=3, deg[8]=2`，从 8 出发。8 的邻居是 6、7，选 6 作第二格；同时邻接 8 和 6 的点是 3，故 `w=3`。第一行填 `[8,6,3]`，第二行从 7 开始反向填 `[7,4,2]`，第三行 `[1,0,5]`。

```python
from collections import defaultdict
deg = defaultdict(int)
adj = defaultdict(list)
for u, v in edges:
    deg[u] += 1; deg[v] += 1
    adj[u].append(v); adj[v].append(u)
start = min(range(n), key=lambda x: deg[x])
# 选第二格和行宽
nbr = adj[start]
second = nbr[0]
w = 1 + sum(1 for x in adj[second] if x in adj[start])
# 蛇形填充
used = {start}
row = [start]
cur = start
for _ in range(w - 1):
    nxt = next(x for x in adj[cur] if x not in used)
    used.add(nxt); row.append(nxt); cur = nxt
```

## 复杂度
时间 O(n + m)，m 为边数，每条边至多被检查常数次。
空间 O(n + m)，邻接表和 `used` 集合各占一份。

## 易错点
- n=2 时 `edges=[[0,1]]`，两节点度数都是 1，没有度数 2 的角点 → 若硬找 `deg==2` 会越界 → 应特判 n=2 直接返回 `[[0,1]]`。
- 单行情形（如示例 2，`w=n`）→ 若按「每行换方向」逻辑会在行末找不到下一行起点而崩溃 → 应判断 `len(row)==n` 时直接结束，不做换行。

## 如果面试官追问
若图不是网格而是任意树，还能构造吗？答：不能，只有最大度数 ≤4 且满足网格约束的树才可构造，需先验证。
