## 一句话思路
逐行把矩阵压成直方图高度数组 `heights`，每行对它跑一次单调栈求最大矩形，取全局最大。

## 怎么做
1. 维护 `heights`，长度 `cols`，初值全 0；`matrix[i][j]=='1'` 时 `heights[j] += 1`，否则清零。
2. 每行更新完 `heights` 后，用单调递增栈求该直方图的最大矩形面积。
3. 栈存下标，出栈时高度 `h = heights[stack.pop()]`，宽度由新栈顶决定：`w = i - stack[-1] - 1`（栈空则 `w = i`）。
4. 末尾补一个哨兵高度 0（或循环到 `i == cols` 时清栈），保证栈内元素全部结算。

以示例 1 的 `matrix = ["10100","10111","11111","10010"]` 为例，处理到第 3 行 `"11111"` 时 `heights = [3,1,3,2,1]`；栈在 `j=4` 弹出 `j=3`（h=2），此时栈顶是 `j=1`，宽度 `4-1-1=2`，面积 4；继续弹出 `j=2`（h=3），栈顶 `j=1`，宽度 `4-1-1=2`，面积 6 —— 这就是最终答案 6。

```python
heights = [0] * cols
best = 0
for row in matrix:
    for j in range(cols):
        heights[j] = heights[j] + 1 if row[j] == '1' else 0
    stack = []
    for i in range(cols + 1):
        cur = heights[i] if i < cols else 0
        while stack and heights[stack[-1]] > cur:
            h = heights[stack.pop()]
            w = i if not stack else i - stack[-1] - 1
            best = max(best, h * w)
        stack.append(i)
```

## 复杂度
时间：O(rows × cols)，每行每个格子入栈出栈各一次。
空间：O(cols)，`heights` 与栈各占一列长度，与行数无关。

## 易错点
- `matrix = []` 时若先写 `cols = len(matrix[0])` 会直接 IndexError；正确做法是先判空返回 0，再取 `cols`。
- 忘记末尾哨兵：若某行 `heights` 单调递增（如 `"11111"` 得 `[1,1,1,1,1]`），栈内元素永不弹出，面积漏算；正确做法是循环到 `i == cols` 时用 `cur = 0` 强制清栈。

## 如果面试官追问
问：要求返回矩形坐标而非面积怎么办？
答：栈里同时存 `(start_index, height)`，出栈时记录 `(top, left, h, w)`，最后按最大面积反查四个边界即可。
