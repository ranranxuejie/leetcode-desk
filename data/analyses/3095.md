## 一句话思路
用滑动窗口维护窗口内 OR 值，因为 OR 只增不减，右扩到满足 k 后左缩即可找到最短。

## 怎么做
1. 右指针 `r` 遍历 `nums`，把 `nums[r]` 并入窗口 OR 值 `cur`。
2. 当 `cur >= k` 时，用 `r - l + 1` 更新答案，然后尝试左移 `l`。
3. 左移的关键：OR 不可逆，不能直接 `cur ^= nums[l]`，必须重新计算窗口 OR。
4. 因为 `nums[i] <= 50`（6 位），窗口内不同 OR 值最多 6 种，重算代价可控。

以 `nums = [2,1,8], k = 10` 为例：`r=0` 时 `cur=2`；`r=1` 时 `cur=2|1=3`；`r=2` 时 `cur=3|8=11 >= 10`，答案暂为 3。左移 `l=0` 后重算 `1|8=9 < 10`，停止，最终返回 3。

```python
n = len(nums)
ans = n + 1
l = 0
cur = 0
for r in range(n):
    cur |= nums[r]
    while cur >= k:
        ans = min(ans, r - l + 1)
        l += 1
        cur = 0
        for i in range(l, r + 1):
            cur |= nums[i]
return ans if ans <= n else -1
```

注意 `k = 0` 时任何非空子数组都满足（OR 值 ≥ 0），`while` 第一次进入就更新为 1，直接返回 1。

## 复杂度
时间：O(n²)，每个 `r` 最多重算窗口 OR 一次，n ≤ 50 足够。
空间：O(1)，只开了 `l`、`r`、`cur`、`ans` 四个变量。

## 易错点
- `nums = [1,2], k = 0` → 若在循环前特判 `k == 0` 返回 0，会错成 0；正确做法是让 `while cur >= k` 自然处理，返回 1（非空子数组）。
- `nums = [2,1,8], k = 10` → 若左移时用 `cur ^= nums[l]` 撤销，`11 ^ 2 = 9` 看似对，但 `nums = [3,3], k = 3` 时 `3 ^ 3 = 0` 会漏掉第二个 3 仍在窗口；正确做法是左移后从头重算 `cur`。

## 如果面试官追问
若 n 放大到 10^5 怎么办？答：用「按位贡献」记录每个 bit 最近出现位置，取所有 bit 位置最小值即为最短窗口右端，O(n log V)。
