## 一句话思路
冠军是唯一「没有输过」的队伍，即第 c 列全为 0，扫列即可。

## 怎么做
1. 对每个候选队伍 c，检查 grid[i][c] 是否全为 0。
2. 一旦发现某个 i 使 grid[i][c] == 1，说明 c 输给 i，c 不是冠军，直接换下一个 c。
3. 找到第一个整列全 0 的 c 就返回。

以示例 2 `grid = [[0,0,1],[1,0,1],[0,0,0]]` 为例：c=0 时，i=1 处 `grid[1][0] == 1`，0 队输给 1 队，淘汰；c=1 时，`grid[0][1]=0`、`grid[2][1]=0`，整列全 0，返回 1。

```python
n = len(grid)
for c in range(n):
    ok = True
    for i in range(n):
        if grid[i][c] == 1:
            ok = False
            break
    if ok:
        return c
```

注意 `grid[c][c] == 0` 是题面保证的，所以内层循环不必跳过 i == c，不会误判。

## 复杂度
时间：O(n²)，最坏要扫完 n 列、每列 n 行。
空间：O(1)，只用了 c、i、ok 三个变量。

## 易错点
- 把方向搞反，去查第 c 行而不是第 c 列：示例 2 中第 0 行是 `[0,0,1]`，含 1 会被误判成「0 队不是冠军」而漏掉正确答案；正确做法是固定列 c、遍历行 i，看 `grid[i][c]`。
- 以为要统计每队胜场数再取最大：示例 2 里 1 队胜 2 场、0 队胜 1 场看似可行，但题面只保证偏序传递，胜场数并非唯一判据；直接找全 0 列才是定义本身。

## 如果面试官追问
追问：如果矩阵不再保证传递性（可能出现环），还能这样找吗？
答：不能，全 0 列可能不存在，需先判环或改用拓扑排序找入度为 0 的点。
