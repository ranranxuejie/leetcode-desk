## 一句话思路
末位元素只有「换」与「不换」两种终局，各枚举一次，其余下标贪心判断能否不超两个末位值。

## 怎么做
1. 记 `a = nums1[-1]`、`b = nums2[-1]`，终局只有两种：末位不换（`nums1[-1]=a, nums2[-1]=b`）或末位交换（`nums1[-1]=b, nums2[-1]=a`）。
2. 对每种终局，设 `x = nums1[-1]`、`y = nums2[-1]`，遍历 `i in range(n-1)`，统计必须交换的下标数。
3. 下标 `i` 若 `nums1[i] <= x and nums2[i] <= y`，不换即可；否则若 `nums2[i] <= x and nums1[i] <= y`，必须换一次；两者都不满足则该终局无解。
4. 两种终局取较小值，都无解返回 `-1`。

以示例 2 为例，`nums1=[2,3,4,5,9]`、`nums2=[8,8,4,4,4]`。终局「不换」：`x=9, y=4`，`i=0` 时 `nums1[0]=2<=9` 但 `nums2[0]=8>4`，只能换，`nums2[0]=8<=9 and nums1[0]=2<=4` 成立，计数 1；`i=3` 同理计数 2；`i=4` 是末位不参与。终局「交换」：`x=4, y=9`，`i=0` 时 `nums2[0]=8>4` 且 `nums1[0]=2<=4`，换后 `nums2[0]=8<=9` 成立，计数 1；`i=1` 同样计数 2；`i=2` 时 `nums1[2]=4<=4 and nums2[2]=4<=9` 不换；`i=3` 时 `nums1[3]=5>4`，换后 `nums2[3]=5<=9` 成立，计数 3。取小得 2。

```python
def solve(nums1, nums2):
    n = len(nums1)
    ans = n + 1
    for swap_last in (False, True):
        x, y = (nums2[-1], nums1[-1]) if swap_last else (nums1[-1], nums2[-1])
        cnt = 1 if swap_last else 0
        ok = True
        for i in range(n - 1):
            if nums1[i] <= x and nums2[i] <= y:
                continue
            if nums2[i] <= x and nums1[i] <= y:
                cnt += 1
            else:
                ok = False
                break
        if ok:
            ans = min(ans, cnt)
    return -1 if ans > n else ans
```

## 复杂度
时间：O(n)，两种终局各扫一遍，n 为数组长度。
空间：O(1)，只用了 `x`、`y`、`cnt`、`ok` 几个标量。

## 易错点
- 把末位下标 `n-1` 也放进循环判断：示例 1 中 `i=2` 时 `nums1[2]=7 > x=7` 不成立会误判无解，正确做法是循环只到 `n-2`，末位由 `swap_last` 直接决定。
- 终局「交换」时忘记把末位那次操作计入 `cnt`：示例 1 交换末位后 `x=3, y=7`，若 `cnt` 从 0 起算会返回 0，正确做法是 `swap_last=True` 时 `cnt` 初值为 1。

## 如果面试官追问
问：若要求输出具体交换的下标集合怎么办？
答：在循环里把「必须换」的 `i` 追加进列表，末位交换时再追加 `n-1`，两种终局各存一份取短者。
