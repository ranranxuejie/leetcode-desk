## 一句话思路
用状态 DP 记录当前列被填满/缺一格，托米诺跨列导致缺口状态转移。

## 怎么做
1. 定义 `dp[i]` 为铺满前 `i` 列的方法数，`dp[0]=1`。
2. 递推式：`dp[i] = 2*dp[i-1] + dp[i-3]`（`i>=3`），因为末尾可用一块竖多米诺、两块横多米诺、或一对托米诺组合。
3. 以 `n=3` 验证：`dp[1]=1`，`dp[2]=2`，`dp[3]=2*2+1=5`，与示例一致。
4. 取模 `10**9+7`。

```python
MOD = 10**9 + 7
dp = [0] * (n + 1)
dp[0] = 1
for i in range(1, n + 1):
    dp[i] = dp[i - 1]
    if i >= 2:
        dp[i] += dp[i - 2]
    if i >= 3:
        dp[i] += dp[i - 3]
    dp[i] %= MOD
return dp[n]
```

## 复杂度
时间：O(n)，单层循环遍历 `1..n`。
空间：O(n)，`dp` 数组长度 `n+1`。

## 易错点
- `n=1` 时若直接套 `dp[i-3]` 会越界 → 需加 `i>=3` 判断，正确做法是初始化 `dp[0]=1` 并逐项判断边界。
- `n=2` 时若漏掉两块横多米诺的情况 → 会得 1 而非 2，正确做法是递推中 `i>=2` 时加 `dp[i-2]`。

## 如果面试官追问
问：能否 O(1) 空间？答：只需保留最近三个 `dp` 值滚动更新即可。
