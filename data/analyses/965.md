## 一句话思路
用根节点的值当基准，DFS 逐点比对，任一节点值不等于基准即返回 `False`。

## 怎么做
1. 取 `root.val` 存为 `target`，空树按题意不存在，节点数至少 1。
2. 从 `root` 开始 DFS，每到一个节点先比 `node.val != target`，不等就立刻返回 `False`。
3. 递归左右子树，用 `and` 连接，任一子树返回 `False` 整体即 `False`。
4. 以示例 2 `[2,2,2,5,2]` 为例：`target = 2`，走到左子树的左孩子 `5` 时 `5 != 2` 成立，直接返回 `False`，不再访问 `5` 的兄弟节点。

```python
def dfs(node):
    if node is None:
        return True
    if node.val != target:
        return False
    return dfs(node.left) and dfs(node.right)

target = root.val
return dfs(root)
```

关键中间值：示例 2 中 `target=2`，访问到值 `5` 的节点时判定失败，`dfs` 返回 `False` 沿调用链一路上传。

## 复杂度
时间 O(n)：每个节点最多访问一次，n 为节点数。
空间 O(h)：递归栈深度等于树高 h，最坏链状树 h=n。

## 易错点
- 输入 `[1,1,1,1,1,None,1]` → 若把 `None` 当节点去取 `.val` 会抛异常 → 正确做法是入口先判 `node is None` 返回 `True`，空孩子不参与比较。
- 输入 `[2,2,2,5,2]` → 若只比较父子节点（`node.val == node.left.val`）会漏掉跨层不同值，或写成只查左子树 → 正确做法是固定 `target=root.val` 与每个节点比，左右子树都要递归。

## 如果面试官追问
问：节点数放大到 10^6 且树退化成链，递归会栈溢出怎么办？
答：改成显式栈的迭代 DFS，把待访问节点压栈，空间仍是 O(h) 但不吃 Python 递归深度限制。
