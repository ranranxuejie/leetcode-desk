## 一句话思路
按值分组记录已出现下标，对每个新下标 j 只与同值的旧下标 i 配对，检查 `(i*j) % k == 0`。

## 怎么做
1. 用字典 `seen` 把值映射到它已出现过的下标列表。
2. 从左到右遍历 `j, x = enumerate(nums)`，先取 `seen.get(x, [])` 里的旧下标。
3. 对每个旧下标 `i` 判断 `(i * j) % k == 0`，成立则 `ans += 1`。
4. 把 `j` 追加进 `seen[x]`，保证只统计 `i < j`。

以 `nums = [3,1,2,2,2,1,3], k = 2` 为例：走到 `j = 4`（`nums[4] = 2`）时，`seen[2] = [2, 3]`，`2*4 = 8`、`3*4 = 12` 都能被 2 整除，`ans` 从 2 涨到 4；随后 `j = 6` 时 `seen[3] = [0]`，`0*6 = 0` 也整除，最终得 4。

```python
seen = {}
ans = 0
for j, x in enumerate(nums):
    for i in seen.get(x, []):
        if (i * j) % k == 0:
            ans += 1
    seen.setdefault(x, []).append(j)
return ans
```

关键点：`i * j` 里 `i` 是旧下标、`j` 是新下标，顺序不能反着写进 `seen` 之后再查，否则同一对会被算两次。

## 复杂度
时间 O(n²)：最坏所有元素相同，每个 j 扫一遍旧下标列表。
空间 O(n)：`seen` 存下每个值的全部下标，共 n 个。

## 易错点
- 输入 `nums = [2,2,2], k = 1`：若在遍历中先 `append(j)` 再查列表，会把自己和自己配对，得到 6 而不是 3。正确做法是先查旧列表、后追加。
- 输入 `nums = [3,1,2,2,2,1,3], k = 2` 中 `i = 0`：`0 * 6 = 0`，`0 % 2 == 0` 成立，必须计入；若写成 `i * j != 0 and ...` 会漏掉含下标 0 的数对。

## 如果面试官追问
问：n 放大到 10⁵ 怎么办？
答：按 `i % k` 的余数分组统计同值下标，只配对余数乘积为 0 的组合，避免全量两两比较。
