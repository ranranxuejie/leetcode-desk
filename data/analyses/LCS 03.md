## 一句话思路
从所有 `"0"` 出发做多源 BFS，把与走廊连通的格子标记掉，剩下的连通块里取最大面积。

## 怎么做
1. 把边界外一圈视为走廊：先把所有 `grid[i][j] == "0"` 的坐标入队，同时把边界上的非零格也当作「贴着外侧走廊」入队（或直接在 BFS 时把越界邻居当走廊处理）。
2. 多源 BFS 向四方向扩散，只走非 `"0"` 且未访问的格子，标记 `bad[i][j] = True`，表示该主题空间与走廊直接相邻。
3. 再遍历一遍矩阵，对每个 `not bad` 且未统计的格子做一次 DFS/BFS 求连通块面积，取最大值。

以 `grid = ["110","231","221"]` 为例：`"0"` 只有 `(0,2)`，BFS 从它出发只能吃到 `(1,2)='1'`，标记 `bad[1][2]=True`；边界格 `(0,0)='1'`、`(0,1)='1'`、`(2,0)='2'`、`(2,1)='2'` 也入队，于是 `(0,0)(0,1)` 这块面积 2 的 `"1"` 和左下 `"22"` 都被判为相邻走廊。剩下只有 `(1,0)='2'` 与 `(1,1)='3'` 两块，各面积 1，答案 1。

```python
from collections import deque
R, C = len(grid), len(grid[0])
bad = [[False]*C for _ in range(R)]
q = deque()
for i in range(R):
    for j in range(C):
        if grid[i][j] == "0" or i in (0, R-1) or j in (0, C-1):
            if grid[i][j] != "0":
                bad[i][j] = True
            q.append((i, j))
while q:
    i, j = q.popleft()
    for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
        x, y = i+di, j+dj
        if 0 <= x < R and 0 <= y < C and not bad[x][y] and grid[x][y] != "0":
            bad[x][y] = True
            q.append((x, y))
```

## 复杂度
时间：O(R·C)，每个格子最多被 BFS 和统计各访问一次。
空间：O(R·C)，`bad` 矩阵加队列，最坏全是走廊时队列装 R·C 个坐标。

## 易错点
- 只把 `"0"` 入队、忘了边界外是走廊：`["11","11"]` 这种全非零矩阵会被判成面积 4，实际四边都贴外侧走廊，答案应为 0。正确做法是把 `i in (0,R-1) or j in (0,C-1)` 的非零格一起标 `bad`。
- 用 `bad` 标记后直接拿它当访问数组做面积统计：`bad` 为 `True` 的格子被跳过是对的，但统计连通块时若复用同一个 `visited` 又没区分「已判相邻」和「已统计」，会把同一块算两次。正确做法是统计阶段单独用 `seen` 或直接把统计过的格子改成 `"0"`。

## 如果面试官追问
问：如果要求返回最大面积那块空间的坐标范围怎么办？
答：统计连通块时顺带记录 `min_i, max_i, min_j, max_j`，面积最大时保存这四个值即可。
