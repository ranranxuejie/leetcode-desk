## 一句话思路
用两个变量滚动保存 F(n-1) 和 F(n-2)，每步取模 1000000007，O(n) 时间 O(1) 空间。

## 怎么做
1. 特判 `n < 2` 直接返回 `n`，因为 F(0)=0、F(1)=1 与下标值相同。
2. 令 `a, b = 0, 1` 分别代表 F(0)、F(1)，循环从 `i = 2` 到 `n`。
3. 每轮执行 `a, b = b, (a + b) % 1000000007`，`b` 始终是当前 F(i)。
4. 循环结束返回 `b`。

以 `n = 4` 为例：初始 `a=0, b=1`；i=2 时 `a=1, b=1`（F(2)=1）；i=3 时 `a=1, b=2`（F(3)=2）；i=4 时 `a=2, b=3`，返回 3，与示例一致。关键中间值是 i=3 那轮的 `b=2`，它同时成为下一轮的 `a`。

```python
def fib(n):
    if n < 2:
        return n
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, (a + b) % 1000000007
    return b
```

注意取模放在 `(a + b)` 外面而不是 `a`、`b` 各自取模后再加，两者等价但前者少一次运算；`a` 本身已在上一轮取过模，所以 `a + b` 最大约 2e9，Python 无溢出问题。

## 复杂度
时间：O(n)，循环执行 n-1 次，每次常数次加法与取模。
空间：O(1)，只开 `a`、`b` 两个变量，无数组无递归栈。

## 易错点
- 输入 `n = 0` → 若循环写成 `for i in range(2, n+1)` 而不特判，会直接返回 `b = 1`，错成 F(0)=1；正确做法是先 `if n < 2: return n`，让 n=0 返回 0、n=1 返回 1。
- 输入 `n = 100` → 若忘记取模，F(100)=354224848179261915075 远超题目要求，返回巨大整数而非模 1000000007 后的值；正确做法是每轮对 `(a + b)` 取模，不能只在最后取一次（虽然数学上等价，但中间值会膨胀，且不符合题目「计算初始结果」的语义）。

## 如果面试官追问
问：n 扩大到 10^18 怎么办？
答：用矩阵快速幂 [[1,1],[1,0]]^n，O(log n) 时间，取模在矩阵乘法每步做。
