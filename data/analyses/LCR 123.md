## 一句话思路
先顺序遍历链表把值 append 进数组，再原地双指针反转，避免额外建链表。

## 怎么做
1. 用 `cur = head` 顺序走链表，把每个 `cur.val` 追加到 `res`。
2. 走完后 `res` 是正序 `[3,6,4,1]`，与目标相反。
3. 用 `i=0, j=len(res)-1` 双指针交换，直到 `i >= j`。
4. 返回 `res`。

关键中间值：以 `head = [3,6,4,1]` 为例，遍历后 `res = [3,6,4,1]`；第一次交换 `res[0]` 与 `res[3]` 得 `[1,6,4,3]`，第二次交换 `res[1]` 与 `res[2]` 得 `[1,4,6,3]`，此时 `i=2, j=1` 退出。

```python
res = []
cur = head
while cur:
    res.append(cur.val)
    cur = cur.next

i, j = 0, len(res) - 1
while i < j:
    res[i], res[j] = res[j], res[i]
    i += 1
    j -= 1
return res
```

也可以省掉第二段循环，直接 `res[::-1]` 或遍历时 `res.insert(0, cur.val)`，但 `insert(0, ...)` 每次搬移整个列表，长度 10000 时是 O(n²)，不推荐。

## 复杂度
时间 O(n)：遍历链表 n 次，双指针交换 n/2 次。
空间 O(n)：`res` 存 n 个节点值；双指针只用了 `i, j` 两个变量。

## 易错点
- 输入 `head = []`（长度 0）→ 若先写 `res[0]` 或假设 `head.val` 存在会抛异常 → 正确做法是 `while cur:` 天然跳过，`len(res)-1 = -1`，`i=0 < j=-1` 不成立，直接返回 `[]`。
- 输入 `head = [3,6,4,1]` → 若用 `res.insert(0, cur.val)` 反转，结果虽对但每次插入搬移整个列表，10000 个节点退化成 O(n²) → 正确做法是先 append 再双指针交换或切片反转，保持 O(n)。

## 如果面试官追问
追问：不允许额外开数组，怎么原地反转？
答：用 `prev=None`，逐个把 `cur.next` 指向 `prev`，三个指针滚动，最后返回 `prev`，空间 O(1)。
