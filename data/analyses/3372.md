## 一句话思路
对两棵树各做一次全源 BFS 得到距离矩阵，答案 = 第一棵树内 ≤k 的节点数 + 第二棵树内 ≤k-1 的节点数最大值。

## 怎么做
1. 对树 1 每个节点跑 BFS，得 `d1[i][j]`；对树 2 每个节点跑 BFS，得 `d2`。
2. 预处理 `cnt2[x] = #{v : d2[x][v] <= k-1}`，取 `best2 = max(cnt2)`。
3. 对每个 i，`ans[i] = #{j : d1[i][j] <= k} + best2`。

以示例 1 为例，k=2，树 2 中节点 4 的 1 步内邻居是 {1,4,5,6}、2 步内再加 {0,2}，共 6 个，`cnt2[4]=6` 是最大值。树 1 中节点 0 的 2 步内节点是 {0,1,2,3,4} 共 5 个，`ans[0]=5+6=11`？不对——注意 k=2 时第二棵树只能用 k-1=1 步，`cnt2[4]` 应为 1 步内 4 个，`ans[0]=5+4=9`，与输出吻合。

```python
from collections import deque
def bfs_all(adj, n):
    d = [[-1]*n for _ in range(n)]
    for s in range(n):
        d[s][s] = 0; q = deque([s])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if d[s][v] < 0:
                    d[s][v] = d[s][u] + 1; q.append(v)
    return d
```

关键点：新边只贡献「从 i 走到连接点，再进第二棵树」的路径，长度上限是 k，所以第二棵树内部可用的步数是 k-1，不是 k。

## 复杂度
时间：O(n² + m²)，两棵树各做 n/m 次 BFS，每次 O(n) 或 O(m)。
空间：O(n² + m²)，存两张距离矩阵，无其他大开销。

## 易错点
- k=0 时第二棵树步数上限是 -1，`cnt2` 全为 0，答案退化为第一棵树内距离 0 的节点数（即 1）。若写成 `k` 而非 `k-1`，示例 2 的 k=1 会输出 7 而不是 6。
- 连接点必须取第二棵树中 `cnt2` 的最大值，而不是固定连 0 号节点。示例 1 中若固定连节点 0，`cnt2[0]` 只有 3，`ans[0]` 会算成 8 而非 9。

## 如果面试官追问
问：n、m 放大到 1e5 怎么办？
答：改用树形 DP 求每个节点 k 步内节点数（换根 + 深度分层），O(n log n) 或 O(nk) 视 k 而定。
