## 一句话思路
枚举删除位置，把问题化成「删掉一个字符后剩下的串是否回文」，用中心扩展一次扫完所有候选。

## 怎么做
1. 关键观察：准回文串删掉一个字符后必是回文，所以它的形态是「回文 + 中间夹一个多余字符 + 回文」，即存在中心 `(i, j)` 使 `s[i] != s[j]` 时只允许一侧多走一步。
2. 对每个中心（奇数中心 `i==i`、偶数中心 `i, i+1`）向两侧扩展，维护 `used` 标记是否已用掉那次删除。
3. 以 `s = "abca"` 为例：中心取 `(0,3)`，`s[0]='a' == s[3]='a'` 继续；`(1,2)` 处 `s[1]='b' != s[2]='c'`，此时 `used=False`，删掉 `c` 让 `j` 左移到 1，`s[1]=='b'` 匹配，长度记为 4。
4. 每个中心取最大长度更新答案；注意长度至少为 2（提示保证 `len(s) >= 2`）。

```python
def expand(l, r):
    used = False
    while l >= 0 and r < n:
        if s[l] == s[r]:
            l -= 1; r += 1
        elif not used:
            used = True
            # 试删左或删右，取能继续的那个
            if l + 1 <= r and s[l+1] == s[r]:
                l += 1
            else:
                r -= 1
        else:
            break
    return r - l - 1
```

上面这段是核心；外层对 `i in range(n)` 分别调 `expand(i, i)` 和 `expand(i, i+1)`，取 `max`。注意删左/删右要真的判断哪边能匹配，不能无脑选一边。

## 复杂度
时间：O(n²)，n 个中心各扩展 O(n)，n = len(s) ≤ 2500。
空间：O(1)，只用 `l, r, used` 几个变量，无额外数组。

## 易错点
- 输入 `"abba"`：若在 `(1,2)` 处 `s[1]='b' != s[2]='b'` 误判为不等（实际相等），会提前用掉删除机会，答案错成 3；正确是先判 `==` 再考虑删除。
- 输入 `"abcba"` 这类本身回文的串：若 `used` 逻辑写成「必须删一次」，会把长度 5 错算成 4；正确是允许不删，`used` 只是上限而非必须。

## 如果面试官追问
问：若要求返回具体子串而非长度？答：在 `expand` 里记录当前 `l, r` 边界，更新答案时同步存 `(l+1, r-1)` 即可。
