## 一句话思路
按二进制 1 的个数把数组切成若干连续段，段内可任意重排，只需检查每段排序后是否与全局有序的对应位置一致。

## 怎么做
1. 对每个 `nums[i]` 算 `popcount`，相邻且 `popcount` 相同的元素属于同一段（段内可任意交换，段间不能跨越）。
2. 把每段单独排序，拼回数组。
3. 检查拼回的数组是否非降序。

以 `nums = [8,4,2,30,15]` 为例：`popcount` 为 `[1,1,1,4,4]`，切成两段 `[8,4,2]` 和 `[30,15]`。第一段排序得 `[2,4,8]`，第二段得 `[15,30]`，拼回 `[2,4,8,15,30]`，非降序，返回 `True`。

```python
def canSortArray(nums):
    res = []
    i, n = 0, len(nums)
    while i < n:
        j = i
        while j + 1 < n and nums[j + 1].bit_count() == nums[i].bit_count():
            j += 1
        res.extend(sorted(nums[i:j + 1]))
        i = j + 1
    return all(res[k] <= res[k + 1] for k in range(len(res) - 1))
```

关键点：段边界由 `bit_count()` 是否相等决定，不是由数值大小决定。`30` 和 `15` 的 `popcount` 都是 4，所以它们同段可交换；`2` 和 `30` 的 `popcount` 分别是 1 和 4，不能跨段交换。

## 复杂度
时间：O(n log n)，每段排序贡献 log n，切段扫描贡献 n。
空间：O(n)，`res` 存重排结果，`sorted` 切片额外开段内数组。

## 易错点
- 输入 `[3,16,8,4,2]`：`popcount` 为 `[2,1,1,1,1]`，第一段只有 `[3]`，后面 `[16,8,4,2]` 排序成 `[2,4,8,16]`，拼回 `[3,2,4,8,16]` 不非降序，返回 `False`。若误以为全局可任意交换会错判成 `True`。
- 输入 `[8,4,2,30,15]`：若只比较相邻元素 `popcount` 是否相同就交换，而不做段内完整排序，可能漏掉 `8` 和 `2` 这种隔着 `4` 的同段交换，导致误判 `False`。正确做法是先确定整段边界再排序。

## 如果面试官追问
问：如果要求输出具体交换方案怎么办？
答：对每段做冒泡排序，每次相邻交换都满足 `popcount` 相同，记录交换下标对即可。
