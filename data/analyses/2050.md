## 一句话思路
按拓扑序递推 `finish[v] = max(finish[u]) + time[v-1]`，答案是所有 `finish` 的最大值。

## 怎么做
1. 建 `adj` 邻接表和 `indeg` 入度数组，`time` 下标要减 1 对齐课程号。
2. 入度为 0 的课入队，其 `finish` 就是自身耗时。
3. 出队 `u` 时遍历后继 `v`，用 `finish[u]` 更新 `finish[v]` 的「最晚先修完成时刻」，入度减到 0 才入队。
4. 全程维护 `ans = max(ans, finish[u])`。

以示例 2 为例：`time = [1,2,3,4,5]`，课程 3 完成后 `finish[3]=3`，课程 4 的 `finish[4]=3+4=7`；课程 5 入队时 `finish[5]=max(1,2,3,7)+5=12`，这就是答案。

```python
from collections import deque
adj = [[] for _ in range(n + 1)]
indeg = [0] * (n + 1)
for u, v in relations:
    adj[u].append(v)
    indeg[v] += 1
finish = [0] * (n + 1)
q = deque(i for i in range(1, n + 1) if indeg[i] == 0)
for i in q:
    finish[i] = time[i - 1]
ans = 0
while q:
    u = q.popleft()
    ans = max(ans, finish[u])
    for v in adj[u]:
        finish[v] = max(finish[v], finish[u])
        indeg[v] -= 1
        if indeg[v] == 0:
            finish[v] += time[v - 1]
            q.append(v)
```

## 复杂度
时间 O(n + m)，m 为 `relations.length`，每条边进出各一次。
空间 O(n + m)，`adj` 存 m 条边，`indeg`/`finish`/队列各 O(n)。

## 易错点
1. 把 `finish[v]` 写成 `finish[u] + time[v-1]` 直接覆盖 → 示例 2 中课程 5 有 4 个先修，会被最后出队的课程 4 覆盖成 7+5=12 碰巧对，但若先修顺序反过来（课程 1 最后出队）就错成 1+5=6 → 必须先 `max` 累积再在入度归零时加自身耗时。
2. `time` 下标忘记减 1 → 课程 1 取到 `time[1]=2` 而非 `time[0]=1`，示例 2 答案变 13 → 统一用 `time[v - 1]`。

## 如果面试官追问
若要求输出具体排课方案（每门课的开始月份）？答：`finish[v] - time[v-1]` 就是开始时刻，拓扑序即合法执行顺序。
