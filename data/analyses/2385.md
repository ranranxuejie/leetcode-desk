## 一句话思路
把树转成无向图（父边补上），从 start 做 BFS，最后一层的层号就是答案。

## 怎么做
1. 一次 DFS 建邻接表 `g`，遍历时把 `node.val` 与子节点值互相加边，这样父指针方向也通了。
2. 从 `start` 出发 BFS，用 `seen` 集合防回访（树转无向图后必有环）。
3. 每弹完一层 `time += 1`，队列空时返回 `time - 1`（最后一层多加了一次）。

以示例 1 为例：`start = 3`，建图后 3 的邻居是 `[1, 10, 6]`。第 1 层弹出这三个，第 2 层弹出 5，第 3 层弹出 4，第 4 层弹出 9 和 2，队列空时 `time = 5`，返回 4。

```python
g = defaultdict(list)
def build(u, p):
    if not u: return
    for v in (u.left, u.right):
        if v:
            g[u.val].append(v.val)
            g[v.val].append(u.val)
            build(v, u)
build(root, None)

q, seen, time = deque([start]), {start}, 0
while q:
    for _ in range(len(q)):
        u = q.popleft()
        for v in g[u]:
            if v not in seen:
                seen.add(v)
                q.append(v)
    time += 1
return time - 1
```

注意 `build` 里 `p` 参数其实没用到，因为加的是双向边，父方向已由 `g[v.val].append(u.val)` 覆盖；保留它只是让递归签名对称，可以删。

## 复杂度
时间 O(n)：建图遍历每个节点一次，BFS 每条无向边访问两次。
空间 O(n)：邻接表存 2(n-1) 条边，`seen` 与队列各 O(n)。

## 易错点
- 只按父子方向建图（不加 `g[v.val].append(u.val)`）→ 从 start 往上走不到祖先，示例 1 里节点 5 永远感染不到，输出 2 而非 4 → 必须建双向边。
- 忘记 `seen` 或只在入队时判重 → 树转无向图后父子会互相回访，BFS 死循环 → 入队前用 `seen` 拦截，且 `start` 一开始就放进 `seen`。

## 如果面试官追问
问：不建图能不能做？答：可以，从 start 分别向下求子树高度、向上求「父侧最大深度」，两次 DFS 取 max，省掉邻接表的 O(n) 空间。
