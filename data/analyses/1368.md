## 一句话思路
把「改方向」看成边权 0/1 的最短路：顺着箭头走代价 0，其余三个方向代价 1，用 0-1 BFS 求 (0,0) 到 (m-1,n-1) 的最小代价。

## 怎么做
1. 建 `dist` 二维数组，全部初始化为 `2**31 - 1`，`dist[0][0] = 0`，用双端队列 `dq` 存坐标。
2. 每次从队首弹出 `(x, y)`，枚举四个方向 `(dx, dy)`，算出 `nx, ny`，越界就跳过。
3. 判断该方向是否等于 `grid[x][y]`：相等则 `w = 0` 并 `appendleft`，否则 `w = 1` 并 `append`；只有 `dist[x][y] + w < dist[nx][ny]` 时才更新并入队。
4. 队列空时返回 `dist[m-1][n-1]`。

以示例 1 的 `grid[0] = [1,1,1,1]` 为例：从 `(0,0)` 出发，向右是箭头 1，`w=0`，`dist[0][1]` 直接为 0；而向下 `w=1`，`dist[1][0]` 记为 1 且排到队尾。整行 `(0,0)~(0,3)` 都以 0 代价铺开，直到 `(0,3)` 处 `grid[0][3]=1` 指向右（越界），向下才付 1，这正是答案 3 的来源。

```python
from collections import deque

dist = [[2**31 - 1] * n for _ in range(m)]
dist[0][0] = 0
dq = deque([(0, 0)])
dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]  # 对应 1,2,3,4
while dq:
    x, y = dq.popleft()
    for i, (dx, dy) in enumerate(dirs):
        nx, ny = x + dx, y + dy
        if 0 <= nx < m and 0 <= ny < n:
            w = 0 if grid[x][y] == i + 1 else 1
            if dist[x][y] + w < dist[nx][ny]:
                dist[nx][ny] = dist[x][y] + w
                dq.appendleft((nx, ny)) if w == 0 else dq.append((nx, ny))
return dist[m - 1][n - 1]
```

## 复杂度
时间 O(m·n)：每个格子最多被松弛常数次，0-1 BFS 每条边只处理一次。
空间 O(m·n)：`dist` 二维数组加双端队列，队列最坏存全部格子。

## 易错点
- 用普通 BFS 按层数当步数 → 示例 1 会返回 4（走的格子数）而不是 3（改的格子数）→ 必须把代价记在边上，用 0-1 BFS 或 Dijkstra。
- 只对 `grid[x][y]` 指向的那个方向入队 → 示例 3 的 `[[1,2],[4,3]]` 从 `(0,0)` 向右到 `(0,1)` 后 `grid[0][1]=2` 指向左，会原地打转，永远到不了 `(1,1)` → 四个方向都要枚举，非箭头方向付 1。

## 如果面试官追问
要求输出具体修改了哪些格子怎么办？
答：在 `dist` 更新时额外记 `pre[nx][ny] = (x, y)`，最后从终点沿 `pre` 回溯，凡 `grid[x][y]` 与走向不符的格子即为修改点。
