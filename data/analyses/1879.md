## 一句话思路
用状压 DP 按位分配 nums2：`dp[mask]` 表示 nums2 中 mask 这些位置已配对给 nums1 的前 `popcount(mask)` 个元素时的最小异或和。

## 怎么做
1. 令 `dp` 长度为 `1 << n`，全部初始化为一个大数，`dp[0] = 0`。
2. 从小到大枚举 `mask`，令 `i = mask.bit_count()`，表示 nums1 中下一个待配对的下标是 `i`。
3. 枚举 nums2 中尚未使用的位置 `j`（`mask` 的第 `j` 位为 0），转移 `dp[mask | (1 << j)] = min(dp[mask | (1 << j)], dp[mask] + (nums1[i] ^ nums2[j]))`。
4. 答案是 `dp[(1 << n) - 1]`。

用示例 1：`nums1 = [1,2]`，`nums2 = [2,3]`。`dp[0]=0`，`i=0` 时转移到 `dp[1]=1^2=3`、`dp[2]=1^3=2`；`mask=2` 时 `i=1`，`j=0` 得 `dp[3]=2+(2^2)=2`，而 `mask=1` 走 `j=1` 得 `3+(2^3)=4`，取小为 2。

```python
n = len(nums1)
INF = float('inf')
dp = [INF] * (1 << n)
dp[0] = 0
for mask in range(1 << n):
    i = mask.bit_count()
    if i == n:
        continue
    for j in range(n):
        if not (mask >> j) & 1:
            nm = mask | (1 << j)
            v = dp[mask] + (nums1[i] ^ nums2[j])
            if v < dp[nm]:
                dp[nm] = v
return dp[(1 << n) - 1]
```

## 复杂度
时间：`O(n * 2^n)`，每个 mask 枚举 n 个 j，n 来自数组长度。
空间：`O(2^n)`，只开一个 dp 数组，无额外结构。

## 易错点
- `nums2` 有重复元素（如 `nums2 = [2,2]`）时，若想「去重后再枚举 j」会漏解：两个相同的 2 对应不同位置，必须按位枚举 `j`，不能按值去重。
- 忘记 `i = mask.bit_count()` 而用「已用元素个数」另开变量统计，会在 `mask` 乱序枚举时错位：必须由 mask 直接算出 i，保证 `nums1[i]` 与已配对数严格对应。

## 如果面试官追问
问：n 放大到 20 还能这么做吗？
答：`2^20 * 20` 约两千万次转移，Python 偏慢但可行；再大就得换思路，这题本质是二分图最小权匹配，可用 KM 或匈牙利算法。
