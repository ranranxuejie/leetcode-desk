## 一句话思路
把每个串归一化成「首字母为 a」的形式（逐位减首字母），相似当且仅当归一化结果相同，用哈希表计数。

## 怎么做
1. 对每个 `w`，取 `base = ord(w[0]) - 97`，把每位 `(ord(c) - 97 - base) % 26` 拼成 key。
2. 用 `cnt` 字典累计每个 key 出现次数，遇到重复 key 时答案加上已有计数。
3. 以 `words = ["ab","aa","za","aa"]` 为例：`"ab"` → base=0 → `(0,1)`；`"aa"` → `(0,0)`；`"za"` → base=25 → `(0-25)%26=1`、`(25-25)%26=0`，即 `(1,0)`？注意这里要按位算：`'z'` 位 25 减 25 得 0，`'a'` 位 0 减 25 得 `(-25)%26=1`，key 是 `(0,1)`，与 `"ab"` 相同，配对成功。
4. 第二个 `"aa"` 到来时 `cnt[(0,0)]` 已是 1，答案 +1，最终 2。

```python
cnt = {}
ans = 0
for w in words:
    base = ord(w[0]) - 97
    key = tuple((ord(c) - 97 - base) % 26 for c in w)
    ans += cnt.get(key, 0)
    cnt[key] = cnt.get(key, 0) + 1
```

关键点：`% 26` 必须对负数也成立，Python 的 `%` 天然返回非负，`(-25) % 26 == 1`，不用额外修正。

## 复杂度
时间：O(n·m)，每个字符算一次 key，n·m ≤ 10^5。
空间：O(n·m) 存所有 key，最坏 n 个长度 m 的元组。

## 易错点
- 用 `w[0]` 当基准却忘了 `"za"` 的 base=25：若直接按 `ord(c)-ord(w[0])` 不取模，`"za"` 得 `(0,-25)`，与 `"ab"` 的 `(0,1)` 不相等，漏掉示例 2 的 1 对。必须 `% 26`。
- 把整个串排序或直接比较原串：`"ab"` 与 `"za"` 原串不同但相似，直接哈希原串会把答案算成 0（示例 2 应为 2）。必须归一化后再哈希。

## 如果面试官追问
若 m 很大而 n 很小，怎么省空间？答：不存完整 key，改存 `hash(tuple(...))` 或滚动哈希，冲突用双哈希控制。
