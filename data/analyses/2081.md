## 一句话思路
按十进制回文长度递增枚举回文数，逐个验 k 进制回文，凑满 n 个即停——十进制回文远少于全部整数。

## 怎么做
1. 从长度 `L = 1` 开始，枚举十进制回文：取前半段 `half`，由它拼出奇数位和偶数位两个回文。
2. 对每个候选 `x`，转成 k 进制字符串，判断 `s == s[::-1]`。
3. 命中就累加进 `ans`，`cnt += 1`，`cnt == n` 立即返回。

以 `k = 3, n = 7` 为例：`L = 1` 时 `half` 取 1..9，得到 1,2,3,4,5,6,7,8,9，其中 3、6 的三进制是 `10`、`20` 非回文，命中 1,2,4,5,7,8 共 6 个；`L = 2` 时 `half = 1` 拼出 11，三进制 `102` 不是回文，`half = 2` 拼出 22 也不是，直到 `half = 11` 拼出 121，三进制 `11111` 命中，成为第 7 个，答案 499。

```python
def gen(L):
    start = 10 ** ((L - 1) // 2)
    for h in range(start, start * 10):
        s = str(h)
        yield int(s + s[-1 - (L % 2 == 0)::-1])

ans = cnt = 0
L = 1
while cnt < n:
    for x in gen(L):
        t = ''
        y = x
        while y:
            t += str(y % k); y //= k
        if t == t[::-1]:
            ans += x; cnt += 1
            if cnt == n: return ans
    L += 1
```

关键点：`gen` 里 `s[-1-(L%2==0)::-1]` 让奇数位回文跳过中间字符、偶数位全镜像，避免重复枚举。

## 复杂度
时间：枚举的十进制回文个数随位数指数增长，每个候选做一次 O(log_k x) 的进制转换与比较。
空间：O(log_k x) 存 k 进制串，无额外数组。

## 易错点
- 用 `range(1, 10**6)` 暴力扫全部整数 → k=2、n=30 时第 30 个 2 镜像数已到 10^7 量级，超时；正确做法是按十进制回文长度分层枚举，候选量级降到约 10^(L/2)。
- 拼回文时对奇数位也做全镜像（如 `half=12` 拼成 `1221` 而非 `121`）→ 漏掉所有奇数位回文，k=3 时 121 就找不到，答案偏小；正确做法是奇数位只镜像 `s[:-1]`。

## 如果面试官追问
问：n 放大到 10^5 怎么办？答：按长度分层仍成立，但需预生成各长度回文并缓存，或改用双向 BFS 按数值序合并两路枚举。
