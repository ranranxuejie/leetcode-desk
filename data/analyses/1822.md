## 一句话思路
只数负号个数和有没有 0，不真乘——乘积的符号只由这两件事决定。

## 怎么做
1. 遍历 `nums`，遇到 `0` 立刻返回 `0`，因为后面乘什么都归零。
2. 用 `neg` 累计负数个数，遇到 `< 0` 就 `neg += 1`。
3. 遍历结束后看 `neg % 2`：偶数返回 `1`，奇数返回 `-1`。

拿示例 1 `nums = [-1,-2,-3,-4,3,2,1]` 走一遍：扫到 `-1` 时 `neg=1`，`-2` 时 `neg=2`，`-3` 时 `neg=3`，`-4` 时 `neg=4`；后面 `3,2,1` 都是正数不动 `neg`。最终 `neg=4`，`4 % 2 == 0`，返回 `1`，和真乘积 `144` 的符号一致。

关键中间值就是 `neg` 的终值：它只记奇偶，所以哪怕数组有 10^5 个 `-100`，`neg` 也最多到 10^5，不会像真乘积那样炸成天文数字。

```python
neg = 0
for x in nums:
    if x == 0:
        return 0
    if x < 0:
        neg += 1
return -1 if neg % 2 else 1
```

注意 `return -1 if neg % 2 else 1` 里 `neg % 2` 为 1 时取 `-1`，为 0 时取 `1`，别写反。

## 复杂度
时间：O(n)，`nums` 每个元素扫一次，`neg += 1` 是 O(1)。
空间：O(1)，只开了 `neg` 一个计数器，没有额外数组。

## 易错点
- 输入 `[1,5,0,2,-3]` → 若先数完所有负数再判断 0，会得到 `neg=1` 返回 `-1`，错成 `-1`；正确做法是扫到 `0` 立即 `return 0`，因为 0 一旦出现符号必为 0，后面的负号无意义。
- 输入 `[-1,1,-1,1,-1]` → 若用 `neg % 2 == 1` 判断却把返回值写成 `1 if neg % 2 else -1`，会返回 `1`，错成 `1`；正确做法是奇数个负号返回 `-1`、偶数返回 `1`，示例 3 的 `neg=3` 必须落到 `-1`。

## 如果面试官追问
问：如果要求返回乘积本身而不是符号？
答：那必须用大整数或取模，符号仍用 `neg` 奇偶定，绝对值靠累乘，Python 可直接算但会 O(n) 位宽。
