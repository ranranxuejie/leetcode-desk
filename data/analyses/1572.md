## 一句话思路
一次遍历 i 从 0 到 n-1，累加 `mat[i][i] + mat[i][n-1-i]`，当 i 落在中心时只加一次。

## 怎么做
1. 取 `n = len(mat)`，初始化 `total = 0`。
2. 循环 `i in range(n)`，每轮加主对角线元素 `mat[i][i]`。
3. 同一轮加副对角线元素 `mat[i][n-1-i]`，但若 `i == n-1-i`（即 n 为奇数且 i 是中心）则跳过，避免重复。
4. 返回 `total`。

以示例 1 的 `mat = [[1,2,3],[4,5,6],[7,8,9]]`，n=3 为例：
- i=0：加 `mat[0][0]=1`，副对角 `mat[0][2]=3`，total=4；
- i=1：加 `mat[1][1]=5`，此时 `i == n-1-i == 1`，跳过副对角，total=9；
- i=2：加 `mat[2][2]=9`，副对角 `mat[2][0]=7`，total=25。

关键中间值就是 i=1 那一轮的判断：`1 == 3-1-1` 成立，所以 5 只算一次。

```python
n = len(mat)
total = 0
for i in range(n):
    total += mat[i][i]
    j = n - 1 - i
    if j != i:
        total += mat[i][j]
return total
```

示例 2 的 4×4 全 1 矩阵：n=4，每轮 j 与 i 都不相等（i=0→j=3，i=1→j=2，i=2→j=1，i=3→j=0），共加 8 个 1，得 8，与预期一致。

## 复杂度
时间：O(n)，只扫 n 行，每行常数次访问。
空间：O(1)，只用了 total、i、j 三个变量。

## 易错点
- 奇数阶矩阵（如示例 1 的 n=3）→ 若不加 `j != i` 判断，中心元素 `mat[1][1]=5` 会被加两次，输出 30 而非 25 → 必须用 `j != i` 跳过。
- n=1 的单元素矩阵（示例 3 的 `[[5]]`）→ 若把副对角线写成无条件累加，5 会算两次得 10 → 同样靠 `j != i` 拦住，此时 i=0、j=0 相等，只加一次得 5。

## 如果面试官追问
问：若矩阵不是方阵（m×n）怎么改？
答：主副对角线长度取 `min(m,n)`，副对角下标改为 `mat[i][n-1-i]`，中心去重条件换成判断两下标是否重合即可。
