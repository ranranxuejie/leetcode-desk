## 一句话思路
从 x、y、z 各跑一次 BFS 得到全树距离，再逐点检查三距离排序后是否满足勾股关系。

## 怎么做
1. 建邻接表 `g`，对 `x`、`y`、`z` 分别做一次 BFS，得到 `dx[]`、`dy[]`、`dz[]`。
2. 遍历每个节点 `u`，把 `(dx[u], dy[u], dz[u])` 排序成 `a <= b <= c`。
3. 判断 `a*a + b*b == c*c`，成立则计数加一。

以示例 1（`n=4, edges=[[0,1],[0,2],[0,3]], x=1, y=2, z=3`）为例：BFS 后节点 0 得 `dx=1, dy=1, dz=1`，排序 `1,1,1`，`1+1 != 1` 不计数；节点 1 得 `dx=0, dy=2, dz=2`，排序 `0,2,2`，`0+4 == 4` 计数，最终答案 3。

```python
from collections import deque

def bfs(src):
    dist = [-1] * n
    dist[src] = 0
    q = deque([src])
    while q:
        u = q.popleft()
        for v in g[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

dx, dy, dz = bfs(x), bfs(y), bfs(z)
ans = 0
for u in range(n):
    a, b, c = sorted((dx[u], dy[u], dz[u]))
    if a * a + b * b == c * c:
        ans += 1
```

## 复杂度
时间：三次 BFS 各 O(n)，逐点检查 O(n)，共 O(n)。
空间：邻接表 O(n)，三个距离数组 O(n)，队列 O(n)。

## 易错点
- 距离含 0（节点本身就是 x/y/z 时）：示例 1 节点 1 得 `0,2,2`，`0+4==4` 成立。若把 0 当非法跳过，会漏掉这类节点，答案从 3 错成 0。
- 忘记排序直接按 `dx,dy,dz` 顺序算：示例 3 节点 1 原始顺序是 `0,1,1`，恰好有序；但示例 1 节点 2 是 `2,0,2`，不排序会拿 `2,0` 当直角边算出 `4 != 4` 之外的错误结论，必须先 `sorted` 再比较。

## 如果面试官追问
若 n 放大到 10^6 且只问「是否存在」特殊节点，怎么办？
答：仍跑三次 BFS，但找到第一个满足 `a*a+b*b==c*c` 的节点即返回 `True`，最坏仍是 O(n)。
