## 一句话思路
用完全背包式的 DP，`dp[i]` 表示凑出和为 `i` 的排列数，外层遍历和、内层遍历 `nums`，这样每个和都能把任意元素接在末尾，天然区分顺序。

## 怎么做
1. 初始化 `dp = [0] * (target + 1)`，`dp[0] = 1`，表示空序列凑出 0 的一种方式。
2. 外层 `i` 从 1 到 `target`，内层遍历 `nums` 中的每个 `x`。
3. 若 `x <= i`，则 `dp[i] += dp[i - x]`，把 `x` 接在所有凑出 `i - x` 的序列末尾。
4. 返回 `dp[target]`。

以 `nums = [1,2,3], target = 4` 为例，算到 `i = 4` 时：`dp[3] = 4`（`111,12,21,3`），`dp[2] = 2`（`11,2`），`dp[1] = 1`。于是 `dp[4] = dp[3] + dp[2] + dp[1] = 4 + 2 + 1 = 7`，正好对应示例输出。

```python
dp = [0] * (target + 1)
dp[0] = 1
for i in range(1, target + 1):
    for x in nums:
        if x <= i:
            dp[i] += dp[i - x]
return dp[target]
```

关键在循环顺序：外层是「和」，内层是「元素」。若反过来（外层 `nums`、内层 `i`），`dp[4]` 只会统计到 `(1,1,1,1)`、`(1,1,2)`、`(2,2)` 这类非降序组合，得到 4 而不是 7。

## 复杂度
时间：`O(target * len(nums))`，两层循环各贡献一个因子。
空间：`O(target)`，只开了一个长度 `target + 1` 的 `dp` 数组。

## 易错点
- 循环顺序写反 → `nums = [1,2,3], target = 4` 会得到 4（组合数）而非 7（排列数）→ 必须外层 `i`、内层 `x`，让每个 `x` 都能接在任意前缀后。
- 忘记 `dp[0] = 1` → 所有 `dp[i]` 全为 0，示例 1 输出 0 → 空序列是递推的起点，必须先置 1；同时 `if x <= i` 不能省，否则 `dp[i - x]` 下标为负。

## 如果面试官追问
问：若 `nums` 含负数会怎样？
答：`dp` 依赖链会出现环（如 `nums=[1,-1]`），排列数无穷，需额外限制每个元素使用次数或序列长度上界。
