## 一句话思路
把状态定义成 `(位置, 上一步是否后退)`，在它上面跑 BFS，第一次弹出 `x` 时的层数就是最少跳跃次数。

## 怎么做
1. 状态用 `(pos, back)` 表示，`back=True` 表示上一步是后退，此时禁止再退。
2. 用 `forbidden` 建集合，并定上界 `limit = max(max(forbidden), x) + a + b`，超过它的位置一律不入队。
3. 从 `(0, False)` 出发，每层只做两种转移：`pos+a` 恒合法；`pos-b` 仅在 `back=False` 且 `pos-b>=0` 时合法。
4. 出队时若 `pos == x` 立即返回当前步数，队列空则返回 `-1`。

以示例 3 为例：`forbidden={1,2,4,5,6,7,14,17}`，`a=16, b=9, x=7`。第 0 层只有 `(0,False)`；第 1 层前进得 `(16,False)`（16 不在 forbidden）；第 2 层从 16 后退得 `(7,True)`，`7 == x`，返回 2。注意 `7` 本身在 forbidden 里吗？不在——forbidden 是 `{1,6,2,14,5,17,4}`，所以能落地。

```python
from collections import deque
forb = set(forbidden)
limit = max(max(forbidden), x) + a + b
q = deque([(0, False)])
seen = {(0, False)}
steps = 0
while q:
    for _ in range(len(q)):
        pos, back = q.popleft()
        if pos == x:
            return steps
        for nxt, nb in ((pos + a, False), (pos - b, True)):
            if nb and back:          # 连续后退两次
                continue
            if nxt < 0 or nxt > limit or nxt in forb:
                continue
            if (nxt, nb) not in seen:
                seen.add((nxt, nb))
                q.append((nxt, nb))
    steps += 1
return -1
```

## 复杂度
时间 O(limit) 级别：状态数约 `2*limit`，每个状态只做两次转移。
空间 O(limit)：`seen` 集合与队列各存至多 `2*limit` 个状态。

## 易错点
- 只按位置去重、不带上 `back` 标记 → 示例 3 中 `(16,False)` 与 `(16,True)` 被合并，后续从 16 后退的路径被误剪，答案偏大或返回 -1。正确做法是 `seen` 存 `(pos, back)` 二元组。
- 上界取 `x + a` 或干脆不设 → 当 `x` 很小而 `a` 很大时（如 `a=16, x=7`），必须先跳到 16 再退回来，砍掉 16 就漏解；不设上界则队列无限增长。正确做法是 `max(max(forbidden), x) + a + b`。

## 如果面试官追问
问：如果要求输出具体跳跃序列而不只是次数？
答：BFS 里给每个状态存 `parent` 指针，到达 `x` 后沿指针回溯即可，状态仍是 `(pos, back)`。
