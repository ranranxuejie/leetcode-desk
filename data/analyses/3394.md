## 一句话思路
把所有矩形的 x 区间和 y 区间分别做「合并区间」，任一方向能合出 ≥3 段就说明有两条切割线。

## 怎么做
1. 竖直切只看 x：把每个矩形压成 `(x1, x2)`，按 `x1` 升序排序。
2. 顺序扫描合并：若当前 `x1 >= 当前段右端 cur_end`，说明出现缝隙，段数 +1，`cur_end = x2`；否则 `cur_end = max(cur_end, x2)`。
3. 段数 ≥3 即返回 `True`；否则对 y 方向（`(y1, y2)`）重复一遍。

以示例 1 的 y 方向为例：区间为 `(0,2),(2,4),(2,3),(4,5)`，排序后扫描，`(2,4)` 的 `y1=2` 不小于 `cur_end=2`，段数变 2、`cur_end=4`；`(2,3)` 被吞进第二段；`(4,5)` 的 `y1=4 >= 4`，段数变 3 → `True`。

```python
def can_cut(intervals):
    intervals.sort()
    parts, cur_end = 1, intervals[0][1]
    for s, e in intervals[1:]:
        if s >= cur_end:
            parts += 1
            cur_end = e
        else:
            cur_end = max(cur_end, e)
    return parts >= 3

xs = sorted((r[0], r[2]) for r in rectangles)
ys = sorted((r[1], r[3]) for r in rectangles)
return can_cut(xs) or can_cut(ys)
```

关键点：切割线必须落在矩形之间的空隙里，所以判据是 `s >= cur_end`（等号成立，因为矩形边界相接时切线正好落在公共边上，两侧矩形分属不同部分）。

## 复杂度
时间：排序 O(m log m)，扫描 O(m)，m = len(rectangles)，两个方向各做一次。
空间：排序额外 O(m)（Python `sorted` 生成新列表），无其他结构。

## 易错点
- 把判据写成 `s > cur_end`：示例 1 的 y 方向 `(2,4)` 与 `(0,2)` 在 y=2 相接，用严格大于会漏掉这次切割，段数停在 2，返回 `False`。正确用 `s >= cur_end`。
- 合并时只写 `cur_end = e` 不取 max：输入 `[(0,5),(1,2),(3,4)]` 时，处理 `(1,2)` 会把 `cur_end` 从 5 缩回 2，随后 `(3,4)` 被误判为新段，段数虚增到 3 返回 `True`。必须 `cur_end = max(cur_end, e)`。

## 如果面试官追问
要求输出具体切割坐标怎么办？记录每次触发新段时的 `s` 作为切线位置，凑满两条即返回这两个坐标。
