## 一句话思路
用一个布尔量 `inside` 标记当前是否处于竖线对内，扫一遍 `s`，只在 `inside == False` 时数 `*`。

## 怎么做
1. 初始化 `inside = False`、`ans = 0`。
2. 遍历 `s` 的每个字符 `ch`：遇到 `'|'` 就翻转 `inside`，因为竖线成对出现，翻转天然配对。
3. 遇到 `'*'` 且 `inside == False` 时 `ans += 1`。
4. 返回 `ans`。

以示例 1 `s = "l|*e*et|c**o|*de|"` 为例，走到下标 1 的 `'|'` 时 `inside` 从 `False` 变 `True`，于是下标 2 的 `'*'` 被跳过；走到下标 7 的 `'|'` 时 `inside` 翻回 `False`，下标 8、9 的 `c**` 两个星号都被计入，`ans` 此时为 2；再遇下标 10 的 `'|'` 又进对内，末尾 `*de|` 的星号不计。最终 `ans = 2`。

```python
inside = False
ans = 0
for ch in s:
    if ch == '|':
        inside = not inside
    elif ch == '*' and not inside:
        ans += 1
return ans
```

关键点：`'|'` 分支必须用 `if` 而不是 `elif` 的兜底，且翻转后不再判断星号——竖线本身不是星号，顺序上先处理竖线不会漏。

## 复杂度
时间：O(n)，n 为 `s` 长度，每个字符访问一次。
空间：O(1)，只开了 `inside` 和 `ans` 两个标量。

## 易错点
- 输入 `s = "|*|"` → 若把 `inside` 初值设成 `True` 或忘记翻转，会把对内星号算成 1 → 正确做法是初值 `False`，遇 `'|'` 立即 `not inside`，该星号被跳过，答案 0。
- 输入 `s = "**|*|*"` → 若在 `'|'` 分支里也顺手判断 `ch == '*'`（写成 `if ch == '|' or ch == '*'` 之类），会把竖线当星号或漏掉对内外的区分 → 正确做法是 `'|'` 与 `'*'` 两个分支互斥，星号计数只在 `elif` 里做。

## 如果面试官追问
问：若竖线不成对（奇数个 `'|'`）怎么办？
答：末尾未闭合的那段按「对内」处理，即扫完后 `inside == True` 时最后一段星号不计，只需在返回前不额外补偿即可。
