## 一句话思路
用 `dp[i][j][c]` 表示前 i 个数、最大值恰为 j、search_cost 为 c 的方案数，转移靠前缀和把 O(m) 压成 O(1)。

## 怎么做
1. 定义 `dp[j][c]` 为当前长度下最大值恰为 j、cost 为 c 的方案数，初始长度 1：`dp[j][1] = 1`（j 从 1 到 m）。
2. 每加一个数 x：若 `x <= j`，最大值不变、cost 不变，贡献 `j * dp[j][c]`；若 `x > j`，新最大值是 x、cost 加 1，贡献来自所有 `j' < x` 的 `dp[j'][c-1]` 之和。
3. 第二项用前缀和 `pre[x-1] = sum(dp[1..x-1][c-1])` 一次算出，避免对每个 x 再扫一遍 j'。
4. 迭代 n-1 轮，答案是 `sum(dp[j][k] for j in 1..m)`。

以 `n=2, m=3, k=1` 为例：长度 1 时 `dp = {1:1, 2:1, 3:1}`（cost 都是 1）。加第二个数时，cost 保持 1 只能走 `x <= j` 分支：j=1 贡献 1×1，j=2 贡献 2×1，j=3 贡献 3×1，合计 6，与示例一致；走 `x > j` 分支会让 cost 变 2，被 k=1 排除。

```python
MOD = 10**9 + 7
# dp[j] 表示最大值恰为 j 的方案数（当前 cost 层）
dp = [0] * (m + 1)
for j in range(1, m + 1):
    dp[j] = 1
for _ in range(n - 1):
    pre = [0] * (m + 1)
    for j in range(1, m + 1):
        pre[j] = (pre[j - 1] + dp[j]) % MOD
    ndp = [0] * (m + 1)
    for j in range(1, m + 1):
        ndp[j] = (j * dp[j] + pre[j - 1]) % MOD
    dp = ndp
```

（上面是 k=1 的单层写法；一般 k 要再套一层 cost 维度，`ndp[j][c] = j*dp[j][c] + pre[j-1][c-1]`。）

## 复杂度
时间：O(n·m·k)，n 轮迭代 × m 个最大值 × k 个 cost 层。
空间：O(m·k)，只保留上一层 dp 和前缀和数组。

## 易错点
- `k > m` 或 `k > n` 时直接返回 0：如 `n=5, m=2, k=3`，最大值最多 2 个数能刷新记录，cost 上不去 3，不判会白跑循环还可能越界访问 `dp[..][c-1]`。
- `k=0` 时返回 0：数组非空且元素 ≥1，第一次取数必然产生 cost=1，别把空数组当成合法解算成 1。

## 如果面试官追问
问：n 放大到 10^9 怎么办？答：转移是线性的，可对 m·k 维状态矩阵做快速幂，O((mk)^3 log n) 或利用结构降维。
