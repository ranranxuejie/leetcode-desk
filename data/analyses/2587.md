## 一句话思路
把正数从大到小排前面、负数从小到大排后面，让前缀和尽量晚跌破 0，贪心即最优。

## 怎么做
1. 排序：`nums.sort(reverse=True)`，得到 `[3,2,1,0,-1,-3,-3]`。
2. 遍历累加 `s`，`s > 0` 时 `ans += 1`。
3. 一旦 `s <= 0` 直接 `break`——后面只会更小，不可能再转正。

用示例 1 走一遍：排序后累加得 `s = 3,5,6,6,5,2,-1`，前 6 个为正，第 7 个 `-1` 触发 break，`ans = 6`。注意原数组里的 `0` 排在第 4 位，此时 `s = 6` 仍为正，所以它也被计入分数——这正是把 0 放在正数之后、负数之前的原因。

```python
nums.sort(reverse=True)
ans = 0
s = 0
for x in nums:
    s += x
    if s > 0:
        ans += 1
    else:
        break
return ans
```

关键点：`break` 而非 `continue`。因为降序排列后剩余元素都 `<= x`，`s` 单调不增，一旦非正就永远非正。

## 复杂度
时间：排序 `O(n log n)` 主导，遍历 `O(n)`。
空间：排序栈开销 `O(log n)`，其余只用了 `s`、`ans` 两个变量。

## 易错点
- 输入 `[0,0,0]` → 若写成 `if s >= 0: ans += 1` 会得 3，但前缀和全是 0，不是正整数 → 必须严格 `s > 0`。
- 输入 `[-1,2]` → 若按原顺序累加得 `s = -1` 立刻 break，答案 0；正确排序后是 `[2,-1]`，`s = 2,1` 全正，答案 2 → 排序这一步不能省。

## 如果面试官追问
问：要求返回具体重排方案怎么办？
答：排序后按同样顺序输出即可，`break` 之后的元素随便接在后面，不影响分数。
