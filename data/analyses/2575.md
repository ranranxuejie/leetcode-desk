## 一句话思路
逐位维护前缀对 m 的余数 `rem = (rem * 10 + int(c)) % m`，`rem == 0` 即该前缀可整除。

## 怎么做
1. 初始化 `rem = 0`、`div = []`，从左到右遍历 `word` 的每个字符。
2. 每步更新 `rem = (rem * 10 + int(c)) % m`，把 `1 if rem == 0 else 0` 追加进 `div`。
3. 用示例 1 走关键一步：`word = "998244353"`，`m = 3`。处理到第 6 个字符 `'4'` 时，前一步 `rem` 为 `99 % 3 = 0`，本步 `rem = (0 * 10 + 4) % 3 = 1`，故 `div[5] = 0`；继续到 `'3'` 时 `rem = (1 * 10 + 3) % 3 = 1`，`div[8] = 0`，与输出 `[1,1,0,0,0,1,1,0,0]` 一致。
4. 全程只保留余数，不构造完整前缀数值，避免大数。

```python
rem = 0
div = []
for c in word:
    rem = (rem * 10 + int(c)) % m
    div.append(1 if rem == 0 else 0)
return div
```

## 复杂度
时间：O(n)，n 为 `word` 长度，每位做一次乘加取模。
空间：O(n) 存 `div`，`rem` 为 O(1)。

## 易错点
- 输入 `word = "1010"`、`m = 10`：若先算完整前缀再取模，`1010` 本身没问题，但 `n = 10^5` 时前缀是 10 万位整数，Python 虽不溢出但乘法代价随位数增长，会超时；正确做法是每步只保留 `rem`，`rem = (rem * 10 + int(c)) % m`。
- 输入 `word = "0"`、`m = 1`：若把 `rem == 0` 的判断写成 `rem == 0 and i > 0`，会漏掉首位 `div[0] = 1`；正确做法是首位也按 `rem == 0` 判断，`0 % 1 == 0` 应输出 `[1]`。

## 如果面试官追问
问：若 `m` 可达 `10^18` 且要求输出每个前缀的余数而非 0/1？答：同样逐位 `rem = (rem * 10 + int(c)) % m`，Python 大整数直接支持，无需改结构。
