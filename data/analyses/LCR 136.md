## 一句话思路
用哑节点 `dummy` 指向 `head`，从 `dummy` 开始遍历找 `cur.next.val == val` 的节点，改指针跳过它。

## 怎么做
1. 建 `dummy = ListNode(0)`，`dummy.next = head`，`cur = dummy`。
2. 循环条件 `cur.next` 非空，判断 `cur.next.val == val`，命中就 `cur.next = cur.next.next` 并 `break`。
3. 未命中则 `cur = cur.next` 继续。
4. 返回 `dummy.next`。

以 `head = [4,5,1,9], val = 5` 为例：`cur` 初始是 `dummy`，`cur.next.val = 4 ≠ 5`，`cur` 前移到值为 4 的节点；此时 `cur.next.val = 5` 命中，执行 `cur.next = cur.next.next`，4 直接指向 1，返回 `dummy.next` 得 `[4,1,9]`。

```python
dummy = ListNode(0)
dummy.next = head
cur = dummy
while cur.next:
    if cur.next.val == val:
        cur.next = cur.next.next
        break
    cur = cur.next
return dummy.next
```

关键点：判断的是 `cur.next.val` 而不是 `cur.val`，因为删除需要前驱指针；`dummy` 让「删头节点」和「删中间节点」走同一条路径，不用单独写 `if head.val == val: return head.next`。

## 复杂度
时间 O(n)：最坏遍历到尾部才命中，n 是链表长度。
空间 O(1)：只开了 `dummy`、`cur` 两个指针。

## 易错点
- `head = [4,5,1,9], val = 4`（删头节点）→ 若直接 `cur = head` 再找前驱，会漏掉头节点或写成 `head = head.next` 后忘记返回 → 用 `dummy` 统一处理，返回 `dummy.next`。
- `head = [4,5,1,9], val = 9`（删尾节点）→ 若循环写成 `while cur:` 再访问 `cur.next.val`，走到尾节点时 `cur.next` 为 `None` 触发 `AttributeError` → 循环条件必须是 `while cur.next:`，保证访问 `.val` 时节点存在。

## 如果面试官追问
问：如果链表可能有重复的 `val`，要删掉所有匹配节点呢？
答：去掉 `break`，命中后原地 `cur.next = cur.next.next` 不移动 `cur`，未命中才 `cur = cur.next`。
