## 一句话思路
排序后，一段连续房子配一个邮筒的最优代价是中位数距离和，用 DP 枚举分段点。

## 怎么做
1. 先对 `houses` 排序，保证每段是连续区间。
2. 预处理 `cost[i][j]`：第 i 到第 j 栋房子共用一个邮筒的最小距离和，邮筒放中位数 `houses[(i+j)//2]`。
3. 定义 `dp[t][i]` 为前 i 栋房子用 t 个邮筒的最小总距离，转移 `dp[t][i] = min(dp[t-1][j] + cost[j][i-1])`。
4. 答案取 `dp[k][n]`。

以示例 1 的 `houses = [1,4,8,10,20], k = 3` 为例：排序后不变。`cost[0][1]`（房子 1、4）中位数取 `houses[0]=1`，代价 `0+3=3`；`cost[2][3]`（8、10）中位数 `houses[2]=8`，代价 `0+2=2`。最终 `dp[3][5]=5`，对应分段 `[1,4]`、`[8,10]`、`[20]`。

```python
houses.sort()
n = len(houses)
cost = [[0] * n for _ in range(n)]
for i in range(n):
    for j in range(i + 1, n):
        mid = houses[(i + j) // 2]
        cost[i][j] = cost[i][j - 1] + houses[j] - mid
        # 注意：上面这行只在 mid 不变时成立，稳妥写法用前缀和
INF = 2**31 - 1
dp = [[INF] * (n + 1) for _ in range(k + 1)]
dp[0][0] = 0
for t in range(1, k + 1):
    for i in range(1, n + 1):
        for j in range(t - 1, i):
            dp[t][i] = min(dp[t][i], dp[t - 1][j] + cost[j][i - 1])
```

`cost` 递推那行有坑：`mid` 随 j 变化会跳，正确做法是 `cost[i][j] = cost[i][j-1] + houses[j] - houses[(i+j)//2]` 仅在 j 与 i 同奇偶时成立，最稳是直接双指针累加或前缀和。

## 复杂度
时间：O(k·n²)，三层循环，n 来自房子数，k 来自邮筒数。
空间：O(n² + k·n)，存 `cost` 表和 `dp` 表。

## 易错点
- `houses` 未排序就建 `cost` → 中位数取错，示例 3 的 `[7,4,6,1]` 会算出比 8 大的值 → 必须先 `sort()`。
- `cost` 递推用固定 `mid` 累加 → 区间跨过中位数时 `mid` 跳变，代价偏小 → 每对 `(i,j)` 重新取 `houses[(i+j)//2]` 或改用前缀和公式。

## 如果面试官追问
问：k 很大接近 n 时能否优化？答：k≥n 直接返回 0，且 `dp` 只需保留上一行，空间降到 O(n)。
