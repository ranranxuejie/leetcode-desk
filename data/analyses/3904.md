## 一句话思路
预处理后缀最小值 `suf[i] = min(nums[i..n-1])`，再从左往右滚动维护前缀最大值，第一个满足 `pre_max - suf[i] <= k` 的下标即答案。

## 怎么做
1. 从右往左扫一遍，建 `suf` 数组，`suf[n-1] = nums[n-1]`，`suf[i] = min(nums[i], suf[i+1])`。
2. 从左往右扫，用变量 `pre_max` 滚动维护 `max(nums[0..i])`。
3. 每个 `i` 判断 `pre_max - suf[i] <= k`，成立就立刻返回 `i`（保证最小）。
4. 扫完没命中返回 `-1`。

以 `nums = [5,0,1,4], k = 3` 为例，`suf = [0,0,1,4]`。`i=0` 时 `pre_max=5`，`5-0=5>3`；`i=2` 时 `pre_max=5`，`5-1=4>3`；`i=3` 时 `pre_max=5`，`5-4=1<=3`，返回 `3`。

```python
n = len(nums)
suf = [0] * n
suf[-1] = nums[-1]
for i in range(n - 2, -1, -1):
    suf[i] = min(nums[i], suf[i + 1])

pre_max = nums[0]
for i in range(n):
    pre_max = max(pre_max, nums[i])
    if pre_max - suf[i] <= k:
        return i
return -1
```

关键点：`suf[i]` 必须包含 `nums[i]` 本身（区间是 `[i, n-1]`），不是 `[i+1, n-1]`。示例 1 中 `i=3` 若取 `[4, n-1]` 会越界或取错值，正确答案 `1` 就出不来。

## 复杂度
时间：O(n)，建 `suf` 一次正扫一次，共两趟。
空间：O(n)，只开了长度 n 的 `suf` 数组。

## 易错点
- `nums = [0], k = 0` → 若把 `suf` 建成 `[i+1, n-1]` 的后缀最小值，`i=0` 时区间为空，会错判成 `-1` → 正确做法是 `suf[i]` 覆盖 `[i, n-1]`，单元素时 `suf[0]=nums[0]`，`0-0=0<=0` 返回 `0`。
- `nums = [3,2,1], k = 1` → 若只维护前缀最大值、不预存后缀最小值，边扫边算 `min(nums[i:])` 会退化成 O(n²)，10^5 规模超时 → 正确做法是先 O(n) 建好 `suf`，正扫时 O(1) 查表，全程两趟线性。

## 如果面试官追问
问：若要求返回所有稳定下标而非最小一个？
答：同一套 `suf` + 滚动 `pre_max`，把 `return i` 改成收集进列表，扫完返回，仍是 O(n)。
