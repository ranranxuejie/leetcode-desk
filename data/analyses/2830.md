## 一句话思路
按 `end` 排序后做 DP：`dp[i]` 表示前 i 所房屋（0..i-1）的最大收益，对每个以 i-1 结尾的 offer 用二分找不重叠前缀。

## 怎么做
1. 把 offers 按 `end` 升序排序，并预处理成 `by_end[e]` 列表，元素为 `(start, gold)`。
2. 令 `dp[0]=0`，`dp[i]` 表示只考虑房屋 `0..i-1` 的最大收益，逐 i 从 1 推到 n。
3. 每个 i 先继承 `dp[i] = dp[i-1]`（第 i-1 所房不卖），再枚举 `by_end[i-1]` 中每个 `(s, g)`，取 `dp[s] + g` 更新。
4. 关键点：`dp[s]` 恰好是房屋 `0..s-1` 的最优值，天然与 `[s, i-1]` 不重叠，无需再判冲突。

以示例 1 为例：offers 排序后 `by_end[0]=[(0,1)]`、`by_end[2]=[(0,2)]`、`by_end[3]=[(1,2)]`。推到 i=3 时 `dp[3]=max(dp[2]=2, dp[1]+2=2)=2`；推到 i=4 时 `dp[4]=max(dp[3]=2, dp[1]+2=2)=2`，最终 `dp[5]=max(dp[4]=2, dp[0]+1=1)=2`？——注意 `[0,0]` 与 `[1,3]` 组合得 3，实际 `dp[4]` 应为 3：`by_end[3]` 的 `(1,2)` 给出 `dp[1]+2=0+2=2`，而 `dp[1]` 已含 `[0,0]` 的 1，故 `dp[1]=1`，得 `dp[4]=3`。

```python
dp = [0] * (n + 1)
for i in range(1, n + 1):
    dp[i] = dp[i - 1]
    for s, g in by_end[i - 1]:
        dp[i] = max(dp[i], dp[s] + g)
return dp[n]
```

## 复杂度
时间：排序 O(m log m)，DP 遍历 O(n + m)，m 为 offers 数。
空间：`by_end` 存 m 个二元组，`dp` 长 n+1，共 O(n + m)。

## 易错点
- 把 `dp[s]` 写成 `dp[s-1]`：示例 1 中 `(1,2)` 会取到 `dp[0]=0` 而非 `dp[1]=1`，结果从 3 掉成 2。正确是 `dp[s]`，因为 `dp` 下标比房屋编号大 1。
- 忘记 `dp[i] = dp[i-1]` 的继承：示例 2 中若只枚举 `by_end[i-1]`，i=1、2 时 `dp` 保持 0，`(0,2,10)` 在 i=3 取 `dp[0]+10=10` 仍对，但一旦出现「前面有更优不卖」的情形（如 `[[0,0,5],[0,1,1]]`）就会漏掉 5。必须先继承再更新。

## 如果面试官追问
问：若要求输出具体选了哪些 offer 怎么办？
答：额外开 `choice[i]` 记录 `dp[i]` 来自继承还是某个 `(s,g)`，从 n 回溯到 0 即可还原。
