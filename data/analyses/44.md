## 一句话思路
用双指针加贪心回溯：`*` 先按匹配空串处理，失配时回退到最近一个 `*` 让它多吃一个字符。

## 怎么做
1. 设 `i` 扫 `s`、`j` 扫 `p`，另存 `star = -1`（最近 `*` 在 `p` 中的下标）和 `match = 0`（该 `*` 当前吃到 `s` 的哪个位置）。
2. `p[j]` 是 `?` 或与 `s[i]` 相等时，`i += 1; j += 1` 直接推进。
3. `p[j] == '*'` 时记下 `star = j; match = i`，然后 `j += 1`，即先假设它匹配空串。
4. 失配且 `star != -1` 时回溯：`j = star + 1; match += 1; i = match`，让那个 `*` 多吞一个字符重试；否则返回 `False`。扫完 `s` 后，`p` 剩余必须全是 `*`。

以 `s = "cb"`, `p = "?a"` 为例：`i=0, j=0`，`?` 匹配 `c`，得 `i=1, j=1`；此时 `s[1]='b'` 对 `p[1]='a'` 失配，而 `star == -1`，直接返回 `False`。

```python
i = j = 0
star, match = -1, 0
while i < len(s):
    if j < len(p) and (p[j] == '?' or p[j] == s[i]):
        i += 1; j += 1
    elif j < len(p) and p[j] == '*':
        star, match = j, i
        j += 1
    elif star != -1:
        match += 1
        i, j = match, star + 1
    else:
        return False
while j < len(p) and p[j] == '*':
    j += 1
return j == len(p)
```

## 复杂度
时间 O(n·m) 最坏（`s="aaaa"`、`p="*a*a"` 反复回溯），均摊接近 O(n+m)。
空间 O(1)，只开了 `i/j/star/match` 四个整数。

## 易错点
- `s = "aa"`, `p = "*"`：若把 `*` 当成必须吃至少一个字符，会在 `i` 走完后误判 `False`；正确做法是 `*` 初始匹配空串，靠 `match` 递增才吃字符。
- `s = ""`, `p = "***"`：循环体一次不进，若直接 `return i == len(s)` 会漏掉尾部 `*`；必须先跳过 `p` 末尾所有 `*` 再比较 `j == len(p)`。

## 如果面试官追问
问：要求返回具体匹配方案而非布尔值怎么办？
答：在 `match += 1` 处记录每个 `*` 最终吞掉的区间 `[match, i)`，回溯时覆盖旧值即可。
