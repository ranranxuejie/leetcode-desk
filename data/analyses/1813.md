## 一句话思路
把两句按空格切成词表，双指针从两端各剥掉相同的词，剥完任一侧走完即相似。

## 怎么做
1. 用 `split()` 切成 `w1`、`w2`，令 `i` 从 0 起、`j1 = len(w1)-1`、`j2 = len(w2)-1`。
2. 前缀循环：`while i <= j1 and i <= j2 and w1[i] == w2[i]: i += 1`。
3. 后缀循环：`while j1 >= i and j2 >= i and w1[j1] == w2[j2]: j1 -= 1; j2 -= 1`。
4. 返回 `i > j1 or i > j2`——即短句的词被前缀+后缀全部覆盖。

以示例 1 为例：`w1 = ["My","name","is","Haley"]`，`w2 = ["My","Haley"]`。前缀循环后 `i = 1`（"My" 匹配）；后缀循环比较 `w1[3]="Haley"` 与 `w2[1]="Haley"` 相等，`j1` 变 2、`j2` 变 0，下一轮 `j2 >= i` 即 `0 >= 1` 不成立退出。此时 `i=1 > j2=0`，返回 `True`。

```python
w1, w2 = sentence1.split(), sentence2.split()
i, j1, j2 = 0, len(w1) - 1, len(w2) - 1
while i <= j1 and i <= j2 and w1[i] == w2[i]:
    i += 1
while j1 >= i and j2 >= i and w1[j1] == w2[j2]:
    j1 -= 1
    j2 -= 1
return i > j1 or i > j2
```

关键在第二个循环的上界用 `i` 而不是 0：前缀已经吃掉的词不能再被后缀重复匹配，否则 `"A A"` 与 `"A"` 这类会误判。

## 复杂度
时间 O(m+n)，m、n 为两句词数，每个词最多被前缀或后缀访问一次。
空间 O(m+n)，`split()` 额外开了两个词表。

## 易错点
- 输入 `"A A"` 与 `"A"` → 若后缀循环上界写成 `j1 >= 0 and j2 >= 0`，同一个 "A" 会被前缀和后缀各用一次，误判 `True`；正确做法是后缀循环条件带 `j1 >= i and j2 >= i`，保证两段不重叠。
- 输入 `"of"` 与 `"A lot of words"` → 若只做前缀匹配就返回，会因首词 "of"≠"A" 直接判 `False`，但正确答案也是 `False`，看不出问题；真正翻车在 `"Eating right now"` 与 `"Eating"`：只做前缀会漏掉后缀匹配，必须两段都剥完再判断哪侧先走完。

## 如果面试官追问
问：若要求返回被插入的那段词而非布尔值？
答：剥完后看哪侧还有剩余，`w1[i:j1+1]` 或 `w2[i:j2+1]` 就是插入内容，空则返回空串。
