## 一句话思路
递归时把「当前深度」往下传，只有 `depth < n` 才展开子数组，否则整段原样保留。

## 怎么做
1. 定义 `dfs(x, depth)`：`x` 不是 list 就直接返回 `[x]`。
2. 若 `depth == n`，返回 `[x]` 本身（不再展开），这是唯一的终止条件。
3. 否则遍历 `x` 的每个元素 `e`，把 `dfs(e, depth + 1)` 的结果拼接进结果列表。
4. 顶层调用 `dfs(arr, 0)`，因为第一层元素的深度定义为 0。

以示例 2 为例，`n = 1`：处理 `[7, 8, [9, 10, 11], 12]` 时 `depth = 0 < 1`，展开它；其中 `[9, 10, 11]` 以 `depth = 1` 进入，命中 `depth == n`，原样返回 `[[9, 10, 11]]`，所以输出里它仍是嵌套的。而 `[4, 5, 6]` 在 `depth = 0` 展开后，元素 `4` 以 `depth = 1` 进入，是整数直接返回 `[4]`。

```python
def dfs(x, depth):
    if not isinstance(x, list):
        return [x]
    if depth == n:
        return [x]
    res = []
    for e in x:
        res.extend(dfs(e, depth + 1))
    return res

return dfs(arr, 0)
```

关键点：`depth == n` 的判断放在「是 list」之后，否则整数在 `depth == n` 时会被错误地包一层。`res.extend` 而不是 `append`，因为子调用返回的是列表。

## 复杂度
时间 O(元素总数)，每个节点只访问一次，展开与否不影响遍历次数。
空间 O(最大深度) 递归栈，加上输出列表本身 O(元素总数)。

## 易错点
- `n = 0` 时若把终止条件写成 `depth >= n` 且放在最前面，`arr` 本身是 list 会直接返回 `[arr]`，多包一层变成 `[[1, 2, 3, ...]]`；正确做法是先判非 list，再判 `depth == n`，让 `n = 0` 时顶层 `dfs(arr, 0)` 直接返回 `[arr]`，即原数组。
- 用 `res.append(dfs(e, depth + 1))` 而非 `extend`，示例 2 会得到 `[[1], [2], [3], [[4, 5, 6]], ...]` 这种每层多套一层的结构；正确做法是 `extend`，因为子调用返回的已经是「扁平化后的片段列表」。

## 如果面试官追问
若 `maxDepth` 到 10^5 导致递归爆栈怎么办？答：改成显式栈，栈里存 `(节点, depth)`，遇到 `depth == n` 的 list 直接整段塞进结果，避免递归。
