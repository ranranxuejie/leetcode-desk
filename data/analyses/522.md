## 一句话思路
答案必是某个 `strs[i]` 本身：枚举每个串，检查它是否不是任何其他串的子序列，取最长者。

## 怎么做
1. 关键结论：特殊序列若来自 `s` 的真子序列，那 `s` 本身也独有且更长，所以只需在 `strs` 原串里挑。
2. 对每个 `i`，用双指针判断 `strs[i]` 是否为 `strs[j]`（`j != i`）的子序列；一旦被某个 `j` 包含就淘汰。
3. 全部 `j` 都装不下它，就用 `len(strs[i])` 更新答案，最后没更新过返回 `-1`。

以 `strs = ["aba","cdc","eae"]` 为例：`i=0` 的 `"aba"` 对 `j=1` 的 `"cdc"` 匹配，指针走到 `"aba"` 的 `'b'` 就卡住，`p=1 < 3`，说明不是子序列；对 `j=2` 同理，于是答案记为 3。

```python
def is_sub(a, b):          # a 是否为 b 的子序列
    p = 0
    for ch in b:
        if p < len(a) and a[p] == ch:
            p += 1
    return p == len(a)

ans = -1
for i, s in enumerate(strs):
    if all(not is_sub(s, t) for j, t in enumerate(strs) if j != i):
        ans = max(ans, len(s))
```

注意 `is_sub` 里 `p < len(a)` 不能省，否则 `a` 走完后 `a[p]` 越界。

## 复杂度
时间 O(n² · L)：n 个串两两配对，每次双指针扫长度 L ≤ 10。
空间 O(1)：只用了 `p`、`ans` 两个标量，没有额外数组。

## 易错点
- 输入 `["aaa","aaa","aa"]` → 若只跟「不同下标」比却漏掉重复串，会误判 `"aaa"` 独有而返回 3 → 正确做法是 `j != i` 而非 `strs[j] != strs[i]`，重复串必须互相淘汰，答案 `-1`。
- 输入 `["a","b"]` → 若把「空串」也算特殊序列或直接返回 `len(strs)`，会错成 2 → 正确做法是逐串验证子序列关系，`"a"` 不是 `"b"` 的子序列，返回 1。

## 如果面试官追问
问：串长上限从 10 提到 10⁵ 怎么办？
答：结论不变，仍是 O(n²·L) 双指针；可先按长度降序排序，遇到第一个独有串立即返回，省掉大量短串比较。
