## 一句话思路
二分答案 L，对每个极大同字符段长度 c 算把它切成 ≤L 所需翻转数，总和 ≤ numOps 即可行。

## 怎么做
1. 把 s 切成极大同字符段，记录每段长度到 `runs`，例如 `s="000001"` 得 `runs=[5,1]`。
2. 二分 L ∈ [1, max(runs)]，判定函数 `need(L)` 累加每段的最小翻转数。
3. 关键公式：长度 c 的段切成每块 ≤L，需要 `c // (L+1)` 次翻转（翻转点把段隔开）。对 `s="000001"`、L=2，`runs=[5,1]` 得 `5//3 + 1//3 = 1 + 0 = 1 ≤ numOps=1`，可行；L=1 时 `5//2 + 1//2 = 2 + 0 = 2 > 1`，不可行，故答案是 2。
4. 二分取最小可行 L。

```python
def minLength(s, numOps):
    runs, cur = [], 1
    for i in range(1, len(s)):
        if s[i] == s[i-1]:
            cur += 1
        else:
            runs.append(cur); cur = 1
    runs.append(cur)

    def ok(L):
        return sum(c // (L + 1) for c in runs) <= numOps

    lo, hi = 1, max(runs)
    while lo < hi:
        mid = (lo + hi) // 2
        if ok(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo
```

## 复杂度
时间 O(n + n log n)：扫一遍建 runs 是 O(n)，二分 log(max(runs)) 每轮 O(段数)。
空间 O(n)：runs 最多存 n 个长度。

## 易错点
- 输入 `s="0000", numOps=2` → 若用 `c // L` 算翻转数会得 `4//1=4 > 2` 判 L=1 不可行，错答 2；正确是 `c // (L+1)`，`4//2=2 ≤ 2`，答 1。
- 输入 `s="0101", numOps=0` → 若二分下界取 0 或漏判 `numOps=0` 直接返回 1，会在 `lo=1, hi=1` 时正常返回，但若把 hi 初始化为 n 且 ok 里用 `<=` 边界写错会多算；正确做法是 hi 取 `max(runs)`，本题 runs 全为 1，直接返回 1。

## 如果面试官追问
若 n 扩大到 10^5 且要求输出具体翻转方案？答：二分出 L 后对每段按 `L+1` 间隔翻转，记录下标即可，仍是 O(n)。
