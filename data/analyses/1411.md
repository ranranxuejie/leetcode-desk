## 一句话思路
按行状态压缩：每行只有 12 种合法涂法，按「相邻行是否同构」分成 6 种 ABA 型和 6 种 ABC 型，用两个计数递推。

## 怎么做
1. 枚举一行 3 格的所有合法涂法（相邻不同），共 12 种；按首尾是否同色分成 ABA 型 6 种、ABC 型 6 种。
2. 设 `aba`、`abc` 为当前行以该型结尾的方案数，初值 `aba = abc = 6`（n=1 时 12 种）。
3. 推转移：ABA 行下一行可接 3 个 ABA + 2 个 ABC；ABC 行下一行可接 2 个 ABA + 2 个 ABC。
4. 迭代 n-1 次，返回 `(aba + abc) % MOD`。

以 n=2 验证：`aba' = 6*3 + 6*2 = 30`，`abc' = 6*2 + 6*2 = 24`，和 `30+24 = 54`，对上示例 2。

```python
MOD = 10**9 + 7
aba = abc = 6
for _ in range(n - 1):
    aba, abc = (3 * aba + 2 * abc) % MOD, (2 * aba + 2 * abc) % MOD
return (aba + abc) % MOD
```

关键中间值：n=3 时 `aba = 3*30+2*24 = 138`，`abc = 2*30+2*24 = 108`，和 `246`，对上示例 3。

## 复杂度
时间：O(n)，循环 n-1 次，每次常数次加乘。
空间：O(1)，只存 `aba`、`abc` 两个变量，无数组。

## 易错点
- 把 12 种行状态直接两两判兼容（12×12 表）也能过，但若漏掉「首尾同色」这一维度，n=2 会算成 12×某常数而非 54；正确做法是先按 ABA/ABC 归类再乘系数 3/2。
- 忘记取模：n=5000 时方案数远超 2**31-1，题目要求对 10**9+7 取余；若只在最后取模，中间值虽在 Python 里不溢出，但会拖慢大数运算，应在每步 `% MOD`。

## 如果面试官追问
问：若列数从 3 改成 m，怎么做？
答：行状态数变成 m 的合法染色数，按首尾同色/异色两类仍可递推，但状态数随 m 指数增长，需改用矩阵快速幂或按 m 小直接枚举。
