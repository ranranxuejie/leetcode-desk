## 一句话思路
按下标 1 到 n 枚举，用 `n % i == 0` 判断特殊元素，累加 `nums[i-1] ** 2`。

## 怎么做
1. 令 `n = len(nums)`，结果 `ans = 0`。
2. 用 `for i in range(1, n + 1)` 枚举 1-based 下标，注意取元素时写 `nums[i - 1]`。
3. 若 `n % i == 0`，把 `nums[i - 1] ** 2` 累加进 `ans`。
4. 返回 `ans`。

以 `nums = [1,2,3,4]` 为例，`n = 4`：`i = 1` 时 `4 % 1 == 0`，累加 `nums[0]**2 = 1`；`i = 2` 时 `4 % 2 == 0`，累加 `nums[1]**2 = 4`；`i = 3` 时 `4 % 3 == 1` 跳过；`i = 4` 时 `4 % 4 == 0`，累加 `nums[3]**2 = 16`，`ans` 依次为 1、5、21。

```python
n = len(nums)
ans = 0
for i in range(1, n + 1):
    if n % i == 0:
        ans += nums[i - 1] ** 2
return ans
```

关键中间值：`i = 3` 时 `n % i` 是 `1` 而不是 `0`，所以 `nums[2] = 3` 被排除，最终 21 而不是 30。

## 复杂度
时间：O(n)，枚举 n 个下标，每次一次取模和一次平方。
空间：O(1)，只开了 `ans` 和循环变量 `i`。

## 易错点
- 输入 `nums = [2,7,1,19,18,3]`，若把 `i` 当成 0-based 从 0 开始，`n % 0` 会抛 `ZeroDivisionError`；正确做法是 `range(1, n + 1)`，取元素时再减 1 写成 `nums[i - 1]`。
- 输入 `nums = [1,2,3,4]`，若判断条件写成 `i % n == 0`（除数和被除数颠倒），只有 `i = 4` 成立，答案会错成 16；正确做法是 `n % i == 0`，即「n 能被下标整除」。

## 如果面试官追问
问：n 放大到 10**9 但只给 n 不给数组怎么办？答：枚举 n 的约数即可，用 `for d in range(1, isqrt(n) + 1)` 成对收集，O(sqrt(n))。
