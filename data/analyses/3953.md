## 一句话思路
枚举选中的值 v（1..maxVal），用容斥统计与 v 不互质的元素个数，代价 = 该个数（v 不在 nums 中时再 +1），取 v - 代价 最大。

## 怎么做
1. 用 `cnt[x]` 记录 nums 中每个值出现次数，`present` 标记哪些值存在。
2. 对每个 v，分解出它的不同质因子列表 `primes`（v=1 时为空）。
3. 容斥：对 primes 的每个非空子集求乘积 d，`bad += (-1)^(k+1) * sum_cnt[d]`，其中 `sum_cnt[d]` 是 d 的所有倍数在 nums 中出现次数之和。
4. 代价 = bad + (0 if present[v] else 1)，得分 = v - 代价，取最大。

以示例 1 `nums=[3,4,6], maxVal=5` 为例，v=5 时 primes=[5]，`sum_cnt[5]=0`，bad=0，present[5]=False，代价=1，得分 5-1=4。v=4 时 primes=[2]，`sum_cnt[2]=cnt[4]+cnt[6]=2`，bad=2，代价=2，得分 2。

```python
# 预处理 sum_cnt[d] = nums 中 d 的倍数个数
sum_cnt = [0] * (maxVal + 1)
for d in range(1, maxVal + 1):
    for m in range(d, maxVal + 1, d):
        sum_cnt[d] += cnt[m]

best = 0
for v in range(1, maxVal + 1):
    ps = distinct_prime_factors(v)   # v=1 时为空
    bad = 0
    for mask in range(1, 1 << len(ps)):
        d, bits = 1, 0
        for i in range(len(ps)):
            if mask >> i & 1:
                d *= ps[i]; bits += 1
        bad += sum_cnt[d] if bits & 1 else -sum_cnt[d]
    cost = bad + (0 if present[v] else 1)
    best = max(best, v - cost)
```

## 复杂度
时间：筛倍数 O(maxVal log maxVal)，枚举 v 的容斥 O(maxVal · 2^ω)，ω≤6。
空间：`cnt`、`sum_cnt`、`present` 各 O(maxVal)。

## 易错点
- 把「与 v 不互质」误算成「等于 v」：`nums=[2,4], maxVal=4` 选 v=4 时，4 与 2 的 gcd 是 2，bad 应为 2（cnt[2]+cnt[4]），只数 cnt[4] 会得代价 1、得分 3，正确是 4-2=2。
- 忘记 v 不在 nums 中要额外 +1：示例 1 的 v=5 若漏加，代价算成 0、得分 5，超过正确答案 4；只有 `present[v]` 为真时才能省这 1 次修改。

## 如果面试官追问
若 maxVal 放大到 10^7 怎么办？答：筛倍数仍是 O(M log M) 可接受，但容斥枚举要改成只对「有质因子的 v」做，且用线性筛预处理最小质因子加速分解。
