## 一句话思路
用指针 `i` 同步走 `voyage`，DFS 时若子节点值与 `voyage[i]` 不符就翻转，翻转后仍不符则返回 `[-1]`。

## 怎么做
1. 维护全局下标 `i`，`dfs(node)` 先校验 `node.val == voyage[i]`，不等直接判失败。
2. 若左子存在且 `left.val != voyage[i+1]`，说明预期先走右子树，翻转当前节点并记录 `node.val`。
3. 翻转后依次 `dfs(left)`、`dfs(right)`，任一失败即整体失败。
4. 以 `root=[1,2,3], voyage=[1,3,2]` 为例：`i=0` 匹配 1，`i+1=1` 处 `voyage[1]=3` 而 `left.val=2`，翻转 1 记入答案，再走右子树 3、左子树 2，全部匹配，返回 `[1]`。

```python
def dfs(node):
    nonlocal i
    if not node or node.val != voyage[i]:
        return False
    i += 1
    if node.left and i < len(voyage) and node.left.val != voyage[i]:
        ans.append(node.val)
        return dfs(node.right) and dfs(node.left)
    return dfs(node.left) and dfs(node.right)
```

`i` 越界前必须先判 `node.val`，否则空树或长度不符时会 `IndexError`。

## 复杂度
时间 O(n)：每个节点恰好访问一次，`i` 单调递增到 n。
空间 O(h)：递归栈深度为树高 h，最坏链状 O(n)，答案列表另计。

## 易错点
- 输入 `root=[1,2], voyage=[2,1]` → 若只比较根就返回 `[]`，会错成「已匹配」；正确做法是 `dfs` 里先判 `node.val != voyage[i]` 立即返回 `[-1]`，根 1 对 `voyage[0]=2` 就失败。
- 输入 `root=[1,2,3], voyage=[1,2,3]` → 若见 `left.val != voyage[i+1]` 就无条件翻转，会把本不需翻的 1 记入答案；正确做法是先判 `node.left` 存在且值不等才翻，此处 `left.val=2 == voyage[1]`，不翻，返回 `[]`。

## 如果面试官追问
问：若允许返回任意一组翻转方案而非最少？答：本题翻转由 `voyage` 唯一确定，方案唯一，最少即唯一，无需额外搜索。
