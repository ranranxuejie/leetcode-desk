## 一句话思路
用单调队列维护每个右端点下「极差≤k」的最左边界，再用可删前缀异或字典树在该窗口内查最大异或。

## 怎么做
1. 预处理前缀异或 `pre[i] = nums[0]^...^nums[i-1]`，子数组 `[l,r]` 的异或值即 `pre[r+1]^pre[l]`。
2. 用两个单调队列（递减求 max、递增求 min）随右端点 `r` 右移，把左端点 `l` 推到满足 `max-min<=k` 的最小位置。
3. 维护一棵支持删除的前缀异或字典树，窗口是 `pre[l..r]`；对每个 `r`，在树中查与 `pre[r+1]` 异或最大的值。
4. 取所有查询结果的最大值。

以 `nums=[5,4,5,6], k=2` 为例：`pre=[0,5,1,4,2]`。`r=3` 时窗口内 `max=6,min=4`，差 2 合法，`l=1`；树中存 `{5,1,4}`，查 `pre[4]=2`，与 `5` 异或得 `7`，即答案。

```python
# 关键片段：滑动窗口 + 可删字典树
for r, x in enumerate(nums):
    push_max(r); push_min(r)          # 单调队列存下标
    while nums[dq_max[0]] - nums[dq_min[0]] > k:
        trie.remove(pre[l]); l += 1   # 左端点右移，同步删树
    trie.insert(pre[r + 1])
    ans = max(ans, trie.query(pre[r + 1]))
```

## 复杂度
时间：每个下标进出单调队列与字典树各一次，每次 15 位，共 O(n·15)。
空间：字典树节点 O(n·15)，两个单调队列 O(n)。

## 易错点
- 窗口是 `pre[l..r]` 而非 `pre[l..r+1]`：查 `pre[r+1]` 时若把 `pre[r+1]` 也插进树，会查到自身得 0，且漏掉 `l=r` 的单元素子数组；正确做法是先查后插，或插入时机与删除同步。
- 删除时字典树节点计数减到 0 后不能直接丢弃子树：`nums=[5,4,5,6], k=1` 中 `pre` 值 5 出现两次，若删一次就清空该路径，后续 `pre=5` 的查询会丢解；正确做法是节点只减 `cnt`，查询时跳过 `cnt==0` 的分支。

## 如果面试官追问
若要求输出该子数组的起止下标？答：在 `ans` 更新处同时记录当时的 `l` 与 `r`，窗口边界已由单调队列实时给出，无需回溯。
