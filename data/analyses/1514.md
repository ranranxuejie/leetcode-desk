## 一句话思路
把「概率相乘」取对数变成「权重相加」，求最长路等价于 Dijkstra 求最短路，用最大堆按当前概率从大到小扩展。

## 怎么做
1. 建邻接表 `graph[a].append((b, p))`，无向边两个方向都存，概率直接存原值不取对数。
2. 初始化 `best = [0.0]*n`，`best[start] = 1.0`，堆里放 `(-1.0, start)`（Python 只有小顶堆，取负号当大顶堆）。
3. 每次弹出 `(neg_p, u)`，若 `-neg_p < best[u]` 说明是过期条目，直接跳过；若 `u == end` 可提前返回。
4. 对 `u` 的每个邻居 `(v, p)`，若 `best[u] * p > best[v]` 就更新 `best[v]` 并压入 `(-best[v], v)`。

用示例 1 走一遍关键一步：`best[0]=1.0` 先弹出 0，把 `best[1]=0.5`、`best[2]=0.2` 入堆；接着弹出 1（0.5），算 `0.5*0.5=0.25 > best[2]=0.2`，于是 `best[2]` 被改成 0.25——这就是答案，直接边那条 0.2 的边被淘汰。

```python
import heapq
graph = [[] for _ in range(n)]
for (a, b), p in zip(edges, succProb):
    graph[a].append((b, p))
    graph[b].append((a, p))
best = [0.0] * n
best[start_node] = 1.0
heap = [(-1.0, start_node)]
while heap:
    neg_p, u = heapq.heappop(heap)
    if -neg_p < best[u]:
        continue
    if u == end_node:
        return best[u]
    for v, p in graph[u]:
        cand = best[u] * p
        if cand > best[v]:
            best[v] = cand
            heapq.heappush(heap, (-cand, v))
return 0.0
```

## 复杂度
时间：O((n + m) log m)，m = len(edges)，每条边最多触发一次入堆，堆操作贡献 log m。
空间：O(n + m)，邻接表存 2m 条边，`best` 数组和堆各 O(n)。

## 易错点
1. 示例 3 这种 `start=0, end=2` 但只有边 `[0,1]` 的输入 → 若循环结束直接返回 `best[end_node]` 会得到 0.0 没问题，但若把 `best` 初始化成 `-1` 再返回就会错成 -1 → 正确做法是 `best` 初始化为 `0.0`，无路径自然返回 0。
2. 概率为 0 的边（`succProb[i]=0`）→ 若用「`best[v]` 初始为 0 且判断 `cand > best[v]`」没问题，但若写成 `>=` 会让 0 概率节点反复入堆，堆膨胀到 O(m) 甚至超时 → 严格用 `>`，且弹出时用 `-neg_p < best[u]` 过滤过期条目。

## 如果面试官追问
问：如果要求输出这条最大概率路径的具体节点序列怎么办？
答：额外开 `parent` 数组，在 `best[v]` 被更新时记 `parent[v] = u`，最后从 `end_node` 沿 `parent` 回溯到 `start_node` 再反转。
