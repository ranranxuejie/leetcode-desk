## 一句话思路
用「懒删除大顶堆 + 哈希表存当前优先级」，堆里存 `(-priority, eventId)`，poll 时跳过已失效的堆顶。

## 怎么做
1. 初始化：`pri[eventId] = priority`，把 `(-priority, eventId)` 全部压入堆 `heap`。
2. `updatePriority`：只改 `pri[eventId] = newPriority`，同时把新元组压入堆，旧元组不删。
3. `pollHighest`：循环弹堆顶，若 `-p != pri[eid]` 说明是过期条目，丢弃；否则 `del pri[eid]` 并返回 `eid`。
4. 堆空则返回 `-1`。

以示例 1 为例：初始 `pri = {5:7, 2:7, 9:4}`，堆顶是 `(-7, 2)`（同优先级取 id 小）。第一次 poll 弹出 `(-7, 2)`，`-(-7) == pri[2] == 7` 成立，返回 2。随后 `updatePriority(9, 7)` 把 `pri[9]` 改成 7 并压入 `(-7, 9)`，此时堆里还留着过期的 `(-4, 9)`。第二次 poll 堆顶 `(-7, 5)` 有效，返回 5；第三次堆顶 `(-7, 9)` 有效，返回 9。

```python
import heapq

def init(events):
    pri = {eid: p for eid, p in events}
    heap = [(-p, eid) for eid, p in events]
    heapq.heapify(heap)
    return pri, heap

def update(pri, heap, eid, newp):
    pri[eid] = newp
    heapq.heappush(heap, (-newp, eid))

def poll(pri, heap):
    while heap:
        negp, eid = heapq.heappop(heap)
        if pri.get(eid) == -negp:
            del pri[eid]
            return eid
    return -1
```

关键点：`pri.get(eid)` 用 `get` 而非 `pri[eid]`，因为被 poll 掉的事件在 `pri` 里已删除，堆中残留条目会触发 `KeyError`。

## 复杂度
时间：初始化 `O(n)` 建堆，每次 update `O(log n)`，每次 poll 均摊 `O(log n)`（每条过期条目最多弹一次）。
空间：`pri` 存 `O(n)`，堆因每次 update 多压一条，最坏 `O(n + m)`，`m` 为 update 次数。

## 易错点
- 堆里存 `(priority, eventId)` 而非 `(-priority, eventId)`：Python 是小顶堆，直接存正优先级会先弹出优先级最低的 4 而不是 7，必须取负。
- `pollHighest` 里用 `pri[eid]` 判断有效性：被 poll 过的事件已从 `pri` 删除，堆中残留条目会让 `pri[eid]` 抛 `KeyError`，应写 `pri.get(eid) == -negp`。

## 如果面试官追问
若要求 poll 后能「恢复」被移除的事件怎么办？答：把 poll 出的事件另存一个栈，恢复时重新压回堆并写回 `pri`。
