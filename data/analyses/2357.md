## 一句话思路
答案就是 `nums` 中不同正整数的个数：每次取当前最小非零值 x，恰好把这一层元素清零。

## 怎么做
1. 把所有元素丢进 `set`，重复值自动合并。
2. 去掉 0（0 本来就不需要操作），剩下的个数就是答案。
3. 用示例 `[1,5,0,3,5]` 走一遍：`set` 得到 `{0,1,3,5}`，去掉 0 后是 `{1,3,5}`，大小 3，与输出 3 一致。
4. 为什么成立：每次操作必须选 x ≤ 当前最小非零值，选更小的 x 只会让同一层多花一步；选 x = 当前最小非零值，正好把这一层全部清零，所以每个不同的正值恰好消耗一次操作。

```python
def minimumOperations(nums):
    return len({v for v in nums if v > 0})
```

等价写法：`len(set(nums) - {0})`。两种都是 O(n) 时间。

## 复杂度
时间 O(n)：遍历 `nums` 一次建集合，n 是数组长度。
空间 O(n)：集合最多存 n 个不同值，最坏全不重复。

## 易错点
- 输入 `[0,0,0]` → 若直接 `len(set(nums))` 会得 1，错答成 1 次操作；正确做法是过滤掉 0，答案应为 0。
- 输入 `[2,2,2]` → 若按「逐个元素清零」计数会得 3；正确做法是先去重，三个 2 属于同一层，一次 x=2 全部清零，答案为 1。

## 如果面试官追问
问：如果要求输出每次选的 x 序列怎么办？
答：把去重后的正值升序排序，依次输出相邻差值即可，最后一个差值就是最大值本身。
