## 一句话思路
前缀和 + 哈希表记录「以 i 结尾的最短达标子数组长度」，再扫一遍用「左侧最优 + 右侧当前」拼出答案。

## 怎么做
1. 用滑动窗口（arr[i] 全正，窗口和单调）找出所有和为 target 的窗口，记 `best[i]` = 以 i 结尾的达标子数组最短长度。
2. 对 `best` 做前缀最小值 `pre[i] = min(best[0..i])`，表示「右端点 ≤ i 的最短达标长度」。
3. 再扫每个窗口 `[l, r]`，若 `l >= 1` 且 `pre[l-1]` 有效，用 `pre[l-1] + (r-l+1)` 更新答案。

以 `arr = [7,3,4,7], target = 7` 为例：窗口是 `[0,0]`、`[1,2]`、`[3,3]`，`best = [1, INF, 2, 1]`，`pre = [1, 1, 1, 1]`。处理窗口 `[3,3]` 时 `pre[2] = 1`，答案 `1 + 1 = 2`。

```python
n = len(arr)
INF = 10**9
best = [INF] * n
s = l = 0
for r in range(n):
    s += arr[r]
    while s > target and l <= r:
        s -= arr[l]; l += 1
    if s == target:
        best[r] = r - l + 1
pre = best[:]
for i in range(1, n):
    pre[i] = min(pre[i], pre[i-1])
ans = INF
for r in range(n):
    if best[r] < INF:
        l = r - best[r] + 1
        if l >= 1 and pre[l-1] < INF:
            ans = min(ans, pre[l-1] + best[r])
return -1 if ans == INF else ans
```

## 复杂度
时间 O(n)：滑动窗口和两次线性扫描各 O(n)，无 log 项。
空间 O(n)：`best` 和 `pre` 两个长度 n 的数组。

## 易错点
- `arr = [1,1,1], target = 2`：若窗口收缩写成 `while s >= target`，会把和恰为 target 的窗口也缩掉，`best` 全为 INF 返回 -1；正确是 `while s > target` 才收缩，`s == target` 时立即记录长度。
- `arr = [3,2,2,4,3], target = 3`：若用 `pre[r]` 而非 `pre[l-1]` 去拼，会取到与当前窗口重叠的左侧子数组（如 `[0,0]` 配 `[0,0]`），长度和算成 2 但实际重叠；必须用严格在 `l` 左侧的 `pre[l-1]`。

## 如果面试官追问
要求输出这两个子数组的下标而非长度和？答：`pre` 里存最短长度对应的起始下标，拼答案时同时记录两个窗口的 `(l, r)` 即可。
