## 一句话思路
把 nums2 按值计数，再对每个 nums1[i] 枚举 k 的倍数做整除判定，用哈希表把 O(n·m) 降到 O(n·√V)。

## 怎么做
1. 用 `Counter(nums2)` 得到每个值出现次数 `cnt2`。
2. 对每个 `x = nums1[i]`，若 `x % k != 0` 直接跳过（不可能被 `nums2[j]*k` 整除）。
3. 令 `t = x // k`，枚举 `t` 的所有因子 `d`，若 `d in cnt2` 则累加 `cnt2[d]`；同时若 `t // d != d` 且 `t // d in cnt2` 也累加。
4. 返回累加总和。

以示例 2 为例：`nums1=[1,2,4,12], nums2=[2,4], k=3`。`cnt2={2:1,4:1}`。`x=12` 时 `t=4`，因子对 `(1,4)`、`(2,2)`：`4 in cnt2` 贡献 1，`2 in cnt2` 贡献 1，合计 2；其余 `x=1,2,4` 均 `x%3!=0` 跳过，答案 2。

```python
from collections import Counter
cnt2 = Counter(nums2)
ans = 0
for x in nums1:
    if x % k:
        continue
    t = x // k
    d = 1
    while d * d <= t:
        if t % d == 0:
            ans += cnt2.get(d, 0)
            if d != t // d:
                ans += cnt2.get(t // d, 0)
        d += 1
```

## 复杂度
时间：O(n·√(V/k))，每个 nums1 元素枚举到 √t，V=10^6。
空间：O(m)，`cnt2` 存 nums2 去重后的值。

## 易错点
- `nums1=[1,3,4], nums2=[1,3,4], k=1` 若漏掉 `x % k` 判断，`x=1` 时 `t=1` 仍能正确枚举，但 `k>1` 时如示例 2 的 `x=1` 会算出 `t=0` 导致死循环或除零 → 必须先 `if x % k: continue`。
- 因子对 `(d, t//d)` 当 `d == t//d` 时若不加 `d != t//d` 判断，`t=4` 的 `d=2` 会被计两次 → 平方根处只加一次。

## 如果面试官追问
若 nums1 长度到 10^6 而值域不变，怎么办？答：仍用因子枚举，瓶颈在 √t 而非 n·m，可预处理 1..10^6 的因子表换空间。
