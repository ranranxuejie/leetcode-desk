## 一句话思路
统计每个字符频次，只保留频次最大的 k 个字符，删掉其余字符的全部出现，用排序后累加最小频次实现。

## 怎么做
1. 用 `Counter(s)` 得到每个字符的频次，转成列表 `freqs`。
2. 若 `len(freqs) <= k` 直接返回 0，无需删除。
3. 对 `freqs` 升序排序，删掉频次最小的 `len(freqs) - k` 个字符（整类删除，代价就是它们的频次和）。
4. 累加这部分频次即为答案。

以 `s = "yyyzz", k = 1` 为例：`freqs = [3, 2]`，排序后 `[2, 3]`，需删 `2 - 1 = 1` 个字符，取最小的 `2`，答案 `2`——即删光 `'z'`。

```python
from collections import Counter

def minDeletion(s, k):
    freqs = sorted(Counter(s).values())
    if len(freqs) <= k:
        return 0
    drop = len(freqs) - k
    return sum(freqs[:drop])
```

关键点：删除某字符必须删它的**全部**出现，所以每类字符的代价是它的频次，问题退化为「从频次集合里去掉若干个，使剩余个数 ≤ k，最小化和」。贪心选最小频次删除最优，因为删哪个字符对「剩余个数」的贡献都是 1，代价却不同。

## 复杂度
时间：O(n + m log m)，n 为 `len(s)` 扫描计数，m 为不同字符数（≤26）排序。
空间：O(m)，`Counter` 与 `freqs` 各存一份频次。

## 易错点
- `s = "aabb", k = 2` → 若先判断 `len(freqs) > k` 才排序，容易漏掉「不同字符数已 ≤ k 时返回 0」的短路，误删字符得 2；正确做法是先比较 `len(freqs)` 与 `k`，相等或更小直接返回 0。
- `s = "abc", k = 2` → 若按「删到剩 k 个字符出现次数」理解，会去删单个 `'c'` 得 1 看似对，但换成 `s = "aaabc", k = 2` 时删单个 `'c'` 只减 1 个不同字符却留下 `'a'` 3 次，若误删 `'a'` 的两次出现会得 2；正确做法是整类删除，代价取该字符完整频次，答案应为 1（删 `'c'`）。

## 如果面试官追问
问：若 k 可大于不同字符数、且要求输出删除后的字符串？
答：先按频次升序删够 `len(freqs) - k` 类字符，再用集合过滤原串保留剩余字符即可。
