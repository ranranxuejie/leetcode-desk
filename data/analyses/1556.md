## 一句话思路
从右往左每数满 3 位就插一个点，用字符串切片 `s[max(0,i-3):i]` 拼块，天然处理最左边不足 3 位的情况。

## 怎么做
1. 先把 `n` 转成字符串 `s = str(n)`，长度记为 `L`。
2. 从右端 `i = L` 开始，每次取 `s[max(0, i-3):i]` 作为一块，把 `i` 减 3。
3. 把各块收集进列表，最后用 `"."` 反转拼接。
4. 循环终止条件是 `i > 0`，这样 `n = 0` 时 `s = "0"`、`i = 1`，仍会取到 `"0"` 这一块，不会返回空串。

以 `n = 123456789` 为例，`s = "123456789"`、`L = 9`。第一轮 `i = 9`，取 `s[6:9] = "789"`；第二轮 `i = 6`，取 `s[3:6] = "456"`；第三轮 `i = 3`，取 `s[0:3] = "123"`；此时 `i = 0` 退出。块列表是 `["789", "456", "123"]`，反转后拼成 `"123.456.789"`。

```python
s = str(n)
parts = []
i = len(s)
while i > 0:
    parts.append(s[max(0, i - 3):i])
    i -= 3
return ".".join(reversed(parts))
```

关键点在于 `max(0, i - 3)`：当 `i = 4`（如 `n = 1234`）时，第二轮取 `s[0:1] = "1"`，而不是 `s[-2:1]` 这种空串，最左块自动变短。

## 复杂度
时间 O(log n)：`str(n)` 产生 `L = ⌊log10 n⌋ + 1` 位，循环 `⌈L/3⌉` 次，每次切片长度 ≤ 3。
空间 O(log n)：`parts` 存 `⌈L/3⌉` 个块，加上结果串共 O(L) 字符。

## 易错点
- `n = 0` → 若写成 `while i > 3` 或先判断 `len(s) <= 3` 直接返回，容易走进死循环或返回空串 → 正确做法是循环条件用 `i > 0`，让 `"0"` 也走一次切片。
- `n = 1234` → 若用 `s[i-3:i]` 而不加 `max(0, ...)`，第二轮 `i = 1` 时 `s[-2:1]` 得到空串，输出变成 `".234"` 或 `"1234"` → 正确做法是左边界取 `max(0, i - 3)`。

## 如果面试官追问
问：如果 `n` 是负数，比如 `-1234` 怎么办？
答：先取 `sign = "-" if n < 0 else ""`，对 `str(abs(n))` 做同样分块，最后 `sign + ".".join(...)`，注意别把负号算进三位分组。
