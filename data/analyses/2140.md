## 一句话思路
从后往前 DP，`dp[i]` 表示从第 i 题开始能拿的最高分，解决则跳到 `i + brainpower[i] + 1`。

## 怎么做
1. 开长度 `n + 1` 的 `dp`，`dp[n] = 0` 作哨兵，表示越界后无题可做。
2. 倒序遍历 `i` 从 `n-1` 到 `0`，取「跳过」与「解决」的较大值。
3. 解决时下一题下标是 `i + questions[i][1] + 1`，用 `min(..., n)` 夹住防止越界。
4. 返回 `dp[0]`。

以示例 1 `questions = [[3,2],[4,3],[4,4],[2,5]]` 为例，`n = 4`：
- `i=3`：跳过得 `dp[4]=0`，解决得 `2 + dp[min(3+5+1,4)] = 2 + dp[4] = 2`，`dp[3]=2`。
- `i=2`：跳过得 `dp[3]=2`，解决得 `4 + dp[min(2+4+1,4)] = 4 + dp[4] = 4`，`dp[2]=4`。
- `i=1`：跳过得 `dp[2]=4`，解决得 `4 + dp[min(1+3+1,4)] = 4 + dp[4] = 4`，`dp[1]=4`。
- `i=0`：跳过得 `dp[1]=4`，解决得 `3 + dp[min(0+2+1,4)] = 3 + dp[3] = 5`，`dp[0]=5`。

关键中间值就是 `i=0` 那步的 `3 + dp[3] = 3 + 2 = 5`，正好是答案。

```python
n = len(questions)
dp = [0] * (n + 1)
for i in range(n - 1, -1, -1):
    p, b = questions[i]
    nxt = min(i + b + 1, n)
    dp[i] = max(dp[i + 1], p + dp[nxt])
return dp[0]
```

注意 `dp[i+1]` 是「跳过第 i 题」的收益，不是 `dp[i]` 本身，倒序保证它已算好。

## 复杂度
时间 O(n)：每个下标 i 只做一次常数比较与加法。
空间 O(n)：额外开了长度 n+1 的 dp 数组，可优化到 O(1) 但没必要。

## 易错点
- 写成 `i + b` 而不是 `i + b + 1`：示例 1 中 `i=0, b=2`，若跳到 `dp[2]=4` 会得 `3+4=7`，把本该禁掉的第 2 题又算了进去，正确是跳到 `dp[3]`。
- 忘记 `min(..., n)` 夹边界：示例 1 的 `i=3, b=5` 算出下标 9，直接索引 `dp[9]` 抛 IndexError；夹到 `dp[4]=0` 才对。

## 如果面试官追问
问：要求输出具体选了哪些题怎么办？
答：再开一个 `choice` 数组记录每步选跳过还是解决，从 `dp[0]` 顺着 `i+1` 或 `i+b+1` 回溯即可。
