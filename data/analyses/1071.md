## 一句话思路
若 `str1 + str2 == str2 + str1`，答案就是两者长度的最大公约数对应的前缀，否则为空串。

## 怎么做
1. 先判 `str1 + str2 != str2 + str1`，不等直接返回 `""`。
2. 相等则答案长度必为 `gcd(len(str1), len(str2))`，用 `math.gcd` 求。
3. 返回 `str1[:g]`。

以示例 2 为例：`str1 = "ABABAB"`、`str2 = "ABAB"`，拼接后 `"ABABABABAB" == "ABABABABAB"` 成立；`g = gcd(6, 4) = 2`，取 `str1[:2]` 得 `"AB"`。

```python
from math import gcd

def gcdOfStrings(str1, str2):
    if str1 + str2 != str2 + str1:
        return ""
    g = gcd(len(str1), len(str2))
    return str1[:g]
```

拼接相等这一步是关键：它同时保证了「存在公共周期」和「周期长度能整除两者」。示例 4 的 `"AAAAAB" + "AAA" = "AAAAABAAA"`，而 `"AAA" + "AAAAAB" = "AAAAAAAAB"`，两者不等，直接返回 `""`，无需再试 `gcd(6, 3) = 3` 取 `"AAA"` 这种错误答案。

## 复杂度
时间：O(n + m)，拼接与比较各扫一遍两串总长，`gcd` 是 O(log min(n,m))。
空间：O(n + m)，`str1 + str2` 和 `str2 + str1` 各开一个新串。

## 易错点
- 输入 `str1 = "AAAAAB", str2 = "AAA"` → 若跳过拼接判断、直接取 `str1[:gcd(6,3)] = "AAA"`，会错答 `"AAA"` → 必须先验证 `str1 + str2 == str2 + str1`。
- 输入 `str1 = "ABABAB", str2 = "ABAB"` → 若误以为答案是较短串 `str2` 本身，会错答 `"ABAB"` → 正确长度是 `gcd(6,4) = 2`，答案只能是 `str1[:2]`。

## 如果面试官追问
问：若要求返回所有能同时除尽两串的 x，而非最长？
答：所有长度是 `g` 的约数的前缀都合法，枚举 `g` 的因子逐个校验即可。
