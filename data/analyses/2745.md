## 一句话思路
把 z 个 "AB" 当作可无限插入的隔板，先算出 x 个 AA 与 y 个 BB 交替能拼出的最长骨架，再插 AB。

## 怎么做
1. 先只用 AA 和 BB：同类不能相邻（否则出现 AAA/BBB），所以两者必须交替，骨架最多用 `2*min(x,y)+1` 个块。
2. 骨架里 AA 与 BB 的块数差至多 1，因此骨架长度 = `2*(2*min(x,y)+1)`，但受总数限制，实际是 `2*(min(x,y)*2 + (1 if x!=y else 0))`。
3. 剩下的同类块（`abs(x-y)-1` 个）无法直接接上，只能靠 AB 隔开：每个 AB 能"救"一个多余块，所以最多再补 `min(z, abs(x-y)-1)` 个块。
4. 剩余 AB 全部追加到末尾，每个贡献长度 2。

以示例 1 `x=2, y=5, z=1` 为例：`min=2`，骨架用 2 个 AA + 2 个 BB，长度 8；多余 BB 有 `5-2-1=2` 个，但 z=1 只能救 1 个，补长度 2；剩余 AB 为 0。总计 `8+2=10`？实际答案 12——说明骨架应取 `2*min+1` 个块（AA、BB 各 2 个再加 1 个 BB），长度 `2*(2*2+1)=10`，再补 1 个 AB 得 12。

```python
def longestString(x, y, z):
    base = 2 * min(x, y)
    if x != y:
        base += 1
    extra = min(z, abs(x - y) - 1) if x != y else 0
    used_z = extra
    return 2 * (base + extra) + 2 * (z - used_z)
```

## 复杂度
时间：O(1)，只做常数次算术。
空间：O(1)，无额外数据结构。

## 易错点
- `x == y` 时误用 `abs(x-y)-1 = -1` 去算 extra → 得到负数或错误补偿 → 应特判 `x != y` 才计算多余块。
- 忘记剩余 AB 也要计入长度 → 示例 2 中 `z=2` 只用 1 个救场，漏算另 1 个 AB 的 2 长度 → 必须 `2*(z-used_z)` 补上。

## 如果面试官追问
问：若要求输出具体拼接方案？答：按骨架交替排 AA/BB，多余块前插 AB，末尾追加剩余 AB 即可。
