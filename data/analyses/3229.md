## 一句话思路
令 `d[i] = target[i] - nums[i]`，答案等于 `d` 的「正部上升量 + 负部下降量」，用单调栈按段合并。

## 怎么做
1. 先算差分数组 `d[i] = target[i] - nums[i]`，把问题变成「用区间 ±1 把全 0 数组变成 `d`」。
2. 正数段和负数段互不干扰，可以分开算：正部只统计「比左侧同段元素高出来的部分」，负部对称。
3. 用单调栈维护当前段内**严格递减**的正值序列；新值 `x` 若比栈顶小，就把栈顶弹出（它被更矮的 `x` 覆盖了），弹到栈顶 ≥ x 为止，再把 `x` 入栈。
4. 每次入栈时，若 `x` 大于栈顶（或栈空），答案加上 `x - 栈顶`（栈空时栈顶视为 0）。

以示例 1 为例：`d = [1,1,1,2]`。前三个 1 依次入栈，栈为 `[1]`（相等不重复入），贡献 1；遇到 2 时栈顶 1 < 2，贡献 `2-1=1`，累计 2。负部为空，答案 2。

```python
def solve(d):
    ans = 0
    for sign in (1, -1):
        st = []
        for v in d:
            x = v * sign
            if x <= 0:
                st = []
                continue
            while st and st[-1] > x:
                st.pop()
            top = st[-1] if st else 0
            if x > top:
                ans += x - top
            if not st or st[-1] != x:
                st.append(x)
    return ans
```

关键点：`st[-1] > x` 用严格大于，相等时不弹也不重复加贡献。

## 复杂度
时间：O(n)，每个元素在正、负两轮里各入栈出栈至多一次。
空间：O(n)，最坏情况（`d` 严格递增）栈深度为 n。

## 易错点
- 输入 `d = [2,1,2]`：若弹栈条件写成 `st[-1] >= x`，遇到中间的 1 会把 2 弹掉，后面再遇 2 又加一次 `2-0`，答案变 5；正确是 `>`，得 3（区间 [0,2] 加 1 再 [0,0]、[2,2] 各加 1）。
- 输入 `d = [1,1,1]`：若相等时也入栈并加 `x - top`，会加 0 不影响答案但栈变长；若写成「相等也弹再入」，栈顶变 0，第三个 1 会多算 1，答案变 2。正确做法是相等时既不弹也不加。

## 如果面试官追问
问：要求输出具体操作方案怎么办？
答：在栈里同时存下标，弹栈时把被覆盖的区间右端点记下来，回溯即可还原每段的高度差操作。
