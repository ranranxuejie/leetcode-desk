## 一句话思路
把每个词倒序存哈希表，枚举每个词的所有切分点，用「左半回文查右半倒序」和「右半回文查左半倒序」两种方式配对。

## 怎么做
1. 建 `rev = {w[::-1]: i}`，键是倒序串，值是原下标。
2. 对每个 `words[i]`，枚举切分点 `k` 从 0 到 `len(w)`，把 `w` 切成 `left = w[:k]`、`right = w[k:]`。
3. 若 `left` 是回文且 `right[::-1]` 在 `rev` 中且下标不等于 `i`，则 `(rev[right[::-1]], i)` 成对；若 `right` 是回文且 `left[::-1]` 在 `rev` 中且下标不等于 `i`，则 `(i, rev[left[::-1]])` 成对。
4. 用 `set` 去重后转列表返回。

以 `words = ["abcd","dcba","lls","s","sssll"]` 为例，`rev` 含 `{"dcba":0, "abcd":1, "sll":2, "s":3, "llsss":4}`。处理 `i=2, w="lls"` 时，`k=1` 得 `left="l"`（回文）、`right="ls"`，`right[::-1]="sl"` 不在 `rev`；`k=2` 得 `left="ll"`（回文）、`right="s"`，`right[::-1]="s"` 命中下标 3，得 `(3,2)`。处理 `i=4, w="sssll"` 时，`k=3` 得 `left="sss"`（回文）、`right="ll"`，`right[::-1]="ll"` 不在 `rev`；`k=2` 得 `left="ss"`（回文）、`right="sll"`，`right[::-1]="lls"` 命中下标 2，得 `(2,4)`。

```python
rev = {w[::-1]: i for i, w in enumerate(words)}
res = set()
for i, w in enumerate(words):
    for k in range(len(w) + 1):
        left, right = w[:k], w[k:]
        if left == left[::-1] and right[::-1] in rev and rev[right[::-1]] != i:
            res.add((rev[right[::-1]], i))
        if right == right[::-1] and left[::-1] in rev and rev[left[::-1]] != i:
            res.add((i, rev[left[::-1]]))
return [list(p) for p in res]
```

## 复杂度
时间：O(sum(len(w)) × 平均串长)，每个切分点做一次回文判断和一次哈希查找。
空间：O(sum(len(w)))，`rev` 存所有倒序串，`res` 存答案对。

## 易错点
- 输入 `["a",""]`：若只处理 `k` 从 1 到 `len(w)`，空串 `""` 的 `k=0` 被漏掉，`(0,1)` 和 `(1,0)` 都丢失；必须让 `k` 取到 `0` 和 `len(w)`，空串本身也是回文。
- 输入 `["bat","tab","cat"]`：若忘记 `rev[...] != i` 判断，`"bat"` 切 `k=0` 时 `left=""` 回文、`right="bat"`，`right[::-1]="tab"` 命中下标 1 得 `(0,1)` 正确；但 `"tab"` 切 `k=3` 时 `right=""` 回文、`left="tab"`，`left[::-1]="bat"` 命中下标 0 得 `(1,0)`，若同时 `k=0` 又命中自身会多出 `(0,0)`，必须排除 `i==j`。

## 如果面试官追问
问：若 `words` 长度到 10^5、单串长度到 10^3，还能用这方法吗？
答：不能，O(sum × 平均串长) 会超；改用字典树存倒序串，边遍历边判回文，仍是 O(sum(len))。
