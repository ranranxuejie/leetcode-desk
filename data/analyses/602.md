## 一句话思路
把 requester_id 和 accepter_id 两列纵向拼成一列，按人分组计数，取计数最大者。

## 怎么做
1. 用 `UNION ALL` 把 `requester_id` 和 `accepter_id` 拼成单列 `id`，每条好友关系贡献两行。
2. 对 `id` 做 `GROUP BY`，`COUNT(*)` 得到每人的好友数 `num`。
3. 按 `num` 降序取第一行（题目保证唯一）。

以官方示例为例：拼出的 id 列为 `1,1,2,3,2,3,3,4`，分组后 `1→2, 2→2, 3→3, 4→1`，最大值 3 对应 id=3。

```python
import pandas as pd

def most_friends(request_accepted: pd.DataFrame) -> pd.DataFrame:
    ids = pd.concat([
        request_accepted["requester_id"],
        request_accepted["accepter_id"],
    ], ignore_index=True)
    cnt = ids.value_counts().reset_index()
    cnt.columns = ["id", "num"]
    return cnt.sort_values("num", ascending=False).head(1)
```

关键中间值：`ids.value_counts()` 得到 `3:3, 1:2, 2:2, 4:1`，`head(1)` 取到 `id=3, num=3`。

## 复杂度
时间 O(n)：n 为表行数，拼接后 2n 行，分组计数线性。
空间 O(n)：额外存 2n 长的 id 序列和去重后的计数表。

## 易错点
- 只统计 `requester_id` 一列 → 示例中 id=4 只出现在 accepter 侧，会被漏掉，num 全错；必须两列 `UNION ALL`（不是 `UNION`，否则同一人既是请求方又是接收方时重复关系会被去重）。
- 用 `UNION` 而非 `UNION ALL` 拼接 → 示例里 id=1 出现两次（作为 requester 两行）会被压成一次，1 的 num 从 2 变 1；本题关系表主键保证无重复对，但同一 id 在两列各出现是常态，必须保留全部行。

## 如果面试官追问
问：若多人并列最多怎么办？答：去掉 `head(1)`，改成 `cnt[cnt["num"] == cnt["num"].max()]` 返回全部并列者。
