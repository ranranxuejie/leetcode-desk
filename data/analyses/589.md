## 一句话思路
用栈迭代：入栈时把子节点**逆序**压入，弹出顺序就正好是前序。

## 怎么做
1. 空树直接返回 `[]`，否则 `stack = [root]`、`res = []`。
2. 循环 `while stack`：`node = stack.pop()`，把 `node.val` 追加进 `res`。
3. 关键一步：把 `node.children` **从右往左**压栈，即 `for c in reversed(node.children): stack.append(c)`。
4. 栈空时 `res` 就是前序序列。

以示例 1 的 `root = [1,null,3,2,4,null,5,6]` 为例：根 1 的子节点是 `[3,2,4]`，逆序压栈后 `stack = [4,2,3]`；下一次 `pop()` 拿到 3 而不是 4，所以 `res` 先变成 `[1,3]`，再压 3 的子节点 `[5,6]` 逆序得 `stack = [4,2,6,5]`，接着弹出 5、6，最后才是 2、4，输出 `[1,3,5,6,2,4]`。若写成正序 `for c in node.children`，`stack` 变 `[3,2,4]`，弹出顺序就成了 4、2、3，输出错成 `[1,4,2,3,...]`。

```python
if not root:
    return []
stack, res = [root], []
while stack:
    node = stack.pop()
    res.append(node.val)
    for c in reversed(node.children):
        stack.append(c)
return res
```

递归版只需三行：先 `res.append(root.val)`，再对 `root.children` 里每个孩子递归。迭代版的价值在于高度 1000 时不受 Python 默认递归深度约 1000 的限制。

## 复杂度
时间 O(n)：每个节点恰好入栈、出栈、追加各一次，`reversed` 只是迭代器不复制。
空间 O(n)：`res` 存 n 个值；栈最坏存一整层节点，n 叉树宽时也是 O(n)。

## 易错点
- 子节点正序压栈 → 示例 1 输出 `[1,4,2,3,6,5]` 这类镜像结果 → 必须 `reversed(node.children)`，因为栈是后进先出。
- `root` 为 `None`（节点总数可为 0）→ 直接 `stack=[None]` 后 `node.val` 抛 `AttributeError` → 入口先判 `if not root: return []`，别指望循环条件兜住。

## 如果面试官追问
问：不用栈也不用递归，能 O(1) 额外空间吗？
答：n 叉树没有父指针做不到；若节点带 `parent` 指针，可用 Morris 式线索化，但实现复杂、收益低。
