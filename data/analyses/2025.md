## 一句话思路
枚举被改的下标，用前缀和哈希表统计「改前已平衡的 pivot」与「改后新平衡的 pivot」，取最大。

## 怎么做
1. 设 `S = sum(nums)`，`pre[i] = nums[0..i-1]`。pivot 在 `p` 处平衡等价于 `pre[p] = S - pre[p]`，即 `2*pre[p] = S`。
2. 先把所有 `pre[p]`（`p=1..n-1`）丢进哈希表 `cnt`，得到不改动时的平衡数 `base`。
3. 遍历 `i` 从 0 到 n-1，把 `nums[i]` 改成 `k`，总和变为 `S' = S - nums[i] + k`。对 `p <= i` 的 pivot，左半含改动，条件变为 `2*pre[p] + (k - nums[i]) = S`；对 `p > i`，左半不含改动，条件变为 `2*pre[p] = S'`。
4. 用两个哈希表分别维护「左侧已扫过的 pre」和「右侧未扫的 pre」，边扫边把 `pre[i+1]` 从右表移到左表，每步取 `left[目标1] + right[目标2]` 的最大值。

以 `nums=[2,-1,2], k=3` 为例：`S=3`，`pre=[0,2,1,3]`，`p=1,2` 的 `pre` 是 `2,1`，`2*pre` 为 `4,2`，都不等于 3，`base=0`。改 `i=0` 时 `S'=4`，`p=1` 左含改动：`2*2+(3-2)=5≠3`；`p=2` 左含改动：`2*1+1=3`，命中，答案 1。

```python
S = sum(nums)
pre = [0] * (n + 1)
for i in range(n):
    pre[i + 1] = pre[i] + nums[i]
right = {}
for p in range(1, n):
    right[pre[p]] = right.get(pre[p], 0) + 1
left, ans = {}, 0
for i in range(n):
    d = k - nums[i]
    ans = max(ans, left.get((S - d) // 2, 0) + right.get(S // 2, 0))
    # 注意：上面这行需按奇偶修正，见易错点
    left[pre[i + 1]] = left.get(pre[i + 1], 0) + 1
    right[pre[i + 1]] -= 1
```

## 复杂度
时间 O(n)：一次前缀和加一次线性扫描，哈希表均摊 O(1)。
空间 O(n)：`pre` 数组与两个哈希表各存至多 n 个键。

## 易错点
- 目标值 `(S-d)//2` 在 `S-d` 为奇数时会被整除截断，误命中不存在的 pivot。正确做法是先判 `(S-d) % 2 == 0` 再查表，否则该侧贡献记 0。
- `right` 表在 `i` 步应只含 `p > i` 的 `pre[p]`，若先查后移或忘记把 `pre[i+1]` 从 `right` 减掉，会把 `p = i+1` 重复计入左侧，导致 `nums=[0,0,0]` 这类全零数组答案偏大。

## 如果面试官追问
问：若要求输出所有最优 pivot 下标而非计数？
答：把两个哈希表的值从计数改成下标列表，取最大时合并对应列表即可，时间不变。
