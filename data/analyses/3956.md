## 一句话思路
用 DP 加单调队列：`dp[k][i]` 表示前 i 个元素选 k 段的最大和，转移时用长度窗口 `[l, r]` 的滑动最大值把 O(n) 压到 O(1)。

## 怎么做
1. 前缀和 `pre[i] = sum(nums[:i])`，任意子数组和 `pre[i] - pre[j]`。
2. 定义 `dp[k][i]`：前 i 个元素中选恰好 k 段（第 k 段可不在 i 结尾）的最大和，转移 `dp[k][i] = max(dp[k][i-1], max_{j in [i-r, i-l]} dp[k-1][j] + pre[i] - pre[j])`。
3. 内层 `max` 拆成 `pre[i] + max(dp[k-1][j] - pre[j])`，j 的窗口随 i 单调右移，用单调队列维护 `dp[k-1][j] - pre[j]` 的递减队列。
4. 答案取 `max(dp[k][n] for k in 1..m)`，因为「至多 m 段」且必须至少一段。

以示例 1 `nums=[4,1,-5,2], m=2, l=1, r=3` 为例：`pre=[0,4,5,0,2]`。k=1 时 i=2，窗口 j∈[max(0,2-3), 2-1]=[0,1]，`dp[0][j]-pre[j]` 为 `0-0=0`、`0-4=-4`，取 0，得 `pre[2]+0=5`，即 `[4,1]` 的和。k=2 时 i=4，窗口 j∈[1,3]，候选含 `dp[1][3]-pre[3]=5-0=5`，得 `pre[4]+5=7`。

```python
from collections import deque
pre = [0]
for x in nums: pre.append(pre[-1] + x)
NEG = -10**30
prev = [0] * (n + 1)          # dp[0][i] = 0
ans = NEG
for k in range(1, m + 1):
    cur = [NEG] * (n + 1)
    dq = deque()
    for i in range(1, n + 1):
        j = i - l             # 新进入窗口的 j
        if j >= 0:
            val = prev[j] - pre[j]
            while dq and dq[-1][1] <= val: dq.pop()
            dq.append((j, val))
        while dq and dq[0][0] < i - r: dq.popleft()
        cur[i] = cur[i - 1]
        if dq: cur[i] = max(cur[i], pre[i] + dq[0][1])
    ans = max(ans, cur[n])
    prev = cur
```

## 复杂度
时间：O(m·n)，外层 m 段、内层 n 个位置，每位置队列均摊 O(1)。
空间：O(n)，`pre`、`prev`、`cur` 各一维，队列最多 n 项。

## 易错点
- 全负输入如 `nums=[-3,-4,-1], m=2, l=1, r=2`：若把 `dp` 初值设 0 并允许「不选」，会返回 0；但题目要求至少选一段，答案应是 -1。正确做法是 `cur` 初值设 `NEG`，只在 `dq` 非空时更新。
- 窗口边界：`j` 的下界是 `i-r`、上界是 `i-l`，若写成 `i-r+1` 或漏掉 `j>=0` 判断，示例 3 中 `l=2` 时 i=2 的窗口会算错，把长度 1 的 `[7]` 误当合法段。

## 如果面试官追问
问：n 放大到 1e5 怎么办？
答：m 也大时 O(mn) 不可行，需二分答案或对 m 做拉格朗日松弛（WQS 二分），把段数约束转成每段罚分。
