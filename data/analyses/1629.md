## 一句话思路
一次遍历算相邻 `releaseTimes` 差值，用 `(时长, 字符)` 元组比较同时处理「最长」和「字母序最大」。

## 怎么做
1. 令 `best_dur = releaseTimes[0]`、`best_key = keysPressed[0]`，把第 0 次按键当作初始候选。
2. 从 `i = 1` 遍历到 `n-1`，每次算 `dur = releaseTimes[i] - releaseTimes[i-1]`。
3. 若 `dur > best_dur`，或 `dur == best_dur and keysPressed[i] > best_key`，就更新两个变量。
4. 遍历结束返回 `best_key`。

拿示例 1 走一遍：`i=1` 时 `dur = 29-9 = 20`，`20 > 9` 更新为 `('b', 20)`；`i=2` 时 `dur = 49-29 = 20`，与 `best_dur` 相等且 `'c' > 'b'`，更新为 `('c', 20)`；`i=3` 时 `dur = 1` 不更新。最终返回 `'c'`。关键中间值就是 `i=2` 那次「相等但字符更大」的更新——漏掉这个分支就会返回 `'b'`。

```python
best_dur, best_key = releaseTimes[0], keysPressed[0]
for i in range(1, len(releaseTimes)):
    dur = releaseTimes[i] - releaseTimes[i - 1]
    if dur > best_dur or (dur == best_dur and keysPressed[i] > best_key):
        best_dur, best_key = dur, keysPressed[i]
return best_key
```

## 复杂度
时间 O(n)：一次遍历，每次做一次减法和至多两次字符比较。
空间 O(1)：只开了 `best_dur`、`best_key`、`dur` 三个标量。

## 易错点
1. 只写 `dur > best_dur` 就更新 → 示例 1 里 `'b'` 和第二次 `'c'` 都是 20，会停在 `'b'` 返回 `'b'`。正确做法是把条件写成 `dur > best_dur or (dur == best_dur and keysPressed[i] > best_key)`，让相等时也比字符。
2. 从 `i = 0` 开始循环并算 `releaseTimes[0] - releaseTimes[-1]` → 在 Python 里 `releaseTimes[-1]` 是最后一个元素，`9 - 50 = -41` 这种负数会污染 `best_dur`。正确做法是第 0 项单独初始化，循环从 `i = 1` 起。

## 如果面试官追问
问：如果要求返回所有并列最长的键（按字母序）怎么办？
答：把 `best_key` 换成集合，`dur > best_dur` 时清空重填，`dur == best_dur` 时加入，最后排序返回。
