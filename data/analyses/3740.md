## 一句话思路
按值分组记录下标，同值下标升序排列后，距离只由相邻三个下标决定，取 `2*(a[k]-a[k-2])` 的最小值。

## 怎么做
1. 用字典 `pos` 把每个值出现的下标按顺序收集起来，因为从左到右扫描天然升序。
2. 对每个值的下标列表，只需检查连续三个下标 `a[i-2], a[i-1], a[i]`，因为距离公式在升序下化简为 `2*(a[i]-a[i-2])`。
3. 维护全局最小值 `ans`，初始为无穷大，最后若仍为无穷大返回 `-1`。

以示例 1 `nums = [1,2,1,1,3]` 为例，`pos[1] = [0,2,3]`。检查 `(0,2,3)` 时，`2*(3-0)=6`，这就是答案。注意中间下标 `2` 不参与距离计算，距离只取决于首尾跨度。

```python
pos = {}
for i, x in enumerate(nums):
    pos.setdefault(x, []).append(i)

ans = float('inf')
for idx in pos.values():
    for k in range(2, len(idx)):
        ans = min(ans, 2 * (idx[k] - idx[k-2]))

return -1 if ans == float('inf') else ans
```

关键点：为什么只看相邻三个？假设同值下标为 `a < b < c < d`，若选 `(a,b,d)`，距离 `2*(d-a)` 一定不小于 `2*(d-b)`，而 `(b,c,d)` 是合法的连续三元组。所以最优解必然来自某个连续三元组。

## 复杂度
时间：O(n)，每个下标最多被访问一次，字典分组和遍历都是线性。
空间：O(n)，`pos` 存储所有下标，最坏情况所有元素相同。

## 易错点
1. 输入 `nums = [1,1,1]` → 若只检查 `i-2` 和 `i` 的跨度而忘记验证中间下标存在，可能漏掉 `(0,1,2)` 这个唯一合法三元组 → 正确做法是 `range(2, len(idx))` 保证三个下标都存在。
2. 输入 `nums = [1,2,3]` → 若 `ans` 初始化为 `0` 或某个小值，会错误返回 `0` → 正确做法是用 `float('inf')` 初始化，最后判断是否仍为无穷大再返回 `-1`。

## 如果面试官追问
如果要求输出具体三元组下标而非距离？答：在更新 `ans` 时同步记录 `(idx[k-2], idx[k-1], idx[k])`，最后返回该元组即可。
