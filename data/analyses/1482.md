## 一句话思路
答案关于天数单调：能等 d 天做成，则 d+1 天也能做成，故对天数二分，用贪心数出 d 天内能凑几束。

## 怎么做
1. 先判 `m * k > len(bloomDay)` 直接返回 -1，总花数不够。
2. 二分区间取 `lo = min(bloomDay)`、`hi = max(bloomDay)`，答案必落在此区间内。
3. 判定函数：扫一遍数组，维护连续盛开计数 `run`，`bloomDay[i] <= d` 时 `run += 1`，否则清零；`run == k` 时 `bouquet += 1`、`run = 0`。
4. `bouquet >= m` 则收缩右界，否则抬左界。

以示例 3 `bloomDay = [7,7,7,7,12,7,7], m = 2, k = 3` 为例，取 `d = 7`：前四朵盛开 `run` 走到 3 时 `bouquet = 1`、`run` 归零，第 5 朵 12 > 7 使 `run = 0`，末尾两朵只把 `run` 推到 2，最终 `bouquet = 1 < 2`，说明 7 天不够，左界右移；取 `d = 12` 时 `run` 依次到 3 得 1 束、再到 3 得第 2 束，判定通过，答案收敛到 12。

```python
def can(d):
    bouquet = run = 0
    for x in bloomDay:
        if x <= d:
            run += 1
            if run == k:
                bouquet += 1
                run = 0
        else:
            run = 0
    return bouquet >= m

lo, hi = min(bloomDay), max(bloomDay)
while lo < hi:
    mid = (lo + hi) // 2
    if can(mid):
        hi = mid
    else:
        lo = mid + 1
return lo
```

## 复杂度
时间 O(n log(max(bloomDay) - min(bloomDay)))，n 来自每次判定扫一遍数组，log 来自二分天数。
空间 O(1)，只用了 `bouquet`、`run`、`lo`、`hi`、`mid` 几个整数。

## 易错点
- 忘记先判 `m * k > n`：示例 2 中 `m*k = 6 > 5`，若直接二分，`can` 永远返回 `False`，`lo` 会一路抬到 `max(bloomDay) = 10` 并返回 10，而正确答案是 -1。
- 判定里 `run` 达到 k 后不归零：示例 3 取 `d = 12` 时若不清零，前 6 朵连续盛开会让 `run` 涨到 6，只记 1 束，误判 12 天不够，答案被推到更大的值。

## 如果面试官追问
问：若要求输出具体是哪几束花（下标区间）？
答：在 `can` 里记录每次 `run == k` 时的结束下标 `i`，二分收敛后再跑一遍收集区间即可，时间不变。
