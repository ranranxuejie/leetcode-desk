## 一句话思路
特殊数恰是 `p²`（p 为质数），故答案 = 区间长度 − 区间内质数平方的个数。

## 怎么做
1. 设 `x` 的真因数个数为 `d(x)-1`，要求等于 2，即 `d(x)=3`；只有 `x=p²` 满足。
2. 于是只需数 `[l, r]` 中有几个 `p²`，即 `p ∈ [ceil(sqrt(l)), floor(sqrt(r))]` 中的质数个数。
3. 用埃氏筛预处理到 `isqrt(r)`，再前缀计数。

以 `l=4, r=16` 为例：`isqrt(16)=4`，筛出质数 `{2,3}`；`ceil(sqrt(4))=2`，`floor(sqrt(16))=4`，区间内质数为 2、3，共 2 个特殊数（4、9），答案 `16-4+1-2=11`。

```python
from math import isqrt

def nonSpecialCount(l, r):
    n = isqrt(r)
    is_p = [True] * (n + 1)
    if n >= 0: is_p[0] = False
    if n >= 1: is_p[1] = False
    for i in range(2, isqrt(n) + 1):
        if is_p[i]:
            for j in range(i * i, n + 1, i):
                is_p[j] = False
    lo = isqrt(l - 1) + 1          # 最小的 p 使 p*p >= l
    hi = n                          # 最大的 p 使 p*p <= r
    special = sum(1 for p in range(lo, hi + 1) if is_p[p])
    return (r - l + 1) - special
```

## 复杂度
时间：筛法 O(√r · log log √r)，前缀统计 O(√r)，`n = isqrt(r)` 贡献。
空间：`is_p` 数组 O(√r)，无其他额外结构。

## 易错点
- `l=1, r=1` → 若直接 `isqrt(l)` 当下界，会把 p=1 算进去（1 不是质数），错成特殊数 1；正确用 `isqrt(l-1)+1`，得 lo=1、hi=1，但 `is_p[1]=False`，special=0，答案 1。
- `l=4, r=4` → 若用 `isqrt(l)` 作 lo 得 2，恰好对；但 `l=5, r=5` 时 `isqrt(5)=2`，会把 4 误算进区间，错成 0 个特殊数；正确用 `isqrt(l-1)+1=3`，special=0，答案 1。

## 如果面试官追问
问：若 r 升到 10^12 怎么办？答：筛到 10^6 仍可行，复杂度 O(√r) 不变，只是常数变大。
