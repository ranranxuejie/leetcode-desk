## 一句话思路
排序后最小绝对差必出现在相邻元素之间，扫一遍相邻差即可。

## 怎么做
1. 先对 `arr` 排序，把「任意两元素之差」缩小到只需看相邻对。
2. 用 `best` 记录当前最小差，`res` 收集达到 `best` 的相邻对。
3. 遍历相邻对 `(arr[i-1], arr[i])`：差值小于 `best` 就清空 `res` 并更新 `best`，等于就追加。

以 `arr = [4,2,1,3]` 为例，排序后 `[1,2,3,4]`。第一对差 `1`，`best` 从无穷大更新为 `1`，`res = [[1,2]]`；第二对差也是 `1`，等于 `best`，追加得 `[[1,2],[2,3]]`；第三对同理得 `[[1,2],[2,3],[3,4]]`。

```python
arr.sort()
best = float('inf')
res = []
for i in range(1, len(arr)):
    d = arr[i] - arr[i - 1]
    if d < best:
        best = d
        res = [[arr[i - 1], arr[i]]]
    elif d == best:
        res.append([arr[i - 1], arr[i]])
return res
```

关键点：排序后相邻差天然有序递增地扫描，`res` 里存的每一对都满足 `a < b`，且因为数组元素互不相同，差不会为 `0`。

## 复杂度
时间：排序 `O(n log n)` 主导，扫描 `O(n)`。
空间：排序额外 `O(log n)` 栈空间，`res` 最坏 `O(n)`。

## 易错点
- 输入 `arr = [1,3,6,10,15]` → 若只比较首尾或跳着比，会漏掉 `[1,3]` 这个唯一最小差对 → 必须只比相邻，排序后相邻差 `2,3,4,5` 中最小是 `2`。
- 输入 `arr = [3,8,-10,23,19,-4,-14,27]` → 若用 `abs` 前忘记排序，负数对 `[-14,-10]` 的差会被算成 `-4` 或漏掉 → 排序后 `[-14,-10,-4,3,8,19,23,27]`，相邻差 `4,6,7,5,11,4,4`，最小 `4` 对应三对，必须全部收集而非只留第一对。

## 如果面试官追问
问：若数组允许重复元素，最小差为 `0` 时怎么办？
答：排序后相邻相等即差 `0`，逻辑不变，`res` 会收集所有 `[x,x]` 对，无需特判。
