## 一句话思路
用取模逐位剥出数字并累加成反转值 `rev`，再算 `abs(n - rev)`；循环次数就是位数。

## 怎么做
1. 把 `n` 复制到临时变量 `x`，`rev = 0`，因为后面要保留原 `n` 做减法。
2. 循环 `while x > 0`：`rev = rev * 10 + x % 10`，再 `x //= 10`，每轮把 `x` 的末位搬到 `rev` 末尾。
3. 循环结束时 `rev` 就是 `reverse(n)`，返回 `abs(n - rev)`。

以 `n = 25` 为例：第一轮 `x % 10 = 5`，`rev = 0 * 10 + 5 = 5`，`x` 变 `2`；第二轮 `x % 10 = 2`，`rev = 5 * 10 + 2 = 52`，`x` 变 `0`，循环结束。`abs(25 - 52) = 27`。

```python
x, rev = n, 0
while x > 0:
    rev = rev * 10 + x % 10
    x //= 10
return abs(n - rev)
```

关键点：`x //= 10` 必须是整除，用 `/` 会得到浮点数，`while x > 0` 永远退不出去。`rev * 10 + x % 10` 的顺序也不能反，先乘 10 才能把旧位左移。

## 复杂度
时间 O(log n)：循环次数等于 `n` 的十进制位数，`n ≤ 10^9` 最多 10 轮。
空间 O(1)：只开了 `x`、`rev` 两个整数，没有字符串或数组。

## 易错点
- `n = 10` → 若用 `str(n)[::-1]` 再 `int()`，得到 `"01"` 转成 `1` 没问题，但若手写反转时忘了处理末尾的 0，比如把 `rev` 初始化成 `n % 10` 再循环，`10` 会算成 `rev = 0` 后直接停，漏掉前导位；正确做法是让 `rev = rev * 10 + x % 10` 从 0 开始累加，`10` 第一轮得 `rev = 0`、`x = 1`，第二轮得 `rev = 1`，结果 `abs(10 - 1) = 9`。
- `n = 7` 这类回文数 → 若循环条件写成 `while x >= 10`，`7` 一轮都不进，`rev` 停在 `0`，返回 `abs(7 - 0) = 7` 而不是 `0`；正确条件是 `while x > 0`，让个位数也走一轮把 `7` 搬进 `rev`。

## 如果面试官追问
问：`n` 扩大到 10^18 甚至超出 64 位怎么办？答：Python 整数无上限，`rev` 照样累加，只是位数变多、循环变长，逻辑一行不用改。
