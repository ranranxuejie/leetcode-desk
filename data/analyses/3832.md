## 一句话思路
按 `(user_id, action)` 分组后用「日期 − 行号」做差，同差值的连续日期归为一段，再取每用户最长且 ≥5 的段。

## 怎么做
1. 先过滤掉同一 `(user_id, action_date)` 出现多行的日期——题面要求「每天只执行一个操作」，这类日期必须整段作废。
2. 对剩余行按 `user_id, action, action_date` 排序，用 `row_number()` 得到组内序号 `rn`。
3. 关键一步：算 `grp = action_date - rn`（日期减整数天）。连续日期减连续序号得同一常量，所以 `grp` 相同即同一段。以用户 3 为例，`view` 的 7 行 `rn` 为 1..7，`grp` 全等于 `2023-12-31`，一段长度 7。
4. 按 `(user_id, action, grp)` 聚合出 `streak_length = count(*)`、`start_date = min(action_date)`、`end_date = max(action_date)`，筛 `streak_length >= 5`，再按 `user_id` 取最长一段（并列取最早开始），最后按 `streak_length` 降序、`user_id` 升序输出。

```python
df = df.groupby(["user_id", "action_date"]).filter(lambda g: len(g) == 1)
df = df.sort_values(["user_id", "action", "action_date"])
df["rn"] = df.groupby(["user_id", "action"]).cumcount()
df["grp"] = df["action_date"] - pd.to_timedelta(df["rn"], unit="D")
seg = df.groupby(["user_id", "action", "grp"]).agg(
    streak_length=("action_date", "size"),
    start_date=("action_date", "min"),
    end_date=("action_date", "max")).reset_index()
seg = seg[seg["streak_length"] >= 5]
seg = seg.sort_values(["user_id", "streak_length", "start_date"],
                      ascending=[True, False, True]).drop_duplicates("user_id")
seg = seg.sort_values(["streak_length", "user_id"], ascending=[False, True])
```

## 复杂度
时间 O(n log n)：n 为 activity 行数，排序与分组各一次。
空间 O(n)：额外存 `rn`、`grp` 两列和段聚合结果。

## 易错点
- 用户 1 的 `login` 段是 5 天、`logout` 只有 1 天：若先按 `user_id` 取最长再判 ≥5，会把只有 4 天 `click` 的用户 2 误留或误删；必须先按 `(user_id, action, grp)` 分段、筛 ≥5、再取最长。
- 若某天同一用户有两条记录（如 2024-01-03 两条 `login`），`action_date - rn` 仍可能凑出连续假象；正确做法是先按 `(user_id, action_date)` 计数，把 count>1 的日期整行剔除，再排序编号。

## 如果面试官追问
问：若要求输出该用户所有 ≥5 的段而非最长一段？答：去掉 `drop_duplicates("user_id")`，只保留 `streak_length >= 5` 的筛选和最终排序即可。
