## 一句话思路
用线段树维护区间乘积模 k，每个节点存长度为 k 的计数数组，合并时做循环卷积，从而支持单点更新与区间查询。

## 怎么做
1. 把每个 `nums[i] % k` 作为叶子，节点 `cnt[r]` 表示该区间内所有后缀乘积模 k 等于 r 的个数（后缀从区间右端往左延伸）。
2. 合并左右儿子 `L`、`R`：`cnt[r] = L.cnt[r] + R.cnt[(r * L.prod) % k]`，其中 `L.prod` 是左区间总乘积模 k。
3. 查询 `[start, n-1]` 得到 `cnt`，答案就是 `cnt[x]`。
4. 更新 `nums[index] = value` 后沿路径重算。

以示例 1 查询 0 为例：`nums` 变为 `[1,2,2,4,5]`，`start=0`，整段乘积 `80 % 3 = 2`，后缀 `[2,4,5]` 乘积 `40 % 3 = 1`，后缀 `[4,5]` 乘积 `20 % 3 = 2`，后缀 `[5]` 乘积 `5 % 3 = 2`，加上空后缀（乘积 1）共 2 个余数为 2，输出 2。

```python
def merge(L, R, k):
    res = [0] * k
    for r in range(k):
        res[r] = L.cnt[r] + R.cnt[(r * L.prod) % k]
    return res, (L.prod * R.prod) % k

# 叶子
cnt = [0] * k
cnt[nums[i] % k] = 1
prod = nums[i] % k
```

## 复杂度
时间：每次更新/查询 O(k log n)，共 O((n + q) k log n)，n 为数组长度，q 为查询数。
空间：线段树 4n 个节点，每节点长度 k 数组，O(nk)。

## 易错点
- `start = 0` 时查询整段，若把空前缀误当成必须移除至少一个元素，会漏掉空后缀方案，导致示例 1 查询 0 输出 1 而非 2；正确做法是空后缀也计入，即 `cnt[1]` 初始为 1。
- `k = 1` 时所有余数都是 0，若合并时用 `(r * L.prod) % k` 且 `L.prod` 为 0，会全部映射到 0，但 `cnt` 长度只有 1，需保证 `cnt[0]` 统计所有后缀数，即区间长度；正确做法是特判 `k == 1` 直接返回区间长度。

## 如果面试官追问
若 `k` 很大（如 10^5）怎么办？答：不能开长度 k 的数组，需改用质因数分解 + 中国剩余定理或只维护实际出现的余数集合。
