## 一句话思路
用 BFS 按层扩展，每层代表转换次数加一，首次遇到 `endWord` 的层数就是最短序列长度。

## 怎么做
1. 先把 `wordList` 放进 `set`，O(1) 判断某词是否在字典里；若 `endWord` 不在集合中直接返回 0。
2. 队列存 `(word, steps)`，`beginWord` 入队时 `steps=1`；同时用 `visited` 记录已扩展的词，避免重复。
3. 出队一个词，枚举每个位置 `i` 替换成 `'a'`~`'z'` 生成 `nxt`；若 `nxt == endWord` 立即返回 `steps + 1`，若 `nxt` 在字典且未访问则入队 `steps + 1`。
4. 队列空仍未命中返回 0。

以示例 1 为例：`beginWord="hit"` 出队 `steps=1`，替换第 2 位得 `"hot"` 在字典，入队 `("hot", 2)`；`"hot"` 出队后生成 `"dot"`、`"lot"` 入队 `steps=3`；`"dot"` 出队生成 `"dog"` 入队 `steps=4`；`"dog"` 出队替换末位得 `"cog" == endWord`，返回 `4+1=5`。

```python
from collections import deque
words = set(wordList)
if endWord not in words:
    return 0
q = deque([(beginWord, 1)])
visited = {beginWord}
while q:
    w, s = q.popleft()
    for i in range(len(w)):
        for c in 'abcdefghijklmnopqrstuvwxyz':
            nxt = w[:i] + c + w[i+1:]
            if nxt == endWord:
                return s + 1
            if nxt in words and nxt not in visited:
                visited.add(nxt)
                q.append((nxt, s + 1))
return 0
```

## 复杂度
时间 O(N × L × 26)，N 为字典词数、L 为单词长度，每个词最多出队一次并枚举 26 个字母。
空间 O(N × L)，`visited` 与队列最多存 N 个词，每个词长 L。

## 易错点
- `endWord` 不在 `wordList`（如示例 2 的 `"cog"`）→ 若先 BFS 再判断会白跑一遍甚至误返回 → 入口处先 `if endWord not in words: return 0`。
- `beginWord` 本身可能不在 `wordList`（如 `"hit"` 不在示例 1 的列表里）→ 若只把 `wordList` 当起点集合会漏掉第一层 → 起点单独入队，`visited` 初始化为 `{beginWord}`，不要要求它在字典中。

## 如果面试官追问
问：要输出具体转换序列而非长度怎么办？
答：队列里存 `(word, path)` 或记录 `parent` 字典，命中 `endWord` 时沿父指针回溯即可，复杂度不变。
