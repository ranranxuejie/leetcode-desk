## 一句话思路
后序 DFS 返回子树最大值，节点值等于该最大值就计数加一，自底向上一次遍历即可。

## 怎么做
1. 定义 `dfs(node)` 返回以 `node` 为根子树的最大值；空节点返回 `-1`（题面 `Node.val >= 1`，安全）。
2. 递归拿到 `left_max = dfs(node.left)`、`right_max = dfs(node.right)`，本子树最大值 `m = max(node.val, left_max, right_max)`。
3. 若 `node.val == m`，说明它是支配节点，`self.ans += 1`。
4. 返回 `m` 给父节点用。

以示例 1 的 `[5,3,8,2,4,7,1]` 为例：走到值为 8 的节点时，`left_max = 7`、`right_max = 1`，`m = max(8,7,1) = 8`，`8 == 8` 成立，计数加一；而根节点 5 拿到 `left_max = 4`、`right_max = 8`，`m = 8`，`5 != 8` 不计数。最终 4 个叶子 + 节点 8 = 5。

```python
def dfs(node):
    if not node:
        return -1
    l = dfs(node.left)
    r = dfs(node.right)
    m = max(node.val, l, r)
    if node.val == m:
        self.ans += 1
    return m

self.ans = 0
dfs(root)
return self.ans
```

关键点：`m` 必须把 `node.val` 一起参与 `max`，否则单节点子树（叶子）会拿 `-1` 比较，逻辑虽然碰巧对，但语义错了。

## 复杂度
时间 O(n)：每个节点被访问一次，`max` 是常数操作。
空间 O(log n)：完全二叉树深度约 `log2(n)`，递归栈只占这么多；`self.ans` 是 O(1)。

## 易错点
- 输入 `[1,2,3,1,2]`（示例 2）→ 若只比较 `node.val` 与左右孩子值、不递归取子树最大值，值为 2 的左孩子会因 `2 > 1` 被误判为支配节点，但它子树 `[2,1,2]` 最大值是 2，其实它确实是支配节点——真正的坑在根节点 1：只看孩子会漏掉「1 小于子树最大值 3」而错判，正确做法是必须用递归返回的 `m` 而非孩子值。
- 输入 `[5,3,8,2,4,7,1]` → 若把空节点返回值设成 `0` 而非 `-1`，当所有值都为正时结果碰巧不变，但一旦题面放宽到允许 `0` 或负数就会错；本题 `Node.val >= 1`，用 `-1` 是明确安全的哨兵，别用 `0` 埋雷。

## 如果面试官追问
问：节点数涨到 10^7、递归会爆栈怎么办？
答：改显式栈做后序，用 `(node, visited)` 标记二次访问，或按完全二叉树数组下标从 `n-1` 倒序递推 `max`。
