## 一句话思路
先从 n 跑 Dijkstra 得每个点的 `dist`，再按 `dist` 升序做 DP 累加路径数，因为受限边只从大 `dist` 指向小 `dist`，天然无环。

## 怎么做
1. 建邻接表，以 n 为源跑堆优化 Dijkstra，得到 `dist[x] = distanceToLastNode(x)`。
2. 把节点按 `dist` 升序排序，DP 从 `dist` 最小的 n 开始推。
3. 初始化 `dp[n] = 1`，遍历排序后的节点 u，对每条边 (u,v,w)，若 `dist[u] > dist[v]` 则 `dp[u] += dp[v]`。
4. 返回 `dp[1] % (10**9+7)`。

以示例 1 为例，Dijkstra 得 `dist = {5:0, 3:1, 2:2, 1:4, 4:10}`（1 到 5 经 3 是 3+1=4）。按升序处理：`dp[5]=1`；处理 3 时 `dist[3]=1 > dist[5]=0`，`dp[3]=1`；处理 2 时 `dist[2]=2 > dist[3]=1` 且 `> dist[5]=0`，`dp[2]=dp[3]+dp[5]=2`；处理 1 时 `dist[1]=4 > dist[2]=2` 和 `> dist[3]=1`，`dp[1]=dp[2]+dp[3]=3`。结果 3，与官方一致。

```python
import heapq
MOD = 10**9 + 7
# dist 已由 Dijkstra 求出，adj 为邻接表
order = sorted(range(1, n + 1), key=lambda x: dist[x])
dp = [0] * (n + 1)
dp[n] = 1
for u in order:
    for v, w in adj[u]:
        if dist[u] > dist[v]:
            dp[u] = (dp[u] + dp[v]) % MOD
return dp[1]
```

关键点：排序保证处理 u 时所有满足 `dist[v] < dist[u]` 的 v 的 `dp[v]` 已算完，无需显式拓扑排序。

## 复杂度
时间：Dijkstra 的 `O(m log n)` 加排序 `O(n log n)`，m 为边数。
空间：`dist`、`dp`、邻接表共 `O(n + m)`，堆额外 `O(m)`。

## 易错点
- 把 DP 写成从 1 出发 DFS 记忆化：示例 1 中 1→2→3→5 与 1→3→5 会在 3 处重复展开，若不加 `dist` 严格递减判断会死循环或重复计数；正确做法是只沿 `dist[u] > dist[v]` 的边转移，且按 `dist` 升序迭代。
- 用 `dist[u] >= dist[v]` 而非严格大于：示例 1 中若 2 和 3 之间 dist 相等（构造等权边时会出现），会多算一条非法路径；题目要求严格递减，必须用 `>`。

## 如果面试官追问
问：若要求输出所有受限路径本身而非计数？
答：把 `dp` 换成记录前驱列表，从 n 反向 DFS 回溯，路径数可能指数级，需按输出规模算复杂度。
