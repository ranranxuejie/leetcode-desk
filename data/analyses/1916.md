## 一句话思路
按树自底向上 DP，每个节点把各子树的可选顺序用组合数「插空」合并，答案即根节点方案数。

## 怎么做
1. 由 `prevRoom` 建邻接表 `children`，`prevRoom[i]` 是 `i` 的父节点，从 0 开始 DFS。
2. 对节点 `u`，先递归求每个孩子 `v` 的 `size[v]`（子树节点数）和 `ways[v]`（子树内部顺序数）。
3. 合并时维护已合并的节点数 `total` 和方案数 `res`：每加入一个孩子子树，把它的 `size[v]` 个节点插入到 `total` 个已排好的位置中，选位方式为 `C(total + size[v], size[v])`，再乘 `ways[v]`。
4. 全部孩子合并后 `ways[u] = res`，`size[u] = total + 1`（含自己）。

以示例 2 `prevRoom = [-1,0,0,1,2]` 为例：节点 1 有孩子 3，`size[3]=1, ways[3]=1`，合并后 `size[1]=2, ways[1]=C(1,1)*1=1`；节点 2 同理 `size[2]=2, ways[2]=1`。根 0 先并入孩子 1：`total=2, res=C(2,2)*1=1`；再并入孩子 2：`res = 1 * C(2+2,2) * 1 = 6`，与输出一致。

```python
MOD = 10**9 + 7
# 预处理阶乘与逆元，C(n,k) = fact[n]*inv_fact[k]*inv_fact[n-k] % MOD
def dfs(u):
    total, res = 0, 1
    for v in children[u]:
        dfs(v)
        res = res * comb(total + size[v], size[v]) % MOD * ways[v] % MOD
        total += size[v]
    size[u] = total + 1
    ways[u] = res
```

## 复杂度
时间 O(n)：每个节点只被合并一次，组合数 O(1) 查表。
空间 O(n)：`children`、`size`、`ways` 及阶乘逆元数组各占 O(n)。

## 易错点
- 用 `prevRoom = [-1,0,1]` 这类链：若把「插入位置」写成 `C(total, size[v])` 而非 `C(total+size[v], size[v])`，链上 `total=0` 时结果仍对，但示例 2 会算成 2 而非 6；正确是插入后总长度 `total+size[v]` 里选 `size[v]` 个位置。
- 递归深度达 10^5 的链（如 `prevRoom[i]=i-1`）：Python 默认递归上限约 1000 会 `RecursionError`；需 `sys.setrecursionlimit(2*10**5)` 或改迭代后序。

## 如果面试官追问
问：n 增到 10^6 怎么办？答：递归改显式栈后序遍历，组合数仍 O(1) 查表，时间 O(n) 不变，只多一份栈空间。
