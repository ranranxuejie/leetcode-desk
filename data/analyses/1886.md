## 一句话思路
把 mat 顺时针转 4 次（含 0 次），每次与 target 逐格比对，任一相等即 true。

## 怎么做
1. 先直接比对 mat 与 target，相等返回 True。
2. 循环 3 次：对 mat 做一次原地顺时针旋转，再与 target 比对。
3. 旋转公式：新矩阵 `nxt[i][j] = mat[n-1-j][i]`，即原矩阵第 `n-1-j` 行第 `i` 列搬到新矩阵第 `i` 行第 `j` 列。
4. 4 次旋转回到原状，所以只需试 4 种状态。

以示例 1 的 `mat = [[0,1],[1,0]]` 为例，n=2。旋转一次时，`nxt[0][0] = mat[1][0] = 1`，`nxt[0][1] = mat[0][0] = 0`，`nxt[1][0] = mat[1][1] = 0`，`nxt[1][1] = mat[0][1] = 1`，得到 `[[1,0],[0,1]]`，正好等于 target，返回 True。

```python
def rotate(m):
    n = len(m)
    return [[m[n - 1 - j][i] for j in range(n)] for i in range(n)]

if mat == target:
    return True
for _ in range(3):
    mat = rotate(mat)
    if mat == target:
        return True
return False
```

注意 `nxt[i][j] = mat[n-1-j][i]` 中两个下标不能写反：`i` 是新行号，对应原矩阵的列号；`n-1-j` 是新列号 `j` 对应的原行号。写反就变成逆时针旋转，示例 1 会得到 `[[0,1],[1,0]]`，与 target 不等而误判 False。

## 复杂度
时间：O(n²)，最多 4 次旋转，每次遍历 n² 个格子。
空间：O(n²)，每次旋转新建一个 n×n 矩阵。

## 易错点
- 输入 `mat = [[0,1],[1,0]]`、`target = [[1,0],[0,1]]`：若把旋转公式写成 `nxt[i][j] = mat[j][n-1-i]`（逆时针），第一次得到 `[[0,1],[1,0]]`，与 target 不等，循环 3 次后返回 False。正确做法是用 `mat[n-1-j][i]`，第一次就得到 `[[1,0],[0,1]]`。
- 输入 `mat == target`（如两者都是 `[[1,1],[1,1]]`）：若循环写成 `for _ in range(4)` 且先旋转后比对，虽然最终仍能返回 True，但多绕一圈；若漏掉开头的直接比对又只循环 3 次，恰好覆盖 4 种状态没问题，但若误写成只循环 2 次，就会漏掉旋转 270° 的情况。正确做法是先比对原矩阵，再循环 3 次，共覆盖 4 种状态。

## 如果面试官追问
问：n 很大且只允许 O(1) 额外空间怎么办？
答：不建新矩阵，用 `mat[n-1-j][i]` 直接和 `target[i][j]` 逐格比对，四次旋转各扫一遍即可。
