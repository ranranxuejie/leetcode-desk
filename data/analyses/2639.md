## 一句话思路
逐列扫描，用 `len(str(grid[r][c]))` 取每列最大值；负号被 `str` 自动计入长度，无需特判。

## 怎么做
1. 先取 `n = len(grid[0])`，答案数组 `ans = [0] * n`。
2. 外层按列 `c` 遍历，内层按行 `r` 遍历，把 `len(str(grid[r][c]))` 与 `ans[c]` 取较大值。
3. 遍历结束直接返回 `ans`。

以示例 2 的 `grid = [[-15,1,3],[15,7,12],[5,6,-2]]` 为例，处理第 0 列时依次得到 `len("-15")=3`、`len("15")=2`、`len("5")=1`，`ans[0]` 从 0 被抬到 3；第 1 列三个值都是 1 位数，`ans[1]` 停在 1；第 2 列 `len("12")=2` 让 `ans[2]=2`，`-2` 的 `len("-2")=2` 不再更新。最终 `[3,1,2]`。

```python
n = len(grid[0])
ans = [0] * n
for c in range(n):
    for r in range(len(grid)):
        ans[c] = max(ans[c], len(str(grid[r][c])))
return ans
```

关键点：`str(-15)` 是 `"-15"`，长度 3，负号天然占一位，所以题面那句「否则为 len + 1」不用手写分支。

## 复杂度
时间 O(m·n·log V)，V 是元素绝对值上界 10^9，`str` 转换最多 10 位。
空间 O(n) 存 `ans`，`str` 临时串 O(log V) 可忽略。

## 易错点
- 输入含 `-10**9`（如 `[[-1000000000]]`）→ 若用 `math.log10(abs(x))+1` 取位数会漏掉负号，得到 10 而非 11 → 直接用 `len(str(x))`，负号自动计入。
- 输入 `[[0]]` → 若用 `while x: x //= 10` 数位数，0 一次都不进循环得 0 → 正确是 `len("0")=1`；用 `str` 天然规避。

## 如果面试官追问
问：若 m、n 放大到 10^4 且要求不转字符串？
答：按绝对值循环 `//10` 数位，再对负数加 1，注意 0 单独返回 1。
