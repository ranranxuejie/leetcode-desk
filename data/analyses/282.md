## 一句话思路
回溯枚举每个数字间的三种运算符，额外传 `prev` 处理乘法优先级，避免转成中缀再求值。

## 怎么做
1. 从下标 `i` 开始枚举操作数 `num[i:j]`，`j` 从 `i+1` 到 `n`，遇到 `num[i]=='0'` 且 `j>i+1` 就 break（禁前导零）。
2. 递归参数带 `(i, expr, val, prev)`：`val` 是当前表达式总值，`prev` 是最后一段乘法的值。
3. 选 `+` 时 `val+cur, prev=cur`；选 `-` 时 `val-cur, prev=-cur`；选 `*` 时 `val-prev+prev*cur, prev=prev*cur`。
4. `i==n` 且 `val==target` 时把 `expr` 收进结果。

以 `num="232", target=8` 为例：先取 `"2"`，再取 `"3"` 走 `*`，此时 `val=2, prev=2`，`prev*cur=6`，`val-prev+prev*cur=6`；最后取 `"2"` 走 `+`，`val=8` 命中，得到 `"2*3+2"`。

```python
def dfs(i, expr, val, prev):
    if i == n:
        if val == target:
            res.append(expr)
        return
    for j in range(i + 1, n + 1):
        if num[i] == '0' and j > i + 1:
            break
        cur = int(num[i:j])
        if i == 0:
            dfs(j, str(cur), cur, cur)
        else:
            dfs(j, expr + '+' + str(cur), val + cur, cur)
            dfs(j, expr + '-' + str(cur), val - cur, -cur)
            dfs(j, expr + '*' + str(cur), val - prev + prev * cur, prev * cur)
```

## 复杂度
时间：O(4^n)，n 个数字间 3 种符号加「不断开」共 4 种选择。
空间：O(n) 递归栈，结果列表另计。

## 易错点
- `num="105", target=5`：若允许 `"1*05"` 这类前导零操作数，会多出错误表达式；正确做法是 `num[i]=='0'` 时只允许单取一位，`j>i+1` 立即 break。
- `num="232", target=8`：若乘法直接写 `val*cur`，`"2+3*2"` 会算成 `(2+3)*2=10`；正确做法是用 `val-prev+prev*cur` 回退上一段再加回乘积。

## 如果面试官追问
问：`num` 长度放宽到 15 还能过吗？
答：4^15 约 10 亿，需剪枝或改 DP 按值聚合，回溯不再可行。
