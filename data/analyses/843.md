## 一句话思路
每轮在候选集里挑一个「最坏分组最小」的单词去猜，用返回的匹配数把候选集缩成同分组，最多 10 轮必收敛。

## 怎么做
1. 预处理 `words` 两两匹配数，存成 `n×n` 的 `match[i][j]`，避免每轮重复算。
2. 每轮对候选集 `cand` 中每个 `w`，统计它把 `cand` 按匹配数 0..6 分成 7 组后**最大组的大小**，取该值最小的 `w` 去猜。
3. 拿到 `g = Master.guess(w)`，若 `g == 6` 结束；否则 `cand = [x for x in cand if match[idx[w]][idx[x]] == g]`。
4. 回到第 2 步，直到猜中或候选只剩 1 个（直接猜它）。

以示例 1 为例，`cand` 初始 4 个词。对 `"acckzz"` 分组：与 `"ccbazz"` 匹配 3、`"eiowzz"` 匹配 2、`"abcczz"` 匹配 4，最大组大小 1；对 `"ccbazz"` 分组时 `"acckzz"` 和 `"abcczz"` 都落在 3 这一组，最大组大小 2。所以第一猜选 `"acckzz"`，返回 6 直接命中。

```python
n = len(words)
match = [[sum(a == b for a, b in zip(words[i], words[j]))
          for j in range(n)] for i in range(n)]
cand = list(range(n))
while cand:
    best = min(cand, key=lambda i: max(
        sum(match[i][j] == g for j in cand) for g in range(7)))
    g = Master.guess(words[best])
    if g == 6:
        return
    cand = [j for j in cand if match[best][j] == g]
```

## 复杂度
时间：预处理 O(n²·6)，每轮选词 O(|cand|²·7)，n≤100 可忽略。
空间：`match` 是 n×n 的整数表，O(n²)。

## 易错点
- 候选集忘了包含「当前猜的词本身」：`"acckzz"` 猜完返回 6 时若先过滤再判断，会把正确答案滤掉导致死循环。正确做法是先判 `g == 6` 直接返回，再过滤。
- 选词时按「平均组大小」或「组数最多」挑：示例 1 里 `"ccbazz"` 组数也是 3，但最大组为 2，选它会多耗一轮。必须按**最大组最小**挑，这才是极小化极大的定义。

## 如果面试官追问
问：词长从 6 改成 10、`allowedGuesses` 只给 8 次还够吗？
答：分组数变成 11，单轮信息量更大，但最坏轮数取决于候选集收缩速度，需实测；一般仍够，因为 100 个词 8 轮足够二分式收缩。
