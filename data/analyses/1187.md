## 一句话思路
对 arr1 每个位置维护「保留原值 / 替换后」两种状态下的最小操作数与末尾值，用 arr2 排序去重后二分找最小可行替换值。

## 怎么做
1. 把 arr2 排序去重，得到 `b`；`b` 中大于某值的最小元素用 `bisect_right` 定位。
2. 定义两个变量：`keep` = 当前位置保留 arr1[i] 时的最小操作数，`swap` = 当前位置被替换时的最小操作数；同时记录各自末尾值。
3. 逐位转移：新 `keep` 要求 `arr1[i] > 旧末尾`，取两种旧状态中可行且操作数最小的；新 `swap` 在 `b` 中二分找 `> 旧末尾` 的最小值，操作数 +1。
4. 若某位置两种状态都不可行，返回 -1；否则取末位两状态最小值。

以示例 2 `arr1=[1,5,3,6,7], arr2=[4,3,1]` 为例，`b=[1,3,4]`。i=1 时旧末尾是 1：`keep` 要求 5>1 成立，操作数 0；`swap` 在 b 中找 >1 的最小值是 3，操作数 1。到 i=2（arr1[2]=3）时，`keep` 要求 3>5 失败，只能从 `swap` 末尾 3 出发再替换成 4，操作数变 2——这正是答案。

```python
from bisect import bisect_right
b = sorted(set(arr2))
INF = 10**9
keep, swap = 0, 1 if b else INF   # 末尾值另存
kv = arr1[0]
sv = b[0] if b else INF
for x in arr1[1:]:
    nk = INF if x <= min(kv, sv) else min(
        keep if x > kv else INF, swap if x > sv else INF)
    j = bisect_right(b, min(kv, sv))
    ns = INF if j == len(b) else min(
        keep if b[j] > kv else INF, swap if b[j] > sv else INF) + 1
    keep, swap, kv, sv = nk, ns, x, (b[j] if j < len(b) else INF)
```

## 复杂度
时间：O(n log m)，n = len(arr1)，m = len(arr2)，每位一次二分。
空间：O(m)，排序去重后的 b 数组，状态只有常数个。

## 易错点
- `arr2=[1,6,3,3]` 这类含重复值的输入 → 不去重时二分可能反复取到同一个 3，导致误判可行 → 先 `sorted(set(arr2))`。
- `arr1=[1,5,3,6,7]` 中 i=2 的 3 小于前一位 5 → 只维护「最小操作数」而丢掉末尾值，会误以为保留 3 可行 → 必须同时记录 keep/swap 各自的末尾值再比较。

## 如果面试官追问
要求输出具体替换方案怎么办？答：转移时额外存前驱指针（用了哪个状态、替换成 b 中哪个值），最后从末位回溯即可。
