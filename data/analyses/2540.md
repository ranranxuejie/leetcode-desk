## 一句话思路
两数组已非降序，用双指针同步推进，第一次相等即为最小公共值。

## 怎么做
1. 指针 `i` 指向 `nums1[0]`，`j` 指向 `nums2[0]`，循环条件 `i < len(nums1) and j < len(nums2)`。
2. 若 `nums1[i] == nums2[j]`，直接返回该值——因为两数组都升序，之前跳过的元素都更小且不相等。
3. 若 `nums1[i] < nums2[j]`，说明 `nums1[i]` 太小不可能匹配，`i += 1`；反之 `j += 1`。
4. 循环结束仍未返回，说明无公共元素，返回 `-1`。

以示例 2 为例：`nums1 = [1,2,3,6]`，`nums2 = [2,3,4,5]`。初始 `i=0, j=0`，`1 < 2` 所以 `i` 推进到 1；此时 `nums1[1]=2 == nums2[0]=2`，返回 2。关键中间值就是 `i` 从 0 跳到 1 这一步。

```python
i = j = 0
while i < len(nums1) and j < len(nums2):
    a, b = nums1[i], nums2[j]
    if a == b:
        return a
    if a < b:
        i += 1
    else:
        j += 1
return -1
```

## 复杂度
时间 O(m + n)：`i` 和 `j` 各自单调前进，最多各走完一遍。
空间 O(1)：只开了 `i`、`j`、`a`、`b` 四个变量，没有额外数组。

## 易错点
1. 输入 `nums1 = [1,2,3]`、`nums2 = [4,5]` → 若把循环条件写成 `i < len(nums1)` 单边判断，`j` 会越界访问 `nums2[j]` 抛 IndexError → 必须用 `and` 同时约束两个指针。
2. 输入 `nums1 = [1,1,2]`、`nums2 = [1,3]` → 若相等时只 `i += 1` 不返回，会继续找下一个公共值，可能返回更大的 2 或漏掉 → 第一次相等就必须 `return a`，因为升序保证它是最小公共值。

## 如果面试官追问
问：若数组未排序怎么办？
答：先对较短数组建 `set`，再遍历另一个数组取最小公共值，时间 O(m + n)，空间 O(min(m, n))。
