## 一句话思路
先升序放 1..n-k，再用剩余数字在两端交替取，制造 k-1 个新差值，加上末尾的 1 共 k 种。

## 怎么做
1. 前 `n-k` 个位置直接放 `1, 2, ..., n-k`，这一段差值全是 1。
2. 剩余区间是 `[n-k+1, n]`，用双指针 `lo = n-k+1`、`hi = n`，交替取 `hi, lo, hi-1, lo+1, ...`。
3. 交替取时相邻差值是 `k-1, k-2, ..., 1`，其中 `1` 与前面重复，所以新增 `k-1` 种，总数正好 `k`。

以 `n=3, k=2` 为例：前 `n-k=1` 个位置放 `[1]`；剩余区间 `lo=2, hi=3`，交替得 `3, 2`；拼接为 `[1, 3, 2]`，差值 `[2, 1]`，不同整数 `{1, 2}` 共 2 个，符合要求。

```python
def constructArray(n, k):
    ans = list(range(1, n - k + 1))
    lo, hi = n - k + 1, n
    while lo <= hi:
        ans.append(hi)
        hi -= 1
        if lo <= hi:
            ans.append(lo)
            lo += 1
    return ans
```

注意 `n-k+1` 这个起点：当 `k=1` 时剩余区间只剩 `[n, n]`，交替只取一个数，整段差值全是 1，正好 1 种。

## 复杂度
时间：O(n)，构造列表和双指针各扫一遍。
空间：O(n)，仅答案数组本身，无额外辅助结构。

## 易错点
- `k=1` 时若仍按「交替取」写死循环条件，可能把 `lo` 和 `hi` 都塞进去导致长度超过 n → 正确做法是循环内先取 `hi` 再判断 `lo <= hi` 才取 `lo`，保证区间长度为奇数时不多取。
- `k=n-1` 时剩余区间是 `[2, n]`，若把起点写成 `n-k` 会重复放入数字 1 → 起点必须是 `n-k+1`，让前缀恰好占 `n-k` 个位置。

## 如果面试官追问
问：如果要求差值集合恰好是 `{1, 2, ..., k}` 而不是任意 k 个不同值，构造要改吗？
答：不用改，本构造的差值正好是 `1..k`，交替段产生 `k-1..1`，前缀段补 `1`。
