## 一句话思路
从右往左预处理后缀最小值，再从左往右累加前缀和，边扫边取 `prefix - suffixMin` 的最大值。

## 怎么做
1. 先建 `suf` 数组，`suf[i] = min(nums[i:])`，从 `n-1` 倒着推：`suf[i] = min(nums[i], suf[i+1])`。
2. 从左往右累加 `prefix`，对每个 `i` 在 `0..n-2` 上算 `prefix - suf[i+1]`，更新答案。
3. 用示例 1 `[10,-1,3,-4,-5]` 走一遍：`suf = [-5,-5,-5,-5,-5]`；`i=2` 时 `prefix = 10 + (-1) + 3 = 12`，`suf[3] = -5`，得分 `12 - (-5) = 17`，是最大值。
4. 注意 `suf` 的下标是 `i+1`，因为后缀从分割点右边第一个元素开始。

```python
n = len(nums)
suf = [0] * n
suf[-1] = nums[-1]
for i in range(n - 2, -1, -1):
    suf[i] = min(nums[i], suf[i + 1])

ans = -2**63
prefix = 0
for i in range(n - 1):
    prefix += nums[i]
    ans = max(ans, prefix - suf[i + 1])
return ans
```

关键点：`suf[i+1]` 而不是 `suf[i]`，因为分割点 `i` 的后缀从 `i+1` 开始。

## 复杂度
时间：O(n)，建 `suf` 和主循环各扫一遍。
空间：O(n)，额外开了长度 n 的 `suf` 数组。

## 易错点
- 输入 `[1,1]` → 若循环写成 `range(n)` 会让 `i = n-1`，`suf[n]` 越界或取到错误值 → 循环必须只到 `n-2`，保证 `i+1 <= n-1`。
- 输入 `[-7,-5,3]` → 若把 `ans` 初始化为 0，会返回 0 而不是 `-2` → 初始值要设成足够小的负数，如 `-2**63`，因为得分可能为负。

## 如果面试官追问
问：能否把空间降到 O(1)？
答：可以，先算总和，从左往右维护 `prefix` 和剩余后缀和，但后缀最小值仍需额外结构，除非允许修改原数组原地存 `suf`。
