## 一句话思路
枚举第一台机器人的下移列 i，第二台最优只能吃「上排 i 右侧」或「下排 i 左侧」的较大者，取所有 i 的最小值。

## 怎么做
1. 第一台机器人路径必是：上排走 0..i，在列 i 下移，再下排走 i..n-1。它只由下移列 i 决定，共 n 种。
2. 它清零后，第二台机器人无论怎么走，能拿到的点数恰好是 `max(上排 i+1..n-1 之和, 下排 0..i-1 之和)`——因为上排左侧和下排右侧已被第一台吃光。
3. 用两个前缀和数组 `pre_top`、`pre_bot`，O(1) 算出这两个区间和，对 i 从 0 到 n-1 取最小值。

以示例 1 `grid = [[2,5,4],[1,5,1]]` 为例，i=1 时：上排右侧 `grid[0][2]=4`，下排左侧 `grid[1][0]=1`，第二台得 `max(4,1)=4`；i=0 时得 `max(5+4, 0)=9`；i=2 时得 `max(0, 1+5)=6`。三者取最小为 4。

```python
n = len(grid[0])
pre_top = [0] * (n + 1)
pre_bot = [0] * (n + 1)
for c in range(n):
    pre_top[c + 1] = pre_top[c] + grid[0][c]
    pre_bot[c + 1] = pre_bot[c] + grid[1][c]
ans = float('inf')
for i in range(n):
    top_right = pre_top[n] - pre_top[i + 1]   # 上排 i+1..n-1
    bot_left = pre_bot[i]                      # 下排 0..i-1
    ans = min(ans, max(top_right, bot_left))
return ans
```

## 复杂度
时间 O(n)：一次建前缀和、一次枚举下移列 i。
空间 O(n)：额外开了 `pre_top`、`pre_bot` 两个长度 n+1 的数组。

## 易错点
- 边界 i=0 或 i=n-1 时区间为空：`pre_top[n]-pre_top[i+1]` 在 i=n-1 得 0，`pre_bot[i]` 在 i=0 得 0，若手写循环漏掉空区间会越界或算错，直接用前缀和相减最稳。
- 把第二台的收益写成「上排右侧 + 下排左侧」：示例 1 的 i=1 会得 4+1=5 而非 4。第二台只能二选一，因为下移后无法回头，必须取 `max` 不是求和。

## 如果面试官追问
若要求输出第一台机器人的具体下移列 i 而非点数？答：在取 min 时同步记录当前 i，返回 `(ans, best_i)` 即可，逻辑不变。
