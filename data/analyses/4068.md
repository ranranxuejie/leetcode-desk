## 一句话思路
按结束时间排序后做 DP，把「空闲收益」并入转移式，用二分找上一个不重叠会议。

## 怎么做
1. 把 meetings 按 end 升序排序，令 `dp[i]` 为前 i 场会议（下标 0..i-1）能拿到的最大总收益。
2. 对第 i 场会议 `[s, e, r]`，用二分在已排序的 end 数组里找最后一个 `end <= s` 的位置 j，即 `bisect_right(ends, s, 0, i)`。
3. 转移：`dp[i+1] = max(dp[i], dp[j] + r + (s - ends[j-1] if j > 0 else 0))`——选它时，空闲收益只算「上一场结束到 s」这一段，前面已由 `dp[j]` 结清。
4. 答案取 `dp[n]`。

以示例 3 `[[1,2,2],[4,5,2],[7,9,3]]` 为例，排序后 ends = [2,5,9]。处理第三场 `[7,9,3]` 时 `bisect_right(ends, 7, 0, 2) = 2`，即 j=2，`dp[2]=4`（前两场 2+2+空闲 2），加上 `3 + (7-5)=5` 得 9，与 `dp[2]=4` 取大仍为 9；最终 `dp[3]=9`？注意这里 dp 定义要一致，正确写法是 `dp[j]` 已含到第 j 场结束的收益，故第三场贡献 `dp[2] + 3 + (7 - ends[1]) = 4 + 3 + 2 = 9`，而全选三场应为 11，说明 `dp[2]` 必须取「以第 2 场结尾」的值而非前缀最大——因此改用 `best[i]` 表示前 i 场最优、`f[i]` 表示必选第 i 场，转移时 `f[i] = r + max(f[j] + s - ends[j], 0 起点)`，`best[i+1] = max(best[i], f[i])`。

```python
ends = [m[1] for m in meetings]
f = [0] * n
best = [0] * (n + 1)
for i, (s, e, r) in enumerate(meetings):
    j = bisect_right(ends, s, 0, i)   # 前 j 场 end <= s
    prev = f[j-1] + s - ends[j-1] if j > 0 else 0
    f[i] = r + prev
    best[i+1] = max(best[i], f[i])
return best[n]
```

## 复杂度
时间 O(n log n)：排序 O(n log n)，每次二分 O(log n)，共 n 次。
空间 O(n)：ends、f、best 三个长度 n 的数组。

## 易错点
- 输入 `[[1,2,2],[4,5,2],[7,9,3]]` 若用前缀最大 `best[j]` 代替 `f[j-1]` 拼空闲段，会把「上一场结束时间」错配成别的会议，算出 9 而非 11；必须用「以第 j-1 场结尾」的结束时间算 `s - ends[j-1]`。
- 端点相接如 `[[2,5,4],[5,8,3]]`：`bisect_right(ends, 5)` 会返回 1（含 end=5），空闲收益 `5-5=0`，若误用 `bisect_left` 会漏掉这场衔接，少算 3。

## 如果面试官追问
要求输出具体选了哪些会议？答：在 `f[i]` 转移时记录前驱下标 `pre[i]=j-1`，最后从 `best[n]` 对应的 i 回溯即可。
