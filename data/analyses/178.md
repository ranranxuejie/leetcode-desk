## 一句话思路
用窗口函数 `DENSE_RANK() OVER (ORDER BY score DESC)`，它天然做到同分同名次、名次连续无空缺。

## 怎么做
1. 先按 `score` 降序排，`DENSE_RANK()` 在排序后的序列上从 1 开始编号。
2. 同分时窗口函数不递增计数，所以 4.00 出现两次都拿 1。
3. 下一个不同分数直接拿 2，不会跳到 3——这正是 `DENSE_RANK` 与 `RANK` 的区别。
4. 外层只投影 `score, rank`，输出顺序由窗口的 `ORDER BY` 保证。

以官方示例为具体输入：排序后序列是 `4.00, 4.00, 3.85, 3.65, 3.65, 3.50`。逐行算 `DENSE_RANK`：第 1 行 4.00 → 1；第 2 行 4.00 与上一行相等 → 仍是 1；第 3 行 3.85 是新的不同值 → 2；第 4 行 3.65 → 3；第 5 行 3.65 → 3；第 6 行 3.50 → 4。关键中间值就是「不同分数的个数」：到 3.85 时已出现 2 个不同分数，所以它的 rank 是 2。

```python
# 思路等价实现（若不用窗口函数，用相关子查询）
# SELECT score,
#        (SELECT COUNT(DISTINCT s2.score)
#         FROM Scores s2 WHERE s2.score >= s.score) AS rank
# FROM Scores s ORDER BY score DESC;

# 窗口函数写法（推荐）
# SELECT score,
#        DENSE_RANK() OVER (ORDER BY score DESC) AS rank
# FROM Scores
# ORDER BY score DESC;
```

子查询版本的含义：对每一行，数一数「有多少个不同的分数 ≥ 当前分数」，这个计数就是它的名次。对 3.85 来说，≥3.85 的不同分数是 {4.00, 3.85}，共 2 个，rank=2，与窗口函数结果一致。

## 复杂度
时间：窗口函数需对 n 行排序，O(n log n)；子查询版本每行扫一遍，O(n²)。
空间：窗口排序额外 O(n)；子查询版本 O(1) 额外空间。

## 易错点
1. 用 `RANK()` 代替 `DENSE_RANK()`：输入示例里 3.65 会得到 4 而不是 3（因为 4.00 占了两行），名次出现空缺，与「排名之间不应该有空缺」直接冲突。正确做法是 `DENSE_RANK()`。
2. 子查询里漏写 `DISTINCT`：`COUNT(s2.score)` 会把两个 4.00 都数进去，3.85 的 rank 变成 3 而不是 2。必须 `COUNT(DISTINCT s2.score)`，因为名次数的是「不同分数」的个数。

## 如果面试官追问
问：如果要求同分不同名次（按 id 打破平局）怎么办？
答：改用 `ROW_NUMBER() OVER (ORDER BY score DESC, id ASC)`，此时 4.00 两行分别拿 1 和 2。
