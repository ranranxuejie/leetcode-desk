## 一句话思路
在 `s + '#' + s[::-1]` 上求最长公共前后缀，其长度就是 `s` 里最长的回文前缀，剩下的后缀反转后拼到前面。

## 怎么做
1. 设 `t = s + '#' + s[::-1]`，`#` 保证匹配长度不超过 `len(s)`。
2. 对 `t` 求 KMP 的 `next` 数组（前缀函数），`next[-1]` 即最长回文前缀长度 `k`。
3. 答案 = `s[k:][::-1] + s`。

以 `s = "aacecaaa"` 为例：`s[::-1] = "aaacecaa"`，`t = "aacecaaa#aaacecaa"`。前缀函数在末尾的值 `k = 7`，因为 `t[:7] = "aacecaa"` 与 `t[-7:] = "aacecaa"` 相等，说明 `s[:7]` 是回文前缀。于是 `s[7:] = "a"`，反转得 `"a"`，答案 `"a" + "aacecaaa" = "aaacecaaa"`。

```python
def shortestPalindrome(s):
    t = s + '#' + s[::-1]
    n = len(t)
    pi = [0] * n
    for i in range(1, n):
        j = pi[i - 1]
        while j > 0 and t[i] != t[j]:
            j = pi[j - 1]
        if t[i] == t[j]:
            j += 1
        pi[i] = j
    k = pi[-1]
    return s[k:][::-1] + s
```

`#` 不在小写字母表里，所以 `pi[-1]` 不会超过 `len(s)`；若 `s` 为空串，`t = "#"`，`pi[-1] = 0`，返回空串，符合预期。

## 复杂度
时间 O(n)：`t` 长 `2n+1`，KMP 前缀函数线性扫描，`while` 回退总次数摊还 O(n)。
空间 O(n)：`pi` 数组长 `2n+1`，外加 `t` 和 `s[::-1]` 两份拷贝。

## 易错点
- 拼接时漏掉分隔符 `#`，直接用 `s + s[::-1]`：对 `s = "aab"`，`t = "aabbaa"`，`pi[-1]` 会算成 4（匹配跨越了中点），得到错误的 `k`，答案变成 `"aab"` 而非正确的 `"baab"`。正确做法是插入一个不在字母表中的字符隔开。
- 把 `pi[-1]` 当成「最长回文子串」而非「最长回文前缀」：对 `s = "abac"`，回文子串 `"aba"` 长度为 3，但回文前缀只有 `"a"`，`k` 应为 1，答案 `"caba" + "bac"` 中的 `"c"+"abac" = "cabac"`。必须只认从下标 0 开始的那段。

## 如果面试官追问
问：不用 KMP，用滚动哈希怎么做？
答：正反两串各算前缀哈希，从 `len(s)` 往下枚举长度 `L`，比较 `s[:L]` 与 `s[n-L:][::-1]` 的哈希，第一个相等即 `k`；需双模数防碰撞。
