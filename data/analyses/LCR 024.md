## 一句话思路
用三个指针 prev/cur/nxt 边走边把 cur.next 掉头指向 prev，因为每个节点只需改一次 next 就能完成反转。

## 怎么做
1. 初始化 `prev = None`，`cur = head`。
2. 循环里先存 `nxt = cur.next`，再执行 `cur.next = prev`。
3. 然后 `prev, cur = cur, nxt` 整体前移一格。
4. 循环结束时 `cur` 为 `None`，返回 `prev`（它指向原链表尾，即新头）。

以 `head = [1,2,3,4,5]` 为例，第一轮进入时 `cur` 是节点 1、`nxt` 是节点 2，执行 `cur.next = prev` 后节点 1 的 next 从 2 变成 `None`；随后 `prev` 变成节点 1、`cur` 变成节点 2。走完五轮后 `prev` 停在节点 5。

```python
prev, cur = None, head
while cur:
    nxt = cur.next      # 先存后继，否则断链后找不到
    cur.next = prev     # 掉头
    prev, cur = cur, nxt
return prev
```

递归写法只需记住：`reverseList(head.next)` 返回新头，此时 `head.next` 已是反转段的尾，把 `head.next.next = head`、`head.next = None` 即可；`head is None or head.next is None` 是递归出口。

## 复杂度
时间 O(n)：每个节点被访问一次，n 为节点数。
空间 O(1)：迭代只开 prev/cur/nxt 三个指针；递归版栈深 O(n)。

## 易错点
- 输入 `[1]`（单节点）或 `[]`（空表）→ 若循环条件写成 `while cur.next` 会空指针或漏掉单节点 → 用 `while cur`，空表直接返回 `None`，单节点走一轮后 `prev` 就是它本身。
- 输入 `[1,2]` → 若先写 `cur.next = prev` 再取 `cur.next`，取到的是已改写的 `None`，第二轮就断链只剩 `[2]` → 必须先 `nxt = cur.next` 再改指针，顺序不能换。

## 如果面试官追问
问：要求只反转区间 `[m, n]` 怎么办？
答：先走 `m-1` 步定位前驱 `pre`，对区间内节点做同样的三指针反转，最后把 `pre.next` 接到反转段头、反转段尾接回 `n+1` 节点。
