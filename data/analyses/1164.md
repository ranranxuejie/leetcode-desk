## 一句话思路
先筛出 `change_date <= '2019-08-16'` 的行，按 `product_id` 取 `change_date` 最大的那行价格，再左连接全部产品补 10。

## 怎么做
1. 用 `WHERE change_date <= '2019-08-16'` 过滤，`2` 号产品的 `2019-08-17` 那行（65）被剔除。
2. 在过滤结果上按 `product_id` 分组取 `MAX(change_date)`，得到每个产品在截止日前的最后一次改价日期。
3. 用 `(product_id, change_date)` 回连原表拿到 `new_price`，`1` 号产品拿到 `2019-08-16` 的 35，`2` 号拿到 `2019-08-14` 的 50。
4. 以 `Products` 去重后的 `product_id` 为左表 `LEFT JOIN` 上面结果，`3` 号产品匹配不上，`COALESCE(price, 10)` 补成 10。

关键中间值：第 2 步对 `1` 号产品，过滤后剩 `08-14`、`08-15`、`08-16` 三行，`MAX(change_date)` 必须是 `2019-08-16` 而不是 `08-15`，否则价格会错成 30。

```python
# df: Products 的 DataFrame
cut = "2019-08-16"
valid = df[df["change_date"] <= cut]
last = valid.groupby("product_id")["change_date"].max().reset_index()
priced = last.merge(valid, on=["product_id", "change_date"], how="left")
all_ids = df[["product_id"]].drop_duplicates()
res = all_ids.merge(priced[["product_id", "new_price"]], on="product_id", how="left")
res["price"] = res["new_price"].fillna(10)
```

## 复杂度
时间：O(n log n)，n 为 Products 行数，排序/分组取 max 贡献 log n。
空间：O(k)，k 为不同 product_id 数，额外开了 last 和 res 两张中间表。

## 易错点
- 用 `change_date < '2019-08-16'` 严格小于 → `1` 号产品取到 `08-15` 的 30，正确是 35；边界日期当天改价算数，必须用 `<=`。
- 只对 `Products` 里出现过的产品做内连接 → `3` 号产品在截止日前无任何改价记录，会被整行丢掉；正确做法是以去重 product_id 为左表左连接，缺失补 10。

## 如果面试官追问
问：如果截止日期是查询参数、要支持任意日期怎么办？
答：把 `cut` 换成参数即可，逻辑不变；若要多次查询，可按 product_id 建 `change_date` 索引或预排序后二分。
