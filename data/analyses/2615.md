## 一句话思路
按值分组收集下标，组内下标天然有序，用前缀和把每个位置的左右两侧距离和 O(1) 算出。

## 怎么做
1. 用字典 `pos` 把 `nums` 中相同值的下标收集成有序列表，遍历时按下标递增追加，列表天然升序。
2. 对每个列表 `p`（长度 m）建前缀和 `pre`，`pre[k] = p[0]+...+p[k-1]`。
3. 对列表中第 k 个下标 `x = p[k]`，左侧有 k 个元素，右侧有 m-1-k 个：左侧距离和 = `x*k - pre[k]`，右侧距离和 = `(pre[m]-pre[k+1]) - x*(m-1-k)`，两者相加写回 `arr[x]`。
4. 单元素列表直接跳过，`arr` 保持 0。

以 `nums = [1,3,1,1,2]` 为例，值 1 的下标列表 `p = [0,2,3]`，`pre = [0,0,2,5]`。取 k=1、x=2：左侧 `2*1 - pre[1] = 2`，右侧 `(5-pre[2]) - 2*(3-1-1) = 3 - 2 = 1`，合计 3，正是 `arr[2]`。

```python
from collections import defaultdict
pos = defaultdict(list)
for i, v in enumerate(nums):
    pos[v].append(i)
arr = [0] * len(nums)
for p in pos.values():
    m = len(p)
    if m == 1:
        continue
    pre = [0] * (m + 1)
    for k in range(m):
        pre[k + 1] = pre[k] + p[k]
    for k, x in enumerate(p):
        left = x * k - pre[k]
        right = (pre[m] - pre[k + 1]) - x * (m - 1 - k)
        arr[x] = left + right
```

## 复杂度
时间 O(n)：每个下标进组一次、算一次，前缀和也是线性。
空间 O(n)：`pos` 存全部下标，`pre` 最长 n。

## 易错点
- 输入 `nums = [1,1]` 这类只有两个相同值时，若把右侧公式写成 `pre[m]-pre[k]`（漏减 `p[k]` 自己），k=0 会得到 `1-0-1*1 = 0` 而非 1；正确是 `pre[m]-pre[k+1]` 只取严格右侧元素。
- 输入 `nums = [0,5,3]` 全不相同时，若对每个值都建 `pre` 并进入循环，`m-1-k` 在 m=1 时算出的 right 依赖空前缀，容易写出负值；正确做法是先 `if m == 1: continue`，让 `arr` 保持初始 0。

## 如果面试官追问
若 `nums` 长度涨到 10^7、内存吃紧怎么办？答：不存 `pre` 数组，先算组内总和与元素个数，再从左往右滚动维护左侧和，边扫边出答案，空间降到 O(不同值个数)。
