## 一句话思路
用长度为 5 的计数数组模拟每只青蛙的进度，同时维护当前正在叫的青蛙数，取最大值。

## 怎么做
1. 建立 `cnt = [0]*5`，`cnt[i]` 表示当前处于第 i 个字母（c/r/o/a/k）的青蛙数，`cur` 表示正在叫的青蛙数，`ans` 记录峰值。
2. 遍历每个字符，映射到下标 `i`；若 `i > 0` 且 `cnt[i-1] == 0`，说明没有青蛙能接这个字母，直接返回 -1。
3. 若 `i > 0` 则 `cnt[i-1] -= 1`；`cnt[i] += 1`；若 `i == 0` 则 `cur += 1`，若 `i == 4` 则 `cur -= 1`（一只青蛙叫完）。
4. 每步更新 `ans = max(ans, cur)`；遍历结束后若 `cur != 0` 返回 -1，否则返回 `ans`。

以 `"crcoakroak"` 为例：读到第 2 个 `c` 时 `cnt = [2,0,0,0,0]`、`cur = 2`、`ans = 2`；随后 `r` 消耗一个 `c`，`cnt` 变 `[1,1,0,0,0]`，`cur` 保持 2，最终答案 2。

```python
cnt = [0] * 5
cur = ans = 0
idx = {'c': 0, 'r': 1, 'o': 2, 'a': 3, 'k': 4}
for ch in croakOfFrogs:
    i = idx[ch]
    if i > 0 and cnt[i - 1] == 0:
        return -1
    if i > 0:
        cnt[i - 1] -= 1
    cnt[i] += 1
    if i == 0:
        cur += 1
    elif i == 4:
        cur -= 1
    ans = max(ans, cur)
return ans if cur == 0 else -1
```

## 复杂度
时间 O(n)：n 为 `croakOfFrogs` 长度，单次遍历，字典查表 O(1)。
空间 O(1)：只开了长度 5 的 `cnt` 和常数个变量。

## 易错点
- 输入 `"croakcrook"`：第二个 `o` 出现时 `cnt[1]`（r）已为 0，若不检查 `cnt[i-1] == 0` 就会让 `cnt[2]` 变成 2，最后 `cur` 不为 0 才报错，但中间状态已污染；正确做法是每次读字符先判前驱计数，为 0 立即返回 -1。
- 输入 `"croak"` 后接 `"croak"` 但中间缺 `k`，如 `"croakcroa"`：遍历结束 `cur == 1`，必须用 `cur == 0` 收尾校验，否则会误返回 1；正确做法是返回前检查 `cur` 是否为 0。

## 如果面试官追问
问：若要求输出每只青蛙的具体叫声序列怎么办？
答：把 `cnt` 换成 5 个栈，存每只青蛙的起始下标，`k` 出栈时记录区间，最后按栈内剩余判 -1。
