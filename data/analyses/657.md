## 一句话思路
分别统计 U/D 和 L/R 的净位移，两个方向都归零才回到原点。

## 怎么做
1. 设 `x = 0` 记水平位移，`y = 0` 记垂直位移。
2. 遍历 `moves`，`R` 让 `x += 1`，`L` 让 `x -= 1`，`U` 让 `y += 1`，`D` 让 `y -= 1`。
3. 遍历结束后返回 `x == 0 and y == 0`。

以 `moves = "UD"` 为例：读到 `'U'` 后 `y` 从 0 变成 1，读到 `'D'` 后 `y` 从 1 回到 0，`x` 始终为 0，最终 `(0, 0)` 判真。

```python
x = y = 0
for m in moves:
    if m == 'R':
        x += 1
    elif m == 'L':
        x -= 1
    elif m == 'U':
        y += 1
    else:
        y -= 1
return x == 0 and y == 0
```

也可以只数四个字符出现次数：`moves.count('U') == moves.count('D') and moves.count('L') == moves.count('R')`，一行搞定，但会扫四遍字符串。

## 复杂度
时间：O(n)，n 为 `moves` 长度，每个字符处理一次。
空间：O(1)，只开了 `x`、`y` 两个整型变量。

## 易错点
- 输入 `moves = "RLU"` → 只看水平方向 `x` 归零就返回 `True`，错成 `true`；正确做法是 `x` 和 `y` 同时判零，这里 `y = 1` 应返回 `False`。
- 输入 `moves = "LL"` → 用 `len(moves) % 2 == 0` 判断，偶数长度就以为能回原点，错成 `True`；正确做法是必须比较 U 与 D、L 与 R 的计数是否相等，`"LL"` 的 `L` 有 2 个、`R` 有 0 个，不相等。

## 如果面试官追问
问：如果 `moves` 长度到 10^7，怎么优化？
答：单次遍历已是最优 O(n)，可改用 `collections.Counter` 一次统计四类字符再比较，避免四次 `count` 扫描。
