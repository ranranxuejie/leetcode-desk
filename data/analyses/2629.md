## 一句话思路
从 `functions` 末尾往前遍历，把 `x` 依次喂给每个函数，因为复合 `f(g(h(x)))` 的最内层是最后一个函数。

## 怎么做
1. 从 `len(functions) - 1` 开始倒序遍历到 0。
2. 每步执行 `x = functions[i](x)`，把结果覆盖回 `x`。
3. 循环结束返回 `x`；空列表时循环不执行，`x` 原样返回，正好是恒等函数。

拿示例 1 的 `functions = [x => x + 1, x => x * x, x => 2 * x], x = 4` 走一遍：`i = 2` 时 `x = functions[2](4) = 8`；`i = 1` 时 `x = functions[1](8) = 64`；`i = 0` 时 `x = functions[0](64) = 65`。关键中间值是 `i = 1` 那步的 64，它证明平方作用在 `2 * 4` 的结果上，而不是作用在 4 上。

```python
def compose(functions, x):
    for i in range(len(functions) - 1, -1, -1):
        x = functions[i](x)
    return x
```

也可以写成 `for f in reversed(functions): x = f(x)`，语义相同，`reversed` 对列表返回倒序迭代器，不复制数组。

注意函数签名里 `functions` 是函数对象列表，不是字符串或表达式，所以不能拼接成 `"f(g(h(x)))"` 再 `eval`，直接调用即可。

## 复杂度
时间 O(n)，n 为 `functions.length`，每个函数恰好调用一次。
空间 O(1)，只维护 `x` 一个变量；`reversed` 不额外复制列表。

## 易错点
- 正序遍历 `functions` → 示例 1 会算成 `(4 + 1) * (4 + 1) * 2 = 50` 而非 65 → 必须从 `len(functions) - 1` 倒着走。
- 空列表 `functions = [], x = 42` → 若先写 `x = functions[0](x)` 会抛 `IndexError` → 用 `range(len(functions) - 1, -1, -1)` 或 `reversed`，空列表时循环体一次都不进，直接返回 42。

## 如果面试官追问
问：若要求返回一个新函数而不是立即求值怎么办？
答：返回闭包 `lambda y: compose(functions, y)`，把倒序循环封进去，调用时才计算。
