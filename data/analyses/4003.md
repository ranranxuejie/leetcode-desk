## 一句话思路
把「位置 + 下一步行动奇偶性」当状态跑 Dijkstra，因为代价非负且奇偶性只有两态。

## 怎么做
1. 状态定为 `(i, j, p)`，`p=0` 表示下一步是奇数行动（只能右/下），`p=1` 表示偶数行动（只能左/上）。
2. 从 `(0,0,0)` 出发，初始距离是入口代价 `1`（即 `(0+1)*(0+1)`）。
3. 每个状态枚举四个方向：方向合法（`p=0` 走右/下，`p=1` 走左/上）只付目标入口代价；方向违规再加 `penalty[i][j]`；等待则付 `penalty[i][j]` 且原地不动、`p` 翻转。
4. 到达 `(m-1,n-1)` 任一 `p` 即答案。

以示例 1 `m=n=2, penalty=[[5,3],[1,4]]` 为例：`(0,0,0)` 距离 1；行动 1 向下到 `(1,0)`，入口代价 `2*1=2`，距离 3，`p` 变 1；此时从 `(1,0,1)` 向右是违规方向，付 `4 + penalty[1][0]=1`，得 8，与输出一致。

```python
import heapq
def minCost(m, n, penalty):
    INF = float('inf')
    dist = [[[INF]*2 for _ in range(n)] for _ in range(m)]
    dist[0][0][0] = 1
    pq = [(1, 0, 0, 0)]
    while pq:
        d, i, j, p = heapq.heappop(pq)
        if d > dist[i][j][p]: continue
        if (i, j) == (m-1, n-1): return d
        moves = [(0,1),(1,0)] if p == 0 else [(0,-1),(-1,0)]
        for di, dj in moves:
            ni, nj = i+di, j+dj
            if 0 <= ni < m and 0 <= nj < n:
                nd = d + (ni+1)*(nj+1)
                if dist[ni][nj][1-p] > nd:
                    dist[ni][nj][1-p] = nd
                    heapq.heappush(pq, (nd, ni, nj, 1-p))
        nd = d + penalty[i][j]
        if dist[i][j][1-p] > nd:
            dist[i][j][1-p] = nd
            heapq.heappush(pq, (nd, i, j, 1-p))
```

## 复杂度
时间：`O(m*n*log(m*n))`，状态数 `2mn`，堆操作贡献 log。
空间：`O(m*n)`，`dist` 三维数组存两态。

## 易错点
- 等待后 `p` 必须翻转：示例 2 中 `(0,0)` 等待付 `penalty[0][0]=0` 后 `p` 从 0 变 1，才能「违规」向右走；若忘记翻转，会误判方向合法性得到 9 而非 7。
- 违规移动的 penalty 取**移动前**单元格 `penalty[i][j]`，不是目标格；示例 1 从 `(1,0)` 向右违规付的是 `penalty[1][0]=1`，写成 `penalty[1][1]` 会得 11。

## 如果面试官追问
若 `m*n` 放大到 `10^7` 且 penalty 全 0，能否省掉堆？答：此时等价于按奇偶分层的最短路，可用 0-1 BFS 或直接按层 DP 降为线性。
