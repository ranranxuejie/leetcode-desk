## 一句话思路
把每层按逆时针顺序摊成一维数组，整体左移 `k % len` 位再填回，逐层独立处理。

## 怎么做
1. 层数 `layers = min(m, n) // 2`，第 `L` 层的四条边按「上→右→下→左」逆时针收集。
2. 对每层数组 `a`，取 `shift = k % len(a)`，新值 `a[(i + shift) % len(a)]` 填回原位置。
3. 用同一组坐标序列先收集后回填，保证顺序一致。

以示例 2 的 `grid`（4×4）为例，最外层 `L=0` 收集到 `a = [1,2,3,4,8,12,16,15,14,13,9,5]`，`len=12`，`k=2` 时 `shift=2`，回填后 `grid[0][0]=a[2]=3`、`grid[0][3]=a[5]=8`，与输出首行 `[3,4,8,12]` 一致。

```python
m, n = len(grid), len(grid[0])
for L in range(min(m, n) // 2):
    pos = []
    pos += [(L, j) for j in range(L, n - L)]              # 上
    pos += [(i, n - 1 - L) for i in range(L + 1, m - L)]  # 右
    pos += [(m - 1 - L, j) for j in range(n - 2 - L, L - 1, -1)]  # 下
    pos += [(i, L) for i in range(m - 2 - L, L, -1)]      # 左
    a = [grid[i][j] for i, j in pos]
    s = k % len(a)
    for t, (i, j) in enumerate(pos):
        grid[i][j] = a[(t + s) % len(a)]
```

## 复杂度
时间：O(m·n)，每个格子被收集和回填各一次，`k` 只参与取模。
空间：O(m + n)，`pos` 与 `a` 存单层元素，最大约 `2(m+n)`。

## 易错点
- `k` 最大 `10^9`，直接循环 `k` 次会超时 → 必须先 `k % len(a)`；注意每层长度不同，取模要放在层内做，不能对全局取一次。
- 四条边的角点重复收集 → 例如 `L=0` 时 `(0, n-1)` 同时属于「上」和「右」；正确做法是右、下、左三条边都跳过已收的角，代码里用 `range(L+1, ...)` 和 `range(..., L-1, -1)` 控制端点。

## 如果面试官追问
若 `k` 改为负数（顺时针轮转）怎么办？答：把 `s = k % len(a)` 换成 `s = (-k) % len(a)`，其余不变。
