## 一句话思路
前 n 个奇数之和是 n²，前 n 个偶数之和是 n(n+1)，两者 GCD 恒等于 n，直接返回 n。

## 怎么做
1. 用求和公式把两个和写成闭式：sumOdd = n²，sumEven = n(n+1)。
2. 提取公因子：GCD(n², n(n+1)) = n · GCD(n, n+1)。
3. 相邻整数互质，GCD(n, n+1) = 1，所以答案就是 n。
4. 以 n = 4 验证：sumOdd = 16，sumEven = 20，GCD(16, 20) = 4 = n；中间量 GCD(n, n+1) = GCD(4, 5) = 1，乘回 n 得 4。

```python
def gcd_of_odd_even_sums(n: int) -> int:
    sum_odd = n * n          # 1+3+...+(2n-1)
    sum_even = n * (n + 1)   # 2+4+...+2n
    a, b = sum_odd, sum_even
    while b:
        a, b = b, a % b
    return a                 # 恒等于 n
```

上面是「按公式算再求 GCD」的写法，用来验证结论；实际提交只需 `return n`。n ≤ 1000 时 n² ≤ 10⁶，两种写法都不会溢出，但闭式写法把 O(n) 的累加直接压成 O(1)。

## 复杂度
时间：O(1)，闭式直接返回 n；若按公式求 GCD 则是 O(log n)，由欧几里得算法贡献。
空间：O(1)，只用了 sum_odd、sum_even、a、b 四个整型变量。

## 易错点
- 误以为要真的循环累加前 n 个奇数/偶数：n = 1000 时循环 1000 次虽不超时，但把简单题写成 O(n)；正确做法是直接用 sumOdd = n*n、sumEven = n*(n+1)，或干脆返回 n。
- 把 sumEven 写成 n² 或 2n：n = 5 时会得到 GCD(25, 25) = 25 或 GCD(25, 10) = 5 的巧合，n = 4 时若写 sumEven = 2n = 8 则 GCD(16, 8) = 8 ≠ 4；正确是 n(n+1) = 20。

## 如果面试官追问
问：若改成「前 n 个奇数之和与前 n 个偶数之和的最小公倍数」呢？
答：LCM = n²(n+1)，因为两数 GCD 为 n，LCM = sumOdd·sumEven/n = n²(n+1)。
