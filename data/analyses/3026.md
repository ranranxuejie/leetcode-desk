## 一句话思路
用哈希表记录每个前缀和对应的最小下标，枚举右端点时查 `nums[j]±k` 是否出现过。

## 怎么做
1. 设 `pre[i] = nums[0]+...+nums[i-1]`，则子数组 `nums[l..r]` 的和为 `pre[r+1]-pre[l]`。
2. 固定右端点 `r`，需要找最小的 `l` 使 `nums[l] == nums[r]±k`，这样 `pre[l]` 最小、和最大。
3. 哈希表 `first` 存「值 → 该值首次出现的下标」，遍历时先查再更新，保证 `l < r`。
4. 用 `pre` 数组配合 `first` 直接算 `pre[r+1]-pre[first[v]]`，取最大值。

以示例 2 `nums=[-1,3,2,4,5], k=3` 为例：`r=2`（`nums[2]=2`）时查 `2-3=-1`，`first[-1]=0`，得和 `pre[3]-pre[0]=4-0=4`；`r=4`（`nums[4]=5`）查 `5-3=2`，`first[2]=2`，得 `pre[5]-pre[2]=13-2=11`，即答案。

```python
n = len(nums)
pre = [0] * (n + 1)
for i, x in enumerate(nums):
    pre[i + 1] = pre[i] + x
first = {}
ans = 0
for r, x in enumerate(nums):
    for v in (x - k, x + k):
        if v in first:
            ans = max(ans, pre[r + 1] - pre[first[v]])
    if x not in first:
        first[x] = r
```

## 复杂度
时间：O(n)，每个元素只做两次哈希查询。
空间：O(n)，`pre` 数组和 `first` 哈希表各占 n。

## 易错点
- 全负数输入如 `[-1,-2,-3,-4], k=2` → 若把 `ans` 初值设为 0 并只在 `ans>0` 时更新，会漏掉 `-6` → 正确做法是初值 0 但用 `max` 无条件比较，或初值设 `-inf` 最后再与 0 取大。
- 更新顺序反了 → 若先写 `first[x]=r` 再查 `x-k`，当 `k=0` 时（本题 k≥1 但换约束会踩）会匹配到自己，且本题中同一值重复出现时若覆盖成较大下标，`pre[l]` 变大导致和偏小 → 必须「先查后写、只写首次」。

## 如果面试官追问
要求输出子数组的起止下标而非和？答：`first` 里存下标即可，命中时记录 `(first[v], r)`，同样 O(n)。
