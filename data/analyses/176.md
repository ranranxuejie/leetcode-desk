## 一句话思路
对 salary 去重后降序取第 2 个，用 `LIMIT 1 OFFSET 1` 配合外层 `SELECT` 把空结果转成 `null`。

## 怎么做
1. 先 `DISTINCT` 去重，否则 `[100,100,200]` 里第二高会被算成 100。
2. 降序排序后跳过第 1 行，取第 2 行。
3. 把子查询包进外层 `SELECT`，这样无第二高时子查询返回空集，外层得到 `null` 而不是 0 行。

以示例 1 为例：去重降序后是 `[300, 200, 100]`，`OFFSET 1` 跳过 300，取到 `200`，作为 `SecondHighestSalary` 返回。示例 2 去重后只有 `[100]`，`OFFSET 1` 无行可取，子查询为空，外层 `SELECT` 输出 `null`。

```python
# SQL 写法（力扣数据库题提交 SQL）
SELECT (
    SELECT DISTINCT salary
    FROM Employee
    ORDER BY salary DESC
    LIMIT 1 OFFSET 1
) AS SecondHighestSalary;
```

```python
# Pandas 写法
s = employee['salary'].drop_duplicates().sort_values(ascending=False)
return None if len(s) < 2 else int(s.iloc[1])
```

关键点：`drop_duplicates()` 必须在 `sort_values` 之前或之后都行，但一定要在取 `iloc[1]` 之前；`len(s) < 2` 的判断负责把「只有一种薪水」映射成 `None`。

## 复杂度
时间：O(n log n)，n 为 Employee 行数，排序贡献 log n。
空间：O(n)，去重后的薪水集合。

## 易错点
- 输入 `[100, 100, 200]` → 不去重直接 `ORDER BY salary DESC LIMIT 1 OFFSET 1` 会返回 100 → 正确做法是先 `DISTINCT salary` 再排序取偏移 1。
- 输入只有 `[100]`（示例 2）→ 只写子查询 `SELECT DISTINCT salary ... LIMIT 1 OFFSET 1` 会返回 0 行，力扣判为错误而非 `null` → 必须套一层外层 `SELECT (...)`，让空集变成标量 `null`。

## 如果面试官追问
问：如果要求返回第二高薪水的 id 而不只是值？
答：先 `DISTINCT salary` 降序取偏移 1 得到目标值，再回表 `WHERE salary = 目标值` 取 id，注意同薪水多人时需说明取哪一个。
