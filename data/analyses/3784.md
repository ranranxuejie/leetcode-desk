## 一句话思路
枚举最终保留的字符 c（26 种），答案 = 总代价 − 该字符所有 cost 之和的最大值。

## 怎么做
1. 先求 `total = sum(cost)`，因为删掉「非 c」的字符代价 = 总代价 − 保留的 c 字符代价。
2. 用哈希表 `keep[c]` 累加每个字符的 cost 之和，遍历 `zip(s, cost)` 一次完成。
3. 答案取 `total - max(keep.values())`，即保留代价最大的那种字符。

以示例 1 `s = "aabaac", cost = [1,2,3,4,1,10]` 为例：`total = 21`；`keep['a'] = 1+2+4+1 = 8`，`keep['b'] = 3`，`keep['c'] = 10`；`max = 10`，答案 `21 - 10 = 11`，与官方一致。

```python
total = sum(cost)
keep = {}
for ch, c in zip(s, cost):
    keep[ch] = keep.get(ch, 0) + c
return total - max(keep.values())
```

注意 `keep` 一定非空（n ≥ 1），`max` 不会报错；返回值用 Python int 即可，无需考虑溢出。

## 复杂度
时间 O(n)：一次遍历累加 `keep`，26 个键取 max 是常数。
空间 O(1)：`keep` 最多 26 个键，与 n 无关。

## 易错点
- 输入 `s = "zzzzz"`：若误写成「删除所有字符再选一个」，会算出 67 而非 0；正确做法是保留全部 z，`total - keep['z'] = 335 - 335 = 0`。
- 输入 `s = "abc", cost = [10,5,8]`：若按「保留出现次数最多的字符」选 a，会得 13 但理由错；本题按代价而非频次，`keep` 里 a=10、b=5、c=8，必须取代价最大的 a，答案 13。

## 如果面试官追问
若要求输出具体删除方案？答：记录 `best = max(keep, key=keep.get)`，再扫一遍 `s`，凡 `s[i] != best` 的索引 i 即为删除位置。
