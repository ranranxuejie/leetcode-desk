## 一句话思路
用有序列表存已订区间，每次 `book` 二分找插入点，只检查左右相邻两个区间是否重叠。

## 怎么做
1. 维护 `self.intervals`，按 `start` 升序存放已接受的 `(start, end)`。
2. 用 `bisect_left` 找第一个 `start >= startTime` 的位置 `i`。
3. 只需检查 `i-1`（左邻）和 `i`（右邻）：左邻冲突当且仅当 `intervals[i-1][1] > startTime`，右邻冲突当且仅当 `endTime > intervals[i][0]`。
4. 都不冲突则 `insert(i, (startTime, endTime))` 返回 `True`，否则返回 `False` 且不插入。

以官方示例为例：已存 `[(10,20)]`，`book(15,25)` 时 `i=1`，左邻 `intervals[0][1]=20 > 15`，冲突返回 `False`；`book(20,30)` 时 `i=1`，左邻 `20 > 20` 为假、右邻不存在，插入得 `[(10,20),(20,30)]`，返回 `True`。

```python
import bisect

def book(self, startTime, endTime):
    i = bisect.bisect_left(self.intervals, (startTime, endTime))
    if i > 0 and self.intervals[i-1][1] > startTime:
        return False
    if i < len(self.intervals) and endTime > self.intervals[i][0]:
        return False
    self.intervals.insert(i, (startTime, endTime))
    return True
```

关键点：半开区间下 `20 > 20` 为假，所以 `[10,20)` 与 `[20,30)` 不冲突，边界必须用严格大于。

## 复杂度
时间：每次 `book` 二分 O(log n)，`insert` 挪动 O(n)，n 为已接受区间数。
空间：`intervals` 存 n 个二元组，O(n) 额外空间。

## 易错点
- 输入 `book(20,30)` 接在 `[10,20)` 后 → 若把左邻判断写成 `>=` 会误判冲突返回 `False` → 半开区间必须用 `intervals[i-1][1] > startTime`。
- 输入 `book(5,10)` 插到最前（`i=0`）→ 若漏判 `i>0` 直接取 `intervals[-1]` 会拿最后一个区间当左邻 → 先判 `i > 0` 再访问 `i-1`。

## 如果面试官追问
若 `book` 调用到 10^5 次、区间数上万，`insert` 的 O(n) 挪动成瓶颈怎么办？
答：换有序集合（如跳表）或线段树，把插入也降到 O(log n)。
