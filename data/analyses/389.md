## 一句话思路
把 s 和 t 所有字符的 ASCII 码异或起来，成对出现的抵消，剩下的就是多出来的那个字符。

## 怎么做
1. 初始化 `ans = 0`，先遍历 `s`，把每个字符的 `ord(c)` 异或进 `ans`。
2. 再遍历 `t`，同样把 `ord(c)` 异或进 `ans`。
3. 遍历结束后 `ans` 就是那个只出现一次的字符的 ASCII 码，用 `chr(ans)` 转回字符返回。

以 `s = "abcd", t = "abcde"` 为例：`ans` 依次吸收 `a,b,c,d` 再吸收 `a,b,c,d,e`，前 8 个字符两两抵消，`ans` 最终停在 `ord('e') = 101`，`chr(101)` 得到 `"e"`。示例 2 中 `s` 为空，`ans` 只吸收 `ord('y') = 121`，直接返回 `"y"`。

```python
ans = 0
for c in s:
    ans ^= ord(c)
for c in t:
    ans ^= ord(c)
return chr(ans)
```

也可以把两个循环合成一个 `zip`，但 `t` 比 `s` 长一位，得单独补最后那个字符，反而更绕，不如两段循环直白。

另一种等价写法是求和相减：`chr(sum(map(ord, t)) - sum(map(ord, s)))`。它同样成立，因为 t 只比 s 多一个字符，差值恰好是那个字符的码值。但异或版不依赖「差值不溢出」这个隐含前提，面试时更稳。

## 复杂度
时间 O(n)：n 为 `len(t)`，两个循环合计扫过 `2n-1` 个字符。
空间 O(1)：只开了一个整数 `ans`，没有额外数组或哈希表。

## 易错点
- `s = ""` 时若先写 `for i in range(len(s))` 再在循环里同时取 `t[i]`，循环体一次都不执行，`ans` 停在 0，返回 `chr(0)` 而不是 `"y"`。正确做法是两段独立循环，或对 `t` 单独补最后一位。
- 用求和相减时把 `ord` 漏在某一侧，比如写成 `sum(map(ord, t)) - len(s)`，`"abcd"/"abcde"` 会算出 `101 - 4 = 97`，返回 `"a"` 而非 `"e"`。两侧必须都转成码值再相减。

## 如果面试官追问
追问：如果 t 是在 s 基础上添加了**两个**不同字母，怎么找？
答：异或会剩下两个码值的异或结果，按最低位的 1 把字符分成两组再各异或一次，即可拆出这两个字符。
