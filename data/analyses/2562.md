## 一句话思路
双指针从两端向中间夹，每轮把 `nums[i]` 与 `nums[j]` 拼成新数累加，指针相遇即止。

## 怎么做
1. 设 `i = 0`、`j = len(nums) - 1`、`ans = 0`，循环条件 `i < j`。
2. 每轮用 `nums[j]` 的位数 `len(str(nums[j]))` 算出拼接值 `nums[i] * 10**d + nums[j]`，累加进 `ans`。
3. 累加后 `i += 1`、`j -= 1`，两端各删一个。
4. 循环结束后若 `i == j`（奇数长度），把剩下的 `nums[i]` 直接加到 `ans`。

以 `nums = [7,52,2,4]` 为例：第一轮 `i=0, j=3`，`nums[j]=4` 位数 `d=1`，拼接值 `7 * 10 + 4 = 74`，`ans=74`；第二轮 `i=1, j=2`，`nums[j]=2` 位数 `d=1`，拼接值 `52 * 10 + 2 = 522`，`ans=596`，此时 `i=2 > j=1` 退出。

```python
i, j, ans = 0, len(nums) - 1, 0
while i < j:
    d = len(str(nums[j]))
    ans += nums[i] * 10 ** d + nums[j]
    i += 1
    j -= 1
if i == j:
    ans += nums[i]
```

关键点：`d` 必须取**右端** `nums[j]` 的位数，因为左数要整体左移让位给右数；取成 `nums[i]` 的位数，示例 1 第一轮会算成 `7 * 10 + 4` 恰好对、第二轮 `52 * 10 + 2` 也恰好对，但 `nums = [1, 100]` 就会错成 `1 * 10 + 100 = 110`，正确是 `1100`。

## 复杂度
时间：O(n)，双指针每轮消掉两个元素，共 n/2 轮，每轮 `str` 转换 O(log nums[j])。
空间：O(1)，只开了 `i`、`j`、`ans`、`d` 四个变量，没有额外数组。

## 易错点
- 奇数长度数组如 `nums = [5,14,13,8,12]` → 若循环写成 `while i <= j` 并在循环内无条件取 `nums[j]`，最后一轮 `i == j == 2` 会把 `13` 和它自己拼成 `1313` → 正确做法是循环条件用 `i < j`，循环外单独判 `i == j` 再加 `nums[i]`。
- 位数取错端：`nums = [1, 100]` → 用 `len(str(nums[i]))` 得 `d=1`，算出 `1 * 10 + 100 = 110` → 正确做法是 `d = len(str(nums[j]))`，得 `1 * 1000 + 100 = 1100`。

## 如果面试官追问
问：`nums[i]` 上限提到 `10**9`、长度到 `10**5`，还这么写吗？
答：思路不变，`10**d` 换成循环除 10 数位数，避免 `str` 开销；Python 整数无溢出，答案按 32 位截断时再取模。
