## 一句话思路
把 k 质因数分解，每个质因子的指数用「隔板法」独立分配到 n 个位置，各质因子方案数相乘。

## 怎么做
1. 对每个查询的 k 做质因数分解，得到指数列表 `exps`（k=1 时为空）。
2. 单个质因子指数 e 分给 n 个位置，方案数是 C(e+n-1, n-1)，即隔板法。
3. 各质因子互相独立，答案 = 所有 C(e+n-1, n-1) 的乘积 mod 1e9+7。
4. 预处理阶乘和逆阶乘到足够大（最大 e+n-1，e ≤ log2(1e4)≈13，n ≤ 1e4，取 1e4+20 即可）。

以 `[2,6]` 为例：6=2¹·3¹，exps=[1,1]。对 e=1,n=2：C(1+2-1,1)=C(2,1)=2；两个质因子各贡献 2，答案 2×2=4。

```python
MOD = 10**9 + 7
def ways(n, k):
    ans = 1
    d = 2
    while d * d <= k:
        if k % d == 0:
            e = 0
            while k % d == 0:
                k //= d; e += 1
            ans = ans * C(e + n - 1, n - 1) % MOD
        d += 1
    if k > 1:
        ans = ans * C(1 + n - 1, n - 1) % MOD
    return ans
```

## 复杂度
时间：每个查询 O(√k + 质因子个数)，预处理 O(M)，M 为阶乘上界。
空间：阶乘与逆阶乘两个数组 O(M)，M≈1e4。

## 易错点
- k=1 时质因数分解循环不进入、`k>1` 也不成立，若忘记直接返回 1 会漏掉 `[5,1]` 这类查询，正确做法是 exps 为空时 ans 保持初值 1。
- 分解循环写成 `while d*d <= k` 且中途 `k //= d`，若用原始 k 判断上界会多跑；且最后残留的 `k>1` 必须单独按指数 1 处理，否则 `[2,6]` 会少乘一个 2 得 2 而非 4。

## 如果面试官追问
若 k 放大到 1e9 且查询很多，怎么优化？
答：先用线性筛预处理到 √(max k) 的素数表，分解时只试素数，单次从 O(√k) 降到 O(π(√k))。
