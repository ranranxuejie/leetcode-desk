## 一句话思路
逐字符扫描并维护一个 `in_block` 布尔状态，遇到 `//` 或 `/*` 就切换跳过模式，其余字符照常拼接。

## 怎么做
1. 用一个 `buf` 累积当前行输出，`in_block` 标记是否在块注释内，逐行逐字符扫描。
2. 在块注释内只找 `*/`，找到就 `in_block = False` 并跳过这两个字符；否则整段丢弃。
3. 不在块注释内时，遇到 `//` 直接 `break` 结束本行；遇到 `/*` 置 `in_block = True` 并跳过两字符。
4. 每行结束若 `buf` 非空就加入答案。

以示例 2 的 `["a/*comment", "line", "more_comment*/b"]` 为例：第 1 行扫到 `a` 后 `buf="a"`，遇 `/*` 置 `in_block=True`，剩余 `comment` 全丢；第 2 行整行在块注释内，`buf` 保持 `"a"`；第 3 行扫到 `*/` 时 `in_block` 变回 `False`，接着拼 `b`，`buf="ab"`，输出 `["ab"]`——注意换行符被块注释吞掉，所以三行合成一行。

```python
res, buf, in_block = [], [], False
for line in source:
    i = 0
    while i < len(line):
        if in_block:
            if line[i:i+2] == '*/':
                in_block = False; i += 2
            else:
                i += 1
        elif line[i:i+2] == '//':
            break
        elif line[i:i+2] == '/*':
            in_block = True; i += 2
        else:
            buf.append(line[i]); i += 1
    if buf:
        res.append(''.join(buf)); buf = []
return res
```

## 复杂度
时间 O(n)：n 为所有行字符总数，每个字符最多被看两次。
空间 O(n)：`buf` 和 `res` 存的是去掉注释后的字符，最坏等于原长。

## 易错点
- 输入 `["a/*b*/c"]` → 若用 `line.find('*/')` 一次性截断，会漏掉 `*/` 之后的 `c` → 正确做法是找到 `*/` 后 `i += 2` 继续扫，不能 `break`。
- 输入 `["/*/"]` 后接 `["x*/y"]` → 若把 `/*/` 里的 `*/` 当成闭合，会提前退出块注释 → 正确做法是遇 `/*` 时 `i += 2` 跳过，从 `/` 之后继续找，`/*/` 不闭合。

## 如果面试官追问
问：如果要求保留块注释删除处的换行符怎么办？
答：在 `in_block` 为真且行结束时往 `buf` 追加 `'\n'`，其余逻辑不变。
