## 一句话思路
排序后贪心：第 i 组取 i 个最小元素，只要前 i 组总人数不超过 n 就能凑出 i 组，答案就是满足 i(i+1)/2 ≤ n 的最大 i。

## 怎么做
1. 先对 `grades` 排序，因为组内元素可以任意挑选，排序后「取最小的若干个」不会让任何一组的总成绩变大。
2. 关键观察：组大小必须严格递增，所以最少需要 1+2+...+k = k(k+1)/2 个学生才能分出 k 组；只要人数够，成绩条件总能靠「大组配大分数」满足。
3. 因此答案只和 n 有关，与具体成绩无关，直接解不等式 k(k+1)/2 ≤ n。
4. 用 while 递增 k 或整数开方，返回最大 k。

以 `grades = [10,6,12,7,3,5]`，n=6 为例：k=1 需 1 人，k=2 需 3 人，k=3 需 6 人，k=4 需 10 人 > 6，所以答案是 3。中间变量就是累计需求 `need = k*(k+1)//2`，k=3 时 need=6 恰好等于 n，k=4 时 need=10 超了。

```python
grades.sort()
n = len(grades)
k = 0
while (k + 1) * (k + 2) // 2 <= n:
    k += 1
return k
```

注意：排序其实对答案没影响，因为答案只依赖 n；但保留排序能说明「成绩条件不构成额外约束」这一直觉，面试时讲清楚即可。

## 复杂度
时间：排序 O(n log n)，n 为 grades 长度，循环 O(√n) 可忽略。
空间：排序额外 O(log n) 栈空间（TimSort），其余 O(1)。

## 易错点
1. 输入 `grades = [8,8]`，n=2 → 若误以为要按成绩分组、两组人数相等不合法就返回 1 是对的，但若写成「每组至少 1 人且人数递增」却用 `k*(k+1)//2 < n` 会得 1，正确是 `≤ n` 得 1，边界要写对。更典型的坑是 n=3 时误判：`[1,2,3]` 应返回 2（1 人组 + 2 人组），若用 `<` 会错成 1。
2. 输入 n=10^5 时，若用浮点 `int((2*n)**0.5)` 开方再修正，可能因精度差 1 导致 k 偏小；正确做法是用整数 while 循环或 `math.isqrt(2*n)` 后再校验 `k*(k+1)//2 <= n`。

## 如果面试官追问
问：如果要求输出具体分组方案怎么办？
答：排序后从大到小分配，第 i 组（从 1 开始）取当前剩余最大的 i 个元素，保证组总成绩随组号递增。
