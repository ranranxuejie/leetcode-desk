## 一句话思路
把区间和转成前缀和之差，用归并排序统计满足 `lower ≤ P[j] - P[i] ≤ upper` 的逆序对式配对。

## 怎么做
1. 构造前缀和 `P = [0, -2, 3, 2]`（`P[0]=0`，`P[k]=nums[0..k-1]` 之和），区间和 `S(i,j) = P[j+1] - P[i]`。
2. 对 `P` 做归并排序，在合并前用双指针统计跨左右两半的合法配对数。
3. 对左半每个 `P[i]`，在右半找 `P[j]` 落在 `[P[i]+lower, P[i]+upper]` 的个数，两个指针都单调右移。

以示例 1 为例，`P = [0,-2,3,2]`，`lower=-2, upper=2`。归并到 `[-2,0]` 与 `[2,3]` 合并时：`i` 指向 `-2`，右半合法区间是 `[-4,0]`，只有 `2` 不满足、无配对；`i` 指向 `0` 时区间 `[-2,2]`，右半 `2` 落入，计数 +1。最终累计 3。

```python
def merge_count(P, lo, hi, lower, upper):
    if hi - lo <= 1:
        return 0
    mid = (lo + hi) // 2
    cnt = merge_count(P, lo, mid, lower, upper) + merge_count(P, mid, hi, lower, upper)
    l = r = mid
    for i in range(lo, mid):
        while l < hi and P[l] - P[i] < lower:
            l += 1
        while r < hi and P[r] - P[i] <= upper:
            r += 1
        cnt += r - l
    P[lo:hi] = sorted(P[lo:hi])
    return cnt
```

注意 `l`、`r` 在 `i` 递增时只前进不回退，因为 `P[i]` 递增使下界 `P[i]+lower` 递增。

## 复杂度
时间：归并 `O(n log n)`，每层双指针扫 `O(n)`，共 `log n` 层。
空间：递归栈 `O(log n)`，切片排序临时数组最坏 `O(n)`。

## 易错点
- `nums = [0]`、`lower=upper=0`：若前缀和只放 `nums` 不放前导 `0`，会漏掉 `[0,0]` 这个区间，答案错成 0；正确做法是 `P` 长度 `n+1` 且 `P[0]=0`。
- 双指针边界写成 `P[l]-P[i] <= lower` 或 `P[r]-P[i] < upper`：示例 1 中 `P[i]=0` 时 `2-0=2` 恰等于 `upper`，用 `<` 会漏计这个配对，答案错成 2；正确做法是左指针用 `< lower`、右指针用 `<= upper`。

## 如果面试官追问
问：`nums` 长度到 `10^5` 且要求输出所有合法区间？答：归并只能计数，需改用树状数组按前缀和值域离散化后逐点查询区间内个数，再回填具体下标。
