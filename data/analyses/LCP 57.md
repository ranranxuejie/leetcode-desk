## 一句话思路
按时间排序后做 DP：`dp[i]` 表示敲中第 i 只地鼠时的最大敲击数，转移只需检查曼哈顿距离不超过时间差的前驱。

## 怎么做
1. 把 `moles` 按 `t` 升序排序，得到 `moles[i] = [t, x, y]`。
2. 初始化 `dp[i] = 1`，若从起点 `(1,1)` 在 `t` 秒内可达（`abs(x-1)+abs(y-1) <= t`），说明第 i 只可作首只。
3. 对每个 i，枚举 j < i，若 `abs(xi-xj)+abs(yi-yj) <= ti-tj`，则 `dp[i] = max(dp[i], dp[j]+1)`。
4. 答案是 `max(dp)`，空则 0。

以示例 1 `[[1,1,0],[2,0,1],[4,2,2]]` 为例：排序后不变。`dp[0]`：起点到 (1,0) 距离 1 ≤ 1，可敲，`dp[0]=1`。`dp[1]`：起点到 (0,1) 距离 1 ≤ 2，可敲；再看 j=0，距离 `|0-1|+|1-0|=2`，时间差 `2-1=1`，2 > 1 不可达，故 `dp[1]=1`。`dp[2]`：起点到 (2,2) 距离 2 ≤ 4，可敲；j=0 距离 `|2-1|+|2-0|=3`，时间差 3，可达，`dp[2]=2`；j=1 距离 `|2-0|+|2-1|=3`，时间差 2，不可达。最终 `max(dp)=2`。

```python
moles.sort()
n = len(moles)
dp = [1] * n
ans = 0
for i, (ti, xi, yi) in enumerate(moles):
    if abs(xi - 1) + abs(yi - 1) > ti:
        dp[i] = 0
    for j in range(i):
        tj, xj, yj = moles[j]
        if dp[j] and abs(xi - xj) + abs(yi - yj) <= ti - tj:
            dp[i] = max(dp[i], dp[j] + 1)
    ans = max(ans, dp[i])
return ans
```

## 复杂度
时间 O(n²)：n 为 `moles.length`，双重循环枚举前驱对。
空间 O(n)：`dp` 数组，排序原地。

## 易错点
- 输入 `[[0,1,0],[0,0,1]]` → 若把起点可达判断写成 `<= t` 却漏了 t=0 时距离必须为 0，会错答 2 → 正确做法是 `abs(x-1)+abs(y-1) <= t`，t=0 时只有 (1,1) 可达，答案为 0。
- 输入 `[[1,1,0],[2,0,1]]` → 若忘记按时间排序，j 可能时间更晚，`ti-tj` 为负导致误判可达 → 必须先 `moles.sort()` 保证 `ti >= tj`。

## 如果面试官追问
若 n 扩大到 10^6 怎么办？答：3×3 只有 9 个格子，按 (时间, 格子) 做状态压缩，用每格最近可达时间维护，可降到 O(n·9)。
