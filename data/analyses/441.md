## 一句话思路
二分查找最大的 k 使 k(k+1)/2 ≤ n，因为前缀和随 k 单调递增。

## 怎么做
1. 把问题转成求最大 k 满足 `k*(k+1)//2 <= n`，答案范围是 `[0, n]`。
2. 用 `lo, hi = 0, n` 做闭区间二分，`mid = (lo + hi + 1) // 2` 取上中位，避免死循环。
3. 若 `mid*(mid+1)//2 <= n` 则 `lo = mid`，否则 `hi = mid - 1`。
4. 循环结束 `lo` 即答案。

以 `n = 8` 为例：初始 `lo=0, hi=8`，`mid=4`，`4*5//2=10 > 8`，故 `hi=3`；再 `mid=2`，`2*3//2=3 <= 8`，`lo=2`；再 `mid=3`，`3*4//2=6 <= 8`，`lo=3`；`lo==hi` 结束，返回 3。关键中间值就是 `mid=4` 时算出的 10，它超过 8 直接把上界砍到 3。

```python
lo, hi = 0, n
while lo < hi:
    mid = (lo + hi + 1) // 2
    if mid * (mid + 1) // 2 <= n:
        lo = mid
    else:
        hi = mid - 1
return lo
```

注意 `mid` 用上中位：若写 `(lo+hi)//2`，当 `lo=2, hi=3` 时 `mid=2` 恒满足条件，`lo` 停在 2 不动，死循环。

## 复杂度
时间：O(log n)，二分每次把区间折半，n 是硬币数。
空间：O(1)，只开 `lo`、`hi`、`mid` 三个整数。

## 易错点
- 输入 `n = 1` → 若把 `hi` 初始化成 `n-1` 或循环条件写成 `lo <= hi` 配 `lo = mid + 1`，会返回 0 或越界 → 正确做法是 `hi = n`、闭区间 `lo < hi`、满足时 `lo = mid`。
- 输入 `n = 2**31 - 1` → 若用 `(lo+hi)//2` 取中位，`lo=2, hi=3` 这类相邻区间会卡死 → 正确做法是 `(lo + hi + 1) // 2` 取上中位，保证满足条件时区间仍收缩。

## 如果面试官追问
问：n 到 10^18 还能二分吗？答：能，Python 大整数无溢出，`mid*(mid+1)//2` 直接算，仍是 O(log n)。
