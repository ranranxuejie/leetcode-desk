## 一句话思路
按 nums 值排序后，相邻差 ≤ maxDiff 的节点连成连通块；块内最短距离等于排序后下标之差。

## 怎么做
1. 把节点按 nums 值排序，得到 `order` 和 `pos`（原下标 → 排序后下标）。
2. 扫描排序后数组，相邻差 > maxDiff 处断开，记录每个排序后位置所属的连通块编号 `comp`。
3. 查询 `[u, v]`：`comp[pos[u]] != comp[pos[v]]` 返回 -1；否则返回 `abs(pos[u] - pos[v])`。

以示例 2 为例：`nums = [5,3,1,9,10]`，排序后 `order = [2,1,0,3,4]`，值 `[1,3,5,9,10]`。相邻差 2,2,4,1，maxDiff=2，第 3 处断开，得到块 `{2,1,0}` 和 `{3,4}`。查询 `[0,2]`：`pos[0]=2, pos[2]=0`，同块，答案 `|2-0|=2`，与输出一致。

```python
order = sorted(range(n), key=lambda i: nums[i])
pos = [0] * n
for k, i in enumerate(order):
    pos[i] = k
comp = [0] * n
for k in range(1, n):
    comp[k] = comp[k - 1] + (nums[order[k]] - nums[order[k - 1]] > maxDiff)
ans = []
for u, v in queries:
    if comp[pos[u]] != comp[pos[v]]:
        ans.append(-1)
    else:
        ans.append(abs(pos[u] - pos[v]))
```

关键点：块内任意两节点直接相邻（值差 ≤ maxDiff），所以距离恒为 1 或 0；跨块则必不相邻，且中间断点无法跨越。

## 复杂度
时间：排序 O(n log n)，扫描与查询各 O(n + q)，总 O(n log n + q)。
空间：`order`/`pos`/`comp` 各 O(n)，额外 O(n)。

## 易错点
- 查询 `[u, u]`（如示例 3 的 `[0,0]`）→ 若先判 `u == v` 返回 1 就错 → 同块时 `abs(pos[u]-pos[v]) = 0`，自然得 0，不要特判成 1。
- 用原下标差当距离 → 示例 1 中 `[0,3]` 原下标差 3，但 `nums[0]=1, nums[3]=4` 差 3 ≤ maxDiff 直接相邻，答案应为 1 → 必须用排序后位置差。
- 断开条件写成 `>=` → 示例 2 中差恰为 2 的相邻对会被误断，`[0,1]` 错成 -1 → 严格用 `> maxDiff`。

## 如果面试官追问
若要求输出具体路径而非距离？答：块内直接 `u → v` 一步可达，跨块无路径，路径要么长度 1 要么不存在，无需 BFS。
