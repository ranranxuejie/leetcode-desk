## 一句话思路
贪心：每段都取到「从当前下标起能凑齐 0..x-1 的最短前缀」，使该段 MEX 最大，再递归处理剩余后缀。

## 怎么做
1. 设当前起点 `i`，从 `i` 开始向后扫，用集合 `seen` 记录出现过的值，同时维护 `mex`（初始 0，`seen` 含 `mex` 就 `mex += 1`）。
2. 一旦 `seen` 覆盖了 `0..mex-1`，即 `mex` 是当前前缀的 MEX，就立刻截断——因为再往后扫只会让 MEX 不变或变大，但会浪费元素给后面的段。
3. 把 `mex` 追加到 `result`，`i` 跳到截断点之后，重复直到 `i == len(nums)`。
4. 关键点：截断位置取「第一次凑齐 `0..mex-1`」的下标，不是最远位置。

以 `nums = [0,1,0]` 为例：`i=0`，扫到 `0` 时 `seen={0}`、`mex=1`，此时 `0..0` 已齐，截断，`result=[1]`？——不对，注意 `mex` 的定义是「最小缺失值」，扫到 `0` 后 `seen={0}`，`mex` 应为 1，但 `0..mex-1 = {0}` 已齐，说明前缀 `[0]` 的 MEX 是 1。可示例给的是 `[2,1]`，说明要取到 `[0,1]` 才得 MEX=2。所以正确判据是：**继续扫直到 `mex` 不再增长的那一刻**，即扫到 `1` 后 `seen={0,1}`、`mex=2`，`0..1` 齐，截断得 2。剩余 `[0]` 得 1，输出 `[2,1]`。

```python
res, i, n = [], 0, len(nums)
while i < n:
    seen, mex = set(), 0
    while i < n:
        seen.add(nums[i]); i += 1
        while mex in seen: mex += 1
        if mex not in seen: break   # 0..mex-1 已齐
    res.append(mex)
```

## 复杂度
时间 O(n)：每个元素只被外层指针 `i` 扫过一次，`mex` 单调递增不回退。
空间 O(n)：`seen` 集合最多存一段内的不同值，最坏整段。

## 易错点
- 输入 `[0,1,0]` → 若在扫到第一个 `0` 就截断，得 `[1,0,0]`，字典序小于 `[2,1]` → 正确做法是扫到 `mex` 不再增长（凑齐 `0..mex-1`）才截断。
- 输入 `[3,1]` → 若误以为「没有 0 就整段 MEX=0 一次截完」，会得 `[0]`，但正确答案是 `[0,0]`，更长者字典序更大 → 每段至少消耗一个元素，`k>=1`，不能空段。

## 如果面试官追问
问：要求返回所有字典序最大的方案之一而非唯一？答：截断点唯一（首次凑齐处），方案本就唯一，无需回溯。
