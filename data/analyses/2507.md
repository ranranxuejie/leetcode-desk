## 一句话思路
反复用试除法把 n 拆成质因数并求和，直到和不再变小；因为质因数之和总小于等于原数（合数严格小于），过程必然收敛到质数。

## 怎么做
1. 写一个 `factor_sum(x)`：从 `d = 2` 试到 `d * d <= x`，能整除就把 `d` 累加进 `s` 并令 `x //= d`，除不动才 `d += 1`；循环结束后若 `x > 1` 说明剩下的是质数，也加进 `s`。
2. 主循环：`while True`，算 `s = factor_sum(n)`，若 `s == n` 就返回 `n`，否则 `n = s`。
3. 用 n = 15 走一遍：`factor_sum(15)` 中 d=2 除不动，d=3 整除一次得 s=3、x=5，d 增到 4 时 `4*4>5` 退出，补加 x=5，s=8；接着 `factor_sum(8)` 连续三次 d=2，s=6；`factor_sum(6)` 得 2+3=5；`factor_sum(5)` 循环不进入、补加 5，s=5 等于 n，返回 5。
4. 终止性靠单调性：合数 x 的质因数之和严格小于 x（最小是 2+2=4<4 不成立，但 4→4 已是 2+2=4 的等号情形，实际 4 的质因数和为 4，直接停），所以每轮要么不变要么严格下降，不会死循环。

```python
def factor_sum(x):
    s, d = 0, 2
    while d * d <= x:
        while x % d == 0:
            s += d
            x //= d
        d += 1
    if x > 1:
        s += x
    return s

n = 15
while True:
    s = factor_sum(n)
    if s == n:
        break
    n = s
```

## 复杂度
时间：每轮试除 O(sqrt(n))，轮数极少（n ≤ 10^5 时通常 2~3 轮），总 O(sqrt(n))。
空间：只用了 `s`、`d`、`x` 三个整型变量，O(1)。

## 易错点
- 输入 n = 4 → 若把「质因数之和严格小于 n」当终止条件，会误判 4 应继续拆；实际 `factor_sum(4) = 2 + 2 = 4` 等于自身，正确做法是用 `s == n` 判停并返回 4。
- 输入 n = 2 或 n = 3 → 若试除循环写成 `while d * d < x` 且漏掉末尾 `if x > 1: s += x`，会返回 0；正确做法是循环条件用 `<=` 之外，必须补加剩余的大于 1 的 x。

## 如果面试官追问
若 n 放大到 10^12，单次分解还够快吗？答：单轮 O(sqrt(n)) 到 10^6 尚可，但需预筛小质数或改用 Pollard-Rho，且轮数依旧很少。
