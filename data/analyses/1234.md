## 一句话思路
窗口外的字符计数若都不超过 n/4，则窗口内字符可补齐缺口，用滑动窗口找最短这样的窗口。

## 怎么做
1. 先统计全串每个字符出现次数 `cnt`，目标 `target = n // 4`。
2. 用左右指针维护窗口 `[l, r)`，窗口内字符从 `cnt` 中扣除，表示「被替换掉」。
3. 当窗口外所有字符计数都 `<= target` 时，窗口合法，记录长度并收缩左边界。
4. 否则扩张右边界。

以 `s = "QQQW"`，n=4，target=1 为例：初始 `cnt = {Q:3, W:1, E:0, R:0}`。窗口 `[0,2)` 含 "QQ"，窗口外 `cnt` 变为 `{Q:1, W:1, E:0, R:0}`，全部 `<= 1`，合法，长度 2。收缩左边界后窗口外 Q 变 2，不合法，故答案为 2。

```python
from collections import Counter
n = len(s)
target = n // 4
cnt = Counter(s)
ans = n
l = 0
for r in range(n):
    cnt[s[r]] -= 1
    while max(cnt.values()) <= target:
        ans = min(ans, r - l + 1)
        cnt[s[l]] += 1
        l += 1
return ans
```

关键：`cnt` 始终表示**窗口外**的字符计数，`max(cnt.values()) <= target` 即窗口外无超额字符，窗口内可自由替换补齐。

## 复杂度
时间 O(n)：左右指针各移动至多 n 次，每次 `max` 只比较 4 个字符，视为常数。
空间 O(1)：`cnt` 只存 4 个键，无额外数组。

## 易错点
- 输入 `"QQQQ"`，n=4，target=1：若误把 `cnt` 当作窗口内计数，窗口为空时 `max=0<=1` 会返回 0，实际需替换 3 个 Q，答案 3。正确做法是 `cnt` 表示窗口外计数，初始为全串统计。
- 输入 `"QQWE"`：若在 `while` 内先记录答案再收缩，可能漏掉更短窗口；若收缩时忘记 `cnt[s[l]] += 1` 恢复左边界字符，`cnt` 会持续偏小导致窗口被误判合法，答案偏小。正确做法是收缩前先更新答案，再恢复左字符并 `l += 1`。

## 如果面试官追问
问：若字符集扩大到 26 个小写字母，`max(cnt.values())` 还够快吗？
答：仍 O(n)，只是每次比较 26 个值，可改用变量维护「超额字符个数」做到 O(1) 判断。
