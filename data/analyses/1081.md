## 一句话思路
用单调栈维护递增结果，出栈前用剩余计数判断该字符后面还会不会出现。

## 怎么做
1. 先统计 `s` 中每个字符的剩余次数 `cnt`，再用 `used` 标记字符是否已在栈中。
2. 遍历 `s`，每读一个字符先把它在 `cnt` 中的计数减 1。
3. 若 `c` 未入栈，则当栈顶字符大于 `c` 且栈顶字符在 `cnt` 中仍大于 0 时，弹出栈顶并清除其 `used` 标记。
4. 把 `c` 入栈并标记 `used`，遍历结束后栈内字符拼接即为答案。

以 `s = "cbacdcbc"` 为例，读到第二个 `c`（下标 6）时，栈为 `['a','c','d']`，`cnt['d']` 已为 0，所以 `d` 不能被弹出，`c` 直接跳过（`used['c']` 为 `True`），最终得到 `"acdb"`。

```python
cnt = [0] * 26
for ch in s:
    cnt[ord(ch) - 97] += 1
used = [False] * 26
stack = []
for ch in s:
    i = ord(ch) - 97
    cnt[i] -= 1
    if used[i]:
        continue
    while stack and stack[-1] > ch and cnt[ord(stack[-1]) - 97] > 0:
        used[ord(stack.pop()) - 97] = False
    stack.append(ch)
    used[i] = True
return ''.join(stack)
```

## 复杂度
时间 O(n)：每个字符最多入栈、出栈各一次，`n = len(s)`。
空间 O(1)：栈最多 26 个字符，`cnt`、`used` 各 26 长度。

## 易错点
- 输入 `s = "bcabc"` 时，若在弹出栈顶前不检查 `cnt[栈顶] > 0`，读到第二个 `b` 会把第一个 `b` 弹掉，但后面已无 `b`，结果缺字符；正确做法是只在栈顶字符后面还会出现时才弹。
- 输入 `s = "cbacdcbc"` 时，若忘记 `used` 判断，重复的 `c` 会被再次入栈，结果变成 `"acdbc"` 之类含重复字符的串；正确做法是 `used[i]` 为 `True` 时直接 `continue`。

## 如果面试官追问
问：若要求返回所有字典序最小的子序列（可能多个）怎么办？
答：在单调栈基础上记录每个位置的可选分支，用回溯枚举等长候选并比较，复杂度升到指数级，需按字典序剪枝。
