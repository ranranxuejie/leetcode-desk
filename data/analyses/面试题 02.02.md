## 一句话思路
快慢双指针，快指针先走 k 步，再同步走，快指针到尾时慢指针即倒数第 k 个。

## 怎么做
1. 令 `fast = slow = head`，先让 `fast` 单独前进 `k` 步。
2. 此时 `fast` 与 `slow` 相距 `k` 个节点，`slow` 正好指向倒数第 `k` 个的候选位置。
3. 两指针同步前进，直到 `fast` 为 `None`。
4. 返回 `slow.val`。

以官方示例 `1->2->3->4->5`、`k = 2` 为例：`fast` 先走 2 步落在节点 `3`，`slow` 仍在 `1`；随后同步走，`fast` 依次到 `4`、`5`、`None`，`slow` 依次到 `2`、`3`、`4`，最终 `slow.val = 4`，与输出一致。

```python
fast = slow = head
for _ in range(k):
    fast = fast.next
while fast:
    fast = fast.next
    slow = slow.next
return slow.val
```

关键中间值：循环结束时 `fast is None`，`slow` 停在值为 `4` 的节点上。注意 `for` 循环走的是 `k` 步而不是 `k-1` 步，这样 `while` 终止时 `slow` 恰好偏移 `k` 位。

## 复杂度
时间 O(n)：`fast` 走完全程 n 个节点，`slow` 走 n-k 个，合计约 n 步。
空间 O(1)：只开了 `fast`、`slow` 两个指针，没有额外容器。

## 易错点
- 输入 `1->2->3->4->5`、`k = 5`（倒数第 5 个即头节点）→ 若把先走步数写成 `k-1`，`fast` 只到 `4`，同步走完 `slow` 停在 `2`，错答 2 → 正确是先走 `k` 步，`fast` 到 `None` 时 `slow` 仍在 `1`，返回 1。
- 输入 `1->2->3->4->5`、`k = 1` → 若 `while` 条件写成 `while fast.next`，`fast` 停在 `5`，`slow` 停在 `4`，错答 4 → 正确用 `while fast`，`fast` 走到 `None`，`slow` 停在 `5`，返回 5。

## 如果面试官追问
追问：若链表长度未知且 k 可能大于长度，怎么处理？
答：先让 `fast` 走 k 步，途中若 `fast` 变 `None` 就提前返回 `None`，表示 k 越界。
