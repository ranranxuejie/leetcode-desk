## 一句话思路
把查询按 `max(a,b)` 从大到小排序，用单调栈维护「右侧第一个更高建筑」的候选，栈上二分出答案。

## 怎么做
1. 预处理：对每个 `a != b` 的查询，令 `l = min(a,b)`、`r = max(a,b)`；若 `heights[l] < heights[r]` 直接答 `r`，否则问题变成「在 `(r, n)` 中找最左的 `j` 使 `heights[j] > heights[l]`」。
2. 从右往左扫 `i`，维护一个**高度严格递减**的栈（存下标），栈内下标递增、高度递减；扫到 `i` 时先把所有 `r == i` 的查询取出。
3. 对每个待查 `l`，在栈上二分找**最靠左**（即下标最小）且 `heights[stack[k]] > heights[l]` 的位置——因为栈高度递减，满足条件的是一段后缀，二分左端点即可。
4. 取 `stack[k]` 作为答案；栈空或无解则 `-1`。

以 `heights = [6,4,8,5,2,7]`、查询 `[0,3]` 为例：`l=0, r=3`，`heights[0]=6 > heights[3]=5`，需在 `(3,6)` 找 `>6` 的。扫到 `i=3` 时栈为 `[5,4,3]`（高度 7,2,5），二分得 `k` 指向下标 5，`heights[5]=7>6`，答案 5，与官方一致。

```python
st = []                      # 下标递增、高度严格递减
for i in range(n - 1, -1, -1):
    for l in bucket[i]:      # bucket[r] 存该 r 下的 l
        lo, hi = 0, len(st)
        while lo < hi:       # 找第一个 heights[st[k]] > heights[l]
            mid = (lo + hi) // 2
            if heights[st[mid]] > heights[l]:
                hi = mid
            else:
                lo = mid + 1
        ans[idx[l]] = st[lo] if lo < len(st) else -1
    while st and heights[st[-1]] <= heights[i]:
        st.pop()
    st.append(i)
```

## 复杂度
时间：排序 `O(q log q)`，扫描加二分共 `O((n + q) log n)`。
空间：栈 `O(n)`，`bucket` 与答案数组 `O(q)`。

## 易错点
- `heights[l] == heights[r]` 时不能直接答 `r`（移动要求严格大于），必须继续往右找；写成 `<=` 会把 `[2,4]`（`heights=[6,4,8,5,2,7]`，`heights[2]=8 > heights[4]=2` 不触发，但对称情形会）判错。
- 栈弹出条件用 `<=` 而非 `<`：相等高度必须弹掉，否则栈不再严格递减，二分找到的「第一个大于」可能落在被遮挡的旧下标上，答案偏大。

## 如果面试官追问
若要求在线回答（查询逐条给出、不能离线排序）怎么办？答：改用线段树存区间最大值，每次查询在 `(r, n)` 上做「找最左大于 `heights[l]`」的线段树二分，`O(log n)` 单次。
