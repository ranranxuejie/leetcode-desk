## 一句话思路
先枚举长度 ≤15 的所有 5 的幂二进制串存进集合，再用 `dp[i]` 表示 `s[:i]` 的最少段数，从每个 `dp[j]` 往后切一段查表。

## 怎么做
1. 预处理：从 `5**0` 开始不断乘 5，把 `bin(x)[2:]` 塞进集合 `beauty`，直到长度超过 15 就停。
2. 定义 `dp = [inf] * (n+1)`，`dp[0] = 0`，表示空串不需要切。
3. 外层 `i` 从 0 到 n-1，若 `dp[i]` 可达，内层 `j` 从 `i+1` 到 n，切出 `s[i:j]` 查 `beauty`，命中就更新 `dp[j] = min(dp[j], dp[i]+1)`。
4. 返回 `dp[n]`，若仍是 `inf` 则返回 `-1`。

以 `s = "1011"` 为例：`beauty` 含 `"1"`、`"101"`、`"11001"`…。`dp[0]=0` 时切 `s[0:3]="101"` 命中，`dp[3]=1`；`i=3` 时切 `s[3:4]="1"` 命中，`dp[4]=2`，最终返回 2。

```python
beauty, x = set(), 1
while len(bin(x)) - 2 <= 15:
    beauty.add(bin(x)[2:])
    x *= 5

n = len(s)
dp = [float('inf')] * (n + 1)
dp[0] = 0
for i in range(n):
    if dp[i] == float('inf'):
        continue
    for j in range(i + 1, n + 1):
        if s[i:j] in beauty:
            dp[j] = min(dp[j], dp[i] + 1)
return dp[n] if dp[n] != float('inf') else -1
```

## 复杂度
时间：O(n²·L)，n 为串长，L 为子串比较长度，`beauty` 集合哈希后近似 O(n²)。
空间：O(n + 5 的幂个数)，`dp` 数组占 n+1，`beauty` 只存约 7 个串。

## 易错点
- 输入 `s = "0"` 或含前导 0 的段如 `"01"` → 若把 `"01"` 当成合法二进制会误判 → `beauty` 里只放 `bin(x)[2:]`，天然无前导 0，`"01"` 查不到。
- 输入 `s = "111"` → 若只枚举到 `5**1` 就漏掉 `"1"` 的多次切分 → 必须从 `5**0=1` 开始枚举，且允许同一段反复使用，`dp[1]=dp[2]=dp[3]=1` 逐层累加得 3。

## 如果面试官追问
问：若 s 长度放大到 10^5 怎么办？
答：预处理不变，但 `dp` 转移要改成对每个位置只尝试长度 ≤ log₅(2^15) 的少数候选串，用滚动哈希 O(1) 比对，降到 O(n·log)。
