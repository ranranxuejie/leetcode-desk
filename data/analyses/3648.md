## 一句话思路
行列方向独立，各需 `ceil(n/(2k+1))` 和 `ceil(m/(2k+1))` 个，相乘即答案。

## 怎么做
1. 一个传感器在行方向覆盖 `2k+1` 个连续行，所以覆盖 n 行至少需要 `(n + 2k) // (2k+1)` 个。
2. 列方向同理，需要 `(m + 2k) // (2k+1)` 个。
3. 行列的覆盖区间可以自由组合成网格状，两个数相乘即总数。

以示例 1 的 `n=5, m=5, k=1` 为例：`2k+1 = 3`，行方向 `(5+2)//3 = 2`，列方向也是 `2`，中间值 `rows=2, cols=2`，答案 `2*2 = 4`，与官方输出一致。

```python
def minSensors(n, m, k):
    span = 2 * k + 1
    rows = (n + span - 1) // span
    cols = (m + span - 1) // span
    return rows * cols
```

注意 `(n + span - 1) // span` 与 `(n + 2k) // (2k+1)` 等价，因为 `span - 1 = 2k`。

## 复杂度
时间：O(1)，只做常数次整数运算，与 n、m、k 无关。
空间：O(1)，只开 `span`、`rows`、`cols` 三个变量。

## 易错点
- `k=0` 时 → 若误用 `2*k` 当跨度会算成 `n//0` 或跨度 0 → 正确跨度是 `2*0+1 = 1`，答案应为 `n*m`，每个格子都要放传感器。
- `n=1, m=1000, k=1` 这类极扁网格 → 若只按行数或只按列数估算会漏乘 → 必须行列分别取 ceil 再相乘，此处 `rows=1, cols=334`，答案 334 而非 1。

## 如果面试官追问
问：若要求输出具体传感器坐标方案？
答：行方向取 `0, span, 2*span, ...` 作为中心行，列方向同理，笛卡尔积即一组最优解。
