## 一句话思路
用快慢指针在「同号跳转」的图上找环，找到环后排除自环（k=1），并把走过的点标记为 0 剪枝。

## 怎么做
1. 对每个起点 `i`，若 `nums[i] == 0` 跳过（已被剪枝）。
2. 设 `slow = i`、`fast = i`，循环里每轮让 `slow` 走一步、`fast` 走两步，每步都要求「方向与起点一致」。
3. 若某一步方向变了（`nums[cur] * nums[i] < 0`）或落到 `nums[cur] == 0`，说明这条路不通，退出。
4. 若 `slow == fast`，检查 `slow` 的下一步是否回到自己（`(slow + nums[slow]) % n == slow`），是则 k=1 不算，否则返回 `True`。

以 `nums = [2,-1,1,2,2]`、起点 `i=0` 为例：`slow` 走 `0→2→3→0`，`fast` 走 `0→3→0→2`，第 3 轮 `slow == fast == 0`；`(0 + 2) % 5 = 2 != 0`，k>1，返回 `True`。

```python
n = len(nums)
for i in range(n):
    if nums[i] == 0:
        continue
    slow = fast = i
    while True:
        slow = (slow + nums[slow]) % n
        fast = (fast + nums[fast]) % n
        fast = (fast + nums[fast]) % n
        if nums[slow] * nums[i] < 0 or nums[fast] * nums[i] < 0:
            break
        if slow == fast:
            if (slow + nums[slow]) % n == slow:
                break
            return True
    # 剪枝：把这条死路全标 0
    j = i
    while nums[j] * nums[i] > 0:
        nxt = (j + nums[j]) % n
        nums[j] = 0
        j = nxt
return False
```

## 复杂度
时间：每个下标最多被访问常数次，剪枝后总 O(n)。
空间：只用了 `slow/fast/j` 几个变量，O(1)。

## 易错点
- 输入 `[-1,-2,-3,-4,-5,6]`：`i=5` 时 `(5+6)%6=5` 是自环，若直接 `slow==fast` 就返回 `True` 会错成 `True`；必须先判 `(slow + nums[slow]) % n == slow` 排除 k=1。
- 输入 `[1,-1,5,1,4]`：从 `i=0` 走 `0→1→0` 会撞上 `nums[1]=-1` 方向相反，若只比 `slow==fast` 不查方向，会把这条混合方向的假环当成答案；每步都要校验 `nums[cur] * nums[i] > 0`。

## 如果面试官追问
问：不剪枝能过吗？答：能，但最坏 O(n²)，`n=5000` 时约 2500 万次跳转，剪枝后每个点只走一次才是 O(n)。
