## 一句话思路
用回溯按位置填字符，每层用 `used` 标记已选下标，并在同层用 `seen` 跳过相同字符，从而去重。

## 怎么做
1. 先对 `goods` 排序，让相同字符相邻，便于同层去重。
2. 回溯函数维护 `path`（当前排列）和 `used`（下标是否已用）。
3. 每层遍历所有下标 `i`：若 `used[i]` 为真，或 `i > 0 and goods[i] == goods[i-1] and not used[i-1]`，跳过。
4. `len(path) == len(goods)` 时把 `"".join(path)` 加入结果。

以 `goods = "agew"` 为例，排序后仍是 `"agew"`。第一层选 `a` 后 `used = [True, False, False, False]`，`path = ['a']`；第二层选 `e` 时 `path = ['a','e']`，继续递归到 `"aegw"` 入结果。关键中间值：当处理到 `"agew"` 的第三层选 `w` 时，`path = ['a','g','e']`，`used = [True, True, True, False]`，只剩下标 3 可选，直接得到 `"agew"`。

```python
def dfs(path, used):
    if len(path) == n:
        res.append("".join(path))
        return
    for i in range(n):
        if used[i]:
            continue
        if i > 0 and goods[i] == goods[i-1] and not used[i-1]:
            continue
        used[i] = True
        path.append(goods[i])
        dfs(path, used)
        path.pop()
        used[i] = False
```

去重条件 `not used[i-1]` 的含义：相同字符中前一个还没被用，说明当前分支是重复的，剪掉。

## 复杂度
时间：O(n × n!)，n 为 `goods` 长度，最坏全排列 n! 个、每个拼接 O(n)。
空间：O(n)，递归栈深度 n，`used` 与 `path` 各 O(n)，结果集不计入。

## 易错点
- 输入 `goods = "aab"` → 若只靠 `used` 不去重，会输出 `"aab"` 两次 → 必须先排序，再用 `goods[i] == goods[i-1] and not used[i-1]` 剪枝。
- 输入 `goods = "aba"` → 未排序时相同字符不相邻，`goods[i] == goods[i-1]` 判断失效，重复仍会出现 → 排序是去重前提，不能省。

## 如果面试官追问
问：若 `goods` 长度增到 12 且要求按字典序输出？答：仍用排序 + 同层去重回溯，天然按字典序生成，无需额外排序结果。
