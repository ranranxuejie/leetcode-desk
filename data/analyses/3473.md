## 一句话思路
用 `dp[j][i]` 表示前 `i` 个元素取 `j` 段的最大和，靠前缀和与「以 i 结尾的段」转移。

## 怎么做
1. 先算前缀和 `pre`，`pre[i]` 是 `nums[:i]` 的和，任意段和 `pre[r]-pre[l]`。
2. 状态 `dp[j][i]`：前 `i` 个元素选 `j` 个不重叠段的最大和，`i` 从 `j*m` 起才有意义。
3. 转移分两种：第 `i` 个元素不选，继承 `dp[j][i-1]`；或选一个以 `i-1` 结尾、长度 ≥ m 的段，起点 `s ≤ i-m`，取 `dp[j-1][s] + pre[i] - pre[s]`。
4. 把 `dp[j-1][s] - pre[s]` 对 `s` 维护成滚动最大值 `best`，边扫 `i` 边更新，省掉一层枚举。

以示例 1 `nums=[1,2,-1,3,3,4], k=2, m=2` 为例，`pre=[0,1,3,2,5,8,12]`。算 `dp[2][6]` 时，`s` 从 2 到 4，`best = max(dp[1][s]-pre[s])`；`s=2` 时 `dp[1][2]=3`（取 `[1,2]`），`3-3=0`；`s=4` 时 `dp[1][4]=3`，`3-5=-2`，故 `best=0`，`dp[2][6]=max(dp[2][5], 0+12)=13`。

```python
pre = [0]
for x in nums: pre.append(pre[-1] + x)
n = len(nums)
NEG = -10**18
dp = [[NEG]*(n+1) for _ in range(k+1)]
for i in range(n+1): dp[0][i] = 0
for j in range(1, k+1):
    best = NEG
    for i in range(j*m, n+1):
        s = i - m
        best = max(best, dp[j-1][s] - pre[s])
        dp[j][i] = max(dp[j][i-1], best + pre[i])
return dp[k][n]
```

## 复杂度
时间 `O(k*n)`：外层 `k` 段、内层扫 `n` 个位置，转移 O(1)。
空间 `O(k*n)`：`dp` 表；可压成两行降到 `O(n)`。

## 易错点
- `nums=[-10,3,-1,-2], k=4, m=1`：若把 `dp` 初值设 0 而非 `NEG`，空状态被当成合法，会错成 0 或漏掉 `-10`；必须用 `-10**18` 初始化，只有 `dp[0][*]=0`。
- `m=3` 且 `i < j*m` 时：若从 `i=0` 起扫，`s=i-m` 为负会索引到 `pre[-1]`（末尾元素），算出错误段和；循环必须从 `i=j*m` 开始，保证 `s≥(j-1)*m`。

## 如果面试官追问
问：要求输出具体选了哪 k 段怎么办？
答：`dp` 里额外存每步来源（继承还是新开段及起点 `s`），从 `dp[k][n]` 回溯即可。
