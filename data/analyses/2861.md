## 一句话思路
对答案二分：制造数 x 单调可判（x 能做则 x-1 必能做），每台机器独立算造 x 份的采购成本，取最小与 budget 比。

## 怎么做
1. 上界取 `max(stock) + budget // min(cost)`，因为最便宜金属单价至少 `min(cost)`，再多也买不起。
2. 二分 `lo=0, hi=上界`，判 `check(mid)`：对每台机器算成本，任一台 ≤ budget 即真。
3. 单台机器成本：第 j 种金属缺 `need = max(0, composition[i][j]*x - stock[j])`，累加 `need * cost[j]`。
4. 用示例 1 验证：x=2 时机器 0 三种金属各缺 2，成本 `2*1+2*2+2*3=12 ≤ 15` 为真；x=3 时成本 18 超预算，故答案 2。

```python
def check(x):
    for i in range(k):
        total = 0
        for j in range(n):
            need = composition[i][j] * x - stock[j]
            if need > 0:
                total += need * cost[j]
            if total > budget:
                break
        if total <= budget:
            return True
    return False

lo, hi = 0, max(stock) + budget // min(cost)
while lo < hi:
    mid = (lo + hi + 1) // 2
    if check(mid):
        lo = mid
    else:
        hi = mid - 1
return lo
```

## 复杂度
时间：`O(k * n * log(hi))`，k 台机器 × n 种金属 × 二分次数，hi 为上界。
空间：`O(1)`，只用了几个标量，没有额外数组。

## 易错点
1. `stock[j]` 很大时（示例 2 的 `stock[2]=100`），`composition[i][j]*x - stock[j]` 为负，若直接乘 `cost[j]` 会得到负成本、误判可行 → 必须先 `max(0, ...)` 再累加。
2. 上界若只取 `budget // min(cost)`，当 `stock` 里已有大量存货（如 `stock=[10**8,...]`）时会漏掉不花钱就能造的量 → 必须加上 `max(stock)`，否则二分区间不够、答案偏小。

## 如果面试官追问
问：如果要求返回具体用哪台机器和采购清单？
答：二分时记录使 `check(mid)` 为真的那台机器下标，最后对该下标重算每种金属的 `need` 即为采购量。
