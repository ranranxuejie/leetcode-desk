## 一句话思路
用双指针维护一段连续正整数区间，靠区间和与 target 的大小关系移动左右端点，枚举出全部解。

## 怎么做
1. 初始化 `left = 1`、`right = 2`、`cur = 3`（即 1+2），区间取 `[left, right)` 半开，至少两个文件所以从 1、2 起步。
2. 当 `cur == target` 时把 `range(left, right)` 收进答案，然后 `cur -= left; left += 1` 继续找下一组。
3. 当 `cur < target` 时右端扩张：`right += 1; cur += right`。
4. 当 `cur > target` 时左端收缩：`cur -= left; left += 1`；循环条件 `left < right`，保证区间非空。

以 `target = 12` 为例：初始 `cur = 3 < 12`，扩张到 `right = 5` 时 `cur = 1+2+3+4+5 = 15 > 12`；收缩 `left` 到 3，`cur = 15-1-2 = 12`，命中 `[3, 5)` 即 `[3,4,5]`，随后 `cur` 减 3 变 9、`left` 变 4，再收缩到 `left = 5` 时 `left < right` 不成立，结束。

```python
left, right, cur = 1, 2, 3
res = []
while left < right:
    if cur == target:
        res.append(list(range(left, right)))
        cur -= left
        left += 1
    elif cur < target:
        right += 1
        cur += right
    else:
        cur -= left
        left += 1
```

注意 `range(left, right)` 是半开区间，`right` 本身已计入 `cur`，所以切片右端不 +1。

## 复杂度
时间 O(target)：`left`、`right` 各自单调递增到约 target/2，总移动步数线性。
空间 O(1) 额外（不计答案列表），答案本身最多 O(target) 个元素。

## 易错点
- `target = 1` 或 `target = 2`：若把循环写成 `while left <= right` 且初始 `cur` 算错，会返回 `[[1]]` 这种单元素组合；题目要求至少两个文件，正确做法是保持 `left < right` 且从 `[1,2)` 起步，这两个输入直接返回 `[]`。
- `target = 9`：正确答案是 `[[2,3,4],[4,5]]`，若命中后只做 `left += 1` 而忘了 `cur -= left`（顺序写反），下一轮 `cur` 会多算一个旧 `left`，导致漏掉 `[4,5]`；正确做法是先 `cur -= left` 再 `left += 1`。

## 如果面试官追问
问：target 放大到 10^9 还能双指针吗？
答：能，指针最多走到 target/2，仍是 O(target) 步，只是要改用数学枚举长度 k 的 O(√target) 解法才够快。
