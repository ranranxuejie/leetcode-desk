## 一句话思路
用二维 DP 数「s 的前 i 个字符里凑出 t 的前 j 个字符」的方案数，匹配时把「用当前 s[i-1]」和「不用」两条来源相加。

## 怎么做
1. 定义 `dp[i][j]` = `s[:i]` 的子序列中等于 `t[:j]` 的个数，边界 `dp[i][0] = 1`（空串只有一种凑法），`dp[0][j>0] = 0`。
2. 转移：`s[i-1] != t[j-1]` 时只能丢弃 `s[i-1]`，`dp[i][j] = dp[i-1][j]`；相等时 `dp[i][j] = dp[i-1][j] + dp[i-1][j-1]`。
3. 用一维滚动数组，`j` 必须**从大到小**遍历，否则 `dp[j-1]` 已被本轮覆盖。
4. 返回 `dp[len(t)]`。

以 `s = "rabbbit", t = "rabbit"` 为例，处理到 `s` 的第 5 个字符（第二个 `b`，下标 4）时，`dp[3]`（凑 `"rab"`）从 1 变成 2：`dp[3] += dp[2]`，因为此时 `s[4] == t[2] == 'b'`，`dp[2]`（凑 `"ra"`）为 1。最终 `dp[6] = 3`。

```python
m, n = len(s), len(t)
dp = [0] * (n + 1)
dp[0] = 1
for i in range(1, m + 1):
    for j in range(n, 0, -1):
        if s[i - 1] == t[j - 1]:
            dp[j] += dp[j - 1]
return dp[n]
```

注意内层循环上界可以收紧到 `min(n, i)`，`j > i` 时 `dp[j]` 恒为 0，省掉无用比较。

## 复杂度
时间 O(m·n)，m = len(s)、n = len(t)，双重循环各扫一遍。
空间 O(n)，只开长度 n+1 的 `dp` 数组，滚动掉 s 那一维。

## 易错点
- `s = "a", t = ""` 或 `t` 为空：若把 `dp[0]` 初始成 0 或漏掉 `dp[0] = 1`，会返回 0；正确做法是空串恒有 1 种凑法，`dp[0] = 1` 且 `n == 0` 时直接返回 1。
- `s = "babgbag", t = "bag"`：若内层 `j` 从小到大遍历，`dp[j-1]` 已被本轮更新，`dp[3]` 会算成 4 而非 5；正确做法是 `j` 从 `n` 递减到 1，保证读到的 `dp[j-1]` 还是上一行 `i-1` 的值。

## 如果面试官追问
要求输出所有具体方案（不只计数）怎么办？
答：把 `dp` 换成回溯 + 记忆化，`dfs(i, j)` 返回方案列表，匹配时把 `s[i-1]` 拼到子方案前面，规模大时只输出前 k 个。
