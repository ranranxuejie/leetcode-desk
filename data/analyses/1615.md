## 一句话思路
用度数数组加邻接集合，枚举所有城市对算 `deg[a]+deg[b]-(a,b相邻)` 取最大。

## 怎么做
1. 遍历 `roads`，对每条 `[a,b]` 同时给 `deg[a]`、`deg[b]` 加一，并把 `b` 塞进 `adj[a]`、`a` 塞进 `adj[b]`。
2. 双重循环枚举所有 `a < b` 的城市对，候选秩为 `deg[a] + deg[b] - (1 if b in adj[a] else 0)`。
3. 用 `best` 记录最大值，循环结束返回 `best`。

以示例 1 `n=4, roads=[[0,1],[0,3],[1,2],[1,3]]` 为例：跑完第 1 步得到 `deg = [2,3,1,2]`，`adj[0]={1,3}`、`adj[1]={0,2,3}`。枚举到 `(0,1)` 时，`deg[0]+deg[1] = 5`，因为 `1 in adj[0]` 要减 1，得 4，正是答案；而 `(1,3)` 得 `3+2-1=4` 也并列，`(0,3)` 得 `2+2-1=3`。

```python
deg = [0] * n
adj = [set() for _ in range(n)]
for a, b in roads:
    deg[a] += 1
    deg[b] += 1
    adj[a].add(b)
    adj[b].add(a)

best = 0
for a in range(n):
    for b in range(a + 1, n):
        cur = deg[a] + deg[b] - (1 if b in adj[a] else 0)
        best = max(best, cur)
return best
```

关键点：这条被重复计算的边只可能有一条（题面保证每对城市最多一条道路），所以减 1 而不是减别的。

## 复杂度
时间 O(n² + m)，n² 来自枚举城市对，m 来自建图。
空间 O(n + m)，`deg` 开 n 个，`adj` 里存 2m 个端点。

## 易错点
1. 输入 `n=8, roads` 分成两个不连通块（示例 3）→ 若只枚举「有边的城市」会漏掉跨块组合，错成 4 → 必须对 `range(n)` 全枚举，孤立城市 `deg=0` 也参与，`(2,5)` 才能算出 `3+2=5`。
2. 输入 `(a,b)` 本身有边 → 若直接写 `deg[a]+deg[b]` 不减 1，示例 1 的 `(0,1)` 会错成 5 → 用 `b in adj[a]` 判断后减 1，注意 `adj` 是集合，别用列表导致 O(度数) 查找。

## 如果面试官追问
问：n 放大到 10^5、边数也 10^5，还能枚举吗？
答：不能，改为取度数最大的若干城市，只在「最大度集合」内部两两检查是否相邻，其余组合直接取两最大度之和。
