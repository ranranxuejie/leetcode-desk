## 一句话思路
把建筑 1 和 n 当作两个已知限制，排序后从左到右、从右到左各扫一遍把限制压紧，再在相邻限制间求能拱起的峰值。

## 怎么做
1. 把 `[1,0]` 和 `[n,0]` 塞进 `restrictions` 一起排序，这样首尾都有锚点。
2. 从左往右扫：`restrictions[i][1] = min(restrictions[i][1], restrictions[i-1][1] + 距离)`，把「左边够不着」的限制压下来。
3. 从右往左再扫一遍，同理压掉「右边够不着」的限制。
4. 相邻两个限制 `(p,hp)`、`(q,hq)` 之间，峰值 = `max(hp,hq) + (q-p-|hp-hq|)//2`，取全局最大。

以示例 3 为例，排序后是 `[1,0],[2,5],[5,3],[7,4],[10,3],[10,0]`。左扫时 `[5,3]` 被 `[2,5]` 压成 `min(3, 5+3)=3` 不变；右扫时 `[7,4]` 被 `[10,3]` 压成 `min(4, 3+3)=4` 不变。关键区间 `[7,4]` 到 `[10,3]`：`max(4,3) + (3-1)//2 = 4+1 = 5`，这就是答案。

```python
pts = sorted(restrictions + [[1, 0], [n, 0]])
for i in range(1, len(pts)):
    d = pts[i][0] - pts[i-1][0]
    pts[i][1] = min(pts[i][1], pts[i-1][1] + d)
for i in range(len(pts)-2, -1, -1):
    d = pts[i+1][0] - pts[i][0]
    pts[i][1] = min(pts[i][1], pts[i+1][1] + d)
ans = 0
for i in range(1, len(pts)):
    p, hp = pts[i-1]
    q, hq = pts[i]
    ans = max(ans, max(hp, hq) + (q - p - abs(hp - hq)) // 2)
```

## 复杂度
时间：排序 O(m log m)，m 是限制数；两遍扫描加区间求峰 O(m)。
空间：`pts` 存 m+2 个点，O(m)。

## 易错点
- 忘记补 `[n,0]` 这个右端点 → 示例 2 中 `restrictions=[]` 只剩 `[1,0]`，循环不执行，答案错成 0；必须同时补 `[1,0]` 和 `[n,0]`。
- 区间峰值公式漏掉 `abs(hp-hq)` 直接写 `(q-p)//2` → 示例 3 的 `[2,5]` 到 `[5,3]` 会算成 `5+1=6`，超过实际可达的 5；正确是 `max(5,3)+(3-2)//2=5`。

## 如果面试官追问
问：如果要求输出具体高度数组怎么办？
答：先按上述方法求出每个区间的峰值位置，再从峰值向两侧按斜率 ±1 递减填值，遇到已压紧的限制自然吻合。
