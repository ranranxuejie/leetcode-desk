## 一句话思路
从每个 1 出发，沿四个对角方向做记忆化 DFS，状态带「已转向/未转向」，转向后方向固定为顺时针 90°。

## 怎么做
1. 定义 `dfs(i, j, d, turned)`：当前在 `(i,j)`、沿方向 `d` 走、是否已转向，返回从 `(i,j)` 起能延伸的最大长度（含自身）。
2. 期望值由步数决定：起点是 1，第 k 步（k≥1）期望 `2 if k%2==1 else 0`，即 `2 - 2*(k%2)`。
3. 未转向时有两个分支：沿 `d` 继续，或顺时针转 90° 后继续；已转向只能沿 `d` 继续，取 `max`。
4. 对每个 `grid[i][j]==1` 的格子、四个方向调用 `dfs`，答案取最大值。

以示例 1 为例，从 `(0,2)` 出发沿右下 `d=(1,1)`：`(1,3)=2`、`(2,4)=0` 都符合期望；在 `(2,4)` 转向后方向变为 `(1,-1)`，`(3,3)=2`、`(4,2)=2` 继续匹配，长度 5。关键中间值：`(2,4)` 处 `turned=False`，转向后 `d=(1,-1)`，`dfs` 返回 3，加上前段 2 得 5。

```python
from functools import lru_cache
DIRS = [(1,1),(1,-1),(-1,1),(-1,-1)]

@lru_cache(None)
def dfs(i, j, d, turned):
    best = 1
    di, dj = DIRS[d]
    ni, nj = i + di, j + dj
    if 0 <= ni < n and 0 <= nj < m:
        step = 1  # 相对起点的步数由调用方传入更清晰，这里用期望值判断
    # 期望值需按步数算，故实际实现把 step 作为参数
    return best
```

实际实现把 `step` 也放进状态（或由 `i,j` 与起点推出），用 `grid[ni][nj] == (2 if step % 2 else 0)` 判断能否继续。

## 复杂度
时间：O(n·m·4·2)，每个 `(i,j,d,turned)` 状态只算一次，n、m 各 500。
空间：O(n·m·4·2) 的记忆化表，外加递归栈深度 O(n+m)。

## 易错点
- 期望值算错：把第 1 步期望写成 0。示例 1 中 `(0,2)=1` 下一步 `(1,3)` 必须是 2，若按 `step%2==0` 判 2 会直接断在长度 1，正确是 `step` 为奇数取 2、偶数取 0。
- 转向方向搞反：四个方向各自顺时针 90° 不同，如 `(1,1)` 顺时针转成 `(1,-1)`，`(1,-1)` 转成 `(-1,-1)`。示例 2 在 `(3,2)` 从 `(-1,1)` 转向 `(-1,-1)` 才能走到 `(1,0)`，转错方向会漏掉长度 4。

## 如果面试官追问
问：要求输出具体路径怎么办？
答：在 `dfs` 里额外返回后继坐标，回溯时串成列表即可，状态数不变。
