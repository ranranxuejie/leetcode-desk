## 一句话思路
中序遍历两棵 BST 各得一个升序数组，再归并这两个有序数组，避免整体排序。

## 怎么做
1. 写一个迭代式中序遍历，把 root1 的节点值按升序压进 `a`。
2. 对 root2 做同样的事得到 `b`。
3. 用双指针 `i`、`j` 归并 `a` 和 `b`，每次取较小者，剩余部分直接拼接。

以示例 1 为例：root1 中序得 `a = [1,2,4]`，root2 中序得 `b = [0,1,3]`；归并时先取 `b[0]=0`，再比较 `a[0]=1` 与 `b[1]=1`，取 `a[0]` 后 `i=1`，最终 `[0,1,1,2,3,4]`。

```python
def inorder(root):
    res, st = [], []
    while root or st:
        while root:
            st.append(root); root = root.left
        root = st.pop()
        res.append(root.val)
        root = root.right
    return res

a, b = inorder(root1), inorder(root2)
i = j = 0
out = []
while i < len(a) and j < len(b):
    if a[i] <= b[j]:
        out.append(a[i]); i += 1
    else:
        out.append(b[j]); j += 1
out += a[i:] + b[j:]
```

## 复杂度
时间 O(m+n)：中序遍历各 O(m)、O(n)，归并 O(m+n)。
空间 O(m+n)：两个中序数组加输出列表，递归栈可忽略（迭代版为 O(h)）。

## 易错点
- 空树输入（如 root1 为空、root2 有节点）→ 若归并循环写成 `while i < len(a) or j < len(b)` 却只处理一侧，会漏掉整棵树的元素 → 用 `a[i:] + b[j:]` 兜底拼接剩余部分。
- 两树有大量重复值（示例 2 的 `[1,null,8]` 与 `[8,1]`）→ 若用 `set` 去重会输出 `[1,8]` 而非 `[1,1,8,8]` → 归并时用 `<=` 保留重复，绝不去重。

## 如果面试官追问
问：节点数涨到 10^6、内存受限怎么办？
答：不存两个完整数组，用两个显式栈做双 BST 迭代器，边遍历边归并，空间降到 O(h1+h2)。
