## 一句话思路
按斜率排序后，最小面积矩形的四条边必由相邻斜率直线的交点决定，故只需枚举相邻对求 x、y 极值。

## 怎么做
1. 把 `lines` 按 `k` 升序排序；`k` 互不相同（否则平行无交点，但题设 `k>0` 且不重合，仍需防同 `k`）。
2. 关键结论：矩形左/右边界来自某对相邻斜率直线的交点 x，上/下边界来自另一对相邻斜率直线的交点 y。因为交点 x 随斜率差单调，极值只在相邻对出现。
3. 枚举相邻两对直线求交点，维护 `minx, maxx, miny, maxy`。

以 `[[2,3],[3,0],[4,1]]` 排序后不变。相邻对 (2,3)&(3,0)：交点 x=(0-3)/(2-3)=3，y=2*3+3=9；相邻对 (3,0)&(4,1)：x=(1-0)/(3-4)=-1，y=3*(-1)+0=-3。故 `maxx=3, minx=-1, maxy=9, miny=-3`，面积 `(3-(-1))*(9-(-3))=4*12=48`。

```python
lines.sort()
minx = miny = float('inf')
maxx = maxy = float('-inf')
for (k1, b1), (k2, b2) in zip(lines, lines[1:]):
    x = (b2 - b1) / (k1 - k2)
    y = k1 * x + b1
    minx, maxx = min(minx, x), max(maxx, x)
    miny, maxy = min(miny, y), max(maxy, y)
return (maxx - minx) * (maxy - miny) if maxx > minx and maxy > miny else 0.0
```

注意 `k1 - k2 != 0` 才可除；同 `k` 时跳过（平行无交点）。

## 复杂度
时间：排序 O(n log n)，枚举 O(n)，n 为直线条数。
空间：排序原地 O(1) 额外（Python `sort` 内部 O(log n) 栈）。

## 易错点
- 输入 `[[1,1],[2,3]]` 只有一对直线 → 若直接算面积会得 0 但 `maxx==minx`，需显式判 `maxx>minx and maxy>miny` 否则返回 0.0，避免 `inf` 参与运算。
- 存在相同 `k` 的直线（题设不重合但可能同斜率）→ 直接 `(b2-b1)/(k1-k2)` 会除零崩溃 → 排序后跳过 `k1==k2` 的对，且此时该对无交点不影响极值。

## 如果面试官追问
若要求输出矩形四角坐标而非面积？答：同样维护四个极值，但需记录取到极值的相邻对下标，回代求对应交点坐标即可。
