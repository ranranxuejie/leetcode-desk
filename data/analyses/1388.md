## 一句话思路
把「选一块、邻居被抢」转成环形数组上选 n 个互不相邻的数，用「首尾拆环 + 打家劫舍式 DP」求最大和。

## 怎么做
1. 关键转化：你选 `slices[i]` 后，`i-1` 和 `i+1` 被 Alice/Bob 拿走，等价于选中的下标两两不相邻；共选 `n = len(slices)//3` 个。
2. 环形首尾不能同时选，拆成两段线性问题：`slices[0:m-1]` 和 `slices[1:m]`，各求「选 n 个不相邻」的最大和，取较大者。
3. 线性版用 DP：`dp[i][j]` 表示前 i 块里选 j 块的最大和，转移 `dp[i][j] = max(dp[i-1][j], dp[i-2][j-1] + a[i-1])`。
4. 用滚动数组把 i 维压成两行，j 从大到小或另开数组避免覆盖。

以 `slices = [1,2,3,4,5,6]`，`n=2` 为例：第一段 `[1,2,3,4,5]` 选 2 个不相邻，最优是 `4+2=6` 或 `5+3=8`？实际 `[1,2,3,4,5]` 中 `3+5=8`；第二段 `[2,3,4,5,6]` 最优 `4+6=10`，取 max 得 10，与答案一致。

```python
def best(a, k):
    # a 线性，选 k 个不相邻
    pre2 = [0]*(k+1)          # dp[i-2]
    pre1 = [0]*(k+1)          # dp[i-1]
    for x in a:
        cur = pre1[:]         # 不选 x
        for j in range(1, k+1):
            cur[j] = max(cur[j], pre2[j-1] + x)
        pre2, pre1 = pre1, cur
    return pre1[k]

m = len(slices); n = m // 3
ans = max(best(slices[:m-1], n), best(slices[1:], n))
```

## 复杂度
时间：两段各 O(m·n)，m 为数组长度、n=m/3，合计 O(m²)。
空间：滚动两行各长 n+1，额外 O(n)，切片 `slices[:m-1]` 另占 O(m)。

## 易错点
- 输入 `[8,9,8,6,1,1]`：若只跑一段 `slices[:m-1]` 会漏掉首尾组合，错成 8+8 之外的 9+6=15；必须两段都跑再取 max，才能得 16。
- 输入 `[1,2,3,4,5,6]`：DP 里 `j` 上界写成 `m` 而非 `n=2`，会允许选 3 个不相邻（如 1,3,5 和 8），错成 9 以上；`k` 必须固定为 `len//3`。

## 如果面试官追问
问：n 到 500 时 O(m²) 够吗，能否更快？
答：m≤500 时 25 万次转移足够；若要 O(m) 需换堆+链表删邻的贪心，但实现复杂、易错，面试优先写 DP。
