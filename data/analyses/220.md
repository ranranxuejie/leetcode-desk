## 一句话思路
用大小为 indexDiff 的滑动窗口维护桶，桶宽 valueDiff+1，同桶或相邻桶命中即返回 True。

## 怎么做
1. 桶编号取 `nums[i] // (valueDiff + 1)`，保证同桶内任意两数差 ≤ valueDiff。
2. 遍历 i，先删掉窗口外的桶 `nums[i - indexDiff - 1] // w`，再查当前桶、左桶、右桶。
3. 命中条件：同桶直接 True；左/右桶要再验一次 `abs(nums[i] - 桶内值) <= valueDiff`。
4. 都不中就把 `nums[i]` 存入当前桶编号。

以 `nums = [1,2,3,1], indexDiff = 3, valueDiff = 0` 为例，`w = 1`：i=0 存桶 1；i=1 桶 2 空、查桶 1 得 1，`abs(2-1)=1 > 0` 不中，存桶 2；i=2 同理不中；i=3 时 `3-3-1 = -1` 无需删，查桶 1 得 1，`abs(1-1)=0 <= 0`，返回 True。

```python
w = valueDiff + 1
buckets = {}
for i, x in enumerate(nums):
    if i > indexDiff:
        buckets.pop(nums[i - indexDiff - 1] // w, None)
    b = x // w
    for nb in (b - 1, b, b + 1):
        if nb in buckets and abs(x - buckets[nb]) <= valueDiff:
            return True
    buckets[b] = x
return False
```

注意 `x // w` 对负数向下取整，`-1 // 2 = -1`，相邻关系仍然成立，不用额外偏移。

## 复杂度
时间：O(n)，每个下标最多查 3 个桶，删桶 O(1)。
空间：O(min(n, indexDiff))，字典最多存 indexDiff+1 个桶。

## 易错点
- `valueDiff = 0` 时若把桶宽写成 `valueDiff`，会除零；必须写 `valueDiff + 1`，示例 1 正是这个边界。
- 只查同桶不查左右桶：如 `nums = [1,5,9,1,5,9], indexDiff = 2, valueDiff = 3`，`w = 4`，1 和 5 分落桶 0 和桶 1，漏查右桶就会错判 False。
- 删窗口外元素时用 `nums[i - indexDiff - 1]`，写成 `i - indexDiff` 会提前删掉仍在窗口内的元素，示例 1 的 i=3 就会把下标 0 的 1 删掉而漏解。

## 如果面试官追问
若要求输出具体下标对而非布尔值？答：桶里存 `(值, 下标)`，命中时连同当前 i 一起返回即可，其余逻辑不变。
