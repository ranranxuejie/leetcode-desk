## 一句话思路
用队列做 BFS，每轮先记下 `len(q)` 作为本层节点数，只弹出这么多节点，就能把层与层切开。

## 怎么做
1. `root` 为 `None` 直接返回 `[]`，否则 `q = [root]`。
2. 外层 `while q:` 每轮新建 `level = []`，并取 `size = len(q)`。
3. 内层循环 `size` 次：`node = q.pop(0)`，把 `node.val` 追加进 `level`，非空的左右孩子入队。
4. 内层结束后 `res.append(level)`。

以 `root = [8,17,21,18,null,null,6]` 为例：第一轮 `size = 1`，弹出 8，`level = [8]`，入队 17、21；第二轮 `size = 2`，弹出 17、21，`level = [17,21]`，入队 18、6；第三轮 `size = 2`，弹出 18、6，`level = [18,6]`。关键中间值是每轮的 `size`：它固定了内层循环次数，所以 18、6 不会和 17、21 混进同一行。

```python
q = [root] if root else []
res = []
while q:
    size = len(q)
    level = []
    for _ in range(size):
        node = q.pop(0)
        level.append(node.val)
        if node.left:
            q.append(node.left)
        if node.right:
            q.append(node.right)
    res.append(level)
```

`size` 必须在入队孩子**之前**取，否则第二轮 `size` 会变成 4，把第三层的 18、6 提前算进第二层。

## 复杂度
时间 O(n)：每个节点入队出队各一次，n 为节点总数。
空间 O(n)：队列最宽时存一层节点，`res` 存全部 n 个值。

## 易错点
- 用 `while q:` 但内层写成 `for node in q:` 或忘记 `size` → 孩子入队后同一轮被继续弹出，`[8,17,21,18,6]` 被压成一行 → 必须先 `size = len(q)` 再循环。
- 空树 `root = None` → 直接 `q = [None]` 会 `AttributeError: 'NoneType' object has no attribute 'val'` → 用 `q = [root] if root else []` 或先判空返回 `[]`。

## 如果面试官追问
若要求之字形（第一层左到右、第二层右到左）？答：仍按层 BFS，加一个 `reverse` 布尔，每层结束按需 `level.reverse()` 再 append，复杂度不变。
