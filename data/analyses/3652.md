## 一句话思路
先算原始总利润，再用滑动窗口找「改后减原始」的最大增益，因为修改只影响窗口内 k 天。

## 怎么做
1. 算 `base = sum(prices[i] * strategy[i])`，这是不修改时的利润。
2. 对每个起点 `l`，窗口 `[l, l+k)` 内前 `k//2` 天改成 0、后 `k//2` 天改成 1，增益为 `-sum(prices[l:l+k//2]*strategy[...]) + sum(prices[l+k//2:l+k]*(1-strategy[...]))`。
3. 用前缀和把每段窗口增益 O(1) 求出，取 `max_gain`，答案 `base + max(0, max_gain)`。

以示例 1 `prices=[4,2,8], strategy=[-1,0,1], k=2` 为例：`base = -4+0+8 = 4`。窗口 `l=0`：前半 `[0]` 原贡献 `-1*4=-4`，改成 0 后增益 `+4`；后半 `[1]` 原贡献 `0*2=0`，改成 1 后贡献 `2`，增益 `+2`，合计 `max_gain=6`，答案 `4+6=10`。窗口 `l=1` 增益为 0。

```python
n = len(prices)
base = sum(p * s for p, s in zip(prices, strategy))
pre = [0] * (n + 1)
for i in range(n):
    pre[i + 1] = pre[i] + prices[i] * strategy[i]
h = k // 2
best = 0
for l in range(n - k + 1):
    # 前半改成 0：减去原贡献；后半改成 1：加 prices*(1-strategy)
    left = -(pre[l + h] - pre[l])
    right = sum(prices[l + h:l + k]) - (pre[l + k] - pre[l + h])
    best = max(best, left + right)
return base + best
```

## 复杂度
时间 O(n)：前缀和与窗口各扫一遍，`n = len(prices)`。
空间 O(n)：额外开 `pre` 长度 n+1。

## 易错点
- `k` 可能等于 `n`，窗口只有 `l=0` 一个；若循环写成 `range(n-k)` 会漏掉唯一窗口，答案退化成 `base`。应写 `range(n - k + 1)`。
- 后半段增益是 `prices[i]*(1-strategy[i])` 而非 `prices[i]`：当 `strategy[i]` 本来就是 1 时增益应为 0，直接加 `prices[i]` 会重复计入，示例 2 的 `l=0` 窗口会算成 5+4 而非 4。

## 如果面试官追问
若要求输出修改后的 strategy 数组？答：在滑动窗口里同步记录取得 `best` 的起点 `l`，最后把 `[l, l+h)` 置 0、`[l+h, l+k)` 置 1 返回即可。
