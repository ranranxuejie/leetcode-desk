## 一句话思路
按值分组收集下标，组内下标有序，用前缀和一次扫描算出每个位置到其余同值下标的距离和。

## 怎么做
1. 用字典 `pos` 把 `arr` 中相同值的下标收集成列表，遍历顺序保证每个列表天然升序。
2. 对某个值的下标列表 `p`（长度 m），预处理前缀和 `pre`，`pre[k] = p[0]+...+p[k-1]`。
3. 对第 i 个下标 `p[i]`，左侧 i 个元素贡献 `p[i]*i - pre[i]`，右侧 m-1-i 个元素贡献 `(pre[m]-pre[i+1]) - p[i]*(m-1-i)`，两者相加写回 `ans[p[i]]`。
4. 以示例 1 中值为 3 的下标列表 `p = [2,5,6]` 为例：`pre = [0,2,7,13]`。i=1 时左侧 `5*1 - 2 = 3`，右侧 `(13-7) - 5*1 = 1`，合计 4，即 `ans[5]=4`，与输出一致。

```python
from collections import defaultdict

pos = defaultdict(list)
for i, v in enumerate(arr):
    pos[v].append(i)

ans = [0] * len(arr)
for p in pos.values():
    m = len(p)
    pre = [0] * (m + 1)
    for k in range(m):
        pre[k + 1] = pre[k] + p[k]
    for i in range(m):
        left = p[i] * i - pre[i]
        right = (pre[m] - pre[i + 1]) - p[i] * (m - 1 - i)
        ans[p[i]] = left + right
```

## 复杂度
时间：O(n)，每个下标在分组、前缀和、求值中各被访问常数次。
空间：O(n)，`pos` 存全部下标，`pre` 最大长度等于某值出现次数。

## 易错点
- 输入 `arr = [10,5,10,10]` 中 5 只出现一次 → 若直接套公式，`m-1-i = -1` 会让右侧项变成非零垃圾值 → 单元素组必须跳过或保证 `right` 项为 0，正确输出 `ans[1]=0`。
- 输入 `arr = [2,1,3,1,2,3,3]` 中 3 出现 3 次 → 若把 `pre[i+1]` 误写成 `pre[i]`，右侧和会多算 `p[i]` 自身，`ans[5]` 会算成 9 而非 4 → 右侧区间是 `p[i+1..m-1]`，前缀和必须用 `pre[m]-pre[i+1]`。

## 如果面试官追问
若要求在线回答（边插入边查询某值的距离和）？答：每个值维护「下标个数 + 下标总和」，插入 x 时该值已有 k 个下标、总和 S，新增距离和为 `x*k - S`（新下标最大），再更新 k、S。
