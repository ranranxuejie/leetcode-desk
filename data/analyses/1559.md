## 一句话思路
对每个未访问格子做 DFS，记录父节点，若走到已访问且非父节点的同值格子即存在环。

## 怎么做
1. 建 `visited = [[False]*n for _ in range(m)]`，遍历每个格子，未访问则从它启动 DFS。
2. DFS 参数带 `(r, c, pr, pc)`，标记 `visited[r][c] = True`，向四邻扩展。
3. 邻居值等于 `grid[r][c]` 时：若未访问就递归；若已访问且不是 `(pr, pc)`，直接返回 `True`。
4. 任一分支返回 `True` 即整体返回 `True`，全部搜完返回 `False`。

以示例 3 的 `grid[1][1] = 'z'` 为例：从 `(1,1)` 出发，四邻全是 `'b'` 不等于 `'z'`，DFS 立即结束，`visited[1][1]` 只被标记一次，不会误判成环。

```python
def dfs(r, c, pr, pc):
    visited[r][c] = True
    for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
        nr, nc = r + dr, c + dc
        if not (0 <= nr < m and 0 <= nc < n):
            continue
        if grid[nr][nc] != grid[r][c]:
            continue
        if not visited[nr][nc]:
            if dfs(nr, nc, r, c):
                return True
        elif (nr, nc) != (pr, pc):
            return True
    return False
```

关键中间值：搜示例 1 的外圈 `'a'`，走到 `(0,3)` 时邻居 `(0,2)` 已访问且父节点是 `(1,3)`，`(0,2) != (1,3)`，命中 `return True`。

## 复杂度
时间 O(m·n)：每个格子最多被访问一次，四邻检查常数次。
空间 O(m·n)：`visited` 布尔矩阵加 DFS 递归栈，最坏深度 m·n。

## 易错点
- 输入 `[["a","a"]]`（1×2 单行）→ 若只判「邻居已访问」不排除父节点，会把 `(0,0)-(0,1)` 这条边误判成环返回 `True` → 必须带 `(pr, pc)` 并显式比较 `(nr, nc) != (pr, pc)`。
- 输入示例 3 的 `'b'` 区域（8 个 `'b'` 围成 U 形但无闭合）→ 若用并查集时把「同值相邻」无条件 union 而不先查是否已同根，会把树边当环边误报 `True` → 并查集版本必须先 `find` 两端，同根才判环，否则再 union。

## 如果面试官追问
问：m、n 到 500 递归会不会爆栈？
答：Python 默认递归上限约 1000，最坏路径 25 万格会 `RecursionError`，改显式栈存 `(r, c, pr, pc)` 迭代即可。
