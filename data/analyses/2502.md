## 一句话思路
用长度 n 的数组 `mem` 逐格记录 mID（0 表示空闲），分配时从左扫描找连续 size 个 0，释放时按 mID 全表清空。

## 怎么做
1. 构造时开 `self.mem = [0] * n`，0 代表空闲，非 0 就是占用它的 mID。
2. `allocate` 用 `i` 从左往右扫，维护当前连续空闲长度 `run`，`run == size` 时起点是 `i - size + 1`。
3. 命中后把 `mem[start:start+size]` 整段赋成 `mID`，返回 `start`；扫完没命中返回 `-1`。
4. `freeMemory` 遍历全表，把等于 `mID` 的格子改回 0 并计数，返回计数。

拿官方示例第 5 步说：此时 `mem = [1, 0, 3, 0, 0, 0, 0, 0, 0, 0]`，`allocate(3, 4)` 扫到 `i=3` 时 `run` 从 1 涨到 3，起点 `3-3+1 = 3`，于是 `mem[3:6] = [4,4,4]`，返回 3。

```python
def allocate(self, size, mID):
    run = 0
    for i in range(len(self.mem)):
        run = run + 1 if self.mem[i] == 0 else 0
        if run == size:
            start = i - size + 1
            self.mem[start:i + 1] = [mID] * size
            return start
    return -1

def freeMemory(self, mID):
    cnt = 0
    for i in range(len(self.mem)):
        if self.mem[i] == mID:
            self.mem[i] = 0
            cnt += 1
    return cnt
```

## 复杂度
时间：`allocate` 与 `freeMemory` 都是 O(n)，n 为内存数组长度，调用 1000 次即 O(1000n)。
空间：额外只有长度 n 的 `mem` 数组，O(n)。

## 易错点
- `allocate(1, 1)` 连调两次：第一次返回 0，第二次必须返回 1 而不是又返回 0。若把「找空闲」写成只判断 `mem[i] == 0` 就返回，会漏掉已占用格；正确做法是维护 `run` 连续计数，占用格把 `run` 归零。
- `freeMemory(1)` 在示例第 8 步要返回 3：mID 1 分散在下标 0、1、6 三处，只清第一段会返回 1。必须全表扫描，不能遇到第一个不匹配就 break。

## 如果面试官追问
若 n 和调用次数都放大到 10^5，怎么优化？答：用有序区间集合（如按起点排序的空闲块表 + 按 mID 索引的占用块表），分配时找首个够长的空闲块，释放时合并相邻空闲块，单次 O(log n)。
