## 一句话思路
分别算出时针、分针相对 12 点的角度，作差后取 `min(diff, 360 - diff)` 得较小夹角。

## 怎么做
1. 分针角度 `minute_angle = minutes * 6`，因为 60 分钟走满 360 度。
2. 时针角度 `hour_angle = (hour % 12) * 30 + minutes * 0.5`，分钟部分必须按 0.5 度/分累加。
3. 差值 `diff = abs(hour_angle - minute_angle)`，再取 `min(diff, 360 - diff)`。

以示例 3 `hour=3, minutes=15` 为例：`minute_angle = 15*6 = 90`，`hour_angle = 3*30 + 15*0.5 = 97.5`，`diff = 7.5`，`360-7.5=352.5`，取小得 `7.5`。

```python
def angleClock(hour, minutes):
    minute_angle = minutes * 6.0
    hour_angle = (hour % 12) * 30.0 + minutes * 0.5
    diff = abs(hour_angle - minute_angle)
    return min(diff, 360.0 - diff)
```

关键点：`hour % 12` 把 12 点映射成 0 度，避免 `12*30=360` 与分针 0 度作差得 360 而非 0。

## 复杂度
时间：O(1)，只有常数次算术运算。
空间：O(1)，只用了 `minute_angle`、`hour_angle`、`diff` 三个标量。

## 易错点
- 输入 `hour=12, minutes=0` → 若直接用 `hour*30=360` 与分针 0 作差得 360，取小后仍是 0 但中间值错；正确做法是先 `hour % 12` 再乘 30，得 0 与 0 差 0。
- 输入 `hour=3, minutes=15` → 若时针只算 `hour*30=90` 忽略分钟偏移，得 `abs(90-90)=0`，错成 0；正确做法是加 `minutes*0.5=7.5`，得 97.5 与 90 差 7.5。

## 如果面试官追问
问：若要求返回较大角而非较小角？答：把 `min(diff, 360-diff)` 换成 `max(diff, 360-diff)`，其余不变。
