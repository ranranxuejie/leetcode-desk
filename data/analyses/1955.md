## 一句话思路
用三个计数器分别记录「已凑出 0」「已凑出 0…1」「已凑出 0…1…2」的子序列数，扫一遍数组边扫边累加。

## 怎么做
1. 设 `c0, c1, c2` 表示当前已形成的、分别以 0、1、2 结尾的合法前缀子序列个数，初值全 0。
2. 遇到 `x == 0`：它可单独成序列，也可接在已有 `c0` 后面，故 `c0 = c0 * 2 + 1`。
3. 遇到 `x == 1`：它可接在任一 `c0` 后，也可接在已有 `c1` 后，故 `c1 = c1 * 2 + c0`。
4. 遇到 `x == 2`：同理 `c2 = c2 * 2 + c1`，最后返回 `c2`。

以 `nums = [0,1,2,2]` 为例：读到第一个 2 时 `c0=1, c1=1`，算出 `c2 = 0*2 + 1 = 1`；读到第二个 2 时 `c2 = 1*2 + 1 = 3`，与输出 3 吻合。关键在 `c2` 的递推里 `c1` 是「此刻」的值，不是最终值。

```python
MOD = 10**9 + 7
c0 = c1 = c2 = 0
for x in nums:
    if x == 0:
        c0 = (c0 * 2 + 1) % MOD
    elif x == 1:
        c1 = (c1 * 2 + c0) % MOD
    else:
        c2 = (c2 * 2 + c1) % MOD
return c2
```

注意 `c0 * 2 + 1` 里的 `+1` 不能省：它代表「只取当前这个 0」这一条新序列，漏掉会让 `[0,1,2]` 这种最短合法序列统计不到。

## 复杂度
时间 O(n)：一次遍历 `nums`，每个元素常数次取模运算。
空间 O(1)：只开 `c0, c1, c2` 三个变量，与 n 无关。

## 易错点
- 输入 `[2,2,0,0]` → 若先扫到 2 就急着累加 `c2`，会得到非 0 的错误结果 → 正确做法是 `c2` 只由 `c1` 转移，前面没有 0、1 时 `c1=0`，`c2` 自然保持 0。
- 输入 `[0,1,2,0,1,2]` → 若在第二次遇到 0 时把 `c0` 重置为 1 而非 `c0*2+1`，会漏掉跨段的组合，答案小于 7 → 正确做法是 `c0` 单调累加，旧序列保留并可与新 0 组合。

## 如果面试官追问
问：若要求输出所有特殊子序列的下标集合而非计数？
答：把三个计数器换成三个列表存下标元组，转移时做笛卡尔拼接，复杂度升到输出规模级别。
