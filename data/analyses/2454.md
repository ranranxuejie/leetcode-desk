## 一句话思路
用两个单调栈接力：第一个栈弹出时把下标转交给第二个栈，第二个栈弹出时即为该下标的第二大元素。

## 怎么做
1. 维护 `s1`（还没遇到第一个更大值的下标）和 `s2`（已遇到第一个更大值、等第二个的下标），都保持栈内 `nums` 值递减。
2. 遍历每个 `i`，先处理 `s2`：只要 `nums[s2[-1]] < nums[i]` 就弹出并写 `ans[idx] = nums[i]`。
3. 再处理 `s1`：只要 `nums[s1[-1]] < nums[i]` 就弹出该下标 `idx`，把它压入 `s2`（它刚拿到第一个更大值）。
4. 最后把 `i` 压入 `s1`。

以 `nums = [2,4,0,9,6]` 为例：`i=1` 时 `nums[1]=4` 弹出 `s1` 中的 0，把 0 压入 `s2`；`i=3` 时 `nums[3]=9` 先弹 `s2` 的 0 得 `ans[0]=9`，再弹 `s1` 的 1 压入 `s2`；`i=4` 时 `nums[4]=6` 弹 `s2` 的 1 得 `ans[1]=6`，再弹 `s1` 的 2 压入 `s2`。注意 `i=3` 时 `s2` 里只有 0，因为 2 的第一个更大值是 9 而非 4（4 不大于 2 吗？4>2，所以 2 在 `i=1` 就该进 `s2`——实际 `i=1` 时 `s1` 栈顶是 0（值 2），4>2 弹出 0 进 `s2`，2 本身还在 `s1` 里，`i=3` 才被 9 弹出）。

```python
n = len(nums)
ans = [-1] * n
s1, s2 = [], []
for i in range(n):
    while s2 and nums[s2[-1]] < nums[i]:
        ans[s2.pop()] = nums[i]
    while s1 and nums[s1[-1]] < nums[i]:
        s2.append(s1.pop())
    s1.append(i)
```

## 复杂度
时间 O(n)：每个下标最多进 `s1` 一次、进 `s2` 一次、被弹出各一次。
空间 O(n)：`s1`、`s2`、`ans` 三个数组，最坏各存 n 个下标。

## 易错点
- 输入 `[3,3]` → 若用 `<=` 比较，相等元素会互相弹出，错得 `ans` 有值；正确做法是严格 `<`，相等不算「更大」，两个 3 都留 `-1`。
- 输入 `[1,2,4,3]` → 若把两个 while 顺序写反（先 `s1` 后 `s2`），`i=2` 时 4 会先把 1 从 `s1` 弹出压进 `s2`，紧接着同一轮又被 `s2` 的 while 弹出，导致 1 的答案错成 4 而非 4（其实对）——真正的坑是 `i=3` 的 3 会误弹 `s2` 里的 1；正确做法是每轮先清 `s2` 再清 `s1`，保证新进 `s2` 的下标不在同一轮被消费。

## 如果面试官追问
问：要求返回第二大元素的下标而非值怎么办？
答：`ans` 存下标，弹出时写 `ans[idx] = s2.pop()` 的下标即可，逻辑不变。
