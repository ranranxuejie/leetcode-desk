## 一句话思路
按列做 DP：`reach[r]` 表示第 `c` 列第 `r` 行能否到达，逐列向右推，能推多远就是答案。

## 怎么做
1. 初始 `reach = [True] * m`，第一列任意行都能出发。
2. 对每列 `c`，用 `nxt = [False] * m`，对每个可达的 `r` 检查 `(r-1, c+1)`、`(r, c+1)`、`(r+1, c+1)` 中值严格大于 `grid[r][c]` 的格子，标记 `nxt` 为 `True`。
3. 若 `nxt` 全为 `False`，返回 `c`（已走步数）；否则 `reach = nxt` 继续。
4. 走完所有列返回 `n - 1`。

以示例 1 为例，第 0 列 `reach = [True, True, True, True]`；处理 `c=0` 时 `r=0` 的 `grid[0][0]=2`，`(0,1)=4 > 2` 使 `nxt[0]=True`，`(1,1)=4 > 2` 使 `nxt[1]=True`；`r=3` 的 `grid[3][0]=10` 三个邻居 `4,4,9` 都不大于 10，`nxt[3]` 保持 `False`。第 1 列 `reach = [True, True, True, False]`，继续推到第 3 列后无路，返回 3。

```python
m, n = len(grid), len(grid[0])
reach = [True] * m
for c in range(n - 1):
    nxt = [False] * m
    for r in range(m):
        if not reach[r]:
            continue
        for nr in (r - 1, r, r + 1):
            if 0 <= nr < m and grid[nr][c + 1] > grid[r][c]:
                nxt[nr] = True
    if not any(nxt):
        return c
    reach = nxt
return n - 1
```

## 复杂度
时间：`O(m * n)`，每格最多被三个来源检查一次。
空间：`O(m)`，只开 `reach` 和 `nxt` 两个长度 `m` 的布尔数组。

## 易错点
- 输入 `grid = [[3,2,4],[2,1,9],[1,1,7]]` → 若把「严格大于」写成 `>=`，`(1,0)=2` 会走到 `(0,1)=2`，错误返回非 0；正确做法是判断 `grid[nr][c+1] > grid[r][c]`，示例 2 应返回 0。
- 输入 `grid = [[2,4,3,5],[5,4,9,3],[3,4,2,11],[10,9,13,15]]` → 若在 `nxt` 全 `False` 时返回 `c + 1`，会多算一步，输出 4；正确做法是返回 `c`，因为第 `c` 列已是最后可达列，移动次数等于列下标差。

## 如果面试官追问
问：要求输出具体路径怎么办？答：把 `nxt[nr]` 改成记录来源 `parent[nr] = r`，最后从终点回溯到第一列即可。
