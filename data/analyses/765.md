## 一句话思路
从左往右扫，每遇到一对没坐一起的情侣，就把其伴侣换到相邻座位，贪心即可，因为每次交换至少修复一对且不会破坏已修复的。

## 怎么做
1. 把 row 按座位两两分组，第 i 组是 `row[2i]` 和 `row[2i+1]`。
2. 对每组，若 `row[2i] // 2 != row[2i+1] // 2`，说明这两人不是情侣。
3. 找到 `row[2i]` 的伴侣 `row[2i] ^ 1`（异或 1 得到配对 ID），在数组中定位它的位置 pos。
4. 交换 `row[2i+1]` 和 `row[pos]`，计数加一。

以 `row = [0,2,1,3]` 为例：i=0 时，`row[0]=0`，`row[1]=2`，`0//2=0`，`2//2=1`，不相等。伴侣是 `0^1=1`，在位置 2。交换 `row[1]` 和 `row[2]`，得到 `[0,1,2,3]`，计数 1。i=1 时 `2//2==3//2==1`，跳过。答案 1。

```python
def minSwapsCouples(row):
    n = len(row)
    pos = {v: i for i, v in enumerate(row)}
    ans = 0
    for i in range(0, n, 2):
        a, b = row[i], row[i + 1]
        if a // 2 != b // 2:
            partner = a ^ 1
            j = pos[partner]
            row[i + 1], row[j] = row[j], row[i + 1]
            pos[b], pos[partner] = j, i + 1
            ans += 1
    return ans
```

关键中间值：交换后 `pos` 字典同步更新，`pos[1]=1`，`pos[2]=2`，保证后续定位正确。

## 复杂度
时间 O(n)：扫 n/2 组，每组 O(1) 查字典定位。
空间 O(n)：pos 字典存 2n 个元素的位置。

## 易错点
- 输入 `row = [0,2,1,3]` 时若用 `a+1` 或 `a-1` 找伴侣，对偶数 ID 会错：`0` 的伴侣是 `1`，但 `0-1=-1` 越界。正确做法是用 `a ^ 1`，偶变奇、奇变偶，统一处理。
- 交换后忘记更新 `pos` 字典：如 `[0,2,1,3]` 交换后 `row=[0,1,2,3]`，若 `pos[2]` 仍指向 1，后续组定位到错误位置导致死循环或错答。正确做法是交换时同步改 `pos[b]` 和 `pos[partner]`。

## 如果面试官追问
若要求输出具体交换方案而非次数？答：在贪心循环里记录每次交换的 `(i+1, j)` 下标对，按顺序输出即可，交换序列本身即一种最优方案。
