## 一句话思路
枚举被删的下标（含不删），用前缀/后缀 gcd 表 O(1) 拼出 arr 的左右 gcd，逐分割位比对。

## 怎么做
1. 预处理 `pre[i] = gcd(nums[0..i])`、`suf[i] = gcd(nums[i..n-1])`，`pre[-1]`、`suf[n]` 视为 0（gcd 单位元）。
2. 枚举删除下标 `d`（`d = n` 表示不删），把 arr 看成「原数组去掉 d」。
3. 对 arr 的每个分割位 `i`，左 gcd 与右 gcd 都能由 `pre`/`suf` 在 O(1) 内拼出，相等则计数。
4. 取所有 `d` 的最大计数。

以 `nums = [10,30,15,10]`、`d = 2` 为例：arr = `[10,30,10]`，分割位 `i = 1` 时左 gcd = `gcd(pre[1]) = 10`，右 gcd = `gcd(suf[3]) = 10`，相等，计入；`i = 0` 同理得 10 与 `gcd(30,10)=10`，也计入，得分 2。

```python
from math import gcd
n = len(nums)
pre = [0] * n
suf = [0] * n
for i in range(n):
    pre[i] = nums[i] if i == 0 else gcd(pre[i - 1], nums[i])
for i in range(n - 1, -1, -1):
    suf[i] = nums[i] if i == n - 1 else gcd(suf[i + 1], nums[i])
best = 0
for d in range(n + 1):          # d == n 表示不删
    m = n - 1 if d < n else n
    for i in range(m - 1):      # arr 的分割位
        l = pre[i] if i < d else pre[i + 1]
        r = suf[i + 1] if i + 1 < d else suf[i + 2]
        if l == r:
            best += 1
```
（上面 `best` 需按 `d` 重置后取 max，此处只展示拼接下标的关键两行。）

## 复杂度
时间 O(n²)：外层枚举 n+1 个删除位，内层扫 n 个分割位，gcd 已预处理好。
空间 O(n)：`pre`、`suf` 两个长度 n 的数组，无其他额外结构。

## 易错点
- `nums = [2,4]` 时若忘了「长度为 1 的 arr 没有分割位」，删一个元素后 m=1，内层 `range(m-1)` 为空得 0，但若写成 `range(m)` 会误判出 1 个有效位。
- 删除下标 `d` 后，arr 的第 `i` 位对应原数组的 `i`（`i < d`）或 `i+1`（`i >= d`）；若统一用 `pre[i]` 不偏移，`nums = [10,30,15,10]`、`d = 0` 时左 gcd 会错取成 10 而非 30，导致漏算。

## 如果面试官追问
若 n 放大到 10^5 怎么办？答：不能枚举删除位，改为只枚举「不删」和「删掉使全局 gcd 变化的少数候选位」，配合前后缀 gcd 降到 O(n log V)。
