## 一句话思路
用长度 4 的数组 `slots` 存三种车位余量，`addCar` 先查后减，O(1) 完成。

## 怎么做
1. 构造时把 `big, medium, small` 依次放进 `slots[1..3]`，`slots[0]` 留空，让 `carType` 直接当下标。
2. `addCar(carType)` 先判断 `slots[carType] == 0`，是则直接返回 `False`，不做任何减法。
3. 否则 `slots[carType] -= 1` 并返回 `True`。

以官方示例 `[1, 1, 0]` 为例：初始 `slots = [0, 1, 1, 0]`。第 3 次调用 `addCar(3)` 时 `slots[3]` 已是 0，命中第 2 步直接返回 `False`，`slots` 保持不变；第 4 次 `addCar(1)` 时 `slots[1]` 在第一次调用后已从 1 减到 0，同样返回 `False`。两次失败都没有误减，这是「先查后减」顺序带来的。

```python
def __init__(self, big, medium, small):
    self.slots = [0, big, medium, small]

def addCar(self, carType):
    if self.slots[carType] == 0:
        return False
    self.slots[carType] -= 1
    return True
```

关键就两行：`slots[carType] == 0` 的守卫，和守卫之后的 `-= 1`。下标对齐省掉了 `if carType == 1 / elif == 2` 的分支。

## 复杂度
时间：每次 `addCar` O(1)，与车位总数、调用次数无关。
空间：额外只开 `slots` 这 4 个整数，O(1)。

## 易错点
- 输入 `[0, 0, 0]` 后连续 `addCar(1)`：若写成先 `-= 1` 再判断 `< 0`，`slots[1]` 会变成 -1，第二次调用仍返回 `True`。正确做法是先判 `== 0` 再减，保证余量永不为负。
- 输入 `carType` 为 1/2/3 而数组按 `[big, medium, small]` 从 0 开始存：若直接 `slots[carType]` 会整体错位一格，`addCar(1)` 扣的是中车位。正确做法是构造时前置一个占位 0，让下标与 `carType` 对齐。

## 如果面试官追问
追问：若车位种类扩到 10^5 种、`carType` 是任意编号怎么办？
答：改用字典 `defaultdict(int)` 存余量，`addCar` 仍是 O(1)，空间随实际出现的类型数增长。
