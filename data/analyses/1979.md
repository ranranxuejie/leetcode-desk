## 一句话思路
先扫一遍取 `min(nums)` 和 `max(nums)`，再对这两个数跑欧几里得辗转相除。

## 怎么做
1. 一次遍历同时维护 `lo` 和 `hi`，别用 `sorted`，`O(n log n)` 没必要。
2. 对 `lo, hi` 跑辗转相除：`while lo: lo, hi = hi % lo, lo`。
3. 循环结束时 `hi` 就是答案。

拿示例 1 `nums = [2,5,6,9,10]` 走一遍：遍历后 `lo = 2`、`hi = 10`。第一轮 `10 % 2 = 0`，于是 `lo, hi = 0, 2`；`lo` 为 0 退出，返回 `hi = 2`。示例 2 里 `lo = 3`、`hi = 8`：`8 % 3 = 2` → `(2, 3)`；`3 % 2 = 1` → `(1, 2)`；`2 % 1 = 0` → `(0, 1)`，返回 1。

```python
lo, hi = min(nums), max(nums)
while lo:
    lo, hi = hi % lo, lo
return hi
```

关键点：`lo` 和 `hi` 的赋值必须同时完成，写成 `lo = hi % lo` 再 `hi = lo` 就串了。另外 `min`/`max` 各扫一遍是 `2n`，合并成一个 `for` 循环也行，但 `n ≤ 1000` 时没必要为常数较劲。

## 复杂度
时间：`O(n + log(max))`，`n` 来自找最值，`log` 来自辗转相除的轮数。
空间：`O(1)`，只开了 `lo`、`hi` 两个变量。

## 易错点
- 输入 `[3,3]` → 若先写 `while lo and hi` 或对 `lo == hi` 特判漏掉，会返回 0 或死循环 → 正确做法是只判 `while lo`，`lo == hi` 时第一轮 `hi % lo == 0` 自然返回 `hi`，示例 3 得 3。
- 输入 `[7,5,6,8,3]` → 若误以为答案是「所有元素的 GCD」而去逐个 `gcd` 累乘，会得到 `gcd(7,5,6,8,3) = 1` 碰巧对，但换成 `[4,6,8]` 就错成 2（正确答案是 `gcd(4,8) = 4`）→ 只对 `min` 和 `max` 两个数求 GCD。

## 如果面试官追问
问：如果要求返回「数组中任意两数的最大 GCD」怎么办？
答：不能只看最值，需对每个数的因子计数，取出现次数 ≥ 2 的最大因子，复杂度升到 `O(n√max)`。
