## 一句话思路
用长度剪枝 + 26 格计数数组，逐字符加减后全零即互为重排。

## 怎么做
1. 先比 `len(s1)` 与 `len(s2)`，不等直接返回 `False`。
2. 开长度 26 的 `cnt`，遍历 `s1` 做 `cnt[ord(c) - 97] += 1`。
3. 遍历 `s2` 做 `cnt[ord(c) - 97] -= 1`，任一项变负立刻返回 `False`。
4. 全部走完返回 `True`（长度相等时负项必伴随正项，故无需再扫一遍）。

以 `s1 = "abc", s2 = "bca"` 为例：第 2 步后 `cnt[0]=1, cnt[1]=1, cnt[2]=1`，其余 23 格为 0；第 3 步依次减 `b`、`c`、`a`，结束时 26 格全为 0，返回 `True`。换成 `s2 = "bad"`，减到 `d` 时 `cnt[3]` 从 0 变 -1，第 3 步当场返回 `False`，不必等循环结束。

```python
if len(s1) != len(s2):
    return False
cnt = [0] * 26
for c in s1:
    cnt[ord(c) - 97] += 1
for c in s2:
    i = ord(c) - 97
    cnt[i] -= 1
    if cnt[i] < 0:
        return False
return True
```

第 3 步的提前返回是本题唯一值得写的优化点：它把 `"abc"` vs `"bad"` 的判定从扫完 3 个字符压到第 3 个字符就结束，且省掉末尾一次 `all(x == 0 for x in cnt)` 的 26 次比较。

## 复杂度
时间 O(n)：n 为 `len(s1)`，两次遍历各 O(n)，26 是常数不计。
空间 O(1)：`cnt` 固定 26 个整数，与输入长度无关。

## 易错点
- 输入 `s1 = "", s2 = ""` → 若先写 `s1[0]` 或假设非空会抛 `IndexError` → 正确做法是先做长度比较，两个空串长度相等、`cnt` 全零，直接返回 `True`。
- 输入 `s1 = "abc", s2 = "ab"` → 只做计数不先比长度时，`cnt` 里 `c` 那格残留 1，若末尾只检查「没有负项」就会误判 `True` → 正确做法是长度不等立刻 `False`，或末尾用 `all(x == 0 for x in cnt)` 而非只查负值。

## 如果面试官追问
若字符集扩到全部 Unicode，26 格数组怎么办？答：换 `collections.Counter(s1) == Counter(s2)`，时间仍 O(n)，空间随不同字符数增长。
