## 一句话思路
先滑窗求每个长度 k 子数组的和，再用前缀最优 + 后缀最优夹出中间块，O(n) 枚举三段。

## 怎么做
1. 用滑动窗口算出 `sums[i]`（起点 i 的长度 k 子数组和），窗口右移时 `sums[i] = sums[i-1] - nums[i-1] + nums[i+k-1]`。
2. 正扫一遍得 `left[i]`：`[0..i]` 内 `sums` 最大的起点，相等时保留更小的下标（保证字典序最小）。
3. 反扫一遍得 `right[i]`：`[i..]` 内 `sums` 最大的起点，相等时同样保留更小的下标。
4. 枚举中间块起点 `j` 从 `k` 到 `n-2k`，取 `sums[left[j-k]] + sums[j] + sums[right[j+k]]` 最大者。

以示例 1 为例，`nums=[1,2,1,2,6,7,5,1]`，`k=2`，`sums=[3,3,3,8,13,12,6]`。`left=[0,0,0,3,4,4,4]`，`right=[4,4,4,4,4,5,6]`。枚举 `j=3`：`sums[0]+sums[3]+sums[5]=3+8+12=23`，对应 `[0,3,5]`，最大。

```python
n, m = len(nums), len(nums) - k + 1
sums = [sum(nums[:k])]
for i in range(1, m):
    sums.append(sums[-1] - nums[i-1] + nums[i+k-1])
left = [0] * m
for i in range(1, m):
    left[i] = i if sums[i] > sums[left[i-1]] else left[i-1]
right = [0] * m
right[-1] = m - 1
for i in range(m-2, -1, -1):
    right[i] = i if sums[i] >= sums[right[i+1]] else right[i+1]
best, ans = -1, None
for j in range(k, m - k):
    a, c = left[j-k], right[j+k]
    if sums[a] + sums[j] + sums[c] > best:
        best, ans = sums[a] + sums[j] + sums[c], [a, j, c]
```

## 复杂度
时间 O(n)：滑窗、两次扫描、一次枚举各 O(n)。
空间 O(n)：`sums`、`left`、`right` 三个长度约 n 的数组。

## 易错点
- 相等时取下标大的 → 示例 2 中 `sums` 全为 3，`left`/`right` 若用 `>=` 会取到靠后的起点，输出 `[0,2,6]` 之类而非字典序最小的 `[0,2,4]`；正扫用严格 `>`、反扫用 `>=` 才能压住下标。
- 枚举 `j` 的边界写成 `range(k, m-k+1)` → 当 `j = m-k` 时 `right[j+k]` 越界；上界必须是 `m-k`（开区间），保证 `j+k <= m-1`。

## 如果面试官追问
若要求四段不重叠最大和？答：把 `left`/`right` 换成二维 DP，`dp[t][i]` 表示前 i 个位置取 t 段的最优，多一维 O(4n)。
