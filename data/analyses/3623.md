## 一句话思路
按 y 分组统计每层点数，枚举两条水平线，用组合数相乘累加，再减去退化成平行四边形的重复计数。

## 怎么做
1. 用哈希表 `cnt[y]` 统计每个 y 上有多少个点，因为水平边只能来自同一 y 的两个点。
2. 对每对不同的 y1 < y2，两条水平边各选 2 点，贡献 `C(cnt[y1],2) * C(cnt[y2],2)`。
3. 但这样会把「两组对边都水平」的平行四边形算两次（上下各算一次），需要减去。
4. 减法是：对每个 y 层，枚举该层所有点对，用 `(x1+x2, y1+y2)` 作为对角线中点键去重计数，再按组合数扣掉。

以示例 1 为例：`cnt = {0:3, 2:2}`，只有一对 y，贡献 `C(3,2)*C(2,2) = 3*1 = 3`，无平行四边形，答案 3。

```python
from collections import defaultdict
from math import comb

cnt = defaultdict(int)
for x, y in points:
    cnt[y] += 1

ys = list(cnt)
ans = 0
for i in range(len(ys)):
    for j in range(i + 1, len(ys)):
        ans += comb(cnt[ys[i]], 2) * comb(cnt[ys[j]], 2)

# 减去平行四边形重复：按层枚举点对，用中点键去重
mid = defaultdict(int)
by_y = defaultdict(list)
for x, y in points:
    by_y[y].append(x)
for y, xs in by_y.items():
    for a in range(len(xs)):
        for b in range(a + 1, len(xs)):
            mid[(xs[a] + xs[b], 2 * y)] += 1
for v in mid.values():
    ans -= comb(v, 2)
```

## 复杂度
时间：O(n + Y² + Σ cnt[y]²)，Y 为不同 y 的层数，最坏 O(n²)。
空间：O(n)，存 `cnt`、`by_y`、`mid` 三张哈希表。

## 易错点
- 输入 `[[0,0],[1,0],[0,1],[1,1]]` → 若只算 `C(2,2)*C(2,2)=1` 会漏减平行四边形，实际该四边形被上下两条水平线各算一次，正确结果是 1-1=0。
- 输入 `[[1,0],[2,0],[3,0],[2,2],[3,2]]` → 若把 `mid` 键写成 `(x1+x2, y1+y2)` 而非 `(x1+x2, 2*y)`，不同 y 层的中点会碰撞，导致多减，正确做法是键里带 `2*y` 或直接用 `(x1+x2, y)`。

## 如果面试官追问
问：若 points 规模到 10^5 且 y 层很多，怎么优化？
答：枚举 y 对是 O(Y²) 瓶颈，可改为按中点键聚合后统一算，或利用坐标范围做桶排序降维。
