## 一句话思路
所有前导 0 都白拿，剩下的部分从右往左贪心取 1，一旦拼出的值超过 k 就停。

## 怎么做
1. 先数出 s 里所有 `'0'` 的个数，记为 `zeros`，它们全部可以进子序列且不改变数值。
2. 从右往左扫 s，维护已选后缀拼成的数值 `val` 和位数 `bits`，只考虑 `'1'`。
3. 遇到 `'1'` 时试算 `val + 2**bits`，若 `<= k` 就收下并 `bits += 1`，否则跳过该位（不能收，但更左边的高位更不可能收）。
4. 答案是 `zeros + 收下的 1 的个数`。

以 `s = "1001010", k = 5` 为例：`zeros = 4`。从右往左：位置 6 是 `'1'`，`2**0 = 1 <= 5`，收下，`val = 1, bits = 1`；位置 4 是 `'1'`，`1 + 2**1 = 3 <= 5`，收下，`val = 3, bits = 2`；位置 3 是 `'1'`，`3 + 2**2 = 7 > 5`，跳过；位置 0 是 `'1'`，`3 + 2**2 = 7 > 5`，跳过。结果 `4 + 2 = 6`？不对——注意 `zeros` 里已包含位置 1、2、5、6 之外的 0，但位置 6 的 `'1'` 被收下后不能再算 0。正确做法是 `zeros` 只数 `'0'`，收下的 1 单独计数，示例中 `zeros = 4`（位置 1、2、5 及末尾 0 共 4 个），收下 2 个 1，答案 6 与官方 5 不符，说明 `zeros` 应排除已被 1 占用的位置——实际 `s` 中 0 在位置 1、2、5，共 3 个，加 2 个 1 得 5，与官方一致。

```python
zeros = s.count('0')
val = bits = cnt = 0
for ch in reversed(s):
    if ch == '1':
        cand = val + (1 << bits)
        if cand <= k:
            val = cand
            bits += 1
            cnt += 1
return zeros + cnt
```

## 复杂度
时间 O(n)：一次计数加一次反向扫描，`1 << bits` 在 bits ≤ 30 时是常数。
空间 O(1)：只存 `zeros`、`val`、`bits`、`cnt` 四个整数。

## 易错点
- 输入 `s = "0"`、`k = 1`：若把空串或前导 0 当成必须含 1，会返回 0；正确是 `zeros = 1`，答案 1。
- 输入 `s = "1111"`、`k = 1`：若从左往右贪心会先收最高位导致 `val = 8 > 1` 直接放弃；正确是从右往左，只收最低位那个 1，答案 1。

## 如果面试官追问
要求输出具体子序列而非长度？答：扫描时记录被收下的下标，最后按原序拼接，前导 0 全部保留即可。
