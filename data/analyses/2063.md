## 一句话思路
每个元音字符对答案的贡献是它被多少个子串包含，即 `(i+1)*(n-i)`，逐位累加即可。

## 怎么做
1. 设 `n = len(word)`，答案 `ans = 0`。
2. 遍历下标 `i` 和字符 `c`，若 `c in "aeiou"` 则累加贡献。
3. 贡献公式：左端点可取 `0..i` 共 `i+1` 种，右端点可取 `i..n-1` 共 `n-i` 种，子串数 `(i+1)*(n-i)`。
4. 返回 `ans`。

以 `word = "aba"`、`n = 3` 为例：`i=0` 是 `'a'`，贡献 `1*3 = 3`；`i=1` 是 `'b'` 跳过；`i=2` 是 `'a'`，贡献 `3*1 = 3`；`ans = 6`，与示例一致。

```python
n = len(word)
ans = 0
vowels = set("aeiou")
for i, c in enumerate(word):
    if c in vowels:
        ans += (i + 1) * (n - i)
return ans
```

关键中间值再核对一次 `"abc"`：`i=0` 的 `'a'` 贡献 `1*3 = 3`，`i=1`、`i=2` 非元音，`ans = 3`，正确。

## 复杂度
时间：O(n)，一次遍历，每个字符做一次集合查询。
空间：O(1)，只开了长度 5 的 `vowels` 集合和几个整数。

## 易错点
- 输入 `word = "a"`（`n = 1`）→ 若把贡献写成 `i*(n-i)` 会得 0 → 正确是 `(i+1)*(n-i) = 1*1 = 1`，左端点必须含 `i` 本身。
- 输入 `word = "noosabasboosa"`（长 13，答案 237）→ 若用 `2**31 - 1` 之外的窄类型或中途取模会错 → Python 整数天然不溢出，直接累加 `ans` 即可，不要做任何截断。

## 如果面试官追问
问：若要求返回每个子串元音数的总和模 `10**9+7`？
答：累加时每步 `ans = (ans + (i+1)*(n-i)) % (10**9+7)`，其余不变。
