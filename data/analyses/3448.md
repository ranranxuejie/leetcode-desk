## 一句话思路
按末位数字 d 分类，用「前缀余数计数」统计以每个位置结尾、能被 d 整除的子串数，d∈{1..9} 分别做一遍。

## 怎么做
1. 枚举末位数字 d 从 1 到 9，跳过 d=0 的位置（末位为 0 的子串不计）。
2. 对固定 d，从左往右扫，维护前缀值 `pre = (pre*10 + int(c)) % d`，以及 `cnt[r]` = 之前出现过余数 r 的前缀个数，初始 `cnt[0]=1`。
3. 扫到位置 i 且 `s[i]==str(d)` 时，以 i 结尾且能被 d 整除的子串数 = `cnt[pre]`（因为 `(pre - pre_j) % d == 0`），累加进答案；随后把当前 `pre` 计入 `cnt`。
4. 注意 `cnt` 要在每个 d 上重置，且计入 `pre` 的时机在统计之后，避免把空串算进去。

以 `s="12936"`、d=3 为例：扫到 i=2（字符 '9'）时 `pre = 129 % 3 = 0`，`cnt[0]` 此时为 1（空前缀），得 1 个（"129"）；继续扫到 i=4（'6'）时 `pre = 12936 % 3 = 0`，`cnt[0]` 已含空前缀和 i=2 后的前缀，得 2 个（"12936"、"936"）。d=3 共 3 个。

```python
ans = 0
for d in range(1, 10):
    cnt = [0] * d
    cnt[0] = 1
    pre = 0
    for ch in s:
        pre = (pre * 10 + int(ch)) % d
        if int(ch) == d:
            ans += cnt[pre]
        cnt[pre] += 1
```

## 复杂度
时间：O(9n)，每个 d 扫一遍 s，n 为串长。
空间：O(9)，每个 d 开一个长度 d 的计数数组，最大 9。

## 易错点
- 输入 `s="1010101010"`：若把 d=0 也纳入循环，末位为 '0' 的子串会被错误计入（题面明确排除）。正确做法是 `range(1,10)`，且 `int(ch)==d` 判断天然跳过 '0'。
- 输入 `s="5701283"`：若先 `cnt[pre]+=1` 再统计，会把当前空后缀算进去，多出 1 个。正确顺序是先 `ans += cnt[pre]` 再更新计数，保证 `cnt` 只含 i 之前的前缀。

## 如果面试官追问
若 s 长度扩到 10^6 且要求 O(n) 而非 O(9n)？答：仍可接受，9 是常数；若要真正单遍，需对每个 d 同步维护 9 组余数状态，空间换时间。
