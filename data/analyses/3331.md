## 一句话思路
按原树 DFS，用 `last[26]` 记录当前路径上每种字符最近的祖先，边遍历边把子节点挂到该祖先下，再自底向上累加子树大小。

## 怎么做
1. 先按 `parent` 建邻接表 `children`，因为改父后还要遍历，不能直接用原 `parent` 数组。
2. DFS 时维护 `last[26]`，进入节点 `u` 前先存下 `old = last[s[u]]`，再把 `last[s[u]] = u`。
3. 遍历 `u` 的每个子节点 `v`：若 `old != -1`，说明 `v` 的最近同字符祖先不是 `u`，把 `v` 从 `children[u]` 挪到 `children[old]`。
4. 回溯时恢复 `last[s[u]] = old`，DFS 结束后对改过的树再跑一次后序累加 `size[u] = 1 + sum(size[v])`。

以示例 1 为例：`parent = [-1,0,0,1,1,1]`，`s = "abaabc"`。DFS 到节点 3（字符 `'a'`）时，路径上 `last['a'] = 0`，`old = 0`，于是把节点 3 从 `children[1]` 挪到 `children[0]`，最终 `answer[0] = 6`。

```python
def dfs(u):
    c = ord(s[u]) - 97
    old = last[c]
    last[c] = u
    for v in list(children[u]):
        if old != -1:
            children[u].remove(v)
            children[old].append(v)
        dfs(v)
    last[c] = old
```

## 复杂度
时间 O(n)：建树、DFS 改父、后序累加各 O(n)，`last` 只有 26 项。
空间 O(n)：`children` 存 n-1 条边，递归栈最深 n。

## 易错点
1. 遍历 `children[u]` 时直接 `for v in children[u]` 并 `remove(v)` → 边遍历边改列表会漏节点或抛异常 → 用 `list(children[u])` 拷贝一份再遍历。
2. 忘记回溯 `last[c] = old` → 兄弟子树会看到错误祖先，示例 2 中节点 2 会被挂到节点 4 而非节点 1 → 进入时存 `old`，退出时恢复。

## 如果面试官追问
若要求输出每个节点改父后的新父亲数组？答：DFS 时把 `v` 的新父 `old` 记到 `new_parent[v]`，最后返回该数组即可。
