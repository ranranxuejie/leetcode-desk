## 一句话思路
排序后回溯，同层跳过相同值去重，每层从 `start` 往后选，保证每个数只用一次。

## 怎么做
1. 先 `candidates.sort()`，让相同数字相邻，去重才有依据。
2. 回溯参数 `(start, path, remain)`，`remain == 0` 时把 `path` 拷进结果。
3. 循环 `i` 从 `start` 到末尾：若 `i > start and candidates[i] == candidates[i-1]` 就 `continue`，这是同层去重；若 `candidates[i] > remain` 直接 `break`（已排序）。
4. 选 `candidates[i]` 后递归传 `i + 1`（不是 `i`），因为每个数只能用一次。

以示例 1 `candidates = [10,1,2,7,6,1,5], target = 8` 为例：排序后 `[1,1,2,5,6,7,10]`。第一层选第一个 `1`（下标 0），第二层 `start = 1`，此时 `i = 1` 的 `1` 与 `candidates[0]` 相等但 `i > start` 成立吗？`i = 1, start = 1`，`i > start` 为假，所以**允许**再选这个 `1`，得到 `[1,1,...]`，`remain = 6`，继续选 `6` 命中 `[1,1,6]`。回到第一层选下标 1 的 `1` 时，`i = 1 > start = 0` 且 `candidates[1] == candidates[0]`，跳过，避免重复的 `[1,2,5]` 等。

```python
def dfs(start, path, remain):
    if remain == 0:
        res.append(path[:])
        return
    for i in range(start, len(candidates)):
        if i > start and candidates[i] == candidates[i - 1]:
            continue
        if candidates[i] > remain:
            break
        path.append(candidates[i])
        dfs(i + 1, path, remain - candidates[i])
        path.pop()
```

关键点：`i > start` 而非 `i > 0`。用 `i > 0` 会把 `[1,1,6]` 这种「同一层不同位置但值相同、且是首次深入」的合法组合误杀。

## 复杂度
时间：O(2^n · n)，n 为 `candidates` 长度，每个元素选或不选，每个叶子拷贝长度 O(n)。
空间：O(n) 递归栈 + O(n) 的 `path`，结果集不计入。

## 易错点
- 输入 `[1,1,6], target=8`：若去重条件写成 `i > 0 and candidates[i]==candidates[i-1]`，会把第二个 `1` 也跳过，漏掉 `[1,1,6]`。正确用 `i > start`，只跳过同层重复。
- 输入 `[2,5,2,1,2], target=5`：若递归传 `i` 而非 `i+1`，会重复使用同一个 `2` 得到 `[2,2,2,...]` 之类非法解。正确传 `i+1`，且排序后 `break` 依赖 `candidates[i] > remain` 的单调性。

## 如果面试官追问
问：若允许每个数无限次使用怎么改？答：递归传 `i` 而非 `i+1`，同时去掉 `break` 前的同层去重逻辑改为值去重即可。
