## 一句话思路
对每个查询区间排序后检查相邻差是否全等于 `a[1]-a[0]`，因为重排成等差数列等价于排序后等差。

## 怎么做
1. 遍历每个查询 `i`，切片 `a = sorted(nums[l[i]:r[i]+1])`。
2. 取基准差 `d = a[1] - a[0]`，再扫一遍 `a[2:]` 检查 `a[j]-a[j-1] == d`。
3. 全部相等则 `True`，否则 `False`。

以示例 1 第 1 个查询为例：`nums[0:4] = [4,6,5,9]`，排序得 `a = [4,5,6,9]`，`d = 1`；检查 `6-5=1` 通过，`9-6=3 != 1`，返回 `False`。而第 0 个查询 `[4,6,5]` 排序为 `[4,5,6]`，`d=1`，`6-5=1`，返回 `True`。

```python
ans = []
for i in range(len(l)):
    a = sorted(nums[l[i]:r[i] + 1])
    d = a[1] - a[0]
    ok = True
    for j in range(2, len(a)):
        if a[j] - a[j - 1] != d:
            ok = False
            break
    ans.append(ok)
```

关键点：排序后等差是**充要条件**——若原集合能重排成等差，排序后必是同一公差序列；反之排序后等差则原集合可重排成等差。区间长度至少为 2（`l[i] < r[i]`），所以 `a[1]` 一定存在，不会越界。

## 复杂度
时间：每个查询排序 `O(k log k)`，`k = r[i]-l[i]+1`，总 `O(m·n log n)`。
空间：每次切片加排序副本 `O(k)`，答案列表 `O(m)`。

## 易错点
- 区间长度恰为 2 时（如 `l=[1], r=[2]`，子数组 `[-9,-3]`），任何两元素都构成等差，必须返回 `True`；若循环从 `j=1` 开始或误判 `d` 需要非零，会错成 `False`。正确做法是 `d` 允许为 0 或任意值，两元素直接通过。
- 子数组含重复值如 `[7,7,7,7]`，`d = 0`；若把 `d == 0` 当作非法提前返回 `False`，会错判。正确做法是照常比较 `a[j]-a[j-1] == 0`，全相等即 `True`。

## 如果面试官追问
问：n、m 都放大到 10^5 怎么办？答：预处理前缀哈希或对每个查询用「最大值-最小值能被 k-1 整除 + 集合去重」判定，避免逐查询排序。
