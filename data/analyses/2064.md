## 一句话思路
对答案 x 二分，用 `sum(ceil(q/x))` 判断能否塞进 n 间店，可行性随 x 单调。

## 怎么做
1. 二分下界 `lo = 1`，上界 `hi = max(quantities)`（一间店最多装一整种商品）。
2. 对候选 `x`，每种商品 `q` 需要 `(q + x - 1) // x` 间店，累加得 `need`。
3. `need <= n` 说明 x 可行，收缩 `hi = mid`；否则 `lo = mid + 1`。
4. 循环结束返回 `lo`。

以 `n = 6, quantities = [11,6]` 为例：`mid = 3` 时，11 需要 `(11+2)//3 = 4` 间，6 需要 `(6+2)//3 = 2` 间，`need = 6 <= 6` 可行，`hi` 收到 3；再试 `mid = 2`，`need = 6 + 3 = 9 > 6` 不可行，`lo` 抬到 3，输出 3。

```python
lo, hi = 1, max(quantities)
while lo < hi:
    mid = (lo + hi) // 2
    need = sum((q + mid - 1) // mid for q in quantities)
    if need <= n:
        hi = mid
    else:
        lo = mid + 1
return lo
```

关键点：`need` 是「最少需要几间店」，只要不超过 n，剩下的空店分配 0 件即可，规则允许。

## 复杂度
时间：O(m log(max(quantities)))，m 来自每次求和，log 来自二分。
空间：O(1)，只开了 lo/hi/mid/need 几个变量。

## 易错点
- `n = 1, quantities = [100000]`：若把上界写成 `sum(quantities) // n` 或某个固定值，可能小于 `max(quantities)`，导致 lo 起点就不可行、答案偏小。正确做法是 `hi = max(quantities)`，因为一间店最多装一整种商品。
- `n = 7, quantities = [15,10,10]`：若用 `q // mid` 而不是 `(q + mid - 1) // mid`，15 在 mid=5 时算成 3 间没问题，但 11 在 mid=3 时 `11//3 = 3` 会漏掉余数 2，`need` 偏小、误判可行。正确做法是向上取整 `(q + mid - 1) // mid`。

## 如果面试官追问
要求输出具体分配方案怎么办？答：二分定下 x 后，对每种商品贪心切成 `ceil(q/x)` 份（前几份 x 件、最后一份余数），依次填进商店即可。
