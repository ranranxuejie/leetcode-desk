## 一句话思路
逐位构造余数 `rem = (rem * 10 + 1) % k`，用哈希表记录已出现的余数，一旦重复说明进入循环、无解。

## 怎么做
1. 从 `rem = 1 % k`、`length = 1` 出发，先判 `rem == 0` 直接返回 1。
2. 循环中每步 `rem = (rem * 10 + 1) % k`、`length += 1`，若 `rem == 0` 返回 `length`。
3. 用 `seen` 集合存出现过的余数，若新 `rem` 已在集合中，说明后续余数会无限循环，返回 -1。

以 `k = 7` 为例：`rem` 依次为 1、4（11%7）、6（111%7）、5、2、0，第 6 步命中 0，返回 6。注意第 2 步 `rem=4` 时 `length=2`，对应 11，说明长度与余数同步推进。

```python
seen = set()
rem = 1 % k
length = 1
while rem != 0:
    if rem in seen:
        return -1
    seen.add(rem)
    rem = (rem * 10 + 1) % k
    length += 1
return length
```

关键点：只维护余数不维护大整数，`k ≤ 10^5` 时余数最多 10^5 种，循环必然在有限步内终止或重复。

## 复杂度
时间：O(k)，余数状态最多 k 个，每步 O(1)。
空间：O(k)，`seen` 集合最多存 k 个余数。

## 易错点
- `k = 2` 或 `k = 5` → 若只写 `while rem != 0` 不加 `seen` 判重，会死循环（余数永远在 1 和 0 之间？实际 1%2=1，之后 (1*10+1)%2=1 恒为 1）→ 必须靠 `seen` 检测到 1 重复后返回 -1。
- 初始 `rem = 1 % k` 而非 `rem = 1` → 当 `k = 1` 时（虽约束 k≥2，但若放宽）`1 % 1 = 0` 应直接返回 1，写成 `rem = 1` 会多跑一轮。

## 如果面试官追问
若要求输出 n 本身而非位数？答：余数相同则后续全同，可在 `seen` 里存 `(rem, length)`，命中 0 时按长度拼 `'1' * length` 即可，但 n 可能长达 k 位，需用字符串。
