## 一句话思路
用 Dijkstra 求最短路，边权是「等到房间开启再走 1 秒」，因为等待时间随到达时刻单调不减，贪心出堆即最优。

## 怎么做
1. 把每个格子看成节点，`dist[i][j]` 初始化为无穷，`dist[0][0] = 0`，堆里放 `(0, 0, 0)`。
2. 出堆时若 `t > dist[i][j]` 就跳过（惰性删除），否则向四邻松弛。
3. 松弛公式是本题核心：从 `(i,j)` 在时刻 `t` 去邻居 `(ni,nj)`，到达时刻为 `max(t, moveTime[ni][nj]) + 1`。
4. 第一次弹出 `(n-1, m-1)` 时返回其时间。

拿示例 1 `moveTime = [[0,4],[4,4]]` 走一遍关键那步：从 `(0,0)` 时刻 0 出发，去 `(1,0)` 得 `max(0,4)+1 = 5`，去 `(0,1)` 得 `max(0,4)+1 = 5`；堆里先弹 5 的 `(1,0)`，再去 `(1,1)` 得 `max(5,4)+1 = 6`，与输出 6 对上。

```python
import heapq
n, m = len(moveTime), len(moveTime[0])
dist = [[float('inf')] * m for _ in range(n)]
dist[0][0] = 0
pq = [(0, 0, 0)]
while pq:
    t, i, j = heapq.heappop(pq)
    if t > dist[i][j]:
        continue
    if (i, j) == (n - 1, m - 1):
        return t
    for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
        ni, nj = i + di, j + dj
        if 0 <= ni < n and 0 <= nj < m:
            nt = max(t, moveTime[ni][nj]) + 1
            if nt < dist[ni][nj]:
                dist[ni][nj] = nt
                heapq.heappush(pq, (nt, ni, nj))
```

## 复杂度
时间：O(n·m·log(n·m))，堆里最多 n·m 个状态，每次 push/pop 是 log(n·m)。
空间：O(n·m)，`dist` 表加堆，堆最坏存 n·m 条。

## 易错点
- 写成 `t + 1` 而漏掉 `max(t, moveTime[ni][nj])`：示例 1 会算出 2 而不是 6，因为没等房间在 t=4 开启。正确是到达时刻取 `max(t, moveTime[ni][nj]) + 1`。
- 把 `moveTime[0][0]` 也当等待条件：起点在 t=0 已可站，若写成 `max(0, moveTime[0][0])` 再出发，示例 1 起点是 0 没事，但若起点非 0 会凭空多等。正确是 `dist[0][0] = 0`，只在进入邻居时查它的 `moveTime`。

## 如果面试官追问
问：若允许斜向移动或移动耗时不为 1 怎么办？
答：边权改成对应耗时，松弛式换成 `max(t, moveTime[ni][nj]) + cost`，Dijkstra 框架不变。
