## 一句话思路
从右往左扫 `s`，遇 `0` 记 1 步（除 2），遇 `1` 记 2 步（加 1 再除 2），用 `carry` 模拟进位。

## 怎么做
1. 从 `s[-1]` 扫到 `s[1]`，维护进位 `carry`，当前位真值 `bit = int(s[i]) + carry`。
2. `bit == 0` 时只需除 2，`steps += 1`，`carry = 0`。
3. `bit == 1` 时先加 1 再除 2，`steps += 2`，`carry = 1`（加 1 产生的进位继续往左传）。
4. `bit == 2`（原本是 1 且已有进位）等价于加 1 后变 0 并进位，`steps += 1`，`carry = 1`。

以 `s = "1101"` 为例：`i=3` 位是 `1`，`bit=1`，`steps=2`、`carry=1`；`i=2` 位是 `0`，`bit=1`，`steps=4`、`carry=1`；`i=1` 位是 `1`，`bit=2`，`steps=5`、`carry=1`。扫完剩最高位 `s[0]='1'`，若 `carry==1` 说明它被加成了 `10`，还要再除一次，`steps=6`，与答案一致。

```python
steps, carry = 0, 0
for i in range(len(s) - 1, 0, -1):
    bit = int(s[i]) + carry
    if bit == 0:
        steps += 1
        carry = 0
    elif bit == 1:
        steps += 2
        carry = 1
    else:
        steps += 1
        carry = 1
if carry:
    steps += 1
```

## 复杂度
时间 O(n)：`n = len(s)`，每个字符扫一次。
空间 O(1)：只开了 `steps`、`carry`、`bit` 三个整数。

## 易错点
- `s = "1"` → 循环 `range(0, 0, -1)` 不执行，若忘了 `carry` 初值判断会返回 0 正确，但若写成先 `steps=1` 再减就错成 1；正确做法是初值 `steps=0`，`carry=0` 时直接返回 0。
- `s = "11"`（3）→ 只按「末位是 1 就 +2」会得 2，漏掉最高位进位；实际 3→4→2→1 是 3 步，正确做法是循环结束后 `if carry: steps += 1`，因为最高位 `1` 被进位变成 `10` 还需一次除 2。

## 如果面试官追问
问：若 `s` 长度到 10^5 且要求输出每步的二进制串？答：仍用 `carry` 从右往左模拟，但每步要维护可变字符数组，时间 O(n^2)，可改用双端队列从低位弹出。
