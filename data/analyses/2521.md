## 一句话思路
不乘总积（会爆），对每个 `nums[i]` 单独试除分解质因数，把质因数丢进 set，答案就是 set 大小。

## 怎么做
1. 建一个空 `set` 叫 `factors`，用来存出现过的质因数。
2. 对 `nums` 里每个 `x`，从 `d = 2` 开始试除：`while x % d == 0` 就把 `d` 加进 `factors` 并 `x //= d`。
3. 内层除完后 `d += 1`，直到 `d * d > x`；循环结束时若 `x > 1`，说明剩下的是一个大质数，也加进 `factors`。
4. 返回 `len(factors)`。

拿示例 1 的 `nums = [2,4,3,7,10,6]` 走一遍：处理 `x = 10` 时，`d = 2` 除一次得 `x = 5`，`factors` 加入 2；`d` 增到 3 时 `3*3 > 5` 退出，剩下 `x = 5 > 1`，把 5 加进去。处理 `x = 4` 时 `d = 2` 连除两次，`factors` 里 2 已存在，set 不增长。最终 `factors = {2,3,5,7}`，返回 4。

```python
factors = set()
for x in nums:
    d = 2
    while d * d <= x:
        if x % d == 0:
            factors.add(d)
            while x % d == 0:
                x //= d
        d += 1
    if x > 1:
        factors.add(x)
return len(factors)
```

关键点：`d * d <= x` 用的是**被除小后的 x**，不是原始值，所以 `x = 10` 时循环到 `d = 3` 就停，不会白跑到 10。

## 复杂度
时间：每个 `nums[i] ≤ 1000`，试除到 `√1000 ≈ 31`，总代价 `O(n · √max(nums))`，n 是数组长度。
空间：set 最多存 168 个 1000 以内的质数，`O(π(max))`，与 n 无关。

## 易错点
- 输入 `nums = [2,4,8,16]` → 若先把总积算出来再分解，`2*4*8*16 = 1024` 还行，但 `10^4` 个 1000 相乘是 30000 位的大数，Python 虽不溢出但分解极慢 → 正确做法是逐元素分解，全程不碰总积。
- 输入 `nums = [7]` 或 `[999983]` 这类大质数 → 若循环写成 `while d * d <= x` 后忘了补 `if x > 1`，7 会被漏掉，返回 0 → 正确做法是循环退出后必检剩余 `x`，它要么是 1 要么是质数。

## 如果面试官追问
问：若 `nums[i]` 上限从 1000 提到 `10^9` 怎么办？
答：单个数试除到 `√10^9 ≈ 31623` 仍可接受；再大就预筛质数表只试质因子，或换 Pollard-Rho。
