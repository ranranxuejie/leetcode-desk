## 一句话思路
逐轮累加，用 `i-1`、`i-2` 是否等于 10 决定本轮乘 1 还是乘 2，两个玩家各扫一遍。

## 怎么做
1. 写一个 `score(arr)` 辅助函数，遍历 `i` 从 0 到 `len(arr)-1`。
2. 判断 `(i >= 1 and arr[i-1] == 10) or (i >= 2 and arr[i-2] == 10)`，成立则加 `2*arr[i]`，否则加 `arr[i]`。
3. 分别算 `s1 = score(player1)`、`s2 = score(player2)`。
4. 比较返回 1 / 2 / 0。

以示例 1 的 `player1 = [5,10,3,2]` 为例：`i=2` 时 `arr[1] == 10` 成立，本轮加 `2*3 = 6`；`i=3` 时 `arr[1] == 10` 仍成立（`arr[2]=3` 不是 10），加 `2*2 = 4`，总分 `5+10+6+4 = 25`。注意 `i=1` 时 `arr[0]=5` 不是 10，所以 10 本身只加一次。

```python
def score(arr):
    s = 0
    for i, x in enumerate(arr):
        if (i >= 1 and arr[i-1] == 10) or (i >= 2 and arr[i-2] == 10):
            s += 2 * x
        else:
            s += x
    return s

s1, s2 = score(player1), score(player2)
return 1 if s1 > s2 else (2 if s2 > s1 else 0)
```

## 复杂度
时间：O(n)，两个数组各扫一遍，n 为数组长度。
空间：O(1)，只用了 `s`、`i`、`x` 几个标量，没有额外数组。

## 易错点
- `player = [10,10,10]` 这类连续满分：若写成「只看前一轮」会漏掉 `i=2` 时 `arr[0]=10` 的加成，正确做法是 `i-1` 和 `i-2` 两个条件用 `or` 连接，任一命中就翻倍。
- 边界 `i=0`、`i=1`：直接写 `arr[i-1]`、`arr[i-2]` 会取到 `arr[-1]`（Python 负索引回绕到末尾），比如 `[3,5,7,6]` 在 `i=0` 时 `arr[-1]=6` 不等于 10 侥幸没事，但 `[3,5,7,10]` 就会在 `i=0` 误判翻倍，必须先判 `i >= 1` / `i >= 2`。

## 如果面试官追问
问：如果规则改成「前一轮或前两轮中**任意一轮**击倒 ≥ 8 个就翻倍」怎么改？
答：把两个 `== 10` 换成 `>= 8`，其余结构不变，仍是 O(n)。
