## 一句话思路
排序后固定第一个数，剩下两数用左右双指针夹逼，跳过重复值保证三元组不重复。

## 怎么做
1. 先 `nums.sort()`，让相同值相邻，双指针和去重都依赖有序。
2. 外层 `i` 从 0 到 n-3 枚举第一个数，`nums[i] > 0` 时直接 break（后面都非负，和不可能为 0）。
3. 内层 `l = i+1`、`r = n-1`，算 `s = nums[i] + nums[l] + nums[r]`：`s < 0` 就 `l += 1`，`s > 0` 就 `r -= 1`，`s == 0` 收下并同时移动两端。
4. 每层移动后跳过与刚用过的值相同的元素。

用示例 `[-1,0,1,2,-1,-4]`，排序得 `[-4,-1,-1,0,1,2]`。`i=0`（-4）时 `l=1,r=5`，`-4+(-1)+2=-3<0`，`l` 一路右移到 5 仍无解。`i=1`（-1）时 `l=2,r=5`：`-1+(-1)+2=0` 收下 `[-1,-1,2]`，`l→3,r→4` 得 `-1+0+1=0` 收下 `[-1,0,1]`。`i=2` 的 -1 与 `i=1` 重复，直接跳过。

```python
nums.sort()
res = []
for i in range(len(nums) - 2):
    if nums[i] > 0:
        break
    if i > 0 and nums[i] == nums[i - 1]:
        continue
    l, r = i + 1, len(nums) - 1
    while l < r:
        s = nums[i] + nums[l] + nums[r]
        if s < 0:
            l += 1
        elif s > 0:
            r -= 1
        else:
            res.append([nums[i], nums[l], nums[r]])
            l += 1
            r -= 1
            while l < r and nums[l] == nums[l - 1]:
                l += 1
```

## 复杂度
时间 O(n²)：排序 O(n log n)，外层 n 次各跑一遍双指针 O(n)。
空间 O(1) 额外（不计结果），排序用原地 sort。

## 易错点
- 输入 `[0,0,0,0]` → 只在外层 `i` 去重、内层不去重，会输出多个 `[0,0,0]` → 命中 `s == 0` 后必须 `l += 1; r -= 1` 再跳过与 `nums[l-1]` 相同的值。
- 输入 `[-2,0,0,2,2]` → 内层只跳 `l` 不跳 `r`，或先跳后移顺序写反，会漏解或重复 → 两端都要跳，且跳之前先各自移动一步。

## 如果面试官追问
问：要求返回下标而不是值怎么办？
答：排序会打乱下标，需先存 `(值, 原下标)` 再排序，去重逻辑改为按下标组合判重。
