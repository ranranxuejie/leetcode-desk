## 一句话思路
把石头分成两堆使重量差最小，答案就是 `sum - 2*best`，用 0/1 背包求不超过 `sum//2` 的最大可达重量。

## 怎么做
1. 记 `total = sum(stones)`，目标堆容量 `half = total // 2`。
2. 定义 `dp[w]` 表示能否用若干石头恰好凑出重量 `w`，初始化 `dp[0] = True`。
3. 对每块石头 `s` 逆序更新 `w` 从 `half` 到 `s`：`dp[w] = dp[w] or dp[w-s]`。
4. 从 `half` 往下找第一个 `dp[w]` 为 `True` 的 `w`，返回 `total - 2*w`。

以 `stones = [2,7,4,1,8,1]` 为例，`total = 23`，`half = 11`。跑完背包后 `dp[11]` 为 `True`（例如 2+8+1），于是答案 `23 - 2*11 = 1`，与示例一致。若 `total` 为奇数，`half` 向下取整，差值自然为奇数，正好对应「剩一块」。

```python
total = sum(stones)
half = total // 2
dp = [False] * (half + 1)
dp[0] = True
for s in stones:
    for w in range(half, s - 1, -1):
        if dp[w - s]:
            dp[w] = True
for w in range(half, -1, -1):
    if dp[w]:
        return total - 2 * w
```

关键在逆序：`w` 从 `half` 递减到 `s`，保证每块石头只用一次；若正序，`dp[w-s]` 可能已被本轮更新过，同一块石头被重复计入，`[2,7,4,1,8,1]` 会算出错误的可达集合。

## 复杂度
时间：`O(n * half)`，`n = len(stones)`，`half = sum(stones)//2 ≤ 1500`。
空间：`O(half)`，只开一个长度 `half+1` 的布尔数组 `dp`。

## 易错点
- 内层循环写成正序 `for w in range(s, half+1)` → `[2,7,4,1,8,1]` 中石头 2 会被反复使用，`dp` 出现虚假可达重量，答案偏小 → 必须逆序 `range(half, s-1, -1)`。
- 直接返回 `dp[half]` 对应的差值而不回退 → `total` 为奇数或 `half` 不可达时（如 `stones=[31,26,33,21,40]`，`total=151`，`half=75`，`dp[75]` 为 `False`）会返回错误值 → 要从 `half` 向下扫描第一个 `True`，得 `w=73`，答案 `151-146=5`。

## 如果面试官追问
问：要输出具体怎么分堆怎么办？
答：再开一个 `parent[w]` 记录凑出 `w` 时最后用的石头下标，从最优 `w` 回溯即可还原两堆。
