## 一句话思路
用单调栈求每个 `arr[i]` 作为最小值能向左、向右延伸的边界，再乘 `(i-left)*(right-i)` 累加。

## 怎么做
1. 从左往右扫，维护一个**严格递增**的栈（存下标），弹出时确定该元素的左边界 `left[i]`。
2. 从右往左扫，维护一个**非严格递增**的栈，弹出时确定右边界 `right[i]`。
3. 对每个 `i`，它作为最小值的子数组个数是 `(i-left[i])*(right[i]-i)`，乘 `arr[i]` 累加。
4. 全程对 `10**9 + 7` 取模。

以 `arr = [3,1,2,4]` 为例：`i=0` 时左边界 `left[0]=-1`，右边界 `right[0]=1`（因为 `arr[1]=1 < 3` 挡住了），贡献 `3 * (0-(-1)) * (1-0) = 3`；`i=1` 的 `1` 左右都无更小值，`left[1]=-1`、`right[1]=4`，贡献 `1 * 2 * 3 = 6`。四个位置分别贡献 3、6、4、4，合计 17。

```python
MOD = 10**9 + 7
n = len(arr)
left, right = [-1] * n, [n] * n
st = []
for i in range(n):
    while st and arr[st[-1]] >= arr[i]:
        st.pop()
    left[i] = st[-1] if st else -1
    st.append(i)
st = []
for i in range(n - 1, -1, -1):
    while st and arr[st[-1]] > arr[i]:
        st.pop()
    right[i] = st[-1] if st else n
    st.append(i)
ans = sum(arr[i] * (i - left[i]) * (right[i] - i) for i in range(n)) % MOD
```

## 复杂度
时间：O(n)，每个下标入栈出栈各一次，两次扫描。
空间：O(n)，`left`、`right` 两个数组加栈。

## 易错点
1. 两侧都用 `>=` 或都用 `>` → 遇到 `arr = [1,1]` 这类重复值，同一个子数组会被两个 `1` 重复计数，答案偏大。正确做法：左扫用 `>=`（弹出相等），右扫用 `>`（保留相等），保证每个子数组只归最左边那个最小值。
2. 边界初值写成 `0` 和 `n-1` → 对 `arr = [3,1,2,4]` 的 `i=0`，`left[0]` 应为 `-1` 而非 `0`，否则 `(i-left[i])` 少算一格，贡献从 3 变 0。正确做法：左边界初值 `-1`、右边界初值 `n`。

## 如果面试官追问
若要求返回所有子数组最小值之和而不取模、`arr` 长度到 `10^5` 且值到 `10^9`？答：Python 大整数直接算，去掉 `% MOD` 即可，复杂度不变。
