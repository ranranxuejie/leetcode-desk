## 一句话思路
每个数 x 独立需要 `f(x)=⌊log₄x⌋+1` 次除 4 才归零，操作可两两配对，故区间答案为 `max(⌈Σf/2⌉, max f)`。

## 怎么做
1. 对单个 x，反复除 4 到 0 的次数就是 `f(x) = x.bit_length()` 对应的四进制位数，即 `(x.bit_length()+1)//2`。
2. 一次操作消耗两个「待除次数」，所以总需求 `S = Σf(x)` 至少要 `⌈S/2⌉` 次操作。
3. 但最大的那个数必须被单独除 `maxf` 次，配对不能减少它，故答案取 `max((S+1)//2, maxf)`。
4. 区间 [l, r] 上按四进制位数分段：位数为 k 的 x 满足 `4^(k-1) ≤ x < 4^k`，每段贡献 `k × 段长`，段数只有约 15 段（r ≤ 1e9）。

以 `queries=[2,6]` 为例：f(2)=1, f(3)=1, f(4)=2, f(5)=2, f(6)=2，S=8，maxf=2，答案 `max(4,2)=4`，与示例一致。

```python
def f(x):
    return (x.bit_length() + 1) // 2

def solve(l, r):
    S = 0
    k = 1
    lo = 1
    while lo <= r:
        hi = min(r, lo * 4 - 1)
        if hi >= l:
            S += k * (hi - max(l, lo) + 1)
        k += 1
        lo *= 4
    return max((S + 1) // 2, f(r))
```

注意 `f(r)` 就是区间内最大需求（f 单调不减），无需再扫一遍。

## 复杂度
时间：每个查询 O(log₄ r) 段，总 O(q log r)，q 为 queries 长度。
空间：O(1)，只用了 S、k、lo 几个标量。

## 易错点
- 只算 `(S+1)//2` 而漏掉 `maxf`：输入 `[1,2]` 时 S=2 得 1 正确，但输入 `[1,4]` 时 S=1+1+2=4 得 2，而 4 单独就要 2 次、且必须独占一次操作，实际仍是 2；换成 `[1,8]` 时 S=1+1+2+2+2+3+3+3=17 得 9，maxf=3，仍取 9——真正翻车的是 `[4,4]` 这类单元素区间，S=2 得 1 但 4 需要 2 次，必须取 max。
- 分段边界写错：用 `lo*4-1` 作段尾、`lo*4` 作下一段头，若写成 `lo*4` 作段尾会把 4 归入位数 1 的段，导致 f(4) 算成 1；正确是位数 k 覆盖 `[4^(k-1), 4^k - 1]`。

## 如果面试官追问
问：若操作改成每次只能选一个数除 4，答案怎么变？
答：配对消失，答案直接是 `Σf(x)`，分段求和逻辑完全不变，只去掉最后的 `max` 与 `⌈S/2⌉`。
