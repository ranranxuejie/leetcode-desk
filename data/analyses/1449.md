## 一句话思路
先 DP 求「恰好花 target 能凑出的最大位数」，再按位从 9 到 1 贪心挑，位数优先于数值。

## 怎么做
1. 定义 `dp[t]` = 恰好花成本 `t` 能凑出的最大位数，`dp[0]=0`，其余 `-inf`。
2. 对每个 `t` 从 1 到 target，枚举 9 个数位，`dp[t] = max(dp[t], dp[t-cost[i]]+1)`。
3. 若 `dp[target] <= 0` 直接返回 `"0"`。
4. 从 `rem=target` 出发，数位 `d` 从 9 递减到 1，只要 `dp[rem-cost[d-1]] == dp[rem]-1` 就选它并 `rem -= cost[d-1]`，重复 `dp[target]` 次。

以示例 1 为例，`cost=[4,3,2,5,6,7,2,5,5]`，`target=9`：数位 7 成本 2，数位 2 成本 3，`dp[9]=4`（三个 7 加一个 2）。贪心时 `rem=9`，先试 9 成本 5，`dp[4]=2` 而 `dp[9]-1=3`，不选；试到 7 成本 2，`dp[7]=3=dp[9]-1`，选 7，`rem=7`，如此三次后 `rem=3`，选 2，得 `"7772"`。

```python
NEG = -10**9
dp = [NEG] * (target + 1)
dp[0] = 0
for t in range(1, target + 1):
    for i in range(9):
        c = cost[i]
        if t >= c and dp[t - c] != NEG:
            dp[t] = max(dp[t], dp[t - c] + 1)
if dp[target] <= 0:
    return "0"
res, rem = [], target
for _ in range(dp[target]):
    for d in range(9, 0, -1):
        c = cost[d - 1]
        if rem >= c and dp[rem - c] == dp[rem] - 1:
            res.append(str(d)); rem -= c; break
return "".join(res)
```

## 复杂度
时间：O(target × 9)，DP 与贪心各扫一遍 target。
空间：O(target)，只开 `dp` 数组和结果串。

## 易错点
- 示例 3 这类 `cost=[2,4,6,2,4,6,4,4,4]`、`target=5`：若把 `dp` 初值设 0 而非 `-inf`，会把「凑不出」误判成 0 位合法，返回空串而非 `"0"`；必须用 `NEG` 哨兵并判 `dp[target] <= 0`。
- 示例 1 中若贪心只按「成本最小」挑数位，会先选成本 2 的 3 或 7 而不比较数值；正确做法是先保证位数最多（`dp[target]`），同位数下从 9 往 1 试，靠 `dp[rem-c]==dp[rem]-1` 判断该位是否可行。

## 如果面试官追问
问：若要求返回所有最优方案？答：把贪心的「选第一个可行数位」改成回溯枚举所有满足 `dp[rem-c]==dp[rem]-1` 的分支，位数固定为 `dp[target]`，复杂度升到指数级。
