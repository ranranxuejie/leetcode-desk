## 一句话思路
每种配料取 0/1/2 份，用回溯枚举全部组合，对每个基料求最接近 target 的成本。

## 怎么做
1. 对每个 `baseCosts[i]`，以它为基础成本，对 `toppingCosts` 做下标 `idx` 的回溯，每层枚举取 0、1、2 份。
2. 递归到 `idx == len(toppingCosts)` 时，用当前总成本 `cost` 更新答案：先比 `abs(cost - target)`，相等时取较小的 `cost`。
3. 剪枝：若 `cost >= target` 且 `cost - target >= abs(ans - target)`，后续只会更大，直接返回。

以示例 1 为例：`baseCosts=[1,7]`，`toppingCosts=[3,4]`，`target=10`。从基料 7 出发，`idx=0` 取 1 份 3 得 `cost=10`，此时已等于 target，更新 `ans=10`；后续任何分支都不可能更优。

```python
def dfs(idx, cost):
    nonlocal ans
    if idx == len(toppingCosts):
        if abs(cost - target) < abs(ans - target) or \
           (abs(cost - target) == abs(ans - target) and cost < ans):
            ans = cost
        return
    for k in range(3):
        dfs(idx + 1, cost + k * toppingCosts[idx])

ans = 2**31 - 1
for b in baseCosts:
    dfs(0, b)
return ans
```

## 复杂度
时间：O(n · 3^m)，每个基料枚举 3^m 种配料组合。
空间：O(m)，递归栈深度为配料种类数 m。

## 易错点
- `baseCosts=[10], toppingCosts=[1], target=1` → 若把「不选配料」当成可以不选基料，会返回 1 或 0 → 必须至少选一种基料，答案应为 10。
- `baseCosts=[3,10], toppingCosts=[2,5], target=9` → 若只比 `abs` 不处理平局，可能返回 10 → 距离相等时（8 和 10 距 9 都是 1）要取较小的 8。

## 如果面试官追问
问：配料种类 m 很大（如 m=30）怎么办？
答：3^m 爆炸，改用集合 DP 或按 target 上界做背包，把可达成本压进一个布尔数组。
