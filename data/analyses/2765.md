## 一句话思路
从每个位置 i 起用 while 往后延伸，用 `nums[j] - nums[j-1]` 与期望差值 `+1/-1` 交替比对，取最长。

## 怎么做
1. 外层 `for i in range(n-1)` 枚举起点，内层用 `j = i+1`、`expect = 1` 往后走。
2. 每步检查 `nums[j] - nums[j-1] == expect`，成立则 `j += 1`、`expect = -expect`，否则 break。
3. 用 `best = max(best, j - i)` 记录，最后 `return best if best >= 2 else -1`。

以 `nums = [2,3,4,3,4]` 为例，`i = 1` 时：`j=2` 差为 `4-3=1` 命中 `expect=1`，`expect` 翻成 `-1`；`j=3` 差为 `3-4=-1` 命中，翻回 `1`；`j=4` 差为 `4-3=1` 命中，`j` 走到 5 越界停，`j-i = 4`。而 `i=0` 时 `j=2` 差为 `4-3=1` 但 `expect` 已是 `-1`，立刻断，长度只有 2。

```python
n = len(nums)
best = 1
for i in range(n - 1):
    j, expect = i + 1, 1
    while j < n and nums[j] - nums[j - 1] == expect:
        expect = -expect
        j += 1
    best = max(best, j - i)
return best if best >= 2 else -1
```

注意 `expect` 的翻转必须写在 `j += 1` 之前或之后都行，但一定要在判断通过之后，否则第一对就比错。

## 复杂度
时间 O(n²)：n 个起点，每个起点最多再扫 n 个元素。
空间 O(1)：只用了 `i, j, expect, best` 四个变量。

## 易错点
- 输入 `[4,5,6]` → 若把 `expect` 固定成 `1` 不翻转，会把 `[4,5,6]` 判成长度 3，实际 `6-5=1` 应为 `-1`，正确答案是 2。必须在每次命中后 `expect = -expect`。
- 输入 `[2,3]` 或全不交替的 `[1,1,1]` → 若 `best` 初值设 0 且不判 `>= 2`，会返回 0 或 1，而题面要求不存在交替子数组时返回 `-1`。用 `best` 初值 1、末尾统一判 `best >= 2` 兜住。

## 如果面试官追问
问：n 放大到 10^5 怎么办？
答：改成一次线性扫描，维护当前交替段长度 `cur`，差值符合交替就 `cur += 1`，否则重置为 2，全程 O(n)。
