## 一句话思路
后序 DFS：先递归处理左右子树，回溯时判断当前节点是否已变成值为 target 的叶子，是则返回 None 交给父节点摘链。

## 怎么做
1. 递归函数返回「处理完后的子树根」，空节点直接返回 None。
2. 先对 `root.left`、`root.right` 递归，把返回值重新赋回去，这一步让子树的删除先完成。
3. 回溯到当前节点时再判断：左右都为空且 `root.val == target`，返回 None。
4. 否则返回 `root` 本身。

以示例 1 `root = [1,2,3,2,null,2,4], target = 2` 为例：先处理节点 2（1 的左孩子），它左右皆空且值为 2，返回 None，于是节点 1 的 `left` 变成 None；再处理节点 3 的两个孩子 2 和 4，左孩子 2 被摘掉，此时节点 3 的 `left` 为 None、`right` 为 4，不是叶子，保留；最后回到根 1，`left` 为 None、`right` 为 3，值 1 ≠ 2，保留。结果 `[1,null,3,null,4]`。

```python
def dfs(node):
    if not node:
        return None
    node.left = dfs(node.left)
    node.right = dfs(node.right)
    if not node.left and not node.right and node.val == target:
        return None
    return node
```

关键在顺序：判断「是不是叶子」必须放在两次递归之后，因为子节点被删掉才可能让当前节点变成叶子。示例 3 的链 `1→2→2→2` 正是靠这个顺序从最深处的 2 一路往上删到只剩 1。

## 复杂度
时间 O(n)：每个节点恰好访问一次，n 为节点总数。
空间 O(h)：递归栈深度等于树高 h，最坏链状树 h = n。

## 易错点
- 输入 `[1,2,null,2,null,2], target = 2`（示例 3）：若先判断当前节点再递归，根 1 的右链上第一个 2 当时还有孩子、不算叶子，会被漏删，最终输出 `[1,2,null,2]` 而非 `[1]`。正确做法是先递归左右子树、拿到返回值后再判叶子。
- 输入 `[1,3,3,3,2], target = 3`（示例 2）：若只写 `if root.val == target: return None` 而不检查 `not root.left and not root.right`，会把非叶子的 3 也删掉，输出 `[1]` 而非 `[1,3,null,null,2]`。必须两个条件同时成立才返回 None。

## 如果面试官追问
问：改成「删除值等于 target 的节点及其整棵子树」怎么做？
答：去掉叶子判断，进入节点时若 `node.val == target` 直接返回 None，其余照常后序递归。
