## 一句话思路
把相同伤害值合并成「值→总伤害」，排序后对相邻值做打家劫舍式 DP：取当前值就跳过差 ≤2 的邻居。

## 怎么做
1. 用 `Counter(power)` 把重复伤害合并，得到 `(值, 该值总伤害)` 列表并按值升序排序。
2. 设 `dp[i]` 为前 `i` 个不同值能拿到的最大伤害，`dp[0] = 0`。
3. 对第 `i` 个值 `v`，二分找最后一个 `< v-2` 的位置 `j`，转移 `dp[i] = max(dp[i-1], dp[j+1] + v*cnt[v])`。
4. 返回 `dp[m]`。

以 `power = [1,1,3,4]` 为例：合并后 `[(1,2),(3,3),(4,4)]`。处理 `v=3` 时，`v-2=1`，二分找到最后一个 `<1` 的位置为 -1，故 `j+1=0`，`dp[2] = max(dp[1]=2, dp[0]+3) = 3`。处理 `v=4` 时，`v-2=2`，最后一个 `<2` 是值 1（下标 0），`dp[3] = max(dp[2]=3, dp[1]+4) = max(3, 2+4) = 6`。

```python
from collections import Counter
from bisect import bisect_left

cnt = Counter(power)
vals = sorted(cnt)
m = len(vals)
dp = [0] * (m + 1)
for i, v in enumerate(vals, 1):
    j = bisect_left(vals, v - 2)   # 第一个 >= v-2 的下标
    take = dp[j] + v * cnt[v]      # dp[j] 对应前 j 个值，均 < v-2
    dp[i] = max(dp[i - 1], take)
return dp[m]
```

## 复杂度
时间：排序 `O(m log m)`，每个值二分一次共 `O(m log m)`，`m` 为不同值个数，`m ≤ n`。
空间：`Counter` 与 `dp` 各 `O(m)`，排序栈开销 `O(log m)`。

## 易错点
- 输入 `power = [1,1,3,4]`：若把重复的 1 当成两个独立元素做线性 DP，会漏掉「两个 1 可以同时用」这一点，错得 5 而非 6。正确做法是先 `Counter` 合并，`v*cnt[v]` 一次性计入。
- 输入 `power = [7,1,6,6]`：若用 `bisect_right(vals, v-2)` 或写成 `<= v-2`，会把差恰好为 2 的值 4 也排除掉；本题只禁差 1、2，差 2 是禁的，但差 3 不禁。边界必须严格是 `< v-2`，用 `bisect_left(vals, v-2)` 得到第一个 `>= v-2` 的下标，`dp[j]` 才恰好是全部安全前缀。

## 如果面试官追问
问：若要求输出具体选了哪些咒语？答：DP 时额外存 `pre[i]` 记录转移来源，从 `dp[m]` 回溯，取 `take` 分支就收集 `v` 及其计数。
