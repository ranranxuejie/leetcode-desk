## 一句话思路
把两个链表压进栈，从个位开始逐位相加，用头插法把结果接到新链表前面。

## 怎么做
1. 把 `l1`、`l2` 的节点值分别压入 `s1`、`s2`，栈顶就是最低位。
2. 循环条件是 `s1 or s2 or carry`，每轮弹出栈顶（空栈取 0）与 `carry` 相加。
3. 用 `carry, digit = divmod(total, 10)` 拆出本位和进位，`digit` 头插到结果链表。
4. 栈空且 `carry == 0` 时结束，返回结果链表头。

以示例 1 为例：`s1 = [7,2,4,3]`、`s2 = [5,6,4]`。第一轮弹出 `3` 和 `4`，`total = 7`，`carry = 0`、`digit = 7`；第二轮弹出 `4` 和 `6`，`total = 10`，`carry = 1`、`digit = 0`；第三轮弹出 `2` 和 `5`，加上 `carry` 得 `total = 8`，`digit = 8`；第四轮 `s2` 已空取 0，`2 + 0 + 0 = 2`，`digit = 2`。头插顺序是 7→0→8→2，反转后得到 `[7,8,0,7]`。

```python
s1, s2 = [], []
while l1: s1.append(l1.val); l1 = l1.next
while l2: s2.append(l2.val); l2 = l2.next
head, carry = None, 0
while s1 or s2 or carry:
    a = s1.pop() if s1 else 0
    b = s2.pop() if s2 else 0
    carry, digit = divmod(a + b + carry, 10)
    node = ListNode(digit)
    node.next, head = head, node
return head
```

## 复杂度
时间 O(max(m, n))：两趟压栈加一趟弹栈，长度由较长的链表决定。
空间 O(m + n)：两个栈各存一条链表，结果链表另开 max(m, n) + 1 个节点。

## 易错点
- 输入 `l1 = [9,9]`、`l2 = [1]` → 只按两条链表长度循环会丢掉最高进位，输出 `[0,0]` 而不是 `[1,0,0]`；循环条件必须带上 `carry`，让最后一轮 `total = 9 + 1 = 10` 再产生一个 `1`。
- 输入 `l1 = [0]`、`l2 = [0]` → 若用「先算数值再转链表」的写法，容易在 `while num:` 里直接返回 `None`；正确做法是循环至少执行一次，`divmod(0, 10)` 得到 `digit = 0`，返回单节点 `[0]`。

## 如果面试官追问
问：不允许修改链表、也不许用栈怎么办？
答：先各遍历一遍求长度差，让长链表先走 `diff` 步，再同步递归/迭代相加，进位靠返回值向上传。
