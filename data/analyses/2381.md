## 一句话思路
用差分数组把每个区间移位累加成每个下标的净位移量，再对 `s` 逐字符取模平移。

## 怎么做
1. 开 `diff = [0] * (n + 1)`，`direction == 1` 记 `+1`，否则记 `-1`。
2. 对 `[start, end]` 做 `diff[start] += d; diff[end + 1] -= d`。
3. 从左到右累加 `diff` 得到每个下标的净位移 `cur`。
4. 用 `(ord(s[i]) - 97 + cur) % 26 + 97` 还原字符。

以示例 1 的 `s = "abc"`、`shifts = [[0,1,0],[1,2,1],[0,2,1]]` 为例：三条记录写入后 `diff = [-1, 1, 1, -1]`，累加得 `cur` 序列 `[-1, 0, 1]`，即下标 0 前移 1、下标 1 不动、下标 2 后移 1，`"abc"` 变成 `"ace"`。

```python
n = len(s)
diff = [0] * (n + 1)
for start, end, direction in shifts:
    d = 1 if direction == 1 else -1
    diff[start] += d
    diff[end + 1] -= d

res = []
cur = 0
for i in range(n):
    cur += diff[i]
    res.append(chr((ord(s[i]) - 97 + cur) % 26 + 97))
return "".join(res)
```

关键点：`diff` 长度是 `n + 1`，`end + 1` 可能等于 `n`，这一位只用于抵消、不参与字符计算。

## 复杂度
时间：O(n + m)，n 是 `s` 长度、m 是 `shifts` 条数，两趟线性扫描。
空间：O(n)，额外开了 `diff` 数组和结果列表 `res`。

## 易错点
- `end == n - 1` 时若把 `diff` 开成 `[0] * n`，`diff[end + 1]` 会越界 → 正确做法是开 `n + 1`，让末尾的抵消位有位置落。
- 净位移 `cur` 可能是负数（示例 1 的 `cur = -1`），若写成 `ord(s[i]) + cur` 再判断是否小于 97，会漏掉 `cur` 绝对值超过 26 的情况 → 直接用 `% 26`，Python 的取模对负数返回非负结果，`-1 % 26 == 25` 正好对应 `'a'` 前移一位到 `'z'`。

## 如果面试官追问
若 `shifts` 长度涨到 10^9 且区间随机，还能用差分吗？答：能，差分只依赖区间端点，把端点排序后按坐标压缩即可，时间 O(m log m)。
