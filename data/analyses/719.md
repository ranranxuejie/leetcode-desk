## 一句话思路
排序后二分答案 D，用双指针数出距离 ≤ D 的数对个数，找第一个计数 ≥ k 的 D。

## 怎么做
1. 先 `nums.sort()`，排序后距离 ≤ D 的数对可用双指针线性统计。
2. 二分距离区间 `[0, nums[-1]-nums[0]]`，对每个 mid 统计 `cnt`。
3. 统计时固定右端 `j`，左端 `i` 单调右移，`nums[j]-nums[i] <= mid` 时 `i..j-1` 共 `j-i` 个合法数对。
4. `cnt >= k` 说明答案 ≤ mid，收缩右界；否则左界右移。

以 `nums=[1,3,1], k=1` 为例：排序得 `[1,1,3]`，二分 mid=1 时，j=1 得 `j-i=1`，j=2 时 `3-1=2>1` 不计数，`cnt=1 >= k`，右界收到 1；最终 lo=0 时 `cnt` 已含 `(1,1)` 距离 0，返回 0。

```python
nums.sort()
lo, hi = 0, nums[-1] - nums[0]
while lo < hi:
    mid = (lo + hi) // 2
    cnt = i = 0
    for j in range(len(nums)):
        while nums[j] - nums[i] > mid:
            i += 1
        cnt += j - i
    if cnt >= k:
        hi = mid
    else:
        lo = mid + 1
return lo
```

关键：`i` 在每轮 `j` 循环里只增不减，所以内层 while 总共走 O(n) 次，整个统计是 O(n) 而非 O(n²)。

## 复杂度
时间 O(n log n + n log(max-min))：排序 O(n log n)，二分 log(max-min) 轮、每轮 O(n)。
空间 O(1) 额外（排序栈忽略），只用了 lo/hi/mid/cnt/i 几个变量。

## 易错点
- `nums=[1,1,1], k=2`：若把 `cnt += j - i` 写成 `cnt += 1`，只数到相邻对，`cnt` 恒为 2 但漏掉 `(0,2)` 那对，mid=0 时仍可能凑够 k 而侥幸通过，换 `k=3` 就错。必须按 `j-i` 累加全部左端点。
- `nums=[1,6,1], k=3`：若二分上界取 `nums[-1]`（未减 `nums[0]`）或取 `10**6`，不影响正确性但多跑几轮；若上界取 `nums[-1]-nums[0]` 却把 `hi` 初始化为开区间 `hi+1` 又忘了返回 `lo` 而是 `hi`，会返回 6 而非 5。闭区间写法下 `cnt>=k` 时 `hi=mid`，最后返回 `lo`。

## 如果面试官追问
问：若 k 很大、n 到 10^5 还能这样吗？
答：能，仍是 O(n log n + n log V)，V 是值域；只有要求输出所有前 k 个距离时才需换堆或计数排序。
