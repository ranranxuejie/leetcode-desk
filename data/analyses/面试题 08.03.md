## 一句话思路
用分治二分：先查左半段，左半段没有才查右半段，靠 `nums[mid]` 与 `mid` 的大小关系剪枝。

## 怎么做
1. 递归函数 `dfs(lo, hi)` 返回 `[lo, hi]` 内最小的魔术索引，越界返回 `-1`。
2. 取 `mid = (lo + hi) // 2`，先递归左半段 `dfs(lo, mid - 1)`，若结果不是 `-1` 就直接返回。
3. 再判断 `nums[mid] == mid`，成立返回 `mid`。
4. 否则递归右半段 `dfs(mid + 1, hi)`。

关键剪枝在步骤 3 之后：以 `nums = [1, 1, 1]` 为例，`lo=0, hi=2, mid=1`，`nums[1]=1 == mid` 直接命中返回 `1`，右半段根本没进。再看 `nums = [0, 2, 3, 4, 5]`，`mid=2` 时 `nums[2]=3 > 2`，说明 `[0,2]` 里 `nums[i] - i` 可能为 0，左半段 `dfs(0,1)` 中 `mid=0` 命中返回 `0`。

```python
def dfs(lo, hi):
    if lo > hi:
        return -1
    mid = (lo + hi) // 2
    left = dfs(lo, mid - 1)
    if left != -1:
        return left
    if nums[mid] == mid:
        return mid
    return dfs(mid + 1, hi)
```

注意：因为要返回**最小**索引，必须先走左分支再判 `mid`，顺序反了在 `[0, 2, 3, 4, 5]` 上仍对，但在 `[0, 0, 2]` 这类会返回 `2` 而非 `0`。

## 复杂度
时间：最坏 O(n)，重复元素使剪枝失效，如全 1 数组；无重复时 O(log n)。
空间：递归栈 O(log n)，无额外数组。

## 易错点
- 输入 `[1, 1, 1]` → 若按「无重复版」用 `nums[mid] < mid` 判方向，会误判为往右走而漏掉 `mid=1` 的答案 → 正确做法是先判 `nums[mid] == mid` 再决定分支，且左分支优先。
- 输入 `[0, 0, 2]` → 若先判 `mid` 再递归左半段，`mid=1` 时 `nums[1]=0 != 1`，继续右走返回 `2`，错成 `2` → 正确做法是左递归结果非 `-1` 立即返回，保证最小索引。

## 如果面试官追问
问：数组无重复元素时能否严格 O(log n)？
答：可以，此时 `nums[i] - i` 单调不减，直接二分判 `nums[mid]` 与 `mid` 大小即可，无需回溯左分支。
