## 一句话思路
用 `result` 列表按序模拟四种操作，`#` 用 `result += result` 原地翻倍，`%` 用 `result.reverse()` 原地反转。

## 怎么做
1. 初始化 `result = []`，遍历 `s` 的每个字符 `ch`。
2. 小写字母直接 `result.append(ch)`；`*` 在 `result` 非空时 `result.pop()`。
3. `#` 执行 `result += result[:]`（或 `result.extend(result[:])`），`%` 执行 `result.reverse()`。
4. 遍历结束 `return ''.join(result)`。

以 `s = "a#b%*"` 为例，走到 `i=3` 的 `%` 之前 `result = ['a','a','b']`，`reverse()` 后变成 `['b','a','a']`，再遇 `*` 弹出末尾 `'a'`，得 `['b','a']`，拼接为 `"ba"`。

```python
result = []
for ch in s:
    if ch == '*':
        if result:
            result.pop()
    elif ch == '#':
        result += result[:]
    elif ch == '%':
        result.reverse()
    else:
        result.append(ch)
return ''.join(result)
```

关键点：`#` 必须复制一份再拼，`result += result` 在 Python 里对列表是原地扩展、右侧先求值，行为正确；但写成 `result.extend(result)` 会因迭代中增长而无限循环，必须用 `result[:]` 切片。

## 复杂度
时间：O(n·L)，n 为 `s` 长度，L 为 `result` 长度，`#` 和 `%` 各贡献一次 O(L)。
空间：O(L)，只开了 `result` 列表，最终字符串拼接再占 O(L)。

## 易错点
- 输入 `s = "z*#"` → 若 `*` 时不判空直接 `pop()`，空列表会抛 `IndexError`；正确做法是先 `if result:` 再弹，此时 `result` 为空，`#` 复制空列表仍为空，输出 `""`。
- 输入含连续 `#` 如 `"a##"` → 若写成 `result.extend(result)`，迭代器随列表增长而永不结束（或结果翻倍次数错）；正确做法是 `result += result[:]`，先切片固定右操作数，`"a"` 经两次翻倍得 `"aaaa"`。

## 如果面试官追问
问：若 `s` 长度放大到 10^5，`#` 会让结果指数膨胀怎么办？
答：先算最终长度上限，超限即按题意截断或改用双端队列 + 惰性反转标记，避免真的物化翻倍。
