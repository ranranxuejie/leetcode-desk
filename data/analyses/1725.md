## 一句话思路
每个矩形能切出的最大正方形边长就是 `min(l, w)`，扫一遍取最大值并计数即可。

## 怎么做
1. 遍历 `rectangles`，对每个 `[l, w]` 算出 `side = min(l, w)`。
2. 维护 `maxLen` 和 `cnt`：`side > maxLen` 时更新 `maxLen = side`、`cnt = 1`；`side == maxLen` 时 `cnt += 1`。
3. 返回 `cnt`。

以示例 1 `[[5,8],[3,9],[5,12],[16,5]]` 为例，四个 `side` 依次是 `5, 3, 5, 5`：第一个把 `maxLen` 置 5、`cnt` 置 1；第二个 `3 < 5` 跳过；第三、四个都等于 5，`cnt` 累加到 3，返回 3。

```python
maxLen, cnt = 0, 0
for l, w in rectangles:
    side = min(l, w)
    if side > maxLen:
        maxLen, cnt = side, 1
    elif side == maxLen:
        cnt += 1
return cnt
```

关键点：`cnt` 必须在 `maxLen` 被刷新时重置为 1，而不是清零后另算，否则旧的最大值计数会污染结果。

## 复杂度
时间 O(n)，n 为矩形个数，每个矩形只做一次 `min` 和两次比较。
空间 O(1)，只开了 `maxLen`、`cnt`、`side` 三个变量。

## 易错点
- 输入 `[[2,3],[3,7],[4,3],[3,7]]` → 若先统计再取最大，容易把 `side=3` 的 3 个和 `side=4` 的 1 个混在一起 → 正确做法是边扫边维护 `maxLen`，刷新时把 `cnt` 重置为 1，最终得 3。
- 输入 `[[5,8],[3,9],[5,12],[16,5]]` → 若用 `max(l, w)` 当边长，会得到 `8,9,12,16`，最大 16、计数 1 → 正确做法是取 `min(l, w)`，因为正方形边长受短边限制，答案应为 3。

## 如果面试官追问
问：若矩形数量到 10^7、内存吃紧怎么办？
答：仍是一次流式扫描，O(1) 额外空间，不需要存 `side` 数组，逐行读入即可。
