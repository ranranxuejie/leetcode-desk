## 一句话思路
逐项解析出分子分母，用通分累加维护 `num/den`，最后对结果取 gcd 约分。

## 怎么做
1. 在表达式前补 `'+'`，让第一个分数也带符号，统一按「符号 + 分子/分母」切分。
2. 用 `i` 扫描，遇到 `+`/`-` 记下符号，再读到 `/` 得分子、读到下一个符号得分母。
3. 每读一项就通分累加：`num = num*d + n*den; den *= d`，再立刻用 gcd 约一次防止数值膨胀。
4. 全部加完后约分，分母为负时把符号挪到分子，按 `f"{num}/{den}"` 输出。

以 `"1/3-1/2"` 为例：初始 `num=0, den=1`；读 `1/3` 后 `num=1, den=3`；读 `-1/2` 时 `num = 1*2 + (-1)*3 = -1`，`den = 3*2 = 6`，约分后 `-1/6`。

```python
from math import gcd
s = '+' + expression
num, den, i = 0, 1, 0
while i < len(s):
    sign = 1 if s[i] == '+' else -1
    i += 1
    j = i
    while s[j] != '/':
        j += 1
    n = sign * int(s[i:j])
    i = j + 1
    j = i
    while j < len(s) and s[j] not in '+-':
        j += 1
    d = int(s[i:j])
    num, den = num * d + n * den, den * d
    g = gcd(abs(num), den)
    num, den = num // g, den // g
    i = j
```

## 复杂度
时间 O(n·log C)：n 是表达式长度，每项做一次 gcd，C 为分母量级。
空间 O(1)：只开了 `num`、`den`、`i`、`j` 几个标量。

## 易错点
- 输入 `"1/3-1/2"` 若只按 `'+'` 切分，`-1/2` 会被当成 `1/2` 的正项 → 结果错成 `5/6`；正确做法是同时以 `'+'` 和 `'-'` 为分隔符，并把符号并入分子。
- 输入 `"-1/2+1/2"` 若累加后不约分直接输出 → 得到 `"0/2"` 而非 `"0/1"`；正确做法是每次累加后都对 `num` 和 `den` 取 gcd 约分，`0` 的 gcd 用 `gcd(0, den) = den` 自然归到 `0/1`。

## 如果面试官追问
若分数个数放大到 10^5 且要求不约分中间结果，怎么办？
答：仍可边加边约分，Python 大整数保证正确，只是乘法位数增长，复杂度多一个 log 因子。
