## 一句话思路
对 t1 每个节点做「同构判定」，用序列化字符串相等代替逐节点比较，把子树匹配降成子串匹配。

## 怎么做
1. 先写 `same(a, b)`：两树同时为空返回 `True`，一空一非空或值不等返回 `False`，否则递归比较左右孩子。
2. 主函数对 t1 做 DFS，每个节点调用一次 `same(node, t2)`，命中即返回 `True`。
3. 剪枝：若 `t2` 为空直接返回 `True`（空树是任何树的子树）；若当前节点子树高度小于 t2 高度可跳过，但本题规模 20000 不必加。
4. 用示例 1 走一遍：t1 根为 1，`same(1, 2)` 因值不等返回 `False`；DFS 到左孩子 2，`same(2, 2)` 两树都无孩子，返回 `True`，整体 `True`。

```python
def same(a, b):
    if not a and not b:
        return True
    if not a or not b or a.val != b.val:
        return False
    return same(a.left, b.left) and same(a.right, b.right)

def dfs(node):
    if not node:
        return False
    if same(node, t2):
        return True
    return dfs(node.left) or dfs(node.right)
```

关键中间值：示例 2 中 t1 根 1 与 t2 根 3 不等，右孩子 2 与 t2 根 3 不等，`same` 全部 `False`，返回 `False`。

## 复杂度
时间：最坏 O(n·m)，n 为 t1 节点数、m 为 t2 节点数，每个 t1 节点都触发一次 m 级比较。
空间：递归栈 O(h1 + h2)，h 为树高，最坏退化成链时 O(n + m)。

## 易错点
1. 输入 t2 为空树（`[]`）→ 若 `same` 里先判 `not a or not b` 就返回 `False`，会错成 `False`；正确做法是先判「两空返回 `True`」，空树是任何树的子树。
2. 输入 t1 = `[1, 2, 3]`、t2 = `[2]` → 若只比较根值不递归比较孩子，遇到 t1 中值为 2 但带孩子的节点会误判 `True`；正确做法是 `same` 必须同时递归左右孩子，结构也要一致。

## 如果面试官追问
问：节点到几万、要求 O(n + m) 怎么办？
答：对两棵树做前序序列化（空孩子写占位符），再用 KMP 在 t1 串里找 t2 串，匹配即子树。
