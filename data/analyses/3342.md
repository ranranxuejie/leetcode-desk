## 一句话思路
用 Dijkstra 求最短路，边权取决于到达当前格时已走的步数奇偶，故把「步数奇偶」并入状态。

## 怎么做
1. 状态取 `(t, i, j)`，`t` 是到达 `(i,j)` 的时刻；从 `(i,j)` 出发的移动耗时由 `(i+j)` 的奇偶决定：`(i+j)` 为偶则下一步花 1，为奇则花 2。
2. 松弛公式：`nt = max(t, moveTime[ni][nj]) + cost`，其中 `cost = 1 if (i+j) % 2 == 0 else 2`。
3. 用堆按 `t` 弹出，第一次弹出终点即答案。

以 `moveTime = [[0,4],[4,4]]` 为例：起点 `(0,0)`，`i+j=0` 偶，故 `cost=1`；到 `(1,0)` 得 `nt = max(0,4)+1 = 5`，到 `(0,1)` 得 `nt = max(0,4)+1 = 5`。从 `(1,0)`（`i+j=1` 奇，`cost=2`）到 `(1,1)`：`nt = max(5,4)+2 = 7`，与输出一致。

```python
import heapq
n, m = len(moveTime), len(moveTime[0])
dist = [[float('inf')] * m for _ in range(n)]
dist[0][0] = 0
pq = [(0, 0, 0)]
while pq:
    t, i, j = heapq.heappop(pq)
    if t > dist[i][j]:
        continue
    if (i, j) == (n - 1, m - 1):
        return t
    cost = 1 if (i + j) % 2 == 0 else 2
    for ni, nj in ((i+1,j),(i-1,j),(i,j+1),(i,j-1)):
        if 0 <= ni < n and 0 <= nj < m:
            nt = max(t, moveTime[ni][nj]) + cost
            if nt < dist[ni][nj]:
                dist[ni][nj] = nt
                heapq.heappush(pq, (nt, ni, nj))
```

## 复杂度
时间：`O(n*m*log(n*m))`，堆中最多 `n*m` 个状态，每次弹出 `log`。
空间：`O(n*m)`，`dist` 表加堆。

## 易错点
- 把 `cost` 写成「进入目标格后按目标格奇偶算」→ 示例 1 会得 6 而非 7 → 正确是按**出发格** `(i+j)` 的奇偶决定这一步耗时。
- 松弛写成 `nt = t + cost` 忽略 `moveTime` 门槛 → 示例 1 中 `(1,0)` 得 1 而非 5 → 必须 `max(t, moveTime[ni][nj])` 再加速。

## 如果面试官追问
若 `moveTime` 全为 0，能否不用堆？答：此时答案只由路径长度奇偶决定，直接 `(n-1)+(m-1)` 加奇偶修正即可，`O(1)`。
