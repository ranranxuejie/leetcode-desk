## 一句话思路
区间 DP：`dp[i]` 表示 source 前 i 个字符转成 target 前 i 个字符的最小成本，每步枚举一条规则覆盖一段连续区间。

## 怎么做
1. 预处理每条规则：把 pattern 中 `*` 的位置记下，成本记为 `costs[i] + pattern.count('*')`。
2. 设 `dp[0] = 0`，其余为 `inf`；`dp[i]` 只从 `dp[l]` 转移，表示规则覆盖 `[l, i)`。
3. 对每个 `l`，枚举规则 `r`，长度 `m = len(pattern)`，检查 `source[l:l+m]` 与 pattern 逐位匹配（相等或 pattern 位是 `*`），且 `target[l:l+m] == replacement`，则 `dp[l+m] = min(dp[l+m], dp[l] + c)`。
4. 返回 `dp[n]`，若为 `inf` 返回 `-1`。

以示例 2 为例：`source="cat"`，`target="dog"`，规则 `["c*t","dog"]`，成本 `2+1=3`。`l=0` 时 `source[0:3]="cat"` 与 `"c*t"` 匹配（`c`、`t` 相等，中间 `*` 通配 `a`），`target[0:3]="dog"` 等于 replacement，故 `dp[3] = dp[0] + 3 = 3`。

```python
n = len(source)
INF = float('inf')
dp = [INF] * (n + 1)
dp[0] = 0
for l in range(n):
    if dp[l] == INF:
        continue
    for pat, rep, base in rules:
        m = len(pat)
        if l + m > n:
            continue
        if all(p == '*' or p == source[l + j] for j, p in enumerate(pat)) \
           and target[l:l + m] == rep:
            dp[l + m] = min(dp[l + m], dp[l] + base + pat.count('*'))
return -1 if dp[n] == INF else dp[n]
```

## 复杂度
时间：O(n · R · m)，n 为串长、R 为规则数、m 为规则长度上限 20。
空间：O(n) 的 dp 数组，规则预处理另存 O(R·m)。

## 易错点
- 规则可重叠覆盖同一段：若只按「从左到右贪心选最长匹配」处理 `source="hello"`，会漏掉 `["he","wo"]` 与 `["llo","rld"]` 拼成 `world` 的组合，必须用 dp 枚举所有 `l` 与规则。
- 只校验 source 匹配却忘了 `target[l:l+m] == replacement`：示例 4 中 `["a*","bd"]` 能匹配 `source="ab"` 的 `a*`，但 replacement `bd` ≠ `target[0:2]="bc"`，误判会输出 9 而非 -1。

## 如果面试官追问
问：若规则允许 pattern 与 replacement 长度不同怎么办？
答：dp 的转移下标从 `l+m` 改为 `l+len(rep)`，但需重新论证位置不重叠的合法性。
