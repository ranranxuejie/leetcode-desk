## 一句话思路
把每条相邻边按高度差排序，用并查集逐条加边，起点终点首次连通时的边权就是答案。

## 怎么做
1. 把 `rows*columns` 个格子编号 `r*columns+c`，枚举每个格子的右、下邻居，生成边 `(abs(差), u, v)`。
2. 所有边按差值升序排序。
3. 依次 union，每次 union 后检查 `find(0) == find(rows*columns-1)`，成立即返回当前差值。

以示例 1 为例：`heights=[[1,2,2],[3,8,2],[5,3,5]]`，边权 0 的边不存在；差值为 1 的边有 (0,0)-(0,1)、(0,1)-(0,2)、(1,2)-(2,2) 等，加完仍不连通；处理到差值 2 的边 (0,0)-(1,0) 时，`find(0)` 与 `find(8)` 首次相等，返回 2。

```python
edges = []
for r in range(rows):
    for c in range(columns):
        u = r * columns + c
        if r + 1 < rows:
            edges.append((abs(heights[r][c] - heights[r+1][c]), u, u + columns))
        if c + 1 < columns:
            edges.append((abs(heights[r][c] - heights[r][c+1]), u, u + 1))
edges.sort()
parent = list(range(rows * columns))
# find 带路径压缩，union 后判断 find(0) == find(rows*columns-1)
```

## 复杂度
时间：边数约 `2*rows*columns`，排序 O(E log E)，并查集近 O(E α)。
空间：`parent` 数组 O(rows*columns)，`edges` 列表 O(rows*columns)。

## 易错点
- 单格输入 `heights=[[5]]` → 若先建边再判断会返回空或报错 → 应在建边前直接返回 0，因为起点即终点。
- 只枚举右、下邻居 → 若误枚举四方向，每条边重复两次，排序后逻辑仍对但边数翻倍；正确做法是只加右、下，保证每条边一次。

## 如果面试官追问
要求输出具体路径而非仅体力值？答：并查集加边时记录每个集合的父指针链，连通后从终点回溯到起点即可还原路径。
