## 一句话思路
对每个结尾下标 i，用哈希表记录「以 nums[i] 结尾、公差为 d 的等差子序列个数」，倒序枚举 j 累加。

## 怎么做
1. 建 `dp = [defaultdict(int) for _ in nums]`，`dp[i][d]` 表示以 i 结尾、公差 d 的等差子序列数（长度 ≥2）。
2. 外层 i 从 0 到 n-1，内层 j 从 0 到 i-1，算 `d = nums[i] - nums[j]`。
3. `dp[i][d] += dp[j][d] + 1`：`dp[j][d]` 是能接上的旧序列（长度 ≥3 的贡献），`+1` 是 `[nums[j], nums[i]]` 这个二元组。
4. 答案只累加 `dp[j][d]`，因为长度 ≥3 的才算；`+1` 那部分只是给后续当垫脚石。

用示例 1 `nums = [2,4,6,8,10]` 看 i=2（值 6）：j=0 时 d=4，`dp[2][4] += dp[0][4]+1 = 1`；j=1 时 d=2，`dp[2][2] += dp[1][2]+1 = 1`。此时 ans 仍为 0，因为 `dp[0][4]`、`dp[1][2]` 都是 0——长度 3 的 `[2,4,6]` 要到 i=2 才成形，但它的贡献记在 `dp[2][4]` 里，等 i=4 时被 `dp[4][4] += dp[2][4]+1` 取走。

```python
from collections import defaultdict

dp = [defaultdict(int) for _ in nums]
ans = 0
for i in range(len(nums)):
    for j in range(i):
        d = nums[i] - nums[j]
        ans += dp[j][d]
        dp[i][d] += dp[j][d] + 1
return ans
```

## 复杂度
时间 O(n²)：双重循环枚举 (j, i) 对，每次哈希操作 O(1)。
空间 O(n²)：最坏每个 `dp[i]` 存 O(n) 个不同公差。

## 易错点
- 全相等输入 `[7,7,7,7,7]` → 若把 `+1` 也计入 ans，会多算所有二元组（10 个），得到 26 而非 16 → 只累加 `dp[j][d]`，`+1` 仅用于构造更长序列。
- 公差可能超出 32 位范围（如 `nums[i]=2**31-1, nums[j]=-2**31`）→ 若用定长整型存 d 会溢出 → Python 整数无此问题，但别手动截断 d；答案本身按题目保证落在 32 位内。

## 如果面试官追问
若 n 扩到 10⁵ 怎么办？答：公差种类爆炸，O(n²) 不可行，需按值域分块或改用「枚举公差 + 计数」的离线做法，但本题 n≤1000 无需。
