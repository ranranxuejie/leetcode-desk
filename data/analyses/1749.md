## 一句话思路
最大绝对子数组和 = max(最大子数组和, -最小子数组和)，用 Kadane 同时跑最大和最小和。

## 怎么做
1. 维护 `cur_max`（以当前元素结尾的最大和）和 `cur_min`（以当前元素结尾的最小和），以及全局 `best`。
2. 对每个 `x`：`cur_max = max(x, cur_max + x)`，`cur_min = min(x, cur_min + x)`。
3. 每步用 `max(abs(cur_max), abs(cur_min))` 更新 `best`；空子数组和为 0，故 `best` 初值取 0。
4. 返回 `best`。

以 `nums = [1,-3,2,3,-4]` 为例，走到 `x=3` 时 `cur_max = max(3, 2+3) = 5`，`cur_min = min(3, -1+3) = 2`，`best` 更新为 5；后续 `x=-4` 时 `cur_max = max(-4, 5-4) = 1`，`cur_min = min(-4, 2-4) = -4`，`best` 保持 5。

```python
cur_max = cur_min = best = 0
for x in nums:
    cur_max = max(x, cur_max + x)
    cur_min = min(x, cur_min + x)
    best = max(best, abs(cur_max), abs(cur_min))
return best
```

关键点：`cur_max` 和 `cur_min` 必须用**更新前**的值算，不能先改 `cur_max` 再拿它算 `cur_min`，否则 `cur_min` 会用到脏数据。

## 复杂度
时间 O(n)：一次遍历，每个元素常数次比较。
空间 O(1)：只开 `cur_max`、`cur_min`、`best` 三个变量。

## 易错点
- 输入全为负数如 `nums = [-3,-1,-2]` → 若只跑最大子数组和会得 `-1`，漏掉 `abs(-6)=6` → 必须同时维护 `cur_min`，答案取 `abs(cur_min)`。
- 输入 `nums = [1,-3,2,3,-4]` → 若把 `best` 初值设成 `-inf` 或第一个元素，空子数组的 0 就丢了；当全数组和绝对值都小于 0 时（本题不会，但换约束会）会返回负数 → `best` 初值取 0，保证空子数组合法。

## 如果面试官追问
要求返回子数组的左右端点怎么办？
答：在更新 `best` 时同步记录 `cur_max`/`cur_min` 的起点下标，取到更优值时把起点和当前 `i` 存下来即可，仍是 O(n)。
