## 一句话思路
状压 DP：`dp[mask]` 记做完 `mask` 这批任务的最少段数，同时记当前段已用时间，按段数优先、余时最少贪心合并。

## 怎么做
1. 用 `mask` 的二进制位表示哪些任务已完成，`dp[mask] = (段数, 当前段已用时间)`，初始 `dp[0] = (1, 0)`。
2. 枚举 `mask` 中未完成的任务 `i`，尝试把它塞进当前段：若 `used + tasks[i] <= sessionTime` 就留在本段，否则新开一段。
3. 两种走法取「段数更少」者；段数相同取「当前段已用时间更少」者，因为余时越少越省后续空间。
4. 答案是 `dp[(1<<n)-1][0]`。

以示例 2 `tasks=[3,1,3,1,1], sessionTime=8` 为例：把前四个任务 `3+1+3+1=8` 塞满一段后 `dp` 该状态为 `(1, 8)`；再放最后一个 `1` 时 `8+1>8`，只能新开段，得 `(2, 1)`，最终输出 2。

```python
n = len(tasks)
full = (1 << n) - 1
INF = (n + 1, 0)
dp = [INF] * (1 << n)
dp[0] = (1, 0)
for mask in range(1 << n):
    cnt, used = dp[mask]
    for i in range(n):
        if mask >> i & 1:
            continue
        nm = mask | (1 << i)
        if used + tasks[i] <= sessionTime:
            cand = (cnt, used + tasks[i])
        else:
            cand = (cnt + 1, tasks[i])
        if cand < dp[nm]:
            dp[nm] = cand
return dp[full][0]
```

## 复杂度
时间：`O(2**n * n)`，`2**n` 个状态各扫 `n` 个任务。
空间：`O(2**n)`，`dp` 数组存 `(段数, 余时)` 二元组。

## 易错点
- 输入 `tasks=[1,2,3], sessionTime=3`：若只按段数比较、不比较余时，`(1,3)` 与 `(1,1)` 会被当成等价，导致后续 `3` 无法判断该不该新开段 → 正确做法是元组比较 `(cnt, used)`，段数相同再比余时。
- 输入 `tasks=[3,1,3,1,1], sessionTime=8`：若把 `dp[0]` 初始化成 `(0, 0)`，第一段会被多算一次，答案变 3 → 正确做法是 `dp[0]=(1,0)`，段数从 1 起算。

## 如果面试官追问
问：n 放大到 20 怎么办？答：`2**20 * 20` 约两千万次仍可跑，但需把 `dp` 压成两个数组避免元组开销；再大就只能回溯剪枝。
