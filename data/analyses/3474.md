## 一句话思路
先把所有 `T` 位置强制写入 `str2`，冲突即返回 `""`；再从右往左把 `F` 位置中恰好等于 `str2` 的窗口改成字典序最小的破坏字符。

## 怎么做
1. 开长度 `n+m-1` 的字符数组 `w`，初值 `'?'`，遍历 `str1`，`'T'` 处把 `str2[j]` 写进 `w[i+j]`，已存在且不等则返回 `""`。
2. 剩余 `'?'` 全填 `'a'`，得到字典序下界。
3. 从右往左扫 `i`（`str1[i]=='F'`），用滚动哈希或直接比较判断 `w[i:i+m]` 是否等于 `str2`；相等则把 `w[i+m-1]` 改成能破坏匹配的最小字符。
4. 返回 `''.join(w)`。

以 `str1="TFTF", str2="ab"` 为例：步骤 1 后 `w = "ab?b?"`（i=0 写 ab，i=2 写 ab 到下标 2、3），步骤 2 得 `"ababa"`。步骤 3 检查 i=3 的 `w[3:5]="ba"` ≠ `"ab"`，i=1 的 `w[1:3]="ba"` ≠ `"ab"`，无需修改，答案 `"ababa"`。

```python
w = ['?'] * (n + m - 1)
for i, c in enumerate(str1):
    if c == 'T':
        for j, ch in enumerate(str2):
            if w[i+j] not in ('?', ch):
                return ""
            w[i+j] = ch
w = ['a' if c == '?' else c for c in w]
for i in range(n - 1, -1, -1):
    if str1[i] == 'F' and ''.join(w[i:i+m]) == str2:
        w[i+m-1] = 'b' if str2[-1] == 'a' else 'a'
return ''.join(w)
```

关键在步骤 3 的修改位置：改 `w[i+m-1]` 而不是 `w[i]`，因为更靠右的字符影响更少的后续窗口，且从右往左扫保证已处理的 `F` 不会被再次破坏。

## 复杂度
时间：O(n·m) 最坏（每步切片比较 m 个字符），n 来自 `str1` 长度，m 来自 `str2` 长度。
空间：O(n+m)，即结果数组 `w`，无额外哈希表。

## 易错点
- `str1` 含多个 `T` 且 `str2` 有自重叠（如 `str2="aa"`、`str1="TT"`）→ 若只在第一个 `T` 处写入就跳过后续，会漏掉重叠位置的一致性校验，错判为可行；必须逐字符比对，冲突立即返回 `""`。
- `F` 窗口恰好等于 `str2` 且 `str2[-1]=='a'` → 若把 `w[i+m-1]` 改成 `'a'` 等于没改，仍匹配；正确做法是改成 `'b'`（`str2[-1]` 为 `'a'` 时唯一能破坏的最小字符），其余情况改 `'a'`。

## 如果面试官追问
若 n 放大到 10^6、m 仍 500，O(n·m) 还够吗？答：改用滚动哈希 O(n+m) 判等，但本题 n≤10^4 直接切片即可。
