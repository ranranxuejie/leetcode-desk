## 一句话思路
从左到右扫描，用差分数组 `diff` 记录当前位置已被前面区间覆盖的减 1 次数，`nums[i]` 必须恰好被减这么多次。

## 怎么做
1. 维护 `cur` 表示当前下标已被多少个长度 k 的区间覆盖，`diff[i+k]` 记录区间结束后的回退量。
2. 对每个 `i`，先 `cur -= diff[i]`，得到 `nums[i]` 实际被减的次数。
3. 若 `nums[i] < cur` 直接返回 `False`（减多了变负）；否则还需 `need = nums[i] - cur` 次操作，从 `i` 开始覆盖。
4. 若 `i + k > n` 而 `need > 0`，说明区间越界，返回 `False`；否则 `cur += need`、`diff[i+k] += need`。

以 `nums = [2,2,3,1,1,0], k = 3` 为例：`i=0` 时 `cur=0`，`need=2`，`cur` 变 2、`diff[3]=2`；`i=3` 时先 `cur -= diff[3]` 得 0，`nums[3]=1`，`need=1`，`diff[6]` 越界但 `i+k=6=n` 合法，继续。

```python
n = len(nums)
diff = [0] * (n + 1)
cur = 0
for i in range(n):
    cur -= diff[i]
    if nums[i] < cur:
        return False
    need = nums[i] - cur
    if need:
        if i + k > n:
            return False
        cur += need
        diff[i + k] += need
return True
```

## 复杂度
时间 O(n)：一次遍历，每个下标只处理常数次。
空间 O(n)：额外开 `diff` 数组，长度 n+1。

## 易错点
- 输入 `nums = [1,3,1,1], k = 2`：`i=0` 时 `need=1`，`cur=1`、`diff[2]=1`；`i=1` 时 `cur` 仍为 1，`nums[1]=3` 需 `need=2`，`cur=3`、`diff[3]=2`；`i=2` 时 `cur -= diff[2]` 得 2，`nums[2]=1 < 2` 返回 `False`。若忘记 `cur -= diff[i]`，会误判为可继续。
- 输入 `nums = [0,0,0], k = 1` 或尾部需要操作但越界：如 `nums=[1], k=2`，`i+k=2 > n=1` 且 `need=1`，必须返回 `False`；漏判 `i + k > n` 会越界写 `diff` 或错误返回 `True`。

## 如果面试官追问
问：若要求输出具体操作方案而非布尔值？
答：在 `need > 0` 时记录 `(i, need)` 表示对 `[i, i+k-1]` 执行 `need` 次，按序输出即可。
