## 一句话思路
把 s1 拼成 s1+s1，s2 是它的子串就说明 s2 由 s1 轮转而来。

## 怎么做
1. 先比长度：`len(s1) != len(s2)` 直接返回 `False`，长度不等不可能轮转。
2. 用 `s2 in s1 + s1` 一次子串检查搞定，不用手动枚举切点。
3. 空串特判：`s1 == s2 == ""` 时 `"" in ""` 为 `True`，符合题意。

以 `s1 = "waterbottle", s2 = "erbottlewat"` 为例，`s1 + s1 = "waterbottlewaterbottle"`，从下标 4 开始正好是 `"erbottlewat"`，所以 `in` 返回 `True`。切点 4 就是 s2 首字符 `e` 在 s1 中的位置。

```python
def isFlipedString(s1, s2):
    if len(s1) != len(s2):
        return False
    return s2 in s1 + s1
```

关键点：`s1 + s1` 覆盖了所有 n 个切点，任意轮转结果都是它的长度 n 子串；反过来长度 n 的子串起点若在 `[0, n-1]` 内就是轮转，起点在 `[n, 2n-1]` 则与前面重复，所以不漏不重。

## 复杂度
时间 O(n)：`s1 + s1` 构造 O(n)，子串匹配 O(n)（Python 用高效算法）。
空间 O(n)：额外开了长度 2n 的拼接串。

## 易错点
- 输入 `s1 = "aa", s2 = "aba"` → 若只写 `s2 in s1 + s1` 不先比长度，`"aba"` 不在 `"aaaa"` 里侥幸返回 `False`，但换成 `s1 = "ab", s2 = "abab"` 就会错判 `True` → 必须先 `len(s1) != len(s2)` 返回 `False`。
- 输入 `s1 = "", s2 = ""` → 若写成 `if not s1 or not s2: return False` 会把空串对空串错判成 `False` → 空串是合法轮转，只靠长度比较即可，不要额外排除空串。

## 如果面试官追问
问：不许拼接、要求 O(1) 额外空间怎么做？
答：在 `s1 + s1` 的逻辑上用双指针模拟取模下标逐位比较，或 KMP 在虚拟拼接串上匹配，避免真正开 2n 空间。
