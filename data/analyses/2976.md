## 一句话思路
把 26 个字母当图节点，对 cost 建边跑 Floyd 求任意两字母最短路，再逐位累加。

## 怎么做
1. 建 26×26 的 `dist`，初始 `2**31 - 1`，对角线置 0；对每条边 `dist[original[i]][changed[i]] = min(..., cost[i])`（重边取小）。
2. 三重循环 Floyd，`dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`，得到任意字母对的最小转换成本。
3. 遍历 `zip(source, target)`，若 `dist[a][b]` 仍是无穷则返回 -1，否则累加。

以示例 1 为例：`dist['a']['b']` 直接边是 2，但 `a→b→c→e` 是 2+5+5=12，Floyd 后 `dist['a']['b']` 保持 2；关键的是 `dist['c']['b']`，直接边 5，而 `c→e→b` 是 1+2=3，Floyd 后被压成 3，所以下标 2 的 `c→e` 走 1、`e→b` 走 2 共 3，而不是 5。最终 2+3+3+20=28。

```python
INF = 2**31 - 1
dist = [[INF] * 26 for _ in range(26)]
for i in range(26):
    dist[i][i] = 0
for o, c, w in zip(original, changed, cost):
    u, v = ord(o) - 97, ord(c) - 97
    if w < dist[u][v]:
        dist[u][v] = w
for k in range(26):
    for i in range(26):
        dik = dist[i][k]
        if dik == INF:
            continue
        for j in range(26):
            nd = dik + dist[k][j]
            if nd < dist[i][j]:
                dist[i][j] = nd
total = 0
for a, b in zip(source, target):
    d = dist[ord(a) - 97][ord(b) - 97]
    if d == INF:
        return -1
    total += d
return total
```

## 复杂度
时间：Floyd 固定 26³≈1.8 万，加遍历 source 的 O(n)，n 为字符串长度。
空间：`dist` 固定 26×26，与 n 无关，额外 O(1)。

## 易错点
- 重边：示例 1 里 `c→b` 出现两次（cost 5 和 1 那条是 `c→e`），若直接赋值不取 min，`dist['c']['b']` 可能被大值覆盖，答案偏大。正确做法是建边时 `min` 比较。
- 不可达判断：示例 3 中 `dist['d']['e']` 始终是 INF，若用 `2**31 - 1` 当无穷直接累加会得到巨大正数而非 -1。正确做法是累加前显式判 `d == INF` 立即返回 -1。

## 如果面试官追问
若 cost 规模涨到 10⁵ 且字母表不变，Floyd 是否还够？答：26³ 是常数，与边数无关，仍是最优选择，无需换 Dijkstra。
