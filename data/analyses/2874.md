## 一句话思路
固定 j 时只需 j 左侧最大值和 j 右侧最大值，一次遍历维护 `max_i - nums[j]` 的最大值即可。

## 怎么做
1. 把 `(nums[i] - nums[j]) * nums[k]` 拆成两段：先对每个 j 求 `best_diff = max(nums[i] - nums[j])`（i < j），再乘右侧的 `nums[k]`。
2. 从左往右扫，用 `max_i` 记录 j 左侧出现过的最大 `nums[i]`，用 `best_diff` 记录历史最优的 `max_i - nums[j]`。
3. 对当前元素当作 k，用 `best_diff * nums[k]` 更新答案；注意顺序是先算答案再更新 `best_diff`，保证 i < j < k。

以 `nums = [12,6,1,2,7]` 为例：扫到 1（下标 2）时 `max_i = 12`，`best_diff = 12 - 1 = 11`；扫到 7（下标 4）时 `best_diff` 仍是 11，`11 * 7 = 77` 即答案。

```python
max_i = nums[0]
best_diff = -10**18
ans = 0
for x in nums[1:]:
    ans = max(ans, best_diff * x)   # x 当 k
    best_diff = max(best_diff, max_i - x)  # x 当 j
    max_i = max(max_i, x)
return ans
```

关键点：`best_diff` 初值取极小负数，因为 `nums[i] - nums[j]` 可能为负；`ans` 初值 0 直接满足「全负返回 0」。

## 复杂度
时间 O(n)：一次遍历，每个元素常数次比较。
空间 O(1)：只开 `max_i`、`best_diff`、`ans` 三个变量。

## 易错点
- 输入 `[1,2,3]` → 若把 `ans` 初值设成 `-inf` 会返回 -3 → 正确做法是 `ans = 0`，负数结果自然被 0 覆盖。
- 输入 `[12,6,1,2,7]` → 若在同一轮里先用 x 更新 `best_diff` 再算 `best_diff * x`，会让 j 和 k 撞成同一个下标 → 正确做法是先算 `ans` 再更新 `best_diff`，保证严格 i < j < k。

## 如果面试官追问
要求输出具体三元组下标怎么办？额外存 `best_i`、`best_j`，在更新 `best_diff` 和 `ans` 时同步记录下标即可，仍是 O(1) 空间。
