## 一句话思路
二分答案 T，用贪心判定「每天最多 T 分钟、可免掉当天最大一题」能否在 m 天内刷完。

## 怎么做
1. 二分下界 `lo = 0`、上界 `hi = sum(time)`，判定函数 `can(T)` 返回能否在 m 天内完成。
2. 贪心切天：一天内累加 `s`，同时记录当天最大值 `mx`；当 `s - mx > T` 时，说明这一天去掉最大题后仍超时，必须把当前题挪到新的一天。
3. 新的一天重置 `s = time[i]`、`mx = time[i]`，天数 `days += 1`；最后看 `days <= m`。
4. 二分收缩：`can(T)` 为真则 `hi = mid`，否则 `lo = mid + 1`，返回 `lo`。

以 `time = [1,2,3,3], m = 2` 为例，判 `T = 3`：第 0 天累加到 `s = 1+2+3 = 6`、`mx = 3`，`s - mx = 3 <= 3` 继续；再加 `3` 得 `s = 9`、`s - mx = 6 > 3`，于是切天，第 1 天 `s = 3`。共 2 天，`can(3) = True`；而 `T = 2` 时第 0 天 `s - mx = 1+2 = 3 > 2`，需 3 天，故答案为 3。

```python
def can(T):
    days, s, mx = 1, 0, 0
    for t in time:
        s += t
        mx = max(mx, t)
        if s - mx > T:          # 去掉当天最大题仍超时
            days += 1
            s, mx = t, t
    return days <= m

lo, hi = 0, sum(time)
while lo < hi:
    mid = (lo + hi) // 2
    if can(mid):
        hi = mid
    else:
        lo = mid + 1
return lo
```

## 复杂度
时间：二分 log(sum(time)) 轮，每轮判定扫 n 个元素，共 O(n log S)。
空间：只用了 `days/s/mx` 几个变量，O(1) 额外空间。

## 易错点
- 判定写成 `s > T` 而不是 `s - mx > T`：对 `time = [1,2,3,3], m = 2` 会算出 4 而非 3，因为漏掉了每天可免费去掉最大一题。
- 切天时把 `mx` 重置成 0 或沿用旧值：新一天的最大值必须是 `time[i]` 本身，否则 `s - mx` 偏小，判定过松，答案偏小。

## 如果面试官追问
要求输出每天的具体分组方案怎么办？答：在 `can` 里记录每次切天的下标，二分出最小 T 后按同样贪心重跑一遍即可。
