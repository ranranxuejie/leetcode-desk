## 一句话思路
排序后取全部绝对值>1的数，负数个数为奇则除以绝对值最小的负数，全非正时取最大单元素。

## 怎么做
1. 把 `nums` 排序，统计负数个数 `neg`，并记录绝对值最小的负数 `max_neg`（即最接近 0 的负数）。
2. 累乘所有 `abs(x) > 1` 的元素到 `prod`；若 `neg` 为奇数，把 `prod` 除以 `max_neg`（等价于剔除它）。
3. 若 `prod` 仍为负或没有可用元素，答案退化为 `max(nums)`（单个最大元素，保证非空）。

以 `nums = [3,-1,-5,2,5,-9]` 为例：排序后 `[-9,-5,-1,2,3,5]`，`neg=3` 为奇，`max_neg=-1`；累乘 `-9*-5*2*3*5 = 1350`，再除以 `-1` 得 `-1350`？不对——剔除 `-1` 应是不乘它，`prod` 直接是 `-9*-5*2*3*5 = 1350`，`neg` 变偶，答案 1350。

```python
nums.sort()
neg = sum(1 for x in nums if x < 0)
prod, used = 1, False
for x in nums:
    if abs(x) > 1:
        prod *= x
        used = True
if neg % 2 == 1:
    prod //= max((x for x in nums if x < 0), default=1)
if not used or prod < 0:
    return max(nums)
return prod
```

## 复杂度
时间 O(n log n)：排序主导，n 为 `nums` 长度。
空间 O(1)：只开 `neg`、`prod`、`used` 几个标量。

## 易错点
- 输入 `[-4,-5,-4]` → 若直接累乘全部负数得 `-80`，错；正确是 `neg=3` 为奇，剔除绝对值最小的 `-4`，剩 `-4*-5=20`。
- 输入 `[0,0,0]` 或 `[-1]` → 若 `prod` 初值 1 直接返回会得 1，错；正确是 `used=False` 时返回 `max(nums)`，即 0 或 -1。

## 如果面试官追问
若要求输出具体下标方案？答：累乘时同步记录被选下标，剔除 `max_neg` 时从列表里删掉它的下标即可。
