## 一句话思路
从每个未访问城市出发 DFS 淹没整个连通块，每启动一次计数器加一，淹没次数即省份数。

## 怎么做
1. 建 `visited = [False] * n`，`count = 0`。
2. 外层 `for i in range(n)`，若 `visited[i]` 为 `False` 则 `count += 1` 并从 `i` 开始 DFS。
3. DFS 里把当前点标记 `visited[j] = True`，再遍历 `isConnected[j]` 中值为 1 的邻居递归下去。
4. 返回 `count`。

拿示例 1 `[[1,1,0],[1,1,0],[0,0,1]]` 走一遍：`i=0` 未访问，`count=1`，DFS 从 0 出发标记 0，看到 `isConnected[0][1]=1` 递归到 1，标记 1，`isConnected[1][0]=1` 但 0 已访问，`isConnected[1][2]=0` 停；回到外层 `i=1` 已访问跳过；`i=2` 未访问，`count=2`，DFS 标记 2，`isConnected[2][0]=isConnected[2][1]=0` 无邻居。最终 `count=2`，与输出一致。

```python
n = len(isConnected)
visited = [False] * n

def dfs(j):
    visited[j] = True
    for k in range(n):
        if isConnected[j][k] == 1 and not visited[k]:
            dfs(k)

count = 0
for i in range(n):
    if not visited[i]:
        count += 1
        dfs(i)
return count
```

关键点：`visited[j] = True` 必须在展开邻居**之前**，否则示例 1 里 0→1→0 会无限递归。

## 复杂度
时间 O(n²)：每个城市被 DFS 访问一次，每次扫一整行 n 个元素。
空间 O(n)：`visited` 数组 n 个布尔值，递归栈最深 n 层。

## 易错点
- 把 `visited[j] = True` 写在 for 循环之后 → 示例 1 中 0 和 1 互相递归，栈溢出或死循环；正确做法是进入 `dfs` 第一行就标记。
- 只遍历 `isConnected[j][k] == 1` 却忘了 `not visited[k]` 判断 → 对称矩阵里每条边被走两遍，示例 1 的 0↔1 会重复入栈；正确做法是条件写成 `isConnected[j][k] == 1 and not visited[k]`。

## 如果面试官追问
若 n 放大到 10⁵ 且边以列表给出，怎么办？答：改用并查集按边 union，最后数根节点个数，时间 O(E α(n))，不必开 n×n 矩阵。
