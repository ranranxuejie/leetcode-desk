## 一句话思路
单调栈求每个 `nums[i]` 作为最小值能撑开的最长区间，再看该区间长度能否满足 `nums[i] * k > threshold`。

## 怎么做
1. 用单调递增栈求每个位置 `i` 的左右边界：左边第一个 `< nums[i]` 的下标 `left[i]`，右边第一个 `< nums[i]` 的下标 `right[i]`。
2. 区间长度 `k = right[i] - left[i] - 1`，这是 `nums[i]` 能当最小值的最大子数组长度。
3. 若 `nums[i] * k > threshold`，直接返回 `k`；全部扫完无解返回 `-1`。

以 `nums = [1,3,4,3,1], threshold = 6` 为例：`i=2`（值 4）左边第一个更小是下标 1（值 3），右边第一个更小是下标 3（值 3），`k = 3 - 1 - 1 = 3`，检查 `4 * 3 = 12 > 6` 成立，返回 3。

```python
n = len(nums)
left = [-1] * n
right = [n] * n
st = []
for i in range(n):
    while st and nums[st[-1]] >= nums[i]:
        right[st.pop()] = i
    left[i] = st[-1] if st else -1
    st.append(i)
for i in range(n):
    k = right[i] - left[i] - 1
    if nums[i] * k > threshold:
        return k
return -1
```

关键点：`while` 里用 `>=` 弹出，保证相等元素只由最左那个负责整段区间，不会重复也不会漏。

## 复杂度
时间 O(n)：每个下标入栈出栈各一次，两趟线性扫描。
空间 O(n)：`left`、`right`、栈各开 n 个位置。

## 易错点
- 把条件写成 `nums[i] > threshold // k` → 遇到 `threshold=7, k=2` 时 `7//2=3`，`nums[i]=4` 被误判通过，而正确阈值是 3.5，`4 > 3.5` 其实也过；真正翻车在 `threshold=6, k=4`，`6//4=1` 会放过 `nums[i]=2`，但 `2 > 1.5` 也过——整除在边界上系统性偏松，必须用乘法 `nums[i] * k > threshold` 比较。
- 单调栈里用 `>` 而非 `>=` 弹栈 → 对 `[3,3,3]` 这类相等段，每个 3 的区间都被截断成 1，`k` 算小，漏掉 `k=3` 的解；正确做法是 `>=` 弹出，让相等元素中最左的那个拿到完整区间。

## 如果面试官追问
要求返回子数组的具体起止下标而非长度？答：`left[i]+1` 到 `right[i]-1` 就是该 `i` 对应的极大区间，命中时直接返回这对下标即可。
