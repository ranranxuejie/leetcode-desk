## 一句话思路
先枚举两两异或得到集合 S，再对每个 s∈S 与每个 nums[k] 异或，去重计数。

## 怎么做
1. 用集合 `pair` 存所有 `nums[i] ^ nums[j]`（i、j 可相同，i<=j 即可，异或对称所以只枚举 i<=j）。
2. 再对 `pair` 中每个值 `p` 与每个 `nums[k]` 异或，塞进 `ans` 集合。
3. 返回 `len(ans)`。

以 `nums = [1,3]` 为例：`pair` 枚举得 `{1^1=0, 1^3=2, 3^3=0}` 即 `{0,2}`；再对 `p=0` 与 `[1,3]` 异或得 `{1,3}`，对 `p=2` 得 `{3,1}`，合并 `ans={1,3}`，返回 2。

```python
pair = set()
for i in range(n):
    for j in range(i, n):
        pair.add(nums[i] ^ nums[j])
ans = set()
for p in pair:
    for x in nums:
        ans.add(p ^ x)
return len(ans)
```

关键点：`i<=j<=k` 允许重复下标，所以 `pair` 里必须包含 `i==j` 的情况（即 `nums[i]^nums[i]=0`），否则会漏掉 `(0,0,0)` 这类三元组。

## 复杂度
时间：O(n²) 枚举 pair + O(|pair|·n) 枚举三元组，|pair|≤n²，最坏 O(n³) 但实际远小。
空间：O(n²) 存 pair 集合，ans 集合最多 O(n²)。

## 易错点
- 输入 `nums=[1,3]`：若 `pair` 只枚举 `i<j`，漏掉 `0`，`ans` 只剩 `{3}`，错答 1。正确做法是 `range(i, n)` 让 `i==j` 参与。
- 输入 `nums=[6,7,8,9]`：若把 `pair` 当最终答案直接返回 `len(pair)`，得 6 而非 4。必须再与 `nums[k]` 异或一轮，因为三元组是三个元素。

## 如果面试官追问
问：n 到 10⁵ 怎么办？答：答案上界是 2^11（nums[i]≤1500），可用 bitset 或布尔数组标记可达异或值，把 pair 集合换成定长数组加速。
