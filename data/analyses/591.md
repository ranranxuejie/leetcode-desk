## 一句话思路
用栈存未闭合的 TAG_NAME，从左到右扫描：遇 `<` 就整段解析到 `>`，CDATA 整段跳过，标签名入栈出栈配对。

## 怎么做
1. 先确认 `code[0] == '<'` 且 `code[1]` 是大写字母，否则直接 `False`；栈初始为空。
2. 用指针 `i` 扫到每个 `<`，按 `code[i:i+9] == "<![CDATA["` 判断是否 CDATA：是则找后续第一个 `]]>`，找不到返回 `False`，找到就 `i` 跳到其后。
3. 否则找下一个 `>`，取 `code[i+1:j]` 作为标签体：以 `/` 开头是结束标签，弹出栈顶比对；否则是起始标签，校验后压栈。
4. 扫描结束后栈必须为空，且最后一个标签必须闭合到字符串末尾。

以示例 2 的 `<DIV>>> ![cdata[]] <![CDATA[<div>]>]]>]]>>]</DIV>` 为例：`i=0` 取到 `DIV` 压栈；扫到 `<![CDATA[` 时找第一个 `]]>`，落在 `<div>]>` 之后，CDATA_CONTENT 就是 `<div>]>`，其中的 `<div>` 不被解析；最后 `</DIV>` 弹出 `DIV`，栈空返回 `True`。

```python
def isValid(code):
    if not code or code[0] != '<': return False
    stack, i, n = [], 0, len(code)
    while i < n:
        if code.startswith('<![CDATA[', i):
            j = code.find(']]>', i)
            if j == -1: return False
            i = j + 3
        elif code.startswith('</', i):
            j = code.find('>', i)
            if j == -1 or not stack or stack.pop() != code[i+2:j]: return False
            i = j + 1
            if not stack and i != n: return False
        elif code[i] == '<':
            j = code.find('>', i)
            if j == -1: return False
            name = code[i+1:j]
            if not (1 <= len(name) <= 9 and name.isupper()): return False
            stack.append(name); i = j + 1
        else:
            i += 1
    return not stack
```

## 复杂度
时间 O(n)：`i` 单调右移，`find` 的区间不重叠，n 为 `code` 长度。
空间 O(n)：栈最多存 n/3 个标签名，无其他额外结构。

## 易错点
- 输入 `<DIV>abc</DIV>xyz`：只检查栈空会返回 `True`，但根标签闭合后还有 `xyz`。正确做法是弹出后若栈空且 `i != n` 立即 `False`。
- 输入 `<A><B></A></B>`：只比长度或只比集合会误判平衡。正确做法是栈顶必须等于 `</` 后的名字，`</A>` 时栈顶是 `B`，直接 `False`。
- 输入 `<A><![CDATA[x]]`：CDATA 缺 `]]>` 时 `find` 返回 -1，若没判就会把 `]]` 当普通字符继续扫，最后栈非空才失败，错误位置被掩盖。正确做法是 `find` 为 -1 立刻返回 `False`。

## 如果面试官追问
问：若 TAG_NAME 允许小写字母和数字，怎么改？
答：把 `name.isupper()` 换成 `name.isalnum()` 并保留长度 1~9 校验，其余逻辑不变。
