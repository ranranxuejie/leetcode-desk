## 一句话思路
统计字母频次，按「唯一字母」顺序解出每个数字的个数：z→0、w→2、u→4、x→6、g→8，再依次扣减推出其余数字。

## 怎么做
1. 用 `Counter(s)` 统计 26 个字母的频次，记为 `cnt`。
2. 先解出含唯一字母的数字：`cnt['z']` 即 0 的个数，`w`→2、`u`→4、`x`→6、`g`→8。
3. 每解出一个数字 d，就把它的英文单词里每个字母从 `cnt` 中减去 `cnt[d]` 份，为后续数字腾出唯一字母。
4. 剩余数字按 1(h)、3(r)、5(f)、7(s)、9(i) 的顺序解，最后按 0..9 拼接。

以 `s = "owoztneoer"` 为例：`cnt['z']=1` 得 0 有 1 个，扣掉 `"zero"` 后 `cnt['o']` 从 4 降到 3；接着 `cnt['w']=1` 得 2，扣 `"two"`；`cnt['u']=1` 得 4，扣 `"four"`；此时 `cnt['o']` 剩 1，`cnt['n']` 剩 1，`cnt['e']` 剩 1，解出 1，最终 `"012"`。

```python
from collections import Counter
cnt = Counter(s)
order = [('z','zero','0'), ('w','two','2'), ('u','four','4'),
         ('x','six','6'), ('g','eight','8'), ('h','three','3'),
         ('r','four','4'), ('f','five','5'), ('s','seven','7'),
         ('i','nine','9')]
res = [0] * 10
for key, word, d in order:
    n = cnt[key]
    res[int(d)] = n
    for ch in word:
        cnt[ch] -= n
return ''.join(str(i) * res[i] for i in range(10))
```

## 复杂度
时间：O(n + 10×5)，n 为 `len(s)`，字母统计一遍，后续常数次扣减。
空间：O(1)，`cnt` 最多 26 个键，`res` 长度 10。

## 易错点
- 扣减顺序写错：若先解 `h`（three）再解 `w`（two），`"two"` 里的 `t` 已被 three 扣走，导致 2 的个数偏小；必须严格按 z→w→u→x→g→h→r→f→s→i 的顺序，保证每个 key 在轮到它时仍是该数字独有。
- 扣减时用 `cnt[ch] -= n` 而非 `-= 1`：一个数字可能出现多次（如 `"zerozero"` 中 0 有 2 个），若只减 1，`cnt['o']` 残留会让后续 1 的计数偏大。

## 如果面试官追问
问：若数字范围扩到 0-99（英文单词），还能用这招吗？
答：不能靠唯一字母，需建字母-数字方程组或按词长/后缀分层消元，本质是解线性系统。
