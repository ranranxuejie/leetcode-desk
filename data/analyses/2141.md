## 一句话思路
对答案 T 二分：判定「能否让 n 台电脑同时跑满 T 分钟」只需看每块电池最多贡献 min(batteries[i], T)，其和是否 ≥ n*T。

## 怎么做
1. 二分的下界 lo=0，上界 hi=sum(batteries)//n（总电量平均分给 n 台，是答案的硬上限）。
2. 判定函数：`sum(min(b, mid) for b in batteries) >= n * mid`，成立则 mid 可行。
3. 以 n=2, batteries=[3,3,3] 为例：hi=9//2=4。mid=2 时 sum(min(b,2))=2+2+2=6 ≥ 4，可行；mid=3 时 3+3+3=9 ≥ 6，可行；mid=4 时 3+3+3=9 ≥ 8，可行，故返回 4。
4. 二分取上界写法：`lo, hi = 0, sum(batteries)//n`，循环 `while lo < hi`，`mid = (lo+hi+1)//2`，可行则 `lo = mid` 否则 `hi = mid-1`，最后返回 lo。

```python
lo, hi = 0, sum(batteries) // n
while lo < hi:
    mid = (lo + hi + 1) // 2
    total = 0
    for b in batteries:
        total += min(b, mid)
    if total >= n * mid:
        lo = mid
    else:
        hi = mid - 1
return lo
```

关键点：`min(b, mid)` 截断是因为一块电池最多只能给一台电脑供 mid 分钟，多出的电量在 T 时间内用不上，不能算进总供给。

## 复杂度
时间 O(m log(sum/n))，m 为电池数，log 来自二分答案。
空间 O(1)，只用了 lo/hi/mid/total 几个变量。

## 易错点
- 上界写成 `sum(batteries)` 而非 `sum(batteries)//n`：n=2, batteries=[3,3,3] 时 hi=9，mid 会探到 5、6 等值，虽然判定会否掉，但多跑几轮且 `n*mid` 变大，逻辑上没错却浪费；更危险的是若误把上界写成 `max(batteries)`，示例 1 会得 3 而非 4，因为三块 3 分钟电池接力能撑 4 分钟。
- 判定里漏掉 `min(b, mid)` 直接累加 `b`：n=2, batteries=[100,1,1] 时 sum=102 ≥ 2*mid 对 mid=50 也成立，会错答 50；正确是 min 截断后 50+1+1=52 ≥ 100 不成立，答案应为 2（受限于两块 1 分钟电池）。

## 如果面试官追问
问：若要求输出每台电脑的电池切换方案怎么办？
答：二分出 T 后，用双指针把电池按 min(b,T) 切片依次填满 n 条长度 T 的时间线即可。
