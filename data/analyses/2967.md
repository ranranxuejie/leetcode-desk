## 一句话思路
排序后取中位数，再在它附近枚举候选回文数（中位数本身、按前缀构造的上下两个回文），取最小代价。

## 怎么做
1. 排序 `nums`，取中位数 `mid = nums[n//2]`；目标值取中位数时绝对差之和最小。
2. 由 `mid` 的前缀构造两个回文：`p1`（前缀直接镜像，可能 ≤ mid）和 `p2`（前缀 +1 再镜像，可能 > mid），再加上 `mid` 本身。
3. 对每个候选 `c`，算 `sum(abs(x - c) for x in nums)`，取最小值。
4. 边界：`mid` 是 1 位数时前缀就是它本身，`p2` 可能进位成 11、101 等，仍要参与比较。

以 `nums = [10,12,13,14,15]` 为例：排序后 `mid = 13`，前缀 `"1"` 镜像得 `p1 = 11`，前缀 `"2"` 镜像得 `p2 = 22`。算代价：`c=11` 时 `1+1+2+3+4 = 11`，`c=13` 时 `3+1+0+1+2 = 7`，但 13 不是回文，所以候选只有 11 和 22，最终取 11。

```python
s = sorted(nums)
mid = s[len(s) // 2]
half = str(mid)[: (len(str(mid)) + 1) // 2]
cands = {mid}
for h in (int(half), int(half) + 1):
    t = str(h)
    cands.add(int(t + t[-2::-1]))   # 偶数位镜像
    cands.add(int(t + t[::-1]))     # 奇数位镜像
ans = min(sum(abs(x - c) for x in s) for c in cands)
```

## 复杂度
时间：排序 `O(n log n)`，枚举常数个候选各扫一遍 `O(n)`，总计 `O(n log n)`。
空间：排序额外 `O(n)`（或 `O(log n)` 栈），候选集合常数大小。

## 易错点
- 只试 `mid` 本身 → 对 `[10,12,13,14,15]` 会得 7，但 13 不是回文，正确答案是 11；必须把镜像构造出的 `p1`、`p2` 都算进去。
- 前缀加 1 后位数变化 → 对 `nums = [99,100]`，`mid = 100`，前缀 `"10"` 加 1 得 `"11"`，镜像成 111 而非 1010；构造时要按新前缀长度重新镜像，别直接拼接原串。

## 如果面试官追问
问：`nums[i]` 上限改成 `10^18` 还成立吗？
答：成立，回文构造只依赖位数，代价用 Python 大整数累加即可，复杂度不变。
