## 一句话思路
用大顶堆存 buy、小顶堆存 sell，每来一单就与对侧堆顶反复撮合，撮合不成就入堆。

## 怎么做
1. 维护 `buy`（存 `-price` 的大顶堆）和 `sell`（存 `price` 的小顶堆），元素为 `[price, amount]`。
2. 来 buy 单时，只要 `sell` 非空且 `sell[0][0] <= price`，就取最小卖单撮合，扣减 `amount`，卖单耗尽则 `heappop`。
3. 来 sell 单时对称处理：只要 `buy` 非空且 `-buy[0][0] >= price`，就与最高买单撮合。
4. 撮合完仍有剩余 `amount` 才入堆；最后把两堆的 `amount` 求和取模。

以示例 1 最后一单 `[30,4,0]` 为例：`sell` 堆顶是 `[15,2]`，`15 <= 30` 撮合掉 2 笔，`amount` 剩 2；堆顶变 `[25,1]`，`25 <= 30` 再撮合 1 笔，`amount` 剩 1；`sell` 空，剩的 1 笔 `[30,1]` 入 `buy` 堆。

```python
import heapq
buy, sell = [], []          # buy 存 -price
for price, amount, t in orders:
    if t == 0:
        while sell and amount and sell[0][0] <= price:
            p, a = sell[0]
            d = min(a, amount)
            amount -= d
            if a == d: heapq.heappop(sell)
            else: sell[0][1] -= d
        if amount: heapq.heappush(buy, [-price, amount])
    else:
        while buy and amount and -buy[0][0] >= price:
            p, a = buy[0]
            d = min(a, amount)
            amount -= d
            if a == d: heapq.heappop(buy)
            else: buy[0][1] -= d
        if amount: heapq.heappush(sell, [price, amount])
```

## 复杂度
时间：O(n log n)，n 为订单批数，每批最多入堆一次、出堆一次，每次堆操作 log n。
空间：O(n)，两个堆最多各存 n 个 `[price, amount]`。

## 易错点
1. 部分撮合时直接 `heappop` 再重新 `heappush` 剩余量，会把同一价格反复进出堆；正确做法是原地改 `sell[0][1] -= d`，只有 `a == d` 才弹出。
2. 示例 2 中 `amount` 累加到 1999999991，若在循环里对每笔 `amount` 取模会破坏撮合计数；正确做法是全程用原始整数累加，只在最后 `sum(...) % (10**9 + 7)`。

## 如果面试官追问
问：如果要求输出最终积压订单的具体价格分布而非总数？答：两堆本身就是分布，遍历 `buy` 取 `-p`、`sell` 取 `p`，按价格合并同价 `amount` 输出即可。
