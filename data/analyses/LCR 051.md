## 一句话思路
后序 DFS 返回「以当前节点为端点、向下单边延伸的最大和」，同时用左右两支拼出穿过当前节点的完整路径更新全局答案。

## 怎么做
1. 定义 `dfs(node)` 返回以 `node` 为顶端、只走一侧的最大贡献值，空节点返回 0。
2. 递归取 `left = max(dfs(node.left), 0)`、`right = max(dfs(node.right), 0)`，负数支直接砍掉。
3. 用 `node.val + left + right` 更新全局 `ans`，这是唯一允许「左右都用」的地方。
4. 向上返回 `node.val + max(left, right)`，因为父节点只能接一支。

以示例 2 的 `20` 节点为例：`left = 15`、`right = 7`，`ans = 20 + 15 + 7 = 42`；向上返回 `20 + 15 = 35` 给 `-10`。到根 `-10` 时 `left = 35`、`right = 0`，`ans` 仍为 42，返回 `25`。

```python
def dfs(node):
    nonlocal ans
    if not node:
        return 0
    left = max(dfs(node.left), 0)
    right = max(dfs(node.right), 0)
    ans = max(ans, node.val + left + right)
    return node.val + max(left, right)

ans = -2**31
dfs(root)
return ans
```

## 复杂度
时间 O(n)：每个节点进 `dfs` 一次，常数次加法比较。
空间 O(h)：递归栈深度，最坏链状树 h = n，未开额外数组。

## 易错点
- 全负树如 `[-3]`：若 `ans` 初始化为 0，会错答 0；正确做法是初始化 `-2**31`（题目保证答案在 32 位内），让单节点负值也能被记录。
- 把 `node.val + left + right` 当作返回值：在示例 2 的 `20` 处会向上返回 42，根 `-10` 再算 `-10 + 42 = 32`，覆盖掉正确答案；返回值必须是 `node.val + max(left, right)`，只留一支。

## 如果面试官追问
问：要输出这条最大路径的节点序列怎么办？
答：`ans` 更新时同步记录 `(node, left, right)` 三元组，最后从该节点向两侧回溯收集。
