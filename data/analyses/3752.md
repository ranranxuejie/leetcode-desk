## 一句话思路
先判 `target` 是否落在 `[-S, S]` 且与 `S` 同奇偶（`S = n(n+1)/2`），再贪心让前缀尽量负。

## 怎么做
1. 记 `S = n*(n+1)//2`。数组和等于「全正和 S」减去「被取负的数的两倍」，所以 `target = S - 2*neg`，`neg` 必须是整数，即 `S - target` 必须是非负偶数且 `≤ 2S`，否则返回 `[]`。
2. 令 `need = (S - target) // 2`，即需要选出一组互不相同的 1..n 使其和恰为 `need`。
3. 字典序最小 = 前面的位置尽量小，所以从 `n` 往下贪心：能取就取（`need >= i`），取完 `need -= i`，这些数取负号。
4. 剩下的数保持正号，按 1..n 顺序输出。

以 `n = 3, target = 0` 为例：`S = 6`，`need = 3`。`i=3` 时 `need >= 3`，取负，`need` 变 0；`i=2,1` 都不取。结果 `[-3, 1, 2]`。

```python
S = n * (n + 1) // 2
d = S - target
if d < 0 or d > 2 * S or d % 2:
    return []
need = d // 2
neg = set()
for i in range(n, 0, -1):
    if need >= i:
        neg.add(i)
        need -= i
return [-i if i in neg else i for i in range(1, n + 1)]
```

贪心正确性：从大到小取，保证「取负的集合」在字典序意义下最优——越大的数越早被牺牲，小数字留在前面当正数，前缀就最小。

## 复杂度
时间：O(n)，一次倒序贪心加一次正序构造。
空间：O(n)，`neg` 集合与答案数组各占 n。

## 易错点
- `n = 1, target = 10**10`：若只判 `abs(target) <= S` 就漏了奇偶与上界，会错误进入贪心；正确做法是先算 `d = S - target`，要求 `0 <= d <= 2*S` 且 `d % 2 == 0`，否则直接 `[]`。
- `n = 3, target = 6`：`d = 0`，`need = 0`，一个都不取负，答案是 `[1,2,3]`；若写成「从 1 开始取」或漏判 `need >= i`，会得到 `[-1,...]` 这类和不对的结果。

## 如果面试官追问
若要求返回字典序最大的数组？答：把贪心方向反过来，从 1 往上取负，等价于让前缀尽量大。
