## 一句话思路
先 BFS 出马到每个兵（及起点）的最短步数，再在兵集合上做位掩码博弈 DP：Alice 取 max、Bob 取 min。

## 怎么做
1. 把起点 `(kx,ky)` 和所有 `positions[i]` 当作节点，对每个节点跑一次 50×50 的 BFS，得到 `dist[i][j]`（第 i 个兵到第 j 个兵，`dist[n][j]` 是起点到第 j 个兵）。
2. 状态 `dp[mask][i]`：已吃掉的兵集合为 `mask`、马当前停在兵 `i` 上时，剩余游戏还能产生的总移动次数。
3. 转移：`turn = popcount(mask)`，偶数步是 Alice（取 max），奇数步是 Bob（取 min），枚举未吃的 `j`，加 `dist[i][j]`。
4. 答案是 `max_j dist[n][j] + dp[1<<j][j]`，因为 Alice 第一步也要计入。

用示例 2：`kx=0,ky=2`，三个兵。BFS 得起点到 (2,2) 是 2 步、(3,3) 是 2 步、(1,1) 是 4 步；兵之间 (2,2)→(3,3) 是 2 步。Alice 先取 (2,2) 得 2，Bob 取 (3,3) 再加 2，最后 (1,1) 加 4，合计 8。

```python
from functools import lru_cache
from collections import deque

@lru_cache(None)
def dp(mask, i):
    if mask == (1 << n) - 1:
        return 0
    alice = bin(mask).count('1') % 2 == 0
    best = -1 if alice else 10**9
    for j in range(n):
        if not (mask >> j) & 1:
            v = dist[i][j] + dp(mask | (1 << j), j)
            best = max(best, v) if alice else min(best, v)
    return best

ans = max(dist[n][j] + dp(1 << j, j) for j in range(n))
```

## 复杂度
时间：BFS 共 (n+1)×2500，DP 为 2^n·n^2，n≤15。
空间：`dist` 是 (n+1)^2，DP 表 2^n·n，BFS 队列 2500。

## 易错点
- 忘记把 Alice 第一步的 `dist[n][j]` 加进去，只返回 `dp` → 示例 1 会输出 0 而不是 4；正确是外层 `max` 里显式加起点距离。
- 用 `mask` 的位数判断回合时写成 `n - popcount(mask)` 的奇偶 → 示例 2 的三人局会整体错位一步，Alice/Bob 角色互换；正确用已吃数量 `popcount(mask)` 的奇偶，0 个已吃是 Alice。

## 如果面试官追问
若兵数涨到 20 以上怎么办？答：2^n·n^2 的 DP 会爆，需要换思路（如利用棋盘距离的度量性质剪枝），但本题 n≤15 就是为位掩码 DP 设的。
