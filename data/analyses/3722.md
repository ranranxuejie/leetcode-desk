## 一句话思路
枚举所有 2n 种反转，直接取字典序最小；n≤1000 时 2n 次比较完全够用。

## 怎么做
1. 把「反转前 k 个」和「反转后 k 个」统一成对 `s` 的切片拼接，k 从 1 到 n 各试一次。
2. 前 k 个反转：`s[k-1::-1] + s[k:]`；后 k 个反转：`s[:n-k] + s[n-1:n-k-1:-1]`，注意 `n-k-1 == -1` 时切片会退化成空串，必须写成 `s[n-1:n-k-1 if n-k-1 >= 0 else None:-1]` 或直接用 `s[n-k:][::-1]`。
3. 用 `min` 累积答案，初始值设为 `s` 本身（虽然操作后一定变，但省一次特判）。
4. 以 `s = "dcab"` 为例：k=3 时前段反转得 `"acd"`，拼上 `s[3:]="b"` 得 `"acdb"`；k=1 时前段反转仍是 `"dcab"`，k=4 时得 `"bacd"`，最终 `min` 选出 `"acdb"`。

```python
n = len(s)
ans = s
for k in range(1, n + 1):
    ans = min(ans, s[k-1::-1] + s[k:])
    ans = min(ans, s[:n-k] + s[n-k:][::-1])
return ans
```

关键中间值：`s="dcab"`, `k=3` 时 `s[2::-1]="acd"`，`s[3:]="b"`，拼接 `"acdb"`。

## 复杂度
时间 O(n²)：2n 种候选，每次切片+比较 O(n)。
空间 O(n)：每次拼接生成新串，`ans` 只存一个。

## 易错点
- `s = "abba"`，后 k 个反转若写成 `s[n-1:n-k-1:-1]`，k=3 时 `n-k-1 = 0`，切片 `s[3:0:-1]` 得 `"bb"` 少了首字符，拼出 `"abb"` 而非 `"aabb"`；正确做法是 `s[n-k:][::-1]` 先取后缀再反转。
- `s = "zxy"`，若只枚举「反转前 k 个」会漏掉后段方案，k=2 时前段得 `"xzy"` 恰好是答案，但 `s = "abba"` 的答案 `"aabb"` 只能由后段 k=3 得到，必须两个方向都枚举。

## 如果面试官追问
追问：n 放大到 10⁵ 怎么办？
答：答案首位只能是 `s` 中最小字符，只需枚举把该字符转到首位的 k，候选数降到出现次数级别。
