## 一句话思路
快慢指针让 `fast` 先走 k 步，再同步走到尾，`slow` 正好落在倒数第 k 个节点。

## 怎么做
1. 用 `fast` 从 `head` 走 k 步，停在正数第 k 个节点，记作 `first`。
2. `slow = head`，`fast` 和 `slow` 一起走，直到 `fast.next is None`，此时 `slow` 是倒数第 k 个，记作 `second`。
3. 交换 `first.val` 和 `second.val`，返回 `head`。

以 `head = [1,2,3,4,5], k = 2` 为例：`fast` 走 2 步停在值为 2 的节点，`first = 2`；随后 `fast` 从 2 走到 5 共 3 步，`slow` 从 1 走 3 步停在值为 4 的节点，`second = 4`。交换后得 `[1,4,3,2,5]`。

```python
first = head
for _ in range(k - 1):
    first = first.next
second = head
fast = first
while fast.next:
    fast = fast.next
    second = second.next
first.val, second.val = second.val, first.val
return head
```

注意 `fast` 从 `first` 出发而不是 `head`，这样 `slow` 与 `fast` 的偏移量恰好是 k-1，`fast` 到尾部时 `slow` 就是倒数第 k 个。当 k 等于 n 时，`first` 就是尾节点，`while fast.next` 一次都不进，`second` 仍是 `head`，正好是倒数第 n 个，逻辑自洽。

## 复杂度
时间 O(n)：`fast` 先走 k-1 步，再走 n-k 步，合计 n-1 步。
空间 O(1)：只开了 `first`、`second`、`fast` 三个指针。

## 易错点
- `head = [1,2], k = 1` → 若把 `fast` 从 `head` 出发同步走，`slow` 会停在值为 1 的节点而非倒数第 1 个（值为 2），交换变成自己和自己换，输出 `[1,2]` 错。正确做法是 `fast` 从 `first` 出发，让偏移量固定为 k-1。
- `head = [1,2,3], k = 2` → 若写成交换节点而非交换值，需要处理 `first` 与 `second` 相邻、`first` 是 `head` 等指针重连分支，容易断链。本题只要求交换值，直接 `first.val, second.val = second.val, first.val` 即可，别去动 `next`。

## 如果面试官追问
问：如果要求交换节点本身而不是值呢？
答：先定位 `first` 和 `second` 的前驱，分「相邻」和「不相邻」两种情形重连 `next`，`first` 是 `head` 时还要更新返回值。
