## 一句话思路
用 DP + 单调队列：`dp[i]` 表示前 i 个箱子运完的最少行程，转移时把「码头切换次数」拆成前缀和，用单调队列维护窗口内最优值。

## 怎么做
1. 预处理前缀和：`w[i]` 为前 i 个箱子总重，`c[i]` 为前 i 个箱子中「与前一个箱子码头不同」的次数（`c[0]=0`，`c[i]=c[i-1]+(boxes[i-1][0]!=boxes[i-2][0])`）。
2. 定义 `dp[i]` = 运完前 i 个箱子的最少行程，`dp[0]=0`。最后一趟运 `(j, i]` 这批箱子，行程 = `dp[j] + 1 + (c[i]-c[j+1]) + 1`，即「去程 1 趟 + 途中码头切换 `c[i]-c[j+1]` 次 + 回仓库 1 趟」。
3. 约束：`i-j <= maxBoxes` 且 `w[i]-w[j] <= maxWeight`，j 的合法区间是 `[lo, i-1]`，lo 随 i 单调右移，用双指针维护。
4. 把转移式整理成 `dp[i] = c[i] + 2 + min(dp[j] - c[j+1])`，对 `dp[j]-c[j+1]` 用单调队列取窗口最小值。

以示例 1 `boxes=[[1,1],[2,1],[1,1]]` 为例：`c=[0,0,1,2]`，`w=[0,1,2,3]`。算 `dp[3]` 时 j 可取 0/1/2，`dp[j]-c[j+1]` 分别为 `0-0=0`、`2-1=1`、`4-2=2`，取最小 0，得 `dp[3]=c[3]+2+0=4`，与答案一致。

```python
from collections import deque
n = len(boxes)
w = [0]*(n+1); c = [0]*(n+1)
for i in range(1, n+1):
    w[i] = w[i-1] + boxes[i-1][1]
    c[i] = c[i-1] + (i > 1 and boxes[i-1][0] != boxes[i-2][0])
dp = [0]*(n+1)
q = deque([0])          # 存 j，值 = dp[j]-c[j+1]
lo = 0
for i in range(1, n+1):
    while w[i]-w[lo] > maxWeight or i-lo > maxBoxes:
        lo += 1
    while q and q[0] < lo:
        q.popleft()
    dp[i] = c[i] + 2 + (dp[q[0]] - c[q[0]+1])
    val = dp[i] - c[i+1] if i < n else 0
    while q and dp[q[-1]] - c[q[-1]+1] >= val:
        q.pop()
    q.append(i)
return dp[n]
```

## 复杂度
时间 O(n)：每个下标进出单调队列各一次，双指针 lo 单调右移。
空间 O(n)：`w`、`c`、`dp` 三个长度 n+1 的数组加一个队列。

## 易错点
1. 转移里写成 `c[i]-c[j]` 而非 `c[i]-c[j+1]`：示例 1 中 j=0 时 `c[1]-c[0]=0` 恰好对，但 j=1 时 `c[3]-c[1]=2` 会多算一次切换，`dp[3]` 错成 5。正确是 `c[i]-c[j+1]`，因为第 j+1 个箱子是这趟的第一个，不产生切换。
2. 单调队列弹出条件用 `>` 而非 `>=`：当 `dp[j]-c[j+1]` 相等时保留旧下标，旧下标更小、更早过期，会让窗口提前失效。用 `>=` 保证队列里下标单调递增、值严格递增。

## 如果面试官追问
问：如果要求输出每趟运哪些箱子，怎么改？
答：在 `dp[i]` 取到最小值时记录对应的 j（即队列头），最后从 n 回溯 j 链即可还原每趟区间。
