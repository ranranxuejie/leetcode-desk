## 一句话思路
从 entrance 做 BFS 逐层扩展，第一次碰到边界空格子时的层数就是最短步数。

## 怎么做
1. 把 `entrance` 入队，`steps = 0`，并把入口标记为已访问（改成 `'+'` 或另开 visited）。
2. 每轮先记下当前队列长度 `size`，只弹出这 `size` 个节点，`steps += 1`。
3. 对弹出的每个 `(r, c)` 检查四个邻居：越界或 `maze[nr][nc] == '+'` 就跳过。
4. 邻居合法时先判断它是否在边界（`nr == 0 or nr == m-1 or nc == 0 or nc == n-1`），是就直接返回 `steps`；否则标记并入队。

用示例 1：`entrance = [1,2]`，第 0 层队列是 `[(1,2)]`。`steps` 变 1 后弹出 `(1,2)`，邻居 `(0,2)` 是 `'.'` 且在边界（`nr == 0`），立即返回 1。注意 `(1,0)` 也是出口，但它在第 2 层才被访问到，BFS 保证先返回更近的。

```python
from collections import deque
q = deque([tuple(entrance)])
maze[entrance[0]][entrance[1]] = '+'
steps = 0
while q:
    steps += 1
    for _ in range(len(q)):
        r, c = q.popleft()
        for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < m and 0 <= nc < n and maze[nr][nc] == '.':
                if nr in (0, m-1) or nc in (0, n-1):
                    return steps
                maze[nr][nc] = '+'
                q.append((nr, nc))
return -1
```

## 复杂度
时间 O(m·n)：每个格子最多入队一次，四个方向常数次检查。
空间 O(m·n)：队列最坏存下整层格子，原地改 `maze` 省掉 visited 数组。

## 易错点
- 入口本身在边界时（如示例 3 的 `[0,0]`，或 `maze = [["."]]`）→ 若把入口当出口直接返回 0 → 入口不算出口，必须从它的邻居开始判边界，示例 3 应返回 -1。
- 把边界判断放在入队之后、或先入队再判 → 同一层里较远的出口可能先被弹出，返回的 `steps` 偏大 → 必须在「邻居合法且是边界」的瞬间返回当前 `steps`，此时 `steps` 正好是走到该邻居的步数。

## 如果面试官追问
要求输出路径而不只是步数怎么办？答：BFS 时给每个格子存 `parent` 指针，命中出口后从出口回溯到 entrance 再反转。
