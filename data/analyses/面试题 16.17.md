## 一句话思路
用 Kadane 动态规划：维护以当前元素结尾的最大和 `cur`，全局最大 `best` 取历史最大。

## 怎么做
1. 初始化 `cur = best = nums[0]`，从下标 1 开始扫。
2. 每步更新 `cur = max(nums[i], cur + nums[i])`——要么接着前面，要么从自己重开。
3. 每步用 `best = max(best, cur)` 记录历史峰值。
4. 扫完返回 `best`。

以官方示例 `[-2,1,-3,4,-1,2,1,-5,4]` 为例，扫到 `4`（下标 3）时，前一步 `cur = -2`，`cur + 4 = 2 < 4`，所以 `cur` 重置为 `4`；继续累加 `-1,2,1` 得 `cur = 6`，此时 `best` 从 4 更新到 6。关键中间值：`i=6` 时 `cur = 6`，`best = 6`。

```python
cur = best = nums[0]
for x in nums[1:]:
    cur = max(x, cur + x)   # 接上 or 重开
    best = max(best, cur)
return best
```

注意 `cur` 的含义是「必须以 `nums[i]` 结尾」，不是「前 i 个里的最优」——后者是 `best`。这个区分决定了转移式里为什么是 `cur + x` 而不是 `best + x`。

## 复杂度
时间 O(n)：一次遍历，每个元素常数次比较。
空间 O(1)：只开 `cur`、`best` 两个变量，无额外数组。

## 易错点
- 全负数输入如 `[-3,-1,-2]` → 若把 `cur` 初始化为 0，`max(0, cur+x)` 会一直得 0，返回 0 而非 -1 → 必须用 `nums[0]` 初始化，且转移式写成 `max(x, cur + x)` 而不是 `max(0, cur + x)`。
- 单元素输入 `[1]` 或 `[-1]` → 若循环写成 `for x in nums` 且先更新 `cur` 再初始化 `best`，会把首元素算两遍或漏掉 → 从 `nums[1:]` 开始扫，`best` 初值就是 `nums[0]`。

## 如果面试官追问
问：要求返回子数组的起止下标怎么办？
答：加 `start` 记录 `cur` 重开的位置，`best` 更新时同步存 `(start, i)`，仍是 O(n)。
