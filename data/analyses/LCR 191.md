## 一句话思路
用前缀积和后缀积各扫一遍，`arrayB[i] = 左侧积 × 右侧积`，避开除法与零元素。

## 怎么做
1. 先建 `res = [1] * n`，把 `res[i]` 当作「i 左侧所有元素的积」填进去。
2. 从左往右扫，`res[i] = res[i-1] * arrayA[i-1]`，这一步结束时 `res[i]` 就是左积。
3. 再从右往左扫，维护一个变量 `right` 表示「i 右侧所有元素的积」，令 `res[i] *= right`，然后 `right *= arrayA[i]`。
4. 返回 `res`。

以 `arrayA = [2, 4, 6, 8, 10]` 为例，第 2 步结束后 `res = [1, 2, 8, 48, 384]`；第 3 步从 `i=4` 开始，`right` 初值 1，`res[4] = 384*1 = 384`，随后 `right = 10`；到 `i=2` 时 `right = 8*10 = 80`，`res[2] = 8*80 = 640`，与输出一致。

```python
n = len(arrayA)
res = [1] * n
for i in range(1, n):
    res[i] = res[i - 1] * arrayA[i - 1]
right = 1
for i in range(n - 1, -1, -1):
    res[i] *= right
    right *= arrayA[i]
return res
```

关键点：`res` 被复用了两次，第一次存左积，第二次乘上右积就地变成答案，不需要额外开两个数组。

## 复杂度
时间：O(n)，两次线性扫描，`n = len(arrayA)`。
空间：O(1) 额外（不算返回的 `res`），只多了 `right` 一个变量。

## 易错点
- 输入含 0，如 `arrayA = [0, 1, 2]` → 若用「总积除以当前元素」会除零崩溃，且多个 0 时结果全为 0 也不对 → 必须用前缀/后缀积，`[0,1,2]` 应得 `[2, 0, 0]`。
- 输入长度为 1，如 `arrayA = [5]` → 若循环写成 `range(1, n)` 之外的边界处理不当会返回 `[5]` 或越界 → 正确结果是 `[1]`（排除唯一元素后空集的积），代码中 `res = [1]`、两个循环都不执行，恰好得 `[1]`。

## 如果面试官追问
问：如果要求答案按 32 位截断怎么办？
答：Python 整数不溢出，需在每步乘完后手动 `& 0xFFFFFFFF` 再转回有符号，或最后统一取模。
