## 一句话思路
对两棵树的每个对应节点，递归判断「不翻」和「翻」两种配对，任一成立即等价。

## 怎么做
1. 先处理终止：`root1 is None and root2 is None` 返回 `True`，只有一个为 `None` 返回 `False`。
2. 值不等直接返回 `False`，这是剪枝的关键，别等到叶子才判。
3. 递归两种配对：`(root1.left, root2.left) and (root1.right, root2.right)`，或交叉配对 `(root1.left, root2.right) and (root1.right, root2.left)`。
4. 两者取 `or` 返回。

用示例 1 走一步：根都是 `1`，进入 `root1.left=2` 与 `root2.left=3` 的配对，值不等，所以「不翻」分支立刻失败；转去交叉配对 `(2, root2.right=2)`，值相等，继续往下，最终返回 `True`。这一步说明为什么必须写 `or` 而不是只比同侧。

```python
def dfs(a, b):
    if a is None and b is None:
        return True
    if a is None or b is None:
        return False
    if a.val != b.val:
        return False
    return (dfs(a.left, b.left) and dfs(a.right, b.right)) or \
           (dfs(a.left, b.right) and dfs(a.right, b.left))
```

注意 `dfs(a.left, b.right)` 里 `b.right` 可能为 `None`，靠第 1、2 行兜住，不要提前取 `.val`。

## 复杂度
时间 O(min(n1, n2))，每个节点对最多展开一次，值不等时提前返回。
空间 O(h)，递归栈深度等于树高，最坏链状为 n。

## 易错点
- 只写同侧比较 `dfs(a.left,b.left) and dfs(a.right,b.right)`：示例 1 中 `2` 对 `3` 直接返回 `False`，漏掉交叉配对，正确答案 `True` 被判错。必须两种配对取 `or`。
- 先取 `a.val` 再判空：示例 3 中 `root2=[1]`，递归到 `dfs(None, 1)` 时若先访问 `.val` 会抛 `AttributeError`。正确顺序是先判 `None` 再比值。

## 如果面试官追问
要求输出具体翻转了哪些节点怎么办？答：把 `or` 改成先试同侧、失败再试交叉，并在选交叉时把当前节点值记入结果列表，回溯时撤销。
