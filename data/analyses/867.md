## 一句话思路
新建 `n` 行 `m` 列的结果矩阵，把 `matrix[i][j]` 填到 `res[j][i]`，行列索引互换即转置。

## 怎么做
1. 取 `m = len(matrix)`、`n = len(matrix[0])`，结果矩阵是 `n × m`。
2. 建 `res = [[0] * m for _ in range(n)]`，注意外层和内层长度不能写反。
3. 双重循环遍历原矩阵，执行 `res[j][i] = matrix[i][j]`。
4. 返回 `res`。

以示例 2 的 `matrix = [[1,2,3],[4,5,6]]` 为例，`m=2, n=3`，`res` 初始为 `[[0,0],[0,0],[0,0]]`。当 `i=0, j=1` 时，`matrix[0][1]=2` 被写入 `res[1][0]`，此时 `res` 变成 `[[1,0],[2,0],[0,0]]`，这正是「第 0 行第 1 列搬到第 1 行第 0 列」。

```python
m, n = len(matrix), len(matrix[0])
res = [[0] * m for _ in range(n)]
for i in range(m):
    for j in range(n):
        res[j][i] = matrix[i][j]
return res
```

关键就一行 `res[j][i] = matrix[i][j]`：下标顺序反过来，就是转置的全部含义。不要试图原地交换，非方阵根本装不下。

## 复杂度
时间：O(m·n)，每个元素恰好访问一次，`m` 行 `n` 列都算进去。
空间：O(m·n)，额外开了 `res` 这个 `n × m` 的新矩阵，输入本身不计。

## 易错点
- 输入 `[[1,2,3],[4,5,6]]`（2×3）→ 若写成 `[[0] * n for _ in range(m)]` 得到 2×3 的 `res`，填 `res[j][i]` 时 `j` 最大到 2 会越界 → 正确是 `[[0] * m for _ in range(n)]`，先 `n` 行再 `m` 列。
- 建矩阵写成 `[[0] * m] * n` → 示例 1 里 `res[0][0]=1` 后 `res[1][0]`、`res[2][0]` 也变成 1，三行共享同一列表 → 必须用列表推导，每行独立创建。

## 如果面试官追问
追问：如果要求原地转置、不许开新矩阵怎么办？
答：只有方阵能原地做，遍历上三角 `i < j` 交换 `matrix[i][j]` 与 `matrix[j][i]`；非方阵必须新开空间。
