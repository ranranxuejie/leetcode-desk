## 一句话思路
用 dp[i] 表示前 i 个元素的最大和，枚举最后一段长度 j（1≤j≤k），取 max(arr[i-j:i]) * j + dp[i-j] 的最大值。

## 怎么做
1. 定义 dp 数组，dp[0]=0，dp[i] 表示 arr 前 i 个元素分隔后的最大和。
2. 对每个 i 从 1 到 n，枚举最后一段长度 j 从 1 到 min(k, i)。
3. 在枚举 j 时维护当前段最大值 mx，dp[i] = max(dp[i], dp[i-j] + mx * j)。
4. 返回 dp[n]。

以示例 1 为例，arr=[1,15,7,9,2,5,10]，k=3。计算 dp[3] 时，j=1 得 dp[2]+7=16+7=23；j=2 得 dp[1]+max(15,7)*2=1+30=31；j=3 得 dp[0]+max(1,15,7)*3=45，取最大 45。最终 dp[7]=84。

```python
n = len(arr)
dp = [0] * (n + 1)
for i in range(1, n + 1):
    mx = 0
    for j in range(1, min(k, i) + 1):
        mx = max(mx, arr[i - j])
        dp[i] = max(dp[i], dp[i - j] + mx * j)
return dp[n]
```

## 复杂度
时间：O(nk)，外层 n 次、内层最多 k 次，每次 O(1)。
空间：O(n)，dp 数组长度 n+1，无其他额外空间。

## 易错点
1. 内层循环 j 的上界写成 k 而非 min(k, i) → 当 i<k 时 arr[i-j] 下标为负，Python 会静默取到数组尾部元素算出错误值 → 必须用 min(k, i) 限制。
2. 维护 mx 时写成先更新 dp 再更新 mx，或把 mx 放在 j 循环外 → 段最大值没有随 j 扩大而更新，dp[i] 偏小 → 必须在每轮 j 内先 `mx = max(mx, arr[i-j])` 再算 dp[i]。

## 如果面试官追问
问：若要求输出具体分隔方案而非只返回和？
答：额外开一个 choice 数组记录每个 i 取得最优时的 j，最后从 n 回溯即可还原每段长度。
