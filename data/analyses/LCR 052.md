## 一句话思路
中序遍历按序取节点，边遍历边用 `prev.right = cur` 串成右链，`prev` 初始为哑节点。

## 怎么做
1. 建哑节点 `dummy`，令 `prev = dummy`，`cur = root`。
2. 用 Morris 中序（`cur` 无左孩子就访问并右移，有左孩子就找左子树最右节点 `pre` 接回 `cur`），省掉递归栈。
3. 访问节点时执行 `prev.right = cur; cur.left = None; prev = cur`，把当前节点挂到链尾并断左指针。
4. 遍历结束返回 `dummy.right`。

以示例 1 为例，中序访问到 `2` 时，`prev` 是刚访问的 `1`，执行 `prev.right = 2`、`2.left = None`，此时链为 `dummy→1→2`；继续访问 `3` 时 `prev` 变成 `2`，链延长为 `1→2→3`。最终 `dummy.right` 指向 `1`。

```python
dummy = TreeNode(0)
prev, cur = dummy, root
while cur:
    if not cur.left:
        prev.right = cur
        cur.left = None
        prev = cur
        cur = cur.right
    else:
        pre = cur.left
        while pre.right and pre.right is not cur:
            pre = pre.right
        if not pre.right:
            pre.right = cur
            cur = cur.left
        else:
            pre.right = None
            prev.right = cur
            cur.left = None
            prev = cur
            cur = cur.right
return dummy.right
```

## 复杂度
时间 O(n)：每个节点被访问常数次，Morris 找前驱的均摊代价是 O(n)。
空间 O(1)：只用了 `dummy`、`prev`、`cur`、`pre` 四个指针，没有递归栈。

## 易错点
1. 输入 `[5,1,7]` 时若忘记 `cur.left = None`，节点 `5` 仍挂着左孩子 `1`，输出会变成带左子树的树而非纯右链；每次挂链后必须显式断左指针。
2. 输入 `[2,1,3]` 时若在 Morris 的「第二次到达 `cur`」分支里漏掉 `pre.right = None`，会形成 `1→2` 的环，`while pre.right` 死循环；恢复前驱右指针必须在访问 `cur` 之前完成。

## 如果面试官追问
问：不允许改原树结构怎么办？
答：先中序收集节点到列表，再新建节点按序串右链，空间 O(n) 换不改原树。
