## 一句话思路
用递归定位：S_n 长度是 2^n−1，中点必为 "1"，按 k 落在左半、中点、右半分别处理，右半要翻转答案。

## 怎么做
1. 先算 `mid = 2**(n-1)`，即 S_n 的中点位置（S_n 长度 `2**n - 1`，中点恰是 `2**(n-1)`）。
2. `k == mid` 直接返回 `"1"`；`k < mid` 递归 `findKthBit(n-1, k)`。
3. `k > mid` 时，右半是 `reverse(invert(S_{n-1}))`，位置 `k` 对应左半的 `mid*2 - k`，结果取反。
4. 递归到 `n == 1` 返回 `"0"`。

以 `n = 4, k = 11` 为例：`mid = 8`，`k > mid`，映射到 `2*8 - 11 = 5`，进入 `n=3, k=5`；此时 `mid = 4`，`k > 4`，映射到 `2*4 - 5 = 3`，进入 `n=2, k=3`；`mid = 2`，`k > 2`，映射到 `2*2 - 3 = 1`，进入 `n=1, k=1` 得 `"0"`。沿途翻转了 3 次（`k=11`、`k=5`、`k=3` 三次都走右半），`"0"` 翻 3 次变 `"1"`，与示例输出一致。

```python
def findKthBit(n, k):
    if n == 1:
        return "0"
    mid = 1 << (n - 1)
    if k == mid:
        return "1"
    if k < mid:
        return findKthBit(n - 1, k)
    bit = findKthBit(n - 1, mid * 2 - k)
    return "1" if bit == "0" else "0"
```

关键就三行：`mid = 1 << (n-1)`、右半映射 `mid*2 - k`、返回时取反。注意映射公式不是 `k - mid`，因为右半是**反转**后的，位置要从右往左数。

## 复杂度
时间：O(n)，每层 n 减 1，最多递归 n 层。
空间：O(n)，递归栈深度 n，无额外字符串。

## 易错点
- 右半映射写成 `k - mid` → 对 `n=4, k=11` 会算成 `11-8=3`，递归到 `n=3,k=3` 得 `"1"`，不翻转直接返回 `"1"`，碰巧对；但 `n=4,k=9` 会算成 `1`，得 `"0"` 不翻转返回 `"0"`，而正确答案是 `"1"`。正确映射是 `mid*2 - k`。
- 忘记取反 → 对 `n=2, k=3`，`mid=2`，映射到 `1` 得 `"0"`，不取反返回 `"0"`，但 S_2 = "011" 第 3 位是 `"1"`。凡是走右半分支，返回值必须翻转。

## 如果面试官追问
问：n 很大（如 n=10^5）但 k 很小，还能递归吗？
答：能，但递归深度是 n 会爆栈；改成 while 循环，每轮 `n -= 1`，用 `flip` 布尔累计翻转次数，最后按 `flip` 决定是否取反。
