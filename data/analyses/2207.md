## 一句话思路
插入 `pattern[0]` 放最前或 `pattern[1]` 放最后，增益分别是 `count(pattern[1])` 和 `count(pattern[0])`，取大者加到原有子序列数上。

## 怎么做
1. 先扫一遍 `text`，用 `cnt0`、`cnt1` 记 `pattern[0]`、`pattern[1]` 出现次数，同时用前缀和算原有 `pattern` 子序列数 `base`。
2. 遍历时遇到 `pattern[1]`，就把当前已见 `pattern[0]` 数累加进 `base`（每个 `pattern[1]` 与它左边所有 `pattern[0]` 配对）。
3. 答案 = `base + max(cnt0, cnt1)`：插 `pattern[0]` 到开头能多配 `cnt1` 个，插 `pattern[1]` 到末尾能多配 `cnt0` 个。
4. 以 `text = "abdcdbc"`, `pattern = "ac"` 为例：`cnt0=1`（一个 `a`），`cnt1=2`（两个 `c`），`base=2`，答案 `2 + max(1,2) = 4`。

```python
cnt0 = cnt1 = base = 0
for ch in text:
    if ch == pattern[1]:
        base += cnt0
        cnt1 += 1
    if ch == pattern[0]:
        cnt0 += 1
return base + max(cnt0, cnt1)
```

注意 `pattern[0] == pattern[1]` 时（如 `"aa"`），上面两个 `if` 都会命中同一个字符，`base` 会多算，需特判：此时答案 = `n*(n+1)//2`，`n` 是 `text` 中该字符个数。

## 复杂度
时间：O(n)，`n = len(text)`，单次遍历。
空间：O(1)，只开了 `cnt0`、`cnt1`、`base` 三个计数器。

## 易错点
- `pattern = "aa"`、`text = "aaa"` → 两个 `if` 对同一字符都执行，`base` 算成 3 而正确子序列数是 3（`C(3,2)`），插入后应为 6；正确做法是 `pattern[0]==pattern[1]` 时直接返回 `n*(n+1)//2`。
- `text` 里根本没有 `pattern[0]` 或 `pattern[1]`（如 `text="xyz"`, `pattern="ab"`）→ 误以为增益为 0 返回 0；实际插一个 `a` 或 `b` 后仍无 `"ab"`，答案确实是 0，但若 `text="b"`, `pattern="ab"`，插 `a` 到前面得 1，别漏掉 `max(cnt0,cnt1)` 这一项。

## 如果面试官追问
若允许插入 k 个字符？答：每个 `pattern[0]` 放最前、每个 `pattern[1]` 放最后，增益为 `k0*cnt1 + k1*cnt0 + k0*k1`，按 `k0+k1=k` 分配取最大。
