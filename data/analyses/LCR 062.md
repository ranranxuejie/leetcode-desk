## 一句话思路
每个节点用长度 26 的数组存子节点，末尾用 `is_end` 标记单词结束，逐字符走树即可。

## 怎么做
1. 节点结构：`children = [None]*26` 加 `is_end = False`，26 对应 `ord(ch)-ord('a')`。
2. `insert` 沿字符走，缺节点就建，走完把当前节点 `is_end` 置 `True`。
3. `search` 走完返回 `node.is_end`；`startsWith` 走完返回 `node is not None`，不看 `is_end`。
4. 两者共用 `_walk` 辅助：中途 `None` 直接返回 `None`。

以官方示例为例，`insert("apple")` 后根节点 `children[0]` 指向 `'a'` 节点，链上 `'a'→'p'→'p'→'l'→'e'`，只有 `'e'` 节点 `is_end=True`。此时 `search("app")` 能走通但停在 `'p'` 节点，其 `is_end=False`，返回 `False`；`startsWith("app")` 同样走通，节点非 `None`，返回 `True`。再 `insert("app")` 只把第二个 `'p'` 节点 `is_end` 置 `True`，`search("app")` 才变 `True`。

```python
def _walk(self, s):
    node = self.root
    for ch in s:
        node = node.children[ord(ch) - 97]
        if node is None:
            return None
    return node

def insert(self, word):
    node = self.root
    for ch in word:
        i = ord(ch) - 97
        if node.children[i] is None:
            node.children[i] = Node()
        node = node.children[i]
    node.is_end = True
```

## 复杂度
时间：每次操作 O(len(word))，总调用 3*10^4 次、单串 ≤2000。
空间：O(总插入字符数 × 26)，每个节点固定开 26 槽，空槽也占位。

## 易错点
- `insert("apple")` 后查 `search("app")` → 若把「走通」当「存在」会错返 `True` → 必须看终点 `is_end`，`startsWith` 才只看走通。
- 先 `insert("app")` 再 `insert("apple")` → 若新建 `'a'` 节点覆盖旧链会丢 `"app"` → 建节点前先判 `children[i] is None`，已有就复用。

## 如果面试官追问
问：字符集扩到全部 ASCII 怎么办？
答：把 26 槽换成 `dict`，键为字符，空间只随实际边数增长。
