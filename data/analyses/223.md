## 一句话思路
总面积 = 两矩形面积之和减去交集面积，交集用「右端点取小、左端点取大」的区间求交公式算出。

## 怎么做
1. 分别算两个矩形的面积：`areaA = (ax2-ax1)*(ay2-ay1)`，`areaB` 同理。
2. 求 x 方向的重叠长度：`overlapX = min(ax2,bx2) - max(ax1,bx1)`。
3. y 方向同理得 `overlapY`，若任一方向 ≤ 0 则交集面积为 0。
4. 返回 `areaA + areaB - overlapX*overlapY`。

用示例 1 走一遍关键步：`overlapX = min(3,9) - max(-3,0) = 3 - 0 = 3`，`overlapY = min(4,2) - max(0,-1) = 2 - 0 = 2`，交集 6；`areaA = 6*4 = 24`，`areaB = 9*3 = 27`，`24+27-6 = 45`，与输出一致。

```python
areaA = (ax2 - ax1) * (ay2 - ay1)
areaB = (bx2 - bx1) * (by2 - by1)
overlapX = min(ax2, bx2) - max(ax1, bx1)
overlapY = min(ay2, by2) - max(ay1, by1)
if overlapX <= 0 or overlapY <= 0:
    return areaA + areaB
return areaA + areaB - overlapX * overlapY
```

注意 `overlapX <= 0` 必须用 `<=` 而不是 `<`：两矩形仅边界相切时重叠长度为 0，减 0 无害，但若写成 `<` 且后续误用负值相乘会得到正数，反而多减。

## 复杂度
时间：O(1)，只做常数次加减和 min/max，与坐标数值大小无关。
空间：O(1)，只开了 areaA、areaB、overlapX、overlapY 四个标量。

## 易错点
- 两矩形分离（如 A 在 B 左侧，`ax2 < bx1`）→ 若直接算 `overlapX*overlapY` 会得到负数乘积，总面积被错误放大 → 必须先判 `overlapX <= 0 or overlapY <= 0` 再决定是否减交集。
- 坐标含负值（示例 1 的 `ax1 = -3`）→ 若用 `abs(ax2-ax1)` 之类或误把「右上减左下」写成「大减小」的绝对值，面积符号会错 → 直接按题面保证的 `ax1 <= ax2`、`ay1 <= ay2` 相减，不要加 `abs`。

## 如果面试官追问
问：若给 N 个轴对齐矩形求并集面积？
答：扫描线按 x 事件排序，线段树维护 y 区间被覆盖长度，O(N log N)。
