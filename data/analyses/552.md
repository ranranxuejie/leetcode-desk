## 一句话思路
按「已用 A 数 × 末尾连续 L 数」建 6 个状态做线性 DP，因为奖励条件只依赖这两个量。

## 怎么做
1. 状态定义为 `dp[a][l]`：`a ∈ {0,1}` 是已出现的 A 个数，`l ∈ {0,1,2}` 是末尾连续 L 的个数；初始 `dp[0][0] = 1`（空串）。
2. 每天追加一个字符，按字符分三种转移：加 P 把 `l` 清零、`a` 不变；加 A 要求 `a == 0`，转移后 `a = 1`、`l = 0`；加 L 要求 `l < 2`，转移后 `l + 1`。
3. 每轮用新数组 `ndp` 承接，避免原地更新污染同一天的数据；每步对 `10**9 + 7` 取余。
4. 跑满 n 天后，把 6 个状态全部求和。

以 `n = 2` 为例，第 1 天结束后 `dp[0][0]=1`（"P"）、`dp[0][1]=1`（"L"）、`dp[1][0]=1`（"A"）；第 2 天从 `dp[1][0]` 加 A 被拒（`a` 已为 1），所以 "AA" 不产生，最终 6 个状态和为 8，与示例一致。

```python
MOD = 10**9 + 7
dp = [[0]*3 for _ in range(2)]
dp[0][0] = 1
for _ in range(n):
    ndp = [[0]*3 for _ in range(2)]
    for a in range(2):
        for l in range(3):
            v = dp[a][l]
            if not v:
                continue
            ndp[a][0] = (ndp[a][0] + v) % MOD          # 加 P
            if a == 0:
                ndp[1][0] = (ndp[1][0] + v) % MOD      # 加 A
            if l < 2:
                ndp[a][l+1] = (ndp[a][l+1] + v) % MOD  # 加 L
    dp = ndp
return sum(sum(row) for row in dp) % MOD
```

## 复杂度
时间：O(n)，外层循环 n 次，内层固定 2×3 个状态。
空间：O(1)，只开了 `dp` 和 `ndp` 两个 2×3 数组，与 n 无关。

## 易错点
- `n = 1` 时若把初始 `dp[0][0] = 1` 当成「第 1 天已过」，循环写成 `range(n-1)`，会返回 1 而不是 3；正确做法是空串作为第 0 天，循环跑满 `range(n)`。
- 加 L 的边界写成 `l <= 2` 时，`n = 3` 会把 "LLL" 计入，答案比正确值 22 偏大；正确做法是 `l < 2` 才允许转移，保证末尾连续 L 最多 2 个。

## 如果面试官追问
问：n 放大到 10^18 怎么办？
答：6 个状态写成 6×6 转移矩阵，快速幂 O(6³ log n)，取余照旧。
