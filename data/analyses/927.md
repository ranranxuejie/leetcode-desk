## 一句话思路
数 1 的个数，按 1 的个数三等分定位三段起点，再逐位比对后缀是否相同。

## 怎么做
1. 统计 `arr` 中 1 的总数 `cnt`；若 `cnt % 3 != 0` 直接返回 `[-1, -1]`。
2. 若 `cnt == 0`，全 0 数组任意切都相等，返回 `[0, len(arr) - 1]`（满足 `i+1 < j`）。
3. 每段含 `k = cnt // 3` 个 1，记第三段第一个 1 的下标为 `third`，则第三段的有效后缀长度 `L = len(arr) - third`；第一段起点必为 0，第二段起点是第 `k+1` 个 1 的位置，第三段起点是第 `2k+1` 个 1 的位置。
4. 三段都取长度为 `L` 的后缀逐位比较，全等则返回 `[first_end, second_end]`，其中 `first_end = first_start + L - 1`，`second_end = second_start + L - 1`。

以 `arr = [1,0,1,0,1]` 为例：`cnt = 3`，`k = 1`，三个 1 的下标是 0、2、4，`third = 4`，`L = 5 - 4 = 1`。三段后缀分别是 `arr[0:1]=[1]`、`arr[2:3]=[1]`、`arr[4:5]=[1]`，相等，返回 `[0, 2]`（`first_end=0`，`second_end=2`，也满足 `i+1<j`）。

```python
cnt = arr.count(1)
if cnt % 3: return [-1, -1]
if cnt == 0: return [0, len(arr) - 1]
k = cnt // 3
pos = [i for i, v in enumerate(arr) if v == 1]
third = pos[2 * k]
L = len(arr) - third
a, b, c = pos[0], pos[k], pos[2 * k]
if arr[a:a + L] == arr[b:b + L] == arr[c:c + L]:
    return [a + L - 1, b + L - 1]
return [-1, -1]
```

## 复杂度
时间 O(n)：一次统计 1、一次收集下标、一次长度 L 的三段切片比较。
空间 O(n)：`pos` 存了全部 1 的下标，最坏 n 个。

## 易错点
- 全 0 输入 `[0,0,0]`：若直接按 `k = 0` 走会取 `pos[0]` 越界或返回 `[-1,-1]`；正确做法是 `cnt == 0` 时单独返回 `[0, len(arr)-1]`，因为三段都是 0，值相等。
- 前导零干扰：如 `[0,1,0,1,0,1]`，若从各段起点（含前导零）开始比会误判不等；正确做法是只比长度 `L = len(arr) - third` 的后缀，前导零不参与比较。

## 如果面试官追问
问：若要求返回所有合法切法而非任意一个？
答：固定 `L` 后三段后缀唯一确定，合法切法至多一种，直接返回该解或 `[-1,-1]`。
