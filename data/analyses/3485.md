## 一句话思路
把 words 建成字典树，每个节点记「经过它的字符串下标集合」，删掉 i 后某节点剩余数量 ≥ k 即该前缀可行，取最深可行深度。

## 怎么做
1. 建 Trie，每个节点维护 `cnt`（经过该节点的字符串数）和 `ids`（经过该节点的下标列表，用于判断删除 i 后是否仍 ≥ k）。
2. 对每个节点，若 `cnt >= k+1`，则删任何下标都仍 ≥ k，该深度对所有 i 都可行，直接更新全局答案 `base`。
3. 若 `cnt == k`，则只有删除 `ids` 中的下标时数量才降到 k-1，其余 i 仍可行；用差分数组 `diff` 记录「哪些 i 会失去这个深度」。
4. 最后 `answer[i] = base` 再按差分修正，`len(words)-1 < k` 时全 0。

以示例 1 为例：节点 "jump" 的 `ids=[0,3]`、`cnt=2=k`，删除 0 或 3 时该前缀失效；节点 "run" 的 `ids=[1,2,4]`、`cnt=3=k+1`，对所有 i 都有效，`base=3`。于是 answer[0]=answer[3]=3，其余为 4。

```python
# 建树后遍历节点
for node in trie_nodes:
    c, ids = node.cnt, node.ids
    if c >= k + 1:
        base = max(base, node.depth)
    elif c == k:
        for i in ids:
            diff[i] = max(diff[i], node.depth)  # 记录 i 失去的深度
ans = [base] * len(words)
for i in range(len(words)):
    if diff[i] > base:  # 该 i 被排除在更深前缀外
        ans[i] = base
```

## 复杂度
时间 O(总字符数 + 节点数 × k)，每个 `cnt==k` 的节点最多枚举 k 个下标。
空间 O(总字符数)，Trie 节点 + 每节点 ids 列表。

## 易错点
- `words=["a","a","a"]`、`k=3`：所有节点 `cnt=3=k`，删任一元素后只剩 2 个，答案应为 0；若把 `cnt>=k` 当成全局可行会错答 1，必须区分 `cnt>=k+1`（删谁都行）和 `cnt==k`（删 ids 内才失效）。
- `len(words)==k` 时删一个就剩 k-1 个，题面要求返回 0；若只按 `cnt==k` 走差分逻辑会漏掉这个整体判断，需在建树前先判 `len(words) < k+1` 直接全 0。

## 如果面试官追问
若要求输出具体是哪 k 个字符串而非长度？答：在 `cnt>=k` 的节点上取 `ids` 中前 k 个（跳过被删下标 i），深度最大的那组即为答案。
