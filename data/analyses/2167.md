## 一句话思路
把「左端删 + 右端删 + 中间删」看成给每个 `'1'` 选一种代价，用 DP 从左扫到右维护三种状态的最小值。

## 怎么做
1. 定义 `dp0` = 当前前缀全部用「左端删」处理完的代价，`dp1` = 已切到「中间删」阶段的代价，`dp2` = 已切到「右端删」阶段的代价。
2. 扫到 `s[i] == '1'` 时：`dp0 += 1`（左端删一节），`dp1 = min(dp0, dp1) + 2`（中间删），`dp2 = min(dp1, dp2) + 1`（右端删）。
3. 扫到 `'0'` 时：`dp0 += 1`（左端删仍要付 1），`dp1` 不变（中间删只对 `'1'` 付 2），`dp2 += 1`（右端删仍要付 1）。
4. 答案是 `min(dp0, dp1, dp2)`。

以 `s = "1100101"` 为例，扫到下标 2 的 `'1'` 时：`dp0 = 3`，`dp1 = min(3, 2) + 2 = 4`，`dp2 = min(2, 2) + 1 = 3`；最终三者取最小得 5。

```python
dp0 = dp1 = dp2 = 0
for ch in s:
    if ch == '1':
        dp0 += 1
        dp1 = min(dp0 - 1, dp1) + 2
        dp2 = min(dp1 - 2, dp2) + 1
    else:
        dp0 += 1
        dp2 += 1
return min(dp0, dp1, dp2)
```

注意上面代码里 `dp1` 用的是 `dp0 - 1`（即更新前的 `dp0`），`dp2` 用的是 `dp1 - 2`（更新前的 `dp1`），顺序不能颠倒。

## 复杂度
时间：O(n)，n 为 `len(s)`，一次线性扫描。
空间：O(1)，只开了 `dp0/dp1/dp2` 三个变量。

## 易错点
- 输入 `s = "0"` 或 `"000"`：若把 `dp1` 初值设成 `inf` 之外的大数、或对 `'0'` 也执行 `dp1 += 2`，会输出 2 而非 0。正确做法是 `'0'` 分支只动 `dp0` 和 `dp2`，`dp1` 保持不动，答案取 `min` 自然得 0。
- 输入 `s = "1"`：若在 `'1'` 分支里先更新 `dp0` 再用它算 `dp1`，`dp1` 会变成 `min(1, 0) + 2 = 2`，而正确值是 `min(0, 0) + 2 = 2` 恰好相同，但换成 `"11"` 就会错成 5 而非 3。正确做法是用更新前的 `dp0` 算 `dp1`、更新前的 `dp1` 算 `dp2`。

## 如果面试官追问
问：如果要求输出具体删除了哪些车厢怎么办？
答：在 DP 转移时记录每步选了哪种操作，回溯即可还原方案，时间空间仍是 O(n)。
