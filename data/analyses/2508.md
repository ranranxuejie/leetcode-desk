## 一句话思路
统计奇度点集合 `odd`，答案只取决于 `len(odd)` 与这些点所在连通块的规模，因为加一条边恰好翻转两个端点的奇偶性。

## 怎么做
1. 用度数数组 `deg` 扫一遍 `edges`，收集 `deg[v] % 2 == 1` 的节点进 `odd`。
2. 若 `len(odd) == 0` 直接 `True`；若 `len(odd) == 2`，检查这两点之间是否已有边，有则需绕路。
3. 若 `len(odd) == 4`，用并查集把 `odd` 按连通块分组，只有「同一块内 4 个奇点」或「两块各 2 个」才可能用两条边消掉。
4. 其余 `len(odd)` 一律 `False`（一条边改 2 个奇偶，两条边最多改 4 个）。

以示例 3 `n=4, edges=[[1,2],[1,3],[1,4]]` 为例：`deg = [3,1,1,1]`，`odd = {1,2,3,4}`，四个奇点全在含节点 1 的同一连通块里，块内边数只有 3 条，凑不出两条不重边的新边把 4 个奇点两两配对，故 `False`。

```python
odd = [v for v in range(1, n + 1) if deg[v] % 2]
k = len(odd)
if k == 0: return True
if k == 2:
    a, b = odd
    return not has_edge(a, b) or n > 2  # 有边时需第三点绕路
if k == 4:
    # 按并查集根分组，判断能否两两配对
    groups = {}
    for v in odd: groups.setdefault(find(v), []).append(v)
    return can_pair(groups, edges)
return False
```

## 复杂度
时间：O(n + m·α(n))，`edges` 的 m 条边各做一次并查集合并，n 个点各查一次度数。
空间：O(n)，`deg` 数组与并查集父数组各占 n。

## 易错点
- `len(odd) == 2` 且这两点之间已有边（如 `n=3, edges=[[1,2],[2,3]]` 得 `odd={1,3}` 但 1-3 无边，没问题；换成 `edges=[[1,2],[1,3]]` 则 `odd={2,3}` 且 2-3 无边）→ 直接返回 `True` 会漏判「必须绕经第三点」的情形，正确做法是确认存在第三点可中转。
- `len(odd) == 4` 时只看数量不看连通块 → 示例 3 会错判成 `True`；正确做法是四个奇点必须能分成两组、每组两点在同一连通块且组内可加边（同块两点间无边，或块内另有节点可绕）。

## 如果面试官追问
若要求输出具体添加的边？答：在 `odd` 上做配对，同块两点直接连，跨块两点连一条边即合并两块，按上述分组顺序输出即可。
