## 一句话思路
先统计每个数的出现次数，再按下标从小到大扫，第一个「偶数且计数为 1」的数就是答案。

## 怎么做
1. 用 `Counter(nums)` 得到每个值的出现次数 `cnt`。
2. 从左到右遍历 `nums`，对每个 `x` 判断 `x % 2 == 0 and cnt[x] == 1`。
3. 第一个满足条件的 `x` 直接返回，循环结束返回 `-1`。

以示例 1 `nums = [3,4,2,5,4,6]` 为例：`cnt = {3:1, 4:2, 2:1, 5:1, 6:1}`。扫描到下标 0 的 `3` 是奇数跳过；下标 1 的 `4` 是偶数但 `cnt[4] == 2`，跳过；下标 2 的 `2` 是偶数且 `cnt[2] == 1`，返回 `2`。注意 `6` 也满足条件，但它在下标 5，晚于 `2`，所以不能先返回 `6`。

```python
from collections import Counter

cnt = Counter(nums)
for x in nums:
    if x % 2 == 0 and cnt[x] == 1:
        return x
return -1
```

关键点：**先建计数表，再按原数组顺序扫描**。如果反过来「先找偶数再查次数」，容易把「第一个出现的偶数」误当成「第一个唯一偶数」；如果直接对 `set(nums)` 排序或遍历，就丢掉了下标先后信息。

## 复杂度
时间：O(n)，建 `Counter` 扫一遍、再扫一遍 `nums`，n 为数组长度。
空间：O(n)，`cnt` 最多存 n 个不同值；本题 `nums[i] <= 100`，实际不超过 100 个键。

## 易错点
1. 输入 `[4,4]` → 若只判断「是偶数」就返回，会错成 `4`；正确做法是必须同时满足 `cnt[x] == 1`，这里 `cnt[4] == 2`，应返回 `-1`。
2. 输入 `[6,2,6]` → 若先收集所有唯一偶数再取最小值，会错成 `2` 之外的顺序问题；本题要的是**下标最早**，`6` 在下标 0 但出现两次，`2` 在下标 1 且唯一，答案应为 `2`，所以必须按 `nums` 原顺序扫描而不是按值排序。

## 如果面试官追问
追问：如果 `nums` 长度到 10^7，怎么省空间？
答：值域若仍很小就用数组计数；否则先 `Counter` 再扫，或两遍哈希，空间 O(不同值个数)。
