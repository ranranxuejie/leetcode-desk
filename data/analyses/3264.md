## 一句话思路
用最小堆存 `(值, 下标)`，每次弹出堆顶乘 `multiplier` 再压回，下标保证并列时取最前。

## 怎么做
1. 建堆 `heap = [(nums[i], i) for i in range(len(nums))]`，元组比较天然先比值再比下标，正好满足「多个最小值取最前面」。
2. 循环 `k` 次：`v, i = heapq.heappop(heap)`，`nums[i] = v * multiplier`，`heapq.heappush(heap, (nums[i], i))`。
3. 以 `nums = [2,1,3,5,6], k = 5, multiplier = 2` 为例，初始堆顶是 `(1,1)`；第 1 次弹出后 `nums[1] = 2`，压回 `(2,1)`，此时堆里有两个 `2`，下标 `1` 的排在 `(2,0)` 前面，所以第 2 次弹的是 `(2,1)` 而不是 `(2,0)`，`nums[1]` 变成 `4`。
4. 第 3 次弹 `(2,0)` 得 `nums[0] = 4`；第 4、5 次依次弹 `(3,2)`、`(4,1)`，最终 `[8,4,6,5,6]`。

```python
import heapq

heap = [(nums[i], i) for i in range(len(nums))]
heapq.heapify(heap)
for _ in range(k):
    v, i = heapq.heappop(heap)
    nums[i] = v * multiplier
    heapq.heappush(heap, (nums[i], i))
return nums
```

`heapify` 是 O(n)，之后每次 `heappop`/`heappush` 都是 O(log n)，共 `k` 轮。

## 复杂度
时间：O(n + k log n)，`n` 来自建堆，`log n` 来自每次堆操作，`k` 轮。
空间：O(n)，堆里存了 `n` 个 `(值, 下标)` 元组。

## 易错点
- 只存值不存下标：`nums = [1,1,2], k = 1, multiplier = 2` 时，堆里两个 `1` 无法区分，可能改到下标 1 而非下标 0，输出 `[1,2,2]` 而不是 `[2,1,2]`。正确做法是元组 `(nums[i], i)`，Python 元组比较先比值再比下标，天然取最前。
- 用 `min(nums)` 加 `index()` 每轮线性扫描：`k = 10` 时虽然能过，但 `index()` 返回第一个匹配，逻辑上没错；真正的坑是原地改 `nums` 后忘了同步堆，导致堆里还是旧值，后续弹出的是过期数据。正确做法是每次改完 `nums[i]` 立刻 `heappush` 新值。

## 如果面试官追问
若 `k` 放大到 `10^9` 怎么办？答：先把所有元素乘到不小于原最大值，之后剩余次数按 `k % n` 轮流给排序后的前几个元素各乘一次。
