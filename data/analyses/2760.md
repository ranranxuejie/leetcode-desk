## 一句话思路
用滑动窗口维护「以偶数开头、奇偶交替、全部 ≤ threshold」的连续段，遇违规就重置左端。

## 怎么做
1. 遍历 `nums`，用 `cur` 记录当前合法交替段的长度，`ans` 记录最大值。
2. 若 `nums[i] > threshold`，说明任何含它的子数组都不合法，`cur = 0` 直接跳过。
3. 若 `nums[i] % 2 == 0`，它可以作为新起点，`cur = 1`；否则若 `cur > 0` 且与前一个数奇偶不同，`cur += 1`，否则 `cur = 0`（奇数不能开头）。
4. 每步 `ans = max(ans, cur)`。

以 `nums = [3,2,5,4], threshold = 5` 为例：i=0 时 3 是奇数且 `cur=0`，跳过；i=1 时 2 是偶数，`cur=1`；i=2 时 5 与 2 奇偶不同，`cur=2`；i=3 时 4 与 5 奇偶不同，`cur=3`，`ans=3`。

```python
cur = ans = 0
for i, x in enumerate(nums):
    if x > threshold:
        cur = 0
    elif x % 2 == 0:
        cur = 1
    elif cur > 0 and nums[i-1] % 2 != x % 2:
        cur += 1
    else:
        cur = 0
    ans = max(ans, cur)
return ans
```

关键在 `elif cur > 0 and nums[i-1] % 2 != x % 2`：`cur > 0` 保证前面已有偶数开头，`nums[i-1]` 是当前段末尾，比较奇偶即可判断能否接上。

## 复杂度
时间 O(n)：每个元素只被访问常数次，n 为 `nums` 长度。
空间 O(1)：只开了 `cur`、`ans` 两个变量。

## 易错点
- 输入 `nums = [1,2], threshold = 2` → 若把奇数也当作可开头，会错答 2 → 正确做法是奇数且 `cur == 0` 时必须 `cur = 0`，只有偶数才能置 `cur = 1`。
- 输入 `nums = [2,3,4,5], threshold = 4` → 若遇到 `5 > threshold` 只跳过不重置，会错答 4 → 正确做法是 `x > threshold` 时 `cur = 0`，因为 5 截断了交替段，后面 4 只能单独成段。

## 如果面试官追问
问：若要求返回最长子数组的起止下标而非长度？
答：额外记录 `cur` 的起点 `start`，每次 `cur` 更新时同步维护 `best_l = start`、`best_r = i`，最后返回这对下标。
