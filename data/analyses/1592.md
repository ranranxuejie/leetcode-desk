## 一句话思路
用 `split()` 拿到单词表、用 `count(' ')` 拿到空格总数，再按 `空格数 // (单词数-1)` 拼回去。

## 怎么做
1. 用 `words = text.split()` 切出单词列表，用 `spaces = text.count(' ')` 数出空格总数（`split()` 无参会自动吞掉所有连续空格和首尾空格）。
2. 若 `len(words) == 1`，直接返回 `words[0] + ' ' * spaces`，因为此时没有相邻单词间隙可放空格。
3. 否则算 `gap = spaces // (len(words) - 1)` 和 `extra = spaces % (len(words) - 1)`。
4. 用 `(' ' * gap).join(words) + ' ' * extra` 拼出结果。

以示例 2 `" practice makes perfect"` 为例：`words = ["practice","makes","perfect"]`，`spaces = 7`，`gap = 7 // 2 = 3`，`extra = 7 % 2 = 1`，拼出 `"practice   makes   perfect"` 再补 1 个尾空格。

```python
words = text.split()
spaces = text.count(' ')
if len(words) == 1:
    return words[0] + ' ' * spaces
gap, extra = divmod(spaces, len(words) - 1)
return (' ' * gap).join(words) + ' ' * extra
```

关键点：`divmod` 一次拿到商和余数，`gap` 是每对相邻单词之间的空格数，`extra` 全部堆到末尾，这样总长度天然等于原 `text` 长度。

## 复杂度
时间 O(n)：`split` 和 `count` 各扫一遍 `text`，拼接再扫一遍，n 是 `text` 长度。
空间 O(n)：`words` 列表和返回字符串各占 O(n)，无额外结构。

## 易错点
- 输入 `"a"`（只有一个单词）→ 若直接算 `spaces // (len(words)-1)` 会除零崩溃 → 必须先判 `len(words) == 1`，把全部空格追加到末尾。
- 输入 `"  hello  "`（首尾都有空格、单词间多个空格）→ 若用 `text.split(' ')` 会切出空串、单词数算错 → 必须用无参 `split()`，它按任意空白切分并丢弃空串。
- 输入 `"hello world"`（`spaces=1`，`len(words)-1=1`）→ 若把 `extra` 也塞进间隙会多出空格、长度变长 → `gap` 和 `extra` 要分开，`extra` 只放末尾。

## 如果面试官追问
问：如果要求相邻单词间空格数尽量大但**不允许**末尾有多余空格，怎么办？
答：那就要把 `spaces` 调成能被 `len(words)-1` 整除的最大值，剩下的空格只能丢弃或报错，取决于题意。
