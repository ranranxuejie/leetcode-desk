## 一句话思路
好串 ⟺ 至少含 1 个 l、2 个 e、1 个 t，用「总数 26^n 减去缺字符的容斥」算。

## 怎么做
1. 把条件翻译成计数：只需统计 l≥1、e≥2、t≥1 的串，其余 23 个字母任意。
2. 用容斥：设 A=无 l，B=e 至多 1 个，C=无 t，答案 = 26^n − |A∪B∪C|。
3. 逐项展开：|A|=25^n，|C|=25^n，|B|=25^n+ n·25^(n−1)（e 取 0 个或 1 个）。
4. 交集：|A∩C|=24^n，|A∩B|=24^n+n·24^(n−1)，|B∩C| 同，|A∩B∩C|=23^n+n·23^(n−1)。

以 n=4 验证：26^4=456976，|A|=|C|=390625，|B|=390625+4·15625=453125，|A∩C|=331776，|A∩B|=331776+4·13824=387072，三交=279841+4·12167=328509。容斥得 456976−(390625+453125+390625)+(331776+387072+387072)−328509=12，与示例一致。

```python
MOD = 10**9 + 7
def pw(b, e):
    r = 1
    while e:
        if e & 1: r = r * b % MOD
        b = b * b % MOD; e >>= 1
    return r
n1 = n - 1
p25, p24, p23 = pw(25, n), pw(24, n), pw(23, n)
q25, q24, q23 = pw(25, n1), pw(24, n1), pw(23, n1)
B = (p25 + n * q25) % MOD
AB = (p24 + n * q24) % MOD
ABC = (p23 + n * q23) % MOD
ans = (pw(26, n) - 2*p25 - B + 2*AB + p24 - ABC) % MOD
```

## 复杂度
时间：O(log n)，6 次快速幂，每次 log n 次乘法。
空间：O(1)，只存几个模值。

## 易错点
- n=1、2、3 时 26^n 本身就不够凑齐 leet，容斥公式会算出负数；必须 `% MOD` 后再取非负，不能直接返回负值。
- 算 |B| 时漏掉 `n·25^(n−1)` 这一项（e 恰好 1 个的情况），n=4 会得到 456976−390625−390625−390625+… 明显偏小；正确做法是 e=0 与 e=1 两种情况都计入。

## 如果面试官追问
若把 "leet" 换成任意给定模式串（含重复字母）？答：仍按各字母所需个数做容斥，项数 2^k，k 为模式串不同字母数。
