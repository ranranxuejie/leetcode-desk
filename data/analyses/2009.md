## 一句话思路
去重排序后，找长度 n 的窗口内最多能装下多少个已有元素，剩下的 n−k 个就是必须替换的。

## 怎么做
1. 对 `nums` 去重排序得到 `a`，记 `m = len(a)`；重复元素必然要改，去重后它们不再占窗口名额。
2. 用双指针维护窗口 `a[l..r]`，要求 `a[r] - a[l] <= n - 1`，因为连续段长度固定为 n，跨度上限就是 n−1。
3. 窗口右端每扩一格就更新 `best = max(best, r - l + 1)`，左端越界时右移。
4. 返回 `n - best`。

以 `nums = [1,2,3,5,6]` 为例：去重排序后 `a = [1,2,3,5,6]`，`n = 5`，跨度上限 4。窗口 `[1,2,3,5]` 满足 `5-1=4`，长度 4；再纳入 6 时 `6-1=5 > 4`，左端移到 2，窗口 `[2,3,5,6]` 长度仍是 4。`best = 4`，答案 `5-4 = 1`。

```python
a = sorted(set(nums))
n, m = len(nums), len(a)
best, l = 0, 0
for r in range(m):
    while a[r] - a[l] > n - 1:
        l += 1
    best = max(best, r - l + 1)
return n - best
```

关键点：窗口里保留的元素可以原样不动，窗口外的元素全部改成窗口内缺失的整数，一定够填，因为窗口跨度 ≤ n−1 意味着缺失个数恰好等于 `n - best`。

## 复杂度
时间：排序 `O(m log m)`，双指针各走一遍 `O(m)`，m 为去重后长度。
空间：`set` 和排序后的列表各 `O(m)` 额外空间。

## 易错点
- 不去重直接滑窗：`nums = [1,1,1,2]` 时窗口会算进 3 个 1，得出 `best = 4`、答案 0，但重复元素必须改，正确做法是先 `set` 再排序，答案应为 1。
- 跨度条件写成 `< n - 1` 或 `<= n`：`nums = [4,2,5,3]` 跨度 `5-2=3` 恰等于 `n-1=3`，写成严格小于会把它判为不合法，答案错成 1 而非 0。

## 如果面试官追问
要求输出具体替换方案怎么办？答：滑窗确定 `[a[l], a[l]+n-1]` 后，把窗口外元素依次填成该区间内缺失的整数即可。
