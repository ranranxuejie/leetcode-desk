## 一句话思路
数出所有 0 的位置，与末尾 k 个位置比对，错位的 0 个数就是最少交换次数。

## 怎么做
1. 统计 `nums` 中 0 的个数 `k`。
2. 目标状态是末尾 `k` 个位置全为 0，即下标 `n-k` 到 `n-1`。
3. 遍历前 `n-k` 个位置，统计其中 0 的个数 `misplaced`，这些 0 必须换出去。
4. 每次交换能把一个 0 换到末尾区、同时换回一个非 0，所以 `misplaced` 就是答案。

以 `nums = [0,1,0,3,12]` 为例：`k = 2`，末尾区是下标 3、4（值 `3,12`）。前 3 个位置 `[0,1,0]` 里有 2 个 0，`misplaced = 2`，输出 2。

```python
k = nums.count(0)
n = len(nums)
misplaced = 0
for i in range(n - k):
    if nums[i] == 0:
        misplaced += 1
return misplaced
```

关键中间值：`n - k = 3`，循环只看 `nums[0..2]`，命中 `nums[0]` 和 `nums[2]` 两次。

## 复杂度
时间：O(n)，`count` 一遍加循环一遍，各扫 n 个元素。
空间：O(1)，只开了 `k`、`misplaced` 两个计数器。

## 易错点
- 输入 `[0,0,1]` → 若把末尾区写成「最后 k 个非零位」或误用 `n-k-1` 作边界，会数出 1 或 2 → 正确边界是 `range(n-k)`，此处 `k=2`、`n-k=1`，前 1 位是 `nums[0]=0`，答案 1。
- 输入 `[1,2,0]` → 若遍历整个数组统计 0 的个数当答案，会得 1 → 末尾区本身已含那个 0，不该计入，只统计前 `n-k=2` 位，得 0。

## 如果面试官追问
问：若要求输出具体交换方案？答：从左往右找前 `n-k` 位里的 0，依次与末尾区第一个非 0 位置配对交换，边扫边记录 `(i, j)` 即可。
