## 一句话思路
统计 text 里 b/a/l/o/n 五个字母的频次，答案就是它们分别除以 "balloon" 中所需个数后的最小值。

## 怎么做
1. 用 `Counter(text)` 一次性拿到所有字母的计数。
2. 列出 "balloon" 的字母需求：b、a、n 各 1 个，o 要 2 个，l 要 2 个。
3. 对每个字母算 `cnt[ch] // need[ch]`，取最小值即为答案。
4. 缺失字母时 `Counter` 返回 0，整除结果 0，最小值自然为 0，无需特判。

以示例 2 `text = "loonbalxballpoon"` 为例，`Counter` 得到 `l:4, o:4, n:2, b:2, a:2`（其余字母忽略）。逐个算：`b:2//1=2`、`a:2//1=2`、`l:4//2=2`、`o:4//2=2`、`n:2//1=2`，最小值 2，输出 2。

```python
from collections import Counter

cnt = Counter(text)
need = {'b': 1, 'a': 1, 'l': 2, 'o': 2, 'n': 1}
ans = min(cnt[ch] // k for ch, k in need.items())
return ans
```

关键点：`l` 和 `o` 的除数必须是 2，写成 1 会把示例 2 算成 4。

## 复杂度
时间 O(n)，n 为 `len(text)`，遍历一次建 Counter 再遍历 5 个键。
空间 O(1)，Counter 最多存 26 个小写字母。

## 易错点
- 把 `l`、`o` 的需求当成 1：输入 `"loonbalxballpoon"` 会错算成 4，正确做法是 `need` 里写 `'l': 2, 'o': 2`。
- 只统计 "balloon" 里出现过的字母却漏掉某个键：输入 `"leetcode"` 时若直接 `cnt['b']` 之外的逻辑写错，可能抛 KeyError 或返回非 0；用 `Counter` 的默认 0 取值即可安全返回 0。

## 如果面试官追问
问：如果 text 长度到 10^9 无法一次读入内存怎么办？
答：流式读入，边读边累加 5 个字母的计数，最后同样取 `min(cnt[ch] // k)`，空间仍是 O(1)。
