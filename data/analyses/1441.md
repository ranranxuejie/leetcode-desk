## 一句话思路
按整数流 1..n 顺序走，命中 target 就 Push，没命中就 Push 再 Pop 丢掉。

## 怎么做
1. 用指针 `i` 指向 `target` 当前待匹配元素，从 1 到 `n` 遍历整数流。
2. 若当前整数 `x == target[i]`，只追加 `"Push"`，`i += 1`。
3. 否则追加 `"Push"` 和 `"Pop"`，表示读入后立刻丢弃。
4. 当 `i == len(target)` 时提前 `break`，不再读流。

以 `target = [1,3], n = 3` 为例：`x=1` 命中，`i` 变 1；`x=2` 不命中，追加 `Push,Pop`；`x=3` 命中，`i` 变 2 等于长度，退出，结果 `["Push","Push","Pop","Push"]`。

```python
res, i = [], 0
for x in range(1, n + 1):
    if i == len(target):
        break
    if x == target[i]:
        res.append("Push")
        i += 1
    else:
        res.append("Push")
        res.append("Pop")
return res
```

关键点：`target` 严格递增，所以整数流只需单向扫一遍，不需要回头；`i` 只增不减，天然对齐。

## 复杂度
时间 O(n)：整数流最多走 n 个，每个元素最多产生 2 次操作。
空间 O(len(target))：结果列表长度最多 2·len(target)，栈本身不用显式建。

## 易错点
- `target = [1,2], n = 4` → 若循环不提前 `break`，会多输出 `Push,Pop,Push,Pop` 对应 3、4，答案被判错 → 必须在 `i == len(target)` 时立刻停。
- `target = [2], n = 2` → 若从 `target[0]` 开始匹配而漏掉 1，会直接 Push 2 得到 `["Push"]`，但栈里是 `[2]` 看似对、实际跳过了流中 1 的读取顺序 → 必须从 `x=1` 起遍历，1 走 `Push,Pop`。

## 如果面试官追问
问：若 target 不严格递增（允许重复）怎么办？答：本题规则下栈底到栈顶必须严格递增才能匹配，重复值无法构造，直接返回空列表。
