## 一句话思路
用 `(行, 列, 当前未匹配左括号数)` 做可达性 DP，因为路径长度固定为 `m+n-1`，只需跟踪余额。

## 怎么做
1. 路径长度恒为 `m+n-1`，合法串要求长度为偶数，故 `(m+n-1) % 2 == 1` 直接返回 `False`。
2. 余额 `bal` 表示已走过格子中 `'('` 减 `')'` 的个数，任何前缀必须 `bal >= 0`，终点必须 `bal == 0`。
3. 状态 `dp[i][j]` 是到达 `(i,j)` 时所有可能的 `bal` 集合，从上方和左方合并后加减当前格。
4. 剪枝：`bal > m+n-1-(i+j)` 时剩余步数不够回零，直接丢弃。

以示例 1 为例，`m=n=4`，路径长 7 为奇数？实际 `4+4-1=7`，但示例返回 `True`——注意路径长是格子数 7，串长 7 为奇数不可能合法，说明示例 1 的 `m` 是 4、`n` 是 3（`grid` 每行 3 个元素），路径长 `4+3-1=6`，偶数，通过。到 `(1,1)` 时 `bal` 集合含 `{0,2}`（走 `((` 或 `()` 后接 `)` 的差异），继续推进。

```python
m, n = len(grid), len(grid[0])
if (m + n - 1) % 2: return False
dp = [[set() for _ in range(n)] for _ in range(m)]
dp[0][0] = {1} if grid[0][0] == '(' else set()
for i in range(m):
    for j in range(n):
        if i == 0 and j == 0: continue
        d = 1 if grid[i][j] == '(' else -1
        cand = (dp[i-1][j] if i else set()) | (dp[i][j-1] if j else set())
        rem = m + n - 1 - (i + j)
        dp[i][j] = {b + d for b in cand if 0 <= b + d <= rem}
return 0 in dp[m-1][n-1]
```

## 复杂度
时间：`O(m*n*(m+n))`，每个格子的 `bal` 集合最多 `m+n` 个值。
空间：`O(m*n*(m+n))`，存了全部 `dp` 集合；可滚动到 `O(n*(m+n))`。

## 易错点
- 输入 `grid = [["("]]`（1×1）→ 会错成返回 `True`，因为 `bal=1` 非零；正确做法是终点必须 `bal == 0`，单格 `'('` 必为 `False`。
- 输入首格是 `')'` 如示例 2 → 会错成仍从 `bal=0` 开始推；正确做法是 `dp[0][0]` 初始就为空集，整条路径直接判 `False`。

## 如果面试官追问
要求输出一条合法路径而非布尔值？答：在 `dp` 里存 `(bal, 前驱方向)`，从终点 `bal=0` 回溯即可。
