## 一句话思路
用单调栈维护结果，遇到比栈顶小且栈顶字符后面还会出现的字符就弹出，保证每个字符至少保留一次。

## 怎么做
1. 先统计 `s` 中每个字符最后出现的位置 `last[c]`。
2. 遍历 `s`，用栈 `st` 存结果，同时用 `used` 标记字符是否已在栈中。
3. 对当前字符 `c`：若 `used[c]` 为真则跳过；否则当栈非空、`st[-1] > c` 且 `last[st[-1]] > i` 时弹出栈顶并清除其 `used` 标记。
4. 将 `c` 入栈并标记 `used[c] = True`，遍历结束后 `''.join(st)` 即为答案。

以 `s = "aaccb"` 为例：`last` 为 `a:1, c:3, b:4`。遍历到 `i=2` 的 `c` 时，栈为 `['a','a']`，`st[-1]='a' < 'c'` 不弹，入栈得 `['a','a','c']`；到 `i=4` 的 `b` 时，`st[-1]='c' > 'b'` 且 `last['c']=3 < 4`，弹出 `c`，栈变 `['a','a']`，再入 `b` 得 `['a','a','b']`，最终 `"aacb"`。

```python
last = {c: i for i, c in enumerate(s)}
st, used = [], set()
for i, c in enumerate(s):
    if c in used:
        continue
    while st and st[-1] > c and last[st[-1]] > i:
        used.discard(st.pop())
    st.append(c)
    used.add(c)
return ''.join(st)
```

## 复杂度
时间 O(n)：每个字符最多入栈、出栈各一次，`n = len(s)`。
空间 O(1)：栈和 `used` 最多 26 个字符，`last` 固定 26 项。

## 易错点
- 输入 `"abacb"`：若弹出条件只写 `st[-1] > c`，会在 `i=2` 的 `a` 处把 `b` 弹掉，但 `b` 后面还有（`last['b']=4`），结果错成 `"aacb"` 少了 `b`；必须加 `last[st[-1]] > i` 才弹。
- 输入 `"bbca"`：若忘记 `used` 去重，`i=1` 的第二个 `b` 会再次入栈得 `"bbca"`；正确做法是 `c in used` 时直接 `continue`，保证每个字符只出现一次。

## 如果面试官追问
若要求返回所有可达的最小字符串数量？答：先按上述算法求出唯一最小串，再统计各字符出现次数与最小串中次数的差值组合数即可。
