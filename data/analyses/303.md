## 一句话思路
用前缀和数组 `pre`，`pre[i]` 存 `nums[0..i-1]` 的和，区间和化为一次减法。

## 怎么做
1. 构造时开 `pre` 长度 `n+1`，`pre[0] = 0`，`pre[i+1] = pre[i] + nums[i]`。
2. 查询 `sumRange(left, right)` 直接返回 `pre[right+1] - pre[left]`。
3. 用官方示例 `nums = [-2, 0, 3, -5, 2, -1]` 走一遍：`pre = [0, -2, -2, 1, -4, -2, -3]`。
4. 查 `[0, 2]`：`pre[3] - pre[0] = 1 - 0 = 1`；查 `[2, 5]`：`pre[6] - pre[2] = -3 - (-2) = -1`，与输出一致。

```python
def build(nums):
    pre = [0] * (len(nums) + 1)
    for i, x in enumerate(nums):
        pre[i + 1] = pre[i] + x
    return pre

def sum_range(pre, left, right):
    return pre[right + 1] - pre[left]
```

关键在 `pre` 多开一位：`pre[0]` 是空前缀，这样 `left = 0` 时 `pre[left]` 合法，不用写 `if left == 0` 分支。`pre[right+1]` 而不是 `pre[right]`，是因为 `pre[i]` 的定义是「前 i 个元素之和」，`right` 这个位置本身要被包含进去。

## 复杂度
时间：构造 O(n)，每次 `sumRange` O(1)，共 q 次查询即 O(n + q)。
空间：额外开 `pre` 数组 O(n)，`nums` 本身不计入。

## 易错点
- 输入 `left = 0`（如示例的 `[0, 2]`）→ 若 `pre` 只开 `n` 位、写成 `pre[right] - pre[left-1]`，`left-1 = -1` 会取到数组末尾的错值 → 正确做法是 `pre` 开 `n+1` 位、`pre[0] = 0`，用 `pre[right+1] - pre[left]`。
- 输入含负数（`nums = [-2, 0, 3, -5, 2, -1]`）→ 若误以为前缀和单调、想用二分或双指针定位区间 → 前缀和在这里不单调，只能靠下标直接相减，别加任何基于大小关系的优化。

## 如果面试官追问
问：如果 `nums` 会被单点修改呢？
答：换成树状数组或线段树，`update` 和 `sumRange` 都是 O(log n)，前缀和数组改一个点要 O(n) 重建。
