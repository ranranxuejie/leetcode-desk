## 一句话思路
贪心：把最高位非 9 的数字全换成 9 得最大 a，把最高位非 1 的数字全换成 1（首位换 0 会前导零）得最小 b，两者相减。

## 怎么做
1. 把 `num` 转成字符串 `s`，先构造最大值 `a`：从左往右找第一个不等于 `'9'` 的字符 `c`，把 `s` 中所有 `c` 替换成 `'9'`。
2. 构造最小值 `b`：若 `s[0] != '1'`，把 `s` 中所有 `s[0]` 换成 `'1'`；否则从 `s[1]` 起找第一个不是 `'0'` 也不是 `'1'` 的字符 `c`，把 `c` 全换成 `'0'`。
3. 返回 `int(a) - int(b)`。

以 `num = 9288` 为例：`s = "9288"`，最大值找第一个非 9 的字符是 `'2'`，替换后 `a = "9988"`；最小值首位 `'9' != '1'`，把 `'9'` 换成 `'1'` 得 `b = "1288"`；差值 `9988 - 1288 = 8700`，与示例 5 一致。

```python
s = str(num)
a = s
for c in s:
    if c != '9':
        a = s.replace(c, '9')
        break
if s[0] != '1':
    b = s.replace(s[0], '1')
else:
    b = s
    for c in s[1:]:
        if c not in '01':
            b = s.replace(c, '0')
            break
return int(a) - int(b)
```

关键点：最大值只需动一个数字，因为替换是「全局替换」，动最高位的非 9 数字收益最大；最小值首位必须保非零，所以首位单独判断。

## 复杂度
时间 O(log num)：字符串长度即十进制位数，`replace` 各扫一遍。
空间 O(log num)：存 `s`、`a`、`b` 三个字符串。

## 易错点
- 输入 `10000` → 若最小值也去替换首位 `'1'` 成 `'0'`，得到 `"00000"` 前导零非法 → 正确做法是首位为 `'1'` 时跳过首位，从 `s[1:]` 找第一个非 `'0'` 非 `'1'` 的字符（这里是 `'1'` 后面的 `'0'`？不对，`10000` 中 `s[1:]` 全是 `'0'`，无可替换，`b` 保持 `10000`），`a` 把 `'1'` 换成 `'9'` 得 `90000`，差 `80000`。
- 输入 `9` → 若最小值分支里 `s[0] != '1'` 成立把 `'9'` 换成 `'1'` 得 `1`，但最大值分支 `c != '9'` 不成立导致 `a` 未赋值 → 正确做法是 `a` 初始化为 `s` 本身，循环找不到非 9 字符时保持原值，`a = 9`、`b = 1`，差 `8`。

## 如果面试官追问
问：如果允许替换两次（两个不同 x）求最大 a 呢？
答：仍按位贪心，第一位非 9 换 9 后，再对结果找下一个非 9 数字换 9，两次替换互不干扰即可。
