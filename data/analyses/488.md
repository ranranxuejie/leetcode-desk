## 一句话思路
对 `board` 做 BFS，状态是（当前球串，剩余手牌），每层枚举插入位置与颜色，用记忆化去重。

## 怎么做
1. 先把 `board` 压成 `(颜色, 连续个数)` 的段列表，插入和消除都在段上做，避免字符串反复拼接。
2. 每层从队列取 `(board, hand)`，对每个位置、每种手牌颜色各试一次插入，插入后立刻跑「消除到不动」。
3. 消除用栈：新段与栈顶同色就合并计数，`>=3` 则弹出，并继续检查新的栈顶是否能与再前一段合并。
4. 用 `visited` 存 `(board, hand)` 去重，第一次得到空串时返回层数。

以示例 2 `board="WWRRBBWW", hand="WRBRW"` 为例：在 `RR` 后插入 `R`，段列表从 `[(W,2),(R,2),(B,2),(W,2)]` 变成 `[(W,2),(R,3),(B,2),(W,2)]`，`R` 段计数 3 被弹出，剩下 `[(W,2),(B,2),(W,2)]`，即 `WWBBWW`；再插一个 `B` 使 `B` 段到 3，弹出后左右两个 `W` 段合并成 `(W,4)`，也 `>=3` 继续弹出，得到空串，答案 2。

```python
def shoot(segs):
    st = []
    for c, n in segs:
        if st and st[-1][0] == c:
            st[-1][1] += n
        else:
            st.append([c, n])
        if st[-1][1] >= 3:
            st.pop()
    return tuple((c, n) for c, n in st)

# BFS 主体
q, seen, step = deque([(start, hand)]), {(start, hand)}, 0
while q:
    for _ in range(len(q)):
        b, h = q.popleft()
        if not b: return step
        for i in range(len(b) + 1):
            for c in set(h):
                nb = shoot(b[:i] + ((c, 1),) + b[i:])
                nh = h.replace(c, '', 1)
                if (nb, nh) not in seen:
                    seen.add((nb, nh)); q.append((nb, nh))
    step += 1
return -1
```

## 复杂度
时间：状态数约 `O(2^|board| · 2^|hand|)`，每个状态枚举 `O(|board|·5)` 个插入并做 `O(|board|)` 消除。
空间：`seen` 存全部状态，每个状态是段元组加手牌串，量级同状态数。

## 易错点
- 插入后只消除一次就停 → 对 `"WWRRBBWW"` 插 `R` 后得到 `WWBBWW` 就以为结束，漏掉后续 `B` 引发的连锁；正确做法是 `shoot` 里弹出后继续用栈顶与新段比较，直到栈稳定。
- 手牌用 `set(h)` 枚举颜色但忘记扣减 → 同一颜色只有 1 张却允许插两次，示例 3 `hand="GGGGG"` 会误判为 1 步；正确做法是每次 `h.replace(c, '', 1)` 生成新串再入队。

## 如果面试官追问
问：`board` 长度放宽到 30 还能 BFS 吗？
答：不能，状态爆炸；需改成对段做区间 DP，枚举「先消掉哪一段」并预判该段需要几张手牌补齐到 3。
