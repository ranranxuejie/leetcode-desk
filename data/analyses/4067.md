## 一句话思路
固定右端点 r，用哈希表记录窗口内每个值出现次数，双指针收缩左端点，使窗口内不存在 a+b==c。

## 怎么做
1. 外层 `r` 从 0 到 n-1，把 `nums[r]` 加入 `cnt`，同时维护窗口内所有「两数之和」的计数 `pair_sum`（加入新元素时，它与窗口内每个已有值 x 组成 `x+nums[r]`，各 +1）。
2. 内层 `while` 检查：只要存在某个 `s` 使 `pair_sum[s] > 0` 且 `cnt[s] > 0`，说明窗口内有 a+b==c，就收缩 `l`：把 `nums[l]` 从 `cnt` 移除，并把它与窗口内其余元素组成的和从 `pair_sum` 中减掉，`l += 1`。
3. 收缩停止后，`r-l+1` 就是当前右端点的最长有效长度，更新答案。

以 `nums = [2,3,5,3,2,1]` 为例：r=2 时窗口 `[2,3,5]`，`pair_sum` 含 `2+3=5`，而 `cnt[5]=1`，触发收缩，l 移到 1，窗口变 `[3,5]`；r=3 加入 3 后窗口 `[3,5,3]`，`pair_sum` 有 6、8、8，`cnt` 里没有 6 或 8，合法，长度 3。

```python
cnt = {}
pair_sum = {}
l = ans = 0
for r, v in enumerate(nums):
    for x in cnt:                 # 新元素与窗口内每个值配对
        pair_sum[x + v] = pair_sum.get(x + v, 0) + 1
    cnt[v] = cnt.get(v, 0) + 1
    while any(pair_sum.get(s, 0) > 0 and cnt.get(s, 0) > 0 for s in pair_sum):
        u = nums[l]
        cnt[u] -= 1
        if cnt[u] == 0: del cnt[u]
        for x in cnt:             # 移除 u 与其余元素的配对
            s = x + u
            pair_sum[s] -= 1
            if pair_sum[s] == 0: del pair_sum[s]
        l += 1
    ans = max(ans, r - l + 1)
```

## 复杂度
时间：每个元素进出窗口各一次，每次 O(窗口内不同值个数)，最坏 O(n²)，n 为 nums 长度。
空间：`cnt` 与 `pair_sum` 各 O(不同值数) 和 O(和的不同取值数)，和值上限 1000。

## 易错点
- 输入 `[1,1,2]`：若只判断 `cnt[s]` 而不检查 `pair_sum[s]`，会把 `1+1=2` 漏判成合法（两个 1 是不同下标），答案错成 3；必须同时要求 `pair_sum[s] > 0`。
- 输入 `[2,3,5,3,2,1]`：收缩时只从 `cnt` 删 `nums[l]` 却忘了从 `pair_sum` 减去它与窗口内其余元素的配对，`pair_sum[5]` 残留，导致后续窗口被误判非法、答案偏小；删 `cnt` 前先遍历剩余元素减 `pair_sum`。

## 如果面试官追问
问：nums[i] 上限改成 10^9 怎么办？答：`pair_sum` 的键变成大整数，哈希表照样存，复杂度不变，只是常数变大。
