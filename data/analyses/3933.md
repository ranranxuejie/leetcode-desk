## 一句话思路
对每个非零格，用二维前缀和 O(1) 求出它「x 行 x 列十字区域」内的最大值，与 x 比较。

## 怎么做
1. 预处理二维前缀和 `pre`，`pre[i+1][j+1] = matrix[i][j] + pre[i][j+1] + pre[i+1][j] - pre[i][j]`。
2. 十字区域 = 第 `row` 行左右各 x 列（列区间 `[col-x, col+x]`）+ 第 `col` 列上下各 x 行（行区间 `[row-x, row+x]`），两段各用前缀和求区间最大值。
3. 前缀和只能求区间和，求最大值要另建「行最大值」和「列最大值」的稀疏表，或直接对每行/每列建 ST 表；本题值域 ≤200，更省事的是对每个值 v 建二维前缀和 `cnt[v]`，判断区域内是否存在 > x 的值。
4. 对每个 `matrix[row][col] = x > 0`，检查十字区域（去掉四角 `(row±x, col±x)`）内是否存在值 > x，不存在则计数 +1。

以示例 1 的 `(3,3)`、x=2 为例：行区间 `[1,5]`、列区间 `[1,5]`，十字区域覆盖第 3 行第 1~5 列和第 1~5 行第 3 列，四角 `(1,1)(1,5)(5,1)(5,5)` 被排除；区域内最大值是 2，等于 x，故计数。

```python
# 值域前缀和：cnt[v][i][j] 表示值恰为 v 的格子在 (0,0)-(i-1,j-1) 的数量
# 对每个 x，检查十字区域内是否存在值 > x
for row in range(n):
    for col in range(m):
        x = matrix[row][col]
        if x == 0:
            continue
        r1, r2 = max(0, row - x), min(n - 1, row + x)
        c1, c2 = max(0, col - x), min(m - 1, col + x)
        ok = True
        for v in range(x + 1, 201):
            # 行条 row 行、列 [c1,c2] 与列条 col 列、行 [r1,r2] 的并
            if rect(v, row, row, c1, c2) or rect(v, r1, r2, col, col):
                ok = False
                break
        # 注意四角被两个条同时排除，上面的并集恰好不含四角
        ans += ok
```

## 复杂度
时间：O(n·m·V)，V=201 为值域，每个格子最多扫 200 个值。
空间：O(V·n·m) 存值域前缀和，或 O(n·m) 若改用 ST 表。

## 易错点
- 十字区域是「整行 row 的 [c1,c2]」并「整列 col 的 [r1,r2]」，不是矩形 `[r1,r2]×[c1,c2]`；示例 1 里若按矩形算会把四角 `(1,1)` 等算进去，虽然本例值都是 0 不影响，但示例 3 的 `(0,0)`、x=1 时矩形会含 `(1,1)=1` 仍判对，换成 `[[2,0,0],[0,1,0],[0,0,2]]` 就会把 `(1,1)` 误判。
- 四角 `(row±x, col±x)` 必须排除，且只在未越界时存在；用「行条 ∪ 列条」天然排除，若写成矩形再减四角，越界时减多了会漏判。

## 如果面试官追问
若 matrix 值域放大到 10^9 怎么办？答：改用每行、每列的稀疏表求区间最大值，十字区域取两段 max，O(nm log) 预处理、O(1) 查询。
