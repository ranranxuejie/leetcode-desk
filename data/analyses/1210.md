## 一句话思路
把蛇的「头坐标 + 朝向」当状态做 BFS，每层扩展 4 种移动，首次到达终点即最少步数。

## 怎么做
1. 状态用 `(r, c, ori)` 表示，`ori=0` 水平（占 `(r,c),(r,c+1)`），`ori=1` 竖直（占 `(r,c),(r+1,c)`），起点 `(0,0,0)`。
2. 每步枚举右移、下移、旋转三种动作，逐个检查目标格是否为 0，合法才入队。
3. 用 `dist` 字典或三维 `visited` 记录步数，出队时若 `(r,c,ori)==(n-1,n-2,0)` 直接返回。

以示例 1 为例，起点 `(0,0,0)` 右移两次到 `(0,2,0)`，此时 `grid[1][2]=0`、`grid[1][3]=0`，旋转合法，状态变为 `(0,2,1)`，占 `(0,2),(1,2)`——这一步的判定条件正是「下方两格都空」，而不是只看 `(1,2)`。

```python
from collections import deque
q = deque([(0, 0, 0)])
dist = {(0, 0, 0): 0}
while q:
    r, c, o = q.popleft()
    d = dist[(r, c, o)]
    if (r, c, o) == (n - 1, n - 2, 0):
        return d
    nxt = []
    if o == 0:  # 水平
        if c + 2 < n and grid[r][c + 2] == 0: nxt.append((r, c + 1, 0))
        if r + 1 < n and grid[r + 1][c] == 0 and grid[r + 1][c + 1] == 0:
            nxt.append((r + 1, c, 0)); nxt.append((r, c, 1))
    else:       # 竖直
        if r + 2 < n and grid[r + 2][c] == 0: nxt.append((r + 1, c, 1))
        if c + 1 < n and grid[r][c + 1] == 0 and grid[r + 1][c + 1] == 0:
            nxt.append((r, c + 1, 1)); nxt.append((r, c, 0))
    for s in nxt:
        if s not in dist:
            dist[s] = d + 1; q.append(s)
return -1
```

## 复杂度
时间 O(n²)：状态数 2n²，每状态常数次转移。
空间 O(n²)：`dist` 最多存 2n² 个状态。

## 易错点
- 旋转只检查「新占的那一格」→ 示例 1 中 `(0,2,0)` 若只看 `grid[1][2]=0` 就旋转，会漏掉 `grid[1][3]=1` 的阻挡，得到偏小答案；必须同时检查下方/右方两格。
- 把蛇当成单点或忽略朝向 → 示例 2 中水平与竖直可达区域不同，合并状态会把不可达路径算通，答案偏小；`ori` 必须进状态键。

## 如果面试官追问
问：n 扩到 1000 怎么办？答：状态数仍是 2n²，BFS 不变，只是内存吃紧，可改用按层滚动的 `visited` 位图。
