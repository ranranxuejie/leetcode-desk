## 一句话思路
用 `new[i]` 记第 i 天新增人数，靠「第 i-delay 天新增的人今天开始传播、第 i-forget 天新增的人今天起失效」两个窗口滚动求和。

## 怎么做
1. 定义 `new[i]` 为第 i 天新知道秘密的人数，`new[1] = 1`，其余按递推填。
2. 第 i 天的新增 = 所有「已过 delay 天、还没到 forget 天」的人之和，即 `sum(new[i-forget+1 : i-delay+1])`。
3. 用前缀和 `pre[i] = pre[i-1] + new[i]` 把每步求和降到 O(1)。
4. 答案不是 `pre[n]`，而是第 n 天仍记得的人：`sum(new[n-forget+1 : n+1])`。

以示例 1（n=6, delay=2, forget=4）走一遍：`new[1]=1`；第 3 天窗口是 `new[3-4+1:3-2+1] = new[0:2]`，得 `new[3]=1`（A 传给 B）；第 4 天窗口 `new[1:3]` 得 `new[4]=1`（A 传 C）；第 5 天窗口 `new[2:4]` 得 `new[5]=1`（B 传 D，A 已失效）；第 6 天窗口 `new[3:5]` 得 `new[6]=2`（B、C 各传一个）。最终 `new[3:7] = 1+1+1+2 = 5`，与输出一致。

```python
MOD = 10**9 + 7
new = [0] * (n + 1)
pre = [0] * (n + 1)
new[1] = 1
pre[1] = 1
for i in range(2, n + 1):
    lo = max(0, i - forget + 1)
    hi = i - delay
    if hi >= 1:
        new[i] = (pre[hi] - pre[lo - 1]) % MOD
    pre[i] = (pre[i - 1] + new[i]) % MOD
lo = max(1, n - forget + 1)
return (pre[n] - pre[lo - 1]) % MOD
```

## 复杂度
时间 O(n)：单层循环，每步 O(1) 前缀和查询。
空间 O(n)：`new` 和 `pre` 两个长度 n+1 的数组。

## 易错点
- 返回 `pre[n]` 而不是「第 n 天仍记得的人」→ 示例 1 会得 6 而非 5，因为 A 在第 5 天已忘记却仍被计入累计。正确做法是只累加 `new[n-forget+1 : n+1]`。
- 窗口右端写成 `i-delay+1` → 示例 1 第 3 天会算进 `new[2]=0` 之外还多算一天，导致 B 提前一天出现、最终答案偏大。正确右端是 `i-delay`，因为「delay 天后」当天才传播。

## 如果面试官追问
问：n 放大到 10^9 怎么办？答：`new` 的递推是固定阶线性递推（阶数 forget），可用矩阵快速幂把 O(n) 降到 O(forget^3 log n)。
