## 一句话思路
水塘抽样：遍历到第 i 个节点时以 1/i 的概率替换答案，保证每个节点最终被选中概率都是 1/n。

## 怎么做
1. 构造函数只存 `self.head = head`，不预先数长度，这样长度未知也能用。
2. `getRandom()` 里用 `p = self.head` 遍历，计数器 `i` 从 1 开始，`ans = p.val` 先取第一个节点。
3. 每走到第 i 个节点，取 `r = random.randint(1, i)`，若 `r == 1` 就 `ans = p.val`，然后 `p = p.next`、`i += 1`。
4. 遍历结束返回 `ans`。

以官方示例 `[1, 2, 3]` 为例，走一遍关键中间值：i=1 时 ans=1；i=2 时 randint(1,2) 若得 1 则 ans=2；i=3 时 randint(1,3) 若得 1 则 ans=3。节点 2 最终留下的概率是「i=2 时被选中(1/2) 且 i=3 时没被覆盖(2/3)」= 1/3，节点 1 是 1/2 × 2/3 = 1/3，节点 3 是 1/3，三者相等。

```python
import random

def getRandom(self):
    p, i, ans = self.head, 1, self.head.val
    while p:
        if random.randint(1, i) == 1:
            ans = p.val
        p = p.next
        i += 1
    return ans
```

注意 `randint(1, i)` 是闭区间，取到 1 的概率正好 1/i；若写成 `randint(0, i-1) == 0` 等价，但别写成 `randint(1, i-1)`，i=1 时会抛异常。

## 复杂度
时间：每次 getRandom 遍历全表 O(n)，n 是链表节点数。
空间：O(1)，只用了 p、i、ans 三个变量，没有额外数组。

## 易错点
- 输入 `[1]`（单节点）→ 若把替换条件写成 `randint(1, i-1)` 或先 `i += 1` 再取随机，i=1 时区间非法直接报错 → 正确做法是计数器从 1 开始、先判断再自增，保证 i=1 时 `randint(1,1)` 恒为 1。
- 输入 `[1, 2, 3]` 反复调用 → 若在构造函数里把节点值全存进 list 再 `random.choice`，虽然结果对但空间 O(n)，且违背进阶要求 → 正确做法是每次 getRandom 现场遍历、只留一个 ans，空间 O(1)。

## 如果面试官追问
问：链表长度已知且要调用 10^4 次，怎么优化？
答：构造函数里把值存进数组，getRandom 用 `random.choice` 做到 O(1)，用空间换时间。
