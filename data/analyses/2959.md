## 一句话思路
n≤10，枚举 2^n 个关闭集合，对每个集合用 Floyd 预处理的全源最短路判断剩余点两两距离是否 ≤ maxDistance。

## 怎么做
1. 先对原图跑 Floyd，得到任意两点最短路 `dist`（注意重边取 min，`dist[i][i]=0`）。
2. 枚举关闭掩码 `mask` 从 0 到 `(1<<n)-1`，`mask` 的第 i 位为 1 表示关闭分部 i。
3. 对每个 `mask`，取出剩余点集合 `keep`，检查 `keep` 中任意两点 `(i,j)` 是否满足 `dist[i][j] <= maxDistance`。
4. 全部满足则计数加一；空集（`keep` 为空）天然满足，直接计入。

以示例 2 为例：`n=3, maxDistance=5, roads=[[0,1,20],[0,1,10],[1,2,2],[0,2,2]]`。Floyd 后 `dist[0][1]` 取重边最小值 10，再经 2 中转得 `dist[0][1]=min(10, 2+2)=4`，`dist[0][2]=2`，`dist[1][2]=2`。当 `mask=0`（不关闭）时三点两两距离最大为 4 ≤ 5，可行；当 `mask=1`（关闭 0）时剩余 `{1,2}`，`dist[1][2]=2` ≤ 5，可行。最终计数 7。

```python
INF = 2**31 - 1
dist = [[INF] * n for _ in range(n)]
for i in range(n):
    dist[i][i] = 0
for u, v, w in roads:
    dist[u][v] = min(dist[u][v], w)
    dist[v][u] = min(dist[v][u], w)
for k in range(n):
    for i in range(n):
        for j in range(n):
            if dist[i][k] + dist[k][j] < dist[i][j]:
                dist[i][j] = dist[i][k] + dist[k][j]
ans = 0
for mask in range(1 << n):
    keep = [i for i in range(n) if not (mask >> i) & 1]
    ok = all(dist[i][j] <= maxDistance for i in keep for j in keep)
    ans += ok
```

## 复杂度
时间：Floyd 贡献 O(n^3)，枚举 2^n 个掩码、每个检查 O(n^2)，合计 O(2^n · n^2)。
空间：`dist` 二维表 O(n^2)，`keep` 列表 O(n)，无其他额外结构。

## 易错点
- 重边处理：示例 2 中 `[0,1,20]` 和 `[0,1,10]` 是同一对点，若直接赋值 `dist[0][1]=20` 会漏掉更短的 10，导致 `dist[0][1]` 算成 20 而非 4，`mask=0` 被误判不可行。正确做法是建图时对每条边取 `min`。
- 空集与单点：`mask=(1<<n)-1` 时 `keep` 为空，`all(...)` 对空生成器返回 `True`，应计入；若写成「`keep` 非空才检查」会漏掉全关闭方案，示例 1 会从 5 错成 4。

## 如果面试官追问
问：若 n 扩大到 20 怎么办？
答：2^20 枚举仍可，但每集合 O(n^2) 检查会到 10^10，需改成按位 DP 或对每个 mask 只增量检查新加入点。
