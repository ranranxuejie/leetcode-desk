## 一句话思路
排序后从最大端贪心取：奇数天取当前最大，偶数天取次大并顺带消耗一个更小的披萨。

## 怎么做
1. 升序排序 `pizzas`，用双指针 `r = n-1` 从最大端取，`l = 0` 记录被"顺带消耗"的小披萨位置。
2. 共 `n//4` 天，奇数天（第 1、3、5…天）直接取 `pizzas[r]`，`r -= 1`。
3. 偶数天取 `pizzas[r-1]`（当前剩余最大两个中的较小者），`r -= 2`，同时 `l += 1` 表示消耗掉一个最小披萨。
4. 累加所有取值即为答案。

以 `pizzas = [1,2,3,4,5,6,7,8]` 为例，排序后 `r=7, l=0`：
- 第 1 天（奇）：取 `pizzas[7]=8`，`r=6`，累计 8。
- 第 2 天（偶）：取 `pizzas[5]=6`，`r=4`，`l=1`，累计 14。

```python
pizzas.sort()
n = len(pizzas)
r, l = n - 1, 0
ans = 0
for day in range(1, n // 4 + 1):
    if day % 2 == 1:
        ans += pizzas[r]
        r -= 1
    else:
        ans += pizzas[r - 1]
        r -= 2
        l += 1
return ans
```

关键点：偶数天取 `pizzas[r-1]` 而非 `pizzas[r]`，因为 `pizzas[r]` 要留给下一个奇数天当最大值；被跳过的 `pizzas[r]` 和 `l` 位置的小披萨一起凑成 4 个。

## 复杂度
时间：排序 `O(n log n)`，遍历 `n//4` 天 `O(n)`，总计 `O(n log n)`。
空间：排序原地进行，仅用 `r, l, ans` 常数变量，`O(1)` 额外空间。

## 易错点
- 偶数天误取 `pizzas[r]` 而非 `pizzas[r-1]`：如 `[1,2,3,4,5,6,7,8]` 第 2 天会取 7 而非 6，导致第 3 天无大值可用，答案偏小。正确做法是偶数天取 `pizzas[r-1]`，把 `pizzas[r]` 留给下个奇数天。
- 忘记偶数天要额外消耗一个小披萨：每天必须吃满 4 个，偶数天取 1 个大值后还需 3 个填充，其中 1 个来自 `pizzas[r]`（被跳过），另 2 个来自 `l` 端。若只 `r -= 2` 不推进 `l`，会导致剩余披萨数对不上，最终 `r` 越界或漏吃。

## 如果面试官追问
问：若天数不固定、要求输出具体分配方案怎么办？
答：仍按排序后双指针贪心，额外用列表记录每天取的下标，偶数天把 `r` 和 `l` 两端各取若干填入即可。
