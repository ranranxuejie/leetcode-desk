## 一句话思路
从右往左找第一个能「贴着 target 前缀、在该位换成更大字符」的位置，换完后缀升序填最小，即为答案。

## 怎么做
1. 用 `cnt[26]` 统计 `s` 的字符频次，`prefix` 记录已与 `target` 前缀对齐的字符。
2. 从左到右枚举分叉点 `i`：先尝试在 `cnt` 中找大于 `target[i]` 的最小字符 `c`，找到即分叉。
3. 分叉成功则 `prefix + c + 剩余字符升序` 就是候选；取所有候选中字典序最小者（等价于分叉点尽量靠右）。
4. 枚举完无分叉则返回 `""`。

以 `s="abc", target="bba"` 为例：`i=0` 时 `cnt` 中大于 `'b'` 的只有 `'c'`，分叉得 `"c" + "ab" = "cab"`；`i=1` 时前缀已消耗 `'b'`，`cnt` 剩 `{a,c}`，大于 `'b'` 的只有 `'c'`，得 `"b"+"c"+"a"="bca"`；`i=2` 时前缀 `"bb"` 已不可能（`s` 只有一个 `b`），枚举终止。候选 `{"cab","bca"}` 中最小是 `"bca"`。

```python
from collections import Counter

def lexGreaterPermutation(s, target):
    n = len(s)
    cnt = Counter(s)
    best = None
    pref = []
    for i in range(n):
        # 在当前位置尝试换成比 target[i] 大的最小字符
        for c in map(chr, range(ord(target[i]) + 1, ord('z') + 1)):
            if cnt[c] > 0:
                cnt[c] -= 1
                tail = ''.join(ch * cnt[ch] for ch in sorted(cnt))
                cand = ''.join(pref) + c + tail
                if best is None or cand < best:
                    best = cand
                cnt[c] += 1
                break
        # 继续贴着 target 走
        if cnt[target[i]] == 0:
            break
        cnt[target[i]] -= 1
        pref.append(target[i])
    return best if best is not None else ""
```

## 复杂度
时间：O(26·n + n log n)，枚举分叉点 O(n)，每次找后继 O(26)，排序后缀 O(n log n)。
空间：O(n)，`cnt` 固定 26 项，`pref` 与候选串各 O(n)。

## 易错点
- `s="baba", target="bbaa"`：若只试 `i=0` 分叉（`'b'` 无更大字符可用），会漏掉 `i=1` 处前缀 `"b"` 后换 `'a'` 也不行，最终误判有解；正确做法是逐位枚举并检查 `cnt[target[i]]` 是否耗尽，耗尽即 `break`。
- `s="ab", target="ab"`：若允许「等于」也算分叉，会返回 `"ab"` 而非 `""`；分叉字符必须严格 `> target[i]`，且贴着走完后无候选时返回空串。

## 如果面试官追问
问：若要求返回所有严格大于 target 的排列个数？答：对每个分叉点累加「剩余字符全排列数」，用多重集排列公式 `n! / ∏cnt!` 求和即可。
