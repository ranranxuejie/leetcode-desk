## 一句话思路
对每个数枚举「交换任意两位」得到的所有变体（含自身），用哈希表按变体归组计数，组内两两配对。

## 怎么做
1. 把每个 `nums[i]` 转成字符串，枚举所有 `(p, q)` 交换位，收集变体集合 `S`（含原数本身）。
2. 关键：变体要**归一化**——前导 0 必须保留位数，`30` 交换得 `"03"`，转回整数是 `3`，与 `3` 的 `"3"` 位数不同，所以统一用 `int(s)` 做键，`"03"` 和 `"3"` 都映射到 `3`。
3. 用 `cnt` 字典记录每个变体已出现次数，对当前数 `x`，答案累加 `sum(cnt[v] for v in S)`，再把 `S` 中每个变体计数 +1。
4. 以 `nums = [3,12,30,17,21]` 为例：处理 `30` 时 `S = {30, 3}`，`cnt[3]` 已为 1（来自 `3`），答案 +1；处理 `21` 时 `S = {21, 12}`，`cnt[12]` 为 1，答案再 +1，共 2。

```python
from collections import defaultdict

cnt = defaultdict(int)
ans = 0
for x in nums:
    s = str(x)
    variants = {x}
    for p in range(len(s)):
        for q in range(p + 1, len(s)):
            t = list(s)
            t[p], t[q] = t[q], t[p]
            variants.add(int("".join(t)))
    ans += sum(cnt[v] for v in variants)
    for v in variants:
        cnt[v] += 1
```

注意 `variants` 用 `set` 去重，否则 `11` 交换两次会重复计数。

## 复杂度
时间：每个数 O(L²) 枚举交换位，L ≤ 7，总计 O(n·L²)。
空间：哈希表存 O(n·L²) 个变体键，L 为位数。

## 易错点
- 输入 `[3, 30]` → 若把 `"03"` 直接当字符串键，`"3"` 与 `"03"` 不相等，会漏掉这对 → 必须 `int()` 归一化，让 `3` 和 `30` 的变体都落到键 `3`。
- 输入 `[11, 11]` → 若 `variants` 用 list 不去重，`11` 交换两次得到两个 `11`，`sum(cnt[v])` 会把同一对算两遍 → 用 `set` 保证每个变体只贡献一次。

## 如果面试官追问
若 `nums[i]` 放大到 10^9 且 n 到 10^5，怎么办？答：位数 L 增大到 10，O(n·L²) 仍可接受，但需改用「排序后按变体签名分组」避免哈希表膨胀。
