## 一句话思路
按「连续加速 k 次」为基本块做 DP，枚举越过 target 后回退或提前倒车，取指令数最小。

## 怎么做
1. 设 `dp[x]` 为到达位置 x 的最短指令数，`dp[0]=0`；对每个 x 从小到大枚举「加速 k 次」的落点 `2**k - 1`。
2. 若 `2**k - 1 == x`，直接 `dp[x] = k`（全 A）。
3. 若 `2**k - 1 > x`，两种走法取小：一是冲过头再倒车回退，代价 `k + 1 + dp[2**k - 1 - x]`；二是先加速 k-1 次、倒车、再正向补，代价 `k - 1 + 1 + 1 + dp[x - (2**(k-1) - 1)]`。
4. 以 target=6 为例：k=3 时 `2**3-1=7>6`，走法一代价 `3+1+dp[1]=4+1=5`，走法二 `2+2+dp[6-3]=4+dp[3]=4+2=6`，取 5，与示例 "AAARA" 一致。

```python
dp = [0] * (target + 1)
for x in range(1, target + 1):
    k = x.bit_length()          # 2**k - 1 >= x 的最小 k
    if (1 << k) - 1 == x:
        dp[x] = k
        continue
    # 冲过头再倒车
    best = k + 1 + dp[(1 << k) - 1 - x]
    # 先到 2**(k-1)-1，倒车，再正向补
    if (1 << (k - 1)) - 1 < x:
        best = min(best, k + 1 + dp[x - ((1 << (k - 1)) - 1)])
    dp[x] = best
```

注意 `k = x.bit_length()` 保证 `2**k - 1 >= x`，省掉一层 while；`dp` 只依赖更小的下标，顺序递推即可。

## 复杂度
时间：O(target · log target)，每个 x 只试常数个 k，k 上界是 log target。
空间：O(target)，一个 dp 数组，无其他额外结构。

## 易错点
- target=2 → 只想到「AA 冲过头再倒车」得 `2+1+dp[1]=4`，漏了「A R A」这种先到 1 倒车再补的 3 步走法；正确做法是两种候选都算再取 min。
- target=5 → 用 `k = x.bit_length()` 后忘记判断 `2**(k-1)-1 < x`，当 x 恰为 `2**(k-1)-1` 时下标为 0 会重复计数；正确做法是加这个下界判断，或直接让候选二只在 `x > 2**(k-1)-1` 时参与比较。

## 如果面试官追问
要求输出具体指令序列怎么办？答：dp 时同步记录每个 x 选的是「全 A / 冲过头 / 先倒车」哪种转移，回溯拼接字符串即可。
