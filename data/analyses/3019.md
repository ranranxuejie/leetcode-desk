## 一句话思路
把每个字符统一转小写后，只比较相邻两字符是否相同，不同就计数——因为大小写差异只是修饰键，不算换键。

## 怎么做
1. 从下标 1 开始遍历 `s`，每次拿 `s[i]` 和 `s[i-1]` 比较。
2. 比较前对两者都做 `.lower()`，把 `'A'` 和 `'a'` 视为同一个键。
3. 若小写后不相等，说明换了键，计数加一。
4. 遍历结束返回计数。

以 `s = "aAbBcC"` 为例：`i=1` 时 `'A'.lower()=='a'` 与 `s[0]='a'` 相同，不计数；`i=2` 时 `'b'` 与 `'A'.lower()=='a'` 不同，计数变 1；`i=3` 时 `'B'.lower()=='b'` 与 `s[2]='b'` 相同，不计数；`i=4` 时 `'c'` 与 `'b'` 不同，计数变 2；`i=5` 时 `'C'.lower()=='c'` 与 `s[4]='c'` 相同。最终返回 2。

```python
def countKeyChanges(s):
    ans = 0
    for i in range(1, len(s)):
        if s[i].lower() != s[i - 1].lower():
            ans += 1
    return ans
```

关键中间值就是 `ans` 的累加时机：只在 `s[i].lower() != s[i-1].lower()` 成立时加一，`"aAbBcC"` 里只有 `i=2` 和 `i=4` 两次成立。

## 复杂度
时间：O(n)，n 为 `s` 长度，每个字符访问一次并做一次 `lower()`。
空间：O(1)，只用了 `ans` 和循环变量 `i`，没有额外数组。

## 易错点
- 输入 `s = "aAbBcC"` 时若直接比较 `s[i] != s[i-1]` 而不转小写，`'a'` 与 `'A'` 会被判为不同，答案错成 5 而非 2；正确做法是两边都 `.lower()` 再比。
- 输入 `s = "AaAaAaaA"` 时若误以为要统计「连续相同字符段数减一」以外的逻辑，或把首字符也算一次变更，会得到 1 而非 0；正确做法是循环从 `i=1` 起，首字符不参与计数。

## 如果面试官追问
问：若 `s` 长度到 10^7 且要求流式读入怎么办？
答：仍 O(1) 空间，只需保留上一个字符的小写值 `prev`，读一个比一个，不必存整个串。
