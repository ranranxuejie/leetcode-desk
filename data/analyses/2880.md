## 一句话思路
用布尔掩码 `students["student_id"] == 101` 过滤行，再取 `["name", "age"]` 两列。

## 怎么做
1. 构造布尔 Series：`mask = students["student_id"] == 101`。
2. 用 `students[mask]` 保留 `student_id` 为 101 的行。
3. 对结果取 `[["name", "age"]]`，列顺序与示例一致。

拿官方示例走一遍：`student_id` 列是 `[101, 53, 128, 3]`，比较后 `mask` 为 `[True, False, False, False]`；`students[mask]` 只剩第一行 `101 / Ulysses / 13`，再取两列得到 `name=Ulysses, age=13`。

```python
mask = students["student_id"] == 101
result = students.loc[mask, ["name", "age"]]
```

注意 `students[mask][["name", "age"]]` 与 `.loc[mask, [...]]` 结果相同，后者一次完成，少一次中间拷贝。返回的是 DataFrame，索引保留原行号 0，力扣判题只比对列和值，索引不影响。

## 复杂度
时间 O(n)：`student_id` 列逐元素比较一次，n 为行数。
空间 O(k)：只存命中行，k 为 `student_id == 101` 的行数，示例中 k=1。

## 易错点
- 写成 `students[students["student_id"] == 101]["name", "age"]` → 单层方括号里传元组会被当成单个列名，报 KeyError；正确用 `[["name", "age"]]` 双层列表或 `.loc[mask, ["name", "age"]]`。
- 忘记过滤直接 `students[["name", "age"]]` → 输出 4 行而非 1 行，与示例不符；必须先算 `mask` 再取列。

## 如果面试官追问
若 `student_id` 有重复 101 怎么办？答：掩码天然保留全部命中行，输出多行，无需改代码。
