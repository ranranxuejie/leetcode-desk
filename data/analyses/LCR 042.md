## 一句话思路
用双端队列按时间顺序存请求，每次 ping 从队头弹出早于 `t-3000` 的，队里剩下的就是答案。

## 怎么做
1. 初始化一个空 `deque`，`ping(t)` 先把 `t` 追加到队尾。
2. 循环检查队头 `q[0]`，若 `q[0] < t - 3000` 就 `popleft()`。
3. 返回 `len(q)`。

用官方示例走一遍：`ping(3001)` 时队里是 `[1, 100, 3001]`，阈值 `3001-3000 = 1`，队头 `1` 不满足 `< 1`，不弹，返回 3。接着 `ping(3002)`，阈值 `2`，队头 `1 < 2` 弹出，队变 `[100, 3001, 3002]`，`100` 不小于 `2` 停手，返回 3。

```python
from collections import deque

class RecentCounter:
    def __init__(self):
        self.q = deque()

    def ping(self, t: int) -> int:
        self.q.append(t)
        while self.q[0] < t - 3000:
            self.q.popleft()
        return len(self.q)
```

关键在边界：区间是闭的 `[t-3000, t]`，所以判断用严格小于 `<`，恰好等于 `t-3000` 的请求要留下。示例里 `ping(3001)` 的 `1` 正好卡在边界上，被保留，答案才是 3 而不是 2。

## 复杂度
时间：每次 ping 均摊 O(1)，每个请求最多入队出队各一次，总 O(n)。
空间：O(n)，队列最多同时存 3000 毫秒窗口内的请求。

## 易错点
- 把边界写成 `<=`：输入 `ping(3001)` 时 `1 <= 1` 成立，`1` 被误弹，返回 2，正确是 3。区间含端点，必须用 `< t - 3000`。
- 用列表 `pop(0)` 代替 `deque.popleft()`：`ping` 调用 10^4 次、窗口内元素多时，每次 `pop(0)` 搬移 O(n)，总退化成 O(n²)。用 `deque` 才是均摊 O(1)。

## 如果面试官追问
问：若 t 不保证递增怎么办？
答：不能只弹队头，得用有序结构（如按 t 排序的平衡树）或先缓存再按窗口过滤，复杂度升到 O(log n)。
