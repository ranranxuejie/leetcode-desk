## 一句话思路
用哈希表记录每个值上次出现的下标，扫一遍时用「当前下标 − 上次下标 + 1」更新最小窗口长度。

## 怎么做
1. 建 `last = {}`，`ans = n + 1`（用 `n+1` 当哨兵，比 `float('inf')` 更直观地表示「还没找到」）。
2. 从左到右遍历 `i, x`，若 `x in last`，则候选长度为 `i - last[x] + 1`，用它更新 `ans`。
3. 无论是否命中，都把 `last[x] = i` 覆盖掉旧下标——保留最近一次出现才能让窗口最短。
4. 遍历结束后 `ans == n + 1` 说明没有任何值重复，返回 `-1`，否则返回 `ans`。

以 `cards = [3,4,2,3,4,7]` 为例：`i=3` 时 `x=3`，`last[3]=0`，候选 `3-0+1=4`，`ans` 从 `7` 变 `4`；`i=4` 时 `x=4`，`last[4]=1`，候选 `4-1+1=4`，`ans` 保持 `4`。最终返回 `4`。

```python
last = {}
ans = len(cards) + 1
for i, x in enumerate(cards):
    if x in last:
        ans = min(ans, i - last[x] + 1)
    last[x] = i
return -1 if ans == len(cards) + 1 else ans
```

关键点：`last[x]` 必须无条件覆盖。若只在首次出现时写入，`[1,2,1,1]` 会拿 `i=3` 去减 `last[1]=0` 得 `4`，而正确答案是 `3-2+1=2`。

## 复杂度
时间 O(n)：`cards` 每个元素进出哈希表各一次，`n = len(cards)`。
空间 O(k)：`last` 最多存 `k` 个不同值，`k ≤ n`，无其他额外数组。

## 易错点
- 输入 `[1,2,1,1]` → 若只在值首次出现时写 `last`，`i=3` 会算成 `3-0+1=4` → 正确做法是每次循环都执行 `last[x] = i`，让 `i=3` 对上 `last[1]=2` 得 `2`。
- 输入 `[1,0,5,3]` → 若把 `ans` 初始化为 `0` 或 `n`，无重复时会误返回 `0` 或 `4` → 正确做法是用 `n+1` 作哨兵，结束时判 `ans == n + 1` 返回 `-1`。

## 如果面试官追问
问：要求返回值本身而不只是长度，怎么改？
答：在更新 `ans` 时同步记下 `(last[x], i)` 这对下标，最后切片 `cards[l:r+1]` 即可，时间空间不变。
