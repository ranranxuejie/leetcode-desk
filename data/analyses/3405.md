## 一句话思路
把 n 个位置切成 n-k 段连续相等的块，先选块边界位置再选每块的值，用组合数 C(n-1,k)·m·(m-1)^(n-1-k) 计数。

## 怎么做
1. 恰好 k 个相邻相等，等价于 n-1 个缝隙里有 k 个「不断开」，剩下 n-1-k 个断开，断点位置有 C(n-1, k) 种选法。
2. 断开后形成 n-k 个块，第一块的值有 m 种，之后每块必须与上一块不同，各有 m-1 种。
3. 以 n=3, m=2, k=1 为例：C(2,1)=2，块数 n-k=2，第一块 2 种、第二块 1 种，得 2·2·1=4，与示例一致。
4. 预处理阶乘与逆元算组合数，幂用 pow 取模。

```python
MOD = 10**9 + 7
fact = [1] * (n + 1)
for i in range(1, n + 1):
    fact[i] = fact[i-1] * i % MOD
inv = [1] * (n + 1)
inv[n] = pow(fact[n], MOD - 2, MOD)
for i in range(n, 0, -1):
    inv[i-1] = inv[i] * i % MOD
def C(a, b):
    if b < 0 or b > a:
        return 0
    return fact[a] * inv[b] % MOD * inv[a-b] % MOD
ans = C(n-1, k) * m % MOD * pow(m-1, n-1-k, MOD) % MOD
```

## 复杂度
时间：O(n) 预处理阶乘逆元，每次组合数 O(1)，快速幂 O(log n)。
空间：O(n) 存 fact 和 inv 两个数组。

## 易错点
- m=1 且 n-1-k>0 时，pow(0, 正数)=0 正确返回 0；但若写成 m*(m-1)**... 而漏判 n-1-k=0，会误算成 0，正确是 m=1 时全等数组恰有 1 个。
- k=n-1 时 C(n-1,n-1)=1、指数为 0，答案应为 m；若组合数函数在 b>a 时返回 1 而非 0，或指数写成 n-k 会多乘 (m-1)，结果翻成 m(m-1)。

## 如果面试官追问
若 n 扩大到 10^9 而 k 很小，怎么算？答：C(n-1,k) 用 O(k) 连乘分子分母求逆元，幂仍用快速幂，总 O(k+log n)。
