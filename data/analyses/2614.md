## 一句话思路
遍历两条对角线上的数，用试除法判质数，取最大者；n≤300 时每个数最多试到 2000，总代价可接受。

## 怎么做
1. 单层循环 `i in range(n)`，同时取 `nums[i][i]` 和 `nums[i][n-1-i]`，中心元素会重复访问一次，判质数幂等所以无害。
2. 判质数写成独立函数：`x < 2` 直接 `False`，否则 `d` 从 2 试到 `isqrt(x)`，`x % d == 0` 即非质数。
3. 用 `ans = 0` 兜底，遇到质数就 `ans = max(ans, x)`，最后返回 `ans`。

以示例 1 的 `nums = [[1,2,3],[5,6,7],[9,10,11]]` 为例，`i=0` 取到 `nums[0][0]=1`（`<2`，非质数）和 `nums[0][2]=3`（试 `d=2`，`3%2!=0`，是质数，`ans=3`）；`i=1` 取到 `6` 和 `6`，`6%2==0` 跳过；`i=2` 取到 `nums[2][2]=11`，试到 `d=3` 都不整除，`ans` 更新为 11。

```python
from math import isqrt

def is_prime(x):
    if x < 2:
        return False
    for d in range(2, isqrt(x) + 1):
        if x % d == 0:
            return False
    return True

n = len(nums)
ans = 0
for i in range(n):
    for x in (nums[i][i], nums[i][n - 1 - i]):
        if is_prime(x):
            ans = max(ans, x)
```

## 复杂度
时间：O(n·√M)，n 是对角线元素个数，√M 来自每个数试除到 `isqrt(x)`，M≤4×10⁶。
空间：O(1)，只开了 `ans`、`i`、`d` 几个标量，没有额外数组。

## 易错点
- 输入 `[[2,1],[1,2]]` → 若把 `x < 2` 写成 `x <= 2` 返回 `True`，会把 1 当质数、把 2 判错 → 正确是 `x < 2` 返回 `False`，2 走循环体（`isqrt(2)=1`，`range(2,2)` 为空）返回 `True`。
- 输入 `[[1,2,3],[5,6,7],[9,10,11]]` → 若循环写成 `range(n)` 但只取 `nums[i][i]`，会漏掉副对角线上的 3 和 11，答案错成 0 → 必须两个下标 `i` 和 `n-1-i` 都取，中心重复访问不影响结果。

## 如果面试官追问
问：若 `nums[i][j]` 上限提到 10⁹ 怎么办？
答：单次判质数改 Miller-Rabin，或先筛出 √10⁹≈31623 内的质数做试除，避免每个数都从 2 试起。
