## 一句话思路
从右往左扫，维护一个「右侧最大值」的单调栈，栈里留下的就是答案节点。

## 怎么做
1. 把链表节点值倒序压入栈，栈内保持从栈底到栈顶严格递减（即栈顶是当前已见最大值）。
2. 对 `[5,2,13,3,8]` 倒序处理：先入 `8`；`3 < 8` 弹出 3；`13 > 8` 入栈，栈变 `[13,8]`；`2 < 13` 弹出；`5 < 13` 弹出。
3. 栈底到栈顶即 `[13,8]`，按此顺序重建链表返回。

```python
st = []
cur = head
while cur:
    while st and st[-1] <= cur.val:
        st.pop()
    st.append(cur.val)
    cur = cur.next
dummy = ListNode(0)
p = dummy
for v in st:
    p.next = ListNode(v)
    p = p.next
return dummy.next
```

关键中间值：处理到 `13` 时栈为 `[8]`，`8 <= 13` 弹出后栈空，再压入 `13`，所以 `5`、`2` 后续都被 `13` 弹掉。

## 复杂度
时间 O(n)：每个节点最多入栈、出栈各一次，n 为节点数。
空间 O(n)：栈最多存 n 个值，另建了 n 个新节点。

## 易错点
- 输入 `[1,1,1,1]` → 若用 `st[-1] < cur.val` 判断，相等不弹，栈变 `[1,1,1,1]` 结果碰巧对；但输入 `[5,5]` 时若用 `<` 会保留两个 5，实际右侧没有更大值应保留两个，这里 `<` 才对；若误用 `<=` 会把相等的也弹掉，`[5,5]` 错成 `[5]`。正确做法：只有严格小于当前值才弹，即 `st[-1] < cur.val`。
- 输入 `[5,2,13,3,8]` → 若从左往右扫并直接删节点，删掉 5 后 `2` 的右侧判断会漏掉 13，结果错留 `[2,13,8]`。正确做法：倒序处理，保证每个节点都见过其右侧全部最大值。

## 如果面试官追问
问：能否 O(1) 额外空间？
答：可以，先反转链表，从左往右用「当前最大值」过滤，再反转回来，空间 O(1)。
