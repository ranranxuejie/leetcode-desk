## 一句话思路
用两个哈希表：`checkin` 按 id 存 (站名, 时间)，`stats` 按 (起点, 终点) 累计总时长和次数，查询时做除法。

## 怎么做
1. `checkIn` 把 `id -> (stationName, t)` 写进 `checkin`，覆盖旧值即可。
2. `checkOut` 用 `id` 取出进站记录，算出 `t - t_in`，把 `(start, end)` 作为键累加进 `stats`，然后删掉该 id。
3. `getAverageTime` 直接取 `stats[(start, end)]` 的 `total / cnt`。

以示例 1 为例：`checkOut(45, "Waterloo", 15)` 时，`checkin[45] = ("Leyton", 3)`，时长 `15 - 3 = 12`，`stats[("Leyton","Waterloo")]` 从 `(0,0)` 变成 `(12,1)`；随后乘客 27 出站，同一键变成 `(22,2)`，查询得 `22/2 = 11.0`。乘客 10 在 24 进站、38 出站后键变成 `(36,3)`，得 `12.0`。

```python
def checkIn(self, id, stationName, t):
    self.checkin[id] = (stationName, t)

def checkOut(self, id, stationName, t):
    start, t0 = self.checkin.pop(id)
    key = (start, stationName)
    total, cnt = self.stats.get(key, (0, 0))
    self.stats[key] = (total + t - t0, cnt + 1)

def getAverageTime(self, startStation, endStation):
    total, cnt = self.stats[(startStation, endStation)]
    return total / cnt
```

## 复杂度
时间：每次操作 O(1)，字符串哈希按站名长度 ≤10 计，总调用 2*10^4 次。
空间：O(k)，k 为不同 id 数与不同 (起点,终点) 对数之和，各开一个字典。

## 易错点
- 同一 id 先出站再进站（如示例 1 的 45 之后没有，但换乘场景常见）→ 若不 `pop` 而只读，残留旧记录会让下一次 `checkOut` 用错起点 → 出站时务必 `pop(id)`，保证一次进站只配对一次。
- 用 `total / cnt` 时若把 `stats` 存成「平均值 + 次数」并原地更新 → 示例 1 第三次查询会得 `(11+14)/2 = 12.5` 而非 `12.0` → 必须存累计总时长，除法只在 `getAverageTime` 里做一次。

## 如果面试官追问
若要求返回「最近一次」而非平均时间？答：`stats` 只存 `(last_duration, 1)` 或直接存时长，`checkOut` 覆盖写，查询 O(1)。
