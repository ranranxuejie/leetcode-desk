## 一句话思路
按空格切出单词列表，逐行取每个单词的第 i 个字符，缺位补空格，最后 `rstrip` 掉尾部空格。

## 怎么做
1. `words = s.split()` 得到单词列表，`max_len = max(len(w) for w in words)` 决定输出行数。
2. 外层 `for i in range(max_len)` 逐行扫描，内层遍历每个单词。
3. 内层用 `w[i] if i < len(w) else ' '` 取字符，拼成一行后 `rstrip()` 去掉尾随空格。
4. 把每行 append 进结果列表返回。

以 `s = "TO BE OR NOT TO BE"` 为例：`words = ["TO","BE","OR","NOT","TO","BE"]`，`max_len = 3`。第 0 行取每个词首字母得 `"TBONTB"`；第 2 行只有 `"NOT"` 的第 3 个字符 `'T'` 存在，其余补空格得 `"     T"`，`rstrip()` 后变成 `" T"`——注意前导空格必须保留，它对应 `"NOT"` 在第 3 列的位置。

```python
words = s.split()
max_len = max(len(w) for w in words)
res = []
for i in range(max_len):
    row = ''.join(w[i] if i < len(w) else ' ' for w in words)
    res.append(row.rstrip())
return res
```

关键点：`rstrip()` 只砍右边，左边的空格是列对齐信息，砍了就错位。示例 2 的 `" T"` 若写成 `strip()` 会变成 `"T"`，与 `"NOT"` 的列位置脱节。

## 复杂度
时间 O(n)：n 为 `s` 长度，每行扫描全部单词，总字符访问量约 `max_len * 单词数`，不超过 O(n + 空格补位)。
空间 O(n)：结果列表存 `max_len` 行，每行长度等于单词数，加上 `words` 列表本身。

## 易错点
- 输入 `"TO BE OR NOT TO BE"` → 若用 `strip()` 或 `lstrip()` 处理每行，`" T"` 会变成 `"T"`，丢失 `"NOT"` 的列偏移 → 正确做法是只用 `rstrip()`，保留前导空格。
- 输入 `"CONTEST IS COMING"` → 若按 `max_len` 之外的单词长度循环，或误以为所有单词等长，第 3 行 `"N M"` 中间的空格会漏掉（`"IS"` 只有 2 个字符，第 3 位补空格）→ 正确做法是内层对每个单词独立判断 `i < len(w)`，短词补空格而非跳过。

## 如果面试官追问
问：若单词间可能有多个空格或含小写字母怎么办？答：`split()` 无参已能吞掉任意空白，大小写不影响逻辑，无需改动。
