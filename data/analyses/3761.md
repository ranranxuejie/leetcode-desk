## 一句话思路
从左到右扫一遍，用哈希表记录每个值最近一次出现的下标，遇到 `reverse(nums[i])` 已在表里就更新最小距离。

## 怎么做
1. 建空字典 `last`，`ans` 初始为 `n`（或一个足够大的数）。
2. 对每个下标 `i`，先算 `r = reverse(nums[i])`，若 `r in last`，用 `i - last[r]` 更新 `ans`。
3. 再把 `nums[i] -> i` 写入 `last`（覆盖旧值，因为更近的下标只会让距离更小）。
4. 扫完若 `ans == n` 返回 `-1`，否则返回 `ans`。

以 `nums = [12,21,45,33,54]` 为例：`i=0` 时 `r = reverse(12) = 21`，`last` 为空，写入 `{12:0}`；`i=1` 时 `r = reverse(21) = 12`，命中 `last[12] = 0`，`ans = 1 - 0 = 1`，之后 `i=4` 命中 `last[45] = 2` 得距离 2，不更优，最终返回 1。

```python
def reverse(x):
    r = 0
    while x:
        r = r * 10 + x % 10
        x //= 10
    return r

last = {}
ans = len(nums)
for i, v in enumerate(nums):
    r = reverse(v)
    if r in last:
        ans = min(ans, i - last[r])
    last[v] = i
return -1 if ans == len(nums) else ans
```

关键点：`last` 存的是「值 → 最近下标」，所以 `i - last[r]` 天然就是当前能取到的最小距离，不需要枚举所有配对。

## 复杂度
时间：O(n · log₁₀M)，n 次遍历，每次反转数字最多 10 位（M ≤ 10⁹）。
空间：O(n)，`last` 最多存 n 个不同值。

## 易错点
- `nums = [120, 21]`：若把 `reverse` 写成字符串反转后不转 `int`，`reverse(120)` 得到 `"021"`，与 `21` 比较失败，返回 -1；正确做法是 `int(str(x)[::-1])` 或按位取模累加，让前导零自然消失。
- `nums = [21, 120]`：若先写 `last[v] = i` 再查 `r`，`i=1` 时 `last` 里已有 `120`，但 `reverse(120)=21` 查的是 `21`，顺序本身不致命；真正会错的是把 `last` 存成「值 → 首次下标」且不覆盖，遇到 `[11, 11, 11]` 时 `i=2` 仍与 `0` 配对得距离 2，而正确答案是 1；必须每次覆盖为最新下标。

## 如果面试官追问
若要求输出所有镜像对而非最小距离，怎么改？答：把 `last` 换成 `dict[值] -> list[下标]`，命中时对列表里每个下标都产出一对，复杂度变为 O(总对数)。
