## 一句话思路
枚举所有二进制回文数（≤5000 只需到 13 位），对每个 nums[i] 二分找最近的两个取最小差。

## 怎么做
1. 按位长 L 从 1 到 13 生成回文：取前半段 `half`，镜像拼接成 `p`。
2. 把生成的 `p` 全部塞进有序列表 `pals`（天然递增，无需再排序）。
3. 对每个 `x`，用 `bisect_left` 找到插入位置 `j`，候选是 `pals[j]` 和 `pals[j-1]`。
4. 取 `min(abs(x - pals[j]), abs(x - pals[j-1]))` 作为答案。

以 `nums = [6,7,12]` 为例：`pals` 中含 5(`101`)、7(`111`)、15(`1111`)。对 `x=12`，`bisect_left` 返回指向 15 的下标 `j`，`pals[j-1]=7`，两个差为 3 和 5，取 3，与官方输出一致。

```python
from bisect import bisect_left

pals = []
for L in range(1, 14):
    half = 1 << ((L - 1) // 2)
    for h in range(half, half << 1):
        s = bin(h)[2:]
        p = int(s + s[-1 - (L % 2 == 0)::-1], 2)
        pals.append(p)
pals.sort()

def solve(x):
    j = bisect_left(pals, x)
    best = abs(x - pals[j]) if j < len(pals) else 10**9
    if j > 0:
        best = min(best, x - pals[j - 1])
    return best
```

## 复杂度
时间：生成 O(2^7) 个回文，每个查询 O(log 2^7)，总 O(n log P)，P 为回文数个数。
空间：`pals` 约 200 个整数，O(P) 额外空间。

## 易错点
- 位长上界取小了：`nums[i]` 最大 5000（约 13 位），若只生成到 12 位，`x=4095` 这类数会找不到上界候选，`bisect_left` 返回 `len(pals)` 导致越界。正确做法是生成到 13 位并处理 `j == len(pals)` 的边界。
- 镜像拼接时奇偶位搞反：`L=3` 时 `half` 从 4 到 7，`s="10"` 应拼成 `101`（去掉末位再反转），若写成 `s + s[::-1]` 会得到 `1001`（4 位），位长错乱。正确做法是按 `L` 的奇偶决定镜像时是否丢弃 `s` 的最后一位。

## 如果面试官追问
若 `nums[i]` 上限提到 10^18（60 位），怎么办？
答：位长循环到 60，回文数约 2^31 个太多，改为对每个 `x` 直接构造其位长及相邻位长的最近回文（枚举前半段偏移 ±1），O(1) 每查询。
