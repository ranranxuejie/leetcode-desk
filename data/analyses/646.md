## 一句话思路
按右端点升序排序后贪心取数对，每次选右端点最小且左端点大于上一个右端点的，这样给后面留的空间最大。

## 怎么做
1. 把 `pairs` 按 `right` 升序排序，右端点相同的顺序无所谓。
2. 维护 `cur = -inf`（上一个选中数对的右端点）和 `ans = 0`。
3. 遍历排序后的 `pairs`，若 `left > cur` 则选中它：`cur = right`，`ans += 1`。
4. 返回 `ans`。

以示例 1 `pairs = [[1,2],[2,3],[3,4]]` 为例：排序后不变。初始 `cur = -inf`，`[1,2]` 的 `left=1 > -inf` 选中，`cur=2`，`ans=1`；`[2,3]` 的 `left=2` 不 `> 2`，跳过；`[3,4]` 的 `left=3 > 2` 选中，`cur=4`，`ans=2`。关键中间值就是 `cur` 从 `-inf` 变成 `2` 再变成 `4`，`[2,3]` 被跳过正是因为它和 `[1,2]` 在端点 2 处「贴住」而不满足严格 `b < c`。

```python
pairs.sort(key=lambda p: p[1])
cur = float('-inf')
ans = 0
for left, right in pairs:
    if left > cur:
        cur = right
        ans += 1
return ans
```

为什么贪心成立：按右端点排序后，第一个能接上的数对右端点最小，选它不会让后续可选集合变小；任何最优解的首个元素都能替换成这个右端点最小的而不变差，归纳下去即得最优。注意这里排序键必须是 `p[1]` 而不是 `p[0]`，按左端点排序会得到错误答案。

## 复杂度
时间 O(n log n)：排序贡献 log n，遍历贡献 n。
空间 O(1) 额外（不计排序本身的开销）。

## 易错点
- 输入 `[[1,2],[2,3]]` → 若把条件写成 `left >= cur` 会错答 2 → 题目要求严格 `b < c`，必须写 `left > cur`，端点相等不能接。
- 输入 `[[-10,-5],[-5,0],[0,5]]` → 若按 `p[0]` 排序或直接按原顺序贪心，可能错答 1 或 2 → 必须按 `p[1]` 升序排序后再贪心，才能保证每步选右端点最小的。

## 如果面试官追问
问：要求输出具体的那条链而不只是长度？答：贪心时把选中的 `(left, right)` 追加进结果列表，最后返回该列表即可，逻辑不变。
