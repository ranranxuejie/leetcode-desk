## 一句话思路
把 s 拼成 s+s，用长度 n 的滑动窗口枚举所有循环移位，窗口内对两种交替模板分别数不匹配数，取全局最小。

## 怎么做
1. 令 n = len(s)，t = s + s；交替模板只有两种：偶数位为 '0' 的 `p0` 和偶数位为 '1' 的 `p1`。
2. 窗口 `t[i:i+n]` 对应一次类型 1 操作后的字符串，窗口内与模板不匹配的字符数就是该移位下需要的类型 2 次数。
3. 用滑动窗口增量维护：窗口右移一位时，去掉 `t[i]` 的贡献、加上 `t[i+n]` 的贡献，O(1) 更新两个计数。
4. 对所有 i 取 `min(cnt0, cnt1)` 的最小值。

以 s = "111000"（n=6）为例，i=2 时窗口是 `t[2:8] = "100011"`，与 `p0 = "010101"` 逐位比较，第 3 位 `0≠1`、第 6 位 `1≠0` 不匹配，`cnt0 = 2`；与 `p1 = "101010"` 比较得 `cnt1 = 4`，取 2，与答案一致。

```python
n = len(s)
t = s + s
cnt0 = sum(1 for j in range(n) if t[j] != ('0' if j % 2 == 0 else '1'))
cnt1 = n - cnt0
ans = min(cnt0, cnt1)
for i in range(1, n):
    # 移出 t[i-1]，移入 t[i+n-1]
    if t[i-1] != ('0' if (i-1) % 2 == 0 else '1'):
        cnt0 -= 1
    if t[i+n-1] != ('0' if (i+n-1) % 2 == 0 else '1'):
        cnt0 += 1
    cnt1 = n - cnt0
    ans = min(ans, cnt0, cnt1)
return ans
```

注意 `cnt1 = n - cnt0` 成立，因为每个位置对两个模板恰好一个匹配、一个不匹配。

## 复杂度
时间：O(n)，滑动窗口每个 i 只做常数次比较，n 来自字符串长度。
空间：O(n)，`t = s + s` 额外开 2n 字符；若原地取模可降到 O(1)。

## 易错点
- 只枚举 s 本身不枚举循环移位 → 对 "111000" 直接算得 `cnt0=3`，漏掉移位后 `cnt0=2` 的更优解 → 必须用 s+s 的 n 个窗口覆盖全部 n 种移位。
- 窗口右移时模板下标用错 → 写成 `t[i+n-1]` 却拿 `(i-1) % 2` 判断，导致 `cnt0` 漂移 → 移入位置的下标是 `i+n-1`，奇偶判断必须用这个下标本身。

## 如果面试官追问
问：若要求输出具体反转位置而非次数？答：记录取得最小值的窗口起点 i 和较小模板，再遍历该窗口逐位比对，不匹配的下标即反转位置。
