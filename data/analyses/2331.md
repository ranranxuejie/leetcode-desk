## 一句话思路
后序遍历：先递归拿到左右子树的布尔值，再用当前节点的 `val`（2 是 or、3 是 and）合并。

## 怎么做
1. 递归函数返回该子树的布尔值，叶子直接返回 `root.val == 1`。
2. 非叶子先算 `left = dfs(root.left)`、`right = dfs(root.right)`。
3. 按 `root.val` 合并：`2` 走 `left or right`，`3` 走 `left and right`。

拿示例 1 的 `[2,1,3,null,null,0,1]` 走一遍：根 `val=2`，左孩子 `1` 是叶子返回 `True`；右孩子 `val=3`，它的左叶 `0` 返回 `False`、右叶 `1` 返回 `True`，于是 `False and True = False`；回到根 `True or False = True`。关键中间值是右子树那一步的 `False`——它决定了根的 or 结果。

```python
def dfs(node):
    if node.left is None and node.right is None:
        return node.val == 1
    left = dfs(node.left)
    right = dfs(node.right)
    if node.val == 2:
        return left or right
    return left and right
```

注意 `node.val == 1` 而不是 `bool(node.val)`：`val=2` 和 `val=3` 在 Python 里都是真值，直接 `bool` 会把运算符节点误判成 `True`。

## 复杂度
时间 O(n)：每个节点访问一次，n 是节点数。
空间 O(h)：递归栈深度等于树高 h，最坏 O(n)，无额外数组。

## 易错点
- 输入 `[3,0,1]`（根是 AND，两叶 0 和 1）→ 若把叶子判断写成 `if not node.left` 而漏判 `node.right`，或反过来，会走进非叶子分支去取 `None` 的 `.val` 报错 → 正确做法是 `node.left is None and node.right is None` 两个条件都判。
- 输入 `[2,1,3,null,null,0,1]` → 若用 `bool(node.val)` 当叶子值，`val=3` 的节点会被当成 `True` 直接返回，跳过 `0 and 1`，结果仍是 `True` 但逻辑错；换成 `[3,2,3,null,null,0,1]` 这类根为 AND 的树就会算错 → 叶子必须显式写 `node.val == 1`。

## 如果面试官追问
问：树不保证完整二叉树（允许单孩子）怎么办？
答：单孩子时把缺失侧视为该运算符的单位元——or 补 `False`、and 补 `True`，其余逻辑不变。
