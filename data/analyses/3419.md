## 一句话思路
二分答案 X，只保留权值 ≤ X 的边，反向建图从 0 出发 BFS，检查每个节点出度是否 ≤ threshold。

## 怎么做
1. 答案必是某条边的权值或 -1，对排序去重后的权值二分。
2. 判定 `check(X)`：只取 `w <= X` 的边，反向建图（`b -> a`），从 0 出发 BFS/DFS 标记可达。
3. 若存在节点不可达，返回 `False`；否则统计每个原节点在保留边中的出度，任一 `> threshold` 即 `False`。
4. 二分找最小可行 X，全不可行返回 -1。

以示例 3 为例，`edges=[[1,2,1],[1,3,3],[1,4,5],[2,3,2],[3,4,2],[4,0,1]]`，threshold=1。取 X=2 时保留边 `1->2(1), 2->3(2), 3->4(2), 4->0(1)`，反向图从 0 可达 4、3、2、1 全部节点；出度：节点1 只有 `1->2` 一条，节点2 只有 `2->3`，节点3 只有 `3->4`，均 ≤1，可行。X=1 时 `2->3`、`3->4` 被删，节点 2 无法到达 0，不可行。

```python
def check(x):
    g = [[] for _ in range(n)]
    outdeg = [0] * n
    for a, b, w in edges:
        if w <= x:
            g[b].append(a)      # 反向：从 b 能回到 a
            outdeg[a] += 1
    seen = [False] * n
    seen[0] = True
    stack = [0]
    while stack:
        u = stack.pop()
        for v in g[u]:
            if not seen[v]:
                seen[v] = True
                stack.append(v)
    return all(seen) and max(outdeg) <= threshold
```

## 复杂度
时间：二分 O(log m) 轮，每轮 O(n + m)，m 为边数。
空间：反向邻接表 + seen + outdeg，O(n + m)。

## 易错点
- 正向建图从 0 出发 → 示例 2 中 0 只能到 1、2、3、4，看起来全可达，但题目要求「其他节点到达 0」，方向反了。必须反向建图 `b -> a`，从 0 出发搜到的才是能回到 0 的节点。
- 只检查可达性不检查出度 → 示例 1 取 X=2 时所有边保留，节点 2 出度为 2（`2->0`、`2->1`），threshold=2 恰好通过；但若 threshold=1 就必须删边，此时删 `2->0` 后节点 2 仍能经 `2->1->0` 到达 0。出度约束和可达性必须同时满足，缺一不可。

## 如果面试官追问
要求输出具体删除方案怎么办？答：在 check 通过时记录每个节点保留的出边（按权值升序取前 threshold 条），二分结束后重跑一次该 X 输出保留边集合。
