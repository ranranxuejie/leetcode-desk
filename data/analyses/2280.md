## 一句话思路
按 day 排序后，用相邻两点差值的叉积判断三点是否共线，共线则延续当前线段，否则线段数加一。

## 怎么做
1. 先按 `day` 升序排序，因为输入不保证有序（示例 2 就是乱序）。
2. 点数 ≤ 2 时直接返回 `len(stockPrices) - 1`（0 或 1 条线段）。
3. 从第 3 个点开始遍历，用前一点与当前点的 `(dx, dy)` 与当前线段方向做叉积比较。
4. 叉积为 0 说明共线，继续；否则 `ans += 1` 并更新方向。

以示例 1 排序后 `[[1,7],[2,6],[3,5],[4,4],[5,4],[6,3],[7,2],[8,1]]` 为例：
- 前三点 `(1,7),(2,6),(3,5)` 方向都是 `(1,-1)`，叉积 `1*(-1) - (-1)*1 = 0`，共线。
- 到 `(5,4)` 时，前一段方向 `(1,-1)`，新方向 `(1,0)`，叉积 `1*0 - (-1)*1 = 1 ≠ 0`，线段数从 1 变 2。
- 到 `(6,3)` 时方向又变回 `(1,-1)`，叉积非 0，线段数变 3。

```python
stockPrices.sort()
n = len(stockPrices)
if n <= 2:
    return n - 1
ans = 1
dx = stockPrices[1][0] - stockPrices[0][0]
dy = stockPrices[1][1] - stockPrices[0][1]
for i in range(2, n):
    ndx = stockPrices[i][0] - stockPrices[i-1][0]
    ndy = stockPrices[i][1] - stockPrices[i-1][1]
    if dx * ndy != dy * ndx:
        ans += 1
        dx, dy = ndx, ndy
return ans
```

## 复杂度
时间：排序 O(n log n)，遍历 O(n)，共 O(n log n)。
空间：排序额外 O(log n) 栈空间，其余 O(1)。

## 易错点
- 输入未排序（如示例 2 的 `[[3,4],[1,2],[7,8],[2,3]]`）→ 直接按原顺序算叉积会把共线判断错，得到错误线段数 → 必须先 `sort()` 按 day 升序。
- 用浮点斜率 `dy/dx` 比较共线 → `day` 和 `price` 达 10^9，除法精度丢失导致误判 → 改用交叉相乘 `dx * ndy == dy * ndx`，Python 大整数无溢出风险。

## 如果面试官追问
若要求输出每条线段的起止点而非数量？答：在叉积非 0 时记录上一段终点 `stockPrices[i-1]` 和当前段起点，最后补上末尾点即可。
