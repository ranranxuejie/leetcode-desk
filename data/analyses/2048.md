## 一句话思路
从 n+1 起逐个枚举并检查数位计数，因为平衡数在 10^6 附近很密集，枚举几步就命中。

## 怎么做
1. 令 `x = n + 1`，进入循环，每次 `x += 1` 后检查。
2. 用 `Counter(str(x))` 统计每个字符出现次数，注意 `'0'` 的计数必须为 0。
3. 对每个 `d, c`，要求 `c == int(d)`；任一不满足就继续下一个 x。
4. 全部满足即返回 x。

以 `n = 1000` 为例：x 从 1001 试到 1022 时，`Counter('1022')` 得 `{'1':1,'0':1,'2':2}`，`'0'` 的计数 1 ≠ 0，被否；继续到 1333，`Counter('1333')` 得 `{'1':1,'3':3}`，1==1、3==3，返回 1333。

```python
from collections import Counter

def check(x):
    for d, c in Counter(str(x)).items():
        if c != int(d):
            return False
    return True

x = n + 1
while not check(x):
    x += 1
return x
```

关键点：`'0'` 不需要特殊分支，`int('0') == 0` 自动要求它出现 0 次，这正是 1022 被排除的原因。

## 复杂度
时间：O(k · log x)，k 为枚举步数（本题实测很小），每步转字符串 O(log x)。
空间：O(log x)，`Counter` 最多存 10 个键。

## 易错点
- 输入 `n = 0` → 若从 `x = n` 开始检查会返回 0 或漏掉严格大于 → 必须 `x = n + 1`，答案应是 1（数字 1 出现 1 次）。
- 输入 `n = 1000` → 若只校验出现过的数位、忽略 `'0'` 的计数 → 会错答 1022 → 用 `Counter` 全量比对，`'0'` 计数必须为 0。

## 如果面试官追问
问：n 上限提到 10^18 怎么办？
答：枚举不可行，改为按数位长度回溯构造候选数位多重集，再拼最小排列与 n 比较。
