## 一句话思路
把相邻翻转看成「把 -1 沿数组搬运」，从右往左贪心，用最少的翻转把每个 -1 消掉。

## 怎么做
1. 目标只有两种：全 1 或全 -1。先算全 1 的代价，再算全 -1 的代价，取较小者与 k 比较。
2. 全 1 的代价：从右往左扫，遇到 `nums[i] == -1` 就必须翻转 `i-1` 和 `i`（i=0 时无解），翻转次数 +1，并把 `nums[i-1]` 取反。
3. 全 -1 的代价：等价于先把整个数组取反变成全 1 的代价，即对 `[-x for x in nums]` 跑一遍步骤 2。
4. 两次代价取 min，`min(cost1, cost2) <= k` 返回 `True`。

以 `nums = [1,-1,1,-1,1], k = 3` 为例跑全 1：i=3 是 -1，翻转下标 2、3，数组变 `[1,-1,-1,1,1]`，cost=1；i=1 是 -1，翻转下标 0、1，数组变 `[1,1,-1,1,1]`，cost=2；i=2 是 -1，翻转下标 1、2，数组变 `[1,1,1,1,1]`，cost=3。3 ≤ 3，返回 `True`。

```python
def cost_to_all_one(a):
    a = a[:]
    c = 0
    for i in range(len(a) - 1, 0, -1):
        if a[i] == -1:
            a[i - 1] = -a[i - 1]
            c += 1
    return c if a[0] == 1 else 10**9

c1 = cost_to_all_one(nums)
c2 = cost_to_all_one([-x for x in nums])
return min(c1, c2) <= k
```

关键点：从右往左扫时，翻转 `i-1` 不会影响已经处理过的 `i` 及右侧，所以每个位置最多被处理一次，贪心即最优。

## 复杂度
时间：O(n)，两次线性扫描，n 是 `nums.length`。
空间：O(n)，`a = a[:]` 和取反列表各开一份副本。

## 易错点
- `nums = [-1,-1,-1,1,1,1], k = 5`：只算全 1 代价会得 3 就返回 `True`，但全 1 实际需要把前三个 -1 逐个右移，代价远超 5；必须同时算全 -1 代价再取 min，本题答案是 `False`。
- `nums = [-1,1], k = 1`：全 1 需要翻转下标 0，代价 1；但若代码从 i=0 开始扫或漏判 `a[0] == 1`，会把无解当成 0 代价返回 `True`；正确做法是扫到 i=1 后单独检查 `a[0]`，不为 1 就返回大数。

## 如果面试官追问
要求输出具体操作序列怎么办？答：在贪心扫描时把每个被翻转的下标 i 追加到列表，正序即为操作序列，长度就是代价。
