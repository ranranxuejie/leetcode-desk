## 一句话思路
反向图 + 拓扑排序：从出度为 0 的节点剥起，能剥掉的都是安全节点。

## 怎么做
1. 建反向图 `rg`，同时统计原图每个节点的出度 `outdeg`。
2. 把所有 `outdeg[i] == 0` 的节点入队（终端节点天然安全）。
3. 逐个出队 `u`，标记安全；对 `rg[u]` 中每个 `v`，把 `outdeg[v]` 减 1，减到 0 就入队。
4. 最后收集所有被标记的节点，天然升序。

以示例 1 `graph = [[1,2],[2,3],[5],[0],[5],[],[]]` 为例：初始 `outdeg = [2,2,1,1,1,0,0]`，队列 `[5,6]`。弹出 5，反向边来自 2 和 4，`outdeg[2]` 变 0、`outdeg[4]` 变 0，两者入队；弹出 6 无反向边。接着弹出 2、4，最终 0、1、3 的 `outdeg` 始终降不到 0（它们绕在环 0→1→3→0 上），答案 `[2,4,5,6]`。

```python
from collections import deque
n = len(graph)
rg = [[] for _ in range(n)]
outdeg = [len(graph[i]) for i in range(n)]
for u in range(n):
    for v in graph[u]:
        rg[v].append(u)
q = deque(i for i in range(n) if outdeg[i] == 0)
safe = [False] * n
while q:
    u = q.popleft()
    safe[u] = True
    for v in rg[u]:
        outdeg[v] -= 1
        if outdeg[v] == 0:
            q.append(v)
return [i for i in range(n) if safe[i]]
```

## 复杂度
时间 O(n + E)：每条边在反向图里被访问一次，E ≤ 4×10^4。
空间 O(n + E)：`rg` 存全部边，`outdeg`/`safe`/队列各 O(n)。

## 易错点
- 输入含自环如 `graph = [[0]]`：节点 0 出度 1，永远进不了队列，正确输出 `[]`；若用朴素 DFS 只判「是否访问过」会把 0 误判成安全，必须用三色标记（0 未访问 / 1 在栈上 / 2 安全）。
- 示例 2 `[[1,2,3,4],[1,2],[3,4],[0,4],[]]`：节点 1 有自环 `1→1`，`outdeg[1]` 从 2 减到 1 就卡住，不会入队；若反向建图时漏掉自环这条边（`rg[1]` 少加一次 1），`outdeg[1]` 会被错误减到 0，答案多出 1。

## 如果面试官追问
问：不用反向图，直接 DFS 三色标记行不行？答：行，`dfs(u)` 遇到状态 1 返回 False、状态 2 返回 True，结果同样按索引升序收集，复杂度不变。
