## 一句话思路
按 `player_id` 分组取 `event_date` 的最小值，因为主键含 `event_date`，最早日期即首次登录。

## 怎么做
1. 用 `GROUP BY player_id` 把同一玩家的多行压成一组。
2. 对每组取 `MIN(event_date)`，这就是该玩家最早的活动日期。
3. 用 `AS first_login` 把聚合列改名，对齐输出列名。

拿官方示例走一遍：玩家 1 的两行是 `2016-03-01` 和 `2016-05-02`，分组后 `MIN(event_date)` 得 `2016-03-01`；玩家 3 的两行是 `2016-03-02` 和 `2018-07-03`，取到 `2016-03-02`。中间值就是每组的最小日期，直接落到 `first_login`。

```python
import pandas as pd

def game_analysis(activity: pd.DataFrame) -> pd.DataFrame:
    return (
        activity.groupby("player_id", as_index=False)["event_date"]
        .min()
        .rename(columns={"event_date": "first_login"})
    )
```

若用 SQL，等价写法是：

```python
# SELECT player_id, MIN(event_date) AS first_login
# FROM Activity GROUP BY player_id;
```

关键点：`as_index=False` 让 `player_id` 留在列里而不是变成索引，否则输出少一列；`rename` 必须在 `min()` 之后做，因为聚合前改列名会找不到 `event_date`。

## 复杂度
时间 O(n)：n 是 Activity 行数，分组加取最小扫一遍。
空间 O(k)：k 是不同玩家数，存分组结果。

## 易错点
- 输入里同一玩家有多台设备（如玩家 3 用 device_id 1 和 4）→ 若按 `(player_id, device_id)` 分组会得到两行 → 正确做法是只按 `player_id` 分组，设备与首次登录无关。
- 输入中某玩家只有一行（如玩家 2 只有 `2017-06-25`）→ 若误用 `event_date != MIN(...)` 之类过滤会把它漏掉或报空 → 正确做法是直接聚合取 `MIN`，单行组自然返回该行日期。

## 如果面试官追问
问：若要求同时输出首次登录当天的 `device_id`？答：先取每组 `MIN(event_date)`，再按 `(player_id, event_date)` 回连原表取该行设备。
