## 一句话思路
平方后最大值必在两端，用左右双指针从后往前填结果数组，一趟 O(n) 完成。

## 怎么做
1. 建 `res = [0] * len(nums)`，指针 `l = 0`、`r = len(nums) - 1`、`k = len(nums) - 1`。
2. 每轮比较 `nums[l] * nums[l]` 与 `nums[r] * nums[r]`，大的那个写进 `res[k]`。
3. 谁被取走谁内移（`l += 1` 或 `r -= 1`），`k -= 1`，直到 `l > r`。

拿 `nums = [-4,-1,0,3,10]` 走关键几步：初始 `l=0, r=4, k=4`，`16` 对 `100`，取 `100` 填 `res[4]`，`r` 变 3；再比 `16` 对 `9`，取 `16` 填 `res[3]`，`l` 变 1；接着 `1` 对 `9` 取 `9` 填 `res[2]`；`1` 对 `0` 取 `1` 填 `res[1]`；最后 `0` 填 `res[0]`，得 `[0,1,9,16,100]`。

```python
res = [0] * len(nums)
l, r, k = 0, len(nums) - 1, len(nums) - 1
while l <= r:
    a, b = nums[l] * nums[l], nums[r] * nums[r]
    if a > b:
        res[k] = a
        l += 1
    else:
        res[k] = b
        r -= 1
    k -= 1
return res
```

注意 `a > b` 用严格大于即可，相等时取右边不影响结果正确性，因为两个值相同。

## 复杂度
时间 O(n)：`l` 和 `r` 各走一遍，每轮只做一次比较和一次赋值。
空间 O(n)：`res` 长度等于 `len(nums)`，除此之外只有三个整型指针。

## 易错点
- 输入 `nums = [-5]`（单元素，或全负数如 `[-3,-2,-1]`）→ 若先找零点再向两边合并，边界下标会越界或漏掉端点 → 直接用 `l=0, r=n-1` 从两端起手，单元素时 `l == r` 一轮就结束，不需要特判。
- 输入 `nums = [-4,-1,0,3,10]` → 若从前往后填 `res[0]` 开始，会误以为最小值在 `nums[0]` 或 `nums[-1]` 的平方里，实际最小平方是 `0` 在中间 → 必须**从后往前**填，因为平方后的最大值一定来自两端，最小值位置不确定。

## 如果面试官追问
问：如果要求原地修改、不额外开数组？答：本题不行，平方后大小顺序被打乱，原地覆盖会丢失未处理元素，O(n) 解必须借 O(n) 空间。
