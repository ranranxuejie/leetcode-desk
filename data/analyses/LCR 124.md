## 一句话思路
先序首元素定根，用哈希表把中序下标降到 O(1)，再按左右子树长度分治递归。

## 怎么做
1. 建 `pos = {v: i for i, v in enumerate(inorder)}`，把「找根在中序的位置」从 O(n) 扫描变成 O(1)。
2. 递归参数用 `(pre_lo, in_lo, size)`：`root = preorder[pre_lo]`，`k = pos[root]`，左子树大小 `left = k - in_lo`。
3. 左子树 `(pre_lo+1, in_lo, left)`，右子树 `(pre_lo+1+left, k+1, size-1-left)`。
4. `size == 0` 返回 `None`。

以示例 1 为例：`pre_lo=0, in_lo=0, size=5`，`root=3`，`k=pos[3]=1`，`left=1`；于是左子树区间 `(1, 0, 1)` 取到 `9`，右子树 `(2, 2, 3)` 取到 `20`，`20` 的 `k=3`、`left=1`，分出 `15` 和 `7`。

```python
def build(pre_lo, in_lo, size):
    if size == 0:
        return None
    root = TreeNode(preorder[pre_lo])
    k = pos[root.val]
    left = k - in_lo
    root.left = build(pre_lo + 1, in_lo, left)
    root.right = build(pre_lo + 1 + left, k + 1, size - 1 - left)
    return root
```

关键是别用 `pre_lo/pre_hi` 双闭区间再算长度，直接传 `size` 少一次减法出错的机会。

## 复杂度
时间 O(n)：每个节点建一次，哈希查根 O(1)。
空间 O(n)：`pos` 哈希表 n 项，递归栈最坏 n 层（链状树）。

## 易错点
- 输入 `preorder=[1,2], inorder=[2,1]`（左链）→ 若右子树起点写成 `pre_lo+1` 而非 `pre_lo+1+left`，会把 `2` 重复挂到右边 → 右子树起点必须加 `left`。
- 输入 `preorder=[1,2,3], inorder=[1,2,3]`（右链）→ 若递归不传 `size` 而用全局 `pre_lo` 自增，右链会错位 → 用 `size-1-left` 显式算右子树规模，`size==0` 立即返回。

## 如果面试官追问
问：数组含重复值怎么办？
答：`pos` 要存下标列表，按先序顺序消费，且需保证中序里同值只对应一个位置，否则解不唯一。
