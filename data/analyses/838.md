## 一句话思路
按相邻两个非 `.` 字符分段处理：`L...L` 全变 `L`，`R...R` 全变 `R`，`R...L` 从两端向中间填，`L...R` 中间保持 `.`。

## 怎么做
1. 在字符串两端各补一个虚拟的 `L`（左）和 `R`（右），这样首尾的 `.` 段也能统一处理。
2. 用双指针 `i`、`j` 找相邻两个非 `.` 的位置，中间 `k = j - i - 1` 个点按四种情况填。
3. 关键分支：`dominoes[i] == 'R' and dominoes[j] == 'L'` 时，左半填 `R`、右半填 `L`，正中间（`k` 为奇数时）留 `.`。

以示例 2 `.L.R...LR..L..` 为例，取 `i` 指向索引 3 的 `R`、`j` 指向索引 7 的 `L`，`k = 3`，左半 `[4,5]` 填 `R`、右半 `[6]` 填 `L`，中间索引 5 因 `k` 为奇数保持 `.`，得到 `RR.LL` 这一段。

```python
s = list('L' + dominoes + 'R')
i = 0
for j in range(1, len(s)):
    if s[j] == '.':
        continue
    k = j - i - 1
    if s[i] == 'R' and s[j] == 'L':
        for t in range(i + 1, i + 1 + k // 2):
            s[t] = 'R'
        for t in range(j - k // 2, j):
            s[t] = 'L'
    elif s[i] == s[j]:
        for t in range(i + 1, j):
            s[t] = s[i]
    i = j
return ''.join(s[1:-1])
```

## 复杂度
时间 O(n)：每个下标最多被填一次，双指针各扫一遍。
空间 O(n)：`list(s)` 拷贝了一份长度 n+2 的字符数组。

## 易错点
- 输入 `"R.L"`（`k = 1` 奇数）→ 若写成 `range(i+1, i+1+k//2)` 之外还多填一格，会把中间索引 1 错填成 `R` 或 `L`；正确做法是 `k // 2 = 0`，两段循环都不执行，中间保持 `.`。
- 输入 `".L"` 或 `"R."` 这类只有一端有推力的 → 若不补虚拟哨兵，首尾的 `.` 段不会被任何分支覆盖，输出仍是 `.`；正确做法是补 `'L' + dominoes + 'R'`，让 `i=0` 的 `L` 把开头 `.` 全推成 `L`，末尾 `R` 同理。

## 如果面试官追问
问：如果要求输出每一秒的中间状态而不是最终态？答：按段模拟，`R...L` 段每秒两端各推进一格，其余段一秒内定型，逐秒记录即可。
