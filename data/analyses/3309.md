## 一句话思路
只有 3 个数，直接枚举 6 种排列，把每种拼接后的二进制串转成整数取最大。

## 怎么做
1. 用 `itertools.permutations(nums)` 生成全部 6 种顺序。
2. 对每种顺序，把每个数用 `bin(x)[2:]` 转成无前导零的二进制串，再 `''.join` 拼起来。
3. 用 `int(s, 2)` 把拼接串转回整数，维护最大值。

以 `nums = [1,2,3]` 为例，顺序 `(3,1,2)` 得到 `bin(3)[2:]='11'`、`bin(1)[2:]='1'`、`bin(2)[2:]='10'`，拼接串 `'11110'`，`int('11110', 2) = 30`，正是答案。顺序 `(1,2,3)` 拼成 `'11011'` = 27，比 30 小，所以枚举是必要的。

```python
from itertools import permutations

best = 0
for p in permutations(nums):
    s = ''.join(bin(x)[2:] for x in p)
    best = max(best, int(s, 2))
return best
```

关键点：拼接的是**二进制串**而不是十进制串，所以不能直接比较 `nums[i]` 的大小来决定顺序。比如 `[2,8,16]`，若按数值降序 `[16,8,2]` 拼成 `'10000100010'` = 1058，而正确答案来自 `[2,8,16]` 拼成 `'10100010000'` = 1296，数值最大的 16 反而不能放最前。

## 复杂度
时间：6 种排列 × 每个数最多 7 位二进制，常数级，可记作 O(1)。
空间：拼接串最长 21 字符，额外 O(1)。

## 易错点
- 用十进制字符串拼接再转二进制 → 对 `[2,8,16]` 会拼出 `'2816'` 再转二进制，得到完全错误的数 → 必须先 `bin(x)[2:]` 再拼接。
- 以为按 `nums` 降序排列最优 → `[2,8,16]` 降序得 1058，正确答案 1296 来自升序 → 必须真正枚举 6 种排列，不能靠排序贪心。

## 如果面试官追问
若 `nums` 长度扩到 n 且 n 较大，枚举 n! 不可行，怎么办？答：按「a 拼 b 与 b 拼 a 哪个更大」自定义比较器排序，即比较 `bin(a)+bin(b)` 与 `bin(b)+bin(a)` 的字典序。
