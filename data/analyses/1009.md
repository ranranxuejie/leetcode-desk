## 一句话思路
用「掩码全 1 异或」：造出与 n 位数相同的全 1 掩码 mask，`n ^ mask` 即逐位取反。

## 怎么做
1. 先处理 n = 0，直接返回 1（二进制 "0" 反码是 "1"）。
2. 用循环把 mask 推到「刚好覆盖 n 的最高位」：`mask = (mask << 1) | 1`，直到 `mask >= n`。
3. 返回 `n ^ mask`，因为 mask 的每一位都是 1，异或等价于取反。

以 n = 10 为例：二进制 "1010"，共 4 位。循环中 mask 依次为 1、3、7、15，`15 >= 10` 停下。此时 `10 ^ 15`：10 是 1010，15 是 1111，异或得 0101 = 5，与示例一致。

```python
if n == 0:
    return 1
mask = 1
while mask < n:
    mask = (mask << 1) | 1
return n ^ mask
```

关键点：循环条件是 `mask < n` 而不是 `mask <= n`。n = 7 时 mask 走到 7 就停，`7 ^ 7 = 0`，正好是示例 2 的答案；若写成 `<=`，mask 会变成 15，结果错成 8。

## 复杂度
时间：O(log n)，循环次数等于 n 的二进制位数。
空间：O(1)，只用了 mask 一个整数。

## 易错点
- 输入 n = 0 → 若直接进循环，mask 初始为 1，`1 < 0` 不成立，返回 `0 ^ 1 = 1`，恰好对；但若把 mask 初始写成 0 或先移位再或，会返回 0。正确做法是显式 `if n == 0: return 1`，别依赖巧合。
- 输入 n = 7（或任何 2^k - 1）→ 若循环条件写成 `mask <= n`，mask 会多推一位到 15，返回 `7 ^ 15 = 8`，而正确答案是 0。正确做法是 `while mask < n`，让 mask 停在 7。

## 如果面试官追问
问：n 接近 10^9 时循环会不会太慢？
答：10^9 < 2^30，最多 30 次迭代，常数级开销，无需优化。
