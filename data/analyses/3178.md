## 一句话思路
周期是 `2*(n-1)`，把 `k` 对周期取模后，用「先右后左」的分段公式直接算位置，不用逐秒模拟。

## 怎么做
1. 取 `t = k % (2 * (n - 1))`，把 50 秒的模拟压成一次取模。
2. 若 `t <= n - 1`，球还在向右走，位置就是 `t`。
3. 否则球在向左走，位置是 `2 * (n - 1) - t`。

拿示例 2 的 `n = 5, k = 6` 走一遍：周期 `2*(5-1) = 8`，`t = 6 % 8 = 6`；因为 `6 > 4`，走第二段，`2*4 - 6 = 2`，返回 2，与官方输出一致。再验示例 1 的 `n = 3, k = 5`：周期 `2*2 = 4`，`t = 5 % 4 = 1`，`1 <= 2`，返回 `t = 1`，也对。

```python
def numberOfChild(n, k):
    period = 2 * (n - 1)
    t = k % period
    if t <= n - 1:
        return t
    return period - t
```

关键点：`t == n - 1` 时球正好在右端，归第一段返回 `n - 1`；`t == 0` 时球在 0 号，也归第一段返回 0。两段在端点处不重不漏，因为第二段的 `period - t` 在 `t = n` 时给 `n - 2`，正好接上。

## 复杂度
时间：O(1)，只有一次取模和一次比较，与 n、k 都无关。
空间：O(1)，没开任何数组，只用了 `period`、`t` 两个整数。

## 易错点
- 忘记取模直接按 `k` 分段：`n = 5, k = 6` 时若判 `k <= n - 1` 得假、算 `2*(n-1) - k = 2` 碰巧对，但 `n = 3, k = 5` 会算成 `4 - 5 = -1`，返回负数。必须先 `k % (2*(n-1))`。
- 周期写成 `2*n` 或 `n-1`：`n = 3` 时 `2*n = 6`，`k = 5` 得 `t = 5`，`5 > 2` 走第二段得 `4 - 5 = -1`。正确周期是 `2*(n-1) = 4`，因为 0 和 n-1 两个端点各只算一次，往返一趟是 `2*(n-1)` 秒。

## 如果面试官追问
问：若 n 和 k 放大到 10^18 还能这么做吗？答：能，公式只依赖 `k % (2*(n-1))`，Python 大整数直接算，时间仍是 O(1)。
