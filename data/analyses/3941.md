## 一句话思路
用集合去重后按字符类别累加固定分值，因为每个字符最多计一次分。

## 怎么做
1. 把 `password` 转成 `set`，重复字符自动消失。
2. 遍历集合中每个字符，按类别映射到分值：小写 1、大写 2、数字 3、`"!@#$"` 中 5。
3. 累加得到结果。

以 `password = "aA1!"` 为例：`set` 后仍是 `{'a','A','1','!'}`，四个字符分别命中 1、2、3、5，累加得 11。若输入 `"bbB11#"`，`set` 后是 `{'b','B','1','#'}`，同样 1+2+3+5=11。

```python
def strength(password):
    total = 0
    for ch in set(password):
        if 'a' <= ch <= 'z':
            total += 1
        elif 'A' <= ch <= 'Z':
            total += 2
        elif '0' <= ch <= '9':
            total += 3
        elif ch in "!@#$":
            total += 5
    return total
```

判断顺序不影响正确性，因为四类字符互斥；用 `ch in "!@#$"` 而不是 `isalnum` 之类，避免把特殊字符误判。

## 复杂度
时间 O(n)：n 为 `password` 长度，建集合扫一遍，再遍历至多 62+4 个不同字符。
空间 O(1)：集合最多存 66 个不同字符，与 n 无关。

## 易错点
- 输入 `"aaa"` → 若直接遍历原串累加会得 3，正确是 1；必须先 `set(password)` 去重再计分。
- 输入 `"aA1!"` 中 `'!'` → 若用 `ch.isalnum()` 判断会漏掉特殊字符，或把 `'!'` 当普通字符跳过；正确做法是显式判断 `ch in "!@#$"`，且注意集合只含这四个符号，`'%'` 不在题面范围内。

## 如果面试官追问
问：若密码长度到 10^7 且要求流式处理怎么办？
答：仍用固定大小集合记录已见字符，边读边判重，空间不变。
