## 一句话思路
words 长度 ≤14，枚举子集（位掩码 0..2^n-1），用 letters 的 26 位计数判断每个子集能否拼出，取最大得分。

## 怎么做
1. 把 letters 压成 `cnt[26]`，每个单词压成 `need[i][26]` 和单词总分 `val[i]`，拼不出的单词直接丢弃。
2. 枚举掩码 `mask`，对每个 mask 累加所有选中单词的字母需求，若任一字母超过 `cnt` 则跳过。
3. 合法则更新 `ans = max(ans, 当前得分)`。

以示例 1 为例：`cnt` 中 d=3、a=2、o=2、g=1、c=1。单词 "dad" 的 need 是 d=2,a=1，val=11；"good" 是 g=1,o=2,d=1，val=12。mask 选中这两个时累加需求 d=3,a=1,g=1,o=2，全部 ≤ cnt，得分 23，是最大值。

```python
cnt = [0] * 26
for ch in letters:
    cnt[ord(ch) - 97] += 1
items = []
for w in words:
    need = [0] * 26
    for ch in w:
        need[ord(ch) - 97] += 1
    if all(need[k] <= cnt[k] for k in range(26)):
        items.append((need, sum(score[k] * need[k] for k in range(26))))
ans = 0
for mask in range(1 << len(items)):
    used = [0] * 26
    total = 0
    for i, (need, v) in enumerate(items):
        if mask >> i & 1:
            total += v
            for k in range(26):
                used[k] += need[k]
    if all(used[k] <= cnt[k] for k in range(26)):
        ans = max(ans, total)
```

## 复杂度
时间：O(2^m · m · 26)，m 为可拼出的单词数（≤14），26 是字母表常数。
空间：O(m · 26)，存每个单词的 need 数组，无额外大结构。

## 易错点
- 单词本身字母数超过 letters 时（如示例 3 的 "leetcode" 需要两个 e，letters 只有一个 e），若先枚举 mask 再判合法，会白跑 2^1 次；正确做法是预处理阶段就用 `all(need[k] <= cnt[k])` 过滤掉，items 只剩可拼单词。
- 示例 2 中 "xxxz" 单独得分 25 高于 "ax"+"bx"+"cx" 的 27 吗？不，25<27，但若误把 "xxxz" 与 "ax" 同时选入，需求 x=4 超过 cnt 的 x=3，必须靠 `used[k] <= cnt[k]` 拦住；漏掉这步会算出 25+9=34 的错误答案。

## 如果面试官追问
问：words 长度放大到 30 怎么办？
答：位掩码枚举 2^30 不可行，改用按字母维度做多重背包/DFS 剪枝，或对 words 按长度分组后回溯加可行性剪枝。
