## 一句话思路
把 word 压成每段连续字符的长度 `cnt`，方案数等于「每段取 1..cnt 个」且总长 ≥ k 的元组数，用补集 + 前缀和 DP 求。

## 怎么做
1. 扫描 word 得到每段长度列表 `cnt`，例如 `"aabbccdd"` → `[2,2,2,2]`，段数 `m=4`。
2. 总方案数 `total = prod(cnt)`，即每段任取 1..cnt 个；`"aabbccdd"` 时 `total = 16`。
3. 用 DP 数「总长 < k」的方案：`dp[j]` 表示前若干段凑出长度 j 的方案数，转移是滑动窗口 `dp[j] = sum(dp_prev[j-c] for c in 1..cnt)`，用前缀和 O(1) 完成。
4. 答案 `= (total - sum(dp[0..k-1])) % (10**9+7)`；`"aabbccdd", k=7` 时长度 <7 的方案为 11，`16-11=5`。

```python
MOD = 10**9 + 7
cnt = []
for ch in word:
    if cnt and ch == prev: cnt[-1] += 1
    else: cnt.append(1)
    prev = ch
total = 1
for c in cnt: total = total * c % MOD
dp = [0] * k
dp[0] = 1
for c in cnt:
    pre = [0] * (k + 1)
    for j in range(k): pre[j+1] = (pre[j] + dp[j]) % MOD
    ndp = [0] * k
    for j in range(k):
        lo = max(0, j - c)
        ndp[j] = (pre[j] - pre[lo]) % MOD
    dp = ndp
ans = (total - sum(dp)) % MOD
```

## 复杂度
时间：O(n + m·k)，n 是 word 长度用于分段，m 是段数，k ≤ 2000。
空间：O(k)，只开两个长度 k 的 dp 数组和前缀和数组。

## 易错点
- `k <= m` 时（如 `"aaabbb", k=3`，m=2），长度 <k 的方案数为 0，答案直接是 `total=9`？不对，示例输出 8——因为每段至少取 1 个，最小长度就是 m=2 < 3，但 `total=3*3=9` 里包含长度恰为 2 的 `"ab"`，它 <3 要扣掉，dp 必须算到 `k-1=2` 这一位，别提前 return。
- 前缀和窗口下界写成 `j-c` 却忘了 `max(0, ...)`，当 `c > j` 时索引变负，Python 会从尾部取值，`"aabbccdd"` 第一段 c=2、j=0 时 `pre[-2]` 悄悄取到错误值，答案偏大。

## 如果面试官追问
若 k 放大到 5*10^5 怎么办？答：DP 维度变成 O(n·k) 不可行，改用生成函数/多项式卷积或对 total 做容斥，需 O(n log n) 的 NTT。
