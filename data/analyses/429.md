## 一句话思路
用队列做 BFS，每轮先记下 `len(q)` 作为本层宽度，只弹出这么多节点，就能天然分层。

## 怎么做
1. `root` 为 `None` 直接返回 `[]`，否则 `q = deque([root])`。
2. 外层 `while q:` 每轮开一个 `level = []`，并记 `size = len(q)`。
3. 内层循环 `size` 次：`node = q.popleft()`，`level.append(node.val)`，再把 `node.children` 全部 `append` 进 `q`。
4. 内层结束后 `res.append(level)`。

以示例 1 的 `[1,null,3,2,4,null,5,6]` 为例，第一轮 `size = 1`，弹出 `1` 后 `q` 变成 `[3,2,4]`，`res = [[1]]`；第二轮 `size = 3`，依次弹出 `3,2,4`，其中 `3` 把 `5,6` 压入，本轮结束 `q = [5,6]`，`res = [[1],[3,2,4]]`。关键就是 `size` 在压入子节点**之前**取，否则第二轮会把 `5,6` 也算进第二层。

```python
from collections import deque

if not root:
    return []
q = deque([root])
res = []
while q:
    size = len(q)
    level = []
    for _ in range(size):
        node = q.popleft()
        level.append(node.val)
        q.extend(node.children)
    res.append(level)
return res
```

`q.extend(node.children)` 依赖 `children` 是列表；若某节点 `children` 为 `[]`，`extend` 不做事，正好对应叶子。

## 复杂度
时间 O(n)：每个节点入队出队各一次，`extend` 总共搬运 n-1 条子边。
空间 O(w)：队列最多存一层宽度 w，`res` 另占 O(n)。

## 易错点
- 把 `size = len(q)` 写进内层循环条件 `while q:` 里逐次判断 → 子节点一压入就被当成本层弹出，示例 1 会输出 `[[1],[3,2,4],[5,6]]` 之外的错层结果 → 必须在 `for` 之前固定 `size`。
- `root = []`（节点总数可为 0）时直接 `deque([root])` → 后续 `node.val` 抛 `AttributeError` → 先判 `if not root: return []`。

## 如果面试官追问
问：高度上限 1000，递归 DFS 按深度收集行不行？
答：可以，`dfs(node, depth)` 用 `depth` 索引 `res`，但要额外判 `depth == len(res)` 才新建行，且深度 1000 有栈风险，BFS 更稳。
