## 一句话思路
枚举每个中心与半径，用两条对角前缀和 O(1) 取菱形边界，再用小顶堆维护前三大且去重。

## 怎么做
1. 对每个方向建对角前缀和：`d1[i][j]` 沿左上到右下累加，`d2[i][j]` 沿右上到左下累加，这样一条斜线段和可 O(1) 求出。
2. 枚举中心 `(i,j)` 与半径 `r`（`r=0` 就是单格），要求 `i-r>=0, i+r<m, j-r>=0, j+r<n`。
3. 半径 `r>0` 时，菱形边界 = 四条斜边之和，但四个顶点被两条边各算一次，要减掉四个顶点值。
4. 把每个和塞进容量 3 的小顶堆并去重，最后倒序输出。

以示例 1 的中心 `(2,2)`（值 200）、`r=1` 为例：四条边分别取到 `(1,2)=4`、`(2,1)=30`、`(2,3)=40`、`(3,2)=5`，四顶点是 `(1,2)=4,(2,1)=30,(2,3)=40,(3,2)=5`，和 = 4+30+40+5 = 79；而 `r=0` 时该中心贡献 200。真正最大的 228 来自中心 `(2,1)`、`r=1`：边和 3+20+200+5 = 228，四顶点 3+20+200+5 恰好就是这四个数本身（此例顶点即边端点），故 228。

```python
m, n = len(grid), len(grid[0])
d1 = [[0]*(n+1) for _ in range(m+1)]
d2 = [[0]*(n+2) for _ in range(m+1)]
for i in range(m):
    for j in range(n):
        d1[i+1][j+1] = grid[i][j] + d1[i][j]
        d2[i+1][j+1] = grid[i][j] + d2[i][j+2]
def seg(a, b, c, d):  # 占位，实际按方向分别写
    ...
heap = []
for i in range(m):
    for j in range(n):
        r = 0
        while i-r >= 0 and i+r < m and j-r >= 0 and j+r < n:
            if r == 0:
                s = grid[i][j]
            else:
                s = (d1[i+1][j+r+1]-d1[i-r][j+1]
                     + d1[i+r+1][j+1]-d1[i+1][j-r+1]
                     + d2[i+1][j-r+1]-d2[i-r][j+1]
                     + d2[i+r+1][j+1]-d2[i+1][j+r+1]
                     - grid[i-r][j] - grid[i+r][j] - grid[i][j-r] - grid[i][j+r])
            if s not in heap:
                heapq.heappush(heap, s)
                if len(heap) > 3: heapq.heappop(heap)
            r += 1
return sorted(heap, reverse=True)
```

## 复杂度
时间 O(m·n·min(m,n))，枚举中心与半径；堆操作每次 O(log 3) 可视为常数。
空间 O(m·n)，两张对角前缀和表；堆只存 3 个元素。

## 易错点
- 半径 `r=0` 时若也套四条边公式，会把同一格算 4 次再减 4 次得 0 → 示例 3 的 `[[7,7,7]]` 会输出 `[0]` → 必须对 `r==0` 单独取 `grid[i][j]`。
- 顶点重复扣除：四条斜边把四个顶点各算两次，若忘记减 `grid[i-r][j]` 等四项，示例 1 中心 `(2,2)`、`r=1` 会得 79+79=158 而非 79 → 减顶点时注意 `r=0` 不进入该分支。

## 如果面试官追问
若要求返回所有不同菱形和的前 k 大？答：把堆容量从 3 改成 k，复杂度不变，只是 `log k` 变大。
