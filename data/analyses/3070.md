## 一句话思路
子矩阵固定含左上角，所以只需枚举右下角 (i,j)，用二维前缀和 O(1) 求其和，与 k 比较计数。

## 怎么做
1. 建 (m+1)×(n+1) 的前缀和 `pre`，`pre[i+1][j+1] = grid[i][j] + pre[i][j+1] + pre[i+1][j] - pre[i][j]`。
2. 枚举右下角 `(i, j)`，`i` 从 0 到 m-1，`j` 从 0 到 n-1。
3. 该子矩阵和 = `pre[i+1][j+1]`（因为左上角是 (0,0)，公式退化成单点）。
4. 若和 ≤ k 则计数加一。

以示例 1 的 `grid = [[7,6,3],[6,6,1]]`、`k = 18` 为例：`pre[1][1]=7`、`pre[1][2]=13`、`pre[2][1]=13`、`pre[2][2]=29`、`pre[2][3]=33`。逐个比 k：7、13、13、29、33 中 ≤18 的有 7、13、13 三个，加上 `pre[1][3]=16` 也 ≤18，共 4 个，与输出一致。

```python
m, n = len(grid), len(grid[0])
pre = [[0] * (n + 1) for _ in range(m + 1)]
for i in range(m):
    for j in range(n):
        pre[i+1][j+1] = grid[i][j] + pre[i][j+1] + pre[i+1][j] - pre[i][j]
ans = 0
for i in range(1, m + 1):
    for j in range(1, n + 1):
        if pre[i][j] <= k:
            ans += 1
return ans
```

## 复杂度
时间 O(m·n)：建前缀和与枚举右下角各扫一遍矩阵。
空间 O(m·n)：额外开 (m+1)×(n+1) 的 `pre`，无其他结构。

## 易错点
- 误把「含左上角」理解成任意子矩阵 → 会去枚举四个边界、套完整二维前缀和公式，复杂度升到 O(m²n²) 且答案偏大；正确做法是只枚举右下角，和直接取 `pre[i+1][j+1]`。
- `grid` 全为 0、`k ≥ 1` 时 → 若把 `pre` 初值或边界写成 `-1` 之类，会漏计或错计；正确做法是 `pre` 首行首列全 0，`pre[i+1][j+1]` 从 0 起累加，m·n 个右下角全部计入。

## 如果面试官追问
若要求子矩阵不必含左上角、统计和 ≤ k 的任意子矩阵数？答：需枚举上下边界压缩成一维，再对列前缀和做双指针/二分，复杂度 O(m²n log n)。
