## 一句话思路
用 `fillna(0)` 把 `quantity` 列的 `None` 一次性替换成 0，其余列不动。

## 怎么做
1. 拿到 `products` 这个 DataFrame，确认缺失只出现在 `quantity` 列（示例里是 WirelessEarbuds 和 GolfClubs 两行）。
2. 对 `quantity` 列调用 `fillna(0)`，把 `None` 替换成整数 0。
3. 返回整个 DataFrame，`name` 和 `price` 保持原值。

关键中间值：以官方示例为例，`products["quantity"]` 原始是 `[32, None, None, 849]`，`fillna(0)` 之后变成 `[32, 0, 0, 849]`；第 2、3 行的 `price` 仍是 821、9319，没被波及。

```python
import pandas as pd

def fill_missing(products: pd.DataFrame) -> pd.DataFrame:
    products["quantity"] = products["quantity"].fillna(0)
    return products
```

注意别写成 `products.fillna(0)`：那样会把 `name` 列里可能存在的 `None` 也填成 0，`name` 是 object 类型，填 0 后列类型变脏，输出对不上。只对 `quantity` 这一列动手。

## 复杂度
时间：O(n)，n 是 `products` 行数，逐行扫描 `quantity` 判断是否缺失。
空间：O(n)，`fillna` 返回新列（或原地改时 O(1) 额外），不额外开与 n 无关的结构。

## 易错点
- 输入里 `quantity` 是 `None` 而非 `NaN` 时，若先做 `astype(int)` 再填，会直接抛 `TypeError`；正确做法是先 `fillna(0)` 再考虑类型转换，示例中 WirelessEarbuds 的 `None` 必须先填。
- 对整个 DataFrame 调 `fillna(0)` 而非只对 `quantity` 列：若 `name` 列有缺失，会被填成 0，输出该行 `name` 变成 `0` 而不是原缺失值，与期望不符；正确做法是 `products["quantity"].fillna(0)` 锁定列。

## 如果面试官追问
问：如果要求原地修改、不返回新对象怎么办？
答：用 `products["quantity"].fillna(0, inplace=True)`，或 `products.fillna({"quantity": 0}, inplace=True)`，避免整表复制。
