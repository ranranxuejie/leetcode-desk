## 一句话思路
后序 DFS 每个节点返回 `(是否BST, 最小值, 最大值, 子树和)`，用左右子树的边界判断当前节点能否拼成 BST。

## 怎么做
1. 空节点返回 `(True, inf, -inf, 0)`，让叶子节点的左右判断自然成立。
2. 后序拿到左 `(lb, lmin, lmax, ls)` 和右 `(rb, rmin, rmax, rs)`，当前节点是 BST 当且仅当 `lb and rb and lmax < root.val < rmin`。
3. 成立时 `cur = root.val + ls + rs`，用 `nonlocal ans` 更新 `ans = max(ans, cur)`，并返回 `(True, min(lmin, root.val), max(rmax, root.val), cur)`。
4. 不成立返回 `(False, 0, 0, 0)`，边界值随便填，因为父节点只看 `lb/rb` 就会否决。

以示例 1 的节点 3（左孩子 2、右孩子 5）为例：左返回 `(True,2,2,2)`，右返回 `(True,5,5,5)`，`2 < 3 < 5` 成立，`cur = 3+2+5 = 10`；再往上到根 1 时右子树根是 4，其左孩子 2 使 `lmax=4` 不满足 `4 < 4`，整棵右子树被否决，最终 `ans` 停在 20（节点 3 那棵 3+2+5+4+6 的子树）。

```python
def dfs(node):
    if not node:
        return True, float('inf'), float('-inf'), 0
    lb, lmin, lmax, ls = dfs(node.left)
    rb, rmin, rmax, rs = dfs(node.right)
    if lb and rb and lmax < node.val < rmin:
        cur = node.val + ls + rs
        nonlocal ans
        ans = max(ans, cur)
        return True, min(lmin, node.val), max(rmax, node.val), cur
    return False, 0, 0, 0
```

## 复杂度
时间 O(n)：每个节点只被访问一次，判断是 O(1)。
空间 O(h)：递归栈深度等于树高，最坏链状 O(n)，无额外数组。

## 易错点
- 示例 5 `[5,4,8,3,null,6,3]`：只看「左<根<右」会误判根 5 的右子树——8 的左孩子 6 合法，但 8 的右孩子 3 小于 8，必须靠 `rmin=3 < 8` 否决；正确做法是每层都用子树全局 `min/max` 而非直接孩子值比较。
- 示例 3 `[-4,-2,-5]`：单节点子树和都是负数，若把 `ans` 初始化为 0 却仍在 BST 成立时无条件更新，会得到 -4；正确做法是 `ans` 初值 0 且只在 `cur > ans` 时更新，让空 BST 的 0 兜底。

## 如果面试官追问
问：节点值范围放宽到 64 位、n 到 10^6 怎么办？
答：逻辑不变，Python 整数无溢出；n 大时改迭代后序或调大递归上限，避免栈溢出。
