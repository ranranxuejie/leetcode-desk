## 一句话思路
前缀和 + 单调递增双端队列：队列里存的是「还没被后面更小前缀和淘汰」的下标，队头到当前下标就是候选最短区间。

## 怎么做
1. 先算前缀和 `pre[i] = nums[0..i-1]` 之和，`pre[0]=0`，长度 `n+1`。
2. 遍历 `i` 从 0 到 n，维护一个下标单调、`pre` 值严格递增的队列 `q`。
3. 每步先「收割」：当 `pre[i] - pre[q[0]] >= k` 时，用 `i - q[0]` 更新答案并弹出队头。
4. 再「入队」：当 `pre[q[-1]] >= pre[i]` 时弹出队尾，再把 `i` 压入。

用示例 3 `nums=[2,-1,2], k=3`：`pre=[0,2,1,3]`。`i=1` 时 `pre[1]-pre[0]=2<3`，入队后 `q=[0,1]`；`i=2` 时 `pre[2]=1`，把 `pre[1]=2` 的队尾弹掉，`q=[0,2]`；`i=3` 时 `pre[3]-pre[0]=3>=3`，答案 `3-0=3`，弹出 0 后 `q=[2]`，`pre[3]-pre[2]=2<3` 停止。最终返回 3。

```python
pre = [0] * (n + 1)
for i in range(n):
    pre[i + 1] = pre[i] + nums[i]
q = deque()
ans = n + 1
for i in range(n + 1):
    while q and pre[i] - pre[q[0]] >= k:
        ans = min(ans, i - q[0])
        q.popleft()
    while q and pre[q[-1]] >= pre[i]:
        q.pop()
    q.append(i)
return ans if ans <= n else -1
```

关键点：队头弹出后不再回来，因为后面的 `i` 更大，同样的 `q[0]` 只会给出更长的区间。

## 复杂度
时间 O(n)：每个下标最多入队、出队各一次，`pre` 计算也是 O(n)。
空间 O(n)：`pre` 数组和队列各占 O(n)。

## 易错点
- 输入 `nums=[1,2], k=4` → 若把 `ans` 初值设成 `n` 而不是 `n+1`，最后判断 `ans <= n` 会误判成有解 → 初值必须取 `n+1`，返回前再判 `ans <= n`。
- 输入 `nums=[2,-1,2], k=3` → 若用普通滑动窗口（左指针只在和 ≥ k 时右移），遇到负数 `-1` 时窗口和会反复横跳，漏掉 `[2,-1,2]` 这个解 → 必须用前缀和 + 单调队列，靠 `pre[q[-1]] >= pre[i]` 弹尾保证队列单调。

## 如果面试官追问
问：如果要求输出该子数组本身而不只是长度？
答：收割时记录 `(i, q[0])` 这对下标，最后返回 `nums[q[0]:i]` 即可，队列逻辑不变。
