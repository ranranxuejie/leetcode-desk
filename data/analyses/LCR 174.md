## 一句话思路
中序遍历按升序输出，改成「右-根-左」逆序，数到第 cnt 个即停，不必遍历全树。

## 怎么做
1. 逆中序：先递归右子树，再访问根，再递归左子树，这样访问顺序是从大到小。
2. 用外部计数器 `self.k` 记录已访问节点数，进入根节点时 `self.k += 1`。
3. 当 `self.k == cnt` 时把 `root.val` 存进 `self.ans` 并立即返回，剪掉剩余分支。
4. 递归返回后若 `self.ans is not None` 就继续向上返回，避免多余遍历。

以示例 2 为例，`cnt = 4`：从 10 出发先走右子树，访问 20（k=1）、15（k=2）、10（k=3），再进左子树访问 8（k=4），此时 `self.ans = 8`，直接返回，节点 7、6、5、2、1 全被跳过。

```python
def dfs(root):
    if root is None or self.ans is not None:
        return
    dfs(root.right)
    if self.ans is not None:
        return
    self.k += 1
    if self.k == cnt:
        self.ans = root.val
        return
    dfs(root.left)
```

关键中间值：走到 8 时 `self.k` 从 3 变 4，等于 `cnt`，`self.ans` 由 `None` 变 8，后续 `dfs(root.left)` 因 `self.ans is not None` 直接返回。

## 复杂度
时间 O(h + cnt)：沿右链下行 O(h)，再访问 cnt 个节点即停，最坏 O(n)。
空间 O(h)：递归栈深度等于树高，最坏退化成链时 O(n)，无额外数组。

## 易错点
- 输入 `root = [7,3,9,1,5], cnt = 2` 若写成普通中序（左-根-右），访问顺序是 1,3,5,7,9，第 2 个得 3，错成第 cnt 小；正确做法是先右后左，第 2 个才是 7。
- 输入 `root = [10,5,15,2,7,null,20,1,null,6,8], cnt = 4` 若在 `self.k == cnt` 后不 return，会继续遍历左子树把 `self.k` 加到 5、6，`self.ans` 被后续节点覆盖成 6 或 1；正确做法是命中后立刻 return，并在每层入口检查 `self.ans is not None` 提前剪枝。

## 如果面试官追问
追问：若树不是 BST 而是普通二叉树，怎么找第 cnt 大？
答：逆中序失效，需先遍历全树收集所有值排序，或维护大小为 cnt 的小顶堆，时间 O(n log cnt)。
