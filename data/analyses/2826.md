## 一句话思路
答案 = n − 最长非递减子序列长度，值域只有 1/2/3，用三阶段 DP 在 O(n) 内求这个长度。

## 怎么做
1. 把保留的元素按值切成三段：一段 1、一段 2、一段 3，段可以为空，段内顺序不变。
2. 定义 `dp[v]` = 当前前缀中，以「值 ≤ v 的段已结束」为状态时能保留的最多元素数，初始 `dp = [0,0,0,0]`。
3. 对每个 `x` 从 3 倒序更新 `dp[v] = max(dp[v], dp[v-1]) + 1`（当 `v >= x`），倒序保证同一元素不被重复计入。
4. 返回 `len(nums) - dp[3]`。

以 `nums = [2,1,3,2,1]` 为例，处理完前两个元素 `2,1` 后 `dp = [0,1,1,1]`；处理到 `3` 时 `dp[3]` 从 1 变成 2，说明「1,3」这段被保留；最终 `dp[3] = 2`，答案 `5 - 2 = 3`。

```python
dp = [0, 0, 0, 0]
for x in nums:
    for v in range(3, x - 1, -1):
        dp[v] = max(dp[v], dp[v - 1]) + 1
return len(nums) - dp[3]
```

关键点：`dp[v]` 只依赖 `dp[v]` 和 `dp[v-1]`，倒序循环让 `dp[v-1]` 还是「不含当前 x」的旧值，等价于 0/1 背包的一维滚动。

## 复杂度
时间 O(n)：外层 n 个元素，内层最多 3 次，常数级。
空间 O(1)：只开长度 4 的 `dp` 数组，与 n 无关。

## 易错点
- 内层写成 `for v in range(x, 4)` 正序 → 同一个 `x` 会被连续塞进 `dp[x]`、`dp[x+1]`…，`[1,1,1]` 会算出保留 3 个以上、答案变成负数。必须 `range(3, x-1, -1)` 倒序。
- 把 `dp[v]` 的语义理解成「以值 v 结尾」而非「值 ≤ v 的段已结束」→ 遇到 `[3,1,2]` 会误以为要丢掉 3 和 1 只留 2，得 2；正确是保留 `[1,2]` 丢 1 个，`dp[3]` 应为 2，答案 1。

## 如果面试官追问
问：值域扩大到 1..k（k 很大）怎么办？
答：`dp` 数组开到 k+1，内层循环变成 O(k)，总 O(nk)；若 k 与 n 同阶就退化成 O(n²)，此时改用「最长非递减子序列」的二分贪心 O(n log n)。
