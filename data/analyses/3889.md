## 一句话思路
用长度 36 的数组统计频次，只遍历 18 个镜像对，每对算一次绝对差。

## 怎么做
1. 把 `'0'-'9'` 映射到下标 0-9，`'a'-'z'` 映射到 10-35，扫一遍 `s` 累加 `cnt`。
2. 镜像关系：数字 `i` 对 `9-i`，字母 `10+j` 对 `10+(25-j)`，即下标 `i` 对 `35-i`（数字段和字母段各自对称，恰好统一）。
3. 只枚举 `i` 从 0 到 17，累加 `abs(cnt[i] - cnt[35-i])`，`i` 与 `35-i` 不会重复计。

以 `s = "ab1z9"` 为例：`cnt` 中 `a`(10)=1、`z`(35)=1、`b`(11)=1、`1`(1)=1、`9`(9)=1，其余 0。`i=0` 时 `abs(cnt[0]-cnt[35]) = |0-1| = 1`（`'0'` 与 `'9'`），`i=1` 时 `|1-0| = 1`（`'1'` 与 `'8'`），`i=10` 时 `|1-1| = 0`，`i=11` 时 `|1-0| = 1`，合计 3。

```python
cnt = [0] * 36
for ch in s:
    if ch.isdigit():
        cnt[ord(ch) - ord('0')] += 1
    else:
        cnt[ord(ch) - ord('a') + 10] += 1
ans = 0
for i in range(18):
    ans += abs(cnt[i] - cnt[35 - i])
```

## 复杂度
时间 O(n + 36)，n 为 `s` 长度，扫串是主项，枚举 18 对是常数。
空间 O(1)，只开了固定 36 个计数槽。

## 易错点
- 若把 `'0'` 的镜像算成 `'9'` 却用 `ord(ch)-ord('0')` 后仍按 26 取模，`"09"` 会错成 0 而非 0（本例恰好对），但 `"0"` 单独出现时若漏掉数字段对称会错成 1；正确做法是数字段用 `9-i`、字母段用 `25-j`，或统一成 `35-i`。
- 若对每个出现过的字符都算一次 `|freq(c)-freq(m)|` 而不去重，`"byby"` 中 `b` 和 `y` 各算一次得 0+0=0 尚可，但 `"ab1z9"` 里 `a` 和 `z` 会各算一次 0，`b` 和 `y` 各算一次 1，结果变 4；正确做法是只枚举 `i < 18`，每对只算一次。

## 如果面试官追问
若字符集扩到全部 ASCII 可打印字符，怎么改？答：仍用定长数组，镜像映射改成 `127 - i` 或按自定义表查，枚举上界取表长一半。
