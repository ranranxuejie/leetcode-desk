## 一句话思路
把 0 映射成 -1、1 映射成 1，求前缀和 `pre`，找最小的 `i` 使 `pre[i] > total - pre[i]`，即 `2*pre[i] > total`。

## 怎么做
1. 先算全数组总和 `total = sum(1 if x else -1 for x in possible)`。
2. 从左往右累加前缀和 `pre`，`i` 从 0 到 `n-2`（Bob 至少留 1 关）。
3. 第一个满足 `pre > total - pre` 的 `i`，返回 `i+1`；遍历完没有就返回 `-1`。

以 `possible = [1,0,1,0]` 为例：`total = 1-1+1-1 = 0`。`i=0` 时 `pre=1`，Bob 得 `0-1=-1`，`1 > -1` 成立，直接返回 `1`。若换成 `[1,1,1,1,1]`，`total=5`；`i=0,1,2` 时 `pre` 分别是 `1,2,3`，Bob 得 `4,3,2`，直到 `i=2` 才首次 `3 > 2`，返回 `3`。

```python
total = sum(1 if x else -1 for x in possible)
pre = 0
for i in range(len(possible) - 1):
    pre += 1 if possible[i] else -1
    if pre > total - pre:
        return i + 1
return -1
```

关键点：`total - pre` 就是 Bob 的分数，不用再扫一遍后缀；循环上界 `len(possible)-1` 保证 Bob 至少完成最后一关。

## 复杂度
时间 O(n)：一次求和加一次单遍扫描，各扫 n 个元素。
空间 O(1)：只开 `total`、`pre`、`i` 三个变量，无额外数组。

## 易错点
- 输入 `[1,1]` → 若循环写到 `range(n)`，`i=1` 时 Bob 得 0 分（没关卡），会误判 `pre=2 > 0` 返回 2 → 正确做法是上界取 `n-1`，Bob 至少留 1 关，此题应返回 `-1`。
- 输入 `[0,0]` → 若用 `pre >= total - pre` 判「更多」，`i=0` 时 `-1 >= -1` 成立会返回 1 → 必须用严格大于 `>`，平局不算赢，正确答案是 `-1`。

## 如果面试官追问
问：如果要求返回所有可行的 Alice 关卡数？答：把 `return i+1` 改成收集进列表，继续扫到 `n-1`，时间仍是 O(n)。
