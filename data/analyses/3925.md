## 一句话思路
用切片拼接：`nums + nums[::-1]`，前半原序、后半逆序，一次成型。

## 怎么做
1. 取 `n = len(nums)`，答案长度固定为 `2 * n`。
2. 前半段直接复用 `nums`，对应 `ans[i] = nums[i]`。
3. 后半段用 `nums[::-1]` 生成逆序，对应 `ans[i + n] = nums[n - i - 1]`。
4. 两段用 `+` 拼成新列表返回，不改动入参。

以 `nums = [1,2,3]` 为例，`n = 3`，`nums[::-1]` 得到 `[3,2,1]`，拼接后 `ans = [1,2,3,3,2,1]`；其中 `ans[3] = nums[2] = 3`，`ans[5] = nums[0] = 1`，与公式逐位吻合。

```python
n = len(nums)
ans = nums + nums[::-1]
return ans
```

若想显式对齐题面公式，也可写成：

```python
n = len(nums)
ans = [0] * (2 * n)
for i in range(n):
    ans[i] = nums[i]
    ans[i + n] = nums[n - i - 1]
return ans
```

两种写法结果一致；前者更短，后者更贴近公式、便于口述下标关系。注意 `nums[::-1]` 产生的是新列表，不会把 `nums` 本身翻转，所以前半段仍是原序。

## 复杂度
时间 O(n)：切片复制 n 个元素、拼接再复制 2n 个元素，均为线性。
空间 O(n)：额外开了长度 2n 的 `ans`，输入本身不计。

## 易错点
- 输入 `nums = [1]` → 若误以为逆序段要跳过或长度算成 `n - 1`，会返回 `[1]` 而非 `[1,1]` → 后半段长度恒为 `n`，`n = 1` 时也要填 `nums[0]`。
- 输入 `nums = [1,2,3]` → 若写成 `nums + nums.reverse()`，`reverse()` 返回 `None`，直接报 `TypeError` → 用返回新列表的 `nums[::-1]`，或先 `nums.reverse()` 再 `nums + nums`（但此时前半段已被改序，结果错成 `[3,2,1,3,2,1]`）。

## 如果面试官追问
追问：若要求原地把 `nums` 扩成 2n 长并返回，怎么做？
答：先 `nums.extend(nums[::-1])` 再返回，仍是 O(n) 时间、O(n) 额外空间。
