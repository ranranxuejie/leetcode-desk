## 一句话思路
答案只可能是 1 或 2：整串回文就 1 次，否则先删全部 'a'、再删全部 'b'，2 次搞定。

## 怎么做
1. 用双指针 `i=0`、`j=len(s)-1` 从两端向中间比对，判断整串是否回文。
2. 一旦 `s[i] != s[j]`，立刻返回 2，不必继续比。
3. 指针相遇仍未失配，返回 1。

以 `s = "abb"` 为例：`i=0, j=2`，`s[0]='a'` 与 `s[2]='b'` 不等，直接返回 2。而 `s = "ababa"`：`s[0]==s[4]='a'`、`s[1]==s[3]='b'`，`i` 增到 2 与 `j` 相遇，返回 1。

关键在第二步的成立理由：'a' 的所有出现按原序取出，形如 `"aaa..."`，必然是回文子序列；'b' 同理。所以非回文时两次一定够，而 0 次不可能（`len(s) >= 1`），答案被夹在 1 和 2 之间。

```python
def removePalindromeSub(s):
    i, j = 0, len(s) - 1
    while i < j:
        if s[i] != s[j]:
            return 2
        i += 1
        j -= 1
    return 1
```

注意循环条件是 `i < j` 而非 `i <= j`：长度为奇数时中间那个字符自己和自己相等，比不比都不影响结论，用 `<` 少一次无意义比较。

## 复杂度
时间 O(n)：双指针最多走 n/2 步，最坏情况（整串回文）走满。
空间 O(1)：只开了 `i`、`j` 两个整数，没有额外字符串或数组。

## 易错点
- 输入 `s = "abb"` → 若误以为要真的模拟删除、去数「最少删几次回文子序列」，会往区间 DP 上想，写出 O(n²) 的 `dp[i][j]` → 正确做法是抓住字母表只有 `{'a','b'}` 这个约束，答案上界被压到 2。
- 输入 `s = "a"` 或 `s = "aa"` → 若把循环写成 `while i <= j` 且在里面做 `i += 1; j -= 1`，单字符时 `i` 会越过 `j` 后仍进循环 → 用 `i < j` 收口，长度 1 的串直接落到 `return 1`。

## 如果面试官追问
问：若字母表扩到 26 个小写字母，答案还是 1 或 2 吗？
答：不是，上界变成 26（按字母分组各删一次），此时需先判回文再数不同字母个数。
