## 一句话思路
用前缀和把子数组和转成两点差，按前缀和排序后二分出「不遥远」的区间，总数减去它。

## 怎么做
1. 令 `P[0]=0`，`P[t]=sum(nums[:t])`，子数组 `nums[i..j]` 的和是 `P[j+1]-P[i]`。
2. 遥远 ⇔ `|P[j+1]-P[i]-goal| >= k`，等价于 `P[j+1]-P[i] <= goal-k` 或 `>= goal+k`；先数「不遥远」即 `goal-k < P[j+1]-P[i] < goal+k`，用总数 `n*(n+1)//2` 减。
3. 把 `P` 排序得 `S`，对每个下标 `b`（代表 `j+1`）二分出 `S` 中落在 `(S[b]-(goal+k), S[b]-(goal-k))` 开区间内的元素个数，累加。
4. 但排序打乱了下标顺序，`i < j+1` 的约束丢失——所以必须按原顺序插入、用树状数组/有序容器查询，而不是整体排序后二分。

示例 1 `nums=[1,2,1], goal=4, k=1`：`P=[0,1,3,4]`，`goal-k=3`，`goal+k=5`。对 `b=3`（`P=4`），需 `4-P[i]` 落在 `(3,5)`，即 `P[i]` 在 `(-1,1)`，只有 `P[0]=0` 满足，计 1 个不遥远；总数 6 减不遥远 1 得 5。

```python
from sortedcontainers import SortedList
sl = SortedList([0])
ans = 0
pre = 0
for x in nums:
    pre += x
    lo = sl.bisect_left(pre - (goal + k) + 1)   # > pre-(goal+k)
    hi = sl.bisect_left(pre - (goal - k))       # < pre-(goal-k)
    ans += hi - lo
    sl.add(pre)
return len(nums) * (len(nums) + 1) // 2 - ans
```

## 复杂度
时间 O(n log n)：每个前缀和一次插入 + 两次二分。
空间 O(n)：`SortedList` 存 n+1 个前缀和。

## 易错点
- `k=0` 时区间 `(goal, goal)` 为空，`hi-lo` 恒为 0，答案应是全部 `n*(n+1)//2`；若把边界写成闭区间 `[goal-k, goal+k]`，会把和恰为 `goal` 的子数组误算成不遥远。
- `nums` 含负数（如示例 2 的 `-1`）时前缀和不单调，不能用双指针滑动窗口；必须用有序结构二分，否则 `lo/hi` 指针会漏解。

## 如果面试官追问
若要求返回所有遥远子数组的下标对而非计数？答：计数可减，枚举不可减，需对每个 `b` 用有序结构定位区间后逐个输出，最坏 O(n²)。
