## 一句话思路
用 dp[i] 表示以 i 结尾的最大子序列和，dp[i] = nums[i] + max(0, max(dp[i-k..i-1]))，用单调队列维护窗口最大值。

## 怎么做
1. 定义 dp[i] 为以 nums[i] 结尾的满足限制的最大子序列和。
2. 转移：dp[i] = nums[i] + max(0, max(dp[j]) for j in [i-k, i-1])，取 0 表示不接前面的。
3. 用单调递减队列维护窗口 [i-k, i-1] 内 dp 值的下标，队首即最大值。
4. 答案取所有 dp[i] 的最大值（因为子序列非空）。

以 nums = [10,2,-10,5,20], k = 2 为例：
- i=0: dp[0]=10，队列 [0]
- i=1: 窗口内 dp[0]=10，dp[1]=2+10=12，队列 [1]（dp[0]<dp[1] 弹出）
- i=2: 窗口 [0,1]，dp[0]=10,dp[1]=12，dp[2]=-10+12=2，队列 [1,2]
- i=3: 窗口 [1,2]，dp[1]=12,dp[2]=2，dp[3]=5+12=17，队列 [3]
- i=4: 窗口 [2,3]，dp[2]=2,dp[3]=17，dp[4]=20+17=37

```python
from collections import deque
dq = deque()
dp = [0] * len(nums)
ans = -2**31
for i, x in enumerate(nums):
    while dq and dq[0] < i - k:
        dq.popleft()
    best = dp[dq[0]] if dq else 0
    dp[i] = x + max(0, best)
    ans = max(ans, dp[i])
    while dq and dp[dq[-1]] <= dp[i]:
        dq.pop()
    dq.append(i)
return ans
```

## 复杂度
时间 O(n)：每个下标入队出队各一次，单调队列均摊 O(1)。
空间 O(n)：dp 数组和队列各 O(n)。

## 易错点
- 全负数输入如 [-1,-2,-3], k=1 → 若初始化 ans=0 会返回 0，但子序列必须非空 → 正确做法是 ans 初始化为 -2**31 或 nums[0]，且转移中 max(0, best) 只影响「接不接前面」，不影响 ans 取值。
- 窗口边界写成 dq[0] < i - k 而非 <= i - k → 例如 k=2, i=3 时下标 1 仍合法（3-1=2<=2），若误删会漏掉 dp[1]=12 导致 dp[3] 算成 5+2=7 而非 17。

## 如果面试官追问
要求输出具体子序列方案怎么办？答：额外记录 pre[i] 表示 dp[i] 接的前驱下标，最后从 ans 对应位置回溯即可。
