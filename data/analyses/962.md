## 一句话思路
维护一个从右往左的递减栈，栈里存的是「可能成为右端点」的下标；再用双指针从右往左扫，找最宽的合法坡。

## 怎么做
1. 从左往右扫 `nums`，把每个「比栈顶元素更小」的下标压入栈 `stack`，这样栈内下标递增、对应的值严格递减。
2. 从右往左扫 `j`，只要 `nums[stack[-1]] <= nums[j]`，就弹出栈顶并更新 `ans = max(ans, j - stack[-1])`。
3. 弹出后继续比较新的栈顶，直到栈空或栈顶值大于 `nums[j]`，然后 `j` 左移一位。
4. 返回 `ans`。

以示例 1 `[6,0,8,2,1,5]` 为例：压栈过程得到 `stack = [0,1]`（6 和 0，8/2/1 都不比 0 小）。从 `j=5` 开始，`nums[5]=5 >= nums[1]=0`，弹出 1，`ans = 5-1 = 4`；再比较栈顶 0，`nums[0]=6 > 5`，不弹，`j` 左移。最终 `ans=4`。

```python
stack = []
for i, x in enumerate(nums):
    if not stack or x < nums[stack[-1]]:
        stack.append(i)
ans = 0
for j in range(len(nums) - 1, -1, -1):
    while stack and nums[stack[-1]] <= nums[j]:
        ans = max(ans, j - stack[-1])
        stack.pop()
return ans
```

关键点：栈里只保留「左侧更小值」的下标，因为如果 `i1 < i2` 且 `nums[i1] <= nums[i2]`，那么 `i2` 作为左端点永远不如 `i1` 宽，可以直接丢弃。

## 复杂度
时间：O(n)，每个下标最多入栈一次、出栈一次，两次线性扫描。
空间：O(n)，栈最多存 n 个下标。

## 易错点
- 输入 `[9,8,1,0,1,9,4,0,4,1]`：如果只压「严格小于栈顶」而漏掉相等情况（比如 `nums[2]=1` 和 `nums[4]=1`），会漏掉 `(2,9)` 这个宽度 7 的解。正确做法是压栈条件用 `x < nums[stack[-1]]`，但出栈比较用 `<=`，保证相等值也能匹配。
- 输入 `[1,2]`：如果从右往左扫时忘记在栈空后停止，或者 `j` 没有正确左移，会死循环或漏掉 `ans=1`。正确做法是 `while stack and ...` 弹出后，无论是否弹出都要 `j -= 1` 继续下一轮。

## 如果面试官追问
问：如果要求输出具体的 `(i, j)` 而不是宽度怎么办？
答：在更新 `ans` 时同步记录当前的 `stack[-1]` 和 `j` 即可，栈弹出前保存这两个下标。
