## 一句话思路
用参数方程求两线段所在直线的交点参数 t、u，落在 [0,1] 内即相交；平行时再判共线重叠。

## 怎么做
1. 令 `d1 = end1 - start1`、`d2 = end2 - start2`，交点写成 `start1 + t*d1 = start2 + u*d2`。
2. 用叉积解出 `den = cross(d1, d2)`；`den != 0` 时 `t = cross(start2-start1, d2) / den`，`u = cross(start2-start1, d1) / den`。
3. `t`、`u` 都在 [0,1] 内则返回 `start1 + t*d1`，否则返回 `[]`。
4. `den == 0` 时判共线：`cross(start2-start1, d1) != 0` 直接无交点；否则把四个端点投影到 d1 上取重叠区间，返回重叠段里 X 最小（X 同则 Y 最小）的端点。

以示例 1 为例：`d1=(1,0)`、`d2=(-1,-2)`、`start2-start1=(1,1)`，`den = 1*(-2) - 0*(-1) = -2`，`t = cross((1,1),(-1,-2)) / -2 = (-2+1)/-2 = 0.5`，交点 `(0,0)+0.5*(1,0) = (0.5, 0)`。

```python
def cross(a, b):
    return a[0] * b[1] - a[1] * b[0]

def sub(a, b):
    return (a[0] - b[0], a[1] - b[1])

den = cross(d1, d2)
if den != 0:
    t = cross(sub(start2, start1), d2) / den
    u = cross(sub(start2, start1), d1) / den
    if 0 <= t <= 1 and 0 <= u <= 1:
        return [start1[0] + t * d1[0], start1[1] + t * d1[1]]
    return []
# den == 0：共线时按 d1 方向投影取重叠段端点
```

## 复杂度
时间 O(1)：只有常数次叉积和比较，与坐标大小无关。
空间 O(1)：只开了 d1、d2、den、t、u 几个标量。

## 易错点
- 示例 2 这种共线重叠（`d1=(3,3)`、`d2=(1,1)`，`den=0`）→ 若只判 `den==0` 就返回 `[]`，会漏掉答案 `{1,1}` → 必须再判 `cross(start2-start1, d1)==0` 确认共线，再取重叠段中 X 最小的端点。
- 端点恰好相接（如 `end1 == start2`）→ 用 `0 < t < 1` 严格不等号会判成无交点 → 边界必须写成 `0 <= t <= 1`，浮点比较可加 `1e-9` 容差。

## 如果面试官追问
问：若要求返回所有交点（重叠时返回整段）怎么办？
答：共线分支里把投影重叠区间的两个端点都算出来返回，非共线仍只返回单点。
