## 一句话思路
在 target 上做 DP，用 Trie 从每个位置向后匹配 words，取最小拼接成本。

## 怎么做
1. 把 words 建成 Trie，同一单词保留最小 cost（重复词只留便宜的）。
2. `dp[i]` 表示拼出 `target[:i]` 的最小成本，`dp[0]=0`，其余 `inf`。
3. 对每个 `i` 且 `dp[i]` 可达，从 Trie 根沿 `target[i:]` 走，每走到一个词尾就更新 `dp[j]`。
4. 返回 `dp[n]`，仍是 `inf` 则 -1。

以示例 1 为例：`target="abcdef"`。`dp[0]=0`，从 0 出发匹配到 `"abc"`（cost 1），得 `dp[3]=1`；从 3 出发匹配到 `"d"`（cost 1），得 `dp[4]=2`；从 4 出发匹配到 `"ef"`（cost 5），得 `dp[6]=7`。注意 `"abdef"` 在 target 里走不通，Trie 在 `'b'` 后遇 `'c'` 就断，不会产生转移。

```python
n = len(target)
dp = [inf] * (n + 1)
dp[0] = 0
for i in range(n):
    if dp[i] == inf:
        continue
    node = root
    for j in range(i, n):
        c = target[j]
        if c not in node.child:
            break
        node = node.child[c]
        if node.cost < inf:
            dp[j + 1] = min(dp[j + 1], dp[i] + node.cost)
return -1 if dp[n] == inf else dp[n]
```

关键点：内层循环一旦 `break` 就停，因为 Trie 前缀断了后面不可能再匹配。

## 复杂度
时间 O(n·L + 总词长)，L 为最长匹配深度，实际远小于 n。
空间 O(总词长) 存 Trie，加 O(n) 的 dp 数组。

## 易错点
- 重复单词如 `words=["ab","ab"]`、`costs=[5,2]` → 若直接按顺序插入，Trie 词尾 cost 会被后插入的 5 覆盖成 5 → 插入时对同一节点取 `min`。
- `target="aaaa"`、`words=["a","aa"]` → 若内层循环不 `break` 或从错误位置续走，会漏掉 `dp[1]→dp[2]` 这条更便宜路径 → 必须对每个可达 `i` 都从根重新走，不能复用上一位置的节点。

## 如果面试官追问
问：若 words 总长到 5×10^5 且 target 也 5×10^5，Trie 还够吗？
答：够，但可换 Aho-Corasick 一次扫描出所有匹配终点，把 O(n·L) 降到 O(n + 总词长)。
