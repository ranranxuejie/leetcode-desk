## 一句话思路
从右往左扫，维护右侧已抬升后的最小值 `cur`，遇到 `nums[i] > cur` 就把 `nums[i] - cur` 计入答案并令 `cur = nums[i]`。

## 怎么做
1. 令 `cur = nums[-1]`、`ans = 0`，从 `n-2` 倒序扫到 `0`。
2. 若 `nums[i] <= cur`，说明它已满足非递减，直接令 `cur = nums[i]`。
3. 若 `nums[i] > cur`，必须把 `nums[i]` 右侧整段抬高 `nums[i] - cur`，累加进 `ans`，并令 `cur = nums[i]`（抬升后右侧最小值变成 `nums[i]`）。
4. 返回 `ans`。

以 `nums = [5,1,2,3]` 为例：`cur` 初值 3；`i=2` 时 `2 <= 3`，`cur = 2`；`i=1` 时 `1 <= 2`，`cur = 1`；`i=0` 时 `5 > 1`，`ans += 5 - 1 = 4`，`cur = 5`。答案 4，与示例一致。

```python
cur = nums[-1]
ans = 0
for i in range(len(nums) - 2, -1, -1):
    if nums[i] > cur:
        ans += nums[i] - cur
        cur = nums[i]
    else:
        cur = nums[i]
return ans
```

关键点：`cur` 存的是「右侧经过抬升后能达到的最小值」，不是原始 `nums[i+1]`。示例 1 中 `[3,3,2,1]`：`cur` 从 1 起，`i=2` 时 `2 > 1`，`ans += 1`，`cur = 2`；`i=1` 时 `3 > 2`，`ans += 1`，`cur = 3`；`i=0` 时 `3 <= 3`，`cur = 3`，答案 2。

## 复杂度
时间：O(n)，倒序单趟扫描，每个下标只访问一次。
空间：O(1)，只开 `cur` 和 `ans` 两个变量。

## 易错点
- 输入 `[3,3,2,1]`：若只比较相邻原始值、把 `nums[i] > nums[i+1]` 的差值累加，会得到 `(3-2)+(2-1)=2` 看似对，但换成 `[5,1,2,3]` 就只算 `5-1=4` 而漏掉后续联动；正确做法是维护抬升后的 `cur` 而非原始 `nums[i+1]`。
- 输入 `[1,2,3]` 已非递减：若忘记 `else` 分支更新 `cur`，`cur` 会停在 `nums[-1]=3`，后续比较全用错基准；正确做法是无论是否抬升都令 `cur = nums[i]`。

## 如果面试官追问
问：若要求输出具体操作方案（哪些子数组、各加多少）？
答：倒序扫描时每遇 `nums[i] > cur` 就记录一次 `(i+1, n-1, nums[i]-cur)`，这些区间抬升量按从右到左叠加即为一组合法方案。
