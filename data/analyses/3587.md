## 一句话思路
分别假设偶数占偶数下标、奇数占偶数下标，用贪心把同类元素按出现顺序一一配对，取两种方案交换次数较小者。

## 怎么做
1. 统计偶数个数 `even`，若 `abs(even - (n - even)) > 1` 直接返回 -1。
2. 收集所有偶数的下标到列表 `pos`，第 k 个偶数最终要落在目标位置 `2*k`（偶数占偶数位时），累加 `abs(pos[k] - 2*k)`。
3. 奇数占偶数位时，偶数目标位置变成 `2*k + 1`，同样累加。
4. 若 `n` 为奇数，只有数量多的那一类能占偶数位，只算那一种；否则取两种的较小值。

以 `nums = [2,4,6,5,7]` 为例：偶数下标 `pos = [0,1,2]`，偶数占偶数位时目标 `[0,2,4]`，代价 `0+1+2 = 3`；奇数占偶数位时目标 `[1,3,5]`，代价 `1+2+3 = 6`。`n=5` 为奇数且偶数 3 个更多，取 3。

```python
even = sum(1 for x in nums if x % 2 == 0)
n = len(nums)
if abs(even - (n - even)) > 1:
    return -1
pos = [i for i, x in enumerate(nums) if x % 2 == 0]
def cost(start):
    return sum(abs(p - (start + 2 * k)) for k, p in enumerate(pos))
if n % 2 == 1:
    return cost(0) if even > n - even else cost(1)
return min(cost(0), cost(1))
```

## 复杂度
时间：O(n)，一次遍历统计偶数个数、一次收集下标、一次求和，各为线性。
空间：O(n)，`pos` 列表最多存 n/2 个下标。

## 易错点
- `nums = [4,5,6,8]` 偶数 3 个、奇数 1 个，差为 2 → 若漏掉 `abs(...) > 1` 的判断，会硬算出一个代价而不是返回 -1。
- `nums = [1,2,3]` 偶数 1 个、奇数 2 个，n 为奇数时若仍取 `min(cost(0), cost(1))`，会把偶数硬塞到下标 1 的位置算出错误的小值；正确做法是只让数量多的奇数占偶数位，即只算 `cost(1)`。

## 如果面试官追问
若要求输出具体交换方案而非次数？答：按配对关系从右往左做相邻交换，每次把目标元素冒泡到目标位置，记录每步交换的下标对即可。
