## 一句话思路
把同值格子用并查集合并成组，按值升序处理，组内取同行同列已确定排名的最大值 +1。

## 怎么做
1. 把每个格子编号 `r*n+c`，同值格子按行、按列合并（同一行同值、同一列同值都要 union）。
2. 按值升序分组，每组是若干并查集根，逐个处理。
3. 对组内每个根，收集它所有格子的行、列上已算出的 `answer` 最大值，取 `max+1` 作为整组排名。
4. 组内所有格子写同一个排名，再更新行、列的最大值。

以 `[[1,2],[3,4]]` 为例：值 1 的组只有 `(0,0)`，行 0 列 0 都空，排名 1；值 2 的组含 `(0,1)` 和 `(1,0)`，前者看行 0 得 1、列 1 空，后者看列 0 得 1、行 1 空，整组排名 2；值 4 看行 1 得 2、列 1 得 2，排名 3。

```python
parent = list(range(m * n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
# 同值同行/同列合并
for i in range(m):
    for j in range(n):
        for k in range(j + 1, n):
            if matrix[i][j] == matrix[i][k]:
                parent[find(i*n+j)] = find(i*n+k)
# 按值分组后逐组处理
row_max, col_max = [0]*m, [0]*n
for v in sorted(groups):
    roots = {find(x) for x in groups[v]}
    for rt in roots:
        r = max(row_max[i] for i, j in cells[rt])
        c = max(col_max[j] for i, j in cells[rt])
        rank = max(r, c) + 1
        for i, j in cells[rt]:
            answer[i][j] = rank
    for rt in roots:
        for i, j in cells[rt]:
            row_max[i] = max(row_max[i], answer[i][j])
            col_max[j] = max(col_max[j], answer[i][j])
```

## 复杂度
时间 O(mn log(mn))，排序贡献 log，并查集近似 O(mn α)。
空间 O(mn)，parent、分组表、answer 各一份。

## 易错点
- 同值格子必须同排名：`[[7,7],[7,7]]` 若逐格算会得 `[[1,2],[2,3]]`，正确是 `[[1,1],[1,1]]`，所以先并查集合并再整组赋同一个 rank。
- 组内排名要取所有格子行列最大值的 max 再 +1，不能只看第一个格子：示例 3 中值 4 出现在 `(1,1)` 和 `(3,1)`，若只按 `(1,1)` 的行列算会漏掉第 3 行的约束，导致排名偏小。

## 如果面试官追问
若 m、n 放大到 10^5 且矩阵稀疏，怎么改？答：只对出现的格子建行、列节点，用哈希表存非零项，按值排序后仍按组处理，空间降到 O(非零数)。
