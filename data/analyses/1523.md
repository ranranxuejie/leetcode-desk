## 一句话思路
用前缀计数 `f(x) = x//2 + x%2`（即 0..x 中奇数个数），答案就是 `f(high) - f(low-1)`。

## 怎么做
1. 定义 `f(x)` 为 `[0, x]` 内奇数个数，`x < 0` 时返回 0。
2. 观察 `0..x` 共 `x+1` 个数，奇数比偶数多一个当且仅当 `x` 为偶数，故 `f(x) = (x+1)//2`。
3. 区间 `[low, high]` 的奇数个数 = `f(high) - f(low-1)`。
4. 直接返回差值，无需循环。

以示例 1 `low = 3, high = 7` 为例：`f(7) = (7+1)//2 = 4`（0..7 的奇数是 1,3,5,7），`f(2) = (2+1)//2 = 1`（只有 1），差值 `4 - 1 = 3`，与 `[3,5,7]` 一致。

```python
def countOdds(low, high):
    def f(x):
        if x < 0:
            return 0
        return (x + 1) // 2
    return f(high) - f(low - 1)
```

等价写法：`(high + 1) // 2 - low // 2`。验证示例 2：`low=8, high=10`，`(10+1)//2 - 8//2 = 5 - 4 = 1`，正确。

## 复杂度
时间：O(1)，只做两次整除和一次减法，与 `high - low` 无关。
空间：O(1)，只用了几个整数变量，没有开数组。

## 易错点
- `low = 0` 时若直接算 `f(low-1) = f(-1)`，用 `(-1+1)//2 = 0` 恰好也对，但若写成 `(x+1)//2` 而不特判 `x < 0`，遇到 `low = 0` 之外的负数场景（如手算验证时传 -1）会得到 0 而非报错，容易掩盖逻辑错误；正确做法是显式 `if x < 0: return 0`。
- 用 `(high - low) // 2` 估算会漏掉端点：`low=3, high=7` 得 `4//2 = 2`，但正确答案是 3，因为两端都是奇数；正确做法是必须用前缀差 `f(high) - f(low-1)`，不能只数「中间隔了几个」。

## 如果面试官追问
问：若 `high` 可达 `10**18` 且要求对 `10**9+7` 取模输出？
答：公式不变，`(high+1)//2 - low//2` 在 Python 大整数下直接算完再取模即可，无需特殊处理。
