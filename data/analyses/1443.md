## 一句话思路
自底向上 DFS：每个子树返回「该子树内是否有苹果」，有苹果就把连向父节点的这条边算两次（下去+回来）。

## 怎么做
1. 用 `edges` 建邻接表 `g`，从 0 出发 DFS，传入 `parent` 防止回头。
2. 对每个子节点递归，若子节点自身 `hasApple[v]` 为真或子树返回真，则 `ans += 2`。
3. 返回 `hasApple[u] or 任一子树为真`，供父节点判断这条边要不要走。

以示例 1 为例：节点 4、5 有苹果，DFS 到 4 时 `hasApple[4]=True`，回到 1 时 `ans += 2`；节点 5 同理 `ans += 2`；节点 1 自身无苹果但子树有，返回 `True`，回到 0 时 `ans += 2`；右侧节点 2 有苹果、3 无，节点 2 返回 `True`，`ans += 2`，累计 8。节点 3、6 无苹果且无子树苹果，不贡献边。

```python
def dfs(u, p):
    found = hasApple[u]
    for v in g[u]:
        if v != p and dfs(v, u):
            ans[0] += 2
            found = True
    return found
```

`ans` 用列表或 `nonlocal` 累加；最终返回 `ans[0]`。若根节点 0 无苹果且所有子树都返回 `False`，`ans` 保持 0，对应示例 3。

## 复杂度
时间 O(n)：每条边在 DFS 中被访问两次（正反各一次），n 个节点各入栈一次。
空间 O(n)：邻接表存 2(n-1) 条边，递归栈最深 n 层。

## 易错点
- 只判断 `hasApple[u]` 而不看子树：示例 1 中节点 1 自身 `hasApple[1]=False`，若只看自身会漏掉通往 4、5 的两条边，答案错成 4 而非 8。正确做法是 `found = hasApple[u] or 子树返回真`。
- 忘记传 `parent` 或没判 `v != p`：无向树建的是双向边，从 0 进入 1 后若不排除父节点会立刻回到 0，无限递归或重复计数。正确做法是 DFS 时传 `p`，遍历时跳过 `v == p`。

## 如果面试官追问
若要求输出具体路径而非只返回秒数？答：DFS 时把「子树有苹果」的边按 `(u, v)` 顺序压入列表，最后从 0 出发按列表顺序走并回溯即可还原。
