## 一句话思路
用 `dp[i]` 表示后缀 `s[i:]` 的最大删除数，从后往前推，靠 LCP 表 O(1) 判断前 i 个与后 i 个是否相等。

## 怎么做
1. 预处理 `lcp[i][j]` = `s[i:]` 与 `s[j:]` 的最长公共前缀长度，倒序递推：`s[i]==s[j]` 时 `lcp[i][j] = lcp[i+1][j+1] + 1`。
2. 定义 `dp[i]` 为删完 `s[i:]` 的最大操作数，`dp[n] = 0`，从 `i = n-1` 倒推到 0。
3. 对每个 `i`，枚举 `k`（1 ≤ k ≤ (n-i)//2），若 `lcp[i][i+k] >= k` 则 `dp[i] = max(dp[i], dp[i+k] + 1)`。
4. 兜底：`dp[i]` 至少为 1（整段一次删掉）。

以 `s = "aaabaab"`（n=7）为例，`i=4` 时后缀是 `"aab"`，`k=1` 检查 `lcp[4][5]`：`s[4]='a'`、`s[5]='a'`，`lcp[4][5]=lcp[5][6]+1=1+1=2 ≥ 1`，于是 `dp[4] = dp[5]+1`；继续试 `k=...` 直到 `(7-4)//2=1` 封顶。最终 `dp[0]=4`。

```python
n = len(s)
lcp = [[0] * (n + 1) for _ in range(n + 1)]
for i in range(n - 1, -1, -1):
    for j in range(n - 1, -1, -1):
        if s[i] == s[j]:
            lcp[i][j] = lcp[i + 1][j + 1] + 1
dp = [0] * (n + 1)
for i in range(n - 1, -1, -1):
    dp[i] = 1
    for k in range(1, (n - i) // 2 + 1):
        if lcp[i][i + k] >= k:
            dp[i] = max(dp[i], dp[i + k] + 1)
return dp[0]
```

## 复杂度
时间 O(n²)：LCP 表 n² 格，DP 枚举 k 总计约 n²/4。
空间 O(n²)：`lcp` 是 (n+1)×(n+1) 的二维表，`dp` 只占 O(n)。

## 易错点
- `s = "aaaaa"` → 若只枚举「能删的最大 k」会漏掉 k=1 的逐步删除，得到 2 而非 5 → 必须对每个 i 枚举所有合法 k 取 max，不能贪心取最大块。
- `s = "abcabcdabc"` → 若用 `s[i:i+k] == s[i+k:i+2k]` 切片比较，n=4000 时每对比较 O(k)，总复杂度退化到 O(n³) 超时 → 必须用 `lcp[i][i+k] >= k` 做 O(1) 判定。

## 如果面试官追问
问：n 放大到 10⁵ 怎么办？答：LCP 表存不下，改用滚动哈希 + 二分求 LCP，或 Z 函数逐位置算，空间降到 O(n)。
