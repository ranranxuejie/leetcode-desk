## 一句话思路
用双指针扫连续相同字符，边扫边拼 `字符+次数`，最后比长度决定返回哪个。

## 怎么做
1. 空串直接返回 `""`，否则从 `i=0` 开始，用 `j` 往后探到第一个不等于 `S[i]` 的位置。
2. 每段把 `S[i]` 和 `str(j-i)` 追加到结果列表，再令 `i=j`。
3. 扫完后比较 `len("".join(res))` 与 `len(S)`，短则返回压缩串，否则返回原串。

以 `"aabcccccaaa"` 为例：`i=0` 时 `j` 停在 2，追加 `"a2"`；`i=2` 时 `j` 停在 3，追加 `"b1"`；`i=3` 时 `j` 一路推到 8，追加 `"c5"`。此时 `res` 为 `["a2","b1","c5"]`，继续得 `"a3"`，拼成 `"a2b1c5a3"`，长度 10 小于 11，返回它。

```python
res = []
i, n = 0, len(S)
while i < n:
    j = i
    while j < n and S[j] == S[i]:
        j += 1
    res.append(S[i] + str(j - i))
    i = j
compressed = "".join(res)
return compressed if len(compressed) < n else S
```

关键在 `j - i` 就是这一段的重复次数，不需要额外计数器；`i = j` 保证每段只处理一次。

## 复杂度
时间 O(n)：`i` 和 `j` 都只前进不后退，每个字符被访问常数次。
空间 O(n)：`res` 列表最多存 n 个片段，`join` 再开一份压缩串。

## 易错点
- 输入 `"abbccd"` → 若忘记最后比较长度，会返回 `"a1b2c2d1"`（长 8 > 6）→ 正确做法是拼完 `compressed` 后必须判断 `len(compressed) < n`，否则返回原串 `S`。
- 输入 `""` 或 `"a"` → 若循环条件写成 `while i < n - 1` 或先取 `S[0]`，空串会下标越界、单字符会漏掉 `"a1"` → 正确做法是 `while i < n`，空串时循环体不执行，`compressed` 为 `""`，长度 0 不小于 0，返回原串 `""`。

## 如果面试官追问
追问：长度上限提到 10**7 怎么办？答：仍用双指针流式扫描，但把结果写进 `list` 分块拼接，避免 `+=` 字符串造成 O(n²)。
