## 一句话思路
按字符分组统计每段连续相同字符的长度，对每个字符用「最长、次长、第三长」三段长度直接算出答案，无需二分。

## 怎么做
1. 一次遍历把 s 切成若干极大连续段，记录每段的字符 c 和长度 L，把 L 追加到 `groups[c]` 里。
2. 对每个字符的长度列表降序取前三个 `a >= b >= c`（不足补 0）。
3. 该字符能贡献的最长长度是 `max(a - 2, min(a - 1, b), c)`，对所有字符取最大。
4. 全程最大值为 0 时返回 -1。

以 `s = "aaaa"` 为例：只有一段，`groups['a'] = [4]`，补零后 `a=4, b=0, c=0`，候选为 `max(2, 0, 0) = 2`，与示例一致。

三个候选的来源：同一段内取长度 k 的子串有 `a-k+1` 个，要 ≥3 需 `k <= a-2`；跨两段时两段各出一次，需 `k <= a-1` 且 `k <= b`，即 `min(a-1, b)`；跨三段时只能取 `c`。

```python
from collections import defaultdict

groups = defaultdict(list)
i = 0
while i < len(s):
    j = i
    while j < len(s) and s[j] == s[i]:
        j += 1
    groups[s[i]].append(j - i)
    i = j

ans = 0
for lens in groups.values():
    lens.sort(reverse=True)
    a, b, c = (lens + [0, 0, 0])[:3]
    ans = max(ans, a - 2, min(a - 1, b), c)
return ans if ans > 0 else -1
```

## 复杂度
时间 O(n + 26·k log k)，n 是 s 长度，k 是单字符段数，排序总代价不超过 O(n log n)。
空间 O(n)，`groups` 存下所有段长，字符表只有 26 个键。

## 易错点
- 输入 `s = "aaabbb"`：只盯最长段 `a=3` 会算出 `a-2=1`，漏掉跨段组合；正确做法是三个候选都算，这里 `min(3-1,3)=2` 才是答案。
- 输入 `s = "aaaaa"`：把 `a-2` 写成 `a-1` 会得 4，但长度 4 的 "aaaa" 只出现 2 次；正确做法是段内候选必须减 2，因为起点有 `a-k+1` 个。
- 输入 `s = "abcaba"`：每段长度都是 1，`a-2 = -1`，若不与 0 取 max 会得到负数；正确做法是候选和 0 比较，最后统一判 0 返回 -1。

## 如果面试官追问
问：若要求出现至少 k 次而非 3 次？答：段内候选变 `a-k+1`，跨段取前 k 大长度中第 i 大的 `min(a-i+1, lens[i-1])`，仍 O(n log n)。
