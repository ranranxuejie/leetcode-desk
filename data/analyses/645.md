## 一句话思路
用「下标标记法」把 nums 里的值当索引取负，最后仍为正的下标即丢失值，已为负的重复值即重复数。

## 怎么做
1. 遍历 nums，对每个值 v 取下标 `i = abs(v) - 1`，若 `nums[i] > 0` 则取负。
2. 再遍历一遍下标 0..n-1，`nums[i] > 0` 说明值 `i+1` 从未出现过，即丢失数。
3. 重复数在第一步就能抓到：若 `nums[i] < 0` 说明已被标记过，`abs(v)` 就是重复数。

以 `nums = [1,2,2,4]` 为例：v=1 标记 `nums[0]=-1`；v=2 标记 `nums[1]=-2`；v=2 时 `nums[1]` 已为负，抓到重复数 2；v=4 标记 `nums[3]=-4`。第二遍扫描 `nums[2]=2>0`，丢失数 = 2+1 = 3，返回 `[2,3]`。

```python
dup = -1
for v in nums:
    i = abs(v) - 1
    if nums[i] < 0:
        dup = abs(v)
    else:
        nums[i] = -nums[i]
miss = -1
for i, v in enumerate(nums):
    if v > 0:
        miss = i + 1
        break
return [dup, miss]
```

注意 `nums[i] = -nums[i]` 而不是 `nums[i] = -v`：v 可能本身已被前一步取负，直接取负会翻回正数，标记失效。

## 复杂度
时间 O(n)：两遍线性扫描，n 为 nums 长度。
空间 O(1)：只用了 dup、miss 两个变量，原地改 nums。

## 易错点
- 输入 `[1,1]`：若写成 `nums[i] = -v`，v=1 时 `nums[0]` 被置 -1，第二遍扫描 `nums[1]=1>0` 判丢失为 2，看似对；但换成 `[2,2]` 就会把 `nums[1]` 反复翻正，重复数抓不到。正确做法是 `nums[i] = -nums[i]`，用当前值判断符号而非用 v。
- 输入 `[3,3,1]`：v=3 时 `i=2`，`nums[2]=1>0` 标记为 -1；v=3 时 `nums[2]=-1<0` 抓到重复 3；v=1 时 `i=0`，`nums[0]=3>0` 标记 -3。第二遍 `nums[1]=3>0`，丢失 = 2。若第一步用 `abs(v)-1` 却忘了 v 可能为负（前一轮已改），下标会错位。

## 如果面试官追问
问：不允许修改原数组怎么办？
答：用异或：`1..n` 与 nums 全体异或得 `dup ^ miss`，再按最低置位位分组异或，O(1) 空间且不改数组。
