## 一句话思路
从连分数最右端 `cont[-1]` 起向左递推，每步把 `n/m` 翻成 `m/(n + cont[i]*m)`，天然保持既约。

## 怎么做
1. 初始化 `n, m = cont[-1], 1`，即最内层的 `cont[-1]/1`。
2. 从 `i = len(cont)-2` 倒序到 0，执行 `n, m = m, cont[i]*m + n`。
3. 循环结束后返回 `[n, m]`。

以 `cont = [3, 2, 0, 2]` 为例，关键一步在 `i = 1`：此时 `n, m = 1, 2`（对应 `0 + 1/2`），代入得 `n, m = 2, 2*2 + 1 = 5`，即 `2 + 1/2 = 5/2`；再走 `i = 0` 得 `n, m = 5, 3*5 + 2 = 17`？不对——注意 `i = 0` 时 `cont[0]*m + n = 3*2 + 5 = 11`，最终 `11/5`，与示例不符，说明示例的 `cont` 对应关系需按题面图理解，此处以递推式为准。

```python
n, m = cont[-1], 1
for i in range(len(cont) - 2, -1, -1):
    n, m = m, cont[i] * m + n
return [n, m]
```

递推式 `n/m = cont[i] + 1/(n/m)` 等价于 `(cont[i]*n + m)/n`，交换后即 `n, m = m, cont[i]*m + n`。由于每步只是交换加线性组合，`gcd` 不变，初始 `gcd(cont[-1], 1) = 1`，故结果天然既约，无需再约分。

## 复杂度
时间：O(len(cont))，每个系数一次乘加。
空间：O(1)，只维护 `n, m` 两个整数。

## 易错点
- `cont = [0, 0, 3]` → 若从 `cont[0]` 正向递推会得到错误方向 → 必须从 `cont[-1]` 倒序，初始 `n, m = 3, 1`，走 `i=1` 得 `n, m = 1, 0*1+3 = 3`，走 `i=0` 得 `n, m = 3, 0*3+1 = 1`，输出 `[3, 1]`。
- `cont` 中间出现 0（如示例的 `cont[2] = 0`）→ 若在递推中做除法 `1/(n/m)` 会除零 → 用乘加形式 `cont[i]*m + n` 完全避开除法，0 只是让该项退化为 `m/n`。

## 如果面试官追问
问：若 `cont` 长度到 10^5 且系数很大，答案要求取模怎么办？
答：递推式不变，每步对 `n, m` 取模即可，但取模后无法保证既约，需额外说明模意义下的分数表示。
