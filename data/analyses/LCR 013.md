## 一句话思路
用二维前缀和 `pre[i][j]` 表示左上角 (0,0) 到 (i-1,j-1) 的矩形和，任意子矩阵用四个前缀和容斥 O(1) 求出。

## 怎么做
1. 建 `(m+1) x (n+1)` 的 `pre`，多出的一行一列全 0，省掉边界判断。
2. 递推 `pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + matrix[i-1][j-1]`。
3. 查询时把 `row1,col1,row2,col2` 各加 1 转成 `pre` 下标，套容斥公式。

用官方示例验证：`sumRegion(2,1,4,3)` 转成 `pre` 下标后是 `(3,2)` 到 `(5,4)`。此时 `pre[5][4]=?`，`pre[2][4]` 是前两行整行和，`pre[5][1]` 是前四列左边界和，`pre[2][1]` 是被减两次的左上角，公式 `pre[5][4] - pre[2][4] - pre[5][1] + pre[2][1] = 8`，与输出一致。

```python
m, n = len(matrix), len(matrix[0])
pre = [[0] * (n + 1) for _ in range(m + 1)]
for i in range(1, m + 1):
    for j in range(1, n + 1):
        pre[i][j] = (pre[i-1][j] + pre[i][j-1]
                     - pre[i-1][j-1] + matrix[i-1][j-1])

def sumRegion(row1, col1, row2, col2):
    r1, c1, r2, c2 = row1 + 1, col1 + 1, row2 + 1, col2 + 1
    return pre[r2][c2] - pre[r1-1][c2] - pre[r2][c1-1] + pre[r1-1][c1-1]
```

## 复杂度
时间：初始化 O(m·n)，每次 `sumRegion` O(1)，共 q 次查询即 O(m·n + q)。
空间：`pre` 额外开 (m+1)(n+1) 个整数，O(m·n)。

## 易错点
1. 查询下标忘记 +1 → 用 `(2,1,4,3)` 直接当 `pre` 下标会取到 `pre[2][1]` 到 `pre[4][3]`，把第 0 行第 0 列也卷进来，结果偏大；正确做法是四个下标统一 +1 再套容斥。
2. 容斥符号写错 → 写成 `pre[r2][c2] - pre[r1-1][c2] - pre[r2][c1-1] - pre[r1-1][c1-1]` 会把左上角减两次，`(2,1,4,3)` 得 8 变成 4 附近的值；正确是最后一项 `+ pre[r1-1][c1-1]`。

## 如果面试官追问
问：若矩阵元素会动态修改怎么办？
答：改用二维树状数组或线段树，单点更新 O(log m·log n)，查询同样 O(log m·log n)。
