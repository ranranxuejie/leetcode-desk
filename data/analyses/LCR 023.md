## 一句话思路
双指针各走完自己再走对方的链，两轮后必在交点相遇或同时到 `None`，因为两边总路程都是 m+n。

## 怎么做
1. 令 `pa = headA`、`pb = headB`，各自同步前进。
2. 走到 `None` 就跳到另一条链的头（`pa` 跳 `headB`，`pb` 跳 `headA`）。
3. 循环条件写 `while pa is not pb`，退出时 `pa` 就是交点或 `None`。

拿示例 1 走一遍：A 长 5、B 长 6，`pa` 走 5 步到 `None` 后跳 `headB`，`pb` 走 6 步到 `None` 后跳 `headA`。第二轮里 `pa` 从 B 头走 3 步、`pb` 从 A 头走 2 步，两者同时落在值为 8 的节点上——因为 `pa` 总路程 5+3=8，`pb` 总路程 6+2=8，交点前的长度差被补齐了。

```python
pa, pb = headA, headB
while pa is not pb:
    pa = pa.next if pa else headB
    pb = pb.next if pb else headA
return pa
```

不相交时（示例 3），A 长 3、B 长 2，两边都走 3+2=5 步后同时变成 `None`，`None is None` 成立，返回 `None`，不会死循环。

## 复杂度
时间 O(m+n)：每个指针最多走 m+n 步。
空间 O(1)：只开了 `pa`、`pb` 两个引用。

## 易错点
- 循环条件写成 `while pa and pb` 或 `while pa != pb` 配 `val` 比较 → 示例 2 里 A 的 `1` 和 B 的 `1` 值相同但节点不同，会误判成交点。必须比节点身份 `is`，不是比 `val`。
- 跳链写成 `pa = pa.next if pa.next else headB` → 示例 3 中 `pa` 走到最后一个节点时 `pa.next` 是 `None`，判断为假直接跳 `headB`，漏走了尾节点本身，两边步数不再相等，可能永远错开。正确写法是先判 `pa` 本身是否为 `None`。

## 如果面试官追问
问：不允许改链表，但允许 O(m) 额外空间，怎么做？
答：先遍历 A 把所有节点 id 塞进 `set`，再遍历 B 找第一个命中的节点，时间仍是 O(m+n)。
