## 一句话思路
用前缀异或把「块异或等于 target」转成「两个前缀异或值之差等于 target」，再用两个哈希表按奇偶层累加方案数。

## 怎么做
1. 令 `pre[i] = nums[0]^...^nums[i-1]`，块 `(j, i]` 的异或就是 `pre[i] ^ pre[j]`。
2. 维护 `cnt1[x]`：以 target1 结尾的合法分割中，前缀异或值为 `x` 的方案数；`cnt2` 同理对应 target2。
3. 扫到位置 `i` 时，若 `pre[i] ^ target1` 在 `cnt2` 里，说明上一块以 target2 结尾、本块凑出 target1，把这些方案数加到 `cnt1[pre[i]]`；对称地查 `cnt1` 更新 `cnt2`。
4. 初始化 `cnt1[0] = 1`（空前缀视为「上一块是 target2 的收尾」），答案取 `cnt1[pre[n]]`。

以示例 2 `nums=[1,0,0], target1=1, target2=0` 为例：`pre = [0,1,1,1]`。`i=1` 时 `pre=1`，`1^1=0` 在 `cnt1` 中（值 1），故 `cnt2[1] += 1`；`i=2` 时 `1^0=1` 在 `cnt1` 中，`cnt2[1] += 1` 变 2；`i=3` 同理 `cnt2[1] = 3`。最终 `cnt1[1]` 由 `cnt2[1]` 三次贡献得 3。

```python
MOD = 10**9 + 7
cnt1, cnt2 = {0: 1}, {}
pre = 0
for v in nums:
    pre ^= v
    a = cnt2.get(pre ^ target1, 0)
    b = cnt1.get(pre ^ target2, 0)
    if a: cnt1[pre] = (cnt1.get(pre, 0) + a) % MOD
    if b: cnt2[pre] = (cnt2.get(pre, 0) + b) % MOD
ans = cnt1.get(pre, 0)
```

## 复杂度
时间 O(n)：一次遍历，每个元素做两次哈希查询。
空间 O(n)：`cnt1`、`cnt2` 最多各存 n 个不同前缀异或值。

## 易错点
- 忘记 `cnt1[0] = 1` 这个哨兵：示例 3 之外，像 `nums=[1], target1=1` 这种单块就合法的输入会返回 0，正确做法是把空前缀当作「已收尾 target2」的起点。
- 先更新 `cnt1` 再查 `cnt2`（或反之）会串味：示例 2 中 `i=1` 若先写 `cnt1[1]`，同一位置又用它去更新 `cnt2`，会把「同一块既当 target1 又当 target2」算进去，正确做法是先算 `a`、`b` 两个查询值，再统一写入。

## 如果面试官追问
要求输出所有方案而非计数怎么办？答：把哈希表的值从计数改成方案列表（存切分点下标），回溯拼接，复杂度升到 O(方案数 × n)。
