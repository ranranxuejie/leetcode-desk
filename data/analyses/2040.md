## 一句话思路
对答案值二分，用「≤ mid 的乘积个数」做单调判定，计数时按 nums1 元素正负分三段双指针。

## 怎么做
1. 二分区间取 `lo, hi = -10**10, 10**10`（乘积极值 ±1e5×1e5），循环 `while lo < hi` 取 `mid = (lo + hi) // 2`。
2. 写 `count(mid)`：统计 `nums1[i] * nums2[j] <= mid` 的对数，按 nums1[i] 的符号分三段处理。
3. 若 `count(mid) >= k` 则 `hi = mid`，否则 `lo = mid + 1`，最后返回 `lo`。

关键在 `count` 的三段。以示例 3 的 `nums1 = [-2,-1,0,1,2]`、`nums2 = [-3,-1,2,4,5]`、`mid = -6` 为例：负数段 i=0（-2）时，`-2 * nums2[j] <= -6` 即 `nums2[j] >= 3`，nums2 中满足的是 4、5 两个，贡献 2；i=1（-1）时需 `nums2[j] >= 6`，无解，贡献 0；零段 i=2 贡献 0（0 ≤ -6 不成立）；正数段 i=3、4 全不满足。合计 `count(-6) = 2 < 3`，所以答案 > -6，最终收敛到 -6 的下一格即 -6 本身（因为 -6 处 count 恰为 2，k=3 落在 -6 之后第一个真实值上，实际收敛结果为 -6，说明 -6 处计数需含等号边界，验证时以 `count(-6)=2`、`count(-5)≥3` 为准）。

```python
def count(mid):
    total = 0
    for x in nums1:
        if x < 0:
            # 需要 nums2[j] >= ceil(mid / x)，用整除向上取整
            need = -((-mid) // x) if mid % x else mid // x
            total += len(nums2) - bisect_left(nums2, need)
        elif x == 0:
            if mid >= 0:
                total += len(nums2)
        else:
            total += bisect_right(nums2, mid // x)
    return total
```

## 复杂度
时间 O((n + m) log(值域))，n、m 为两数组长度，log 来自二分约 35 轮。
空间 O(1)，只用了几个计数变量。

## 易错点
- 负数段用 `mid // x` 直接整除：Python 向下取整，`-7 // -2 = 3` 但实际需要 `nums2[j] >= 3.5` 即 ≥4，会多算一对 → 必须对负数用向上取整 `-((-mid) // x)` 或先转正再算。
- `x == 0` 时若 `mid < 0` 仍去加 `len(nums2)`：0 乘任何数都是 0，`0 <= -6` 为假，会凭空多出 m 对 → 必须加 `if mid >= 0` 判断。

## 如果面试官追问
问：若要求返回第 k 小的乘积本身而非值，且存在重复？
答：二分收敛到的 `lo` 就是该值，重复不影响，因为 `count` 用 `<=` 统计的是「≤ 该值的对数」。
