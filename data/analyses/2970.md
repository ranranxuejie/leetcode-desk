## 一句话思路
先找最长递增前缀 `i` 和最长递增后缀 `j`，再对每个左端点二分右端点，用双指针 O(n) 统计。

## 怎么做
1. 从 0 开始找最长严格递增前缀的末尾下标 `i`（`nums[i] < nums[i+1]` 才前进）；若整个数组递增，直接返回 `n*(n+1)//2`。
2. 从 `n-1` 开始找最长严格递增后缀的起点下标 `j`（`nums[j-1] < nums[j]` 才后退）。
3. 枚举左端点 `l` 从 `0` 到 `i+1`，对每个 `l` 找最小的 `r` 使 `nums[l-1] < nums[r]`（`l=0` 时无左约束），则 `r` 从该位置到 `n-1` 都合法，累加 `n - r`。
4. 因为 `nums[0..i]` 递增、`nums[j..n-1]` 递增，`r` 随 `l` 增大单调不减，用指针 `r` 从 `j` 起只前进不回退。

以 `nums = [6,5,7,8]` 为例：`i=0`（6>5 停），`j=2`（7<8 但 5<7 不成立，从后往前 8,7 递增，到 5 停）。枚举 `l=0`：无左约束，`r=2`，贡献 `4-2=2`（移除 `[6,5]`、`[6,5,7]`… 实际是 `[6,5]` 和 `[6,5,7]` 对应 r=2,3 之外还有 `[6,5,7,8]`，即 `n-r` 从 2 起算得 2）。`l=1`：需 `nums[0]=6 < nums[r]`，`r` 移到 2（`nums[2]=7>6`），贡献 `4-2=2`。合计 7，与示例一致。

```python
n = len(nums)
i = 0
while i + 1 < n and nums[i] < nums[i+1]:
    i += 1
if i == n - 1:
    return n * (n + 1) // 2
j = n - 1
while j - 1 >= 0 and nums[j-1] < nums[j]:
    j -= 1
ans, r = 0, j
for l in range(i + 2):
    while r < n and (l == 0 or nums[l-1] < nums[r]):
        r += 1
    ans += n - r + 1
return ans
```

## 复杂度
时间 O(n)：`i`、`j` 各扫一遍，`r` 指针单调前进最多 n 步。
空间 O(1)：只用了 `i`、`j`、`r`、`ans` 四个整型变量。

## 易错点
- 输入 `[1,2,3,4]` 全递增时，若仍走双指针会漏算「移除任意子数组」的 `n*(n+1)//2=10` 种，必须在 `i==n-1` 时提前返回。
- 输入 `[8,7,6,6]` 中 `nums[2]==nums[3]`，找后缀时若用 `<=` 会把 `j` 推到 3，导致 `[8,7,6]` 这类合法解被漏掉；必须严格用 `<` 判断递增。

## 如果面试官追问
若 n 扩大到 10^5 且要求输出所有方案，怎么做？答：仍用双指针定位 `i`、`j`，但枚举 `l` 时对每个 `l` 二分 `r`，总 O(n log n)，输出方案本身 O(答案数)。
