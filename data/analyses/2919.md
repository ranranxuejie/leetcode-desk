## 一句话思路
只需保证每个长度恰为 3 的窗口最大值 ≥ k，用 dp[i] 记「i 被抬到 k」的最小代价，滚动取前三项最小值。

## 怎么做
1. 把「所有长度 ≥3 子数组」压缩成「所有长度恰为 3 的窗口」：任何长窗口都包含一个 3 窗口，其最大值 ≥ k 即可。
2. 定义 `cost[i] = max(0, k - nums[i])`，`dp[i]` 表示处理到 i 且**强制**把 nums[i] 抬到 ≥ k 时的最小总代价。
3. 转移：`dp[i] = cost[i] + min(dp[i-1], dp[i-2], dp[i-3])`，因为窗口 [i-2, i] 必须有一个被抬，选最便宜的那个。
4. 答案取 `min(dp[n-1], dp[n-2], dp[n-3])`，末尾三个窗口各需一个被抬。

以 `nums = [2,3,0,0,2], k = 4` 为例：`cost = [2,1,4,4,2]`。`dp[0]=2, dp[1]=1, dp[2]=4+min(2,1)=5`；`dp[3]=4+min(1,2,5)=5`；`dp[4]=2+min(5,5,1)=3`。末尾取 `min(dp[4], dp[3], dp[2]) = min(3,5,5) = 3`，与示例一致。

```python
cost = [max(0, k - x) for x in nums]
dp = [0] * len(nums)
for i in range(len(nums)):
    best = 0 if i == 0 else min(dp[max(0, i - 3):i])
    dp[i] = cost[i] + best
return min(dp[-3:])
```

注意 `dp[max(0, i-3):i]` 在 i=0 时是空切片，所以单独处理 `best = 0`；i=1、2 时切片自动只含已有项，无需特判。

## 复杂度
时间 O(n)：一次遍历，每步只比较前 3 个 dp 值。
空间 O(n)：dp 数组；可压成 3 个变量降到 O(1)。

## 易错点
- `nums = [0,0,0], k = 0` → 若把 `cost` 写成 `k - nums[i]` 不加 `max(0, ...)`，会得到负数代价并让 dp 变小 → 必须 `max(0, k - x)`，因为只能增不能减。
- `nums = [2,3,0,0,2], k = 4` → 若答案取 `dp[n-1]` 而非 `min(dp[-3:])`，会得 3 但换成 `nums=[0,0,0,0], k=5` 时 `dp[3]=5` 而 `dp[1]=5` 恰好相等看不出错，真正翻车在末尾窗口只需覆盖到 n-3 位置 → 必须对最后三个 dp 取 min。

## 如果面试官追问
要求输出具体抬哪些下标怎么办？答：dp 时额外存 `pre[i]` 记录选中的前驱下标，从 `argmin(dp[-3:])` 回溯即可，代价不变。
