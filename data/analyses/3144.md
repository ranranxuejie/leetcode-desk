## 一句话思路
对每个右端点 j 枚举左端点 i，用「出现次数种类数 × 最大次数 == 子串长度」判平衡，再做 dp 取最小分割数。

## 怎么做
1. 定义 `dp[j]` 为 `s[:j]` 的最少平衡分割数，`dp[0] = 0`，其余初始化为 `inf`。
2. 外层枚举右端点 `j` 从 1 到 n，内层 `i` 从 `j-1` 递减到 0，边扩边统计 `cnt[26]`。
3. 维护 `kinds`（出现次数 > 0 的字符数）和 `mx`（最大出现次数），平衡条件写成 `kinds * mx == j - i`。
4. 满足时更新 `dp[j] = min(dp[j], dp[i] + 1)`。

以 `s = "fabccddg"` 为例，当 `j = 8`、`i = 4` 时子串是 `"ccdd"`，此时 `cnt` 中 c、d 各 2，`kinds = 2`、`mx = 2`，`2 * 2 == 4` 成立，于是 `dp[8] = dp[4] + 1`；而 `dp[4]` 由 `"fab"` 得到 1，最终 `dp[8] = 3`。

```python
n = len(s)
dp = [0] + [float('inf')] * n
for j in range(1, n + 1):
    cnt = [0] * 26
    kinds = mx = 0
    for i in range(j - 1, -1, -1):
        c = ord(s[i]) - 97
        if cnt[c] == 0:
            kinds += 1
        cnt[c] += 1
        mx = max(mx, cnt[c])
        if kinds * mx == j - i and dp[i] + 1 < dp[j]:
            dp[j] = dp[i] + 1
```

注意 `mx` 只增不减是安全的：内层是往左扩，字符只增不减，最大频次单调不降。

## 复杂度
时间 O(n²)：外层 n 个右端点，内层最多 n 次，每次 O(1) 更新。
空间 O(n)：`dp` 数组 n+1 项，`cnt` 固定 26 项。

## 易错点
- 判平衡写成「所有 cnt 相等」→ 对 `"fabccddg"` 的 `"fab"` 会因 a、b 为 0 而误判不平衡 → 正确做法是只看 `cnt > 0` 的字符，用 `kinds * mx == 长度` 判。
- 内层循环写成 `for i in range(j)` 从左往右扩 → `mx` 不再单调，且 `dp[i]` 依赖已算好的前缀，方向反了会用到未更新的 `dp` → 必须 `i` 从 `j-1` 递减到 0，保证 `dp[i]` 是最终值。

## 如果面试官追问
问：n 放大到 10⁵ 怎么办？答：O(n²) 不可行，需要按「平衡子串长度必为 kinds 的倍数」剪枝，或改用前缀计数 + 哈希定位候选左端点。
