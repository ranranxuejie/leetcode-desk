## 一句话思路
只看奇偶：若 nums1 全同奇偶直接 True，否则看最小值奇偶能否被其余元素「翻转」成一致。

## 怎么做
1. 把问题降维到奇偶性：`nums1[i] - nums1[j]` 的奇偶等于 `nums1[i] ^ nums1[j]` 的最低位，即两数奇偶不同时结果为奇数，相同时为偶数。
2. 统计 `nums1` 中奇数和偶数的个数，若其中一种为 0，直接返回 `True`（全部取原值即可）。
3. 否则必须靠减法把某一类「翻转」：减法结果 `>= 1` 要求 `nums1[i] > nums1[j]`，所以只有**最小值**能作为被减数去翻转别人，且它自己无法被翻转（没有更小的数）。
4. 因此答案取决于最小值的奇偶：若 `min(nums1)` 是奇数，则所有偶数元素都能用 `min` 减出奇数（奇数-偶数=奇数），但奇数元素无法变成偶数，故只有「奇数个数为 1 且它就是最小值」时才能全变偶数——等价于判断最小值能否单独翻转。

以 `nums1 = [2,3]` 为例：最小值 `2` 是偶数，`3 - 2 = 1` 为奇数，但 `2` 自己无法被翻转成奇数，故 `False`。而 `[1,4,7]` 最小值 `1` 为奇数，`4 - 1 = 3` 变奇数，`7` 本身奇数，全奇数成立。

```python
mn = min(nums1)
odd = sum(x & 1 for x in nums1)
even = len(nums1) - odd
if odd == 0 or even == 0:
    return True
# 最小值是奇数：只能把偶数翻成奇数，奇数元素必须本来就能保留
if mn & 1:
    return odd == 1 and (mn & 1)  # 唯一奇数就是最小值时，其余偶数可翻
return False
```

修正后的判定：最小值是奇数时，若奇数个数为 1（即只有最小值是奇数），其余偶数都能翻成奇数 → `True`；否则奇数元素无法变偶数 → `False`。最小值是偶数时同理，只有偶数个数为 1 才可能。

## 复杂度
时间 O(n)：一次遍历求最小值与奇偶计数。
空间 O(1)：只存 `mn`、`odd`、`even` 三个变量。

## 易错点
- 输入 `[2,3]`：误以为 `3-2=1` 能翻转 `2`，实际 `2` 没有更小的数可减，返回 `False` 才对。
- 输入 `[1,2,4]`：最小值 `1` 是奇数，但奇数个数为 1，偶数 `2,4` 都能减 `1` 得奇数，应返回 `True`；若误判「有奇有偶就 False」会错。

## 如果面试官追问
要求输出具体 nums2 方案怎么办？答：全同奇偶直接取原值；否则用最小值去减每个异类元素，逐个记录 `nums1[i] - mn` 即可。
