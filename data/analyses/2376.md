## 一句话思路
数位 DP：从高位到低位枚举，用 10 位掩码记录已用数字，`tight` 标记是否贴着 n 的前缀。

## 怎么做
1. 把 n 转成字符串 `s`，长度 `L`，状态 `(pos, mask, tight, started)`，`started` 表示是否已放过非零位。
2. 记忆化只对 `tight == False` 且 `started == True` 的状态缓存，因为 `tight` 为真时路径唯一、`started` 为假时后续还要单独算前导零。
3. 转移时若 `started` 为假，可以继续跳过（`mask` 不变），也可以选 `1..up` 中任一数字开启；若已开启，只能选 `mask` 中未出现的数字。
4. 用 n = 135 走一遍：`pos=0` 选 1 后 `mask=0b10`；`pos=1` 选 3 后 `mask=0b1010`；`pos=2` 时 `up=5`，可选 {0,2,4,5} 共 4 个，加上前面不贴紧的分支，最终得 110。

```python
from functools import lru_cache
s = str(n)
L = len(s)

@lru_cache(None)
def dfs(pos, mask, tight, started):
    if pos == L:
        return 1 if started else 0
    up = int(s[pos]) if tight else 9
    res = 0
    for d in range(up + 1):
        if not started and d == 0:
            res += dfs(pos + 1, mask, tight and d == up, False)
        elif not (mask >> d) & 1:
            res += dfs(pos + 1, mask | (1 << d), tight and d == up, True)
    return res
```

## 复杂度
时间：状态数 `L * 2^10 * 2 * 2`，每个状态枚举 10 个数字，约 `O(L * 2^10 * 10)`，L = log n。
空间：缓存表 `O(L * 2^10 * 4)`，递归栈 `O(L)`。

## 易错点
- n = 5 时若把 `started=False` 的终止状态也计 1，会把「全前导零」当成数字 0 算进去，答案变 6；正确做法是 `pos == L` 时返回 `1 if started else 0`。
- n = 20 时若在 `started=False` 分支里也检查 `mask` 冲突，前导零会被当成「已用数字 0」，导致 10、20 被误判非法；正确做法是跳过前导零时完全不碰 `mask`。

## 如果面试官追问
问：n 扩大到 10^18 怎么办？
答：算法不变，L 从 10 变 18，状态数只线性增长，仍是 `O(L * 2^10 * 10)`，无需改结构。
