## 一句话思路
用 `Sales` 左连接 `Product`，按 `product_id` 匹配后只投影 `product_name, year, price`。

## 怎么做
1. 以 `Sales` 为驱动表，`LEFT JOIN Product ON s.product_id = p.product_id`。
2. 只 `SELECT p.product_name, s.year, s.price`，其余列（`sale_id`、`quantity`）不输出。
3. 无排序要求，省掉 `ORDER BY`。

以官方示例验证：`Sales` 第 1 行 `product_id=100`，在 `Product` 中命中 `(100, 'Nokia')`，输出 `('Nokia', 2008, 5000)`；第 3 行 `product_id=200` 命中 `(200, 'Apple')`，输出 `('Apple', 2011, 9000)`。`Product` 里的 `300 Samsung` 在 `Sales` 中无对应行，不会出现在结果里。

```python
import pandas as pd

def sales_analysis(sales: pd.DataFrame, product: pd.DataFrame) -> pd.DataFrame:
    merged = sales.merge(
        product,
        on="product_id",
        how="left",
        suffixes=("", "_p"),
    )
    return merged[["product_name", "year", "price"]]
```

关键中间值：`merge` 后 `merged` 有 3 行、列含 `sale_id, product_id, year, quantity, price, product_name`；`product_id=100` 的两行都填上 `'Nokia'`，`200` 那行填 `'Apple'`，最后切片丢掉多余列。

## 复杂度
时间：`Sales` 行数 m 与 `Product` 行数 n 做哈希连接，约 O(m+n)。
空间：额外开一个 m 行的合并结果表，O(m)。

## 易错点
- 若把 `Sales` 和 `Product` 写成内连接，`Product` 中 `300 Samsung` 这类无销售记录的产品会被丢掉——本题要求保留 `Sales` 全部 `sale_id`，必须用 `LEFT JOIN` 以 `Sales` 为左表。
- 若 `SELECT *` 或漏掉列裁剪，结果会多出 `sale_id`、`quantity`、`product_id`，与期望的三列 `product_name, year, price` 不符；`quantity` 是数量不是单价，别误当 `price` 输出。

## 如果面试官追问
问：若要求按 `year` 升序、同年按 `price` 降序输出怎么办？
答：在末尾加 `ORDER BY s.year ASC, s.price DESC`，连接逻辑不变。
