## 一句话思路
先假设全给第二只老鼠，再按 `reward1[i]-reward2[i]` 从大到小挑 k 块改判给第一只老鼠。

## 怎么做
1. 基准分取 `sum(reward2)`，此时第一只老鼠吃 0 块。
2. 对每块奶酪算「改判收益」`d[i] = reward1[i] - reward2[i]`。
3. 把 `d` 降序排序，取前 k 个加到基准分上。
4. 返回 `sum(reward2) + sum(sorted(d, reverse=True)[:k])`。

以示例 1 为例：`reward1=[1,1,3,4]`，`reward2=[4,4,1,1]`，基准分 `4+4+1+1=10`；`d=[-3,-3,2,3]`，降序后前 2 个是 `3,2`，和 `5`，答案 `10+5=15`。注意下标 2、3 的 `d` 为正，正好对应题解里第一只老鼠吃第 2、3 块。

```python
base = sum(reward2)
d = [a - b for a, b in zip(reward1, reward2)]
d.sort(reverse=True)
return base + sum(d[:k])
```

`k=0` 时 `d[:0]` 为空，返回 `sum(reward2)`，不用特判；`k=n` 时全部改判，返回 `sum(reward1)`。

## 复杂度
时间：排序 `O(n log n)`，n 是奶酪块数，log n 来自 `d.sort`。
空间：`O(n)`，额外开了长度 n 的 `d` 列表（原地排序不另算）。

## 易错点
- `k=0` 或 `k=n` 的边界 → 若写成「先取 k 个最大再处理剩余」的分支逻辑，容易在 `k=0` 时误加 `d[0]` 或漏掉基准分 → 直接用 `d[:k]` 切片，空切片求和为 0，天然正确。
- `d` 里有大量负数（如示例 1 的 `-3,-3`）→ 若误按 `reward1` 降序挑前 k 块，会选中 `reward1=4` 那块却漏掉收益更高的组合，示例 1 会得 14 而非 15 → 必须按差值 `reward1[i]-reward2[i]` 排序，而不是按单边奖励。

## 如果面试官追问
问：n 扩大到 10^7、k 很小怎么办？
答：用大小为 k 的小根堆维护最大的 k 个 `d`，时间降到 `O(n log k)`，空间 `O(k)`。
