## 一句话思路
先找出全局支配元素 x，再从左往右扫前缀计数，第一个让 x 在左右两半都过半的下标就是答案。

## 怎么做
1. 用哈希表统计频次，取出现次数最多的值作为支配元素 `x`（题面保证唯一）。
2. 记 `total = count[x]`，从左到右维护 `left_x`（前缀里 x 的个数），下标 i 处左半长度 `i+1`、右半长度 `n-i-1`。
3. 判定条件写成乘法避免浮点：`left_x * 2 > i + 1` 且 `(total - left_x) * 2 > n - i - 1`，第一个满足的 i 直接返回。
4. 扫完没命中返回 -1。

以示例 2 `nums = [2,1,3,1,1,1,7,1,2,1]` 为例，`x = 1`、`total = 6`、`n = 10`。扫到 i=3 时 `left_x = 2`，`2*2 > 4` 成立但 `(6-2)*2 = 8 > 6` 也成立——注意这里右半是 `nums[4..9] = [1,1,7,1,2,1]`，长度 6，1 出现 4 次，8>6 确实成立，所以 i=3 就合法？实际答案给的是 4，原因是 i=3 时左半 `[2,1,3,1]` 长度 4，1 只出现 2 次，`2*2 > 4` 不成立（严格大于），所以被排除。i=4 时 `left_x = 3`，`6 > 5` 成立，`(6-3)*2 = 6 > 5` 成立，返回 4。这个「严格大于」是本题最容易翻车的地方。

```python
from collections import Counter

cnt = Counter(nums)
x = max(cnt, key=cnt.get)
total, left_x, n = cnt[x], 0, len(nums)
for i, v in enumerate(nums):
    if v == x:
        left_x += 1
    if i < n - 1 and left_x * 2 > i + 1 and (total - left_x) * 2 > n - i - 1:
        return i
return -1
```

## 复杂度
时间 O(n)：一次 Counter 建表加一次线性扫描，哈希操作均摊 O(1)。
空间 O(n)：Counter 最多存 n 个不同值，其余只有常数个变量。

## 易错点
- 把「超过一半」写成 `>=`：示例 2 在 i=3 时左半 1 出现 2 次、长度 4，`2*2 >= 4` 会误判合法并返回 3，正确必须用严格 `>`，答案才是 4。
- 循环边界写成 `i < n`：i = n-1 时右半是空数组，`(total - left_x) * 2 > 0` 在 `total == left_x` 时恒成立，会错误返回 n-1；必须限定 `i < n - 1`，示例 1 `[1,2,2,2]` 若漏掉该判断，i=3 时左半 2 出现 3 次、右半为空，会误返回 3 而非 2。

## 如果面试官追问
问：如果数组不保证有支配元素怎么办？答：先扫一遍确认 `max(cnt.values()) * 2 > n`，不满足直接返回 -1，后续逻辑不变。
