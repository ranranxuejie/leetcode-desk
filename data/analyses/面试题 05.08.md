## 一句话思路
按 32 位一组定位起止像素落在哪个 int，中间整块直接填 -1，两端用掩码或运算。

## 怎么做
1. 行内像素 `x` 对应数组下标 `y * (w // 32) + x // 32`，位偏移 `x % 32`。
2. 起点 `x1` 所在 int 的掩码是 `-1 << (x1 % 32)`，终点 `x2` 所在 int 的掩码是 `-1 >> (31 - x2 % 32)`，两者都按 32 位截断。
3. 若 `x1 // 32 == x2 // 32`，两个掩码相与后只改这一个 int；否则分别改首尾，中间 `base + 1 .. base + end` 整段赋 `-1`。
4. 用示例 1 验证：`w // 32 = 1`，`base = 0`，`x1 // 32 == x2 // 32 == 0`，掩码 `-1 << 30` 与 `-1 >> 0` 相与得 `3`，写入 `ans[0]`。

```python
def draw(length, w, x1, x2, y):
    ans = [0] * length
    per = w // 32
    base = y * per
    s, e = x1 // 32, x2 // 32
    if s == e:
        m = ((-1 << (x1 % 32)) & (-1 >> (31 - x2 % 32))) & 0xFFFFFFFF
        ans[base + s] |= m
    else:
        ans[base + s] |= (-1 << (x1 % 32)) & 0xFFFFFFFF
        ans[base + e] |= (-1 >> (31 - x2 % 32)) & 0xFFFFFFFF
        for i in range(base + s + 1, base + e):
            ans[i] = -1
    return ans
```

注意 `-1 >> k` 在 Python 里是算术右移，结果仍是负数，`& 0xFFFFFFFF` 后再 `|=` 到 `ans` 上，最终值可能超过 `2**31 - 1`，需要按 32 位截断：`v & 0xFFFFFFFF` 后若 `v >= 2**31` 则 `v -= 2**32`。示例 2 中 `x1=0, x2=95`，`s=0, e=2`，首块掩码 `-1`、尾块 `-1 >> 0 = -1`，中间 `ans[1] = -1`，输出 `[-1, -1, -1]`。

## 复杂度
时间：O(length)，最坏要遍历整行 `per` 个 int 并填中间段。
空间：O(length)，返回数组本身，无额外结构。

## 易错点
- `x1 % 32 == 0` 时若写成 `-1 >> (x1 % 32)` 会得到 `-1`，把整块 32 位都点亮 → 正确是左移 `-1 << 0` 得 `-1`，但起点掩码必须用左移，终点掩码必须用右移，两者方向不能混。
- Python 的 `-1 >> k` 是算术右移，结果仍是负数，直接 `|=` 到 `ans` 上不会出错，但若先 `& 0xFFFFFFFF` 再存，值会变成 `2**32 - 1` 这类正数，与题目要求的 32 位有符号表示不符 → 存回前统一做 `v - 2**32 if v >= 2**31 else v`。

## 如果面试官追问
若 `w` 不能被 32 整除怎么办？答：一个 int 会跨行，需按全局像素偏移 `y * w + x` 重新定位，首尾掩码要拆成两段处理。
