## 一句话思路
正反两遍扫描：从左找「最后一个小于左侧最大值」的位置，从右找「第一个大于右侧最小值」的位置，两者夹出的区间即答案。

## 怎么做
1. 正向扫一遍，维护 `max_seen`，凡是 `nums[i] < max_seen` 就更新 `right = i`，因为该元素必须被纳入排序区间。
2. 反向扫一遍，维护 `min_seen`，凡是 `nums[i] > min_seen` 就更新 `left = i`。
3. 若 `right == -1`（全程升序），返回 0；否则返回 `right - left + 1`。

以 `nums = [2,6,4,8,10,9,15]` 为例：正向扫到 `i=2` 时 `nums[2]=4 < max_seen=6`，`right` 更新为 2；继续扫到 `i=5` 时 `nums[5]=9 < max_seen=10`，`right` 变为 5。反向扫到 `i=4` 时 `nums[4]=10 > min_seen=9`，`left` 变为 4；扫到 `i=1` 时 `nums[1]=6 > min_seen=4`，`left` 变为 1。最终 `right-left+1 = 5-1+1 = 5`。

```python
left, right = -1, -1
max_seen, min_seen = nums[0], nums[-1]
for i in range(len(nums)):
    if nums[i] < max_seen:
        right = i
    else:
        max_seen = nums[i]
for i in range(len(nums) - 1, -1, -1):
    if nums[i] > min_seen:
        left = i
    else:
        min_seen = nums[i]
return 0 if right == -1 else right - left + 1
```

关键点：`max_seen` 只在 `nums[i] >= max_seen` 时更新，保证 `right` 记录的是「最靠右的逆序元素」，而不是被后续更大值覆盖。

## 复杂度
时间 O(n)：正向、反向各扫一遍，共 2n 次比较。
空间 O(1)：只开了 `left/right/max_seen/min_seen` 四个变量。

## 易错点
- 输入 `[1,3,2,2,2]` → 若用 `nums[i] <= max_seen` 更新 `right`，会把末尾相等的 2 也算进区间，得到长度 4；正确做法是严格 `<` 才更新，答案应为 3（`[3,2,2]`）。
- 输入 `[2,1]` → 若只做正向扫描、忘记反向扫 `left`，`left` 停在 -1，返回 `right-(-1)+1 = 3` 越界；必须两遍都扫，`left` 由反向扫描确定。

## 如果面试官追问
要求输出具体子数组而非长度？答：同样两遍扫描拿到 `left/right`，直接返回 `nums[left:right+1]`，复杂度不变。
