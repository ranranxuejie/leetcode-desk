## 一句话思路
对每个格子记忆化 DFS，`f(i,j)` 返回以 `(i,j)` 为起点的递增路径数，等于 1 加上四个严格更大邻居的 `f` 之和。

## 怎么做
1. 定义 `f(i,j) = 1 + Σ f(ni,nj)`，求和只对 `grid[ni][nj] > grid[i][j]` 的邻居做，`1` 是长度 1 的路径本身。
2. 用 `memo` 二维数组初始化为 0，非 0 即已算过，直接返回；严格递增保证无环，不会死循环。
3. 答案是对所有 `(i,j)` 的 `f(i,j)` 求和再取模。

以 `grid = [[1,1],[3,4]]` 为例：`f(1,1)`（值 4）无更大邻居 = 1；`f(1,0)`（值 3）只有右邻 4 更大 = 1+1 = 2；`f(0,1)`（值 1）下方 4 更大 = 1+1 = 2；`f(0,0)`（值 1）下方 3、右方 1 中只有 3 更大 = 1+2 = 3。总和 1+2+2+3 = 8。

```python
MOD = 10**9 + 7
def dfs(i, j):
    if memo[i][j]:
        return memo[i][j]
    res = 1
    for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
        ni, nj = i+di, j+dj
        if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] > grid[i][j]:
            res += dfs(ni, nj)
    memo[i][j] = res % MOD
    return memo[i][j]
```

## 复杂度
时间：O(m·n)，每个格子只算一次，每格查 4 个邻居。
空间：O(m·n)，`memo` 二维表加递归栈深度最坏 O(m·n)。

## 易错点
- `grid = [[1,1],[3,4]]` 中两个 1 相邻：若把 `>=` 写成 `>` 的反面（即允许相等就转移），会把 `[1 -> 1]` 算成路径，答案变 9 而非 8；判断必须是 `grid[ni][nj] > grid[i][j]` 严格大于。
- 全等网格如 `[[2,2],[2,2]]`：若忘记 `res` 初值取 1，只累加邻居会得 0，正确是 4 条长度 1 路径；`res = 1` 必须在循环外先赋。
- `memo` 用 0 表示未访问，但 `f` 最小是 1，所以 `if memo[i][j]` 判真安全；若把某格结果存成 0（比如先取模再减）就会重复计算，取模只放在赋值处。

## 如果面试官追问
问：m·n 到 10^5 递归会爆栈怎么办？
答：按 `grid` 值升序排序后迭代 DP，`f` 只依赖更大值，从大到小填表，用显式栈或排序代替递归。
