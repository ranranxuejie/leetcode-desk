## 一句话思路
把字母列号 `ord(coordinates[0]) - ord('a')` 与数字行号 `int(coordinates[1]) - 1` 相加，和为偶数即白格。

## 怎么做
1. 取列索引 `col = ord(coordinates[0]) - ord('a')`，取行索引 `row = int(coordinates[1]) - 1`。
2. 判断 `(col + row) % 2 == 0`，为真返回 `True`，否则 `False`。
3. 以 `"h3"` 为例：`col = ord('h') - ord('a') = 7`，`row = 3 - 1 = 2`，`7 + 2 = 9` 为奇数，返回 `True`，与示例一致。
4. 以 `"a1"` 验证：`col = 0`，`row = 0`，和为 0 偶数，返回 `False`，与示例一致。

```python
col = ord(coordinates[0]) - ord('a')
row = int(coordinates[1]) - 1
return (col + row) % 2 == 0
```

棋盘相邻格颜色交替，因此行列索引之和的奇偶性唯一决定颜色；`a1` 为黑格对应和为偶数返回 `False`，所以偶数判白、奇数判黑。

## 复杂度
时间：O(1)，只做两次字符转换和一次加法取模。
空间：O(1)，仅用 `col`、`row` 两个整型变量，无额外数组。

## 易错点
1. 输入 `"a1"` 时若直接用 `ord(coordinates[0]) + int(coordinates[1])` 判断奇偶，`97 + 1 = 98` 为偶数却返回 `True`，与答案 `False` 相反；必须先减去 `ord('a')` 和 `1` 归零到 0 基索引再判奇偶。
2. 输入 `"h8"` 时若把行号写成 `int(coordinates[1])` 而不减 1，`7 + 8 = 15` 为奇数返回 `False`，但 `h8` 实际是白格应返回 `True`；行号必须减 1 才能与列索引对齐。

## 如果面试官追问
问：若坐标改为 `"a1"` 到 `"z26"` 的变长字符串怎么办？
答：用 `coordinates[0]` 取列、`int(coordinates[1:])` 取行，索引规则不变，仍 O(1)。
