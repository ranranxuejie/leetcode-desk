## 一句话思路
相邻两词首个不同字母给出有向边，建图后拓扑排序；有环即无解。

## 怎么做
1. 只比较相邻两词 `words[i]` 与 `words[i+1]`，找到第一个不同字符，加边 `a -> b`。
2. 若 `words[i]` 是 `words[i+1]` 的前缀且更长（如 `"abc"` 在 `"ab"` 前），直接返回 `""`。
3. 收集所有出现过的字母作为节点，对入度为 0 的节点做 BFS 拓扑排序。
4. 输出序列长度小于节点数说明有环，返回 `""`。

以 `["wrt","wrf","er","ett","rftt"]` 为例：`wrt/wrf` 得 `t->f`，`wrf/er` 得 `w->e`，`er/ett` 得 `r->t`，`ett/rftt` 得 `e->r`。入度：`w:0, e:1, r:1, t:1, f:1`，队列初始只有 `w`，弹出后 `e` 入度归零，依次得 `wertf`。

```python
from collections import defaultdict, deque

g = defaultdict(set)
indeg = {c: 0 for w in words for c in w}
for a, b in zip(words, words[1:]):
    if len(a) > len(b) and a.startswith(b):
        return ""
    for x, y in zip(a, b):
        if x != y:
            if y not in g[x]:
                g[x].add(y)
                indeg[y] += 1
            break

q = deque(c for c in indeg if indeg[c] == 0)
res = []
while q:
    c = q.popleft()
    res.append(c)
    for nxt in g[c]:
        indeg[nxt] -= 1
        if indeg[nxt] == 0:
            q.append(nxt)
return "".join(res) if len(res) == len(indeg) else ""
```

## 复杂度
时间 O(C)，C 为所有单词字符总数，建图与拓扑各扫一遍。
空间 O(V+E)，V≤26 个字母，E 为边数，额外开了邻接表和入度表。

## 易错点
- 输入 `["abc","ab"]` → 若只比较到 `min` 长度就跳过，会漏判非法前缀，错误返回非空串 → 必须先检查 `len(a) > len(b) and a.startswith(b)` 并返回 `""`。
- 输入 `["z","x","z"]` → 若用 DFS 只标记访问不区分「在栈中」，会把环当合法路径 → 拓扑排序用「结果长度 < 节点数」判环，或 DFS 用三色标记。

## 如果面试官追问
若要求输出字典序最小的合法顺序？答：把 BFS 队列换成最小堆，每次弹出当前入度为 0 的最小字母。
