## 一句话思路
按列从左到右贪心：只要某列在「尚未确定大小」的相邻行上出现降序就必删，否则保留并锁定那些升序的行。

## 怎么做
1. 维护布尔数组 `sorted`，`sorted[i]` 表示 `strs[i]` 与 `strs[i+1]` 已由前面保留的列分出大小，后续列不再约束它们。
2. 对每一列 `c`，先扫一遍所有 `i`：若 `not sorted[i] and strs[i][c] > strs[i+1][c]`，这列必须删，直接跳过。
3. 若没有降序，这列保留，再扫一遍把 `strs[i][c] < strs[i+1][c]` 的 `i` 置 `sorted[i] = True`（相等则继续悬着）。
4. 返回删除列数。

以 `strs = ["ca","bb","ac"]` 为例：初始 `sorted = [False, False]`。第 0 列是 `c,b,a`，`i=0` 处 `'c' > 'b'` 且未定序，必删，`answer = 1`。第 1 列是 `a,b,c`，无降序，保留，`i=0` 处 `'a' < 'b'` 置 `sorted[0]=True`，`i=1` 处 `'b' < 'c'` 置 `sorted[1]=True`，最终 `answer = 1`。

```python
m, n = len(strs[0]), len(strs)
sorted_ = [False] * (n - 1)
ans = 0
for c in range(m):
    if any(not sorted_[i] and strs[i][c] > strs[i + 1][c] for i in range(n - 1)):
        ans += 1
        continue
    for i in range(n - 1):
        if strs[i][c] < strs[i + 1][c]:
            sorted_[i] = True
return ans
```

## 复杂度
时间 O(n·m)，n 为行数、m 为列数，每列最多扫两遍。
空间 O(n)，只开 `sorted_` 这个长度 n-1 的布尔数组。

## 易错点
- 输入 `["ca","bb","ac"]` 若只看第 0 列 `c,b,a` 发现降序就删，但忘了第 1 列 `a,b,c` 本身已能定序，会误删第 1 列得 2；正确是删第 0 列后第 1 列保留，答案 1。
- 输入 `["xga","xfb","yfa"]` 这类前缀相等的行，若把 `strs[i][c] == strs[i+1][c]` 也当成已定序置 `sorted[i]=True`，后续列就不再检查它们，可能漏删；正确做法是相等时保持 `sorted[i]=False`，等后面某列分出大小。

## 如果面试官追问
若要求返回具体删除的列索引而非个数？答：把 `ans += 1` 换成 `ans.append(c)`，其余逻辑不变，因为贪心每列的删/留决策独立于顺序。
