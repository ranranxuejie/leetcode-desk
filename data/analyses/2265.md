## 一句话思路
后序 DFS 让每个节点返回 `(子树和, 节点数)`，回溯时顺手判断 `val == sum // cnt`。

## 怎么做
1. 递归函数返回二元组 `(s, c)`：以当前节点为根的子树元素和、节点个数。
2. 空节点返回 `(0, 0)`，作为叶子节点合并的基准。
3. 当前节点合并：`s = val + ls + rs`，`c = 1 + lc + rc`，再判断 `val == s // c`。
4. 用 `nonlocal` 计数，或让递归函数直接返回「本子树内满足条件的节点数」再累加。

以示例 1 的 `root = [4,8,5,0,1,null,6]` 为例，走到值为 5 的节点时，左孩子为空返回 `(0,0)`，右孩子 6 返回 `(6,1)`，合并得 `s = 5+0+6 = 11`、`c = 1+0+1 = 2`，`11 // 2 = 5` 等于节点值，计数加一。根节点 4 最后合并出 `s = 24`、`c = 6`，`24 // 6 = 4`，也计入，最终 5 个。

```python
def dfs(node):
    if not node:
        return 0, 0
    ls, lc = dfs(node.left)
    rs, rc = dfs(node.right)
    s, c = node.val + ls + rs, 1 + lc + rc
    if node.val == s // c:
        nonlocal ans
        ans += 1
    return s, c
```

关键点：`s // c` 是向下取整，Python 的 `//` 对非负数正好符合题意（节点值 ≥ 0，和也 ≥ 0），不用额外处理。

## 复杂度
时间 O(n)：每个节点被访问一次，合并是 O(1)。
空间 O(h)：递归栈深度为树高，最坏链状 O(n)，未开额外数组。

## 易错点
- 输入是链状树（如 `[1,2,3,4,...]` 全在左子树）→ 递归深度达 1000 层，Python 默认递归上限约 1000，可能 `RecursionError` → 提前 `sys.setrecursionlimit(10000)`，或改写成显式栈的后序遍历。
- 用 `s / c` 而非 `s // c` → 对 `[5,6]` 这种 `11/2 = 5.5` 的情况，浮点比较 `5 == 5.5` 为假，但若写成 `int(s / c)` 在极大和时可能因浮点精度偏差 → 一律用整数 `//`，本题和最大 1000×1000 = 10^6，浮点其实安全，但 `//` 更稳。

## 如果面试官追问
追问：节点数放大到 10^5 且树可能退化成链怎么办？
答：递归会爆栈，改成显式栈做后序（记录访问标记），或先迭代求后序序列再逆序合并。
