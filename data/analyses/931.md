## 一句话思路
逐行滚动 DP：`dp[j]` 表示落到当前行第 j 列的最小路径和，每格取上一行 j-1/j/j+1 三者的最小值加上 `matrix[i][j]`。

## 怎么做
1. 初始化 `dp = matrix[0][:]`，第一行没有前驱，路径和就是元素本身。
2. 从第 1 行起逐行更新，对每个 `j` 取 `dp[max(j-1,0):j+2]` 的最小值，加上 `matrix[i][j]`。
3. 用 `new` 数组承接本行结果，整行算完再赋回 `dp`，避免同一行内串用。
4. 最后返回 `min(dp)`。

以 `[[2,1,3],[6,5,4],[7,8,9]]` 为例，第 1 行：`j=0` 取 `dp[0:2]=[2,1]` 的 1，加 6 得 7；`j=1` 取 `[2,1,3]` 的 1，加 5 得 6；`j=2` 取 `[1,3]` 的 1，加 4 得 5，`dp=[7,6,5]`。第 2 行 `j=1` 时取 `[7,6,5]` 的 5，加 8 得 13，最终 `min(dp)=13`。

```python
dp = matrix[0][:]
for i in range(1, len(matrix)):
    new = []
    for j in range(len(matrix)):
        lo, hi = max(j - 1, 0), min(j + 2, len(matrix))
        new.append(min(dp[lo:hi]) + matrix[i][j])
    dp = new
return min(dp)
```

## 复杂度
时间：O(n²)，每行 n 格、每格看至多 3 个前驱。
空间：O(n)，只留一行 `dp` 和一行 `new`，没有开 n×n 表。

## 易错点
- 边界列直接写 `dp[j-1]` / `dp[j+1]`：`j=0` 时 `dp[-1]` 在 Python 里会绕到行尾，把 `matrix[1][0]` 算成能从上行最后一列过来。必须用 `max(j-1,0)` 和 `min(j+2,n)` 切片。
- 原地更新 `dp[j]`：算 `j=1` 时 `dp[0]` 已被本行覆盖，等于允许同行横跳。示例 1 第 1 行会算出错误的小值。必须整行写进 `new` 再赋回。

## 如果面试官追问
问：n 到 10⁴ 但每行只有少数非零，怎么办？
答：只对非零列及其左右邻居做松弛，用字典存 `dp`，复杂度降到 O(非零数)。
