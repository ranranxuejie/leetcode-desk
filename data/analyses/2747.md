## 一句话思路
把 logs 按时间排序，对每个 query 用双指针维护窗口 `[q-x, q]`，再用「服务器 id → 窗口内出现次数」的哈希表实时统计有多少个不同 id 在窗口里，答案就是 `n - len(cnt)`。

## 怎么做
1. 把 `logs` 按 `time` 升序排序，`queries` 连同下标一起排序，保证窗口左右端点单调右移。
2. 对每个 query 维护左指针 `l`、右指针 `r`：`r` 一直右移把 `time <= q` 的 log 加入窗口，`l` 一直右移把 `time < q - x` 的 log 移出窗口。
3. 用 `cnt` 记录窗口内每个 server_id 的出现次数，`len(cnt)` 就是收到请求的服务器种数，答案 `n - len(cnt)`。
4. 按原下标把答案填回 `ans`。

以示例 1 为例：`logs` 排序后仍是 `[[1,3],[1,5],[2,6]]`，`x=5`。处理 `q=10` 时窗口是 `[5,10]`，`r` 扫到 `time=6` 停，`l` 把 `time=3` 的 `[1,3]` 移出，此时 `cnt={1:1,2:1}`，`len(cnt)=2`，答案 `3-2=1`。

```python
logs.sort(key=lambda p: p[1])
order = sorted(range(len(queries)), key=lambda i: queries[i])
cnt, l, r, ans = {}, 0, 0, [0] * len(queries)
for i in order:
    q = queries[i]
    while r < len(logs) and logs[r][1] <= q:
        s = logs[r][0]
        cnt[s] = cnt.get(s, 0) + 1
        r += 1
    while l < r and logs[l][1] < q - x:
        s = logs[l][0]
        cnt[s] -= 1
        if cnt[s] == 0:
            del cnt[s]
        l += 1
    ans[i] = n - len(cnt)
```

## 复杂度
时间：排序 `logs` 和 `queries` 各 O(m log m)、O(k log k)，双指针总移动 O(m)，合计 O(m log m + k log k)。
空间：`cnt` 最多存 n 个 id，加上 `order`、`ans` 各 O(k)，额外 O(n + k)。

## 易错点
- 区间是闭区间 `[q-x, q]`：移出条件必须写 `logs[l][1] < q - x`，写成 `<=` 会把恰好等于 `q-x` 的请求误删。示例 1 的 `q=10` 若写成 `<=`，`time=5` 的 `[1,5]` 被移出，`cnt` 只剩 `{2:1}`，答案错成 2。
- 同一服务器在窗口内多次请求：`cnt[s]` 减到 0 时必须 `del cnt[s]`，否则 `len(cnt)` 把计数为 0 的 id 也算进「收到请求」，示例 2 的 `q=3` 窗口 `[1,3]` 里 id=2 出现两次，不删会少算一个未收到请求的服务器。

## 如果面试官追问
问：logs 时间范围到 10^9、queries 也到 10^9 还成立吗？答：成立，双指针只依赖排序后的相对顺序，与时间绝对值无关，复杂度不变。
