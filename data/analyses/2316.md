## 一句话思路
用并查集把每个连通块的大小算出来，答案就是所有「跨连通块」点对数，即总数减去块内对数。

## 怎么做
1. 初始化 `parent = list(range(n))`、`size = [1]*n`，对 `edges` 里每条 `[a,b]` 做 union。
2. 遍历 `0..n-1`，用 `find(i)` 把每个根的大小累加进 `comp` 字典。
3. 答案用增量法：每遇到一个大小为 `s` 的块，`ans += s * (n - s)`，最后 `ans //= 2`。

以示例 2 为例，`n=7`，union 后得到三个块：`{0,2,4,5}` 大小 4、`{1,6}` 大小 2、`{3}` 大小 1。增量计算：`4*3=12`，`2*5=10`，`1*6=6`，和 `28`，除以 2 得 `14`，与输出一致。

```python
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

for a, b in edges:
    ra, rb = find(a), find(b)
    if ra != rb:
        if size[ra] < size[rb]:
            ra, rb = rb, ra
        parent[rb] = ra
        size[ra] += size[rb]

ans = 0
for i in range(n):
    if find(i) == i:
        ans += size[i] * (n - size[i])
return ans // 2
```

## 复杂度
时间：`O(n + m·α(n))`，`m = len(edges)`，路径压缩近似常数。
空间：`O(n)`，`parent` 和 `size` 两个长度 n 的数组。

## 易错点
- `edges = []`、`n = 10^5` → 若只遍历 `edges` 里的点建块，会漏掉孤立点，答案偏小 → 必须对 `0..n-1` 全部 `find` 一遍，孤立点自成一个大小 1 的块。
- 直接双重循环枚举点对 → `n = 10^5` 时是 `10^10` 次操作必然超时 → 必须用「总数减块内对数」的公式，`ans` 用 Python 整数累加，不要按 32 位截断。

## 如果面试官追问
问：如果要求输出所有无法互达的点对而不是只给个数？
答：块大小乘积仍是 `O(n^2)` 量级，只能按需枚举，先给块编号再双重循环输出。
