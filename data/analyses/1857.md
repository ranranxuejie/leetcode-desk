## 一句话思路
按拓扑序做 DP，`dp[v][c]` 记以 v 结尾的路径上颜色 c 的最大出现次数，环则返回 -1。

## 怎么做
1. 建邻接表 `g` 和入度 `indeg`，用 Kahn 算法跑拓扑排序，出队节点数不足 n 说明有环，直接返回 -1。
2. 每个节点维护长度 26 的数组 `dp[v]`，初始全 0，只有 `dp[v][ord(colors[v])-97] = 1`。
3. 出队 v 时把 `dp[v]` 沿边推给每个后继 u：`dp[u][c] = max(dp[u][c], dp[v][c] + (c == colors[u]))`，入度减到 0 时 u 入队。
4. 答案取所有 `dp[v]` 中的最大值。

以示例 1 为例，`colors="abaca"`，拓扑序为 0,1,2,3,4。处理到 3 时 `dp[3]` 的 a 计数为 2（0→2→3），推给 4 后 `dp[4]['a']=3`，即答案 3。

```python
from collections import deque
n = len(colors)
g = [[] for _ in range(n)]
indeg = [0] * n
for a, b in edges:
    g[a].append(b)
    indeg[b] += 1
dp = [[0] * 26 for _ in range(n)]
for v in range(n):
    dp[v][ord(colors[v]) - 97] = 1
q = deque(v for v in range(n) if indeg[v] == 0)
seen = 0
while q:
    v = q.popleft()
    seen += 1
    for u in g[v]:
        for c in range(26):
            dp[u][c] = max(dp[u][c], dp[v][c] + (c == ord(colors[u]) - 97))
        indeg[u] -= 1
        if indeg[u] == 0:
            q.append(u)
return -1 if seen < n else max(max(row) for row in dp)
```

## 复杂度
时间：O((n + m) × 26)，每条边推 26 个颜色，26 是常数。
空间：O(26n + n + m)，dp 表占 26n，邻接表和入度各占 O(n + m)。

## 易错点
- 自环如 `edges=[[0,0]]`：若只判 `indeg[0]==0` 就入队会漏掉环，必须用 `seen < n` 判断，示例 2 应返回 -1 而不是 1。
- 多入边汇聚节点如 0→2、1→2：若在第一次入度减到 0 前就更新 `dp[2]`，会漏掉另一条路径的贡献；正确做法是每次出队都更新 `dp[u]`，只在 `indeg[u]==0` 时才入队。

## 如果面试官追问
若 n 升到 10^6 且颜色只有 3 种，怎么改？答：把 26 换成实际颜色数 k，dp 表降为 O(kn)，复杂度 O((n+m)k)。
