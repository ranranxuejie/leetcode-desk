## 一句话思路
对每个 k×k 窗口取全部元素排序，最小差必出现在排序后相邻两项之间，取相邻差最小值。

## 怎么做
1. 枚举左上角 `(i, j)`，`i` 取 `0..m-k`，`j` 取 `0..n-k`。
2. 把窗口内 `k*k` 个元素收集成一个列表 `vals`。
3. 对 `vals` 排序，扫描相邻差 `vals[t+1] - vals[t]` 取最小。
4. 把结果填进 `ans[i][j]`。

以示例 1 `grid = [[1,8],[3,-2]], k = 2` 为例：唯一窗口 `(0,0)` 收集到 `vals = [1,8,3,-2]`，排序后 `[-2,1,3,8]`，相邻差为 `3,2,5`，最小是 `2`，写入 `ans[0][0]`。

```python
m, n = len(grid), len(grid[0])
ans = [[0] * (n - k + 1) for _ in range(m - k + 1)]
for i in range(m - k + 1):
    for j in range(n - k + 1):
        vals = sorted(grid[r][c]
                      for r in range(i, i + k)
                      for c in range(j, j + k))
        best = min(vals[t + 1] - vals[t] for t in range(len(vals) - 1))
        ans[i][j] = best
```

注意 `k == 1` 时 `vals` 只有一个元素，`range(len(vals)-1)` 为空，`min` 会抛 `ValueError`；示例 2 正是这种情况，必须单独处理成 `0`（或把 `best` 初值设为 `0` 再取 `min`）。

## 复杂度
时间：`O((m-k+1)(n-k+1) * k² log k)`，`log k` 来自每个窗口对 `k²` 个元素排序。
空间：`O(k²)` 存 `vals`，外加输出矩阵 `O((m-k+1)(n-k+1))`。

## 易错点
- `k == 1`（如示例 2 `[[3,-1]]`）→ 窗口内只有一个值，相邻差列表为空，`min()` 直接报错 → 应显式返回 `0`，因为题面规定全相同答案为 0。
- 窗口内有重复值（如 `[[2,2],[2,5]]`）→ 若先 `set` 去重再排序，`2` 与 `2` 的差 0 被抹掉，可能错答成 `3` → 保留重复元素，排序后相邻差自然出现 `0`，直接取最小即可。

## 如果面试官追问
问：m、n 放大到 200 且 k 固定较小，怎么优化？
答：用滑动窗口维护每列的有序结构，横向滑动时只删一列加一列，把每窗口重排换成增量更新。
