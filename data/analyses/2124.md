## 一句话思路
扫描时一旦见过 `'b'` 又遇到 `'a'`，就说明有 `'a'` 落在某个 `'b'` 之后，直接返回 `False`。

## 怎么做
1. 设布尔标记 `seen_b = False`，表示当前位置之前是否出现过 `'b'`。
2. 从左到右遍历 `s` 的每个字符 `c`。
3. 遇到 `'b'` 就把 `seen_b` 置 `True`；遇到 `'a'` 且 `seen_b` 已为 `True`，立即返回 `False`。
4. 遍历结束没触发返回，说明所有 `'a'` 都在第一个 `'b'` 之前，返回 `True`。

以 `s = "abab"` 为例：下标 0 是 `'a'`，`seen_b` 仍为 `False`，放行；下标 1 是 `'b'`，`seen_b` 变 `True`；下标 2 是 `'a'` 而 `seen_b == True`，此处返回 `False`——正是示例 2 要抓的那对「下标 2 的 a、下标 1 的 b」。

```python
seen_b = False
for c in s:
    if c == 'b':
        seen_b = True
    elif seen_b:
        return False
return True
```

等价的一行写法是 `return 'ba' not in s`：只要存在相邻的 `'ba'`，就必然存在一个 `'b'` 后面跟着 `'a'`；反之若所有 `'a'` 都在所有 `'b'` 之前，字符串必是若干个 `'a'` 接若干个 `'b'`，不可能出现 `'ba'` 子串。两种写法都成立，面试时先讲清 `seen_b` 的语义更稳。

## 复杂度
时间 O(n)：`n = len(s)`，每个字符最多看一次。
空间 O(1)：只开了一个 `seen_b` 布尔量，没有额外数组。

## 易错点
- 输入 `s = "bbb"` 或 `s = "aaa"` → 容易在循环里默认「必须同时出现 a 和 b」而返回 `False` → 正确做法是：没有 `'a'` 或没有 `'b'` 时条件空真，返回 `True`，`seen_b` 从头到尾没被 `'a'` 触发即可。
- 输入 `s = "ba"` → 若只比较「第一个 `'a'` 的下标」和「最后一个 `'b'` 的下标」却把边界写反（用 `>=` 或漏掉单字符情况），会把 `"ba"` 判成 `True` → 正确做法是严格用「遇到 `'a'` 时 `seen_b` 为真即失败」，`"ba"` 在下标 1 立刻返回 `False`。

## 如果面试官追问
问：如果字符集扩成 `'a'..'z'`，要求按字母序非递减排列怎么办？
答：改成记录上一个字符 `prev`，当前字符 `< prev` 就返回 `False`，仍是 O(n) 一趟扫描。
