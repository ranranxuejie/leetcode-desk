## 一句话思路
数每段连续 0 的长度 L，它对答案贡献 L*(L+1)//2，边扫边累加即可。

## 怎么做
1. 维护 `run` 表示当前连续 0 的长度，`ans` 存答案。
2. 遇到 `nums[i] == 0` 时 `run += 1`，并把 `run` 加到 `ans`（新增的以 i 结尾的全 0 子数组正好 `run` 个）。
3. 遇到非 0 时把 `run` 清零。
4. 返回 `ans`。

以示例 2 `[0,0,0,2,0,0]` 为例：i=0 时 `run=1, ans=1`；i=1 时 `run=2, ans=3`；i=2 时 `run=3, ans=6`；i=3 遇 2 清零；i=4 时 `run=1, ans=7`；i=5 时 `run=2, ans=9`。最终 9，与输出一致。

```python
ans = 0
run = 0
for x in nums:
    if x == 0:
        run += 1
        ans += run
    else:
        run = 0
return ans
```

关键点：`ans += run` 而不是 `ans += 1`，因为以当前位置结尾的全 0 子数组有 `run` 个（长度 1 到 run 各一个）。等价写法是分段后算 `L*(L+1)//2`，但边扫边加省一次遍历。

## 复杂度
时间 O(n)：一次遍历，每个元素只做常数次判断和加法。
空间 O(1)：只开 `ans`、`run` 两个变量，不复制数组。

## 易错点
- 输入 `[0,0,0]` → 若写成每遇 0 只 `ans += 1`，会得 3，正确是 6（长度 1 有 3 个、长度 2 有 2 个、长度 3 有 1 个）。必须 `ans += run`，让 `run` 随长度递增。
- 输入 `[1,3,0,0,2,0,0,4]` → 若在非 0 处忘记 `run = 0`，第二段 0 会接着第一段的长度算，`run` 变成 3、4，答案偏大成 10 而非 6。每个非 0 元素都要把 `run` 归零。

## 如果面试官追问
问：n 扩大到 10^9 且数组以游程编码给出怎么办？
答：按每段 0 的长度 L 直接算 `L*(L+1)//2` 累加，跳过非 0 段，时间只与段数有关。
