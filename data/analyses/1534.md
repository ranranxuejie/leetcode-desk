## 一句话思路
n≤100，三重循环枚举 i<j<k 并逐个校验三个绝对值条件即可，O(n³)=10⁶ 完全够用。

## 怎么做
1. 外层 `i` 从 0 到 n-3，中层 `j` 从 i+1 到 n-2，内层 `k` 从 j+1 到 n-1，天然保证 i<j<k。
2. 每层进入后先算 `abs(arr[i]-arr[j])`，超过 `a` 就 `continue`，省掉内层整轮。
3. 内层只校验 `abs(arr[j]-arr[k]) <= b` 和 `abs(arr[i]-arr[k]) <= c`，两条都成立才 `ans += 1`。
4. 返回 `ans`。

拿示例 1 走一遍：`arr = [3,0,1,1,9,7], a=7, b=2, c=3`。当 `i=0, j=1` 时 `abs(3-0)=3 <= 7` 通过；`k=2` 时 `abs(0-1)=1 <= 2`、`abs(3-1)=2 <= 3`，计数 +1；`k=3` 同理再 +1；`k=4` 时 `abs(0-9)=9 > 2` 被淘汰。最终 `i=0` 贡献 3 个，`i=1, j=2` 再贡献 1 个，合计 4。

```python
n = len(arr)
ans = 0
for i in range(n - 2):
    for j in range(i + 1, n - 1):
        if abs(arr[i] - arr[j]) > a:
            continue
        for k in range(j + 1, n):
            if abs(arr[j] - arr[k]) <= b and abs(arr[i] - arr[k]) <= c:
                ans += 1
return ans
```

注意 `abs(arr[i]-arr[j]) > a` 的剪枝放在 `j` 层，不是 `k` 层——它只跟 i、j 有关，提前判断能整轮跳过内层。

## 复杂度
时间：O(n³)，三层循环各贡献一个 n，剪枝只降常数不改阶。
空间：O(1)，只用了 `ans`、`i`、`j`、`k` 四个标量。

## 易错点
1. 循环上界写成 `range(n)` 或 `range(n-1)` → 会漏掉 `k` 的合法取值或让 `k` 越界 → 正确写法是 `i` 到 `n-2`、`j` 到 `n-1`、`k` 到 `n-1`，保证 `k` 最大取到 `n-1`。
2. 把 `abs(arr[i]-arr[j]) > a` 的剪枝误写成 `>= a` → 示例 1 中 `abs(3-0)=3` 与 `a=7` 无关，但若 `a=3` 时 `3 >= 3` 会误杀合法三元组 → 条件必须是严格大于才跳过。

## 如果面试官追问
问：n 放大到 10⁵ 怎么办？答：三重枚举失效，需按值域 0~1000 用前缀和/树状数组统计中间值落在 `[arr[j]-b, arr[j]+b]` 且与 `arr[i]` 差不超过 c 的 k 个数，降到 O(n·V) 或 O(n log V)。
