## 一句话思路
用两次二分分别求 target 的左右边界，右边界减左边界即出现次数。

## 怎么做
1. 写一个 `lower_bound(x)`：返回第一个 `>= x` 的下标，找不到返回 `len(scores)`。
2. 左边界 `lo = lower_bound(target)`，右边界 `hi = lower_bound(target + 1)`。
3. 答案就是 `hi - lo`，无需再判 target 是否存在。

以示例 1 的 `scores = [2,2,3,4,4,4,5,6,6,8], target = 4` 为例：`lower_bound(4)` 收敛到下标 3，`lower_bound(5)` 收敛到下标 6，`6 - 3 = 3`。示例 2 中 `lower_bound(6)` 和 `lower_bound(7)` 都返回 6，差为 0，天然覆盖不存在的情况。

```python
def lower_bound(x):
    l, r = 0, len(scores)
    while l < r:
        m = (l + r) // 2
        if scores[m] < x:
            l = m + 1
        else:
            r = m
    return l

lo = lower_bound(target)
hi = lower_bound(target + 1)
return hi - lo
```

关键在循环条件 `l < r` 配 `r = m`（不是 `m - 1`），区间是左闭右开，退出时 `l == r` 就是答案。`target + 1` 依赖数组是整数，若 target 是 `10**9` 也安全，Python 无溢出。

## 复杂度
时间 O(log n)：两次二分，每次区间减半，n 是 scores 长度。
空间 O(1)：只开了 l、r、m 几个整数变量。

## 易错点
- 输入 `scores = []`（长度可为 0）→ 若先取 `scores[0]` 判空会 IndexError → 直接走二分，`l = r = 0`，返回 0，不要额外特判。
- 输入 `scores = [4,4,4], target = 4` → 若把 `r = m` 写成 `r = m - 1`，`lower_bound(4)` 可能返回 0 之外的错位，导致 `hi - lo` 少算 → 求下界必须用 `r = m`，保持左闭右开。

## 如果面试官追问
问：数组改成非严格递减怎么办？
答：把比较改成 `scores[m] > x` 求第一个 `<= x` 的位置，或直接反转后复用同一份代码。
