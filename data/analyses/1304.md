## 一句话思路
取 `1..n-1` 再补一个负数抵消，用 `-n*(n-1)//2` 保证总和为 0 且互不相同。

## 怎么做
1. 先放 `1, 2, ..., n-1`，这 `n-1` 个数两两不同，和是 `n*(n-1)//2`。
2. 第 `n` 个数取 `-(n*(n-1)//2)`，总和立刻归零。
3. 验证这个负数不会撞上前面任何一个正数：它 ≤ -1，前面全是正数，天然不冲突。
4. `n == 1` 时 `1..0` 为空，补的数是 `-0 == 0`，返回 `[0]`，正好符合示例 3。

以 `n = 5` 为例：先得 `[1,2,3,4]`，和 `s = 5*4//2 = 10`，补 `-10`，结果 `[1,2,3,4,-10]`，和 `10 + (-10) = 0`，五个数互不相同。注意这跟官方示例 `[-7,-1,1,3,4]` 不是同一个答案，但题目要求「任意一个」，合法即可。

```python
def sumZero(n):
    res = list(range(1, n))          # 1..n-1
    s = n * (n - 1) // 2             # 前 n-1 项之和
    res.append(-s)                   # 抵消项
    return res
```

关键就一行 `-s`：`s` 是正数，所以补的项必为负，与 `1..n-1` 的正数集合不相交，唯一性不用额外判重。`n = 1` 时 `range(1,1)` 为空、`s = 0`、补 `0`，返回 `[0]`。

## 复杂度
时间 O(n)：`range` 生成 n-1 个数，`append` 一次。
空间 O(n)：结果数组本身占 n 个元素，无其他额外结构。

## 易错点
- `n = 1` → 若写成先放 `1..n` 再补 `-n*(n+1)//2`，会得到 `[1,-1]` 两个数，长度错成 2；正确做法是只放 `1..n-1`，让 `n=1` 时自然退化成 `[0]`。
- `n = 2` → 若用「正负对称」思路写 `[-n//2, n//2]` 之类，`n` 为偶数时容易凑出两个相同值或漏掉一个；本题用 `1..n-1` 加单个负数，`n=2` 得 `[1,-1]`，不会重复。

## 如果面试官追问
问：要求这 n 个数绝对值都不超过某个上界怎么办？
答：改用 `-(n//2)..-1` 配 `0`（n 为奇数）或 `1..n//2`（n 为偶数），最大绝对值只有 `n//2`。
