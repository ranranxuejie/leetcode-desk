## 一句话思路
每步贪心选当前剩余多的那个字母，若它已连续出现两次就改选另一个，保证任意时刻不会凑出三个相同。

## 怎么做
1. 维护 `res` 列表、剩余计数 `a`、`b`，循环 `a + b` 次。
2. 每轮判断：若 `a >= b` 且 `res` 末尾不是两个 `'a'`，就追加 `'a'` 并 `a -= 1`；否则追加 `'b'` 并 `b -= 1`。
3. 对称地，若 `b > a` 且末尾不是两个 `'b'`，追加 `'b'`；否则追加 `'a'`。
4. 循环结束 `''.join(res)` 即为答案。

以 `a = 4, b = 1` 为例：第 1、2 轮 `a >= b` 且末尾未满两个 `'a'`，`res` 变成 `"aa"`，此时 `a = 2`；第 3 轮 `a >= b` 但末尾已是 `"aa"`，改追加 `'b'`，`res = "aab"`、`b = 0`；第 4、5 轮只剩 `a`，`res` 依次变 `"aaba"`、`"aabaa"`，与示例一致。

```python
res = []
while a + b > 0:
    if a >= b and not (len(res) >= 2 and res[-1] == res[-2] == 'a'):
        res.append('a'); a -= 1
    elif b > a and not (len(res) >= 2 and res[-1] == res[-2] == 'b'):
        res.append('b'); b -= 1
    elif a > 0:
        res.append('a'); a -= 1
    else:
        res.append('b'); b -= 1
return ''.join(res)
```

关键在 `a >= b` 这个比较：它让多数派字母优先出场，而「末尾两个相同」这个条件负责在多数派连出两次后强制换边，两者配合就不会出现 `"aaa"` 或 `"bbb"`。

## 复杂度
时间 O(a + b)：循环恰好 a + b 轮，每轮 O(1) 判断与追加。
空间 O(a + b)：`res` 列表存下全部 a + b 个字符，join 时再开一份等长字符串。

## 易错点
- `a = 4, b = 1` 这类悬殊输入：若只写 `if a >= b` 而不检查末尾两个 `'a'`，会输出 `"aaaab"` 直接违规；必须把「末尾是否已连两个」作为追加前的硬条件。
- `a = 0, b = 2` 或 `a = 2, b = 0`：若循环里只写 `a >= b` 分支、没有 `elif a > 0` 兜底，当 `b > a` 但 `b` 已连两次时会走进空分支死循环；兜底分支保证每轮必追加一个字符。

## 如果面试官追问
问：若要求返回字典序最小的合法串怎么办？答：贪心时在「不违规」的候选里优先选 `'a'`，即把 `a >= b` 换成「`a > 0` 且追加 `'a'` 不违规就先选 `'a'`」，其余逻辑不变。
