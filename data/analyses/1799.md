## 一句话思路
用位掩码 `mask` 记录已删除元素，`dp[mask]` 存该状态最大得分，按已删个数推出当前操作编号。

## 怎么做
1. 预处理 `g[i][j] = gcd(nums[i], nums[j])`，避免重复计算。
2. 状态 `mask` 的二进制第 `k` 位为 1 表示 `nums[k]` 已删除；`dp[mask]` 表示删掉这些元素后的最大得分。
3. 当前操作编号 `i = popcount(mask) // 2 + 1`，因为每轮删两个。
4. 枚举 `mask` 中两个未删的下标 `j < k`，转移 `dp[mask | (1<<j) | (1<<k)] = max(..., dp[mask] + i * g[j][k])`。

以 `nums = [3,4,6,8]` 为例：`mask=0` 时 `i=1`，枚举到 `j=0,k=2` 得 `dp[0b0101] = 1 * gcd(3,6) = 3`；再从此状态出发 `i=2`，删 `4,8` 得 `3 + 2 * 4 = 11`，即答案。

```python
from math import gcd
m = len(nums)
g = [[gcd(nums[i], nums[j]) for j in range(m)] for i in range(m)]
dp = [0] * (1 << m)
for mask in range(1 << m):
    cnt = bin(mask).count("1")
    if cnt % 2:
        continue
    i = cnt // 2 + 1
    for j in range(m):
        if mask >> j & 1:
            continue
        for k in range(j + 1, m):
            if mask >> k & 1:
                continue
            nm = mask | (1 << j) | (1 << k)
            dp[nm] = max(dp[nm], dp[mask] + i * g[j][k])
return dp[(1 << m) - 1]
```

## 复杂度
时间：`O(2^(2n) * (2n)^2)`，`2n ≤ 14`，`mask` 与配对枚举各贡献一层。
空间：`dp` 数组 `O(2^(2n))`，`g` 表 `O((2n)^2)`。

## 易错点
- 对 `mask` 中已删个数为奇数的状态也做转移 → 会把 `i` 算错（如 `mask=0b1` 时 `i` 应为 1 却算成 1 后继续配对），正确做法是 `cnt % 2` 为奇数直接 `continue`。
- 只枚举 `j` 不限制 `k > j` → 同一对 `(j,k)` 被算两次，虽不改变最大值但白白翻倍耗时；正确做法是内层从 `j+1` 起，保证每对只出现一次。

## 如果面试官追问
问：`n` 放大到 15 怎么办？答：`2^30` 状态不可行，需换思路（如按 gcd 值分组贪心），本题规模下位掩码 DP 是标准解。
