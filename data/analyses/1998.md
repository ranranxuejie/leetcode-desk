## 一句话思路
用并查集把「共享质因子」的下标连成连通块，块内元素可任意重排，逐位比对排序后的目标值即可。

## 怎么做
1. 对每个 `nums[i]` 分解质因数，把质因子 `p` 与下标 `i` 合并（用 `p` 作虚拟节点，避免两两求 gcd 的 O(n²)）。
2. 建 `sorted(nums)` 作为目标数组，逐位检查 `nums[i]` 与目标值是否同块。
3. 同块则说明该位置能换到正确值，全部通过返回 `True`。

以 `nums = [7,21,3]` 为例：7 的质因子 7、21 的质因子 3 和 7、3 的质因子 3。下标 0 与 1 经质因子 7 连通，下标 1 与 2 经质因子 3 连通，三者同块；目标 `[3,7,21]` 每个位置都能对上，返回 `True`。而 `[5,2,6,2]` 中 5 的质因子 5 无人共享，下标 0 自成一块，目标首位是 2，不同块 → `False`。

```python
parent = list(range(n + maxv + 1))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
def union(a, b):
    ra, rb = find(a), find(b)
    if ra != rb: parent[ra] = rb
for i, v in enumerate(nums):
    x, p = v, 2
    while p * p <= x:
        if x % p == 0:
            union(i, n + p)
            while x % p == 0: x //= p
        p += 1
    if x > 1: union(i, n + x)
return all(find(i) == find(n + t) for i, t in enumerate(sorted(nums)))
```

注意 `n + p` 的偏移：质因子节点从 `n` 开始编号，`maxv = max(nums)` 保证不越界。

## 复杂度
时间 O(n·√maxv·α)，分解质因数贡献 √maxv，并查集近似常数。
空间 O(n + maxv)，parent 数组开了下标节点加质因子节点。

## 易错点
- 输入 `[2,1]` 类含 1 的数组（本题约束 ≥2 可忽略），但若放宽到 1：1 无质因子、永不连通，会被误判可换；正确做法是 1 单独成块且只与自身位置匹配。
- 分解时忘记 `while x % p == 0: x //= p` 剥离干净，如 `nums=[4,8]` 只连了质因子 2 却漏掉 4 的剩余，虽本例仍对，但 `[12,18]` 会漏连质因子 3 导致误判 `False`；正确做法是每个质因子都 union 一次并彻底除尽。

## 如果面试官追问
若要求输出具体交换方案？答：在并查集块内做置换分解，沿环逐次交换即可，块内元素两两可达故环必可拆。
