## 一句话思路
右指针扩张、左指针只在「相同相邻对」计数超过 1 时收缩，窗口内始终至多一对相等相邻字符。

## 怎么做
1. 用 `left`、`right` 维护窗口，`pairs` 记录窗口内相邻相等对的个数。
2. `right` 右移时，若 `s[right] == s[right-1]` 则 `pairs += 1`。
3. 当 `pairs > 1`，左移 `left`：若 `s[left] == s[left+1]` 则 `pairs -= 1`，再 `left += 1`。
4. 每轮用 `right - left + 1` 更新答案。

以 `s = "52233"` 为例：`right=3`（字符 `'3'`）时窗口 `"5223"`，`pairs=1`（只有 `22`），长度 4；`right=4` 时 `s[4]==s[3]` 使 `pairs=2`，左移 `left` 到 1 才把 `22` 移出，窗口变 `"2233"` 仍含两对，继续移到 `left=2`，窗口 `"233"` 长度 3，答案保持 4。

```python
left = pairs = ans = 0
for right in range(len(s)):
    if right > 0 and s[right] == s[right - 1]:
        pairs += 1
    while pairs > 1:
        if s[left] == s[left + 1]:
            pairs -= 1
        left += 1
    ans = max(ans, right - left + 1)
return ans
```

注意 `pairs` 的减法是「移出左端那一对」，所以判断条件是 `s[left] == s[left+1]`，不是 `s[left] == s[left-1]`。

## 复杂度
时间 O(n)：`right` 和 `left` 各走一遍字符串，每个字符最多进出窗口一次。
空间 O(1)：只开了 `left`、`pairs`、`ans` 三个整数。

## 易错点
- 输入 `"1111111"` → 若把 `pairs > 1` 写成 `pairs >= 1`，窗口会被压到长度 1，输出 1 而非 2 → 条件必须是「超过一对」才收缩，允许恰好一对。
- 输入 `"52233"` → 收缩时若用 `s[left] == s[left-1]` 判断，`left=0` 时越界或漏减 `22`，`pairs` 卡在 2 死循环 → 统一用 `s[left] == s[left+1]`，且 `while` 内先减 `pairs` 再 `left += 1`。

## 如果面试官追问
若要求输出最长子串本身而非长度？答：记录 `ans` 更新时的 `(left, right)`，最后返回 `s[best_l:best_r+1]`，逻辑不变。
