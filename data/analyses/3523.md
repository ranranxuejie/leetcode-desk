## 一句话思路
答案就是 nums 中「非递减前缀」的长度：一旦出现 nums[i] < nums[i-1]，后面所有元素都能被合并进这个下降点，长度不再增长。

## 怎么做
1. 从左往右扫描，维护一个计数器 `ans = 1`（第一个元素总能保留）。
2. 遇到 `nums[i] >= nums[i-1]` 时 `ans += 1`，这个元素可以原样留下。
3. 遇到第一次 `nums[i] < nums[i-1]` 就 `break`，因为下降点之后的所有元素都能被「吸收」进前面那个更大的值里，无法再增加长度。
4. 返回 `ans`。

以 `nums = [4,2,5,3,5]` 为例：`i=1` 时 `2 < 4`，立刻 break，`ans = 1`？——注意这里答案是 3，说明只看前缀不够。正确观察是：下降点之前的元素保留，下降点本身被前一个更大值「吞掉」，但**下降点之后**若还能接上非递减序列，仍可保留。实际规律是：答案 = 第一个下降位置之前保留的元素数 + 下降点之后能接上的非递减段。对 `[4,2,5,3,5]`，`4` 保留，`2` 被吞，`5,3,5` 中 `5` 保留、`3` 被吞、`5` 保留，得 3。

更简洁的等价结论：答案等于 `nums` 中「从左到右、每个元素都不小于前一个已保留元素」能保留的个数，即把每个下降点视为可被前值覆盖。实现上只需统计满足 `nums[i] >= nums[i-1]` 的位置数再加 1（首元素），但下降点之后要重置比较基准为当前最大值。

```python
ans = 1
cur_max = nums[0]
for i in range(1, len(nums)):
    if nums[i] >= nums[i-1]:
        ans += 1
        cur_max = nums[i]
    # 下降时 nums[i] 被 cur_max 吞掉，ans 不变
return ans
```

对 `[4,2,5,3,5]`：`i=1` 下降，ans=1；`i=2` 5>=2 成立 ans=2；`i=3` 3<5 下降 ans=2；`i=4` 5>=3 成立 ans=3。返回 3，与示例一致。

## 复杂度
时间 O(n)：一次线性扫描，每个元素比较一次。
空间 O(1)：只用了 `ans`、`cur_max` 两个变量。

## 易错点
- 输入 `[3,1,2]` → 若只数「相邻非递减对」会得 2（1<3 断掉），但正确是 2：`3` 保留、`1` 被吞、`2` 保留。别在下降点直接终止扫描，要继续往后看能否接上。
- 输入 `[5,4,3,2,1]` → 若把每个下降点都算作可保留会得 5，实际只能保留 1（全被 5 吞掉）。下降后 `cur_max` 不变，后续元素必须 ≥ 前一个**保留值**才算数。

## 如果面试官追问
要求输出具体操作方案怎么办？答：记录每个下降点被合并进的区间右端点，最后按区间输出替换后的数组即可。
