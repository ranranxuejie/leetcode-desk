## 一句话思路
把有向边拆成「正向代价 0、反向代价 1」的无向树，先以 0 为根 DFS 求出 answer[0]，再用换根 DP 沿树边 O(1) 推出其余节点。

## 怎么做
1. 建邻接表 `g[u]` 存 `(v, w)`：原边 `u→v` 存 `(v, 0)`，同时在 `g[v]` 存 `(u, 1)`，w 表示「从当前点走到对面点」要不要反转。
2. 以 0 为根 DFS，累加路径上的 w 得到 `ans[0]`。用示例 1 `edges=[[2,0],[2,1],[1,3]]`：从 0 出发只有边 `0→2` 是反的，`ans[0]=1`。
3. 换根：设 `u` 是 `v` 的父节点，边权为 `w`（从 u 走向 v 的代价）。则 `ans[v] = ans[u] + (1 if w == 0 else -1)`——原来顺着的边变成逆着，原来逆着的变顺。
4. 对示例 1 从 2 推：`ans[2]=0`，边 `2→0` 权 0，`ans[0]=0+1=1`；边 `2→1` 权 0，`ans[1]=1`；边 `1→3` 权 0，`ans[3]=ans[1]+1=2`，与输出 `[1,1,0,2]` 一致。

```python
def dfs(u, p, cost):
    ans[u] = cost
    for v, w in g[u]:
        if v != p:
            dfs(v, u, cost + w)

dfs(0, -1, 0)                      # 第一遍：定 ans[0]
stack = [(0, -1)]
while stack:                       # 第二遍：换根
    u, p = stack.pop()
    for v, w in g[u]:
        if v != p:
            ans[v] = ans[u] + (1 if w == 0 else -1)
            stack.append((v, u))
```

## 复杂度
时间 O(n)：建图遍历 2(n-1) 条邻接项，两遍 DFS 各 O(n)。
空间 O(n)：邻接表存 2(n-1) 个二元组，ans 与栈各 O(n)。

## 易错点
1. 邻接表只存单向边 → 从 0 出发 DFS 走不到「箭头指向 0」的那些子树，`ans[0]` 偏小。必须每条输入边双向各存一次，且反向那条的权是 1，否则换根时 `w` 判断全错。
2. 换根公式写成 `ans[v] = ans[u] + w` → 示例 1 会得 `ans[0]=1, ans[1]=1, ans[3]=1`，但正确答案 `ans[3]=2`。正确是「父边顺（w=0）则 +1，父边逆（w=1）则 -1」，因为视角从 u 换到 v 时这条边的方向意义翻转了。

## 如果面试官追问
问：n 放大到 10^6、递归会爆栈怎么办？
答：两遍 DFS 都改成显式栈迭代，第一遍压 `(u, p, cost)` 三元组即可，逻辑不变。
