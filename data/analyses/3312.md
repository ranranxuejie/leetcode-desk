## 一句话思路
用倍数容斥统计每个 gcd 值对应的数对个数，再前缀和 + 二分回答查询。

## 怎么做
1. 统计 `nums` 中每个值的出现次数 `cnt[v]`，值域上界 `M = max(nums)`。
2. 从大到小枚举 `g`，先算 `s = sum(cnt[g], cnt[2g], ...)`，即能被 `g` 整除的元素个数，`s*(s-1)//2` 是这些元素两两配对的总数。
3. 减去所有 `g` 的真倍数已经统计到的数对，剩下的就是 gcd 恰好为 `g` 的数对个数 `exact[g]`。
4. 对 `exact` 做前缀和得到 `pref`，每个查询 `q` 用 `bisect_right(pref, q)` 找到第一个前缀和大于 `q` 的下标，即答案。

以 `nums = [4,4,2,1]` 为例：`cnt[4]=2, cnt[2]=1, cnt[1]=1`。`g=4` 时 `s=2`，`exact[4]=1`；`g=2` 时 `s=3`（4,4,2），总数 3，减去 `exact[4]=1`，得 `exact[2]=2`；`g=1` 时 `s=4`，总数 6，减去 `exact[2]+exact[4]=3`，得 `exact[1]=3`。前缀和 `[3,5,6]`，查询 5 落在下标 2，答案 4。

```python
M = max(nums)
cnt = [0] * (M + 1)
for v in nums:
    cnt[v] += 1
exact = [0] * (M + 1)
for g in range(M, 0, -1):
    s = sum(cnt[g::g])
    exact[g] = s * (s - 1) // 2 - sum(exact[2*g::g])
pref = list(accumulate(exact))
return [bisect_right(pref, q) for q in queries]
```

## 复杂度
时间：`O(M log M + Q log M)`，调和级数枚举倍数贡献 `M log M`，`Q` 次二分。
空间：`O(M)`，`cnt`、`exact`、`pref` 三个长度 `M+1` 的数组。

## 易错点
- `nums = [2,2]` 这类全相同输入：若只算 `s*(s-1)//2` 不减去真倍数，`exact[2]` 会重复计入 `exact[1]` 的部分，导致前缀和偏大、查询 0 返回 1 而非 2。正确做法是从大到小枚举，用 `exact[2*g::g]` 的和扣除。
- `queries[i]` 可能等于 `n*(n-1)/2 - 1`（最大下标）：若前缀和数组末尾没覆盖到最大 gcd 值，`bisect_right` 会越界返回 `M+1`。正确做法是 `pref` 长度取 `M+1`，且 `exact[M]` 必须被计算（`g=M` 时 `s=cnt[M]`）。

## 如果面试官追问
若 `nums[i]` 上界从 `5*10^4` 提到 `10^9` 怎么办？答：值域太大不能开桶，改用哈希表存出现过的值，只对出现值的约数做容斥，复杂度转为按不同值个数分摊。
