## 一句话思路
用计数器 `depth` 记录当前嵌套深度，只在 `depth > 0` 时把字符加入结果，遇到 `(` 先加深度、遇到 `)` 后减深度。

## 怎么做
1. 初始化 `depth = 0`、`res = []`。
2. 遍历 `s` 的每个字符 `c`：若 `c == '('`，先 `depth += 1`，再判断 `depth > 1` 才 `res.append(c)`。
3. 若 `c == ')'`，先判断 `depth > 1` 才 `res.append(c)`，再 `depth -= 1`。
4. 返回 `''.join(res)`。

以 `s = "(()())(())"` 为例，走到第 2 个字符（下标 1）时 `depth` 从 1 变 2，这个 `(` 被保留；走到下标 5 的 `)` 时 `depth` 仍为 2，先保留再减到 1——它正是第一个原语 `(()())` 的收尾括号，被正确删掉。整串跑完 `res` 拼出 `"()()()"`。

```python
depth = 0
res = []
for c in s:
    if c == '(':
        depth += 1
        if depth > 1:
            res.append(c)
    else:
        if depth > 1:
            res.append(c)
        depth -= 1
return ''.join(res)
```

关键在顺序：`(` 是「先加后判」，`)` 是「先判后减」。这样 `depth` 在判断时刻恰好表示「这个字符处于第几层」，最外层（第 1 层）的两个括号都被 `depth > 1` 挡掉，而原语内部的所有括号 `depth >= 2` 全部保留。

## 复杂度
时间 O(n)：`s` 每个字符进出循环一次，`join` 再扫一遍结果。
空间 O(n)：`res` 最多存 n-2k 个字符，`depth` 是 O(1)。

## 易错点
- 输入 `s = "()()"` → 若把 `)` 写成「先减后判」，第一个 `)` 减完 `depth` 变 0，`depth > 1` 为假仍能删对，但 `s = "(())"` 时内层 `)` 会因先减到 1 被误删，输出 `"("` → 正确做法是 `)` 先判 `depth > 1` 再减。
- 输入 `s = "(()(()))"` → 若用「遇到 `(` 就跳过、遇到 `)` 就跳过」的朴素配对思路，会把内层 `()` 也删掉，输出 `"(())"` 而非 `"()(())"` → 必须靠 `depth` 区分层级，只有第 1 层的括号才删。

## 如果面试官追问
问：若要求返回每个原语删除外层后的列表而非拼接串？
答：在 `depth` 减到 0 时把当前 `res` 段切出来 append 到列表，再清空 `res` 即可。
