## 一句话思路
把 n 转成三进制，逐位检查是否出现数字 2，出现即说明该幂次被用了两次以上，返回 False。

## 怎么做
1. 循环取 `n % 3` 得到当前最低位三进制数字。
2. 若该位等于 2，直接返回 `False`（同一个 3^k 用了两次，违反“不同”）。
3. 否则 `n //= 3` 右移一位，继续检查下一位。
4. 循环结束（n 归零）返回 `True`。

以 n = 21 为例：`21 % 3 = 0`，n 变 7；`7 % 3 = 1`，n 变 2；`2 % 3 = 2` —— 命中，返回 `False`。对应 21 = 2·3^0 + 1·3^1 + 2·3^2 里 3^0 和 3^2 各需两份，无法用不同幂凑出。

```python
def checkPowersOfThree(n: int) -> bool:
    while n > 0:
        if n % 3 == 2:
            return False
        n //= 3
    return True
```

关键点：三进制每一位只能是 0/1/2，0 表示该幂不取，1 表示取一次，2 表示取两次——而题目要求每个幂最多取一次，所以合法表示恰好对应“三进制无 2”。

## 复杂度
时间：O(log₃ n)，每轮 `n //= 3` 缩小三倍，n = 10^7 时约 15 轮。
空间：O(1)，只用了 n 本身和循环变量，没开数组。

## 易错点
- n = 3（三进制 10）→ 若写成“n 能被 3 整除就返回 False”会错判成 False，实际 3 = 3^1 合法；正确做法是只看余数是否为 2，余数 0 和 1 都继续。
- n = 12 → 若用“不断减去最大的 3 的幂”贪心，减 9 剩 3 再减 3 得 0 看似可行，但 n = 21 时贪心减 9 剩 12、减 9 又超，容易陷入死循环或误判；正确做法是进制分解而非贪心减法。

## 如果面试官追问
问：要求输出具体方案（哪些 3 的幂）怎么办？
答：三进制分解时把余数为 1 的位下标 i 收集起来，即得 3^i 列表。
