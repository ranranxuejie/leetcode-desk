## 一句话思路
答案恒为 `False`：取 `b = n - 2`，n 在该进制下必为 `12`，不是回文。

## 怎么做
1. 直接 `return False`，不做任何进制转换。
2. 关键推理：`b = n - 2` 落在允许区间 `[2, n-2]` 内（`n >= 4` 保证 `n-2 >= 2`）。
3. 此时 `n = 1*(n-2) + 2`，即表示为两位 `"12"`，首位 `1` 与末位 `2` 不等。
4. 以 `n = 9` 验证：`b = 7`，`9 // 7 = 1`、`9 % 7 = 2`，得 `"12"`，非回文，故 `9` 返回 `False`。

```python
# 只需这一行
return False

# 若想显式验证思路（非提交版）：
# b = n - 2
# digits = [n // b, n % b]   # n=9 -> [1, 2]
# digits == digits[::-1]     # False
```

`n = 4` 时 `b = 2`，`4 = 100`（三位），首位 `1` 末位 `0`，同样非回文——注意 `n-2` 进制下 `n` 恰好是两位数 `"12"`，而 `b=2` 时 `4` 是三位，两者不冲突，因为 `4` 的 `n-2` 进制就是 `b=2`，`4 = 1*2 + 2` 不成立（余数必须小于基数），实际 `4 = 100`。这里要小心：`n-2` 进制下 `n` 表示为 `"12"` 的前提是 `2 < n-2`，即 `n > 4`；`n = 4` 时 `b = 2`，`2` 不小于基数 `2`，退化为 `"100"`，仍非回文。所以 `n = 4` 单独成立，结论不变。

## 复杂度
时间：O(1)，不进行任何进制转换或循环。
空间：O(1)，只返回一个布尔常量。

## 易错点
- 输入 `n = 4` → 若机械套用「`n-2` 进制是 `12`」会误判 `b=2` 下 `4` 为 `"12"`，实际是 `"100"` → 正确做法是记住 `n=4` 时 `b=2`，`4` 的二进制 `100` 非回文，结论仍为 `False`。
- 输入任意 `n` → 若真去枚举 `b` 从 `2` 到 `n-2` 逐个转进制判回文，`n=10^5` 时约 `10^5` 次转换、每次 O(log n)，虽能过但白费 → 正确做法是直接返回 `False`，因为 `b=n-2` 这一档已经反例。

## 如果面试官追问
问：如果改成「存在某个 b 使回文」怎么求？答：从 `b=2` 枚举到 `n-2`，每个转进制双指针判回文，`n` 大时用 `n-1` 进制恒为 `"11"` 先短路。
