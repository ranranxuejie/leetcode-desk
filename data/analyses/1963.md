## 一句话思路
从左到右累计未匹配的 `]` 数，记下它的最大值 `mx`，答案就是 `(mx + 1) // 2`。

## 怎么做
1. 用 `bal` 表示当前未匹配的闭括号数：遇到 `]` 就 `bal += 1`，遇到 `[` 就 `bal -= 1`。
2. 用 `mx` 记录 `bal` 在整个扫描过程中的最大值，它代表最深的“欠债”。
3. 一次交换能把一个 `]` 换到后面、一个 `[` 换到前面，正好消掉两层欠债，所以答案是 `(mx + 1) // 2`。

以 `s = "]]][[["` 为例：扫描到下标 2 时 `bal = 3`，`mx = 3`；后面三个 `[` 把 `bal` 拉回 0，但 `mx` 保持 3，答案 `(3 + 1) // 2 = 2`，与示例一致。

```python
bal = 0
mx = 0
for ch in s:
    if ch == ']':
        bal += 1
        if bal > mx:
            mx = bal
    else:
        bal -= 1
return (mx + 1) // 2
```

关键点：`mx` 只看前缀，不看最终 `bal`（最终必为 0，因为 `[` 和 `]` 各占一半），所以不能拿 `bal` 的末值算答案。

## 复杂度
时间 O(n)：一次线性扫描，每个字符只判断一次。
空间 O(1)：只开 `bal`、`mx` 两个整数，不建栈。

## 易错点
- 输入 `"][]["`：若只看最终 `bal = 0` 就返回 0，会错成“已平衡”；实际扫描到下标 0 时 `bal = 1`、`mx = 1`，答案应为 `(1+1)//2 = 1`。必须用前缀最大值。
- 输入 `"[]"`：若把 `mx` 初始化成 1 或把公式写成 `mx // 2 + 1`，会错成 1；`mx` 必须初始化为 0，`"[]"` 全程 `bal` 不超 0，答案 0。

## 如果面试官追问
问：如果允许交换任意两个字符（不限于括号），答案会变吗？
答：不会，因为 `[` 和 `]` 数量固定，最优仍是把靠前的 `]` 与靠后的 `[` 对换，公式不变。
