## 一句话思路
用入度出度数组：法官的入度必须是 n-1、出度必须是 0，其余人都不满足。

## 怎么做
1. 开两个长度 n+1 的数组 `in_deg`、`out_deg`，下标直接用人的编号 1..n。
2. 遍历 `trust` 中每条 `[a, b]`，`out_deg[a] += 1`、`in_deg[b] += 1`。
3. 从 1 到 n 扫一遍，找 `in_deg[i] == n-1 and out_deg[i] == 0` 的人，找到就返回 i。
4. 扫完没找到返回 -1。

以示例 2 `n = 3, trust = [[1,3],[2,3]]` 为例：遍历后 `in_deg = [0,0,0,2]`、`out_deg = [0,1,1,0]`。扫到 i=3 时 `in_deg[3] == 2 == n-1` 且 `out_deg[3] == 0`，返回 3。

```python
in_deg = [0] * (n + 1)
out_deg = [0] * (n + 1)
for a, b in trust:
    out_deg[a] += 1
    in_deg[b] += 1
for i in range(1, n + 1):
    if in_deg[i] == n - 1 and out_deg[i] == 0:
        return i
return -1
```

关键点：两个条件必须同时查。只查 `in_deg[i] == n-1` 时，示例 3 的 3 号入度为 2 会被误判；只查 `out_deg[i] == 0` 时，示例 3 的 1 号出度为 1 但 2 号出度为 1，仍可能漏判。两个条件合起来才唯一。

## 复杂度
时间：O(n + len(trust))，遍历 trust 一次、扫 1..n 一次。
空间：O(n)，`in_deg` 和 `out_deg` 各开 n+1 个槽。

## 易错点
1. 输入 `n = 1, trust = []` → 若把「法官入度为 n-1 = 0」当成不成立而返回 -1，就错了；正确做法是 1 号入度 0、出度 0，满足条件应返回 1。空 trust 时唯一的人天然是法官。
2. 输入 `n = 3, trust = [[1,3],[2,3],[3,1]]` → 若只统计入度，3 号入度 2 会被误返回；正确做法是同时检查 `out_deg[3] == 1 != 0`，排除后返回 -1。出度非零说明法官信任了别人，直接否决。

## 如果面试官追问
问：如果 trust 规模涨到 10^7 且内存受限，怎么改？
答：不建两个数组，只用一个 `score` 数组：`score[b] += 1`、`score[a] -= 1`，最后找 `score[i] == n-1` 的人，空间仍是 O(n) 但省一半。
