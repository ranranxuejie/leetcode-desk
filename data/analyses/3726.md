## 一句话思路
逐位取余剥出数字，非零位按位权累加进结果，零位直接跳过。

## 怎么做
1. 用 `place = 1` 记录当前位的位权，`res = 0` 记录答案。
2. 循环 `while n > 0`，每次取 `d = n % 10`，再 `n //= 10`。
3. 若 `d != 0`，执行 `res += d * place`，然后 `place *= 10`；若 `d == 0`，`place` 不变。
4. 返回 `res`。

以 `n = 1020030` 为例，从低位剥：`d=0` 跳过（`place` 仍为 1）；`d=3` 得 `res=3, place=10`；`d=0` 跳过；`d=0` 跳过；`d=2` 得 `res=23, place=100`；`d=0` 跳过；`d=1` 得 `res=123, place=1000`。关键点是**零位不推进 `place`**，所以 2 落在十位、1 落在百位，中间的空洞被自动压缩掉。

```python
place = 1
res = 0
while n > 0:
    d = n % 10
    n //= 10
    if d != 0:
        res += d * place
        place *= 10
return res
```

## 复杂度
时间：O(log n)，循环次数等于 n 的十进制位数。
空间：O(1)，只用了 `place`、`res`、`d` 三个整数。

## 易错点
- 输入 `n = 1000` → 若把 `place *= 10` 写在 `if` 外面，会得到 `res = 1` 但位权被推高到 10000，后续若还有非零位就整体错位；正确做法是只在 `d != 0` 时推进 `place`。
- 输入 `n = 1020030` → 若先把 n 转成字符串再 `replace("0","")` 再 `int()`，遇到 `n = 1000` 会得到空串 `""`，`int("")` 直接抛 `ValueError`；本题保证 n 是正整数且至少有一位非零，但用字符串法时仍要先判空或改用 `int(s) if s else 0`，而取余法天然没有这个分支。

## 如果面试官追问
问：如果 n 大到 10^1000 超出整数范围怎么办？
答：按字符串从右往左扫，遇到非零字符就追加到结果尾部，最后反转，同样 O(位数) 时间。
