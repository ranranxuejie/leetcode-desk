## 一句话思路
按左端点排序后枚举窗口右端落在哪个区间，用前缀和 O(1) 算出「以该点为结尾的 k 个袋子」的硬币数，取最大。

## 怎么做
1. 把 `coins` 按 `l` 升序排序，并预处理前缀和 `pre[i]` = 前 i 个区间（按排序后顺序）的硬币总数。
2. 枚举每个区间 `i` 作为窗口右端所在区间，窗口左端 `start = r_i - k + 1`。
3. 二分找到第一个 `l_j >= start` 的区间 `j`，则 `[j, i-1]` 整段被窗口完全覆盖，用前缀和一次取出。
4. 对区间 `j-1` 单独算它被窗口覆盖的那一段（可能为 0），加上去更新答案。

以示例 1 为例：排序后 `[[1,3,2],[5,6,4],[8,10,1]]`，前缀和 `pre = [0,6,14,17]`。取 `i=1`（区间 `[5,6,4]`），`start = 6-4+1 = 3`，二分得 `j=1`，整段区间为空，只剩 `j-1=0` 的 `[1,3,2]` 被覆盖 `[3,3]` 一段，贡献 `2`，加上 `[5,6]` 的 `4+4=8`，得 `10`。

```python
coins.sort()
pre = [0]
for l, r, c in coins:
    pre.append(pre[-1] + (r - l + 1) * c)
ans = 0
for i, (l, r, c) in enumerate(coins):
    start = r - k + 1
    j = bisect_left(coins, [start])          # 第一个 l >= start
    total = pre[i] - pre[j]                  # [j, i-1] 整段
    if j > 0:                                # 处理 j-1 的残余部分
        pl, pr, pc = coins[j - 1]
        total += (min(pr, r) - max(pl, start) + 1) * pc
    ans = max(ans, total)
```

## 复杂度
时间：排序 O(n log n)，每个区间一次二分 O(n log n)，n 为 `coins.length`。
空间：前缀和数组 O(n)，无其他额外结构。

## 易错点
- `k` 大于所有区间总长度时，`start` 会落到最左区间左边，`j=0` 且 `j-1` 不存在，残余部分必须跳过；若直接访问 `coins[-1]` 会取到最右区间，答案虚高。
- 残余区间 `j-1` 与窗口可能完全不相交（如 `start > pr`），此时 `min(pr,r) - max(pl,start) + 1` 为负，必须 `max(0, ...)` 或先判交，否则减掉一段不存在的硬币。

## 如果面试官追问
若 `k` 固定但要求输出具体坐标区间？答：在更新 `ans` 时同步记录 `i` 和 `start`，最后按 `[start, r_i]` 还原即可。
