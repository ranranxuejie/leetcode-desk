## 一句话思路
先按 `project_id` 把 Project 与 Employee 连接，再分组求 `experience_years` 的均值并保留两位小数。

## 怎么做
1. 用 `Project.employee_id = Employee.employee_id` 做内连接，把每个项目行补上年限。
2. 以 `project_id` 分组，对 `experience_years` 求平均。
3. 用 `ROUND(..., 2)` 把均值截到两位小数，并起别名 `average_years`。

以示例 1 的 project_id=1 为例：连接后得到三行年限 3、2、1，`AVG` 得 `6/3 = 2.0`，`ROUND(2.0, 2)` 输出 `2.00`；project_id=2 得 `(3+2)/2 = 2.5`，输出 `2.50`。

```python
# 伪代码：SQL 逻辑
# SELECT p.project_id,
#        ROUND(AVG(e.experience_years), 2) AS average_years
# FROM Project p
# JOIN Employee e ON p.employee_id = e.employee_id
# GROUP BY p.project_id;

# 若用 pandas 模拟：
merged = project.merge(employee, on="employee_id")
result = (merged.groupby("project_id")["experience_years"]
                .mean().round(2).reset_index(name="average_years"))
```

关键点：`AVG` 在 SQL 中自动忽略 NULL，但题面保证 `experience_years` 非空，所以分母就是该项目的人数，不需要额外处理。

## 复杂度
时间：连接 O(P + E)，分组聚合 O(P)，P 为 Project 行数、E 为 Employee 行数。
空间：分组哈希表 O(不同 project_id 数)，结果集同量级。

## 易错点
1. 用 `LEFT JOIN` 而非 `JOIN`：若某 project 在 Employee 中无匹配员工（外键约束下不会发生，但若数据异常），`AVG(NULL)` 返回 NULL，输出该行 `average_years` 为 NULL 而非报错；正确做法是用内连接，保证只统计有员工的项目。
2. 忘记 `ROUND(..., 2)`：示例 1 中 project_id=2 的均值是 2.5，直接输出会变成 `2.5` 而非要求的 `2.50`；必须显式保留两位小数，且注意 `ROUND` 是四舍五入而非截断。

## 如果面试官追问
问：如果要求同时输出项目名称和员工人数？答：在 `GROUP BY` 中加 `COUNT(e.employee_id) AS cnt`，项目名从 Project 表取（需确认 Project 表是否有 name 列，本题没有则需额外关联）。
