## 一句话思路
只需检查当前边与前 3、4、5 条边的三种相交形态，因为更早的边已被更近的边隔开，不可能再相交。

## 怎么做
1. 从 `i = 3` 开始遍历，每条新边只可能撞上 `i-3`（对面平行）、`i-4`（垂直）、`i-5`（同向平行）三条边。
2. 形态一：`d[i] >= d[i-2] and d[i-1] <= d[i-3]`，当前边穿过 `i-3` 那条边。
3. 形态二：`d[i-1] == d[i-3] and d[i] + d[i-4] >= d[i-2]`，当前边撞上 `i-4` 那条边。
4. 形态三：`d[i-2] > d[i-4] and d[i-3] > d[i-1] and d[i] + d[i-4] >= d[i-2] and d[i-1] + d[i-5] >= d[i-3]`，当前边撞上 `i-5` 那条边。

拿 `distance = [2,1,1,2]` 走一遍：`i=3` 时 `d[3]=2 >= d[1]=1` 且 `d[2]=1 <= d[0]=2`，形态一成立，返回 `True`。这里的关键中间量是 `d[i-2]=1` 与 `d[i-3]=2` 的比较——南向边只走了 1 米，没回到起点高度，所以东向边必然横穿北向边。

```python
for i in range(3, len(d)):
    if d[i] >= d[i-2] and d[i-1] <= d[i-3]:
        return True
    if i >= 4 and d[i-1] == d[i-3] and d[i] + d[i-4] >= d[i-2]:
        return True
    if i >= 5 and d[i-2] > d[i-4] and d[i-3] > d[i-1] \
       and d[i] + d[i-4] >= d[i-2] and d[i-1] + d[i-5] >= d[i-3]:
        return True
return False
```

## 复杂度
时间 O(n)：一次遍历 `distance`，每条边做常数次比较。
空间 O(1)：只用到下标 `i` 和几个相邻元素，没有额外数组。

## 易错点
- `distance = [1,1,1,1]` → 只写形态一会漏判：`i=3` 时 `d[3]=1 >= d[1]=1` 且 `d[2]=1 <= d[0]=1` 其实成立，但若把条件写成严格大于 `>` 就会返回 `False`。相等即相撞，必须用 `>=` 和 `<=`。
- `distance = [1,1,2,1,1]` → 形态二里漏掉 `d[i] + d[i-4] >= d[i-2]` 的加法项，只看 `d[i-1] == d[i-3]` 会误判。当前边必须够长才能顶到对面那条边，长度不够只是擦肩。

## 如果面试官追问
问：`distance` 长度到 10^5 但值到 10^9，会溢出吗？
答：Python 整数无上限，加法比较直接用；若换 C++ 需注意 `d[i] + d[i-4]` 可能超 `2**31 - 1`，要开 `long long`。
