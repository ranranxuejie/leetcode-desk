## 一句话思路
只看奇偶性：若 nums1 奇偶混杂，任一元素都能借另一个不同奇偶的元素做差翻成任意奇偶，故必 true；只有全同奇偶时才需检查。

## 怎么做
1. 统计 nums1 中奇数的个数 `odd`，偶数个数即 `n - odd`。
2. 若 `odd` 既不为 0 也不为 n，直接返回 `True`——混杂时每个元素都能改奇偶。
3. 若全偶（`odd == 0`），nums2 全偶天然成立，返回 `True`。
4. 若全奇（`odd == n`），差值为偶数、原值为奇数，nums2 只能全奇，也返回 `True`。

等等——按此推理答案恒为 true？关键在 n == 1：此时没有 `j != i`，nums2[0] 只能是 nums1[0]，全奇或全偶都成立，仍为 true。所以本题对任意合法输入都返回 `True`。

用示例 1 验证：`nums1 = [2,3]`，`odd = 1`，`0 < 1 < 2`，混杂分支命中，返回 `True`，与 `2 - 3 = -1`（奇）一致。

```python
def uniformArray(nums1):
    n = len(nums1)
    odd = sum(x % 2 for x in nums1)
    if 0 < odd < n:
        return True          # 混杂：每个元素都能翻奇偶
    return True              # 全奇或全偶：保持原值即可
```

（若面试要求写出「为什么全奇也成立」：全奇时 `nums1[i] - nums1[j]` 为偶数，选原值即得全奇数组。）

## 复杂度
时间：O(n)，`sum` 遍历一次 nums1，无 log 项。
空间：O(1)，只开 `odd` 一个计数器。

## 易错点
- 看到「全奇」就以为要构造偶数：`nums1 = [1,3,5]` 时误判 false。实际选原值即全奇，返回 true。
- 把 n == 1 当特例排除：`nums1 = [7]` 时误以为无 j 可选而返回 false。实际 nums2[0] = 7 已是全奇，返回 true。

## 如果面试官追问
问：若要求返回具体 nums2 而非布尔值？答：混杂时对每个 i 找异奇偶的 j 做差翻奇偶，全同奇偶时直接复制 nums1。
