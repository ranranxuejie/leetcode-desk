## 一句话思路
把 1 的位置抽成数组 `pos`，枚举「连续段 + 若干次造 1」，用前缀和 O(1) 算中位数聚合代价。

## 怎么做
1. 记 `pos` 为所有 1 的下标，`m = len(pos)`；造一个 1 并搬到身边固定花 2 次行动（造 1 一次、交换一次）。
2. 先算「只用造 1」的答案：若 `k <= maxChanges`，代价 `2*k`；否则用掉全部 `maxChanges`，剩 `k - maxChanges` 个必须来自真实 1。
3. 真实 1 的个数 `need = k - maxChanges`，在 `pos` 上滑长度 `need` 的窗口，窗口内全部搬到窗口中位数处最省，用前缀和算。
4. 答案取「纯造 1」与「窗口代价 + 2*maxChanges」的较小值。

用示例 1：`nums = [1,1,0,0,0,1,1,0,0,1]`，`pos = [0,1,5,6,9]`，`k=3, maxChanges=1`，故 `need=2`。窗口 `[0,1]` 中位数取 0 或 1，代价 1，加 `2*1=2` 得 3，与输出一致。

```python
pos = [i for i, v in enumerate(nums) if v]
pre = [0]
for p in pos:
    pre.append(pre[-1] + p)
need = k - maxChanges
ans = 2 * k if k <= maxChanges else 2 * maxChanges + (k - maxChanges) * 2
for l in range(len(pos) - need + 1):
    r = l + need - 1
    mid = (l + r) // 2
    left = pos[mid] * (mid - l) - (pre[mid] - pre[l])
    right = (pre[r + 1] - pre[mid + 1]) - pos[mid] * (r - mid)
    ans = min(ans, left + right + 2 * maxChanges)
```

## 复杂度
时间：`pos` 长度 m ≤ n，滑窗 O(m)，前缀和 O(m)，总 O(n)。
空间：`pos` 与 `pre` 各 O(m)，即 O(n)。

## 易错点
- `k <= maxChanges` 时若仍进滑窗，`need <= 0`，`range` 为空但初值写成 `2*maxChanges + need*2` 会得负数 → 初值必须单独分支给 `2*k`。
- 窗口代价用 `pos[mid]` 做基准时，右半段前缀和要取 `pre[r+1] - pre[mid+1]`；写成 `pre[r+1] - pre[mid]` 会把中位数自己多减一次，示例 1 的窗口 `[0,1]` 会算成 0 而非 1。

## 如果面试官追问
问：若要求输出具体行动序列而非次数？
答：滑窗确定中位数后，把窗口内 1 逐个向中位数方向交换，造 1 统一放在 `aliceIndex` 相邻空格，按距离从近到远搬。
