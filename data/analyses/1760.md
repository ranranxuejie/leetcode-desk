## 一句话思路
答案单调：若上限 `m` 可行，更大的上限也可行，故对答案二分，用贪心计数判断可行性。

## 怎么做
1. 二分区间取 `lo=1`、`hi=max(nums)`，答案必在其中。
2. 对给定上限 `m`，每个袋子 `x` 需要的刀数是 `(x-1)//m`，全部相加得总操作数。
3. 若总和 `<= maxOperations`，说明 `m` 可行，收缩 `hi=mid`；否则 `lo=mid+1`。
4. 循环到 `lo==hi` 返回 `lo`。

以 `nums=[9], maxOperations=2` 为例，`hi=9`。试 `m=4`：`(9-1)//4=2`，恰好 2 刀可行，`hi=4`；试 `m=2`：`(9-1)//2=4>2` 不可行，`lo=3`；试 `m=3`：`(9-1)//3=2` 可行，`hi=3`，最终返回 3。关键中间值是 `m=4` 时算出的 2 刀——它说明 4 可行，但 3 才是下界。

```python
lo, hi = 1, max(nums)
while lo < hi:
    mid = (lo + hi) // 2
    ops = 0
    for x in nums:
        ops += (x - 1) // mid
    if ops <= maxOperations:
        hi = mid
    else:
        lo = mid + 1
return lo
```

`(x-1)//mid` 的写法要点：`x=9, mid=3` 得 `8//3=2`，正好把 9 切成 3+3+3；若写成 `x//mid` 会得 3，多算一刀。

## 复杂度
时间：`O(n log(max(nums)))`，`n` 来自每轮遍历 `nums`，`log` 来自二分次数。
空间：`O(1)`，只开了 `lo/hi/mid/ops` 几个标量。

## 易错点
- 用 `x // mid` 代替 `(x - 1) // mid`：输入 `nums=[9], maxOperations=2`、`mid=3` 时会算成 3 刀，判定 3 不可行，答案错成 4。正确做法是整除前先减一，因为 `x` 恰好被 `mid` 整除时不需要额外一刀。
- 二分上界取 `max(nums)` 却把 `lo` 初始化成 0：`mid` 可能取到 0，`(x-1)//0` 直接抛 `ZeroDivisionError`。正确做法是 `lo=1`，因为每个袋子至少 1 个球，答案下界就是 1。

## 如果面试官追问
问：要求返回具体分割方案怎么办？
答：二分定出最小 `m` 后，对每个 `x` 贪心切成 `ceil(x/m)` 份，每份不超过 `m`，把剩余刀数按顺序消耗即可。
