## 一句话思路
自底向上 DFS 归并子树，每个节点只保留最大的 3 个和最小的 2 个 cost，用它们枚举出三数最大乘积。

## 怎么做
1. 把 `edges` 建成邻接表，从 0 出发 DFS，用 `parent` 参数避免走回父节点。
2. 每个节点返回自己子树里 `cost` 的「最大 3 个 + 最小 2 个」列表（不足则全给），因为三数乘积最大只可能来自 3 个最大正数，或 1 个最大正数 × 2 个最小负数。
3. 合并时把子节点返回的列表和 `cost[u]` 拼起来，排序后取 `[-3:]` 与 `[:2]` 的并集向上传。
4. 若子树节点数 < 3 记 1；否则在候选列表里三重循环取最大乘积，负数则记 0。

以示例 2 的节点 1 为例：子树 cost 为 `{4,3,5,7}`，候选保留 `[7,5,4,3]`，三数最大是 `7*5*4=140`；节点 2 子树含 `-4`，候选为 `[8,2,2,-4]`，`8*2*2=32` 胜过含负数的组合。

```python
def dfs(u, p):
    cand = [cost[u]]
    size = 1
    for v in g[u]:
        if v == p: continue
        sub, sz = dfs(v, u)
        cand += sub
        size += sz
    cand.sort()
    keep = cand[-3:] + cand[:2]
    if size < 3:
        coin[u] = 1
    else:
        best = max(keep[i]*keep[j]*keep[k]
                   for i in range(len(keep))
                   for j in range(i+1, len(keep))
                   for k in range(j+1, len(keep)))
        coin[u] = max(best, 0)
    return keep, size
```

## 复杂度
时间 O(n log n)：每个节点对常数个（≤5）候选排序，n 个节点各一次。
空间 O(n)：邻接表 + 递归栈 + `coin` 数组，候选列表每层常数大小。

## 易错点
- 只保留最大 3 个 → 遇到 `cost = [1,4,2,3,5,7,8,-4,2]` 的节点 2，会漏掉 `-4` 与两个正数组合的可能，虽然本例最优是 `8*2*2`，但若子树是 `[-100,-100,1]` 就必须靠两个最小负数，正确做法是同时保留最小 2 个。
- 子树节点数用 `len(cand)` 判断 → 候选被截断成 5 个后长度失真，节点 1 子树有 4 个节点却只看到 4 个候选尚可，但大子树会误判 <3，正确做法是单独维护 `size` 累加。

## 如果面试官追问
若要求输出取到最大乘积的三个具体节点编号而非金币数？答：候选列表里存 `(cost, node)` 二元组，排序和枚举时按 cost 比较，返回时取对应 node 即可。
