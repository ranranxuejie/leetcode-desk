## 一句话思路
统计全部字符的奇偶频次，先凑出尽可能多的「成对字符」和「单字符」，再按字符串长度从小到大贪心分配。

## 怎么做
1. 把 `words` 所有字符丢进一个 `Counter`，累加 `pairs += cnt // 2`，`odd += cnt % 2`。
2. 每个字符串长度 `L` 需要 `L // 2` 对字符；若 `L` 是奇数还需 1 个单字符（可由一对拆开或已有 `odd` 提供）。
3. 按长度升序排序 `words`，短串优先消耗 `pairs`，能凑满就计数并扣减。
4. 关键中间值：示例 1 `["abbb","ba","aa"]` 统计得 `pairs = 4`（b×4、a×3 各取半），`odd = 1`；排序后长度 `[2,2,4]`，前两个各耗 1 对，第三个耗 2 对，`pairs` 恰好归零，答案 3。

```python
from collections import Counter

cnt = Counter("".join(words))
pairs = sum(v // 2 for v in cnt.values())
odd = sum(v % 2 for v in cnt.values())

ans = 0
for L in sorted(len(w) for w in words):
    need = L // 2
    if need <= pairs:
        pairs -= need
        if L % 2 and odd == 0 and pairs > 0:
            pairs -= 1  # 拆一对补单字符
        elif L % 2 and odd > 0:
            odd -= 1
        elif L % 2:
            continue
        ans += 1
```

## 复杂度
时间：O(总字符数 + n log n)，排序贡献 log n。
空间：O(1)，Counter 最多 26 个键。

## 易错点
- 输入 `["cd","ef","a"]`：若只按 `pairs` 判断，会误以为 `c,d,e,f` 能凑 2 对就答 2；实际每串长度 2 需 1 对，但 `pairs=2` 只够 2 个串，而 `"a"` 长度 1 需 0 对却要 1 个 `odd`，正确做法是短串优先且奇数长度串要检查 `odd` 或拆对。
- 输入 `["abc","ab"]`：若忽略「拆一对补单字符」，`pairs=2`、`odd=1`，处理长度 3 的 `"abc"` 时 `need=1` 扣完 `pairs=1`，但 `odd` 已用尽无法补中间字符，会漏算；正确做法是 `odd==0 and pairs>0` 时再扣一对。

## 如果面试官追问
问：若要求输出具体构造方案怎么办？
答：记录每个串分配到的字符对和单字符，按原长度回填即可，贪心顺序不变。
