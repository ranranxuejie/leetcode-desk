## 一句话思路
用前缀和把「左侧元素都 ≤ nums[i]」的绝对值拆成符号已知的差，一次遍历 O(n) 求出全部 result[i]。

## 怎么做
1. 先算前缀和 `pre[i] = nums[0] + ... + nums[i-1]`（`pre[0]=0`），总长 n+1。
2. 对每个 i，左侧 i 个元素都 ≤ nums[i]，贡献 `nums[i]*i - pre[i]`。
3. 右侧 n-1-i 个元素都 ≥ nums[i]，贡献 `(pre[n]-pre[i+1]) - nums[i]*(n-1-i)`。
4. 两者相加写入 `result[i]`。

以 `nums = [2,3,5]` 为例，`pre = [0,2,5,10]`。i=1 时：左侧 `3*1 - pre[1] = 3-2 = 1`，右侧 `(pre[3]-pre[2]) - 3*(3-1-1) = (10-5)-3 = 2`，`result[1] = 3`，与示例一致。

```python
n = len(nums)
pre = [0] * (n + 1)
for i in range(n):
    pre[i + 1] = pre[i] + nums[i]
result = [0] * n
total = pre[n]
for i in range(n):
    left = nums[i] * i - pre[i]
    right = (total - pre[i + 1]) - nums[i] * (n - 1 - i)
    result[i] = left + right
```

关键点：`pre[i]` 是前 i 项和，`pre[i+1]` 才含 `nums[i]`，右侧求和必须从 `pre[i+1]` 减起，否则会把 `nums[i]` 自己算进去。

## 复杂度
时间：O(n)，一次建前缀和、一次遍历，无排序。
空间：O(n)，`pre` 和 `result` 各开 n+1 / n 个。

## 易错点
1. 右侧用 `total - pre[i]` 而不是 `total - pre[i+1]` → 对 `[2,3,5]` 的 i=1 会多减一个 `nums[1]=3`，得 `result[1]=0` 而非 3 → 正确写法是 `total - pre[i+1]`，把自身排除。
2. 右侧系数写成 `n - i` 而非 `n - 1 - i` → 对 `[1,4,6,8,10]` 的 i=0 会多减一个 `nums[0]`，`result[0]` 从 24 变成 23 → 右侧元素个数是 `n-1-i`，因为要排除自身。

## 如果面试官追问
问：若 nums 含负数且未排序怎么办？答：先排序并记录原下标，按排序后位置算前缀和，再按下标映射回原顺序，时间升到 O(n log n)。
