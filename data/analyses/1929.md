## 一句话思路
直接把 `nums` 拼在自身后面，因为 `ans[i+n] == nums[i]` 正好就是「原数组再抄一遍」。

## 怎么做
1. 用切片拼接 `nums + nums` 得到长度 2n 的新列表，一步到位。
2. 若要求原地或不用拼接语法，就新建 `ans = [0] * (2 * n)`，再按下标回填。
3. 回填时对每个 `i` 同时写两个位置：`ans[i] = nums[i]` 和 `ans[i + n] = nums[i]`。

以 `nums = [1,2,1]`、`n = 3` 为例，`i = 0` 时写 `ans[0] = 1` 和 `ans[3] = 1`；`i = 2` 时写 `ans[2] = 1` 和 `ans[5] = 1`，最终 `ans = [1,2,1,1,2,1]`，与示例一致。

```python
n = len(nums)
ans = [0] * (2 * n)
for i in range(n):
    ans[i] = nums[i]
    ans[i + n] = nums[i]
return ans
```

最省事的写法是 `return nums + nums`，但面试里写回填版本更能体现「下标 i 与 i+n 一一对应」这个结构。

## 复杂度
时间：O(n)，回填循环跑 n 次，每次两次赋值。
空间：O(n)，额外开了长度 2n 的 `ans`，输出本身占 2n。

## 易错点
- `nums = [1]`（n=1）→ 若把循环写成 `range(2*n)` 再取 `nums[i]`，`i=1` 时越界 → 循环只跑 `range(n)`，第二份靠 `i+n` 偏移写入。
- `nums = [1,2,1]` → 若写成 `ans[i+n] = ans[i]` 且顺序从后往前，会读到还没填的 0 → 两个位置都从 `nums[i]` 取值，不要从 `ans` 里转手。

## 如果面试官追问
问：不许开新数组，能不能原地把 `nums` 变成 2n？
答：Python 列表长度固定，只能 `nums.extend(nums[:])`，本质仍是 O(n) 拷贝，无法真正原地。
