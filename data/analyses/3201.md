## 一句话思路
只看奇偶性：相邻两项和的奇偶固定，等价于奇偶交替或全同，用 dp[末位奇偶][目标和奇偶] 扫一遍。

## 怎么做
1. 把 `nums[i]` 压成 `p = nums[i] & 1`，只关心 0/1。
2. 设 `dp[a][b]` 为「以奇偶 a 结尾、相邻和奇偶恒为 b」的最长长度，初始全 0。
3. 对每个 `p`，枚举目标 `b in (0,1)`：`dp[p][b] = dp[b][p] + 1`，因为前一项奇偶必须是 `b ^ p`（和为 b 时两项同奇偶当 b=0，异奇偶当 b=1，即前项 = b 异或 p）。
4. 答案取所有 `dp` 值的最大。

以 `nums = [1,2,1,1,2,1,2]` 为例，压成 `[1,0,1,1,0,1,0]`。处理到第 4 个元素 `p=1` 时，`dp[1][0]` 由 `dp[0][1]+1` 更新为 3（子序列 `1,0,1` 全交替），而 `dp[1][1]` 由 `dp[0][1]+1` 得 2；继续扫完，`dp[1][0]` 与 `dp[0][1]` 最终都是 6，对应 `1,2,1,2,1,2`。

```python
dp = [[0, 0], [0, 0]]
ans = 0
for v in nums:
    p = v & 1
    for b in (0, 1):
        dp[p][b] = dp[b][p] + 1
        ans = max(ans, dp[p][b])
return ans
```

注意 `dp[p][b]` 与 `dp[b][p]` 是同一张表的两个格子，`p == b` 时是自引用，必须先读后写，上面写法天然满足（右边先算完再赋值）。

## 复杂度
时间 O(n)：每个元素固定枚举 2 个目标奇偶，n 来自 `nums` 长度。
空间 O(1)：只开 2×2 的 `dp` 表，与 n 无关。

## 易错点
- 输入 `[1,3]`（全奇数）→ 若只按「奇偶交替」更新，会漏掉目标和为 0 的全同奇偶情况，错答 1；正确做法是 `b` 取 0 和 1 都更新，`dp[1][0]` 得 2。
- 输入 `[2,2,2]` → 若把 `dp[p][b]` 写成先赋值再读 `dp[b][p]`，`p == b` 时读到刚写的新值，长度虚增；正确做法是右侧表达式整体求值后再赋值，或用临时变量存旧值。

## 如果面试官追问
问：n 扩到 2*10^5 且要求输出具体子序列？
答：dp 里额外存前驱下标，回溯即可，时间空间仍是 O(n)。
