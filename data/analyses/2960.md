## 一句话思路
维护一个 `tested` 计数，遍历时判断 `batteryPercentages[i] - tested > 0` 即可，因为前面每测试一台设备就让当前设备减 1。

## 怎么做
1. 初始化 `tested = 0`，表示已测试设备数。
2. 从左到右遍历 `batteryPercentages`，对每个 `batteryPercentages[i]` 判断 `batteryPercentages[i] - tested > 0`。
3. 若成立则 `tested += 1`，否则跳过。
4. 遍历结束返回 `tested`。

关键中间值：以 `[1,1,2,1,3]` 为例，`i=0` 时 `1-0>0`，`tested` 变 1；`i=1` 时 `1-1=0` 不测试；`i=2` 时 `2-1=1>0`，`tested` 变 2；`i=3` 时 `1-2<0` 跳过；`i=4` 时 `3-2=1>0`，`tested` 变 3。

```python
tested = 0
for x in batteryPercentages:
    if x - tested > 0:
        tested += 1
return tested
```

不需要真的修改数组：第 `i` 台设备被前面 `tested` 次测试各减 1，所以它的有效电量就是 `x - tested`，与 `max(0, ...)` 的截断无关，因为只关心是否大于 0。

## 复杂度
时间：O(n)，一次遍历，n 为数组长度。
空间：O(1)，只开 `tested` 一个变量，不复制数组。

## 易错点
- 输入 `[0,1,2]` → 若直接数 `x > 0` 的个数会得 2 但过程错位，比如把 `i=0` 的 0 也当有效；正确做法是每步用 `x - tested` 判断，`i=0` 时 `0-0=0` 不测试，`tested` 保持 0。
- 输入 `[1,1,2,1,3]` → 若真的去改后续元素 `batteryPercentages[j] = max(0, ...)`，会写成 O(n²) 且容易越界；正确做法是用 `tested` 代替累计减量，`i=2` 时 `2-1=1` 直接判断。

## 如果面试官追问
问：如果要求返回每台设备测试后的数组状态？答：遍历时维护 `tested`，输出 `max(0, batteryPercentages[i] - tested)` 即可，仍是 O(n)。
