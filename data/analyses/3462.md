## 一句话思路
每行只可能取最大的前 limits[i] 个，把这些候选全丢进一个堆，取全局最大的 k 个。

## 怎么做
1. 对第 i 行排序后截取末尾 `limits[i]` 个，得到该行的候选集。
2. 把所有行的候选集合并，用大小为 k 的小顶堆保留最大的 k 个。
3. 堆内元素求和即为答案。

以 `grid = [[5,3,7],[8,2,6]], limits = [2,2], k = 3` 为例：第 0 行排序后取末尾 2 个得 `[5,7]`，第 1 行得 `[6,8]`；合并候选 `[5,7,6,8]`，小顶堆保留最大的 3 个即 `{6,7,8}`，和为 21。

```python
import heapq
h = []
for row, lim in zip(grid, limits):
    for v in sorted(row)[-lim:] if lim else []:
        heapq.heappush(h, v)
        if len(h) > k:
            heapq.heappop(h)
return sum(h)
```

注意 `lim` 为 0 时 `sorted(row)[-0:]` 会取整行，必须显式判空。

## 复杂度
时间 O(n·m log m + n·m log k)：每行排序贡献 log m，堆操作贡献 log k。
空间 O(n·m + k)：候选集最多 n·m 个，堆额外开 k 个。

## 易错点
- `limits[i] = 0` 时写成 `sorted(row)[-lim:]`，`-0` 等于 `0`，会取到整行 → 结果偏大 → 必须写成 `sorted(row)[-lim:] if lim else []`。
- 只对每行取前 limits[i] 个后直接累加前 k 大，忘了跨行比较：示例 2 中若按行顺序贪心取，可能先拿第 0 行的 7 和 5 再加第 1 行的 8，得 20 → 正确做法是全局堆比较，得 21。

## 如果面试官追问
若要求输出具体选了哪些元素（行号和列号）？答：堆里存 `(值, 行号, 列号)` 元组，弹出时记录即可，比较逻辑不变。
