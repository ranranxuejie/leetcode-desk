## 1. 一句话本质

在「每个位置只能从正上方或左上方下来」的 DAG 上，求从唯一源点到最后一层所有汇点的最短路径长度。

## 2. 读完题的第一反应

最朴素的想法是枚举所有路径。从第 0 行到第 n-1 行，每步有 2 种选择，路径总数是 $2^{n-1}$，逐条求和取最小，复杂度 $O(2^n)$。n 稍大就爆炸——这是「暴力卡在哪」：**它把大量重复的子问题反复算了一遍**。

关键观察来自题面那句「如果正位于当前行的下标 i，那么下一步可以移动到下一行的下标 i 或 i+1」。反过来读这句话：**到达第 i 行第 j 列的位置，只可能来自第 i-1 行的 j-1 列或 j 列**。也就是说，每个格子的「前驱」最多两个，且都在上一行。

这个「反向读」是整道题的转折点：它把「从顶往下枚举所有走法」变成了「对每个格子，只问它上面两个格子谁更便宜」。子问题被定义成「到达某个格子的最小路径和」，而它只依赖上一行两个更小的子问题——这就是动态规划的形状。

## 3. 从暴力到最优

**第一步：把子问题写出来。** 定义 `dp[i][j]` = 从顶点走到第 i 行第 j 列的最小路径和。由上面的前驱关系：

```
dp[i][j] = triangle[i][j] + min(dp[i-1][j-1], dp[i-1][j])
```

边界：`dp[0][0] = triangle[0][0]`；第 i 行第 0 列没有左上方前驱，只能从正上方来，即 `dp[i][0] = triangle[i][0] + dp[i-1][0]`；第 i 行最后一列（下标 i）没有正上方前驱，只能从左上方来。

**第二步：用示例 1 走一遍。** 三角形是 `[[2],[3,4],[6,5,7],[4,1,8,3]]`。

第 0 行：`dp = [2]`。

第 1 行：
- j=0：只能从上方来，`3 + 2 = 5`
- j=1：只能从左上方来，`4 + 2 = 6`

`dp = [5, 6]`。

第 2 行 `[6,5,7]`：
- j=0：`6 + 5 = 11`
- j=1：`5 + min(dp[0], dp[1]) = 5 + min(5,6) = 10`
- j=2：`7 + dp[1] = 7 + 6 = 13`

`dp = [11, 10, 13]`。

第 3 行 `[4,1,8,3]`：
- j=0：`4 + 11 = 15`
- j=1：`1 + min(11,10) = 11`
- j=2：`8 + min(10,13) = 18`
- j=3：`3 + 13 = 16`

`dp = [15, 11, 18, 16]`，取最小得 **11**，和示例一致。注意 11 对应的正是 2→3→5→1 这条路径。

**第三步：消掉空间。** 观察递推式：算第 i 行时只用到第 i-1 行。所以不需要存整个二维表，一个长度为 n 的一维数组就够。但这里有个坑：如果从左往右原地更新，`dp[j-1]` 已经被这一行覆盖了，读到的是新值。解决办法是**从右往左更新**——算 `dp[j]` 时，`dp[j-1]` 还是上一行的旧值，`dp[j]` 本身也还是旧值，两个前驱都完好。这就是进阶要求的 $O(n)$ 空间。

## 4. 正确性：为什么不会漏、不会重

用**不变量**来论证。设 `dp[i][j]` 表示「从顶点到 (i,j) 的所有合法路径中的最小和」。我们断言：按行从上到下、每行从右到左填表后，每个 `dp[i][j]` 都等于该定义值。

归纳证明。基础情形 i=0 只有一条路径，成立。归纳步：任取一条从顶点到 (i,j) 的合法路径，它的倒数第二步必然落在 (i-1,j-1) 或 (i-1,j)——这是题面移动规则的反向表述，**没有第三种可能**。于是这条路径的和 = 某个前驱的路径和 + `triangle[i][j]`。要让总和最小，前驱部分必须取到最小，即 `min(dp[i-1][j-1], dp[i-1][j])`。由归纳假设前驱值已是最优，故 `dp[i][j]` 也是最优。

「不漏」：任何合法路径都被上述分类覆盖，因为前驱只有两个。「不重」：两类前驱互斥（j-1 ≠ j），取 min 时不会把同一条路径算两次。最后答案取最后一行的最小值，因为终点可以是最后一行的任意一列，题面没有限定终点。

## 5. 完整代码（Python）

```python
class Solution:
    def minimumTotal(self, triangle):
        n = len(triangle)
        # dp[j] 表示「到达当前行第 j 列」的最小路径和
        # 初始为第 0 行，只有一个元素
        dp = [triangle[0][0]]

        for i in range(1, n):
            row = triangle[i]
            # 先扩容一格，给本行最后一列留位置
            dp.append(0)
            # 从右往左更新：保证 dp[j-1] 和 dp[j] 读到的都还是上一行的值
            for j in range(i, -1, -1):
                if j == 0:
                    # 最左列没有左上方前驱，只能从正上方来
                    dp[j] = row[j] + dp[j]
                elif j == i:
                    # 最右列没有正上方前驱，只能从左上方来
                    dp[j] = row[j] + dp[j - 1]
                else:
                    # 中间列：两个前驱取较小者
                    dp[j] = row[j] + min(dp[j - 1], dp[j])

        # 终点可以是最后一行的任意一列
        return min(dp)
```

## 6. 复杂度

**时间 $O(n^2)$。** 三角形第 i 行有 i+1 个元素，总元素数 $\sum_{i=0}^{n-1}(i+1) = n(n+1)/2$。每个元素只做一次常数时间的 min 和加法，所以总时间正比于元素总数，即 $O(n^2)$。这里的 n 是行数，不是元素个数——如果按元素总数记，就是 $O(N)$，$N = n(n+1)/2$。

**空间 $O(n)$。** 只开了一个长度最多为 n 的 `dp` 数组，没有二维表。注意没有 log n 项：本题没有任何分治或二分结构，所有复杂度都来自「行数 × 每行元素数」这个二维规模。

## 7. 边界与反例（至少 4 条）

1. **输入 `[[-10]]`** → 期望 `-10`。容易错在：循环从 `range(1, n)` 开始，n=1 时根本不进循环，直接 `min(dp)` 返回 `-10`。如果代码里写了 `dp[1]` 之类的越界访问就会崩。

2. **输入 `[[1],[2,3]]`** → 期望 `3`（1+2）。容易错在：只写了中间列的 `min` 分支，忘了 j=0 和 j=i 两个边界列各自只有一个前驱，写成 `min(dp[j-1], dp[j])` 会访问 `dp[-1]`——Python 里 `dp[-1]` 不报错，而是取到数组末尾，静默算出错误答案，这是最阴险的坑。

3. **输入 `[[1],[-2,-3]]`** → 期望 `-1`（1+(-2)）。容易错在：初始化 `dp` 时用了 `[0]*n` 或把 `dp` 初值设成 0，导致负数被 0「污染」。必须用 `triangle[0][0]` 初始化。

4. **输入 `[[1],[2,3],[4,5,6]]`** → 期望 `7`（1+2+4）。容易错在：原地更新时从左往右遍历，`dp[1]` 用了本行刚更新的 `dp[0]`，等于允许「同一行内横向移动」，破坏了题面的移动规则。必须从右往左。

5. **全负数三角形**，如 `[[-1],[-2,-3],[-4,-5,-6]]` → 期望 `-7`。容易错在：把「取最小值」误写成「取最大值」，或者用 0 做初始哨兵导致负数路径被忽略。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求返回具体路径而不只是和，怎么改？** 思路：额外开一个 `parent[i][j]` 记录每个格子选的是左上方还是正上方，最后从末行最小值处回溯到顶点。

2. **追问：如果移动规则改成「可以到下一行任意列」，答案怎么变？** 思路：前驱变成整行取 min，递推式变为 `dp[i][j] = triangle[i][j] + min(dp[i-1])`，可以维护一个滚动最小值，时间仍是 $O(n^2)$ 但每行多一次前缀 min 预处理。

3. **追问：如果三角形是「倒三角」（每行长度递减），还能用同样方法吗？** 思路：可以，但更自然的是自底向上——从最后一行往上推，`dp[j] = triangle[i][j] + min(dp[j], dp[j+1])`，这样连边界列的特判都省了，代码更短。

- **64. 最小路径和**：同样是网格上的「只能向右/向下」最短路径，前驱关系从两个变成两个，DP 形状完全一致，只是网格是矩形而非三角形。
- **931. 下降路径最小和**：从矩阵第一行走到最后一行，每步可到下一行相邻三列，是本题「前驱最多三个」的推广。
- **62. 不同路径**：同一套「前驱求和」的框架，只是把 min 换成加法计数，用来练熟「反向读移动规则」这个动作。
