## 1. 一句话本质

在**不能随机访问**的链表上，用「分治 + 合并两个有序链表」实现 O(n log n) 排序——难点不在排序思想，而在链表上如何**切分**和**合并**。

## 2. 读完题的第一反应

**朴素解法**：把链表值全部倒进数组，`sorted()` 排完再写回链表。时间 O(n log n) 没问题，但空间 O(n)——题目进阶明确要求常数级空间，这条路直接堵死。

**第二个朴素想法**：链表上做插入排序。每次把当前节点插到前面已排好的部分里。时间 O(n²)，n = 5×10⁴ 时约 2.5×10⁹ 次操作，超时。

**关键观察**：数组排序里 O(n log n) 且空间友好的方案是归并排序。归并排序只依赖两件事——「把序列切成两半」和「把两个有序序列合并」。这两件事在链表上**都不需要额外空间**：

- 切分：用快慢指针找中点，改一个 `next` 指针就切开了，O(1) 空间。
- 合并：两个有序链表合并，只需改指针，天然 O(1) 额外空间（数组归并要 O(n) 辅助数组，链表反而占优）。

所以「链表 + 归并排序」不是巧合搭配，而是链表的结构恰好消掉了归并排序唯一的空间开销。这就是进阶要求的答案。

## 3. 从暴力到最优

**第一步：合并两个有序链表（这是地基）**

给定 `1→4` 和 `2→3`，用哨兵节点 `dummy` 起头，`cur` 指向已合并部分的尾巴：

| 步骤 | 比较 | 接到 cur 后 | cur 移到 | 合并链 |
|---|---|---|---|---|
| 初始 | — | — | dummy | dummy |
| 1 | 1 < 2 | 1 | 节点1 | dummy→1 |
| 2 | 4 vs 2 | 2 | 节点2 | dummy→1→2 |
| 3 | 4 vs 3 | 3 | 节点3 | dummy→1→2→3 |
| 4 | 剩 4 | 4 | 节点4 | dummy→1→2→3→4 |

这一步 O(m+n) 时间、O(1) 空间。它是整个算法的「原子操作」。

**第二步：怎么切**

对 `4→2→1→3`，快慢指针：`slow` 每步走 1，`fast` 每步走 2。当 `fast` 到末尾或 `fast.next` 为空时，`slow` 停在中点偏左。对 4 个节点：slow 停在 2（第 2 个），从 `slow.next` 处切断，得到 `4→2` 和 `1→3`。

注意必须切在 `slow.next` 之前并把 `slow.next = None`，否则两半还连着，递归会无限循环——这是本题最常见的 bug。

**第三步：递归结构**

```
sortList(4→2→1→3)
├─ 切分 → (4→2) 和 (1→3)
├─ sortList(4→2)
│   ├─ 切分 → (4) 和 (2)
│   ├─ sortList(4) = 4   ← base case：单节点/空
│   ├─ sortList(2) = 2
│   └─ merge(4, 2) = 2→4
├─ sortList(1→3) = 1→3
└─ merge(2→4, 1→3) = 1→2→3→4
```

瓶颈对比：插入排序的瓶颈是「每次插入要线性扫描」，共 n 次 → n²；归并把它换成「每层合并总共扫 n 个节点，共 log n 层」→ n log n。**消掉瓶颈的动作就是把「逐个插入」换成「两两合并」**。

## 4. 正确性：为什么不会漏、不会重

用**循环不变量**证明 `merge` 正确，再用**结构归纳**证明整体正确。

**merge 的不变量**：在每次循环开始时，`dummy→...→cur` 是「已从 a、b 中取出的所有节点按升序排好的链」，且 `a`、`b` 分别指向各自剩余部分的头。

- 初始化：`cur = dummy`，已取出集合为空，空链有序，成立。
- 保持：比较 `a.val` 与 `b.val`，取较小者 x 接到 `cur` 后。x 是两剩余头中较小的，而两剩余部分各自有序（归纳假设），所以 x ≤ 剩余所有元素，接到尾部不破坏升序。取出后对应指针后移，不变量恢复。
- 终止：某一方为空，把另一方整段接上（它本身有序），全部节点恰好被取一次。

**不漏不重**：切分时 `slow.next = None` 保证两半的节点集合**互不相交**且**并集为原链表**（快慢指针只改指针不改节点，节点总数守恒）。递归对两半分别排序，merge 把两半各取一次，所以每个节点恰好出现一次。

**整体归纳**：base case（空/单节点）有序；归纳步中，两半各自有序（归纳假设），merge 输出有序且含全部节点。由结构归纳，任意长度链表都正确。

## 5. 完整代码（Python）

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def sortList(self, head: ListNode) -> ListNode:
        # base case：空链表或单节点，本身有序
        if not head or not head.next:
            return head

        # 1) 快慢指针找中点，slow 停在中点偏左
        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        # 2) 从 slow.next 处切断，得到两段互不相交的链表
        mid = slow.next
        slow.next = None          # 关键：断开，否则递归死循环

        # 3) 递归排序两半
        left = self.sortList(head)
        right = self.sortList(mid)

        # 4) 合并两个有序链表
        return self._merge(left, right)

    def _merge(self, a: ListNode, b: ListNode) -> ListNode:
        dummy = ListNode(0)       # 哨兵，省去头节点特判
        cur = dummy
        while a and b:
            if a.val <= b.val:    # <= 保证稳定（本题不要求，但好习惯）
                cur.next = a
                a = a.next
            else:
                cur.next = b
                b = b.next
            cur = cur.next
        # 一方耗尽，整段接上另一方
        cur.next = a if a else b
        return dummy.next
```

## 6. 复杂度

**时间 O(n log n)**：
- 递归树有 log₂n 层（每层把长度减半，n 个节点 → 1 个节点需 log n 次二分）。
- 每层所有 merge 加起来恰好扫过该层全部节点，共 n 个。
- 层数 × 每层工作量 = log n × n。

**空间 O(log n)**：
- merge 本身 O(1)（只改指针，无辅助数组）。
- 但递归调用栈深度为 log n（二分深度），这是空间来源。
- 若严格追求进阶的「常数级空间」，需把递归改成自底向上的迭代归并（按步长 1,2,4,... 两两合并），栈空间降为 O(1)。面试中先写递归版，被追问再讲迭代版思路即可。

## 7. 边界与反例（至少 4 条）

1. **输入 `[]`** → 输出 `[]`。容易错：没写 `if not head` 直接访问 `head.next` 报错。
2. **输入 `[1]`** → 输出 `[1]`。容易错：base case 只判了空没判单节点，进入切分后 `slow.next` 为 None，`mid` 为 None，递归 `sortList(None)` 虽能返回但逻辑绕；更常见的是快慢指针在单节点上 `fast=head.next=None` 直接跳过循环，`mid=None`，merge 退化为返回 left，结果对但依赖巧合，应显式 base case。
3. **输入 `[2,1]`** → 输出 `[1,2]`。容易错：`slow, fast = head, head.next` 的初始化若写成 `fast = head`，两节点时 slow 会走到第二个节点，切出空的一半，死循环或结果错。
4. **输入 `[1,1,1]`**（含重复值）→ 输出 `[1,1,1]`。容易错：merge 里用 `<` 而非 `<=` 不影响本题结果，但若变体要求稳定排序会出错；另外切分必须保证重复值不被复制。
5. **输入 `[3,2,1]`** → 输出 `[1,2,3]`。容易错：忘记 `slow.next = None`，两半仍相连，递归在长度 2 的子链表上再次切出「自己」，无限递归爆栈。

## 8. 面试追问与变体（3 条）

1. **追问：不用递归，O(1) 空间怎么做？** 思路：自底向上归并。外层 `step = 1, 2, 4, ...` 直到 ≥ n；内层每次取两段长度 step 的链表 merge 后接回，用 `dummy` 串起整条结果链。
2. **追问：为什么不用快排？** 思路：链表无法随机访问，快排的 partition 需要从两端向中间扫，链表只能单向走；且快排最坏 O(n²)、递归深度可能 O(n)。归并的「切分」在链表上是 O(1) 改指针，天然契合。
3. **追问：如果要稳定排序且按对象某字段排？** 思路：merge 时用 `<=` 取左段优先，保证相等元素相对顺序不变，即稳定；本题的 `<=` 已满足。

## 9. 举一反三（2-3 道同类题）

- **21. 合并两个有序链表**：本题的 `_merge` 就是它的完整解，是归并排序的原子操作。
- **23. 合并 K 个升序链表**：把「两两合并」扩展成 K 路归并，可用分治两两合并或小顶堆，共同点是「合并有序序列」这一核心动作。
- **147. 对链表进行插入排序**：同题不同解，O(n²)，用来对比理解「为什么归并才是链表排序的正解」。
