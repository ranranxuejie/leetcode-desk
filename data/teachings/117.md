## 1. 一句话本质

在**每一层**上，把该层所有节点按从左到右的顺序串成一条单链表，用 `next` 指针连接，层尾指向 `NULL`。

注意这句话里有两个关键词：**每一层**（不是整棵树）和**从左到右**（不是任意顺序）。题目给的输出 `[1,#,2,3,#,4,5,7,#]` 就是按层串起来的结果，`#` 是层分隔符——这直接告诉你：答案的形态是「每层一条链」。

## 2. 读完题的第一反应

**朴素解法**：层序遍历（BFS），用一个队列把每层节点收集起来，然后在这一层内部把相邻节点用 `next` 串起来。

它卡在哪？队列里最多会同时存一整层的节点。节点数上限是 6000，最坏情况（完全二叉树最后一层）队列里能放约 3000 个节点。空间是 `O(n)`。而题目**进阶**明确要求「常量级额外空间」——所以 BFS 队列这条路被堵死了。

**关键观察**：题目里 `next` 指针本身就是一条「横向的链」。如果我们已经处理完第 `k` 层，那么第 `k` 层的 `next` 链就是一条现成的、不用额外空间的「队列」——顺着 `next` 走，就能按从左到右的顺序访问第 `k` 层的每一个节点，进而访问它们的左右孩子，去串第 `k+1` 层。

换句话说：**上一层已经串好的 `next` 链，就是下一层的遍历工具**。这就是把 `O(n)` 的队列空间消成 `O(1)` 的钥匙。这个观察不是凭空来的，是题目把 `next` 字段塞给你、又要求常量空间，两个条件夹出来的唯一出路。

## 3. 从暴力到最优

**第 0 步（暴力 BFS）**：队列存一层，逐个弹出、串 `next`。时间 `O(n)`，空间 `O(n)`。瓶颈在空间。

**第 1 步（用 next 链替代队列）**：处理第 `k` 层时，不再用队列存第 `k+1` 层，而是：
- 沿着第 `k` 层的 `next` 链走（`cur = cur.next`），这是「读」；
- 同时把第 `k+1` 层的节点用 `next` 串起来，这是「写」。

但这里有个坑：串第 `k+1` 层时，需要一个「当前串到哪了」的尾巴指针，还需要记住这一层的头（下一轮从它开始）。这两个指针是 `O(1)` 的。

**第 2 步（处理「孩子不全」的情况）**：这是本题比 116 题（完全二叉树）难的地方。第 `k` 层的某个节点可能只有左孩子、只有右孩子、或两个孩子都没有。串第 `k+1` 层时，要按「左孩子、右孩子」的先后顺序，**跳过空孩子**，把非空的依次接到尾巴后面。

**具体小例子走一遍**：`root = [1,2,3,4,5,null,7]`

树结构：
```
        1
       / \
      2   3
     / \   \
    4   5   7
```

- **第 0 层**：只有 `1`，`1.next = NULL`。当前层头 `levelHead = 1`。
- **处理第 0 层，串第 1 层**：`cur = 1`。左孩子 `2` 非空 → 它是第 1 层头，`nextLevelHead = 2`，尾巴 `tail = 2`。右孩子 `3` 非空 → `tail.next = 3`，`tail = 3`。`cur = cur.next = NULL`，本层结束。第 1 层链：`2 → 3 → NULL`。
- **处理第 1 层，串第 2 层**：`cur = 2`。左孩子 `4` 非空 → `nextLevelHead = 4`，`tail = 4`。右孩子 `5` 非空 → `tail.next = 5`，`tail = 5`。`cur = 2.next = 3`。`3` 的左孩子 `null` 跳过；右孩子 `7` 非空 → `tail.next = 7`，`tail = 7`。`cur = 3.next = NULL`，结束。第 2 层链：`4 → 5 → 7 → NULL`。
- **处理第 2 层**：`4`、`5`、`7` 都没有孩子，`nextLevelHead` 始终为 `NULL`，循环终止。

最终每层链：`1`；`2→3`；`4→5→7`。与输出 `[1,#,2,3,#,4,5,7,#]` 一致。

注意中间变量 `tail` 的作用：它保证「跨过父节点」时也能正确接上——`5` 是 `2` 的孩子，`7` 是 `3` 的孩子，它们分属不同父节点，但 `tail` 一路带着走，所以 `5.next = 7` 能接上。这正是「跳过空孩子」逻辑的价值。

## 4. 正确性：为什么不会漏、不会重

用**不变量**说清楚。设当前正在处理第 `k` 层，声明不变量：

> **进入处理第 `k` 层的循环时，第 `k` 层的 `next` 链已经完整且正确（从左到右、层尾为 `NULL`）；且第 `k+1` 层尚未被触碰。**

归纳证明：

- **基础**：`k = 0`，第 0 层只有根，`root.next = NULL`，不变量成立（根是层尾）。
- **归纳步**：假设第 `k` 层链正确。循环沿 `cur = levelHead` 出发，每次 `cur = cur.next`，因为链正确，所以**恰好访问第 `k` 层每个节点一次、不漏不重**。对每个 `cur`，按「左、右」顺序检查孩子，非空才接到 `tail` 后。由于 `tail` 单调向后移动、每次只接一个新节点，第 `k+1` 层每个节点**恰好被接一次**，且顺序就是「父节点从左到右、同一父节点先左后右」——这正是层序从左到右的定义。循环结束时 `tail.next` 保持初始的 `NULL`（新节点初始 `next` 为 `NULL`，我们只改 `tail.next`，不改新节点的 `next` 指向别人），所以层尾为 `NULL`。不变量对 `k+1` 成立。
- **终止**：当某层没有孩子时 `nextLevelHead == NULL`，循环退出，此时所有层都已处理完。

「不漏」由「沿正确链遍历」保证，「不重」由「`tail` 只前进、每个孩子只被检查一次」保证。

## 5. 完整代码（Python）

```python
class Solution:
    def connect(self, root: 'Node') -> 'Node':
        if not root:
            return root

        level_head = root          # 当前正在处理的这一层的第一个节点

        while level_head:
            cur = level_head       # 沿当前层的 next 链从左到右扫描
            next_level_head = None # 下一层的第一个节点（下一轮的 level_head）
            tail = None            # 下一层已串好的链的尾巴

            while cur:
                # 按「先左后右」的顺序，把非空孩子接到下一层链尾
                for child in (cur.left, cur.right):
                    if child:
                        if tail is None:
                            # 下一层的第一个孩子，记下头
                            next_level_head = child
                        else:
                            tail.next = child   # 接到尾巴后面
                        tail = child            # 尾巴前移
                cur = cur.next      # 借当前层的 next 链走到下一个父节点

            # 本层处理完，跳到下一层继续
            level_head = next_level_head

        return root
```

关键逻辑对应上一节：外层 `while level_head` 控制「处理哪一层」，内层 `while cur` 借 `next` 链遍历当前层，`for child in (cur.left, cur.right)` 保证先左后右且跳过空孩子，`tail` 负责跨父节点串接。

## 6. 复杂度

- **时间 `O(n)`**：每个节点作为「父节点」被 `cur` 访问一次（内层循环），作为「孩子」被检查一次（`for child` 里），常数次操作。总操作数与节点数成正比。这里没有 `log n` 项，因为不是分治递归，是逐层线性扫描。
- **空间 `O(1)`**：只用了 `level_head`、`cur`、`next_level_head`、`tail` 四个指针，与 `n` 无关。注意**没有递归**，所以连隐式栈都没有。如果写成递归版（进阶允许），空间是 `O(h)`，`h` 为树高，最坏 `O(n)`——所以迭代版才是严格 `O(1)`。

## 7. 边界与反例（至少 4 条）

1. **空树** `root = []` → 输出 `[]` → 容易错在没判空就访问 `root.next` 或 `root.left`，直接 `AttributeError`。代码开头 `if not root: return root` 兜住。
2. **单节点** `root = [1]` → 输出 `[1,#]` → 容易错在以为要处理孩子，其实 `1.next` 保持 `NULL` 即可，循环第一轮 `next_level_head` 为 `NULL` 就退出。
3. **链状树（每层只有一个节点）** `root = [1,2,null,3]` → 每层 `next` 都是 `NULL` → 容易错在 `tail` 逻辑：每层只有一个孩子时 `tail` 先被赋值、`next_level_head` 也被赋值，但 `tail.next` 永远不被写，结果正确；若误写成「无条件 `tail.next = child`」会在 `tail is None` 时崩。
4. **左孩子缺失、只有右孩子** `root = [1,null,2,3]`（`1` 只有右孩子 `2`，`2` 只有左孩子 `3`）→ 第 1 层 `2`，第 2 层 `3` → 容易错在只检查 `cur.left` 就以为没孩子，漏掉右孩子。`for child in (cur.left, cur.right)` 必须两个都查。
5. **跨父节点串接** `root = [1,2,3,4,5,null,7]`（示例 1）→ `5.next = 7` → 容易错在把「串下一层」写成「只串同一父节点的两个孩子」，导致 `5` 和 `7` 之间断链。`tail` 跨父节点携带是必须的。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求返回每层的头节点列表，怎么做？** 思路：在 `next_level_head` 被赋值时把它 append 进结果列表，其余逻辑不变，空间变成 `O(层数)`。
2. **追问：如果树是 N 叉树呢？** 思路：把 `for child in (cur.left, cur.right)` 换成 `for child in cur.children`，其余完全一样——`tail` 机制天然支持任意多个孩子。
3. **追问：能不能用递归做，且满足进阶？** 思路：递归处理 `root.right` 再 `root.left`（先右后左，保证同层右侧已串好），对每个节点用 `root.next` 链找「下一个有孩子的节点」来接自己的孩子。递归栈 `O(h)`，进阶说隐式栈不计入，所以符合要求。
