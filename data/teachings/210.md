## 1. 一句话本质

在有向图上求一个**拓扑序**：把「先修关系」看成有向边 `b → a`（先修课指向后继课），输出一个线性序列，使得每条边的起点都排在终点前面；若图中有环（互相依赖），则无解，返回空数组。

## 2. 读完题的第一反应

**朴素解法**：反复扫描所有课程，每一轮找出「所有先修课都已排好」的课程，把它们追加到答案里，直到没有新课可加。这个做法本身逻辑没错，但每一轮都要把 `prerequisites` 整个扫一遍，最坏要扫 `numCourses` 轮，复杂度是 `O(n · m)`（n 是课程数，m 是先修关系数）。当 n = 2000、m 接近 n² 时，这个量级直接爆掉。

**关键观察**：一门课什么时候「可以选了」？只取决于**它的入度是否降到 0**——也就是它的所有先修课是否都已出队。而一门课被排进答案后，只会影响它的**直接后继**的入度，让每个后继的入度减 1。这意味着我们不需要每轮重扫全表，只需要维护一个「当前入度为 0 的课程集合」，每次从里面取一门、把它的后继入度减一、减到 0 就加入集合。这就是 Kahn 算法（BFS 拓扑排序）的由来——**把「全局重扫」换成「局部更新」**。

另一个观察：如果最后排进答案的课程数小于 `numCourses`，说明剩下的课互相卡死（成环），直接返回空数组即可，不需要额外判环逻辑。

## 3. 从暴力到最优

用示例 2 走一遍：`numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]`。

先建图。按「先修 → 后继」的方向：`0→1, 0→2, 1→3, 2→3`。入度数组 `indeg = [0, 1, 1, 2]`（课程 0 入度 0，课程 1 被 0 指向所以入度 1，课程 2 同理，课程 3 被 1 和 2 指向所以入度 2）。

**暴力版**：第一轮扫描，发现只有课程 0 入度为 0，答案 `[0]`；第二轮扫描，课程 1、2 入度变 0，答案 `[0,1,2]`；第三轮，课程 3 入度变 0，答案 `[0,1,2,3]`。三轮全表扫描，每轮 O(m)。

**优化版**：初始队列 `q = [0]`（入度为 0 的课），答案 `ans = []`。

- 弹出 0，`ans = [0]`。0 的后继是 1 和 2，入度各减 1：`indeg = [0, 0, 0, 2]`。1、2 入度归零，入队，`q = [1, 2]`。
- 弹出 1，`ans = [0, 1]`。1 的后继是 3，入度减 1：`indeg = [0, 0, 0, 1]`。3 还没归零，不入队。
- 弹出 2，`ans = [0, 1, 2]`。2 的后继是 3，入度减 1：`indeg = [0, 0, 0, 0]`。3 归零，入队，`q = [3]`。
- 弹出 3，`ans = [0, 1, 2, 3]`，3 无后继，队列空，结束。

每条边只被处理一次（在它的起点出队时），总代价 O(n + m)，比暴力的 O(n·m) 少了一个 n 因子。注意输出 `[0,1,2,3]` 和官方给的 `[0,2,1,3]` 不同，但两者都合法——题目明确说「任意一种」。

**为什么想到队列而不是栈**？其实都行，DFS 版拓扑排序就是用栈（递归）实现的。选 BFS 是因为「入度归零就入队」这个动作非常自然，代码短、不用处理递归深度（n 可达 2000，递归有栈溢出风险）。

## 4. 正确性：为什么不会漏、不会重

用**不变量**论证。维护两个集合：`ans`（已输出的课）和 `q`（当前入度为 0 但未输出的课）。不变量是：

> **任意时刻，`ans` 中任意课程的任意先修课，都已在 `ans` 中；且 `ans` 中无重复。**

- **不会重**：每门课只在入度**恰好**降到 0 的那一刻入队一次（入度只减不增，归零后不会再触发入队），出队时追加到 `ans`，所以 `ans` 无重复。
- **不会漏（前提是无环）**：反证。假设有课没进 `ans`，取其中一门 c。c 的入度始终没归零，说明存在某条先修链 `c ← x₁ ← x₂ ← …` 一直往上追溯。由于课程数有限，这条链必然重复某个节点，即存在环。但题目场景下若图无环，链必终止于某门入度为 0 的课，它一开始就在队列里，会被处理，矛盾。所以无环时所有课都会进 `ans`。
- **顺序合法**：课程 c 出队时，它的所有先修课都已出队（因为入度归零意味着每条入边 `b→c` 的 b 都已处理过），所以 c 排在所有先修课之后。每条边 `b→a` 都满足 b 在 a 前，拓扑序成立。

**有环时**：环上每门课的入度至少为 1（环内前驱贡献），永远归不了零，所以 `len(ans) < numCourses`，据此返回 `[]`，判环和排序一步完成。

## 5. 完整代码（Python）

```python
from collections import deque

class Solution:
    def findOrder(self, numCourses: int, prerequisites: list[list[int]]) -> list[int]:
        # 建图：graph[b] 存所有「以 b 为先修课」的后继课程
        graph = [[] for _ in range(numCourses)]
        indeg = [0] * numCourses          # indeg[a] = 课程 a 还差几门先修课
        for a, b in prerequisites:        # 题面 [a, b] 表示 b 是 a 的先修
            graph[b].append(a)            # 边方向：先修 b -> 后继 a
            indeg[a] += 1

        # 所有入度为 0 的课（没有先修要求）先入队
        q = deque(i for i in range(numCourses) if indeg[i] == 0)
        ans = []

        while q:
            cur = q.popleft()
            ans.append(cur)               # 出队即确定位置
            for nxt in graph[cur]:        # 只更新直接后继，不重扫全表
                indeg[nxt] -= 1
                if indeg[nxt] == 0:       # 恰好归零才入队，保证不重复
                    q.append(nxt)

        # 排不满说明有环，环上课入度永远降不到 0
        return ans if len(ans) == numCourses else []
```

## 6. 复杂度

- **时间 O(n + m)**：n = `numCourses`，m = `prerequisites.length`。建图遍历 m 条边一次；每门课入队出队各一次，共 O(n)；每条边在起点出队时被处理一次，共 O(m)。没有排序、没有二分，所以**没有 log 项**。
- **空间 O(n + m)**：`graph` 存 m 条边（邻接表），`indeg` 和 `q`、`ans` 各 O(n)。递归版 DFS 还要 O(n) 的调用栈，BFS 版省掉了这一项。

## 7. 边界与反例（至少 4 条）

1. **`numCourses = 1, prerequisites = []`** → `[0]`。容易错在：初始化队列时漏掉「入度为 0 的孤立点」，或者循环条件写成 `while q and len(ans) < numCourses` 之外的奇怪形式导致空图返回 `[]`。
2. **`numCourses = 2, prerequisites = [[0,1],[1,0]]`** → `[]`。两门课互为先修，成环。容易错在：只判「有没有课入度为 0」就以为有解，忘了最后要检查 `len(ans) == numCourses`。
3. **`numCourses = 3, prerequisites = [[1,0],[2,1],[0,2]]`** → `[]`。三元环，且每门课入度都是 1，初始队列为空，循环一次都不进，`ans = []`，长度检查兜底。容易错在：以为「初始队列为空」就代表无解——其实这题里确实无解，但逻辑上要靠长度检查统一处理，别写特判。
4. **`numCourses = 3, prerequisites = []`** → 任意排列如 `[0,1,2]`。全孤立点。容易错在：建图时 `graph` 初始化成 `[[]] * numCourses`（浅拷贝陷阱），所有行共享同一个列表，追加后继时互相污染。
5. **`numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]`** → 如 `[0,1,2,3]`。容易错在：把边方向建反（建成 `a→b`），导致入度含义颠倒，输出顺序全错但长度对，很难 debug。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求返回「字典序最小」的拓扑序怎么办？** 思路：把队列换成最小堆，每次取编号最小的入度 0 课程，其余不变，复杂度多一个 log n。
2. **追问：如何判断是否存在唯一拓扑序？** 思路：任意时刻若队列中元素个数 > 1，说明有多个可选分支，拓扑序不唯一；全程队列大小始终为 1 才唯一。
3. **追问：如果课程有学分，要求总学分不超过 K 的前提下尽量多选课？** 思路：这是带权拓扑排序 + 背包，先拓扑排序确定合法顺序，再在 DAG 上做 DP，不是单纯拓扑排序能解决的。
