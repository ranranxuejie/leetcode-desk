## 1. 一句话本质

在一个「值域被限制在 1..n、长度却是 n+1」的数组里，找出那个被多塞进去的数——本质是**在一条由下标指向值的函数图上找环的入口**。

## 2. 读完题的第一反应

最直接的想法：用一个哈希集合记录见过的数，第二次遇到就返回。时间 O(n)，但空间 O(n)，直接违反「O(1) 额外空间」。

退一步：排序后扫相邻元素。时间 O(n log n)，空间 O(1)（原地排序），但违反「不修改数组」。

再退一步：暴力两重循环，对每个 nums[i] 数它出现几次。时间 O(n²)，太慢。

所以三条路都被题面卡死了：哈希卡空间、排序卡「不修改」、暴力卡时间。**必须找到一种既不额外开数组、又不改动原数组、还能 O(n) 的做法。**

关键观察来自题面的两个约束联立：

- 数组长度是 n+1，下标范围是 `0..n`；
- 每个元素的值域是 `1..n`。

把「下标 i」看成节点，「nums[i]」看成从 i 出发指向的节点，就得到一个**每个节点出度恰好为 1** 的有向图（因为每个位置只有一个值）。而值域 1..n 意味着**没有任何边指向下标 0**，所以 0 是一个只进不出的「入口」，从 0 出发沿着 `0 → nums[0] → nums[nums[0]] → ...` 走，一定会走进一个环——这个环的入口，就是那个重复的数。

为什么？因为 n+1 个节点、每个节点出度 1，边数等于节点数，图里必然有环；而重复的数 x 意味着有两个不同的下标都指向 x，x 的入度为 2，它正是环的汇合点。这就是 Floyd 判圈算法（快慢指针）能用的原因。

## 3. 从暴力到最优

用示例 1：`nums = [1,3,4,2,2]`，n=4。

**第一步：把「找重复」翻译成「找环入口」。**

构造映射：`0→1, 1→3, 2→4, 3→2, 4→2`。

从 0 出发：`0 → 1 → 3 → 2 → 4 → 2 → 4 → 2 ...`

走进去之后卡在 `2 ↔ 4` 这个环上，环的入口是 2，答案就是 2。注意：**重复值 2 恰好是环入口**，这不是巧合——下标 2 和下标 4 都指向 2，两条路在 2 汇合，2 就是环的起点。

**第二步：快慢指针找相遇点。**

- 慢指针 `slow = nums[slow]`，每次走一步；快指针 `fast = nums[nums[fast]]`，每次走两步。
- 初始 `slow = fast = 0`。

| 轮次 | slow | fast |
|---|---|---|
| 0 | 0 | 0 |
| 1 | nums[0]=1 | nums[nums[0]]=nums[1]=3 |
| 2 | nums[1]=3 | nums[nums[3]]=nums[2]=4 |
| 3 | nums[3]=2 | nums[nums[4]]=nums[2]=4 |
| 4 | nums[2]=4 | nums[nums[4]]=nums[2]=4 |

第 4 轮 `slow == fast == 4`，在环内相遇。**相遇点不一定是环入口**，这里入口是 2，相遇在 4。

**第三步：一个指针回到起点，两个指针同速前进，再次相遇即入口。**

- `slow` 留在 4，`fast` 回到 0。
- 两者都每次走一步：

| 轮次 | slow | fast |
|---|---|---|
| 0 | 4 | 0 |
| 1 | nums[4]=2 | nums[0]=1 |
| 2 | nums[2]=4 | nums[1]=3 |
| 3 | nums[4]=2 | nums[3]=2 |

第 3 轮相遇于 2，返回 2。✓

**为什么第二次一定在入口相遇？** 设从起点 0 到环入口的距离为 a，环长为 c，相遇点距入口为 b。快指针走的路程是慢指针的两倍：`a + b + kc = 2(a + b)`，整理得 `a = kc - b`，即 `a ≡ -b (mod c)`。也就是说，从起点走 a 步、从相遇点走 `c - b` 步，会同时到达入口。所以让一个指针回起点、两者同速走，必在入口相遇。**这一步的推导就是「为什么不会漏」的根据。**

## 4. 正确性：为什么不会漏、不会重

用**不变量**说清楚。

**不变量 1（图结构）**：对任意下标 i ∈ [0, n]，`nums[i] ∈ [1, n]`，所以从任何节点出发都有一条出边，且出边终点不会是 0。因此 0 是唯一入度为 0 的节点，从 0 出发的路径**必然进入环且永不回到 0**。

**不变量 2（重复值 = 环入口）**：设重复值为 x。因为 x 出现至少两次，存在两个不同下标 p ≠ q 满足 `nums[p] = nums[q] = x`，即 x 的入度 ≥ 2。在有向函数图（每点出度 1）中，入度 ≥ 2 的节点**恰好是环的入口**：从 0 出发的路径第一次到达 x 后，无论沿哪条入边回溯都会绕回 x，形成环；而 x 之前的部分是树链，不会重复。所以「找重复值」等价于「找从 0 出发路径的环入口」，**不漏**。

**不变量 3（Floyd 必相遇）**：慢指针每轮 +1 步、快指针 +2 步，两者都在环内运动时相对速度为 1，环长为有限值 c，最多 c 轮必相遇，**不会死循环**。

**不变量 4（第二次相遇点唯一）**：由第 3 节的同余式 `a ≡ -b (mod c)`，从起点走 a 步与从相遇点走 `c-b` 步落在同一节点，即环入口。由于环入口唯一（入度 ≥ 2 的节点只有一个，因为题面保证只有一个重复整数），第二次相遇点**就是答案，不会重**。

## 5. 完整代码（Python）

```python
class Solution:
    def findDuplicate(self, nums: list[int]) -> int:
        # 阶段一：快慢指针在环内相遇
        slow = nums[0]
        fast = nums[nums[0]]
        while slow != fast:
            slow = nums[slow]              # 慢指针每次走一步
            fast = nums[nums[fast]]        # 快指针每次走两步
        # 此时 slow == fast，位于环内某点（不一定是入口）

        # 阶段二：一个指针回起点，两者同速前进，相遇点即环入口
        fast = 0
        while slow != fast:
            slow = nums[slow]              # 同速，每次一步
            fast = nums[fast]
        return slow                        # 环入口 = 重复的数
```

注意初始化的写法：`slow = nums[0]`、`fast = nums[nums[0]]`，而不是都从 0 开始。如果都从 0 开始，第一轮 `slow = nums[0]`、`fast = nums[nums[0]]` 也等价，但用上面的写法可以少一次循环判断，且语义更清晰——「已经各走了一步」。两种写法都对，关键是**阶段二必须让一个指针回到 0**。

## 6. 复杂度

- **时间 O(n)**：阶段一快慢指针在环内相遇，慢指针最多走 `a + c` 步（a 为链长、c 为环长），快指针走两倍，总步数 O(a + c) ≤ O(n)；阶段二两个指针各走 a 步到入口。两阶段相加仍是 O(n)。这里的 n 来自「数组长度 n+1，路径长度不超过节点数」。
- **空间 O(1)**：只用了 `slow`、`fast` 两个整型变量，没有开任何与 n 相关的容器。这正是题面「常量级额外空间」的要求。
- 对比：哈希法时间 O(n) 但空间 O(n)；排序法空间 O(1) 但时间 O(n log n) 且修改数组；二分法（按值域二分统计 ≤ mid 的个数）时间 O(n log n)、空间 O(1)，是另一条合法路径，但比 Floyd 慢一个 log。

## 7. 边界与反例（至少 4 条）

1. **输入 `[1,1]`** → 期望 `1`。容易错：初始 `slow = nums[0] = 1`、`fast = nums[nums[0]] = nums[1] = 1`，第一轮就相等，直接进阶段二；若阶段二忘了把 `fast` 置 0，会死循环。
2. **输入 `[3,3,3,3,3]`** → 期望 `3`。容易错：所有值相同，`slow` 和 `fast` 第一步就都落在 3，阶段二 `fast=0` 后 `slow=nums[3]=3`、`fast=nums[0]=3` 立刻相遇返回 3；若误以为「相遇点就是答案」而跳过阶段二，这里恰好也对，但换别的例子就错，说明不能省阶段二。
3. **输入 `[2,2,2,2,2]`（n=4，值域 1..4 合法）** → 期望 `2`。容易错：环入口是 2，但 0 的入度为 0、`nums[0]=2`，链长为 1，环是 `2→2` 自环；快慢指针第一轮 `slow=2, fast=nums[2]=2` 即相遇，阶段二返回 2。若把「自环」当成特殊情况特判反而容易写错，统一用 Floyd 即可。
4. **输入 `[1,2,3,4,5,6,7,8,9,9]`（重复值在末尾）** → 期望 `9`。容易错：链很长、环是自环 `9→9`，若循环条件写成 `while slow != fast` 但初始值设错（如都设 0），第一轮 `slow=1, fast=nums[nums[0]]=nums[1]=2`，正常推进，最终在 9 相遇；这类「长链 + 自环」是检验初始化是否正确的典型用例。
5. **输入 `[1,3,4,2,2]`** → 期望 `2`。容易错：相遇点在 4 而非 2，若直接返回相遇点会得到 4，必须走阶段二。

## 8. 面试追问与变体（3 条）

1. **追问：如果允许修改数组，有没有更简单的 O(n) 做法？** 思路：把每个数 x 放到下标 x-1 的位置（原地交换），若发现 `nums[x-1] == x` 则 x 重复，时间 O(n)、空间 O(1)，但违反「不修改」约束。
2. **追问：如果重复的数可能不止一个，怎么改？** 思路：Floyd 只能找「环入口」这一个，多重复值需要换思路，比如按值域二分统计（对每个 mid 数 ≤ mid 的个数），或哈希计数，复杂度会上升。
3. **追问：如何证明至少存在一个重复数？** 思路：n+1 个数放进 n 个取值（1..n）的抽屉，鸽巢原理直接给出；这也是题面进阶第一问的标准答案。
