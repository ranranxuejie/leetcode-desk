## 1. 一句话本质

把矩阵中每个元素 `(i, j)` 搬到它顺时针转 90° 后的新位置 `(j, n-1-i)`，且必须在原数组上完成，不能开一个同样大的新矩阵。

## 2. 读完题的第一反应

**朴素解法**：开一个 `n × n` 的新矩阵 `res`，对每个 `(i, j)` 令 `res[j][n-1-i] = matrix[i][j]`，最后再把 `res` 拷回 `matrix`。时间 O(n²) 已经是最优（每个元素至少要看一次），但空间 O(n²) 被题面那句「不占用额外内存空间能否做到？」直接否掉了。

**关键观察**：题目要的是「原地」。原地意味着每个元素只能被临时存进常数个变量里，所以必须把整个变换拆成若干个**两两交换**（swap）的步骤——因为 swap 天然是原地操作。那么问题就变成：90° 旋转能不能分解成几次「成对交换」？

能。看示例 1 的 3×3：

```
1 2 3        7 4 1
4 5 6   →    8 5 2
7 8 9        9 6 3
```

先沿主对角线翻转（转置）：

```
1 4 7
2 5 8
3 6 9
```

再左右翻转每一行：

```
7 4 1
8 5 2
9 6 3
```

正好是答案。**转置 + 水平翻转 = 顺时针 90°**。这两步都是纯 swap，各自原地完成。这就是下一步的入口。

## 3. 从暴力到最优

**第一步（暴力）**：新开矩阵，O(n²) 空间。瓶颈就是这块额外空间。

**第二步（消掉空间）**：把「一次性映射」拆成两次原地 swap。用示例 1 的 3×3 走一遍，把中间变量写出来：

转置阶段，只遍历上三角（`j > i`），对每对 `(i,j)` 和 `(j,i)` 交换：

- `(0,1)`：交换 `matrix[0][1]=2` 与 `matrix[1][0]=4` → 矩阵变成 `[[1,4,3],[2,5,6],[7,8,9]]`
- `(0,2)`：交换 `3` 与 `7` → `[[1,4,7],[2,5,6],[3,8,9]]`
- `(1,2)`：交换 `6` 与 `8` → `[[1,4,7],[2,5,8],[3,6,9]]`

此时矩阵已是转置结果。注意对角线元素 `(0,0)(1,1)(2,2)` 没动——它们本来就在转置下不动，这正是「只遍历上三角」的依据。

水平翻转阶段，每行内部首尾对换，`j` 只走到 `n//2`：

- 第 0 行：交换 `(0,0)=1` 与 `(0,2)=7` → `[7,4,1]`
- 第 1 行：交换 `(1,0)=2` 与 `(1,2)=8` → `[8,5,2]`
- 第 2 行：交换 `(2,0)=3` 与 `(2,2)=9` → `[9,6,3]`

得到 `[[7,4,1],[8,5,2],[9,6,3]]`，与示例一致。中间列（n 为奇数时）不动，所以 `j < n//2`。

**为什么这样就消掉了瓶颈**：两次遍历各自只做 `O(n²)` 次 swap，每次 swap 只用一个临时变量 `tmp`，额外空间是 O(1)。时间仍是 O(n²)，没有变差。

**另一条等价路线（顺带提一句，面试可加分）**：也可以「先上下翻转，再转置」，或者用四元组循环 `(i,j) → (j,n-1-i) → (n-1-i,n-1-j) → (n-1-j,i)` 一次搬四个元素。后者更「炫」，但四个下标容易写错，转置+翻转更稳，推荐先写稳的。

## 4. 正确性：为什么不会漏、不会重

用**不变量**说清楚。

**转置阶段的不变量**：循环按 `i` 从 0 到 n-1、`j` 从 `i+1` 到 n-1 进行。任意时刻，所有满足 `j < i` 的位置 `(i,j)` 已经和它的对称位置 `(j,i)` 交换过；所有 `j > i` 的位置尚未处理；对角线 `(i,i)` 永远不碰。因为每一对 `(i,j)` 与 `(j,i)`（`i≠j`）恰好被枚举一次（枚举的是 `j>i` 那一半），所以**每对恰好交换一次，不漏不重**，结束后 `matrix[i][j] == 原 matrix[j][i]`，即完成转置。

**翻转阶段的不变量**：对每一行，`j` 从 0 到 `n//2 - 1`，把 `(i,j)` 与 `(i, n-1-j)` 交换。每一对左右对称位置恰好被枚举一次（只取左半），所以每对交换一次，结束后第 i 行反转。

**组合的正确性**：设原矩阵为 A。转置得 B，`B[i][j] = A[j][i]`。水平翻转得 C，`C[i][j] = B[i][n-1-j] = A[n-1-j][i]`。而顺时针 90° 旋转的目标正是 `C[i][j] = A[n-1-j][i]`（原第 `n-1-j` 行第 `i` 列的元素落到新第 `i` 行第 `j` 列）。两者相等，故结果正确。

**为什么不会「覆盖丢数据」**：所有写操作都是 swap，写之前先把旧值存进 `tmp`，不存在「先覆盖后读取」的问题——这是原地算法正确性的核心，暴力映射法如果直接写回原数组就会踩这个坑。

## 5. 完整代码（Python）

```python
from typing import List

class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        n = len(matrix)

        # 第一步：沿主对角线转置。
        # 只遍历上三角 (j > i)，因为 (i,j) 与 (j,i) 是一对，
        # 遍历一半即可保证每对恰好交换一次；对角线元素不动。
        for i in range(n):
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

        # 第二步：每一行做水平翻转（左右对换）。
        # j 只走到 n//2，保证每对左右对称位置只交换一次；
        # n 为奇数时中间那一列自然不动。
        for i in range(n):
            for j in range(n // 2):
                matrix[i][j], matrix[i][n - 1 - j] = matrix[i][n - 1 - j], matrix[i][j]
```

Python 的元组赋值 `a, b = b, a` 底层就是借助临时变量完成的 swap，等价于手写 `tmp`，所以是原地操作。

## 6. 复杂度

**时间 O(n²)**：转置阶段枚举上三角，次数为 `n(n-1)/2`；翻转阶段枚举每行左半，次数为 `n * (n//2)`。两者相加是 `Θ(n²)`。这里 n 是矩阵的边长，元素总数是 n²，而每个元素至少要被读一次才能确定它的新位置，所以 O(n²) 是下界，本解法达到下界，时间最优。

**空间 O(1)**：除了循环变量 `i, j` 和 swap 用的一个临时变量，没有申请任何与 n 相关的存储。注意**没有** `log n` 项——本题不涉及分治或递归，递归栈深度为 0。如果面试官问「递归写法呢」，那才会引入 O(log n) 或 O(n) 的栈空间，但本题不需要递归。

## 7. 边界与反例（至少 4 条）

1. **n = 1**：输入 `[[5]]` → 期望 `[[5]]`。容易错在：以为至少要转一下，或循环边界写成 `range(1, n)` 之外的东西导致越界；实际上两个循环都空转，直接返回，正确。

2. **n = 2**：输入 `[[1,2],[3,4]]` → 期望 `[[3,1],[4,2]]`。容易错在：转置时误用 `range(n)` 全遍历，导致每对交换两次、又转回原样；必须 `range(i+1, n)`。

3. **n 为奇数（如 3）**：中间列 `[2,5,8]` 在翻转阶段不该动。容易错在：翻转循环写成 `range(n)` 而不是 `range(n//2)`，导致中间列被交换两次、等于没变（碰巧对）但左右两列被多交换一次而错乱；更隐蔽的是 `range((n+1)//2)` 会把中间列和自己交换，虽结果对但逻辑冗余。

4. **含重复值或负数**：输入 `[[-1,-1],[-1,-1]]` → 期望 `[[-1,-1],[-1,-1]]`。容易错在：调试时用「值是否变化」判断对错，全相同值看不出 bug；应改用带下标的唯一值（如 `i*10+j`）构造测试。

5. **非方阵的误用**：题面明确 N×N，若有人拿 2×3 的矩阵来测，转置后形状变成 3×2，`matrix[j][i]` 会越界。这不是本题的合法输入，但要能说清「为什么本题不需要处理矩形矩阵」——因为旋转 90° 对非方阵会改变维度，无法原地完成。

## 8. 面试追问与变体（3 条）

1. **追问：逆时针 90° 怎么做？** 一句话思路：先转置，再上下翻转（或先左右翻转再转置），顺序与顺时针相反，仍是两次原地 swap。

2. **追问：旋转 180° 呢？** 一句话思路：中心对称交换，`(i,j)` 与 `(n-1-i, n-1-j)` 对换，只遍历左上四分之一区域，一趟 O(n²) 搞定。

3. **追问：如果允许 O(n²) 额外空间，有没有更直观的写法？** 一句话思路：直接 `res[j][n-1-i] = matrix[i][j]` 建新矩阵再拷回，代码短、不易错，代价是空间；面试时先讲这个作为 baseline，再优化到原地，能体现思考层次。
