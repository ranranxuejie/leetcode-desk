## 1. 一句话本质

在字符串 s 的所有子序列里，找出长度最大的那个「正着读和反着读一样」的序列——注意是**子序列**（可以跳字符、不能换顺序），不是子串（必须连续）。

## 2. 读完题的第一反应

**朴素解法**：枚举所有子序列（共 2^n 个），逐个判断是否回文，取最长。n 最大到 1000 时，2^1000 是天文数字，直接卡死。就算只枚举「回文子序列」也逃不掉指数级。

**关键观察**：回文有一个天然的自相似结构——一个回文串去掉首尾两个相同字符，剩下的还是回文。反过来想：如果 s 的首尾字符相同，那它们俩可以「配对」进答案，问题就缩小到中间那段；如果首尾不同，那至少有一个端点的字符不会出现在最优解的两端，可以分别「砍掉左边」或「砍掉右边」再试。

这个「大问题 = 小问题 + 一个决策」的形状，正是**区间 DP** 的典型信号：状态用 `(i, j)` 表示「只考虑 s[i..j] 这一段」时的答案，转移只依赖更短的区间。一旦你意识到答案只跟「区间」有关、跟区间外面是什么无关，DP 就成立了。

## 3. 从暴力到最优

**第 0 步：暴力**。枚举子序列 → O(2^n · n)。瓶颈在「枚举」本身，因为大量子序列被重复判断。

**第 1 步：发现重叠子问题**。以 `s = "bbbab"` 为例，考虑区间 `[0,4]`（整个串）。首字符 `s[0]='b'`，尾字符 `s[4]='b'`，相同，于是 `dp[0][4] = dp[1][3] + 2`。而 `dp[1][3]` 对应子串 `"bba"`，首 `'b'` 尾 `'a'` 不同，于是 `dp[1][3] = max(dp[2][3], dp[1][2])`。你看，`dp[1][2]`（子串 `"bb"`）会被 `dp[1][3]` 和别的区间反复用到——这就是重叠子问题，暴力会重复算，DP 只算一次。

**第 2 步：定义状态**。`dp[i][j]` = 子串 `s[i..j]` 的最长回文子序列长度。区间长度从 1 开始往上推，因为长区间依赖短区间。

**第 3 步：转移**（这是整道题的核心，务必背下来它的**理由**而不是形式）：

- 若 `s[i] == s[j]`：这两个字符可以同时作为回文的两端，`dp[i][j] = dp[i+1][j-1] + 2`。
- 若 `s[i] != s[j]`：它们不可能同时出现在回文的两端（回文两端必须相等），所以最优解至少放弃其中一个端点，`dp[i][j] = max(dp[i+1][j], dp[i][j-1])`。

**第 4 步：用 "bbbab" 走一遍**（只列关键区间，下标 0-based）：

| 区间 | 子串 | 首尾是否相同 | 计算 | dp 值 |
|---|---|---|---|---|
| [0,0] | "b" | — | 单字符 | 1 |
| [1,1] | "b" | — | 单字符 | 1 |
| [2,2] | "b" | — | 单字符 | 1 |
| [3,3] | "a" | — | 单字符 | 1 |
| [4,4] | "b" | — | 单字符 | 1 |
| [0,1] | "bb" | 同 | dp[1][0]+2 = 0+2 | 2 |
| [1,2] | "bb" | 同 | dp[2][1]+2 = 0+2 | 2 |
| [2,3] | "ba" | 异 | max(dp[3][3], dp[2][2]) = max(1,1) | 1 |
| [3,4] | "ab" | 异 | max(dp[4][4], dp[3][3]) = 1 | 1 |
| [0,2] | "bbb" | 同 | dp[1][1]+2 = 1+2 | 3 |
| [1,3] | "bba" | 异 | max(dp[2][3], dp[1][2]) = max(1,2) | 2 |
| [2,4] | "bab" | 同 | dp[3][3]+2 = 1+2 | 3 |
| [0,3] | "bbba" | 异 | max(dp[1][3], dp[0][2]) = max(2,3) | 3 |
| [0,4] | "bbbab" | 同 | dp[1][3]+2 = 2+2 | **4** |

答案 `dp[0][4] = 4`，对应 "bbbb"。注意 `dp[i+1][j-1]` 在 `i+1 > j-1`（即区间长度 ≤ 2）时视为 0，这是边界。

**第 5 步：空间优化（可选）**。观察转移只用到 `dp[i+1][j-1]`、`dp[i+1][j]`、`dp[i][j-1]`，都是「下一行」和「本行左边」。所以可以压成一维，从右往左、从下往上填。面试里先写二维版讲清楚，再提一维优化即可。

## 4. 正确性：为什么不会漏、不会重

用**不变量**说：对任意区间 `[i,j]`，`dp[i][j]` 恰好等于 `s[i..j]` 的最长回文子序列长度。对区间长度做归纳。

- **基**：长度 1，单字符本身是回文，长度 1，正确。
- **归纳**：设长度 < L 的区间都正确，考虑长度 L 的区间 `[i,j]`。
  - 若 `s[i]==s[j]`：任何回文子序列若同时用到 `s[i]` 和 `s[j]`，它们必在两端（因为顺序不能变、且两端字符相等），中间部分必是 `s[i+1..j-1]` 的回文子序列，长度 ≤ `dp[i+1][j-1]+2`；而 `dp[i+1][j-1]+2` 本身构造得出，所以取等。**不会漏**：最优解若不用这对端点，长度不可能超过 `dp[i+1][j-1]+2`（因为 `dp[i+1][j-1]` 已是中间段最优）。
  - 若 `s[i]!=s[j]`：最优回文子序列不可能同时以 `s[i]` 和 `s[j]` 为两端（两端必须相等），所以它要么不含 `s[i]`（落在 `[i+1,j]`），要么不含 `s[j]`（落在 `[i,j-1]`），两者取大即覆盖全部可能。**不会重**：`max` 只是取较大者，重复计算不影响正确性。

这个论证的关键是「回文两端必须相等」这一结构性事实，它把「枚举所有子序列」压缩成了「只做一次二选一决策」。

## 5. 完整代码（Python）

```python
class Solution:
    def longestPalindromeSubseq(self, s: str) -> int:
        n = len(s)
        if n == 0:
            return 0
        # dp[i][j] = s[i..j] 的最长回文子序列长度
        dp = [[0] * n for _ in range(n)]

        # 区间长度从 1 到 n 递推，保证长区间依赖的短区间已算好
        for length in range(1, n + 1):
            for i in range(0, n - length + 1):
                j = i + length - 1
                if i == j:
                    # 单字符，回文长度 1
                    dp[i][j] = 1
                elif s[i] == s[j]:
                    # 首尾相同，可配对，中间段长度 +2
                    # 长度 2 时 i+1 > j-1，dp 取 0，正好是 +2
                    dp[i][j] = dp[i + 1][j - 1] + 2
                else:
                    # 首尾不同，至少放弃一个端点，取两种砍法的较大值
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])

        return dp[0][n - 1]
```

一维空间优化版（面试加分项，思路：`dp[j]` 存「当前行」的值，`prev` 暂存 `dp[i+1][j-1]`）：

```python
class Solution:
    def longestPalindromeSubseq(self, s: str) -> int:
        n = len(s)
        dp = [0] * n          # dp[j] 表示以当前 i 为左端、j 为右端的结果
        for i in range(n - 1, -1, -1):
            dp[i] = 1
            prev = 0          # 相当于 dp[i+1][j-1]，初始为 0
            for j in range(i + 1, n):
                tmp = dp[j]   # 保存 dp[i+1][j]，下一轮 j+1 时它就是 dp[i+1][j-1]
                if s[i] == s[j]:
                    dp[j] = prev + 2
                else:
                    dp[j] = max(dp[j], dp[j - 1])
                prev = tmp
        return dp[n - 1]
```

## 6. 复杂度

- **时间 O(n²)**：两层循环，外层 `length` 有 n 种取值，内层 `i` 平均约 n/2 个，合计约 n²/2 次转移，每次转移 O(1)。n 来自字符串长度，没有 log 项。
- **空间 O(n²)**：二维 `dp` 表是 n×n。一维优化后降到 **O(n)**，因为每行只依赖下一行和本行左侧，用滚动数组即可。

## 7. 边界与反例（至少 4 条）

1. `s = "a"` → 期望 `1` → 容易错在把 `dp[i+1][j-1]` 的下标越界（i+1=1 > j-1=-1），必须单独处理单字符或让越界访问返回 0。
2. `s = "ab"` → 期望 `1` → 首尾不同，`max(dp[1][1], dp[0][0]) = 1`；容易错在误以为「不同就返回 0」。
3. `s = "aa"` → 期望 `2` → 首尾相同，`dp[1][0]` 越界，必须视为 0 才能得到 2；容易错在没处理长度 2 的边界。
4. `s = "abcba"` → 期望 `5` → 整串本身是回文，容易错在只考虑「砍端点」而漏掉首尾配对这条分支。
5. `s = "cbbd"` → 期望 `2` → 首尾 `c`、`d` 不同，答案来自中间 "bb"；容易错在把子序列当成子串，误答 2 却说不清为什么不是 3。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求返回具体的最长回文子序列（不只是长度）？** 思路：在 DP 表上从 `(0,n-1)` 回溯，首尾相同就收集两端字符并向内走，不同就朝 dp 值大的方向走，最后拼出序列。
2. **追问：能不能用「s 和 reverse(s) 的最长公共子序列」来解？** 思路：可以，`LCS(s, s[::-1])` 的长度等于答案；但要注意这只能求长度，且 LCS 的 DP 是 O(n²) 空间，和本题等价，面试官想听你说出「为什么等价」——回文子序列反转后仍是它自己，所以它同时是 s 和 reverse(s) 的公共子序列。
3. **追问：如果改成「最长回文子串」（必须连续）怎么做？** 思路：状态定义要加「必须以 i、j 为两端」的约束，转移变成 `s[i]==s[j] and dp[i+1][j-1]` 才成立，或者用中心扩展 O(n²)/Manacher O(n)。

## 9. 举一反三（2-3 道同类题）

- **5. 最长回文子串**：同样是区间 DP，区别是要求连续，转移多一个「内部必须也是回文」的与条件。
- **1143. 最长公共子序列**：同样是二维区间/前缀 DP，转移是「末尾相同则 +1，否则取 max」，和本题的骨架几乎一样。
- **1312. 让字符串成为回文串的最少插入次数**：区间 DP，`dp[i][j]` 表示把 `s[i..j]` 变回文的最少插入数，首尾相同则等于内部，不同则 `min(左, 右)+1`，和本题是「同一张表、换一种语义」。
