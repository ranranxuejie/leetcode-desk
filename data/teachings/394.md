## 1. 一句话本质

把「带嵌套重复计数的字符串」按括号层级逐层展开成最终字符串——本质是**处理嵌套结构**，而嵌套结构天然对应栈或递归。

## 2. 读完题的第一反应

**朴素解法**：反复用正则或字符串查找，找到最内层的 `k[...]`（里面不含括号），展开它，替换回原串，再找下一个最内层，直到没有括号。

它卡在哪？每次替换都要重新扫描整个字符串，而嵌套深度为 d、总长为 n 时，最坏要做 O(d) 轮、每轮 O(n)，总复杂度 O(n·d)。示例 2 的 `3[a2[c]]` 只有两层还好，但如果输入是 `2[2[2[...2[a]...]]]` 嵌套 30 层，每轮都要重扫，白白浪费。

**关键观察**：`k[encoded_string]` 里，`encoded_string` 本身可能又含 `k[...]`。也就是说「遇到 `[` 时，我要先记住当前的 k 和已拼好的前缀，转去处理里面；遇到 `]` 时，里面处理完了，把结果重复 k 次接回前缀」。这正是**后进先出**——最近遇到的 `[` 最先被 `]` 闭合。所以用栈，或者用递归（递归调用栈就是栈）。

这个观察直接给出下一步：扫描一遍，遇到 `[` 压栈、遇到 `]` 弹栈，每个字符只处理一次，O(n)。

## 3. 从暴力到最优

**暴力**（以 `3[a2[c]]` 为例）：

- 第 1 轮：找最内层 `2[c]` → 展开成 `cc`，串变成 `3[acc]`
- 第 2 轮：找 `3[acc]` → 展开成 `accaccacc`
- 结束。两轮，每轮扫全串。

嵌套 30 层时就是 30 轮 × 每轮 O(n)，这就是瓶颈。

**栈解法**，一遍扫描，维护两个栈：`num_stack` 存重复次数，`str_stack` 存「进入括号前已拼好的前缀」。当前串 `cur` 和当前数字 `num` 是滚动变量。

走 `3[a2[c]]`：

| 字符 | 动作 | num | cur | num_stack | str_stack |
|---|---|---|---|---|---|
| `3` | num=3 | 3 | "" | [] | [] |
| `[` | 压栈，重置 | 0 | "" | [3] | [""] |
| `a` | cur="a" | 0 | "a" | [3] | [""] |
| `2` | num=2 | 2 | "a" | [3] | [""] |
| `[` | 压栈，重置 | 0 | "" | [3,2] | ["","a"] |
| `c` | cur="c" | 0 | "c" | [3,2] | ["","a"] |
| `]` | 弹 2 和 "a"，cur="a"+"c"*2="acc" | 0 | "acc" | [3] | [""] |
| `]` | 弹 3 和 ""，cur=""+"acc"*3="accaccacc" | 0 | "accaccacc" | [] | [] |

每个字符进出栈各一次，O(n)。瓶颈被消掉的关键：**不再回头重扫**，`]` 一出现就地结算，前缀早就存在栈里了。

## 4. 正确性：为什么不会漏、不会重

用**不变量**说清楚。定义扫描到位置 i 时的状态：

> 不变量：`cur` 恰好等于「从最近一个未闭合的 `[` 之后到 i 为止，已经解码好的字符串」；`str_stack` 栈顶是「该 `[` 之前已拼好的前缀」；`num_stack` 栈顶是「该 `[` 对应的重复次数 k」。

逐字符验证这个不变量在每步后仍成立：

- **字母**：直接追加到 `cur`，`cur` 的含义不变，成立。
- **数字**：只更新 `num`，不影响 `cur` 的含义，成立。
- **`[`**：把当前 `cur` 和 `num` 压栈，然后 `cur` 重置为空——此时「最近未闭合的 `[`」变成了这个新 `[`，它后面还没内容，`cur=""` 正确，成立。
- **`]`**：弹出 k 和前缀 p，`cur = p + cur * k`。因为 `cur` 正是这个 `[` 内部解码好的串（由归纳假设），重复 k 次再接回前缀 p，恰好是「这个 `[` 整体解码后接在前缀后面」的结果；弹栈后「最近未闭合的 `[`」回到上一层，`cur` 的含义正好对上，成立。

扫描结束时没有未闭合的 `[`（题面保证括号合法），所以 `cur` 就是整个串的解码结果。**不漏**：每个字符都被处理且只被处理一次；**不重**：`]` 结算时只把内部串乘 k 接回前缀，前缀本身不会再被乘一次（它存在栈里，是「外面」的）。

## 5. 完整代码（Python）

```python
class Solution:
    def decodeString(self, s: str) -> str:
        num_stack = []   # 存每个 '[' 对应的重复次数 k
        str_stack = []   # 存每个 '[' 之前已经拼好的前缀
        cur = ""         # 当前层正在拼的字符串
        num = 0          # 当前正在读的重复次数（可能多位数字）

        for ch in s:
            if ch.isdigit():
                # 多位数字：3 后面跟 12 要拼成 312 而不是 3 和 12
                num = num * 10 + int(ch)
            elif ch == '[':
                # 进入新一层：把「外面的」次数和前缀存起来，本层从空开始
                num_stack.append(num)
                str_stack.append(cur)
                num = 0
                cur = ""
            elif ch == ']':
                # 本层结束：弹出次数和前缀，把本层结果重复 k 次接回前缀
                k = num_stack.pop()
                prefix = str_stack.pop()
                cur = prefix + cur * k
            else:
                # 普通字母，直接追加到当前层
                cur += ch

        return cur
```

注意 `cur += ch` 在 Python 里对短串没问题；若担心长串拼接开销，可把 `cur` 换成 list 再 `"".join`，但本题 n ≤ 30 输入、输出 ≤ 10^5，直接拼足够。

## 6. 复杂度

设输入串长度为 n（题面 n ≤ 30），输出串长度为 m（题面 m ≤ 10^5）。

- **时间 O(n + m)**：扫描 n 个字符，每个字符 O(1) 处理（数字拼接、压弹栈）；但 `cur * k` 和 `prefix + ...` 的拼接总代价与最终输出长度 m 成正比——每个输出字符在它被生成的那一层只被写一次，不会重复写。所以是 n 的扫描 + m 的输出构造。
- **空间 O(n + m)**：栈的深度最多是嵌套层数 d ≤ n，每层存一个前缀，前缀总长不超过 m；`cur` 和最终结果占 O(m)。严格说栈里存的前缀是「已生成但还没被乘 k 展开」的部分，总量不超过 m。

这里没有 log n——没有二分、没有按位分解，纯线性。

## 7. 边界与反例（至少 4 条）

1. **`s = "3[a]"`** → `"aaa"`。容易错：把 `]` 结算时忘了加前缀（前缀是空串，`"" + "a"*3`），若写成 `cur = cur * k` 而丢掉 `prefix`，在示例 3 这种「括号前有字母」的输入上就会丢字符。
2. **`s = "10[a]"`** → 十个 `a`。容易错：数字是多位的，若每个数字字符都当成独立的 k（`1` 和 `0`），会得到错误次数。必须 `num = num*10 + digit`。
3. **`s = "2[abc]3[cd]ef"`** → `"abcabccdcdcdef"`。容易错：两个 `]` 结算后，`ef` 要接在 `cur` 后面；如果 `]` 结算时把 `cur` 重置为空而不是保留，`ef` 就丢了。代码里 `]` 分支不重置 `cur`，正确。
4. **`s = "abc3[cd]xyz"`** → `"abccdcdcdxyz"`。容易错：括号前有普通字母 `abc`，它属于「外层前缀」，`[` 时压栈、`]` 时接回；若把 `abc` 也乘了 3，就错了。
5. **`s = "2[2[a]]"`** → `"aaaa"`。容易错：内层 `2[a]` 先结算成 `aa`，外层再乘 2 得 `aaaa`；若顺序反了（先乘外层）会得 `2[aa]` 再展开仍是 `aaaa`——这例恰好对，但换成 `2[3[a]b]` 就能暴露顺序错误，正确是 `aaabaaab`。

## 8. 面试追问与变体（3 条）

1. **追问：如果编码里允许 `k` 为 0 或负数怎么办？** 思路：题面保证正整数，若放开，`k=0` 时 `]` 结算直接丢弃本层（`cur = prefix`），负数需先约定语义（通常非法），加校验即可。
2. **追问：不用栈，用递归怎么写？** 思路：写 `dfs(i)` 返回「从 i 开始解码到匹配的 `]` 为止的串和下一个位置」，遇到 `[` 递归进去，遇到 `]` 返回，递归调用栈替代显式栈。
3. **追问：如果要求支持转义字符（如 `\[` 表示字面量左括号）？** 思路：扫描时多一个「上一字符是否反斜杠」的状态，遇到转义就跳过特殊含义、按普通字符追加，栈逻辑不变。
