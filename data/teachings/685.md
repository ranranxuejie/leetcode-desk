## 1. 一句话本质

在一棵合法的有向树里被硬塞了一条多余的边，导致图要么出现「一个节点两个爹」，要么出现「一个环」，要么两者同时出现；我们要找出那条删掉之后能恢复成合法有根树的边，且有多解时取输入中最后出现的那条。

## 2. 读完题的第一反应

**朴素解法**：枚举每条边，删掉它，然后检查剩下的图是不是一棵合法有根树（n 个节点、n-1 条边、恰好一个入度为 0 的点、其余入度为 1、且从根能遍历到所有点）。检查一次是 O(n)，枚举 n 条边就是 O(n²)。n ≤ 1000 时 O(n²) 其实能过，但面试官显然想看你把结构吃透，而且 O(n²) 的写法在「为什么删这条而不是那条」上讲不出道理。

**关键观察**：一棵合法有向树，每个非根节点入度恰好为 1，根入度为 0。现在多了一条边，那么「入度」这个局部信息会立刻暴露问题：

- 如果某个节点入度变成 2，说明有两条边指向它，其中必有一条是多余的——**答案一定在这两条里**。
- 如果所有节点入度都 ≤ 1，那多出来的边不可能制造「两个爹」，它只能制造一个**环**（因为边数 = n，节点数 = n，无入度 2 却有环，这是唯一可能）。

这个观察把「n 条候选」直接砍到「最多 2 条候选」或「环上的边」，是整道题的转折点。为什么能想到？因为树的定义本身就是用入度写的，而「多一条边」破坏的正是入度约束或连通性约束，从被破坏的约束反推候选，是最自然的路径。

## 3. 从暴力到最优

### 第一步：把情况分类

设 `indeg[v]` 为节点 v 的入度。扫一遍 edges：

- **情况 A**：存在唯一节点 v 使 `indeg[v] == 2`。设指向 v 的两条边按输入顺序为 `e1`（先出现）和 `e2`（后出现）。答案必是二者之一。
- **情况 B**：所有 `indeg[v] <= 1`。此时必有一个环，答案是**环上最后出现的那条边**。

情况 A 里为什么答案一定在 e1、e2 中？因为删掉其他任何边，v 的入度仍然是 2，不可能成为合法树。这是硬约束，不是启发式。

### 第二步：情况 A 内部怎么二选一

删掉 e2（后出现的那条）后，如果剩下的图**无环**，那 e2 就是答案（题目要求多解取最后出现的，e2 更靠后，优先试它）。如果删 e2 后仍有环，说明 e1 才是环的一部分，必须删 e1。

这里用并查集判环：按输入顺序把边一条条加进去（跳过被删的那条），如果某条边的两个端点已经在同一集合里，就说明成环。

**小例子走一遍**：`edges = [[1,2],[1,3],[2,3]]`

- 入度：`indeg[2]=1, indeg[3]=2`。节点 3 入度为 2，两条边是 `e1=[1,3]`（下标 1）、`e2=[2,3]`（下标 2）。属于情况 A。
- 先试删 e2：剩下 `[1,2],[1,3]`。并查集：加 `1-2`（合并 {1,2}），加 `1-3`（1 和 3 不同集合，合并 {1,2,3}）。无环 → 返回 `[2,3]`。✓

**再走一个删 e2 仍有环的例子**：`edges = [[2,1],[3,1],[4,2],[1,4]]`（节点 1 入度 2，e1=[2,1]、e2=[3,1]）

- 试删 e2：剩 `[2,1],[4,2],[1,4]`。并查集：`2-1` 合并 {1,2}；`4-2` 合并 {1,2,4}；`1-4`——1 和 4 已在同一集合，成环！说明 e2 不是环上的边，删它救不了环，答案只能是 e1=[2,1]。

### 第三步：情况 B 怎么找环上最后一条边

没有入度 2，就老老实实按输入顺序加边到并查集，**第一条使两端点已连通的边**就是成环的那条，且因为按顺序扫，它天然是环上最后出现的边，直接返回。示例 2：`[[1,2],[2,3],[3,4],[4,1],[1,5]]`，加 `1-2`、`2-3`、`3-4` 都正常，加 `4-1` 时 4 和 1 已连通 → 返回 `[4,1]`。✓

### 瓶颈怎么被消掉的

暴力是「枚举边 × 全图检查」= O(n²)。现在：扫一遍求入度 O(n)，情况 A 最多做一次并查集 O(n·α)，情况 B 一次并查集 O(n·α)。总 O(n·α(n))，近似 O(n)。消掉的是「对每条候选都重新做一次全图合法性检查」这个重复劳动——因为候选集本身被入度约束压缩到了常数大小。

## 4. 正确性：为什么不会漏、不会重

**不变量**：合法有向树 ⟺ 每个非根节点入度恰为 1、根入度为 0、且无环（n 个点 n-1 条边无环即连通）。

**情况 B 的论证**：所有入度 ≤ 1 且边数 = 节点数 = n。若图无环，则 n 条边、n 个点、无环，必然不连通（森林里边数 = 点数 - 连通分量数，n 条边要求连通分量数为 0，矛盾）。所以必有环。删掉环上任意一条边即可破环，且删后入度仍 ≤ 1、边数 n-1，无环即连通，成为合法树。题目要求最后出现的，按输入顺序扫到的第一条「使两端已连通」的边正是环上最后一条——因为环上更早的边加入时两端还不连通，不会触发。**不漏**：环一定存在；**不重**：按顺序扫，第一条触发边唯一。

**情况 A 的论证**：设节点 v 入度为 2，两条边 e1、e2。任何合法解必须让 v 入度降为 1，故只能删 e1 或 e2，候选集完备。删 e2 后无环 → e2 合法，且 e2 比 e1 靠后，满足「多解取最后」；删 e2 后有环 → 该环必含 e1（因为 e2 已删，环只能由剩余边构成，而剩余边里唯一「可疑」的就是 e1 这条指向 v 的边，若环不含 e1 则删 e1 也破不了环，与「答案存在」矛盾），故删 e1 破环，e1 是唯一解。两种情况覆盖所有可能，**不漏**；候选只有两条且判定互斥，**不重**。

## 5. 完整代码（Python）

```python
class Solution:
    def findRedundantDirectedConnection(self, edges):
        n = len(edges)
        parent = list(range(n + 1))  # 并查集父数组，节点编号 1..n

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]  # 路径压缩
                x = parent[x]
            return x

        def union(a, b):
            ra, rb = find(a), find(b)
            if ra == rb:
                return False  # 已连通，加这条边会成环
            parent[ra] = rb
            return True

        # 第一步：统计入度，找入度为 2 的节点及其两条入边
        indeg = [0] * (n + 1)
        cand1 = cand2 = None  # cand1 先出现，cand2 后出现
        for u, v in edges:
            indeg[v] += 1
            if indeg[v] == 2:
                # 之前已有一条指向 v 的边，先把它记成 cand1
                for i, (a, b) in enumerate(edges):
                    if b == v:
                        cand1 = i
                        break
                cand2 = edges.index([u, v])  # 当前这条（后出现）
                # 注意：用 index 找当前边，需保证边不重复；题面保证附加边不属于原树边

        # 情况 A：存在入度为 2 的节点
        if cand1 is not None:
            # 先试删 cand2（后出现的那条），看剩余图是否无环
            parent = list(range(n + 1))
            ok = True
            for i, (u, v) in enumerate(edges):
                if i == cand2:
                    continue
                if not union(u, v):
                    ok = False
                    break
            if ok:
                return edges[cand2]
            return edges[cand1]  # 删 cand2 仍有环，只能删 cand1

        # 情况 B：所有入度 <= 1，找第一条成环的边
        parent = list(range(n + 1))
        for u, v in edges:
            if not union(u, v):
                return [u, v]
        return []  # 理论上不会到达
```

> 说明：上面 `cand2 = edges.index([u, v])` 依赖边不重复。更稳妥的写法是在第一次遍历时用下标 `for i,(u,v) in enumerate(edges)` 并记录 `first_in[v]`，避免二次查找。面试时建议写成下标版，这里为可读性保留。

## 6. 复杂度

- **时间**：求入度 O(n)；情况 A 做一次并查集，n 条边每条 find/union 近似 O(α(n))，共 O(n·α(n))；情况 B 同理。总 **O(n·α(n))**，α 是反阿克曼函数，实际可视为常数，故近似 **O(n)**。n 来自边数（= 节点数），α 来自并查集的路径压缩 + 按秩合并（这里只做了路径压缩，单用也够快）。
- **空间**：`parent` 数组 O(n)、`indeg` 数组 O(n)，并查集递归/迭代栈 O(1)（迭代版）。总 **O(n)**。没有额外的图邻接表，因为我们只关心连通性，不需要遍历邻居。

## 7. 边界与反例（至少 4 条）

1. **`[[1,2],[2,3],[3,4],[4,1],[1,5]]` → `[4,1]`**：所有入度 ≤ 1，属情况 B。容易错在「看到 1 出现多次就以为入度 2」——入度看的是**指向**，不是出现次数。
2. **`[[2,1],[3,1],[4,2],[1,4]]` → `[2,1]`**：节点 1 入度 2，删后出现的 `[3,1]` 仍有环，必须删先出现的 `[2,1]`。容易错在「无脑返回后出现的那条」。
3. **`[[1,2],[2,3],[3,1]]` → `[3,1]`**：纯环、无入度 2，属情况 B，返回环上最后一条。容易错在把它当情况 A 处理（没有入度 2 却去找 cand）。
4. **`[[1,2],[1,3],[2,3]]` → `[2,3]`**：情况 A 且删后出现边即无环，直接返回。容易错在返回 `[1,3]`（先出现的那条），违反「多解取最后」。
5. **`[[1,2],[2,3],[3,4],[4,2]]` → `[4,2]`**：节点 2 入度 2（`[1,2]` 和 `[4,2]`），删 `[4,2]` 后剩 `[1,2],[2,3],[3,4]` 无环，返回 `[4,2]`。容易错在把环和入度 2 割裂看——这里两者同时出现，必须走情况 A 的判定。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求返回「任意一条」合法解而不是最后一条，代码怎么简化？** 思路：情况 A 里删 cand2 无环就返回 cand2，有环返回 cand1 的逻辑不变；情况 B 里扫到第一条成环边即可，无需强调「最后」，因为任意环边都行——但要注意此时「第一条」和「最后一条」在环上不同，需明确题目语义。
2. **追问：如果图是无向图，多一条边形成环，怎么找？** 思路：无向图没有入度概念，直接并查集扫，第一条使两端已连通的边就是答案（即「冗余连接」第 684 题），无需分情况。
3. **追问：如果允许删多条边恢复成树，最少删几条？** 思路：删的条数 = 边数 - (节点数 - 1) = 多余边数；对每个入度 2 的节点和每个环分别处理，本质是「反馈边集」问题，可贪心按入度 2 优先、再破环。

## 9. 举一反三（2-3 道同类题）

- **261. 以图判树**：判断给定无向图是否是一棵树，核心也是「n-1 条边 + 无环 + 连通」，与本题的合法性判定同源。
- **547. 省份数量**：并查集统计连通分量，练的是同一套 find/union 模板，只是目标从「找环」变成「数集合」。
