## 1. 一句话本质

在整棵树里找**唯一一个**「p 和 q 分居两侧（或自己就是其中一方）」的节点——它是 p、q 往上走第一次交汇的地方。

## 2. 读完题的第一反应

**朴素解法**：对每个节点 x，判断「p 和 q 是否都在 x 的子树里」，找到**最深**的那个 x。判断一次要遍历子树，对 n 个节点各判一次，最坏 O(n²)（链状树）。瓶颈在于：每个节点都在重复扫描同一批子树。

**关键观察**：题目保证 p、q 都存在，且 `p != q`。那么从根往下走，p 和 q 的位置关系只有三种：

1. p、q 都在左子树 → 答案在左子树里；
2. p、q 都在右子树 → 答案在右子树里；
3. p、q 一个在左、一个在右（或当前节点就是 p 或 q）→ **当前节点就是答案**。

这个观察之所以能直接导向解法，是因为它把「判断两个节点在不在子树里」变成了「递归返回值非空即代表子树里至少有一个目标节点」。也就是说，**一次后序遍历就能同时回答所有子树的「含不含 p/q」问题**，不用重复扫描。

## 3. 从暴力到最优

**暴力**：`contains(x, target)` 遍历子树，对每个 x 调用两次，再取最深。复杂度 O(n²)，空间 O(h)。

**优化思路**：把「子树里有没有 p/q」这个信息**自底向上传**。定义递归函数 `dfs(node)` 的返回值语义：

- 返回 `None`：这棵子树里 p、q 都没有；
- 返回 `p` 或 `q`：这棵子树里**只**找到了其中一个；
- 返回某个节点 x：这棵子树里 p、q 都找到了，且 x 就是它们的 LCA。

这样每个节点只被访问一次，O(n)。

**小例子走一遍**：树 `[3,5,1,6,2,0,8,null,null,7,4]`，p=5，q=4。

```
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4
```

后序递归（自底向上）：

| 节点 | 左返回 | 右返回 | 本节点判断 | 返回 |
|---|---|---|---|---|
| 7 | None | None | 不是 p/q | None |
| 4 | None | None | 是 q | 4 |
| 2 | None(7) | 4 | 左右只有一个非空 | 4（把 q 往上送） |
| 6 | None | None | 不是 p/q | None |
| 5 | None(6) | 4 | 本节点是 p → 命中 | **5** |
| 0,8 | None | None | — | None |
| 1 | None(0) | None(8) | — | None |
| 3 | 5 | None(1) | 只有一个非空 | 5 |

根节点返回 5，答案就是 5。注意节点 2 那一步：它只看到一个非空返回值，就**原样往上送**，不急着下结论——这是整个算法的核心动作。

再看示例 1（p=5, q=1）：节点 5 返回 5，节点 1 返回 1，根 3 的左右都非空 → 返回 3。命中「分居两侧」这一条。

## 4. 正确性：为什么不会漏、不会重

用**不变量**说清楚。对任意节点 x，设 `dfs(x)` 的返回值为 r，则：

> **不变量**：r 非空 ⟺ x 的子树里至少含 p、q 之一；且若 x 的子树里 p、q 都在，则 r 恰为它们的 LCA。

**归纳证明**（对子树高度归纳）：

- **基例**（叶子）：子树只含自己。若自己是 p 或 q，返回自己，不变量成立；否则返回 None，成立。
- **归纳步**：设左右子树的返回值都满足不变量。
  - 若左右**都非空**：说明 p、q 分别落在两侧子树（因为 p≠q，不可能同一个节点被两边同时返回）。x 是它们共同祖先，而两侧子树里的任何节点都不可能是共同祖先（各自只含一个目标），所以 x 是最近的 → 返回 x，正确。
  - 若**只有一个非空**：p、q 要么都在那一侧（此时那一侧的返回值按归纳已是 LCA，原样上送正确），要么只有一个在树里（返回值就是那个目标节点，上送正确）。两种情况都满足不变量。
  - 若**都为空**：子树不含 p、q，返回 None，正确。

**不会漏**：题目保证 p、q 都在树里，根节点的返回值必然非空，且按不变量它就是 LCA。
**不会重**：每个节点只被访问一次，返回值只有一个，不存在「算出两个候选再挑」的问题。

## 5. 完整代码（Python）

```python
class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        def dfs(node):
            # 空子树：不含任何目标节点
            if node is None:
                return None
            # 当前节点就是 p 或 q：直接返回自己（自己可以是自己的祖先）
            if node is p or node is q:
                return node

            left = dfs(node.left)    # 左子树里找到的目标节点 / LCA
            right = dfs(node.right)  # 右子树里找到的目标节点 / LCA

            # 左右都非空：p、q 分居两侧，当前节点就是最近公共祖先
            if left and right:
                return node
            # 只有一侧非空：把那一侧的结果原样上送
            # （可能是单个目标节点，也可能是已经确定的 LCA）
            return left if left else right

        return dfs(root)
```

两个细节值得强调：

- 用 `is` 而不是 `==` 比较节点。题面说「所有 Node.val 互不相同」，用 `==` 在力扣上也能过，但 `is` 表达的是「同一个对象」，语义更准确，也不依赖值唯一这个额外条件。
- `return left if left else right` 这一行同时覆盖了「只有左边有」「只有右边有」「都没有（返回 None）」三种情况，不需要再写分支。

## 6. 复杂度

**时间 O(n)**：n 是节点数。`dfs` 对每个节点恰好调用一次（进入即返回，不会重复进入），每次调用内部只做常数次比较和赋值。没有嵌套遍历，所以是线性。

**空间 O(h)**：h 是树高，由递归调用栈贡献。最坏情况是链状树，h = n，空间 O(n)；最好情况是平衡树，h = log n，空间 O(log n)。注意这里**没有**额外的数组或哈希表，空间全部来自栈。

对比暴力解 O(n²) 时间：省掉的是「对每个候选节点重新扫描子树」这一层，靠的是把子树信息通过返回值**一次传上来**。

## 7. 边界与反例（至少 4 条）

1. **p 是 q 的祖先**：`root=[3,5,1,6,2,0,8], p=5, q=4` → 输出 `5`。容易错在：递归到 5 时直接返回 5，忘了「自己可以是自己的祖先」这条定义，误以为要继续往下找 4。
2. **p、q 是兄弟**：`root=[1,2,3], p=2, q=3` → 输出 `1`。容易错在：只写了「本节点是 p/q 就返回」的分支，漏掉「左右都非空返回本节点」的分支，导致返回 None 或返回其中一个孩子。
3. **只有两个节点且根是 p**：`root=[1,2], p=1, q=2` → 输出 `1`（示例 3）。容易错在：先递归左右再判断本节点，导致根 1 被当成「只含一个目标」上送，最后返回 2。
4. **链状树，p、q 在两端**：`root=[1,2,null,3,null,4]`（1-2-3-4 一条链），p=1, q=4 → 输出 `1`。容易错在：递归深度达到 n，Python 默认递归上限约 1000，n 到 10⁵ 时会 `RecursionError`。面试里要主动提这一点，并给出「迭代后序 + 父指针」或「先建 parent 字典再往上跳」的替代方案。
5. **p、q 都在同一侧子树深处**：`root=[1,2,3,4,5], p=4, q=5` → 输出 `2`。容易错在：根 1 看到左子树返回 2、右子树返回 None，若误判为「只有一个目标」而返回 2 是对的，但如果代码写成「左右都非空才返回本节点，否则返回 None」，就会丢掉答案。

## 8. 面试追问与变体（3 条）

1. **追问：如果 p、q 不一定在树里，怎么办？** 思路：递归返回值改成三元组 `(找到p, 找到q, lca)`，或者先做一次遍历确认存在性；也可以在返回时区分「找到 1 个」和「找到 2 个」两种非空状态。
2. **追问：不用递归怎么写？** 思路：迭代后序遍历（显式栈 + `last_visited` 指针），或者先 BFS 建 `parent` 字典，再从 p 往上走记录路径、从 q 往上走找第一个交点，时间 O(n)、空间 O(n)。
3. **追问：如果是 BST 呢（题号 235）？** 思路：利用有序性，从根往下走，p、q 都小于当前值就往左、都大于就往右，否则当前节点就是答案，时间 O(h)，不需要后序。

- **1123. 最深叶节点的最近公共祖先**：共同点是「自底向上返回子树信息」，只是返回值从「目标节点」变成「子树深度 + 该深度下的 LCA」。
- **865. 具有所有最深节点的最小子树**：和 1123 几乎同构，共同点是后序递归时把「深度」和「候选答案」打包成一个返回值往上送。
