## 1. 一句话本质

把链表按「相邻两个一组」切开，把每一组内部的两个节点对调，组与组之间的连接关系保持不变。

## 2. 读完题的第一反应

**朴素解法**：最容易想到的是「把链表转成数组，两两交换数组元素，再重建链表」。这能过，但它卡在两件事上：一是额外 O(n) 空间，二是面试官会追问「能不能原地做」。而且它绕开了这道题真正想考的东西——指针操作。

**关键观察**：题目说「只能进行节点交换」，这等于告诉你：每个节点的 `next` 指针是要被改写的对象。再盯着示例 `[1,2,3,4] → [2,1,4,3]` 看：节点 1 的 `next` 从 2 变成了 3，节点 2 的 `next` 变成了 1。也就是说，**每一组交换只影响三个指针**：组内两个节点的 `next`，以及「前一组最后一个节点」指向本组的那个指针。

这个观察直接推出下一步：既然每组的处理方式完全一样、且处理完一组后「下一组的起点」是确定的，那就可以用**一个指针指向「当前组的前驱」**，循环往前推。这就是迭代法。而「处理完第一组后，剩下的链表是同样的问题」这个结构，则直接给出递归法。

## 3. 从暴力到最优

**暴力（数组法）**：遍历链表存进 list，`for i in range(0, len(a)-1, 2): a[i], a[i+1] = a[i+1], a[i]`，再重建。时间 O(n)，空间 O(n)。瓶颈是空间，且没练到指针。

**迭代法**：引入哑节点 `dummy`，令 `prev = dummy`，`prev.next` 指向当前组的第一个节点。每轮做三件事：

以 `dummy → 1 → 2 → 3 → 4` 为例，初始 `prev = dummy`：

- `first = prev.next` → `first = 节点1`
- `second = first.next` → `second = 节点2`
- 交换：`first.next = second.next`（节点1 指向 3）；`second.next = first`（节点2 指向 1）；`prev.next = second`（dummy 指向 2）

此时链表变成 `dummy → 2 → 1 → 3 → 4`。然后 `prev = first`（即节点1，它是下一组的前驱），进入下一轮：`first = 节点3`，`second = 节点4`，同样三步后得到 `dummy → 2 → 1 → 4 → 3`。下一轮 `first = None`，循环结束，返回 `dummy.next`。

**瓶颈怎么被消掉的**：数组法的 O(n) 空间来自「把节点搬进另一个容器」；迭代法不搬节点，只改三个指针，空间降到 O(1)。时间仍是 O(n)，因为每个节点恰好被访问常数次——这是下限，不可能更快，因为输出本身就要 n 个节点。

**递归法**（另一种最优解）：`swapPairs(head)` 的定义就是「返回交换后的新头」。若 `head` 或 `head.next` 为空，直接返回 `head`。否则设 `second = head.next`，先递归处理 `second.next` 之后的链表得到 `rest`，再令 `head.next = rest`、`second.next = head`，返回 `second`。以 `[1,2,3,4]` 走一遍：`second=2`，递归 `[3,4]` 返回 `4→3`，于是 `1.next = 4→3`，`2.next = 1`，返回 `2`，最终 `2→1→4→3`。递归的空间是 O(n) 的调用栈，所以面试里通常优先写迭代。

## 4. 正确性：为什么不会漏、不会重

用**循环不变量**来论证迭代法。定义不变量：

> 每轮循环开始时，`dummy.next` 到 `prev` 这一段已经全部交换完毕且连接正确；`prev` 是这段的最后一个节点；`prev.next` 是尚未处理的第一个节点。

**初始化**：`prev = dummy`，已处理段为空，`dummy.next` 是原链表头，不变量成立。

**保持**：设 `first = prev.next`、`second = first.next`。若 `second` 存在，三步指针改写后，`first` 与 `second` 位置互换，且 `prev.next = second` 把新组接回已处理段，`first.next = second.next` 把未处理段接回新组尾部。此时 `prev = first` 成为新的段尾，不变量恢复。若 `second` 不存在（剩余 0 或 1 个节点），循环终止，此时已处理段覆盖全部节点。

**终止**：链表长度有限，每轮 `prev` 前进两个节点，必然终止。终止时不变量告诉我们整条链表已正确交换，故 `dummy.next` 是答案。

「不会漏」由不变量中「`prev.next` 是未处理第一个节点」保证；「不会重」由「每轮 `prev` 恰好前进两个节点、且只改写三个指针」保证——没有节点被第二次当作 `first` 处理。

## 5. 完整代码（Python）

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution:
    def swapPairs(self, head: ListNode) -> ListNode:
        # 哑节点：让「第一组的前驱」和「中间组的前驱」用同一套代码处理
        dummy = ListNode(0, head)
        prev = dummy  # prev 始终是「已交换部分的最后一个节点」

        while prev.next and prev.next.next:
            # 剩余至少两个节点，才有一组可交换
            first = prev.next
            second = first.next

            # 三步指针改写，顺序不能乱：
            # 先让 first 跨过 second 接上后面，再让 second 指回 first，
            # 最后把 prev 接到 second 上（此时 second 已是本组新头）
            first.next = second.next
            second.next = first
            prev.next = second

            # 本组交换完毕，first 变成下一组的前驱
            prev = first

        return dummy.next
```

递归版本（对照理解，空间 O(n)）：

```python
class Solution:
    def swapPairs(self, head: ListNode) -> ListNode:
        if not head or not head.next:
            return head
        second = head.next
        head.next = self.swapPairs(second.next)  # 先处理后面的，拿到新头
        second.next = head
        return second
```

## 6. 复杂度

**时间 O(n)**：`while` 每轮处理两个节点，共约 n/2 轮；每轮内部是常数次指针赋值和比较。n 来自链表节点总数，没有 log 项，因为不存在折半结构。

**空间 O(1)**（迭代版）：只用了 `dummy`、`prev`、`first`、`second` 四个指针变量，与 n 无关。递归版空间 O(n)，n 来自递归调用栈深度（每层消耗两个节点，深度约 n/2，仍记作 O(n)）。

## 7. 边界与反例（至少 4 条）

1. `head = []` → 输出 `[]` → 容易错在没判空就访问 `head.next`，直接 `AttributeError`。迭代法靠 `prev.next` 为 `None` 自然跳过。
2. `head = [1]` → 输出 `[1]` → 容易错在 `while prev.next and prev.next.next` 只写了前半句，导致 `second = first.next` 拿到 `None` 后继续改写指针，把单节点链表的 `next` 弄乱。
3. `head = [1,2]` → 输出 `[2,1]` → 容易错在返回 `head` 而不是 `dummy.next`，返回的是交换后的尾节点 1。
4. `head = [1,2,3]` → 输出 `[2,1,3]` → 容易错在以为奇数长度要特殊处理；实际上最后一组只剩一个节点时循环条件自动退出，节点 3 原样保留，无需额外代码。
5. `head = [1,2,3,4,5]` → 输出 `[2,1,4,3,5]` → 容易错在 `prev = first` 写成了 `prev = second`，导致下一组的前驱指错，链表断裂或成环。

## 8. 面试追问与变体（3 条）

1. **追问：改成「每 k 个一组翻转」，k 是参数。** 思路：先数出是否有 k 个节点，够则用「头插法」翻转这 k 个，再把前驱接到新头、新尾接到递归结果；不够则原样返回。本题是 k=2 的特例。
2. **追问：不允许用哑节点，怎么写？** 思路：单独处理第一组，把新头存下来，之后用「上一组尾节点」当 `prev` 继续循环，逻辑与哑节点版一致，只是初始化多几行。
3. **追问：如果链表带随机指针（类似复制带随机指针的链表），两两交换后随机指针怎么维护？** 思路：交换只改 `next`，随机指针指向的节点对象没变，所以不用动；但若要求「随机指针也按位置交换」，则需先建立旧节点到新位置的映射再统一改写。
