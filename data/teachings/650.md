## 1. 一句话本质

把整数 n 拆成若干个（≥2 的）因子之积，使得「所有因子之和」最小——这个最小和就是答案。

为什么？因为一次 Copy All + 若干次 Paste 的完整循环，等价于把当前长度乘以某个因子 k，代价是 1 + (k-1) = k 次操作。于是整条路径就是 n = k₁·k₂·…·kₘ，总代价 = k₁+k₂+…+kₘ。题目要的就是这个和的最小值。

## 2. 读完题的第一反应

**朴素解法**：把状态定义成 `(当前字符数, 剪贴板字符数)`，做 BFS 或 DP。状态空间是 O(n²)，每个状态两条转移，复杂度 O(n²)。n ≤ 1000 时其实能过，但这不是这题想考的东西，而且一旦 n 放大到 10⁶ 就废了。瓶颈在于：我们被迫同时跟踪「剪贴板里有多少」，而这个信息其实是可以被消掉的。

**关键观察**：剪贴板的内容只在你执行 Copy All 的那一刻被确定，之后它就是个常数，直到下一次 Copy All。所以一次 Copy All 到下一次 Copy All 之间，发生的事情就是「把当前长度乘以某个整数 k」——k-1 次 Paste 加上那次 Copy，一共 k 步。于是问题从「二维状态搜索」塌缩成「一维的整数分解」。

这个观察之所以能让你想到下一步，是因为它把「操作序列」这种时序结构，换成了「因子分解」这种纯数论结构。一旦变成数论，最优解的形状就非常清楚了：**因子越小越好，而最小的因子就是质因子**。把 n 分解成质因数，答案就是质因数之和（带重数）。

## 3. 从暴力到最优

**第一步：二维 DP（能过，但笨）**

`dp[i][j]` = 当前有 i 个 A、剪贴板有 j 个 A 时的最少操作数。转移：Copy All → `dp[i][i] = dp[i][j]+1`；Paste → `dp[i+j][j] = dp[i][j]+1`。状态 O(n²)，答案取 `min_j dp[n][j]`。

**第二步：消掉剪贴板维度**

上面说了，一段「Copy + 若干 Paste」= 乘以 k，代价 k。所以定义 `f[i]` = 得到 i 个 A 的最少操作数，转移是：

```
f[i] = min over k | i, k >= 2 of ( f[i/k] + k )
```

也就是「最后一次操作循环把长度从 i/k 乘到了 i」。这是 O(n√n) 的（枚举 i 的因子）。

**第三步：看出质因数**

在 `f[i] = min(f[i/k] + k)` 里，如果 k 是合数，比如 k = a·b（a,b ≥ 2），那么 `f[i/k] + a·b` 一定不优于 `f[i/(k/a)] + a + b`，因为 a·b ≥ a+b 对 a,b ≥ 2 恒成立（等号仅在 a=b=2 时取到，此时 4 = 2+2，不劣）。所以最优的 k 一定取质数。于是答案 = n 的质因数之和（带重数）。

**小例子走一遍：n = 12**

- 二维视角：12 = 2×6，代价 2+6 = 8；12 = 3×4，代价 3+4 = 7；12 = 2×2×3，代价 2+2+3 = 7。最优 7。
- 质因数分解：12 = 2²×3，和 = 2+2+3 = 7。✓
- 验证操作序列：Copy(1) → Paste → Paste（得 3 个，花 3 步）→ Copy → Paste → Paste → Paste（得 12 个，花 4 步），共 7 步。✓

再看 n = 9：9 = 3×3，和 6；对比 9 = 9（一次乘 9，代价 9）。6 < 9，所以答案是 6。操作：Copy → Paste → Paste（3 个，3 步）→ Copy → Paste → Paste（9 个，3 步），共 6 步。

## 4. 正确性：为什么不会漏、不会重

**不变量**：任意一个合法操作序列，都可以唯一地切分成若干段，每段以一次 Copy All 开头、以「下一次 Copy All 之前」结束。第 t 段把长度从 L 变成 L·kₜ，其中 kₜ = 1 + (该段 Paste 次数) ≥ 2，代价恰好是 kₜ（1 次 Copy + kₜ-1 次 Paste）。因此总长度 n = ∏kₜ，总代价 = ∑kₜ。这个映射是双射：给定因子分解就能构造操作序列，给定操作序列就能读出因子分解。所以「最小化操作数」和「最小化因子和」是同一个优化问题，不会漏解。

**为什么质因子最优（交换论证）**：设某个最优分解里有一个合数因子 k = a·b，a,b ≥ 2。把它替换成 a, b 两个因子，乘积不变，而和从 a·b 变成 a+b。因为 (a-1)(b-1) ≥ 1，展开得 ab ≥ a+b，等号只在 a=b=2 时成立。所以替换后和不增，仍是合法分解且不劣。反复替换直到所有因子都是质数，得到一个「质因数分解」，其和不大于原最优值。又因为质因数分解本身是合法分解，所以它就是最优解。这就证明了：**答案 = n 的质因数之和（带重数）**。

**不会重**：质因数分解在不计顺序时唯一（算术基本定理），所以「质因数之和」是一个确定的数，不存在多个候选需要比较。

## 5. 完整代码（Python）

```python
class Solution:
    def minSteps(self, n: int) -> int:
        # 答案 = n 的所有质因数之和（带重数）
        # 例如 12 = 2*2*3 -> 2+2+3 = 7
        ans = 0
        d = 2
        # 只需试到 sqrt(n)：若 n 还有大于 sqrt 的因子，它必然是质数且只剩一个
        while d * d <= n:
            while n % d == 0:      # d 能整除就反复除，保证 d 是质数
                ans += d           # 每除一次，贡献一个因子 d 的代价
                n //= d
            d += 1
        if n > 1:
            # 剩下的 n 是最后一个质因子（可能等于 1，表示已除尽）
            ans += n
        return ans
```

关键逻辑说明：

- 外层 `while d*d <= n` 是标准的试除法上界。当 d 超过 √n 时，若 n > 1，它不可能再有小于自身的因子，所以剩下的 n 本身是质数。
- 内层 `while n % d == 0` 反复除，是因为同一个质因子可能出现多次（重数），每次都要计入和。
- `d += 1` 从 2 开始逐个试，虽然会试到合数，但合数早被更小的质因子除干净了，所以真正生效的只有质数——这就是「不需要额外判质数」的原因。
- n = 1 时循环不进入，`n > 1` 为假，返回 0，符合示例 2。

## 6. 复杂度

**时间**：O(√n)。试除的 d 从 2 走到 √n，最多 √n 次迭代；内层 while 的总执行次数等于质因子的总重数，最多 log₂n 次（因为每除一次 n 至少减半）。所以总时间是 O(√n + log n) = O(√n)。这里的 √n 来自「枚举可能的因子」，log n 来自「因子重数」——两者量级不同，主导项是 √n。

**空间**：O(1)。只用了 `ans`、`d`、`n` 三个变量，没有数组、没有递归栈。

对比一下：二维 DP 是 O(n²) 时间、O(n²) 空间；一维因子 DP 是 O(n√n) 时间、O(n) 空间；质因数解法是 O(√n) 时间、O(1) 空间。这就是「消掉剪贴板维度」带来的全部收益。

## 7. 边界与反例（至少 4 条）

1. **n = 1** → 期望 0。容易错在：直接返回 1 或进入循环后返回某个正数。题面明确说初始就有 1 个 A，不需要任何操作。代码里靠 `n > 1` 判断兜住。
2. **n = 2** → 期望 2（Copy + Paste）。容易错在：以为 2 是质数就直接返回 2 是对的，但若写成「返回 n」在 n=2 时碰巧对，在 n=4 时就错成 4（正确是 4=2+2=4，碰巧也对），真正暴露问题的是 n=6：返回 6 错，正确是 2+3=5。所以不能偷懒返回 n。
3. **n = 4** → 期望 4。两条路径：4 = 2×2 代价 4；4 = 4 代价 4。相等。容易错在：认为「因子越少越好」而选 4，虽然答案对，但推理错，遇到 8 就翻车（8 = 2+2+2 = 6 < 8）。
4. **n 是质数且较大，如 n = 997** → 期望 997。容易错在：试除法里忘记处理「剩下的大质数」，直接返回 ans = 0。必须补 `if n > 1: ans += n`。
5. **n = 1000** → 1000 = 2³×5³，和 = 2+2+2+5+5+5 = 21。容易错在：只除一次 2 就 `d += 1`，漏掉重数，得到 2+5 = 7 这种荒谬结果。

## 8. 面试追问与变体（3 条）

1. **追问：如果允许「复制部分字符」呢？** 思路：那问题退化成「每次可以复制任意 ≤ 当前长度的量」，最优策略变成每次翻倍，答案是 ⌈log₂n⌉ 量级，用贪心或 BFS 重做，质因数结论失效。
2. **追问：如果 Paste 有冷却，或者 Copy 有代价 c 呢？** 思路：回到一维 DP `f[i] = min(f[i/k] + c + k - 1)`，枚举因子，O(n√n)；质因数结论在 c ≠ 1 时不再成立，需要重新做交换论证。
3. **追问：要输出具体操作序列而不只是次数呢？** 思路：先做质因数分解，然后按因子从大到小（或从小到大）依次生成「Copy + (k-1) 次 Paste」的指令，因为分解顺序不影响总和，任选一种即可。
