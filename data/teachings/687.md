## 1. 一句话本质

对每个节点，求「以它为最高点、左右两侧各挂一条同值链」时能拼出的最长同值路径，再对所有节点取最大值。

## 2. 读完题的第一反应

**朴素解法**：枚举每一对节点 (u, v)，判断 u 到 v 的路径上所有节点值是否相同，相同则用边数更新答案。判断一条路径是否同值要 O(路径长度)，枚举点对是 O(n²)，总复杂度 O(n³) 级别。n 到 10⁴ 时直接爆掉。瓶颈在于「枚举点对」这个动作本身——路径数量是 O(n²) 的，逐条检查必然慢。

**关键观察**：一条同值路径在树上一定有一个「最高点」（离根最近的那个节点），路径从这个最高点向左右两个子树各延伸出一条链。也就是说，任何一条合法路径都能唯一地拆成「左链 + 最高点 + 右链」。于是问题从「枚举所有路径」变成「枚举所有节点作为最高点」——只有 n 种情况，每种情况只需要知道「从该节点往左能延伸多长的同值链」和「往右能延伸多长」。这两个量恰好是子树递归能返回的东西，DFS 的形态就出来了。

这个观察之所以关键，是因为它把「路径」这个二维对象（两个端点）降维成了「节点 + 两条向下链」这个一维对象（一个最高点），而向下链的信息天然适合自底向上合并。

## 3. 从暴力到最优

**第一步：定义递归返回值。** 对节点 u，定义 `dfs(u)` = 从 u 出发、**向下**走、且沿途节点值都等于 `u.val` 的最长链的**边数**。注意这个链只能走一个方向（要么全在左子树，要么全在右子树），因为它是「半条路径」，要给父节点继续接。

**第二步：怎么算 `dfs(u)`。** 分别递归拿到 `L = dfs(u.left)`、`R = dfs(u.right)`。但 L 只有在 `u.left.val == u.val` 时才可用，否则左子树根本接不上，记 `left_len = L + 1 if 左孩子存在且值相等 else 0`；右边同理得 `right_len`。于是 `dfs(u) = max(left_len, right_len)`——因为向上只能选一条链。

**第三步：顺手更新全局答案。** 在 u 这个最高点上，左右两条链可以**同时**用（路径允许拐弯），所以经过 u 的最长同值路径是 `left_len + right_len`，用它更新全局最大值。

**小例子走一遍**：`root = [5,4,5,1,1,5]`，树形为

```
        5
       / \
      4   5
     / \   \
    1   1   5
```

自底向上：

- 节点 1（左，4 的左孩子）：叶子，`dfs=0`，`ans=max(0, 0+0)=0`。
- 节点 1（右，4 的右孩子）：同上，`dfs=0`。
- 节点 4：左孩子值 1 ≠ 4 → `left_len=0`；右孩子值 1 ≠ 4 → `right_len=0`。`dfs(4)=0`，`ans` 仍为 0。
- 节点 5（右，5 的右孩子）：叶子，`dfs=0`。
- 节点 5（根的右孩子）：它的右孩子值 5 == 5 → `right_len = 0+1 = 1`；无左孩子 → `left_len=0`。`dfs=1`，经过它的路径长 `0+1=1`，`ans=1`。
- 根 5：左孩子值 4 ≠ 5 → `left_len=0`；右孩子值 5 == 5 → `right_len = dfs(右)+1 = 1+1 = 2`。经过根的路径长 `0+2=2`，`ans=2`。`dfs(根)=2`。

输出 2，与示例一致。注意中间变量 `right_len` 在根处变成了 2，这正是「根的右孩子那条链」贡献的。

**瓶颈怎么被消掉的**：原来枚举 O(n²) 条路径，现在每个节点只做常数次比较和加法，一次后序遍历 O(n) 全部搞定。信息复用体现在 `dfs` 的返回值——子树的链长被父节点直接拿去用，不重复计算。

## 4. 正确性：为什么不会漏、不会重

**不变量**：在 `dfs(u)` 返回之前，全局变量 `ans` 已经等于「所有以 u 的子树中某节点为最高点的同值路径长度的最大值」。

**归纳证明**：

- **基例**：叶子节点，子树内没有边，任何路径长度为 0，`ans` 初值 0 满足不变量。
- **归纳步**：设 u 的左右子树都满足不变量。任取一条最高点为 u 的同值路径，它由左链、u、右链组成。左链若存在，其第一个节点必是 u 的左孩子且值等于 `u.val`（否则链在 u 处就断了，u 不可能是最高点），而这条左链的最大长度正是 `left_len`；右链同理是 `right_len`。所以这条路径长度恰为 `left_len + right_len`，被 `ans = max(ans, left_len + right_len)` 覆盖。而最高点不是 u 的路径，全在某个子树内，已由归纳假设被旧 `ans` 覆盖。故更新后不变量对 u 成立。

**不漏**：每条合法路径都有唯一最高点，归纳覆盖了所有最高点情形。
**不重**：`ans` 取 max，重复计算不影响结果；且 `left_len`、`right_len` 各自只统计「值等于 u.val 的连续链」，不会把不同值的节点错误拼进来——这是靠 `u.left.val == u.val` 这个判断保证的，缺了它就会把断链接上，答案偏大。

## 5. 完整代码（Python）

```python
class Solution:
    def longestUnivaluePath(self, root) -> int:
        self.ans = 0  # 全局最优：任意最高点拼出的最长同值路径（边数）

        def dfs(node) -> int:
            """返回：从 node 向下、且节点值都等于 node.val 的最长链的边数。"""
            if node is None:
                return 0

            # 先递归拿到左右子树各自的「同值向下链」长度
            left_chain = dfs(node.left)
            right_chain = dfs(node.right)

            # 只有当孩子存在且值与当前节点相同，这条链才能接到当前节点上
            left_len = left_chain + 1 if node.left and node.left.val == node.val else 0
            right_len = right_chain + 1 if node.right and node.right.val == node.val else 0

            # 以当前节点为最高点，左右两条链可以同时使用，拼成一条完整路径
            self.ans = max(self.ans, left_len + right_len)

            # 但返回给父节点时只能选一条链（路径不能分叉）
            return max(left_len, right_len)

        dfs(root)
        return self.ans
```

关键点：`left_len`/`right_len` 的「+1」是加当前节点到孩子的那条边；`self.ans` 用 `left_len + right_len`（两条边都算），返回值用 `max`（只算一条）。这两处的区别是本题最容易写错的地方。

## 6. 复杂度

- **时间 O(n)**：n 是节点数。`dfs` 对每个节点恰好调用一次（二叉树后序遍历，每个节点被其父节点访问一次），每次调用内部是常数次比较、加法和 max，所以总操作数与 n 成正比。没有重复访问，没有嵌套循环。
- **空间 O(h)**：h 是树高，来自递归调用栈的深度。最坏情况（链状树）h = n，空间 O(n)；最好情况（平衡树）h = log n，空间 O(log n)。题面给「深度不超过 1000」，所以栈深可控。这里没有额外开辟数组或哈希表，辅助空间就是栈。

## 7. 边界与反例（至少 4 条）

1. **空树 `root = []`** → 期望 0 → 容易错在没判空直接访问 `root.val` 崩掉。代码里 `dfs(None)` 返回 0，`ans` 保持 0，安全。
2. **单节点 `[1]`** → 期望 0 → 容易错在把「节点数」当答案返回 1。路径长度是**边数**，单节点没有边，必须是 0。
3. **全同值链 `[1,1,1,1]`（一条左斜链）** → 期望 3 → 容易错在只算 `max(left_len, right_len)` 而忘了在每层更新 `ans`，或者把返回值直接当答案。必须每层都用 `left_len + right_len` 更新全局。
4. **根值不同但子树内同值 `[1,2,2]`** → 期望 1 → 容易错在认为「必须经过根」。根 1 与孩子 2 不同，`left_len=right_len=0`，但左子树内部 2-2 那条边由子树的 `ans` 更新，最终为 1。这验证了「不经过根」的情形。
5. **左右值不同、只有一侧能接 `[1,1,2]`** → 期望 1 → 容易错在把 `left_len + right_len` 当成返回值传给父节点（返回 2 就错了），返回值必须是单侧 max。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求路径上节点值「单调不减」而不是全相等，怎么改？**
   思路：`dfs` 返回值改为「从当前节点向下、值单调不减的最长链」，接孩子的条件从 `==` 改成 `<=`，其余框架不变。
2. **追问：改成求「最长同值路径的节点个数」而非边数？**
   思路：边数 + 1 即可，但注意空树要特判返回 0；或者在 `ans` 更新处用 `left_len + right_len + 1`，最后统一处理。
3. **追问：如果树是 N 叉树呢？**
   思路：`dfs` 返回单侧最长链，但在当前节点处要取「所有可接孩子中链长最大的两条」相加更新 `ans`，返回值取这些链长的最大值。

## 9. 举一反三（2-3 道同类题）

- **124. 二叉树中的最大路径和**：同样是「最高点 + 左右两条向下链」，只是链的贡献从「长度」换成「节点值之和」，且允许负数时返回值要 clamp 到 0。
- **543. 二叉树的直径**：完全同构的框架，`dfs` 返回单侧深度，在每层用「左深 + 右深」更新答案，区别只是不检查值相等。
- **110. 平衡二叉树**：也是后序返回子树高度，在返回途中用左右高度差做判断，体现「递归返回值 + 途中更新全局状态」这一通用模式。
