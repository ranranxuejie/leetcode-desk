## 1. 一句话本质

统计每个字符的出现次数，然后按次数从大到小把字符「重复展开」拼成一个新字符串——本质是**按频次给字符分组排序**，而不是给原串的每个位置排序。

## 2. 读完题的第一反应

**朴素解法**：把字符串转成列表，写一个自定义比较函数，比较两个字符时现算它们的频次，然后 `sort`。问题在于：每次比较都要重新数频次，一次 `count` 是 O(n)，排序有 O(k log k) 次比较（k 为不同字符数），总复杂度 O(n · k log k)，在 n = 5×10⁵ 时直接超时。瓶颈很清楚：**频次被反复计算，而不是算一次存起来**。

**关键观察**：一个字符的频次在整个过程中是固定的，与它被排到哪个位置无关。所以应该先做一次 O(n) 的频次统计，把「频次」变成每个字符的静态属性，之后排序只读这个属性。这一步把「动态计算」降级成「查表」，是整道题的转折点。

第二个观察来自题面示例 2 的注释：「相同的字母必须放在一起」。这句话其实在提示你——**输出是按字符分块的**，每块内部全是同一个字符，块与块之间按频次降序。这意味着我们不需要对 n 个位置排序，只需要对 k 个不同字符排序，再按频次展开。k ≤ 62（大小写字母 + 数字），这个规模小到几乎可以忽略。

## 3. 从暴力到最优

**第一步：暴力比较排序。** 瓶颈是 O(n · k log k)，消掉它的办法就是上面说的预统计，得到 O(n + k log k)。

**第二步：能不能把 k log k 也消掉？** 可以，用桶排序。频次的取值范围是 [1, n]，而 k ≤ 62，所以桶的个数最多 n+1 个。把「频次为 f 的字符列表」放进第 f 个桶，然后从 f = n 倒着扫到 1，遇到非空桶就把里面的字符按频次展开。这一步是 O(n + k)，因为扫桶是 O(n)、展开是 O(n)、装桶是 O(k)。

**用 s = "tree" 走一遍桶排序：**

1. 统计频次：`{'t': 1, 'r': 1, 'e': 2}`。
2. 建桶（长度 n+1 = 5）：`buckets[1] = ['t', 'r']`，`buckets[2] = ['e']`，其余为空。
3. 从 f = 4 倒扫到 1：
   - f=4、f=3 空，跳过；
   - f=2：桶里是 `['e']`，展开成 `'e' * 2 = "ee"`，结果 `"ee"`；
   - f=1：桶里是 `['t', 'r']`，依次展开成 `"t"`、`"r"`，结果 `"eetr"`。
4. 返回 `"eetr"`，与示例输出 `"eert"` 同为合法答案（题面明确说多个答案任选其一）。

注意第 3 步里 `['t', 'r']` 的顺序取决于字典插入顺序，换一种语言或换一个输入顺序，得到 `"eert"` 也完全正确——这正是题面「返回其中任何一个」的含义。

**为什么桶排序在这里成立？** 因为频次是**有界整数**（1 到 n），而有界整数排序不需要比较。如果频次是任意实数，桶排序就不适用了，得退回比较排序。这是选择算法的依据，不是背下来的套路。

## 4. 正确性：为什么不会漏、不会重

用**不变量**来论证。设最终结果串为 `res`，我们证明两个性质：

**不漏**：每个在原串中出现过的字符 c，其频次 f(c) ≥ 1，所以 c 一定被放进 `buckets[f(c)]`。倒扫时 f 从 n 递减到 1，必然经过 f(c)，此时 c 被展开进 `res`。所以每个字符都出现了。

**不重**：每个字符 c 只被放进一个桶（频次唯一），倒扫时每个桶只被访问一次，桶内每个字符只被展开一次。所以 `res` 中字符 c 恰好出现 f(c) 次，与它在原串中的次数一致。

**有序**：倒扫保证了频次大的桶先被处理。若 f(a) > f(b)，则 a 所在桶的下标更大，先被扫到，a 的所有副本都排在 b 之前。所以 `res` 中频次单调不增，满足「降序」要求。

**分块**：同一字符的所有副本在同一次展开中连续写入 `res`，中间不插入其他字符，所以相同字母必然相邻，满足示例 2 注释的要求。

三条合起来：`res` 是原串的一个排列（不漏不重）、频次降序（有序）、同字符连续（分块），正是题目要求的输出。

## 5. 完整代码（Python）

```python
from collections import Counter

class Solution:
    def frequencySort(self, s: str) -> str:
        # 第一步：一次遍历统计频次，O(n)
        freq = Counter(s)

        # 第二步：建桶。桶下标 = 频次，值 = 该频次下的字符列表
        # 频次最大不超过 len(s)，所以桶数组长度取 n+1
        n = len(s)
        buckets = [[] for _ in range(n + 1)]
        for ch, f in freq.items():
            buckets[f].append(ch)

        # 第三步：从高频到低频倒扫，按频次展开字符
        res = []
        for f in range(n, 0, -1):
            for ch in buckets[f]:
                res.append(ch * f)   # 同一字符连续写 f 次，保证分块

        return "".join(res)
```

关键逻辑说明：`Counter(s)` 把「动态数频次」变成「一次查表」；`buckets[f].append(ch)` 把排序问题转成「按下标归位」，省掉比较；`ch * f` 一次性写入整块，既保证分块又避免逐字符 append 的开销。

## 6. 复杂度

**时间 O(n + k)**，其中 n = len(s)，k = 不同字符数（≤ 62）：

- `Counter(s)` 遍历 n 个字符，贡献 O(n)；
- 遍历 `freq.items()` 是 O(k)，装桶 O(k)；
- 倒扫 `range(n, 0, -1)` 是 O(n)，这是 n 的来源；内层展开总共写入 n 个字符，也是 O(n)；
- 没有 log n：因为桶排序不做比较，k log k 那一项被消掉了。

**空间 O(n + k)**：

- `Counter` 存 k 个键值对，O(k)；
- `buckets` 是 n+1 个列表，O(n)；
- `res` 最终长度 n，O(n)。

如果面试官追问「能不能 O(k) 空间」，可以改用「按频次排序字符列表」的写法（`sorted(freq, key=freq.get, reverse=True)`），时间 O(n + k log k)、空间 O(k)，用一点时间换空间。

## 7. 边界与反例（至少 4 条）

1. **输入 `"a"` → 期望 `"a"`**。容易错在桶数组长度写成 `len(s)` 而非 `len(s)+1`，导致 `buckets[1]` 越界；或者倒扫写成 `range(n-1, 0, -1)` 漏掉频次为 1 的字符。
2. **输入 `"cccaaa"` → 期望 `"cccaaa"` 或 `"aaaccc"`**。容易错在把同频字符交错输出成 `"cacaca"`——这违反了「相同字母必须放在一起」，说明展开时必须整块写入，不能逐字符轮流取。
3. **输入 `"Aabb"` → 期望 `"bbAa"` 或 `"bbaA"`**。容易错在用 `s.lower()` 或 `Counter(s.lower())` 合并大小写，把 `'A'` 和 `'a'` 当成同一个字符，导致频次算错、输出缺字符。题面明确说二者是不同字符。
4. **输入 `"2a2"` → 期望 `"22a"`**。容易错在只处理字母、忽略数字，或者用 `isalpha()` 过滤时把数字丢掉。题面说 s 由字母和数字组成，数字也是合法字符。
5. **输入长度 5×10⁵ 的全同字符串 `"aaaa..."` → 期望原样返回**。容易错在暴力比较排序里每次比较都 `count`，直接 TLE；也容易错在 `res` 用字符串 `+=` 拼接，Python 中退化成 O(n²)。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求同频字符按字典序输出，怎么改？** 思路：装桶后对每个桶 `sort()`，或在展开前对桶内列表排序，时间增加 O(k log k)，k ≤ 62 可忽略。
2. **追问：如果频次是浮点数（比如按权重排序），桶排序还能用吗？** 思路：不能，桶下标必须是整数；退回 `sorted(freq, key=..., reverse=True)` 的比较排序，时间 O(n + k log k)。
3. **追问：内存受限，不允许 O(n) 的桶数组，怎么办？** 思路：用「频次 → 字符列表」的字典代替数组，只存出现过的频次，空间降到 O(k)，再按频次键降序迭代。

## 9. 举一反三（2-3 道同类题）

1. **347. 前 K 个高频元素**：同样先统计频次，再用桶或堆取前 k 个，共同点是「频次是有界整数，可用桶代替比较排序」。
2. **692. 前 K 个高频单词**：频次统计 + 排序，区别在于同频时要按字典序，正好对应上面追问 1 的处理方式。
3. **1636. 按照频率将数组升序排序**：同一套「统计频次 → 按频次排序 → 展开」的骨架，只是排序方向相反、同频时按数值降序，可作为本题的镜像练习。
