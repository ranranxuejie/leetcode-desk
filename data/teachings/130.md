## 1. 一句话本质

在矩阵里找出所有「四连通、且不碰边界」的 `'O'` 区域，把它们翻成 `'X'`；等价于**从边界出发能走到的 `'O'` 全部保留，其余 `'O'` 全部清除**。

## 2. 读完题的第一反应

朴素解法：对每个 `'O'` 做一次 DFS/BFS，看这个连通块里有没有任何一个格子落在第 0 行、第 m-1 行、第 0 列、第 n-1 列。如果整块都不碰边界，就把整块改成 `'X'`。

它卡在哪：每个 `'O'` 都可能被反复遍历。最坏情况整张图全是 `'O'`，你从每个格子出发都扫一遍连通块，复杂度 O((mn)²)，m=n=200 时是 1.6×10⁹ 量级，超时。瓶颈在于「同一个连通块被重复判定」。

关键观察：**「被围绕」这个性质是连通块级别的，不是格子级别的**——一个 `'O'` 被不被捕获，只取决于它所在的连通块碰不碰边界。而「碰边界」这件事，反过来看更好用：**从边界上的 `'O'` 出发，能走到的所有 `'O'` 一定不被捕获**。于是问题从「判断每个块是否碰边」翻转成「从边界灌水，标记所有安全格」，每个格子只访问一次。

这个翻转为什么自然：题目给的是「边缘」这个特殊位置，而边缘是**已知的、少量的入口**（最多 2m+2n 个格子），从入口出发做一次遍历，天然避免重复。

## 3. 从暴力到最优

**第一步（暴力）**：对每个未访问的 `'O'` 启动 DFS，收集整个连通块到列表 `comp`，同时记录 `touch_edge` 布尔值。遍历完若 `touch_edge == False`，把 `comp` 里所有坐标改成 `'X'`。

小例子，board 为：

```
X X X X
X O O X
X X O X
X O X X
```

从 (1,1) 出发，连通块是 {(1,1),(1,2),(2,2)}，都不在边缘 → 全改 `'X'`。再从 (3,1) 出发，连通块 {(3,1)}，它在最后一行 → 保留。结果正确。但注意：如果图是 200×200 全 `'O'`，第一块就扫了 40000 格，之后每个格子虽然被标记过不再扫，可如果实现里忘了 visited 数组，就会退化成 O((mn)²)。即便有 visited，暴力也要额外存 `comp` 列表，空间多一份。

**第二步（翻转视角）**：不再问「这块碰不碰边」，而是「从边往里灌」。把所有边界上的 `'O'` 作为多源起点，DFS/BFS 把能到达的 `'O'` 标记成临时字符 `'#'`（表示「安全」）。灌完之后，全图扫一遍：`'O'` → `'X'`（被捕获），`'#'` → `'O'`（还原）。

同一个例子走一遍：

- 边界上的 `'O'`：只有 (3,1)。从它出发，四邻都是 `'X'` 或越界，标记 (3,1)='#'。
- 全图扫描：`'#'` 还原成 `'O'`，其余 `'O'` 变 `'X'`。
- 结果：

```
X X X X
X X X X
X X X X
X O X X
```

和示例 1 输出一致。中间变量只有 board 本身，没有额外列表，每个格子最多被访问常数次。

**第三步（为什么这就是最优形态）**：任何正确算法都必须至少读一遍所有格子（否则无法知道哪些 `'O'` 存在），所以时间下界 Ω(mn)。上面的做法正好 O(mn)，达到下界。空间上，DFS 递归栈最坏 O(mn)（一条蛇形路径），BFS 队列同理；若想压到 O(1) 额外空间，可以用「原地标记 + 迭代」或并查集，但并查集反而多 O(mn) 的 parent 数组，不划算。所以标准答案就是「边界多源 DFS/BFS + 原地标记」。

## 4. 正确性：为什么不会漏、不会重

用**不变量**说清楚。定义：遍历结束后，格子 (i,j) 的值是 `'#'` 当且仅当存在一条从 (i,j) 到某个边界 `'O'` 的四连通路径，且路径上全是 `'O'`。

- **不漏（安全格一定被标记）**：若 (i,j) 所在连通块碰边界，则存在边界格 b 与 (i,j) 连通。DFS 从 b 出发，沿连通路径必然能走到 (i,j)，所以 (i,j) 被标 `'#'`。因此所有「不该被捕获」的格子都被保护。
- **不重（标记格一定安全）**：DFS 只从边界 `'O'` 出发、只走 `'O'`，所以任何被标 `'#'` 的格子都与边界 `'O'` 连通，确实不该被捕获。不会误伤。
- **捕获正确**：扫描阶段把剩余 `'O'` 全变 `'X'`。由上面两条，剩余 `'O'` 恰好是「不与边界连通」的格子，正是题目要捕获的集合。`'#'` 还原成 `'O'`，保持安全格原值。

「不重」还体现在访问次数：每个格子进入 DFS 时立刻被改成 `'#'`，之后不会再被任何起点重新进入（因为判断条件是 `board[i][j] == 'O'`），所以每个格子至多入栈一次，不会指数爆炸。

## 5. 完整代码（Python）

```python
class Solution:
    def solve(self, board) -> None:
        """
        Do not return anything, modify board in-place instead.
        思路：从四条边界上的 'O' 出发做多源 DFS，
        把能到达的 'O' 临时标记为 '#'（安全区）。
        最后全图扫描：'O' -> 'X'（被捕获），'#' -> 'O'（还原）。
        """
        if not board or not board[0]:
            return
        m, n = len(board), len(board[0])

        def dfs(i, j):
            # 越界或不是未访问的 'O'，直接返回
            if i < 0 or i >= m or j < 0 or j >= n or board[i][j] != 'O':
                return
            board[i][j] = '#'          # 标记为安全，同时充当 visited
            dfs(i + 1, j)
            dfs(i - 1, j)
            dfs(i, j + 1)
            dfs(i, j - 1)

        # 1) 左右两列
        for i in range(m):
            if board[i][0] == 'O':
                dfs(i, 0)
            if board[i][n - 1] == 'O':
                dfs(i, n - 1)

        # 2) 上下两行（角落在上面已覆盖，这里重复调用无害，因为已变 '#'）
        for j in range(n):
            if board[0][j] == 'O':
                dfs(0, j)
            if board[m - 1][j] == 'O':
                dfs(m - 1, j)

        # 3) 收尾：被捕获的变 'X'，安全的还原成 'O'
        for i in range(m):
            for j in range(n):
                if board[i][j] == 'O':
                    board[i][j] = 'X'
                elif board[i][j] == '#':
                    board[i][j] = 'O'
```

说明：`dfs` 里先判 `board[i][j] != 'O'` 再改 `'#'`，保证每个格子只被真正处理一次；边界循环里对角落的重复调用会被这个判断挡掉，不会重复展开。

## 6. 复杂度

- **时间 O(m·n)**：四条边界循环共 O(m+n) 次调用，但每次 DFS 展开的格子总数不超过 mn；收尾扫描 O(mn)。每个格子最多被标记一次、被扫描一次，常数次操作。没有 log 项，因为没有排序或二分。
- **空间 O(m·n) 最坏**：递归栈深度。最坏情况是整张图一条蛇形 `'O'` 路径，DFS 深度达到 mn，栈帧各占常数空间。若改用 BFS，队列最坏也存 O(mn) 个坐标。原地标记省掉了 visited 数组，所以额外空间只有栈/队列。平均/常见网格下栈深接近 O(m+n)，但复杂度按最坏写。

## 7. 边界与反例（至少 4 条）

1. **输入 `[['X']]`** → 输出 `[['X']]`。为什么容易错：m=n=1，边界循环会访问 (0,0)，但它是 `'X'`，DFS 直接返回；收尾扫描也不改。若代码里把「边界上的格子一律保留」写成无条件跳过，逻辑仍对；但若误把单格 `'O'` 当内部格捕获就错了——单格 `'O'` 在边界上，必须保留。
2. **输入 `[['O']]`** → 输出 `[['O']]`。为什么容易错：这是最小反例，验证「边界 `'O'` 永不被捕获」。若 DFS 起点只取内部格，会把它误改成 `'X'`。
3. **输入全 `'O'` 的 3×3** → 输出不变（全 `'O'`）。为什么容易错：所有格子都连通到边界，DFS 从边界灌满全图，收尾时全是 `'#'` 还原成 `'O'`。若标记字符和原字符混用（比如用 `'O'` 当 visited），会死循环或误判。
4. **输入 `[['X','X','X'],['X','O','X'],['X','X','X']]`** → 输出中间变 `'X'`。为什么容易错：这是「唯一被完全包围」的典型，中心格四邻全 `'X'`，DFS 从边界根本到不了它，收尾时 `'O'`→`'X'` 正确。若把「边界」判断写成 `i==0 or j==0` 漏掉 `i==m-1 or j==n-1`，会漏掉下/右边界的安全格。
5. **输入 `[['O','O'],['O','O']]`** → 输出不变。为什么容易错：2×2 全 `'O'`，每个格子都在边界上，全部安全。若边界循环只处理第一行第一列，会漏掉右下角，导致 (1,1) 被误捕获。

## 8. 面试追问与变体（3 条）

1. **追问：如果不能用递归（栈溢出风险），怎么改？** 思路：用显式栈做迭代 DFS，或 BFS 队列，把 `(i,j)` 压栈/入队，弹出时标记并推四邻，空间同为 O(mn) 但可控。
2. **追问：如果要求额外空间 O(1)，怎么做？** 思路：仍用原地标记，但把递归换成「沿边界扫描 + 手动栈」或并查集（并查集需 O(mn) parent，不满足 O(1)，所以正解是迭代 + 原地，栈用数组模拟但数组也算空间——严格 O(1) 需用 Morris 式技巧，本题一般不要求，答「原地标记已省 visited，栈深是主要开销」即可）。
3. **追问：如果 `'O'` 区域按 8 连通（含对角）算，怎么改？** 思路：DFS 四邻改成八邻，边界判断不变，正确性论证里「连通」定义换成八连通即可，复杂度不变。

## 9. 举一反三（2-3 道同类题）

- **200. 岛屿数量**：同样是网格四连通 + DFS/BFS 灌水，区别是数连通块个数而非翻转，核心「从格子出发标记整块」完全一致。
- **695. 岛屿的最大面积**：在 200 的基础上累加连通块大小，DFS 返回值求和，和本题「整块处理」是同一套骨架。
- **1020. 飞地的数量**：几乎是本题的计数版——先标记边界可达的陆地，再数剩余陆地个数，思路和代码结构可直接复用。
