## 1. 一句话本质

判断两个等长字符串之间是否存在一个**双向唯一**的字符对应关系：s 的每个字符固定映射到 t 的某个字符，且 t 的每个字符也只能被 s 的一个字符映射过来。

## 2. 读完题的第一反应

**朴素解法**：枚举 s 到 t 的所有可能字符映射（26 个字母的排列），逐个验证。这显然不可行——映射数量是阶乘级，而且题面里字符是「任意有效 ASCII」，连 26 这个常数都不成立。

稍微聪明一点的朴素做法：对 s 中每一对位置 `(i, j)`，如果 `s[i] == s[j]`，就检查 `t[i] == t[j]`；如果 `s[i] != s[j]`，就检查 `t[i] != t[j]`。这是 O(n²) 的两两比较，n 最大 5×10⁴，平方是 2.5×10⁹，超时。

**关键观察**：题面里有两句话是解题的钥匙——

- 「相同字符只能映射到同一个字符上」：s 里同一个字符，在 t 里对应位置必须全是同一个字符。
- 「不同字符不能映射到同一个字符上」：t 里同一个字符，在 s 里对应位置也必须全是同一个字符。

这两条合起来说明：**映射必须是双向的、唯一的**。于是问题从「两两比较所有位置」变成「边扫描边记录已经建立的映射，遇到冲突就返回 false」。冲突只有两种形态：s 的字符已经映射过、但映射目标不一致；或者 t 的字符已经被别的 s 字符占用。用两个哈希表分别记录「s→t」和「t→s」，一次线性扫描即可。

为什么想到用两个表而不是一个？因为只记 s→t 会漏掉第二种冲突。示例 2 就是活证据：`s="f11", t="b23"`，扫描到 `s[1]='1'` 时建立 `'1'→'2'`，扫描到 `s[2]='1'` 时发现 `'1'` 已映射到 `'2'`，但当前要映射到 `'3'`，冲突。这个例子一个表就够。但反过来构造 `s="ab", t="aa"`：一个表记录 `'a'→'a'`、`'b'→'a'`，没有冲突，却违反了「不同字符不能映射到同一个字符上」。所以必须双向记录。

## 3. 从暴力到最优

**暴力版**：对每个 i，向后扫描所有 j > i，按第 2 节的两条规则比较。瓶颈是 O(n²) 的重复比较——同一个字符被反复检查。

**优化版**：把「某个字符之前映射到了谁」这个信息缓存下来。扫描到位置 i 时，只需 O(1) 查表判断是否冲突，冲突信息不必再回头找。

用 `s = "paper", t = "title"` 走一遍，两个表分别叫 `s2t` 和 `t2s`：

| i | s[i] | t[i] | s2t 查表 | t2s 查表 | 动作 | s2t | t2s |
|---|------|------|----------|----------|------|-----|-----|
| 0 | p | t | 无 | 无 | 建立双向映射 | {p:t} | {t:p} |
| 1 | a | i | 无 | 无 | 建立双向映射 | {p:t, a:i} | {t:p, i:a} |
| 2 | p | t | 有，值为 t，与 t[i] 一致 | — | 通过 | 不变 | 不变 |
| 3 | e | l | 无 | 无 | 建立双向映射 | {p:t, a:i, e:l} | {t:p, i:a, l:e} |
| 4 | r | e | 无 | 无 | 建立双向映射 | {p:t, a:i, e:l, r:e} | {t:p, i:a, l:e, e:r} |

全部通过，返回 true。

再走一个反例 `s = "ab", t = "aa"`：

| i | s[i] | t[i] | s2t 查表 | t2s 查表 | 动作 |
|---|------|------|----------|----------|------|
| 0 | a | a | 无 | 无 | 建立 {a:a} / {a:a} |
| 1 | b | a | 无 | **有，值为 a** | t2s 里 `'a'` 已被 `'a'` 占用，冲突，返回 false |

注意这里 s2t 查表是通过的（`'b'` 没出现过），只有 t2s 能拦住它。这就是为什么必须两个表。

**瓶颈怎么被消掉的**：暴力版每个位置要回看前面所有位置，O(n²)；哈希表把「回看」变成「查一次」，每个位置 O(1)，总 O(n)。哈希表的单次操作平均 O(1)，这是它能替代线性扫描的原因。

## 4. 正确性：为什么不会漏、不会重

用**不变量**来论证。定义扫描到第 i 个位置（处理完 `s[0..i-1]`）时的不变量：

> `s2t` 恰好记录了 `s[0..i-1]` 中所有出现过的字符到 t 对应位置的映射，且每个映射都满足「相同字符映射到相同字符」；`t2s` 恰好记录了反向映射，且满足「不同字符不映射到同一字符」。

**初始化**：i=0 时两个表为空，不变量平凡成立。

**保持**：假设处理完前 i 个位置不变量成立，处理位置 i 时：

- 若 `s[i]` 在 `s2t` 中且值不等于 `t[i]`，说明 s 的同一字符之前映射到了别的字符，违反「相同字符只能映射到同一个字符上」，返回 false 是正确的。
- 若 `t[i]` 在 `t2s` 中且值不等于 `s[i]`，说明 t 的同一字符之前被别的 s 字符映射过，违反「不同字符不能映射到同一个字符上」，返回 false 是正确的。
- 两个检查都通过，则把 `s[i]→t[i]` 和 `t[i]→s[i]` 写入两个表。写入后，新映射与已有映射不冲突（因为刚检查过），不变量对 i+1 继续成立。

**终止**：扫描完所有位置都没返回 false，说明整个字符串满足两条映射规则，即存在合法的同构映射，返回 true 正确。

**为什么不会漏**：任何一对违反规则的字符，必然在扫描到其中较后的那个位置时被检查到——因为较前的那个位置已经把映射写进了表里，较后的位置查表必然命中冲突。**为什么不会重**：每个位置只做一次查表和至多一次写入，没有重复判定。

## 5. 完整代码（Python）

```python
class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        # 题面保证 len(s) == len(t)，这里不额外校验
        s2t = {}  # s 的字符 -> t 的字符
        t2s = {}  # t 的字符 -> s 的字符，用于拦截「多对一」

        for cs, ct in zip(s, t):
            # 检查 s->t 方向：同一 s 字符必须映射到同一 t 字符
            if cs in s2t:
                if s2t[cs] != ct:
                    return False
            else:
                s2t[cs] = ct

            # 检查 t->s 方向：同一 t 字符不能被多个 s 字符映射
            if ct in t2s:
                if t2s[ct] != cs:
                    return False
            else:
                t2s[ct] = cs

        return True
```

关键逻辑说明：两个 `if/else` 是独立的，不能合并成一个 `if` 提前 `return`，因为两个方向都要检查。`zip(s, t)` 依赖题面「长度相等」的保证；如果面试官追问长度不等的情况，在函数开头加一行 `if len(s) != len(t): return False` 即可。

## 6. 复杂度

**时间 O(n)**：`zip` 遍历 n 个位置，每个位置做两次哈希表查找（`in`）和至多两次写入，哈希表平均 O(1)，所以是 O(n)。n 来自字符串长度，最大 5×10⁴。没有 log 项——这里没有排序或二分。

**空间 O(k)**，k 是字符集大小，最坏 O(min(n, |Σ|))：两个哈希表各存至多 n 个键值对，但键来自字符集 Σ（题面说是任意有效 ASCII，最多 128 个），所以实际是 O(min(n, 128))，可视为 O(1) 常数空间。严格写 O(n) 也不算错，因为 n 是上界。

## 7. 边界与反例（至少 4 条）

1. `s = "a", t = "a"` → true。单字符，建立 `a→a` 后结束。容易错在：误以为「字符不能映射到自己」——题面明确说「字符可以映射到自己本身」。
2. `s = "ab", t = "aa"` → false。`t2s` 拦截：`'a'` 已被 `'a'` 占用，`'b'` 又要映射到 `'a'`。容易错在：只用一个 `s2t` 表，会误判为 true。
3. `s = "aa", t = "ab"` → false。`s2t` 拦截：`'a'` 已映射到 `'a'`，第二个位置要映射到 `'b'`。容易错在：只用一个 `t2s` 表，会误判为 true。和第 2 条互为镜像，说明两个方向缺一不可。
4. `s = "egg", t = "add"` → true。示例 1，`e→a`、`g→d`，`g` 第二次出现时映射一致。容易错在：看到 `g` 出现两次就紧张，其实重复出现且映射一致正是合法情形。
5. `s = "f11", t = "b23"` → false。示例 2，`'1'` 先映射到 `'2'`，第二次要映射到 `'3'`，`s2t` 拦截。容易错在：把 `'1'` 当成数字而非字符，或误以为相同字符可以映射到不同字符。

## 8. 面试追问与变体（3 条）

1. **追问：如果 s 和 t 长度不等怎么办？** 思路：长度不等直接返回 false，因为映射是逐位置对应的，长度必须一致；在函数开头加一行判断。
2. **追问：不用哈希表，能不能 O(1) 额外空间做？** 思路：字符集是 ASCII，可以用两个长度 128 的数组代替哈希表，记录「第一次出现的位置下标」，两个数组对应位置必须相等，否则冲突。本质是把哈希表换成定长数组，时间仍是 O(n)。
3. **追问：如果要求判断「s 能否通过重排字符变成 t 的同构」呢？** 思路：这变成字符频次的多重集比较，用两个计数数组统计频次，排序后比较或直接逐字符比较计数，O(n + |Σ|)。

- **242. 有效的字母异位词**：同样用计数/哈希处理字符对应关系，区别是它只要求频次相同、不要求位置对应，是本题的「弱化版」。
- **1. 两数之和**：共同点是「边扫描边用哈希表缓存已见信息、O(1) 查表消掉回看」，是同一套「用空间换掉线性回看」的思维模板。
