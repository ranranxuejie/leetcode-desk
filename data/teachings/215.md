## 1. 一句话本质

在无序数组里定位「排序后从大到小数第 k 个位置」的那个值，而不必真的把整个数组排好序。

## 2. 读完题的第一反应

最直接的做法：`sorted(nums)[-k]`，一行搞定。它卡在哪？排序是 O(n log n)，而题面明确要求 O(n)。所以瓶颈不在「找第 k 个」这个动作，而在「为了知道谁排第 k，把所有人都排了一遍」——我们做了大量与答案无关的排序工作。

关键观察来自快速排序的分区（partition）操作：选一个基准值 pivot，把数组分成「大于 pivot」和「小于 pivot」两堆后，pivot 的最终下标就确定了。如果这个下标恰好是我们要的位置，直接返回；如果不是，**另一整堆可以整个丢掉**——因为那一堆里的元素全部比答案大或全部比答案小，不可能包含答案。这就是「快速选择」：每次只递归一半，而不是两半都排。

为什么这个观察能引出下一步？因为快排的瓶颈是「两半都要排」，而本题只要一个位置，天然只需要走一条路径，期望复杂度从 O(n log n) 降到 O(n)。

## 3. 从暴力到最优

**第 0 步：全排序。** `sorted(nums)` 是 O(n log n)。n = 1e5 时约 1.7e6 次比较，其实也能过，但面试官要的是 O(n)。

**第 1 步：快速选择（期望 O(n)）。** 以示例 1 走一遍：`nums = [3,2,1,5,6,4], k = 2`。第 k 大等价于升序下标 `n - k = 6 - 2 = 4`（0 基），记目标下标 `target = 4`。

选最后一个元素 4 作 pivot，做分区（小于等于放左边，大于放右边）：

- 遍历过程：3<4 放左，2<4 放左，1<4 放左，5>4 放右，6>4 放右。
- 分区后数组变成 `[3,2,1,4,5,6]`，pivot 落在下标 3。

`3 < target=4`，说明答案在 pivot 右边，左边 `[3,2,1]` 连同 pivot 一起丢掉，只在 `[5,6]` 里继续找，目标下标仍是 4（全局下标不变）。

第二轮：子数组 `[5,6]`，选 6 作 pivot，分区后 `[5,6]`，pivot 落在全局下标 5。`5 > 4`，答案在左边，丢掉 6，只剩 `[5]`，pivot 下标 4 == target，返回 5。✓

对比：全排序要处理 6 个元素的两侧；快速选择第一轮处理 6 个，第二轮只处理 2 个，第三轮 1 个。总工作量 6+2+1，而不是 6+6+... 的 log 层。

**第 2 步：为什么要随机化 pivot。** 如果数组已经有序（如 `[1,2,3,4,5,6]`）且固定取末尾元素，每次分区都极不均衡，退化成 O(n²)。随机选 pivot 后，期望上每次能把问题规模砍半，期望复杂度 O(n)。这是「期望」而非「最坏」——最坏仍是 O(n²)，但随机化让最坏情况几乎不可能出现。

**第 3 步（可选）：堆解法。** 维护大小为 k 的小顶堆，遍历完堆顶就是第 k 大，O(n log k)。k 很小时比快速选择更稳（无最坏退化），但题面要求 O(n)，快速选择是主答案，堆是面试时的备选。

## 4. 正确性：为什么不会漏、不会重

用**循环不变量**说清楚。设目标下标 `target = n - k`（升序 0 基）。维护不变量：

> 当前搜索区间 `[lo, hi]` 内，**全局第 target 小的元素一定在区间内**，且区间外被丢弃的元素要么全部小于答案、要么全部大于答案。

- **初始**：区间是整个数组，显然成立。
- **保持**：分区后 pivot 落在下标 p。若 `p == target`，pivot 就是答案，直接返回。若 `p < target`，因为分区保证 `[lo, p-1]` 全部 ≤ pivot < 答案（答案下标更大），这些元素不可能是答案，丢弃后新区间 `[p+1, hi]` 仍包含答案。若 `p > target` 对称，丢弃 `[p+1, hi]`。
- **终止**：区间收缩到单元素时，由不变量它必是答案。

「不会重」体现在：每次丢弃的是**确定不含答案**的一整段，剩下的区间是原区间的子集，答案唯一且始终留在里面，不存在重复计数问题。

## 5. 完整代码（Python）

```python
import random

class Solution:
    def findKthLargest(self, nums, k):
        # 第 k 大 == 升序排列后下标 n-k 的元素（0 基）
        target = len(nums) - k
        lo, hi = 0, len(nums) - 1

        while lo <= hi:
            # 随机选 pivot 并与 hi 交换，避免有序数组退化
            pivot_idx = random.randint(lo, hi)
            nums[pivot_idx], nums[hi] = nums[hi], nums[pivot_idx]
            pivot = nums[hi]

            # Lomuto 分区：把 <= pivot 的放左边，返回 pivot 最终下标
            store = lo
            for i in range(lo, hi):
                if nums[i] <= pivot:
                    nums[store], nums[i] = nums[i], nums[store]
                    store += 1
            nums[store], nums[hi] = nums[hi], nums[store]

            # 根据 pivot 位置决定丢弃哪一半
            if store == target:
                return nums[store]
            elif store < target:
                lo = store + 1   # 答案在右半区
            else:
                hi = store - 1   # 答案在左半区

        return nums[lo]  # 理论上不会走到这里
```

关键逻辑说明：`store` 是「下一个 ≤ pivot 的元素该放的位置」，循环结束后 `store` 就是 pivot 的最终下标；`target` 用升序下标表达，避免「第 k 大」和「第 k 小」来回换算出错。

## 6. 复杂度

**时间（期望 O(n)）**：第 1 轮扫描 n 个元素，第 2 轮期望扫描 n/2，第 3 轮 n/4……等比数列求和 `n + n/2 + n/4 + ... = 2n`，即 O(n)。这里的 n 来自「每轮分区要遍历当前区间所有元素」，log 不出现是因为只走一条分支（对比快排两分支都走才有 log n 层）。最坏 O(n²) 出现在每次 pivot 都取到极值时，随机化把这种情况压到可忽略的概率。

**空间（O(1)）**：原地分区，只用几个下标变量。注意这里是迭代写法；若写成递归，栈深度期望 O(log n)、最坏 O(n)。

## 7. 边界与反例（至少 4 条）

1. `nums = [1], k = 1` → 输出 1 → 容易错在循环边界 `lo <= hi` 写成 `lo < hi`，单元素直接跳过返回错误值。
2. `nums = [3,2,1,5,6,4], k = 1` → 输出 6 → 容易错在把「第 k 大」当成「第 k 小」，target 算成 `k-1` 而非 `n-k`。
3. `nums = [2,2,2], k = 2` → 输出 2 → 容易错在分区用 `<` 而非 `<=`，导致重复元素全堆到一边，pivot 下标计算偏移，或误以为要去重。
4. `nums = [1,2,3,4,5], k = 3`（已升序）→ 输出 3 → 固定取末尾 pivot 会退化 O(n²)，必须随机化；这是最容易被面试官追问的用例。
5. `nums = [5,4,3,2,1], k = 5` → 输出 1 → 目标下标为 0，检查 `store < target` 分支不会越界。

## 8. 面试追问与变体（3 条）

1. **「如果数据是流式的，不能全存下来怎么办？」** → 用大小为 k 的小顶堆，O(n log k) 时间、O(k) 空间，堆顶即第 k 大。
2. **「要求最坏 O(n) 而不是期望 O(n) 呢？」** → 用 BFPRT（中位数的中位数）选 pivot，把随机化换成确定性线性选主元，代价是常数大。
3. **「数组有大量重复元素，快速选择会怎样？」** → 用三路分区（<、=、> pivot），把等于 pivot 的一段整体跳过，避免重复元素导致的偏斜。

## 9. 举一反三（2-3 道同类题）

- **剑指 Offer 40 / 最小的 k 个数**：同款快速选择，只是目标下标换成 `k-1`，且返回前 k 个而非单个值。
- **LC 347 前 K 个高频元素**：先统计频率，再用大小为 k 的堆或快速选择挑出前 k 个，核心仍是「不必全排序」。
- **LC 973 最接近原点的 K 个点**：把距离当键做快速选择，思路完全同构。
