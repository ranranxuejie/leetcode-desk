## 1. 一句话本质

把一棵二叉树按**先序遍历的访问顺序**重新串成一条只走 `right` 的单链，且必须复用原有结点、不能新建结点。

## 2. 读完题的第一反应

**朴素解法**：先做一次先序遍历，把结点按顺序存进一个列表 `nodes`，然后循环 `nodes[i].right = nodes[i+1]`、`nodes[i].left = None`。

它卡在哪？卡在**空间**。列表要存 n 个结点引用，额外空间 O(n)。题目进阶明确要求 O(1) 额外空间，所以这个解法虽然能过（n ≤ 2000），但拿不到进阶分，面试官会追问。

**关键观察**：先序遍历的顺序是「根 → 左子树全部 → 右子树全部」。也就是说，根结点 `root` 展开后，紧跟它的应该是**左子树展开后的链**，而这条链的**尾巴**要接到原来的右子树上。

这个观察直接给出一个递归结构：如果我能把左子树和右子树各自展开成链，那么整棵树展开 = `root` → 左链 → 右链。问题只剩一个：**左链的尾巴在哪？** 左子树展开后，最右下的那个结点就是尾巴（因为链只走 right）。于是「找左子树的最右结点」成了核心动作——而这个动作恰好可以原地完成，不需要额外容器。

## 3. 从暴力到最优

**暴力（O(n) 空间）**：先序遍历存列表，再重连。瓶颈是那个列表。

**递归版（O(h) 栈空间）**：按上面的观察写：

```
flatten(root):
    if root is None: return
    flatten(root.left)
    flatten(root.right)
    # 此时 left、right 都已是链
    left_chain = root.left
    right_chain = root.right
    root.left = None
    root.right = left_chain
    # 把 left_chain 的尾巴接到 right_chain
    tail = root
    while tail.right: tail = tail.right
    tail.right = right_chain
```

瓶颈变成两处：递归栈 O(h)，以及每个结点都要「走一遍左链找尾巴」，最坏情况（退化成左斜树）每次找尾巴是 O(n)，总时间 O(n²)。

**最优（O(1) 空间，Morris 式）**：把递归也去掉。核心是把「找左子树最右结点」这件事**就地**做，并且把右子树**先挂到那个最右结点的右边**，这样就不用再回头找尾巴了。

对当前结点 `cur`：
1. 若 `cur.left` 为空，无事可做，`cur = cur.right` 继续。
2. 否则找到 `cur.left` 这棵子树的最右结点 `pre`（`pre.right` 为空的那个）。
3. 把 `cur.right` 挂到 `pre.right` 上；把 `cur.left` 挪到 `cur.right`；`cur.left = None`。
4. `cur = cur.right` 继续。

**小例子走一遍**：`root = [1,2,5,3,4,null,6]`，结构是 1 的左 2（左 3、右 4），右 5（右 6）。

- `cur=1`，`cur.left=2` 非空。找 2 子树最右：2→4，`pre=4`。`pre.right = cur.right = 5`；`cur.right = 2`；`cur.left = None`。此时 1 的链：1→2→3、4→5→6（4 的 right 是 5）。
- `cur=2`，`cur.left=3` 非空。找 3 子树最右：`pre=3`。`pre.right = cur.right = 4`；`cur.right = 3`；`cur.left=None`。链：1→2→3→4→5→6。
- `cur=3`，`left` 空，`cur=4`；`cur=4`，`left` 空，`cur=5`；`cur=5`，`left` 空，`cur=6`；`cur=6`，`left` 空，`cur=None` 结束。

结果 `1→2→3→4→5→6`，与先序 `1,2,3,4,5,6` 一致。全程只用了 `cur`、`pre` 两个指针。

## 4. 正确性：为什么不会漏、不会重

用**循环不变量**说清楚。设当前处理到 `cur`，不变量是：

> `cur` 之前的所有结点已经串成一条只走 right 的链，且顺序等于原树的先序；`cur` 及其之后的结点构成的「剩余森林」中，先序顺序保持不变。

分两种情况维护它：

- **`cur.left` 为空**：`cur` 本身就是剩余森林先序的第一个，它已经在正确位置，只需前进到 `cur.right`。不变量保持。
- **`cur.left` 非空**：原树先序中，`cur` 之后紧跟的是「左子树先序」再「右子树先序」。我们把 `cur.right`（右子树整棵）挂到左子树最右结点 `pre` 的右边——`pre` 是左子树先序的**最后一个**，所以挂上去后，左子树先序 + 右子树先序恰好接成一条链，顺序不变。再把 `cur.left` 提为 `cur.right`，`cur` 就接上了这条链的开头。不变量保持。

**不会漏**：右子树被挂到 `pre.right`，没有丢弃任何结点。**不会重**：每个结点只被移动一次（`cur.left` 置空后不再被访问为左孩子），且 `pre` 是「最右」结点，其 `right` 原本为空，挂接不覆盖已有链接。终止时 `cur` 为空，整条链就是先序，证毕。

## 5. 完整代码（Python）

```python
class Solution:
    def flatten(self, root) -> None:
        """
        Do not return anything, modify root in-place instead.
        原地 Morris 式展开：时间 O(n)，额外空间 O(1)。
        """
        cur = root
        while cur is not None:
            if cur.left is not None:
                # 1) 找左子树的最右结点 pre（先序中左子树的最后一个）
                pre = cur.left
                while pre.right is not None:
                    pre = pre.right
                # 2) 把当前右子树整棵挂到 pre 的右边，保证先序顺序
                pre.right = cur.right
                # 3) 左子树提上来成为右链，左指针清空
                cur.right = cur.left
                cur.left = None
            # 4) 左空（或已处理完）则沿 right 前进
            cur = cur.right
```

## 6. 复杂度

- **时间 O(n)**：外层 `while` 每个结点访问一次；内层 `while` 找 `pre` 的代价，摊还后每个结点最多被当作 `pre` 走一次（因为一旦某结点成为 `pre`，它的 `right` 就被填上，之后不会再被当作「最右空位」重复走到）。所以总步数是 O(n)，不是 O(n²)。
- **空间 O(1)**：只用了 `cur`、`pre` 两个指针，没有递归栈、没有列表。注意这是**额外**空间；输入树本身占 O(n) 不算在内。
- 对比：递归版空间 O(h)，h 为树高，最坏 O(n)；暴力版 O(n)。

## 7. 边界与反例（至少 4 条）

1. `root = []` → 输出 `[]`。容易错：没判空直接 `cur.left` 崩。代码里 `while cur is not None` 天然处理。
2. `root = [0]` → 输出 `[0]`。容易错：单结点时误以为要做什么，其实 `left` 为空直接跳过，正确。
3. `root = [1,2]`（只有左孩子）→ 输出 `[1,null,2]`。容易错：忘记把 `cur.left` 置 `None`，结果左指针残留，不符合「左始终为 null」。
4. `root = [1,null,2]`（只有右孩子）→ 输出 `[1,null,2]`。容易错：以为要特殊处理，其实 `cur.left` 为空直接前进即可。
5. `root = [1,2,3,4,5]`（满层偏左）→ 先序 `1,2,4,5,3`。容易错：找 `pre` 时只走一步就停，漏掉更深的最右结点，导致右子树挂错位置、顺序乱。

## 8. 面试追问与变体（3 条）

1. **追问：改成「后序」展开成链怎么做？** 思路：先递归/迭代处理右、再左，最后把左链接到右链尾部，或反向 Morris 从右往左处理。
2. **追问：不要求原地，但要求返回链头且原树可破坏，有更简单写法吗？** 思路：先序迭代用栈收集，再顺序重连，代码短但空间 O(n)。
3. **追问：展开成「双向」链表（left 指向前驱）呢？** 思路：在 Morris 过程中额外维护 `prev` 指针，串链时同时设 `prev.right` 和 `cur.left`。
