## 1. 一句话本质

这道题要求我们模拟一个「括号嵌套导致的反转顺序」：每遇到一层括号，就把该层内部已经处理好的字符串翻转一次，最终把所有层的结果拼起来。

换句话说，括号的嵌套结构决定了反转的**顺序和范围**，而字母本身只是被搬运的对象。

## 2. 读完题的第一反应

**朴素解法**：反复扫描字符串，每次找到最内层的 `(...)`（即括号内不含括号的那一对），把里面的内容反转，去掉括号，拼回原串；重复直到没有括号。

这个做法卡在哪？每次「找最内层括号 + 反转 + 拼接」都要扫描一遍字符串，而嵌套层数最多可达 n/2 层（比如 `((((a))))`），每层扫描 O(n)，总复杂度 O(n²)。n = 2000 时 O(n²) = 4×10⁶ 其实能过，但这不是面试官想看到的——他们想看你能不能一次扫描解决。

**关键观察**：括号是**后进先出**的结构——最后打开的括号最先闭合，正好对应栈。而且「从内到外逐层反转」意味着：当我们遇到 `)` 时，当前这一层的内容已经确定，只需要把它反转后交给外层。这提示我们：**用栈保存每一层的「上半部分」，遇到 `)` 时把当前累积的字符串反转后接到栈顶**。

更妙的是，反转操作有一个代数性质：连续反转两次等于没反转。这让我们可以用一个「方向标记」代替真正的反转，从而避免 O(n) 的反转开销。

## 3. 从暴力到最优

### 暴力：反复找最内层括号

以 `s = "(u(love)i)"` 为例：

- 第 1 轮：找到最内层 `(love)`，反转得 `evol`，替换后串变为 `(uevoli)`
- 第 2 轮：找到 `(uevoli)`，反转得 `iloveu`，替换后串变为 `iloveu`
- 无括号，结束。输出 `iloveu`。

每轮扫描 O(n)，共 O(层数) 轮，最坏 O(n²)。

### 优化思路：栈 + 一次扫描

我们维护一个栈 `stack`，栈里存的是「每一层括号外已经累积的字符串」。再维护一个当前字符串 `cur`。

扫描 `s` 的每个字符：

- 遇到 `(`：把当前的 `cur` 压栈，`cur` 清空（开始新的一层）
- 遇到 `)`：说明当前层结束，把 `cur` 反转，然后弹出栈顶 `prev`，令 `cur = prev + reversed(cur)`
- 遇到字母：`cur += ch`

还是用 `(u(love)i)` 走一遍：

| 字符 | 操作 | stack | cur |
|------|------|-------|-----|
| `(` | 压栈空串，清空 cur | `[""]` | `""` |
| `u` | 追加 | `[""]` | `"u"` |
| `(` | 压栈 `"u"`，清空 cur | `["", "u"]` | `""` |
| `l` | 追加 | `["", "u"]` | `"l"` |
| `o` | 追加 | `["", "u"]` | `"lo"` |
| `v` | 追加 | `["", "u"]` | `"lov"` |
| `e` | 追加 | `["", "u"]` | `"love"` |
| `)` | 反转 `"love"`→`"evol"`，弹出 `"u"`，拼接 | `[""]` | `"uevol"` |
| `i` | 追加 | `[""]` | `"uevoli"` |
| `)` | 反转 `"uevoli"`→`"iloveu"`，弹出 `""`，拼接 | `[]` | `"iloveu"` |

结果 `iloveu`，正确。

这个做法每个字符只处理一次，但**反转操作本身是 O(当前层长度)**，而每层长度加起来最坏是 O(n²) 吗？不是——每一层的字符串在反转时只被处理一次，且各层长度之和不超过 n（因为每个字母只属于某一层），所以总反转开销是 O(n)。整体 O(n)。

### 再进一步：用方向标记避免反转

其实还可以更省：用一个布尔变量 `rev` 表示「当前层是否需要反转」。遇到 `(` 时切换 `rev`，遇到 `)` 时也切换 `rev`，字母根据 `rev` 决定是追加到 `cur` 的头部还是尾部。这样连反转都省了，但代码稍复杂，且 Python 中头部插入是 O(n)，反而不划算。所以**栈 + 反转**是工程上最平衡的写法。

## 4. 正确性：为什么不会漏、不会重

**不变量**：在扫描过程中，栈 `stack` 中从底到顶依次保存的是「当前未闭合的每一层括号外已经累积的字符串」，`cur` 是「当前最内层未闭合括号内已经累积的字符串」。

- **初始**：栈空，`cur` 空，不变量成立。
- **遇到字母**：它属于当前最内层，追加到 `cur`，不变量保持。
- **遇到 `(`**：新开一层，当前 `cur` 成为外层的「已累积部分」，压栈；新层 `cur` 清空。不变量保持。
- **遇到 `)`**：当前层闭合，按题意「从内到外」应先反转本层内容，再交给外层。反转 `cur` 后与栈顶拼接，正好模拟了「本层反转后作为外层的一部分」。不变量保持。

扫描结束时栈必为空（题面保证括号成对），`cur` 就是最终结果。由于每个字符恰好被追加一次、每层恰好被反转一次，不会漏也不会重。

## 5. 完整代码（Python）

```python
class Solution:
    def reverseParentheses(self, s: str) -> str:
        stack = []   # 保存每一层括号外已累积的字符串
        cur = []     # 当前层已累积的字符（用 list 追加，最后 join）

        for ch in s:
            if ch == '(':
                # 新开一层：把当前累积压栈，清空当前层
                stack.append(''.join(cur))
                cur = []
            elif ch == ')':
                # 当前层闭合：先反转本层内容
                cur.reverse()
                # 再与外层已累积部分拼接
                prev = stack.pop()
                cur = list(prev) + cur
            else:
                # 普通字母：追加到当前层
                cur.append(ch)

        return ''.join(cur)
```

注意 `cur.reverse()` 是原地反转 list，O(本层长度)；`list(prev) + cur` 是拼接，O(外层长度 + 本层长度)。整体每个字符最多参与一次反转和一次拼接，总 O(n)。

## 6. 复杂度

- **时间 O(n)**：每个字符被访问一次（O(n)）；每个字符最多参与一次 `reverse`（各层长度之和 ≤ n）；每个字符最多参与一次拼接（同理）。所以总时间 O(n)。
- **空间 O(n)**：栈中保存的字符串总长度不超过 n（每个字母只属于某一层的外层累积），`cur` 长度也不超过 n。最坏情况如 `((((a))))`，栈深度 O(n)，但栈中字符串总长仍是 O(n)。

没有 log n 项——本题不涉及分治或树高。

## 7. 边界与反例（至少 4 条）

1. **输入 `"a"` → 输出 `"a"`**：没有括号，容易错在代码假设一定有 `(` 而崩溃，或忘记处理纯字母情况。
2. **输入 `"()"` → 输出 `""`**：空括号对，反转空串仍是空串。容易错在拼接时把空串当异常，或返回 `"()"`。
3. **输入 `"(ab)(cd)"` → 输出 `"badc"`**：两个并列括号对，各自独立反转。容易错在把两个括号对当成嵌套处理，或只反转了第一个。
4. **输入 `"a(bc)d"` → 输出 `"acbd"`**：括号外还有字母，且括号在中间。容易错在只处理括号内而丢掉外层字母，或拼接顺序搞反（应是 `a` + `cb` + `d`）。
5. **输入 `"((a))"` → 输出 `"a"`**：两层嵌套，反转两次等于没反转。容易错在只反转一次，或栈弹出顺序错误。

## 8. 面试追问与变体（3 条）

1. **追问：如果括号不保证成对，怎么处理？** 思路：扫描时若 `)` 时栈空，说明多余右括号，可跳过或报错；扫描结束栈非空说明左括号多余，按未闭合处理（不反转直接拼接）。
2. **追问：能否不用栈，用递归实现？** 思路：写一个 `dfs(i)` 返回「从 i 开始处理到匹配的 `)` 为止的字符串和下一个位置」，遇到 `(` 递归，遇到 `)` 返回，返回前反转本层结果。
3. **追问：如果要求输出每一步的中间结果（每次反转后的串），怎么改？** 思路：在 `)` 分支里反转后，把当前 `cur` 拼成字符串记录到结果列表，最后统一返回。
