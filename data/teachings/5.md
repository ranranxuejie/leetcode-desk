## 1. 一句话本质

在所有「以某个位置为中心、向两边对称展开」的字符区间里，找出能完整展开到底的那一个中长度最大的。

## 2. 读完题的第一反应

**朴素解法**：枚举所有子串 `s[i:j]`，对每个子串判断是否回文。子串数量是 O(n²)，每次判断回文又要 O(n)，总复杂度 O(n³)。n=1000 时是 10⁹ 量级，必然超时。

**卡在哪**：枚举子串这一步本身没错——答案确实是某个子串。瓶颈在于「判断回文」和「枚举」被拆成了两个独立动作，重复劳动太多。比如判断 `s[0:5]` 是回文时，其实已经隐含了 `s[1:4]` 是回文的信息，但暴力法把它扔掉了。

**关键观察**：回文串有自相似结构——如果 `s[i:j]` 是回文，那么去掉首尾的 `s[i+1:j-1]` 一定也是回文。反过来，一个回文串可以由「更小的回文串两边各扩一个相同字符」得到。这意味着我们不需要「先枚举再验证」，而是可以「从一个已知的小回文出发，尝试向外扩」。最小的回文是什么？长度 1 的单个字符，以及长度 2 的两个相同字符。**所有回文都能从这两类「种子」向外生长出来**。

这个观察直接给出两条路：一条是「以每个位置为中心向外扩」（中心扩展），一条是把「向外扩」写成递推（区间 DP）。两者本质相同，中心扩展空间 O(1)，更适合面试手写。

## 3. 从暴力到最优

**第一步：从 O(n³) 到 O(n²) 的枚举方式改变。**

不再枚举「所有子串再验证」，而是枚举「所有中心再扩展」。中心有两类：

- 奇数长度回文，中心是一个字符，共 n 个中心；
- 偶数长度回文，中心是两个字符之间的缝隙，共 n-1 个中心。

对每个中心，用两个指针 `l`、`r` 向两边走，只要 `s[l] == s[r]` 就继续，否则停。每个中心最多扩 O(n) 步，总 O(n²)。n=1000 时约 10⁶，完全够。

**走一遍 `s = "babad"`：**

| 中心 | 类型 | 扩展过程 | 得到的最长 |
|---|---|---|---|
| i=0 ('b') | 奇 | l=0,r=0 → 越界停 | "b" |
| i=0.5 | 偶 | s[0]='b', s[1]='a' 不等，停 | "" |
| i=1 ('a') | 奇 | l=1,r=1 → s[0]='b'=s[2]='b' → l=0,r=2 → 越界停 | "bab" |
| i=1.5 | 偶 | s[1]='a', s[2]='b' 不等 | "" |
| i=2 ('b') | 奇 | l=2,r=2 → s[1]='a'=s[3]='a' → l=1,r=3 → s[0]='b'=s[4]='d'? 不等停 | "aba" |
| i=2.5 | 偶 | s[2]='b', s[3]='a' 不等 | "" |
| i=3 ('a') | 奇 | l=3,r=3 → s[2]='b'=s[4]='d'? 不等停 | "a" |
| i=3.5 | 偶 | s[3]='a', s[4]='d' 不等 | "" |
| i=4 ('d') | 奇 | l=4,r=4 → 越界停 | "d" |

全程记录 `(start, max_len)`，最终得到 `"bab"`（长度 3，起点 0）。注意 i=2 也扩出了长度 3 的 `"aba"`，两者都合法，题目说任一即可。

**第二步：为什么这已经是最优的实用解？**

中心扩展是 O(n²) 时间、O(1) 空间。理论上有 Manacher 算法做到 O(n)，但它需要维护「当前最右回文边界 + 对称中心」并做镜像复用，代码量和出错率对面试不友好，且 n≤1000 时 O(n²) 的 10⁶ 次操作远在时限内。**面试里先写中心扩展，追问再提 Manacher 的思路**，这是更稳的策略。

## 4. 正确性：为什么不会漏、不会重

用**不变量**说清楚。

**不变量**：算法结束时，`max_len` 等于「所有以某个字符为中心或某条缝隙为中心的极大回文半径」中的最大值对应的长度。

**为什么不会漏**：任取一个最长回文子串 `s[i:j]`（长度 L）。

- 若 L 为奇数，它的中心是下标 `(i+j)//2` 这个字符。当我们枚举到这个中心时，`l`、`r` 从中心出发，由于 `s[i:j]` 是回文，对任意偏移 k 都有 `s[center-k] == s[center+k]`，所以扩展至少能走到 `l=i, r=j` 才停（可能更远，但不会更近）。因此这个长度被记录。
- 若 L 为偶数，它的中心是 `i` 和 `i+1` 之间的缝隙，即枚举时的 `(i, i+1)` 这对起点。同理，扩展至少能覆盖整个 `s[i:j]`。

**为什么不会重**：每个中心只被枚举一次（奇数中心 n 个、偶数中心 n-1 个），每个中心只做一次单向扩展，不存在同一区间被两个不同中心重复计算为「答案候选」的情况。即使 `"bab"` 和 `"aba"` 长度相同，它们来自不同中心，是并列候选，取第一个即可，不影响正确性。

**为什么扩展停下的位置是对的**：扩展停止的条件是 `l < 0` 或 `r >= n` 或 `s[l] != s[r]`。前两者是边界，第三者说明再往外扩就不再对称，此时 `[l+1, r-1]` 就是以该中心能得到的极大回文，长度 `r-l-1`。这个「极大」性质保证了不会漏掉更长的、以同一中心出发的回文。

## 5. 完整代码（Python）

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        if not s:
            return ""
        n = len(s)
        start, max_len = 0, 1  # 至少有一个字符，长度 1 一定合法

        def expand(l: int, r: int):
            # 从 (l, r) 出发向两边扩，返回扩展后的 [l, r] 闭区间
            while l >= 0 and r < n and s[l] == s[r]:
                l -= 1
                r += 1
            # 循环退出时，合法回文是 [l+1, r-1]
            return l + 1, r - 1

        for i in range(n):
            # 奇数长度：中心是单个字符 i
            l1, r1 = expand(i, i)
            if r1 - l1 + 1 > max_len:
                start, max_len = l1, r1 - l1 + 1

            # 偶数长度：中心是 i 和 i+1 之间的缝隙
            l2, r2 = expand(i, i + 1)
            if r2 - l2 + 1 > max_len:
                start, max_len = l2, r2 - l2 + 1

        return s[start:start + max_len]
```

关键点说明：

- `expand` 返回的是**闭区间** `[l+1, r-1]`，因为 while 退出时 `l`、`r` 已经越过了合法边界一步。这个「多走一步再回退」的写法比在循环里记录更简洁，也不容易错。
- 偶数中心用 `expand(i, i+1)`，当 `i = n-1` 时 `r = n` 越界，while 条件第一轮就不成立，返回 `[n, n-1]` 这个空区间，长度 0，不会更新 `max_len`，安全。
- 初始 `max_len = 1` 而不是 0，因为 n≥1 时单字符一定是回文，省去对空串的特判分支。

## 6. 复杂度

**时间 O(n²)**：外层循环 n 次，每次调用 `expand` 两次。单次 `expand` 的 while 循环最多走 `min(l+1, n-r)` 步，最坏 O(n)（例如 `"aaaa...a"`，每个中心都能扩到边界）。所以总时间是 `n × 2 × O(n) = O(n²)`。n=1000 时约 2×10⁶ 次比较，Python 里毫秒级。

**空间 O(1)**：只用了 `start`、`max_len`、`l`、`r` 几个整型变量，没有开辟与 n 相关的数组。返回的子串切片 `s[start:start+max_len]` 是 O(L) 的输出空间，不计入算法辅助空间。

对比：区间 DP 是 O(n²) 时间 + O(n²) 空间（`dp[i][j]` 布尔表）；Manacher 是 O(n) 时间 + O(n) 空间。中心扩展在空间上占优，是这道题 n≤1000 约束下的最优实用选择。

## 7. 边界与反例（至少 4 条）

1. **输入 `"a"` → 输出 `"a"`**。容易错在：初始 `max_len` 设成 0 后，奇数中心扩展返回长度 1 能更新，但若代码里对偶数中心先判断且用了 `s[i+1]` 越界访问，会抛 IndexError。用 `expand(i, i+1)` 让 while 条件兜住越界即可。

2. **输入 `"ac"` → 输出 `"a"` 或 `"c"`**。容易错在：两个字符不相等，没有任何长度 ≥2 的回文，必须回退到长度 1。若初始 `max_len` 设 0 且忘记单字符种子，会返回空串。

3. **输入 `"aaaa"` → 输出 `"aaaa"`**。容易错在：只枚举奇数中心会得到 `"aaa"`（长度 3），漏掉偶数中心的 `"aaaa"`（长度 4）。必须两类中心都枚举，这是本题最常见的 WA 来源。

4. **输入 `"cbbd"` → 输出 `"bb"`**。容易错在：中心在 `i=1` 的缝隙 `(1,2)`，`s[1]='b'=s[2]='b'` 扩一步后 `l=0, r=3`，`s[0]='c' != s[3]='d'` 停，得到 `"bb"`。若偶数中心写成 `expand(i, i)` 就退化成奇数中心，永远得不到 `"bb"`。

5. **输入 `"abacdfgdcaba"` → 输出 `"abacdfgdcaba"` 中的 `"aba"`（首或尾）**。容易错在：多个等长答案时，代码用 `>` 而非 `>=` 更新，会保留最先找到的那个；若用 `>=` 会保留最后一个。两者都合法，但要意识到题目允许多解，不要因为和示例不同就怀疑代码。

## 8. 面试追问与变体（3 条）

1. **追问：能不能做到 O(n)？** 思路：Manacher 算法。维护当前最右回文右边界 `R` 和对应中心 `C`，利用回文的对称性，新中心的半径至少等于其关于 `C` 的镜像点的半径（受 `R` 限制），从而避免重复扩展，总扩展次数摊还 O(n)。

2. **追问：如果要求返回「最长回文子序列」而不是子串呢？** 思路：子序列不要求连续，中心扩展失效。转成区间 DP：`dp[i][j] = dp[i+1][j-1] + 2 if s[i]==s[j] else max(dp[i+1][j], dp[i][j-1])`，O(n²) 时间空间。

3. **追问：如何判断一个字符串能否通过「删除至多一个字符」变成回文？** 思路：双指针从两端向中间走，遇到不等时，分别尝试跳过左字符或右字符，检查剩余子串是否回文，O(n) 时间。

## 9. 举一反三（2-3 道同类题）

1. **LeetCode 647. 回文子串**：同样用中心扩展，区别是不求最长而是计数——每扩展成功一步就 `count += 1`，两类中心都统计，O(n²) 时间 O(1) 空间。

2. **LeetCode 516. 最长回文子序列**：和本题共享「回文的自相似结构」这一观察，但子序列不连续，必须用区间 DP 而非中心扩展，是理解「连续 vs 不连续」差异的好对照。

3. **LeetCode 125. 验证回文串**：本题的退化版——只判断整个串是否回文，双指针从两端向中间走即可，O(n) 时间 O(1) 空间，是中心扩展思想的「单中心、全长」特例。
