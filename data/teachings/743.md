## 1. 一句话本质

求有向带权图中从源点 k 到**所有**节点的最短距离，然后取这些距离的**最大值**；若有节点不可达则返回 -1。

换句话说：单源最短路（SSSP）+ 取 max。

## 2. 读完题的第一反应

**朴素解法**：从 k 出发做 DFS/BFS，枚举所有路径，记录到每个节点的最小到达时间。

卡在哪？BFS 只能处理**边权相同**的情况（每层距离 +1）。这里边权是 0~100 的任意值，BFS 第一次到达某节点时不一定是最短的——你可能先走了一条"跳数少但权重大"的路。DFS 枚举所有路径则是指数级的（虽然 n≤100 时勉强能过，但面试官不会满意）。

**关键观察**：题目问的是"所有节点都收到信号的时间"，也就是 `max(dist[k][v]) for v in 1..n`。这直接把问题归约成**单源最短路**。而单源最短路在非负权图上的标准解法是 Dijkstra。

为什么能想到 Dijkstra？因为"信号传播"天然满足：一旦某个节点以最短时间收到信号，它就可以作为新的中继去更新邻居——这正是 Dijkstra 的贪心扩展过程。边权非负（w≥0）保证了"已确定的最短距离不会再被更短的路径推翻"。

## 3. 从暴力到最优

**第一步：暴力 DFS 枚举所有路径**

从 k 出发，尝试每条出边，记录到达每个节点的最小时间。问题：同一个节点会被反复访问，路径数可能爆炸。n=100、边数 6000 时，最坏情况下的路径数远超可接受范围。

**第二步：Bellman-Ford 式松弛（O(n·E)）**

维护 `dist[v]` = 当前已知的 k 到 v 的最短时间，初始 `dist[k]=0`，其余 ∞。反复扫描所有边 `(u,v,w)`，若 `dist[u]+w < dist[v]` 则更新。最多扫 n-1 轮就能收敛。

这个思路是对的，但每轮都要扫全部 6000 条边，n=100 时是 60 万次操作——能过，但不是最优。瓶颈在于：**很多边在某一轮根本没被更新过，却仍然被扫描**。

**第三步：Dijkstra + 优先队列（O((n+E) log n)）**

只从"当前 dist 最小的未确定节点"出发去松弛它的出边。用一个最小堆维护候选。

**具体小例子走一遍**：`times = [[2,1,1],[2,3,1],[3,4,1]], n=4, k=2`

邻接表：`2→[(1,1),(3,1)]`，`3→[(4,1)]`。

- 初始：`dist = [∞, 0, ∞, ∞]`（下标 1..4），堆 = `[(0, 2)]`
- 弹出 `(0, 2)`：松弛 2→1 得 `dist[1]=1`，2→3 得 `dist[3]=1`。堆 = `[(1,1),(1,3)]`
- 弹出 `(1, 1)`：节点 1 无出边，跳过。
- 弹出 `(1, 3)`：松弛 3→4 得 `dist[4]=2`。堆 = `[(2,4)]`
- 弹出 `(2, 4)`：无出边。
- 堆空，`dist = [1, 0, 1, 2]`，max = **2**。✓

对比 Bellman-Ford：它第一轮会扫全部 3 条边，第二轮再扫 3 条……而 Dijkstra 只处理了 4 次弹出、3 次松弛。边越多、n 越大，差距越明显。

## 4. 正确性：为什么不会漏、不会重

**不变量**：每次从堆中弹出节点 u 时，`dist[u]` 已经是 k 到 u 的最终最短距离。

**证明（交换论证）**：假设存在一条更短的路径 P 到达 u。设 P 上第一个尚未被确定的节点为 x，则 `dist[x] < dist[u]`（因为边权非负，路径上距离单调不减）。那么 x 应该比 u 更早被弹出——矛盾。所以 u 弹出时不可能还有更短路径。

**不会漏**：所有从已确定节点出发的边都被松弛过，任何最短路径上的节点都会被依次确定。

**不会重**：每个节点一旦弹出就标记 `visited`，后续即使堆里还有它的旧条目也直接跳过（这就是代码里 `if d > dist[u]: continue` 的作用——惰性删除）。

**为什么边权必须非负**：如果存在负权边，上面"路径上距离单调不减"就不成立，x 可能比 u 更晚弹出，交换论证失效。题目保证 `w ≥ 0`，所以 Dijkstra 适用。

## 5. 完整代码（Python）

```python
import heapq
from typing import List

class Solution:
    def networkDelayTime(self, times: List[List[int]], n: int, k: int) -> int:
        # 建邻接表：graph[u] = [(v, w), ...]
        graph = [[] for _ in range(n + 1)]  # 节点编号 1..n，下标 0 不用
        for u, v, w in times:
            graph[u].append((v, w))

        INF = float('inf')
        dist = [INF] * (n + 1)   # dist[v] = k 到 v 的当前最短时间
        dist[k] = 0

        # 最小堆，元素为 (当前距离, 节点)
        heap = [(0, k)]

        while heap:
            d, u = heapq.heappop(heap)
            # 惰性删除：堆里可能残留同一节点的旧（更大）距离
            if d > dist[u]:
                continue
            # 用 u 去松弛所有出边
            for v, w in graph[u]:
                nd = d + w
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(heap, (nd, v))

        # 取 1..n 中的最大距离；若有 INF 说明不可达
        ans = max(dist[1:])
        return -1 if ans == INF else ans
```

关键逻辑说明：
- `if d > dist[u]: continue` 是 Dijkstra 配堆的标准写法，避免处理过期条目。
- `max(dist[1:])` 直接对应"所有节点都收到信号的时间"。
- 用 `float('inf')` 判不可达，比用 `-1` 哨兵更不容易出错。

## 6. 复杂度

**时间：O((n + E) log n)**，其中 E = len(times)。

- 建图：O(E)。
- 每个节点最多被弹出一次有效条目，堆操作 O(log n)，共 O(n log n)。
- 每条边最多触发一次成功松弛（`nd < dist[v]` 成立时），每次 push 是 O(log n)，共 O(E log n)。
- 合计 O(E log n + n log n) = O((n+E) log n)。

注意：堆里最多有 O(E) 个条目（每次成功松弛 push 一个），所以弹出操作总数上界是 O(E)，不是 O(n)——但每个节点只有第一次弹出是有效的，其余被 `continue` 跳过，所以有效弹出是 O(n)。严格写是 O(E log E)，因为 E ≥ n-1（连通时），可简化为 O(E log n)。

**空间：O(n + E)**。

- 邻接表 O(n + E)。
- `dist` 数组 O(n)。
- 堆最坏 O(E)。

## 7. 边界与反例（至少 4 条）

1. **`times = [[1,2,1]], n = 2, k = 2`** → 期望 `-1`。容易错：从 k=2 出发没有任何出边，节点 1 不可达，`dist[1]` 仍是 INF。如果忘记检查 INF 直接返回 max，会返回 inf 或报错。

2. **`times = [[1,2,1]], n = 1, k = 1`** → 期望 `0`。容易错：n=1 时没有边，但源点自己已经收到信号，答案是 0。如果代码里 `max(dist[1:])` 对空列表取 max 会抛异常——这里 `dist[1:]` 长度为 1（只有 dist[1]=0），没问题；但如果写成 `dist[2:]` 就错了。

3. **`times = [[1,2,1],[2,3,1],[1,3,3]], n = 3, k = 1`** → 期望 `2`。容易错：1→3 直连权重 3，但 1→2→3 只需 2。BFS 按跳数会先到 3（1 跳），误判为 3。Dijkstra 会正确更新为 2。

4. **`times = [[1,2,0]], n = 2, k = 1`** → 期望 `0`。容易错：边权为 0 是合法的（提示里 `0 <= w_i`）。如果代码用 `if w > 0` 过滤边，或把 0 当作"无边"处理，就会漏掉这条边导致节点 2 不可达。

5. **`times = [[1,2,1],[2,1,1]], n = 2, k = 1`** → 期望 `1`。容易错：有环。Dijkstra 的 `visited`/惰性删除机制保证不会死循环；如果手写 BFS 不加访问标记会无限循环。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求返回"信号到达每个节点的具体路径"而不只是时间，怎么改？**
   思路：在松弛成功时记录 `parent[v] = u`，最后从每个节点沿 parent 回溯到 k 即得路径。

2. **追问：如果图中有负权边（但无负环），Dijkstra 还能用吗？**
   思路：不能。改用 Bellman-Ford 或 SPFA，O(n·E)。负权会破坏"弹出即最终"的不变量。

3. **追问：如果只问"信号能否到达所有节点"，不需要具体时间，能否更快？**
   思路：只需判断从 k 出发的可达性，用普通 BFS/DFS 即可，O(n+E)，不需要堆。但本题要求时间，所以必须最短路。
