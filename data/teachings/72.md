## 1. 一句话本质

求两个字符串之间的「最小编辑代价」：把 word1 的某个前缀变成 word2 的某个前缀，每一步只允许插入、删除、替换一个字符，问最少几步。

## 2. 读完题的第一反应

**朴素解法**：把 word1 所有可能的编辑序列都试一遍。每一步有 3 种操作，最多要操作 n+m 次，搜索树规模是 3^(n+m)，n、m 到 500 时完全不可行。就算加剪枝，也说不清剪枝后还剩多少状态。

**关键观察**：题目问的是「最少操作数」，而操作只影响字符串的**前缀**——一旦我们决定了 word1 前 i 个字符怎么变成 word2 前 j 个字符，后面的字符怎么变，和前面已经无关。换句话说，**子问题之间没有后效性**：把 word1[:i] 变成 word2[:j] 的最优代价，只取决于 i、j，不取决于具体走的是哪条路径。

这个观察直接指向两个东西：一是「状态」可以用 (i, j) 两个下标描述，二是「最优子结构」成立——大问题的最优解由小问题的最优解拼出来。于是想到动态规划。

## 3. 从暴力到最优

**第一步：定义状态。** 令 `dp[i][j]` = 把 `word1[:i]` 变成 `word2[:j]` 的最少操作数。i 从 0 到 n，j 从 0 到 m。

**第二步：想转移。** 看 `word1[:i]` 和 `word2[:j]` 的**最后一个字符**，分两种情况：

- 若 `word1[i-1] == word2[j-1]`：这两个字符天然对上，不用动它们，问题退化成 `dp[i-1][j-1]`。
- 若不等：最后一步必然是三种操作之一，分别对应三个来源：
  - **替换**：把 `word1[i-1]` 改成 `word2[j-1]`，代价 1 + `dp[i-1][j-1]`；
  - **删除**：删掉 `word1[i-1]`，代价 1 + `dp[i-1][j]`；
  - **插入**：在 word1 末尾插入 `word2[j-1]`，代价 1 + `dp[i][j-1]`。

取三者最小。

**第三步：用具体例子走一遍。** 取 `word1 = "horse"`、`word2 = "ros"`，只算最后一行附近，看转移怎么工作。

先填边界：`dp[i][0] = i`（全删），`dp[0][j] = j`（全插）。

算到 `dp[3][3]`（即 "hor" → "ros"）时，`word1[2]='r'`，`word2[2]='s'`，不等：

- 替换：`dp[2][2] + 1`。`dp[2][2]` 是 "ho"→"ro"，'o'≠'o'？其实 'o'=='o'，所以 `dp[2][2] = dp[1][1] = 1`（"h"→"r" 替换一次）。故替换候选 = 2。
- 删除：`dp[2][3] + 1`。`dp[2][3]` 是 "ho"→"ros"，算出来是 2，候选 = 3。
- 插入：`dp[3][2] + 1`。`dp[3][2]` 是 "hor"→"ro"，是 1，候选 = 2。

取 min = 2。继续推到 `dp[5][3]` 得 3，与示例一致。**注意**：这里 `dp[2][2]` 之所以是 1，是因为 "h"→"r" 只需一次替换，而不是两次——转移里「相等就白拿」这条规则把代价压下来了，这正是 DP 比暴力聪明的点：它复用了已经算好的子问题，而不是重新搜。

**第四步：为什么暴力被消掉了。** 暴力枚举的是「操作序列」，长度指数级；DP 枚举的是「(i, j) 状态」，只有 (n+1)(m+1) 个，每个状态 O(1) 转移。瓶颈从「序列数」变成「状态数」，这就是全部收益。

## 4. 正确性：为什么不会漏、不会重

用**最优子结构 + 最后一步分类**来论证。

**不变量**：对任意 i、j，`dp[i][j]` 等于把 `word1[:i]` 变成 `word2[:j]` 的真实最小操作数。

**归纳**：假设所有更小下标的状态都正确。考虑任意一条把 `word1[:i]` 变成 `word2[:j]` 的最优操作序列，看它的**最后一步**作用在哪个字符上：

- 若最后一步是替换 `word1[i-1]`，则替换前必须已经把 `word1[:i-1]` 变成 `word2[:j-1]`，且这一步代价 1，总代价 ≥ `dp[i-1][j-1] + 1`；
- 若最后一步是删除 `word1[i-1]`，则删除前已把 `word1[:i-1]` 变成 `word2[:j]`，总代价 ≥ `dp[i-1][j] + 1`；
- 若最后一步是插入 `word2[j-1]`，则插入前已把 `word1[:i]` 变成 `word2[:j-1]`，总代价 ≥ `dp[i][j-1] + 1`。

这三种情况**互斥且穷尽**（最后一步只能动一个字符，且只能动这三个位置之一），所以最优解必落在三者之一，取 min 不会漏。反过来，每个候选都能构造出一条合法序列，所以取 min 不会多算。当 `word1[i-1] == word2[j-1]` 时，可以证明存在最优解不动这两个字符（交换论证：若某最优解动了它们，把这对操作删掉仍合法且不更差），故直接取 `dp[i-1][j-1]`。

## 5. 完整代码（Python）

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        n, m = len(word1), len(word2)

        # dp[j] 表示当前行（word1 前 i 个字符）变成 word2 前 j 个字符的最小代价
        # 初始化第 0 行：word1 为空，只能靠插入，代价 = j
        dp = list(range(m + 1))

        for i in range(1, n + 1):
            # prev 保存 dp[i-1][j-1]，即左上角的值
            prev = dp[0]
            # 第 i 行第 0 列：word2 为空，只能靠删除，代价 = i
            dp[0] = i

            for j in range(1, m + 1):
                temp = dp[j]  # 先存下 dp[i-1][j]，后面会被覆盖

                if word1[i - 1] == word2[j - 1]:
                    # 字符相同，直接继承左上角，不花代价
                    dp[j] = prev
                else:
                    # 三种操作取最小：替换(左上)、删除(上)、插入(左)
                    dp[j] = 1 + min(prev, dp[j], dp[j - 1])

                prev = temp  # 为下一列准备左上角

        return dp[m]
```

关键点：`prev` 和 `temp` 两个变量负责在滚动数组里保住「左上角」和「上方」的值，否则一维数组会被本行新值覆盖，转移就错了。

## 6. 复杂度

- **时间 O(n·m)**：两层循环，外层 n 次、内层 m 次，每次转移 O(1)。n、m 分别来自 word1、word2 的长度。
- **空间 O(m)**：只开一个长度 m+1 的一维数组。滚动掉的是「行」这一维，所以空间由**较短串**决定——代码里可以加一句 `if len(word1) < len(word2): word1, word2 = word2, word1` 让 m 取较小值，进一步省空间。这里没有 log 项，因为没有任何分治或二分。

## 7. 边界与反例（至少 4 条）

1. `word1 = ""`, `word2 = "abc"` → 3。容易错在没初始化第 0 行，或把空串当成非法输入。空串是合法输入（提示里长度可以为 0）。
2. `word1 = "abc"`, `word2 = ""` → 3。对称情况，容易错在只处理了插入没处理删除，或 `dp[0]` 没随行更新。
3. `word1 = "abc"`, `word2 = "abc"` → 0。容易错在相等时仍加 1，或忘记「相等直接继承左上角」这条捷径。
4. `word1 = "a"`, `word2 = "b"` → 1。容易错在把替换和删除/插入的候选搞混，或一维数组里 `prev` 没及时更新导致读到本行新值。
5. `word1 = "intention"`, `word2 = "execution"` → 5。这是官方示例，用来验证转移在长串上不退化；若输出不是 5，多半是 `prev`/`temp` 的更新顺序写反了。

## 8. 面试追问与变体（3 条）

1. **追问：如果操作代价不是 1，而是插入 a、删除 b、替换 c，怎么改？** 思路：转移里把三个 `+1` 换成对应代价即可，结构不变，仍是 O(nm)。
2. **追问：只允许插入和删除，不允许替换，答案是多少？** 思路：替换候选删掉，只剩 `dp[i-1][j]+1` 和 `dp[i][j-1]+1`；此时答案等于 `n + m - 2·LCS`，可顺带引出 LCS。
3. **追问：要输出具体操作序列而不只是步数，怎么做？** 思路：再开一个 `(n+1)×(m+1)` 的方向表，回溯时按转移来源反推每一步是替换/删除/插入，空间回到 O(nm)。

## 9. 举一反三（2-3 道同类题）

- **1143. 最长公共子序列**：同样是「两个前缀」的二维 DP，转移只分「相等继承」和「不等取 max」，是编辑距离的简化版。
- **583. 两个字符串的删除操作**：只保留删除操作，答案 = n + m - 2·LCS，和本题共享同一套状态定义。
- **10. 正则表达式匹配**：也是字符串前缀上的二维 DP，区别在于转移要考虑 `*` 的「零次或多次」，是编辑距离的加强版。
