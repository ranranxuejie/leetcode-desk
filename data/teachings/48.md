## 1. 一句话本质

把矩阵中每个位置 `(i, j)` 的元素搬到它顺时针转 90° 后的新位置 `(j, n-1-i)`，且全程只允许用 O(1) 额外空间完成这次「全员搬家」。

## 2. 读完题的第一反应

最直白的做法：新建一个 n×n 矩阵 `res`，遍历原矩阵，令 `res[j][n-1-i] = matrix[i][j]`，最后把 `res` 的内容拷回 `matrix`。这完全正确，但题目明确禁止「使用另一个矩阵」，而且它需要 O(n²) 额外空间——n=20 时是 400 个格子，虽然不大，但面试官要的是原地。

关键观察来自**坐标映射本身**：`(i, j) → (j, n-1-i)`。盯着这个式子看，它把「行下标」和「列下标」互换了一下，再对列做了个翻转。而「下标互换」正是**转置**的定义（`(i,j) → (j,i)`），「翻转」正是**沿某条轴镜像**。于是问题被拆成两个各自都能原地完成的动作：先转置，再左右翻转。这个观察的价值在于：它把一个「四元循环置换」的难题，降级成两个「二元交换」的简单题——而二元交换天然可以原地做。

## 3. 从暴力到最优

**第一步：暴力。** 开新矩阵，按映射填，再拷回。时间 O(n²)（每个元素搬一次），空间 O(n²)。瓶颈在空间。

**第二步：想原地，先看元素怎么「成环」。** 取 n=3 的示例，追踪 `(0,0)` 这个位置：

- `(0,0)` 的值 1 → 去 `(0, 2)`
- `(0,2)` 的值 3 → 去 `(2, 2)`
- `(2,2)` 的值 9 → 去 `(2, 0)`
- `(2,0)` 的值 7 → 去 `(0, 0)`

四个位置首尾相接成一个环。这意味着：只要用一个临时变量 `tmp`，就能让这 4 个格子原地轮转一圈，不丢值。这就是「四元组轮换」解法，空间 O(1)，时间 O(n²)。但它有个坑：**哪些格子是环的起点？** 如果每个格子都当起点转一圈，就会重复旋转、把结果转坏。必须精确地只取「每个环的一个代表」，这个边界推导容易出错（n 为奇数时中心格不能碰）。

**第三步：换成转置 + 翻转，边界变得平凡。** 还是 n=3：

原矩阵：
```
1 2 3
4 5 6
7 8 9
```
**转置**（只遍历上三角 `i < j`，交换 `(i,j)` 与 `(j,i)`）：
- 交换 `(0,1)↔(1,0)`：2 和 4 换位
- 交换 `(0,2)↔(2,0)`：3 和 7 换位
- 交换 `(1,2)↔(2,1)`：6 和 8 换位

得到：
```
1 4 7
2 5 8
3 6 9
```
**左右翻转**（每行 `i`，交换第 `j` 列与第 `n-1-j` 列，只遍历 `j < n/2`）：
- 第 0 行：1↔7 → `7 4 1`
- 第 1 行：2↔8 → `8 5 2`
- 第 2 行：3↔9 → `9 6 3`

结果 `[[7,4,1],[8,5,2],[9,6,3]]`，与期望一致。

瓶颈被消掉的方式很干净：转置和翻转都只做**两两交换**，每次交换只需一个临时变量，所以额外空间从 O(n²) 降到 O(1)；两个动作各扫约 n²/2 个格子，总时间仍是 O(n²)，没有变差。而且「只遍历一半」的边界规则极其简单（`i < j`、`j < n//2`），不像四元轮换那样要单独处理奇偶和中心格。

## 4. 正确性：为什么不会漏、不会重

用**不变量**来论证。

**转置阶段的不变量**：循环变量满足 `i < j` 时，我们交换 `(i,j)` 与 `(j,i)`。对任意一对下标 `{i,j}`（i≠j），它恰好被访问一次——因为循环只枚举 `i<j` 的那一半，`(j,i)` 这一半永远不会作为起点出现。对角线 `i==j` 不参与，因为转置后它原地不动。所以每个非对角元素恰好被交换一次，转置结果正确且无重复。

**翻转阶段的不变量**：对第 `i` 行，循环只枚举 `j < n//2`，把 `j` 与 `n-1-j` 配对。当 `n` 为偶数，`n//2` 正好把行分成两半，每对访问一次；当 `n` 为奇数，中间列 `j == n//2` 满足 `j == n-1-j`，它被排除在循环外，原地不动——这正是镜像翻转应有的行为。所以每对列恰好交换一次。

**两阶段复合的正确性**：转置把 `(i,j)` 的值送到 `(j,i)`；翻转把 `(j,i)` 的值送到 `(j, n-1-i)`。复合映射 `(i,j) → (j, n-1-i)` 与题目要求的顺时针 90° 映射逐位相等，因此最终每个位置的值都正确。整个过程没有「先读后被覆盖」的问题，因为每一步交换都是先读后写、且两个阶段互不干扰。

## 5. 完整代码（Python）

```python
class Solution:
    def rotate(self, matrix: list[list[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        n = len(matrix)

        # 阶段一：转置。只遍历上三角 (i < j)，
        # 保证每一对 (i,j)/(j,i) 恰好交换一次，对角线不动。
        for i in range(n):
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

        # 阶段二：每一行左右翻转。只遍历前一半列 (j < n//2)，
        # n 为奇数时中间列 j == n-1-j，自动被排除、原地不动。
        for i in range(n):
            for j in range(n // 2):
                matrix[i][j], matrix[i][n - 1 - j] = matrix[i][n - 1 - j], matrix[i][j]
```

## 6. 复杂度

- **时间 O(n²)**：转置阶段访问上三角，约 `n(n-1)/2` 次交换；翻转阶段访问每行前一半，约 `n·(n//2)` 次交换。两者相加是 `n²` 量级的常数倍，所以是 O(n²)。这里的 n 来自矩阵的边长，元素总数是 n²，任何解法都至少要看一遍所有元素，故 O(n²) 是下界、也是最优。
- **空间 O(1)**：只用了 `n`、循环变量 `i, j` 和 Python 元组交换时的临时值，都是常数个变量，与 n 无关。没有开辟任何与 n² 成比例的辅助结构。注意：Python 的 `a, b = b, a` 在字节码层面会建一个临时 tuple，但那是常数大小，不影响渐进空间。

## 7. 边界与反例（至少 4 条）

1. **n = 1**：输入 `[[5]]` → 期望 `[[5]]`。容易错在：转置循环 `range(i+1, n)` 为空、翻转循环 `range(n//2)` 也为空，代码应原样返回。若误写成 `range(n)` 做翻转，会自己和自己交换，虽然结果碰巧对，但逻辑是错的，遇到别的输入会暴露。
2. **n = 2**：输入 `[[1,2],[3,4]]` → 期望 `[[3,1],[4,2]]`。容易错在：转置时若写成 `j in range(n)` 全遍历，会交换两次把矩阵转回原样；翻转时 `n//2 = 1`，只交换第 0、1 列，正确。
3. **n 为奇数（如 n=3）**：输入 `[[1,2,3],[4,5,6],[7,8,9]]` → 期望 `[[7,4,1],[8,5,2],[9,6,3]]`。容易错在：翻转时若写成 `j in range((n+1)//2)`，中间列会被交换两次（自己和自己换），虽结果不变但多做了无用功；更危险的是若用四元轮换解法，中心格 `(1,1)` 会被错误地卷入环中导致值错乱。
4. **含负数/重复值**：输入 `[[-1,-1],[2,2]]` → 期望 `[[2,-1],[2,-1]]`。容易错在：如果实现里用「值相等就跳过」之类的优化，会把本该交换的重复值误判为无需处理，导致结果错误。本题必须按下标交换，不能按值判断。
5. **n = 20 上限**：输入任意 20×20 矩阵 → 期望按映射旋转。容易错在：若用递归或额外二维数组，空间会到 O(n²)=400，虽不超内存但违反「原地」要求，面试会被判不合规。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求逆时针旋转 90° 呢？** 思路：映射变成 `(i,j) → (n-1-j, i)`，等价于「先转置，再上下翻转」（或先左右翻转再转置），代码只需把阶段二换成按行交换 `i` 与 `n-1-i`。
2. **追问：如果矩阵不是 n×n，而是 m×n 的矩形，还能原地吗？** 思路：矩形转置后形状变成 n×m，原地无法容纳，必须开新矩阵；但若只要求「顺时针旋转」且允许返回新矩阵，直接按映射建 `n×m` 结果即可，时间 O(mn)、空间 O(mn)。
3. **追问：如何原地旋转 180°？** 思路：映射是 `(i,j) → (n-1-i, n-1-j)`，可以「上下翻转 + 左右翻转」两步完成，也可以按中心对称两两交换，空间 O(1)、时间 O(n²)。
