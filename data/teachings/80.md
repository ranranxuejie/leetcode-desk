## 1. 一句话本质

在**已排序**的数组上，用 O(1) 额外空间原地保留每个不同值的「前两次出现」，返回保留下来的元素个数。

关键词是「已排序」和「前两次」：前者保证相同元素挨在一起，后者把「去重」放宽成「限流」。

## 2. 读完题的第一反应

**朴素解法**：新建一个结果数组 `res`，遍历 `nums`，用一个计数器记录当前值出现了几次，超过 2 次就跳过，否则 append 到 `res`。最后把 `res` 写回 `nums` 前段。

它卡在哪？卡在**空间**。题面明确要求「不要为另一个数组分配额外空间」「O(1) 的额外内存」。`res` 是 O(n) 的，直接违规。所以瓶颈不是时间（朴素法已经是 O(n)），而是**我们不敢往原数组里写**——怕写坏还没读到的元素。

**关键观察**：结果数组的长度 `k` 永远 `<=` 当前已经读过的位置 `i`。因为每读一个元素最多往结果里放一个，所以写入位置永远追不上读取位置。这意味着「往 `nums[k]` 写」绝不会覆盖掉「还没读的 `nums[i]`」。于是我们可以把结果直接写在原数组的前段，用两个指针：一个读（`i`），一个写（`k`）。

这个观察是双指针原地题的通用钥匙：**只要写指针不越过读指针，原地覆盖就是安全的**。

## 3. 从暴力到最优

**第一步：朴素法。** 时间 O(n)，空间 O(n)。瓶颈是空间。

**第二步：原地化。** 把 `res` 换成 `nums` 的前段，用 `k` 表示「结果已写到哪」。核心问题变成：读到一个 `nums[i]` 时，怎么判断「它该不该写」？

**第三步：判断条件。** 因为数组有序，相同值连续。一个值最多留两次，等价于：**如果 `nums[i]` 和结果里倒数第二个元素相同，说明这个值已经留满两次了，跳过；否则写入。**

为什么看「倒数第二个」而不是「最后一个」？因为结果里最后一个元素如果等于 `nums[i]`，那只是这个值的第 1 次或第 2 次出现，还允许；只有当倒数第二个也等于它，才说明已经存了两个。

**小例子走一遍**：`nums = [1,1,1,2,2,3]`

初始化 `k = 0`（结果长度），`i` 从 0 扫到 5。

| i | nums[i] | 判断 | 动作 | 数组前段 | k |
|---|---|---|---|---|---|
| 0 | 1 | k<2，直接写 | nums[0]=1 | [1] | 1 |
| 1 | 1 | k<2，直接写 | nums[1]=1 | [1,1] | 2 |
| 2 | 1 | nums[k-2]=nums[0]=1 == 1 → 跳过 | — | [1,1] | 2 |
| 3 | 2 | nums[k-2]=nums[0]=1 != 2 → 写 | nums[2]=2 | [1,1,2] | 3 |
| 4 | 2 | nums[k-2]=nums[1]=1 != 2 → 写 | nums[3]=2 | [1,1,2,2] | 4 |
| 5 | 3 | nums[k-2]=nums[2]=2 != 3 → 写 | nums[4]=3 | [1,1,2,2,3] | 5 |

返回 `k = 5`，前 5 个是 `[1,1,2,2,3]`，与示例一致。

注意 `i=2` 那一步：`nums[k-2]` 是结果里的倒数第二个，此时 `k=2`，`nums[0]=1`，等于当前值 1，所以跳过。这就是「限流到两次」的判定。

**为什么 `k < 2` 要特判？** 因为 `nums[k-2]` 在 `k < 2` 时会越界（`k=0` 时是 `nums[-2]`，Python 里会绕到数组尾部，逻辑就错了）。前两个元素无论是什么都该保留（每个值最多两次，前两个位置不可能违反规则），所以直接写。

## 4. 正确性：为什么不会漏、不会重

用**循环不变量**说清楚。

**不变量**：在处理完 `nums[0..i-1]` 之后，`nums[0..k-1]` 恰好是「`nums[0..i-1]` 中每个值保留前两次出现」的结果，且保持原相对顺序。

**初始化**：`i=0, k=0`，空数组满足不变量。

**保持**：处理 `nums[i]` 时，分两种情况。

- 若 `k < 2` 或 `nums[k-2] != nums[i]`：说明结果里这个值出现次数 `< 2`（因为数组有序，若已出现两次，倒数第二个必是它），写入合法，`k` 加一，不变量保持。
- 若 `nums[k-2] == nums[i]`：说明结果里这个值已经出现至少两次。又因为数组有序，`nums[i]` 之后不会再有比它小的值，这个值再出现也只能被跳过。跳过它，不变量保持。

**终止**：`i = n` 时，`nums[0..k-1]` 就是全数组的答案，返回 `k`。

**不会漏**：每个值的前两次出现，在扫描到时 `k<2` 或 `nums[k-2] != nums[i]` 必成立（结果里该值不足两次），一定被写入。

**不会重**：第三次及以后的出现，`nums[k-2]` 必等于它（结果里已有两次），一定被跳过。

**顺序不变**：写入是按 `i` 递增进行的，`nums[k]` 的赋值顺序就是原数组顺序。

## 5. 完整代码（Python）

```python
class Solution:
    def removeDuplicates(self, nums: list[int]) -> int:
        k = 0  # 写指针：结果已写入的长度，也指向下一个待写位置
        for i in range(len(nums)):  # 读指针：遍历原数组
            # 前两个元素无条件保留；否则检查结果里倒数第二个是否等于当前值
            if k < 2 or nums[k - 2] != nums[i]:
                nums[k] = nums[i]  # 原地写入，写指针不会超过读指针
                k += 1
        return k
```

关键点说明：

- `k < 2` 的短路求值保证 `nums[k-2]` 不会在 `k=0/1` 时被访问（Python 的 `or` 短路）。
- `nums[k] = nums[i]` 中 `k <= i` 恒成立，所以不会覆盖未读元素。
- 不需要显式「删除」尾部，题面说 `k` 之后的内容无关紧要。

## 6. 复杂度

- **时间 O(n)**：`for` 循环遍历 `n` 个元素，每次循环内是常数次比较和赋值，没有嵌套循环。`n` 来自数组长度。
- **空间 O(1)**：只用了 `k`、`i` 两个整型变量，没有分配与 `n` 相关的结构。注意 Python 的 `range` 是惰性对象，不占 O(n) 额外空间。

对比朴素法：时间同为 O(n)，空间从 O(n) 降到 O(1)，这就是「原地」带来的收益。

## 7. 边界与反例（至少 4 条）

1. **`nums = [1]`** → 期望 `k=1, nums=[1]`。容易错：若忘记 `k<2` 特判，`nums[-2]` 在 Python 里取到 `nums[-1]`（即最后一个元素），逻辑混乱。
2. **`nums = [1,1]`** → 期望 `k=2, nums=[1,1]`。容易错：误以为「去重」要删到只剩一个，返回 1。
3. **`nums = [1,1,1]`** → 期望 `k=2, nums=[1,1]`。容易错：判断条件写成 `nums[k-1] != nums[i]`（看最后一个而非倒数第二个），会把第三个 1 也留下，返回 3。
4. **`nums = [1,1,1,1,1]`** → 期望 `k=2`。容易错：同上，看错位置导致限流失效。
5. **`nums = [1,2,3]`（无重复）** → 期望 `k=3`，原样返回。容易错：条件写反（`==` 写成 `!=`），把不重复的也跳过。
6. **`nums = [0,0,1,1,1,1,2,3,3]`** → 期望 `k=7, nums=[0,0,1,1,2,3,3,...]`。这是示例 2，用来验证「中间值超两次、末尾值恰好两次」的组合情况。

## 8. 面试追问与变体（3 条）

1. **「如果改成每个元素最多出现 m 次呢？」** 把 `k < 2` 改成 `k < m`，`nums[k-2]` 改成 `nums[k-m]`，其余不变。本质是「限流阈值参数化」。
2. **「如果数组没排序，还能 O(1) 空间做吗？」** 不能。无序时相同元素不连续，O(1) 空间无法判断某值是否已出现两次（除非用哈希表，那就 O(n) 空间）。排序是这题能用双指针的前提。
3. **「返回的 k 之后的内容要不要清理？」** 不用，题面明确说无关紧要。但如果追问「要求 k 之后全置 0」，加一个循环 `for j in range(k, len(nums)): nums[j] = 0` 即可，仍是 O(n) 时间 O(1) 空间。
