## 1. 一句话本质

在所有「选 m 个篮子放球」的方案里，让**相邻两球距离的最小值**尽可能大——即求一个**最大化最小值**（max-min）问题。

## 2. 读完题的第一反应

**朴素解法**：枚举所有 $C(n, m)$ 种放球方案，对每种方案算出相邻球距的最小值，取全局最大。瓶颈在组合爆炸：$n=10^5$ 时方案数是天文数字，完全不可行。即使退一步想「枚举最小磁力 $d$ 的所有可能值」，$d$ 的取值范围到 $10^9$，逐个试也是 $O(10^9 \cdot n)$。

**关键观察**：题目要的是「最大值」，而这个「能不能做到最小磁力 $\ge d$」的判断有一个极强的单调性——

> 如果存在一种方案让最小磁力 $\ge d$，那么对任何 $d' \le d$，同一种方案也满足最小磁力 $\ge d'$。

也就是说，**可行性关于 $d$ 是单调的**：$d$ 小容易做到，$d$ 大难做到，中间存在一个分界点。一旦看到「单调 + 求最大可行值」，就该条件反射想到**二分答案**。这是本题从「无从下手」到「有明确套路」的转折点。

## 3. 从暴力到最优

### 第一步：把「判断可行性」独立出来

给定一个候选值 $d$，问：能否放下 $m$ 个球，使任意两球距离都 $\ge d$？

**贪心**：排序后，第一个球一定放在最左边的篮子（放最左不会比放别处更差，因为左边没有球要迁就，越靠左给后面留的空间越大）。之后从左往右扫，只要当前篮子与「上一个放球位置」的距离 $\ge d$，就放一个球。数一数最终放下的球数是否 $\ge m$。

这一步是 $O(n)$（排序另算）。

### 第二步：二分这个 $d$

$d$ 的可行区间：下界 $1$（位置互不相同，最小距离至少 1），上界 $\lfloor(\max - \min)/(m-1)\rfloor$（$m$ 个球把总跨度切成 $m-1$ 段，最小段不可能超过平均值）。

### 具体小例子走一遍

`position = [1,2,3,4,7]`，`m = 3`。排序后 `[1,2,3,4,7]`，`lo=1`，`hi=(7-1)//2=3`。

**二分第 1 轮**：`mid=(1+3)//2=2`。判断 $d=2$：
- 放球位置 `last=1`，计数 `cnt=1`
- 2-1=1 < 2，跳过
- 3-1=2 ≥ 2，放，`last=3`，`cnt=2`
- 4-3=1 < 2，跳过
- 7-3=4 ≥ 2，放，`last=7`，`cnt=3`

`cnt=3 ≥ m`，可行。记录答案 `ans=2`，`lo=mid+1=3`。

**二分第 2 轮**：`mid=(3+3)//2=3`。判断 $d=3$：
- `last=1`，`cnt=1`
- 2,3 都因距离 <3 跳过
- 4-1=3 ≥ 3，放，`last=4`，`cnt=2`
- 7-4=3 ≥ 3，放，`last=7`，`cnt=3`

`cnt=3 ≥ m`，可行。`ans=3`，`lo=4`。

**循环结束**（`lo=4 > hi=3`），返回 `ans=3`。与示例一致。

对比暴力：暴力要枚举 $C(5,3)=10$ 种方案；这里只做了 2 次 $O(n)$ 判断。$n=10^5$ 时差距是「$10^{15}$ 量级」对「$10^5 \times 30$」。

## 4. 正确性：为什么不会漏、不会重

分两块论证。

**（a）贪心判断的正确性——交换论证。**

设贪心依次放的球位置为 $g_1 < g_2 < \dots < g_k$（$g_1$ 是最左篮子）。设存在某个可行方案 $s_1 < s_2 < \dots < s_m$ 满足相邻距离 $\ge d$。断言：对每个 $i$，都有 $g_i \le s_i$。

- 基础：$g_1$ 是最左篮子，$g_1 \le s_1$。
- 归纳：若 $g_{i-1} \le s_{i-1}$，贪心在 $g_{i-1}$ 之后找**第一个**距离 $\ge d$ 的篮子作为 $g_i$。而 $s_i$ 满足 $s_i - s_{i-1} \ge d \ge s_i - g_{i-1}$（因为 $g_{i-1}\le s_{i-1}$），所以 $s_i$ 本身就是一个「距 $g_{i-1}$ 至少 $d$」的候选，贪心取的是第一个这样的篮子，故 $g_i \le s_i$。

于是贪心能放下的球数 $k \ge m$。反过来，若贪心放不满 $m$ 个，任何方案也放不满——因为任何方案的第 $i$ 个球都不比贪心的第 $i$ 个球更靠左，贪心已经是「最省空间」的放法。所以「贪心 $\ge m$」与「存在可行方案」等价，判断不会误判。

**（b）二分不漏解——单调性不变量。**

维护不变量：**答案始终落在 $[lo, hi]$ 内，且 `ans` 记录的是已验证可行的最大值**。当 $d$ 可行时，答案 $\ge d$，故把 $lo$ 推到 $mid+1$ 并更新 `ans`；当 $d$ 不可行时，由单调性，所有 $\ge d$ 的值都不可行，答案 $< d$，故把 $hi$ 收到 $mid-1$。每轮区间严格缩小，最终 `ans` 必为最大可行值，不会漏掉真正的答案，也不会把不可行的值当成答案。

## 5. 完整代码（Python）

```python
from typing import List

class Solution:
    def maxDistance(self, position: List[int], m: int) -> int:
        position.sort()                      # 贪心依赖有序，先排序
        n = len(position)

        def can_place(d: int) -> bool:
            """能否放下 m 个球，使任意两球距离都 >= d"""
            cnt = 1                          # 第一个球放在最左篮子
            last = position[0]               # 上一个放球的位置
            for i in range(1, n):
                if position[i] - last >= d:  # 距离够，就放
                    cnt += 1
                    last = position[i]
                    if cnt >= m:             # 提前剪枝，放够就返回
                        return True
            return cnt >= m

        # 二分答案：最小磁力的取值范围
        lo, hi = 1, (position[-1] - position[0]) // (m - 1)
        ans = 1
        while lo <= hi:
            mid = (lo + hi) // 2
            if can_place(mid):
                ans = mid                    # mid 可行，尝试更大
                lo = mid + 1
            else:
                hi = mid - 1                 # mid 不可行，缩小上界
        return ans
```

## 6. 复杂度

- **时间**：$O(n \log n + n \log(\text{range}))$。
  - 排序贡献 $O(n \log n)$，$n$ 来自篮子个数。
  - 二分次数是 $O(\log(\text{range}))$，`range` 上界约 $10^9$，故约 30 次；每次 `can_place` 是 $O(n)$，$n$ 来自扫描所有篮子。合计 $O(n \log(\text{range}))$。
  - 两项合并，排序通常被二分项支配或同阶，写作 $O(n\log n + n\log V)$，$V$ 为位置跨度。
- **空间**：$O(1)$ 额外空间（不计排序本身的开销；Python 的 `sort` 是 Timsort，最坏 $O(n)$ 辅助空间，若严格计则 $O(n)$）。算法本身只用了几个标量变量。

## 7. 边界与反例（至少 4 条）

1. **`position = [1, 2], m = 2`** → 期望 `1`。容易错在把 `hi` 算成 `(2-1)//(2-1)=1` 没问题，但若 `m-1` 写成 `m` 会得 0，或忘记 `m=2` 时只有一段距离。注意 `hi` 的分母是 `m-1`。
2. **`position = [1, 1000000000], m = 2`** → 期望 `999999999`。容易错在把 `hi` 设成 `10^9` 或更大导致越界判断；也容易在 `can_place` 里用 `>` 而非 `>=`，把恰好等于 $d$ 的情况误判为不可行。
3. **`position = [1, 2, 3, 4, 5], m = 5`** → 期望 `1`。所有篮子都得用，最小距离只能是 1。容易错在二分下界设成 0 或忘记 `ans` 初值，导致返回 0。
4. **`position` 未排序，如 `[5,4,3,2,1,1000000000], m = 2`** → 期望 `999999999`。最容易错在**忘记排序**就直接贪心扫描，`last` 与后续位置的大小关系错乱，判断全错。
5. **`m = n`（用满所有篮子）** → 答案就是排序后相邻差的最小值。容易错在二分上界 `(max-min)//(m-1)` 可能大于真实答案，但二分本身能收敛，问题不大；真正的坑是 `can_place` 里提前 `return True` 的条件写成 `cnt > m` 导致永远不提前返回（不影响正确性但影响效率）。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求返回具体放球方案，而不只是最大距离？** 思路：二分出答案 $d$ 后，再用一次贪心（同样的 `can_place` 逻辑）把选中的位置收集起来返回即可，$O(n)$ 额外一趟。
2. **追问：如果篮子位置可以重复放多个球（同一位置允许多球）？** 思路：此时最小磁力可能为 0（同位置两球距离 0），需先判断 $m > n$ 时是否允许重叠；若允许，答案下界变 0，二分下界改为 0，其余逻辑不变。
3. **追问：如果改成「最大化所有相邻球距之和」？** 思路：这就不是 max-min 而是 max-sum，单调性不再成立，二分失效；需转成 DP（选 $m$ 个点使相邻差之和最大，等价于选首尾跨度，因为中间点会被「抵消」），是另一类问题。

这三道与本题的共同点：**答案本身是一个数，可行性关于这个数单调，于是二分答案 + 线性贪心判断**。看到「最大化的最小值 / 最小化的最大值」这八个字，先想二分。
