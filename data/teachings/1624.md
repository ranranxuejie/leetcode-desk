## 1. 一句话本质

对每个字符，找它**第一次出现**和**最后一次出现**的位置，两者下标之差减一就是夹在中间的子串长度，在所有出现过的字符里取最大。

## 2. 读完题的第一反应

**朴素解法**：枚举所有字符对 `(i, j)`，`i < j` 且 `s[i] == s[j]`，长度就是 `j - i - 1`，取最大。两层循环，O(n²) 对，每对 O(1) 判断，总 O(n²)。n ≤ 300 时这完全能过（9 万次操作），但面试官不会满足于此——他想看你有没有把 O(n²) 压到 O(n)。

**卡在哪**：对每个 `j`，我们都在重新扫描它前面所有位置找"同一个字符最早出现在哪"。这个"找最早出现"的动作被重复做了 n 次，而它其实只跟字符本身有关，跟 `j` 无关。

**关键观察**：题目要的是"两个相同字符之间"的最长子串。对某个字符 `c` 来说，夹在中间的部分要最长，显然应该选它**最靠左的那次出现**和**最靠右的那次出现**——中间跨度最大。所以对每个字符，我们只需要记住两件事：它第一次出现的下标、它最后一次出现的下标。而"最后一次"可以在从左往右扫的过程中不断更新，扫完自然就是最后一次。

这一步观察把"枚举所有对"变成了"每个字符只维护两个数"，瓶颈就消掉了。

## 3. 从暴力到最优

**暴力版**（写出来对照用）：

```python
def maxLength_brute(s):
    best = -1
    for i in range(len(s)):
        for j in range(i + 1, len(s)):
            if s[i] == s[j]:
                best = max(best, j - i - 1)
    return best
```

**优化版**：从左往右扫一遍，用字典 `first` 记录每个字符第一次出现的下标。扫到位置 `i`、字符 `c` 时：

- 如果 `c` 没在 `first` 里，说明这是第一次见，记下 `first[c] = i`；
- 如果已经在里面，说明 `first[c]` 是它最早的位置，`i` 是当前（也是目前最靠右的）位置，候选长度 `i - first[c] - 1`，更新答案。

**走一遍示例 4：`s = "cabbac"`**

| i | s[i] | first 表 | 候选长度 | best |
|---|------|----------|----------|------|
| 0 | c | {c:0} | — | -1 |
| 1 | a | {c:0, a:1} | — | -1 |
| 2 | b | {c:0, a:1, b:2} | — | -1 |
| 3 | b | 已有 b，first[b]=2 | 3-2-1=0 | 0 |
| 4 | a | 已有 a，first[a]=1 | 4-1-1=2 | 2 |
| 5 | c | 已有 c，first[c]=0 | 5-0-1=4 | 4 |

返回 4，和示例一致。注意 `b` 在 i=3 时算出的 0 后来被 `a`、`c` 的更大值覆盖——这正是"每个字符取最左和最右"在起作用：`b` 的最右出现就是 3，它贡献不了更长的。

再看示例 1 `"aa"`：i=0 记 `{a:0}`；i=1 已有 a，候选 `1-0-1=0`，返回 0。空子串长度就是 0，符合题意。

示例 3 `"cbzxy"`：五个字符各出现一次，`first` 里只有插入没有命中，`best` 始终是 -1，返回 -1。

## 4. 正确性：为什么不会漏、不会重

用**不变量**说清楚。

**不变量**：扫描到下标 `i` 时，`best` 等于"所有右端点 ≤ i 的合法字符对中，`j - i' - 1` 的最大值"，其中 `i'` 是该字符在 `[0, j]` 内最早出现的位置。

**归纳**：

- 初始 `i = -1`，没有字符对，`best = -1`，成立。
- 假设扫到 `i-1` 时成立。处理 `s[i] = c`：
  - 若 `c` 首次出现，它不可能作为任何字符对的右端点（左边没有同字符），`best` 不变，不变量保持。
  - 若 `c` 已出现，`first[c]` 是 `c` 在 `[0, i-1]` 内最早的位置（字典只在首次出现时写入，之后不再改）。以 `i` 为右端点、`c` 为字符的所有字符对中，`i - first[c] - 1` 是最大的（左端点越靠左，长度越大）。把 `best` 与它取 max，就覆盖了所有以 `i` 为右端点的候选；之前右端点 < i 的候选已被旧 `best` 覆盖。不变量保持。

**不漏**：任何最优解对应某个字符 `c` 的某对出现 `(p, q)`，`p < q`。当扫描到 `q` 时，`first[c] ≤ p`，所以 `q - first[c] - 1 ≥ q - p - 1`，即我们算出的候选不小于该解。所以最优解一定被覆盖。

**不重**：每个右端点只处理一次，每次只产生一个候选，不存在重复计数的问题；取 max 也不受重复影响。

**为什么"最左 + 最右"就够**：对固定字符 `c`，长度函数 `q - p - 1` 关于 `p` 单调递减、关于 `q` 单调递增，所以最大值在 `p` 最小、`q` 最大处取得。这就是为什么不需要枚举所有对。

## 5. 完整代码（Python）

```python
class Solution:
    def maxLengthBetweenEqualCharacters(self, s: str) -> int:
        first = {}          # 字符 -> 第一次出现的下标
        best = -1           # 没有任何字符出现两次时返回 -1

        for i, ch in enumerate(s):
            if ch in first:
                # first[ch] 是该字符最早的位置，i 是当前最靠右的位置
                # 中间子串长度 = 下标差 - 1（不含两端字符）
                best = max(best, i - first[ch] - 1)
            else:
                # 第一次见到这个字符，只记录位置，不产生候选
                first[ch] = i

        return best
```

## 6. 复杂度

- **时间 O(n)**：`for` 循环跑 n 次（n = `len(s)`），每次字典查找/插入平均 O(1)，所以是 n × O(1) = O(n)。没有嵌套循环，没有排序，所以不出现 log n 项。
- **空间 O(Σ)**：字典最多存 Σ 个键，Σ 是字符集大小。本题 `s` 只含小写字母，Σ = 26，所以是 O(1) 的常数空间；一般化写 O(min(n, Σ))。这里没有递归栈、没有额外数组。

## 7. 边界与反例（至少 4 条）

1. **`s = "a"`** → 期望 `-1`。容易错：以为单字符也算"两个相同字符"，返回 0。实际上只有一个字符，凑不成一对，必须返回 -1。代码里 `first` 只插入不命中，`best` 保持 -1，正确。
2. **`s = "aa"`** → 期望 `0`。容易错：把长度算成 `j - i`（=1）而不是 `j - i - 1`。题目明确"不含这两个字符"，相邻同字符之间是空串，长度 0。
3. **`s = "abba"`** → 期望 `2`。容易错：只盯着相邻重复（`bb` 得 0）就返回，漏掉 `a...a` 夹住 `bb` 得 2。这正是"取最左最右"的意义。
4. **`s = "abcdefghij"`**（全不重复）→ 期望 `-1`。容易错：初始化 `best = 0`，导致无解时返回 0。必须初始化为 -1。
5. **`s = "abacaba"`** → 期望 `5`（两个 `a` 夹住 `bacab`）。容易错：只更新第一次命中的 `a` 就停，或者把 `first[a]` 在后续出现时覆盖掉，导致左端点右移、长度变短。代码里 `first` 只在 `else` 分支写入，命中时不改，保证左端点永远是最左。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求返回那个最长子串本身，而不只是长度？** 思路：字典里同时存首次下标，命中时用 `s[first[ch]+1 : i]` 切片取子串，和 `best` 一起更新；切片是 O(长度)，总复杂度仍是 O(n²) 最坏（但 n ≤ 300 无所谓），或者只记下标最后再切一次，O(n)。
2. **追问：如果字符集不是小写字母而是任意 Unicode，空间怎么算？** 思路：字典大小上界变成 O(min(n, Σ))，Σ 可能很大，但实际键数不超过 n，所以空间 O(n)；时间不变，哈希平均 O(1)。
3. **追问：改成"两个相同字符之间的最长子串，且子串内不能含有该字符"？** 思路：对每个字符，取它相邻两次出现之间的间隔，找最大间隔减一；等价于对每个字符记录"上一次出现位置"，命中时用 `i - last[ch] - 1` 更新，然后 `last[ch] = i`——注意这里要**覆盖**而不是保留首次，和本题正好相反，是容易混淆的变体。

## 9. 举一反三（2-3 道同类题）

1. **力扣 3. 无重复字符的最长子串**：同样用"字典记录字符最近位置 + 一次扫描"，区别是本题记首次、那题记最近且要维护左边界。
2. **力扣 1. 两数之和**：核心套路一致——用哈希表把"回头找之前出现过的元素"从 O(n) 降到 O(1)，把 O(n²) 压成 O(n)。
3. **力扣 387. 字符串中的第一个唯一字符**：同样是"一次扫描统计每个字符的出现信息"，只是统计的是次数而非位置，思路同源。
