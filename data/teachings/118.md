## 1. 一句话本质

给定行数 n，逐行构造一个「每个内部元素 = 上一行同列 + 上一行前一列」的二维数组，边界恒为 1。

## 2. 读完题的第一反应

**朴素解法**：直接按定义模拟——第 i 行有 i+1 个元素，首尾填 1，中间每个位置 `res[i][j] = res[i-1][j-1] + res[i-1][j]`。这其实就是正解，没有「卡住」的地方。

那为什么这题还值得讲？因为**大多数人第一次写会卡在两个细节上**：

1. **下标对齐**：第 i 行（0-indexed）长度是 i+1，中间元素 j 从 1 到 i-1，取的是上一行 `j-1` 和 `j`。写错一个下标就 IndexError 或结果错位。
2. **边界行的处理**：第 0 行只有一个 `[1]`，它没有「上一行」，必须单独初始化，否则循环第一轮就崩。

**关键观察**：每一行只依赖**紧邻的上一行**，不依赖更早的行。这意味着不需要二维 DP 表去回查历史，只需要手里攥着「上一行」，滚动生成下一行即可。这个观察直接决定了空间复杂度能从 O(n²) 压到 O(n)（如果只要求输出最后一行的话；但本题要求输出全部行，所以输出本身占 O(n²)，这是逃不掉的）。

换句话说：**时间上无法优于 O(n²)，因为输出就有约 n²/2 个数字；能优化的是「辅助空间」**。想清楚这一点，就不会在面试里被追问「能不能更快」时慌。

## 3. 从暴力到最优

这题的「暴力」和「最优」其实是同一条路，差别只在**辅助空间**。我用 `numRows = 5` 走一遍。

**版本 A：二维表直接填（最直白）**

```
row0 = [1]
row1 = [1, 1]              # 首尾 1，中间 = row0[0]+row0[1]? 不对，row0 只有 1 个元素
```

这里就暴露了细节：第 1 行长度 2，中间没有元素（j 从 1 到 0，空区间），所以直接是 `[1,1]`。从第 2 行开始才有真正的加法：

```
row2: 长度 3，j=1: row1[0]+row1[1] = 1+1 = 2  → [1,2,1]
row3: 长度 4，j=1: row2[0]+row2[1] = 1+2 = 3
              j=2: row2[1]+row2[2] = 2+1 = 3  → [1,3,3,1]
row4: 长度 5，j=1: 1+3=4, j=2: 3+3=6, j=3: 3+1=4 → [1,4,6,4,1]
```

中间变量就是 `prev`（上一行）和 `cur`（当前行），每轮结束 `prev = cur`。辅助空间峰值是「上一行 + 当前行」≈ 2n，即 O(n)。

**版本 B：原地在结果列表上追加（本题最常用写法）**

既然结果要返回全部行，就直接往 `res` 里 append，用 `res[-1]` 当上一行：

```
res = [[1]]
i=1: prev=[1], cur=[1] + [prev[j-1]+prev[j] for j in 1..0] + [1] = [1,1]
i=2: prev=[1,1], cur=[1] + [1+1] + [1] = [1,2,1]
i=3: prev=[1,2,1], cur=[1] + [1+2, 2+1] + [1] = [1,3,3,1]
i=4: prev=[1,3,3,1], cur=[1] + [1+3,3+3,3+1] + [1] = [1,4,6,4,1]
```

瓶颈在哪？**没有瓶颈可消**——每个输出元素恰好被计算一次，加法次数 = 输出元素总数 ≈ n²/2，这是信息量下界。所谓「从暴力到最优」在这题里体现为：**别去用递归重复计算**（有人会写 `C(n,k)` 递归求组合数，那是 O(n²) 甚至更差且带大量重复子问题），直接用滚动数组一趟扫完。

## 4. 正确性：为什么不会漏、不会重

用**循环不变量**说清楚。

**不变量**：在第 i 轮循环开始时，`res` 中恰好存放了杨辉三角的前 i 行（即 `res[0..i-1]`），且每一行都满足定义。

- **初始化**：i=1 时，`res = [[1]]`，恰好是前 1 行，成立。
- **保持**：第 i 轮构造 `cur`：首元素 `1`、尾元素 `1`、中间第 j 个为 `res[i-1][j-1] + res[i-1][j]`。由不变量，`res[i-1]` 是合法的第 i-1 行，故 `cur` 的每个内部元素都等于「左上方 + 右上方」，符合定义；长度 i+1 也符合。append 后 `res` 含前 i+1 行，不变量保持。
- **终止**：循环执行 numRows-1 轮后，`res` 含前 numRows 行，正是所求。

**不漏**：每个位置 j ∈ [1, i-1] 都被列表推导枚举一次，首尾单独补 1，覆盖了整行 i+1 个位置。
**不重**：每个 `cur[j]` 只被赋值一次，且只读取 `res[i-1]` 的两个不同下标，不存在同一元素被多次写入。

## 5. 完整代码（Python）

```python
class Solution:
    def generate(self, numRows: int) -> list[list[int]]:
        # 第 0 行恒为 [1]，同时作为 numRows == 1 的答案
        res = [[1]]

        # 从第 1 行开始逐行构造，共构造 numRows - 1 行
        for i in range(1, numRows):
            prev = res[-1]                      # 上一行，长度 i
            # 中间元素：上一行相邻两数之和，共 i-1 个
            mid = [prev[j - 1] + prev[j] for j in range(1, i)]
            # 首尾补 1，拼成完整的一行（长度 i+1）
            res.append([1] + mid + [1])

        return res
```

几个值得在课上点出来的写法细节：

- `range(1, i)` 在 i=1 时是空区间，`mid = []`，于是第 1 行是 `[1] + [] + [1] = [1,1]`，**不需要为第 1 行写特判**。这是这段代码最优雅的地方。
- `prev[j-1] + prev[j]` 中 j 最大取 i-1，`prev` 长度是 i，下标 i-1 合法，不会越界。
- 用 `res[-1]` 而不是额外维护 `prev` 变量，少一个状态，也少一处可能写错的地方。

## 6. 复杂度

**时间 O(n²)**，其中 n = numRows。第 i 行做 i-1 次加法，总加法次数 = Σ(i-1) for i=1..n = n(n-1)/2 = O(n²)。这里没有 log 因子——没有分治、没有二分、没有堆操作，纯线性扫描的嵌套。**n 来自行数，平方来自「第 i 行有 i 个元素」这个三角结构**。

**空间 O(n²)**，但要说清是谁贡献的：
- **输出本身**：共 n(n+1)/2 个整数，O(n²)，这部分是题目要求返回的，不算「额外」。
- **辅助空间 O(n)**：`prev` 引用 + `mid` 列表，峰值长度 n。若面试官问「额外空间」，答 O(n)；若问「总空间」，答 O(n²)。

对比一下：如果题目改成「只返回第 n 行」，辅助空间可以做到 O(n) 且输出也是 O(n)，那时 O(n) 就是真正的总复杂度。本题因为要全部行，O(n²) 是下界。

## 7. 边界与反例（至少 4 条）

1. **numRows = 1** → `[[1]]`。容易错在：把初始化写成 `res = []` 然后循环从 0 开始，导致第 0 行被当成「有上一行」去取 `res[-1]`，空列表取 `[-1]` 直接 IndexError。
2. **numRows = 2** → `[[1],[1,1]]`。容易错在：列表推导写成 `range(1, i+1)`，i=1 时取 `prev[0]+prev[1]`，而 `prev` 只有 1 个元素，越界。
3. **numRows = 30（上界）** → 最后一行是 `[1,29,406,...,29,1]`。容易错在：以为会溢出。Python 大整数无所谓，但若用 C++/Java 的 int，第 30 行中间值 C(29,14) ≈ 7.7×10⁷，仍在 int 范围内；不过面试若被要求换语言，要主动提一句「这里 int 够用，但更大 n 需要 long 或大数」。
4. **numRows = 0**（题面约束是 ≥1，但面试官常故意问）→ 期望 `[]`。当前代码会返回 `[[1]]`，**是错的**。正确做法是在开头加 `if numRows == 0: return []`。这条最能体现「你有没有读约束、有没有防御性思维」。
5. **下标错位反例**：把 `prev[j-1] + prev[j]` 写成 `prev[j] + prev[j+1]`，numRows=3 时第 2 行会算出 `[1, 2, 1]` 看似对，但 numRows=4 时第 3 行 j=2 取 `prev[2]+prev[3]`，`prev` 长度 3，越界。**小样例能过、大样例崩**，是这类下标错误最阴险的地方。

## 8. 面试追问与变体（3 条）

1. **追问：只返回第 n 行，空间能否 O(n)？**
   思路：用长度为 n+1 的数组原地从右往左更新 `a[j] += a[j-1]`，避免覆盖还要用的旧值；或直接用组合数 `C(n,k) = C(n,k-1) * (n-k+1) / k` 递推，O(n) 时间 O(1) 辅助空间。

2. **追问：返回第 n 行第 k 个数（1-indexed），要求 O(k) 时间？**
   思路：直接算组合数 `C(n-1, k-1)`，用乘除交替递推避免阶乘溢出，注意先乘后除保证整除。

3. **追问：如果把「左上 + 右上」改成「左上 + 右上 + 正上」，即三项和，怎么改？**
   思路：`cur[j] = prev[j-1] + prev[j] + prev[j+1]`，边界处理要小心（首尾外侧视为 0），本质是「帕斯卡三角的广义卷积」，代码结构不变，只是每项多读一个下标。

## 9. 举一反三（2-3 道同类题）

- **119. 杨辉三角 II**：只求第 n 行，共同点是同一递推关系，但逼你把空间从 O(n²) 压到 O(n)，是本题的「空间优化版」。
- **70. 爬楼梯**：共同点是「当前状态只依赖前一个（或前两个）状态」，都是滚动数组 / 一维 DP 的入门形态，`dp[i] = dp[i-1] + dp[i-2]` 与本题的相邻求和同构。
- **120. 三角形最小路径和**：共同点是三角结构的逐行 DP，区别在于本题是「生成」、那题是「在生成的结构上求最优」，能帮你把「三角 DP 的遍历方向」练熟。
