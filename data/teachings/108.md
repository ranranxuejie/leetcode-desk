## 1. 一句话本质

给定一个**已排好序**的数组，选一个"中间"元素当根，把左右两半分别递归地建成左右子树，从而让树既满足 BST 有序性、又满足高度平衡。

## 2. 读完题的第一反应

**朴素解法**：随便构造一棵 BST。比如按数组顺序依次插入，或者每次取第一个元素当根。问题在于——数组是升序的，按顺序插入会退化成一条**右斜链**（高度 n），完全不是平衡树。要"平衡"，就必须让左右子树的节点数尽量相等。

**关键观察**：BST 有一个铁律——**中序遍历结果就是升序序列**。反过来，题目给的数组本身就是升序的，那它天然就是某棵 BST 的中序遍历。于是问题变成：给定中序序列，反推一棵**平衡**的 BST。

中序序列里，**根节点一定在中间位置**：它左边的所有元素都比它小（进左子树），右边的都比它大（进右子树）。要让树平衡，就取正中间的元素当根，左右两半长度最多差 1，递归下去每层都平衡。这一步观察直接锁定了"取中点"这个动作，剩下的就是递归。

## 3. 从暴力到最优

**暴力**：枚举所有可能的根，对每种选择递归建树，再检查是否平衡，取一个合法的。这是指数级，且完全没必要——因为"取中点"已经能保证平衡，不需要搜索。

**从暴力到最优的消瓶颈过程**，用 `nums = [-10,-3,0,5,9]` 走一遍：

- 区间 `[0,4]`，中点 `mid = (0+4)//2 = 2`，`nums[2] = 0` 当根。
  - 左区间 `[0,1]`：`mid = 0`，`nums[0] = -10` 当左子树的根。
    - 它的左区间 `[0,-1]` 为空 → 左孩子 None。
    - 右区间 `[1,1]`：`mid = 1`，`nums[1] = -3` 当 `-10` 的右孩子。
  - 右区间 `[3,4]`：`mid = 3`，`nums[3] = 5` 当右子树的根。
    - 左区间 `[3,2]` 为空 → None。
    - 右区间 `[4,4]`：`mid = 4`，`nums[4] = 9` 当 `5` 的右孩子。

得到的树：根 0，左 -10（右孩子 -3），右 5（右孩子 9）。层序输出 `[0,-10,5,null,-3,null,9]`，正是示例里被认可的答案之一。

**瓶颈怎么被消掉的**：暴力要"搜索根的位置"，而中序性质告诉我们根的位置**由区间中点唯一确定**，不需要搜索。每个元素恰好被访问一次，复杂度从指数降到 O(n)。

## 4. 正确性：为什么不会漏、不会重

用**不变量**来论证。对任意递归调用 `build(lo, hi)`，维护两个不变量：

1. **BST 不变量**：`build(lo, hi)` 返回的树中，所有节点值都落在 `nums[lo..hi]` 内，且中序遍历恰好是 `nums[lo..hi]`。归纳证明：取 `mid` 为根，左子树来自 `nums[lo..mid-1]`（全部 < `nums[mid]`），右子树来自 `nums[mid+1..hi]`（全部 > `nums[mid]`），左右子树各自满足不变量（归纳假设），拼起来中序就是 `nums[lo..mid]` 再接 `nums[mid+1..hi]`，即整个区间。**不会漏**：区间被 `mid` 切成三段，每段都被处理。**不会重**：三段互不相交，每个下标只属于一个区间。

2. **平衡不变量**：`build(lo, hi)` 返回的树高度 ≤ ⌈log₂(hi-lo+1)⌉ + 1。因为左右子树大小分别为 `mid-lo` 和 `hi-mid`，两者差不超过 1（`mid` 取中点），由归纳假设左右高度差不超过 1，整棵树平衡。

两个不变量合起来，说明算法输出的树**既是有序 BST、又是平衡的**，且覆盖了全部元素、没有重复使用任何元素。

## 5. 完整代码（Python）

```python
from typing import List, Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        # 闭区间 [lo, hi] 表示当前要建树的元素范围
        def build(lo: int, hi: int) -> Optional[TreeNode]:
            # 空区间：没有元素，返回空树
            if lo > hi:
                return None
            # 取中点作为根，保证左右两半长度差不超过 1 → 平衡
            mid = (lo + hi) // 2
            root = TreeNode(nums[mid])
            # 左半区间递归建左子树（全部小于 nums[mid]）
            root.left = build(lo, mid - 1)
            # 右半区间递归建右子树（全部大于 nums[mid]）
            root.right = build(mid + 1, hi)
            return root

        return build(0, len(nums) - 1)
```

关键点：用 `lo, hi` 两个下标传区间，而不是每次切片 `nums[lo:hi]`。切片会复制数组，把每层开销从 O(1) 变成 O(区间长度)，总复杂度会退化到 O(n log n) 甚至更差。传下标是这道题一个容易忽略的细节。

## 6. 复杂度

**时间 O(n)**：`build` 对每个下标恰好调用一次（区间不重叠），每次调用内部只做常数工作（取中点、建节点、两次递归调用）。n 个元素 → n 次调用 → O(n)。注意这里**没有** log n 因子，因为递归树虽然有 log n 层，但每层的区间总长度加起来是 n，不是每层都 O(n)。

**空间 O(log n)**（不计输出树本身）：递归栈深度等于树高，而树是平衡的，高度为 ⌈log₂ n⌉，所以栈空间 O(log n)。如果算上返回的树，节点数 n，那是 O(n)，但这属于输出，通常不计入辅助空间。`mid`、`lo`、`hi` 都是常数级局部变量。

## 7. 边界与反例（至少 4 条）

1. **输入 `[1]`** → 输出 `[1]`。容易错：忘记处理 `lo == hi` 时 `mid = lo`，左右递归都传空区间，要确保 `lo > hi` 返回 None，否则死递归或越界。

2. **输入 `[1,3]`** → 输出 `[3,1]` 或 `[1,null,3]` 都合法。容易错：以为答案唯一。题目明确说多种答案都接受，别去纠结"必须和示例一模一样"。`mid = (0+1)//2 = 0` 取到 1 当根，也是合法平衡树。

3. **输入 `[-10,-3,0,5,9]`** → 输出 `[0,-3,9,-10,null,5]` 或 `[0,-10,5,null,-3,null,9]` 等。容易错：用 `mid = (lo+hi+1)//2` 取上中点，结果也合法，但和示例不同——这不叫错，只要平衡且有序即可。

4. **输入 `[1,2,3,4,5,6,7]`** → 应得到高度 3 的完全平衡树，根为 4。容易错：如果误用"取第一个元素当根"的贪心，会退化成右斜链，高度 7，违反平衡要求。

5. **输入长度 10^4 的递增数组** → 递归深度约 log₂(10^4) ≈ 14，安全。容易错：如果误写成按顺序插入建树，递归/迭代深度会到 10^4，Python 默认递归上限 1000 会直接 `RecursionError`。

## 8. 面试追问与变体（3 条）

1. **追问：如果数组不是严格递增、有重复元素怎么办？** 思路：BST 通常要求严格有序；若有重复，需明确重复值放左还是放右（比如"小于等于放左"），取中点逻辑不变，但要保证切分时重复值不被分到两边导致中序不唯一。

2. **追问：不用递归，用迭代怎么写？** 思路：用显式栈模拟递归，栈里存 `(lo, hi, parent, is_left)`，弹出时建节点并挂到 parent 上，再把左右子区间压栈。本质是把递归栈手动化。

3. **追问：如果要求返回"高度最小的那棵" BST（唯一解）？** 思路：取中点已经保证高度最小（⌈log₂(n+1)⌉），但中点的选择（下取整 vs 上取整）会产生不同形状；若要唯一，需额外规定取法，比如固定下取整。

3. **LeetCode 1382. 将二叉搜索树变平衡**：共同点是"平衡 BST"的目标，区别是输入是一棵可能不平衡的 BST，需要先中序遍历拿到有序数组，再套用本题的建树逻辑——本题正好是它的子过程。
