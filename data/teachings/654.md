## 1. 一句话本质

对数组做「以区间最大值为根」的递归切分，把每次切分产生的父子关系固化成二叉树。

## 2. 读完题的第一反应

题面已经把算法写死了：找最大值当根，左边递归建左子树，右边递归建右子树。所以**朴素解法**就是照抄这段话——每次在当前区间里线性扫一遍找最大值，然后对左右两段递归。

它卡在哪？找最大值是 O(区间长度)，而递归树在最坏情况下（数组单调递减或单调递增）会退化成一条链，每层区间长度只减少 1，总代价是 n + (n-1) + ... + 1 = O(n²)。n ≤ 1000 时这也能过，但面试官问这道题，显然不是想看你写 O(n²)。

**关键观察**：每个元素最终只会被「找最大值」这个过程访问一次就够了吗？不是——朴素解法里一个元素会被反复扫描。真正的问题是：我们能不能在**一次从左到右的扫描**中，就确定每个元素挂在谁下面？

答案是能。因为「谁是区间最大值」这件事，本质上是**最近的大于关系**：对某个元素 x，它左边第一个比它大的元素 L 和右边第一个比它大的元素 R，决定了 x 的父节点是 L 和 R 中较小的那个。这个「第一个更大」的结构，正是单调栈擅长处理的。看到「找左右第一个更大/更小」就该条件反射想到单调栈。

## 3. 从暴力到最优

**第一步：朴素递归（分治）**

以 `nums = [3,2,1,6,0,5]` 为例：

- 区间 [0,5]，最大值 6（下标 3）→ 根 6，左区间 [0,2]，右区间 [4,5]
- 左区间 [0,2] 最大值 3（下标 0）→ 3 是 6 的左孩子，右区间 [1,2]
- [1,2] 最大值 2 → 2 是 3 的右孩子，右区间 [2,2]
- [2,2] 最大值 1 → 1 是 2 的右孩子
- 右区间 [4,5] 最大值 5 → 5 是 6 的右孩子，左区间 [4,4]
- [4,4] 最大值 0 → 0 是 5 的左孩子

瓶颈：每层都要重新扫区间找最大值，链状退化时 O(n²)。

**第二步：单调栈，一次扫描**

维护一个**单调递减栈**（栈底到栈顶严格递减），栈里存的是「还没找到父节点的候选节点」。扫描到 nums[i] 时：

- 只要栈顶的值比 nums[i] 小，说明栈顶元素的「右边第一个更大值」就是 nums[i]，弹出它，并把它挂到 nums[i] 的**左孩子**上（因为它比 nums[i] 小，且出现在 nums[i] 左边）。
- 弹出结束后，如果栈非空，栈顶就是 nums[i] 的「左边第一个更大值」，把 nums[i] 挂到栈顶的**右孩子**上。
- nums[i] 入栈。

走一遍 `[3,2,1,6,0,5]`，用 `stack` 表示栈内节点值（从底到顶）：

| i | nums[i] | 操作 | stack（底→顶） |
|---|---|---|---|
| 0 | 3 | 入栈 | [3] |
| 1 | 2 | 2<3，不弹；2 挂到 3 的右孩子 | [3,2] |
| 2 | 1 | 1<2，不弹；1 挂到 2 的右孩子 | [3,2,1] |
| 3 | 6 | 弹 1（1 挂 6 左）、弹 2（2 挂 6 左）、弹 3（3 挂 6 左）；栈空，6 入栈 | [6] |
| 4 | 0 | 0<6，不弹；0 挂到 6 的右孩子 | [6,0] |
| 5 | 5 | 弹 0（0 挂 5 左）；5<6 不弹；5 挂到 6 的右孩子 | [6,5] |

注意第 3 步：连续弹出 1、2、3 时，每次都是「把弹出的节点挂到当前 nums[i] 的左孩子」。但 1 已经被挂到 2 的右孩子了，再挂到 6 的左孩子会覆盖吗？不会——因为 2 是 1 的父节点，6 是 2 的父节点，覆盖的是**不同节点**的 left 指针。实际上弹出顺序是 1、2、3，最后一次弹出 3 时把 3 挂到 6 的 left，而 2 是 3 的 right、1 是 2 的 right，链条完整保留。代码里「每次弹出都赋值给 cur.left」之所以正确，是因为后弹出的节点会成为先弹出节点的祖先，赋值顺序恰好让最终 cur.left 指向「被弹出序列里最大的那个」，也就是原区间的最大值。

最终树：6 的左孩子 3，3 的右孩子 2，2 的右孩子 1；6 的右孩子 5，5 的左孩子 0。和示例输出 `[6,3,5,null,2,0,null,null,1]` 一致。

瓶颈消掉了：每个元素最多入栈一次、出栈一次，总操作 O(n)。

## 4. 正确性：为什么不会漏、不会重

用**不变量**论证。扫描到下标 i 时，维护不变量：

> 栈中元素是「当前已处理前缀中，尚未确定父节点的节点」，且从栈底到栈顶值严格递减；栈中相邻元素在最终树里构成祖先-后代关系（栈底是栈顶的祖先）。

三条性质保证正确：

1. **不漏**：每个节点入栈时，要么栈空（它是当前前缀最大值，暂时无父），要么挂到栈顶的右孩子。出栈时挂到当前元素的左孩子。每个非根节点恰好被赋值一次父指针——入栈时挂右孩子，或出栈时挂左孩子，二者必居其一（根节点是全局最大值，永不作为别人的孩子）。
2. **不重**：一个节点一旦出栈就不再参与后续，不会二次赋值。入栈时若挂了右孩子，之后它出栈时挂的是左孩子，两个指针互不冲突。
3. **父子关系正确**：对元素 x，设 L 是它左边第一个更大值，R 是它右边第一个更大值。x 的父节点必是 L、R 中较小者（因为父节点是包含 x 的区间的最大值，区间边界由更大的元素卡住）。单调栈在 x 入栈时给出 L（栈顶），在 x 出栈时给出 R（当前元素），且「较小者」恰好对应「先触发的那一侧」——若 R < L，x 会先被 R 弹出并挂到 R 左边；若 L < R，x 会一直留在栈里直到 R 出现，此时它作为栈顶被弹出挂到 R 左边，而它入栈时已挂到 L 右边。两种情形都符合「父节点是较小者」。

## 5. 完整代码（Python）

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def constructMaximumBinaryTree(self, nums):
        # 单调递减栈：栈底到栈顶值严格递减
        stack = []
        for x in nums:
            node = TreeNode(x)
            # 当前 x 是栈顶元素的「右边第一个更大值」
            # 栈顶比 x 小，说明栈顶的父节点在 x 这一侧，挂到 x 左边
            while stack and stack[-1].val < x:
                node.left = stack.pop()
            # 弹出结束后，栈顶是 x 的「左边第一个更大值」，x 挂到它右边
            if stack:
                stack[-1].right = node
            stack.append(node)
        # 栈底元素是全局最大值，即根
        return stack[0]
```

关键点：`node.left = stack.pop()` 在循环里反复执行，最后一次赋值留下的是「被弹出序列中最大的节点」，它才是 x 左子树的根；前面被覆盖的赋值对象早已作为那个最大节点的后代被接好了。

## 6. 复杂度

- **时间 O(n)**：外层 for 循环 n 次；内层 while 每次弹出一个元素，而每个元素最多入栈一次，所以 while 总执行次数 ≤ n。合计 O(n)。这里没有 log n 的来源——单调栈是线性结构，不是分治。
- **空间 O(n)**：栈最多存 n 个节点（数组严格递减时全部入栈）；返回的树本身占 n 个节点，但那是输出，不计入辅助空间。辅助空间就是栈的 O(n)。

对比朴素分治：时间 O(n²)（链状退化）或 O(n log n)（用 RMQ 预处理后每次 O(1) 查最大值，但预处理本身 O(n log n)），空间 O(n) 递归栈。

## 7. 边界与反例（至少 4 条）

1. **输入 `[1]`** → 输出单节点 `[1]`。容易错：忘记处理栈最终只剩一个元素时它就是根，代码里 `return stack[0]` 依赖栈非空，n≥1 由题面保证，但若自己加防御要小心。
2. **输入 `[3,2,1]`（严格递减）** → 输出 `[3,null,2,null,1]`，一条右斜链。容易错：误以为递减数组会建出平衡树；实际每个元素都挂到前一个的右孩子，栈深度达到 n。
3. **输入 `[1,2,3]`（严格递增）** → 输出 `[3,1,null,null,2]` 形态的左斜链（3 为根，1 是 3 的左孩子，2 是 1 的右孩子……具体形态需按代码推）。容易错：递增时每次新元素都把栈弹空，`node.left` 被反复覆盖，若写成「只弹一次」就会丢节点。
4. **输入 `[5,4,3,2,1,6]`** → 6 出现时一次性弹出 5 个节点，6 的左孩子应是 5（原栈底），而不是最后弹出的 1。容易错：把 `node.left = stack.pop()` 写在 while 外面只执行一次，或者弹出后忘记保留「最后弹出的那个」作为左孩子——代码里靠循环内反复赋值天然解决。
5. **输入含 0，如 `[0,5]`** → 0 是 5 的左孩子。容易错：用 `if stack[-1].val` 判断真值，0 被当成假值跳过。

## 8. 面试追问与变体（3 条）

1. **追问：不用栈，用递归 + 线段树/RMQ 查区间最大值，复杂度多少？** 思路：预处理 O(n log n) 或 O(n)，每次查最大值 O(1) 或 O(log n)，递归建树 O(n) 次查询，总 O(n log n) 或 O(n)，但常数和代码量都大于单调栈。
2. **追问：如果数组有重复元素，算法还成立吗？** 思路：题面保证互不相同；有重复时「第一个更大」需改成「第一个大于等于」，且父子关系可能不唯一，需要重新定义规则。
3. **追问：如何只返回根节点而不建整棵树？** 思路：单调栈过程中栈底元素始终是当前前缀最大值，扫描结束后栈底就是根，无需额外遍历。
