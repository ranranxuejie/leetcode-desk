## 1. 一句话本质

在一条**首尾相连**的环形数组上，选出若干个**互不相邻**的位置，使它们的和最大。

## 2. 读完题的第一反应

先不管"环形"这个约束。如果房子是排成一排的，这就是最经典的线性打家劫舍：对第 `i` 间房，要么偷它（则第 `i-1` 间不能偷），要么不偷它（则直接继承前 `i-1` 间的最优解）。设 `dp[i]` 为前 `i` 间房能偷到的最大金额，转移是

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```

这个朴素 DP 是 O(n) 时间、O(n) 空间，本身没有瓶颈。**真正的卡点在于"环形"**：第 0 间和第 n-1 间相邻，于是"偷不偷第 0 间"会影响"能不能偷第 n-1 间"，一个线性的 `dp` 数组没法同时记住这个跨首尾的依赖。

关键观察是：**首尾相邻这个约束，只可能以两种方式被违反——要么同时偷了第 0 间和第 n-1 间。** 反过来想，任何合法方案必然满足以下至少一条：

- 没偷第 0 间（那么第 n-1 间偷不偷都无所谓，问题退化成 `nums[1:]` 上的线性问题）；
- 没偷第 n-1 间（同理，退化成 `nums[:-1]` 上的线性问题）。

这两个集合的并集覆盖了所有合法方案，于是答案就是这两个线性子问题的较大者。**把"环"拆成"两条链"，环形约束就被消掉了**——这就是这道题的全部思想。

## 3. 从暴力到最优

**第一步：暴力枚举。** 环形数组上每个位置选/不选，共 2^n 种组合，逐一检查"无相邻"并取最大和。n=100 时 2^100 完全不可行。瓶颈是"组合爆炸"，因为暴力没有利用"相邻约束只作用于局部"这个结构。

**第二步：线性 DP。** 先解决 `nums[0..n-1]` 排成一排的版本。以 `nums = [2,3,2]` 为例，手动走一遍：

| i | nums[i] | dp[i-2]+nums[i] | dp[i-1] | dp[i] |
|---|---|---|---|---|
| 0 | 2 | — | — | 2 |
| 1 | 3 | — | 2 | 3 |
| 2 | 2 | 2+2=4 | 3 | 4 |

线性版本答案是 4（偷第 0、2 间）。但环形下这是**非法**的，因为第 0 和第 2 间相邻。这说明线性 DP 直接套用会给出错误答案，必须处理首尾。

**第三步：拆环。** 对 `[2,3,2]`：

- 情况 A，不偷第 0 间：在 `[3,2]` 上跑线性 DP → `dp = [3, 3]`，答案 3。
- 情况 B，不偷最后一间：在 `[2,3]` 上跑线性 DP → `dp = [2, 3]`，答案 3。

取 max(3, 3) = 3，与示例 1 一致。注意情况 A 和情况 B 都**没有**把"偷 0 又偷 2"算进去，非法方案被自然排除了。

**第四步：空间优化。** 线性 DP 的转移只依赖 `dp[i-1]` 和 `dp[i-2]` 两个值，不需要整个数组。用两个滚动变量 `prev2`（即 dp[i-2]）和 `prev1`（即 dp[i-1]）即可，空间从 O(n) 降到 O(1)。对 `[3,2]` 走一遍：

- 初始 `prev2=0, prev1=0`
- 处理 3：`cur = max(prev1, prev2+3) = max(0,3)=3`；`prev2=0, prev1=3`
- 处理 2：`cur = max(3, 0+2)=3`；`prev2=3, prev1=3`
- 返回 `prev1=3` ✓

## 4. 正确性：为什么不会漏、不会重

用**不变量**论证。设 `OPT` 为环形问题的最优解（一个下标集合，内部无相邻，且不含 {0, n-1} 这一对）。

**引理（覆盖性）**：任意合法解 S 必满足 `0 ∉ S` 或 `n-1 ∉ S`。因为若两者都在 S 中，它们相邻，S 非法。所以 S 属于"不含 0"或"不含 n-1"至少一个集合。

**引理（子问题等价）**：若 S 不含 0，则 S 是 `nums[1:]` 上的合法解；反之 `nums[1:]` 上任意合法解加上原下标偏移，也是原问题的合法解（因为去掉了 0 之后，剩下的下标 1..n-1 在环上不再首尾相接，相邻关系与线性数组完全一致）。对"不含 n-1"同理。

于是 `OPT = max(OPT(nums[1:]), OPT(nums[:-1]))`：一方面 `OPT` 落在某个子问题里，故 `OPT ≤ 右边`；另一方面两个子问题的解都是原问题的合法解，故 `右边 ≤ OPT`。两边夹逼，等式成立。

**不会重**：两个子问题有交集（既不含 0 也不含 n-1 的解），但取 max 时重复计算不影响结果——我们求的是最大值，不是计数。

**线性 DP 本身的不变量**：处理完前 i 间房后，`prev1` 等于"前 i 间房、且第 i-1 间状态自由时的最优值"，`prev2` 等于"前 i-1 间的最优值"。转移 `max(prev1, prev2+nums[i])` 恰好对应"不偷第 i 间"与"偷第 i 间"两个互斥且完备的分支，归纳可证。

## 5. 完整代码（Python）

```python
class Solution:
    def rob(self, nums) -> int:
        n = len(nums)
        # 只有一间房时，环形的首尾是同一个元素，直接返回
        if n == 1:
            return nums[0]

        def rob_linear(arr) -> int:
            """在一排房子上打家劫舍，滚动变量版 O(1) 空间"""
            prev2 = 0  # dp[i-2]
            prev1 = 0  # dp[i-1]
            for x in arr:
                # 偷当前房：prev2 + x；不偷：prev1
                cur = max(prev1, prev2 + x)
                prev2, prev1 = prev1, cur
            return prev1

        # 情况 A：不偷第 0 间 -> 在 nums[1:] 上求
        # 情况 B：不偷最后一间 -> 在 nums[:-1] 上求
        # 两者取大，覆盖所有合法方案
        return max(rob_linear(nums[1:]), rob_linear(nums[:-1]))
```

## 6. 复杂度

- **时间 O(n)**：`rob_linear` 对长度为 m 的数组做一次单层循环，每次 O(1) 转移，贡献 O(m)。两次调用分别处理长度 n-1 的数组，总代价 O(n-1) + O(n-1) = O(n)。没有排序、没有二分，所以不出现 log n。
- **空间 O(1)**：`rob_linear` 只用 `prev2 / prev1 / cur` 三个变量，与 n 无关。切片 `nums[1:]`、`nums[:-1]` 在 Python 中会各复制一份 O(n) 的列表，若严格计空间则是 O(n)；面试中可主动说明"若不允许切片复制，可改为传下标区间 `rob_linear(lo, hi)`，空间即为 O(1)"。

## 7. 边界与反例（至少 4 条）

1. `nums = [5]` → 期望 `5` → 容易错：若不加 `n==1` 特判，`nums[1:]` 和 `nums[:-1]` 都是空数组，两个 `rob_linear` 都返回 0，答案错成 0。
2. `nums = [2,3,2]` → 期望 `3` → 容易错：直接对原数组跑线性 DP 会得到 4（偷首尾），忽略环形相邻。
3. `nums = [1,2,3,1]` → 期望 `4` → 容易错：误以为"环形必须少偷一间"，实际最优解 1+3 恰好避开了首尾，两个子问题都能覆盖。
4. `nums = [0,0,0]` → 期望 `0` → 容易错：金额非负，全 0 时答案应为 0；若把初始 `prev1` 设成负数或误用 `-inf` 初始化会出错。
5. `nums = [1,3,1,3,100]` → 期望 `103`（偷 3 和 100？验证：下标 1、4 不相邻？环上 4 与 0 相邻，1 与 4 不相邻，合法，1+3+100 中 1 与 3 相邻不行；实际最优为下标 1、4 → 3+100=103）→ 容易错：只考虑"不偷 0"分支会漏掉某些组合，必须两个分支都算再取 max。

## 8. 面试追问与变体（3 条）

1. **追问：如果房子排成树形（每个节点一间房，父子相邻），怎么求？** 思路：树形 DP，`dp[u][0/1]` 表示 u 选/不选时子树最优，后序遍历合并。
2. **追问：如果环形上允许偷相邻但要求"恰好偷 k 间"，怎么改？** 思路：DP 增加一维"已偷数量"，`dp[i][j][0/1]`，最后对首尾状态做环形修正。
3. **追问：如果要求输出具体偷了哪几间，而不只是金额？** 思路：DP 时记录每个状态的决策来源（predecessor），最后从末尾回溯；环形版本需分别回溯两个子问题再比较。
