## 1. 一句话本质

对每个节点，求「它的左子树最大深度 + 右子树最大深度」的最大值——即枚举所有节点作为路径的「最高点」，取其中能拼出的最长边数。

## 2. 读完题的第一反应

**朴素解法**：枚举所有节点对 (u, v)，求它们之间的距离，取最大。求两点距离需要先找 LCA 再算深度，单次 O(n)，总 O(n²) 甚至 O(n³)。卡在：节点对是 O(n²) 量级，而每次求距离又要遍历，完全不可行。

**关键观察**：任意一条路径，一定存在唯一一个「最高点」——即路径上深度最小的那个节点（离根最近）。这条路径在最高点处「拐弯」：从最高点向下走左子树一段、向下走右子树一段（也可能只走一边，那就是一条竖直链）。于是：

> 直径 = max over 所有节点 x 的 ( depth(x.left) + depth(x.right) )

其中 depth 指「从该子节点往下能走的最长边数」。这个观察把「枚举节点对」降维成「枚举拐点」，因为拐点只有 n 个。而每个拐点需要的信息（左右子树深度）恰好是后序遍历能自底向上一次算出来的。

## 3. 从暴力到最优

**暴力**：对每个节点 x 当拐点，分别递归求左子树深度、右子树深度，再取和。求一次深度 O(子树大小)，对 n 个节点各求一次，最坏（链状树）是 O(n²)。

**瓶颈在哪**：同一个子树的深度被反复计算。比如链状树里，根求深度要走到叶子，根的左孩子求深度又要再走一遍。

**消瓶颈**：后序遍历（DFS）时，函数返回「以当前节点为根的子树最大深度」，同时在返回前顺手用「左深度 + 右深度」更新全局答案。每个节点只被访问一次，深度信息自底向上传递，不再重复计算。

**小例子走一遍**：`root = [1,2,3,4,5]`，结构是 1 的左孩子 2、右孩子 3；2 的左孩子 4、右孩子 5。

后序 DFS，设全局 `ans = 0`：

- 到节点 4（叶子）：左深 0、右深 0，`ans = max(0, 0+0) = 0`，返回 `1 + max(0,0) = 1`。
- 到节点 5（叶子）：同理 `ans = 0`，返回 1。
- 回到节点 2：左深 = 1（来自 4），右深 = 1（来自 5），`ans = max(0, 1+1) = 2`，返回 `1 + max(1,1) = 2`。
- 到节点 3（叶子）：`ans = max(2, 0) = 2`，返回 1。
- 回到节点 1：左深 = 2（来自 2），右深 = 1（来自 3），`ans = max(2, 2+1) = 3`，返回 `1 + max(2,1) = 3`。

最终 `ans = 3`，与示例一致。注意节点 2 处算出 2（路径 4-2-5），节点 1 处算出 3（路径 4-2-1-3），全局取最大。

## 4. 正确性：为什么不会漏、不会重

**不变量**：DFS 处理完以 x 为根的子树后，`ans` 已经等于「该子树内部所有路径长度的最大值」，且函数返回「x 到其子树中最远叶子的边数」（即子树深度）。

**归纳证明**：

- 叶子：子树内无路径，`ans` 不变（初值 0 正确），返回深度 0+1=1，不变量成立。
- 内部节点 x：设左子树返回 `L`、右子树返回 `R`。任何经过 x 的路径，必然是「左子树某点到 x」+「x 到右子树某点」，最长就是 `L + R`（边数）。任何不经过 x 的路径完全落在左子树或右子树内，已由归纳假设被 `ans` 覆盖。所以 `ans = max(旧 ans, L+R)` 恰好覆盖「经过 x」这一类，不漏。返回 `1 + max(L,R)` 是 x 到最远叶子的边数，也正确。

**不重**：每条路径有唯一的最高点 x，只在处理 x 时被计入一次 `L+R`，不会在别的节点重复计入。

**边界情形**：路径只走一边（竖直链）时，`L+R` 中有一项为 0，仍被正确计入；单节点树 `L=R=0`，`ans=0`，符合「边数」定义。

## 5. 完整代码（Python）

```python
class Solution:
    def diameterOfBinaryTree(self, root) -> int:
        self.ans = 0  # 全局答案：目前见过的最大直径（边数）

        def depth(node) -> int:
            # 返回：以 node 为根的子树的最大深度（到最远叶子的边数）
            if node is None:
                return 0  # 空树深度为 0，边数为 0
            left = depth(node.left)    # 左子树深度
            right = depth(node.right)  # 右子树深度
            # 以 node 为「最高点」的路径长度 = 左深 + 右深
            self.ans = max(self.ans, left + right)
            # 向上返回本子树深度：自己到最远叶子
            return 1 + max(left, right)

        depth(root)
        return self.ans
```

关键点：`self.ans` 用实例属性而非闭包变量，避免 Python 里 `nonlocal` 的写法差异；`depth` 的返回值语义是「深度（边数）」，与 `ans` 的「路径边数」量纲一致，不会差 1。

## 6. 复杂度

- **时间 O(n)**：`depth` 对每个节点恰好调用一次（后序遍历，每个节点进一次、出一次），每次内部是常数次比较和加法。n 来自节点总数，没有 log n 项，因为不是分治到「一半规模」而是遍历所有节点。
- **空间 O(h)**，h 为树高：递归栈深度等于当前路径长度，最坏（链状树）h = n，即 O(n)；最好（完全平衡）h = log n，即 O(log n)。没有额外数组，只有递归栈。

## 7. 边界与反例（至少 4 条）

1. **单节点** `root = [1]` → 期望 `0`。易错：把「节点数」当直径返回 1，或初值设成 1 导致多算一条边。直径是边数，单节点没有边。
2. **只有左孩子的链** `root = [1,2,null,3]`（1-2-3 一条链）→ 期望 `2`。易错：只考虑「左右都有」的拐点，漏掉竖直链；本解中每个节点 `L+R` 有一项为 0，仍能取到 2。
3. **直径不经过根** `root = [1,2,3,4,5,null,null,6,7]` 这类左子树内部更长的树 → 期望是左子树内部的长度而非经过根。易错：只算根处 `L+R` 就返回。本解全局 `ans` 取所有节点最大值，天然覆盖。
4. **完全平衡树** `root = [1,2,3,4,5,6,7]` → 期望 `4`（如 4-2-1-3-6 或 4-2-1-3-7 的边数）。易错：把深度当直径，返回 3（层数）或 2（根处 L+R 若深度算错）。注意根处 L=2、R=2，`L+R=4` 正确。
5. **两节点** `root = [1,2]` → 期望 `1`。易错：返回 0（误以为要三个节点）或 2（把节点数当边数）。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求返回具体路径（节点列表）而不只是长度？** 思路：DFS 时记录每个节点「最深叶子来自哪个孩子」，找到取到最大 `L+R` 的拐点后，从拐点分别向左右沿最深孩子回溯拼出路径。
2. **追问：如果树是 N 叉树？** 思路：把「左深 + 右深」换成「所有孩子深度中最大的两个之和」，其余逻辑不变，仍是一次后序 DFS。
3. **追问：如果边带权（每条边有权重），求最长路径？** 思路：`depth` 返回「到最远叶子的加权距离」，`ans` 更新为「孩子中最大的两个加权深度之和」，本质是树形 DP 求直径，O(n)。
