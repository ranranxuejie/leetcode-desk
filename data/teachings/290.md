## 1. 一句话本质

判断两个序列（字符序列与单词序列）之间是否存在**一一对应**（双射）关系——即位置对齐后，同位置的两个元素必须"同进同退"：字符相同当且仅当单词相同。

## 2. 读完题的第一反应

朴素解法：把 pattern 里每个字母和 s 里每个单词按位置配对，然后检查所有配对是否一致。具体做法是：对每一对位置 (i, j)，都去扫一遍全部位置，看是否满足"pattern[i]==pattern[j] 等价于 words[i]==words[j]"。这是 O(n²) 的，n 最大 300，其实也能过，但思维上没抓住要点。

卡在哪：O(n²) 的瓶颈在于**每次比较都要重新扫描历史**。而"两个元素是否曾经建立过对应"这件事，本质是一个**查表**问题——历史信息可以压缩成两张表存起来，查询 O(1)。

关键观察：题面明确要求"双向连接"——"没有两个字母映射到同一个单词，也没有两个单词映射到同一个字母"。这句话直接告诉你：**单向映射不够，必须两个方向都查**。只维护 `字母 → 单词` 会漏掉示例 3 那种情况（两个不同字母映射到同一个单词），所以必须同时维护 `单词 → 字母`。

## 3. 从暴力到最优

**暴力版**：对每个位置 i，遍历之前所有位置 j < i，检查 `(pattern[i]==pattern[j]) == (words[i]==words[j])` 是否成立。一旦不成立返回 False。时间 O(n²)。

**瓶颈**：内层循环在反复回答同一个问题——"这个字母之前配过哪个单词？这个单词之前配过哪个字母？"

**消除瓶颈**：用两个字典把答案缓存下来。

- `p2w`：字母 → 单词
- `w2p`：单词 → 字母

对每个位置 i 做三件事：
1. 若 `pattern[i]` 已在 `p2w` 中，检查 `p2w[pattern[i]] == words[i]`，不等则 False；
2. 若 `words[i]` 已在 `w2p` 中，检查 `w2p[words[i]] == pattern[i]`，不等则 False；
3. 都没问题，把这对关系写入两个字典。

**小例子走一遍**：`pattern = "abba"`，`s = "dog cat cat dog"`，words = `["dog","cat","cat","dog"]`。

| i | 字符 | 单词 | p2w 检查 | w2p 检查 | 写入后 p2w | 写入后 w2p |
|---|------|------|----------|----------|------------|------------|
| 0 | a | dog | 无 | 无 | {a:dog} | {dog:a} |
| 1 | b | cat | 无 | 无 | {a:dog,b:cat} | {dog:a,cat:b} |
| 2 | b | cat | p2w[b]=cat ✓ | w2p[cat]=b ✓ | 不变 | 不变 |
| 3 | a | dog | p2w[a]=dog ✓ | w2p[dog]=a ✓ | 不变 | 不变 |

全部通过 → True。

再看示例 3：`pattern="aaaa"`，words=`["dog","cat","cat","dog"]`。

| i | 字符 | 单词 | 检查结果 |
|---|------|------|----------|
| 0 | a | dog | 通过，p2w={a:dog}，w2p={dog:a} |
| 1 | a | cat | p2w[a]=dog ≠ cat → False |

在 i=1 就被拦下。注意：如果只维护 `p2w`，i=1 也会失败；但换个反例 `pattern="ab"`，`s="dog dog"`，只维护 `p2w` 时 i=1 发现 b 没出现过、直接写入 `{b:dog}`，就漏判了——这正是需要 `w2p` 的原因。

## 4. 正确性：为什么不会漏、不会重

**不变量**：在处理完前 i 个位置后，`p2w` 和 `w2p` 恰好记录了前 i 个位置中所有出现过的"字母—单词"配对，且互为逆映射（`p2w[x]=y` 当且仅当 `w2p[y]=x`）。

**归纳证明**：

- 初始 i=0，两表为空，不变量成立。
- 假设处理完前 i 个位置不变量成立，处理第 i+1 个位置时：
  - 若 `pattern[i]` 在 `p2w` 中，说明之前某个位置 j 已建立 `pattern[j] → words[j]`。由不变量，`p2w[pattern[i]] = words[j]`。检查 `p2w[pattern[i]] == words[i]` 等价于检查 `words[j] == words[i]`，即"同字母必须同单词"。
  - 若 `words[i]` 在 `w2p` 中，同理检查"同单词必须同字母"。
  - 两项都通过后写入，两表仍互为逆映射，不变量保持。

**为什么不会漏**：题面要求的三条（每个字母映射唯一单词、每个单词映射唯一字母、无两个字母映射同一单词）恰好对应上述两个检查——第一个检查覆盖"字母→单词唯一"，第二个检查覆盖"单词→字母唯一"，两者合起来覆盖"无两个字母映射同一单词"（因为若两个字母映射同一单词，第二个字母处理时 `w2p` 检查会失败）。

**为什么不会重**：每个位置只处理一次，字典写入是幂等的（重复写入相同值不改变状态），不会产生额外配对。

**长度检查**：若 `len(pattern) != len(words)`，直接返回 False——这是双射存在的前提，题面虽未明说但"完全匹配"隐含此意。

## 5. 完整代码（Python）

```python
class Solution:
    def wordPattern(self, pattern: str, s: str) -> bool:
        words = s.split(' ')  # 题面保证单空格分隔、无前后空格
        
        # 长度不等，双射不可能存在
        if len(pattern) != len(words):
            return False
        
        p2w = {}  # 字母 -> 单词
        w2p = {}  # 单词 -> 字母
        
        for ch, w in zip(pattern, words):
            # 检查字母方向：若该字母已配对，必须配的是同一个单词
            if ch in p2w and p2w[ch] != w:
                return False
            # 检查单词方向：若该单词已配对，必须配的是同一个字母
            if w in w2p and w2p[w] != ch:
                return False
            # 建立双向配对（重复写入相同值无副作用）
            p2w[ch] = w
            w2p[w] = ch
        
        return True
```

## 6. 复杂度

设 n = len(pattern)，m = len(s)（字符串长度），w = 单词个数。

- **时间**：`s.split(' ')` 需要扫描整个 s，O(m)；`zip` 循环 n 次，每次字典查询/插入均摊 O(1)，共 O(n)。总时间 **O(m + n)**。注意 m 和 n 不是同一个量——m 是字符数（含空格），n 是单词数；由于每个单词至少 1 字符加分隔符，m ≥ 2n-1，所以也可写成 O(m)。
- **空间**：`words` 列表存 w 个单词，O(m)（单词总字符数）；两个字典各存至多 min(n, 不同单词数) 项，O(n)。总空间 **O(m + n)**。

没有 log 项——本题不涉及排序或二分。

## 7. 边界与反例（至少 4 条）

1. **`pattern="ab"`, `s="dog dog"`** → 期望 False → 容易错：只维护 `p2w` 时，b 首次出现直接写入 `{b:dog}`，漏判"两个字母映射同一单词"。必须靠 `w2p` 拦截。
2. **`pattern="aa"`, `s="dog cat"`** → 期望 False → 容易错：只维护 `w2p` 时，cat 首次出现直接写入，漏判"同一字母映射不同单词"。必须靠 `p2w` 拦截。
3. **`pattern="abc"`, `s="dog cat"`** → 期望 False → 容易错：忘记先比较长度，`zip` 会静默截断到较短序列，把不等长误判为 True。
4. **`pattern="a"`, `s="dog"`** → 期望 True → 容易错：单元素时两个字典都为空，若代码在空字典上做 `p2w[ch]` 直接索引会 KeyError，必须用 `in` 判断。
5. **`pattern="abba"`, `s="dog cat cat dog"`** → 期望 True → 容易错：这是正例，用来验证"重复配对写入"不会误报——第二次遇到 a/dog 时两表检查都通过，写入相同值不改变状态。

## 8. 面试追问与变体（3 条）

1. **追问：如果 pattern 允许大写字母、s 的单词间允许多个空格怎么办？** 思路：`s.split()` 不带参数会自动按任意空白分割并丢弃空串，替换掉 `split(' ')` 即可；字母范围不影响字典逻辑。
2. **追问：不用两个字典，能不能只用一个？** 思路：可以，用 `dict` 存 `字母→单词`，再用一个 `set` 存已出现的单词，插入前检查单词是否已在 set 中——本质仍是双向，只是把 `w2p` 退化成集合（因为只需判"是否已被占用"，不需反查字母）。
3. **追问：如果要求返回具体的双射关系而不是布尔值？** 思路：循环结束后直接返回 `p2w`（或 `w2p`），失败时返回 None；注意此时长度检查失败也要返回 None。
