## 1. 一句话本质

在 haystack 的每个可能起点上，判断「从这里开始的连续 needle.length 个字符」是否与 needle 逐位相等，返回第一个成立的起点。

## 2. 读完题的第一反应

**朴素解法**：枚举起点 `i` 从 `0` 到 `n - m`（`n = len(haystack)`，`m = len(needle)`），对每个 `i` 再枚举 `j` 从 `0` 到 `m-1` 比较 `haystack[i+j]` 和 `needle[j]`，全相等就返回 `i`。这是双重循环，最坏 `O(n*m)`。

它卡在哪？卡在**失配之后的信息被浪费了**。比如 `haystack = "aaaaab"`、`needle = "aaab"`，起点 0 比较到第 4 位才失配，可起点 1、2 又要从头比一遍——明明前几位都是 `a`，这些比较结果在上一轮已经知道了，却全部丢掉重来。这就是 `O(n*m)` 的来源：每一轮失配只让起点前进 1，而比较长度接近 `m`。

**关键观察**：失配时，我们已经"看过"了 haystack 的一段前缀，这段前缀和 needle 的一段前缀是相等的。能不能利用"已匹配部分"自身的前后缀结构，让起点一次跳得更远、或者让 `j` 回退到某个非零位置而不是回到 0？这个观察直接指向 KMP：预处理 needle 的 `next`（最长相等前后缀）数组，失配时 `j` 回退到 `next[j-1]`，起点 `i` 永不回退。

不过要注意：这道题是**简单题**，面试里更常见的期望是「朴素解 + 说清复杂度」，KMP 是加分项。下面两条路都讲，主线走朴素解，KMP 作为第 3 节的进阶。

## 3. 从暴力到最优

**第一步：朴素双指针。**

固定起点 `i`，用 `j` 扫 needle。小例子：`haystack = "sadbutsad"`，`needle = "sad"`。

- `i=0`：`j=0` 比 `s==s` ✓，`j=1` 比 `a==a` ✓，`j=2` 比 `d==d` ✓，`j` 走到 3 等于 `m`，返回 0。

再看一个会失配的：`haystack = "sadbutsad"`，`needle = "but"`。

- `i=0`：`s` vs `b` 失配，`i` 前进。
- `i=1`：`a` vs `b` 失配。
- `i=2`：`d` vs `b` 失配。
- `i=3`：`b==b` ✓，`u==u` ✓，`t==t` ✓，返回 3。

瓶颈：`i=0..2` 这三次失配都只前进 1，如果 needle 很长、haystack 里全是"几乎匹配"的前缀，就会退化成 `O(n*m)`。

**第二步：用切片比较（Python 的写法优化）。**

Python 里 `haystack[i:i+m] == needle` 一次比较是 `O(m)`，但底层是 C 实现，常数极小。循环 `i` 从 `0` 到 `n-m`，总复杂度仍是 `O(n*m)` 最坏，但实际跑得比手写双重循环快得多，代码也短。**这是本题在 Python 下最实用的写法**，面试时先写这个，再讨论最坏复杂度。

**第三步：KMP（消除回退）。**

核心是预处理 needle 的 `next` 数组：`next[j]` 表示 `needle[0..j]` 的**最长相等真前后缀长度**。

以 `needle = "aaab"` 为例，手算 `next`：

- `j=0`，`"a"`：无真前后缀，`next[0]=0`。
- `j=1`，`"aa"`：前缀 `"a"`、后缀 `"a"`，长度 1，`next[1]=1`。
- `j=2`，`"aaa"`：前缀 `"aa"`、后缀 `"aa"`，长度 2，`next[2]=2`。
- `j=3`，`"aaab"`：前缀 `"a"` 后缀 `"b"` 不等，`next[3]=0`。

匹配 `haystack = "aaaaab"`、`needle = "aaab"`：

- `i=0..2` 匹配，`j` 到 3；`i=3` 时 `haystack[3]='a'` vs `needle[3]='b'` 失配。此时 `j=3`，回退 `j = next[2] = 2`，`i` 不动（还是 3）。
- 再比 `haystack[3]='a'` vs `needle[2]='a'` ✓，`j=3`，`i=4`；`haystack[4]='a'` vs `needle[3]='b'` 失配，`j = next[2] = 2`，`i` 仍不动。
- 再比 `haystack[4]='a'` vs `needle[2]='a'` ✓，`j=3`，`i=5`；`haystack[5]='b'` vs `needle[3]='b'` ✓，`j=4==m`，返回 `i-m+1 = 5-4+1 = 2`。

验证：`"aaaaab"[2:6] == "aaab"` ✓。整个过程中 `i` 只增不减，`j` 每次失配至少减 1，总比较次数 `O(n+m)`。

## 4. 正确性：为什么不会漏、不会重

**朴素解的不变量**：外层循环到起点 `i` 时，我们已经**完整检查过**所有起点 `< i`，且都不匹配（否则早就返回了）。所以当 `i` 处内层循环走完 `j==m`，返回的 `i` 就是第一个匹配项；循环结束还没返回，说明所有合法起点（`0..n-m`）都试过了，返回 -1 正确。**不会漏**：合法起点被逐个枚举；**不会重**：每个起点只检查一次。

**KMP 的不变量**：设当前已匹配 `needle[0..j-1] == haystack[i-j..i-1]`。失配时令 `j = next[j-1]`，由 `next` 定义，`needle[0..next[j-1]-1]` 同时是已匹配段的前缀和后缀，所以新的 `needle[0..j-1]` 仍与 `haystack[i-j..i-1]` 相等——**不变量保持**。同时，所有起点在 `(i-j, i-next[j-1]]` 之间的位置都不可能匹配（否则会得到更长的相等前后缀，与 `next` 的最长性矛盾），所以跳过它们**不会漏解**。`i` 单调递增保证每个 haystack 字符最多被"消费"一次，**不会重**。

## 5. 完整代码（Python）

```python
class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        n, m = len(haystack), len(needle)
        # needle 比 haystack 还长，不可能匹配
        if m > n:
            return -1

        # ---------- 写法一：切片比较（推荐，代码短、常数小） ----------
        # 起点 i 最多到 n-m，再往后长度不够
        for i in range(n - m + 1):
            # 切片长度恰好为 m，与 needle 整体比较
            if haystack[i:i + m] == needle:
                return i
        return -1

        # ---------- 写法二：KMP（最坏 O(n+m)，面试加分） ----------
```

## 6. 复杂度

**切片写法**：外层 `n-m+1` 次，每次切片 + 比较最坏 `O(m)`，时间 `O((n-m+1)*m)`，最坏 `O(n*m)`；切片会复制 `m` 个字符，额外空间 `O(m)`。这里的 `n` 来自 haystack 长度、`m` 来自 needle 长度，没有 `log` 项。

**KMP 写法**：预处理 `next` 是 `O(m)`（`j` 走 `m` 步，`k` 每次失配至少减 1，总回退不超过 `m`）；匹配阶段 `i` 走 `n` 步、`j` 总回退不超过 `n`，是 `O(n)`。合计时间 `O(n+m)`。空间是 `next` 数组 `O(m)`。

## 7. 边界与反例（至少 4 条）

1. `haystack="a", needle="a"` → 期望 `0`。容易错：循环上界写成 `range(n-m)` 会漏掉唯一起点，必须是 `range(n-m+1)`。
2. `haystack="a", needle="aa"` → 期望 `-1`。容易错：不先判 `m > n` 就切片，`haystack[0:2]` 得到 `"a"`，长度不足却可能被误判；切片比较本身安全，但 KMP 里 `needle[j]` 会越界，所以开头要挡。
3. `haystack="aaa", needle="aaaa"` → 期望 `-1`。同上，长度检查是硬边界。
4. `haystack="mississippi", needle="issip"` → 期望 `4`。容易错：`i=1` 时 `"issis"` 与 `"issip"` 前 4 位相同、第 5 位失配，朴素解要能正确前进到 `i=4` 再匹配成功；KMP 里则靠 `next` 回退，若 `next` 算错（把 `next[3]` 算成 0 而非 1）会漏掉这个解。
5. `haystack="abc", needle="c"` → 期望 `2`。容易错：单字符 needle 时 `next` 全 0，KMP 的 `while j>0` 不触发，靠 `if` 逐位推进，逻辑要写对。

## 8. 面试追问与变体（3 条）

1. **追问：如果 haystack 是流式输入（不能随机访问），怎么办？** 思路：KMP 天然适合流式——维护当前 `j`，每来一个字符就按 `next` 更新，匹配满 `m` 即报告，空间只需 `O(m)` 的 `next`。
2. **追问：找出所有匹配位置，不只第一个。** 思路：匹配成功后不返回，令 `j = next[m-1]` 继续扫，即可在 `O(n+m)` 内输出全部起点。
3. **追问：needle 里含通配符 `?`（匹配任意单字符）怎么改？** 思路：比较函数改成 `haystack[i]==needle[j] or needle[j]=='?'`，但 `next` 的构造也要用同一比较规则，否则前后缀判定不一致会出错。
