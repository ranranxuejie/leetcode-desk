## 1. 一句话本质

把数组末尾的 `k mod n` 个元素整体搬到开头，其余元素顺次后移——即对数组做一次「循环右移」的置换。

## 2. 读完题的第一反应

**朴素解法**：真的模拟「右移一步」做 k 次。每次右移要把最后一个元素暂存，然后从后往前把 `nums[i]` 挪到 `nums[i+1]`，最后把暂存值放到 `nums[0]`。单次 O(n)，做 k 次就是 O(n·k)。题面给 `n, k ≤ 10^5`，最坏 10^10 次操作，必然超时。瓶颈很清楚：**k 次重复劳动，而 k 可能远大于 n**。

**关键观察**：右移 n 次等于没动。所以真正有效的位移量是 `k % n`。这一步先把 k 从 10^5 压到小于 n，但 O(n·k') 仍是 O(n²) 级别，还不够。

第二个观察来自示例 1：`[1,2,3,4,5,6,7]` 右移 3 位得 `[5,6,7,1,2,3,4]`。盯着结果看——它其实是**两段各自保持原序**：后 3 个 `[5,6,7]` 在前，前 4 个 `[1,2,3,4]` 在后。也就是说，答案 = 「原数组的后缀」+「原数组的前缀」，两段内部顺序都不变。这个「分界点」就是 `n - k%n`。一旦把问题看成「把数组在某个位置切成两半再交换前后」，就有了不靠模拟、直接构造答案的空间。

## 3. 从暴力到最优

**第一步：消掉 k 的冗余。** 令 `k = k % n`。若 `k == 0` 直接返回。示例 1 中 k=3、n=7，不变。

**第二步：用额外数组直接拼。** 开一个长度 n 的新数组 `res`，对每个 `i`，`nums[i]` 的新位置是 `(i + k) % n`。示例 1 走一遍：

| i | nums[i] | (i+3)%7 | res |
|---|---|---|---|
| 0 | 1 | 3 | [_,_,_,1,_,_,_] |
| 1 | 2 | 4 | [_,_,_,1,2,_,_] |
| 2 | 3 | 5 | [_,_,_,1,2,3,_] |
| 3 | 4 | 6 | [_,_,_,1,2,3,4] |
| 4 | 5 | 0 | [5,_,_,1,2,3,4] |
| 5 | 6 | 1 | [5,6,_,1,2,3,4] |
| 6 | 7 | 2 | [5,6,7,1,2,3,4] |

时间 O(n)，但空间 O(n)。瓶颈从「时间」换成了「空间」——进阶要求 O(1) 原地，这一步不达标。

**第三步：三次反转（最优）。** 核心技巧：**反转整个数组，再分别反转前 k 个和后 n-k 个**。为什么？因为「反转」是可逆的、且能把「搬到前面」变成「就地翻面」。示例 1 走一遍，k=3：

- 原数组：`[1,2,3,4,5,6,7]`
- 反转整体：`[7,6,5,4,3,2,1]`
- 反转前 k=3 个：`[5,6,7,4,3,2,1]`
- 反转后 n-k=4 个：`[5,6,7,1,2,3,4]` ✅

中间变量一目了然。每一步都是 O(n) 的原地双指针交换，总共 3 次遍历，时间 O(n)、空间 O(1)。瓶颈被彻底消掉：不再有 k 次重复，也不再需要额外数组。

**为什么是「整体 + 前 k + 后 n-k」而不是别的切法？** 因为整体反转把「后缀跑到前面、前缀跑到后面」这个位置关系先摆对了，只是每段内部顺序被打乱；再对两段各自反转一次，就把内部顺序复原。切点必须是 k（后缀长度），不是 n-k——这是最容易写反的地方，第 7 节会专门列。

## 4. 正确性：为什么不会漏、不会重

用**不变量**论证。设 `k = k % n`，`m = n - k`（前缀长度）。

**引理（反转的逆序性）**：对任意序列 `S`，`reverse(S)` 中元素顺序与 `S` 完全相反。

**主论证**：把原数组写成 `A = P + S`，其中 `P = nums[0..m-1]`（长 m），`S = nums[m..n-1]`（长 k）。目标答案是 `S + P`（后缀在前、前缀在后，各自保序）。

1. `reverse(A) = reverse(S) + reverse(P)`。这一步把 S 的元素整体挪到了前半段、P 的元素挪到了后半段——**位置关系已经正确**，只是每段内部逆序。
2. `reverse(reverse(S)) = S`，`reverse(reverse(P)) = P`。对前半段（长 k）反转一次得 S，对后半段（长 m）反转一次得 P。

所以最终结果恰为 `S + P`，与目标逐位相等。

**不漏不重的关键**：三次反转都是**对同一块内存做双指针首尾交换**，每个下标恰好被访问常数次，没有元素被复制到别处、也没有元素被跳过。位置映射是双射：第 1 步把下标 i 映到 n-1-i，第 2、3 步各自在子区间内做同样的对合映射，复合后仍是 [0,n) 上的置换，因此「每个原元素恰好落到一个目标位置」。这就是为什么不会漏、不会重。

## 5. 完整代码（Python）

```python
class Solution:
    def rotate(self, nums: list[int], k: int) -> None:
        n = len(nums)
        if n <= 1:
            return
        k %= n                      # 右移 n 次等于没动，先消冗余
        if k == 0:
            return                  # 无需移动，直接返回

        def reverse(lo: int, hi: int) -> None:
            # 反转闭区间 [lo, hi]，原地双指针交换
            while lo < hi:
                nums[lo], nums[hi] = nums[hi], nums[lo]
                lo += 1
                hi -= 1

        reverse(0, n - 1)           # 第 1 步：整体反转
        reverse(0, k - 1)           # 第 2 步：反转前 k 个（即后缀 S）
        reverse(k, n - 1)           # 第 3 步：反转后 n-k 个（即前缀 P）
```

注意第 2、3 步的切点是 `k`：前 k 个是「原后缀」，后 n-k 个是「原前缀」。若把两步的区间写反（先反转前 n-k 个），结果会变成 `P + S` 的原序，等于没转——这是本题最高频的实现错误。

## 6. 复杂度

- **时间 O(n)**：`k %= n` 是 O(1)；三次 `reverse` 分别扫描 n、k、n-k 个元素，总访问次数 `n + k + (n-k) = 2n`，常数次遍历，故 O(n)。没有 log 项——本题不涉及分治或排序，所有操作都是线性扫描。
- **空间 O(1)**：只用了 `n`、`k`、`lo`、`hi` 几个整型变量和交换时的临时值，与输入规模无关。递归栈也没有（`reverse` 是迭代的）。对比第 3 节第二步的额外数组方案，空间从 O(n) 降到 O(1)。

## 7. 边界与反例（至少 4 条）

1. **`nums = [1], k = 0`** → 期望 `[1]`。容易错在没处理 `n <= 1` 或 `k == 0`，导致 `reverse(0, -1)` 这类非法区间；Python 的 `while lo < hi` 恰好能兜住，但显式 return 更清晰。
2. **`nums = [1,2], k = 2`** → 期望 `[1,2]`（右移 2 次回到原位）。容易错在忘记 `k %= n`，于是 `reverse(0, k-1)` 变成 `reverse(0, 1)` 越界或切错段。
3. **`nums = [1,2,3], k = 4`** → 期望 `[3,1,2]`（等价于 k=1）。容易错在直接用 k=4 去切区间，`reverse(0,3)` 越界；`k %= n` 后 k=1 才正确。
4. **`nums = [1,2,3,4], k = 0`** → 期望 `[1,2,3,4]`。容易错在没提前返回，三次反转里第 2 步 `reverse(0,-1)` 虽空转，但若实现成 `reverse(0, k)` 就会多翻一个元素。
5. **`nums = [-1,-100,3,99], k = 2`**（示例 2）→ 期望 `[3,99,-1,-100]`。容易错在切点写反：若先 `reverse(0, n-k-1)` 再 `reverse(n-k, n-1)`，得到的是原序，负数和正数的相对位置全错。

## 8. 面试追问与变体（3 条）

1. **追问：不用三次反转，怎么原地做？** 思路：**循环置换（环状替换）**。从 i=0 出发，把 `nums[i]` 放到 `(i+k)%n`，再沿着环继续，直到回到起点；用 `gcd(n,k)` 个环覆盖全部元素，每个元素恰好动一次，O(n) 时间 O(1) 空间。难点是要数清已处理元素个数，避免重复。
2. **追问：如果要求左轮转 k 位呢？** 思路：左移 k 等价于右移 `n-k`，直接复用本题；或把三次反转的切点改成 `n-k`（先反转前 n-k、再反转后 k、最后整体）。
3. **追问：如果数组是链表而不是数组？** 思路：找到倒数第 k 个节点作为新头，把尾节点接到原头，断开新头的前驱——本质是「找切点 + 改指针」，O(n) 时间 O(1) 空间，不需要反转。
