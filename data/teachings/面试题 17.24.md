## 1. 一句话本质

在所有连续行区间 × 连续列区间构成的矩形里，找元素和最大的那一个，并返回它的四个边界坐标。

## 2. 读完题的第一反应

**朴素解法**：枚举左上角 `(r1,c1)` 和右下角 `(r2,c2)`，共 O(n²m²) 个矩形，每个矩形求和 O(nm)，总 O(n³m³)。n,m ≤ 200 时这是 200⁶ 量级，完全不可行。即使加二维前缀和把单次求和降到 O(1)，枚举本身仍是 O(n²m²) = 1.6×10⁹，Python 里也过不去。

**关键观察**：一维的「最大子数组和」我们有 O(k) 的 Kadane 算法。二维能不能压成一维？可以——**固定上下边界 `r1, r2` 后，把每一列在 `[r1, r2]` 行内的元素纵向求和，得到一个长度为 m 的一维数组**，问题立刻退化成「在这个一维数组上找最大子数组」，而它的左右端点就是 `c1, c2`。

为什么这个观察能让你想到下一步：它把「二维枚举」拆成了「枚举行区间（O(n²) 对）+ 一维线性扫描（O(m)）」，总复杂度 O(n²m)。n,m ≤ 200 时约 8×10⁶，Python 可接受。这就是「降维」这一招的标准用法。

## 3. 从暴力到最优

**第一步：暴力枚举四边界。** 瓶颈是 O(n²m²) 个矩形，每个都要重新求和。

**第二步：加二维前缀和。** 单次求和 O(1)，但枚举量没变，瓶颈从「求和」转移到了「枚举」。

**第三步：降维。** 不再枚举列边界，而是固定行区间后，用 Kadane 一次性求出最优列区间。瓶颈被消掉的原因是：**Kadane 在扫描过程中同时尝试了所有可能的右端点，并保留了每个右端点下最优的左端点**，所以不需要显式枚举 `c1, c2`。

**具体小例子**走一遍。取

```
matrix = [
  [-1,  0],
  [ 0, -1]
]
```

枚举行区间：

- `r1=0, r2=0`：列压缩数组 `col = [-1, 0]`。Kadane 扫描：
  - 第 0 列：`cur = -1`，`best = -1`，`bestL = bestR = 0`
  - 第 1 列：`cur = max(0 + (-1), 0) = 0`（因为 `cur + x = -1 < x = 0`，重置起点），`cur = 0 > best = -1`，更新 `best = 0`，`bestL = bestR = 1`
  - 得到列区间 `[1,1]`，和 0。
- `r1=0, r2=1`：`col = [-1+0, 0+(-1)] = [-1, -1]`。Kadane：`cur` 依次为 -1, -1，`best = -1`，列区间 `[0,0]`，和 -1。
- `r1=1, r2=1`：`col = [0, -1]`。Kadane：第 0 列 `cur=0, best=0`；第 1 列 `cur = max(0-1, -1) = -1`，不更新。列区间 `[0,0]`，和 0。

三个候选里，`r1=0,r2=0,c1=1,c2=1` 与 `r1=1,r2=1,c1=0,c2=0` 都是和 0，任取一个，比如前者，输出 `[0,1,0,1]`，与官方示例一致。

注意一个细节：**Kadane 的「重置」条件必须写成 `cur + x < x` 才重置**，等价于 `cur < 0`。如果写成 `cur <= 0` 也重置，遇到全 0 矩阵时会退化成单元素，虽然和仍为 0 但区间不同——本题允许任意答案，所以两种写法都能过，但为了「不漏掉更长的等和区间」，推荐用严格小于。

## 4. 正确性：为什么不会漏、不会重

**不变量**：外层循环枚举了所有 `(r1, r2)` 且 `r1 ≤ r2` 的行区间，恰好一次，不重不漏。对每个固定的行区间，`col[c] = sum(matrix[r1..r2][c])`，于是「原矩阵中行区间为 `[r1,r2]`、列区间为 `[c1,c2]` 的子矩阵和」严格等于「一维数组 `col` 在 `[c1,c2]` 上的子数组和」。这是一个恒等式，不是近似。

**Kadane 的正确性用交换论证说**：设 `best` 是扫描到第 `j` 列时记录的最大子数组和。归纳假设：扫描完前 `j` 列后，`best` 等于 `col[0..j]` 中所有子数组和的最大值，且 `cur` 等于「以第 `j` 列结尾的最大子数组和」。转移时，以 `j+1` 结尾的子数组要么只含 `col[j+1]`（对应 `cur < 0` 时重置），要么是「以 `j` 结尾的最优子数组」再接上 `col[j+1]`（对应 `cur + col[j+1]`）。任何以 `j+1` 结尾的子数组都落在这两类之一，所以 `cur` 的更新不遗漏；`best` 取历史最大，也不遗漏。归纳成立。

**不漏**：任意一个最优子矩阵，其行区间必被外层某一对 `(r1,r2)` 枚举到，其列区间必被该次 Kadane 覆盖到（由上面的归纳），所以最优解一定被检查过。

**不重**：每个 `(r1,r2)` 只处理一次，每次只输出一个列区间，不会重复计数。多个等和答案时返回任意一个，符合题意。

## 5. 完整代码（Python）

```python
class Solution:
    def getMaxMatrix(self, matrix):
        n = len(matrix)
        m = len(matrix[0])
        # 全局最优：和、r1、c1、r2、c2
        best_sum = float('-inf')
        ans = [0, 0, 0, 0]

        # 枚举上边界 r1
        for r1 in range(n):
            # col[c] 表示第 c 列在 [r1, r2] 行区间内的纵向和
            col = [0] * m
            # 枚举下边界 r2，边扩边累加，避免每次重算
            for r2 in range(r1, n):
                row = matrix[r2]
                for c in range(m):
                    col[c] += row[c]

                # 在 col 上跑 Kadane，求最大子数组及其左右端点
                cur = 0
                start = 0          # 当前子数组的左端点候选
                for c in range(m):
                    if cur < 0:
                        # 以 c 为新的起点，之前的贡献为负，丢掉
                        cur = col[c]
                        start = c
                    else:
                        cur += col[c]
                    # 严格大于才更新，保证等和时保留先出现的区间
                    if cur > best_sum:
                        best_sum = cur
                        ans = [r1, start, r2, c]

        return ans
```

关键逻辑注释已在代码中。注意 `col` 的累加放在 `r2` 循环内部、Kadane 之前，这样每个 `(r1,r2)` 只花 O(m) 更新 `col`，而不是 O(nm) 重算。

## 6. 复杂度

- **时间 O(n²m)**：外层 `r1` 有 n 种，内层 `r2` 有 O(n) 种，共 O(n²) 个行区间；每个行区间内，更新 `col` 花 O(m)，Kadane 花 O(m)，合计 O(m)。乘起来 O(n²m)。n=m=200 时约 8×10⁶ 次基本操作。
- **空间 O(m)**：`col` 数组长度 m，其余是常数个变量。没有用二维前缀和，所以不是 O(nm)。
- 若把矩阵转置后让 n ≤ m，可把复杂度写成 O(min(n,m)² · max(n,m))，常数更优，但本题 n,m 同阶，非必需。

## 7. 边界与反例（至少 4 条）

1. **输入 `[[-3]]`** → 期望 `[0,0,0,0]`。容易错在把 `best_sum` 初始化为 0，导致全负时返回空区间或错误坐标；必须初始化为 `-inf`。
2. **输入 `[[0]]`** → 期望 `[0,0,0,0]`。容易错在 `cur < 0` 判断写成 `cur <= 0` 时把起点重置到下一列，单列矩阵会越界或返回错误列号。
3. **输入 `[[-1,-2],[-3,-4]]`** → 期望 `[0,0,0,0]`（和为 -1）。容易错在只考虑「至少两个元素」的区间，或 Kadane 里忘记在 `cur < 0` 时重置，导致累加成 -10。
4. **输入 `[[1,2,3],[4,5,6]]`** → 期望整个矩阵 `[0,0,1,2]`，和为 21。容易错在 `col` 累加写在内层 `r2` 循环外，导致 `r2` 变化时 `col` 没更新，结果只反映第一行。
5. **输入 `[[2,-1,2]]`（单行）** → 期望 `[0,0,0,2]`，和为 3。容易错在 Kadane 遇到 -1 时重置，丢掉前后两段 2 的合并；正确做法是 `cur = 2-1 = 1 ≥ 0` 不重置，继续加 2 得 3。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求返回「字典序最小」的 `[r1,c1,r2,c2]` 怎么办？** 思路：在 `cur > best_sum` 改为 `cur >= best_sum` 时比较坐标字典序，或在等和时显式比较四元组，保留更小的那个。
2. **追问：如果矩阵是稀疏的、非零元素很少，能否更快？** 思路：只枚举行区间端点来自非零行、列端点来自非零列，配合前缀和，复杂度降到与非零元素数量相关。
3. **追问：如果要求子矩阵面积至少为 k？** 思路：Kadane 的 `start` 需要记录「满足列宽 ≥ k 的最优左端点」，用滑动窗口或额外数组维护每个右端点下合法的左端点集合，复杂度升到 O(n²m) 但常数变大。
