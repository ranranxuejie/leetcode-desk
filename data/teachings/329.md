## 1. 一句话本质

对矩阵里每个格子，求「以它为起点、只能走向严格更大邻居」的最长有向路径长度，再在所有格子中取最大值——本质是在一张 DAG 上做最长路。

## 2. 读完题的第一反应

**朴素解法**：把每个格子都当作起点，做一次 DFS，沿四个方向只走严格更大的格子，记录能走多深，取全局最大。

它卡在哪？看一个 3×3 全是 `1,2,3,...` 递增的矩阵：从左上角出发能一路走到右下角，路径长度约 m+n；而每个格子都要重新搜一遍，同一段后缀被反复计算。最坏情况（比如蛇形递增矩阵）单次 DFS 能访问 O(mn) 个格子，总共 O((mn)²)。m=n=100 时就是 10⁸ 量级，超时。

**关键观察**：题目要求「严格递增」，所以沿着任何一条合法路径，数值一定单调上升——**路径不可能成环**。既然无环，那「从格子 (i,j) 出发能走多长」就是一个**只由 (i,j) 自己决定、与从哪来无关**的量。这个量一旦算出来，就可以缓存复用。这正是记忆化搜索的适用条件：状态无后效性 + 子问题重复。

## 3. 从暴力到最优

**瓶颈**：同一个格子的「最长延伸长度」被不同起点重复计算。

**消掉它的手段**：给每个格子开一个缓存 `memo[i][j]`，第一次算出来就存下，之后直接返回。

用示例 1 走一遍：`matrix = [[9,9,4],[6,6,8],[2,1,1]]`，坐标 (行,列)。

从 (2,1)（值 1）出发 DFS：

- 邻居：上 (1,1)=6 > 1，左 (2,0)=2 > 1，右 (2,2)=1 不满足严格大于，下越界。
- 先走上 (1,1)=6：它的邻居里 (0,1)=9 > 6、(2,1)=1 不大于 6、(1,0)=6 不严格大于、(1,2)=8 > 6。
  - 走 (0,1)=9：四个邻居都 ≤ 9，返回 1。`memo[0][1]=1`。
  - 走 (1,2)=8：邻居 (0,2)=4、(2,2)=1、(1,1)=6 都不大于 8，返回 1。`memo[1][2]=1`。
  - 于是 `memo[1][1] = 1 + max(1,1) = 2`。
- 再走左 (2,0)=2：邻居 (1,0)=6 > 2、(2,1)=1 不大于 2，返回 `1 + memo[1][0]`；而 `memo[1][0]` 由 (0,0)=9 得 2。所以这条支路给 3。
- `memo[2][1] = 1 + max(2, 3) = 4`。

之后任何格子若走到 (2,1)，直接读 4，不再展开。全局扫描时 (0,0)=9 的 DFS 会走到 (1,0)=6 再走到 (2,0)=2，此时 `memo[1][0]`、`memo[2][0]` 已就绪，O(1) 拿到结果。总访问量从「每条路径重算」降到「每个格子只真正展开一次」。

**为什么不需要拓扑排序**：记忆化 DFS 天然按「值从小到大」的依赖顺序回填——一个格子的答案只依赖比它大的邻居，递归返回时依赖已算完，等价于在 DAG 上做后序 DP。拓扑排序是同一件事的迭代写法，二选一即可。

## 4. 正确性：为什么不会漏、不会重

**不变量**：对任意格子 v，`memo[v]` 一旦被写入，就等于「以 v 为起点的最长递增路径长度」，且此后不再改变。

**归纳证明**（对格子数值从小到大归纳，等价于对 DAG 的拓扑序归纳）：

- 基例：v 的所有邻居都不大于 v（局部极大点），DFS 中四个方向全部不递归，返回 1。以 v 为起点的路径只能含 v 自己，长度确为 1。✓
- 归纳步：设所有值大于 v 的格子 u 都满足不变量。以 v 为起点的任意递增路径，第二步必落在某个邻居 u 上且 `matrix[u] > matrix[v]`，之后的最长延伸恰是 `memo[u]`（由归纳假设）。故 `memo[v] = 1 + max over 合法邻居 u of memo[u]`，与真实最长路径一致。✓

**不漏**：外层对每个格子都调用一次 DFS，答案取所有 `memo` 的最大值，覆盖了「以任意格子为起点」的全部情况；而任何递增路径必有起点，故全局最长必被枚举到。

**不重（不重复计算）**：`memo[v] != 0` 时直接返回，保证每个格子的展开体只执行一次。由于严格递增排除了环，递归不会回到自身，不存在「算到一半又依赖自己」的循环依赖，缓存值不会读到半成品。

## 5. 完整代码（Python）

```python
class Solution:
    def longestIncreasingPath(self, matrix) -> int:
        if not matrix or not matrix[0]:
            return 0
        m, n = len(matrix), len(matrix[0])
        # memo[i][j] = 以 (i,j) 为起点的最长递增路径长度；0 表示尚未计算
        memo = [[0] * n for _ in range(m)]
        dirs = ((1, 0), (-1, 0), (0, 1), (0, -1))

        def dfs(i, j):
            # 命中缓存：该格子的答案已确定，直接复用
            if memo[i][j] != 0:
                return memo[i][j]
            best = 1  # 至少包含自己
            for di, dj in dirs:
                ni, nj = i + di, j + dj
                # 只允许走向严格更大的邻居，保证无环
                if 0 <= ni < m and 0 <= nj < n and matrix[ni][nj] > matrix[i][j]:
                    best = max(best, 1 + dfs(ni, nj))
            memo[i][j] = best  # 回填缓存，后续 O(1) 读取
            return best

        ans = 0
        for i in range(m):
            for j in range(n):
                ans = max(ans, dfs(i, j))
        return ans
```

## 6. 复杂度

**时间 O(mn)**。每个格子最多被真正展开一次（`memo` 非零即返回），单次展开检查 4 个方向，是常数工作；外层双重循环共 mn 次调用，其中大部分是 O(1) 的缓存命中。所以总工作量正比于格子数，与路径长度无关——这正是相对暴力 O((mn)²) 的改进来源。

**空间 O(mn)**。`memo` 表占 mn 个整数。递归栈深度最坏等于最长递增路径长度，上界也是 mn（严格递增路径最多经过每个格子一次），故栈空间 O(mn)。两者相加仍是 O(mn)。这里没有 log 项：没有排序、没有二分，只有线性扫描与常数次邻居检查。

## 7. 边界与反例（至少 4 条）

1. **输入 `[[1]]`** → 期望 1。容易错在把 `best` 初始化为 0，或忘记「路径至少含起点」，导致返回 0。
2. **输入 `[[1,1],[1,1]]`** → 期望 1。四个格子互相都不严格大于，任何方向都不能走。容易错在把条件写成 `>=`，那样会互相递归、栈溢出或死循环。
3. **输入 `[[1,2],[4,3]]`** → 期望 4（1→2→3→4 绕一圈）。容易错在只沿「右下」方向搜，漏掉先右后下再左的折返路径；必须四个方向都试。
4. **输入 `[[7,8,9],[6,1,2],[5,4,3]]`** → 期望 9（从 1 螺旋走到 9）。容易错在误以为路径必须单调沿某个方向，或误用 BFS 层数当答案——BFS 层数只在多源同时扩展时才对，这里起点不唯一且要取最大，DFS+记忆化更直接。
5. **输入 `[[1,2,3],[6,5,4],[7,8,9]]`** → 期望 9。容易错在缓存写成「访问过就返回 1」，把记忆化退化成去重，答案偏小。

## 8. 面试追问与变体（3 条）

1. **追问：不用递归，改成迭代怎么写？** 思路：按格子数值从小到大排序，依次用「比它小的邻居的 dp 值 +1」更新，本质是拓扑序 DP；或对每个格子算出度做 Kahn 拓扑排序，按弹出顺序累加层数。
2. **追问：如果允许相等也算递增（非严格），还能这么做吗？** 思路：不能直接记忆化，因为相等格子之间会成环、状态互相依赖；需要先把相等值缩成连通分量（并查集/DFS 染色），在分量构成的 DAG 上再做最长路。
3. **追问：只要求返回路径本身而不只是长度？** 思路：`memo` 里额外存「最优下一步的坐标」，全局最大值所在格子顺着指针走即可还原路径，空间仍是 O(mn)。
