## 1. 一句话本质

在一条升序单链表中，把所有「值出现过至少两次」的节点整组删掉，只保留那些值恰好出现一次的节点，并返回新链表的头。

## 2. 读完题的第一反应

**朴素解法**：用一个哈希表统计每个值出现的次数，第二遍遍历时把计数 > 1 的节点删掉。

它卡在哪？空间是 O(n)。而且它完全没用上「已排序」这个条件——题目特意强调升序，说明出题人希望你利用它。对链表来说，O(n) 额外空间在面试里通常会被追问「能不能 O(1)」。

**关键观察**：因为链表升序，**相同值的节点一定连续挨在一起**。于是「某个值是否重复」不需要全局统计，只要看「当前节点和它的下一个节点值是否相等」就够了。相等 → 这一整段都要删；不等 → 当前节点可以安全保留。

这个观察直接消掉了哈希表：我们只需要在遍历时多看一个节点（下一个），就能判断当前节点该不该留。这就是「双指针」在这里的真实含义——不是快慢指针，而是**一个指针指向「最后一个确定保留的节点」，另一个指针去前面探路**。

还有一个隐藏的坑：如果头节点本身是重复的（比如 `[1,1,2]`），头会被删掉，返回值就不再是原来的 head。所以需要一个**哑节点（dummy）**挂在最前面，让「删除头节点」和「删除中间节点」变成同一件事。

## 3. 从暴力到最优

**第一步：哈希计数版**

遍历一遍，`cnt[val] += 1`；再遍历一遍，遇到 `cnt[val] > 1` 就删。时间 O(n)，空间 O(n)。瓶颈是那张表。

**第二步：利用有序性，去掉表**

因为有序，重复值成段出现。设 `prev` 指向「最后一个确定要保留的节点」，`cur = prev.next` 是待检查的节点：

- 若 `cur.val != cur.next.val`（或 cur.next 为空）→ cur 是独苗，保留，`prev = cur`，`cur = cur.next`。
- 若 `cur.val == cur.next.val` → cur 属于重复段，一路 `cur = cur.next` 直到值变化，然后把 `prev.next` 直接接到新的 cur 上，整段丢弃。

**走一遍示例 1：`[1,2,3,3,4,4,5]`**

先建 dummy(0) → 1 → 2 → 3 → 3 → 4 → 4 → 5，`prev = dummy`，`cur = 1`。

| 步骤 | cur.val | cur.next.val | 判断 | 动作 | prev 指向 |
|---|---|---|---|---|---|
| 1 | 1 | 2 | 不等 | 保留，prev=1，cur=2 | 1 |
| 2 | 2 | 3 | 不等 | 保留，prev=2，cur=3 | 2 |
| 3 | 3 | 3 | 相等 | 进入删除：cur 走到第二个 3，再走到 4；`prev.next = 4` | 2 |
| 4 | 4 | 4 | 相等 | 进入删除：cur 走到第二个 4，再走到 5；`prev.next = 5` | 2 |
| 5 | 5 | None | — | 保留，prev=5，cur=None | 5 |

结果 dummy.next = 1 → 2 → 5，正确。注意第 3 步里 `prev` 没动，这正是「整段删掉、保留指针原地不动」的体现。

**第三步：为什么这就是最优**

每个节点最多被 `cur` 访问一次（删除段里 cur 一路向前，不会回头），时间 O(n)；只用了 dummy、prev、cur 三个指针，空间 O(1)。有序性已经把「判断重复」的成本压到了 O(1)，没有进一步优化的空间。

## 4. 正确性：为什么不会漏、不会重

用**循环不变量**来证。

**不变量**：在每一轮循环开始时，`prev` 及其之前的所有节点，都是最终答案的前缀，且其中不含任何重复值；`prev.next == cur`；`cur` 之后（含 cur）的节点尚未被处理。

**初始化**：`prev = dummy`，dummy 是虚构节点，前缀为空，不变量成立。

**保持**：
- 情况 A（`cur` 是独苗）：由有序性，cur 的值既不等于前一个保留值（否则前一轮就会把它一起删掉），也不等于后一个值，所以 cur 在最终答案中恰好出现一次，接到 prev 后面合法。prev 前移，不变量保持。
- 情况 B（`cur` 与后继同值）：由有序性，所有等于 cur.val 的节点构成从 cur 开始的一段连续区间，循环把它们全部跳过，`prev.next` 直接指向第一个不同值的节点。这一段在最终答案中一个都不该留，全部丢弃正确。prev 不动，不变量保持。

**终止**：cur 为 None 时，所有节点都已判定，dummy.next 就是答案。

**不会漏**：每个节点要么被判定为独苗保留，要么落在某个被整段跳过的区间里，二者必居其一，没有第三种情况。
**不会重**：保留的节点值两两不同——若两个保留节点同值，由有序性它们之间不会有别的值，那它们必然相邻，而相邻同值时后一个会被并入删除段，矛盾。

## 5. 完整代码（Python）

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution:
    def deleteDuplicates(self, head: ListNode) -> ListNode:
        # 哑节点：让「删头节点」和「删中间节点」走同一套逻辑
        dummy = ListNode(0, head)
        prev = dummy          # 最后一个确定保留的节点
        cur = head            # 待检查的节点

        while cur:
            # 情况 B：cur 与后继同值，说明 cur 属于重复段
            if cur.next and cur.val == cur.next.val:
                # 一路跳过所有同值节点，直到值变化或到链尾
                while cur.next and cur.val == cur.next.val:
                    cur = cur.next
                # 此时 cur 是这段重复值的最后一个，整段丢弃
                prev.next = cur.next
                cur = cur.next
            else:
                # 情况 A：cur 是独苗，安全保留
                prev = cur
                cur = cur.next

        return dummy.next
```

关键点：`prev.next = cur.next` 之后 `prev` **不移动**，因为新的 `prev.next` 还没被验证过；而 `cur = cur.next` 让检查继续往下走。

## 6. 复杂度

**时间 O(n)**：n 是节点数。外层 while 每轮要么让 cur 前进一格（情况 A），要么让 cur 在删除段里前进若干格后跳出（情况 B）。无论哪种，cur 只向链尾移动、从不回退，所以所有内层 `cur = cur.next` 的总次数不超过 n。每个节点被访问常数次，总时间线性。

**空间 O(1)**：只用了 `dummy`、`prev`、`cur` 三个指针变量，与 n 无关。注意这里没有递归，所以也没有递归栈的 O(n) 开销——这是相对「递归版」的一个实际优势。

## 7. 边界与反例（至少 4 条）

1. **空链表** `head = []` → 输出 `[]`。容易错在没判空就访问 `head.next`；本代码 `while cur` 直接跳过，`dummy.next` 是 None，正确。
2. **单节点** `[1]` → 输出 `[1]`。容易错在把「没有 next」误判成需要删除；`cur.next` 为 None 时走 else 分支保留，正确。
3. **全部相同** `[1,1,1]` → 输出 `[]`。容易错在只删掉「多余的」而留下一个；本题要求全删。代码里整段跳过、`prev.next = None`，返回 None，正确。
4. **头节点重复** `[1,1,2]` → 输出 `[2]`。最容易错：不用 dummy 时，删头节点需要特判并更新 head，很容易写漏或写错；dummy 让这种情况和普通情况完全一致。
5. **尾部重复** `[1,2,2]` → 输出 `[1]`。删除段一直到链尾，`cur.next` 为 None 时内层循环要能正常退出，`prev.next = None`，正确。
6. **无重复** `[1,2,3]` → 输出 `[1,2,3]`。全程走 else 分支，等价于原样返回。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求「重复的只保留一个」（即 83 题），代码怎么改？**
   思路：不需要 dummy，也不需要整段跳过；遇到 `cur.val == cur.next.val` 时直接 `cur.next = cur.next.next`，保留 cur 本身。

2. **追问：链表没有排序，还能 O(1) 空间做吗？**
   思路：不能一趟做完。要么用哈希表 O(n) 空间，要么先排序（链表排序 O(n log n)）再套本题逻辑。要讲清楚「有序」是本题 O(1) 空间的前提。

3. **追问：如果要求返回被删除的值集合呢？**
   思路：在整段跳过的分支里，把 `cur.val` 收集起来即可，其余逻辑不变；注意同一段只收集一次，别在内层循环里重复添加。
