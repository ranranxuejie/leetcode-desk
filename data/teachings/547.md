## 1. 一句话本质

把 `isConnected` 看成一张无向图的邻接矩阵，求这张图里**连通分量的个数**。

城市是顶点，`isConnected[i][j] == 1` 是 i 和 j 之间的一条边。题目说的「省份」就是图论里的连通分量：一组互相可达的顶点，且不与组外任何顶点相连。所以这题不是新题，是「数连通分量」这个经典图论问题换了个故事外壳。

## 2. 读完题的第一反应

**朴素解法**：对每个城市 i，看它和哪些城市相连，然后顺着连接关系一路找下去，把所有能到达的城市标记为「同一个省」。这其实就是 DFS/BFS 的雏形。真正的瓶颈不在「怎么找」，而在「找过的怎么不重复找」——如果每次从 i 出发都重新遍历一遍全图，最坏情况是 O(n²) 个顶点访问被重复执行 n 次，退化成 O(n³)。

**关键观察**：一旦某个城市被归入某个省，它就永远属于那个省，后面不需要再考虑它。这提示我们维护一个 `visited` 数组：**每发现一个未访问的城市，就说明遇到了一个新省份**，然后把它能到达的所有城市一次性标记掉。这样每个城市最多被访问一次，总访问量是 O(n²)（因为要扫描矩阵），而不是 O(n³)。

另一个观察来自题面提示 `isConnected[i][j] == isConnected[j][i]`：矩阵是对称的，图是无向的。无向图意味着「从 i 能到 j」等价于「从 j 能到 i」，所以从任意一个未访问点出发做一次遍历，就能完整地圈出一个连通分量，不会漏掉反向的连接。

## 3. 从暴力到最优

**暴力版本**：对每个城市 i，做一次完整 DFS 判断它属于哪个已发现的省。问题在于判断「属于哪个省」需要和所有已发现的省逐一比对，最坏 O(n) 次比对，每次比对又要 O(n²) 遍历，总计 O(n³)。

**优化路径**：把「判断归属」变成「发现即标记」。维护 `visited`，外层循环扫一遍所有城市，遇到未访问的就 `count += 1` 并从这个城市出发 DFS，把整个连通分量标记为已访问。外层循环总共 n 次，每次 DFS 内部对每个顶点扫一遍它的 n 个邻居，所以总代价 O(n²)。

**小例子走一遍**：`isConnected = [[1,1,0],[1,1,0],[0,0,1]]`，n=3。

- `visited = [F,F,F]`，`count = 0`
- i=0，未访问 → `count = 1`，从 0 出发 DFS：
  - 访问 0，`visited = [T,F,F]`
  - 扫 0 的邻居：`isConnected[0][1]=1` 且 1 未访问 → 访问 1，`visited = [T,T,F]`
  - 扫 1 的邻居：`isConnected[1][0]=1` 但 0 已访问，跳过；`isConnected[1][2]=0`，跳过
  - 回到 0，`isConnected[0][2]=0`，跳过。DFS 结束
- i=1，已访问，跳过
- i=2，未访问 → `count = 2`，从 2 出发 DFS：访问 2，邻居 0、1 都是 0，结束
- 返回 `count = 2` ✓

对比示例 2 的对角矩阵：每个 i 都未访问，每次 DFS 只标记自己，`count` 累加到 3，正好对应三个孤立城市。

## 4. 正确性：为什么不会漏、不会重

用**不变量**来论证。定义不变量：**在外层循环的每一轮开始时，`visited` 中为 True 的城市恰好是已经被完整圈出的那些连通分量的并集，且 `count` 等于这些分量的个数。**

- **初始化**：循环开始前 `visited` 全 False，`count = 0`，空集是 0 个分量的并，不变量成立。
- **保持**：假设第 i 轮开始时不变量成立。若 `visited[i]` 为 True，说明 i 已在某个已圈出的分量里，跳过不改变任何状态，不变量保持。若 `visited[i]` 为 False，说明 i 不属于任何已圈出的分量，那么 i 所在的整个连通分量与已圈出的分量**不相交**（否则 i 会通过那条连接被之前的 DFS 标记到）。从 i 出发的 DFS 会且只会访问这个分量内的所有顶点——「只会」因为 DFS 只沿边扩展，「所有」因为连通分量内任意顶点都存在到 i 的路径，DFS 沿路径必然到达。于是这一轮恰好新增一个完整分量，`count += 1`，不变量保持。
- **终止**：外层循环结束时所有城市都被处理，每个连通分量恰好被圈出一次，`count` 就是分量总数。

**不会重**：每个分量只在「第一个被扫到的未访问顶点」处被计数一次，之后该分量内所有顶点都变为已访问，不会再触发计数。**不会漏**：任何分量至少有一个顶点，外层循环必然扫到它，且扫到它时它要么未访问（触发计数）要么已访问（说明已被更早的顶点计数过），两种情况都保证该分量被计入。

## 5. 完整代码（Python）

```python
class Solution:
    def findCircleNum(self, isConnected: list[list[int]]) -> int:
        n = len(isConnected)
        visited = [False] * n   # 标记城市是否已被归入某个省
        count = 0               # 省份计数

        def dfs(i: int) -> None:
            # 进入即标记，保证每个城市只被访问一次
            visited[i] = True
            for j in range(n):
                # 只看「有边」且「未访问」的邻居，避免重复递归
                if isConnected[i][j] == 1 and not visited[j]:
                    dfs(j)

        for i in range(n):
            # 遇到未访问城市，说明发现了一个新省份
            if not visited[i]:
                count += 1
                dfs(i)          # 把这个省份的所有城市一次性标记

        return count
```

关键逻辑说明：`dfs` 里先标记再递归，而不是先递归再标记，是为了防止环（比如 0-1-0）导致无限递归；`isConnected[i][j] == 1 and not visited[j]` 两个条件缺一不可，前者保证沿边走，后者保证不回头。

## 6. 复杂度

**时间 O(n²)**：外层循环 n 次；每次 DFS 对一个顶点扫它的 n 个邻居，而每个顶点最多被 DFS 进入一次（`visited` 保证），所以 DFS 总代价是 n 个顶点 × 每个 n 次邻居扫描 = O(n²)。外层循环本身 O(n)，被 O(n²) 吸收。注意这里**没有 log n**，因为没有任何排序或二分操作；n² 完全来自邻接矩阵的规模——矩阵本身就有 n² 个元素，读一遍就是下界。

**空间 O(n)**：`visited` 数组 n 个布尔值；递归栈最深为一条链，最多 n 层，每层 O(1)。两者都是 O(n)。**没有 O(n²) 空间**，因为我们没有复制矩阵，也没有建邻接表。

## 7. 边界与反例（至少 4 条）

1. **n = 1，`[[1]]`** → 期望 1。容易错在把 `count` 初始化为 0 后忘了外层循环会处理它，或者误以为「没有边就没有省」。题面保证 `isConnected[i][i] == 1`，单个城市自成一个省。
2. **全连通，`[[1,1],[1,1]]`** → 期望 1。容易错在 DFS 里只标记不检查 `visited`，导致 0→1→0 无限递归爆栈。
3. **全孤立，`[[1,0,0],[0,1,0],[0,0,1]]`** → 期望 3。容易错在 DFS 里把 `isConnected[i][i] == 1` 当成「有邻居」，结果每个城市都递归到自己，虽然加了 `visited` 不会死循环，但逻辑上应理解为「自己不是自己的邻居」，靠 `visited` 兜住。
4. **链式连接，`[[1,1,0],[1,1,1],[0,1,1]]`** → 期望 1。容易错在只做一层邻居扩展（BFS 只扩一层就停），漏掉间接相连的 0 和 2。DFS 的递归天然处理了传递性。
5. **两个不相交的二元组，`[[1,1,0,0],[1,1,0,0],[0,0,1,1],[0,0,1,1]]`** → 期望 2。容易错在 `count` 在 DFS 内部累加而不是外层，导致一个分量被数多次。

## 8. 面试追问与变体（3 条）

1. **追问：如果矩阵是稀疏的（n 很大但边很少），怎么优化？** 思路：把邻接矩阵转成邻接表，DFS/BFS 时间降到 O(n + E)，E 是边数；或者直接用并查集，只处理为 1 的边。
2. **追问：不用递归，怎么写？** 思路：用显式栈模拟 DFS，或改用 BFS 队列；也可以写并查集，`find` 带路径压缩，最后数根节点个数。
3. **追问：如果要返回每个省份包含哪些城市，而不只是个数？** 思路：DFS 时把访问到的顶点收集进当前列表，外层每触发一次 DFS 就 append 一个列表，最后返回列表的列表。
