## 1. 一句话本质

把 n 拆成若干个完全平方数之和，求**拆法里项数的最小值**——这是一个「用最少的步数凑出目标和」的最短路问题。

## 2. 读完题的第一反应

**朴素解法**：枚举所有拆分方式。n=12 时可以是 9+1+1+1、4+4+4、4+4+1+1+1+1……组合数随 n 爆炸，不可行。

退一步，一个自然的贪心想法是「每次减掉不超过当前值的最大平方数」。n=12 时 12-9=3，3-1-1-1，得 4 项；但正确答案是 4+4+4 共 3 项。**贪心在这里直接失效**，因为「先拿大的」不保证剩余部分好拆。这个反例很重要，它告诉我们：局部最优推不出全局最优，必须搜索或 DP。

**关键观察**：把问题看成一张图。节点是 0..n 的每个整数，从节点 i 出发，对每个平方数 s ≤ i，有一条边指向 i-s，边权为 1。题目问的就是「从 n 走到 0 的最少边数」。边权全为 1 的最短路，标准解法是 BFS——**第一次碰到 0 的那一层，就是答案**。这个转化把「组合枚举」变成了「逐层扩展」，是本题所有解法的共同起点。

另一个观察来自数论（拉格朗日四平方定理）：答案只可能是 1、2、3、4。这给了 O(√n) 的数学解法，但需要额外的判定定理，面试里通常作为加分项而非主线。

## 3. 从暴力到最优

**第一步：BFS 建模。** 以 n=12 为例。第 0 层 {12}；第 1 层 = {12-1, 12-4, 12-9} = {11, 8, 3}；第 2 层从这三个节点各减平方数，得到 {10,7,2, 7,4,-1, 2,-1,-6}，去重后 {10,7,2,4}；第 3 层从 4 出发减 4 得 0，命中。答案 3。瓶颈：每层节点数最坏 O(n)，每个节点枚举 O(√n) 个平方数，总 O(n√n)，n=10⁴ 时约 10⁶，能过，但不够漂亮。

**第二步：DP 消掉「层」的重复计算。** BFS 里同一个数会被多个父节点重复访问（上面 7 和 2 都出现了两次），去重靠 visited 集合。换成 DP：令 `dp[i]` = 凑出 i 的最少项数，则 `dp[i] = 1 + min(dp[i - s])`，s 取遍所有 ≤ i 的平方数。这是「按目标值从小到大填表」，每个 i 只算一次，天然消掉了重复。n=12 时：dp[1]=1, dp[2]=2, dp[3]=3, dp[4]=1, dp[5]=2, dp[8]=2, dp[9]=1, dp[12]=min(dp[11],dp[8],dp[3])+1 = min(3,2,3)+1 = 3。复杂度 O(n√n)，空间 O(n)。

**第三步：数学判定，O(√n)。** 依据三平方定理：n 能表示成 3 个平方数之和，当且仅当 n 不是 4^a(8b+7) 的形式。于是：
- 若 n 本身是完全平方数 → 1；
- 若 n = 4^a(8b+7) → 4；
- 若 n 能写成两个平方数之和（枚举 a 从 0 到 √n，检查 n-a² 是否平方）→ 2；
- 否则 → 3。

n=12：不是平方数；12 = 4·3，3 不是 8b+7 形式（b 需为整数，3=8b+7 无解），所以不是 4；12-0=12、12-1=11、12-4=8、12-9=3 都不是平方数，不是 2；故答案 3。n=13：13-4=9 是平方数，答案 2。这条路径把瓶颈从「枚举所有拆分」压到「枚举一个加数」，是本题的最优解。

## 4. 正确性：为什么不会漏、不会重

**BFS 版本的不变量**：队列中弹出的节点，其距离（已用平方数个数）单调不减。归纳证明：初始只有 n，距离 0；每次从距离 d 的节点扩展出的邻居距离为 d+1，入队顺序保证先处理完所有距离 d 的节点才处理 d+1。因此第一次弹出 0 时，其距离就是最短距离——若存在更短路径，0 会更早被弹出，矛盾。**不漏**：任何合法拆分对应图上一条从 n 到 0 的路径，BFS 会遍历所有可达节点。**不重**：visited 集合保证每个节点只入队一次，且入队时记录的距离就是最短距离（因为首次到达必然经过最少边数）。

**DP 版本的最优子结构**：任何凑出 i 的方案，取走其中一个平方数 s 后，剩下 i-s 的方案也必须是「最少项数」的，否则替换成更优的会得到更优的 i 的方案，矛盾。所以 `dp[i] = 1 + min dp[i-s]` 覆盖了所有最优解，且 min 只取合法 s，不会引入非法方案。**不重**：每个 i 只依赖更小的下标，填表顺序保证依赖已就绪。

**数学版本**：三平方定理是已证定理，四个分支互斥且穷尽（1、2、3、4 是全部可能值），所以判定逻辑不会漏也不会重。

## 5. 完整代码（Python）

```python
class Solution:
    def numSquares(self, n: int) -> int:
        # 数学判定版：O(sqrt(n))
        # 分支 1：n 本身是完全平方数
        r = int(n ** 0.5)
        if r * r == n:
            return 1

        # 分支 2：n = 4^a * (8b + 7) 时答案为 4
        m = n
        while m % 4 == 0:
            m //= 4
        if m % 8 == 7:
            return 4

        # 分支 3：n 能否写成两个平方数之和
        for a in range(1, int(n ** 0.5) + 1):
            b2 = n - a * a
            b = int(b2 ** 0.5)
            if b * b == b2:
                return 2

        # 分支 4：其余情况答案为 3
        return 3
```

如果面试官要求写通用 DP（不依赖数论），用下面这版，逻辑更直白：

```python
class Solution:
    def numSquares(self, n: int) -> int:
        # dp[i] 表示凑出 i 的最少完全平方数个数
        dp = [0] + [float('inf')] * n
        # 预生成所有不超过 n 的平方数
        squares = [i * i for i in range(1, int(n ** 0.5) + 1)]
        for i in range(1, n + 1):
            for s in squares:
                if s > i:
                    break          # 平方数超过 i，后面的更大，直接停
                dp[i] = min(dp[i], dp[i - s] + 1)
        return dp[n]
```

## 6. 复杂度

**数学版**：时间 O(√n)。分支 1 是 O(1)；分支 2 的 while 循环最多执行 log₄n 次，即 O(log n)；分支 3 枚举 a 从 1 到 √n，每次 O(1)，共 O(√n)。总时间由分支 3 主导，O(√n)。空间 O(1)，只用了几个整型变量。这里的 log n 来自「反复除以 4」的次数，√n 来自「枚举一个加数」。

**DP 版**：时间 O(n√n)。外层 i 走 n 次，内层平方数个数约 √n（因为 s ≤ i ≤ n，s 的取值个数是 √i ≤ √n）。空间 O(n)，dp 数组长度 n+1。这里的 n 来自「每个目标值都要填一次表」，√n 来自「每个目标值要试的平方数个数」。

## 7. 边界与反例（至少 4 条）

1. **n = 1** → 期望 1。容易错在：数学版分支 1 的 `r*r == n` 判断，若用浮点 `n**0.5` 在极大 n 时有精度问题，n=1 本身没问题，但提醒要用整数比较而非 `== 1.0`。
2. **n = 12** → 期望 3。容易错在：贪心会给出 4（9+1+1+1），必须用搜索/DP/数学判定，这是本题最经典的陷阱。
3. **n = 7** → 期望 4。7 = 4+1+1+1，也是 8b+7 中 b=0 的情形。容易错在：只写了 1/2/3 三个分支，忘了 4 这个分支，返回 3。
4. **n = 4** → 期望 1。容易错在：分支 2 的 while 循环把 4 除成 1，1 % 8 = 1 ≠ 7，正确跳过；但如果先判 4 再判平方数，顺序写反会误判。分支顺序必须是「先平方数，再 4^a(8b+7)」。
5. **n = 10000** → 期望 1（100²）。容易错在：DP 版 `float('inf')` 参与 `min` 没问题，但若用 `dp[i-s]+1` 且 dp 初值设 0 会全错；另外 n=10⁴ 时 DP 约 10⁶ 次操作，Python 能过但要注意别写成 O(n²)。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求输出具体的拆分方案，不只是个数？** 思路：DP 时额外记录 `choice[i]` = 选中的那个平方数，最后从 n 回溯到 0 输出。
2. **追问：如果平方数不能重复使用（每个平方数最多用一次）？** 思路：变成 0/1 背包，dp 维度加一维「已用平方数集合」或按平方数逐个做 0/1 更新，复杂度上升。
3. **追问：证明答案不超过 4。** 思路：拉格朗日四平方定理，任何正整数都是四个平方数之和；配合三平方定理说明何时恰好是 4。
