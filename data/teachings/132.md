## 1. 一句话本质

在字符串的所有「切成若干回文段」的方案里，找段数最少的那个，返回段数减一（即切几刀）。

## 2. 读完题的第一反应

**朴素解法**：枚举所有切法。一个长度 n 的串有 n-1 个「切/不切」的位置，共 2^(n-1) 种切法，对每种切法检查每段是不是回文。n 到 2000 时这是天文数字，直接死。

稍微聪明一点的暴力：DFS 从位置 0 开始，每次尝试切出一个回文前缀 `s[0:j]`，递归处理 `s[j:]`，取最小段数。这仍然是「枚举所有回文切分方案」，最坏情况（比如 `"aaaa...a"`，每个前缀都是回文）是指数级的。

**关键观察**：题目问的是「最少切几刀」，这是一个**最优化问题**，而且具有最优子结构——`s` 的最优切分，去掉最后一段回文后，前面那部分也一定是最优切分。为什么？反证：如果前面那部分有更少刀的切法，换上去整体就更少，矛盾。这就是动态规划的信号。

第二个观察：判断「某段是不是回文」这件事会被反复用到。与其每次 O(n) 去判，不如预处理出一张表 `is_pal[i][j]`，O(1) 查询。而这张表本身也能用 DP 递推出来（`s[i]==s[j]` 且内部是回文）。

所以思路链条是：**最优化 + 最优子结构 → DP；回文判断被反复查询 → 预处理回文表**。两件事都要做，缺一个复杂度就下不来。

## 3. 从暴力到最优

**第一步：定义状态。** 设 `dp[i]` = 把前缀 `s[0:i]`（长度 i，下标 0..i-1）切成全是回文段所需的**最少段数**。注意我定义的是「段数」不是「刀数」，最后答案要减一。这样定义的好处是递推时不用纠结边界上的 +1/-1。

**第二步：转移。** 枚举最后一段的起点 j（0 ≤ j < i），如果 `s[j:i]` 是回文，那么 `dp[i] = min(dp[i], dp[j] + 1)`。含义：前 j 个字符用 `dp[j]` 段搞定，再接上 `s[j:i]` 这一段。

**第三步：走一遍 `s = "aab"`。**

先预处理回文表（只列用到的）：
- `is_pal[0][0]=T`（"a"）
- `is_pal[1][1]=T`（"a"）
- `is_pal[2][2]=T`（"b"）
- `is_pal[0][1]`：s[0]==s[1]=='a'，且内部为空 → T（"aa"）
- `is_pal[1][2]`：s[1]='a' ≠ s[2]='b' → F
- `is_pal[0][2]`：s[0]='a' ≠ s[2]='b' → F

DP 过程（`dp[0]=0` 表示空串 0 段）：

| i | 枚举 j | s[j:i] | 回文? | 候选 dp[j]+1 | dp[i] |
|---|--------|--------|-------|--------------|-------|
| 1 | 0 | "a" | T | dp[0]+1=1 | 1 |
| 2 | 0 | "aa" | T | dp[0]+1=1 | 1 |
| 2 | 1 | "a" | T | dp[1]+1=2 | 1（更小，保留） |
| 3 | 0 | "aab" | F | — | ∞ |
| 3 | 1 | "ab" | F | — | ∞ |
| 3 | 2 | "b" | T | dp[2]+1=2 | 2 |

答案 `dp[3]-1 = 1`，和示例一致：切成 `["aa","b"]`，1 刀。

**瓶颈怎么被消掉的**：暴力是指数级枚举切法；DP 把「前缀的最优解」缓存下来，每个 i 只枚举 O(n) 个 j，配合 O(1) 的回文查询，总复杂度 O(n²)。回文表用递推 O(n²) 建好，避免了每次 O(n) 的判断，否则总复杂度会变成 O(n³)（n=2000 时 8×10⁹，超时）。

## 4. 正确性：为什么不会漏、不会重

**不变量**：处理完 `dp[i]` 时，`dp[i]` 等于前缀 `s[0:i]` 所有合法回文切分方案中段数的最小值。

**归纳证明**：

- 基础：`dp[0]=0`，空串 0 段，唯一方案，成立。
- 归纳步：假设对一切 `j < i`，`dp[j]` 都是前缀 `s[0:j]` 的最优段数。考虑 `s[0:i]` 的任一合法切分，它的最后一段必然是某个 `s[j:i]`（j 从 0 到 i-1），且这段是回文。该切分的段数 = 前面 `s[0:j]` 的段数 + 1 ≥ `dp[j] + 1`。我们对所有满足回文的 j 取 min，得到的 `dp[i]` 不大于任何合法方案的段数；同时每个候选 `dp[j]+1` 本身对应一个合法方案（`dp[j]` 的最优切分 + 最后一段），所以 `dp[i]` 也不小于最优值。两边夹住，`dp[i]` 恰为最优。

**不漏**：任何合法切分的最后一段一定被某个 j 枚举到（j 遍历了所有可能起点），所以最优方案不会漏掉。
**不重**：我们取 min，重复枚举同一个 j 不会影响结果；不同 j 对应「最后一段起点不同」，是不同方案，本来就该都考虑。

## 5. 完整代码（Python）

```python
class Solution:
    def minCut(self, s: str) -> int:
        n = len(s)
        if n <= 1:
            return 0

        # 第一步：预处理回文表 is_pal[i][j] 表示 s[i:j+1] 是否回文
        # 按区间长度从小到大递推：长度 1 必回文；长度 2 看两字符是否相等；
        # 更长则看两端字符相等且内部回文
        is_pal = [[False] * n for _ in range(n)]
        for i in range(n):
            is_pal[i][i] = True
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if s[i] == s[j]:
                    # 长度 2 时内部为空，视为回文；否则看内部
                    is_pal[i][j] = True if length == 2 else is_pal[i + 1][j - 1]

        # 第二步：dp[i] = 前缀 s[0:i] 切成全回文段的最少段数
        # dp[0] = 0（空串），答案 dp[n] - 1（段数减一 = 刀数）
        dp = [0] + [float('inf')] * n
        for i in range(1, n + 1):
            for j in range(i):
                # 最后一段是 s[j:i]，若为回文则可从 dp[j] 转移
                if is_pal[j][i - 1]:
                    dp[i] = min(dp[i], dp[j] + 1)

        return dp[n] - 1
```

关键逻辑说明：
- 回文表按 `length` 递增填，保证 `is_pal[i+1][j-1]` 在用到时已经算好（区间更短）。
- `dp` 初始化为 `inf`，`dp[0]=0` 是哨兵，让「整串就是一个回文」的情况能走 `dp[0]+1=1` 这条路。
- 返回 `dp[n]-1`：段数 1 对应 0 刀，段数 k 对应 k-1 刀。

## 6. 复杂度

**时间 O(n²)**：
- 回文表：外层 `length` 有 n 种，内层 i 平均约 n/2 个，合计约 n²/2 次 O(1) 操作 → O(n²)。
- DP：外层 i 有 n 个，内层 j 平均 i/2 个，合计约 n²/2 次 O(1) 操作 → O(n²)。
- 两项相加仍是 O(n²)。这里的 n 来自字符串长度，没有 log 项。

**空间 O(n²)**：`is_pal` 是 n×n 布尔矩阵，占主导；`dp` 是 O(n)。所以总空间 O(n²)。n=2000 时约 4×10⁶ 个布尔值，Python 里用 list of list 存 bool 大约几十 MB，可接受；若想省空间可用位运算或 `bytearray`，但面试一般不要求。

## 7. 边界与反例（至少 4 条）

1. **`s = "a"` → 0**：长度 1，代码里 `n<=1` 直接返回 0。容易错在忘记特判，导致 `dp[1]-1` 虽然也对（dp[1]=1），但若写成别的形式可能越界。
2. **`s = "ab"` → 1**：两个字符都不是回文整体，只能切成 `["a","b"]`。容易错在回文表长度 2 的判断：`s[0]!=s[1]` 时 `is_pal[0][1]=False`，DP 只能走 j=1 的 `"b"`，得 dp[2]=2，答案 1。若把长度 2 的内部判断写错（比如访问 `is_pal[1][0]` 越界），会崩。
3. **`s = "aaaa"` → 0**：整串回文，一刀不用。容易错在 DP 转移时只考虑「切一刀」而漏掉「整段就是回文」的情况——必须让 j=0 的候选 `dp[0]+1=1` 参与 min，答案 `1-1=0`。
4. **`s = "abac"` → 1**：切成 `["aba","c"]`。容易错在只检查「单字符」和「相邻两字符」的回文，漏掉长度 3 的 `"aba"`；回文表必须按长度递推覆盖所有区间。
5. **`s = "aab"` → 1**（官方示例）：验证「贪心切最长回文前缀」会失败吗？`"aa"` 是最长回文前缀，切完剩 `"b"`，得 1 刀，恰好对；但换成 `"aabbaa"` 之类贪心就可能不是最优。这提醒不能用贪心，必须 DP 取全局 min。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求返回具体的一种最优切分方案，而不只是刀数？**
   思路：DP 时额外记录 `pre[i]` = 让 `dp[i]` 取到最小的那个 j，最后从 n 往回跳，收集切点，再反转输出。

2. **追问：空间能不能从 O(n²) 降到 O(n)？**
   思路：回文表可以按「中心扩展」在 DP 外层 i 递增时同步维护，或者用 Manacher 预处理成 O(n) 查询结构；DP 本身只需一维。但实现复杂度上升，面试中先说清 O(n²) 方案再提优化即可。

3. **追问：如果允许把串切成「回文段」但要求段数恰好为 k，是否可行？**
   思路：把状态改成 `dp[i][t]` = 前缀 i 切成 t 段是否可行（布尔）或最小/最大段数，多一维 t，复杂度 O(n²k)，本质是同一套区间 DP 加一维。
