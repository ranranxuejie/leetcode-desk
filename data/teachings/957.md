## 1. 一句话本质

给定一个 8 位二进制状态和一个巨大的天数 n，求这个状态在「相邻两位相同则置 1，否则置 0」的确定性演化规则下，迭代 n 次后的结果——本质是**在有限状态空间里找循环节，把 n 次迭代压缩成 n mod 周期**。

## 2. 读完题的第一反应

**朴素解法**：写一个 `next_day(cells)` 函数，按规则逐位算出下一天，然后循环 n 次。复杂度 O(8n)，n 最大 10^9，也就是 8×10^9 次操作——在 Python 里必然超时。瓶颈不在单步（单步只有 8 位，很便宜），而在**天数 n 太大**。

**关键观察**：`cells.length == 8` 是题面明确给的约束。8 位二进制一共只有 2^8 = 256 种可能状态。而演化规则是**确定性的**——同一个状态永远产生同一个后继。这意味着：从初始状态出发，走不超过 257 步，必然撞上之前出现过的状态，从此进入循环。于是 n 再大也没用，我们只需要走到循环里，然后用 `(n - 进入循环前的步数) % 循环长度` 定位最终状态。

这个观察之所以能立刻落地，是因为「状态数有限 + 转移确定」这两个条件在题面上都成立：`cells[i] 为 0 或 1`、`cells.length == 8` 给了有限性，规则里没有任何随机性给了确定性。缺任何一个，找循环这招都不成立。

## 3. 从暴力到最优

**第一步：把「一天」写对。** 对第 i 位（1 ≤ i ≤ 6），新值 = `1 if cells[i-1] == cells[i+1] else 0`。第 0 位和第 7 位没有两个邻居，题面说「不存在两个相邻的房间」，按规则「否则空置」处理，所以新值恒为 0。这一步是 O(8)。

**第二步：发现状态会重复。** 用示例 1 走一遍，把每天的状态记下来（用元组表示）：

```
Day 0: (0,1,0,1,1,0,0,1)
Day 1: (0,1,1,0,0,0,0,0)
Day 2: (0,0,0,0,1,1,1,0)
Day 3: (0,1,1,0,0,1,0,0)
Day 4: (0,0,0,0,0,1,0,0)
Day 5: (0,1,1,1,0,1,0,0)
Day 6: (0,0,1,0,1,1,0,0)
Day 7: (0,0,1,1,0,0,0,0)
```

n=7 直接走 7 步就够，看不出循环的好处。但把 n 换成 10^9，我们就不能走 10^9 步了。注意 Day 0 到 Day 7 这 8 个状态互不相同，说明这个例子里循环还没闭合——继续走下去，最多再走 248 步一定闭合（因为总共只有 256 个状态）。

**第三步：用「状态 → 首次出现天数」的字典定位循环。** 维护 `seen = {状态: 天数}`。每走一步先查 `seen`：没出现过就记录；出现过，说明从 `seen[状态]` 到当前天构成了一个环，环长 = `当前天 - seen[状态]`。此时剩余天数 `n - 当前天` 可以对这个环长取模，直接跳到答案。

具体到示例 1，假设 n = 10^9：走到某一天（比如第 k 天）发现状态重复，环长 L，那么答案就是「从当前状态再走 `(n - k) % L` 步」的结果。因为环内状态是周期重复的，走 L 步回到原地，走 `(n-k) mod L` 步和走 `n-k` 步等价。

**瓶颈怎么被消掉的**：原来 O(n) 的循环被压成 O(256 + L) ≤ O(512) 的「找环 + 环内定位」，n 只出现在一次取模里，不再出现在循环次数里。

## 4. 正确性：为什么不会漏、不会重

**不变量 1（确定性）**：`next_day` 是纯函数，同一输入必得同一输出。所以从初始状态出发的演化序列是一条「单链」——每个状态只有一个后继。这条链要么一直不重复（不可能，状态只有 256 个），要么在某个位置第一次撞上之前出现过的状态，之后完全周期化。

**不变量 2（首次重复即环起点）**：设第一次重复发生在第 t 天，重复到的旧状态首次出现在第 s 天（s < t）。因为链是单链，s 之后到 t-1 的这段状态互不相同，且 t 的后继必然等于 s 的后继（确定性），所以 [s, t) 构成一个长度 L = t - s 的环，且 s 之前的部分是「尾巴」，不会再次进入。这保证了「用 `(n - t) % L` 定位」不会算错——n 若落在尾巴上（n < t），直接返回第 n 天的状态；n 若落在环上，取模后落在环内正确位置。

**为什么不会漏**：我们逐天走并记录，直到第一次重复才停，所以 s 和 t 都是精确的首次值，不存在「跳过某个状态导致环长算错」的可能。

**为什么不会重**：字典以状态为键，同一状态只记录首次出现天数，后续再遇到直接触发循环判定，不会重复计算。

## 5. 完整代码（Python）

```python
class Solution:
    def prisonAfterNDays(self, cells: list[int], n: int) -> list[int]:
        def next_day(state: tuple) -> tuple:
            # 第 0 位和第 7 位没有两个邻居，按规则恒为 0
            nxt = [0] * 8
            for i in range(1, 7):
                # 左右邻居相同则占用，否则空置
                nxt[i] = 1 if state[i - 1] == state[i + 1] else 0
            return tuple(nxt)

        state = tuple(cells)
        seen = {}          # 状态 -> 首次出现的天数
        day = 0

        while day < n:
            if state in seen:
                # 第一次撞上旧状态：环长 = 当前天 - 首次出现天
                cycle_len = day - seen[state]
                # 剩余天数对环长取模，直接跳到答案所在的天
                remain = (n - day) % cycle_len
                for _ in range(remain):
                    state = next_day(state)
                return list(state)
            # 记录当前状态首次出现的天数，然后走一天
            seen[state] = day
            state = next_day(state)
            day += 1

        # n 很小，没进循环就走完了
        return list(state)
```

关键逻辑说明：`while day < n` 保证 n 小于循环长度时直接逐天走完；`if state in seen` 在**走之前**检查，所以 `seen[state]` 一定是更早的天数，`cycle_len` 恒为正；取模后只走 `remain < cycle_len` 步，不会死循环。

## 6. 复杂度

**时间**：O(min(n, 256) + L)，其中 L ≤ 256 是环长。找环阶段最多走 256 步（状态总数 2^8），每步 O(8)；环内定位最多走 L 步，每步 O(8)。所以总操作数 ≤ 512×8，与 n 无关。n 只贡献一次取模运算 O(1)。**没有 log n**——这题不涉及二分或快速幂，n 的「大」被循环节直接吃掉了。

**空间**：O(256)，字典最多存 256 个状态，每个状态是长度 8 的元组。与 n 无关。

## 7. 边界与反例（至少 4 条）

1. **n = 1**：`cells = [1,1,1,1,1,1,1,1], n = 1` → 期望 `[0,0,0,0,0,0,0,0]`。容易错在把第 0/7 位也按「邻居相同」算成 1——它们没有两个邻居，必须置 0。

2. **全 0 输入**：`cells = [0,0,0,0,0,0,0,0], n = 10^9` → 期望全 0。容易错在找环时把「第 0 天状态」和「第 1 天状态」搞混：全 0 走一天还是全 0，`seen` 里第 0 天已记录，第 1 天立刻触发循环，`cycle_len = 1`，取模后 remain = 0，直接返回全 0，正确。

3. **n 恰好等于环起点**：`cells = [0,1,0,1,1,0,0,1], n = 0`（虽然题面 n ≥ 1，但测试常含 0）→ 期望原样返回。代码里 `while day < n` 不进入，直接返回 `list(state)`，正确。若把循环判定写在走之后，n=0 时可能误走一步。

4. **n 落在尾巴上而非环上**：某些初始状态进入环前有若干天「尾巴」。若 n 小于尾巴长度，必须返回第 n 天的真实状态，不能取模。代码里 `while day < n` 保证 n 没到环起点时逐天走，不会提前取模。

5. **状态重复但环长算错**：若用 `seen` 记录「最近一次」而非「首次」，环长会算成 1 或错误值。必须记录首次出现天数。

## 8. 面试追问与变体（3 条）

1. **追问：如果 cells 长度不是 8，而是 100，n 仍是 10^9，怎么办？** 思路：状态空间变成 2^100，找环不再可行；但转移是线性的（模 2 加法），可以用矩阵快速幂或位运算 + 快速幂，O(L^3 log n) 或 O(L log n)。

2. **追问：如果规则改成「邻居不同则占用」，答案会变吗？** 思路：规则取反等价于整体异或 1 再演化，循环结构不变，但边界处理要重新确认——第 0/7 位仍恒为 0，因为「没有两个邻居」的条件没变。

3. **追问：如何证明循环一定在 256 步内出现？** 思路：鸽巢原理——257 个状态（第 0 天到第 256 天）放进 256 个格子，必有两个相同；又因确定性，首次重复即闭合，所以环起点 ≤ 256。
