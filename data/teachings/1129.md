## 1. 一句话本质

在有向图上求从 0 出发、**边颜色必须严格交替**的最短路，且"到达某个点"这件事本身要区分"最后一步是红边还是蓝边"两种状态。

## 2. 读完题的第一反应

朴素想法：从 0 开始做 BFS，每层扩展时记住"上一条边是什么颜色"，下一步只能走另一种颜色。这思路方向是对的，问题出在**状态怎么定义**。

如果只把"节点"当状态，就会卡住：节点 1 可能通过红边到达（下一步只能走蓝），也可能通过蓝边到达（下一步只能走红），这两种到达方式对后续路径的影响完全不同。只记 `dist[1]` 一个数，等于把两种状态混成一个，BFS 的"第一次访问即最短"就不再成立——你可能用红边先到了 1，把 `dist[1]` 占了，但真正能继续往下走的是"蓝边到 1"那条路。

关键观察：**决定下一步能走什么颜色的，只有"上一条边的颜色"**，而颜色只有两种。所以把状态从 `节点` 升级成 `(节点, 上一条边的颜色)`，一共 `2n` 个状态。在这个扩展后的状态图上，每条边都是"颜色交替"的合法转移，问题就退化成**无权图上的标准 BFS**。这一步想通了，剩下的就是套 BFS 模板。

## 3. 从暴力到最优

**暴力**：枚举所有从 0 出发的路径，检查颜色是否交替，取最短。路径数指数级，`n=100` 直接爆炸。

**第一层优化——BFS 而非枚举**：因为每条边代价都是 1，"最短"等价于"BFS 层数最小"。但如上一节所说，只按节点 BFS 会漏状态。

**第二层优化——状态扩展**：状态设为 `(u, c)`，`c ∈ {0,1}` 表示"到达 u 时最后一条边的颜色"（约定 0=红，1=蓝）。从 `(u,c)` 出发，只能走颜色为 `1-c` 的边到 `(v, 1-c)`。起点特殊：0 号点还没走过任何边，所以 `(0,0)` 和 `(0,1)` 都作为起点入队，距离都是 0（这样第一步红蓝都能走）。

**小例子走一遍**：`n=3, red=[[0,1],[1,2]], blue=[]`。

- 初始队列 `[(0,0), (0,1)]`，`dist[0][0]=dist[0][1]=0`。
- 弹出 `(0,0)`（最后是红边，下一步只能走蓝）：蓝边表里 0 没有出边，无扩展。
- 弹出 `(0,1)`（最后是蓝边，下一步只能走红）：红边 0→1，得到 `(1,0)`，`dist[1][0]=1`，入队。
- 弹出 `(1,0)`：下一步走蓝，1 无蓝出边，无扩展。
- 队列空。答案：`answer[0]=0`，`answer[1]=min(dist[1][0], dist[1][1])=1`，`answer[2]=-1`。

对照示例 1 输出 `[0,1,-1]`，吻合。注意节点 2 明明有红边 1→2，但到 1 时最后是红边，下一步必须蓝，蓝边不存在，所以 2 不可达——这正是"只记节点"会算错的地方。

## 4. 正确性：为什么不会漏、不会重

**不变量**：BFS 队列中，状态按距离非递减排列；每个状态 `(u,c)` 第一次被访问时的距离，就是到达该状态的最短距离。

论证分两点。

*不会漏*：任何一条合法的交替路径，从 0 出发，逐步对应状态序列 `(0, c0) → (v1, c1) → ...`，其中相邻状态颜色相反。这条状态序列在扩展图上是一条真实路径，BFS 一定会沿它扩展，所以终点状态会被访问到。答案取 `min(dist[x][0], dist[x][1])`，覆盖了"以红边结尾"和"以蓝边结尾"两种到达方式，不漏。

*不会重（且最短）*：扩展图是无权图，BFS 按层扩展的性质保证第一次出队/入队时距离最小。我们用 `visited`（即 `dist != -1`）阻止同一状态二次入队：若 `(u,c)` 已被访问，说明已存在一条不更长的路径到达它，再入队只会得到不更短的距离，丢弃不影响最优性。这里"重"指的是**状态重复**，不是节点重复——同一节点允许以两种颜色各被访问一次，这是必要的，不是冗余。

## 5. 完整代码（Python）

```python
from collections import deque

class Solution:
    def shortestAlternatingPaths(self, n, redEdges, blueEdges):
        # 建两张邻接表：red_adj 存红边，blue_adj 存蓝边
        red_adj = [[] for _ in range(n)]
        blue_adj = [[] for _ in range(n)]
        for u, v in redEdges:
            red_adj[u].append(v)
        for u, v in blueEdges:
            blue_adj[u].append(v)

        # dist[u][c]：到达 u、且最后一条边颜色为 c 的最短距离
        # c=0 表示最后走红边，c=1 表示最后走蓝边；-1 表示未访问
        dist = [[-1, -1] for _ in range(n)]

        # 起点 0 没有"上一条边"，两种颜色状态都置 0，使第一步红蓝皆可
        dist[0][0] = 0
        dist[0][1] = 0
        q = deque([(0, 0), (0, 1)])

        while q:
            u, c = q.popleft()
            # 下一步必须走相反颜色：c=0 走蓝，c=1 走红
            nxt_adj = blue_adj[u] if c == 0 else red_adj[u]
            nc = 1 - c
            for v in nxt_adj:
                if dist[v][nc] == -1:          # 该状态首次到达
                    dist[v][nc] = dist[u][c] + 1
                    q.append((v, nc))

        # 每个节点取两种到达方式中的较小值；都不可达则为 -1
        ans = []
        for u in range(n):
            d0, d1 = dist[u][0], dist[u][1]
            if d0 == -1 and d1 == -1:
                ans.append(-1)
            elif d0 == -1:
                ans.append(d1)
            elif d1 == -1:
                ans.append(d0)
            else:
                ans.append(min(d0, d1))
        return ans
```

## 6. 复杂度

设红边数 `R`、蓝边数 `B`，`E = R + B`。

- **时间** `O(n + E)`：状态总数 `2n`，每个状态出队一次；每个状态扩展时遍历其对应颜色的出边，红边只会从"最后是蓝"的状态被遍历一次，蓝边只会从"最后是红"的状态被遍历一次，所以每条边最多被检查一次。建图 `O(E)`，最后汇总 `O(n)`。
- **空间** `O(n + E)`：两张邻接表共 `O(E)`，`dist` 是 `2n` 个格子即 `O(n)`，队列最多装 `2n` 个状态即 `O(n)`。

没有 `log` 项，因为全程没有排序或堆操作，纯 BFS。

## 7. 边界与反例（至少 4 条）

1. **`n=1, red=[], blue=[]`** → `[0]`。容易错在把起点也当成"需要一条边才能到达"，返回 `[-1]`。起点距离恒为 0。
2. **`n=2, red=[[0,1]], blue=[[0,1]]`** → `[0,1]`。平行边（同向同起点的红蓝各一条）容易错在建图时去重或只保留一种颜色，导致第一步只能走一种颜色。两张表分开存即可。
3. **`n=2, red=[[0,0]], blue=[[0,1]]`** → `[0,1]`。自环容易错在：走红自环 0→0 后状态变 `(0,0)`，下一步必须蓝，正好能走 0→1。若把自环当无效边删掉，就会漏掉这条合法路径。
4. **`n=3, red=[[0,1],[1,2]], blue=[[1,0]]`** → 到 2 的路径 0→1(红)→0(蓝)→1(红)→2(红) 不合法（最后两步都红）；实际 0→1(红) 后只能蓝，1 的蓝边回 0，再红到 1，循环，永远到不了 2，答案 `[0,1,-1]`。容易错在只按节点判重，以为"1 访问过就结束"，其实 `(1,0)` 和 `(1,1)` 是不同状态，需要分别处理。
5. **`n=2, red=[], blue=[[0,1]]`** → `[0,1]`。只有蓝边时，起点必须能走蓝边，靠 `dist[0][1]=0` 这个初始化才成立；若只初始化 `dist[0][0]`，第一步就被迫走蓝（因为 `c=0` 走蓝），看似也对，但语义混乱，遇到"只有红边"就崩。两个起点状态都置 0 才对称安全。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求"红蓝红蓝…"必须以红边开头（不能蓝开头），怎么改？** 思路：只把 `(0,0)` 入队（最后是红边意味着下一步走蓝，等价于第一步走蓝）——按需调整初始入队的状态即可，BFS 主体不动。
2. **追问：如果边带权（正权），还要求颜色交替的最短路？** 思路：状态图不变，把 BFS 换成 Dijkstra，用堆维护 `(距离, 节点, 颜色)`，复杂度变 `O(E log n)`。
3. **追问：不只两种颜色，而是 k 种颜色且要求"相邻边颜色不同"？** 思路：状态扩成 `(u, 上一条边颜色)` 共 `kn` 个，转移时枚举所有"不同于当前颜色"的出边，复杂度 `O(kE)`；若要求"按固定颜色序列循环"，则状态是 `(u, 序列下标 mod k)`。
