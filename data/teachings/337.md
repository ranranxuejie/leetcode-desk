## 1. 一句话本质

在二叉树上选一个节点集合，要求集合内任意两个节点都不直接相连（父子关系），求集合节点权值和的最大值。

## 2. 读完题的第一反应

最朴素的思路：枚举所有合法的节点集合，取最大权值和。合法集合的数量是指数级的——每个节点都有"选/不选"两种状态，虽然有父子不能同选的约束，但合法组合仍然随节点数指数增长。节点数上限是 10^4，这条路直接死掉。

换个角度想：为什么暴力会重复计算？因为同一个子树会被反复求解。比如根节点选不选，会影响左右子树的决策，但左右子树内部的决策和外部无关——一棵子树能贡献的最大值，只取决于"它的根节点选不选"这一个外部信息。这就是关键观察：**每个节点只需要向上汇报两种答案**——"我选的时候，我这棵子树最多能拿多少"和"我不选的时候，我这棵子树最多能拿多少"。父节点拿到这两个数就能做决策，不需要知道子树内部长什么样。

这个观察把"指数级枚举"压缩成"每个节点算两个数"，因为子树的最优解可以被父节点直接复用，不需要重新展开。

## 3. 从暴力到最优

**暴力版本**：对每个节点，递归地尝试"选它"和"不选它"两种可能。

- 选当前节点：左右子节点都不能选，但左右子节点的子节点可以选。于是需要递归到"孙子层"。
- 不选当前节点：左右子节点各自可以选或不选，取较大值。

写成递归大概是：

```
rob(node):
    if node is None: return 0
    选 = node.val + rob(node.left.left) + rob(node.left.right)
                    + rob(node.right.left) + rob(node.right.right)
    不选 = rob(node.left) + rob(node.right)
    return max(选, 不选)
```

瓶颈在哪？`rob(node.left)` 和 `rob(node.left.left)` 会被反复调用。以一条链为例：算根节点时调了 `rob(左子)`，算左子时又调了 `rob(左左)`，而根节点算"选"的分支里也调了 `rob(左左)`——同一个节点被算了很多次。最坏情况（链状树）复杂度退化到指数级。

**关键优化**：让每个节点只被访问一次，返回一对值 `(选当前节点的最优, 不选当前节点的最优)`。父节点直接用这对值，不再递归展开。

**小例子走一遍**：`root = [3,2,3,null,3,null,1]`，结构是：

```
        3
       / \
      2   3
       \   \
        3   1
```

从叶子往上算，每个节点返回 `(选, 不选)`：

- 节点 3（2 的右子，叶子）：选=3，不选=0 → `(3, 0)`
- 节点 2：选 = 2 + 0（左子为空贡献 0，右子不选贡献 0）= 2；不选 = 左子最优 + 右子最优 = 0 + max(3,0) = 3 → `(2, 3)`
- 节点 1（3 的右子，叶子）：`(1, 0)`
- 节点 3（根的右子）：选 = 3 + 0 + 0 = 3；不选 = 0 + max(1,0) = 1 → `(3, 1)`
- 根节点 3：选 = 3 + 左子不选(3) + 右子不选(1) = 7；不选 = 左子最优 max(2,3)=3 + 右子最优 max(3,1)=3 = 6 → `(7, 6)`

最终 `max(7, 6) = 7`，和示例一致。注意根节点"选"的时候用的是左右子树的"不选"值，这正是父子不能同选约束的体现。

## 4. 正确性：为什么不会漏、不会重

用**不变量**来论证。定义：对任意节点 `u`，函数返回的二元组 `(take, skip)` 满足：

- `take` = 在"`u` 被选中"的前提下，以 `u` 为根的子树能取得的最大权值和；
- `skip` = 在"`u` 不被选中"的前提下，以 `u` 为根的子树能取得的最大权值和。

**归纳证明**：

基础情况：`u` 为空，返回 `(0, 0)`，空树没有可选节点，两种前提下的最优都是 0，成立。

归纳步：假设 `u` 的左右子节点 `l`、`r` 都满足不变量，返回 `(take_l, skip_l)` 和 `(take_r, skip_r)`。

- 若 `u` 被选，则 `l`、`r` 都不能被选（直接相连会报警），所以左右子树只能取 `skip_l`、`skip_r`。此时子树最优 = `u.val + skip_l + skip_r`，这就是 `take`。
- 若 `u` 不被选，则 `l`、`r` 各自可以选也可以不选，互不影响（它们之间没有边），所以左右子树各自取 `max(take, skip)`。此时子树最优 = `max(take_l, skip_l) + max(take_r, skip_r)`，这就是 `skip`。

两种前提穷尽了 `u` 的所有状态，且每种状态下左右子树的决策相互独立、各自取到了最优，所以不会漏掉任何合法方案。又因为每个节点只被计算一次（后序遍历，算完即返回），不存在重复计算。归纳成立，根节点返回的 `max(take, skip)` 就是全局最优。

## 5. 完整代码（Python）

```python
class Solution:
    def rob(self, root) -> int:
        # 返回 (选当前节点的最优, 不选当前节点的最优)
        def dfs(node):
            if node is None:
                # 空树：选不选都是 0
                return (0, 0)

            # 后序遍历：先拿到左右子树的两组答案
            take_l, skip_l = dfs(node.left)
            take_r, skip_r = dfs(node.right)

            # 选当前节点：左右子节点都不能选，只能取它们的 skip
            take = node.val + skip_l + skip_r
            # 不选当前节点：左右子节点各自选或不选取最大，互不影响
            skip = max(take_l, skip_l) + max(take_r, skip_r)

            return (take, skip)

        take_root, skip_root = dfs(root)
        # 根节点选或不选，取较大者
        return max(take_root, skip_root)
```

关键逻辑说明：`dfs` 是后序遍历，先递归左右子树拿到 `(take, skip)` 二元组，再在当前节点合并。`take` 用子树的 `skip`（因为父子不能同选），`skip` 用子树的 `max`（因为子节点选不选都合法）。每个节点只进一次 `dfs`，天然避免重复计算。

## 6. 复杂度

**时间 O(n)**：`n` 是节点数。每个节点恰好被 `dfs` 访问一次，每次做常数次加法和比较（`take` 一次加法链、`skip` 两次 `max` 加一次加法），所以总操作数和 `n` 成正比。这里没有 `log n` 的项，因为不是平衡树上的分治——即使树退化成链，每个节点仍只访问一次。

**空间 O(h)**：`h` 是树高。递归调用栈的深度等于树高，每层栈帧存常数个变量。最坏情况（链状树）`h = n`，空间 O(n)；最好情况（平衡树）`h = log n`，空间 O(log n)。题目节点数上限 10^4，递归深度最多 10^4，Python 默认递归限制约 1000，实际提交时若遇到深链可能需要 `sys.setrecursionlimit`，但力扣环境通常已放宽。

## 7. 边界与反例（至少 4 条）

1. **单节点 `[5]`** → 期望 5 → 容易错写成返回 0 或漏掉 `max` 直接返回 `take`（虽然这里 `take=5, skip=0`，`max` 恰好对，但如果只返回 `skip` 就错了）。
2. **两个节点 `[3,4]`（根 3，左子 4）** → 期望 4 → 容易错：以为根必须选，返回 3；正确做法是比较 `take=3` 和 `skip=4`，取 4。
3. **全零树 `[0,0,0]`** → 期望 0 → 容易错：某些实现用 `-1` 初始化或把 `None` 当 0 处理不当，可能返回负数或异常；本代码空树返回 `(0,0)`，安全。
4. **链状树 `[1,2,3,4]`（一路左子）** → 期望 `max(1+3, 2+4) = 6` → 容易错：递归深度达到 4，若节点数到 10^4 且是链，可能触发递归深度限制；另外容易错在只考虑隔层选，漏掉"选 2 和 4"这种方案。
5. **根值很小但子树很大 `[1,100,100]`** → 期望 200 → 容易错：贪心地选根（1）导致只能拿 1；正确是放弃根，拿两个子节点 100+100。

## 8. 面试追问与变体（3 条）

1. **追问：如果树不是二叉树，而是多叉树呢？** 思路：`dfs` 返回 `(take, skip)`，`take = node.val + sum(所有孩子的 skip)`，`skip = sum(所有孩子的 max(take, skip))`，逻辑完全一样，只是把两个孩子的合并改成遍历孩子列表。
2. **追问：如果限制"不能选距离小于等于 2 的节点"（即隔代也不能同选）呢？** 思路：状态需要扩展，每个节点返回三种状态（选、不选但父选、不选且父不选），或者用树上 DP 加距离维度，本质是状态机 DP 在树上的推广。
3. **追问：如果要求输出具体选了哪些节点，而不只是最大值？** 思路：在 `dfs` 返回 `(take, skip)` 的同时记录决策来源（选的时候来自孩子的 skip，不选的时候来自孩子的 max 分支），最后从根回溯重建方案。

## 9. 举一反三（2-3 道同类题）

1. **打家劫舍 I（198）**：线性数组上不能选相邻元素，和本题共同点是"相邻不能同选"的约束，区别是结构从树变成数组，可用一维 DP 滚动变量。
2. **打家劫舍 II（213）**：环形数组，共同点是相邻约束，区别是首尾相连需要分"选首不选尾"和"不选首"两种情况各跑一次线性 DP。
3. **二叉树的最大路径和（124）**：同样是在二叉树上做后序 DFS、每个节点向上汇报"经过我的最优值"，共同点是"子树答案可被父节点复用"的树形 DP 思想。
