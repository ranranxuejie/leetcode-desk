## 1. 一句话本质

对树中**每一个**节点，把它的左右孩子互换——注意是每个节点都换，不是只换根。

## 2. 读完题的第一反应

**朴素解法**：把整棵树按层序读成一个数组，反转数组，再按层序重建一棵树。这能过，但卡在两处：一是你得额外维护「数组下标 → 树节点」的映射关系（层序数组里空位怎么表示、下标怎么算父子），二是重建时每个节点都要重新 `new` 一遍，空间和时间都多了一层常数，而且代码里全是下标运算，容易写错。

**关键观察**：看示例 1，输入 `[4,2,7,1,3,6,9]`，输出 `[4,7,2,9,6,3,1]`。根 4 没动，它的左子树 `[2,1,3]` 和右子树 `[7,6,9]` 整体对调了；而对调之后，`[7,6,9]` 内部又变成了 `[7,9,6]`——也就是 7 的左右孩子 6、9 也换了。这说明「翻转」这个操作对**子树是自相似的**：翻转整棵树 = 先翻转左子树、再翻转右子树、最后交换根的左右指针。这个自相似性直接指向递归，而且它告诉你：不需要任何额外的数据结构来记录「谁该去哪」，交换指针这个动作本身就完成了搬运。

## 3. 从暴力到最优

**第一步（暴力）**：层序收集 → 反转 → 重建。

拿示例 2 走一遍：`root = [2,1,3]`。

- 层序收集：`nodes = [2, 1, 3]`
- 反转：`[3, 1, 2]`
- 重建：新根取 `3`，它的左孩子取 `1`，右孩子取 `2` → 得到 `[3,1,2]`

但正确答案是 `[2,3,1]`——根还是 2。所以「整体反转数组」是错的，因为层序数组里根永远在下标 0，反转会把它挪走。你得改成「根不动，只反转每层的兄弟对」，那下标计算立刻变复杂：第 k 层有 2^k 个位置，兄弟对是 (2i, 2i+1) 互换……这就是瓶颈：**用数组下标去模拟树结构，把「交换两个孩子」这个本来 O(1) 的动作，变成了需要推导下标的动作**。

**第二步（关键跳跃）**：既然树本身就是用指针表达的，为什么还要绕道数组？直接在指针上做交换。

还是 `[2,1,3]`：

- 进入节点 2，先递归翻转左子树（节点 1，叶子，左右都是 None，交换后还是 None，返回 1）
- 再递归翻转右子树（节点 3，同理返回 3）
- 回到节点 2，交换：`2.left, 2.right = 3, 1`
- 返回 2

结果 `[2,3,1]`，和期望一致。整个过程中没有任何数组、没有新建节点，每个节点只被访问一次。

**第三步（为什么这就是最优）**：翻转必须触及每个节点——因为每个节点的左右指针都要交换，漏掉任何一个，那棵子树就是没翻的。所以下界是 Ω(n)，而上面的递归正好是每个节点 O(1) 工作，达到下界。

## 4. 正确性：为什么不会漏、不会重

用**不变量**说：定义「以 x 为根的子树已被正确翻转」为——该子树的结构等于原树镜像，且 x 的左右孩子已互换。

递归的归纳基础：空树（`None`）翻转后仍是空树，不变量成立。

归纳步：假设对任意规模小于当前子树的树，递归调用返回的子树都满足不变量。对以 `root` 为根的树，先递归翻转 `root.left` 得到镜像后的左子树 L'，再翻转 `root.right` 得到 R'，然后执行 `root.left, root.right = R', L'`。此时 `root` 的左指针指向原右子树的镜像、右指针指向原左子树的镜像，正是整棵树镜像的定义，不变量成立。

**不会漏**：每个非空节点都会被执行一次交换语句，因为递归只在 `root is None` 时提前返回，其余情况必然走到交换那一行。

**不会重**：每个节点只属于一条从根出发的路径，父节点调用一次、子节点被调用一次，没有第二条路径能再次到达它（树无环、每个节点只有一个父亲）。

## 5. 完整代码（Python）

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def invertTree(self, root: TreeNode) -> TreeNode:
        # 递归出口：空节点没有孩子可换，直接返回
        if root is None:
            return None

        # 先递归处理两棵子树，拿到它们各自的镜像结果
        # 顺序无所谓：先左后右、先右后左都对，因为两步互不依赖
        left_inverted = self.invertTree(root.left)
        right_inverted = self.invertTree(root.right)

        # 把镜像后的右子树挂到左边，镜像后的左子树挂到右边
        # 这一步是"翻转"真正发生的地方，只改指针，不新建节点
        root.left = right_inverted
        root.right = left_inverted

        # 返回当前根，让上层调用者把它挂回去
        return root
```

如果面试官允许原地改、想写得更紧凑，交换那两行可以合并成一行元组赋值：

```python
        root.left, root.right = self.invertTree(root.right), self.invertTree(root.left)
```

但注意：Python 会先算完右边两个递归调用再赋值，所以这行是安全的；换成某些语言（比如 C++ 里手写 `swap(root->left, root->right)` 之后再递归）就要小心顺序。教学时建议先写四行版本，把「先递归、后交换」讲清楚，再展示一行版本。

## 6. 复杂度

**时间 O(n)**：n 是节点数。每个非空节点恰好进入函数一次，函数体内的工作是常数次指针操作（两次递归调用本身不算工作，算在子节点头上），所以总工作量正比于节点数。注意这里**没有 log n 项**——虽然树高是 O(log n)（平衡时），但递归是「分叉」的，总调用次数是节点总数而不是树高。

**空间 O(h)**，h 是树高。空间全部来自递归调用栈：最深的一条链上同时存活的栈帧数等于树高。平衡树 h = O(log n)，退化成链表时 h = O(n)。除栈之外没有额外分配（不新建节点、不用辅助数组），所以空间就是 O(h)。如果面试官追问「能不能 O(1) 空间」，答案是迭代版（用栈或队列）也需要 O(n) 或 O(h) 的容器，真正 O(1) 需要 Morris 遍历那套线索二叉树技巧，本题没必要。

## 7. 边界与反例（至少 4 条）

1. **输入 `[]`** → 期望 `[]`。容易错在：没写 `root is None` 的出口，直接访问 `root.left` 抛 `AttributeError`。示例 3 就是在提醒你这个出口必须有。

2. **输入 `[1]`（单节点）** → 期望 `[1]`。容易错在：以为「翻转」会改变什么，或者写了出口但返回了 `None` 而不是 `root`，导致整棵树丢失。

3. **输入 `[1,2]`（只有左孩子）** → 期望 `[1,null,2]`。容易错在：只交换了值没交换指针，或者交换时写成 `root.left = root.left` 这种笔误。这题考的就是「左孩子要挪到右边去」，单边树最能暴露指针写反。

4. **输入 `[1,2,3,4]`（左子树有左孩子，右子树为空）** → 期望 `[1,3,2,null,null,null,4]`。容易错在：只交换了根的孩子，忘了递归进子树，结果 4 还挂在 2 的左边。这题必须「每个节点都换」，示例 1 的 `[1,3,6,9]` → `[9,6,3,1]` 就是在提示这一点。

5. **输入 `[1,2,3,4,5,6,7]`（满二叉树）** → 期望 `[1,3,2,7,6,5,4]`。容易错在：交换完根就以为完事，或者递归时把 `left_inverted` / `right_inverted` 挂反了（挂成 `root.left = left_inverted`），结果树没变。

## 8. 面试追问与变体（3 条）

1. **追问：不用递归，用迭代怎么写？** 思路：用队列做 BFS，每次出队一个节点就交换它的左右孩子，然后把非空孩子入队；或者用栈做 DFS，弹栈时交换、再把孩子压栈。核心不变——每个节点交换一次。

2. **追问：判断两棵树是否互为镜像（对称二叉树，题号 101）？** 思路：写辅助函数 `check(a, b)`，比较 `a.val == b.val` 且 `check(a.left, b.right)` 且 `check(a.right, b.left)`，注意是交叉比较，不是同侧比较。

3. **追问：这题和「翻转二叉树的某一层」有什么区别？** 思路：只翻某一层就要带深度参数，在递归时判断当前深度是否等于目标层，等于才交换，其余层原样返回；本质是把「无条件交换」改成「条件交换」。

## 9. 举一反三（2-3 道同类题）

- **对称二叉树（101）**：同样利用「左右子树互为镜像」的自相似结构，只是把「翻转」换成「比较」，递归骨架几乎一样。
- **相同的树（100）**：同样是双指针递归遍历两棵树，区别在于本题是「自己和自己」的镜像关系，那题是「两棵独立树」的相等关系。
- **二叉树的直径（543）**：同样需要「先递归子树、再在根处做合并」的后序思路，本题合并的是指针交换，那题合并的是左右深度之和。
