## 1. 一句话本质

数出矩阵里「连通的 X 块」有多少个，其中连通只算上下左右四个方向。

## 2. 读完题的第一反应

**朴素解法**：遍历每个格子，遇到 `'X'` 就做一次 DFS/BFS，把整艘战舰的所有格子标记为已访问，计数加一。复杂度 O(m·n)，每个格子最多进一次队列。

它卡在哪？其实**不卡**——O(m·n) 已经是理论下界，因为你至少要把每个格子看一遍。真正的麻烦在于：DFS 需要一个 `visited` 矩阵，额外空间 O(m·n)；而且面试官在进阶里明确要求「一次扫描 + O(1) 额外空间 + 不修改 board」。

**关键观察**：题面里有一句容易被略过的话——「两个舰队之间至少有一个水平或垂直的空格分隔」。这句话是整个题的钥匙。它保证了任意两艘战舰**不会上下左右相邻**。于是「一艘战舰」在矩阵里就是一个极大的、四连通的 `'X'` 块，而每个块必然有且仅有一个「最左上」的格子。

什么叫最左上？对某个 `'X'` 格子 `(i, j)`，如果它**上面不是 X**（`i == 0` 或 `board[i-1][j] == '.'`）**且左边不是 X**（`j == 0` 或 `board[i][j-1] == '.'`），那它就是所在战舰的「头部」。一艘水平放置的战舰，只有最左那格满足；一艘垂直放置的战舰，只有最上那格满足。数头部个数 = 数战舰个数。

这一步把「连通块计数」问题降维成了「数满足局部条件的格子」，不需要任何搜索、不需要 visited、不需要改 board。

## 3. 从暴力到最优

**第一步：DFS 版本**

```
board = [["X",".",".","X"],
         [".",".",".","X"],
         [".",".",".","X"]]
```

从 `(0,0)` 出发 DFS，只碰到自己，标记 visited，count=1。继续扫，`(0,3)` 出发 DFS，向下走到 `(1,3)`、`(2,3)`，count=2。其余是 `.`。答案 2。正确，但 visited 是 3×4 的布尔矩阵。

**第二步：注意到「不需要 visited」**

DFS 里 visited 的唯一作用是防止同一艘战舰被数两次。但如果我们换一种计数口径——**只在战舰头部计数**——那么每个 `'X'` 格子被检查时，要么它是头部（计数），要么它上面或左边是 X（跳过），天然不会重复。visited 被「局部条件」替代了。

**第三步：走一遍头部判定**

对示例 1 逐格扫描，维护 `count`：

| 格子 | 值 | 上 | 左 | 是头部? | count |
|---|---|---|---|---|---|
| (0,0) | X | 越界→非X | 越界→非X | 是 | 1 |
| (0,1) | . | — | — | — | 1 |
| (0,2) | . | — | — | — | 1 |
| (0,3) | X | 越界→非X | `.`→非X | 是 | 2 |
| (1,0) | . | — | — | — | 2 |
| (1,3) | X | `X` | `.` | 否（上面是X） | 2 |
| (2,3) | X | `X` | `.` | 否 | 2 |

结果 2，和 DFS 一致。注意 `(1,3)`、`(2,3)` 被「上面是 X」这一条挡掉了，这正是垂直战舰只数最上一格的机制。

**瓶颈消掉了什么**：visited 矩阵没了（空间 O(1)），递归栈没了（不怕 m·n=40000 的深链），board 也没被改。一次扫描，每个格子 O(1) 判断。

## 4. 正确性：为什么不会漏、不会重

用**不变量**来证。定义：扫描到第 `k` 个格子后，`count` 等于「已经完全扫描过的区域中，战舰头部的个数」。

**不会重**：假设某艘战舰有多个格子被判为头部。取其中任意两个 `p`、`q`。由于它们同属一个四连通块，且题面保证战舰是 1×k 或 k×1 的直线形状，块内格子按行（或列）单调排列。头部要求「上、左都不是 X」。对水平战舰，只有最左格左边是 `.`，其余格子左边都是 X，故只有一格合格；对垂直战舰同理只有最上格合格。所以每艘战舰恰好贡献 1 次计数。

**不会漏**：任取一艘战舰，它的格子集合非空，取其中行号最小者（同行取列号最小），该格子上方必非 X（否则有更小行号），左方必非 X（否则同行有更小列号），故它一定被判为头部并被计入。

两条合起来：`count` 恰好等于战舰数。注意这里**没有用到「不同战舰之间不相邻」以外的任何假设**——如果题面允许两艘战舰斜着贴在一起，头部判定依然成立；真正依赖「至少一个空格分隔」的是「一艘战舰 = 一个四连通块」这个建模，而头部判定本身对任意 1×k / k×1 形状都成立。

## 5. 完整代码（Python）

```python
class Solution:
    def countBattleships(self, board) -> int:
        if not board or not board[0]:
            return 0
        m, n = len(board), len(board[0])
        count = 0

        for i in range(m):
            for j in range(n):
                # 只关心 X 格子
                if board[i][j] != 'X':
                    continue
                # 上面是 X：说明它是某艘垂直战舰的「身体」，不是头部
                if i > 0 and board[i - 1][j] == 'X':
                    continue
                # 左边是 X：说明它是某艘水平战舰的「身体」，不是头部
                if j > 0 and board[i][j - 1] == 'X':
                    continue
                # 上、左都不是 X（或越界），这是某艘战舰的头部
                count += 1

        return count
```

关键逻辑就三行判断：是 X、上面不是 X、左边不是 X。越界用 `i > 0` / `j > 0` 短路掉，不需要额外写边界分支。

## 6. 复杂度

**时间 O(m·n)**：两层循环各走 m、n 次，循环体内是常数次比较和数组下标访问，没有内层循环、没有递归。m·n 来自「必须看每个格子」这一信息论下界，无法再降。

**空间 O(1)**：只用了 `m`、`n`、`count`、`i`、`j` 五个整型变量，与输入规模无关。没有 visited 矩阵（那是 O(m·n)），没有递归栈（DFS 最坏 O(m·n)），没有复制 board。这里没有 log 项，因为没有任何排序或分治。

对比：DFS 版本时间同为 O(m·n)，但空间 O(m·n)；本解法在时间不变的前提下把空间压到常数，正好命中进阶要求。

## 7. 边界与反例（至少 4 条）

1. **输入 `[["."]]`** → 输出 `0`。容易错在：忘了 `board[i][j] != 'X'` 的提前 `continue`，或者把空棋盘当成 1 艘。题面示例 2 就是这个。

2. **输入 `[["X"]]`** → 输出 `1`。容易错在：`i > 0` 和 `j > 0` 的短路写反成 `board[i-1][j]`，单格时下标 -1 会绕到上一行末尾（Python 负索引不报错，静默取错值），结果变成 0 或异常。必须用 `i > 0 and ...` 的顺序。

3. **输入 `[["X","X","X"]]`**（一艘 1×3 水平战舰）→ 输出 `1`。容易错在：只判「上面不是 X」而漏判「左边不是 X」，会把三个格子都数成头部，输出 3。

4. **输入 `[["X"],["X"],["X"]]`**（一艘 3×1 垂直战舰）→ 输出 `1`。容易错在：只判「左边不是 X」漏判上面，输出 3。和第 3 条互为镜像，两个条件缺一不可。

5. **输入 `[["X",".","X"]]`**（两艘 1×1 战舰，中间隔空格）→ 输出 `2`。容易错在：误以为「同一行有 X 就算一艘」，把同行当连通。连通只看四邻接，不看同行同列。

6. **输入 `[["X",".","X"],["X",".","X"]]`**（两艘 2×1 垂直战舰并排）→ 输出 `2`。容易错在：把「上下相邻」误判成同一艘而跨列合并。每列独立成艘，头部判定给出 `(0,0)` 和 `(0,2)` 两个头部，正确。

## 8. 面试追问与变体（3 条）

**追问 1：如果允许战舰斜着相邻（八连通），还能 O(1) 空间吗？**
思路：不能简单用「上、左」判头部了，因为斜向的 X 可能让一个块出现多个「上左皆空」的格子。需要改成「上、左、左上、右上」四个方向都非 X 才计头部，或者退回 DFS + visited。先和面试官确认连通定义再答。

**追问 2：如果要求返回每艘战舰的长度列表？**
思路：头部判定仍可定位每艘战舰的起点，但从头部出发需要沿行或列向右/向下延伸数长度，延伸时用「下一个是 X 就继续」判断，整体仍是 O(m·n)，因为每个格子最多被延伸访问一次。

**追问 3：如果 board 是流式输入的（一行一行来，不能回看上一行之外）？**
思路：只保留上一行和当前行两个数组，逐行扫描时用「上一行同列是否 X」判断垂直连续性，用「当前行左邻是否 X」判断水平连续性，空间 O(n)，是 O(1) 的放宽版。这题在「不修改 board」约束下，O(1) 已经是最优，流式场景才需要退让。

## 9. 举一反三（2-3 道同类题）

- **力扣 200. 岛屿数量**：同样是四连通块计数，区别是岛屿允许任意形状（不限于直线），所以必须 DFS/BFS 或并查集，不能只靠「上左判头部」。
- **力扣 695. 岛屿的最大面积**：在 200 的基础上求最大连通块大小，DFS 时累加面积，头部判定那套技巧在这里不适用，因为要的是块的大小而非个数。
- **力扣 463. 岛屿的周长**：数连通块边界，思路是每个 X 格子贡献 4 减去相邻 X 的个数，和本题一样属于「用局部邻居信息代替全局搜索」的技巧家族。
