## 1. 一句话本质

在一条线性排列的非负数组中，选出一个**不含相邻下标**的子集，使子集元素之和最大。

## 2. 读完题的第一反应

**朴素解法**：枚举所有合法子集（任意两个被选下标不相邻），取和的最大值。子集数量是指数级的——对长度 n 的数组，合法子集大约按斐波那契速度增长，n=30 就爆了。即使剪枝，复杂度也是 O(2^n) 级别，卡在「组合爆炸」上。

**关键观察**：题目只问「最大金额」，不问「选了哪几间」。而且约束是**局部的**——第 i 间房能不能偷，只取决于第 i-1 间房偷没偷，跟更远的房子无关。这种「决策只依赖前一个状态」的结构，正是动态规划的入口：我们不需要记住整个选择历史，只需要记住「考虑到第 i 间房为止，能拿到的最大金额」。

再进一步想：对第 i 间房，只有两种命运——偷或不偷。偷它，则第 i-1 间必须放弃，收益是「前 i-2 间的最优 + nums[i]」；不偷它，收益就是「前 i-1 间的最优」。两个候选取大即可。这就把指数枚举压成了线性递推。

## 3. 从暴力到最优

**第一步：暴力枚举。** 对每个子集检查合法性再求和，O(2^n · n)。瓶颈在「枚举所有组合」。

**第二步：带记忆的递归。** 定义 `f(i)` = 只考虑前 i 间房（下标 0..i）能偷到的最大金额。转移：

```
f(i) = max(f(i-1), f(i-2) + nums[i])
```

朴素递归会重复计算同一个 `f(i)` 多次（比如 `f(5)` 会从 `f(4)` 和 `f(3)` 两条路径被反复调用），复杂度仍是 O(2^n)。加一个 memo 数组，每个状态只算一次，降到 O(n)。瓶颈从「组合数」变成「状态数 × 转移代价」= n × O(1)。

**第三步：改写成自底向上。** 因为 `f(i)` 只依赖 `f(i-1)` 和 `f(i-2)`，可以从小到大填表，甚至只用两个变量滚动。

**小例子走一遍**：`nums = [2, 7, 9, 3, 1]`

| i | nums[i] | 偷它: f(i-2)+nums[i] | 不偷: f(i-1) | f(i) |
|---|---------|----------------------|--------------|------|
| 0 | 2 | 0 + 2 = 2 | 0 | **2** |
| 1 | 7 | 0 + 7 = 7 | 2 | **7** |
| 2 | 9 | 2 + 9 = 11 | 7 | **11** |
| 3 | 3 | 7 + 3 = 10 | 11 | **11** |
| 4 | 1 | 11 + 1 = 12 | 11 | **12** |

（约定 f(-1)=0，f(-2)=0。）最终答案 12，对应偷 0、2、4 号房：2+9+1=12，与示例一致。

注意 i=3 时「偷它」得 10 < 「不偷」得 11，说明**不是每间房都值得偷**——这正是取 max 的意义，也是很多人手写时容易漏掉的分支。

**第四步：滚动变量。** 观察上表，算 f(i) 时只需要 f(i-1) 和 f(i-2)，用一个 `prev2` 存 f(i-2)、`prev1` 存 f(i-1)，每轮更新即可，空间从 O(n) 降到 O(1)。

## 4. 正确性：为什么不会漏、不会重

用**最优子结构 + 分类讨论**来论证，这是 DP 正确性的标准套路。

**不变量**：对每个 i ≥ 0，`f(i)` 等于「只在下标 0..i 中选、且不含相邻下标」的所有合法子集的元素和的最大值。

**归纳证明**：考虑前 i 间房的任意一个最优合法子集 S。

- **情况一：i ∉ S。** 那么 S 完全落在 0..i-1 内，且仍合法，所以 `sum(S) ≤ f(i-1)`。
- **情况二：i ∈ S。** 由合法性，i-1 ∉ S，于是 S \ {i} 落在 0..i-2 内且合法，`sum(S) = nums[i] + sum(S\{i}) ≤ nums[i] + f(i-2)`。

两种情况覆盖了所有可能（i 要么在 S 里要么不在），所以任意合法子集的和都不超过 `max(f(i-1), f(i-2)+nums[i])`；反过来，取到这两个值的子集本身合法（情况一取 f(i-1) 的最优解，情况二取 f(i-2) 的最优解并上 i，二者都不含相邻下标）。因此等号成立，归纳成立。

**为什么不会重**：情况一和情况二按「i 是否被选」互斥划分，同一个子集只归入其中一类，不存在重复计数。**为什么不会漏**：任何合法子集必然落入这两类之一，没有第三类。这正是「按最后一个元素分类」的威力——它把无限多的组合压成了两个分支。

## 5. 完整代码（Python）

```python
class Solution:
    def rob(self, nums: list[int]) -> int:
        # prev2 表示 f(i-2)，prev1 表示 f(i-1)
        # 初始对应 f(-2)=0, f(-1)=0，即「没有房子」时的收益
        prev2 = 0
        prev1 = 0
        for x in nums:
            # 两种选择：不偷当前房（继承 prev1），或偷当前房（prev2 + x）
            cur = max(prev1, prev2 + x)
            # 滚动：为下一轮准备 f(i-1) 和 f(i-2)
            prev2 = prev1
            prev1 = cur
        # 循环结束后 prev1 就是 f(n-1)，即全局最优
        return prev1
```

这段代码对空数组返回 0（循环不执行，prev1 保持 0），对单元素数组返回该元素，都符合直觉。题面提示里数组长度下界被截断了，按力扣原题是 `1 <= nums.length <= 100`，但代码对空数组也安全，无需特判。

## 6. 复杂度

**时间 O(n)**：n 来自 `nums` 的长度，循环体执行 n 次，每次只做一次加法、一次 `max`、两次赋值，都是 O(1)。没有嵌套循环，没有排序，所以没有 log n 项。

**空间 O(1)**：只用了 `prev2`、`prev1`、`cur` 三个标量，与 n 无关。如果写成 DP 数组版本则是 O(n)，滚动变量把它压掉了。递归 + memo 版本是 O(n) 时间和 O(n) 栈空间，不如迭代版。

## 7. 边界与反例（至少 4 条）

1. **`[5]` → 5**：只有一间房，直接偷。容易错在把 `prev2 + x` 写成越界访问，或误以为必须至少偷两间。
2. **`[2, 1]` → 2**：两间相邻只能选一间，选大的。容易错在无脑「隔一个偷一个」从 0 号开始，得到 2 碰巧对，但换成 `[1, 2]` 就错成 1。
3. **`[2, 7, 9, 3, 1]` → 12**：中间 9 很大，但最优解跳过 3 号房（7+3=10 < 11）。容易错在贪心地「每步都偷当前能偷的最大值」，或漏掉「不偷」分支。
4. **`[0, 0, 0]` → 0**：金额可以为 0，全偷也是 0。容易错在把 0 当成「没房子」提前返回，或初始化 `prev1 = -1` 之类导致负数。
5. **`[1, 3, 1, 3, 100]` → 104**：偷 1、3、100 号（下标 1、3、4 不相邻？注意 3 和 4 相邻！）——正确解是偷下标 0、2、4：1+1+100=102，或下标 1、3：3+3=6，或 1、3 号加不了 4 号。实际最优是 1+1+100=102。这条提醒：**别凭感觉，按递推表算**。

## 8. 面试追问与变体（3 条）

1. **追问：如果房屋围成一圈（首尾也相邻）怎么办？**（力扣 213）→ 分两种情况：不偷 0 号房（对 1..n-1 跑本题）或不偷 n-1 号房（对 0..n-2 跑本题），取两者较大值。
2. **追问：如果房屋排成一棵树，相邻（父子）不能同时偷呢？**（力扣 337）→ 树形 DP，每个节点返回 `(偷该节点的最优, 不偷该节点的最优)` 两个值，自底向上合并。
3. **追问：不仅要最大金额，还要输出具体偷了哪几间？** → 额外开一个 `choice` 数组记录每步选了「偷」还是「不偷」，最后从末尾倒推回溯；空间回到 O(n)。

## 9. 举一反三（2-3 道同类题）

- **力扣 213 打家劫舍 II**：环形版本，共同点是「相邻互斥 + 线性 DP」，区别只在首尾约束，用「拆成两条链」化解。
- **力扣 746 使用最小花费爬楼梯**：同样是「每步二选一、只依赖前两个状态」的线性 DP，把 `max` 换成 `min`、把「偷不偷」换成「从哪层跳上来」。
- **力扣 53 最大子数组和**：都是「以 i 结尾/考虑到 i 的最优值」的线性递推，训练同一个思维：定义好状态、写对转移、滚动优化。
