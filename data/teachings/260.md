## 1. 一句话本质

把数组里所有数异或起来，得到的是那两个「单身数」的异或值；再用这个值里任意一个为 1 的二进制位当「筛子」，把数组劈成两半，两个单身数必然分居两半，各自异或一次就分别现形。

## 2. 读完题的第一反应

**朴素解法**：拿一个哈希表（或 `collections.Counter`）统计每个数出现次数，最后挑出次数为 1 的两个。时间 O(n)，但空间 O(n)——题面明确要求「仅使用常量额外空间」，这条路直接被堵死。另一种朴素思路是双重循环两两比对，时间 O(n²)，更不行。

**关键观察**：题面说「其余所有元素都出现两次」。出现两次这个条件，在位运算里有一个天然搭档——异或。`x ^ x = 0`，`x ^ 0 = x`，异或满足交换律和结合律。所以如果把整个数组异或一遍，所有成对的数会两两抵消成 0，最后剩下的就是那两个单身数的异或值，记作 `xor_all = a ^ b`。

这一步已经把「找两个数」压缩成了「一个数」，但还没完：`xor_all` 是 `a ^ b`，不是 `a` 也不是 `b`。怎么把它拆开？看 `xor_all` 的二进制：`a` 和 `b` 不同，所以 `a ^ b` 必然至少有一位是 1（否则 a == b，与「恰好两个不同元素」矛盾）。这一位为 1，说明 `a` 和 `b` 在这一位上**一个 0 一个 1**。于是拿这一位当分类标准，把原数组分成「这一位是 1」和「这一位是 0」两组，`a`、`b` 必然被分到不同组，而每对相同的数必然被分到同一组。两组各自异或，成对的抵消，剩下的就是 `a` 和 `b`。

## 3. 从暴力到最优

**第一步：哈希表**。遍历一遍，`count[x] += 1`，再遍历一遍挑出 count 为 1 的。时间 O(n)，空间 O(n)。瓶颈在空间——题目不允许。

**第二步：整体异或**。用 `xor_all` 代替哈希表来「抵消成对的数」。以 `nums = [1,2,1,3,2,5]` 为例：

```
xor_all = 1^2^1^3^2^5
        = (1^1) ^ (2^2) ^ 3 ^ 5
        = 0 ^ 0 ^ 3 ^ 5
        = 3 ^ 5
        = 6   (二进制 110)
```

现在知道 `a ^ b = 6`，但不知道 a、b 各是多少。瓶颈变成「如何从 a^b 反推 a 和 b」。

**第三步：找分割位**。`6 = 110`，最低位的 1 是 `6 & -6 = 2`（二进制 `010`）。这一位为 1，意味着 3 和 5 在这一位上不同：`3 = 011`，`5 = 101`，第 1 位（从 0 数）分别是 1 和 0。用 `mask = 2` 把数组分成两组：

```
mask = 2 (010)
1 & 2 = 0  → 组0
2 & 2 = 2  → 组1
1 & 2 = 0  → 组0
3 & 2 = 2  → 组1
2 & 2 = 2  → 组1
5 & 2 = 0  → 组0
```

组0 = `[1, 1, 5]`，组1 = `[2, 3, 2]`。各自异或：组0 得 `1^1^5 = 5`，组1 得 `2^3^2 = 3`。答案 `[5, 3]`。

**瓶颈消解链**：O(n) 空间 → 用异或抵消降到 O(1) 空间，但只剩一个混合值 → 用「a^b 必有一位为 1」这个性质做二次分割，把混合值拆成两个独立值。每一步都只多扫一遍数组，总时间仍是 O(n)。

## 4. 正确性：为什么不会漏、不会重

用**不变量**来论证。

**不变量 1（整体异或）**：设数组为 `nums`，两个单身数为 `a`、`b`（`a ≠ b`），其余元素每个恰好出现两次。由于异或满足交换律、结合律，且 `x ^ x = 0`、`x ^ 0 = x`，把所有元素异或的结果等于 `a ^ b`。证明：把数组重排成 `[a, b, p1, p1, p2, p2, ...]`，异或为 `a ^ b ^ (p1^p1) ^ (p2^p2) ^ ... = a ^ b ^ 0 ^ 0 ^ ... = a ^ b`。这一步不会漏掉任何元素，也不会重复计入——每个元素恰好参与一次异或。

**不变量 2（分割位存在且有效）**：因为 `a ≠ b`，`a ^ b ≠ 0`，所以 `a ^ b` 至少有一位二进制为 1。取 `mask = (a^b) & -(a^b)`（最低位的 1），则 `a & mask` 与 `b & mask` 必不相等（一个为 mask，一个为 0）。因此 `a`、`b` 被分到不同组。

**不变量 3（组内抵消）**：对任意一对相同元素 `p`，`p & mask` 的值相同，所以它们必在同一组；组内异或时 `p ^ p = 0` 抵消。因此组0 异或的结果恰好是「组0 中那个单身数」，组1 同理。两组各得一个，合起来就是 `{a, b}`，不漏不重。

三个不变量串起来：整体异或保证「混合值正确」，分割位保证「两个单身数被分开」，组内抵消保证「每组只剩一个单身数」。任何一步都不依赖数组顺序，所以对任意满足题意的输入都成立。

## 5. 完整代码（Python）

```python
class Solution:
    def singleNumber(self, nums: list[int]) -> list[int]:
        # 第一步：整体异或，成对的数抵消，剩下 a ^ b
        xor_all = 0
        for x in nums:
            xor_all ^= x

        # 第二步：取 xor_all 最低位的 1 作为分割位
        # x & -x 是取最低位 1 的经典技巧（补码性质）
        mask = xor_all & -xor_all

        # 第三步：按 mask 分组异或
        # a 和 b 在 mask 位上不同，必分居两组；每对相同数必同组
        a = 0
        b = 0
        for x in nums:
            if x & mask:
                a ^= x      # 这一位为 1 的组，成对抵消后剩一个单身数
            else:
                b ^= x      # 这一位为 0 的组，剩另一个单身数

        return [a, b]
```

注意 Python 的整数是任意精度，`x & -x` 对负数也成立（补码语义在 Python 中通过无限符号位实现，但 `x & -x` 取最低位 1 的结论不变）。题面给的 `nums[i]` 范围在 32 位有符号整数内，异或结果也在范围内，不会溢出。

## 6. 复杂度

**时间 O(n)**：三次线性扫描——第一次算 `xor_all`（n 次异或），第二次算 `mask`（O(1)），第三次分组异或（n 次判断 + 至多 n 次异或）。总操作数约 3n，常数级，所以是 O(n)。这里没有 log n 的项：`x & -x` 是单条位运算指令，不随数值大小循环。

**空间 O(1)**：只用了 `xor_all`、`mask`、`a`、`b` 四个整型变量，与 n 无关。没有哈希表、没有额外数组。返回值 `[a, b]` 是题目要求的输出，不计入额外空间。

## 7. 边界与反例（至少 4 条）

1. **`nums = [-1, 0]`** → 期望 `[-1, 0]`（顺序任意）。易错点：负数参与异或时，`mask = xor_all & -xor_all` 在 Python 里对负数仍然正确，但如果用 C/Java 且误以为「负数不能做位运算」而加特殊判断，反而会错。Python 直接算即可。

2. **`nums = [0, 1]`** → 期望 `[0, 1]` 或 `[1, 0]`。易错点：`xor_all = 1`，`mask = 1`，分组时 `0 & 1 = 0` 进组0，`1 & 1 = 1` 进组1，结果 `[1, 0]`。有人会误以为 0 是「空值」要特殊处理，其实 0 是合法元素，正常参与异或。

3. **`nums = [1, 1, 2, 3]`** → 期望 `[2, 3]`。易错点：`xor_all = 2^3 = 1`，`mask = 1`，分组后组0 是 `[2]`（2&1=0），组1 是 `[1,1,3]`（1&1=1, 3&1=1），组1 异或得 `1^1^3 = 3`。如果误把「组0 只有一个元素」当成异常，就会漏解——组0 恰好只有一个元素是正常的，因为那一组里没有成对的数。

4. **`nums = [2, 2, 3, 3, 4, 5]`** → 期望 `[4, 5]`。易错点：`xor_all = 4^5 = 1`，`mask = 1`，4&1=0、5&1=1 分居两组，各自组内成对的 2、3 抵消。如果实现时用 `if x & mask == 1` 而不是 `if x & mask`，在 mask 不是 1 的情况下会出错（比如 mask=2 时 `x & 2` 可能是 2 而不是 1）。必须用真值判断。

5. **两个单身数相同？** 题面保证「恰好有两个元素只出现一次」，且「其余出现两次」，隐含这两个元素不同（否则它们各出现一次但值相同，就变成「一个值出现两次」了，与「只出现一次」矛盾）。如果输入违反此保证（如 `[1, 1]`），`xor_all = 0`，`mask = 0`，分组失效——但这不是合法输入，不需要处理。

## 8. 面试追问与变体（3 条）

1. **追问：如果数组里只有一个数出现一次，其余出现两次，怎么做？** 思路：直接整体异或，结果就是那个数，不需要分割。这是本题的退化版（LeetCode 136）。

2. **追问：如果有三个数各出现一次，其余出现两次呢？** 思路：整体异或得 `a^b^c`，无法直接分割成三组。需要更复杂的位计数（统计每一位 1 的个数对 3 取模）或分情况讨论，时间复杂度仍是 O(n) 但常数更大。这题（LeetCode 137 的变体）说明「两个」是异或技巧的甜点区。

3. **追问：不用位运算，只用 O(1) 空间能做到吗？** 思路：可以，但需要排序后扫描（O(n log n) 时间）或用数学方法（求和、平方和联立方程，但有溢出风险）。位运算是唯一同时满足 O(n) 时间和 O(1) 空间的方案，这也是本题被归为「位运算」标签的原因。
