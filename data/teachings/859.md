## 1. 一句话本质

判断能否通过**恰好一次**「交换 s 中两个不同下标」的操作，把 s 变成 goal——注意是恰好一次，不是至多一次，这是本题所有坑的源头。

## 2. 读完题的第一反应

朴素解法：枚举所有下标对 (i, j)，i < j，交换后和 goal 比较。下标对数量是 C(n,2) ≈ n²/2，每次比较 O(n)，总复杂度 O(n³)。n 到 2×10⁴ 时这是 8×10¹² 量级，直接爆掉。

即使优化成「先交换、再逐位比较、发现不等就提前退出」，最坏仍是 O(n³)（比如 s 和 goal 只差最后一位时，每个下标对都要比到末尾）。

关键观察来自一个事实：**交换只影响两个位置**。也就是说，如果 s 和 goal 真的只差一次交换，那么它们「不同的位置」必然**恰好是两个**，而且这两个位置上 s 和 goal 的字符是**交叉相等**的：s[i] == goal[j] 且 s[j] == goal[i]。

这个观察把「枚举交换」变成了「先定位差异」：扫一遍找出所有 s[k] != goal[k] 的位置，差异位置的数量直接决定了答案的形态。差异数只可能是 0、2、或其他，三种情况分开处理，问题就从「搜索」降级成「分类讨论」。

## 3. 从暴力到最优

**暴力**：对每个 (i,j) 真交换、真比较。瓶颈在于「枚举 + 每次 O(n) 比较」两层嵌套。

**第一步消掉「每次 O(n) 比较」**：不真交换，而是先扫一遍记录差异位置列表 diff。这一步 O(n)。扫完后，如果 len(diff) 不是 0 或 2，直接 false——因为一次交换最多改变两个位置，差异数不可能变成 1、3、4……

**第二步消掉「枚举下标对」**：差异数只有 0 或 2 两种可能，各自 O(1) 判断。

- len(diff) == 2：设 diff = [i, j]，只需检查 s[i] == goal[j] and s[j] == goal[i]。是则 true，否则 false。
- len(diff) == 0：s 和 goal 完全相同。此时必须**恰好交换两个不同下标**，交换后还得等于原串。这只有当 s 中存在**至少一个字符出现次数 ≥ 2** 时才可能（交换两个相同的字符，串不变）。用哈希表/计数数组统计频次即可。

走一遍示例 1：s = "ab", goal = "ba"。
- 扫差异：k=0 时 'a' != 'b'，记 0；k=1 时 'b' != 'a'，记 1。diff = [0, 1]。
- len == 2，检查 s[0]=='a' == goal[1]=='a' ✓，s[1]=='b' == goal[0]=='b' ✓ → true。

走一遍示例 2：s = "ab", goal = "ab"。
- 扫差异：diff = []，len == 0。
- 统计频次：'a':1, 'b':1，没有任何字符出现 ≥ 2 → false。正确，因为唯一能交换的 (0,1) 会得到 "ba" ≠ "ab"。

走一遍示例 3：s = "aa", goal = "aa"。
- diff = []，len == 0。
- 频次：'a':2 ≥ 2 → true。交换下标 0 和 1 后仍是 "aa"。

再补一个容易漏的：s = "ab", goal = "ba" 但改成 s = "ab", goal = "ca"。diff = [0,1]，检查 s[0]=='a' == goal[1]=='a' ✓，s[1]=='b' == goal[0]=='c' ✗ → false。差异位置对了但字符不交叉，必须拒绝。

## 4. 正确性：为什么不会漏、不会重

用**不变量**论证。核心不变量：**一次交换 (i,j) 只改变下标 i 和 j 两个位置的字符，其余位置保持不变。**

由此推出两条：

**（必要性）** 若存在一次交换使 s 变成 goal，则对所有 k ∉ {i,j}，s[k] == goal[k]。所以差异位置集合 diff ⊆ {i,j}，|diff| ≤ 2。这解释了为什么 len(diff) > 2 时可以直接 false——不存在任何交换能修复三个及以上位置的差异，不会漏掉合法解。

**（充分性，分两支）**

- |diff| == 2，diff = {i,j}：交换 (i,j) 后，位置 i 变成 s[j]，位置 j 变成 s[i]，其余不变。要等于 goal，当且仅当 s[j] == goal[i] 且 s[i] == goal[j]。这是充要条件，判断它既不漏也不重。注意 i、j 由 diff 唯一确定，所以「枚举」退化成「唯一候选」，不存在重复计数。

- |diff| == 0：s == goal。此时任何交换 (i,j) 后要仍等于 goal，必须 s[i] == s[j]（交换相同字符串不变）。存在这样的 (i,j)（i≠j）当且仅当某个字符出现次数 ≥ 2。这也是充要条件。

两支覆盖了 |diff| ∈ {0, 2} 的全部合法情形，|diff| 为其他值时两支都不适用且确实无解，所以分类是完备的，不会漏；每支内部是充要判断，不会误判。

## 5. 完整代码（Python）

```python
class Solution:
    def buddyStrings(self, s: str, goal: str) -> bool:
        # 长度不同，一次交换不可能改变长度，直接 false
        if len(s) != len(goal):
            return False

        # 收集所有 s[k] != goal[k] 的下标
        diff = [k for k in range(len(s)) if s[k] != goal[k]]

        if len(diff) == 2:
            i, j = diff
            # 两个差异位置必须字符交叉相等，交换后才对齐
            return s[i] == goal[j] and s[j] == goal[i]

        if len(diff) == 0:
            # s 与 goal 完全相同：必须存在重复字符，才能交换两个相同字符而不改变串
            # 用集合判重：一旦遇到已出现过的字符，说明有频次 >= 2
            seen = set()
            for ch in s:
                if ch in seen:
                    return True
                seen.add(ch)
            return False

        # 差异位置数为 1、3、4... 一次交换无法修复
        return False
```

## 6. 复杂度

- **时间 O(n)**：n = len(s)。第一段 `diff` 列表推导扫一遍 O(n)；len==2 分支是 O(1)；len==0 分支的 `seen` 循环最坏扫完整个串 O(n)。三段不嵌套，取最大，总 O(n)。没有 log 项，因为没有任何排序或二分。
- **空间 O(n)**：`diff` 最坏存 n 个下标（当 s 和 goal 完全不同时），O(n)；`seen` 最坏存 26 个字符，因字母表固定是 O(1)，但按输入规模保守写 O(min(n, 26))。整体 O(n)。若想省空间，`diff` 可以只记前两个差异位置、遇到第三个直接返回 false，空间降到 O(1)，但当前写法更易读。

## 7. 边界与反例（至少 4 条）

1. **s = "ab", goal = "ab"** → false。容易错在「相同就返回 true」。必须恰好交换一次，而 "ab" 没有重复字符，交换后必变。
2. **s = "aa", goal = "aa"** → true。容易错在「相同就返回 false」。有重复字符 'a'，交换两个 'a' 串不变，满足恰好一次。
3. **s = "ab", goal = "ba"** → true。基础正例，但要注意检查的是交叉相等，不是「字符集合相同」。反例：s = "ab", goal = "ca"，字符集合不同，diff 长度 2 但交叉检查失败 → false。
4. **s = "abc", goal = "abc"** → false。三个字符全不同，无重复，恰好交换必改变串。这是 len==0 分支最典型的坑。
5. **s = "abcd", goal = "badc"** → false。diff = [0,1,2,3]，长度 4 > 2，一次交换修不了四个位置。容易错在「差异是偶数就以为能两两配对」。
6. **s = "ab", goal = "a"** → false。长度不等，任何交换都不改变长度。容易错在没先判长度就进 diff 循环，导致越界或逻辑混乱。

## 8. 面试追问与变体（3 条）

1. **追问：如果允许「至多一次」交换（可以不交换），答案怎么变？** 思路：len(diff)==0 时直接返回 true，不再要求重复字符；其余分支不变。
2. **追问：如果允许「恰好 k 次」交换呢？** 思路：k 次交换能实现的置换由若干轮换组成，需讨论差异位置能否分解成 ≤ k 个轮换，且 k 与轮换长度的奇偶性要匹配（多余次数可用重复字符空转）。这是本题的困难版，先讲清 k=1 的轮换结构再推广。
3. **追问：不要求恰好一次，而是问「最少交换几次能把 s 变成 goal」？** 思路：对 diff 位置建图，字符作为节点、差异位置作为有向边，最少交换次数 = 差异位置数 − 图中环的个数（每个环省一次交换）。本题是「环数是否为 1 或存在自环」的特例。
