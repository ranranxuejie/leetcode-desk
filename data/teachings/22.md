## 1. 一句话本质

在所有长度为 2n 的括号串里，按「任意前缀左括号数 ≥ 右括号数」这条约束做**带剪枝的枚举**，把满足约束的串全部收集起来。

## 2. 读完题的第一反应

最朴素的想法：长度 2n 的串，每个位置要么 `(` 要么 `)`，一共 2^(2n) 种，逐个检查是否合法。n=8 时 2^16 = 65536，其实不算大，但检查每个串要 O(n)，总 O(n·2^(2n))，而且绝大多数串在第一个字符是 `)` 时就已经废了——**枚举了大量注定不合法的前缀**。

关键观察：合法性是**前缀性质**。一个串合法 ⟺ 任意前缀里 `(` 的个数不少于 `)` 的个数，且最终两者相等。这意味着我可以**边构造边判断**：每加一个字符，只要当前前缀还满足「左 ≥ 右」，就还有救；一旦右超过左，这个前缀无论后面怎么补都救不回来，直接砍掉。于是枚举从「先造完整串再检查」变成「造的过程中随时剪枝」，搜索树被大幅削掉。

这个观察为什么能想到下一步？因为它把「全局合法性检查」降级成了「局部一步检查」——每步只需要看两个计数器，天然适合回溯/DFS。

## 3. 从暴力到最优

**暴力**：生成全部 2^(2n) 个串，对每个串扫描一遍验证。瓶颈在「先造后验」，大量无效分支被完整走完。

**剪枝版回溯**：维护两个计数器 `left`（已用左括号数）、`right`（已用右括号数），每步只做两件事：

- 若 `left < n`，可以放 `(`；
- 若 `right < left`，可以放 `)`。

第二条就是剪枝的核心：右括号只有在「数量还没追上左括号」时才允许放。

以 n=3 走一遍（只列部分路径，`path` 表示当前串）：

```
开始 path="" left=0 right=0
├─ 放( → path="("  left=1 right=0
│  ├─ 放( → path="(("  left=2 right=0
│  │  ├─ 放( → path="((("  left=3 right=0
│  │  │  └─ 只能放) → "((()" → "((())" → "((()))"  ✅ 收集
│  │  └─ 放) → path="(()"  left=2 right=1
│  │     ├─ 放( → "(()("  left=3 right=1 → 只能) → "(()()" → "(()())" ✅
│  │     └─ 放) → "(())"  left=2 right=2 → 只能( → "(())(" → "(())()" ✅
│  └─ 放) → path="()"  left=1 right=1
│     ├─ 放( → "()("  left=2 right=1
│     │  ├─ 放( → "()(("  left=3 right=1 → "()(()" → "()(())" ✅
│     │  └─ 放) → "()()"  left=2 right=2 → "()()(" → "()()()" ✅
│     └─ 放) → 非法！right=1 会变成 2 > left=1，剪掉
```

注意最后那条被剪的分支：`path="()"` 时若再放 `)`，得到 `())`，右括号数 2 超过左括号数 1，后面无论补什么都无法让前缀条件恢复（前缀一旦违规，整串必违规）。这一剪直接砍掉整棵子树。

对比暴力：暴力会走到 `())` 再继续补到长度 6 才发现不合法；剪枝版在长度 3 就停了。n 越大，省得越多。

**为什么这就是最优形态**：答案本身有 Catalan 数 C_n 个，n=8 时 C_8 = 1430。回溯的搜索树每个叶子恰好对应一个合法串，中间节点是合法前缀，**没有一条路径是白走的**——搜索量正比于答案规模，已经到理论下界附近。

## 4. 正确性：为什么不会漏、不会重

**不漏**：任何合法串，从左往右读，每个前缀都满足「左 ≥ 右」，且左括号总数不超过 n。所以构造它时，每一步都落在我们允许的两个分支里（放 `(` 要求 `left < n`，放 `)` 要求 `right < left`），回溯一定会走到这个叶子。

**不重**：每个合法串对应搜索树里**唯一一条**从根到叶的路径——路径上第 i 步放什么字符，由串的第 i 个字符唯一决定。不同的串在第某个位置字符不同，路径就在那一层分叉，不可能重合。所以每个答案只被收集一次。

**不变量**（贯穿整个搜索）：进入任意递归节点时，`path` 是一个「合法前缀」，即 `left ≥ right` 且 `left ≤ n`。初始空串满足；放 `(` 时 `left+1 ≤ n` 由分支条件保证，`left+1 ≥ right` 显然；放 `)` 时 `right+1 ≤ left` 由分支条件保证。归纳可知不变量始终成立，所以收集到的每个串都合法。

## 5. 完整代码（Python）

```python
class Solution:
    def generateParenthesis(self, n: int) -> list[str]:
        res = []
        path = []  # 用 list 存字符，避免字符串拼接的 O(n) 拷贝

        def backtrack(left: int, right: int) -> None:
            # 终止条件：左右括号都用满 n 个，得到一个完整合法串
            if len(path) == 2 * n:
                res.append("".join(path))
                return

            # 分支一：还能放左括号（总数没超过 n）
            if left < n:
                path.append("(")
                backtrack(left + 1, right)
                path.pop()  # 撤销选择，回到上一层状态

            # 分支二：右括号数严格少于左括号数时才允许放
            # 这一步就是剪枝：保证任意前缀 左 >= 右
            if right < left:
                path.append(")")
                backtrack(left, right + 1)
                path.pop()

        backtrack(0, 0)
        return res
```

关键逻辑说明：

- `left`、`right` 是**已使用**的括号数，不是剩余数，读分支条件时别搞反。
- `path.pop()` 是回溯的灵魂：进入分支前 `append`，递归返回后必须 `pop`，否则兄弟分支会看到脏状态。
- 两个 `if` 是并列的，不是 `if/else`——同一个节点可能两个分支都能走（比如 `left=1, right=0` 时放 `(` 和放 `)` 都合法），这正是搜索树分叉的地方。
- 用 `list` 而非字符串拼接：`"".join(path)` 只在叶子做一次，中间过程 O(1) 追加。

## 6. 复杂度

**时间**：O(4^n / √n)，即 Catalan 数 C_n 的量级乘以每个答案的构造代价。拆开看：

- 叶子数 = C_n = (1/(n+1))·C(2n, n) ≈ 4^n / (n^1.5 · √π)，这是答案个数，每个叶子做一次 `"".join`，代价 O(n)，所以光收集就是 O(n·C_n)。
- 中间节点总数也是 O(C_n) 量级（每个内部节点至少有一个叶子后代，树是「满」的），每步 O(1)。
- 综合写作 O(4^n / √n)（把 n·C_n 里的 n 吸收进渐近式，严格说时间上界是 O(n·C_n)，面试说 O(4^n/√n) 或 O(C_n) 都可接受，**关键是能说出「正比于答案数」**）。

**空间**：

- 递归栈深度最多 2n，每层 O(1)，栈空间 O(n)。
- `path` 长度最多 2n，O(n)。
- 结果集存 C_n 个长度 2n 的串，O(n·C_n)——这部分是**输出本身**占的，通常不计入「算法额外空间」，但面试要主动区分。
- 所以额外空间（不含输出）是 O(n)。

## 7. 边界与反例（至少 4 条）

1. **n = 1** → `["()"]`。容易错在：只写 `if left < n` 分支忘了 `right < left` 分支，或者终止条件写成 `left == n` 而漏掉右括号补全，导致返回空或返回 `["("]`。
2. **n = 2** → `["(())","()()"]`。容易错在：把 `right < left` 写成 `right <= left`，于是允许 `())` 这种前缀，产出非法串 `())()` 之类；或写成 `right < n` 导致 `)(` 这种以右括号开头的串混进来。
3. **n = 8**（上界）→ 1430 个串。容易错在：用字符串 `path + "("` 拼接，每层 O(n) 拷贝，n=8 虽能过但体现不出优化意识；更隐蔽的是递归里忘了 `pop`，结果集里出现重复或长度不对的串。
4. **n = 0**（题面约束是 1≤n≤8，但面试常追问）→ 期望 `[""]`（空串算一个合法组合）或 `[]`，取决于约定。容易错在：终止条件 `len(path) == 2*n` 在 n=0 时立即成立，返回 `[""]`；若面试官期望 `[]` 需显式特判。**这里明确假设：按力扣惯例 n≥1，不处理 n=0。**
5. **分支顺序反例**：若先写 `if right < left` 再写 `if left < n`，结果集顺序会变（先出 `()()()` 类），力扣判题不校验顺序，但若面试要求字典序需注意——本题不要求。

## 8. 面试追问与变体（3 条）

1. **追问：不用回溯，用 DP 怎么做？** 思路：`dp[i]` 表示 i 对括号的所有合法串，`dp[i] = "(" + dp[j] + ")" + dp[i-1-j]` 对所有 j 拼接，本质是 Catalan 递推的字符串版，时间同阶但常数更大、代码更绕。
2. **追问：只求方案数不求具体串？** 思路：直接算 Catalan 数 `C(2n,n)/(n+1)`，O(n) 时间 O(1) 空间，或用 DP `dp[i] = Σ dp[j]·dp[i-1-j]`。
3. **追问：给定一个括号串，判断是否合法 / 求最少添加几个括号使其合法？** 思路：前者用计数器扫描，遇 `)` 且计数为 0 即非法；后者扫描时记录「欠账」和「多余左括号」，答案 = 需补右 + 需补左，O(n) 一趟。
