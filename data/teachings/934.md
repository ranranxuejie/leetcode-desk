## 1. 一句话本质

在「两座岛之间的所有 0 格路径」里，找一条**最短的、只穿过 0 的路径**，答案就是这条路径上 0 的个数。

换句话说：把其中一座岛当成起点集合，另一座岛当成终点集合，求两个集合之间的**最短曼哈顿式距离（步数）**，而步数恰好等于要翻转的 0 的个数。

## 2. 读完题的第一反应

**朴素解法**：枚举所有「把某些 0 变成 1」的方案，检查两岛是否连通，取翻转数最小者。方案数是 $2^{k}$（$k$ 为 0 的个数），完全不可行。

稍微聪明一点的暴力：枚举第一座岛的每个格子作为起点、第二座岛的每个格子作为终点，对每对起点终点跑一次 BFS 求最短路，取最小。设两岛大小分别为 $a,b$，单次 BFS 是 $O(n^2)$，总复杂度 $O(ab \cdot n^2)$，最坏 $a,b$ 都是 $O(n^2)$，直接爆炸。

**关键观察**：题目保证**恰好两座岛**。这意味着「起点集合」和「终点集合」是天然给定的、互不相交的两块。我们不需要枚举起点终点配对——**多源 BFS** 一次就能同时从整座岛出发向外扩散，第一次碰到另一座岛时，扩散的层数就是最短距离。

为什么这个观察能直接导向下一步？因为「翻转最少的 0」等价于「从岛 A 走到岛 B 经过的 0 最少」，而 BFS 按层扩散的性质保证：**第一次触达目标时的层数 = 最短步数**。于是问题从「枚举配对」降为「一次多源 BFS」。

还有一个前置动作：得先**找出**这两座岛分别是谁。用一次 DFS/BFS 把第一座岛的所有格子标记出来即可（找到第一个 1 就开始 flood fill）。

## 3. 从暴力到最优

分三步走，用示例 2 走一遍：`grid = [[0,1,0],[0,0,0],[0,0,1]]`，坐标 (r,c)。

**第一步：定位第一座岛。** 扫描到 (0,1) 是 1，从它 DFS，得到岛 A = {(0,1)}。把它标记成 2（区分于未访问的 1）。

此时 grid：
```
0 2 0
0 0 0
0 0 1
```

**第二步：多源 BFS 初始化。** 队列装入岛 A 的所有格子：`queue = [(0,1)]`，`dist = 0`（这里 dist 表示「已经跨过的 0 的层数」，起点层为 0）。

**第三步：逐层扩散，每扩一层 dist+1。**

- 第 0 层弹出 (0,1)，它的邻居 (0,0)、(0,2)、(1,1) 都是 0，标记为已访问（改成 2 或用一个 visited 集合），入队。`queue = [(0,0),(0,2),(1,1)]`，层数变为 1。
- 第 1 层弹出 (0,0)：邻居 (1,0) 是 0，入队。(0,2)：邻居 (1,2) 是 0，入队。(1,1)：邻居 (1,0)、(1,2)、(2,1) 中 (2,1) 是 0，入队。`queue = [(1,0),(1,2),(2,1)]`，层数变为 2。
- 第 2 层弹出 (1,0)：邻居 (2,0) 是 0，入队。(1,2)：邻居 (2,2) 是 **1**——这是另一座岛！立刻返回当前层数 2。

答案 2，与示例一致。注意关键点：**碰到 1 就返回当前 dist，而不是把 1 入队**，因为 1 属于目标岛，不需要被翻转。

对比一下：暴力枚举配对要算 (0,1)→(2,2) 的 BFS，虽然这里只有一对，但一般情形下配对数是乘积级；多源 BFS 把所有起点合并成一个「超级源」，只跑一次，瓶颈从 $O(ab \cdot n^2)$ 降到 $O(n^2)$。

## 4. 正确性：为什么不会漏、不会重

**不变量**：BFS 进行到第 $d$ 层时，队列中所有格子到岛 A 的最短「0 步数」恰好等于 $d$，且所有距离 $< d$ 的格子都已被访问过。

**为什么不会漏（下界）**：任何一条从岛 A 到岛 B 的路径，其 0 的个数至少是某个格子到 A 的最短距离。BFS 按层扩展，第一次遇到岛 B 的格子时，该格子到 A 的距离就是所有 A→B 路径中的最小值，因此返回值不可能大于真实答案。

**为什么不会重（上界可达）**：BFS 找到的那条路径，把沿途所有 0 翻成 1，就真的把两岛连通了，翻转数正好等于路径长度。所以返回值是一个**可行解**，不可能小于真实答案。

两者夹逼，返回值 = 最优解。这里用的是「下界 + 构造可行解」的夹逼论证，而不是「显然」。

**一个容易忽略的点**：多源 BFS 中，同一层的格子之间互相扩展不会产生更短路径（因为层数相同），所以用「标记已访问」防止重复入队是安全的，不会漏掉更优解。

## 5. 完整代码（Python）

```python
from collections import deque

class Solution:
    def shortestBridge(self, grid):
        n = len(grid)
        dirs = [(1,0),(-1,0),(0,1),(0,-1)]

        # 第一步：找到第一座岛，用 DFS 把它全部标记为 2
        def dfs(r, c):
            grid[r][c] = 2
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < n and 0 <= nc < n and grid[nr][nc] == 1:
                    dfs(nr, nc)

        found = False
        for i in range(n):
            if found:
                break
            for j in range(n):
                if grid[i][j] == 1:
                    dfs(i, j)      # 标记整座岛 A
                    found = True
                    break

        # 第二步：多源 BFS，从岛 A 的所有格子同时出发
        q = deque()
        for i in range(n):
            for j in range(n):
                if grid[i][j] == 2:
                    q.append((i, j, 0))   # (行, 列, 已跨过的 0 层数)

        while q:
            r, c, d = q.popleft()
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if not (0 <= nr < n and 0 <= nc < n):
                    continue
                if grid[nr][nc] == 1:
                    # 第一次碰到另一座岛，当前层数就是答案
                    return d
                if grid[nr][nc] == 0:
                    grid[nr][nc] = 2      # 标记为已访问，防止重复入队
                    q.append((nr, nc, d + 1))
        return -1   # 题面保证有解，不会走到这里
```

注意 `d` 的语义：从岛 A 的格子出发时 `d=0`；每跨过一个 0 进入下一格，`d+1`。所以碰到 1 时返回的 `d` 正好是「路径上 0 的个数」。如果写成「入队时 d+1、返回 d+1」就会多算一层，这是最常见的 off-by-one。

## 6. 复杂度

设矩阵边长 $n$，总格子数 $N = n^2$。

- **时间**：DFS 标记岛 A 最多访问 $N$ 个格子，$O(N)$；多源 BFS 每个格子最多入队一次、出队一次，每次检查 4 个邻居，$O(N)$。总计 $O(N) = O(n^2)$。这里没有 $\log n$ 项，因为 BFS 是线性扫描，不涉及排序或二分。
- **空间**：DFS 递归栈最坏 $O(N)$（一条蛇形岛）；BFS 队列最坏 $O(N)$；grid 原地修改，不额外开 visited 数组。总计 $O(N) = O(n^2)$。

如果担心递归深度（$n=100$ 时蛇形岛可达 10000 层，Python 默认递归限制约 1000 会爆栈），可以把 DFS 改成显式栈的迭代版，或者 `sys.setrecursionlimit(10000)`。面试时主动提这一点是加分项。

## 7. 边界与反例（至少 4 条）

1. **输入** `[[1,1],[1,0]]`（岛 A 是 3 个格子，岛 B 是 1 个格子，对角相邻）→ 期望 `1`。易错点：DFS 只标记了部分岛 A 就停，导致 BFS 起点不全，答案偏大。
2. **输入** `[[0,1],[1,0]]` → 期望 `1`。易错点：两个 1 对角，不是四连通，所以确实是两座岛；若误以为对角相连会判成 0 座岛。
3. **输入** `[[1,0,1]]` 这类 $n=2$ 的最小规模（题面 $n \ge 2$）→ 期望 `1`。易错点：BFS 返回 `d` 时若写成 `d+1`，会输出 2。
4. **输入** 两岛被一整行 0 隔开，如 `[[1,1,1],[0,0,0],[1,1,1]]` → 期望 `1`。易错点：BFS 把 0 标记成 2 后，第二座岛的 1 没被标记，若判断条件写成 `grid[nr][nc] != 2` 就会把 1 也当 0 入队，层数错乱。
5. **输入** 岛 A 是蛇形长条（递归深度大）→ 期望正常返回。易错点：Python 递归爆栈，需改迭代或调高限制。

## 8. 面试追问与变体（3 条）

1. **追问**：如果不止两座岛，要求把所有岛连成一座，最少翻转多少 0？
   **思路**：变成最小生成树问题——把每座岛缩成一个点，岛间距离用多源 BFS 预处理，再跑 Kruskal/Prim。
2. **追问**：如果允许翻转的 0 必须构成一条直线（只能横或竖）？
   **思路**：分别对每行、每列扫描，找两岛之间连续 0 的最短段，取全局最小。
3. **追问**：如果要求返回具体翻转哪些格子，而不只是数量？
   **思路**：BFS 时记录每个格子的 `parent` 指针，碰到目标岛后沿 parent 回溯出路径。
