## 1. 一句话本质

在「数组首尾相接」这个额外约束下，求所有**非空连续段**和的最大值——难点全在「环形」两个字上：它让候选子数组从 O(n²) 个变成「可以跨过末尾接回开头」的那一批。

## 2. 读完题的第一反应

**朴素解法**：枚举起点 i 和终点 j，累加求和。环形的话，把数组复制一份接在后面（长度 2n），枚举所有长度 ≤ n 的窗口。候选窗口数是 O(n²)，每个窗口求和 O(1)（前缀和）或 O(n)（暴力累加），总复杂度 O(n²) 或 O(n³)。n = 3×10⁴ 时 O(n²) 是 9×10⁸，Python 里必超时。瓶颈在于：**「跨环」的子数组太多，逐个枚举枚举不完。**

**关键观察**：环上的一个子数组只有两种形态——

- 形态 A：**不跨环**，就是原数组里一段普通的连续区间；
- 形态 B：**跨环**，由「原数组的一个后缀」+「原数组的一个前缀」拼成。

而形态 B 有一个漂亮的等价说法：它等于**原数组总和 减去 中间被挖掉的那一段连续区间**。也就是说：

> 跨环子数组的和 = total − （某个不跨环的连续区间之和）

要让左边最大，就要让被减数最小，即**挖掉的那段区间和最小**。于是「环形最大子数组和」被翻译成了「普通最大子数组和」与「普通最小子数组和」两个线性问题。这一步是整个解法的支点：**环形约束没有增加新维度，只是把「求最大」翻转成了「求最小」。**

## 3. 从暴力到最优

### 第一步：先解决「不跨环」——Kadane

设 `cur` = 以当前元素结尾的最大子数组和，`best` = 全局最大。转移只有一句：

```
cur = max(x, cur + x)   # 要么从 x 重新开始，要么接上前面的
best = max(best, cur)
```

以 `nums = [5, -3, 5]` 走一遍：

| x | cur = max(x, cur+x) | best |
|---|---|---|
| 5 | max(5, 5) = 5 | 5 |
| -3 | max(-3, 2) = 2 | 5 |
| 5 | max(5, 7) = 7 | 7 |

不跨环的最大值是 7（子数组 `[5,-3,5]`）。但正确答案是 10（`[5, 5]`，跨环）。**差距正好来自形态 B。**

### 第二步：把形态 B 翻译成「最小子数组和」

total = 5 + (−3) + 5 = 7。跨环答案 10 = 7 − (−3)，被挖掉的正是中间那个 `-3`——它单独构成最小子数组和 −3。

于是算法变成：同时跑一遍 Kadane 求 `maxSum`，再跑一遍「取反版 Kadane」求 `minSum`，答案 = `max(maxSum, total − minSum)`。

### 第三步：堵住一个致命的坑

如果整个数组全是负数，比如 `[-3, -1, -2]`：total = −6，minSum = −6（挖掉整段），`total − minSum = 0`。但题目要求**非空**子数组，0 是空数组的和，非法。此时正确答案是 −1。

所以必须加一条：**当 `maxSum < 0`（全负）时，直接返回 `maxSum`**，不要走 `total − minSum` 那条分支。这条判断不是补丁，而是逻辑必然：全负时「挖掉一段」等于「剩下空集」，而空集不被允许。

### 第四步：为什么这就到最优了

每个元素被常数次访问，两遍 Kadane 都是 O(n)，没有嵌套循环。n = 3×10⁴ 时约 6×10⁴ 次操作，毫无压力。**瓶颈（枚举跨环窗口）被「总和减去最小段」这个恒等式彻底消掉了。**

## 4. 正确性：为什么不会漏、不会重

用**划分 + 不变量**来论证。

**划分**：环上任一非空子数组 S，要么不包含「末尾接开头」的那条缝（形态 A），要么包含（形态 B）。二者互斥且穷尽，所以只需分别求两类的最优再取 max。

**形态 A 的正确性**：Kadane 的不变量是「循环到第 i 个元素后，`cur` 等于所有以 i 结尾的子数组和的最大值」。归纳：以 i 结尾的子数组要么只有 `nums[i]`，要么是「以 i−1 结尾的某段」+ `nums[i]`；前者取 `nums[i]`，后者取 `cur_prev + nums[i]`，取 max 即转移式。由于每个子数组都有唯一终点，`best` 扫过所有终点即覆盖全部候选，不漏。

**形态 B 的正确性**：设 S 跨环，则 S 的补集（在环上）是一段**非空**连续区间 T（因为 S 非空且不覆盖全部……注意：若 S 覆盖全部元素，则 T 为空，此时 S 的和 = total，而 total 一定 ≤ maxSum，因为 maxSum 至少能取到某个单元素或全段，实际上全段本身也是形态 A 的一个候选，故不会漏）。对 T 非空的情形：`sum(S) = total − sum(T)`。于是

```
max over 跨环 S 的 sum(S) = total − min over 非空连续 T 的 sum(T)
```

右边正是「最小子数组和」。取 max 时对 total 是常数、对 sum(T) 取负号，max 变 min，方向正确。

**全负的例外**：此时 total − minSum = 0 对应 T = 整个数组、S = 空集，违反非空约束，故该分支必须被 `maxSum < 0` 的判断拦截。拦截后返回 maxSum，由形态 A 的正确性保证它是最优。

**不会重**：两类取 max，重复不影响正确性；关键是**不会漏**，而上面的划分保证了穷尽。

## 5. 完整代码（Python）

```python
class Solution:
    def maxSubarraySumCircular(self, nums: list[int]) -> int:
        total = 0

        # 第一遍：普通 Kadane，求「不跨环」的最大子数组和
        cur_max = 0
        max_sum = nums[0]          # 用首元素初始化，避免空数组语义
        # 第二遍：取反版 Kadane，求「最小子数组和」
        cur_min = 0
        min_sum = nums[0]

        for x in nums:
            total += x

            # cur_max 表示「以当前元素结尾」的最大和
            cur_max = max(x, cur_max + x)
            max_sum = max(max_sum, cur_max)

            # cur_min 表示「以当前元素结尾」的最小和
            cur_min = min(x, cur_min + x)
            min_sum = min(min_sum, cur_min)

        # 全负：挖掉一段后剩下空集，非法，只能取不跨环的答案
        if max_sum < 0:
            return max_sum

        # 否则在「不跨环最大」与「总和减去最小段」之间取大
        return max(max_sum, total - min_sum)
```

关键点说明：`cur_max` / `cur_min` 每轮都从 `x` 重新起算，这保证了「以当前元素结尾」的语义；`max_sum` / `min_sum` 用 `nums[0]` 初始化而不是 0，是为了在全负时不被 0 污染（虽然最后有 `max_sum < 0` 兜底，但初始化干净能少一层心智负担）。

## 6. 复杂度

- **时间 O(n)**：单层 for 循环遍历 n 个元素，循环体内是常数次比较与加法。n 来自数组长度，没有 log 项——因为没有任何分治或排序，Kadane 是纯线性扫描。
- **空间 O(1)**：只用了 `total, cur_max, max_sum, cur_min, min_sum` 五个标量，与 n 无关。没有开前缀和数组、没有复制数组接环（那是 O(n) 空间的常见写法，本题不需要）。

## 7. 边界与反例（至少 4 条）

1. **`[-3,-1,-2]` → `-1`**：全负。若漏掉 `max_sum < 0` 判断，会返回 `total − min_sum = −6 − (−6) = 0`，错。这是本题最高频的 WA。
2. **`[5,-3,5]` → `10`**：跨环。若只写 Kadane 返回 7，说明没处理形态 B。
3. **`[1]` → `1`**：n = 1。`max_sum = 1`，`total − min_sum = 1 − 1 = 0`，取 max 得 1，正确；但若初始化写成 0 且数组为 `[-1]`，就会错成 0。
4. **`[3,-2,2,-3]` → `3`**：示例 3。注意 `total − min_sum = 0 − (−3) = 3`，与 `max_sum = 3` 打平，说明两条分支都可能给出最优，取 max 是必要的。
5. **`[-1, -1, -1]` → `-1`**：全负且多元素，验证 `max_sum < 0` 分支在 n > 1 时同样生效。

## 8. 面试追问与变体（3 条）

1. **追问：如果要求返回子数组本身（下标），怎么做？** 思路：Kadane 时额外记录 `cur` 的起点，`best` 更新时同步记录 `(start, end)`；最小段同理，最后按两条分支各自的下标还原。
2. **追问：如果允许子数组为空（和至少为 0），答案怎么变？** 思路：去掉 `max_sum < 0` 的拦截，直接 `max(0, max_sum, total − min_sum)`，全负时返回 0。
3. **追问：如果数组是「环形但最多只能绕一圈半」或「限制子数组长度 ≤ k」？** 思路：Kadane 失效，改用**单调队列 + 前缀和**：把数组复制成 2n，维护长度 ≤ n 的窗口内前缀和最小值，O(n) 时间 O(n) 空间。
