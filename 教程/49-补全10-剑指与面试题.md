## 49-1. 二维数组中的查找（Easy）

> 力扣 剑指 Offer 04 · 数组/矩阵 · Easy
> 前置：无

**一句话**：表格每行从左到右递增、每列从上到下递增，判断目标数在不在表里。

### 精讲（零基础版）

#### ① 这题要用到的东西

**二维列表（列表里套列表）**

一句话：`plants` 是"列表的列表"，`plants[r]` 拿到第 r 行（它还是一个列表），`plants[r][c]` 才拿到第 r 行第 c 列那个数。

生活类比：一栋楼的门牌号要两段才定位，先看第几层（行），再看第几户（列）。

```python
plants = [[2, 3, 6, 8], [4, 5, 8, 9], [5, 9, 10, 12]]
print(plants[0][3])    # -> 8
print(plants[2][0])    # -> 5
print(len(plants))     # -> 3
print(len(plants[0]))  # -> 4
```

它在这题里：整道题就是在这个两层结构里挪位置，行号 `r`、列号 `c` 两个数字决定你站在哪一格。

**空列表的判断 `not plants`**

一句话：空列表放在 if 里算"假"，所以 `not plants` 就是"这个表格是空的"。

生活类比：翻开的册子一页都没有，直接合上就行，不用再往里找。

```python
print(not [])       # -> True
print(not [[]])     # -> False
print(not [[]][0])  # -> True
```

它在这题里：力扣的测试数据里有 `[]`（一行都没有）和 `[[]]`（有一行，但这一行没有格子）两种空输入，两种都要先挡掉，否则取 `plants[0][0]` 会直接报错。

**行号列号加减 `r += 1` / `c -= 1`**

一句话：行号加一就是往下走一格，列号减一就是往左走一格。

生活类比：看地图时"往南走一步""往西走一步"，位置是记在脑子里的两个数，不是真的在纸上把格子划掉。

```python
r, c = 0, 3
r += 1
c -= 1
print(r, c)   # -> 1 2
```

它在这题里：不用删数据、不用开新数组，靠两个下标一格格挪，挪出边界就结束。

#### ② 大白话：这题到底在干什么

最笨的办法：从第一行第一格开始，一格一格扫过去，把 m 行 n 列全看一遍。

笨在哪：表格明明是有序的（右边更大、下边更大），一格一格扫等于把这个条件全扔了。1000×1000 的表就要看一百万个格子。

聪明的办法：站到**右上角**那一格。这一格有两个身份，它是这一行里最大的，又是这一列里最小的。

- 它比目标大：它下面只会更大，所以它自己以及它下面那一整列都不可能是目标，往左挪一格；
- 它比目标小：它左边只会更小，所以它自己以及它左边那一整行都不可能是目标，往下挪一格；
- 正好相等：找到了，返回 `true`。

每挪一步都稳稳扔掉一整行或一整列，最多挪 m + n 步就能走完整张表。挪出表格边界还没碰到目标，就说明不存在。

#### ③ 拿题面示例 2 走一遍

输入 `plants = [[1,3,5],[2,5,7]]`、`target = 4`，从右上角 (0,2) 出发。

| 步骤 | 站在哪 | 这一格的值 | 判断与动作 |
|---|---|---|---|
| 1 | (0,2) | 5 | 5 > 4，往左挪，c 变成 1 |
| 2 | (0,1) | 3 | 3 < 4，往下挪，r 变成 1 |
| 3 | (1,1) | 5 | 5 > 4，往左挪，c 变成 0 |
| 4 | (1,0) | 2 | 2 < 4，往下挪，r 变成 2 |
| 结束 | (2,0) | — | r = 2 已经等于行数 2，走出表格 |

所以答案是 `false`。整个过程只走了 4 步，一次都没有回头。

换成示例 1 的 `target = 8` 就更短：从右上角 (0,3) 出发，第一格就是 8，直接返回 `true`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `def findNumberIn2DArray(self, plants, target) -> bool:` | 收表格和目标数，还一个"在不在" |
| `if not plants or not plants[0]:` | 一行都没有，或者有一行但这一行没有格子 |
| `return False` | 空表格里什么都不会有 |
| `r, c = 0, len(plants[0]) - 1` | 站到右上角：第 0 行、最后一列 |
| `while r < len(plants) and c >= 0:` | 只要还站在表格里面就继续走 |
| `if plants[r][c] == target:` | 这一格正好是目标 |
| `return True` | 交卷，找到了 |
| `if plants[r][c] > target:` | 这格太大 |
| `c -= 1` | 往左挪一格 |
| `else:` | 这格太小 |
| `r += 1` | 往下挪一格 |
| `return False` | 走出表格还没碰到，说明不存在 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def findNumberIn2DArray(self, plants: List[List[int]], target: int) -> bool:
        if not plants or not plants[0]:
            return False
        r, c = 0, len(plants[0]) - 1
        while r < len(plants) and c >= 0:
            if plants[r][c] == target:
                return True
            if plants[r][c] > target:
                c -= 1
            else:
                r += 1
        return False
```

边界自测：`plants = [[5]]`、`target = 5` 返回 `True`；`target = 6` 返回 `False`；`plants = []` 返回 `False`。

## 49-2. 青蛙跳台阶问题（Easy）

> 力扣 剑指 Offer 10- II · 动态规划 · Easy
> 前置：无

**一句话**：每次只能跳一格或两格，问跳完 n 格一共有多少种跳法，结果对 1e9+7 取模。

### 精讲（零基础版）

#### ① 这题要用到的东西

**递推：用前面几步算出这一步**

一句话：想知道第 n 格的答案，先看第 n-1 格和第 n-2 格的答案，把它们拼起来。

生活类比：要到第 5 层，最后一步要么是从第 4 层跨一层上来，要么是从第 3 层跨两层上来。所以"到 5 层的走法"等于"到 4 层的走法"加上"到 3 层的走法"。

```python
ways = [0] * 6
ways[0] = 1
ways[1] = 1
for i in range(2, 6):
    ways[i] = ways[i - 1] + ways[i - 2]
print(ways)   # -> [1, 1, 2, 3, 5, 8]
```

它在这题里：`ways[n]` 就是答案；题目 n 最大 100，用列表存 101 个数完全够。

**只用两个变量滚动**

一句话：算 `ways[i]` 只需要 `ways[i-1]` 和 `ways[i-2]` 两个数，更早的算完就没用了，用两个变量轮着顶替即可。

生活类比：记账只留"本月"和"上月"两张单子，再早的可以收起来。

```python
a, b = 1, 1
a, b = b, a + b
print(a, b)   # -> 1 2
a, b = b, a + b
print(a, b)   # -> 2 3
```

它在这题里：`a` 记 f(i-1)，`b` 记 f(i)，每轮一起往后挪一格，空间只用两个变量。

**取模 `%`**

一句话：`x % 1000000007` 就是"x 除以 1000000007 的余数"，把结果压回 0 到 1000000006 之间。

生活类比：时钟走到 12 点之后又从 1 点开始，只保留"表盘上指着几"。

```python
print(1000000008 % 1000000007)                 # -> 1
print((1000000006 + 1000000006) % 1000000007)  # -> 1000000005
print(1000000007 * 3 % 1000000007)             # -> 0
```

它在这题里：n = 100 时真实答案有 21 位数字，题目要求"结果可能过大，取模 1e9+7"，所以每次相加后立刻取模。

#### ② 大白话：这题到底在干什么

最笨的办法：把所有跳法一条条列出来，数一数有几条。

笨在哪：n = 100 时跳法有 573147844013817084101 种（21 位数），一条条列出来根本列不完；而且很多跳法前半段完全一样，重复计算了无数遍。

聪明的办法：不关心"具体怎么跳"，只关心"有多少种"。把所有跳法按最后一步分类，最后一步只有两种可能：从 n-1 跳一格，或者从 n-2 跳两格。于是 f(n) = f(n-1) + f(n-2)。起手 f(0) = 1（一格不跳也算一种走法）、f(1) = 1（只能跳一格），后面一路推上去就行。

#### ③ 拿题面示例 2 的 n = 5 走一遍

一开始 `a` 记 f(0) = 1，`b` 记 f(1) = 1，循环跑 n = 5 次。

| 轮次 | 跑完之后 a | 跑完之后 b | 含义 |
|---|---|---|---|
| 初始 | 1 | 1 | a = f(0)，b = f(1) |
| i=0 | 1 | 2 | a = f(1)，b = f(2) = 1+1 |
| i=1 | 2 | 3 | a = f(2)，b = f(3) = 1+2 |
| i=2 | 3 | 5 | a = f(3)，b = f(4) = 2+3 |
| i=3 | 5 | 8 | a = f(4)，b = f(5) = 3+5 |
| i=4 | 8 | 13 | a = f(5)，b = f(6) = 5+8（这一步 b 已经用不上了） |
| 返回 | 8 | — | 循环结束时 a 正好是 f(5) |

所以答案是 `8`，和题面示例 2 一致。n = 2 时循环只跑两次，a 停在 2，也和示例 1 一致。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `def numWays(self, n: int) -> int:` | 收格子数 n，还走法总数 |
| `MOD = 1000000007` | 题目指定的模数，先存好 |
| `a, b = 1, 1` | 一开始 a 记 f(0) = 1，b 记 f(1) = 1 |
| `for _ in range(n):` | 一共往前推 n 次，下划线表示循环变量用不上 |
| `range(n)` | 生成 0 到 n-1 这 n 个整数，循环体正好跑 n 次 |
| `a, b = b, ...` | 等号右边先全部取值，所以新的 a 拿到的就是旧的 b |
| `... (a + b) % MOD` | 新的 b 是旧的 a 加旧的 b，加完立刻取模 |
| `return a` | 推完 n 次，a 正好是 f(n) |

n = 0 时循环一次都不跑，直接返回 a = 1，正好符合"一格不跳也算一种走法"。另外题面正文把格子数写成了 `num`，示例和参数名用的是 `n`，代码按参数名 `n` 写。

### 完整代码（Python）

```python
from typing import List


class Solution:
    def numWays(self, n: int) -> int:
        MOD = 1000000007
        a, b = 1, 1
        for _ in range(n):
            a, b = b, (a + b) % MOD
        return a
```

边界自测：`n = 0` 返回 `1`，`n = 1` 返回 `1`，`n = 7` 返回 `21`，`n = 100` 返回 `782204094`。

## 49-3. 顺时针打印矩阵（Easy）

> 力扣 剑指 Offer 29 · 数组/矩阵 · Easy
> 前置：无

**一句话**：从外圈开始，按"右 → 下 → 左 → 上"一圈圈把矩阵里的数读出来。

### 精讲（零基础版）

#### ① 这题要用到的东西

**列表切片 `row[a:b]`**

一句话：`row[a:b]` 取下标 a 到 b-1 这一段，得到一个新列表，原来的列表不动。

生活类比：一队人排着，把第 3 个到第 5 个整段叫出来问话，队伍本身没变。

```python
row = [1, 2, 3, 4, 5]
print(row[1:4])     # -> [2, 3, 4]
print(row[3:0:-1])  # -> [4, 3, 2]
print(row[::-1])    # -> [5, 4, 3, 2, 1]
```

它在这题里：读一整行时用切片一次性取出来，比一个个 `append` 短得多；读下边那一行要倒着来，靠的就是步长写 `-1`。

**列表拼接 `+`**

一句话：两个列表用 `+` 拼成一个新列表，前一个在前、后一个在后。

生活类比：两队人接成一队，前面那队先走。

```python
print([1, 2] + [3])   # -> [1, 2, 3]
```

它在这题里：`res = res + row[left:right+1]` 就是"把这一整行接到答案末尾"。

**四条边界：top / bottom / left / right**

一句话：用四个数字圈住"还没读的那块"，top 是最上面一行、bottom 是最下面一行、left 是最左一列、right 是最右一列。

生活类比：剥洋葱，剥掉外面一圈，剩下的芯还是被四条边圈着，只是边界往里收了一圈。

```python
top, bottom, left, right = 0, 2, 0, 2
top += 1
right -= 1
print(top, bottom, left, right)   # -> 1 2 0 1
```

它在这题里：每读完一条边就把它往里收一格，四条边撞到一起时正好读完。

#### ② 大白话：这题到底在干什么

最笨的办法：把走过的格子记在一张表上，每走到头就右转，遇到"走过的"或"出界的"再右转。

笨在哪：要多开一张和矩阵一样大的表格专门记"这个格子读没读过"，而且转向的逻辑容易写错。

聪明的办法：其实不用记录走过的格子。每一圈的形状都是一个长方形，只要知道这个长方形还剩哪四条边，就按"上边一行 → 右边一列 → 下边一行 → 左边一列"依次读掉，然后把长方形往里缩一圈，重复。上边读完了 top 加一，右边读完了 right 减一，下边、左边同理。每读一条边之前先检查这块还有没有东西，没有了就收工。

#### ③ 拿题面示例 1 走一遍

`array = [[1,2,3],[8,9,4],[7,6,5]]`，一开始 top=0、bottom=2、left=0、right=2。

| 步骤 | 读哪条边 | 读出来的数 | 答案变成 |
|---|---|---|---|
| 1 | 上边：第 0 行，列 0..2 | 1, 2, 3 | [1, 2, 3] |
| 2 | 右边：第 2 列，行 1..2 | 4, 5 | [1, 2, 3, 4, 5] |
| 3 | 下边：第 2 行，列 1..0 倒着读 | 6, 7 | [1, 2, 3, 4, 5, 6, 7] |
| 4 | 左边：第 0 列，行 1..1 | 8 | [1, 2, 3, 4, 5, 6, 7, 8] |
| 5 | 上边：第 1 行，列 1..1 | 9 | [1, 2, 3, 4, 5, 6, 7, 8, 9] |
| 结束 | top 变成 2，比 bottom = 1 还大 | — | 停 |

所以答案是 `[1,2,3,4,5,6,7,8,9]`，和题面一致。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `if not array or not array[0]: return []` | 空矩阵直接给空答案 |
| `top, bottom = 0, len(array) - 1` | 圈住整个矩阵的上下边 |
| `left, right = 0, len(array[0]) - 1` | 圈住整个矩阵的左右边 |
| `for c in range(left, right + 1):` | 上边一整行，从左读到右 |
| `res.append(array[top][c])` | 一个个装进答案 |
| `top += 1` | 上边往里收一格 |
| `if top > bottom: break` | 上边越过下边，说明读完了 |
| `for r in range(top, bottom + 1):` | 右边一整列，从上读到下 |
| `right -= 1` | 右边往里收一格 |
| `for c in range(right, left - 1, -1):` | 下边一整行，从右读到左 |
| `bottom -= 1` | 下边往里收一格 |
| `for r in range(bottom, top - 1, -1):` | 左边一整列，从下读到上 |
| `left += 1` | 左边往里收一格 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def spiralOrder(self, array: List[List[int]]) -> List[int]:
        if not array or not array[0]:
            return []
        res = []
        top, bottom = 0, len(array) - 1
        left, right = 0, len(array[0]) - 1
        while True:
            for c in range(left, right + 1):
                res.append(array[top][c])
            top += 1
            if top > bottom:
                break
            for r in range(top, bottom + 1):
                res.append(array[r][right])
            right -= 1
            if left > right:
                break
            for c in range(right, left - 1, -1):
                res.append(array[bottom][c])
            bottom -= 1
            if top > bottom:
                break
            for r in range(bottom, top - 1, -1):
                res.append(array[r][left])
            left += 1
            if left > right:
                break
        return res
```

边界自测：`[[1]]` 返回 `[1]`；只有一行 `[[1,2,3]]` 返回 `[1,2,3]`；只有一列 `[[1],[2],[3]]` 返回 `[1,2,3]`；`[]` 和 `[[]]` 都返回 `[]`。

## 49-4. 数组中的逆序对（Hard）

> 力扣 剑指 Offer 51 · 分治/归并排序 · Hard
> 前置：49-3（列表切片）

**一句话**：数一数数组里有多少对"前面的数比后面的数大"。

### 精讲（零基础版）

#### ① 这题要用到的东西

**递归：函数自己调用自己**

一句话：把大问题拆成一个一模一样的小问题，交给"自己"去算，直到小到能直接回答为止。

生活类比：想知道一个大箱子有多重，先称其中一个盒子，再把剩下的部分整个放上去称——"剩下的部分有多重"还是同一个问题，只是小了一点，于是再拆一次。

```python
def countdown(n):
    if n == 0:
        return
    print(n)
    countdown(n - 1)

countdown(3)   # -> 3
               # -> 2
               # -> 1
```

它在这题里：归并排序就是"左半边自己排好、右半边自己排好，再把两半合并"，那两个"自己排好"就是递归。`if n == 0: return` 这种能让递归停下来的条件叫出口，没有出口的递归会一直往下跑直到报错。

**把计数器挂在 `self` 上**

一句话：写在 `class Solution` 里的方法，第一个参数 `self` 代表"这个解法对象本身"；变量写成 `self.count` 就存进了对象里，所有方法（包括递归调用的自己）都读得到、改得动。

生活类比：把计分板钉在墙上，谁经过都能看一眼、加一笔；写在自己手心里就只有自己知道。

```python
class Counter:
    def __init__(self):
        self.n = 0

    def add(self):
        self.n += 1

c = Counter()
c.add()
c.add()
print(c.n)   # -> 2
```

它在这题里：`merge_sort` 会递归调用自己很多次，如果计数写成普通局部变量，每次调用都是新的一份；写成 `self.count` 才是同一块计分板。

**归并排序：两半各自排好，再合并**

一句话：把数组从中间切成两半，两半各自排序，然后用两个指针把两个有序数组拼成一个有序数组。

生活类比：两摞已经按身高排好的队伍，各看队首，矮的那个先出列，合成一队。

```python
left, right = [7, 9], [4, 5, 6]
i = j = 0
merged = []
while i < len(left) and j < len(right):
    if left[i] <= right[j]:
        merged.append(left[i])
        i += 1
    else:
        merged.append(right[j])
        j += 1
merged += left[i:] + right[j:]
print(merged)   # -> [4, 5, 6, 7, 9]
```

它在这题里：合并的时候有一个免费的副产品——每次从右半边取数，就说明右半边这个数比左半边"还没取的那些"都小。

**计数：`len(left) - i`**

一句话：合并到某一步时，左半边从下标 i 往后都还没取，它们的个数正好是 `len(left) - i`。

生活类比：左边队里还剩几个人，右边这个人就比这几个人都矮，一下就配出这么多对。

```python
left = [7, 9]
i = 0
print(len(left) - i)   # -> 2
print(left[i:])        # -> [7, 9]
```

它在这题里：`right[j]` 要出列时，它比 `left[i:]` 里每一个都小，而 `left[i:]` 在原数组里都排在它前面，所以一下子多出 `len(left) - i` 个逆序对。

#### ② 大白话：这题到底在干什么

最笨的办法：两两比一遍。i 从 0 走到 n-1，j 从 i+1 走到 n-1，只要 `record[i] > record[j]` 就记一个。

笨在哪：n = 50000 时要比 1249975000 次，也就是十二亿多次，跑不动。

聪明的办法：借用"归并排序"这个过程。归并排序在合并两个有序小段时，本来就要一个数一个数地比较大小；而比较的那一瞬间，"右半边的这个数比左半边剩下的几个数都小"是看得见的，顺手加进计数器就行。排序做完，答案也数完了，只比纯排序多了一行加法。

#### ③ 拿题面示例 `record = [9,7,5,4,6]` 走一遍

先切成 `[9,7]` 和 `[5,4,6]`，各自再切，一路切到单个数字，再一层层合并。

| 步骤 | 合并谁和谁 | 合并结果 | 本次新增 | 累计 |
|---|---|---|---|---|
| 1 | [9] + [7] | [7, 9] | 1 | 1 |
| 2 | [4] + [6] | [4, 6] | 0 | 1 |
| 3 | [5] + [4, 6] | [4, 5, 6] | 1 | 2 |
| 4 | [7, 9] + [4, 5, 6] | [4, 5, 6, 7, 9] | 6 | 8 |

第 1 步：7 比 9 小，右半边的 7 要出列，此时左半边还剩 `[9]` 一个数，新增 1 对 (9,7)。

第 3 步：4 比 5 小，右半边的 4 出列，左半边还剩 `[5]` 一个数，新增 1 对 (5,4)。

第 4 步：4 出列时左半边还剩 `[7,9]` 两个，加 2；5 出列时左半边还剩 `[7,9]` 两个，加 2；6 出列时左半边还剩 `[7,9]` 两个，加 2，一共加 6，对应 (7,4)(9,4)(7,5)(9,5)(7,6)(9,6)。

所以答案是 `8`，和题面示例一致。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `self.count = 0` | 计分板挂在对象上，递归每一层都能加 |
| `self.merge_sort(record)` | 排一遍序，排序过程中顺手数 |
| `if len(nums) <= 1: return nums` | 一个数或没有数，天然有序，直接返回（递归出口） |
| `mid = len(nums) // 2` | 从正中间切一刀 |
| `left = self.merge_sort(nums[:mid])` | 左半边交给递归排好 |
| `right = self.merge_sort(nums[mid:])` | 右半边也交给递归排好 |
| `while i < len(left) and j < len(right):` | 两摞都没取完就继续比 |
| `if left[i] <= right[j]:` | 左边这个更小 |
| `merged.append(left[i]); i += 1` | 先取左边的，不产生逆序对 |
| `else:` | 右边这个更小 |
| `self.count += len(left) - i` | 它比左半边剩下的每一个都小，一次记这么多对 |
| `merged.extend(left[i:])` | 左半边剩的整段接在后面 |
| `return merged` | 返回排好序的这一段 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def reversePairs(self, record: List[int]) -> int:
        self.count = 0
        self.merge_sort(record)
        return self.count

    def merge_sort(self, nums: List[int]) -> List[int]:
        if len(nums) <= 1:
            return nums
        mid = len(nums) // 2
        left = self.merge_sort(nums[:mid])
        right = self.merge_sort(nums[mid:])
        merged = []
        i = j = 0
        while i < len(left) and j < len(right):
            if left[i] <= right[j]:
                merged.append(left[i])
                i += 1
            else:
                merged.append(right[j])
                self.count += len(left) - i
                j += 1
        merged.extend(left[i:])
        merged.extend(right[j:])
        return merged
```

边界自测：`[1,2,3,4,5]` 返回 `0`；`[5,4,3,2,1]` 返回 `10`；`[7,5,6,4]` 返回 `5`；`[]` 返回 `0`。

## 49-5. 扑克牌中的顺子（Easy）

> 力扣 剑指 Offer 61 · 数组/矩阵 · Easy
> 前置：无

**一句话**：给 5 张牌，0 当万能牌，判断能不能凑成连续的五张。

### 精讲（零基础版）

#### ① 这题要用到的东西

**排序 `sorted()`**

一句话：`sorted(x)` 返回一个从小到大排好的新列表，原来的列表一点不动。

生活类比：把手里一把牌摊在桌上，从左到右按大小理一遍；理的是摊开的那一份，手里那把还是乱的。

```python
cards = [9, 0, 6, 0, 7]
print(sorted(cards))   # -> [0, 0, 6, 7, 9]
print(cards)           # -> [9, 0, 6, 0, 7]
```

它在这题里：排好序之后 0（万能牌）全跑到最前面，方便数"有几张万能牌"，也方便检查有没有重复。

**`count(0)` 和切片 `cards[zeros:]`（切片前面 49-3 讲过）**

一句话：`cards.count(0)` 数 0 出现了几次；`cards[zeros:]` 把前面这 zeros 张切掉，只剩真牌。

生活类比：先把大小王单独挑出来放一边，桌上只剩编号 1 到 13 的牌。

```python
cards = [0, 0, 6, 7, 9]
print(cards.count(0))   # -> 2
print(cards[2:])        # -> [6, 7, 9]
```

它在这题里：万能牌可以当任何数，所以它们不参与"有没有重复"和"跨度多大"的判断，先挑走。

**排序后，相同的数一定挨在一起**

一句话：从小到大排好之后，如果有两个一样的数，它们中间不可能插进别的数。

生活类比：按身高排队，两个一样高的人一定站在一起，中间不会夹一个更高的。

```python
nums = [7, 6, 6, 9]
print(sorted(nums))                          # -> [6, 6, 7, 9]
print(sorted(nums)[1] == sorted(nums)[0])    # -> True
```

它在这题里：不用集合去重，只要扫一遍"每个数和它前一个数是否相等"，就能查重。

**"最大值减最小值 < 5" 为什么够用**

一句话：五个连续整数的最大值减最小值正好是 4，所以只要真牌的最大值和最小值相差不超过 4，中间缺的位一定能用万能牌填满。

生活类比：一排 5 个座位，头尾两人已经坐下，中间空几个位就让万能牌坐进去；头尾跨度超过 4 个座位，这一排 5 个位子就装不下了。

```python
cards = [6, 7, 9]
print(cards[-1] - cards[0])                 # -> 3
print(cards[-1] - cards[0] < 5)             # -> True
cards2 = [6, 11, 12]
print(cards2[-1] - cards2[0] < 5)           # -> False
```

它在这题里：`rest[-1] - rest[0] < 5` 是最后一道判据，配合"没有重复"就能回答整道题。

#### ② 大白话：这题到底在干什么

最笨的办法：把每张 0 都换成 1 到 13 里某个还没出现过的数，每换一次就检查这五张牌是不是连续的，所有换法都试完。

笨在哪：0 最多 5 张，每张有 13 种换法，组合起来数量极大，而且大量换法得到的结果是重复的。

聪明的办法：换个角度，"能不能连成五张"其实只取决于两件事。

第一件，真牌里有没有重复？有重复就永远连不成，一对 6 不可能同时当 6 和 7。

第二件，真牌的最大值和最小值差多少？差 4 以内，中间的窟窿最多 4 个，手里的万能牌一定填得满；差到 5 及以上，五张牌的位置根本装不下这么长的跨度。

两条都过关就是顺子，否则不是。

#### ③ 拿题面示例 1 的 `places = [0,6,9,0,7]` 走一遍

| 步骤 | 结果 |
|---|---|
| 排序 `sorted(places)` | [0, 0, 6, 7, 9] |
| 数 0 的个数 | 2 |
| 切掉 0 剩下的真牌 | [6, 7, 9] |
| 查相邻有没有重复 | 6、7、9 互不相同，通过 |
| 最大值减最小值 | 9 - 6 = 3 |
| 3 < 5 是否成立 | 成立，返回 `True` |

所以答案是 `True`。两张 0 分别当 5 和 8，正好凑成 5、6、7、8、9 五个连续朝代。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `def isStraight(self, places: List[int]) -> bool:` | 收 5 张牌，还一个"是不是顺子" |
| `cards = sorted(places)` | 从小到大理牌，0 全跑到最前面 |
| `zeros = cards.count(0)` | 数一数有几张万能牌 |
| `rest = cards[zeros:]` | 把万能牌切掉，只看真牌 |
| `if len(rest) <= 1: return True` | 真牌不到两张，既没有重复也没有跨度问题 |
| `for i in range(1, len(rest)):` | 挨个看每张真牌和它前一张 |
| `if rest[i] == rest[i - 1]:` | 和前一张一样 |
| `return False` | 有重复，永远连不成 |
| `return rest[-1] - rest[0] < 5` | 跨度小于 5 就能连，否则不能 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def isStraight(self, places: List[int]) -> bool:
        cards = sorted(places)
        zeros = cards.count(0)
        rest = cards[zeros:]
        if len(rest) <= 1:
            return True
        for i in range(1, len(rest)):
            if rest[i] == rest[i - 1]:
                return False
        return rest[-1] - rest[0] < 5
```

边界自测：`[7,8,9,10,11]` 返回 `True`；`[0,0,2,3,4]` 返回 `True`；`[0,0,1,3,6]` 返回 `False`；`[0,1,1,2,3]` 返回 `False`（有重复）；`[0,0,0,0,0]` 返回 `True`。

## 49-6. 一次编辑（Medium）

> 力扣 面试题 01.05 · 字符串 · Medium
> 前置：49-3（切片）

**一句话**：判断两个字符串能不能只靠"插入 / 删除 / 替换一个字符"就变成一样。

### 精讲（零基础版）

#### ① 这题要用到的东西

**字符串切片（前面 49-3 讲过）**：`s[a:b]` 取下标 a 到 b-1 这一段，得到一个新字符串；`s[i:]` 表示从 i 一直取到末尾。这题用它把"已经对上的前半截"跳过去，只比较后面没对上的部分。

**长度差超过 1 就一定不行**

一句话：一次编辑最多让长度变化 1，长度差 2 及以上，一次怎么都不够。

生活类比：一摞书只许拿走一本或者塞进一本，厚度最多变化一本的厚度。

```python
print(abs(len("pale") - len("ple")))    # -> 1
print(abs(len("pales") - len("pal")))   # -> 2
```

它在这题里：开头一句 `if abs(...) > 1: return False` 就把示例 2 这类输入直接挡掉，不用再往下比。

**双指针：两个下标一起往前走**

一句话：用 i 指第一个串、j 指第二个串，字符相等就一起往前走，不相等就停下来处理。

生活类比：两个人对着同一段台词一个字一个字念，念到不一样的地方同时停住。

```python
s, t = "abc", "abd"
i = 0
while i < len(s) and s[i] == t[i]:
    i += 1
print(i)            # -> 2
print(s[i], t[i])   # -> c d
```

它在这题里：找到第一处对不上的位置 i，答案就只看 i 后面那一段。

**只比较剩下的尾巴**

一句话：第一处不同之前的字符都一样，之后能不能对上，取决于"跳过哪一个字符"。

生活类比：两句话前面完全一样，中间少了一个字，那就把长的那句在这个位置让开一个字，再看后面还对不对得上。

```python
first, second = "pale", "ple"
print(first[1:])                  # -> ale
print(second[1:])                 # -> le
print(first[1:] == second[1:])    # -> False
print(first[2:] == second[1:])    # -> True
```

它在这题里：长度相同说明是"替换"，比 `first[i+1:]` 和 `second[i+1:]`；长度差 1 说明是"插入/删除"，比 `first[i:]` 和 `second[i+1:]`。

#### ② 大白话：这题到底在干什么

最笨的办法：把两个串所有可能的编辑都试一遍（每个位置插入一个字符、删除一个字符、替换一个字符），看哪种能变成对方。

笨在哪：一个长度 1000 的串，光"替换"就有 1000×26 种，加上插入、删除，试不完；而且绝大多数改法一眼就知道不对。

聪明的办法：先看长度。差 2 及以上，一次编辑不可能，直接否掉。长度一样或差 1 之后，从头一个字一个字比，找到第一处不一样的位置。

长度一样：只可能用"替换"补救，那就看这一位之后两个尾巴是否完全相同。

长度差 1：只可能用"插入/删除"补救，让短的那个串停在原地，长的那个串跳过这一位，再看后面的尾巴是否完全相同。

尾巴对上了就是一次编辑（或者本来就一样，一次都不用改），对不上就不是。

#### ③ 拿题面示例 1 走一遍

`first = "pale"`、`second = "ple"`。长度差 1，先把长的那个放到后面：交换后 first = "ple"、second = "pale"。

| 步骤 | 位置 | first 的字符 | second 的字符 | 结果 |
|---|---|---|---|---|
| 1 | i=0 | p | p | 相同，继续 |
| 2 | i=1 | l | a | 不同，停下 |
| 3 | — | 长度不同（3 对 4） | — | 走"插入/删除"分支 |
| 4 | — | first[1:] = "le" | second[2:] = "le" | 相等 |

所以答案是 `True`：在 "ple" 的 a 前面插入一个 l，就得到 "pale"。

再看示例 2 的 `first = "pales"`、`second = "pal"`：长度差 2，第一步就被挡掉，直接返回 `False`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `def oneEditAway(self, first: str, second: str) -> bool:` | 收两个串，还一个"能不能一次改完" |
| `if abs(len(first) - len(second)) > 1:` | 长度差两格以上 |
| `return False` | 一次改不了 |
| `if len(first) > len(second):` | 让长的那个排后面 |
| `first, second = second, first` | 交换名字，后面只写一套逻辑 |
| `for i in range(len(first)):` | 从头一个字一个字比 |
| `if first[i] != second[i]:` | 找到第一处不一样 |
| `if len(first) == len(second):` | 长度一样，说明是"替换" |
| `return first[i + 1:] == second[i + 1:]` | 替换掉这一位之后，尾巴要完全一样 |
| `return first[i:] == second[i + 1:]` | 长度差 1，长的跳过这一位，尾巴要完全一样 |
| `return True` | 一路都没遇到不同，本来就一样 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def oneEditAway(self, first: str, second: str) -> bool:
        if abs(len(first) - len(second)) > 1:
            return False
        if len(first) > len(second):
            first, second = second, first
        for i in range(len(first)):
            if first[i] != second[i]:
                if len(first) == len(second):
                    return first[i + 1:] == second[i + 1:]
                return first[i:] == second[i + 1:]
        return True
```

边界自测：`("abc","abc")` 返回 `True`；`("abc","abd")` 返回 `True`；`("abc","axy")` 返回 `False`；`("","")` 返回 `True`；`("","a")` 返回 `True`；`("","ab")` 返回 `False`。

## 49-7. 旋转矩阵（Medium）

> 力扣 面试题 01.07 · 数组/矩阵 · Medium
> 前置：49-1（二维列表下标）

**一句话**：把 N×N 的方阵顺时针转 90 度，而且要原地改，不许另开一个矩阵。

### 精讲（零基础版）

#### ① 这题要用到的东西

**两数交换 `a, b = b, a`**

一句话：等号右边先把两个值都取出来，再一起赋给左边，所以一句话就能换掉两个变量。

生活类比：两个人换座位，先把两人都叫起来，再各自坐到对方的位置上，不会出现"坐重了"。

```python
a, b = 1, 2
a, b = b, a
print(a, b)   # -> 2 1
```

它在这题里：转置时要把 `matrix[i][j]` 和 `matrix[j][i]` 互换，用这一行最省事，也不需要临时变量。

**二维列表下标（前面 49-1 讲过）**：`matrix[i]` 是第 i 行，`matrix[i][j]` 是第 i 行第 j 列。这题靠改这两个下标完成转置。

**转置：行变列**

一句话：转置就是让第 i 行第 j 列的数跑到第 j 行第 i 列去，行和列互换。

生活类比：一张座位表，本来横着念是"第几排坐了谁"，转置之后横着念变成"第几列坐了谁"。

```python
m = [[1, 2], [3, 4]]
print(m[0][1], m[1][0])                          # -> 2 3
print([[m[0][0], m[1][0]], [m[0][1], m[1][1]]])  # -> [[1, 3], [2, 4]]
```

它在这题里：顺时针 90 度 = 先转置，再把每一行左右翻转，这两步拼起来正好是答案。

**`row.reverse()`：把一行原地倒过来**

一句话：`reverse()` 直接改这一行本身，不返回新列表。

生活类比：把一排人原地转身，还是那一排人，只是顺序反了。

```python
row = [1, 2, 3]
row.reverse()
print(row)   # -> [3, 2, 1]
```

它在这题里：转置之后对每一行调用一次 `reverse()`，矩阵就转好了，全程没有开新矩阵。

#### ② 大白话：这题到底在干什么

最笨的办法：新建一个 N×N 的空矩阵，把每个数按"新行 = 旧列、新列 = N-1-旧行"搬到新位置，最后再把新矩阵的内容抄回原矩阵。

笨在哪：题目问"不占用额外内存空间能否做到"，新建矩阵就多占了 N×N 的空间。

聪明的办法：把"顺时针转 90 度"拆成两步看得懂的操作。先沿主对角线**转置**（i 行 j 列与 j 行 i 列互换），再把每一行**左右翻转**。

比如 `[[1,2,3],[4,5,6],[7,8,9]]`，转置成 `[[1,4,7],[2,5,8],[3,6,9]]`，每行翻转后是 `[[7,4,1],[8,5,2],[9,6,3]]`，正好是题面要的结果。两步都只在原矩阵里换位置，一个格子都不多占。

#### ③ 拿题面示例 1 走一遍

`matrix = [[1,2,3],[4,5,6],[7,8,9]]`，n = 3。转置只处理对角线右上方那一半，也就是 (0,1)、(0,2)、(1,2) 三对。

| 步骤 | 操作 | 矩阵当前样子 |
|---|---|---|
| 开始 | — | [[1,2,3],[4,5,6],[7,8,9]] |
| 1 | 交换 (0,1) 与 (1,0) | [[1,4,3],[2,5,6],[7,8,9]] |
| 2 | 交换 (0,2) 与 (2,0) | [[1,4,7],[2,5,6],[3,8,9]] |
| 3 | 交换 (1,2) 与 (2,1) | [[1,4,7],[2,5,8],[3,6,9]] |
| 4 | 第 0 行 reverse | [[7,4,1],[2,5,8],[3,6,9]] |
| 5 | 第 1 行 reverse | [[7,4,1],[8,5,2],[3,6,9]] |
| 6 | 第 2 行 reverse | [[7,4,1],[8,5,2],[9,6,3]] |

所以答案是 `[[7,4,1],[8,5,2],[9,6,3]]`，和题面一致。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `def rotate(self, matrix: List[List[int]]) -> None:` | 原地改，所以没有返回值 |
| `n = len(matrix)` | 方阵的边长 |
| `for i in range(n):` | 一行一行来 |
| `for j in range(i + 1, n):` | 只取对角线右上方那一半 |
| `matrix[i][j], matrix[j][i] = ...` | 转置：i 行 j 列与 j 行 i 列互换 |
| `= matrix[j][i], matrix[i][j]` | 等号右边先把两个值都取出来，不会互相覆盖 |
| `for row in matrix:` | 转置完了，逐行处理 |
| `row.reverse()` | 每一行左右翻转，原地改 |

`j` 从 `i + 1` 开始而不是从 0 开始，是为了不把刚换好的又换回去：如果 (0,1) 和 (1,0) 换两次，等于没换。

### 完整代码（Python）

```python
from typing import List


class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        n = len(matrix)
        for i in range(n):
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        for row in matrix:
            row.reverse()
```

边界自测：`[[1]]` 返回 `[[1]]`；`[[1,2],[3,4]]` 返回 `[[3,1],[4,2]]`；题面示例 2 的 4×4 输入返回 `[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]`。

## 49-8. 汉诺塔问题（Easy）

> 力扣 面试题 08.06 · 递归/栈 · Easy
> 前置：49-4（递归）

**一句话**：把 A 柱上的一摞盘子整体搬到 C 柱，中途借用 B 柱，每次只能搬一个，大盘不能压在小盘上。

### 精讲（零基础版）

#### ① 这题要用到的东西

**递归（前面 49-4 讲过）**：函数自己调用自己，把"搬 n 个盘子"拆成"搬 n-1 个盘子"的同类小问题，n 减到 0 就停。这题用它把大任务一层层拆小。

**栈：只能在末尾增删的列表**

一句话：列表的 `append` 往末尾加一个，`pop()` 从末尾拿走一个，`[-1]` 只看末尾那个但不拿走。把列表竖起来看就是一摞盘子，只能从顶上动。

生活类比：一摞盘子，你只能往最上面放、从最上面取，想抽中间那个会全塌。

```python
stack = [3, 2, 1]
print(stack[-1])     # -> 1
print(stack.pop())   # -> 1
print(stack)         # -> [3, 2]
stack.append(0)
print(stack)         # -> [3, 2, 0]
```

它在这题里：题目直接用列表表示柱子，`A[-1]` 就是 A 柱最上面那个盘子，`A.pop()` 就是"从 A 柱顶上拿走一个"，`C.append(x)` 就是"放到 C 柱顶上"。

**原地修改和换名字的区别**

一句话：`C.append(x)` 是往 C 这个列表里真的加东西，调用方手里的 C 也跟着变；`C = [1,2,3]` 只是让函数里的名字 C 指向另一个新列表，调用方的 C 一点没动。

生活类比：往公用冰箱里放东西，别人打开冰箱能看到；自己另买一个冰箱放家里，别人家的冰箱不会多东西。

```python
def bad(C):
    C = [9]

def good(C):
    C.append(9)

a, b = [], []
bad(a)
good(b)
print(a, b)   # -> [] [9]
```

它在这题里：题目要求"原地修改栈"，所以只能写 `C.append(...)`、`A.pop()`，不能写 `C = ...`。

#### ② 大白话：这题到底在干什么

最笨的办法：把每一步都手写出来。3 个盘子是 7 步，4 个盘子是 15 步，14 个盘子是 16383 步，写不动。

笨在哪：步数随盘子数翻倍增长，硬写不可能；但每一步的规律其实完全一样。

聪明的办法：只盯住"把 n 个盘子从 src 搬到 dst"这一件事，把它拆成三步。

第一步，先把上面 n-1 个盘子从 src 搬到 mid，这一步要借 dst 当中转。

第二步，把 src 最底下那个最大的盘子直接搬到 dst，因为它最大，放在空柱子上不会压到谁。

第三步，再把 mid 上的 n-1 个盘子搬到 dst，这次借 src 当中转。

第一步和第三步都是"搬 n-1 个盘子"，和原问题是同一件事，只是数量少一个，于是交给递归。n 减到 0 就什么都不用做。

#### ③ 拿题面示例 1 的 `A = [2,1,0]` 走一遍

3 个盘子一共 7 步，每一步都是"从某根柱子的顶上拿一个，放到另一根柱子顶上"。

| 步骤 | 动作（搬哪个盘子，从哪到哪） | A | B | C |
|---|---|---|---|---|
| 1 | 盘子 0：A → C | [2,1] | [] | [0] |
| 2 | 盘子 1：A → B | [2] | [1] | [0] |
| 3 | 盘子 0：C → B | [2] | [1,0] | [] |
| 4 | 盘子 2：A → C | [] | [1,0] | [2] |
| 5 | 盘子 0：B → A | [0] | [1] | [2] |
| 6 | 盘子 1：B → C | [0] | [] | [2,1] |
| 7 | 盘子 0：A → C | [] | [] | [2,1,0] |

所以答案是 `C = [2,1,0]`，和题面一致。注意 C 里现在是"2 在底、0 在顶"，和 A 一开始的顺序完全一样，因为大盘永远在下。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `def hanota(self, A, B, C) -> None:` | 收三根柱子，原地改，没有返回值 |
| `self.move(len(A), A, B, C)` | 把 A 上全部盘子搬到 C，B 当中转 |
| `def move(self, n, src, mid, dst) -> None:` | 搬 n 个盘子：从 src 到 dst，mid 是中转 |
| `if n == 0: return` | 没有盘子要搬，直接结束（递归出口） |
| `self.move(n - 1, src, dst, mid)` | 先把上面 n-1 个搬到中转柱 |
| `src.pop()` | 从源柱顶上拿走一个 |
| `dst.append(...)` | 放到目标柱顶上 |
| `self.move(n - 1, mid, src, dst)` | 再把中转柱上的 n-1 个搬到最后的目标柱 |

两次递归调用里参数的顺序变了：第一次是 `src, dst, mid`，把"目标"和"中转"两个角色对调；第二次是 `mid, src, dst`，"出发点"和"中转"对调。角色的对调就是这一步的全部内容。

### 完整代码（Python）

```python
from typing import List


class Solution:
    def hanota(self, A: List[int], B: List[int], C: List[int]) -> None:
        self.move(len(A), A, B, C)

    def move(self, n: int, src: List[int], mid: List[int], dst: List[int]) -> None:
        if n == 0:
            return
        self.move(n - 1, src, dst, mid)
        dst.append(src.pop())
        self.move(n - 1, mid, src, dst)
```

边界自测：`A = [1,0]` 时 C 变成 `[1,0]`；`A = []` 时 C 保持 `[]`；`A = [0]` 时 C 变成 `[0]`。

## 49-9. 单词频率（Medium）

> 力扣 面试题 16.02 · 哈希表 · Medium
> 前置：49-4（`self`）

**一句话**：先给一整本书的单词，之后反复问"某个单词在书里出现几次"，每次都要答得快。

### 精讲（零基础版）

#### ① 这题要用到的东西

**哈希表（字典 dict）：名字 → 值**

一句话：字典用"键"直接查到"值"，不用从头翻；`cnt[键]` 取值，`cnt[键] = 值` 存值。

生活类比：查字典按拼音直接翻到那一页，不用从第一页开始读。

```python
cnt = {"have": 2, "an": 1}
print(cnt["have"])   # -> 2
cnt["pen"] = 1
print(cnt)           # -> {'have': 2, 'an': 1, 'pen': 1}
```

它在这题里：把"单词"当键、"出现次数"当值，问一次查一次，都是瞬间出结果。

**`dict.get(键, 默认值)`**

一句话：`get` 按键取值，键不存在时不报错，而是返回你给的默认值。

生活类比：问前台"张三在不在"，不在就回答"没有"，而不是把前台弄崩。

```python
cnt = {"have": 2}
print(cnt.get("have", 0))   # -> 2
print(cnt.get("you", 0))    # -> 0
print("you" in cnt)         # -> False
```

它在这题里：`self.cnt.get(word, 0)` 一句话回答查询，没出现过的单词自然返回 0。

**类：`__init__` 和 `self`（`self` 前面 49-4 讲过）**

一句话：这题要交的不是"一个函数"，而是"一个对象"：`__init__` 在对象刚造出来时跑一次（把书读进字典），之后每次调用 `get` 都用这份字典。

生活类比：开业那天把货全部上架（`__init__`），之后顾客来问（`get`）直接查货架。

```python
class Adder:
    def __init__(self, start):
        self.total = start

    def add(self, x):
        self.total += x
        return self.total

a = Adder(10)
print(a.add(5))   # -> 15
print(a.add(1))   # -> 16
```

它在这题里：`__init__` 里把 book 统计成字典存进 `self.cnt`；`get` 只管查这张表，所以每次查询都只是一次取值。

**`Counter`：现成的计数器**

一句话：`collections.Counter(列表)` 直接把"每个元素出现几次"统计成一个字典。

生活类比：把一筐水果按品种分堆，每堆数一下写个标签。

```python
from collections import Counter
print(Counter(["a", "b", "a"]))       # -> Counter({'a': 2, 'b': 1})
print(Counter(["a", "b", "a"])["a"])  # -> 2
```

它在这题里：`__init__` 里一行就统计完，不用自己写循环和 `get`。

#### ② 大白话：这题到底在干什么

最笨的办法：每次有人问"have 出现几次"，就把整本书从头到尾扫一遍，数到几就是几。

笨在哪：书最多 10 万个单词，查询也最多 10 万次，最坏要扫一百亿个单词，太慢。

聪明的办法：书是固定的、只给一次，问题却要问很多次。那就把活提前干完：造对象的时候把整本书扫一遍，用一个字典记下每个单词出现过几次。之后每次查询只是在这个字典里按键取值，一次就出结果。这是典型的"预处理换查询速度"——花一次 O(书的大小) 的功夫，把之后每一次查询都变成 O(1)。

#### ③ 拿题面示例走一遍

`book = ["i","have","an","apple","he","have","a","pen"]`，一共 8 个单词。

| 步骤 | 动作 | 结果 |
|---|---|---|
| 1 | 造对象时统计 | {'i':1, 'have':2, 'an':1, 'apple':1, 'he':1, 'a':1, 'pen':1} |
| 2 | get("you") | 字典里没有，返回 0 |
| 3 | get("have") | 字典里是 2，返回 2 |
| 4 | get("an") | 返回 1 |
| 5 | get("apple") | 返回 1 |
| 6 | get("pen") | 返回 1 |

所以示例里五个查询的答案依次是 0、2、1、1、1。整本书 8 个单词、7 个不同的单词，`have` 出现了 2 次，7 + 1 = 8，数目正好对得上。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `from typing import List` | 类型标注要用的 List，力扣后台已自动导入 |
| `from collections import Counter` | 把现成的计数器拿进来 |
| `class WordsFrequency:` | 这题要交的是一个类，不是一个函数 |
| `def __init__(self, book: List[str]):` | 造对象时执行一次，参数是整本书 |
| `self.cnt = Counter(book)` | 把书统计成"单词 → 次数"的字典，存进对象 |
| `self.cnt` | 之后每次查询都查这一份字典，不再看 book |
| `def get(self, word: str) -> int:` | 每次查询调用一次 |
| `return self.cnt.get(word, 0)` | 查字典；没这个单词就返回 0 |

### 完整代码（Python）

```python
from typing import List
from collections import Counter


class WordsFrequency:

    def __init__(self, book: List[str]):
        self.cnt = Counter(book)

    def get(self, word: str) -> int:
        return self.cnt.get(word, 0)
```

力扣这题提交的类是 `WordsFrequency`，不是 `Solution`，`__init__` 和 `get` 的名字都不能改。边界自测：查询一个书里没出现过的单词返回 `0`；`book` 只有一个元素时，查这个元素返回 `1`。

## 49-10. 模式匹配（Medium）

> 力扣 面试题 16.18 · 字符串 · Medium
> 前置：49-3（切片）

**一句话**：pattern 里只有 a 和 b 两种字母，判断 value 能不能拆成"a 代表一段、b 代表另一段"。

### 精讲（零基础版）

#### ① 这题要用到的东西

**枚举：把所有可能一个个试**

一句话：不知道 a 代表多长，那就把 a 的长度从 0 到 `len(value)` 每个都试一遍，试到对上为止。

生活类比：密码锁不知道是几位，从 0 位试到最长，总有一位对。

```python
value = "dogcatcatdog"
for la in range(4):
    print(la, repr(value[:la]))
```

输出：

```
0 ''
1 'd'
2 'do'
3 'dog'
```

它在这题里：外层 `for la in range(n + 1)` 就是"假设 a 有这么长"，每一种假设都按 pattern 拼一遍试试。

**由总长度反推 b 的长度**

一句话：a 出现 ca 次、b 出现 cb 次，如果 a 长 la，那么 b 的长度只能是 `(n - ca*la) / cb`，除不尽就说明这个 la 不可能。

生活类比：一箱苹果和梨共 12 个，苹果装了 2 筐、每筐 3 个，剩下的梨装 2 筐，每筐自然是 3 个。

```python
n, ca, cb, la = 12, 2, 2, 3
print(n - ca * la)          # -> 6
print((n - ca * la) % cb)   # -> 0
print((n - ca * la) // cb)  # -> 3
```

它在这题里：不用再套一层循环去猜 b 的长度，一条除法就把它定死，速度快很多。

**`count` 数某个字符出现几次**

一句话：字符串的 `count` 数某个字符在里面出现了几次。

生活类比：一段话里数有几个逗号，从头划到尾，划一个记一个。

```python
print("abba".count('a'))   # -> 2
print("abba".count('b'))   # -> 2
```

它在这题里：ca 和 cb 决定"总长度里 a 占几份、b 占几份"，是反推长度的前提。

**切片（前面 49-3 讲过）**：`value[pos:pos+L]` 取出从 pos 开始的 L 个字符。这题用它按 pattern 的顺序一段段切出 a 和 b 对应的子串。

#### ② 大白话：这题到底在干什么

最笨的办法：把 a 和 b 所有可能的字符串都试一遍——a 从空串试到整个 value，b 也一样，然后看拼出来等不等于 value。

笨在哪：光 a 的长度就有上千种可能，每种长度下还有 26 的"长度次方"种内容，b 再乘一层，根本试不完。

聪明的办法：不去猜"内容"，只猜"长度"。pattern 里 a 和 b 各出现几次是固定的，一旦假设 a 长 la，b 的长度就被总长度定死了（除不尽就跳过这个 la）。长度定了以后，从 value 开头按 pattern 的顺序一段段切下来，第一段就是 a 的样子、第二段是 b 的样子，后面每次切到的 a 都必须和第一段一模一样，b 同理。全部切完还正好用完整串，就匹配。

还要照顾题目那句"a 和 b 不能同时表示相同的字符串"：如果 pattern 里 a 和 b 都出现过，切出来的两段内容不能相等。

#### ③ 拿题面示例 1 走一遍

`pattern = "abba"`、`value = "dogcatcatdog"`。value 长 12，a 出现 2 次、b 出现 2 次。

| 假设 a 的长度 | 剩下的长度 | b 的长度 | 切出来的 a / b | 结论 |
|---|---|---|---|---|
| 0 | 12 | 6 | a=''，b='dogcat' | 第二个 b 切出 'catdog'，和 'dogcat' 不同，不行 |
| 1 | 10 | 5 | a='d'，b='ogcat' | 第二个 b 切出 'catdo'，不行 |
| 2 | 8 | 4 | a='do'，b='gcat' | 第二个 b 切出 'catd'，不行 |
| 3 | 6 | 3 | a='dog'，b='cat' | 两次都是 'cat'，拼完正好 12 个字符，匹配 |

所以答案是 `True`：a = "dog"，b = "cat"，"dog" + "cat" + "cat" + "dog" 正好是 value。

再看示例 3 的 `pattern = "aaaa"`、`value = "dogcatcatdog"`：cb = 0，只能让 a 长 la，要求 4 × la 正好等于 12，可 12 除以 4 得 3，la = 3 时 a = "dog"、"cat"、"cat"、"dog" 四段并不相同，所以不匹配。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `if not pattern: return not value` | pattern 是空的，只有 value 也空才算匹配 |
| `ca = pattern.count('a')` | a 在 pattern 里出现几次 |
| `cb = len(pattern) - ca` | 剩下的次数都是 b 的 |
| `for la in range(n + 1):` | 挨个假设 a 的长度 |
| `rest = n - ca * la` | 去掉 a 占掉的字符，还剩多少 |
| `if cb == 0: if rest != 0: continue` | pattern 里只有 a，长度必须刚好用完 |
| `if rest < 0 or rest % cb != 0: continue` | 除不尽，这个假设不成立，换下一个 |
| `lb = rest // cb` | b 的长度被定死了 |
| `ma = mb = None` | 一开始还不知道 a、b 长什么样 |
| `sub = value[pos:pos + L]` | 按顺序切出一段 |
| `if ma is None: ma = sub` | 第一次遇到 a，把它记下来 |
| `elif ma != sub: ok = False` | 后面再遇到 a，必须和第一次一样 |
| `if ok and pos == n:` | 全部切完，正好用完整串 |
| `if ca == 0 or cb == 0 or ma != mb: return True` | a、b 都在场时，两者内容不能相同 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def patternMatching(self, pattern: str, value: str) -> bool:
        if not pattern:
            return not value
        ca = pattern.count('a')
        cb = len(pattern) - ca
        n = len(value)
        for la in range(n + 1):
            rest = n - ca * la
            if cb == 0:
                if rest != 0:
                    continue
                lb = 0
            else:
                if rest < 0 or rest % cb != 0:
                    continue
                lb = rest // cb
            ma = mb = None
            pos = 0
            ok = True
            for ch in pattern:
                L = la if ch == 'a' else lb
                sub = value[pos:pos + L]
                if len(sub) != L:
                    ok = False
                    break
                if ch == 'a':
                    if ma is None:
                        ma = sub
                    elif ma != sub:
                        ok = False
                        break
                else:
                    if mb is None:
                        mb = sub
                    elif mb != sub:
                        ok = False
                        break
                pos += L
            if ok and pos == n:
                if ca == 0 or cb == 0 or ma != mb:
                    return True
        return False
```

边界自测：`("","")` 返回 `True`；`("","abc")` 返回 `False`；`("a","")` 返回 `True`；`("ab","")` 返回 `False`（a、b 不能都是空串）；`("b","abc")` 返回 `True`。

## 49-11. 最大子矩阵（Hard）

> 力扣 面试题 17.24 · 动态规划/前缀和 · Hard
> 前置：无

**一句话**：在一个有正有负的矩阵里，找一个"元素之和最大"的子矩阵，返回它的左上角和右下角坐标。

### 精讲（零基础版）

#### ① 这题要用到的东西

**累加：把多行压成一行**

一句话：想只看第 top 行到第 bottom 行这一横条，就把这几行同一个位置的数加起来，得到一个新的一维数组，里面每一格都是"这一列在这几行里加起来是多少"。

生活类比：把几层楼的高度表叠成一张总表，每一列写的是这几层加起来的数。

```python
matrix = [[1, 2], [3, 4]]
col = [0, 0]
for r in range(2):
    for c in range(2):
        col[c] += matrix[r][c]
print(col)   # -> [4, 6]
```

它在这题里：枚举行的上下界，每换一次 bottom 就把新的一行加到 `col_sum` 上，二维的问题立刻变成一维的问题。

**一维"最大子段和"（Kadane 思路）**

一句话：在一维数组里找"连续一段的和最大"，只要一路往右加：加上当前数之后如果反而变小了，不如从当前数重新开始。

生活类比：接力攒钱，前面攒的钱还不够抵消这次的亏损，那就不如从今天重新开始记。

```python
nums = [-2, 1, -3, 4, -1]
cur = best = nums[0]
for x in nums[1:]:
    cur = max(x, cur + x)
    best = max(best, cur)
print(cur, best)   # -> 3 4
```

它在这题里：压成一维之后，这个"连续一段的最大和"就对应"列范围 c1..c2 里所有元素之和"，也就是一个候选子矩阵的和。

**用 `None` 表示"还没有答案"**

一句话：一开始还没比较过任何候选，用 `None` 占位；第一次比较时把 `best is None` 也当成条件，就能顺利记下第一个候选。

生活类比：比赛还没开始，冠军栏先空着写"待定"，第一位选手一上场就直接填进去。

```python
best = None
for x in [-3, -1, -4]:
    if best is None or x > best:
        best = x
print(best)   # -> -1
```

它在这题里：矩阵里可能全是负数，用 `0` 当初始值会把"全是负数"的情况答错，用 `None` 就不会。

#### ② 大白话：这题到底在干什么

最笨的办法：枚举所有可能的子矩阵（左上角一对坐标、右下角一对坐标），每个都求一次和，取最大的。

笨在哪：N = M = 200 时，行的上下界有 20100 种选法，列的左右界也有 20100 种，合起来四亿多个矩形，每个再求和，完全跑不完。

聪明的办法：先固定"用哪几行"（枚举 top 和 bottom），把这几行按列加起来，压成一个一维数组。这样"这个横条里的最大子矩阵"就变成"这个一维数组里的最大连续子段和"。一维版本只要从左到右扫一遍：一路累加，累加到变成负数就丢掉、从当前位置重新开始。扫的过程中记下最大值以及它对应的列范围，再加上当前的 top、bottom，就凑齐了 `[r1, c1, r2, c2]`。

#### ③ 拿题面示例 `[[-1,0],[0,-1]]` 走一遍

| 轮次 | 行区间 top..bottom | 压出来的一维数组 | 这一轮的最大连续和 | 记下的答案 |
|---|---|---|---|---|
| 1 | 0..0 | [-1, 0] | 0（第 1 列单独那个 0） | [0,1,0,1] |
| 2 | 0..1 | [-1, -1] | -1，不如已有的 0 | 不变 |
| 3 | 1..1 | [0, -1] | 0，和已有的 0 一样大，不更新 | [0,1,0,1] |

所以答案是 `[0,1,0,1]`，也就是右下角那个单独的 0，和题面一致。题面说"若有多个满足条件的子矩阵，返回任意一个均可"，左上角那个 0 同样是和 0，返回它也合法。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `def getMaxMatrix(self, matrix) -> List[int]:` | 收矩阵，还四个坐标 |
| `rows, cols = len(matrix), len(matrix[0])` | 行数、列数 |
| `best = None; res = []` | best 记"目前最大的和"，None 表示还没开始比 |
| `for top in range(rows):` | 枚举子矩阵的上边界 |
| `col_sum = [0] * cols` | 每换一个 top，重新开始累加 |
| `for bottom in range(top, rows):` | 枚举下边界，从 top 开始往下长 |
| `col_sum[c] += matrix[bottom][c]` | 把新的一行加到列和里 |
| `if cur <= 0: cur = col_sum[c]; start = c` | 前面的和是负的，不如从这一列重新开始 |
| `else: cur += col_sum[c]` | 否则接着累加 |
| `if best is None or cur > best:` | 出现了更大的和 |
| `res = [top, start, bottom, c]` | 顺手记下四个坐标 |

外层两重循环是 O(rows²)，里面每轮扫一遍列是 O(cols)，所以总复杂度是 O(rows² × cols)。200×200 的矩阵大约 800 万次加法，跑得动。

### 完整代码（Python）

```python
from typing import List


class Solution:
    def getMaxMatrix(self, matrix: List[List[int]]) -> List[int]:
        if not matrix or not matrix[0]:
            return []
        rows, cols = len(matrix), len(matrix[0])
        best = None
        res = []
        for top in range(rows):
            col_sum = [0] * cols
            for bottom in range(top, rows):
                for c in range(cols):
                    col_sum[c] += matrix[bottom][c]
                cur = 0
                start = 0
                for c in range(cols):
                    if cur <= 0:
                        cur = col_sum[c]
                        start = c
                    else:
                        cur += col_sum[c]
                    if best is None or cur > best:
                        best = cur
                        res = [top, start, bottom, c]
        return res
```

边界自测：`[[5]]` 返回 `[0,0,0,0]`；`[[1,2],[3,4]]` 返回 `[0,0,1,1]`（整个矩阵和是 10，最大）；`[[-3,-2],[-1,-4]]` 返回 `[1,0,1,0]`（全是负数，最大是单个 -1）。另外 `[[9,-8,1,3],[-4,6,7,-2],[5,8,-9,4]]` 返回 `[0,0,2,3]`，对应子矩阵的和是 20。
