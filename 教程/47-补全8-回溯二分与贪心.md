## 47-1. x 的平方根（Easy）

> 力扣 69 · 二分查找 · Easy

**一句话**：找一个整数 r，使 r² ≤ x 而 (r+1)² > x，也就是 x 平方根的整数部分。

### 精讲（零基础版）

#### ① 这题要用到的东西

**二分查找**

- 一句人话：在一个"排好序、看一眼就能判断该往左还是往右"的范围里，每次砍掉一半。
- 生活类比：猜数字 1~100，你说 50，对方说"大了"，那 51~100 就全部作废。
- 最小例子：

```python
nums = [1, 3, 5, 7, 9, 11]
target = 7
left, right = 0, len(nums) - 1
while left <= right:
    mid = (left + right) // 2
    if nums[mid] == target:
        print("找到，下标", mid)   # -> 找到，下标 3
        break
    if nums[mid] < target:
        left = mid + 1            # 太小，去右半边
    else:
        right = mid - 1           # 太大，去左半边
```

- 这题里干什么：平方根没有现成公式能用（题目还不许用 `**0.5`），但"mid 的平方比 x 大还是小"一算就知道，正好能二分。

**整除 `//`**

- 一句人话：做除法但只留整数部分，小数直接丢掉。
- 生活类比：13 块糖分给 4 个人，每人 3 块，剩下 1 块不要了。
- 最小例子：

```python
print(13 // 4)   # -> 3
print(7 // 2)    # -> 3
print(0 // 2)    # -> 0
```

- 这题里干什么：`mid = (left + right) // 2` 用来取中点，中点必须是个整数下标，不能是 3.5。

#### ② 大白话：这题到底在干什么

最笨的办法：从 0 开始一个个试，试到"这个数的平方超过 x"就停，返回前一个。x 最大到 21 亿，最坏要试 46340 次左右，其实也能过，但不是这题想考的做法。

聪明办法：把 0 到 x 看成一排从小到大排好的候选答案，越靠右平方越大。每次取正中间那个数试一下：平方没超过 x，说明答案至少是它，先记下来，再去右半边找更大的；平方超过了，说明答案在左半边。

有个坑要注意：答案不一定是"平方正好等于 x"的数。比如 x = 8，没有整数的平方等于 8，答案取 2。所以需要一个变量专门记住"目前最靠右的那个合格值"。

#### ③ 拿一个具体输入走一遍

以题面示例 x = 8 为例：

| 步骤 | left / right | mid | mid² 与 8 比 | 动作 |
|---|---|---|---|---|
| 1 | 0 / 8 | 4 | 16 > 8 | 太大，right = 3 |
| 2 | 0 / 3 | 1 | 1 ≤ 8 | 合格，ans = 1，left = 2 |
| 3 | 2 / 3 | 2 | 4 ≤ 8 | 合格，ans = 2，left = 3 |
| 4 | 3 / 3 | 3 | 9 > 8 | 太大，right = 2 |
| 5 | 3 / 2 | — | left 超过 right | 循环结束 |

所以答案是 2（8 的平方根是 2.828…，小数部分被舍掉）。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `left, right = 0, x` | 候选范围一开始是 0 到 x（答案不会超过 x 本身） |
| `ans = 0` | 记住目前找到的"最靠右的合格答案"，先记 0 |
| `while left <= right:` | 范围里还有数就继续找 |
| `mid = (left + right) // 2` | 取正中间那个数 |
| `if mid * mid <= x:` | 它的平方没超过 x，说明 mid 本身合格 |
| `ans = mid` | 先把 mid 记成答案（后面可能找到更大的） |
| `left = mid + 1` | 去 mid 右边继续找，看能不能更大 |
| `else:` | 平方超过 x 了，mid 太大 |
| `right = mid - 1` | 把 mid 和它右边全部扔掉 |
| `return ans` | 循环结束时 ans 就是平方根的整数部分 |

### 完整代码（Python）

```python
class Solution:
    def mySqrt(self, x: int) -> int:
        left, right = 0, x
        ans = 0
        while left <= right:
            mid = (left + right) // 2
            if mid * mid <= x:
                ans = mid
                left = mid + 1
            else:
                right = mid - 1
        return ans
```

## 47-2. 两个数组的交集（Easy）

> 力扣 349 · 二分查找 · Easy

**一句话**：找出两个数组里都出现过的数，结果里每个数只留一份。

### 精讲（零基础版）

#### ① 这题要用到的东西

**集合 `set`**

- 一句人话：一个"只记有没有、不记顺序、不放重复"的袋子。
- 生活类比：会场门口的签到表，同一个名字签十次也只算一个人到了。
- 最小例子：

```python
s = set()
s.add(4)
s.add(9)
s.add(4)          # 加第二遍，没有效果
print(s)          # -> {9, 4}   （顺序不保证，可能显示成 {4, 9}）
print(4 in s)     # -> True
print(sorted(s))  # -> [4, 9]   （想要顺序就自己排一下）
```

- 这题里干什么：题目要求"输出结果中的每个元素一定是唯一的"，用集合装结果天然去重，最后转成列表返回。

**列表原地排序 `list.sort()`**

- 一句人话：把列表本身从小到大排好，改的是原来那个列表，不产生新列表。
- 生活类比：把摊在桌上的一摞扑克牌，就在这张桌子上理齐。
- 最小例子：

```python
a = [9, 4, 9, 8, 4]
a.sort()
print(a)          # -> [4, 4, 8, 9, 9]
b = sorted(a)     # sorted 是另给一个新列表
print(b)          # -> [4, 4, 8, 9, 9]
```

- 这题里干什么：只有排好序的数组才能二分。这题我们挑第二个数组去排序。

**`bisect_left`**

- 一句人话：在一个已经排好序的列表里，找出"第一个不小于 v 的位置"。
- 生活类比：查字典找一个词，翻到它"应该插进去"的那一页。
- 最小例子：

```python
import bisect
a = [4, 4, 8, 9, 9]
print(bisect.bisect_left(a, 8))    # -> 2
print(bisect.bisect_left(a, 5))    # -> 2   （5 该插在下标 2）
print(bisect.bisect_left(a, 100))  # -> 5   （比所有数都大，返回列表长度）
```

- 这题里干什么：nums2 排序后，对 nums1 里每个数 v 用 `bisect_left` 找到位置，再看那个位置上的数是不是 v。是，就说明 v 在 nums2 里出现过；不是，就说明没有。

#### ② 大白话：这题到底在干什么

最笨的办法：拿 nums1 的每一个数，去 nums2 里从头到尾扫一遍看有没有。两个数组各 1000 个数的话，要扫 100 万次，而且同一个数会被反复确认很多遍。

聪明办法：先把 nums2 排好序，这样"查一个数在不在"就不用从头扫了，一次二分只要十几次比较。再拿一个集合装结果，同一个数不管命中几次，集合里只留一份。

#### ③ 拿一个具体输入走一遍

以题面示例 2 为例：`nums1 = [4,9,5]`，`nums2 = [9,4,9,8,4]`。先把 nums2 排好序，得到 `[4, 4, 8, 9, 9]`。

| 步骤 | 取 nums1 的数 v | bisect_left 位置 | 是否命中（位置上的值） | 结果集合 |
|---|---|---|---|---|
| 1 | 4 | 0 | 是（位置 0 上是 4） | {4} |
| 2 | 9 | 3 | 是（位置 3 上是 9） | {4, 9} |
| 3 | 5 | 2 | 否（位置 2 上是 8） | {4, 9} |

所以答案是 `[4, 9]`（题面说 `[9, 4]` 也算通过，集合转列表的顺序不固定）。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `nums2.sort()` | 把第二个数组原地排好序，为二分做准备 |
| `res = set()` | 结果用集合装，天然去重 |
| `for v in nums1:` | 遍历第一个数组里的每个数 |
| `i = bisect.bisect_left(nums2, v)` | 在排好序的 nums2 里找 v 该待的位置 |
| `if i < len(nums2)` | 位置没越界，说明后面还有数可以比 |
| `and nums2[i] == v` | 而且那个位置上的数正好就是 v |
| `res.add(v)` | 两边都有，收进结果集合 |
| `return list(res)` | 集合转成列表返回（顺序随意） |

### 完整代码（Python）

```python
from typing import List
import bisect

class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        nums2.sort()
        res = set()
        for v in nums1:
            i = bisect.bisect_left(nums2, v)
            if i < len(nums2) and nums2[i] == v:
                res.add(v)
        return list(res)
```

## 47-3. 猜数字大小（Easy）

> 力扣 374 · 二分查找 · Easy

**一句话**：1 到 n 里藏了一个数，每次猜一个数，只能得到"大了/小了/对了"三个回答，把这个数猜出来。

### 精讲（零基础版）

#### ① 这题要用到的东西

**题目自带的接口 `guess(num)`（交互式题）**

- 一句人话：这类题不给你数组，只给你一个"问一句、答一句"的函数，你要靠一次次问答把答案问出来。
- 生活类比：打电话问客服，你只能问"是不是大于 50"，对方只能回答"大了""小了""对了"，你得靠一串问题锁定答案。
- 最小例子（本地跑的时候自己写一个假的，力扣后台已经有真的了）：

```python
pick = 6                 # 假装答案是 6
def guess(num):
    if num > pick:
        return -1        # 你猜大了
    if num < pick:
        return 1         # 你猜小了
    return 0             # 猜对了

print(guess(5))   # -> 1    （猜小了）
print(guess(8))   # -> -1   （猜大了）
print(guess(6))   # -> 0    （猜对了）
```

- 这题里干什么：我们只管调用 `guess(mid)`，根据返回值把范围砍一半。力扣会把 `guess` 放在后台，不用我们自己写。

**二分查找**（前面 47-1 讲过）：每次砍掉一半。这题把它用在"猜数"上，猜的每个数就是一次二分的中点。

#### ② 大白话：这题到底在干什么

最笨的办法：从 1 开始一个一个猜，最坏要猜 n 次。n 最大 21 亿，肯定超时。

聪明办法：每次都猜范围的正中间。猜大了，说明答案比它小，它和它右边全部作废；猜小了，说明答案比它大，它和它左边全部作废；猜对了就结束。范围每次减半，21 亿也只要三十来次就能猜中。

这题唯一的新东西是：数据不是数组，而是藏在对方的回答里。但"往左还是往右"的判断逻辑和普通二分完全一样。

#### ③ 拿一个具体输入走一遍

以题面示例 1 为例：n = 10，藏着的数是 6。

| 步骤 | left / right | mid（猜的数） | guess 返回 | 说明 |
|---|---|---|---|---|
| 1 | 1 / 10 | 5 | 1 | 猜小了，答案在右边，left = 6 |
| 2 | 6 / 10 | 8 | -1 | 猜大了，答案在左边，right = 7 |
| 3 | 6 / 7 | 6 | 0 | 猜中，返回 6 |

所以答案是 6。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `left, right = 1, n` | 候选范围是 1 到 n |
| `while left <= right:` | 范围没空就继续猜 |
| `mid = (left + right) // 2` | 猜正中间那个数 |
| `g = guess(mid)` | 问力扣：这个数大了、小了、还是对了 |
| `if g == 0: return mid` | 猜中，直接返回 |
| `if g < 0:` | 返回 -1 表示猜大了 |
| `right = mid - 1` | 比 mid 大的全部作废 |
| `else:` | 返回 1 表示猜小了 |
| `left = mid + 1` | 比 mid 小的全部作废 |
| `return -1` | 兜底返回（正常输入走不到这里） |

### 完整代码（Python）

```python
class Solution:
    def guessNumber(self, n: int) -> int:
        left, right = 1, n
        while left <= right:
            mid = (left + right) // 2
            g = guess(mid)          # 力扣后台已定义 guess，本地测试要自己写一个
            if g == 0:
                return mid
            if g < 0:
                right = mid - 1
            else:
                left = mid + 1
        return -1
```

## 47-4. 搜索二维矩阵（Medium）

> 力扣 74 · 二分查找 · Medium

**一句话**：在一个"每行从左到右递增、且下一行第一个比上一行最后一个还大"的矩阵里，判断某个数在不在。

### 精讲（零基础版）

#### ① 这题要用到的东西

**把矩阵按行展开成一维下标**

- 一句人话：把 m 行 n 列的表格当成一条长队，第 k 个格子（从 0 数）就在"第 k // n 行、第 k % n 列"。
- 生活类比：电影院座位编号，一排 n 个座位，第 k 号座位在第几排第几座，用除法和取余就能算。
- 最小例子：

```python
matrix = [[1, 3, 5, 7], [10, 11, 16, 20], [23, 30, 34, 60]]
n = len(matrix[0])          # 每行 4 个
k = 6                       # 想找第 6 个格子（从 0 数）
print(k // n, k % n)        # -> 1 2      （第 1 行第 2 列）
print(matrix[k // n][k % n])  # -> 16
```

- 这题里干什么：题面保证"每行第一个 > 上一行最后一个"，所以整张表按行连起来就是一条严格递增的一维数组，可以直接对"第几个"二分，不用管行和列。

**二分查找**（前面 47-1 讲过）：这次不是在数组上二分，而是在"格子编号"上二分，取到编号后再换算成行列去读值。

#### ② 大白话：这题到底在干什么

最笨的办法：一行一行看，每行从头扫到尾，最坏要把 m×n 个格子全看一遍。

聪明办法：题面给了两条性质——每行从左到右递增，而且下一行第一个比上一行最后一个大。这两条合起来说明：整张表按"先第一行、再第二行……"的顺序读出来，就是一个排好序的一维数组。既然排好序，就能二分。

唯一要处理的是"一维编号怎么变成行列"。编号 k 除以列数得到行号，取余得到列号，两次整数运算搞定。

#### ③ 拿一个具体输入走一遍

以题面示例 2 为例：矩阵是 3 行 4 列共 12 个格子，target = 13。

| 步骤 | left / right | mid | 取到的值（行, 列） | 判断 |
|---|---|---|---|---|
| 1 | 0 / 11 | 5 | 11（第 1 行第 1 列） | 11 < 13，往右，left = 6 |
| 2 | 6 / 11 | 8 | 23（第 2 行第 0 列） | 23 > 13，往左，right = 7 |
| 3 | 6 / 7 | 6 | 16（第 1 行第 2 列） | 16 > 13，往左，right = 5 |
| 4 | 6 / 5 | — | — | left > right，结束 |

所以答案是 false。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `m, n = len(matrix), len(matrix[0])` | 拿到行数和列数 |
| `left, right = 0, m * n - 1` | 把整张表看成一维，范围是第 0 个到第 m×n-1 个 |
| `while left <= right:` | 还有格子没被排除 |
| `mid = (left + right) // 2` | 取中间那个格子的"编号" |
| `val = matrix[mid // n][mid % n]` | 编号换算成行列，把那个格子读出来 |
| `if val == target: return True` | 正好等于目标 |
| `if val < target: left = mid + 1` | 太小，去右半边 |
| `else: right = mid - 1` | 太大，去左半边 |
| `return False` | 找遍了都没有 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        m, n = len(matrix), len(matrix[0])
        left, right = 0, m * n - 1
        while left <= right:
            mid = (left + right) // 2
            val = matrix[mid // n][mid % n]
            if val == target:
                return True
            if val < target:
                left = mid + 1
            else:
                right = mid - 1
        return False
```

## 47-5. 组合（Medium）

> 力扣 77 · 回溯 · Medium

**一句话**：从 1 到 n 里挑出所有长度为 k 的组合（顺序不同算同一个）。

### 精讲（零基础版）

#### ① 这题要用到的东西

**回溯（backtracking）**

- 一句人话：一步一步做选择，走到死路就退回上一步，换一个选择再走。
- 生活类比：走迷宫，走到死胡同就退回上一个岔口，选另一条路。
- 最小例子（从 1、2、3 里挑 2 个数）：

```python
res, path = [], []
def dfs(start):
    if len(path) == 2:          # 挑够了
        res.append(path[:])     # 拍照存一份
        return
    for i in range(start, 4):   # 只从 start 往后挑，避免重复
        path.append(i)          # 选
        dfs(i + 1)              # 往下走
        path.pop()              # 撤销（这一步就叫"回溯"）
dfs(1)
print(res)   # -> [[1, 2], [1, 3], [2, 3]]
```

- 这题里干什么：这题就是上面这段骨架，只多了一行剪枝。

**`path[:]` 复制列表**

- 一句人话：把当前列表"拍张照片"存一份，以后 path 怎么改，照片都不变。
- 生活类比：把桌上摆好的积木拍张照，之后积木拆了重摆，照片还是原来那个样子。
- 最小例子：

```python
path = [1, 2]
res = []
res.append(path)        # 存的是"同一个列表"，不是照片
path.append(3)
print(res)              # -> [[1, 2, 3]]   跟着变了

res2 = []
res2.append(path[:])    # 存的是照片
path.append(4)
print(res2)             # -> [[1, 2, 3]]   没有跟着变
```

- 这题里干什么：`res.append(path[:])` 把当前组合存进答案。要是写成 `res.append(path)`，最后所有答案都会变成同一个（被清空的）列表。

**剪枝**

- 一句人话：提前发现这条路肯定走不通，干脆不进，省下整棵子树的功夫。
- 生活类比：还差 2 个人才能组队，但场上只剩 1 个人没被选，那就别组了。
- 最小例子：

```python
n, k = 4, 2
for i in range(1, n + 1):
    remain = n - i + 1     # 从 i 开始，一共有几个数可选
    need = k               # 还需要选几个
    print(i, "剩余可选", remain, "还需要", need, "->", "够" if remain >= need else "不够，停")
# -> 1 剩余可选 4 还需要 2 -> 够
# -> 2 剩余可选 3 还需要 2 -> 够
# -> 3 剩余可选 2 还需要 2 -> 够
# -> 4 剩余可选 1 还需要 2 -> 不够，停
```

- 这题里干什么：`if n - i + 1 < k - len(path): break` 就是这段判断。注意这里用 `break` 而不是 `continue`——i 越大剩余可选越少，后面只会更不够。

#### ② 大白话：这题到底在干什么

要从 1 到 n 里挑 k 个数，顺序无关（`[1,2]` 和 `[2,1]` 算同一个）。

最笨的办法：把 n 个数所有子集都列出来，再筛出长度为 k 的。n 最大 20，子集有 100 多万个，太浪费。

聪明办法：按"从小到大的顺序"挑。选了一个数之后，下一个只能从比它大的数里挑，这样天然不会出现 `[2,1]` 这种重复。挑够 k 个就记一笔，然后退回来把最后一个数换掉。中途如果发现"剩下的数不够凑满 k 个"，立刻停手，不用再往下试。

#### ③ 拿一个具体输入走一遍

以题面示例 1 为例：n = 4，k = 2。

| 步骤 | 动作 | path | 结果 |
|---|---|---|---|
| 1 | 选 1 | [1] | — |
| 2 | 选 2 | [1, 2] | 够 2 个，记录 [1,2] |
| 3 | 撤销 2，选 3 | [1, 3] | 记录 [1,3] |
| 4 | 撤销 3，选 4 | [1, 4] | 记录 [1,4] |
| 5 | 撤销 1，选 2 | [2] | — |
| 6 | 选 3 | [2, 3] | 记录 [2,3] |
| 7 | 撤销 3，选 4 | [2, 4] | 记录 [2,4] |
| 8 | 撤销 2，选 3 | [3] | — |
| 9 | 选 4 | [3, 4] | 记录 [3,4] |
| 10 | 撤销 3，试 4 | [4] | 剩余可选 1 个 < 还需要 2 个，剪枝，结束 |

所以答案是 6 个组合：`[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `res = []` | 存所有答案 |
| `path = []` | 当前正在拼的组合 |
| `def dfs(start):` | start 表示"从哪个数开始选" |
| `if len(path) == k:` | 已经选够 k 个 |
| `res.append(path[:])` | 拍照存一份（不能直接存 path） |
| `return` | 这一条路走完了，回去换下一个 |
| `for i in range(start, n + 1):` | 从 start 开始往后逐个试 |
| `if n - i + 1 < k - len(path): break` | 剩下的数不够凑满，后面更不够，直接停 |
| `path.append(i)` | 选上 i |
| `dfs(i + 1)` | 往下走一层，下一个数只能比 i 大 |
| `path.pop()` | 撤销：把 i 拿掉，去试下一个 |
| `dfs(1)` | 从 1 开始选 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def combine(self, n: int, k: int) -> List[List[int]]:
        res = []
        path = []

        def dfs(start: int) -> None:
            if len(path) == k:
                res.append(path[:])
                return
            for i in range(start, n + 1):
                if n - i + 1 < k - len(path):
                    break
                path.append(i)
                dfs(i + 1)
                path.pop()

        dfs(1)
        return res
```

## 47-6. 复原 IP 地址（Medium）

> 力扣 93 · 回溯 · Medium

**一句话**：往一个纯数字串里插 3 个点，切成 4 段合法的 0~255 数字，列出所有切法。

### 精讲（零基础版）

#### ① 这题要用到的东西

**字符串切片 `s[a:b]`**

- 一句人话：从下标 a 取到 b 之前（含 a、不含 b）的一小段，a 和 b 都可以省。
- 生活类比：从一句话里剪下"第 3 个字到第 6 个字"那一段。
- 最小例子：

```python
s = "25525511135"
print(s[0:3])    # -> 255
print(s[3:6])    # -> 255
print(s[0:1])    # -> 2
print(len(s))    # -> 11
```

- 这题里干什么：每一段就是 `s[start:end]`，`end - start` 取 1 到 3 就是"这一段切 1~3 位数字"。

**前导零规则**

- 一句人话：长度大于 1 的段不能以字符 `'0'` 开头。`"0"` 合法，`"01"` 不合法。
- 生活类比：门牌号不会写成 007，多写的前导零不算数。
- 最小例子：

```python
for seg in ["0", "01", "255", "256"]:
    ok = (len(seg) == 1 or seg[0] != "0") and int(seg) <= 255
    print(seg, "->", ok)
# -> 0 -> True
# -> 01 -> False
# -> 255 -> True
# -> 256 -> False
```

- 这题里干什么：切出一段之后先过这两道关——没有多余前导零、数值不超过 255。

**回溯**（前面 47-5 讲过）：一段一段往下切，切不动就退回来换更长的段。这题里的"选择"是"这一刀切在哪儿"。

#### ② 大白话：这题到底在干什么

要在数字串里插 3 个点，把串切成 4 段。每段的要求是：长度 1~3、数值在 0 到 255 之间、不能有多余的前导零（`"0"` 可以，`"01"` 不行）。

最笨的办法：枚举 3 个点的位置，10 个字符里选 3 个位置，120 种，每种再验一遍。可行，但代码啰嗦。

聪明办法：从前往后一段一段切。第一段切 1 位、2 位、3 位都试一下，合法就往下切第二段。切到某一段不合法时立刻停——因为再往长切只会更不合法（前导零还在，数值只会更大）。凑满 4 段之后还要检查一件事：是不是正好用完了所有字符。用完了才算一个答案。

#### ③ 拿一个具体输入走一遍

以题面示例 1 为例：s = `"25525511135"`，长度 11。

| 步骤 | 已切出的段 | 下一个起点 | 试切的段 | 判断 |
|---|---|---|---|---|
| 1 | [] | 0 | "2" | 合法，进下一层 |
| 2 | ["2"] | 1 | "5" | 合法，进下一层 |
| 3 | ["2","5"] | 2 | "5" | 合法，进下一层 |
| 4 | ["2","5","5"] | 3 | "2"、"25"、"255" | 已是第 4 段，但起点 3 ≠ 11，全失败，回退 |
| 5 | ["2"] | 1 | "55" | 合法，但后面同样凑不满，回退 |
| 6 | ["255"] | 3 | "255" | 合法，进下一层 |
| 7 | ["255","255"] | 6 | "11" | 合法，进下一层 |
| 8 | ["255","255","11"] | 8 | "135" | 第 4 段，正好用完 11 个字符 → 255.255.11.135 |
| 9 | ["255","255"] | 6 | "111" | 合法，进下一层 |
| 10 | ["255","255","111"] | 9 | "35" | 第 4 段，正好用完 → 255.255.111.35 |

所以答案是 `["255.255.11.135", "255.255.111.35"]`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `res, parts = [], []` | 答案列表、当前已经切好的段 |
| `def dfs(start):` | start 是这一层从哪个字符开始切 |
| `if len(parts) == 4:` | 已经切满 4 段 |
| `if start == len(s):` | 而且正好把所有字符用完 |
| `res.append(".".join(parts))` | 用点拼起来，收进答案 |
| `for end in range(start + 1, min(start + 3, len(s)) + 1):` | 每段切 1~3 个字符，别越界 |
| `seg = s[start:end]` | 切出这一段 |
| `if len(seg) > 1 and seg[0] == "0": break` | 有前导零，不合法；再切更长也不合法 |
| `if int(seg) > 255: break` | 超过 255；再切更长只会更大 |
| `parts.append(seg)` | 这一段合法，先收下 |
| `dfs(end)` | 从 end 开始切下一段 |
| `parts.pop()` | 撤销，换一种切法 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def restoreIpAddresses(self, s: str) -> List[str]:
        res = []
        parts = []

        def dfs(start: int) -> None:
            if len(parts) == 4:
                if start == len(s):
                    res.append(".".join(parts))
                return
            for end in range(start + 1, min(start + 3, len(s)) + 1):
                seg = s[start:end]
                if len(seg) > 1 and seg[0] == "0":
                    break
                if int(seg) > 255:
                    break
                parts.append(seg)
                dfs(end)
                parts.pop()

        dfs(0)
        return res
```

## 47-7. 两数之和 II - 输入有序数组（Medium）

> 力扣 167 · 二分查找 · Medium

**一句话**：在一个已排好序的数组里找两个数，使它们的和等于 target，返回它们从 1 开始的下标。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`bisect_left` 的第三个参数 `lo`**

- 一句人话：只在 `lo` 这个位置之后找，前面的部分完全不看。
- 生活类比：在一本书里找某个词，你直接从第 100 页开始翻，前 99 页跳过。
- 最小例子：

```python
import bisect
a = [2, 7, 11, 15]
print(bisect.bisect_left(a, 7))       # -> 1
print(bisect.bisect_left(a, 7, 2))    # -> 2   （从下标 2 开始找，后面的 11、15 里没有 7）
print(bisect.bisect_left(a, 100, 1))  # -> 4
```

- 这题里干什么：`lo = i + 1`，保证第二个数一定在下标 i 的后面，不会出现"自己和自己配对"。题目还要求同一个元素不能用两次，这样正好卡住。

**`enumerate`**

- 一句人话：一边遍历元素，一边把它的下标也给你。
- 生活类比：点名的时候报"第几个、叫什么"。
- 最小例子：

```python
for i, v in enumerate(["a", "b", "c"]):
    print(i, v)
# -> 0 a
# -> 1 b
# -> 2 c
```

- 这题里干什么：答案要的是下标（而且是从 1 开始），所以要同时拿到值和下标。

**二分查找**（前面 47-1 讲过）：固定第一个数之后，第二个数必须是 `target - v`，在有序数组里找它就用二分。

#### ② 大白话：这题到底在干什么

数组已经从小到大排好了，要两个数加起来等于 target。

最笨的办法：两层循环，把每两个数都配一遍，O(n²)。n 最大 3 万，要试 9 亿次。

聪明办法：先固定第一个数 v，那么第二个数只能是 `target - v`。既然数组有序，"`target - v` 在不在、在第几个"用二分一查就知道。外层 n 次，每次 log n，总共 O(n log n)，而且额外空间只用常数个变量——正好满足题目"常数级额外空间"的要求。

（这题还有个更快的双指针做法，后面 47-15 会讲，这里先用二分。）

#### ③ 拿一个具体输入走一遍

用自造例子 `numbers = [1,2,3,4,6]`，target = 10，比题面示例多走几步，能看清"找不到"是怎么过去的：

| 步骤 | i / v | 需要的另一个数 target-v | bisect_left 位置 / 该位置的值 | 结果 |
|---|---|---|---|---|
| 1 | 0 / 1 | 9 | 5（越界） | 数组里没有 9，继续 |
| 2 | 1 / 2 | 8 | 5（越界） | 没有 8，继续 |
| 3 | 2 / 3 | 7 | 5（越界） | 没有 7，继续 |
| 4 | 3 / 4 | 6 | 4 / 6 | 命中，返回 [4, 5] |

所以答案是 `[4, 5]`。（题面示例 1 是 `numbers=[2,7,11,15]`、target=9，第一轮 i=0 时 v=2、需要 7、二分命中，直接返回 `[1,2]`。）

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `for i, v in enumerate(numbers):` | 遍历数组，同时拿到下标 i 和数值 v |
| `target - v` | 算出"另一个数应该是几" |
| `bisect_left(numbers, target - v, i + 1)` | 只在 i 的右边找它该待的位置 |
| `j = ...` | j 就是那个数该待的位置 |
| `if j < len(numbers)` | 位置没越界，说明后面还有数 |
| `and numbers[j] == target - v` | 那个位置上真的是它（不是它说明不存在） |
| `return [i + 1, j + 1]` | 题目下标从 1 开始，两个都加 1 |
| `return []` | 兜底（题面保证有答案） |

### 完整代码（Python）

```python
from typing import List
import bisect

class Solution:
    def twoSum(self, numbers: List[int], target: int) -> List[int]:
        for i, v in enumerate(numbers):
            j = bisect.bisect_left(numbers, target - v, i + 1)
            if j < len(numbers) and numbers[j] == target - v:
                return [i + 1, j + 1]
        return []
```

## 47-8. 搜索二维矩阵 II（Medium）

> 力扣 240 · 二分查找 · Medium

**一句话**：矩阵每行从左到右递增、每列从上到下递增（但行与行之间不保证整行更大），判断 target 在不在。

### 精讲（零基础版）

#### ① 这题要用到的东西

**从右上角出发的"阶梯搜索"**

- 一句人话：站在右上角，比目标大就往左挪一格，比目标小就往下挪一格，每挪一步就排除一整行或一整列。
- 生活类比：查一张"行递增、列也递增"的成绩表，从右上角开始一格格挪，不用把整张表看完。
- 最小例子：

```python
matrix = [[1, 4, 7], [2, 5, 8], [3, 6, 9]]
r, c = 0, 2                 # 右上角
while r < 3 and c >= 0:
    print("看", matrix[r][c])
    if matrix[r][c] > 6:
        c -= 1              # 大了，往左
    elif matrix[r][c] < 6:
        r += 1              # 小了，往下
    else:
        print("找到")
        break
# -> 看 7
# -> 看 4
# -> 看 5
# -> 看 6
# -> 找到
```

- 这题里干什么：这就是本题的解法。右上角这个位置很特殊：它左边的数都比它小，它下面的数都比它大。所以拿它和目标比一次，就能砍掉一整行或一整列。

**为什么 47-4 的做法在这里不能用**（前面 47-4 讲过展平二分）：那题保证"下一行第一个比上一行最后一个大"，整张表连起来是严格递增的一维数组；这题只保证行内递增、列内递增，行与行之间可能交叉（比如第一行最后是 15，第二行第一个是 2），连起来不是有序的，没法直接二分。

#### ② 大白话：这题到底在干什么

最笨的办法：把 m×n 个格子全看一遍，O(m×n)。m 和 n 都到 300，也就 9 万次，其实能过。

聪明办法：从右上角走楼梯。当前格子比目标大，说明这一整列（从当前行往下）都比目标大，整列作废，往左走一格；当前格子比目标小，说明这一整行（从当前列往左）都比目标小，整行作废，往下走一格。每走一步至少排除一整行或一整列，所以最多走 m+n 步。

换个说法：每行每列都有序，说明"右上方"那块都比当前格大，"左下方"那块都比当前格小。一次比较就能确定答案不在哪一大块里，这正是能快速缩小的原因。

#### ③ 拿一个具体输入走一遍

以题面示例 1 为例，target = 5：

| 步骤 | 位置 (r, c) | 格子里的值 | 与 5 比 | 动作 |
|---|---|---|---|---|
| 1 | (0, 4) | 15 | 大 | 这一列下面更大，往左，c = 3 |
| 2 | (0, 3) | 11 | 大 | 往左，c = 2 |
| 3 | (0, 2) | 7 | 大 | 往左，c = 1 |
| 4 | (0, 1) | 4 | 小 | 这一行左边更小，往下，r = 1 |
| 5 | (1, 1) | 5 | 相等 | 返回 true |

所以答案是 true。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `m, n = len(matrix), len(matrix[0])` | 行数、列数 |
| `r, c = 0, n - 1` | 站在右上角：第 0 行、最后一列 |
| `while r < m and c >= 0:` | 只要人还在表里就继续走 |
| `v = matrix[r][c]` | 看当前格子 |
| `if v == target: return True` | 命中 |
| `if v > target: c -= 1` | 比目标大：这一列下面只会更大，往左挪 |
| `else: r += 1` | 比目标小：这一行左边只会更小，往下挪 |
| `return False` | 走出边界还没找到，说明没有 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        m, n = len(matrix), len(matrix[0])
        r, c = 0, n - 1
        while r < m and c >= 0:
            v = matrix[r][c]
            if v == target:
                return True
            if v > target:
                c -= 1
            else:
                r += 1
        return False
```

## 47-9. 寻找重复数（Medium）

> 力扣 287 · 二分查找 · Medium

**一句话**：n+1 个整数，数字都在 1 到 n 之间，只有一个数重复出现，找出它；不许改数组，只能花常数空间。

### 精讲（零基础版）

#### ① 这题要用到的东西

**二分答案**

- 一句人话：不在数组上二分，而是在"答案的可能范围"上二分；每次猜一个答案，用一个判定函数看它"偏大还是偏小"。
- 生活类比：猜箱子里有几个球，不打开箱子，而是称一下重量，判断"比 5 个重还是轻"。
- 最小例子（猜 1~100 里最小的、平方 ≥ 50 的数）：

```python
left, right = 1, 100
while left < right:
    mid = (left + right) // 2
    if mid * mid >= 50:      # 判定：mid 够不够大
        right = mid
    else:
        left = mid + 1
print(left)                  # -> 8   （7×7=49 < 50，8×8=64 ≥ 50）
```

- 这题里干什么：答案一定是 1 到 n 之间的某个数，我们在"1 到 n"这个答案范围上二分，判定函数是"数一数数组里 ≤ mid 的有几个"。

**计数判定（抽屉原理）**

- 一句人话：如果只有 1 到 mid 这 mid 个不同的数，那它们最多出现 mid 次；一旦出现次数超过 mid，说明 1 到 mid 里一定有数重复了。
- 生活类比：5 个抽屉放 6 个苹果，必有一个抽屉放了 2 个。
- 最小例子：

```python
nums = [1, 3, 4, 2, 2]
mid = 2
cnt = 0
for v in nums:
    if v <= mid:
        cnt += 1
print(cnt)         # -> 3
print(cnt > mid)   # -> True   （1 和 2 只有 2 个位置，却挤进来 3 个数）
```

- 这题里干什么：这是二分里那个"判定函数"。`cnt > mid` 说明重复的数不超过 mid，往左收；否则往右收。

#### ② 大白话：这题到底在干什么

数组长度是 n+1，数字都在 1 到 n 之间，所以必有一个数重复。题目有三个限制：不能改数组、只能用常数空间、要 O(n) 或更好。这三条一叠加，排序（要改数组）、哈希表（要额外空间）都不能用了。

换个角度：不找"哪个数是重复的"，改问"重复的数比 mid 大还是小"。数一数数组里 ≤ mid 的数有几个：如果只有 1 到 mid 这 mid 个不同的数，最多出现 mid 次；现在数出来比 mid 多，说明 1 到 mid 里挤进了重复的数，答案 ≤ mid。反过来答案 > mid。

这个"多不多"的判断随着 mid 变大是从"多"变成"不多"的，单调翻转，所以能二分。

#### ③ 拿一个具体输入走一遍

以题面示例 1 为例：`nums = [1,3,4,2,2]`，n = 4（长度 5 减 1）。

| 步骤 | left / right | mid | 数一数 ≤ mid 的个数 | 判断 |
|---|---|---|---|---|
| 1 | 1 / 4 | 2 | 3（是 1、2、2） | 3 > 2，答案 ≤ 2，right = 2 |
| 2 | 1 / 2 | 1 | 1（只有 1） | 1 ≤ 1，答案 > 1，left = 2 |
| 3 | 2 / 2 | — | — | left == right，结束 |

所以答案是 2。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `n = len(nums) - 1` | 数组长 n+1，所以数字范围是 1 到 n |
| `left, right = 1, n` | 在"答案范围"上二分，不是在数组上 |
| `while left < right:` | 答案范围缩到一个数就停 |
| `mid = (left + right) // 2` | 猜答案是不是 ≤ mid |
| `cnt = 0` | 准备数数 |
| `for v in nums: if v <= mid: cnt += 1` | 数一数 ≤ mid 的有几个 |
| `if cnt > mid:` | 超过 mid 个，说明 1 到 mid 里挤了重复数 |
| `right = mid` | 答案不会超过 mid |
| `else:` | 没超过，说明重复数比 mid 大 |
| `left = mid + 1` | 答案在 mid 右边 |
| `return left` | left 和 right 碰头的地方就是答案 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        n = len(nums) - 1
        left, right = 1, n
        while left < right:
            mid = (left + right) // 2
            cnt = 0
            for v in nums:
                if v <= mid:
                    cnt += 1
            if cnt > mid:
                right = mid
            else:
                left = mid + 1
        return left
```

## 47-10. 累加数（Medium）

> 力扣 306 · 回溯 · Medium

**一句话**：判断一个数字串能不能切成"累加序列"——至少 3 个数，从第 3 个起每个数都等于前两个之和。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`str.startswith`**

- 一句人话：判断一个字符串是不是以某段开头。
- 生活类比：看一列火车的第一节车厢是不是你要找的那节。
- 最小例子：

```python
rest = "358"
print(rest.startswith("3"))    # -> True
print(rest.startswith("35"))   # -> True
print(rest.startswith("4"))    # -> False
```

- 这题里干什么：算出 a+b 之后，看剩下的串是不是以 a+b 的十进制写法开头。是，就把这一段切掉继续；不是，这种切法就作废。

**Python 的整数不会溢出**

- 一句人话：Python 的 int 想多大就多大，不会像 64 位整数那样超过上限就绕回去。
- 生活类比：别人用 8 位的计算器，你用一条无限长的纸带，写多少位都行。
- 最小例子：

```python
a = 10 ** 30
print(a + 1)                # -> 1000000000000000000000000000001
print(len(str(2 ** 100)))   # -> 31
```

- 这题里干什么：串长最多 35，前两个数可能非常大，a+b 也可能非常大。用 Python 直接 `int()` 算就行，不用手写大整数加法，也不用担心溢出。

**回溯**（前面 47-5 讲过）：枚举"第一个数多长、第二个数多长"，然后顺着往下验证；验证失败就换下一种切法。

#### ② 大白话：这题到底在干什么

累加序列的规则是：前两个数随便定，从第三个开始，每个都必须是前两个之和。

关键观察：**前两个数一旦定下来，后面所有数就全定死了**。所以不需要枚举所有切法，只需要枚举"第一个数切几位、第二个数切几位"。

枚举出来之后，把剩下的串一段段处理：算出 a+b，看剩下的串是不是以它开头。是，就把它切掉，把 (a, b) 换成 (b, a+b)，继续；不是，这种切法直接失败，换下一个。

还有两个小规则：长度大于 1 的数不能以 `'0'` 开头（`"03"` 不合法），以及序列至少要有 3 个数。

#### ③ 拿一个具体输入走一遍

以题面示例 1 为例：`"112358"`。

| 步骤 | a / b | 期待的 a+b | 剩下的串 | 结果 |
|---|---|---|---|---|
| 1 | 1 / 1 | 2 | "2358" | 以 "2" 开头，切掉，剩 "358" |
| 2 | 1 / 2 | 3 | "358" | 以 "3" 开头，切掉，剩 "58" |
| 3 | 2 / 3 | 5 | "58" | 以 "5" 开头，切掉，剩 "8" |
| 4 | 3 / 5 | 8 | "8" | 以 "8" 开头，切掉，剩空串 |

剩下空串，说明整串都切完了，答案是 true。

作为对照：切法 "11" + "2"（i=2, j=3）算出 11+2=13，剩下的 "358" 不以 "13" 开头，立刻失败；切法 "11" + "23" 算出 34，剩下 "58" 也不以 "34" 开头，同样失败。所以真正成功的只有 1、1、2、3、5、8 这一种。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `n = len(num)` | 串的长度 |
| `for i in range(1, n):` | 第一个数切前 i 位 |
| `for j in range(i + 1, n):` | 第二个数从 i 切到 j |
| `first, second = num[:i], num[i:j]` | 切出前两个数 |
| `if len(first) > 1 and first[0] == "0": break` | 有前导零，不合法；再切更长也不合法 |
| `if len(second) > 1 and second[0] == "0": break` | 同上 |
| `a, b = int(first), int(second)` | 转成整数准备做加法 |
| `rest = num[j:]` | 剩下还没处理的串 |
| `while rest:` | 只要还剩东西就继续验 |
| `cs = str(a + b)` | 下一个数"应该"长这样 |
| `if not rest.startswith(cs): break` | 开头对不上，这种切法作废 |
| `rest = rest[len(cs):]` | 对上了，切掉这一段 |
| `a, b = b, a + b` | 往前推两个数 |
| `if not rest: return True` | 全切完，说明是累加数 |

### 完整代码（Python）

```python
class Solution:
    def isAdditiveNumber(self, num: str) -> bool:
        n = len(num)
        for i in range(1, n):
            for j in range(i + 1, n):
                first, second = num[:i], num[i:j]
                if len(first) > 1 and first[0] == "0":
                    break
                if len(second) > 1 and second[0] == "0":
                    break
                a, b = int(first), int(second)
                rest = num[j:]
                while rest:
                    cs = str(a + b)
                    if not rest.startswith(cs):
                        break
                    rest = rest[len(cs):]
                    a, b = b, a + b
                if not rest:
                    return True
        return False
```

## 47-11. 第 N 位数字（Medium）

> 力扣 400 · 二分查找 · Medium

**一句话**：把 1、2、3、4……一个接一个写成一串长数字 `123456789101112...`，求这串里的第 n 位是几。

### 精讲（零基础版）

#### ① 这题要用到的东西

**按位数分组**

- 一句人话：1 位数有 9 个、2 位数有 90 个、3 位数有 900 个……先看第 n 位落在"几位数"那一组，再进组里找。
- 生活类比：图书馆按书架分区，先看你要的书在哪个区，再走进那个区数第几本。
- 最小例子：

```python
n = 11
digits, count, start = 1, 9, 1
while n > count * digits:
    print("跳过", count, "个", digits, "位数，共", count * digits, "位")
    n -= count * digits
    digits += 1
    count *= 10
    start *= 10
print("落在", digits, "位数区，区内第", n, "位，该区从", start, "开始")
# -> 跳过 9 个 1 位数，共 9 位
# -> 落在 2 位数区，区内第 2 位，该区从 10 开始
```

- 这题里干什么：整个解法就是这个循环。`count` 是这一组有几个数，`digits` 是每个数几位，`start` 是这一组从哪个数开始。

**`str(整数)[k]` 取某一位**

- 一句人话：把数字转成字符串，就能像取字符一样按下标取它的某一位。
- 生活类比：把一串钥匙上的编号抄成一张卡片，再看卡片上的第几个字符。
- 最小例子：

```python
s = str(10)
print(s)          # -> 10
print(s[0])       # -> 1
print(s[1])       # -> 0
print(int(s[1]))  # -> 0   （字符 '0' 转回数字 0）
```

- 这题里干什么：定位到具体是哪个数字之后，取它的第 `pos` 位字符，再转回整数返回。

#### ② 大白话：这题到底在干什么

把所有正整数连成一串：`123456789101112...`。要找第 n 位。

最笨的办法：一个个数字拼起来，拼到第 n 个字符为止。n 最大 21 亿，拼不完。

聪明办法：分组算。1 位数有 9 个，占 9 个字符；2 位数有 90 个，占 180 个字符；3 位数有 900 个，占 2700 个字符……每组的"总字符数"是 `9 × 10^(k-1) × k`。先从 n 里减掉整组的字符数，减到 n 落进某一组为止。

落进某一组之后，组内每个数都是 `digits` 位，所以 `(n-1) // digits` 就是"是组内第几个数"，`(n-1) % digits` 就是"是这个数的第几位"。

这题虽然归在二分查找里，但标准解法是上面这种按位数分组的数学做法，比二分更好写也更快。

#### ③ 拿一个具体输入走一遍

以题面示例 2 为例：n = 11。

| 阶段 | 变量状态（digits / count / start） | 剩余 n | 说明 |
|---|---|---|---|
| 1 | 1 / 9 / 1 | 11 | 11 > 9×1 = 9，减掉 9，剩 2 |
| 2 | 2 / 90 / 10 | 2 | 2 ≤ 90×2 = 180，停在这一组 |
| 3 | 2 / 90 / 10 | 2 | idx = (2-1)//2 = 0，pos = (2-1)%2 = 1 |
| 4 | — | — | 组内第 0 个数是 10，取它的第 1 位是 `'0'` |

所以答案是 0。（对照：第 11 位确实落在数字 10 的第二个字符上。）

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `digits, count, start = 1, 9, 1` | 从 1 位数这组开始：每个数 1 位、有 9 个数、从 1 开始 |
| `while n > count * digits:` | n 还在这一组后面，就得整组跳过 |
| `n -= count * digits` | 把这一组占的字符数从 n 里减掉 |
| `digits += 1` | 进入下一组，每个数多一位 |
| `count *= 10` | 下一组的数字个数是这一组的 10 倍 |
| `start *= 10` | 下一组的起始数字也乘 10 |
| `idx = (n - 1) // digits` | 组内第几个数（从 0 数） |
| `pos = (n - 1) % digits` | 是这个数的第几位（从 0 数） |
| `str(start + idx)[pos]` | 取出那个数，再取它的第 pos 位 |
| `int(...)` | 字符转回整数返回 |

### 完整代码（Python）

```python
class Solution:
    def findNthDigit(self, n: int) -> int:
        digits, count, start = 1, 9, 1
        while n > count * digits:
            n -= count * digits
            digits += 1
            count *= 10
            start *= 10
        idx = (n - 1) // digits
        pos = (n - 1) % digits
        return int(str(start + idx)[pos])
```

## 47-12. 寻找右区间（Medium）

> 力扣 436 · 二分查找 · Medium

**一句话**：给每个区间找一个"起点 ≥ 它的终点、且起点最小"的区间，返回那个区间的下标，找不到就是 -1。

### 精讲（零基础版）

#### ① 这题要用到的东西

**排序时保住原下标**

- 一句人话：把"值"和"它原来排第几"捆成一对再排序，排完还能找回原来的位置。
- 生活类比：给每个学生贴上"原座位号"的标签再按身高排队，队排好了也知道谁原来坐哪儿。
- 最小例子：

```python
intervals = [[3, 4], [2, 3], [1, 2]]
pairs = sorted((s, i) for i, (s, e) in enumerate(intervals))
print(pairs)         # -> [(1, 2), (2, 1), (3, 0)]
print(pairs[0][1])   # -> 2   （起点是 1 的那个区间，原来在下标 2）
```

- 这题里干什么：答案要的是"原下标"，但排序会打乱下标，所以排序时要把 (起点, 原下标) 一起带着走。

**`sorted` 排元组时的比较规则**

- 一句人话：元组比较是"先比第一个，第一个相同再比第二个"，所以 `sorted((起点, 下标) ...)` 会自动按起点从小到大排。
- 生活类比：排队时先按身高排，身高一样再按学号排。
- 最小例子：

```python
pairs = [(3, "c"), (1, "a"), (1, "b")]
print(sorted(pairs))
# -> [(1, 'a'), (1, 'b'), (3, 'c')]
```

- 这题里干什么：起点各不相同（题目保证），所以排序结果唯一，不用担心并列。

**`bisect_left`**（前面 47-2 讲过）：在排好序的起点列表里找"第一个 ≥ 终点"的位置。

#### ② 大白话：这题到底在干什么

每个区间 `[start, end]` 要找一个"起点 ≥ end、而且起点最小"的区间。因为所有起点各不相同，把起点排好序之后，问题就变成一句话：**在起点数组里找第一个 ≥ end 的位置**。

找到就返回那个区间的原下标，找不到（说明 end 比所有起点都大）就返回 -1。

唯一的麻烦是：排完序之后下标全乱了，而答案要的恰恰是原下标。所以排序的时候不能只排起点，要把"起点 + 它原来在第几个"捆在一起排。

#### ③ 拿一个具体输入走一遍

以题面示例 2 为例：`intervals = [[3,4],[2,3],[1,2]]`。

先把起点和原下标配对排序，得到 `[(1, 2), (2, 1), (3, 0)]`，起点列表是 `[1, 2, 3]`。

| 步骤 | 当前区间 | 要找的起点（≥ 终点） | bisect_left 位置 | 答案 |
|---|---|---|---|---|
| 1 | [3, 4] | ≥ 4 | 3（越界，起点最大才 3） | -1 |
| 2 | [2, 3] | ≥ 3 | 2 → 对应 (3, 0) | 0 |
| 3 | [1, 2] | ≥ 2 | 1 → 对应 (2, 1) | 1 |

所以答案是 `[-1, 0, 1]`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `starts = sorted((s, i) for i, (s, e) in enumerate(intervals))` | 把每个区间拆成 (起点, 原下标)，按起点排好 |
| `vals = [s for s, _ in starts]` | 单独抽出一列起点，给二分用 |
| `res = []` | 存答案 |
| `for s, e in intervals:` | 按原顺序处理每个区间 |
| `k = bisect.bisect_left(vals, e)` | 找第一个 ≥ 这个区间终点的起点 |
| `if k < len(starts)` | 位置没越界，说明找到了 |
| `starts[k][1]` | 取那一对里的原下标 |
| `else: -1` | 越界说明没有满足条件的区间 |

### 完整代码（Python）

```python
from typing import List
import bisect

class Solution:
    def findRightInterval(self, intervals: List[List[int]]) -> List[int]:
        starts = sorted((s, i) for i, (s, e) in enumerate(intervals))
        vals = [s for s, _ in starts]
        res = []
        for s, e in intervals:
            k = bisect.bisect_left(vals, e)
            res.append(starts[k][1] if k < len(starts) else -1)
        return res
```

## 47-13. 供暖器（Medium）

> 力扣 475 · 二分查找 · Medium

**一句话**：房子和供暖器都在一条直线上，给所有供暖器设一个统一的加热半径，求能盖住所有房子的最小半径。

### 精讲（零基础版）

#### ① 这题要用到的东西

**最近邻：比较左右两个邻居**

- 一句人话：在有序列表里找离目标最近的值，先二分找到"该插进去的位置"，最近的那个只可能是这个位置的左邻居或右邻居。
- 生活类比：在一条街上找最近的便利店，先定位自己在哪两个门牌之间，再比较左边和右边哪家近。
- 最小例子：

```python
import bisect
heaters = [1, 4, 9]
h = 6
k = bisect.bisect_left(heaters, h)   # 6 该插在下标 2
print(k)                             # -> 2
print("右邻居", heaters[k], "距离", heaters[k] - h)      # -> 右邻居 9 距离 3
print("左邻居", heaters[k - 1], "距离", h - heaters[k - 1])  # -> 左邻居 4 距离 2
```

- 这题里干什么：每栋房子只可能被"左边最近的供暖器"或"右边最近的供暖器"覆盖，取距离小的那个就是这栋房子需要的半径。

**`float('inf')`**

- 一句人话：一个比所有数都大的"无穷大"，用来当初始的最小值。
- 生活类比：把"最差成绩"先设成负无穷，之后任何一个真实成绩都能刷新它。
- 最小例子：

```python
best = float('inf')
for d in [3, 1, 2]:
    best = min(best, d)
print(best)                    # -> 1
print(float('inf') > 10 ** 100)  # -> True
```

- 这题里干什么：当某一侧根本没有供暖器时（比如房子在所有供暖器左边），那一侧要忽略。用 inf 初始化，`min` 会自动跳过它。

#### ② 大白话：这题到底在干什么

半径要盖住所有房子，所以半径至少得是"每栋房子到它最近供暖器的距离"。把这些距离都算出来，取最大的那个，就是答案。

最笨的办法：每栋房子把所有供暖器扫一遍，找最近的。房子和供暖器都到 3 万，那就是 9 亿次。

聪明办法：把供暖器排好序。每栋房子二分找到"自己该插在哪个位置"，那么最近的供暖器只可能是这个位置右边那个或左边那个，比较一下取小的就行。每栋房子 log 次比较。

#### ③ 拿一个具体输入走一遍

以题面示例 3 为例：`houses = [1, 5]`，`heaters = [2]`（已排序）。

| 步骤 | 房子位置 | bisect_left 位置 | 左右邻居距离 | 这栋房子需要的半径 |
|---|---|---|---|---|
| 1 | 1 | 0 | 右邻 2，距离 2 - 1 = 1；没有左邻 | 1 |
| 2 | 5 | 1（越界） | 左邻 2，距离 5 - 2 = 3；没有右邻 | 3 |

所以答案是 max(1, 3) = 3。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `heaters.sort()` | 供暖器排好序，才能二分 |
| `ans = 0` | 记录目前所有房子里"需要半径最大"的那个 |
| `for h in houses:` | 一栋一栋房子算 |
| `k = bisect.bisect_left(heaters, h)` | 这栋房子该插在供暖器列表的哪个位置 |
| `best = float('inf')` | 这栋房子需要的半径，先设成无穷大 |
| `if k < len(heaters): best = min(best, heaters[k] - h)` | 右边有供暖器，算一下距离 |
| `if k > 0: best = min(best, h - heaters[k - 1])` | 左边有供暖器，也算一下 |
| `ans = max(ans, best)` | 所有房子都要盖住，所以取最大值 |
| `return ans` | 这个最大距离就是最小半径 |

### 完整代码（Python）

```python
from typing import List
import bisect

class Solution:
    def findRadius(self, houses: List[int], heaters: List[int]) -> int:
        heaters.sort()
        ans = 0
        for h in houses:
            k = bisect.bisect_left(heaters, h)
            best = float("inf")
            if k < len(heaters):
                best = min(best, heaters[k] - h)
            if k > 0:
                best = min(best, h - heaters[k - 1])
            ans = max(ans, best)
        return ans
```

## 47-14. 非重叠矩形中的随机点（Medium）

> 力扣 497 · 二分查找 · Medium

**一句话**：给一堆互不重叠的矩形，设计一个 `pick()`，每次等概率返回矩形覆盖的某个整数点。

### 精讲（零基础版）

#### ① 这题要用到的东西

**前缀和**

- 一句人话：把"前 k 个加起来是多少"提前算好存成一排，以后要哪一段的和，用两个前缀相减就行。
- 生活类比：存钱罐上每天刻一个"截至今天共存了多少钱"，想知道这周存了多少，用今天的数减上周的数。
- 最小例子：

```python
counts = [16, 15]
prefix = []
total = 0
for c in counts:
    total += c
    prefix.append(total)
print(prefix)                                        # -> [16, 31]
print("第 2 个矩形的区间是", prefix[0] + 1, "到", prefix[1])   # -> 第 2 个矩形的区间是 17 到 31
```

- 这题里干什么：每个矩形有多少个整数点先算出来，累加成前缀和，就把"所有点"排成了一条 1 到 31 的长队，第 t 个点落在哪个矩形一目了然。

**类设计 `__init__`**

- 一句人话：创建对象时自动跑一次的函数，用来提前把数据准备好。
- 生活类比：新员工入职第一天先领工牌、配电脑，之后每天上班直接用。
- 最小例子：

```python
class Adder:
    def __init__(self, start):
        self.value = start          # 创建对象时就把初始值存好
    def add(self, x):
        self.value += x
        return self.value

a = Adder(10)
print(a.add(5))    # -> 15
```

- 这题里干什么：题目要求实现 `Solution` 类，`__init__` 里先把前缀和算好存进 `self`，之后每次 `pick()` 直接用，不用重算。

**`random.randint(a, b)`**

- 一句人话：随机返回 a 到 b 之间（含两端）的一个整数。
- 生活类比：掷一个面数不定的骰子，每个面都可能出现。
- 最小例子：

```python
import random
random.seed(7)                  # 固定随机种子，结果可复现
print(random.randint(1, 31))    # -> 11
print(random.randint(1, 31))    # -> 31
```

- 这题里干什么：每次 `pick()` 先从 1 到总点数里随机抽一个 t，再反推它是哪个点。

#### ② 大白话：这题到底在干什么

每个矩形大小不一样，覆盖的整数点个数也不一样。直接随机挑一个矩形是不公平的——点多的矩形应该更容易被选中。

做法：把每个矩形的点数算出来（宽 × 高，宽 = x - a + 1），累加得到前缀和。这样"1 到总点数"里每个整数都唯一对应一个点：第 1 到 16 号点属于第一个矩形，第 17 到 31 号属于第二个。

每次调用 `pick()`：随机抽一个 1 到总点数之间的整数 t，用二分找它落在哪个矩形的区间里，再在这个矩形内部把"第几个点"换算成坐标（用除法和取余把一维序号拆成行和列）。

#### ③ 拿一个具体输入走一遍

以题面示例为例：`rects = [[-2,-2,1,1],[2,2,4,6]]`。

| 步骤 | 矩形 | 宽 × 高 | 点数 | 前缀和 |
|---|---|---|---|---|
| 1 | [-2,-2] 到 [1,1] | 4 × 4 | 16 | 16 |
| 2 | [2,2] 到 [4,6] | 3 × 5 | 15 | 31 |
| 3 | seed = 7 抽到 t | — | t = 11 | 落在前缀 16 的矩形 0 里 |
| 4 | offset = 11 - 0 - 1 = 10 | 10 % 4 = 2 | 10 // 4 = 2 | 点 = [-2+2, -2+2] = [0, 0] |

所以这一次 `pick()` 返回 `[0, 0]`。（题面示例里的 `[1,-2]`、`[1,-1]` 等是另几次随机的结果，顺序和取值都取决于随机数，只要落在矩形里且等概率就正确。）

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `def __init__(self, rects):` | 创建对象时自动跑，先把数据准备好 |
| `self.rects = rects` | 把矩形数组存进对象，后面还要用 |
| `total = 0` | 累计到目前为止一共多少个点 |
| `for a, b, x, y in rects:` | 逐个矩形处理 |
| `total += (x - a + 1) * (y - b + 1)` | 宽 × 高 = 这个矩形覆盖的整数点个数 |
| `self.prefix.append(total)` | 把累计值存进前缀和数组 |
| `self.total = total` | 总点数，抽签的上限 |
| `t = random.randint(1, self.total)` | 随机抽一个 1 到总点数的编号 |
| `idx = bisect.bisect_left(self.prefix, t)` | 二分找这个编号落在哪个矩形 |
| `before = self.prefix[idx - 1] if idx > 0 else 0` | 前面所有矩形一共占了多少号 |
| `offset = t - before - 1` | 在这个矩形内部是第几个点（从 0 数） |
| `return [a + offset % width, b + offset // width]` | 一维序号拆成列和行，换成坐标 |

### 完整代码（Python）

```python
from typing import List
import bisect
import random

class Solution:
    def __init__(self, rects: List[List[int]]):
        self.rects = rects
        self.prefix = []
        total = 0
        for a, b, x, y in rects:
            total += (x - a + 1) * (y - b + 1)
            self.prefix.append(total)
        self.total = total

    def pick(self) -> List[int]:
        t = random.randint(1, self.total)
        idx = bisect.bisect_left(self.prefix, t)
        a, b, x, y = self.rects[idx]
        before = self.prefix[idx - 1] if idx > 0 else 0
        offset = t - before - 1
        width = x - a + 1
        return [a + offset % width, b + offset // width]
```

## 47-15. 有效三角形的个数（Medium）

> 力扣 611 · 二分查找 · Medium

**一句话**：给一堆边长，数一数能挑出多少组三条边可以围成三角形。

### 精讲（零基础版）

#### ① 这题要用到的东西

**对撞双指针**

- 一句人话：先把数组排好序，一个指针站在最左边、一个站在最右边，根据条件往中间挤，碰头就停。
- 生活类比：两个人从走廊两头往中间走，遇到就停。
- 最小例子：

```python
nums = [1, 2, 3, 4, 5]
i, j = 0, len(nums) - 1
while i < j:
    print("左", nums[i], "右", nums[j], "和", nums[i] + nums[j])
    if nums[i] + nums[j] > 6:
        j -= 1
    else:
        i += 1
# -> 左 1 右 5 和 6
# -> 左 2 右 5 和 7
# -> 左 2 右 4 和 6
# -> 左 3 右 4 和 7
```

- 这题里干什么：把最长边固定住，在它左边用对撞双指针数出所有合法组合，比三重循环快得多。

**三角形判定**

- 一句人话：任意两边之和大于第三边；排序之后只要保证"最小的两条边之和 > 最长边"就够了。
- 生活类比：三根棍子，两根短的接起来都够不到最长那根，就围不成三角形。
- 最小例子：

```python
for a, b, c in [(2, 3, 4), (2, 2, 3), (1, 2, 3)]:
    print(a, b, c, "->", a + b > c)
# -> 2 3 4 -> True
# -> 2 2 3 -> True
# -> 1 2 3 -> False   （1 + 2 正好等于 3，退化成一条线）
```

- 这题里干什么：判断条件就是 `nums[i] + nums[j] > nums[k]`，其中 k 是最长边的下标。

#### ② 大白话：这题到底在干什么

三个数能不能围成三角形：排序之后，看最小的两个加起来是不是大于最大的那个。

最笨的办法：三重循环把所有三元组都试一遍，O(n³)。n 最大 1000，10 亿次，太慢。

聪明办法：先排序。把"最长边"固定住（枚举 k），然后在 k 左边用两个指针 i、j 从两头往中间挤。关键的一步是：如果 `nums[i] + nums[j] > nums[k]`，那么从 i 到 j-1 之间的每一个数，配 nums[j] 都合法——因为数组有序，它们都比 nums[i] 大。所以一次就能加上 `j - i` 个，然后 j 往左挪一格继续。如果加起来不够大，说明 nums[i] 太小，i 往右挪。

这样整体是 O(n²)。

#### ③ 拿一个具体输入走一遍

以题面示例 1 为例：`nums = [2,2,3,4]`，排序后还是 `[2, 2, 3, 4]`。

| 步骤 | 最长边 k | i / j | nums[i]+nums[j] | 与最长边比，累计怎么变 |
|---|---|---|---|---|
| 1 | 4 | 0 / 2 | 2 + 3 = 5 | 5 > 4，i 到 j-1 都合法，加 2 → 2 |
| 2 | 4 | 0 / 1 | 2 + 2 = 4 | 4 不大于 4，不变 → 2，i 挪到 1 |
| 3 | 3 | 0 / 1 | 2 + 2 = 4 | 4 > 3，合法，加 1 → 3 |

k 走到 1 时左边只剩一个数，凑不出三条边，循环结束。所以答案是 3。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `nums.sort()` | 先排序，后面才能用"有序"这个性质 |
| `cnt = 0` | 数合法三元组的个数 |
| `for k in range(len(nums) - 1, 1, -1):` | 从最长的边开始，逐个固定最长边 |
| `i, j = 0, k - 1` | 两个指针放在最长边左边的两头 |
| `while i < j:` | 两头没碰头就继续 |
| `if nums[i] + nums[j] > nums[k]:` | 这两条短边加起来比最长边大 |
| `cnt += j - i` | 从 i 到 j-1 每个数配 nums[j] 都合法，一次加完 |
| `j -= 1` | 试下一组更小的 j |
| `else:` | 加起来不够，说明 nums[i] 太小 |
| `i += 1` | 换一个更大的 nums[i] |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def triangleNumber(self, nums: List[int]) -> int:
        nums.sort()
        cnt = 0
        for k in range(len(nums) - 1, 1, -1):
            i, j = 0, k - 1
            while i < j:
                if nums[i] + nums[j] > nums[k]:
                    cnt += j - i
                    j -= 1
                else:
                    i += 1
        return cnt
```

## 47-16. 最大交换（Medium）

> 力扣 670 · 贪心 · Medium

**一句话**：一个非负整数，最多交换其中两位数字，让结果尽可能大。

### 精讲（零基础版）

#### ① 这题要用到的东西

**贪心**

- 一句人话：每一步都做"当下看起来最划算"的选择，并且相信这样能得到全局最优。
- 生活类比：换零钱时先用最大面额，能用 100 就不用 50。
- 最小例子：

```python
coins = [100, 50, 10, 1]
amount = 186
used = []
for c in coins:
    while amount >= c:
        amount -= c
        used.append(c)
print(used)     # -> [100, 50, 10, 10, 10, 1, 1, 1, 1, 1, 1]
print(amount)   # -> 0
```

- 这题里干什么：要让数字最大，就从最高位开始，每一位都尽量换成"右边能换到的最大数字"。最高位涨 1 比最低位涨 9 都值钱，所以一旦能换就立刻换。

**字典记录"每个数字最后出现的位置"**

- 一句人话：把每个数字和它最后一次出现的位置存起来。
- 生活类比：记下每个球员最后一次上场是在第几分钟。
- 最小例子：

```python
s = "2736"
last = {}
for i, ch in enumerate(s):
    last[ch] = i
print(last)     # -> {'2': 0, '7': 1, '3': 2, '6': 3}
```

- 这题里干什么：要把某一位换成更大的数字时，希望换来的那个数字尽量靠右——这样被换走的小数字影响最小。所以记"最后出现位置"。

#### ② 大白话：这题到底在干什么

最多换一次，要换出最大的数。

直觉：越靠左的位越重要，所以从最左边开始看。看这一位右边有没有比它大的数字：没有，这一位换不了，看下一位；有，就换——换哪个？换最大的那个；如果有好几个一样大的，换最靠右的那个（把小的数字扔到越后面越好）。

第一位一旦能换就换完收工，因为高位变大已经是最优了，再动低位只会更小。如果一直看到最后都换不了（比如 9973，每位都不比右边小），就原样返回。

#### ③ 拿一个具体输入走一遍

以题面示例 1 为例：num = 2736。

先记录每个数字最后出现的位置：`{'2': 0, '7': 1, '3': 2, '6': 3}`。

| 步骤 | 当前位 i / 数字 | 试换成的数字（从 9 往下） | 该数字最后出现的位置 | 结论 |
|---|---|---|---|---|
| 1 | 0 / 2 | 9 | 不存在 | 继续试 |
| 2 | 0 / 2 | 8 | 不存在 | 继续试 |
| 3 | 0 / 2 | 7 | 1（大于 0，在右边） | 交换下标 0 和 1 → 7236 |

所以答案是 7236。（对照示例 2：9973 的每一位都不比右边任何数小，一次都换不了，返回 9973。）

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `s = list(str(num))` | 把数字拆成一个个字符，方便交换 |
| `last = {}` | 记每个数字最后出现的下标 |
| `for i, ch in enumerate(s): last[ch] = i` | 边遍历边覆盖，最后留下的就是"最后一次" |
| `for i, ch in enumerate(s):` | 从左往右看每一位 |
| `for d in range(9, int(ch), -1):` | 从 9 往下试，看有没有比当前位更大的数字 |
| `if c in last and last[c] > i:` | 这个更大的数字存在，而且在当前位右边 |
| `j = last[c]` | 取它最后出现的位置（最靠右的那个） |
| `s[i], s[j] = s[j], s[i]` | 交换这两位 |
| `return int("".join(s))` | 换完就是最大，直接返回 |
| `return num` | 一次都没换成，原样返回 |

### 完整代码（Python）

```python
class Solution:
    def maximumSwap(self, num: int) -> int:
        s = list(str(num))
        last = {}
        for i, ch in enumerate(s):
            last[ch] = i
        for i, ch in enumerate(s):
            for d in range(9, int(ch), -1):
                c = str(d)
                if c in last and last[c] > i:
                    j = last[c]
                    s[i], s[j] = s[j], s[i]
                    return int("".join(s))
        return num
```

## 47-17. 字母大小写全排列（Medium）

> 力扣 784 · 回溯 · Medium

**一句话**：把字符串里每个字母都可以变大写或小写，列出所有能拼出来的字符串（数字不动）。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`str.isalpha()` / `lower()` / `upper()`**

- 一句人话：判断是不是字母、转成全小写、转成全大写。
- 生活类比：一张卡片正面印大写、反面印小写，翻一下就是另一个。
- 最小例子：

```python
ch = "b"
print(ch.isalpha())   # -> True
print(ch.lower())     # -> b
print(ch.upper())     # -> B
print("1".isalpha())  # -> False
```

- 这题里干什么：遇到字母就分"小写、大写"两个分支，遇到数字只有一个分支（原样保留）。

**`"".join(列表)`**

- 一句人话：把一堆字符按顺序拼成一个字符串。
- 生活类比：把散落的珠子按顺序穿成一条项链。
- 最小例子：

```python
path = ["a", "1", "B", "2"]
print("".join(path))   # -> a1B2
```

- 这题里干什么：递归过程中用一个列表攒字符，走到末尾时 join 成答案。

**回溯**（前面 47-5 讲过）：一个字符一个字符往下走，字母分两支、数字一支，走到底记一笔，然后退回来换另一支。

#### ② 大白话：这题到底在干什么

每个字母有两种状态（原样 / 换大小写），数字只有一种。所以答案个数是 2 的"字母个数"次方。

最笨的办法：枚举 0 到 2^k-1 的每个二进制数，第 i 位是 1 就翻转第 i 个字母。能写，但读起来绕。

聪明办法：一个字符一个字符往下走。是字母，就走两次：一次选小写、一次选大写；是数字，只走一次。走到字符串末尾，当前攒出来的就是一个答案。这样代码和"枚举所有可能"的直觉完全对得上。

#### ③ 拿一个具体输入走一遍

以题面示例 1 为例：s = `"a1b2"`。

| 步骤 | 走到第几位 | 字符 | 选择 | 当前拼出的串 |
|---|---|---|---|---|
| 1 | 0 | a | 小写 a | a |
| 2 | 1 | 1 | 数字，只有一种 | a1 |
| 3 | 2 | b | 小写 b | a1b |
| 4 | 3 | 2 | 数字，只有一种 | a1b2 → 记录 |
| 5 | 退回第 2 位 | b | 大写 B | a1B2 → 记录 |
| 6 | 退回第 0 位 | a | 大写 A | A1b2 → 记录 |
| 7 | 退回第 2 位 | b | 大写 B | A1B2 → 记录 |

所以答案是 `["a1b2", "a1B2", "A1b2", "A1B2"]`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `res, path = [], []` | 答案列表、当前正在拼的字符 |
| `def dfs(i):` | i 是当前处理到第几个字符 |
| `if i == len(s):` | 所有字符都处理完了 |
| `res.append("".join(path))` | 拼成字符串收进答案 |
| `if ch.isalpha():` | 是字母，有两个分支 |
| `path.append(ch.lower()); dfs(i + 1); path.pop()` | 选小写，往下走，再撤销 |
| `path.append(ch.upper()); dfs(i + 1); path.pop()` | 选大写，往下走，再撤销 |
| `else:` | 是数字，只有一个分支 |
| `path.append(ch); dfs(i + 1); path.pop()` | 原样放进去，往下走 |
| `dfs(0)` | 从第 0 个字符开始 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def letterCasePermutation(self, s: str) -> List[str]:
        res = []
        path = []

        def dfs(i: int) -> None:
            if i == len(s):
                res.append("".join(path))
                return
            ch = s[i]
            if ch.isalpha():
                path.append(ch.lower())
                dfs(i + 1)
                path.pop()
                path.append(ch.upper())
                dfs(i + 1)
                path.pop()
            else:
                path.append(ch)
                dfs(i + 1)
                path.pop()

        dfs(0)
        return res
```

## 47-18. 爱吃香蕉的珂珂（Medium）

> 力扣 875 · 二分查找 · Medium

**一句话**：有 n 堆香蕉，珂珂每小时选一堆吃掉 k 根（这堆不够 k 就吃完、这个小时不再吃别的），求 h 小时内吃完所有香蕉的最小速度 k。

### 精讲（零基础版）

#### ① 这题要用到的东西

**向上取整 `(a + b - 1) // b`**

- 一句人话：a 除以 b，除不尽就进一。
- 生活类比：25 个人坐 10 人一桌，要 3 桌（第 3 桌只坐 5 人）。
- 最小例子：

```python
for p, k in [(3, 4), (7, 4), (11, 4), (8, 4)]:
    print(p, "根，速度", k, "->", (p + k - 1) // k, "小时")
# -> 3 根，速度 4 -> 1 小时
# -> 7 根，速度 4 -> 2 小时
# -> 11 根，速度 4 -> 3 小时
# -> 8 根，速度 4 -> 2 小时
```

- 这题里干什么：一堆 p 根香蕉、速度 k，需要的小时数就是"p 除以 k 向上取整"，也就是 `(p + k - 1) // k`。

**单调性**

- 一句人话：速度越快，总时间越少；所以"能不能在 h 小时内吃完"这件事，随着 k 变大从"不能"变成"能"。
- 生活类比：走得越快，到得越早；问"能不能在 10 点前到"，走得越快越可能做到。
- 最小例子：

```python
piles = [3, 6, 7, 11]
for k in [3, 4, 6, 11]:
    hours = 0
    for p in piles:
        hours += (p + k - 1) // k
    print("速度", k, "-> 总时间", hours)
# -> 速度 3 -> 总时间 10
# -> 速度 4 -> 总时间 8
# -> 速度 6 -> 总时间 6
# -> 速度 11 -> 总时间 4
```

- 这题里干什么：正因为这个条件随 k 单调翻转，才能在 k 的范围上二分找"最小的能行的 k"。

**二分答案**（前面 47-9 讲过）：这次二分的对象是"速度 k"，范围是 1 到最大那一堆的香蕉数（再快也没意义，因为每小时最多吃一堆）。判定函数是"以速度 k 吃完要几小时 ≤ h"。

#### ② 大白话：这题到底在干什么

速度越慢越舒服，但必须 h 小时内吃完，所以要找"能行的最慢速度"。

速度的范围很明确：最小 1，最大是最大那堆的香蕉数（速度超过最大堆也没用，因为每小时只能吃一堆，吃超了也浪费）。在这个范围里二分：猜一个速度，算算总共要几小时。不超过 h，说明这个速度够用，记下来，试试更慢的；超过 h，说明太慢，得加快。

算时间有个容易错的地方：每一堆单独计时。一堆 7 根、速度 4，需要 2 小时（1 小时吃 4 根，第 2 小时吃剩下 3 根），不能把第 2 小时剩的时间拿去吃别的堆。所以是"每堆分别向上取整，再求和"。

#### ③ 拿一个具体输入走一遍

以题面示例 1 为例：`piles = [3,6,7,11]`，h = 8，速度范围是 1 到 11。

| 步骤 | left / right | 猜的速度 mid | 每堆要几小时（合计） | 判断 |
|---|---|---|---|---|
| 1 | 1 / 11 | 6 | 1, 1, 2, 2 → 共 6 | 6 ≤ 8，够，right = 6 |
| 2 | 1 / 6 | 3 | 1, 2, 3, 4 → 共 10 | 10 > 8，不够，left = 4 |
| 3 | 4 / 6 | 5 | 1, 2, 2, 3 → 共 8 | 8 ≤ 8，够，right = 5 |
| 4 | 4 / 5 | 4 | 1, 2, 2, 3 → 共 8 | 8 ≤ 8，够，right = 4 |

left 和 right 都变成 4，结束。所以答案是 4。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `left, right = 1, max(piles)` | 速度范围：最少 1，最多最大那堆的根数 |
| `while left < right:` | 范围缩到一个数就停 |
| `mid = (left + right) // 2` | 猜一个速度 |
| `hours = 0` | 累计需要的小时数 |
| `for p in piles:` | 每堆单独算 |
| `hours += (p + mid - 1) // mid` | 这堆要几小时（向上取整），加进总数 |
| `if hours <= h:` | 这个速度能在 h 小时内吃完 |
| `right = mid` | 够用，但可能还能更慢，往左收 |
| `else:` | 吃不完，太慢了 |
| `left = mid + 1` | 必须更快 |
| `return left` | 碰头的这个速度就是最小的可行速度 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def minEatingSpeed(self, piles: List[int], h: int) -> int:
        left, right = 1, max(piles)
        while left < right:
            mid = (left + right) // 2
            hours = 0
            for p in piles:
                hours += (p + mid - 1) // mid
            if hours <= h:
                right = mid
            else:
                left = mid + 1
        return left
```

## 47-19. 串联字符串的最大长度（Medium）

> 力扣 1239 · 回溯 · Medium

**一句话**：从字符串数组里挑若干个拼起来，要求拼出来的串没有重复字母，求能拼出的最大长度。

### 精讲（零基础版）

#### ① 这题要用到的东西

**位掩码（bitmask）表示"有哪些字母"**

- 一句人话：用一个整数的二进制位当开关，第 0 位代表 a、第 1 位代表 b……某位是 1 就表示这个字母出现过。
- 生活类比：26 个开关的配电箱，每个字母一个开关，出现过就按下。
- 最小例子：

```python
mask = 0
for ch in "ab":
    mask |= 1 << (ord(ch) - 97)     # 按下对应开关
print(bin(mask))        # -> 0b11
print(mask & (1 << 0))  # -> 1   （a 出现过）
print(mask & (1 << 2))  # -> 0   （c 没出现过）
```

- 这题里干什么：判断两段字符串有没有重复字母，只要 `mask1 & mask2 == 0`；合并两段就是 `mask1 | mask2`。比用 set 判断快，写起来也短。
- 小知识：`ord('a')` 是 97，所以 `ord(ch) - 97` 把 a~z 映射成 0~25，正好当第几位用。

**回溯**（前面 47-5 讲过）：一段一段往后试，能拼就拼上、往下走，拼不上就跳过。

#### ② 大白话：这题到底在干什么

从数组里挑若干段拼起来，要求拼出来的串没有重复字母，求最长能拼多长。

最笨的办法：枚举所有子集（数组最多 16 个元素，2^16 = 65536 个子集），每个子集拼起来再检查有没有重复字母。能过，但每次都重新拼一遍很浪费。

聪明办法：还是回溯，但把"已经用了哪些字母"压缩成一个整数。试一段新字符串时，先把它自己的字母压成一个整数；如果它自己内部就有重复（比如 "aa"），直接不能用；如果它和已经用过的字母有交集，跳过；否则合并两个整数继续往下走。

#### ③ 拿一个具体输入走一遍

以题面示例 1 为例：`arr = ["un","iq","ue"]`。

| 步骤 | 已选 | 试的字符串 | 冲突检查 / 当前总长 | 最优 |
|---|---|---|---|---|
| 1 | [] | "un" | 无冲突，总长 2 | 2 |
| 2 | ["un"] | "iq" | 无冲突，总长 4 | 4 |
| 3 | ["un","iq"] | "ue" | u 已经用过，冲突，跳过 | 4 |
| 4 | ["un"] | "ue" | u 已经用过，冲突，跳过（总长仍是 2） | 4 |
| 5 | [] | "iq" | 无冲突，总长 2 | 4 |
| 6 | ["iq"] | "ue" | 无冲突，总长 4 | 4 |
| 7 | [] | "ue" | 无冲突，总长 2 | 4 |

所以答案是 4（"uniq" 和 "ique" 都能拼到 4）。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `best = 0` | 记录目前最长能拼多长 |
| `def dfs(i, mask, length):` | i 是下一段从哪开始试，mask 是已用字母，length 是当前长度 |
| `if length > best: best = length` | 每到一个状态都刷新一次最优 |
| `for j in range(i, len(arr)):` | 从 i 往后试每一段 |
| `m = 0; ok = True` | 准备算这一段的字母掩码 |
| `b = 1 << (ord(ch) - 97)` | 这个字母对应的开关 |
| `if m & b: ok = False; break` | 这段自己内部就重复了，直接作废 |
| `m \|= b` | 按下开关 |
| `if not ok or (mask & m): continue` | 自己重复，或者和已用的冲突，跳过 |
| `dfs(j + 1, mask \| m, length + len(arr[j]))` | 没冲突，拼上，往下走 |
| `dfs(0, 0, 0)` | 从第 0 段开始，已用字母为空，长度 0 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def maxLength(self, arr: List[str]) -> int:
        best = 0

        def dfs(i: int, mask: int, length: int) -> None:
            nonlocal best
            if length > best:
                best = length
            for j in range(i, len(arr)):
                m = 0
                ok = True
                for ch in arr[j]:
                    b = 1 << (ord(ch) - 97)
                    if m & b:
                        ok = False
                        break
                    m |= b
                if not ok or (mask & m):
                    continue
                dfs(j + 1, mask | m, length + len(arr[j]))

        dfs(0, 0, 0)
        return best
```

## 47-20. 两球之间的磁力（Medium）

> 力扣 1552 · 二分查找 · Medium

**一句话**：把 m 个球放进 n 个篮子里（位置给定），让"最近的两个球"尽量远，求这个最近距离的最大值。

### 精讲（零基础版）

#### ① 这题要用到的东西

**上取整的中点 `(left + right + 1) // 2`**

- 一句人话：二分"找最大的可行值"时，中点要向上取整，否则 left 和 right 相邻时会原地打转，永远出不来。
- 生活类比：两个台阶之间只差一级，你每次迈半步却总是落在原地，就永远上不去。
- 最小例子：

```python
left, right = 3, 4
print((left + right) // 2)       # -> 3   （向下取整，等于 left，卡住）
print((left + right + 1) // 2)   # -> 4   （向上取整，能往前走）
```

- 这题里干什么：这题找的是"最大的 d"，所以要用向上取整的中点。47-18 那题找"最小的 k"，用的是向下取整的中点。**找最大用 +1 上取整，找最小用下取整**，记这一条就够。

**贪心判定**（贪心前面 47-16 讲过）

- 一句人话：判断"距离 d 行不行"时，从左到右能放就放——第一个球放最左边，之后每个球放在"第一个和上一个距离 ≥ d"的篮子里。这样放能放的球最多。
- 生活类比：公交车座位，尽量往前坐，只要和上一个人隔够距离就坐。
- 这题里干什么：判定函数 `feasible(d)`。如果这种"能放就放"的策略都放不下 m 个球，那别的放法更不可能。

**二分答案**（前面 47-9 讲过）：在"最小磁力 d"的范围 [1, 最大位置差] 上二分。

#### ② 大白话：这题到底在干什么

把 m 个球放进篮子里，让最近的两个球尽量远，求这个最近距离最大能是多少。

d 越大越难放，d 越小越容易放。这个"能放/不能放"随 d 变大从"能"变成"不能"，单调翻转，所以可以二分 d。

对每个 d，怎么判断能不能放下 m 个球？贪心：第一个球放最左边那个篮子，然后从左往右扫，遇到第一个"和上一个球距离 ≥ d"的篮子就放一个。这样放出来的球数是最多的。数一数够不够 m 个就行。

#### ③ 拿一个具体输入走一遍

以题面示例 1 为例：`position = [1,2,3,4,7]`，m = 3，位置差最大是 7-1 = 6。

| 步骤 | left / right | 猜的 d | 贪心放球的位置（放几个） | 判断 |
|---|---|---|---|---|
| 1 | 1 / 6 | 4 | 1, 7（2 个） | 不够 3 个，right = 3 |
| 2 | 1 / 3 | 2 | 1, 3, 7（3 个） | 够，left = 2 |
| 3 | 2 / 3 | 3 | 1, 4, 7（3 个） | 够，left = 3 |

left 和 right 都变成 3，结束。所以答案是 3。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `position.sort()` | 位置排好序，贪心才能从左往右走 |
| `def feasible(d):` | 判断"最小距离 d"行不行 |
| `cnt, last = 1, position[0]` | 第一个球放在最左边，已放 1 个 |
| `for p in position[1:]:` | 从左往右看剩下的篮子 |
| `if p - last >= d:` | 这个篮子和上一个球够远 |
| `cnt += 1; last = p` | 放一个球，更新"上一个球"的位置 |
| `return cnt >= m` | 放得下 m 个就说明 d 可行 |
| `left, right = 1, position[-1] - position[0]` | d 的范围：最小 1，最大是首尾位置差 |
| `mid = (left + right + 1) // 2` | 找最大值，中点要向上取整 |
| `if feasible(mid): left = mid` | 可行，试试更大的 d |
| `else: right = mid - 1` | 不可行，d 得变小 |
| `return left` | 碰头的这个 d 就是答案 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def maxDistance(self, position: List[int], m: int) -> int:
        position.sort()

        def feasible(d: int) -> bool:
            cnt, last = 1, position[0]
            for p in position[1:]:
                if p - last >= d:
                    cnt += 1
                    last = p
            return cnt >= m

        left, right = 1, position[-1] - position[0]
        while left < right:
            mid = (left + right + 1) // 2
            if feasible(mid):
                left = mid
            else:
                right = mid - 1
        return left
```

## 47-21. 模式匹配（Medium）

> 力扣 面试题 16.18 · 回溯 · Medium

**一句话**：pattern 只由 a、b 组成，判断 value 能不能被切成"a 代表一段、b 代表另一段"的样子（a 和 b 不能代表同一个字符串）。

### 精讲（零基础版）

#### ① 这题要用到的东西

**枚举 + 校验**

- 一句人话：把可能的答案一个个试，每个都完整验一遍，对了就返回。
- 生活类比：试钥匙，一把把插进锁里拧，能开就是它。
- 最小例子：

```python
def verify(segs, a, b):
    return all(s == a or s == b for s in segs)

print(verify(["dog", "cat", "cat", "dog"], "dog", "cat"))    # -> True
print(verify(["dog", "cat", "cat", "fish"], "dog", "cat"))   # -> False
```

- 这题里干什么：枚举"a 代表的字符串有多长"，每一种都按 pattern 切一遍 value 来验证。

**长度方程组**

- 一句人话：设 a 代表的串长为 lenA、b 的为 lenB，那么 `lenA × (a 出现次数) + lenB × (b 出现次数) = value 的长度`。只枚举 lenA，lenB 就被算出来了。
- 生活类比：买东西只知道总价和两种商品的件数，只要猜出第一种的单价，第二种的单价就被总价定死了。
- 最小例子：

```python
pattern = "abba"
value = "dogcatcatdog"
na = pattern.count("a")          # a 出现 2 次
nb = len(pattern) - na           # b 也出现 2 次
print("na =", na, "nb =", nb)    # -> na = 2 nb = 2
for lenA in range(0, len(value) // na + 1):
    rest = len(value) - lenA * na
    if rest % nb == 0:
        print("lenA =", lenA, "-> lenB =", rest // nb)
# -> lenA = 0 -> lenB = 6
# -> lenA = 1 -> lenB = 5
# -> lenA = 2 -> lenB = 4
# -> lenA = 3 -> lenB = 3
# -> lenA = 4 -> lenB = 2
# -> lenA = 5 -> lenB = 1
# -> lenA = 6 -> lenB = 0
```

- 这题里干什么：不用猜两个长度，只枚举 lenA（最多 1000 种），lenB 直接算出来。`rest % nb != 0` 的那些 lenA 连整除都做不到，直接跳过。

**`str.count`**（前面 47-19 用过 `arr` 里的字符统计思路，这里是最直接的用法）：`print("abba".count("a"))` 输出 `2`，数一个字符出现几次。

#### ② 大白话：这题到底在干什么

pattern 里的 a 和 b 各代表一段"未知的字符串"，而且这两段不能相同。value 要能按 pattern 完整对出来。

最笨的办法：枚举 a 和 b 的所有可能内容——这是不可能的，组合太多。

聪明办法：a 和 b 的长度加起来必须刚好等于 value 的长度。所以只枚举 a 的长度（0 到 value 长度），b 的长度就由总长度定死了。定好两个长度之后，按 pattern 的顺序去切 value：遇到 a 就切 lenA 个字符，遇到 b 就切 lenB 个字符。切完检查两件事——每次切出来的 a 是不是都一样、每次切出来的 b 是不是都一样；最后再看 a 和 b 是不是不同的字符串。

还有两种特殊情况要单独处理：pattern 里只有 a（或只有 b），这时只有一个未知长度，另一种字母根本不出现；pattern 是空串，那 value 也必须是空串。

#### ③ 拿一个具体输入走一遍

以题面示例 1 为例：pattern = `"abba"`，value = `"dogcatcatdog"`，长度 12，a、b 各出现 2 次。

| 步骤 | 猜的 lenA | 算出的 lenB | 按 abba 切出来的四段 | 结论 |
|---|---|---|---|---|
| 1 | 0 | 6 | "" / "dogcat" / "catdog" / "" | 两次 b 不一样，失败 |
| 2 | 1 | 5 | "d" / "ogcat" / "catdo" / "g" | 两次 a 不一样，失败 |
| 3 | 2 | 4 | "do" / "gcat" / "catd" / "og" | 两次 a 不一样，失败 |
| 4 | 3 | 3 | "dog" / "cat" / "cat" / "dog" | a 两次都是 "dog"、b 两次都是 "cat"，且 "dog" ≠ "cat" → true |

所以答案是 true。（对照示例 2：value = `"dogcatcatfish"`，只有 lenA=3 这一种切法能对上长度，但最后一段是 "fish" 而 a 是 "dog"，对不上，返回 false。）

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `if not pattern: return value == ""` | pattern 是空串，value 也必须是空串 |
| `na = pattern.count("a")` | a 出现几次 |
| `nb = len(pattern) - na` | b 出现几次 |
| `if na == 0:` | pattern 全是 b，只有一个未知长度 |
| `if len(value) % nb != 0: return False` | 除不尽，不可能切开 |
| `sub * nb == value` | 切成 nb 段，每段必须一样 |
| `for lenA in range(0, len(value) // na + 1):` | 枚举 a 的长度 |
| `rest = len(value) - lenA * na` | 剩下留给 b 的总长度 |
| `if rest % nb != 0: continue` | b 那边除不尽，这个 lenA 不行 |
| `lenB = rest // nb` | b 的长度被算出来了 |
| `b = None` … `elif b != seg: ok = False` | 第一次见到 b 就记住，后面每次都要和它一样 |
| `if ok and pos == len(value) and a != b:` | 全部对上、正好用完、且 a 和 b 不同 → true |

### 完整代码（Python）

```python
class Solution:
    def patternMatching(self, pattern: str, value: str) -> bool:
        if not pattern:
            return value == ""
        na = pattern.count("a")
        nb = len(pattern) - na
        if na == 0:
            if len(value) % nb != 0:
                return False
            L = len(value) // nb
            sub = value[:L]
            return sub * nb == value
        for lenA in range(0, len(value) // na + 1):
            rest = len(value) - lenA * na
            if nb == 0:
                if rest != 0:
                    continue
                a = value[:lenA]
                ok = True
                pos = 0
                for ch in pattern:
                    if value[pos:pos + lenA] != a:
                        ok = False
                        break
                    pos += lenA
                if ok and pos == len(value):
                    return True
                continue
            if rest % nb != 0:
                continue
            lenB = rest // nb
            a = value[:lenA]
            b = None
            pos = 0
            ok = True
            for ch in pattern:
                if ch == "a":
                    if value[pos:pos + lenA] != a:
                        ok = False
                        break
                    pos += lenA
                else:
                    seg = value[pos:pos + lenB]
                    if b is None:
                        b = seg
                    elif b != seg:
                        ok = False
                        break
                    pos += lenB
            if ok and pos == len(value) and a != b:
                return True
        return False
```

## 47-22. 寻找两个正序数组的中位数（Hard）

> 力扣 4 · 二分查找 · Hard

**一句话**：两个各自排好序的数组，求把它们合并排好序之后的中位数，要求 O(log(m+n))。

### 精讲（零基础版）

#### ① 这题要用到的东西

**中位数的定义（按位置找）**

- 一句人话：合并排好序后，正中间那个数（个数是偶数就取中间两个的平均）。
- 生活类比：一排人按身高站好，找站在正中间的那个；人数是双数就取中间两个取平均。
- 最小例子：

```python
merged = sorted([1, 3] + [2])
print(merged)                      # -> [1, 2, 3]
print(merged[len(merged) // 2])    # -> 2

merged2 = sorted([1, 2] + [3, 4])
n = len(merged2)
print((merged2[n // 2 - 1] + merged2[n // 2]) / 2)   # -> 2.5
```

- 这题里干什么：中位数等价于"把合并后的数组从中间切一刀，左边那一半的最大值和右边那一半的最小值"。所以我们不用真的合并，只要找到这一刀切在哪儿。

**在短数组上二分**

- 一句人话：只枚举"第一个数组切几刀"，第二个数组切几刀由总长度决定。
- 生活类比：一队人分成左右两排，你只需要决定左边那排站几个人，右边那排自然就定了。
- 最小例子：

```python
nums1, nums2 = [2], [1, 3]
total_left = (1 + 2 + 1) // 2       # 左边一共要有 2 个元素
print("左边应有", total_left, "个")   # -> 左边应有 2 个
for i in range(len(nums1) + 1):      # i = 第一个数组切几刀
    j = total_left - i               # j 就定了
    print("i =", i, "j =", j)
# -> i = 0 j = 2
# -> i = 1 j = 1
```

- 这题里干什么：i 的取值范围只有"短数组长度 + 1"种，所以二分次数是 log(min(m,n))。

**哨兵 `float('-inf')` / `float('inf')`**

- 一句人话：假装数组两端各有一个"永远更小/永远更大"的虚拟元素，省掉一堆"数组空了怎么办"的边界判断。
- 生活类比：在队伍两头各站一个"最矮"和"最高"的假人，比较的时候不用特判"这头没人了"。
- 最小例子：

```python
nums = [2]
i = 0
left_val = nums[i - 1] if i > 0 else float('-inf')
right_val = nums[i] if i < len(nums) else float('inf')
print(left_val)    # -> -inf
print(right_val)   # -> 2
```

- 这题里干什么：切在数组最左端时，左边没有元素，用 `-inf` 顶上；切在最右端时，右边没有元素，用 `inf` 顶上。这样四个值永远存在，比较逻辑就只有一套。

#### ② 大白话：这题到底在干什么

最直接的办法：把两个数组合并、排序，取中间。合并是 O(m+n)，题目要 O(log(m+n))。

聪明办法：不真合并，只决定"第一个数组从哪里切开"。假设第一个数组切在 i，第二个数组切在 j，要求左边一共有 `(m+n+1)//2` 个元素，那么 `j = (m+n+1)//2 - i`，j 由 i 决定，不用单独枚举。

一刀切得对不对，看两个条件：左边最大的元素 ≤ 右边最小的元素。具体是 `A左 ≤ B右` 且 `B左 ≤ A右`。成立就说明这一刀切对了，中位数就在刀口两边：总个数是奇数就取左边最大值；偶数就取"左边最大值"和"右边最小值"的平均。

不成立就调整：如果 `A左 > B右`，说明第一个数组切多了（左边塞了太大的数），i 往左挪；否则 i 往右挪。

#### ③ 拿一个具体输入走一遍

以题面示例 1 为例：`nums1 = [1,3]`，`nums2 = [2]`。因为要在短数组上二分，先交换成 `nums1 = [2]`、`nums2 = [1,3]`，左边一共要有 (1+2+1)//2 = 2 个元素。

| 步骤 | i / j（切几刀） | 短数组左 / 右 | 长数组左 / 右 | 判断 |
|---|---|---|---|---|
| 1 | 0 / 2 | -inf / 2 | 3 / inf | B左 = 3 > A右 = 2，刀切少了，i 往右 → i = 1 |
| 2 | 1 / 1 | 2 / inf | 1 / 3 | 2 ≤ 3 且 1 ≤ inf，这一刀对 |
| 3 | — | — | — | 总个数 3 是奇数，取 max(2, 1) = 2 |

所以答案是 2.00000。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `if len(nums1) > len(nums2): nums1, nums2 = nums2, nums1` | 保证在短的那个数组上二分 |
| `m, n = len(nums1), len(nums2)` | 两个数组的长度 |
| `total_left = (m + n + 1) // 2` | 左半边应该有几个元素 |
| `while left <= right:` | 在"切几刀"上二分 |
| `i = (left + right) // 2` | 第一个数组切 i 刀 |
| `j = total_left - i` | 第二个数组切几刀由总数决定 |
| `a_left = ... if i > 0 else float("-inf")` | 第一个数组左边的最大值（切在最左边就是 -inf） |
| `a_right = ... if i < m else float("inf")` | 第一个数组右边的最小值（切在最右边就是 inf） |
| `b_left` / `b_right` | 第二个数组同理 |
| `if a_left <= b_right and b_left <= a_right:` | 这一刀切对了 |
| `(m + n) % 2 == 1` | 总个数是奇数，取左边最大值 |
| `(max(...) + min(...)) / 2` | 偶数，取中间两个的平均 |
| `elif a_left > b_right: right = i - 1` | 切多了，往左挪 |
| `else: left = i + 1` | 切少了，往右挪 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1
        m, n = len(nums1), len(nums2)
        total_left = (m + n + 1) // 2
        left, right = 0, m
        while left <= right:
            i = (left + right) // 2
            j = total_left - i
            a_left = nums1[i - 1] if i > 0 else float("-inf")
            a_right = nums1[i] if i < m else float("inf")
            b_left = nums2[j - 1] if j > 0 else float("-inf")
            b_right = nums2[j] if j < n else float("inf")
            if a_left <= b_right and b_left <= a_right:
                if (m + n) % 2 == 1:
                    return float(max(a_left, b_left))
                return (max(a_left, b_left) + min(a_right, b_right)) / 2
            if a_left > b_right:
                right = i - 1
            else:
                left = i + 1
        return 0.0
```

## 47-23. N 皇后 II（Hard）

> 力扣 52 · 回溯 · Hard

**一句话**：n 个皇后放在 n×n 棋盘上，任意两个不能同行、同列、同斜线，求一共有几种摆法。

### 精讲（零基础版）

#### ① 这题要用到的东西

**对角线编号 `r + c` 与 `r - c`**

- 一句人话：同一条"左上到右下"斜线上的格子，行号减列号一样；同一条"右上到左下"斜线上的格子，行号加列号一样。
- 生活类比：棋盘上斜着走的象，走过的每一格都有固定的"斜线编号"，同一条斜线编号相同。
- 最小例子（把每个格子的两个编号打印出来）：

```python
n = 4
for r in range(n):
    row = []
    for c in range(n):
        row.append("%d/%d" % (r + c, r - c))
    print(row)
# -> ['0/0', '1/-1', '2/-2', '3/-3']
# -> ['1/1', '2/0', '3/-1', '4/-2']
# -> ['2/2', '3/1', '4/0', '5/-1']
# -> ['3/3', '4/2', '5/1', '6/0']
```

- 这题里干什么：判断"这个位置会不会被斜线上的皇后攻击"，不用沿着斜线一格格检查，只看 `r+c` 和 `r-c` 这两个编号有没有被占用过。
- 注意 `r - c` 可能是负数，但集合存负数完全没问题，不用加偏移。

**用集合记"已占用的列 / 两条斜线"**（集合前面 47-2 讲过）

- 一句人话：把用过的列号、两条斜线的编号分别丢进三个集合，判断冲突就是三次 `in`，O(1)。
- 生活类比：门口三张登记表——"列登记表""左斜线登记表""右斜线登记表"，进来先查三张表。
- 这题里干什么：代替"遍历前面所有皇后逐个比较"的笨检查。

**回溯**（前面 47-5 讲过）：一行一行放皇后，能放就放下并进入下一行，放不下就退回来换下一列。

#### ② 大白话：这题到底在干什么

每行必须放一个皇后（n 个皇后放 n 行，一行放两个就冲突了），所以可以一行一行放。

放第 r 行时，枚举 0 到 n-1 每一列，检查三件事：这一列有没有被占、这条主对角线（r+c）有没有被占、这条副对角线（r-c）有没有被占用。三样都空就放下去，进入下一行；有一样被占就跳过这一列。

放满 n 行就数到一个解，然后退回来继续试别的列。退回的时候一定要把"占用的列和斜线"还回去，不然会越积越多。

题目只问"几种摆法"，不要求输出棋盘，所以连棋盘都不用存，只要一个计数器。

#### ③ 拿一个具体输入走一遍

以题面示例 1 为例：n = 4。

| 步骤 | 行 r | 试的列 c | 检查结果 | 动作 |
|---|---|---|---|---|
| 1 | 0 | 0 | 列 0、两条斜线 0 都空 | 放下，进第 1 行 |
| 2 | 1 | 0 | 列 0 被占 | 跳过 |
| 3 | 1 | 1 | 副斜线 0 被占 | 跳过 |
| 4 | 1 | 2 | 列 2 空、斜线 3 和 -1 都空 | 放下，进第 2 行 |
| 5 | 2 | 0, 1, 2, 3 | 列 0 被占、主斜线 3 被占、列 2 被占、副斜线 -1 被占 | 全跳过，退回第 1 行 |
| 6 | 1 | 3 | 列 3 空、斜线 4 和 -2 都空 | 放下，进第 2 行 |
| 7 | 2 | 1 | 列 1 空、斜线 3 和 1 都空 | 放下，进第 3 行 |
| 8 | 3 | 0, 1, 2, 3 | 列 0 和 1 被占、副斜线 1 被占、列 3 被占 | 全跳过，退回 |
| 9 | 一路回退 | — | 最后在行 0 列 1 重新开始 | 得到第 1 个解（每行列号 1, 3, 0, 2） |
| 10 | 继续搜索 | — | — | 得到第 2 个解（每行列号 2, 0, 3, 1），共 2 个 |

所以答案是 2。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `cols, d1, d2 = set(), set(), set()` | 三张登记表：列、主斜线（r+c）、副斜线（r-c） |
| `count = 0` | 数解法的个数 |
| `def dfs(r):` | 正在放第 r 行 |
| `if r == n:` | n 行都放完了 |
| `count += 1; return` | 数到一个解，回去继续找 |
| `for c in range(n):` | 枚举这一行的每一列 |
| `if c in cols or (r + c) in d1 or (r - c) in d2:` | 三张表里有任意一张被占了 |
| `continue` | 这个位置不能放，试下一列 |
| `cols.add(c); d1.add(r + c); d2.add(r - c)` | 三张表都登记上 |
| `dfs(r + 1)` | 去下一行放 |
| `cols.remove(c); d1.remove(r + c); d2.remove(r - c)` | 撤销登记（回溯） |
| `dfs(0)` | 从第 0 行开始放 |

### 完整代码（Python）

```python
class Solution:
    def totalNQueens(self, n: int) -> int:
        cols, d1, d2 = set(), set(), set()
        count = 0

        def dfs(r: int) -> None:
            nonlocal count
            if r == n:
                count += 1
                return
            for c in range(n):
                if c in cols or (r + c) in d1 or (r - c) in d2:
                    continue
                cols.add(c)
                d1.add(r + c)
                d2.add(r - c)
                dfs(r + 1)
                cols.remove(c)
                d1.remove(r + c)
                d2.remove(r - c)

        dfs(0)
        return count
```

## 47-24. 单词搜索 II（Hard）

> 力扣 212 · 回溯 · Hard

**一句话**：在一个字母网格里，找出给定单词表里所有能在网格中走出来的单词（相邻格连线，同一格不能重复用）。

### 精讲（零基础版）

#### ① 这题要用到的东西

**前缀树（Trie）**

- 一句人话：把一堆单词按字母一层层摞成一棵树，公共前缀只存一次；从根往下走一条路径就是一个前缀，走到带标记的节点就是一个完整单词。
- 生活类比：字典的目录树，先翻到首字母那一栏，再往下找第二个字母，一路上都在缩小范围。
- 最小例子：

```python
words = ["oath", "eat"]
trie = {}
for w in words:
    node = trie
    for ch in w:
        node = node.setdefault(ch, {})
    node["#"] = w            # 用 "#" 标记"这里是一个单词的结尾"
print(trie)
# -> {'o': {'a': {'t': {'h': {'#': 'oath'}}}}, 'e': {'a': {'t': {'#': 'eat'}}}}
print(trie["o"]["a"]["t"]["h"]["#"])   # -> oath
```

- 这题里干什么：网格里从一个格子出发有很多方向，用 Trie 走一步就知道"这个前缀还有没有希望"——树上没有这个字母分支，立刻回头，不用把每个单词都单独搜一遍。所有单词共享同一遍搜索。

**`dict.setdefault(key, 默认值)`**

- 一句人话：有就取出来，没有就先放一个默认值再取出来。
- 生活类比：抽屉里找工具，有就拿，没有就先放一个新的进去再拿。
- 最小例子：

```python
node = {}
child = node.setdefault("a", {})
print(child)                               # -> {}
print(node)                                # -> {'a': {}}
print(node.setdefault("a", {}) is child)   # -> True   （第二次取到的还是同一个）
```

- 这题里干什么：建 Trie 的时候一层层往下钻，`node = node.setdefault(ch, {})` 一行就完成"没有就新建"。

**回溯**（前面 47-5 讲过）：在网格里走格子，走过就临时标记、走完改回来。这题把走过的格子临时改成 `"@"`（网格里只有小写字母，不会冲突），这样就不用额外开一个 visited 数组。

**剪枝**（前面 47-5 讲过）：树上没有对应分支就直接 return；某个单词已经找到了就把它的 `"#"` 删掉，防止后面从别的起点又把它记录一遍。

#### ② 大白话：这题到底在干什么

网格里每个格子可以向上下左右走，问给定单词表里哪些能走出来。

最笨的办法：对每个单词单独做一次搜索。单词表最多 3 万条，每条都要把网格走一遍，肯定超时。

聪明办法：先把所有单词建成一棵前缀树。然后从网格的每个格子出发做一次搜索，但不是"为了找某个词"，而是"沿着树往下走"：当前格子是字母 o，树根下有 o 这个分支吗？没有就停；有就进入 o 这个节点，继续看邻居格子是不是 o 的子节点（a）。这样一次搜索同时推进所有以 o 开头的单词。

走到某个节点发现它带 `"#"`，说明整条路径正好拼出一个单词，收进答案。找到之后把 `"#"` 删掉，避免重复记录。

#### ③ 拿一个具体输入走一遍

以题面示例 1 为例：board 是 4×4，words = `["oath","pea","eat","rain"]`。

先看网格里有哪些字母：有 o、a、n、e、t、i、h、k、r、f、l、v，**没有 p**，所以 "pea" 根本不可能出现。再看 "rain"：r 在 (2,3)，它的邻居是 (1,3) 的 e、(3,3) 的 v、(2,2) 的 k，没有 a，也走不下去。

| 步骤 | 当前 Trie 节点 | 网格里的走法 | 结果 |
|---|---|---|---|
| 1 | 根 | 网格里没有字母 p | "pea" 直接不可能 |
| 2 | 根 | r 在 (2,3)，邻居字母是 v、e、k | 没有 a 分支，剪掉 |
| 3 | 根 → o(0,0) → a(0,1) → t(1,1) → h(2,1) | 一路都有分支，h 节点带 `#` | 命中 "oath" |
| 4 | 根 → e(1,3) → a(1,2) → t(1,1) | t 节点带 `#` | 命中 "eat" |

所以答案是 `["eat", "oath"]`（顺序随意，题面写的是 `["eat","oath"]`）。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `trie = {}` | 前缀树的根 |
| `for w in words:` | 一个单词一个单词插进去 |
| `node = trie` | 从根开始 |
| `node = node.setdefault(ch, {})` | 有这条边就走，没有就新建 |
| `node["#"] = w` | 单词结尾打个标记，顺便把单词本身存进去 |
| `def dfs(r, c, node):` | 站在 (r,c)，当前在树的 node 节点 |
| `nxt = node.get(ch)` | 树上有当前格子这个字母的分支吗 |
| `if nxt is None: return` | 没有，剪枝，立刻回头 |
| `if "#" in nxt: res.append(nxt["#"]); del nxt["#"]` | 走到单词结尾，收进答案，并删标记防重复 |
| `board[r][c] = "@"` | 标记这个格子已经走过 |
| `for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):` | 上下左右四个方向 |
| `if 0 <= nr < m and 0 <= nc < n and board[nr][nc] != "@":` | 邻居没出界、也没走过 |
| `dfs(nr, nc, nxt)` | 往邻居走，树也往下走一层 |
| `board[r][c] = ch` | 撤销标记（回溯） |
| `for r ... for c ...: dfs(r, c, trie)` | 每个格子都当一次起点 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def findWords(self, board: List[List[str]], words: List[str]) -> List[str]:
        trie = {}
        for w in words:
            node = trie
            for ch in w:
                node = node.setdefault(ch, {})
            node["#"] = w

        m, n = len(board), len(board[0])
        res = []

        def dfs(r: int, c: int, node: dict) -> None:
            ch = board[r][c]
            nxt = node.get(ch)
            if nxt is None:
                return
            if "#" in nxt:
                res.append(nxt["#"])
                del nxt["#"]
            board[r][c] = "@"
            for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and board[nr][nc] != "@":
                    dfs(nr, nc, nxt)
            board[r][c] = ch

        for r in range(m):
            for c in range(n):
                dfs(r, c, trie)
        return res
```
