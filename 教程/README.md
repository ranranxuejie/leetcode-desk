## 每道题的结构（七段）

每道 A 类题都按这个固定结构写，方便你快速定位：

1. **一句话** —— 这题要你干什么
2. **考什么** —— 表面考点 / 真正考点 / 面试官想听到的关键句
3. **思路是怎么想出来的** —— 从暴力一步步推到最优，每步说清"为什么上一步不够好"
4. **代码（Python）** —— 完整可运行，关键行有注释
5. **复杂度** —— 时间/空间，为什么
6. **常见误区** —— 精确到"错在哪一行、错了会得到什么错误结果"
7. **面试追问 / 自测** —— 变体、必测用例

B 类题（第一册已讲过）只有三段：**30 秒回顾 + 核心代码 + 换个角度**。

## 代码可信度

所有 `class Solution` 都经过实际运行验证：

- 每道题跑题面示例 + 至少 2 个边界用例
- 多册作者额外做了「从 markdown 里抽出代码块再跑一遍」，确保**文档里的代码 = 跑过的代码**
- 「常见误区」里声称的错误输出，都是**实跑出来的真实结果**，不是编的
