## 41-1. 罗马数字转整数（Easy）

> 力扣 13 · 哈希表 · Easy
> 前置：无

**一句话**：把一串罗马字母按"右边比它大就减、否则就加"的规则，累加成一个整数。

### 精讲（零基础版）

#### ① 这题要用到的东西

**字典 `dict`（也就是哈希表）**

一句话：一张"键 → 值"的对照表。你报一个键，它直接告诉你对应的值，不用从头一个个找。

生活类比：手机通讯录。你输入名字（键），它直接跳出号码（值），不会从 A 开头念一遍。

```python
value = {'I': 1, 'V': 5, 'X': 10}
print(value['X'])         # -> 10
print('V' in value)       # -> True
print(value.get('Z', 0))  # -> 0
```

它在这题里：把 `I V X L C D M` 这 7 个字母换成 7 个数字，`value[s[i]]` 一行就拿到当前字母代表几。

**下标 `s[i]` 和"先看右边有没有人"**

一句话：字符串是一排从 0 开始编号的格子，`s[i]` 取第 i 格；`s[i + 1]` 在最后一格会越界，所以要先判断 `i + 1 < len(s)`。

生活类比：一排 7 个座位，你站在最后一号往右看，那里没有人——先确认有没有人，再去问他叫什么。

```python
s = "IV"
print(s[0], s[1])                        # -> I V
print(len(s))                            # -> 2
print(s[2] if 2 < len(s) else "右边没人")  # -> 右边没人
```

它在这题里：每个字母都要和"右边那一个"比大小，最右边那个没有右边，得走"直接加"这条路。

#### ② 大白话：这题到底在干什么

最笨的办法：把 `IV`、`IX`、`XL`、`XC`、`CD`、`CM` 这 6 个"两字母组合"先当成整体找出来，替换成数字，再把剩下的单字母加起来。能做，但要写一堆替换，还得小心替换顺序。

笨在哪？它把"同一个规则"拆成了 6 个特例去背。

聪明办法：只看相邻的两个字母。**只要左边的字母比右边小，左边这个就是"减法里的那个减数"**；否则就是正常相加。`IV` 里 `I(1) < V(5)`，所以减 1；`VI` 里 `V(5) > I(1)`，所以加 5 再加 1。整串扫一遍，每个字母只看一眼。

#### ③ 拿 `s = "MCMXCIV"` 走一遍

| i | s[i] | 右边那个 | 判定 | total |
|---|---|---|---|---|
| 0 | M | C | 比下一个 C 不小 → 加 1000 | 1000 |
| 1 | C | M | 比下一个 M 小 → 减 100 | 900 |
| 2 | M | X | 比下一个 X 不小 → 加 1000 | 1900 |
| 3 | X | C | 比下一个 C 小 → 减 10 | 1890 |
| 4 | C | I | 比下一个 I 不小 → 加 100 | 1990 |
| 5 | I | V | 比下一个 V 小 → 减 1 | 1989 |
| 6 | V | 无 | 最后一个 → 加 5 | 1994 |

所以答案是 1994。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `value = {'I': 1, ...}` | 建好"字母 → 数字"的对照表 |
| `total = 0` | 累加器，从 0 开始 |
| `for i in range(len(s)):` | 一个格子一个格子走过去 |
| `if i + 1 < len(s) and value[s[i]] < value[s[i + 1]]:` | 右边还有人，并且右边比我大 |
| `total -= value[s[i]]` | 那我就是减数，减掉自己 |
| `else:` / `total += value[s[i]]` | 其余情况（含最后一个）都是加 |
| `return total` | 扫完就是答案 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def romanToInt(self, s: str) -> int:
        value = {'I': 1, 'V': 5, 'X': 10, 'L': 50, 'C': 100, 'D': 500, 'M': 1000}
        total = 0
        for i in range(len(s)):
            if i + 1 < len(s) and value[s[i]] < value[s[i + 1]]:
                total -= value[s[i]]      # 右边比我大：我是减数
            else:
                total += value[s[i]]      # 否则正常加
        return total
```

## 41-2. 多数元素（Easy）

> 力扣 169 · 哈希表 · Easy
> 前置：41-1（字典）

**一句话**：找出出现次数超过一半的那个数。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`Counter`（计数器）**

一句话：专门用来数数的字典，丢进去一个列表，它直接给你"每个元素出现了几次"。

生活类比：收票员不记谁先来，只在一张表上给每个号码画"正"字，最后看谁的笔画最多。

```python
from collections import Counter
cnt = Counter([2, 2, 1, 1, 1, 2, 2])
print(cnt)            # -> Counter({2: 4, 1: 3})
print(cnt[2])         # -> 4
print(cnt[99])        # -> 0
```

它在这题里：一行就能知道每个数字出现了几次，不用自己写 `if x in d` 那套。

**`//` 整除**

一句话：`//` 是"除完只留整数部分"，`7 // 2` 是 3，不是 3.5。

生活类比：7 个苹果分给 2 个人，每人 3 个，剩下 1 个不参与分配。

```python
print(7 // 2)      # -> 3
print(6 // 2)      # -> 3
print(1 // 2)      # -> 0
```

它在这题里：题目说"出现次数大于 `⌊n/2⌋`"，`⌊n/2⌋` 就是 `n // 2`。

**`cnt.items()`**

一句话：把字典里的每一对"键和值"同时取出来，左边接键、右边接值。

生活类比：点名时一次喊"名字 + 学号"，而不是先喊名字再查学号。

```python
d = {'a': 2, 'b': 1}
for k, v in d.items():
    print(k, v)
# -> a 2
# -> b 1
```

它在这题里：一边拿到数字、一边拿到它的次数，直接比大小。

#### ② 大白话：这题到底在干什么

最笨的办法：对每个数字，都从头把数组数一遍，看它出现了几次。n 个数就要数 n 遍，n 是 5 万时是 25 亿次，跑不动。

笨在哪？**同一个数字被反复数了很多遍**，而这些遍数其实是同一次统计。

聪明办法：只走一遍数组，边走边在表上记"这个数出现过几次"，走完再看谁的次数过半。这一步就是用 `Counter`。

题目还提了一个不占额外空间的进阶做法（摩尔投票：不同的数两两抵消，最后剩下的就是过半的那个），哈希表这版更好写，先把这版吃透。

#### ③ 拿 `nums = [2,2,1,1,1,2,2]` 走一遍

`n = 7`，门槛是 `7 // 2 = 3`，也就是次数必须 **大于 3**。

| 数字 | 出现次数 | 是否 > 3 | 结论 |
|---|---|---|---|
| 2 | 4 | 4 > 3 成立 | 就是它 |
| 1 | 3 | 3 > 3 不成立 | 不是（刚好一半不算） |

所以答案是 2。注意 1 出现了 3 次，看起来很多，但"大于一半"是严格大于，3 次不够。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `cnt = Counter(nums)` | 一趟数完，每个数几次都在表里 |
| `for num, c in cnt.items():` | 一个数字一个数字检查 |
| `if c > len(nums) // 2:` | 次数是否严格超过一半 |
| `return num` | 是，就是答案 |
| `return -1` | 题目保证有答案，这行实际走不到，留着兜底 |

### 完整代码（Python）

```python
from typing import List
from collections import Counter

class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        cnt = Counter(nums)
        for num, c in cnt.items():
            if c > len(nums) // 2:
                return num
        return -1        # 题目保证存在多数元素，兜底
```

## 41-3. 快乐数（Easy）

> 力扣 202 · 哈希表 · Easy
> 前置：无

**一句话**：反复把 n 换成"各位数字的平方和"，能变成 1 就是快乐数，绕回老路就是不是。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`set`（集合）**

一句话：只存"有哪些"，不存"第几个"，而且自动去重；问"在不在"非常快。

生活类比：已经打卡过的名单。你报一个名字，一眼就知道他来没来过，但名单上没有第几号。

```python
seen = set()
seen.add(19)
seen.add(82)
seen.add(19)          # 重复加，不会变两份
print(sorted(seen))   # -> [19, 82]
print(82 in seen)     # -> True
print(len(seen))      # -> 2
```

它在这题里：把"走过的每个数"记下来。一旦新算出的数已经在 `seen` 里，说明进了循环，永远到不了 1。

**`%` 和 `//` 拆数字**

一句话：`n % 10` 取个位，`n // 10` 把个位扔掉；反复做就能一位一位拆完。

生活类比：从右往左一位一位掰手指，掰掉一位就把手缩回去一位。

```python
n = 19
print(n % 10)     # -> 9
print(n // 10)    # -> 1
print(1 % 10)     # -> 1
```

它在这题里：`square_sum` 里就是靠这两步把 19 拆成 1 和 9，再分别平方。

#### ② 大白话：这题到底在干什么

最笨的办法：一直往下算，算到 1 就返回真。问题是——**不是快乐数的那些数，永远算不到 1**，程序会转圈转到天荒地老。

笨在哪？没有"什么时候该停"的判断。

聪明办法：准备一张"我来过"的名单。每算出一个新数，先看它在不在名单上：不在就记下来继续算；在了就说明我绕回了走过的路，这条路永远到不了 1，直接返回假。因为每位平方和会迅速变小（比如 4 位数最多变成 4×81=324），所以这个循环很短，很快就会撞上重复。

#### ③ 拿 `n = 19` 走一遍

| 步 | 当前 n 的各位 | 平方和 | seen 里已记下 |
|---|---|---|---|
| 1 | 1 9 | 1 + 81 = 82 | {19} |
| 2 | 8 2 | 64 + 4 = 68 | {19, 82} |
| 3 | 6 8 | 36 + 64 = 100 | {19, 68, 82} |
| 4 | 1 0 0 | 1 + 0 + 0 = 1 | {19, 68, 82, 100} |

第 4 步算出 1，循环条件 `n != 1` 不成立，退出，返回真。所以答案是 `true`——19 是快乐数。

换成 `n = 2`：2 → 4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4，第 9 步算出的 4 早就在 `seen` 里了，返回假。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `seen = set()` | 准备一张"来过"的名单 |
| `while n != 1 and n not in seen:` | 还没到 1，而且这个数没来过，就继续 |
| `seen.add(n)` | 把当前数记进名单 |
| `n = self.square_sum(n)` | 换成各位平方和 |
| `return n == 1` | 停下来的原因只可能是"到 1"或"撞重复"，用这个判断 |
| `d = n % 10` | 取出个位 |
| `total += d * d` | 平方后累加 |
| `n //= 10` | 扔掉个位 |

### 完整代码（Python）

```python
class Solution:
    def isHappy(self, n: int) -> bool:
        seen = set()
        while n != 1 and n not in seen:
            seen.add(n)
            n = self.square_sum(n)
        return n == 1

    def square_sum(self, n: int) -> int:
        total = 0
        while n > 0:
            d = n % 10
            total += d * d
            n //= 10
        return total
```

## 41-4. 同构字符串（Easy）

> 力扣 205 · 哈希表 · Easy
> 前置：41-1（字典）

**一句话**：`s` 和 `t` 的字符能不能一一对应地互相替换。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`zip` 把两个字符串并排走**

一句话：`zip(s, t)` 一次吐出一对字符（`s` 的第 i 个和 `t` 的第 i 个），走到短的用完为止。

生活类比：两个人并排走路，每走一步，左右脚同时落地——`zip` 就是"同时取一对"。

```python
for a, b in zip("egg", "add"):
    print(a, b)
# -> e a
# -> g d
# -> g d
```

它在这题里：位置 i 的 `s[i]` 必须对上 `t[i]`，用 `zip` 就不用自己写下标。

**双向映射：两个字典对着记**

一句话：既要记"`s` 的字符映射到 `t` 的谁"，也要反过来记"`t` 的字符映射到 `s` 的谁"。只记一个方向会漏。

生活类比：婚姻登记。只登记"丈夫→妻子"不够，重婚就查不出来；两边都要登记，才能保证一对一。

```python
s2t, t2s = {}, {}
s2t['e'] = 'a'
t2s['a'] = 'e'
print(s2t)      # -> {'e': 'a'}
print(t2s)      # -> {'a': 'e'}
```

它在这题里：`f11` 对 `b23` 时，`1` 先映射到 `2`，后来又要求它映射到 `3`，第二个字典一查就露馅。

#### ② 大白话：这题到底在干什么

最笨的办法：对每个位置，把两个字符串的字符配成对，然后检查"同一个字符是不是一直配同一个对手"。听起来简单，但只查一个方向会出错：`s = "ab"`、`t = "aa"` 里，`a→a`、`b→a`，`s` 这边没矛盾，可 `t` 的 `a` 同时被 `a` 和 `b` 两个字符映射，这就不合法。

笨在哪？**"一对一"是两个方向都要管的事**，只盯一边必然漏。

聪明办法：开两本账。第一本记 `s→t`，第二本记 `t→s`。每来一对字符，两本账都翻一下：账上已经写过、而且写的不是对方，就返回假；否则两边都记上。全程只看一遍字符串。

#### ③ 拿 `s = "paper"`、`t = "title"` 走一遍

| 步 | s 的字符 | t 的字符 | s→t 这本账 | t→s 这本账 |
|---|---|---|---|---|
| 1 | p | t | {p: t} | {t: p} |
| 2 | a | i | {p: t, a: i} | {t: p, i: a} |
| 3 | p | t | 账上 p 本来就对 t，一致 | 不变 |
| 4 | e | l | {p: t, a: i, e: l} | {t: p, i: a, l: e} |
| 5 | r | e | {p: t, a: i, e: l, r: e} | {t: p, i: a, l: e, e: r} |

5 步全部一致，所以答案是 `true`。第 3 步是关键：`p` 第二次出现，必须还是对 `t`，对得上才继续。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `s2t, t2s = {}, {}` | 开两本空账 |
| `for a, b in zip(s, t):` | 一次取一对字符 |
| `if a in s2t and s2t[a] != b:` | s 这边以前记的不是它，矛盾 |
| `return False` | 直接判假 |
| `if b in t2s and t2s[b] != a:` | 反过来也查一遍 |
| `s2t[a] = b` / `t2s[b] = a` | 两本账都登记 |
| `return True` | 全程没矛盾 |

### 完整代码（Python）

```python
class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        s2t, t2s = {}, {}
        for a, b in zip(s, t):
            if a in s2t and s2t[a] != b:
                return False
            if b in t2s and t2s[b] != a:
                return False
            s2t[a] = b
            t2s[b] = a
        return True
```

## 41-5. 单词规律（Easy）

> 力扣 290 · 哈希表 · Easy
> 前置：41-4（双向映射）

**一句话**：`pattern` 的每个字母，要一一对应 `s` 里一个完整的单词。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`s.split()` 按空格切词**

一句话：不给参数时按"任意连续空白"切开，返回一个单词列表。

生活类比：把一串糖葫芦按竹签的节切开，每颗山楂单独放一格。

```python
print("dog cat cat dog".split())    # -> ['dog', 'cat', 'cat', 'dog']
print("a  b".split())               # -> ['a', 'b']
print("".split())                   # -> []
```

它在这题里：把 `"dog cat cat dog"` 变成 4 个单词，才能和 `pattern` 的 4 个字母对齐。

**`zip` + 双向映射**（前面 41-4 讲过）：一次取一对，两本账互相校验。

一句话回顾：`zip` 同时取一对，两个字典分别记 `字母→单词` 和 `单词→字母`，任何一边矛盾就判假。

它在这题里：和 41-4 一模一样的骨架，只是右边的"字符"换成了"单词"，而且**右边可能比左边多或少**，得先数个数。

#### ② 大白话：这题到底在干什么

最笨的办法：拿 `pattern` 的第一个字母，去 `s` 里数"这个字母出现在哪几个位置"，再检查那几个位置的单词是不是同一个。每个字母都这么做一遍，代码长、还容易漏。

笨在哪？它把"对应关系"当成"位置集合"来比，绕远了。

聪明办法：把 `pattern` 的字母和 `s` 的单词**按顺序并排**，一位一位看：字母 A 一直对着单词 X 吗？单词 X 一直对着字母 A 吗？两边都成立就合法。动手前先做一件小事：`pattern` 有几个字母，`s` 就必须有几个单词，个数不对直接假——这一条能挡掉一大半错误输入。

#### ③ 拿 `pattern = "abba"`、`s = "dog cat cat dog"` 走一遍

先切词：`["dog", "cat", "cat", "dog"]`，4 个词，`pattern` 也是 4 个字母，个数对得上。

| 步 | 字母 | 单词 | 字母→单词 | 单词→字母 |
|---|---|---|---|---|
| 1 | a | dog | {a: dog} | {dog: a} |
| 2 | b | cat | {a: dog, b: cat} | {dog: a, cat: b} |
| 3 | b | cat | 账上 b 本来就对 cat，一致 | 不变 |
| 4 | a | dog | 账上 a 本来就对 dog，一致 | 不变 |

4 步全过，所以答案是 `true`。

对比示例 3：`pattern = "aaaa"`、`s = "dog cat cat dog"`。第 2 步字母 `a` 账上记的是 `dog`，可这次配的是 `cat`，矛盾，返回假。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `words = s.split()` | 按空格切成单词表 |
| `if len(pattern) != len(words): return False` | 个数不一样，直接假 |
| `p2w, w2p = {}, {}` | 两本账 |
| `for a, b in zip(pattern, words):` | 一位一位并排看 |
| `if a in p2w and p2w[a] != b:` | 这个字母以前对的是别人 |
| `if b in w2p and w2p[b] != a:` | 这个单词以前对的是别的字母 |
| `p2w[a] = b` / `w2p[b] = a` | 两边登记 |
| `return True` | 全过 |

### 完整代码（Python）

```python
class Solution:
    def wordPattern(self, pattern: str, s: str) -> bool:
        words = s.split()
        if len(pattern) != len(words):
            return False
        p2w, w2p = {}, {}
        for a, b in zip(pattern, words):
            if a in p2w and p2w[a] != b:
                return False
            if b in w2p and w2p[b] != a:
                return False
            p2w[a] = b
            w2p[b] = a
        return True
```

## 41-6. 赎金信（Easy）

> 力扣 383 · 哈希表 · Easy
> 前置：41-2（Counter）

**一句话**：`magazine` 里的字母够不够拼出 `ransomNote`，每个字母只能用一次。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`all(...)` 和生成器表达式**

一句话：`all(一串判断)` 表示"这些判断是不是全都成立"；括号里那串可以用 `x > 0 for x in ...` 这种"边算边给"的写法，不用先造列表。

生活类比：老师收作业，挨个问"你交了吗"，只要有一个说没交，`all` 立刻返回"不齐"。

```python
print(all(x > 0 for x in [1, 2, 3]))     # -> True
print(all(x > 0 for x in [1, -2, 3]))    # -> False
print(all([]))                           # -> True
```

它在这题里：`all(have[ch] >= need[ch] for ch in need)` 就是"每个字母的库存都不少于需求"，一行说完。

**`Counter`**（前面 41-2 讲过）：专门数数的字典，`cnt[x]` 取不到时给 0 而不是报错。

一句话回顾：`Counter("aab")` 得到 `{'a': 2, 'b': 1}`，取没出现过的字符得 0。

它在这题里：`need` 数 `ransomNote` 要几个，`have` 数 `magazine` 有几个，两边一对比就知道够不够。

#### ② 大白话：这题到底在干什么

最笨的办法：拿 `ransomNote` 的第一个字母，去 `magazine` 里从头找一个，找到就划掉；再拿第二个字母，再从剩下的里找。找得到最后就返回真。

笨在哪？**每找一个字母都要把杂志重扫一遍**，两个串都长到 10 万时是百亿级操作，跑不动。

聪明办法：先各数一遍"每个字母有几个"，再逐字母比库存。`ransomNote` 要 2 个 `a`，杂志里只有 1 个，那就直接判假——不需要关心它们在杂志里的什么位置。

#### ③ 拿两个用例走一遍

| 用例 | 字母 | ransomNote 要几个 | magazine 有几个 | 够不够 |
|---|---|---|---|---|
| `"aa"` / `"aab"` | a | 2 | 2 | 够，2 ≥ 2 |
| `"aa"` / `"aab"` | b | 0 | 1 | 不用管 |
| `"aa"` / `"ab"` | a | 2 | 1 | 不够，1 < 2 → 返回假 |

所以第一个用例答案是 `true`，第二个是 `false`。注意 `"aab"` 里那个 `b` 帮不上忙——**只看需要的字母**。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `need = Counter(ransomNote)` | 数清楚"要什么、要几个" |
| `have = Counter(magazine)` | 数清楚"有什么、有几个" |
| `for ch in need:` | 只遍历需要的字母（多出来的库存不用看） |
| `have[ch]` | 这个字母的库存，没有就是 0 |
| `have[ch] >= need[ch]` | 库存 ≥ 需求 |
| `all(...)` | 全部满足才返回真 |

### 完整代码（Python）

```python
from collections import Counter

class Solution:
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:
        need = Counter(ransomNote)
        have = Counter(magazine)
        return all(have[ch] >= need[ch] for ch in need)
```

## 41-7. 分糖果（Easy）

> 力扣 575 · 哈希表 · Easy
> 前置：41-3（set）

**一句话**：只能吃一半的糖，最多能吃到几种。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`len(set(...))` 数"有几种"**（前面 41-3 讲过 set）：集合自动去重，长度就是"不同值的个数"。

一句话回顾：`set([1, 1, 2])` 是 `{1, 2}`，`len` 得 2，重复的 1 只算一种。

它在这题里：`len(set(candyType))` 就是"一共有几种糖"。

**`min(a, b)` 取小的那个**

一句话：`min` 把几个数里最小的给你；这里用来"两条限制里只能听更严的那条"。

生活类比：妈妈说最多吃 3 颗，医生说最多吃 2 颗，实际只能吃 2 颗——取更小的那个上限。

```python
print(min(3, 5))          # -> 3
print(min([4, 2, 9]))     # -> 2
print(min(3, 3))          # -> 3
```

它在这题里：`min(种类数, n // 2)`——种类再多，也只能吃 `n // 2` 颗。

#### ② 大白话：这题到底在干什么

最笨的办法：把所有吃法列出来，每种数一下有几种，取最大。糖一多，吃法的数量就爆炸了。

笨在哪？**答案其实被两个数卡死了**，根本不用枚举。

聪明办法：问自己两个问题。第一，我最多能吃几颗？`n // 2` 颗。第二，一共有几种糖？假设 `k` 种。那我最多也只能吃到 `k` 种，因为我每种只拿一颗的话，拿 `k` 颗就没了。所以答案是这两个上限里更小的那个。

举个例子：`[1,1,2,3]` 有 3 种糖，但只能吃 2 颗，所以最多 2 种。反过来 `[1,1,2,2,3,3]` 只能吃 3 颗，正好 3 种各拿一颗，所以是 3 种。

#### ③ 拿 `candyType = [1,1,2,2,3,3]` 走一遍

| 步 | 拿到的糖 | 已有种类 | 种类数 |
|---|---|---|---|
| 1 | 1 | {1} | 1 |
| 2 | 1 | {1} | 1 |
| 3 | 2 | {1, 2} | 2 |
| 4 | 2 | {1, 2} | 2 |
| 5 | 3 | {1, 2, 3} | 3 |
| 6 | 3 | {1, 2, 3} | 3 |

走完得到种类数 3，能吃 `6 // 2 = 3` 颗，`min(3, 3) = 3`。所以答案是 3。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `set(candyType)` | 去重，重复的糖只剩一个 |
| `len(...)` | 数一数剩几个，就是种类数 |
| `len(candyType) // 2` | 医生允许吃几颗 |
| `min(kinds, ...)` | 两条限制取更严的那条 |
| `return ...` | 就是答案 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def distributeCandies(self, candyType: List[int]) -> int:
        kinds = len(set(candyType))          # 一共有几种糖
        return min(kinds, len(candyType) // 2)   # 和"只能吃一半"取更小的
```

## 41-8. 数组的度（Easy）

> 力扣 697 · 哈希表 · Easy
> 前置：41-1（字典）

**一句话**：数组的"度"是出现次数最多的那个次数；求包含全部这些元素的**最短**连续片段长度。

### 精讲（零基础版）

#### ① 这题要用到的东西

**字典的 value 存一个列表**

一句话：字典的值不一定是单个数字，也可以是一整个列表，这样"一个键"就能同时挂好几条信息。

生活类比：档案袋。每个名字一个袋子，袋子里装着"来过几次、第一次哪天、最后一次哪天"三张纸。

```python
info = {}
info['a'] = [1, 0, 0]      # [次数, 首次下标, 末次下标]
info['a'][0] += 1
info['a'][2] = 5
print(info)                # -> {'a': [2, 0, 5]}
print(info['a'][1])        # -> 0
```

它在这题里：每个数字挂 `[出现次数, 第一次下标, 最后一次下标]`，后面两个信息正好算"跨度"。

**`enumerate` 同时拿下标和值**

一句话：`for i, v in enumerate(nums)` 一边走一边给你"第几个"和"是什么"。

生活类比：点名单。念到第 3 个同学时，你知道"序号 3"和"他叫什么"，不用自己数。

```python
for i, v in enumerate("abc"):
    print(i, v)
# -> 0 a
# -> 1 b
# -> 2 c
```

它在这题里：要记"第一次出现在第几位"，就必须同时有下标和值。

#### ② 大白话：这题到底在干什么

最笨的办法：先数出数组的度，然后把所有子数组都试一遍，看哪个子数组的度也等于这个数，取最短的。子数组有 n² 个，n 是 5 万时直接超时。

笨在哪？**"包含某个数字的所有出现"这件事，只取决于这个数字的第一次和最后一次出现**，和中间试哪个子数组无关。

聪明办法：对每个数字记三件事——出现几次、第一次在哪、最后一次在哪。度数 = 最大的那个次数；然后在所有"次数等于度数"的数字里，算它们的 `末次 - 首次 + 1`，取最小的那个。因为要包含这个数字的全部出现，片段就必须从它的第一次拉到它的最后一次，再短就会漏。

#### ③ 拿 `nums = [1,2,2,3,1]` 走一遍

| 数字 | 次数 | 第一次下标 | 最后一次下标 | 跨度 = 末 - 首 + 1 |
|---|---|---|---|---|
| 1 | 2 | 0 | 4 | 5 |
| 2 | 2 | 1 | 2 | 2 |
| 3 | 1 | 3 | 3 | 1 |

最大次数是 2，所以度是 2。次数等于 2 的数字有 1 和 2，跨度分别是 5 和 2，取小的 2。所以答案是 2（片段是 `[2,2]`）。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `info = {}` | 准备档案柜 |
| `if v in info:` | 这个数字以前来过 |
| `info[v][0] += 1` | 次数加一 |
| `info[v][2] = i` | 最后一次出现的下标更新成现在 |
| `info[v] = [1, i, i]` | 第一次见：次数 1，首尾都是现在 |
| `degree = max(c for c, _, _ in info.values())` | 所有次数里最大的就是度 |
| `if c == degree:` | 只看达到度的数字 |
| `ans = min(ans, last - first + 1)` | 跨度取最小 |
| `return ans` | 答案 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def findShortestSubArray(self, nums: List[int]) -> int:
        info = {}                      # 数字 -> [次数, 首次下标, 末次下标]
        for i, v in enumerate(nums):
            if v in info:
                info[v][0] += 1
                info[v][2] = i
            else:
                info[v] = [1, i, i]
        degree = max(c for c, _, _ in info.values())
        ans = len(nums)
        for c, first, last in info.values():
            if c == degree:
                ans = min(ans, last - first + 1)
        return ans
```

## 41-9. 亲密字符串（Easy）

> 力扣 859 · 哈希表 · Easy
> 前置：41-4（双向映射）

**一句话**：能不能只交换 `s` 里的两个字符，就让它变成 `goal`。

### 精讲（零基础版）

#### ① 这题要用到的东西

**列表推导式 + `if` 过滤**

一句话：`[表达式 for 变量 in 序列 if 条件]` 一步"边筛边造"出一个新列表，比写 for 循环再 append 短。

生活类比：从一筐苹果里挑出有虫眼的，装进另一个筐——挑的动作和装的动作合成一步。

```python
pairs = [(a, b) for a, b in zip("abcd", "badc") if a != b]
print(pairs)      # -> [('a', 'b'), ('b', 'a'), ('c', 'd'), ('d', 'c')]
print(len(pairs)) # -> 4
```

它在这题里：一句话就收集到"所有对不上的位置"，长度就是需要改的位置个数。

**切片反转 `[::-1]`**

一句话：`[::-1]` 表示"从尾到头，每次走一步"，得到倒过来的副本。

生活类比：把一叠牌整个翻个面，第一张变最后一张。

```python
print("ba"[::-1])          # -> ab
print([1, 2, 3][::-1])     # -> [3, 2, 1]
print(('a', 'b')[::-1])    # -> ('b', 'a')
```

它在这题里：`diffs[0] == diffs[1][::-1]` 用来检查两个错位是不是正好互相颠倒。

#### ② 大白话：这题到底在干什么

最笨的办法：把 `s` 的每一对位置都试一遍交换，看换完等不等于 `goal`。位置对有 n² 个，n 是 2 万时是 4 亿次，太慢。

笨在哪？**交换的效果可以先看"哪几个位置对不上"，不用真的动手换**。

聪明办法：分两种情况。
第一种，`s` 和 `goal` 本来就一样：那必须能"换两个相同的字符"才不影响结果，也就是 `s` 里得有一个字符出现两次以上。
第二种，本来就不一样：把所有对不上的位置收集起来。一次交换只能改两个位置，所以对不上的必须**正好 2 个**，而且这两个位置的内容得正好互换（`s` 的 `a` 对上 `goal` 的 `b`，`s` 的 `b` 对上 `goal` 的 `a`）。

#### ③ 拿四个输入走一遍

| s | goal | 判定依据 | 结果 |
|---|---|---|---|
| `"ab"` | `"ba"` | 对不上 2 个位置，且内容正好互换 | 真 |
| `"ab"` | `"ab"` | 完全相同，但没有重复字符可换 | 假 |
| `"aa"` | `"aa"` | 完全相同，`a` 有重复，换两个 `a` 还是 `aa` | 真 |
| `"abcd"` | `"badc"` | 对不上 4 个位置，一次交换只改 2 个 | 假 |

所以答案依次是真、假、真、假。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `if len(s) != len(goal): return False` | 长度不同，换不出来 |
| `if s == goal:` | 本来就一样，走另一条路 |
| `return len(set(s)) < len(s)` | 有重复字符才能"换了个寂寞" |
| `diffs = [...]` | 收集所有对不上的位置 |
| `if a != b` | 只留对不上的 |
| `len(diffs) == 2` | 一次交换只能修 2 个位置 |
| `diffs[0] == diffs[1][::-1]` | 两个错位正好互相颠倒 |

### 完整代码（Python）

```python
class Solution:
    def buddyStrings(self, s: str, goal: str) -> bool:
        if len(s) != len(goal):
            return False
        if s == goal:
            return len(set(s)) < len(s)     # 有重复字符才能白换一次
        diffs = [(a, b) for a, b in zip(s, goal) if a != b]
        return len(diffs) == 2 and diffs[0] == diffs[1][::-1]
```

## 41-10. 数组的相对排序（Easy）

> 力扣 1122 · 哈希表 · Easy
> 前置：41-1（字典）

**一句话**：`arr1` 按 `arr2` 给的顺序排，`arr2` 里没出现的数按升序接在末尾。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`sorted(key=...)` 自定义排序依据**

一句话：`sorted` 默认比大小，给了 `key` 之后就按"key 算出来的东西"比，原元素只是被搬来搬去。

生活类比：排队时按"身高"排，而不是按名字排——每个人还是那个人，只是比较时看身高。

```python
words = ["ccc", "a", "bb"]
print(sorted(words, key=len))              # -> ['a', 'bb', 'ccc']
nums = [3, 1, 2]
print(sorted(nums, key=lambda x: -x))      # -> [3, 2, 1]
```

它在这题里：`key` 算出"这个数在 `arr2` 里排第几"，按这个排名排。

**字典推导式 `{v: i for i, v in enumerate(arr2)}`**

一句话：一边遍历一边把"值 → 下标"直接造成字典，比先建空字典再循环赋值短。

生活类比：给一队人发号码牌，念到谁就把号码记在他名字后面，一轮发完。

```python
rank = {v: i for i, v in enumerate(["a", "b", "c"])}
print(rank)          # -> {'a': 0, 'b': 1, 'c': 2}
print(rank['b'])     # -> 1
```

它在这题里：`rank[2] = 0`、`rank[1] = 1`……一眼看出每个数该排在哪。

**`dict.get(x, 默认值)`**（前面 41-1 讲过）：键不在时返回默认值，不报错。

一句话回顾：`rank.get(7, 6)` 在 `7` 不在字典里时返回 6。

它在这题里：`arr2` 里没有的数统一给一个"排在最后"的假排名。

#### ② 大白话：这题到底在干什么

最笨的办法：照 `arr2` 的顺序，把 `arr1` 里等于 `arr2[0]` 的挑出来、再挑等于 `arr2[1]` 的……最后把剩下的排序接上去。要做很多次扫描。

笨在哪？**每个元素被翻来覆去地找了很多遍**，而它该排第几其实一次就能确定。

聪明办法：先做一张"排名表"，记下 `arr2` 里每个数排第几。然后给 `arr1` 的每个数算一个排序键：在表里的用它的排名，不在表里的统一用一个比所有排名都大的数（这样自然排到最后）。最后按排序键排一遍。排序键相同的（也就是都不在 `arr2` 里的），再按数值本身升序，这就是排序键写成 `(排名, 数值)` 元组的原因。

#### ③ 拿示例 1 走一遍

`arr2 = [2,1,4,3,9,6]`，长度 6，所以"不在表里"的假排名取 6。

| 值 | 排名 | 排序键 (排名, 值) | 在 arr1 出现次数 |
|---|---|---|---|
| 1 | 1 | (1, 1) | 1 |
| 2 | 0 | (0, 2) | 3 |
| 3 | 3 | (3, 3) | 2 |
| 4 | 2 | (2, 4) | 1 |
| 6 | 5 | (5, 6) | 1 |
| 7 | 不在 → 用 6 | (6, 7) | 1 |
| 9 | 4 | (4, 9) | 1 |
| 19 | 不在 → 用 6 | (6, 19) | 1 |

按排序键从小到大排：`(0,2)` 三次 → `(1,1)` → `(2,4)` → `(3,3)` 两次 → `(4,9)` → `(5,6)` → 然后是 `(6,7)`、`(6,19)` 按数值升序。

所以答案是 `[2,2,2,1,4,3,3,9,6,7,19]`，和题面示例一致。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `rank = {v: i for i, v in enumerate(arr2)}` | 做排名表 |
| `big = len(arr2)` | 一个比所有排名都大的数 |
| `rank.get(x, big)` | 在表里用真排名，不在表里排最后 |
| `(rank.get(x, big), x)` | 先按排名，排名相同再按数值 |
| `sorted(arr1, key=...)` | 按这个键排一遍 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def relativeSortArray(self, arr1: List[int], arr2: List[int]) -> List[int]:
        rank = {v: i for i, v in enumerate(arr2)}   # 值 -> 该排第几
        big = len(arr2)                             # 不在表里的统一排最后
        return sorted(arr1, key=lambda x: (rank.get(x, big), x))
```

## 41-11. 有多少小于当前数字的数字（Easy）

> 力扣 1365 · 哈希表 · Easy
> 前置：41-8（enumerate）、41-10（排序）

**一句话**：对每个数，数一数数组里有几个数比它小。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`sorted()` 排完序，"第一次出现的下标"就是答案**

一句话：把数组从小到大排好，一个数排在第几位（从 0 数），前面就有几个数比它小。同一个值只记第一次出现的位置。

生活类比：全班按身高站成一排，你站在第 5 个位置，那你前面就有 4 个人比你矮——不用一个个去比。

```python
ordered = sorted([8, 1, 2, 2, 3])
print(ordered)              # -> [1, 2, 2, 3, 8]
first_pos = {}
for i, v in enumerate(ordered):
    if v not in first_pos:
        first_pos[v] = i
print(first_pos)            # -> {1: 0, 2: 1, 3: 3, 8: 4}
```

它在这题里：`first_pos[8] = 4` 就是"有 4 个数比 8 小"，`first_pos[2] = 1` 就是"只有 1 个数比 2 小"。

**`enumerate`**（前面 41-8 讲过）：同时给下标和值。

一句话回顾：`for i, v in enumerate(序列)` 里 `i` 是位置、`v` 是内容。

**列表推导式**（前面 41-9 讲过）：`[f(v) for v in 序列]` 一步造出新列表。

一句话回顾：`[first_pos[v] for v in nums]` 把每个数换成它对应的答案。

#### ② 大白话：这题到底在干什么

最笨的办法：对每个数，把整个数组再扫一遍，数有多少个比它小。n 个数扫 n 遍，n 到 500 也才 25 万次，勉强能过，但方法很笨。

笨在哪？**"有几个比它小"这个信息，排一次序就全有了**，不需要为每个数重新数。

聪明办法：先排序。排完之后，一个数的"名次"就是"比它小的个数"。同一个值会出现多次，它们的名次相同，所以只记第一次出现的位置。最后拿原数组的顺序，逐个去表里查答案。

#### ③ 拿 `nums = [8,1,2,2,3]` 走一遍

排序后是 `[1, 2, 2, 3, 8]`。

| 排序后下标 i | 值 | 是否第一次见 | first_pos |
|---|---|---|---|
| 0 | 1 | 是 | {1: 0} |
| 1 | 2 | 是 | {1: 0, 2: 1} |
| 2 | 2 | 否，跳过 | 不变 |
| 3 | 3 | 是 | {1: 0, 2: 1, 3: 3} |
| 4 | 8 | 是 | {1: 0, 2: 1, 3: 3, 8: 4} |

再按原数组 `[8,1,2,2,3]` 查表：4、0、1、1、3。所以答案是 `[4,0,1,1,3]`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `ordered = sorted(nums)` | 从小到大排好 |
| `first_pos = {}` | 准备记"每个值第一次排第几" |
| `for i, v in enumerate(ordered):` | 边走边拿位置和值 |
| `if v not in first_pos:` | 只记第一次 |
| `first_pos[v] = i` | 记下它的名次 |
| `[first_pos[v] for v in nums]` | 按原顺序查答案 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def smallerNumbersThanCurrent(self, nums: List[int]) -> List[int]:
        ordered = sorted(nums)
        first_pos = {}
        for i, v in enumerate(ordered):
            if v not in first_pos:      # 同一个值只记第一次
                first_pos[v] = i
        return [first_pos[v] for v in nums]
```

## 41-12. 两个相同字符之间的最长子字符串（Easy）

> 力扣 1624 · 哈希表 · Easy
> 前置：41-11（记录首次出现位置）

**一句话**：找一对相同字符，让它们中间夹的字符尽量多。

### 精讲（零基础版）

#### ① 这题要用到的东西

**只记"第一次出现的位置"**（前面 41-11 讲过）：同一个字符出现多次时，想让中间夹得最长，左端点当然越靠左越好。

一句话回顾：`if ch not in first: first[ch] = i`，后面的重复出现都不覆盖它。

它在这题里：每个字符只记最左边那次，右边的重复出现算长度时才能最大。

**`ans` 打擂台 + `max`**

一句话：先给 `ans` 一个"最差"的初值，每算出一个候选就 `ans = max(ans, 候选)`，最后 `ans` 就是最好的那个。

生活类比：跳高比赛。横杆记录不断被更高的成绩刷新，最后留下的就是冠军成绩。

```python
ans = -1
for x in [2, 0, 5, 1]:
    ans = max(ans, x)
    print(ans)
# -> 2
# -> 2
# -> 5
# -> 5
```

它在这题里：`ans` 初值取 -1，因为题目说"不存在就返回 -1"，正好省掉特判。

#### ② 大白话：这题到底在干什么

最笨的办法：把所有字符对 `(i, j)` 都试一遍，`s[i] == s[j]` 就更新答案。位置对有 n² 个，n 是 300 时是 9 万，能过但没必要。

笨在哪？**对每个字符，最长的夹法一定是"第一次出现"和"最后一次出现"之间**，中间的配对都是白试。

聪明办法：从左往右走一遍，每个字符只记它第一次出现的位置。以后再遇到同一个字符，就用"当前位置 - 第一次位置 - 1"算出夹了多少个字符，拿去刷新答案。全程只走一遍。

#### ③ 拿 `s = "abca"` 走一遍

| i | 字符 | 判定 | 候选长度 | ans |
|---|---|---|---|---|
| 0 | a | 第一次见，记 0 | 无 | -1 |
| 1 | b | 第一次见，记 1 | 无 | -1 |
| 2 | c | 第一次见，记 2 | 无 | -1 |
| 3 | a | 见过，第一次在 0 | 3 - 0 - 1 = 2 | 2 |

所以答案是 2（夹的是 `"bc"`）。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `first = {}` | 记"每个字符第一次出现在哪" |
| `ans = -1` | 最差情况就是 -1，正好当初值 |
| `for i, ch in enumerate(s):` | 从左到右走 |
| `if ch in first:` | 这个字符以前来过 |
| `i - first[ch] - 1` | 中间夹了几个字符 |
| `ans = max(ans, ...)` | 刷新最好成绩 |
| `else: first[ch] = i` | 第一次来，记下位置 |

### 完整代码（Python）

```python
class Solution:
    def maxLengthBetweenEqualCharacters(self, s: str) -> int:
        first = {}
        ans = -1
        for i, ch in enumerate(s):
            if ch in first:
                ans = max(ans, i - first[ch] - 1)
            else:
                first[ch] = i
        return ans
```

## 41-13. 按照频率将数组升序排序（Easy）

> 力扣 1636 · 哈希表 · Easy
> 前置：41-10（多关键字排序）、41-2（Counter）

**一句话**：出现次数少的排前面；次数一样的，数值大的排前面。

### 精讲（零基础版）

#### ① 这题要用到的东西

**排序键里"查表"**（前面 41-10 讲过 `rank.get(x)`）：`key` 不一定要用元素本身，也可以拿元素去字典里查一个数出来当比较依据。

一句话回顾：`key=lambda x: rank[x]` 就是"按查到的排名排"，这里把排名换成"出现次数"。

它在这题里：`cnt[x]` 给出每个数出现了几次，正好当第一关键字。

**元组当排序键**（前面 41-10 讲过）：`(a, b)` 先比 a，a 相同再比 b。

一句话回顾：`sorted(key=lambda x: (cnt[x], -x))` 先按次数升序，次数相同按数值降序。

**`-x` 把升序变降序**

一句话：排序永远是从小到大，想从大到小就比相反数——数越大，相反数越小。

生活类比：比谁欠钱多。把"欠款"换成"存款负数"，谁欠得多谁的数更小，排前面正好是欠得多的。

```python
nums = [1, 2, 3]
print(sorted(nums))                     # -> [1, 2, 3]
print(sorted(nums, key=lambda x: -x))   # -> [3, 2, 1]
print(sorted(nums, reverse=True))       # -> [3, 2, 1]
```

它在这题里：`-x` 让"频率相同"的那一组按数值从大到小排。

#### ② 大白话：这题到底在干什么

最笨的办法：先数每个数的频率，再手写一个冒泡排序，比较两个数时先比频率、频率一样比大小。能过，但要自己写排序。

笨在哪？**"怎么比"和"怎么排"是两件事**，Python 已经把"怎么排"做好了，你只要告诉它"怎么比"。

聪明办法：数好频率，然后直接调用 `sorted`，把"先频率后数值"这个比较规则写进 `key`。注意要排的是**原数组**（里面有重复元素），不是"不同的值"——因为结果里每个值都要按它的频率重复出现。

#### ③ 拿 `nums = [2,3,1,3,2]` 走一遍

| 值 | 频率 | 排序键 (频率, -值) |
|---|---|---|
| 1 | 1 | (1, -1) |
| 2 | 2 | (2, -2) |
| 3 | 2 | (2, -3) |

排序键从小到大：`(1,-1)` 最前，然后 `(2,-3)` 比 `(2,-2)` 小（-3 < -2），所以 3 排在 2 前面。

所以答案是 `[1, 3, 3, 2, 2]`，和题面示例一致。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `cnt = Counter(nums)` | 数出每个数的频率 |
| `sorted(nums, ...)` | 排原数组，不是排"不同的值" |
| `key=lambda x: (cnt[x], -x)` | 先按频率升序，再按数值降序 |
| `(cnt[x], -x)` | 元组，前一个一样才看后一个 |

### 完整代码（Python）

```python
from typing import List
from collections import Counter

class Solution:
    def frequencySort(self, nums: List[int]) -> List[int]:
        cnt = Counter(nums)
        return sorted(nums, key=lambda x: (cnt[x], -x))
```

## 41-14. 整数转罗马数字（Medium）

> 力扣 12 · 哈希表 · Medium
> 前置：41-1（罗马数字规则）

**一句话**：把整数按"从大到小能减就减"的规则，翻译成罗马数字。

### 精讲（零基础版）

#### ① 这题要用到的东西

**列表里放元组：`[(1000, "M"), (900, "CM"), ...]`**

一句话：一个列表，每个元素是一对"数值 + 符号"，按数值从大到小排好，就是一个"面值表"。

生活类比：收银台的钱箱，从 100 元、50 元、20 元……一格格排好，找零时从大面额开始拿。

```python
table = [(1000, "M"), (900, "CM"), (500, "D")]
for val, sym in table:
    print(val, sym)
# -> 1000 M
# -> 900 CM
# -> 500 D
```

它在这题里：13 个"面值"按从大到小排成一张表，包括 `900=CM`、`4=IV` 这些减法的特例，这样后面就不用写 if 判断了。

**贪心：每次都拿"能拿的最大面值"**

一句话：贪心就是"每一步都选眼前最好的那个"，在这题里恰好能得到正确答案。

生活类比：找零 37 元，先拿最大面额 20，剩 17；再拿 10，剩 7；再拿 5，剩 2；再拿两个 1。每一步都拿不超过剩余金额的最大面额。

```python
num = 37
for val in [20, 10, 5, 1]:
    while num >= val:
        num -= val
        print("拿", val, "剩", num)
# -> 拿 20 剩 17
# -> 拿 10 剩 7
# -> 拿 5 剩 2
# -> 拿 1 剩 1
# -> 拿 1 剩 0
```

它在这题里：`while num >= val` 反复扣，直到这个面值用不上为止。

#### ② 大白话：这题到底在干什么

最笨的办法：按个位、十位、百位、千位分别判断，写一堆 `if`：个位是 4 就 `IV`、是 9 就 `IX`、是 5 就 `V`……四个位各一套，代码又长又容易错。

笨在哪？**每个位置上的规则其实长得一模一样**，只是符号不同，写成四套就是重复劳动。

聪明办法：把 13 个"面值"从大到小排成一张表：1000、900、500、400、100、90、50、40、10、9、5、4、1。然后从表头开始，能扣就扣、扣一次就在结果里拼一个对应符号，扣到扣不动就换下一个面值。因为表里已经包含了 `900=CM` 这种减法特例，所以不需要任何 if。

#### ③ 拿 `num = 1994` 走一遍

| 步 | 命中 | 扣之前 | 扣之后 | 已拼出 |
|---|---|---|---|---|
| 1 | 1000 → M | 1994 | 994 | M |
| 2 | 900 → CM | 994 | 94 | MCM |
| 3 | 90 → XC | 94 | 4 | MCMXC |
| 4 | 4 → IV | 4 | 0 | MCMXCIV |

剩下的面值都大于 0，`while` 一次都不进。所以答案是 `"MCMXCIV"`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `table = [(1000, "M"), ...]` | 13 个面值从大到小排好 |
| `out = []` | 结果先攒在列表里 |
| `for val, sym in table:` | 从大面值开始试 |
| `while num >= val:` | 这个面值还用得上 |
| `out.append(sym)` | 拼一个符号 |
| `num -= val` | 把面值扣掉 |
| `"".join(out)` | 拼成一整串 |

### 完整代码（Python）

```python
class Solution:
    def intToRoman(self, num: int) -> str:
        table = [
            (1000, "M"), (900, "CM"), (500, "D"), (400, "CD"),
            (100, "C"), (90, "XC"), (50, "L"), (40, "XL"),
            (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I"),
        ]
        out = []
        for val, sym in table:
            while num >= val:      # 这个面值能扣就一直扣
                out.append(sym)
                num -= val
        return "".join(out)
```

## 41-15. 有效的数独（Medium）

> 力扣 36 · 哈希表 · Medium
> 前置：41-3（set）

**一句话**：检查 9×9 的盘面上，每行、每列、每个 3×3 宫里有没有重复的数字。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`[set() for _ in range(9)]` 造 9 个互不相干的集合**

一句话：列表推导式会给每个位置**新建**一个集合；而 `[set()] * 9` 是同一个集合复制 9 次，改一个全变。

生活类比：发 9 个新本子（各写各的）和"复印同一个本子 9 份"（一笔写下去 9 本一起变），区别很大。

```python
sets = [set() for _ in range(3)]
sets[0].add(1)
print(sets)                # -> [{1}, set(), set()]
bad = [set()] * 3
bad[0].add(1)
print(bad)                 # -> [{1}, {1}, {1}]
```

它在这题里：9 行、9 列、9 宫各要一个独立的集合来记"这一组里出现过哪些数字"。

**宫号公式 `(r // 3) * 3 + c // 3`**

一句话：把 9 个 3×3 宫从 0 到 8 编号：先看在第几条"宫带"（`r // 3`），再看在这带里第几列（`c // 3`）。

生活类比：一栋楼分 3 层，每层 3 户。房号 = 层号 × 3 + 户号。

```python
for r, c in [(0, 0), (1, 1), (4, 4), (8, 8)]:
    print(r, c, (r // 3) * 3 + c // 3)
# -> 0 0 0
# -> 1 1 0
# -> 4 4 4
# -> 8 8 8
```

它在这题里：`(0,0)` 和 `(1,1)` 落在同一个宫 0，所以它们的数字不能重复。

#### ② 大白话：这题到底在干什么

最笨的办法：把 9 行分别检查一遍有没有重复，9 列检查一遍，9 个宫再检查一遍。每个检查都要两两比对，代码要写三套，还容易把宫的下标写错。

笨在哪？**三种检查本质是同一件事**：往一个集合里放数字，放之前看看在不在。不同的只是"往哪个集合里放"。

聪明办法：一次遍历盘面，每个格子同时往三个集合里放：第 r 行的集合、第 c 列的集合、第 b 宫的集合。只要有任何一次"放不进去（已经存在）"，立刻返回假。遍历完都没撞，返回真。空位 `.` 直接跳过。

#### ③ 拿示例 1 的前几格走一遍

| 格子 | 数字 | 宫号 | 检查结果 |
|---|---|---|---|
| (0,0) | 5 | 0 | 三个集合都没有 → 记下 |
| (0,1) | 3 | 0 | 三个集合都没有 → 记下 |
| (0,4) | 7 | 1 | 三个集合都没有 → 记下 |
| (1,0) | 6 | 0 | 行 1、列 0、宫 0 都没有 → 记下 |
| (1,3) | 1 | 1 | 都没有 → 记下 |
| (1,4) | 9 | 1 | 都没有 → 记下 |
| (1,5) | 5 | 1 | 行 1 没有、列 5 没有、宫 1 没有 → 记下 |
| (2,1) | 9 | 0 | 行 2 没有、列 1 没有、宫 0 没有 → 记下 |
| (2,2) | 8 | 0 | 都没有 → 记下 |

整盘走完没有撞，所以示例 1 的答案是 `true`。示例 2 把 `(0,0)` 的 5 改成 8：走到 `(2,2)` 时，宫 0 里已经有 8 了，撞上，返回假。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `rows = [set() for _ in range(9)]` | 9 个独立集合记每行 |
| `cols` / `boxes` | 列和宫同理 |
| `if v == '.': continue` | 空位不参与检查 |
| `b = (r // 3) * 3 + c // 3` | 算出这个格子属于哪个宫 |
| `if v in rows[r] or v in cols[c] or v in boxes[b]:` | 三个集合里有一个已经存在 |
| `return False` | 撞了，判假 |
| `rows[r].add(v)` 等三行 | 三个集合都记上 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        rows = [set() for _ in range(9)]
        cols = [set() for _ in range(9)]
        boxes = [set() for _ in range(9)]
        for r in range(9):
            for c in range(9):
                v = board[r][c]
                if v == '.':
                    continue
                b = (r // 3) * 3 + c // 3      # 宫号 0~8
                if v in rows[r] or v in cols[c] or v in boxes[b]:
                    return False
                rows[r].add(v)
                cols[c].add(v)
                boxes[b].add(v)
        return True
```

## 41-16. 矩阵置零（Medium）

> 力扣 73 · 哈希表 · Medium
> 前置：41-3（set）

**一句话**：矩阵里凡是 0，就把它所在的行和列整条清零，而且要在原矩阵上改。

### 精讲（零基础版）

#### ① 这题要用到的东西

**原地修改（in-place）**

一句话：函数不返回新矩阵，而是直接改你传进来的那个矩阵。因为列表是"按引用传递"的，函数里改，外面看得见。

生活类比：不是把文件另存一份再改副本，而是直接在原件上涂改。

```python
def fill_first(m):
    m[0][0] = 99        # 直接改传进来的列表

grid = [[1, 2], [3, 4]]
fill_first(grid)
print(grid)             # -> [[99, 2], [3, 4]]
```

它在这题里：题目要求原地改，所以最后没有 `return`，改完调用者的矩阵就变了。

**`any(...)`**

一句话：`any(一串判断)` 表示"这些判断里有没有一个成立"；和 `all` 正好相反。

生活类比：安检门。只要有一个包报警，`any` 就说"有情况"。

```python
print(any(x > 0 for x in [1, -2, 3]))   # -> True
print(any(x > 0 for x in [-1, -2]))     # -> False
print(any([]))                          # -> False
```

它在这题里：`any(matrix[0][j] == 0 for j in range(n))` 一句话问出"第一行有没有 0"。

#### ② 大白话：这题到底在干什么

最笨的办法：先复制一份矩阵当"备忘录"，然后扫原矩阵，遇到 0 就把备忘录里对应的整行、整列改成 0。最后把备忘录拷回去。要多开一整个矩阵。

笨在哪？**备忘录太大了**。其实"第几行要清、第几列要清"只需要两排小记号，不需要一整张表。

聪明办法：直接拿矩阵的**第一行和第一列当记号板**。扫内部（第 1 行到第 m-1 行、第 1 列到第 n-1 列），遇到 0 就在 `matrix[i][0]` 和 `matrix[0][j]` 上打记号。然后再扫一遍内部，谁的行记号或列记号是 0，谁就清零。

有个坑：第一行和第一列自己既是"数据"又是"记号板"，所以要先单独记住"第一行本来有没有 0、第一列本来有没有 0"，等内部处理完了再补上。

#### ③ 拿示例 2 走一遍

`matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]`

| 阶段 | 矩阵变成 | 说明 |
|---|---|---|
| 初始 | `[[0,1,2,0],[3,4,5,2],[1,3,1,5]]` | 第一行有 0，第一列也有 0 |
| 打标记 | `[[0,1,2,0],[3,4,5,2],[1,3,1,5]]` | 内部没有 0，所以记号位不变 |
| 按标记清零 | `[[0,1,2,0],[3,4,5,0],[1,3,1,0]]` | 第 3 列有记号，内部各行的第 3 格清零 |
| 补第一行/列 | `[[0,0,0,0],[0,4,5,0],[0,3,1,0]]` | 第一行、第一列整体清零 |

所以答案是 `[[0,0,0,0],[0,4,5,0],[0,3,1,0]]`，和题面一致。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `first_row_zero = any(...)` | 先记住第一行原本有没有 0 |
| `first_col_zero = any(...)` | 第一列同理 |
| `for i in range(1, m)` | 只看内部，别碰记号板 |
| `matrix[i][0] = 0` | 在这一行的行首打记号 |
| `matrix[0][j] = 0` | 在这一列的列首打记号 |
| `if matrix[i][0] == 0 or matrix[0][j] == 0:` | 行或列任一有记号 |
| `matrix[i][j] = 0` | 清掉这一格 |
| `if first_row_zero:` | 最后补第一行 |
| `if first_col_zero:` | 最后补第一列 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        m, n = len(matrix), len(matrix[0])
        first_row_zero = any(matrix[0][j] == 0 for j in range(n))
        first_col_zero = any(matrix[i][0] == 0 for i in range(m))

        for i in range(1, m):                 # 用第一行/第一列当记号板
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0
                    matrix[0][j] = 0

        for i in range(1, m):                 # 按记号清零内部
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0

        if first_row_zero:                    # 最后补第一行
            for j in range(n):
                matrix[0][j] = 0
        if first_col_zero:                    # 最后补第一列
            for i in range(m):
                matrix[i][0] = 0
```

## 41-17. 分数到小数（Medium）

> 力扣 166 · 哈希表 · Medium
> 前置：41-12（记录首次出现位置）

**一句话**：把分数写成小数，循环的部分用括号括起来。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`divmod(a, b)` 一次拿到商和余数**

一句话：`divmod(7, 2)` 给你 `(3, 1)`，相当于同时算 `7 // 2` 和 `7 % 2`，少写一行。

生活类比：分苹果时同时报"每人几个"和"剩几个"，一句话说完两件事。

```python
print(divmod(7, 2))        # -> (3, 1)
print(divmod(4, 333))      # -> (0, 4)
q, r = divmod(17, 5)
print(q, r)                # -> 3 2
```

它在这题里：整数部分用一次 `divmod`，小数部分每一位再用一次 `divmod`。

**"余数出现过没有"决定循环节**（前面 41-12 讲过"记录首次出现位置"）：小学除法里，**余数一旦重复，后面的商就会一模一样地重复**。

一句话回顾：用一个字典记"这个余数第一次出现在小数的第几位"，再次遇到同一个余数，就说明循环开始了。

它在这题里：字典 `seen` 的键是余数、值是它在小数里的位置，重复时把那段用括号包起来。

#### ② 大白话：这题到底在干什么

最笨的办法：真去做除法，一位一位往下算，算到什么时候停？不知道——循环小数永远算不完。

笨在哪？**没有"该停了"的判断**。

聪明办法：回想小学竖式除法。每一步都是"把余数乘 10，再除以分母，得到这一位商和一个新余数"。关键观察：**余数的种类是有限的**（一定小于分母），所以算着算着必然出现重复的余数。一旦某个余数第二次出现，从它第一次出现的那一位开始，后面的商就会原样重复——这一段就是循环节。

于是：用字典记下每个余数第一次出现时"小数已经写到第几位"。每算一位就查一次，查到重复就收工。

#### ③ 拿 `4 / 333` 走一遍

整数部分是 `4 // 333 = 0`，余数 4，开始算小数。

| 步 | 进入循环的余数（记下它的位置） | 乘 10 再除 333 | 这一位商 / 新余数 | 小数部分 |
|---|---|---|---|---|
| 1 | 4（seen[4] = 0） | 40 ÷ 333 | 商 0，余 40 | `"0"` |
| 2 | 40（seen[40] = 1） | 400 ÷ 333 | 商 1，余 67 | `"01"` |
| 3 | 67（seen[67] = 2） | 670 ÷ 333 | 商 2，余 4 | `"012"` |

第 4 步要用的余数是 4，而 `seen[4] = 0` 说明它已经出现过——循环从第 0 位开始。

所以答案是 `"0.(012)"`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `if numerator == 0: return "0"` | 0 单独处理，否则会出现 `-0` |
| `sign = "-" if ...` | 先定符号，后面全用绝对值算 |
| `integer, rem = divmod(a, b)` | 整数部分和第一个余数 |
| `if rem == 0: return ...` | 除得尽，没有小数部分 |
| `while rem != 0 and rem not in seen:` | 余数没除尽、也没重复过 |
| `seen[rem] = len(frac)` | 记下"这个余数在第几位出现" |
| `rem *= 10` 然后 `divmod(rem, b)` | 借一位，算出这一位的商和新的余数 |
| `idx = seen[rem]` | 循环节从第 idx 位开始 |
| `frac[:idx]` + `"(" + frac[idx:] + ")"` | 不循环的部分 + 括号包住的循环部分 |

### 完整代码（Python）

```python
class Solution:
    def fractionToDecimal(self, numerator: int, denominator: int) -> str:
        if numerator == 0:
            return "0"
        sign = "-" if (numerator < 0) != (denominator < 0) else ""
        a, b = abs(numerator), abs(denominator)
        integer, rem = divmod(a, b)
        if rem == 0:
            return sign + str(integer)

        frac = []
        seen = {}                          # 余数 -> 它在小数里的位置
        while rem != 0 and rem not in seen:
            seen[rem] = len(frac)
            rem *= 10
            digit, rem = divmod(rem, b)
            frac.append(str(digit))

        if rem == 0:                       # 除尽了，不是循环小数
            return sign + str(integer) + "." + "".join(frac)
        idx = seen[rem]                    # 从这里开始循环
        return (sign + str(integer) + "."
                + "".join(frac[:idx]) + "(" + "".join(frac[idx:]) + ")")
```

## 41-18. O(1) 时间插入、删除和获取随机元素（Medium）

> 力扣 380 · 哈希表 · Medium
> 前置：41-1（字典）

**一句话**：做一个"集合"，插入、删除、随机取一个，三个操作都要平均 O(1)。

### 精讲（零基础版）

#### ① 这题要用到的东西

**类 `class` 和 `__init__`**

一句话：`class` 是"模板"，`__init__` 是"造一个新对象时自动跑一遍的初始化函数"，`self.xxx` 就是这个对象自己的数据。

生活类比：`class` 是房型图纸，`__init__` 是交房时的装修清单，`self.xxx` 是这套房子里具体的家具。

```python
class Box:
    def __init__(self, v):
        self.v = v

    def double(self):
        return self.v * 2

b = Box(5)
print(b.v)          # -> 5
print(b.double())   # -> 10
```

它在这题里：`RandomizedSet()` 造对象时，`__init__` 负责准备好一个空列表和一个空字典。

**`random.choice(列表)`**

一句话：从列表里等概率随机挑一个元素。

生活类比：抽签，每根签被抽中的机会一样。

```python
import random
random.seed(0)
print(random.choice([7]))              # -> 7
print(random.choice([7, 8]) in (7, 8)) # -> True
```

它在这题里：`getRandom` 只要 `random.choice(self.nums)`，因为数组是连续存满的，每个元素被选中的概率天然相等。

**数组 + "值 → 下标"字典，配合删除**

一句话：数组负责"随机访问"，字典负责"O(1) 找到它在哪"；删除时把**最后一个元素搬到被删的位置**，再删末尾，这样数组中间不会留洞。

生活类比：一排编号的储物柜，要撤掉 3 号柜，就把最后一号柜的东西搬到 3 号，然后把最后一号空出来——全程不用挪动中间所有柜子。

```python
nums = [10, 20, 30, 40]
pos = {10: 0, 20: 1, 30: 2, 40: 3}
i = pos[20]              # 要删 20，它在 1 号位
nums[i] = nums[-1]       # 把末尾的 40 搬过来
pos[nums[i]] = i         # 40 的位置改成 1
nums.pop()               # 删掉末尾
del pos[20]
print(nums)              # -> [10, 40, 30]
print(pos)               # -> {10: 0, 30: 2, 40: 1}
```

它在这题里：`remove` 的全部逻辑就是这五行。

#### ② 大白话：这题到底在干什么

最笨的办法：用一个列表。插入时先查有没有、再 append；删除时 `list.remove` 要从头找到尾。查找和删除都是 O(n)，不达标。

只用一个集合：插入、删除都快，可 `set` 不能按下标随机取，想"随机取一个"只能先转成列表，O(n)。

笨在哪？**没有一个东西能同时擅长"按值查找"和"按下标随机取"**。

聪明办法：两个一起用。列表存值（支持 O(1) 随机取），字典记"每个值在列表的第几位"（支持 O(1) 查位置）。插入就是 append + 记位置；删除的难点在于"删中间会留洞"，所以把末尾元素搬到那个洞上、更新它的位置、再把末尾 pop 掉——三步都是 O(1)。

#### ③ 走一遍插入和删除（前五步是题面的，后两步是补的"删末尾"边界）

| 操作 | nums | pos | 返回 |
|---|---|---|---|
| `insert(1)` | `[1]` | `{1: 0}` | 真 |
| `remove(2)` | `[1]` | `{1: 0}` | 假（本来就没有） |
| `insert(2)` | `[1, 2]` | `{1: 0, 2: 1}` | 真 |
| `remove(1)` | `[2]` | `{2: 0}` | 真（末尾 2 搬到 0 号位） |
| `insert(2)` | `[2]` | `{2: 0}` | 假（已经有了） |
| `insert(3)` | `[2, 3]` | `{2: 0, 3: 1}` | 真 |
| `remove(3)` | `[2]` | `{2: 0}` | 真 |

所以答案是：前五步的返回依次是 `true`、`false`、`true`、`true`、`false`，后两步（删末尾）都是 `true`。`getRandom` 不改变结构，返回 `nums` 里随机一个下标的值；集合里只剩一个元素时必然返回它。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `self.nums = []` / `self.pos = {}` | 一个存值，一个记位置 |
| `if val in self.pos: return False` | 已经有了，不插 |
| `self.pos[val] = len(self.nums)` | 它将被放在末尾 |
| `self.nums.append(val)` | 真放进去 |
| `i = self.pos[val]` | 找到要删的那个洞 |
| `last = self.nums[-1]` | 拿末尾元素 |
| `self.nums[i] = last` / `self.pos[last] = i` | 末尾元素搬到洞里，位置也改 |
| `self.nums.pop()` / `del self.pos[val]` | 删末尾、删记录 |
| `random.choice(self.nums)` | 等概率随机取 |

### 完整代码（Python）

```python
import random

class RandomizedSet:

    def __init__(self):
        self.nums = []      # 存所有值，支持 O(1) 随机访问
        self.pos = {}       # 值 -> 它在 nums 里的下标

    def insert(self, val: int) -> bool:
        if val in self.pos:
            return False
        self.pos[val] = len(self.nums)
        self.nums.append(val)
        return True

    def remove(self, val: int) -> bool:
        if val not in self.pos:
            return False
        i = self.pos[val]
        last = self.nums[-1]
        self.nums[i] = last         # 末尾元素搬到被删位置
        self.pos[last] = i
        self.nums.pop()             # 删末尾，不留洞
        del self.pos[val]
        return True

    def getRandom(self) -> int:
        return random.choice(self.nums)
```

## 41-19. 连续的子数组和（Medium）

> 力扣 523 · 哈希表 · Medium
> 前置：41-12（记录首次出现位置）

**一句话**：有没有长度至少为 2 的连续片段，元素和是 k 的倍数。

### 精讲（零基础版）

#### ① 这题要用到的东西

**前缀和**

一句话：`pre[i]` 表示"从第一个数一直加到第 i 个数"的累计和。任意一段 `[i+1, j]` 的和，等于 `pre[j] - pre[i]`，不用重新加。

生活类比：存折上的余额。想知道"3 月到 5 月花了多少"，不用把三个月的账单重加，用 5 月底余额减 2 月底余额就行。

```python
nums = [23, 2, 4, 6, 7]
pre = [0]
for x in nums:
    pre.append(pre[-1] + x)
print(pre)                 # -> [0, 23, 25, 29, 35, 42]
print(pre[3] - pre[1])     # -> 6
```

它在这题里：`pre[3] - pre[1] = 6` 就是 `nums[1] + nums[2] = 2 + 4`，一段的和一句话算出来。

**同余：余数相同 ⇒ 差是 k 的倍数**

一句话：两个数除以 k 的余数一样，它们的差就能被 k 整除。

生活类比：两班人数都是"除以 7 余 3"，那么这两班人数的差一定是 7 的倍数。

```python
k = 6
print(23 % k)             # -> 5
print(29 % k)             # -> 5
print((29 - 23) % k)      # -> 0
```

它在这题里：只要两个前缀和对 k 的余数相同，它们之间的那段和就是 k 的倍数——于是问题变成"有没有两个下标余数相同"。

#### ② 大白话：这题到底在干什么

最笨的办法：把所有长度 ≥ 2 的片段都试一遍，每个片段求和。片段有 n² 个，n 是 10 万时直接超时。

笨在哪？**求和这一步被重复做了无数遍**，而前缀和可以让任意一段的和一次减法算出来。

聪明办法：一边往后走一边累加前缀和，同时算它对 k 的余数。把"余数 → 这个余数第一次出现的下标"记进字典。如果后面又遇到同一个余数，说明这两个下标之间的那段和是 k 的倍数。还要注意长度至少 2：所以下标差必须 ≥ 2。为了让下标差尽量大，字典里只记**第一次**出现的下标（这和 41-12 是同一个套路）。

初始化时 `first = {0: -1}`：余数 0 代表"空前缀"，下标记 -1，这样从数组开头开始的片段也能被算到。

#### ③ 拿 `nums = [23,2,4,6,7]`、`k = 6` 走一遍

| i | x | 前缀和 | 前缀和 % 6 | 说明 |
|---|---|---|---|---|
| 0 | 23 | 23 | 5 | 没见过 → 记下下标 0 |
| 1 | 2 | 25 | 1 | 没见过 → 记下下标 1 |
| 2 | 4 | 29 | 5 | 见过（下标 0），下标差 2 ≥ 2 → 返回真 |

第 2 步就能收工：`[2,4]` 的和是 6，正好是 6 的倍数。所以答案是真。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `first = {0: -1}` | 余数 0 代表空前缀，位置 -1 |
| `prefix = 0` | 累加器 |
| `prefix += x` | 加上当前数 |
| `r = prefix % k` | 当前余数 |
| `if r in first:` | 以前出现过同一个余数 |
| `if i - first[r] >= 2:` | 中间至少夹了 2 个数 |
| `return True` | 找到了 |
| `else: first[r] = i` | 第一次见，记下位置 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def checkSubarraySum(self, nums: List[int], k: int) -> bool:
        first = {0: -1}          # 余数 -> 最早出现的下标
        prefix = 0
        for i, x in enumerate(nums):
            prefix += x
            r = prefix % k
            if r in first:
                if i - first[r] >= 2:    # 长度至少 2
                    return True
            else:
                first[r] = i             # 只记第一次
        return False
```

## 41-20. 单词替换（Medium）

> 力扣 648 · 哈希表 · Medium
> 前置：41-3（set）

**一句话**：句子里的词，只要以某个词根开头，就换成那个词根（多个词根能匹配时取最短的）。

### 精讲（零基础版）

#### ① 这题要用到的东西

**字符串前缀 `word[:i]`**

一句话：切片 `word[:i]` 取前 i 个字符；`i` 从 1 试到词长，就把所有前缀都试了一遍。

生活类比：从糖葫芦的头上咬，咬一颗、咬两颗、咬三颗……每咬一口就是一个前缀。

```python
w = "cattle"
print(w[:1], w[:2], w[:3])   # -> c ca cat
print(len(w))                # -> 6
print(w[:6] == w)            # -> True
```

它在这题里：`for i in range(1, min(len(word), max_len) + 1)` 就是在挨个试前缀。

**`in` 查集合**（前面 41-3 讲过 set）：`x in 集合` 平均 O(1)，比 `in 列表` 快得多。

一句话回顾：`word[:i] in roots` 就是"这个前缀是不是词根"。

它在这题里：把词典变成集合 `roots`，查前缀一次就够。

**`" ".join(列表)`**（前面 41-14 讲过 join）：用一个空格把单词列表粘回句子。

一句话回顾：`" ".join(["the", "cat"])` 得到 `"the cat"`。

#### ② 大白话：这题到底在干什么

最笨的办法：对句子里的每个词，把词典里的每个词根都试一遍，看它是不是这个词的开头；能匹配的里面挑最短的。

笨在哪？**"这个词以谁开头"其实短前缀一试就知道**，不用把整个词典翻一遍。而且词根最长也就 100 个字符，试前缀最多试 100 次。

聪明办法：先把词典变成集合。然后对每个词，从"取 1 个字符"开始依次加长，一旦这个前缀在集合里，就立刻换成它并停下——因为**先命中的一定是最短词根**。为了不做无用功，前缀长度到"词典里最长词根的长度"就停。

#### ③ 拿示例 1 走一遍

`dictionary = ["cat","bat","rat"]`，最长词根长度 3。

| 单词 | 依次试的前缀 | 命中词根 | 输出 |
|---|---|---|---|
| the | t / th / the | 没命中 | the |
| cattle | c / ca / cat | cat | cat |
| was | w / wa / was | 没命中 | was |
| rattled | r / ra / rat | rat | rat |
| by | b / by | 没命中 | by |
| the | t / th / the | 没命中 | the |
| battery | b / ba / bat | bat | bat |

所以答案是 `"the cat was rat by the bat"`，和题面一致。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `roots = set(dictionary)` | 词典变集合，查得快 |
| `max_len = max(len(r) for r in dictionary)` | 前缀最多试这么长 |
| `for word in sentence.split()` | 一个词一个词处理 |
| `range(1, min(len(word), max_len) + 1)` | 前缀长度从 1 到 min(词长, 最长词根) |
| `if word[:i] in roots:` | 这个前缀就是词根 |
| `word = word[:i]` | 换成词根 |
| `break` | 先命中的最短，后面的不用试 |
| `" ".join(out)` | 拼回句子 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def replaceWords(self, dictionary: List[str], sentence: str) -> str:
        roots = set(dictionary)
        max_len = max(len(r) for r in dictionary)
        out = []
        for word in sentence.split():
            for i in range(1, min(len(word), max_len) + 1):
                if word[:i] in roots:      # 从短到长试，先命中就是最短词根
                    word = word[:i]
                    break
            out.append(word)
        return " ".join(out)
```

## 41-21. 词典中最长的单词（Medium）

> 力扣 720 · 哈希表 · Medium
> 前置：41-6（all）、41-20（前缀）

**一句话**：找最长的词，要求它的每个前缀也都是词典里的词。

### 精讲（零基础版）

#### ① 这题要用到的东西

**"前缀链"：一个词合法 ⟺ 它的所有前缀都在词典里**

一句话：`world` 合法，要求 `w`、`wo`、`wor`、`worl` 全都在词典里；也就是说这个长词必须能由短词一个一个字母加上来。

生活类比：爬楼梯。想到第 5 级，必须第 1、2、3、4 级都踩得住；中间空一级就上不去。

```python
words = {"w", "wo", "wor"}
w = "wor"
print([w[:i] for i in range(1, len(w))])                # -> ['w', 'wo']
print(all(w[:i] in words for i in range(1, len(w))))    # -> True
```

它在这题里：`all(...)` 就是一次把整条楼梯检查完，中间缺一级就判否。

**`all(...)`**（前面 41-6 讲过）：`all` 里全成立才为真；空序列也算成立。

一句话回顾：`all(生成器)` 只要有一个不成立就返回假。

**两个答案怎么比大小：先比长度，再比字典序**

一句话：题目要"最长"，长度一样时要"字典序最小"，所以更新答案的条件要写两半。

生活类比：比赛先看谁跳得高；一样高的时候，看谁号码小。

```python
best = "apply"
w = "apple"
better = len(w) > len(best) or (len(w) == len(best) and w < best)
print(better)      # -> True
```

它在这题里：`if len(w) < len(best) or (len(w) == len(best) and w >= best): continue` 就是"不比现在好就跳过"。

#### ② 大白话：这题到底在干什么

最笨的办法：把每个词都拿去检查——它的所有前缀是不是都在词典里。检查完再从合法的里面挑最长的。能过，但检查一个词要查好几次。

笨在哪？其实不算笨，只是"怎么挑出最长的"容易写乱：要先按长度排，长度一样还要按字典序排，排完取第一个合法的。

聪明办法：不排序，走一遍数组，用一个 `best` 记当前最好的答案。对每个词：先看它有没有资格当答案（比 `best` 长，或者一样长但字典序更小）；有资格再去检查前缀链；检查通过就更新 `best`。

#### ③ 拿 `words = ["w","wo","wor","worl","world"]` 走一遍

| 单词 | 它的前缀 | 前缀都在词典里吗 | best |
|---|---|---|---|
| w | 无前缀 | 成立（空检查） | w |
| wo | w | 成立 | wo |
| wor | w, wo | 成立 | wor |
| worl | w, wo, wor | 成立 | worl |
| world | w, wo, wor, worl | 成立 | world |

所以答案是 `"world"`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `word_set = set(words)` | 词典变集合，查前缀快 |
| `best = ""` | 答案初值：空串 |
| `if len(w) < len(best) or (...)` | 不比现在好，跳过 |
| `w >= best` | 长度一样但字典序不更小 |
| `for i in range(1, len(w))` | 所有真前缀（不含自己） |
| `w[:i] in word_set` | 这一级楼梯在不在 |
| `all(...)` | 每一级都在才行 |
| `best = w` | 更新答案 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def longestWord(self, words: List[str]) -> str:
        word_set = set(words)
        best = ""
        for w in words:
            if len(w) < len(best) or (len(w) == len(best) and w >= best):
                continue
            if all(w[:i] in word_set for i in range(1, len(w))):
                best = w
        return best
```

## 41-22. 划分字母区间（Medium）

> 力扣 763 · 哈希表 · Medium
> 前置：41-12（记录位置）

**一句话**：把字符串切成尽量多段，同一个字母只能出现在一段里。

### 精讲（零基础版）

#### ① 这题要用到的东西

**"最后一次出现的位置"字典**

一句话：和"第一次出现"相反，这里每个字母只留最后一次出现的位置——后面的覆盖前面的，留下的自然就是最后一次。

生活类比：签到表上每个人只保留最后一条记录，那么表上剩下的就是"他最后一次来是哪天"。

```python
last = {}
for i, ch in enumerate("abca"):
    last[ch] = i          # 后面覆盖前面
print(last)               # -> {'a': 3, 'b': 1, 'c': 2}
```

它在这题里：`last['a'] = 8` 表示 `a` 最后一次出现在第 8 位，那么第一段至少得延伸到第 8 位。

**用 `max` 扩展区间右端**

一句话：一路往后走，右端 `end` 要不断更新成"到目前为止所有字母的最后位置的最大值"。

生活类比：一根橡皮筋，每遇到一个新字母就往后拉一拉，拉到最远的那个点。

```python
end = 0
for ch in "abac":
    end = max(end, {"a": 2, "b": 1, "c": 3}[ch])
    print(ch, end)
# -> a 2
# -> b 2
# -> a 2
# -> c 3
```

它在这题里：`end = max(end, last[ch])`，只有当走到 `i == end` 时，这一段才算"封口"，可以切。

#### ② 大白话：这题到底在干什么

最笨的办法：从第一个字符开始，找出它最后一次出现在哪，那中间的所有字符也必须一起包进来；包进来之后，这些字符各自又可能把右端推得更远……一直推，推到不再变为止。思路对，但要反复扫。

笨在哪？**右端只增不减**，所以走一遍就够了，不用回头。

聪明办法：先扫一遍记下每个字母的最后位置。再从头走一遍，边走边把 `end` 更新成"已遇到字母的最后位置的最大值"。当走到 `i == end`，说明这一段里所有字母都不会再在后面出现了，可以切一刀，然后从下一位重新开始。

#### ③ 拿 `s = "ababcbacadefegdehijhklij"` 的第一段走一遍

先记最后位置：a=8、b=5、c=7、d=14、e=15、f=11、g=13、h=19、i=22、j=23。

| i | 字符 | 它的最后位置 | end | 动作 |
|---|---|---|---|---|
| 0 | a | 8 | 0 → 8 | 还没到 |
| 1 | b | 5 | 8 → 8 | 还没到 |
| 2 | a | 8 | 8 → 8 | 还没到 |
| 3 | b | 5 | 8 → 8 | 还没到 |
| 4 | c | 7 | 8 → 8 | 还没到 |
| 5 | b | 5 | 8 → 8 | 还没到 |
| 6 | a | 8 | 8 → 8 | 还没到 |
| 7 | c | 7 | 8 → 8 | 还没到 |
| 8 | a | 8 | 8 → 8 | `i == end`，切一段，长度 9 |

第一段是 `"ababcbaca"`，长度 9。接着从第 9 位重新开始，同理切出长度 7 和 8 的两段，最终答案 `[9,7,8]`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `last = {ch: i for i, ch in enumerate(s)}` | 每个字母的最后位置（后面覆盖前面） |
| `start = end = 0` | 当前段的左端和右端 |
| `for i, ch in enumerate(s):` | 从头走一遍 |
| `end = max(end, last[ch])` | 右端只会往后推 |
| `if i == end:` | 走到右端了，这段封口 |
| `res.append(end - start + 1)` | 记下这段长度 |
| `start = end + 1` | 下一段从后面开始 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        last = {ch: i for i, ch in enumerate(s)}   # 每个字母最后出现的位置
        res = []
        start = end = 0
        for i, ch in enumerate(s):
            end = max(end, last[ch])       # 右端只会往后推
            if i == end:                   # 走到右端，这一段封口
                res.append(end - start + 1)
                start = end + 1
        return res
```

## 41-23. 自定义字符串排序（Medium）

> 力扣 791 · 哈希表 · Medium
> 前置：41-10（排名表 + sorted）

**一句话**：按 `order` 给的字符顺序重排 `s`，不在 `order` 里的字符随便放。

### 精讲（零基础版）

#### ① 这题要用到的东西

**排名表 + `sorted(key=...)`**（前面 41-10 讲过）：把"自定义顺序"翻译成"数字排名"，剩下的交给 `sorted`。

一句话回顾：`rank = {ch: i for i, ch in enumerate(order)}`，`sorted(s, key=lambda ch: rank[ch])` 就按这个顺序排。

它在这题里：`order` 里的字符有真排名，不在的给一个统一的大排名，自然排到最后。

**`sorted` 是稳定排序**

一句话：排序键相同的元素，排完之后**保持原来的相对顺序**。

生活类比：按身高排队，身高一样的两个人不会互换位置，原来谁在前还在前。

```python
pairs = [("b", 1), ("a", 1), ("c", 0)]
print(sorted(pairs, key=lambda p: p[1]))   # -> [('c', 0), ('b', 1), ('a', 1)]
```

它在这题里：`s` 里不在 `order` 中的字符排名都一样，稳定排序让它们保持原来的先后，题目正好允许。

**字符串也能 `sorted`，再用 `join` 拼回去**

一句话：`sorted("cba")` 得到字符列表 `['a','b','c']`，`"".join(...)` 拼回字符串。

```python
print(sorted("cba"))            # -> ['a', 'b', 'c']
print("".join(sorted("cba")))   # -> abc
```

它在这题里：`"".join(sorted(s, key=...))` 一行完成排序加拼串。

#### ② 大白话：这题到底在干什么

最笨的办法：先按 `order` 的顺序，把 `s` 里等于 `order[0]` 的字符全挑出来、再挑 `order[1]` 的……最后把剩下的接上。要扫很多遍。

笨在哪？**每个字符该排第几，一次就能查出来**，不用按 `order` 逐字符扫 `s`。

聪明办法：做一张排名表，`order` 里第 i 个字符排名就是 i。然后给 `s` 的每个字符算出排名当排序键，排一遍就完事。不在表里的字符统一给一个"比所有排名都大"的数，它们自然落在最后。

#### ③ 拿 `order = "cba"`、`s = "abcd"` 走一遍

`order` 长度 3，所以"不在表里"的排名取 3。

| 字符 | 排名 | 排序键 |
|---|---|---|
| a | 2 | 2 |
| b | 1 | 1 |
| c | 0 | 0 |
| d | 不在 order → 用 3 | 3 |

所以答案是 `"cbad"`——按排序键从小到大：`c(0)`、`b(1)`、`a(2)`、`d(3)`，和题面示例一致。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `rank = {ch: i for i, ch in enumerate(order)}` | 自定义顺序 → 数字排名 |
| `big = len(order)` | 不在表里的统一排名 |
| `sorted(s, key=...)` | 按排名排字符 |
| `rank.get(ch, big)` | 查得到用真排名，查不到排最后 |
| `"".join(...)` | 字符列表拼回字符串 |

### 完整代码（Python）

```python
class Solution:
    def customSortString(self, order: str, s: str) -> str:
        rank = {ch: i for i, ch in enumerate(order)}
        big = len(order)                       # 不在 order 里的字符统一排最后
        return "".join(sorted(s, key=lambda ch: rank.get(ch, big)))
```

## 41-24. N 天后的牢房（Medium）

> 力扣 957 · 哈希表 · Medium
> 前置：41-3（set）

**一句话**：8 间牢房每天按"左右邻居相同就有人、否则空"变一次，问 n 天后的状态。

### 精讲（零基础版）

#### ① 这题要用到的东西

**元组当字典的键（把"状态"压成一个值）**

一句话：8 个 0/1 组成的列表不能当字典的键（列表可改、不可哈希），换成元组 `(0,1,0,...)` 就可以了。

生活类比：把一整套棋局拍成一张照片存进相册；以后拿照片比对，比拿整盘棋比对方便。

```python
state = (0, 1, 0)
seen = {state: 7}
print(state in seen)      # -> True
print(seen[(0, 1, 0)])    # -> 7
```

它在这题里：`seen` 记"这个状态是在还剩 n 天的时候遇到的"，键必须是不可变的元组。

**找循环节**

一句话：状态只有有限多种，走够久必然重复；一旦重复，就可以直接跳过中间的整数轮。

生活类比：日历。你知道今天是星期几，就不用一天一天数，直接按 7 取余。

```python
seen = {}
n = 10
state = "A"
while n > 0:
    if state in seen:
        print("循环长度", seen[state] - n)   # -> 循环长度 4
        break
    seen[state] = n
    state = chr(ord(state) + 1) if state != "D" else "A"
    n -= 1
```

它在这题里：`n %= seen[state] - n` 直接把 `n` 缩到一个循环长度以内。

**`[0] * 8` 造一个全零列表**

一句话：列表乘整数就是把元素复制几遍，得到 8 个独立的 0（0 是不可变数字，所以没有共享问题）。

```python
nxt = [0] * 8
print(nxt)        # -> [0, 0, 0, 0, 0, 0, 0, 0]
print(len(nxt))   # -> 8
```

它在这题里：每天先造一个全零的"明天"，只填中间 6 位。

#### ② 大白话：这题到底在干什么

最笨的办法：老老实实模拟 n 天。可 n 能到 10 亿，一天一次循环，跑到天亮。

笨在哪？**状态总数其实很少**：8 个格子、首尾永远是 0，中间 6 位一共只有 2⁶ = 64 种状态。走不了几十天就会回到某个见过的状态，然后开始周而复始。

聪明办法：模拟的同时，把"每个遇到过的状态 + 当时还剩几天"记进字典。一旦发现当前状态以前出现过，说明从那时到现在是一个完整的循环，可以直接把 `n` 对循环长度取余，跳过所有整圈。

#### ③ 拿 `cells = [0,1,0,1,1,0,0,1]`、`n = 7` 走一遍

| 天 | 状态 | 说明 |
|---|---|---|
| 0 | 01011001 | 初始 |
| 1 | 01100000 | 第 0、7 位永远是 0 |
| 2 | 00001110 | 同上 |
| 3 | 01100100 | 同上 |
| 4 | 00000100 | 同上 |
| 5 | 01110100 | 同上 |
| 6 | 00101100 | 同上 |
| 7 | 00110000 | 第 7 天 |

所以答案是 `[0,0,1,1,0,0,0,0]`。7 天还没走到重复，循环节那条捷径没被触发；换成 `n = 10 亿` 时，走十几天就会撞上重复状态，`n` 立刻被缩小。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `seen = {}` | 状态 → 当时还剩几天 |
| `state = tuple(cells)` | 列表转元组才能当字典的键 |
| `while n > 0:` | 还有天数要变 |
| `if state in seen:` | 这个状态以前来过 |
| `n %= seen[state] - n`，然后 `seen = {}` | 跳过所有整圈，清空避免再触发 |
| `seen[state] = n` | 记下"这个状态还剩 n 天" |
| `if n == 0: break` | 取余后可能正好 0 天，直接收工 |
| `nxt[i] = 1 if state[i-1] == state[i+1] else 0` | 左右邻居相同就是 1 |
| `state = tuple(nxt)` / `n -= 1` | 进入下一天 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def prisonAfterNDays(self, cells: List[int], n: int) -> List[int]:
        seen = {}                      # 状态 -> 遇到它时还剩几天
        state = tuple(cells)
        while n > 0:
            if state in seen:
                n %= seen[state] - n   # 跳过整圈
                seen = {}
            seen[state] = n
            if n == 0:
                break
            nxt = [0] * 8
            for i in range(1, 7):      # 只填中间 6 位
                nxt[i] = 1 if state[i - 1] == state[i + 1] else 0
            state = tuple(nxt)
            n -= 1
        return list(state)
```

## 41-25. 和可被 K 整除的子数组（Medium）

> 力扣 974 · 哈希表 · Medium
> 前置：41-19（前缀和 + 同余）

**一句话**：数一数有多少个连续片段，元素和能被 k 整除。

### 精讲（零基础版）

#### ① 这题要用到的东西

**前缀和 + 同余**（前面 41-19 讲过）：两个前缀和对 k 余数相同，它们之间的那段和就是 k 的倍数。

一句话回顾：`(pre[j] - pre[i]) % k == 0` ⟺ `pre[j] % k == pre[i] % k`。

它在这题里：和 41-19 是同一个工具，区别是这里要**数个数**而不是只判断有没有。

**Python 的 `%` 对负数返回非负数**

一句话：Python 里 `-7 % 5` 是 3，不是 -2——余数永远和除数同号，这里恒为非负。

生活类比：钟表往回拨 2 小时，指针不会变成"负 2 点"，而是 10 点。

```python
print(-7 % 5)      # -> 3
print(7 % 5)       # -> 2
print(-7 // 5)     # -> -2
```

它在这题里：数组里有负数，前缀和会变成负数，但 `prefix % k` 依然落在 `0 ~ k-1`，可以直接当字典的键，不用自己修正。

**把"记录下标"换成"记录次数"**

一句话：41-19 只问有没有，所以记"最早下标"；这里问有多少个，就要记"这个余数出现过几次"——每来一个新的同余前缀和，就新增 `cnt` 个符合条件的片段。

```python
cnt = {0: 1}
cnt[4] = cnt.get(4, 0) + 1
print(cnt)         # -> {0: 1, 4: 1}
```

它在这题里：`ans += cnt.get(r, 0)` 一句话累加所有以当前位置结尾的合法片段数。

#### ② 大白话：这题到底在干什么

最笨的办法：把所有片段都列出来，每个求和再判断能不能被 k 整除。片段有 n² 个，n 是 3 万时是 9 亿次，超时。

笨在哪？**同一个"前缀和"被反复计算**，而"能不能整除"只跟余数有关，跟具体和是多少无关。

聪明办法：边走边算前缀和，边走边算余数。用一个字典记"每个余数到目前为止出现过几次"。走到第 i 个位置时，如果当前余数以前出现过 `c` 次，那就说明有 `c` 段以 i 结尾的片段和能被 k 整除——把这 `c` 加进答案。字典一开始放 `{0: 1}`，代表"空前缀"这个余数为 0 的起点。

#### ③ 拿 `nums = [4,5,0,-2,-3,1]`、`k = 5` 走一遍

| i | x | 前缀和 | 前缀和 % 5 | 同余的已有几个 → 累计答案 |
|---|---|---|---|---|
| 0 | 4 | 4 | 4 | 0 个 → 答案 0 |
| 1 | 5 | 9 | 4 | 1 个 → 答案 1 |
| 2 | 0 | 9 | 4 | 2 个 → 答案 3 |
| 3 | -2 | 7 | 2 | 0 个 → 答案 3 |
| 4 | -3 | 4 | 4 | 3 个 → 答案 6 |
| 5 | 1 | 5 | 0 | 1 个 → 答案 7 |

走完字典是 `{0: 2, 4: 4, 2: 1}`，答案是 7，和题面一致。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `cnt = {0: 1}` | 余数 0 已经出现过 1 次（空前缀） |
| `prefix += x` | 累计和 |
| `r = prefix % k` | 当前余数，负数也落在 0~k-1 |
| `ans += cnt.get(r, 0)` | 以前同余的每一个都能配成一段 |
| `cnt[r] = cnt.get(r, 0) + 1` | 这个余数又多了一次 |
| `return ans` | 总数 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def subarraysDivByK(self, nums: List[int], k: int) -> int:
        cnt = {0: 1}          # 余数 -> 出现过几次（0 代表空前缀）
        prefix = 0
        ans = 0
        for x in nums:
            prefix += x
            r = prefix % k    # Python 里负数取模也非负
            ans += cnt.get(r, 0)
            cnt[r] = cnt.get(r, 0) + 1
        return ans
```

## 41-26. 受标签影响的最大值（Medium）

> 力扣 1090 · 哈希表 · Medium
> 前置：41-4（zip）、41-10（sorted）

**一句话**：最多挑 `numWanted` 个物品，同标签最多挑 `useLimit` 个，让值的和最大。

### 精讲（零基础版）

#### ① 这题要用到的东西

**先排序，再从大的开始拿（贪心）**

一句话：每个物品占掉一个名额，那就先拿值最大的，反正名额一样占。

生活类比：限购 3 件，货架上东西价格不同，当然先拿最贵的。

```python
items = sorted([(5, 1), (4, 1), (3, 2)], key=lambda p: -p[0])
print(items)          # -> [(5, 1), (4, 1), (3, 2)]
print(items[0][0])    # -> 5
```

它在这题里：`sorted(zip(values, labels), key=lambda p: -p[0])` 把"值、标签"配成对，按值从大到小排。

**`zip(values, labels)` 把两个数组配成对**（前面 41-4 讲过 zip）：一次取一个值和一个标签。

一句话回顾：`list(zip([5,4], [1,1]))` 得到 `[(5, 1), (4, 1)]`。

**每个标签的用量计数**（前面 41-1 讲过 `dict.get`）：用字典记"这个标签已经拿了几个"。

一句话回顾：`used.get(lab, 0)` 取不到就是 0，拿来和上限比。

```python
used = {}
used['a'] = used.get('a', 0) + 1
used['a'] = used.get('a', 0) + 1
print(used)          # -> {'a': 2}
```

#### ② 大白话：这题到底在干什么

最笨的办法：把所有子集都列出来，逐个检查"个数 ≤ numWanted、同标签 ≤ useLimit"，取和最大的。物品有 2 万个，子集数量根本数不清。

笨在哪？**这个问题不需要"试所有组合"**：值大的物品永远不会比值小的差，能拿就拿。

聪明办法：把物品按值从大到小排好，然后从前往后走，能拿就拿：名额没满、且这个标签还没用满，就拿走并记账。遇到标签用满的就跳过，继续看下一个。为什么对？因为每个物品占的名额一样多，用值大的换掉值小的，总和只会更大。

#### ③ 拿 `values=[5,4,3,2,1]`、`labels=[1,1,2,2,3]`、`numWanted=3`、`useLimit=1` 走一遍

按值从大到小：`(5,1)`、`(4,1)`、`(3,2)`、`(2,2)`、`(1,3)`。

| 物品（值,标签） | 该标签已选几个（选后） | 动作 | 累计和 |
|---|---|---|---|
| (5,1) | 1 | 选它 | 5 |
| (4,1) | 1 | 标签 1 已用满 → 跳过 | 5 |
| (3,2) | 1 | 选它 | 8 |
| (2,2) | 1 | 标签 2 已用满 → 跳过 | 8 |
| (1,3) | 1 | 选它 | 9 |

选满 3 个，答案是 9。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `zip(values, labels)` | 值和标签配成对 |
| `sorted(..., key=lambda p: -p[0])` | 按值从大到小 |
| `if chosen == numWanted: break` | 名额满了就收工 |
| `if used.get(lab, 0) == useLimit: continue` | 这个标签用满了，跳过 |
| `used[lab] = ... + 1` | 记账 |
| `total += v` / `chosen += 1` | 累加值、占一个名额 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def largestValsFromLabels(self, values: List[int], labels: List[int],
                              numWanted: int, useLimit: int) -> int:
        items = sorted(zip(values, labels), key=lambda p: -p[0])  # 按值从大到小
        used = {}
        total = 0
        chosen = 0
        for v, lab in items:
            if chosen == numWanted:
                break
            if used.get(lab, 0) == useLimit:     # 这个标签用满了
                continue
            used[lab] = used.get(lab, 0) + 1
            total += v
            chosen += 1
        return total
```

## 41-27. 安排电影院座位（Medium）

> 力扣 1386 · 哈希表 · Medium
> 前置：41-3（set）

**一句话**：每行 10 个座位，四人小组只能坐 2-5、4-7、6-9 三个块之一，求最多能安排几组。

### 精讲（零基础版）

#### ① 这题要用到的东西

**集合交集 `&`**

一句话：`A & B` 取出两边都有的元素；判断"这个块里有没有人订过"，只要看交集是不是空。

生活类比：两张名单对一遍，找出同时出现在两张名单上的名字。

```python
a = {2, 3}
print(bool(a & {4, 5, 6, 7}))   # -> False
print(bool(a & {2, 3, 4, 5}))   # -> True
```

它在这题里：`seats & {2,3,4,5}` 非空，就说明左块 2-5 被占了，不能坐。

**`dict.setdefault(r, set()).add(c)`**

一句话：键不存在时先塞一个空集合进去，然后往集合里加元素——一行完成"没有就先建"。

生活类比：去储物间，柜子没贴标签就先贴一张空的，再往里放东西。

```python
rows = {}
for r, c in [(1, 2), (1, 3), (2, 6)]:
    rows.setdefault(r, set()).add(c)
print(sorted(rows[1]))   # -> [2, 3]
print(len(rows))         # -> 2
```

它在这题里：把"每一行被订了哪些座位"收集成"行号 → 座位集合"。

**只处理有预约的行**

一句话：`n` 能到 10 亿，一行一行遍历是不可能的；没被预约的行每一行都能坐 2 组，直接乘出来。

生活类比：全校只有 3 个班有人请假，统计人数时不用把全校每个班都点一遍。

```python
n = 1000000000
reserved = {1: {2, 3}, 2: {6}}
print(len(reserved))              # -> 2
print((n - len(reserved)) * 2)    # -> 1999999996
```

它在这题里：`total + (n - len(rows)) * 2` 一句补上没有预约的那些行。

#### ② 大白话：这题到底在干什么

最笨的办法：给每一行都试着放，放得下就减人数。可 `n` 有 10 亿行，光循环就跑不完。

笨在哪？**绝大多数行根本没被订过**，这些行的答案完全一样（都是 2 组）。

聪明办法：只关心"有预约的行"。对每一行，把订掉的座位收成一个集合，然后看三个四人块哪个没被碰过：左块 2-5、右块 6-9 互不重叠，两块都空就是 2 组；否则看看中间块 4-7，或者左、右任一块能不能用，能用就是 1 组，都不能用就是 0 组。剩下的 `n - 有预约的行数` 行，每行直接算 2 组。

注意座位 1 和 10 在任何四人块之外，订了也不影响，所以判断时不用管它们。

#### ③ 拿 `n=3`、`reservedSeats=[[1,2],[1,3],[1,8],[2,6],[3,1],[3,10]]` 走一遍

| 行 | 被订的座位 | 可用的四人块 | 这一行几组 |
|---|---|---|---|
| 1 | [2, 3, 8] | 4-7 | 1 |
| 2 | [6] | 2-5 | 1 |
| 3 | [1, 10] | 2-5、4-7、6-9 | 2 |

三行都有预约，没有"空行"可补。所以答案是 1 + 1 + 2 = 4，和题面一致。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `rows.setdefault(r, set()).add(c)` | 收集"每行订了哪些座位" |
| `left = not (seats & {2,3,4,5})` | 左块 2-5 没人订 |
| `right = not (seats & {6,7,8,9})` | 右块 6-9 没人订 |
| `middle = not (seats & {4,5,6,7})` | 中间块 4-7 没人订 |
| `if left and right: total += 2` | 左右都不冲突，一行两组 |
| `elif left or right or middle: total += 1` | 只能挤一组 |
| `total + (n - len(rows)) * 2` | 空行每行两组 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def maxNumberOfFamilies(self, n: int, reservedSeats: List[List[int]]) -> int:
        rows = {}                                  # 行号 -> 被订的座位集合
        for r, c in reservedSeats:
            rows.setdefault(r, set()).add(c)
        total = 0
        for seats in rows.values():
            left = not (seats & {2, 3, 4, 5})
            right = not (seats & {6, 7, 8, 9})
            middle = not (seats & {4, 5, 6, 7})
            if left and right:
                total += 2
            elif left or right or middle:
                total += 1
        return total + (n - len(rows)) * 2          # 没被预约的行，每行 2 组
```

## 41-28. 单词频率（Medium）

> 力扣 面试题 16.02 · 哈希表 · Medium
> 前置：41-18（类）、41-2（Counter）

**一句话**：设计一个"查词频"的类，构造时给一本书，之后每次查询返回某个词出现了几次。

### 精讲（零基础版）

#### ① 这题要用到的东西

**类 + 构造时把活干完（预处理）**

一句话：`__init__` 里先数好所有词频存起来，`get` 只做一次查表——把重活放在"一次性"的地方，把轻活放在"反复调用"的地方。

生活类比：开馆前先把书按索引摆好，读者来问就翻索引，不用每次把整个书库重找一遍。

```python
class WordBag:
    def __init__(self, book):
        self.cnt = {}
        for w in book:
            self.cnt[w] = self.cnt.get(w, 0) + 1

    def get(self, word):
        return self.cnt.get(word, 0)

bag = WordBag(["a", "b", "a"])
print(bag.get("a"))     # -> 2
print(bag.get("z"))     # -> 0
```

它在这题里：`__init__` 收下 `book` 立刻统计，`get` 只剩一行查表。

**`Counter`**（前面 41-2 讲过）：数数的字典。

一句话回顾：`Counter(book)` 一步得到"每个词出现几次"，`cnt[词]` 取不到给 0。

**`dict.get(word, 0)`**（前面 41-1 讲过）：键不在时给默认值，不报错。

它在这题里：`self.cnt.get(word, 0)` 让"书里没有这个词"自动返回 0，不用写 if。

#### ② 大白话：这题到底在干什么

最笨的办法：每次调用 `get`，都把整本书从头到尾数一遍。书有 10 万个词、查询也有 10 万次，那是 100 亿次操作。

笨在哪？**同一本书被数了 10 万遍**，而这 10 万遍的结果完全一样。

聪明办法：构造对象的时候数一次，把结果存进字典。之后每次查询只是"拿词去字典里查一下"，O(1)。这就是"预处理"：把重复劳动提前做一次。

#### ③ 拿题面的书走一遍

书是 `["i","have","an","apple","he","have","a","pen"]`。

| 单词 | 书里出现几次 | get 返回 |
|---|---|---|
| i | 1 | 1 |
| have | 2 | 2 |
| an | 1 | 1 |
| apple | 1 | 1 |
| he | 1 | 1 |
| a | 1 | 1 |
| pen | 1 | 1 |
| you | 0（书里没有） | 0 |

所以答案是：`get("you")` 返回 0，`get("have")` 返回 2，其余都是 1。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `def __init__(self, book):` | 造对象时自动执行一次 |
| `self.cnt = Counter(book)` | 把整本书数一遍，存到对象身上 |
| `def get(self, word):` | 每次查询 |
| `return self.cnt.get(word, 0)` | 查字典，没有就是 0 |

### 完整代码（Python）

```python
from typing import List
from collections import Counter

class WordsFrequency:

    def __init__(self, book: List[str]):
        self.cnt = Counter(book)      # 构造时数一次，之后只查表

    def get(self, word: str) -> int:
        return self.cnt.get(word, 0)
```

## 41-29. 缺失的第一个正数（Hard）

> 力扣 41 · 哈希表 · Hard
> 前置：41-3（set）

**一句话**：找出数组里没有出现的最小正整数，要求 O(n) 时间、常数额外空间。

### 精讲（零基础版）

#### ① 这题要用到的东西

**原地哈希：把值 v 放到下标 v-1 的位置上**

一句话：数组自己就能当"哈希表"用——让 `nums[0] = 1`、`nums[1] = 2`……谁没在位，谁就是缺的。

生活类比：一排带编号的储物柜，规定 1 号物品必须放 1 号柜、2 号物品放 2 号柜。最后检查哪一号柜里放的不是对应物品，答案就出来了。

```python
nums = [3, 4, -1, 1]
nums[0], nums[2] = nums[2], nums[0]     # 把 3 换到下标 2
print(nums)                             # -> [-1, 4, 3, 1]
```

它在这题里：`3` 应该待在下标 `3-1=2`，一个交换就位。

**`while` 交换，而不是 `if` 交换一次**

一句话：换过来的新值可能也不在位，得接着换，所以用 `while` 一直换到"这个位置上的值已经合适"为止。

生活类比：整理书架，把放错的书换回去，换回来的那本可能还是放错的，得继续换。

```python
nums = [4, 1, 2, 3]
i = 0
while 1 <= nums[i] <= 4 and nums[nums[i] - 1] != nums[i]:
    j = nums[i] - 1
    nums[i], nums[j] = nums[j], nums[i]
print(nums)     # -> [1, 2, 3, 4]
```

它在这题里：`while` 保证每个数最终都回到自己的位置。

#### ② 大白话：这题到底在干什么

最笨的办法：把所有数放进一个集合，然后从 1 开始一个个问"在不在"，第一个不在的就是答案。时间 O(n)，但多花了一个集合的空间。

笨在哪？**题目要求常数额外空间**，不能另开一个大结构。

聪明办法：数组自己就是那张表，下标 `i` 用来表示"数字 i+1 在不在"。做法是把每个值 `v` 搬到下标 `v-1` 去（只搬 `1 ≤ v ≤ n` 的那些，其他值没用）。全部搬完之后扫一遍：第一个 `nums[i] != i + 1` 的位置，答案就是 `i + 1`。如果每个位置都对得上，说明 1 到 n 全齐了，答案是 `n + 1`。

为什么答案一定在 `1 ~ n+1` 之间？因为数组只有 n 个数，最多占掉 n 个正整数。

#### ③ 拿 `nums = [3,4,-1,1]` 走一遍

| 步 | 动作 | 数组变成 | 说明 |
|---|---|---|---|
| 初始 | — | `[3, 4, -1, 1]` | |
| i=0 | 换 nums[0] ↔ nums[2] | `[-1, 4, 3, 1]` | 3 该去下标 2 |
| i=0 | nums[0] = -1 不用换 | `[-1, 4, 3, 1]` | 负数不管，前进 |
| i=1 | 换 nums[1] ↔ nums[3] | `[-1, 1, 3, 4]` | 4 该去下标 3 |
| i=1 | 换 nums[1] ↔ nums[0] | `[1, -1, 3, 4]` | 换来的 1 该去下标 0 |
| i=1 | nums[1] = -1 不用换 | `[1, -1, 3, 4]` | 前进 |
| i=2 | nums[2] = 3 已在位 | `[1, -1, 3, 4]` | 前进 |
| i=3 | nums[3] = 4 已在位 | `[1, -1, 3, 4]` | 前进 |

收尾扫描：`nums[0]=1` 对、`nums[1]=-1` 应该是 2，对不上。所以答案是 2。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `n = len(nums)` | 答案最多是 n+1 |
| `while 1 <= nums[i] <= n` | 只处理 1~n 范围内的值 |
| `nums[nums[i] - 1] != nums[i]` | 它的"家"还没被它占住 |
| `j = nums[i] - 1` | 它该去的下标 |
| `nums[i], nums[j] = nums[j], nums[i]` | 交换，让它就位 |
| `if nums[i] != i + 1:` | 这个位置对不上 |
| `return i + 1` | 缺的就是它 |
| `return n + 1` | 1~n 全齐，答案是 n+1 |

### 完整代码（Python）

```python
from typing import List

class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        n = len(nums)
        for i in range(n):
            # 把 nums[i] 换到它该在的位置 nums[i] - 1
            while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
                j = nums[i] - 1
                nums[i], nums[j] = nums[j], nums[i]
        for i in range(n):
            if nums[i] != i + 1:
                return i + 1
        return n + 1
```

## 41-30. 直线上最多的点数（Hard）

> 力扣 149 · 哈希表 · Hard
> 前置：41-24（元组当键）

**一句话**：平面上最多有多少个点在同一条直线上。

### 精讲（零基础版）

#### ① 这题要用到的东西

**斜率用"约分后的 `(dx, dy)`"表示**

一句话：两点确定一个方向；把所有方向都约分到最简，方向相同的点就在同一条过基点的直线上。

生活类比：从同一个路口出发，所有朝东北走的车，不管走多远，都在同一条射线上。

```python
import math
for dx, dy in [(4, 2), (2, 1), (-2, -1)]:
    g = math.gcd(abs(dx), abs(dy))
    sdx, sdy = dx // g, dy // g
    if sdx < 0 or (sdx == 0 and sdy < 0):
        sdx, sdy = -sdx, -sdy
    print(sdx, sdy)
# -> 2 1
# -> 2 1
# -> 2 1
```

它在这题里：三个不同的位移最后都化成 `(2, 1)`，所以它们在同一条过基点的直线上。

**`math.gcd` 最大公约数**

一句话：`math.gcd(a, b)` 给出能同时整除 a 和 b 的最大整数；用它一除，分数就约到最简。

生活类比：把 4:2 的配方按比例缩成 2:1，比例不变但数字最小。

```python
import math
print(math.gcd(4, 2))      # -> 2
print(math.gcd(-2, 2))     # -> 2
print(math.gcd(3, 7))      # -> 1
```

它在这题里：`dx // g, dy // g` 就是约分，保证 `(4,2)` 和 `(2,1)` 变成同一个键。

**元组当字典的键**（前面 41-24 讲过）：`(dx, dy)` 是不可变的，可以当键。

一句话回顾：列表不能当键，元组可以；用 `(sdx, sdy)` 当斜率的名字。

**统一符号，让 `(2,1)` 和 `(-2,-1)` 变成同一个键**

一句话：同一条直线的两个方向互为相反数，所以规定"`dx` 为负时整体取反"，把两个方向压成一个。

它在这题里：`if sdx < 0 or (sdx == 0 and sdy < 0)` 这一段就是在统一符号。

#### ② 大白话：这题到底在干什么

最笨的办法：每两个点确定一条直线，再数有多少个点在这条线上。点是 300 个时，直线有 4 万多条，每条再数 300 个点，太慢。

笨在哪？**"在同一条直线上"这件事，可以只看每个点跟基点的方向**，不用真去求直线方程。

聪明办法：每次固定一个点当"基点"，然后看其他所有点相对它的方向（约分后的 `(dx, dy)`）。方向相同的点，全都在同一条过基点的直线上。用字典数"每个方向有几个点"，最多的那个再加 1（加的是基点自己）就是这一轮的最优解。每个点都当一次基点，取最大值。

为什么不直接算斜率 `dy/dx`？因为浮点数会丢精度，两个本该相等的斜率可能差一点点。用约分后的整数对，永远精确。

#### ③ 拿示例 2 走一遍（基点取 `(3,2)`）

| 其他点 | 位移 (dx, dy) | 除以 gcd | 约分后方向 |
|---|---|---|---|
| (1,1) | (-2, -1) | 1 | (2, 1) |
| (5,3) | (2, 1) | 1 | (2, 1) |
| (4,1) | (1, -1) | 1 | (1, -1) |
| (2,3) | (-1, 1) | 1 | (1, -1) |
| (1,4) | (-2, 2) | 2 | (1, -1) |

统计方向：`(2,1)` 有 2 个点，`(1,-1)` 有 3 个点。

最多 3 个点同方向，加上基点自己是 4 个点。所以答案是 4。

#### ④ 代码逐行对译

| 代码 | 大白话 |
|---|---|
| `if n <= 2: return n` | 一两个点肯定共线 |
| `for i in range(n):` | 每个点轮流当基点 |
| `x1, y1 = points[i]` | 取出基点坐标 |
| `dx = points[j][0] - x1` | 横向位移 |
| `g = math.gcd(abs(dx), abs(dy))` | 求最大公约数 |
| `dx //= g` / `dy //= g` | 约到最简 |
| `if dx < 0 or (dx == 0 and dy < 0):` | 统一符号 |
| `slopes[(dx, dy)] = ... + 1` | 这个方向又多一个点 |
| `max(slopes.values()) + 1` | 最多的点数，加上基点自己 |

### 完整代码（Python）

```python
from typing import List
import math

class Solution:
    def maxPoints(self, points: List[List[int]]) -> int:
        n = len(points)
        if n <= 2:
            return n
        best = 2
        for i in range(n):
            slopes = {}
            x1, y1 = points[i]
            for j in range(i + 1, n):
                dx = points[j][0] - x1
                dy = points[j][1] - y1
                g = math.gcd(abs(dx), abs(dy))
                dx //= g
                dy //= g
                if dx < 0 or (dx == 0 and dy < 0):   # 统一符号
                    dx, dy = -dx, -dy
                slopes[(dx, dy)] = slopes.get((dx, dy), 0) + 1
            if slopes:
                best = max(best, max(slopes.values()) + 1)
        return best
```
