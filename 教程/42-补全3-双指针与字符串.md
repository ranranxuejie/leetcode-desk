## 42-1. 最长公共前缀（Easy）

> 力扣 14 · 字符串 · Easy

**一句话**：找出所有字符串开头共有的那一段，一个字符一个字符地往下比。

### 精讲（零基础版）

#### ① 这题要用到的东西

**字符串下标 `s[i]` 和长度 `len(s)`**

一句人话：字符串就是一排字符，`s[0]` 是第一个字符，`s[3]` 是第四个，编号从 0 开始。

生活类比：像一排编了号的信箱，`s[i]` 就是打开第 i 号信箱往里看一眼。

```python
s = "flower"
print(len(s))     # -> 6
print(s[0])       # -> f
print(s[3])       # -> w
```

它在这题里干什么：外层循环用 `i` 表示「现在比到第几个字符」，内层用 `w[i]` 取出每个字符串同一位置的字符来对。

**切片 `s[:i]`**

一句人话：切片是「截一段出来」，`s[:i]` 表示从开头截到第 i 个字符之前，正好 i 个字符。

生活类比：像从一叠纸上撕下最上面几张，`s[:2]` 就是撕下前两张。

```python
s = "flower"
print(s[:2])          # -> fl
print(repr(s[:0]))    # -> ''
```

它在这题里干什么：一旦比出不一致，答案就是 `first[:i]`，即前 i 个字符。

#### ② 大白话：这题到底在干什么

要找所有单词共有的开头。最笨的办法是把每个单词的所有前缀都列出来，再一个个去别的单词里查，写起来麻烦。

换个角度想：公共前缀一定也是第一个单词的前缀。那就拿第一个单词当尺子，一个字符一个字符地往后走。走到第 i 位时，看所有单词的第 i 位是不是都跟尺子一样。只要有一个单词在这一位不一样，或者它已经比尺子短了，那么前 i 个字符就是答案。如果一直走到尺子末尾都没出事，那整个第一个单词就是答案。

#### ③ 拿一个具体输入走一遍

`strs = ["flower","flow","flight"]`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 起始 | `first = "flower"`，`i = 0` | 拿第一个单词当尺子 |
| i=0，ch='f' | `flower[0]`、`flow[0]`、`flight[0]` 全是 'f' | 三个都命中，继续 |
| i=1，ch='l' | 三个字符串第 1 位全是 'l' | 三个都命中，继续 |
| i=2，ch='o' | `flight[2]` 是 'i'，不等于 'o' | 第一个不匹配出现 |
| 返回 | `first[:2]` | 返回 `"fl"` |

所以答案是 `"fl"`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `first = strs[0]` | 拿第一个单词当尺子 |
| `for i in range(len(first)):` | 从第 0 位走到尺子的最后一位 |
| `ch = first[i]` | 这一位要对的字符是谁 |
| `for w in strs:` | 挨个单词检查这一位 |
| `if i >= len(w) or w[i] != ch:` | 这个单词太短，或者这一位对不上 |
| `return first[:i]` | 前面 i 个字符就是答案 |
| `return first` | 一直没出错，整个第一个单词都是公共前缀 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        first = strs[0]
        for i in range(len(first)):
            ch = first[i]
            for w in strs:
                if i >= len(w) or w[i] != ch:
                    return first[:i]
        return first
```

## 42-2. 删除有序数组中的重复项（Easy）

> 力扣 26 · 双指针 · Easy

**一句话**：数组已经排好序，把重复的去掉，只留一份，还要原地改、返回新长度。

### 精讲（零基础版）

#### ① 这题要用到的东西

**双指针（快慢指针）**

一句人话：在同一个数组上放两个下标，一个跑得快、负责「看新元素」，一个跑得慢、负责「写下要留的元素」。

生活类比：像整理一摞卡片，左手不停往后翻（快指针），右手只在遇到该留下的卡片时，把它放到左边已经理好的那一叠末尾（慢指针）。

```python
nums = [1, 1, 2]
slow = 1
for fast in range(1, len(nums)):
    if nums[fast] != nums[slow - 1]:
        nums[slow] = nums[fast]
        slow += 1
print(slow, nums)   # -> 2 [1, 2, 2]
```

它在这题里干什么：`fast` 扫过整个数组找「跟上一个保留值不同的数」，`slow` 记录「已经确定要留几个」。

**原地修改**

一句人话：不新建数组，直接在原来那个数组的格子里改内容。

生活类比：像在白板上改字，不是换一块新白板。

```python
nums = [1, 1, 2]
nums[1] = 9
print(nums)         # -> [1, 9, 2]
```

它在这题里干什么：题目要求原地做，所以只能把要留的元素往前覆盖，不能 `return` 一个新列表。

#### ② 大白话：这题到底在干什么

数组已经从小到大排好了，相同的数一定挨在一起。最笨的办法是新建一个空列表，挨个往里塞，塞之前看一眼上一个塞进去的是不是同一个数，最后把新列表复制回原数组——但这用到了额外空间。

聪明办法：不用新建列表，直接把原数组的前半段当成那个「新列表」。放一个慢指针 `slow` 指向「下一个空位」，快指针 `fast` 从头扫到尾。只要 `nums[fast]` 跟「最后一个已保留的数」不一样，就把它写到 `slow` 位置，然后 `slow` 往后挪一格。扫完之后，前 `slow` 个位置就是去重结果，`slow` 就是新长度。

#### ③ 拿一个具体输入走一遍

`nums = [1,1,2]`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 起始 | `slow = 1`，`nums = [1,1,2]` | 第一个元素天然算「唯一」，慢指针从 1 开始 |
| fast=1 | `nums[1]=1` 与 `nums[0]=1` 相同 | 重复，跳过，`slow` 还是 1 |
| fast=2 | `nums[2]=2` 与 `nums[0]=1` 不同 | 写到 `nums[1]=2`，数组变 `[1,2,2]`，`slow=2` |
| 结束 | 返回 `slow = 2` | 前两个元素是 `[1,2]` |

所以答案是 `k = 2`，数组前两位是 `[1,2]`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `if not nums: return 0` | 空数组直接返回 0 |
| `slow = 1` | 第一个元素一定保留，下一个空位是 1 |
| `for fast in range(1, len(nums)):` | 快指针从第 1 位扫到最后 |
| `if nums[fast] != nums[slow - 1]:` | 跟「最后一个已保留的数」比，不一样才要留 |
| `nums[slow] = nums[fast]` | 把它写到下一个空位 |
| `slow += 1` | 空位往后挪一格 |
| `return slow` | 慢指针的值就是新长度 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        if not nums:
            return 0
        slow = 1
        for fast in range(1, len(nums)):
            if nums[fast] != nums[slow - 1]:
                nums[slow] = nums[fast]
                slow += 1
        return slow
```

## 42-3. 移除元素（Easy）

> 力扣 27 · 双指针 · Easy

**一句话**：把数组里所有等于 `val` 的数删掉，剩下的挪到前面，返回剩下的个数。

### 精讲（零基础版）

#### ① 这题要用到的东西

**快慢指针**（前面 42-2 讲过）：一个快指针扫全部元素，一个慢指针指着「下一个要写入的位置」。这题用它把不等于 `val` 的元素依次往前搬。

**列表赋值与「有效前缀」**

一句人话：题目只要求「前 k 个位置是对的」，k 之后留下什么垃圾都行。

生活类比：像把书架前 k 格整理好，后面几格乱着也没人管。

```python
nums = [3, 2, 2, 3]
nums[0] = 2
print(nums)         # -> [2, 2, 2, 3]
print(nums[:2])     # -> [2, 2]
```

它在这题里干什么：只把要留的元素写到 `slow` 位置，`slow` 之后的旧内容不用清理。

#### ② 大白话：这题到底在干什么

要在原地删掉某些元素。最笨的办法是找到一个就把它后面的所有元素往前挪一格，挪一次是 O(n)，找很多次就慢得没法看。

聪明办法还是快慢指针。慢指针 `slow` 表示「已经整理好的部分有多长」，也就是下一个该写的位置。快指针 `fast` 从头扫到尾：遇到不等于 `val` 的数，就把它抄到 `slow` 位置，`slow` 加一；遇到等于 `val` 的数，跳过不管。扫完之后，前 `slow` 个位置正好是全部要留的元素。

#### ③ 拿一个具体输入走一遍

`nums = [3,2,2,3]`，`val = 3`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| fast=0 | `nums[0]=3` 等于 val | 跳过，`slow=0`，数组不变 |
| fast=1 | `nums[1]=2` 不等于 val | 写 `nums[0]=2`，数组变 `[2,2,2,3]`，`slow=1` |
| fast=2 | `nums[2]=2` 不等于 val | 写 `nums[1]=2`，数组不变，`slow=2` |
| fast=3 | `nums[3]=3` 等于 val | 跳过，`slow=2` |
| 结束 | 返回 `slow = 2` | 前两位是 `[2,2]` |

所以答案是 `k = 2`，`nums` 前两位是 `[2,2]`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `slow = 0` | 还没有任何元素被保留，下一个空位是 0 |
| `for fast in range(len(nums)):` | 快指针从头扫到尾 |
| `if nums[fast] != val:` | 这个数不是要删的 |
| `nums[slow] = nums[fast]` | 把它搬到下一个空位 |
| `slow += 1` | 空位往后挪一格 |
| `return slow` | 留下的个数 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def removeElement(self, nums: List[int], val: int) -> int:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != val:
                nums[slow] = nums[fast]
                slow += 1
        return slow
```

## 42-4. 最后一个单词的长度（Easy）

> 力扣 58 · 字符串 · Easy

**一句话**：字符串末尾可能挂着好几个空格，跳过它们，数出最后一个单词有几个字母。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`while` 循环 + 下标往小走**

一句人话：`while` 是「只要条件还成立就继续」，下标不一定非要从小到大，也可以从末尾往前走。

生活类比：像从走廊尽头往回走，边走边数门牌，遇到墙就停。

```python
s = "ab cde"
i = len(s) - 1
while i >= 0 and s[i] != ' ':
    print(s[i])
    i -= 1
# -> e
# -> d
# -> c
```

它在这题里干什么：先用一个 `while` 从末尾跳过空格，再用第二个 `while` 往前数单词里的字母。

**字符比较 `s[i] != ' '`**

一句人话：单个字符之间可以直接用 `==`、`!=` 比，比的是「是不是同一个字符」。

生活类比：像核对两枚印章的花纹是否一模一样。

```python
print('a' == 'a')    # -> True
print('a' != ' ')    # -> True
```

它在这题里干什么：判断「这一位是不是空格」来决定循环停不停。

#### ② 大白话：这题到底在干什么

要找最后一个单词，最容易想到的是把整串按空格切开，拿最后一块数长度。但那会创建一个新列表，写法也不够「顺着原字符串走」。

更直接的办法：从字符串的最后一个字符开始，先往回走，把末尾的空格全部跳过去；跳到第一个真正的字母时停住，然后从这个字母开始继续往回数，数到空格或者数到字符串开头为止。数出来的个数就是答案。

#### ③ 拿一个具体输入走一遍

`s = "   fly me   to   the moon  "`（长度 27，最后一位下标 26）：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 起始 | `n = 26` | 指向最后一位 |
| n=26 | `s[26] = ' '` | 是空格，`n` 减到 25 |
| n=25 | `s[25] = ' '` | 还是空格，`n` 减到 24 |
| n=24 | `s[24] = 'n'` | 碰到字母，停止跳空格 |
| 数单词 | 依次读到 'n'、'o'、'o'、'm' | `cnt` 依次变成 1、2、3、4 |
| n=20 | `s[20] = ' '` | 碰到空格，循环停止 |
| 返回 | `cnt = 4` | 最后一个单词是 "moon" |

所以答案是 `4`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `n = len(s) - 1` | 指向字符串最后一位 |
| `while n >= 0 and s[n] == ' ': n -= 1` | 一直往回跳过末尾的空格 |
| `cnt = 0` | 单词长度从 0 开始数 |
| `while n >= 0 and s[n] != ' ': ` | 只要还没越过开头、也没碰到空格 |
| `cnt += 1` | 数一个字母 |
| `n -= 1` | 往前挪一位 |
| `return cnt` | 数到的就是最后一个单词的长度 |

### 完整代码（Python）

```python
class Solution:
    def lengthOfLastWord(self, s: str) -> int:
        n = len(s) - 1
        while n >= 0 and s[n] == ' ':
            n -= 1
        cnt = 0
        while n >= 0 and s[n] != ' ':
            cnt += 1
            n -= 1
        return cnt
```

## 42-5. 二进制求和（Easy）

> 力扣 67 · 字符串 · Easy

**一句话**：两个二进制字符串当竖式加起来，结果还是二进制字符串。

### 精讲（零基础版）

#### ① 这题要用到的东西

**进位 carry**

一句人话：二进制里 1+1 会「满二进一」，写 0、往前进 1，这个进上去的 1 就叫进位。

生活类比：像算盘满十进一，只不过这里满二就进。

```python
total = 1 + 1 + 0     # 两位相加再加进位
print(total % 2)      # -> 0
print(total // 2)     # -> 1
```

它在这题里干什么：每一轮把「两个位 + 上次的进位」加起来，`% 2` 是这一位的结果，`// 2` 是新的进位。

**`int(字符)`、`str(整数)`、`''.join(列表)`**

一句人话：`int('1')` 把字符变成数字 1，`str(0)` 把数字变回字符，`''.join(parts)` 把一串字符拼成一个字符串。

生活类比：`join` 像把散落的珠子用线穿成一串。

```python
print(int('1') + int('0'))        # -> 1
print(str(7 % 2))                 # -> 1
print(''.join(['1', '0', '0']))   # -> 100
```

它在这题里干什么：算的时候用数字，存结果的时候用字符，最后拼起来。

**`reversed(列表)`**

一句人话：把列表倒过来从头看，但不改动原列表。

生活类比：像从队尾往队头报数。

```python
print(list(reversed(['0', '0', '1'])))   # -> ['1', '0', '0']
```

它在这题里干什么：竖式是从低位往高位算的，拼答案时要倒过来。

#### ② 大白话：这题到底在干什么

把两个字符串想成两行竖式，从最右边（个位）开始往左加。每一位取两个字符串对应位置的字符，加上上一轮剩下的进位，得到 0、1、2、3 中的一个。这个数除以 2 的余数是这一位的结果，除出来的商是往前进的进位。

有一位算一位，注意两个字符串可能不一样长：短的先走完，走完之后那一位按 0 处理。最后如果两个都走完了但进位还是 1，还要再补一个 '1'。把所有结果字符反过来拼起来就是答案。

#### ③ 拿一个具体输入走一遍

`a = "11"`，`b = "1"`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 第 1 轮 | a 位 '1'、b 位 '1'、旧 carry=0，total=2 | 本位写 `'0'`，新 carry=1，`out=['0']` |
| 第 2 轮 | a 位 '1'、b 已用完、旧 carry=1，total=2 | 本位写 `'0'`，新 carry=1，`out=['0','0']` |
| 第 3 轮 | a、b 都用完，但 carry=1，total=1 | 本位写 `'1'`，carry=0，`out=['0','0','1']` |
| 反转拼接 | `reversed(out)` | 得到 `"100"` |

所以答案是 `"100"`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `i, j = len(a)-1, len(b)-1` | 两个指针都指向各自最后一位 |
| `carry = 0`，`out = []` | 进位从 0 开始，结果先存进列表 |
| `while i >= 0 or j >= 0 or carry:` | 只要还有位没算，或者还有进位没处理 |
| `total = carry` | 先放上进位 |
| `if i >= 0: total += int(a[i]); i -= 1` | 有 a 的位就加上，指针左移 |
| `if j >= 0: total += int(b[j]); j -= 1` | 有 b 的位就加上，指针左移 |
| `out.append(str(total % 2))` | 余数是本位结果 |
| `carry = total // 2` | 商是新的进位 |
| `return ''.join(reversed(out))` | 倒过来拼成字符串 |

### 完整代码（Python）

```python
class Solution:
    def addBinary(self, a: str, b: str) -> str:
        i, j = len(a) - 1, len(b) - 1
        carry = 0
        out = []
        while i >= 0 or j >= 0 or carry:
            total = carry
            if i >= 0:
                total += int(a[i])
                i -= 1
            if j >= 0:
                total += int(b[j])
                j -= 1
            out.append(str(total % 2))
            carry = total // 2
        return ''.join(reversed(out))
```

## 42-6. 合并两个有序数组（Easy）

> 力扣 88 · 双指针 · Easy

**一句话**：把 `nums2` 并进 `nums1` 里，合并后仍然有序，结果必须落在 `nums1` 中。

### 精讲（零基础版）

#### ① 这题要用到的东西

**从后往前双指针**

一句人话：两个指针分别指向两个数组「还剩的最大元素」，谁大就把谁填到结果末尾，填完往前挪。

生活类比：两摞从大到小排好的盘子，要合成一摞同样从大到小的。从最底下往上码，每次挑两摞里最大的那个放进去，最省事。

```python
a = [1, 5]
b = [2, 9]
i, j = len(a) - 1, len(b) - 1
print(a[i], b[j])    # -> 5 9
```

它在这题里干什么：`nums1` 后面那 `n` 个 0 正好是空位，从后往前填就不会覆盖还没比过的数。

**`nums1` 的空位约定**

一句人话：`nums1` 长度是 `m + n`，前 `m` 个是真数据，后 `n` 个是 0，占位用的。

生活类比：像提前在桌上摆好空盘子，等着往上盛菜。

```python
nums1 = [1, 2, 3, 0, 0, 0]
print(len(nums1))    # -> 6
print(nums1[3:])     # -> [0, 0, 0]
```

它在这题里干什么：知道空位在哪，才敢从后往前写。

#### ② 大白话：这题到底在干什么

两个数组都已经排好序了，要合成一个有序数组，而且结果必须装进 `nums1`。

最笨的办法是把 `nums2` 拼到 `nums1` 后面再排序，但题目要 O(m+n)，排序是 O(n log n)，不合格。另一个笨办法是从前往后合并，问题是往 `nums1` 前面写会把它自己后面的元素盖掉。

关键点就在这：`nums1` 后面本来就有一排空位。那就从最大的开始比，谁大谁去填空位，从最右边往左填。因为每次填的都是当前最大的，填过的位置不会再被用到，所以不会覆盖任何还没比较的数。

#### ③ 拿一个具体输入走一遍

`nums1 = [1,2,3,0,0,0]`，`m = 3`，`nums2 = [2,5,6]`，`n = 3`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| k=5 | `nums1[2]=3` 与 `nums2[2]=6` 比，6 大 | 填 6，`j=1`，`nums1=[1,2,3,0,0,6]` |
| k=4 | `nums1[2]=3` 与 `nums2[1]=5` 比，5 大 | 填 5，`j=0`，`nums1=[1,2,3,0,5,6]` |
| k=3 | `nums1[2]=3` 大于 `nums2[0]=2` | 填 3，`i=1`，`nums1=[1,2,3,3,5,6]` |
| k=2 | `nums2[0]=2` 不小于 `nums1[1]=2` | 填 2，`j=-1`，`nums1=[1,2,2,3,5,6]` |
| 结束 | `j < 0`，`nums2` 用完了 | 返回 `[1,2,2,3,5,6]` |

所以答案是 `[1,2,2,3,5,6]`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `i, j, k = m-1, n-1, m+n-1` | `i` 指 nums1 末尾真实数据，`j` 指 nums2 末尾，`k` 指填充位 |
| `while j >= 0:` | 只要 nums2 还有数没放完 |
| `if i >= 0 and nums1[i] > nums2[j]:` | nums1 的数更大，而且 nums1 还有数 |
| `nums1[k] = nums1[i]; i -= 1` | 把 nums1 的数搬到 k 位置，i 左移 |
| `else:` | 否则（nums2 更大，或 nums1 已空） |
| `nums1[k] = nums2[j]; j -= 1` | 把 nums2 的数搬过去，j 左移 |
| `k -= 1` | 填充位往左挪一格 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def merge(self, nums1: List[int], m: int, nums2: List[int], n: int) -> None:
        i, j, k = m - 1, n - 1, m + n - 1
        while j >= 0:
            if i >= 0 and nums1[i] > nums2[j]:
                nums1[k] = nums1[i]
                i -= 1
            else:
                nums1[k] = nums2[j]
                j -= 1
            k -= 1
```

## 42-7. 验证回文串（Easy）

> 力扣 125 · 双指针 · Easy

**一句话**：只保留字母和数字、统一小写，然后判断正着读和反着读是否一样。

### 精讲（零基础版）

#### ① 这题要用到的东西

**对撞双指针**

一句人话：一个指针在开头往右走，一个指针在末尾往左走，两边对着逼近。

生活类比：两个人从纸条的两端往中间读，每人读一个字符，读到的要一样。

```python
s = "abba"
print(s[0], s[-1])    # -> a a
print(s[1], s[-2])    # -> b b
```

它在这题里干什么：左指针和右指针各取一个有效字符比较，比完就往中间收一格。

**`s[i].isalnum()` 和 `s[i].lower()`**

一句人话：`isalnum()` 判断这个字符是不是字母或数字，`lower()` 把大写变小写。

生活类比：`isalnum` 像门卫，只放字母和数字进门，标点符号一律拦下；`lower` 像把所有人名都登记成小写，避免大小写误判。

```python
print('a'.isalnum())    # -> True
print(','.isalnum())    # -> False
print('A'.lower())      # -> a
```

它在这题里干什么：跳过标点和空格，并把 'A' 和 'a' 当成同一个字符。

#### ② 大白话：这题到底在干什么

先把无关字符（空格、逗号、冒号）和大小写差异都忽略掉，再看剩下的一串字符是否左右对称。

最笨的办法是先用一个新字符串装下所有有效字符并转小写，再把它和它的反转比较。这样能过，但要额外开一份内存。

聪明办法是双指针：左指针从开头找下一个字母或数字，右指针从末尾找上一个字母或数字，两个都找到了就比一下小写后是否相同。相同就各自往中间走一格，不同就直接返回 False。当两个指针相遇或交叉时，说明全部对称，返回 True。

#### ③ 拿一个具体输入走一遍

`s = "A man, a plan, a canal: Panama"`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 第 1 步 | `i=0` 是 'A'，`j=29` 是 'a' | 小写后相同，`i→1`，`j→28` |
| 第 2 步 | `i` 跳过空格停在 2（'m'），`j=28` 是 'm' | 相同，`i→3`，`j→27` |
| 第 3 步 | `i=3`（'a'），`j=27`（'a'） | 相同，`i→4`，`j→26` |
| 第 4 步 | `i=4`（'n'），`j=26`（'n'） | 相同，`i→5`，`j→25` |
| 第 5 步 | `i` 跳过 ", " 停在 7（'a'），`j=25`（'a'） | 相同，`i→8`，`j→24` |
| 第 6 步 | `i` 跳过空格停在 9（'p'），`j=24`（'P'） | 小写后相同，`i→10`，`j→23` |
| 继续 | 一直比到指针交叉 | 全程没出现不同 |
| 结束 | 共比较 11 次 | 返回 `True` |

所以答案是 `True`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `i, j = 0, len(s) - 1` | 左指针在头，右指针在尾 |
| `while i < j:` | 两个指针还没碰上就继续 |
| `while i < j and not s[i].isalnum(): i += 1` | 左边跳过标点和空格 |
| `while i < j and not s[j].isalnum(): j -= 1` | 右边跳过标点和空格 |
| `if s[i].lower() != s[j].lower(): return False` | 两边不一样，直接判失败 |
| `i += 1; j -= 1` | 两边各往中间收一格 |
| `return True` | 全程对称，是回文串 |

### 完整代码（Python）

```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        i, j = 0, len(s) - 1
        while i < j:
            while i < j and not s[i].isalnum():
                i += 1
            while i < j and not s[j].isalnum():
                j -= 1
            if s[i].lower() != s[j].lower():
                return False
            i += 1
            j -= 1
        return True
```

## 42-8. 移动零（Easy）

> 力扣 283 · 双指针 · Easy

**一句话**：把所有 0 挪到数组末尾，非零元素的先后顺序不能变，而且必须原地做。

### 精讲（零基础版）

#### ① 这题要用到的东西

**两个变量交换 `a, b = b, a`**

一句人话：Python 里交换两个位置的值不用中间变量，一行就够。

生活类比：两个人换座位，直接起身互换，不需要先站到第三个空位上。

```python
nums = [3, 1]
nums[0], nums[1] = nums[1], nums[0]
print(nums)          # -> [1, 3]
```

它在这题里干什么：把快指针找到的非零元素和慢指针位置的元素互换，一步完成「搬走非零、把 0 挪后」。

**快慢指针**（前面 42-2 讲过）：慢指针指着「下一个该放非零元素的位置」，快指针扫全部元素。这题用它把非零元素按原顺序挤到前面，剩下的位置自然就全是 0。

#### ② 大白话：这题到底在干什么

要求把 0 全赶到后面，非零元素的相对顺序还得保持，而且不许新建数组。

最笨的办法是遇到一个 0 就把后面所有元素往前挪一格，再把 0 放到末尾。挪一次要动很多元素，数组一大就很慢。

聪明办法：不要真去「删 0」，而是把非零元素往前挤。慢指针 `slow` 表示「下一个非零元素该放的位置」，快指针 `fast` 从头扫到尾。遇到非零元素，就把它和 `slow` 位置的元素交换，然后 `slow` 往后挪一格。因为每次交换都是把非零的换到前面、把 0 换到后面，所以扫完之后前面全是非零（且顺序不变），后面全是 0。

#### ③ 拿一个具体输入走一遍

`nums = [0,1,0,3,12]`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| fast=0 | `nums[0]=0` | 是 0，跳过，`slow=0` |
| fast=1 | `nums[1]=1` | 非零，与 `nums[0]` 交换，数组变 `[1,0,0,3,12]`，`slow=1` |
| fast=2 | `nums[2]=0` | 是 0，跳过，`slow=1` |
| fast=3 | `nums[3]=3` | 非零，与 `nums[1]` 交换，数组变 `[1,3,0,0,12]`，`slow=2` |
| fast=4 | `nums[4]=12` | 非零，与 `nums[2]` 交换，数组变 `[1,3,12,0,0]`，`slow=3` |
| 结束 | `slow=3` | 返回 `[1,3,12,0,0]` |

所以答案是 `[1,3,12,0,0]`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `slow = 0` | 下一个非零元素该放的位置 |
| `for fast in range(len(nums)):` | 快指针扫一遍 |
| `if nums[fast] != 0:` | 碰到非零元素 |
| `nums[slow], nums[fast] = nums[fast], nums[slow]` | 换到前面去 |
| `slow += 1` | 前面已经多了一个非零元素 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow], nums[fast] = nums[fast], nums[slow]
                slow += 1
```

## 42-9. 反转字符串中的元音字母（Easy）

> 力扣 345 · 双指针 · Easy

**一句话**：只把字符串里的元音字母（a e i o u，大小写都算）倒过来排，其它字符原地不动。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`set` 集合**

一句人话：`set` 是一堆「不重复、没有顺序」的东西，用 `x in 集合` 判断存不存在特别快。

生活类比：像门口的允许通行名单，保安一眼就能看出你在不在名单上，不需要从头一个个对。

```python
vowels = set('aeiou')
print('e' in vowels)     # -> True
print('z' in vowels)     # -> False
print(len(vowels))       # -> 5
```

它在这题里干什么：判断「这个字符是不是元音」，一行 `ch[i] not in vowels` 就够。

**`list(s)` 把字符串变成可改的列表**

一句人话：Python 的字符串是「不能改」的，想换掉某个字符，得先转成列表，改完再拼回字符串。

生活类比：像把装好框的照片取出来重新排，排好再装回框里。

```python
ch = list("abc")
ch[0] = "x"
print(''.join(ch))       # -> xbc
```

它在这题里干什么：要交换两个位置的元音，必须先把 `s` 变成 `list(s)`。

**对撞双指针**（前面 42-7 讲过）：左指针找下一个元音，右指针找上一个元音，找到就交换。这题用它把左右两端的元音对着换。

#### ② 大白话：这题到底在干什么

题目只要元音字母的顺序倒过来，其它字母不动。

最笨的办法是把所有元音抽出来、倒序、再塞回去。要额外开列表记录位置，写起来啰嗦。

聪明办法：左指针从前往后找元音，右指针从后往前找元音。两个都找到了，就把它俩换一下，然后各自往中间走一格。如果某个指针走到了非元音字符，就跳过它继续走。当两个指针相遇，说明所有元音都对调完了。

#### ③ 拿一个具体输入走一遍

`s = "IceCreAm"`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 起始 | `i=0`，`j=6` | 左右两端开始 |
| 第 1 次 | `i=0` 是 'I'，`j=6` 是 'A'，都是元音 | 交换后 `"AceCreIm"`，`i→1`，`j→5` |
| 第 2 次 | `i` 走到 2 是 'e'，`j` 走到 5 是 'e'，都是元音 | 交换（两个 e 换了个位置），`i→3`，`j→4` |
| 第 3 次 | `i` 从 3 的 'C' 走到 4 是 'r'，`j` 从 4 的 'r' 走不动 | `i` 不再小于 `j`，循环结束 |
| 返回 | `"AceCreIm"` | 元音顺序已反转 |

所以答案是 `"AceCreIm"`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `vowels = set('aeiouAEIOU')` | 元音名单，大小写都收 |
| `ch = list(s)` | 转成可改的列表 |
| `i, j = 0, len(ch) - 1` | 左指针在头，右指针在尾 |
| `while i < j and ch[i] not in vowels: i += 1` | 左指针跳过非元音 |
| `while i < j and ch[j] not in vowels: j -= 1` | 右指针跳过非元音 |
| `if i < j:` | 两端都真找到元音了 |
| `ch[i], ch[j] = ch[j], ch[i]` | 交换这两个元音 |
| `i += 1; j -= 1` | 两边各往中间收一格 |
| `return ''.join(ch)` | 拼回字符串 |

### 完整代码（Python）

```python
class Solution:
    def reverseVowels(self, s: str) -> str:
        vowels = set('aeiouAEIOU')
        ch = list(s)
        i, j = 0, len(ch) - 1
        while i < j:
            while i < j and ch[i] not in vowels:
                i += 1
            while i < j and ch[j] not in vowels:
                j -= 1
            if i < j:
                ch[i], ch[j] = ch[j], ch[i]
                i += 1
                j -= 1
        return ''.join(ch)
```

## 42-10. 密钥格式化（Easy）

> 力扣 482 · 字符串 · Easy

**一句话**：把密钥里的破折号去掉、字母转大写，然后从右往左每 k 个字符插一个破折号。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`s.replace('-', '')` 和 `s.upper()`**

一句人话：`replace` 把某种字符全部换成另一种（换成空字符串就是删掉），`upper` 把字母全部变大写。

生活类比：`replace` 像用橡皮把纸上所有的逗号都擦掉，`upper` 像把整页小写字母重新用大写描一遍。

```python
print("5F3Z-2e-9-w".replace('-', ''))    # -> 5F3Z2e9w
print("5F3Z2e9w".upper())                # -> 5F3Z2E9W
```

它在这题里干什么：先把字符串洗成「纯字符 + 全大写」，后面才好切块。

**取模 `%` 决定第一组多长**

一句人话：`总长度 % k` 就是「除不尽剩下的那几个」，它们必须放到第一组去。

生活类比：像分糖果，最后不够一包的那几颗，单独放第一包。

```python
raw = "5F3Z2E9W"
k = 4
print(len(raw) % k)      # -> 0
raw2 = "AAAAA"
print(len(raw2) % k)     # -> 1
```

它在这题里干什么：`first = len(raw) % k` 就是第一组的长度；如果正好整除，第一组不用短，就是 k 个。

**`range(start, stop, step)`**

一句人话：从 `start` 开始，每次加 `step`，一直到 `stop` 之前。

生活类比：像楼梯上每隔两阶跳一次。

```python
print(list(range(1, 8, 4)))    # -> [1, 5]
```

它在这题里干什么：从第一组之后开始，每次跨 k 个字符切一组。

#### ② 大白话：这题到底在干什么

先不管破折号，把所有字符（转成大写）排成一长条。现在要从右往左按每 k 个切成若干组，最后可能剩下不到 k 个——这一小组放在最前面。

为什么从右往左分？因为题目要求「除第一组外，每组恰好 k 个」。如果从左边开始分，最后会剩一小截挂在末尾，不符合要求；从右边开始分，零头自然落在开头，正好是允许短一点的第一组。

所以做法是：先算 `len(raw) % k`，这就是第一组的长度；如果是 0，说明能整除，第一组也是 k 个。然后按 k 一段一段切出来，用 `'-'` 连起来。

#### ③ 拿一个具体输入走一遍

`S = "5F3Z-2e-9-w"`，`k = 4`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 清洗 | 去掉破折号、转大写 | `raw = "5F3Z2E9W"`，长度 8 |
| 算第一组 | `8 % 4 = 0` | 能整除，第一组就是 4 个 |
| 切第一段 | `raw[0:4]` | `"5F3Z"` |
| 切第二段 | `raw[4:8]` | `"2E9W"` |
| 拼接 | 用 `'-'` 连接 | `"5F3Z-2E9W"` |

所以答案是 `"5F3Z-2E9W"`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `raw = s.replace('-', '').upper()` | 洗掉破折号并全部转大写 |
| `out = []` | 用来装每一组 |
| `first = len(raw) % k` | 第一组的长度（零头） |
| `if first: out.append(raw[:first])` | 有零头就先把它作为第一组 |
| `for i in range(first, len(raw), k):` | 从零头之后开始，每 k 个切一段 |
| `out.append(raw[i:i + k])` | 切出这一组 |
| `return '-'.join(out)` | 用破折号连起来 |

### 完整代码（Python）

```python
class Solution:
    def licenseKeyFormatting(self, s: str, k: int) -> str:
        raw = s.replace('-', '').upper()
        out = []
        first = len(raw) % k
        if first:
            out.append(raw[:first])
        for i in range(first, len(raw), k):
            out.append(raw[i:i + k])
        return '-'.join(out)
```

## 42-11. 验证回文串 II（Easy）

> 力扣 680 · 双指针 · Easy

**一句话**：最多允许删掉一个字符，判断剩下的能不能变成回文串。

### 精讲（零基础版）

#### ① 这题要用到的东西

**在函数里定义函数**

一句人话：Python 允许在方法内部再写一个小函数，这个小函数能直接用外层的变量（比如 `s`）。

生活类比：像在厨房里再摆一个小案板，专门切一种配料，用完就收。

```python
def outer(s):
    def inner(lo, hi):
        return s[lo:hi + 1]
    return inner(0, 1)


print(outer("abcd"))     # -> ab
```

它在这题里干什么：把「判断某一段是不是回文」抽成 `ok(lo, hi)`，主流程里两处调用，不用写两遍循环。

**`or` 短路**

一句人话：`A or B` 先算 A，A 为真就不再算 B，直接返回真。

生活类比：两个方案里只要有一个能成，就不用再试第二个。

```python
def ok(x):
    return x > 0


print(ok(5) or ok(-1))   # -> True
```

它在这题里干什么：`ok(i+1, j) or ok(i, j-1)` 表示「删左边那个」或「删右边那个」只要有一种成立就返回 True。

**对撞双指针**（前面 42-7 讲过）：左右指针往中间比，一旦发现不同，就用掉那一次删除机会，试试跳过左边或跳过右边。

#### ② 大白话：这题到底在干什么

和普通回文判断差不多，只是多了一次「后悔」的机会。

左右指针往中间走，一路都相同就继续。第一次遇到不同的字符时，说明这里必须删掉一个：要么删左边这个字符（于是左指针跳过它，继续比剩下的），要么删右边这个字符。两种都试一遍，只要有一种能让剩下的部分完全对称，答案就是 True。

如果两种都不行，说明一次删除不够，返回 False。如果从头到尾都没遇到不同，本来就已经是回文串，返回 True。

#### ③ 拿一个具体输入走一遍

`s = "abca"`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 第 1 步 | `i=0` 是 'a'，`j=3` 是 'a' | 相同，`i→1`，`j→2` |
| 第 2 步 | `i=1` 是 'b'，`j=2` 是 'c' | 不同，开始试用那一次删除 |
| 试删左 | 检查 `s[2..2]` 即 `"c"` | 只剩一个字符，算回文，返回 True |
| 结束 | `ok(2, 2) = True` | 整体返回 `True` |

所以答案是 `True`（删掉 'b' 得到 "aca"，或删掉 'c' 得到 "aba"）。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `def ok(lo, hi):` | 小工具：判断 s[lo..hi] 是不是回文 |
| `while lo < hi:` | 两头往中间比 |
| `if s[lo] != s[hi]: return False` | 有一个不同就不是回文 |
| `i, j = 0, len(s) - 1` | 主流程的左右指针 |
| `if s[i] != s[j]:` | 第一次撞上不同 |
| `return ok(i + 1, j) or ok(i, j - 1)` | 删左边那个，或者删右边那个，有一种行就行 |
| `return True` | 全程没撞上不同，本来就是回文 |

### 完整代码（Python）

```python
class Solution:
    def validPalindrome(self, s: str) -> bool:
        def ok(lo: int, hi: int) -> bool:
            while lo < hi:
                if s[lo] != s[hi]:
                    return False
                lo += 1
                hi -= 1
            return True

        i, j = 0, len(s) - 1
        while i < j:
            if s[i] != s[j]:
                return ok(i + 1, j) or ok(i, j - 1)
            i += 1
            j -= 1
        return True
```

## 42-12. 旋转字符串（Easy）

> 力扣 796 · 字符串 · Easy

**一句话**：把 `s` 最左边的字符反复搬到最右边，问能不能变成 `goal`。

### 精讲（零基础版）

#### ① 这题要用到的东西

**字符串相加 `s + s`**

一句人话：两个字符串用 `+` 接起来，`s + s` 就是把 `s` 抄一遍接在后面。

生活类比：像把一条环形跑道剪开铺直，你多绕一圈再剪，就能看到所有可能的起点。

```python
s = "abc"
print(s + s)          # -> abcabc
print(s * 2)          # -> abcabc
```

它在这题里干什么：`s + s` 里包含了「从任意位置开始、长度等于 len(s)」的所有旋转结果。

**子串判断 `x in y`**

一句人话：`x in y` 判断 `x` 是不是 `y` 里连续的一段。

生活类比：像在一条长纸带上找有没有印着这几个字的一段。

```python
print("cd" in "abcde")    # -> True
print("ce" in "abcde")    # -> False
```

它在这题里干什么：只要 `goal in s + s`，说明 `goal` 是 `s` 的某次旋转结果。

#### ② 大白话：这题到底在干什么

每次旋转就是把第一个字符挪到末尾。转 `len(s)` 次就回到原样，所以真正不同的结果最多 `len(s)` 个。

最笨的办法是老老实实转 len(s) 次，每次比一下是不是等于 `goal`。这样能过，但代码里有个循环，还容易写错边界。

巧办法：把 `s` 复制一遍接在自己后面，得到长度 2n 的长串。这个长串里，任何一个长度为 n 的连续片段，正好对应「从某个位置开始绕一圈」的结果，也就是一次旋转。所以只要在 `s + s` 里查一下 `goal` 在不在就行。

有个前提不能忘：两个字符串长度必须相等。不然 `s = "aa"`、`goal = "a"` 时，`"a"` 确实在 `"aaaa"` 里，但长度都不一样，根本转不出来。

#### ③ 拿一个具体输入走一遍

`s = "abcde"`，`goal = "cdeab"`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 比长度 | `len("abcde")=5`，`len("cdeab")=5` | 长度相同，继续 |
| 拼双倍 | `s + s = "abcdeabcde"` | 长度 10 |
| 查子串 | `"cdeab" in "abcdeabcde"` | 从下标 2 开始正好是 `"cdeab"` |
| 返回 | `True` | 旋转 2 次即可 |

所以答案是 `True`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `len(s) == len(goal)` | 长度不一样，直接不可能 |
| `and` | 两个条件都满足才算真 |
| `goal in s + s` | 在「转两圈」的长串里找 goal |
| `return` | 找到就是 True，找不到就是 False |

### 完整代码（Python）

```python
class Solution:
    def rotateString(self, s: str, goal: str) -> bool:
        return len(s) == len(goal) and goal in s + s
```

## 42-13. 按奇偶排序数组（Easy）

> 力扣 905 · 双指针 · Easy

**一句话**：把所有偶数挪到前面、奇数挪到后面，顺序随意，返回任意一种结果。

### 精讲（零基础版）

#### ① 这题要用到的东西

**快慢指针 + 交换**（快慢指针前面 42-2、交换前面 42-8 讲过）：慢指针指着「下一个偶数的位置」，快指针扫全数组，碰到偶数就换到前面来。这题用它把偶数按原顺序挤到数组前段。

**取模判断奇偶 `x % 2`**（前面 42-10 讲过取模）：余数是 0 就是偶数，是 1 就是奇数。这题里 `nums[fast] % 2 == 0` 就是「这个数是偶数，该往前挪」。

#### ② 大白话：这题到底在干什么

题目只要求偶数都在奇数前面，偶数之间、奇数之间的先后顺序无所谓。

最笨的办法是开两个新列表，一个装偶数一个装奇数，最后拼起来。能过，但多用了内存。

聪明办法：还是快慢指针。慢指针 `slow` 表示「下一个偶数该放的位置」，快指针 `fast` 从头扫。遇到偶数，就把它和 `slow` 位置的元素交换，`slow` 加一。这样所有偶数都会被依次换到前面，剩下的位置自然全是奇数。

#### ③ 拿一个具体输入走一遍

`nums = [3,1,2,4]`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| fast=0 | `nums[0]=3` 是奇数 | 跳过，`slow=0` |
| fast=1 | `nums[1]=1` 是奇数 | 跳过，`slow=0` |
| fast=2 | `nums[2]=2` 是偶数 | 与 `nums[0]` 交换，数组变 `[2,1,3,4]`，`slow=1` |
| fast=3 | `nums[3]=4` 是偶数 | 与 `nums[1]` 交换，数组变 `[2,4,3,1]`，`slow=2` |
| 结束 | `slow=2` | 返回 `[2,4,3,1]` |

所以答案是 `[2,4,3,1]`（题目允许任何合法排列）。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `slow = 0` | 下一个偶数该放的位置 |
| `for fast in range(len(nums)):` | 快指针扫一遍 |
| `if nums[fast] % 2 == 0:` | 这个数是偶数 |
| `nums[slow], nums[fast] = nums[fast], nums[slow]` | 换到前面去 |
| `slow += 1` | 前面已经多了一个偶数 |
| `return nums` | 返回原地改好的数组 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def sortArrayByParity(self, nums: List[int]) -> List[int]:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] % 2 == 0:
                nums[slow], nums[fast] = nums[fast], nums[slow]
                slow += 1
        return nums
```

## 42-14. 连续字符（Easy）

> 力扣 1446 · 字符串 · Easy

**一句话**：找出「只由同一个字符组成」的最长子串有多长。

### 精讲（零基础版）

#### ① 这题要用到的东西

**两个计数器 `cur` 和 `best`**

一句人话：`cur` 记「当前这一段连着几个」，`best` 记「目前为止最多连着几个」。

生活类比：像数跑步连续打卡天数：`cur` 是当前连续天数，`best` 是历史最高纪录。

```python
cur, best = 3, 5
cur += 1
best = max(best, cur)
print(cur, best)      # -> 4 5
```

它在这题里干什么：每走一步更新 `cur`，再用 `max` 刷新 `best`。

**`max(a, b)`**

一句人话：返回两个数里大的那个。

生活类比：两笔账取多的那笔。

```python
print(max(3, 7))      # -> 7
print(max(7, 7))      # -> 7
```

它在这题里干什么：`best = max(best, cur)` 就是「刷新纪录」。

#### ② 大白话：这题到底在干什么

要数「同一个字符连着出现的最长长度」。

从第二个字符开始，一个一个往后看：如果这个字符和前面那个一样，说明这一段还没断，`cur` 加一；如果不一样，说明新的一段开始了，`cur` 归 1。每走一步都把 `cur` 和历史最高纪录 `best` 比一下，取大的。

走完全串，`best` 就是答案。整个过程只扫一遍，不需要记住任何子串内容。

#### ③ 拿一个具体输入走一遍

`s = "abbcccddddeeeeedcba"`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| i=1 | 'b' 与 'a' 不同 | `cur` 归 1，`best=1` |
| i=2 | 'b' 与 'b' 相同 | `cur=2`，`best=2` |
| i=3 | 'c' 与 'b' 不同 | `cur` 归 1，`best=2` |
| i=5 | 'c' 与 'c' 相同 | `cur=3`，`best=3` |
| i=9 | 'd' 与 'd' 相同 | `cur=4`，`best=4` |
| i=14 | 'e' 与 'e' 相同 | `cur=5`，`best=5` |
| i=15 | 'd' 与 'e' 不同 | `cur` 归 1，`best` 仍是 5 |
| 结束 | `best=5` | 返回 5 |

所以答案是 `5`（来自 `"eeeee"`）。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `best = 1; cur = 1` | 至少有一个字符，所以长度至少 1 |
| `for i in range(1, len(s)):` | 从第二个字符开始看 |
| `if s[i] == s[i - 1]:` | 和前面那个一样，这一段还在延续 |
| `cur += 1` | 当前连续长度加一 |
| `else: cur = 1` | 不一样，新的一段从 1 开始 |
| `best = max(best, cur)` | 刷新历史纪录 |
| `return best` | 返回最长的那一段 |

### 完整代码（Python）

```python
class Solution:
    def maxPower(self, s: str) -> int:
        best = 1
        cur = 1
        for i in range(1, len(s)):
            if s[i] == s[i - 1]:
                cur += 1
            else:
                cur = 1
            best = max(best, cur)
        return best
```

## 42-15. Z 字形变换（Medium）

> 力扣 6 · 字符串 · Medium

**一句话**：把字符串按「竖着往下、斜着往上」的路线摆成 Z 字，再一行一行读出来。

### 精讲（零基础版）

#### ① 这题要用到的东西

**用列表存多行字符串**

一句人话：`rows = [''] * numRows` 造出 numRows 个空字符串，`rows[2] += ch` 就是往第 2 行末尾接一个字符。

生活类比：像准备 numRows 个空碗，按规则把每颗豆子丢进对应的碗里。

```python
rows = [''] * 3
rows[0] += 'A'
rows[2] += 'Y'
print(rows)          # -> ['A', '', 'Y']
```

它在这题里干什么：每个元素代表 Z 字的一行，遍历字符串时把字符接到当前行的末尾。

**方向变量 `step`**

一句人话：`step` 只能取 1 或 -1，表示「下一行走下面一行」还是「上面一行」。

生活类比：像电梯的方向箭头，到底层就朝上，到顶层就朝下。

```python
row, step = 0, 1
row += step
print(row)           # -> 1
step = -1
row += step
print(row)           # -> 0
```

它在这题里干什么：控制行号在 0 到 numRows-1 之间来回摆动。

#### ② 大白话：这题到底在干什么

要的是「按 Z 字路线摆好之后，逐行读」。既然最终按行读，那就干脆一开始就按行来收集字符：准备 numRows 个空字符串，一个代表一行。

然后从第一个字符开始，按 Z 字的路线决定这个字符该进哪一行，接在该行末尾。行号走到 0 的时候方向朝下，走到最后一行的时候方向朝上，中间就顺着当前方向走。

全部字符都放好之后，把 numRows 个字符串按顺序接起来，就是答案。

有个特殊情况要提前挡掉：`numRows == 1` 时根本没有拐弯，原样返回；`numRows` 比字符串还长时也一样，每个字符各占一行，读出来还是原串。

#### ③ 拿一个具体输入走一遍

`s = "PAYPALISHIRING"`，`numRows = 3`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| i=0 'P' | 写第 0 行，`step=1`，下一行 1 | `rows = ['P','','']` |
| i=1 'A' | 写第 1 行，`step=1`，下一行 2 | `rows = ['P','A','']` |
| i=2 'Y' | 写第 2 行，到底了，`step=-1`，下一行 1 | `rows = ['P','A','Y']` |
| i=3 'P' | 写第 1 行，`step=-1`，下一行 0 | `rows = ['P','AP','Y']` |
| i=4 'A' | 写第 0 行，到顶了，`step=1`，下一行 1 | `rows = ['PA','AP','Y']` |
| … | 14 个字符按同样规则各就各位 | `rows = ['PAHN','APLSIIG','YIR']` |
| 拼接 | 三行首尾相接 | `"PAHNAPLSIIGYIR"` |

所以答案是 `"PAHNAPLSIIGYIR"`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `if numRows == 1 or numRows >= len(s): return s` | 不会拐弯的情况，原样返回 |
| `rows = [''] * numRows` | 准备 numRows 个空碗 |
| `row = 0; step = 1` | 从第 0 行开始，方向朝下 |
| `for ch in s:` | 每个字符按顺序处理 |
| `rows[row] += ch` | 接到当前行末尾 |
| `if row == 0: step = 1` | 到顶了，改朝下 |
| `elif row == numRows - 1: step = -1` | 到底了，改朝上 |
| `row += step` | 行号按方向走一格 |
| `return ''.join(rows)` | 各行首尾相接 |

### 完整代码（Python）

```python
class Solution:
    def convert(self, s: str, numRows: int) -> str:
        if numRows == 1 or numRows >= len(s):
            return s
        rows = [''] * numRows
        row = 0
        step = 1
        for ch in s:
            rows[row] += ch
            if row == 0:
                step = 1
            elif row == numRows - 1:
                step = -1
            row += step
        return ''.join(rows)
```

## 42-16. 字符串转换整数 (atoi)（Medium）

> 力扣 8 · 字符串 · Medium

**一句话**：按题目规定的顺序——跳空格、读符号、读数字、卡范围——把字符串变成整数。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`s[i].isdigit()`**

一句人话：判断这个字符是不是 '0' 到 '9' 之一。

生活类比：像验票员只看是不是有效票，其它一律不放行。

```python
print('7'.isdigit())     # -> True
print('-'.isdigit())     # -> False
```

它在这题里干什么：数字读到第一个非数字字符就停。

**32 位整数边界 `2 ** 31`**

一句人话：`2**31 = 2147483648`，所以 32 位有符号整数的范围是 `[-2147483648, 2147483647]`。

生活类比：像电梯的承重上限，超了就只能按上限算。

```python
limit = 2 ** 31
print(limit)              # -> 2147483648
print(-limit)             # -> -2147483648
print(limit - 1)          # -> 2147483647
```

它在这题里干什么：最后把结果卡进 `[-limit, limit-1]`。

**累加构造数字 `num = num * 10 + int(ch)`**

一句人话：每读一个新数字，就把之前的结果乘 10 再加新数字，相当于往右接一位。

生活类比：像往一个数后面贴新数字，贴之前先把已有的整体左移一位。

```python
num = 0
for ch in "042":
    num = num * 10 + int(ch)
print(num)               # -> 42
```

它在这题里干什么：一边读一边把数字拼出来，前导零自动被吃掉。

#### ② 大白话：这题到底在干什么

题目把规则写得很死，照着做就行，分四步。

第一步，从前往后把空格全部跳过去，只跳空格，别的都不算。第二步，看下一个字符是不是 `'+'` 或 `'-'`：是 `'-'` 就记下结果是负数，然后把这个符号字符跳过；是 `'+'` 就只跳过它；都不是就当作正数。第三步，从当前位置开始读连续的数字，一边读一边拼成整数，读到非数字字符或者到字符串末尾就停。第四步，如果拼出来的数超出 32 位整数范围，就截断到边界值。

有两个坑：一是符号只认一个，`"+-12"` 读到 `'-'` 之后下一位是 `'+'`，不是数字，所以结果是 0；二是没读到任何数字时结果就是 0。

#### ③ 拿一个具体输入走一遍

`s = " -042"`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| i=0 | `s[0] = ' '` | 前导空格，`i→1` |
| 符号 | `s[1] = '-'` | `sign=-1`，`i→2` |
| 读 '0' | `num = 0*10+0 = 0` | `i→3` |
| 读 '4' | `num = 0*10+4 = 4` | `i→4` |
| 读 '2' | `num = 4*10+2 = 42` | `i→5`，到末尾 |
| 收尾 | `42 * (-1) = -42` | 在范围内，返回 `-42` |

所以答案是 `-42`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `while i < n and s[i] == ' ': i += 1` | 跳过前导空格 |
| `sign = 1` | 默认是正数 |
| `if i < n and s[i] in '+-':` | 看看有没有符号 |
| `if s[i] == '-': sign = -1` | 负号就记下来 |
| `i += 1` | 符号本身也要跳过 |
| `while i < n and s[i].isdigit():` | 一直读数字 |
| `num = num * 10 + int(s[i])` | 往右接一位 |
| `num *= sign` | 把符号补上 |
| `if num < -limit: return -limit` | 超下界就截断 |
| `if num > limit - 1: return limit - 1` | 超上界就截断 |

### 完整代码（Python）

```python
class Solution:
    def myAtoi(self, s: str) -> int:
        i, n = 0, len(s)
        while i < n and s[i] == ' ':
            i += 1
        sign = 1
        if i < n and s[i] in '+-':
            if s[i] == '-':
                sign = -1
            i += 1
        num = 0
        while i < n and s[i].isdigit():
            num = num * 10 + int(s[i])
            i += 1
        num *= sign
        limit = 2 ** 31
        if num < -limit:
            return -limit
        if num > limit - 1:
            return limit - 1
        return num
```

## 42-17. 最接近的三数之和（Medium）

> 力扣 16 · 双指针 · Medium

**一句话**：从数组里挑三个不同位置的数，让它们的和尽量贴近 `target`，返回这个和。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`nums.sort()` 原地排序**

一句人话：`sort()` 直接把列表从小到大排好，不返回新列表。

生活类比：像把一叠牌在桌上摊开、按大小理好，之后找牌就不用乱翻了。

```python
nums = [3, 1, 2]
nums.sort()
print(nums)          # -> [1, 2, 3]
```

它在这题里干什么：排好序之后，才能根据「和偏大还是偏小」决定移动哪个指针。

**`abs(x)` 绝对值**

一句人话：`abs(-5)` 是 5，`abs(3)` 是 3，也就是「离 0 有多远」。

生活类比：不管往左偏还是往右偏，只看偏了多远。

```python
print(abs(-5))       # -> 5
print(abs(3))        # -> 3
print(abs(2 - 1))    # -> 1
```

它在这题里干什么：`abs(total - target)` 就是「这次的和离目标差多远」，用来判断是不是更好了。

**对撞双指针**（前面 42-7 讲过）：先固定第一个数，剩下两个数用左右指针从两端往中间夹。这题用它把三重循环降成两重。

#### ② 大白话：这题到底在干什么

要找三个数，最笨的办法是三重循环把所有组合都试一遍，n 到 1000 时太慢。

聪明办法要先排序。排完之后，固定第一个数（下标 i），剩下的两个数从 i 后面那段的头和尾各取一个。把三个数加起来看看：

和太小了，说明得让它大一点，于是左指针往右挪（右边的数更大）；和太大了，说明得让它小一点，于是右指针往左挪。每挪一次都拿当前和去和「目前最接近的那个和」比一下，谁离 target 更近就记住谁。

这样固定 i 之后只需扫一遍，总体是 O(n²)。如果某次和正好等于 target，那就是最接近的，可以直接返回。

#### ③ 拿一个具体输入走一遍

`nums = [-1,2,1,-4]`，`target = 1`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 排序 | `[-4,-1,1,2]` | 便于双指针夹逼 |
| i=0(-4) | lo=1(-1)，hi=3(2)，和 = -3 | 离 target 差 4，`best=-3`，和偏小，lo 右移 |
| i=0(-4) | lo=2(1)，hi=3(2)，和 = -1 | 差 2，比 4 近，`best=-1`，仍偏小，lo 右移 |
| i=1(-1) | lo=2(1)，hi=3(2)，和 = 2 | 差 1，比 2 近，`best=2` |
| 结束 | `best=2` | 返回 2 |

所以答案是 `2`（-1 + 2 + 1 = 2）。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `nums.sort()` | 先排序 |
| `best = nums[0] + nums[1] + nums[2]` | 先拿前三个数当初始答案 |
| `for i in range(n - 2):` | 固定第一个数 |
| `lo, hi = i + 1, n - 1` | 剩下两个数从后段两头取 |
| `total = nums[i] + nums[lo] + nums[hi]` | 当前三数之和 |
| `if abs(total - target) < abs(best - target): best = total` | 更接近就更新答案 |
| `if total < target: lo += 1` | 和太小，让左边的数变大 |
| `elif total > target: hi -= 1` | 和太大，让右边的数变小 |
| `else: return target` | 正好命中，直接返回 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def threeSumClosest(self, nums: List[int], target: int) -> int:
        nums.sort()
        n = len(nums)
        best = nums[0] + nums[1] + nums[2]
        for i in range(n - 2):
            lo, hi = i + 1, n - 1
            while lo < hi:
                total = nums[i] + nums[lo] + nums[hi]
                if abs(total - target) < abs(best - target):
                    best = total
                if total < target:
                    lo += 1
                elif total > target:
                    hi -= 1
                else:
                    return target
        return best
```

## 42-18. 下一个排列（Medium）

> 力扣 31 · 双指针 · Medium

**一句话**：把数组调成「字典序里紧跟在它后面的那个排列」，必须原地改、只用常数空间。

### 精讲（零基础版）

#### ① 这题要用到的东西

**字典序**

一句人话：把数组当成一个数来比大小，从左往右逐位比，第一位大的就大。

生活类比：像字典里查单词，先比第一个字母，第一个字母相同再比第二个。

```python
print([1, 2, 3] < [1, 3, 2])    # -> True
print([3, 2, 1] > [2, 9, 9])    # -> True
```

它在这题里干什么：题目要的就是「比当前排列大的最小排列」，也就是字典序紧邻的下一个。

**原地反转一段**

一句人话：用左右两个指针往中间换，把一段区间倒过来。

生活类比：像把一列车厢的顺序整段调头。

```python
nums = [1, 2, 3]
lo, hi = 0, 2
while lo < hi:
    nums[lo], nums[hi] = nums[hi], nums[lo]
    lo += 1
    hi -= 1
print(nums)      # -> [3, 2, 1]
```

它在这题里干什么：找到拐点后，把后半段（它一定是降序的）反转成升序，得到最小后缀。

#### ② 大白话：这题到底在干什么

要找「比现在大一点点的下一个排列」。想让数变大，必须把某个靠右的数和它右边一个更大的数交换。但换完还得保证「变大的幅度尽量小」。

思路分三步。

第一步，从右往左找第一个「比右边邻居小」的位置 i。这说明从 i 往右是一路递减的，已经是这段能组成的最大排列，没法再靠右边变大了，必须动 i 这一位。如果根本找不到这样的 i（整个数组一路递减，比如 `[3,2,1]`），说明它已经是最大排列，那就整体反转成升序，回到最小。

第二步，从右往左找第一个比 `nums[i]` 大的数 j，把 i 和 j 交换。因为 i 右边是递减的，从右往左找的第一个更大值就是「比 nums[i] 大的里面最小的那个」。

第三步，交换之后 i 右边仍然是递减的，把它反转成递增，就是这段能组成的最小排列。三步合起来，正好是「紧邻的下一个」。

#### ③ 拿一个具体输入走一遍

`nums = [1,2,3]`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 找拐点 | `i=1`，`nums[1]=2` 小于 `nums[2]=3` | 停在这里，`i=1` |
| 找交换对象 | 从右往左第一个大于 `nums[1]=2` 的是 `j=2`（值 3） | 交换后 `[1,3,2]` |
| 反转后缀 | 后缀从 `i+1=2` 到末尾，只有 1 个元素 | 不用动 |
| 结束 | `[1,3,2]` | 返回 |

所以答案是 `[1,3,2]`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `i = n - 2` | 从倒数第二位开始往左找 |
| `while i >= 0 and nums[i] >= nums[i+1]: i -= 1` | 一路递减就继续往左 |
| `if i >= 0:` | 找到了能变大的位置 |
| `j = n - 1` | 从最右边开始找 |
| `while nums[j] <= nums[i]: j -= 1` | 找到第一个比 nums[i] 大的 |
| `nums[i], nums[j] = nums[j], nums[i]` | 交换 |
| `lo, hi = i + 1, n - 1` | 后缀区间 |
| `while lo < hi: 交换; lo += 1; hi -= 1` | 把后缀反转成升序 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def nextPermutation(self, nums: List[int]) -> None:
        n = len(nums)
        i = n - 2
        while i >= 0 and nums[i] >= nums[i + 1]:
            i -= 1
        if i >= 0:
            j = n - 1
            while nums[j] <= nums[i]:
                j -= 1
            nums[i], nums[j] = nums[j], nums[i]
        lo, hi = i + 1, n - 1
        while lo < hi:
            nums[lo], nums[hi] = nums[hi], nums[lo]
            lo += 1
            hi -= 1
```

## 42-19. 字符串相乘（Medium）

> 力扣 43 · 字符串 · Medium

**一句话**：两个数字字符串相乘，结果也用字符串表示，不许直接转成整数。

### 精讲（零基础版）

#### ① 这题要用到的东西

**竖式乘法**

一句人话：把两个数上下对齐，下面每一位依次乘上面每一位，结果错位相加。

生活类比：就是小学算 123×456 的竖式，一位一位算、往左错位。

```python
# 123 * 456 的竖式核心：逐位相乘后按位置累加
print(3 * 6)      # -> 18
print(3 * 5)      # -> 15
print(2 * 4)      # -> 8
```

它在这题里干什么：`num1[i] * num2[j]` 就是竖式里的一步。

**数位数组 + 位置规律 `i + j`、`i + j + 1`**

一句人话：结果最多 `m + n` 位，`num1[i]` 和 `num2[j]` 相乘的结果，个位落在 `i+j+1`，进位落在 `i+j`。

生活类比：像往一个固定长度的小格子里记数，每一位有它固定的位置，不会串位。

```python
m, n = 3, 3
res = [0] * (m + n)
print(len(res))          # -> 6
i, j = 2, 2
print(i + j, i + j + 1)  # -> 4 5
```

它在这题里干什么：算出每个乘积该写进 `res` 的哪个下标。

#### ② 大白话：这题到底在干什么

题目不让转成整数再乘，那就只能模拟竖式。

准备一个长度 `m + n` 的数组 `res`，先全填 0，用来存结果的每一位。然后两层循环，把 `num1` 的每一位和 `num2` 的每一位都乘一遍。每次乘积加上「目标位置上原来的数」，个位留在 `i+j+1`，十位（进位）加到 `i+j` 上。

为什么是这两个下标？因为 `num1[i]` 实际代表 `num1[i] × 10^(m-1-i)`，`num2[j]` 代表 `num2[j] × 10^(n-1-j)`，乘起来是 10 的 `(m-1-i)+(n-1-j)` 次方。而 `res` 从后往前数的位置正好对应，化简后就是个位在 `i+j+1`、进位在 `i+j`。

最后把 `res` 开头连续的 0 去掉，剩下的数字拼成字符串。两个数里只要有一个是 "0"，直接返回 "0"。

#### ③ 拿一个具体输入走一遍

`num1 = "123"`，`num2 = "456"`，`res` 长度 6：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 3×6=18 | `p1=4`，`p2=5` | `res[5]=8`，进位 1 加到 `res[4]`，`res=[0,0,0,0,1,8]` |
| 3×5=15 | `p1=3`，`p2=4`，`res[4]` 已有 1，合计 16 | `res[4]=6`，进位 1 加到 `res[3]`，`res=[0,0,0,1,6,8]` |
| 3×4=12 | `p1=2`，`p2=3`，`res[3]` 已有 1，合计 13 | `res[3]=3`，进位 1 加到 `res[2]`，`res=[0,0,1,3,6,8]` |
| 2×6=12 | `p1=3`，`p2=4`，`res[4]=6`，合计 18 | `res[4]=8`，进位 1 加到 `res[3]`，`res=[0,0,1,4,8,8]` |
| … 9 轮走完 | `res = [0,5,6,0,8,8]` | 去掉前导 0 |
| 拼接 | `"56088"` | 返回 |

所以答案是 `"56088"`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `if num1 == '0' or num2 == '0': return '0'` | 有 0 直接返回 0 |
| `res = [0] * (m + n)` | 结果最多 m+n 位 |
| `for i in range(m-1, -1, -1):` | 从 num1 的最低位往高位 |
| `for j in range(n-1, -1, -1):` | 从 num2 的最低位往高位 |
| `mul = int(num1[i]) * int(num2[j])` | 竖式的一步乘积 |
| `p1, p2 = i + j, i + j + 1` | 进位位和个位分别落在哪 |
| `total = mul + res[p2]` | 加上这一位原来的数 |
| `res[p2] = total % 10` | 个位留下 |
| `res[p1] += total // 10` | 十位加到进位位 |
| `while res[k] == 0: k += 1` | 跳过前导 0 |
| `return ''.join(str(d) for d in res[k:])` | 拼成字符串 |

### 完整代码（Python）

```python
class Solution:
    def multiply(self, num1: str, num2: str) -> str:
        if num1 == '0' or num2 == '0':
            return '0'
        m, n = len(num1), len(num2)
        res = [0] * (m + n)
        for i in range(m - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                mul = int(num1[i]) * int(num2[j])
                p1, p2 = i + j, i + j + 1
                total = mul + res[p2]
                res[p2] = total % 10
                res[p1] += total // 10
        k = 0
        while k < len(res) and res[k] == 0:
            k += 1
        return ''.join(str(d) for d in res[k:])
```

## 42-20. 颜色分类（Medium）

> 力扣 75 · 双指针 · Medium

**一句话**：数组里只有 0、1、2 三种数，一趟扫描把它们排成 0…0 1…1 2…2。

### 精讲（零基础版）

#### ① 这题要用到的东西

**三指针（荷兰国旗问题）**

一句人话：用三个下标把数组切成四段：`[0, lo)` 全是 0，`[lo, cur)` 全是 1，`[cur, hi]` 还没看，`(hi, n-1]` 全是 2。

生活类比：像把一堆红白蓝三色球分到三个筐里，左手边红筐、右手边蓝筐，中间留一块待分区。

```python
nums = [2, 0, 1]
lo, cur, hi = 0, 0, 2
print(nums[lo], nums[cur], nums[hi])   # -> 2 2 1
```

它在这题里干什么：`lo` 是 0 区的右边界，`hi` 是 2 区的左边界，`cur` 是当前检查的位置。

**为什么碰到 2 时 `cur` 不前进**

一句人话：和 `hi` 交换之后，换到 `cur` 位置上的数是从未检查区拿来的，还没看过，得再看一遍。

生活类比：像从待处理筐里随手抓一个放到当前位置，抓来的这个还没分类，不能跳过。

```python
nums = [2, 0, 1]
cur, hi = 0, 2
nums[cur], nums[hi] = nums[hi], nums[cur]
print(nums)        # -> [1, 0, 2]
```

它在这题里干什么：交换 2 之后 `cur` 留在原地，下一轮重新判断这个新来的数。

#### ② 大白话：这题到底在干什么

只有三种值，所以不需要真的排序，只要把它们分到三个区。

维护三个下标：`lo` 指向「0 区后面第一个位置」，`hi` 指向「2 区前面最后一个位置」，`cur` 是当前正在看的格子。

看 `nums[cur]`：如果是 0，就把它和 `nums[lo]` 交换，`lo` 和 `cur` 都往后挪——因为换过来的是 1 区末尾的数，已经归好类了。如果是 2，就把它和 `nums[hi]` 交换，`hi` 往前挪，`cur` 不动——因为换过来的是没检查过的数。如果是 1，本来就该待在中间，`cur` 直接往后挪。

当 `cur` 越过 `hi` 时，待检查区空了，数组就排好了。整个过程只扫一遍，只用了三个整数。

#### ③ 拿一个具体输入走一遍

`nums = [2,0,2,1,1,0]`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| cur=0 | `nums[0]=2` | 与 `hi=5` 交换，变 `[0,0,2,1,1,2]`，`hi=4`，`cur` 不动 |
| cur=0 | `nums[0]=0` | 与 `lo=0` 交换（原地），`lo=1`，`cur=1` |
| cur=1 | `nums[1]=0` | 与 `lo=1` 交换（原地），`lo=2`，`cur=2` |
| cur=2 | `nums[2]=2` | 与 `hi=4` 交换，变 `[0,0,1,1,2,2]`，`hi=3` |
| cur=2 | `nums[2]=1` | 该在中间，`cur=3` |
| cur=3 | `nums[3]=1` | 该在中间，`cur=4`，已越过 `hi=3` |
| 结束 | `[0,0,1,1,2,2]` | 返回 |

所以答案是 `[0,0,1,1,2,2]`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `lo, cur, hi = 0, 0, len(nums) - 1` | 三个指针的初始位置 |
| `while cur <= hi:` | 待检查区还有元素 |
| `if nums[cur] == 0:` | 这是 0，该去左边 |
| `nums[lo], nums[cur] = nums[cur], nums[lo]` | 换到 0 区末尾 |
| `lo += 1; cur += 1` | 两个指针都往后 |
| `elif nums[cur] == 2:` | 这是 2，该去右边 |
| `nums[cur], nums[hi] = nums[hi], nums[cur]` | 换到 2 区开头 |
| `hi -= 1` | 只有 hi 往前，cur 不动 |
| `else: cur += 1` | 是 1，原地不动 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def sortColors(self, nums: List[int]) -> None:
        lo, cur, hi = 0, 0, len(nums) - 1
        while cur <= hi:
            if nums[cur] == 0:
                nums[lo], nums[cur] = nums[cur], nums[lo]
                lo += 1
                cur += 1
            elif nums[cur] == 2:
                nums[cur], nums[hi] = nums[hi], nums[cur]
                hi -= 1
            else:
                cur += 1
```

## 42-21. 删除有序数组中的重复项 II（Medium）

> 力扣 80 · 双指针 · Medium

**一句话**：有序数组里每个不同的数最多留两份，原地改，返回新的长度。

### 精讲（零基础版）

#### ① 这题要用到的东西

**快慢指针**（前面 42-2 讲过）：慢指针指向「下一个写入位置」，快指针扫全数组。这题的关键改动是——比较对象不是「上一个保留值」，而是「往前数第 2 个保留值」。

**`nums[slow - 2]` 这个判断为什么够用**

一句人话：数组是有序的，所以只要 `nums[fast]` 不等于往前数第 2 个保留值，它就一定是个新值或者第 2 次出现，可以留。

生活类比：排队时规定「同一家人最多进两个」。你要进门前，只要看看队伍末尾往前数第二个人是不是你家人就行——如果是，说明你家已经进了至少两个。

```python
nums = [1, 1, 2, 2, 2, 3]
slow = 4
print(nums[slow - 2], nums[2])   # -> 2 2
```

它在这题里干什么：`if nums[fast] != nums[slow - 2]` 是这题唯一的判断条件。

#### ② 大白话：这题到底在干什么

上一题（42-2）要求每个数只留一份，判断方法是「跟最后一个保留值比」。这题允许留两份，判断就得往前多看一格。

做法：前两个元素无论如何都保留（同一个数最多两份），所以慢指针从 2 开始。快指针从下标 2 开始扫。每看一个元素，就跟「已保留部分往前数第 2 个」比一比：不相等，说明这个数还没到两份，可以写进去；相等，说明这个数已经有两份了，跳过。

因为数组有序，相同的数一定连在一起，所以这个判断是可靠的。扫完之后，前 `slow` 个位置就是答案。

#### ③ 拿一个具体输入走一遍

`nums = [1,1,1,2,2,3]`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 起始 | `slow=2`，`nums=[1,1,1,2,2,3]` | 前两个天然保留 |
| fast=2 | `nums[2]=1` 等于 `nums[0]=1` | 这个 1 已经是第三份，跳过，`slow=2` |
| fast=3 | `nums[3]=2` 不等于 `nums[1]=1` | 写 `nums[2]=2`，`slow=3`，数组变 `[1,1,2,2,2,3]` |
| fast=4 | `nums[4]=2` 不等于 `nums[1]=1` | 写 `nums[3]=2`，`slow=4` |
| fast=5 | `nums[5]=3` 不等于 `nums[2]=2` | 写 `nums[4]=3`，`slow=5`，数组变 `[1,1,2,2,3,3]` |
| 结束 | 返回 5 | 前五位 `[1,1,2,2,3]` |

所以答案是 `k = 5`，`nums` 前五位是 `[1,1,2,2,3]`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `if len(nums) <= 2: return len(nums)` | 不超过两个元素，全留 |
| `slow = 2` | 前两个一定保留 |
| `for fast in range(2, len(nums)):` | 从第三个开始扫 |
| `if nums[fast] != nums[slow - 2]:` | 跟已保留部分往前第 2 个比 |
| `nums[slow] = nums[fast]` | 不一样就写进去 |
| `slow += 1` | 写入位置后移 |
| `return slow` | 新长度 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        if len(nums) <= 2:
            return len(nums)
        slow = 2
        for fast in range(2, len(nums)):
            if nums[fast] != nums[slow - 2]:
                nums[slow] = nums[fast]
                slow += 1
        return slow
```

## 42-22. 反转字符串中的单词（Medium）

> 力扣 151 · 双指针 · Medium

**一句话**：把句子里的单词顺序倒过来，单词之间的多余空格压成一个。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`s.split()` 不带参数**

一句人话：`split()` 不写参数时，会按「任意长度的空白」切分，并且自动丢掉开头和结尾的空格。

生活类比：像把一句话按空格撕成纸条，顺手把撕出来的空白纸条扔掉。

```python
s = "  a  b c  "
print(s.split())         # -> ['a', 'b', 'c']
print("a b".split(' '))  # -> ['a', 'b']
```

它在这题里干什么：一步就搞定「去掉多余空格 + 拆成单词列表」。

**`列表.reverse()` 和 `' '.join(列表)`**

一句人话：`reverse()` 把列表顺序倒过来（原地改，不返回值）；`join` 用指定的连接符把一串字符串拼成一个。

生活类比：`reverse` 像把一叠纸翻个面，`join` 像用胶水把纸条按顺序粘成一条。

```python
words = ['a', 'b', 'c']
words.reverse()
print(words)                 # -> ['c', 'b', 'a']
print(' '.join(words))       # -> c b a
```

它在这题里干什么：倒转单词顺序，再用单个空格拼回去。

#### ② 大白话：这题到底在干什么

题目要求：单词顺序倒过来，单词之间只留一个空格，前后不留空格。

最笨的办法是手动扫字符串找每个单词的起止位置，处理各种连续空格、前导空格、尾随空格——很容易漏情况。

Python 里有个现成的省事路子：`split()` 不带参数时，正好就是「按任意空白切开并丢掉空串」，多余空格问题一次解决。切出来的列表里每个元素就是一个单词。把这个列表反转，再用单个空格 `join` 起来，答案就出来了。

需要注意的是不能用 `split(' ')`：那样连续两个空格会切出一个空字符串，拼回去就多出空格了。

#### ③ 拿一个具体输入走一遍

`s = "  hello world  "`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| `split()` | `['hello', 'world']` | 前后空格自动丢掉，切成两个单词 |
| `reverse()` | `['world', 'hello']` | 单词顺序倒过来 |
| `' '.join()` | `"world hello"` | 用单个空格连接 |
| 返回 | `"world hello"` | 无前导、无尾随空格 |

所以答案是 `"world hello"`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `words = s.split()` | 按空白切分，顺手去掉多余空格 |
| `words.reverse()` | 单词顺序倒过来 |
| `return ' '.join(words)` | 用单个空格拼成一句话 |

### 完整代码（Python）

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        words = s.split()
        words.reverse()
        return ' '.join(words)
```

## 42-23. 最大数（Medium）

> 力扣 179 · 字符串 · Medium

**一句话**：把一组非负整数重新排序拼成一个字符串，让拼出来的数最大。

### 精讲（零基础版）

#### ① 这题要用到的东西

**自定义排序 `cmp_to_key`**

一句人话：`sort()` 默认按大小排，想按自己的规则排，就传 `key=cmp_to_key(比较函数)`，比较函数返回负数表示 a 排前面、正数表示 b 排前面。

生活类比：像给排队的人定一条临时规矩：「谁站前面更合适就谁站前面」，而不是按身高体重。

```python
from functools import cmp_to_key


def cmp(a, b):
    if a + b > b + a:
        return -1
    if a + b < b + a:
        return 1
    return 0


nums = ['3', '30']
nums.sort(key=cmp_to_key(cmp))
print(nums)      # -> ['3', '30']
```

它在这题里干什么：比较规则不是「谁大谁在前」，而是「谁拼在前面得到的数更大」。

**为什么比较 `a+b` 和 `b+a`**

一句人话：两个数谁排前面，就看「a 在前」和「b 在前」哪个拼出来更大。

生活类比：两件家具，试试先放哪件能塞得更满，就按那个顺序放。

```python
a, b = "3", "30"
print(a + b, b + a)      # -> 330 303
print(a + b > b + a)     # -> True
```

它在这题里干什么：这就是比较函数的核心判断，能保证排序结果拼起来最大。

#### ② 大白话：这题到底在干什么

直觉上会觉得「数字大的放前面」，但这样是错的：`[3, 30]` 按数字排是 30 在前，拼出来 "303"；而 3 在前拼出来是 "330"，更大。

所以比较规则要换：对于两个数 a 和 b，把 a 拼在 b 前面得到 `a+b`，把 b 拼在 a 前面得到 `b+a`，哪个大就按哪个顺序排。这个规则有个好处：它是可传递的，所以能直接交给排序函数用。

排序完之后按顺序拼接就是答案。还有一个坑：如果所有数都是 0，拼出来是 "000…"，得返回单个 "0"。

#### ③ 拿一个具体输入走一遍

`nums = [3,30,34,5,9]`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 比 '3' 与 '30' | `"330"` 对 `"303"` | `"330"` 更大，'3' 排前面 |
| 比 '3' 与 '34' | `"334"` 对 `"343"` | `"343"` 更大，'34' 排前面 |
| 比 '5' 与 '9' | `"59"` 对 `"95"` | `"95"` 更大，'9' 排前面 |
| 排序完成 | `['9','5','34','3','30']` | 按自定义规则排好 |
| 拼接 | `"9534330"` | 返回 |

所以答案是 `"9534330"`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `strs = [str(x) for x in nums]` | 全部转成字符串，方便拼接比较 |
| `def cmp(a, b):` | 自定义比较规则 |
| `if a + b > b + a: return -1` | a 排前面拼出来更大，a 在前 |
| `if a + b < b + a: return 1` | 反过来，b 在前 |
| `return 0` | 拼出来一样大，谁前谁后都行 |
| `strs.sort(key=cmp_to_key(cmp))` | 按这个规则排序 |
| `ans = ''.join(strs)` | 拼成最终字符串 |
| `return '0' if ans[0] == '0' else ans` | 全是 0 时只返回一个 "0" |

### 完整代码（Python）

```python
from typing import List
from functools import cmp_to_key


class Solution:
    def largestNumber(self, nums: List[int]) -> str:
        strs = [str(x) for x in nums]

        def cmp(a: str, b: str) -> int:
            if a + b > b + a:
                return -1
            if a + b < b + a:
                return 1
            return 0

        strs.sort(key=cmp_to_key(cmp))
        ans = ''.join(strs)
        return '0' if ans[0] == '0' else ans
```

## 42-24. 轮转数组（Medium）

> 力扣 189 · 双指针 · Medium

**一句话**：把数组整体往右挪 k 格，超出末尾的绕回开头，必须原地做。

### 精讲（零基础版）

#### ① 这题要用到的东西

**取模 `k % n`**（前面 42-10 讲过取模）：挪 n 格等于没挪，所以先把 k 缩到 `0 ~ n-1` 之间。这题里写一句 `k %= n` 就完成了这次收缩，防止 k 比数组还长时越界。

**三次反转**

一句人话：把整段倒过来，再把前 k 个倒回来，再把后面 n-k 个倒回来，就完成了右移。

生活类比：像把一叠牌上下颠倒，再把上半叠和下半叠分别颠倒，牌的顺序就正好循环移动了。

```python
nums = [1, 2, 3, 4, 5]
nums.reverse()
print(nums)              # -> [5, 4, 3, 2, 1]
nums[:2] = reversed(nums[:2])
print(nums)              # -> [4, 5, 3, 2, 1]
```

它在这题里干什么：不用额外数组，只靠反复交换就能完成整体位移。

#### ② 大白话：这题到底在干什么

把数组往右推 k 格，末尾的元素会绕到开头。

最笨的办法是开一个同样大的新数组，把每个元素按 `(i+k) % n` 放到新位置，再复制回来。能过，但多用了 O(n) 空间。

不用额外空间的办法是三次反转。第一步，把整个数组反转，此时原来的末尾元素跑到最前面了，顺序全乱。第二步，反转前 k 个元素，把这 k 个内部顺序恢复。第三步，反转剩下的 n-k 个，把它们内部顺序也恢复。三步做完，整体就是右移 k 格的结果。

为什么对？把数组看成 A、B 两段，其中 B 是要挪到前面的那 k 个。反转整个得到 `rev(B) rev(A)`，再分别反转就得到 `B A`，正是右移的结果。

#### ③ 拿一个具体输入走一遍

`nums = [1,2,3,4,5,6,7]`，`k = 3`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 第一次反转 | `[7,6,5,4,3,2,1]` | 整体掉头 |
| 第二次反转 | 前 3 个 → `[5,6,7,4,3,2,1]` | 要挪到前面的那 3 个内部恢复顺序 |
| 第三次反转 | 后 4 个 → `[5,6,7,1,2,3,4]` | 剩下的部分内部恢复顺序 |
| 结束 | `[5,6,7,1,2,3,4]` | 返回 |

所以答案是 `[5,6,7,1,2,3,4]`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `n = len(nums)` | 数组长度 |
| `k %= n` | 挪 n 格等于没挪，先缩到有效范围 |
| `def rev(lo, hi):` | 小工具：反转区间 lo..hi |
| `while lo < hi: 交换; lo += 1; hi -= 1` | 两头往中间换 |
| `rev(0, n - 1)` | 整体反转 |
| `rev(0, k - 1)` | 前 k 个反转回来 |
| `rev(k, n - 1)` | 后 n-k 个反转回来 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        n = len(nums)
        k %= n

        def rev(lo: int, hi: int) -> None:
            while lo < hi:
                nums[lo], nums[hi] = nums[hi], nums[lo]
                lo += 1
                hi -= 1

        rev(0, n - 1)
        rev(0, k - 1)
        rev(k, n - 1)
```

## 42-25. 最大单词长度乘积（Medium）

> 力扣 318 · 字符串 · Medium

**一句话**：挑两个单词，要求它们没有共同的字母，让长度乘积最大。

### 精讲（零基础版）

#### ① 这题要用到的东西

**位掩码（bitmask）**

一句人话：用一个整数的二进制位表示「某个字母出现过没有」，第 0 位代表 'a'，第 1 位代表 'b'，依此类推。

生活类比：像一排 26 个开关，单词里出现过的字母就把对应开关打开，26 个开关的状态压缩成一个数字。

```python
mask = 0
for ch in "abc":
    mask |= 1 << (ord(ch) - ord('a'))
print(mask)          # -> 7
print(bin(mask))     # -> 0b111
```

它在这题里干什么：每个单词算一个 mask，后面比「有没有公共字母」就变成比 mask。

**`<<`、`|`、`&`**

一句人话：`1 << k` 是把 1 的二进制左移 k 位（等于 2 的 k 次方），`|` 是按位或（有 1 就 1），`&` 是按位与（都是 1 才 1）。

生活类比：`|` 像把两个开关面板合并，谁亮就亮；`&` 像找出两个面板上「同时亮着」的开关。

```python
print(1 << 3)        # -> 8
print(0b101 | 0b010) # -> 7
print(7 & 8)         # -> 0
print(7 & 3)         # -> 3
```

它在这题里干什么：`masks[i] & masks[j] == 0` 就说明两个单词没有共同字母。

#### ② 大白话：这题到底在干什么

要挑两个单词，检查它们有没有重复字母，再算长度乘积取最大。

最笨的办法是两两配对，每一对都逐个字母去比对，最坏情况下很慢。

换个角度：一个单词里有哪些字母，可以压缩成一个 26 位的「开关板」。两个单词没有共同字母，等价于它们的开关板没有任何一位同时亮着——也就是两个数按位与等于 0。

于是流程变成：先把每个单词的开关板算出来存好，然后两两配对，只要按位与是 0 就说明合格，用长度乘积去刷新最大值。位运算一步就能判断，比逐字母比快得多。

#### ③ 拿一个具体输入走一遍

`words = ["abcw","baz","foo","bar","xtfn","abcdef"]`：

| 单词 | mask（十进制） | 二进制 |
| --- | --- | --- |
| `"abcw"` | 4194311 | `0b10000000000000000000111` |
| `"xtfn"` | 8921120 | `0b100010000010000000100000` |
| 两者 `&` | 0 | 没有公共字母，乘积 4×4 = 16 |
| `"foo"` | 16416 | `0b100000000100000` |
| 最终 best | 16 | 返回 16 |

所以答案是 `16`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `masks = []` | 存每个单词的开关板 |
| `for ch in w: mask \|= 1 << (ord(ch) - ord('a'))` | 出现的字母把对应位点亮 |
| `for i in range(len(words)):` | 第一个单词 |
| `for j in range(i + 1, len(words)):` | 第二个单词，只往后取避免重复配对 |
| `if masks[i] & masks[j] == 0:` | 没有共同字母 |
| `best = max(best, len(words[i]) * len(words[j]))` | 刷新最大乘积 |
| `return best` | 一个都没有就是 0 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def maxProduct(self, words: List[str]) -> int:
        masks = []
        for w in words:
            mask = 0
            for ch in w:
                mask |= 1 << (ord(ch) - ord('a'))
            masks.append(mask)
        best = 0
        for i in range(len(words)):
            for j in range(i + 1, len(words)):
                if masks[i] & masks[j] == 0:
                    best = max(best, len(words[i]) * len(words[j]))
        return best
```

## 42-26. 通过删除字母匹配到字典里最长单词（Medium）

> 力扣 524 · 双指针 · Medium

**一句话**：从字典里挑一个能由 `s` 删掉一些字母得到的词，要最长；一样长就取字母序最小的。

### 精讲（零基础版）

#### ① 这题要用到的东西

**子序列判断**

一句人话：一个词是 `s` 的子序列，意思是能在 `s` 里从左往右按顺序找到它的每个字母，不要求连续。

生活类比：像在一条长队伍里点名，只要被点到的人前后顺序对得上，中间夹着别人也没关系。

```python
s = "abpcplea"
word = "apple"
k = 0
for ch in s:
    if k < len(word) and ch == word[k]:
        k += 1
print(k, k == len(word))     # -> 5 True
```

它在这题里干什么：`k` 走到 `len(word)` 就说明这个词能从 `s` 删字母得到。

**字符串比大小（字典序）**（字典序的思想前面 42-18 讲过）：两个字符串用 `<`、`>` 比，是按字符从左往右逐个比，谁先出现更小的字符谁就小，`"apple" < "plea"` 为 True 就是这个道理。这题在长度相同时用 `w < best` 挑字母序更小的那个。
#### ② 大白话：这题到底在干什么

对字典里每个词，判断它能不能从 `s` 里「删字母」得到，也就是它是不是 `s` 的子序列。在所有合格的词里挑最长，长度一样挑字母序最小。

判断子序列不用复杂算法：拿一个指针指着单词开头，从前往后扫 `s`，扫到的字符如果正好等于指针指着的那个字母，指针就往后挪一格。扫完 `s` 之后，指针走到单词末尾就说明匹配成功。

挑最优的时候有两条规则要同时满足：长度更大就替换；长度相等但字母序更小也替换。这两条不能写反，否则会挑错。

#### ③ 拿一个具体输入走一遍

`s = "abpcplea"`，`dictionary = ["ale","apple","monkey","plea"]`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| `"ale"` | 在 `s` 里按顺序找到 a、l、e | 是子序列，`best = "ale"` |
| `"apple"` | 按顺序找到 a、p、p、l、e | 是子序列，长度 5 > 3，`best = "apple"` |
| `"monkey"` | 找不到 m | 不是子序列，跳过 |
| `"plea"` | 是子序列，长度 4 | 不比 5 长，`best` 不变 |
| 结束 | `best = "apple"` | 返回 |

所以答案是 `"apple"`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `def sub(word):` | 小工具：判断 word 是不是 s 的子序列 |
| `k = 0` | 单词里匹配到第几个字母 |
| `for ch in s:` | 扫一遍 s |
| `if k < len(word) and ch == word[k]: k += 1` | 对上了就往前走一格 |
| `return k == len(word)` | 整个单词都匹配上了 |
| `if sub(w) and (len(w) > len(best) or ...)` | 是子序列，且更长 |
| `(len(w) == len(best) and w < best)` | 或者一样长但字母序更小 |
| `best = w` | 替换当前最优 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def findLongestWord(self, s: str, dictionary: List[str]) -> str:
        def sub(word: str) -> bool:
            k = 0
            for ch in s:
                if k < len(word) and ch == word[k]:
                    k += 1
            return k == len(word)

        best = ''
        for w in dictionary:
            if sub(w) and (len(w) > len(best) or (len(w) == len(best) and w < best)):
                best = w
        return best
```

## 42-27. 求解方程（Medium）

> 力扣 640 · 字符串 · Medium

**一句话**：解析一个只含 `x` 和整数的一次方程，解出 `x`，按题目规定的三种结果返回。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`split('=')` 切成左右两边**（`split` 前面 42-22 讲过）：按 `'='` 把方程切成两段字符串，左边一段右边一段，`"x+5-3+x=6+x-2".split('=')` 得到 `['x+5-3+x', '6+x-2']`。这题用它把方程拆成两个式子，各自算出「x 的系数」和「常数」。

**`s.replace('-', '+-')` 把减号变成加负数**（前面 42-10 讲过 `replace`）：把 `-` 换成 `+-`，整条式子就只剩加法，可以统一按 `'+'` 切开。这题用它把每一项都变成「带符号的一项」，要么是 `x`、`-x`、`3x`，要么是纯数字，分类处理很容易。

**一次方程移项**

一句人话：`a1x + b1 = a2x + b2` 移项得 `(a1-a2)x = b2-b1`，再除一下就得到 x。

生活类比：天平两边同时拿掉同样的东西，等式仍然成立。

```python
a1, b1 = 2, 2
a2, b2 = 1, 4
print(a1 - a2, b2 - b1)     # -> 1 2
```

它在这题里干什么：`a = a1-a2` 是 x 的总系数，`b = b2-b1` 是常数，`x = b / a`。

#### ② 大白话：这题到底在干什么

要把字符串形式的方程解出来，分三步。

第一步，按 `'='` 把方程切成左右两边。第二步，分别解析每一边：把 `-` 换成 `+-` 之后按 `+` 切开，每一项要么带 `x`（把系数累加到 a），要么是纯数字（累加到 b）。这里有个细节：`x` 前面没数字就是系数 1，`-x` 是系数 -1。第三步，把两边的 a、b 合起来：x 的系数是左减右，常数是右减左。

然后判断：如果 x 的系数是 0，那就要看常数——常数也是 0 说明任何 x 都成立（无限解），常数不是 0 说明无解。系数不为 0 时，用常数除以系数得到 x；题目保证有唯一解时 x 是整数，除不尽就返回无解。

#### ③ 拿一个具体输入走一遍

`equation = "x+5-3+x=6+x-2"`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 切两边 | `left="x+5-3+x"`，`right="6+x-2"` | 按 `=` 分开 |
| 解析左边 | 变成 `"x+5+-3+x"`，切出 `['x','5','-3','x']` | x 系数 2，常数 2 |
| 解析右边 | 变成 `"6+x+-2"`，切出 `['6','x','-2']` | x 系数 1，常数 4 |
| 移项 | `(2-1)x = 4-2` | 得到 `1x = 2` |
| 求解 | `x = 2 / 1 = 2` | 返回 `"x=2"` |

所以答案是 `"x=2"`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `left, right = equation.split('=')` | 切成左右两个式子 |
| `side = side.replace('-', '+-')` | 减号改写成加负数 |
| `for tok in side.split('+'):` | 一项一项处理 |
| `if not tok: continue` | 空串跳过 |
| `if tok.endswith('x'):` | 这是带 x 的项 |
| `coef = tok[:-1]` | 去掉 x 剩下的系数部分 |
| `if coef in ('', '+'): a += 1` | 没数字就是系数 1 |
| `elif coef == '-': a -= 1` | 单独一个负号就是 -1 |
| `a, b = a1 - a2, b2 - b1` | 移项：系数左减右，常数右减左 |
| `if a == 0: return 'Infinite solutions' if b == 0 else 'No solution'` | 系数为 0 的两种情况 |
| `if b % a != 0: return 'No solution'` | 除不尽说明不是整数解 |
| `return 'x=' + str(b // a)` | 拼成答案 |

### 完整代码（Python）

```python
class Solution:
    def solveEquation(self, equation: str) -> str:
        left, right = equation.split('=')

        def parse(side: str):
            side = side.replace('-', '+-')
            a = b = 0
            for tok in side.split('+'):
                if not tok:
                    continue
                if tok.endswith('x'):
                    coef = tok[:-1]
                    if coef in ('', '+'):
                        a += 1
                    elif coef == '-':
                        a -= 1
                    else:
                        a += int(coef)
                else:
                    b += int(tok)
            return a, b

        a1, b1 = parse(left)
        a2, b2 = parse(right)
        a, b = a1 - a2, b2 - b1
        if a == 0:
            return 'Infinite solutions' if b == 0 else 'No solution'
        if b % a != 0:
            return 'No solution'
        return 'x=' + str(b // a)
```

## 42-28. 情感丰富的文字（Medium）

> 力扣 809 · 双指针 · Medium

**一句话**：一个词能不能靠「把某些连续字母组拉长到 3 个以上」变成目标串 `s`，能就计数。

### 精讲（零基础版）

#### ① 这题要用到的东西

**行程编码（把连续相同字符压成一组）**

一句人话：把字符串里每一段连续相同的字符，记成「字符 + 出现几次」这样的一对。

生活类比：像把一长串「啊啊啊哦哦」记成「a 三个，o 两个」，长度信息一眼就看到。

```python
s = "heeellooo"
groups = []
for ch in s:
    if groups and groups[-1][0] == ch:
        groups[-1][1] += 1
    else:
        groups.append([ch, 1])
print(groups)     # -> [['h', 1], ['e', 3], ['l', 2], ['o', 3]]
```

它在这题里干什么：把 `s` 和每个查询词都压成组，比较就从「比字符」变成「比组」。

**`zip()` 同时遍历两个列表**

一句人话：`zip(a, b)` 把两个列表按位置配成一对一对，一次循环就能同时拿到两边。

生活类比：像把两张清单并排放在一起，一行一行对照着看。

```python
a = [('h', 1), ('e', 3)]
b = [('h', 1), ('e', 1)]
print(list(zip(a, b)))
# -> [(('h', 1), ('h', 1)), (('e', 3), ('e', 1))]
```

它在这题里干什么：`for (c1, n1), (c2, n2) in zip(target, g)` 一次拿到「目标组」和「查询组」。

#### ② 大白话：这题到底在干什么

扩张操作只能干一件事：把某个连续字母组变长，而且变长之后长度必须至少是 3。

所以先把 `s` 和查询词都压成「字母 + 次数」的组列表。然后逐条判断：

第一，两边的组数必须一样，否则连字母的骨架都对不上，不可能通过拉长来匹配。

第二，每一组的字母必须相同。

第三，次数上有三条限制：目标的次数不能比查询的次数少（只能拉长不能缩短）；如果两边次数一样，那没问题，不用拉；如果不一样，那目标的次数必须至少是 3——因为「拉长到 2」是不允许的，只能拉到 3 或更多。

三条都满足才算可扩张。统计满足的个数就是答案。

#### ③ 拿一个具体输入走一遍

`s = "heeellooo"`，`words = ["hello","hi","helo"]`：

| 对象 | 组状态 | 判断结果 |
| --- | --- | --- |
| `s` | `[('h',1), ('e',3), ('l',2), ('o',3)]` | 目标骨架 |
| `"hello"` | `[('h',1), ('e',1), ('l',2), ('o',1)]` | 组数 4 相同，字母相同，每组目标次数都 ≥ 查询次数，且不同处目标都 ≥ 3 → 可扩张 |
| `"hi"` | `[('h',1), ('i',1)]` | 只有 2 组，组数不同 → 不可扩张 |
| `"helo"` | `[('h',1), ('e',1), ('l',1), ('o',1)]` | 第 3 组目标 2、查询 1，不相等且目标 2 < 3 → 不可扩张 |
| 统计 | 只有 `"hello"` 通过 | 返回 1 |

所以答案是 `1`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `def encode(w):` | 小工具：把字符串压成组列表 |
| `if groups and groups[-1][0] == ch:` | 和上一组是同一个字符 |
| `groups[-1][1] += 1` | 次数加一 |
| `else: groups.append([ch, 1])` | 否则开新的一组 |
| `if len(g) != len(target): continue` | 组数不同直接跳过 |
| `if c1 != c2 or n1 < n2:` | 字母不同，或目标次数更少 |
| `or (n1 != n2 and n1 < 3)` | 次数不同但目标不到 3，没法拉长 |
| `if good: cnt += 1` | 全部通过就计数 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def expressiveWords(self, s: str, words: List[str]) -> int:
        def encode(w: str):
            groups = []
            for ch in w:
                if groups and groups[-1][0] == ch:
                    groups[-1][1] += 1
                else:
                    groups.append([ch, 1])
            return groups

        target = encode(s)
        cnt = 0
        for w in words:
            g = encode(w)
            if len(g) != len(target):
                continue
            good = True
            for (c1, n1), (c2, n2) in zip(target, g):
                if c1 != c2 or n1 < n2 or (n1 != n2 and n1 < 3):
                    good = False
                    break
            if good:
                cnt += 1
        return cnt
```

## 42-29. 优势洗牌（Medium）

> 力扣 870 · 双指针 · Medium

**一句话**：重排 `nums1`，让尽量多的位置满足 `nums1[i] > nums2[i]`。

### 精讲（零基础版）

#### ① 这题要用到的东西

**贪心（田忌赛马）**

一句人话：每一步只做一个当下最划算的决定——能赢就用「刚好能赢的最小牌」去赢，赢不了就用「最小的牌」去送掉。

生活类比：田忌赛马。上等马对中等马，中等马对下等马，下等马对上等马（送掉），总胜场最多。

```python
a = sorted([2, 7, 11, 15])
lo, hi = 0, len(a) - 1
print(a[lo], a[hi])      # -> 2 15
print(a[hi] > 11)        # -> True
```

它在这题里干什么：`a[lo]` 是最小的牌（用来送），`a[hi]` 是最大的牌（用来赢）。

**`sorted(range(n), key=...)` 按下标排序**

一句人话：`range(n)` 是 0 到 n-1，按 `nums2` 的值给这些下标排序，就得到「从大到小的处理顺序」。

生活类比：像给一堆任务按难度排个先后，但任务本身不动，只是记下「先做第几号」。

```python
nums2 = [1, 10, 4, 11]
order = sorted(range(4), key=lambda i: -nums2[i])
print(order)     # -> [3, 1, 2, 0]
```

它在这题里干什么：`order` 就是从大到小处理 `nums2` 的顺序，先解决最难赢的对手。

#### ② 大白话：这题到底在干什么

要让尽量多的位置赢，关键是别浪费牌：拿大牌去打小对手是浪费。

标准做法是把 `nums1` 从小到大排好，然后从「最难赢的对手」开始处理，也就是按 `nums2` 的值从大到小。

手里还剩一段排好的牌，用两个下标标出最小和最大。面对当前这个对手：如果手里最大的牌能赢它，就派最大的牌上，赢下这一场；如果连最大的都赢不了，那这场怎么打都赢不了，就派手里最小的牌去送掉，把大牌留给后面更容易的对手。

这样贪心地走完，胜场就是最多的。

#### ③ 拿一个具体输入走一遍

`nums1 = [2,7,11,15]`，`nums2 = [1,10,4,11]`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 排序 | `a = [2,7,11,15]` | `nums1` 从小到大 |
| 处理顺序 | `nums2` 降序下标 `[3,1,2,0]` | 先解决 11 这个最难赢的 |
| 对手 11 | 手上最大 15 > 11 | 派 15 赢下，`ans[3]=15`，`hi=2` |
| 对手 10 | 手上最大 11 > 10 | 派 11 赢下，`ans[1]=11`，`hi=1` |
| 对手 4 | 手上最大 7 > 4 | 派 7 赢下，`ans[2]=7`，`hi=0` |
| 对手 1 | 手上最大 2 > 1 | 派 2 赢下，`ans[0]=2` |
| 结束 | `[2,11,7,15]` | 4 个位置全赢 |

所以答案是 `[2,11,7,15]`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `a = sorted(nums1)` | 牌从小到大排好 |
| `order = sorted(range(n), key=lambda i: -nums2[i])` | 对手从大到小处理 |
| `lo, hi = 0, n - 1` | 手上最小牌和最大牌的下标 |
| `for idx in order:` | 一个个对手解决 |
| `if a[hi] > nums2[idx]:` | 最大牌能赢这个对手 |
| `ans[idx] = a[hi]; hi -= 1` | 派最大牌赢下 |
| `else: ans[idx] = a[lo]; lo += 1` | 赢不了就派最小牌送掉 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def advantageCount(self, nums1: List[int], nums2: List[int]) -> List[int]:
        a = sorted(nums1)
        n = len(nums2)
        ans = [0] * n
        order = sorted(range(n), key=lambda i: -nums2[i])
        lo, hi = 0, n - 1
        for idx in order:
            if a[hi] > nums2[idx]:
                ans[idx] = a[hi]
                hi -= 1
            else:
                ans[idx] = a[lo]
                lo += 1
        return ans
```

## 42-30. 救生艇（Medium）

> 力扣 881 · 双指针 · Medium

**一句话**：每艘船最多载两人、总重不超过 `limit`，问最少要几艘船。

### 精讲（零基础版）

#### ① 这题要用到的东西

**贪心**（前面 42-29 讲过）：每一步只做当下最划算的决定。这题里是「最重的人优先上船，能捎上最轻的就捎上」。

**排序 + 对撞双指针**（前面 42-7 讲过）：`people.sort()` 之后，左指针指最轻的、右指针指最重的，往中间夹。这题用它一轮一轮地安排船。

```python
people = [3, 2, 2, 1]
people.sort()
print(people)              # -> [1, 2, 2, 3]
i, j = 0, len(people) - 1
print(people[i], people[j])    # -> 1 3
```

它在这题里干什么：`people[j]` 是最重的人，`people[i]` 是最轻的人，两者之和决定能不能同船。

#### ② 大白话：这题到底在干什么

要让船数最少，就得让每艘船尽量坐满两个人。

最重的那个人一定得上船，谁也躲不掉。那不如让他先上，然后看他还能不能捎上最轻的那个人：如果两人加起来不超重，就让最轻的也上这艘船，一举两得；如果超重，那最轻的都捎不上，别人更不行，最重的只能一个人走。

于是把体重从小到大排好，左右两个指针。每一轮先安排最重的那个人（右指针），然后试着把最轻的（左指针）塞给他。塞得下就左指针也往里走一格。右指针每轮都往里走一格，船数加一。两个指针交叉时，所有人都安排完了。

#### ③ 拿一个具体输入走一遍

`people = [3,2,2,1]`，`limit = 3`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 排序 | `[1,2,2,3]` | 从小到大 |
| 第 1 轮 | 最重 3 + 最轻 1 = 4 > 3 | 3 只能单独一船，`boats=1`，`j=2` |
| 第 2 轮 | 最重 2 + 最轻 1 = 3 ≤ 3 | 两人同船，`boats=2`，`i=1`，`j=1` |
| 第 3 轮 | 最重 2 + 最轻 2 = 4 > 3 | 剩下的 2 单独一船，`boats=3` |
| 结束 | `boats=3` | 返回 3 |

所以答案是 `3`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `people.sort()` | 按体重从小到大排 |
| `i, j = 0, len(people) - 1` | 最轻、最重两个指针 |
| `boats = 0` | 船数从 0 开始 |
| `while i <= j:` | 还有人没上船 |
| `if people[i] + people[j] <= limit:` | 最轻的能和他同船 |
| `i += 1` | 最轻的也上船了 |
| `j -= 1` | 最重的上船了 |
| `boats += 1` | 用掉一艘船 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def numRescueBoats(self, people: List[int], limit: int) -> int:
        people.sort()
        i, j = 0, len(people) - 1
        boats = 0
        while i <= j:
            if people[i] + people[j] <= limit:
                i += 1
            j -= 1
            boats += 1
        return boats
```

## 42-31. 一次编辑（Medium）

> 力扣 面试题 01.05 · 双指针 · Medium

**一句话**：判断两个字符串能不能只靠「插入、删除、替换」其中一个字符（或零次）就变成对方。

### 精讲（零基础版）

#### ① 这题要用到的东西

**长度差决定操作类型**

一句人话：长度差超过 1，肯定不行；长度相等只可能是「替换」；长度差正好 1 只可能是「插入或删除」。

生活类比：两排人数不同的队伍，差两个以上不可能只调整一次；人数一样才可能只换一个人。

```python
print(abs(len("pale") - len("ple")))     # -> 1
print(abs(len("pales") - len("pal")))    # -> 2
```

它在这题里干什么：差 2 直接返回 False；差 0 走替换逻辑，差 1 走插入删除逻辑。

**把短串换到前面**（交换两个变量前面 42-8 讲过）：`first, second = second, first` 一行就能对调。这题先用它保证 `first` 总是短的那个，后面的分支只用考虑「短的走完了没有」。

#### ② 大白话：这题到底在干什么

先看长度：差两个及以上，一次编辑救不回来，直接 False。

然后统一成 `first` 是短的那个，用两个指针同时扫。字符相同就都往后走一格。字符不同，说明必须用掉那唯一的一次编辑：如果之前已经用过一次了，那就不行，返回 False；没用过就记下来「用掉了」，然后根据长度决定怎么走——长度相等说明是替换，两个指针都要往后走；长度不等说明是插入或删除，只有长串的指针往后走，短串留在原地等匹配。

循环结束时如果短串走完了，说明长串最多还剩一个字符（因为长度差不超过 1），也算一次编辑，返回 True。

#### ③ 拿一个具体输入走一遍

`first = "pale"`，`second = "ple"`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 换位 | `first="ple"`，`second="pale"` | 让短的在前 |
| i=0,j=0 | 'p' 与 'p' | 相同，都前进 |
| i=1,j=1 | 'l' 与 'a' | 不同，用掉唯一一次编辑，`j→2` |
| i=1,j=2 | 'l' 与 'l' | 相同，都前进 |
| i=2,j=3 | 'e' 与 'e' | 相同，都前进，短串走完 |
| 结束 | `used = True` | 返回 True |

所以答案是 `True`（"pale" 删掉 'a' 就是 "ple"）。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `if abs(len(first) - len(second)) > 1: return False` | 长度差太多，不可能 |
| `if len(first) > len(second): first, second = second, first` | 保证 first 是短的那个 |
| `used = False` | 那一次编辑还没用掉 |
| `if first[i] == second[j]:` | 字符相同，都前进 |
| `else:` | 遇到不同 |
| `if used: return False` | 已经用过一次编辑了，不行 |
| `used = True` | 用掉这一次 |
| `if len(first) == len(second): i += 1` | 长度相等是替换，短的也要走 |
| `j += 1` | 长串总要往前走一格 |
| `return True` | 扫完没出事 |

### 完整代码（Python）

```python
class Solution:
    def oneEditAway(self, first: str, second: str) -> bool:
        if abs(len(first) - len(second)) > 1:
            return False
        if len(first) > len(second):
            first, second = second, first
        i = j = 0
        used = False
        while i < len(first) and j < len(second):
            if first[i] == second[j]:
                i += 1
                j += 1
            else:
                if used:
                    return False
                used = True
                if len(first) == len(second):
                    i += 1
                j += 1
        return True
```

## 42-32. 文本左右对齐（Hard）

> 力扣 68 · 字符串 · Hard

**一句话**：把单词贪心地塞进每行 `maxWidth` 个字符里，除最后一行外要左右两端对齐。

### 精讲（零基础版）

#### ① 这题要用到的东西

**`divmod` 一次算出商和余数**

一句人话：`divmod(a, b)` 返回 `(a // b, a % b)`，也就是「平均每份多少」和「还多出来几个」。

生活类比：把 8 个苹果分给 3 个人，`divmod(8, 3)` 得到「每人 2 个，还剩 2 个」，剩下的这 2 个按规矩给前面的人多分一个。

```python
print(divmod(8, 2))     # -> (4, 0)
print(divmod(8, 3))     # -> (2, 2)
print(divmod(3, 2))     # -> (1, 1)
```

它在这题里干什么：`base, extra = divmod(空格总数, 空隙数)`，`base` 是每个空隙至少几个空格，`extra` 是多出来的几个空隙各加一个（从左往右加）。

**`' ' * n` 重复空格**

一句人话：字符串乘以整数就是把内容重复那么多次。

生活类比：像盖章，盖几次就有几个。

```python
print('a' + ' ' * 3 + 'b')    # -> a   b
print(len(' ' * 5))           # -> 5
```

它在这题里干什么：按算出来的空格数一次性造出填充串。

**贪心**（前面 42-29 讲过）：这题用贪心分行——能塞就继续塞，塞不下就结算这一行。这题用它把单词分成若干行。

#### ② 大白话：这题到底在干什么

分两大步。

第一步，分行。从第一个单词开始往当前行里塞，每塞一个要占「单词长度 + 一个空格」。如果塞进去会超过 `maxWidth`，就结算当前行，从这个单词开始新的一行。因为每次都是「能塞就塞」，所以每行放的单词最多，这就是贪心。

第二步，填充每一行。要区分三种情况：最后一行、只有一个单词的行、普通行。最后一行左对齐，单词间一个空格，剩下的位置全补在末尾。只有一个单词的行也是左对齐，后面全补空格。普通行要把 `maxWidth` 减去所有字母数得到空格总数，再除以空隙数（单词数减 1）平均分配；除不尽时，多出来的空格从左往右每个空隙多给一个，这样左边空隙比右边宽，符合题目要求。

#### ③ 拿一个具体输入走一遍

`words = ["This","is","an","example","of","text","justification."]`，`maxWidth = 16`：

| 步骤 | 变量状态 | 发生了什么 |
| --- | --- | --- |
| 塞单词 | 依次放入 This、is、an，字母数 8 | 再加 example(7) 会超过 16，结算第一行 |
| 第一行填充 | 8 个字母，空格总数 8，2 个空隙 | `divmod(8,2)=(4,0)`，每个空隙 4 个空格 → `"This    is    an"` |
| 继续塞 | 放入 example、of、text，字母数 13 | 再加 justification. 会超，结算第二行 |
| 第二行填充 | 空格总数 3，2 个空隙 | `divmod(3,2)=(1,1)`，左空隙 2 个、右空隙 1 个 → `"example  of text"` |
| 最后一行 | `["justification."]`，字母 14 | 左对齐补 2 个空格 → `"justification.  "` |
| 返回 | 三行，每行长度都是 16 | 返回列表 |

所以答案是 `["This    is    an", "example  of text", "justification.  "]`。

#### ④ 代码逐行对译

| 代码 | 大白话 |
| --- | --- |
| `if cur_len + len(cur) + len(w) > maxWidth:` | 这个单词塞不进去了（已含分隔空格） |
| `lines.append((cur, cur_len))` | 结算当前行，记下单词和字母总数 |
| `cur = [w]; cur_len = len(w)` | 新的一行从这个单词开始 |
| `last = idx == len(lines) - 1` | 是不是最后一行 |
| `if last or len(ws) == 1:` | 最后一行或只有一个单词，左对齐 |
| `' '.join(ws) + ' ' * (maxWidth - letters - (len(ws) - 1))` | 单词间一个空格，剩余补在末尾 |
| `spaces = maxWidth - letters` | 这一行总共要放多少空格 |
| `base, extra = divmod(spaces, gaps)` | 每个空隙至少几个，多出来几个 |
| `base + (1 if i < extra else 0)` | 前面的空隙多给一个 |
| `''.join(parts)` | 拼成这一行 |

### 完整代码（Python）

```python
from typing import List


class Solution:
    def fullJustify(self, words: List[str], maxWidth: int) -> List[str]:
        lines = []
        cur = []
        cur_len = 0
        for w in words:
            if cur_len + len(cur) + len(w) > maxWidth:
                lines.append((cur, cur_len))
                cur = [w]
                cur_len = len(w)
            else:
                cur.append(w)
                cur_len += len(w)
        if cur:
            lines.append((cur, cur_len))

        out = []
        for idx, (ws, letters) in enumerate(lines):
            last = idx == len(lines) - 1
            if last or len(ws) == 1:
                out.append(' '.join(ws) + ' ' * (maxWidth - letters - (len(ws) - 1)))
            else:
                gaps = len(ws) - 1
                spaces = maxWidth - letters
                base, extra = divmod(spaces, gaps)
                parts = []
                for i in range(gaps):
                    parts.append(ws[i])
                    parts.append(' ' * (base + (1 if i < extra else 0)))
                parts.append(ws[-1])
                out.append(''.join(parts))
        return out
```
