# 一、查找

## ① 哈希表

**信号词**：「两数之和」「是否出现过」「去重」「计数」「第一个只出现一次」「下标映射」

**核心**：用 `dict` / `set` 把"遍历一遍才能找到"变成"O(1) 直接查"。

```python
# 骨架：一边遍历一边记录，用"当前 + 记录"拼答案
seen = {}
for i, x in enumerate(nums):
    need = target - x
    if need in seen:            # O(1) 查
        return [seen[need], i]
    seen[x] = i                 # 记录：值 -> 下标
```

**为什么是 O(n)**：每个元素进表一次、查一次，都是 O(1)。

**常见变体**：
- 计数：`d[x] = d.get(x, 0) + 1`
- 分组：`defaultdict(list)`
- 去重：`set`

**对应题目**：1 两数之和、560 和为 K 的子数组、554 砖墙、820 单词的压缩编码、415 字符串相加

## ② 前缀和 + 哈希

**信号词**：「子数组和等于 k」「连续子数组」「和为某值」

**核心**：`sum(nums[i..j]) = pre[j+1] - pre[i]`。所以"找和为 k 的子数组" = "找两个前缀和相差 k"。

```python
# 骨架
count = {0: 1}          # ★ 空前缀和为 0，出现 1 次
pre = 0
ans = 0
for x in nums:
    pre += x
    if pre - k in count:        # 存在前缀和 = pre - k
        ans += count[pre - k]
    count[pre] = count.get(pre, 0) + 1
```

**最容易错的点**：`count = {0: 1}` 这一行。它的意思是"从数组开头到当前位置的子数组"这种情况也要算进去。**漏了它会漏掉所有从下标 0 开始的答案。**

**对应题目**：560 和为 K 的子数组、724 寻找数组的中心下标、1109 航班预订统计

# 二、扫描

## ③ 双指针（对撞）

**信号词**：「有序数组」「两数之和（有序）」「三数之和」「盛最多水的容器」「反转」

**核心**：两个指针从两头往中间走，根据当前情况决定动哪一个。

```python
left, right = 0, len(nums) - 1
while left < right:
    s = nums[left] + nums[right]
    if s == target:
        # 找到
        left += 1; right -= 1
    elif s < target:
        left += 1          # 太小，左指针右移让和变大
    else:
        right -= 1         # 太大，右指针左移让和变小
```

**为什么可以这么走**：因为数组有序。`nums[left] + nums[right] < target` 时，`left` 和任何 `<= right` 的数相加都太小，所以 `left` 可以直接跳过。

**对应题目**：15 三数之和、167 两数之和 II、11 盛最多水的容器、344 反转字符串

---

## ④ 双指针（快慢）

**信号词**：「原地删除」「链表找环」「找中点」「倒数第 k 个」

**核心**：一个走得快一个走得慢，快慢差决定它们的位置关系。

```python
# 数组：原地删除重复/指定元素
slow = 0
for fast in range(len(nums)):
    if nums[fast] != val:
        nums[slow] = nums[fast]     # 保留
        slow += 1
return slow                          # 新长度

# 链表：快慢指针找中点
slow = fast = head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
# 此时 slow 在中点
```

**对应题目**：27 移除元素、26 删除有序数组中的重复项、19 删除链表倒数第 N 个、141/142 环形链表、876 链表中点

## ⑤ 滑动窗口（变长）

**信号词**：「最长/最短的连续子数组/子串」「满足某条件的连续区间」「不重复」「至多 K 个」

**核心**：右端一直扩张，当窗口不满足条件时收缩左端。**左端只前进不后退**，所以总共 O(n)。

```python
left = 0
ans = 0
window = {}                  # 或 Counter / 计数变量，看题目需要维护什么
for right in range(len(s)):
    # 1. 右端进窗口
    window[s[right]] = window.get(s[right], 0) + 1

    # 2. 当窗口不合法，收缩左端
    while 窗口不合法:
        window[s[left]] -= 1
        if window[s[left]] == 0:
            del window[s[left]]
        left += 1

    # 3. 此时窗口合法，更新答案
    ans = max(ans, right - left + 1)
```

**三个必须想清楚的问题**：
1. **窗口里维护什么状态？**（字符计数？和？不同字符数？）
2. **什么条件算"不合法"？**（有重复？和超过 target？不同字符超过 k？）
3. **什么时候更新答案？**（每次循环都更新，还是只在合法时更新？）

**对应题目**：3 无重复字符的最长子串、209 长度最小的子数组、1004 最大连续 1 的个数 III、340 至多包含 K 个不同字符

## ⑥ 滑动窗口（定长）

**信号词**：「长度为 k 的窗口」「固定大小」「窗口内的最大/最小」

**核心**：窗口大小固定，整体平移：右边进一个、左边出一个。

```python
# 骨架：定长窗口 k
window_sum = sum(nums[:k])
ans = window_sum
for i in range(k, len(nums)):
    window_sum += nums[i]        # 右边进
    window_sum -= nums[i - k]    # 左边出
    ans = max(ans, window_sum)
```

**对应题目**：567 字符串的排列、438 找到字符串中所有字母异位词、643 子数组最大平均数、239 滑动窗口最大值（这题要单调队列）

# 三、结构

## ⑦ 栈

**信号词**：「括号匹配」「嵌套」「撤销」「最近一次」「表达式求值」「字符串解码」

**核心**：Python 里就是 `list`，`append` / `pop` 都在尾巴上，O(1)。

```python
stack = []
for c in s:
    if 是左括号:
        stack.append(c)          # 入栈
    else:
        if not stack:            # 栈空 = 没有匹配的左括号
            return False
        if stack[-1] != 对应的左括号:
            return False
        stack.pop()              # 出栈
return len(stack) == 0           # ★ 最后必须清空
```

**对应题目**：20 有效的括号、394 字符串解码、227 基本计算器 II、735 小行星碰撞

---

## ⑧ 单调栈

**信号词**：「下一个更大/更小的元素」「左右第一个比它大/小的」「接雨水」「柱状图最大矩形」

**核心**：栈里保持**单调**（递增或递减）。新元素进来时，把所有"被它打败"的元素弹出去——弹出去的那一刻，就找到了那个元素的答案。

```python
# 骨架：找"下一个更大"（栈里存下标，单调递减）
stack = []                       # 存下标
ans = [0] * len(nums)
for i, x in enumerate(nums):
    while stack and nums[stack[-1]] < x:   # 栈顶比当前小 → 栈顶的答案就是 i
        j = stack.pop()
        ans[j] = i - j                     # 或者 ans[j] = x，看题目要什么
    stack.append(i)
# 循环结束后栈里剩下的，就是"后面没有更大的"
```

**为什么是 O(n)**：每个元素最多进栈一次、出栈一次（见 02 章摊还分析）。

**对应题目**：739 每日温度、496 下一个更大元素、316 去除重复字母、42 接雨水、84 柱状图中最大的矩形

---

## ⑨ 单调队列

**信号词**：「滑动窗口最大值/最小值」

**核心**：用 `deque` 维护一个**下标单调递增、值单调递减**的队列，队头永远是当前窗口最大值。

```python
from collections import deque
q = deque()                      # 存下标，对应值单调递减
ans = []
for i, x in enumerate(nums):
    while q and nums[q[-1]] <= x:   # 比新元素小的都出队（它们永远不可能成为最大值了）
        q.pop()
    q.append(i)
    if q[0] <= i - k:               # 队头滑出窗口
        q.popleft()
    if i >= k - 1:
        ans.append(nums[q[0]])      # 队头就是最大值
```

**对应题目**：239 滑动窗口最大值

## ⑩ 堆

**信号词**：「第 K 大/小」「Top K」「动态求最值」「合并 K 个有序」

**核心**：`heapq` 是小顶堆。求 Top K **大**，就维护一个大小为 k 的**小顶堆**（堆顶是这 k 个里最小的，来了更大的就换掉它）。

```python
import heapq
# Top K 大
h = []
for x in nums:
    heapq.heappush(h, x)
    if len(h) > k:
        heapq.heappop(h)          # 弹掉最小的
return h[0]                       # 第 k 大

# 或者直接用
heapq.nlargest(k, nums)
```

**对应题目**：215 数组中的第 K 个最大元素、347 前 K 个高频元素、23 合并 K 个升序链表

# 四、节点

## ⑪ 链表

**信号词**：题目直接给 `ListNode`

**核心三件套**：

```python
# 1. 哑节点（dummy）：处理"可能要删/插头节点"的情况
dummy = ListNode(0)
dummy.next = head
cur = dummy
...
return dummy.next                 # 返回时跳过哑节点

# 2. 反转链表（三个指针，顺序不能错）
prev, cur = None, head
while cur:
    nxt = cur.next                # ★ 先存下一个
    cur.next = prev               # 掉头
    prev = cur                    # prev 前进
    cur = nxt                     # cur 前进
return prev                       # prev 是新的头

# 3. 快慢指针（找中点/找环/倒数第 k）
slow = fast = head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
```

**对应题目**：206 反转链表、19 删除倒数第 N 个、21 合并两个有序链表、146 LRU 缓存、141/142 环形链表

---

## ⑫ 二叉树

**信号词**：题目给 `TreeNode`

**核心：递归 = 左子树答案 + 右子树答案 + 根节点自己**

```python
# 骨架：递归 DFS（"信任递归"：假设左右子树已经算好了）
def dfs(node):
    if node is None:              # 基线条件
        return 某个初始值
    left = dfs(node.left)         # 信任：左子树答案
    right = dfs(node.right)       # 信任：右子树答案
    return 用 left, right, node.val 组合成答案
```

**三种遍历的区别**（就是"根"什么时候处理）：

| 遍历 | 顺序 | 代码位置 |
|---|---|---|
| 前序 | 根 → 左 → 右 | 先 `res.append(node.val)`，再递归 |
| 中序 | 左 → 根 → 右 | 递归左，再 `res.append`，再递归右 |
| 后序 | 左 → 右 → 根 | 递归完左右，再 `res.append` |

**BFS 层序遍历**（要按层处理时用）：

```python
from collections import deque
q = deque([root])
while q:
    level = []
    for _ in range(len(q)):       # ★ 先记住当前层有多少个
        node = q.popleft()
        level.append(node.val)
        if node.left: q.append(node.left)
        if node.right: q.append(node.right)
    res.append(level)
```

**对应题目**：94 中序遍历、102 层序遍历、104 最大深度、105 从前序中序构造二叉树、226 翻转二叉树

## ⑬ 图

**信号词**：「连通块」「岛屿」「路径」「依赖关系」「课程安排」

**核心：图就是"邻接表 + 遍历"**。两种表示：

```python
# 网格图（岛屿问题）：直接遍历上下左右
for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
    nr, nc = r + dr, c + dc
    if 0 <= nr < m and 0 <= nc < n:
        ...

# 邻接表（课程表、朋友圈）
graph = [[] for _ in range(n)]
for a, b in edges:
    graph[a].append(b)
```

**连通块模板（DFS 淹岛）**：

```python
def dfs(r, c):
    if 越界 or grid[r][c] != '1':
        return
    grid[r][c] = '0'              # ★ 标记已访问（淹掉）
    for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
        dfs(r + dr, c + dc)

count = 0
for r in range(m):
    for c in range(n):
        if grid[r][c] == '1':
            count += 1
            dfs(r, c)             # 把整座岛淹掉
```

**拓扑排序（判环）**：

```python
indeg = [0] * n
for a, b in edges:                # b -> a，先修 b
    graph[b].append(a)
    indeg[a] += 1

q = deque(i for i in range(n) if indeg[i] == 0)
cnt = 0
while q:
    u = q.popleft()
    cnt += 1
    for v in graph[u]:
        indeg[v] -= 1
        if indeg[v] == 0:
            q.append(v)
return cnt == n                   # 全部上完 = 无环
```

**对应题目**：200 岛屿数量、207 课程表、547 省份数量、994 腐烂的橘子、684 冗余连接

# 五、搜索

## ⑭ 回溯

**信号词**：「所有可能的」「组合」「排列」「子集」「N 皇后」「括号生成」

**核心：做选择 → 递归 → 撤销选择**（撤销是灵魂）。

```python
res = []
path = []

def backtrack(选择列表):
    if 满足结束条件:
        res.append(path[:])       # ★ 一定要复制！
        return
    for 选择 in 选择列表:
        if 不合法: continue        # 剪枝
        path.append(选择)          # 做选择
        backtrack(新的选择列表)     # 递归
        path.pop()                # ★ 撤销选择

backtrack(初始选择列表)
```

**最容易错的两个点**：
1. `res.append(path)` 而不是 `path[:]` → 最后全是空列表（因为 path 是同一个对象）
2. 忘了 `path.pop()` → 路径越积越多

**对应题目**：46 全排列、22 括号生成、78 子集、39 组合总和、51 N 皇后、679 24 点游戏

## ⑮ 二分

**信号词**：「有序数组」「查找目标」「第一个/最后一个」「旋转数组」「答案单调」

**核心：每次砍一半**。本教材统一用**左闭右闭**写法，不容易死循环。

```python
left, right = 0, len(nums) - 1
while left <= right:              # ★ 注意是 <=
    mid = (left + right) // 2
    if nums[mid] == target:
        return mid
    elif nums[mid] < target:
        left = mid + 1            # ★ 注意 +1
    else:
        right = mid - 1           # ★ 注意 -1
return -1
```

**三个死循环陷阱**：
1. `while left < right` 配 `left = mid` → 死循环（mid 不变）
2. `left = mid` 而不是 `mid + 1` → 死循环
3. 找边界时（第一个 >= target），返回 `left` 而不是 `mid`

**对应题目**：704 二分查找、34 查找第一个和最后一个位置、33 搜索旋转排序数组、69 x 的平方根

# 六、决策

## ⑯ 动态规划

**信号词**：「最多/最少/最大/最小」「有多少种方案」「能不能」「前 i 个」「最优子结构」

**核心三步**：

1. **定义状态**：`dp[i]` 表示什么？用一句人话说出来（这一步最难，也最关键）
2. **写转移方程**：`dp[i]` 从哪些更小的状态来？
3. **初始化 + 遍历顺序**：边界是什么？从小到大还是从大到小？

```python
# 一维 DP 骨架（以 53 最大子数组和为例）
dp = [0] * n
dp[0] = nums[0]                       # 初始化
for i in range(1, n):
    dp[i] = max(nums[i], dp[i-1] + nums[i])   # 转移
return max(dp)

# 二维 DP 骨架（以 1143 最长公共子序列为例）
dp = [[0] * (n + 1) for _ in range(m + 1)]    # ★ +1 是为了空串
for i in range(1, m + 1):
    for j in range(1, n + 1):
        if a[i-1] == b[j-1]:
            dp[i][j] = dp[i-1][j-1] + 1
        else:
            dp[i][j] = max(dp[i-1][j], dp[i][j-1])
return dp[m][n]
```

**常见类型**：
- 线性 DP（53、300、5）
- 背包（322 完全背包、518、416 0-1 背包）
- 二维/区间（1143、72 编辑距离）
- 树形 DP（337）

**对应题目**：53、322、300、1143、5、72、198、416

---

## ⑰ 贪心

**信号词**：「最少需要几步」「最大覆盖」「区间调度」「能不能到达」

**核心：每一步都选当前看起来最好的，不回头。** 难点不在代码，在**证明"局部最优能推出全局最优"**。

```python
# 骨架：维护一个"当前状态"，每步更新它
cur = 0
for x in nums:
    cur = max(cur, 某表达式)      # 贪心选择
    if 满足条件:
        ...
```

**对应题目**：55 跳跃游戏、45 跳跃游戏 II、134 加油站、56 合并区间、435 无重叠区间

| 最长/最短的连续子串、不重复 | ⑤ 滑动窗口（变长） |
| 长度为 k 的窗口 | ⑥ 滑动窗口（定长） |
| 括号、嵌套、表达式、解码 | ⑦ 栈 |
| 下一个更大/更小、接雨水 | ⑧ 单调栈 |
| 滑动窗口最大值 | ⑨ 单调队列 |
| 第 K 大、Top K | ⑩ 堆 |
| 题目给 ListNode | ⑪ 链表三件套 |
| 题目给 TreeNode | ⑫ 二叉树递归 |
| 连通块、岛屿、依赖、课程表 | ⑬ 图 |
| 所有可能的组合/排列 | ⑭ 回溯 |
| 有序 + 查找、答案单调 | ⑮ 二分 |
| 最多/最少/方案数 | ⑯ 动态规划 |
| 最少步数、最大覆盖、区间 | ⑰ 贪心 |

## 怎么用这一章

1. **第一遍通读**，不求记住，只求"知道有这些模板"。
2. **做题时回来查**：卡住了，先看「信号词 → 模板」表，大概率能找到方向。
3. **刷完一册后回来复习**：你会发现每道题都能挂到某个模板上，这就是"套路库"建立起来了。
